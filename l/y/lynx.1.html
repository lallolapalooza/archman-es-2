LYNX(1) Lynx – el navegador web de texto LYNX(1)

NOMBRE

lynx - un navegador de información distribuida de propósito general para la World Wide Web

SINOPSIS

lynx [opciones] [rutas o URLs opcionales]

lynx [opciones] [ruta o URL] -get_data
datos
--

lynx [opciones] [ruta o URL] -post_data
datos
--

Use “lynx -help” para mostrar una lista completa de las opciones actuales.

DESCRIPCIÓN

Lynx es un cliente completo de World Wide Web (WWW) para usuarios que utilizan dispositivos de visualización con direccionamiento de cursor y celdas de caracteres (por ejemplo, terminales vt100, emuladores vt100 que se ejecutan en Windows o cualquier plataforma POSIX, o cualquier otra pantalla “orientada a curses”). Mostrará documentos de lenguaje de marcado de hipertexto (HTML) que contienen enlaces a archivos que residen en el sistema local, así como archivos que residen en sistemas remotos que ejecutan servidores Gopher, HTTP, FTP, WAIS y NNTP.

Lynx ha sido portado a muchos sistemas, incluidas todas las variantes de Unix, Windows (desde Windows 95), DOS DJGPP y OS/2, así como VMS y OS/390.

Lynx puede usarse para acceder a información en la World Wide Web, o para construir sistemas de información destinados principalmente al acceso local. Por ejemplo, Lynx se ha utilizado para construir varios Sistemas de Información de Campus (CWIS). Además, Lynx puede usarse para construir sistemas aislados dentro de una sola LAN.

OPCIONES

Al iniciarse, Lynx cargará cualquier archivo local o URL remota especificado en la línea de comandos. Para obtener ayuda con las URLs, presione “?” o “H” mientras ejecuta Lynx. Luego siga el enlace titulado “Help on URLs” (Ayuda sobre URLs).

Si se enumeran más de un archivo local o URL remota en la línea de comandos, Lynx solo abrirá el último interactivamente. Todos los nombres (archivos locales y URLs remotas) se agregan al historial de G)oto.

Lynx utiliza solo nombres de opción largos. Los nombres de opción también pueden comenzar con doble guion “--”. Los guiones bajos y guiones se pueden mezclar en los nombres de opción (en la referencia a continuación, las opciones se muestran con un solo guion “-” delante y con guiones bajos “_” en ellas).

Lynx proporciona muchas opciones de línea de comandos. Algunas opciones requieren un valor (cadena, número o palabra clave). Estos se indican en la referencia a continuación. Las otras opciones establecen valores booleanos en el programa. Hay tres tipos de opciones booleanas: establecer, anular y alternar. Si no se proporciona ningún valor de opción, estas tienen el significado obvio: establecer (a verdadero), anular (a falso) o alternar (entre verdadero/falso). Para cualquiera de estas, se puede proporcionar un valor explícito en diferentes formas para permitir las restricciones del sistema operativo, por ejemplo:


-center:off
-center=off
-center-

Lynx reconoce “1”, “+”, “on” y “true” para valores verdaderos, y “0”, “-”, “off” y “false” para valores falsos. Otros valores de opción se ignoran.

Los valores predeterminados booleanos, numéricos y de cadena que se compilan en Lynx se muestran en el mensaje de ayuda proporcionado por lynx -help. Algunos de estos pueden diferir según cómo se haya compilado Lynx; consulte el propio mensaje de ayuda para estos valores. La opción -help se procesa en el tercer pase del procesamiento de opciones, por lo que cualquier opción que establezca un valor, así como los valores de configuración en tiempo de ejecución, se reflejan en el mensaje de ayuda.

-
Si el argumento es solo “-”, entonces Lynx espera recibir los argumentos de la entrada estándar. Esto permite la línea de comandos potencialmente muy larga que puede estar asociada con los argumentos -get_data o -post_data (ver más abajo). También se puede utilizar para evitar tener información confidencial en la línea de comandos de invocación (que sería visible para otros procesos en la mayoría de los sistemas), especialmente cuando se utilizan las opciones -auth o -pauth.
-accept_all_cookies
acepta todas las cookies.
-anonymous
aplica restricciones para la cuenta anónima, ver también -restrictions.
-assume_charset=MIMEname
conjunto de caracteres para documentos que no lo especifican.
-assume_local_charset=MIMEname
conjunto de caracteres asumido para archivos locales, es decir, archivos que Lynx crea, como páginas internas para el menú de opciones.
-assume_unrec_charset=MIMEname
usa esto en lugar de conjuntos de caracteres no reconocidos.
-auth=ID:PASSWD
establece el ID de autorización y la contraseña para documentos protegidos al inicio. Asegúrese de proteger cualquier archivo de script que utilice este modificador.
-base
precede un comentario de URL de solicitud y una etiqueta BASE a las salidas de text/html para volcados de -source.
-bibhost=URL
especifica un servidor bibp local (por defecto http://bibhost/).
-blink
fuerza colores de fondo de alta intensidad para el modo de color, si están disponibles y son compatibles con el terminal. Esto se aplica a la biblioteca slang (para algunos emuladores de terminal), o a OS/2 EMX con ncurses.
-book
usa la página de marcadores como archivo de inicio. El archivo de inicio predeterminado o de línea de comandos todavía está configurado para el comando de pantalla principal y se utilizará si la página de marcadores no está disponible o está en blanco.
-buried_news
alterna el escaneo de artículos de noticias para referencias enterradas y los convierte en enlaces de noticias. No se recomienda porque las direcciones de correo electrónico encerradas entre corchetes angulares se convertirán en enlaces de noticias falsos y los mensajes codificados en uu pueden ser descartados.
-cache=NUMERO
establece el NUMERO de documentos cacheados en memoria. El valor por defecto es 10.
-case
habilita la búsqueda de cadenas que distingue entre mayúsculas y minúsculas.
-center
alterna la alineación centrada en TABLA HTML. Normalmente, las celdas de la tabla están centradas en la cuadrícula de la tabla. Establezca esta opción en “on” para deshabilitar el centrado. El valor por defecto es “off” (desactivado).
-cfg=NOMBREARCHIVO
especifica un archivo de configuración de Lynx distinto del predeterminado lynx.cfg.
-child
sale al presionar la flecha izquierda en el archivo de inicio, y deshabilita el guardado en disco y las opciones asociadas de impresión/correo.
-child_relaxed
sale al presionar la flecha izquierda en el archivo de inicio, pero permite el guardado en disco y las opciones asociadas de impresión/correo.
-cmd_log=NOMBREARCHIVO
escribe comandos de pulsaciones de teclas e información relacionada en el archivo especificado.
-cmd_script=NOMBREARCHIVO
lee comandos de pulsaciones de teclas del archivo especificado. Puedes usar los datos escritos usando la opción -cmd_log. Lynx ignorará otra información que el registro de comandos pueda haber escrito en el archivo de registro. Cada línea del script de comandos contiene un comentario que comienza con “#”, o una palabra clave:
exit
provoca que el script se detenga y obliga a Lynx a salir inmediatamente.
key
el valor del carácter, en forma imprimible. Las teclas de cursor y otras teclas especiales se dan como nombres, por ejemplo, “Flecha Abajo”. Los códigos ASCII de 7 bits imprimibles se dan tal cual, y los valores hexadecimales representan otros códigos de 8 bits.
set
seguido de un “nombre=valor” permite anular uno de los valores valores establecidos en los archivos lynx.cfg o .lynxrc. Lynx intenta primero la configuración del archivo cfg.
-collapse_br_tags
alterna el colapso de las etiquetas BR.
-color
fuerza el modo de color activado, si está disponible. Se asumen secuencias de control de color predeterminadas que funcionan para muchos tipos de terminales si la descripción de la capacidad del terminal no especifica cómo manejar el color. Lynx necesita ser compilado con la biblioteca slang para esta bandera, es equivalente a establecer la variable de entorno COLORTERM. (Si el soporte de color es proporcionado en su lugar por una biblioteca curses capaz de manejar color como ncurses, Lynx depende completamente de la descripción del terminal para determinar si el modo de color es posible, y esta bandera no es necesaria y por lo tanto no está disponible.) Una configuración guardada show_color=always encontrada en un archivo .lynxrc al inicio tiene el mismo efecto. Una configuración guardada show_color=never encontrada en .lynxrc al inicio es anulada por esta bandera.
-connect_timeout=N
Establece el tiempo de espera de conexión, donde N se da en segundos.
-cookie_file=NOMBRE_ARCHIVO
especifica un archivo para leer las cookies. Si no se especifica ninguno, el valor predeterminado es ~/.lynx_cookies para la mayoría de los sistemas, pero ~/cookies para MS-DOS.
-cookie_save_file=NOMBRE_ARCHIVO
especifica un archivo para almacenar las cookies. Si no se especifica ninguno, se utiliza el valor dado por -cookie_file.
-cookies
alterna el manejo de las cabeceras Set-Cookie.
-core
alterna los core dumps forzados en errores fatales. Desactive esta opción para solicitar a Lynx que fuerce un core dump si ocurre un error fatal.
-crawl
con -traversal, guarda cada página en un archivo. con -dump, formatea la salida como con -traversal, pero a la salida estándar.
-curses_pads
alterna el uso de la característica de "pads" de curses que soporta el desplazamiento izquierdo/derecho de la pantalla. La característica está normalmente disponible para configuraciones de curses, pero inactiva. Para activarla, use el carácter “|” o el comando LINEWRAP_TOGGLE. Alternar esta opción hace que la característica sea completamente inaccesible.
-debug_partial
separa las etapas de visualización incremental con un retraso de MessageSecs
-default_colors
alterna la característica de colores predeterminados que normalmente se configura en el archivo lynx.cfg .
-delay
agrega un retraso DebugSecs después de cada mensaje de progreso
-display=DISPLAY
establece la variable de visualización para programas rexec-ados en X.
-display_charset=nombre_MIME
establece el conjunto de caracteres para la salida del terminal.
-dont_wrap_pre
inhibe el ajuste de texto al hacer -dump y -crawl, marca las líneas ajustadas de <pre> en la sesión interactiva.
-dump
guarda la salida formateada del documento predeterminado o los especificados en la línea de comandos a la salida estándar. A diferencia del modo interactivo, todos los documentos son procesados. Esto se puede usar de la siguiente manera: 


lynx -dump http://www.subir.com/lynx.html

Los archivos especificados en la línea de comandos se formatean como HTML si sus nombres terminan con uno de los sufijos web estándar como “.htm” o “.html”. Use la opción -force_html para formatear archivos cuyos nombres no siguen esta convención.
-editor=EDITOR
habilita la edición externa, usando el EDITOR especificado. (vi, ed, emacs, etc.)
-emacskeys
habilita el movimiento de teclas similar a emacs.
-enable_scrollback
alterna la compatibilidad con las teclas de scrollback de los programas de comunicación (puede ser incompatible con algunos paquetes curses).
-error_file=ARCHIVO
define un archivo donde Lynx informará los códigos de acceso HTTP.
-exec
habilita la ejecución de programas locales (normalmente no configurado).
-fileversions
incluye todas las versiones de archivos en los listados de directorios locales de VMS.
-find_leaks
alterna la verificación de fugas de memoria. Normalmente esto no está compilado en tu ejecutable, pero cuando lo está, puede ser deshabilitado para una sesión.
-force_empty_hrefless_a
fuerza que los elementos “A” vacíos sin HREF sean vacíos (ciérralos tan pronto como se vean).
-force_html
fuerza que el primer documento sea interpretado como HTML.
Esto es más útil cuando se procesan archivos especificados en la línea de comandos que tienen un sufijo no reconocido (o el sufijo está asociado con un tipo no HTML, como “.txt” para archivos de texto plano).
Lynx reconoce estos sufijos de archivo como HTML: 


“.ht3”,
“.htm”,
“.html3”,
“.html”,
“.htmlx”,
“.php3”,
“.php”,
“.phtml”,
“.sht”, y
“.shtml”.

-force_secure
alterna el forzado de la bandera segura para cookies SSL.
-forms_options
alterna si el Menú de Opciones se basa en teclas o en formularios.
-from
alterna las transmisiones de cabeceras From.
-ftp
deshabilita el acceso ftp.
-get_data
los datos formateados correctamente para un formulario get se leen de la entrada estándar y se pasan al formulario. La entrada se termina con una línea que comienza con “---”.
Lynx emite un GET HTTP, enviando el formulario a la ruta o URL dada en la línea de comandos e imprime la respuesta del servidor. Si no se proporciona ruta o URL, Lynx envía el formulario a la página de inicio.
-head
envía una solicitud HEAD para las cabeceras mime.
-help
imprime el mensaje de uso de la sintaxis del comando Lynx y sale.
-hiddenlinks=[opción]
controla la visualización de enlaces ocultos.
merge
los enlaces ocultos aparecen como números entre corchetes y se numeran junto con otros enlaces en la secuencia de su aparición en el documento.
listonly
los enlaces ocultos solo se muestran en las pantallas de L)istar y en los listados generados por -dump o desde el menú I)mprimir, pero aparecen por separado al final de esas listas. Este es el comportamiento predeterminado.
ignore
los enlaces ocultos no aparecen ni siquiera en los listados.
-historical
alterna el uso de “>” o “-->” como terminador para los comentarios.
-homepage=URL
establece la página principal por separado de la página de inicio.
-image_links
alterna la inclusión de enlaces para todas las imágenes.
-index=URL
establece el archivo de índice predeterminado a la URL especificada.
-ismap
alterna la inclusión de enlaces ISMAP cuando hay MAPs del lado del cliente.
-justify
justifica el texto.
-link=NÚMERO
recuento inicial para los archivos lnk#.dat producidos por -crawl.
-list_decoded
para -dump, muestra los enlaces codificados en URL decodificados.
-list_inline
para -dump, muestra los enlaces en línea con el texto.
-listonly
para -dump, muestra solo la lista de enlaces.
-localhost
deshabilita las URL que apuntan a hosts remotos.
-locexec
habilita la ejecución de programas locales solo desde archivos locales (si Lynx fue compilado con ejecución local habilitada).
-lss=NOMBRE_ARCHIVO
especifica el nombre del archivo que contiene la información de estilo de color. El valor predeterminado es lynx.lss. Si proporciona un nombre de archivo vacío, Lynx usa un esquema monocromático incorporado que imita la configuración sin estilo de color.
-mime_header
imprime la cabecera MIME de un documento recuperado junto con su fuente.
-minimal
alterna el análisis de comentarios mínimo frente a válido.
-nested_tables
alterna la lógica de tablas anidadas (para depuración).
-newschunksize=NÚMERO
número de artículos en listas de noticias fragmentadas.
-newsmaxchunk=NÚMERO
número máximo de artículos de noticias en las listas antes de fragmentar.
-nobold
deshabilita el atributo de video en negrita.
-nobrowse
deshabilita la navegación de directorios.
-nocc
deshabilita las solicitudes de Cc: para copias propias de los correos. Tenga en cuenta que esto no deshabilita ninguna CC que esté incorporada en una URL mailto o en la ACTION de un formulario.
-nocolor
fuerza la desactivación del modo de color, anulando las capacidades de la terminal y cualquier bandera -color, la variable COLORTERM y la configuración guardada de .lynxrc.
-noexec
deshabilita la ejecución de programas locales. (PREDETERMINADO)
-nofilereferer
deshabilita la transmisión de encabezados Referer para URLs de archivo.
-nolist
deshabilita la función de lista de enlaces en los volcados.
-nolog
deshabilita el envío por correo de mensajes de error a los propietarios de los documentos.
-nomargins
deshabilita los márgenes izquierdo/derecho en la hoja de estilos predeterminada.
-nomore
deshabilita la cadena -more- en los mensajes de la línea de estado.
-nonrestarting_sigwinch
Esta bandera no está disponible en todos los sistemas; Lynx necesita ser compilado con HAVE_SIGACTION definido. Si está disponible, esta bandera puede hacer que Lynx reaccione de manera más inmediata a los cambios de ventana cuando se ejecuta dentro de un xterm.
-nonumbers
deshabilita la numeración de enlaces y campos. Esto anula -number_fields y -number_links.
-nopause
deshabilita las pausas forzadas para los mensajes de la línea de estado.
-noprint
deshabilita la mayoría de las funciones de impresión.
-noredir
impide la redirección automática e imprime un mensaje con un enlace a la nueva URL.
-noreferer
deshabilita la transmisión de encabezados Referer.
-noreverse
deshabilita el atributo de video invertido.
-nosocks
deshabilita el uso del proxy SOCKS por un Lynx con soporte SOCKS.
-nostatus
deshabilita los mensajes de estado de recuperación.
-notitle
deshabilita el título y la línea en blanco de la parte superior de la página.
-nounderline
deshabilita el atributo de video subrayado.
-number_fields
fuerza la numeración de enlaces así como de los campos de entrada de formularios
-number_links
fuerza la numeración de enlaces.
-partial
alterna la visualización de páginas parciales mientras se cargan.
-partial_thres=NÚMERO
número de líneas a renderizar antes de repintar la pantalla con lógica de visualización parcial
-passive_ftp
alterna las conexiones ftp pasivas.
-pauth=ID:CONTRASEÑA
establece el ID de autorización y la contraseña para un servidor proxy protegido al inicio. Asegúrese de proteger cualquier archivo de script que utilice este modificador.
-popup
alterna el manejo de opciones SELECT de opción única a través de ventanas emergentes o como listas de botones de radio.
-post_data
los datos formateados correctamente para un formulario post se leen desde la entrada estándar y se pasan al formulario. La entrada se termina con una línea que comienza con “---”.

-preparsed
muestra el código fuente HTML pre-analizado y reformateado cuando se usa con -source o en vista de fuente.
-prettysrc
muestra la vista de código fuente HTML con elementos léxicos y etiquetas en color.
-print
habilita las funciones de impresión. (predeterminado)
-pseudo_inlines
alterna pseudo-ALT para imágenes en línea sin cadena ALT.
-raw
alterna la configuración predeterminada de traducciones de caracteres de 8 bits o modo CJK para el conjunto de caracteres de inicio.
-realm
restringe el acceso a las URLs dentro del dominio de inicio.
-read_timeout=N
Establece el tiempo de espera de lectura, donde N se da en segundos.
-reload
vacía la caché en un servidor proxy (solo se ve afectado el primer documento dado en la línea de comandos).
-restrictions=[opción][,opción][,opción]...

bookmark_exec

default

Se establece en todas las restricciones, excepto: inside_telnet, outside_telnet, inside_ftp, outside_ftp, inside_rlogin, outside_rlogin, inside_news, outside_news, telnet_port, jump, mail, print, exec y goto. La configuración para estos, así como restricciones adicionales de goto para esquemas de URL específicos que también se aplican, se derivan de las definiciones dentro de userdefs.h.
dired_support

disk_save

file_url

goto

ENTORNO

Además de varias variables de entorno "estándar" como DISPLAY, HOME, PATH, SHELL, TMPDIR, USER, etc., Lynx utiliza varias variables de entorno específicas de Lynx, si existen.

Otras pueden ser creadas o modificadas por Lynx para pasar datos a un programa externo, o por otras razones. Estas se enumeran por separado a continuación.

Consulte también las secciones sobre SOPORTE CGI SIMULADO y SOPORTE DE LENGUAJE NATIVO, a continuación.

Nota: No todas las variables de entorno se aplican a todos los tipos de plataformas compatibles con Lynx, aunque la mayoría sí lo hace. Se solicita retroalimentación sobre las dependencias de plataforma.

Variables de Entorno Utilizadas Por Lynx:

COLORTERM
Si está establecida, la capacidad de color para la terminal se fuerza al inicio. El valor real asignado a la variable se ignora. Esta variable solo es significativa si Lynx fue compilado usando la biblioteca de manejo de pantalla slang.
LYNX_CFG
Esta variable, si está establecida, anulará la ubicación y el nombre predeterminado del archivo de configuración global (normalmente, lynx.cfg) que fue definido por la constante LYNX_CFG_FILE en el archivo userdefs.h, durante la instalación.
Consulte el archivo userdefs.h para obtener más información.
LYNX_CFG_PATH
Si está establecida, esta variable anula la lista de búsqueda de directorios compilada para encontrar los archivos de configuración, por ejemplo, lynx.cfg y lynx.lss. La lista está delimitada por ":" (o ";" para Windows) al igual que la variable de entorno PATH.
LYNX_HELPFILE
Si está establecida, esta variable anula la URL compilada y la URL del archivo de configuración para el archivo de ayuda de Lynx.
LYNX_LOCALEDIR
Si está establecida, esta variable anula la ubicación compilada del directorio de localización que contiene el texto de los mensajes en idioma nativo (NLS).
LYNX_LSS
Esta variable, si está establecida, especifica la ubicación del archivo de hoja de estilo de caracteres predeterminado de Lynx. [Actualmente solo es significativa si Lynx fue compilado con soporte de estilo de color curses.]
LYNX_SAVE_SPACE
Esta variable, si está establecida, anulará el prefijo de ruta predeterminado para los archivos guardados en disco que se define en la declaración lynx.cfg SAVE_SPACE:.
Consulte el archivo lynx.cfg para obtener más información.
LYNX_TEMP_SPACE
Esta variable, si está establecida, anulará el prefijo de ruta predeterminado para los archivos temporales que se definió durante la instalación, así como cualquier valor que se pueda asignar a la variable TMPDIR.
MAIL
Esta variable especifica la bandeja de entrada predeterminada que Lynx comprobará en busca de correo nuevo, si dicha comprobación está habilitada en el archivo lynx.cfg.
NEWS_ORGANIZATION
Esta variable, si está establecida, proporciona la cadena utilizada en la cabecera Organization: de las publicaciones de noticias de USENET. Anulará la configuración de la variable de entorno ORGANIZATION, si también está establecida (y, en UNIX, el contenido de un archivo /etc/organization, si está presente).
NNTPSERVER
Si está establecida, esta variable especifica el servidor NNTP predeterminado que se utilizará para leer y publicar noticias de USENET con Lynx, a través de URLs news:.
ORGANIZATION
Esta variable, si está establecida, proporciona la cadena utilizada en la cabecera Organization: de las publicaciones de noticias de USENET. En UNIX, anulará el contenido de un archivo /etc/organization, si está presente.

ENVIRONMENT

Lynx consults the following environment variables.

COLOR_TERMS
If set, and if Lynx is compiled with color support, then this variable specifies the names of the terminals that support color graphics. The names are separated by colons, and are case-insensitive. The default set is: ansi:vt100:vt102:vt220:xterm:xterm-color:xterm-16color:xterm-256color:xterm-fullcolor.
FTP_PASSIVE_MODE
If set to 1, Lynx will use passive mode FTP transfers. If set to 0, active mode will be used. If unset, passive mode is the default.
LYNX_CFG
If set, this variable specifies the path to the configuration file to be used by Lynx. Otherwise, Lynx looks for the configuration file in the user's home directory (~/.lynxrc) or in the system-wide location (e.g., /etc/lynx.cfg).
LYNX_DATADIR
This variable, if set, specifies the directory for Lynx's data files (e.g., lynx.cfg, lynx.hist, message files, etc.). If unset, Lynx uses a compiled-in default, typically /usr/share/lynx/.
LYNX_HTML_VERSION
This variable may be used to set the default HTML version if the document does not specify one. The value should be one of the following: 2.0, 2.1, 2.1.2, 2.2, 2.3, 2.4, 2.5, 2.6, 3.0.
LYNX_LINK_COLOR
Sets the color for links. This variable is checked only if Lynx is built with color support.
LYNX_MAIN_COLOR
Sets the main (default) color. This variable is checked only if Lynx is built with color support.
LYNX_TEXT_COLOR
Sets the text color. This variable is checked only if Lynx is built with color support.
LYNX_VPRINT_ADDRESS
This variable is used to specify the address of the printer daemon (e.g., lpr) for the vprint command. The format is host:port. If this variable is not set, the default is to use the local lpr command.
LYNX_VPRINT_PRINTER
This variable is used to specify the printer name for the vprint command. If this variable is not set, the default printer is used.
LYNX_VERSION
This variable is always set by Lynx, and may be used by an external program to determine if it was invoked by Lynx.
MAILCAPS
This variable may be used to specify a list of mailcap files to be read. The files are separated by colons. See also the comments in the distribution's sample mailcap file, for notes on usage in such a file.
TERM
Normally, this variable is used by Lynx to determine the terminal type being used to invoke Lynx. If, however, it is unset at startup time (or has the value “unknown”), or if the -term command-line option is used (see OPTIONS section above), Lynx will set or modify its value to the user specified terminal type (for the Lynx execution environment). Note: If set/modified by Lynx, the values of the LINES and/or COLUMNS environment variables may also be changed.

Native Language Support

If configured and installed with Native Language Support, Lynx will display status and other messages in your local language. See the file ABOUT_NLS in the source distribution, or at your local GNU site, for more information about internationalization.

The following environment variables may be used to alter default settings:

LANG
This variable, if set, will override the default message language. It is an ISO 639 two-letter code identifying the language. Language codes are NOT the same as the country codes given in ISO 3166.
LANGUAGE
This variable, if set, will override the default message language. This is a GNU extension that has higher priority for setting the message catalog than LANG or LC_ALL.
LC_ALL
and
LC_MESSAGES
These variables, if set, specify the notion of native language formatting style. They are POSIXly correct.
LINGUAS
This variable, if set prior to configuration, limits the installed languages to specific values. It is a space-separated list of two-letter codes. Currently, it is hard-coded to a wish list.
NLSPATH
This variable, if set, is used as the path prefix for message catalogs.

The CGI Specification, and other associated documentation, should be consulted for general information on CGI script programming.

Native Language Support

If configured and installed with Native Language Support, Lynx will display status and other messages in your local language. See the file ABOUT_NLS in the source distribution, or at your local GNU site, for more information about internationalization.

The following environment variables may be used to alter default settings:

LANG
This variable, if set, will override the default message language. It is an ISO 639 two-letter code identifying the language. Language codes are NOT the same as the country codes given in ISO 3166.
LANGUAGE
This variable, if set, will override the default message language. This is a GNU extension that has higher priority for setting the message catalog than LANG or LC_ALL.
LC_ALL
and
LC_MESSAGES
These variables, if set, specify the notion of native language formatting style. They are POSIXly correct.
LINGUAS
This variable, if set prior to configuration, limits the installed languages to specific values. It is a space-separated list of two-letter codes. Currently, it is hard-coded to a wish list.
NLSPATH
This variable, if set, is used as the path prefix for message catalogs.
