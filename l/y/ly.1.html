NOMBRE

ly - Manipular archivos fuente de LilyPond

Uso:

ly [opciones] comandos archivo, ...

Una herramienta para manipular archivos fuente de LilyPond

OPCIONES

-v, --version
mostrar número de versión y salir
-h, --help
mostrar este texto de ayuda y salir
-i, --in-place
sobrescribir archivos de entrada
-o,--output NOMBRE
nombre del archivo de salida
-e,--encoding CODIFICACION
codificación (de entrada) (por defecto UTF-8)
--output-encoding CODIFICACION
codificación de salida (por defecto la misma que la de entrada)
-l,--language NOMBRE
idioma por defecto para los nombres de las notas (por defecto "nederlands")
-d <variable=valor>
establecer una variable

La opción especial -- considera los argumentos restantes como nombres de archivo.

ARGUMENTOS

El comando es un argumento con comandos separados por punto y coma. En la mayoría de los casos, citarás el comando para que sea visto como un solo argumento.

Puedes especificar más de un archivo LilyPond. Si quieres procesar muchos archivos y escribir los resultados de las operaciones en cada archivo a un archivo de salida separado, puedes usar dos caracteres especiales en el nombre del archivo de salida: un '*' será reemplazado por el nombre de ruta completo del archivo de entrada actual (sin extensión), y un '?' será reemplazado por el nombre del archivo de entrada (sin ruta y extensión). Si no quieres que '*' o '?' sean reemplazados en el nombre del archivo de salida, puedes establecer -d replace-pattern=false.

Si no especificas nombres de archivo de entrada o salida, se leerá la entrada estándar y se escribirá en la salida estándar.

COMANDOS

Comandos informativos que escriben información a la salida estándar y no modifican el archivo:

modo
imprimir el modo (adivinado si no se da) del documento
version
imprimir la versión de LilyPond, si está establecida en el documento
idioma
imprimir el idioma de los nombres de las notas, si está establecido en el documento

Comandos que modifican el archivo:

indent
re-indentar el archivo
reformat
reformatear el archivo
translate <idioma>
traducir los nombres de las notas al idioma
transpose <de> <a>
transponer el archivo como lo haría LilyPond, las notas se dan en el idioma 'nederlands'
abs2rel
convertir música absoluta a relativa
rel2abs
convertir música relativa a absoluta
simplify-accidentals
reemplazar notas con alteraciones tanto como sea posible por sus vecinas naturales
write [nombre_archivo]
escribir el archivo al nombre de archivo dado o a la variable de salida. Si el último comando fue un comando de edición, se llama a write automáticamente.

Comandos que exportan el archivo a otro formato:

musicxml [nombre_archivo]
exportar a MusicXML (en desarrollo, lejos de estar completo)
highlight [nombre_archivo]
exportar el documento como HTML con coloreado de sintaxis
hl [nombre_archivo]
alias de highlight

Entre comandos, puedes establecer o desestablecer una variable usando:

variable=valor
establecer una variable a valor. Los valores especiales son true, false, que se interpretan como valores booleanos, o dígitos, que se interpretarán como valores enteros.
variable=
desestablecer una variable

VARIABLES

Las siguientes variables se pueden establecer para influir en el comportamiento de los comandos. Si hay un valor por defecto, está escrito entre paréntesis:

modo
modo del archivo a leer (por defecto automático) puede ser uno de: lilypond, scheme, latex, html, docbook, texinfo.
salida [-]
el nombre del archivo de salida (también establecido por el argumento -o)
encoding [UTF-8]
codificación a leer (también establecido por el argumento -e)
default-language [nederlands]
el idioma de los nombres de las notas a usar por defecto, cuando no se especifica lo contrario en el documento
output-encoding
codificación a escribir (por defecto es encoding, también establecido por el argumento --output-encoding)
in-place [false]
si se sobrescriben los archivos de entrada (igual que -i)
backup-suffix [~]
sufijo a usar al editar archivos en el lugar, si se establece, se hace una copia de seguridad del archivo original antes de sobrescribirlo
replace-pattern [true]
si se reemplazan '*' y '?' en el nombre del archivo de salida.
rel-startpitch [true]
si se escribe música relativa con una nota inicial
rel-absolute
si se asume que la primera nota en una expresión relativa sin nota inicial especificada es absoluta. Si es false, se asume que es relativa a c'. Si es true, se asume que es absoluta (de hecho, relativa a f. Si no se establece, esta variable por defecto es true solo cuando la versión de LilyPond en el documento es >= 2.18.
indent-tabs [false]
si se usan tabulaciones para la indentación
indent-width [2]
cuántos espacios por cada nivel de indentación (si no se usan tabulaciones)
full-html [True]
si se establece a True se exportará un documento completo con HTML con coloreado de sintaxis, de lo contrario solo el contenido desnudo envuelto en un elemento configurado por las variables wrapper-.
stylesheet
nombre de archivo a referenciar como hoja de estilos externa para HTML con coloreado de sintaxis. Este nombre de archivo se usa literalmente en la etiqueta <link rel="stylesheet">.
inline-style [false

]
si usar atributos de estilo en línea para HTML con resaltado de sintaxis. Por defecto, se incrusta una hoja de estilo CSS.
number-lines [false]
si añadir números de línea al crear HTML con resaltado de sintaxis.
wrapper-tag [pre]
en qué etiqueta se envolverá el HTML con resaltado de sintaxis. Valores posibles: div, pre, id y code
wrapper-attribute [class]
atributo utilizado para la etiqueta de envoltura. Valores posibles: id y class.
document-id [lilypond]
nombre aplicado al atributo de envoltura. Si las tres últimas opciones usan sus configuraciones predeterminadas, los elementos HTML resaltados se envolverán en un elemento <pre class="lilypond"></pre>
linenumbers-id [linenumbers]
si se exportan números de línea, este es el nombre utilizado para los elementos <td>

Estas variables influyen en la salida de los comandos de información:

with-filename
imprime el nombre del archivo junto a información como la versión, etc. Esto es true por defecto si se especifica más de un archivo.

EJEMPLOS

Aquí hay un ejemplo para re-indentar y transponer un archivo LilyPond:

ly "indent; transpose c d" -o output.ly file.ly

Ejemplos usando el '*' en el nombre del archivo de salida:

ly "transpose c d" *.ly -o '*-transposed.ly'
ly highlight *.ly -o 'html/?.html'
