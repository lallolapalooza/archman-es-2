NOMBRE

X509_STORE_CTX_get_by_subject, X509_STORE_CTX_get_obj_by_subject, X509_STORE_CTX_get1_certs, X509_STORE_CTX_get1_crls, X509_STORE_CTX_get1_issuer, X509_STORE_get_by_subject, X509_STORE_get1_certs, X509_STORE_get1_crls — recuperar objetos de un almacén de certificados

SINOPSIS

biblioteca “libcrypto”
#include <openssl/x509_vfy.h>

int
X509_STORE_CTX_get_by_subject(X509_STORE_CTX *ctx, X509_LOOKUP_TYPE type, X509_NAME *name, X509_OBJECT *object);

X509_OBJECT *
X509_STORE_CTX_get_obj_by_subject(X509_STORE_CTX *ctx, X509_LOOKUP_TYPE type, X509_NAME *name);

STACK_OF(X509) *
X509_STORE_CTX_get1_certs(X509_STORE_CTX *ctx, X509_NAME *name);

STACK_OF(X509_CRL) *
X509_STORE_CTX_get1_crls(X509_STORE_CTX *ctx, X509_NAME *name);

int
X509_STORE_CTX_get1_issuer(X509 **issuer, X509_STORE_CTX *ctx, X509 *certificate);

int
X509_STORE_get_by_subject(X509_STORE_CTX *ctx, X509_LOOKUP_TYPE type, X509_NAME *name, X509_OBJECT *object);

STACK_OF(X509) *
X509_STORE_get1_certs(X509_STORE_CTX *ctx, X509_NAME *name);

STACK_OF(X509_CRL) *
X509_STORE_get1_crls(X509_STORE_CTX *ctx, X509_NAME *name);

DESCRIPCIÓN

X509_STORE_CTX_get_by_subject() recupera el primer objeto que coincide con type y name del X509_STORE asociado con el ctx. El type puede ser X509_LU_X509 para recuperar un certificado o X509_LU_CRL para recuperar una lista de revocación.

Si el almacén aún no contiene un objeto coincidente o si el tipo es X509_LU_CRL, se realiza una búsqueda por sujeto en los objetos X509_LOOKUP asociados con el almacén hasta que se encuentre una coincidencia, lo que puede agregar cero o más objetos al almacén.

En caso de éxito, el contenido del object proporcionado por el llamador se sobrescribe con un puntero a la primera coincidencia, y el recuento de referencias de ese certificado o lista de revocación se incrementa en 1. Evitar una fuga de memoria asegurándose de que el object

X509_STORE_CTX_get_obj_by_subject() es similar excepto que se asigna y devuelve un nuevo objeto.

X509_STORE_CTX_get1_certs() recupera todos los certificados que coinciden con el sujeto name del X509_STORE asociado con ctx. Si aún no hay ninguno, X509_STORE_CTX_get_by_subject() se llama para intentar agregar algunos. En caso de éxito, los recuentos de referencias de todos los certificados agregados al array devuelto se incrementan en 1.

X509_STORE_CTX_get1_crls() es similar excepto que opera en listas de revocación de certificados en lugar de en certificados y que siempre llama X509_STORE_CTX_get_by_subject(), incluso si el X509_STORE ya contiene una lista de revocación coincidente.

X509_STORE_CTX_get1_issuer() recupera el certificado CA issuer para el certificate dado del X509_STORE asociado con ctx. Internamente, el nombre del emisor se recupera con X509_get_issuer_name(3) y el certificado CA emisor candidato con X509_STORE_X509_get_by_subject() usando ese nombre de emisor. X509_check_issued(3) o una función de reemplazo proporcionada por el usuario se utiliza para verificar si el certificate fue emitido efectivamente usando el certificado CA issuer antes de devolverlo. Si los parámetros de verificación asociados con ctx fomentan la verificación de tiempos de validez, se prefieren las CA con un tiempo válido, pero si ninguna CA coincidente tiene un tiempo válido, se acepta de todos modos una con un tiempo inválido.

Las siguientes son alias obsoletas implementadas como macros:

X509_STORE_get_by_subject() para X509_STORE_CTX_get_by_subject()
X509_STORE_get1_certs() para X509_STORE_CTX_get1_certs()
X509_STORE_get1_crls() para X509_STORE_CTX_get1_crls()

VALORES DE RETORNO

X509_STORE_CTX_get_by_subject() y X509_STORE_get_by_subject() devuelven 1 si se encuentra una coincidencia o 0 en caso de error. Además de no encontrar una coincidencia, también pueden fallar debido a un error de asignación de memoria. Con implementaciones de biblioteca distintas de LibreSSL, también pueden devolver valores negativos para errores internos.

X509_STORE_CTX_get_obj_by_subject() devuelve el nuevo objeto o NULL en caso de error, en particular si no se encuentra ninguna coincidencia o falla la asignación de memoria.

X509_STORE_CTX_get1_certs() y X509_STORE_get1_certs() devuelven un array de certificados recién asignado y poblado o NULL en caso de error. Fallan si no se encuentra ninguna coincidencia, si falla X509_STORE_CTX_get_by_subject(), o si falla la asignación de memoria.

X509_STORE_CTX_get1_crls() y X509_STORE_get1_crls() devuelven un array de CRLs recién asignado y poblado o NULL en caso de error. Fallan si X509_STORE_CTX_get_by_subject() no encuentra una nueva coincidencia, incluso si el X509_STORE asociado ya contiene CRLs coincidentes, o si falla la asignación de memoria.

X509_STORE_CTX_get1_issuer() devuelve 1 si se encuentra un certificado CA issuer coincidente o 0 en caso contrario. Con implementaciones de biblioteca distintas de LibreSSL, también podría devolver valores negativos para errores internos.

HISTORY

X509_STORE_get_by_subject() apareció por primera vez en SSLeay 0.8.0 y ha estado disponible desde OpenBSD 2.4.

X509_STORE_CTX_get1_issuer() apareció por primera vez en OpenSSL 0.9.6 y ha estado disponible desde OpenBSD 2.9.

X509_STORE_get1_certs() y X509_STORE_get1_crls() aparecieron por primera vez en OpenSSL 1.0.0 y han estado disponibles desde OpenBSD 4.9.

X509_STORE_CTX_get_by_subject() y X509_STORE_CTX_get_obj_by_subject() aparecieron por primera vez en OpenSSL 1.1.0 y han estado disponibles desde OpenBSD 7.1.

X509_STORE_CTX_get1_certs() y X509_STORE_CTX_get1_crls() aparecieron por primera vez en OpenSSL 1.1.0 y han estado disponibles desde OpenBSD 7.4.
