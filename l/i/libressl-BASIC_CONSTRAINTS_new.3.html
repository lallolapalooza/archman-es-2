libressl-BASIC_CONSTRAINTS_new(3)

Paquete: libressl

Licencias: ISC, custom:OpenSSL

BASIC_CONSTRAINTS_NEW(3) Manual de Funciones de Biblioteca BASIC_CONSTRAINTS_NEW(3)

NOMBRE

BASIC_CONSTRAINTS_new, BASIC_CONSTRAINTS_free — Extensión X.509 para marcar certificados CA

SINOPSIS

biblioteca “libcrypto”
#include <openssl/x509v3.h>

BASIC_CONSTRAINTS *
BASIC_CONSTRAINTS_new(void);

void
BASIC_CONSTRAINTS_free(BASIC_CONSTRAINTS *bc);

DESCRIPCIÓN

BASIC_CONSTRAINTS_new() asigna e inicializa un objeto BASIC_CONSTRAINTS vacío, representando una estructura BasicConstraints ASN.1 definida en la sección 4.2.1.9 de la RFC 5280.

Este objeto contiene dos campos. El campo int ca es distinto de cero si el certificado es un certificado de CA. El campo ASN1_INTEGER *pathlen especifica el número máximo de certificados intermedios no autoemitidos que pueden seguir a este certificado en una ruta de certificación válida.

Si un certificado X.509 versión 3 no contiene esta extensión o si el campo ca del objeto BASIC_CONSTRAINTS es 0, o si el certificado contiene una extensión de uso de clave que tiene el bit KU_KEY_CERT_SIGN desmarcado, entonces no es un certificado de CA sino un certificado de entidad final.

BASIC_CONSTRAINTS_free() libera bc.

VALORES DE RETORNO

BASIC_CONSTRAINTS_new() devuelve el nuevo objeto BASIC_CONSTRAINTS o NULL si ocurre un error.

VEA TAMBIÉN

d2i_BASIC_CONSTRAINTS(3), X509_check_purpose(3), X509_EXTENSION_new(3), X509_get_extension_flags(3), X509_new(3)

ESTÁNDARES

RFC 5280: Perfil de Certificado y Lista de Revocación de Certificados (CRL) de Infraestructura de Clave Pública X.509 de Internet:

  • sección 4.2.1.9: Restricciones Básicas
  • sección 6.1: Validación Básica de Ruta

HISTORIA

BASIC_CONSTRAINTS_new() y BASIC_CONSTRAINTS_free() aparecieron por primera vez en OpenSSL 0.9.2b y han estado disponibles desde OpenBSD 2.6.
