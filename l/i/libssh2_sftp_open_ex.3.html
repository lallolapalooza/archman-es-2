libssh2_sftp_open_ex(3)

Paquete: libssh2

Licencias: BSD

libssh2_sftp_open_ex(3) libssh2 libssh2_sftp_open_ex(3)

NOMBRE

libssh2_sftp_open_ex - abre un manejador de archivo para un archivo en SFTP.

SINOPSIS

#include <libssh2.h>
#include <libssh2_sftp.h>
LIBSSH2_SFTP_HANDLE *
libssh2_sftp_open_ex(LIBSSH2_SFTP *sftp, const char *filename,
                     unsigned int filename_len,
                     unsigned long flags,
                     long mode,
                     int open_type);

DESCRIPCIÓN

sftp - Instancia SFTP devuelta por libssh2_sftp_init(3)

filename - Recurso de archivo/directorio remoto a abrir

filename_len - Longitud del nombre del archivo

flags - Cualquier combinación razonable de las constantes LIBSSH2_FXF_*:

LIBSSH2_FXF_READ
Abre el archivo para lectura.
LIBSSH2_FXF_WRITE
Abre el archivo para escritura. Si se especifican tanto este como LIBSSH2_FXF_READ, el archivo se abre para lectura y escritura.
LIBSSH2_FXF_APPEND
Fuerza que todas las escrituras añadan datos al final del archivo.
LIBSSH2_FXF_CREAT,
Si se especifica esta bandera, se creará un nuevo archivo si no existe uno (si se especifica LIBSSH2_FXF_TRUNC, el nuevo archivo se truncará a longitud cero si existía previamente).
LIBSSH2_FXF_TRUNC
Fuerza que un archivo existente con el mismo nombre se trunque a longitud cero al crear un archivo especificando LIBSSH2_FXF_CREAT. SE DEBE especificar LIBSSH2_FXF_CREAT también si se usa esta bandera.
LIBSSH2_FXF_EXCL
Hace que la solicitud falle si el archivo nombrado ya existe. SE DEBE especificar LIBSSH2_FXF_CREAT también si se usa esta bandera.
mode - Permisos de archivo POSIX a asignar si el archivo se está creando por primera vez. Consulte las definiciones de conveniencia LIBSSH2_SFTP_S_* en <libssh2_sftp.h>

open_type - Puede ser LIBSSH2_SFTP_OPENFILE (para abrir un archivo) o LIBSSH2_SFTP_OPENDIR (para abrir un directorio).

VALOR DE RETORNO

Un puntero a la instancia LIBSSH2_SFTP_HANDLE recién creada o NULL en caso de fallo.

ERRORES

LIBSSH2_ERROR_ALLOC - Falló una llamada interna de asignación de memoria.

LIBSSH2_ERROR_SOCKET_SEND - No se pudieron enviar datos en el socket.

LIBSSH2_ERROR_SOCKET_TIMEOUT -

LIBSSH2_ERROR_SFTP_PROTOCOL - Se recibió una respuesta inválida del protocolo SFTP en el socket, o una operación SFTP provocó que el servidor devolviera un código de error.

LIBSSH2_ERROR_EAGAIN - Marcado para E/S no bloqueante pero la llamada bloquearía.
