libssh2_session_callback_set2(3)

Paquete: libssh2

Licencias: BSD

libssh2_session_callback_set2(3) libssh2 libssh2_session_callback_set2(3)

NOMBRE

libssh2_session_callback_set2 - establecer una función de devolución de llamada

SINOPSIS

#include <libssh2.h>
libssh2_cb_generic *
libssh2_session_callback_set2(LIBSSH2_SESSION *session, int cbtype,
                              libssh2_cb_generic *callback);

DESCRIPCIÓN

Establece un manejador de devolución de llamada personalizado para un objeto de sesión previamente inicializado. Las devoluciones de llamada se activan al recibir paquetes especiales en la capa de Transporte. Para deshabilitar una devolución de llamada, establécela a NULL.

session - Instancia de sesión devuelta por libssh2_session_init_ex(3)

cbtype - Tipo de devolución de llamada. Uno de los tipos listados en Tipos de Devolución de Llamada.

callback - Puntero a la función de devolución de llamada personalizada. El prototipo de esta función debe coincidir con la macro de declaración de devolución de llamada asociada.

TIPOS DE DEVOLUCIÓN DE LLAMADA

LIBSSH2_CALLBACK_IGNORE
Se llama cuando se recibe un mensaje SSH_MSG_IGNORE
LIBSSH2_CALLBACK_DEBUG
Se llama cuando se recibe un mensaje SSH_MSG_DEBUG
LIBSSH2_CALLBACK_DISCONNECT
Se llama cuando se recibe un mensaje SSH_MSG_DISCONNECT
LIBSSH2_CALLBACK_MACERROR
Se llama cuando se ha detectado un MAC que no coincide en la capa de transporte. Si la función devuelve 0, el paquete se aceptará de todos modos.
LIBSSH2_CALLBACK_X11
Se llama cuando se ha aceptado una conexión X11
LIBSSH2_CALLBACK_SEND
Se llama cuando libssh2 quiere enviar datos en la conexión. Puede establecerse a una función personalizada para manejar la E/S a tu manera.

El prototipo de la devolución de llamada:

ssize_t sendcb(libssh2_socket_t sockfd, const void *buffer,
               size_t length, int flags, void **abstract);

sockfd es el socket al que escribir, buffer apunta a los datos a enviar, length es el tamaño de los datos, flags son las banderas que se habrían utilizado en una llamada send() y abstract es un puntero al puntero abstracto establecido en la llamada libssh2_session_init_ex(3).

La devolución de llamada devuelve el número de bytes enviados o -1 en caso de error. El código de retorno especial -EAGAIN puede devolverse para indicar que el envío se abortó para evitar el bloqueo y que debe llamarse de nuevo.

LIBSSH2_CALLBACK_RECV
Se llama cuando libssh2 quiere leer datos de la conexión. Puede establecerse a una función personalizada para manejar la E/S a tu manera.

El prototipo de la devolución de llamada:

ssize_t recvcb(libssh2_socket_t sockfd, void *buffer,
               size_t length, int flags, void **abstract);

sockfd es el socket del que leer, buffer es donde almacenar los datos recibidos, length es el tamaño del búfer, flags son las banderas que se habrían utilizado en una llamada recv() y abstract es un puntero al puntero abstracto establecido en la llamada libssh2_session_init_ex(3).

La devolución de llamada devuelve el número de bytes leídos o -1 en caso de error. El código de retorno especial -EAGAIN puede devolverse para indicar que la lectura se abortó para evitar el bloqueo y que debe llamarse de nuevo.

LIBSSH2_CALLBACK_AUTHAGENT
Se llama durante el proceso de autenticación para permitir que el cliente se conecte al agente ssh y realice cualquier configuración, como configurar el agente o añadir claves.

El prototipo de la devolución de llamada:

void authagent(LIBSSH2_SESSION* session, LIBSSH2_CHANNEL *channel,
               void **abstract);
LIBSSH2_CALLBACK_AUTHAGENT_IDENTITIES
No es llamada por libssh2. El cliente es responsable de llamar a este método cuando se ha recibido un mensaje SSH2_AGENTC_REQUEST_IDENTITIES.

El prototipo de la devolución de llamada:

void identities(LIBSSH2_SESSION* session, void *buffer,
                const char *agent_path,
                void **abstract)

El buffer debe ser rellenado por la devolución de llamada. Diferentes clientes pueden implementar esto de manera diferente. Por ejemplo, un cliente puede pasar un unsigned char ** para este parámetro, mientras que otro puede pasar un puntero a una struct.

Independientemente del tipo de búfer utilizado, el cliente deberá enviar una lista de identidades en el siguiente formato.

longitud del búfer uint32 número de entradas entradas

Donde cada entrada en la lista de entradas tiene el formato:

cadena de datos cstring comentario

agent_path La ruta a un ssh-agent en ejecución en la máquina cliente, desde la cual se pueden listar las identidades.

LIBSSH2_CALLBACK_AUTHAGENT_SIGN
No es llamada por libssh2. El cliente es responsable de llamar a este método cuando se ha recibido un mensaje SSH2_AGENTC_SIGN_REQUEST.

El prototipo de la devolución de llamada:

void sign(LIBSSH2_SESSION* session,
          unsigned char *blob, unsigned int blen,
          const unsigned char *data, unsigned int dlen,
          unsigned char **sig, unsigned int *sig_len,
          const char *agent_path,
          void **abstract);

Al interactuar con un ssh-agent instalado en el sistema cliente, este método puede llamar a libssh2_agent_sign(3) para realizar la firma.

VALOR DE RETORNO

Puntero al manejador de devolución de llamada anterior. Devuelve NULL si no se estableció ningún manejador de devolución de llamada anterior o si el tipo de devolución de llamada era desconocido.
