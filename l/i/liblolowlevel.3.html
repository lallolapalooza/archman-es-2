SINOPSIS

Estructuras de datos


struct lo_server_config
Una estructura de configuración para inicializar lo_server usando lo_server_new_from_config().

Typedefs


typedef long double lo_hires
Tipo utilizado para representar valores numéricos en conversiones entre tipos OSC.

Enumeraciones


enum lo_slip_encoding
Usado con lo_address_set_stream_slip() para especificar si los mensajes enviados deben codificarse con SLIP, y si la codificación debe ser de un solo extremo (single-ENDed) o de doble extremo (double-ENDed).

int lo_address_set_iface(lo_address t, const char *iface, const char *ip)

Establece la interfaz de red a utilizar para una dirección de destino dada. El llamador debe especificar la variable iface o ip. La IP, si se especifica, debe coincidir con la misma familia de red que la dirección OSC. (Es decir, debe corresponder correctamente a IPv4 o IPv6). Típicamente, la interfaz de red asignada solo se utilizará en el caso de enviar mensajes multicast. Se recomienda usar la función POSIX if_nameindex para obtener una lista de nombres de interfaces de red.

Parámetros

t Una dirección OSC.
iface El nombre de una interfaz de red en el sistema local.
ip La dirección IP de una interfaz de red en el sistema local.

Devuelve

0 si la interfaz se identificó correctamente, o un valor distinto de cero en caso contrario.

int lo_address_set_stream_slip(lo_address t, lo_slip_encoding encoding)

Establece las conexiones de transmisión salientes (por ejemplo, TCP) para que se transmitan utilizando el protocolo de encapsulación SLIP.

Parámetros

t La dirección para la que se establecerá esta bandera.
encoding Especifica SLIP de un solo extremo o de doble extremo, o deshabilita SLIP.

Devuelve

el valor anterior de esta bandera.

int lo_address_set_tcp_nodelay(lo_address t, int enable)

Establece la bandera TCP_NODELAY en las conexiones TCP salientes.

Parámetros

t La dirección para la que se establecerá esta bandera.
enable Distinto de cero para establecer la bandera, cero para desestablecerla.

Devuelve

el valor anterior de esta bandera.

void lo_address_set_ttl(lo_address t, int ttl)

Establece el valor de Tiempo de Vida (Time-to-Live) para una dirección de destino dada. Esto es necesario para enviar mensajes UDP multicast. Un valor de 1 (el caso habitual) mantiene el mensaje dentro de la subred, mientras que 255 significa un alcance global y sin restricciones.

Parámetros

t Una dirección OSC.
ttl Un entero que especifica el alcance de un mensaje UDP multicast.

void lo_bundle_incref(lo_bundle b)

Suma uno al contador de referencias de un paquete. Los paquetes tienen un contador de referencias. Si un paquete tiene referencias múltiples, el contador del paquete debe incrementarse. Se decrementa automáticamente mediante lo_bundle_free y lo_bundle_free_recursive, siendo lo_bundle_free_recursive el método preferible.

size_t lo_bundle_length(lo_bundle b)

Devuelve la longitud de un paquete en bytes. Incluye la longitud del marcador y la etiqueta de tipo.

Parámetros

b El paquete que se va a dimensionar

lo_bundle lo_bundle_new(lo_timetag tt)

Crea un nuevo objeto paquete. Los paquetes OSC encapsulan uno o más mensajes OSC y pueden incluir una marca de tiempo que indica cuándo se debe despachar el paquete.

Parámetros

tt La marca de tiempo cuando el receptor debe manejar el paquete. Pase LO_TT_IMMEDIATE si desea que el servidor receptor despache el paquete tan pronto como lo reciba.

int lo_message_add_varargs (lo_message m, const char * types, va_list ap)

Añade una lista de varargs a un mensaje. Los datos se añadirán en el orden de bytes de OSC (bigendian). IMPORTANTE: la lista de argumentos debe terminar con LO_ARGS_END, o esta llamada fallará. Esto se utiliza para realizar una comprobación simple de errores en los tamaños de los parámetros pasados.

Parámetros

m El mensaje a extender.
types Los tipos de los elementos de datos en el mensaje, los tipos se definen en lo_types_common.h
ap La lista va_list creada por una función C declarada con un argumento elíptico (...), e inicializada previamente con "va_start(ap)". Los tipos de los argumentos pasados aquí deben coincidir con los tipos especificados en el parámetro de tipo.

Devuelve

Menos de 0 en caso de fallo, 0 en caso de éxito.

void lo_message_clear (lo_message m)

Borra los elementos de un lo_message pero no libera la memoria asignada.

lo_message lo_message_clone (lo_message m)

Crea un nuevo objeto lo_message clonando uno ya existente.

int lo_message_decref (lo_message m)

Resta uno al contador de referencias de un mensaje. Los mensajes tienen un contador de referencias. En general, la disminución del contador debe ser manejada automáticamente usando lo_message_free o lo_bundle_free_recursive, sin embargo, si es necesario, el contador puede ser disminuido manualmente.

lo_message lo_message_deserialise (void * data, size_t size, int * result)

Deserializa un mensaje OSC en bruto y devuelve un nuevo objeto lo_message. Lo contrario de lo_message_serialise().

Parámetros

data Puntero a los datos del mensaje OSC en bruto en forma de transmisión de red (orden de bytes de red cuando sea apropiado).
size El tamaño de los datos en bytes.
result Si este puntero no es NULL, el resultado o código de error se escribirá aquí.

Devuelve un nuevo lo_message, o NULL si la deserialización falla. Use lo_message_free() para liberar el objeto resultante.

void lo_message_free (lo_message m)

Libera la memoria asignada por lo_message_new() y cualquier llamada posterior a lo_message_add_int32, lo_message_add*().

int lo_message_get_argc (lo_message m)

NAME

lo_url_get_protocol, lo_url_get_protocol_id - Obtiene el protocolo de una URL OSC

SYNOPSIS

#include <lo/lo.h>


char *lo_url_get_protocol (const char *url)


int lo_url_get_protocol_id (const char *url)

Detailed Description

char * lo_url_get_protocol (const char * url)

Devuelve la porción del protocolo de una URL OSC, por ejemplo, udp, tcp. Esta biblioteca utiliza URL OSC del tipo: osc.prot://hostname:port/path si la parte prot falta, se asume UDP.

El valor de retorno debe ser liberado con free() cuando ya no se necesite.

int lo_url_get_protocol_id (const char * url)

Devuelve el ID del protocolo de una URL OSC. Esta biblioteca utiliza URL OSC del tipo: osc.prot://hostname:port/path si la parte prot falta, se asume UDP. El valor devuelto será uno de LO_UDP, LO_TCP, LO_UNIX o -1.

Returns

Un entero que especifica el protocolo. Devuelve -1 cuando el protocolo no es compatible con liblo.
