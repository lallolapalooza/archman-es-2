Descripción Detallada

Funciones para manipular listas alpm_list_t.

Estas funciones están diseñadas para crear, destruir y modificar listas de tipo alpm_list_t. Este es un tipo de lista interno utilizado por libalpm que se expone públicamente para su uso por parte de interfaces si se desea.

Se expone para que las interfaces de usuario puedan usarla y evitar la necesidad de reimplementar listas propias; sin embargo, no es obligatorio que la interfaz de usuario la utilice.

fn la función de comparación

onlyright puntero a la segunda lista de resultados
