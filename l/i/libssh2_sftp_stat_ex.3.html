NOMBRE

libssh2_sftp_stat_ex - obtener información sobre un archivo SFTP

SINOPSIS

#include <libssh2.h>
#include <libssh2_sftp.h>
int
libssh2_sftp_stat_ex(LIBSSH2_SFTP *sftp, const char *path,
                     unsigned int path_len, int stat_type,
                     LIBSSH2_SFTP_ATTRIBUTES *attrs);

DESCRIPCIÓN

sftp - instancia SFTP devuelta por libssh2_sftp_init(3)

path - Objeto del sistema de archivos remoto a stat/lstat/setstat.

path_len - Longitud del nombre del objeto del sistema de archivos remoto a stat/lstat/setstat.

stat_type - Una de las tres constantes que especifican el tipo de operación stat a realizar:

LIBSSH2_SFTP_STAT: realiza la operación stat(2)
LIBSSH2_SFTP_LSTAT: realiza la operación lstat(2)
LIBSSH2_SFTP_SETSTAT: realiza la operación para establecer la información stat en el archivo

attrs - Puntero a una estructura LIBSSH2_SFTP_ATTRIBUTES para establecer metadatos de archivo desde o hacia, dependiendo del valor de stat_type.

Obtiene o establece datos de tipo statbuf en un objeto del sistema de archivos remoto. Al obtener datos de statbuf, libssh2_sftp_stat(3) seguirá todos los enlaces simbólicos, mientras que libssh2_sftp_lstat(3) devolverá datos sobre el objeto encontrado, incluso si ese objeto resulta ser un enlace simbólico.

La estructura LIBSSH2_SFTP_ATTRIBUTES se ve así:

struct LIBSSH2_SFTP_ATTRIBUTES {
    /* Si el bit flags & ATTR_* está establecido, entonces el valor en esta struct será
     * significativo. De lo contrario, debe ser ignorado.
     */
    unsigned long flags;
    libssh2_uint64_t filesize;
    unsigned long uid;
    unsigned long gid;
    unsigned long permissions;
    unsigned long atime;
    unsigned long mtime;
};

VALOR DE RETORNO

Devuelve 0 si tiene éxito o un valor negativo si falla. Devuelve LIBSSH2_ERROR_EAGAIN cuando de otro modo se bloquearía. Si bien LIBSSH2_ERROR_EAGAIN es un número negativo, no es realmente un error en sí mismo.

ERRORES

LIBSSH2_ERROR_ALLOC - Falló una llamada interna de asignación de memoria.

LIBSSH2_ERROR_SOCKET_SEND - No se pueden enviar datos en el socket.

LIBSSH2_ERROR_SOCKET_TIMEOUT -

LIBSSH2_ERROR_SFTP_PROTOCOL - Se recibió una respuesta de protocolo SFTP inválida en el socket, o una operación SFTP causó que el servidor devolviera un código de error.
