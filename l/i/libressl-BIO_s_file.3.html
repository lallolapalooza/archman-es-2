DESCRIPCIÓN

BIO_s_file() devuelve el método BIO de archivo. Como su nombre indica, es un envoltorio alrededor de la estructura FILE de stdio y es un BIO fuente/sumidero.

Las llamadas a BIO_read(3) y BIO_write(3) leen y escriben datos en el flujo subyacente. BIO_gets(3) y BIO_puts(3) son compatibles con los BIO de archivo.

BIO_flush(3) en un BIO de archivo llama a la función fflush(3) en el flujo envuelto.

BIO_reset(3) intenta cambiar el puntero de archivo al inicio del archivo usando fseek(stream, 0, 0).

BIO_seek(3) establece el puntero de archivo en la posición ofs desde el inicio del archivo usando fseek(stream, ofs, 0).

BIO_eof(3) llama a feof(3).

Establecer la bandera BIO_CLOSE llama a fclose(3) en el flujo cuando el BIO se libera.

BIO_new_file() crea un nuevo BIO de archivo con el modo mode. El significado de mode es el mismo que para la función stdio fopen(3). La bandera BIO_CLOSE se establece en el BIO devuelto.

BIO_new_fp() crea un BIO de archivo que envuelve stream. Las banderas pueden ser: BIO_CLOSE, BIO_NOCLOSE (la bandera de cierre), BIO_FP_TEXT (establece el flujo subyacente en modo texto, el predeterminado es binario: esto solo tiene algún efecto en Win32).

BIO_set_fp() establece el puntero de archivo de un BIO de archivo en fp. flags tiene el mismo significado que en BIO_new_fp().

BIO_get_fp() recupera el puntero de archivo de un BIO de archivo.

BIO_seek(3) establece el puntero de posición a offset bytes desde el inicio del archivo.

BIO_tell(3) devuelve el valor del puntero de posición.

BIO_read_filename(), BIO_write_filename(), BIO_append_filename(), y BIO_rw_filename() establecen el BIO de archivo b para usar el archivo name para leer, escribir, añadir o leer escribir respectivamente.

Al envolver stdout, stdin o stderr, el flujo subyacente normalmente no debería cerrarse, por lo que la bandera BIO_NOCLOSE debería establecerse.

Debido a que el BIO de archivo llama a las funciones subyacentes de stdio, cualquier peculiaridad en el comportamiento de stdio será reflejada por el BIO correspondiente.

En Windows, BIO_new_files() reserva el argumento del nombre de archivo para que esté codificado en UTF-8. En otras palabras, si tiene que hacer que funcione en un entorno multilingüe, codifique los nombres de archivo en UTF-8.

DESCRIPTION

The file BIO allows reading and writing to standard C FILE pointers or files specified by a filename.

BIO_s_file() returns the file BIO method. This method can be used with BIO_new(3) to create a file BIO.

BIO_new_file() creates a new BIO which reads and writes to the file specified by filename. The mode argument is the same as that used by fopen(3). If the file cannot be opened, NULL is returned. The BIO will automatically close the file when BIO_free(3) is called.

BIO_new_fp() creates a new BIO which reads and writes to the standard C FILE pointer fp. The flags argument determines whether the file should be closed when the BIO is freed. If BIO_CLOSE or BIO_FP_CLOSE is set, then fclose(3) will be called on fp when the BIO is freed. If BIO_NOCLOSE is set, then the file pointer will not be closed.

BIO_set_fp() associates the BIO bio with the standard C FILE pointer fp. The flags argument is the same as for BIO_new_fp().

BIO_get_fp() returns the FILE pointer associated with the BIO bio.

BIO_read_filename(), BIO_write_filename(), BIO_append_filename(), and BIO_rw_filename() are convenience functions that create a file BIO and open the file specified by filename in read, write, append, or read/write mode, respectively. They return 1 on success and 0 on failure.

BIO_seek(3) attempts to seek to a specific position in the BIO. The offset and whence arguments are the same as for fseek(3). It returns the resulting offset on success or -1 on failure.

BIO_tell(3) returns the current position in the BIO. This is equivalent to calling ftell(3) on the underlying FILE pointer.

BIO_reset(3) attempts to reposition the BIO to the beginning of the file. This is equivalent to calling fseek(bio, 0, SEEK_SET).

The BIO_method_type() and BIO_method_name() functions are described in BIO_meth(3).

BIO_CLOSE Close the underlying FILE pointer when the BIO is freed.
BIO_FP_READ Open the file in read mode.
BIO_FP_WRITE Open the file in write mode.
BIO_FP_APPEND Open the file in append mode.
BIO_FP_READ|BIO_FP_WRITE Open the file in read/write mode.
BIO_NOCLOSE Do not close the underlying FILE pointer when the BIO is freed.

BIO_new_file() is equivalent to calling BIO_new with BIO_s_file(), and then calling BIO_set_fp with the correct mode flags. Similarly, BIO_read_filename() is equivalent to BIO_new_file(filename, "r"), BIO_write_filename() is equivalent to BIO_new_file(filename, "w"), and BIO_append_filename() is equivalent to BIO_new_file(filename, "a"). BIO_rw_filename() is equivalent to BIO_new_file(filename, "r+").

The flags argument to BIO_new_fp() and BIO_set_fp() can be a combination of the BIO_CLOSE, BIO_FP_READ, BIO_FP_WRITE, BIO_FP_APPEND, and BIO_NOCLOSE flags.

BIO_CLOSE Close the underlying FILE pointer when the BIO is freed.
BIO_FP_READ Open the file in read mode.
BIO_FP_WRITE Open the file in write mode.
BIO_FP_APPEND Open the file in append mode.
BIO_FP_READ|BIO_FP_WRITE Open the file in read/write mode.
BIO_NOCLOSE Do not close the underlying FILE pointer when the BIO is freed.

BIO_new_file() is equivalent to calling BIO_new with BIO_s_file(), and then calling BIO_set_fp with the correct mode flags. Similarly, BIO_read_filename() is equivalent to BIO_new_file(filename, "r"), BIO_write_filename() is equivalent to BIO_new_file(filename, "w"), and BIO_append_filename() is equivalent to BIO_new_file(filename, "a"). BIO_rw_filename() is equivalent to BIO_new_file(filename, "r+").

The flags argument to BIO_new_fp() and BIO_set_fp() can be a combination of the BIO_CLOSE, BIO_FP_READ, BIO_FP_WRITE, BIO_FP_APPEND, and BIO_NOCLOSE flags.

BIO_CLOSE | BIO_FP_READ | BIO_read_filename()
BIO_CLOSE | BIO_FP_WRITE | BIO_write_filename()
BIO_CLOSE | BIO_FP_APPEND | BIO_append_filename()
BIO_CLOSE | BIO_FP_READ | BIO_FP_WRITE | BIO_rw_filename()

RETURN VALUES

BIO_s_file() returns the file BIO method.

BIO_new_file() and BIO_new_fp() return a file BIO or NULL if an error occurred.

When called on a file BIO object, BIO_method_type(3) returns the constant BIO_TYPE_FILE and BIO_method_name(3) returns a pointer to the static string "FILE pointer".

BIO_set_fp() and BIO_get_fp() return 1 for success or 0 for failure (although the current implementation never returns 0).

BIO_seek(3) returns the same value as the underlying fseek(3) function: 0 for success or -1 for failure.

BIO_tell(3) returns the current file position.

BIO_read_filename(), BIO_write_filename(), BIO_append_filename(), and BIO_rw_filename() return 1 for success or 0 for failure.

EXAMPLES

File BIO "hello world":

BIO *bio_out;
bio_out = BIO_new_fp(stdout, BIO_NOCLOSE);
BIO_printf(bio_out, "Hello World\n");

Alternative technique:

BIO *bio_out;
bio_out = BIO_new(BIO_s_file());
if(bio_out == NULL) /* Error ... */
if(!BIO_set_fp(bio_out, stdout, BIO_NOCLOSE)) /* Error ... */
BIO_printf(bio_out, "Hello World\n");

Write to a file:

BIO *out;
out = BIO_new_file("filename.txt", "w");
if(!out) /* Error occurred */
BIO_printf(out, "Hello World\n");
BIO_free(out);

Alternative technique:

BIO *out;
out = BIO_new(BIO_s_file());
if(out == NULL) /* Error ... */
if(!BIO_write_filename(out, "filename.txt")) /* Error ... */
BIO_printf(out, "Hello World\n");
BIO_free(out);

HISTORY

BIO_s_file(), BIO_set_fp(), BIO_get_fp(), BIO_read_filename(), BIO_write_filename(), and BIO_append_filename() first appeared in SSLeay 0.6.0. BIO_new_file() and BIO_new_fp() first appeared in SSLeay 0.8.0. All these functions have been available since OpenBSD 2.4.

BIO_rw_filename() first appeared in SSLeay 0.9.1 and has been available since OpenBSD 2.6.

BUGS

BIO_reset(3) and BIO_seek(3) are implemented using fseek(3) on the underlying stream. The return value for fseek(3) is 0 for success or -1 if an error occurred. This differs from other types of BIO which will typically return 1 for success and a non-positive value if an error occurred.
