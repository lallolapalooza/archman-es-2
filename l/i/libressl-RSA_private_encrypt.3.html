libressl-RSA_private_encrypt(3)

Paquete: libressl

Licencias: ISC, custom:OpenSSL

RSA_PRIVATE_ENCRYPT(3) Manual de Funciones de Biblioteca RSA_PRIVATE_ENCRYPT(3)

NOMBRE

RSA_private_encrypt, RSA_public_decrypt — operaciones de firma de bajo nivel

SINOPSIS

biblioteca “libcrypto”
#include <openssl/rsa.h>

int
RSA_private_encrypt(int flen, const unsigned char *from, unsigned char *to, RSA *rsa, int padding);

int
RSA_public_decrypt(int flen, const unsigned char *from, unsigned char *to, RSA *rsa, int padding);

DESCRIPCIÓN

Estas funciones manejan firmas RSA a bajo nivel.

RSA_private_encrypt() firma los flen bytes en from (generalmente un resumen de mensaje con un identificador de algoritmo) usando la clave privada rsa y almacena la firma en to. to debe apuntar a RSA_size(rsa) bytes de memoria.

padding denota uno de los siguientes modos:

RSA_PKCS1_PADDING
Relleno PKCS #1 v1.5. Esta función no maneja el identificadorDeAlgoritmo especificado en PKCS #1. Al generar o verificar firmas PKCS #1, se deben usar RSA_sign(3) y RSA_verify(3).
RSA_NO_PADDING
Firma RSA en bruto. Este modo solo debe usarse para implementar modos de relleno criptográficamente seguros en el código de la aplicación. Firmar datos de usuario directamente con RSA es inseguro.

RSA_public_decrypt() recupera el resumen del mensaje de la firma de flen bytes en from usando la clave pública del firmante rsa. to debe apuntar a una sección de memoria lo suficientemente grande como para contener el resumen del mensaje (que es menor que RSA_size(rsa) - 11). padding es el modo de relleno que se utilizó para firmar los datos.

VALORES DE RETORNO

RSA_private_encrypt() devuelve el tamaño de la firma (es decir, RSA_size(rsa)). RSA_public_decrypt() devuelve el tamaño del resumen del mensaje recuperado.

En caso de error, se devuelve -1; los códigos de error se pueden obtener mediante ERR_get_error(3).

VER TAMBIÉN

RSA_meth_set_priv_enc(3), RSA_new(3), RSA_sign(3), RSA_verify(3)

HISTORIA

RSA_private_encrypt() y RSA_public_decrypt() aparecieron en SSLeay 0.4 o anterior y han estado disponibles desde OpenBSD 2.4.

RSA_NO_PADDING está disponible desde SSLeay 0.9.0.
