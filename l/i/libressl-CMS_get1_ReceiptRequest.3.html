libressl-CMS_get1_ReceiptRequest(3)

Paquete: libressl

Licencias: ISC, custom:OpenSSL

CMS_GET1_RECEIPTREQUEST(3) Manual de funciones de biblioteca CMS_GET1_RECEIPTREQUEST(3)

NOMBRE

CMS_ReceiptRequest_create0, CMS_add1_ReceiptRequest, CMS_get1_ReceiptRequest, CMS_ReceiptRequest_get0_values — funciones de solicitud de recibo firmado CMS

SINOPSIS

biblioteca “libcrypto”
#include <openssl/cms.h>

CMS_ReceiptRequest *
CMS_ReceiptRequest_create0(unsigned char *id, int idlen, int allorfirst, STACK_OF(GENERAL_NAMES) *receiptList, STACK_OF(GENERAL_NAMES) *receiptsTo);

int
CMS_add1_ReceiptRequest(CMS_SignerInfo *si, CMS_ReceiptRequest *rr);

int
CMS_get1_ReceiptRequest(CMS_SignerInfo *si, CMS_ReceiptRequest **prr);

void
CMS_ReceiptRequest_get0_values(CMS_ReceiptRequest *rr, ASN1_STRING **pcid, int *pallorfirst, STACK_OF(GENERAL_NAMES) **plist, STACK_OF(GENERAL_NAMES) **prto);

DESCRIPCIÓN

CMS_ReceiptRequest_create0() crea una nueva estructura ReceiptRequest. El campo signedContentIdentifier se establece utilizando id y idlen, o se establece en 32 bytes de datos pseudoaleatorios si id es NULL. Si receiptList es NULL, la opción allOrFirstTier en el campo receiptsFrom se establece en el valor del argumento allorfirst. Si receiptList no es NULL, se utiliza la opción receiptList en el campo receiptsFrom. El argumento receiptsTo especifica el valor del campo receiptsTo.

CMS_add1_ReceiptRequest() agrega una copia codificada en BER de rr a si.

CMS_get1_ReceiptRequest() busca una solicitud de recibo firmada en si. Si se encuentra alguna, se decodifica y se escribe en prr.

CMS_ReceiptRequest_get0_values() recupera los valores de una solicitud de recibo. El signedContentIdentifier se copia a pcid. Si se utiliza la opción allOrFirstTier en el campo receiptsFrom, su valor se copia a pallorfirst; de lo contrario, el campo receiptList se copia a plist. El campo receiptsTo se copia a prto.

El contenido de un recibo firmado solo debe considerarse significativo si la estructura CMS_ContentInfo correspondiente se puede verificar correctamente utilizando CMS_verify(3).

VALORES DE RETORNO

CMS_ReceiptRequest_create0() devuelve la nueva estructura de solicitud de recibo o NULL si ocurrió un error.

CMS_add1_ReceiptRequest() devuelve 1 si tiene éxito o 0 si ocurrió un error.

CMS_get1_ReceiptRequest() devuelve 1 si se encuentra y decodifica una solicitud de recibo firmada. Devuelve 0 si no hay una solicitud de recibo firmada presente o -1 si está presente pero mal formada.

VER TAMBIÉN

CMS_ContentInfo_new(3), CMS_sign(3), CMS_sign_receipt(3), CMS_verify(3), CMS_verify_receipt(3), ERR_get_error(3)

ESTÁNDARES

RFC 2634: Servicios de seguridad mejorados para S/MIME, sección 2.7: Sintaxis de solicitud de recibo

HISTORIA
