NOMBRE

lightdm-webkit2-greeter

SINOPSIS

LightDM greeter que usa webkit2 para temas mediante HTML/JavaScript.

DESCRIPCIÓN

lightdm-webkit2-greeter es un greeter de LightDM que utiliza webkit2 para la tematización. Los temas se pueden escribir utilizando una combinación de HTML y Javascript.

API JAVASCRIPT DE TEMAS

Tenga en cuenta que todas las propiedades y funciones marcadas como "obsoletas" solo están disponibles por compatibilidad con versiones anteriores y se eliminarán en una futura versión de lightdm-webkit2-greeter. Los autores de temas no deben utilizar ninguna propiedad o función obsoleta en trabajos nuevos y deben actualizar cualquier trabajo existente que utilice propiedades y/o funciones obsoletas para garantizar la funcionalidad continua y correcta.

Las siguientes funciones **deben** ser proporcionadas por el tema del greeter y ser invocables en el objeto global "window".

show_prompt(text, type)

Esto se llamará cuando LightDM necesite solicitar algo al usuario, como pedir una contraseña. El parámetro "text" será el texto de la solicitud y el parámetro "type" será "text" para una solicitud visible, o "password" para una solicitud cuya entrada deba ocultarse.

show_message(text, type)

Esto se llamará cuando LightDM necesite mostrar alguna información al usuario. El parámetro "text" será el texto del mensaje y el parámetro "type" será "info" para un mensaje de información o "error" para un mensaje de error que LightDM haya encontrado.

authentication_complete()

LightDM llamará a esta función cuando la autenticación se haya completado.

autologin_timer_expired()

LightDM llamará a esta función cuando el temporizador de inicio de sesión del usuario de autologin haya expirado. El greeter debe restablecer el proceso de autenticación.

Las siguientes funciones están disponibles para que el greeter las llame para ejecutar acciones dentro de LightDM.

lightdm.authenticate(username)

Especifica el nombre de usuario del usuario para el que nos gustaría comenzar a autenticarnos. Tenga en cuenta que si llama a lightdm.authenticate sin un argumento, LightDM (a través de PAM) emitirá una llamada a show_prompt() para solicitar el nombre de usuario. La función anterior lightdm.start_authentication() ha sido obsoleta.

lightdm.authenticate_as_guest()

Autentica como usuario invitado.

lightdm.cancel_authentication()

Cancela la autenticación de cualquier usuario que esté actualmente en proceso de autenticación.

lightdm.cancel_autologin()

Cancela la autenticación del usuario de autologin. La función anterior lightdm.cancel_timed_login() ha sido obsoleta.

lightdm.get_hint(hint_name)

Devuelve el valor de una sugerencia nombrada proporcionada por LightDM.

lightdm.suspend()

Suspende el sistema, si el greeter tiene la autoridad para hacerlo.

lightdm.hibernate()

Pone el sistema en hibernación, si el greeter tiene la autoridad para hacerlo.

lightdm.start_session_sync(session)

Una vez que LightDM haya autenticado correctamente al usuario, inicie la sesión del usuario llamando a esta función. "session" es la sesión del usuario autenticado. Si no se pasa ninguna sesión, inicie la sesión del usuario autenticado con la sesión predeterminada del sistema. La función anterior lightdm.login(user, session) ha sido obsoleta.

lightdm.respond(text)

Cuando LightDM haya solicitado una entrada, proporcione la respuesta a LightDM. La función obsoleta era "provide_secret". Todavía está disponible para compatibilidad con versiones anteriores, pero los autores de greeters deben pasar a usar lightdm.respond().

lightdm.restart()

Reinicia el sistema, si el greeter tiene la autoridad para hacerlo.

lightdm.set_language(lang)

Establecerá el idioma para la sesión actual de LightDM.

lightdm.shutdown()

Apaga el sistema, si el greeter tiene la autoridad para hacerlo.

Las variables disponibles dentro del greeter son:

lightdm.authentication_user

Cadena. El nombre de usuario del usuario de autenticación que se está autenticando o nulo si no hay ninguna autenticación en curso.

lightdm.autologin_guest

Booleano. Indica que el usuario invitado debe usarse para el autologin.

lightdm.autologin_timeout

Número. El número de segundos que se esperará antes de iniciar sesión automáticamente. La variable anterior lightdm.timed_user_delay ha sido obsoleta.

lightdm.autologin_user

Cadena. El nombre de la cuenta de usuario que debe iniciarse sesión automáticamente después de que haya transcurrido el retraso de inicio de sesión programado. La variable anterior lightdm.timed_login_user ha sido obsoleta.

lightdm.can_hibernate

Booleano. Si el sistema puede ponerse en hibernación por el greeter o no.

lightdm.can_restart

Booleano. Si el sistema puede ser reiniciado por el greeter o no.

lightdm.can_shutdown

Booleano. Si el sistema puede ser apagado por el greeter o no.

lightdm.can_suspend

Booleano. Si el sistema puede ser suspendido por el greeter o no.

lightdm.default_session

Cadena. El nombre de la sesión predeterminada (según lo configurado en lightdm.conf).

lightdm.has_guest_account

Booleano. Hay una cuenta de invitado disponible para iniciar sesión.

lightdm.hide_users

Booleano. No se debe mostrar la lista completa de usuarios.

lightdm.hostname

Cadena. El nombre del host del sistema.

lightdm.is_authenticated

Booleano. Indica si el usuario se ha autenticado correctamente.

lightdm.in_authentication

Booleano. Indica si lightdm está actualmente en la fase de autenticación.

lightdm.language

Cadena. El idioma seleccionado actualmente. El nombre de variable anterior lightdm.default_language está obsoleto.

lightdm.layout

Cadena. El nombre de la distribución de teclado actualmente activa. Para cambiar la distribución, asigne un nombre de distribución válido a esta variable. El nombre de variable anterior lightdm.default_layout está obsoleto.

lightdm.layouts

Matriz. Las distribuciones de teclado que están disponibles en el sistema. Devuelve una matriz de objetos LightDMLayout.

lightdm.num_users

Número. El número de usuarios que pueden iniciar sesión.

lightdm.select_guest

Booleano. El usuario invitado debe seleccionarse por defecto para iniciar sesión.

lightdm.select_user

Cadena. El nombre de usuario que debe seleccionarse por defecto para iniciar sesión.

lightdm.sessions

Matriz. Las sesiones que están disponibles en el sistema. Devuelve una matriz de objetos LightDMSession.

lightdm.users

Matriz. Los usuarios que pueden iniciar sesión. Devuelve una matriz de objetos LightDMUser.

NAME

lightdm-webkit2-greeter - A LightDM greeter

SYNOPSIS

/usr/bin/lightdm-webkit2-greeter

DESCRIPTION

The lightdm-webkit2-greeter is a greeter for LightDM that uses the WebKit engine to render the login screen. This allows themes to be written using HTML, CSS, and JavaScript.

THEME JAVASCRIPT API

The greeter exposes a JavaScript API that themes can use to interact with LightDM. This API allows themes to:

  • Get a list of available users.
  • Authenticate users.
  • Get the hostname and model of the machine.
  • Restart or shut down the computer.
  • Get the theme name and path.

A complete list of the available calls can be found in the LightDM API documentation. The lightdm-webkit2-greeter implements the entire LightDM API.

CONFIGURATION

/etc/lightdm/lightdm-webkit2-greeter.conf

Keyfile that contains one key: webkit-theme. This should point to which theme the greeter should use.

FILES

/usr/share/lightdm-webkit/themes

Directory where themes should be stored.

EXAMPLES

Please see the "antergos" and "simple" themes that are shipped with lightdm-webkit2-greeter.
