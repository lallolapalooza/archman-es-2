NOMBRE

libssh2_knownhost_checkp - comprobar un host+clave contra la lista de hosts conocidos

SINOPSIS

#include <libssh2.h>
int
libssh2_knownhost_checkp(LIBSSH2_KNOWNHOSTS *hosts,
                         const char *host, int port,
                         const char *key, size_t keylen,
                         int typemask,
                         struct libssh2_knownhost **knownhost);

DESCRIPCIÓN

Comprueba un host y su clave asociada contra la colección de hosts conocidos, y devuelve información sobre la entrada coincidente (parcialmente).

host es un puntero al nombre del host en texto plano. El nombre del host puede ser la dirección IP numérica del host o el nombre completo.

port es el número de puerto utilizado por el host (o un número negativo para comprobar el host genérico). Si se proporciona el número de puerto, libssh2 comprobará la clave para la combinación específica de host + número de puerto, además de la comprobación del nombre del host en texto plano.

key es un puntero a la clave del host proporcionado.

keylen es el tamaño total en bytes de la clave a la que apunta el argumento key.

typemask es una máscara de bits que especifica el formato y la información sobre los datos pasados a esta función. Específicamente, detalla el formato del nombre del host, el formato de la clave y el tipo de clave que es.

El nombre del host se proporciona como uno de los siguientes tipos: LIBSSH2_KNOWNHOST_TYPE_PLAIN o LIBSSH2_KNOWNHOST_TYPE_CUSTOM.

La clave está codificada utilizando una de las siguientes codificaciones: LIBSSH2_KNOWNHOST_KEYENC_RAW o LIBSSH2_KNOWNHOST_KEYENC_BASE64.

knownhost si se establece en NULL, debe ser un puntero a un puntero de 'struct libssh2_knownhost' que se rellena para apuntar a información sobre un host conocido que coincide o coincide parcialmente.

VALOR DE RETORNO

libssh2_knownhost_check(3) devuelve información sobre la calidad de la coincidencia del par host + clave proporcionado con una de las entradas de la lista de hosts conocidos.

LIBSSH2_KNOWNHOST_CHECK_FAILURE - algo impidió que se realizara la comprobación.

LIBSSH2_KNOWNHOST_CHECK_NOTFOUND - no se encontró ninguna coincidencia de host.

LIBSSH2_KNOWNHOST_CHECK_MATCH - los hosts y las claves coinciden.

LIBSSH2_KNOWNHOST_CHECK_MISMATCH - se encontró el host, ¡pero las claves no coincidieron!

DISPONIBILIDAD

Añadido en libssh2 1.2.6

EJEMPLO

Ver el ejemplo ssh2_exec.c tal como se proporciona en el archivo tarball.
