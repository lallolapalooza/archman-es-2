SSL_SESSION_REUSED(3) Manual de funciones de la biblioteca SSL_SESSION_REUSED(3)

NOMBRE

SSL_session_reused — consultar si se negoció una sesión reutilizada durante el handshake

SINÓPSIS

biblioteca “libssl” libcrypto
#include <openssl/ssl.h>

int
SSL_session_reused(SSL *ssl);

DESCRIPCIÓN

Consulta si se negoció una sesión reutilizada durante el handshake.

Durante la negociación, un cliente puede proponer reutilizar una sesión. El servidor busca la sesión en su caché. Si tanto el cliente como el servidor acuerdan la sesión, esta se reutilizará y se establecerá una bandera que la aplicación puede consultar.

VALORES DE RETORNO

Los siguientes valores de retorno pueden ocurrir:

0
Se negoció una nueva sesión.
1
Se reutilizó una sesión.

VER TAMBIÉN

ssl(3), SSL_ctrl(3), SSL_CTX_set_session_cache_mode(3), SSL_set_session(3)

HISTORIA

SSL_session_reused() apareció por primera vez en SSLeay 0.8.0 y ha estado disponible desde OpenBSD 2.4.
