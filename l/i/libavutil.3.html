NOMBRE

libavutil - biblioteca de utilidades con sesgo multimedia

DESCRIPCIÓN

La biblioteca libavutil es una biblioteca de utilidades para ayudar a la programación multimedia portátil. Contiene funciones seguras y portátiles de cadenas de texto, generadores de números aleatorios, estructuras de datos, funciones matemáticas adicionales, criptografía y funcionalidad relacionada con multimedia (como enumeraciones para formatos de píxeles y de muestras). No es una biblioteca para código necesario tanto por libavcodec como por libavformat.

Los objetivos de esta biblioteca son ser:

Modular
Debería tener pocas interdependencias y la posibilidad de deshabilitar partes individuales durante ./configure.
Pequeño
Tanto las fuentes como los objetos deberían ser pequeños.
Eficiente
Debería tener un bajo uso de CPU y memoria.
Útil
Debería evitar características inútiles que casi nadie necesita.

VER TAMBIÉN

AUTORES

Los desarrolladores de FFmpeg.

Para obtener detalles sobre la autoría, consulte el historial de Git del proyecto (https://git.ffmpeg.org/ffmpeg), por ejemplo, escribiendo el comando git log en el directorio de fuentes de FFmpeg, o navegando por el repositorio en línea en https://git.ffmpeg.org/ffmpeg.

Los mantenedores de los componentes específicos se enumeran en el archivo MAINTAINERS en el árbol de código fuente.
