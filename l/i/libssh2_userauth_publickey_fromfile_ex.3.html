libssh2_userauth_publickey_fromfile_ex(3)

Paquete: libssh2

Licencias: BSD

libssh2_userauth_publickey_fromfile_ex(3) libssh2 libssh2_userauth_publickey_fromfile_ex(3)

NOMBRE

libssh2_userauth_publickey_fromfile_ex - autenticar una sesión con una clave pública, leída desde un archivo

SINOPSIS

#include <libssh2.h>
int
libssh2_userauth_publickey_fromfile_ex(LIBSSH2_SESSION *session,
                                       const char *username,
                                       unsigned int username_len,
                                       const char *publickey,
                                       const char *privatekey,
                                       const char *passphrase);

DESCRIPCIÓN

session - Instancia de sesión devuelta por libssh2_session_init_ex(3)

username - Puntero al nombre de usuario a autenticar.

username_len - Longitud de username.

publickey - Nombre de la ruta del archivo de clave pública. (ej. /etc/ssh/hostkey.pub). Si libssh2 está compilado contra OpenSSL, esta opción puede ser NULL.

privatekey - Nombre de la ruta del archivo de clave privada. (ej. /etc/ssh/hostkey)

passphrase - Frase de contraseña a usar al decodificar privatekey.

Intenta la autenticación con clave pública usando un archivo de clave pública o un archivo de clave privada codificado en PEM almacenado en disco. Al proporcionar una clave privada, la clave pública se extrae automáticamente de ella. Al proporcionar ambas, la clave pública pasada tiene precedencia.

VALOR DE RETORNO

Retorna 0 en caso de éxito o un valor negativo en caso de fallo. Retorna LIBSSH2_ERROR_EAGAIN cuando de otro modo se bloquearía. Aunque LIBSSH2_ERROR_EAGAIN es un número negativo, no es realmente un fallo en sí mismo.

ERRORES

LIBSSH2_ERROR_FILE - Un problema al abrir, leer o analizar el archivo del disco.

LIBSSH2_ERROR_ALLOC - Una llamada interna de asignación de memoria falló.

LIBSSH2_ERROR_SOCKET_SEND - No se pueden enviar datos por el socket.

LIBSSH2_ERROR_SOCKET_TIMEOUT -

LIBSSH2_ERROR_PUBLICKEY_UNVERIFIED - La combinación usuario/clave pública fue inválida.

LIBSSH2_ERROR_AUTHENTICATION_FAILED - La autenticación usando la clave pública proporcionada no fue aceptada.

VER TAMBIÉN
