NOMBRE

libtar_list_new, libtar_list_free, libtar_list_next, libtar_list_prev, libtar_list_add, libtar_list_del, libtar_list_search, libtar_list_dup, libtar_list_merge, libtar_list_add_str - rutinas de lista enlazada

SINOPSIS

#include <libtar.h>

libtar_list_t *libtar_list_new(int flags, int (*cmpfunc)());
void libtar_list_free(libtar_list_t *l, void (*freefunc)());
int libtar_list_add_str(libtar_list_t *l, char *str, char *delim);
int libtar_list_add(libtar_list_t *l, void *data);
void libtar_list_del(libtar_list_t *l, libtar_node_t **n);
int libtar_list_search(libtar_list_t *l, libtar_node_t **n, void *data, int (*matchfunc)());
int libtar_list_next(libtar_list_t *l, libtar_node_t **n);
int libtar_list_prev(libtar_list_t *l, libtar_node_t **n);
libtar_list_t *libtar_list_dup(libtar_list_t *l);
libtar_list_t *libtar_list_merge(int (*cmpfunc)(), int flags, libtar_list_t *list1, libtar_list_t *list2);

DESCRIPCIÓN

La función libtar_list_new() crea una nueva lista. El argumento flags debe ser uno de los siguientes valores:

LIST_USERFUNC
El argumento cmpfunc apunta a una función proporcionada por el usuario que determina el orden de la lista.
LIST_STACK
Utiliza la lista como una pila. Los nuevos elementos se añaden al principio de la lista.
LIST_QUEUE
Utiliza la lista como una cola. Los nuevos elementos se añaden al final de la lista.

La función libtar_list_free() libera toda la memoria asociada con la lista l. Si freefunc no es NULL, se llama para liberar la memoria asociada con cada nodo de la lista.

La función libtar_list_add() añade el elemento apuntado por data a la lista l. La posición del nuevo elemento se determinará según las banderas pasadas a libtar_list_new() cuando se creó la lista.

La función libtar_list_add_str() tokeniza la cadena str utilizando los caracteres delimitadores en la cadena delim. Los tokens resultantes se añaden a la lista l usando libtar_list_add().

La función libtar_list_search() busca un elemento que coincida con data utilizando la función de coincidencia matchfunc. Si matchfunc es NULL, se utiliza una función de coincidencia predeterminada diseñada para cadenas ASCII. La búsqueda comienza desde el nodo apuntado por n.

La función libtar_list_del() elimina la entrada apuntada por n de la lista apuntada por l.

La función libtar_list_dup() crea una copia de la lista l utilizando memoria asignada dinámicamente.

La función libtar_list_merge() crea una nueva lista con flags y cmpfunc, de la misma manera que libtar_list_new(). Luego añade todos los elementos de list1 y list2 usando libtar_list_add().

VALOR DE RETORNO

Las funciones libtar_list_new(), libtar_list_dup() y libtar_list_merge() devuelven un puntero a la nueva estructura de lista, o NULL en caso de error.

Las funciones libtar_list_next(), libtar_list_prev() y libtar_list_search() devuelven 1 cuando se devuelven datos válidos, o 0 en caso contrario.

Las funciones libtar_list_add() y libtar_list_add_str() devuelven 0 en caso de éxito, o -1 en caso de error.
