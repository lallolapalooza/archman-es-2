NOMBRE

libpipewire-module-netjack2-driver - Controlador Netjack2

DESCRIPCIÓN

El módulo netjack2-driver proporciona una fuente o sumidero que sigue a un gestor netjack2.

Está destinado a ser utilizado a través de conexiones de red estables (ethernet) con latencia y fluctuación mínimas.

El controlador normalmente decide cuántos puertos enviará y recibirá del gestor. Por defecto, sin embargo, estos valores se establecen en -1 para que el gestor decida el número de puertos.

Con las propiedades globales o por flujo audio.port y midi.ports, este comportamiento se puede ajustar.

El controlador enviará mensajes UDP a una dirección (típicamente) multicast para informar al gestor del controlador disponible. Esto instruirá al gestor a configurar e iniciar el controlador.

En el lado del controlador, se creará un sumidero y/o una fuente con el número especificado de puertos de audio y MIDI. En el lado del gestor, se creará una fuente y/o un sumidero correspondiente respectivamente.

El controlador se programará con exactamente el mismo período que el gestor, pero con un número configurable de períodos de retraso (ver netjack2.latency, por defecto 2).

NOMBRE DEL MÓDULO

libpipewire-module-netjack2-driver

OPCIONES DEL MÓDULO

  • driver.mode: el modo del controlador, sink|source|duplex, por defecto duplex. Esto establece el valor predeterminado de audio.port y midi.ports por flujo de -1 a 0. El modo sink por defecto no tiene puertos de origen, el modo source no tiene puertos de sumidero y duplex deja los valores predeterminados como están.
  • local.ifname = <str>: nombre de la interfaz a utilizar
  • net.ip =<str>: dirección IP multicast, por defecto "225.3.19.154"
  • net.port =<int>: puerto de control, por defecto 19000
  • net.mtu = <int>: MTU a utilizar, por defecto 1500
  • net.ttl = <int>: TTL a utilizar, por defecto 1
  • net.loop = <bool>: multicast de loopback, por defecto false
  • source.ip =<str>: dirección IP a la que enlazarse, por defecto "0.0.0.0"
  • source.port =<int>: puerto a el que enlazarse, por defecto 0 (asignar)
  • netjack2.client-name: el nombre del cliente NETJACK2.
  • netjack2.latency: la latencia en ciclos, por defecto 2
  • audio.ports: el número de puertos de audio. También se puede añadir a las propiedades del flujo. Un valor de -1 lo configurará al número de puertos de audio del gestor.
  • midi.ports: el número de puertos MIDI. También se puede añadir a las propiedades del flujo. Un valor de -1 lo configurará al número de puertos MIDI del gestor.
  • source.props: propiedades adicionales para el filtro de origen.
  • sink.props: propiedades adicionales para el filtro de sumidero.

OPCIONES GENERALES

Opciones con comportamiento conocido.

  • remote.name
  • audio.channels
  • audio.position
  • node.name
  • node.description
  • node.group
  • node.virtual
  • media.class
  • target.object para especificar el nombre del nodo remoto o el ID de serie al que vincularse

EJEMPLO DE CONFIGURACIÓN DE UN SUMIDERO/FUENTE DUPLEX

# ~/.config/pipewire/pipewire.conf.d/my-netjack2-driver.conf
context.modules = [
{   name = libpipewire-module-netjack2-driver
    args = {
        #netjack2.client-name = PipeWire
        #netjack2.latency     = 2
        #midi.ports           = 0
        #audio.ports          = -1
        #audio.channels       = 2
        #audio.position       = [ FL FR ]
        source.props = {
            # propiedades adicionales del origen
        }
        sink.props = {
            # propiedades adicionales del sumidero
        }
    }
}
]
