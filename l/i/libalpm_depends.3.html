Descripción Detallada

Funciones que manejan la información de dependencia y conflicto de libalpm.

Documentación de Estructuras de Datos

struct alpm_depend_t

El tipo básico de dependencia.

Este tipo se utiliza en todo libalpm, no solo para dependencias, sino también para conflictos y proveedores.

Campos de Datos:

char * desc Una descripción de por qué se necesita esta dependencia (opcional)

alpm_depmod_t mod Cómo la versión debe coincidir con el proveedor.

char * name Nombre del proveedor para satisfacer esta dependencia.

unsigned long name_hash Un hash del nombre (utilizado internamente para acelerar las comprobaciones de conflictos)

char * version Versión del proveedor para coincidir (opcional)

struct alpm_depmissing_t

Dependencia faltante.

Campos de Datos:

char * causingpkg Si la dependencia faltante fue causada por un conflicto, el nombre del paquete que se instalaría, causando la eliminación del paquete que la satisface.

alpm_depend_t * depend La dependencia que se deseaba.

char * target Nombre del paquete que tiene la dependencia.

struct alpm_conflict_t

Un conflicto que ha ocurrido entre dos paquetes.

Campos de Datos:

alpm_pkg_t * package1 El primer paquete.

alpm_pkg_t * package2 El segundo paquete.

alpm_depend_t * reason El conflicto.

struct alpm_fileconflict_t

Conflicto de archivo.

Un conflicto que ha ocurrido porque dos paquetes contienen el mismo archivo, o un paquete contiene un archivo que ya está en el sistema de archivos y no es propiedad de ese paquete.

Campos de Datos:

char * ctarget El nombre del paquete que también posee el archivo si lo hay.

char * file El nombre del archivo con el que el paquete entra en conflicto.

char * target El nombre del paquete que causó el conflicto.

alpm_fileconflicttype_t type El tipo de conflicto.

Documentación de Tipos de Enumeración

enum alpm_depmod_t

Tipos de restricciones de versión en las especificaciones de dependencia.

Enumerador

ALPM_DEP_MOD_ANY
Sin restricción de versión.
ALPM_DEP_MOD_EQ
Comprueba la igualdad de versión (paquete=x.y.z)
ALPM_DEP_MOD_GE
Comprueba si la versión es mayor o igual (paquete>=x.y.z)
ALPM_DEP_MOD_LE
Comprueba si la versión es menor o igual (paquete<=x.y.z)
ALPM_DEP_MOD_GT
Comprueba si la versión es mayor que (paquete>x.y.z)
ALPM_DEP_MOD_LT
Comprueba si la versión es menor que (paquete<x.y.z)

enum alpm_fileconflicttype_t

Tipo de conflicto de archivo. Si el conflicto resulta de un archivo existente en el sistema de archivos, o con otro destino en la transacción.

Enumerador

ALPM_FILECONFLICT_TARGET
El conflicto resulta con otro destino en la transacción.
ALPM_FILECONFLICT_FILESYSTEM
El conflicto resulta de un archivo existente en el sistema de archivos.

alpm_list_t * alpm_find_dbs_satisfier (alpm_handle_t * handle, alpm_list_t * dbs, const char * depstring)

Find a package satisfying a specified dependency in the given databases.

This function first looks for a literal match for the dependency string. If no literal match is found, it searches for providers of the dependency. It prioritizes packages that are already installed. If multiple installed packages satisfy the dependency, the first one encountered is returned.

If no installed package satisfies the dependency, but providers exist, an alpm_question_select_provider_t structure is created to allow the user to select a provider.

The dependency string can include version specifiers (e.g., "package>=1.2.3").

Parameters

handle
A pointer to the alpm handle.
dbs
An alpm_list_t* containing the databases to search within.
depstring
The dependency string to satisfy (e.g., "glibc" or "python>=3.9").

Returns

A pointer to an alpm_pkg_t structure representing the satisfying package, or NULL if no package satisfies the dependency. The returned pointer is owned by the caller and should be freed using alpm_pkg_free().

alpm_pkg_t * alpm_find_satisfier (alpm_list_t * pkgs, const char * depstring)

Find a package satisfying a specified dependency within a given list of packages.

This function searches through the provided list of packages (`pkgs`) to find one that satisfies the dependency specified by `depstring`. The dependency can include version specifiers.

Parameters

pkgs
An alpm_list_t* of alpm_pkg_t pointers to search within.
depstring
The dependency string to satisfy (e.g., "package" or "package<2.0").

Returns

A pointer to an alpm_pkg_t structure representing the satisfying package, or NULL if no package in the list satisfies the dependency. The returned pointer is owned by the caller and should be freed using alpm_pkg_free().
