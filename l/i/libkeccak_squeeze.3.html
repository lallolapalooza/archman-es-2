LIBKECCAK_SQUEEZE(3) Manual de funciones de biblioteca LIBKECCAK_SQUEEZE(3)

NOMBRE

libkeccak_squeeze - Ejecuta la fase de exprimido (squeeze)

SINOPSIS

#include <libkeccak.h>
void libkeccak_squeeze(struct libkeccak_state *state, void *hashsum);

Enlazar con -lkeccak.

DESCRIPCIÓN

La función libkeccak_squeeze() ejecuta la fase de exprimido de Keccak, sobre el proceso de hash descrito por *state, y almacena un nuevo resumen (digest), en formato binario, en hashsum.

hashsum tiene el mismo requisito que para las funciones libkeccak_digest(3) y libkeccak_fast_digest(3): debe tener un tamaño de asignación de al menos ((state->n + 7) / 8) bytes. Sin embargo, no puede ser NULL.

VALORES DE RETORNO

La función libkeccak_squeeze() no devuelve ningún valor.

ERRORES

La función libkeccak_squeeze() no puede fallar.

VER TAMBIÉN

libkeccak_digest(3), libkeccak_fast_digest(3), libkeccak_zerocopy_digest(3), libkeccak_simple_squeeze(3), libkeccak_fast_squeeze(3)
