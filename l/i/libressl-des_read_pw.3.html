DES_READ_PW(3) Manual de funciones de biblioteca DES_READ_PW(3)

NOMBRE

EVP_read_pw_string, EVP_read_pw_string_min, EVP_set_pw_prompt, EVP_get_pw_prompt — funciones de interfaz de usuario de compatibilidad

SINOPSIS

biblioteca “libcrypto”
#include <openssl/evp.h>

int
EVP_read_pw_string(char *buf, int length, const char *prompt, int verify);

int
EVP_read_pw_string_min(char *buf, int min_length, int length, const char *prompt, int verify);

void
EVP_set_pw_prompt(const char *default_prompt);

char *
EVP_get_pw_prompt(void);

DESCRIPCIÓN

EVP_read_pw_string() escribe el prompt en /dev/tty, o, si no se pudo abrir, en la salida estándar, desactiva el eco y lee una cadena de entrada de /dev/tty, o, si no se pudo abrir, de la entrada estándar. La cadena se devuelve en buf, que debe tener espacio para al menos length bytes. Si el argumento length excede BUFSIZ, se usa BUFSIZ en su lugar. Si verify está establecido, se le pide al usuario la contraseña dos veces y, a menos que las dos copias coincidan, se devuelve un error.

EVP_read_pw_string_min() además verifica que la contraseña tenga al menos min_length bytes de longitud.

EVP_set_pw_prompt() establece un prompt predeterminado a una copia de default_prompt, o borra el prompt predeterminado si el argumento default_prompt es NULL o una cadena vacía. Si el argumento default_prompt es más largo que 79 bytes, la copia se trunca silenciosamente a una longitud de cadena de 79 bytes.

Mientras un prompt predeterminado esté establecido, EVP_read_pw_string() y EVP_read_pw_string_min() pueden ser llamadas con un argumento prompt de NULL, en cuyo caso se utiliza el prompt predeterminado.

VALORES DE RETORNO

EVP_read_pw_string() y EVP_read_pw_string_min() devuelven 0 en caso de éxito o un valor negativo en caso de fallo.

Devuelven -1 si length es menor o igual que cero o en caso de fallo de asignación de memoria. Devuelven -1 o -2 si la llamada interna a UI_process(3) falla.

Además, EVP_read_pw_string_min devuelve -1 si min_length es negativo, si length es menor o igual que min_length, o si el usuario introdujo una contraseña más corta que min_length.

EVP_get_pw_prompt() devuelve un puntero interno a memoria estática que contiene el prompt predeterminado, o NULL si no se ha establecido ningún prompt predeterminado.

VER TAMBIÉN

UI_new(3)

HISTORIA

EVP_read_pw_string() apareció por primera vez en SSLeay 0.5.1 y EVP_set_pw_prompt() y EVP_get_pw_prompt() en SSLeay 0.6.0. Estas funciones han estado disponibles desde OpenBSD 2.4.

EVP_read_pw_string_min() apareció por primera vez en OpenSSL 1.0.0 y ha estado disponible desde OpenBSD 4.9.
