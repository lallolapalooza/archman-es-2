SSL_SESSION_IS_RESUMABLE(3) Manual de funciones de biblioteca SSL_SESSION_IS_RESUMABLE(3)

NOMBRE

SSL_SESSION_is_resumable — determina si un objeto SSL_SESSION se puede utilizar para la reanudación

SINOPSIS

biblioteca “libssl” libcrypto
#include <openssl/ssl.h>

int
SSL_SESSION_is_resumable(const SSL_SESSION *session);

DESCRIPCIÓN

SSL_SESSION_is_resumable() determina si el objeto session se puede utilizar para reanudar una sesión. Tenga en cuenta que intentar reanudar con una sesión no reanudable dará como resultado un handshake completo.

VALORES DE RETORNO

SSL_SESSION_is_resumable() devuelve 1 si la sesión es reanudable o 0 en caso contrario. Siempre devuelve 0 con LibreSSL.

VER TAMBIÉN

ssl(3), SSL_CTX_sess_set_new_cb(3), SSL_get_session(3)

HISTORIA

SSL_SESSION_is_resumable() apareció por primera vez en OpenSSL 1.1.1 y ha estado disponible desde OpenBSD 7.0.
