NOMBRE

libguestfs-make-fixed-appliance - Crea una "appliance fija" para libguestfs

SINOPSIS

libguestfs-make-fixed-appliance [--opciones] DIRECTORiodesalida
libguestfs-make-fixed-appliance [--opciones] --xz

DESCRIPCIÓN

libguestfs-make-fixed-appliance te permite crear una appliance binaria precompilada para libguestfs.

Nota: los usuarios normales no deberían necesitar ejecutar esta herramienta.

Algunas razones por las que *podrías* querer usar esto incluyen:

  • Quieres crear una appliance libguestfs autónoma que pueda ser copiada a otra máquina o plataforma que no sea compatible con supermin(1).
  • Tienes varios usuarios en la misma máquina y quieres evitar la duplicación de almacenamiento y la sobrecarga de inicio al tener varias copias cacheadas de la appliance.
  • Quieres tener un rendimiento muy predecible de libguestfs (ver guestfs-performance(1)).

Para una comprensión más profunda de por qué podrías necesitar esta herramienta, lee "APPLIANCE FIJA" en guestfs-internals(1).

En lugar de ejecutar esta herramienta, puedes descargar appliances fijas de http://libguestfs.org/download/binaries/appliance/. Estas appliances se hicieron usando esta herramienta.

Hay dos formas de usar esta herramienta.

  • Especifica un directorio de salida, por ejemplo: 
    libguestfs-make-fixed-appliance /usr/local/lib/guestfs/appliance

    El directorio de salida se crea si no existe. Se crean cuatro archivos en este directorio:

    <DIRECTORIODESALIDA>/kernel
<DIRECTORIODESALIDA>/initrd
<DIRECTORIODESALIDA>/root
<DIRECTORIODESALIDA>/README.fixed

    Nota que "DIRECTORIODESALIDA/root" es un archivo disperso, así que ten cuidado al copiarlo.

    Puedes ejecutar libguestfs (posiblemente después de copiar este directorio a otra máquina) estableciendo la variable de entorno LIBGUESTFS_PATH a "DIRECTORIODESALIDA".

  • El método alternativo es usar la opción --xz para crear un archivo tar comprimido: 
    libguestfs-make-fixed-appliance --xz

    Esto crea un archivo tar en el directorio actual llamado:

    appliance-<VERSION>.tar.xz

    (donde "VERSION" es la versión de libguestfs). El archivo tar contiene los cuatro archivos:

    appliance/kernel
appliance/initrd
appliance/root
appliance/README.fixed

    Nota que "appliance/root" es un archivo disperso, así que ten cuidado al copiarlo.

OPCIONES

--help
Muestra información breve de uso y sale.
-V
--version
Muestra el número de versión y sale.
--xz
En lugar de crear la appliance en un directorio de salida, crea un archivo tar comprimido de la appliance en el directorio actual llamado appliance-VERSION.tar.xz donde "VERSION" es la versión de libguestfs.

Usar --xz puede llevar algo de tiempo. Si está funcionando normalmente, la herramienta es completamente silenciosa mientras se ejecuta.

LICENCIA

La appliance fija es una distribución binaria completa de Linux. Si la distribuyes, es posible que necesites distribuir archivos fuente correspondientes para cumplir legalmente con las licencias del software en la appliance (como la Licencia Pública General de GNU).

ESTADO DE SALIDA

libguestfs-make-fixed-appliance devuelve 0 si la appliance se construyó sin errores.

VARIABLES DE ENTORNO

Para la lista completa de variables de entorno que pueden afectar a libguestfs, consulta la página del manual de guestfs(3).

NOMBRE

libguestfs-make-fixed-appliance - crear un appliance fijo para libguestfs

SINOPSIS

make-fixed-appliance [OPCIÓN]... nombre-disco-salida

DESCRIPCIÓN

make-fixed-appliance crea un disco de appliance fijo para libguestfs. Un appliance fijo es una imagen de disco que contiene una distribución de Linux preconfigurada y optimizada para su uso por libguestfs. Esta imagen se puede copiar y usar como base para varias operaciones de libguestfs.

OPCIONES

-h, --help
Muestra un mensaje de ayuda y sale.
-v, --verbose
Habilita la salida detallada.
-d, --debug
Habilita la depuración.
-o, --output-dir directorio
Especifica el directorio donde se creará el disco de appliance. Por defecto es el directorio actual.
-a, --arch arquitectura
Especifica la arquitectura de destino (por ejemplo, x86_64, aarch64). Por defecto es la arquitectura del sistema actual.
-r, --release versión
Especifica la versión del sistema operativo a usar (por ejemplo, 8 para Fedora 8, 20.04 para Ubuntu 20.04). Consulte la documentación de libguestfs para obtener una lista de versiones compatibles.
-N, --no-kernel
No incluye un kernel en el appliance. Esto puede ser útil si el kernel se cargará por separado.
-U, --user-packages paquete1,paquete2...
Instala paquetes adicionales en el appliance que no son necesarios para el funcionamiento básico de libguestfs pero que pueden ser útiles para ciertas operaciones.
-X, --extra-files archivo1,archivo2...
Copia archivos adicionales especificados en la imagen del appliance.

EJEMPLO

Crear un appliance fijo de 64 bits de Fedora 35 y guardarlo en el directorio /var/tmp:

make-fixed-appliance -o /var/tmp -a x86_64 -r 35 fedora-35-x86_64.img

ESTADO DE SALIDA

Devuelve 0 si la operación se completa con éxito, o un valor distinto de cero en caso de error.
