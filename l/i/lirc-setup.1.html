NOMBRE

lirc-setup - Herramienta interactiva de configuración de lirc

SINOPSIS

lirc-setup [directorio de salida]

DESCRIPCIÓN

Una herramienta GUI sencilla que crea una configuración de lirc tras algunos diálogos del usuario que definen el controlador, el dispositivo, las acciones de modprobe, etc. Los resultados se escriben como archivos separados en el directorio de salida, que por defecto es lirc-setup.conf.d

ARCHIVOS

configs
La base de datos de hardware de lirc. Por defecto, el archivo se busca en ., .., /usr/share/lirc y el directorio donde se encuentra lirc-setup. configs es un directorio con un archivo separado para cada entrada del menú. Ver configs/README.
lirc-setup.conf.d
El directorio de salida. En salidas normales contiene al menos los archivos lircd.conf y lirc_options.conf. Archivos opcionales lirc-modprobe.conf y lircmd.conf

Varios otros archivos de soporte se descargan del sitio web de lirc como parte del proceso de configuración.

VER TAMBIÉN

http://sf.net/p/lirc-remotes
La base de datos de configuraciones de mandos a distancia de lirc, un proyecto separado. lirc-setup obtiene todas las configuraciones de mandos a distancia de este punto.
