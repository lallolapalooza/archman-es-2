SSL_CTX_ADD_SESSION(3) Manual de funciones de la biblioteca SSL_CTX_ADD_SESSION(3)

NOMBRE

SSL_CTX_add_session, SSL_CTX_remove_session — manipular la caché de sesiones

SINOPSIS

biblioteca “libssl” libcrypto
#include <openssl/ssl.h>

int
SSL_CTX_add_session(SSL_CTX *ctx, SSL_SESSION *c);

int
SSL_CTX_remove_session(SSL_CTX *ctx, SSL_SESSION *c);

DESCRIPCIÓN

SSL_CTX_add_session() añade la sesión c al contexto ctx. El contador de referencias de la sesión c se incrementa en 1. Si ya existe una sesión con el mismo ID de sesión, la sesión antigua se elimina llamando a SSL_SESSION_free(3).

SSL_CTX_remove_session() elimina la sesión c del contexto ctx y la marca como no resumible. SSL_SESSION_free(3) se llama una vez para c.

Al añadir una nueva sesión a la caché de sesiones interna, se examina si ya existe una sesión con el mismo ID de sesión. En este caso, se asume que ambas sesiones son idénticas. Si la misma sesión está almacenada en un objeto SSL_SESSION diferente, la sesión antigua se elimina y se reemplaza por la nueva sesión. Si la sesión es realmente idéntica (el objeto SSL_SESSION es idéntico), SSL_CTX_add_session() no hace nada y el valor de retorno es 0.

Si un contexto de servidor SSL_CTX está configurado con la bandera SSL_SESS_CACHE_NO_INTERNAL_STORE, la caché interna no se poblará automáticamente con nuevas sesiones negociadas por la implementación SSL/TLS, aunque la caché interna se buscará automáticamente para solicitudes de reanudación de sesión (esto último se puede suprimir con SSL_SESS_CACHE_NO_INTERNAL_LOOKUP). Por lo tanto, la aplicación puede usar SSL_CTX_add_session() directamente para tener control total sobre las sesiones que se pueden reanudar si se desea.

VALORES DE RETORNO

Los siguientes valores son devueltos por todas las funciones:

0
La operación falló. En el caso de la operación de adición, se intentó añadir la misma sesión (idéntica) dos veces. En el caso de la operación de eliminación, la sesión no se encontró en la caché.
1
La operación tuvo éxito.

VER TAMBIÉN

ssl(3), SSL_CTX_set_session_cache_mode(3), SSL_SESSION_free(3)

HISTORIA

SSL_CTX_add_session() y SSL_CTX_remove_session() aparecieron por primera vez en SSLeay 0.8.0 y han estado disponibles desde OpenBSD 2.4.
