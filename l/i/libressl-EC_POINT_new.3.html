EC_POINT_NEW(3) Manual de funciones de biblioteca EC_POINT_NEW(3)

NOMBRE

EC_POINT_new, EC_POINT_free, EC_POINT_clear_free, EC_POINT_copy, EC_POINT_dup — asignar, liberar y copiar puntos de curva elíptica

SINOPSIS

biblioteca “libcrypto”
#include <openssl/ec.h>


EC_POINT *
EC_POINT_new(const EC_GROUP *group);

void
EC_POINT_free(EC_POINT *point);

void
EC_POINT_clear_free(EC_POINT *point);

int
EC_POINT_copy(EC_POINT *dst, const EC_POINT *src);

EC_POINT *
EC_POINT_dup(const EC_POINT *point, const EC_GROUP *group);

DESCRIPCIÓN

Un objeto EC_POINT contiene un punto en la curva elíptica representada por un EC_GROUP. Los detalles de la representación interna dependen del grupo y nunca deberían ser una preocupación de la aplicación, ya que la biblioteca EC tiene una API para establecer las coordenadas de un punto, EC_POINT_set_affine_coordinates(3).

EC_POINT_new() asigna e inicializa un objeto EC_POINT para ser usado con el group. Antes de establecer explícitamente sus coordenadas, el EC_POINT devuelto no es válido.

EC_POINT_free() libera point y toda la memoria asociada a él. Si point es un puntero NULL, no se realiza ninguna acción.

EC_POINT_clear_free() está diseñado para destruir datos sensibles contenidos en point además de liberar toda la memoria asociada a él. Dado que los puntos de curva elíptica suelen contener datos públicos, esto rara vez es necesario. En LibreSSL, EC_POINT_free() y EC_POINT_clear_free() se comportan de manera idéntica.

EC_POINT_copy() copia la representación interna de src en dst. Si src y dst son idénticos, no se realiza ninguna acción. Ambos src y dst deberían ser el resultado de EC_POINT_new() con el mismo argumento group, aunque EC_POINT_copy() no puede verificar eso.

EC_POINT_dup() crea una copia profunda de point combinando EC_POINT_new() con EC_GROUP_copy().

VALORES DE RETORNO

EC_POINT_new() devuelve un EC_POINT recién asignado o NULL en caso de fallo de asignación de memoria.

EC_POINT_copy() devuelve 1 en caso de éxito o 0 en caso de error. Las condiciones de error incluyen fallos de asignación de memoria y que dst sea incompatible con el grupo en el que se define src.

EC_POINT_dup() devuelve un EC_POINT recién asignado o NULL en caso de fallo. Las condiciones de error incluyen fallos de asignación de memoria o que group sea incompatible con src.

VER TAMBIÉN

HISTORIA

EC_POINT_new(), EC_POINT_free(), EC_POINT_clear_free(), y EC_POINT_copy() aparecieron por primera vez en OpenSSL 0.9.7 y han estado disponibles desde OpenBSD 3.2.

EC_POINT_dup() apareció por primera vez en OpenSSL 0.9.8 y ha estado disponible desde OpenBSD 4.5.

ERRORES

Un defecto fundamental en el conjunto de herramientas de la API de OpenSSL es que las funciones *_new() usualmente crean objetos inválidos que son difíciles de convertir en objetos válidos. Un defecto específico en los detalles internos de la biblioteca EC es que los objetos EC_POINT no mantienen una referencia al grupo en el que residen, a pesar del hecho de que EC_POINT_new() tiene un argumento group. Esto es difícil de arreglar porque los objetos EC_GROUP no tienen conteo de referencia y debido a los calificadores const en la API. Esta es la causa raíz de varias contorsiones en la biblioteca y la API EC y tiene implicaciones de seguridad porque no solo la biblioteca no sabe si un objeto EC_POINT representa un punto válido, sino que incluso si lo supiera, todavía no sabría en qué curva.

La firma de EC_GROUP_dup() es extraña y el orden de point y group es inconsistente con el resto de la API EC.

NOMBRE

EC_POINT_new, EC_POINT_free, EC_POINT_copy, EC_POINT_cmp - crear, destruir, copiar y comparar puntos de curva elíptica

SINÓPSIS


#include <openssl/ec.h>

EC_POINT *EC_POINT_new(const EC_GROUP *group);
void EC_POINT_free(EC_POINT *point);
int EC_POINT_copy(EC_POINT *dst, const EC_POINT *src);
int EC_POINT_cmp(const EC_POINT *a, const EC_POINT *b, const EC_GROUP *group);

DESCRIPCIÓN

La función EC_POINT_new() asigna y inicializa una estructura EC_POINT. El parámetro group especifica la curva elíptica a la que pertenecerá el punto. Si group es NULL, entonces no se asigna ninguna curva específica, y será necesario establecerla más tarde mediante una llamada a EC_POINT_set_curve() antes de usar el punto.

La función EC_POINT_free() libera la memoria asignada a point.

La función EC_POINT_copy() copia el punto src al punto dst. dst debe haber sido inicializado previamente, por ejemplo, mediante una llamada a EC_POINT_new(). Ambos puntos deben pertenecer al mismo grupo de curvas elípticas. La función EC_POINT_copy() devuelve 1 si la operación fue exitosa, y 0 en caso contrario.

La función EC_POINT_cmp() compara los puntos a y b dentro del grupo group. Devuelve 0 si los puntos son iguales, 1 si a es mayor que b, y -1 si a es menor que b.

VALORES DE RETORNO

EC_POINT_new() devuelve un puntero a la estructura EC_POINT recién asignada, o NULL si ocurre un error.

EC_POINT_copy() devuelve 1 en caso de éxito, y 0 en caso de error.

EC_POINT_cmp() devuelve 0 si a y b son iguales, 1 si a > b, y -1 si a < b.

CONFORMACIÓN

Estos no son estándares de ninguna organización. Están destinados a ser compatibles con la especificación de curva elíptica de OpenSSL.
