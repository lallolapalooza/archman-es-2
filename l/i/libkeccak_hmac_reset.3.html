LIBKECCAK_HMAC_RESET(3) Manual de funciones de biblioteca LIBKECCAK_HMAC_RESET(3)

NOMBRE

libkeccak_hmac_reset - Reinicializa un estado de hash HMAC

SINOPSIS

#include <libkeccak.h>
int libkeccak_hmac_reset(struct libkeccak_hmac_state *state, const void *key, size_t key_length);

Enlace con -lkeccak.

DESCRIPCIÓN

La función libkeccak_hmac_reset() reinicializa un estado de hash HMAC con una nueva clave. key_length es la longitud de la clave en bits. Si key es NULL, la clave no se modifica.

VALORES DE RETORNO

La función libkeccak_hmac_reset() devuelve 0 en caso de éxito. En caso de error, devuelve -1 y establece errno para describir el error.

ERRORES

La función libkeccak_hmac_reset() puede fallar por cualquier motivo especificado para las funciones malloc(3) y realloc(3).
