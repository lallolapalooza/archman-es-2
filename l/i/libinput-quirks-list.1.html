NOMBRE

libinput-quirks - utilidad de depuración de correcciones para libinput

SINOPSIS

libinput quirks list [--data-dir /ruta/al/dir] [--verbose] /dev/input/event0

libinput quirks validate [--data-dir /ruta/al/dir] [--verbose]

libinput quirks --help

DESCRIPCIÓN

La herramienta libinput quirks interactúa con la base de datos de correcciones de libinput.

Cuando se invoca como libinput quirks list, la herramienta lista todas las correcciones aplicadas al dispositivo especificado.

Cuando se invoca como libinput quirks validate, la herramienta comprueba si hay errores de análisis en los archivos de correcciones y falla si se encuentra algún error de análisis.

Esta es solo una herramienta de depuración, su salida y comportamiento pueden cambiar en cualquier momento. No confíe en la salida.

OPCIONES

--data-dir /ruta/al/dir
Usa el directorio especificado como directorio de datos para los archivos de correcciones. Si se omite, se utilizan los directorios predeterminados.
--help
Imprime la ayuda.
--verbose
Usa salida detallada, útil para depuración.
