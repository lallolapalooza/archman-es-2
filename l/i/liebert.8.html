LIEBERT(8) Manual de NUT LIEBERT(8)

NOMBRE

liebert - Driver para equipos UPS Liebert de cierre de contacto

SINOPSIS

liebert -h

liebert -a NOMBRE_UPS [OPCIONES]


Nota

Esta página del manual solo documenta las características específicas del hardware del driver liebert. Para obtener información sobre el driver principal, consulte nutupsdrv(8).

HARDWARE SOPORTADO

Este driver soporta algunos equipos UPS Liebert con una interfaz de cierre de contacto. Esto incluye el UPStation GXT2 con su cable de cierre de contacto.

El cable en modo inteligente ("Multilink") NO es compatible con este driver.

ARGUMENTOS ADICIONALES

Este driver no soporta configuraciones adicionales en el archivo ups.conf(5).

ERRORES

Este driver aún no soporta apagados al elevar DTR. Tenga en cuenta que los apagados no son posibles con el cable de cierre de contacto estándar. Es posible que necesite construir otro cable con DTR conectado a la UPS para que funcione.

No hay forma de que este driver detecte el hardware o el cable. Se iniciará correctamente incluso si no hay ninguna UPS presente. Esta es una limitación fundamental de cualquier driver de cierre de contacto.
