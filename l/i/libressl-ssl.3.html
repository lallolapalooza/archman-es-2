SSL(3) Manual de funciones de biblioteca SSL(3)

NOMBRE

ssl — Biblioteca TLS OpenSSL

DESCRIPCIÓN

La biblioteca ssl implementa el protocolo Transport Layer Security (TLS), el sucesor del protocolo Secure Sockets Layer (SSL).

Se crea un objeto SSL_CTX como marco para establecer conexiones habilitadas para TLS/SSL (ver SSL_CTX_new(3)). Varias opciones relativas a certificados, algoritmos, etc., se pueden configurar en este objeto.

Cuando se ha creado una conexión de red, se puede asociar a un objeto SSL. Después de que se haya creado el objeto SSL usando SSL_new(3), SSL_set_fd(3) o SSL_set_bio(3) se pueden usar para asociar la conexión de red con el objeto.

Luego, se realiza el handshake TLS/SSL usando SSL_accept(3) o SSL_connect(3) respectivamente. SSL_read(3) y SSL_write(3) se usan para leer y escribir datos en la conexión TLS/SSL. SSL_shutdown(3) se puede usar para cerrar la conexión TLS/SSL.

ESTRUCTURAS DE DATOS

Actualmente, las funciones de la biblioteca ssl manejan las siguientes estructuras de datos:

SSL_METHOD (Método SSL)
Es una estructura de despacho que describe los métodos/funciones internas de la biblioteca ssl que implementan las diversas versiones de protocolo. Es necesaria para crear un SSL_CTX. Ver TLS_method(3) para los constructores.
SSL_CIPHER (Cifrado SSL)
Esta estructura contiene la información del algoritmo para un cifrado particular que es una parte central del protocolo SSL/TLS. Los cifrados disponibles se configuran sobre una base SSL_CTX y los que se usan realmente forman parte de SSL_SESSION.
SSL_CTX (Contexto SSL)
Es la estructura de contexto global que es creada por un servidor o cliente una vez por ciclo de vida del programa y que contiene principalmente valores predeterminados para las estructuras SSL que luego se crean para las conexiones.
SSL_SESSION (Sesión SSL)
Es una estructura que contiene los detalles de la sesión TLS/SSL actual para una conexión: SSL_CIPHERs, certificados de cliente y servidor, claves, etc.
SSL (Conexión SSL)
Es la estructura principal de SSL/TLS que es creada por un servidor o cliente por conexión establecida. Esta es en realidad la estructura central de la API SSL. En tiempo de ejecución, la aplicación generalmente trata con esta estructura, que tiene enlaces a la mayoría de las otras estructuras.

ARCHIVOS DE ENCABEZADO

Actualmente, la biblioteca ssl proporciona los siguientes archivos de encabezado C que contienen los prototipos de las estructuras de datos y funciones:

ssl.h
Este es el archivo de encabezado común para la API SSL/TLS. Inclúyalo en su programa para que la API de la biblioteca ssl esté disponible. Incluye internamente encabezados SSL más privados y encabezados de la biblioteca crypto. Siempre que necesite detalles profundos sobre los aspectos internos de la API SSL, consulte este archivo de encabezado.
ssl3.h
Este es el sub-archivo de encabezado que trata solo con el protocolo SSLv3.
Generalmente no necesita incluirlo explícitamente porque ya está incluido por ssl.h.
tls1.h
Este es el sub-archivo de encabezado que trata solo con el protocolo TLSv1.
Generalmente no necesita incluirlo explícitamente porque ya está incluido por ssl.h.

NAME

libressl-ssl - OpenSSL SSL/TLS library

SYNOPSIS

#include <openssl/ssl.h>

DESCRIPTION

The libressl-ssl library provides an interface to the TLS and SSL protocols. It is a free implementation of the Transport Layer Security (TLS) and Secure Sockets Layer (SSL) protocols.

The library provides functions for creating and managing SSL/TLS contexts, sessions, and connections. It also includes functions for handling certificates, keys, and various configuration options.

DATA STRUCTURES

The library uses the following data structures:

  • SSL_CTX: Represents the SSL/TLS context. It holds configuration options that are shared among multiple SSL connections.
  • SSL: Represents an SSL/TLS connection. It holds state information specific to a single connection.
  • SSL_SESSION: Represents an SSL/TLS session. It stores session state information that can be used to resume a previous session.

HEADER FILES

The following header files are relevant:

  • <openssl/ssl.h>: Main header file for SSL/TLS functions.
  • <openssl/err.h>: For error handling.
  • <openssl/x509.h>: For certificate handling.
