TLS_CONFIG_OCSP_REQUIRE_STAPLING(3) Manual de Funciones de Biblioteca TLS_CONFIG_OCSP_REQUIRE_STAPLING(3)

NOMBRE

tls_config_ocsp_require_stapling — Configuración OCSP para libtls

SINOPSIS

biblioteca “libtls” libssl libcrypto
#include <tls.h>

void
tls_config_ocsp_require_stapling(struct tls_config *config);

DESCRIPCIÓN

tls_config_ocsp_require_stapling() requiere que se proporcione una respuesta OCSP "stapled" válida durante el apretón de manos TLS.

VER TAMBIÉN

tls_config_add_keypair_file(3), tls_handshake(3), tls_init(3), tls_ocsp_process_response(3)

HISTORIA

Estas funciones aparecieron en OpenBSD 6.1.
