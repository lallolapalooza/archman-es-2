NOMBRE

libxslt - librería usada para realizar transformaciones XSL en documentos XML

DESCRIPCIÓN

La librería libxslt se utiliza para realizar transformaciones XSL en documentos XML que han sido cargados en memoria con funciones de libxml.

ARCHIVOS

/usr/lib/libxslt_1.0.0/libxslt.a
librería estática
/usr/lib/libxslt_1.0.0/libxslt.so
librería compartida
/usr/package/libxslt_1.0.0/bin/xsltproc
aplicación binaria para realizar transformaciones XSL en la línea de comandos
