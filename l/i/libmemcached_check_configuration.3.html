#include <libmemcached-1.0/memcached.h>

  • string_length -- longitud de la cadena de configuración sin ningún cero terminador
Retorna
estructura memcached_st asignada e inicializada
memcached_return_t libmemcached_check_configuration(const char *option_string, size_t length, char *error_buffer, size_t error_buffer_size)
Parámetros
  • option_string -- cadena de configuración
  • length -- longitud de la cadena de configuración sin ningún cero terminador
  • error_buffer -- búfer utilizado para almacenar cualquier mensaje de error
  • error_buffer_size -- tamaño disponible del error_buffer
Retorna
memcached_return_t indicando éxito

DESCRIPCIÓN

libmemcached implementa un lenguaje personalizado para configurar y modificar servidores. Al pasar una cadena de opciones puedes generar un objeto memcached_st que puedes usar directamente en tu aplicación.

Opciones Generales:

--SERVIDOR=<nombre_servidor>:<puerto_opcional>/?<peso_opcional>
Proporciona un nombre de servidor a ser utilizado por el cliente.

Proporcionar un peso hará que ocurra el ponderado con todos los hosts, recibiendo cada servidor un peso predeterminado de 1.

--SOCKET="<ruta_archivo>/?<peso_opcional>"
Proporciona una ruta de archivo a un socket UNIX. Proporcionar un peso hará que ocurra el ponderado con todos los hosts, recibiendo cada servidor un peso predeterminado de 1.
--VERIFICAR-CLAVE
Verifica que las claves que se están utilizando encajen dentro del diseño del protocolo que se está utilizando.
--ELIMINAR-SERVIDORES-FALLIDOS
Habilita el comportamiento MEMCACHED_BEHAVIOR_REMOVE_FAILED_SERVERS.
--PROTOCOLO-BINARIO
Fuerza que todas las conexiones utilicen el protocolo binario.
--BUFFER-SOLICITUDES
Por favor, consulta MEMCACHED_BEHAVIOR_BUFFER_REQUESTS.
--CONFIGURAR-ARCHIVO=
Proporciona un archivo de configuración a ser utilizado para cargar solicitudes. Ten en cuenta que al usar un archivo de configuración, libmemcached reiniciará memcached_st basándose únicamente en la información contenida en el archivo.
--TIEMPO-ESPERA-CONEXION=
Consulta memcached_behavior_set() para MEMCACHED_BEHAVIOR_CONNECT_TIMEOUT.
--DISTRIBUCION=
Establece el modelo de distribución utilizado por el cliente. Consulta memcached_behavior_set() para más detalles.
--HASH=
Establece el algoritmo de hash utilizado para colocar claves en los servidores.
--HASH-CON-ESPACIO-NOMBRES
Cuando se habilita, la clave prefijo se agregará a la clave al determinar en qué servidor almacenar los datos.
--SINRESPUESTA
Habilita "sin respuesta" para todas las llamadas que lo admitan. Se recomienda encarecidamente usar esta opción solo con el protocolo binario.
--NUMERO-DE-REPLICAS=
Establece el número de servidores a los que se replicarán las claves.
--ALEATORIZAR-LECTURA-REPLICA
Selecciona aleatoriamente el servidor dentro del grupo de replicación para leer.
--ORDENAR-HOSTS
Al agregar nuevos servidores, siempre calcula su distribución basándose en el orden de nombres ordenado.
--SOPORTE-CAS
Consulta memcached_behavior_set() para MEMCACHED_BEHAVIOR_SUPPORT_CAS
--USAR-UDP
Consulta memcached_behavior_set() para MEMCACHED_BEHAVIOR_USE_UDP
--ESPACIO-NOMBRES=
Un espacio de nombres es un contenedor que proporciona contexto para las claves; solo otras solicitudes que conozcan el espacio de nombres pueden acceder a estos valores. Esto se logra anteponiendo el valor del espacio de nombres a todas las claves.

Opciones de Pool de Memcached:

--POOL-MIN
Tamaño inicial del pool.
--POOL-MAX
Maximiza el tamaño del pool.

Opciones de E/S:

--SIN-DEMORA-TCP
Consulta memcached_behavior_set() para MEMCACHED_BEHAVIOR_TCP_NODELAY
--MANTENER-CONEXION-TCP
Consulta memcached_behavior_set() para MEMCACHED_BEHAVIOR_TCP_KEEPALIVE
--TIEMPO-ESPERA-REINTENTO=
Consulta memcached_behavior_set() para MEMCACHED_BEHAVIOR_RETRY_TIMEOUT
--LIMITE-FALLOS-SERVIDOR=
Consulta memcached_behavior_set() para MEMCACHED_BEHAVIOR_SERVER_FAILURE_LIMIT
--TIEMPO-ESPERA-ENVIO=
Consulta memcached_behavior_set() para MEMCACHED_BEHAVIOR_SND_TIMEOUT
--TAMANO-RECEPCION-SOCKET=
Consulta memcached_behavior_set() para MEMCACHED_BEHAVIOR_SOCKET_RECV_SIZE
--TAMANO-ENVIO-SOCKET=
Consulta memcached_behavior_set() para MEMCACHED_BEHAVIOR_SOCKET_SEND_SIZE

NAME

libmemcached_check_configuration — validate and process a configuration string for libmemcached.

SYNOPSIS

memcached_st *memcached(const char *config_string, size_t config_string_length);

DESCRIPTION

The memcached() function is used to validate and process a configuration string. The configuration string is a series of options, separated by whitespace. The memcached() function will then process these options to configure the libmemcached object.

Configuration Options:

--SERVER=
Add a server to the pool of servers. The server is specified in the format host:port. If the port is not specified, the default memcached port (11211) is used.
--BINARY
Enable the binary protocol. This is the default behavior.
--ASCII
Enable the ASCII protocol. Use this if you need to communicate with a memcached server that does not support the binary protocol.
--POLL-TIMEOUT=
Set the timeout in milliseconds to use for the poll(3) calls. This value is used to determine how long to wait for a server to respond before timing out. A value of 0 means to poll once and return immediately. A negative value means to poll indefinitely.
--SOCKET-RECV-SIZE=
See memcached_behavior_set() for MEMCACHED_BEHAVIOR_SOCKET_RECV_SIZE
--SOCKET-SEND-SIZE=
See memcached_behavior_set() for MEMCACHED_BEHAVIOR_SOCKET_SEND_SIZE
--POLL-TIMEOUT=
Set the timeout used by poll(3).
--IO-BYTES-WATERMARK=
--IO-KEY-PREFETCH=
--IO-MSG-WATERMARK=
--TCP-KEEPIDLE
--RCV-TIMEOUT=

Other Options:

INCLUDE
Include a file in configuration. Unlike --CONFIGURE-FILE= this will not reset memcached_st.
RESET
Reset memcached_st and continue to process.
END
End configuration processing.
ERROR
End configuration processing and throw an error.

ENVIRONMENT

LIBMEMCACHED

RETURN VALUE

memcached() returns a pointer to the memcached_st that was created (or initialized). On an allocation failure, it returns NULL.
