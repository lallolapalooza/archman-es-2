libressl-SSL_get_finished(3)

Paquete: libressl

Licencias: ISC, custom:OpenSSL

SSL_GET_FINISHED(3) Manual de funciones de biblioteca SSL_GET_FINISHED(3)

NOMBRE

SSL_get_finished, SSL_get_peer_finished — obtener el último mensaje de finalización enviado o esperado

SINOPSIS

biblioteca “libssl” libcrypto
#include <openssl/ssl.h>

size_t
SSL_get_finished(const SSL *ssl, void *buf, size_t count);

size_t
SSL_get_peer_finished(const SSL *ssl, void *buf, size_t count);

DESCRIPCIÓN

SSL_get_finished() y SSL_get_peer_finished() copian count bytes del último mensaje de finalización enviado al par o esperado del par en el búfer proporcionado por el llamador buf.

El mensaje de finalización se calcula a partir de una suma de verificación de los registros de saludo intercambiados con el par. Su longitud depende del cifrado en uso y es como máximo EVP_MAX_MD_SIZE, es decir, 64 bytes.

VALORES DE RETORNO

SSL_get_finished() y SSL_get_peer_finished() devuelven el número de bytes copiados en buf. El valor de retorno es cero si el saludo no ha llegado al mensaje de finalización.

VER TAMBIÉN

ssl(3), SSL_get_session(3), SSL_set_session(3)

ESTÁNDARES

RFC 8446: El protocolo Transport Layer Security (TLS) versión 1.3, sección 4.4.4: Finished.

RFC 5246: El protocolo Transport Layer Security (TLS) versión 1.2, sección 7.4.9: Finished.

HISTORIA

SSL_get_finished() y SSL_get_peer_finished() aparecieron por primera vez en SSLeay 0.9.5 y han estado disponibles desde OpenBSD 2.7.
