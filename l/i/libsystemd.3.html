NOMBRE

libsystemd - Funciones para implementar servicios e interactuar con systemd

SINOPSIS

#include <systemd/sd-bus.h>
#include <systemd/sd-daemon.h>
#include <systemd/sd-device.h>
#include <systemd/sd-event.h>
#include <systemd/sd-gpt.h>
#include <systemd/sd-hwdb.h>
#include <systemd/sd-id128.h>
#include <systemd/sd-journal.h>
#include <systemd/sd-json.h>
#include <systemd/sd-login.h>
#include <systemd/sd-messages.h>
#include <systemd/sd-path.h>
#include <systemd/sd-varlink.h>

pkg-config --cflags --libs libsystemd

DESCRIPCIÓN

La biblioteca libsystemd proporciona funciones que permiten interactuar con varias interfaces proporcionadas por el gestor de servicios systemd(1), así como otras funciones y constantes útiles para implementar servicios en general.

Consulte sd-bus(3), sd-bus-errors(3), sd-daemon(3), sd-device(3), sd-event(3), sd-hwdb(3), sd-id128(3), sd-journal(3), sd-json(3), sd-login(3), sd-path(3) y sd-varlink(3) para obtener información sobre las diferentes partes de la interfaz de la biblioteca.

ESTABILIDAD DE LA INTERFAZ

Se mantiene una estricta compatibilidad con versiones anteriores para la API (interfaz de programación de aplicaciones) y ABI (interfaz binaria de aplicaciones). Se utiliza el versionado de símbolos, añadiendo símbolos pero nunca eliminándolos.

NOTAS

Las funciones descritas aquí están disponibles como una biblioteca compartida, que se puede compilar y enlazar con el archivo libsystemd pkg-config(1).

El código descrito aquí utiliza getenv(3), que se declara no ser seguro para la ejecución en paralelo. Esto significa que el código que llama a las funciones descritas aquí no debe llamar a setenv(3) desde un hilo paralelo. Se recomienda realizar solo llamadas a setenv() desde una fase temprana del programa cuando no se hayan iniciado otros hilos.
