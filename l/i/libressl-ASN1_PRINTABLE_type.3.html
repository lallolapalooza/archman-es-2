ASN1_PRINTABLE_TYPE(3) Manual de funciones de biblioteca ASN1_PRINTABLE_TYPE(3)

NOMBRE

ASN1_PRINTABLE_type — clasifica una cadena de caracteres de un solo byte

SINOPSIS

biblioteca “libcrypto”
#include <openssl/asn1.h>

int
ASN1_PRINTABLE_type(const unsigned char *string, int len);

DESCRIPCIÓN

ASN1_PRINTABLE_type() asume que la cadena dada consta de caracteres de un solo byte y la clasifica según los tipos de caracteres que aparecen. Si len es mayor que 0, se inspeccionan como máximo len caracteres. De lo contrario, la cadena debe terminar en NUL.

VALORES DE RETORNO

Si la cadena dada contiene un carácter fuera del rango de ascii(7), ASN1_PRINTABLE_type() devuelve V_ASN1_T61STRING.

De lo contrario, si contiene un carácter que no es ni una letra ni un dígito ni un carácter de espacio (‘ ’, ASCII 0x20) ni la comilla apóstrofo (‘'’, ASCII 0x27) ni está contenido en el conjunto "()+,-./:=?", devuelve V_ASN1_IA5STRING.

De lo contrario, incluso si string es un puntero NULL o apunta a una cadena vacía, devuelve V_ASN1_PRINTABLESTRING.

VER TAMBIÉN

ASN1_mbstring_copy(3), ASN1_STRING_new(3), ASN1_STRING_to_UTF8(3), isascii(3), ascii(7)

HISTORIA

ASN1_PRINTABLE_type() apareció por primera vez en SSLeay 0.4.5d, ha sido parte de la API pública desde SSLeay 0.5.1 y ha estado disponible desde OpenBSD 2.4.

ADVERTENCIAS

La noción ASN.1 de lo que constituye una PrintableString es más restrictiva que lo que la función de biblioteca C isprint(3) considera imprimible.
