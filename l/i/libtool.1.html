LIBTOOL(1) Comandos de usuario LIBTOOL(1)

NOMBRE

libtool - Proporciona servicios generalizados de creación de bibliotecas

SINOPSIS

libtool [OPCIÓN]... [ARGUMENTO-MODO]...

DESCRIPCIÓN

Proporciona servicios generalizados de creación de bibliotecas.

OPCIONES

--config
muestra todas las variables de configuración
--debug
habilita el rastreo detallado del shell
-n, --dry-run
muestra los comandos sin modificar ningún archivo
--features
muestra información básica de configuración
--finish
usa la operación '--mode=finish'
--mode=MODO
usa el modo de operación MODO
--no-finish
no actualiza la caché de bibliotecas compartidas
--no-quiet, --no-silent
imprime mensajes informativos por defecto
--no-warnings
equivalente a '-Wnone'
--preserve-dup-deps
no elimina bibliotecas de dependencia duplicadas
--quiet, --silent
no imprime mensajes informativos
--reorder-cache=DIRS
reordena la caché de bibliotecas compartidas para DIRS preferidos
--tag=TAG
usa variables de configuración de la etiqueta TAG
-v, --verbose
imprime más mensajes informativos que el predeterminado
--version
imprime información de la versión
-W, --warnings=CATEGORÍA
informa de las advertencias que caen en CATEGORÍA [all]
-h, --help, --help-all
imprime un mensaje de ayuda corto, largo o detallado

Las categorías de advertencia incluyen:

'all'
muestra todas las advertencias
'none'
desactiva todas las advertencias
'error'
las advertencias se tratan como errores fatales

Si se proporciona una ETIQUETA, debe usar uno de los nombres de etiqueta a continuación:

Si no ve un nombre de etiqueta asociado con su lenguaje de programación, entonces está utilizando un compilador que libtool no soporta.

MODO debe ser uno de los siguientes:

clean
elimina archivos del directorio de compilación
compile
compila un archivo fuente en un objeto libtool
execute
establece automáticamente la ruta de la biblioteca y luego ejecuta un programa
finish
completa la instalación de bibliotecas libtool
install
instala bibliotecas o ejecutables
link
crea una biblioteca o un ejecutable
uninstall
elimina bibliotecas de un directorio instalado

Los ARGUMENTOS-MODO varían según el MODO. Cuando se pasan como primera opción, '--mode=MODO' puede abreviarse como 'MODO' o una abreviatura única del mismo.
