LIRCRCD(8) Manual del Administrador del Sistema LIRCRCD(8)

NOMBRE

lircrcd - Sincroniza el estado de lircrc entre aplicaciones cliente.

SINOPSIS

lircrcd [opciones] archivo-de-configuración

DESCRIPCIÓN

lircrcd lee el archivo de configuración .lircrc dado y sincroniza el modo en que se encuentran los clientes LIRC como irexec(1), irxevent(1), etc. El uso de lircrcd debe estar explícitamente habilitado en el archivo de configuración lircrc añadiendo la siguiente línea al principio del archivo:

lircrc_class default

Esto debe hacerse en el archivo de nivel superior, no en uno incluido. La cadena lircrc_class (aquí "default") podría ser en realidad cualquier cosa; los clientes que usen la misma cadena en su lircrc se sincronizarán.

OPCIONES

-h --help
Muestra el mensaje de ayuda.
-v --version
Muestra la versión.
-p, --permission=modo
La opción --permission otorga al socket de dominio Unix que lircrcd crea al iniciarse los permisos del archivo en representación octal. Lea la documentación de chmod para más detalles. Si no se proporciona la opción --permission al crear el socket, el valor predeterminado es otorgar solo al usuario propietario del archivo permisos de lectura y escritura (0600 en representación octal).
-o, --output=socket
Con la opción --output puede seleccionar el socket de dominio Unix que lircrcd creará. El valor predeterminado es crear un socket en VARRUNDIR (/var/run/lirc), véase ARCHIVOS.

PROTOCOLO DE SOCKET

lircrcd utiliza sintácticamente el mismo protocolo que lircd descrito en la página del manual de lircd(8). Admite los siguientes comandos:

IDENT ident
Cada programa que se conecta a lircrcd se identifica con este programa. ident es la cadena que se utiliza en el token Prog = dentro del archivo .lircrc.
CODE code
Cuando el cliente recibe la cadena de código de lircd, la enviará a lircrcd y recibirá de vuelta la cadena de configuración aplicable del archivo de configuración .lircrc. Debería reenviar el comando CODE hasta que no se devuelva nada, lo que significa que no debería ocurrir nada (más) en respuesta a code. Este comando se utiliza cada vez que la función lirc_code2char() es llamada por un cliente.
GETMODE
lircrcd devolverá la cadena del modo actual.
SETMODE mode
lircrcd establecerá el modo actual, reflejando un modo en el archivo .lircrc.

ARCHIVOS

lircrcd crea sus sockets en el directorio VARRUNDIR (/var/run/lirc). El nombre base del socket incluye el UID del usuario y la cadena de la opción lircrc_class.
