listmount(2) Manual de llamadas al sistema listmount(2)

NOMBRE

listmount - obtener una lista de IDs de montaje

BIBLIOTECA

Biblioteca C estándar (libc, -lc)

SINOPSIS

#include <linux/mount.h>  /* Definición de las constantes de la estructura mnt_id_req */
#include <unistd.h>
int syscall(size_t n;
            SYS_listmount, struct mnt_id_req *req,
            uint64_t mnt_ids[n], size_t n,
            unsigned long flags);
#include <linux/mount.h>
struct mnt_id_req {
    __u32  size;    /* sizeof(struct mnt_id_req) */
    __u64  mnt_id;  /* El mnt_id padre que se está buscando */
    __u64  param;   /* El siguiente mnt_id que queremos encontrar */
};

Nota: glibc no proporciona un envoltorio para listmount(), lo que requiere el uso de syscall(2).

DESCRIPCIÓN

Para acceder a los montajes en tu namespace, debes tener CAP_SYS_ADMIN en el namespace de usuario.

Esta función devuelve una lista de IDs de montaje bajo req.mnt_id. Esto está destinado a ser utilizado en conjunción con statmount(2) para proporcionar una forma de iterar y descubrir sistemas de archivos montados.

La estructura mnt_id_req

req.size es utilizado por el kernel para determinar qué struct mnt_id_req se está pasando, siempre debe establecerse en sizeof(struct mnt_id_req).

req.mnt_id es el mnt_id padre del cual listaremos, que puede ser LSMT_ROOT, que significa el montaje raíz del namespace de montaje actual, o un ID de montaje obtenido de statx(2) usando STATX_MNT_ID_UNIQUE o de listmount(2).

req.param se utiliza para indicar al kernel desde qué ID de montaje comenzar la lista. Esto es útil si se requieren múltiples llamadas a listmount(2). Puede establecerse en el último ID de montaje devuelto para reanudar desde un punto anterior en la lista.

VALOR DE RETORNO

En caso de éxito, se devuelve el número de entradas rellenadas en mnt_ids; 0 si no quedan más montajes. En caso de error, se devuelve -1 y errno se establece para indicar el error.

ERRORES

EPERM
El llamador no tiene CAP_SYS_ADMIN en el namespace de usuario.
EFAULT
req o mnt_ids apuntan a una ubicación fuera del espacio de direcciones accesible del proceso.
EINVAL
Se especificó una bandera inválida en flags.
EINVAL
req es de tamaño insuficiente para ser utilizado.
E2BIG
req es demasiado grande, el límite es el tamaño de página de la arquitectura.
ENOENT
El req.mnt_id especificado no existe.
ENOMEM
Falta de memoria (es decir, memoria del kernel).

ESTNDARES

Linux.

VER TAMBIÉN

statmount(2), statx(2)
