Paquete: libressl

X509_REQ_ADD_EXTENSIONS(3) Manual de funciones de la biblioteca X509_REQ_ADD_EXTENSIONS(3)

NOMBRE

X509_REQ_add_extensions, X509_REQ_add_extensions_nid, X509_REQ_get_extensions, X509_REQ_extension_nid — extensiones en solicitudes de certificación

SINOPSIS

biblioteca “libcrypto”
#include <openssl/x509.h>

int
X509_REQ_add_extensions(X509_REQ *req, STACK_OF(X509_EXTENSION) *extensions);

int
X509_REQ_add_extensions_nid(X509_REQ *req, STACK_OF(X509_EXTENSION) *extensions, int nid);

STACK_OF(X509_EXTENSION) *
X509_REQ_get_extensions(X509_REQ *req);

int
X509_REQ_extension_nid(int nid);

DESCRIPCIÓN

X509_REQ_add_extensions() codifica el array de extensions usando i2d_X509_EXTENSIONS(3) y añade un nuevo objeto Atributo X.501 del tipo NID_ext_req a req usando el equivalente de X509_ATTRIBUTE_create_by_NID(3) con un type de V_ASN1_SEQUENCE.

X509_REQ_add_extensions_nid() es idéntica excepto que el nid especificado se usa como el tipo de Atributo X.501 en lugar de NID_ext_req.

X509_REQ_get_extensions() recupera el primer valor del primer Atributo X.501 del tipo apropiado. Por defecto, los tipos de atributo NID_ext_req y NID_ms_ext_req se consideran apropiados.

X509_REQ_extension_nid() comprueba si X509_REQ_get_extensions() considera que el argumento nid es un tipo apropiado para almacenar extensiones.

VALORES DE RETORNO

X509_REQ_add_extensions() y X509_REQ_add_extensions_nid() devuelven 1 para éxito o 0 para fallo.

X509_REQ_get_extensions() devuelve un array recién asignado de objetos Extension ASN.1 o NULL si req es NULL, no contiene CertificationRequestInfo, no contiene ningún atributo del tipo apropiado, o si la decodificación o la asignación de memoria fallan.

X509_REQ_extension_nid() devuelve 1 si nid se considera apropiado o 0 en caso contrario.

VER TAMBIÉN

d2i_X509_EXTENSION(3), STACK_OF(3), X509_EXTENSION_new(3), X509_REQ_new(3), X509V3_extensions_print(3)
