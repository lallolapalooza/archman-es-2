lirc-config-tool(1) Manual de comandos generales lirc-config-tool(1)

NOMBRE

lirc-config-tool - herramienta para escanear y generar archivos de configuración de lirc

SINOPSIS

lirc-config-tool -s|-u [ -c ARCHIVO]

lirc-config-tool [-o DIR] [-d] [-c ARCHIVO] [ARCHIVOS]

lirc-config-tool -l

OPCIONES

Sin opciones, genera todos los archivos lircrc específicos de aplicación disponibles en ~/.config/lirc. Los [archivos] opcionales son una lista de archivos para construir o volcar, tal como se enumera con -l.

-s
Escanea el archivo lircd en busca de símbolos de tecla duplicados o que no estén en el espacio de nombres.
-u
Actualiza el archivo lircd existente para usar símbolos de tecla en el espacio de nombres.
-l
Lista los archivos disponibles para generar.
-d
Vuelca plantillas de archivo utilizables como entrada estándar en la salida estándar.
-o <dir>
Directorio de salida, por defecto es ~/.config/lirc
-c <nombre-archivo-lircd>
Archivo de configuración de lircd(8), por defecto es /etc/lirc/lircd.conf
-h
Imprime el mensaje de ayuda

DESCRIPCIÓN

El script está diseñado para ayudar en la configuración de los archivos de configuración de lirc(8) para controles remotos comunes. No está destinado a manejar teclados o joysticks completos. Los archivos lircrc generados representan un punto de partida que requerirá refinamientos manuales adicionales, pero en muchos casos podría "funcionar" de manera básica.

La configuración implica normalizar lircd.conf para usar símbolos en el espacio de nombres legal y crear archivos lircrc específicos de aplicación que utilizan los símbolos normalizados.

Para ayudar a normalizar /etc/lircd.conf, el script puede informar símbolos utilizados que no están en el espacio de nombres. También puede actualizar muchos de estos símbolos a símbolos correspondientes dentro del espacio de nombres.

El script también puede crear archivos lircrc específicos de aplicación, como mythtv.lircrc o vlc.lircrc. Luego utiliza los símbolos de tecla normalizados en /etc/lirdc.conf. Por defecto, los archivos se crean en ~/.config/lirc.

Los archivos lircrc generados combinan básicamente teclas conocidas de /etc/lircd.conf con datos de plantilla para una aplicación. El proceso resulta en un archivo lircrc, una lista de teclas no utilizadas y algunas entradas que no coinciden con ninguna tecla existente. Las teclas no utilizadas y las entradas no coincidentes se escriben como comentarios en el archivo generado.

Una tecla 'ilegal', es decir, una tecla que no está en el espacio de nombres, no coincidirá con ninguna entrada y, por lo tanto, siempre estará sin usar. Sin embargo, es perfectamente posible usarla más adelante al modificar manualmente los archivos lircrc.

Al actualizar archivos, el script siempre crea copias de seguridad.

Los archivos lircrc generados están destinados a incluirse en un archivo principal ~/.config/lircrc. Un archivo mínimo podría verse así:


include ~/.config/lirc/mythtv.lircrc

EJEMPLOS

Escanear /etc/lirc/lircd.conf en busca de símbolos duplicados y símbolos que no estén en el espacio de nombres:

lirc-config-tool -s

Actualizar un archivo lircd.conf local para usar símbolos en el espacio de nombres:

lirc-config-tool -uc ./lircd.conf

Listar archivos disponibles para generar:

lirc-config-tool -l

Generar uno de los archivos listados por -l, crea ~/.config/lirc/mythtv.lircrc:

lirc-config-tool mythtv

Volcar datos de plantilla para mythtv:

lirc-config-tool -d mythtv >mythtv.lircdata

Usar datos posiblemente editados para crear un mythtv.lircrc modificado en el directorio actual:

lirc-config-tool -o . stdin < mythtv.lircdata

CONVERSIONES LIRCD.CONF

La opción -s simplemente informa todos los símbolos de tecla que no están en el espacio de nombres. También informa algunos símbolos que, aunque legales, son inapropiados en este contexto, especialmente KEY_NUMERIC_0..KEY_NUMERIC_9. Si están presentes, también se informan las teclas duplicadas.

La opción -u convierte varios símbolos conocidos a sus símbolos KEY_ correspondientes. Los símbolos que tienen nombres como KEY_WINDOWS pero que no están en el espacio de nombres reciben un prefijo X_, por ejemplo, KEY_WINDOWS -> X_KEY_WINDOWS. Por lo tanto, el archivo convertido garantiza que cualquier símbolo de tecla que comience con KEY_ sea un símbolo legal.

Todas las teclas numéricas conocidas como '1', 'KEY_1', 'KEY_KP_1', 'KEY_NUMERIC_1 se convierten a KEY_1.

Todas las modificaciones están marcadas con comentarios en el archivo.

EXTENDER

El script se puede extender para admitir más aplicaciones proporcionando una función de shell llamada *.lircdata. Por ejemplo, para agregar una nueva aplicación llamada "mi_app" basada en la aplicación vlc incorporada:


$ lirc-config-tool -d vlc >mi_app.lircdata
$ function mi_app_lircdata()
> {
> cat mi_app.lircdata
> }
$ export -f mi_app_lircdata
$ lirc-config-tool mi_app

FORMATO DATOS

El script utiliza un formato simple basado en líneas para representar los archivos lircrc. El propósito del formato es ser compacto y, por lo tanto, proporcionar una buena visión general, y también ser fácil de analizar. Cada línea se divide en tokens separados por comas. Hay cuatro tipos de líneas.

Las líneas de comentarios comienzan con '#'. Estas se copian literalmente al archivo de salida.

La primera línea de datos representa elementos globales, aplicables a todas las entradas. La primera palabra es el nombre del programa. Se usa en la primera línea 'program='. Las palabras siguientes, si están presentes, son líneas opcionales que se agregarán a cada entrada en el archivo.

Una línea de datos que comienza con 'begin' o 'end' es un diseñador de bloque de modo. Se copia literalmente al archivo de salida.

Todas las demás líneas de datos representan una entrada de botón / configuración. El formato es
<botón> <configuración> [extra]...
El valor del botón se usa en la línea button =, y el elemento de configuración se usa en la línea config =. Ambos son obligatorios. Los elementos siguientes, si los hay, se copian como líneas literales a la entrada.

Un ejemplo poco probable: el formato de datos


mi_programa, flags = salir
begin modo_volumen
KEY_VOLUMEN_ARRIBA, volumen-arriba, delay=4, repeat=1
KEY_VOLUMEN_ABAJO, volumen-abajo
end modo_volumen

se traduce a:


begin modo_volumen
begin
program = mi_programa
button = KEY_VOLUMEN_ARRIBA
config = volumen-arriba
delay = 4
repeat = 1
flags = salir
end
begin
program = mi_programa
button = KEY_VOLUMEN_ABAJO
config = volumen-abajo
flags = salir
end
end modo_volumen

LIRC-CONFIG-TOOL(1) User Commands LIRC-CONFIG-TOOL(1)

NAME

lirc-config-tool - tool for configuring LIRC

SYNOPSIS

lirc-config-tool [OPTIONS]

OPTIONS

-h, --help Show help message

DESCRIPTION

The lirc-config-tool is a command-line utility that simplifies the configuration of LIRC (Linux Infrared Remote Control). It allows users to create, edit, and manage LIRC configuration files, which define how LIRC interprets signals from infrared remote controls.

The tool can be used to:

  • Generate new remote control configuration files.
  • Edit existing configuration files.
  • Convert configuration files between different formats.
  • Test remote control configurations.
  • Manage a collection of remote control configurations.

EXAMPLES

To create a new configuration file for a remote control:

$ lirc-config-tool create my_remote.lirc

To edit an existing configuration file:

$ lirc-config-tool edit my_remote.lirc

To convert a configuration file from a different format to LIRC format:

$ lirc-config-tool convert legacy_format.conf my_remote.lirc

LIRCD.CONF CONVERSIONS

The lirc-config-tool can also assist in converting older `lircd.conf` files to the newer format used by LIRC. This is often necessary when upgrading LIRC or migrating configurations.

EXTENDING

The lirc-config-tool is designed to be extensible. Users can add support for new remote control protocols or file formats by providing custom modules or scripts. Refer to the LIRC documentation for details on extending the tool.

DATA FORMAT

The primary data format used by lirc-config-tool is the standard LIRC configuration file format, which typically uses a `.lirc` or `.conf` extension. This format defines remote control names, button names, and the corresponding pulse/space timing data.
