LIQUIDCTL(8) Manual del Administrador del Sistema LIQUIDCTL(8)

NOMBRE

liquidctl - monitorizar y controlar refrigeradores líquidos y otros dispositivos

SINOPSIS

liquidctl [opciones] list
liquidctl [opciones] initialize [all]
liquidctl [opciones] status
liquidctl [opciones] set canal speed (temperatura porcentaje) ...
liquidctl [opciones] set canal speed porcentaje
liquidctl [opciones] set canal color modo [color ...]
liquidctl --version
liquidctl --help

DESCRIPCIÓN

liquidctl es una utilidad para supervisar y controlar algunos dispositivos de monitorización de hardware que aún no son compatibles a nivel de núcleo. Dado que liquidctl accede directamente a los dispositivos de hardware, generalmente se requieren privilegios de root, aunque esto se puede evitar con reglas udev apropiadas.

liquidctl list muestra todos los dispositivos compatibles encontrados en el sistema. En caso de que se encuentre más de un dispositivo, el deseado se puede seleccionar para invocaciones posteriores con --match=subcadena, donde subcadena coincide con parte de la descripción del dispositivo deseado utilizando una comparación insensible a mayúsculas y minúsculas.

liquidctl list --verbose habilita la visualización de identificadores y direcciones adicionales que también se pueden utilizar para seleccionar dispositivos específicos. Estos pueden ser más adecuados para ciertos casos de uso, como scripts no interactivos.

liquidctl initialize prepara un dispositivo para comandos posteriores, y la mayoría de los dispositivos deben inicializarse después de cada arranque o al reanudar desde un estado suspendido. A menos que se requiera un control más fino, todos los dispositivos se pueden inicializar a la vez con liquidctl initialize all. Algunos dispositivos pueden mostrar información en esta etapa.

liquidctl status muestra el estado de todos los dispositivos que coinciden con las opciones de filtrado proporcionadas.

liquidctl set canal speed permite al usuario establecer las velocidades de los ventiladores y las bombas. Estas, dependiendo del dispositivo, se pueden establecer a valores fijos de duty cycle, curvas variables de temperatura\[u2013]duty cycle, o ambas.

liquidctl set canal color permite al usuario configurar y establecer modos de iluminación. Los modos de iluminación soportados y las opciones adicionales varían según el dispositivo y se enumeran en secciones posteriores de este manual. Cada color se puede especificar como:

  • RGB hexadecimal con o sin prefijo '0x': ff7f3f;
  • Triple RGB decimal, R,G,B ∈ [0, 255]: rgb(255,127,63);
  • Triple HUE-SATURACIÓN-VALOR HSV, H ∈ [0, 360], S,V ∈ [0, 100]: hsv(20,75,100);
  • Triple HUE-SATURACIÓN-LUMINOSIDAD HSL, H ∈ [0, 360], S,L ∈ [0, 100]: hsl(20,100,62).

liquidctl set canal screen permite al usuario configurar la pantalla LCD integrada en algunos modelos AIO.

liquidctl detecta automáticamente cuándo un controlador de núcleo está enlazado al dispositivo y, siempre que sea posible, lo utiliza en lugar de acceder directamente al dispositivo. Alternativamente, se puede forzar el acceso directo al dispositivo con --direct-access.

OPCIONES

Opciones de selección de dispositivo

Los dispositivos se pueden seleccionar utilizando uno o más valores obtenidos de list --verbose.

-m subcadena, --match=subcadena
Filtra dispositivos por subcadena insensible a mayúsculas y minúsculas de la descripción del dispositivo.
-n número, --pick=número
Selecciona entre muchos resultados para un filtro dado.
--vendor=id
Filtra dispositivos por ID de vendedor hexadecimal.
--product=id
Filtra dispositivos por ID de producto hexadecimal.
--release=número
Filtra dispositivos por número de versión hexadecimal.
--serial=número
Filtra dispositivos por número de serie.
--bus=bus
Filtra dispositivos por bus.
--address=dirección
Filtra dispositivos por dirección en el bus.
--usb-port=puerto
Filtra dispositivos por puerto USB en el bus.
-d índice, --device=índice
(Obsoleto), selecciona el dispositivo por índice de lista.

Opciones de animación

Algunos dispositivos y modos de animación soportan opciones adicionales.

--speed=valor
Velocidad de animación abstracta (específica del dispositivo/modo).
--time-per-color=valor
Tiempo de espera en cada color (segundos).
--time-off=valor
Tiempo de espera con el LED apagado (segundos).
--alert-threshold=número
Umbral de temperatura para una alerta visual (grados Celsius).
--alert-color=color
Color utilizado por la alerta visual de alta temperatura.
--direction=cadena
Si el patrón debe moverse hacia adelante o hacia atrás.
--start-led=número
El primer LED en el que comenzar el efecto.
--maximum-leds=número
El número de LEDs a los que se aplicará el efecto.

Otras opciones

--fan-mode=canal:modo[,...]
Establece los modos de ventilador.
--single-12v-ocp
Habilita OCP de un solo riel de +12V.
--pump-mode=modo
Establece el modo de bomba.
--temperature-sensor=número
El número de sensor de temperatura para el Commander Pro.
--legacy-690lc
Usa Asetek 690LC en modo legado (Krakens antiguos).
--non-volatile
Almacena en la memoria no volátil del controlador.
--direct-access
Accede directamente al dispositivo a pesar de los controladores del núcleo.
--unsafe=características
Características de vanguardia separadas por comas para habilitar.
-v, --verbose
Muestra información adicional.
-g, --debug
Muestra información de depuración en stderr.
--json
Salida JSON legible por máquina. Solo compatible con list, initialize y status.
--version
Muestra el número de versión.
--help
Muestra la ayuda integrada.

ESTATUS DE SALIDA

1 si hubo un error, 0 en caso contrario.

AMBIENTE

Si LANG está configurado a C, los caracteres no ASCII se escapan de la salida de --json.

ARCHIVOS

$XDG_RUNTIME_DIR/liquidctl/*, /var/run/liquidctl/*, /tmp/liquidctl/*
Datos internos utilizados por algunos controladores.

EJEMPLO

liquidctl list --verbose
liquidctl initialize all
liquidctl --match kraken set pump speed 90
liquidctl --product 170e set led color fading 350017 ff2608
liquidctl status
