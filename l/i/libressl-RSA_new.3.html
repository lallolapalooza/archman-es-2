RSA_NEW(3) Manual de Funciones de Biblioteca RSA_NEW(3)

NOMBRE

RSA_new, RSAPrivateKey_dup, RSAPublicKey_dup, RSA_up_ref, RSA_free — asigna y libera objetos RSA

SINOPSIS

biblioteca “libcrypto”
#include <openssl/rsa.h>

RSA *
RSA_new(void);

RSA *
RSAPrivateKey_dup(RSA *rsa);

RSA *
RSAPublicKey_dup(RSA *rsa);

int
RSA_up_ref(RSA *rsa);

void
RSA_free(RSA *rsa);

DESCRIPCIÓN

Las funciones RSA implementan el cifrado y las firmas de clave pública RSA según se definen en PKCS #1 v2.0 (RFC 2437).

RSA_new() asigna e inicializa una estructura RSA, estableciendo el contador de referencias a 1. Es equivalente a llamar a RSA_new_method(3) con un argumento NULL.

RSAPrivateKey_dup() llama a RSA_new() y copia los componentes de clave pública y privada de rsa en la nueva estructura. RSAPublicKey_dup() hace lo mismo excepto que copia solo los componentes de clave pública.

RSA_up_ref() incrementa el contador de referencias en 1.

RSA_free() decrementa el contador de referencias en 1. Si llega a 0, llama a la función opcional finish configurada con RSA_meth_set_finish(3) y libera la estructura RSA y sus componentes. La clave se borra antes de que la memoria se devuelva al sistema. Si rsa es un puntero NULL, no ocurre ninguna acción.

La estructura RSA consta de varios componentes BIGNUM. Puede contener claves RSA públicas y privadas:

typedef struct {
	BIGNUM *n;		// módulo público
	BIGNUM *e;		// exponente público
	BIGNUM *d;		// exponente privado
	BIGNUM *p;		// factor primo secreto
	BIGNUM *q;		// factor primo secreto
	BIGNUM *dmp1;		// d mod (p-1)
	BIGNUM *dmq1;		// d mod (q-1)
	BIGNUM *iqmp;		// q^-1 mod p
	// ...
} RSA;

En las claves públicas, el exponente privado d y los valores secretos relacionados p, q, dmp1, dmq1 y iqmp son NULL.

p, q, dmp1, dmq1 y iqmp pueden ser NULL en las claves privadas, pero las operaciones RSA son mucho más rápidas cuando estos valores están disponibles.

Tenga en cuenta que las claves RSA pueden usar implementaciones RSA_METHOD no estándar. En algunos casos, estos valores BIGNUM no serán utilizados por la implementación o pueden ser utilizados para almacenamiento de datos alternativo. Por esta razón, las aplicaciones generalmente deben evitar usar los elementos de estructura RSA directamente y en su lugar usar funciones de API para consultar o modificar claves.

VALORES DE RETORNO

RSA_new(), RSAPrivateKey_dup() y RSAPublicKey_dup() devuelven un puntero a la estructura recién asignada, o NULL si ocurre un error. Se puede obtener un código de error llamando a ERR_get_error(3).

RSA_up_ref() devuelve 1 para éxito o 0 para fallo.

HISTORIAL

RSA_new() y RSA_free() aparecieron en SSLeay 0.4 o anterior. RSAPrivateKey_dup() apareció por primera vez en SSLeay 0.5.1 y RSAPublicKey_dup() en SSLeay 0.5.2. Estas funciones han estado disponibles desde OpenBSD 2.4.

RSA_up_ref() apareció por primera vez en OpenSSL 0.9.7 y ha estado disponible desde OpenBSD 3.2.
