LINKS(1) Manual de comandos generales LINKS(1)

NOMBRE

links - navegador WWW alternativo en modo de caracteres similar a lynx

SINOPSIS

links [opciones] URL

DESCRIPCIÓN

links es un navegador WWW en modo de texto con interfaz ncurses, que soporta colores, renderizado correcto de tablas, descarga en segundo plano, interfaz de configuración basada en menús y código eficiente.

Los frames son compatibles. Puede asociar diferentes formatos de archivo con visores externos. mailto: y telnet: se soportan a través de clientes externos.

links puede manejar URLs locales (file://) o remotas (http:// o ftp://).

OPCIONES

La mayoría de las opciones se pueden configurar en la interfaz de usuario o en el archivo de configuración, por lo que generalmente no necesita preocuparse por ellas.

-help
Muestra una pantalla de ayuda.
-version
Muestra el número de versión de links y sale.
-lookup <hostname>
Realiza una búsqueda de nombre, como el comando "host".
-g
Ejecuta Links en modo gráfico. Si no se especifica, Links se ejecutará en modo texto. Ejecutar en modo gráfico significa que Links examinará todos los dispositivos gráficos compilados y se ejecutará en el primero que encuentre. Si no se encuentra ninguno, Links no se ejecutará en modo gráfico. Esta opción solo funciona si se le dio --enable-graphics a ./configure.
-no-g
Ejecuta en modo texto (anula el -g anterior).
-driver <nombre del driver>
Driver gráfico a utilizar. Los drivers son: x, svgalib, fb, directfb, pmshell, atheos. Se mostrará una lista de drivers si se le proporciona un driver desconocido. Los drivers disponibles dependen de su sistema operativo y de las bibliotecas disponibles.
-mode <parámetro>
Pasa un parámetro al driver gráfico. En SVGAlib, es ancho*alto*profundidad, (donde la profundidad es 16, 256, 32K, 64K, 16M o 16M32) y define el modo gráfico, en X el formato es ANCHO*ALTO y define el tamaño de la ventana.
-display <pantalla x>
Establece la pantalla de ventana X.
-force-html
Trata los archivos con tipo desconocido como html en lugar de texto. (se puede alternar con la tecla '\')
-source <url>
Escribe el flujo de datos sin formato en la salida estándar.
-dump <url>
Escribe el documento formateado en la salida estándar.
-width <número>
Para dump, el documento se formateará con este ancho de pantalla (pero aún puede excederlo si las líneas no se pueden dividir).
-codepage <página de códigos>
Para dump, convierte la salida al conjunto de caracteres especificado, por ejemplo, iso-8859-2, windows-1250.
-anonymous
Restringe links para que se pueda ejecutar en una cuenta anónima. No navegación de archivos locales. No descargas. Se permite la ejecución de visores, pero el usuario no puede agregar ni modificar entradas en la tabla de asociaciones.
-no-connect
Ejecuta links como una instancia separada, en lugar de conectarse a una instancia existente.
-download-dir <ruta>
Directorio de descarga predeterminado. (predeterminado: directorio actual)
-language <idioma>
Establece el idioma de la interfaz de usuario.
-max-connections <máx>
Número máximo de conexiones concurrentes. (predeterminado: 10)
-max-connections-to-host <máx>
Número máximo de conexiones concurrentes a un host dado. (predeterminado: 2)
-retries <reintentos>
Número de reintentos. (predeterminado: 3)
-receive-timeout <seg>
Tiempo de espera en la recepción. (predeterminado: 120)
-unrestartable-receive-timeout <seg>
Tiempo de espera en conexiones no reiniciables. (predeterminado: 600)
-timeout-when-trying-multiple-addresses <seg>
Tiempo de espera para la conexión al intentar múltiples direcciones o al reanudar una conexión keepalive. (predeterminado: 3)
-bind-address <dirección IP o nombre de interfaz>
Utiliza una dirección IP local específica.
-bind-address-ipv6 <dirección IPv6 o nombre de interfaz>
Utiliza una dirección IPv6 local específica.
-no-libevent
No usar la biblioteca libevent.
-no-openmp
No usar OpenMP.
-download-utime <0>/<1>
Establece la hora de los archivos descargados a la hora de última modificación informada por el servidor.
-format-cache-size <num>
Número de páginas de documentos formateadas cacheadas. (predeterminado: 5)
-memory-cache-size <bytes>
Caché de memoria en bytes. (predeterminado: 1048576)
-image-cache-size <bytes>
Caché de memoria en bytes. (predeterminado: 1048576)
-font-cache-size <bytes>
Caché de memoria en bytes. (predeterminado: 2097152)
-aggressive-cache <0>/<1>
Caché de todo siempre, independientemente de las recomendaciones de caché del servidor. Muchos servidores niegan el caché incluso si su contenido no cambia solo para obtener más visitas y más dinero de publicidad.
-address-preference <0>/<1>/<2>/<3>/<4>
(predeterminado 0) 0 - usar predeterminado del sistema. 1 - preferir IPv4. 2 - preferir IPv6. 3 - usar solo IPv4. 4 - usar solo IPv6.
-http-proxy <host:puerto>
Host y número de puerto del proxy HTTP, o vacío. (predeterminado: vacío)
-ftp-proxy <host:puerto>
Host y número de puerto del proxy FTP, o vacío. (predeterminado: vacío)
-https-proxy <host:puerto>
Host y número de puerto del proxy HTTPS, o vacío. (predeterminado: vacío)
-socks-proxy <usuario@host:puerto>
Nombre de usuario, host y puerto de Socks4a, o vacío. (predeterminado: vacío)
-append-text-to-dns-lookups <texto>
Añade texto a las búsquedas DNS. Es útil para especificar un nodo de salida Tor fijo. (predeterminado: vacío)
-no-proxy-domains <dominio,dominio...>
No usar proxy para los dominios especificados. (predeterminado: vacío)

ref="#only_proxies">-only-proxies <0>/<1>
"1" hace que Links no inicie ninguna conexión no proxy. Es útil para anonimato con tor o redes similares.
-ssl.certificates <0>/<1>/<2>
(por defecto 1) 0 - ignora certificado inválido. 1 - advierte sobre certificado inválido. 2 - rechaza certificado inválido.
-ssl.builtin-certificates <0>/<1>
(por defecto 0; en DOS y OpenVMS por defecto 1) Usa certificados integrados en lugar de certificados del sistema.
-ssl.client-cert-key <nombre_archivo>
Nombre del archivo codificado en PEM con la clave privada del usuario para la autenticación de certificado de cliente.
-ssl.client-cert-crt <nombre_archivo>
Nombre del archivo codificado en PEM con el certificado del usuario para la autenticación de certificado de cliente.
-ssl.client-cert-password <texto>
Contraseña para la clave privada del usuario.
-async-dns <0>/<1>
Resolución DNS asíncrona activada(1)/desactivada(0).
-dns-over-https <url>
URL de DNS sobre HTTPS.
-http-bugs.http10 <0>/<1>
(por defecto 0) "1" fuerza el uso exclusivo del protocolo HTTP/1.0. (útil para servidores defectuosos que afirman ser compatibles con HTTP/1.1 pero no lo son) "0" permite usar ambos protocolos HTTP/1.0 y HTTP/1.1.
-http-bugs.allow-blacklist <0>/<1>
(por defecto 1) "1" usa por defecto una lista de servidores que tienen soporte HTTP/1.1 roto. Cuando Links encuentra un servidor así, reintentará la solicitud con HTTP/1.0.
-http-bugs.bug-no-accept-charset <0>/<1>
(por defecto 0) No envía el campo Accept-Charset de la cabecera HTTP. Debido a que es demasiado largo, algunos servidores rechazarán la solicitud. Otros servidores convertirán el contenido a texto plano ASCII cuando Accept-Charset esté ausente.
-http-bugs.no-compression <0>/<1>
(por defecto 0) "1" hace que Links no anuncie soporte de compresión HTTP (pero seguirá aceptando datos comprimidos). Úsalo cuando te comuniques con un servidor que tenga soporte de compresión defectuoso.
-http-bugs.retry-internal-errors <0>/<1>
(por defecto 0) Reintenta en caso de errores internos del servidor (50x).
-http.fake-firefox <0>/<1>
(por defecto 0) Finge que el navegador es Firefox en la cabecera HTTP.
-http.do-not-track <0>/<1>
(por defecto 0) Envía la solicitud "do not track" en la cabecera HTTP.
-http.referer <0>/<1>/<2>/<3>/<4>
(por defecto 0) 0 - no enviar referer. 1 - enviar la URL solicitada como referer. 2 - enviar referer falso. 3 - enviar referer real. 4 - enviar referer real solo al mismo servidor.
-http.fake-referer <cadena>
Valor falso del referer.
-http.fake-user-agent <cadena>
Valor falso del user agent.
-http.extra-header <cadena>
Cadena extra añadida a la cabecera HTTP.
-ftp.anonymous-password <cadena>
Contraseña para el acceso anónimo a ftp.
-ftp.use-passive <0>/<1>
Usa el comando ftp PASV para evitar firewalls.
-ftp.use-erpt-epsv <0>/<1>
Usa los comandos EPRT y EPSV en lugar de PORT y PASV.
-ftp.set-iptos <0>/<1>
Establece el Tipo de Servicio IP a alto rendimiento en las conexiones ftp.
-smb.allow-hyperlinks-to-smb <0>/<1>
Permite hipervínculos al protocolo SMB. Desactivar esto mejora la seguridad, ya que los sitios de Internet no pueden explotar posibles errores en el cliente SMB.
-menu-font-size <tamaño>
Tamaño de la fuente en el menú.
-menu-background-color 0xRRGGBB
Establece el color de fondo del menú en modo gráfico. RRGGBB son hexadecimales.
-menu-foreground-color 0xRRGGBB
Establece el color de primer plano del menú en modo gráfico. RRGGBB son hexadecimales.
-scroll-bar-area-color 0xRRGGBB
Establece el color del área de la barra de desplazamiento. RRGGBB son hexadecimales.
-scroll-bar-bar-color 0xRRGGBB
Establece el color de la barra de desplazamiento. RRGGBB son hexadecimales.
-scroll-bar-frame-color 0xRRGGBB
Establece el color del marco de la barra de desplazamiento. RRGGBB son hexadecimales.
-bookmarks-file <archivo>
Archivo para guardar los marcadores.
-bookmarks-codepage <página_de_códigos>
Juego de caracteres del archivo de marcadores.
-save-url-history <0>/<1>
Guarda el historial de URLs al salir.
-enable-cookies <0>/<1>
Habilita las cookies.
-save-cookies <0>/<1>
Guarda las cookies al salir.
-max-cookie-age <valor_fp>
Edad máxima de las cookies en días. 0 - ilimitado
-display-red-gamma <valor_fp>
Gamma roja de la pantalla. (por defecto 2.2)
-display-green-gamma <valor_fp>
Gamma verde de la pantalla. (por defecto 2.2)
-display-blue-gamma <valor_fp>
Gamma azul de la pantalla. (por defecto 2.2)
-user-gamma <valor_fp>
Gamma adicional. (por defecto 1)
-bfu-aspect <valor_fp>
Relación de aspecto de la pantalla.
-dither-letters <0>/<1>
Realiza difuminado de letras.
-dither-images <0>/<1>
Realiza difuminado de imágenes.
-display-optimize <0>/<1>/<2>
Optimiza para CRT (0), LCD RGB (1), LCD BGR (2).
-gamma-correction <0>/<1>/<2>
Tipo de corrección gamma: (por defecto 2) 0 - 8 bits (rápido). 1 - 16 bits (lento). 2 - detecta automáticamente según la velocidad de la FPU.
-overwrite-instead-of-scroll <0>/<1>
Sobrescribe la pantalla en lugar de desplazarla (válido para svgalib y framebuffer). Sobrescribir puede ser más rápido o no, dependiendo del hardware.
-font <archivo>
Archivo de fuente para texto normal.
-font-bold <archivo>
Archivo de fuente para texto en negrita.
-font-monospaced <archivo>
Archivo de fuente para texto monoespaciado.
-font-monospaced-bold <archivo>
Archivo de fuente para texto monoespaciado en negrita.
-font-italic <archivo>
Archivo de fuente para texto en cursiva.
-font-italic-bold <archivo>
Archivo de fuente para texto en cursiva y negrita.
-font-monospaced-italic <archivo>
Archivo de fuente para texto monoespaciado en cursiva.
-font-monospaced-italic-bold <archivo>
Archivo de fuente para texto monoespaciado en cursiva y negrita.
-html-assume-codepage <página de códigos>
Use la página de códigos dada cuando la página web no especificó su página de códigos. (predeterminado: ISO 8859-1)
-html-hard-assume <0>/<1>
Usar siempre el conjunto de caracteres de "-html-assume-codepage", sin importar lo que el servidor haya enviado.
-html-tables <0>/<1>
Renderizar tablas. (0) hace que las tablas se rendericen como en lynx.
-html-frames <0>/<1>
Renderizar marcos. (0) hace que los marcos se rendericen como en lynx.
-html-break-long-lines <0>/<1>
Dividir líneas largas en secciones <pre>.
-html-images <0>/<1>
Mostrar enlaces a imágenes sin nombre como [IMG]
-html-image-names <0>/<1>
Mostrar el nombre de archivo de una imagen en lugar de [IMG].
-html-display-images <0>/<1>
Mostrar imágenes en modo gráfico.
-html-image-scale <porcentaje>
Escalar imágenes en modo gráfico.
-html-bare-image-autoscale <0>/<1>
Ajustar automáticamente el tamaño de las imágenes mostradas a pantalla completa.
-html-numbered-links <0>/<1>
Numerar enlaces en modo texto. Permite la selección rápida de enlaces escribiendo el número del enlace y presionando enter.
-html-table-order <0>/<1>
En modo texto, recorrer la tabla por filas (0) o por columnas (1).
-html-auto-refresh <0>/<1>
Procesar la actualización a otra página (1), o mostrar un enlace a esa página (0).
-html-target-in-new-window <0>/<1>
Permitir abrir nuevas ventanas desde html.
-html-margin <número de espacios>
Margen en modo texto.
-html-user-font-size <tamaño>
Tamaño de fuente en las páginas en modo gráfico.
-html-text-color <0>-<15>
Color del texto en modo texto.
-html-link-color <0>-<15>
Color del enlace en modo texto.
-html-background-color <0>-<7>
Color de fondo en modo texto.
-html-ignore-document-color <0>/<1>
Ignorar los colores especificados en el documento html en modo texto.
-html-g-text-color 0xRRGGBB
Color del texto en modo gráfico.
-html-g-link-color 0xRRGGBB
Color del enlace en modo gráfico.
-html-g-background-color 0xRRGGBB
Color de fondo en modo gráfico.
-html-g-ignore-document-color <0>/<1>
Ignorar los colores especificados en el documento html en modo gráfico.

PLATAFORMAS

links funciona en Linux, FreeBSD, Solaris, IRIX, HPUX, Digital Unix, AIX, OS/2, BeOS y Win32.

ERRORES
