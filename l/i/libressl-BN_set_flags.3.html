libressl-BN_set_flags(3)

Paquete: libressl

Licencias: ISC, custom:OpenSSL

BN_SET_FLAGS(3) Manual de funciones de biblioteca BN_SET_FLAGS(3)

NOMBRE

BN_set_flags, BN_get_flags — habilitar e inspeccionar indicadores en objetos BIGNUM

SINOPSIS

biblioteca “libcrypto”
#include <openssl/bn.h>

void
BN_set_flags(BIGNUM *b, int flags);

int
BN_get_flags(const BIGNUM *b, int flags);

DESCRIPCIÓN

BN_set_flags() habilita los flags dados en b. El argumento flags puede contener cero o más de las siguientes constantes OR'eadas juntas:

BN_FLG_CONSTTIME
Si este indicador está establecido en el dividendo a o el divisor d en BN_div(3), en el exponente p en BN_mod_exp(3), o en el divisor a o el módulo n en BN_mod_inverse(3), estas funciones seleccionan algoritmos con un tiempo de ejecución independiente de los números respectivos, para evitar exponer información sensible a ataques de canal lateral de temporización.

Este indicador está deshabilitado por defecto para los objetos BIGNUM creados con BN_new(3).

BN_FLG_MALLOCED
Si este indicador está establecido, BN_free(3) y BN_clear_free(3) no solo limpiarán y liberarán los componentes de b, sino también b mismo. Este indicador es establecido internamente por BN_new(3). Establecerlo manualmente en un objeto BIGNUM existente suele ser una mala idea y puede causar llamadas a free(3) con argumentos incorrectos.
BN_FLG_STATIC_DATA
Si este indicador está establecido, BN_clear_free(3) no limpiará ni liberará la memoria utilizada para almacenar el número. En consecuencia, establecerlo manualmente en un objeto BIGNUM existente suele ser una idea terrible que puede causar tanto la divulgación de datos secretos como fugas de memoria. Este indicador se establece automáticamente en el objeto BIGNUM constante devuelto por BN_value_one(3).

BN_get_flags() interpreta flags como una máscara de bits y devuelve aquellos de los indicadores dados que están establecidos en b, OR'eados juntos, o 0 si ninguno de los flags dados está establecido. El argumento flags tiene la misma sintaxis que para BN_set_flags().

VALORES DE RETORNO

BN_get_flags() devuelve cero o más de las constantes anteriores, OR'eadas juntas.

VER TAMBIÉN

BN_mod_exp(3), BN_mod_inverse(3), BN_new(3), BN_with_flags(3)

HISTORIA

BN_set_flags() y BN_get_flags() aparecieron por primera vez en SSLeay 0.9.1 y han estado disponibles desde OpenBSD 2.6.

ADVERTENCIAS

No existe una interfaz pública para borrar un indicador una vez que está establecido. Así que piense dos veces antes de usar BN_set_flags().

ERRORES

Incluso si el indicador BN_FLG_CONSTTIME está establecido en a o b, BN_gcd() ni falla ni opera en tiempo constante, potencialmente permitiendo ataques de canal lateral de temporización.

Incluso si el indicador BN_FLG_CONSTTIME está establecido en p, si el módulo m es par, BN_mod_exp(3) no opera en tiempo constante, potencialmente permitiendo ataques de canal lateral de temporización.

Si BN_FLG_CONSTTIME está establecido en p, BN_exp() falla en lugar de operar en tiempo constante.
