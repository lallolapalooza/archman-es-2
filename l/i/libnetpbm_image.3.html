NOMBRE

libnetpbm_image - descripción general de las funciones de procesamiento de imágenes de netpbm

DESCRIPCIÓN

Este manual de referencia cubre las funciones de la biblioteca libnetpbm para el procesamiento de imágenes, utilizando los formatos de imagen Netpbm y los formatos de imagen en memoria de libnetpbm.

Por razones históricas y para evitar desorden, no cubre las clases de funciones de libnetpbm en gran parte obsoletas PBM, PGM, PPM y PNM. Para ellas, consulte el Manual de Funciones de PBM (3), Manual de Funciones de PGM(3), Manual de Funciones de PPM(3) y Manual de Funciones de PNM(3) . Necesitará esas funciones para procesar imágenes PBM, PGM, PPM y PNM. Las funciones de este manual son suficientes para ello.

Las funciones de dibujo PPM se cubren por separado en el Manual de Funciones de Dibujo de PPM(1)

Para obtener información introductoria y general sobre el uso de libnetpbm, consulte la Guía del Usuario de Libnetpbm

libnetpbm también contiene funciones que no están específicamente orientadas al procesamiento de datos de imágenes. Lea sobre ellas en el Manual de Utilidades de Libnetpbm

Para utilizar estos servicios, incluya pam.h.

Tipos

Aquí hay algunos tipos importantes que se utilizan con libnetpbm:

muestra
Una muestra de una imagen Netpbm. Consulte las especificaciones del formato: como ejemplo, la intensidad roja de un píxel particular de una imagen PPM es una muestra. Este es un tipo entero.
tupla
Una tupla de una imagen PAM o el equivalente PAM de una imagen PNM. Consulte la especificación del formato PAM: como ejemplo, un píxel de una imagen PPM sería una tupla. Una tupla es una matriz de muestras.
muestran
Lo mismo que muestra, excepto en forma normalizada. Este es un tipo de punto flotante con un valor en el rango 0..1. 0 corresponde a un valor de muestra PAM/PNM de 0. 1 corresponde a un valor de muestra PAM/PNM igual al maxval de la imagen.
Lo mismo que tupla, excepto que está compuesta por muestras normalizadas (muestran) en lugar de muestras regulares (muestra).

struct pam

El argumento principal de la mayoría de las funciones PAM es la dirección de una estructura pam, que se define de la siguiente manera:

  
    struct pam {
        int tamaño
        int longitud
        FILE *archivo   
        int formato
        int formatoplano
        int alto
        int ancho
        int profundidad
        muestra maxval
        int bytes_por_muestra
        char tipotupla[256]
        int profundidadallocacion
        char **comentario_p;
    }

Consulte La Guía del Usuario de Libnetbm para obtener información sobre la estructura pam.

Macros

PNM_MAXMAXVAL es el maxval máximo que históricamente pudieron tener las imágenes Netpbm: 255. Muchos programas no son capaces de manejar imágenes Netpbm con un maxval mayor que este. Se llama así por compatibilidad con versiones anteriores: tenía este nombre cuando era *el* maxval máximo.

PNM_OVERALLMAXVAL es el maxval máximo que pueden tener las imágenes Netpbm hoy en día (65535).

PBM_FORMAT, RPBM_FORMAT, PGM_FORMAT, RPGM_FORMAT, PPM_FORMAT, RPPM_FORMAT y PAM_FORMAT son los códigos de formato de los diversos formatos Netpbm. RPBM_FORMAT es el formato PBM crudo y PBM_FORMAT es el formato PBM plano, y así sucesivamente. Consulte el miembro formato de la estructura pam.

PAM_FORMAT_TYPE(formato) obtiene el tipo de un formato, dado el código de formato. Los tipos de formatos son PBM, PGM, PPM y PAM, y los macros para los códigos de tipo son, respectivamente, PBM_TYPE, PGM_TYPE, PPM_TYPE y PAM_TYPE. Tenga en cuenta que hay más códigos de formato que tipos de formato porque existen diferentes códigos de formato para los subformatos planos y crudos de cada formato.

Descripción

pnm_allocpamarray() asigna espacio para una matriz de tuplas. pnm_freepamarray() libera el espacio de la matriz asignado por pnm_allocpamarray() o pnm_readpam().

pnm_allocpamrow() asigna espacio para una fila de una imagen PAM, en forma básica. pnm_freepamrow() la libera.

pnm_allocpamrown() es lo mismo que pnm_allocpamrow() excepto que asigna espacio para una fila PAM en forma normalizada. pnm_freepamrown() es de manera similar a pnm_freepamrow.

NAME

libnetpbm_image - image manipulation functions

DESCRIPTION

This manual page describes functions for manipulating the pixels in a Netpbm image. These functions typically operate on one row of pixels at a time.

Types

The Netpbm image format uses the concept of a tuple to represent a pixel. A tuple is a sequence of sample values. For example, an RGB pixel has 3 samples: Red, Green, and Blue. A grayscale image has 1 sample. The samples are stored as unsigned integers.

An image may have an opacity plane. This is an extra sample value that determines how opaque the pixel is. For example, an RGB pixel with an opacity plane would have 4 samples: Red, Green, Blue, and Alpha (opacity). The opacity value ranges from 0 (fully transparent) to 1 (fully opaque).

The tuple type identifies the samples in a tuple. For example, RGB_ALPHA indicates that a tuple contains Red, Green, Blue, and Alpha samples. GRAYSCALE_ALPHA indicates a single grayscale sample followed by an Alpha sample.

Macros

The following macros operate on a single tuple:

pnm_applyopacityrown( struct pam *pamP, const tuple src, tuple dst);
Reduces the intensity of the samples in src according to the opacity plane and stores the result in dst. This function is used when preparing an image for composition with another image. If the image does not have an opacity plane, dst is a copy of src.
pnm_unapplyopacityrown( struct pam *pamP, const tuple src, tuple dst);
Reverses the operation of pnm_applyopacityrown(). It assumes that the intensities in src have already been reduced by the opacity plane and restores them to their original values. This function is used after image composition is complete.
pnm_normalizetuple( const struct pam *pamP, const tuple src, const double *dst);
Converts the sample values in src from the image's native integer format to floating-point values in the range 0.0 to 1.0. This is done by dividing each sample value by the image's maximum sample value (maxval).
pnm_unnormalizetuple( const struct pam *pamP, const double *src, tuple dst);
Reverses the operation of pnm_normalizetuple(). It converts floating-point sample values in src (assumed to be in the range 0.0 to 1.0) back to the image's native integer format by multiplying each value by the image's maxval.

Functions

The following functions operate on an entire row of pixels:

void pnm_applyopacityrown( struct pam *pamP, const tuple src, tuple dst);
This function prepares an image row for composition. If the image has an opacity plane (e.g., tuple type RGB_ALPHA or GRAYSCALE_ALPHA), it reduces the intensity of each sample in the row according to the opacity value. For example, if a pixel is 50% opaque, its sample values are halved. If the image does not have an opacity plane, the function does nothing (equivalent to 100% opacity).
void pnm_unapplyopacityrown( struct pam *pamP, const tuple src, tuple dst);
This function reverses the effect of pnm_applyopacityrown(). It assumes that the sample intensities in the input row src have already been reduced by an opacity plane and restores them to their original values, storing the result in dst. This is typically done after an image composition operation.
void pnm_normalizeRow( const struct pam *pamP, const tuple src, pnm_transformMap *transform, double *dst);
This function normalizes a row of pixels. It converts the sample values from the image's native integer format to floating-point values in the range 0.0 to 1.0. Additionally, it can apply a transformation function specified by transform. If transform is NULL, only normalization occurs. This function is often used with gamma correction functions (e.g., created by pnm_createungammatransform()) to work with intensity-proportional sample values.
void pnm_unnormalizeRow( const struct pam *pamP, const double *src, pnm_transformMap *transform, tuple dst);
This function reverses the operation of pnm_normalizeRow(). It converts normalized floating-point sample values in src back to the image's native integer format and can optionally apply a reverse transformation (e.g., gamma correction). If transform is NULL, only unnormalization occurs.
pnm_transformMap * pnm_createungammatransform( const struct pam *pamP);
Creates a pnm_transformMap object that describes the inverse gamma correction (ITU-R Recommendation BT.709) typically used in visual Netpbm images. This object is used with pnm_normalizeRow() to convert from gamma-adjusted sample values to intensity-proportional ones.
pnm_transformMap * pnm_creategammatransform( const struct pam *pamP);
Creates a pnm_transformMap object that describes the gamma correction (ITU-R Recommendation BT.709) typically used in visual Netpbm images. This object is used with pnm_unnormalizeRow() to convert from intensity-proportional sample values back to gamma-adjusted ones.
void pnm_freegammatransform( pnm_transformMap *transformP);
Frees the memory allocated for a gamma transform map created by pnm_creategammatransform().
void pnm_freeungammatransform( pnm_transformMap *transformP);
Frees the memory allocated for an inverse gamma transform map created by pnm_createungammatransform().
void pnm_checkpam( struct pam *pamP, const enum pm_check_type check_type, enum pm_check_code *retvalP);
Checks for common file integrity errors, such as the file being the wrong size for the raster dimensions specified in the header.
void pnm_nextimage( FILE *file, int * const eofP);
Positions the input file stream to the beginning of the next Netpbm image. A subsequent call to pnm_readpaminit() will read the header for this next image.

pnm_applyopacityrown() and pnm_unapplyopacityrown() work on normalized, intensity-proportional tuples. This means you typically read the row, gamma-correct it using pnm_ungammarown() (which is a convenience function that internally calls pnm_normalizeRow() with a gamma transform), then apply pnm_applyopacityrown(). After manipulations, you would call pnm_unapplyopacityrown(), then gamma-correct back using pnm_gammarown() (which internally calls pnm_unnormalizeRow() with a gamma transform), and finally write the row.

pnm_applyopacityrown() and pnm_unapplyopacityrown() were new in Netpbm 10.25 (October 2004).

pnm_normalizeRow() and pnm_unnormalizeRow() work on an entire tuple row. They convert between the image's native integer format and floating-point values in the range 0.0 to 1.0. They also allow an optional transformation function to be applied, which is often a gamma transform. Combining normalization and transformation in a single function call is usually significantly faster than doing them separately, as it allows for optimizations like using lookup tables.

If no transformation is needed, pass NULL for the transform argument.

Here is an example of composing two images using these functions:

    struct pam pam1, pam2, pamout;
    tuple row1, row2, outrow;
    double *normrow1, *normrow2, *normoutrow;
    pnm_transformMap *transform1, *transform2, *transformOut;
    int col;

    /* ... initialize pam1, pam2, pamout and read headers ... */

    transform1 = pnm_createungammatransform(&pam1);
    transform2 = pnm_createungammatransform(&pam2);
    transformOut = pnm_creategammatransform(&pamout);

    pnm_readpamrow(&pam1, row1);
    pnm_readpamrow(&pam2, row2);

    normrow1 = malloc(pam1.width * sizeof(double));
    normrow2 = malloc(pam2.width * sizeof(double));
    normoutrow = malloc(pamout.width * sizeof(double));

    pnm_normalizeRow(&pam1, row1, transform1, normrow1);
    pnm_normalizeRow(&pam2, row2, transform2, normrow2);

    /* Example: average the two normalized rows */
    for (col = 0; col < pamout.width; ++col) {
        normoutrow[col] = (normrow1[col] + normrow2[col]) / 2.0;
    }

    pnm_unnormalizeRow(&pamout, normoutrow, transformOut, outrow);
    pnm_writepamrow(&pamout, outrow);

    /* ... free memory and handle subsequent rows ... */

    free(normrow1);
    free(normrow2);
    free(normoutrow);
    pnm_freeungammatransform(transform1);
    pnm_freeungammatransform(transform2);
    pnm_freegammatransform(transformOut);
