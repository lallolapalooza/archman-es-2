Paquete: libressl

Licencias: ISC, custom:OpenSSL

OCSP_REQUEST_ADD1_NONCE(3) Manual de funciones de biblioteca OCSP_REQUEST_ADD1_NONCE(3)

NOMBRE

OCSP_request_add1_nonce, OCSP_basic_add1_nonce, OCSP_check_nonce, OCSP_copy_nonce — funciones OCSP nonce

SINOPSIS

biblioteca “libcrypto”
#include <openssl/ocsp.h>

int
OCSP_request_add1_nonce(OCSP_REQUEST *req, unsigned char *val, int len);

int
OCSP_basic_add1_nonce(OCSP_BASICRESP *resp, unsigned char *val, int len);

int
OCSP_check_nonce(OCSP_REQUEST *req, OCSP_BASICRESP *resp);

int
OCSP_copy_nonce(OCSP_BASICRESP *resp, OCSP_REQUEST *req);

DESCRIPCIÓN

Un nonce OCSP se añade normalmente a una solicitud OCSP para evitar ataques de repetición comprobando que el mismo valor de nonce aparece en la respuesta.

OCSP_request_add1_nonce() añade un nonce de valor val y longitud len a la solicitud OCSP req. Si val es NULL, se usa un nonce aleatorio. Si len es cero o negativo, se usará una longitud predeterminada (actualmente 16 bytes). Para la mayoría de los propósitos, el valor del nonce en una solicitud se establece en un valor aleatorio, por lo que el parámetro val en OCSP_request_add1_nonce() suele ser NULL.

OCSP_basic_add1_nonce() es idéntico a OCSP_request_add1_nonce() excepto que añade un nonce a la respuesta básica OCSP resp.

OCSP_check_nonce() compara el valor del nonce en req y resp.

OCSP_copy_nonce() copia cualquier valor de nonce presente en req a resp.

Algunos respondedores pueden incluir un nonce en todas las respuestas, incluso si no se proporciona uno.

Algunos respondedores almacenan en caché las respuestas OCSP y no firman cada respuesta por razones de rendimiento. Como resultado, no admiten nonces.

VALORES DE RETORNO

OCSP_request_add1_nonce() y OCSP_basic_add1_nonce() devuelven 1 para éxito o 0 para fallo.

OCSP_copy_nonce() devuelve 1 si se copió un nonce con éxito, 2 si no había ningún nonce presente en req, o 0 si se produjo un error.

OCSP_check_nonce() devuelve valores positivos para éxito: 1 si los nonces están presentes e iguales, 2 si ambos nonces están ausentes, o 3 si solo hay un nonce presente en la respuesta. Un valor de retorno cero indica que ambos nonces están presentes pero no coinciden: esto debe tratarse como una condición de error. Un valor de retorno de -1 indica que solo hay un nonce presente en la solicitud: esto ocurrirá si el respondedor no admite nonces.
