DESCRIPCIÓN

ASN1_mbstring_copy() interpreta inbytes bytes a partir de in como una cadena multibyte y la copia en *out, cambiando opcionalmente la codificación. Si el argumento inbytes es negativo, se utiliza en su lugar la longitud de in devuelta por strlen(3).

El argumento inform especifica la codificación de caracteres de in:

inform codificación
MBSTRING_ASC ISO-Latin-1
MBSTRING_BMP UTF-16
MBSTRING_UNIV UTF-32
MBSTRING_UTF8 UTF-8

La máscara de bits mask especifica un conjunto de tipos de cadenas ASN.1 que el usuario está dispuesto a aceptar:

bit en mask tipo de salida aceptable por defecto
B_ASN1_PRINTABLESTRING ASN1_PRINTABLESTRING sí
B_ASN1_IA5STRING ASN1_IA5STRING no
B_ASN1_T61STRING ASN1_T61STRING sí
B_ASN1_BMPSTRING ASN1_BMPSTRING sí
B_ASN1_UNIVERSALSTRING ASN1_UNIVERSALSTRING no
cualquier otro bit ASN1_UTF8STRING sí

El primer tipo de la tabla anterior que se incluye en el argumento mask y que puede representar in se utiliza como tipo de salida. La columna "por defecto" indica si el tipo se considera aceptable si el argumento mask tiene el valor especial 0.

Las siguientes constantes de máscara de bits incluyen cada una varios de los bits enumerados anteriormente:

constante de máscara PRI IA5 T61 BMP UNI UTF8
B_ASN1_DIRECTORYSTRING sí no sí sí sí sí
DIRSTRING_TYPE sí no sí sí no sí
PKCS9STRING_TYPE sí sí sí sí no sí

Si out es NULL, se validan inform, inbytes y in, se determina el tipo de salida y se devuelve, pero no se copia nada.

De lo contrario, si *out es NULL, se asigna un nuevo objeto de salida del tipo de salida y se almacena un puntero a él en *out.

De lo contrario, se utiliza **out como objeto de salida. Cualquier dato almacenado previamente en él se libera y su tipo se cambia al tipo de salida.

Finalmente, in se copia en el objeto de salida, cambiando la codificación de caracteres si inform no coincide con la codificación utilizada por el tipo de salida.

ASN1_mbstring_ncopy() es similar excepto en que el número de caracteres en in se restringe al rango de minchars a maxchars, ambos inclusive. Si maxchars es 0, no se aplica ningún límite superior al número de caracteres.

ASN1_STRING_set_by_NID() es similar con las siguientes diferencias:

  • Si out es NULL, se asigna un nuevo objeto de salida y se devuelve en lugar de omitir la copia.
  • Si nid tiene una entrada de tabla de cadenas global que se puede recuperar con ASN1_STRING_TABLE_get(3), mask, minchars y maxchars se toman de esa entrada de tabla de cadenas. Para algunos valores de nid, una máscara global adicional se aplica mediante AND a la máscara antes de usarla. El valor predeterminado de la máscara global es B_ASN1_UTF8STRING.
  • Si nid no tiene una entrada de tabla de cadenas global, se utiliza B_ASN1_PRINTABLESTRING | B_ASN1_T61STRING | B_ASN1_BMPSTRING | B_ASN1_UTF8STRING en lugar de la máscara tomada de la tabla, y la máscara global también se aplica mediante AND a ella.
  • Aunque el éxito y el fracaso ocurren en las mismas situaciones, el valor de retorno es diferente.

libressl(3) - ASN1_mbstring_copy

NAME

ASN1_mbstring_copy, ASN1_mbstring_ncopy, ASN1_STRING_set_by_NID, ASN1_STRING_set_default_mask, ASN1_STRING_set_default_mask_asc, ASN1_STRING_get_default_mask, ASN1_tag2bit - ASN.1 string manipulation.

SYNOPSIS

 #include <openssl/asn1.h>

 int
-ASN1_mbstring_copy(ASN1_STRING *dst,
     const unsigned char *src, int len,
     int type, unsigned int mask);

 int
-ASN1_mbstring_ncopy(ASN1_STRING *dst,
     const unsigned char *src, int len,
     int type, unsigned int mask);

 int
-ASN1_STRING_set_by_NID(ASN1_STRING *dst,
     const uchar *src, int len,
     int type, unsigned int mask);

 unsigned int
-ASN1_STRING_set_default_mask(unsigned int mask,
     unsigned int bit);

 int
-ASN1_STRING_set_default_mask_asc(const char *str);

 unsigned int
-ASN1_STRING_get_default_mask(void);

 int
-ASN1_tag2bit(int tag);

DESCRIPTION

These functions are related to the manipulation of ASN.1 strings. They are primarily used internally by OpenSSL but can be useful in other contexts as well. The functions handle the conversion of various character set strings into ASN.1 structures, often performing character set validation and conversion.

ASN1_mbstring_copy() and ASN1_mbstring_ncopy() copy a string of length len from src to dst. The type parameter specifies the desired ASN.1 string type (e.g., V_ASN1_UTF8, V_ASN1_PRINTABLE). The mask parameter controls character validation and conversion rules.

ASN1_STRING_set_by_NID() is similar to ASN1_mbstring_copy() but uses an ASN.1 NID (Numeric Identification) to determine the string type.

ASN1_STRING_set_default_mask() and ASN1_STRING_set_default_mask_asc() are used to set a default mask for ASN.1 string operations. The _asc variant parses a string representation of the mask.

ASN1_STRING_get_default_mask() retrieves the currently set default mask.

ASN1_tag2bit() converts an ASN.1 tag into a bit value, typically used for flag manipulation.

RETURN VALUES

The ASN1_* functions generally return 1 on success and 0 on failure. Specific error codes might be set in errno or available through OpenSSL's error reporting mechanism.

SEE ALSO

ASN1_STRING(3).

HISTORY

ASN1_mbstring_copy(), ASN1_mbstring_ncopy(), ASN1_STRING_set_by_NID(), ASN1_STRING_set_default_mask(), ASN1_STRING_set_default_mask_asc(), and ASN1_STRING_get_default_mask() first appeared in OpenSSL 0.9.5 and have been available since OpenBSD 2.7.

ASN1_tag2bit() first appeared in OpenSSL 0.9.7 and has been available since OpenBSD 3.2.

BUGS

If integer overflow occurs in ASN1_STRING_set_default_mask_asc() while parsing a number following "MASK:", the function succeeds, essentially behaving in the same way as for "default".

Passing "default" to ASN1_STRING_set_default_mask_asc() does not restore the default mask. Instead, passing "utf8only" does that.
