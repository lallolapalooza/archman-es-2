int alpm_sandbox_setup_child (alpm_handle_t * handle, const char * sandboxuser, const char * sandbox_path)

Reduce privilegios cambiando a un usuario diferente.

Parámetros

handle el manejador de contexto
sandboxuser el usuario al que cambiar
sandbox_path si no es NULL, restringe las escrituras a esta ruta del sistema de archivos

Devuelve

0 en caso de éxito, -1 en caso de fallo

alpm_pkg_t * alpm_sync_get_new_version (alpm_pkg_t * pkg, alpm_list_t * dbs_sync)

Comprueba si hay una nueva versión de pkg en syncdbs. Si el mismo paquete aparece en múltiples bases de datos, solo se comprobará la primera.

Esto solo comprueba la syncdb en busca de una versión más reciente. No accede a la red en absoluto. Consulte alpm_db_update para actualizar una base de datos.

int alpm_unlock (alpm_handle_t * handle)

Elimina el archivo de bloqueo de la base de datos.

Parámetros

handle el manejador de contexto

Devuelve

0 en caso de éxito, -1 en caso de error

Nota

Es seguro llamar desde dentro de manejadores de señales.
