DESCRIPCIÓN

La biblioteca libstatgrab proporciona una interfaz multiplataforma para obtener varias estadísticas del sistema. Las estadísticas del sistema no están estandarizadas, por lo que la biblioteca statgrab intenta elegir los valores más importantes en todos los sistemas operativos compatibles. Esto implica que algunos valores podrían no estar disponibles en todos los sistemas operativos, mientras que algunos valores específicos faltan cuando no hay contrapartes en ningún otro sistema operativo.

La libstatgrab está organizada en componentes, cada uno para estadísticas interrelacionadas.

componente estadísticas
cpu sg_cpu_stats, sg_cpu_percents
disk sg_disk_io_stats, sg_fs_stats
load sg_load_stats
mem sg_mem_stats
network sg_network_io_stats, sg_network_iface_stats
os sg_host_info
page sg_page_stats
process sg_process_stats, sg_process_count
swap sg_swap_stats
user sg_user_stats

The library is thread-safe. All functions that return pointers to dynamically allocated memory should be free’d using their respective free functions. All functions that return pointers to static memory should not be free’d.

All functions can fail. If a function fails, it will return an error code which can be checked with the sg_error enumeration. The error code can be converted to a human-readable string using sg_str_error(). If an error code is returned, the system call that failed is returned in errno. If the error code is not related to a system call, errno is set to 0.

The functions ending with R return values that are stored in static memory. This makes them not thread-safe.

NAME

libstatgrab — system statistics retrieval library

SYNOPSIS

#include <statgrab.h>

DESCRIPTION

sg_intro(3) provides an overview of the library. The library provides functions for retrieving system statistics.

The following table lists the functions available in the library:

Category Functions
CPU sg_get_cpu_stats
Disk I/O sg_get_disk_io_stats
File system sg_get_fs_stats
Host sg_get_host_info
Load sg_get_load_stats
Memory sg_get_mem_stats
Network I/O sg_get_network_io_stats
Network interface sg_get_network_iface_stats
Page sg_page_stats
Process sg_process_stats, sg_process_count
Swap sg_swap_stats
User sg_user_stats

The library was originally written to support the i-scream central monitoring system, but has since become a standalone package. It has been ported to work on Linux, NetBSD, FreeBSD, OpenBSD, DragonFly BSD, Solaris, HP-UX, AIX and Cygwin.
