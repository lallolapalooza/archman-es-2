libressl-SSL_CTX_set_info_callback(3)

Paquete: libressl

Licencias: ISC, custom:OpenSSL

SSL_CTX_SET_INFO_CALLBACK(3) Manual de funciones de biblioteca SSL_CTX_SET_INFO_CALLBACK(3)

NOMBRE

SSL_CTX_set_info_callback, SSL_CTX_get_info_callback, SSL_set_info_callback, SSL_get_info_callback — manejar la devolución de llamada de información para conexiones SSL

SINOPSIS

biblioteca “libssl” libcrypto
#include <openssl/ssl.h>

void
SSL_CTX_set_info_callback(SSL_CTX *ctx, void (*callback)(const SSL *ssl, int where, int ret));

void
(*SSL_CTX_get_info_callback(const SSL_CTX *ctx))(const SSL *ssl, int where, int ret);

void
SSL_set_info_callback(SSL *ssl, void (*callback)(const SSL *ssl, int where, int ret));

void
(*SSL_get_info_callback(const SSL *ssl))(const SSL *ssl, int where, int ret);

DESCRIPCIÓN

SSL_CTX_set_info_callback() establece la función de devolución de llamada que se puede utilizar para obtener información de estado para objetos SSL creados a partir de ctx durante la configuración y el uso de la conexión. La configuración para ctx se anula por la configuración para un objeto SSL específico, si se especifica. Cuando devolución de llamada es NULL, no se utiliza ninguna función de devolución de llamada.

SSL_set_info_callback() establece la función de devolución de llamada que se puede utilizar para obtener información de estado para ssl durante la configuración y el uso de la conexión. Cuando devolución de llamada es NULL, se utiliza la configuración de devolución de llamada actualmente válida para ctx.

SSL_CTX_get_info_callback() devuelve un puntero a la función de devolución de llamada de información actualmente establecida para ctx.

SSL_get_info_callback() devuelve un puntero a la función de devolución de llamada de información actualmente establecida para ssl.

Al configurar una conexión y durante su uso, es posible obtener información de estado del motor SSL/TLS. Cuando se establece, se llama a una función de devolución de llamada de información siempre que cambia el estado, aparece una alerta o ocurre un error.

Se llama a la función de devolución de llamada como callback(SSL *ssl, int where, int ret). El argumento where especifica información sobre dónde (en qué contexto) se llamó a la función de devolución de llamada. Si ret es 0, ocurrió una condición de error. Si se maneja una alerta, se establece SSL_CB_ALERT y ret especifica la información de la alerta.

where es una máscara de bits formada por los siguientes bits:

SSL_CB_LOOP
Se llamó a la devolución de llamada para indicar un cambio de estado dentro de un bucle.
SSL_CB_EXIT
Se llamó a la devolución de llamada para indicar la salida de error de una función de handshake. (Puede ser un error leve con opción de reintento para configuraciones no bloqueantes).
SSL_CB_READ
Se llamó a la devolución de llamada durante la operación de lectura.
SSL_CB_WRITE
Se llamó a la devolución de llamada durante la operación de escritura.
SSL_CB_ALERT
Se llamó a la devolución de llamada debido a que se envió o recibió una alerta.
SSL_CB_READ_ALERT
 
SSL_CB_WRITE_ALERT
 
SSL_CB_ACCEPT_LOOP
 
SSL_CB_ACCEPT_EXIT
 
SSL_CB_CONNECT_LOOP
 
SSL_CB_CONNECT_EXIT
 
SSL_CB_HANDSHAKE_START
Se llamó a la devolución de llamada porque se inició un nuevo handshake.
SSL_CB_HANDSHAKE_DONE
Se llamó a la devolución de llamada porque finalizó un handshake.

La información de estado actual se puede obtener utilizando la familia de funciones SSL_state_string(3).

La información ret se puede evaluar utilizando la familia de funciones SSL_alert_type_string(3).

VALORES DE RETORNO

SSL_CTX_get_info_callback() y SSL_get_info_callback() devuelven un puntero a la devolución de llamada actual o NULL si no hay ninguna establecida.

EJEMPLOS

La siguiente función de devolución de llamada de ejemplo imprime cadenas de estado, información sobre las alertas que se están manejando y mensajes de error en el bio_err BIO.

void
apps_ssl_info_callback(SSL *s, int where, int ret)
{
	const char *str;
	int w;

	w = where & ~SSL_ST_MASK;

	if (w & SSL_ST_CONNECT)
		str = "SSL_connect";
	else if (w & SSL_ST_ACCEPT)
		str = "SSL_accept";
	else
		str = "undefined";

	if (where & SSL_CB_LOOP) {
		BIO_printf(bio_err, "%s:%s\n", str,
		    SSL_state_string_long(s));
	} else if (where & SSL_CB_ALERT) {
		str = (where & SSL_CB_READ) ? "read" : "write";
		BIO_printf(bio_err, "SSL3 alert %s:%s:%s\n", str,
			SSL_alert_type_string_long(ret),
			SSL_alert_desc_string_long(ret));
	} else if (where & SSL_CB_EXIT) {
		if (ret == 0)
			BIO_printf(bio_err, "%s:failed in %s\n",
				str, SSL_state_string_long(s));
		else if (ret < 0) {
			BIO_printf(bio_err, "%s:error in %s\n",
				str, SSL_state_string_long(s));
		}
	}
}
