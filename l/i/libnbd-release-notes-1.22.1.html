NOMBRE

libnbd-release-notes-1.22 - notas de la versión de libnbd 1.22

DESCRIPCIÓN

Estas son las notas de la versión estable 1.22 de libnbd. Se describen los principales cambios desde la 1.20.

libnbd 1.22.0 fue lanzada el 11 de febrero de 2025.

Seguridad

Se encontraron y corrigieron múltiples fallos en la verificación de certificados de servidor TLS (CVE-2024-7383). Ver https://lists.libguestfs.org/archives/list/guestfs@lists.libguestfs.org/thread/LHR3BW6RJ7K4BJBQIYV3GTZLSY27VZO2/ (gracias a Jon Szymaniak, Daniel P. Berrangé).

Si encuentra un problema de seguridad, lea SECURITY en el código fuente (en línea aquí: https://gitlab.com/nbdkit/libnbd/blob/master/SECURITY). Para conocer problemas de seguridad anteriores en libnbd, consulte libnbd-security(3).

Nuevas APIs

nbd_set_tls_hostname(3) y nbd_get_tls_hostname(3) pueden usarse para establecer y obtener el nombre de host utilizado para la verificación del certificado del servidor TLS. Este nombre de host, si se establece, se utiliza con preferencia al nombre de host del servidor. Esto puede usarse cuando las conexiones NBD se conectan a través de un proxy o se transportan a través de un socket de dominio Unix.

nbd_is_uri(3) aplica una heurística para detectar si algo es probablemente una URI NBD o no.

nbd_get_subprocess_pid(3) devuelve el ID de proceso (PID) del subproceso creado por funciones como nbd_connect_command(3).

Mejoras en APIs existentes

Como extensión de nbd_connect_uri(3), ahora puede conectarse a URIs "nbd+ssh://" o "nbds+ssh://", creando un túnel NBD sobre una conexión SSH. Esto es muy conveniente cuando tiene acceso SSH a un host remoto, pero un firewall impide el acceso directo a los puertos NBD.

Protocolo

Ahora imprimimos el mensaje de error completo si el servidor envía uno. nbdkit ≥ 1.42 enviará mensajes de error completos desde los plugins a través de la conexión NBD a clientes NBD compatibles como libnbd 1.22 o qemu.

Herramientas

Se corrigió nbdfuse(1) para que las URIs TLS que usan "?tls-certificates" o "?tls-psk-file" ahora funcionen correctamente (Jon Szymaniak).

nbddump(1) tiene una nueva opción --offset (Eric Blake).

Bindings de lenguaje

Varias correcciones a los bindings de Rust (gracias a Hanna Czenczek).

La documentación incluida en los bindings de Rust ha mejorado considerablemente.

Otras mejoras y correcciones de errores

Ahora se utiliza código común para obtener el tamaño de los dispositivos de bloque, y esto se ha corregido para que funcione correctamente en BSD. Esto afectó al menos a nbdcopy cuando se usaba para copiar hacia y desde dispositivos de bloque en BSD.

Documentación

Se corrigieron los enlaces a nbd-server(1) y otras páginas en la documentación generada en HTML (Vera Wu).

En nbd_connect_uri(3) documentamos pequeñas diferencias en la forma en que analizamos las URIs NBD en comparación con qemu.

nbd_connect_uri(3) añade documentación adicional sobre los números de puerto VSock reservados.

Compilación

Ahora se requiere gnutls ≥ 3.5.18. Esto coincide con la versión necesaria por qemu. Si se usa RHEL, esto significa que ahora se requiere RHEL ≥ 8.

libnbd debería compilar ahora en macOS.

examples/connect-benchmark es un nuevo ejemplo que puede usarse para medir el rendimiento de las conexiones.

Se añadió soporte para GCC 15.
