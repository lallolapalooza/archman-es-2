NOMBRE

libpipewire-module-metadata - Metadatos

DESCRIPCIÓN

Permite a los clientes exportar un almacén de metadatos al servidor PipeWire.

Tanto el cliente como el servidor necesitan cargar este módulo para que los metadatos se exporten.

Este módulo crea una nueva factoría y un nuevo tipo de exportación para la interfaz PW_TYPE_INTERFACE_Metadata.

Un cliente primero creará una implementación de la interfaz PW_TYPE_INTERFACE_Metadata con pw_context_create_metadata(), por ejemplo. Con pw_core_export(), este módulo creará un recurso del lado del servidor para exponer la implementación de metadatos a otros clientes. Las modificaciones realizadas por el cliente en la interfaz de metadatos local serán visibles para todos los clientes de PipeWire.

También es posible utilizar la factoría para crear metadatos en los procesos actuales utilizando un fragmento de archivo de configuración.

Como argumento para la llamada a create_object, un conjunto de propiedades controlará el nombre de los metadatos y algunos valores iniciales.

NOMBRE DEL MÓDULO

libpipewire-module-metadata

OPCIONES DEL MÓDULO

Este módulo no tiene opciones.

PROPIEDADES PARA LA LLAMADA CREATE_OBJECT

  • metadata.name: El nombre del nuevo objeto de metadatos. Si no se proporciona, el nombre del objeto de metadatos será el predeterminado.
  • metadata.values: Una matriz JSON de objetos con valores iniciales para el objeto de metadatos.

la clave metadata.values tiene la siguiente estructura:

metadata.values = [
   { id = <int>  key = <key>  type = <type> value = <object> }
   ....
]
•
id: un id de objeto opcional para los metadatos, por defecto 0
•
key: una cadena, la clave de metadatos
•
type: un tipo de valor de metadatos opcional
•
value: un elemento JSON, el valor de metadatos.

EJEMPLO DE CONFIGURACIÓN

El módulo se suele añadir al archivo de configuración del demonio principal de PipeWire y a los clientes.

context.modules = [
{ name = libpipewire-module-metadata }
]

OBJETOS DE CONFIGURACIÓN

Para crear un objeto desde la factoría, se puede utilizar el método pw_core_create_object() o crear un objeto en la sección context.objects, como en el archivo de configuración principal de PipeWire:

context.objects = [
{ factory = metadata
    args = {
        metadata.name = default
        metadata.values = [
           { key = default.audio.sink   value = { name = somesink } }
           { key = default.audio.source value = { name = somesource } }
        ]
    }
}

Esto crea un nuevo almacén de metadatos predeterminado con 2 claves/valores.
