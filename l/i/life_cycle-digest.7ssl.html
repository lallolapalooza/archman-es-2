NOMBRE

life_cycle-digest - El ciclo de vida del algoritmo de resumen

DESCRIPCIÓN

Todos los resúmenes de mensajes (MD) pasan por varias etapas en su ciclo de vida:

inicio
Este estado representa el MD antes de que haya sido asignado. Es el estado inicial para cualquier transición del ciclo de vida.
nuevo
Este estado representa el MD después de que ha sido asignado.
inicializado
Este estado representa el MD cuando está configurado y es capaz de procesar entrada.
actualizado
Este estado representa el MD cuando está configurado y es capaz de procesar entrada adicional o generar salida.
finalizado
Este estado representa el MD cuando ha generado una salida. Para un resumen XOF, este estado representa el MD cuando ha generado una salida de un solo disparo.
estrujado
Para un resumen XOF, este estado representa el MD cuando ha generado salida. Puede llamarse varias veces para generar más salida. La longitud de la salida es variable para cada llamada.
liberado
Se entra en este estado cuando el MD es liberado. Es el estado terminal para todas las transiciones del ciclo de vida.

NOTAS
