DESCRIPCIÓN

El tipo EVP_CIPHER es una estructura que contiene punteros a funciones para la implementación de un cifrador simétrico.

EVP_CIPHER_meth_new() asigna una nueva estructura EVP_CIPHER. El NID (véase EVP_CIPHER_nid(3)) del cifrador se establece en cipher_type, el tamaño del bloque y la longitud de la clave se establecen en block_size y key_len, respectivamente.

EVP_CIPHER_meth_dup() crea una copia de cipher.

EVP_CIPHER_meth_free() libera una estructura EVP_CIPHER.

EVP_CIPHER_meth_set_iv_length() establece la longitud del vector de inicialización. Esto solo es necesario cuando el modo de cifrado implementado lo requiere.

EVP_CIPHER_meth_set_flags() sobrescribe las banderas para describir comportamientos opcionales en cipher con flags. A lo sumo se puede establecer uno de los siguientes modos de cifrado: EVP_CIPH_STREAM_CIPHER, EVP_CIPH_ECB_MODE, EVP_CIPH_CBC_MODE, EVP_CIPH_CFB_MODE, EVP_CIPH_OFB_MODE, EVP_CIPH_CTR_MODE, EVP_CIPH_GCM_MODE, EVP_CIPH_CCM_MODE, EVP_CIPH_XTS_MODE, y EVP_CIPH_WRAP_MODE.

Se pueden OR'ear cero o más de las siguientes banderas en el argumento flags:

EVP_CIPH_VARIABLE_LENGTH
Este cifrador tiene una longitud de clave variable, y la función EVP_CIPHER_CTX_set_key_length(3) se puede usar con él.
EVP_CIPH_CUSTOM_IV
Instruye a EVP_CipherInit_ex(3) y funciones de inicialización similares para que dejen el almacenamiento e inicialización del IV completamente a la implementación. Si esta bandera está establecida, normalmente se espera que la implementación lo haga en su función init.
EVP_CIPH_ALWAYS_CALL_INIT
Instruye a EVP_CipherInit_ex(3) y funciones de inicialización similares para que llamen a la función init de la implementación incluso si el argumento key es NULL.
EVP_CIPH_CTRL_INIT
Instruye a EVP_CipherInit_ex(3) y funciones de inicialización similares para que llamen a la función ctrl de la implementación con un comando type de EVP_CTRL_INIT al principio de la configuración.
EVP_CIPH_NO_PADDING
Instruye a EVP_CipherFinal_ex(3) y funciones de finalización similares para que no utilicen el relleno de bloque estándar, sino que informen de un error si la cantidad total de datos a cifrar o descifrar no es un múltiplo del tamaño del bloque.
EVP_CIPH_RAND_KEY
Instruye a EVP_CIPHER_CTX_rand_key(3) para que no genere una clave aleatoria usando arc4random_buf(3), sino que deje eso a la implementación llamando a la función ctrl con un comando type de EVP_CTRL_RAND_KEY y el puntero al almacenamiento de la clave en ptr.
EVP_CIPH_CUSTOM_COPY
Instruye a EVP_CIPHER_CTX_copy(3) para que llame a la función ctrl de la implementación con un comando type de EVP_CTRL_COPY y el EVP_CIPHER_CTX *out de destino en el argumento ptr inmediatamente antes de retornar exitosamente. El uso previsto es para que otras cosas se manejen después de que el bloque de datos específico de la implementación se haya copiado. Se accede al bloque de datos específico de la implementación con EVP_CIPHER_CTX_get_cipher_data(3).
EVP_CIPH_FLAG_DEFAULT_ASN1
Instruct EVP_CIPHER_param_to_asn1(3) and EVP_CIPHER_asn1_to_param(3) to use the default ASN1 parameter encoding/decoding routines. This flag should only be set if the cipher has no parameters or if the cipher implements ASN1 parameter encoding/decoding routines.

EVP_CIPHER_meth_set_impl_ctx_size() sets the size of the implementation-defined context data to ctx_size bytes.

EVP_CIPHER_meth_set_init() sets the cipher initialization function to init. The function is called when initializing the cipher context.

EVP_CIPHER_meth_set_do_cipher() sets the main cipher function to do_cipher. This function performs the actual encryption or decryption of data.

EVP_CIPHER_meth_set_cleanup() sets the cleanup function to cleanup. This function is called when the cipher context is destroyed.

EVP_CIPHER_meth_set_set_asn1_params() sets the function to encode cipher parameters into ASN1 format.

EVP_CIPHER_meth_set_get_asn1_params() sets the function to decode cipher parameters from ASN1 format.

EVP_CIPHER_meth_set_ctrl() sets the control function to ctrl. This function can be used to perform various control operations, such as setting options or retrieving information about the cipher.

The callback functions should return 1 on success and 0 on failure.

RETURN VALUES

EVP_CIPHER_meth_new(), EVP_CIPHER_meth_dup() return a pointer to a newly allocated EVP_CIPHER structure, or NULL on error.

EVP_CIPHER_meth_set_iv_length(), EVP_CIPHER_meth_set_flags(), EVP_CIPHER_meth_set_impl_ctx_size(), EVP_CIPHER_meth_set_init(), EVP_CIPHER_meth_set_do_cipher(), EVP_CIPHER_meth_set_cleanup(), EVP_CIPHER_meth_set_set_asn1_params(), EVP_CIPHER_meth_set_get_asn1_params(), EVP_CIPHER_meth_set_ctrl() return 1 on success, and 0 on failure.

EVP_CIPHER_meth_free() does not return a value.

DESCRIPTION

These functions are used to create and configure an EVP_CIPHER method. An EVP_CIPHER method is a structure containing function pointers and data that defines how a particular cipher should be implemented using the EVP cipher interface. This is typically used internally by OpenSSL or by applications that want to provide their own custom cipher implementations.

EVP_CIPHER_meth_new() creates a new EVP_CIPHER method structure. The nid parameter is the NID (numeric identifier) of the cipher. The block_size is the block size of the cipher in bytes. The key_len is the size of the key in bytes.

EVP_CIPHER_meth_dup() duplicates an existing EVP_CIPHER method structure.

EVP_CIPHER_meth_free() frees a previously allocated EVP_CIPHER method structure.

The following functions are used to set the function pointers within the EVP_CIPHER structure:

EVP_CIPH_FLAG_DEFAULT_ASN1
Instruct EVP_CIPHER_param_to_asn1(3) to use ASN1_TYPE_set_octetstring(3) if no set_asn1_parameters function is installed, and instruct EVP_CIPHER_asn1_to_param(3) to use ASN1_TYPE_get_octetstring(3) if no get_asn1_parameters function is installed.
EVP_CIPH_FLAG_LENGTH_BITS
Signals that the length of the input buffer for encryption / decryption is to be understood as the number of bits instead of bytes for this implementation. This is only useful for CFB1 ciphers.
EVP_CIPH_FLAG_CUSTOM_CIPHER
Instruct EVP_CipherUpdate(3), EVP_CipherFinal_ex(3), and similar encryption, decryption, and finalization functions that the implementation's do_cipher function takes care of everything, including padding, buffering and finalization.
EVP_CIPH_FLAG_AEAD_CIPHER
This indicates that this is an AEAD cipher implementation.

EVP_CIPHER_meth_set_impl_ctx_size() sets the size of the EVP_CIPHER's implementation context so that it can be automatically allocated.

EVP_CIPHER_meth_set_init() sets the init function for cipher. The cipher init function is called by EVP_CipherInit(3), EVP_CipherInit_ex(3), EVP_EncryptInit(3), EVP_EncryptInit_ex(3), EVP_DecryptInit(3), and EVP_DecryptInit_ex(3).

EVP_CIPHER_meth_set_do_cipher() sets the cipher function for cipher. The cipher function is called by EVP_CipherUpdate(3), EVP_EncryptUpdate(3), EVP_DecryptUpdate(3), EVP_CipherFinal(3), EVP_EncryptFinal(3), EVP_EncryptFinal_ex(3), EVP_DecryptFinal(3) and EVP_DecryptFinal_ex(3).

EVP_CIPHER_meth_set_cleanup() sets the function for cipher to do extra cleanup before the method's private data structure is cleaned out and freed. Note that the cleanup function is passed a EVP_CIPHER_CTX *, the private data structure is then available with EVP_CIPHER_CTX_get_cipher_data(3). This cleanup function is called by EVP_CIPHER_CTX_reset(3) and EVP_CIPHER_CTX_free(3).

EVP_CIPHER_meth_set_set_asn1_params() sets the function for cipher to set the AlgorithmIdentifier "parameter" based on the passed cipher. This function is called by EVP_CIPHER_param_to_asn1(3). EVP_CIPHER_meth_set_get_asn1_params() sets the function for cipher that sets the cipher parameters based on an ASN.1 AlgorithmIdentifier "parameter". Both these functions are needed when there is a need for custom data (more or other than the cipher IV). They are called by EVP_CIPHER_param_to_asn1(3) and EVP_CIPHER_asn1_to_param(3) respectively if defined.

EVP_CIPHER_meth_set_ctrl() sets the control function for cipher.

RETURN VALUES

EVP_CIPHER_meth_new() and EVP_CIPHER_meth_dup() return a pointer to a newly created EVP_CIPHER, or NULL on failure.

All EVP_CIPHER_meth_set_*() functions return 1.
