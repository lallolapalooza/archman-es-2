libssh2_banner_set(3)

Paquete: libssh2

Licencias: BSD

libssh2_banner_set(3) libssh2 libssh2_banner_set(3)

NOMBRE

libssh2_banner_set - establece el banner del protocolo SSH para el cliente local

SINOPSIS

#include <libssh2.h>
int
libssh2_banner_set(LIBSSH2_SESSION *session, const char *banner);

DESCRIPCIÓN

Esta función está OBSOLETA en la versión 1.4.0. ¡Utilice la función libssh2_session_banner_set(3) en su lugar!

session - Instancia de sesión devuelta por libssh2_session_init_ex(3)

banner - Un puntero a un banner definido por el usuario

Establece el banner que se enviará al host remoto cuando se inicie la sesión SSH con libssh2_session_handshake(3). Esto es opcional; por defecto, se enviará un banner correspondiente al protocolo y la versión de libssh2.

VALOR DE RETORNO

Devuelve 0 en caso de éxito o un valor negativo en caso de fallo. Devuelve LIBSSH2_ERROR_EAGAIN cuando de otro modo bloquearía. Aunque LIBSSH2_ERROR_EAGAIN es un número negativo, en realidad no es un fallo en sí mismo.

DISPONIBILIDAD

Marcada como obsoleta desde la versión 1.4.0

ERRORES

LIBSSH2_ERROR_ALLOC - Falló una llamada interna de asignación de memoria.

VER TAMBIÉN

libssh2_session_handshake(3)
