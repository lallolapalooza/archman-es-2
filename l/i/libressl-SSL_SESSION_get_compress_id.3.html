SSL_SESSION_GET_COMPRESS_ID(3) Manual de funciones de biblioteca SSL_SESSION_GET_COMPRESS_ID(3)

NOMBRE

SSL_SESSION_get_compress_id — obtener detalles sobre la compresión asociada con una sesión

SINOPSIS

biblioteca “libssl” libcrypto
#include <openssl/ssl.h>

unsigned int
SSL_SESSION_get_compress_id(const SSL_SESSION *s);

DESCRIPCIÓN

Si se ha negociado compresión para una sesión ssl, SSL_SESSION_get_compress_id() devuelve el id para el método de compresión, o 0 en caso contrario. El único método de compresión soportado internamente es zlib, que tiene un id de 1.

VER TAMBIÉN

ssl(3), SSL_get_session(3), SSL_SESSION_get_id(3), SSL_SESSION_get_protocol_version(3), SSL_SESSION_new(3)

HISTORIA

SSL_SESSION_get_compress_id() apareció por primera vez en OpenSSL 1.0.1 y ha estado disponible desde OpenBSD 5.3.
