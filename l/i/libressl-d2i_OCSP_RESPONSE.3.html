DESCRIPCIÓN

Estas funciones decodifican y codifican estructuras ASN.1 utilizadas para respuestas OCSP. Para obtener detalles sobre la semántica, ejemplos, advertencias y errores, consulte ASN1_item_d2i(3).

d2i_OCSP_RESPONSE() y i2d_OCSP_RESPONSE() decodifican y codifican una estructura OCSPResponse ASN.1 definida en la RFC 6960 sección 4.2.1.

d2i_OCSP_RESPBYTES() y i2d_OCSP_RESPBYTES() decodifican y codifican una estructura ResponseBytes ASN.1 definida en la RFC 6960 sección 4.2.1.

d2i_OCSP_BASICRESP() y i2d_OCSP_BASICRESP() decodifican y codifican una estructura BasicOCSPResponse ASN.1 definida en la RFC 6960 sección 4.2.1.

d2i_OCSP_RESPDATA() y i2d_OCSP_RESPDATA() decodifican y codifican una estructura ResponseData ASN.1 definida en la RFC 6960 sección 4.2.1.

d2i_OCSP_RESPID() y i2d_OCSP_RESPID() decodifican y codifican una estructura ResponderID ASN.1 definida en la RFC 6960 sección 4.2.1.

d2i_OCSP_SINGLERESP() y i2d_OCSP_SINGLERESP() decodifican y codifican una estructura SingleResponse ASN.1 definida en la RFC 6960 sección 4.2.1.

d2i_OCSP_CERTSTATUS() y i2d_OCSP_CERTSTATUS() decodifican y codifican una estructura CertStatus ASN.1 definida en la RFC 6960 sección 4.2.1.

d2i_OCSP_REVOKEDINFO() y i2d_OCSP_REVOKEDINFO() decodifican y codifican una estructura RevokedInfo ASN.1 definida en la RFC 6960 sección 4.2.1.

d2i_OCSP_CRLID() y i2d_OCSP_CRLID() decodifican y codifican una estructura CrlID ASN.1 definida en la RFC 6960 sección 4.4.2.

DESCRIPTION

These functions convert between ASN.1 encoded data and the corresponding internal OpenSSL structures representing OCSP (Online Certificate Status Protocol) messages.

The d2i_* functions decode an ASN.1 structure from the data pointed to by cpp. The parameter l is the maximum number of bytes to decode. If pp is not NULL, the decoded structure is stored in pp. If pp is NULL, the structure is allocated and pp is updated to point to it. The parameter cpp is updated to point to the next unparsed byte after decoding.

The i2d_* functions encode the specified structure into ASN.1 format. If cpp is not NULL, the encoded data is written to the buffer pointed to by cpp. If cpp is NULL, memory is allocated using malloc() for the encoded data, and the pointer is updated to point to it. The caller is responsible for freeing this memory using OPENSSL_free().

RETURN VALUES

The d2i_* functions return a pointer to the decoded structure, or NULL if an error occurs.

The i2d_* functions return the number of bytes successfully encoded or a negative value if an error occurs.
