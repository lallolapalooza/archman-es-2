libressl-X509V3_EXT_get_nid(3)

Paquete: libressl

Licencias: ISC, custom:OpenSSL

X509V3_EXT_GET_NID(3) Manual de funciones de biblioteca X509V3_EXT_GET_NID(3)

NOMBRE

X509V3_EXT_get_nid, X509V3_EXT_get — recuperar métodos de extensión de certificados X.509v3

SINOPSIS

biblioteca “libcrypto”
#include <openssl/x509v3.h>

const X509V3_EXT_METHOD *
X509V3_EXT_get_nid(int nid);

const X509V3_EXT_METHOD *
X509V3_EXT_get(X509_EXTENSION *ext);

DESCRIPCIÓN

Una extensión de certificado X.509v3 contiene un Identificador de Objeto (OID), un indicador booleano de criticidad y un valor de extensión opaco (un ASN1_OCTET_STRING) cuyo significado está determinado por el OID. El tipo X509V3_EXT_METHOD de la biblioteca, que aún no se documenta en detalle, contiene un identificador numérico (NID) para representar el OID y varios manejadores para codificar, decodificar, imprimir y configurar el valor de la extensión. La criticidad se maneja por separado, por ejemplo, como un argumento para X509V3_add1_i2d(3).

VALORES DE RETORNO

X509V3_EXT_get_nid() devuelve el X509V3_EXT_METHOD correspondiente al identificador numérico nid, o NULL si no hay ninguno.

X509V3_EXT_get() devuelve el X509V3_EXT_METHOD asociado con el tipo de extensión de ext, o NULL si no hay ninguno.

VER TAMBIÉN

i2s_ASN1_ENUMERATED_TABLE(3), OBJ_create(3), v2i_ASN1_BIT_STRING(3), X509_EXTENSION_get_object(3), X509V3_get_d2i(3)

ESTÁNDARES

RFC 5280: Perfil de certificado y lista de revocación de certificados (CRL) de la infraestructura de clave pública Internet X.509

  • sección 4.2: Extensiones de certificado

HISTORIA

Estas funciones aparecieron por primera vez en OpenSSL 0.9.2b y han estado disponibles desde OpenBSD 2.6.

ADVERTENCIAS

En LibreSSL, estas funciones solo admiten nids integrados correspondientes a objetos estáticos integrados. Otras implementaciones tienen soporte incompleto para métodos de extensión personalizados, cuya API no es segura para hilos, no afecta el comportamiento de X509_verify_cert(3), y tiene varias otras peculiaridades sorprendentes. Ambas funciones prefieren los métodos integrados sobre los métodos personalizados con el mismo OID.
