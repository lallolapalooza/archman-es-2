DESCRIPCIÓN

BIO_f_buffer() devuelve el método BIO de almacenamiento en búfer.

Los datos escritos en un BIO de almacenamiento en búfer se almacenan en búfer y se escriben periódicamente en el siguiente BIO de la cadena. Los datos leídos de un BIO de almacenamiento en búfer provienen de un búfer interno que se llena desde el siguiente BIO de la cadena. Se admiten tanto BIO_gets(3) como BIO_puts(3).

Llamar a BIO_reset(3) en un BIO de almacenamiento en búfer limpia cualquier dato en búfer.

BIO_get_buffer_num_lines() devuelve el número de líneas actualmente en búfer.

BIO_set_read_buffer_size(), BIO_set_write_buffer_size(), y BIO_set_buffer_size() establecen los tamaños de los búferes de lectura, escritura o ambos a size. El tamaño inicial del búfer es DEFAULT_BUFFER_SIZE, actualmente 4096. Se ignora cualquier intento de reducir el tamaño del búfer por debajo de DEFAULT_BUFFER_SIZE. Los datos almacenados en búfer se limpian cuando se redimensiona el búfer.

BIO_set_buffer_read_data() limpia el búfer de lectura y lo llena con num bytes de buf. Si num es mayor que el tamaño actual del búfer, el búfer se expande.

Los BIOs de almacenamiento en búfer implementan BIO_gets(3) utilizando operaciones BIO_read(3) en el siguiente BIO de la cadena. Al anteponer un BIO de almacenamiento en búfer a una cadena, es posible proporcionar la funcionalidad de BIO_gets(3) si los BIOs siguientes no lo admiten (por ejemplo, BIOs SSL).

Los datos solo se escriben en el siguiente BIO de la cadena cuando el búfer de escritura se llena o cuando se llama a BIO_flush(3). Por lo tanto, es importante llamar a BIO_flush(3) siempre que se deban escribir datos pendientes, como al eliminar un BIO de almacenamiento en búfer usando BIO_pop(3). Es posible que sea necesario reintentar BIO_flush(3) si la fuente/destino final del BIO no está bloqueando.

Cuando una cadena que contiene un BIO de almacenamiento en búfer se copia con BIO_dup_chain(3), BIO_set_read_buffer_size() y BIO_set_write_buffer_size() se llaman internamente para copiar automáticamente ambos tamaños de búfer del objeto BIO original al nuevo.

VALORES DE RETORNO

BIO_f_buffer() devuelve el método BIO de almacenamiento en búfer.

Cuando se llama en un objeto BIO de almacenamiento en búfer, BIO_method_type(3) devuelve la constante BIO_TYPE_BUFFER y BIO_method_name(3) devuelve un puntero a la cadena de caracteres estática "buffer".

BIO_get_buffer_num_lines() devuelve el número de líneas en búfer (puede ser 0).

BIO_set_read_buffer_size(), BIO_set_write_buffer_size(), y BIO_set_buffer_size() devuelven 1 si el búfer se redimensionó correctamente o 0 si hubo un error.

BIO_set_buffer_read_data() devuelve 1 si los datos se establecieron correctamente o 0 si hubo un error.

BIO_f_buffer(3) - Arch Linux Manual Pages

NAME

BIO_f_buffer - buffer BIO filter

SYNOPSIS

BIO_f_buffer(), BIO_set_buffer_read_data(), BIO_set_buffer_size(), BIO_get_buffer_num_lines(), BIO_set_write_buffer_size(), BIO_set_read_buffer_size()

DESCRIPTION

The buffer BIO is a pseudo BIO that adds buffering capabilities to another BIO.

The functions BIO_set_buffer_read_data(), BIO_set_buffer_size(), BIO_set_write_buffer_size() and BIO_set_read_buffer_size() can be used to set the buffer size for reading and writing. The default size is 16384 bytes.

The function BIO_get_buffer_num_lines() returns the number of lines currently stored in the buffer.

RETURN VALUES

BIO_f_buffer() returns a BIO filter.

BIO_set_buffer_read_data(), BIO_set_buffer_size(), BIO_set_write_buffer_size() and BIO_set_read_buffer_size() return 1 on success or 0 on failure.

BIO_get_buffer_num_lines() returns the number of lines stored in the buffer.
