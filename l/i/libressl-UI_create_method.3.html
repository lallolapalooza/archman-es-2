DESCRIPCIÓN

Un método contiene algunas funciones que implementan el nivel bajo de la Interfaz de Usuario. Estas funciones son:

un abridor (opener)
Esta función toma una referencia a una UI e inicia una sesión, por ejemplo, abriendo un canal a una tty, o creando un cuadro de diálogo.
un escritor (writer)
Esta función toma una referencia a una UI y una cadena UI, y escribe la cadena donde sea apropiado, tal vez a la tty, tal vez añadida como etiqueta de campo en un cuadro de diálogo. Nótese que esto recibe todas las cadenas asociadas con una UI, una tras otra, por lo que se debe tener cuidado con cuáles utiliza realmente.
un limpiador (flusher)
Esta función toma una referencia a una UI y limpia todo lo que se ha producido hasta el momento. Por ejemplo, si el método construye un cuadro de diálogo, esto se puede usar para mostrarlo realmente y aceptar la entrada finalizada con un botón presionado.
un lector (reader)
Esta función toma una referencia a una UI y una cadena UI y lee el prompt dado, tal vez desde la tty, tal vez desde un campo en un cuadro de diálogo. Nótese que esto recibe todas las cadenas asociadas con una UI, una tras otra, por lo que se debe tener cuidado con cuáles utiliza realmente.
un cerrador (closer)
Esta función toma una referencia a una UI y cierra la sesión, tal vez cerrando el canal a la tty, tal vez destruyendo un cuadro de diálogo.

Se espera que todas estas funciones devuelvan 0 en caso de error, 1 en caso de éxito, o -1 para eventos fuera de banda, por ejemplo, si algún prompt ha sido cancelado (presionando Ctrl-C, por ejemplo). Solo se espera que el limpiador o el lector devuelvan -1. Si lo devuelven otras funciones, se trata como si se hubiese devuelto 0.

Con respecto al escritor y al lector, no asuma que el primero solo debe escribir y no asuma que el segundo solo debe leer. Esto depende de las necesidades del método.

Por ejemplo, un lector de tty típico no escribiría los prompts en el escritor, sino que lo haría en el lector, debido a la naturaleza secuencial de los prompts en una tty. Así es como lo hace el método UI_OpenSSL(3).

En contraste, un método que construye un cuadro de diálogo añadiría todo el texto del prompt en el escritor, tendría toda la entrada leída en el limpiador y almacenaría los resultados en algún búfer temporal, y finalmente el lector solo recuperaría esos resultados.

La función central que utiliza estas funciones de método es UI_process(3), y lo hace en cinco pasos:

  1. Abre la sesión usando la función abridora si está definida. Si ocurre un error, salta al paso 5.
  2. Para cada Cadena UI asociada con la UI, llama a la función escritora si está definida. Si ocurre un error, salta al paso 5.
  3. Limpia todo usando la función limpiadora si está definida. Si ocurre un error, salta al paso 5.
  4. Para cada Cadena UI asociada con la UI, llama a la función lectora si está definida. Si ocurre un error, salta al paso 5.
  5. Cierra la sesión usando la función cerradora si está definida.

UI_create_method() crea un nuevo método UI con un nombre dado.

UI_destroy_method() destruye el ui_method dado.

UI_method_set_opener(), UI_method_set_writer(), UI_method_set_flusher(), UI_method_set_reader() y UI_method_set_closer() establecen uno de los cinco métodos principales al puntero de función dado.

UI_method_set_prompt_constructor() establece el constructor de prompts, véase UI_construct_prompt(3).

VALORES DE RETORNO

UI_create_method() devuelve un puntero UI_METHOD en caso de éxito o NULL en caso de error.

UI_method_set_opener(), UI_method_set_writer(), UI_method_set_flusher(), UI_method_set_reader(), UI_method_set_closer(), y UI_method_set_prompt_constructor() devuelven 0 en éxito o -1 si el método dado es NULL.

UI_method_get_opener(), UI_method_get_writer(), UI_method_get_flusher(), UI_method_get_reader(), UI_method_get_closer(), y UI_method_get_prompt_constructor() devuelven el puntero de función correspondiente o NULL si no está establecido.

DESCRIPTION

User Interface (UI) methods are used to implement various ways of interacting with the user, for example, prompting for passwords or displaying information.

A UI_METHOD is a structure containing function pointers for different UI operations.

UI_create_method() creates a new UI_METHOD structure and associates the given name with it. The name is mainly for debugging purposes.

UI_destroy_method() destroys the given UI_METHOD structure. Note that this function does not free any memory that might have been allocated by the functions set using UI_method_set_* family of functions.

The UI_method_set_* functions set the corresponding function pointer in the UI_METHOD structure. The functions that can be set are:

opener
Called when a UI operation needs to open a channel for interaction. The function is expected to prepare for interaction. The rwflag parameter indicates whether the interaction is read-only (0) or read-write (1). The pass and size parameters can be used to store a password if the interaction is for password input.
writer
Called to write a string to the UI. The strs parameter is an array of UI_STRING structures, and count is the number of strings to write.
flusher
Called to flush any buffered output. This is typically used after writing all strings.
reader
Called to read input from the user. The strs parameter is an array of UI_STRING structures, and index is the index of the string to read.
closer
Called when a UI operation needs to close the interaction channel.
prompt_constructor
Called to construct a prompt string. The function receives information about the object source, name, type, and prompt type, and should fill the prompt buffer with the constructed prompt string.

The UI_method_get_* functions retrieve the function pointer for the corresponding operation from the given UI_METHOD structure.

If a function pointer is not set in the method, the UI_method_get_* functions return NULL.

RETURN VALUES

UI_create_method() returns a pointer to the newly created UI_METHOD structure, or NULL if an error occurred.

The UI_method_set_* functions return 1 on success and 0 on error.

The UI_method_get_* functions return the corresponding function pointer if it is set in the method, or otherwise NULL.
