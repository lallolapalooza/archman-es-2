alpm_list_t * alpm_find_group_pkgs (alpm_list_t * dbs, const char * name)

Busca miembros del grupo en una lista de bases de datos. Si un miembro existe en varias bases de datos, solo se utiliza la primera base de datos. IgnorePkg también se maneja.

Parámetros

dbs la lista de alpm_db_t *
name el nombre del grupo

Devoluciones

la lista de alpm_pkg_t * (el llamador es responsable de alpm_list_free)
