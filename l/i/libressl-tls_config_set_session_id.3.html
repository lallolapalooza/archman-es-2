libressl-tls_config_set_session_id(3)

Paquete: libressl

Licencias: ISC, custom:OpenSSL

TLS_CONFIG_SET_SESSION_ID(3) Manual de funciones de biblioteca TLS_CONFIG_SET_SESSION_ID(3)

NOMBRE

tls_config_set_session_fd, tls_config_set_session_id, tls_config_set_session_lifetime, tls_config_add_ticket_key — configurar la reanudación de handshakes TLS

SINOPSIS

biblioteca “libtls” libssl libcrypto
#include <tls.h>

int
tls_config_set_session_fd(struct tls_config *config, int session_fd);

int
tls_config_set_session_id(struct tls_config *config, const unsigned char *session_id, size_t len);

int
tls_config_set_session_lifetime(struct tls_config *config, int lifetime);

int
tls_config_add_ticket_key(struct tls_config *config, uint32_t keyrev, unsigned char *key, size_t keylen);

DESCRIPCIÓN

tls_config_set_session_fd() establece un descriptor de archivo para ser utilizado en la gestión de datos para sesiones TLS (solo cliente). El descriptor de archivo dado debe ser un archivo regular y ser propiedad del usuario actual, con permisos restringidos para permitir solo al propietario leer y escribir el archivo (0600). Si el archivo tiene una longitud distinta de cero, el cliente intentará leer datos de sesión de este archivo y reanudar la sesión TLS anterior con el servidor. Tras un handshake exitoso, el archivo se actualizará con los datos actuales de la sesión, si están disponibles. El llamador es responsable de cerrar este descriptor de archivo, después de que todos los contextos TLS que se hayan configurado para usarlo se hayan liberado mediante tls_free().

tls_config_set_session_id() establece el identificador de sesión que será utilizado por el servidor TLS cuando las sesiones estén habilitadas (solo servidor). Por defecto se utiliza un valor aleatorio.

tls_config_set_session_lifetime() establece el tiempo de vida a ser utilizado para las sesiones TLS (solo servidor). El soporte de sesiones se deshabilita si se especifica un tiempo de vida de cero, que es el valor por defecto.

tls_config_add_ticket_key() añade una clave utilizada para el cifrado y autenticación de tickets TLS (solo servidor). Por defecto, las claves se generan y rotan automáticamente en función de su tiempo de vida. Esta función solo debe utilizarse para sincronizar la clave de cifrado de tickets entre múltiples procesos. Volver a añadir una clave conocida dará lugar a un error, a menos que sea la clave añadida más recientemente.

VALORES DE RETORNO

Estas funciones retornan 0 en caso de éxito o -1 en caso de error.

VER TAMBIÉN

tls_accept_socket(3), tls_config_set_protocols(3), tls_init(3), tls_load_file(3), tls_server(3)

HISTORIA

tls_config_set_session_id(), tls_config_set_session_lifetime() y tls_config_add_ticket_key() aparecieron en OpenBSD 6.1.

tls_config_set_session_fd() apareció en OpenBSD 6.3.
