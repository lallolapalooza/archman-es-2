NOMBRE

PKCS7_add_attribute(PKCS7_SIGNER_INFO *si, int nid, int attrtype, void *value);

PKCS7_set_attributes(PKCS7_SIGNER_INFO *si, STACK_OF(X509_ATTRIBUTE) *sk);

PKCS7_get_attribute(PKCS7_SIGNER_INFO *si, int nid);

int
PKCS7_add_signed_attribute(PKCS7_SIGNER_INFO *si, int nid, int attrtype, void *value);

int
PKCS7_set_signed_attributes(PKCS7_SIGNER_INFO *si, STACK_OF(X509_ATTRIBUTE) *sk);

ASN1_TYPE *
PKCS7_get_signed_attribute(PKCS7_SIGNER_INFO *si, int nid);

int
PKCS7_add_attrib_content_type(PKCS7_SIGNER_INFO *si, ASN1_OBJECT *coid);

int
PKCS7_add1_attrib_digest(PKCS7_SIGNER_INFO *si, const unsigned char *md, int mdlen);

int
PKCS7_add0_attrib_signing_time(PKCS7_SIGNER_INFO *si, ASN1_TIME *t);

int
PKCS7_add_attrib_smimecap(PKCS7_SIGNER_INFO *si, STACK_OF(X509_ALGOR) *cap);

DESCRIPCIÓN

PKCS7_add_attribute() añade un nuevo atributo de tipo nid a la lista unauthenticatedAttributes de si, y añade un nuevo objeto ASN.1 ANY de tipo attrtype con el valor dado value al nuevo atributo. La propiedad del value se transfiere al nuevo objeto atributo, por lo que el código llamante no debe usar free(3) el value. Si la lista ya contiene un atributo no autenticado de tipo nid antes de la llamada, el nuevo atributo reemplaza al antiguo en lugar de añadirse al final de la lista.

PKCS7_set_attributes() libera la lista unauthenticatedAttributes de si y todos los atributos contenidos en ella, y la reemplaza con una copia profunda de sk.

PKCS7_get_attribute() recupera el primer miembro ASN.1 ANY del atributo de tipo nid de la lista unauthenticatedAttributes de si.

El comportamiento de PKCS7_add_signed_attribute(), PKCS7_set_signed_attributes(), y PKCS7_get_signed_attribute() es idéntico excepto que operan sobre la lista de authenticatedAttributes.

La forma normal de usar PKCS7_add_signed_attribute() es crear primero un objeto SignedInfo con PKCS7_sign(3) usando las banderas PKCS7_PARTIAL o PKCS7_STREAM, recuperar el objeto PKCS7_SIGNER_INFO con PKCS7_get_signer_info(3) o añadir uno adicional con PKCS7_sign_add_signer(3), llamar a PKCS7_add_signed_attribute() para cada atributo adicional deseado, y luego realizar la firma con PKCS7_final(3) o con otra función de finalización.

Las cuatro funciones restantes son envoltorios alrededor de PKCS7_add_signed_attribute().

PKCS7_add_attrib_content_type() establece el atributo NID_pkcs9_contentType a coid, que especifica el tipo de contenido del valor ContentInfo a ser firmado. Este atributo es obligatorio y se añade automáticamente por PKCS7_sign(3) y PKCS7_sign_add_signer(3) a menos que esté presente la bandera PKCS7_NOATTR. Los objetos adecuados como argumentos de coid se pueden obtener, por ejemplo, con OBJ_nid2obj(3). Si coid es NULL, el tipo de contenido por defecto es NID_pkcs7_data.

PKCS7_add1_attrib_digest() establece o reemplaza el atributo NID_pkcs9_messageDigest, que es el resumen del mensaje de los octetos de contenido de la codificación DER del campo de contenido del valor ContentInfo que se está firmando, a una copia de md, que se supone que tiene una longitud de mdlen bytes. Si mdlen es -1, entonces se usa strlen(md) en lugar de mdlen. Este atributo es obligatorio y se añade automáticamente por PKCS7_dataFinal(3) y PKCS7_final(3).

PKCS7_add0_attrib_signing_time() establece o reemplaza el atributo opcional NID_pkcs9_signingTime a t, especificando la hora en que el firmante realizó el proceso de firma. La propiedad de t se transfiere al nuevo objeto atributo, por lo que el código llamante no debe usar free(3) t. Si t es NULL, se asigna una nueva estructura ASN1_TIME. Este atributo se añade automáticamente por PKCS7_dataFinal(3) y PKCS7_final(3).

PKCS7_add_attrib_smimecap() establece o reemplaza el atributo opcional NID_SMIMECapabilities, indicando los algoritmos que el remitente está preparado para manejar. El puntero cap no se almacena en el nuevo objeto atributo y puede pasarse a sk_X509_ALGOR_pop_free() después de la llamada.

VALOR DE RETORNO

Todas estas funciones devuelven 1 si tienen éxito, o 0 si falla.

VER TAMBIÉN

PKCS7_new(3), PKCS7_sign(3), X509_ATTRIBUTE_create_by_NID(3).

libressl PKCS7_add_attribute(3)

NAME

PKCS7_add_attribute, PKCS7_set_attributes, PKCS7_get_attribute, PKCS7_add_signed_attribute, PKCS7_set_signed_attributes, PKCS7_get_signed_attribute, PKCS7_add_attrib_content_type, PKCS7_add1_attrib_digest, PKCS7_add0_attrib_signing_time, PKCS7_add_attrib_smimecap - add/get attributes to/from PKCS7 structures

SYNOPSIS

#include <openssl/pkcs7.h>
#include <openssl/x509.h>

PKCS7_add_attribute(PKCS7 *p7, int nid, int type,
    void *value);
PKCS7_set_attributes(PKCS7 *p7,
    STACK_OF(X509_ATTRIBUTE) *sk);
PKCS7_get_attribute(PKCS7 *p7, int nid);

PKCS7_add_signed_attribute(PKCS7_SIGNER_INFO *si,
    int nid, int type, void *value);
PKCS7_set_signed_attributes(PKCS7_SIGNER_INFO *si,
    STACK_OF(X509_ATTRIBUTE) *sk);
PKCS7_get_signed_attribute(PKCS7_SIGNER_INFO *si,
    int nid);

PKCS7_add_attrib_content_type(PKCS7_SIGNER_INFO *si,
    ASN1_OBJECT *oid);
PKCS7_add1_attrib_digest(PKCS7_SIGNER_INFO *si,
    const unsigned char *dgst, int dgstlen);
PKCS7_add0_attrib_signing_time(PKCS7_SIGNER_INFO *si,
    ASN1_TIME *t);
PKCS7_add_attrib_smimecap(PKCS7_SIGNER_INFO *si,
    STACK_OF(X509_ALGOR) *caps);

DESCRIPTION

These functions are used to add and retrieve attributes from a PKCS7 object or a PKCS7 signer info structure.

A PKCS7 object can contain a set of attributes. These are accessed using PKCS7_add_attribute(), PKCS7_set_attributes(), and PKCS7_get_attribute(). The attributes are stored in the auth_attr field of the PKCS7 structure.

A PKCS7 signer info structure can contain two sets of attributes: authenticated attributes and unauthenticated attributes. The authenticated attributes are intended to be signed over, while the unauthenticated attributes are not. The functions PKCS7_add_signed_attribute(), PKCS7_set_signed_attributes(), and PKCS7_get_signed_attribute() operate on the authenticated attributes, which are stored in the auth_attr field of the PKCS7_SIGNER_INFO structure.

The unauthenticated attributes are stored in the unauth_attr field of the PKCS7_SIGNER_INFO structure. There are currently no functions to manipulate these.

The functions PKCS7_add_attrib_content_type(), PKCS7_add1_attrib_digest(), PKCS7_add0_attrib_signing_time(), and PKCS7_add_attrib_smimecap() are convenience functions for adding commonly used attributes.

  • PKCS7_add_attrib_content_type() adds an attribute of type NID_pkcs9_contentType. The value is an ASN1_OBJECT(3) representing the type of the content.
  • PKCS7_add1_attrib_digest() adds an attribute of type NID_pkcs9_messageDigest. The value is a digest buffer of length dgstlen. The buffer is copied.
  • PKCS7_add0_attrib_signing_time() adds an attribute of type NID_pkcs9_signingTime. The value is an ASN1_TIME(3) structure. The value is not copied.
  • PKCS7_add_attrib_smimecap() adds an attribute of type NID_smime_aa_smimeCap. The value is a STACK_OF(X509_ALGOR)(3) representing the S/MIME capabilities. The stack is not copied.

The PKCS7_set_attributes() and PKCS7_set_signed_attributes() functions replace any existing attributes with the new stack sk. The caller is responsible for freeing the old attribute list if necessary, and the new stack sk becomes owned by the PKCS7 structure. The caller should not free it.

The functions PKCS7_add_attribute() and PKCS7_add_signed_attribute() append a new attribute to the list. The attribute is created using X509_ATTRIBUTE_create() internally. The caller should free the created attribute using X509_ATTRIBUTE_free(3) after the call. This attribute is automatically added by PKCS7_sign(3) and PKCS7_sign_add_signer(3) unless the PKCS7_NOATTR or PKCS7_NOSMIMECAP flag is present.

RETURN VALUES

PKCS7_add_attribute(), PKCS7_set_attributes(), PKCS7_add_signed_attribute(), PKCS7_set_signed_attributes(), PKCS7_add_attrib_content_type(), PKCS7_add1_attrib_digest(), PKCS7_add0_attrib_signing_time(), and PKCS7_add_attrib_smimecap() return 1 on success or 0 on failure. The most common reason for failure is lack of memory. PKCS7_add_attribute() and PKCS7_add_signed_attribute() also fail if nid is invalid, and PKCS7_add_attrib_content_type() if si already contains an authenticated attribute of type NID_pkcs9_contentType.

PKCS7_get_attribute() and PKCS7_get_signed_attribute() return an internal pointer to an ASN.1 ANY object or NULL on failure. They fail if nid is invalid, if the respective list in si contains no attribute of the requested type, or if an invalid element is found in the list before finding the attribute of the requested type.

STANDARDS

RFC 2315: PKCS #7: Cryptographic Message Syntax Version 1.5, section 9.2: SignerInfo type

RFC 2985: PKCS #9: Selected Object Classes and Attribute Types Version 2.0, section 5.3: Attribute types for use in PKCS #7 data and section 5.6: Attributes defined in S/MIME

RFC 5652: Cryptographic Message Syntax (CMS), section 5.3: SignerInfo Type and section 11: Useful Attributes

RFC 8551: Secure/Multipurpose Internet Mail Extensions (S/MIME) Version 4.0 Message Specification, section 2.5.2: SMIMECapabilities Attribute

HISTORY

PKCS7_add_attribute(), PKCS7_set_attributes(), PKCS7_get_attribute(), PKCS7_add_signed_attribute(), PKCS7_set_signed_attributes(), and PKCS7_get_signed_attribute() first appeared in OpenSSL 0.9.1 and have been available since OpenBSD 2.6.

PKCS7_add_attrib_smimecap() first appeared in OpenSSL 0.9.5 and has been available since OpenBSD 2.7.

PKCS7_add_attrib_content_type(), PKCS7_add1_attrib_digest(), and PKCS7_add0_attrib_signing_time() first appeared in OpenSSL 1.0.0 and have been available since OpenBSD 4.9.

CAVEATS

PKCS7_set_signed_attributes() does not validate that sk contains the PKCS #9 content type and message digest attributes required by RFC 2315. It succeeds even when sk is empty, leaving si in a state that violates the standard.

PKCS7_add0_attrib_signing_time() does not validate t beyond checking that it is well-formed per RFC 5652, section 11.3. In particular, it may set the signing time to the future or to the remote past.

BUGS

A function to remove individual attributes from these lists does not appear to exist. A program desiring to do that might have to manually iterate the fields auth_attr and unauth_attr of si, which are both of type STACK_OF(X509_ATTRIBUTE), using the facilities described in STACK_OF(3) and OPENSSL_sk_new(3).
