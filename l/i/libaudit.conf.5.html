LIBAUDIT.CONF(5) Utilidades de administración del sistema LIBAUDIT.CONF(5)

NOMBRE

libaudit.conf - archivo de configuración de libaudit

DESCRIPCIÓN

El archivo /etc/libaudit.conf contiene información de configuración para aplicaciones de espacio de usuario que se enlazan a libaudit. Las aplicaciones son responsables de consultar la configuración en este archivo y obedecer las preferencias del administrador. Este archivo contiene una palabra clave de configuración por línea, un signo igual y luego la información de configuración apropiada. Las palabras clave reconocidas son: failure_action. Estas palabras clave se describen a continuación.

failure_action
Esta palabra clave especifica qué acción desea el administrador que tome una aplicación de espacio de usuario cuando hay un error al enviar un evento de auditoría al kernel. Los valores posibles son: IGNORE
- significa no hacer nada, LOG - escribir en syslog la incapacidad de enviar un evento de auditoría, y TERMINATE - la aplicación de espacio de usuario debe salir.

VER TAMBIÉN
