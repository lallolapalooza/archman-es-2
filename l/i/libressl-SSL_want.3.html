SSL_WANT(3) Manual de funciones de biblioteca SSL_WANT(3)

NOMBRE

SSL_want, SSL_want_nothing, SSL_want_read, SSL_want_write, SSL_want_x509_lookup — obtener información de estado de la operación de E/S TLS/SSL

SINOPSIS

biblioteca “libssl” libcrypto
#include <openssl/ssl.h>

int
SSL_want(const SSL *ssl);

int
SSL_want_nothing(const SSL *ssl);

int
SSL_want_read(const SSL *ssl);

int
SSL_want_write(const SSL *ssl);

int
SSL_want_x509_lookup(const SSL *ssl);

DESCRIPCIÓN

SSL_want() devuelve información de estado para el objeto SSL ssl.

Las otras llamadas SSL_want_*() son atajos para los estados posibles devueltos por SSL_want().

SSL_want() examina la información de estado interna del objeto SSL. Sus valores de retorno son similares a los de SSL_get_error(3). A diferencia de SSL_get_error(3), que también evalúa la cola de errores, la información se obtiene examinando solo una bandera de estado interna. Por lo tanto, los resultados solo deben usarse para operaciones normales en E/S no bloqueante. Las condiciones de error no se manejan y deben tratarse con SSL_get_error(3).

El resultado devuelto por SSL_want() siempre debe ser coherente con el resultado de SSL_get_error(3).

VALORES DE RETORNO

Los siguientes valores de retorno pueden ocurrir actualmente para SSL_want():

SSL_NOTHING
No hay datos para escribir ni leer.
SSL_WRITING
Hay datos en el búfer SSL que deben escribirse en la capa BIO subyacente para completar la operación SSL_*() real. Una llamada a SSL_get_error(3) debería devolver SSL_ERROR_WANT_WRITE.
SSL_READING
Se deben leer más datos de la capa BIO subyacente para completar la operación SSL_*() real. Una llamada a SSL_get_error(3) debería devolver SSL_ERROR_WANT_READ.
SSL_X509_LOOKUP
La operación no se completó porque una devolución de llamada de aplicación configurada por SSL_CTX_set_client_cert_cb(3) pidió que se volviera a llamar. Una llamada a SSL_get_error(3) debería devolver SSL_ERROR_WANT_X509_LOOKUP.

SSL_want_nothing(), SSL_want_read(), SSL_want_write(), y SSL_want_x509_lookup() devuelven 1 cuando la condición correspondiente es verdadera o 0 en caso contrario.

VER TAMBIÉN

err(3), ssl(3), SSL_get_error(3)

HISTORIA

SSL_want(), SSL_want_nothing(), SSL_want_read(), y SSL_want_write() aparecieron por primera vez en SSLeay 0.5.2. SSL_want_x509_lookup() apareció por primera vez en SSLeay 0.6.0. Estas funciones han estado disponibles desde OpenBSD 2.4.
