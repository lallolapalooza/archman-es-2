libressl-AES_encrypt(3)

Paquete: libressl

Licencias: ISC, custom:OpenSSL

AES_ENCRYPT(3) Manual de funciones de biblioteca AES_ENCRYPT(3)

NOMBRE

AES_set_encrypt_key, AES_set_decrypt_key, AES_encrypt, AES_decrypt, AES_cbc_encrypt — interfaz de bajo nivel para el cifrado simétrico AES

SINOPSIS

biblioteca “libcrypto”
#include <openssl/aes.h>

int
AES_set_encrypt_key(const unsigned char *userKey, const int bits, AES_KEY *key);

int
AES_set_decrypt_key(const unsigned char *userKey, const int bits, AES_KEY *key);

void
AES_encrypt(const unsigned char *in, unsigned char *out, const AES_KEY *key);

void
AES_decrypt(const unsigned char *in, unsigned char *out, const AES_KEY *key);

void
AES_cbc_encrypt(const unsigned char *in, unsigned char *out, size_t length, const AES_KEY *key, unsigned char *ivec, const int enc);

DESCRIPCIÓN

Estas funciones proporcionan una interfaz de bajo nivel para el algoritmo de cifrado simétrico AES, también llamado Rijndael. Por razones de flexibilidad, se recomienda que los programas de aplicación utilicen la interfaz de alto nivel descrita en EVP_EncryptInit(3) y EVP_aes_128_cbc(3) en su lugar siempre que sea posible.

AES_KEY es una estructura que puede contener hasta 60 valores int y un número de rondas.

AES_set_encrypt_key() expande la userKey, que tiene una longitud de bits, en la estructura key para prepararla para el cifrado. El número de bits y bytes leídos de userKey, el número de valores int almacenados en key, y el número de rondas son los siguientes:

bits bytes ints rondas
128 16 44 10
192 24 52 12
256 32 60 14

AES_set_decrypt_key() hace lo mismo, pero en preparación para el descifrado.

AES_encrypt() lee un único bloque de 16 bytes de *in, lo cifra con la key, y escribe los 16 bytes resultantes en *out. Los búferes de 16 bytes que comienzan en in y out pueden solaparse, e incluso in y out pueden apuntar a la misma ubicación de memoria.

AES_decrypt() descifra un solo bloque y es, por lo demás, idéntico a AES_encrypt().

Si enc es distinto de cero, AES_cbc_encrypt() cifra len bytes en in a out usando la key de 128 bits y el vector de inicialización ivec de 128 bits en modo CBC. Si enc es 0, AES_cbc_encrypt() realiza el descifrado correspondiente.

VALORES DE RETORNO

AES_set_encrypt_key() y AES_set_decrypt_key() devuelven 0 si tienen éxito, -1 si userKey o key es NULL, o -2 si el número de bits no es compatible.

VER TAMBIÉN

crypto(3), EVP_aes_128_cbc(3), EVP_EncryptInit(3)

ESTÁNDARES

ISO/IEC 18033-3:2010 Tecnologías de la información — Técnicas de seguridad — Algoritmos de cifrado — Parte 3: Cifrados por bloques

HISTORIA

Estas funciones aparecieron por primera vez en OpenSSL 0.9.7 y han estado disponibles desde OpenBSD 3.2.
