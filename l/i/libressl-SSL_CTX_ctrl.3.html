SSL_CTX_CTRL(3) Manual de funciones de biblioteca SSL_CTX_CTRL(3)

NOMBRE

SSL_CTX_ctrl, SSL_CTX_callback_ctrl, SSL_ctrl, SSL_callback_ctrl — funciones internas de manejo para objetos SSL_CTX y SSL

SINOPSIS

biblioteca “libssl” libcrypto
#include <openssl/ssl.h>

long
SSL_CTX_ctrl(SSL_CTX *ctx, int cmd, long larg, void *parg);

long
SSL_CTX_callback_ctrl(SSL_CTX *, int cmd, void (*fp)());

long
SSL_ctrl(SSL *ssl, int cmd, long larg, void *parg);

long
SSL_callback_ctrl(SSL *, int cmd, void (*fp)());

DESCRIPCIÓN

La familia de funciones SSL_*_ctrl() se utiliza para manipular la configuración de los objetos SSL_CTX y SSL. Dependiendo del comando cmd, se evalúan los argumentos larg, parg o fp. Estas funciones nunca deben llamarse directamente. Todas las funcionalidades necesarias están disponibles a través de otras funciones o macros.

VALORES DE RETORNO

Los valores de retorno de las funciones SSL*_ctrl() dependen del comando proporcionado a través del parámetro cmd().

VER TAMBIÉN

ssl(3), SSL_CTX_add_extra_chain_cert(3), SSL_CTX_sess_number(3), SSL_CTX_sess_set_cache_size(3), SSL_CTX_set_max_cert_list(3), SSL_CTX_set_mode(3), SSL_CTX_set_options(3), SSL_CTX_set_session_cache_mode(3), SSL_CTX_set_tlsext_servername_callback(3), SSL_CTX_set_tlsext_status_cb(3), SSL_CTX_set_tlsext_ticket_key_cb(3), SSL_get_server_tmp_key(3), SSL_num_renegotiations(3), SSL_session_reused(3), SSL_set_max_send_fragment(3)

HISTORIAL

SSL_CTX_ctrl() y SSL_ctrl() aparecieron por primera vez en SSLeay 0.8.0 y han estado disponibles desde OpenBSD 2.4.

SSL_CTX_callback_ctrl() y SSL_callback_ctrl() aparecieron por primera vez en OpenSSL 0.9.5 y han estado disponibles desde OpenBSD 2.7.
