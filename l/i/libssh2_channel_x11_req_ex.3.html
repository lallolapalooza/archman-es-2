libssh2_channel_x11_req_ex(3)

Paquete: libssh2

Licencias: BSD

libssh2_channel_x11_req_ex(3) libssh2 libssh2_channel_x11_req_ex(3)

NOMBRE

libssh2_channel_x11_req_ex - solicitar un canal de reenvío X11

SINOPSIS

#include <libssh2.h>
int
libssh2_channel_x11_req_ex(LIBSSH2_CHANNEL *channel, int single_connection,
                           const char *auth_proto, const char *auth_cookie,
                           int screen_number);
int
libssh2_channel_x11_req(LIBSSH2_CHANNEL *channel,
                        int screen_number);

DESCRIPCIÓN

channel - Instancia de canal previamente abierta, tal como la devuelve libssh2_channel_open_ex(3)

single_connection - distinto de cero para reenviar solo una conexión.

auth_proto - Protocolo de autenticación X11 a usar

auth_cookie - la cookie (codificada en hexadecimal).

screen_number - la pantalla XLL a reenviar

Solicita un reenvío X11 en el channel. Para usar el reenvío X11, primero se debe llamar a libssh2_session_callback_set2(3) para establecer LIBSSH2_CALLBACK_X11. Esta devolución de llamada se invocará cuando el host remoto acepte el reenvío X11.

VALOR DE RETORNO

Devuelve 0 en caso de éxito o un valor negativo en caso de fallo. Devuelve LIBSSH2_ERROR_EAGAIN cuando de lo contrario se bloquearía. Si bien LIBSSH2_ERROR_EAGAIN es un número negativo, no es realmente un fallo en sí mismo.

ERRORES

LIBSSH2_ERROR_ALLOC - Falló una llamada interna de asignación de memoria.

LIBSSH2_ERROR_SOCKET_SEND - Imposible enviar datos en el socket.

LIBSSH2_ERROR_CHANNEL_REQUEST_DENIED -
