DESCRIPCIÓN

Estas funciones de biblioteca forman parte de Netpbm(1)

TIPOS Y CONSTANTES

Cada xel contiene tres xelvales, cada uno de los cuales debe contener solo valores entre 0 y PNM_MAXMAXVAL, inclusive.

MANIPULACIÓN DE XEL

La macro PNM_GET1 extrae un único valor de un xel, cuando sabes que proviene de un archivo PBM o PGM. Cuando proviene de un archivo PPM, usa PPM_GETR(), PPM_GETG() y PPM_GETB().

La macro PNM_ASSIGN1 asigna un único valor a un xel, cuando sabes que proviene de un archivo PBM o PGM. Cuando proviene de un archivo PPM, usa PPM_ASSIGN.

La macro PNM_EQUAL compara dos xels para verificar su igualdad. La macro PNM_FORMAT_TYPE calcula un código de tipo de formato a partir de un código de formato. Los tipos de formato son PBM, PGM, PPM y PAM. Pero ten en cuenta que PBM, PGM y PPM son cada uno dos formatos diferentes: uno plano y uno sin procesar. Por lo tanto, hay cuatro tipos de formato, pero siete formatos. PNM_FORMAT_TYPE no funciona con el código de formato PAM.

pnm_whitexel() y pnm_blackxel() devuelven un xel blanco o negro, respectivamente, para el maxval y format dados.

pnm_invertxel() invierte un xel.

INICIALIZACIÓN

pnm_init() está obsoleto (al menos desde Netpbm 9.25 (marzo de 2002)). Usa pm_proginit() en su lugar.

pnm_init() es idéntico a pm_proginit.

GESTIÓN DE MEMORIA

pnm_allocarray() asigna espacio para una matriz de xels. pnm_freearray() libera el espacio de matriz asignado por pnm_allocarray() o pnm_readpnm().

pnm_allocrow() asigna espacio para una fila de una imagen PNM. pnm_freerow() la libera.

LECTURA DE ARCHIVOS PNM

pnm_readpnminit() es similar a pnm_readpaminit(), pero solo lee imágenes PNM y tiene una lista de parámetros diferente.

pnm_readpnmrow() es similar a pnm_readpamrow() pero solo funciona en imágenes PNM y tiene una lista de parámetros diferente y devuelve la fila como una matriz de xels en lugar de tuplas.

pnm_readpnm() es similar a pnm_readpam() excepto que solo lee imágenes PNM y utiliza una lista de parámetros diferente y devuelve una matriz de filas de la que pnm_readpnmrow() devolvería en lugar de la que pnm_readpamrow() devolvería.

ESCRITURA DE ARCHIVOS

pnm_writepnminit() es similar a pnm_writepaminit() excepto que solo puede escribir una cabecera PNM y tiene una lista de parámetros diferente.

forceplain es un valor binario. Verdadero (distinto de cero) significa escribir la imagen en la versión plana (ASCII) del formato seleccionado. Falso (cero) significa escribirla en la versión sin procesar (binaria) del formato seleccionado. Ver formatoPNMspecification(5)

pnm_writepnmrow() es similar a pnm_writepamrow() excepto que solo funciona en imágenes PNM y tiene una lista de parámetros diferente y toma una matriz de xels en lugar de una matriz de tuplas. Ver la descripción de forceplain arriba.

pnm_writepnm() es similar a pnm_writepam() excepto que solo funciona en imágenes PNM, tiene una lista de parámetros diferente y toma una matriz de filas de xels en lugar de una matriz de filas de tuplas. Ver la descripción de forceplain arriba.

PROMOCIÓN DE FORMATO

pnm_promoteformatrow() promueve una fila de xels de un maxval y formato a un nuevo conjunto. Úselo cuando combine varios aninimos de diferentes tipos: simplemente tome el máximo de los maxvals y el máximo de los formatos, y promuevalos todos a ese.

pnm_promoteformat() promueve un animap completo.

MISCELÁNEA

libpnm(3)

NAME

libpnm - functions for manipulating PNM images

SYNOPSIS

#include <netpbm/pam.h>

#include <netpbm/pbm.h>

#include <netpbm/pgm.h>

#include <netpbm/ppm.h>

#include <netpbm/pnm.h>

void pnm_nextimage(FILE *fp);

pnm_check(FILE *fp, int *rows, int *cols, int *maxval);

void pnm_backgroundxelrow(const struct pixel *xelrow, int cols, int maxval, enum pm_truecolorformat format);

struct pixel pnm_backgroundxel(const struct pam *pam);

DESCRIPTION

pnm_nextimage() advances the file pointer fp to the start of the next image in a multi-image PNM input file (so that a subsequent pnm_readpnminit() reads its header).

pnm_nextimage() is analogous to pbm_nextimage(), but works on PPM, PGM, and PBM files.

pnm_check() is similar to pnm_checkpam() except it works only on PNM images.

pnm_check() is identical to ppm_check().

pnm_backgroundxelrow() figures out an appropriate background xel based on the row of xels xelrow, which is cols xels wide, has maxval maxval, and represents an image with format format.

This estimate works best when the row is the top or bottom row of the image.

pnm_backgroundxel() does the same thing as pnm_backgroundxelrow(), except based on an entire image instead of just one row. This tends to do a slightly better job than pnmbackgroundxelrow().
