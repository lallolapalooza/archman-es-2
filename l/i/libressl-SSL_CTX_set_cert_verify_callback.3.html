Licencias: ISC, custom:OpenSSL

SSL_CTX_SET_CERT_VERIFY_CALLBACK(3) Manual de funciones de biblioteca SSL_CTX_SET_CERT_VERIFY_CALLBACK(3)

NOMBRE

SSL_CTX_set_cert_verify_callback — establece el procedimiento de verificación del certificado del par

SINOPSIS

biblioteca “libssl” libcrypto
#include <openssl/ssl.h>

void
SSL_CTX_set_cert_verify_callback(SSL_CTX *ctx, int (*callback)(X509_STORE_CTX *, void *), void *arg);

DESCRIPCIÓN

SSL_CTX_set_cert_verify_callback() establece la función de devolución de llamada de verificación para ctx. Los objetos SSL que se crean a partir de ctx heredan la configuración válida en el momento en que se llama a SSL_new(3).

Cada vez que se verifica un certificado durante un apretón de manos SSL/TLS, se llama a una función de verificación. Si la aplicación no especifica explícitamente una función de devolución de llamada de verificación, se utiliza la función de verificación integrada. Si se especifica una función de devolución de llamada de verificación callback a través de SSL_CTX_set_cert_verify_callback(), se llama a la función de devolución de llamada proporcionada en su lugar. Al establecer callback en NULL, se restaura el comportamiento predeterminado.

Cuando se debe realizar la verificación, se llamará a callback con los argumentos callback(X509_STORE_CTX *x509_store_ctx, void *arg). El argumento arg es especificado por la aplicación al establecer callback.

callback debe devolver 1 para indicar éxito en la verificación y 0 para indicar fallo en la verificación. Si SSL_VERIFY_PEER está establecido y callback devuelve 0, el apretón de manos fallará. Dado que el procedimiento de verificación puede permitir que la conexión continúe en caso de fallo (al devolver siempre 1), el resultado de la verificación debe establecerse en cualquier caso utilizando el miembro error de x509_store_ctx para que la aplicación que llama sea informada sobre el resultado detallado del procedimiento de verificación.

Dentro de x509_store_ctx, callback tiene acceso a la función verify_callback establecida usando SSL_CTX_set_verify(3).

VER TAMBIÉN

ssl(3), SSL_CTX_load_verify_locations(3), SSL_CTX_set_verify(3), SSL_get_verify_result(3)

HISTORIA

SSL_CTX_set_cert_verify_callback() apareció por primera vez en SSLeay 0.6.1 y ha estado disponible desde OpenBSD 2.4.

Antes de OpenSSL 0.9.7, el argumento arg de SSL_CTX_set_cert_verify_callback() se ignoraba, y callback se llamaba simplemente como int (*callback)(X509_STORE_CTX *). Para compilar software escrito para versiones anteriores de OpenSSL, habrá que añadir un argumento ficticio a callback.

ADVERTENCIAS

No mezcle la devolución de llamada de verificación descrita en esta función con la función verify_callback llamada durante el proceso de verificación. Esta última se establece utilizando la familia de funciones SSL_CTX_set_verify(3).

Proporcionar un procedimiento de verificación completo, incluidas las configuraciones del propósito del certificado, etc., es una tarea compleja. El procedimiento integrado es bastante potente y, en la mayoría de los casos, debería ser suficiente modificar su comportamiento utilizando la función verify_callback.

ERRORES

SSL_CTX_set_cert_verify_callback() no proporciona información de diagnóstico.
