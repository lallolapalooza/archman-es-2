LIBKECCAK_CSHAKE_INITIALISE(3) Manual de funciones de biblioteca LIBKECCAK_CSHAKE_INITIALISE(3)

NOMBRE

libkeccak_cshake_initialise - Inicializa una esponja para el hash cSHAKE

SINOPSIS

#include <libkeccak.h>
void libkeccak_cshake_initialise(struct libkeccak_state *restrict state,
                                 const void *n_text, size_t n_len, size_t n_bits, const char *n_suffix,
                                 const void *s_text, size_t s_len, size_t s_bits, const char *s_suffix);

Enlace con -lkeccak.

DESCRIPCIÓN

La función libkeccak_cshake_suffix() se llamará inmediatamente después de la función libkeccak_state_initialise(3) (antes de libkeccak_update(3) o libkeccak_digest(3), o cualquier variante de esas funciones), para proporcionar los bloques de inicialización, que contienen datos de personalización, a la esponja Keccak.

El valor del parámetro state será un estado inicializado al que se alimentarán los bloques de inicialización.

El valor del parámetro n_text será la cadena de bits del nombre de la función, representada en bytes crudos; n_len será un valor no mayor que el número de bytes completos en n_text y n_bits será el número de bits en n_text sin los bytes cubiertos por n_len, es decir, el número de bits en n_text menos (nlen_*8). n_suffix será NULL o un apéndice de bits a n_suffix (ni n_len ni n_bits contarán estos), almacenado como una cadena terminada en NUL de los dígitos ASCII 1 y 0.

El valor del parámetro s_text será la cadena de bits de personalización, representada en bytes crudos; s_len será un valor no mayor que el número de bytes completos en s_text y s_bits será el número de bits en s_text sin los bytes cubiertos por s_len, es decir, el número de bits en s_text menos (nles_*8). s_suffix será NULL o un apéndice de bits a s_suffix (ni s_len ni s_bits contarán estos), almacenado como una cadena terminada en NUL de los dígitos ASCII 1 y 0.

Para los parámetros n_suffix y s_suffix, NULL se trata como la cadena vacía.

VALORES DE RETORNO

La función libkeccak_cshake_suffix() no devuelve un valor.

ERRORES

La función libkeccak_cshake_suffix() no puede fallar.
