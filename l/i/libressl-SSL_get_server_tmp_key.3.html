SSL_GET_SERVER_TMP_KEY(3) Manual de funciones de biblioteca SSL_GET_SERVER_TMP_KEY(3)

NOMBRE

SSL_get_server_tmp_key — clave temporal del servidor durante un apretón de manos

SINOPSIS

biblioteca “libssl” libcrypto
#include <openssl/ssl.h>

long
SSL_get_server_tmp_key(SSL *ssl, EVP_PKEY **key);

DESCRIPCIÓN

SSL_get_server_tmp_key() recupera la clave temporal proporcionada por el servidor y utilizada durante el intercambio de claves. Por ejemplo, si se está utilizando ECDHE, esta representa la clave pública ECDHE del servidor.

En caso de éxito, se almacena una copia de la clave en *key. Es responsabilidad del llamador liberar esta clave después de su uso utilizando EVP_PKEY_free(3).

Esta función solo puede ser llamada por el cliente.

Esta función está implementada como una macro.

VALORES DEVUELTOS

SSL_get_server_tmp_key() devuelve 1 en caso de éxito o 0 en caso de fallo.

VER TAMBIÉN

EVP_PKEY_free(3), ssl(3), SSL_ctrl(3)

HISTORIA

SSL_get_server_tmp_key() apareció por primera vez en OpenSSL 1.0.2 y ha estado disponible desde OpenBSD 6.1.
