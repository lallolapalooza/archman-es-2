LIGHTDM(1) Manual de Comandos Generales LIGHTDM(1)

NOMBRE

lightdm - un gestor de pantalla

SINOPSIS

lightdm [ OPCIÓN ]

DESCRIPCIÓN

lightdm es un gestor de pantalla.

OPCIONES

-h, --help
Mostrar opciones de ayuda
-c, --config=ARCHIVO
Usar archivo de configuración
-d, --debug
Imprimir mensajes de depuración
--test-mode
Ejecutar como usuario no privilegiado, omitiendo cosas que requieren acceso root
--pid-file=ARCHIVO
Archivo donde escribir el PID
--xsessions-dir=DIRECTORIO
Directorio desde donde cargar sesiones X
--xgreeters-dir=DIRECTORIO
Directorio desde donde cargar greeters X
--log-dir=DIRECTORIO
Directorio donde escribir logs
--run-dir=DIRECTORIO
Directorio para almacenar el estado de ejecución
--cache-dir=DIRECTORIO
Directorio para información cacheadas
-v, --version
Mostrar versión de lanzamiento

ARCHIVOS

/etc/lightdm/lightdm.conf
Configuración
/etc/lightdm/users.conf
Configuración de lista de usuarios (si no se usa Accounts Service)
/etc/lightdm/keys.conf
Claves XDMCP
