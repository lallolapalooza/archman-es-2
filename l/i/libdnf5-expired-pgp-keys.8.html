NOMBRE

libdnf5-expired-pgp-keys - Plugin de Claves PGP Caducadas

DESCRIPCIÓN

El plugin comprueba las claves PGP instaladas pero caducadas antes de ejecutar la transacción. Para cada clave caducada, se le pide al usuario información sobre la clave específica y se le permite confirmar su eliminación, permitiendo la importación de una clave actualizada más tarde. Cuando la opción assumeyes está configurada, las claves caducadas se eliminan automáticamente.

CONFIGURACIÓN

La configuración del plugin se encuentra en /etc/dnf/libdnf5-plugins/expired-pgp-keys.conf. Todas las opciones de configuración están en la sección [main].

habilitado
Si el plugin está habilitado. El valor por defecto es True.
