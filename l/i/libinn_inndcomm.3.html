DESCRIPCIÓN

Las rutinas descritas en esta página de manual forman parte de la biblioteca InterNetNews, libinn(3). Se utilizan para enviar comandos a un demonio innd en ejecución en el host local. Las letras "ICC" significan Comando de **C**ontrol de **I**nnd.

La función ICCopen crea un socket de datagrama de dominio Unix y lo vincula al socket de control del servidor, si dichos sockets son soportados. De lo contrario, crea una tubería con nombre para comunicarse con el servidor. Devuelve "-1" en caso de fallo o 0 en caso de éxito. Esta rutina debe ser llamada antes que cualquier otra rutina.

La función ICCclose cierra cualquier descriptor que haya sido creado por ICCopen. Devuelve "-1" en caso de fallo o 0 en caso de éxito.

La función ICCsettimeout puede ser llamada antes que cualquiera de las siguientes rutinas para determinar cuánto tiempo la biblioteca esperará antes de renunciar a obtener la respuesta del servidor. Esto se hace estableciendo y capturando una señal SIGALRM de signal(2). Si el tiempo de espera es menor que cero, entonces no se esperará ninguna respuesta. Los comandos SC_SHUTDOWN, SC_XABORT y SC_XEXEC tampoco reciben una respuesta. El valor predeterminado, que se puede obtener estableciendo el tiempo de espera a <0>, es esperar durante 2 minutos.

La función ICCcommand envía el comando cmd con los parámetros argv al servidor. Devuelve "-1" en caso de error. Si el servidor responde y replyp no es NULL, se rellenará con un buffer asignado que contiene el texto completo de la respuesta del servidor. Este buffer es una cadena en el formato "dígitos texto" donde dígitos es el valor textual del código de salida recomendado (generalmente 1, seguido de texto, dando la razón del fallo); un valor de 0 indica éxito. Las respuestas más largas que 64KB se truncarán. Los valores posibles de cmd están definidos en el archivo de cabecera inn/inndcomm.h, y también en la SINOPSIS de esta página de manual. Los parámetros para cada comando se describen en ctlinnd(8). Esta rutina devuelve "-1" en caso de fallo de comunicación, o el estado de salida enviado por el servidor, que nunca será negativo.

La función ICCcancel envía un mensaje "cancel" al servidor. Su argumento msgid es el ID del mensaje del artículo que debe ser cancelado. El valor de retorno es el mismo que para ICCcommand.

Las funciones ICCpause, ICCreserve e ICCgo envían un comando "pause", "reserve" o "go" al servidor, respectivamente. Si se utiliza ICCreserve, entonces el valor why utilizado en la invocación de ICCpause debe coincidir; el valor utilizado en la invocación de ICCgo siempre debe coincidir con el utilizado en la invocación de ICCpause. El valor de retorno para las tres rutinas es el mismo que para ICCcommand.

Si alguna rutina descrita anteriormente falla, la variable ICCfailure identificará la llamada al sistema que falló.
