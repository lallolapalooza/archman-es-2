NOMBRE

libpipewire-module-rt - RT

DESCRIPCIÓN

Los módulos rt pueden otorgar prioridades en tiempo real a los hilos de procesamiento.

Utiliza el planificador del sistema operativo para permitir la planificación en tiempo real para ciertos hilos, con el fin de facilitar el procesamiento de audio de baja latencia. Esto requiere que RLIMIT_RTPRIO se establezca en un valor igual o superior al parámetro rt.prio de este módulo. La mayoría de las distribuciones vendrán con algún paquete que configure esto para ciertos grupos o usuarios. Si esto no está configurado y DBus está disponible, este módulo recurrirá a la API DBus Realtime Portal o a RTKit.

NOMBRE DEL MÓDULO

libpipewire-module-rt

OPCIONES DEL MÓDULO

  • nice.level: El valor de nice establecido para el hilo de la aplicación. Mejora el rendimiento de la comunicación con el demonio de PipeWire.
  • rt.prio: La prioridad en tiempo real del hilo de datos. Valores más altos significan mayor prioridad.
  • rt.time.soft, rt.time.hard: La cantidad de tiempo de CPU que un hilo RT puede consumir sin realizar llamadas de bloqueo antes de que el kernel mate el hilo. Esta es una medida de seguridad para evitar bloqueos del sistema completo cuando algún hilo consume el 100%.
  • rlimits.enabled: habilita el uso de rtlimits, por defecto true.
  • rtportal.enabled: habilita el uso de realtime portal, por defecto true
  • rtkit.enabled: habilita el uso de rtkit, por defecto true
  • uclamp.min: el valor mínimo de utilización que el planificador debería considerar
  • uclamp.max: el valor máximo de utilización que el planificador debería considerar

El nivel de nice se establece por defecto en un valor inválido para que los clientes no aumenten automáticamente el nivel de nice.

Los procesos del servidor PipeWire están configurados explícitamente con un nivel de nice válido.

SOBREESCRITURA DE CONFIGURACIÓN

Se puede agregar una sección de configuración module.rt.args para anular los argumentos del módulo.

# ~/.config/pipewire/pipewire.conf.d/my-rt-args.conf
module.rt.args = {
    #nice.level = 22
}

EJEMPLO DE CONFIGURACIÓN

context.modules = [
{   name = libpipewire-module-rt
    args = {
        #nice.level   = 20
        #rt.prio      = 88
        #rt.time.soft = -1
        #rt.time.hard = -1
        #rlimits.enabled = true
        #rtportal.enabled = true
        #rtkit.enabled = true
        #uclamp.min = 0
        #uclamp.max = 1024
    }
    flags = [ ifexists nofail ]
}
]
