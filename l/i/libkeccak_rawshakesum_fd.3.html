LIBKECCAK_RAWSHAKESUM_FD(3) Manual de funciones de biblioteca LIBKECCAK_RAWSHAKESUM_FD(3)

NOMBRE

libkeccak_rawshakesum_fd - Calcula un hash RawSHAKE de un archivo

SINOPSIS

#include <libkeccak.h>
int libkeccak_rawshakesum_fd(int fd, struct libkeccak_state *state, long int semicapacity, long int output, void *hashsum);

Enlace con -lkeccak.

DESCRIPCIÓN

La función libkeccak_rawshakesum_fd() calcula un hash RawSHAKE de un archivo, cuyo descriptor de archivo se especifica mediante fd (y debe estar al principio del archivo.) El algoritmo de hash se ajusta mediante los parámetros semicapacity y output; estos especifican la mitad de la capacidad y el tamaño de salida, respectivamente, en bits.

El hash se almacena en forma binaria en hashsum. hashsum debe tener un tamaño de asignación de al menos (((output + 7) / 8) * sizeof(char)).

*state no debe inicializarse. libkeccak_rawshakesum_fd() inicializa *state por sí misma. Por lo tanto, habría una fuga de memoria si *state ya está inicializado.

VALORES DE RETORNO

La función libkeccak_rawshakesum_fd() devuelve 0 si se completa con éxito. En caso de error, se devuelve -1 y se establece errno para describir el error.

ERRORES

La función libkeccak_rawshakesum_fd() puede fallar por cualquier motivo, excepto aquellos que resultan en que errno se establezca en EINTR, especificados para las funciones read(2), malloc(3), y realloc(3).

NOTAS

Tenga en cuenta que libkeccak_rawshakesum_fd() calcula el hash del archivo hasta que se alcanza el final. Para tuberías y sockets, esto significa hasta que el archivo se cierre. Pero para dispositivos de caracteres, esto generalmente significa nunca. Por lo tanto, intentar calcular el hash de archivos en /dev suele ser una mala idea. libkeccak_rawshakesum_fd() no comprueba la longitud del archivo ni el tipo de archivo antes de calcular el hash, ya que esto podría limitar lo que puede hacer y hacer que la biblioteca sea más compleja.

libkeccak_rawshakesum_fd() no se detiene si se interrumpe (cuando read(2) devuelve EINTR.)

libkeccak_rawshakesum_fd() asume que toda la información es no sensible y, por lo tanto, no realizará ninguna eliminación segura de información.

libkeccak_rawshakesum_fd() no valida la configuración del algoritmo.

EJEMPLO

Este ejemplo calcula el hash RawSHAKE256(, 512) de la entrada desde stdin, e imprime el hash, en formato hexadecimal, en stdout.

struct libkeccak_state state;
if (libkeccak_rawshakesum_fd(STDIN_FILENO, &state, 256, 512, binhash) < 0)
	goto fail;
libkeccak_behex_lower(hexhash, binhash, sizeof(binhash));
printf("%s\n", hexhash);
libkeccak_state_destroy(&state);
