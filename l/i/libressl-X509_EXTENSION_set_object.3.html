DESCRIPCIÓN

X509_EXTENSION_new() asigna e inicializa un objeto X509_EXTENSION vacío, que representa una estructura Extension ASN.1 definida en la RFC 5280 sección 4.1. Es un objeto envoltorio alrededor de objetos de extensión específicos de diferentes tipos y almacena un identificador de tipo de extensión y un indicador de criticidad además de la forma codificada DER del objeto envuelto. Los objetos X509_EXTENSION se pueden usar para certificados X.509 v3 dentro de objetos X509_CINF y para listas de revocación de certificados X.509 v2 dentro de objetos X509_CRL_INFO y X509_REVOKED.

X509_EXTENSION_dup() crea una copia profunda de ex usando ASN1_item_dup(3).

X509_EXTENSION_free() libera ex y todos los objetos que esté utilizando.

X509_EXTENSION_create_by_NID() crea una extensión de tipo nid y criticidad crit utilizando los datos data. La extensión creada se devuelve y se escribe en *ex reutilizando o asignando una nueva extensión si es necesario, por lo que *ex debe ser NULL o una estructura X509_EXTENSION válida. No debe ser un puntero no inicializado.

X509_EXTENSION_create_by_OBJ() es idéntica a X509_EXTENSION_create_by_NID() excepto que crea una extensión usando obj en lugar de un NID.

X509_EXTENSION_set_object() establece el tipo de extensión de ex a obj. El puntero obj se duplica internamente, por lo que obj debe liberarse después de su uso.

X509_EXTENSION_set_critical() establece la criticidad de ex a crit. Si crit es cero, la extensión no es crítica, de lo contrario es crítica.

X509_EXTENSION_set_data() establece los datos en la extensión ex a data. El puntero data se duplica internamente.

X509_EXTENSION_get_object() devuelve el tipo de extensión de ex como un puntero ASN1_OBJECT. El puntero devuelto es un valor interno que no debe liberarse.

X509_EXTENSION_get_critical() comprueba si ex es crítico.

X509_EXTENSION_get_data() devuelve los datos de la extensión ex. El puntero devuelto es un valor interno que no debe liberarse.

X509_supported_extension() comprueba si ex es de un tipo compatible con el verificador. La lista de tipos de extensión compatibles está codificada en la biblioteca. Si una extensión es crítica pero no compatible, el certificado normalmente será rechazado.

Estas funciones manipulan directamente el contenido de una extensión. La mayoría de las aplicaciones querrán analizar o codificar y agregar una extensión: deberían usar las funciones de codificación y decodificación de extensiones en su lugar, como X509_add1_ext_i2d(3) y X509_get_ext_d2i(3).

Los datos asociados con una extensión son la codificación de la extensión en una estructura ASN1_OCTET_STRING.

VALORES DE RETORNO

X509_EXTENSION_new(), X509_EXTENSION_dup(), X509_EXTENSION_create_by_NID(), y X509_EXTENSION_create_by_OBJ() devuelven un puntero X509_EXTENSION o NULL si ocurre un error.

X509_EXTENSION_set_object(), X509_EXTENSION_set_critical(), y X509_EXTENSION_set_data() devuelven 1 para éxito o 0 para fallo.

X509_EXTENSION_get_object() devuelve un puntero ASN1_OBJECT.

X509_EXTENSION_get_critical() devuelve 0 para no crítico o 1 para crítico.

X509_EXTENSION_get_data() devuelve un puntero ASN1_OCTET_STRING.

X509_supported_extension() devuelve 1 si la extensión es compatible, 0 en caso contrario.

DESCRIPTION

X509_EXTENSION_new() allocates and initializes a new X509_EXTENSION structure. It should be freed later using X509_EXTENSION_free().

X509_EXTENSION_free() frees the memory occupied by ex.

X509_EXTENSION_dup() makes a copy of ex.

X509_EXTENSION_create_by_NID() and X509_EXTENSION_create_by_OBJ() create a new extension based on the provided NID (numeric ID) or an ASN1_OBJECT respectively. The value is a string representation of the extension data. If sk is not NULL, the new extension is added to the stack sk. The extension is marked critical if crit is non-zero, otherwise it is non-critical.

X509_EXTENSION_set_object() sets the extension's object identifier to obj.

X509_EXTENSION_set_critical() sets whether the extension is critical or not.

X509_EXTENSION_set_data() sets the extension's data to data of length len.

X509_EXTENSION_get_object() returns the object identifier of the extension ex.

X509_EXTENSION_get_critical() returns 1 if the extension ex is critical, and 0 otherwise.

X509_EXTENSION_get_data() returns the data part of the extension ex as an ASN1_OCTET_STRING pointer.

X509_supported_extension() returns 1 if the type of ex is supported by the verifier or 0 otherwise.
