NOMBRE

libevdev - biblioteca de envoltura para dispositivos evdev

SINOPSIS

#include <libevdev/libevdev.h>

int libevdev_new_from_fd (int fd, struct libevdev **device)

void libevdev_free (struct libevdev *device)

DESCRIPCIÓN

libevdev es una biblioteca de envoltura para dispositivos evdev. Mueve las tareas comunes al tratar con dispositivos evdev a una biblioteca y proporciona una interfaz de biblioteca a los llamadores, evitando así ioctl erróneos, etc.

Esta página del manual es solo un marcador de posición. La documentación para esta versión de libevdev está disponible en:

http://www.freedesktop.org/software/libevdev/doc/1.13.6/

LICENCIA

libevdev tiene licencia bajo la licencia MIT.
