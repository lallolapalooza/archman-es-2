NOMBRE

libinput-test - prueba varios componentes del propio libinput

SINOPSIS

libinput test [--ayuda] <característica> [<argumentos>]

DESCRIPCIÓN

La herramienta libinput test ejecuta pruebas sobre el propio libinput. Normalmente, un usuario no necesita usar esta herramienta, ya que se proporciona a los distribuidores. ¡Esta herramienta ha sido deshabilitada durante la compilación!

Esta es solo una herramienta de prueba, su salida puede cambiar en cualquier momento. No confíe en la salida.

Esta herramienta puede necesitar ejecutarse como root para tener acceso a los nodos /dev/input/eventX y/o crear dispositivos /dev/uinput.

OPCIONES

--ayuda
Imprime la ayuda

CARACTERÍSTICAS

Las pruebas que se pueden ejecutar son:

libinput-test-suite(1)
Ejecuta el conjunto completo de pruebas. Este es el conjunto de pruebas más completo para ejecutar en libinput.
libinput-test-utils
Ejecuta el conjunto de pruebas para funciones internas de utilidad.
