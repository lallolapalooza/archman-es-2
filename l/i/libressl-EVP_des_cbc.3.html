DESCRIPCIÓN

Estas funciones proporcionan el algoritmo de cifrado DES en el framework evp(3). DES es un cifrado de bloque que opera sobre bloques de 64 bits. La longitud de clave a utilizar para EVP_EncryptInit(3) es de 64 bits. Sin embargo, solo 56 de estos bits se utilizan en el algoritmo de cifrado. El bit menos significativo de cada uno de los ocho bytes solo se utiliza para verificar la paridad. Se desaconseja el uso de este algoritmo porque la corta longitud de la clave lo hace vulnerable a ataques de fuerza bruta.

EVP_des_cbc(), EVP_des_cfb1(), EVP_des_cfb8(), EVP_des_cfb64(), EVP_des_ecb(), y EVP_des_ofb() proporcionan DES en modos CBC, CFB con desplazamiento de 1 bit, CFB con desplazamiento de 8 bits, CFB con desplazamiento de 64 bits, ECB y OFB. EVP_des_cfb() es un alias para EVP_des_cfb64(), implementado como una macro.

EVP_des_ede_cbc(), EVP_des_ede_cfb64(), EVP_des_ede_ecb(), y EVP_des_ede_ofb() proporcionan triple DES de dos claves en modos CBC, CFB con desplazamiento de 64 bits, ECB y OFB. EVP_des_ede_cfb() es un alias para EVP_des_ede_cfb64(), implementado como una macro. EVP_des_ede() es un alias para EVP_des_ede_ecb().

EVP_des_ede3_cbc(), EVP_des_ede3_cfb1(), EVP_des_ede3_cfb8(), EVP_des_ede3_cfb64(), EVP_des_ede3_ecb(), EVP_des_ede3_ofb() proporcionan triple DES de tres claves en modos CBC, CFB con desplazamiento de 1 bit, CFB con desplazamiento de 8 bits, CFB con desplazamiento de 64 bits, ECB y OFB. EVP_des_ede3_cfb() es un alias para EVP_des_ede3_cfb64(), implementado como una macro. EVP_des_ede3() es un alias para EVP_des_ede3_ecb().

EVP_desx_cbc() proporciona el algoritmo de cifrado DES-X en modo CBC. Utiliza una longitud de clave de 128 bits y opera sobre bloques de 128 bits.

VALORES DE RETORNO

Estas funciones devuelven una estructura EVP_CIPHER que proporciona la implementación del cifrado simétrico.

DESCRIPTION

These functions provide access to the DES encryption algorithms.

DES is a block cipher with a 64-bit block size and a 56-bit key. It is considered insecure and should not be used.

The different functions correspond to different modes of operation and key lengths:

  • EVP_des_cbc(), EVP_des_cfb(), EVP_des_ecb(), EVP_des_ofb(): These provide the standard DES algorithm with a 56-bit key.
    • EVP_des_cbc(): Cipher Block Chaining (CBC) mode. Requires an IV.
    • EVP_des_cfb(): Cipher Feedback (CFB) mode. Requires an IV.
    • EVP_des_ecb(): Electronic Codebook (ECB) mode. No IV needed.
    • EVP_des_ofb(): Output Feedback (OFB) mode. Requires an IV.
  • EVP_des_ede(), EVP_des_ede_cbc(), EVP_des_ede_cfb(), EVP_des_ede_ofb(): These provide DES-EDE (Double DES) with two 56-bit keys (112-bit effective key length).
    • EVP_des_ede_cbc(): DES-EDE in CBC mode. Requires an IV.
    • EVP_des_ede_cfb(): DES-EDE in CFB mode. Requires an IV.
    • EVP_des_ede_ofb(): DES-EDE in OFB mode. Requires an IV.
  • EVP_des_ede3(), EVP_des_ede3_cbc(), EVP_des_ede3_cfb(), EVP_des_ede3_ofb(): These provide DES-EDE3 (Triple DES) with three 56-bit keys (168-bit effective key length).
    • EVP_des_ede3_cbc(): DES-EDE3 in CBC mode. Requires an IV.
    • EVP_des_ede3_cfb(): DES-EDE3 in CFB mode. Requires an IV.
    • EVP_des_ede3_ofb(): DES-EDE3 in OFB mode. Requires an IV.
  • EVP_desx_cbc(): This provides DESX, a variant of DES that uses a 128-bit key and XORs it with the data before encryption. It is available in CBC mode.
  • EVP_des_ede_ecb() and EVP_des_ede3_ecb(): These provide DES-EDE and DES-EDE3 respectively in ECB mode.
  • EVP_des_cfb1(), EVP_des_cfb8(), EVP_des_cfb64(): These provide DES in CFB mode with 1-bit, 8-bit, and 64-bit feedback respectively.
  • EVP_des_ede_cfb64(): This provides DES-EDE in CFB64 mode.
  • EVP_des_ede3_cfb1(), EVP_des_ede3_cfb8(), EVP_des_ede3_cfb64(): These provide DES-EDE3 in CFB1, CFB8, and CFB64 modes respectively.

These functions are wrappers around the low-level DES implementation and are typically used with the high-level EVP encryption functions like EVP_EncryptInit_ex(), EVP_EncryptUpdate(), EVP_EncryptFinal_ex(), EVP_DecryptInit_ex(), EVP_DecryptUpdate(), and EVP_DecryptFinal_ex().

RETURN VALUES

These functions return a pointer to a static EVP_CIPHER structure that can be used with the high-level EVP interface. The pointer should not be freed.
