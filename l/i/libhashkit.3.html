NOMBRE

libhashkit - Documentación de libhashkit

SINOPSIS

#include <libhashkit-1.0/hashkit.h>
Compilar y enlazar con -lhashkit.

DESCRIPCIÓN

libhashkit es una biblioteca cliente pequeña y segura para hilos que proporciona una colección de algoritmos de hash útiles.

libhashkit se distribuye con libmemcached.

Creación de una estructura hashkit

SINOPSIS

#include <libhashkit-1.0/hashkit.h>
Compilar y enlazar con -lhashkit
typedef struct hashkit_st hashkit_st
hashkit_st *hashkit_create(hashkit_st *hash)
Parámetros
hash -- dirección de memoria de una estructura hashkit_st; si se pasa un valor nulo, la estructura se asignará dinámicamente mediante libhashkit
Devuelve
puntero a la estructura hashkit_st inicializada
hashkit_st *hashkit_clone(hashkit_st *destination, const hashkit_st *ptr)
Parámetros
  • destination -- dirección de memoria de una estructura hashkit_st; si se pasa un valor nulo, la estructura se asignará dinámicamente mediante libhashkit
  • ptr -- puntero a la estructura hashkit_st a copiar
Devuelve
puntero a una estructura hashkit_st (destination, si no es nulo), inicializada a partir de ptr
void hashkit_free(hashkit_st *hash)
Parámetros
hash -- puntero a una estructura hashkit_st inicializada
bool hashkit_is_allocated(const hashkit_st *hash)
Parámetros
hash -- puntero a una estructura hashkit_st inicializada
Devuelve
booleano, si la estructura hash fue asignada dinámicamente

DESCRIPCIÓN

La función hashkit_create() inicializa un objeto hashkit para su uso. Si pasas un argumento nulo para hash, entonces la memoria para el objeto se asignará. Si especificas un bloque de memoria preasignado, este se inicializará para su uso.

La función hashkit_clone() inicializa un objeto hashkit de manera similar a hashkit_create(), pero en lugar de usar la configuración predeterminada, utilizará la configuración del objeto hashkit apuntado por ptr.

La función hashkit_free() libera cualquier recurso que esté siendo consumido por los objetos hashkit que fueron inicializados con hashkit_create() o hashkit_clone().

La función hashkit_is_allocated() informa si la memoria fue asignada para un objeto hashkit.

VALOR DEVUELTO

hashkit_create() y hashkit_clone() devolverán nulo en caso de fallo o un puntero a hashkit_st en caso de éxito.

hashkit_is_allocated() devuelve verdadero si la memoria para el objeto hashkit fue asignada dentro de hashkit_create() o hashkit_clone(), de lo contrario es falso y se trataba de memoria suministrada por el usuario.

NAME

hashkit_value - Generate hash value

LIBRARY

libhashkit, -lhashkit

SYNOPSIS

#include <libhashkit-1.0/hashkit.h>
Compile and link with -lhashkit
uint32_t hashkit_value(hashkit_st *hash, const char *key, size_t key_length);
Parameters
  • hash -- pointer to an initialized hashkit_st struct
  • key -- the key to generate a hash of
  • key_length -- the length of the key without any terminating zero byte

DESCRIPTION

The hashkit_value() function generates a 32-bit hash value from the given key and key_length. The hash argument is an initialized hashkit object, and distribution type and hash function is used from this object while generating the value.

RETURN VALUE

A 32-bit hash value.
