libressl-ERR_error_string(3)

Paquete: libressl

Licencias: ISC, custom:OpenSSL

ERR_ERROR_STRING(3) Manual de funciones de biblioteca ERR_ERROR_STRING(3)

NOMBRE

ERR_error_string, ERR_error_string_n, ERR_lib_error_string, ERR_func_error_string, ERR_reason_error_string — obtener mensajes de error de OpenSSL legibles por humanos

SINOPSIS

biblioteca “libcrypto”
#include <openssl/err.h>

char *
ERR_error_string(unsigned long e, char *buf);

void
ERR_error_string_n(unsigned long e, char *buf, size_t len);

const char *
ERR_lib_error_string(unsigned long e);

const char *
ERR_func_error_string(unsigned long e);

const char *
ERR_reason_error_string(unsigned long e);

DESCRIPCIÓN

ERR_error_string() genera una cadena legible por humanos que representa el código de error e y la coloca en buf. buf debe tener al menos 256 bytes de longitud. Si buf es NULL, la cadena de error se coloca en un búfer estático. Tenga en cuenta que esta función no es segura para hilos y no realiza comprobaciones sobre el tamaño del búfer; use ERR_error_string_n() en su lugar.

ERR_error_string_n() es una variante de ERR_error_string() que escribe como máximo len caracteres (incluyendo el carácter nulo de terminación) y trunca la cadena si es necesario. Para ERR_error_string_n(), buf no puede ser NULL.

La cadena tendrá el siguiente formato:

error:[código de error]:[nombre de la biblioteca]:[nombre de la función]:[cadena de razón]

El código de error es un número hexadecimal de 8 dígitos. El nombre de la biblioteca, el nombre de la función y la cadena de razón son texto ASCII.

ERR_lib_error_string(), ERR_func_error_string(), y ERR_reason_error_string() devuelven el nombre de la biblioteca, el nombre de la función y la cadena de razón, respectivamente.

Las cadenas de error de OpenSSL deben cargarse llamando primero a ERR_load_crypto_strings(3) o, para aplicaciones SSL, a SSL_load_error_strings(3). Si no hay una cadena de texto registrada para el código de error dado, la cadena de error contendrá el código numérico.

ERR_print_errors(3) puede usarse para imprimir todos los códigos de error actualmente en la cola.

VALORES DE RETORNO

ERR_error_string() devuelve un puntero a un búfer estático que contiene la cadena si buf es NULL, o buf en caso contrario.

ERR_lib_error_string(), ERR_func_error_string(), y ERR_reason_error_string() devuelven las cadenas, o NULL si no hay ninguna registrada para el código de error.

VER TAMBIÉN

ERR(3), ERR_get_error(3), ERR_load_crypto_strings(3), ERR_print_errors(3), SSL_load_error_strings(3)

HISTORIA

ERR_error_string(), ERR_lib_error_string(), ERR_func_error_string(), y ERR_reason_error_string() aparecieron por primera vez en SSLeay 0.4.4 y han estado disponibles desde OpenBSD 2.4.

ERR_error_string_n() apareció por primera vez en OpenSSL 0.9.6 y ha estado disponible desde OpenBSD 2.9.
