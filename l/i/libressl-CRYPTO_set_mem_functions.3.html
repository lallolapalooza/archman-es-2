libressl-CRYPTO_set_mem_functions(3)

Paquete: libressl

Licencias: ISC, custom:OpenSSL

CRYPTO_SET_MEM_FUNCTIONS(3) Manual de funciones de la biblioteca CRYPTO_SET_MEM_FUNCTIONS(3)

NOMBRE

CRYPTO_set_mem_functions, CRYPTO_mem_ctrl, CRYPTO_mem_leaks, CRYPTO_mem_leaks_fp, CRYPTO_mem_leaks_cb — control de asignación de memoria de OpenSSL heredado

SINOPSIS

biblioteca “libcrypto”
#include <openssl/crypto.h>

int
CRYPTO_set_mem_functions(void *(*m)(size_t, const char *, int), void *(*r)(void *, size_t, const char *, int), void (*f)(void *, const char *, int));

int
CRYPTO_mem_ctrl(int mode);

int
CRYPTO_mem_leaks(BIO *b);

int
CRYPTO_mem_leaks_fp(FILE *fp);

typedef int *
CRYPTO_MEM_LEAK_CB(unsigned long, const char *, int, int, void *);

int
CRYPTO_mem_leaks_cb(CRYPTO_MEM_LEAK_CB *cb);

DESCRIPCIÓN

No utilice ninguna de las interfaces documentadas aquí. Se proporcionan puramente para compatibilidad con código de aplicación heredado.

CRYPTO_set_mem_functions(), CRYPTO_mem_ctrl(), CRYPTO_mem_leaks(), CRYPTO_mem_leaks_fp(), y CRYPTO_mem_leaks_cb() no tienen ningún efecto.

VALORES DE RETORNO

CRYPTO_set_mem_functions() siempre retorna 0.

CRYPTO_mem_ctrl() siempre retorna CRYPTO_MEM_CHECK_OFF.

CRYPTO_mem_leaks(), CRYPTO_mem_leaks_fp(), y CRYPTO_mem_leaks_cb() siempre retornan -1.

VER TAMBIÉN

crypto(3)

HISTORIA

CRYPTO_mem_ctrl(), CRYPTO_mem_leaks(), y CRYPTO_mem_leaks_fp() aparecieron por primera vez en SSLeay 0.6.4. CRYPTO_set_mem_functions() apareció por primera vez en SSLeay 0.6.5. CRYPTO_mem_leaks_cb() apareció por primera vez en SSLeay 0.6.6. Todas estas funciones han estado disponibles desde OpenBSD 2.4.
