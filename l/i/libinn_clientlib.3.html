libinn_clientlib(3) Documentación de InterNetNews libinn_clientlib(3)

NOMBRE

clientlib - parte clientlib de NNTP de la biblioteca libinn de InterNetNews

SINOPSIS

#include <inn/libinn.h>
extern FILE *ser_rd_fp;
extern FILE *ser_wr_fp;
extern char ser_line[];
extern char *getserverbyfile(char *file UNUSED);
extern int server_init(char *host, int port);
extern int handle_server_response(int response, char *host);
extern void put_server(const char *text);
extern int get_server(char *buff, int buffsize);
extern void close_server(void);

DESCRIPCIÓN

Las rutinas descritas en esta página del manual forman parte de la biblioteca InterNetNews, libinn(3). Son reemplazos para la parte clientlib de la distribución NNTP, y están destinadas a ser utilizadas en la construcción de clientes de noticias.

La función getserverbyfile recupera el valor del parámetro server en inn.conf (o el valor de la variable de entorno "NNTPSERVER" si está configurada) como el nombre del servidor NNTP local. Devuelve un puntero a espacio estático. El parámetro file se ignora (inn.conf es forzado).

La función server_init abre una conexión al servidor NNTP en el host especificado, en modo lector. Devuelve el código de respuesta del servidor o "-1" en caso de error. Si se estableció una conexión, entonces ser_rd_fp y ser_wr_fp se pueden usar para leer y escribir desde y hacia el servidor, respectivamente, y ser_line contendrá la respuesta del servidor (aunque debería usar las funciones más convenientes put_server y get_server en su lugar).

La función handle_server_response decodifica el código response, que proviene del servidor en host. Si el cliente está autorizado, devuelve 0. Un cliente que solo tiene permitido leer está autorizado, pero handle_server_response imprimirá un mensaje en la salida estándar. Si el cliente no está autorizado para hablar con el servidor, se imprime un mensaje y la rutina devuelve "-1".

La función put_server envía text al servidor, agregando los terminadores de línea NNTP necesarios y vaciando el búfer de E/S.

La función get_server lee una línea de texto del servidor en buff, leyendo como máximo buffsize caracteres. Cualquier terminador "\r\n" final se elimina. get_server devuelve "-1" en caso de error, 0 en caso de éxito.

La función close_server envía un comando "QUIT" al servidor y cierra la conexión.
