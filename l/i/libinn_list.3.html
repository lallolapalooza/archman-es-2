libinn_list(3)

Licencias: custom:INN

libinn_list(3) Documentación de InterNetNews libinn_list(3)

NOMBRE

list - rutinas de lista

SINOPSIS

#include <inn/list.h>
struct node {
    struct node *succ;
    struct node *pred;
};
struct list {
    struct node *head;
    struct node *tail;
    struct node *tailpred;
};
void list_new(struct list *list);
struct node *list_addhead(struct list *list, struct node *node);
struct node *list_addtail(struct list *list, struct node *node);
struct node *list_head(struct list *list);
struct node *list_tail(struct list *list);
struct node *list_succ(struct node *node);
struct node *list_pred(struct node *node);
struct node *list_remhead(struct list *list);
struct node *list_remtail(struct list *list);
struct node *list_remove(struct node *node);
struct node *list_insert(struct list *list, struct node *node,
                         struct node *pred);
bool list_isempty(struct list *list);

DESCRIPCIÓN

list_new inicializa la cabecera de lista list para crear una lista vacía.

list_addhead añade node a la cabeza de list, devolviendo el nodo recién añadido.

list_addtail añade node a la cola de list, devolviendo el nodo recién añadido.

list_head devuelve un puntero al nodo en la cabeza de list o NULL si la lista está vacía.

list_tail devuelve un puntero al nodo en la cola de list o NULL si la lista está vacía.

list_succ devuelve el siguiente nodo (sucesor) en la lista después de node o NULL si node era el último nodo.

list_pred devuelve el nodo anterior (predecesor) en la lista antes de node o NULL si node era el primer nodo.

list_remhead elimina el primer nodo de list y lo devuelve al llamador. Si la lista está vacía se devuelve NULL.

list_remtail elimina el último nodo de list y lo devuelve al llamador. Si la lista está vacía se devuelve NULL.

list_remove elimina node de la lista en la que se encuentra y lo devuelve al llamador.

list_insert inserta node en list después del nodo pred. Si pred es NULL, entonces node se añade a la cabeza de list.
