DESCRIPCIÓN

Estas funciones decodifican y codifican estructuras de X.509 usadas para el protocolo de marca de tiempo. Para detalles sobre la semántica, ejemplos, advertencias y errores, ver ASN1_item_d2i(3).

d2i_TS_REQ() y i2d_TS_REQ() decodifican y codifican una estructura TimeStampReq ASN.1 definida en la RFC 3161 sección 2.4.1. d2i_TS_REQ_bio(), i2d_TS_REQ_bio(), d2i_TS_REQ_fp(), y i2d_TS_REQ_fp() son similares excepto que decodifican o codifican usando un puntero BIO o FILE.

d2i_TS_RESP() y i2d_TS_RESP() decodifican y codifican una estructura TimeStampResp ASN.1 definida en la RFC 3161 sección 2.4.2. d2i_TS_RESP_bio(), i2d_TS_RESP_bio(), d2i_TS_RESP_fp(), y i2d_TS_RESP_fp() son similares excepto que decodifican o codifican usando un puntero BIO o FILE.

d2i_TS_STATUS_INFO() y i2d_TS_STATUS_INFO() decodifican y codifican una estructura TS_STATUS_INFO ASN.1 definida en la RFC 3161 sección 3.4.

d2i_TS_TST_INFO() y i2d_TS_TST_INFO() decodifican y codifican una estructura TSTInfo ASN.1 definida en la RFC 3161 sección 3.6. d2i_TS_TST_INFO_bio(), i2d_TS_TST_INFO_bio(), d2i_TS_TST_INFO_fp(), y i2d_TS_TST_INFO_fp() son similares excepto que decodifican o codifican usando un puntero BIO o FILE.

d2i_TS_ACCURACY() y i2d_TS_ACCURACY() decodifican y codifican una estructura Accuracy ASN.1 definida en la RFC 3161 sección 3.6.

d2i_TS_MSG_IMPRINT() y i2d_TS_MSG_IMPRINT() decodifican y codifican una estructura MessageImprint ASN.1 definida en la RFC 3161 sección 3.6. d2i_TS_MSG_IMPRINT_bio(), i2d_TS_MSG_IMPRINT_bio(), d2i_TS_MSG_IMPRINT_fp(), y i2d_TS_MSG_IMPRINT_fp() son similares excepto que decodifican o codifican usando un puntero BIO o FILE.

VALOR DEVUELTO

d2i_*() devuelve un puntero a la estructura descodificada, o NULL si ocurre un error.

i2d_*() devuelve el número de bytes escritos en der_out, o un valor negativo si ocurre un error.

Las funciones que usan BIO o FILE devuelven 1 en caso de éxito, y 0 en caso de error.

DESCRIPTION

The Time-Stamp Protocol (TSP) is defined in RFC 3161. The functions described here provide ASN.1 encoding and decoding support for the various structures defined by the protocol.

d2i_TS_TS_REQ() and i2d_TS_REQ() decode and encode an ASN.1 TS_REQ structure defined in RFC 3161 section 3.4.

d2i_TS_REQ_bio(), i2d_TS_REQ_bio(), d2i_TS_REQ_fp(), and i2d_TS_REQ_fp() are similar except that they decode or encode using a BIO or FILE pointer.

d2i_TS_RESP() and i2d_TS_RESP() decode and encode an ASN.1 TS_RESP structure defined in RFC 3161 section 3.4.

d2i_TS_RESP_bio(), i2d_TS_RESP_bio(), d2i_TS_RESP_fp(), and i2d_TS_RESP_fp() are similar except that they decode or encode using a BIO or FILE pointer.

d2i_TS_STATUS_INFO() and i2d_TS_STATUS_INFO() decode and encode an ASN.1 PKIStatusInfo structure defined in RFC 3161 section 2.4.2.

d2i_TS_TST_INFO() and i2d_TS_TST_INFO() decode and encode an ASN.1 TSTInfo structure defined in RFC 3161 section 2.4.2. d2i_TS_TST_INFO_bio(), i2d_TS_TST_INFO_bio(), d2i_TS_TST_INFO_fp(), and i2d_TS_TST_INFO_fp() are similar except that they decode or encode using a BIO or FILE pointer.

d2i_TS_ACCURACY() and i2d_TS_ACCURACY() decode and encode an ASN.1 Accuracy structure defined in RFC 3161 section 2.4.2.

d2i_TS_MSG_IMPRINT() and i2d_TS_MSG_IMPRINT() decode and encode an ASN.1 MessageImprint structure defined in RFC 3161 section 2.4.1. d2i_TS_MSG_IMPRINT_bio(), i2d_TS_MSG_IMPRINT_bio(), d2i_TS_MSG_IMPRINT_fp(), and i2d_TS_MSG_IMPRINT_fp() are similar except that they decode or encode using a BIO or FILE pointer.

RETURN VALUES

d2i_TS_REQ(), d2i_TS_REQ_bio(), d2i_TS_REQ_fp(), d2i_TS_RESP(), d2i_TS_RESP_bio(), d2i_TS_RESP_fp(), d2i_TS_STATUS_INFO(), d2i_TS_TST_INFO(), d2i_TS_TST_INFO_bio(), d2i_TS_TST_INFO_fp(), d2i_TS_ACCURACY(), d2i_TS_MSG_IMPRINT(), d2i_TS_MSG_IMPRINT_bio(), and d2i_TS_MSG_IMPRINT_fp() return an object of the respective type or NULL if an error occurs.

i2d_TS_REQ(), i2d_TS_RESP(), i2d_TS_STATUS_INFO(), i2d_TS_TST_INFO(), i2d_TS_ACCURACY(), and i2d_TS_MSG_IMPRINT() return the number of bytes successfully encoded or a negative value if an error occurs.

i2d_TS_REQ_bio(), i2d_TS_REQ_fp(), i2d_TS_RESP_bio(), i2d_TS_RESP_fp(), i2d_TS_TST_INFO_bio(), i2d_TS_TST_INFO_fp(), i2d_TS_MSG_IMPRINT_bio(), and i2d_TS_MSG_IMPRINT_fp() return 1 for success or 0 if an error occurs.
