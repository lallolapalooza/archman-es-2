libressl-EVP_PKEY_asn1_get_count(3)

Paquete: libressl

Licencias: ISC, custom:OpenSSL

EVP_PKEY_ASN1_GET_COUNT(3) Manual de funciones de biblioteca EVP_PKEY_ASN1_GET_COUNT(3)

NOMBRE

EVP_PKEY_asn1_get_count, EVP_PKEY_asn1_get0, EVP_PKEY_get0_asn1, EVP_PKEY_asn1_find, EVP_PKEY_asn1_find_str, EVP_PKEY_asn1_get0_info — enumerar métodos ASN.1 de clave pública

SINOPSIS

biblioteca “libcrypto”
#include <openssl/evp.h>

int
EVP_PKEY_asn1_get_count(void);

const EVP_PKEY_ASN1_METHOD *
EVP_PKEY_asn1_get0(int idx);

const EVP_PKEY_ASN1_METHOD *
EVP_PKEY_get0_asn1(const EVP_PKEY *pkey);

const EVP_PKEY_ASN1_METHOD *
EVP_PKEY_asn1_find(ENGINE **engine, int type);

const EVP_PKEY_ASN1_METHOD *
EVP_PKEY_asn1_find_str(ENGINE **engine, const char *str, int len);

int
EVP_PKEY_asn1_get0_info(int *ppkey_id, int *pkey_base_id, int *ppkey_flags, const char **pinfo, const char **ppem_str, const EVP_PKEY_ASN1_METHOD *ameth);

DESCRIPCIÓN

EVP_PKEY_asn1_get_count() devuelve el número de métodos ASN.1 de clave pública disponibles.

EVP_PKEY_asn1_get0() devuelve el método ASN.1 de clave pública idx. El valor de idx debe estar en el rango de cero a EVP_PKEY_asn1_get_count() - 1.

EVP_PKEY_asn1_find() busca el método con NID type, que puede ser cualquiera de los valores que EVP_PKEY_base_id(3) y EVP_PKEY_id(3) pueden devolver. Si engine no es NULL, *engine se establece en NULL.

EVP_PKEY_asn1_find_str() busca el método con la cadena de tipo PEM dada por los primeros len bytes de str. Si len es -1, se utiliza la longitud de strlen(3) de str en su lugar. Las cadenas de tipo PEM compatibles de forma predeterminada se enumeran en la página del manual de EVP_PKEY_base_id(3). Al igual que EVP_PKEY_asn1_find(), si engine no es NULL, *engine se establece en NULL.

EVP_PKEY_asn1_get0_info() recupera el ID de clave pública devuelto por EVP_PKEY_id(3), el ID de clave pública base devuelto por EVP_PKEY_base_id(3) (ambos NIDs), cualquier bandera y punteros internos propiedad de ameth que apuntan a su cadena de descripción de método y a su cadena de tipo PEM.

Los siguientes bits de bandera pueden ocurrir, combinados con OR, en *ppkey_flags:

ASN1_PKEY_ALIAS
Este objeto ameth sirve como un alias para otro objeto EVP_PKEY_ASN1_METHOD y nunca será devuelto por EVP_PKEY_asn1_find() o EVP_PKEY_asn1_find_str().
ASN1_PKEY_DYNAMIC
Esta bandera no se utiliza. Anteriormente se podía usar para marcar un objeto ameth como asignado dinámicamente.
ASN1_PKEY_SIGPARAM_NULL
Si el contexto de firma (ctx) utiliza una clave privada EVP_PKEY asociada con este ameth, indica a ASN1_item_sign_ctx(3) que utilice un tipo de parámetro V_ASN1_NULL en lugar de V_ASN1_UNDEF por defecto al codificar los objetos AlgorithmIdentifier ASN.1 con X509_ALGOR_set0(3). En particular, esto se usa para EVP_PKEY_RSA.

VALORES DE RETORNO

EVP_PKEY_asn1_get_count() devuelve el número de métodos de clave pública disponibles.

EVP_PKEY_asn1_get0() devuelve un método de clave pública o NULL si idx está fuera de rango.

EVP_PKEY_get0_asn1() devuelve el método de clave pública utilizado por pkey.

EVP_PKEY_asn1_find() y EVP_PKEY_asn1_find_str() devuelven un método de clave pública coincidente o NULL si no se encuentra ninguna coincidencia.

EVP_PKEY_asn1_get0_info() devuelve 1 si tiene éxito o 0 si falla.

VER TAMBIÉN

EVP_PKEY_base_id(3), EVP_PKEY_new(3)

HISTORIA

Estas funciones aparecieron por primera vez en OpenSSL 1.0.0 y han estado disponibles desde OpenBSD 4.9.
