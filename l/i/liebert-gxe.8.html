NOMBRE

liebert-gxe - Controlador para UPS de la serie Liebert GXE, usando el protocolo serie YDN23

SINOPSIS

liebert-gxe -h

liebert-gxe -a NOMBRE_UPS [OPCIONES]


Nota

Esta página del manual solo documenta las características específicas del hardware del controlador liebert-gxe. Para obtener información sobre el controlador principal, consulte nutupsdrv(8).

HARDWARE SOPORTADO

Probado para funcionar en las siguientes unidades:

•Liebert GXE 01k00TS1101C00

Nota
Esta UPS tiene un puerto RS-232 y un puerto USB. El puerto USB tiene una interfaz ACM que funciona como un puerto serie para el sistema operativo anfitrión. Ambos puertos pueden usarse para gestionar el dispositivo.

Este es un controlador experimental. Usted ha sido advertido.

ARGUMENTOS ADICIONALES

Este controlador admite las siguientes configuraciones opcionales en ups.conf(5):

addr=núm

Establece la dirección de la UPS — 01 (predeterminado) ~ 99.

retry=núm

Establece el número máximo de fallos de lectura. (La UPS a veces ignora el comando entrante y provoca que el controlador se quede colgado. El controlador ignorará los fallos de retry si ocurren en secuencia. Sin embargo, esto aumenta la latencia si ocurre un verdadero cuelgue. El valor predeterminado es 3)
