Documentación de estructuras de datos

struct alpm_pgpkey_t

Una clave PGP.

Campos de datos:

alpm_time_t created Cuándo se creó la clave.

void * data Los datos reales de la clave.

char * email Correo electrónico del propietario de la clave.

alpm_time_t expires Cuándo expira la clave.

char * fingerprint La huella digital de la clave.

unsigned int length La longitud de la clave.

char * name Nombre del propietario de la clave.

char pubkey_algo Un carácter que representa el algoritmo de cifrado utilizado por la clave pública.
? = desconocido R = RSA D = DSA E = EDDSA

unsigned int revoked ¿ha sido revocada la clave?

char * uid UID de la clave.

struct alpm_sigresult_t

Resultado de la firma.

Contiene la clave, el estado y la validez de una firma dada.

Campos de datos:

alpm_pgpkey_t key La clave de la firma.

alpm_sigstatus_t status El estado de la firma.

alpm_sigvalidity_t validity La validez de la firma.

struct alpm_siglist_t

Lista de firmas.

Contiene el número de firmas encontradas y un puntero a una matriz de resultados. La matriz es de tamaño count.

Campos de datos:

size_t count La cantidad de resultados en la matriz.

alpm_sigresult_t * results Una matriz de resultados de firma.

Documentación de tipos de enumeración

enum alpm_siglevel_t

Opciones de verificación de firmas PGP.

Enumerador

ALPM_SIG_PACKAGE
Los paquetes requieren una firma.
ALPM_SIG_PACKAGE_OPTIONAL
Los paquetes no requieren una firma, pero verifican los paquetes que sí tienen firmas.
ALPM_SIG_PACKAGE_MARGINAL_OK
Permite paquetes con firmas de confianza marginal.
ALPM_SIG_PACKAGE_UNKNOWN_OK
Permite paquetes con firmas de confianza desconocida.
ALPM_SIG_DATABASE
Las bases de datos requieren una firma.
ALPM_SIG_DATABASE_OPTIONAL
Las bases de datos no requieren una firma, pero verifican las bases de datos que sí tienen firmas.
ALPM_SIG_DATABASE_MARGINAL_OK
Permite bases de datos con firmas de confianza marginal.
ALPM_SIG_DATABASE_UNKNOWN_OK
Permite bases de datos con firmas de confianza desconocida.
ALPM_SIG_USE_DEFAULT
El siglevel por defecto.

enum alpm_sigstatus_t

Códigos de retorno de la verificación de firmas PGP.

Enumerador

ALPM_SIGSTATUS_VALID
La firma es válida.
ALPM_SIGSTATUS_KEY_EXPIRED
La clave ha expirado.
ALPM_SIGSTATUS_SIG_EXPIRED
La firma ha expirado.
ALPM_SIGSTATUS_KEY_UNKNOWN
La clave no está en el llavero.
ALPM_SIGSTATUS_KEY_DISABLED
La clave ha sido deshabilitada.
ALPM_SIGSTATUS_INVALID
La firma no es válida.

enum alpm_sigvalidity_t

El nivel de confianza de una clave PGP.

Enumerador

ALPM_SIGVALIDITY_FULL
La firma tiene plena confianza.
ALPM_SIGVALIDITY_MARGINAL
La firma tiene confianza marginal.
ALPM_SIGVALIDITY_NEVER
La firma nunca tiene confianza.
ALPM_SIGVALIDITY_UNKNOWN
La firma tiene confianza desconocida.

Documentation de la función

int alpm_db_check_pgp_signature (alpm_db_t * db, alpm_siglist_t * siglist)

Comprueba la firma PGP de la base de datos dada.

Parámetros

db la base de datos a comprobar
siglist un puntero al almacenamiento de los resultados de la firma

Devuelve

0 si es válida, -1 si se produjo un error o la firma no es válida

int alpm_decode_signature (const char * base64_data, unsigned char ** data, size_t * data_len)

Decodifica una firma cargada en formato base64.

Parámetros

base64_data la firma que se intenta decodificar
data los datos decodificados; deben ser liberados por el llamador
data_len la longitud de los datos devueltos

Devuelve

0 si tiene éxito, -1 si falla la decodificación correcta

int alpm_extract_keyid (alpm_handle_t * handle, const char * identifier, const unsigned char * sig, const size_t len, alpm_list_t ** keys)

Extrae el ID de clave del emisor de una firma.

Parámetros

handle el manejador del contexto
identifier el identificador de la clave. Puede ser el nombre del paquete o la ruta del paquete.
sig firma PGP
len longitud de la firma
keys un puntero al almacenamiento de los IDs de clave

Devuelve

0 si tiene éxito, -1 si hay un error

int alpm_pkg_check_pgp_signature (alpm_pkg_t * pkg, alpm_siglist_t * siglist)

Comprueba la firma PGP del archivo de paquete dado.

Parámetros

pkg el paquete a comprobar
siglist un puntero al almacenamiento de los resultados de la firma

Devuelve

0 si es válida, -1 si se produjo un error o la firma no es válida

int alpm_siglist_cleanup (alpm_siglist_t * siglist)

Limpia y libera una lista de resultados de firma. Nota: esto no libera el objeto siglist en sí en caso de que se haya asignado en la pila; esto es responsabilidad del llamador.

Parámetros

siglist un puntero al almacenamiento de resultados de firma

Devuelve

0 si tiene éxito, -1 si hay un error
