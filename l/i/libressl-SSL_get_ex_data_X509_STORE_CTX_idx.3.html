SSL_GET_EX_DATA_X509_STORE_CTX_IDX(3) Manual de funciones de biblioteca SSL_GET_EX_DATA_X509_STORE_CTX_IDX(3)

NOMBRE

SSL_get_ex_data_X509_STORE_CTX_idx — obtener el índice ex_data para acceder a la estructura SSL desde X509_STORE_CTX

SINOPSIS

biblioteca “libssl” libcrypto
#include <openssl/ssl.h>

int
SSL_get_ex_data_X509_STORE_CTX_idx(void);

DESCRIPCIÓN

SSL_get_ex_data_X509_STORE_CTX_idx() devuelve el número de índice bajo el cual se almacena el puntero al objeto SSL en el objeto X509_STORE_CTX.

Cada vez que se crea un objeto X509_STORE_CTX para la verificación del certificado del par durante un handshake, se almacena un puntero al objeto SSL en el objeto X509_STORE_CTX para identificar la conexión afectada. Para recuperar este puntero, se puede utilizar la función X509_STORE_CTX_get_ex_data(3) con el índice correcto. Este índice es globalmente el mismo para todos los objetos X509_STORE_CTX y se puede recuperar utilizando SSL_get_ex_data_X509_STORE_CTX_idx(). El valor del índice se establece cuando SSL_get_ex_data_X509_STORE_CTX_idx() se llama por primera vez, ya sea directamente por el programa de aplicación o indirectamente durante otras funciones de configuración de SSL o durante el handshake.

El valor depende de otros valores de índice definidos para objetos X509_STORE_CTX antes de que se cree el índice SSL.

VALORES DE RETORNO

≥0
El valor del índice para acceder al puntero.
<0
Ocurrió un error, consulte la pila de errores para obtener un mensaje de error detallado.

EJEMPLOS

El índice devuelto por SSL_get_ex_data_X509_STORE_CTX_idx() proporciona acceso al objeto SSL para la conexión durante el verify_callback() al verificar el certificado del par. Consulte el ejemplo en SSL_CTX_set_verify(3).

VER TAMBIÉN

CRYPTO_set_ex_data(3), ssl(3), SSL_CTX_set_verify(3)

HISTORIAL

SSL_get_ex_data_X509_STORE_CTX_idx() apareció por primera vez en SSLeay 0.9.1 y ha estado disponible desde OpenBSD 2.6.
