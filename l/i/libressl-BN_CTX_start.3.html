libressl-BN_CTX_start(3)

Paquete: libressl

Licencias: ISC, custom:OpenSSL

BN_CTX_START(3) Manual de Funciones de Biblioteca BN_CTX_START(3)

NOMBRE

BN_CTX_start, BN_CTX_get, BN_CTX_end — uso de variables BIGNUM temporales

SINOPSIS

biblioteca “libcrypto”
#include <openssl/bn.h>

void
BN_CTX_start(BN_CTX *ctx);

BIGNUM *
BN_CTX_get(BN_CTX *ctx);

void
BN_CTX_end(BN_CTX *ctx);

DESCRIPCIÓN

Estas funciones se utilizan para obtener variables BIGNUM temporales de un BN_CTX (que se puede crear usando BN_CTX_new(3)) con el fin de ahorrar la sobrecarga de crear y liberar repetidamente BIGNUMs en funciones que se llaman desde dentro de un bucle.

Una función debe llamar primero a BN_CTX_start(). Luego, se puede llamar a BN_CTX_get() repetidamente para obtener BIGNUMs temporales. Todas las llamadas a BN_CTX_get() deben hacerse antes de llamar a cualquier otra función que utilice ctx como argumento.

Finalmente, se debe llamar a BN_CTX_end() antes de regresar de la función. Cuando se llama a BN_CTX_end(), los punteros BIGNUM obtenidos de BN_CTX_get() se invalidan. Si ctx es NULL, no ocurre ninguna acción.

VALORES DE RETORNO

BN_CTX_get() devuelve un puntero al BIGNUM, o NULL en caso de error. Una vez que BN_CTX_get() ha fallado, las llamadas posteriores también devolverán NULL, por lo que es suficiente comprobar el valor de retorno de la última llamada a BN_CTX_get(). En caso de error, se establece un código de error que se puede obtener con ERR_get_error(3).

VER TAMBIÉN

BN_CTX_new(3), BN_new(3)

HISTORIA

BN_CTX_start(), BN_CTX_get(), y BN_CTX_end() aparecieron por primera vez en OpenSSL 0.9.5 y han estado disponibles desde OpenBSD 2.7.
