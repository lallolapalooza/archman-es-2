NOMBRE

libcurl-share - cómo usar la interfaz de compartición (share)

DESCRIPCIÓN

Esta es una descripción general sobre cómo usar la interfaz de compartición (share) de libcurl en sus programas C. Hay páginas de manual específicas para cada función mencionada aquí.

Todas las funciones de la interfaz de compartición tienen el prefijo curl_share.

OBJETIVOS

La interfaz de compartición se agregó para permitir compartir datos entre manejadores (handles) de curl.

UN CONJUNTO DE DATOS - MUCHAS TRANSFERENCIAS

Puede tener múltiples manejadores (handles) fáciles compartiendo datos entre ellos. Haga que actualicen y usen la base de datos de cookies misma, la caché de DNS, la caché de sesiones TLS y/o la caché de conexiones. De esta manera, cada transferencia individual se beneficia de las actualizaciones de datos realizadas por las otras transferencias.

OBJETO DE COMPARTICIÓN

Crea un objeto compartido con curl_share_init(3). Devuelve un manejador para uno recién creado.

Le dice al objeto compartido qué datos quiere que comparta usando curl_share_setopt(3).

Dado que puede usar esta compartición desde múltiples hilos (threads) y libcurl no tiene sincronización interna de hilos, debe proporcionar callbacks de mutex si está usando esto multi-hilo. Establece funciones de bloqueo (lock) y desbloqueo (unlock) también con curl_share_setopt(3).

Luego, para hacer que un manejador (handle) fácil use esta compartición, establece la opción CURLOPT_SHARE(3) con curl_easy_setopt(3) y pasa el manejador de compartición. Puede hacer que cualquier número de manejadores fáciles comparta el mismo manejador de compartición.

Para hacer que un manejador fácil deje de usar esa compartición particular, establece CURLOPT_SHARE(3) a NULL para ese manejador fácil. Para hacer que un manejador deje de compartir datos particulares, puede usar CURLSHOPT_UNSHARE(3).

Cuando haya terminado de usar la compartición, asegúrese de que ningún manejador fácil la esté usando todavía, y llame a curl_share_cleanup(3) sobre el manejador.

VER TAMBIÉN

curl_share_cleanup(3), curl_share_init(3), curl_share_setopt(3), libcurl-easy(3), libcurl-errors(3), libcurl-multi(3)
