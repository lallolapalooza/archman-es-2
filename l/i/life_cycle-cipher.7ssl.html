NOMBRE

life_cycle-cipher - El ciclo de vida del algoritmo de cifrado

DESCRIPCIÓN

Todos los cifrados simétricos (CIPHERs) pasan por una serie de etapas en su ciclo de vida:

inicio
Este estado representa el CIFRADOR antes de haber sido asignado. Es el estado inicial para cualquier transición de ciclo de vida.
creado
Este estado representa el CIFRADOR después de haber sido asignado.
inicializado
Estos estados representan el CIFRADOR cuando está configurado y es capaz de procesar entrada. Hay tres estados inicializados posibles:
inicializado usando EVP_CipherInit
inicializado para desencriptación usando EVP_DecryptInit
inicializado para encriptación usando EVP_EncryptInit
actualizado
Estos estados representan el CIFRADOR cuando está configurado y es capaz de procesar entrada adicional o generar salida. Los tres estados posibles corresponden directamente a los de inicializado anteriormente. Los tres flujos diferentes no deben mezclarse.
finalizado
Este estado representa el CIFRADOR cuando ha generado salida.
liberado
Se entra en este estado cuando el CIFRADOR es liberado. Es el estado terminal para todas las transiciones del ciclo de vida.
