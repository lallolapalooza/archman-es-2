libressl-RSA_set_method(3)

Paquete: libressl

Licencias: ISC, custom:OpenSSL

RSA_SET_METHOD(3) Manual de funciones de biblioteca RSA_SET_METHOD(3)

NOMBRE

RSA_set_default_method, RSA_get_default_method, RSA_set_method, RSA_get_method, RSA_PKCS1_SSLeay, RSA_flags, RSA_new_method — seleccionar método RSA

SINOPSIS

biblioteca “libcrypto”
#include <openssl/rsa.h>

void
RSA_set_default_method(const RSA_METHOD *meth);

const RSA_METHOD *
RSA_get_default_method(void);

int
RSA_set_method(RSA *rsa, const RSA_METHOD *meth);

const RSA_METHOD *
RSA_get_method(const RSA *rsa);

const RSA_METHOD *
RSA_PKCS1_SSLeay(void);

int
RSA_flags(const RSA *rsa);

RSA *
RSA_new_method(ENGINE *engine);

DESCRIPCIÓN

Un objeto RSA_METHOD contiene punteros a las funciones utilizadas para las operaciones RSA. Por defecto, se utiliza la implementación interna devuelta por RSA_PKCS1_SSLeay(). Seleccionando otro método, se pueden utilizar implementaciones alternativas, como aceleradores de hardware.

RSA_set_default_method() selecciona meth como el método por defecto para todas las estructuras RSA creadas posteriormente.

RSA_get_default_method() devuelve un puntero al método por defecto actual.

RSA_set_method() selecciona meth para realizar todas las operaciones utilizando la clave rsa. Esto reemplaza el RSA_METHOD anterior utilizado por la clave RSA, llamando a la función finish configurada con RSA_meth_set_finish(3) si existe alguna. Si meth contiene una función init configurada con RSA_meth_set_init(3), esa función se llama justo antes de devolver el valor de RSA_set_method().

Es posible tener claves RSA que solo funcionen con ciertas implementaciones de RSA_METHOD, y en tales casos, intentar cambiar el RSA_METHOD para la clave puede tener resultados inesperados.

RSA_get_method() devuelve un puntero al RSA_METHOD que está siendo utilizado por rsa.

La función, con un nombre engañoso, RSA_flags() devuelve las banderas que están establecidas para el RSA_METHOD actual de rsa. Las banderas utilizadas por el propio rsa se pueden probar en su lugar con RSA_test_flags(3). Consulte la sección ERRORES para obtener más detalles.

RSA_new_method() asigna e inicializa una estructura RSA. El argumento engine se ignora y se utiliza el método por defecto controlado por RSA_set_default_method().

Las flags iniciales se copian del objeto RSA_METHOD utilizado y no se verán afectadas por cambios posteriores en ese objeto, pero pueden ser modificadas por la función opcional init que puede haber sido configurada con RSA_meth_set_init(3) y que se llama justo antes de devolver el valor de RSA_new_method().

VALORES DE RETORNO

RSA_PKCS1_SSLeay(), RSA_get_default_method(), y RSA_get_method() devuelven punteros a los respectivos RSA_METHOD.

RSA_set_method() devuelve 1 en caso de éxito o 0 en caso de error. Actualmente, no puede fallar.

RSA_new_method() devuelve NULL y establece un código de error que puede ser obtenido por ERR_get_error(3) si falla la asignación. De lo contrario, devuelve un puntero a la estructura recién asignada.

VER TAMBIÉN

RSA_meth_new(3), RSA_new(3)

HISTORIA

RSA_set_default_method(), RSA_PKCS1_SSLeay(), y RSA_new_method() aparecieron por primera vez en SSLeay 0.8.0. RSA_flags() apareció por primera vez en SSLeay 0.9.0. Estas funciones han estado disponibles desde OpenBSD 2.4.

RSA_get_default_method(), RSA_set_method(), y RSA_get_method() así como los componentes rsa_sign y rsa_verify de RSA_METHOD aparecieron por primera vez en OpenSSL 0.9.4 y han estado disponibles desde OpenBSD 2.6.

ERRORES

El comportamiento de RSA_flags() es un mal diseño que se deja como está por ahora para evitar crear problemas de compatibilidad. La funcionalidad RSA, como las funciones de cifrado, se controlan mediante el valor de flags en la propia clave RSA, no mediante el valor de flags en el RSA_METHOD adjunto a la clave RSA (que es lo que esta función devuelve). Si el elemento flags de una clave RSA se cambia, los cambios serán tenidos en cuenta por la funcionalidad RSA pero no se reflejarán en el valor de retorno de la función RSA_flags() - en efecto, RSA_flags() se comporta más como una función RSA_default_flags(), que actualmente no existe.
