NOMBRE

libnbd-release-notes-1.20 - notas de la versión de libnbd 1.20

DESCRIPCIÓN

Estas son las notas de la versión de la versión estable de libnbd 1.20. Se describen los principales cambios desde la versión 1.18.

libnbd 1.20.0 se lanzó el 5 de abril de 2024.

Seguridad

Fuzzing encontró y Eric Blake corrigió una aserción que podría activarse al conectarse a un servidor malicioso. Esto fue asignado a CVE-2023-5871 (baja severidad). Vea el anuncio aquí: https://lists.libguestfs.org/archives/list/guestfs@lists.libguestfs.org/thread/5CRC7LRTN35WPZZ4BT6NAMH4JGMF47IK/

Si encuentra un problema de seguridad, lea SECURITY en el código fuente (en línea aquí: https://gitlab.com/nbdkit/libnbd/blob/master/SECURITY). Para conocer los problemas de seguridad anteriores en libnbd, consulte libnbd-security(3).

Mejoras en las APIs existentes

nbd_connect_uri(3) ahora admite URIs en mayúsculas y minúsculas de forma insensible.

Protocolo

Mejora la interoperabilidad con nbd-server(1), que admite respuestas estructuradas pero no contexto de metadatos (Eric Blake).

Herramientas

nbdinfo(1) agrega soporte para --isnt, --cannot, --hasnt, lo que le permite verificar si las características de un servidor NBD *no* son soportadas.

nbdinfo(1) agrega soporte para --uri, que simplemente imprime la URI canónica del servidor.

nbdinfo(1) ahora imprime tamaños legibles para las restricciones de tamaño de bloque (Eric Blake).

Enlaces de idiomas

Se agregó una nueva página del manual libnbd-rust(3), que proporciona una descripción general para escribir programas Rust utilizando libnbd.

La documentación de Rust ha sido mejorada mediante el uso de un traductor personalizado de nuestro propio formato de documentación (Perl POD) a rustdoc.

Se corrigieron algunas advertencias del compilador de Rust (Eric Blake).

Los enlaces OCaml ahora admiten cero copias en las funciones AIO pread y pwrite. Este cambio es compatible con versiones anteriores del código existente. (Gracias Nicolas Ojeda Bar, Anil Madhavapeddy, Simon Cruanes).

Los enlaces OCaml ahora utilizan "Gc.finalize" (finalizadores a nivel de OCaml en lugar de finalizadores a nivel de C), lo que mejora la compatibilidad en OCaml 5.1.1 y posteriores (Guillaume Munch-Maccagnoni).

Se requiere formalmente OCaml ≥ 4.05 y se verifica en ./configure. Anteriormente no especificábamos una versión mínima de OCaml, pero en la práctica las versiones anteriores a 4.05 probablemente no funcionaban.

Pruebas

El enfoque de fuzzing se cambió para usar comandos asíncronos. Esto mejora significativamente la velocidad del fuzzing y debería encontrar más problemas.

Múltiples correcciones de CI (Eric Blake).

Respeta la elección del usuario de qemu-nbd, nbdkit y otros binarios de (por ejemplo) "./configure NBDKIT=/algún/nbdkit". Anteriormente, a menudo probábamos con binarios encontrados en el PATH, incluso si el usuario había especificado otros binarios para usar.

Otras mejoras y correcciones de errores

nbdinfo(1) ahora se desconecta elegantemente del servidor en casos de error, mejorando la salida (Eric Blake).

"struct nbd_handle" ahora contiene un valor mágico que se verifica al ingresar a libnbd, lo que debería identificar errores donde los programas que llaman a libnbd pasan un puntero incorrecto.

Documentación

Se agregó un ejemplo de cómo usar userfaultfd para mapear en memoria una unidad respaldada por NBD. Consulte examples/userfault-map.c en el código fuente de libnbd.

La documentación de los estados de manejo aceptables en las páginas del manual ha sido mejorada.

Compilación

contrib/libnbd.m4 es una prueba de configuración contribuida para libnbd (Bruno Haible).

"./configure --with-bash-completions" ahora fallará si no está instalado el paquete bash-completions requerido.
