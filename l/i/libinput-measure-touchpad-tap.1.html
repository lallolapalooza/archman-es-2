NOMBRE

libinput-measure-touchpad-tap - mide las propiedades de toque para hacer clic de los dispositivos

SINOPSIS

libinput measure touchpad-tap [--help] [--format=<formato>] [/dev/input/event0]

DESCRIPCIÓN

La herramienta libinput measure touchpad-tap mide las propiedades del comportamiento de toque para hacer clic del usuario. Esta es una herramienta interactiva. Cuando se ejecuta, la herramienta pedirá al usuario que interactúe con el panel táctil. Al finalizar, la herramienta imprime un resumen de las interacciones de toque observadas. Estos datos deben adjuntarse a cualquier informe de error relacionado con toques.

Para una descripción completa de cómo funciona el comportamiento de toque para hacer clic de libinput, consulte la documentación en línea aquí: https://wayland.freedesktop.org/libinput/doc/latest/tapping.html

Esta es solo una herramienta de depuración, su salida puede cambiar en cualquier momento. No confíe en la salida.

Esta herramienta generalmente necesita ejecutarse como root para tener acceso a los nodos /dev/input/eventX.

OPCIONES

Si se proporciona un nodo de dispositivo, esta herramienta abre ese nodo de dispositivo. De lo contrario, esta herramienta busca el primer nodo que parezca un panel táctil y utiliza ese nodo.

--help
Imprimir ayuda
--format=summary|dat
Especificar el formato de los datos a imprimir. El valor predeterminado (o si se omite --format) es "summary". Ver sección FORMATOS DE DATOS

FORMATOS DE DATOS

Esta sección describe los formatos de datos impresos con el argumento de línea de comandos --format. Tenga en cuenta que cualquiera de las salidas puede cambiar en cualquier momento.

summary

El formato summary imprime un resumen de los datos recopilados. Este formato es útil para obtener una vista rápida del comportamiento de toque de un usuario y por qué algunos toques pueden ser o no detectados.

dat

El formato dat imprime los datos de la secuencia de toque (crudos y procesados) en formato de columna, adecuado para ser procesado por otras herramientas como gnuplot(1). Los datos están alineados en una fila por toque con cada columna que contiene una entrada de datos separada. libinput-measure-touchpad-tap imprime comentarios en la parte superior del archivo para describir cada columna.

ADVERTENCIA: Los datos contenidos en la salida se agrupan por diferentes órdenes de clasificación. Por ejemplo, las primeras columnas pueden listar información de toque en el orden de clasificación 'natural' (es decir, como ocurrieron), los datos en las siguientes columnas pueden listar información de toque ordenada por el tiempo delta entre el toque hacia abajo y el toque hacia arriba. Comparar columnas entre estos límites de grupo comparará datos de dos puntos de toque diferentes y dará como resultado un análisis inválido.

ERRORES

Esta herramienta no tiene en cuenta la presión del dedo. El toque que detecta puede ser diferente a los detectados por libinput si los umbrales de presión de libinput difieren significativamente de los umbrales de presión del kernel.
