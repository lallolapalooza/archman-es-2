DESCRIPCIÓN

La función EVP_PKEY_keygen_init() inicializa un contexto de algoritmo de clave pública usando el contexto ctx->pkey para una operación de generación de claves.

La función EVP_PKEY_keygen() realiza una operación de generación de claves. La clave generada se escribe en ppkey.

Las funciones EVP_PKEY_paramgen_init() y EVP_PKEY_paramgen() son similares excepto que se generan parámetros.

Las funciones EVP_PKEY_CTX_set_cb() y EVP_PKEY_CTX_get_cb() establecen y recuperan la devolución de llamada de generación de claves o parámetros, respectivamente.

La función EVP_PKEY_CTX_set0_keygen_info() establece los parámetros asociados con la operación de generación en la matriz dat que contiene datlen parámetros enteros. El llamador conserva la propiedad de la matriz dat; la biblioteca nunca la liberará.

La función EVP_PKEY_CTX_get_keygen_info() devuelve parámetros asociados con la operación de generación. Si idx es -1, se devuelve el número total de parámetros disponibles. Cualquier valor no negativo devuelve el valor de ese parámetro. EVP_PKEY_CTX_get_keygen_info() con un valor no negativo para idx solo debe llamarse dentro de la devolución de llamada de generación.

Si la devolución de llamada devuelve 0, la operación de generación de claves se aborta y se produce un error. Esto podría ocurrir durante una operación que consume mucho tiempo en la que un usuario hace clic en un botón "cancelar".

Las funciones EVP_PKEY_CTX_set_app_data() y EVP_PKEY_CTX_get_app_data() establecen y recuperan un puntero opaco. Esto se puede usar para establecer algún valor definido por la aplicación que se puede recuperar en la devolución de llamada: por ejemplo, un identificador que se utiliza para actualizar un "diálogo de progreso".

Las funciones obsoletas EVP_PKEY_CTX_set_data() y EVP_PKEY_CTX_get_data() establecen y recuperan un puntero opaco diferente que es ignorado por la biblioteca.

Después de la llamada a EVP_PKEY_keygen_init() o EVP_PKEY_paramgen_init(), se pueden realizar operaciones de control específicas del algoritmo para establecer cualquier parámetro apropiado para la operación.

Las funciones EVP_PKEY_keygen() y EVP_PKEY_paramgen() pueden llamarse más de una vez en el mismo contexto si se realizan varias operaciones utilizando los mismos parámetros.

El significado de los parámetros pasados a la devolución de llamada dependerá del algoritmo y de la implementación específica del algoritmo. Algunos podrían no proporcionar información útil durante la generación de claves o parámetros. Otros podrían ni siquiera llamar a la devolución de llamada.

La operación realizada por la generación de claves o parámetros depende del algoritmo utilizado. En algunos casos (por ejemplo, EC con una curva nombrada proporcionada), la opción de "generación" simplemente establece los campos apropiados en una estructura EVP_PKEY.

En OpenSSL, una estructura EVP_PKEY que contiene una clave privada también contiene los componentes de la clave pública y los parámetros (si los hay). Una clave privada de OpenSSL es equivalente a lo que algunas bibliotecas llaman un "par de claves". Una clave privada se puede utilizar en funciones que requieren el uso de una clave pública o parámetros.

VALORES DE RETORNO

EVP_PKEY_keygen_init(), EVP_PKEY_paramgen_init(), EVP_PKEY_keygen() y EVP_PKEY_paramgen() devuelven 1 para éxito y 0 o un valor negativo para fallo. En particular, un valor de retorno de -2 indica que la operación no es compatible con el algoritmo de clave pública.

Las funciones de devolución de llamada del tipo EVP_PKEY_gen_cb() deben devolver 1 en caso de éxito o 0 en caso de error.

EVP_PKEY_CTX_get_cb() devuelve un puntero de función a la función de devolución de llamada actualmente instalada o NULL si no hay ninguna función de devolución de llamada instalada.

EVP_PKEY_CTX_get_keygen_info() devuelve el número de parámetros disponibles si idx es -1, uno de estos parámetros si idx es mayor o igual

DESCRIPTION

The EVP_PKEY key generation functions provide a uniform API for generating public/private keys for various algorithms.

A private key context is created using EVP_PKEY_CTX_new(3), EVP_PKEY_CTX_new_id(3) or EVP_PKEY_CTX_new_from_pkey(3).

EVP_PKEY_keygen_init() initializes the key generation operation.

EVP_PKEY_keygen() performs the key generation. The generated key is stored in the location pointed to by ppkey. The ctx is not freed by this call and should be freed later using EVP_PKEY_CTX_free(3).

EVP_PKEY_keygen_param() is similar to EVP_PKEY_keygen(), but it generates a key from the provided parameters in param. If param is NULL, then a suitable default parameter set is generated.

The key generation process can be controlled by various algorithms-specific properties set on the ctx using EVP_PKEY_CTX_ctrl(3) or EVP_PKEY_CTX_ctrl_str(3).

For example, for RSA key generation, the key size can be set using EVP_PKEY_CTX_set_rsa_keygen_bits(). For DSA and EC keys, parameters can be explicitly set using EVP_PKEY_CTX_set_dsa_paramgen_bits() and EVP_PKEY_CTX_set_ec_paramgen_curve_nid() respectively.

EVP_PKEY_CTX_set_app_data() sets an arbitrary pointer data to be associated with ctx. This can be used for callbacks.

EVP_PKEY_CTX_get_app_data() retrieves the arbitrary pointer previously set with EVP_PKEY_CTX_set_app_data().

EVP_PKEY_CTX_set_data() sets an arbitrary pointer data to be associated with ctx. This is intended for use by the implementation, not by the application.

EVP_PKEY_CTX_get_data() retrieves the arbitrary pointer previously set with EVP_PKEY_CTX_set_data().

EVP_PKEY_CTX_get_keygen_info() returns information about the key generation process. The meaning of idx depends on the underlying algorithm. For example, for DSA and EC key generation, it returns the bit length of the modulus or curve, respectively.

If idx is 0, it returns the current progress of the key generation, in percent, rounded down to the nearest integer. Valid values are integers from 0 to 100.

If idx is 1, it returns the expected total number of bits of the generated key. This is typically the bit length of the modulus for RSA and DSA keys.

If idx is 2, it returns the number of bits already generated. This is useful to know how much progress has been made.

If idx is 3, it returns the total number of parameters required for the key generation process. This is typically 1.

It returns a value less than 0 for an invalid idx or if the information is not available. It returns 0 if the total number of bits is not known.

RETURN VALUES

EVP_PKEY_keygen_init(), EVP_PKEY_keygen(), and EVP_PKEY_keygen_param() return 1 on success, or 0 or a negative value on failure. A return value of 0 typically means an operation is not supported. A negative return value means a fatal error occurred.

EVP_PKEY_CTX_get_keygen_info() returns information about the key generation process. It returns a value greater than 0 but less than the number of available parameters, or 0 otherwise.

EVP_PKEY_CTX_get_app_data() and EVP_PKEY_CTX_get_data() return the pointer that was last passed to the corresponding set function, or NULL if the corresponding set function was never called on ctx.

EXAMPLES

Generate a 2048-bit RSA key:

#include <openssl/evp.h>
#include <openssl/rsa.h>

EVP_PKEY_CTX *ctx;
EVP_PKEY *pkey = NULL;

ctx = EVP_PKEY_CTX_new_id(EVP_PKEY_RSA, NULL);
if (!ctx)
	/* Error occurred */
if (EVP_PKEY_keygen_init(ctx) <= 0)
	/* Error */
if (EVP_PKEY_CTX_set_rsa_keygen_bits(ctx, 2048) <= 0)
	/* Error */

/* Generate key */
if (EVP_PKEY_keygen(ctx, &pkey) <= 0)
	/* Error */

Generate a key from a set of parameters:

#include <openssl/evp.h>
#include <openssl/rsa.h>

EVP_PKEY_CTX *ctx;
EVP_PKEY *pkey = NULL, *param;

/* Assumes that param is already set up. */
ctx = EVP_PKEY_CTX_new(param, NULL);
if (!ctx)
	/* Error occurred */
if (EVP_PKEY_keygen_init(ctx) <= 0)
	/* Error */

/* Generate key */
if (EVP_PKEY_keygen(ctx, &pkey) <= 0)
	/* Error */

Example of generation callback for OpenSSL public key implementations:

/* Application data is a BIO to output status to */

EVP_PKEY_CTX_set_app_data(ctx, status_bio);

static int
genpkey_cb(EVP_PKEY_CTX *ctx)
{
	char c = '*';
	BIO *b = EVP_PKEY_CTX_get_app_data(ctx);
	int p;

	p = EVP_PKEY_CTX_get_keygen_info(ctx, 0);
	if (p == 0)
		c = '.';
	if (p == 1)
		c = '+';
	if (p == 2)
		c = '*';
	if (p == 3)
		c = '\n';
	BIO_write(b, &c, 1);
	(void)BIO_flush(b);
	return 1;
}
