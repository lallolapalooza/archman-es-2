union alpm_event_t

Eventos.

Esta es una unión pasada a la función de devolución de llamada que permite al frontend saber qué tipo de evento se activó (a través de type). Luego es posible hacer un typecast del puntero a la estructura correcta, o usar el campo de la unión, para acceder a los datos específicos del evento.

Campos de datos:

alpm_event_any_t any El evento de cualquier tipo.
Siempre es seguro acceder a esto.

alpm_event_database_missing_t database_missing Falta una base de datos.

alpm_event_hook_t hook Se están ejecutando hooks pre/post transacción.

alpm_event_hook_run_t hook_run Se ejecutó un hook.

alpm_event_optdep_removal_t optdep_removal Se eliminó una dependencia opcional.

alpm_event_package_operation_t package_operation Operación de paquete.

alpm_event_pacnew_created_t pacnew_created Se creó un archivo pacnew.

alpm_event_pacsave_created_t pacsave_created Se creó un archivo pacsave.

alpm_event_pkg_retrieve_t pkg_retrieve Descargar paquetes.

alpm_event_pkgdownload_t pkgdownload Se descargó un paquete.

alpm_event_scriptlet_info_t scriptlet_info Se ejecutó un scriptlet.

alpm_event_type_t type Tipo de evento, siempre es seguro acceder a esto.

alpm_question_remove_pkgs_t remove_pkgs ¿Se deben eliminar del transacción los objetivos no resolubles?

alpm_question_replace_t replace ¿Se debe reemplazar un paquete?

Parámetros

typedef int(* alpm_cb_fetch) (void *ctx, const char *url, const char *localpath, int force)

Un callback para descargar archivos.

Parámetros

ctx contexto proporcionado por el usuario
url la URL del archivo a descargar
localpath el directorio al que se debe descargar el archivo
force si se debe forzar una actualización, incluso si el archivo es el mismo

Devuelve

0 en caso de éxito, 1 si el archivo existe y es idéntico, -1 en caso de error.

typedef void(* alpm_cb_progress) (void *ctx, alpm_progress_t progress, const char *pkg, int percent, size_t howmany, size_t current)

Callback de progreso. Alerta a la interfaz de usuario sobre el progreso de ciertos eventos. Permite la implementación de barras de carga para eventos que pueden tardar en completarse.

Parámetros

ctx contexto proporcionado por el usuario
progress el tipo de evento que está progresando
pkg para operaciones de paquetes, el nombre del paquete en el que se está operando
percent el porcentaje de finalización de la acción
howmany la cantidad total de elementos en la acción
current la cantidad actual de elementos completados Callback de progreso

typedef void(* alpm_cb_question) (void *ctx, alpm_question_t *question)

Callback de pregunta. Este callback permite al usuario dar entrada y decidir qué hacer durante ciertos eventos

Parámetros

ctx contexto proporcionado por el usuario
question la pregunta que se hace.
