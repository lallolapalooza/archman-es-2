libcaca-tutorial - Un tutorial de libcaca

Primero, un programa de trabajo muy simple, para verificar las funcionalidades básicas de libcaca.

#include <caca.h>
int main(void)
{
    caca_canvas_t *cv; caca_display_t *dp; caca_event_t ev;
    dp = caca_create_display(NULL);
    if(!dp) return 1;
    cv = caca_get_canvas(dp);
    caca_set_display_title(dp, "¡Hola!");
    caca_set_color_ansi(cv, CACA_BLACK, CACA_WHITE);
    caca_put_str(cv, 0, 0, "Este es un mensaje");
    caca_refresh_display(dp);
    caca_get_event(dp, CACA_EVENT_KEY_PRESS, &ev, -1);
    caca_free_display(dp);
    return 0;
}

¿Qué hace?

  • Crea una pantalla. Físicamente, la pantalla es una ventana o un contexto en una terminal (ncurses, slang) o incluso toda la pantalla (VGA).
  • Obtiene el lienzo asociado a la pantalla. Un lienzo es la superficie donde ocurre todo: escribir caracteres, sprites, cadenas, imágenes... Es invariable. Aquí el tamaño del lienzo lo establece la pantalla.
  • Establece el nombre de la ventana de la pantalla (solo disponible en pantallas con ventana, no hace nada en otro caso).
  • Establece los colores actuales del lienzo a fondo negro y primer plano blanco.
  • Escribe la cadena 'Este es un mensaje' en el lienzo, utilizando el par de colores actual.
  • Refresca la pantalla, haciendo que el texto se muestre efectivamente.
  • Espera un evento de tipo CACA_EVENT_KEY_PRESS.
  • Libera la pantalla (libera memoria). Dado que se creó junto con la pantalla, el lienzo también se liberará automáticamente.

Puedes compilar este código en un sistema tipo UNIX utilizando los siguientes comandos (requiere pkg-config y gcc):

gcc `pkg-config --libs --cflags caca` example.c -o example
