EVP_BYTESTOKEY(3) Manual de funciones de biblioteca EVP_BYTESTOKEY(3)

NOMBRE

EVP_BytesToKey — rutina de cifrado basada en contraseña

SINOPSIS

biblioteca “libcrypto”
#include <openssl/evp.h>

int
EVP_BytesToKey(const EVP_CIPHER *type, const EVP_MD *md, const unsigned char *salt, const unsigned char *data, int datal, int count, unsigned char *key, unsigned char *iv);

DESCRIPCIÓN

EVP_BytesToKey() deriva una clave y un IV a partir de varios parámetros. type es el cifrador para el que se deriva la clave y el IV. md es el resumen de mensaje a utilizar. El parámetro salt se utiliza como sal en la derivación: debe apuntar a un búfer que contenga PKCS5_SALT_LEN = 8 bytes o NULL si no se utiliza sal. data es un búfer que contiene datal bytes que se utiliza para derivar los datos de clave. count es el número de iteraciones a utilizar. La clave y el IV derivados se escribirán en key e iv, respectivamente.

Una aplicación típica de esta función es derivar material de clave para un algoritmo de cifrado a partir de una contraseña en el parámetro data.

Aumentar el parámetro count ralentiza el algoritmo, lo que dificulta que un atacante realice un ataque de fuerza bruta utilizando un gran número de contraseñas candidatas.

Si la longitud total de la clave y el IV es menor que la longitud del resumen y se utiliza MD5, el algoritmo de derivación es compatible con PKCS#5 v1.5. De lo contrario, se utiliza una extensión no estándar para derivar los datos adicionales.

Las aplicaciones más nuevas deben usar algoritmos más estándar como PBKDF2 definido en PKCS#5v2.1 para la derivación de claves.

ALGORITMO DE DERIVACIÓN DE CLAVES

La clave y el IV se derivan concatenando D_1, D_2, etc. hasta que haya suficientes datos disponibles para la clave y el IV. D_i se define recursivamente como:

D_i = HASH^count(D_(i-1) || data || salt)

donde || denota concatenación, D_0 está vacío, HASH es el algoritmo de resumen en uso, HASH^1(data) es simplemente HASH(data), HASH^2(data) es HASH(HASH(data)) y así sucesivamente.

Los bytes iniciales se utilizan para la clave y los bytes subsiguientes para el IV.

VALORES DE RETORNO

Si data es NULL, EVP_BytesToKey() devuelve el número de bytes necesarios para almacenar la clave derivada. De lo contrario, EVP_BytesToKey() devuelve el tamaño de la clave derivada en bytes o 0 en caso de error.

VER TAMBIÉN

evp(3), EVP_EncryptInit(3), PKCS5_PBKDF2_HMAC(3)

HISTORIA

EVP_BytesToKey() apareció por primera vez en SSLeay 0.5.1 y ha estado disponible desde OpenBSD 2.4.
