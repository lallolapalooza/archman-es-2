NOMBRE

libgphoto2_port - biblioteca de acceso a puertos multiplataforma

SINOPSIS

#include <gphoto2/gphoto2_port.h>

DESCRIPCIÓN

La biblioteca libgphoto2_port fue escrita para proporcionar a libgphoto2(3) una forma genérica de acceder a los puertos. En esta función, libgphoto2_port es el sucesor de la biblioteca libgpio.

Actualmente, libgphoto2_port soporta conexiones seriales (RS-232) y USB, esta última requiere que libusb esté instalada.

La documentación de la API generada automáticamente se añadirá aquí en el futuro.

VARIABLES DE ENTORNO

IOLIBS
Si está establecida, define el directorio donde la biblioteca libgphoto2_port busca sus controladores de E/S (iolibs). Solo necesitas establecer esto en sistemas Windows y en instalaciones rotas/de prueba.
LD_DEBUG
Establécela en all para recibir mucha información de depuración sobre la carga de bibliotecas en sistemas basados en ld.
USB_DEBUG
Si está establecida, define el nivel de depuración numérico con el que la biblioteca libusb imprimirá mensajes. Para obtener alguna salida de depuración, establécela en 1.
