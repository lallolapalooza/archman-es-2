Accesoress al directorio raíz

El directorio raíz es el prefijo al que libalpm instala los paquetes.

Los hooks y los scripts también se ejecutarán en un chroot para asegurar que se comportan correctamente en raíces alternativas.
const char * alpm_option_get_root (alpm_handle_t *handle)
Devuelve la ruta raíz.

Accesoress a la ruta de la base de datos

La ruta de la base de datos es donde libalpm almacena la base de datos local y descarga las bases de datos de sincronización.
const char * alpm_option_get_dbpath (alpm_handle_t *handle)
Devuelve la ruta al directorio de la base de datos.

Accesoress al archivo de bloqueo

El archivo de bloqueo se utiliza para asegurar que dos instancias de libalpm no puedan escribir en la base de datos al mismo tiempo.

El archivo de bloqueo se crea al confirmar una transacción y se libera cuando la transacción se completa. O al llamar a alpm_unlock.
const char * alpm_option_get_lockfile (alpm_handle_t *handle)
Obtiene el nombre del archivo de bloqueo de la base de datos.

Accesoress a la lista de archivos sobrescritibles.

Normalmente, libalpm se negará a instalar un paquete que posea archivos que ya existen en el disco y que no son propiedad de ese paquete.

Si un archivo en conflicto coincide con un glob en la lista overwrite_files, no se generará ningún conflicto y libalpm simplemente sobrescribirá el archivo.

Accesoores para la extensión de la base de datos

Esto controla la extensión utilizada para las bases de datos de sincronización.

libalpm utilizará esta extensión tanto para buscar bases de datos remotas como como nombre utilizado al abrirlas para leerlas.

Esto es útil para bases de datos de archivos. Dado que los archivos pueden aumentar considerablemente el tamaño de una base de datos, un servidor podría tener una base de datos sin archivos bajo una extensión, y otra con archivos bajo otra extensión.

Cuál se descarga y se utiliza depende de esta configuración.
const char * alpm_option_get_dbext (alpm_handle_t *handle)
Obtiene la extensión de base de datos configurada. int alpm_option_set_dbext (alpm_handle_t *handle, const char *dbext)
Establece la extensión de base de datos.

Accesoores para el tiempo de espera de descarga

Por defecto, libalpm dará tiempo de espera si una descarga ha estado transfiriendo menos de 1 byte durante 10 segundos.
int alpm_option_set_disable_dl_timeout (alpm_handle_t *handle, unsigned short disable_dl_timeout)
Habilita/deshabilita el tiempo de espera de descarga.

Accesoores para descargas paralelas

alpm_db_update, alpm_fetch_pkgurl y alpm_trans_commit pueden descargar paquetes en paralelo.

Esta configuración controla cuántos paquetes se pueden descargar en paralelo.

Por defecto, este valor se establece en 1, lo que significa que los paquetes se descargan secuencialmente.
int alpm_option_get_parallel_downloads (alpm_handle_t *handle)
Obtiene el número de flujos paralelos para descargar archivos de base de datos y de paquetes. int alpm_option_set_parallel_downloads (alpm_handle_t *handle, unsigned int num_streams)
Establece el número de flujos paralelos para descargar archivos de base de datos y de paquetes.

Habilita/deshabilita el sandbox.
