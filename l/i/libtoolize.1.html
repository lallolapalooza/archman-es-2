LIBTOOLIZE(1) Comandos de usuario LIBTOOLIZE(1)

NOMBRE

libtoolize — Prepara un paquete para usar libtool

SINOPSIS

libtoolize [OPCIÓN]...

DESCRIPCIÓN

Prepara un paquete para usar libtool.

OPCIONES

-c, --copy
copiar archivos en lugar de enlazar simbólicamente
--debug
habilitar el rastreo detallado del shell
-n, --dry-run
imprimir comandos en lugar de ejecutarlos
-f, --force
reemplazar archivos existentes
-i, --install
copiar archivos auxiliares faltantes
--ltdl[=DIR]
instalar las fuentes de libltdl [por defecto: libltdl]
--no-warnings
equivalente a '-Wnone'
--nonrecursive
preparar ltdl para make no recursivo
-q, --quiet
trabajar silenciosamente
--recursive
preparar ltdl para make recursivo
--subproject
preparar ltdl para configurar y construir de forma independiente
-v, --verbose
informar detalladamente sobre el procesamiento
--version
imprimir información de versión y salir
-W, --warnings=CATEGORÍA
informar las advertencias que caen en CATEGORÍA [todas]
-h, --help
imprimir mensaje de ayuda corto o largo

Las categorías de advertencia incluyen:

'all'
mostrar todas las advertencias
'none'
desactivar todas las advertencias
'error'
las advertencias se tratan como errores fatales
'environment'
mostrar advertencias sobre el contenido de LIBTOOLIZE_OPTIONS
'file'
mostrar advertencias sobre la copia y el enlace de archivos

Las siguientes opciones separadas por espacio o coma se pueden pasar a libtoolize a través de la variable de entorno LIBTOOLIZE_OPTIONS; las opciones de entorno desconocidas se ignoran:

--debug
habilitar el rastreo detallado del shell
--no-warnings
no mostrar mensajes de advertencia
--quiet
trabajar silenciosamente
--verbose
informar detalladamente sobre el procesamiento

Debes ejecutar 'cd' al directorio principal de tu paquete antes de ejecutar 'libtoolize'.

Al informar un error, describe un caso de prueba para reproducirlo e incluye la siguiente información:
