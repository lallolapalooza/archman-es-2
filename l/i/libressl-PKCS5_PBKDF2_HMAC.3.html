NOMBRE

PKCS5_PBKDF2_HMAC, PKCS5_PBKDF2_HMAC_SHA1 — rutinas de derivación basadas en contraseña con salt y contador de iteraciones

SINOPSE

biblioteca “libcrypto”
#include <openssl/evp.h>

int
PKCS5_PBKDF2_HMAC(const char *pass, int passlen, const unsigned char *salt, int saltlen, int iter, const EVP_MD *digest, int keylen, unsigned char *out);

int
PKCS5_PBKDF2_HMAC_SHA1(const char *pass, int passlen, const unsigned char *salt, int saltlen, int iter, int keylen, unsigned char *out);

DESCRIPCIÓN

PKCS5_PBKDF2_HMAC() deriva una clave de una contraseña utilizando un salt y un contador de iteraciones según lo especificado en RFC 2898.

pass es la contraseña utilizada en la derivación de longitud passlen. pass es un parámetro opcional y puede ser NULL. Si passlen es -1, la función calculará la longitud de pass usando strlen(3).

salt es el salt utilizado en la derivación de longitud saltlen. Si el salt es NULL, entonces saltlen debe ser 0. La función no intentará calcular la longitud del salt ya que no se asume que termine en NUL.

iter es el contador de iteraciones y su valor debe ser mayor o igual a 1. RFC 2898 sugiere un contador de iteraciones de al menos 1000. Cualquier iter menor que 1 se trata como una sola iteración.

digest es la función de resumen de mensajes utilizada en la derivación. Los valores incluyen cualquiera de los resúmenes de mensajes EVP_*. PKCS5_PBKDF2_HMAC_SHA1() llama a PKCS5_PBKDF2_HMAC() con EVP_sha1(3).

La clave derivada se escribirá en out. El tamaño del búfer de out se especifica a través de keylen.

Una aplicación típica de esta función es derivar material de clave para un algoritmo de cifrado a partir de una contraseña en pass, un salt en salt, y un contador de iteraciones.

Incrementar el parámetro iter ralentiza el algoritmo, lo que dificulta que un atacante realice un ataque de fuerza bruta utilizando un gran número de contraseñas candidatas.

VALORES DE RETORNO

PKCS5_PBKDF2_HMAC() y PBKCS5_PBKDF2_HMAC_SHA1() devuelven 1 en caso de éxito o 0 en caso de error.

VER TAMBIÉN

EVP_BytesToKey(3), EVP_DigestInit(3)
