NOMBRE

libpbm - funciones de libnetpbm para leer y escribir archivos de imagen PBM

SINOPSIS

#include <netpbm/pbm.h>

bit **pbm_allocarray(int cols, int rows);

bit *pbm_allocrow(int cols);

pbm_freearray(bit **bits, int rows);

pbm_freerow(bit *bitrow);

void pbm_readpbminit(FILE * fp, int *colsP, int *rowsP, int *formatP);

void pbm_readpbmrow(FILE * fp, bit *bitrow, int cols, int format);

void pbm_readpbmrow_packed(FILE * fp, unsigned char * const packed_bits, const int cols, const int format);

bit** pbm_readpbm(FILE * fp, int *colsP, int *rowsP);

void pbm_writepbminit(FILE * fp, int cols, int rows, int forceplain);

void pbm_writepbmrow(FILE * fp, bit *bitrow, int cols, int forceplain);

void pbm_writepbmrow_packed(FILE * fp, unsigned char * const packed_bits, const int cols, const int forceplain);

void pbm_writepbm(FILE * fp, bit **bits, int cols, int rows, int forceplain);

#define pbm_packed_bytes(cols) ...

void pbm_nextimage( FILE *file, int * const eofP);

void pbm_check( FILE * file, const enum pm_check_type check_type, const int format, const int cols, const int rows, enum pm_check_code * const retval);

DESCRIPCION

Estas funciones de biblioteca son parte de Netpbm(1)

TIPOS Y CONSTANTES

typedef ... bit;

#define PBM_WHITE ...

#define PBM_BLACK ...

Cada bit debe contener solo los valores de PBM_WHITE o PBM_BLACK.

#define PBM_FORMAT ...

#define RPBM_FORMAT ...

#define PBM_TYPE PBM_FORMAT

#define PBM_FORMAT_TYPE(f) ...

Estos son para distinguir diferentes formatos y tipos de archivo.

INICIALIZACION

pbm_init() está obsoleto (al menos desde Netpbm 9.25 (marzo de 2002)). Usa pm_proginit() en su lugar.

pbm_init() es idéntico a pm_proginit.

GESTIÓN DE MEMORIA

pbm_allocarray() asigna un array de bits. pbm_allocrow() asigna una fila del número dado de bits. pbm_freearray() libera el array asignado con pbm_allocarray() que contiene el número dado de filas. pbm_freerow() libera una fila de bits.

LECTURA DE ARCHIVOS DE IMAGEN PBM

pbm_readpbminit() lee la cabecera de una imagen PBM en un archivo PBM, rellenando las variables de filas, columnas y formato. pbm_readpbmrow() lee una fila de bits en el array bitrow. El formato y las columnas fueron rellenados por pbm_readpbminit().

pbm_readpbmrow_packed() es similar a pbm_readpbmrow() excepto que en lugar de devolver un array de bits, devuelve un array packed_bits de bytes con los píxeles de la fila de imagen empaquetados en ellos. Los píxeles están en orden de izquierda a derecha a lo largo de la fila y desde el principio del array hasta el final. Dentro de un byte, los bits están en orden del bit más significativo al bit menos significativo. Si el número de píxeles en la fila no es un múltiplo de 8, el último byte devuelto se rellena en el lado del bit menos significativo con bits indefinidos. El blanco se representa por un bit PBM_WHITE; el negro por PBM_BLACK.

pbm_readpbm() lee un archivo completo de mapa de bits en memoria, devolviendo el array asignado y rellenando las variables de filas y columnas. Esta función combina pbm_readpbminit(), pbm_allocarray() y pbm_readpbmrow().

pbm_readpbminit() y pbm_readpbm abortan el programa con un mensaje al error estándar si la cabecera de la imagen PBM no es sintácticamente válida, incluyendo si contiene un número demasiado grande para ser procesado usando las estructuras de datos normales del sistema (es decir, un número que no cabe en un 'int' de C).

ppm_readppminit() y ppm_readppm abortan el programa con un mensaje al error estándar si la cabecera de la imagen PPM no es sintácticamente válida, incluyendo si contiene un número demasiado grande para ser procesado usando las estructuras de datos normales del sistema (es decir, un número que no cabe en un 'int' de C).

ESCRITURA DE ARCHIVOS DE IMAGEN PBM

pbm_writepbminit() escribe la cabecera para una imagen PBM en un archivo PBM. forceplain es un valor booleano que especifica que se debe escribir un archivo de formato plano (texto), en contraposición a uno de formato crudo (binario). pbm_writepbmrow() escribe una fila en un archivo PBM. pbm_writepbmrow_packed() es lo mismo que pbm_writepbmrow() excepto que usted suministra la fila a escribir como un array de bytes empaquetados con bits en lugar de como un array de bits. El formato de packed_bits es el mismo que el devuelto por pbm_readpbmrow().

pbm_writepbm() escribe la cabecera y todos los datos de una imagen PBM en un archivo PBM. Esta función combina pbm_writepbminit() y pbm_writepbmrow().

VARIOS

pbm_nextimage() posiciona un archivo de entrada PBM a la siguiente imagen en él (de modo que una llamada posterior a pbm_readpbminit() lea su cabecera).

Inmediatamente antes de una llamada a pbm_nextimage(), el archivo debe estar posicionado bien al principio (es decir, no se ha leído nada del archivo todavía) o justo después de una imagen (es decir, tal como lo dejó una llamada a pbm_readpbmrow() de la última fila de la imagen).

Tenga en cuenta que en el formato crudo PNM y PAM, la siguiente imagen siempre comienza inmediatamente después de la imagen anterior, por lo que todo lo que hace pbm_nextimage() es comprobar si hay una siguiente imagen o si el archivo está posicionado al final del archivo. En PNM plano, sin embargo, puede haber espacios en blanco entre imágenes.

Si pbm_nextimage() se posiciona correctamente a la siguiente imagen, devuelve *eofP falso (0). Si no hay una siguiente imagen en el archivo, devuelve *eofP verdadero. Si no puede posicionarse o determinar el estado del archivo debido a un error de archivo, lanza un error.

pbm_check() comprueba el error común de integridad del archivo donde el archivo tiene un tamaño incorrecto para contener todos los datos de la imagen. pbm_check() asume que el archivo está posicionado después de una cabecera de imagen (como si pbm_readpbminit() hubiera sido la última operación en el archivo). Comprueba el tamaño del archivo para ver si el número de bytes restantes en el archivo es el número requerido para contener el raster de la imagen. Si el archivo es demasiado corto, pbm_check() hace que el programa lance un error. De lo contrario, devuelve uno de los siguientes valores (enumeraciones del tipo enum pm_check_code) en *retval:

PM_CHECK_OK
El tamaño del archivo es exactamente el requerido para contener el raster de la imagen.
PM_CHECK_UNKNOWN_TYPE
format no es un formato cuyo tamaño pbm_check() pueda

NAME

pbm_check — check if a PBM file is valid

SYNOPSIS

#include <pbm.h>

int pbm_check(const char *filename);

int pbm_check_raw(FILE *fp);

int pbm_check_type(const char *filename, enum pm_check_type check_type);

DESCRIPTION

These functions check the validity of a PBM file. The exact checks performed depend on the argument check_type, which must be one of the following values:

PM_CHECK_BASIC
This is the most basic check. It verifies that the file is a PBM file, has a valid header, and is not truncated.
PM_CHECK_RAW
This check is performed by the pbm_check_raw() function. It checks if the file is a raw PBM file. The only format that pbm_check_raw() can handle is the raw PBM format.
PM_CHECK_TOO_LONG
The file is longer than it needs to be to contain the image raster. The extra data might be another image.
PM_CHECK_UNCHECKABLE
The file is not of a type that has a predictable size, so there is no simple way for pbm_check() to know if it is the right size. A pipe is a common example of a file that does not.

check_type must have the value PM_CHECK_BASIC (an enumerated value of the pm_check_type enumerated type). Otherwise, the effect of pbm_check() is unpredictable. This argument exists for future backward compatible expansion of the function of pbm_check().
