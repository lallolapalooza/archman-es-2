libressl-MD5(3)

Paquete: libressl

Licencias: ISC, custom:OpenSSL

MD5(3) Manual de funciones de biblioteca MD5(3)

NOMBRE

MD4, MD5, MD4_Init, MD4_Update, MD4_Final, MD5_Init, MD5_Update, MD5_Final — Funciones hash MD4 y MD5

SINOPSIS

biblioteca “libcrypto”
#include <openssl/md4.h>

unsigned char *
MD4(const unsigned char *d, unsigned long n, unsigned char *md);

int
MD4_Init(MD4_CTX *c);

int
MD4_Update(MD4_CTX *c, const void *data, unsigned long len);

int
MD4_Final(unsigned char *md, MD4_CTX *c);

#include <openssl/md5.h>

unsigned char *
MD5(const unsigned char *d, unsigned long n, unsigned char *md);

int
MD5_Init(MD5_CTX *c);

int
MD5_Update(MD5_CTX *c, const void *data, unsigned long len);

int
MD5_Final(unsigned char *md, MD5_CTX *c);

DESCRIPCIÓN

MD4 y MD5 son funciones hash criptográficas con una salida de 128 bits.

MD4() y MD5() calculan el resumen del mensaje MD4 y MD5 de los n bytes en d y lo colocan en md, el cual debe tener espacio para MD4_DIGEST_LENGTH == MD5_DIGEST_LENGTH == 16 bytes de salida.

Las siguientes funciones se pueden usar si el mensaje no se almacena completamente en memoria:

MD5_Init() inicializa una estructura MD5_CTX.

MD5_Update() se puede llamar repetidamente con fragmentos del mensaje a cifrar (len bytes en data).

MD5_Final() coloca el resumen del mensaje en md, el cual debe tener espacio para MD5_DIGEST_LENGTH == 16 bytes de salida, y borra el MD5_CTX.

MD4_Init(), MD4_Update(), y MD4_Final() son análogas usando una estructura MD4_CTX.

Las aplicaciones deben usar las funciones de nivel superior EVP_DigestInit(3), etc., en lugar de llamar directamente a estas funciones hash.

VALORES DE RETORNO

MD4() y MD5() devuelven punteros al valor hash.

MD4_Init(), MD4_Update(), MD4_Final(), MD5_Init(), MD5_Update(), y MD5_Final() devuelven 1 para éxito o 0 en caso contrario.

VER TAMBIÉN

EVP_DigestInit(3)

ESTÁNDARES

RFC 1320, RFC 1321

HISTORIA

MD5(), MD5_Init(), MD5_Update(), y MD5_Final() aparecieron en SSLeay 0.4 o anterior y han estado disponibles desde OpenBSD 2.4.

MD4(), MD4_Init(), MD4_Update(), y MD4_Final() aparecieron por primera vez en OpenSSL 0.9.6 y han estado disponibles desde OpenBSD 2.9.

ADVERTENCIAS

Otras implementaciones permiten que md en MD4() y MD5() sea NULL y devuelva un array estático, que no es seguro para hilos.
