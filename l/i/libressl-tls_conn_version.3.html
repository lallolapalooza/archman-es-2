DESCRIPCIÓN

Estas funciones devuelven información sobre una conexión TLS y solo tendrán éxito después de que se complete el handshake (la información de la conexión se aplica tanto a clientes como a servidores, a menos que se indique lo contrario):

tls_conn_version() devuelve una cadena correspondiente a una versión TLS negociada con el par conectado a ctx.

tls_conn_cipher() devuelve una cadena correspondiente al conjunto de cifrado negociado con el par conectado a ctx.

tls_conn_cipher_strength() devuelve la fortaleza en bits del cifrado simétrico que se está utilizando con el par conectado a ctx.

tls_conn_alpn_selected() devuelve una cadena que especifica el protocolo ALPN seleccionado para su uso con el par conectado a ctx. Si no se seleccionó ningún protocolo, se devuelve NULL.

tls_conn_servername() devuelve una cadena correspondiente al nombre del servidor que el cliente conectado a ctx solicitó enviando una extensión TLS Server Name Indication (solo servidor).

tls_conn_session_resumed() indica si se reanudó una sesión TLS durante el handshake con el servidor conectado a ctx (solo cliente).

tls_peer_cert_provided() comprueba si el par de ctx ha proporcionado un certificado.

tls_peer_cert_contains_name() comprueba si el par de un TLS ctx ha proporcionado un certificado que contiene una SAN o CN que coincide con name.

tls_peer_cert_chain_pem() devuelve un puntero a la memoria que contiene una cadena de certificados codificada en PEM para el certificado del par de ctx.

tls_peer_cert_subject() devuelve una cadena correspondiente al sujeto del certificado del par de ctx.

tls_peer_cert_issuer() devuelve una cadena correspondiente al emisor del certificado del par de ctx. tls_peer_cert_common_name() devuelve una cadena correspondiente al nombre común del certificado del par de ctx o la cadena vacía si no hay un nombre común presente.

tls_peer_cert_hash() devuelve una cadena correspondiente a un hash del certificado del par en bruto de ctx, precedida por un nombre de hash seguido de dos puntos. El hash utilizado actualmente es SHA256, aunque esto podría cambiar en el futuro. La cadena de hash para un certificado en el archivo mycert.crt se puede generar usando los comandos:

h=$(openssl x509 -outform der -in mycert.crt | sha256)
printf "SHA256:${h}\n"

tls_peer_cert_notbefore() devuelve la hora correspondiente al inicio del período de validez del certificado del par de ctx.

tls_peer_cert_notafter() devuelve la hora correspondiente al final del período de validez del certificado del par de ctx.

VALORES DE RETORNO

La función tls_conn_session_resumed() devuelve 1 si se reanudó una sesión TLS o 0 si no fue así.

Las funciones tls_peer_cert_provided() y tls_peer_cert_contains_name() devuelven 1 si la comprobación tiene éxito o 0 si no.

tls_peer_cert_notbefore() y tls_peer_cert_notafter() devuelven un tiempo en segundos desde la época (epoch) en caso de éxito o -1 en caso de error.

Las funciones que devuelven un puntero devuelven NULL en caso de error o condición de falta de memoria.

VER TAMBIÉN
