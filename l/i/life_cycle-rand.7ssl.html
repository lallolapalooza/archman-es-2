NOMBRE

life_cycle-rand - El ciclo de vida del algoritmo RAND

DESCRIPCIÓN

Todos los generadores de números aleatorios (RANDs) pasan por una serie de etapas en su ciclo de vida:

inicio
Este estado representa el RAND antes de haber sido asignado. Es el estado inicial para cualquier transición del ciclo de vida.
creado
Este estado representa el RAND después de haber sido asignado pero incapaz de generar ninguna salida.
instanciado
Este estado representa el RAND cuando está configurado y es capaz de generar salida.
no_instanciado
Este estado representa el RAND cuando ha sido cerrado y ya no es capaz de generar salida.
liberado
Este estado se alcanza cuando el RAND es liberado. Es el estado terminal para todas las transiciones del ciclo de vida.

Diagrama de transición de estados

El ciclo de vida habitual de un RAND se ilustra:
+-------------------------+
| inicio |
+-------------------------+
|
| EVP_RAND_CTX_new
v
+-------------------------+
| creado |
+-------------------------+
|
| EVP_RAND_instantiate
v
EVP_RAND_generate +-------------------------+
+-------------------- | |
| | instanciado |
+-------------------> | | <+
+-------------------------+ '
| '
| EVP_RAND_uninstantiate ' EVP_RAND_instantiate
v '
+-------------------------+ '
| no_instanciado | -+
+-------------------------+
|
| EVP_RAND_CTX_free
v
+-------------------------+
| liberado |
+-------------------------+

Transiciones formales de estado

Esta sección define todas las transiciones de estado legales. Esta es la lista canónica.
Llamada a función ------------------ Estado actual ------------------
inicio creado instanciado no_instanciado liberado
EVP_RAND_CTX_new creado
EVP_RAND_instantiate instanciado
EVP_RAND_generate instanciado
EVP_RAND_uninstantiate no_instanciado
EVP_RAND_CTX_free liberado liberado liberado liberado
EVP_RAND_CTX_get_params creado instanciado no_instanciado liberado
EVP_RAND_CTX_set_params creado instanciado no_instanciado liberado
EVP_RAND_CTX_gettable_params creado instanciado no_instanciado liberado
EVP_RAND_CTX_settable_params creado instanciado no_instanciado liberado

NOTAS

En algún momento, la capa EVP comenzará a aplicar las transiciones descritas aquí.
