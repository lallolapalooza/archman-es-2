NOMBRE

libkeccak_state_marshal - Serializa un estado de hash

SINOPSIS

#include <libkeccak.h>
size_t libkeccak_state_marshal(const struct libkeccak_state *state, void *data);

Enlace con -lkeccak.

DESCRIPCIÓN

La función libkeccak_state_marshal() serializa *state al principio de data.

Pase NULL como data para obtener el tamaño mínimo de asignación utilizable para

VALORES DEVUELTOS

La función libkeccak_state_marshal() devuelve el número de bytes escritos en data.

ERRORES

La función libkeccak_state_marshal() no puede fallar.

VER TAMBIÉN

libkeccak_state_unmarshal(3)
