NOMBRE

libpfm_intel_spr_unc_imc - soporte para el PMU no core del controlador de memoria integrado (IMC) de Intel SapphireRapids Server

SINOPSIS

#include <perfmon/pfmlib.h>

Nombre del PMU: spr_unc_imc[0-11]
Descripción del PMU: PMU no core del controlador de memoria integrado (IMC) de Intel SapphireRapids Server

DESCRIPCIÓN

La biblioteca soporta el PMU no core del controlador de memoria integrado (IMC) de Intel SapphireRapids Server.

MODIFICADORES

Los siguientes modificadores son compatibles con el PMU no core del IMC de Intel SapphireRapids Server:

e
Habilita la detección de flancos, es decir, cuenta solo cuando hay una transición de estado de no ocurrencia del evento a al menos una ocurrencia. Este modificador debe combinarse con un modificador de umbral (t) con un valor mayor o igual a uno. Este es un modificador booleano.
t
Establece el valor del umbral. Cuando se establece en un valor distinto de cero, el contador cuenta el número de ciclos del IMC en los que el número de ocurrencias del evento es mayor o igual al umbral. Este es un modificador entero con valores en el rango [0:255]. i Invierte la prueba del umbral (t) de estrictamente mayor que a menor o igual que. Este es un modificador booleano.
