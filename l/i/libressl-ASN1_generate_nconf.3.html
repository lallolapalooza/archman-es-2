ASN1_GENERATE_NCONF(3) Manual de Funciones de Biblioteca ASN1_GENERATE_NCONF(3)

NOMBRE

ASN1_generate_nconf, ASN1_generate_v3 — Funciones de generación ASN.1

SINOPSIS

biblioteca “libcrypto”
#include <openssl/asn1.h>

ASN1_TYPE *
ASN1_generate_nconf(const char *str, CONF *nconf);

ASN1_TYPE *
ASN1_generate_v3(const char *str, X509V3_CTX *cnf);

DESCRIPCIÓN

Estas funciones generan la codificación ASN.1 de una cadena en una estructura ASN1_TYPE.

str contiene la cadena a codificar. nconf o cnf contienen la información de configuración opcional donde se leerán cadenas adicionales. nconf normalmente provendrá de un archivo de configuración, mientras que cnf se obtiene de una estructura X509V3_CTX que normalmente será utilizada por las funciones de extensión de certificado X509 v3. cnf o nconf pueden establecerse a NULL si no se utilizará configuración adicional.

FORMATO DE CADENA DE GENERACIÓN

Los datos reales codificados están determinados por la cadena str y la información de configuración. El formato general de la cadena es:

[modificador,]tipo[:valor]

Es decir, cero o más modificadores separados por comas seguidos de un tipo y opcionalmente dos puntos y un valor. Los formatos de tipo, valor y modificador se explican a continuación.

Tipos compatibles

Los tipos admitidos se enumeran a continuación. A menos que se especifique lo contrario, solo se permite el formato ASCII.

BOOLEAN, BOOL
Esto codifica un tipo booleano. La cadena valor es obligatoria y debe ser TRUE o FALSE. Además, se aceptan true, Y, y, YES, yes, false, N, n, NO y no.
NULL
Codifica el tipo NULL. La cadena valor no debe estar presente.
INTEGER, INT
Codifica un tipo ASN.1 INTEGER. La cadena valor representa el valor del entero. Puede ir precedida por un signo menos y normalmente se interpreta como un valor decimal a menos que se incluya el prefijo 0x.
ENUMERATED, ENUM
Codifica el tipo ASN.1 ENUMERATED. Es idéntico al INTEGER.
OBJECT, OID
Codifica un OBJECT IDENTIFIER ASN.1. La cadena valor puede ser un nombre corto, un nombre largo o formato numérico.
UTCTIME, UTC
Codifica una estructura ASN.1 UTCTime. El valor debe estar en el formato YYMMDDHHMMSSZ.
GENERALIZEDTIME, GENTIME
Codifica una estructura ASN.1 GeneralizedTime. El valor debe estar en el formato YYYYMMDDHHMMSSZ.
OCTETSTRING, OCT
Codifica una OCTET STRING ASN.1. valor representa el contenido de esta estructura. Se pueden utilizar los formatos de cadena ASCII y HEX para especificar el formato de valor.
BITSTRING, BITSTR
Codifica una BIT STRING ASN.1. valor representa el contenido de esta estructura. Se pueden utilizar los formatos de cadena ASCII, HEX y BITLIST para especificar el formato de valor.

Si el formato es diferente de BITLIST, el número de bits no utilizados se establece en cero.

BMPSTRING, BMP, GeneralString, IA5STRING, IA5, NUMERICSTRING, NUMERIC, PRINTABLESTRING, PRINTABLE, T61STRING, T61, TELETEXSTRING, UNIVERSALSTRING, UNIV, UTF8String, UTF8, VISIBLESTRING, VISIBLE
Estos codifican los tipos de cadena correspondientes. valor representa el contenido de esta estructura. El formato puede ser ASCII o UTF8.
SEQUENCE, SEQ, SET
Formatea el resultado como un tipo ASN.1 SEQUENCE o SET. valor debe ser un nombre de sección que contendrá el contenido. Los nombres de campo en la sección se ignoran y los valores están en el formato de cadena generado. Si valor está ausente, se codificará una SEQUENCE vacía.

Modificadores

Los modificadores afectan a la estructura siguiente. Se pueden usar para agregar etiquetado EXPLICIT o IMPLICIT, agregar envolturas o cambiar el formato de cadena del tipo y valor finales. Los formatos compatibles son:

EXPLICIT, EXP
Agrega una etiqueta explícita a la estructura siguiente. Esta cadena debe ir seguida de dos puntos y el valor de la etiqueta a usar como valor decimal.

Al seguir el número con U, A, P o C, se pueden usar etiquetas UNIVERSAL, APPLICATION, PRIVATE o CONTEXT SPECIFIC. El valor predeterminado es CONTEXT SPECIFIC.

IMPLICIT, IMP
Esto es lo mismo que EXPLICIT excepto que se usa etiquetado IMPLICIT.
OCTWRAP, SEQWRAP, SETWRAP, BITWRAP
La estructura siguiente se rodea de una OCTET STRING, una SEQUENCE, un SET o una BIT STRING, respectivamente. Para una BIT STRING, el número de bits no utilizados se establece en cero.
FORMAT
Esto especifica el formato del valor final. Debe ir seguido de dos puntos y una de las cadenas ASCII, UTF8, HEX o BITLIST.
