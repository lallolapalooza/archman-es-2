LINK(1) Comandos de Usuario LINK(1)

NOMBRE

link - llamar a la función link para crear un enlace a un archivo

SINOPSIS

link ARCHIVO1 ARCHIVO2
link OPCIÓN

DESCRIPCIÓN

Llama a la función link para crear un enlace llamado ARCHIVO2 a un ARCHIVO1 existente.

--help
mostrar esta ayuda y salir

mostrar información de versión y salir
