EVP_CIPHER_DO_ALL(3) Manual de funciones de biblioteca EVP_CIPHER_DO_ALL(3)

NOMBRE

EVP_CIPHER_do_all, EVP_CIPHER_do_all_sorted, EVP_MD_do_all, EVP_MD_do_all_sorted, OBJ_NAME_do_all, OBJ_NAME_do_all_sorted — itera sobre tablas de búsqueda para cifrados y resúmenes

SINOPSIS

biblioteca “libcrypto”
#include <openssl/evp.h>

void
EVP_CIPHER_do_all(void (*fn)(const EVP_CIPHER *cipher, const char *from, const char *to, void *arg), void *arg);

void
EVP_CIPHER_do_all_sorted(void (*fn)(const EVP_CIPHER *cipher, const char *from, const char *to, void *arg), void *arg);

void
EVP_MD_do_all(void (*fn)(const EVP_MD *md, const char *from, const char *to, void *arg), void *arg);

void
EVP_MD_do_all_sorted(void (*fn)(const EVP_MD *md, const char *from, const char *to, void *arg), void *arg);

typedef struct {
        int	    type;
        int	    alias;
        const char *name;
        const char *data;
} OBJ_NAME;


void
OBJ_NAME_do_all(int type, void (*fn)(const OBJ_NAME *obj_name, void *arg), void *arg);

void
OBJ_NAME_do_all_sorted(int type, void (*fn)(const OBJ_NAME *obj_name, void *arg), void *arg);

DESCRIPCIÓN

EVP_CIPHER_do_all() llama a fn en cada entrada de la tabla global de nombres de cifrado y alias. Para una entrada de nombre de cifrado, se llama a fn con un cipher no nulo, su nombre de cifrado no nulo from, un to nulo y el puntero arg. Para una entrada de alias, se llama a fn con un cipher nulo, su alias from, el nombre de cifrado al que apunta ese alias to, y el puntero arg.

EVP_CIPHER_do_all_sorted() es similar, excepto que procesa los nombres de cifrado y los alias en orden lexicográfico de sus nombres from según lo determinado por strcmp(3).

EVP_MD_do_all() llama a fn en cada entrada de la tabla global de nombres de resumen y alias. Para una entrada de nombre de resumen, se llama a fn con un md no nulo, su nombre de resumen no nulo from, un to nulo y el puntero arg. Para una entrada de alias, se llama a fn con un md nulo, su alias from, el nombre de resumen al que apunta ese alias to, y el puntero arg.

EVP_MD_do_all_sorted() es similar, excepto que procesa los nombres de resumen y los alias en orden lexicográfico de sus nombres from según lo determinado por strcmp(3).

OBJ_NAME es una abstracción de los tipos subyacentes a las tablas de búsqueda para cifrados y sus alias, y resúmenes y sus alias, respectivamente. Para un cifrado, type es OBJ_NAME_TYPE_CIPHER_METH, alias es 0, name es su nombre de búsqueda y data es el objeto EVP_CIPHER que representa, casteado a const char *. Para un alias de cifrado, type es OBJ_NAME_TYPE_CIPHER_METH, alias es OBJ_NAME_ALIAS, name es su nombre de búsqueda y data es el nombre al que hace referencia. Los resúmenes que representan un objeto EVP_MD y sus alias se representan de manera similar, excepto que su tipo es OBJ_NAME_TYPE_MD_METH.

OBJ_NAME_do_all() llama a fn en cada obj_name en la tabla que tiene el type dado (ya sea OBJ_NAME_TYPE_CIPHER_METH o OBJ_NAME_TYPE_MD_METH), pasando también el puntero arg. OBJ_NAME_do_all_sorted() es similar excepto que procesa los obj_name en orden lexicográfico de sus nombres según lo determinado por strcmp(3).

VER TAMBIÉN

evp(3), EVP_get_cipherbyname(3), EVP_get_digestbyname(3)

HISTORIA

Estas funciones aparecieron por primera vez en OpenSSL 1.0.0 y han estado disponibles desde OpenBSD 4.9.

ADVERTENCIAS

EVP_CIPHER_do_all_sorted(), EVP_MD_do_all_sorted(), y OBJ_NAME_do_all_sorted() no pueden informar de errores. En algunas implementaciones necesitan asignar memoria internamente y si la asignación de memoria falla, no hacen nada, sin informar al llamador sobre el problema.
