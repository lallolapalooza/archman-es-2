libressl-ASN1_put_object(3)

Paquete: libressl

Licencias: ISC, custom:OpenSSL

ASN1_PUT_OBJECT(3) Manual de funciones de la biblioteca ASN1_PUT_OBJECT(3)

NOMBRE

ASN1_put_object, ASN1_put_eoc, ASN1_object_size — iniciar y finalizar la codificación BER de un elemento de datos ASN.1 arbitrario

SINOPSIS

biblioteca “libcrypto”
#include <openssl/asn1.h>

void
ASN1_put_object(unsigned char **ber_out, int constructed, int content_length, int tag, int class);

int
ASN1_put_eoc(unsigned char **ber_out);

int
ASN1_object_size(int constructed, int content_length, int tag);

DESCRIPCIÓN

ASN1_put_object() comienza a escribir la codificación BER de un elemento de datos ASN.1 arbitrario en el búfer *ber_out escribiendo el identificador y los bytes de longitud. La responsabilidad de asegurar que haya suficiente espacio en el búfer recae en el llamador. Esta función no escribe ningún byte de contenido ni bytes de fin de contenido.

La etiqueta clase puede ser V_ASN1_UNIVERSAL, V_ASN1_APPLICATION, V_ASN1_CONTEXT_SPECIFIC, o V_ASN1_PRIVATE y se escribe en los dos bits más significativos del primer byte escrito.

El argumento constructed puede tener los siguientes valores:

0
Inicia un valor primitivo estableciendo el tercer bit más significativo del primer byte escrito a 0. Usa siempre la forma definida.
1
Inicia un valor construido estableciendo el tercer bit más significativo del primer byte escrito a 1, y usa la forma definida.
2
Inicia un valor construido y usa la forma indefinida,

Si la etiqueta es menor que V_ASN1_PRIMITIVE_TAG (= 0x1f), se escribe en los cinco bits menos significativos del único byte de identificador escrito. De lo contrario, estos cinco bits se establecen todos a 1, y la etiqueta se codifica en uno o más bytes de identificador siguientes según sea necesario.

Después de completar el/los byte(s) de identificador, cuando se utiliza la forma definida, la longitud_contenido dada se codifica en uno o más bytes según sea necesario, utilizando la forma larga si y solo si la longitud_contenido es mayor que 127. Cuando se utiliza la forma indefinida, se escribe el byte especial 0x80 en su lugar y se ignora el argumento longitud_contenido.

Al final, *ber_out se establece en el byte siguiente al último byte escrito. El código llamador puede entonces comenzar a escribir bytes de contenido.

Si se seleccionó la forma indefinida, el código llamador también es responsable de llamar a ASN1_put_eoc() que escribe un marcador de fin de contenido en *ber_out, que consiste en dos bytes NUL, y avanza *ber_out en dos bytes.

ASN1_object_size() calcula la longitud total en bytes de la codificación BER de un elemento de datos ASN.1 con la etiqueta dada y el número de bytes de contenido proporcionado por content_length. El argumento constructed tiene el mismo significado que para ASN1_put_object(). El valor de retorno incluye el identificador, la longitud y los bytes de contenido. Si constructed es 2, también incluye los bytes de fin de contenido. Para la forma definida, solo se admite la forma corta si la content_length es menor que 128.

VALORES DE RETORNO

ASN1_put_eoc() devuelve el número de bytes escritos, que siempre es 2.

ASN1_object_size() devuelve el número total de bytes en la codificación del elemento de datos.

VER TAMBIÉN

ASN1_item_i2d(3), ASN1_TYPE_get(3), i2d_ASN1_NULL(3), i2d_ASN1_OBJECT(3), i2d_ASN1_OCTET_STRING(3), i2d_ASN1_SEQUENCE_ANY(3)

ESTÁNDARES

Recomendación X.690 de la ITU-T, también conocida como ISO/IEC 8825-1: Tecnología de la información - Reglas de codificación ASN.1: Especificación de las Reglas de Codificación Básica (BER), Reglas de Codificación Canónica (CER) y Reglas de Codificación Distinguida (DER), sección 8.1: Reglas generales para la codificación

HISTORIA

ASN1_put_object() y ASN1_object_size() aparecieron por primera vez en SSLeay 0.5.1 y han estado disponibles desde OpenBSD 2.4.

ASN1_put_eoc() apareció por primera vez en OpenSSL 0.9.8 y ha estado disponible desde OpenBSD 4.5.

ADVERTENCIAS

Ninguna de estas funciones realiza comprobaciones de validez. Cuando se llaman de forma inconsistente, pueden resultar datos inválidos en *ber_out, por ejemplo:

  • un número de etiqueta menor que V_ASN1_PRIMITIVE_TAG con una clase distinta de V_ASN1_UNIVERSAL
  • un número de etiqueta igual a V_ASN1_EOC (0x00) o V_ASN1_PRIMITIVE_TAG (0x1f)
  • un BOOLEAN, INTEGER, NULL, etc. con el bit de constructed establecido
  • una SEQUENCE o SET, etc. sin el bit de constructed establecido
  • una longitud_contenido que no tiene sentido para la etiqueta dada
  • una longitud_contenido que no coincide con los datos siguientes
  • un BOOLEAN, INTEGER, NULL, etc. en forma indefinida
  • un marcador de fin de contenido a pesar de que no se inició ninguna forma indefinida
  • ...

Si el código llamador desea saber cuántos bytes se escribieron, necesita guardar una copia del puntero *ber_out antes de llamar a ASN1_put_object().
