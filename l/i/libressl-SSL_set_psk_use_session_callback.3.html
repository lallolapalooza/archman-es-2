libressl-SSL_set_psk_use_session_callback(3)

Paquete: libressl

Licencias: ISC, custom:OpenSSL

SSL_SET_PSK_USE_SESSION_CALLBACK(3) Manual de funciones de la biblioteca SSL_SET_PSK_USE_SESSION_CALLBACK(3)

NOMBRE

SSL_set_psk_use_session_callback, SSL_psk_use_session_cb_func — establecer la función de devolución de llamada del cliente de clave precompartida TLS

SINOPSIS

biblioteca “libssl” libcrypto
#include <openssl/ssl.h>

typedef int
(*SSL_psk_use_session_cb_func)(SSL *ssl, const EVP_MD *md, const unsigned char **id, size_t *idlen, SSL_SESSION **session);

void
SSL_set_psk_use_session_callback(SSL *ssl, SSL_psk_use_session_cb_func cb);

DESCRIPCIÓN

LibreSSL proporciona la función de marcador de posición SSL_set_psk_use_session_callback() para permitir la compilación de programas de aplicación que contienen soporte opcional para claves precompartidas TLSv1.3.

LibreSSL no admite claves precompartidas TLS, y no ocurre ninguna acción cuando se llama SSL_set_psk_use_session_callback(). En particular, se ignoran ambos argumentos. Durante la negociación de sesión, LibreSSL nunca llama a la función de devolución de llamada cb y siempre se comporta como si esa función de devolución de llamada hubiera tenido éxito y hubiera establecido el puntero *session a NULL. Es decir, LibreSSL nunca envía una clave precompartida al servidor ni aborta el apretón de manos por falta de una clave precompartida.

Con OpenSSL, una aplicación cliente que desee utilizar claves precompartidas TLSv1.3 puede instalar una función de devolución de llamada cb utilizando SSL_set_psk_use_session_callback(). La biblioteca OpenSSL puede llamar a cb una o dos veces durante la negociación de sesión. Si la función de devolución de llamada falla, OpenSSL aborta la configuración de la conexión. Si la función de devolución de llamada tiene éxito pero establece el puntero *session a NULL, OpenSSL continúa el apretón de manos pero no envía una clave precompartida al servidor.

VALORES DE RETORNO

Se espera que la función de devolución de llamada SSL_psk_use_session_cb_func() devuelva 1 en caso de éxito o 0 en caso de fallo.

HISTORIA

SSL_set_psk_use_session_callback() y SSL_psk_use_session_cb_func() aparecieron por primera vez en OpenSSL 1.1.1 y han estado disponibles desde OpenBSD 7.0.
