LINBOX-CONFIG(1) Comandos de usuario LINBOX-CONFIG(1)

NOMBRE

linbox-config - herramienta para enlazar con LinBox

SINOPSIS

linbox-config [OPCIÓN]

DESCRIPCIÓN

Valores conocidos para OPCIÓN son:

--prefix
muestra el prefijo de instalación de Linbox
--libs
imprime información de enlace de bibliotecas
--cflags
imprime las banderas del preprocesador y compilador
--help
muestra esta ayuda y sale
--version
muestra información de la versión

VER TAMBIÉN

La documentación completa de linbox-config se mantiene como un manual de Texinfo. Si los programas info y linbox-config están instalados correctamente en su sitio, el comando

info linbox-config

debería darle acceso al manual completo.
