libressl-d2i_ASN1_SEQUENCE_ANY(3)

Paquete: libressl

Licencias: ISC, custom:OpenSSL

D2I_ASN1_SEQUENCE_ANY(3) Manual de funciones de la biblioteca D2I_ASN1_SEQUENCE_ANY(3)

NOMBRE

d2i_ASN1_SEQUENCE_ANY, i2d_ASN1_SEQUENCE_ANY, d2i_ASN1_SET_ANY, i2d_ASN1_SET_ANY — decodifican y codifican secuencias y conjuntos ASN.1

SINOPSIS

biblioteca “libcrypto”
#include <openssl/asn1.h>

ASN1_SEQUENCE_ANY *
d2i_ASN1_SEQUENCE_ANY(ASN1_SEQUENCE_ANY **val_out, const unsigned char **der_in, long length);

int
i2d_ASN1_SEQUENCE_ANY(const ASN1_SEQUENCE_ANY *val_in, unsigned char **der_out);

ASN1_SEQUENCE_ANY *
d2i_ASN1_SET_ANY(ASN1_SEQUENCE_ANY **val_out, const unsigned char **der_in, long length);

int
i2d_ASN1_SET_ANY(const ASN1_SEQUENCE_ANY *val_in, unsigned char **der_out);

DESCRIPCIÓN

Estas funciones decodifican y codifican secuencias y conjuntos ASN.1, que también se representan mediante las constantes identificadoras de tipo V_ASN1_SEQUENCE y V_ASN1_SET, respectivamente. Para obtener detalles sobre la semántica, ejemplos, advertencias y errores, consulte ASN1_item_d2i(3).

El tipo ASN1_SEQUENCE_ANY se define como STACK_OF(ASN1_TYPE). Si un objeto de este tipo representa una secuencia o un conjunto no se almacena en el objeto en sí, sino que debe recordarse por separado.

Al igual que con d2i_ASN1_TYPE(3) y i2d_ASN1_TYPE(3), el tipo de los valores individuales contenidos en la secuencia o conjunto no se especifica al llamar a las funciones. Puede variar entre los miembros y se almacena junto con cada valor en cada objeto ASN1_TYPE contenido en la secuencia o conjunto.

VALORES DE RETORNO

d2i_ASN1_SEQUENCE_ANY() devuelve un objeto ASN1_SEQUENCE_ANY o NULL si ocurre un error.

i2d_ASN1_SEQUENCE_ANY() devuelve el número de bytes escritos o un valor negativo si ocurre un error.

VER TAMBIÉN

ASN1_item_d2i(3), ASN1_TYPE_new(3)

HISTORIA

d2i_ASN1_SEQUENCE_ANY(), i2d_ASN1_SEQUENCE_ANY(), d2i_ASN1_SET_ANY() y i2d_ASN1_SET_ANY() aparecieron por primera vez en OpenSSL 1.0.0 y han estado disponibles desde OpenBSD 4.9.
