NOMBRE

libiio-0.26 - introducción a libiio, una biblioteca para interactuar con el subsistema IIO de Linux y dispositivos

SINOPSIS

#include <iio.h>

cc file.c -liio

OPCIONES

La definición IIO_CHECK_REG advertirá si los valores de retorno no se comprueban. La mayoría de las funciones de libiio, si ocurre un fallo, devolverán un número de error negativo. esta advertencia asegurará que estos números de error sean observados. No hay nada más frustrante que llamar a una función, depurar algún hardware y finalmente darse cuenta de que hubo un error tipográfico en un nombre de atributo. Esta opción forzará a los usuarios de la biblioteca a capturar al menos el valor de retorno.

cc file.c -DIIO_CHECK_REG -liio

DESCRIPCIÓN

libiio es una biblioteca utilizada para interactuar con el subsistema Industrial Input/Output (IIO) de Linux. El subsistema IIO de Linux está diseñado para dar soporte a dispositivos que en cierto sentido son convertidores analógicos a digitales o digitales a analógicos (ADC, DAC). Esto incluye, entre otros, ADC, Acelerómetros, Giroscopios, IMU, Convertidores de Capacidad a Digital (CDC), Sensores de Presión, Sensores de Color, Luz y Proximidad, Sensores de Temperatura, Magnetómetros, DAC, DDS (Direct Digital Synthesis), PLL (Phase Locked Loops), Amplificadores de Ganancia Variable/Programable (VGA, PGA) y transceptores de RF. Puede usar libiio de forma nativa en un sistema embebido con Linux (modo local), o usar libiio para comunicarse de forma remota con ese mismo sistema desde un host Linux, Windows o MAC a través de USB, Ethernet o Serie.

TIPOS DE DATOS

La biblioteca utiliza estructuras y `typedef` de C para promover la portabilidad, y se sabe que funciona en varias distribuciones GNU/Linux, macOS, Windows y mbed (a través de tiny-iiod). Las principales estructuras de C son:

iio_scan_context
El contexto de escaneo
iio_context_info
La información relacionada con un contexto descubierto
iio_context
Contiene la representación de un contexto IIO
iio_device
Representa un dispositivo en el contexto IIO
iio_channel
Representa un canal de entrada o salida de un dispositivo
iio_buffer
Un buffer de entrada o salida, utilizado para leer o escribir muestras
iio_data_format
Contiene el formato de una muestra de datos.

NAME

libiio - Interface library for IIO devices

SYNOPSIS

#include <iio.h>

Link with -liio

DESCRIPTION

The libiio library provides a simple API to access devices that export the IIO (Industrial I/O) interface in the Linux kernel.

The library is structured around the concepts of contexts, devices, channels, and buffers.

A context represents an IIO context, which can be either local (e.g. accessing devices on the local machine) or remote (e.g. accessing devices on a remote machine via network). A context can contain multiple devices. The function iio_create_local_context() and iio_create_remote_context() are used to create a context.

A device represents an IIO device. A device can have multiple channels. The function iio_context_get_devices() enumerates all devices within a context. The function iio_device_find() can be used to find a device by its ID.

A channel represents a data stream of a device, e.g. an analog input, an analog output, a digital input, a digital output, etc. A device can have multiple channels. The function iio_device_get_channels() enumerates all channels of a device. The function iio_channel_find() can be used to find a channel by its ID.

A buffer is used to transfer data to and from devices. A buffer is associated with a device. The function iio_device_create_buffer() creates a buffer for a device. Data can be read from or written to the buffer using functions like iio_buffer_refill() and iio_buffer_push().

This page describes the list of routines provided by the libiio library.

DATA TYPES

iio_context
An opaque structure representing an IIO context.
iio_device
An opaque structure representing an IIO device.
iio_channel
An opaque structure representing an IIO channel.
iio_buffer
An opaque structure representing an IIO buffer.
