DESCRIPCIÓN

X509V3_get_d2i() busca una extensión con el OID nid en las extensiones x y, si la encuentra, la decodifica. Si idx es NULL, entonces solo se permite una ocurrencia de la extensión. De lo contrario, se devuelve la primera extensión después del índice *idx y *idx se actualiza a la ubicación de la extensión. Si crit no es NULL, entonces *crit se establece en un valor de estado: -2 si la extensión ocurre múltiples veces (esto solo se devuelve si idx es NULL), -1 si la extensión no se pudo encontrar, 0 si la extensión se encuentra y no es crítica, y 1 si es crítica. Se devuelve un puntero a una estructura específica de la extensión o NULL.

X509V3_add1_i2d() agrega la extensión value a la STACK *x (asignando una nueva STACK si es necesario) usando el OID nid y la criticidad crit según flags.

X509V3_EXT_d2i() intenta decodificar los datos ASN.1 contenidos en la extensión ext y devuelve un puntero a una estructura específica de la extensión o NULL si la extensión no pudo ser decodificada (sintaxis inválida o no soportada).

X509V3_EXT_i2d() codifica la estructura específica de la extensión ext con el OID ext_nid y la criticidad crit.

X509_get_ext_d2i() y X509_add1_ext_i2d() operan sobre las extensiones del certificado x, y son en otros aspectos idénticas a X509V3_get_d2i() y X509V3_add1_i2d().

X509_CRL_get_ext_d2i() y X509_CRL_add1_ext_i2d() operan sobre las extensiones de la CRL crl, y son en otros aspectos idénticas a X509V3_get_d2i() y X509V3_add1_i2d().

X509_REVOKED_get_ext_d2i() y X509_REVOKED_add1_ext_i2d() operan sobre las extensiones de la estructura X509_REVOKED r (es decir, para extensiones de entrada de CRL), y son en otros aspectos idénticas a X509V3_get_d2i() y X509V3_add1_i2d().

X509_get0_extensions(), X509_CRL_get0_extensions(), y X509_REVOKED_get0_extensions() devuelven una pila de todas las extensiones de un certificado, una CRL o una entrada de CRL, respectivamente.

En casi todos los casos, una extensión puede ocurrir como máximo una vez y las ocurrencias múltiples son un error. Por lo tanto, el parámetro idx suele ser NULL.

El argumento flags consta de dos partes OR'adas: el modo de operación y la bandera opcional de silencio. El modo de operación es el OR a nivel de bits de flags y la máscara de bits X509V3_ADD_OP_MASK. Se reconocen los siguientes modos de operación:

X509V3_ADD_DEFAULT agrega una nueva extensión solo si la extensión aún no existe. Se devuelve un error si la extensión ya existe.

X509V3_ADD_APPEND agrega una nueva extensión, ignorando si la extensión ya existe. Esto es un mal diseño y no debe usarse porque los certificados no deben incluir la misma extensión más de una vez.

X509V3_ADD_REPLACE reemplaza una extensión si existe de otro modo

DESCRIPTION

The following functions are available to add and query certificate extensions:

X509V3_add1_i2d()
Adds an extension with NID nid and value ext to the certificate x according to the flags specified in flags. The extension is encoded using DER. If ext is NULL, the extension is deleted if it exists. X509V3_add1_i2d() is a general-purpose function; see also the specific functions like X509_add1_ext_i2d() etc.
X509V3_EXT_d2i()
Decodes extension ext according to NID nid. The content is a GeneralName structure. This is a low-level function; see also X509V3_get_ext_d2i() etc.
X509V3_get_ext_d2i()
Gets extension nid from certificate x. The extension is decoded and returned. If the extension is not found, or if multiple instances are found, NULL is returned. The crit parameter is a pointer to an integer which will be set to the criticality of the extension if found. The return value is typically an ASN1_OCTET_STRING or other appropriate structure depending on the extension type.
X509_get_ext_d2i()
Similar to X509V3_get_ext_d2i() but without the criticality flag.
X509_CRL_get_ext_d2i()
Similar to X509V3_get_ext_d2i() but for a CRL crl.
X509_REVOKED_get_ext_d2i()
Similar to X509V3_get_ext_d2i() but for a revoked certificate entry rev.
X509_add1_ext_i2d()
Adds an extension to a certificate x. nid is the extension NID, value is the extension value, and flags are operation flags.
X509_CRL_add1_ext_i2d()
Adds an extension to a CRL crl.
X509_REVOKED_add1_ext_i2d()
Adds an extension to a revoked certificate entry rev.
X509V3_get_ext()
Returns the extension with NID nid from certificate x. If no such extension exists, NULL is returned. This function returns the raw X509_EXTENSION structure. Use X509V3_EXT_print() to print it or X509V3_EXT_d2i() to decode it.
X509_get0_extension_flags()
Returns the flags for the extension with NID nid in certificate x. If the extension is not found, 0 is returned.
X509_get0_authority_key_id()
Returns the authority key identifier from certificate x in *key. Returns NULL if the extension is not present.
X509_get0_subject_key_id()
Returns the subject key identifier from certificate x in *key. Returns NULL if the extension is not present.
X509_get0_uids()
Returns the issuer and subject unique identifiers of the certificate x in *issuerUID and *subjectUID. If a unique identifier field is not present in x, NULL is returned. Either one of issuerUID and subjectUID can be NULL.

The operation flags are:

X509V3_ADD_APPEND
Appends a new extension. If the extension already exists, it is not added. No error is returned if the extension exists.
X509V3_ADD_REPLACE
Replaces an existing extension if it exists, otherwise appends a new extension.
X509V3_ADD_NEW
Appends a new extension. If the extension already exists, an error is returned.
X509V3_ADD_SILENT
Suppresses error messages. If this flag is set, errors are not printed.
X509V3_ADD_USE_NID
Uses the NID nid to identify the extension. Without this flag, the OID is used.

X509V3_ADD_NEW replaces an existing extension if it exists otherwise returns an error.

X509V3_ADD_KEEP_EXISTING appends a new extension only if the extension does not already exist. An error is not returned if the extension does already exist.

X509V3_ADD_DELETE deletes extension nid if it exists and errors otherwise. No new extension is added.

Any other operation mode results in an error.

If X509V3_ADD_SILENT is OR'd into the flags, any error returned will not be added to the error queue.

The function X509V3_get_d2i() will return NULL if the extension is not found, occurs multiple times or cannot be decoded. It is possible to determine the precise reason by checking the value of *crit.

X509_get0_uids() returns the issuer and subject unique identifiers of the certificate x in *issuerUID and *subjectUID. If a unique identifier field is not present in x, NULL is returned. Either one of issuerUID and subjectUID can be NULL.

RETURN VALUES

X509V3_get_d2i(), X509V3_EXT_d2i(), X509_get_ext_d2i(), X509_CRL_get_ext_d2i(), and X509_REVOKED_get_ext_d2i() return a pointer to an extension specific structure or NULL if an error occurs.

X509V3_add1_i2d(), X509_add1_ext_i2d(), X509_CRL_add1_ext_i2d(), and X509_REVOKED_add1_ext_i2d() return 1 if the operation is successful, 0 if it fails due to a non-fatal error (extension not found, already exists, cannot be encoded), or -1 due to a fatal error such as a memory allocation failure. In some cases of failure, the reason

puede ser determinado con ERR_get_error(3).

La función X509V3_EXT_i2d() devuelve un puntero a una estructura X509_EXTENSION si tiene éxito; de lo contrario, se devuelve NULL y se puede recuperar un código de error con ERR_get_error(3).

X509_get0_extensions(), X509_CRL_get0_extensions() y X509_REVOKED_get0_extensions() devuelven una pila de extensiones, o NULL si no hay extensiones presentes.

HISTORIA

La función X509V3_EXT_d2i() apareció por primera vez en OpenSSL 0.9.2b. La función X509V3_EXT_i2d() apareció por primera vez en OpenSSL 0.9.3. Ambas funciones han estado disponibles desde OpenBSD 2.6.

Las funciones X509V3_get_d2i(), X509_get_ext_d2i(), X509_CRL_get_ext_d2i() y X509_REVOKED_get_ext_d2i() aparecieron por primera vez en OpenSSL 0.9.5 y han estado disponibles desde OpenBSD 2.7.

Las funciones X509V3_add1_i2d(), X509_add1_ext_i2d(), X509_CRL_add1_ext_i2d() y X509_REVOKED_add1_ext_i2d() aparecieron por primera vez en OpenSSL 0.9.7 y han estado disponibles desde OpenBSD 3.2.

Las funciones X509_get0_extensions(), X509_CRL_get0_extensions() y X509_REVOKED_get0_extensions() aparecieron por primera vez en OpenSSL 1.1.0 y han estado disponibles desde OpenBSD 6.3.

La función X509_get0_uids() apareció por primera vez en OpenSSL 1.1.0 y ha estado disponible desde OpenBSD 7.3.
