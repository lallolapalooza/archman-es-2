LILYPOND(1) Comandos de usuario LILYPOND(1)

NOMBRE

LilyPond - página del manual para LilyPond 2.24.4 (ejecutando Guile 3.0)

SINOPSIS

lilypond [OPCIÓN]... ARCHIVO...

DESCRIPCIÓN

Compone música y/o produce MIDI a partir de ARCHIVO.

LilyPond produce hermosas partituras. Para más información, vea https://lilypond.org

OPCIONES

-f, --formats=FORMATOS
exportar FORMATO,... También como opciones separadas:
--pdf
generar archivos PDF (por defecto)
--svg
generar archivos SVG
--png
generar archivos PNG
--ps
generar archivos PostScript
-E, --eps
generar archivos PostScript encapsulado
-O, --pspdfopt=CLAVE
establecer la optimización de ps/pdf a CLAVE, que puede ser 'size' (por defecto), 'TeX', o 'TeX-GS'
-d, --define-default=SIMBOLO[=VALOR]
establecer la opción Scheme SIMBOLO a VALOR (por defecto: '#t')
-d, --define-default=no-SIMBOLO
establecer la opción Scheme SIMBOLO a '#f'
-d, --define-default=help
mostrar ayuda para las opciones de Scheme
-e, --evaluate=EXPR
evaluar código scheme
-h, --help
mostrar esta ayuda y salir
-H, --header=CAMPO
exportar el campo \header CAMPO al archivo llamado BASENAME.CAMPO
-I, --include=DIR
añadir DIR a la ruta de búsqueda
-i, --init=ARCHIVO
usar ARCHIVO como archivo de inicialización
-j, --jail=USUARIO,GRUPO,JAIL,DIR
cambiar la raíz a JAIL, convertirse en USUARIO:GRUPO y cambiar al directorio DIR
-l, --loglevel=NIVEL_DE_LOG
imprimir mensajes de log de acuerdo con NIVEL_DE_LOG, que puede ser NONE, ERROR, WARNING, BASIC, PROGRESS, INFO (por defecto), o DEBUG
-o, --output=ARCHIVO
escribir la salida a ARCHIVO (se añadirá sufijo) o a CARPETA, en cuyo caso el nombre del archivo se tomará del archivo de entrada.
--relocate
(ignorado)
-s, --silent
sin progreso, solo mensajes de error (equivalente a --loglevel=ERROR)
-v, --version
mostrar número de versión y salir
-V, --verbose
ser verboso (equivalente a --loglevel=DEBUG)
-w, --warranty
mostrar garantía y derechos de autor

¿Encontraste un error? Por favor lee https://lilypond.org/bug-reports.html
