LIBKECCAK_HMAC_INITIALISE(3) Manual de funciones de biblioteca LIBKECCAK_HMAC_INITIALISE(3)

NOMBRE

libkeccak_hmac_initialise - Inicializar estado de hashing HMAC

SINOPSIS

#include <libkeccak.h>
int libkeccak_hmac_initialise(struct libkeccak_hmac_state *state, const struct libkeccak_spec *spec,
                              const void *key, size_t key_length);

Enlazar con -lkeccak.

DESCRIPCIÓN

La función libkeccak_hmac_initialise() inicializa *state y establece los parámetros de ajuste del algoritmo a los especificados por *spec, y la clave a key de longitud key_length.

VALORES DE RETORNO

La función libkeccak_hmac_initialise() devuelve 0 al completar con éxito. En caso de error, se devuelve -1 y errno se establece para describir el error.

ERRORES

La función libkeccak_hmac_initialise() puede fallar por cualquier error especificado para las funciones malloc(3) y realloc(3).
