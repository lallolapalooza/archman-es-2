libressl-BN_cmp(3)

Paquete: libressl

Licencias: ISC, custom:OpenSSL

BN_CMP(3) Manual de funciones de biblioteca BN_CMP(3)

NOMBRE

BN_cmp, BN_ucmp, BN_is_zero, BN_is_one, BN_is_word, BN_abs_is_word, BN_is_odd — funciones de comparación y prueba de BIGNUM

SINOPSIS

biblioteca «libcrypto»
#include <openssl/bn.h>

int
BN_cmp(const BIGNUM *a, const BIGNUM *b);

int
BN_ucmp(const BIGNUM *a, const BIGNUM *b);

int
BN_is_zero(const BIGNUM *a);

int
BN_is_one(const BIGNUM *a);

int
BN_is_word(const BIGNUM *a, const BN_ULONG w);

int
BN_abs_is_word(const BIGNUM *a, const BN_ULONG w);

int
BN_is_odd(const BIGNUM *a);

DESCRIPCIÓN

BN_cmp() compara los números a y b. BN_ucmp() compara sus valores absolutos.

BN_is_zero(), BN_is_one() y BN_is_word() comprueban si a es igual a 0, 1 o w respectivamente. BN_abs_is_word() comprueba si el valor absoluto de a es igual a w. BN_is_odd() comprueba si a es impar.

BN_ULONG es una macro que se expande a unsigned long (= uint64_t) en plataformas _LP64 y unsigned int (= uint32_t) en otros casos.

VALORES DE RETORNO

BN_cmp() devuelve -1 si a<b, 0 si a==b, y 1 si a>b. BN_ucmp() es lo mismo usando los valores absolutos de a y b.

BN_is_zero(), BN_is_one(), BN_is_word(), BN_abs_is_word() y BN_is_odd() devuelven 1 si la condición es verdadera, 0 en caso contrario.

VER TAMBIÉN

BN_new(3)

HISTORIA

BN_cmp(), BN_ucmp(), BN_is_zero(), BN_is_one() y BN_is_word() aparecieron por primera vez en SSLeay 0.5.1. BN_is_odd() apareció por primera vez en SSLeay 0.8.0. Estas funciones han estado disponibles desde OpenBSD 2.4.

BN_abs_is_word() apareció por primera vez en OpenSSL 0.9.7 y ha estado disponible desde OpenBSD 3.2.
