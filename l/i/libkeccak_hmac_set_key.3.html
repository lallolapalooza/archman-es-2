LIBKECCAK_HMAC_SET_KEY(3) Manual de Funciones de Biblioteca LIBKECCAK_HMAC_SET_KEY(3)

NOMBRE

libkeccak_hmac_set_key - Cambia la clave para un estado de hash HMAC sin restablecer el estado del algoritmo de hash subyacente.

SINOPSIS

#include <libkeccak.h>
int libkeccak_hmac_set_key(struct libkeccak_hmac_state *state, const void *key, size_t key_length);

Enlazar con -lkeccak.

DESCRIPCIÓN

La función libkeccak_hmac_set_key() establece la clave para un estado de hash HMAC sin restablecer el estado del algoritmo de hash subyacente. key_length es la longitud de la clave en bits.

VALORES DEVUELTOS

La función libkeccak_hmac_set_key() devuelve 0 en caso de éxito. En caso de error, devuelve -1 y establece errno para describir el error.

ERRORES

La función libkeccak_hmac_set_key() puede fallar por cualquier motivo especificado para la función realloc(3).

VER TAMBIÉN

libkeccak_hmac_create(3), libkeccak_hmac_initialise(3), libkeccak_hmac_reset(3)
