NOMBRE

libkeccak_hmac_fast_digest - Completa el hash HMAC de un mensaje sin borrado

SINOPSIS

#include <libkeccak.h>
int libkeccak_hmac_fast_digest(struct libkeccak_hmac_state *state, const void *msg, size_t msglen,
                               size_t bits, const char *suffix, void *hashsum);

Enlazar con -lkeccak.

DESCRIPCIÓN

La función libkeccak_hmac_fast_digest() absorbe la última parte de (o todo) un mensaje y devuelve el hash HMAC de todo el mensaje. La última parte del mensaje se especifica mediante el parámetro msg, y su tamaño en bytes se especifica mediante el parámetro msglen. Si todo el mensaje ya ha sido procesado por llamadas a la función libkeccak_hmac_update(3) o a la función libkeccak_hmac_fast_update(3) (con el mismo puntero en state), msg y msglen deben establecerse en NULL y 0, respectivamente.

Si el mensaje no se compone de un número entero de bytes, el número de bits, módulo 8, en el mensaje debe especificarse en el parámetro bits. msglen solo debe contar el número de bytes completos, es decir, el suelo del número de bits en el mensaje dividido por 8.

suffix debe ser una cadena terminada en NUL de caracteres ASCII '1' y '0', que representa los bits que se añadirán al mensaje. Si esta cadena está vacía, se puede usar NULL en su lugar. Esto se utiliza para seleccionar el algoritmo de hash. Para Keccak puro, se usa NULL o "". Para los otros algoritmos se usan las constantes LIBKECCAK_SHA3_SUFFIX (para SHA-3), LIBKECCAK_RAWSHAKE_SUFFIX (para RawSHAKE) y LIBKECCAK_SHAKE_SUFFIX (para SHAKE).

El hash del mensaje se almacenará en hashsum, a menos que hashsum sea NULL (lo que aumenta el rendimiento de la llamada). Se escribirán un total de ((state->n + 7) / 8) bytes en el inicio de hashsum. Por lo tanto, hashsum necesita al menos una asignación de ese número de bytes.

La función libkeccak_hmac_fast_digest() puede reasignar el buffer del mensaje del estado. Al hacerlo, intenta hacerlo lo más rápido posible, en lugar de asegurar que la información en la asignación antigua se elimine de forma segura si se requiere una nueva asignación.

VALORES DE RETORNO

La función libkeccak_hmac_fast_digest() devuelve 0 si se completa con éxito. En caso de error, se devuelve -1 y se establece errno para describir el error.

ERRORES

La función libkeccak_hmac_fast_digest() puede fallar por cualquier motivo especificado por la función realloc(3).

VER TAMBIÉN
