LIBMIKMOD(1) Manual de Comandos Generales LIBMIKMOD(1)

NOMBRE

libmikmod-config - script para obtener información sobre la versión instalada de libmikmod.

SINOPSIS

libmikmod-config [--prefix[=DIR]] [--exec-prefix[=DIR]] --version --libs --cflags --ldadd

DESCRIPCIÓN

libmikmod-config es una herramienta que se utiliza para determinar las opciones del compilador y del enlazador que deben usarse para compilar y enlazar programas que utilizan libmikmod. También es utilizado internamente por la macro libmikmod.m4 para GNU autoconf que se incluye con libmikmod.

OPCIONES

libmikmod-config acepta las siguientes opciones:

--version
Imprime la versión actualmente instalada de libmikmod en la salida estándar.
--libs
Imprime las opciones del enlazador que son necesarias para enlazar un programa libmikmod.
--ldadd
Imprime las opciones adicionales del enlazador que son necesarias para enlazar un programa libmikmod si fue compilado con el compilador GNU C.
--cflags
Imprime las opciones del compilador que son necesarias para compilar un programa libmikmod.
--prefix=PREFIJO
Si se especifica, utiliza PREFIJO en lugar del prefijo de instalación con el que se compiló libmikmod al calcular la salida para las opciones --cflags y --libs. Esta opción también se utiliza para el prefijo de ejecución si no se especificó --exec-prefix. Esta opción debe especificarse antes de cualquier opción --libs o --cflags.
--exec-prefix=PREFIJO
Si se especifica, utiliza PREFIJO en lugar del prefijo de ejecución de instalación con el que se compiló libmikmod al calcular la salida para las opciones --cflags y --libs. Esta opción debe especificarse antes de cualquier opción --libs o --cflags.
