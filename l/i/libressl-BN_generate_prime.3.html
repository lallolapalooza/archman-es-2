DESCRIPCIÓN

BN_is_prime_ex() y BN_is_prime_fasttest_ex() comprueban si el número a es primo. En LibreSSL, ambas funciones se comportan de forma idéntica y utilizan el algoritmo de Baillie-Pomerance-Selfridge-Wagstaff combinado con nchecks rondas de Miller-Rabin. El argumento do_trial_division se ignora.

Se desconoce si existe algún número compuesto que el algoritmo Baillie-PSW clasifique erróneamente como primo. Algunos sospechan que puede existir un número infinito de tales números, pero actualmente no se conoce ninguno. Se sabe que no existe ningún número de este tipo por debajo de 2^64.

Para reducir la probabilidad de que un número compuesto supere las pruebas de primalidad BN_is_prime_fasttest_ex() y BN_is_prime_ex(), se realizan un número de rondas de la prueba probabilística de Miller-Rabin. Si nchecks es positivo, se utiliza como número de rondas; si es cero o el valor especial BN_prime_checks, se calcula un número adecuado de rondas a partir de la longitud en bits de a.

Si se pasa NULL para el argumento ctx, estas funciones asignan un objeto BN_CTX internamente cuando lo necesitan y lo liberan antes de devolver. Alternativamente, para ahorrar la sobrecarga de asignar y liberar ese objeto en cada llamada, el llamador puede preasignar un objeto BN_CTX y pasarlo en el argumento ctx.

BN_generate_prime_ex() genera un número primo pseudoaleatorio de al menos bits bits de longitud y lo coloca en ret. La primalidad de ret se prueba internamente utilizando BN_is_prime_ex(). En consecuencia, para bits mayores que 64, es teóricamente posible que esta función coloque un número compuesto en ret; la probabilidad de tal evento es desconocida pero muy pequeña.

El primo puede tener que cumplir requisitos adicionales para su uso en el intercambio de claves Diffie-Hellman:

  • Si modulus no es NULL, se genera un primo que cumple la condición ret % modulus = remainder. Si el argumento remainder es NULL, se utiliza 1 como resto deseado.
  • Si el argumento safe es distinto de cero, se genera un primo seguro, es decir, (ret - 1)/2 también es primo.

Si cb no es NULL, se utiliza de la siguiente manera:

  • BN_GENCB_call(cb, 0, serial_number) se llama después de generar un primo potencial.
  • El state_code de 1 está reservado para devoluciones de llamada durante las pruebas de primalidad, pero LibreSSL no realiza dichas devoluciones de llamada.
  • Cuando safe es distinto de cero y se ha encontrado un primo seguro, se llama BN_GENCB_call(cb, 2, serial_number).
  • Los llamadores de BN_generate_prime_ex() pueden llamar a BN_GENCB_call() con otros valores como se describe en sus respectivas páginas del manual; véase VER TAMBIÉN.

En todos los casos, el serial_number es el número de candidatos que ya han sido descartados por no ser primos; es decir, serial_number es 0 para el primer candidato y luego se incrementa cada vez que se genera un nuevo candidato.

BN_GENCB_call() llama a la función de devolución de llamada que se encuentra en cb y pasa el state_code y el serial_number como argumentos. Si cb es NULL o no contiene una función de devolución de llamada, no ocurre ninguna acción.

BN_GENCB_new() asigna un nuevo objeto BN_GENCB.

BN_GENCB_free() libera cb. Si cb es NULL, no ocurre ninguna acción.

BN_GENCB_set() inicializa cb para usar el puntero a la función de devolución de llamada cb_fp y el argumento adicional de devolución de llamada cb_arg.

La función obsoleta BN_GENCB_set_old() inicializa cb para usar el puntero a la función de devolución de llamada de estilo antiguo cb_fp y el argumento adicional de devolución de llamada cb_arg.

VALORES DE RETORNO

BN_is_prime_ex() y BN_is_prime_fasttest_ex() devuelven 0 si el número es compuesto, 1 si es primo con una probabilidad de error muy pequeña, o -1 en caso de error.

BN_generate_prime_ex() devuelve 1 en caso de éxito o 0 en caso de error.

BN_GENCB_call() devuelve 1 en caso de éxito, incluido cuando cb es NULL o no contiene una función de devolución de llamada, o 0 en caso de error.

BN_generate_prime(3)

NAME

BN_generate_prime, BN_generate_prime_ex, BN_is_prime, BN_is_prime_ex, BN_is_prime_fasttest, BN_is_prime_fasttest_ex, BN_GENCB_new, BN_GENCB_free, BN_GENCB_get_arg, BN_GENCB_call, BN_GENCB_set, BN_GENCB_set_old – generate prime numbers, check for primality, and setup callback functions

BN_is_prime_ex(const BIGNUM *a, int checks, BN_CTX *ctx, BN_GENCB *cb);

    BN_GENCB *cb);
BN_GENCB *
BN_GENCB_new(void);
void
BN_GENCB_free(BN_GENCB *cb);
void *
BN_GENCB_get_arg(const BN_GENCB *cb);
int
BN_GENCB_call(BN_GENCB *cb, int event, int arg2);
void
BN_GENCB_set(BN_GENCB *cb, int (*callback)(int, int, void *), void *arg);
void
BN_GENCB_set_old(BN_GENCB *cb, int (*callback)(int, int, BN_CTX *),
    BN_CTX *ctx);

BN_is_prime_fasttest(const BIGNUM *a, int checks, void (*callback)(int, int, void *),
    BN_CTX *ctx, int doAtest, void *arg);

DESCRIPTION

The functions BN_generate_prime() and BN_generate_prime_ex() generate a prime number of bits length and store it in ret. If safe is non-zero, a safe prime is generated. A prime number p is a safe prime if (p-1)/2 is also a prime.

If add is not NULL, the generated prime is of the form 2*add + rem, where rem is 0 or 1. If add is NULL, then rem is ignored.

If cb is not NULL, it is a pointer to a callback structure which will be used to report progress and receive control information.

The callback functions pointed to by the cb_fp arguments are supposed to return 1 on success or 0 on error.

The function BN_generate_prime_ex2() is similar to BN_generate_prime_ex() but it allows passing a BN_CTX. This is useful for performance.

The function BN_is_prime() checks if the BIGNUM a is prime. The parameter checks specifies the number of Miller-Rabin iterations to perform. The higher the value, the lower the probability of a false positive (i.e. a composite number being reported as prime). A value of 0 means that the default number of iterations is used.

The parameter cb is a pointer to a callback structure. The function BN_GENCB_call() is called during the primality testing to report progress. The event parameter indicates the type of event and arg2 contains additional information. The return value of the callback function should be 1 to continue the primality test, or 0 to abort it.

The function BN_is_prime_ex() is similar to BN_is_prime() but it allows passing a BN_CTX. This is useful for performance.

The function BN_is_prime_fasttest_ex() performs a faster primality test. It first performs a series of trial divisions by small primes, and then uses the Miller-Rabin test. The parameter doAtest should be non-zero if the Lucas test should be performed after the Miller-Rabin test.

BN_GENCB_new() allocates and initializes a new BN_GENCB object. It returns a pointer to the newly allocated object, or NULL if memory allocation fails.

BN_GENCB_free() frees the memory associated with cb.

BN_GENCB_set() sets the callback function and user data pointer for the BN_GENCB object cb. The callback function callback is called with the user data pointer arg.

BN_GENCB_set_old() sets the callback function and BN_CTX for the BN_GENCB object cb. The callback function callback is called with the BN_CTX pointer.

The callback functions pointed to by the cb_fp arguments are supposed to return 1 on success or 0 on error.

BN_GENCB_get_arg() returns the cb_arg pointer that was previously stored in cb using BN_GENCB_set() or BN_GENCB_set_old().

In some cases, error codes can be obtained by ERR_get_error(3).

RETURN VALUES

BN_generate_prime(), BN_generate_prime_ex(), and BN_generate_prime_ex2() return 1 on success, or 0 on failure. Use ERR_get_error(3) to get error codes.

BN_is_prime(), BN_is_prime_ex(), and BN_is_prime_fasttest_ex() return 1 if a is likely prime, and 0 otherwise. If the callback function returns 0, the primality test is aborted and these functions return 0.

BN_GENCB_new() returns a pointer to the newly allocated BN_GENCB object or NULL if memory allocation fails.

The callback functions pointed to by the cb_fp arguments are supposed to return 1 on success or 0 on error.

BN_GENCB_get_arg() returns the cb_arg pointer that was previously stored in cb using BN_GENCB_set() or BN_GENCB_set_old().

In some cases, error codes can be obtained by ERR_get_error(3).

HISTORY

BN_generate_prime_ex(), BN_is_prime_ex(), BN_is_prime_fasttest_ex(), BN_GENCB_call(), BN_GENCB_set_old(), and BN_GENCB_set() first appeared in OpenSSL 0.9.8 and have been available since OpenBSD 4.5.

BN_GENCB_new(), BN_GENCB_free(), and BN_GENCB_get_arg() first appeared in OpenSSL 1.1.0 and have been available since OpenBSD 6.3.
