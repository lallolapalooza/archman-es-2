SMIME_READ_PKCS7(3) Manual de funciones de biblioteca SMIME_READ_PKCS7(3)

NOMBRE

SMIME_read_PKCS7 — extraer un objeto PKCS#7 de un mensaje S/MIME

SINOPSIS

biblioteca “libcrypto”
#include <openssl/pkcs7.h>

PKCS7 *
SMIME_read_PKCS7(BIO *in, BIO **bcont);

DESCRIPCIÓN

SMIME_read_PKCS7() analiza un mensaje en formato S/MIME.

in es un BIO desde el cual leer el mensaje.

Si se utiliza firma de texto plano, el contenido se guarda en un BIO de memoria que se escribe en *bcont, de lo contrario, *bcont se establece en NULL.

Se devuelve la estructura PKCS#7 analizada, o NULL si ocurrió un error.

Si *bcont no es NULL, entonces el mensaje está firmado con texto plano. Luego, *bcont se puede pasar a PKCS7_verify(3) con el indicador PKCS7_DETACHED establecido.

De lo contrario, el tipo de la estructura devuelta se puede determinar utilizando las macros PKCS7_type_is_*() definidas en <openssl/pkcs7.h>.

Para admitir funcionalidad futura, si bcont no es NULL, *bcont debe inicializarse en NULL. Por ejemplo:

BIO *cont = NULL;
PKCS7 *p7;

p7 = SMIME_read_PKCS7(in, &cont);

VALORES DEVUELTOS

SMIME_read_PKCS7() devuelve una estructura PKCS7 válida o NULL si ocurrió un error. El error se puede obtener de ERR_get_error(3).

VER TAMBIÉN

BIO_f_base64(3), BIO_new(3), PKCS7_new(3), SMIME_read_CMS(3), SMIME_text(3), SMIME_write_PKCS7(3)

HISTORIA

SMIME_read_PKCS7() apareció por primera vez en OpenSSL 0.9.5 y ha estado disponible desde OpenBSD 2.7.

ERRORES

El analizador MIME utilizado por SMIME_read_PKCS7() es algo primitivo. Si bien manejará la mayoría de los mensajes S/MIME, los formatos compuestos más complejos pueden no funcionar.

El analizador asume que la estructura PKCS7 siempre está codificada en base64, y no manejará el caso en que esté en formato binario o utilice formato quoted-printable.

El uso de un BIO de memoria para contener el contenido firmado limita el tamaño del mensaje que se puede procesar debido a restricciones de memoria: debería haber disponible una opción de paso único en streaming.
