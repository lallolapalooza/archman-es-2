libressl-DSA_meth_new(3)

Paquete: libressl

Licencias: ISC, custom:OpenSSL

DSA_METH_NEW(3) Manual de funciones de biblioteca DSA_METH_NEW(3)

NOMBRE

DSA_meth_new, DSA_meth_free, DSA_meth_dup, DSA_meth_get0_name, DSA_meth_set1_name, DSA_meth_set_sign, DSA_meth_set_finish — crear métodos DSA

SINOPSIS

biblioteca “libcrypto”
#include <openssl/dsa.h>

DSA_METHOD *
DSA_meth_new(const char *name, int flags);

void
DSA_meth_free(DSA_METHOD *meth);

DSA_METHOD *
DSA_meth_dup(const DSA_METHOD *meth);

const char *
DSA_meth_get0_name(const DSA_METHOD *meth);

int
DSA_meth_set1_name(DSA_METHOD *meth, const char *name);

int
DSA_meth_set_sign(DSA_METHOD *meth, DSA_SIG *(*sign)(const unsigned char *, int, DSA *));

int
DSA_meth_set_finish(DSA_METHOD *meth, int (*finish)(DSA *));

DESCRIPCIÓN

La estructura DSA_METHOD contiene punteros de función para implementaciones DSA personalizadas.

DSA_meth_new() crea una nueva estructura DSA_METHOD. Se almacena una copia del name terminado en NUL en el nuevo objeto DSA_METHOD. Cualquier nuevo objeto DSA construido a partir de esta DSA_METHOD tendrá los flags dados establecidos por defecto.

DSA_meth_dup() crea una copia profunda de meth. Esto puede ser útil para crear una nueva DSA_METHOD basada en una existente, pero con algunas diferencias.

DSA_meth_free() destruye meth y libera cualquier memoria asociada a él.

DSA_meth_get0_name() devuelve un puntero interno al nombre de meth. DSA_meth_set1_name() almacena una copia del name terminado en NUL en meth después de liberar el nombre almacenado previamente. Los nombres de método son ignorados por la implementación DSA predeterminada, pero pueden ser utilizados por implementaciones alternativas y por el programa de aplicación.

DSA_meth_set_sign() establece la función utilizada para crear una firma DSA. Esta función será llamada desde DSA_do_sign(3) e indirectamente desde DSA_sign(3). Los parámetros de sign tienen el mismo significado que para DSA_do_sign(3).

DSA_meth_set_finish() establece una función opcional para destruir un objeto DSA. A menos que finish sea NULL, será llamada desde DSA_free(3). Toma el mismo argumento y tiene la intención de realizar una limpieza específica de la implementación DSA. La memoria utilizada por el propio objeto DSA no debe ser liberada por la función finish.

VALORES DE RETORNO

DSA_meth_new() y DSA_meth_dup() devuelven el objeto DSA_METHOD recién asignado o NULL en caso de fallo.

DSA_meth_get0_name() devuelve un puntero interno que el llamante no debe liberar.

DSA_meth_set1_name() y todas las funciones DSA_meth_set_*() devuelven 1 en caso de éxito o 0 en caso de fallo. En la implementación actual, solo DSA_meth_set1_name() puede fallar realmente.

VER TAMBIÉN

DSA_do_sign(3), DSA_new(3), DSA_set_method(3), DSA_SIG_new(3), DSA_sign(3)

HISTORIA

Estas funciones aparecieron por primera vez en OpenSSL 1.1.0.

DSA_meth_new(), DSA_meth_free(), DSA_meth_dup(), DSA_meth_set_sign(), y DSA_meth_set_finish() han estado disponibles desde OpenBSD 6.3.

DSA_meth_get0_name() y DSA_meth_set1_name() han estado disponibles desde OpenBSD 7.2.
