libressl-X509_CRL_get0_by_serial(3)

Paquete: libressl

Licencias: ISC, custom:OpenSSL

X509_CRL_GET0_BY_SERIAL(3) Manual de funciones de biblioteca X509_CRL_GET0_BY_SERIAL(3)

NOMBRE

X509_CRL_get0_by_serial, X509_CRL_get0_by_cert, X509_CRL_get_REVOKED, X509_CRL_add0_revoked, X509_CRL_sort — añadir, ordenar y recuperar entradas de CRL

SINOPSIS

biblioteca “libcrypto”
#include <openssl/x509.h>

int
X509_CRL_get0_by_serial(X509_CRL *crl, X509_REVOKED **ret, ASN1_INTEGER *serial);

int
X509_CRL_get0_by_cert(X509_CRL *crl, X509_REVOKED **ret, X509 *x);

STACK_OF(X509_REVOKED) *
X509_CRL_get_REVOKED(X509_CRL *crl);

int
X509_CRL_add0_revoked(X509_CRL *crl, X509_REVOKED *rev);

int
X509_CRL_sort(X509_CRL *crl);

DESCRIPCIÓN

X509_CRL_get0_by_serial() intenta encontrar una entrada revocada en crl para el número de serie serial. Si tiene éxito, establece *ret al puntero interno de la entrada coincidente. En consecuencia, *ret no debe liberarse después de la llamada.

X509_CRL_get0_by_cert() es similar a X509_CRL_get0_by_serial() excepto en que busca una entrada revocada usando el número de serie del certificado x.

X509_CRL_get_REVOKED() devuelve un puntero interno a una pila de todas las entradas revocadas para crl.

X509_CRL_add0_revoked() añade la entrada revocada rev a la CRL crl. Se usa el puntero rev internamente, por lo que no debe liberarse después de la llamada: se libera cuando se libera la CRL padre.

X509_CRL_sort() ordena las entradas revocadas de crl en orden ascendente de número de serie.

Las aplicaciones pueden determinar el número de entradas revocadas devueltas por X509_CRL_get_revoked() usando sk_X509_REVOKED_num() y examinarlas una por una usando sk_X509_REVOKED_value(), ambas definidas en <openssl/safestack.h>.

VALORES DE RETORNO

X509_CRL_get0_by_serial() y X509_CRL_get0_by_cert() devuelven 0 para fallo o 1 para éxito, excepto si la entrada revocada tiene la razón "removeFromCRL", en cuyo caso se devuelve 2.

La función X509_CRL_add0_revoked() devuelve 1 si tiene éxito; de lo contrario, se devuelve 0 y se puede obtener un código de error con ERR_get_error(3).

X509_CRL_sort() devuelve 1 para éxito o 0 para fallo. La implementación actual no puede fallar.

X509_CRL_get_REVOKED() devuelve una STACK de entradas revocadas.

VER TAMBIÉN

HISTORIA

X509_CRL_get_REVOKED() apareció por primera vez en OpenSSL 0.9.2b y ha estado disponible desde OpenBSD 2.6.

X509_CRL_add0_revoked() y X509_CRL_sort() aparecieron por primera vez en OpenSSL 0.9.7 y han estado disponibles desde OpenBSD 3.2.

X509_CRL_get0_by_serial() y X509_CRL_get0_by_cert() aparecieron por primera vez en OpenSSL 1.0.0 y han estado disponibles desde OpenBSD 4.9.
