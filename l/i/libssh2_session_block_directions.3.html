NOMBRE

libssh2_session_block_directions - obtener direcciones para esperar

SINOPSIS

#include <libssh2.h>
int
libssh2_session_block_directions(LIBSSH2_SESSION *session);

DESCRIPCIÓN

session - Instancia de sesión devuelta por libssh2_session_init_ex(3)

Cuando alguna de las funciones de libssh2 devuelve LIBSSH2_ERROR_EAGAIN, la aplicación debe esperar a que el socket tenga datos disponibles para leer o escribir. Dependiendo del valor de retorno de libssh2_session_block_directions(3), la aplicación debe esperar para leer, escribir o ambos.

VALOR DE RETORNO

Devuelve el conjunto de direcciones como una máscara binaria. Puede ser una combinación de:

LIBSSH2_SESSION_BLOCK_INBOUND: Dirección entrante bloqueada.

LIBSSH2_SESSION_BLOCK_OUTBOUND: Dirección saliente bloqueada.

La aplicación debe esperar a que haya datos disponibles para el socket antes de llamar de nuevo a una función de libssh2. Si se establece LIBSSH2_SESSION_BLOCK_INBOUND, select debe incluir el socket de la sesión en el conjunto readfds. De manera correspondiente, en caso de LIBSSH2_SESSION_BLOCK_OUTBOUND, el conjunto writefds debe incluir el socket.
