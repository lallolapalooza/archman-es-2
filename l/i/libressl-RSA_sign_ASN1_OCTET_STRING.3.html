libressl-RSA_sign_ASN1_OCTET_STRING(3)

Paquete: libressl

Licencias: ISC, custom:OpenSSL

RSA_SIGN_ASN1_OCTET_STRING(3) Manual de funciones de la biblioteca RSA_SIGN_ASN1_OCTET_STRING(3)

NOMBRE

RSA_sign_ASN1_OCTET_STRING, RSA_verify_ASN1_OCTET_STRING — firmas RSA

SINOPSIS

biblioteca “libcrypto”;
#include <openssl/rsa.h>

int
RSA_sign_ASN1_OCTET_STRING(int dummy, unsigned char *m, unsigned int m_len, unsigned char *sigret, unsigned int *siglen, RSA *rsa);

int
RSA_verify_ASN1_OCTET_STRING(int dummy, unsigned char *m, unsigned int m_len, unsigned char *sigbuf, unsigned int siglen, RSA *rsa);

DESCRIPCIÓN

RSA_sign_ASN1_OCTET_STRING() firma la cadena de octetos m de tamaño m_len usando la clave privada rsa representada en DER usando el relleno PKCS #1. Almacena la firma en sigret y el tamaño de la firma en siglen. sigret debe apuntar a RSA_size(rsa) bytes de memoria.

dummy se ignora.

RSA_verify_ASN1_OCTET_STRING() verifica que la firma sigbuf de tamaño siglen es la representación DER de una cadena de octetos dada m de tamaño m_len. dummy se ignora. rsa es la clave pública del firmante.

VALORES DE RETORNO

RSA_sign_ASN1_OCTET_STRING() devuelve 1 en caso de éxito o 0 en caso contrario. RSA_verify_ASN1_OCTET_STRING() devuelve 1 en caso de verificación exitosa o 0 en caso contrario.

Los códigos de error se pueden obtener mediante ERR_get_error(3).

VER TAMBIÉN

RSA_new(3), RSA_sign(3), RSA_verify(3)

HISTORIAL

RSA_sign_ASN1_OCTET_STRING() y RSA_verify_ASN1_OCTET_STRING() aparecieron por primera vez en SSLeay 0.8.0 y han estado disponibles desde OpenBSD 2.4.

ERRORES

Estas funciones no tienen un propósito reconocible.
