libressl-RSA_sign(3)

Paquete: libressl

Licencias: ISC, custom:OpenSSL

RSA_SIGN(3) Manual de funciones de la biblioteca RSA_SIGN(3)

NOMBRE

RSA_sign, RSA_verify — firmas RSA

SINOPSIS

biblioteca “libcrypto”
#include <openssl/rsa.h>

int
RSA_sign(int type, const unsigned char *m, unsigned int m_len, unsigned char *sigret, unsigned int *siglen, RSA *rsa);

int
RSA_verify(int type, const unsigned char *m, unsigned int m_len, unsigned char *sigbuf, unsigned int siglen, RSA *rsa);

DESCRIPCIÓN

RSA_sign() firma el resumen del mensaje m de tamaño m_len usando la clave privada rsa utilizando RSASSA-PKCS1-v1_5 según se especifica en RFC 3447. Almacena la firma en sigret y el tamaño de la firma en siglen. sigret debe apuntar a RSA_size(rsa) bytes de memoria. Tenga en cuenta que PKCS #1 agrega metadatos, lo que limita el tamaño de la clave que se puede utilizar. Consulte RSA_private_encrypt(3) para ver operaciones de menor nivel.

type denota el algoritmo de resumen de mensaje que se utilizó para generar m. Si type es NID_md5_sha1, se crea una firma SSL (resúmenes MD5 y SHA-1 con relleno PKCS #1 y sin identificador de algoritmo).

RSA_verify() verifica que la firma sigbuf de tamaño siglen coincida con un resumen de mensaje dado m de tamaño m_len. type denota el algoritmo de resumen de mensaje que se utilizó para generar la firma. rsa es la clave pública del firmante.

VALORES DE RETORNO

RSA_sign() devuelve 1 en caso de éxito. RSA_verify() devuelve 1 en caso de verificación exitosa.

Los códigos de error se pueden obtener mediante ERR_get_error(3).

VER TAMBIÉN

RSA_meth_set_sign(3), RSA_new(3), RSA_private_encrypt(3), RSA_public_decrypt(3)

ESTÁNDARES

SSL, PKCS #1 v2.0

HISTORIA

RSA_sign() apareció por primera vez en SSLeay 0.4.4. RSA_verify() apareció por primera vez en SSLeay 0.6.0. Ambas funciones han estado disponibles desde OpenBSD 2.4.
