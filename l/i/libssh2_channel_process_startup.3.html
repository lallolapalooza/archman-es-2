NOMBRE

libssh2_channel_process_startup - solicitar un shell en un canal

SINOPSIS

#include <libssh2.h>
int
libssh2_channel_process_startup(LIBSSH2_CHANNEL *channel,
                                const char *request,
                                unsigned int request_len,
                                const char *message,
                                unsigned int message_len);

DESCRIPCIÓN

channel - Instancia de canal de sesión activa.

request - Tipo de proceso a iniciar. El protocolo SSH2 actualmente define shell, exec y subsystem como servicios de proceso estándar.

request_len - Longitud del parámetro request.

message - Datos del mensaje específico de la solicitud a incluir.

message_len - Longitud del parámetro message.

Inicia una solicitud en un canal de tipo sesión, como el devuelto por libssh2_channel_open_ex(3)

VALOR DE RETORNO

Devuelve 0 si tiene éxito o un valor negativo en caso de fallo. Devuelve LIBSSH2_ERROR_EAGAIN cuando de otro modo se bloquearía. Si bien LIBSSH2_ERROR_EAGAIN es un número negativo, no es realmente un fallo en sí mismo.

ERRORES

LIBSSH2_ERROR_ALLOC - Falló una llamada interna de asignación de memoria.

LIBSSH2_ERROR_SOCKET_SEND - No se pudieron enviar datos por el socket.

LIBSSH2_ERROR_CHANNEL_REQUEST_DENIED -
