NOMBRE

libmicrohttpd — biblioteca para integrar servidores HTTP

BIBLIOTECA

biblioteca “libmicrohttpd”

SINOPSIS

#include <microhttpd.h>

DESCRIPCIÓN

GNU libmicrohttpd (MHD en adelante) permite a las aplicaciones integrar fácilmente la funcionalidad de un servidor HTTP simple. MHD es un paquete GNU.

Los detalles de la API se describen en comentarios en el archivo de encabezado, una documentación de referencia detallada en Texinfo, un tutorial y brevemente en la página web de MHD.

AVISO LEGAL

libmicrohttpd se publica bajo la LGPL Versión 2.1 o superior y la GNU GPL con la extensión eCos. Para obtener detalles sobre ambas licencias, lea el apéndice correspondiente en el manual de Texinfo.
