Descripción Detallada

Funciones para manipular transacciones de libalpm

Las transacciones son la forma de añadir/eliminar paquetes al/del sistema. Solo puede existir una transacción a la vez.

El flujo básico de una transacción es:

  • Inicializar con alpm_trans_init
  • Elegir qué paquetes añadir con alpm_add_pkg y alpm_remove_pkg
  • Preparar la transacción con alpm_trans_prepare
  • Confirmar la transacción con alpm_trans_commit
  • Liberar la transacción con alpm_trans_release

Una transacción puede ser liberada en cualquier momento. Una transacción no tiene por qué ser confirmada.

Documentación de Tipos de Enumeración

enum alpm_transflag_t

Marcas de transacción.

Enumerador

ALPM_TRANS_FLAG_NODEPS
Ignorar comprobaciones de dependencias.
ALPM_TRANS_FLAG_NOSAVE
Eliminar archivos aunque estén marcados como copia de seguridad.
ALPM_TRANS_FLAG_NODEPVERSION
Ignorar números de versión al comprobar dependencias.
ALPM_TRANS_FLAG_CASCADE
Eliminar también cualquier paquete que dependa de un paquete que se está eliminando.
ALPM_TRANS_FLAG_RECURSE
Eliminar paquetes y sus dependencias no necesarias (no instaladas explícitamente).
ALPM_TRANS_FLAG_DBONLY
Modificar la base de datos pero no confirmar los cambios en el sistema de archivos.
ALPM_TRANS_FLAG_NOHOOKS
No ejecutar hooks durante una transacción.
ALPM_TRANS_FLAG_ALLDEPS
Usar ALPM_PKG_REASON_DEPEND al instalar paquetes.
ALPM_TRANS_FLAG_DOWNLOADONLY
Solo descargar paquetes y no instalarlos realmente.
ALPM_TRANS_FLAG_NOSCRIPTLET
No ejecutar scriptlets de instalación después de instalar.
ALPM_TRANS_FLAG_NOCONFLICTS
Ignorar conflictos de dependencias.
ALPM_TRANS_FLAG_NEEDED
No instalar un paquete si ya está instalado y actualizado.
ALPM_TRANS_FLAG_ALLEXPLICIT
Usar ALPM_PKG_REASON_EXPLICIT al instalar paquetes.
ALPM_TRANS_FLAG_UNNEEDED
No eliminar un paquete si es necesario para otro.
ALPM_TRANS_FLAG_RECURSEALL
Eliminar también las dependencias no necesarias instaladas explícitamente (usar con ALPM_TRANS_FLAG_RECURSE).
ALPM_TRANS_FLAG_NOLOCK
No bloquear la base de datos durante la operación.

Documentación de Funciones

int alpm_add_pkg (alpm_handle_t * handle, alpm_pkg_t * pkg)

Añade un paquete a la transacción. Si el paquete fue cargado por alpm_pkg_load(), se liberará al invocar alpm_trans_release.

Parámetros

handle el manejador de contexto
pkg el paquete a añadir

Devuelve

0 si tiene éxito, -1 si hay un error (pm_errno se establece en consecuencia)

int alpm_remove_pkg (alpm_handle_t * handle, alpm_pkg_t * pkg)

Añade la eliminación de un paquete a la transacción.

Parámetros

handle el manejador de contexto
pkg el paquete a desinstalar

Devuelve

0 si tiene éxito, -1 si hay un error (pm_errno se establece en consecuencia)

int alpm_sync_sysupgrade (alpm_handle_t * handle, int enable_downgrade)

Busca paquetes para actualizar y los añade a la transacción. Si enable_downgrade es distinto de cero, se buscarán también actualizaciones para paquetes que tengan instalada una versión más reciente.

Parámetros

handle el manejador de contexto
enable_downgrade habilita la búsqueda de paquetes para degradar

Devuelve

0 si tiene éxito, -1 si hay un error (pm_errno se establece en consecuencia)

int alpm_trans_commit (alpm_handle_t * handle, alpm_list_t ** data)

Confirma la transacción. Los paquetes se descargarán si es necesario, se actualizará la base de datos y se instalarán/eliminarán los archivos. Los paquetes descargados se guardarán en la caché de paquetes.

Parámetros

handle el manejador de contexto
data el puntero al que se devolverá una lista de paquetes que han sido eliminados o que se han actualizado. La lista solo se asigna si la función tiene éxito.

Devuelve

0 si tiene éxito, -1 si hay un error (pm_errno se establece en consecuencia)

alpm_list_t * alpm_trans_get_add (alpm_handle_t * handle)

Devuelve una lista de paquetes añadidos por la transacción. La lista debe ser liberada con alpm_list_free().

Parámetros

handle el manejador de contexto

Devuelve

la lista de paquetes a añadir o NULL si no hay ninguno.

int alpm_trans_get_flags (alpm_handle_t * handle)

Devuelve el campo de bits de marcas para la transacción actual.

Parámetros

handle el manejador de contexto

Devuelve

el campo de bits de marcas o 0 si no se ha inicializado ninguna transacción.

alpm_list_t * alpm_trans_get_remove (alpm_handle_t * handle)

Devuelve la lista de paquetes eliminados por la transacción. La lista debe ser liberada con alpm_list_free().

Parámetros

handle el manejador de contexto

Devuelve

la lista de paquetes a eliminar o NULL si no hay ninguno.

int alpm_trans_init (alpm_handle_t * handle, int flags)

Inicializa la transacción. Solo puede existir una transacción a la vez.

Parámetros

handle el manejador de contexto
flags marcas para la transacción (ver alpm_transflag_t)

Devuelve

0 si tiene éxito, -1 si hay un error (pm_errno se establece en consecuencia)

int alpm_trans_interrupt (alpm_handle_t * handle)

Interrumpe una transacción. Esto es útil si el usuario desea cancelar la operación.

Parámetros

handle el manejador de contexto

Devuelve

0 si tiene éxito, -1 si hay un error (pm_errno se establece en consecuencia)

int alpm_trans_prepare (alpm_handle_t * handle, alpm_list_t ** data)

Prepara una transacción. Esto implica comprobar las dependencias, detectar conflictos y calcular la lista de paquetes a instalar/eliminar.

Parámetros

handle el manejador de contexto
data el puntero al que se devolverá una lista de paquetes que han sido eliminados o que se han actualizado. La lista solo se asigna si la función tiene éxito.

Devuelve

0 si tiene éxito, -1 si hay un error (pm_errno se establece en consecuencia)

int alpm_trans_release (alpm_handle_t * handle)

Libera una transacción. Esto también liberará cualquier paquete que haya sido cargado por alpm_pkg_load() y añadido a la transacción.

Parámetros

handle el manejador de contexto

Devuelve

0 si tiene éxito, -1 si hay un error (pm_errno se establece en consecuencia)
