libkeccak_update(3)

Paquete: libkeccak

LIBKECCAK_UPDATE(3) Manual de funciones de biblioteca LIBKECCAK_UPDATE(3)

NOMBRE

libkeccak_update - Calcula parcialmente un hash de un mensaje con borrado

SINOPSIS

#include <libkeccak.h>
int libkeccak_update(struct libkeccak_state *state, const void *msg, size_t msglen);

Enlazar con -lkeccak.

DESCRIPCIÓN

La función libkeccak_update() continúa (o inicia) el cálculo del hash de un mensaje. El estado actual del cálculo del hash se almacena en *state y se actualizará. Se calculará el hash del mensaje especificado por el parámetro msg con el tamaño en bytes especificado por el parámetro msglen.

La función libkeccak_update() puede reasignar el búfer de fragmentos de mensaje del estado. Al hacerlo, intenta hacerlo de forma tan segura como sea posible, en lugar de lo más rápido posible.

VALORES DE RETORNO

La función libkeccak_update() devuelve 0 al completarse con éxito. En caso de error, se devuelve -1 y se establece errno para describir el error.

ERRORES

La función libkeccak_update() puede fallar por cualquier motivo especificado por la función malloc(3).

NOTAS

Ninguno de los parámetros puede ser NULL o 0.

EJEMPLO

Este ejemplo calcula el hash Keccak[b = 1024, c = 576, n = 256] de la entrada estándar y lo imprime en formato hexadecimal en la salida estándar.

struct libkeccak_state state;
struct libkeccak_spec spec;
char binhash[256 / 8];
char hexhash[256 / 8 * 2 + 1];
char chunk[4 << 10];
ssize_t len;
spec.bitrate = 1024;
spec.capacity = 576;
spec.output = 256;
if (libkeccak_state_initialise(&state, &spec) < 0)
	goto fail;
for (;;) {
	len = read(STDIN_FILENO, chunk, sizeof(chunk));
	if ((len < 0) && (errno == EINTR))
		continue;
	if (len < 0)
		goto fail;
	if (len == 0)
		break;
	if (libkeccak_update(&state, chunk, (size_t)len) < 0)
		goto fail;
}
if (libkeccak_digest(&state, NULL, 0, 0, "", binhash) < 0)
	goto fail;
libkeccak_behex_lower(hexhash, binhash, sizeof(binhash));
printf("%s\n", hexhash);
libkeccak_state_destroy(&state);

NOTAS

Para cSHAKE, se debe llamar a libkeccak_cshake_initialise(3) una vez, inmediatamente después de la inicialización del estado; antes de la primera llamada a la función libkeccak_update().
