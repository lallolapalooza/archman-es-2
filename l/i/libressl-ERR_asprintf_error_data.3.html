ERR_ASPRINTF_ERROR_DATA(3) Manual de Funciones de Librería ERR_ASPRINTF_ERROR_DATA(3)

NOMBRE

ERR_asprintf_error_data — registra un error de LibreSSL usando una cadena formateada

SINOPSIS

librería “libcrypto”
#include <openssl/err.h>

void
ERR_asprintf_error_data(char * format, ...);

DESCRIPCIÓN

ERR_asprintf_error_data construye una cadena usando asprintf(3) llamado con el formato y los argumentos proporcionados. La cadena resultante se asocia con el código de error que se agregó más recientemente. Si asprintf(3) falla, se asocia la cadena "malloc failed" en su lugar.

ERR_asprintf_error_data está pensada para ser utilizada en lugar de las funciones de OpenSSL ERR_add_error_data() y ERR_add_error_vdata().

VER TAMBIÉN

ERR(3), ERR_put_error(3), printf(3)

HISTORIAL

ERR_asprintf_error_data apareció en OpenBSD 5.6 y está disponible en todas las versiones de LibreSSL.
