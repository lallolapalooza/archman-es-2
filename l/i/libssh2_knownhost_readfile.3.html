NOMBRE

libssh2_knownhost_readfile - analizar un archivo de hosts conocidos

SINOPSIS

#include <libssh2.h>
int
libssh2_knownhost_readfile(LIBSSH2_KNOWNHOSTS *hosts,
                           const char *filename, int type);

DESCRIPCIÓN

Lee una colección de hosts conocidos de un archivo especificado y los agrega a la colección de hosts conocidos.

filename especifica qué archivo leer

type especifica qué tipo de archivo es, y LIBSSH2_KNOWNHOST_FILE_OPENSSH es el único formato actualmente soportado. Este archivo normalmente se encuentra con el nombre ~/.ssh/known_hosts

VALOR DE RETORNO

Devuelve un valor negativo, un código de error regular de libssh2 para errores, o un número positivo que representa la cantidad de hosts conocidos analizados en el archivo.

DISPONIBILIDAD

Añadido en libssh2 1.2
