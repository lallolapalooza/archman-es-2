DESCRIPCIÓN

SSL_CTX_set0_chain() y SSL_CTX_set1_chain() establecen la cadena de certificados asociada con el certificado actual de ctx a chain. Se supone que chain no incluye el certificado actual en sí mismo.

SSL_CTX_add0_chain_cert() y SSL_CTX_add1_chain_cert() añaden el certificado individual cert a la cadena asociada con el certificado actual de ctx.

SSL_CTX_get0_chain_certs() recupera la cadena asociada con el certificado actual de ctx.

SSL_CTX_clear_chain_certs() borra la cadena existente asociada con el certificado actual de ctx, si la hay. Esto es equivalente a llamar a SSL_CTX_set0_chain() con chain establecido a NULL.

Cada una de estas funciones opera en el certificado de extremo (es decir, servidor o cliente) actual. Este es el último certificado cargado o seleccionado en la estructura ctx correspondiente, por ejemplo, usando SSL_CTX_use_certificate(3).

SSL_set0_chain(), SSL_set1_chain(), SSL_add0_chain_cert(), SSL_add1_chain_cert(), SSL_get0_chain_certs(), y SSL_clear_chain_certs() son similares excepto que operan en la conexión ssl.

Las funciones que contienen un 1 en su nombre incrementan el contador de referencias del certificado o cadena proporcionado, por lo que debe liberarse en algún momento después de la operación. Las que contienen un 0 no incrementan los contadores de referencias y el certificado o cadena proporcionado no debe liberarse después de la operación.

Las cadenas asociadas con una estructura SSL_CTX se copian a la nueva estructura SSL cuando se llama a SSL_new(3). Las estructuras SSL existentes no se ven afectadas por ninguna cadena modificada posteriormente en la SSL_CTX padre.

Se puede establecer una cadena por cada tipo de clave admitido por un servidor. Por lo tanto, por ejemplo, un certificado RSA y uno ECDSA pueden tener cadenas diferentes.

Si se añaden certificados utilizando estas funciones, no se utilizarán los certificados añadidos con SSL_CTX_add_extra_chain_cert(3).

VALORES DE RETORNO

Estas funciones devuelven 1 para éxito o 0 para fallo.

VER TAMBIÉN
