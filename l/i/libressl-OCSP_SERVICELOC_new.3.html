libressl-OCSP_SERVICELOC_new(3)

Paquete: libressl

Licencias: ISC, custom:OpenSSL

OCSP_SERVICELOC_NEW(3) Manual de funciones de la biblioteca OCSP_SERVICELOC_NEW(3)

NOMBRE

OCSP_SERVICELOC_new, OCSP_SERVICELOC_free, OCSP_url_svcloc_new — extensión de localizador de servicio OCSP

SINOPSIS

biblioteca “libcrypto”
#include <openssl/ocsp.h>

OCSP_SERVICELOC *
OCSP_SERVICELOC_new(void);

void
OCSP_SERVICELOC_free(OCSP_SERVICELOC *sloc);

X509_EXTENSION *
OCSP_url_svcloc_new(X509_NAME *issuer, const char **urls);

DESCRIPCIÓN

Debido a las restricciones de enrutamiento de red, un cliente puede no ser capaz de contactar directamente al servidor OCSP autoritativo para un certificado que necesita ser verificado. En ese caso, la solicitud puede ser enviada a través de un servidor proxy. Una estructura ASN.1 ServiceLocator se incluye en el campo singleRequestExtensions de la estructura Request para indicar dónde reenviar la solicitud. El ServiceLocator es representado por un objeto OCSP_SERVICELOC, que se almacenará dentro del objeto OCSP_ONEREQ documentado en OCSP_ONEREQ_new(3).

OCSP_SERVICELOC_new() asigna e inicializa un objeto OCSP_SERVICELOC vacío. OCSP_SERVICELOC_free() libera sloc.

OCSP_url_svcloc_new() requiere un nombre issuer y opcionalmente acepta un array de urls. Si urls o su primer elemento es NULL, el campo localizador se omite de la estructura ServiceLocator y solo se incluye el emisor. La estructura resultante ServiceLocator se codifica en ASN.1 usando X509V3_EXT_i2d(3) con criticidad 0.

VALORES DE RETORNO

OCSP_SERVICELOC_new() devuelve un nuevo objeto OCSP_SERVICELOC o NULL si ocurrió un error.

OCSP_url_svcloc_new() devuelve un nuevo objeto X509_EXTENSION o NULL si ocurrió un error.

VER TAMBIÉN

OCSP_REQUEST_new(3), X509_EXTENSION_new(3), X509_get1_ocsp(3), X509_get_issuer_name(3), X509_NAME_new(3)

ESTÁNDARES

RFC 6960: X.509 Internet Public Key Infrastructure Online Certificate Status Protocol, sección 4.4.6: Service Locator

HISTORIA

OCSP_SERVICELOC_new(), OCSP_SERVICELOC_free(), y OCSP_url_svcloc_new() aparecieron por primera vez en OpenSSL 0.9.7 y han estado disponibles desde OpenBSD 3.2.
