D2I_PKCS8PRIVATEKEY_BIO(3) Manual de funciones de biblioteca D2I_PKCS8PRIVATEKEY_BIO(3)

NOMBRE

d2i_PKCS8PrivateKey_bio, d2i_PKCS8PrivateKey_fp, i2d_PKCS8PrivateKey_bio, i2d_PKCS8PrivateKey_fp, i2d_PKCS8PrivateKey_nid_bio, i2d_PKCS8PrivateKey_nid_fp — Funciones de clave privada en formato PKCS#8

SINOPSIS

biblioteca “libcrypto”
#include <openssl/evp.h>

EVP_PKEY *
d2i_PKCS8PrivateKey_bio(BIO *bp, EVP_PKEY **x, pem_password_cb *cb, void *u);

EVP_PKEY *
d2i_PKCS8PrivateKey_fp(FILE *fp, EVP_PKEY **x, pem_password_cb *cb, void *u);

int
i2d_PKCS8PrivateKey_bio(BIO *bp, EVP_PKEY *x, const EVP_CIPHER *enc, char *kstr, int klen, pem_password_cb *cb, void *u);

int
i2d_PKCS8PrivateKey_fp(FILE *fp, EVP_PKEY *x, const EVP_CIPHER *enc, char *kstr, int klen, pem_password_cb *cb, void *u);

int
i2d_PKCS8PrivateKey_nid_bio(BIO *bp, EVP_PKEY *x, int nid, char *kstr, int klen, pem_password_cb *cb, void *u);

int
i2d_PKCS8PrivateKey_nid_fp(FILE *fp, EVP_PKEY *x, int nid, char *kstr, int klen, pem_password_cb *cb, void *u);

DESCRIPCIÓN

Las funciones PKCS#8 codifican y decodifican claves privadas en formato PKCS#8 utilizando algoritmos de cifrado basados en contraseña de PKCS#5 v1.5 y PKCS#5 v2.0.

Aparte del uso de DER en lugar de PEM, estas funciones son idénticas a las funciones correspondientes descritas en PEM_read_PrivateKey(3).

Actualmente, estas funciones son la única forma de almacenar claves privadas cifradas en formato DER.

Actualmente, todas las funciones utilizan punteros a BIO o FILE. No hay funciones que operen directamente sobre memoria, aunque esto se puede solucionar fácilmente convirtiendo los búferes a BIOs de memoria; consulte BIO_s_mem(3) para más detalles.

VALORES DE RETORNO

d2i_PKCS8PrivateKey_bio() y d2i_PKCS8PrivateKey_fp() devuelven un objeto EVP_PKEY o NULL si ocurre un error.

i2d_PKCS8PrivateKey_bio(), i2d_PKCS8PrivateKey_fp(), i2d_PKCS8PrivateKey_nid_bio() y i2d_PKCS8PrivateKey_nid_fp() devuelven 1 si la operación es exitosa o 0 si ocurre un error.

VER TAMBIÉN

d2i_X509_SIG(3), PEM_write_PKCS8PrivateKey(3), PKCS8_PRIV_KEY_INFO_new(3)

HISTORIAL

Estas funciones aparecieron por primera vez en OpenSSL 0.9.5 y han estado disponibles desde OpenBSD 2.7.

ADVERTENCIAS

No confunda estas funciones con i2d_PKCS8PrivateKeyInfo_bio(3) y i2d_PKCS8PrivateKeyInfo_fp(3), que escriben claves privadas en formato DER sin cifrar.
