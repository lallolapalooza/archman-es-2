X509_CHECK_PRIVATE_KEY(3) Manual de funciones de biblioteca X509_CHECK_PRIVATE_KEY(3)

NOMBRE

X509_check_private_key, X509_REQ_check_private_key — comparar componentes de clave pública

SINOPSIS

biblioteca “libcrypto”
#include <openssl/x509.h>

int
X509_check_private_key(const X509 *x, const EVP_PKEY *k);

int
X509_REQ_check_private_key(X509_REQ *x, EVP_PKEY *k);

DESCRIPCIÓN

Estas funciones tienen nombres muy desafortunados. X509_check_private_key() compara los componentes públicos (por ejemplo, el exponente y el módulo de una clave RSA) y los parámetros (por ejemplo, los parámetros EC de una clave EC) de k con las propiedades correspondientes de x. A pesar del nombre, no comprueba si k contiene componentes de clave privada en absoluto, ni, si hay alguno presente, si son consistentes con los componentes de clave pública.

X509_REQ_check_private_key() es equivalente a X509_check_private_key() excepto en que compara con la clave pública contenida en una solicitud de certificado.

VALORES DE RETORNO

Estas funciones devuelven 1 si los componentes y parámetros de la clave pública coinciden, o 0 si no lo hacen o si ocurre un error. En caso de error o desajuste, se puede obtener un código de motivo utilizando ERR_get_error(3).

VER TAMBIÉN

SSL_check_private_key(3), X509_new(3), X509_REQ_new(3)

HISTORIA

X509_check_private_key() apareció por primera vez en SSLeay 0.6.5 y ha estado disponible desde OpenBSD 2.4.

X509_REQ_check_private_key() apareció por primera vez en OpenSSL 0.9.8 y ha estado disponible desde OpenBSD 4.5.
