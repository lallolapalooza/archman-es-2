NOMBRE

nss-myhostname, libnss_myhostname.so.2 - Resolución de nombres de host para el nombre de host del sistema configurado localmente

SINOPSIS

libnss_myhostname.so.2

DESCRIPCIÓN

nss-myhostname es un módulo plug-in para la funcionalidad NSS (Name Service Switch) de la biblioteca C de GNU (glibc), que proporciona principalmente la resolución de nombres de host para el nombre de host del sistema configurado localmente, tal como lo devuelve gethostname(2). Los nombres de host precisos resueltos por este módulo son:

•El nombre de host local configurado se resuelve en todas las direcciones IP configuradas localmente, ordenadas por su alcance o, si no hay ninguna configurada, la dirección IPv4 127.0.0.2 (que está en el bucle local) y la dirección IPv6 ::1 (que es el host local).
•Los nombres de host "localhost" y "localhost.localdomain" (así como cualquier nombre de host que termine en ".localhost" o ".localhost.localdomain") se resuelven en las direcciones IP 127.0.0.1 y ::1.
•El nombre de host "_gateway" se resuelve en todas las direcciones IP de la puerta de enlace de enrutamiento predeterminada actuales, ordenadas por su métrica. Esto asigna un nombre de host estable a la puerta de enlace actual, útil para referenciarlo independientemente del estado de configuración de red actual.
•El nombre de host "_outbound" se resuelve en las direcciones IP IPv4 e IPv6 locales que probablemente se utilizarán para la comunicación con otros hosts. Estas son las direcciones de origen preferidas de las puertas de enlace predeterminadas si se especifican, o se determinan solicitando una decisión de enrutamiento a las puertas de enlace predeterminadas configuradas del kernel y luego utilizando las direcciones IP locales seleccionadas por esta decisión. Este nombre de host solo está disponible si hay al menos una puerta de enlace predeterminada local configurada. Esto asigna un nombre de host estable a las direcciones IP de salida locales, útil para referenciarlas independientemente del estado de configuración de red actual.

Diversos programas dependen de un nombre de host local siempre resoluble. Cuando se utilizan nombres de host dinámicos, esto se logra tradicionalmente modificando /etc/hosts al mismo tiempo que se cambia el nombre de host. Esto es problemático ya que requiere un sistema de archivos /etc/ escribible y es frágil porque el administrador podría editar el archivo al mismo tiempo. Con nss-myhostname habilitado, modificar /etc/hosts es innecesario, y en muchos sistemas, el archivo se vuelve completamente opcional.

Para activar los módulos NSS, agregue "myhostname" a la línea que comienza con "hosts:" en /etc/nsswitch.conf.

Se recomienda colocar "myhostname" después de "files" y antes de "dns". Esto resuelve nombres de host conocidos como "localhost" y los nombres de host de la máquina localmente. Es coherente con el comportamiento de nss-resolve, y aún permite la anulación a través de /etc/hosts.

Tenga en cuenta que nss-myhostname (y nss-resolve) también resuelven en la otra dirección, de direcciones IP adjuntas localmente a nombres de host. Si depende de que esa búsqueda sea proporcionada por DNS, es posible que desee ordenar las cosas de manera diferente.

EJEMPLO

Aquí hay un ejemplo de archivo /etc/nsswitch.conf que habilita correctamente nss-myhostname:

passwd:         files systemd
group:          files [SUCCESS=merge] systemd
shadow:         files systemd
gshadow:        files systemd
hosts:          mymachines resolve [!UNAVAIL=return] files myhostname dns
networks:       files
protocols:      db files
services:       db files
ethers:         db files
rpc:            db files
netgroup:       nis

Para probar, use la herramienta getent(1) de glibc:

$ getent ahosts `hostname`
::1       STREAM omega
::1       DGRAM
::1       RAW
127.0.0.2       STREAM
127.0.0.2       DGRAM
127.0.0.2       RAW

En este caso, el nombre de host local es omega.
