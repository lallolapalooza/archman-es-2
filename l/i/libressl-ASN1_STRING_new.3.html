DESCRIPCIÓN

El objeto ASN1_STRING puede representar una variedad de tipos incorporados de ASN.1. Puede almacenar un tipo y un valor.

Todas las funciones *_new() asignan e inicializan un objeto ASN1_STRING vacío. La siguiente tabla muestra el tipo asignado al nuevo objeto y qué tipo ASN.1 representa.

función constructora ASN1_STRING_new V

El tipo se establece en V_UNKNOWN (desconocido).
ASN1_STRING_type_new V

El tipo se establece en el valor proporcionado type.
ASN1_OCTET_STRING_new ASN1_OCTET_STRING

El tipo se establece en V_OCTET_STRING.
ASN1_BIT_STRING_new ASN1_BIT_STRING

El tipo se establece en V_BIT_STRING.
ASN1_INTEGER_new ASN1_INTEGER

El tipo se establece en V_INTEGER.
ASN1_ENUMERATED_new ASN1_ENUMERATED

El tipo se establece en V_ENUMERATED.
ASN1_UTF8STRING_new ASN1_UTF8STRING

El tipo se establece en V_UTF8STRING.
ASN1_IA5STRING_new ASN1_IA5STRING

El tipo se establece en V_IA5STRING.
ASN1_UNIVERSALSTRING_new ASN1_UNIVERSALSTRING

El tipo se establece en V_UNIVERSALSTRING.
ASN1_BMPSTRING_new ASN1_BMPSTRING

El tipo se establece en V_BMPSTRING.
ASN1_GENERALSTRING_new ASN1_GENERALSTRING

El tipo se establece en V_GENERALSTRING.
ASN1_T61STRING_new ASN1_T61STRING

El tipo se establece en V_T61STRING.
ASN1_VISIBLESTRING_new ASN1_VISIBLESTRING

El tipo se establece en V_VISIBLESTRING.
ASN1_PRINTABLESTRING_new ASN1_PRINTABLESTRING

El tipo se establece en V_PRINTABLESTRING.
ASN1_PRINTABLE_new ASN1_STRING

Similar a ASN1_PRINTABLESTRING_new, pero se utiliza para el tipo general V_PRINTABLE.
DIRECTORYSTRING_new ASN1_STRING

Similar a ASN1_PRINTABLESTRING_new, pero se utiliza para el tipo general V_DIRECTORYSTRING.
DISPLAYTEXT_new ASN1_STRING

Similar a ASN1_PRINTABLESTRING_new, pero se utiliza para el tipo general V_DISPLAYTEXT.
ASN1_GENERALIZEDTIME_new ASN1_GENERALIZEDTIME

El tipo se establece en V_GENERALIZEDTIME.
ASN1_UTCTIME_new ASN1_UTCTIME

El tipo se establece en V_UTCTIME.
ASN1_TIME_new ASN1_TIME

El tipo se establece en V_GENERALIZEDTIME o V_UTCTIME dependiendo de la implementación subyacente.

Las funciones *_free() liberan la memoria asignada al objeto ASN.1 a. Si a es NULL, no se hace nada.

Las estructuras de datos ASN1_OCTET_STRING, ASN1_BIT_STRING, ASN1_INTEGER, ASN1_ENUMERATED, ASN1_UTF8STRING, ASN1_IA5STRING, ASN1_UNIVERSALSTRING, ASN1_BMPSTRING, ASN1_GENERALSTRING, ASN1_T61STRING, ASN1_VISIBLESTRING, ASN1_PRINTABLESTRING, ASN1_GENERALIZEDTIME, ASN1_UTCTIME y ASN1_TIME son tipos opacos que representan tipos de datos ASN.1. Internamente, todos son estructuras ASN1_STRING con el campo type establecido apropiadamente.

Normalmente, se utilizará una de las funciones *_new() para crear un objeto ASN.1. Después de usarlo, se liberará con la correspondiente función *_free().

La función ASN1_STRING_type_new() es útil si necesita crear una ASN1_STRING con un tipo específico que no está cubierto por las otras funciones constructoras.

EJEMPLO

Crear y liberar una ASN1_OCTET_STRING:

ASN1_OCTET_STRING *os;
os = ASN1_OCTET_STRING_new();
if (os == NULL) {
    /* Error */
    return;
}
/* ... usar os ... */
ASN1_OCTET_STRING_free(os);

DESCRIPTION

The ASN.1 functions with the suffix _new() are constructors for various ASN.1 types. The ASN.1 type is specified by the type argument. The supported types are:

  • V_ASN1_UNDEF: An undefined type.
  • V_ASN1_OCTET_STRING: An OCTET STRING.
  • V_ASN1_BIT_STRING: A BIT STRING.
  • V_ASN1_INTEGER: An INTEGER.
  • V_ASN1_ENUMERATED: An ENUMERATED.
  • V_ASN1_UTF8STRING: A UTF8String.
  • V_ASN1_PRINTABLESTRING: A PrintableString.
  • V_ASN1_ T61STRING: A T61String.
  • V_ASN1_IA5STRING: An IA5String.
  • V_ASN1_GENERALSTRING: A GeneralString.
  • V_ASN1_UNIVERSALSTRING: A UniversalString.
  • V_ASN1_BMPSTRING: A BMPString.
  • V_ASN1_VISIBLSTRING: A VisibleString.
  • V_ASN1_UTCTIME: A UTCTime.
  • V_ASN1_GENERALIZEDTIME: A GeneralizedTime.
  • V_ASN1_ANY: A value of any ASN.1 type.

The constructors for specific ASN.1 types, such as ASN1_OCTET_STRING_new(), are convenience functions that call ASN1_STRING_type_new() with the appropriate type.

The ASN1_UTCTIME_new() and ASN1_GENERALIZEDTIME_new() functions create new ASN.1 time values. The ASN1_TIME_new() function creates a generic ASN.1 time value. It is recommended to use ASN1_UTCTIME_new() or ASN1_GENERALIZEDTIME_new() directly.

The DIRECTORYSTRING_new() and DISPLAYTEXT_new() functions are convenience functions for creating ASN.1 strings that are suitable for use in directory information.

The ASN.1 type is a value of the ASN1_TYPE enumeration. The supported constants are defined in <openssl/asn1.h>.

The functions ending in _free() free the ASN.1 structure pointed to by a. If a is NULL, no action is taken.

RETURN VALUES

All the *_new() functions return the new ASN1_STRING object if successful; otherwise NULL is returned and an error code can be retrieved with ERR_get_error(3).

BUGS

ASN1_OCTET_STRING, ASN1_BIT_STRING, ASN1_INTEGER, ASN1_ENUMERATED, ASN1_UTF8STRING, ASN1_IA5STRING, ASN1_UNIVERSALSTRING, ASN1_BMPSTRING, ASN1_GENERALSTRING, ASN1_T61STRING, ASN1_VISIBLESTRING, ASN1_PRINTABLESTRING, ASN1_GENERALIZEDTIME, ASN1_UTCTIME, ASN1_PRINTABLE, DIRECTORYSTRING, and DISPLAYTEXT are all represented using the ASN1_STRING structure. This means that the functions for handling them are largely interchangeable. See ASN1_STRING_set(3) for details.
