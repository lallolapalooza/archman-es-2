NOMBRE

libsmbclient - Una biblioteca de extensión para navegadores que puede ser utilizada como una API de navegación genérica.

SINOPSIS

URL del navegador: smb://[[[dominio:]usuario[:contraseña@]]servidor[/recurso[/ruta[/archivo]]]] [?opciones]

DESCRIPCIÓN

Esta herramienta forma parte del conjunto de herramientas de samba(7).

libsmbclient es un conjunto de herramientas de biblioteca que permite a las aplicaciones manipular recursos de red CIFS/SMB utilizando muchas de las funciones POSIX estándar disponibles para manipular archivos locales de UNIX/Linux. Permite mucho más que la simple navegación; los archivos pueden ser abiertos y leídos o escritos, los permisos modificados, los tiempos de archivo alterados, los atributos y ACLs manipulados, etc. Por supuesto, su funcionalidad incluye todas las capacidades comúnmente llamadas navegación.

libsmbclient no puede ser utilizado directamente desde la línea de comandos; en su lugar, proporciona una extensión de las capacidades de herramientas como los gestores de archivos y navegadores. Esta página del manual describe las opciones de configuración para esta herramienta para que el usuario pueda obtener la mayor utilidad de su uso.

OPCIONES

Lo que significan las URL:

smb://

Muestra todos los grupos de trabajo o dominios que son visibles en la red. El comportamiento coincide con el del Explorador de Microsoft Windows.

El método para localizar la lista de grupos de trabajo (también dominios) varía según la configuración de la variable de contexto (context->options.browse_max_lmb_count). Es responsabilidad de la aplicación que llama a esta biblioteca establecer este valor a uno sensato. Esta es una opción de compilación. Este valor determina el número máximo de navegadores maestros locales a consultar para obtener la lista de grupos de trabajo. Con el fin de asegurar que la lista esté completa para los presentes en la red, se deben consultar todos los navegadores maestros. Si hay un gran número de grupos de trabajo en la red, el tiempo dedicado a la consulta será significativo. Para redes pequeñas (solo unos pocos grupos de trabajo), se sugiere establecer este valor a 0, instruyendo a libsmbclient a consultar todos los navegadores maestros locales. En un entorno que tiene muchos grupos de trabajo, una configuración más razonable puede ser alrededor de 3.

smb://nombre/

Este comando hace que libsmbclient realice una búsqueda de nombre. Si el NOMBRE<1D> o NOMBRE<1B> existe (nombre de grupo de trabajo), libsmbclient listará todos los servidores del grupo de trabajo (o dominio). De lo contrario, se realizará una búsqueda de nombre para el NOMBRE<20> (nombre de máquina), y se mostrará la lista de recursos compartidos en el servidor.

Cuando libsmbclient es invocado por una aplicación, busca un directorio llamado .smb en el directorio $HOME especificado en el entorno del shell del usuario. Luego busca un archivo llamado smb.conf que, si está presente, reemplazará completamente el archivo del sistema /etc/samba/smb.conf. Si en su lugar libsmbclient encuentra un archivo llamado ~/.smb/smb.conf.append, leerá el archivo del sistema /etc/samba/smb.conf y luego añadirá el contenido de ~/.smb/smb.conf.append a él.

libsmbclient comprobará el entorno del shell del usuario en busca del parámetro USER y utilizará su valor si el parámetro user no fue incluido en la URL.
