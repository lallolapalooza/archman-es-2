Paquete: libressl

Licencias: ISC, custom:OpenSSL

ERR_PUT_ERROR(3) Manual de funciones de la biblioteca ERR_PUT_ERROR(3)

NOMBRE

ERR_put_error — registrar un error de OpenSSL

SINOPSIS

biblioteca “libcrypto”
#include <openssl/err.h>

void
ERR_put_error(int lib, int func, int reason, const char *file, int line);

DESCRIPCIÓN

ERR_put_error() añade un código de error a la cola de errores del hilo. Señala que el error con el código de razón reason ocurrió en la función func de la biblioteca lib, en la línea número line del archivo file. Esta función suele ser llamada por una macro.

ERR_load_strings(3) puede usarse para registrar cadenas de error de modo que la aplicación pueda generar mensajes de error legibles para el código de error.

Cada sub-biblioteca tiene una macro específica XXXerr(f, r) que se utiliza para informar de errores. Su primer argumento es un código de función XXX_F_*; el segundo argumento es un código de razón XXX_R_*. Los códigos de función se derivan de los nombres de las funciones, mientras que los códigos de razón consisten en descripciones textuales del error. Por ejemplo, la función ssl23_read() informa de un "fallo en el handshake" de la siguiente manera:

SSLerr(SSL_F_SSL23_READ, SSL_R_SSL_HANDSHAKE_FAILURE);

Los códigos de función y de razón deben consistir únicamente en caracteres en mayúsculas, números y guiones bajos. El script de generación de archivos de error traduce los códigos de función a nombres de función buscando en los archivos de cabecera un nombre de función apropiado. Si no se encuentra ninguno, simplemente utiliza la forma capitalizada como "SSL23_READ" en el ejemplo anterior.

La sección final de un código de razón (después de "_R_") se traduce a minúsculas y los guiones bajos se cambian por espacios.

Aunque una biblioteca normalmente informará de los errores utilizando su macro XXXerr() específica, se puede utilizar la macro de otra biblioteca. Esto normalmente solo se hace cuando una biblioteca quiere incluir código ASN.1 que debe usar la macro ASN1err().

VER TAMBIÉN

ERR(3), ERR_asprintf_error_data(3), ERR_load_strings(3)

HISTORIA

ERR_put_error() apareció por primera vez en SSLeay 0.4.4 y ha estado disponible desde OpenBSD 2.4.
