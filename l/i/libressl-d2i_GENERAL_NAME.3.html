D2I_GENERAL_NAME(3) Manual de funciones de biblioteca D2I_GENERAL_NAME(3)

NOMBRE

d2i_GENERAL_NAME, i2d_GENERAL_NAME, d2i_GENERAL_NAMES, i2d_GENERAL_NAMES, d2i_EDIPARTYNAME, i2d_EDIPARTYNAME, d2i_OTHERNAME, i2d_OTHERNAME — decodifica y codifica nombres para su uso en extensiones X.509

SINOPSIS

biblioteca “libcrypto”
#include <openssl/x509v3.h>

GENERAL_NAME *
d2i_GENERAL_NAME(GENERAL_NAME **val_out, const unsigned char **der_in, long length);

int
i2d_GENERAL_NAME(GENERAL_NAME *val_in, unsigned char **der_out);

GENERAL_NAMES *
d2i_GENERAL_NAMES(GENERAL_NAMES **val_out, const unsigned char **der_in, long length);

int
i2d_GENERAL_NAMES(GENERAL_NAMES *val_in, unsigned char **der_out);

EDIPARTYNAME *
d2i_EDIPARTYNAME(EDIPARTYNAME **val_out, const unsigned char **der_in, long length);

int
i2d_EDIPARTYNAME(EDIPARTYNAME *val_in, unsigned char **der_out);

OTHERNAME *
d2i_OTHERNAME(OTHERNAME **val_out, const unsigned char **der_in, long length);

int
i2d_OTHERNAME(OTHERNAME *val_in, unsigned char **der_out);

DESCRIPCIÓN

Estas funciones decodifican y codifican nombres que se pueden usar en extensiones X.509. Para obtener detalles sobre la semántica, ejemplos, advertencias y errores, consulte ASN1_item_d2i(3).

d2i_GENERAL_NAME() y i2d_GENERAL_NAME() decodifican y codifican una estructura ASN.1 GeneralName definida en la sección 4.2.1.6 de RFC 5280.

d2i_GENERAL_NAMES() y i2d_GENERAL_NAMES() decodifican y codifican una estructura ASN.1 GeneralNames definida en la sección 4.2.1.6 de RFC 5280.

d2i_EDIPARTYNAME() y i2d_EDIPARTYNAME() decodifican y codifican una estructura ASN.1 EDIPartyName definida en la sección 4.2.1.6 de RFC 5280.

d2i_OTHERNAME() y i2d_OTHERNAME() decodifican y codifican una estructura ASN.1 OtherName definida en la sección 4.2.1.6 de RFC 5280.

VALORES DE RETORNO

d2i_GENERAL_NAME(), d2i_GENERAL_NAMES(), d2i_EDIPARTYNAME(), y d2i_OTHERNAME() devuelven un objeto GENERAL_NAME, GENERAL_NAMES, EDIPARTYNAME o OTHERNAME, respectivamente, o NULL si ocurre un error.

i2d_GENERAL_NAME(), i2d_GENERAL_NAMES(), i2d_EDIPARTYNAME(), y i2d_OTHERNAME() devuelven el número de bytes codificados con éxito o un valor negativo si ocurre un error.

VER TAMBIÉN

ASN1_item_d2i(3), d2i_X509_NAME(3), GENERAL_NAME_new(3), X509_EXTENSION_new(3)

ESTÁNDARES

RFC 5280: Internet X.509 Public Key Infrastructure Certificate and Certificate Revocation List (CRL) Profile, sección 4.2: Extensiones de certificados

HISTORIAL

d2i_GENERAL_NAME(), i2d_GENERAL_NAME(), d2i_GENERAL_NAMES(), y i2d_GENERAL_NAMES() aparecieron por primera vez en OpenSSL 0.9.2b y han estado disponibles desde OpenBSD 2.6.

d2i_OTHERNAME() y i2d_OTHERNAME() aparecieron por primera vez en OpenSSL 0.9.5 y han estado disponibles desde OpenBSD 2.7.

d2i_EDIPARTYNAME() y i2d_EDIPARTYNAME() aparecieron por primera vez en OpenSSL 0.9.7 y han estado disponibles desde OpenBSD 3.2.
