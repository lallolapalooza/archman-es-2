NOMBRE

libkeccak_hmac_update - Calcula parcialmente el hash HMAC de un mensaje con borrado

SINOPSIS

#include <libkeccak.h>
int libkeccak_hmac_update(struct libkeccak_state *state, const void *msg, size_t msglen);

Enlace con -lkeccak.

DESCRIPCIÓN

La función libkeccak_hmac_update() continúa (o inicia) el cálculo del hash HMAC de un mensaje. El estado actual del cálculo del hash se almacena en *state y se actualizará. Se calculará el hash del mensaje especificado por el parámetro msg con el tamaño en bytes especificado por el parámetro msglen.

La función libkeccak_hmac_update() puede reasignar el búfer de fragmentos de mensaje del estado. Al hacerlo, intenta hacerlo de forma segura, en lugar de rápida.

VALORES DE RETORNO

La función libkeccak_hmac_update() devuelve 0 al completarse con éxito. En caso de error, se devuelve -1 y se establece errno para describir el error.

ERRORES

La función libkeccak_hmac_update() puede fallar por cualquier razón especificada por la función malloc(3).

NOTAS

Ninguno de los parámetros puede ser NULL o 0.

VER TAMBIÉN
