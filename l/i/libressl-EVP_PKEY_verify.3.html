libressl-EVP_PKEY_verify(3)

Paquete: libressl

Licencias: ISC, custom:OpenSSL

EVP_PKEY_VERIFY(3) Manual de funciones de la biblioteca EVP_PKEY_VERIFY(3)

NOMBRE

EVP_PKEY_verify_init, EVP_PKEY_verify — verificación de firma usando un algoritmo de clave pública

SINOPSIS

biblioteca “libcrypto”
#include <openssl/evp.h>

int
EVP_PKEY_verify_init(EVP_PKEY_CTX *ctx);

int
EVP_PKEY_verify(EVP_PKEY_CTX *ctx, const unsigned char *sig, size_t siglen, const unsigned char *tbs, size_t tbslen);

DESCRIPCIÓN

La función EVP_PKEY_verify_init() inicializa un contexto de algoritmo de clave pública usando la clave ctx->pkey para una operación de verificación de firma.

La función EVP_PKEY_verify() realiza una operación de verificación de clave pública usando ctx. La firma se especifica usando los parámetros sig y siglen. Los datos verificados (es decir, los datos que se cree que fueron firmados originalmente) se especifican usando los parámetros tbs y tbslen.

Después de la llamada a EVP_PKEY_verify_init(), se pueden realizar operaciones de control específicas del algoritmo para establecer los parámetros apropiados para la operación.

La función EVP_PKEY_verify() se puede llamar más de una vez en el mismo contexto si se realizan varias operaciones utilizando los mismos parámetros.

VALORES DE RETORNO

EVP_PKEY_verify_init() y EVP_PKEY_verify() devuelven 1 si la verificación fue exitosa y 0 si falló. A diferencia de otras funciones, el valor de retorno 0 de EVP_PKEY_verify() solo indica que la firma no se verificó correctamente. Es decir, tbs no coincidió con los datos originales o la firma tenía una forma inválida. No es una indicación de un error más grave.

Un valor negativo indica un error distinto de la falla de verificación de firma. En particular, un valor de retorno de -2 indica que la operación no es compatible con el algoritmo de clave pública.

EJEMPLOS

Verificar firma usando PKCS#1 y el digest SHA-256:

#include <openssl/evp.h>
#include <openssl/rsa.h>

EVP_PKEY_CTX *ctx;
unsigned char *md, *sig;
size_t mdlen, siglen;
EVP_PKEY *verify_key;

/*
 * Supone que verify_key, sig, siglen, md y mdlen ya están configurados
 * y que verify_key es una clave pública RSA.
 */
ctx = EVP_PKEY_CTX_new(verify_key, NULL);
if (!ctx)
	/* Ocurrió un error */
if (EVP_PKEY_verify_init(ctx) <= 0)
	/* Error */
if (EVP_PKEY_CTX_set_rsa_padding(ctx, RSA_PKCS1_PADDING) <= 0)
	/* Error */
if (EVP_PKEY_CTX_set_signature_md(ctx, EVP_sha256()) <= 0)
	/* Error */

/* Realizar operación */
ret = EVP_PKEY_verify(ctx, sig, siglen, md, mdlen);

/*
 * ret == 1 indica éxito, 0 falla la verificación,
 * y < 0 algún otro error.
 */
