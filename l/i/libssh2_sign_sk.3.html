libssh2_sign_sk(3)

Paquete: libssh2

Licencias: BSD

libssh2_sign_sk(3) libssh2 libssh2_sign_sk(3)

NOMBRE

libssh2_sign_sk - Crea una firma de un autenticador FIDO2.

SINOPSIS

#include <libssh2.h>
int
libssh2_sign_sk(LIBSSH2_SESSION *session,
                unsigned char **sig,
                size_t *sig_len,
                const unsigned char *data,
                size_t data_len,
                void **abstract);
typedef struct _LIBSSH2_PRIVKEY_SK {
    int algorithm;
    uint8_t flags;
    const char *application;
    const unsigned char *key_handle;
    size_t handle_len;
    LIBSSH2_USERAUTH_SK_SIGN_FUNC((*sign_callback));
    void **orig_abstract;
} LIBSSH2_PRIVKEY_SK;

DESCRIPCIÓN

session - Instancia de sesión como la devuelta por libssh2_session_init_ex(3)

sig - Un puntero a un búfer donde se colocará la firma. El llamador es responsable de liberar la firma con LIBSSH2_FREE.

sig_len - Un puntero a la longitud del parámetro sig.

data - Los datos a firmar.

data_len - La longitud del parámetro data.

abstract - Un puntero a un puntero a un LIBSSH2_PRIVKEY_SK. Ver descripción más abajo.

Crea una firma a partir de un autenticador FIDO2, utilizando los algoritmos de intercambio de claves sk-ssh-ed25519@openssh.com o sk-ecdsa-sha2-nistp256@openssh.com.

El parámetro abstract es un puntero a un puntero debido al funcionamiento interno de libssh2. LIBSSH2_PRIVKEY_SK debe estar completamente relleno, y el llamador es responsable de toda la gestión de memoria de sus campos.

algorithm - El algoritmo de firma a utilizar. Los valores posibles son LIBSSH2_HOSTKEY_TYPE_ED25519 y LIBSSH2_HOSTKEY_TYPE_ECDSA_256.

flags - Una máscara de bits que especifica opciones para el autenticador. Cuando LIBSSH2_SK_PRESENCE_REQUIRED está establecido, el autenticador requiere un toque. Cuando LIBSSH2_SK_VERIFICATION_REQUIRED está establecido, el autenticador requiere un PIN. Muchos servidores y autenticadores no funcionan correctamente cuando LIBSSH2_SK_PRESENCE_REQUIRED no está establecido.

application - Una cadena definida por el usuario para usarla como nombre RP para el autenticador. Normalmente "ssh:".

key_handle - El identificador de clave a utilizar para la lista de permisos del autenticador.

handle_len - La longitud del parámetro key_handle.

abstract - Datos definidos por el usuario. Cuando se requiere un PIN, use esto para pasar el PIN, o un puntero de función para recuperar el PIN.

key_handle El identificador de clave decodificado del archivo de clave privada.

handle_len La longitud del parámetro key_handle.

sign_callback - Responsable de comunicarse con el autenticador de hardware para generar una firma. En caso de éxito, la información de la firma debe colocarse en el parámetro `sig_info sig_info` y la devolución de llamada debe devolver 0. En caso de fallo, debe devolver un número negativo. Ver libssh2_userauth_publickey_sk(3) para más información.

orig_abstract - Datos definidos por el usuario. Cuando se requiere un PIN, use esto para pasar el PIN, o un puntero de función para recuperar el PIN.

VALOR DE RETORNO

Devuelve 0 en caso de éxito o un valor negativo en caso de fallo.
