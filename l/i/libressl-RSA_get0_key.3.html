DESCRIPCIÓN

Un objeto RSA contiene los componentes para la clave pública y privada. n es el módulo común a ambas claves pública y privada, e es el exponente público y d es el exponente privado. p, q, dmp1, dmq1, y iqmp son los factores para la segunda representación de una clave privada (ver sección 3 Tipos de Clave de PKCS#1), donde p y q son el primer y segundo factor de n. dmp1, dmq1, y iqmp son los exponentes y el coeficiente para los cálculos del Teorema Chino del Resto (CRT).

Los parámetros n, e, y d pueden obtenerse llamando a RSA_get0_key(). Si aún no se han establecido, entonces *n, *e, y *d se establecen a NULL. De lo contrario, se establecen a punteros a las representaciones internas de los valores que no deben ser liberados por el llamador.

Los valores de los parámetros n, e, y d pueden establecerse llamando a RSA_set0_key(). Los valores n y e deben ser distintos de NULL la primera vez que se llama a esta función en un objeto RSA dado. El valor d puede ser NULL. En llamadas subsiguientes, cualquiera de estos valores puede ser NULL, lo que significa que el campo correspondiente se deja sin cambios. Llamar a esta función transfiere la gestión de memoria de los valores al objeto RSA. Por lo tanto, los valores que se han pasado no deben ser liberados por el llamador.

De manera similar, los parámetros p y q pueden obtenerse y establecerse con RSA_get0_factors() y RSA_set0_factors(), y los parámetros dmp1, dmq1, y iqmp pueden obtenerse y establecerse con RSA_get0_crt_params() y RSA_set0_crt_params().

Para RSA_get0_key(), RSA_get0_factors(), y RSA_get0_crt_params(), se permiten argumentos de salida BIGNUM ** con valor NULL. Las funciones ignoran los argumentos NULL pero devuelven valores para otros argumentos no NULL.

Los valores recuperados con RSA_get0_key(), RSA_get0_factors(), y RSA_get0_crt_params() son propiedad del objeto RSA utilizado en la llamada y, por lo tanto, no pueden pasarse a RSA_set0_key(), RSA_set0_factors(), o RSA_set0_crt_params(). Si es necesario, duplique el valor recibido usando BN_dup(3) y pase el duplicado.

Cualquiera de los valores n, e, d, p, q, dmp1, dmq1, y iqmp también pueden ser recuperados por separado por las funciones correspondientes RSA_get0_n(), RSA_get0_e(), RSA_get0_d(), RSA_get0_p(), RSA_get0_q(), RSA_get0_dmp1(), RSA_get0_dmq1(), y RSA_get0_iqmp().

Las funciones RSA_set_flags(), RSA_clear_flags(), y RSA_test_flags() se utilizan para establecer, borrar y probar bits de configuración en el objeto RSA. Los valores de flags se definen en <openssl/rsa.h> y actualmente incluyen RSA_FLAG_SIGN_ VEGFRIFY, RSA_FLAG_NO_BLINDING, y RSA_FLAG_ALLOC_MAX.

VALOR DE RETORNO

Las funciones RSA_set0_key(), RSA_set0_factors(), y RSA_set0_crt_params() devuelven 1 con éxito, o 0 si ocurre un error.

Las funciones RSA_test_flags() devuelven un valor distinto de cero si todos los bits especificados en flags están establecidos en el objeto RSA, y 0 en caso contrario.

Las funciones de obtención devuelven punteros constantes a los datos internos o NULL si los datos no están establecidos.

HISTORIAL

DESCRIPTION

These functions provide access to the components of an RSA private key.

The functions RSA_get0_n(3), RSA_get0_e(3), RSA_get0_d(3), RSA_get0_p(3), RSA_get0_q(3), RSA_get0_dmp1(3), RSA_get0_dmq1(3), and RSA_get0_iqmp(3) return pointers to the public modulus n, public exponent e, private exponent d, prime factor p, prime factor q, exponent CRT parameter dmp1, exponent CRT parameter dmq1, and CRT coefficient iqmp, respectively. The pointers are owned by the RSA object.

The functions RSA_set0_key(3), RSA_set0_factors(3), and RSA_set0_crt_params(3) set the public and private key components. The caller must ensure that the provided BIGNUMs are valid. The RSA object takes ownership of the pointers and will free them when the RSA object is destroyed using RSA_free(3). The arguments n, e, d, p, q, dmp1, dmq1, and iqmp may be NULL to indicate that the respective component is not set. However, for a valid RSA key, n, e, and d must be set. If p and q are set, then dmp1, dmq1, and iqmp can be computed by OpenSSL. If p and q are not set, then the CRT parameters dmp1, dmq1, and iqmp must be provided.

RSA_clear_flags() clears the specified flags in r. RSA_test_flags() tests the flags in r. RSA_set_flags() sets the flags in r; any flags already set remain set. For all three functions, multiple flags can be passed in one call, OR'ed together bitwise.

The following flags are supported:

RSA_FLAG_CACHE_PRIVATE and RSA_FLAG_CACHE_PUBLIC
Precompute information needed for Montgomery multiplication from the private and public key, respectively, and cache it in r for repeated use. These two flags are set by default for the default RSA implementation, RSA_PKCS1_SSLeay(3).
RSA_FLAG_EXT_PKEY
The function set with RSA_meth_set_mod_exp(3) is used for private key operations even if p, q, dmp1, dmq1, and iqmp are all NULL. This flag may be useful with RSA implementations that do not use the private key components stored in the standard fields, for example because they store the private key in external hardware. If this flag is unset, the function set with RSA_meth_set_bn_mod_exp(3) is used with n and d instead.
RSA_FLAG_NO_BLINDING
Turn off blinding during private key encryption and decryption. This flag is set by RSA_blinding_off(3).
RSA_FLAG_SIGN_VER
This flag has no effect. It is provided only for backward compatibility with legacy applications.

The flags RSA_FLAG_BLINDING, RSA_FLAG_CHECKED, RSA_FLAG_FIPS_METHOD, RSA_FLAG_NON_FIPS_ALLOW, and RSA_FLAG_THREAD_SAFE are defined for compatibility with existing code but have no effect.

RETURN VALUES

RSA_get0_n(), RSA_get0_e(), RSA_get0_d(), RSA_get0_p(), RSA_get0_q(), RSA_get0_dmp1(), RSA_get0_dmq1(), and RSA_get0_iqmp() return a pointer owned by the RSA object if the corresponding value has been set, otherwise they return NULL.

RSA_set0_key(), RSA_set0_factors(), and RSA_set0_crt_params() return 1 on success or 0 on failure.

RSA_test_flags() returns those of the given flags currently set in r or 0 if none of the given flags are set.
