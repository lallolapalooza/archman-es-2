libressl-DSA_set_method(3)

Paquete: libressl

Licencias: ISC, custom:OpenSSL

DSA_SET_METHOD(3) Manual de funciones de biblioteca DSA_SET_METHOD(3)

NOMBRE

DSA_set_default_method, DSA_get_default_method, DSA_set_method, DSA_new_method, DSA_OpenSSL — seleccionar método DSA

SINOPSIS

biblioteca “libcrypto”
#include <openssl/dsa.h>

void
DSA_set_default_method(const DSA_METHOD *meth);

const DSA_METHOD *
DSA_get_default_method(void);

int
DSA_set_method(DSA *dsa, const DSA_METHOD *meth);

DSA *
DSA_new_method(ENGINE *engine);

DSA_METHOD *
DSA_OpenSSL(void);

DESCRIPCIÓN

Un objeto DSA_METHOD contiene punteros a las funciones utilizadas para operaciones DSA. Por defecto, se utiliza la implementación interna devuelta por DSA_OpenSSL(). Al seleccionar otro método, se pueden utilizar implementaciones alternativas, como aceleradores de hardware.

DSA_set_default_method() selecciona meth como el método por defecto para todas las estructuras DSA creadas posteriormente.

DSA_get_default_method() devuelve un puntero al método por defecto actual.

DSA_set_method() selecciona meth para realizar todas las operaciones utilizando la clave dsa. Esto reemplaza al DSA_METHOD utilizado por la clave DSA. Es posible tener claves DSA que solo funcionen con ciertas implementaciones de DSA_METHOD, y en tales casos, intentar cambiar el DSA_METHOD para la clave puede tener resultados inesperados.

DSA_new_method() asigna e inicializa una estructura DSA. El argumento engine se ignora y se utiliza el método por defecto controlado por DSA_set_default_method().

La estructura DSA_METHOD se define de la siguiente manera:

struct {
	/* nombre de la implementación */
	const char *name;
	/* firmar */
	DSA_SIG *(*dsa_do_sign)(const unsigned char *dgst, int dlen,
	    DSA *dsa);
	/* pre-calcular k^-1 y r */
	int (*dsa_sign_setup)(DSA *dsa, BN_CTX *ctx_in, BIGNUM **kinvp,
	    BIGNUM **rp);
	/* verificar */
	int (*dsa_do_verify)(const unsigned char *dgst, int dgst_len,
	    DSA_SIG *sig, DSA *dsa);
	/* llamado en DSA_new */
	int (*init)(DSA *DSA);
	/* llamado en DSA_free */
	int (*finish)(DSA *DSA);
	int flags;
} DSA_METHOD;

VALORES DE RETORNO

DSA_OpenSSL() y DSA_get_default_method() devuelven punteros al respectivo DSA_METHOD.

DSA_set_method() devuelve 1 si tiene éxito o 0 si falla. Actualmente, no puede fallar.

DSA_new_method() devuelve NULL y establece un código de error que puede obtenerse con ERR_get_error(3) si la asignación falla. De lo contrario, devuelve un puntero a la estructura recién asignada.

VER TAMBIÉN

DSA_meth_new(3), DSA_new(3)

HISTORIA
