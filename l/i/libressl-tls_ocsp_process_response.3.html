SINOPSIS

biblioteca “libtls” libssl libcrypto
#include <tls.h>

int
tls_ocsp_process_response(struct tls *ctx, const unsigned char *response, size_t size);

const char *
tls_peer_ocsp_url(struct tls *ctx);

int
tls_peer_ocsp_response_status(struct tls *ctx);

int
tls_peer_ocsp_cert_status(struct tls *ctx);

int
tls_peer_ocsp_crl_reason(struct tls *ctx);

const char *
tls_peer_ocsp_result(struct tls *ctx);

time_t
tls_peer_ocsp_revocation_time(struct tls *ctx);

time_t
tls_peer_ocsp_this_update(struct tls *ctx);

time_t
tls_peer_ocsp_next_update(struct tls *ctx);

DESCRIPCIÓN

tls_ocsp_process_response() procesa una respuesta OCSP en bruto en response de tamaño size para verificar el estado de revocación del certificado del par desde ctx. Un código de retorno exitoso de 0 indica que el certificado no ha sido revocado.

tls_peer_ocsp_url() devuelve la URL para la validación OCSP del certificado del par desde ctx.

Las siguientes funciones devuelven información sobre el certificado del par desde ctx que se obtuvo validando una respuesta OCSP grapada durante el apretón de manos, o a través de una llamada anterior a tls_ocsp_process_response().

tls_peer_ocsp_response_status() devuelve el estado de la respuesta OCSP según la RFC 6960 sección 2.3.

tls_peer_ocsp_cert_status() devuelve el código de estado del certificado OCSP según la RFC 6960 sección 2.2.

tls_peer_ocsp_crl_reason() devuelve el código de estado de la razón de revocación del certificado OCSP según la RFC 5280 sección 5.3.1.

tls_peer_ocsp_result() devuelve una representación textual del código de estado OCSP devuelto por una de las tres funciones anteriores. Si la respuesta OCSP fue válida y el certificado no fue revocado, la cadena indica el estado del certificado OCSP. De lo contrario, la cadena indica la razón de revocación del certificado OCSP o el error OCSP.

tls_peer_ocsp_revocation_time() devuelve la hora de revocación OCSP.

tls_peer_ocsp_this_update() devuelve la hora de esta actualización OCSP.

tls_peer_ocsp_next_update() devuelve la hora de la próxima actualización OCSP.

VALORES DE RETORNO

tls_ocsp_process_response() devuelve 0 en éxito o -1 en caso de error.

tls_peer_ocsp_url() y tls_peer_ocsp_result() devuelven NULL en caso de error o condición de falta de memoria.

La función tls_peer_ocsp_response_status() devuelve uno de TLS_OCSP_RESPONSE_SUCCESSFUL, TLS_OCSP_RESPONSE_MALFORMED, TLS_OCSP_RESPONSE_INTERNALERROR, TLS_OCSP_RESPONSE_TRYLATER, TLS_OCSP_RESPONSE_SIGREQUIRED, o TLS_OCSP_RESPONSE_UNAUTHORIZED en caso de éxito o -1 en caso de error.

La función tls_peer_ocsp_cert_status() devuelve uno de TLS_OCSP_CERT_GOOD, TLS_OCSP_CERT_REVOKED, o TLS_OCSP_CERT_UNKNOWN en caso de éxito, y -1 en caso de error.

La función tls_peer_ocsp_crl_reason() devuelve uno de TLS_CRL_REASON_UNSPECIFIED, TLS_CRL_REASON_KEY_COMPROMISE, TLS_CRL_REASON_CA_COMPROMISE, TLS_CRL_REASON_AFFILIATION_CHANGED, TLS_CRL_REASON_SUPERSEDED, TLS_CRL_REASON_CESSATION_OF_OPERATION, TLS_CRL_REASON_CERTIFICATE_HOLD, TLS_CRL_REASON_REMOVE_FROM_CRL, TLS_CRL_REASON_PRIVILEGE_WITHDRAWN, o TLS_CRL_REASON_AA_COMPROMISE en caso de éxito o -1 en caso de error.

tls_peer_ocsp_revocation_time(), tls_peer_ocsp_this_update(), y tls_peer_ocsp_next_update() devuelven un tiempo en segundos desde la época en caso de éxito o -1 en caso de error.

tls_ocsp_process_response(3)

FreeBSD documentation, version 13.1-RELEASE

NAME
tls_ocsp_process_response, tls_ocsp_verify, tls_ocsp_request_ocsp, tls_ocsp_request_raw - functions for processing OCSP responses
LIBRARY
libssl

NAME

tls_ocsp_process_response, tls_ocsp_verify, tls_ocsp_request_ocsp, tls_ocsp_request_raw - functions for processing OCSP responses

SYNOPSIS

#include <openssl/tls.h>

int tls_ocsp_process_response(const struct tls_config *config, BIO *response, X509_STORE *store, OCSP_RESPONSE **resp);

int tls_ocsp_verify(OCSP_RESPONSE *resp, X509_STORE *store, X509_STORE_CTX **ctx);

BIO *tls_ocsp_request_ocsp(X509 *cert, X509 *issuer, const char *host, const char *path);

BIO *tls_ocsp_request_raw(X509 *cert, X509 *issuer, const char *host, const char *path);

DESCRIPTION

The OCSP (Online Certificate Status Protocol) is a protocol for retrieving the revocation status of X.509 digital certificates.

tls_ocsp_process_response() processes an OCSP response from the BIO response. The OCSP response is verified against the certificates in store. If successful, the parsed OCSP response is returned in resp.

tls_ocsp_verify() verifies the OCSP response resp using the certificates in store. If successful, the certificate store context is returned in ctx.

tls_ocsp_request_ocsp() generates an OCSP request for the certificate cert signed by the issuer certificate issuer. The request is sent to the OCSP responder at host and path. A BIO containing the OCSP request is returned.

tls_ocsp_request_raw() is similar to tls_ocsp_request_ocsp(), but it generates a raw OCSP request instead of a signed one.

RETURN VALUES

tls_ocsp_process_response(), tls_ocsp_verify(), tls_ocsp_request_ocsp(), and tls_ocsp_request_raw() return 0 on success, or -1 on failure.
