libssh2_sftp_open_ex_r(3)

Paquete: libssh2

Licencias: BSD

libssh2_sftp_open_ex_r(3) libssh2 libssh2_sftp_open_ex_r(3)

NOMBRE

libssh2_sftp_open_ex_r - abre un manejador de archivo para un archivo en SFTP.

SINOPSIS

#include <libssh2.h>
#include <libssh2_sftp.h>
LIBSSH2_SFTP_HANDLE *
libssh2_sftp_open_ex_r(LIBSSH2_SFTP *sftp, const char *filename,
                       size_t filename_len,
                       unsigned long flags,
                       long mode,
                       int open_type,
                       LIBSSH2_SFTP_ATTRIBUTES *attrs);

DESCRIPCIÓN

sftp - Instancia SFTP devuelta por libssh2_sftp_init(3)

filename - Recurso de archivo/directorio remoto a abrir

filename_len - Longitud del nombre del archivo

flags - Cualquier combinación razonable de las constantes LIBSSH2_FXF_*:

LIBSSH2_FXF_READ
Abre el archivo para lectura.
LIBSSH2_FXF_WRITE
Abre el archivo para escritura. Si se especifican ambos, LIBSSH2_FXF_READ y LIBSSH2_FXF_WRITE, el archivo se abre para lectura y escritura.
LIBSSH2_FXF_APPEND
Fuerza que todas las escrituras añadan datos al final del archivo.
LIBSSH2_FXF_CREAT,
Si se especifica esta bandera, se creará un nuevo archivo si no existe uno previamente (si se especifica LIBSSH2_FXF_TRUNC, el nuevo archivo se truncará a cero longitud si existía anteriormente)
LIBSSH2_FXF_TRUNC
Fuerza que un archivo existente con el mismo nombre se trunque a cero longitud al crear un archivo especificando LIBSSH2_FXF_CREAT. DEBE especificarse LIBSSH2_FXF_CREAT si se usa esta bandera.
LIBSSH2_FXF_EXCL
Hace que la solicitud falle si el archivo nombrado ya existe. DEBE especificarse LIBSSH2_FXF_CREAT si se usa esta bandera.
mode - Permisos de archivo POSIX que se asignarán si el archivo se está creando nuevo. Consulte las definiciones de conveniencia LIBSSH2_SFTP_S_* en <libssh2_sftp.h>

open_type - Puede ser LIBSSH2_SFTP_OPENFILE (para abrir un archivo) o LIBSSH2_SFTP_OPENDIR (para abrir un directorio).

attrs - Puntero a la estructura LIBSSH2_SFTP_ATTRIBUTES. Consulte libssh2_sftp_fstat_ex para uso detallado.

VALOR DE RETORNO

Un puntero a la instancia LIBSSH2_SFTP_HANDLE recién creada o NULL si falla.

ERRORES

LIBSSH2_ERROR_ALLOC - Falló una llamada interna de asignación de memoria.

LIBSSH2_ERROR_SOCKET_SEND - No se pudo enviar datos en el socket.

LIBSSH2_ERROR_SOCKET_TIMEOUT -

LIBSSH2_ERROR_SFTP_PROTOCOL - Se recibió una respuesta de protocolo SFTP inválida en el socket, o una operación SFTP causó que el servidor devolviera un código de error.

LIBSSH2_ERROR_EAGAIN - Marcado para I/O no bloqueante pero la llamada se bloquearía.

DISPONIBILIDAD

Añadido en libssh2 1.11.0

VER TAMBIÉN
