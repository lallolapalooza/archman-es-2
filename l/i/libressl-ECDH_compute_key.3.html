libressl-ECDH_compute_key(3)

Paquete: libressl

Licencias: ISC, custom:OpenSSL

ECDH_COMPUTE_KEY(3) Manual de Funciones de Biblioteca ECDH_COMPUTE_KEY(3)

NOMBRE

ECDH_compute_key, ECDH_size — Intercambio de claves Diffie-Hellman de curva elíptica

SINOPSIS

biblioteca “libcrypto”
#include <openssl/ec.h>

int
ECDH_compute_key(void *out, size_t outlen, const EC_POINT *public_key, EC_KEY *ecdh, void *(*KDF)(const void *in, size_t inlen, void *out, size_t *outlen));

int
ECDH_size(const EC_KEY *ecdh);

DESCRIPCIÓN

ECDH_compute_key() realiza la concordancia de claves Diffie-Hellman de curva elíptica. Combina la clave privada contenida en ecdh con la public_key del otro participante, toma el componente x de las coordenadas afines y, opcionalmente, aplica la función de derivación de claves KDF. Almacena la clave simétrica resultante en el búfer out, que tiene outlen bytes de longitud. Si KDF es NULL, outlen debe ser al menos ECDH_size(ecdh).

ECDH_size() devuelve el número de bytes necesarios para almacenar una coordenada afín de un punto en la curva elíptica utilizada por ecdh, que es una octava parte del grado del campo finito subyacente de esa curva elíptica, redondeado hacia arriba al siguiente número entero.

VALORES DE RETORNO

ECDH_compute_key() devuelve la longitud de la clave calculada en bytes o -1 si ocurre un error.

ECDH_size() devuelve el número de bytes necesarios para almacenar una coordenada afín.

VER TAMBIÉN

DH_generate_key(3), DH_size(3), EC_GROUP_new_by_curve_name(3), EC_KEY_new(3), EC_POINT_new(3), X25519(3)

HISTORIAL

ECDH_compute_key() apareció por primera vez en OpenSSL 0.9.8 y ha estado disponible desde OpenBSD 4.5.

ECDH_size() apareció por primera vez en OpenBSD 6.1.
