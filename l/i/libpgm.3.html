DESCRIPCIÓN

Estas funciones de biblioteca forman parte de Netpbm(1)

TIPOS Y CONSTANTES

Cada gray solo debe contener valores entre 0 y PGM_OVERALLMAXVAL.

PGM_OVERALLMAXVAL es el valor máximo de un maxval en un archivo PGM. PGM_MAXMAXVAL es el valor máximo de un maxval en un archivo PGM que es compatible con el formato PGM tal como existía antes de abril de 2000. Es también el valor máximo de un maxval que da como resultado el tamaño mínimo posible de trama para una imagen dada. Es decir, una imagen con un maxval superior a PGM_MAXMAXVAL no puede ser leída ni generada por programas antiguos de procesamiento PGM y requiere más espacio en disco.

PGM_FORMAT es el código de formato para un archivo de imagen en formato PGM Plano. RPGM_FORMAT es el código de formato para un archivo de imagen PGM sin formato (raw). PGM_TYPE es el código de tipo de formato para los formatos PGM. PGM_FORMAT_TYPE es una macro que genera código para calcular el código de tipo de formato de un formato PBM o PGM a partir del código de formato que es su argumento.

INICIALIZACIÓN

pgm_init() está obsoleto (al menos desde Netpbm 9.25 (marzo de 2002)). Usa pm_proginit() en su lugar.

pgm_init() es idéntico a pm_proginit.

GESTIÓN DE MEMORIA

pgm_allocarray() asigna un array de grises.

pgm_allocrow() asigna una fila del número dado de grises.

pgm_freearray() libera el array asignado con pgm_allocarray() que contiene el número dado de filas.

pgm_freerow() libera una fila de grises asignada con pgm_allocrow().

LECTURA DE ARCHIVOS

Si una función en esta sección se llama en un archivo de formato PBM, traduce el archivo PBM a un archivo PGM sobre la marcha y funciona como si se hubiera llamado en el archivo PGM equivalente. El valor format devuelto por pgm_readpgminit(), sin embargo, no se traduce. Representa el formato real del archivo PBM.

pgm_readpgminit() lee la cabecera de un archivo PGM, devuelve toda la información de la cabecera y deja el archivo posicionado justo después de la cabecera.

pgm_readpgmrow() lee una fila de grises en el array grayrow. format, cols y maxval son los valores devueltos por pgm_readpgminit().

pgm_readpgm() lee una imagen PGM completa en memoria, devolviendo el array asignado como valor de retorno y devolviendo la información de la cabecera como rows, cols y maxval. Esta función combina pgm_readpgminit(), pgm_allocarray() y pgm_readpgmrow().

pgm_readpgminit() y pgm_readpgm abortan el programa con un mensaje a la salida estándar de error si la cabecera de la imagen PGM no es sintácticamente válida, incluso si contiene un número demasiado grande para ser procesado usando las estructuras de datos normales del sistema (es decir, un número que no cabe en un 'int' de C).

ESCRITURA DE ARCHIVOS

pgm_writepgminit() escribe la cabecera de un archivo PGM y lo deja posicionado justo después de la cabecera.

forceplain es un valor lógico que indica a pgm_writepgminit() que escriba una cabecera para un archivo de formato PGM plano, en contraposición a un archivo de formato PGM sin formato (raw).

pgm_writepgmrow() escribe la fila grayrow en un archivo PGM. Para obtener resultados significativos, cols, maxval y forceplain deben ser los mismos que se utilizaron con pgm_writepgminit().

pgm_writepgm() escribe la cabecera y todos los datos de una imagen PGM. Esta función combina pgm_writepgminit() y pgm_writepgmrow().

VARIOS

pgm_nextimage() posiciona un archivo de entrada PGM en la siguiente imagen (para que una posterior llamada a pgm_readpgminit() lea su cabecera).

pgm_nextimage() es análogo a pbm_nextimage(), pero funciona en archivos PGM y PBM.

pgm_check() comprueba el error común de integridad de archivo donde el archivo tiene un tamaño incorrecto para contener todos los datos de la imagen.

pgm_check() es análogo a pbm_check(), pero funciona en archivos PGM y PBM.

libpgm - Portable Graymap Library (PGM) functions

NAME

libpgm - Portable Graymap Library (PGM) functions

SYNOPSIS

#include <pgm.h>

DESCRIPTION

This library provides functions for reading and writing Portable Graymap (PGM) images. PGM is a simple image format that stores grayscale images.

The library supports both ASCII and binary PGM formats.
