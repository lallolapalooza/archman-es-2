NOMBRE

libcaca-migrating - Migración de libcaca 0.x a la API 1.0

Esta sección te guiará a través de la migración de una aplicación de libcaca 0.x a la última versión de la API.

Resumen

El cambio más importante en la API 1.0 de libcaca es el diseño orientado a objetos. Consulta estos dos ejemplos para tener una idea aproximada de lo que cambió:

#include <caca.h>
/* Programa de libcaca - API 0.x */
int main(void)
{
    /* Inicializar libcaca */
    caca_init();
    /* Establecer título de la ventana */
    caca_set_window_title("Ventana");
    /* Elegir colores de dibujo */
    caca_set_color(CACA_COLOR_BLACK,
                   CACA_COLOR_WHITE);
    /* Dibujar una cadena en (0, 0) */
    caca_putstr(0, 0, "¡Hola mundo!");
    /* Refrescar pantalla */
    caca_refresh();
    /* Esperar evento de pulsación de tecla */
    caca_wait_event(CACA_EVENT_KEY_PRESS);
    /* Limpiar librería */
    caca_end();
    return 0;
}
#include <caca.h>
/* Programa de libcaca - API 1.0 */
int main(void)
{
    /* Inicializar libcaca */
    caca_canvas_t *cv;
    caca_display_t *dp;
    dp = caca_create_display(NULL);
    cv = caca_get_canvas(dp);
    /* Establecer título de la ventana */
    caca_set_display_title(dp, "Ventana");
    /* Elegir colores de dibujo */
    caca_set_color_ansi(cv, CACA_BLACK,
                            CACA_WHITE);
    /* Dibujar una cadena en (0, 0) */
    caca_put_str(cv, 0, 0, "¡Hola mundo!");
    /* Refrescar pantalla */
    caca_refresh_display();
    /* Esperar evento de pulsación de tecla */
    caca_get_event(dp, CACA_EVENT_KEY_PRESS,
                   NULL, -1);
    /* Limpiar librería */
    caca_free_display(dp);
    return 0;
}

Nota las siguientes cosas importantes:

•
La mayoría de las funciones ahora toman un manejador de objeto como su primer argumento.

Estrategia de migración

Tienes dos formas de migrar tu aplicación para usar libcaca 1.x:

  • Porta tu código usando la lista de equivalencia de funciones. Esta es la forma preferida porque las nuevas funciones son seguras para hilos y ofrecen muchas más características tanto al programador como al usuario final.
  • Usa la capa de compatibilidad heredada.

Usar la capa de compatibilidad es tan fácil como añadir las siguientes tres líneas:

#include <caca.h>
/* Programa de libcaca - API 0.x */
...
#include <caca.h>
#ifdef CACA_API_VERSION_1
#   include <caca0.h>
#endif
/* Programa de libcaca - API 0.x */
...

El código modificado está garantizado para compilar tanto con libcaca 0.x como con libcaca 1.0.

Lista de equivalencia de funciones

Funciones básicas

  • caca_init(): usa caca_create_canvas() para crear un lienzo de libcaca, seguido de caca_create_display() para adjuntar una pantalla de libcaca a él. Alternativamente, caca_create_display() con un argumento NULL creará un lienzo automáticamente.
  • caca_set_delay(): usa caca_set_display_time().
  • caca_get_feature(): obsoleto.
  • caca_set_feature(): obsoleto, usa caca_set_dither_antialias(), caca_set_dither_color() y caca_set_dither_mode() en su lugar.
  • caca_get_feature_name(): obsoleto, usa caca_get_dither_mode_list(), caca_get_dither_antialias_list() y caca_get_dither_color_list() en su lugar.
  • caca_get_rendertime(): usa caca_get_display_time().
  • caca_get_width(): usa caca_get_canvas_width().
  • caca_get_height(): usa caca_get_canvas_height().
  • caca_set_window_title(): usa caca_set_display_title().
  • caca_get_window_width(): usa caca_get_display_width().
  • caca_get_window_height(): usa caca_get_display_height().
  • caca_refresh(): usa caca_refresh_display().
  • caca_end(): usa caca_free_display() para desadjuntar la pantalla de libcaca, seguido de caca_free_canvas() para liberar el lienzo subyacente de libcaca. Alternativamente, si el lienzo fue creado por caca_create_display(), será destruido automáticamente por caca_free_display().

Manejo de eventos

  • caca_get_event(): sin cambios, pero la recuperación de información del evento cambió mucho.
  • caca_wait_event(): usa caca_get_event() con un argumento de tiempo de espera de -1.
  • caca_get_mouse_x(): sin cambios.
  • caca_get_mouse_y(): sin cambios.

Impresión de caracteres

  • caca_set_color(): usa caca_set_color_ansi() o caca_set_color_argb().
  • caca_get_fg_color(): usa caca_get_attr().
  • caca_get_bg_color(): usa caca_get_attr().
  • caca_get_color_name(): esta función ahora está obsoleta debido a su gran inutilidad.
  • caca_putchar(): usa caca_put_char().
  • caca_putstr(): usa caca_put_str().
  • caca_printf(): sin cambios.
  • caca_clear(): usa caca_clear_canvas().

Dibujo de primitivas

Estas funciones son casi idénticas, excepto por el soporte Unicode y el hecho de que ahora actúan sobre un lienzo dado.

  • caca_draw_line(): sin cambios.
  • caca_draw_polyline(): sin cambios.
  • caca_draw_thin_line(): sin cambios.
  • caca_draw_thin_polyline(): sin cambios.
  • caca_draw_circle(): sin cambios.
  • caca_draw_ellipse(): sin cambios.
  • caca_draw_thin_ellipse(): sin cambios.
  • caca_fill_ellipse(): sin cambios.
  • caca_draw_box(): sin cambios, pero el significado del argumento cambió (ancho y alto en lugar de coordenadas de esquina).
  • caca_draw_thin_box(): usa caca_draw_thin_box() o caca_draw_cp437_box(), además el significado del argumento cambió (ancho y alto en lugar de coordenadas de esquina).
  • caca_fill_box(): sin cambios, pero el significado del argumento cambió (ancho y alto en lugar de coordenadas de esquina).
  • caca_draw_triangle(): sin cambios.
  • caca_draw_thin_triangle(): sin cambios.
  • caca_fill_triangle(): sin cambios.

Funciones matemáticas

  • caca_rand(): sin cambios, pero el segundo argumento es diferente, asegúrate de tenerlo en cuenta.
  • caca_sqrt(): esta función ahora está obsoleta, usa la llamada sqrt() de tu sistema en su lugar.

Manejo de sprites

Los lienzos recién introducidos pueden tener varios fotogramas. Los sprites, por lo tanto, están completamente obsoletos.

  • caca_load_sprite(): usa caca_import_file().
  • caca_get_sprite_frames(): usa caca_get_frame_count().
  • caca_get_sprite_width(): usa caca_get_canvas_width().
  • caca_get_sprite_height(): usa caca_get_canvas_height().
  • caca_get_sprite_dx(): usa caca_get_canvas_handle_x().
  • caca_get_sprite_dy(): usa caca_get_canvas_handle_y().
  • caca_draw_sprite(): usa caca_set_frame() y caca_blit().
  • caca_free_sprite(): usa caca_free_canvas().

Manejo de mapas de bits

Los mapas de bits han sido renombrados a dithers, porque estos objetos en realidad no almacenan ningún píxel, solo tienen información sobre cómo se harán los dithers de los mapas de bits.

  • caca_create_bitmap(): usa caca_create_dither().
  • caca_set_bitmap_palette(): usa libcaca-migrating(3caca) — libcaca 0.99.beta20

    NAME

    libcaca-migrating - migrating from libcaca to caca

    Overview

    This page describes the changes between libcaca versions and how to migrate your code.

    Migration strategy

    The libcaca API has been significantly refactored between versions 0.9.5 and 0.9.6. The main goals were to unify the API, make it more object-oriented, and allow for easier future development.

    The old API was based on a global canvas state, which made it difficult to manage multiple canvases simultaneously. The new API introduces a caca_canvas_t structure that represents a canvas, and all operations are performed on this structure.

    Compilation

    The caca-config utility is deprecated in favour of the standard pkg-config interface:

    gcc -c foobar.c -o foobar.o `pkg-config --cflags caca`
gcc foobar.o -o foobar `pkg-config --libs caca`

    caca-config is still provided as a convenience tool but may be removed in the future.
