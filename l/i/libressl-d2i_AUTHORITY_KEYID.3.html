libressl-d2i_AUTHORITY_KEYID(3)

Paquete: libressl

Licencias: ISC, custom:OpenSSL

D2I_AUTHORITY_KEYID(3) Manual de funciones de biblioteca D2I_AUTHORITY_KEYID(3)

NOMBRE

d2i_AUTHORITY_KEYID, i2d_AUTHORITY_KEYID — decodifica y codifica identificadores de clave de autoridad X.509

SINOPSIS

biblioteca “libcrypto”;
#include <openssl/x509v3.h>

AUTHORITY_KEYID *
d2i_AUTHORITY_KEYID(AUTHORITY_KEYID **val_out, const unsigned char **der_in, long length);

int
i2d_AUTHORITY_KEYID(AUTHORITY_KEYID *val_in, unsigned char **der_out);

DESCRIPCIÓN

d2i_AUTHORITY_KEYID() y i2d_AUTHORITY_KEYID() decodifican y codifican una estructura ASN.1 AuthorityKeyIdentifier definida en la RFC 5280 sección 4.2.1.1. Para obtener detalles sobre la semántica, ejemplos, advertencias y errores, consulte ASN1_item_d2i(3).

VALORES DE RETORNO

d2i_AUTHORITY_KEYID() devuelve un objeto AUTHORITY_KEYID o NULL si ocurre un error.

i2d_AUTHORITY_KEYID() devuelve el número de bytes codificados con éxito o un valor negativo si ocurre un error.

VER TAMBIÉN

ASN1_item_d2i(3), AUTHORITY_KEYID_new(3), X509_EXTENSION_new(3)

ESTÁNDARES

RFC 5280: Internet X.509 Public Key Infrastructure Certificate and Certificate Revocation List (CRL) Profile:

  • sección 4.2.1.1: Extensiones de certificado: Identificador de clave de autoridad
  • sección 5.2.1: Extensiones de CRL: Identificador de clave de autoridad

HISTORIA

d2i_AUTHORITY_KEYID() y i2d_AUTHORITY_KEYID() aparecieron por primera vez en OpenSSL 0.9.2b y han estado disponibles desde OpenBSD 2.6.
