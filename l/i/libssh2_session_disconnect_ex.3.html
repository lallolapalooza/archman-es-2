libssh2_session_disconnect_ex(3)

Paquete: libssh2

Licencias: BSD

libssh2_session_disconnect_ex(3) libssh2 libssh2_session_disconnect_ex(3)

NOMBRE

libssh2_session_disconnect_ex - termina la capa de transporte

SINOPSIS

#include <libssh2.h>
int
libssh2_session_disconnect_ex(LIBSSH2_SESSION *session, int reason,
                              const char *description,
                              const char *lang);
int
libssh2_session_disconnect(LIBSSH2_SESSION *session,
                           const char *description);

DESCRIPCIÓN

session - Instancia de sesión devuelta por libssh2_session_init_ex(3)

reason - Una de las constantes de Razón de Desconexión.

description - Razón legible por humanos para la desconexión.

lang - Cadena de localización que describe el idioma/codificación de la descripción proporcionada.

Envía un mensaje de desconexión al host remoto asociado con session, junto con un símbolo de reason y una description detallada.

Como conveniencia, se proporciona la macro libssh2_session_disconnect(3). Esta llama a libssh2_session_disconnect_ex(3) con reason establecido en SSH_DISCONNECT_BY_APPLICATION y lang establecido en una cadena vacía.

VALOR DE RETORNO

Devuelve 0 en caso de éxito o un valor negativo en caso de fallo. Devuelve LIBSSH2_ERROR_EAGAIN cuando de otro modo se bloquearía. Aunque LIBSSH2_ERROR_EAGAIN es un número negativo, no es realmente un fallo en sí mismo.
