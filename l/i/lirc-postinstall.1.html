LIRC_POSTINSTALL(1) Comandos de usuario LIRC_POSTINSTALL(1)

NOMBRE

lirc-postinstall - configuración postinstalación de lirc

SINOPSIS

lirc-postinstall <config.py>

ARGUMENTOS

config.py
Normalmente, el archivo config.py de lirc que se instala típicamente en /usr/share/lirc/python-pkg/lirc/config.py. Este archivo contiene las rutas de instalación de lirc.

DESCRIPCIÓN

lirc-postinstall realiza varias tareas que deben hacerse ya sea en el sistema de destino y/o utilizando las rutas de instalación finales. Los datos generados incluyen la documentación de la tabla de controladores y los complementos externos.

ENTORNO

PYTHON
Intérprete de Python, por defecto python3
DESTDIR
Prefijo común para todas las rutas de instalación, típicamente como se pasa a make install.

NOTAS

Este script modifica algunos archivos con rutas de configuración absolutas. Como consecuencia, el paquete instalado no puede ser reubicado a otra ubicación después de ejecutar lirc-postinstall.

Último cambio: sep 2017 lirc-postinstall 0.10.2
