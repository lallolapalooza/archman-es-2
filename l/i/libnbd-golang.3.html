NOMBRE

libnbd-golang - cómo usar libnbd desde Go

SINOPSIS

import "libguestfs.org/libnbd"
h, err := libnbd.Create()
if err != nil {
    panic(err)
}
defer h.Close()
uri := "nbd://localhost"
err = h.ConnectUri(uri)
if err != nil {
    panic(err)
}
size, err := h.GetSize()
if err != nil {
    panic(err)
}
fmt.Printf("tamaño de %s = %d\n", uri, size)

DESCRIPCIÓN

Esta página del manual documenta cómo usar libnbd para acceder a servidores Network Block Device (NBD) desde el lenguaje de programación Go. Los bindings de Go funcionan de manera muy similar a los bindings de C, por lo que deberías empezar leyendo libnbd(3).

MANEJADORES

Crea un manejador de libnbd de tipo "Libnbd" llamando a Create().

Puedes cerrar el manejador explícitamente con una llamada diferida a "h.Close()" o se cerrará automáticamente cuando sea recogido por el recolector de basura.

ERRORES

La mayoría de las llamadas devuelven un único "LibnbdError" o un par "(ret, LibnbdError)".
