RIPEMD160(3) Manual de funciones de biblioteca RIPEMD160(3)

NOMBRE

RIPEMD160, RIPEMD160_Init, RIPEMD160_Update, RIPEMD160_Final — función hash RIPEMD-160

SINOPSIS

biblioteca “libcrypto”
#include <openssl/ripemd.h>

unsigned char *
RIPEMD160(const unsigned char *d, unsigned long n, unsigned char *md);

int
RIPEMD160_Init(RIPEMD160_CTX *c);

int
RIPEMD160_Update(RIPEMD160_CTX *c, const void *data, unsigned long len);

int
RIPEMD160_Final(unsigned char *md, RIPEMD160_CTX *c);

DESCRIPCIÓN

RIPEMD-160 es una función hash criptográfica con una salida de 160 bits.

RIPEMD160() calcula el resumen del mensaje RIPEMD-160 de los n bytes en d y lo coloca en md, el cual debe tener espacio para RIPEMD160_DIGEST_LENGTH == 20 bytes de salida.

Las siguientes funciones pueden ser utilizadas si el mensaje no está completamente almacenado en memoria:

RIPEMD160_Init() inicializa una estructura RIPEMD160_CTX.

RIPEMD160_Update() puede ser llamada repetidamente con fragmentos del mensaje a hashear (len bytes en data).

RIPEMD160_Final() coloca el resumen del mensaje en md, el cual debe tener espacio para RIPEMD160_DIGEST_LENGTH == 20 bytes de salida, y borra el RIPEMD160_CTX.

Las aplicaciones deben usar las funciones de alto nivel EVP_DigestInit(3) etc. en lugar de llamar directamente a las funciones hash.

VALORES DE RETORNO

RIPEMD160() devuelve un puntero al valor hash.

RIPEMD160_Init(), RIPEMD160_Update(), y RIPEMD160_Final() devuelven 1 en caso de éxito o 0 en caso contrario.

VER TAMBIÉN

EVP_DigestInit(3), HMAC(3)

ESTÁNDARES

ISO/IEC 10118-3:2004/Cor 1:2011
Hash-functions — Part 3: Dedicated hash-functions
Clause 7: RIPEMD-160

HISTORIA

RIPEMD160(), RIPEMD160_Init(), RIPEMD160_Update(), y RIPEMD160_Final() aparecieron por primera vez en SSLeay 0.9.0 y han estado disponibles desde OpenBSD 2.4.

ADVERTENCIAS

Otras implementaciones permiten que md en RIPEMD160() sea NULL y devuelven un array estático, lo cual no es seguro para hilos.
