NOMBRE

linsert - Insertar elementos en una lista

SINOPSIS

linsert lista índice ?elemento elemento ...?

DESCRIPCIÓN

Este comando produce una nueva lista a partir de lista insertando todos los argumentos elemento justo antes del elemento índice de lista. Cada argumento elemento se convertirá en un elemento separado de la nueva lista. Si índice es menor o igual a cero, los nuevos elementos se insertan al principio de la lista, y si índice es mayor o igual a la longitud de lista, es como si fuera end. Al igual que con string index, el valor de índice admite tanto la aritmética de índices simple como la indexación relativa al final.

Sujeto a las restricciones de que los índices deben referirse a ubicaciones dentro de la lista y que los elementos siempre se insertarán en orden, las inserciones se realizan de manera que cuando índice es relativo al inicio, el primer elemento estará en ese índice en la lista resultante, y cuando índice es relativo al final, el último elemento estará en ese índice en la lista resultante.

EJEMPLO

Poner algunos valores en una lista, primero indexando desde el principio y luego indexando desde el final, y luego enlazándolos:

set oldList {the fox jumps over the dog}
set midList [linsert $oldList 1 quick]
set newList [linsert $midList end-1 lazy]
# Las listas antiguas todavía existen, sin embargo...
set newerList [linsert [linsert $oldList end-1 quick] 1 lazy]
