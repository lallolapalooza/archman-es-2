NOMBRE

libnutclient - Biblioteca de acceso de alto nivel para clientes de Network UPS Tools

SINOPSIS

        #include <nutclient.h>

Consulte este archivo para obtener más información.

DESCRIPCIÓN

La biblioteca nutclient de Network UPS Tools (NUT) proporciona una serie de funciones útiles para que los programas las utilicen al comunicarse con upsd(8). Proporciona una representación de alto nivel de los datos de NUT a través de conexiones de cliente, dispositivos, variables y comandos. A diferencia de upsclient(3) (también conocido como la API "upscli"), aquí se ocultan todos los detalles del protocolo de bajo nivel.

El estado se mantiene a través de las llamadas en una estructura opaca llamada NUTCLIENT_t. Se espera que los llamadores creen una por cada conexión de cliente. Estas se proporcionarán a la mayoría de las funciones de nutclient. El formato de esta estructura está sujeto a cambios, y los programas cliente no deben hacer referencia directa a sus elementos.

NUTCLIENT_t representa la información de conexión común. Existen versiones derivadas para cada tipo de conexión (NUTCLIENT_TCP_t para conexión TCP; de hecho, el tipo de conexión único, NUTCLIENT_TCP_t puede pasarse como parámetro de NUTCLIENT_t).

Consulte el archivo de cabecera nutclient.h para obtener más información.

MANEJO DE ERRORES

Actualmente no existe ningún mecanismo específico en torno al manejo de errores.
