NOMBRE

X25519, X25519_keypair, ED25519_keypair, ED25519_sign, ED25519_verify — Primitivas de Diffie-Hellman de curva elíptica y de firma basadas en Curve25519

SINOPSIS

biblioteca “libcrypto”
#include <openssl/curve25519.h>

int
X25519(uint8_t out_shared_key[X25519_KEY_LENGTH], const uint8_t private_key[X25519_KEY_LENGTH], const uint8_t peer_public_value[X25519_KEY_LENGTH]);

void
X25519_keypair(uint8_t out_public_value[X25519_KEY_LENGTH], uint8_t out_private_key[X25519_KEY_LENGTH]);

void
ED25519_keypair(uint8_t out_public_key[ED25519_PUBLIC_KEY_LENGTH], uint8_t out_private_key[ED25519_PRIVATE_KEY_LENGTH]);

int
ED25519_sign(uint8_t *out_sig, const uint8_t *message, size_t message_len, const uint8_t public_key[ED25519_PUBLIC_KEY_LENGTH], const uint8_t private_key_seed[ED25519_PRIVATE_KEY_LENGTH]);

int
ED25519_verify(const uint8_t *message, size_t message_len, const uint8_t signature[ED25519_SIGNATURE_LENGTH], const uint8_t public_key[ED25519_PUBLIC_KEY_LENGTH]);

DESCRIPCIÓN

Curve25519 es una curva elíptica sobre un campo primo especificado en RFC 7748 sección 4.1. El campo primo se define por el número primo 2^255 - 19.

X25519 es la primitiva Diffie-Hellman construida a partir de Curve25519, tal como se describe en RFC 7748 sección 5. La sección 6.1 describe el uso previsto en un protocolo Diffie-Hellman de curva elíptica (ECDH).

X25519() escribe una clave compartida en out_shared_key que se calcula a partir de la private_key dada y el peer_public_value mediante multiplicación escalar. No utilice la clave compartida directamente, sino que utilice una función de derivación de claves e incluya también los dos valores públicos como entradas.

X25519_keypair() establece out_public_value y out_private_key en un par de claves pública/privada recién generado. Primero, out_private_key se genera con arc4random_buf(3). Luego, se aplica lo opuesto del enmascaramiento descrito en la RFC 7748 sección 5 para asegurarse de que la clave privada generada nunca se enmascare correctamente. El propósito es hacer que las implementaciones incorrectas en el lado del par fallen consistentemente. Las implementaciones correctas decodificarán la clave correctamente incluso cuando no esté enmascarada correctamente. Finalmente, out_public_value se calcula a partir de out_private_key multiplicándola por el punto base de Montgomery uint8_t u[32] = {9}.

El tamaño de una clave pública y privada es X25519_KEY_LENGTH = 32 bytes cada una.

Ed25519 es un esquema de firma que utiliza una curva de Edwards torsionada que es biracionalmente equivalente a Curve25519.

ED25519_keypair() establece out_public_key y out_private_key en un par de claves pública/privada recién generado. Primero, out_private_key se genera con arc4random_buf(3). Luego, out_public_key se calcula a partir de la clave privada.

ED25519_sign() firma el message de message_len bytes utilizando la public_key y la private_key y escribe la firma en out_sig.

ED25519_verify() comprueba que firmar el message de message_len bytes utilizando la public_key daría como resultado la signature dada.

Los tamaños de las claves pública y privada son ED25519_PUBLIC_KEY_LENGTH y ED25519_PRIVATE_KEY_LENGTH, que son ambos de 32 bytes, y el tamaño de una firma es ED25519_SIGNATURE_LENGTH = 64 bytes.

VALORES DE RETORNO

X25519() y ED25519_sign() devuelven 1 en caso de éxito o 0 en caso de error. X25519() puede fallar si la entrada es un punto de orden pequeño. ED25519_sign() siempre tiene éxito en LibreSSL, pero la API reserva el valor de retorno 0 para fallos de asignación de memoria.

ED25519_verify() devuelve 1 si la signature es válida o 0 en caso contrario.

NAME

X25519, DH_new_X25519, DH_set0_X25519, DH_get0_X25519 - X25519 Diffie-Hellman key agreement

SYNOPSIS

In <openssl/dh.h> 

int DH_set0_X25519(DH *dh, BIGNUM *priv, BIGNUM *pub);
int DH_get0_X25519(const DH *dh, const BIGNUM **priv, const BIGNUM **pub);
int DH_new_X25519(DH **ret);

DESCRIPTION

The X25519 curve is a Montgomery curve, which is suitable for Diffie-Hellman key exchange.

The functions DH_set0_X25519(), DH_get0_X25519(), and DH_new_X25519() provide an API for using the X25519 curve.

DH_new_X25519() allocates and initialises a DH structure for X25519.

DH_set0_X25519() sets the private key priv and public key pub in the DH structure dh. The keys are taken by the function, meaning the caller should not free them afterwards.

DH_get0_X25519() retrieves the private key priv and public key pub from the DH structure dh. The returned pointers point to the keys within the DH structure, and should not be freed by the caller.

RETURN VALUES

DH_new_X25519(), DH_set0_X25519() and DH_get0_X25519() return 1 on success, and 0 on failure.

SEE ALSO

dh(3)

STANDARDS

This function implements the X25519 Diffie-Hellman key exchange algorithm, as described in the paper "Curve25519: new Diffie-Hellman prime" by Daniel J. Bernstein.
