libressl-d2i_ASN1_NULL(3)

Paquete: libressl

Licencias: ISC, custom:OpenSSL

D2I_ASN1_NULL(3) Manual de funciones de la biblioteca D2I_ASN1_NULL(3)

NOMBRE

d2i_ASN1_NULL, i2d_ASN1_NULL — decodificar y codificar un tipo ASN.1 NULL

SINOPSIS

biblioteca “libcrypto”
#include <openssl/asn1.h>

ASN1_NULL *
d2i_ASN1_NULL(ASN1_NULL **val_out, const unsigned char **der_in, long length);

int
i2d_ASN1_NULL(ASN1_NULL *val_in, unsigned char **der_out);

DESCRIPCIÓN

Estas funciones decodifican y codifican el valor ASN.1 NULL de tipo NULL. Para obtener detalles sobre la semántica, ejemplos, advertencias y errores, consulte ASN1_item_d2i(3).

d2i_ASN1_NULL() verifica que el valor codificado en BER en *der_in sea NULL y de tipo NULL. Falla si length es menor que 2 o si los dos primeros bytes de *der_in difieren de 0x05 y 0x00. En caso de éxito, *der_in se avanza en dos bytes y *val_out se establece en un puntero inválido específico que representa el objeto único ASN1_NULL.

i2d_ASN1_NULL() ignora val_in y codifica el valor ASN.1 NULL de tipo NULL utilizando DER. Específicamente, escribe el octeto identificador para el tipo NULL, 0x05, seguido del octeto de longitud 0x00, y sin octetos de contenido o fin de contenido.

VALORES DE RETORNO

d2i_ASN1_NULL() devuelve un puntero inválido específico que representa el objeto único ASN1_NULL o NULL si ocurre un error.

i2d_ASN1_NULL() devuelve 2 si tiene éxito o 0 si ocurre un error.

VER TAMBIÉN

ASN1_item_d2i(3), ASN1_item_new(3), ASN1_NULL_new(3), ASN1_TYPE_get(3)

ESTÁNDARES

Recomendación X.690 de la ITU-T, también conocida como ISO/IEC 8825-1: Tecnología de la información - Reglas de codificación ASN.1: Especificación de Reglas de Codificación Básica (BER), Reglas de Codificación Canónica (CER) y Reglas de Codificación Distinguidas (DER), sección 8.8: Codificación de un valor nulo

HISTORIA

d2i_ASN1_NULL() y i2d_ASN1_NULL() aparecieron por primera vez en OpenSSL 0.9.5 y han estado disponibles desde OpenBSD 2.7.
