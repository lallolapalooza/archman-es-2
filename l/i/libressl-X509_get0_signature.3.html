X509_get0_signature(const ASN1_BIT_STRING **psig, const X509_ALGOR **palg, const X509 *x);

X509_CRL_get0_signature(const X509_CRL *crl, const ASN1_BIT_STRING **psig, const X509_ALGOR **palg);

const X509_ALGOR *
X509_get0_tbs_sigalg(const X509 *x);

const X509_ALGOR *
X509_CRL_get0_tbs_sigalg(const X509_CRL *crl);

int
X509_get_signature_type(const X509 *x);

int
X509_get_signature_nid(const X509 *x);

int
X509_REQ_get_signature_nid(const X509_REQ *req);

X509_get_signature_info(X509 *x, int *md_nid, int *pkey_nid, int *security_bits, uint32_t *flags);

DESCRIPCIÓN

X509_get0_signature(), X509_REQ_get0_signature(), y X509_CRL_get0_signature() establecen *psig a la firma y *palg al algoritmo de firma de x, req, o crl, respectivamente. X509_get0_tbs_sigalg() y X509_CRL_get0_tbs_sigalg() devuelven el algoritmo de firma en la porción firmada de x o crl, respectivamente. Los valores devueltos son punteros internos que no deben ser liberados por el llamador.

X509_get_signature_type() devuelve el NID base correspondiente al algoritmo de firma de x, de forma similar a como lo hace EVP_PKEY_base_id(3).

X509_get_signature_nid(), X509_REQ_get_signature_nid(), y X509_CRL_get_signature_nid() devuelven el NID correspondiente al algoritmo de firma de x, req, o crl, respectivamente, de forma similar a como lo hace EVP_PKEY_id(3).

X509_get_signature_info() recupera información sobre la firma del certificado x. El NID del algoritmo de resumen se escribe en *md_nid, el algoritmo de clave pública en *pkey_nid, los bits de seguridad efectivos en *security_bits, y los detalles de las banderas en *flags. Cualquiera de los parámetros de salida puede ser establecido a NULL si la información no es requerida. Si flags no es un puntero NULL, *flags se establece al OR a nivel de bits de:

X509_SIG_INFO_VALID
No ocurrió ningún error. Esta bandera se establece si X509_get_signature_info() devuelve 1.
X509_SIG_INFO_TLS
El algoritmo de firma es apropiado para su uso en TLS. Para un algoritmo EdDSA soportado (en LibreSSL este es Ed25519) esta bandera siempre se establece. Para un algoritmo RSASSA-PSS PSS esta bandera se establece si los parámetros están codificados en DER, el algoritmo de resumen es uno de SHA-256, SHA-384 o SHA-512, se usa el mismo algoritmo de resumen en la función de generación de máscara, y la longitud de la sal es igual a la longitud de salida del algoritmo de resumen. Para todos los demás algoritmos de firma esta bandera se establece si el algoritmo de resumen es uno de SHA-1, SHA-256, SHA-384 o SHA-512.

X509_get_signature_info() devuelve 1 en caso de éxito y 0 en caso de fallo. Las condiciones de fallo incluyen algoritmos de firma no soportados, errores de análisis de certificados y fallos de asignación de memoria.

Estas funciones proporcionan acceso de bajo nivel a la firma para casos en los que una aplicación desea analizar o generar una firma en un formato donde X509_sign(3) no es apropiado, por ejemplo, en un formato no estándar o no soportado.

HISTORIA

X509_get_signature_type() apareció por primera vez en SSLeay 0.8.0 y ha estado disponible desde OpenBSD 2.4.

X509_get0_signature() y X509_get_signature_nid() aparecieron por primera vez en OpenSSL 1.0.2. X509_REQ_get0_signature(), X509_CRL_get0_signature(), X509_get0_tbs_sigalg(), X509_REQ_get_signature_nid(), y X509_CRL_get_signature_nid() aparecieron por primera vez en OpenSSL 1.1.0. Todas estas funciones han estado disponibles desde OpenBSD 6.3.

X509_CRL_get0_tbs_sigalg() apareció por primera vez en LibreSSL 3.7.1 y ha estado disponible desde OpenBSD 7.3.

X509_GET_SIGNATURE_INFO

Get information about the signature on an X509 certificate.

SYNOPSIS

#include <openssl/x509.h>
int
X509_get_signature_info(const X509 *x, int *hash_alg, int *pkey_alg,
    int *bits, int *pmodulus);

DESCRIPTION

The X509_get_signature_info() function retrieves information about the signature on the X509 certificate x. The hash algorithm is returned in hash_alg, the public key algorithm in pkey_alg, the bit length of the public key in bits, and the bit length of the modulus in pmodulus.

The values returned for hash_alg and pkey_alg are integers that are defined in <openssl/obj_mac.h>. For example, NID_sha256, NID_rsa, NID_dsa, NID_ed25519, NID_X25519, etc.

The values returned for bits and pmodulus are integers representing the key and modulus size in bits, respectively. For example, 2048 for a 2048-bit RSA key.

If the certificate signature is invalid or has not been computed, the function returns 0. Otherwise it returns 1.

SEE ALSO

X509_new(3)

HISTORY

X509_get_signature_info() first appeared in OpenSSL 1.1.1 and has been available since OpenBSD 7.6.

CAVEATS

The security bits returned by X509_get_signature_info() refer to the information available from the certificate signature (such as the signing digest). In some cases the actual security of the signature is smaller because the signing key is less secure. For example in a certificate signed using SHA-512 and a 1024-bit RSA key.

BUGS

The signatures of X509_get0_signature(), X509_REQ_get0_signature(), and X509_CRL_get0_signature() are inconsistent.
