NOMBRE

EVP_PKEY_missing_parameters, EVP_PKEY_copy_parameters, EVP_PKEY_cmp_parameters, EVP_PKEY_cmp — funciones de parámetros y comparación de claves públicas

SINOPSIS

biblioteca “libcrypto”
#include <openssl/evp.h>

int
EVP_PKEY_missing_parameters(const EVP_PKEY *pkey);

int
EVP_PKEY_copy_parameters(EVP_PKEY *destination, const EVP_PKEY *source);

int
EVP_PKEY_cmp_parameters(const EVP_PKEY *a, const EVP_PKEY *b);

int
EVP_PKEY_cmp(const EVP_PKEY *a, const EVP_PKEY *b);

DESCRIPCIÓN

EVP_PKEY_missing_parameters() comprueba si faltan parámetros de clave pública en pkey.

EVP_PKEY_copy_parameters() copia todos los parámetros de clave pública desde el source al destination. Si el algoritmo no utiliza parámetros, no se realiza ninguna acción.

EVP_PKEY_cmp_parameters() compara los parámetros de clave pública de a y b. Esto solo se admite para algoritmos que utilizan parámetros.

EVP_PKEY_cmp() compara los componentes de clave pública de a y b. Si el algoritmo utiliza parámetros de clave pública, también compara los parámetros.

El propósito principal de las funciones EVP_PKEY_missing_parameters() y EVP_PKEY_copy_parameters() es manejar claves públicas en certificados donde los parámetros a veces se omiten de una clave pública si son heredados de la CA que la firmó.

Dado que las claves privadas de OpenSSL también contienen componentes de clave pública, la función EVP_PKEY_cmp() también se puede utilizar para determinar si una clave privada coincide con una clave pública.

VALORES DE RETORNO

EVP_PKEY_missing_parameters() devuelve 1 si faltan o están incompletos los parámetros de clave pública de pkey, o 0 si están presentes y completos, o si el algoritmo no utiliza parámetros.

EVP_PKEY_copy_parameters() devuelve 1 en caso de éxito o 0 en caso de fallo. En particular, falla si los tipos de clave no coinciden o si los parámetros de clave pública en el source faltan o están incompletos.

EVP_PKEY_cmp_parameters() y EVP_PKEY_cmp() devuelven 1 si las claves coinciden, 0 si no coinciden, -1 si los tipos de clave son diferentes y -2 si la operación no es compatible.

VER TAMBIÉN

EVP_PKEY_CTX_new(3), EVP_PKEY_keygen(3), EVP_PKEY_new(3), X509_get_pubkey_parameters(3)

HISTORIA

EVP_PKEY_missing_parameters() y EVP_PKEY_copy_parameters() aparecieron por primera vez en SSLeay 0.8.0. EVP_PKEY_cmp_parameters() apareció por primera vez en SSLeay 0.9.0. Estas funciones han estado disponibles desde OpenBSD 2.4.

EVP_PKEY_cmp() apareció por primera vez en OpenSSL 0.9.8 y ha estado disponible desde OpenBSD 4.5.
