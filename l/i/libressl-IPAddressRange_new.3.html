DESCRIPCIÓN

IPAddressRange, IPAddressOrRange, IPAddressChoice, y IPAddressFamily son bloques de construcción del tipo IPAddrBlocks que representan la extensión de delegación de direcciones IP RFC 3779.

Según RFC 3779, sección 2.1.1, una dirección IPv4 o IPv6 se codifica en orden de bytes de red en una cadena de bits ASN.1 de tamaño 32 o 128 bits, respectivamente. El tamaño en bits de un prefijo es su longitud de prefijo; todos los bits cero insignificantes se omiten de la codificación. Según la sección 2.1.2, un rango de direcciones se expresa como un par de cadenas de bits donde se omiten todos los bits cero menos significativos del límite inferior y todos los bits uno menos significativos del límite superior.

La biblioteca no proporciona una API para convertir directamente una dirección IP o un prefijo (en cualquier formato) hacia y desde una ASN1_BIT_STRING. Tampoco proporciona una API para manejar directamente rangos. Los detalles internos de ASN1_BIT_STRING son sutiles y se desaconseja manipularlos directamente en el contexto de la API de RFC 3779. El tamaño en bits de una ASN1_BIT_STRING que representa un prefijo o rango de direcciones IP es ocho veces su miembro length menos los tres bits inferiores de su flags, siempre que se establezca la bandera ASN1_STRING_FLAG_BITS_LEFT.

El tipo IPAddressRange definido en la sección 2.2.3.9 de RFC 3779 se implementa como

typedef struct IPAddressRange_st {
	ASN1_BIT_STRING *min;
	ASN1_BIT_STRING *max;
} IPAddressRange;

Representa el rango cerrado [min,max] de direcciones IP entre min y max, donde min debe ser estrictamente menor que max y el rango no debe ser expresable como un prefijo.

IPAddressRange_new() asigna un nuevo objeto IPAddressRange con min y max asignados y vacíos, representando así todo el espacio de direcciones de forma inválida como un no-prefijo.

IPAddressRange_free() libera range, incluyendo cualquier dato contenido en él. Si range es NULL, no se realiza ninguna acción.

No existe un tipo dedicado que represente el tipo IPAddress definido en la sección 2.2.3.8 de RFC 3779. La API utiliza ASN1_BIT_STRING para esto.

El tipo IPAddressOrRange definido en la sección 2.2.3.7 de RFC 3779 se implementa como

typedef struct IPAddressOrRange_st {
	int type;
	union {
		ASN1_BIT_STRING *addressPrefix;
		IPAddressRange *addressRange;
	} u;
} IPAddressOrRange;

Representando un prefijo de dirección individual o un rango de direcciones. El miembro type debe establecerse en IPAddressOrRange_addressPrefix o IPAddressOrRange_addressRange para indicar qué miembro de la unión u es válido.

IPAddressOrRange_new() devuelve un nuevo objeto IPAddressOrRange con tipo inválido y miembros de la unión u como NULL.

IPAddressOrRange_free() libera aor, incluyendo cualquier dato contenido en él, siempre que type esté configurado correctamente. Si aor es NULL, no se realiza ninguna acción.

Para expresar una lista de prefijos de dirección y rangos de dirección, la sección 2.2.3.6 de RFC 3779 utiliza una SECUENCIA ASN.1, que se implementa a través de una construcción STACK_OF(3) sobre IPAddressOrRange:

typedef STACK_OF(IPAddressOrRange) IPAddressOrRanges;
