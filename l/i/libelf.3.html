LIBELF(3) Manual del programador de Libelf LIBELF(3)

NOMBRE

libelf - una biblioteca para acceder y manipular archivos ELF (Executable and Linkable Format)

BIBLIOTECA

Biblioteca Elfutils (libelf, libelf.so, -lelf)

SINOPSIS

#include <libelf.h>

DESCRIPCIÓN

libelf proporciona una API para leer, escribir y manipular archivos ELF (Executable and Linkable Format). ELF es un formato estándar para archivos objeto, bibliotecas compartidas, volcados de memoria (core dumps) y ejecutables. Consulte elf(5) para obtener más información sobre ELF.

libelf proporciona rutinas para trabajar con encabezados de archivos objeto ELF, secciones, tablas de símbolos, entradas de reubicación y otros componentes clave.

El núcleo de la biblioteca se basa en descriptores de archivo Elf que representan archivos ELF, los cuales se pueden leer, escribir o actualizar en el lugar. La función elf_begin inicializa el acceso a un objeto ELF, mientras que funciones adicionales como elf_getscn, elf_getdata y elf_ndxscn proporcionan acceso a partes específicas del archivo ELF.

REPRESENTACIÓN DE ARCHIVO VS MEMORIA

La biblioteca libelf distingue entre la representación en archivo de un archivo ELF y su representación en memoria.

La Representación en Archivo se refiere al formato en el que un archivo ELF se almacena en disco. Los campos en el archivo pueden usar tamaños, alineaciones y orden de bytes (endianness) específicos que pueden ser diferentes del formato nativo utilizado por el sistema anfitrión.

La Representación en Memoria se refiere a la forma en que las estructuras de datos ELF se organizan cuando se cargan en la memoria de una aplicación. En memoria, las estructuras de datos generalmente se convierten al formato nativo del sistema anfitrión (por ejemplo, el endianness, tamaño de palabra y alineación del sistema).

libelf proporciona las siguientes funciones para traducir datos ELF entre representaciones de archivo y memoria: elf32_xlatetom, elf64_xlatetom, elf32_xlatetof y elf64_xlatetof.

Consulte elf32_xlatetom(3) para obtener más información.

VERSIÓN ELF

Para tener en cuenta la posibilidad de múltiples versiones de la especificación ELF, el número de versión ELF debe especificarse con la función elf_version antes que cualquier otra función de libelf. Esta función establece la versión ELF de libelf al valor especificado. En este momento, la única versión ELF admitida es EV_CURRENT.

DESCRIPTORES

Los descriptores Elf son el objeto central de libelf para acceder y manipular archivos ELF. Se crean con las funciones elf_begin, elf_clone y elf_memory y se cierran con la función elf_end.

libelf también proporciona descriptores Elf_Scn y Elf_Data para secciones ELF y contenidos de sección, respectivamente. Los miembros de la estructura Elf_Data se describen a continuación. Los miembros de las estructuras Elf y Elf_Scn están ocultos a las aplicaciones.

Estos descriptores se pueden adquirir y modificar utilizando varias funciones proporcionadas por libelf. Consulte libelf.h para obtener una lista completa.

MANEJO DE ERRORES

Si una función de libelf encuentra un error, establecerá un código de error interno que se puede recuperar con elf_errno. Cada hilo mantiene su propio código de error separado. El significado de cada código de error se puede determinar con elf_errmsg, que devuelve una cadena que describe el error.

GESTIÓN DE MEMORIA

libelf gestiona toda la memoria que asigna y la libera con elf_end. La aplicación no debe llamar a free en ninguna memoria asignada por libelf.

NAME

libelf

ELF library

LIBRARY

libelf, -lelf

SYNOPSIS

#include <libelf.h>

DESCRIPTION

The libelf library provides an interface for accessing and manipulating ELF (Executable and Linkable Format) files. It allows programs to read, write, and modify ELF files in a portable and structured manner. The library handles the differences between various ELF formats and architectures, providing a consistent API.

The library can be used for tasks such as inspecting the sections, symbols, relocation entries, and other components of an ELF file, as well as for creating or modifying ELF files.

FILE VS MEMORY REPRESENTATION

ELF files can be accessed in two different representations: file representation and memory representation.

  • File representation: This representation reflects how the data is stored on disk. It is useful for understanding the on-disk layout and for direct manipulation of the file content. Functions that retrieve data in file representation typically return pointers to the raw data as it appears in the file, without any adjustments for the current system's endianness or word size.
  • Memory representation: This representation is adjusted for the current system's architecture (endianness, word size). It is useful when you need to work with the ELF data as if it were loaded into memory by the system. Functions that retrieve data in memory representation perform necessary conversions to match the host system's format.

The library provides functions like elf_getdata to retrieve data in memory representation and elf_rawdata to retrieve data in file representation.

ELF VERSION

The ELF specification defines a version number for ELF files. The libelf library allows you to access and interpret this version information.

DESCRIPTORS

The library uses opaque descriptors to represent ELF files, sections, symbols, and other ELF structures. These descriptors are opaque pointers that are passed to various library functions.

ERROR HANDLING

The library reports errors by returning specific error codes or values. Functions that can fail typically return NULL or -1, and the specific error can be retrieved using functions like elf_errno.

MEMORY MANAGEMENT

The libelf library manages its own memory. When you obtain data or structures from the library, it is often the library's responsibility to allocate and free that memory. You should consult the documentation for specific functions to understand their memory management behavior and whether you need to free any returned data.

NAMESPACE

All functions, data structures, and constants defined by the libelf library are typically prefixed with elf_ or Elf_ to avoid naming conflicts with other libraries.

DATA STRUCTURES

The library defines several structures to represent various ELF entities.

ELF Section Descriptor

This structure represents a section within an ELF file. It contains information about the section's data and its properties.

typedef struct {
  Elf *elf;
  Elf_Scn *next;
  Elf_Data *data;
  Elf_Type d_type;
  size_t d_size;
  Elf_Off d_off;
  Elf_Align d_align;
  char *d_buf;
  size_t d_bufsize;
  unsigned int d_flags;
} Elf_Scn;
d_type
The Elf_Type of this piece of data. See the Elf_Type enum in libelf.h for descriptions of each value.
d_version
The ELF version for this data.
d_size
The size in bytes of this data.
d_off
The section offset of this data.
d_align
The section alignment of this data.

Archive Member Header

This structure represents the header of a member within an archive file (like a static library).

typedef struct {
  char *ar_name;
  time_t ar_date;
  uid_t ar_uid;
  gid_t ar_gid;
  mode_t ar_mode;
  int64_t ar_size;
  char *ar_rawname;
} Elf_Arhdr;
ar_name
Name of archive member.
ar_data
File date.
ar_uid
User ID.
ar_gid
Group ID.
ar_mode
File mode.
ar_size
File size.
ar_rawname
Original name of archive member.

Archive Symbol Table Entry

This structure represents an entry in the symbol table of an archive file.

typedef struct {
  char *as_name;
  size_t as_off;
  unsigned long int as_hash;
} Elf_Arsym;
as_name
Symbol name.
as_off
Offset for this file in the archive.
as_hash
Hash value of the name.
