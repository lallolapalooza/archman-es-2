libressl-SSL_CTX_set_max_cert_list(3)

Paquete: libressl

Licencias: ISC, custom:OpenSSL

SSL_CTX_SET_MAX_CERT_LIST(3) Manual de funciones de biblioteca SSL_CTX_SET_MAX_CERT_LIST(3)

NOMBRE

SSL_CTX_set_max_cert_list, SSL_CTX_get_max_cert_list, SSL_set_max_cert_list, SSL_get_max_cert_list — manipular el tamaño permitido para la cadena de certificados del par

SINOPSIS

biblioteca “libssl” libcrypto
#include <openssl/ssl.h>

long
SSL_CTX_set_max_cert_list(SSL_CTX *ctx, long size);

long
SSL_CTX_get_max_cert_list(SSL_CTX *ctx);

long
SSL_set_max_cert_list(SSL *ssl, long size);

long
SSL_get_max_cert_list(SSL *ctx);

DESCRIPCIÓN

SSL_CTX_set_max_cert_list() establece el tamaño máximo permitido para la cadena de certificados del par para todos los objetos SSL creados a partir de ctx a ser size bytes. Los objetos SSL heredan la configuración válida para ctx en el momento en que se llama a SSL_new(3).

SSL_CTX_get_max_cert_list() devuelve el tamaño máximo actualmente configurado para ctx.

SSL_set_max_cert_list() establece el tamaño máximo permitido para la cadena de certificados del par para ssl a ser size bytes. Esta configuración permanece válida hasta que se establezca un nuevo valor.

SSL_get_max_cert_list() devuelve el tamaño máximo actualmente configurado para ssl.

Durante el proceso de apretón de manos (handshake), el par puede enviar una cadena de certificados. El estándar TLS/SSL no establece ningún tamaño máximo para la cadena de certificados. La biblioteca OpenSSL maneja los datos entrantes mediante un búfer asignado dinámicamente. Para evitar que este búfer crezca sin límites debido a datos recibidos de un par defectuoso o malicioso, se establece un tamaño máximo para la cadena de certificados.

El valor predeterminado para el tamaño máximo de la cadena de certificados es 100 kB (30 kB en la plataforma DOS de 16 bits). Esto debería ser suficiente para cadenas de certificados habituales (la longitud máxima predeterminada de la cadena de OpenSSL es 10, consulte SSL_CTX_set_verify(3), y los certificados sin extensiones especiales tienen un tamaño típico de 1-2 kB).

Para aplicaciones especiales puede ser necesario extender el tamaño máximo de la cadena de certificados permitido para ser enviado por el par. Consulte, por ejemplo, el trabajo sobre Internet X.509 Public Key Infrastructure Proxy Certificate Profile y TLS Delegation Protocol en https://www.ietf.org/ y http://www.globus.org/.

En condiciones normales, nunca debería ser necesario establecer un valor inferior al predeterminado, ya que el búfer se maneja dinámicamente y solo utiliza la memoria requerida por los datos enviados por el par.

Si se excede el tamaño máximo permitido de la cadena de certificados, el apretón de manos fallará con un error SSL_R_EXCESSIVE_MESSAGE_SIZE.

VALORES DE RETORNO

SSL_CTX_set_max_cert_list() y SSL_set_max_cert_list() devuelven el valor previamente establecido.

SSL_CTX_get_max_cert_list() y SSL_get_max_cert_list() devuelven el valor actualmente establecido.

VER TAMBIÉN

ssl(3), SSL_CTX_ctrl(3), SSL_CTX_set_verify(3), SSL_new(3)

HISTORIA

Estas funciones aparecieron por primera vez en OpenSSL 0.9.7 y han estado disponibles desde OpenBSD 3.2.
