LIBBLKID(3) Manual del programador LIBBLKID(3)

NOMBRE

libblkid - biblioteca de identificación de dispositivos de bloque

SINOPSIS

#include <blkid.h>

cc archivo.c -lblkid

DESCRIPCIÓN

La biblioteca libblkid se utiliza para identificar dispositivos de bloque (discos) en cuanto a su contenido (por ejemplo, tipo de sistema de archivos) así como para extraer información adicional como etiquetas/nombres de volumen del sistema de archivos, identificadores únicos/números de serie. Un uso común es permitir el uso de etiquetas LABEL= y UUID= en lugar de codificar nombres específicos de dispositivos de bloque en archivos de configuración. Ver la lista de todas las etiquetas disponibles en la sección ETIQUETAS.

La parte de bajo nivel de la biblioteca también permite la extracción de información sobre particiones y topología de dispositivos de bloque.

La parte de alto nivel de la biblioteca mantiene información sobre los dispositivos de bloque en un archivo de caché y se verifica que siga siendo válida antes de ser devuelta al usuario (si el usuario tiene permiso de lectura en el dispositivo de bloque sin procesar, de lo contrario no). El archivo de caché también permite a los usuarios sin privilegios (normalmente cualquiera que no sea root, o aquellos que no están en el grupo "disk") localizar dispositivos por etiqueta/id. La ubicación estándar del archivo de caché puede ser anulada por la variable de entorno BLKID_FILE.

En situaciones donde se está obteniendo información sobre un solo dispositivo conocido, no afecta el rendimiento si se utiliza la caché o no (a menos que no pueda leer el dispositivo de bloque directamente).

La parte de alto nivel de la biblioteca admite dos métodos para determinar LABEL/UUID. Lee información directamente desde un dispositivo de bloque o lee información desde los enlaces simbólicos de udev /dev/disk/by-*. udev es el método preferido por defecto.

Si está tratando con varios dispositivos, se recomienda encarecidamente el uso de la caché (incluso si está vacía), ya que los dispositivos se escanearán como máximo una vez y la caché en disco se actualizará si es posible.

En algunos casos (kernels modulares), los dispositivos de bloque ni siquiera son visibles hasta después de ser accedidos por primera vez, por lo que es fundamental que exista alguna forma de localizar estos dispositivos sin enumerar solo los dispositivos visibles, por lo que el uso del archivo de caché es requerido en esta situación.

ARCHIVO DE CONFIGURACIÓN

La ubicación estándar del archivo de configuración /etc/blkid.conf puede ser anulada por la variable de entorno BLKID_CONF. Para más detalles sobre el archivo de configuración, consulte la página del manual blkid(8).

ETIQUETAS

Todas las etiquetas disponibles se enumeran a continuación. No todas las etiquetas son compatibles con todos los sistemas de archivos. Para habilitar una etiqueta, establezca una de las siguientes banderas con blkid_probe_set_superblocks_flags():

BLKID_SUBLKS_TYPE

•TYPE - tipo de sistema de archivos

BLKID_SUBLKS_SECTYPE

•SEC_TYPE - tipo de sistema de archivos secundario

BLKID_SUBLKS_LABEL

•LABEL - etiqueta del sistema de archivos

BLKID_SUBLKS_LABELRAW

•LABEL_RAW - etiqueta sin procesar de la superbloque del FS

BLKID_SUBLKS_UUID

•UUID - UUID del sistema de archivos (en minúsculas)
•UUID_SUB - UUID miembro del pool o UUID elemento de dispositivo, etc. (por ejemplo, zfs, btrfs, ...)
•LOGUUID - UUID de registro externo (por ejemplo, xfs)

BLKID_SUBLKS_UUIDRAW

•UUID_RAW - UUID sin procesar de la superbloque del FS

BLKID_SUBLKS_USAGE

•USAGE - cadena de uso: "raid", "filesystem", etc.

BLKID_SUBLKS_VERSION

•VERSION - versión del sistema de archivos

BLKID_SUBLKS_MAGIC

•SBMAGIC - cadena mágica de la superbloque
•SBMAGIC_OFFSET - desplazamiento de SBMAGIC

BLKID_SUBLKS_FSINFO

•FSSIZE - tamaño del sistema de archivos. Tenga en cuenta que para XFS esto devolverá el mismo valor que lsblk (sin los metadatos de XFS), pero para ext4 devolverá el tamaño con metadatos y para BTRFS no contará la sobrecarga de la configuración RAID (datos redundantes).
•FSLASTBLOCK - último bloque del sistema de archivos/número total de bloques del sistema de archivos
•FSBLOCKSIZE - tamaño del bloque del sistema de archivos

Las siguientes etiquetas están siempre habilitadas

•BLOCK_SIZE - tamaño mínimo de bloque accesible por el sistema de archivos
•MOUNT - nombre de montaje del clúster (solo ocfs)
•EXT_JOURNAL - UUID del diario externo
•SYSTEM_ID - identificador del sistema ISO9660
•VOLUME_SET_ID - identificador del conjunto de volúmenes ISO9660
•DATA_PREPARER_ID - identificador de datos ISO9660
•PUBLISHER_ID - identificador del editor ISO9660
•APPLICATION_ID - identificador de la aplicación ISO9660
•BOOT_SYSTEM_ID - identificador del sistema de arranque ISO9660

libblkid(3) - Linux Utility Library for Block Device Identification

SYNOPSIS

#include <blkid.h>

int blkid_get_size(int fd, blkid_loff_t *result);

int blkid_get_sectors(int fd, blkid_loff_t *result);

int blkid_get_block_size(int fd, int *result);

DESCRIPTION

The blkid library provides functions for identifying block devices and retrieving their attributes.

blkid_get_size(): Retrieves the total size of the block device in bytes.

blkid_get_sectors(): Retrieves the total number of sectors of the block device.

blkid_get_block_size(): Retrieves the size of a sector in bytes.

RETURN VALUE

On success, these functions return 0. On failure, they return a non-zero error code.

EXAMPLE

```c #include <blkid.h> #include <stdio.h> #include <fcntl.h> #include <unistd.h> int main() { int fd; blkid_loff_t size, sectors; int block_size; fd = open("/dev/sda1", O_RDONLY); if (fd < 0) { perror("open"); return 1; } if (blkid_get_size(fd, &size) == 0) { printf("Device size: %lld bytes\n", (long long)size); } else { fprintf(stderr, "Failed to get device size\n"); } if (blkid_get_sectors(fd, §ors) == 0) { printf("Number of sectors: %lld\n", (long long)sectors); } else { fprintf(stderr, "Failed to get number of sectors\n"); } if (blkid_get_block_size(fd, &block_size) == 0) { printf("Block size: %d bytes\n", block_size); } else { fprintf(stderr, "Failed to get block size\n"); } close(fd); return 0; } ```
