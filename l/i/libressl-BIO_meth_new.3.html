DESCRIPCIÓN

La estructura BIO_METHOD almacena punteros de función que implementan un tipo de BIO. Ver BIO_new(3) para más información sobre objetos BIO.

BIO_meth_new() crea una nueva estructura BIO_METHOD. Requiere un entero único type; usa BIO_get_new_index() para obtener el valor para type. Actualmente, el usuario solo puede crear hasta 127 tipos diferentes de BIO, y type está limitado al rango 129–255. El puntero name se almacena en la estructura y no será liberado por BIO_meth_free().

Los tipos estándar de BIO se listan en <openssl/bio.h>. Algunos ejemplos incluyen BIO_TYPE_BUFFER y BIO_TYPE_CIPHER. El type de los BIOs de filtro debe tener el bit BIO_TYPE_FILTER establecido. Los BIOs de origen/sumidero deben tener el bit BIO_TYPE_SOURCE_SINK establecido. Los BIOs basados en descriptores de archivo (por ejemplo, socket, fd, connect, accept, etc.) deben tener adicionalmente el bit BIO_TYPE_DESCRIPTOR establecido. Ver BIO_find_type(3) para más información.

BIO_meth_free() es un alias para free(3).

BIO_meth_get_write(), BIO_meth_set_write(), BIO_meth_get_read(), y BIO_meth_set_read() obtienen y establecen las funciones write y read utilizadas para escribir y leer datos de longitud arbitraria hacia y desde el BIO. Estas funciones se llaman desde BIO_write(3) y BIO_read(3), respectivamente. Los parámetros y los valores de retorno de write y read tienen el mismo significado que para BIO_write(3) y BIO_read(3).

BIO_meth_get_puts() y BIO_meth_set_puts() obtienen y establecen la función puts utilizada para escribir una cadena terminada en NUL en el BIO. Esta función se llama desde BIO_puts(3). Los parámetros y el valor de retorno de puts tienen el mismo significado que para BIO_puts(3).

BIO_meth_get_gets() y BIO_meth_set_gets() obtienen y establecen la función gets utilizada para leer una línea de texto del BIO. Esta función se llama desde BIO_gets(3). Los parámetros y el valor de retorno de gets tienen el mismo significado que para BIO_gets(3).

BIO_meth_get_ctrl() y BIO_meth_set_ctrl() obtienen y establecen la función ctrl utilizada para realizar operaciones de control específicas del BIO. Esta función se llama desde BIO_ctrl(3). Los parámetros y el valor de retorno de ctrl tienen el mismo significado que para BIO_ctrl(3).

BIO_meth_get_create() y BIO_meth_set_create() obtienen y establecen la función create utilizada para inicializar datos privados de un BIO cuando se crea un nuevo BIO de este tipo. Esta función se llama desde BIO_new(3).

BIO_meth_get_destroy() y BIO_meth_set_destroy() obtienen y establecen la función destroy utilizada para liberar datos privados de un BIO cuando se destruye el BIO. Esta función se llama desde BIO_free(3).

BIO_meth_get_callback_ctrl() y BIO_meth_set_callback_ctrl() obtienen y establecen la función callback_ctrl utilizada para obtener y establecer la información de devolución de llamada de un BIO. Esta función se llama desde BIO_set_callback(3).

VALORES DE RETORNO

BIO_get_new_index() devuelve el siguiente índice de tipo BIO disponible.

BIO_meth_new() devuelve un puntero a una nueva estructura BIO_METHOD en caso de éxito, o NULL si falla.

BIO_meth_free() no devuelve ningún valor.

Las funciones BIO_meth_get_*() devuelven el valor actual del puntero de función correspondiente.

Las funciones BIO_meth_set_*() devuelven 1 en caso de éxito, o 0 en caso de error.

BIO_meth_get_gets() y BIO_meth_set_gets()

Estas funciones obtienen y establecen la función gets utilizada para leer una línea de datos del BIO. Esta función se llama desde BIO_gets(3). Los parámetros y el valor de retorno de gets tienen el mismo significado que para BIO_gets(3).

BIO_meth_get_ctrl() y BIO_meth_set_ctrl()

Estas funciones obtienen y establecen la función ctrl utilizada para procesar mensajes de control en el BIO. Esta función se llama desde BIO_ctrl(3). Los parámetros y el valor de retorno de ctrl tienen el mismo significado que para BIO_ctrl(3).

BIO_meth_get_create() y BIO_meth_set_create()

Estas funciones obtienen y establecen una función create utilizada al inicializar una nueva instancia del BIO. Esta función se llama desde BIO_new(3). La función BIO_new(3) asigna memoria para el nuevo BIO, y se pasa un puntero a esta estructura recién asignada como parámetro a create.

BIO_meth_get_destroy() y BIO_meth_set_destroy()

Estas funciones obtienen y establecen una función destroy utilizada al destruir una instancia de un BIO. Esta función se llama desde BIO_free(3). Se pasa un puntero al BIO que se va a destruir como parámetro. La función destroy está destinada a realizar una limpieza específica del tipo de BIO. La memoria para el BIO en sí no debe ser liberada por esta función.

BIO_meth_get_callback_ctrl() y BIO_meth_set_callback_ctrl()

Estas funciones obtienen y establecen la función callback_ctrl utilizada para procesar mensajes de control de devolución de llamada en el BIO. Esta función se llama desde BIO_callback_ctrl(3). Los parámetros y el valor de retorno de callback_ctrl tienen el mismo significado que para BIO_callback_ctrl(3).

VALORES DE RETORNO

BIO_get_new_index() devuelve el nuevo valor de tipo BIO o -1 si ocurre un error.

BIO_meth_new() devuelve la nueva estructura BIO_METHOD o NULL si ocurre un error.

Las funciones BIO_meth_set_*() devuelven 1 en caso de éxito o 0 en caso de error. Actualmente, no pueden fallar.

Las funciones BIO_meth_get_*() devuelven punteros de función.

VER TAMBIÉN

BIO_ctrl(3), BIO_find_type(3), BIO_new(3), BIO_read(3)
