libssh2_userauth_password_ex(3)

Paquete: libssh2

Licencias: BSD

libssh2_userauth_password_ex(3) libssh2 libssh2_userauth_password_ex(3)

NOMBRE

libssh2_userauth_password_ex - autenticar una sesión con nombre de usuario y contraseña

SINOPSIS

#include <libssh2.h>
int
libssh2_userauth_password_ex(LIBSSH2_SESSION *session,
                             const char *username,
                             unsigned int username_len,
                             const char *password,
                             unsigned int password_len,
                           LIBSSH2_PASSWD_CHANGEREQ_FUNC((*passwd_change_cb)));
#define libssh2_userauth_password(session, username, password) \
     libssh2_userauth_password_ex((session), (username), \
                                  strlen(username), \
                                  (password), strlen(password), NULL)

DESCRIPCIÓN

session - Instancia de sesión devuelta por libssh2_session_init_ex(3)

username - Nombre del usuario para el que intentar la autenticación con contraseña sin cifrar.

username_len - Longitud del parámetro username.

password - Contraseña a usar para autenticar el nombre de usuario.

password_len - Longitud del parámetro password.

passwd_change_cb - Si el host acepta la autenticación pero solicita un cambio de contraseña, se invocará esta función de devolución de llamada. Si no se define ninguna función de devolución de llamada pero el servidor requiere un cambio de contraseña, la autenticación fallará.

Intenta autenticación básica con contraseña. Tenga en cuenta que muchos servidores SSH que parecen admitir autenticación de contraseña normal la tienen deshabilitada y en su lugar usan autenticación interactiva (dirigida a través de PAM u otro backend de autenticación).

VALOR DE RETORNO

Devuelve 0 si la operación es exitosa o un valor negativo en caso de fallo. Devuelve LIBSSH2_ERROR_EAGAIN cuando de lo contrario se bloquearía. Aunque LIBSSH2_ERROR_EAGAIN es un número negativo, no es realmente un fallo en sí mismo.

ERRORES

Algunos de los errores que esta función puede devolver incluyen:

LIBSSH2_ERROR_ALLOC - Una llamada interna de asignación de memoria falló.

LIBSSH2_ERROR_SOCKET_SEND - No se pueden enviar datos en el socket.

LIBSSH2_ERROR_PASSWORD_EXPIRED -

LIBSSH2_ERROR_AUTHENTICATION_FAILED - falló, nombre de usuario/contraseña o clave pública/privada inválida.
