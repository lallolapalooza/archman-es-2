NOMBRE

libpipewire-module-rtp-session - sesión RTP

DESCRIPCIÓN

El módulo rtp-session crea una sesión de medios que se anuncia con avahi/mDNS/Bonjour.

Otras máquinas en la red que ejecuten una sesión compatible se verán entre sí y podrán enviar audio/midi entre ellas.

La configuración de la sesión se basa en apple-midi y es compatible con apple-midi cuando la sesión utiliza midi.

NOMBRE DEL MÓDULO

libpipewire-module-rtp-session

OPCIONES DEL MÓDULO

Opciones específicas del comportamiento de este módulo

  • local.ifname = <str>: nombre de la interfaz a utilizar
  • control.ip =<str>: dirección IP de control, por defecto "0.0.0.0"
  • control.port =<int>: puerto de control, por defecto "0"
  • net.mtu = <int>: MTU a utilizar, por defecto 1280
  • net.ttl = <int>: TTL a utilizar, por defecto 1
  • net.loop = <bool>: multicast de loopback, por defecto falso sess.discover-local: descubrir también servicios locales, por defecto falso
  • sess.min-ptime = <int>: tiempo mínimo de paquete en milisegundos, por defecto 2
  • sess.max-ptime = <int>: tiempo máximo de paquete en milisegundos, por defecto 20
  • sess.latency.msec = <int>: latencia del receptor en milisegundos, por defecto 100
  • sess.name = <str>: un nombre de sesión
  • sess.ts-offset = <int>: un desplazamiento a aplicar a la marca de tiempo, por defecto -1 = desplazamiento aleatorio
  • sess.ts-refclk = <string>: el nombre de un reloj de referencia
  • sess.media = <string>: el tipo de medio audio|midi|opus, por defecto midi
  • stream.props = {}: propiedades a pasar al stream

OPCIONES GENERALES

Opciones con comportamiento bien conocido:

  • remote.name
  • audio.format
  • audio.rate
  • audio.channels
  • audio.position
  • node.name
  • node.description
  • media.name
  • node.group
  • node.latency
  • node.virtual
  • media.class

EJEMPLO DE CONFIGURACIÓN

 # ~/.config/pipewire/pipewire.conf.d/my-rtp-session.conf
 context.modules = [
 {   name = libpipewire-module-rtp-session
     args = {
         #local.ifname = "eth0"
         #control.ip = "0.0.0.0"
         #control.port = 0
         #net.mtu = 1280
         #net.ttl = 1
         #net.loop = false
         #sess.discover-local = false
         #sess.min-ptime = 2
         #sess.max-ptime = 20
         #sess.name = "PipeWire RTP stream"
         #sess.media = "audio"
         stream.props = {
             node.name = "rtp-sink"
             #audio.format = "S16BE"
             #audio.rate = 48000
             #audio.channels = 2
             #audio.position = [ FL FR ]
         }
     }
}
]
