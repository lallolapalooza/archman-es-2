libressl-d2i_SSL_SESSION(3)

Paquete: libressl

Licencias: ISC, custom:OpenSSL

D2I_SSL_SESSION(3) Manual de Funciones de Biblioteca D2I_SSL_SESSION(3)

NOMBRE

d2i_SSL_SESSION, i2d_SSL_SESSION — convierte el objeto SSL_SESSION de/a representación ASN1

SINOPSIS

biblioteca “libssl” libcrypto
#include <openssl/ssl.h>

SSL_SESSION *
d2i_SSL_SESSION(SSL_SESSION **a, const unsigned char **pp, long length);

int
i2d_SSL_SESSION(SSL_SESSION *in, unsigned char **pp);

DESCRIPCIÓN

d2i_SSL_SESSION() transforma la representación ASN1 externa de una sesión SSL/TLS, almacenada como datos binarios en la ubicación pp con longitud length, en un objeto SSL_SESSION.

i2d_SSL_SESSION() transforma el objeto SSL_SESSION in en la representación ASN1 y la almacena en la ubicación de memoria apuntada por pp. Se devuelve la longitud de la representación ASN1 resultante. Si pp es un puntero NULL, solo se calcula y devuelve la longitud.

El objeto SSL_SESSION se construye a partir de varias partes asignadas con malloc(3); por lo tanto, no se puede mover, copiar o almacenar directamente. Para almacenar datos de sesión en disco o en una base de datos, deben ser transformados a una representación ASN1 binaria.

Al usar d2i_SSL_SESSION(), el objeto SSL_SESSION se asigna automáticamente. El contador de referencias es 1, por lo que la sesión debe ser eliminada explícitamente usando SSL_SESSION_free(3), a menos que el objeto SSL_SESSION sea completamente tomado, cuando se llama dentro de la get_session_cb(), ver SSL_CTX_sess_set_get_cb(3).

SSL_SESSION objetos mantienen información de enlace interna sobre la lista de caché de sesiones cuando se insertan en la caché de sesiones de un objeto SSL_CTX. Por lo tanto, un objeto SSL_SESSION, independientemente de su contador de referencias, solo debe usarse con un objeto SSL_CTX (y los objetos SSL creados a partir de ese objeto SSL_CTX).

Al usar i2d_SSL_SESSION(), la ubicación de memoria apuntada por pp debe ser lo suficientemente grande para contener la representación binaria de la sesión. No hay un límite conocido en el tamaño de la representación ASN1 creada, así que llame a i2d_SSL_SESSION() primero con pp=NULL para obtener el tamaño codificado, antes de asignar la cantidad de memoria requerida y llamar a i2d_SSL_SESSION() de nuevo. Tenga en cuenta que esto avanzará el valor contenido en *pp, por lo que es necesario guardar una copia de la asignación original. Por ejemplo:

char	*p, *pp;
int	 elen, len;

elen = i2d_SSL_SESSION(sess, NULL);
p = pp = malloc(elen);
if (p != NULL) {
	len = i2d_SSL_SESSION(sess, &pp);
	assert(elen == len);
	assert(p + len == pp);
}

VALORES DE RETORNO

d2i_SSL_SESSION() devuelve un puntero al objeto SSL_SESSION recién asignado. En caso de fallo, se devuelve un puntero NULL y el mensaje de error se puede recuperar de la pila de errores.

i2d_SSL_SESSION() devuelve el tamaño de la representación ASN1 en bytes. Cuando la sesión no es válida, se devuelve 0 y no se realiza ninguna operación.

VER TAMBIÉN

d2i_X509(3), ssl(3), SSL_CTX_sess_set_get_cb(3), SSL_SESSION_free(3)

HISTORIA

d2i_SSL_SESSION() y i2d_SSL_SESSION() aparecieron por primera vez en SSLeay 0.5.2 y han estado disponibles desde OpenBSD 2.4.
