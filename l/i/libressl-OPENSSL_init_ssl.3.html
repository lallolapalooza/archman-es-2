libressl-OPENSSL_init_ssl(3)

Paquete: libressl

Licencias: ISC, custom:OpenSSL

OPENSSL_INIT_SSL(3) Manual de funciones de la biblioteca OPENSSL_INIT_SSL(3)

NOMBRE

OPENSSL_init_ssl — inicializa las bibliotecas criptográfica y SSL

SINOPSIS

biblioteca “libssl” libcrypto
#include <openssl/ssl.h>

int
OPENSSL_init_ssl(uint64_t options, const void *dummy);

DESCRIPCIÓN

Esta función está obsoleta. Nunca es útil que un programa de aplicación la llame explícitamente. La biblioteca la llama automáticamente internamente con un argumento options de 0 siempre que sea necesario. Es más seguro asumir que cualquier función puede hacerlo.

Para habilitar o deshabilitar el archivo de configuración estándar, en su lugar use OPENSSL_config(3) o OPENSSL_no_config(3), respectivamente. Para cargar un archivo de configuración no estándar, consulte CONF_modules_load_file(3).

OPENSSL_init_ssl() llama a OPENSSL_init_crypto(3), SSL_load_error_strings(3), y SSL_library_init(3).

El argumento options se pasa a OPENSSL_init_crypto(3) y el argumento dummy se ignora.

Si esta función se llama más de una vez, ninguna de las llamadas, excepto la primera, tiene ningún efecto.

VALORES DE RETORNO

OPENSSL_init_ssl() tiene la intención de devolver 1 en caso de éxito o 0 en caso de error.

VER TAMBIÉN

CONF_modules_load_file(3), OPENSSL_config(3), ssl(3)

HISTORIA

OPENSSL_init_ssl() apareció por primera vez en OpenSSL 1.1.0 y ha estado disponible desde OpenBSD 6.3.

ERRORES

OPENSSL_init_ssl() ignora silenciosamente incluso más fallos de configuración que OPENSSL_init_crypto(3).
