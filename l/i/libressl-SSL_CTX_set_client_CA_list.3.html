libressl-SSL_CTX_set_client_CA_list(3)

Paquete: libressl

Licencias: ISC, custom:OpenSSL

SSL_CTX_SET_CLIENT_CA_LIST(3) Manual de funciones de biblioteca SSL_CTX_SET_CLIENT_CA_LIST(3)

NOMBRE

SSL_CTX_set_client_CA_list, SSL_set_client_CA_list, SSL_CTX_add_client_CA, SSL_add_client_CA — establece la lista de CAs enviada al cliente al solicitar un certificado de cliente

SINOPSIS

biblioteca “libssl” libcrypto
#include <openssl/ssl.h>

void
SSL_CTX_set_client_CA_list(SSL_CTX *ctx, STACK_OF(X509_NAME) *list);

void
SSL_set_client_CA_list(SSL *s, STACK_OF(X509_NAME) *list);

int
SSL_CTX_add_client_CA(SSL_CTX *ctx, X509 *cacert);

int
SSL_add_client_CA(SSL *ssl, X509 *cacert);

DESCRIPCIÓN

SSL_CTX_set_client_CA_list() establece la lista de CAs enviada al cliente al solicitar un certificado de cliente para ctx.

SSL_set_client_CA_list() establece la lista de CAs enviada al cliente al solicitar un certificado de cliente para el ssl elegido, anulando la configuración válida para el objeto SSL_CTX de ssl.

SSL_CTX_add_client_CA() añade el nombre de la CA extraído de cacert a la lista de CAs enviada al cliente al solicitar un certificado de cliente para ctx.

SSL_add_client_CA() añade el nombre de la CA extraído de cacert a la lista de CAs enviada al cliente al solicitar un certificado de cliente para el ssl elegido, anulando la configuración válida para el objeto SSL_CTX de ssl.

Cuando un servidor TLS/SSL solicita un certificado de cliente (ver SSL_CTX_set_verify()), envía una lista de CAs para las cuales aceptará certificados al cliente.

Esta lista debe establecerse explícitamente usando SSL_CTX_set_client_CA_list() para ctx y SSL_set_client_CA_list() para el ssl específico. La lista especificada anula la configuración anterior. Las CAs listadas no se vuelven de confianza (list solo contiene los nombres, no los certificados completos); use SSL_CTX_load_verify_locations(3) para cargarlas adicionalmente para la verificación.

Si la lista de CAs aceptables se compila en un archivo, la función SSL_load_client_CA_file(3) puede usarse para ayudar a importar los datos necesarios.

SSL_CTX_add_client_CA() y SSL_add_client_CA() pueden usarse para añadir elementos adicionales a la lista de CAs de cliente. Si no se especificó una lista previamente usando SSL_CTX_set_client_CA_list() o SSL_set_client_CA_list(), se abre una nueva lista de CAs de cliente para ctx o ssl (según corresponda).

Estas funciones solo son útiles para servidores TLS/SSL.

VALORES DE RETORNO

SSL_CTX_add_client_CA() y SSL_add_client_CA() tienen los siguientes valores de retorno:

0
Ocurrió un fallo al manipular el objeto STACK_OF(X509_NAME) o no se pudo extraer el X509_NAME de cacert. Verifique la pila de errores para descubrir la razón.
1
La operación tuvo éxito.

EJEMPLOS

Analiza todos los certificados en CAfile y los lista como CAs aceptables:

SSL_CTX_set_client_CA_list(ctx, SSL_load_client_CA_file(CAfile));

VER TAMBIÉN

ssl(3), SSL_CTX_load_verify_locations(3), SSL_get_client_CA_list(3), SSL_load_client_CA_file(3), X509_NAME_new(3)
