EVP_AES_128_GCM(3) Manual de funciones de biblioteca EVP_AES_128_GCM(3)

NOMBRE

EVP_aes_128_gcm, EVP_aes_192_gcm, EVP_aes_256_gcm — Cifrado EVP AES en modo Galois/Counter Mode

SINOPSIS

biblioteca “libcrypto”
#include <openssl/evp.h>

const EVP_CIPHER *
EVP_aes_128_gcm(void);

const EVP_CIPHER *
EVP_aes_192_gcm(void);

const EVP_CIPHER *
EVP_aes_256_gcm(void);

DESCRIPCIÓN

EVP_aes_128_gcm(), EVP_aes_192_gcm(), y EVP_aes_256_gcm() proporcionan el algoritmo Advanced Encryption Standard para claves de 128, 192 y 256 bits en modo Galois/Counter Mode dentro del framework de evp(3).

Para los cifrados en modo GCM, el comportamiento de la interfaz EVP se altera sutilmente y se requieren varias operaciones adicionales de EVP_CIPHER_CTX_ctrl(3) para funcionar correctamente. Algunos de los comandos de control EVP_CTRL_GCM_* son alias antiguos para las constantes correspondientes EVP_CTRL_AEAD_*, como se indica a continuación.

Para evitar usar la API engorrosa y propensa a errores documentada en la página del manual actual, considere usar las funciones documentadas en EVP_AEAD_CTX_init(3) en su lugar.

Controles de configuración

EVP_CTRL_AEAD_SET_IVLEN (== EVP_CTRL_GCM_SET_IVLEN)
Establece la longitud del vector de inicialización a arg bytes; el argumento ptr se ignora y se recomienda pasar NULL. Esta llamada solo se puede realizar antes de especificar un vector de inicialización. Si no se llama, se utiliza la longitud de IV predeterminada de 12 bytes.

Se desaconseja el uso de este comando de control porque la sección 5.2.1.1 de la especificación recomienda explícitamente que las implementaciones de GCM restrinjan el soporte a la longitud de IV predeterminada de 12 bytes para interoperabilidad, eficiencia y simplicidad de diseño.

EVP_CTRL_AEAD_SET_IV_FIXED (== EVP_CTRL_GCM_SET_IV_FIXED)
Generalmente, se pasa -1 para arg. En ese caso, el vector de inicialización completo se copia de ptr.

De lo contrario, establece el campo fijo al principio del vector de inicialización con los arg bytes apuntados por ptr. Al cifrar, también genera aleatoriamente los bytes restantes del vector de inicialización. Es un error especificar un arg menor que 4 o tan grande que queden menos de 8 bytes.

Controles de cifrado

EVP_CTRL_GCM_IV_GEN
Genera el bloque de precontador a partir del vector de inicialización, copia los últimos arg bytes del vector de inicialización a la ubicación apuntada por ptr, o todos si arg es menor que 1 o mayor que la longitud del vector de inicialización, e incrementa el vector de inicialización en 1. El incremento ignora la longitud del IV y la longitud del campo fijo que puedan haberse configurado anteriormente y siempre opera en los últimos ocho bytes del vector de inicialización. Es un error emitir este comando cuando no hay una clave o un vector de inicialización establecidos.
EVP_CTRL_AEAD_GET_TAG (== EVP_CTRL_GCM_GET_TAG)
Escribe arg bytes del valor de etiqueta en la ubicación apuntada por ptr. Este comando de control solo tiene sentido después de que se hayan procesado todos los datos, por ejemplo, después de llamar a EVP_EncryptFinal(3). Es un error emitir este comando al descifrar, antes de procesar cualquier dato, o especificar un arg menor que 1 o mayor que 16.

Para especificar cualquier dato autenticado adicional (AAD), llame a EVP_EncryptUpdate(3) con el argumento out establecido en NULL.

Controles de descifrado

EVP_CTRL_GCM_SET_IV_INV
Copia arg bytes de ptr a los últimos bytes del vector de inicialización y genera el bloque de precontador a partir del vector de inicialización. La biblioteca no verifica si los argumentos son coherentes con las longitudes configuradas del vector de inicialización y del campo fijo. Cuando se utilizan las longitudes predeterminadas, pase 8 para arg. En ese caso, este comando de control establece el campo de invocación. Es un error emitir este comando cuando no hay una clave o un vector de inicialización establecidos, o al cifrar.
EVP_CTRL_AEAD_SET_TAG (== EVP_CTRL_GCM_SET_TAG)
Establece la etiqueta esperada a los arg bytes ubicados en ptr. Este comando de control es obligatorio antes de procesar cualquier dato, por ejemplo, antes de llamar a EVP_DecryptUpdate(3). Es un error emitir este comando al cifrar o especificar un arg menor que 1 o mayor que 16.

Para especificar cualquier dato autenticado adicional (AAD), llame a EVP_DecryptUpdate(3) con el argumento out establecido en NULL.

Si el valor de retorno de EVP_DecryptFinal(3), EVP_DecryptFinal_ex(3), EVP_CipherFinal(3), o EVP_CipherFinal_ex(3) no indica éxito al descifrar, la operación de autenticación falló. En ese caso, considere cualquier dato de salida como corrupto.
