NOMBRE

libpipewire-module-netjack2-manager - gestor de Netjack2

DESCRIPCIÓN

El módulo gestor de netjack2 escucha los nuevos mensajes del controlador netjack2 y iniciará un canal de comunicación con ellos.

Los mensajes se reciben en una dirección (típicamente) multicast.

Normalmente, el controlador especificará el número de canales de envío y recepción que desea configurar con el gestor. Sin embargo, si el controlador especifica un valor de no importar de -1, se utilizan los valores de configuración audio.ports y midi.ports del gestor.

El gestor creará los flujos correspondientes para enviar y recibir datos hacia/desde los controladores. Estos suelen ser sinks y sources, pero con la propiedad netjack2.connect, serán flujos que se autoconectarán al source y sink predeterminados por el gestor de sesiones.

NOMBRE DEL MÓDULO

libpipewire-module-netjack2-manager

OPCIONES DEL MÓDULO

  • local.ifname = <str>: nombre de la interfaz a usar
  • net.ip =<str>: dirección IP multicast, predeterminada "225.3.19.154"
  • net.port =<int>: puerto de control, predeterminado "19000"
  • net.mtu = <int>: MTU a usar, predeterminado 1500
  • net.ttl = <int>: TTL a usar, predeterminado 1
  • net.loop = <bool>: multicast de loopback, predeterminado false
  • netjack2.connect: si los puertos jack deben conectarse automáticamente. También se puede colocar por flujo, predeterminado false.
  • netjack2.sample-rate: la frecuencia de muestreo a usar, predeterminada 48000
  • netjack2.period-size: el tamaño del búfer a usar, predeterminado 1024
  • netjack2.encoding: la codificación, float|opus|int, predeterminada float
  • netjack2.kbps: el número de kilobits por segundo al codificar, predeterminado 64
  • audio.ports: el número de puertos de audio. También se puede añadir a las propiedades del flujo. Esta es la sugerencia predeterminada para los controladores que no especifican ningún número de canales de audio.
  • midi.ports: el número de puertos midi. También se puede añadir a las propiedades del flujo. Esta es la sugerencia predeterminada para los controladores que no especifican ningún número de canales midi.
  • audio.position: posición de canal predeterminada para el número de audio.ports.
  • source.props: Propiedades adicionales para el filtro source.
  • sink.props: Propiedades adicionales para el filtro sink.

OPCIONES GENERALES

Opciones con comportamiento conocido.

  • remote.name
  • audio.channels
  • audio.position
  • node.name
  • node.description
  • node.group
  • node.virtual
  • media.class
  • target.object para especificar el remote node.name o serial.id al que enlazar

EJEMPLO DE CONFIGURACIÓN DE UN SINK/SOURCE DÚPLEX

# ~/.config/pipewire/pipewire.conf.d/my-netjack2-manager.conf
context.modules = [
{   name = libpipewire-module-netjack2-manager
    args = {
        #netjack2.connect     = true
        #netjack2.sample-rate = 48000
        #netjack2.period-size = 1024
        #netjack2.encoding    = float # float|opus
        #netjack2.kbps        = 64
        #audio.ports          = 0
        #midi.ports           = 0
        #audio.channels       = 2
        #audio.position       = [ FL FR ]
        source.props = {
            # propiedades source adicionales
        }
        sink.props = {
            # propiedades sink adicionales
        }
    }
}
]
