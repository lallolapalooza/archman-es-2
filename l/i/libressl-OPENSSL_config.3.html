libressl-OPENSSL_config(3)

Paquete: libressl

Licencias: ISC, custom:OpenSSL

OPENSSL_CONFIG(3) Manual de funciones de biblioteca OPENSSL_CONFIG(3)

NOMBRE

OPENSSL_config, OPENSSL_no_config — configuración simple de la biblioteca criptográfica y SSL

SINOPSIS

biblioteca “libcrypto”
#include <openssl/conf.h>

void
OPENSSL_config(const char *appname);

void
OPENSSL_no_config(void);

DESCRIPCIÓN

OPENSSL_config() inicializa la biblioteca criptográfica y llama a CONF_modules_load_file(3) con el archivo de configuración estándar y el appname dado. Si appname es NULL, se utiliza el nombre predeterminado openssl_conf. Se ignoran los errores. Las llamadas posteriores a OPENSSL_config() no tienen ningún efecto.

OPENSSL_no_config() suprime la carga del archivo de configuración estándar, de modo que cualquier llamada futura a OPENSSL_config() o a OPENSSL_init_crypto(3) asegurará que la biblioteca se inicialice pero no se cargará ningún archivo de configuración.

Llamar a estas funciones es opcional. Toda la inicialización necesaria de las bibliotecas criptográficas ocurre automáticamente cuando es necesario.

Para usar un archivo de configuración no estándar, consulte CONF_modules_load_file(3).

Internamente, OPENSSL_config() llama a OPENSSL_init_crypto(3).

Si una aplicación se compila con el símbolo del preprocesador OPENSSL_LOAD_CONF definido, OpenSSL_add_all_algorithms(3) llama automáticamente a OPENSSL_config().

Las aplicaciones deben liberar la configuración al cerrar la aplicación llamando a CONF_modules_free(3).

ARCHIVOS

/etc/ssl/openssl.cnf
archivo de configuración estándar

VER TAMBIÉN

CONF_modules_free(3), CONF_modules_load_file(3), crypto(3), OPENSSL_VERSION_NUMBER(3), openssl.cnf(5), x509v3.cnf(5)

HISTORIA

OPENSSL_config() y OPENSSL_no_config() aparecieron por primera vez en OpenSSL 0.9.7 y han estado disponibles desde OpenBSD 3.2.
