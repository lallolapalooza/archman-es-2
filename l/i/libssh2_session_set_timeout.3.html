NOMBRE

libssh2_session_set_timeout - establecer tiempo de espera para funciones bloqueantes

SINOPSIS

#include <libssh2.h>
void
libssh2_session_set_timeout(LIBSSH2_SESSION *session, long timeout);

DESCRIPCIÓN

Establece el timeout en milisegundos para cuánto tiempo las llamadas de función bloqueantes de libssh2 pueden esperar hasta considerar la situación un error y retornar LIBSSH2_ERROR_TIMEOUT.

Por defecto o si establece el tiempo de espera a cero, libssh2 no tiene tiempo de espera para funciones bloqueantes.

VALOR DE RETORNO

Nada

DISPONIBILIDAD

Añadido en la versión 1.2.9
