libcaca-env - Variables de entorno de Libcaca

Algunas variables de entorno pueden usarse para cambiar el comportamiento de libcaca sin tener que modificar el programa que la utiliza. Estas variables son:

•
CACA_DRIVER: establece el controlador de video backend. En orden de preferencia:
•
conio utiliza la interfaz conio.h de DOS.
•
ncurses utiliza la biblioteca ncurses.
•
slang utiliza la biblioteca S-Lang.
•
x11 utiliza el controlador nativo X11.
•
gl utiliza las bibliotecas freeglut y opengl.
•
raw envía la salida al estándar de salida en lugar de renderizar el lienzo. Esto puede usarse junto con cacaserver.
•
CACA_GEOMETRY: establece el tamaño de la pantalla de video. El formato de esta variable debe ser XxY, con X e Y siendo valores enteros. Esta opción funciona actualmente con los controladores raw, X11 y GL.
•
CACA_FONT: establece la fuente renderizada. El formato de esta variable depende de la implementación, pero dado que actualmente solo funciona con el controlador X11, se espera un nombre de fuente X11 como fixed o 5x7.
