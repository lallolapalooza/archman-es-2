psl_is_public_suffix2 ()

int
psl_is_public_suffix2 (const psl_ctx_t *psl,
                       const char *domain,
                       int type);

Esta función verifica si domain es un sufijo público por medio de la Lista de Sufijos Públicos de Mozilla[2].

type especifica la sección PSL donde realizar la búsqueda. Los valores válidos son PSL_TYPE_PRIVATE, PSL_TYPE_ICANN, PSL_TYPE_NO_STAR_RULE y PSL_TYPE_ANY.

PSL_TYPE_NO_STAR_RULE desactiva la 'regla del comodín predominante' (ver List[3] bajo 'Algorithm' 2.). La aplicación de esta bandera significa que los TLDs no listados explícitamente en la PSL *no* se tratan como sufijos públicos.

Los nombres de dominio internacionales deben estar en UTF-8 (minúsculas + NFKC) o en formato ASCII/ACE (punycode). Otras codificaciones probablemente resulten en valores de retorno incorrectos. Utilice la función auxiliar psl_str_to_utf8lower() para normalizar domain.

psl es un contexto devuelto por psl_load_file(), psl_load_fp() o psl_builtin().

Parámetros

psl Contexto PSL  
domain Cadena de dominio  
type Tipo de dominio

NAME

psl - Public Suffix List matching library

STABILITY LEVEL

Unstable

The Application Programming Interface exposed by this library is marked as Unstable. This means that the API is not guaranteed to remain backward-compatible between releases. Use with caution.

SYNOPSIS

#include <psl.h>

DESCRIPTION

libpsl is a library to match hostname against the Public Suffix List. It is able to match rules like 'com' or 'co.uk' which are specified in the Public Suffix List.

The primary use case is to check if a cookie domain is allowed to be set for a given hostname.

The Public Suffix List (PSL) is a project by Mozilla that aims to provide a list of public suffixes of a number of top-level domains (TLDs). A public suffix is one that is explicitly listed by registrars. Examples: 'com' and 'co.uk'.

The list can be obtained from https://publicsuffix.org/.

psl_is_cookie_domain_acceptable ()

int
psl_is_cookie_domain_acceptable (psl_ctx_t *psl,
                                const char *hostname,
                                const char *cookie_domain);

Checks if a cookie domain is acceptable for a given hostname. It follows the algorithm specified in RFC 6265 section 5.3.

The inputs hostname and cookie_domain must be normalized using the normalisation function in psl_str_to_utf8lower() . Otherwise the result might be incorrect.

The function checks if the cookie_domain matches the hostname.

The algorithm checks if the Public Suffix List contains a rule that matches the hostname. If the rule is a public suffix like 'example.com' or 'com', it checks if the cookie_domain is equal to the public suffix or if it matches the rule like 'www.example.com' would match 'example.com'.

A cookie domain is considered acceptable if it is equal to the public suffix of the hostname, or if it is a subdomain of the public suffix.

Important: The inputs hostname and cookie_domain MUST be in UTF-8 format (and lowercase + NFKC). Mixing UTF-8 and punycode (ASCII/ACE) inputs will lead to incorrect results.

Use helper function psl_str_to_utf8lower() for normalization of hostname and cookie_domain.

Hint for Windows users: Please make sure the calling application has called WSAStartup() before calling psl_is_cookie_domain_acceptable().

Examples:

1.Cookie domain 'example.com' would be acceptable for hostname 'www.example.com', but '.com' or 'com' would NOT be acceptable since 'com' is a public suffix.
2.Cookie domain 'his.name' would be acceptable for hostname 'remember.his.name', but NOT for 'forgot.his.name' since 'forgot.his.name' is a public suffix.

Parameters

psl PSL context pointer  
hostname The request hostname.  
cookie_domain The domain value from a cookie  

Returns

1 if acceptable, 0 if not acceptable.

Since: 0.1

libpsl-3

libpsl - biblioteca de Listas de Sufijos Públicos (PSL)

SINTAXIS

#include <psl.h>

DESCRIPCIÓN

La biblioteca libpsl proporciona una implementación de la Lista de Sufijos Públicos (PSL).

La PSL es una lista centralizada de dominios de nivel superior (TLD) y sufijos de dominio que no son de nivel superior (por ejemplo, .com, .co.uk, .gitlab.io) que se utiliza para determinar si un dominio puede ser una parte pública de una dirección de Internet, o si se puede registrar un subdominio de un dominio dado. Su propósito principal es permitir que las aplicaciones identifiquen qué partes de un nombre de dominio son necesarias para inferir la propiedad de alto nivel.

Por ejemplo, si el nombre de dominio es www.bbc.co.uk, la PSL diría que .uk es un TLD, que .co.uk es una entrada de sufijo público en el Reino Unido, y por lo tanto, bbc.co.uk es un dominio público que se puede registrar. Luego, www.bbc.co.uk sería un subdominio de bbc.co.uk.

Por otro lado, si el nombre de dominio es www.example.com, la PSL diría que .com es un TLD y que example.com es un dominio público. Luego, www.example.com sería un subdominio de example.com.

FUNCIONES

Las siguientes funciones están disponibles:

  • psl_builtin_lst(): Devuelve un puntero a la lista de sufijos públicos incorporada.
  • psl_load_lst_from_file(): Carga la lista de sufijos públicos desde un archivo.
  • psl_free_lst(): Libera la memoria utilizada por una lista de sufijos públicos.
  • psl_get_public_suffix(): Obtiene el sufijo público de un nombre de dominio dado.
  • psl_get_domain(): Obtiene el dominio público de un nombre de dominio dado.
  • psl_is_public_suffix(): Comprueba si una cadena dada es un sufijo público.
  • psl_can_register_subdomain(): Comprueba si se puede registrar un subdominio de un dominio dado.

INCLUYE

Todas las funciones requieren la inclusión del archivo de cabecera <psl.h>.

DESCRIPCIÓN

libpsl es una biblioteca que implementa la Lista de Sufijos Públicos (PSL). La PSL es una lista de dominios de nivel superior (TLD) y sufijos de dominio que no son de nivel superior (por ejemplo, .com, .co.uk, .gitlab.io) que se utiliza para determinar si un dominio puede ser una parte pública de una dirección de Internet, o si se puede registrar un subdominio de un dominio dado. Su propósito principal es permitir que las aplicaciones identifiquen qué partes de un nombre de dominio son necesarias para inferir la propiedad de alto nivel.

FUNCIONES

Las funciones principales proporcionadas por libpsl son:

  • psl_builtin_lst(): Devuelve un puntero a la lista de sufijos públicos incorporada en la biblioteca.
  • psl_load_lst_from_file(const char *path): Carga una lista de sufijos públicos desde un archivo especificado por path. Devuelve un puntero a la lista cargada o NULL si ocurre un error.
  • psl_free_lst(psl_lst_t *lst): Libera la memoria asignada para una lista de sufijos públicos.
  • psl_get_public_suffix(const char *domain, psl_lst_t *lst): Dado un nombre de dominio, devuelve el sufijo público correspondiente de la lista proporcionada. Devuelve una cadena de texto que representa el sufijo público o NULL si no se encuentra.
  • psl_get_domain(const char *domain, psl_lst_t *lst): Dado un nombre de dominio, devuelve el dominio público (la parte registrable del dominio). Devuelve una cadena de texto que representa el dominio público o NULL si no se encuentra.
  • psl_is_public_suffix(const char *suffix, psl_lst_t *lst): Comprueba si la cadena dada suffix es un sufijo público válido en la lista proporcionada. Devuelve 1 si es un sufijo público, 0 en caso contrario.
  • psl_can_register_subdomain(const char *domain, psl_lst_t *lst): Determina si se puede registrar un subdominio para el dominio dado según la lista de sufijos públicos. Devuelve 1 si se puede registrar, 0 en caso contrario.

NOTAS

La lista de sufijos públicos se actualiza periódicamente. Es recomendable mantener la lista actualizada para garantizar la precisión.
