libressl-CMS_compress(3)

Paquete: libressl

Licencias: ISC, custom:OpenSSL

CMS_COMPRESS(3) Manual de funciones de biblioteca CMS_COMPRESS(3)

NOMBRE

CMS_compress — crea una estructura CMS CompressedData

SINOPSIS

biblioteca “libcrypto”
#include <openssl/cms.h>

CMS_ContentInfo *
CMS_compress(BIO *in, int comp_nid, unsigned int flags);

DESCRIPCIÓN

CMS_compress() crea y devuelve una estructura CMS CompressedData.

comp_nid es el algoritmo de compresión a usar o NID_undef para usar el algoritmo predeterminado. Actualmente, el algoritmo predeterminado NID_zlib_compression es el único algoritmo soportado. Si la soporte de zlib no está compilado, CMS_compress() siempre devuelve un error.

in proporciona el contenido a comprimir.

Cualquiera de las siguientes banderas (combinadas mediante OR) pueden pasarse en el parámetro flags:

CMS_TEXT
Anteponer cabeceras MIME para el tipo text/plain a los datos.
CMS_BINARY
No traducir el contenido suministrado a formato canónico MIME, aunque esto sea requerido por las especificaciones S/MIME. Esta opción debe usarse si los datos suministrados están en formato binario. De lo contrario, la traducción los corromperá. Si CMS_BINARY está activado, CMS_TEXT se ignora.
CMS_STREAM
Devolver una estructura CMS_ContentInfo parcial adecuada para E/S en streaming: no se leen datos de in. Varias funciones, incluyendo SMIME_write_CMS(3), i2d_CMS_bio_stream(3), o PEM_write_bio_CMS_stream(3) pueden usarse para finalizar la estructura. Alternativamente, la finalización puede realizarse obteniendo el ASN1 BIO en streaming directamente usando BIO_new_CMS(3). La salida de los contenidos de la estructura CMS_ContentInfo a través de una función que no la finalice correctamente dará resultados impredecibles.
CMS_DETACHED
No incluir los datos comprimidos en la estructura CMS_ContentInfo. Esto rara vez se usa en la práctica y no está soportado por SMIME_write_CMS(3).

Actualmente no se pueden establecer parámetros de compresión adicionales, como el nivel de compresión zlib.

VALORES DE RETORNO

CMS_compress() devuelve una estructura CMS_ContentInfo o NULL si ocurrió un error. El error puede obtenerse de ERR_get_error(3).

VER TAMBIÉN

CMS_ContentInfo_new(3), CMS_uncompress(3)

ESTÁNDARES

RFC 3274: Compressed Data Content Type for Cryptographic Message Syntax (CMS)

HISTORIA

CMS_compress() apareció por primera vez en OpenSSL 0.9.8h y ha estado disponible desde OpenBSD 6.7.

La bandera CMS_STREAM apareció por primera vez en OpenSSL 1.0.0.
