libssh2_knownhost_addc(3)

Paquete: libssh2

Licencias: BSD

libssh2_knownhost_addc(3) libssh2 libssh2_knownhost_addc(3)

NOMBRE

libssh2_knownhost_addc - añadir un host conocido

SINOPSIS

#include <libssh2.h>
int
libssh2_knownhost_addc(LIBSSH2_KNOWNHOSTS *hosts,
                       char *host, char *salt,
                       char *key, size_t keylen,
                       const char *comment, size_t commentlen,
                       int typemask,
                       struct libssh2_knownhost **store);

DESCRIPCIÓN

Añade un host conocido a la colección de hosts conocidos identificada por el manejador 'hosts'.

host es un puntero al nombre del host en texto plano o hash. Si está hasheado, debe proporcionarse codificado en base64. El nombre del host puede ser la dirección numérica IP del host o el nombre completo.

Si desea añadir una clave para un número de puerto específico para el host dado, debe proporcionar el nombre del host como '[host]:puerto' con los caracteres '[' y ']' encerrando el nombre del host y dos puntos separando la parte del host del número de puerto. Por ejemplo: "[host.ejemplo.com]:222".

salt es un puntero a la sal utilizada para el hashing del host, si el host se proporciona hasheado. Si el host se proporciona en texto plano, la sal no tiene significado. La sal debe proporcionarse codificada en base64 con un byte nulo final.

key es un puntero a la clave para el host dado.

keylen es el tamaño total en bytes de la clave apuntada por el argumento key.

comment es un puntero a un comentario para la clave.

commentlen es el tamaño total en bytes del comentario apuntado por el argumento comment.

typemask es una máscara de bits que especifica el formato e información sobre los datos pasados a esta función. Específicamente, detalla en qué formato está el nombre del host, en qué formato está la clave y qué tipo de clave es.

El nombre del host se da como uno de los siguientes tipos: LIBSSH2_KNOWNHOST_TYPE_PLAIN, LIBSSH2_KNOWNHOST_TYPE_SHA1 o LIBSSH2_KNOWNHOST_TYPE_CUSTOM.

La clave está codificada usando una de las siguientes codificaciones: LIBSSH2_KNOWNHOST_KEYENC_RAW o LIBSSH2_KNOWNHOST_KEYENC_BASE64.

La clave utiliza uno de los siguientes algoritmos: LIBSSH2_KNOWNHOST_KEY_RSA1, LIBSSH2_KNOWNHOST_KEY_SSHRSA o LIBSSH2_KNOWNHOST_KEY_SSHDSS (obsoleto).

store debe apuntar a un puntero que se llenará para apuntar a los datos del host conocido después de la adición. Se puede pasar NULL si no le importa este puntero.

VALOR DE RETORNO

Devuelve un código de error regular de libssh2, donde los valores negativos son códigos de error y 0 indica éxito.

DISPONIBILIDAD

Añadido en libssh2 1.2.5
