NOMBRE

libkeccak_state_duplicate - Asigna un estado de hash duplicado

SINOPSIS

#include <libkeccak.h>
struct libkeccak_state *libkeccak_state_duplicate(const struct libkeccak_state *src);

Enlazar con -lkeccakP.

DESCRIPCIÓN

La función libkeccak_state_duplicate() asigna un nuevo estado de hash y lo inicializa para que sea idéntico a *src. Esto incluye todos los miembros de la estructura struct libkeccak_state, incluido el estado de la esponja y el búfer de fragmentos de mensaje.

VALORES DE RETORNO

La función libkeccak_state_duplicate() devuelve un struct libkeccak_state* recién asignado (de un elemento inicializado) en caso de éxito. En caso de error, se devuelve NULL y se establece errno para describir el error.

ERRORES

La función libkeccak_state_duplicate() puede fallar por cualquier motivo especificado para la función malloc(3).

VER TAMBIÉN

libkeccak_state_copy(3), libkeccak_state_create(3)
