Paquete: libressl

Licencias: ISC, custom:OpenSSL

PKCS12_CREATE(3) Manual de funciones de biblioteca PKCS12_CREATE(3)

NOMBRE

PKCS12_create — crear una estructura PKCS#12

SINOPSIS

biblioteca “libcrypto”
#include <openssl/pkcs12.h>

PKCS12 *
PKCS12_create(const char *pass, const char *name, EVP_PKEY *pkey, X509 *cert, STACK_OF(X509) *ca, int nid_key, int nid_cert, int iter, int mac_iter, int keytype);

DESCRIPCIÓN

PKCS12_create() crea una estructura PKCS#12.

pass es la frase de contraseña a usar. name es el friendlyName a usar para el certificado y la clave proporcionados. pkey es la clave privada a incluir en la estructura y cert su certificado correspondiente. ca es un conjunto opcional de certificados a incluir también en la estructura. pkey, cert, o ambos pueden ser NULL para indicar que no se requiere clave ni certificado.

nid_key y nid_cert son los algoritmos de cifrado que deben usarse para la clave y el certificado, respectivamente. Si nid_key o nid_cert se establecen en -1, no se usará cifrado.

iter es el recuento de iteraciones del algoritmo de cifrado a usar y mac_iter es el recuento de iteraciones del MAC a usar. Si mac_iter se establece en -1, el MAC se omitirá por completo.

keytype es el tipo de clave.

Los parámetros nid_key, nid_cert, iter, mac_iter, y keytype pueden todos ser establecidos en cero y se usarán valores predeterminados sensatos.

Estos valores predeterminados son: cifrado RC2 de 40 bits para certificados, cifrado triple DES para claves privadas, un recuento de iteraciones de clave de PKCS12_DEFAULT_ITER (actualmente 2048) y un recuento de iteraciones de MAC de 1.

El recuento de iteraciones de MAC predeterminado es 1 para mantener la compatibilidad con software antiguo que no interpretaba los recuentos de iteraciones de MAC. Si no se requiere dicha compatibilidad, entonces mac_iter debería establecerse en PKCS12_DEFAULT_ITER.

keytype agrega una bandera a la clave privada almacenada. Esta es una extensión no estándar que solo es interpretada actualmente por MSIE. Si se establece en cero, se omite la bandera; si se establece en KEY_SIG, la clave se puede usar solo para firmar; y si se establece en KEY_EX, se puede usar para firmar y cifrar. Esta opción fue útil para software antiguo de grado de exportación que podía usar claves solo de firma de tamaño arbitrario pero tenía restricciones en los tamaños permisibles de claves que podían usarse para cifrar.

Si un certificado contiene un alias o keyid entonces esto se usará para el friendlyName o localKeyID correspondiente en la estructura PKCS12.

VALORES DE RETORNO

PKCS12_create() devuelve una estructura PKCS12 válida o NULL si ocurrió un error.

VER TAMBIÉN

crypto(3), d2i_PKCS12(3), PKCS12_new(3), PKCS12_newpass(3), PKCS12_parse(3), PKCS12_SAFEBAG_new(3), X509_keyid_set1(3)

HISTORIAL

PKCS12_create() apareció por primera vez en OpenSSL 0.9.3 y ha estado disponible desde OpenBSD 2.6.

Antes de OpenSSL 0.9.8, ni pkey ni cert podían ser NULL, y un valor de -1 no estaba permitido para nid_key, nid_cert, y mac_iter.
