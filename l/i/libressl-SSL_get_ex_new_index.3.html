SSL_GET_EX_NEW_INDEX(3) Manual de funciones de biblioteca SSL_GET_EX_NEW_INDEX(3)

NOMBRE

SSL_get_ex_new_index, SSL_set_ex_data, SSL_get_ex_data — funciones de datos específicos de la aplicación internos

SINOPSIS

biblioteca “libssl” libcrypto
#include <openssl/ssl.h>

int
SSL_get_ex_new_index(long argl, void *argp, CRYPTO_EX_new *new_func, CRYPTO_EX_dup *dup_func, CRYPTO_EX_free *free_func);

int
SSL_set_ex_data(SSL *ssl, int idx, void *arg);

void *
SSL_get_ex_data(const SSL *ssl, int idx);

typedef int new_func(void *parent, void *ptr, CRYPTO_EX_DATA *ad,
               int idx, long argl, void *argp);
typedef void free_func(void *parent, void *ptr, CRYPTO_EX_DATA *ad,
               int idx, long argl, void *argp);
typedef int dup_func(CRYPTO_EX_DATA *to, CRYPTO_EX_DATA *from, void *from_d,
               int idx, long argl, void *argp);

DESCRIPCIÓN

Varias estructuras de OpenSSL pueden tener datos específicos de la aplicación adjuntos a ellas. Estas funciones se utilizan internamente por OpenSSL para manipular datos específicos de la aplicación adjuntos a una estructura específica.

SSL_get_ex_new_index() se utiliza para registrar un nuevo índice para datos específicos de la aplicación.

SSL_set_ex_data() se utiliza para almacenar datos de la aplicación en arg para idx en el objeto ssl.

SSL_get_ex_data() se utiliza para recuperar la información para idx de ssl.

Una descripción detallada de la funcionalidad de *_get_ex_new_index() se puede encontrar en RSA_get_ex_new_index(3). La funcionalidad de *_get_ex_data() y *_set_ex_data() se describe en CRYPTO_set_ex_data(3).

EJEMPLOS

Un ejemplo de cómo utilizar la funcionalidad se incluye en la función de ejemplo verify_callback() en SSL_CTX_set_verify(3).

VER TAMBIÉN

CRYPTO_set_ex_data(3), RSA_get_ex_new_index(3), ssl(3), SSL_CTX_set_verify(3)

HISTORIA

Las funciones precursoras SSL_set_app_data() y SSL_get_app_data() aparecieron por primera vez en SSLeay 0.6.1.

SSL_get_ex_new_index(), SSL_set_ex_data(), y SSL_get_ex_data() aparecieron por primera vez en SSLeay 0.9.0 y han estado disponibles desde OpenBSD 2.4.
