SSL_SET_SSL_CTX(3) Manual de funciones de la biblioteca SSL_SET_SSL_CTX(3)

NOMBRE

SSL_set_SSL_CTX — modifica un objeto de conexión SSL para usar otro contexto

SINOPSIS

biblioteca “libssl” libcrypto
#include <openssl/ssl.h>

SSL_CTX *
SSL_set_SSL_CTX(SSL *ssl, SSL_CTX* ctx);

DESCRIPCIÓN

SSL_set_SSL_CTX() hace que ssl use el contexto ctx.

Si ctx es NULL, ssl vuelve a usar el contexto con el que se creó inicialmente con SSL_new(3).

Si ssl ya usa ctx, no se realiza ninguna acción.

VALORES DE RETORNO

SSL_set_SSL_CTX() devuelve un puntero interno al contexto que ssl está usando como resultado de la llamada, o NULL si falla la asignación de memoria.

VER TAMBIÉN

ssl(3), SSL_clear(3), SSL_CTX_new(3), SSL_get_SSL_CTX(3), SSL_new(3), SSL_set_security_level(3)

HISTORIAL

SSL_set_SSL_CTX() apareció por primera vez en OpenSSL 0.9.8f y ha estado disponible desde OpenBSD 4.5.
