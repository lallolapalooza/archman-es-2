libssh2_sftp_fstat_ex(3)

Paquete: libssh2

Licencias: BSD

libssh2_sftp_fstat_ex(3) libssh2 libssh2_sftp_fstat_ex(3)

NOMBRE

libssh2_sftp_fstat_ex - obtener o establecer atributos en un manejador de archivo SFTP

SINOPSIS

#include <libssh2.h>
#include <libssh2_sftp.h>
int
libssh2_sftp_fstat_ex(LIBSSH2_SFTP_HANDLE *handle,
                      LIBSSH2_SFTP_ATTRIBUTES *attrs, int setstat)
#define libssh2_sftp_fstat(handle, attrs) \
    libssh2_sftp_fstat_ex((handle), (attrs), 0)
#define libssh2_sftp_fsetstat(handle, attrs) \
    libssh2_sftp_fstat_ex((handle), (attrs), 1)

DESCRIPCIÓN

handle - Manejador de archivo SFTP devuelto por libssh2_sftp_open_ex(3)

attrs - Puntero a una estructura LIBSSH2_SFTP_ATTRIBUTES para establecer metadatos de archivo desde o hacia, dependiendo del valor de setstat.

setstat - Cuando es distinto de cero, los metadatos del archivo se actualizarán con los datos encontrados en attrs de acuerdo con los valores de attrs->flags y otros atributos miembro relevantes.

Obtener o establecer datos de tipo statbuf para una instancia dada de LIBSSH2_SFTP_HANDLE.

TIPOS DE DATOS

LIBSSH2_SFTP_ATTRIBUTES es una estructura tipificada que se define como se muestra a continuación:

struct _LIBSSH2_SFTP_ATTRIBUTES {
    /* Si flags & ATTR_* bit está establecido, entonces el valor en esta
     * estructura será significativo. De lo contrario, se debe ignorar.
     */
    unsigned long flags;
    /* tamaño del archivo, en bytes */
    libssh2_uint64_t filesize;
    /* representación numérica del usuario y grupo propietario del
     * archivo
     */
    unsigned long uid, gid;
    /* máscara de bits de permisos */
    unsigned long permissions;
    /* tiempo de acceso y tiempo de modificación del archivo */
    unsigned long atime, mtime;
};

Encontrará un conjunto completo de defines y macros para identificar flags y permisos en el archivo de cabecera libssh2_sftp.h, pero algunos de los más comunes son:

Para verificar permisos de usuario específicos, el conjunto de defines sigue el patrón LIBSSH2_SFTP_S_I<accion><quien> donde <accion> es R, W o X para leer, escribir y ejecutar, y <quien> es USR, GRP y OTH para usuario, grupo y otros. Por lo tanto, para verificar si un archivo es legible por el usuario, use el bit LIBSSH2_SFTP_S_IRUSR, mientras que si desea ver si es ejecutable para otros, use LIBSSH2_SFTP_S_IXOTH y así sucesivamente.

Para verificar tipos de archivo específicos, anteriormente (antes de libssh2 1.2.5) se usaban las macros estándar posix S_IS***(), pero desde la 1.2.5 libssh2 ofrece su propio conjunto de macros para esta funcionalidad:

LIBSSH2_SFTP_S_ISLNK
Verificar si es un enlace simbólico
LIBSSH2_SFTP_S_ISREG
Verificar si es un archivo regular
LIBSSH2_SFTP_S_ISDIR
Verificar si es un directorio
LIBSSH2_SFTP_S_ISCHR
Verificar si es un archivo de caracteres especiales
LIBSSH2_SFTP_S_ISBLK
Verificar si es un archivo de bloque especial
LIBSSH2_SFTP_S_ISFIFO
Verificar si es una tubería o archivo especial FIFO
LIBSSH2_SFTP_S_ISSOCK
Verificar si es un socket

VALOR DE RETORNO

Devuelve 0 en caso de éxito o un valor negativo en caso de fallo. Devuelve LIBSSH2_ERROR_EAGAIN cuando de otro modo se bloquearía. Si bien LIBSSH2_ERROR_EAGAIN es un número negativo, no es realmente un fallo en sí mismo.

ERRORES

LIBSSH2_ERROR_ALLOC - Falló una llamada interna de asignación de memoria.

LIBSSH2_ERROR_SOCKET_SEND - No se pudo enviar datos en el socket.

LIBSSH2_ERROR_SOCKET_TIMEOUT -

LIBSSH2_ERROR_SFTP_PROTOCOL - Se recibió una respuesta inválida del protocolo SFTP en el socket, o una operación SFTP provocó que el servidor devolviera un código de error.

DISPONIBILIDAD

Esta función ha existido desde siempre, pero la mayoría de los defines LIBSSH2_SFTP_S_* se introdujeron en libssh2 0.14 y las macros LIBSSH2_SFTP_S_IS***() se introdujeron en libssh2 1.2.5.
