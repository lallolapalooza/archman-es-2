SSL_CTX_SET_SSL_VERSION(3) Manual de Funciones de Librería SSL_CTX_SET_SSL_VERSION(3)

NOMBRE

SSL_CTX_set_ssl_version, SSL_set_ssl_method, SSL_CTX_get_ssl_method, SSL_get_ssl_method — elegir un nuevo método TLS/SSL

SINOPSIS

librería “libssl” libcrypto
#include <openssl/ssl.h>

int
SSL_CTX_set_ssl_version(SSL_CTX *ctx, const SSL_METHOD *method);

int
SSL_set_ssl_method(SSL *s, const SSL_METHOD *method);

const SSL_METHOD *
SSL_CTX_get_ssl_method(SSL_CTX *ctx);

const SSL_METHOD *
SSL_get_ssl_method(SSL *ssl);

DESCRIPCIÓN

SSL_CTX_set_ssl_version() establece un nuevo método TLS/SSL por defecto method para los objetos SSL recién creados a partir de este ctx. Los objetos SSL ya creados con SSL_new(3) no se ven afectados, excepto cuando se llama a SSL_clear(3).

SSL_set_ssl_method() establece un nuevo método TLS/SSL method para un objeto SSL particular s. Puede restablecerse cuando se llama a SSL_clear(3).

SSL_CTX_get_ssl_method() y SSL_get_ssl_method() devuelven un puntero de función al método TLS/SSL establecido en ctx y ssl, respectivamente.

Las opciones de method disponibles se describen en SSL_CTX_new(3).

Cuando se llama a SSL_clear(3) y no hay una sesión conectada a un objeto SSL, el método del objeto SSL se restablece al método actualmente establecido en el objeto SSL_CTX correspondiente.

VALORES DE RETORNO

Los siguientes valores de retorno pueden ocurrir para SSL_CTX_set_ssl_version() y SSL_set_ssl_method():

0
La nueva elección falló. Compruebe la pila de errores para averiguar el motivo.
1
La operación tuvo éxito.

VER TAMBIÉN

ssl(3), SSL_clear(3), SSL_CTX_new(3), SSL_new(3), SSL_set_connect_state(3)

HISTORIA

SSL_CTX_set_ssl_version(), SSL_set_ssl_method(), y SSL_get_ssl_method() aparecieron por primera vez en SSLeay 0.8.0 y han estado disponibles desde OpenBSD 2.4. SSL_CTX_get_ssl_method() apareció por primera vez en OpenSSL 1.1.0 y ha estado disponible desde OpenBSD 7.0.
