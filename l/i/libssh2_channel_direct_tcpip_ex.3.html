libssh2_channel_direct_tcpip_ex(3)

Paquete: libssh2

Licencias: BSD

libssh2_channel_direct_tcpip_ex(3) libssh2 libssh2_channel_direct_tcpip_ex(3)

NOMBRE

libssh2_channel_direct_tcpip_ex - Tuneliza una conexión TCP a través de una sesión SSH

SINOPSIS

#include <libssh2.h>
LIBSSH2_CHANNEL *
libssh2_channel_direct_tcpip_ex(LIBSSH2_SESSION *session,
                                const char *host, int port,
                                const char *shost, int sport);
LIBSSH2_CHANNEL *
libssh2_channel_direct_tcpip(LIBSSH2_SESSION *session,
                             const char *host, int port);

DESCRIPCIÓN

session - Instancia de sesión como la devuelta por libssh2_session_init_ex(3)

host - Host de terceros al que conectarse utilizando el host SSH como proxy.

port - Puerto en el host de terceros al que conectarse.

shost - Host que se le indica al servidor SSH en qué host se originó la conexión.

sport - Puerto que se le indica al servidor SSH desde qué puerto se originó la conexión.

Tuneliza una conexión TCP/IP a través del transporte SSH, vía el host remoto, a un tercero. La comunicación del cliente al servidor SSH permanece cifrada, la comunicación del servidor al host del 3er partido viaja en texto plano.

VALOR DE RETORNO

Puntero a una instancia LIBSSH2_CHANNEL recién asignada, o NULL en caso de errores.

ERRORES

LIBSSH2_ERROR_ALLOC - Falló una llamada interna de asignación de memoria.

VER TAMBIÉN

libssh2_session_init_ex(3)
