libssh2_session_callback_set(3)

Paquete: libssh2

Licencias: BSD

libssh2_session_callback_set(3) libssh2 libssh2_session_callback_set(3)

NOMBRE

libssh2_session_callback_set - establece una función de devolución de llamada

SINOPSIS

#include <libssh2.h>
void *
libssh2_session_callback_set(LIBSSH2_SESSION *session,
                             int cbtype, void *callback);

DESCRIPCIÓN

¡Esta función está OBSOLETA en la versión 1.11.1. ¡Utilice la función libssh2_session_callback_set2(3) en su lugar!

Esta implementación espera y devuelve un puntero de datos para funciones de devolución de llamada.

Para obtener más detalles sobre la función de reemplazo, consulte libssh2_session_callback_set2(3), que espera y devuelve un puntero de función.

VALOR DEVUELTO

Puntero al manejador de devolución de llamada anterior. Devuelve NULL si no se estableció ningún manejador de devolución de llamada previo o si el tipo de devolución de llamada era desconocido.
