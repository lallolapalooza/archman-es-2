NOMBRE

libpipewire-module-combine-stream - Combinar Flujo

DESCRIPCIÓN

El flujo combinado puede crear:

  • un nuevo sumidero virtual que reenvía audio a otros sumideros
  • una nueva fuente virtual que combina audio de otras fuentes

Las fuentes y sumideros que necesitan ser combinados pueden ser seleccionados usando reglas de coincidencia genéricas. Esto hace posible combinar nodos estáticos o nodos basados en ciertas propiedades.

NOMBRE DEL MÓDULO

libpipewire-module-combine-stream

OPCIONES DEL MÓDULO

  • node.name: un nombre único para el flujo
  • node.description: un nombre legible para el flujo
  • combine.mode = capture | playback | sink | source, por defecto sink
  • combine.latency-compensate: usar buffers de retardo para igualar las latencias de los flujos
  • combine.on-demand-streams: usar metadatos para crear flujos bajo demanda
  • combine.props = {}: propiedades que se pasarán al sumidero/fuente
  • stream.props = {}: propiedades que se pasarán a los flujos
  • stream.rules = {}: reglas para la coincidencia de flujos, usar acciones create-stream

OPCIONES GENERALES

Opciones con comportamiento bien conocido.

  • remote.name
  • audio.channels
  • audio.position
  • media.name
  • node.latency
  • node.name
  • node.description
  • node.group
  • node.virtual
  • media.class

OPCIONES DEL FLUJO

  • audio.position: Establece el mapa de canales del flujo. Por defecto, es el mismo mapa de canales que el del flujo combinado.
  • combine.audio.position: mapea las posiciones de audio del flujo combinado a las posiciones del flujo. Los canales de entrada combinados se mapean uno a uno a los canales de salida del flujo.

EJEMPLO DE CONFIGURACIÓN

# ~/.config/pipewire/pipewire.conf.d/my-combine-stream-1.conf
context.modules = [
{   name = libpipewire-module-combine-stream
    args = {
        combine.mode = sink
        node.name = "combine_sink"
        node.description = "Mi Sumidero Combinado"
        combine.latency-compensate = false
        combine.props = {
            audio.position = [ FL FR ]
        }
        stream.props = {
        }
        stream.rules = [
            {
                matches = [
                    # cualquiera de los elementos en matches necesita coincidir, si uno lo hace,
                    # se emiten acciones.
                    {
                        # todas las claves deben coincidir con el valor. ! niega. ~ empieza con regex.
                        #node.name = "~alsa_input.*"
                        media.class = "Audio/Sink"
                    }
                ]
                actions = {
                    create-stream = {
                        #combine.audio.position = [ FL FR ]
                        #audio.position = [ FL FR ]
                    }
                }
            }
        ]
    }
}
]

A continuación se muestra un ejemplo de configuración que crea un sumidero de audio virtual 5.1 a partir de 3 sumideros estéreo separados.

# ~/.config/pipewire/pipewire.conf.d/my-combine-stream-2.conf
context.modules = [
{   name = libpipewire-module-combine-stream
    args = {
        combine.mode = sink
        node.name = "combine_sink_5_1"
        node.description = "Mi Sumidero Combinado 5.1"
        combine.latency-compensate = false
        combine.props = {
            audio.position = [ FL FR FC LFE SL SR ]
        }
        stream.props = {
                stream.dont-remix = true      # enlaza canales coincidentes sin remezclar
        }
        stream.rules = [
            {   matches = [
                    {   media.class = "Audio/Sink"
                        node.name = "alsa_output.usb-Topping_E30-00.analog-stereo"
                    } ]
                actions = { create-stream = {
                        combine.audio.position = [ FL FR ]
                        audio.position = [ FL FR ]
                } } }
            {   matches = [
                    {   media.class = "Audio/Sink"
                        node.name = "alsa_output.usb-BEHRINGER_UMC404HD_192k-00.pro-output-0"
                    } ]
                actions = { create-stream = {
                        combine.audio.position = [ FC LFE ]
                        audio.position = [ AUX0 AUX1 ]
                } } }
            {   matches = [
                    {   media.class = "Audio/Sink"
                        node.name = "alsa_output.pci-0000_00_1b.0.analog-stereo"
                    } ]
                actions = { create-stream = {
                        combine.audio.position = [ SL SR ]
                        audio.position = [ FL FR ]
                } } }
        ]
    }
}
]

A continuación se muestra un ejemplo de configuración que crea una fuente de audio virtual 4.0 a partir de 2 fuentes estéreo separadas.

# ~/.config/pipewire/pipewire.conf.d/my-combine-stream-3.conf
context.modules = [
{   name = libpipewire-module-combine-stream
    args = {
        combine.mode = source
        node.name = "combine_source_4_0"
        node.description = "Mi Fuente Combinada 4.0"
        combine.props = {
            audio.position = [ FL FR SL SR ]
        }
        stream.props = {
                stream.dont-remix = true
        }
        stream.rules = [
            {   matches = [
                    {   media.class = "Audio/Source"
                        node.name = "alsa_input.usb-046d_HD_Pro_Webcam_C920_09D53E1F-02.analog-stereo"
                    } ]
                actions = { create-stream = {
                        audio.position = [ FL FR ]
                        combine.audio.position = [ FL FR ]
                } } }
            {   matches = [
                    {   media.class = "Audio/Source"
                        node.name = "alsa_input.usb-046d_0821_9534DE90-00.analog-stereo"
                    } ]
                actions = { create-stream = {
                        audio.position = [ FL FR ]
                        combine.audio.position = [ SL SR ]
                } } }
        ]
    }
}
]
