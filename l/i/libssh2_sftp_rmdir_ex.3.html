NOMBRE

libssh2_sftp_rmdir_ex - eliminar un directorio SFTP

SINOPSIS

#include <libssh2.h>
#include <libssh2_sftp.h>
int
libssh2_sftp_rmdir_ex(LIBSSH2_SFTP *sftp, const char *path,
                      unsigned int path_len);

DESCRIPCIÓN

Eliminar un directorio del sistema de archivos remoto.

sftp - Instancia SFTP devuelta por libssh2_sftp_init(3)

path - Ruta completa del directorio existente a eliminar.

path_len - Longitud de la ruta completa del directorio existente a eliminar.

VALOR DE RETORNO

Devuelve 0 si tiene éxito o un valor negativo en caso de fallo. Devuelve LIBSSH2_ERROR_EAGAIN cuando de lo contrario bloquearía. Aunque LIBSSH2_ERROR_EAGAIN es un número negativo, no es realmente un fallo en sí mismo.

ERRORES

LIBSSH2_ERROR_ALLOC - Falló una llamada interna de asignación de memoria.

LIBSSH2_ERROR_SOCKET_SEND - No se pueden enviar datos por el socket.

LIBSSH2_ERROR_SOCKET_TIMEOUT -

LIBSSH2_ERROR_SFTP_PROTOCOL - Se recibió una respuesta de protocolo SFTP inválida en el socket, o una operación SFTP causó que el servidor devolviera un código de error.

VER TAMBIÉN
