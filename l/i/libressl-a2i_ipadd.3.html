libressl-a2i_ipadd(3)

Paquete: libressl

Licencias: ISC, custom:OpenSSL

A2I_IPADD(3) Manual de funciones de biblioteca A2I_IPADD(3)

NOMBRE

a2i_ipadd, a2i_IPADDRESS, a2i_IPADDRESS_NC — analizar direcciones de Protocolo de Internet en cadenas de OCTETOS ASN.1 para X.509

SINOPSIS

biblioteca “libcrypto”
#include <openssl/x509v3.h>

int
a2i_ipadd(unsigned char *ipout, const char *ipasc);

ASN1_OCTET_STRING *
a2i_IPADDRESS(const char *ipasc);

ASN1_OCTET_STRING *
a2i_IPADDRESS_NC(const char *ipasc);

DESCRIPCIÓN

a2i_ipadd() y a2i_IPADDRESS() analizan la cadena ipasc que contiene una dirección IPv4 o IPv6 en uno de los siguientes formatos:

d.d.d.d
x:x:x:x:x:x:x:x (exactamente 8 palabras)
(x:)*x::x(:x)* (menos de 8 palabras)
(x:)*x:: (menos de 8 palabras)
::x(:x)* (menos de 8 palabras)
::
(x:)*d.d.d.d (hasta 6 palabras hexadecimales, se puede usar ::)

donde cada d representa un número decimal no negativo menor que 256 con uno, dos o tres dígitos, y cada x representa un número hexadecimal no negativo con uno, dos, tres o cuatro dígitos. Se pueden usar tanto las letras minúsculas a-f como las mayúsculas A-F.

a2i_ipadd() almacena los bytes de la dirección en orden de bytes de red (big endian) comenzando en ipout. El llamador es responsable de proporcionar suficiente espacio; siempre se recomienda proporcionar un búfer de al menos 16 bytes, incluso si se espera una dirección IPv4, para evitar desbordamientos de búfer en caso de que ipasc esté mal formado.

a2i_IPADDRESS() almacena la dirección en una OCTET STRING ASN.1 recién asignada.

a2i_IPADDRESS_NC() espera que ipasc contenga dos direcciones de la misma familia de direcciones en la forma anterior, separadas por un carácter de barra (‘/’), y almacena la concatenación de ambas direcciones en una OCTET STRING ASN.1 recién asignada, que se utiliza típicamente para pares de dirección/máscara en extensiones de restricciones de nombre de certificados CA.

VALORES DE RETORNO

a2i_ipadd() devuelve el número de bytes escritos en ipout en caso de éxito, es decir, 4 para una dirección IPv4 o 16 para una dirección IPv6, o 0 si el análisis falló.

a2i_IPADDRESS() y a2i_IPADDRESS_NC() devuelven el nuevo objeto o NULL si el análisis o la asignación de memoria fallaron.

VER TAMBIÉN

HISTORIA

a2i_IPADDRESS() y a2i_IPADDRESS_NC() aparecieron por primera vez en OpenSSL 0.9.8 y a2i_ipadd() en OpenSSL 0.9.8e. Han estado disponibles desde OpenBSD 4.5.

ADVERTENCIAS

Aunque se detectan algunos errores de sintaxis, solo se realiza una validación mínima, y estas funciones a menudo devuelven objetos que no tienen sentido, en particular en el contexto de IPv6. Por ejemplo, la sintaxis :d.d.d.d final se puede anexar a una parte hexadecimal que da como resultado doce bytes arbitrarios.
