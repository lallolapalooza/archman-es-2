D2I_PKCS8_PRIV_KEY_INFO(3) Manual de funciones de biblioteca D2I_PKCS8_PRIV_KEY_INFO(3)

NOMBRE

d2i_PKCS8_PRIV_KEY_INFO, i2d_PKCS8_PRIV_KEY_INFO, d2i_PKCS8_PRIV_KEY_INFO_bio, i2d_PKCS8_PRIV_KEY_INFO_bio, d2i_PKCS8_PRIV_KEY_INFO_fp, i2d_PKCS8_PRIV_KEY_INFO_fp — decodificar y codificar clave privada PKCS#8

SINOPSIS

biblioteca “libcrypto”
#include <openssl/x509.h>

PKCS8_PRIV_KEY_INFO *
d2i_PKCS8_PRIV_KEY_INFO(PKCS8_PRIV_KEY_INFO **val_out, const unsigned char **der_in, long length);

int
i2d_PKCS8_PRIV_KEY_INFO(PKCS8_PRIV_KEY_INFO *val_in, unsigned char **der_out);

PKCS8_PRIV_KEY_INFO *
d2i_PKCS8_PRIV_KEY_INFO_bio(BIO *in_bio, PKCS8_PRIV_KEY_INFO **val_out);

int
i2d_PKCS8_PRIV_KEY_INFO_bio(BIO *out_bio, PKCS8_PRIV_KEY_INFO *val_in);

PKCS8_PRIV_KEY_INFO *
d2i_PKCS8_PRIV_KEY_INFO_fp(FILE *in_fp, PKCS8_PRIV_KEY_INFO **val_out);

int
i2d_PKCS8_PRIV_KEY_INFO_fp(BIO *out_fp, PKCS8_PRIV_KEY_INFO *val_in);

DESCRIPCIÓN

d2i_PKCS8_PRIV_KEY_INFO() y i2d_PKCS8_PRIV_KEY_INFO() decodifican y codifican una estructura PrivateKeyInfo ASN.1 definida en la RFC 5208, sección 5.

d2i_PKCS8_PRIV_KEY_INFO_bio(), i2d_PKCS8_PRIV_KEY_INFO_bio(), d2i_PKCS8_PRIV_KEY_INFO_fp(), y i2d_PKCS8_PRIV_KEY_INFO_fp() son similares excepto que decodifican o codifican usando un puntero BIO o FILE.

Para obtener detalles sobre la semántica, ejemplos, advertencias y errores, consulte ASN1_item_d2i(3).

Estas funciones utilizan el formato DER sin cifrar. Para almacenar claves privadas en formato cifrado, considere d2i_PKCS8PrivateKey_bio(3) o PEM_write_PKCS8PrivateKey(3).

VALORES DE RETORNO

d2i_PKCS8_PRIV_KEY_INFO(), d2i_PKCS8_PRIV_KEY_INFO_bio(), y d2i_PKCS8_PRIV_KEY_INFO_fp() devuelven un objeto PKCS8_PRIV_KEY_INFO o NULL si ocurre un error.

i2d_PKCS8_PRIV_KEY_INFO() devuelve el número de bytes codificados correctamente o un valor negativo si ocurre un error.

i2d_PKCS8_PRIV_KEY_INFO_bio() y i2d_PKCS8_PRIV_KEY_INFO_fp() devuelven 1 para éxito o 0 si ocurre un error.

VER TAMBIÉN

ASN1_item_d2i(3), d2i_PKCS8PrivateKey_bio(3), d2i_PrivateKey(3), PEM_write_PKCS8_PRIV_KEY_INFO(3), PKCS8_PRIV_KEY_INFO_new(3)

ESTÁNDARES

RFC 5208: PKCS#8: Especificación de sintaxis de información de clave privada

HISTORIA

d2i_PKCS8_PRIV_KEY_INFO() y i2d_PKCS8_PRIV_KEY_INFO() aparecieron por primera vez en OpenSSL 0.9.3. d2i_PKCS8_PRIV_KEY_INFO_bio(), i2d_PKCS8_PRIV_KEY_INFO_bio(), d2i_PKCS8_PRIV_KEY_INFO_fp(), y i2d_PKCS8_PRIV_KEY_INFO_fp() aparecieron por primera vez en OpenSSL 0.9.4. Todas estas funciones han estado disponibles desde OpenBSD 2.6.
