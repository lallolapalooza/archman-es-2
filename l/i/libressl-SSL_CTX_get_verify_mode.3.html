libressl-SSL_CTX_get_verify_mode(3)

Paquete: libressl

Licencias: ISC, custom:OpenSSL

SSL_CTX_GET_VERIFY_MODE(3) Manual de funciones de biblioteca SSL_CTX_GET_VERIFY_MODE(3)

NOMBRE

SSL_CTX_get_verify_mode, SSL_get_verify_mode, SSL_CTX_get_verify_depth, SSL_get_verify_depth, SSL_get_verify_callback, SSL_CTX_get_verify_callback — obtener los parámetros de verificación establecidos actualmente

SINOPSIS

biblioteca “libssl” libcrypto
#include <openssl/ssl.h>

int
SSL_CTX_get_verify_mode(const SSL_CTX *ctx);

int
SSL_get_verify_mode(const SSL *ssl);

int
SSL_CTX_get_verify_depth(const SSL_CTX *ctx);

int
SSL_get_verify_depth(const SSL *ssl);

int
(*SSL_CTX_get_verify_callback(const SSL_CTX *ctx))(int, X509_STORE_CTX *);

int
(*SSL_get_verify_callback(const SSL *ssl))(int, X509_STORE_CTX *);

DESCRIPCIÓN

SSL_CTX_get_verify_mode() devuelve el modo de verificación establecido actualmente en ctx.

SSL_get_verify_mode() devuelve el modo de verificación establecido actualmente en ssl.

SSL_CTX_get_verify_depth() devuelve el límite de profundidad de verificación establecido actualmente en ctx. Si no se ha establecido explícitamente ningún límite, se devuelve −1 y se utilizará el valor predeterminado.

SSL_get_verify_depth() devuelve el límite de profundidad de verificación establecido actualmente en ssl. Si no se ha establecido explícitamente ningún límite, se devuelve −1 y se utilizará el valor predeterminado.

SSL_CTX_get_verify_callback() devuelve un puntero de función al callback de verificación establecido actualmente en ctx. Si no se ha establecido explícitamente ningún callback, se devuelve el puntero NULL y se utilizará el callback predeterminado.

SSL_get_verify_callback() devuelve un puntero de función al callback de verificación establecido actualmente en ssl. Si no se ha establecido explícitamente ningún callback, se devuelve el puntero NULL y se utilizará el callback predeterminado.

VER TAMBIÉN

ssl(3), SSL_CTX_set_verify(3)

HISTORIA

SSL_CTX_get_verify_mode(), SSL_get_verify_mode(), SSL_get_verify_callback() y SSL_CTX_get_verify_callback() aparecieron por primera vez en SSLeay 0.8.0 y han estado disponibles desde OpenBSD 2.4.

SSL_CTX_get_verify_depth() y SSL_get_verify_depth() aparecieron por primera vez en OpenSSL 0.9.3 y han estado disponibles desde OpenBSD 2.6.
