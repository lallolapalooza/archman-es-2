NOMBRE

libpipewire-module-example-filter - Filtro de ejemplo

DESCRIPCIÓN

El filtro de ejemplo es un buen punto de partida para escribir un filtro personalizado.

Consulte el código fuente para obtener más información.

NOMBRE DEL MÓDULO

libpipewire-module-example-filter

OPCIONES DEL MÓDULO

  • node.description: un nombre legible por humanos para los flujos del filtro
  • capture.props = {}: propiedades que se pasarán al flujo de entrada
  • playback.props = {}: propiedades que se pasarán al flujo de salida

OPCIONES GENERALES

Opciones con comportamiento conocido. La mayoría de las opciones se pueden agregar a la configuración global o a los flujos individuales:

  • remote.name
  • audio.rate
  • audio.channels
  • audio.position
  • media.name
  • node.latency
  • node.description
  • node.group
  • node.link.group
  • node.virtual
  • node.name : Consulte las notas a continuación. Si no se especifica, el valor predeterminado es 'filter-PID-MODULEID'.

Propiedades solo de flujo:

  • media.class
  • node.name : si no se proporciona por flujo, al global node.name se le agregarán los prefijos 'input.' y 'output.' para generar un nombre de nodo de captura y reproducción respectivamente.

EJEMPLO DE CONFIGURACIÓN DE UNA FUENTE VIRTUAL

# ~/.config/pipewire/pipewire.conf.d/my-example-filter.conf
context.modules = [
{   name = libpipewire-module-example-filter
    args = {
      node.description = "Filtro de ejemplo"
      capture.props = {
          audio.position = [ FL FR ]
          node.passive = true
      }
      playback.props = {
          node.name = "Filtro de ejemplo"
          media.class = "Audio/Source"
          audio.position = [ FL FR ]
      }
    }
}
]
pw-cli -m lm libpipewire-module-example-filter '{ audio.position=[FL FR] }'
