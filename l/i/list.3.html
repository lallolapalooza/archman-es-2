LIST(3) Manual de funciones de biblioteca LIST(3)

NOMBRE

LIST_EMPTY, LIST_ENTRY, LIST_FIRST, LIST_FOREACH, LIST_HEAD, LIST_HEAD_INITIALIZER, LIST_INIT, LIST_INSERT_AFTER, LIST_INSERT_BEFORE, LIST_INSERT_HEAD, LIST_NEXT, LIST_REMOVE - implementación de una lista doblemente enlazada

BIBLIOTECA

Biblioteca C estándar (libc, -lc)

SINOPSIS

#include <sys/queue.h>
LIST_ENTRY(TIPO);
LIST_HEAD(NOMBRE_CABEZA, TIPO);
LIST_HEAD LIST_HEAD_INITIALIZER(LIST_HEAD cabeza);
void LIST_INIT(LIST_HEAD *cabeza);
int LIST_EMPTY(LIST_HEAD *cabeza);
void LIST_INSERT_HEAD(LIST_HEAD *cabeza,
                        struct TIPO *elem, LIST_ENTRY NOMBRE);
void LIST_INSERT_BEFORE(struct TIPO *elem_lista,
                        struct TIPO *elem, LIST_ENTRY NOMBRE);
void LIST_INSERT_AFTER(struct TIPO *elem_lista,
                        struct TIPO *elem, LIST_ENTRY  NOMBRE);
struct TIPO *LIST_FIRST(LIST_HEAD *cabeza);
struct TIPO *LIST_NEXT(struct TIPO *elem, LIST_ENTRY  NOMBRE);
LIST_FOREACH(struct TIPO *var, LIST_HEAD *cabeza, LIST_ENTRY  NOMBRE);
void LIST_REMOVE(struct TIPO *elem, LIST_ENTRY  NOMBRE);

DESCRIPCIÓN

Estas macros definen y operan sobre listas doblemente enlazadas.

En las definiciones de macro, TIPO es el nombre de una estructura definida por el usuario, que debe contener un campo de tipo LIST_ENTRY, llamado NOMBRE. El argumento NOMBRE_CABEZA es el nombre de una estructura definida por el usuario que debe declararse usando la macro LIST_HEAD().

Creación

Una lista está encabezada por una estructura definida por la macro LIST_HEAD(). Esta estructura contiene un único puntero al primer elemento de la lista. Los elementos están doblemente enlazados para que se pueda eliminar un elemento arbitrario sin recorrer la lista. Se pueden agregar nuevos elementos a la lista después de un elemento existente, antes de un elemento existente o al principio de la lista. Una estructura LIST_HEAD se declara de la siguiente manera:


LIST_HEAD(NOMBRE_CABEZA, TIPO) cabeza;

donde struct NOMBRE_CABEZA es la estructura que se va a definir, y struct TIPO es el tipo de los elementos que se van a enlazar en la lista. Un puntero a la cabeza de la lista se puede declarar posteriormente como:


struct NOMBRE_CABEZA *puntero_cabeza;

(Los nombres cabeza y puntero_cabeza son elegibles por el usuario.)

LIST_ENTRY() declara una estructura que conecta los elementos de la lista.

LIST_HEAD_INITIALIZER() se evalúa como un inicializador para la lista cabeza.

LIST_INIT() inicializa la lista referenciada por cabeza.

LIST_EMPTY() se evalúa como verdadero si no hay elementos en la lista.

Inserción

LIST_INSERT_HEAD() inserta el nuevo elemento elem al principio de la lista.

LIST_INSERT_BEFORE() inserta el nuevo elemento elem antes del elemento elem_lista.

LIST_INSERT_AFTER() inserta el nuevo elemento elem después del elemento elem_lista.

Recorrido

LIST_FIRST() devuelve el primer elemento de la lista, o NULL si la lista está vacía.

LIST_NEXT() devuelve el siguiente elemento de la lista, o NULL si es el último.

LIST_FOREACH() recorre la lista referenciada por cabeza en dirección hacia adelante, asignando cada elemento en su turno a var.

Eliminación

LIST_REMOVE() elimina el elemento elem de la lista.

VALOR DE RETORNO

LIST_EMPTY() devuelve un valor distinto de cero si la lista está vacía y cero si la lista contiene al menos una entrada.

LIST_FIRST() y LIST_NEXT() devuelven un puntero a la estructura TIPO primera o siguiente, respectivamente.

LIST_HEAD_INITIALIZER() devuelve un inicializador que puede ser asignado a la lista cabeza.

ESTÁNDARES

BSD.

HISTORIA

4.4BSD.

ERRORES

LIST_FOREACH() no permite que var sea eliminado o liberado dentro del bucle, ya que interferiría con el recorrido. LIST_FOREACH_SAFE(), que está presente en los BSD pero no en glibc, soluciona esta limitación al permitir que var sea eliminado de forma segura de la lista y liberado desde dentro del bucle sin interferir con el recorrido.

EJEMPLOS

#include <stddef.h>
#include <stdio.h>
#include <stdlib.h>
#include <sys/queue.h>
struct entry {
    int data;
    LIST_ENTRY(entry) entries;              /* List */
};
LIST_HEAD(listhead, entry);
int
main(void)
{
    struct entry *n1, *n2, *n3, *np;
    struct listhead head;                   /* List head */
    int i;
    LIST_INIT(&head);                       /* Initialize the list */
    n1 = malloc(sizeof(struct entry));      /* Insert at the head */
    LIST_INSERT_HEAD(&head, n1, entries);
    n2 = malloc(sizeof(struct entry));      /* Insert after */
    LIST_INSERT_AFTER(n1, n2, entries);
    n3 = malloc(sizeof(struct entry));      /* Insert before */
    LIST_INSERT_BEFORE(n2, n3, entries);
    i = 0;                                  /* Forward traversal */
    LIST_FOREACH(np, &head, entries)
        np->data = i++;
    LIST_REMOVE(n2, entries);               /* Deletion */
    free(n2);
                                            /* Forward traversal */
    LIST_FOREACH(np, &head, entries)
        printf("%i\n", np->data);
                                            /* List deletion */
    n1 = LIST_FIRST(&head);
    while (n1 != NULL) {
        n2 = LIST_NEXT(n1, entries);
        free(n1);
        n1 = n2;
    }
    LIST_INIT(&head);
    exit(EXIT_SUCCESS);
}

NAME

list - Create a list of strings.

SYNOPSIS

#include <list.h>

int list(char ***list, size_t *count, const char *...);

int list_v(char ***list, size_t *count, va_list args);

DESCRIPTION

The list() function creates a null-terminated array of strings from a variable number of arguments. The arguments must be valid strings, and the list of arguments must be terminated by a NULL pointer.

The list_v() function is similar to list(), but it accepts a va_list as an argument, allowing for more flexibility in how the list of strings is passed.

The created list is stored in the memory pointed to by list, and the number of strings in the list is stored in count. The caller is responsible for freeing the memory allocated for the list using free().

RETURN VALUE

On success, list() and list_v() return 0. On failure, they return -1 and set errno to indicate the error.

ERRORS

ENOMEM
Insufficient memory available to create the list.

EXAMPLE

#include <stdio.h>
#include <stdlib.h>
#include <list.h>

int main() {
    char **my_list = NULL;
    size_t count = 0;
    int ret;

    ret = list(&my_list, &count, "hello", "world", NULL);
    if (ret != 0) {
        perror("list");
        return 1;
    }

    printf("List created with %zu strings:\n", count);
    for (size_t i = 0; i < count; ++i) {
        printf("%s\n", my_list[i]);
    }

    // Free the allocated memory
    free(my_list);

    return 0;
}
