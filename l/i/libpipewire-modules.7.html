NOMBRE

libpipewire-modules - Módulos de PipeWire

DESCRIPCIÓN

Un módulo de PipeWire es efectivamente un cliente de PipeWire que se ejecuta dentro de pipewire(1) y que puede albergar múltiples módulos. Normalmente, los módulos se cargan cuando se listan en los archivos de configuración. Por ejemplo, el archivo de configuración predeterminado carga varios módulos:

context.modules = [
    ...
    # El protocolo de comunicación nativo.
    {   name = libpipewire-module-protocol-native }
    # El módulo de perfil. Permite a las aplicaciones acceder a datos de
    # perfilador y de rendimiento. Proporciona una interfaz que es utilizada
    # por pw-top y pw-profiler.
    {   name = libpipewire-module-profiler }
    # Permite a las aplicaciones crear objetos de metadatos. Crea
    # una fábrica para objetos de Metadatos.
    {   name = libpipewire-module-metadata }
    # Crea una fábrica para crear dispositivos que se ejecutan en el
    # contexto del servidor PipeWire.
    {   name = libpipewire-module-spa-device-factory }
    ...
]
