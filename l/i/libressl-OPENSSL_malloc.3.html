libressl-OPENSSL_malloc(3)

Paquete: libressl

Licencias: ISC, custom:OpenSSL

OPENSSL_MALLOC(3) Manual de funciones de la biblioteca OPENSSL_MALLOC(3)

NOMBRE

OPENSSL_malloc, OPENSSL_free, OPENSSL_strdup, CRYPTO_malloc, CRYPTO_free, CRYPTO_strdup — envolturas heredadas para la asignación de memoria de OpenSSL

SINOPSIS

biblioteca «libcrypto»
#include <openssl/crypto.h>

void *
OPENSSL_malloc(size_t num);

void
OPENSSL_free(void *addr);

char *
OPENSSL_strdup(const char *str);

void *
CRYPTO_malloc(size_t num, const char *file, int line);

void
CRYPTO_free(void *str, const char *, int);

char *
CRYPTO_strdup(const char *p, const char *file, int line);

DESCRIPCIÓN

No utilice ninguna de las interfaces documentadas aquí en código nuevo. Se proporcionan únicamente por compatibilidad con código de aplicación heredado.

Estas funciones son envolturas alrededor de las funciones estándar correspondientes de malloc(3), free(3) y strdup(3).

Las funciones OPENSSL_*() se implementan como macros.

VALORES DE RETORNO

Estas funciones devuelven el mismo tipo y valor que las funciones estándar correspondientes.

VER TAMBIÉN

crypto(3)

HISTORIA

CRYPTO_malloc() y CRYPTO_free() aparecieron por primera vez en SSLeay 0.6.4 y han estado disponibles desde OpenBSD 2.4.

OPENSSL_malloc() y OPENSSL_free() aparecieron por primera vez en OpenSSL 0.9.6 y han estado disponibles desde OpenBSD 2.9.

CRYPTO_strdup() y OPENSSL_strdup() aparecieron por primera vez en OpenSSL 0.9.8j y han estado disponibles desde OpenBSD 4.5.

ADVERTENCIAS

Si se requiere interoperabilidad con otras implementaciones, la memoria devuelta por la biblioteca como punteros sin procesar debe liberarse con OPENSSL_free().
