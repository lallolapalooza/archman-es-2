NOMBRE

libssh2_channel_receive_window_adjust2 - ajustar la ventana del canal

SINOPSIS

#include <libssh2.h>
int
libssh2_channel_receive_window_adjust2(LIBSSH2_CHANNEL * channel,
                                       unsigned long adjustment,
                                       unsigned char force,
                                       unsigned int *window);

DESCRIPCIÓN

Ajusta la ventana de recepción para un canal en 'adjustment' bytes. Si la cantidad a ajustar es menor que LIBSSH2_CHANNEL_MINADJUST y 'force' es 0, la cantidad de ajuste se pondrá en cola para un paquete posterior.

Esta función almacena el nuevo tamaño de la ventana de recepción (tal como lo entiende el extremo remoto) en la variable a la que apunta 'window'.

VALOR DE RETORNO

Devuelve 0 en caso de éxito y un valor negativo en caso de error. Si se usa en modo no bloqueante, devolverá LIBSSH2_ERROR_EAGAIN cuando de lo contrario se bloquearía.

ERRORES

DISPONIBILIDAD

Añadido en libssh2 1.1 ya que la API anterior tiene deficiencias.
