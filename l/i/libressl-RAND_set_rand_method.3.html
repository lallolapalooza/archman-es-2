libressl-RAND_set_rand_method(3)

Paquete: libressl

Licencias: ISC, custom:OpenSSL

RAND_SET_RAND_METHOD(3) Manual de funciones de biblioteca RAND_SET_RAND_METHOD(3)

NOMBRE

RAND_set_rand_method, RAND_get_rand_method, RAND_SSLeay — seleccionar método RAND

SINOPSIS

biblioteca “libcrypto”
#include <openssl/rand.h>

int
RAND_set_rand_method(const RAND_METHOD *meth);

const RAND_METHOD *
RAND_get_rand_method(void);

RAND_METHOD *
RAND_SSLeay(void);

DESCRIPCIÓN

Estas funciones solían permitir que las funciones del generador de números aleatorios se reemplazaran por código arbitrario.

Se conservan por compatibilidad de ABI, pero ya no son funcionales y no deben usarse en programas nuevos.

VALORES DE RETORNO

RAND_set_rand_method() siempre devuelve 1. RAND_get_rand_method() y RAND_SSLeay() siempre devuelven NULL.

HISTORIAL

RAND_set_rand_method(), RAND_get_rand_method() y RAND_SSLeay() aparecieron por primera vez en SSLeay 0.9.1 y han estado disponibles desde OpenBSD 2.6.

8 de junio de 2025 Linux 6.17.8-arch1-1
