libssh2_sftp_unlink_ex(3)

Paquete: libssh2

Licencias: BSD

libssh2_sftp_unlink_ex(3) libssh2 libssh2_sftp_unlink_ex(3)

NOMBRE

libssh2_sftp_unlink_ex - eliminar un archivo SFTP

SINOPSIS

#include <libssh2.h>
#include <libssh2_sftp.h>
int
libssh2_sftp_unlink_ex(LIBSSH2_SFTP *sftp, const char *filename, unsigned int filename_len);
int
libssh2_sftp_unlink(LIBSSH2_SFTP *sftp, const char *filename);

DESCRIPCIÓN

sftp - instancia SFTP devuelta por libssh2_sftp_init(3)

filename - Ruta y nombre de la entrada existente en el sistema de archivos

filename_len - Longitud de la ruta y nombre de la entrada existente en el sistema de archivos

Elimina (borra) un archivo del sistema de archivos remoto.

VALOR DE RETORNO

Retorna 0 en caso de éxito o un número negativo en caso de fallo. Devuelve LIBSSH2_ERROR_EAGAIN cuando de otro modo bloquearía. Si bien LIBSSH2_ERROR_EAGAIN es un número negativo, no es realmente un fallo en sí mismo.

ERRORES

LIBSSH2_ERROR_ALLOC - Una llamada interna de asignación de memoria falló.

LIBSSH2_ERROR_SOCKET_SEND - No se pudieron enviar datos por el socket.

LIBSSH2_ERROR_SOCKET_TIMEOUT -

LIBSSH2_ERROR_SFTP_PROTOCOL - Se recibió una respuesta inválida del protocolo SFTP en el socket, o una operación SFTP provocó que el servidor devolviera un código de error.

VER TAMBIÉN
