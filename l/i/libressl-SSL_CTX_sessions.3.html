NOMBRE

SSL_CTX_sessions — acceder al caché de sesiones interno

SINOPSIS

biblioteca “libssl” libcrypto
#include <openssl/ssl.h>

LHASH_OF(SSL_SESSION) *
SSL_CTX_sessions(SSL_CTX *ctx);

DESCRIPCIÓN

SSL_CTX_sessions() devuelve un puntero a las bases de datos lhash que contienen el caché de sesiones interno para ctx.

Las sesiones en el caché de sesiones interno se mantienen en una base de datos de tipo lhash (ver lh_new(3)). Es posible acceder directamente a esta base de datos, por ejemplo, para buscar. Paralelamente, las sesiones forman una lista enlazada que se mantiene por separado de las operaciones lhash, por lo que la base de datos no debe modificarse directamente, sino utilizando la familia de funciones SSL_CTX_add_session(3).

VER TAMBIÉN

lh_new(3), ssl(3), SSL_CTX_add_session(3), SSL_CTX_set_session_cache_mode(3)

HISTORIA

SSL_CTX_sessions() apareció por primera vez en SSLeay 0.5.2 y ha estado disponible desde OpenBSD 2.4.
