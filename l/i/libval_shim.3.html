NOMBRE

La biblioteca de "shim" del validador

DESCRIPCIÓN

La biblioteca de "shim" del validador (libval_shim.so) es una biblioteca compartida diseñada para ser cargada dinámicamente usando el mecanismo 'LD_PRELOAD' (ld.so(8)) compatible con Linux y varias otras plataformas similares a Unix. La biblioteca de "shim" implementa envolturas para un número de funciones relacionadas con DNS y, a su vez, llama a funciones de validación equivalentes y conscientes de DNSSEC de libval(3), mapeando los resultados a códigos de retorno reconocidos por las funciones originales. De esta manera, una amplia variedad de aplicaciones pueden ser conscientes de DNSSEC sin cambios en el código y sin recompilación.

El método de mapeo de códigos de retorno asume que cualquier resultado 'no confiable' o de fallo de la función de libval(3) se refleja como un fallo para la función llamada original.

Uso:

Para cargar la biblioteca, establezca la variable LD_PRELOAD en el entorno de la aplicación objetivo antes de la ejecución:

Política de validación:

La biblioteca de "shim" del validador creará un contexto de política y lo almacenará en caché para todas las llamadas posteriores a libval(3). Se pasará una etiqueta de política NULL para crear el contexto. La política se elige de acuerdo con las reglas definidas para libval(3).

Consulte dnsval.conf(1) para obtener información sobre etiquetas y definiciones de políticas.

Registro:

El registro para las funciones de libval(3) puede habilitarse en la biblioteca de "shim" estableciendo una variable de entorno.

Consulte dt-validate(1) para obtener detalles.

NOTAS

programas setuid/setgid

Los programas setuid y setgid root (por ejemplo, ping(8)) no respetan la configuración de LD_PRELOAD. Estas aplicaciones aún pueden usar el mecanismo LD_PRELOAD cuando se ejecutan directamente desde una shell de root.
