libnetlink(3) Manual de Funciones de Librería libnetlink(3)

NOMBRE

libnetlink - Una librería para acceder al servicio netlink

SINOPSIS

#include <asm/types.h>
#include <libnetlink.h>
#include <linux/netlink.h>
#include <linux/rtnetlink.h>

int rtnl_open(struct rtnl_handle *rth, unsigned subscriptions)

int rtnl_wilddump_request(struct rtnl_handle *rth, int family, int type)

int rtnl_send(struct rtnl_handle *rth, char *buf, int len)

int rtnl_dump_request(struct rtnl_handle *rth, int type, void *req, int len)

int rtnl_dump_filter(struct rtnl_handle *rth,
		     int (*filter)(struct sockaddr_nl *, struct nlmsghdr *n, void *),
		     void *arg1,
		     int (*junk)(struct sockaddr_nl *,struct nlmsghdr *n, void *),
		     void *arg2)

int rtnl_talk(struct rtnl_handle *rtnl, struct nlmsghdr *n, pid_t peer,
	      unsigned groups, struct nlmsghdr *answer,
	      int (*junk)(struct sockaddr_nl *,struct nlmsghdr *n, void *),
	      void *jarg)

int rtnl_listen(struct rtnl_handle *rtnl,
	      int (*handler)(struct sockaddr_nl *, struct rtnl_ctrl_data *,
			     struct nlmsghdr *n, void *),
	      void *jarg)

int rtnl_from_file(FILE *rtnl,
	      int (*handler)(struct sockaddr_nl *,struct nlmsghdr *n, void *),
	      void *jarg)

int addattr32(struct nlmsghdr *n, int maxlen, int type, __u32 data)

int addattr_l(struct nlmsghdr *n, int maxlen, int type, void *data, int alen)

int rta_addattr32(struct rtattr *rta, int maxlen, int type, __u32 data)

int rta_addattr_l(struct rtattr *rta, int maxlen, int type, void *data, int alen)

DESCRIPCIÓN

libnetlink proporciona una interfaz de nivel superior a rtnetlink(7). Las funciones de lectura devuelven 0 en caso de éxito y un errno negativo en caso de error. Las funciones de envío devuelven la cantidad de datos enviados, o -1 en caso de error.

rtnl_open
Abre un socket rtnetlink y guarda el estado en el manejador rth. Este manejador se pasa a todas las llamadas subsiguientes. subscriptions es un mapa de bits de los grupos de multidifusión de rtnetlink de los que será miembro el socket.
rtnl_wilddump_request
Solicita un volcado completo de la base de datos type para direcciones de la familia family. type es un tipo de mensaje rtnetlink.
rtnl_dump_request
Solicita un volcado completo del buffer de datos type en buf con una longitud máxima de len. type es un tipo de mensaje rtnetlink.
rtnl_dump_filter
Recibe datos netlink después de una solicitud y los filtra. El callback filter comprueba si el mensaje recibido es el deseado. Recibe la dirección de origen del mensaje, el mensaje en sí y arg1 como argumentos. Un valor de 0 como retorno significa que el filtro ha pasado, un valor negativo es devuelto por rtnl_dump_filter en caso de error. NULL para filter significa no usar filtro. junk se utiliza para filtrar mensajes no destinados al socket local. Solo se recibe un paquete de mensajes. Si hay un mensaje pendiente, esta función no se bloquea.
rtnl_listen
Recibe datos netlink después de una solicitud y los pasa a handler. handler es un callback que recibe la dirección de origen del mensaje, datos auxiliares, el mensaje en sí y la cookie jarg como argumentos. Se llamará para todos los mensajes recibidos. Solo se recibe un paquete de mensajes. Si hay un mensaje pendiente, esta función no se bloquea.
rtnl_from_file
Funciona como rtnl_listen, pero lee un paquete de mensajes netlink del archivo file y pasa los mensajes a handler para su análisis. El archivo debe contener datos crudos tal como se reciben de un socket rtnetlink.

Las siguientes funciones son útiles para construir mensajes rtnetlink personalizados. Para volcados simples de bases de datos con filtrado, es mejor utilizar las funciones de nivel superior mencionadas. Consulte rtnetlink(3) y netlink(3) sobre cómo generar un mensaje rtnetlink. Las siguientes funciones de utilidad requieren un buffer continuo que ya contenga una cabecera de mensaje netlink y una solicitud rtnetlink.

rtnl_send
Envía el mensaje rtnetlink en buf de longitud len al manejador rth.
addattr32
Añade un atributo __u32 de tipo type y con valor data al mensaje netlink n, que forma parte de un buffer de longitud maxlen.
addattr_l
Añade un atributo de longitud variable de tipo type y con valor data y longitud alen al mensaje netlink n, que forma parte de un buffer de longitud maxlen. Se copia data.
rta_addattr32
Inicializa el atributo rtnetlink rta con un valor de datos __u32.
rta_addattr32
Inicializa el atributo rtnetlink rta con un valor de datos de longitud variable.

ERRORES

Esta librería está destinada a uso interno, utilice libmnl para nuevos programas.

Las funciones a veces usan fprintf y exit cuando ocurre un error fatal. Esta librería debería llamarse librtnetlink.
