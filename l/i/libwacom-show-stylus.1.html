NOMBRE

libwacom-show-stylus - utilidad para mostrar el ID de herramienta y el número de serie de un lápiz óptico

SINOPSIS

libwacom-show-stylus [ruta]

DESCRIPCIÓN

libwacom-show-stylus es una utilidad interactiva de depuración para mostrar el ID de herramienta y el número de serie de un lápiz óptico que se encuentra actualmente en proximidad.

Esta herramienta necesita acceso de lectura al nodo del dispositivo /dev/input/event*. Normalmente, esto significa que debe ejecutarse como root.

Si no se proporciona ninguna ruta, esta herramienta busca el primer dispositivo de tableta disponible y lo utiliza. De lo contrario, la ruta debe ser un nodo de dispositivo evdev, por ejemplo, /dev/input/event0.
