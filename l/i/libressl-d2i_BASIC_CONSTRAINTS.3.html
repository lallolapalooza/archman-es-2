libressl-d2i_BASIC_CONSTRAINTS(3)

Paquete: libressl

Licencias: ISC, custom:OpenSSL

D2I_BASIC_CONSTRAINTS(3) Manual de Funciones de Librería D2I_BASIC_CONSTRAINTS(3)

NOMBRE

d2i_BASIC_CONSTRAINTS, i2d_BASIC_CONSTRAINTS, d2i_EXTENDED_KEY_USAGE, i2d_EXTENDED_KEY_USAGE — decodifica y codifica los propósitos de uso de claves X.509

SINOPSIS

librería «libcrypto»
#include <openssl/x509v3.h>

BASIC_CONSTRAINTS *
d2i_BASIC_CONSTRAINTS(BASIC_CONSTRAINTS **val_out, const unsigned char **der_in, long length);

int
i2d_BASIC_CONSTRAINTS(BASIC_CONSTRAINTS *val_in, unsigned char **der_out);

EXTENDED_KEY_USAGE *
d2i_EXTENDED_KEY_USAGE(EXTENDED_KEY_USAGE **val_out, const unsigned char **der_in, long length);

int
i2d_EXTENDED_KEY_USAGE(EXTENDED_KEY_USAGE *val_in, unsigned char **der_out);

DESCRIPCIÓN

Estas funciones decodifican y codifican estructuras de datos que describen los propósitos previstos para los que se va a utilizar la clave contenida en un certificado X.509. Para obtener detalles sobre la semántica, ejemplos, advertencias y errores, consulte ASN1_item_d2i(3).

d2i_BASIC_CONSTRAINTS() y i2d_BASIC_CONSTRAINTS() decodifican y codifican una estructura ASN.1 BasicConstraints definida en la RFC 5280 sección 4.2.1.9.

d2i_EXTENDED_KEY_USAGE() y i2d_EXTENDED_KEY_USAGE() decodifican y codifican una estructura ASN.1 ExtKeyUsageSyntax definida en la RFC 5280 sección 4.2.1.12.

VALORES DE RETORNO

d2i_BASIC_CONSTRAINTS() y d2i_EXTENDED_KEY_USAGE() devuelven un objeto BASIC_CONSTRAINTS o EXTENDED_KEY_USAGE, respectivamente, o NULL si ocurre un error.

i2d_BASIC_CONSTRAINTS() y i2d_EXTENDED_KEY_USAGE() devuelven el número de bytes codificados con éxito o un valor negativo si ocurre un error.

VER TAMBIÉN

ASN1_item_d2i(3), BASIC_CONSTRAINTS_new(3), EXTENDED_KEY_USAGE_new(3), X509_EXTENSION_new(3)

ESTÁNDARES

RFC 5280: Perfil de Certificado y Lista de Revocación de Certificados (CRL) de la Infraestructura de Clave Pública Internet X.509

HISTORIA

d2i_BASIC_CONSTRAINTS() y i2d_BASIC_CONSTRAINTS() aparecieron por primera vez en OpenSSL 0.9.2b y han estado disponibles desde OpenBSD 2.6.

d2i_EXTENDED_KEY_USAGE() y i2d_EXTENDED_KEY_USAGE() aparecieron por primera vez en OpenSSL 0.9.7 y han estado disponibles desde OpenBSD 3.2.
