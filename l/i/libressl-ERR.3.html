ERR(3) Manual de funciones de biblioteca ERR(3)

NOMBRE

ERR — Códigos de error de OpenSSL

SINOPSIS

biblioteca “libcrypto”
#include <openssl/err.h>

DESCRIPCIÓN

Cuando una llamada a la biblioteca OpenSSL falla, esto generalmente se señala mediante el valor de retorno, y un código de error se almacena en una cola de errores asociada con el hilo actual. La biblioteca ERR proporciona funciones para obtener estos códigos de error y mensajes de error textuales. La página del manual de ERR_get_error(3) describe cómo acceder a los códigos de error.

Los códigos de error contienen información sobre dónde ocurrió el error y qué salió mal. ERR_GET_LIB(3) describe cómo extraer esta información. Un método para obtener mensajes de error legibles se describe en ERR_error_string(3).

ERR_clear_error(3) se puede usar para vaciar la cola de errores.

Tenga en cuenta que ERR_remove_state(3) debe usarse para evitar fugas de memoria cuando los hilos terminan.

AÑADIR NUEVOS CÓDIGOS DE ERROR A OPENSSL

Consulte ERR_put_error(3) si desea registrar códigos de error en el sistema de códigos de error de OpenSSL desde dentro de su aplicación.

El resto de esta sección solo es de interés si desea agregar nuevos códigos de error a OpenSSL o agregar códigos de error de bibliotecas externas.

Cuando esté utilizando nuevas funciones o códigos de razón, ejecute make errors. Las definiciones #define necesarias se agregarán automáticamente al archivo de encabezado de la sub-biblioteca.

Añadir nuevas bibliotecas

Al agregar una nueva sub-biblioteca a OpenSSL, asígnele un número de biblioteca ERR_LIB_XXX, defina una macro XXXerr() (tanto en <openssl/err.h>), agregue su nombre a ERR_str_libraries[] (en /usr/src/lib/libcrypto/err/err.c), y agregue ERR_load_XXX_strings() a la función ERR_load_crypto_strings() (en /usr/src/lib/libcrypto/err/err_all.c). Finalmente, agregue xxx_err.c al Makefile.

USO DE CÓDIGOS DE ERROR EN BIBLIOTECAS EXTERNAS

También es posible utilizar el esquema de códigos de error de OpenSSL en bibliotecas externas.

DETALLES INTERNOS

Las colas de errores se almacenan en una tabla hash con una entrada ERR_STATE por cada PID. ERR_get_state() devuelve la ERR_STATE del hilo actual. Una ERR_STATE puede contener hasta ERR_NUM_ERRORS códigos de error. Cuando se agregan más códigos de error, los antiguos se sobrescriben, asumiendo que los errores más recientes son los más importantes.

Las cadenas de error también se almacenan en una tabla hash.
