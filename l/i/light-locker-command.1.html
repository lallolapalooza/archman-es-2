NOMBRE

light-locker-command - controla light-locker

SINOPSIS

light-locker-command [OPCIÓN...]

DESCRIPCIÓN

light-locker-command es una herramienta para controlar una instancia ya en ejecución de light-locker. Esto se hace a través de LightDM, que no garantiza que light-locker esté en ejecución.

OPCIONES

-q, --query
Consulta el estado del bloqueador.
-t, --time
Consulta el tiempo que el bloqueador ha estado activo.
-l, --lock
Indica al proceso bloqueador en ejecución que bloquee la pantalla inmediatamente.
-a, --activate
Activa el salvapantallas (oscurece la pantalla).
-d, --deactivate
Si el salvapantallas está activo, desactívalo (desoscurece la pantalla).
-p, --poke
Pulsa el bloqueador en ejecución para simular actividad del usuario.
-i, --inhibit
Inhibe la activación del salvapantallas. Termina el proceso light-locker-command para finalizar la inhibición.
-n, --application-name
La aplicación que llama y que está inhibiendo el salvapantallas.
-r, --reason
La razón para inhibir el salvapantallas.
-V, --version
Versión de esta aplicación.
