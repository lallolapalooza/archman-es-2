DESCRIPCION

Estas funciones decodifican y codifican claves privadas y públicas RSA. Para obtener detalles sobre la semántica, ejemplos, advertencias y errores, consulte ASN1_item_d2i(3).

d2i_RSAPublicKey() y i2d_RSAPublicKey() decodifican y codifican una estructura RSAPublicKey PKCS#1 definida en el apéndice A.1.1 de RFC 8017. d2i_RSAPublicKey_bio(), d2i_RSAPublicKey_fp(), i2d_RSAPublicKey_bio() y i2d_RSAPublicKey_fp() son similares excepto que decodifican o codifican usando un puntero BIO o FILE.

d2i_RSAPrivateKey() y i2d_RSAPrivateKey() decodifican y codifican una estructura RSAPrivateKey PKCS#1 definida en el apéndice A.1.2 de RFC 8017. La estructura RSA pasada a las funciones de codificación de clave privada debe tener todos los componentes de clave privada PKCS#1 presentes. Los datos codificados por las funciones de clave privada no están cifrados y, por lo tanto, no ofrecen seguridad de clave privada. d2i_RSAPrivateKey_bio(), d2i_RSAPrivateKey_fp(), i2d_RSAPrivateKey_bio() y i2d_RSAPrivateKey_fp() son similares excepto que decodifican o codifican usando un puntero BIO o FILE.

d2i_Netscape_RSA() y i2d_Netscape_RSA() decodifican y codifican una clave privada RSA en formato NET. Estas funciones están presentes para proporcionar compatibilidad con cierto software muy antiguo. El formato NET tiene algunas debilidades de seguridad graves y debe evitarse si es posible.

d2i_RSA_PSS_PARAMS() y i2d_RSA_PSS_PARAMS() decodifican y codifican una estructura RSASSA-PSS-params PKCS#1 definida en el apéndice A.2.3 de RFC 8017 y documentada en RSA_PSS_PARAMS_new(3).

d2i_RSA_PUBKEY() y i2d_RSA_PUBKEY() decodifican y codifican una clave pública RSA

DESCRIPTION

d2i_RSAPublicKey() and i2d_RSAPublicKey() decode and encode an ASN.1 RSA public key structure. The RSA public key is defined as:

RSAPublicKey ::= SEQUENCE {
        version           Version,
        modulus           MPRINT,
        publicExponent    MPRINT
}

where Version is either 0 or 1, and MPRINT is an RSA modulus or public exponent, respectively.

d2i_RSAPrivateKey() and i2d_RSAPrivateKey() decode and encode an ASN.1 RSA private key structure.

d2i_Netscape_RSA() and i2d_Netscape_RSA() are similar to d2i_RSAPublicKey() and i2d_RSAPublicKey() respectively, but they handle the older Netscape RSA key format.

d2i_RSA_PUBKEY() and i2d_RSA_PUBKEY() decode and encode an RSA public key that is wrapped in a SubjectPublicKeyInfo structure defined in RFC 5280 section 4.1 and documented in X509_PUBKEY_new(3). d2i_RSA_PUBKEY_bio(), d2i_RSA_PUBKEY_fp(), i2d_RSA_PUBKEY_bio(), and i2d_RSA_PUBKEY_fp() are similar except that they decode or encode using a BIO or FILE pointer.

RETURN VALUES

d2i_RSAPublicKey(), d2i_RSAPublicKey_bio(), d2i_RSAPublicKey_fp(), d2i_RSAPrivateKey(), d2i_RSAPrivateKey_bio(), d2i_RSAPrivateKey_fp(), d2i_Netscape_RSA(), d2i_RSA_PUBKEY(), d2i_RSA_PUBKEY_bio(), and d2i_RSA_PUBKEY_fp() return a valid RSA object or NULL if an error occurs.

d2i_RSA_PSS_PARAMS() returns a valid RSA_PSS_PARAMS object or NULL if an error occurs.

i2d_RSAPublicKey(), i2d_RSAPrivateKey(), i2d_Netscape_RSA(), i2d_RSA_PSS_PARAMS(), and i2d_RSA_PUBKEY() return the number of bytes successfully encoded or a negative value if an error occurs.

i2d_RSAPublicKey_bio(), i2d_RSAPublicKey_fp(), i2d_RSAPrivateKey_bio(), i2d_RSAPrivateKey_fp(), i2d_RSA_PUBKEY_bio(), and i2d_RSA_PUBKEY_fp() return 1 for success or 0 if an error occurs.

d2i_RSA_PSS_PARAMS() and i2d_RSA_PSS_PARAMS() first appeared in OpenSSL 1.0.1 and have been available since OpenBSD 5.3.
