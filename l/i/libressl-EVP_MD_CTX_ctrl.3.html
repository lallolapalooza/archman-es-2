libressl-EVP_MD_CTX_ctrl(3)

Paquete: libressl

EVP_MD_CTX_CTRL(3) Manual de funciones de la biblioteca EVP_MD_CTX_CTRL(3)

NOMBRE

EVP_MD_CTX_ctrl, EVP_MD_CTX_set_flags, EVP_MD_CTX_clear_flags, EVP_MD_CTX_test_flags, EVP_MD_CTX_pkey_ctx, EVP_MD_CTX_set_pkey_ctx, EVP_MD_CTX_md_data — configurar contextos de resumen de mensajes EVP

SINOPSIS

biblioteca “libcrypto”
#include <openssl/evp.h>

int
EVP_MD_CTX_ctrl(EVP_MD_CTX *ctx, int command, int p1, void* p2);

void
EVP_MD_CTX_set_flags(EVP_MD_CTX *ctx, int flags);

void
EVP_MD_CTX_clear_flags(EVP_MD_CTX *ctx, int flags);

int
EVP_MD_CTX_test_flags(const EVP_MD_CTX *ctx, int flags);

EVP_PKEY_CTX *
EVP_MD_CTX_pkey_ctx(const EVP_MD_CTX *ctx);

void
EVP_MD_CTX_set_pkey_ctx(EVP_MD_CTX *ctx, EVP_PKEY_CTX *pctx);

void *
EVP_MD_CTX_md_data(const EVP_MD_CTX *ctx);

DESCRIPCIÓN

EVP_MD_CTX_ctrl() realiza el comando de control específico del resumen con los argumentos específicos del comando p1 y p2 en ctx, el cual ya debe estar configurado con EVP_DigestInit_ex(3) antes de llamar a esta función. Pueden aplicarse otras restricciones dependiendo del comando de control y la implementación del resumen.

Si el comando es EVP_MD_CTRL_MICALG, p1 se ignora y p2 es un argumento de salida del tipo char **p2. Se asigna una cadena que especifica el algoritmo de resumen de integridad de mensajes (MICALG) y se devuelve un puntero a esta cadena en *p2. Es responsabilidad del llamador free(3) *p2 cuando ya no sea necesario. Este comando es utilizado por SMIME_write_CMS(3) y SMIME_write_PKCS7(3) al crear mensajes multipart/signed de S/MIME según lo especificado en RFC 3851.

EVP_MD_CTX_set_flags() establece y EVP_MD_CTX_clear_flags() borra todos los bits de bandera en ctx que estén establecidos en el argumento flags. EVP_MD_CTX_test_flags() prueba cuáles de los bits de bandera que están establecidos en el argumento flags también están establecidos en ctx. Los bits de bandera posibles son:

EVP_MD_CTX_FLAG_NO_INIT
Instruye a EVP_DigestInit_ex(3) y a las funciones que la llaman a no inicializar los datos internos que son específicos del método de resumen y su implementación.
EVP_MD_CTX_FLAG_ONESHOT
Instruye al resumen para que optimice solo para una actualización, si es posible. Para algoritmos de resumen integrados en la biblioteca, esta bandera generalmente no tiene efecto.

EVP_MD_CTX_pkey_ctx() devuelve el EVP_PKEY_CTX asignado a ctx. El puntero devuelto no debe ser liberado por el llamador.

EVP_MD_CTX_set_pkey_ctx() asigna pctx a ctx. Esto se utiliza normalmente para proporcionar un EVP_PKEY_CTX personalizado a EVP_DigestSignInit(3) o EVP_DigestVerifyInit(3). El llamador conserva la propiedad de pctx pasado a esta función y es responsable de liberarlo cuando ya no sea necesario.

Si ctx ya contiene un EVP_PKEY_CTX cuando se llama a esta función, ese EVP_PKEY_CTX antiguo se libera si se creó internamente, pero si también se instaló con EVP_MD_CTX_set_pkey_ctx(), el puntero al EVP_PKEY_CTX antiguo simplemente se reemplaza por el nuevo puntero y la propiedad del antiguo EVP_PKEY_CTX permanece con el llamador anterior.

Pasar un puntero NULL para el argumento pctx también está permitido. En ese caso, cualquier EVP_PKEY_CTX ya asignado a ctx se disocia de él como se describe anteriormente, pero no se asigna ningún EVP_PKEY_CTX nuevo.

EVP_MD_CTX_md_data() devuelve los datos privados del método de resumen de ctx. El espacio se asigna con un tamaño determinado en tiempo de compilación. El tamaño no se expone a través de una API.

VALORES DE RETORNO

EVP_MD_CTX_ctrl() devuelve 1 para éxito o 0 para fallo.

EVP_MD_CTX_test_flags() devuelve el OR a nivel de bits del argumento flags y las banderas establecidas en ctx.

EVP_MD_CTX_pkey_ctx() y EVP_MD_CTX_md_data() devuelven punteros al almacenamiento propiedad de ctx.

VER TAMBIÉN

evp(3), EVP_DigestInit(3), EVP_MD_nid(3)

HISTORIA

EVP_MD_CTX_set_flags(), EVP_MD_CTX_clear_flags(), y EVP_MD_CTX_test_flags(), aparecieron por primera vez en OpenSSL 0.9.7 y han estado disponibles desde OpenBSD 3.2.

EVP_MD_CTX_ctrl() apareció por primera vez en OpenSSL 1.1.0 y ha estado disponible desde OpenBSD 5.7.

EVP_MD_CTX_pkey_ctx() y EVP_MD_CTX_md_data() aparecieron por primera vez en OpenSSL 1.1.0 y EVP_MD_CTX_set_pkey_ctx() en OpenSSL 1.1.1. Estas funciones han estado disponibles desde OpenBSD 7.1.
