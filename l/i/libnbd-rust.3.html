NOMBRE

libnbd-rust - cómo usar libnbd desde Rust

SINOPSIS

let nbd = libnbd::Handle::new().unwrap();
nbd.connect_uri("nbd://localhost").unwrap();
let size = nbd.get_size().unwrap();
println!("{size} bytes");

En "Cargo.toml" añade:

[dependencies]
libnbd = VERSION | { path = "libnbd/rust" }

DESCRIPCIÓN

Esta página del manual documenta cómo usar libnbd para acceder a servidores NBD (Network Block Device) desde el lenguaje de programación Rust.

Los bindings de Rust funcionan de manera muy similar a los bindings de C, así que deberías empezar leyendo libnbd(3).

También hay una API asíncrona de nivel superior que utiliza Tokio.

Si construyes libnbd desde el código fuente, la documentación principal se encuentra en libnbd/rust/target/doc/libnbd/index.html

Para la interfaz ordinaria, empieza leyendo la documentación de "Handle". Para la API asíncrona de nivel superior, empieza leyendo "AsyncHandle".

"libnbd-sys" es un wrapper de muy bajo nivel alrededor de la API de libnbd que no debería ser usado directamente.
