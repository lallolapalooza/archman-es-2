libressl-CMS_uncompress(3)

Paquete: libressl

Licencias: ISC, custom:OpenSSL

CMS_UNCOMPRESS(3) Manual de funciones de biblioteca CMS_UNCOMPRESS(3)

NOMBRE

CMS_uncompress — descomprime una estructura CMS CompressedData

SINOPSIS

biblioteca “libcrypto”
#include <openssl/cms.h>

int
CMS_uncompress(CMS_ContentInfo *cms, BIO *dcont, BIO *out, unsigned int flags);

DESCRIPCIÓN

CMS_uncompress() extrae y descomprime el contenido de una estructura CMS CompressedData cms y lo escribe en out.

En el raro caso en que el contenido comprimido esté separado, páselo a través de dcont. Para un uso normal, establezca dcont a NULL.

El único algoritmo de compresión compatible actualmente es zlib: si la estructura indica el uso de cualquier otro algoritmo, se devuelve un error. Si el soporte zlib no está compilado, CMS_uncompress() siempre devuelve un error.

Si el bit CMS_TEXT está activado en flags, se eliminan las cabeceras MIME para el tipo text/plain del contenido. Si el contenido no es del tipo text/plain, se devuelve un error.

VALORES DE RETORNO

CMS_uncompress() devuelve 1 en caso de éxito o 0 en caso de fallo. El error puede obtenerse de ERR_get_error(3).

VER TAMBIÉN

CMS_compress(3), CMS_ContentInfo_new(3)

ESTÁNDARES

RFC 3274: Compressed Data Content Type for Cryptographic Message Syntax (CMS)

HISTORIA

CMS_uncompress() apareció por primera vez en OpenSSL 0.9.8h y ha estado disponible desde OpenBSD 6.7.

ERRORES

La falta de procesamiento de una sola pasada y la necesidad de mantener todos los datos en memoria como se menciona en CMS_verify(3) también se aplica a CMS_uncompress().
