Paquete: libssh2

Licencias: BSD

libssh2_channel_get_exit_status(3) libssh2 libssh2_channel_get_exit_status(3)

NOMBRE

libssh2_channel_get_exit_status - obtener el código de salida remoto

SINOPSIS

#include <libssh2.h>
int
libssh2_channel_get_exit_status(LIBSSH2_CHANNEL* channel)

DESCRIPCIÓN

channel - Flujo de canal cerrado para obtener el estado de salida.

Devuelve el código de salida generado por el proceso que se ejecuta en el host remoto al otro extremo del canal nombrado. Tenga en cuenta que el estado de salida puede no estar disponible si el extremo remoto aún no ha establecido su estado como cerrado.

VALOR DE RETORNO

Devuelve 0 en caso de fallo, de lo contrario el *Estado de salida* informado por el host remoto
