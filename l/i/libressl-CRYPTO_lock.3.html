libressl-CRYPTO_lock(3)

Paquete: libressl

Licencias: ISC, custom:OpenSSL

CRYPTO_LOCK(3) Manual de funciones de biblioteca CRYPTO_LOCK(3)

NOMBRE

CRYPTO_lock, CRYPTO_w_lock, CRYPTO_w_unlock, CRYPTO_r_lock, CRYPTO_r_unlock, CRYPTO_add — soporte de hilos

SINOPSIS

biblioteca “libcrypto”
#include <openssl/crypto.h>

void
CRYPTO_lock(int mode, int type, const char *file, int line);

int
CRYPTO_add(int *p, int amount, int type);

#define	CRYPTO_w_lock(type) \
	CRYPTO_lock(CRYPTO_LOCK|CRYPTO_WRITE, type, __FILE__, __LINE__)
#define	CRYPTO_w_unlock(type) \
	CRYPTO_lock(CRYPTO_UNLOCK|CRYPTO_WRITE, type, __FILE__, __LINE__)
#define	CRYPTO_r_lock(type) \
	CRYPTO_lock(CRYPTO_LOCK|CRYPTO_READ, type, __FILE__, __LINE__)
#define	CRYPTO_r_unlock(type) \
	CRYPTO_lock(CRYPTO_UNLOCK|CRYPTO_READ, type, __FILE__, __LINE__)

DESCRIPCIÓN

Estas funciones están obsoletas.

CRYPTO_lock() bloquea o desbloquea un bloqueo de exclusión mutua.

mode es un campo de bits que describe lo que se debe hacer con el bloqueo. Para cada llamada, se debe incluir CRYPTO_LOCK o CRYPTO_UNLOCK. En la implementación de LibreSSL, CRYPTO_READ y CRYPTO_WRITE se ignoran.

type es un número en el rango 0 <= type < CRYPTO_NUM_LOCKS que identifica un bloqueo particular. Actualmente, el valor de CRYPTO_NUM_LOCKS es 41.

Los argumentos file y line se ignoran.

En la implementación de LibreSSL, CRYPTO_lock() es una envoltura alrededor de pthread_mutex_lock(3) y pthread_mutex_unlock(3).

CRYPTO_add() bloquea el número de bloqueo type, añade amount a *p, y desbloquea el bloqueo número type de nuevo.

VALORES DE RETORNO

CRYPTO_add() devuelve el nuevo valor de *p.

VER TAMBIÉN

crypto(3)

HISTORIA

CRYPTO_lock(), CRYPTO_w_lock(), CRYPTO_w_unlock(), CRYPTO_r_lock(), y CRYPTO_r_unlock() aparecieron por primera vez en SSLeay 0.6.0. CRYPTO_add() apareció por primera vez en SSLeay 0.6.2. Estas funciones han estado disponibles desde OpenBSD 2.4.
