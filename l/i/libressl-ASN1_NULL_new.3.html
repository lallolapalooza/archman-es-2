libressl-ASN1_NULL_new(3)

Paquete: libressl

Licencias: ISC, custom:OpenSSL

ASN1_NULL_NEW(3) Manual de funciones de la biblioteca ASN1_NULL_NEW(3)

NOMBRE

ASN1_NULL_new, ASN1_NULL_free — valor NULL de ASN.1

SINOPSIS

biblioteca “libcrypto”
#include <openssl/asn1.h>

ASN1_NULL *
ASN1_NULL_new(void);

void
ASN1_NULL_free(ASN1_NULL *val_in);

DESCRIPCIÓN

ASN1_NULL_new() devuelve un puntero específico e inválido que representa el valor NULL de ASN.1, que es el único valor posible del tipo NULL de ASN.1. Ese puntero es diferente de un puntero NULL. Desreferenciarlo casi con toda seguridad resulta en un error de segmentación. Esta función no asigna memoria y no puede fallar.

ASN1_NULL_free() no tiene ningún efecto. En particular, ignora el argumento val_in y no libera ninguna memoria. En uso normal, los programas de aplicación solo pasan el puntero inválido obtenido de ASN1_NULL_new() a esta función. Pero incluso si se pasa un puntero válido, ese puntero no se vuelve inválido.

El tipo NULL de ASN.1 también está representado por la constante identificadora de tipo V_ASN1_NULL.

VER TAMBIÉN

ASN1_item_new(3), d2i_ASN1_NULL(3)

ESTÁNDARES

Recomendación X.208 de la ITU-T, también conocida como ISO/IEC 8824-1: Especificación de Abstract Syntax Notation One (ASN.1), sección 19: Notación para el tipo nulo

HISTORIA

ASN1_NULL_new() y ASN1_NULL_free() aparecieron por primera vez en OpenSSL 0.9.5 y han estado disponibles desde OpenBSD 2.7.
