LIBNETCFG(1perl) Guía de referencia para programadores de Perl LIBNETCFG(1perl)

NOMBRE

libnetcfg - configurar libnet

DESCRIPCIÓN

La utilidad libnetcfg se puede usar para configurar libnet. A partir de perl 5.8, libnet forma parte de la distribución estándar de Perl, pero libnetcfg puede usarse para cualquier instalación de libnet.

USO

Sin argumentos, libnetcfg muestra la configuración actual.

$ libnetcfg
# antiguo config ./libnet.cfg
daytime_hosts        ntp1.none.such
ftp_int_passive      0
ftp_testhost         ftp.funet.fi
inet_domain          none.such
nntp_hosts           nntp.none.such
ph_hosts             
pop3_hosts           pop.none.such
smtp_hosts           smtp.none.such
snpp_hosts           
test_exist           1
test_hosts           1
time_hosts           ntp.none.such
# libnetcfg -h para ayuda
$

Indica dónde se encontró el archivo de configuración antiguo (si se encontró).

La opción "-h" mostrará un mensaje de uso.

Para cambiar la configuración, necesitará usar las opciones "-c" o "-d".

El nombre por defecto del archivo de configuración antiguo es "libnet.cfg", a menos que se especifique lo contrario usando la opción -i, "-i oldfile", y se busca primero en el directorio actual y luego en tu ruta de módulos.

El nombre por defecto del nuevo archivo de configuración es "libnet.cfg", y por defecto se escribe en el directorio actual, a menos que se especifique lo contrario usando la opción -o, "-o newfile".

VER TAMBIÉN

Net::Config, libnetFAQ

AUTORES

Graham Barr, el script de Configuración original de libnet.

Jarkko Hietaniemi, conversión a libnetcfg para su inclusión en Perl 5.8.
