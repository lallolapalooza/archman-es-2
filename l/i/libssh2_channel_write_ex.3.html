libssh2_channel_write_ex(3)

Paquete: libssh2

Licencias: BSD

libssh2_channel_write_ex(3) libssh2 libssh2_channel_write_ex(3)

NOMBRE

libssh2_channel_write_ex - escribir datos en un stream de canal bloqueante

SINOPSIS

#include <libssh2.h>
ssize_t
libssh2_channel_write_ex(LIBSSH2_CHANNEL *channel,
                         int stream_id, char *buf,
                         size_t buflen);

DESCRIPCIÓN

Escribe datos en un stream de canal. Todos los streams de canal tienen un sub-stream de I/O estándar (stream_id == 0), y pueden tener hasta 2^32 streams de datos extendidos identificados por el stream_id seleccionado. El protocolo SSH2 actualmente define el ID de stream 1 como el sub-stream stderr.

channel - stream de canal activo al que escribir.

stream_id - número de ID del sub-stream (ej. 0 o SSH_EXTENDED_DATA_STDERR)

buf - puntero al buffer a escribir

buflen - tamaño de los datos a escribir

libssh2_channel_write(3) y libssh2_channel_write_stderr(3) son macros de conveniencia para esta función.

libssh2_channel_write_ex(3) utilizará tanto como sea posible del buffer y lo colocará en un único paquete del protocolo SSH. Esto significa que para obtener el máximo rendimiento al enviar archivos grandes, debes intentar pasar siempre al menos 32K de datos a esta función.

VALOR DEVUELTO

Número real de bytes escritos o un valor negativo en caso de fallo. LIBSSH2_ERROR_EAGAIN cuando de otro modo bloquearía. Aunque LIBSSH2_ERROR_EAGAIN es un número negativo, no es realmente un fallo en sí mismo.

ERRORES

LIBSSH2_ERROR_ALLOC - Una llamada interna de asignación de memoria falló.

LIBSSH2_ERROR_SOCKET_SEND - No se pueden enviar datos en el socket.

LIBSSH2_ERROR_CHANNEL_CLOSED - El canal ha sido cerrado.

LIBSSH2_ERROR_CHANNEL_EOF_SENT - Se ha solicitado el cierre del canal.

LIBSSH2_ERROR_BAD_USE - Esto puede devolverse si ignoraste una devolución previa de LIBSSH2_ERROR_EAGAIN y en lugar de enviar el buffer original con el tamaño original, enviaste un nuevo buffer con un tamaño diferente.

cerrado.
