NOMBRE

tst - Funciones de árbol de búsqueda ternario

SINOPSIS

#include <inn/tst.h>
enum tst_constants {
    TST_OK,
    TST_NULL_KEY,
    TST_NULL_DATA,
    TST_DUPLICATE_KEY,
    TST_REPLACE
};
struct tst;
struct tst *tst_init(int node_line_width);
void tst_cleanup(struct tst *tst);
int tst_insert(struct tst *tst, const unsigned char *key,
               void *data, int option, void **exist_ptr);
void *tst_search(struct tst *tst, const unsigned char *key);
void *tst_delete(struct tst *tst, const unsigned char *key);

DESCRIPCIÓN

tst_init asigna memoria para los miembros de struct tst y asigna los primeros node_line_width nodos. tst_init devuelve un puntero NULL si falla alguna parte de la asignación de memoria. En caso de éxito, devuelve un puntero a una struct tst.

El valor de node_line_width debe elegirse con mucho cuidado. Se requiere un nodo por cada carácter en el árbol. Si elige un valor demasiado pequeño, su aplicación pasará demasiado tiempo llamando a malloc(3) y su espacio de nodos estará demasiado disperso. Un valor demasiado grande simplemente desperdicia espacio.

tst_cleanup libera toda la memoria asignada a los nodos, estructuras internas y también tst.

tst_insert inserta la cadena key en el árbol. El comportamiento cuando se inserta una clave duplicada se controla mediante option. Si key ya está en el árbol, se devuelve "TST_DUPLICATE_KEY" y el puntero de datos para la clave existente se coloca en exist_ptr. Si option se establece en "TST_REPLACE", el puntero de datos existente para la clave existente se reemplaza por data. Tenga en cuenta que el puntero de datos antiguo todavía se colocará en exist_ptr.

Si se encuentra una clave duplicada y option no está establecida en "TST_REPLACE", se devuelve "TST_DUPLICATE_KEY". Si key tiene longitud cero, se devuelve "TST_NULL_KEY". Una inserción o reemplazo exitoso devuelve "TST_OK". Un valor de retorno de "TST_ERROR" indica que ocurrió un error de asignación de memoria al intentar aumentar el pool de nodos.

Tenga en cuenta que el argumento data nunca debe ser "NULL". Si lo es, las llamadas a tst_search fallarán para una clave que existe porque el valor de datos se estableció en "NULL", que es lo que devuelve tst_search. Si solo desea un árbol de existencia simple, use el puntero tst como puntero de datos.

tst_search busca la cadena key en el árbol si existe y devuelve el puntero de datos asociado con esa clave.

Si no se encuentra key, se devuelve "NULL"; de lo contrario, se devuelve el puntero de datos asociado con key.

tst_delete elimina la cadena key del árbol si existe y devuelve el puntero de datos asociado con esa clave.

Si no se encuentra key, se devuelve "NULL"; de lo contrario, se devuelve el puntero de datos asociado con key.
