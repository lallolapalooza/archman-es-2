libssh2_sftp_rename_ex(3)

Paquete: libssh2

Licencias: BSD

libssh2_sftp_rename_ex(3) libssh2 libssh2_sftp_rename_ex(3)

NOMBRE

libssh2_sftp_rename_ex - renombrar un archivo SFTP

SINOPSIS

#include <libssh2.h>
#include <libssh2_sftp.h>
int
libssh2_sftp_rename_ex(LIBSSH2_SFTP *sftp,
                       const char *source_filename,
                       unsigned int source_filename_len,
                       const char *dest_filename,
                       unsigned int dest_filename_len,
                       long flags);
int
libssh2_sftp_rename_ex(LIBSSH2_SFTP *sftp,
                       const char *source_filename,
                       const char *dest_filename);

DESCRIPCIÓN

sftp - instancia SFTP devuelta por libssh2_sftp_init(3)

sourcefile - Ruta y nombre de la entrada del sistema de archivos existente

sourcefile_len - Longitud de la ruta y nombre de la entrada del sistema de archivos existente

destfile - Ruta y nombre de la entrada del sistema de archivos de destino

destfile_len - Longitud de la ruta y nombre de la entrada del sistema de archivos de destino

flags - Máscara de bits compuesta por las constantes LIBSSH2_SFTP_RENAME_*.

Renombra un objeto del sistema de archivos en el sistema de archivos remoto. Las semánticas de este comando típicamente incluyen la capacidad de mover un objeto del sistema de archivos entre carpetas y/o montajes del sistema de archivos. Si la bandera LIBSSH2_SFTP_RENAME_OVERWRITE no está establecida y la entrada destfile ya existe, la operación fallará. El uso de las otras dos banderas indica una preferencia (pero no un requisito) de que el extremo remoto realice una operación de renombrado atómico y/o utilice llamadas nativas del sistema cuando sea posible.

VALOR DE RETORNO

Devuelve 0 en caso de éxito o un valor negativo en caso de fallo. Devuelve LIBSSH2_ERROR_EAGAIN cuando de otro modo bloquearía. Aunque LIBSSH2_ERROR_EAGAIN es un número negativo, en realidad no es un fallo en sí mismo.

ERRORES

LIBSSH2_ERROR_ALLOC - Falló una llamada interna de asignación de memoria.

LIBSSH2_ERROR_SOCKET_SEND - No se pudo enviar datos por el socket.

LIBSSH2_ERROR_SOCKET_TIMEOUT -

LIBSSH2_ERROR_SFTP_PROTOCOL - Se recibió una respuesta inválida del protocolo SFTP en el socket, o una operación SFTP causó que el servidor devolviera un código de error.
