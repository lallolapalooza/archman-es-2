Licencias: BSD

libssh2_base64_decode(3) libssh2 libssh2_base64_decode(3)

NOMBRE

libssh2_base64_decode - decodifica una cadena codificada en base64

SINOPSIS

#include <libssh2.h>
int
libssh2_base64_decode(LIBSSH2_SESSION *session, char **dest,
                      unsigned int *dest_len, const char *src,
                      unsigned int src_len);

DESCRIPCIÓN

Esta función se considera OBSOLETA y se eliminará de libssh2 en una versión futura. ¡No la uses!

Decodifica un fragmento base64 y lo almacena en un búfer recién asignado. 'dest_len' se establecerá para contener la longitud del búfer devolución al que apuntará '*dest'.

El búfer devuelto es asignado por esta función, ¡pero no está claro cómo liberar esa memoria!

ERRORES

La memoria a la que apunta *dest es asignada por la función malloc que utiliza libssh2, ¡pero no hay forma de que una aplicación libere estos datos de manera segura y confiable!

VALOR DE RETORNO

0 si tiene éxito, -1 si ocurrió algún error.
