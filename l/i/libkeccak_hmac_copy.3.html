LIBKECCAK_HMAC_COPY(3) Manual de funciones de biblioteca LIBKECCAK_HMAC_COPY(3)

NOMBRE

libkeccak_hmac_copy - Copia un estado de hash HMAC

SINOPSIS

#include <libkeccak.h>
int libkeccak_hmac_copy(struct libkeccak_hmac_state *dest, const struct libkeccak_hmac_state *src);

Enlace con -lkeccak.

DESCRIPCIÓN

La función libkeccak_hmac_copy() inicializa *dest para que sea idéntico a *src. Esto incluye todos los miembros de la estructura struct libkeccak_hmac_state, incluido el estado de la esponja y el búfer de fragmentos de mensaje.

VALORES DEVUELTOS

La función libkeccak_hmac_copy() devuelve 0 al completarse con éxito. En caso de error, se devuelve -1 y se establece errno para describir el error.

ERRORES

La función libkeccak_hmac_copy() puede fallar por cualquier motivo especificado para la función malloc(3).

VER TAMBIÉN

libkeccak_hmac_duplicate(3), libkeccak_hmac_initialise(3)
