libssh2_session_supported_algs(3)

Paquete: libssh2

Licencias: BSD

libssh2_session_supported_algs(3) libssh2 libssh2_session_supported_algs(3)

NOMBRE

libssh2_session_supported_algs - obtener lista de algoritmos soportados

SINOPSIS

#include <libssh2.h>
int
libssh2_session_supported_algs(LIBSSH2_SESSION* session,
                               int method_type,
                               const char*** algs);

DESCRIPCIÓN

session - Una instancia de LIBSSH2_SESSION inicializada (la función usará su puntero a la función de asignación de memoria). method_type - Tipo de método. Ver libssh2_session_method_pref(3). algs - Dirección de un puntero que apuntará a una matriz de algoritmos devueltos.

Obtiene una lista de algoritmos soportados para el method_type dado. El parámetro method_type es equivalente a method_type en libssh2_session_method_pref(3). Si tiene éxito, la función asignará la cantidad adecuada de memoria. Cuando ya no se necesite, debe ser liberada llamando a libssh2_free(3). Cuando esta función no tiene éxito, esto no debe hacerse.

Para obtener una lista de todos los algoritmos de compresión soportados, se debe llamar a libssh2_session_flag(session, LIBSSH2_FLAG_COMPRESS, 1) antes de llamar a esta función, de lo contrario solo se devolverá "none".

Si tiene éxito, la función asignará y rellenará la matriz con los algoritmos soportados (los mismos nombres que se definen en RFC 4253). La matriz no está terminada en NULL.

EJEMPLO

#include "libssh2.h"
const char **algorithms;
int rc, i;
LIBSSH2_SESSION *session;
/* inicializar sesión */
session = libssh2_session_init();
rc = libssh2_session_supported_algs(session,
                                    LIBSSH2_METHOD_CRYPT_CS,
                                    &algorithms);
if(rc > 0) {
    /* la llamada tuvo éxito, haz algo con la lista de algoritmos
       (por ejemplo, listarlos)... */
    printf("Algoritmos simétricos soportados:\n");
    for(i = 0; i < rc; i++)
        printf("\t%s\n", algorithms[i]);
    /* ... y libera la memoria asignada cuando ya no sea necesaria */
    libssh2_free(session, algorithms);
}
else {
    /* la llamada falló, manejo de errores */
}

VALOR DE RETORNO

En caso de éxito, se devolverá el número de algoritmos devueltos (es decir, un número positivo). En caso de fallo, se devolverá un código de error (un número negativo, ver abajo). Nunca se debe devolver 0.

ERRORES

LIBSSH2_ERROR_BAD_USE - Dirección inválida de algs.

LIBSSH2_ERROR_METHOD_NOT_SUPPORTED - Tipo de método desconocido.

LIBSSH2_ERROR_INVAL - Error interno (normalmente no debería ocurrir).

LIBSSH2_ERROR_ALLOC - Falló la asignación de memoria.

DISPONIBILIDAD
