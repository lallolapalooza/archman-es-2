DESCRIPTION

The Media Transfer Protocol (MTP) is a protocol used for transferring media files (images, audio, video) from and to digital portable devices (like digital cameras, mobile phones, mp3 players, etc.) to computers. The protocol is specified by the USB Implementers Forum.

This library provides a relatively high-level interface to the MTP protocol, abstracting away the low-level USB communication and the complex MTP command/response handling.

The following are the main functionalities provided by the library:

Device Discovery and Initialization:
Find MTP devices connected via USB and initialize communication with them.
Object Listing and Retrieval:
Get lists of files and folders on the device, retrieve file metadata, and download files.
Object Upload and Management:
Upload files to the device, create folders, delete, move, and copy objects.
Metadata Handling:
Manage metadata for tracks (songs), playlists, and albums.
Special File Handling:
Handle representative samples and thumbnails.
Error Handling and Debugging:
Provides mechanisms for error reporting and debugging.

Supported Features and Limitations

libmtp aims to support the MTP standard as widely as possible. However, MTP has many optional features and vendor-specific extensions. Compatibility with all devices may not be guaranteed. Some common issues and limitations include:

Device Compatibility:
While libmtp works with a large number of devices, some devices might implement MTP in non-standard ways, leading to compatibility issues.
MTP Variants:
There are variations like MTP/IP (MTP over IP networks) which libmtp might not fully support.
Optional Operations:
Features like direct file editing, certain PTP (Picture Transfer Protocol) operations, or device-specific commands might not be implemented or fully supported.
Concurrency:
The library is generally not thread-safe. Operations on a device should typically be performed sequentially within a single thread.

int LIBMTP_debug = LIBMTP_DEBUG_NONE

Global debug level We use a flag system to enable a part of logs.

The LIBMTP_DEBUG environment variable sets the debug flags for any binary that uses libmtp and calls LIBMTP_Init. The value can be given in decimal (must not start with '0' or it will be interpreted in octal), or in hexadecimal (must start with '0x').

The value '-1' enables all debug flags.

Some of the utilities in examples/ also take a command-line flag '-d' that enables LIBMTP_DEBUG_PTP and LIBMTP_DEBUG_DATA (same as setting LIBMTP_DEBUG=9).

Flags (combine by adding the hex values): 0x00 [0000 0000] : LIBMTP_DEBUG_NONE : no debug (default) 0x01 [0000 0001] : LIBMTP_DEBUG_PTP : PTP debug 0x02 [0000 0010] : LIBMTP_DEBUG_PLST : Playlist debug 0x04 [0000 0100] : LIBMTP_DEBUG_USB : USB debug 0x08 [0000 1000] : LIBMTP_DEBUG_DATA : USB data debug

(Please keep this list in sync with libmtp.h.)
