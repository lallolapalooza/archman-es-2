libressl-OpenSSL_add_all_algorithms(3)

Paquete: libressl

Licencias: ISC, custom:OpenSSL

OPENSSL_ADD_ALL_ALGORITHMS(3) Manual de funciones de biblioteca OPENSSL_ADD_ALL_ALGORITHMS(3)

NOMBRE

OpenSSL_add_all_algorithms, OpenSSL_add_all_ciphers, OpenSSL_add_all_digests, EVP_cleanup, SSLeay_add_all_algorithms — añadir algoritmos a la tabla interna

SINOPSIS

biblioteca “libcrypto”
#include <openssl/evp.h>

void
OpenSSL_add_all_algorithms(void);

void
OpenSSL_add_all_ciphers(void);

void
OpenSSL_add_all_digests(void);

void
EVP_cleanup(void);

void
SSLeay_add_all_algorithms(void);

DESCRIPCIÓN

Estas funciones están obsoletas. Nunca es útil que ningún programa de aplicación las llame explícitamente. La mayoría de ellas no tienen ningún efecto excepto que pueden o no llamar a OPENSSL_init_crypto(3).

La biblioteca contiene tablas internas de algoritmos de resumen y cifrados. Utiliza estas tablas para buscar resúmenes y cifrados a través de EVP_get_digestbyname(3) y EVP_get_cipherbyname(3), respectivamente. En LibreSSL, estas tablas son constantes estáticas y no requieren inicialización.

OpenSSL_add_all_algorithms() solía añadir todos los resúmenes y cifrados a las tablas. Si una aplicación se compila con el símbolo preprocesador OPENSSL_LOAD_CONF definido, también llama a OPENSSL_config(3) con un argumento NULL, cargando el archivo de configuración predeterminado. No se recomienda depender de este comportamiento. Si se desea cargar un archivo de configuración, llame directamente a OPENSSL_config(3) o CONF_modules_load_file(3).

OpenSSL_add_all_digests() solía añadir todos los algoritmos de resumen a la tabla.

OpenSSL_add_all_ciphers() solía añadir todos los algoritmos de cifrado a la tabla.

EVP_cleanup() no tiene ningún efecto; solía eliminar varios tipos de datos suministrados por la aplicación que ya no son compatibles.

SSLeay_add_all_algorithms() es un alias obsoleto para OpenSSL_add_all_algorithms().

OpenSSL_add_all_algorithms() y SSLeay_add_all_algorithms() se implementan como macros.

VER TAMBIÉN

evp(3), EVP_DigestInit(3), EVP_EncryptInit(3), OPENSSL_config(3)

HISTORIA

EVP_cleanup(), SSLeay_add_all_algorithms(), y las funciones precursoras SSLeay_add_all_ciphers() y SSLeay_add_all_digests() aparecieron por primera vez en SSLeay 0.8.0 y han estado disponibles desde OpenBSD 2.4.

OpenSSL_add_all_algorithms(), OpenSSL_add_all_ciphers(), y OpenSSL_add_all_digests() aparecieron por primera vez en OpenSSL 0.9.5 y han estado disponibles desde OpenBSD 2.7.

ERRORES

Aunque las funciones no devuelven códigos de error, es posible que fallen.
