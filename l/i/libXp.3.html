libXp(3Xp) FUNCIONES DE IMPRESIÓN X libXp(3Xp)

NOMBRE

libXp - Biblioteca cliente de impresión X

SINOPSIS

cc [ flag... ] archivo...-lXp [ biblioteca... ]

#include <X11/extensions/Print.h>

DESCRIPCIÓN

libXp proporciona APIs públicas para permitir que las aplicaciones cliente rendericen en dispositivos que no son de visualización.

Cuando una aplicación desea imprimir, establece una conexión de visualización con el servidor de impresión X y solicita ver la lista de impresoras disponibles con una solicitud de XpGetPrinterList(). Una vez que la aplicación ha seleccionado una impresora, crea y establece un contexto de impresión usando XpCreateContext() y XpSetContext().

El Contexto de Impresión representa la encarnación de la impresora seleccionada. Es inicializado por el servidor Xprint en el momento de XpCreateContext() para contener las capacidades predeterminadas de una impresora, así como, la descripción de sus capacidades generales, y para mantener el estado de las configuraciones en la impresora, el estado de la renderización contra la impresora, y la salida renderizada.

El contexto de impresión afecta cómo el controlador DDX genera su lenguaje de descripción de página (PDL) y cómo el PDL se envía a un gestor de cola. El contexto de impresión también puede afectar a las fuentes y otros elementos en la capa dix del Servidor de Impresión X. Los contextos de impresión pueden ser compartidos entre procesos. Las aplicaciones pueden solicitar la ayuda de procesos secundarios para manipular las opciones de impresión en el contexto de Impresión en lugar de asumir la tarea directamente.

Una vez que una aplicación ha establecido opciones dentro del contexto de impresión, realiza llamadas como XpStartJob() para delinear trabajos, documentos y páginas dentro de una secuencia de llamadas X normales.

Un trabajo es una colección de documentos, donde cada documento es a su vez una colección de páginas. Cuando se llama a XpEndJob(), el PDL resultante se envía a un gestor de cola de impresión o puede ser recuperado por la propia aplicación.

El desarrollador básicamente tiene que hacer cambios en la aplicación X para utilizar el Servicio de Impresión X.

Una aplicación X simple complementada con algunas de las rutinas de libXp podría verse así:

#include <X11/Xlib.h>
#include <X11/extensions/Print.h>
main()
{
    Display *pdpy;
    Screen *pscreen;
    Window pwin;
    XPPrinterList plist;
    XPContext pcontext;
    int plistCnt;
    char *attrPool;
#define NPOOLTYPES 5
    XPAttributes poolType[NPOOLTYPES] = {XPJobAttr,XPDocAttr,XPPageAttr,
					 XPPrinterAttr,XPServerAttr};
    int i;
    unsigned short width, height;
    XRectangle rect;
    char *printServerName = ":1";
    char *mylaser = "varos";
    /*
     * conectarse al servidor de impresión X
     */
    pdpy = XOpenDisplay( printServerName );
    /*
     * ver si la impresora "mylaser" está disponible
     */
    plist =  XpGetPrinterList (pdpy, mylaser, &plistCnt );
    /*
     * Inicializar un contexto de impresión que representa "mylaser"
     */
    pcontext = XpCreateContext( pdpy, plist[0].name );
    XpFreePrinterList( plist );
	/*
	 * Posiblemente modificar atributos en el contexto de impresión
	 */
    for(i=0;i < NPOOLTYPES;i++) {
	if(attrPool = XpGetAttributes( pdpy, pcontext, poolType[i] )) {
	    /* manipular atributos */
	    /*
	      XpSetAttributes( pdpy, pcontext, poolType[i],
	                       attrPool, XPAttrMerge );
	    */
	    XFree(attrPool);
	}
    }
    /*
     * Establecer un servidor de impresión, luego iniciar un trabajo de impresión contra él
     */
    XpSetContext( pdpy, pcontext );
    XpStartJob( pdpy, XPSpool );
    /*
     * Generar la primera página
     */
    pscreen = XpGetScreenOfContext( pdpy, pcontext );
    XpGetPageDimensions( pdpy, pcontext, &width, &height,
			 &rect);
    pwin = XCreateSimpleWindow( pdpy, RootWindowOfScreen( pscreen ),
				rect.x, rect.y, rect.width, rect.height, 2,
				BlackPixelOfScreen( pscreen),
				WhitePixelOfScreen( pscreen));
    XpStartPage( pdpy, pwin );
    /* tareas de renderización habituales..... */
    XpEndPage( pdpy );
    XpStartPage( pdpy, pwin );
    /* más renderización.....   */
    XpEndPage( pdpy );
    /*
     * Finalizar el trabajo de impresión - los resultados finales son enviados por el servidor de impresión X
     * al subsistema de gestor de cola.
     */
    XpEndJob( pdpy );
    XpDestroyContext( pdpy, pcontext );
    XCloseDisplay( pdpy );
}
