NOMBRE

libipset - Una biblioteca para usar ipset

SINOPSIS

#include <libipset/ipset.h>

void ipset_load_types(void)

struct ipset * ipset_init(void)
int ipset_parse_argv(struct ipset *ipset, int argc, char *argv[])

int ipset_parse_line(struct ipset *ipset, char *line)

int ipset_parse_stream(struct ipset *ipset, FILE *f)

int ipset_fini(struct ipset *ipset)

int ipset_custom_printf(struct ipset *ipset,
			ipset_custom_errorfn custom_error,
			ipset_standard_errorfn standard_error,
			ipset_print_outfn outfn,
			void *p)

struct ipset_session * ipset_session(struct ipset *ipset)

int ipset_session_full_io(struct ipset_session *session,
			  const char *filename,
			  enum ipset_io_type what)

int ipset_session_normal_io(struct ipset_session *session,
			    const char *filename,
			    enum ipset_io_type what)

FILE * ipset_session_io_stream(struct ipset_session *session,
			       enum ipset_io_type what)

int ipset_session_io_close(struct ipset_session *session,
			   enum ipset_io_type what)

DESCRIPCIÓN

libipset proporciona una interfaz de biblioteca para ipset(8). Las funciones cuyo valor de retorno es un entero devuelven 0 en caso de éxito y un valor negativo en caso de fallo.

ipset_load_types
Carga los tipos de ipset soportados en la biblioteca y los hace disponibles para la interfaz ipset.
ipset_init
Inicializa la interfaz ipset: asigna y inicializa las estructuras internas necesarias, abre el canal netlink. La función devuelve la estructura de interfaz de la biblioteca de tipo struct ipset * o NULL en caso de fallo.
ipset_parse_argv
Analiza la matriz de cadenas argv de longitud argc con la estructura de biblioteca ipset ya inicializada. Si el comando se analiza correctamente, se envía al kernel para su ejecución. En caso de error, se imprime el mensaje de error textual y se devuelve un número negativo.
ipset_parse_line
Analiza la cadena line con la estructura de biblioteca ipset ya inicializada. Se supone que la línea contiene un único comando ipset en formato de restauración. Si el comando se analiza correctamente, se envía al kernel para su ejecución. En caso de error, se imprime el mensaje de error textual y se devuelve un número negativo.
ipset_parse_stream
Analiza el flujo f con la estructura de biblioteca ipset ya inicializada. El flujo puede contener múltiples comandos ipset separados por saltos de línea en formato de restauración. Los comandos se analizan y luego se envían al kernel en lotes para mayor eficiencia. En caso de error, se imprime el mensaje de error textual y se devuelve un número negativo.
ipset_fini
Cierra el canal netlink, cierra los flujos abiertos y libera las estructuras asignadas por la estructura de biblioteca ipset.

Las siguientes funciones hacen posible personalizar la interfaz.

ipset_custom_printf
Establece o restablece las funciones de impresión para la estructura de biblioteca ipset, donde custom_error es la función de impresión de errores personalizada para los errores internos de la biblioteca, standard_error es la función de impresión para los errores relacionados con netlink/kernel y outfn es la función de salida para imprimir el resultado de los comandos list/save. El puntero p permite pasar una estructura arbitraria a las funciones de impresión personalizadas. Si se pasa NULL en lugar de un puntero de función, se establece la función de impresión predeterminada para la tarea dada. Si alguna de las funciones de impresión no es la predeterminada, se ignoran los comandos ipset version, help, interactive.
ipset_session
La función devuelve la estructura de sesión de la estructura de biblioteca ipset, para manipular los parámetros de IO.
ipset_session_full_io
Puede controlar la IO completa, es decir, entrada (restauración) y salida (guardado) por separado mediante la función. El parámetro session es la estructura de sesión de la interfaz de la biblioteca, filename es el nombre del archivo que desea utilizar para entrada o salida y what le dice a la función que desea establecer el archivo de entrada o salida. Si ya hay un archivo abierto para el modo IO dado, se cierra. La función devuelve un error si el modo normal está en uso. Si se pasa NULL en lugar de un nombre de archivo, se cierra el archivo ya abierto y se establece el flujo normal para el modo IO dado (stdin para entrada, stdout para salida). Los archivos de entrada/salida se pueden configurar por separado.
ipset_session_normal_io
Puede controlar la IO normal, que corresponde a la interfaz proporcionada por ipset(8). El parámetro session es la estructura de sesión de la interfaz de la biblioteca, filename es el nombre del archivo que desea utilizar para entrada o salida y what le dice a la función que desea establecer el archivo de entrada o salida. Si ya hay un archivo abierto para entrada/salida, se cierra. La función devuelve un error si el modo completo está en uso. Si se pasa NULL en lugar de un nombre de archivo, se cierra el archivo ya abierto y se establece el flujo normal para el modo IO dado (stdin para entrada, stdout para salida). Los archivos de entrada/salida no se pueden configurar por separado.
ipset_session_io_stream
La función devuelve el flujo establecido para la session donde what le dice a la función que desea obtener el flujo de entrada o salida.
ipset_session_io_close
La función cierra el flujo para la session donde what le dice a la función que desea cerrar el flujo de entrada o salida. Después de cerrar, se establecen los flujos estándar: stdin para entrada, stdout para salida.
