libssh2_userauth_publickey_frommemory(3)

Paquete: libssh2

Licencias: BSD

libssh2_userauth_publickey_frommemory(3) libssh2 libssh2_userauth_publickey_frommemory(3)

NOMBRE

libssh2_userauth_publickey_frommemory - autentica una sesión con una clave pública, leída desde memoria

SINOPSIS

#include <libssh2.h>
int
libssh2_userauth_publickey_frommemory(LIBSSH2_SESSION *session,
                                      const char *username,
                                      size_t username_len,
                                      const char *publickeydata,
                                      size_t publickeydata_len,
                                      const char *privatekeydata,
                                      size_t privatekeydata_len,
                                      const char *passphrase);

DESCRIPCIÓN

session - Instancia de sesión como la devuelta por libssh2_session_init_ex(3)

username - Nombre de usuario remoto a utilizar para la autenticación.

username_len - Longitud del nombre de usuario.

publickeydata - Buffer que contiene el contenido de un archivo de clave pública.

publickeydata_len - Longitud de los datos de la clave pública.

privatekeydata - Buffer que contiene el contenido de un archivo de clave privada.

privatekeydata_len - Longitud de los datos de la clave privada.

passphrase - Frase de contraseña a utilizar al decodificar el archivo de clave privada.

Intenta la autenticación con clave pública utilizando un archivo de clave pública o un archivo de clave privada codificado en PEM almacenado en memoria. Al proporcionar una clave privada, la clave pública se extrae automáticamente de ella. Al proporcionar ambas, la clave pública pasada tiene prioridad.

VALOR DE RETORNO

Retorna 0 en caso de éxito o un valor negativo en caso de fallo. Devuelve LIBSSH2_ERROR_EAGAIN cuando de otro modo bloquearía. Aunque LIBSSH2_ERROR_EAGAIN es un número negativo, no es realmente un fallo en sí mismo.

ERRORES

LIBSSH2_ERROR_ALLOC - Falló una llamada interna de asignación de memoria.

LIBSSH2_ERROR_SOCKET_SEND - No se pudieron enviar datos por el socket.

LIBSSH2_ERROR_SOCKET_TIMEOUT -

LIBSSH2_ERROR_PUBLICKEY_UNVERIFIED - La combinación de nombre de usuario/clave pública no era válida.

LIBSSH2_ERROR_AUTHENTICATION_FAILED - La autenticación utilizando la clave pública proporcionada no fue aceptada.

DISPONIBILIDAD

libssh2_userauth_publickey_frommemory se añadió en libssh2 1.6.0. Soportado con los backends criptográficos OpenSSL, WinCNG, mbedTLS, OS/400.

VER TAMBIÉN
