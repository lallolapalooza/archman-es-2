NOMBRE

libfreeipmi - Biblioteca FreeIPMI

Introducción

Libfreeipmi es la biblioteca principal en la que se basan la mayoría de las herramientas de FreeIPMI. Las siguientes secciones describen las subsecciones de la biblioteca.

api
La API de nivel más alto proporcionada por libfreeipmi. Abstrae los detalles de los protocolos inband y outofband del usuario. También proporciona códigos de error útiles para que el usuario interprete fácilmente los problemas de IPMI. La 'api' es utilizada por la mayoría de las herramientas y bibliotecas de FreeIPMI, como bmc-info(8), ipmi-sensors(8), y libipmimonitoring(3).
cmds
Proporciona plantillas fiid y funciones 'fill' para comandos IPMI. También proporciona macros que definen parámetros comunes para comandos IPMI. Los cmds son utilizados por la mayoría de las otras partes de libfreeipmi, incluyendo la subsección 'api' y herramientas como ipmipower(8) y ipmiconsole(8).
debug
Proporciona varias funciones de utilidad para volcado de paquetes/registros. Utilizado por la subsección 'api' y por herramientas como ipmipower(8) y ipmiconsole(8).
driver
Proporciona APIs para la comunicación IPMI inband. Los drivers actualmente soportados son KCS, SSIF, OpenIPMI y SUNBMC. La subsección 'driver' es usada por herramientas como bmc-watchdog(8) y la subsección 'api'.
fiid
La "Definición de Interfaz FreeIPMI" (FreeIPMI Interface Definition) proporciona una API utilizada para la construcción/deconstrucción de paquetes en libfreeipmi. La API funciona con plantillas fiid, que luego se utilizan para crear objetos fiid. Las plantillas fiid se utilizan para describir paquetes a través de una asignación de nombre de cadena a campo de bits. La API permite a los usuarios leer/escribir campos en un objeto utilizando la asignación de nombre de cadena a campo de bits. La serialización, empaquetado, endianidad y otros problemas de red se manejan dentro de 'fiid'. Los objetos fiid se utilizan en toda libfreeipmi, incluyendo la subsección 'api', la subsección 'cmds', y varias herramientas.
fru-parse
Proporciona una API para analizar registros de Unidad Reemplazable en Campo (FRU - Field Replaceable Unit). Utilizado por herramientas como ipmi-fru(8).
interface
Proporciona funciones de 'ensamblaje' y 'desensamblaje' para construir paquetes para protocolos inband o outofband individuales. También proporciona todas las plantillas fiid, funciones 'fill' y otras funciones de utilidad necesarias para comunicarse en una interfaz IPMI. Utilizado por la subsección 'api' y herramientas como ipmipower(8) y ipmiconsole(8).
interpret
Proporciona una API para interpretar eventos de sensores mapeándolos a estados Nominal, Advertencia o Crítico. Utilizado por herramientas y bibliotecas de FreeIPMI como ipmi-sensors(8) y libipmimonitoring(3).
locate
Proporciona una API para sondear varios estándares para encontrar valores predeterminados para la comunicación IPMI inband. Utilizado por la subsección 'api' y la herramienta ipmi-locate(8).
record-format
Proporciona macros, plantillas fiid e información sobre registros utilizados en IPMI. Utilizado por la subsección 'sdr-cache' y herramientas como ipmi-sensors(8).
sdr-cache
Proporciona una API para crear, almacenar en caché, leer y analizar un repositorio de datos de sensores (SDR - Sensor Data Repository). Utilizado por herramientas como ipmi-fru(8) y ipmi-sensors(8).
sdr-parse
Proporciona una API para analizar registros SDR. Utilizado por herramientas como ipmi-fru(8) y ipmi-sensors(8)
sel-parse
Proporciona una API para leer y analizar entradas del Registro de Eventos del Sistema (SEL - System Event Log). Utilizado por herramientas como ipmi-sel(8).
sensor-read
Proporciona una API para leer un sensor. Utilizado por herramientas como ipmi-sensors(8).
spec
Proporciona macros y arreglos para varias otras definiciones y tablas en IPMI. Utilizado por herramientas como ipmi-sensors(8).
util
Proporciona varias funciones de utilidad para el cálculo de claves, lecturas de sensores, etc. Utilizado por la mayor parte del resto de FreeIPMI.
