LIBQUVI-SCRIPTS(7) Manual de libquvi-scripts LIBQUVI-SCRIPTS(7)

NOMBRE

libquvi-scripts - Resumen de los scripts de la biblioteca

DESCRIPCIÓN

libquvi-scripts contiene los scripts de Lua para libquvi que utiliza para analizar las diferentes propiedades, como las propiedades de los medios.

TIPOS

Scripts comunes

Los scripts comunes son módulos que pueden ser cargados desde otros scripts, por ejemplo, los quvi-modules(7).

Estos scripts se instalan típicamente en

$prefix/share/libquvi-scripts/$major_ver.$minor_ver/common/

Scripts de medios

Los scripts de medios son responsables de analizar las propiedades de los medios, por ejemplo, las URL de los flujos de medios. Normalmente hay un script de medios para cada sitio web soportado.

Estos scripts se instalan típicamente en

$prefix/share/libquvi-scripts/$major_ver.$minor_ver/media/

Scripts de listas de reproducción

Los scripts de listas de reproducción son responsables de analizar las propiedades de las listas de reproducción. Normalmente hay un script de lista de reproducción para cada sitio web soportado.

Estos scripts se instalan típicamente en

$prefix/share/libquvi-scripts/$major_ver.$minor_ver/playlist/

Scripts de escaneo

Los scripts de escaneo se utilizan para escanear una URL en busca de URL de medios incrustados.

Estos scripts se instalan típicamente en

$prefix/share/libquvi-scripts/$major_ver.$minor_ver/scan/

Scripts de subtítulos

Los scripts de subtítulos son responsables de recuperar los datos de subtítulos para los medios, así como de exportar los datos a otro formato, por ejemplo, SubRip.

Estos scripts se instalan típicamente en

$prefix/share/libquvi-scripts/$major_ver.$minor_ver/subtitle/ $prefix/share/libquvi-scripts/$major_ver.$minor_ver/subtitle/export/

Scripts utilitarios

Los scripts utilitarios son utilizados por libquvi para realizar tareas varias, como analizar la extensión del archivo a partir de un tipo de contenido o convertir entidades HTML a caracteres UTF-8.

Estos scripts se instalan típicamente en

$prefix/share/libquvi-scripts/$major_ver.$minor_ver/util/

AMBIENTE

LIBQUVI_SCRIPTS_VERBOSE

Cuando está definido, habilita la salida de cualquier script de libquvi que utilice la instalación de depuración (módulo quvi/debug).
