NOMBRE

libpipewire-module-raop-sink - Salida AirPlay

DESCRIPCIÓN

Crea una nueva salida (sink) para transmitir a un dispositivo Airplay.

Normalmente, esta salida se crea automáticamente con RAOP Discover con los parámetros correctos, pero también es posible crear manualmente una salida RAOP.

NOMBRE DEL MÓDULO

libpipewire-module-raop-sink

OPCIONES DEL MÓDULO

Opciones específicas del comportamiento de este módulo

  • raop.ip: La dirección IP del extremo remoto.
  • raop.port: El puerto del extremo remoto.
  • raop.name: El nombre del extremo remoto.
  • raop.hostname: El nombre de host del extremo remoto.
  • raop.transport: El transporte de datos a usar, uno de "udp" o "tcp". Por defecto es "udp".
  • raop.encryption.type: El tipo de cifrado a usar. Uno de "none", "RSA" o "auth_setup". Por defecto es "none".
  • raop.audio.codec: El códec de audio a usar. Debe ser "PCM". Por defecto es "PCM".
  • raop.password: La contraseña a usar.
  • stream.props = {}: propiedades que se pasarán a la salida del stream

Opciones con comportamiento conocido.

  • remote.name
  • audio.format
  • audio.rate
  • audio.channels
  • audio.position
  • node.name
  • node.description
  • node.group
  • node.latency
  • node.virtual
  • media.class

EJEMPLO DE CONFIGURACIÓN

# ~/.config/pipewire/pipewire.conf.d/my-raop-sink.conf
context.modules = [
{   name = libpipewire-module-raop-sink
    args = {
        # Establecer la dirección remota a la que se conectará
        raop.ip = "127.0.0.1"
        raop.port = 8190
        raop.name = "mi-dispositivo-raop"
        raop.hostname = "Mi Servicio"
        #raop.transport = "udp"
        raop.encryption.type = "RSA"
        #raop.audio.codec = "PCM"
        #raop.password = "****"
        #audio.format = "S16"
        #audio.rate = 44100
        #audio.channels = 2
        #audio.position = [ FL FR ]
        stream.props = {
            # propiedades adicionales de la salida
        }
    }
}
]
