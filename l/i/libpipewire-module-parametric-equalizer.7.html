NOMBRE

libpipewire-module-parametric-equalizer - Ecualizador Paramétrico

DESCRIPCIÓN

El módulo parametric-equalizer carga la configuración del ecualizador paramétrico generada a partir del proyecto AutoEQ o Squiglink.

Ambos proyectos permiten ecualizar auriculares o monitores in-ear a una curva objetivo. Si bien estos generan un archivo para ecualización paramétrica para una curva objetivo dada, este no es un formato que se pueda dar directamente al módulo de cadena de filtros.

Un ejemplo popular de lo anterior es ecualizar a la curva objetivo de Harman o ecualizar un auricular/IEM a otro.

Para AutoEQ, consulte https://github.com/jaakkopasanen/AutoEq. Para SquigLink, consulte https://squig.link/.

La configuración del ecualizador paramétrico generada a partir de AutoEQ o Squiglink se ve así:

Preamp: -6.8 dB
Filter 1: ON PK Fc 21 Hz Gain 6.7 dB Q 1.100
Filter 2: ON PK Fc 85 Hz Gain 6.9 dB Q 3.000
Filter 3: ON PK Fc 110 Hz Gain -2.6 dB Q 2.700
Filter 4: ON PK Fc 210 Hz Gain 5.9 dB Q 2.100
Filter 5: ON PK Fc 710 Hz Gain -1.0 dB Q 0.600
Filter 6: ON PK Fc 1600 Hz Gain 2.3 dB Q 2.700

Fc, Gain y Q especifican la frecuencia, ganancia y factor Q, respectivamente. La cuarta columna puede ser PK, LSC o HSC, especificando un filtro de pico, estantería baja y estantería alta, respectivamente. La mayoría de las veces solo se involucran filtros de pico.

Este módulo analiza una configuración como la anterior y carga el módulo de cadena de filtros con la configuración anterior traducida a argumentos de cadena de filtros.

NOMBRE DEL MÓDULO

libpipewire-module-parametric-equalizer

OPCIONES DEL MÓDULO

Opciones específicas del comportamiento de este módulo

  • equalizer.filepath = <str>: ruta del archivo con EQ paramétrico
  • equalizer.description = <str>: Nombre que aparecerá en
  • audio.channels = <int>: Número de canales de audio, por defecto 2
  • audio.position = <str>: Mapa de canales, por defecto "[FL, FR]"
  • remote.name = <str>: entorno con nombre remoto, por defecto "pipewire-0"
  • capture.props = {}: propiedades pasadas al flujo de entrada, por defecto { media.class = "Audio/Sink", node.name = "effect_input.eq<número de nodos>" }
  • playback.props = {}: propiedades pasadas al flujo de salida, por defecto { node.passive = true, node.name = "effect_output.eq<número de nodos>" }

OPCIONES GENERALES

Opciones con comportamiento bien conocido:

  • audio.channels
  • audio.position
  • remote.name
