LIBTOOL-NEXT-VERSION(1) Comandos de usuario LIBTOOL-NEXT-VERSION(1)

NOMBRE

libtool-next-version - Determina la próxima versión a usar para una biblioteca libtool

SINOPSIS

libtool-next-version [OPCIÓN]... BIBLIOTECA-ANTERIOR BIBLIOTECA-ACTUAL

DESCRIPCIÓN

Determina la próxima versión a usar para una biblioteca libtool.

BIBLIOTECA-ANTERIOR es la biblioteca instalada (en formato .a o .so) de la versión anterior.

BIBLIOTECA-ACTUAL es la biblioteca instalada (en formato .a o .so) del candidato a la versión actual.

OPCIONES

--help
imprimir esta ayuda y salir
--version
imprimir información de versión y salir

Enviar parches e informes de errores a <bug-libtool@gnu.org>.
