libcurl-url(3) Manual de funciones de biblioteca libcurl-url(3)

NOMBRE

libcurl-url - resumen de la interfaz URL

DESCRIPCIÓN

La interfaz URL proporciona funciones para analizar y generar URL.

INCLUIR

Todavía solo incluye <curl/curl.h> en su código.

CREAR

Cree un manejador que contenga información y recursos de URL con curl_url(3):

  CURLU *h = curl_url();

LIMPIAR

Cuando haya terminado, límpielo con curl_url_cleanup(3)

  curl_url_cleanup(h);

DUPLICAR

Cuando necesite una copia de un manejador, simplemente duplíquelo con curl_url_dup(3):

  CURLU *nh = curl_url_dup(h);

ANÁLISIS

Al establecer una URL en el manejador con curl_url_set(3), la URL se analiza y se almacena en el manejador. Si la URL no es sintácticamente correcta, devuelve un error en su lugar.

  rc = curl_url_set(h, CURLUPART_URL,
                    "https://example.com:449/foo/bar?name=moo", 0);

El cero en el cuarto argumento es una máscara de bits para cambiar características específicas.

Si tiene éxito, esto almacena la URL en sus partes individuales dentro del manejador.

REDirección

Cuando un manejador ya contiene información sobre una URL, establecer una URL relativa hace que se "redirija" a esa.

  rc = curl_url_set(h, CURLUPART_URL, "../test?another", 0);

OBTENER URL

El manejador CURLU representa una URL y puede extraerla fácilmente con curl_url_get(3):

  char *url;
  rc = curl_url_get(h, CURLUPART_URL, &url, 0);
  curl_free(url);

El cero en el cuarto argumento es una máscara de bits para cambiar características específicas.

OBTENER PARTES

Cuando se ha analizado una URL o se han establecido partes, puede extraer esas piezas del manejador en cualquier momento.

  rc = curl_url_get(h, CURLUPART_FRAGMENT, &fragment, 0);
  rc = curl_url_get(h, CURLUPART_HOST, &host, 0);
  rc = curl_url_get(h, CURLUPART_PASSWORD, &password, 0);
  rc = curl_url_get(h, CURLUPART_PATH, &path, 0);
  rc = curl_url_get(h, CURLUPART_PORT, &port, 0);
  rc = curl_url_get(h, CURLUPART_QUERY, &query, 0);
  rc = curl_url_get(h, CURLUPART_SCHEME, &scheme, 0);
  rc = curl_url_get(h, CURLUPART_USER, &user, 0);
  rc = curl_url_get(h, CURLUPART_ZONEID, &zoneid, 0);

Las partes extraídas no se decodifican como URL a menos que el usuario también lo solicite con la bandera CURLU_URLDECODE establecida en el argumento de máscara de bits del cuarto argumento.

Recuerde liberar la cadena devuelta con curl_free(3) cuando haya terminado con ella.

ESTABLECER PARTES

Un usuario establece partes individuales de la URL, ya sea después de haber analizado una URL completa o en lugar de analizar una de ellas.

  rc = curl_url_set(urlp, CURLUPART_FRAGMENT, "anchor", 0);
  rc = curl_url_set(urlp, CURLUPART_HOST, "www.example.com", 0);
  rc = curl_url_set(urlp, CURLUPART_PASSWORD, "doe", 0);
  rc = curl_url_set(urlp, CURLUPART_PATH, "/index.html", 0);
  rc = curl_url_set(urlp, CURLUPART_PORT, "443", 0);
  rc = curl_url_set(urlp, CURLUPART_QUERY, "name=john", 0);
  rc = curl_url_set(urlp, CURLUPART_SCHEME, "https", 0);
  rc = curl_url_set(urlp, CURLUPART_USER, "john", 0);
  rc = curl_url_set(urlp, CURLUPART_ZONEID, "eth0", 0);

Las partes establecidas no se codifican como URL a menos que el usuario lo solicite con la bandera CURLU_URLENCODE.

CURLU_APPENDQUERY

Una aplicación puede agregar una cadena al final del lado derecho de la parte de consulta con la bandera CURLU_APPENDQUERY a curl_url_set(3).

Imagine un manejador que contiene la URL "https://example.com/?shoes=2". Una aplicación puede entonces agregar la cadena "hat=1" a la parte de consulta así:

  rc = curl_url_set(urlp, CURLUPART_QUERY, "hat=1", CURLU_APPENDQUERY);

Detecta la falta de un separador ampersand (&) e inyecta uno, y la URL completa del manejador entonces se convierte en "https://example.com/?shoes=2&hat=1".

La cadena agregada, por supuesto, también puede ser codificada como URL al agregarla, y si se solicita codificar como URL, el proceso de codificación omite el carácter '='. Por ejemplo, agregue "candy=N&N" a lo que ya tenemos, y codifíquelo como URL para manejar el ampersand en los datos:

  rc = curl_url_set(urlp, CURLUPART_QUERY, "candy=N&N",
                    CURLU_APPENDQUERY | CURLU_URLENCODE);

Ahora la URL se ve así

  https://example.com/?shoes=2&hat=1&candy=N%26N

NOTAS

Una URL con una dirección IPv6 literal se puede analizar incluso cuando el soporte para IPv6 no está habilitado.
