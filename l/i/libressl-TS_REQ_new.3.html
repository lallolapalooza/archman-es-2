DESCRIPCIÓN

Una autoridad de marca de tiempo es un tercero de confianza que permite a sus clientes probar que datos específicos existieron en un momento particular. Los clientes envían solicitudes de marca de tiempo al servidor de marca de tiempo, que devuelve tokens de marca de tiempo a los clientes.

TS_REQ_new() asigna e inicializa un objeto TS_REQ vacío, representando una estructura ASN.1 TimeStampReq definida en la sección 2.4.1 de RFC 3161. Puede contener un hash de los datos a marcar y alguna información auxiliar opcional. TS_REQ_free() libera req.

TS_RESP_new() asigna e inicializa un objeto TS_RESP vacío, representando una estructura ASN.1 TimeStampResp definida en la sección 2.4.2 de RFC 3161. Puede contener información de estado y un token de marca de tiempo. TS_RESP_free() libera resp.

TS_STATUS_INFO_new() asigna e inicializa un objeto TS_STATUS_INFO vacío, representando una estructura ASN.1 PKIStatusInfo definida en la sección 2.4.2 de RFC 3161. Se utiliza dentro de TS_RESP y describe el resultado de una solicitud de marca de tiempo. TS_STATUS_INFO_free() libera status.

TS_TST_INFO_new() asigna e inicializa un objeto TS_TST_INFO vacío, representando una estructura ASN.1 TSTInfo definida en la sección 2.4.2 de RFC 3161. Es el token de marca de tiempo incluido en un objeto TS_RESP en caso de éxito, y puede contener el hash de los datos copiados de una solicitud, la hora de generación y alguna información auxiliar. TS_TST_INFO_free() libera token.

TS_ACCURACY_new() asigna e inicializa un objeto TS_ACCURACY vacío, representando una estructura ASN.1 Accuracy definida en la sección 2.4.2 de RFC 3161. Puede utilizarse dentro de un objeto TS_TST_INFO e indica el error máximo del tiempo indicado en el token. TS_ACCURACY_free() libera accuracy.

TS_MSG_IMPRINT_new() asigna e inicializa un objeto TS_MSG_IMPRINT vacío, representando una estructura ASN.1 MessageImprint definida en la sección 2.4.1 de RFC 3161. Se utiliza dentro de los objetos TS_REQ y TS_RESP. Especifica un algoritmo de hash y almacena el valor hash de los datos. TS_MSG_IMPRINT_free() libera imprint.

VALORES DE RETORNO

TS_REQ_new(), TS_RESP_new(), TS_STATUS_INFO_new(), TS_TST_INFO_new(), TS_ACCURACY_new(), y TS_MSG_IMPRINT_new() devuelven el nuevo objeto TS_REQ, TS_RESP, TS_STATUS_INFO, TS_TST_INFO, TS_ACCURACY, o TS_MSG_IMPRINT, respectivamente, o NULL si ocurrió un error.

ESTÁNDARES

RFC 3161: Protocolo de Marca de Tiempo de Infraestructura de Clave Pública X.509 de Internet

Tenga en cuenta que RFC 3161 ha sido actualizado por RFC 5816: Actualización de ESSCertIDv2 para RFC 3161. Esa actualización permite el uso de la Versión 2 de Definición de Atributo de Certificado de Firma según RFC 5035, pero la implementación actual solo admite la Versión 1 de Definición de Atributo de Certificado de Firma según RFC 2634, y por lo tanto solo admite RFC 3161, pero no la funcionalidad RFC 5816.

DESCRIPTION

The timestamping protocol defined in RFC 3161 requires a requester to create a timestamp request (TS_REQ) structure which is then sent to a timestamping authority (TSA). The requester is responsible for filling in the appropriate fields of the TS_REQ structure.

TS_REQ_new() allocates and initializes a new TS_REQ structure.

TS_REQ_set_version(), TS_REQ_set_policy(), TS_REQ_add_serial(), TS_REQ_add_attribute(), TS_REQ_add_extension(), TS_REQ_set_nonce(), and TS_REQ_set_ordering() are functions to set the fields of a TS_REQ structure. The version number is typically 0 or 1. The policy OID is the policy under which the timestamp is requested. A serial number may be provided which is returned in the response. Attributes can be added to the request, such as extensions. A nonce may be added to prevent replay attacks. The ordering flag indicates whether the TSA should generate a nonce.

TS_REQ_get_version(), TS_REQ_get_policy(), TS_REQ_get_serial(), TS_REQ_get_attributes(), TS_REQ_get_attr_by_NID(), TS_REQ_get_ext(), TS_REQ_get_ext_by_NID(), TS_REQ_get_ext_by_OBJ(), TS_REQ_get_ext_count(), TS_REQ_get_ext_d2i(), TS_REQ_get_msgimprints(), TS_REQ_get_nonce(), and TS_REQ_get_ordering() are functions to retrieve the fields of a TS_REQ structure.

TS_REQ_to_TBS() converts a TS_REQ structure into a TS_TBC structure suitable for signing. This function is not provided by this library.

TS_REQ_verify_token() verifies a given timestamp token against the request. This function is not provided by this library.

TS_REQ_check_policy() checks if the requested policy is among the accepted policies. This function is not provided by this library.

TS_REQ_print_bio() prints the contents of the TS_REQ structure to the specified BIO.

RETURN VALUES

TS_REQ_new() returns a pointer to the newly allocated TS_REQ structure, or NULL on error.

All other functions return 1 on success, and 0 on error.
