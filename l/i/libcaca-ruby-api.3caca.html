NOMBRE

libcaca-ruby-api - API de Ruby para Libcaca

Clases

Las clases disponibles para libcaca son:

  • Caca::Canvas: funciones que tienen un argumento `caca_canvas_t*` como primer argumento
  • Caca::Dither: funciones que tienen un argumento `caca_dither_t*` como primer argumento
  • Caca::Font: funciones que tienen un argumento `caca_font_t*` como primer argumento (El constructor actualmente solo puede aceptar el nombre de una fuente incorporada)
  • Caca::Display
  • Caca::Event
  • Caca::Event::Key
  • Caca::Event::Key::Press
  • Caca::Event::Key::Release
  • Caca::Event::Mouse
  • Caca::Event::Mouse::Press
  • Caca::Event::Mouse::Release
  • Caca::Event::Mouse::Motion
  • Caca::Event::Resize
  • Caca::Event::Quit

Las funciones de conversión de conjuntos de caracteres aún no están disponibles en el binding.

# Redefinir Event::Key#quit? para que q, Q y Esc sean teclas de salida
module Caca
  class Event::Key
    def quit?
      "qQ^[".split('').member?(@ch.chr)
    end
  end
end
while((e= d.get_event(Caca::Event, -1)) && ! e.quit?)
  p e
  d.refresh
end
