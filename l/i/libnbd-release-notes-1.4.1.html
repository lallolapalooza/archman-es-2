NOMBRE

libnbd-release-notes-1.4 - notas de lanzamiento para libnbd 1.4

DESCRIPCIÓN

Estas son las notas de lanzamiento para la versión estable de libnbd 1.4. Describe los principales cambios desde la versión 1.2.

libnbd 1.4.0 fue lanzado el 25 de agosto de 2020.

Seguridad

No se encontraron problemas de seguridad en esta versión. Si encuentra un problema de seguridad, por favor lea SECURITY en el código fuente (en línea aquí: https://gitlab.com/nbdkit/libnbd/blob/master/SECURITY). Para saber sobre problemas de seguridad anteriores en libnbd, consulte libnbd-security(3).

Nuevas APIs

nbd_set_opt_mode(3)
nbd_get_opt_mode(3)
nbd_aio_is_negotiating(3)
libnbd 1.4 añade un nuevo estado de "negociando" durante el apretón de manos NBD. Por compatibilidad con versiones anteriores, los programas deben solicitar esto antes de iniciar la conexión llamando a nbd_set_opt_mode(3). Puede averiguar si la conexión está en este estado llamando a nbd_aio_is_negotiating(3).

Para una descripción detallada de cómo se puede utilizar este estado adicional para negociar opciones del servidor, consulte "CONTROLLING NEGOTIATION" en libnbd(3).

nbd_aio_opt_abort(3)
nbd_opt_abort(3)
Durante el estado de negociación, abortar la conexión.
nbd_aio_opt_go(3)
nbd_opt_go(3)
Durante el estado de negociación, completar el apretón de manos.
nbd_aio_opt_info(3)
nbd_opt_info(3)
Durante el estado de negociación, solicitar información completa sobre la exportación del servidor.
nbd_aio_opt_list(3)
nbd_opt_list(3)
Durante el estado de negociación, solicitar la lista de exportaciones que proporciona el servidor.
nbd_get_block_size(3)
Devuelve las restricciones de tamaño de bloque mínimo, preferido o máximo para las solicitudes enviadas al servidor.
nbd_get_canonical_export_name(3)
Devuelve el nombre canónico de exportación por defecto del servidor. Esta información puede estar disponible solo si llama a nbd_set_full_info(3) antes de conectar.
nbd_get_export_description(3)
Devuelve la descripción textual opcional de la exportación actual. Esta información puede estar disponible solo si llama a nbd_set_full_info(3) antes de conectar.
nbd_set_full_info(3)
nbd_get_full_info(3)
Habilita información extendida sobre las exportaciones del servidor.

Gracias: Eric Blake por todas las nuevas APIs.

Nuevas características

Ahora hay enlaces disponibles en el lenguaje de programación Go.

FreeBSD y OpenBSD son ahora plataformas totalmente compatibles.

La compleción por tabulación en Bash está disponible para todas las herramientas de línea de comandos.

Documentación

El texto literal en las páginas del manual que se extendía en varias líneas ahora se compone correctamente.

Los enlaces dentro de la documentación se han mejorado y ahora se comprueba su corrección.

Herramientas

La nueva herramienta nbdcopy(1) te permite copiar entre un servidor NBD y un archivo local, o transmitir desde y hacia un servidor NBD.

La nueva herramienta nbdinfo(1) te permite imprimir información extendida sobre las exportaciones de un servidor NBD (Eric Blake).

Pruebas

Los sockets de prueba se crean en /tmp (en lugar del directorio local). Esto evita que la suite de pruebas falle si la ruta del directorio local es más larga que la longitud máxima de ruta del socket de dominio Unix.

Otras mejoras y correcciones de errores

Los mensajes de rastreo se han mejorado: las cadenas largas se truncan, las cadenas con caracteres no imprimibles se escapan y las listas de cadenas se imprimen.

El generador se dividió de un script grande en varios archivos pequeños. Para compilar desde git, ahora se requiere el compilador de bytecode OCaml (ocamlc(1)) en lugar del intérprete (ocaml(1)).

Se admiten nombres de inicio de sesión largos en nbd_get_tls_username(3).

El nombre del manejador en nbdsh(1) ahora se establece en "nbdsh" (en lugar de un nombre generado aleatoriamente).

Compatibilidad con OCaml 4.10.0 y 4.11.0.

El búfer AIO de Python añade un nuevo método "is_zero" que permite a los clientes de Python realizar la esparsificación al copiar.

Compatibilidad con Python 3.9.

Los programas C externos ahora se pueden compilar contra el directorio de compilación de libnbd usando "../libnbd/run ./configure".

Honggfuzz se puede usar como otra opción de fuzzing externo.

Corrección de la compilación con glibc 2.32 que desaprueba "sys_errlist".

Se añadieron o ampliaron muchos ejemplos para demostrar el uso de las nuevas APIs (Eric Blake).

libnbd-release-notes-1.4.1(7)

LIBNDD RELEASE NOTES

1.4.1 2023-09-17

NOMBRE

libnbd-release-notes - notas de la versión de libnbd

DESCRIPCIÓN

Esta es la versión 1.4.1 de libnbd. Contiene las siguientes correcciones y características nuevas.

  • Se ha corregido un error en la copia de seguridad de libnbd que podía devolver datos incorrectos si el dispositivo subyacente se reordenaba. (Error #167)

  • Los mensajes de error de libnbd son ahora más detallados cuando se intenta conectar a un servidor nbd que no responde o que rechaza la conexión. (Error #174)

  • Se ha corregido una fuga de memoria en la rutina de manejo de errores de libnbd. (Error #180)

  • Se ha mejorado el manejo de errores para las operaciones de apertura de archivos de solo lectura. (Error #185)

  • Se ha añadido soporte para la exportación de archivos vacíos como dispositivos de tamaño cero. (Error #191)

  • Se ha actualizado la documentación para reflejar los cambios realizados en esta versión. (Error #195)
