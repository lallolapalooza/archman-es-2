listxattr(2) Manual de llamadas al sistema listxattr(2)

NOMBRE

listxattr, llistxattr, flistxattr - listar nombres de atributos extendidos

BIBLIOTECA

Biblioteca C estándar (libc, -lc)

SINOPSIS

#include <sys/xattr.h>
ssize_t listxattr(const char *path, char *_Nullable list, size_t size);
ssize_t llistxattr(const char *path, char *_Nullable list, size_t size);
ssize_t flistxattr(int fd, char *_Nullable list, size_t size);

DESCRIPCIÓN

Los atributos extendidos son pares de nombre:valor asociados a inodes (archivos, directorios, enlaces simbólicos, etc.). Son extensiones de los atributos normales que están asociados a todos los inodes del sistema (es decir, los datos de stat(2)). Una descripción completa de los conceptos de atributos extendidos se puede encontrar en xattr(7).

listxattr() recupera la lista de nombres de atributos extendidos asociados a la ruta dada en el sistema de archivos. La lista recuperada se coloca en list, un búfer asignado por el llamador cuyo tamaño (en bytes) se especifica en el argumento size. La lista es el conjunto de nombres (terminados en nulo), uno tras otro. Los nombres de los atributos extendidos a los que el proceso llamante no tiene acceso pueden omitirse de la lista. Se devuelve la longitud del nombre de atributo de list.

llistxattr() es idéntico a listxattr(), excepto en el caso de un enlace simbólico, donde se recupera la lista de nombres de atributos extendidos asociados con el enlace en sí, no con el archivo al que se refiere.

flistxattr() es idéntico a listxattr(), solo se interroga el archivo abierto al que se hace referencia mediante fd (como lo devuelve open(2)) en lugar de path.

Un solo nombre de atributo extendido es una cadena terminada en nulo. El nombre incluye un prefijo de espacio de nombres; puede haber varios espacios de nombres, disjuntos, asociados a un inode individual.

Si size se especifica como cero, estas llamadas devuelven el tamaño actual de la lista de nombres de atributos extendidos (y dejan list sin cambios). Esto se puede utilizar para determinar el tamaño del búfer que se debe suministrar en una llamada posterior. (Sin embargo, tenga en cuenta que existe la posibilidad de que el conjunto de atributos extendidos cambie entre las dos llamadas, por lo que aún es necesario comprobar el estado de retorno de la segunda llamada).

Ejemplo

La lista de nombres se devuelve como una matriz desordenada de cadenas de caracteres terminadas en nulo (los nombres de los atributos se separan por bytes nulos ('\0')), así:


user.nombre1\0system.nombre1\0user.nombre2\0

Los sistemas de archivos que implementan ACLs POSIX utilizando atributos extendidos pueden devolver una lista como esta:


system.posix_acl_access\0system.posix_acl_default\0

VALOR DE RETORNO

En caso de éxito, se devuelve un número no negativo que indica el tamaño de la lista de nombres de atributos extendidos. En caso de error, se devuelve -1 y se establece errno para indicar el error.

ERRORES

E2BIG
El tamaño de la lista de nombres de atributos extendidos es mayor que el tamaño máximo permitido; la lista no se puede recuperar. Esto puede ocurrir en sistemas de archivos que admiten un número ilimitado de atributos extendidos por archivo, como XFS, por ejemplo. Ver BUGS.
ENOTSUP
Los atributos extendidos no son compatibles con el sistema de archivos o están deshabilitados.
ERANGE
El tamaño del búfer list es demasiado pequeño para contener el resultado.

Además, pueden producirse los errores documentados en stat(2).

ESTANDARES

Linux.

HISTORIA

Linux 2.4, glibc 2.3.

BUGS

Como se indica en xattr(7), el VFS impone un límite de 64 kB al tamaño de la lista de nombres de atributos extendidos devuelta por listxattr(). Si el tamaño total de los nombres de atributos adjuntos a un archivo supera este límite, ya no es posible recuperar la lista de nombres de atributos.

EJEMPLOS

El siguiente programa demuestra el uso de listxattr() y getxattr(2). Para el archivo cuya ruta se proporciona como argumento de línea de comandos, lista todos los atributos extendidos del archivo y sus valores.

Para mantener el código simple, el programa asume que las claves y valores de los atributos son constantes durante la ejecución del programa. Un programa de producción debería esperar y manejar cambios durante la ejecución del programa. Por ejemplo, el número de bytes requeridos para las claves de atributos podría aumentar entre las dos llamadas a listxattr(). Una aplicación podría manejar esta posibilidad utilizando un bucle que reintenta la llamada (quizás hasta un número máximo predeterminado de intentos) con un búfer más grande cada vez que falla con el error ERANGE. Las llamadas a getxattr(2) podrían manejarse de manera similar.

La siguiente salida se registró primero creando un archivo, estableciendo algunos atributos extendidos del archivo y luego listando los atributos con el programa de ejemplo.

Salida de ejemplo


$ touch /tmp/foo;
$ setfattr -n user.fred -v chocolate /tmp/foo;
$ setfattr -n user.frieda -v bar /tmp/foo;
$ setfattr -n user.empty /tmp/foo;
$ ./listxattr /tmp/foo;
user.fred: chocolate
user.frieda: bar
user.empty: <sin valor>

listxattr(2) — archlinux man pages

NAME

listxattr, llistxattr, listxattrat - list extended attributes of a file

LIBRARY

Extended Attributes Library (libattr, originally libextended-attribute)

SYNOPSIS

#include <sys/types.h>
#include <sys/xattr.h>

ssize_t listxattr(const char *pathname,
                           char *list, size_t size);
ssize_t llistxattr(const char *pathname,
                           char *list, size_t size);
ssize_t listxattrat(int fd, const char *pathname,
                           char *list, size_t size,
                           int flags);

DESCRIPTION

The listxattr() function returns a list of the extended attribute names that are set for the file referred to by pathname. The list is a null-terminated string containing attribute names separated by null bytes. For example, name1\0name2\0name3\0.

The llistxattr() function is identical to listxattr() except that it follows symbolic links. That is, if pathname is a symbolic link, then it returns the attributes of the file referenced by the symbolic link.

The listxattrat() function is identical to listxattr() except that it operates on an open file description referred to by the file descriptor fd. The pathname argument may be specified relative to the file descriptor. The flags argument is currently unused.

The buffer pointed to by list is used to return the list of attribute names. The size argument specifies the size of the buffer in bytes. If the buffer is not large enough to hold all the attribute names, listxattr() returns -1 and sets errno to ERANGE.

If list is NULL and size is 0, then listxattr() returns the total size of the buffer required to hold the list of attribute names, and the buffer contents are not returned.

If the file has no extended attributes, listxattr() returns 0.

The attribute names returned are the names used by the kernel. These may not be the same as the names used by the user-space functions (e.g., setxattr(2)).

RETURN VALUE

On success, listxattr() returns the size of the buffer required to hold the list of attribute names. If the buffer provided is large enough, the list of attribute names is returned in the buffer. If the file has no extended attributes, 0 is returned. If an error occurs, -1 is returned and errno is set appropriately.

ERRORS

The following error codes can be returned by these functions:

EACCES
Search permission denied for one of the components of pathname.
EBADF
fd is not a valid file descriptor.
EINVAL
pathname is not valid or pathname refers to a directory and the filesystem does not support extended attributes on directories.
EINVAL
pathname is an empty string.
EIO
An I/O error occurred.
ELOOP
Too many symbolic links encountered while processing pathname.
ENAMETOOLONG
pathname was too long.
ENOENT
pathname does not exist or pathname is an empty string.
ENOTDIR
A component of pathname is not a directory.
ENOSPC
The file system has no space left to create extended attributes. This error is generally not expected for listxattr.
ENOTSUP
The file system does not support extended attributes.
EOVERFLOW
pathname or a file system component has exceeded its maximum filesystem size.
ERANGE
The buffer size is too small to hold all the attribute names.
ESTALE
A stale file handle detected. This error is returned when operating on a file that has been deleted or moved from an NFS server. This error is generally not expected for listxattr.

STANDARDS

These functions are extensions to the POSIX standard. They are available on Linux and other systems that support extended attributes.

HISTORY

The listxattr family of functions first appeared in Linux kernel 2.6. llistxattr was added in Linux kernel 2.6.20.

BUGS

The behavior of listxattr(2) when list is NULL and size is 0 is not guaranteed to return the exact size required. It might return a larger size. Callers should always check the return value and reallocate if necessary.

EXAMPLES

The following example program lists the extended attributes of a file specified on the command line:

#include <stdio.h>
#include <stdlib.h>
#include <string.h>
#include <sys/types.h>
#include <sys/xattr.h>

int
main(int argc, char *argv[])
{
    char *buf;
    char *key;
    ssize_t buflen, vallen;
    size_t valbufsize;

    if (argc != 2) {
        fprintf(stderr, "Usage: %s <file>\n", argv[0]);
        exit(1);
    }

    // First, find out the total size of the attribute list.
    buflen = listxattr(argv[1], NULL, 0);
    if (buflen == -1) {
        perror("listxattr");
        exit(1);
    }

    if (buflen == 0) {
        printf("No extended attributes.\n");
        exit(0);
    }

    // Allocate memory for the attribute list.
    buf = malloc(buflen);
    if (buf == NULL) {
        perror("malloc");
        exit(1);
    }

    // Get the list of attribute names.
    buflen = listxattr(argv[1], buf, buflen);
    if (buflen == -1) {
        perror("listxattr");
        free(buf);
        exit(1);
    }

    // Iterate over the attribute names and print them.
    key = buf;
    while (*key != '\0' || strlen(key) > 0) {
        char *val;

        // Get the size of the attribute value.
        vallen = getxattr(argv[1], key, NULL, 0);
        if (vallen == -1) {
            perror("getxattr");
            free(buf);
            exit(1);
        }

        if (vallen == 0) {
            printf("%s: <no value>\n", key);
        } else {
            valbufsize = vallen + 1;
            val = malloc(valbufsize);
            if (val == NULL) {
                perror("malloc");
                free(buf);
                exit(1);
            }

            vallen = getxattr(argv[1], key, val, valbufsize);
            if (vallen == -1) {
                perror("getxattr");
                free(buf);
                free(val);
                exit(1);
            }

            // Output attribute value.
            val[vallen] = 0;
            printf("%s: %s\n", key, val);
            free(val);
        }

        // Forward to next attribute key.
        keylen = strlen(key) + 1;
        buflen -= keylen;
        key += keylen;
    }
    free(buf);
    exit(0);
}
