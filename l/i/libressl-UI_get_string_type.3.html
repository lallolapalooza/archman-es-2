#include <openssl/ui.h>

enum UI_string_types {
	UIT_NONE = 0,
	UIT_PROMPT,	/* Preguntar por una cadena */
	UIT_VERIFY,	/* Preguntar por una cadena y verificar */

	UIT_ERROR	/* Enviar un mensaje de error al usuario */

DESCRIPCIÓN

Un UI_STRING se crea internamente y se añade a un objeto UI cada vez que se llama a una de las funciones UI_add_input_string(3), UI_dup_input_string(3), UI_add_verify_string(3), UI_dup_verify_string(3), UI_add_input_boolean(3), UI_dup_input_boolean(3), UI_add_info_string(3), UI_dup_info_string(3), UI_add_error_string(3) o UI_dup_error_string(3). Para un usuario de UI_METHOD, no hay necesidad de saber más. Para un creador de UI_METHOD, es de interés obtener texto de estos objetos UI_STRING, así como añadir resultados a algunos de ellos.

UI_get_string_type() se utiliza para recuperar el tipo del UI_STRING dado.

UI_get_input_flags() se utiliza para recuperar las banderas asociadas con el UI_STRING dado.

UI_get0_output_string() se utiliza para recuperar la cadena real a mostrar (pregunta, información, error, ...).

UI_get0_action_string() se utiliza para recuperar la descripción de la acción asociada con un UI_STRING de tipo UIT_BOOLEAN. Ver UI_add_input_boolean(3).

UI_get0_result_string() se utiliza para recuperar el resultado de una pregunta. Esto solo es útil para cadenas de tipo UIT_PROMPT y UIT_VERIFY.

UI_get0_test_string() se utiliza para recuperar la cadena con la que comparar el resultado de la pregunta. Esto solo es útil para cadenas de tipo UIT_VERIFY.

UI_get_result_minsize() y UI_get_result_maxsize() se utilizan para recuperar el tamaño mínimo y máximo requerido del resultado. Esto solo es útil para cadenas de tipo UIT_PROMPT y UIT_VERIFY.

UI_set_result() se utiliza para establecer el valor del resultado de una pregunta. Para las cadenas de UI de tipo UIT_PROMPT y UIT_VERIFY, esto establece el resultado recuperable con UI_get0_result_string() copiando el contenido de result si su longitud se ajusta a los requisitos de tamaño mínimo y máximo. Para las cadenas de UI de tipo UIT_BOOLEAN, esto establece el primer carácter del resultado recuperable con UI_get0_result_string() al primer carácter de ok_chars proporcionado con UI_add_input_boolean(3) o UI_dup_input_boolean(3) si result coincidió con alguno de ellos, o al primer carácter de cancel_chars si result coincidió con alguno de ellos; de lo contrario, se establece en el carácter NUL. Ver UI_add_input_boolean(3) para más información sobre ok_chars y cancel_chars.

VALORES DE RETORNO

UI_get_string_type() devuelve el tipo de cadena de UI.

UI_get_input_flags() devuelve las banderas de cadena de UI.

UI_get0_output_string() devuelve la cadena de salida de la cadena de UI.

UI_get0_action_string() devuelve la cadena de descripción de la acción de la cadena de UI para cadenas de UI de tipo UIT_BOOLEAN, o NULL para cualquier otro tipo.

UI_get0_result_string() devuelve el búfer de resultado de la cadena de UI para cadenas de UI de tipo UIT_PROMPT y UIT_VERIFY, o NULL para cualquier otro tipo.

UI_get0_test_string() devuelve la cadena de descripción de la acción de la cadena de UI para cadenas de UI de tipo UIT_VERIFY, o NULL para cualquier otro tipo.

UI_get_result_minsize() devuelve el tamaño mínimo de resultado permitido para la cadena de UI para cadenas de tipo UIT_PROMPT y UIT_VERIFY, o -1 para cualquier otro tipo.

UI_get_result_maxsize() devuelve el tamaño mínimo de resultado permitido para la cadena de UI para cadenas de tipo UIT_PROMPT y UIT_VERIFY, o -1 para cualquier otro tipo.

UI_set_result() devuelve 0 en caso de éxito o cuando la cadena de UI es de cualquier tipo distinto de UIT_PROMPT, UIT_VERIFY o UIT_BOOLEAN, o -1 en caso de error.
