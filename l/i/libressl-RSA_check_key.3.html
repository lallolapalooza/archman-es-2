libressl-RSA_check_key(3)

Paquete: libressl

Licencias: ISC, custom:OpenSSL

RSA_CHECK_KEY(3) Manual de funciones de biblioteca RSA_CHECK_KEY(3)

NOMBRE

RSA_check_key — valida claves privadas RSA

SINOPSIS

biblioteca “libcrypto”
#include <openssl/rsa.h>

int
RSA_check_key(RSA *rsa);

DESCRIPCIÓN

Esta función valida claves RSA. Comprueba que rsa->p y rsa->q sean de hecho primos, y que rsa->n satisfaga n = p*q.

También comprueba que rsa->d y rsa->e satisfagan d*e = 1 mod ((p-1)*(q-1)), y que rsa->dmp1, rsa->dmq1, y resa->iqmp estén configurados correctamente o sean NULL.

Esta función no funciona en claves públicas RSA que solo tienen los elementos del módulo y el exponente público poblados. Realiza comprobaciones de integridad en todo el material de la clave RSA, por lo que la estructura de clave RSA debe contener también todos los datos de la clave privada. Por lo tanto, no se puede utilizar con cualquier objeto de clave RSA arbitrario, incluso si de otro modo sería adecuado para operaciones RSA regulares.

VALORES DE RETORNO

RSA_check_key() devuelve 1 si rsa es una clave RSA válida y 0 en caso contrario. Se devuelve -1 si ocurre un error al comprobar la clave.

Si la clave no es válida o ocurrió un error, el código de razón se puede obtener usando ERR_get_error(3).

VER TAMBIÉN

BN_is_prime_ex(3), RSA_get0_key(3), RSA_new(3)

HISTORIAL

RSA_check_key() apareció por primera vez en OpenSSL 0.9.4 y ha estado disponible desde OpenBSD 2.6.

ERRORES

Podría considerarse un método para verificar la clave RSA utilizando funciones API opacas de RSA. En este momento RSA_check_key() simplemente utiliza los elementos de la estructura RSA directamente, eludiendo la tabla RSA_METHOD por completo (y violando completamente la encapsulación y la orientación a objetos en el proceso). La mejor solución probablemente será introducir un manejador check_key() en la tabla de funciones RSA_METHOD para que las implementaciones alternativas también puedan proporcionar sus propios verificadores.
