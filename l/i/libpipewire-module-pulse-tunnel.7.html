NOMBRE

libpipewire-module-pulse-tunnel - Túnel Pulse

DESCRIPCIÓN

El módulo pulse-tunnel proporciona una fuente o sumidero que redirige todo el audio a una conexión PulseAudio remota.

Normalmente se utiliza junto con PulseAudio o module-protocol-pulse en el extremo remoto para aceptar la conexión.

Este módulo se utiliza normalmente junto con module-zeroconf-discover, que cargará automáticamente el túnel con los parámetros correctos basándose en la información de zeroconf.

NOMBRE DEL MÓDULO

libpipewire-module-pulse-tunnel

OPCIONES DEL MÓDULO

  • tunnel.mode: el túnel deseado a crear, debe ser source o sink. (Por defecto: sink)
  • pulse.server.address: la dirección del servidor PulseAudio al que redirigir.
  • pulse.latency: la latencia de extremo a extremo en milisegundos a mantener (Por defecto: 200).
  • reconnect.interval.ms: cuando la conexión remota se rompe, reintenta conectar con este intervalo en milisegundos. Un valor de 0 deshabilita la recuperación y resultará en la descarga del módulo. (Por defecto: 0) (Desde 1.1.0)
  • stream.props: Propiedades adicionales para el flujo local.

OPCIONES GENERALES

Opciones con comportamiento bien conocido.

  • remote.name
  • audio.format
  • audio.rate
  • audio.channels
  • audio.position
  • node.latency
  • node.name
  • node.description
  • node.group
  • node.virtual
  • media.class
  • target.object para especificar el nombre o id de serial del nodo remoto al que vincular

EJEMPLO DE CONFIGURACIÓN DE UN SUMIDERO VIRTUAL

# ~/.config/pipewire/pipewire.conf.d/my-pulse-tunnel.conf
context.modules = [
{   name = libpipewire-module-pulse-tunnel
    args = {
        tunnel.mode = sink
        # Establecer la dirección remota a la que redirigir
        pulse.server.address = "tcp:192.168.1.126"
        #pulse.latency = 200
        #reconnect.interval.ms = 0
        #audio.rate=<frecuencia de muestreo>
        #audio.channels=<número de canales>
        #audio.position=<mapa de canales>
        #target.object=<nombre del objetivo remoto>
        stream.props = {
            # propiedades adicionales del sumidero
        }
    }
}
]
