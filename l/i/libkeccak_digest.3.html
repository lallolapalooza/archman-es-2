libkeccak_digest(3)

Paquete: libkeccak

Licencias: custom:ISC

LIBKECCAK_DIGEST(3) Manual de Funciones de Biblioteca LIBKECCAK_DIGEST(3)

NOMBRE

libkeccak_digest - Completar el hash de un mensaje con borrado

SINOPSIS

#include <libkeccak.h>
int libkeccak_digest(struct libkeccak_state *state, const void *msg, size_t msglen,
                     size_t bits, const char *suffix, void *hashsum);

Enlazar con -lkeccak.

DESCRIPCIÓN

La función libkeccak_digest() absorbe la última parte de (o todo) un mensaje, y devuelve el hash del mensaje completo. La última parte del mensaje se especifica mediante el parámetro msg, y su tamaño en bytes se especifica mediante el parámetro msglen. Si todo el mensaje ha sido procesado previamente mediante llamadas a las funciones libkeccak_update(3), libkeccak_fast_update(3), o libkeccak_zerocopy_update(3) (con el mismo puntero en state), msg y msglen deben establecerse a NULL y 0, respectivamente.

Si el mensaje no consta de un número entero de bytes, el número de bits, módulo 8, en el mensaje debe especificarse en el parámetro bits. msglen solo debe contar el número de bytes completos, es decir, el suelo del número de bits del mensaje dividido por 8.

suffix debe ser una cadena terminada en NUL de caracteres '1' y '0' ASCII, que representan los bits que deben añadirse al mensaje. Si esta cadena está vacía, se puede usar NULL en su lugar. Esto se utiliza para seleccionar el algoritmo de hash. Para Keccak puro, se usa NULL o "". Para los otros algoritmos se usan las constantes LIBKECCAK_SHA3_SUFFIX (para SHA-3), LIBKECCAK_RAWSHAKE_SUFFIX (para RawSHAKE), y LIBKECCAK_SHAKE_SUFFIX (para SHAKE), o el retorno de la función libkeccak_cshake_suffix(3) (para cSHAKE).

El hash del mensaje se almacenará en hashsum, a menos que hashsum sea NULL (lo que aumenta el rendimiento de la llamada). Se escribirán un total de ((state->n + 7) / 8) bytes en el principio de hashsum. Por lo tanto, hashsum necesita al menos un tamaño de asignación de esa cantidad de bytes.

La función libkeccak_digest() puede reasignar el búfer de fragmentos de mensaje del estado. Al hacerlo, intenta hacerlo de la forma más segura posible, en lugar de la más rápida.

VALORES DE RETORNO

La función libkeccak_digest() devuelve 0 si la ejecución es exitosa. En caso de error, se devuelve -1 y se establece errno para describir el error.

ERRORES

La función libkeccak_digest() puede fallar por cualquier razón especificada por la función malloc(3).

EJEMPLO

Este ejemplo calcula el hash Keccak[b = 1024, c = 576, n = 256] de la entrada estándar, y imprime el hash, en formato hexadecimal, en la salida estándar.

struct libkeccak_state state;
struct libkeccak_spec spec;
char binhash[256 / 8];
char hexhash[256 / 8 * 2 + 1];
char chunk[4 << 10];
ssize_t len;
spec.bitrate = 1024;
spec.capacity = 576;
spec.output = 256;
if (libkeccak_state_initialise(&state, &spec) < 0)
	goto fail;
for (;;) {
	len = read(STDIN_FILENO, chunk, sizeof(chunk));
	if ((len < 0) && (errno == EINTR))
		continue;
	if (len < 0)
		goto fail;
	if (len == 0)
		break;
	if (libkeccak_update(&state, chunk, (size_t)len) < 0)
		goto fail;
}
if (libkeccak_digest(&state, NULL, 0, 0, "", binhash) < 0)
	goto fail;
libkeccak_behex_lower(hexhash, binhash, sizeof(binhash));
printf("%s\n", hexhash);
libkeccak_state_destroy(&state);

NOTAS

Para cSHAKE, se debe llamar a libkeccak_cshake_initialise(3), una vez, inmediatamente después de la inicialización del estado; antes de la primera llamada a cualquiera de las funciones libkeccak_fast_update(), libkeccak_zerocopy_update(), libkeccak_update(), y libkeccak_digest().
