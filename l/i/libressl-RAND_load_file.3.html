libressl-RAND_load_file(3)

Paquete: libressl

Licencias: ISC, custom:OpenSSL

RAND_LOAD_FILE(3) Manual de funciones de biblioteca RAND_LOAD_FILE(3)

NOMBRE

RAND_file_name, RAND_load_file, RAND_write_file — archivo de semilla PRNG

SINOPSIS

biblioteca “libcrypto”
#include <openssl/rand.h>

const char *
RAND_file_name(char *buf, size_t num);

int
RAND_load_file(const char *filename, long max_bytes);

int
RAND_write_file(const char *filename);

DESCRIPCIÓN

RAND_file_name() devuelve una ruta predeterminada para el archivo de semilla aleatoria. buf apunta a un búfer de tamaño num en el que almacenar el nombre del archivo. Si num es demasiado pequeño para el nombre de la ruta, se produce un error.

RAND_load_file() utilizado para permitir que el estado del generador de números aleatorios sea controlado por fuentes externas. Se mantiene por compatibilidad de ABI, pero ya no es funcional y no debe utilizarse en programas nuevos.

RAND_write_file() escribe un número de bytes aleatorios (actualmente 1024) en el archivo filename.

VALORES DE RETORNO

RAND_load_file() devuelve max_bytes, o un valor positivo ficticio si max_bytes es -1.

RAND_write_file() devuelve el número de bytes escritos, o un número menor o igual a 1 si se produce un error.

RAND_file_name() devuelve un puntero a buf en caso de éxito o NULL en caso de error.

HISTORIA

RAND_load_file(), RAND_write_file(), y RAND_file_name() aparecieron por primera vez en SSLeay 0.5.1 y han estado disponibles desde OpenBSD 2.4.
