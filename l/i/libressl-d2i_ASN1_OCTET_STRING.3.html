DESCRIPCIÓN

Estas funciones decodifican y codifican varios tipos integrados de ASN.1 que pueden ser representados por objetos ASN1_STRING. Para obtener detalles sobre la semántica, ejemplos, advertencias y errores, consulte ASN1_item_d2i(3).

El formato consta de un byte identificador, uno o más bytes de longitud y uno o más bytes de contenido. Los bytes identificadores y los tipos ASN.1 correspondientes son los siguientes:

Tipo OpenSSL identificador Tipo ASN.1
ASN1_OCTET_STRING 0x04 OCTET STRING
ASN1_BIT_STRING 0x03 BIT STRING
ASN1_INTEGER 0x02 INTEGER
ASN1_ENUMERATED 0x0a ENUMERATED
ASN1_UTF8STRING 0x0c UTF8String
ASN1_IA5STRING 0x16 IA5String
ASN1_UNIVERSALSTRING 0x1c UniversalString
ASN1_BMPSTRING 0x1e BMPString
ASN1_GENERALSTRING 0x1b GeneralString
ASN1_T61STRING 0x14 T61String
ASN1_VISIBLESTRING 0x1a VisibleString
ASN1_PRINTABLESTRING 0x13 PrintableString
ASN1_GENERALIZEDTIME 0x18 GeneralizedTime
ASN1_UTCTIME 0x17 UTCTime

d2i_DIRECTORYSTRING() y i2d_DIRECTORYSTRING() decodifican y codifican una estructura DirectoryString de ASN.1 definida en la sección 4.1.2.4 de RFC 5280 y utilizada para las estructuras EDIPartyName de ASN.1; consulte EDIPARTYNAME_new(3). Al decodificar, acepta cualquiera de los tipos UTF8String, UniversalString, BMPString, T61String o PrintableString. Al codificar, escribe el tipo de cadena de caracteres que se pasa realmente.

d2i_ASN1_PRINTABLE() y i2d_ASN1_PRINTABLE() son variantes no estándar de d2i_DIRECTORYSTRING() y i2d_DIRECTORYSTRING() que también aceptan valores IA5String, NumericString, BIT STRING y SEQUENCE de ASN.1, así como valores de ASN.1 con bytes identificadores desconocidos (0x07, 0x08, 0x09, 0x0b, 0x0d, 0x0e, 0x0f, 0x1d y 0x1f). Aunque el estándar requiere el uso de DirectoryString en los nombres distintivos relativos descritos en X509_NAME_ENTRY_new(3), la biblioteca acepta esta gama más amplia de opciones.

d2i_DISPLAYTEXT() y i2d_DISPLAYTEXT() decodifican y codifican una estructura DisplayText de ASN.1 definida en la sección 4.2.1.4 de RFC 5280 y utilizada para las estructuras UserNotice de ASN.1 en las políticas de certificado; consulte USERNOTICE_new(3). Al decodificar, acepta cualquiera de los tipos UTF8String, IA5String, BMPString o VisibleString. Al codificar, escribe el tipo de cadena de caracteres que se pasa realmente.

d2i_ASN1_TIME() y i2d_ASN1_TIME() decodifican y codifican una estructura Time de ASN.1 definida en la sección 4.1 de RFC 5280 y utilizada para las estructuras Validity de ASN.1 en los certificados; consulte X509_VAL_new(3). También se utilizan para las listas de revocación de certificados; consulte X509_CRL_INFO_new(3). Al decodificar, acepta tanto GeneralizedTime como UTCTime. Al codificar, escribe el tipo de tiempo que se pasa realmente.

Las siguientes constantes describen las etiquetas ASN.1 que son válidas al decodificar con las funciones anteriores. Consulte ASN1_tag2bit(3) para obtener más detalles sobre las constantes B_ASN1_*.

función de decodificación constante de máscara
d2i_DIRECTORYSTRING() B_ASN1_DIRECTORYSTRING
d2i_ASN1_PRINTABLE() B_ASN1_PRINTABLE
d2i_DISPLAYTEXT() B_ASN1_DISPLAYTEXT
d2i_ASN1_TIME() B_ASN1_TIME

d2i_ASN1_UINTEGER() es similar a d2i_ASN1_INTEGER() excepto que ignora el bit de signo en la codificación BER y trata todos los enteros como positivos. Ayuda a procesar la entrada BER producida por software defectuoso que omite añadir un byte de contenido NUL inicial donde sea necesario.

VALORES DE RETORNO

Las funciones de decodificación d2i_*() devuelven un objeto ASN1_STRING o NULL si ocurre un error.

Las funciones de codificación i2d_*() devuelven el número de bytes codificados correctamente o un valor negativo si ocurre un error.

TRADUCCIÓN AL ESPAÑOL

='CAVEATS'>ADVERTENCIAS

Otras implementaciones pueden aceptar o emitir codificaciones DER no válidas de GeneralizedTime y UTCTime. Las aplicaciones portátiles deben usar ASN1_STRING_length() para verificar si un objeto GeneralizedTime o UTCTime dado tiene al menos 15 o 13 bytes, respectivamente.
