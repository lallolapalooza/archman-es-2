LIBDAVIX(3) Manual de funciones de la biblioteca LIBDAVIX(3)

NOMBRE

libdavix - biblioteca compartida para E/S HTTP

DESCRIPCIÓN

libdavix es una biblioteca compartida C++ para E/S remota de alto rendimiento y gestión de recursos con protocolos basados en HTTP.

libdavix tiene como objetivo ser una capa de E/S completa, confiable y de alto rendimiento para sistemas de almacenamiento en la nube, grid y web.
Soporta los protocolos Http (http(s)://), WebDav (dav(s)://) y S3 (s3(s)://).

Consulta la documentación doxygen de libdavix para más detalles.
