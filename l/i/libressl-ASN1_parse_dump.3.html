Paquete: libressl

Licencias: ISC, custom:OpenSSL

ASN1_PARSE_DUMP(3) Manual de funciones de biblioteca ASN1_PARSE_DUMP(3)

NOMBRE

ASN1_parse_dump, ASN1_parse — analiza BER e imprime información sobre él

SINOSIS

biblioteca “libcrypto”
#include <openssl/asn1.h>

int
ASN1_parse_dump(BIO *bio, const unsigned char *ber_in, long length, int indent, int dump);

int
ASN1_parse(BIO *bio, const unsigned char *ber_in, long length, int indent);

DESCRIPCIÓN

ASN1_parse_dump() analiza valores codificados en BER e imprime información sobre ellos en bio. Al inicio de la función, se espera que *ber_in apunte al primer octeto de identificador de un valor codificado. Se inspeccionan como máximo length bytes.

Por cada valor analizado e impreso con éxito, se muestra la siguiente información:

  1. El índice de su primer octeto de identificador relativo a ber_in como un número decimal seguido de dos puntos. Para el primer valor analizado e impreso, esto es "0:".
  2. La profundidad de anidamiento como un entero decimal. Para el primer valor analizado e impreso, esto es "d=0".
  3. La longitud de la cabecera en bytes, incluyendo los octetos de identificador y los octetos de longitud, como un entero decimal. Por ejemplo, para un valor booleano, esto es "hl=2" porque la codificación de un valor booleano contiene un octeto de identificador (0x01) y un octeto de longitud (también 0x01, ya que sigue un octeto de contenido después de la cabecera).
  4. Si el valor está codificado usando la forma definida para los octetos de longitud, el número codificado en los octetos de longitud como un entero decimal. Este es el número de octetos de contenido que siguen. Por ejemplo, para un valor booleano, esto es "l=1". Si el valor está codificado con un octeto de longitud que indica la forma indefinida, en su lugar se imprime "l=inf".
  5. Si el valor es primitivo, se imprime "prim:"; si es construido, "cons:".
  6. El siguiente campo depende de la clase de la etiqueta:
    V_ASN1_PRIVATE
    "priv" seguido del número de etiqueta decimal entre corchetes
    V_ASN1_CONTEXT_SPECIFIC
    "cont" seguido del número de etiqueta decimal entre corchetes
    V_ASN1_APPLICATION
    "appl" seguido del número de etiqueta decimal entre corchetes
    V_ASN1_UNIVERSAL
    Si el número de etiqueta es 30 o menor, se imprime el valor devuelto por ASN1_tag2str(3); de lo contrario, se imprime "<ASN1" seguido del número de etiqueta decimal y un corchete de cierre.

Para valores construidos, los valores contenidos se imprimen recursivamente.

Los valores primitivos se procesan de la siguiente manera:

V_ASN1_BOOLEAN
Su valor entero se imprime como un número decimal.
V_ASN1_INTEGER
Se decodifica con d2i_ASN1_INTEGER(3), se imprime como un número hexadecimal con un número par de dígitos.
V_ASN1_ENUMERATED
Se decodifica con d2i_ASN1_ENUMERATED(3), se imprime como un número hexadecimal con un número par de dígitos.
V_ASN1_OBJECT
Se decodifica con d2i_ASN1_OBJECT(3), se imprime con i2a_ASN1_OBJECT(3).
V_ASN1_OCTET_STRING
Se decodifica con d2i_ASN1_OCTET_STRING(3). Si los datos consisten únicamente en caracteres ASCII imprimibles, saltos de línea, retornos de carro y tabulaciones horizontales, se imprimen como una cadena ASCII.

De lo contrario, el argumento dump decide el formato. Si es cero, se emite un volcado hexadecimal crudo, que consta de dos dígitos hexadecimales por cada byte de datos. Si dump es distinto de cero, se utiliza BIO_dump_indent(3). A menos que dump sea -1, los datos se truncan después de dump bytes.

V_ASN1_PRINTABLESTRING
Se imprime como una cadena ASCII. Lo mismo se aplica a V_ASN1_IA5STRING, V_ASN1_T61STRING, V_ASN1_NUMERICSTRING, V_ASN1_VISIBLESTRING, V_ASN1_UTF8STRING, V_ASN1_UTCTIME, y V_ASN1_GENERALIZEDTIME.
Otras etiquetas
Si el argumento dump es 0, sus datos se ignoran silenciosamente. Si dump es distinto de cero, se utiliza BIO_dump_indent(3). A menos que dump sea -1, los datos se truncan después de dump bytes.

ASN1_parse() es idéntica a ASN1_parse_dump() con 0 pasado como argumento dump.

VALORES DE RETORNO

Estas funciones devuelven 1 en caso de éxito o 0 en caso de fallo.

En particular, imprimen un mensaje de error en bio, abortan el análisis y la impresión, y devuelven 0 cuando el análisis o la decodificación fallan, al encontrar un valor que se extiende más allá de length, o al encontrar un nivel de anidamiento superior a 128. También abortan el análisis y la impresión, y devuelven 0 cuando falla cualquier operación de impresión.

VER TAMBIÉN

ASN1_get_object(3), ASN1_item_d2i(3), ASN1_item_new(3), ASN1_STRING_print(3), ASN1_TYPE_new(3)

ESTÁNDARES

Recomendación ITU-T X.690, también conocida como ISO/IEC 8825-1: Tecnología de la información - Reglas de codificación ASN.1: Especificación de las Reglas de Codificación Básica (BER), Reglas de Codificación Canónica (CER) y Reglas de Codificación Distinguida (DER), sección 8.1: Reglas generales para la codificación

HISTORIAL

ASN1_parse() apareció por primera vez en SSLeay 0.5.1 y ha estado disponible desde OpenBSD 2.4.

ASN1_parse_dump() apareció por primera vez en OpenSSL 0.9.6 y ha estado disponible desde OpenBSD 2.9.

ERRORES

El contenido de los valores etiquetados como V_ASN1_BMPSTRING se ignora silenciosamente y no se imprime nada de él.
