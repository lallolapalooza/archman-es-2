DESCRIPCIÓN

EVP_CIPHER_nid() devuelve el identificador numérico (NID) del cipher. El NID es un valor interno que puede o no tener un Identificador de Objeto ASN.1 correspondiente; vea OBJ_nid2obj(3) para detalles.

EVP_CIPHER_CTX_nid() devuelve el NID del cifrador que ctx está configurado para usar.

EVP_CIPHER_name() convierte el NID del cipher a su nombre corto con OBJ_nid2sn(3).

EVP_CIPHER_type() devuelve el NID asociado con el Identificador de Objeto ASN.1 del cipher, ignorando los parámetros del cifrador. Por ejemplo, EVP_aes_256_cfb1(3), EVP_aes_256_cfb8(3), y EVP_aes_256_cfb128(3) todos devuelven el mismo NID, NID_aes_256_cfb128.

EVP_CIPHER_CTX_type() devuelve el NID asociado con el Identificador de Objeto ASN.1 del cifrador que ctx está configurado para usar.

EVP_CIPHER_block_size() devuelve el tamaño del bloque del cipher en bytes. EVP_CIPHER_CTX_block_size() devuelve el tamaño del bloque del cifrador que ctx está configurado para usar. Los tamaños de bloque están garantizados a ser menores o iguales a la constante EVP_MAX_BLOCK_LENGTH. Actualmente, EVP_CipherInit_ex(3) y las otras funciones documentadas en la misma página del manual solo admiten tamaños de bloque de 1, 8 y 16 bytes.

EVP_CIPHER_flags() devuelve las banderas del cifrador utilizadas por el cipher. El significado de las banderas se describe en la página del manual EVP_CIPHER_meth_set_flags(3).

EVP_CIPHER_CTX_flags() devuelve las banderas del cifrador del cifrador que ctx está configurado para usar. Tenga cuidado de no confundir estas con las banderas del contexto del cifrador, no relacionadas, que pueden inspeccionarse con EVP_CIPHER_CTX_test_flags(3).

EVP_CIPHER_mode() devuelve el modo del cipher, que es el AND lógico de la constante EVP_CIPH_MODE y el valor de retorno de EVP_CIPHER_flags().

EVP_CIPHER_CTX_mode() devuelve el modo del cifrador del cifrador que ctx está configurado para usar.

EVP_CIPHER_name(), EVP_CIPHER_CTX_type(), EVP_CIPHER_mode(), y EVP_CIPHER_CTX_mode() están implementados como macros.

VALORES DE RETORNO

EVP_CIPHER_nid() y EVP_CIPHER_CTX_nid() devuelven un NID.

EVP_CIPHER_name() devuelve un puntero a una cadena que es propiedad de un objeto de biblioteca interno o NULL si el NID no está integrado en la biblioteca ni agregado a la tabla global de objetos por una de las funciones documentadas en la página del manual OBJ_create(3), o si el objeto no contiene un nombre corto.

EVP_CIPHER_type() y EVP_CIPHER_CTX_type() devuelven el NID del Identificador de Objeto del cifrador o NID_undef si no está asociado con un Identificador de Objeto.

EVP_CIPHER_block_size() y EVP_CIPHER_CTX_block_size() devuelven el tamaño del bloque en bytes.

EVP_CIPHER_flags() y EVP_CIPHER_CTX_flags() devuelven uno o más bits de bandera EVP_CIPH_* combinados con OR.

EVP_CIPHER_mode() y EVP_CIPHER_CTX_mode() devuelven una de las constantes EVP_CIPH_ECB_MODE, EVP_CIPH_CBC_MODE, EVP_CIPH_CFB_MODE, EVP_CIPH_OFB_MODE, EVP_CIPH_CTR_MODE, EVP_CIPH_GCM_MODE, EVP_CIPH_CCM_MODE, EVP_CIPH_XTS_MODE, o EVP_CIPH_WRAP_MODE para indicar un cifrador de bloque o EVP_CIPH_STREAM_CIPHER para indicar un cifrador de flujo.

libressl-EVP_CIPHER_nid.3.en

NAME

EVP_CIPHER_nid, EVP_CIPHER_CTX_nid, EVP_CIPHER_flags, EVP_CIPHER_CTX_flags, EVP_CIPHER_mode, EVP_CIPHER_CTX_mode, EVP_CIPHER_name, EVP_CIPHER_CTX_name, EVP_CIPHER_key_length, EVP_CIPHER_CTX_key_length, EVP_CIPHER_iv_length, EVP_CIPHER_CTX_iv_length - query cipher context and type information

SYNOPSIS

#include <openssl/evp.h>

int EVP_CIPHER_nid(const EVP_CIPHER *cipher);
int EVP_CIPHER_CTX_nid(const EVP_CIPHER_CTX *ctx);
unsigned long EVP_CIPHER_flags(const EVP_CIPHER *cipher);
unsigned long EVP_CIPHER_CTX_flags(const EVP_CIPHER_CTX *ctx);
int EVP_CIPHER_mode(const EVP_CIPHER *cipher);
int EVP_CIPHER_CTX_mode(const EVP_CIPHER_CTX *ctx);
const char *EVP_CIPHER_name(const EVP_CIPHER *cipher);
const char *EVP_CIPHER_CTX_name(const EVP_CIPHER_CTX *ctx);
int EVP_CIPHER_key_length(const EVP_CIPHER *cipher);
int EVP_CIPHER_CTX_key_length(const EVP_CIPHER_CTX *ctx);
int EVP_CIPHER_iv_length(const EVP_CIPHER *cipher);
int EVP_CIPHER_CTX_iv_length(const EVP_CIPHER_CTX *ctx);

DESCRIPTION

These functions query information about a cipher or a cipher context.

A cipher context EVP_CIPHER_CTX is an abstract structure that contains all the information about a cipher operation. It is created using functions like EVP_CIPHER_CTX_new(3), and is associated with a specific cipher by calling functions like EVP_EncryptInit_ex(3) or EVP_DecryptInit_ex(3).

EVP_CIPHER_nid() returns the numeric identifier (NID) of the cipher cipher. The set of available NIDs is defined in the header file <openssl/obj_mac.h>.

EVP_CIPHER_CTX_nid() returns the NID of the cipher currently configured in the context ctx. If no cipher is configured, it returns 0.

EVP_CIPHER_flags() returns the flags associated with the cipher cipher. These flags are bitmasks composed of values like EVP_CIPH_RAND_KEY, EVP_CIPH_CBC_MODE, etc.

EVP_CIPHER_CTX_flags() returns the flags of the cipher currently configured in the context ctx. If no cipher is configured, it returns 0.

EVP_CIPHER_mode() returns the mode of the cipher cipher. The mode is typically a value like EVP_CM_CBC, EVP_CM_ECB, etc.

EVP_CIPHER_CTX_mode() returns the mode of the cipher currently configured in the context ctx. If no cipher is configured, it returns 0.

EVP_CIPHER_name() returns the short name of the cipher cipher.

EVP_CIPHER_CTX_name() returns the short name of the cipher currently configured in the context ctx. If no cipher is configured, it returns NULL.

EVP_CIPHER_key_length() returns the recommended key length for the cipher cipher.

EVP_CIPHER_CTX_key_length() returns the key length of the cipher currently configured in the context ctx. If no cipher is configured, it returns 0.

EVP_CIPHER_iv_length() returns the recommended IV length for the cipher cipher.

EVP_CIPHER_CTX_iv_length() returns the IV length of the cipher currently configured in the context ctx. If no cipher is configured, it returns 0.

RETURN VALUES

All functions return the requested information. For context-based functions, a return value of 0 or NULL indicates that no cipher is currently configured in the context.

SEE ALSO

EVP_EncryptInit_ex(3), EVP_DecryptInit_ex(3), EVP_get_cipherbyname(3), EVP_CIPHER_CTX_new(3), EVP_add_cipher(3)

HISTORY

EVP_CIPHER_CTX_nid(), EVP_CIPHER_CTX_flags(), EVP_CIPHER_CTX_mode(), EVP_CIPHER_CTX_name(), EVP_CIPHER_CTX_key_length(), and EVP_CIPHER_CTX_iv_length() first appeared in SSLeay 0.8.0.

The functions EVP_CIPHER_flags(), EVP_CIPHER_mode(), EVP_CIPHER_name(), EVP_CIPHER_key_length(), and EVP_CIPHER_iv_length() were added in OpenSSL 0.9.6.

EVP_CIPHER_CTX_nid() first appeared in SSLeay 0.8.0. All these functions have been available since OpenBSD 2.4.

EVP_CIPHER_flags(), EVP_CIPHER_CTX_flags(), EVP_CIPHER_mode(), and EVP_CIPHER_CTX_mode() first appeared in OpenSSL 0.9.6 and have been available since OpenBSD 2.9.

EVP_CIPHER_name() first appeared in OpenSSL 0.9.7 and has been available since OpenBSD 3.2.

CAVEATS

The behavior of the functions taking an EVP_CIPHER_CTX argument is undefined if they are called on a ctx that has no cipher configured yet, for example one freshly returned from EVP_CIPHER_CTX_new(3). In that case, the program may for example be terminated by a NULL pointer access.
