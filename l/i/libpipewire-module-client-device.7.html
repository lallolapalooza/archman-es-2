NOMBRE

libpipewire-module-client-device - Dispositivo cliente

DESCRIPCIÓN

Permite a los clientes exportar dispositivos al demonio PipeWire.

Este módulo crea un tipo de exportación para la interfaz SPA_TYPE_INTERFACE_Device.

Con pw_core_export(), los objetos de este tipo se pueden exportar al servidor PipeWire. Todas las acciones realizadas en el dispositivo localmente serán visibles para los clientes conectados.

En algunos casos, es posible usar esta fábrica directamente. Con pw_core_create_object() en la fábrica client-device se obtendrá un proxy SPA_TYPE_INTERFACE_Device que se puede usar para controlar la implementación de Device creada en el lado del servidor.

Esquemáticamente, el Device del lado del cliente se envuelve en el proxy ClientDevice y se desempaqueta por el recurso del lado del servidor, de modo que todas las acciones en el dispositivo del lado del cliente se reflejan en el dispositivo del lado del servidor y las acciones del lado del servidor se reflejan en el cliente.

  proxy del lado del cliente                      recurso del lado del servidor
.------------------------------.            .----------------------------------.
| SPA_TYPE_INTERFACE_Device    |            |  PW_TYPE_INTERFACE_Device        |
|                              |  IPC       |.--------------------------------.|
|                              | ----->     || SPA_TYPE_INTERFACE_Device      ||
|                              |            |'--------------------------------'|

NOMBRE DEL MÓDULO

libpipewire-module-client-device

OPCIONES DEL MÓDULO

Este módulo no tiene opciones.

PROPIEDADES PARA LA LLAMADA CREATE_OBJECT

Todas las propiedades se pasan directamente a la llamada pw_context_create_device().

EJEMPLO DE CONFIGURACIÓN

El módulo se suele añadir al archivo de configuración del demonio principal de PipeWire y de los clientes.

context.modules = [
{ name = libpipewire-module-client-device }
]
