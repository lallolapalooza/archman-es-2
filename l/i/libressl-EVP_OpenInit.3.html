libressl-EVP_OpenInit(3)

Paquete: libressl

Licencias: ISC, custom:OpenSSL

EVP_OPENINIT(3) Manual de funciones de biblioteca EVP_OPENINIT(3)

NOMBRE

EVP_OpenInit, EVP_OpenUpdate, EVP_OpenFinal — descifrado de sobres EVP

SINOPSIS

biblioteca “libcrypto”
#include <openssl/evp.h>

int
EVP_OpenInit(EVP_CIPHER_CTX *ctx, EVP_CIPHER *type, unsigned char *ek, int ekl, unsigned char *iv, EVP_PKEY *priv);

int
EVP_OpenUpdate(EVP_CIPHER_CTX *ctx, unsigned char *out, int *outl, unsigned char *in, int inl);

int
EVP_OpenFinal(EVP_CIPHER_CTX *ctx, unsigned char *out, int *outl);

DESCRIPCIÓN

Las rutinas de sobres EVP son una interfaz de alto nivel para el descifrado de sobres. Descifran una clave simétrica cifrada con clave pública y luego descifran los datos usando esa clave.

EVP_OpenInit() inicializa un contexto de cifrado ctx para el descifrado con el cifrado type. Descifra la clave simétrica cifrada de longitud ekl bytes pasada en el parámetro ek utilizando la clave privada priv. El IV se proporciona en el parámetro iv.

EVP_OpenUpdate() y EVP_OpenFinal() tienen exactamente las mismas propiedades que las rutinas EVP_DecryptUpdate(3) y EVP_DecryptFinal(3).

Es posible llamar a EVP_OpenInit() dos veces de la misma manera que a EVP_DecryptInit(3). La primera llamada debe tener priv establecido en NULL y (después de establecer cualquier parámetro de cifrado) se debe llamar de nuevo con type establecido en NULL.

Si el cifrado pasado en el parámetro type es un cifrado de longitud variable, la longitud de la clave se establecerá en el valor de la longitud de la clave recuperada. Si el cifrado es un cifrado de longitud fija, la longitud de la clave recuperada debe coincidir con la longitud fija del cifrado.

EVP_OpenUpdate() está implementado como una macro.

VALORES DE RETORNO

EVP_OpenInit() devuelve 0 en caso de error o un entero distinto de cero (en realidad, el tamaño de la clave secreta recuperada) si tiene éxito.

EVP_OpenUpdate() devuelve 1 para éxito o 0 para fallo.

EVP_OpenFinal() devuelve 0 si el descifrado falló o 1 para éxito.

VER TAMBIÉN

evp(3), EVP_EncryptInit(3), EVP_SealInit(3)

HISTORIAL

EVP_OpenInit(), EVP_OpenUpdate(), y EVP_OpenFinal() aparecieron por primera vez en SSLeay 0.5.1 y han estado disponibles desde OpenBSD 2.4.
