DESCRIPCIÓN

X509v3_get_ext_count() recupera el número de extensiones en x.

X509v3_get_ext() recupera la extensión loc de x. El índice loc puede tomar cualquier valor desde 0 hasta X509_get_ext_count(x) - 1. La extensión devuelta es un puntero interno que la aplicación no debe liberar.

X509v3_get_ext_by_NID() y X509v3_get_ext_by_OBJ() buscan una extensión con nid u obj de la pila de extensiones x. La búsqueda comienza desde la extensión posterior a lastpos o desde el principio si lastpos es -1. Si se encuentra la extensión, se devuelve su índice; de lo contrario, se devuelve un valor negativo.

X509v3_get_ext_by_critical() es similar a X509v3_get_ext_by_NID() excepto en que busca una extensión con la criticidad crit. Un valor cero para crit busca una extensión no crítica; un valor distinto de cero busca una extensión crítica.

DESCRIPTION

These functions provide direct access to the stack of extensions associated with an X.509 certificate, CRL or CRL entry.

The functions prefixed with X509v3_ operate on a generic stack of extensions exts. The other functions operate on the extensions within an X509 certificate, X509_CRL certificate revocation list, or X509_REVOKED entry in a CRL.

The functions X509v3_get_ext_count(), X509_get_ext_count(), X509_CRL_get_ext_count(), and X509_REVOKED_get_ext_count() return the number of extensions present.

The functions X509v3_get_ext(), X509_get_ext(), X509_CRL_get_ext(), and X509_REVOKED_get_ext() return a pointer to the extension at the specified location loc. Locations are zero-based.

The functions X509v3_get_ext_by_NID(), X509v3_get_ext_by_OBJ(), X509v3_get_ext_by_critical(), X509_get_ext_by_NID(), X509_get_ext_by_OBJ(), X509_get_ext_by_critical(), X509_CRL_get_ext_by_NID(), X509_CRL_get_ext_by_OBJ(), X509_CRL_get_ext_by_critical(), X509_REVOKED_get_ext_by_NID(), X509_REVOKED_get_ext_by_OBJ(), and X509_REVOKED_get_ext_by_critical() search for an extension.

They search for an extension matching the given nid or obj. If the crit parameter is non-zero, only critical extensions are searched for. If crit is zero, only non-critical extensions are searched for. If crit is -1, extensions of any criticality are searched for.

The search starts from the extension after the position given by lastpos. Initially, lastpos should be set to -1. Subsequent calls should use the return value of the previous call as the new lastpos to find subsequent matches. If lastpos is set to 0, the first extension will not be checked.

The functions X509v3_add_ext(), X509_add_ext(), X509_CRL_add_ext(), and X509_REVOKED_add_ext() add the extension ex to the stack at position loc. If loc is -1, the extension is added to the end. If the stack pointer is NULL, a new stack is allocated. The passed extension ex is duplicated internally, so it must be freed after use.

X509v3_add_ext_by_NID() and X509v3_add_ext_by_OBJ() are convenience functions that construct an extension from the value val and add it to the certificate x.

The functions X509v3_delete_ext(), X509_delete_ext(), X509_CRL_delete_ext(), and X509_REVOKED_delete_ext() delete the extension at the specified position loc. If an invalid index value is passed, NULL is returned for the extension pointer functions and -1 is returned for the index returning functions.

The functions X509_get_ext_count(), X509_get_ext(), X509_get_ext_by_NID(), X509_get_ext_by_OBJ(), X509_get_ext_by_critical(), X509_delete_ext(), and X509_add_ext() operate on the extensions of certificate x. They are otherwise identical to the X509v3 functions.

The functions X509_CRL_get_ext_count(), X509_CRL_get_ext(), X509_CRL_get_ext_by_NID(), X509_CRL_get_ext_by_OBJ(), X509_CRL_get_ext_by_critical(), X509_CRL_delete_ext(), and X509_CRL_add_ext() operate on the extensions of the CRL x. They are otherwise identical to the X509v3 functions.

The functions X509_REVOKED_get_ext_count(), X509_REVOKED_get_ext(), X509_REVOKED_get_ext_by_NID(), X509_REVOKED_get_ext_by_OBJ(), X509_REVOKED_get_ext_by_critical(), X509_REVOKED_delete_ext(), and X509_REVOKED_add_ext() operate on the extensions of the CRL entry x. They are otherwise identical to the X509v3 functions.

These functions are used to examine stacks of extensions directly. Many applications will want to parse or encode and add an extension: they should use the extension encode and decode functions instead such as X509_get_ext_d2i(3).

Extension indices start from zero, so a zero index return value is not an error. These search functions start from the extension after the lastpos parameter, so it should initially be set to -1. If it is set to 0, the initial extension will not be checked.

RETURN VALUES

X509v3_get_ext_count() returns the extension count.

X509v3_get_ext(), X509v3_delete_ext(), and X509_delete_ext() return an X509_EXTENSION pointer or NULL if an error occurs.

X509v3_get_ext_by_NID(), X509v3_get_ext_by_OBJ(), and X509v3_get_ext_by_critical() return the extension index or -1 if an error occurs. In addition, X509v3_get_ext_by_NID() returns -2 if OBJ_nid2obj(3) fails on the requested nid.

X509v3_add_ext() returns a stack of extensions or NULL on error.

X509_add_ext() returns 1 on success or 0 on error.
