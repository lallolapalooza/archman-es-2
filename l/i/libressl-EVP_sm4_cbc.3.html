libressl-EVP_sm4_cbc(3)

Licencias: ISC, custom:OpenSSL

EVP_SM4_CBC(3) Manual de funciones de la biblioteca EVP_SM4_CBC(3)

NOMBRE

EVP_sm4_cbc, EVP_sm4_ecb, EVP_sm4_cfb, EVP_sm4_cfb128, EVP_sm4_ofb, EVP_sm4_ctr — cifrado EVP SM4

SINOPSIS

biblioteca «libcrypto»
#include <openssl/evp.h>

const EVP_CIPHER *
EVP_sm4_cbc(void);

const EVP_CIPHER *
EVP_sm4_ecb(void);

const EVP_CIPHER *
EVP_sm4_cfb(void);

const EVP_CIPHER *
EVP_sm4_cfb128(void);

const EVP_CIPHER *
EVP_sm4_ofb(void);

const EVP_CIPHER *
EVP_sm4_ctr(void);

DESCRIPCIÓN

Estas funciones proporcionan el cifrado de bloque SM4 en el marco evp(3).

Todos los modos utilizan una longitud de clave de 128 bits y actúan sobre bloques de 128 bits.

EVP_sm4_cfb() es un alias para EVP_sm4_cfb128(), implementado como una macro.

Con un argumento de «sm4» o «SM4», EVP_get_cipherbyname(3) devuelve EVP_sm4_cbc().

VALORES DE RETORNO

Estas funciones devuelven una estructura EVP_CIPHER que proporciona la implementación del cifrado simétrico.

VER TAMBIÉN

evp(3), EVP_EncryptInit(3)

ESTÁNDARES

Tecnología de seguridad de la información - Algoritmo de cifrado de bloque SM4, Normas Nacionales de la República Popular China, GB/T 32907-2016, 29 de agosto de 2016.

Estas funciones aparecieron en OpenSSL 1.1.1 y han estado disponibles desde OpenBSD 6.5.
