libressl-X509_NAME_get_index_by_NID(3)

Paquete: libressl

Licencias: ISC, custom:OpenSSL

X509_NAME_GET_INDEX_BY_NID(3) Manual de Funciones de Biblioteca X509_NAME_GET_INDEX_BY_NID(3)

NOMBRE

X509_NAME_get_index_by_NID, X509_NAME_get_index_by_OBJ, X509_NAME_entry_count, X509_NAME_get_entry, X509_NAME_get_text_by_NID, X509_NAME_get_text_by_OBJ — Funciones de búsqueda y enumeración de X509_NAME

SINOPSIS

biblioteca “libcrypto”
#include <openssl/x509.h>

int
X509_NAME_get_index_by_NID(const X509_NAME *name, int nid, int lastpos);

int
X509_NAME_get_index_by_OBJ(const X509_NAME *name, const ASN1_OBJECT *obj, int lastpos);

int
X509_NAME_entry_count(const X509_NAME *name);

X509_NAME_ENTRY *
X509_NAME_get_entry(const X509_NAME *name, int loc);

int
X509_NAME_get_text_by_NID(X509_NAME *name, int nid, char *buf, int len);

int
X509_NAME_get_text_by_OBJ(X509_NAME *name, const ASN1_OBJECT *obj, char *buf, int len);

DESCRIPCIÓN

Estas funciones permiten examinar una estructura X509_NAME. La estructura X509_NAME es la misma que el tipo ASN.1 Name definido en RFC 2459 (y en otros lugares) y utilizado, por ejemplo, en los nombres de sujeto y emisor de certificados.

X509_NAME_get_index_by_NID() y X509_NAME_get_index_by_OBJ() recuperan el siguiente índice que coincide con nid o obj después de lastpos. lastpos debe inicializarse a -1.

X509_NAME_get_entry() recupera la X509_NAME_ENTRY de name correspondiente al índice loc. Los valores aceptables para loc van de 0 a X509_NAME_entry_count(name) - 1.

X509_NAME_get_text_by_NID() y X509_NAME_get_text_by_OBJ() recuperan los bytes codificados como UTF-8 de la primera entrada en name que coincide con nid o obj. Si buf es NULL, no se escribe nada, pero el valor de retorno se calcula como de costumbre. Si buf no es NULL, no se escribirán más de len bytes y el texto escrito en buf se terminará con NUL.

Si len no es lo suficientemente grande para albergar la codificación UTF-8 del texto terminada en NUL, o si la codificación UTF-8 del texto contuviera un byte NUL, no se escribirán datos y la llamada fallará.

Todos los códigos relevantes de NID_* y OBJ_* se pueden encontrar en el archivo de cabecera <openssl/objects.h>.

Las aplicaciones que podrían pasar NIDs inválidos a X509_NAME_get_index_by_NID() deberían comprobar el valor de retorno de -2. Alternativamente, la validez del NID se puede determinar primero comprobando que OBJ_nid2obj(nid) no sea NULL.

VALORES DE RETORNO

X509_NAME_get_index_by_NID() devuelve el índice de la siguiente entrada coincidente, -1 si no se encuentra, o -2 si el nid no corresponde a un OID válido.

X509_NAME_get_index_by_OBJ() devuelve el índice de la siguiente entrada coincidente o -1 si no se encuentra.

X509_NAME_entry_count() devuelve el número total de entradas en name.

X509_NAME_get_entry() devuelve un puntero interno que no debe ser liberado por el llamador, o NULL si el índice es inválido.

X509_NAME_get_text_by_NID() y X509_NAME_get_text_by_OBJ() devuelven la longitud de la cadena UTF-8 de salida escrita, sin contar el NUL de terminación, o -1 en caso de error o si no se encuentra ninguna coincidencia.

En algunos casos de error de X509_NAME_get_index_by_NID() y X509_NAME_get_text_by_NID(), la razón puede determinarse con ERR_get_error(3).

EJEMPLOS

Procesar todas las entradas:

int i;
X509_NAME_ENTRY *e;

for (i = 0; i < X509_NAME_entry_count(nm); i++) {
	e = X509_NAME_get_entry(nm, i);
	/* Hacer algo con e */
}

Procesar todas las entradas commonName:

int lastpos = -1;
X509_NAME_ENTRY *e;

for (;;) {
	lastpos = X509_NAME_get_index_by_NID(nm, NID_commonName, lastpos);
	if (lastpos == -1)
		break;
	e = X509_NAME_get_entry(nm, lastpos);
	/* Hacer algo con e */
}

VER TAMBIÉN

d2i_X509_NAME(3), X509_NAME_ENTRY_get_object(3), X509_NAME_new(3)

HISTORIA

Estas funciones aparecieron por primera vez en SSLeay 0.8.0 y han estado disponibles desde OpenBSD 2.4.

ADVERTENCIAS

X509_NAME_get_text_by_NID() y X509_NAME_get_text_by_OBJ() son funciones heredadas que tienen varias limitaciones que las hacen de utilidad mínima en la práctica. Solo pueden encontrar la primera entrada coincidente y copiarán el contenido del campo tal cual: esto puede ser muy confuso si el objetivo es un tipo de cadena de varios caracteres como una BMPString o una UTF8String.

Para una solución más general, se debe usar X509_NAME_get_index_by_NID() o X509_NAME_get_index_by_OBJ(), seguido de X509_NAME_get_entry() en cualquier índice coincidente y luego las diversas funciones de utilidad X509_NAME_ENTRY sobre el resultado.
