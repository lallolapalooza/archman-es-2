NOMBRE

EVP_sha3_224, EVP_sha3_256, EVP_sha3_384, EVP_sha3_512 — Algoritmo de Hash Seguro 3 para EVP

SINOPSIS

biblioteca “libcrypto”
#include <openssl/evp.h>

const EVP_MD *
EVP_sha3_224(void);

const EVP_MD *
EVP_sha3_256(void);

const EVP_MD *
EVP_sha3_384(void);

const EVP_MD *
EVP_sha3_512(void);

DESCRIPCIÓN

SHA-3 (Secure Hash Algorithm 3) es una familia de funciones de hash criptográficas estandarizadas en NIST FIPS 202, publicadas por primera vez en 2015. Se basa en el algoritmo Keccak.

EVP_sha3_224(), EVP_sha3_256(), EVP_sha3_384(), y EVP_sha3_512() implementan los algoritmos SHA3-224, SHA3-256, SHA3-384 y SHA3-512 y producen 224, 256, 384 y 512 bits de salida a partir de una entrada dada, respectivamente.

VALORES DE RETORNO

Estas funciones devuelven punteros a objetos EVP_MD estáticos que implementan las funciones de hash.

VER TAMBIÉN

evp(3), EVP_DigestInit(3)

ESTÁNDARES

NIST FIPS 202
