libssh2_sftp_readdir_ex(3)

Paquete: libssh2

Licencias: BSD

libssh2_sftp_readdir_ex(3) libssh2 libssh2_sftp_readdir_ex(3)

NOMBRE

libssh2_sftp_readdir_ex - leer datos de directorio de un identificador SFTP

SINOPSIS

#include <libssh2.h>
#include <libssh2_sftp.h>
int
libssh2_sftp_readdir_ex(LIBSSH2_SFTP_HANDLE *handle,
                        char *buffer, size_t buffer_maxlen,
                        char *longentry, size_t longentry_maxlen,
                        LIBSSH2_SFTP_ATTRIBUTES *attrs);

DESCRIPCIÓN

Lee un bloque de datos de un LIBSSH2_SFTP_HANDLE y devuelve información de entrada de archivo para la siguiente entrada, si la hay.

handle - es el identificador de archivo SFTP devuelto por libssh2_sftp_open_ex(3)

buffer - es un puntero a un búfer preasignado de al menos buffer_maxlen bytes para leer datos.

buffer_maxlen - es la longitud del búfer en bytes. Si la longitud del nombre del archivo es mayor que el espacio proporcionado por buffer_maxlen, se truncará para que quepa.

longentry - es un puntero a un búfer preasignado de al menos longentry_maxlen bytes para leer datos. El formato del campo `longname' no está especificado por el protocolo SFTP. DEBE ser adecuado para su uso en la salida de un comando de listado de directorios (de hecho, la operación recomendada para un comando de listado de directorios es mostrar estos datos).

longentry_maxlen - es la longitud de longentry en bytes. Si la longitud de la entrada completa del directorio es mayor que el espacio proporcionado por longentry_maxlen, se truncará para que quepa.

attrs - es un puntero al almacenamiento de LIBSSH2_SFTP_ATTRIBUTES para poblar datos de estilo statbuf.

VALOR DE RETORNO

Número de bytes realmente poblados en el búfer (sin contar el cero de terminación), o negativo en caso de fallo. Devuelve LIBSSH2_ERROR_EAGAIN cuando de lo contrario se bloquearía. Mientras que LIBSSH2_ERROR_EAGAIN es un número negativo, no es realmente un fallo en sí.

ERRORES DE PROGRAMACIÓN

Pasar un búfer demasiado pequeño para 'buffer' o 'longentry' al recibir datos solo resulta en que libssh2 1.2.7 o anterior no copie la cantidad total de datos, ¡y es imposible para la aplicación saber cuándo ocurre!

ERRORES

LIBSSH2_ERROR_ALLOC - Falló una llamada interna de asignación de memoria.

LIBSSH2_ERROR_SOCKET_SEND - Imposible enviar datos en el socket.

LIBSSH2_ERROR_SOCKET_TIMEOUT -

LIBSSH2_ERROR_SFTP_PROTOCOL - Se recibió una respuesta de protocolo SFTP inválida en el socket, o una operación SFTP causó que el servidor devolviera un código de error.

A partir de la versión 1.2.8, se devuelve LIBSSH2_ERROR_BUFFER_TOO_SMALL si alguno de los búferes 'buffer' o 'longentry' proporcionados es demasiado pequeño para contener el nombre del objeto solicitado.
