DSA_GENERATE_PARAMETERS_EX(3) Manual de funciones de la biblioteca DSA_GENERATE_PARAMETERS_EX(3)

NOMBRE

DSA_generate_parameters_ex — generar parámetros DSA

SINOPSIS

biblioteca “libcrypto”
#include <openssl/dsa.h>

int
DSA_generate_parameters_ex(DSA *dsa, int bits, const unsigned char *seed, int seed_len, int *counter_ret, unsigned long *h_ret, BN_GENCB *cb);

DESCRIPCIÓN

DSA_generate_parameters_ex() genera los primos p y q y un generador g para usar en DSA y almacena el resultado en dsa.

bits es la longitud del primo a generar; el DSS permite un máximo de 1024 bits.

Si seed es NULL o seed_len < 20, los primos se generarán aleatoriamente. De lo contrario, la semilla se utiliza para generarlos. Si la semilla dada no produce un primo q, se elige una nueva semilla aleatoria y se coloca en seed.

DSA_generate_parameters_ex() coloca el contador de iteraciones en *counter_ret y un contador utilizado para encontrar un generador en *h_ret, a menos que estos sean NULL.

Se puede usar una función de devolución de llamada para proporcionar información sobre el progreso de la generación de claves. Si cb no es NULL, se llamará como se muestra a continuación. Para obtener información sobre la estructura BN_GENCB, consulte BN_GENCB_call(3).

  • Cuando se genera un candidato para q, BN_GENCB_call(cb, 0, m++) se llama (m es 0 para el primer candidato).
  • Cuando un candidato para q ha pasado una prueba por división de prueba, se llama BN_GENCB_call(cb, 1, -1). Mientras se prueba un candidato para q con pruebas de primalidad de Miller-Rabin, se llama BN_GENCB_call(cb, 1, i) en el bucle externo (una vez por cada testigo que confirma que el candidato puede ser primo); i es el contador del bucle (comenzando en 0).
  • Cuando se encuentra un primo q, se llaman BN_GENCB_call(cb, 2, 0) y BN_GENCB_call(cb, 3, 0).
  • Antes de generar y probar un candidato para p (distinto del primero), se llama BN_GENCB_call(cb, 0, counter).
  • Cuando un candidato para p ha pasado la prueba por división de prueba, se llama BN_GENCB_call(cb, 1, -1). Mientras se prueba con la prueba de primalidad de Miller-Rabin, se llama BN_GENCB_call(cb, 1, i) en el bucle externo (una vez por cada testigo que confirma que el candidato puede ser primo). i es el contador del bucle (comenzando en 0).
  • Cuando se encuentra p, se llama BN_GENCB_call(cb, 2, 1).
  • Cuando se encuentra el generador, se llama BN_GENCB_call(cb, 3, 1).

VALORES DE RETORNO

DSA_generate_parameters_ex() devuelve 1 en caso de éxito o 0 en caso contrario.

Los códigos de error se pueden obtener mediante ERR_get_error(3).

VER TAMBIÉN

BN_generate_prime(3), DSA_get0_pqg(3), DSA_new(3)

HISTORIA

DSA_generate_parameters_ex() apareció por primera vez en OpenSSL 0.9.8 y ha estado disponible desde OpenBSD 4.5.

ERRORES

Las longitudes de semilla mayores que 20 no son compatibles.
