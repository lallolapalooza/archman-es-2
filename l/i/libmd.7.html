NOMBRE

libmd — Funciones de resumen de mensajes de sistemas BSD

DESCRIPCIÓN

La biblioteca libmd proporciona funciones de resumen de mensajes encontradas en los sistemas BSD, ya sea en su libc o en sus bibliotecas libmd, y que faltan en otros sistemas como los GNU, lo que facilita la portabilidad de proyectos con un fuerte origen BSD, sin necesidad de incrustar el mismo código una y otra vez en cada proyecto.

La biblioteca proporciona una interfaz de compatibilidad para la implementación MD5 de Aladdin Enterprises, pero la interfaz no se expone por defecto para evitar la contaminación del espacio de nombres. La variable de preprocesador LIBMD_MD5_ALADDIN debe definirse para exponer esta interfaz.

La biblioteca proporciona una entrada de pkgconf(1) llamada libmd.

CABECERAS

La biblioteca libmd proporciona compatibilidad con varias cabeceras e interfaces de BSD.

Las siguientes cabeceras se proporcionan para compatibilidad con NetBSD y OpenBSD.

<md2.h>
 
<md4.h>
 
<md5.h>
 
<rmd160.h>
 
<sha1.h>
 
<sha2.h>
 

Las siguientes cabeceras se proporcionan para compatibilidad con FreeBSD y DragonFly.

<ripemd.h>
 
<sha.h>
 
<sha256.h>
 
<sha512.h>
 

VER TAMBIÉN

md2(3), md4(3), md5(3), rmd160(3), sha1(3), sha2(3).

HISTORIA

El proyecto libmd comenzó en el puerto Debian GNU/kFreeBSD como parte de la biblioteca libbsd, como una forma de facilitar la portabilidad de código de FreeBSD al sistema basado en GNU. Posteriormente, se dividió en un proyecto creado en Hadrons.Org (reflejado en FreeDesktop.Org) para que lo usaran otras distribuciones y proyectos, y se amplió para que coincidiera con las otras interfaces de BSD.

Ahora se distribuye como parte de la mayoría de las distribuciones no-BSD.
