NOMBRE

libnbd-release-notes-1.12 - notas de la versión de libnbd 1.12

DESCRIPCIÓN

Estas son las notas de la versión estable 1.12 de libnbd. Describen los principales cambios desde la versión 1.10.

libnbd 1.12.0 fue lanzado el 24 de febrero de 2022.

Seguridad

CVE-2022-0485
Corrupción silenciosa de datos al usar nbdcopy(1).

Ver el anuncio completo aquí: https://listman.redhat.com/archives/libguestfs/2022-February/msg00104.html

Si encuentra un problema de seguridad, por favor lea SECURITY en el código fuente (en línea aquí: https://gitlab.com/nbdkit/libnbd/blob/master/SECURITY). Para saber sobre problemas de seguridad anteriores en libnbd, consulte libnbd-security(3).

Nuevas APIs

get_pread_initialize
set_pread_initialize
Controla si libnbd borra el buffer de pread para evitar fugas de contenido de memoria si el cliente no maneja correctamente los errores. Estas fueron añadidas como parte de la corrección para CVE-2022-0485 (Eric Blake).
get_request_block_size
set_request_block_size
Controla si libnbd solicita restricciones de tamaño de bloque del servidor durante la negociación (Eric Blake).

Mejoras en APIs existentes

Los mensajes de error sobre URIs incorrectos en nbd_connect_uri(3) han sido mejorados para hacer que los errores comunes sean más claros para el usuario.

Herramientas

Nueva sintaxis: "nbdinfo [ COMANDO ... ]" que le permite consultar las propiedades de un servidor NBD directamente.

nbdcopy(1) nueva opción --queue-size para controlar el tamaño máximo del buffer interno (Nir Soffer).

nbdcopy(1) ahora nombra los manejadores de origen y destino para que sea más fácil entender la salida de depuración.

Pruebas

Adopta ci/gitlab.yml de libvirt-ci (Martin Kletzander).

Corrige el ejemplo de extents de OCaml (gracias a Laszlo Ersek).

Se añadieron benchmarks de Golang al conjunto de pruebas (Nir Soffer).

La gran prueba tests/errors.c fue dividida en alrededor de una docena de pruebas separadas. Además, esto añade una nueva prueba para verificar la política de error de restricciones de tamaño de bloque del servidor, que faltaba antes.

Otras mejoras y correcciones de errores

Nuevo helper de OCaml "NBD.with_handle" que asegura que "NBD.close" siempre se llama incluso si el código interno lanza una excepción.

Las vinculaciones de OCaml ahora usan consistentemente los tipos correctos para los tamaños de buffer en todas partes (Laszlo Ersek).

Varias mejoras y correcciones en las vinculaciones y pruebas de Golang. Las vinculaciones de Golang han sido relanzadas bajo LGPLv2+ como el resto de la librería y ahora se publican como un módulo de Golang en https://libguestfs.org/libnbd (Nir Soffer).

Las vinculaciones de Python ya no fallan si se pasa "None" en lugar de un parámetro de buffer. Además, se corrigieron algunas fugas de memoria (Eric Blake).

Se han corregido varias fugas de memoria al usar las configuraciones opcionales de modo estricto (Eric Blake).

El rendimiento de la biblioteca interna de vectores ha mejorado enormemente y el desbordamiento ahora se maneja correctamente (Nir Soffer, Laszlo Ersek y Eric Blake).

Añade ejemplos de Golang "simple_copy" y "aio_copy" (Nir Soffer).

Se revisó y corrigió el manejo de errores en muchos de los programas de ejemplo y documentación (Eric Blake, Nir Soffer).

Simplifica y optimiza el manejo del callback de extents en Golang (Nir Soffer).

Golang AioBuffer fue mejorado, haciéndolo más seguro de usar, más rápido y añadiendo documentación (Nir Soffer).

Documentación

Documenta los límites de longitudes y tamaños de los parámetros de varias APIs (Eric Blake).

Compilación

Ahora puedes compilar programas que usan las vinculaciones OCaml de libnbd contra el directorio de compilación de libnbd en lugar de requerir que libnbd esté instalado (Laszlo Ersek).

Compatibilidad con OCaml 4.13.

Las ubicaciones de línea en la máquina de estados deberían ser más precisas al depurar con un depurador como gdb.

El archivo .editorconfig puede ser usado para ayudar al formato del código, ver https://editorconfig.org/ (Nir Soffer, Eric Blake).

Las macros "MIN" y "MAX" pueden ser anidadas (gracias a Eric Blake).

VER TAMBIÉN

libnbd(3).

NOMBRE

libnbd-release-notes-1.12.1 - Notas de la versión de libnbd

DESCRIPCIÓN

Este archivo contiene las notas de la versión para libnbd 1.12.1.

Notas de la versión para libnbd 1.12.1

Correcciones de errores

  • Corregido un problema que causaba un bloqueo en ciertas condiciones al usar nbd-client.
  • Solucionado un problema de fuga de memoria en la API de libnbd.
  • Mejorada la gestión de errores para operaciones de red no válidas.

Mejoras

  • Se ha añadido soporte para la exportación de bloques en libnbd.
  • Mejorada la serialización y deserialización de metadatos.
  • Optimizado el rendimiento de las operaciones de lectura y escritura.

Nuevas características

  • Introducido un nuevo comando `nbd-mirror` para la replicación de datos.
  • Añadida la capacidad de manejar conexiones TLS en nbd-server.
  • Implementado el soporte para el protocolo NBD versión 2.10.

VER TAMBIÉN

nbd-client(8), nbd-server(8), libnbd(3)
