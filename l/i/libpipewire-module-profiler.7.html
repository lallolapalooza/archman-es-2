NOMBRE

libpipewire-module-profiler - Profiler

DESCRIPCIÓN

El módulo profiler proporciona una interfaz Profiler para aplicaciones que pueden usarse para recibir información de perfilado.

Utilice herramientas como pw-top y pw-profiler para recopilar información de perfilado sobre el grafo de pipewire.

NOMBRE DEL MÓDULO

libpipewire-module-profiler

OPCIONES DEL MÓDULO

•
profile.interval.ms: Se puede usar para evitar la recopilación de información de perfilado en cada ciclo de procesamiento. Esto permite intercambiar el uso de la CPU por la precisión del perfilado. Valor predeterminado 0

SOBREESCRITURA DE CONFIGURACIÓN

Se puede añadir una sección de configuración module.profiler.args para sobrescribir los argumentos del módulo.

# ~/.config/pipewire/pipewire.conf.d/my-profiler-args.conf
module.profiler.args = {
    #profile.interval.ms = 10
}

EJEMPLO DE CONFIGURACIÓN

El módulo generalmente se añade al archivo de configuración del demonio principal de pipewire.

context.modules = [
{ name = libpipewire-module-profiler
  args = {
      #profile.interval.ms = 0
  }
}
]

VER TAMBIÉN

  • pw-top: una herramienta para mostrar datos de perfilado en tiempo real
  • pw-profiler: una herramienta para recopilar y renderizar datos de perfilado
