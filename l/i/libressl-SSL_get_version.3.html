Paquete: libressl

Licencias: ISC, custom:OpenSSL

SSL_GET_VERSION(3) Manual de funciones de la biblioteca SSL_GET_VERSION(3)

NOMBRE

SSL_get_version, SSL_is_dtls, SSL_version — obtener la información del protocolo de una conexión

SINOPSIS

biblioteca “libssl” libcrypto
#include <openssl/ssl.h>

const char *
SSL_get_version(const SSL *ssl);

int
SSL_is_dtls(const SSL *ssl);

int
SSL_version(const SSL *ssl);

DESCRIPCIÓN

SSL_get_version() devuelve el nombre del protocolo utilizado para la conexión ssl.

SSL_is_dtls() devuelve 1 si la conexión está utilizando DTLS, 0 si no.

SSL_version() devuelve una constante entera que representa dicho protocolo.

Estas funciones solo devuelven resultados fiables después de que se haya completado el handshake inicial.

VALORES DE RETORNO

Las siguientes cadenas o enteros pueden ser devueltos por SSL_get_version() y SSL_version():

"TLSv1" o TLS1_VERSION
La conexión utiliza el protocolo TLSv1.0.
"TLSv1.1" o TLS1_1_VERSION
La conexión utiliza el protocolo TLSv1.1.
"TLSv1.2" o TLS1_2_VERSION
La conexión utiliza el protocolo TLSv1.2.
"TLSv1.3" o TLS1_3_VERSION
La conexión utiliza el protocolo TLSv1.3.
"DTLSv1" o DTLS1_VERSION
La conexión utiliza el protocolo Datagram Transport Layer Security 1.0.
"DTLSv1.2" o DTLS1_2_VERSION
La conexión utiliza el protocolo Datagram Transport Layer Security 1.2.
"unknown"
Esto indica una versión de protocolo desconocida; actualmente no puede ocurrir con LibreSSL.

SSL_is_dtls() devuelve 1 si la conexión utiliza DTLS, 0 si no.

VER TAMBIÉN

ssl(3)

HISTORIA

SSL_get_version() y SSL_version() aparecieron por primera vez en SSLeay 0.8.0 y han estado disponibles desde OpenBSD 2.4.

SSL_is_dtls() apareció por primera vez en OpenSSL 1.1.0 y ha estado disponible desde OpenBSD 6.9.
