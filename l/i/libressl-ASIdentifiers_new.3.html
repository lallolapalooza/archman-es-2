ASIDENTIFIERS_NEW(3) Manual de funciones de la biblioteca ASIDENTIFIERS_NEW(3)

NOMBRE

ASIdentifiers_new, ASIdentifiers_free, d2i_ASIdentifiers, i2d_ASIdentifiers — extensiones de delegación de identificadores de sistema autónomo RFC 3779

SINOPSIS

biblioteca “libcrypto”
#include <openssl/x509v3.h>

ASIdentifiers *
ASIdentifiers_new(void);

void
ASIdentifiers_free(ASIdentifiers *asid);

ASIdentifiers *
d2i_ASIdentifiers(ASIdentifiers **asid, const unsigned char **in, long len);

int
i2d_ASIdentifiers(ASIdentifiers *asid, unsigned char **out);

DESCRIPCIÓN

El RFC 3779 define dos extensiones de certificado X.509v3 que permiten la delegación de direcciones IP e identificadores de sistema autónomo (AS) desde el emisor al sujeto del certificado. Un objeto ASIdentifiers contiene colecciones de números AS individuales y rangos de números AS a delegar.

ASIdentifiers_new() asigna e inicializa un nuevo objeto ASIdentifiers vacío que puede ser poblado con X509v3_asid_add_id_or_range(3). Ver ASRange_new(3) para detalles de implementación.

ASIdentifiers_free() libera asid incluyendo cualquier dato contenido en él. Si asid es NULL, no se realiza ninguna acción.

d2i_ASIdentifiers() y i2d_ASIdentifiers() decodifican y codifican objetos ASIdentifiers ASN.1 según lo definido en el RFC 3779, sección 3.2.3.1. Para detalles sobre la semántica, ejemplos, advertencias y errores, ver ASN1_item_d2i(3). Para que la codificación producida por i2d_ASIdentifiers() cumpla con el RFC 3779, asid debe estar en forma “canónica”, ver X509v3_asid_canonize(3).

VALORES DE RETORNO

ASIdentifiers_new() devuelve un nuevo objeto ASIdentifiers o NULL si ocurre un error.

d2i_ASIdentifiers() devuelve un objeto ASIdentifiers o NULL si ocurre un error de decodificación o de asignación de memoria.

i2d_ASIdentifiers() devuelve el número de bytes codificados con éxito o un valor <= 0 si ocurre un error.
