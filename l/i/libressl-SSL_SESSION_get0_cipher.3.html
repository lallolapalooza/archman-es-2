SSL_SESSION_get0_CIPHER(3) Manual de funciones de la biblioteca SSL_SESSION_get0_CIPHER(3)

NOMBRE

SSL_SESSION_get0_cipher — recuperar la cifra SSL asociada a una sesión

SINOPSIS

biblioteca “libssl” libcrypto
#include <openssl/ssl.h>

const SSL_CIPHER *
SSL_SESSION_get0_cipher(const SSL_SESSION *session);

DESCRIPCIÓN

SSL_SESSION_get0_cipher() recupera la cifra que fue utilizada por la conexión cuando se creó la sesión, o NULL si no se puede determinar.

El valor devuelto es un puntero a un objeto mantenido dentro de session y no debe ser liberado.

VALORES DE RETORNO

SSL_SESSION_get0_cipher() devuelve la SSL_CIPHER asociada con session o NULL si no se puede determinar.

VER TAMBIÉN

ssl(3), SSL_CIPHER_get_name(3), SSL_get_current_cipher(3), SSL_get_session(3), SSL_SESSION_new(3)

HISTORIAL

La función SSL_SESSION_get0_cipher() apareció por primera vez en OpenSSL 1.1.0 y ha estado disponible desde OpenBSD 7.0.
