NOMBRE

libkeccak_zerocopy_update - Hash parcial de un mensaje sin copiar (AVANZADO)

SINOPSIS

#include <libkeccak.h>
void libkeccak_zerocopy_update(struct libkeccak_state *state, const void *msg, size_t msglen);

Enlazar con -lkeccak.

DESCRIPCIÓN

La función libkeccak_zerocopy_update() continúa (o inicia) el hash de un mensaje. El estado actual del hash se almacena en *state, y será actualizado. El mensaje especificado por el parámetro msg con el tamaño en bytes especificado por el parámetro msglen, será hasheado.

Como una restricción específica de la función libkeccak_zerocopy_update(), el argumento msglen debe ser un múltiplo entero del bitrate dividido por ocho. Esto se devuelve por la función libkeccak_zerocopy_chunksize(3). Las funciones libkeccak_update(3) o libkeccak_fast_update(3) se pueden usar para evitar esta restricción, pero estas, a diferencia de la función libkeccak_zerocopy_update(), copiarán el mensaje y moverán los datos copiados.

VALORES DE RETORNO

La función libkeccak_zerocopy_update() no devuelve ningún valor.

ERRORES

La función libkeccak_zerocopy_update() no puede fallar.

NOTAS

Ninguno de los parámetros puede ser NULL o 0.

Es seguro llamar a la función libkeccak_zerocopy_update() antes que a las funciones libkeccak_update(3), libkeccak_fast_update(3) libkeccak_digest(3) y libkeccak_fast_digest(3) con el mismo argumento state. Sin embargo, llamar a la función libkeccak_zerocopy_update() después de las funciones libkeccak_update(3) o libkeccak_fast_update(3) puede causar que el mensaje se lea incorrectamente.

NOTAS

Para cSHAKE, libkeccak_cshake_initialise(3), debe ser llamada, una vez, inmediatamente después de la inicialización del estado; antes de la primera llamada a la función libkeccak_zerocopy_update().

VER TAMBIÉN
