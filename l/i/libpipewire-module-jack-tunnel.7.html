NOMBRE

libpipewire-module-jack-tunnel - JACK Tunnel

DESCRIPCIÓN

El módulo jack-tunnel proporciona una fuente o un sumidero que canaliza todo el audio a un servidor JACK.

Este módulo se usa normalmente junto con JACK DBus detect que cargará automáticamente el túnel con los parámetros correctos basados en la información de dbus.

NOMBRE DEL MÓDULO

libpipewire-module-jack-tunnel

OPCIONES DEL MÓDULO

  • jack.library: la libjack a cargar, por defecto se busca libjack.so.0 en los directorios JACK_PATH y luego en algunas rutas de biblioteca estándar. Puede ser una ruta absoluta.
  • jack.server: el nombre del servidor JACK al que canalizar.
  • jack.client-name: el nombre del cliente JACK.
  • jack.connect: si los puertos JACK deben conectarse automáticamente. También se puede colocar por flujo.
  • tunnel.mode: el modo del túnel, sink|source|duplex, por defecto duplex
  • midi.ports: el número de puertos midi. También se puede añadir a las propiedades del flujo.
  • source.props: Propiedades adicionales para el filtro de origen.
  • sink.props: Propiedades adicionales para el filtro de sumidero.

OPCIONES GENERALES

Opciones con comportamiento conocido.

  • remote.name
  • audio.channels
  • audio.position
  • node.name
  • node.description
  • node.group
  • node.virtual
  • media.class
  • target.object para especificar el nombre del nodo remoto o el id.serial al que vincularse

EJEMPLO DE CONFIGURACIÓN DE UN SUMIDERO/FUENTE DUPLEX

# ~/.config/pipewire/pipewire.conf.d/my-jack-tunnel.conf
context.modules = [
{   name = libpipewire-module-jack-tunnel
    args = {
        #jack.library     = libjack.so.0
        #jack.server      = null
        #jack.client-name = PipeWire
        #jack.connect     = true
        #tunnel.mode      = duplex
        #midi.ports       = 0
        #audio.channels   = 2
        #audio.position   = [ FL FR ]
        source.props = {
            # propiedades adicionales del sumidero
        }
        sink.props = {
            # propiedades adicionales del sumidero
        }
    }
}
]
