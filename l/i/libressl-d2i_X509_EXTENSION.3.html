libressl-d2i_X509_EXTENSION(3)

Paquete: libressl

Licencias: ISC, custom:OpenSSL

D2I_X509_EXTENSION(3) Manual de funciones de biblioteca D2I_X509_EXTENSION(3)

NOMBRE

d2i_X509_EXTENSION, i2d_X509_EXTENSION, d2i_X509_EXTENSIONS, i2d_X509_EXTENSIONS — decodifica y codifica extensiones X.509

SINOPSIS

biblioteca “libcrypto”
#include <openssl/x509.h>

X509_EXTENSION *
d2i_X509_EXTENSION(X509_EXTENSION **val_out, const unsigned char **der_in, long length);

int
i2d_X509_EXTENSION(X509_EXTENSION *val_in, unsigned char **der_out);

X509_EXTENSIONS *
d2i_X509_EXTENSIONS(X509_EXTENSIONS **val_out, const unsigned char **der_in, long length);

int
i2d_X509_EXTENSIONS(X509_EXTENSIONS *val_in, unsigned char **der_out);

DESCRIPCIÓN

d2i_X509_EXTENSION() y i2d_X509_EXTENSION() decodifican y codifican una estructura de Extension ASN.1 definida en la sección 4.1 de RFC 5280.

d2i_X509_EXTENSIONS() y i2d_X509_EXTENSIONS() decodifican y codifican una estructura de Extensions ASN.1 definida en la sección 4.1 de RFC 5280, que es una SEcuencia DE Extension.

VALORES DE RETORNO

d2i_X509_EXTENSION() y d2i_X509_EXTENSIONS() devuelven un objeto X509_EXTENSION o X509_EXTENSIONS, respectivamente, o NULL si ocurre un error.

i2d_X509_EXTENSION() y i2d_X509_EXTENSIONS() devuelven el número de bytes codificados con éxito o un valor negativo si ocurre un error.

VER TAMBIÉN

ASN1_item_d2i(3), X509_EXTENSION_new(3), X509V3_get_d2i(3), X509v3_get_ext_by_NID(3)

ESTÁNDARES

RFC 5280: Perfil de Certificado y Lista de Revocación de Certificados (CRL) de Infraestructura de Clave Pública X.509 de Internet

HISTORIA

d2i_X509_EXTENSION() y i2d_X509_EXTENSION() aparecieron por primera vez en SSLeay 0.6.2 y han estado disponibles desde OpenBSD 2.4.

d2i_X509_EXTENSIONS() y i2d_X509_EXTENSIONS() aparecieron por primera vez en OpenSSL 0.9.8h y han estado disponibles desde OpenBSD 4.5.
