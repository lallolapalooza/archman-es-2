libressl-PKCS7_dataFinal(3)

Paquete: libressl

Licencias: ISC, custom:OpenSSL

PKCS7_DATAFINAL(3) Manual de funciones de biblioteca PKCS7_DATAFINAL(3)

NOMBRE

PKCS7_dataFinal — mueve datos de una cadena BIO a un objeto ContentInfo

SINOPSIS

biblioteca “libcrypto”
#include <openssl/pkcs7.h>

int
PKCS7_dataFinal(PKCS7 *p7, BIO *chain);

DESCRIPCIÓN

PKCS7_dataFinal() transfiere los datos del BIO de memoria al final de la cadena dada al campo de contenido apropiado de p7 o de su subestructura apropiada. Típicamente se usa como el paso final para poblar p7, después de crear la cadena con PKCS7_dataInit(3) y después de escribir los datos en ella.

Después de llamar PKCS7_dataFinal(), el programa puede llamar BIO_free_all(3) en la cadena porque tales cadenas no están diseñadas para su reutilización.

Dependiendo del contentType de p7, PKCS7_dataFinal() establece los siguientes campos:

para SignedData o DigestedData:
en subestructuras del campo content de p7: el campo content en la estructura ContentInfo (a menos que p7 esté configurado para almacenar una firma desacoplada) y los campos encryptedDigest en todas las estructuras SignerInfo
para EnvelopedData o SignedAndEnvelopedData:
el campo encryptedContent en la estructura EncryptedContentInfo contenida en el campo content de p7
para datos arbitrarios:
el campo content del propio p7

VALORES DE RETORNO

PKCS7_dataFinal() devuelve 1 en caso de éxito o 0 en caso de fallo.

Razones posibles de fallo incluyen:

  • p7 es NULL.
  • El campo content de p7 está vacío.
  • El contentType de p7 no es compatible.
  • La cadena no contiene el BIO de memoria esperado.
  • Se solicita firma o digestión y p7 no está configurado para almacenar una firma desacoplada, pero tampoco contiene el campo requerido para almacenar el contenido.
  • Al menos un firmante carece de un algoritmo de digestión utilizable.
  • La firma o la digestión fallan.
  • Falla la asignación de memoria.

Los firmantes que carecen de claves privadas no provocan fallos, sino que se omiten silenciosamente.

VER TAMBIÉN

BIO_new(3), PKCS7_dataInit(3), PKCS7_final(3), PKCS7_new(3), PKCS7_sign(3)

HISTORIA

PKCS7_dataFinal() apareció por primera vez en SSLeay 0.9.1 y ha estado disponible desde OpenBSD 2.6.

ADVERTENCIAS

Esta función no soporta EncryptedData.

Aunque esta función se utiliza típicamente después de PKCS7_dataInit(3) y aunque PKCS7_dataInit(3) también soporta la lectura de estructuras ContentInfo que ya están completamente pobladas, no utilice PKCS7_dataFinal() en estructuras completamente pobladas. Solo está pensada para insertar datos en estructuras nuevas y no es ni necesaria ni adecuada para la lectura.
