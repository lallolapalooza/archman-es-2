libressl-X509v3_addr_inherits(3)

Paquete: libressl

Licencias: ISC, custom:OpenSSL

X509V3_ADDR_INHERITS(3) Manual de Funciones de Biblioteca X509V3_ADDR_INHERITS(3)

NOMBRE

X509v3_addr_inherits, X509v3_asid_inherits — Herencia RFC 3779

SINOPSIS

biblioteca “libcrypto”
#include <openssl/x509v3.h>

int
X509v3_addr_inherits(IPAddrBlocks *addrblocks);

int
X509v3_asid_inherits(ASIdentifiers *asids);

DESCRIPCIÓN

X509v3_addr_inherits() determina si existe al menos una familia de direcciones en addrblocks que utiliza la herencia.

X509v3_asid_inherits() está destinada a determinar si al menos uno de la lista de números de sistema autónomos o la lista de identificadores de enrutamiento utiliza la herencia.

VALORES DEVUELTOS

X509v3_addr_inherits() devuelve 1 si y solo si addrblocks contiene al menos un objeto IPAddressFamily que está correctamente marcado como "heredar": su IPAddressChoice es de tipo IPAddressChoice_inherit y su elemento inherit está presente. De lo contrario, devuelve 0.

X509v3_asid_inherits() devuelve 1 si y solo si al menos una de las listas asnum o rdi tiene tipo ASIdentifierChoice_inherit. De lo contrario, devuelve 0.

VER TAMBIÉN

ASIdentifiers_new(3), ASRange_new(3), crypto(3), IPAddressRange_new(3), X509_new(3), X509v3_addr_add_inherit(3), X509v3_asid_add_inherit(3)

ESTÁNDARES

RFC 3779: Extensiones X.509 para Direcciones IP y Identificadores AS:

  • sección 2: Extensión de delegación de direcciones IP
  • sección 2.2.3.5: Elemento inherit
  • sección 3: Extensión de delegación de identificadores AS
  • sección 3.2.3.3: Elemento inherit

HISTORIAL

Estas funciones aparecieron por primera vez en OpenSSL 0.9.8e y han estado disponibles desde OpenBSD 7.1.

ERRORES

X509v3_asid_inherits() ignora si el elemento inherit está presente o ausente en la lista que se considera que utiliza la herencia.

No hay una API que determine si todas las listas contenidas en un objeto ASIdentifiers o IPAddrBlocks heredan. Consulte RFC 9287, 5.1.2 para ver un ejemplo donde esto es relevante.
