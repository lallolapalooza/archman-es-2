libssh2_knownhost_writeline(3)

Paquete: libssh2

Licencias: BSD

libssh2_knownhost_writeline(3) libssh2 libssh2_knownhost_writeline(3)

NOMBRE

libssh2_knownhost_writeline - convierte un host conocido a una línea para su almacenamiento

SINOPSIS

#include <libssh2.h>
int
libssh2_knownhost_writeline(LIBSSH2_KNOWNHOSTS *hosts,
                            struct libssh2_knownhost *known,
                            char *buffer, size_t buflen,
                            size_t *outlen,
                            int type);

DESCRIPCIÓN

Convierte un host conocido individual a una línea de salida para su almacenamiento, utilizando el formato de salida 'type'.

known identifica qué host conocido en particular

buffer apunta a un búfer asignado

buflen es el tamaño del buffer. Ver VALOR DE RETORNO sobre el tamaño.

outlen debe ser un puntero a una variable size_t que recibirá la longitud de salida del fragmento de datos almacenado. El número no incluye el cero final.

type especifica qué tipo de archivo es, y LIBSSH2_KNOWNHOST_FILE_OPENSSH es el único formato actualmente soportado.

VALOR DE RETORNO

Devuelve un código de error regular de libssh2, donde los valores negativos son códigos de error y 0 indica éxito.

Si el búfer proporcionado se considera demasiado pequeño para contener los datos que libssh2 desea almacenar en él, se devolverá LIBSSH2_ERROR_BUFFER_TOO_SMALL. Se aconseja a la aplicación que vuelva a llamar a la función con un búfer más grande. El tamaño de outlen contendrá entonces el tamaño solicitado.

DISPONIBILIDAD

Añadido en libssh2 1.2
