NOMBRE

libnet - Una biblioteca C para la creación e inyección de paquetes

SINOPSIS

#include <libnet.h>

DESCRIPCIÓN

libnet es una biblioteca de ensamblaje de paquetes que proporciona una interfaz portable para la creación e inyección de paquetes.

Es una API de alto nivel que permite a un programador de aplicaciones construir e inyectar paquetes de red. libnet proporciona una interfaz simplificada para la conformación, manejo e inyección de paquetes de red de bajo nivel.

libnet oculta gran parte del tedio de la creación de paquetes al programador de aplicaciones, como la multiplexación, la gestión de búferes, la información arcana de las cabeceras de paquetes, el orden de bytes, los problemas dependientes del sistema operativo y mucho más. libnet ofrece interfaces portables de creación de paquetes a nivel de IP y de enlace, así como una gran cantidad de funcionalidad suplementaria y complementaria. Utilizando libnet, se pueden desarrollar rápidamente aplicaciones sencillas de ensamblaje de paquetes con poco esfuerzo. Con un poco más de tiempo, se pueden escribir programas más complejos (como traceroute(8) y ping(8), que se reescribieron fácilmente usando libnet y pcap(3).

Al construir aplicaciones con libnet, recomendamos usar pkg-config(1) para detectar la presencia y la versión requerida de libnet. El script libnet-config(1) todavía se incluye en la distribución de libnet, pero se considera obsoleto en favor de pkg-config(1). Ambos pueden usarse para obtener las banderas del compilador y del enlazador de la biblioteca libnet instalada, así como para proporcionar otra información útil. Para aplicaciones que utilizan las herramientas GNU autotools, recomendamos usar las macros m4 PKG_PROG_PKG_CONFIG y PKG_CHECK_MODULES.

NOTA: Si está escribiendo su aplicación con libnet, incluya libnet.h, que incluirá cualquier encabezado adicional por usted, en lugar de incluir libnet/libnet-functions.h, libnet/libnet-macros.h o cualquiera de los otros.

COMPATIBILIDAD INVERSA

Su código antiguo (circa libnet 1.0.x) NO FUNCIONARÁ con libnet >= 1.1.x. Consulte doc/MIGRATION.md para conocer los pasos sencillos para portar su código antiguo.
