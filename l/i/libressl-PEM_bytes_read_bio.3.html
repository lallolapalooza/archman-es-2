PEM_BYTES_READ_BIO(3) Manual de funciones de la biblioteca PEM_BYTES_READ_BIO(3)

NOMBRE

PEM_bytes_read_bio — lee una estructura de datos codificada en PEM de un BIO

SINOPSIS

biblioteca «libcrypto»
#include <openssl/pem.h>

int
PEM_bytes_read_bio(unsigned char **pdata, long *plen, char **pnm, const char *name, BIO *in_bp, pem_password_cb *cb, void *u);

DESCRIPCIÓN

PEM_bytes_read_bio() lee y decodifica PEM el primer objeto de tipo name (por ejemplo, RSA PRIVATE KEY, CERTIFICATE, etc.) de in_bp. Si hay múltiples estructuras de datos codificadas en PEM en el mismo flujo, salta los tipos de datos que no coinciden y continúa leyendo. Antes de leer cada objeto PEM, también se omiten las líneas que no comienzan con "-----BEGIN "; consulte PEM_read_bio(3) para obtener detalles del análisis PEM.

La cabecera PEM puede indicar que los siguientes datos están cifrados; si es así, los datos se descifran, utilizando opcionalmente cb y u, como se describe en pem_password_cb(3).

Algunos tipos de datos tienen alias de compatibilidad, como un archivo que contiene X509 CERTIFICATE y que coincide con una solicitud del tipo obsoleto CERTIFICATE. El tipo real indicado por el archivo se devuelve en *pnm si pnm no es NULL. El llamador debe liberar el almacenamiento apuntado por *pnm.

Los datos devueltos son la forma codificada DER del tipo solicitado, en *pdata con longitud *plen. El llamador debe liberar el almacenamiento apuntado por *pdata.

VALORES DE RETORNO

PEM_bytes_read_bio() devuelve 1 para éxito o 0 para fallo.

ERRORES

Los diagnósticos que se pueden recuperar con ERR_get_error(3), ERR_GET_REASON(3), y ERR_reason_error_string(3) incluyen:

PEM_R_NO_START_LINE "no start line"
No se encontraron más objetos PEM en la entrada. Esto puede ocurrir cuando la entrada no contiene ningún objeto PEM, o solo objetos que no coinciden con el tipo name.
PEM_R_NOT_PROC_TYPE "not proc type"
La primera cabecera PEM no comienza con "Proc-Type: ".
PEM_R_NOT_ENCRYPTED "not encrypted"
La cabecera Proc-Type difiere de "4,ENCRYPTED".
PEM_R_SHORT_HEADER "short header"
La cabecera Proc-Type es la última línea de cabecera.
PEM_R_NOT_DEK_INFO "not dek info"
La segunda cabecera PEM no comienza con "DEK-Info: ".
PEM_R_UNSUPPORTED_ENCRYPTION "unsupported encryption"
El nombre del cifrado dado en la cabecera DEK-Info es desconocido para EVP_get_cipherbyname(3).
PEM_R_BAD_IV_CHARS "bad iv chars"
La palabra que sigue al nombre del cifrado en la cabecera DEK-Info contiene bytes que no son dígitos hexadecimales. Esto también ocurre cuando el vector de inicialización está ausente o es demasiado corto.
PEM_R_BAD_PASSWORD_READ "bad password read"
cb reportó un fallo. Esto puede ocurrir, por ejemplo, cuando el usuario escribe mal la contraseña.
PEM_R_BAD_DECRYPT "bad decrypt"
EVP_DecryptInit_ex(3), EVP_DecryptUpdate(3), o EVP_DecryptFinal_ex(3) fallaron.

Tipos adicionales de errores pueden resultar de PEM_read_bio(3).
