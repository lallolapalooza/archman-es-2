NOMBRE

X509_check_purpose — comprobar el uso previsto de una clave pública

SINOPSIS

biblioteca “libcrypto”
#include <openssl/x509v3.h>

int
X509_check_purpose(X509 *certificate, int purpose, int ca);

DESCRIPCIÓN

Si el argumento purpose es -1, X509_check_purpose() ignora el argumento ca y comprueba que todas las extensiones del certificate se puedan analizar y superen comprobaciones de cordura mínimas, asegurando que ninguna extensión ocurra más de una vez. También se asegura de que todas las extensiones estén almacenadas en caché en el objeto X509.

Si el argumento purpose no es -1 y el indicador ca es 0, X509_check_purpose() también comprueba si la clave pública contenida en el certificate está destinada a ser utilizada para el purpose dado, que puede ser una de las siguientes constantes enteras. La comprobación tiene éxito si no se viola ninguna de las condiciones dadas en la lista a continuación. Siempre falla si el análisis falla para cualquier extensión contenida en el certificate.

X509_PURPOSE_SSL_CLIENT
  • Si el certificate contiene una extensión de Uso de Clave Extendida, contiene el propósito RFC 5280 "Autenticación de cliente WWW TLS" (NID_client_auth).
  • Si el certificate contiene una extensión de Uso de Clave, el bit de digitalSignature está establecido.
  • Si el certificate contiene una extensión de Tipo de Certificado Netscape, el bit de "Certificado de cliente SSL" está establecido (NS_SSL_CLIENT).
X509_PURPOSE_SSL_SERVER
  • Si el certificate contiene una extensión de Uso de Clave Extendida, contiene el propósito RFC 5280 "Autenticación de servidor WWW TLS" (NID_server_auth) o el propósito privado "Netscape Server Gated Crypto" (NID_ns_sgc) o "Microsoft Server Gated Crypto" (NID_ms_sgc).
  • Si el certificate contiene una extensión de Uso de Clave, al menos uno de los bits digitalSignature y keyEncipherment está establecido.
  • Si el certificate contiene una extensión de Tipo de Certificado Netscape, el bit de "Certificado de servidor SSL" está establecido (NS_SSL_SERVER)
X509_PURPOSE_NS_SSL_SERVER
Esto realiza las mismas comprobaciones que X509_PURPOSE_SSL_SERVER y, además, requiere que una extensión de Uso de Clave, si está presente, tenga el bit de keyEncipherment establecido.
X509_PURPOSE_SMIME_SIGN
  • Si el certificate contiene una extensión de Uso de Clave Extendida, contiene el propósito RFC 5280 "Protección de correo electrónico" (NID_email_protect).
  • Si el certificate contiene una extensión de Uso de Clave, al menos uno de los bits digitalSignature y nonRepudiation está establecido.
  • Si el certificate contiene una extensión de Tipo de Certificado Netscape, tiene el bit de "Certificado S/MIME" establecido. Si el bit de "Certificado de cliente SSL" está establecido pero el bit de "Certificado S/MIME" no lo está, no se toma ninguna decisión.
X509_PURPOSE_SMIME_ENCRYPT
  • Si el certificate contiene una extensión de Uso de Clave Extendida, contiene el propósito RFC 5280 "Protección de correo electrónico" (NID_email_protect).
  • Si el certificate contiene una extensión de Uso de Clave, el bit de keyEncipherment está establecido.
  • Si el certificate contiene una extensión de Tipo de Certificado Netscape, tiene el bit de "Certificado S/MIME" establecido. Si el bit de "Certificado de cliente SSL" está establecido pero el bit de "Certificado S/MIME" no lo está, no se toma ninguna decisión.
X509_PURPOSE_CRL_SIGN
  • Si el certificate contiene una extensión de Uso de Clave, el bit de cRLSign está establecido.
X509_PURPOSE_ANY
No se requiere nada más que, si hay extensiones presentes, su análisis sea exitoso.
X509_PURPOSE_OCSP_HELPER
No se requiere nada más que, si hay extensiones presentes, su análisis sea exitoso. Se espera que el programa de aplicación realice la comprobación real por otros medios.
X509_PURPOSE_TIMESTAMP_SIGN
  • El certificate contiene una extensión de Uso de Clave Extendida que contiene el propósito RFC 5280 "Sellado de tiempo" y ningún otro propósito. Esta extensión está marcada como crítica.
  • Si el certificate contiene una extensión de Uso de Clave, al menos uno de los bits digitalSignature y nonRepudiation está establecido, y ningún otro bit está establecido.

Si el argumento purpose no es -1 y el indicador ca no es cero, X509_check_purpose() comprueba, además de las comprobaciones de cordura mínimas, si el certificate puede usarse como certificado de autoridad de certificación en el contexto del purpose dado. Para tener éxito, la comprobación siempre requiere que no se viole ninguna de las siguientes condiciones:

  • Si el certificate contiene alguna extensión, su análisis tiene éxito.
  • Si el certificate contiene una extensión de Uso de Clave, el bit de keyCertSign está establecido.
  • Si el certificate contiene una extensión de Restricciones Básicas, el campo cA está establecido.
  • Si el certificate es un certificado de versión 1, el nombre del sujeto coincide con el nombre del emisor y el certificado se autofirma.

NOMBRE

X509_check_purpose, X509_PURPOSE_add(3), X509_PURPOSE_set(3), X509_check_host(3), X509_check_email(3)

comprobar el propósito de un certificado X509

SINOPSIS

#include <openssl/x509v3.h>

int X509_check_purpose(X509 *cert, int purpose, int ca);

DESCRIPCIÓN

La función X509_check_purpose() comprueba si el cert puede ser utilizado para el propósito especificado por purpose. El parámetro ca es un indicador que especifica si el cert se está utilizando como un certificado de autoridad de certificación (CA) o no.

Los valores de propósito predefinidos son:

X509_PURPOSE_SSL_CLIENT o X509_PURPOSE_NS_SSL_CLIENT
  • Si el certificado contiene una extensión de Uso de Clave Extendida, contiene el propósito RFC 5280 "Autenticación de cliente TLS WWW" (NID_client_auth).
  • Si el certificado no es un certificado de versión 1 y no contiene una extensión de Restricciones Básicas, contiene una extensión de Uso de Clave con el bit keyCertSign establecido o una extensión de Tipo de Certificado Netscape con el bit "Certificado de CA SSL" establecido.
X509_PURPOSE_SSL_SERVER o X509_PURPOSE_NS_SSL_SERVER
  • Si el certificado contiene una extensión de Uso de Clave Extendida, contiene el propósito RFC 5280 "Autenticación de servidor TLS WWW" (NID_server_auth) o el propósito privado "Netscape Server Gated Crypto" (NID_ns_sgc) o "Microsoft Server Gated Crypto" (NID_ms_sgc).
  • Si el certificado no es un certificado de versión 1 y no contiene una extensión de Restricciones Básicas, contiene una extensión de Uso de Clave con el bit keyCertSign establecido o una extensión de Tipo de Certificado Netscape con el bit "Certificado de CA SSL" establecido.
X509_PURPOSE_SMIME_SIGN o X509_PURPOSE_SMIME_ENCRYPT
  • Si el certificado contiene una extensión de Uso de Clave Extendida, contiene el propósito RFC 5280 "Protección de correo electrónico" (NID_email_protect).
  • Si el certificado no es un certificado de versión 1 y no contiene una extensión de Restricciones Básicas, contiene una extensión de Uso de Clave con el bit keyCertSign establecido o una extensión de Tipo de Certificado Netscape con el bit "Certificado de CA S/MIME" establecido.
X509_PURPOSE_CRL_SIGN, X509_PURPOSE_OCSP_HELPER, o X509_PURPOSE_TIMESTAMP_SIGN
  • Si el certificado no es un certificado de versión 1 y no contiene una extensión de Restricciones Básicas, contiene una extensión de Uso de Clave con el bit keyCertSign establecido o una extensión de Tipo de Certificado Netscape con al menos uno de los bits "Certificado de CA SSL", "Certificado de CA S/MIME", o "Certificado de CA de firma de objetos" establecido.
X509_PURPOSE_ANY
No se requiere nada excepto que, si hay alguna extensión presente, su análisis debe tener éxito. La comprobación incluso tiene éxito si las tres condiciones comunes citadas anteriormente en esta lista se violan.

Si la función X509_PURPOSE_add(3) se llamó antes que X509_check_purpose(), puede haber instalado funciones de comprobación diferentes, definidas por el usuario, para algunos de los propósitos estándar listados anteriormente, o puede haber instalado funciones de comprobación adicionales, definidas por el usuario, para identificadores de propósito definidos por el usuario no listados anteriormente.

VALORES DE RETORNO

Si el análisis de las extensiones del certificado falla, las comprobaciones de integridad fallan o el propósito es inválido, X509_check_purpose() devuelve -1 para indicar el error.

Si el argumento purpose es -1 y el análisis y las comprobaciones de integridad mínimas tienen éxito, X509_check_purpose() devuelve 1 para indicar éxito.

De lo contrario, devuelve los siguientes valores:

Si ca es 0:

0 Fallo El certificado no se puede utilizar para el propósito.
1 Éxito El certificado se puede utilizar para el propósito.
2 Desconocido No se puede tomar ninguna decisión.

Si ca no es cero:

0 Fallo El certificado no se puede utilizar como una CA para el propósito.
1 Éxito El certificado se puede utilizar como una CA para el propósito.
3 Éxito El certificado es una CA de versión 1.
4 Éxito El Uso de Clave permite keyCertSign.
5 Éxito Un Tipo de Certificado Netscape permite su uso como CA.
