X509_STORE_CTX_SET_FLAGS(3) Manual de funciones de la biblioteca X509_STORE_CTX_SET_FLAGS(3)

NOMBRE

X509_STORE_CTX_set_flags, X509_STORE_CTX_set_time, X509_STORE_CTX_set_depth, X509_STORE_CTX_set_trust, X509_STORE_CTX_set_purpose, X509_STORE_CTX_get0_param, X509_STORE_CTX_set0_param, X509_STORE_CTX_set_default — Inicialización de parámetros de X509_STORE_CTX

SINOPSIS

biblioteca “libcrypto”
#include <openssl/x509_vfy.h>

void
X509_STORE_CTX_set_flags(X509_STORE_CTX *ctx, unsigned long flags);

void
X509_STORE_CTX_set_time(X509_STORE_CTX *ctx, unsigned long dummy, time_t time);

void
X509_STORE_CTX_set_depth(X509_STORE_CTX *ctx, int depth);

int
X509_STORE_CTX_set_trust(X509_STORE_CTX *ctx, int trust);

int
X509_STORE_CTX_set_purpose(X509_STORE_CTX *ctx, int purpose);

X509_VERIFY_PARAM *
X509_STORE_CTX_get0_param(X509_STORE_CTX *ctx);

void
X509_STORE_CTX_set0_param(X509_STORE_CTX *ctx, X509_VERIFY_PARAM *param);

int
X509_STORE_CTX_set_default(X509_STORE_CTX *ctx, const char *name);

DESCRIPCIÓN

Estas funciones operan sobre el objeto X509_VERIFY_PARAM utilizado por ctx. Normalmente, se llama a X509_STORE_CTX_init(3) sobre ctx antes de estas funciones, y a X509_verify_cert(3) después.

X509_STORE_CTX_set_flags() establece las banderas de parámetros de verificación internos a flags. Consulte X509_VERIFY_PARAM_set_flags(3) para obtener una descripción de las banderas de verificación.

X509_STORE_CTX_set_time() establece la hora de verificación utilizando X509_VERIFY_PARAM_set_time(3). El argumento dummy se ignora.

X509_STORE_CTX_set_depth() establece la profundidad máxima de verificación utilizando X509_VERIFY_PARAM_set_depth(3). Este es el número máximo de certificados CA no confiables que pueden aparecer en una cadena.

X509_STORE_CTX_set_trust() establece el identificador de confianza que también se puede establecer utilizando X509_VERIFY_PARAM_set_trust(3). Si el argumento trust es 0 o inválido, o si el identificador de confianza ya está establecido en un valor distinto de cero en el objeto X509_VERIFY_PARAM, no se realiza ninguna acción.

X509_STORE_CTX_set_purpose() establece el identificador de propósito que también se puede establecer utilizando X509_VERIFY_PARAM_set_purpose(3). Si el argumento purpose es 0 o si ocurre algún error, no se modifica nada.

En lo siguiente, el identificador de confianza contenido en el objeto X509_PURPOSE asociado con purpose se denomina la “confianza asociada”.

La función falla si el argumento purpose o la confianza asociada son inválidos pero no 0; de lo contrario, X509_STORE_CTX_set_purpose() realiza también el equivalente a llamar a X509_STORE_CTX_set_trust() con la confianza asociada.

Si el identificador de propósito ya está establecido en un valor distinto de cero en el objeto X509_VERIFY_PARAM, no se cambia, incluso si el argumento purpose también es válido.

X509_STORE_CTX_get0_param() recupera un puntero interno a los parámetros de verificación asociados con ctx.

X509_STORE_CTX_set0_param() establece el puntero interno de parámetros de verificación a param. Después de esta llamada, param no debe usarse.

X509_STORE_CTX_set_default() busca y establece el método de verificación predeterminado a name. Esto utiliza la función X509_VERIFY_PARAM_lookup(3) para encontrar un conjunto apropiado de parámetros de name y los copia utilizando X509_VERIFY_PARAM_inherit(3).

VALORES DE RETORNO

X509_STORE_CTX_set_trust() devuelve 1 si el argumento trust es 0 o válido, o 0 si es inválido pero no 0. Un valor de retorno de 1 no implica que el identificador de confianza almacenado en el objeto X509_VERIFY_PARAM fue cambiado.

X509_STORE_CTX_set_purpose() devuelve 1 si tanto el argumento purpose como la confianza asociada son 0 o válidos. Devuelve 0 si el argumento purpose o la confianza asociada son inválidos pero no 0. Un valor de retorno de 1 no implica que se modificaran datos.

X509_STORE_CTX_get0_param() devuelve un puntero a una estructura X509_VERIFY_PARAM o NULL si ocurrió un error.

X509_STORE_CTX_set_default() devuelve 1 para éxito o 0 si ocurrió un error.

ERRORES

Los siguientes diagnósticos se pueden recuperar con ERR_get_error(3), ERR_GET_REASON(3) y ERR_reason_error_string(3):

X509_R_UNKNOWN_TRUST_ID "id de confianza desconocido"
X509_STORE_CTX_set_trust() fue llamado con un argumento trust que es inválido pero no 0. Otras implementaciones también pueden devolver esto cuando X509_STORE_CTX_set_purpose() se llama con un argumento purpose con confianza asociada inválida.
X509_R_UNKNOWN_PURPOSE_ID "id de propósito desconocido"
El argumento purpose es inválido pero no 0.

Las otras funciones no proporcionan diagnósticos.

HISTORIA

X509_STORE_CTX_set_depth() apareció por primera vez en OpenSSL 0.9.3 y ha estado disponible desde OpenBSD 2.4.

X509_STORE_CTX_set_trust() y X509_STORE_CTX_set_purpose() aparecieron por primera vez en OpenSSL 0.9.5 y han estado disponibles desde OpenBSD 2.7.

X509_STORE_CTX_set_flags() y X509_STORE_CTX_set_time() aparecieron por primera vez en OpenSSL 0.9.6 y han estado disponibles desde OpenBSD 2.9.

X509_STORE_CTX_get0_param(), X509_STORE_CTX_set0_param() y X509_STORE_CTX_set_default() aparecieron por primera vez en OpenSSL 0.9.8 y han estado disponibles desde OpenBSD 4.5.

ADVERTENCIAS

El efecto preciso de una llamada exitosa a X509_STORE_CTX_set_trust() y X509_STORE_CTX_set_purpose() no está claro a menos que solo se utilice una de estas funciones inmediatamente después de X509_STORE_CTX_init(3). Por lo tanto, se recomienda utilizar X509_STORE_CTX_get0_param(), X509_VERIFY_PARAM_set_trust(3) y X509_VERIFY_PARAM_set_purpose(3) en su lugar.
