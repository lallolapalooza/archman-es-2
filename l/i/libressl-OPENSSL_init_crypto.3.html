libressl-OPENSSL_init_crypto(3)

Paquete: libressl

Licencias: ISC, custom:OpenSSL

OPENSSL_INIT_CRYPTO(3) Manual de funciones de la biblioteca OPENSSL_INIT_CRYPTO(3)

NOMBRE

OPENSSL_init_crypto, OPENSSL_init — inicializa la biblioteca criptográfica

SINOPSIS

biblioteca «libcrypto»
#include <openssl/crypto.h>

int
OPENSSL_init_crypto(uint64_t options, const void *dummy);

void
OPENSSL_init(void);

DESCRIPCIÓN

Estas funciones están obsoletas. Nunca es útil que un programa de aplicación llame explícitamente a ninguna de ellas.

La biblioteca llama automáticamente a OPENSSL_init_crypto() internamente con un argumento options de 0 cuando es necesario. Es más seguro asumir que cualquier función puede hacerlo.

Para habilitar o deshabilitar el archivo de configuración estándar, use en su lugar OPENSSL_config(3) o OPENSSL_no_config(3), respectivamente. Para cargar un archivo de configuración no estándar, consulte CONF_modules_load_file(3).

Si OPENSSL_init_crypto() se llama antes que cualquier otra función criptográfica o ssl, la biblioteca criptográfica se inicializa asignando varios recursos internos, en particular llamando a ERR_load_crypto_strings(3).

Las siguientes options son compatibles:

OPENSSL_INIT_LOAD_CONFIG
Al final de la inicialización, llama a OPENSSL_config(3) con un argumento NULL, cargando el archivo de configuración predeterminado.
OPENSSL_INIT_NO_LOAD_CONFIG
Ignora cualquier llamada posterior a OPENSSL_config(3).

Las otras banderas de options definidas por OpenSSL son ignoradas por LibreSSL. El argumento dummy no tiene ningún efecto.

Si esta función se llama más de una vez, ninguna de las llamadas excepto la primera tiene ningún efecto.

OPENSSL_init() no tiene ningún efecto en absoluto.

VALORES DE RETORNO

OPENSSL_init_crypto() tiene la intención de devolver 1 en caso de éxito o 0 en caso de error.

VER TAMBIÉN

CONF_modules_load_file(3), OPENSSL_config(3), openssl.cnf(5)

HISTORIA

OPENSSL_init() apareció por primera vez en OpenSSL 1.0.0e y ha estado disponible desde OpenBSD 5.3. Dejó de tener efecto en OpenSSL 1.1.1 y en OpenBSD 5.6.

OPENSSL_init_crypto() apareció por primera vez en OpenSSL 1.1.0 y ha estado disponible desde OpenBSD 6.3.

ERRORES

OPENSSL_init_crypto() ignora silenciosamente casi todo tipo de errores. En particular, si falla la asignación de memoria, la inicialización probablemente permanecerá incompleta, la biblioteca puede estar en un estado interno inconsistente, pero el valor de retorno generalmente indicará éxito de todos modos. No hay forma para que el programa de aplicación sepa si la inicialización de la biblioteca está realmente completa, ni para volver a un estado consistente si no lo está.
