DESCRIPCIÓN

SSL_CTX_set1_groups() establece los grupos compatibles para ctx a los glistlen grupos del array glist. El array consiste en NIDs de grupo en orden de preferencia. Para un cliente TLS, los grupos se utilizan directamente en la extensión de grupos compatibles. Para un servidor TLS, los grupos se utilizan para determinar el conjunto de grupos compartidos.

SSL_CTX_set1_groups_list() establece los grupos compatibles para ctx a la representación de list como una lista separada por dos puntos de NIDs o nombres de grupo, por ejemplo, "P-521:P-384:P-256".

SSL_set1_groups() y SSL_set1_groups_list() son similares excepto que establecen los grupos compatibles solo para la estructura SSL ssl.

Las funciones de curva son sinónimos obsoletos de las funciones de grupo con el mismo nombre y son idénticas en todos los aspectos excepto que se implementan como macros. Existen porque antes de TLS1.3, solo existía el concepto de curvas compatibles. En TLS1.3, esto se renombró a grupos compatibles y se amplió para incluir grupos Diffie Hellman.

Si una aplicación desea hacer uso de varias de estas funciones con fines de configuración, ya sea en una línea de comandos o en un archivo, debería considerar usar la interfaz SSL_CONF en lugar de analizar manualmente las opciones.

VALORES DE RETORNO

Todas estas funciones devuelven 1 en caso de éxito o 0 en caso de fallo.

VER TAMBIÉN

HISTORIAL

Las funciones de curva aparecieron por primera vez en OpenSSL 1.0.2 y las funciones de grupo en OpenSSL 1.1.1. Ambas han estado disponibles desde OpenBSD 6.1.
