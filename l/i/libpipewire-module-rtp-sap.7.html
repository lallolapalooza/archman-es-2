NOMBRE

libpipewire-module-rtp-sap - Anuncia SAP y crea flujos RTP

DESCRIPCIÓN

El módulo rtp-sap anuncia flujos RTP que coinciden con las reglas con la acción announce-stream.

Creará flujos RTP de origen que se anuncian con SAP cuando coinciden con la regla con la acción create-stream.

Si no se proporcionan stream.rules, anunciará todos los flujos con sess.sap.announce = true y creará un receptor para todos los flujos anunciados.

NOMBRE DEL MÓDULO

libpipewire-module-rtp-sap

OPCIONES DEL MÓDULO

Opciones específicas del comportamiento de este módulo

  • local.ifname = <str>: nombre de la interfaz a usar
  • sap.ip = <str>: dirección IP de los mensajes SAP, por defecto "224.0.0.56"
  • sap.port = <int>: puerto de los mensajes SAP, por defecto 9875
  • sap.cleanup.sec = <int>: intervalo de limpieza en segundos, por defecto 90 segundos
  • source.ip =<str>: dirección IP de origen, por defecto "0.0.0.0"
  • net.ttl = <int>: TTL a usar, por defecto 1
  • net.loop = <bool>: loopback multicast, por defecto falso
  • stream.rules = <rules>: reglas de coincidencia, usa las acciones create-stream y announce-stream
  • sap.max-sessions = <int>: número máximo de sesiones concurrentes de envío/recepción a rastrear
  • sap.preamble-extra = [strings]: atributos adicionales para añadir a la preámbulo atómico SDP
  • sap.end-extra = [strings]: atributos adicionales para añadir al final del mensaje SDP

OPCIONES GENERALES

Opciones con comportamiento bien conocido:

•
remote.name

EJEMPLO DE CONFIGURACIÓN

# ~/.config/pipewire/pipewire.conf.d/my-rtp-sap.conf
context.modules = [
{   name = libpipewire-module-rtp-sap
    args = {
        #local.ifname = "eth0"
        #sap.ip = "224.0.0.56"
        #sap.port = 9875
        #sap.cleanup.sec = 5
        #source.ip = "0.0.0.0"
        #net.ttl = 1
        #net.loop = false
        stream.rules = [
            {   matches = [
                    # cualquiera de los elementos en matches necesita coincidir, si uno lo hace,
                    # se emiten acciones.
                    {   # todas las claves deben coincidir con el valor. ! niega. ~ inicia regex.
                        #rtp.origin = "wim 3883629975 0 IN IP4 0.0.0.0"
                        #rtp.payload = "127"
                        #rtp.fmt = "L16/48000/2"
                        #rtp.session = "PipeWire RTP Stream on fedora"
                        #rtp.ts-offset = 0
                        #rtp.ts-refclk = "private"
                        sess.sap.announce = true
                    }
                ]
                actions = {
                    announce-stream = {
                    }
                }
            }
            {   matches = [
                    {   # todas las claves deben coincidir con el valor. ! niega. ~ inicia regex.
                        #rtp.origin = "wim 3883629975 0 IN IP4 0.0.0.0"
                        #rtp.payload = "127"
                        #rtp.fmt = "L16/48000/2"
                        #rtp.session = "PipeWire RTP Stream on fedora"
                        #rtp.ts-offset = 0
                        #rtp.ts-refclk = "private"
                        rtp.session = "~.*"
                    }
                ]
                actions = {
                    create-stream = {
                        #sess.latency.msec = 100
                        #sess.ts-direct = false
                        #target.object = ""
                    }
                }
            }
        ]
    }
}
