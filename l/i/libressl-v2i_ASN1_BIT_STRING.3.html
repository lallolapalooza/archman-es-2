V2I_ASN1_BIT_STRING(3) Manual de Funciones de Biblioteca V2I_ASN1_BIT_STRING(3)

NOMBRE

v2i_ASN1_BIT_STRING, i2v_ASN1_BIT_STRING — Funciones de utilidad ASN.1 BIT STRING para extensiones de certificados

SINOPSIS

biblioteca “libcrypto”
#include <openssl/x509v3.h>

ASN1_BIT_STRING *
v2i_ASN1_BIT_STRING(X509V3_EXT_METHOD *method, X509V3_CTX *ctx, STACK_OF(CONF_VALUE) *nval);

STACK_OF(CONF_VALUE) *
i2v_ASN1_BIT_STRING(X509V3_EXT_METHOD *method, ASN1_BIT_STRING *bit_string, STACK_OF(CONF_VALUE) *nval);

DESCRIPCIÓN

v2i_ASN1_BIT_STRING() asigna un nuevo objeto ASN.1 BIT STRING y lo inicializa a partir de una lista de nombres de bits. El argumento nval se utiliza esencialmente como la lista de los nombres de los bits a establecer. Se pueden usar tanto nombres largos como nombres cortos. Se toma un nombre de cada elemento de nval. El argumento ctx y cualquier nombre de sección o valor contenido en los elementos de nval se ignoran. Para convertir una cadena C que contiene una lista de nombres separada por comas al formato de entrada de esta función, se puede usar X509V3_parse_list(3).

i2v_ASN1_BIT_STRING() traduce los números de los bits que están establecidos en el bit_string a nombres largos. Por cada bit que está establecido, se agrega un elemento que contiene el nombre largo correspondiente a nval. Si se pasa un puntero NULL para el argumento nval, se asignará un nuevo STACK_OF(CONF_VALUE).

Para ambas funciones, el argumento method solo se utiliza para la traducción de nombres de bits a números de bits y viceversa. Cualquier nombre y número de bit que no aparezca en la tabla de traducción usr_data en el method se ignorará silenciosamente.

Para los siguientes argumentos, X509V3_EXT_get_nid(3) devuelve objetos constantes estáticos method que soportan estas funciones:

NID_crl_reason
códigos de razón, RFC 5280 sección 5.3.1
NID_key_usage
propósitos de uso de clave, RFC 5280 sección 4.2.1.3
NID_netscape_cert_type
tipos de certificado Netscape (obsoleto)

Si bien una aplicación podría teóricamente proporcionar su propio objeto method que contenga una tabla de traducción personalizada, es poco probable que sea útil para algún propósito práctico.

VALORES DE RETORNO

v2i_ASN1_BIT_STRING() devuelve el nuevo objeto BIT STRING y i2v_ASN1_BIT_STRING() la lista de nombres de bits modificada o nueva. Ambas funciones devuelven NULL si ocurre un error, en particular si falla la asignación de memoria.

VER TAMBIÉN

ASN1_BIT_STRING_new(3), ASN1_BIT_STRING_set(3), i2s_ASN1_ENUMERATED_TABLE(3), STACK_OF(3), tls_peer_ocsp_crl_reason(3), X509_get_key_usage(3), X509V3_EXT_get_nid(3), X509V3_get_d2i(3), X509V3_parse_list(3)

HISTORIA

Estas funciones aparecieron por primera vez en OpenSSL 0.9.8 y han estado disponibles desde OpenBSD 4.5.
