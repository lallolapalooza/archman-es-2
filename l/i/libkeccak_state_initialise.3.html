NOMBRE

libkeccak_state_initialise - Inicializar estado del hash

SINOPSIS

#include <libkeccak.h>
int libkeccak_state_initialise(struct libkeccak_state *state, const struct libkeccak_spec *spec);

Enlazar con -lkeccak.

DESCRIPCIÓN

La función libkeccak_state_initialise() inicializa *state y establece los parámetros de ajuste del algoritmo a los especificados por *spec.

VALORES DEVUELTOS

La función libkeccak_state_initialise() devuelve 0 en caso de éxito. En caso de error, devuelve -1 y establece errno para describir el error.

ERRORES

La función libkeccak_state_initialise() puede fallar por cualquier motivo especificado para la función malloc(3).
