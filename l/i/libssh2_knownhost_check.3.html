libssh2_knownhost_check(3)

Paquete: libssh2

Licencias: BSD

libssh2_knownhost_check(3) libssh2 libssh2_knownhost_check(3)

NOMBRE

libssh2_knownhost_check - comprobar un host y su clave contra la lista de hosts conocidos

SINOPSIS

#include <libssh2.h>
int
libssh2_knownhost_check(LIBSSH2_KNOWNHOSTS *hosts,
                        const char *host,
                        const char *key, size_t keylen,
                        int typemask,
                        struct libssh2_knownhost **knownhost);

DESCRIPCIÓN

Comprueba un host y su clave asociada contra la colección de hosts conocidos, y devuelve información sobre la entrada coincidentes (parcialmente).

host es un puntero al nombre del host en texto plano. El nombre del host puede ser la dirección numérica IP del host o el nombre completo.

key es un puntero a la clave del host dado.

keylen es el tamaño total en bytes de la clave a la que apunta el argumento key.

typemask es una máscara de bits que especifica el formato y la información sobre los datos pasados a esta función. Específicamente, detalla en qué formato está el nombre del host, en qué formato está la clave y qué tipo de clave es.

El nombre del host se proporciona como uno de los siguientes tipos: LIBSSH2_KNOWNHOST_TYPE_PLAIN o LIBSSH2_KNOWNHOST_TYPE_CUSTOM.

La clave está codificada utilizando una de las siguientes codificaciones: LIBSSH2_KNOWNHOST_KEYENC_RAW o LIBSSH2_KNOWNHOST_KEYENC_BASE64.

knownhost, si se establece en no nulo, debe ser un puntero a un puntero de 'struct libssh2_knownhost' que se rellena para apuntar a información sobre un host conocido que coincide o coincide parcialmente.

VALOR DE RETORNO

libssh2_knownhost_check(3) devuelve información sobre qué tan bien el par host + clave proporcionado coincidió con una de las entradas en la lista de hosts conocidos.

LIBSSH2_KNOWNHOST_CHECK_FAILURE - algo impidió que se realizara la comprobación

LIBSSH2_KNOWNHOST_CHECK_NOTFOUND - no se encontró ninguna coincidencia de host

LIBSSH2_KNOWNHOST_CHECK_MATCH - los hosts y las claves coinciden.

LIBSSH2_KNOWNHOST_CHECK_MISMATCH - se encontró el host, ¡pero las claves no coincidieron!

DISPONIBILIDAD

Añadido en libssh2 1.2

EJEMPLO

Consulte el ejemplo ssh2_exec.c proporcionado en el archivo tarball.
