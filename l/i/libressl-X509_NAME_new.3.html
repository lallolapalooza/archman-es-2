X509_NAME_NEW(3) Manual de funciones de la biblioteca X509_NAME_NEW(3)

NOMBRE

X509_NAME_new, X509_NAME_free — Objeto de Nombre X.501

SINÓPSIS

biblioteca “libcrypto”
#include <openssl/x509.h>

X509_NAME *
X509_NAME_new(void);

void
X509_NAME_free(X509_NAME *name);

DESCRIPCIÓN

Un Nombre X.501 es una secuencia ordenada de nombres distintos relativos. Un nombre distinto relativo es un conjunto de pares clave-valor; véase X509_NAME_ENTRY_new(3) para más detalles.

Varias estructuras X.509 contienen subestructuras de Nombre X.501. Se utilizan, por ejemplo, para los emisores de certificados y listas de revocación de certificados, y para los sujetos de certificados y solicitudes de certificados.

X509_NAME_new() asigna e inicializa un objeto X509_NAME vacío, representando una estructura Name ASN.1 definida en la sección 4.1.2.4 de la RFC 5280. Se pueden añadir datos a dichos objetos con las funciones descritas en X509_NAME_add_entry_by_txt(3), y se pueden inspeccionar con las funciones descritas en X509_NAME_get_index_by_NID(3).

X509_NAME_free() libera name y todos los objetos X509_NAME_ENTRY que contiene. Si name es un puntero NULL, no se realiza ninguna acción.

VALORES DEVUELTOS

X509_NAME_new() devuelve un nuevo objeto X509_NAME o NULL si ocurrió un error.
