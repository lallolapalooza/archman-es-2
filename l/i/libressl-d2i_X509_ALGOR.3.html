libressl-d2i_X509_ALGOR(3)

Paquete: libressl

Licencias: ISC, custom:OpenSSL

D2I_X509_ALGOR(3) Manual de funciones de biblioteca D2I_X509_ALGOR(3)

NOMBRE

d2i_X509_ALGOR, i2d_X509_ALGOR, d2i_X509_ALGORS, i2d_X509_ALGORS — decodificar y codificar identificadores de algoritmo

SINOPSIS

biblioteca “libcrypto”
#include <openssl/x509.h>

X509_ALGOR *
d2i_X509_ALGOR(X509_ALGOR **val_out, const unsigned char **der_in, long length);

int
i2d_X509_ALGOR(X509_ALGOR *val_in, unsigned char **der_out);

X509_ALGORS *
d2i_X509_ALGORS(X509_ALGORS **val_out, const unsigned char **der_in, long length);

int
i2d_X509_ALGORS(X509_ALGORS *val_in, unsigned char **der_out);

DESCRIPCIÓN

d2i_X509_ALGOR() y i2d_X509_ALGOR() decodifican y codifican una estructura AlgorithmIdentifier ASN.1 definida en la RFC 5280, sección 4.1.1.2.

d2i_X509_ALGORS() y i2d_X509_ALGORS() decodifican y codifican una secuencia ASN.1 de estructuras AlgorithmIdentifier. El tipo de dato X509_ALGORS se define como STACK_OF(X509_ALGOR).

Para obtener detalles sobre la semántica, ejemplos, advertencias y errores, consulte ASN1_item_d2i(3).

VER TAMBIÉN

ASN1_item_d2i(3), STACK_OF(3), X509_ALGOR_new(3)

ESTÁNDARES

RFC 5280: Internet X.509 Public Key Infrastructure Certificate and Certificate Revocation List (CRL) Profile

HISTORIA

d2i_X509_ALGOR() y i2d_X509_ALGOR() aparecieron por primera vez en SSLeay 0.5.1 y han estado disponibles desde OpenBSD 2.4.

d2i_X509_ALGORS() y i2d_X509_ALGORS() aparecieron por primera vez en OpenSSL 0.9.8h y han estado disponibles desde OpenBSD 4.5.
