libressl-SSL_CTX_sess_set_get_cb(3)

Paquete: libressl

SSL_CTX_SESS_SET_GET_CB(3) Manual de funciones de la biblioteca SSL_CTX_SESS_SET_GET_CB(3)

NOMBRE

SSL_CTX_sess_set_new_cb, SSL_CTX_sess_set_remove_cb, SSL_CTX_sess_set_get_cb, SSL_CTX_sess_get_new_cb, SSL_CTX_sess_get_remove_cb, SSL_CTX_sess_get_get_cb — proporciona funciones de devolución de llamada para el almacenamiento en caché de sesiones externas del lado del servidor

SINOPSIS

biblioteca “libssl” libcrypto
#include <openssl/ssl.h>

void
SSL_CTX_sess_set_new_cb(SSL_CTX *ctx, int (*new_session_cb)(SSL *, SSL_SESSION *));

void
SSL_CTX_sess_set_remove_cb(SSL_CTX *ctx, void (*remove_session_cb)(SSL_CTX *ctx, SSL_SESSION *));

void
SSL_CTX_sess_set_get_cb(SSL_CTX *ctx, SSL_SESSION (*get_session_cb)(SSL *, const unsigned char *, int, int *));

int
(*SSL_CTX_sess_get_new_cb(SSL_CTX *ctx))(SSL *ssl, SSL_SESSION *sess);

void
(*SSL_CTX_sess_get_remove_cb(SSL_CTX *ctx))(SSL_CTX *ctx, SSL_SESSION *sess);

SSL_SESSION *
(*SSL_CTX_sess_get_get_cb(SSL_CTX *ctx))(SSL *ssl, const unsigned char *data, int len, int *copy);

int
(*new_session_cb)(SSL *ssl, SSL_SESSION *sess);

void
(*remove_session_cb)(SSL_CTX *ctx, SSL_SESSION *sess);

SSL_SESSION *
(*get_session_cb)(SSL *ssl, unsigned char *data, int len, int *copy);

DESCRIPCIÓN

SSL_CTX_sess_set_new_cb() establece la función de devolución de llamada que se llama automáticamente siempre que se negocia una nueva sesión.

SSL_CTX_sess_set_remove_cb() establece la función de devolución de llamada que se llama automáticamente siempre que el motor SSL elimina una sesión (porque se considera defectuosa o la sesión se ha vuelto obsoleta debido a la superación del valor de tiempo de espera).

SSL_CTX_sess_set_get_cb() establece la función de devolución de llamada que se llama cada vez que un cliente SSL/TLS propone reanudar una sesión pero la sesión no se encuentra en la caché de sesiones interna (ver SSL_CTX_set_session_cache_mode(3)). (Solo servidor SSL/TLS.)

SSL_CTX_sess_get_new_cb(), SSL_CTX_sess_get_remove_cb(), y SSL_CTX_sess_get_get_cb() recuperan los punteros de función de las funciones de devolución de llamada proporcionadas. Si no se ha establecido una función de devolución de llamada, se devuelve el puntero NULL.

Para permitir el almacenamiento en caché de sesiones externas, la sincronización con la caché de sesiones interna se realiza a través de funciones de devolución de llamada. Dentro de estas funciones de devolución de llamada, las sesiones se pueden guardar en disco o colocar en una base de datos utilizando la interfaz d2i_SSL_SESSION(3).

La función new_session_cb() se llama siempre que se ha negociado una nueva sesión y el almacenamiento en caché de sesiones está habilitado (ver SSL_CTX_set_session_cache_mode(3)). La función new_session_cb() recibe la conexión ssl y la sesión ssl sess. Si la devolución de llamada devuelve 0, la sesión se eliminará inmediatamente de nuevo.

La función remove_session_cb() se llama cada vez que el motor SSL elimina una sesión de la caché interna. Esto ocurre cuando la sesión se elimina porque está caducada o cuando una conexión no se cerró limpiamente. También ocurre para todas las sesiones en la caché de sesiones interna cuando se llama a SSL_CTX_free(3). La función remove_session_cb() recibe el ctx y la sesión ssl sess. No proporciona ningún tipo de retroalimentación.

La función get_session_cb() solo se llama en servidores SSL/TLS con el ID de sesión propuesto por el cliente. La función get_session_cb() siempre se llama, incluso cuando el almacenamiento en caché de sesiones estaba deshabilitado. La función get_session_cb() recibe la conexión ssl, el ID de sesión de longitud len en la ubicación de memoria data. Con el parámetro copy, la devolución de llamada puede solicitar al motor SSL que incremente el contador de referencias del objeto SSL_SESSION. Normalmente, el contador de referencias no se incrementa y, por lo tanto, la sesión no debe liberarse explícitamente con SSL_SESSION_free(3).

VER TAMBIÉN

d2i_SSL_SESSION(3), ssl(3), SSL_CTX_flush_sessions(3), SSL_CTX_free(3), SSL_CTX_set_session_cache_mode(3), SSL_SESSION_free(3)

HISTORIA

SSL_CTX_sess_set_new_cb(), SSL_CTX_sess_set_get_cb(), SSL_CTX_sess_get_new_cb(), y SSL_CTX_sess_get_get_cb() aparecieron por primera vez en SSLeay 0.6.0. SSL_CTX_sess_set_remove_cb() y SSL_CTX_sess_get_remove_cb() aparecieron por primera vez en SSLeay 0.8.0. Estas funciones han estado disponibles desde OpenBSD 2.4.
