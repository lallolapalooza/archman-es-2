NOMBRE

libppl_c - la interfaz C de la Parma Polyhedra Library

SINOPSIS

#include <ppl_c.h>

cc file.c -lppl

DESCRIPCIÓN

Este es un breve resumen sobre cómo usar la Parma Polyhedra Library (PPL) en sus programas C en sistemas tipo Unix. Tenga en cuenta que la PPL también tiene interfaces para C++, Java, OCaml y varios sistemas Prolog: busque en otra parte la documentación sobre ellos. Tenga en cuenta también que este documento no describe la funcionalidad de la biblioteca, sus clases o sus métodos y funciones: consulte The Parma Polyhedra Library User's Manual (version 1.2) y The Parma Polyhedra Library C Language Interface User's Manual (version 1.2) para este tipo de información.

INCLUSIÓN DEL ARCHIVO DE CABECERA

La interfaz C de la PPL solo tiene un archivo de cabecera, llamado ppl_c.h. Por lo tanto, su programa debe contener una directiva del tipo

#include <ppl_c.h>

Por supuesto, debe asegurarse de haber instalado la PPL en un lugar donde el compilador pueda encontrarla, ya sea por sí solo o con la ayuda de una opción adecuada de línea de comandos -Idir (consulte el archivo INSTALL para obtener información sobre cómo configurar la biblioteca para que se instale en el lugar de su elección).

INICIALIZACIÓN Y FINALIZACIÓN DE LA BIBLIOTECA

Para inicializar la Parma Polyhedra Library, debe llamar a la función

int ppl_initialize(void)

antes de utilizar cualquiera de sus funcionalidades. También es una buena práctica llamar a la función

int ppl_finalize(void)

cuando haya terminado con la biblioteca.

USO DE LA BIBLIOTECA

Teniendo en cuenta que no hay sustituto para una lectura cuidadosa de The Parma Polyhedra Library User's Manual (version 1.2) y The Parma Polyhedra Library C Language Interface User's Manual (version 1.2), puede encontrar ejemplos de uso en los directorios interfaces/C/tests y demos/ppl_lpsol de la distribución fuente.

ENLAZADO CON LA BIBLIOTECA

El enlazado con la interfaz C de la Parma Polyhedra Library se realiza mejor utilizando el propio compilador C: normalmente, especificar la opción de línea de comandos -lppl_c es suficiente. De hecho, si utiliza una versión compartida de la biblioteca, esto registra automáticamente la dependencia de la biblioteca central de PPL y las bibliotecas GMP, algo que el enlazador debería manejar sin problemas. De lo contrario, tendrá que añadir -lppl -lgmpxx -lgmp a la línea de comandos. Las cosas son más complejas si instaló la PPL en algún lugar no estándar. En este caso, tendrá que usar la opción -Ldir y, si utiliza una versión compartida de la biblioteca, es posible que deba tomar medidas adicionales: consulte la documentación de su sistema para obtener más información sobre este tema (el Program Library HOWTO es especialmente valioso para los usuarios de GNU/Linux).

VALORES DE RETORNO

Todas las funciones de la interfaz C de PPL devuelven un int: un valor negativo significa que ocurrió un error. Consulte The Parma Polyhedra Library C Language Interface User's Manual (version 1.2) para ver los códigos de error.

IMPLEMENTACIÓN DE CÁLCULOS PROTEGIDOS POR MEMORIA

Una de las características interesantes de la Parma Polyhedra Library es la posibilidad de implementar cálculos protegidos por memoria. La idea es que se puede limitar la cantidad de memoria virtual disponible para el proceso, iniciar un cálculo de PPL y estar preparado para recibir un código de error PPL_ERROR_OUT_OF_MEMORY. A continuación, puede tomar las medidas correctivas apropiadas (por ejemplo, simplificar los poliedros y/o seleccionar algoritmos menos precisos aunque menos complejos) y reiniciar el cálculo. Para ello, debe definir funciones de asignación de memoria alternativas para GMP que lancen std::bad_alloc al agotar la memoria. Consulte libppl(3) para obtener instrucciones sobre cómo hacerlo.

USO DE NÚMEROS DE PUNTO FLOTANTE NATIVOS

En el momento de la inicialización, la Parma Polyhedra Library configura el modo de redondeo de la FPU de manera que permite que sus cálculos basados en punto flotante sean conservadores (es decir, posiblemente aproximados pero correctos) y razonablemente eficientes. En caso de que su aplicación utilice números de punto flotante nativos y dependa de un modo de redondeo particular (si tiene dudas, asuma que depende de que el redondeo al más cercano esté activo), debe usar la función

int ppl_restore_pre_PPL_rounding()

después de la inicialización de PPL y antes de usar números de punto flotante nativos en la aplicación. Si su aplicación no utiliza ninguna abstracción de PPL basada en punto flotante, no se deben tomar medidas adicionales. De lo contrario, es imperativo llamar a la función

int ppl_set_rounding_for_PPL()

antes de invocar cualquier interfaz de PPL relacionada con dichas abstracciones.
