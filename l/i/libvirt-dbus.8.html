NOMBRE

libvirt-dbus - Demonio D-Bus que exporta la API de libvirt

SINOPSIS

libvirt-dbus [OPCIÓN]...

DESCRIPCIÓN

libvirt-dbus envuelve la API de libvirt para proporcionar una API orientada a objetos de alto nivel más adecuada para aplicaciones basadas en dbus.

Normalmente, libvirt-dbus es iniciado por el demonio D-Bus a demanda.

OPCIONES

-h --help

Muestra la ayuda de uso de la línea de comandos y luego sale.

--system

Conéctate al bus del sistema.

--session

Conéctate al bus de sesión.

-t --threads NUM

Configura el número máximo de hilos trabajadores.
