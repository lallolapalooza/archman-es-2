LIBCVC4(3) Interfaces de la biblioteca CVC4 LIBCVC4(3)

NOMBRE

libcvc4 - una interfaz de biblioteca para el demostrador de teoremas CVC4

SINOPSIS

Un programa pequeño como:

#include <iostream>
#include "expr/expr_manager.h"
#include "smt/smt_engine.h"
using namespace CVC4;
int main() {
  ExprManager em;
  SmtEngine smt(&em);
  Expr onePlusTwo = em.mkExpr(kind::PLUS,
                              em.mkConst(Rational(1)),
                              em.mkConst(Rational(2)));
  std::cout << language::SetLanguage(language::output::LANG_CVC4)
            << smt.getInfo("name")
            << " dice que 1 + 2 = "
            << smt.simplify(onePlusTwo)
            << std::endl;
  return 0;
}

produce la salida:

"cvc4" dice que 1 + 2 = 3

DESCRIPCIÓN

Las clases principales de interés en la API de CVC4 son ExprManager, SmtEngine y algunas relacionadas como Expr y Type.

El ExprManager se utiliza para construir expresiones y tipos, y el SmtEngine se utiliza principalmente para hacer aserciones, comprobar satisfacibilidad/validez y extraer modelos y pruebas.

VER TAMBIÉN

cvc4(1), libcvc4parser(3)

Además, la wiki de CVC4 contiene información útil sobre el diseño e internals de CVC4. Se mantiene en http://cvc4.cs.stanford.edu/wiki/.
