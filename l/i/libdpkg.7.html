NOMBRE

libdpkg - Biblioteca C del gestor de paquetes de Debian

DESCRIPCIÓN

La biblioteca C libdpkg proporciona funciones e infraestructura para el conjunto de herramientas dpkg y para proyectos externos que necesiten integrarse estrechamente con él.

La biblioteca proporciona una entrada de pkgconf(1) llamada libdpkg.

Advertencia: La API proporcionada por esta biblioteca es muy volátil, todavía está en proceso de limpieza. Solo debe ser utilizada internamente por dpkg por ahora. Los archivos de cabecera, funciones, variables y tipos pueden ser renombrados, eliminados o cambiar su semántica. Si aun así tiene la necesidad de usarla, lo cual haría de todos modos, por ejemplo, compilando dpkg localmente para obtener la biblioteca, entonces defina la macro del preprocesador C LIBDPKG_VOLATILE_API en su compilación para reconocer este hecho.

Debido a la volatilidad actual de la API, solo se proporciona una biblioteca estática.
