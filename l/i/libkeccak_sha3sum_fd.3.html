libkeccak_sha3sum_fd(3)

Paquete: libkeccak

Licencias: custom:ISC

LIBKECCAK_SHA3SUM_FD(3) Manual de funciones de biblioteca LIBKECCAK_SHA3SUM_FD(3)

NOMBRE

libkeccak_sha3sum_fd - Calcular un hashsum SHA-3 de un archivo

SINOPSIS

#include <libkeccak.h>
int libkeccak_sha3sum_fd(int fd, struct libkeccak_state *state, long int output, void *hashsum);

Enlazar con -lkeccak.

DESCRIPCIÓN

La función libkeccak_sha3sum_fd() calcula un hashsum SHA-3 de un archivo, cuyo descriptor de archivo se especifica mediante fd (y debe estar al principio del archivo). El algoritmo de hash se ajusta mediante el parámetro output; especifica el tamaño de salida, en bits.

El hash se almacena en formato binario en hashsum. hashsum debe tener un tamaño de asignación de al menos (((output + 7) / 8) * sizeof(char)).

*state no debe inicializarse. libkeccak_sha3sum_fd() inicializa *state en sí misma. Por lo tanto, habría una fuga de memoria si *state ya estuviera inicializado.

VALORES DE RETORNO

La función libkeccak_sha3sum_fd() devuelve 0 si la ejecución se completa correctamente. En caso de error, se devuelve -1 y se establece errno para describir el error.

ERRORES

La función libkeccak_sha3sum_fd() puede fallar por cualquier motivo, excepto aquellos que resultan en que errno se establezca en EINTR, especificados para las funciones read(2), malloc(3) y realloc(3).

NOTAS

Tenga en cuenta que libkeccak_sha3sum_fd() calcula el hash del archivo hasta que se llega al final. Para tuberías y sockets, esto significa hasta que el archivo se cierra. Pero para los dispositivos de caracteres, esto generalmente significa nunca. Por lo tanto, intentar calcular el hash de archivos en /dev suele ser una mala idea. libkeccak_sha3sum_fd() no comprueba la longitud o el tipo de archivo antes de calcular el hash, ya que esto podría limitar lo que puede hacer y hacer que la biblioteca sea más compleja.

libkeccak_sha3sum_fd() no se detiene si se interrumpe (read(2) devuelve EINTR.)

libkeccak_sha3sum_fd() asume que toda la información no es sensible y, por lo tanto, no realizará ninguna eliminación segura de la información.

libkeccak_sha3sum_fd() no valida la configuración del algoritmo.

EJEMPLO

Este ejemplo calcula el hash SHA3-256 de la entrada estándar (stdin) e imprime el hash, en formato hexadecimal, en la salida estándar (stdout).

struct libkeccak_state state;
if (libkeccak_sha3sum_fd(STDIN_FILENO, &state, 256, binhash) < 0)
	goto fail;
libkeccak_behex_lower(hexhash, binhash, sizeof(binhash));
printf("%s\n", hexhash);
libkeccak_state_destroy(&state);
