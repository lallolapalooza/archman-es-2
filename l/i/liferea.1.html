LIFEREA(1) Manual de Comandos Generales LIFEREA(1)

NOMBRE

Liferea - Agregador de noticias de escritorio GTK

SINOPSIS

liferea [OPCIONES]

DESCRIPCIÓN

Liferea (Linux Feed Reader) es un agregador de fuentes de noticias en línea. Se puede utilizar para mantener una lista de fuentes suscritas, navegar y buscar entre sus elementos y mostrar sus contenidos. Además, Liferea permite sincronizar suscripciones y leer titulares con cuentas en línea de TinyTinyRSS y TheOldReader.

OPCIONES

Opciones de Liferea:

-v, --version
Imprime la información de la versión y sale.
-h, --help
Muestra un resumen de opciones y sale.
-a, --add-feed=URI
Añade una nueva URI de suscripción, que puede ser una URL de fuente o de sitio web.
-w, --mainwindow-state=ESTADO
Inicia Liferea con su ventana principal en ESTADO: shown (visible), hidden (oculta).
-p, --disable-plugins
Inicia con todos los plugins deshabilitados.
--debug-all
Imprime mensajes de depuración de todos los tipos.
--debug-cache
Imprime mensajes de depuración para el manejo de caché.
--debug-conf
Imprime mensajes de depuración del manejo de configuración.
--debug-db
Imprime mensajes de depuración del manejo de la base de datos.
--debug-gui
Imprime mensajes de depuración de todas las funciones de la GUI.
--debug-html
Habilita la depuración de renderizado HTML. Cada vez que Liferea renderice salida HTML, también volcará el HTML generado en $XDG_CACHE_DIR/liferea/output.html.
--debug-net
Imprime mensajes de depuración de todas las actividades de red y muestra la cadena User-Agent de HTTP/S.
--debug-parsing
Imprime mensajes de depuración de todas las funciones de análisis.
--debug-update
Imprime mensajes de depuración del procesamiento de actualización de fuentes.
--debug-vfolder
Imprime mensajes de depuración de la coincidencia de carpetas de búsqueda.

INTERFAZ DBUS

Para permitir la integración con otros programas, Liferea proporciona una interfaz DBUS para la creación automática de nuevas suscripciones. El script liferea-add-feed es una forma conveniente de utilizar esta interfaz. Simplemente pase una URL de fuente válida como parámetro y la fuente se añadirá a la lista de fuentes. También puede pasar URLs que no sean de fuentes para utilizar el descubrimiento automático de fuentes. Vea la sección EJEMPLOS.

ENTORNO

http_proxy (para conexiones HTTP)

https_proxy (para conexiones HTTPS)

Si está definida y no se especifica un proxy en las preferencias de Liferea (que utiliza la configuración de proxy proporcionada por dconf), su valor se utilizará como URIs de proxy. Ambas son utilizadas por muchas herramientas de línea de comandos comunes, así que asegúrese de exportarlas en un subshell dedicado.
LIFEREA_FEED_CMD_TIMEOUT
Si está definida, anula el tiempo de espera predeterminado para los comandos que generan fuentes con el número de segundos dado en esta variable. Debe ser un valor entero mayor que cero; los valores no válidos se ignorarán.
LIFEREA_UA_ANONYMOUS
Si está definida, aleatoriza y anonimiza la cadena User-Agent predeterminada de HTTP/S.
LIFEREA_UA
Si está definida, su valor reemplaza la cadena User-Agent predeterminada de HTTP/S.

LIFEREA_UA siempre tiene precedencia sobre LIFEREA_UA_ANONYMOUS, por lo que esta última se puede definir de forma segura en archivos de inicialización globales del shell.

EJEMPLOS

$ http_proxy="http://proxy.example.com:3128" liferea

$ http_proxy="http://username:password@proxy.example.com:3128" liferea
Alterará cada solicitud saliente para usar proxy.example.com en el puerto 3128 como proxy. Si la resolución DNS no funciona, se puede usar una dirección IP en su lugar.
$ LIFEREA_UA_ANONYMOUS=1 liferea --debug-net
Alterará cada solicitud HTTP/S saliente para aleatorizar la versión de Liferea y ocultar el sistema operativo en uso. Además, imprime el User-Agent HTTP/S y todas las solicitudes de red salientes.
$ LIFEREA_UA="Mozilla/5.0 (X11; Linux x86_64; rv:10.0) Gecko/20100101 Firefox/10.0" liferea
Alterará cada solicitud HTTP/S saliente para hacerse pasar por Firefox en Linux.
$ liferea-add-feed "feed:https://www.example.com/feed.rss"

$ liferea --add-feed "https://www.example.com/feed.rss"
Suscribirse a "example.com/feed.rss". Recuerde proporcionar una URL de fuente válida y correctamente escapada como parámetro. Tenga en cuenta que Liferea debe estar en ejecución para que liferea-add-feed funcione.

ARCHIVOS

$XDG_CONFIG_DIR/liferea/feedlist.opml
Contiene la lista actual de suscripciones.
$XDG_CONFIG_DIR/liferea/liferea.css
Hoja de estilos que se puede usar para anular el estilo HTML predeterminado.
$XDG_DATA_DIR/liferea/liferea.db
Base de datos SQLite3 con todas las suscripciones y titulares.
$XDG_DATA_DIR/liferea/plugins/
Los plugins instalados por el usuario se almacenan aquí. Puede colocar manualmente plugins aquí o usar el instalador de plugins en Liferea.
