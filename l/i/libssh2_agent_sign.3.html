libssh2_agent_sign(3)

Paquete: libssh2

Licencias: BSD

libssh2_agent_sign(3) libssh2 libssh2_agent_sign(3)

NOMBRE

libssh2_agent_sign - firmar datos, con la ayuda de ssh-agent

SINOPSIS

#include <libssh2.h>
int
libssh2_agent_sign(LIBSSH2_AGENT *agent,
                   struct libssh2_agent_publickey *identity,
                   unsigned char **sig,
                   size_t *s_len,
                   const unsigned char *data,
                   size_t d_len,
                   const char *method,
                   unsigned int method_len);

DESCRIPCIÓN

agent - manejador de ssh-agent devuelto por libssh2_agent_init(3)

identity - Clave pública con la que autenticarse, devuelta por libssh2_agent_get_identity(3)

sig - Un puntero a un búfer donde colocar la firma. El llamador es responsable de liberar la firma con LIBSSH2_FREE.

s_len - Un puntero a la longitud del parámetro sig.

data - Los datos a firmar.

d_len - La longitud del parámetro data.

method - Un búfer que indica el método de firma. Debe coincidir con la cadena al principio de identity->blob.

method_len - La longitud del parámetro method.

Firma datos usando un ssh-agent. Esta función se puede usar en una devolución de llamada registrada con libssh2_session_callback_set2(3) usando LIBSSH2_CALLBACK_AUTHAGENT_SIGN para firmar un desafío de autenticación de un servidor. Sin embargo, el cliente es responsable de implementar el código que llama a esta devolución de llamada en respuesta a un mensaje SSH2_AGENTC_SIGN_REQUEST.

VALOR DE RETORNO

Devuelve 0 si tuvo éxito, o un valor negativo en caso de error.

DISPONIBILIDAD

Añadido en libssh2 1.11.0
