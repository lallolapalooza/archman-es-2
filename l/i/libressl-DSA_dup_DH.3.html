DSA_DUP_DH(3) Manual de funciones de biblioteca DSA_DUP_DH(3)

NOMBRE

DSA_dup_DH — crear una estructura DH a partir de una estructura DSA

SINOPSIS

biblioteca «libcrypto»
#include <openssl/dsa.h>

DH *
DSA_dup_DH(const DSA *r);

DESCRIPCIÓN

DSA_dup_DH() duplica parámetros/claves DSA como parámetros/claves DH.

VALORES DE RETORNO

DSA_dup_DH() devuelve la nueva estructura DH o NULL en caso de error. Los códigos de error se pueden obtener mediante ERR_get_error(3).

VER TAMBIÉN

DH_new(3), DSA_get0_pqg(3), DSA_new(3)

HISTORIA

DSA_dup_DH() apareció por primera vez en OpenSSL 0.9.4 y ha estado disponible desde OpenBSD 2.6.

ADVERTENCIAS

Tenga cuidado de evitar ataques de subgrupo pequeños al usar esto.
