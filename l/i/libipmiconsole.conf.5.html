NOMBRE

libipmiconsole.conf - especificar valores predeterminados para libipmiconsole

DESCRIPCIÓN

El archivo de configuración Libipmiconsole se puede usar para establecer valores predeterminados alternativos para la biblioteca libipmiconsole. La configuración de estos valores predeterminados puede ser útil para entornos en los que los programas se enlazan a libipmiconsole pero no admiten la configuración de parámetros de libipmiconsole. Los usuarios deben tener en cuenta que establecer valores predeterminados alternativos en libipmiconsole afectará a todas las herramientas que se enlacen a la biblioteca, como la herramienta ipmiconsole(8). Para los usuarios que deseen establecer valores predeterminados alternativos para ipmiconsole(8), use en su lugar el archivo freeipmi.conf(5).

El archivo de configuración se almacena en /etc/freeipmi//libipmiconsole.conf.

FORMATO

Las opciones de configuración que se pueden especificar en el archivo de configuración se enumeran a continuación. Cada opción de configuración debe enumerarse en una línea separada. Los argumentos de una opción están separados por cualquier cantidad de espacio en blanco. Múltiples argumentos también están separados por espacio en blanco. Los comentarios se pueden marcar utilizando el carácter de signo de almohadilla ("#"), y las líneas se pueden continuar en la siguiente usando la barra invertida ("\").

OPCIONES DE CONFIGURACIÓN IPMI DEL CONTEXTO

Cada sesión SOL se aloja dentro de un contexto libipmiconsole. Lo siguiente define los valores predeterminados de configuración IPMI para cada contexto creado.

libipmiconsole-context-username NOMBRE_DE_USUARIO
Especifica el nombre de usuario predeterminado a utilizar.
libipmiconsole-context-password CONTRASEÑA
Especifica la contraseña predeterminada a utilizar.
libipmiconsole-context-k_g str
Especifica la clave BMC predeterminada (K_g) a utilizar. Prefije con '0x' para introducir la clave en formato hexadecimal.
libipmiconsole-context-privilege-level NIVEL_DE_PRIVILEGIO
Especifica el nivel de privilegio predeterminado a utilizar. Los siguientes niveles de privilegio son compatibles: USER, OPERATOR, ADMIN.
libipmiconsole-context-cipher-suite-id ID_DE_SUITE_DE_CIFRADO
Especifica el ID de la suite de cifrado predeterminada a utilizar. Los siguientes ID de suite de cifrado son compatibles: 0, 1, 2, 3, 6, 7, 8, 11, 12.
libipmiconsole-context-workaround-flags SOLUCIONES_TEMPORALES
Especifica las marcas de solución temporal predeterminadas a utilizar. Se pueden especificar múltiples soluciones temporales separadas por espacios. Las siguientes soluciones temporales son compatibles: authcap, intel20, supermicro20, sun20, opensesspriv, integritycheckvalue, solpayloadsize, solport, solstatus, solchannelsupport, serialalertsdeferred, solpacketseq

OPCIONES DE CONFIGURACIÓN DE PROTOCOLO DEL CONTEXTO

Cada sesión SOL se aloja dentro de un contexto libipmiconsole. Lo siguiente define los valores predeterminados de configuración de protocolo para cada contexto creado.

libipmiconsole-context-session-timeout-len MILISEGUNDOS
Especifica la longitud del tiempo de espera de sesión predeterminado a utilizar en milisegundos.
libipmiconsole-context-retransmission-timeout-len MILISEGUNDOS
Especifica la longitud del tiempo de espera de retransmisión predeterminado a utilizar en milisegundos.
libipmiconsole-context-retransmission-backoff-count NUM
Especifica el recuento de retroceso de retransmisión predeterminado a utilizar.
libipmiconsole-context-keepalive-timeout-len MILISEGUNDOS
Especifica la longitud del tiempo de espera de "keep-alive" predeterminado a utilizar en milisegundos.
libipmiconsole-context-retransmission-keepalive-timeout-len MILISEGUNDOS
Especifica la longitud del tiempo de espera de retransmisión predeterminado a utilizar para los paquetes "keep-alive" en milisegundos.
libipmiconsole-context-acceptable-packet-errors-count NUM
Especifica el recuento de errores de paquete predeterminado a utilizar.
libipmiconsole-context-maximum-retransmission-count NUM
Especifica el recuento de retransmisión máximo predeterminado a utilizar.

OPCIONES DE CONFIGURACIÓN DEL MOTOR DEL CONTEXTO

Cada sesión SOL se aloja dentro de un contexto libipmiconsole. Lo siguiente define los valores predeterminados de configuración del motor para cada contexto creado. Puede ser necesario tener conocimientos de la biblioteca libipmiconsole para comprender el significado de estas configuraciones. Consulte el archivo de cabecera ipmiconsole.h para obtener información adicional sobre la biblioteca.

libipmiconsole-context-engine-flags MARCAS
Especifica las marcas del motor predeterminadas a utilizar. Se pueden especificar múltiples marcas separadas por espacios. Las siguientes marcas son compatibles: closefd, outputonsolestablished, lockmemory, serialkeepalive.
libipmiconsole-context-behavior-flags MARCAS
Especifica las marcas de comportamiento predeterminadas a utilizar. Se pueden especificar múltiples marcas separadas por espacios. Las siguientes marcas son compatibles: erroronsolinuse, deactivateonly, deactivateallinstances.
libipmiconsole-context-debug-flags MARCAS
Especifica las marcas de depuración predeterminadas a utilizar. Se pueden especificar múltiples marcas separadas por espacios. Las siguientes marcas son compatibles: stdout, stderr, syslog, file, ipmipackets.
libipmiconsole-context-sol-payload-instance NUM
Especifica la instancia de carga útil SOL predeterminada. Tiene un rango de 1 a 15.
