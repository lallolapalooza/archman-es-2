libssh2_scp_send64(3)

Paquete: libssh2

Licencias: BSD

libssh2_scp_send64(3) libssh2 libssh2_scp_send64(3)

NOMBRE

libssh2_scp_send64 - Enviar un archivo vía SCP

SINOPSIS

#include <libssh2.h>
LIBSSH2_CHANNEL *
libssh2_scp_send64(LIBSSH2_SESSION *session, const char *path, int mode,
                   libssh2_uint64_t size, time_t mtime, time_t atime);

DESCRIPCIÓN

session - Instancia de sesión devuelta por libssh2_session_init_ex(3)

path - Ruta completa y nombre de archivo a transferir. Este es el nombre del archivo remoto.

mode - Modo de acceso de archivo con el que se creará el archivo

size - Tamaño del archivo que se está transmitiendo (Debe conocerse de antemano). Tenga en cuenta que esto debe pasarse como el tipo de variable libssh2_uint64_t. Este tipo es de 64 bits en sistemas operativos y compiladores modernos.

mtime - mtime a asignar al archivo que se está creando

atime - atime a asignar al archivo que se está creando (Establezca este y mtime en cero para indicar al host remoto que use la hora actual).

Envía un archivo al host remoto a través de SCP.

VALOR DE RETORNO

Puntero a una instancia de LIBSSH2_CHANNEL recién asignada, o NULL en caso de error.

ERRORES

LIBSSH2_ERROR_ALLOC - Falló una llamada interna de asignación de memoria.

LIBSSH2_ERROR_SOCKET_SEND - No se pudieron enviar datos en el socket.

LIBSSH2_ERROR_SCP_PROTOCOL -

LIBSSH2_ERROR_EAGAIN - Marcado para E/S sin bloqueo pero la llamada bloquearía.

DISPONIBILIDAD

Esta función se añadió en libssh2 1.2.6 y está destinada a reemplazar la función anterior libssh2_scp_send_ex(3).
