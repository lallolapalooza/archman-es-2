NOMBRE

libnbd-ocaml - cómo usar libnbd desde OCaml

SINOPSIS

let nbd = NBD.create () in
NBD.connect_uri nbd "nbd://localhost";
let size = NBD.get_size nbd in
printf "%Ld\n" size;
NBD.close ()

Sintaxis alternativa que asegura que close se llama incluso si se lanza una excepción:

let size =
  NBD.with_handle (
    fun nbd ->
      NBD.connect_uri nbd "nbd://localhost";
      NBD.get_size nbd
  ) in
printf "%Ld\n" size

Para compilar:

ocamlopt -I +nbd mlnbd.cmxa prog.ml -o prog

o usando findlib:

ocamlfind opt -package nbd -linkpkg prog.ml -o prog

DESCRIPCIÓN

Esta página del manual documenta cómo usar libnbd para acceder a servidores NBD (Network Block Device) desde el lenguaje de programación OCaml.

Los enlaces de OCaml funcionan de manera muy similar a los enlaces de C, así que deberías empezar leyendo libnbd(3).

Para la documentación de la API de OCaml, consulta NBD(3).

MANEJADORES

Crea un manejador de libnbd de tipo "NBD.t" llamando a "NBD.create ()".

Puedes cerrar el manejador explícitamente llamando a "NBD.close" o se cerrará automáticamente cuando sea recolectado por el recolector de basura. Si llamas a cualquier otro método en un manejador que hayas cerrado explícitamente, la API lanzará una excepción "NBD.Closed".

"NBD.with_handle" puede usarse para asegurar que el manejador se cierre a tiempo. Consulta el ejemplo en la sección "SINOPSIS" anterior.

ERRORES

Los errores de Libnbd se convierten automáticamente en excepciones de tipo:

NBD.Error (str, Unix.error option)

El primer parámetro de la excepción es una cadena que es el mensaje de error imprimible. El segundo es el código de "Unix.error" de OCaml, si está disponible (ver nbd_get_errno(3)).

Callbacks con parámetro de error "int ref"

Algunas callbacks toman un parámetro de error de tipo "int ref", que corresponde al "int *error" pasado a esas callbacks en C. Ver también: "Callbacks with "int *error" parameter" en libnbd(3)

Si ocurre un error durante la callback, puedes actualizar el "int" en la referencia, estableciéndolo a un errno compatible con C. Para convertir un "Unix.error" de OCaml en un errno compatible con C, llama a "NBD.errno_of_unix_error".
