libressl-X509V3_parse_list(3)

Paquete: libressl

Licencias: ISC, custom:OpenSSL

X509V3_PARSE_LIST(3) Manual de funciones de biblioteca X509V3_PARSE_LIST(3)

NOMBRE

X509V3_parse_list, X509V3_conf_free — crear y destruir objetos CONF_VALUE

SINOPSIS

biblioteca “libcrypto”
#include <openssl/x509v3.h>

STACK_OF(CONF_VALUE) *
X509V3_parse_list(const char *string);

void
X509V3_conf_free(CONF_VALUE *conf);

DESCRIPCIÓN

X509V3_parse_list() analiza la cadena string y asigna una matriz de objetos CONF_VALUE según las siguientes reglas.

  1. La cadena se divide en campos en los caracteres coma (‘,’).
  2. Si un campo contiene un carácter de dos puntos (‘:’), la parte anterior a los dos puntos se considera un nombre y la parte posterior al primer dos puntos, el valor asociado. De lo contrario, el campo completo se considera el nombre y NULL se utiliza como el valor asociado.
  3. Para cada nombre y cada valor, se ignoran los espacios en blanco iniciales y finales definidos por isspace(3).
  4. El análisis termina cuando se encuentra un carácter NULO, de retorno de carro o de nueva línea.

Se asigna un nuevo objeto STACK_OF(CONF_VALUE) vacío y, para cada nombre analizado, se inserta una estructura CONF_VALUE que contiene el valor opcional en él.

X509V3_conf_free() libera toda la memoria utilizada por conf. Si conf es NULL, no se realiza ninguna acción.

La forma típica de liberar la memoria devuelta por X509V3_parse_list() es llamando a sk_CONF_VALUE_pop_free() sobre él, pasando un puntero a la función X509V3_conf_free() como segundo argumento.

VALORES DE RETORNO

X509V3_parse_list() devuelve el nuevo objeto STACK_OF(CONF_VALUE) o NULL si ocurre un error, en particular si no hay ningún nombre, si el nombre anterior a dos puntos o posterior a una coma está vacío, si el valor posterior a dos puntos está vacío, o si falla la asignación de memoria.

VER TAMBIÉN

isspace(3), sk_pop_free(3), STACK_OF(3), v2i_ASN1_BIT_STRING(3)

HISTORIA

X509V3_parse_list() y X509V3_conf_free() aparecieron por primera vez en OpenSSL 0.9.2 y han estado disponibles desde OpenBSD 2.6.
