DESCRIPCIÓN

BN_bn2bin() convierte el valor absoluto de a a formato big-endian y lo almacena en to. to debe apuntar a BN_num_bytes(a) bytes de memoria.

BN_bn2binpad() también convierte el valor absoluto de a a formato big-endian y lo almacena en to. tolen indica la longitud del búfer de salida *to. El resultado se rellena con ceros si es necesario. Si tolen es menor que BN_num_bytes(a), se devuelve un error.

BN_bin2bn() convierte el entero positivo en formato big-endian de longitud len en s a un BIGNUM y lo coloca en ret. Si ret es NULL, se crea un nuevo BIGNUM.

BN_bn2lebinpad() y BN_lebin2bn() son idénticos a BN_bn2binpad() y BN_bin2bn() excepto que el búfer *to está en formato little-endian.

BN_bn2hex() y BN_bn2dec() devuelven cadenas imprimibles que contienen la codificación hexadecimal y decimal de a respectivamente. Para números negativos, la cadena va precedida de un signo menos. La cadena debe liberarse más tarde usando free(3).

BN_hex2bn() interpreta str como un número hexadecimal. La cadena puede comenzar con un signo menos (‘-’). La conversión se detiene en el primer byte que no sea un dígito hexadecimal. El número se convierte a un BIGNUM y se almacena en **ap. Si *ap es NULL, se crea un nuevo BIGNUM. Si ap es NULL, solo calcula la longitud del número en dígitos hexadecimales, contando también el signo menos si lo hay. Un "cero negativo" se convierte en cero. BN_dec2bn() es lo mismo usando el sistema decimal. BN_asc2bn() infiere la base numérica de un prefijo opcional. Si str comienza con "0x" o "0X", llama a BN_hex2bn(), de lo contrario BN_dec2bn(). Si el número es negativo, el signo menos puede estar antes o después del prefijo.

BN_print() y BN_print_fp() escriben la codificación hexadecimal de a, con un signo menos inicial para números negativos, en el BIO o FILE fp.

BN_bn2mpi() y BN_mpi2bn() convierten BIGNUMs desde y hacia un formato que consiste en la longitud del número en bytes representada como un número big-endian de 4 bytes, y el número mismo en formato big-endian, donde el bit más significativo señala un número negativo (la representación de números con el MSB establecido se antepone con un byte NUL).

BN_bn2mpi() almacena la representación de a en to, donde *to debe ser lo suficientemente grande para contener el resultado. El tamaño se puede determinar llamando a BN_bn2mpi(a, NULL).

BN_mpi2bn() convierte los len bytes de la representación en s a un BIGNUM y lo almacena en ret, o en un BIGNUM recién asignado si ret es NULL.

VALORES DE RETORNO

BN_bn2bin() devuelve la longitud del número big-endian colocado en to.

BN_bn2binpad() y BN_bn2lebinpad() devuelven el número de bytes escritos o -1 si el búfer proporcionado es demasiado pequeño.

BN_bin2bn() y BN_lebin2bn() devuelven el BIGNUM, o NULL en caso de error.

BN_bn2hex() y BN_bn2dec() devuelven una cadena terminada en NUL, o NU

BN_bn2bin(3)

NAME

BN_bn2bin, BN_bin2bn, BN_bn2hex, BN_hex2bn, BN_bn2dec, BN_dec2bn, BN_asc2bn, BN_print_fp, BN_print, BN_bn2mpi, BN_mpi2bn, BN_bn2binpad, BN_bn2lebinpad, BN_lebin2bn – BIGNUM conversion functions

SYNOPSIS

#include <openssl/bn.h>

int BN_bn2bin(const BIGNUM *a, unsigned char *to);

BIGNUM *BN_bin2bn(const unsigned char *from, int len, BIGNUM *ret);

int BN_bn2hex(const BIGNUM *a, char *to);

BIGNUM *BN_hex2bn(BIGNUM **a, const char *str);

int BN_bn2dec(const BIGNUM *a, char *to);

BIGNUM *BN_dec2bn(BIGNUM **a, const char *str);

BIGNUM *BN_asc2bn(BIGNUM **a, const char *str);

int BN_print_fp(FILE *fp, const BIGNUM *a);

int BN_print(BIO *bp, const BIGNUM *a);

int BN_bn2mpi(const BIGNUM *a, unsigned char *to);

BIGNUM *BN_mpi2bn(const unsigned char *from, int len, BIGNUM *ret);

int BN_bn2binpad(const BIGNUM *a, unsigned char *to, int tolen);

int BN_bn2lebinpad(const BIGNUM *a, unsigned char *to, int tolen);

BIGNUM *BN_lebin2bn(const unsigned char *from, int len, BIGNUM *ret);

DESCRIPTION

These functions convert between BIGNUM structures and various external representations.

BN_bn2bin() converts the BIGNUM a into a binary(5) representation. The number is written into the buffer to. The caller must ensure that to is large enough to hold the result. The size required can be calculated using BN_num_bytes(3). The function returns the number of bytes written. It is the caller's responsibility to ensure that the BIGNUM is non-negative.

BN_bin2bn() converts the binary(5) representation from of length len bytes into a BIGNUM. If ret is not NULL, it is reused to store the result. Otherwise, a new BIGNUM is allocated. The caller can obtain the created BIGNUM by calling BN_new(3) and passing the result as ret, or by checking the return value of BN_bin2bn().

BN_bn2hex() converts the BIGNUM a into a NULL-terminated hexadecimal string. The string is written into the buffer to. The caller must ensure that to is large enough to hold the result, including the potential minus sign and the NULL terminator. The size required can be calculated using BN_num_bytes() * 2 + 2 (for the sign and NULL terminator).

BN_hex2bn() converts a NULL-terminated hexadecimal string str into a BIGNUM. If a is not NULL, it is reused to store the result. Otherwise, a new BIGNUM is allocated. The caller can obtain the created BIGNUM by calling BN_new(3) and passing the result as a, or by checking the return value of BN_hex2bn().

BN_bn2dec() converts the BIGNUM a into a NULL-terminated decimal string. The string is written into the buffer to. The caller must ensure that to is large enough to hold the result, including the potential minus sign and the NULL terminator. The size required can be calculated using BN_num_bytes() * 4 + 2 (for the sign and NULL terminator).

BN_dec2bn() converts a NULL-terminated decimal string str into a BIGNUM. If a is not NULL, it is reused to store the result. Otherwise, a new BIGNUM is allocated. The caller can obtain the created BIGNUM by calling BN_new(3) and passing the result as a, or by checking the return value of BN_dec2bn().

BN_asc2bn() converts a NULL-terminated string str containing a number in any base (specified by BN_hex2bn() or BN_dec2bn()) into a BIGNUM. The base is determined by the first character of str: '0x' or '0X' for hexadecimal, '0' for octal, and any other character for decimal. If a is not NULL, it is reused to store the result. Otherwise, a new BIGNUM is allocated.

BN_print_fp() prints the BIGNUM a to the FILE pointer fp. The output is in decimal format.

BN_print() prints the BIGNUM a to the BIO object bp. The output is in decimal format.

BN_bn2mpi() converts the BIGNUM a into an MPI (Multiple Precision Integer) representation. The result is written to the buffer to. The caller must ensure that to is large enough to hold the result. The function returns the number of bytes written.

BN_mpi2bn() converts an MPI representation from of length len bytes into a BIGNUM. If ret is not NULL, it is reused to store the result. Otherwise, a new BIGNUM is allocated.

BN_bn2binpad() converts the BIGNUM a into a binary(5) representation of length tolen bytes, padding with leading zeros if necessary. The result is written to the buffer to.

BN_bn2lebinpad() converts the BIGNUM a into a little-endian binary(5) representation of length tolen bytes, padding with leading zeros if necessary. The result is written to the buffer to.

BN_lebin2bn() converts a little-endian binary(5) representation from of length len bytes into a BIGNUM. If ret is not NULL, it is reused to store the result. Otherwise, a new BIGNUM is allocated.

RETURN VALUES

BN_bn2bin(), BN_bn2hex(), BN_bn2dec(), BN_bn2mpi(), BN_bn2binpad(), BN_bn2lebinpad() return the number of bytes written on success, or a value less than or equal to 0 on error.

BN_bin2bn(), BN_hex2bn(), BN_dec2bn(), BN_mpi2bn(), BN_lebin2bn() return the BIGNUM on success, or NULL on error. If ret was not NULL, it is returned on success or NULL on error.

BN_asc2bn() returns 1 on success or 0 on error, in which case no new BIGNUM is created.

BN_print_fp() and BN_print() return 1 on success, 0 on write errors.

The error codes can be obtained by ERR_get_error(3).

HISTORY

BN_bn2bin(), BN_bin2bn(), and BN_print() first appeared in SSLeay 0.5.1. BN_print_fp() first appeared in SSLeay 0.6.0. BN_bn2hex(), BN_bn2dec(), BN_hex2bn(), BN_dec2bn(), BN_bn2mpi(), and BN_mpi2bn() first appeared in SSLeay 0.9.0. All these functions have been available since OpenBSD 2.4.

BN_asc2bin() first appeared in OpenSSL 1.0.0 and has been available since OpenBSD 4.9.

BN_bn2binpad(), BN_bn2lebinpad(), and BN_lebin2bn() first appeared in OpenSSL 1.1.0 and have been available since OpenBSD 7.0.
