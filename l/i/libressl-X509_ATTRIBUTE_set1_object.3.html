libressl-X509_ATTRIBUTE_set1_object(3)

Paquete: libressl

Licencias: ISC, custom:OpenSSL

X509_ATTRIBUTE_SET1_OBJECT(3) Manual de funciones de biblioteca X509_ATTRIBUTE_SET1_OBJECT(3)

NOMBRE

X509_ATTRIBUTE_set1_object, X509_ATTRIBUTE_set1_data, X509_ATTRIBUTE_create_by_OBJ, X509_ATTRIBUTE_create_by_NID, X509_ATTRIBUTE_create_by_txt — modificar un Atributo X.501

SINOPSIS

biblioteca “libcrypto”
#include <openssl/x509.h>

int
X509_ATTRIBUTE_set1_object(X509_ATTRIBUTE *attr, const ASN1_OBJECT *obj);

int
X509_ATTRIBUTE_set1_data(X509_ATTRIBUTE *attr, int type, const void *data, int len);

X509_ATTRIBUTE *
X509_ATTRIBUTE_create_by_OBJ(X509_ATTRIBUTE **pattr, const ASN1_OBJECT *obj, int type, const void *data, int len);

X509_ATTRIBUTE *
X509_ATTRIBUTE_create_by_NID(X509_ATTRIBUTE **pattr, int nid, int type, const void *data, int len);

X509_ATTRIBUTE *
X509_ATTRIBUTE_create_by_txt(X509_ATTRIBUTE **pattr, const char *name, int type, const unsigned char *data, int len);

DESCRIPCIÓN

X509_ATTRIBUTE_set1_object() establece el tipo de attr en obj. Si obj está asignado dinámicamente, se crea una copia profunda. Si el tipo de attr ya estaba establecido, el tipo antiguo se libera en la medida en que fue asignado dinámicamente. Después de llamar a esta función, attr puede estar en un estado inconsistente porque sus valores pueden no coincidir con el nuevo tipo de atributo.

X509_ATTRIBUTE_set1_data() establece attr como multivalor e inicializa su conjunto de valores para contener un nuevo objeto ASN.1 ANY que representa los datos.

La interpretación de los datos depende de los valores de los argumentos type y len; hay cuatro casos diferentes.

Si el argumento type tiene el bit MBSTRING_FLAG establecido, se espera que data apunte a una cadena de caracteres multibyte que tenga len bytes de longitud y utilice la codificación especificada por el argumento type, y se espera que un tipo de atributo ya haya sido asignado a attr, por ejemplo, llamando a X509_ATTRIBUTE_set1_object() antes de llamar a X509_ATTRIBUTE_set1_data(). En este caso, se elige un tipo de cadena multibyte ASN.1 apropiado y se asigna y popula un nuevo objeto de ese tipo para representar los datos llamando a ASN1_STRING_set_by_NID(3). El tipo de ese nuevo objeto de cadena ASN.1 se utiliza posteriormente en lugar del argumento type.

Si el argumento type no tiene el bit MBSTRING_FLAG establecido y el argumento len no es -1, se espera que el argumento type sea uno de los tipos documentados en ASN1_STRING_new(3) y se espera que data apunte a un búfer de len bytes. En este caso, se asigna un nuevo objeto con ASN1_STRING_type_new(3) y se popula con ASN1_STRING_set(3).

Si el argumento type no tiene el bit MBSTRING_FLAG establecido y el argumento len es -1, se espera que data apunte a un objeto del type dado en lugar de a un búfer. En este caso, se realiza una copia profunda del objeto existente en el nuevo objeto ASN.1 ANY con ASN1_TYPE_set1(3).

Si el argumento type es 0, los argumentos data y len se ignoran y el conjunto de valores se deja vacío en lugar de añadirle un único objeto ASN.1 ANY. Esto viola la sección 8.2 del estándar X.501, que requiere que cada atributo contenga al menos un valor, pero algunos tipos de atributos utilizados por la biblioteca usan conjuntos de valores vacíos de todos modos.

X509_ATTRIBUTE_create_by_OBJ() establece el tipo de **attr en obj usando X509_ATTRIBUTE_set1_object() y copia los datos en él usando X509_ATTRIBUTE_set1_data(). Si attr o *attr es NULL, se asigna, popula y devuelve un nuevo objeto X509_ATTRIBUTE.

X509_ATTRIBUTE_create_by_NID() es una envoltura alrededor de X509_ATTRIBUTE_create_by_OBJ() que obtiene el argumento obj requerido llamando a OBJ_nid2obj(3) en el argumento nid.

X509_ATTRIBUTE_create_by_txt() es una envoltura similar que obtiene obj llamando a OBJ_txt2obj(3) con los argumentos name y 0, lo que significa que los nombres largos, nombres cortos y cadenas OID numéricas son aceptables.

VALORES DEVUELTOS

X509_ATTRIBUTE_set1_object() devuelve 1 si tiene éxito o 0 si attr o obj es NULL o si falla la asignación de memoria.

X509_ATTRIBUTE_set1_data() devuelve 1 si tiene éxito o 0 si attr es NULL o si ASN1_STRING_set_by_NID(3), ASN1_STRING_set(3), ASN1_TYPE_set1(3), o falla la asignación de memoria.

X509_ATTRIBUTE_create_by_OBJ(), X509_ATTRIBUTE_create_by_NID(), y X509_ATTRIBUTE_create_by_txt() devuelven un puntero al objeto modificado o nuevo, o NULL si la obtención de obj, la asignación de memoria o la copia fallan.

VER TAMBIÉN

ASN1_OBJECT_new(3), ASN1_STRING_new(3), ASN1_STRING_set(3), ASN1_STRING_set_by_NID(3), ASN1_TYPE_new(3), OBJ_nid2obj(3), X509_ATTRIBUTE_get0_object(3), X509_ATTRIBUTE_new(3)

HISTORIA

BUGS

Si attr ya contiene uno o más valores, X509_ATTRIBUTE_set1_data(), X509_ATTRIBUTE_create_by_OBJ(), X509_ATTRIBUTE_create_by_NID() y X509_ATTRIBUTE_create_by_txt() sobrescriben silenciosamente los punteros a los valores antiguos y pierden la memoria utilizada para ellos.
