libressl-SSL_set_tmp_ecdh(3)

Paquete: libressl

Licencias: ISC, custom:OpenSSL

SSL_SET_TMP_ECDH(3) Manual de funciones de la biblioteca SSL_SET_TMP_ECDH(3)

NOMBRE

SSL_set_tmp_ecdh, SSL_CTX_set_tmp_ecdh, SSL_set_ecdh_auto, SSL_CTX_set_ecdh_auto, SSL_set_tmp_ecdh_callback, SSL_CTX_set_tmp_ecdh_callback — seleccionar una curva para el intercambio de claves ECDH efímero

SINOPSIS

biblioteca “libssl” libcrypto
#include <openssl/ssl.h>

long
SSL_set_tmp_ecdh(SSL *ssl, EC_KEY *ecdh);

long
SSL_CTX_set_tmp_ecdh(SSL_CTX *ctx, EC_KEY *ecdh);

long
SSL_set_ecdh_auto(SSL *ssl, int state);

long
SSL_CTX_set_ecdh_auto(SSL_CTX *ctx, int state);

void
SSL_set_tmp_ecdh_callback(SSL *ssl, EC_KEY *(*ecdh)(SSL *ssl, int is_export, int keylength));

void
SSL_CTX_set_tmp_ecdh_callback(SSL_CTX *ctx, EC_KEY *(*ecdh)(SSL *ssl, int is_export, int keylength));

DESCRIPCIÓN

La selección y generación automática de curvas EC está siempre habilitada en LibreSSL, y las aplicaciones no pueden proporcionar manualmente claves EC para su uso con el intercambio de claves ECDH.

El único efecto que queda de SSL_set_tmp_ecdh() es que la curva de la clave ecdh dada se convierte en la única curva habilitada para la conexión ssl, por lo que es equivalente a llamar a SSL_set1_groups(3) con el mismo nombre de curva único.

SSL_CTX_set_tmp_ecdh() tiene el mismo efecto en todas las conexiones que se crearán a partir de ctx en el futuro.

Las funciones SSL_set_ecdh_auto(), SSL_CTX_set_ecdh_auto(), SSL_set_tmp_ecdh_callback(), y SSL_CTX_set_tmp_ecdh_callback() están obsoletas y no tienen ningún efecto.

VALORES DEVUELTOS

SSL_set_tmp_ecdh() y SSL_CTX_set_tmp_ecdh() devuelven 1 en caso de éxito o 0 en caso de fallo.

SSL_set_ecdh_auto(), SSL_CTX_set_ecdh_auto(), SSL_set_tmp_ecdh_callback(), y SSL_CTX_set_tmp_ecdh_callback() siempre devuelven 1.

VER TAMBIÉN

ssl(3), SSL_CTX_set1_groups(3), SSL_CTX_set_cipher_list(3), SSL_CTX_set_options(3), SSL_CTX_set_tmp_dh_callback(3), SSL_new(3)

HISTORIA

SSL_set_tmp_ecdh(), SSL_CTX_set_tmp_ecdh(), SSL_set_tmp_ecdh_callback(), y SSL_CTX_set_tmp_ecdh_callback() aparecieron por primera vez en OpenSSL 0.9.8 y han estado disponibles desde OpenBSD 4.5.

SSL_CTX_set_ecdh_auto() y SSL_set_ecdh_auto() aparecieron por primera vez en OpenSSL 1.0.2 y han estado disponibles desde OpenBSD 5.7.
