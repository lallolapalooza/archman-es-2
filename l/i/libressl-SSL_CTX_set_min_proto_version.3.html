SSL_CTX_SET_MIN_PROTO_VERSION(3) Manual de funciones de biblioteca SSL_CTX_SET_MIN_PROTO_VERSION(3)

NOMBRE

SSL_CTX_set_min_proto_version, SSL_CTX_set_max_proto_version, SSL_CTX_get_min_proto_version, SSL_CTX_get_max_proto_version, SSL_set_min_proto_version, SSL_set_max_proto_version, SSL_get_min_proto_version, SSL_get_max_proto_version — obtener y establecer la versión mínima y máxima de protocolo admitida

SINOPSIS

biblioteca “libssl” libcrypto
#include <openssl/ssl.h>

int
SSL_CTX_set_min_proto_version(SSL_CTX *ctx, uint16_t version);

int
SSL_CTX_set_max_proto_version(SSL_CTX *ctx, uint16_t version);

int
SSL_CTX_get_min_proto_version(SSL_CTX *ctx);

int
SSL_CTX_get_max_proto_version(SSL_CTX *ctx);

int
SSL_set_min_proto_version(SSL *ssl, uint16_t version);

int
SSL_set_max_proto_version(SSL *ssl, uint16_t version);

int
SSL_get_min_proto_version(SSL *ssl);

int
SSL_get_max_proto_version(SSL *ssl);

DESCRIPCIÓN

Estas funciones obtienen o establecen las versiones mínimas y máximas de protocolo admitidas para ctx o ssl. Esto funciona en combinación con las opciones establecidas a través de SSL_CTX_set_options(3) que también permiten deshabilitar versiones de protocolo específicas. Use estas funciones en lugar de deshabilitar versiones de protocolo específicas.

Establecer la versión mínima o máxima a 0 habilitará las versiones de protocolo hasta la versión más baja o hasta la versión más alta admitida por la biblioteca, respectivamente.

Actualmente, las versiones admitidas son TLS1_VERSION, TLS1_1_VERSION y TLS1_2_VERSION para TLS y DTLS1_VERSION y DTLS1_2_VERSION para DTLS.

En otras implementaciones, estas funciones pueden implementarse como macros.

VALORES DE RETORNO

Las funciones de establecimiento devuelven 1 si tienen éxito o 0 si fallan.

Las funciones de obtención devuelven la versión configurada o 0 si ctx o ssl se han configurado para utilizar automáticamente la versión más baja o más alta admitida por la biblioteca.

VER TAMBIÉN

ssl(3), SSL_CTX_new(3), SSL_CTX_set_options(3)

HISTORIA

Las funciones de establecimiento aparecieron por primera vez en BoringSSL en diciembre de 2014, con nombres más cortos sin la parte proto_. Dos años después, OpenSSL las incluyó en su lanzamiento 1.1.0, cambiando gratuitamente los nombres; Google se encogió de hombros y adoptó los nombres más largos un mes después. Han estado disponibles desde OpenBSD 6.2.

Las funciones de obtención aparecieron por primera vez en OpenSSL 1.1.0g y han estado disponibles desde OpenBSD 6.3.
