EVP_CIPHER_CTX_CTRL(3) Manual de funciones de biblioteca EVP_CIPHER_CTX_CTRL(3)

NOMBRE

EVP_CIPHER_CTX_ctrl, EVP_CIPHER_CTX_set_padding, EVP_CIPHER_CTX_set_key_length, EVP_CIPHER_CTX_key_length, EVP_CIPHER_key_length, EVP_CIPHER_CTX_iv_length, EVP_CIPHER_iv_length, EVP_CIPHER_CTX_set_iv, EVP_CIPHER_CTX_get_iv — configurar contextos de cifrado EVP

SINOPSIS

biblioteca “libcrypto”
#include <openssl/evp.h>

int
EVP_CIPHER_CTX_ctrl(EVP_CIPHER_CTX *ctx, int type, int arg, void *ptr);

int
EVP_CIPHER_CTX_set_padding(EVP_CIPHER_CTX *x, int padding);

int
EVP_CIPHER_CTX_set_key_length(EVP_CIPHER_CTX *x, int keylen);

int
EVP_CIPHER_CTX_key_length(const EVP_CIPHER_CTX *ctx);

int
EVP_CIPHER_key_length(const EVP_CIPHER *e);

int
EVP_CIPHER_CTX_iv_length(const EVP_CIPHER_CTX *ctx);

int
EVP_CIPHER_iv_length(const EVP_CIPHER *e);

int
EVP_CIPHER_CTX_set_iv(EVP_CIPHER_CTX *ctx, const unsigned char *iv, size_t len);

int
EVP_CIPHER_CTX_get_iv(const EVP_CIPHER_CTX *ctx, unsigned char *iv, size_t len);

DESCRIPCIÓN

EVP_CIPHER_CTX_ctrl() permite determinar y establecer varios parámetros específicos del cifrado. Actualmente, solo se puede establecer la longitud efectiva de la clave RC2; ver EVP_rc2_cbc(3) para detalles.

EVP_CIPHER_CTX_set_padding() habilita o deshabilita el relleno. Esta función debe llamarse después de que el contexto se haya configurado para cifrado o descifrado con EVP_EncryptInit_ex(3), EVP_DecryptInit_ex(3), o EVP_CipherInit_ex(3). Por defecto, las operaciones de cifrado se rellenan utilizando el relleno de bloque estándar y el relleno se comprueba y se elimina al descifrar. Si el parámetro padding es cero, entonces no se realiza relleno, la cantidad total de datos cifrados o descifrados debe ser un múltiplo del tamaño del bloque o se producirá un error.

EVP_CIPHER_CTX_set_key_length() establece la longitud de la clave del contexto del cifrador. Si el cifrador es de longitud fija, intentar establecer la longitud de la clave a un valor distinto del valor fijo es un error.

EVP_CIPHER_CTX_key_length() y EVP_CIPHER_key_length() devuelven la longitud de la clave de un cifrador cuando se les pasa una estructura EVP_CIPHER_CTX o EVP_CIPHER. La constante EVP_MAX_KEY_LENGTH es la longitud máxima de clave para todos los cifradores. Nota: aunque EVP_CIPHER_key_length() es fija para un cifrador dado, el valor de EVP_CIPHER_CTX_key_length() puede ser diferente para cifradores de longitud de clave variable.

EVP_CIPHER_CTX_iv_length() y EVP_CIPHER_iv_length() devuelven la longitud del IV de un cifrador cuando se les pasa un EVP_CIPHER_CTX o EVP_CIPHER. Devolverán cero si el cifrador no utiliza un IV. EVP_CIPHER_CTX_iv_length() puede fallar y devolver -1. La constante EVP_MAX_IV_LENGTH es la longitud máxima del IV para todos los cifradores.

EVP_CIPHER_CTX_set_iv() y EVP_CIPHER_CTX_get_iv() establecen y recuperan el IV para un EVP_CIPHER_CTX, respectivamente. En ambos casos, la longitud del IV especificada debe ser exactamente igual a la longitud del IV esperada para el contexto, tal como la devuelve EVP_CIPHER_CTX_iv_length().

VALORES DE RETORNO

EVP_CIPHER_CTX_ctrl() devuelve 1 en caso de éxito o 0 en caso de fallo. Algunas implementaciones pueden devolver valores negativos para algunos errores.

EVP_CIPHER_CTX_set_padding() siempre devuelve 1.

EVP_CIPHER_CTX_set_key_length(), EVP_CIPHER_CTX_set_iv(), y EVP_CIPHER_CTX_get_iv() devuelven 1 en caso de éxito o 0 en caso de fallo.

EVP_CIPHER_CTX_key_length() y EVP_CIPHER_key_length() devuelven la longitud de la clave.

EVP_CIPHER_CTX_iv_length() y EVP_CIPHER_iv_length() devuelven la longitud del IV o cero si el cifrador no utiliza un IV. EVP_CIPHER_CTX_iv_length() puede fallar y devolver -1.

VER TAMBIÉN

evp(3), EVP_CIPHER_nid(3), EVP_EncryptInit(3)

HISTORIAL

EVP_CIPHER_CTX_key_length(), EVP_CIPHER_key_length(), EVP_CIPHER_CTX_iv_length(), y EVP_CIPHER_iv_length() aparecieron por primera vez en SSLeay 0.6.5 y han estado disponibles desde OpenBSD 2.4.

EVP_CIPHER_CTX_ctrl() y EVP_CIPHER_CTX_set_key_length() aparecieron por primera vez en OpenSSL 0.9.6 y han estado disponibles desde OpenBSD 2.9.

EVP_CIPHER_CTX_set_padding() apareció por primera vez en OpenSSL 0.9.7 y ha estado disponible desde OpenBSD 3.2.

EVP_CIPHER_CTX_set_iv() y EVP_CIPHER_CTX_get_iv() aparecieron por primera vez en LibreSSL 2.8.1 y han estado disponibles desde OpenBSD 6.4.

ERRORES

EVP_MAX_KEY_LENGTH y EVP_MAX_IV_LENGTH solo se refieren a los cifradores internos con longitudes de clave predeterminadas. Si los cifradores personalizados superan estos valores, los resultados son impredecibles. Esto se debe a que se ha convertido en una práctica estándar definir una clave genérica como una matriz unsigned char fija que contiene EVP_MAX_KEY_LENGTH bytes.
