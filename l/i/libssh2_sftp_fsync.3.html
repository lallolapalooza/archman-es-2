libssh2_sftp_fsync(3)

Paquete: libssh2

Licencias: BSD

libssh2_sftp_fsync(3) libssh2 libssh2_sftp_fsync(3)

NOMBRE

libssh2_sftp_fsync - sincronizar archivo con disco

SINOPSIS

#include <libssh2.h>
#include <libssh2_sftp.h>
int
libssh2_sftp_fsync(LIBSSH2_SFTP_HANDLE *handle)

DESCRIPCIÓN

Esta función provoca que el servidor remoto sincronice los datos y metadatos del archivo con el disco (similar a fsync(2)).

Para que esto funcione, se requiere el soporte de fsync@openssh.com en el servidor.

handle - Identificador de archivo SFTP devuelto por libssh2_sftp_open_ex(3)

VALOR DE RETORNO

Devuelve 0 en caso de éxito o un valor negativo en caso de fallo. Si se utiliza en modo no bloqueante, devuelve LIBSSH2_ERROR_EAGAIN cuando de lo contrario se bloquearía. Si bien LIBSSH2_ERROR_EAGAIN es un número negativo, no es realmente un fallo en sí.

ERRORES

LIBSSH2_ERROR_ALLOC - Falló una llamada interna de asignación de memoria.

LIBSSH2_ERROR_SOCKET_SEND - No se pudieron enviar datos por el socket.

LIBSSH2_ERROR_SFTP_PROTOCOL - Se recibió una respuesta inválida del protocolo SFTP en el socket, o una operación SFTP causó que el servidor devolviera un código de error. En particular, esto puede devolverse si el servidor SSH no admite la operación fsync: en este caso se devolverá el subcódigo SFTP LIBSSH2_FX_OP_UNSUPPORTED.

DISPONIBILIDAD

Añadido en libssh2 1.4.4 y OpenSSH 6.3.

VER TAMBIÉN

fsync(2)
