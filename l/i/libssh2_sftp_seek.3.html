libssh2_sftp_seek(3)

Paquete: libssh2

Licencias: BSD

libssh2_sftp_seek(3) libssh2 libssh2_sftp_seek(3)

NOMBRE

libssh2_sftp_seek - establece el indicador de posición de lectura/escritura dentro de un archivo

SINOPSIS

#include <libssh2.h>
#include <libssh2_sftp.h>
void
libssh2_sftp_seek(LIBSSH2_SFTP_HANDLE *handle,
                  size_t offset);

DESCRIPCIÓN

Función obsoleta. ¡Use libssh2_sftp_seek64(3) en su lugar!

handle - Identificador de archivo SFTP devuelto por libssh2_sftp_open_ex(3)

offset - Número de bytes desde el principio del archivo hasta donde buscar.

Mueve el puntero interno del identificador de archivo a una ubicación arbitraria. Tenga en cuenta que libssh2 implementa los punteros de archivo como un concepto localizado para hacer que el acceso a archivos parezca más similar a POSIX. No se intercambian paquetes con el servidor durante una operación de búsqueda. El puntero de archivo localizado se utiliza como un desplazamiento de conveniencia durante las operaciones de lectura/escritura.

VER TAMBIÉN

libssh2_sftp_open_ex(3), libssh2_sftp_seek64(3)
