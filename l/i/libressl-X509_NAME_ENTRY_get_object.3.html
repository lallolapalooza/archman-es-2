DESCRIPCIÓN

Un RelativeDistinguishedName de X.501 es un conjunto ordenado de pares de tipo de campo y valor. Es el bloque de construcción para construir objetos Name de X.501. El objeto X509_NAME_ENTRY almacena un par de estos, conteniendo un tipo de campo y un valor.

Los objetos X509_NAME_ENTRY están destinados a ser utilizados por los objetos X509_NAME documentados en X509_NAME_new(3). Dado que parte de la información sobre cómo varios objetos X509_NAME_ENTRY se combinan para formar un Name de X.501 se almacena en los objetos X509_NAME_ENTRY individuales en lugar de en el objeto X509_NAME, cualquier objeto X509_NAME_ENTRY dado solo puede ser utilizado por un objeto X509_NAME a la vez.

X509_NAME_ENTRY_new() asigna e inicializa un objeto vacío X509_NAME_ENTRY, representando una estructura RelativeDistinguishedName ASN.1 definida en la sección 4.1.2.4 de RFC 5280, pero que no contiene más de un par tipo-valor.

X509_NAME_ENTRY_free() libera ne y el tipo y valor contenidos en él.

X509_NAME_ENTRY_get_object() recupera el tipo de campo de ne en una estructura ASN1_OBJECT. X509_NAME_ENTRY_get_data() recupera el valor del campo de ne en una estructura ASN1_STRING. Estas dos funciones se pueden utilizar para examinar un objeto X509_NAME_ENTRY devuelto por X509_NAME_get_entry(3).

X509_NAME_ENTRY_set() recupera el índice del RelativeDistinguishedName (RDN) de X.501 del que ne forma parte en el objeto Name de X.501 que lo utiliza. El primer RDN tiene el índice 0. Si un RDN consta de más de un objeto X509_NAME_ENTRY, todos comparten el mismo índice. En la práctica, los RDN que contienen más de un par tipo-valor se utilizan raramente, por lo que si un objeto X509_NAME *name utiliza ne, entonces X509_NAME_ENTRY_set(ne) generalmente concuerda con sk_X509_NAME_ENTRY_find(name->entries, ne), pero cuando se utilizan RDNs de múltiples pares, puede ser menor.

X509_NAME_ENTRY_set_object() establece el tipo de campo de ne a obj.

X509_NAME_ENTRY_set_data() establece el valor del campo de ne a la cadena dada type y el valor determinado por bytes y len. Si el argumento type es positivo e incluye el bit MBSTRING_FLAG, se utiliza ASN1_STRING_set_by_NID(3) para establecer el valor, pasando type como argumento inform y utilizando el nid correspondiente a ne. De lo contrario, si el argumento type es V_ASN1_APP_CHOOSE, el tipo de ne se establece al valor devuelto por ASN1_PRINTABLE_type(3).

X509_NAME_ENTRY_create_by_txt(), X509_NAME_ENTRY_create_by_NID(), y X509_NAME_ENTRY_create_by_OBJ() crean y devuelven una estructura X509_NAME_ENTRY.

Excepto para X509_NAME_ENTRY_get_object() y X509_NAME_ENTRY_get_data(), estas funciones se utilizan raramente porque las estructuras X509_NAME_ENTRY son casi siempre parte de estructuras X509_NAME y las funciones descritas en X509_NAME_add_entry_by_txt(3) se utilizan típicamente para crear y añadir nuevas entradas en una sola operación.

DESCRIPTION

An X509_NAME is a multi-valued attribute consisting of a sequence of relative distinguished names (RDNs). Each RDN is itself a set of attribute-value pairs. X509_NAME_ENTRY represents a single attribute-value pair within an RDN.

The function X509_NAME_ENTRY_new() allocates and initializes a new, empty X509_NAME_ENTRY structure. The caller is responsible for freeing it with X509_NAME_ENTRY_free(3).

The function X509_NAME_ENTRY_get_object() returns the attribute type of the entry ne. The type is represented by an ASN1_OBJECT structure.

The function X509_NAME_ENTRY_get_data() returns the attribute value of the entry ne. The value is represented by an ASN1_STRING structure.

The function X509_NAME_ENTRY_set() sets the attribute type and value of the entry ne to obj and data respectively. The index of the RDN that ne is a part of is returned. If ne is not yet part of any X509_NAME object, 0 is returned.

The function X509_NAME_ENTRY_set_object() sets the attribute type of the entry ne to obj.

The function X509_NAME_ENTRY_set_data() sets the attribute value of the entry ne to data.

The functions X509_NAME_ENTRY_create_by_txt(), X509_NAME_ENTRY_create_by_NID(), and X509_NAME_ENTRY_create_by_OBJ() create and return a new X509_NAME_ENTRY structure based on the supplied attribute type and value. The attribute type is specified by a text string txt and its length len in X509_NAME_ENTRY_create_by_txt(), by an integer object identifier number (NID) nid in X509_NAME_ENTRY_create_by_NID(), or by an ASN1_OBJECT structure obj in X509_NAME_ENTRY_create_by_OBJ(). The attribute value is specified by a character string bytes and its length byteslen.

The type argument in X509_NAME_ENTRY_create_by_txt() specifies the ASN1 type of the attribute value, for example V_ASN1_UTF8 . If type is 0, the type is determined from txt.

The created X509_NAME_ENTRY structure must be freed by the caller using X509_NAME_ENTRY_free(3).

The underlying field information for the attribute type can be looked up internally.

RETURN VALUES

The X509_NAME_ENTRY_new() function returns a valid X509_NAME_ENTRY structure if successful; otherwise NULL is returned and an error code can be retrieved with ERR_get_error(3).

X509_NAME_ENTRY_get_object() returns a valid ASN1_OBJECT structure if it is set or NULL if an error occurred.

X509_NAME_ENTRY_get_data() returns a valid ASN1_STRING structure if it is set or NULL if an error occurred.

X509_NAME_ENTRY_set() returns the zero-based index of the RDN ne is used in, or 0 if ne is not yet used by any X509_NAME object.

The X509_NAME_ENTRY_set_object() function returns 1 if successful; otherwise 0 is returned and an error code can be retrieved with ERR_get_error(3).

X509_NAME_ENTRY_set_data() returns 1 on success or 0 on error. In some cases of failure, the reason can be determined with ERR_get_error(3).

X509_NAME_ENTRY_create_by_txt(), X509_NAME_ENTRY_create_by_NID(), and X509_NAME_ENTRY_create_by_OBJ() return a valid X509_NAME_ENTRY structure on success or NULL if an error occurred. In some cases of failure, the reason can be determined with ERR_get_error(3).

HISTORY

X509_NAME_ENTRY_new() and X509_NAME_ENTRY_free() first appeared in SSLeay 0.5.1. X509_NAME_ENTRY_get_object(), X509_NAME_ENTRY_get_data(), X509_NAME_ENTRY_set_object(), X509_NAME_ENTRY_set_data(), X509_NAME_ENTRY_create_by_NID(), and X509_NAME_ENTRY_create_by_OBJ() first appeared in SSLeay 0.8.0. These functions have been available since OpenBSD 2.4.

X509_NAME_ENTRY_create_by_txt() first appeared in OpenSSL 0.9.5 and has been available since OpenBSD 2.7.

X509_NAME_ENTRY_set() first appeared in OpenSSL 1.1.0 and has been available since OpenBSD 6.3.

CAVEATS

Despite its name, X509_NAME_ENTRY_set() does not set anything. Something like “X509_NAME_ENTRY_get_set” would have been a better name.
