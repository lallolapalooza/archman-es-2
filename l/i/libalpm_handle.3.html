Documentación de Typedef

typedef struct _alpm_handle_t alpm_handle_t

El manejador de contexto de libalpm. Esta estructura representa una instancia de libalpm.

Documentación de Funciones

alpm_handle_t * alpm_initialize (const char * root, const char * dbpath, alpm_errno_t * err)

Inicializa la biblioteca. Crea el manejador, se conecta a la base de datos y crea el archivo de bloqueo. Esto debe llamarse antes de que se llamen otras funciones.

Parámetros

root la ruta raíz para todas las operaciones del sistema de archivos
dbpath la ruta absoluta a la base de datos de libalpm
err una variable opcional para contener los códigos de retorno de error

Retorna

un manejador de contexto en caso de éxito, NULL en caso de error, err se establecerá si se proporciona

int alpm_release (alpm_handle_t * handle)

Libera la biblioteca. Desconecta de la base de datos, elimina el manejador y el archivo de bloqueo. Esta debería ser la última llamada a alpm que realices. Después de que esto retorne, el manejador debe considerarse inválido y no puede ser reutilizado de ninguna manera.

Parámetros

handle el manejador de contexto

Retorna

0 en caso de éxito, -1 en caso de error
