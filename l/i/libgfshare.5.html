LIBGFSHARE(5) Compartición de secretos de Shamir en gf(2**8) LIBGFSHARE(5)

NOMBRE

gfshare_ctx_init_enc, etc. - Compartición de secretos de Shamir

SINOPSIS

#include <libgfshare.h>

gfshare_rand_func_t gfshare_fill_rand;

gfshare_rand_func_t gfshare_bad_idea_but_fill_rand_using_random;

gfshare_ctx *gfshare_ctx_init_enc( unsigned char *sharenrs,
                                   unsigned int   sharecount,
                                   unsigned char  threshold,
                                   unsigned int   size );

gfshare_ctx *gfshare_ctx_init_dec( unsigned char *sharenrs,
                                   unsigned int   sharecount,
                                   unsigned int   size );

void gfshare_ctx_free( gfshare_ctx *ctx );

void gfshare_ctx_enc_setsecret( gfshare_ctx   *ctx,
                                unsigned char *secret );

void gfshare_ctx_enc_getshare( gfshare_ctx   *ctx,
                               unsigned char  sharenr,
                               unsigned char *share );

void gfshare_ctx_dec_newshares( gfshare_ctx   *ctx,
                                unsigned char *sharenrs );

void gfshare_ctx_dec_giveshare( gfshare_ctx   *ctx,
                                unsigned char  sharenr,
                                unsigned char *share );

void gfshare_ctx_dec_extract( gfshare_ctx   *ctx,
                              unsigned char *secretbuf );

DESCRIPCIÓN

La variable gfshare_fill_rand debe contener un puntero a una función que tome un unsigned char * y un unsigned int y llene el buffer dado con el número dado de bytes aleatorios antes de llamar a cualquiera de las funciones que crean o pueblan contextos.
Si no puede hacer esto con un mecanismo criptográficamente seguro, entonces la biblioteca proporciona el valor gfshare_bad_idea_but_fill_rand_using_random que puede colocar en gfshare_fill_rand y que usará la función de biblioteca C random() para llenar el buffer. Debe asegurarse de llamar a srandom() al menos una vez antes de usar cualquiera de las otras funciones.

La función gfshare_ctx_init_enc() devuelve un objeto de contexto que se puede utilizar para codificar comparticiones de un secreto. El contexto codifica contra sharecount comparticiones que están numeradas en el array sharenrs. El secreto siempre tiene una longitud de size bytes y las comparticiones resultantes necesitarán al menos threshold de las comparticiones presentes para la recombinación. Es crítico que threshold sea al menos uno menor que sharecount.

La función gfshare_ctx_init_dec() devuelve un objeto de contexto que se puede utilizar para recombinar comparticiones y recuperar un secreto. Cada compartición y el secreto resultante tendrán una longitud de size bytes. El contexto se puede utilizar para recombinar sharecount comparticiones que están numeradas en el array sharenrs.

La función gfshare_ctx_free() libera toda la memoria asociada con un contexto de gfshare, incluida la memoria perteneciente al propio contexto.

La función gfshare_ctx_enc_setsecret() proporciona el secreto que desea codificar al contexto. El secret se copiará en el buffer interno de la biblioteca.

La función gfshare_ctx_enc_getshare() extrae una compartición particular del contexto. El buffer share debe estar preasignado al tamaño de las comparticiones y el parámetro sharenr es un índice en el array sharenrs utilizado para inicializar el contexto.

La función gfshare_ctx_dec_newshares() informa al contexto de decodificación sobre un cambio en los números de compartición disponibles para el contexto. El número de comparticiones no se puede cambiar, pero sharenrs se puede poner a cero para indicar que una compartición particular falta actualmente.

La función gfshare_ctx_dec_giveshare() proporciona al contexto de decodificación una compartición dada. El número de compartición en sí fue proporcionado previamente en un array sharenrs y el parámetro sharenr es el índice en ese array del número de la compartición que se proporciona en el bloque de memoria share.

La función gfshare_ctx_dec_extract() combina las comparticiones proporcionadas para recalcular el secreto. Se recomienda que ejecute mlock() en secretbuf antes de llamar a esta función, para que el secreto recombinado nunca se escriba en el swap. Esto puede ayudar a evitar que una parte malintencionada descubra el contenido de su secreto. También debe aleatorizar el contenido del buffer una vez que haya terminado de usar el secreto recombinado.

ERRORES

Cualquier función que pueda fallar por cualquier motivo devolverá NULL en caso de error.
