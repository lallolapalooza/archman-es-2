LIBQUVI(3) Manual de libquvi LIBQUVI(3)

NOMBRE

libquvi - Visión general de la biblioteca

DESCRIPCIÓN

libquvi es una biblioteca multiplataforma con API en C para analizar propiedades de medios Flash de Adobe. "quvi" es un acrónimo de "query video" (consultar video).

ENTORNO

LIBQUVI_EXCLUSIVE_SCRIPTS_DIR

Cuando se define, la biblioteca usará únicamente aquellos scripts encontrados en los directorios especificados por LIBQUVI_SCRIPTS_DIR.

Nota
Útil, por ejemplo, cuando el conjunto actual de scripts en $top_srcdir/share/ (de libquvi-scripts) está siendo probado por la suite de pruebas de libquvi-scripts. La biblioteca, de lo contrario, incluiría los scripts de la instancia de libquvi-scripts compilada con la biblioteca y probablemente interferiría con las pruebas.

LIBQUVI_SCRIPTS_DIR

La biblioteca buscará adicionalmente en la lista de directorios separados por dos puntos especificada por la variable de entorno LIBQUVI_SCRIPTS_DIR.

LIBQUVI_SCRIPTS_VERBOSE

Cuando se define, habilita la salida de cualquier script de libquvi que utilice la instalación de depuración (módulo quvi/debug).

LIBQUVI_SHOW_DIR

Cuando se define, la biblioteca mostrará las rutas de los directorios buscados en stderr.

LIBQUVI_SHOW_SCRIPT

Cuando se define, la biblioteca mostrará los nombres de archivo de los scripts encontrados en stderr. La salida también indicará si el script fue aceptado por la biblioteca.

Proxy

libquvi utiliza libcurl(3). Consulte la documentación de libcurl (API en C y/o curl(1)) para obtener una lista completa de las variables de entorno de proxy soportadas.
