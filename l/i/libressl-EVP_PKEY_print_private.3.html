libressl-EVP_PKEY_print_private(3)

Paquete: libressl

Licencias: ISC, custom:OpenSSL

EVP_PKEY_PRINT_PRIVATE(3) Manual de funciones de la biblioteca EVP_PKEY_PRINT_PRIVATE(3)

NOMBRE

EVP_PKEY_print_public, EVP_PKEY_print_private, EVP_PKEY_print_params — rutinas de impresión de algoritmos de claves públicas

SINOPSIS

biblioteca “libcrypto”
#include <openssl/evp.h>

int
EVP_PKEY_print_public(BIO *out, const EVP_PKEY *pkey, int indent, ASN1_PCTX *pctx);

int
EVP_PKEY_print_private(BIO *out, const EVP_PKEY *pkey, int indent, ASN1_PCTX *pctx);

int
EVP_PKEY_print_params(BIO *out, const EVP_PKEY *pkey, int indent, ASN1_PCTX *pctx);

DESCRIPCIÓN

Las funciones EVP_PKEY_print_public(), EVP_PKEY_print_private(), y EVP_PKEY_print_params() imprimen los componentes públicos, privados o de parámetros de la clave pkey, respectivamente. La clave se envía a BIO out en formato legible por humanos. El parámetro indent indica el nivel de sangría de la impresión.

El parámetro pctx permite ajustar finamente la salida de la impresión utilizando opciones de impresión ASN.1. Si pctx se establece en NULL, se utilizarán los valores predeterminados. Actualmente, ningún algoritmo de clave pública incluye opciones en el parámetro pctx.

Si la clave no incluye todos los componentes indicados por la función, solo se imprimirán los que contiene la clave. Por ejemplo, pasar una clave pública a EVP_PKEY_print_private() solo imprimirá los componentes públicos.

VALORES DE RETORNO

Estas funciones devuelven 1 en caso de éxito y 0 o un valor negativo en caso de fallo. En particular, un valor de retorno de -2 indica que la operación no es compatible con el algoritmo de clave pública.

VER TAMBIÉN

EVP_PKEY_CTX_new(3), EVP_PKEY_keygen(3), EVP_PKEY_new(3)

HISTORIAL

Estas funciones aparecieron por primera vez en OpenSSL 1.0.0 y han estado disponibles desde OpenBSD 4.9.
