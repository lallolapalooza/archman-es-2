NOMBRE

libpipewire-module-vban-recv - Receptor VBAN

DESCRIPCIÓN

El módulo vban-recv crea una fuente de PipeWire que recibe paquetes VBAN de audio y midi.

El receptor escuchará en un puerto específico (6980) y creará un stream para cada stream VBAN recibido en el puerto.

NOMBRE DEL MÓDULO

libpipewire-module-vban-recv

OPCIONES DEL MÓDULO

Opciones específicas del comportamiento de este módulo

  • local.ifname = <str>: nombre de la interfaz a usar
  • source.ip = <str>: la dirección IP de origen en la que escuchar, por defecto 127.0.0.1
  • source.port = <int>: el puerto de origen en el que escuchar, por defecto 6980
  • node.always-process = <bool>: true para recibir incluso cuando no se está ejecutando
  • sess.latency.msec = <str>: latencia de red objetivo en milisegundos, por defecto 100
  • stream.props = {}: propiedades que se pasarán a todos los streams
  • stream.rules = <rules>: reglas de coincidencia, usar acciones create-stream.

coincidencias de stream.rules

  • vban.ip: la dirección IP del remitente VBAN
  • vban.port: el puerto del remitente VBAN
  • sess.name: el nombre del stream VBAN

create-stream de stream.rules

Además de todas las propiedades que se pueden pasar a un stream, también puedes establecer:

•
sess.latency.msec = <str>: latencia de red objetivo en milisegundos, por defecto 100

OPCIONES GENERALES

Opciones con comportamiento bien conocido:

  • remote.name
  • audio.position
  • media.name
  • media.class
  • node.name
  • node.description
  • node.group
  • node.latency
  • node.virtual

EJEMPLO DE CONFIGURACIÓN

# ~/.config/pipewire/pipewire.conf.d/my-vban-recv.conf
context.modules = [
{   name = libpipewire-module-vban-recv
    args = {
        #local.ifname = eth0
        #source.ip = 127.0.0.1
        #source.port = 6980
        sess.latency.msec = 100
        #node.always-process = false
        #audio.position = [ FL FR ]
        stream.props = {
           #media.class = "Audio/Source"
           #node.name = "vban-receiver"
        }
        stream.rules = [
            {   matches = [
                    {    sess.name = "~.*"
                         #sess.media = "audio" | "midi"
                         #vban.ip = ""
                         #vban.port = 1000
                         #audio.channels = 2
                         #audio.format = "U8" | "S16LE" | "S24LE" | "S32LE" | "F32LE" | "F64LE"
                         #audio.rate = 44100
                    }
                ]
                actions = {
                    create-stream = {
                        stream.props = {
                            #sess.latency.msec = 100
                            #target.object = ""
                            #audio.position = [ FL FR ]
                            #media.class = "Audio/Source"
                            #node.name = "vban-receiver"
                        }
                    }
                }
            }
        ]
    }
}
]
