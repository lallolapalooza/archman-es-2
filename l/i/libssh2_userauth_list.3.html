libssh2_userauth_list(3)

Paquete: libssh2

Licencias: BSD

libssh2_userauth_list(3) libssh2 libssh2_userauth_list(3)

NOMBRE

libssh2_userauth_list - lista de métodos de autenticación admitidos

SINOPSIS

#include <libssh2.h>
char *
libssh2_userauth_list(LIBSSH2_SESSION *session,
                      const char *username,
                      unsigned int username_len);

DESCRIPCIÓN

session - Instancia de sesión devuelta por libssh2_session_init_ex(3)

username - Nombre de usuario que se utilizará durante la autenticación. Tenga en cuenta que la mayoría de las implementaciones de servidor no permiten intentar la autenticación con diferentes nombres de usuario entre solicitudes. Por lo tanto, este debe ser el mismo nombre de usuario que utilizará en las llamadas posteriores de autenticación de usuario.

username_len - Longitud del parámetro username.

Envía una solicitud SSH_USERAUTH_NONE al host remoto. A menos que el host remoto esté configurado para aceptar "none" como un esquema de autenticación viable (improbable), devolverá SSH_USERAUTH_FAILURE junto con una lista de los esquemas de autenticación que sí admite. En el improbable caso de que la autenticación "none" tenga éxito, este método devolverá NULL. Este caso puede distinguirse de un caso fallido examinando libssh2_userauth_authenticated(3).

VALOR DE RETORNO

En caso de éxito, una lista separada por comas de los esquemas de autenticación admitidos. Esta lista es administrada internamente por libssh2. En caso de fallo, devuelve NULL.

ERRORES

LIBSSH2_ERROR_ALLOC - Falló una llamada interna de asignación de memoria.

LIBSSH2_ERROR_SOCKET_SEND - No se pudieron enviar datos en el socket.

LIBSSH2_ERROR_EAGAIN - Marcado para E/S no bloqueante pero la llamada

VER TAMBIÉN
