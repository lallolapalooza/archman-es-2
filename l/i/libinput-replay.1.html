NOMBRE

libinput-replay - reproducir eventos del kernel a partir de una grabación

SINOPSIS

libinput replay [opciones] grabación

DESCRIPCIÓN

La herramienta libinput replay reproduce eventos del kernel de una grabación de dispositivo realizada con la herramienta libinput record(1). Esta herramienta necesita ejecutarse como root para crear un dispositivo y/o reproducir eventos.

Si la grabación contiene más de un dispositivo, todos los dispositivos se reproducen simultáneamente.

OPCIONES

--help
Imprimir ayuda
--once
Reproducir la grabación solo una vez y luego salir.
--replay-after=s
Reproducir la grabación después de esperar s segundos. Esto reemplaza el mensaje interactivo predeterminado para iniciar la reproducción.

NOTAS

Esta herramienta reproduce eventos de una grabación a través del kernel y es independiente de libinput. En otras palabras, actualizar o cambiar libinput de cualquier otra manera no alterará la salida de esta herramienta. libinput en sí mismo no necesita estar en uso para reproducir eventos.

Esta herramienta no reproduce eventos de repetición de teclas emulados por el kernel (eventos de tipo EV_KEY con un valor de 2).
