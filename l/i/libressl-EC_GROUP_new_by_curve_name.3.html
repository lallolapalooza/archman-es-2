DESCRIPCIÓN

La mayoría de las curvas elípticas utilizadas en protocolos criptográficos tienen una representación estandarizada como curva nombrada, donde se utiliza un Identificador de Objeto (OID) ASN.1 en lugar de parámetros de dominio detallados. Este OID se representa internamente mediante un Identificador Numérico (NID), y los propios parámetros deben estar integrados en la biblioteca. En la biblioteca EC, el nombre de la curva se refiere a este NID.

EC_GROUP_new_by_curve_name() devuelve un nuevo objeto EC_GROUP que representa la curva nombrada correspondiente al nid, utilizando los parámetros integrados en la biblioteca. Es equivalente a pasar los parámetros apropiados a EC_GROUP_new_curve_GFp(3), EC_GROUP_set_curve_name(3), EC_GROUP_set_generator(3) y EC_GROUP_set_seed(3).

EC_GROUP_free() libera group y toda la memoria asociada a él. Si group es NULL, no se realiza ninguna acción.

EC_GROUP_dup() crea una copia profunda de group.

EC_GROUP_cmp() está diseñado para determinar si group1 y group2 representan la misma curva elíptica, haciendo uso del ctx opcional. Si el nombre de la curva está establecido en ambas curvas, se comparan como enteros, luego el campo primo, los coeficientes de la ecuación de Weierstrass, los generadores, su orden y sus cofactores se comparan usando BN_cmp(3) o EC_POINT_cmp(3), respectivamente.

EC_get_builtin_curves() devuelve el número de curvas integradas. Si curves es NULL o ncurves es cero, no realiza ninguna otra acción. De lo contrario, después de reducir ncurves al número de curvas integradas si es necesario, copia el nid y un puntero al comment de las primeras ncurves curvas integradas al array de objetos EC_builtin_curve apuntado por curves y deja el resto del array sin inicializar.

Algunas curvas pueden identificarse por su nombre NIST además del identificador numérico (NID). EC_curve_nist2nid() y EC_curve_nid2nist() traducen entre ambos. Las curvas NIST integradas sobre un campo primo son:

NIST nombre NID ASN.1 notas
"P-224" NID_secp224r1
"P-256" NID_X9_62_prime256v1 también conocido como secp256r1
"P-384" NID_secp384r1
"P-521" NID_secp521r1

EC_curve_nist2nid() y EC_curve_nid2nist() también aceptan las curvas binarias definidas en FIPS 186-4 y obsoletas en SP800-186, así como "P-192" y NID_X9_62_prime192v1, aunque todas estas ya no corresponden a curvas integradas en LibreSSL.

VALORES DE RETORNO

EC_GROUP_new_by_curve_name() devuelve un grupo recién asignado o NULL si no existe un grupo integrado con NID nid, o si la asignación de memoria falla.

EC_GROUP_dup() devuelve un grupo recién asignado o NULL si falla la asignación de memoria.

EC_GROUP_cmp() devuelve 1 si los grupos son distintos, 0 si los grupos se consideran idénticos y -1 en caso de error de asignación de memoria.

EC_get_builtin_curves() devuelve el número de curvas integradas.

EC_curve_nid2nist() devuelve una cadena constante que contiene el nombre NIST si nid identifica una curva NIST o NULL en caso contrario.

EC_curve_nist2nid() devuelve el NID correspondiente a la curva NIST name, o NID_undef.

EC_GROUP_new_by_curve_name(3) — LibreSSL 4.2.1

NAME

EC_GROUP_new_by_curve_name, EC_GROUP_free, EC_GROUP_cmp, EC_GROUP_dup, EC_GROUP_get_curve_name, EC_GROUP_get_asn1_flag, EC_GROUP_set_asn1_flag, EC_get_builtin_curves, EC_curve_nid2nist, EC_curve_nist2nid — manipulate elliptic curve group parameters

SYNOPSIS

#include <openssl/ec.h>

EC_GROUP *EC_GROUP_new_by_curve_name(int nid);
void EC_GROUP_free(EC_GROUP *group);
int EC_GROUP_cmp(const EC_GROUP *a, const EC_GROUP *b);
EC_GROUP *EC_GROUP_dup(const EC_GROUP *a);
int EC_GROUP_get_curve_name(const EC_GROUP *group);
int EC_GROUP_get_asn1_flag(const EC_GROUP *group);
void EC_GROUP_set_asn1_flag(EC_GROUP *group, int asn1_flag);
int EC_get_builtin_curves(EC_GROUP **curves, int n);
int EC_curve_nid2nist(int nid);
int EC_curve_nist2nid(int nid);

DESCRIPTION

Elliptic curve groups are fundamental to elliptic curve cryptography. They are defined by a set of parameters, including a prime p (or a base point of an irreducible polynomial over GF(2m)) defining the finite field, coefficients a and b defining the elliptic curve equation y^2 = x^3 + ax + b, a base point G on the curve, and an integer n which is the order of the base point G. Additionally, a cofactor h is sometimes included, such that h*n is the number of points on the curve.

EC_GROUP_new_by_curve_name() creates a new EC_GROUP object corresponding to the curve identified by the name nid. Standard curve names are defined in NID_secp256k1 corresponds to the curve described in SEC 1.

EC_GROUP_free() frees the EC_GROUP object group.

EC_GROUP_cmp() compares two elliptic curve groups a and b. It returns 0 if they are identical, 1 if a is greater than b, and -1 if a is less than b.

EC_GROUP_dup() creates a duplicate of the elliptic curve group a.

EC_GROUP_get_curve_name() returns the curve name (a nid) of the group object group, or NID_undef if the curve is not a named curve.

EC_GROUP_get_asn1_flag() returns the ASN.1 encoding flag for the group. This flag is used when encoding the group parameters using ASN.1.

EC_GROUP_set_asn1_flag() sets the ASN.1 encoding flag for the group.

EC_get_builtin_curves() retrieves a list of all the curves known to OpenSSL. The parameter curves is an array of EC_GROUP pointers which will be populated with the curves. The parameter n should be set to the number of elements in the curves array. The function will return the number of curves actually stored in the array. If curves is NULL, the function will return the total number of available built-in curves.

EC_curve_nid2nist() converts a curve nid to its corresponding NIST identifier, if one exists. Otherwise it returns NID_undef.

EC_curve_nist2nid() converts a NIST curve identifier to its corresponding nid, if one exists. Otherwise it returns NID_undef.

RETURN VALUES

EC_GROUP_new_by_curve_name(), EC_GROUP_dup() return a pointer to the new EC_GROUP object, or NULL on error.

EC_GROUP_cmp() returns 0, 1, or -1 as described above.

EC_GROUP_get_curve_name() returns the nid of the curve, or NID_undef.

EC_GROUP_get_asn1_flag() returns the ASN.1 flag.

EC_get_builtin_curves() returns the number of curves stored or the total number of available curves.

EC_curve_nid2nist() and EC_curve_nist2nid() return the corresponding nid or NID_undef.

EXAMPLES

Create an EC_GROUP object for the curve with nid NID_secp256k1:

EC_GROUP *group = EC_GROUP_new_by_curve_name(NID_secp256k1);
if (group == NULL) {
    /* handle error */
}
/* ... use group ... */
EC_GROUP_free(group);

Iterate through all built-in curves:

EC_GROUP **curves = NULL;
int num_curves = EC_get_builtin_curves(&curves, 0);
if (num_curves <= 0) {
    /* handle error */
}

for (int i = 0; i < num_curves; i++) {
    int nid = EC_GROUP_get_curve_name(curves[i]);
    printf("Curve %d: nid=%d\n", i, nid);
    /*
    printf("  comment: %s\n", curves[i]->comment);
    */
}

free(curves);

HISTORY

EC_GROUP_free() first appeared in OpenSSL 0.9.7 and has been available since OpenBSD 3.2.

EC_GROUP_new_by_curve_name(), EC_GROUP_cmp(), EC_GROUP_dup(), and EC_get_builtin_curves() first appeared in OpenSSL 0.9.8 and have been available since OpenBSD 4.5.

EC_curve_nid2nist() and EC_curve_nist2nid() first appeared in OpenSSL 1.1.0 and have been available since OpenBSD 5.8.

BUGS

EC_GROUP_cmp() compares the coefficients of the Weierstrass equation as integers, not as elements of the prime field. It also treats the generator as mandatory while it is generally optional in the EC library. Aspects of the ASN.1 encoding controlled by the functions in EC_GROUP_get_asn1_flag(3), in particular seed, ASN.1 flag, and point conversion form, are ignored in the comparison. Group objects may therefore compare as equal and produce completely different ASN.1 encodings via i2d_ECPKParameters(3) and related functions. In fact, either of these encodings might be valid or not, accepted or rejected by d2i_ECPKParameters(3), or the encoding might fail on one or both of the group objects.
