libressl-CRYPTO_memcmp(3)

Paquete: libressl

Licencias: ISC, custom:OpenSSL

CRYPTO_MEMCMP(3) Manual de Funciones de Biblioteca CRYPTO_MEMCMP(3)

NOMBRE

CRYPTO_memcmp — comparación de memoria en tiempo constante

SINOPSIS

biblioteca “libcrypto”
#include <openssl/crypto.h>

int
CRYPTO_memcmp(const void *a, const void *b, size_t len);

DESCRIPCIÓN

CRYPTO_memcmp() compara los len bytes apuntados por a y b para verificar su igualdad. Tarda un tiempo que depende de len, pero es independiente del contenido de las regiones de memoria apuntadas por a y b.

VALORES DE RETORNO

CRYPTO_memcmp() devuelve 0 si el contenido de las regiones de memoria es igual, o un valor distinto de cero en caso contrario.

HISTORIA

CRYPTO_memcmp() apareció por primera vez en OpenSSL 1.0.1d y ha estado disponible desde OpenBSD 5.6.

ERRORES

A diferencia de memcmp(3) y timingsafe_memcmp(3), esta función no puede usarse para ordenar las dos regiones de memoria. En la implementación actual, el valor de retorno es siempre mayor o igual a 0.
