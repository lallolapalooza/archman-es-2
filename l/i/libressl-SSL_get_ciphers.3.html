SSL_GET_CIPHERS(3) Manual de funciones de biblioteca SSL_GET_CIPHERS(3)

NOMBRE

SSL_get_ciphers, SSL_CTX_get_ciphers, SSL_get1_supported_ciphers, SSL_get_client_ciphers, SSL_get_cipher_list — obtener listas de SSL_CIPHERs disponibles

SINOPSIS

biblioteca “libssl” libcrypto
#include <openssl/ssl.h>

STACK_OF(SSL_CIPHER) *
SSL_get_ciphers(const SSL *ssl);

STACK_OF(SSL_CIPHER) *
SSL_CTX_get_ciphers(const SSL_CTX *ctx);

STACK_OF(SSL_CIPHER) *
SSL_get1_supported_ciphers(SSL *ssl);

STACK_OF(SSL_CIPHER) *
SSL_get_client_ciphers(const SSL *ssl);

const char *
SSL_get_cipher_list(const SSL *ssl, int priority);

DESCRIPCIÓN

SSL_get_ciphers() devuelve la pila de SSL_CIPHERs disponibles para ssl, ordenada por preferencia.

SSL_CTX_get_ciphers() devuelve la pila de SSL_CIPHERs disponibles para ctx.

SSL_get1_supported_ciphers() devuelve una pila de SSL_CIPHERs habilitados para ssl tal como se enviaría en un ClientHello, ordenada por preferencia. La lista depende de configuraciones como la lista de cifrados, las versiones de protocolo admitidas, el nivel de seguridad y los algoritmos de firma habilitados. La lista de cifrados que se enviaría en un ClientHello puede diferir de la lista de cifrados que serían aceptables al actuar como servidor. Por ejemplo, un servidor puede utilizar cifrados adicionales si hay una brecha en la lista de protocolos admitidos, y algunos cifrados pueden no ser utilizables por un servidor si no hay un certificado adecuado configurado.

SSL_get_client_ciphers() devuelve la pila de SSL_CIPHERs disponibles que coinciden con la lista recibida del cliente en ssl.

Los detalles de los cifrados obtenidos por SSL_get_ciphers(), SSL_CTX_get_ciphers(), SSL_get1_supported_ciphers(), y SSL_get_client_ciphers() se pueden obtener utilizando la familia de funciones SSL_CIPHER_get_name(3).

SSL_get_cipher_list() está obsoleto — usa SSL_get_ciphers() en su lugar — y está mal nombrado; no devuelve una lista sino el nombre de un elemento del valor de retorno de SSL_get_ciphers(), con el índice dado por el argumento priority. Pasar 0 selecciona el cifrado con la mayor prioridad. Para iterar sobre todos los cifrados disponibles en orden de prioridad decreciente, incrementa repetidamente el argumento en 1 hasta que se devuelva NULL.

VALORES DE RETORNO

SSL_get_ciphers() devuelve un puntero interno a una lista de cifrados o NULL si ssl es NULL o si no hay cifrados disponibles. El puntero devuelto puede volverse inválido no solo cuando ssl es destruido o cuando se llama a SSL_set_cipher_list(3) en él, sino también cuando el objeto SSL_CTX en uso por ssl en el momento de la llamada es liberado o cuando se llama a SSL_CTX_set_cipher_list(3) en ese objeto de contexto.

SSL_CTX_get_ciphers() devuelve un puntero interno a una lista de cifrados o NULL si ctx es NULL o si no hay cifrados disponibles. El puntero devuelto se vuelve inválido cuando ctx es destruido o cuando se llama a SSL_CTX_set_cipher_list(3) en él.

SSL_get1_supported_ciphers() devuelve una lista de cifrados recién asignada o NULL si ssl es NULL, si no hay cifrados disponibles, o si ocurre un error. Cuando el puntero devuelto ya no es necesario, el llamador es responsable de liberarlo usando sk_SSL_CIPHER_free().

SSL_get_client_ciphers() devuelve un puntero interno a una lista de cifrados o NULL si ssl es NULL, no tiene una sesión activa, o no está operando en modo servidor. El puntero devuelto se vuelve inválido cuando el objeto SSL_SESSION es destruido, incluso si el objeto ssl permanece válido. También puede volverse inválido en otras circunstancias, por ejemplo, al procesar un nuevo ClientHello.

SSL_get_cipher_list() devuelve un puntero interno a una cadena o NULL si ssl es NULL, si no hay cifrados disponibles, o si priority es mayor o igual que el número de cifrados disponibles.

VER TAMBIÉN

ssl(3), SSL_CIPHER_get_name(3), SSL_CTX_set_cipher_list(3)

HISTORIA

SSL_get_cipher_list() apareció por primera vez en SSLeay 0.5.2. SSL_get_ciphers() apareció por primera vez en SSLeay 0.8.0. Ambas funciones han estado disponibles desde OpenBSD 2.4.

SSL_CTX_get_ciphers() apareció por primera vez en OpenSSL 1.1.0 y ha estado disponible desde OpenBSD 6.3.

SSL_get1_supported_ciphers() y SSL_get_client_ciphers() aparecieron por primera vez en OpenSSL 1.1.0 y han estado disponibles desde OpenBSD 6.5.

NAME

SSL_get_ciphers, SSL_get_client_CA_list, SSL_get_shared_ciphers, SSL_set_cipher_list, SSL_set_client_CA_list

SYNOPSIS

#include <openssl/ssl.h>
const char * SSL_get_ciphers(SSL *ssl);
STACK_OF(X509_NAME) * SSL_get_client_CA_list(SSL *ssl);
const char * SSL_get_shared_ciphers(SSL *ssl);
int SSL_set_cipher_list(SSL *ssl, const char *priorities);
int SSL_set_client_CA_list(SSL *ssl, STACK_OF(X509_NAME) *list);

DESCRIPTION

SSL_get_ciphers() returns a string containing a colon-separated list of the ciphers that are available for the SSL/TLS connection ssl. This is the list that was negotiated or will be used for the connection. The string is owned by the SSL object and must not be freed.

SSL_get_client_CA_list() returns a stack of X509_NAME objects representing the CAs that the client is willing to trust. This is used during the TLS handshake when the server requests a client certificate.

SSL_get_shared_ciphers() returns a colon-separated list of the ciphers that are available for the SSL/TLS connection ssl and are supported by both the client and the server. This is the list that will be used for the connection. The string is owned by the SSL object and must not be freed.

SSL_set_cipher_list() sets the list of acceptable ciphers for the SSL/TLS connection ssl to priorities. The format of priorities is a colon-separated list of cipher names, possibly with modifiers. For example, "DEFAULT:!aNULL:!eNULL:!FIPS".

SSL_set_client_CA_list() sets the list of acceptable CAs for the SSL/TLS connection ssl to list. This is used during the TLS handshake when the server requests a client certificate. The list is copied, so the caller is still responsible for freeing the original list.

RETURN VALUES

SSL_get_ciphers() and SSL_get_shared_ciphers() return a pointer to a string, or NULL on error.

SSL_get_client_CA_list() returns a pointer to a STACK_OF(X509_NAME) or NULL on error.

SSL_set_cipher_list() and SSL_set_client_CA_list() return 1 on success, or 0 on error.

SEE ALSO

SSL_new(3), SSL_CTX_new(3), SSL_CTX_set_cipher_list(3)

HISTORY

The SSL_get_ciphers(), SSL_get_client_CA_list(), SSL_get_shared_ciphers(), SSL_set_cipher_list(), and SSL_set_client_CA_list() functions first appeared in OpenSSL 0.9.3.
