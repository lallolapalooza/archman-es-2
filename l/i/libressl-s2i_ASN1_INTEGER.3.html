NOMBRE

i2s_ASN1_ENUMERATED, i2s_ASN1_ENUMERATED_TABLE, i2s_ASN1_INTEGER, s2i_ASN1_INTEGER, i2s_ASN1_OCTET_STRING, s2i_ASN1_OCTET_STRING — Utilidades de conversión de tipos de datos ASN.1 para extensiones de certificado

SINOPSIS

biblioteca “libcrypto”
#include <openssl/asn1.h>
#include <openssl/x509v3.h>

char *
i2s_ASN1_ENUMERATED(X509V3_EXT_METHOD *method, const ASN1_ENUMERATED *a);

char *
i2s_ASN1_INTEGER(X509V3_EXT_METHOD *method, const ASN1_INTEGER *a);

ASN1_INTEGER *
s2i_ASN1_INTEGER(X509V3_EXT_METHOD *method, const char *value);

char *
i2s_ASN1_OCTET_STRING(X509V3_EXT_METHOD *method, const ASN1_OCTET_STRING *aos);

ASN1_OCTET_STRING *
s2i_ASN1_OCTET_STRING(X509V3_EXT_METHOD *method, X509V3_CTX *ctx, const char *value);

char *
i2s_ASN1_ENUMERATED_TABLE(X509V3_EXT_METHOD *method, const ASN1_ENUMERATED *a);

DESCRIPCIÓN

Estas funciones convierten objetos ASN1_ENUMERATED, ASN1_INTEGER y ASN1_OCTET_STRING de y hacia las representaciones en cadena. Se utilizan principalmente de forma interna para analizar archivos de configuración y mostrar extensiones de certificados X.509v3. Con la excepción de i2s_ASN1_ENUMERATED_TABLE(), estas funciones ignoran el argumento method. Cualquier objeto o cadena devuelto por estas funciones debe ser liberado por el llamador.

i2s_ASN1_ENUMERATED() e i2s_ASN1_INTEGER() primero convierten a en un objeto BIGNUM con ASN1_ENUMERATED_to_BN(3) o ASN1_INTEGER_to_BN(3) y luego derivan una representación en cadena usando BN_bn2dec(3) o BN_bn2hex(3). Se utiliza la representación decimal si el número tiene menos de 128 bits, de lo contrario, se utiliza la representación hexadecimal para evitar costos excesivos de conversión.

s2i_ASN1_INTEGER() convierte la representación en cadena decimal o hexadecimal terminada en NUL de un entero en value en un objeto ASN1_INTEGER. Un prefijo de signo ‘-’ indica un número negativo y los prefijos de base ‘0x’ y ‘0X’ indican representación hexadecimal, de lo contrario, se asume representación decimal. Después de omitir el signo y los prefijos de base, se realiza una conversión intermedia a un BIGNUM usando BN_dec2bn(3) o BN_hex2bn(3) y el ASN1_INTEGER se obtiene entonces con BN_to_ASN1_INTEGER(3).

i2s_ASN1_OCTET_STRING() convierte los octetos en aos en una cadena donde los octetos están separados por dos puntos y representados como pares de dígitos hexadecimales en mayúsculas.

s2i_ASN1_OCTET_STRING() convierte la cadena str terminada en NUL en un ASN1_OCTET_STRING. Los argumentos method y ctx se ignoran. Cada par de dígitos hexadecimales se convierte en un octeto. Los dos puntos se ignoran si están al principio, al final o si separan dos pares de dígitos.

i2s_ASN1_ENUMERATED_TABLE() busca el valor de a en el campo usr_data del method no NULL y devuelve una copia del nombre largo asociado. Si no se encuentra ninguna coincidencia, a se pasa a i2s_ASN1_ENUMERATED(). Los methods predeterminados correspondientes a los argumentos nid siguientes tienen cadenas configuradas en su campo usr_data:

NID_crl_reason códigos de razón, RFC 5280, 5.3.1
NID_key_usage uso de clave, RFC 5280, 4.2.1.3
NID_netscape_cert_type tipo de certificado Netscape (obsoleto)

VALORES DE RETORNO

i2s_ASN1_ENUMERATED(), i2s_ASN1_ENUMERATED_TABLE(), i2s_ASN1_INTEGER(), y i2s_ASN1_OCTET_STRING() devuelven una cadena terminada en NUL, o NULL en caso de fallo de asignación de memoria.

s2i_ASN1_INTEGER() devuelve un ASN1_INTEGER, o NULL en caso de error. Las condiciones de error son fallo de asignación de memoria o si value no es una codificación decimal o hexadecimal válida de un entero.

s2i_ASN1_OCTET_STRING() devuelve un ASN1_OCTET_STRING, o NULL en caso de error. Las condiciones de error son fallo de asignación de memoria o si value contiene un número impar de dígitos hexadecimales o cualquier cosa excepto dos puntos al principio, al final o entre pares de dígitos hexadecimales.

A veces se pueden obtener códigos de error llamando a ERR_get_error(3).

VER TAMBIÉN

NAME

libressl-s2i_ASN1_INTEGER - Abstract data types for ASN.1

SYNOPSIS

#include <openssl/asn1.h>

ASN1_INTEGER *ASN1_INTEGER_new(void);

void ASN1_INTEGER_free(ASN1_INTEGER *a);

ASN1_INTEGER *d2i_ASN1_INTEGER(ASN1_INTEGER **x, const unsigned char **pp, long length);

int i2d_ASN1_INTEGER(ASN1_INTEGER *a, unsigned char **pp);

ASN1_INTEGER *ASN1_INTEGER_dup(ASN1_INTEGER *a);

DESCRIPTION

The ASN.1 type INTEGER is a signed or unsigned integer. It is represented as a two's complement signed binary number. 

ASN1_INTEGER_new()
allocates and initializes a new ASN1_INTEGER structure. 

ASN1_INTEGER_free()
frees the structure `a` and any memory associated with it. 

d2i_ASN1_INTEGER()
decodes an ASN.1 DER encoded INTEGER from input data. `x` is the target ASN1_INTEGER pointer. If `x` is NULL, a new structure is allocated. If `*x` is not NULL, the existing structure is used. `pp` is a pointer to the input data. This pointer is updated to point to the data after the decoded INTEGER. `length` is the length of the input data. 

i2d_ASN1_INTEGER()
encodes the ASN1_INTEGER `a` into DER format. If `pp` is not NULL, the encoded data is written to the buffer pointed to by `*pp`. The pointer `*pp` is incremented to point after the encoded data. If `pp` is NULL, the required buffer size is returned. 

ASN1_INTEGER_dup()
creates a duplicate of the ASN1_INTEGER structure `a`.

RETURN VALUES

ASN1_INTEGER_new()
returns a pointer to the newly allocated ASN1_INTEGER structure, or NULL on error. 

ASN1_INTEGER_free()
does not return a value. 

d2i_ASN1_INTEGER()
returns a pointer to the decoded ASN1_INTEGER structure, or NULL on error. 

i2d_ASN1_INTEGER()
returns the length of the encoded data, or -1 on error. 

ASN1_INTEGER_dup()
returns a pointer to the duplicated ASN1_INTEGER structure, or NULL on error.
