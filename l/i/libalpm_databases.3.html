Descripción Detallada

Funciones para consultar y manipular la base de datos de libalpm.

Documentación de Typedef

typedef struct _alpm_db_t alpm_db_t

Una base de datos. Una base de datos es un contenedor que almacena metadatos sobre paquetes.

Una base de datos puede estar ubicada en el sistema de archivos local o en un servidor remoto.

Para usar una base de datos, primero debe ser registrada a través de alpm_register_syncdb. Si la base de datos ya está presente en dbpath entonces será utilizable. De lo contrario, la base de datos necesita ser descargada usando alpm_db_update. Incluso si la fuente de la base de datos es el sistema de archivos local.

Después de esto, la base de datos puede ser usada para consultar paquetes y grupos. Cualquier paquete o grupo de la base de datos continuará siendo propiedad de la base de datos y no necesita ser liberado por el usuario. Serán liberados cuando la base de datos sea desregistrada.

Las bases de datos se desregistran automáticamente cuando el alpm_handle_t es liberado.

Enumerador

ALPM_DB_USAGE_SYNC

ALPM_DB_USAGE_SEARCH
Habilita la búsqueda para esta base de datos.
ALPM_DB_USAGE_INSTALL
Habilita la instalación de paquetes desde esta base de datos.
ALPM_DB_USAGE_UPGRADE
Habilita las actualizaciones del sistema con esta base de datos.
ALPM_DB_USAGE_ALL
Habilita todos los niveles de uso.

int alpm_db_update (alpm_handle_t * handle, alpm_list_t * dbs, int force)

Update package databases. An update of the package databases in the list dbs will be attempted. Unless force is true, the update will only be performed if the remote databases were modified since the last update.

This operation requires a database lock, and will return an applicable error if the lock could not be obtained.

Example:

alpm_list_t *dbs = alpm_get_syncdbs(config->handle);
ret = alpm_db_update(config->handle, dbs, force);
if(ret < 0) {
    pm_printf(ALPM_LOG_ERROR, _("failed to synchronize all databases (%s)\n"),
        alpm_strerror(alpm_errno(config->handle)));
}

Note

After a successful update, the package cache will be invalidated

Parameters

handle the context handle
dbs list of package databases to update
force if true, then forces the update, otherwise update only in case the databases aren't up to date

Returns

0 on success, -1 on error (pm_errno is set accordingly), 1 if all databases are up to to date

Returns

alpm_register_syncdb

Register a sync database of packages. Databases can not be registered when there is an active transaction.

Parameters

handle the context handle
treename the name of the sync repository
level what level of signature checking to perform on the database; note that this must be a '.sig' file type verification

Returns

an alpm_db_t* on success (the value), NULL on error
