NOMBRE

SSL_CTX_get_ex_new_index, SSL_CTX_set_ex_data, SSL_CTX_get_ex_data — funciones de datos específicos de la aplicación interna

SINOPSIS

librería “libssl” libcrypto
#include <openssl/ssl.h>

int
SSL_CTX_get_ex_new_index(long argl, void *argp, CRYPTO_EX_new *new_func, CRYPTO_EX_dup *dup_func, CRYPTO_EX_free *free_func);

int
SSL_CTX_set_ex_data(SSL_CTX *ctx, int idx, void *arg);

void *
SSL_CTX_get_ex_data(const SSL_CTX *ctx, int idx);

typedef int new_func(void *parent, void *ptr, CRYPTO_EX_DATA *ad,
               int idx, long argl, void *argp);
typedef void free_func(void *parent, void *ptr, CRYPTO_EX_DATA *ad,
               int idx, long argl, void *argp);
typedef int dup_func(CRYPTO_EX_DATA *to, CRYPTO_EX_DATA *from, void *from_d,
               int idx, long argl, void *argp);

DESCRIPCIÓN

Varias estructuras de OpenSSL pueden tener datos específicos de la aplicación adjuntos. Estas funciones se utilizan internamente en OpenSSL para manipular los datos específicos de la aplicación adjuntos a una estructura específica.

SSL_CTX_get_ex_new_index() se utiliza para registrar un nuevo índice para datos específicos de la aplicación.

SSL_CTX_set_ex_data() se utiliza para almacenar datos de aplicación en arg para el índice idx en el objeto ctx.

SSL_CTX_get_ex_data() se utiliza para recuperar la información del índice idx del objeto ctx.

Una descripción detallada de la funcionalidad de *_get_ex_new_index() se puede encontrar en RSA_get_ex_new_index(3). La funcionalidad de *_get_ex_data() y *_set_ex_data() se describe en CRYPTO_set_ex_data(3).

VER TAMBIÉN

CRYPTO_set_ex_data(3), RSA_get_ex_new_index(3), ssl(3)

HISTORIA

SSL_CTX_get_ex_new_index(), SSL_CTX_set_ex_data(), y SSL_CTX_get_ex_data() aparecieron por primera vez en SSLeay 0.9.0 y han estado disponibles desde OpenBSD 2.4.
