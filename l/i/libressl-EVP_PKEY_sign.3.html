libressl-EVP_PKEY_sign(3)

Paquete: libressl

Licencias: ISC, custom:OpenSSL

EVP_PKEY_SIGN(3) Manual de funciones de biblioteca EVP_PKEY_SIGN(3)

NOMBRE

EVP_PKEY_sign_init, EVP_PKEY_sign — firmar usando un algoritmo de clave pública

SINOPSIS

biblioteca “libcrypto”
#include <openssl/evp.h>

int
EVP_PKEY_sign_init(EVP_PKEY_CTX *ctx);

int
EVP_PKEY_sign(EVP_PKEY_CTX *ctx, unsigned char *sig, size_t *siglen, const unsigned char *tbs, size_t tbslen);

DESCRIPCIÓN

La función EVP_PKEY_sign_init() inicializa un contexto de algoritmo de clave pública utilizando la clave ctx->pkey para una operación de firma.

La función EVP_PKEY_sign() realiza una operación de firma de clave pública utilizando ctx. Los datos a firmar se especifican utilizando los parámetros tbs y tbslen. Si sig es NULL, entonces el tamaño máximo del búfer de salida se escribe en el parámetro siglen. Si sig no es NULL, entonces antes de la llamada, el parámetro siglen debe contener la longitud del búfer sig. Si la llamada tiene éxito, la firma se escribe en sig y la cantidad de datos escritos en siglen.

EVP_PKEY_sign() no aplica hash a los datos a firmar y, por lo tanto, normalmente se utiliza para firmar resúmenes (digests). Para firmar mensajes arbitrarios, consulte las interfaces de firma EVP_DigestSignInit(3) y EVP_SignInit(3) en su lugar.

Después de la llamada a EVP_PKEY_sign_init(), se pueden realizar operaciones de control específicas del algoritmo para establecer los parámetros apropiados para la operación; consulte EVP_PKEY_CTX_ctrl(3).

La función EVP_PKEY_sign() puede llamarse más de una vez en el mismo contexto si se realizan varias operaciones utilizando los mismos parámetros.

VALORES DE RETORNO

EVP_PKEY_sign_init() y EVP_PKEY_sign() devuelven 1 en caso de éxito y 0 o un valor negativo en caso de fallo. En particular, un valor de retorno de -2 indica que la operación no es compatible con el algoritmo de clave pública.

EJEMPLOS

Firmar datos usando RSA con relleno PKCS#1 y resumen SHA-256:

#include <openssl/evp.h>
#include <openssl/rsa.h>

EVP_PKEY_CTX *ctx;
/* md es un resumen SHA-256 en este ejemplo. */
unsigned char *md, *sig;
size_t mdlen = 32, siglen;
EVP_PKEY *signing_key;

/*
 * NOTA: asume que signing_key y md están configurados antes del siguiente
 * paso. signing_key debe ser una clave privada RSA y md debe
 * apuntar al resumen SHA-256 a firmar.
 */
ctx = EVP_PKEY_CTX_new(signing_key, NULL /* sin motor */);
if (!ctx)
	/* Ocurrió un error */
if (EVP_PKEY_sign_init(ctx) <= 0)
	/* Error */
if (EVP_PKEY_CTX_set_rsa_padding(ctx, RSA_PKCS1_PADDING) <= 0)
	/* Error */
if (EVP_PKEY_CTX_set_signature_md(ctx, EVP_sha256()) <= 0)
	/* Error */

/* Determinar la longitud del búfer */
if (EVP_PKEY_sign(ctx, NULL, &siglen, md, mdlen) <= 0)
	/* Error */

sig = malloc(siglen);

if (!sig)
	/* Fallo de malloc */

if (EVP_PKEY_sign(ctx, sig, &siglen, md, mdlen) <= 0)
	/* Error */

/* La firma tiene siglen bytes escritos en el búfer sig */
