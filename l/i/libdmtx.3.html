LIBDMTX(3) Manual de Funciones de Biblioteca LIBDMTX(3)

NOMBRE

libdmtx - Biblioteca de codificación y decodificación de Data Matrix 0.7.5

SINOPSIS

#include <dmtx.h>

cc file.c -ldmtx

DESCRIPCIÓN

libdmtx es una biblioteca de software que permite a los programas leer y escribir códigos de barras Data Matrix de la variedad moderna ECC200. La biblioteca se ejecuta de forma nativa en varias plataformas y puede ser accesible desde múltiples lenguajes utilizando los wrappers de lenguaje de libdmtx. Las utilidades de línea de comandos dmtxread y dmtxwrite proporcionan una interfaz de línea de comandos para libdmtx y sirven como una buena referencia para los desarrolladores que escriben sus propios programas con libdmtx.

Los códigos de barras Data Matrix almacenan datos como un patrón de módulos ACTIVADOS y DESACTIVADOS (a menudo negro sobre blanco) en un patrón de cuadrícula que se asemeja a un tablero de ajedrez. Al igual que otras simbologías 2D, los códigos de barras Data Matrix tienen una gran capacidad de datos en comparación con sus primos 1D tradicionales y emplean sofisticadas técnicas de corrección de errores. Los códigos de barras Data Matrix pueden tener forma cuadrada o rectangular, y ofrecen varios esquemas de codificación para el almacenamiento optimizado de datos de texto y/o binarios. La simbología Data Matrix fue inventada y liberada al dominio público por RVSI Acuity CiMatrix.

CODIFICACIÓN - Generación de códigos de barras Data Matrix

Los programas C/C++ pueden generar un código de barras con solo unas pocas llamadas básicas a libdmtx:

1. Llamar a dmtxEncodeCreate()

Crea una nueva estructura DmtxEncode e inicializa el proceso de codificación. Esta función debe ser llamada antes de usar las otras funciones de codificación.

2. Llamar a dmtxEncodeSetProp() [opcional]

Permite controlar aspectos específicos del comportamiento de la codificación. Si esta función no se llama, libdmtx usará los valores predeterminados establecidos por dmtxEncodeCreate() anteriormente. La función complementaria, dmtxEncodeGetProp(), permite detectar la configuración actual.

3. Llamar a dmtxEncodeDataMatrix() o dmtxEncodeDataMosaic()

Llama a una de estas funciones para generar una imagen del tipo de código de barras deseado. Tu programa es responsable de enviar la salida resultante a su destino, ya sea mostrándola en una pantalla, escribiendo un archivo de imagen, copiándola a otro lugar, etc...

4. Llamar a dmtxEncodeDestroy()

Libera la memoria asignada durante el proceso de codificación.

DECODIFICACIÓN - Lectura de códigos de barras Data Matrix

La lectura de códigos de barras requiere más pasos que la generación de códigos de barras, principalmente porque libdmtx debe encontrar una región de código de barras antes de poder decodificar el mensaje. Sin embargo, este también es un proceso relativamente simple que utiliza 4 estructuras principales:

DmtxImage almacena las propiedades de la imagen y un puntero a los datos de píxeles mantenidos por el programa que llama.

DmtxDecode almacena valores para controlar el comportamiento de decodificación y el progreso del escaneo. Al escanear una nueva imagen, los programas que llaman siempre deben crear una nueva estructura DmtxDecode en lugar de reutilizar una antigua.

DmtxRegion define una región de 4 lados en coordenadas de píxeles. Las regiones pueden encontrarse en casi cualquier orientación, y sus esquinas no formarán necesariamente ángulos rectos. libdmtx utiliza esta estructura para almacenar la ubicación de códigos de barras potenciales, que luego se devuelven al programa que llama uno por uno.

DmtxMessage almacena el mensaje decodificado después de ser extraído de la región del código de barras. Una región decodificada exitosamente producirá exactamente un mensaje.

Utilice las siguientes funciones para encontrar y decodificar códigos de barras Data Matrix:

1. Llamar a dmtxImageCreate()

Crea e inicializa una nueva estructura DmtxImage utilizando los datos de píxeles proporcionados por la aplicación que llama. Los parámetros incluyen un puntero a la matriz de píxeles existente, el ancho, la altura de la imagen y el formato de empaquetado de píxeles.

2. Llamar a dmtxImageSetProp() [opcional]

Establece las propiedades de la imagen para controlar la lógica de mapeo de píxeles. Estas configuraciones permiten a libdmtx comprender muchos diseños nativos de imágenes en memoria, evitando así el trabajo adicional de transformar y copiar datos a un formato universal.

Una función dmtxDecodeGetProp() también está disponible para detectar las propiedades actuales de la imagen.

3. Llamar a dmtxDecodeCreate()

Crea e inicializa una nueva estructura DmtxDecode, que designa la imagen a escanear e inicializa el patrón de cuadrícula de escaneo. Esta función debe ser llamada antes que cualquier otra función de escaneo.

4. Llamar a dmtxDecodeSetProp() [opcional]

Establece propiedades internas para controlar el comportamiento de decodificación. Esta característica permite optimizar el rendimiento y la precisión para condiciones de imagen específicas.

Una función dmtxDecodeGetProp() también está disponible.

5. Llamar a dmtxRegionFindNext()

Busca en cada ubicación de píxel en un patrón de cuadrícula en busca de regiones de código de barras potenciales. Se devuelve una DmtxRegion cada vez que se encuentra una región de código de barras potencial, o si se ha escaneado la ubicación final del píxel. Las llamadas subsiguientes a esta función reanudarán la búsqueda donde la llamada anterior la dejó.

6. Llamar a dmtxDecodeMatrixRegion() o dmtxDecodeMosaicRegion()

Extrae datos brutos de la región del código de barras y decodifica el mensaje subyacente.

7. Llamar a dmtxMessageDestroy()

Libera la memoria mantenida por una estructura DmtxMessage. La función complementaria, dmtxMessageCreate(), es llamada automáticamente por dmtxDecodeMatrixRegion() y por lo tanto normalmente no es utilizada por el programa que llama.

8. Llamar a dmtxRegionDestroy()

Libera la memoria mantenida por una estructura DmtxRegion. La función complementaria, dmtxRegionCreate(), es llamada automáticamente por dmtxRegionFindNext() (en realidad dmtxRegionScanPixel()) y por lo tanto normalmente no es utilizada por el programa que llama.

9. Llamar a dmtxDecodeDestroy()

Libera la memoria mantenida por una estructura DmtxDecode. Esta es la función complementaria a dmtxDecodeCreate().

10. Llamar a dmtxImageDestroy()

Libera la memoria mantenida por una estructura DmtxImage, excluyendo la matriz de píxeles pasada a dmtxImageCreate(). El programa que llama es responsable de liberar la memoria de la matriz de píxeles, si es necesario.

EJEMPLO DE PROGRAMA

Este programa de ejemplo (disponible como simple_test.c en el paquete de origen) demuestra la funcionalidad de libdmtx en ambas direcciones: codificación y decodificación. Crea una imagen de código de barras Data Matrix en memoria, la lee y imprime el mensaje decodificado. El mensaje de salida final debe coincidir con la cadena de entrada original.


#include <stdlib.h>
#include <stdio.h>
#include <string.h>
#include <assert.h>
#include <dmtx.h>


int
main(int argc, char *argv[])
{
size_t width, height, bytesPerPixel;
unsigned char str[] = "30Q324343430794<OQQ";
unsigned char *pxl;
DmtxEncode *enc;
DmtxImage *img;
DmtxDecode *dec;
DmtxRegion *reg;
DmtxMessage *msg;


fprintf(stdout, "entrada: \"%s\"\n", str);


/* 1) CODIFICAR una nueva imagen de código de barras Data Matrix (solo en memoria) */


enc = dmtxEncodeCreate();
assert(enc != NULL);
dmtxEncodeDataMatrix(enc, strlen(str), str);


/* 2) COPIAR los nuevos datos de la imagen antes de liberar la memoria de codificación */


width = dmtxImageGetProp(enc->image, DmtxPropWidth);
height = dmtxImageGetProp(enc->image, DmtxPropHeight);
bytesPerPixel = dmtxImageGetProp(enc->image, DmtxPropBytesPerPixel);


pxl = (unsigned char *)malloc(width * height * bytesPerPixel);
assert(pxl != NULL);
memcpy(pxl, enc->image->pxl, width * height * bytesPerPixel);


dmtxEncodeDestroy(&enc);


/* 3) DECODIFICAR el código de barras Data Matrix desde la imagen copiada */


img = dmtxImageCreate(pxl, width, height, DmtxPack24bppRGB);
assert(img != NULL);


dec = dmtxDecodeCreate(img, 1);
assert(dec != NULL);


reg = dmtxRegionFindNext(dec, NULL);

EXAMPLE PROGRAM

A basic example of how to read a Data Matrix symbol from an image file, and print its contents to stdout.

#include <dmtx.h>

int
main (int argc, char *argv[])
{
    dmtxImage *img = NULL;
    dmtxDecode *dec = NULL;
    dmtxRegion *reg = NULL;
    dmtxMessage *msg = NULL;
    unsigned char *pxl;
    int width, height, bytesPerPixel, handle;

    /* initialize */
    dmtxInitialize();

    /* create a decoder */
    dec = dmtxDecodeCreate();

    /* load image */
    img = dmtxImageRead(argv[1], DmtxPackfile);

    /* create a region */
    reg = dmtxRegionCreate(img, DmtxRegionAuto);

    /* if a region was found */
    if(reg != NULL) {
        /* decode region */
        msg = dmtxDecodeMatrixRegion(dec, reg, DmtxUndefined);

        /* if a message was found */
        if(msg != NULL) {
            fputs("output: \"", stdout);
            fwrite(msg->output, sizeof(unsigned char), msg->outputIdx, stdout);
            fputs("\"\n", stdout);
            dmtxMessageDestroy(&msg);
        }
        dmtxRegionDestroy(&reg);
    }
    dmtxDecodeDestroy(&dec);
    dmtxImageDestroy(&img);
    free(pxl);

    exit(0);
}


dmtxDecodeDestroy(&dec);
dmtxImageDestroy(&img);
free(pxl);


exit(0);
}
