libssh2_channel_request_pty_ex(3)

Licencias: BSD

libssh2_channel_request_pty_ex(3) libssh2 libssh2_channel_request_pty_ex(3)

NOMBRE

libssh2_channel_request_pty_ex - descripción corta de la función

SINOPSIS

#include <libssh2.h>
int
libssh2_channel_request_pty_ex(LIBSSH2_CHANNEL *channel, const char *term,
                               unsigned int term_len,
                               const char *modes, unsigned int modes_len,
                               int width, int height,
                               int width_px, int height_px);
int
libssh2_channel_request_pty(LIBSSH2_CHANNEL *channel, const char *term);

DESCRIPCIÓN

channel - Instancia de canal previamente abierta como la retornada por libssh2_channel_open_ex(3)

term - Emulación de terminal (por ejemplo, vt102, ansi, etc...)

term_len - Longitud del parámetro term

modes - Valores modificadores del modo de terminal

modes_len - Longitud del parámetro modes.

width - Ancho del pty en caracteres

height - Alto del pty en caracteres

width_px - Ancho del pty en píxeles

height_px - Alto del pty en píxeles

Solicita un PTY en un canal establecido. Tenga en cuenta que esto no tiene sentido para todos los tipos de canales y puede ser ignorado por el servidor a pesar de retornar éxito.

VALOR DE RETORNO

Retorna 0 en caso de éxito o un número negativo en caso de fallo. Retorna LIBSSH2_ERROR_EAGAIN cuando de otro modo se bloquearía. Aunque LIBSSH2_ERROR_EAGAIN es un número negativo, no es realmente un fallo per se.

ERRORES

LIBSSH2_ERROR_ALLOC - Una llamada interna de asignación de memoria falló.

LIBSSH2_ERROR_SOCKET_SEND - No se pudieron enviar datos en el socket.

LIBSSH2_ERROR_CHANNEL_REQUEST_DENIED -
