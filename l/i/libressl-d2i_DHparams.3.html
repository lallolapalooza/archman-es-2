libressl-d2i_DHparams(3)

Paquete: libressl

Licencias: ISC, custom:OpenSSL

D2I_DHPARAMS(3) Manual de funciones de biblioteca D2I_DHPARAMS(3)

NOMBRE

d2i_DHparams, i2d_DHparams — funciones de parámetros DH de PKCS#3

SINOPSIS

biblioteca “libcrypto”
#include <openssl/dh.h>

DH *
d2i_DHparams(DH **a, unsigned char **pp, long length);

int
i2d_DHparams(DH *a, unsigned char **pp);

DESCRIPCIÓN

Estas funciones decodifican y codifican parámetros DH de PKCS#3 utilizando la estructura DHparameter descrita en PKCS#3. Por lo demás, se comportan de forma similar a d2i_X509(3) y i2d_X509(3).

VALORES DEVUELTOS

d2i_DHparams() devuelve un objeto DH o NULL si ocurre un error.

i2d_DHparams() devuelve el número de bytes codificados con éxito o un valor <= 0 si ocurre un error.

VER TAMBIÉN

d2i_X509(3), DH_new(3)

HISTORIAL

d2i_DHparams() y i2d_DHparams() aparecieron por primera vez en SSLeay 0.5.1 y han estado disponibles desde OpenBSD 2.4.
