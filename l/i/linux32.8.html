SETARCH(8) Administración del sistema SETARCH(8)

NOMBRE

setarch - cambia la arquitectura informada en el nuevo entorno del programa y/o establece indicadores de personalidad

SINOPSIS

setarch [arch] [opciones] [programa [argumento...]]

setarch --list|-h|-V

arch [opciones] [programa [argumento...]]

DESCRIPCIÓN

setarch modifica los dominios de ejecución y los indicadores de personalidad del proceso.

Los dominios de ejecución actualmente solo afectan la salida de uname -m. Por ejemplo, en un sistema AMD64, ejecutar setarch i386 programa hará que programa vea i686 en lugar de x86_64 como tipo de máquina. También se puede usar para establecer varias opciones de personalidad. El programa predeterminado es /bin/sh.

Desde la versión 2.33, el argumento de línea de comandos arch es opcional y setarch se puede usar para cambiar los indicadores de personalidad (ADDR_LIMIT_*, SHORT_INODE, etc.) sin modificar el dominio de ejecución.

OPCIONES

--list

Enumera las arquitecturas que setarch conoce. Si setarch puede establecer cada una de estas arquitecturas depende del kernel en ejecución.

--show[=personalidad]

Muestra la personalidad y los indicadores actualmente activos. Si se proporciona el argumento personalidad, se muestra en lugar del actual. personalidad es un número hexadecimal con valores descritos en sys/personality.h.

--uname-2.6

Hace que el programa vea un número de versión del kernel que comience con 2.6. Activa UNAME26.

-v, --verbose

Sea detallado.

-3, --3gb

Especifica que el programa debe usar un máximo de 3 GB de espacio de direcciones. Compatible con x86. Activa ADDR_LIMIT_3GB.

--4gb

Esta opción no tiene efecto. Se conserva solo para compatibilidad con versiones anteriores y puede eliminarse en futuras versiones.

-B, --32bit

Limita el espacio de direcciones a 32 bits para emular hardware. Compatible con ARM y Alpha. Activa ADDR_LIMIT_32BIT.

-F, --fdpic-funcptrs

Trata los punteros de función en el espacio de usuario a los manejadores de señales como punteros a descriptores de direcciones. Esta opción no tiene efecto en arquitecturas que no admiten binarios ELF FDPIC. En el kernel v4.14, la compatibilidad se limita a las arquitecturas de CPU ARM, Blackfin, Fujitsu FR-V y SuperH.

-I, --short-inode

Indicador obsoleto de emulación de errores. Activa SHORT_INODE.

-L, --addr-compat-layout

Proporciona un diseño de espacio de direcciones virtual heredado. Úselo cuando el binario programa no tenga el encabezado ELF PT_GNU_STACK. Activa ADDR_COMPAT_LAYOUT.

-R, --addr-no-randomize

Deshabilita la aleatorización del espacio de direcciones virtual. Activa ADDR_NO_RANDOMIZE.

-S, --whole-seconds

Indicador obsoleto de emulación de errores. Activa WHOLE_SECONDS.

-T, --sticky-timeouts

Hace que las llamadas al sistema select(2), pselect(2) y ppoll(2) conserven el valor del tiempo de espera en lugar de modificarlo para reflejar la cantidad de tiempo no dormido cuando es interrumpido por un manejador de señales. Úselo cuando programa dependa de este comportamiento. Para más detalles, consulte la descripción del tiempo de espera en la página del manual de select(2). Activa STICKY_TIMEOUTS.

-X, --read-implies-exec

Si se establece esto, entonces mmap(2) PROT_READ también agregará el bit PROT_EXEC, como se espera en binarios x86 heredados. Tenga en cuenta que el cargador ELF establecerá automáticamente este bit cuando encuentre un binario heredado. Activa READ_IMPLIES_EXEC.

-Z, --mmap-page-zero

Emulación de errores SVr4 que establecerá la página cero de mmap(2) como de solo lectura. Úselo cuando programa dependa de este comportamiento y el código fuente no esté disponible para ser corregido. Activa MMAP_PAGE_ZERO.

-h, --help

Muestra el texto de ayuda y sale.

-V, --version

Muestra la versión y sale.

EJEMPLO

setarch --addr-no-randomize mi_programa_prueba
setarch ppc32 rpmbuild --target=ppc --rebuild foo.src.rpm
setarch ppc32 -v -vL3 rpmbuild --target=ppc --rebuild bar.src.rpm
setarch ppc32 --32bit rpmbuild --target=ppc --rebuild foo.src.rpm
