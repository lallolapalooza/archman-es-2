EVP(3) Manual de funciones de la biblioteca EVP(3)

NOMBRE

evp — funciones criptográficas de alto nivel

SINOPSIS

biblioteca “libcrypto”
#include <openssl/evp.h>

DESCRIPCIÓN

La biblioteca EVP proporciona una interfaz de alto nivel a funciones criptográficas. La abreviatura “EVP” pretende significar “EnVeloPe” en el sentido de “biblioteca envoltorio”. No está relacionada con el significado técnico del término “envoltorio” en contextos como CMS_encrypt(3), EVP_SealInit(3), PKCS7_encrypt(3), o SMIME_write_PKCS7(3).

EVP_SealInit(3) y EVP_OpenInit(3) proporcionan cifrado y descifrado de clave pública para implementar "envoltorios" digitales.

Las funciones EVP_DigestSignInit(3) y EVP_DigestVerifyInit(3) implementan firmas digitales y códigos de autenticación de mensajes (MACs). Consulte también las funciones más antiguas EVP_SignInit(3) y EVP_VerifyInit(3).

El cifrado simétrico está disponible con las funciones EVP_EncryptInit(3). Las funciones EVP_DigestInit(3) proporcionan resúmenes de mensajes.

El cifrado autenticado con datos adicionales (AEAD) está disponible con las funciones EVP_AEAD_CTX_init(3).

Las funciones EVP_PKEY_*() proporcionan una interfaz de alto nivel a algoritmos asimétricos. Para crear un nuevo EVP_PKEY, consulte EVP_PKEY_new(3). Los EVP_PKEY se pueden asociar con una clave privada de un algoritmo particular utilizando las funciones descritas en la página EVP_PKEY_set1_RSA(3), o se pueden generar nuevas claves usando EVP_PKEY_keygen(3). Los EVP_PKEY se pueden comparar usando EVP_PKEY_cmp(3) o imprimir usando EVP_PKEY_print_private(3).

Las funciones EVP_PKEY_*() admiten la gama completa de operaciones de algoritmos asimétricos:

  • Para el acuerdo de claves, consulte EVP_PKEY_derive(3).
  • Para firmar y verificar, consulte EVP_PKEY_sign(3), EVP_PKEY_verify(3), y EVP_PKEY_verify_recover(3). Sin embargo, tenga en cuenta que estas funciones no realizan un resumen de los datos a firmar. Por lo tanto, normalmente usaría las funciones EVP_DigestSignInit(3) para este propósito.
  • Para cifrar y descifrar, consulte EVP_PKEY_encrypt(3) y EVP_PKEY_decrypt(3), respectivamente. Sin embargo, tenga en cuenta que estas funciones solo realizan cifrado y descifrado. Dado que el cifrado de clave pública es una operación costosa, normalmente envolvería un mensaje cifrado en un envoltorio digital utilizando las funciones EVP_SealInit(3) y EVP_OpenInit(3).

La función EVP_BytesToKey(3) proporciona un soporte limitado para el cifrado basado en contraseñas. La selección cuidadosa de los parámetros proporcionará una implementación compatible con PKCS#5 PBKDF1. Sin embargo, las nuevas aplicaciones normalmente no deberían usar esto (prefiriendo, por ejemplo, PBKDF2 de PCKS#5).

La familia de funciones EVP_EncodeInit(3) proporciona codificación y decodificación base64.

libressl-evp(3) — Arch Linux

NAME

libressl-evp — Evp algorithms

SYNOPSIS

#include <openssl/evp.h>

DESCRIPTION

The EVP interface is a high-level interface to the various cryptographic algorithms supported by OpenSSL.

The primary goal is to provide a uniform interface to different implementations of the same algorithm. For example, an RSA public key operation can be performed using different implementations of RSA, such as those provided by hardware accelerators, without changing the application code.

The EVP interface uses "abstract" types to represent algorithms, operations, and parameters. For example, the abstract type EVP_CIPHER represents a symmetric cipher algorithm, while EVP_Digest represents a message digest algorithm.

The interface is based on the concept of "engines," which are pluggable modules that can provide implementations of cryptographic algorithms. This allows applications to use hardware-accelerated cryptographic operations without being tied to a specific hardware vendor.

Key functions in the EVP interface include:

  • EVP_CipherInit_ex(), EVP_CipherUpdate(), EVP_CipherFinal_ex(): For symmetric encryption and decryption.
  • EVP_DigestInit_ex(), EVP_DigestUpdate(), EVP_DigestFinal_ex(): For message digests.
  • EVP_SignInit_ex(), EVP_SignUpdate(), EVP_SignFinal(): For digital signatures.
  • EVP_VerifyInit_ex(), EVP_VerifyUpdate(), EVP_VerifyFinal(): For signature verification.
  • EVP_PKEY_new(), EVP_PKEY_assign(), EVP_PKEY_get_id(), EVP_PKEY_encrypt(), EVP_PKEY_decrypt(): For public key operations.

The EVP interface is a powerful and flexible way to access cryptographic functionality. It is the recommended interface for most applications that need to perform cryptographic operations.
