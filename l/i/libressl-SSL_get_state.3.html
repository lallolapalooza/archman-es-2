SSL_GET_STATE(3) Manual de Funciones de Biblioteca SSL_GET_STATE(3)

NOMBRE

SSL_get_state, SSL_state, SSL_in_accept_init, SSL_in_before, SSL_in_connect_init, SSL_in_init, SSL_is_init_finished — inspeccionar el estado de la máquina de estados SSL

SINOPSIS

biblioteca “libssl” libcrypto
#include <openssl/ssl.h>

int
SSL_get_state(const SSL *ssl);

int
SSL_state(const SSL *ssl);

int
SSL_in_accept_init(const SSL *ssl);

int
SSL_in_before(const SSL *ssl);

int
SSL_in_connect_init(const SSL *ssl);

int
SSL_in_init(const SSL *ssl);

int
SSL_is_init_finished(const SSL *ssl);

DESCRIPCIÓN

SSL_get_state() devuelve una representación codificada del estado actual de la máquina de estados SSL. SSL_state() es un alias obsoleto para SSL_get_state().

Los siguientes bits pueden estar establecidos:

SSL_ST_ACCEPT
Este bit es establecido por SSL_accept(3) y por SSL_set_accept_state(3). Indica que ssl está configurado para modo servidor y ningún cliente inició aún la negociación TLS. La función SSL_in_accept_init() devuelve un valor distinto de cero si este bit está establecido o 0 en caso contrario.
SSL_ST_BEFORE
Este bit es establecido por las funciones SSL_accept(3), SSL_connect(3), SSL_set_accept_state(3), y SSL_set_connect_state(3). Indica que la negociación TLS no se ha iniciado todavía. La función SSL_in_before() devuelve un valor distinto de cero si este bit está establecido o 0 en caso contrario.
SSL_ST_CONNECT
Este bit es establecido por SSL_connect(3) y por SSL_set_connect_state(3). Indica que ssl está configurado para modo cliente y ninguna negociación TLS se ha iniciado todavía. La función SSL_in_connect_init() devuelve un valor distinto de cero si este bit está establecido o 0 en caso contrario.

Las siguientes máscaras pueden ser utilizadas:

SSL_ST_INIT
Establecido si SSL_ST_ACCEPT o SSL_ST_CONNECT están establecidos. La función SSL_in_init() devuelve un valor distinto de cero si uno de estos está establecido o 0 en caso contrario.
SSL_ST_MASK
Esta máscara incluye todos los bits excepto SSL_ST_ACCEPT, SSL_ST_BEFORE, y SSL_ST_CONNECT.
SSL_ST_OK
El estado se establece en este valor cuando se establece una conexión. La función SSL_is_init_finished() devuelve un valor distinto de cero si el estado es igual a esta constante, o 0 en caso contrario.
SSL_ST_RENEGOTIATE
El programa está a punto de renegociar, por ejemplo al entrar en SSL_read(3) o SSL_write(3) justo después de que SSL_renegotiate(3) fuera llamado.

El significado de otros bits depende del protocolo. Las aplicaciones normalmente no necesitan inspeccionar ninguno de estos otros bits.

Todas estas funciones pueden ser implementadas como macros.

VER TAMBIÉN

ssl(3), SSL_renegotiate(3), SSL_set_connect_state(3)

HISTORIA

SSL_is_init_finished() apareció por primera vez en SSLeay 0.4.5b. SSL_state() apareció por primera vez en SSLeay 0.5.2. SSL_in_accept_init(), SSL_in_connect_init(), y SSL_in_init() aparecieron por primera vez en SSLeay 0.6.0. SSL_in_before() apareció por primera vez en SSLeay 0.8.0. SSL_get_state() apareció por primera vez en SSLeay 0.9.0. Todas estas funciones han estado disponibles desde OpenBSD 2.4.
