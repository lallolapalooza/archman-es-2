EVP_PKEY_CTX_GET_OPERATION(3) Manual de funciones de biblioteca EVP_PKEY_CTX_GET_OPERATION(3)

NOMBRE

EVP_PKEY_CTX_get_operation, EVP_PKEY_CTX_get0_pkey — inspeccionar objetos EVP_PKEY_CTX

SINOPSIS

biblioteca “libcrypto”;
#include <openssl/evp.h>

int
EVP_PKEY_CTX_get_operation(EVP_PKEY_CTX *ctx);

EVP_PKEY *
EVP_PKEY_CTX_get0_pkey(EVP_PKEY_CTX *ctx);

DESCRIPCIÓN

EVP_PKEY_CTX_get_operation() averigua qué función de inicialización se ha llamado en ctx, si alguna:

valor de retorno inicializado con ej. para
EVP_PKEY_OP_DECRYPT EVP_PKEY_decrypt_init(3) RSA, SM2
EVP_PKEY_OP_DERIVE EVP_PKEY_derive_init(3) HKDF
EVP_PKEY_OP_ENCRYPT EVP_PKEY_encrypt_init(3) RSA, SM2
EVP_PKEY_OP_KEYGEN EVP_PKEY_keygen_init(3) casi todos
EVP_PKEY_OP_PARAMGEN EVP_PKEY_paramgen_init(3) DH, DSA, EC
EVP_PKEY_OP_SIGN EVP_PKEY_sign_init(3) DSA,EC,RSA,SM2
EVP_PKEY_OP_SIGN EVP_DigestSignInit(3) ED25519
EVP_PKEY_OP_SIGNCTX EVP_DigestSignInit(3) CMAC, HMAC
EVP_PKEY_OP_UNDEFINED no inicializado NINGUNO
EVP_PKEY_OP_VERIFY EVP_PKEY_verify_init(3) DSA,EC,RSA,SM2
EVP_PKEY_OP_VERIFY EVP_DigestVerifyInit(3) ED25519
EVP_PKEY_OP_VERIFYCTX EVP_DigestVerifyInit(3) ninguno incorporado
EVP_PKEY_OP_VERIFYRECOVER EVP_PKEY_verify_recover_init(3) RSA

La columna más a la derecha de la tabla anterior muestra ejemplos de algoritmos para los que pueden ocurrir los valores de retorno. Por ejemplo, si EVP_PKEY_base_id(3) devuelve EVP_PKEY_HKDF, entonces llamar a EVP_PKEY_CTX_get_operation() en un EVP_PKEY_CTX que usa esa clave puede devolver EVP_PKEY_OP_DERIVE.

Si el valor de retorno es EVP_PKEY_OP_SIGNCTX o EVP_PKEY_OP_VERIFYCTX, el ctx soporta EVP_DigestSignUpdate(3) o EVP_DigestVerifyUpdate(3), respectivamente. Si el valor de retorno es EVP_PKEY_OP_SIGN o EVP_PKEY_OP_VERIFY, no lo hace, y solo se soporta firma o verificación de un solo disparo.

El valor de retorno EVP_PKEY_OP_UNDEFINED puede ocurrir, por ejemplo, si el ctx fue devuelto recientemente de EVP_PKEY_CTX_new(3) o EVP_PKEY_CTX_new_id(3) y aún no se ha inicializado.

Las siguientes máscaras se definen como el OR lógico de dos o más de los bits EVP_PKEY_OP_* anteriores:

EVP_PKEY_OP_TYPE_CRYPT
DECRYPT | ENCRYPT
EVP_PKEY_OP_TYPE_GEN
KEYGEN | PARAMGEN
EVP_PKEY_OP_TYPE_NOGEN
CRYPT | DERIVE | SIG
EVP_PKEY_OP_TYPE_SIG
SIGN | SIGNCTX | VERIFY | VERIFYCTX | VERIFYRECOVER

VALORES DE RETORNO

EVP_PKEY_CTX_get_operation() devuelve una de las constantes EVP_PKEY_OP_* de un solo bit o EVP_PKEY_OP_UNDEFINED si ctx no está inicializado.

EVP_PKEY_CTX_get0_pkey() devuelve un puntero interno al objeto EVP_PKEY utilizado por ctx, sin incrementar su contador de referencias.

VER TAMBIÉN

evp(3), EVP_PKEY_base_id(3), EVP_PKEY_CTX_ctrl(3), EVP_PKEY_CTX_new(3), EVP_PKEY_new(3)

HISTORIA

NAME

EVP_PKEY_CTX_get_operation - get the operation associated with a key generation context

SYNOPSIS

```c void EVP_PKEY_CTX_get_operation(EVP_PKEY_CTX *ctx, int *operation); ```

DESCRIPTION

The EVP_PKEY_CTX_get_operation() function retrieves the operation associated with the key generation context ctx. The operation is stored in the integer pointed to by operation.

The possible values for operation are:

  • EVP_PKEY_OP_KEYGEN: Key generation
  • EVP_PKEY_OP_SIGN: Signing
  • EVP_PKEY_OP_VERIFY: Verification
  • EVP_PKEY_OP_WRAP: Key wrapping
  • EVP_PKEY_OP_UNWRAP: Key unwrapping

RETURN VALUES

This function does not return a value.

SEE ALSO

EVP_PKEY_CTX_new(3), EVP_PKEY_CTX_ctrl(3), EVP_PKEY_keygen_init(3)

HISTORY

This function was added in OpenSSL 1.0.0.
