BN_SET_BIT(3) Manual de funciones de biblioteca BN_SET_BIT(3)

NOMBRE

BN_set_bit, BN_clear_bit, BN_is_bit_set, BN_mask_bits, BN_lshift, BN_lshift1, BN_rshift, BN_rshift1 — operaciones de bits en BIGNUMs

SINOPSIS

biblioteca “libcrypto”
#include <openssl/bn.h>

int
BN_set_bit(BIGNUM *a, int n);

int
BN_clear_bit(BIGNUM *a, int n);

int
BN_is_bit_set(const BIGNUM *a, int n);

int
BN_mask_bits(BIGNUM *a, int n);

int
BN_lshift(BIGNUM *r, const BIGNUM *a, int n);

int
BN_lshift1(BIGNUM *r, const BIGNUM *a);

int
BN_rshift(BIGNUM *r, const BIGNUM *a, int n);

int
BN_rshift1(BIGNUM *r, const BIGNUM *a);

DESCRIPCIÓN

BN_set_bit() establece el bit n en a a 1 (a|=(1<<n)). El número se expande si es necesario.

BN_clear_bit() establece el bit n en a a 0 (a&=~(1<<n)). Ocurre un error si a tiene menos de n bits.

BN_is_bit_set() comprueba si el bit n en a está establecido.

BN_mask_bits() trunca a a un número de n bits (a&=~((~0)>>n)). Ocurre un error si a ya tiene menos de n bits.

BN_lshift() desplaza a a la izquierda en n bits y coloca el resultado en r (r=a*2^n). Tenga en cuenta que n debe ser no negativo. BN_lshift1() desplaza a a la izquierda en uno y coloca el resultado en r (r=2*a).

BN_rshift() desplaza a a la derecha en n bits y coloca el resultado en r (r=a/2^n). Tenga en cuenta que n debe ser no negativo. BN_rshift1() desplaza a a la derecha en uno y coloca el resultado en r (r=a/2).

Para las funciones de desplazamiento, r y a pueden ser la misma variable.

VALORES DE RETORNO

BN_is_bit_set() devuelve 1 si el bit está establecido, 0 en caso contrario.

Todas las demás funciones devuelven 1 en caso de éxito, 0 en caso de error. Los códigos de error se pueden obtener mediante ERR_get_error(3).

VER TAMBIÉN

BN_add(3), BN_new(3), BN_num_bytes(3), BN_set_negative(3), BN_zero(3)

HISTORIA
