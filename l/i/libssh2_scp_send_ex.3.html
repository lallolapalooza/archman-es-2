libssh2_scp_send_ex(3)

Paquete: libssh2

Licencias: BSD

libssh2_scp_send_ex(3) libssh2 libssh2_scp_send_ex(3)

NOMBRE

libssh2_scp_send_ex - Enviar un archivo vía SCP

SINOPSIS

#include <libssh2.h>
LIBSSH2_CHANNEL *
libssh2_scp_send_ex(LIBSSH2_SESSION *session, const char *path, int mode,
                    size_t size, long mtime, long atime);

DESCRIPCIÓN

Esta función se consideró obsoleta desde libssh2 1.2.6. Véase libssh2_scp_send64(3).

session - Instancia de sesión devuelta por libssh2_session_init_ex(3)

path - Ruta completa y nombre de archivo a transferir. Este es el nombre del archivo remoto.

mode - Modo de acceso al archivo con el que se creará el archivo

size - Tamaño del archivo que se está transmitiendo (debe conocerse de antemano con precisión)

mtime - mtime a asignar al archivo que se está creando

atime - atime a asignar al archivo que se está creando (Establezca este y mtime a cero para indicar al host remoto que use la hora actual).

Envía un archivo al host remoto vía SCP.

VALOR DE RETORNO

Puntero a una instancia LIBSSH2_CHANNEL recién asignada, o NULL en caso de error.

ERRORES

LIBSSH2_ERROR_ALLOC - Falló una llamada interna de asignación de memoria.

LIBSSH2_ERROR_SOCKET_SEND - No se pueden enviar datos en el socket.

LIBSSH2_ERROR_SCP_PROTOCOL -

LIBSSH2_ERROR_EAGAIN - Marcado para E/S no bloqueante pero la llamada bloquearía.

DISPONIBILIDAD

Esta función fue marcada como obsoleta en libssh2 1.2.6 ya que
se introdujo libssh2_scp_send64(3) para reemplazar esta función.
