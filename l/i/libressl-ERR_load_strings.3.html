libressl-ERR_load_strings(3)

Paquete: libressl

Licencias: ISC, custom:OpenSSL

ERR_LOAD_STRINGS(3) Manual de funciones de la biblioteca ERR_LOAD_STRINGS(3)

NOMBRE

ERR_load_strings, ERR_PACK, ERR_get_next_error_library — carga cadenas de error arbitrarias de OpenSSL

SINOPSIS

biblioteca “libcrypto”
#include <openssl/err.h>

void
ERR_load_strings(int lib, ERR_STRING_DATA str[]);

unsigned long
ERR_PACK(int lib, int func, int reason);

int
ERR_get_next_error_library(void);

DESCRIPCIÓN

ERR_load_strings() registra cadenas de error para el número de biblioteca lib.

str es un array de datos de cadena de error:

typedef struct ERR_string_data_st {
        unsigned long error;
        char *string;
} ERR_STRING_DATA;

El código de error se genera a partir del número de biblioteca y un código de función y razón:

error = ERR_PACK(lib, func, reason)

ERR_PACK() es una macro.

La última entrada en el array es {0, NULL}.

ERR_get_next_error_library() puede usarse para asignar números de biblioteca a bibliotecas de usuario en tiempo de ejecución.

VALORES DE RETORNO

ERR_PACK() devuelve el código de error. ERR_get_next_error_library() devuelve un nuevo número de biblioteca.

VER TAMBIÉN

ERR(3)

HISTORIA

ERR_load_strings() y ERR_PACK() aparecieron por primera vez en SSLeay 0.4.4. ERR_get_next_error_library() apareció por primera vez en SSLeay 0.9.0. Estas funciones han estado disponibles desde OpenBSD 2.4.
