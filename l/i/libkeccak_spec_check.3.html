libkeccak_spec_check(3)

Paquete: libkeccak

Licencias: custom:ISC

LIBKECCAK_SPEC_CHECK(3) Manual de funciones de la biblioteca LIBKECCAK_SPEC_CHECK(3)

NOMBRE

libkeccak_spec_check - Valida los parámetros de hash

SINOPSIS

#include <libkeccak.h>
int libkeccak_spec_check(const struct libkeccak_spec *spec);

Enlazar con -lkeccak.

DESCRIPCIÓN

La función libkeccak_spec_check() valida los parámetros de *spec, para que se puedan detectar configuraciones inutilizables. Se recomienda llamar a esta función después de llamar a libkeccak_spec_sha3(3), libkeccak_spec_cshake(3), libkeccak_spec_rawshake(3), libkeccak_spec_shake(3), o, especialmente, después de establecer los parámetros manualmente para el hashing Keccak.

struct libkeccak_spec {
	long int bitrate;  /* tasa de bits (en bits) */
	long int capacity; /* capacidad (en bits) */
	long int output;   /* tamaño de salida (en bits) */
};

VALORES DE RETORNO

La función libkeccak_spec_check() devuelve 0 si la configuración es utilizable. De lo contrario, devolverá una de las siguientes constantes.

LIBKECCAK_SPEC_ERROR_BITRATE_NONPOSITIVE
La tasa de bits especificada no era positiva.
LIBKECCAK_SPEC_ERROR_BITRATE_MOD_8
La tasa de bits especificada no era equivalente a 0 módulo 8, es decir, no estaba en bytes completos.
LIBKECCAK_SPEC_ERROR_CAPACITY_NONPOSITIVE
La capacidad especificada no era positiva.
LIBKECCAK_SPEC_ERROR_CAPACITY_MOD_8
La capacidad especificada no era equivalente a 0 módulo 8, es decir, no estaba en bytes completos.
LIBKECCAK_SPEC_ERROR_OUTPUT_NONPOSITIVE
El tamaño de salida especificado no era positivo.
LIBKECCAK_SPEC_ERROR_STATE_TOO_LARGE
El tamaño del estado, es decir, la suma de la tasa de bits y la capacidad, excedió el límite soportado (actualmente 1600 bits).
LIBKECCAK_SPEC_ERROR_STATE_MOD_25
El tamaño del estado, es decir, la suma de la tasa de bits y la capacidad, en bits, no era equivalente a 0 módulo 25. Lo que significa que el tamaño del estado no puede cubrir todos los carriles de manera equivalente.
LIBKECCAK_SPEC_ERROR_WORD_NON_2_POTENT
El tamaño de la palabra, es decir, el tamaño del estado dividido por 25, no es una potencia de 2.
LIBKECCAK_SPEC_ERROR_WORD_MOD_8
El tamaño de la palabra, es decir, el tamaño del estado dividido por 25, no es equivalente a 0 módulo 8, es decir, no está en bytes completos.

Tenga en cuenta que puede haber más de un error. Solo se devuelve el primero detectado.

ERRORES

La función libkeccak_spec_check() no puede fallar.

VER TAMBIÉN
