FBB::LinearMap(3bobcat) Contenedor de mapeo basado en búsqueda lineal FBB::LinearMap(3bobcat)

NOMBRE

FBB::LinearMap - Un contenedor de mapeo que utiliza búsqueda lineal

SINOPSIS

#include <bobcat/linearmap>

DESCRIPCIÓN

La clase plantilla LinearMap implementa un contenedor de mapeo utilizando un algoritmo de búsqueda lineal. Un contenedor de mapeo que utiliza búsqueda lineal es menos complejo que tanto std::map ordenado como std::unordered_map no ordenado. Para un número relativamente pequeño de elementos, el algoritmo de búsqueda lineal también es más rápido que los algoritmos de búsqueda basados en búsqueda binaria o hashing.

LinearMap implementa todos los miembros que también se encuentran en std::map estándar, excepto los miembros key_comp y value_comp. Estos dos últimos miembros no están disponibles ya que ordenar las claves no es un problema con el método de búsqueda lineal no ordenada que utiliza LinearMap.

ESPACIO DE NOMBRES

FBB
Todos los constructores, miembros, operadores y manipuladores mencionados en esta página del manual están definidos en el espacio de nombres FBB.

HEREDA (PRIVADAMENTE) DE

std::vector<Key, Value>

TIPOS DE PLANTILLA

La definición completa del tipo de plantilla de LinearMap es:

    template < typename Key, typename Value >

El tipo Key debe ofrecer bool operator==. Además, los tipos Key y Value deben admitir constructores predeterminados y de copia, y operadores de asignación (de copia) sobrecargados.

ESPECIFICACIONES DE USO

o
using value_type = std::pair<Key, Value>;
o
iterator - un iterador hacia los elementos de un objeto LinearMap;
o
const_iterator - un const_iterator hacia los elementos de un objeto LinearMap;
o
reverse_iterator - un reverse_iterator hacia los elementos de un objeto LinearMap;
o
const_reverse_iterator - un const_reverse_iterator hacia los elementos de un objeto LinearMap.

CONSTRUCTORES

o
LinearMap(Iterator begin, Iterator end):
El constructor se inicializa utilizando el rango de iteradores [begin, end), donde Iterator es cualquier tipo de iterador que apunte a objetos value_type. Si se utilizan claves idénticas K, solo se inserta la primera ocurrencia del objeto value_type que utiliza la clave K.
o
LinearMap(std:initializer_list<value_type> initial):
El constructor se inicializa con los valores almacenados en la lista de inicialización std::initializer_list de objetos value_type. Si se utilizan claves idénticas K, solo se inserta la primera ocurrencia del objeto value_type que utiliza la clave K.

Se encuentran disponibles constructores predeterminados, de copia y de movimiento (así como operadores de asignación de copia y de movimiento).

OPERADORES SOBRECARGADOS

o
Value &operator[](Key const &key):
Se devuelve una referencia al Value asociado con key. Si key no estaba disponible antes de la llamada al operador de índice, se inserta un objeto value_map(key, Value()).

FUNCIONES MIEMBRO

Tenga en cuenta que los miembros de std::vector no están automáticamente disponibles, ya que LinearMap hereda privadamente de std::vector.

LinearMap ofrece las siguientes funciones miembro:
o
Value &at(int idx):
devuelve una referencia al Value de LinearMap que está asociado con key. Si la key no está almacenada en LinearMap, se lanza una excepción std::out_of_range.
o
iterator begin():
devuelve un iterador que apunta al primer elemento de LinearMap.
o
size_t capacity():
devuelve el número de elementos que pueden almacenarse en LinearMap antes de que su capacidad se amplíe.
o
const_iterator cbegin() const:
devuelve un const_iterator que apunta al primer elemento de LinearMap.
o
const_iterator cend() const:
devuelve un const_iterator que apunta más allá del último elemento de LinearMap.
o
void clear():
elimina todos los elementos de LinearMap.
o
size_t count(key):
devuelve 1 si la clave proporcionada está disponible en LinearMap, de lo contrario devuelve 0.
o
const_reverse_iterator crbegin() const:
devuelve un const_reverse_iterator que apunta al último elemento de un objeto LinearMap.
o
const_reverse_iterator crend() const:
devuelve un const_reverse_iterator que apunta antes del primer elemento de un objeto LinearMap.
o
std::pair<iterator, bool> emplace(Args &&...args):
se construye un objeto value_type a partir de los argumentos de emplace. Se devuelve un std::pair que contiene un iterador que apunta al objeto que utiliza esa clave. Si LinearMap ya contiene un objeto con el valor Key proporcionado, el valor booleano del std::pair devuelto es false. Si no se encontró la key proporcionada, el objeto recién construido se inserta en LinearMap y el valor booleano del std::pair devuelto es true.
o
bool empty():
devuelve true si LinearMap no contiene elementos.
o
iterator end():
devuelve un iterador que apunta más allá del último elemento de LinearMap.
o
std::pair<iterator, iterator> equal_range(key):
devuelve un par de iteradores, que son respectivamente los valores de retorno de las funciones miembro lower_bound y upper_bound.
o
bool erase(Key const &key):
elimina el elemento que tiene la key dada de LinearMap. Se devuelve true si el valor fue eliminado, false si LinearMap no contenía un elemento que utilizara la key dada.
o
void erase(iterator pos):
elimina el elemento en la posición del iterador pos.
o
void erase(iterator begin, iterator end):
elimina todos los elementos indicados por el rango de iteradores [first, beyond).
o
iterator find(Key const &key):
devuelve un iterador al elemento que tiene la clave dada. Si el elemento no está disponible, se devuelve end.

MIEMBROS DE LA CLASE

o
const_iterator find(Key const &key) const:
devuelve un const_iterator al elemento que tiene la clave dada. Si el elemento no está disponible, se devuelve end.
o
allocator_type get_allocator() const:
devuelve una copia del objeto asignador utilizado por el objeto LinearMap.
o
std::pair<iterator, bool> insert(value_type const &keyValue):
intenta insertar un nuevo objeto value_type en el LinearMap, devolviendo un std::pair<iterator, bool>. Si el campo ti(bool) devuelto es true, keyValue se insertó en el LinearMap. El valor false indica que la clave especificada ya estaba disponible y keyvalue no se insertó en el LinearMap. En ambos casos, el campo iterator apunta al elemento de datos que tiene la key especificada.
o
iterator insert(iterator pos, value_type const &keyValue):
intenta insertar keyValue en el LinearMap. Pos se ignora y se devuelve un iterador al elemento que tiene el valor de clave de keyValue. Si la clave especificada ya estaba presente, keyValue no se inserta en el LinearMap.
o
void insert(Iterator begin, Iterator end):
intenta insertar los elementos value_type a los que apuntan los objetos del rango de iteradores [begin, end) en el LinearMap. Iterator es cualquier tipo de iterador que apunta a objetos value_type. Los elementos value_type ya existentes con claves iguales a las claves de los elementos a los que apunta el rango de iteradores no se reemplazan.
o
iterator lower_bound(Key const &key):
devuelve un iterador que apunta al elemento keyvalue que tiene la key especificada. Si no existe tal elemento, se devuelve end.
o
const_iterator lower_bound(Key const &key) const:
devuelve un const_iterator que apunta al elemento keyvalue que tiene la key especificada. Si no existe tal elemento, se devuelve end.
o
size_t max_size() const:
devuelve el número máximo de elementos que puede contener este objeto LinearMap.
o
reverse_iterator rbegin():
devuelve un reverse_iterator que apunta al último elemento del objeto LinearMap.
o
const_reverse_iterator rbegin() const:
devuelve un const_reverse_iterator que apunta al último elemento del objeto LinearMap.
o
reverse_iterator rend():
devuelve un reverse_iterator que apunta antes del primer elemento del objeto LinearMap.
o
const_reverse_iterator rbegin() const:
devuelve un const_reverse_iterator que apunta antes del primer elemento del objeto LinearMap.
o
size_t size() const:
devuelve el número de elementos en el LinearMap.
o
void swap(LinearMap &other):
intercambia dos LinearMaps utilizando tipos Key y Value idénticos.
o
iterator upper_bound(Key const &key):
devuelve un iterador que apunta al elemento keyvalue que tiene la key especificada. Si no existe tal elemento, se devuelve end.
o
const_iterator upper_bound(Key const &key) const:
devuelve un const_iterator que apunta al elemento keyvalue que tiene la key especificada. Si no existe tal elemento, se devuelve end.

EJEMPLO

#include <iostream>
#include <string>
#include <iostream>
#include <bobcat/linearmap>
using namespace std;
using namespace FBB;
int main()
{
    typedef LinearMap<string, string> LM;
    // constructores:
    LM lm;
    LM lm2 =
    {
        {"one", "value 1"},
        {"two", "value 2"}
    };
    LM lm3(lm2);
    LM lm4(lm3.begin(), lm3.end());
    // asignación:
    lm = lm2;
    // algunos miembros:
    lm["key"] = "value";
    cout << lm["key"] << ’\n’;
    cout << lm.find("key")->second << ’\n’;
    for (auto value: lm)
        cout << "For loop: " << value.first << ", " <<
                                                value.second << ’\n’;
    cerr << "# veces que se almacena ’key’: " << lm.count("key") << "\n"
            "# veces que se almacena ’value: " << lm.count("value") << ’\n’;
    lm4 = lm2;
    cout << "Tamaño de lm4 después de la asignación: " << lm4.size() << ’\n’;
    lm4.clear();
    cout << "Tamaño de lm4 después de clear: " << lm4.size() << ’\n’;
};
