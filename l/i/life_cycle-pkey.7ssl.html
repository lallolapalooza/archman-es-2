NOMBRE

life_cycle-pkey - El ciclo de vida del algoritmo PKEY

DESCRIPCIÓN

Todas las claves públicas (PKEYs) pasan por una serie de etapas en su ciclo de vida:

inicio
Este estado representa la PKEY antes de haber sido asignada. Es el estado inicial para cualquier transición del ciclo de vida.
asignada
Este estado representa la PKEY después de haber sido asignada.
desencapsular
Este estado representa la PKEY cuando está lista para realizar una operación de desencapsulación de clave privada.
descifrar
Este estado representa la PKEY cuando está lista para descifrar algún texto cifrado.
derivar
Este estado representa la PKEY cuando está lista para derivar un secreto compartido.
firma de resumen
Este estado representa la PKEY cuando está lista para realizar una operación de firma de clave privada.
encapsular
Este estado representa la PKEY cuando está lista para realizar una operación de encapsulación de clave pública.
cifrar
Este estado representa la PKEY cuando está lista para cifrar algún texto plano.
generación de clave
Este estado representa la PKEY cuando está lista para generar una nueva clave pública/privada.
generación de parámetros
Este estado representa la PKEY cuando está lista para generar parámetros de clave.
verificar
Este estado representa la PKEY cuando está lista para verificar una firma de clave pública.
verify recover
Este estado representa la PKEY cuando está lista para recuperar datos de firma de clave pública.
liberada
Se accede a este estado cuando la PKEY es liberada. Es el estado terminal para todas las transiciones del ciclo de vida.

NAME

life_cycle-pkey - PKEY provider life cycle

DESCRIPTION

The OpenSSL PKEY provider has a life cycle. The life cycle is intended to implement the transitions described in the specification. The specification is available as part of the OpenSSL source distribution.

The PKEY provider supports the following operations:

  • key generation
  • encapsulate
  • decapsulate
  • derive
  • sign
  • recover
  • parameter generation
  • encrypt
  • decrypt

The following figure illustrates the state transitions.

EVP_PKEY_CTX_free
derive encapsulate decapsulate parameter key
sign recover generation generation
EVP_PKEY_CTX_free freed freed freed freed freed freed freed freed freed freed freed freed

NOTES

At some point the EVP layer will begin enforcing the transitions described herein.

HISTORY

The provider PKEY interface was introduced in OpenSSL 3.0.
