Paquete: libressl

Licencias: ISC, custom:OpenSSL

BN_RAND(3) Manual de funciones de biblioteca BN_RAND(3)

NOMBRE

BN_rand, BN_rand_range, BN_pseudo_rand, BN_pseudo_rand_range — generar número pseudoaleatorio

SINOPSIS

biblioteca “libcrypto”
#include <openssl/bn.h>

int
BN_rand(BIGNUM *rnd, int bits, int top, int bottom);

int
BN_rand_range(BIGNUM *rnd, const BIGNUM *range);

DESCRIPCIÓN

BN_rand() genera un número pseudoaleatorio criptográficamente fuerte de bits de longitud y lo almacena en rnd. Si top es BN_RAND_TOP_ANY, el bit más significativo del número aleatorio puede ser cero. Si top es BN_RAND_TOP_ONE, el bit más significativo se establece en 1, y si top es BN_RAND_TOP_TWO, los dos bits más significativos del número se establecerán en 1, de modo que el producto de dos números aleatorios de este tipo siempre tendrá una longitud de 2*bits. Si bottom es BN_RAND_BOTTOM_ODD, el número será impar; si es BN_RAND_BOTTOM_ANY, puede ser par o impar. El valor de bits debe ser cero o mayor. Si bits es +1, entonces top no puede ser BN_RAND_TOP_TWO.

BN_rand_range() genera un número pseudoaleatorio criptográficamente fuerte rnd en el rango 0 <= rnd < range.

BN_pseudo_rand() es un alias obsoleto para BN_rand(), y BN_pseudo_rand_range() para BN_rand_range().

VALORES DE RETORNO

Las funciones devuelven 1 en caso de éxito, 0 en caso de error. Los códigos de error se pueden obtener mediante ERR_get_error(3).

VER TAMBIÉN

BN_new(3)

HISTORIA

BN_rand() apareció por primera vez en SSLeay 0.5.1 y ha estado disponible desde OpenBSD 2.4.

El caso top == -1 y la función BN_rand_range() aparecieron por primera vez en OpenSSL 0.9.6a y han estado disponibles desde OpenBSD 3.0.
