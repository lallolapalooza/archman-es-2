Paquete: libressl

Licencias: ISC, custom:OpenSSL

RSA_SECURITY_BITS(3) Manual de funciones de biblioteca RSA_SECURITY_BITS(3)

NOMBRE

RSA_security_bits, DSA_security_bits, DH_security_bits, BN_security_bits — obtener la fuerza de seguridad

SINOPSIS

biblioteca “libcrypto”
#include <openssl/rsa.h>

int
RSA_security_bits(const RSA *rsa);

#include <openssl/dsa.h>

int
DSA_security_bits(const DSA *dsa);

#include <openssl/dh.h>

int
DH_security_bits(const DH *dh);

#include <openssl/bn.h>

int
BN_security_bits(int pubbits, int privbits);

DESCRIPCIÓN

Estas funciones devuelven la fuerza de seguridad de ciertos tipos específicos de claves criptográficas, medida en bits. Es aproximadamente el logaritmo binario del número de operaciones que un atacante tiene que realizar para romper la clave.

RSA_security_bits() utiliza solo el número de bits significativos en el módulo público de rsa devuelto por RSA_bits(3). Devuelve

256 para 15360 o más bits significativos
192 7680
128 3072
112 2048
80 1024

o 0 en caso contrario.

DSA_security_bits() utiliza el número de bits significativos en el parámetro de dominio público p contenido en el objeto dsa, que es igual al tamaño de la clave pública, de la misma manera que RSA_security_bits(). Además, se inspecciona el parámetro de dominio público q contenido en el objeto dsa, que es igual al tamaño de la clave privada. El valor devuelto es la fuerza de seguridad según la tabla anterior o la mitad del tamaño de la clave privada, lo que sea menor. Si el valor devuelto fuera menor que 80, se devuelve 0 en su lugar.

DH_security_bits() utiliza el número de bits significativos en el secreto compartido contenido en el objeto dh devuelto por DH_bits(3) de la misma manera que RSA_security_bits(). Si dh contiene el parámetro de dominio q, su número de bits significativos se utiliza de la misma manera que para DSA_security_bits() para limitar el valor devuelto. De lo contrario, si dh contiene la longitud del exponente secreto en bits, se utiliza ese número. Si no se dispone de ninguno, solo se utiliza la tabla anterior sin calcular un mínimo.

BN_security_bits() es una función combinada. Si se pasa -1 para el argumento privbits, se comporta como RSA_security_bits(). De lo contrario, se comporta como DSA_security_bits().

VALORES DE RETORNO

Todas estas funciones devuelven números en el rango de 0 a 256 inclusive.

DSA_security_bits() falla y devuelve -1 a menos que ambos parámetros de dominio p y q estén presentes.

VER TAMBIÉN

BN_num_bits(3), DH_bits(3), DH_get0_pqg(3), DSA_get0_pqg(3), RSA_bits(3), SSL_CTX_set_security_level(3)

Elaine Barker, Recommendation for Key Management, U.S. National Institute of Standards and Technology, NIST Special Publication 800-57 Part 1 Revision 5, https://doi.org/10.6028/NIST.SP.800-57pt1r5, Gaithersburg, MD, Mayo 2020.
