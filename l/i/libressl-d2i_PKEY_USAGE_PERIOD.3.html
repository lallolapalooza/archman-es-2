libressl-d2i_PKEY_USAGE_PERIOD(3)

Paquete: libressl

Licencias: ISC, custom:OpenSSL

D2I_PKEY_USAGE_PERIOD(3) Manual de funciones de biblioteca D2I_PKEY_USAGE_PERIOD(3)

NOMBRE

d2i_PKEY_USAGE_PERIOD, i2d_PKEY_USAGE_PERIOD — decodifica y codifica extensiones de período de uso de clave X.509

SINOPSIS

biblioteca “libcrypto”
#include <openssl/x509v3.h>

PKEY_USAGE_PERIOD *
d2i_PKEY_USAGE_PERIOD(PKEY_USAGE_PERIOD **val_out, const unsigned char **der_in, long length);

int
i2d_PKEY_USAGE_PERIOD(PKEY_USAGE_PERIOD *val_in, unsigned char **der_out);

DESCRIPCIÓN

d2i_PKEY_USAGE_PERIOD() y i2d_PKEY_USAGE_PERIOD() decodifican y codifican una estructura ASN.1 PrivateKeyUsagePeriod definida en la RFC 3280 sección 4.2.1.4. Para obtener detalles sobre la semántica, ejemplos, advertencias y errores, consulte ASN1_item_d2i(3).

VALORES DE RETORNO

d2i_PKEY_USAGE_PERIOD() devuelve un objeto PKEY_USAGE_PERIOD o NULL si ocurre un error.

i2d_PKEY_USAGE_PERIOD() devuelve el número de bytes codificados correctamente o un valor negativo si ocurre un error.

VER TAMBIÉN

ASN1_item_d2i(3), PKEY_USAGE_PERIOD_new(3), X509_EXTENSION_new(3)

ESTÁNDARES

RFC 3280: Perfil de certificado y lista de revocación de certificados (CRL) de la infraestructura de clave pública X.509 de Internet, sección 4.2.1.4: Período de uso de clave privada

La RFC 3280 fue obsoleta por la RFC 5280; consulte PKEY_USAGE_PERIOD_new(3) para obtener detalles.

HISTORIA

d2i_PKEY_USAGE_PERIOD() y i2d_PKEY_USAGE_PERIOD() aparecieron por primera vez en OpenSSL 0.9.2b y han estado disponibles desde OpenBSD 2.6.
