SSL_CIPHER_GET_NAME(3) Manual de funciones de biblioteca SSL_CIPHER_GET_NAME(3)

NOMBRE

SSL_CIPHER_get_name, SSL_CIPHER_get_bits, SSL_CIPHER_get_version, SSL_CIPHER_get_cipher_nid, SSL_CIPHER_get_digest_nid, SSL_CIPHER_get_handshake_digest, SSL_CIPHER_get_kx_nid, SSL_CIPHER_get_auth_nid, SSL_CIPHER_is_aead, SSL_CIPHER_find, SSL_CIPHER_get_id, SSL_CIPHER_description — obtener propiedades de SSL_CIPHER

DESCRIPCIÓN

SSL_CIPHER_get_name() devuelve un puntero al nombre de cipher.

SSL_CIPHER_get_bits() devuelve el número de bits secretos utilizados para cipher. Si alg_bits no es NULL, el número de bits procesados por el algoritmo elegido se almacena en él.

SSL_CIPHER_get_version() devuelve una cadena que indica la versión del protocolo SSL/TLS que definió por primera vez el cifrado. Actualmente es "TLSv1/SSLv3". En algunos casos, podría devolver "TLSv1.2", pero la función no lo hace; use SSL_CIPHER_description() en su lugar.

SSL_CIPHER_get_cipher_nid() devuelve el NID del cifrado correspondiente a cipher. Si no hay cifrado (por ejemplo, para suites de cifrado sin cifrado), se devuelve NID_undef.

SSL_CIPHER_get_digest_nid() devuelve el NID del resumen correspondiente a la MAC utilizada por cipher durante el cifrado/descifrado de registros. Si no hay resumen (por ejemplo, para suites de cifrado AEAD), se devuelve NID_undef.

SSL_CIPHER_get_handshake_digest() devuelve el objeto EVP_MD que representa el resumen utilizado durante un handshake TLS con el cifrado c, que puede ser diferente al resumen utilizado en el código de autenticación de mensajes para registros cifrados.

SSL_CIPHER_get_kx_nid() devuelve el NID de intercambio de claves correspondiente al método utilizado por cipher. Si no hay intercambio de claves, se devuelve NID_undef. Ejemplos de posibles valores de retorno incluyen NID_kx_rsa, NID_kx_dhe, y NID_kx_ecdhe.

SSL_CIPHER_get_auth_nid() devuelve el NID de autenticación correspondiente al método utilizado por cipher. Si no hay autenticación, se devuelve NID_undef. Ejemplos de posibles valores de retorno incluyen NID_auth_rsa y NID_auth_ecdsa.

SSL_CIPHER_is_aead() devuelve 1 si cipher es AEAD (por ejemplo, GCM o ChaCha20/Poly1305), o 0 si no lo es.

SSL_CIPHER_find() devuelve un puntero a una estructura SSL_CIPHER que tiene el ID del cifrado especificado en ptr. El parámetro ptr es una matriz de longitud dos que almacena el ID del cifrado TLS de dos bytes (según lo asignado por IANA) en orden de bytes de red. SSL_CIPHER_find devuelve NULL si ocurre un error o no se encuentra el cifrado indicado.

SSL_CIPHER_get_id() devuelve el ID del cipher dado, que no debe ser NULL. El ID aquí es un concepto específico de OpenSSL, que almacena un prefijo de 0x0300 en los dos bytes superiores y el ID de la suite de cifrado especificado por IANA en los dos bytes inferiores. Por ejemplo, TLS_RSA_WITH_NULL_MD5 tiene el ID de IANA "0x00, 0x01", por lo que SSL_CIPHER_get_id() devuelve 0x03000001.

SSL_CIPHER_description() copia una descripción textual de cipher en el búfer buf, que debe tener al menos size bytes de longitud. El argumento cipher no debe ser un puntero NULL. Si buf es NULL, se asigna un búfer usando asprintf(3); ese búfer debe liberarse usando la función free(3). Si len es demasiado pequeño para contener la descripción, se devuelve un puntero a la cadena estática "Buffer too small". Si la asignación de memoria falla, lo que puede ocurrir incluso si se proporciona un buf de tamaño suficiente, se devuelve un puntero a la cadena estática "OPENSSL_malloc Error" y el contenido de buf permanece sin cambios.

La cadena devuelta por SSL_CIPHER_description() consiste en varios campos separados por espacios en blanco:

⟨nombre del cifrado⟩
Representación textual del nombre del cifrado.
⟨versión del protocolo⟩

SSL=⟨protocol⟩
Versión del protocolo: SSLv3, TLSv1.2, o TLSv1.3. Las cifras TLSv1.0 están marcadas con SSLv3. TLSv1.1 no añadió nuevas cifras.
Kx=⟨intercambio de claves⟩
Método de intercambio de claves: DH, ECDH, GOST, RSA, o TLSv1.3.
Au=⟨autenticación⟩
Método de autenticación: ECDSA, GOST01, RSA, TLSv1.3, o None. None es la representación de cifrados anónimos.
Enc=⟨método de cifrado simétrico⟩
Método de cifrado con número de bits secretos: 3DES(168), RC4(128), AES(128), AES(256), AESGCM(128), AESGCM(256), Camellia(128), Camellia(256), ChaCha20-Poly1305, GOST-28178-89-CNT, o None.
Mac=⟨código de autenticación de mensajes⟩
Resumen del mensaje: MD5, SHA1, SHA256, SHA384, AEAD, GOST94, GOST89IMIT, o STREEBOG256.

VALORES DE RETORNO

SSL_CIPHER_get_name() devuelve un puntero interno a una cadena terminada en NUL. SSL_CIPHER_get_version() devuelve un puntero a una cadena terminada en NUL estática. Si cipher es un puntero NULL, ambas funciones devuelven un puntero a la cadena estática ""(NONE)"".

SSL_CIPHER_get_bits() devuelve un entero positivo que representa el número de bits secretos o 0 si cipher es un puntero NULL.

SSL_CIPHER_get_cipher_nid(), SSL_CIPHER_get_digest_nid(), SSL_CIPHER_get_kx_nid(), y SSL_CIPHER_get_auth_nid() devuelven una constante NID o NID_undef si ocurrió un error. SSL_CIPHER_get_handshake_digest() devuelve un objeto EVP_MD válido o NULL si ocurrió un error.

SSL_CIPHER_is_aead() devuelve 1 si el cipher es AEAD o 0 en caso contrario.

SSL_CIPHER_find() devuelve un puntero a una estructura SSL_CIPHER válida o NULL si ocurrió un error.

SSL_CIPHER_get_id() devuelve un entero sin signo de 32 bits.

SSL_CIPHER_description() devuelve buf o una cadena recién asignada en caso de éxito o un puntero a una cadena estática en caso de error.

EJEMPLOS

Un ejemplo de la salida de SSL_CIPHER_description():

ECDHE-RSA-AES256-GCM-SHA256 TLSv1.2 Kx=ECDH Au=RSA Enc=AESGCM(256) Mac=AEAD

Se puede obtener una lista completa invocando el siguiente comando:

$ openssl ciphers -v ALL:COMPLEMENTOFALL

HISTORIA

SSL_CIPHER_description() apareció por primera vez en SSLeay 0.8.0. SSL_CIPHER_get_name(), SSL_CIPHER_get_bits(), y SSL_CIPHER_get_version() aparecieron por primera vez en SSLeay 0.8.1. Estas funciones han estado disponibles desde OpenBSD 2.4.

SSL_CIPHER_get_id() apareció por primera vez en OpenSSL 1.0.1 y ha estado disponible desde OpenBSD 5.3.

SSL_CIPHER_get_cipher_nid(), SSL_CIPHER_get_digest_nid(), SSL_CIPHER_get_kx_nid(), SSL_CIPHER_get_auth_nid(), y SSL_CIPHER_is_aead() aparecieron por primera vez en OpenSSL 1.1.0 y han estado disponibles desde OpenBSD 6.3. SSL_CIPHER_find() apareció por primera vez en OpenSSL 1.1.0 y ha estado disponible desde OpenBSD 7.0. SSL_CIPHER_get_handshake_digest() apareció por primera vez en OpenSSL 1.1.1 y ha estado disponible desde OpenBSD 7.6.

ERRORES

Si SSL_CIPHER_description() no puede manejar una cifra integrada, la descripción correspondiente de la propiedad de la cifra es "unknown". Este caso no debería ocurrir.
