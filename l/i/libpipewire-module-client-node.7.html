NOMBRE

libpipewire-module-client-node - Nodo Cliente

DESCRIPCIÓN

Permite a los clientes exportar nodos de procesamiento al demonio de PipeWire.

Este módulo crea 2 tipos de exportación, uno para la interfaz PW_TYPE_INTERFACE_Node y otro para la interfaz SPA_TYPE_INTERFACE_Node.

Con pw_core_export(), los objetos de estos tipos se pueden exportar al servidor PipeWire. Todas las acciones realizadas en el nodo localmente serán visibles para los clientes conectados y la programación del Nodo se realizará.

Los objetos de la interfaz PW_TYPE_INTERFACE_Node se pueden crear con pw_context_create_node(), por ejemplo. Necesitarías crear y agregar manualmente un objeto de la interfaz SPA_TYPE_INTERFACE_Node. Exportar una SPA_TYPE_INTERFACE_Node directamente primero la envolverá en una interfaz PW_TYPE_INTERFACE_Node.

Normalmente, este módulo no se usa directamente sino a través de las APIs Stream y Filter, que proporcionan API para implementar la interfaz SPA_TYPE_INTERFACE_Node.

En algunos casos, es posible usar esta fábrica directamente (la implementación JACK de PipeWire hace esto). Con pw_core_create_object() en la fábrica client-node se obtendrá un proxy PW_TYPE_INTERFACE_ClientNode que se puede usar para controlar el Node Impl creado en el lado del servidor.

Esquemáticamente, el Node Impl del lado del cliente se envuelve en el proxy ClientNode y se desempaqueta por el recurso del lado del servidor para que todas las acciones en el nodo del lado del cliente se reflejen en el nodo del lado del servidor y las acciones del lado del servidor se reflejen en el cliente.

  proxy del lado del cliente                  recurso del lado del servidor
.------------------------------.            .----------------------------------.
| PW_TYPE_INTERFACE_ClientNode |            |  PW_TYPE_INTERFACE_Node          |
|.----------------------------.|  IPC       |.--------------------------------.|
|| PW_TYPE_INTERFACE_Node     || ----->     || SPA_TYPE_INTERFACE_Node        ||
||.--------------------------.||            ||.------------------------------.||
||| SPA_TYPE_INTERFACE_Node  |||            ||| PW_TYPE_INTERFACE_ClientNode |||
|||                          |||            |||                              |||
||'--------------------------'||            ||'------------------------------'||
|'----------------------------'|            |'--------------------------------'|

NOMBRE DEL MÓDULO

libpipewire-module-client-node

OPCIONES DEL MÓDULO

Este módulo no tiene opciones.

PROPIEDADES PARA LA LLAMADA CREATE_OBJECT

Todas las propiedades se pasan directamente a la llamada pw_context_create_node().

EJEMPLO DE CONFIGURACIÓN

El módulo generalmente se agrega al archivo de configuración del demonio principal de PipeWire y de los clientes.

context.modules = [
{ name = libpipewire-module-client-node }
]
