LIRC_MAKE_DEVINPUT(1) Comandos de usuario LIRC_MAKE_DEVINPUT(1)

NOMBRE

lirc-make-devinput - crea un devinput.lircd.conf para el sitio local.

SINOPSIS

lirc-make-devinput [input.h]

ARGUMENTOS

input.h
Archivo de encabezado analizado para crear el archivo de configuración.

DESCRIPCIÓN

Lee los archivos de encabezado del sistema y crea un devinput.lircd.conf que coincida con el sistema local (es decir, el kernel local). Normalmente requiere que el paquete kernel-headers esté instalado.

ENTORNO

PYTHON
Intérprete de Python, por defecto python

ARCHIVOS

/usr/include/linux/input-event-codes.h
Archivo de encabezado del sistema por defecto
/usr/include/linux/input.h
Archivo alternativo utilizado en kernels más antiguos.

VER TAMBIÉN
