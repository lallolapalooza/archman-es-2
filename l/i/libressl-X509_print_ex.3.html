Paquete: libressl

Licencias: ISC, custom:OpenSSL

X509_PRINT_EX(3) Manual de Funciones de Biblioteca X509_PRINT_EX(3)

NOMBRE

X509_print_ex, X509_CERT_AUX_print, X509_print_ex_fp, X509_print, X509_print_fp — imprimir de forma legible un certificado X.509

SINOPSIS

biblioteca “libcrypto”
#include <openssl/x509.h>

int
X509_print_ex(BIO *bio, X509 *x, unsigned long nameflags, unsigned long skipflags);

int
X509_CERT_AUX_print(BIO *bio, X509_CERT_AUX *aux, int indent);

int
X509_print_ex_fp(FILE *fp, X509 *x, unsigned long nameflags, unsigned long skipflags);

int
X509_print(BIO *bio, X509 *x);

int
X509_print_fp(FILE *fp, X509 *x);

DESCRIPCIÓN

X509_print_ex() imprime la información contenida en x a bio de forma legible para humanos. La impresión se interrumpe tan pronto como cualquier operación falla, con la excepción de que los fallos al intentar decodificar o imprimir la clave pública, las extensiones de la versión 3 de X.509 o datos auxiliares no estándar no se consideran errores.

Por defecto, los siguientes bloques de información se imprimen en el siguiente orden. Cada bloque puede omitirse estableciendo el bit correspondiente en skipflags, proporcionado entre paréntesis después de cada descripción de bloque.

  • Un par de líneas que dicen "Certificate:" y "Data:" que no contienen información. (X509_FLAG_NO_HEADER)
  • El número de versión del certificado según lo definido por el estándar, seguido entre paréntesis por el valor contenido en el campo de versión en notación hexadecimal. Consulte X509_get_version(3) para más detalles. (X509_FLAG_NO_VERSION)
  • El número de serie del certificado devuelto por X509_get_serialNumber(3). Si no es -1 y la conversión a long tiene éxito, se imprime en formato decimal y hexadecimal. Si es -1, demasiado grande para caber en long, o la conversión falla, se imprime byte a byte en notación hexadecimal. (X509_FLAG_NO_SERIAL)
  • El nombre del algoritmo de firma se imprime con X509_signature_print(3). (X509_FLAG_NO_SIGNAME)
  • El nombre del emisor devuelto por X509_get_issuer_name(3) se imprime con X509_NAME_print_ex(3). (X509_FLAG_NO_ISSUER)
  • El período de validez desde X509_get_notBefore(3) hasta X509_get_notAfter(3) se imprime usando ASN1_TIME_print(3). (X509_FLAG_NO_VALIDITY)
  • El nombre del sujeto devuelto por X509_get_subject_name(3) se imprime con X509_NAME_print_ex(3). (X509_FLAG_NO_SUBJECT)
  • El algoritmo de clave pública se imprime con i2a_ASN1_OBJECT(3), y la clave pública devuelta por X509_get_pubkey(3) con EVP_PKEY_print_public(3). (X509_FLAG_NO_PUBKEY)
  • Si un identificador único de emisor o sujeto está presente, su volcado hexadecimal se imprime con X509_signature_dump(3). (X509_FLAG_NO_IDS)
  • Todas las extensiones X.509 contenidas en el certificado se imprimen con X509V3_extensions_print(3). (X509_FLAG_NO_EXTENSIONS)
  • La firma se imprime con X509_signature_print(3). (X509_FLAG_NO_SIGDUMP)
  • Los datos auxiliares no estándar asociados con el certificado se imprimen usando la función X509_CERT_AUX_print() descrita a continuación. (X509_FLAG_NO_AUX)

El argumento nameflags modifica el formato para imprimir objetos de Name X.501 contenidos en x. Se pasa a X509_NAME_print_ex(3). Si nameflags es X509_FLAG_COMPAT, el argumento indent de X509_NAME_print_ex(3) se establece en 16 espacios y se utiliza el formato tradicional de SSLeay. De lo contrario, si el único bit establecido en XN_FLAG_SEP_MASK es XN_FLAG_SEP_MULTILINE, indent se establece en 12 espacios. De lo contrario, indent se establece en cero.

X509_CERT_AUX_print() imprime información contenida en aux a bio de forma legible para humanos con un margen izquierdo de indent espacios. Si aux es NULL, no imprime nada.

La información se imprime en el siguiente orden:

  • Propósitos para los que se pretende usar el certificado, según lo establecido con X509_add1_trust_object(3), cada uno impreso con OBJ_obj2txt(3).
  • Propósitos para los que el certificado no se pretende usar explícitamente, según lo establecido con X509_add1_reject_object(3), de nuevo cada uno impreso con OBJ_obj2txt(3).
  • Si aux contiene datos establecidos con X509_alias_set1(3), los bytes crudos se imprimen en formato sin codificar.
  • Si aux contiene datos establecidos con X509_keyid_set1(3), los bytes se imprimen en notación hexadecimal con dos puntos intermedios.

X509_print_ex_fp() es similar a X509_print_ex() excepto que imprime a fp.

X509_print() y X509_print_fp() son funciones envoltorio que establecen nameflags a XN_FLAG_COMPAT y skipflags a X509_FLAG_COMPAT.

VALORES DE RETORNO

X509_print_ex(), X509_print_ex_fp(), X509_print(), y X509_print_fp() devuelven 1 si toda la información solicitada se imprimió con éxito, incluso si ocurrieron fallos al intentar decodificar o imprimir la clave pública o las extensiones de la versión 3 de X.509, o 0 si cualquier otra operación falló.

X509_CERT_AUX_print() siempre devuelve 1 e ignora silenciosamente los errores de escritura.

HISTORIAL

X509_print() apareció por primera vez en SSLeay 0.5.1 y se cambió para imprimir en un BIO en SSLeay 0.6.0. X509_print_fp() apareció por primera vez en SSLeay 0.6.0. Ambas funciones han estado disponibles desde OpenBSD 2.4.

X509_CERT_AUX_print() apareció por primera vez en OpenSSL 0.9.5 y ha estado disponible desde OpenBSD 2.7.

X509_print_ex() y X509_print_ex_fp() aparecieron por primera vez en OpenSSL 0.9.7 y han estado disponibles desde OpenBSD 3.2.

ERRORES

Si se almacenaron datos arbitrarios en x utilizando X509_alias_set1(3), estas funciones pueden imprimir datos binarios e incluso bytes NUL.
