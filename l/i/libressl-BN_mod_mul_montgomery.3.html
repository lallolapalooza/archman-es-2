DESCRIPCIÓN

Estas funciones implementan la multiplicación de Montgomery. Se usan automáticamente cuando se llama a BN_mod_exp(3) con entradas adecuadas, pero pueden ser útiles cuando se van a realizar varias operaciones utilizando el mismo módulo.

BN_MONT_CTX_new() asigna e inicializa una estructura BN_MONT_CTX.

BN_MONT_CTX_set() configura la estructura mont a partir del módulo m precalculando su inverso y un valor R.

BN_MONT_CTX_set_locked() es un envoltorio para BN_MONT_CTX_new() y BN_MONT_CTX_set() que es útil si más de un hilo pretende utilizar el mismo BN_MONT_CTX y ninguno de estos hilos es exclusivamente responsable de crear e inicializar el contexto. BN_MONT_CTX_set_locked() primero adquiere el lock especificado utilizando CRYPTO_lock(3). Si *pmont ya es diferente de NULL, no se realiza ninguna acción. De lo contrario, se asigna un nuevo BN_MONT_CTX con BN_MONT_CTX_new(), se configura con BN_MONT_CTX_set(), y se almacena un puntero a él en *pmont. Finalmente, se libera el lock.

BN_MONT_CTX_copy() copia el BN_MONT_CTX from a to.

BN_MONT_CTX_free() libera los componentes del BN_MONT_CTX y, si fue creado por BN_MONT_CTX_new(), también la propia estructura. Si mont es un puntero NULL, no se realiza ninguna acción.

BN_mod_mul_montgomery() calcula

Mont(a, b) := a * b * R^-1

y coloca el resultado en r.

BN_from_montgomery() realiza la reducción de Montgomery

r = a * R^-1

BN_to_montgomery() calcula

Mont(a, R^2) = a * R

Tenga en cuenta que a debe ser no negativo y menor que el módulo.

Para todas las funciones, ctx es un BN_CTX asignado previamente utilizado para variables temporales.

Advertencia: Las entradas deben estar reducidas módulo m, de lo contrario el resultado estará fuera del rango esperado.

VALORES DE RETORNO

BN_MONT_CTX_new() devuelve el BN_MONT_CTX recién asignado o NULL en caso de error.

BN_MONT_CTX_set_locked() devuelve un puntero al contexto existente o de nueva creación, o NULL en caso de error.

Para las demás funciones, se devuelve 1 en caso de éxito o 0 en caso de error. Los códigos de error se pueden obtener mediante ERR_get_error(3).

NOMBRE

BN_mod_mul_montgomery, BN_montgomery_multiplicar, BN_mod_mul_montgomery_word, BN_mod_mul_montgomery_exp, BN_montgomery_exp - multiplicaciones y exponenciaciones modulares de Montgomery

SINOSIS

#include <openssl/bn.h>

int BN_mod_mul_montgomery(BIGNUM *r, const BIGNUM *a, const BIGNUM *b, const BIGNUM *m, BN_CTX *ctx);

int BN_montgomery_multiplicar(BIGNUM *r, const BIGNUM *a, const BIGNUM *b, const BIGNUM *m, BN_CTX *ctx);

int BN_mod_mul_montgomery_word(BIGNUM *r, const BIGNUM *a, BN_ULONG b, const BIGNUM *m, BN_CTX *ctx);

int BN_mod_mul_montgomery_exp(BIGNUM *r, const BIGNUM *a, const BIGNUM *d, const BIGNUM *m, BN_CTX *ctx);

int BN_montgomery_exp(BIGNUM *r, const BIGNUM *a, const BIGNUM *d, const BIGNUM *m, BN_CTX *ctx);

DESCRIPCIÓN

Estas funciones realizan multiplicaciones y exponenciaciones modulares utilizando la representación de Montgomery. La representación de Montgomery de un entero a módulo m es a * R mod m, donde R es una potencia de 2, típicamente mayor que m. Las operaciones en la representación de Montgomery son más rápidas que las operaciones modulares normales, pero requieren una conversión inicial y final.

BN_mod_mul_montgomery() calcula (a * b) mod m usando la representación de Montgomery. El módulo m debe ser impar. Las entradas a y b se asumen que están en representación de Montgomery y, por lo tanto, también son mayores que m. El resultado r se deja en representación de Montgomery.

BN_montgomery_multiplicar() es un sinónimo de BN_mod_mul_montgomery().

BN_mod_mul_montgomery_word() calcula (a * b) mod m, donde b es un BN_ULONG (un entero sin signo). a se asume que está en representación de Montgomery. El resultado r se deja en representación de Montgomery.

BN_mod_mul_montgomery_exp() calcula (a ^ d) mod m usando la representación de Montgomery. a se asume que está en representación de Montgomery. El resultado r se deja en representación de Montgomery.

BN_montgomery_exp() es un sinónimo de BN_mod_mul_montgomery_exp().

Para usar estas funciones, el módulo m primero debe ser convertido a la representación de Montgomery usando BN_to_montgomery(). Las entradas a y b deben ser convertidas a la representación de Montgomery usando BN_to_montgomery() o BN_to_montgomery_word(). Después de realizar las operaciones deseadas, el resultado puede ser convertido de nuevo a la representación normal usando BN_from_montgomery().

Estas funciones son optimizadas para módulos m que son potencias de dos menos uno, como los utilizados en la criptografía RSA. Para módulos generales, se deben usar las funciones de multiplicación y exponenciación modular estándar.

VALORES DE RETORNO

Todas estas funciones devuelven 1 en caso de éxito, y 0 en caso de error.

VER TAMBIÉN

BN_CTX_new(3), BN_add(3), BN_mul(3), BN_mod_inverse(3), BN_mod_exp(3), BN_to_montgomery(3), BN_from_montgomery(3).

HISTORIAL

Las funciones BN_mod_mul_montgomery, BN_montgomery_multiplicar, BN_mod_mul_montgomery_word, BN_mod_mul_montgomery_exp, y BN_montgomery_exp fueron añadidas en OpenSSL 1.0.0.
