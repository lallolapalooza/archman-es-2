NOMBRE

libssh2_channel_flush_ex - vaciar un canal

SINOPSIS

#include <libssh2.h>
int
libssh2_channel_flush_ex(LIBSSH2_CHANNEL *channel, int streamid);
int
libssh2_channel_flush(LIBSSH2_CHANNEL *channel);
int
libssh2_channel_flush_stderr(LIBSSH2_CHANNEL *channel);

DESCRIPCIÓN

channel - Flujo de canal activo para vaciar.

streamid - Número de subflujo específico para vaciar. Se pueden vaciar grupos de subflujos pasando una de las siguientes constantes.
LIBSSH2_CHANNEL_FLUSH_EXTENDED_DATA: Vaciar todos los subflujos de datos extendidos
LIBSSH2_CHANNEL_FLUSH_ALL: Vaciar todos los subflujos

Vacía el búfer de lectura para una instancia de canal dada. Se pueden vaciar subflujos individuales por número o utilizando una de las macros proporcionadas.

VALOR DE RETORNO

Devuelve el número de bytes vaciados o un valor negativo en caso de error. Devuelve LIBSSH2_ERROR_EAGAIN cuando normalmente bloquearía. Aunque LIBSSH2_ERROR_EAGAIN es un número negativo, no es realmente un error en sí mismo.
