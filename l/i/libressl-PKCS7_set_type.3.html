libressl-PKCS7_set_type(3)

Paquete: libressl

Licencias: ISC, custom:OpenSSL

PKCS7_SET_TYPE(3) Manual de funciones de biblioteca PKCS7_SET_TYPE(3)

NOMBRE

PKCS7_set_type, PKCS7_set0_type_other — inicializar el tipo de ContentInfo de PKCS#7

SINOPSIS

biblioteca “libcrypto”
#include <openssl/pkcs7.h>

int
PKCS7_set_type(PKCS7 *p7, int type);

int
PKCS7_set0_type_other(PKCS7 *p7, int type, ASN1_TYPE *content);

DESCRIPCIÓN

Estas funciones establecen el type de una estructura ContentInfo no utilizada p7.

La función PKCS7_set_type() también asigna e inicializa un objeto hijo vacío en p7. El argumento type puede ser cualquiera de estos NIDs, creando un objeto hijo del tipo de datos indicado:

Argumento type tipo de datos del hijo versión
NID_pkcs7_data ASN1_OCTET_STRING n.a.
NID_pkcs7_digest PKCS7_DIGEST 0
NID_pkcs7_encrypted PKCS7_ENCRYPT 0
NID_pkcs7_enveloped PKCS7_ENVELOPE 0
NID_pkcs7_signed PKCS7_SIGNED 1
NID_pkcs7_signedAndEnveloped PKCS7_SIGN_ENVELOPE 1

Si el type proporcionado es inválido, p7 permanece sin cambios y PKCS7_set_type() falla.

Si falla la asignación de memoria, PKCS7_set_type() falla y p7 puede permanecer en un estado inconsistente.

La función PKCS7_set0_type_other() acepta un NID arbitrario como type y también establece el content, sin verificarlo de ninguna manera ni copiarlo.

Para ambas funciones, el resto del estado interno de p7 permanece sin cambios.

VALORES DE RETORNO

La función PKCS7_set_type() devuelve 1 en caso de éxito o 0 en caso de fallo.

La función PKCS7_set0_type_other() no realiza ningún manejo de errores y siempre devuelve 1.

VER TAMBIÉN

ASN1_OCTET_STRING_new(3), ASN1_TYPE_new(3), PKCS7_encrypt(3), PKCS7_new(3), PKCS7_set_content(3), PKCS7_sign(3)

HISTORIA

La función PKCS7_set_type() apareció por primera vez en SSLeay 0.8.1 y PKCS7_set0_type_other() en OpenSSL 0.9.8. Ambas han estado disponibles desde OpenBSD 2.4.

ADVERTENCIAS

Si p7 ya se ha utilizado antes de ser pasado a una de estas funciones, informará éxito aunque filtre memoria. Más adelante, si otras funciones intentan usar p7 en su función anterior, es probable que se comporten incorrectamente.
