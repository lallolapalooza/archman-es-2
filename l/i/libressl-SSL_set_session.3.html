SSL_SET_SESSION(3) Manual de funciones de biblioteca SSL_SET_SESSION(3)

NOMBRE

SSL_set_session — establecer una sesión TLS/SSL a ser utilizada durante la conexión TLS/SSL

SINOPSIS

biblioteca “libssl” libcrypto
#include <openssl/ssl.h>

int
SSL_set_session(SSL *ssl, SSL_SESSION *session);

DESCRIPCIÓN

SSL_set_session() establece session para ser utilizada cuando se establezca la conexión TLS/SSL. SSL_set_session() solo es útil para clientes TLS/SSL. Cuando se establece la sesión, el contador de referencias de session se incrementa en 1. Si la sesión no se reutiliza, el contador de referencias se decrementa nuevamente durante SSL_connect(). Si la sesión se reutilizó o no, se puede consultar con la llamada SSL_session_reused(3).

Si ya hay una sesión establecida dentro de ssl (porque se estableció con SSL_set_session() anteriormente o porque el mismo ssl se usó previamente para una conexión), SSL_SESSION_free(3) se llamará para esa sesión.

SSL_SESSION los objetos mantienen información de enlace interna sobre la lista de caché de sesiones cuando se insertan en un objeto de caché de sesiones SSL_CTX. Por lo tanto, un objeto SSL_SESSION, independientemente de su contador de referencias, solo debe usarse con un objeto SSL_CTX (y los objetos SSL creados a partir de este objeto SSL_CTX).

VALORES DE RETORNO

Los siguientes valores de retorno pueden ocurrir:

0
La operación falló; compruebe la pila de errores para averiguar el motivo.
1
La operación se realizó correctamente.

VER TAMBIÉN

ssl(3), SSL_CTX_set_session_cache_mode(3), SSL_get_session(3), SSL_SESSION_free(3), SSL_session_reused(3)

HISTORIA

SSL_set_session() apareció por primera vez en SSLeay 0.5.2 y ha estado disponible desde OpenBSD 2.4.
