SSL_CTX_FLUSH_SESSIONS(3) Manual de funciones de biblioteca SSL_CTX_FLUSH_SESSIONS(3)

NOMBRE

SSL_CTX_flush_sessions — eliminar sesiones expiradas

SINOPSIS

biblioteca “libssl” libcrypto
#include <openssl/ssl.h>

void
SSL_CTX_flush_sessions(SSL_CTX *ctx, long tm);

DESCRIPCIÓN

SSL_CTX_flush_sessions() realiza un recorrido por la caché de sesiones de ctx para eliminar las sesiones expiradas en el momento tm.

Si está habilitada, la caché de sesiones interna recopilará todas las sesiones establecidas hasta el número máximo especificado (ver SSL_CTX_sess_set_cache_size(3)). Dado que las sesiones no se reutilizarán una vez que hayan expirado, deben eliminarse de la caché para ahorrar recursos. Esto se puede hacer automáticamente cada vez que se hayan establecido 255 sesiones nuevas (ver SSL_CTX_set_session_cache_mode(3)) o manualmente llamando a SSL_CTX_flush_sessions().

El parámetro tm especifica el tiempo que se utilizará para la prueba de expiración, en la mayoría de los casos se utilizará el tiempo real proporcionado por time(0).

SSL_CTX_flush_sessions() solo verificará las sesiones almacenadas en la caché interna. Sin embargo, cuando se encuentra y se elimina una sesión, se llama a remove_session_cb para sincronizar con la caché externa (ver SSL_CTX_sess_set_get_cb(3)).

VER TAMBIÉN

ssl(3), SSL_CTX_sess_set_get_cb(3), SSL_CTX_set_session_cache_mode(3), SSL_CTX_set_timeout(3)

HISTORIA

SSL_CTX_flush_sessions() apareció por primera vez en SSLeay 0.8.0 y ha estado disponible desde OpenBSD 2.4.
