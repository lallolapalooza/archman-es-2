lib::core::only(3) Documentación de Perl aportada por el usuario lib::core::only(3)

NOMBRE

lib::core::only - Elimina todas las rutas que no sean del núcleo de @INC para evitar directorios de sitio/proveedor

SINOPSIS

use lib::core::only; # ahora @INC contiene solo los dos directorios del núcleo

Para obtener solo los directorios del núcleo más los que están en el ámbito de local::lib:

$ perl -mlocal::lib -Mlib::core::only -Mlocal::lib=~/perl5 myscript.pl

Para intentar hacer una compilación autocontenida (pero ten en cuenta que esto no se propagará de manera fiable a los subprocesos, consulta las ADVERTENCIAS a continuación):

$ PERL5OPT='-mlocal::lib -Mlib::core::only -Mlocal::lib=~/perl5' cpan

Ten en cuenta que es necesario usar "local::lib" dos veces para que esto funcione. Primero, para que "lib::core::only" no impida la carga de "local::lib" (actualmente no está en el núcleo) y luego de nuevo después de "lib::core::only" para que las rutas locales no se eliminen.

DESCRIPCIÓN

lib::core::only es simplemente un atajo para decir "por favor, reduce mi @INC solo a los directorios de biblioteca principal y de biblioteca (específica de la arquitectura) de este perl".

Puede que quieras hacer esto para asegurarte de que un local::lib contenga solo el código que necesitas, o para probar un árbol de App::FatPacker, o para evitar paquetes de proveedor conocidos y malos.

Puede que quieras usar esto para intentar instalar un árbol autocontenido de módulos de perl. Ten cuidado, ya que probablemente no funcione (ver "ADVERTENCIAS").

Este módulo se extrajo de la función --self-contained de local::lib, y contiene la única parte que alguna vez funcionó. Me disculpo con cualquiera que pensó que otra cosa lo hizo.

ADVERTENCIAS

Esto **no** se propaga correctamente entre invocaciones de perl como lo hace el contenido de local::lib. No puede. Es solo una importación de módulo, por lo que **solo afecta a la instancia específica de la máquina virtual de perl en la que la cargas y la importas()**.

Si deseas propagarla entre invocaciones, puedes establecer la variable de entorno PERL5OPT a '-Mlib::core::only' y funcionará más o menos. Pero ten en cuenta que el modo taint ignora esto, por lo que el código de compilación y prueba de algunos módulos probablemente también lo hará.

También debes tener en cuenta que las opciones de línea de comandos de perl no se procesan en orden: las opciones -I surten efecto antes que las opciones -M, por lo tanto:

perl -Mlib::core::only -Ilib

es poco probable que haga lo que deseas; es exactamente equivalente a:

perl -Mlib::core::only

Si deseas combinar un @INC solo del núcleo con rutas adicionales, necesitas agregar las rutas adicionales usando opciones -M y el módulo lib:

perl -Mlib::core::only -Mlib=lib
# o si estás intentando probar código compilado:
perl -Mlib::core::only -Mblib

Para obtener más información sobre la imposibilidad de propagar esto de manera sensata a través de la compilación de módulos sin ayuda del programa de compilación, consulta http://www.shadowcat.co.uk/blog/matt-s-trout/tainted-love - y para formas de lograr los resultados de la antigua función --self-contained, consulta la función tree de App::FatPacker, y la función --local-lib-contained de App::cpanminus.
