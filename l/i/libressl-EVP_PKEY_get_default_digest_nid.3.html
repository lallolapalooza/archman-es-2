NOMBRE

EVP_PKEY_get_default_digest_nid — obtener el hash de firma predeterminado

SINOPSIS

biblioteca “libcrypto”
#include <openssl/evp.h>

int
EVP_PKEY_get_default_digest_nid(EVP_PKEY *pkey, int *pnid);

DESCRIPCIÓN

La función EVP_PKEY_get_default_digest_nid() establece *pnid al NID (identificador numérico) del hash (digest) predeterminado para las operaciones de firma de clave pública asociadas con pkey.

Algunos algoritmos de firma, por ejemplo EVP_PKEY_ED25519, no usan un hash durante la firma. En este caso, *pnid se establece en NID_undef.

El soporte para los siguientes algoritmos de clave pública está integrado en la biblioteca:

EVP_PKEY_base_id(3) *pnid valor de retorno
EVP_PKEY_DSA NID_sha1 obligatorio
EVP_PKEY_EC NID_sha1 obligatorio
EVP_PKEY_ED25519 NID_undef obligatorio
EVP_PKEY_HMAC NID_sha1 asesoramiento
EVP_PKEY_RSA NID_sha256 asesoramiento

VALORES DE RETORNO

La función EVP_PKEY_get_default_digest_nid() devuelve 1 si el hash es de asesoramiento (es decir, se pueden usar otros hashes) y 2 si es obligatorio (no se pueden usar otros hashes). Devuelve 0 o un valor negativo en caso de error. En particular, un valor de retorno de -2 indica que la operación no es compatible con el algoritmo de clave pública.

VER TAMBIÉN

EVP_PKEY_CTX_ctrl(3), EVP_PKEY_CTX_new(3), EVP_PKEY_new(3), EVP_PKEY_sign(3), EVP_PKEY_verify(3), EVP_PKEY_verify_recover(3)

HISTORIA

EVP_PKEY_get_default_digest_nid() apareció por primera vez en OpenSSL 1.0.0 y ha estado disponible desde OpenBSD 4.9.
