libssh2_scp_recv(3)

Paquete: libssh2

Licencias: BSD

libssh2_scp_recv(3) libssh2 libssh2_scp_recv(3)

NOMBRE

libssh2_scp_recv - solicitar un archivo remoto vía SCP

SINOPSIS

#include <libssh2.h>
LIBSSH2_CHANNEL *
libssh2_scp_recv(LIBSSH2_SESSION *session, const char *path, struct stat *sb);

DESCRIPCIÓN

¡Esta función está OBSOLETA en 1.7.0. ¡Utiliza la función libssh2_scp_recv2(3) en su lugar!

session - Instancia de sesión como la devuelve libssh2_session_init_ex(3)

path - Ruta completa y nombre de archivo a transferir. Es el nombre del archivo remoto.

sb - Se rellena con el tamaño, modo, mtime y atime del archivo remoto.

Solicita un archivo del host remoto vía SCP.

VALOR DE RETORNO

Puntero a una instancia LIBSSH2_CHANNEL recién asignada, o NULL en caso de error.

ERRORES

LIBSSH2_ERROR_ALLOC - Una llamada interna de asignación de memoria falló.

LIBSSH2_ERROR_SCP_PROTOCOL -

LIBSSH2_ERROR_EAGAIN - Marcado para E/S no bloqueante pero la llamada bloquearía.

VER TAMBIÉN
