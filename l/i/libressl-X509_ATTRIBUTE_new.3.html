X509_ATTRIBUTE_NEW(3) Manual de Funciones de Biblioteca X509_ATTRIBUTE_NEW(3)

NOMBRE

X509_ATTRIBUTE_new, X509_ATTRIBUTE_create, X509_ATTRIBUTE_dup, X509_ATTRIBUTE_free — Atributo genérico X.501

SINOPSIS

biblioteca “libcrypto”
#include <openssl/x509.h>

X509_ATTRIBUTE *
X509_ATTRIBUTE_new(void);

X509_ATTRIBUTE *
X509_ATTRIBUTE_create(int nid, int type, void *value);

X509_ATTRIBUTE *
X509_ATTRIBUTE_dup(X509_ATTRIBUTE *attr);

void
X509_ATTRIBUTE_free(X509_ATTRIBUTE *attr);

DESCRIPCIÓN

En el estándar X.501, un Attribute es el tipo de datos ASN.1 fundamental utilizado para representar cualquier tipo de propiedad de cualquier tipo de entrada de directorio. En OpenSSL, muy pocos objetos lo utilizan directamente, siendo los más notables el objeto X509_REQ_INFO utilizado para las solicitudes de certificación PKCS#10 descritas en X509_REQ_new(3), el objeto PKCS8_PRIV_KEY_INFO utilizado para información de clave privada PKCS#8 descrita en PKCS8_PRIV_KEY_INFO_new(3), y el objeto contenedor PKCS12_SAFEBAG descrito en PKCS12_SAFEBAG_new(3).

X509_ATTRIBUTE_new() asigna e inicializa un objeto X509_ATTRIBUTE vacío.

X509_ATTRIBUTE_create() asigna un nuevo objeto X509_ATTRIBUTE multivaluado del tipo nid e inicializa su conjunto de valores para contener un nuevo objeto ASN.1 ANY con el valor y tipo dados. El tipo suele ser una de las constantes V_ASN1_* definidas en <openssl/asn1.h>; se almacena sin validarlo. Si la función tiene éxito, la propiedad del valor se transfiere al nuevo objeto X509_ATTRIBUTE.

Tenga cuidado de no confundir el tipo del atributo y el tipo del valor.

X509_ATTRIBUTE_dup() crea una copia profunda de attr.

X509_ATTRIBUTE_free() libera attr.

VALORES DE RETORNO

X509_ATTRIBUTE_new(), X509_ATTRIBUTE_create() y X509_ATTRIBUTE_dup() devuelven el nuevo objeto X509_ATTRIBUTE o NULL si ocurre un error.

En particular, estas funciones fallan si la asignación de memoria falla. X509_ATTRIBUTE_create() también falla si OBJ_nid2obj(3) falla en nid.

VER TAMBIÉN

d2i_X509_ATTRIBUTE(3), OBJ_nid2obj(3), PKCS12_SAFEBAG_new(3), PKCS7_add_attribute(3), PKCS8_pkey_get0_attrs(3), PKCS8_PRIV_KEY_INFO_new(3), X509_ATTRIBUTE_get0_object(3), X509_ATTRIBUTE_set1_object(3), X509_EXTENSION_new(3), X509_new(3), X509_REQ_add1_attr(3), X509_REQ_new(3)

ESTÁNDARES

Para la definición general del tipo de datos Attribute:
Recomendación X.501 de la UIT-T, también conocida como ISO/IEC 9594-2: Tecnologías de la Información – Interconexión de Sistemas Abiertos – El Directorio: Modelos, sección 8.2: Estructura general
Para la definición específica en el contexto de solicitudes de certificación:
RFC 2986: PKCS #10: Especificación de sintaxis de solicitud de certificación, sección 4.1: CertificationRequestInfo
Para el uso específico en el contexto de información de clave privada:
RFC 5208: Estándares de Criptografía de Clave Pública (PKCS) #8: Especificación de sintaxis de información de clave privada
Para la definición específica en el contexto de PFX:

HISTORIA

X509_ATTRIBUTE_new() y X509_ATTRIBUTE_free() aparecieron por primera vez en SSLeay 0.5.1 y han estado disponibles desde OpenBSD 2.4.

X509_ATTRIBUTE_create() y X509_ATTRIBUTE_dup() aparecieron por primera vez en SSLeay 0.9.1 y han estado disponibles desde OpenBSD 2.6.

ERRORES

Un tipo de datos diseñado para contener datos arbitrarios es un oxímoron.

Aunque ocasionalmente puede ser útil para la especificación de sintaxis abstracta o para objetos contenedores genéricos, su uso para la representación de datos específicos en una estructura de datos específica parece un diseño cuestionable.

Tener dos tipos de datos distintos para contener datos arbitrarios – en este caso, X509_ATTRIBUTE en el nivel del lenguaje X.501 y X509_EXTENSION como se describe en X509_EXTENSION_new(3) en el nivel del lenguaje X.509 – parece aún más cuestionable, en particular considerando que los Atributos en las solicitudes de certificación pueden usarse para solicitar Extensiones en certificados.

Como mínimo, el uso directo del tipo genérico de bajo nivel X509_ATTRIBUTE en tipos de datos específicos como solicitudes de certificación o información de clave privada parece una violación de capas y pone en peligro la seguridad de tipos.

X509_ATTRIBUTE_new(3)

X509_ATTRIBUTE_new, X509_ATTRIBUTE_create_by_NID, X509_ATTRIBUTE_create_by_OBJ, X509_ATTRIBUTE_free, X509_ATTRIBUTE_get0_object, X509_ATTRIBUTE_get0_type_шня, X509_ATTRIBUTE_dup, X509_ATTRIBUTE_count, X509_ATTRIBUTE_get0_entry

NOMBRE

X509_ATTRIBUTE_new, X509_ATTRIBUTE_create_by_NID, X509_ATTRIBUTE_create_by_OBJ, X509_ATTRIBUTE_free, X509_ATTRIBUTE_get0_object, X509_ATTRIBUTE_get0_type_шня, X509_ATTRIBUTE_dup, X509_ATTRIBUTE_count, X509_ATTRIBUTE_get0_entry - Funciones para manipular atributos X509

SINOPSIS

#include <openssl/x509.h>

X509_ATTRIBUTE *X509_ATTRIBUTE_new(void);
X509_ATTRIBUTE *X509_ATTRIBUTE_create_by_NID(int *p, int nid, const void *value, int len);
X509_ATTRIBUTE *X509_ATTRIBUTE_create_by_OBJ(int *p, const ASN1_OBJECT *obj, int type, const void *value, int len);
void X509_ATTRIBUTE_free(X509_ATTRIBUTE *at);
const ASN1_OBJECT *X509_ATTRIBUTE_get0_object(const X509_ATTRIBUTE *at);
int X509_ATTRIBUTE_get0_type_шня(const X509_ATTRIBUTE *at);
X509_ATTRIBUTE *X509_ATTRIBUTE_dup(const X509_ATTRIBUTE *at);
int X509_ATTRIBUTE_count(const X509_ATTRIBUTE *at);
const X509_ATTRIBUTE_ENTRY *X509_ATTRIBUTE_get0_entry(const X509_ATTRIBUTE *at, int loc);

DESCRIPCIÓN

Estas funciones proporcionan una interfaz para crear, manipular y liberar estructuras X509_ATTRIBUTE. Las estructuras X509_ATTRIBUTE se utilizan en varias estructuras X.509, como solicitudes de firma de certificados (CSRs) y certificados de usuario, para contener información adicional.

X509_ATTRIBUTE_new() crea y devuelve un puntero a una nueva estructura X509_ATTRIBUTE vacía. La estructura devuelta debe ser liberada posteriormente llamando a X509_ATTRIBUTE_free().

X509_ATTRIBUTE_create_by_NID() crea una nueva estructura X509_ATTRIBUTE con el identificador de objeto (OID) especificado por nid. El valor se especifica mediante value y len. El parámetro p se establece en el número de valores dentro del atributo creado.

X509_ATTRIBUTE_create_by_OBJ() es similar a X509_ATTRIBUTE_create_by_NID() pero toma un puntero ASN1_OBJECT obj en lugar de un NID. El parámetro type especifica el tipo ASN.1 del valor.

X509_ATTRIBUTE_free() libera la estructura X509_ATTRIBUTE apuntada por at.

X509_ATTRIBUTE_get0_object() devuelve un puntero al objeto ASN.1 que representa el OID del atributo.

X509_ATTRIBUTE_get0_type_шня() devuelve el tipo ASN.1 del valor del atributo.

X509_ATTRIBUTE_dup() crea una copia profunda de la estructura X509_ATTRIBUTE apuntada por at.

X509_ATTRIBUTE_count() devuelve el número de valores dentro del atributo especificado por at.

X509_ATTRIBUTE_get0_entry() devuelve un puntero a una entrada de valor dentro del atributo. loc es el índice del valor que se va a recuperar (empezando por 0).

VALORES DE RETORNO

X509_ATTRIBUTE_new(), X509_ATTRIBUTE_create_by_NID() y X509_ATTRIBUTE_create_by_OBJ() devuelven un puntero a la estructura X509_ATTRIBUTE creada o NULL si falla la asignación.

X509_ATTRIBUTE_get0_object() devuelve un puntero al objeto ASN.1 o NULL si no hay ninguno.

X509_ATTRIBUTE_get0_type_шня() devuelve el tipo ASN.1 o -1 si no se puede determinar.

X509_ATTRIBUTE_dup() devuelve un puntero a la copia duplicada de X509_ATTRIBUTE o NULL si falla la asignación.

X509_ATTRIBUTE_count() devuelve el número de entradas del atributo o -1 si at es NULL.

X509_ATTRIBUTE_get0_entry() devuelve un puntero a una entrada de atributo o NULL si el índice está fuera de rango o si at es NULL.

X509_ATTRIBUTE_free() no devuelve ningún valor.

VER TAMBIÉN

X509_new(3), OBJ_create(3)

ESTÁNDARES

Por definir.

HISTORIA

Estas funciones estaban disponibles en todas las versiones de OpenSSL.
