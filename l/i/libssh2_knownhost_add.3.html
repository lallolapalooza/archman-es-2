libssh2_knownhost_add(3)

Paquete: libssh2

Licencias: BSD

libssh2_knownhost_add(3) libssh2 libssh2_knownhost_add(3)

NOMBRE

libssh2_knownhost_add - agregar un host conocido

SINOPSIS

#include <libssh2.h>
int
libssh2_knownhost_add(LIBSSH2_KNOWNHOSTS *hosts,
                      char *host, char *salt,
                      char *key, size_t keylen,
                      int typemask,
                      struct libssh2_knownhost **store);

DESCRIPCIÓN

Desaconsejamos el uso de esta función a partir de libssh2 1.2.5. En su lugar, instamos encarecidamente a los usuarios a utilizar en su lugar libssh2_knownhost_addc(3), que tiene una API más completa. libssh2_knownhost_add(3) está sujeto a eliminación en una futura versión.

Agrega un host conocido a la colección de hosts conocidos identificada por el manejador 'hosts'.

host es un puntero al nombre del host en texto plano o hasheado. Si está hasheado, debe proporcionarse codificado en base64. El nombre del host puede ser la dirección numérica IP del host o el nombre completo.

saltP es un puntero a la sal utilizada para el hash del host, si el host se proporciona hasheado. Si el host se proporciona en texto plano, la sal no tiene significado. La sal debe proporcionarse codificada en base64 con un byte nulo al final.

key es un puntero a la clave para el host dado.

keylen es el tamaño total en bytes de la clave apuntada por el argumento key.

typemask es una máscara de bits que especifica el formato e información sobre los datos pasados a esta función. Específicamente, detalla en qué formato está el nombre del host, en qué formato está la clave y qué tipo de clave es.

El nombre del host se proporciona como uno de los siguientes tipos: LIBSSH2_KNOWNHOST_TYPE_PLAIN, LIBSSH2_KNOWNHOST_TYPE_SHA1 o LIBSSH2_KNOWNHOST_TYPE_CUSTOM.

La clave está codificada utilizando una de las siguientes codificaciones: LIBSSH2_KNOWNHOST_KEYENC_RAW o LIBSSH2_KNOWNHOST_KEYENC_BASE64.

La clave utiliza uno de los siguientes algoritmos: LIBSSH2_KNOWNHOST_KEY_RSA1, LIBSSH2_KNOWNHOST_KEY_SSHRSA o LIBSSH2_KNOWNHOST_KEY_SSHDSS (obsoleto).

store debe apuntar a un puntero que se rellenará para apuntar a los datos del host conocido después de la adición. Se puede pasar NULL si no te importa este puntero.

VALOR DE RETORNO

Devuelve un código de error regular de libssh2, donde los valores negativos son códigos de error y 0 indica éxito.

DISPONIBILIDAD

Agregado en libssh2 1.2, obsoleto desde libssh2 1.2.5. ¡Use libssh2_knownhost_addc(3) en su lugar!
