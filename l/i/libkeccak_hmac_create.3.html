NOMBRE

libkeccak_hmac_create - Asigna e inicializa el estado de hashing HMAC

SINOPSIS

#include <libkeccak.h>
struct libkeccak_hmac_state *libkeccak_hmac_create(const struct libkeccak_spec *spec, const void *key, size_t key_length);

Enlazar con -lkeccak.

DESCRIPCIÓN

La función libkeccak_hmac_create() asigna un nuevo struct libkeccak_hmac_state * con un elemento inicializado, y establece los parámetros de ajuste del algoritmo a los especificados por *spec, y la clave a key de longitud key_length.

VALORES DE RETORNO

La función libkeccak_hmac_create() devuelve un struct libkeccak_hmac_state * recién asignado (de un elemento inicializado) en caso de éxito. En caso de error, devuelve NULL y errno se establece para describir el error.

ERRORES

La función libkeccak_hmac_create() puede fallar por cualquiera de los errores especificados para las funciones malloc(3) y realloc(3).

VER TAMBIÉN

libkeccak_hmac_initialise(3), libkeccak_hmac_free(3), libkeccak_hmac_fast_free(3), libkeccak_hmac_duplicate(3)
