NOMBRE

X509_verify_cert — descubrir y verificar la cadena de certificados X509

SINOPSIS

biblioteca “libcrypto”
#include <openssl/x509.h>

int
X509_verify_cert(X509_STORE_CTX *ctx);

DESCRIPCIÓN

La función X509_verify_cert() intenta descubrir y validar una cadena de certificados basándose en los parámetros de ctx.

Las aplicaciones rara vez llaman a esta función directamente, pero OpenSSL la utiliza internamente para la validación de certificados, tanto en el código S/MIME como en el código SSL/TLS.

VALORES DE RETORNO

Si se puede construir y validar una cadena completa, esta función devuelve 1; de lo contrario, devuelve un valor <= 0 que indica un fallo.

Se puede obtener información adicional sobre el error examinando ctx, utilizando X509_STORE_CTX_get_error(3).

VEASE TAMBIÉN

openssl(1), X509_STORE_CTX_get_error(3), X509_STORE_CTX_new(3)

HISTORIA

X509_verify_cert() apareció por primera vez en SSLeay 0.8.0 y ha estado disponible desde OpenBSD 2.4.

ERRORES

Esta función utiliza el encabezado <openssl/x509.h> en contraposición a la mayoría de las funciones de verificación de cadena que utilizan <openssl/x509_vfy.h>.
