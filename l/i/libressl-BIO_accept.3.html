NOMBRE

int
BIO_accept(int socket, char **addr);

int
BIO_sock_error(int socket);

int
BIO_sock_non_fatal_error(int errnum);

int
BIO_sock_should_retry(int retval);

int
BIO_socket_nbio(int socket, int mode);

int
BIO_set_tcp_ndelay(int socket, int on);

DESCRIPCIÓN

BIO_get_host_ip() busca una dirección IPv4 para el hostname dado utilizando getaddrinfo(3) y escribe la primera dirección IPv4 devuelta en *in_addr_buffer. El llamador es responsable de proporcionar un búfer que tenga al menos el tamaño de sizeof(in_addr_t) bytes. Después de una llamada exitosa, el llamador necesita convertir in_addr_buffer a (in_addr_t *).

BIO_get_port() busca servname en la base de datos services(5) utilizando getaddrinfo(3) y almacena el número de puerto asociado en la ubicación especificada por el argumento port.

BIO_get_accept_socket() crea un socket TCP IPv4 y listen(2)s para conexiones entrantes. La cadena host_port se analiza. Si contiene dos puntos, la subcadena antes de los dos puntos se interpreta como el nombre de host local de la interfaz a la que enlazar usando bind(2). Si el nombre de host está vacío, consiste en un único asterisco ("*:..."), o si no hay dos puntos, se utiliza INADDR_ANY en lugar de un nombre de host local. El resto de la cadena host_port, o toda la cadena si no contiene dos puntos, se trata como un nombre de servicio. El nombre de host y el nombre de servicio se convierten a una dirección IP local y un número de puerto utilizando getaddrinfo(3). Si bind_mode es la constante BIO_BIND_REUSEADDR, se intenta permitir la reutilización de direcciones locales usando setsockopt(2) con un argumento de SO_REUSEADDR antes de llamar a bind(2).

BIO_accept() llama a accept(2) para recibir una conexión en el socket. Cuando recibe una conexión, free(3)s *addr, y si es una conexión IPv4, asigna una nueva cadena, escribe la dirección IP del par en formato decimal punteado, dos puntos y el número de puerto en decimal en la cadena, y almacena un puntero a la cadena en *addr. Para otras familias de direcciones o si falla getnameinfo(3) o la asignación de memoria, *addr se establece en NULL pero BIO_accept() tiene éxito de todos modos.

BIO_sock_error() recupera, borra y devuelve el código de estado de error del socket llamando a getsockopt(2) con los argumentos SOL_SOCKET y SO_ERROR.

BIO_sock_non_fatal_error() determina si el código de estado de error errnum representa un error recuperable.

BIO_sock_should_retry() determina si ocurrió un error recuperable inspeccionando tanto errno(2) como retval, que se supone que es el valor de retorno de una función llamada previamente como BIO_accept(), BIO_read(3), o BIO_write(3).

Si mode no es cero, BIO_socket_nbio() cambia el socket a modo no bloqueante utilizando fcntl(2). Si mode es 0, lo cambia a modo bloqueante.

BIO_set_tcp_ndelay() establece la opción TCP_NODELAY en el socket si on es 1 o la borra si on es 0; véase tcp(4) para más detalles.

VALORES DE RETORNO

BIO_get_host_ip(), BIO_get_port(), y BIO_socket_nbio() devuelven 1 en caso de éxito o 0 en caso de fallo.

BIO_get_accept_socket() devuelve el descriptor de archivo del nuevo socket de escucha creado o -1 si host_port es NULL, no se especifica servicio, o falla getaddrinfo(3), socket(2), bind(2), listen(2), o la asignación de memoria.

BIO_accept() devuelve el descriptor de archivo de la conexión recibida, -1 en caso de errores fatales, es decir, cuando addr es NULL o accept(2) falla fatalmente, o -2 cuando accept(2) falla de forma no fatal y podría tener éxito al reintentarlo más tarde.

BIO_sock_error() devuelve un código de estado de error como EAGAIN, ECONNABORTED, ECONNREFUSED, ECONNRESET, ELOOP, EMSGSIZE, ENOBUFS, ENOTCONN, EPIPE, ETIMEDOUT, u otros, 0 si el socket no está en estado de error, o 1 si getsockopt(2) falla.

DESCRIPTION

These functions provide a convenient interface to network socket operations.

BIO_set_fd() associates the file descriptor fd with the BIO bio. If close_flag is true, then the file descriptor will be closed when the BIO is closed. BIO_set_fd() is intended for use with existing file descriptors, and is therefore not available for use with SSL.

BIO_set_nbio() sets the non-blocking mode for the socket BIO bio. If nbio is non-zero, the socket is set to non-blocking mode. Otherwise, it is set to blocking mode. This function is equivalent to BIO_socket_nbio().

BIO_socket_nbio() sets the non-blocking mode for the socket BIO bio. If nbio is non-zero, the socket is set to non-blocking mode. Otherwise, it is set to blocking mode.

BIO_setup_buffering() sets the buffering mode for the socket BIO bio. bufmode can be BIO_BUF_NONE, BIO_BUF_GET, BIO_BUF_PUT, or BIO_BUF_BOTH.

BIO_set_tcp_ndelay() sets the TCP_NODELAY option on the socket associated with bio. If on is non-zero, TCP_NODELAY is enabled. Otherwise, it is disabled.

BIO_get_host_ip() resolves a host name to an IP address string. host is the hostname, and ip_addr is a buffer to store the IP address. ip_len is the size of the buffer. It returns 1 on success, and 0 on failure.

BIO_get_port() resolves a service name or port number string to a port number string. host_port is a string containing the hostname and port, separated by a colon. port_str is a buffer to store the port number string, and port_len is the size of the buffer. It returns 1 on success, and 0 on failure.

BIO_get_accept_socket() allocates and configures a listening socket. It takes a hostname and a service name or port number. It returns the listening socket file descriptor on success, or -1 on failure.

BIO_socket_bind() binds the socket in bio to a specific host and port. It uses the same arguments as BIO_get_accept_socket() to determine the address to bind to. It returns 1 on success, and 0 on failure.

BIO_socket_listen() puts the socket in bio into listening mode with the specified backlog. It returns 1 on success, and 0 on failure.

BIO_accept() performs an accept operation on the socket BIO bio. It waits until a connection is established. If addr is not NULL, the address of the connecting client is stored in the buffer pointed to by addr. hlen is a pointer to the size of the address buffer, which will be updated with the actual size of the client's address. It returns 1 on success, and 0 on failure. Note that this function blocks until a connection is accepted.

BIO_accept_ex() is similar to BIO_accept(), but allows passing a flags argument.

RETURN VALUES

BIO_sock_non_fatal_error() returns 1 if errnum is EAGAIN, EALREADY, EINPROGRESS, EINTR, or ENOTCONN and 0 otherwise, even if errnum is 0.

BIO_sock_should_retry() returns 1 if BIO_sock_non_fatal_error(errno) is 1 and retval is either 0 or -1, or 0 otherwise.

BIO_set_tcp_ndelay() returns 0 on success or -1 on failure.

ERRORS

If BIO_get_host_ip(), BIO_get_port(), or BIO_get_accept_socket() fail or BIO_accept() fails fatally, the following diagnostics can be retrieved with ERR_get_error(3), ERR_GET_REASON(3), and ERR_reason_error_string(3):

BIO_R_ACCEPT_ERROR "accept error"
accept(2) failed fatally in BIO_accept().
BIO_R_BAD_HOSTNAME_LOOKUP "bad hostname lookup"
getaddrinfo(3) failed or hostname was NULL in BIO_get_host_ip(), or getaddrinfo(3) failed in BIO_get_accept_socket().
BIO_R_INVALID_ARGUMENT "invalid argument"
getaddrinfo(3) failed in BIO_get_port().
ERR_R_MALLOC_FAILURE "malloc failure"
Memory allocation failed in BIO_get_accept_socket(), or BIO_accept() succeeded but was unable to allocate memory for *addr. For BIO_accept(), the returned file descriptor is valid, and communication with the peer can be attempted using it.
BIO_R_NO_PORT_SPECIFIED "no port specified"
The servname argument was NULL in BIO_get_port(), or host_port was NULL or ended after the first colon in BIO_get_accept_socket().
BIO_R_NULL_PARAMETER "null parameter"
The addr argument was NULL in BIO_accept().
BIO_R_UNABLE_TO_BIND_SOCKET "unable to bind socket"
bind(2) failed in BIO_get_accept_socket().
BIO_R_UNABLE_TO_CREATE_SOCKET "unable to create socket"
socket(2) failed in BIO_get_accept_socket().
BIO_R_UNABLE_TO_LISTEN_SOCKET "unable to listen socket"
listen(2) failed in BIO_get_accept_socket().

HISTORY

BIO_sock_should_retry() first appeared in SSLeay 0.6.5 and the other functions except BIO_socket_nbio() in SSLeay 0.8.0. They have all been available since OpenBSD 2.4.

BIO_socket_nbio() first appeared in SSLeay 0.9.1 and has been available since OpenBSD 2.6.
