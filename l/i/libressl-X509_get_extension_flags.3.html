libressl-X509_get_extension_flags(3)

Paquete: libressl

Licencias: ISC, custom:OpenSSL

X509_GET_EXTENSION_FLAGS(3) Manual de Funciones de Biblioteca X509_GET_EXTENSION_FLAGS(3)

NOMBRE

X509_get_extension_flags, X509_get_key_usage, X509_get_extended_key_usage — recuperar datos de extensiones de certificados

SINOPSIS

biblioteca “libcrypto”
#include <openssl/x509v3.h>

uint32_t
X509_get_extension_flags(X509 *x);

uint32_t
X509_get_key_usage(X509 *x);

uint32_t
X509_get_extended_key_usage(X509 *x);

DESCRIPCIÓN

Estas funciones recuperan información relacionada con extensiones de certificados de uso común.

X509_get_extension_flags() recupera información general sobre un certificado. Devuelve uno o más de los siguientes indicadores ORados juntos.

EXFLAG_V1
El certificado es un certificado obsoleto versión 1.
EXFLAG_BCONS
El certificado contiene una extensión de restricciones básicas.
EXFLAG_CA
El certificado contiene restricciones básicas y afirma el indicador CA.
EXFLAG_PROXY
El certificado es un certificado proxy válido. En LibreSSL este indicador nunca se establece.
EXFLAG_SI
El certificado es auto-emitido (es decir, los nombres del sujeto y del emisor coinciden).
EXFLAG_SS
Los nombres del sujeto y del emisor coinciden y los valores de extensión implican que está auto-firmado.
EXFLAG_FRESHEST
La extensión CRL más reciente está presente en el certificado.
EXFLAG_CRITICAL
El certificado contiene una extensión crítica no manejada.
EXFLAG_INVALID
Algunos valores de extensión del certificado son inválidos o inconsistentes. El certificado debe ser rechazado. Este bit también puede activarse después de un error de falta de memoria al procesar el objeto X509, por lo que puede no estar relacionado con el objeto ASN1 procesado en sí.
EXFLAG_INVALID_POLICY
La extensión de certificado NID_certificate_policies es inválida o inconsistente. El certificado debe ser rechazado. Este bit también puede activarse después de un error de falta de memoria al procesar el objeto X509, por lo que puede no estar relacionado con el objeto ASN1 procesado en sí.
EXFLAG_KUSAGE
El certificado contiene una extensión de uso de clave. El valor se puede recuperar usando X509_get_key_usage().
EXFLAG_XKUSAGE
El certificado contiene una extensión de uso de clave extendido. El valor se puede recuperar usando X509_get_extended_key_usage().

X509_get_key_usage() devuelve el valor de la extensión de uso de clave. Si el uso de clave está presente, devuelve cero o más de los siguientes indicadores: KU_DIGITAL_SIGNATURE, KU_NON_REPUDIATION, KU_KEY_ENCIPHERMENT, KU_DATA_ENCIPHERMENT, KU_KEY_AGREEMENT, KU_KEY_CERT_SIGN, KU_CRL_SIGN, KU_ENCIPHER_ONLY, o KU_DECIPHER_ONLY, correspondientes a bits de uso de clave individuales. Si el uso de clave está ausente, se devuelve UINT32_MAX.

Los siguientes alias para estos indicadores están definidos en <openssl/x509.h>: X509v3_KU_DIGITAL_SIGNATURE, X509v3_KU_NON_REPUDIATION, X509v3_KU_KEY_ENCIPHERMENT, X509v3_KU_DATA_ENCIPHERMENT, X509v3_KU_KEY_AGREEMENT, X509v3_KU_KEY_CERT_SIGN, X509v3_KU_CRL_SIGN, X509v3_KU_ENCIPHER_ONLY, y X509v3_KU_DECIPHER_ONLY.

X509_get_extended_key_usage() devuelve el valor de la extensión de uso de clave extendido. Si el uso de clave extendido está presente, devuelve cero o más de los siguientes indicadores: XKU_SSL_SERVER, XKU_SSL_CLIENT, XKU_SMIME, XKU_CODE_SIGN XKU_OCSP_SIGN, XKU_TIMESTAMP, XKU_DVCS, o XKU_ANYEKU. Estos corresponden a los OID "id-kp-serverAuth", "id-kp-clientAuth", "id-kp-emailProtection", "id-kp-codeSigning", "id-kp-OCSPSigning", "id-kp-timeStamping", "id-kp-dvcs", y "anyExtendedKeyUsage", respectivamente. Adicionalmente, XKU_SGC se establece si están presentes los OID Netscape o Microsoft SGC.

El valor de los indicadores corresponde a valores de extensión que están cacheados en la estructura X509. Si los indicadores devueltos no proporcionan información suficiente, una aplicación debería examinar los valores de extensión directamente, por ejemplo, usando X509_get_ext_d2i(3).

Si la extensión de uso de clave o de uso de clave extendido está ausente, entonces típicamente el uso no está restringido. Por esta razón X509_get_key_usage() y X509_get_extended_key_usage() devuelven UINT32_MAX cuando la extensión correspondiente está ausente. Las aplicaciones pueden además verificar el valor de retorno de X509_get_extension_flags() y tomar la acción apropiada si una extensión está ausente.

VALORES DE RETORNO

X509_get_extension_flags(), X509_get_key_usage() y X509_get_extended_key_usage() devuelven conjuntos de indicadores correspondientes a los valores de extensión del certificado.
