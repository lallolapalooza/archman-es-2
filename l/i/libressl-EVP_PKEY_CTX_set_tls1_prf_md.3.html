libressl-EVP_PKEY_CTX_set_tls1_prf_md(3)

Paquete: libressl

Licencias: ISC, custom:OpenSSL

EVP_PKEY_CTX_SET_TLS1_PRF_MD(3) Manual de funciones de biblioteca EVP_PKEY_CTX_SET_TLS1_PRF_MD(3)

NOMBRE

EVP_PKEY_CTX_set_tls1_prf_md, EVP_PKEY_CTX_set1_tls1_prf_secret, EVP_PKEY_CTX_add1_tls1_prf_seed — algoritmo de derivación de claves PRF de TLS

SINOPSIS

biblioteca “libcrypto”
#include <openssl/evp.h>
#include <openssl/kdf.h>

int
EVP_PKEY_CTX_set_tls1_prf_md(EVP_PKEY_CTX *pctx, const EVP_MD *md);

int
EVP_PKEY_CTX_set1_tls1_prf_secret(EVP_PKEY_CTX *pctx, unsigned char *sec, int seclen);

int
EVP_PKEY_CTX_add1_tls1_prf_seed(EVP_PKEY_CTX *pctx, unsigned char *seed, int seedlen);

DESCRIPCIÓN

El algoritmo EVP_PKEY_TLS1_PRF implementa la función de derivación de claves PRF para TLS. No tiene una clave privada asociada y solo implementa la derivación de claves utilizando EVP_PKEY_derive(3).

EVP_PKEY_set_tls1_prf_md() establece el resumen de mensajes asociado con el PRF de TLS. EVP_md5_sha1(3) se trata como un caso especial que utiliza el algoritmo PRF con MD5 y SHA-1, como se usó en TLS 1.0 y 1.1.

EVP_PKEY_CTX_set_tls1_prf_secret() establece el valor secreto del PRF de TLS a seclen bytes del buffer sec. Cualquier valor secreto existente se reemplaza y cualquier semilla se restablece.

EVP_PKEY_CTX_add1_tls1_prf_seed() establece la semilla a seedlen bytes de seed. Si ya hay una semilla establecida, se adjunta al valor existente.

CTRLS DE CADENA

El PRF de TLS también admite operaciones de control basadas en cadenas utilizando EVP_PKEY_CTX_ctrl_str(3). El parámetro type "md" utiliza el value suministrado como el nombre del algoritmo de resumen a utilizar. Los parámetros type "secret" y "seed" utilizan el parámetro value suministrado como valor secreto o de semilla. Los nombres "hexsecret" y "hexseed" son similares excepto que toman una cadena hexadecimal que se convierte a binario.

NOTAS

Todas estas funciones están implementadas como macros.

Se puede obtener un contexto para el PRF de TLS llamando a:

EVP_PKEY_CTX *pctx = EVP_PKEY_CTX_new_id(EVP_PKEY_TLS1_PRF, NULL);

El resumen, el valor secreto y la semilla deben establecerse antes de derivar una clave o se producirá un error.

La longitud total de todas las semillas no puede exceder los 1024 bytes. Esto debería ser más que suficiente para cualquier uso normal del PRF de TLS.

La longitud de salida del PRF se especifica mediante el parámetro de longitud en la función EVP_PKEY_derive(3). Dado que la longitud de salida es variable, establecer el buffer en NULL no es significativo para el PRF de TLS.

VALORES DE RETORNO

Todas estas funciones devuelven 1 en caso de éxito y 0 o un valor negativo en caso de fallo. En particular, un valor de retorno de -2 indica que la operación no es compatible con el algoritmo de clave pública.

EJEMPLOS

Este ejemplo deriva 10 bytes usando SHA-256 con la clave secreta "secret" y el valor de semilla "seed":

EVP_PKEY_CTX *pctx;
unsigned char out[10];
size_t outlen = sizeof(out);

pctx = EVP_PKEY_CTX_new_id(EVP_PKEY_TLS1_PRF, NULL);
if (EVP_PKEY_derive_init(pctx) <= 0)
    /* Error */
if (EVP_PKEY_CTX_set_tls1_prf_md(pctx, EVP_sha256()) <= 0)
    /* Error */
if (EVP_PKEY_CTX_set1_tls1_prf_secret(pctx, "secret", 6) <= 0)
    /* Error */
if (EVP_PKEY_CTX_add1_tls1_prf_seed(pctx, "seed", 4) <= 0)
    /* Error */
if (EVP_PKEY_derive(pctx, out, &outlen) <= 0)
    /* Error */

VER TAMBIÉN

EVP_PKEY_CTX_ctrl_str(3), EVP_PKEY_CTX_new(3), EVP_PKEY_derive(3)
