DESCRIPCIÓN

Estas funciones proporcionan una interfaz de bajo nivel para ECDSA. La mayoría de las aplicaciones deberían usar la interfaz EVP de nivel superior, como EVP_DigestSignInit(3) o EVP_DigestVerifyInit(3) en su lugar. La creación de los objetos EC_KEY requeridos se describe en EC_KEY_new(3).

La estructura ECDSA_SIG consta de dos BIGNUMs para los valores r y s de una firma ECDSA (ver X9.62 o FIPS 186-2).

struct {
	BIGNUM *r;
	BIGNUM *s;
} ECDSA_SIG;

ECDSA_SIG_new() asigna una nueva estructura ECDSA_SIG (nota: esta función también asigna los BIGNUMs) y la inicializa.

ECDSA_SIG_free() libera la estructura ECDSA_SIG sig.

ECDSA_SIG_get0() recupera punteros internos a los valores r y s contenidos en sig. Los valores r y s también pueden recuperarse por separado mediante las funciones correspondientes ECDSA_SIG_get0_r() y ECDSA_SIG_get0_s(), respectivamente.

ECDSA_SIG_set0() establece los valores r y s en sig. Llamar a esta función transfiere la gestión de memoria de los valores a sig. Por lo tanto, los valores que se han pasado no deben ser liberados por el llamador.

i2d_ECDSA_SIG() crea la codificación DER de la firma ECDSA sig_in y escribe la firma codificada en *der_out. d2i_ECDSA_SIG() decodifica la firma codificada en DER almacenada en el buffer *der_in que tiene len bytes de longitud en *sig_out. Para obtener detalles sobre la semántica, ejemplos, advertencias y errores, consulte ASN1_item_d2i(3).

ECDSA_size() devuelve la longitud máxima de una firma ECDSA codificada en DER creada con la clave EC privada eckey.

ECDSA_sign() calcula una firma digital del valor hash dgst de dgstlen bytes utilizando la clave EC privada eckey. La firma codificada en DER se almacena en sig y su longitud se devuelve en siglen. Nota: sig debe apuntar a ECDSA_size() bytes de memoria. El parámetro type se ignora.

ECDSA_verify() verifica que la firma en sig de tamaño siglen es una firma ECDSA válida del valor hash dgst de tamaño dgstlen usando la clave pública eckey. El parámetro type se ignora.

ECDSA_do_sign() calcula una firma digital del valor hash dgst de dgst_len bytes utilizando la clave privada eckey. La firma se devuelve en una estructura ECDSA_SIG recién asignada (o NULL en caso de error).

ECDSA_do_verify() verifica que la firma sig es una firma ECDSA válida del valor hash dgst de tamaño dgst_len usando la clave pública eckey.

VALORES DE RETORNO

ECDSA_SIG_new() devuelve el nuevo objeto ECDSA_SIG o NULL si ocurre un error.

i2d_ECDSA_SIG() devuelve el número de bytes codificados con éxito o un valor negativo si ocurre un error.

d2i_ECDSA_SIG() devuelve un puntero a la estructura ECDSA_SIG decodificada o NULL si ocurre un error.

ECDSA_size() devuelve la longitud máxima de la firma o 0 en caso de error.

DESCRIPTION

\n

ECDSA_SIG_new() allocates and initializes a new ECDSA_SIG structure. It returns a pointer to the structure, or NULL on error.

\n

ECDSA_SIG_free() frees the structure sig.

\n

ECDSA_size() returns the maximum length of the DER encoded signature for the given EC_KEY eckey.

\n

ECDSA_sign() computes an ECDSA signature of the digest with dgstlen bytes using the EC key eckey. The signature is DER encoded and stored in sig. The maximum length of sig is specified by siglen and the actual length is written back to siglen. If type is 0, the signature is generated using the default method. Otherwise, type specifies the ECDSA method to be used.

\n

ECDSA_verify() verifies the ECDSA signature sig of length siglen for the digest with dgstlen bytes using the EC key eckey. If type is 0, the signature is verified using the default method. Otherwise, type specifies the ECDSA method to be used.

\n

ECDSA_do_sign() computes an ECDSA signature of the digest with dgstlen bytes using the EC key eckey. It returns a pointer to an allocated ECDSA_SIG structure, or NULL on error. The caller is responsible for freeing the returned structure with ECDSA_SIG_free().

\n

ECDSA_do_verify() verifies the ECDSA signature sig for the digest with dgstlen bytes using the EC key eckey. It returns 1 for a valid signature, 0 for an invalid signature, and -1 on error. The error codes can be obtained by ERR_get_error(3).

\n

ECDSA_SIG_get0() retrieves the r and s values of the signature sig by setting the BIGNUM pointers pr and ps to point to them. The returned pointers are owned by the ECDSA_SIG object and should not be freed.

\n

ECDSA_SIG_get0_r() and ECDSA_SIG_get0_s() return a pointer owned by the ECDSA_SIG object if it has been set or NULL otherwise.

\n

ECDSA_SIG_set0() and ECDSA_sign() return 1 if successful or 0 on error.

\n

ECDSA_do_sign() returns a pointer to an allocated ECDSA_SIG structure or NULL on error.

\n

ECDSA_verify() and ECDSA_do_verify() return 1 for a valid signature, 0 for an invalid signature and -1 on error. The error codes can be obtained by ERR_get_error(3).

Creating an ECDSA signature of given SHA-384 hash value using the named curve secp384r1.

\n

\n

\n
\n

Second step: compute the ECDSA signature of a SHA-384 hash value using ECDSA_do_sign()

\n
\n
sig = ECDSA_do_sign(digest, SHA384_DIGEST_LENGTH, eckey);\nif (sig == NULL) {\n\t/* error */\n}
\n
\n

or using ECDSA_sign()

\n
\n
unsigned char *buffer, *pp;\nint buf_len;\n\nbuf_len = ECDSA_size(eckey);\nbuffer  = malloc(buf_len);\npp = buffer;\nif (!ECDSA_sign(0, dgst, dgstlen, pp, &buf_len, eckey) {\n\t/* error */\n}
\n
\n

Third step: verify the created ECDSA signature using ECDSA_do_verify()

\n
ret = ECDSA_do_verify(digest,\n SHA384_DIGEST_LENGTH, sig, eckey);

ret = ECDSA_verify(0, digest,\n SHA384_DIGEST_LENGTH, buffer, buf_len, eckey);

if (ret == -1) {\n\t/* error */\n} else if (ret == 0) {\n\t/* incorrect signature */\n} else {\n\t/* ret == 1 */\n\t/* signature ok */\n}
