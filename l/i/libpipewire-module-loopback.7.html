NOMBRE

libpipewire-module-loopback - Loopback

DESCRIPCIÓN

El módulo loopback pasa la salida de un flujo de captura sin modificar a un flujo de reproducción.

Se puede utilizar para construir un enlace entre una fuente y un sumidero, pero también para crear nuevos sumideros o fuentes virtuales o para remapear canales entre flujos.

Dado que ambos extremos del loopback se construyen con flujos, el gestor de sesiones puede administrar la configuración y la conexión con los sumideros y fuentes.

NOMBRE DEL MÓDULO

libpipewire-module-loopback

OPCIONES DEL MÓDULO

  • node.description: un nombre legible por humanos para los flujos de loopback
  • target.delay.sec: retardo en segundos como flotante (Desde 0.3.60)
  • capture.props = {}: propiedades a pasar al flujo de entrada
  • playback.props = {}: propiedades a pasar al flujo de salida

OPCIONES GENERALES

Opciones con comportamiento bien conocido. La mayoría de las opciones se pueden agregar a la configuración global o a los flujos individuales:

  • remote.name
  • audio.rate
  • audio.channels
  • audio.position
  • media.name
  • node.latency
  • node.description
  • node.group
  • node.link.group
  • node.virtual
  • node.name : Ver notas abajo. Si no se especifica, por defecto será 'loopback-PID-MODULEID'.

Propiedades exclusivas del flujo:

  • media.class
  • node.name : si no se proporciona por flujo, el node.name global se prefijará con 'input.' y 'output.' para generar un nombre de flujo de captura y reproducción respectivamente.

MANEJO DE CANALES

Los canales del flujo de captura se copian, en orden, a los canales del flujo de salida. Los canales restantes se ignoran (cuando la captura tiene más canales) o se rellenan con silencio (cuando la reproducción tiene más canales).

Cuando se establece una posición de canal global, tanto la captura como la reproducción se convertirán desde y hacia esta disposición de canales común. Esto se puede utilizar para implementar sumideros/fuentes de loopback de submezcla (downmixing) o sobremezcla (upmixing).

EJEMPLO DE CONFIGURACIÓN DE ENLACE DE FUENTE A SUMIDERO

Este loopback enlaza un nodo fuente a un nodo sumidero. Puedes cambiar las propiedades de target.object para que coincidan con el nombre de tu nodo fuente/sumidero.

# ~/.config/pipewire/pipewire.conf.d/my-loopback-0.conf
context.modules = [
{   name = libpipewire-module-loopback
    args = {
        capture.props = {
            #  si quieres capturar puertos de monitorización de sumidero,
            #  descomenta la siguiente línea y establece target.object
            #  al nombre del sumidero.
            #stream.capture.sink = true
            target.object = "alsa_input.usb-C-Media_Electronics_Inc._TONOR_TC-777_Audio_Device-00.mono-fallback"
            node.passive = true
            node.dont-reconnect = true
        }
        playback.props = {
            target.object = "alsa_output.usb-0d8c_USB_Sound_Device-00.analog-surround-71"
            node.dont-reconnect = true
            node.passive = true
        }
    }
}
]

EJEMPLO DE CONFIGURACIÓN DE UN SUMIDERO VIRTUAL

Este sumidero virtual enruta la entrada estéreo a los canales traseros de un sumidero 7.1.

# ~/.config/pipewire/pipewire.conf.d/my-loopback-1.conf
context.modules = [
{   name = libpipewire-module-loopback
    args = {
        node.description = "Par Estéreo CM106 2"
        #target.delay.sec = 1.5
        capture.props = {
            node.name = "CM106_stereo_pair_2"
            media.class = "Audio/Sink"
            audio.position = [ FL FR ]
        }
        playback.props = {
            node.name = "playback.CM106_stereo_pair_2"
            audio.position = [ RL RR ]
            target.object = "alsa_output.usb-0d8c_USB_Sound_Device-00.analog-surround-71"
            node.dont-reconnect = true
            stream.dont-remix = true
            node.passive = true
        }
    }
}
]

EJEMPLO DE CONFIGURACIÓN DE UNA FUENTE VIRTUAL

Esta fuente virtual enruta el canal frontal izquierdo de una entrada multicanal a un canal mono. Esto es útil para separar entradas multicanal de interfaces de audio USB que aún no son totalmente compatibles con alsa.

# ~/.config/pipewire/pipewire.conf.d/my-loopback-2.conf
context.modules = [
{   name = libpipewire-module-loopback
    args = {
        node.description = "Focusrite Scarlett Line 1"
        capture.props = {
            audio.position = [ FL ]
            stream.dont-remix = true
            node.target = "alsa_input.usb-Focusrite_Scarlett_Solo_USB_Y7ZD17C24495BC-00.analog-stereo"
            node.passive = true
        }
        playback.props = {
            node.name = "SF_mono_in_1"
            media.class = "Audio/Source"
            audio.position = [ MONO ]
        }
    }
}
]

EJEMPLO DE CONFIGURACIÓN DE UN SUMIDERO DE SOBREMEZCLA

Este sumidero virtual tiene 2 canales de entrada y 6 canales de salida. Realizará una sobremezcla utilizando el algoritmo PSD en el flujo de reproducción.

# ~/.config/pipewire/pipewire.conf.d/my-loopback-3.conf
context.modules = [
{   name = libpipewire-module-loopback
    args = {
        node.description = "Sumidero de Sobremezcla"
        audio.position = [ FL FR ]
        capture.props = {
            node.name = "effect_input.upmix"
            media.class = Audio/Sink
        }
        playback.props = {
            node.name = "effect_output.upmix"
            audio.position = [ FL FR RL RR FC LFE ]
            node.passive = true
            stream.dont-remix = true
            channelmix.upmix = true
            channelmix.upmix-method = psd
            channelmix.lfe-cutoff = 150
            channelmix.fc-cutoff = 12000
            channelmix.rear-delay = 12.0
        }
    }
}
]

EJEMPLO DE CONFIGURACIÓN DE UNA FUENTE DE SUBMEZCLA

Esta fuente virtual tiene 2 canales de entrada y un canal de salida mono. Realizará una submezcla de los dos primeros canales AUX de un dispositivo pro-audio.

# ~/.config/pipewire/pipewire.conf.d/my-loopback-4.conf
context.modules = [
{   name = libpipewire-module-loopback
    args = {
        node.description = "Fuente de Submezcla"
        audio.position = [ AUX0 AUX1 ]
        capture.props = {
            node.name = "effect_input.downmix"
            target.object = "alsa_input.usb-BEHRINGER_UMC404HD_192k-00.pro-input-0"
            node.passive = true
            stream.dont-remix = true
        }
        playback.props = {
            node.name = "effect_output.downmix"
            media.class = Audio/Source
            audio.position = [ MONO ]
        }
    }
}
]
