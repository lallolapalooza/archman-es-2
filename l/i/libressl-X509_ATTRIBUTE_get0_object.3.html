libressl-X509_ATTRIBUTE_get0_object(3)

Paquete: libressl

Licencias: ISC, custom:OpenSSL

X509_ATTRIBUTE_GET0_OBJECT(3) Manual de Funciones de Biblioteca X509_ATTRIBUTE_GET0_OBJECT(3)

NOMBRE

X509_ATTRIBUTE_get0_object, X509_ATTRIBUTE_count, X509_ATTRIBUTE_get0_type, X509_ATTRIBUTE_get0_data — Acceso de lectura de atributos X.501

SINOPSIS

biblioteca “libcrypto”
#include <openssl/x509.h>

ASN1_OBJECT *
X509_ATTRIBUTE_get0_object(X509_ATTRIBUTE *attr);

int
X509_ATTRIBUTE_count(const X509_ATTRIBUTE *attr);

ASN1_TYPE *
X509_ATTRIBUTE_get0_type(X509_ATTRIBUTE *attr, int index);

void *
X509_ATTRIBUTE_get0_data(X509_ATTRIBUTE *attr, int index, int type, void *data);

DESCRIPCIÓN

Estas funciones proporcionan acceso de lectura al objeto de Atributo X.501 attr.

Para X509_ATTRIBUTE_get0_data, el argumento type suele ser una de las constantes V_ASN1_* definidas en <openssl/asn1.h>. Por ejemplo, si se espera un valor de retorno del tipo ASN1_OCTET_STRING, pase V_ASN1_OCTET_STRING como argumento type. El argumento data se ignora; se recomienda pasar NULL.

VALORES DE RETORNO

X509_ATTRIBUTE_get0_object() devuelve un puntero interno al tipo de attr o NULL si attr es NULL o si su tipo no está establecido.

X509_ATTRIBUTE_count() devuelve el número de valores almacenados en attr o 0 si no hay ningún valor o valores establecidos.

X509_ATTRIBUTE_get0_type() devuelve un puntero interno al objeto ASN.1 ANY que representa el valor con el index dado basado en cero o NULL si attr es NULL, si el index es mayor o igual que el número de valores almacenados en attr, o si no hay ningún valor o valores establecidos.

X509_ATTRIBUTE_get0_data() devuelve un puntero interno a los datos contenidos en el valor con el index dado basado en cero o NULL si attr es NULL, si el index es mayor o igual que el número de valores almacenados en attr, si no hay ningún valor o valores establecidos, o si el objeto ASN.1 ANY que representa el valor con el index dado no es del type solicitado.

VER TAMBIÉN

ASN1_OBJECT_new(3), ASN1_TYPE_new(3), OPENSSL_sk_new(3), X509_ATTRIBUTE_new(3), X509_ATTRIBUTE_set1_object(3)

HISTORIAL

Estas funciones aparecieron por primera vez en OpenSSL 0.9.5 y han estado disponibles desde OpenBSD 2.7.
