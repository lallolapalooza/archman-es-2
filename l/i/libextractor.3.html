DESCRIPCIÓN

GNU libextractor es una biblioteca sencilla para la extracción de palabras clave. libextractor no soporta todos los formatos pero soporta un mecanismo de plugins simple para que puedas añadir rápidamente extractores para formatos adicionales, incluso sin recompilar libextractor. libextractor típicamente incluye docenas de plugins que pueden ser usados para obtener metadatos de tipos de archivo comunes. Si quieres escribir tu propio plugin para algún tipo de archivo, todo lo que necesitas hacer es escribir una pequeña biblioteca que implemente un único método con esta firma:


void EXTRACTOR_XXX_extract_method (struct EXTRACTOR_ExtractContext *ec);

ec contiene punteros a funciones para leer, buscar, obtener el tamaño total del archivo y devolver metadatos. También hay un campo con opciones para el plugin. Los nuevos plugins serán localizados y usados automáticamente una vez que sean instalados en el directorio respectivo (típicamente algo como /usr/lib/libextractor/).

La aplicación extract da un ejemplo de cómo usar libextractor.

El uso básico de libextractor es cargar los plugins (por ejemplo con EXTRACTOR_plugin_add_defaults), luego extraer la lista de palabras clave usando EXTRACTOR_extract, y finalmente descargar los plugins (con EXTRACTOR_plugin_remove_all).

Se supone que los metadatos textuales obtenidos de libextractor están codificados en UTF-8 si la codificación del texto es conocida. Se supone que los plugins convierten los metadatos a UTF-8 si es necesario. La función EXTRACTOR_meta_data_print convierte las palabras clave UTF-8 al juego de caracteres de la localización actual antes de imprimirlas.
