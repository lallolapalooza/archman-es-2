NOMBRE

libipmimonitoring - una biblioteca para la monitorización de eventos y sensores del sistema IPMI

SINOPSIS

#include <ipmi_monitoring.h>

DESCRIPCIÓN

libipmimonitoring implementa una API de alto nivel para la monitorización de sensores y eventos del sistema. Para eventos del sistema, se proporciona una interfaz de iterador que permite al usuario recorrer eventos del sistema, tipos, estados y más. Para sensores, se proporciona una interfaz de iterador y de devolución de llamada que permite al usuario recorrer valores de sensores, tipos, unidades, estados y más.

Para mejorar la eficiencia, los datos SDR se almacenarán en caché en el host. Por defecto, se almacenan en caché en /var/cache/ipmimonitoringsdrcache.

Las reglas de interpretación para eventos del sistema y sensores se guían por la biblioteca de interpretación de libfreeipmi(3). La configuración de las reglas de interpretación se puede realizar a través de los archivos de configuración /etc/freeipmi//freeipmi_interpret_sel.conf y /etc/freeipmi//freeipmi_interpret_sensor.conf. Consulte freeipmi_interpret_sel.conf(5) y freeipmi_interpret_sensor.conf(5) para obtener más información sobre la configuración de las interpretaciones de sensores y eventos del sistema.
