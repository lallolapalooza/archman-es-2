SSL_GET_DEFAULT_TIMEOUT(3) Manual de funciones de biblioteca SSL_GET_DEFAULT_TIMEOUT(3)

NOMBRE

SSL_get_default_timeout — obtener el valor de tiempo de espera predeterminado de la sesión

SINAPSIS

biblioteca “libssl” libcrypto
#include <openssl/ssl.h>

long
SSL_get_default_timeout(const SSL *ssl);

DESCRIPCIÓN

SSL_get_default_timeout() devuelve el valor de tiempo de espera predeterminado asignado a los objetos SSL_SESSION negociados para el protocolo válido para ssl.

Cada vez que se negocia una nueva sesión, se le asigna un valor de tiempo de espera, después del cual no se aceptará para la reutilización de la sesión. Si el valor de tiempo de espera no se estableció explícitamente usando SSL_CTX_set_timeout(3), se utilizará el tiempo de espera predeterminado codificado para el protocolo.

SSL_get_default_timeout() devuelve este valor codificado, que es de 300 segundos para todos los protocolos actualmente compatibles (SSLv2, SSLv3 y TLSv1).

VER TAMBIÉN

ssl(3), SSL_CTX_flush_sessions(3), SSL_CTX_set_session_cache_mode(3), SSL_SESSION_get_time(3)

HISTORIA

SSL_get_default_timeout() apareció por primera vez en SSLeay 0.8.0 y ha estado disponible desde OpenBSD 2.4.
