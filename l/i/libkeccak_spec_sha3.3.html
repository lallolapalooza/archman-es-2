NOMBRE

libkeccak_spec_sha3 - Configurar parámetros de hash SHA-3

SINOPSIS

#include <libkeccak.h>
void libkeccak_spec_sha3(struct libkeccak_spec *spec, long int x);

Enlazar con -lkeccak.

DESCRIPCIÓN

La función libkeccak_spec_sha3() establece *spec para especificar los parámetros Keccak utilizados para el hash SHA-3 con el tamaño de salida especificado, en bits, a través del parámetro x.

VALORES DE RETORNO

La función libkeccak_spec_sha3() no devuelve ningún valor.

ERRORES

La función libkeccak_spec_sha3() no puede fallar.

EJEMPLO

Este ejemplo configura una struct libkeccak_spec para especificar los parámetros Keccak utilizados para SHA3-256:

struct libkeccak_spec spec;
libkeccak_spec_sha3(&spec, 256);
