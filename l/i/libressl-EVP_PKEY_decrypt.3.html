libressl-EVP_PKEY_decrypt(3)

Paquete: libressl

Licencias: ISC, custom:OpenSSL

EVP_PKEY_DECRYPT(3) Manual de funciones de biblioteca EVP_PKEY_DECRYPT(3)

NOMBRE

EVP_PKEY_decrypt_init, EVP_PKEY_decrypt — descifrar usando un algoritmo de clave pública

SINOPSIS

biblioteca “libcrypto”
#include <openssl/evp.h>

int
EVP_PKEY_decrypt_init(EVP_PKEY_CTX *ctx);

int
EVP_PKEY_decrypt(EVP_PKEY_CTX *ctx, unsigned char *out, size_t *outlen, const unsigned char *in, size_t inlen);

DESCRIPCIÓN

La función EVP_PKEY_decrypt_init() inicializa un contexto de algoritmo de clave pública usando la clave ctx->pkey para una operación de descifrado.

La función EVP_PKEY_decrypt() realiza una operación de descifrado de clave pública usando ctx. Los datos a descifrar se especifican mediante los parámetros in y inlen. Si out es NULL, entonces el tamaño máximo del búfer de salida se escribe en el parámetro outlen. Si out no es NULL, entonces antes de la llamada, el parámetro outlen debe contener la longitud del búfer out. Si la llamada tiene éxito, los datos descifrados se escriben en out y la cantidad de datos escritos en outlen.

Después de la llamada a EVP_PKEY_decrypt_init(), se pueden realizar operaciones de control específicas del algoritmo para establecer los parámetros apropiados para la operación.

La función EVP_PKEY_decrypt() puede llamarse más de una vez en el mismo contexto si se realizan varias operaciones usando los mismos parámetros.

VALORES DE RETORNO

EVP_PKEY_decrypt_init() y EVP_PKEY_decrypt() devuelven 1 en caso de éxito y 0 o un valor negativo en caso de fallo. En particular, un valor de retorno de -2 indica que la operación no es compatible con el algoritmo de clave pública.

EJEMPLOS

Descifrar datos usando OAEP (para claves RSA):

#include <openssl/evp.h>
#include <openssl/rsa.h>

EVP_PKEY_CTX *ctx;
unsigned char *out, *in;
size_t outlen, inlen;
EVP_PKEY *key;

/*
 * Se asume que key, in e inlen ya están configurados
 * y que key es una clave privada RSA.
 */
ctx = EVP_PKEY_CTX_new(key, NULL);
if (!ctx)
	/* Ocurrió un error */
if (EVP_PKEY_decrypt_init(ctx) <= 0)
	/* Error */
if (EVP_PKEY_CTX_set_rsa_padding(ctx, RSA_PKCS1_OAEP_PADDING) <= 0)
	/* Error */

/* Determinar la longitud del búfer */
if (EVP_PKEY_decrypt(ctx, NULL, &outlen, in, inlen) <= 0)
	/* Error */

out = malloc(outlen);

if (!out)
	/* Fallo de malloc */

if (EVP_PKEY_decrypt(ctx, out, &outlen, in, inlen) <= 0)
	/* Error */

/* Los datos descifrados son outlen bytes escritos en el búfer out */

VER TAMBIÉN
