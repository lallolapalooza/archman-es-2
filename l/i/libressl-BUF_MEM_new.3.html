BUF_MEM_NEW(3) Manual de funciones de la biblioteca BUF_MEM_NEW(3)

NOMBRE

BUF_MEM_new, BUF_MEM_free, BUF_MEM_grow, BUF_MEM_grow_clean — estructura simple de arreglos de caracteres

SINOPSIS

biblioteca “libcrypto”
#include <openssl/buffer.h>

BUF_MEM *
BUF_MEM_new(void);

void
BUF_MEM_free(BUF_MEM *a);

int
BUF_MEM_grow(BUF_MEM *str, size_t len);

int
BUF_MEM_grow_clean(BUF_MEM *str, size_t len);

DESCRIPCIÓN

La biblioteca de búfer maneja arreglos de caracteres simples. Los búferes se utilizan para diversos propósitos en la biblioteca, en particular los BIO de memoria.

La biblioteca utiliza la estructura BUF_MEM definida en buffer.h:

typedef struct buf_mem_st {
	size_t length;	/* número actual de bytes */
	char *data;
	size_t max;	/* tamaño del búfer */
} BUF_MEM;

length es el tamaño actual del búfer en bytes; max es la cantidad de memoria asignada al búfer. Hay tres funciones que manejan estos y una función miscelánea.

BUF_MEM_new() asigna un nuevo búfer de tamaño cero.

BUF_MEM_free() libera un búfer ya existente. Los datos se ponen a cero antes de liberarlos en caso de que el búfer contenga datos sensibles. Si a es un puntero NULL, no se realiza ninguna acción.

BUF_MEM_grow() cambia el tamaño de un búfer ya existente a len. Cualquier dato que ya esté en el búfer se conserva si aumenta de tamaño.

BUF_MEM_grow_clean() es similar a BUF_MEM_grow(), pero establece a cero cualquier memoria liberada o asignada adicionalmente.

VALORES DE RETORNO

BUF_MEM_new() devuelve el búfer o NULL en caso de error.

BUF_MEM_grow() y BUF_MEM_grow_clean() devuelven cero en caso de error o el nuevo tamaño (es decir, len).

VER TAMBIÉN

BIO_new(3), BIO_s_mem(3)

HISTORIA

BUF_MEM_new(), BUF_MEM_free() y BUF_MEM_grow() aparecieron por primera vez en SSLeay 0.6.0. Todas estas funciones han estado disponibles desde OpenBSD 2.4.

BUF_MEM_grow_clean() apareció por primera vez en OpenSSL 0.9.7 y ha estado disponible desde OpenBSD 3.2.
