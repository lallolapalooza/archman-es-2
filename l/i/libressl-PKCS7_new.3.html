DESCRIPCIÓN

PKCS#7 es un formato basado en ASN.1 para transmitir datos a los que se les ha aplicado criptografía, en particular datos firmados y cifrados.

PKCS7_new() asigna e inicializa un objeto PKCS7 vacío, representando una estructura ASN.1 ContentInfo definida en la RFC 2315, sección 7. Es la estructura de datos de nivel superior capaz de contener cualquier tipo de contenido que se pueda transmitir usando PKCS#7. Se puede utilizar de forma recursiva en objetos PKCS7_SIGNED y PKCS7_DIGEST. PKCS7_free() libera p7.

PKCS7_SIGNED_new() asigna e inicializa un objeto PKCS7_SIGNED vacío, representando una estructura ASN.1 SignedData definida en la RFC 2315, sección 9. Se puede utilizar dentro de objetos PKCS7 y contiene cualquier tipo de contenido junto con firmas de cero o más firmantes e información sobre el algoritmo de firma y los certificados utilizados. PKCS7_SIGNED_free() libera signed.

PKCS7_ENVELOPE_new() asigna e inicializa un objeto PKCS7_ENVELOPE vacío, representando una estructura ASN.1 EnvelopedData definida en la RFC 2315, sección 10. Se puede utilizar dentro de objetos PKCS7 y contiene cualquier tipo de contenido cifrado junto con claves de cifrado de contenido para uno o más destinatarios. PKCS7_ENVELOPE_free() libera envelope.

PKCS7_SIGN_ENVELOPE_new() asigna e inicializa un objeto PKCS7_SIGN_ENVELOPE vacío, representando una estructura ASN.1 SignedAndEnvelopedData definida en la RFC 2315, sección 11. Se puede utilizar dentro de objetos PKCS7 y contiene cualquier tipo de contenido cifrado junto con firmas de uno o más firmantes, información sobre el algoritmo de firma y los certificados utilizados, y claves de cifrado de contenido para uno o más destinatarios. PKCS7_SIGN_ENVELOPE_free() libera signed_envelope.

PKCS7_DIGEST_new() asigna e inicializa un objeto PKCS7_DIGEST vacío, representando una estructura ASN.1 DigestedData definida en la RFC 2315, sección 12. Se puede utilizar dentro de objetos PKCS7 y contiene cualquier tipo de contenido junto con un resumen del mensaje para verificar su integridad e información sobre el algoritmo utilizado. PKCS7_DIGEST_free() libera digested.

PKCS7_ENCRYPT_new() asigna e inicializa un objeto PKCS7_ENCRYPT vacío, representando una estructura ASN.1 EncryptedData definida en la RFC 2315, sección 13. Se puede utilizar dentro de objetos PKCS7 y contiene cualquier tipo de contenido cifrado. Las claves no se incluyen y deben comunicarse por separado. PKCS7_ENCRYPT_free() libera encrypted.

PKCS7_ENC_CONTENT_new() asigna e inicializa un objeto PKCS7_ENC_CONTENT vacío, representando una estructura ASN.1 EncryptedContentInfo definida en la RFC 2315, sección 10.1. Se puede utilizar dentro de PKCS7_ENVELOPE, PKCS7_SIGN_ENVELOPE

DESCRIPTION

PKCS7_new() and PKCS7_free() allocate and free a PKCS7 object respectively.

PKCS7_encrypt() creates a new PKCS#7 structure of type PKCS7_ENCRYPTED (also known as PKCS7_ENVELOPED) for the content in in. The content is encrypted using the cipher specified by cipher. The resulting content-encryption key is then encrypted for each recipient specified in the recips stack. The flags parameter can be used to control the behaviour of the function. Currently, only PKCS7_TEXT is supported which requests that any text attributes be processed.

PKCS7_decrypt() attempts to decrypt the content of p7. If recips is specified, it is used to find the correct recipient info. Otherwise, the supplied recipient certificate recip_cert and private key recip_pkey are used. The flags parameter can be used to control the behaviour of the function. Currently, only PKCS7_TEXT is supported which requests that any text attributes be processed.

PKCS7_sign() creates a new PKCS#7 structure of type PKCS7_SIGNED for the content in in. The structure is signed using the signer's certificate signcert and private key pkey. The stack of certificates certs is included in the structure. The flags parameter can be used to control the behaviour of the function. Currently, only PKCS7_TEXT is supported which requests that any text attributes be processed.

PKCS7_verify() verifies the signature of the PKCS#7 structure p7. If certs is specified, it is used to find the signer's certificate. Otherwise, the certificates are searched for in the PKCS7_Certificates field of p7. The store is used to verify the signer's certificate. The original content is read from in and the verified content is written to out. The flags parameter can be used to control the behaviour of the function. Currently, only PKCS7_TEXT is supported which requests that any text attributes be processed.

PKCS7_add_attribute(), PKCS7_add_certificate(), PKCS7_add_crl(), PKCS7_add_signer(), PKCS7_add_recipient(), PKCS7_add_signature(), PKCS7_add_otherTypeAttribute(), PKCS7_add_identity(), and PKCS7_add_NULL() are utility functions to add various components to a PKCS7 structure.

PKCS7_set_content() sets the content of the PKCS7 structure p7 to content. The type parameter can be one of PKCS7_TEXT, PKCS7_ENCRYPTED, PKCS7_SIGNED, or PKCS7_DIGESTS.

PKCS7_set_type() sets the type of the PKCS7 structure p7.

PKCS7_type_is_other(), PKCS7_type_is_data(), PKCS7_type_is_digests(), PKCS7_type_is_encrypted(), PKCS7_type_is_enveloped(), PKCS7_type_is_signed(), PKCS7_type_is_signature(), and PKCS7_type_is_smime() return true if the PKCS7 structure p7 is of the indicated type.

PKCS7_get_attr() and PKCS7_get_attribute() return the attributes from the PKCS7 structure.

PKCS7_get_signature() and PKCS7_get_content() return the signature and content from the PKCS7 structure, respectively.

PKCS7_get_recip_info() and PKCS7_get_signer_info() return the recipient and signer information at index idx from the PKCS7 structure, respectively.

PKCS7_get_certificate() and PKCS7_get_crl() return the stack of certificates and certificate revocation lists from the PKCS7 structure, respectively.

PKCS7_get_digest() returns the digests from the PKCS7 structure.

PKCS7_get_message() returns a BIO containing the DER encoded PKCS#7 message.

PKCS7_get_decoded_content() returns a BIO containing the decoded content of the PKCS#7 structure.

PKCS7_final() finalizes a PKCS#7 message after the content has been added.

PKCS7_dataInit(), PKCS7_dataAppend(), and PKCS7_dataFinal() are used to stream PKCS#7 data.

PKCS7_stream() processes a PKCS#7 message in a streaming fashion.

PKCS7_RECIP_INFO_new() allocates and initializes an empty PKCS7_RECIP_INFO object. PKCS7_RECIP_INFO_free() frees recip.

PKCS7_SIGNER_INFO_new() allocates and initializes an empty PKCS7_SIGNER_INFO object. PKCS7_SIGNER_INFO_free() frees signer.

PKCS7_ISSUER_AND_SERIAL_new() allocates and initializes an empty PKCS7_ISSUER_AND_SERIAL object. PKCS7_ISSUER_AND_SERIAL_free() frees cert.

PKCS7_ENC_CONTENT_new() allocates and initializes an empty PKCS7_ENC_CONTENT object. PKCS7_ENC_CONTENT_free() frees content.

PKCS7_ATTR_free() frees an X509_ATTRIBUTE object.

PKCS7_SIGNER_INFO_set_issuer() sets the issuer of the PKCS7_SIGNER_INFO object si to the issuer of the certificate x509.

PKCS7_SIGNER_INFO_set_serial() sets the serial number of the PKCS7_SIGNER_INFO object si to serial.

PKCS7_SIGNER_INFO_set_authname() sets the authenticated attribute name of the PKCS7_SIGNER_INFO object si to name.

PKCS7_SIGNER_INFO_set_authattr() sets the authenticated attributes of the PKCS7_SIGNER_INFO object si to attrs.

PKCS7_SIGNER_INFO_set_cipher() sets the content encryption cipher of the PKCS7_SIGNER_INFO object si to cipher.

PKCS7_SIGNER_INFO_set_digest() sets the digest algorithm of the PKCS7_SIGNER_INFO object si to digest.

PKCS7_RECIP_INFO_set_issuer() sets the issuer of the PKCS7_RECIP_INFO object ri to the issuer of the certificate x509.

PKCS7_RECIP_INFO_set_serial() sets the serial number of the PKCS7_RECIP_INFO object ri to serial.

PKCS7_RECIP_INFO_set_rid() sets the recipient identifier of the PKCS7_RECIP_INFO object ri to issuer and serial.

PKCS7_RECIP_INFO_set_keytype() sets the key type of the PKCS7_RECIP_INFO object ri to keytype.

PKCS7_RECIP_INFO_set_key() sets the encrypted content encryption key of the PKCS7_RECIP_INFO object ri to key of length keylen.

PKCS7_RECIP_INFO_set_protected() sets the protected attributes of the PKCS7_RECIP_INFO object ri to protected_attrs.

PKCS7_RECIP_INFO_set_unprotected() sets the unprotected attributes of the PKCS7_RECIP_INFO object ri to unprotected_attrs.

PKCS7_ISSUER_AND_SERIAL_set_issuer() sets the issuer of the PKCS7_ISSUER_AND_SERIAL object ias to the issuer of the certificate x509.

PKCS7_ISSUER_AND_SERIAL_set_serial() sets the serial number of the PKCS7_ISSUER_AND_SERIAL object ias to serial.

PKCS7_ISSUER_AND_SERIAL_copy() creates a copy of the PKCS7_ISSUER_AND_SERIAL object ias.

PKCS7_ISSUER_AND_SERIAL_digest() computes the digest of the PKCS7_ISSUER_AND_SERIAL object ias using the algorithm specified by type. The digest is stored in md and its length is stored in len.

PKCS7_ENC_CONTENT_set_type() sets the type of the encrypted content in PKCS7_ENC_CONTENT object ec.

PKCS7_ENC_CONTENT_set_value() sets the encrypted content value in PKCS7_ENC_CONTENT object ec to value.

PKCS7_ENC_CONTENT_set_encoding() sets the encoding of the encrypted content in PKCS7_ENC_CONTENT object ec.

PKCS7_ENC_CONTENT_get_type() returns the type of the encrypted content in PKCS7_ENC_CONTENT object ec.

PKCS7_ENC_CONTENT_get_value() returns the encrypted content value from PKCS7_ENC_CONTENT object ec.

PKCS7_ENC_CONTENT_get_encoding() returns the encoding of the encrypted content in PKCS7_ENC_CONTENT object ec.

PKCS7_ENC_CONTENT_new() allocates and initializes an empty PKCS7_ENC_CONTENT object and holds encrypted content together with information about the encryption algorithm used. PKCS7_ENC_CONTENT_free() frees content.

PKCS7_SIGNER_INFO_new() allocates and initializes an empty PKCS7_SIGNER_INFO object, representing an ASN.1 SignerInfo structure defined in RFC 2315 section 9.2. It can be used inside PKCS7_SIGNED and PKCS7_SIGN_ENVELOPE objects and holds a signature together with information about the signer and the algorithms used. PKCS7_SIGNER_INFO_free() frees signer.

PKCS7_RECIP_INFO_new() allocates and initializes an empty PKCS7_RECIP_INFO object, representing an ASN.1 RecipientInfo structure defined in RFC 2315 section 10.2. It can be used inside PKCS7_ENVELOPE and PKCS7_SIGN_ENVELOPE objects and holds a content-encryption key together with information about the intended recipient and the key encryption algorithm used. PKCS7_RECIP_INFO_free() frees recip.

PKCS7_ISSUER_AND_SERIAL_new() allocates and initializes an empty PKCS7_ISSUER_AND_SERIAL object, representing an ASN.1 IssuerAndSerialNumber structure defined in RFC 2315 section 6.7. It can be used inside PKCS7_SIGNER_INFO and PKCS7_RECIP_INFO objects and identifies a certificate by holding the distinguished name of the certificate issuer and an issuer-specific certificate serial number. PKCS7_ISSUER_AND_SERIAL_free() frees cert.
