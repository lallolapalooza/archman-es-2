NOMBRE

libpipewire-module-snapcast-discover - Descubrimiento de Snapcast

DESCRIPCIÓN

Crea automáticamente un dispositivo de salida Snapcast basado en información de zeroconf.

Este módulo cargará el módulo-protocol-simple para cada stream anunciado que coincida con la regla con la acción create-stream y pasará las propiedades al módulo.

Si no se proporcionan stream.rules, creará una salida para todos los servidores snapcast anunciados.

Se creará un nuevo stream en el servidor snapcast con el nombre de stream snapcast.stream-name o PipeWire-<hostname> dado. Deberá enrutar este nuevo stream a los clientes con la aplicación de control de snapcast.

NOMBRE DEL MÓDULO

libpipewire-module-snapcast-discover

OPCIONES DEL MÓDULO

Opciones específicas del comportamiento de este módulo

  • snapcast.discover-local = permite el descubrimiento de servicios locales también. false por defecto.
  • stream.rules = <reglas>: reglas de coincidencia, usa acciones create-stream. Ver Protocol Simple para propiedades del módulo.

Coincidencias de stream.rules

  • snapcast.ip: la dirección IP del servidor snapcast
  • snapcast.port: el puerto del servidor snapcast
  • snapcast.ifindex: el índice de la interfaz donde se recibió el anuncio de snapcast.
  • snapcast.ifname: el nombre de la interfaz donde se recibió el anuncio de snapcast.
  • snapcast.name: el nombre del servidor snapcast
  • snapcast.hostname: el nombre de host del servidor snapcast
  • snapcast.domain: el dominio del servidor snapcast

create-stream de stream.rules

Además de todas las propiedades que se pueden pasar a Protocol Simple, también puedes establecer:

  • snapcast.stream-name: El nombre del stream en un servidor snapcast.
  • node.name: El nombre de la salida que se crea en el emisor.

EJEMPLO DE CONFIGURACIÓN

# ~/.config/pipewire/pipewire.conf.d/my-snapcast-discover.conf
context.modules = [
{   name = libpipewire-module-snapcast-discover
    args = {
        stream.rules = [
            {   matches = [
                    {    snapcast.ip = "~.*"
                         #snapcast.port = 1000
                         #snapcast.ifindex = 1
                         #snapcast.ifname = eth0
                         #snapcast.name = ""
                         #snapcast.hostname = ""
                         #snapcast.domain = ""
                    }
                ]
                actions = {
                    create-stream = {
                        #audio.rate = 44100
                        #audio.format = S16LE   # S16LE, S24_32LE, S32LE
                        #audio.channels = 2
                        #audio.position = [ FL FR ]
                        #
                        # El nombre del stream tal como aparece en
                        # el servidor snapcast:
                        #snapcast.stream-name = "PipeWire"
                        #
                        # El nombre de la salida en el emisor:
                        #node.name = "Snapcast Sink"
                        #
                        #capture = true
                        #server.address = [ "tcp:4711" ]
                        #capture.props = {
                            #target.object = ""
                            #node.latency = 2048/48000
                            #media.class = "Audio/Sink"
                        #}
                    }
                }
            }
        ]
    }
}
]
