NOMBRE

libavdevice - biblioteca de manejo de dispositivos multimedia

DESCRIPCIÓN

La biblioteca libavdevice proporciona un marco genérico para capturar desde y renderizar a muchos dispositivos comunes de entrada/salida multimedia, y soporta varios dispositivos de entrada y salida, incluyendo Video4Linux2, VfW, DShow y ALSA.

VER TAMBIÉN

ffmpeg(1), ffplay(1), ffprobe(1), ffmpeg-devices(1), libavutil(3), libavcodec(3), libavformat(3)

AUTORES

Los desarrolladores de FFmpeg.

Para detalles sobre la autoría, ver el historial de Git del proyecto (https://git.ffmpeg.org/ffmpeg), por ejemplo, escribiendo el comando git log en el directorio fuente de FFmpeg, o navegando el repositorio en línea en https://git.ffmpeg.org/ffmpeg.

Los mantenedores de los componentes específicos se listan en el archivo MAINTAINERS en el árbol de código fuente.
