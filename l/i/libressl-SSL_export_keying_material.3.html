libressl-SSL_export_keying_material(3)

Paquete: libressl

Licencias: ISC, custom:OpenSSL

SSL_EXPORT_KEYING_MATERIAL(3) Manual de funciones de biblioteca SSL_EXPORT_KEYING_MATERIAL(3)

NOMBRE

SSL_export_keying_material — obtener material de clave para uso de la aplicación

SINOPSIS

biblioteca “libssl” libcrypto
#include <openssl/ssl.h>

int
SSL_export_keying_material(SSL *s, unsigned char *out, size_t olen, const char *label, size_t llen, const unsigned char *context, size_t contextlen, int use_context);

DESCRIPCIÓN

Durante la creación de una conexión TLS o DTLS, se establece material de clave compartido entre los dos extremos. La función SSL_export_keying_material() permite a una aplicación utilizar parte de este material de clave para sus propios fines de acuerdo con RFC 5705.

Una aplicación puede necesitar establecer de forma segura el contexto dentro del cual se utilizará este material de clave. Por ejemplo, esto puede incluir identificadores para la sesión de la aplicación, algoritmos o parámetros de la aplicación, o la vida útil del contexto. El valor del contexto se deja a la aplicación, pero debe ser el mismo en ambos lados de la comunicación.

Para una conexión SSL dada s, se escribirán olen bytes de datos en out. El contexto específico de la aplicación debe proporcionarse en la ubicación apuntada por context y debe tener contextlen bytes de longitud. La provisión de un contexto es opcional. Si el contexto debe omitirse por completo, entonces use_context debe establecerse en 0. De lo contrario, debe ser cualquier otro valor. Si use_context es 0, entonces los valores de context y contextlen se ignoran.

En TLSv1.2 y versiones inferiores, un contexto de longitud cero se trata de manera diferente a la ausencia de contexto, y dará como resultado un material de clave diferente que se devolverá.

Se debe proporcionar una etiqueta específica de la aplicación en la ubicación apuntada por label y debe tener llen bytes de longitud. Típicamente, este será un valor del Registro de etiquetas exportadoras de la IANA.

Alternativamente, las etiquetas que comienzan con "EXPERIMENTAL" están permitidas por el estándar para ser utilizadas sin registro.

VALORES DE RETORNO

SSL_export_keying_material() devuelve 1 en caso de éxito o 0 o -1 en caso de error.

VER TAMBIÉN

ssl(3)

HISTORIA
