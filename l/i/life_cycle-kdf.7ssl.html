NOMBRE

life_cycle-kdf - El ciclo de vida del algoritmo KDF

DESCRIPCIÓN

Todas las funciones de derivación de claves (KDFs) y funciones pseudoaleatorias (PRFs) pasan por una serie de etapas en su ciclo de vida:

inicio
Este estado representa la KDF/PRF antes de haber sido asignada. Es el estado inicial para cualquier transición de ciclo de vida.
creada
Este estado representa la KDF/PRF después de haber sido asignada.
derivando
Este estado representa la KDF/PRF cuando está configurada y es capaz de generar salida.
liberada
Se entra en este estado cuando la KDF/PRF es liberada. Es el estado terminal para todas las transiciones de ciclo de vida.

Diagrama de Transición de Estados

El ciclo de vida habitual de una KDF/PRF se ilustra:
+-------------------+
| inicio |
+-------------------+
|
| EVP_KDF_CTX_new
v
+-------------------+
| creada | <+
+-------------------+ |
| |
| EVP_KDF_derive |
v | EVP_KDF_CTX_reset
EVP_KDF_derive +-------------------+ |
+ - - - - - - - - | | |
' | derivando | |
+ - - - - - - - -> | | -+
+-------------------+
|
| EVP_KDF_CTX_free
v
+-------------------+
| liberada |
+-------------------+

Transiciones Formales de Estado

Esta sección define todas las transiciones de estado legales. Esta es la lista canónica.
Llamada a Función ------------- Estado Actual -------------
inicio creada derivando liberada
EVP_KDF_CTX_new creada
EVP_KDF_derive derivando derivando
EVP_KDF_CTX_free liberada liberada liberada
EVP_KDF_CTX_reset creada creada
EVP_KDF_CTX_get_params creada derivando
EVP_KDF_CTX_set_params creada derivando
EVP_KDF_CTX_gettable_params creada derivando
EVP_KDF_CTX_settable_params creada derivando

NOTAS

En algún momento, la capa EVP comenzará a hacer cumplir las transiciones descritas aquí.

HISTORIAL
