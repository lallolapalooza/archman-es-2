Funciones para registrar usando libalpm

Documentación de alias de tipos

typedef void(* alpm_cb_log) (void *ctx, alpm_loglevel_t level, const char *fmt, va_list args)

El tipo de callback para registrar. libalpm llamará a esta función cada vez que algo deba ser registrado. muchas libalpm producirán salida de registro. Además, todas las llamadas a alpm_logaction también llamarán a este callback.

Parámetros

ctx contexto proporcionado por el usuario
level el loglevel actualmente establecido
fmt la cadena de formato similar a printf
args argumentos similares a printf

Enumerador

Error.
ALPM_LOG_WARNING
Advertencia.
ALPM_LOG_DEBUG
Depuración.
ALPM_LOG_FUNCTION
Función.

Documentación de funciones

int alpm_logaction (alpm_handle_t * handle, const char * prefix, const char * fmt, ...)

Una función similar a printf para registrar.

Parámetros

handle el manejador de contexto
prefix prefijo específico del llamador para el registro
fmt formato de salida

Devoluciones

0 en caso de éxito, -1 en caso de error (pm_errno se establece en consecuencia)
