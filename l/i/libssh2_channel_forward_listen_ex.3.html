libssh2_channel_forward_listen_ex(3)

Paquete: libssh2

Licencias: BSD

libssh2_channel_forward_listen_ex(3) libssh2 libssh2_channel_forward_listen_ex(3)

NOMBRE

libssh2_channel_forward_listen_ex - escuchar conexiones entrantes

SINOPSIS

#include <libssh2.h>
LIBSSH2_LISTENER *
libssh2_channel_forward_listen_ex(LIBSSH2_SESSION *session,
                                  char *host, int port,
                                  int *bound_port, int queue_maxsize);
LIBSSH2_LISTENER *
libssh2_channel_forward_listen(LIBSSH2_SESSION *session, int port);

DESCRIPCIÓN

Instruye al servidor SSH remoto para que comience a escuchar las conexiones TCP/IP entrantes. Las nuevas conexiones serán puestas en cola por la biblioteca hasta que sean aceptadas por libssh2_channel_forward_accept(3).

session - instancia devuelta por libssh2_session_init().

host - dirección específica a la que vincular en el host remoto. Vincular a 0.0.0.0 (valor predeterminado cuando se pasa NULL) vinculará a todas las direcciones disponibles.

port - puerto al que vincular en el host remoto. Cuando se pasa 0, el host remoto seleccionará el primer puerto dinámico disponible.

bound_port - Se pobla con el puerto real vinculado en el host remoto. Útil al solicitar números de puerto dinámicos.

queue_maxsize - Número máximo de conexiones pendientes que se pondrán en cola antes de rechazar nuevos intentos.

libssh2_channel_forward_listen(3) es una macro.

VALOR DE RETORNO

Una instancia LIBSSH2_LISTENER recién asignada o NULL en caso de fallo.

ERRORES

LIBSSH2_ERROR_ALLOC - falló una llamada interna de asignación de memoria.

LIBSSH2_ERROR_SOCKET_SEND - No se pudieron enviar datos en el socket.

LIBSSH2_ERROR_PROTO - Se recibió una respuesta de protocolo SSH inválida en el socket.

LIBSSH2_ERROR_REQUEST_DENIED - El servidor remoto rechazó la solicitud.

LIBSSH2_ERROR_EAGAIN - Marcado para E/S no bloqueante, pero la llamada bloquearía.

VER TAMBIÉN
