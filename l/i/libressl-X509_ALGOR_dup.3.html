X509_ALGOR_DUP(3) Manual de funciones de biblioteca X509_ALGOR_DUP(3)

NOMBRE

X509_ALGOR_new, X509_ALGOR_free, X509_ALGOR_dup, X509_ALGOR_set0, X509_ALGOR_get0, X509_ALGOR_cmp — crear, cambiar e inspeccionar identificadores de algoritmo

SINOPSIS

biblioteca “libcrypto”
#include <openssl/x509.h>

X509_ALGOR *
X509_ALGOR_new(void);

void
X509_ALGOR_free(X509_ALGOR *alg);

X509_ALGOR *
X509_ALGOR_dup(X509_ALGOR *alg);

int
X509_ALGOR_set0(X509_ALGOR *alg, ASN1_OBJECT *aobj, int ptype, void *pval);

void
X509_ALGOR_get0(const ASN1_OBJECT **paobj, int *pptype, const void **ppval, const X509_ALGOR *alg);

int
X509_ALGOR_cmp(const X509_ALGOR *a, const X509_ALGOR *b);

DESCRIPCIÓN

Un objeto X509_ALGOR representa una estructura ASN.1 AlgorithmIdentifier definida en la sección 4.1.1.2 de RFC 5280. Especifica un algoritmo criptográfico mediante un identificador de objeto ASN.1 (OID) que se puede obtener de OBJ_nid2obj(3), junto con parámetros opcionales específicos del algoritmo (parámetros) del tipo ASN1_TYPE, ver ASN1_TYPE_set(3). Los objetos X509_ALGOR son utilizados por muchos otros objetos, por ejemplo, certificados, listas de revocación de certificados y solicitudes de certificados.

X509_ALGOR_new() asigna un nuevo objeto X509_ALGOR que contiene el objeto que OBJ_nid2obj(3) devuelve para NID_undef como el algoritmo y un puntero NULL como los parámetros.

X509_ALGOR_free() libera alg y todos los datos contenidos en él. Si alg es NULL, no se realiza ninguna acción.

X509_ALGOR_dup() crea una copia profunda de alg. Se implementa llamando a ASN1_item_dup(3) con argumentos de X509_ALGOR_it y alg, lo que equivale a llamar a i2d_X509_ALGOR(3) y d2i_X509_ALGOR(3).

X509_ALGOR_set0() establece el OID del algoritmo de alg a aobj y el tipo de parámetro asociado a ptype con el valor pval. Si ptype es V_ASN1_UNDEF, el parámetro se omite y se ignora pval. Si ptype es cero, se ignora pval y se deja sin cambios el parámetro existente, o si alg no contiene un parámetro, se agrega un nuevo parámetro vacío de tipo V_ASN1_UNDEF. De lo contrario, ptype y pval tienen el mismo significado que los parámetros type y value de ASN1_TYPE_set(3). La propiedad de aobj y, a menos que se ignore, de pval se transfiere a alg en caso de éxito.

X509_ALGOR_get0() devuelve el OID del algoritmo de alg en *paobj, su tipo de parámetro en *pptype y su valor de parámetro en *ppval. Cualquiera de paobj, pptype y ppval puede ser NULL. Si pptype es NULL o si *pptype es V_ASN1_UNDEF, entonces el valor de *ppval no está definido.

X509_ALGOR_cmp() compara a y b.

VALORES DE RETORNO

X509_ALGOR_new() y X509_ALGOR_dup() devuelven un nuevo objeto X509_ALGOR o NULL si ocurre un error.

X509_ALGOR_set0() devuelve 1 para éxito o 0 si alg es NULL o falla la asignación de memoria.

X509_ALGOR_cmp() devuelve 0 si a y b tienen codificaciones idénticas o un valor distinto de cero en caso contrario.

VER TAMBIÉN

ASN1_TYPE_set(3), d2i_X509_ALGOR(3), EVP_DigestInit(3), OBJ_nid2obj(3), X509_get0_signature(3), X509_new(3), X509_PUBKEY_get0_param(3), X509_signature_dump(3)

ESTÁNDARES

HISTORIA

X509_ALGOR_new() y X509_ALGOR_free() aparecieron en SSLeay 0.4 o anterior y han estado disponibles desde OpenBSD 2.4.

X509_ALGOR_dup() apareció por primera vez en SSLeay 0.9.1 y ha estado disponible desde OpenBSD 2.6.

X509_ALGOR_set0() y X509_ALGOR_get0() aparecieron por primera vez en OpenSSL 0.9.8h y han estado disponibles desde OpenBSD 4.5.

X509_ALGOR_cmp() apareció por primera vez en OpenSSL 0.9.8zd, 1.0.0p y 1.0.1k y ha estado disponible desde OpenBSD 4.9.
