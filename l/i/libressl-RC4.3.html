libressl-RC4(3)

Paquete: libressl

Licencias: ISC, custom:OpenSSL

RC4(3) Manual de funciones de biblioteca RC4(3)

NOMBRE

RC4_set_key, RC4 — cifrado RC4

SINOPSIS

biblioteca “libcrypto”
#include <openssl/rc4.h>

void
RC4_set_key(RC4_KEY *key, int len, const unsigned char *data);

void
RC4(RC4_KEY *key, unsigned long len, const unsigned char *indata, unsigned char *outdata);

DESCRIPCIÓN

Esta biblioteca implementa el supuesto cifrado RC4, que se describe por ejemplo en "Applied Cryptography". Se cree que es compatible con RC4[TM], un cifrado propietario de RSA Security Inc.

RC4 es un cifrado de flujo con longitud de clave variable. Típicamente, se utilizan claves de 128 bits (16 bytes) para un cifrado seguro, pero se han utilizado tamaños de clave más cortos e inseguros debido a restricciones de exportación.

RC4 consta de una fase de configuración de clave y la fase real de cifrado o descifrado.

RC4_set_key() configura la RC4_KEY key utilizando los len bytes de longitud de clave en data.

RC4() cifra o descifra los len bytes de datos en indata utilizando key y coloca el resultado en outdata. Las llamadas repetidas a RC4() con la misma key producen un flujo de claves continuo.

Dado que RC4 es un cifrado de flujo (la entrada se combina con XOR con un flujo de claves pseudoaleatorio para producir la salida), el descifrado utiliza las mismas llamadas a funciones que el cifrado.

VER TAMBIÉN

blowfish(3), EVP_EncryptInit(3), EVP_rc4(3)

HISTORIA

RC4_set_key() y RC4() aparecieron en SSLeay 0.4 o anterior y han estado disponibles desde OpenBSD 2.4.

ERRORES

Este cifrado está roto y ya no debería usarse.
