libressl-SSL_CTX_set_read_ahead(3)

Paquete: libressl

Licencias: ISC, custom:OpenSSL

SSL_CTX_SET_READ_AHEAD(3) Manual de funciones de biblioteca SSL_CTX_SET_READ_AHEAD(3)

NOMBRE

SSL_CTX_set_read_ahead, SSL_CTX_get_read_ahead, SSL_set_read_ahead, SSL_get_read_ahead, SSL_CTX_get_default_read_ahead — gestionar si se leen tantos bytes de entrada como sea posible

SINOPSIS

biblioteca “libssl” libcrypto
#include <openssl/ssl.h>

void
SSL_CTX_set_read_ahead(SSL_CTX *ctx, int yes);

long
SSL_CTX_get_read_ahead(SSL_CTX *ctx);

void
SSL_set_read_ahead(SSL *s, int yes);

long
SSL_get_read_ahead(const SSL *s);

long
SSL_CTX_get_default_read_ahead(SSL_CTX *ctx);

DESCRIPCIÓN

SSL_CTX_set_read_ahead() y SSL_set_read_ahead() establecen si se leen tantos bytes de entrada como sea posible para lecturas no bloqueantes. Por ejemplo, si OpenSSL requiere actualmente x bytes, pero hay y bytes disponibles del BIO subyacente (donde y > x), entonces OpenSSL leerá todos los y bytes en su búfer (siempre que el búfer sea lo suficientemente grande) si la lectura anticipada está activada, o x bytes en caso contrario. El parámetro yes debe ser 0 para asegurar que la lectura anticipada esté desactivada, o distinto de cero en caso contrario.

SSL_CTX_get_read_ahead() y SSL_get_read_ahead() indican si la lectura anticipada está establecida o no.

SSL_CTX_get_default_read_ahead() es idéntico a SSL_CTX_get_read_ahead().

Estas funciones están implementadas como macros.

Estas funciones no tienen efecto cuando se usan con DTLS.

VALORES DE RETORNO

SSL_CTX_get_read_ahead() y SSL_get_read_ahead() devuelven 0 si la lectura anticipada está desactivada o distinto de cero en caso contrario, excepto que los valores de retorno no están definidos para DTLS.

VER TAMBIÉN

ssl(3), SSL_pending(3)

HISTORIA

SSL_set_read_ahead() y SSL_get_read_ahead() aparecieron en SSLeay 0.4 o anteriores y han estado disponibles desde OpenBSD 2.4.

SSL_CTX_set_read_ahead(), SSL_CTX_get_read_ahead(), y SSL_CTX_get_default_read_ahead() aparecieron por primera vez en OpenSSL 0.9.2b y han estado disponibles desde OpenBSD 2.6.

ADVERTENCIAS

Cambiar la lectura anticipada puede afectar el comportamiento de la función SSL_pending(3).
