NOMBRE

libzzuf - librería auxiliar para el fuzzer multifuncional zzuf

DESCRIPCIÓN

libzzuf es una librería auxiliar pre-cargada automáticamente por zzuf al realizar fuzzing en aplicaciones, pero también puede ser usada por sí sola con fines de depuración o en casos específicos que no pueden ser cubiertos por zzuf.

USO

libzzuf debe ser pre-cargada usando la forma predeterminada del sistema operativo para pre-cargar librerías. Por ejemplo, en una instalación típica de Linux:

LD_PRELOAD=/usr/lib/zzuf/libzzuf.so

VARIABLES DE ENTORNO

La configuración inicial de libzzuf se realiza a través de variables de entorno. Después de leerlas, no se puede enviar más información al proceso fuzzedo.

Todas las variables de entorno son opcionales.

ZZUF_DEBUG
Esta variable de entorno se establece al nivel de depuración. 0 significa que no se envía información de depuración a zzuf. 1 registra información importante, así como todas las funciones desviadas. 2 registra el estado del fuzzing y toda la información opcional del stream de archivos.
ZZUF_DEBUGFD
Esta variable de entorno se establece a un descriptor de archivo donde libzzuf enviará la información de depuración. Esto se usa para enviar datos al binario principal de control de zzuf.
ZZUF_SEED
Esta variable se establece a la semilla aleatoria inicial. Indicador de zzuf correspondiente: --seed.
ZZUF_MINRATIO, ZZUF_MAXRATIO
Estas variables se establecen a las ratios de fuzzing mínima y máxima. Indicador de zzuf correspondiente: --ratio.
ZZUF_AUTOINC
Si esta variable está establecida, la semilla aleatoria se incrementa cada vez que se abre un nuevo archivo. Indicador de zzuf correspondiente: --autoinc.
ZZUF_BYTES
Esta variable contiene rangos de bytes a los que se debe restringir el fuzzing. Indicador de zzuf correspondiente: --bytes.
ZZUF_LIST
Esta variable contiene rangos de descriptores de archivo a los que se debe restringir el fuzzing. Indicador de zzuf correspondiente: --list.
ZZUF_NETWORK
Si esta variable está establecida, se activa el modo de red. Indicador de zzuf correspondiente: --network.
ZZUF_PORTS
Esta variable contiene rangos de puertos a los que se debe restringir el fuzzing. Indicador de zzuf correspondiente: --port.
ZZUF_PROTECT, ZZUF_REFUSE
Estas variables contienen rangos de caracteres a proteger o rechazar. Indicadores de zzuf correspondientes: --protect, --refuse.
ZZUF_INCLUDE, ZZUF_EXCLUDE
Estas variables contienen expresiones regulares para indicar qué archivos deben incluirse o excluirse de la lista de archivos fuzzedos. Indicadores de zzuf correspondientes: --include, --exclude.
ZZUF_SIGNAL
Si esta variable está establecida, se evitará que el proceso fuzzedo instale manejadores de señales que normalmente causan volcados de memoria. Indicador de zzuf correspondiente: --signal.
ZZUF_MEMORY
Esta variable contiene la cantidad máxima de memoria que se permite asignar al proceso fuzzedo. Indicador de zzuf correspondiente: --max-memory.
ZZUF_STDIN
Si esta variable está establecida, la entrada estándar también será fuzzeda. Indicador de zzuf correspondiente: --stdin.

NOTAS

Para interceptar operaciones de archivos y red, manejadores de señales y asignaciones de memoria, libzzuf desvía y reimplementa las siguientes funciones, que a veces también pueden ser símbolos privados de la librería C:

Manejo de descriptores de archivo Unix:
open(), dup(), dup2(), lseek(), read(), readv(), pread(), accept(), socket(), recv(), recvfrom(), recvmsg(), aio_read(), aio_return(), close()
Streams de IO Estándar:
fopen(), freopen(), fseek(), fseeko(), rewind(), fread(), getc(), getchar(), fgetc(), fgets(), ungetc(), fclose()
Gestión de memoria:
mmap(), munmap(), malloc(), calloc(), valloc(), free(), memalign(), posix_memalign()
Requerido en Linux:
open64(), lseek64(), mmap64(), _IO_getc(), getline(), getdelim(), __getdelim(), getc_unlocked(), getchar_unlocked(), fgetc_unlocked(), fgets_unlocked(), fread_unlocked(), __uflow()
Requerido en sistemas BSD:
fgetln(), __srefill(), __srget()
Requerido en Mac OS X:
map_fd()
Requerido en HP-UX:
__open64(), __lseek64(), __filbuf()
Requerido en OpenSolaris:
freopen64(), fseeko64(), fsetpos64()
Manejo de señales:
signal(), sigaction()

Si una aplicación manipula descriptores de archivo (leyendo datos, buscando) usando funciones que no están en esa lista, libzzuf no realizará fuzzing de su entrada de manera consistente y los resultados no deberían ser confiables. Puedes usar una herramienta como ltrace(1) en Linux para conocer las funciones faltantes.

En sistemas BSD, como FreeBSD o Mac OS X, __srefill() es suficiente para monitorear todas las funciones de streams de IO estándar. En otros sistemas, como Linux, cada función se reimplementa caso por caso. Una función importante no implementada es fscanf(), debido a su complejidad. Se añadirán funciones faltantes a petición del usuario.

NOMBRE

zzuf - un mutador de paquetes para probar la robustez de los programas

DESCRIPCIÓN

Zzuf es una herramienta para encontrar errores de programas al corromper silenciosamente los datos de entrada o de salida. Es una herramienta de fuzzing muy sencilla que se puede utilizar para poner a prueba cualquier programa que lea de la entrada estándar o escriba en la salida estándar.

La corrupción puede ser de muchos tipos diferentes: bytes aleatorios, bytes corruptos, inserción de bytes nulos, escritura de bytes incorrectos, etc. Zzuf también puede reordenar bytes, eliminar bytes o duplicarlos.

USO

zzuf [OPCIONES] -- [PROGRAMA] [ARGUMENTOS]

Opciones:

-s <semente>
Semilla para el generador de números aleatorios.
-r <tasa>
Tasa de corrupción (porcentaje de bytes afectados).
-f <archivo>
Utilizar archivo como entrada.
-o <archivo>
Escribir la salida en archivo.
-d <profundidad>
Profundidad de corrupción (cuántas veces se corrompen los bytes).
-m <modo>
Modo de corrupción (ver la documentación para más detalles).
-p <pid>
Adjuntar a un proceso existente con PID.
-v
Verboso, muestra información sobre la corrupción.
-h
Muestra un mensaje de ayuda.

Ejemplo:

$ zzuf -r 10 -- cat input.txt | grep 'hello' > output.txt

Esto corromperá el 10% de los datos que fluyen a través de cat input.txt y luego los pasará a grep 'hello'.

VARIABLES DE ENTORNO

ZZUF_SEED
Semilla para el generador de números aleatorios.
ZZUF_RATE
Tasa de corrupción.
ZZUF_DEPTH
Profundidad de corrupción.
ZZUF_MODE
Modo de corrupción.

NOTAS

Zzuf es una herramienta poderosa pero debe usarse con precaución. La corrupción de datos puede provocar resultados impredecibles y, en algunos casos, podría dañar sus datos o su sistema.

Zzuf puede ser útil para encontrar errores en programas que procesan datos de texto, como editores, compiladores o intérpretes.

VER TAMBIÉN

afl-fuzz(1), radamsa(1)
