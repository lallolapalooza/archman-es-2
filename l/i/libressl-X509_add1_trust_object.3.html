X509_ADD1_TRUST_OBJECT(3) Manual de funciones de la biblioteca X509_ADD1_TRUST_OBJECT(3)

NOMBRE

X509_add1_trust_object, X509_trust_clear, X509_add1_reject_object, X509_reject_clear — marcar un certificado X.509 como destinado a un propósito específico

SINOPSIS

biblioteca “libcrypto”
#include <openssl/x509.h>

int
X509_add1_trust_object(X509 *x, const ASN1_OBJECT *purpose);

void
X509_trust_clear(X509 *x);

int
X509_add1_reject_object(X509 *x, const ASN1_OBJECT *purpose);

void
X509_reject_clear(X509 *x);

DESCRIPCIÓN

X509_add1_trust_object() añade una copia profunda del objeto purpose al conjunto de propósitos previstos que x contiene como datos auxiliares no estándar. La función OBJ_nid2obj(3) se puede usar para crear objetos de propósito apropiados a partir de las constantes NID_* mencionadas en X509_check_purpose(3), aunque las constantes X509_PURPOSE_* listadas en ese manual no están destinadas a usarse con X509_add1_trust_object().

X509_trust_clear() libera y elimina todos los objetos de propósito del conjunto de propósitos previstos en los datos auxiliares no estándar de x.

X509_add1_reject_object() y X509_reject_clear() son similares excepto que operan sobre un conjunto de propósitos no deseados.

Como alternativa al uso de las funciones documentadas en la presente página del manual, se pueden usar extensiones de certificados X.509. Con el precio de una mayor complejidad, estas permiten almacenar el propósito dentro del propio certificado de una manera que cumple con los estándares en lugar de simplemente en datos auxiliares no estándar asociados con el certificado. Véase EXTENDED_KEY_USAGE_new(3) para más detalles.

VALORES DE RETORNO

X509_add1_trust_object() y X509_add1_reject_object() devuelven el nuevo número de propósitos en el conjunto respectivo o 0 si ocurre un error, en particular si la asignación de memoria falla o si x no contiene un sub-objeto que pueda contener datos auxiliares no estándar.

VER TAMBIÉN

ASN1_OBJECT_new(3), EXTENDED_KEY_USAGE_new(3), OBJ_nid2obj(3), X509_CERT_AUX_new(3), X509_new(3)

HISTORIAL

Estas funciones aparecieron por primera vez en OpenSSL 0.9.4 y han estado disponibles desde OpenBSD 2.7.
