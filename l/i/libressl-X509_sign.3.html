libressl-X509_sign(3)

Paquete: libressl

Licencias: ISC, custom:OpenSSL

X509_SIGN(3) Manual de funciones de biblioteca X509_SIGN(3)

NOMBRE

X509_sign, X509_sign_ctx, X509_verify, X509_REQ_sign, X509_REQ_sign_ctx, X509_REQ_verify, X509_CRL_sign, X509_CRL_sign_ctx, X509_CRL_verify — firma o verifica la firma de certificados, solicitudes de certificados o CRLs

SINOPSIS

biblioteca “libcrypto”
#include <openssl/x509.h>

int
X509_sign(X509 *x, EVP_PKEY *pkey, const EVP_MD *md);

int
X509_sign_ctx(X509 *x, EVP_MD_CTX *ctx);

int
X509_verify(X509 *x, EVP_PKEY *pkey);

int
X509_REQ_sign(X509_REQ *x, EVP_PKEY *pkey, const EVP_MD *md);

int
X509_REQ_sign_ctx(X509_REQ *x, EVP_MD_CTX *ctx);

int
X509_REQ_verify(X509_REQ *x, EVP_PKEY *pkey);

int
X509_CRL_sign(X509_CRL *x, EVP_PKEY *pkey, const EVP_MD *md);

int
X509_CRL_sign_ctx(X509_CRL *x, EVP_MD_CTX *ctx);

int
X509_CRL_verify(X509_CRL *x, EVP_PKEY *pkey);

DESCRIPCIÓN

X509_sign() firma el certificado x usando la clave privada pkey y el resumen de mensajes md y establece la firma en x. X509_sign_ctx() también firma el certificado x pero utiliza los parámetros contenidos en el contexto del resumen ctx.

X509_verify() verifica la firma del certificado x usando la clave pública pkey. Solo se comprueba la firma: no se realizan otras comprobaciones (como la validez de la cadena de certificados).

X509_REQ_sign(), X509_REQ_sign_ctx(), X509_REQ_verify(), X509_CRL_sign(), X509_CRL_sign_ctx(), y X509_CRL_verify() firman y verifican solicitudes de certificados y CRLs, respectivamente.

X509_sign_ctx() se utiliza cuando los parámetros predeterminados para la clave pública y el resumen correspondientes no son adecuados. Puede usarse para firmar claves utilizando RSA-PSS, por ejemplo.

VALORES DE RETORNO

X509_sign(), X509_sign_ctx(), X509_REQ_sign(), X509_REQ_sign_ctx(), X509_CRL_sign(), y X509_CRL_sign_ctx() devuelven el tamaño de la firma en bytes para el éxito o 0 para el fallo.

X509_verify(), X509_REQ_verify(), y X509_CRL_verify() devuelven 1 si la firma es válida o 0 si la comprobación de la firma falla. Si la firma no se pudo comprobar en absoluto porque era inválida o ocurrió algún otro error, entonces se devuelve -1.

En algunos casos de fallo, la razón puede determinarse con ERR_get_error(3).

HISTORIAL

X509_verify() apareció en SSLeay 0.4 o anterior. X509_sign() y X509_REQ_sign() aparecieron por primera vez en SSLeay 0.4.4. X509_REQ_verify() y X509_CRL_verify() aparecieron por primera vez en SSLeay 0.4.5b. X509_CRL_sign() apareció por primera vez en SSLeay 0.5.1. Estas funciones han estado disponibles desde OpenBSD 2.4.

X509_sign_ctx(), X509_REQ_sign_ctx(), y X509_CRL_sign_ctx() aparecieron por primera vez en OpenSSL 1.0.1 y han estado disponibles desde OpenBSD 5.3.
