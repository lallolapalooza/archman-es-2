libssh2_sftp_close_handle(3)

Paquete: libssh2

Licencias: BSD

libssh2_sftp_close_handle(3) libssh2 libssh2_sftp_close_handle(3)

NOMBRE

libssh2_sftp_close_handle - cerrar manejador de archivo

SINOPSIS

#include <libssh2.h>
#include <libssh2_sftp.h>
int
libssh2_sftp_close_handle(LIBSSH2_SFTP_HANDLE *handle);
int
libssh2_sftp_close(LIBSSH2_SFTP_HANDLE *handle);
int
libssh2_sftp_closedir(LIBSSH2_SFTP_HANDLE *handle);

DESCRIPCIÓN

handle - Manejador de archivo SFTP como el devuelto por libssh2_sftp_open_ex(3) o libssh2_sftp_opendir(3) (que es una macro).

Cierra un LIBSSH2_SFTP_HANDLE activo. Debido a que los archivos y directorios comparten el mismo mecanismo de almacenamiento subyacente, estos métodos pueden usarse indistintamente. libssh2_sftp_close(3) y libssh2_sftp_closedir(3) son macros para libssh2_sftp_close_handle(3).

VALOR DE RETORNO

Retorna 0 en caso de éxito o un valor negativo en caso de fallo. Retorna LIBSSH2_ERROR_EAGAIN cuando de otra manera se bloquearía. Aunque LIBSSH2_ERROR_EAGAIN es un número negativo, no es realmente un fallo en sí mismo.

ERRORES

LIBSSH2_ERROR_ALLOC - Falló una llamada interna de asignación de memoria.

LIBSSH2_ERROR_SOCKET_SEND - No se pudieron enviar datos por el socket.

LIBSSH2_ERROR_SOCKET_TIMEOUT -

LIBSSH2_ERROR_SFTP_PROTOCOL - Se recibió una respuesta de protocolo SFTP inválida en el socket, o una operación SFTP causó que el servidor retornara un código de error.
