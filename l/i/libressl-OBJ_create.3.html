libressl-OBJ_create(3)

Paquete: libressl

Licencias: ISC, custom:OpenSSL

OBJ_CREATE(3) Manual de funciones de biblioteca OBJ_CREATE(3)

NOMBRE

OBJ_new_nid, OBJ_add_object, OBJ_create, OBJ_create_objects, OBJ_cleanup — modificar la tabla de identificadores de objetos ASN.1

SINOPSIS

biblioteca “libcrypto”
#include <openssl/objects.h>

int
OBJ_new_nid(int increment);

int
OBJ_add_object(const ASN1_OBJECT *object);

int
OBJ_create(const char *oid, const char *sn, const char *ln);

int
OBJ_create_objects(BIO *in_bio);

void
OBJ_cleanup(void);

DESCRIPCIÓN

OBJ_new_nid() devuelve el identificador de objeto numérico ASN.1 (NID) no asignado más pequeño actualmente y reserva increment NIDs consecutivos a partir de él. Generalmente se recomienda pasar un argumento de 1. El valor de retorno se puede asignar a un nuevo objeto pasándolo como argumento nid a ASN1_OBJECT_create(3) y pasando el objeto resultante a OBJ_add_object().

OBJ_add_object() añade una copia del object a la tabla interna de identificadores de objetos ASN.1 para su uso por OBJ_nid2obj(3) y funciones relacionadas.

OBJ_create() proporciona una forma más sencilla de añadir un nuevo objeto a la tabla interna. oid es la forma numérica del objeto, sn el nombre corto y ln el nombre largo. Se asigna automáticamente un nuevo NID usando OBJ_new_nid().

OBJ_create_objects() lee líneas de texto del formato

oid sn ln

desde in_bio y llama a OBJ_create(oid, sn, ln) por cada línea leída. Los tres campos de las líneas de entrada están separados por uno o más caracteres de espacio en blanco.

Para las tres funciones, los objetos añadidos a la tabla interna y todos los datos contenidos en ellos se marcan como no asignados dinámicamente. En consecuencia, recuperarlos con OBJ_nid2obj(3) o una función similar y luego llamar a ASN1_OBJECT_free(3) en el puntero devuelto no tendrá ningún efecto.

OBJ_cleanup() restablece la tabla de objetos interna a su estado predeterminado, eliminando y liberando todos los objetos que se añadieron con OBJ_add_object(), OBJ_create(), o OBJ_create_objects().

VALORES DE RETORNO

OBJ_new_nid() devuelve el nuevo NID.

OBJ_add_object() devuelve el NID del object añadido o NID_undef si no se añadió ningún objeto porque el argumento object era NULL, no contenía un NID, o la asignación de memoria falló.

OBJ_create() devuelve el nuevo NID o NID_undef si oid no es una representación válida de un identificador de objeto o si falla la asignación de memoria.

OBJ_create_objects() devuelve el número de objetos añadidos.

En algunos casos de fallo de OBJ_add_object(), OBJ_create(), y OBJ_create_objects(), la razón puede determinarse con ERR_get_error(3).

EJEMPLOS

Crear un nuevo NID e inicializar un objeto a partir de él:

int new_nid;
ASN1_OBJECT *obj;

new_nid = OBJ_create("1.2.3.4", "NewOID", "New Object Identifier");
obj = OBJ_nid2obj(new_nid);

VER TAMBIÉN

ASN1_OBJECT_new(3), OBJ_nid2obj(3)

HISTORIA

OBJ_new_nid(), OBJ_add_object(), y OBJ_cleanup() aparecieron por primera vez en SSLeay 0.8.0 y OBJ_create() en SSLeay 0.9.0. Estas funciones han estado disponibles desde OpenBSD 2.4.

ADVERTENCIAS

OBJ_add_object() indica éxito incluso después de añadir un objeto incompleto que se creó con ASN1_OBJECT_create(3) pero carece de un nombre corto, un nombre largo o un OID.

Incluso OBJ_create() tolera que se pasen punteros NULL para los argumentos sn y/o ln, en cuyo caso OBJ_nid2sn(3) y OBJ_sn2nid(3) o OBJ_nid2ln(3) y OBJ_ln2nid(3) no funcionarán en el objeto añadido, respectivamente.

ERRORES

OBJ_new_nid() no reserva ningún valor de retorno para indicar un error. En consecuencia, para evitar conflictos en la asignación de NIDs y desbordamientos de enteros, se debe tener cuidado de no pasar argumentos negativos, cero o grandes a OBJ_new_nid().

OBJ_create_objects() no distingue entre fin de archivo, errores de E/S, indisponibilidad temporal de datos en un BIO no bloqueante, sintaxis de entrada inválida y fallo de asignación de memoria. En todos estos casos, la lectura se interrumpe y se devuelve el número de objetos que ya se añadieron.
