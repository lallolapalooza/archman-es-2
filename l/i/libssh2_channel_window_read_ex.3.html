NOMBRE

libssh2_channel_window_read_ex - Comprobar el estado de la ventana de lectura

SINOPSIS

#include <libssh2.h>
unsigned long
libssh2_channel_window_read_ex(LIBSSH2_CHANNEL *channel,
                               unsigned long *read_avail,
                               unsigned long *window_size_initial)

DESCRIPCIÓN

Comprueba el estado de la ventana de lectura. Devuelve el número de bytes que el extremo remoto puede enviar sin exceder el límite de la ventana. Si se proporciona `read_avail`, se poblará con el número de bytes realmente disponibles para leer. Si se proporciona `window_size_initial`, se poblará con el tamaño de ventana inicial tal como se define en la solicitud `channel_open`.

VALOR DE RETORNO

El número de bytes que el extremo remoto puede enviar sin exceder el límite de la ventana.
