I2A_ASN1_STRING(3) Manual de Funciones de Librería I2A_ASN1_STRING(3)

NOMBRE

i2a_ASN1_STRING, i2a_ASN1_INTEGER, i2a_ASN1_ENUMERATED, a2i_ASN1_STRING, a2i_ASN1_INTEGER, a2i_ASN1_ENUMERATED — volcado hexadecimal de una cadena ASN.1

SINOPSIS

librería “libcrypto”
#include <openssl/asn1.h>

int
i2a_ASN1_STRING(BIO *out_bio, const ASN1_STRING *a, int type);

int
i2a_ASN1_INTEGER(BIO *out_bio, const ASN1_INTEGER *a);

int
i2a_ASN1_ENUMERATED(BIO *out_bio, const i2a_ASN1_ENUMERATED *a);

int
a2i_ASN1_STRING(BIO *in_bio, ASN1_STRING *out_string, char *buffer, int size);

int
a2i_ASN1_INTEGER(BIO *in_bio, ASN1_INTEGER *out_string, char *buffer, int size);

int
a2i_ASN1_ENUMERATED(BIO *in_bio, ASN1_ENUMERATED *out_string, char *buffer, int size);

DESCRIPCIÓN

Las funciones i2a_ASN1_STRING(), i2a_ASN1_INTEGER(), y i2a_ASN1_ENUMERATED() escriben una representación hexadecimal de a en out_bio. El argumento type se ignora.

Cada byte de ASN1_STRING_get0_data(3) se escribe como un número que consta de dos dígitos hexadecimales en mayúsculas. Después de cada grupo de 70 dígitos, se insertan una barra invertida y un salto de línea antes del siguiente dígito.

Si la ASN1_STRING_length(3) de a es 0, en su lugar se escribe un par de ceros ("00") por i2a_ASN1_INTEGER() y i2a_ASN1_ENUMERATED() y un solo dígito cero ("0") por i2a_ASN1_STRING(). Si a es un puntero NULL, no se escribe nada.

Si a representa un entero negativo, i2a_ASN1_INTEGER() antepone un signo menos a la salida.

Las funciones a2i_ASN1_STRING(), a2i_ASN1_INTEGER(), y a2i_ASN1_ENUMERATED() analizan una representación hexadecimal de una cadena ASN.1 en out_string. Se aceptan tanto dígitos hexadecimales en minúsculas como en mayúsculas. Cada par de dígitos de entrada se convierte en un byte de salida.

En cada línea de entrada, se ignoran el carácter de salto de línea final y un carácter de retorno de carro opcional que lo precede. El salto de línea final no es necesario en la última línea. Si hay un carácter de barra invertida antes del carácter de salto de línea, el análisis continúa en la siguiente línea de entrada.

Se requiere al menos un par de dígitos de entrada por a2i_ASN1_INTEGER() y a2i_ASN1_ENUMERATED(), mientras que a2i_ASN1_STRING() convierte la entrada vacía en una cadena vacía.

Estas funciones son capaces de analizar la salida de i2a_ASN1_ENUMERATED(). Pueden analizar la salida de i2a_ASN1_INTEGER() a menos que a fuera negativo, y pueden analizar la salida de i2a_ASN1_STRING() a menos que la ASN1_STRING_length(3) de a fuera 0.

El análisis falla si una línea de entrada contiene un número impar de dígitos de entrada o si falla la asignación de memoria.

Estas funciones utilizan el buffer proporcionado por el llamador y asumen que tiene al menos size bytes de longitud. No se especifica qué contiene el búfer después de que las funciones regresen.

VALORES DE RETORNO

Las funciones i2a_ASN1_STRING(), i2a_ASN1_INTEGER(), y i2a_ASN1_ENUMERATED() devuelven el número de bytes escritos o -1 si BIO_write(3) falla. En particular, todas devuelven 0 cuando a es un puntero NULL. i2a_ASN1_STRING() devuelve 1 para una cadena vacía o un número par mayor que 1 para una cadena no vacía. i2a_ASN1_INTEGER() devuelve un número par mayor que 1 para entrada positiva o un número impar mayor que 2 para entrada negativa. i2a_ASN1_ENUMERATED() siempre devuelve un número par no negativo cuando tiene éxito.

Las funciones a2i_ASN1_STRING(), a2i_ASN1_INTEGER(), y a2i_ASN1_ENUMERATED() pretenden devolver 1 para éxito o 0 para fallo, pero vea la sección BUGS para conocer una serie de trampas.

VER TAMBIÉN

a2i_ipadd(3), ASN1_STRING_length(3), ASN1_STRING_new(3), ASN1_STRING_print_ex(3), i2a_ASN1_OBJECT(3), i2s_ASN1_INTEGER(3)

HISTORIA

i2a_ASN1_INTEGER() y a2i_ASN1_INTEGER() aparecieron por primera vez en SSLeay 0.6.0. i2a_ASN1_STRING() y a2i_ASN1_STRING() aparecieron por primera vez en SSLeay 0.6.5. a2i_ASN1_STRING() ha sido parte de la API pública desde SSLeay 0.6.5 y i2a_ASN1_STRING() desde SSLeay 0.8.0. Estas funciones han estado disponibles desde OpenBSD 2.4.

i2a_ASN1_ENUMERATED() y a2i_ASN1_ENUMERATED() aparecieron por primera vez en OpenSSL 0.9.2 y han estado disponibles desde OpenBSD 2.6.

BUGS

Si la primera llamada a BIO_gets(3) no devuelve ningún dato, incluso si esto se debe a un error de E/S fatal, si el tipo de BIO no soporta la operación “gets”, o si se debe a que el BIO no es bloqueante, a2i_ASN1_STRING() tiene éxito inmediatamente y devuelve un out_string vacío.

Si BIO_gets(3) devuelve una línea parcial, por ejemplo, porque el size proporcionado es insuficiente para contener una de las líneas de entrada o por razones específicas del tipo de BIO, a2i_ASN1_STRING(), a2i_ASN1_INTEGER(), y a2i_ASN1_ENUMERATED() pueden fallar o devolver silenciosamente un resultado truncado. El llamador es responsable de proporcionar un buffer de tamaño suficiente para contener la línea de entrada más larga posible y de elegir un BIO de un tipo que solo devuelva líneas de entrada completas y no realice lecturas parciales.

LibreSSL | i2a_ASN1_STRING(3)

NAME

i2a_ASN1_STRING, a2i_ASN1_INTEGER, a2i_ASN1_ENUMERATED - convert between integer and ASN1_STRING

SYNOPSIS

 #include <openssl/asn1.h>

 ASN1_STRING *i2a_ASN1_STRING(ASN1_STRING *a, long i);
 long a2i_ASN1_INTEGER(const ASN1_STRING *s);
 long a2i_ASN1_ENUMERATED(const ASN1_STRING *s);

DESCRIPTION

These functions convert between C integer types and ASN.1 integer or enumerated types. i2a_ASN1_STRING() converts a C long integer i into an ASN.1 string a. If a is NULL then a new ASN1_STRING is allocated.

a2i_ASN1_INTEGER() converts an ASN1_STRING s representing an integer into a C long integer. It is assumed that s contains a valid ASN.1 INTEGER or ENUMERATED value.

a2i_ASN1_ENUMERATED() is similar to a2i_ASN1_INTEGER() but treats the input as an ASN.1 ENUMERATED value.

These functions are used to convert between internal C representations and the ASN.1 data types used in X.509 certificates and other cryptographic structures.

RETURN VALUES

i2a_ASN1_STRING() returns a pointer to the resulting ASN1_STRING on success, or NULL on failure. If a was NULL then the caller must free the returned ASN1_STRING.

a2i_ASN1_INTEGER() and a2i_ASN1_ENUMERATED() return the converted C long integer value on success. If the conversion fails or the value is out of range for a C long, the behavior is undefined (may return an incorrect value or crash).

SEE ALSO

ASN1_STRING_new(3)

HISTORY

These functions first appeared in OpenSSL 0.9.3.

BUGS

i2a_ASN1_STRING(), a2i_ASN1_INTEGER(), and a2i_ASN1_ENUMERATED() do not support non-blocking BIOs. Reading is terminated as soon as BIO_gets(3) returns a value less than 1.
