DOCUMENTACIÓN DE FUNCIONES

alpm_file_t * alpm_filelist_contains (const alpm_filelist_t * filelist, const char * path)

Determina si una lista de archivos de paquete contiene una ruta dada. La ruta proporcionada debe ser relativa a la raíz de instalación sin barras iniciales, por ejemplo, "etc/localtime". Al buscar directorios, la ruta debe tener una barra final.

Parámetros

filelist un puntero a una lista de archivos del paquete
path la ruta a buscar en el paquete

Devuelve

un puntero al archivo coincidente o NULL si no se encuentra
