NOMBRE

libi2c - funciones accesibles públicamente proporcionadas por la biblioteca i2c

SINOPSIS

#include <linux/i2c.h>
#include <i2c/smbus.h>
/* Transacción SMBus universal */
__s32 i2c_smbus_access(int file, char read_write, __u8 command,
                       int size, union i2c_smbus_data *data);
/* Transacciones SMBus simples */
__s32 i2c_smbus_write_quick(int file, __u8 value);
__s32 i2c_smbus_read_byte(int file);
__s32 i2c_smbus_write_byte(int file, __u8 value);
__s32 i2c_smbus_read_byte_data(int file, __u8 command);
__s32 i2c_smbus_write_byte_data(int file, __u8 command, __u8 value);
__s32 i2c_smbus_read_word_data(int file, __u8 command);
__s32 i2c_smbus_write_word_data(int file, __u8 command, __u16 value);
__s32 i2c_smbus_process_call(int file, __u8 command, __u16 value);
/* Transacciones SMBus (y no SMBus) en bloque */
__s32 i2c_smbus_read_block_data(int file, __u8 command, __u8 *values);
__s32 i2c_smbus_write_block_data(int file, __u8 command, __u8 length,
                                 const __u8 *values);
__s32 i2c_smbus_block_process_call(int file, __u8 command, __u8 length,
                                   __u8 *values);
__s32 i2c_smbus_read_i2c_block_data(int file, __u8 command, __u8 length,
                                    __u8 *values);
__s32 i2c_smbus_write_i2c_block_data(int file, __u8 command, __u8 length,
                                     const __u8 *values);

DESCRIPCIÓN

Esta biblioteca ofrece a los espacios de usuario una API de nivel SMBus similar a la del kernel. Cada función es un envoltorio alrededor de la llamada ioctl apropiada para que i2c-dev procese. El controlador del kernel i2c-dev convertirá el ioctl a su llamada de función equivalente dentro del kernel y pasará el resultado al llamador del espacio de usuario.

i2c_smbus_access() es la función universal para ejecutar cualquier transacción SMBus. Debe rellenar y enlazar las estructuras de datos usted mismo. Devuelve 0 en caso de éxito, o un valor negativo de errno en caso de error. En la práctica, nunca debería necesitar llamar a esta función directamente, sino usar una de las funciones específicas a continuación, que prepararán los datos y luego la llamarán por usted.

i2c_smbus_write_quick() ejecuta una transacción SMBus de "Comando rápido".

i2c_smbus_write_byte() ejecuta una transacción SMBus de "Enviar byte".

i2c_smbus_write_byte_data() ejecuta una transacción SMBus de "Escribir byte".

i2c_smbus_write_word_data() ejecuta una transacción SMBus de "Escribir palabra".

Estas funciones de transacción de escritura devuelven 0 en caso de éxito. En caso de error, se devuelve un valor negativo de errno.

i2c_smbus_read_byte() ejecuta una transacción SMBus de "Recibir byte".

i2c_smbus_read_byte_data() ejecuta una transacción SMBus de "Leer byte".

i2c_smbus_read_word_data() ejecuta una transacción SMBus de "Leer palabra".

i2c_smbus_process_call() ejecuta una transacción SMBus de "Llamada de proceso".

Estas funciones de transacción de lectura devuelven el valor del byte o palabra leída en caso de éxito. En caso de error, se devuelve un valor negativo de errno.

i2c_smbus_write_block_data() ejecuta una transacción SMBus de "Escritura en bloque".

i2c_smbus_read_block_data() ejecuta una transacción SMBus de "Lectura en bloque".

i2c_smbus_block_process_call() ejecuta una transacción SMBus de "Llamada de proceso de escritura-lectura en bloque".

Estas funciones de transacción en bloque devuelven 0 en caso de éxito. En caso de error, se devuelve un valor negativo de errno. La longitud del bloque está limitada a 32 bytes.

i2c_smbus_write_i2c_block_data() ejecuta una transacción de "Escritura de bloque I2C". Esto se usa típicamente para escribir en una EEPROM de hasta 4 KB de tamaño.

i2c_smbus_read_i2c_block_data() ejecuta una transacción de "Lectura de bloque I2C". Esto se usa típicamente para leer de una EEPROM de hasta 4 KB de tamaño.

Aunque técnicamente no forman parte de la especificación SMBus, muchos controladores host SMBus soportan estas transacciones de bloque I2C. Estas funciones de transacción de bloque devuelven 0 en caso de éxito. En caso de error, se devuelve un valor negativo de errno. Al igual que sus homólogos SMBus, la longitud del bloque está limitada a 32 bytes.

ESTRUCTURAS DE DATOS

La estructura i2c_smbus_ioctl_data se utiliza para enviar y recuperar datos del kernel a través del controlador i2c-dev. Será rellenada para usted por i2c_smbus_access(), por lo que no necesita preocuparse por los detalles.

La unión i2c_smbus_data se utiliza para almacenar todos los datos posibles de SMBus.

union i2c_smbus_data {
__u8 byte;
__u16 word;
__u8 block[I2C_SMBUS_BLOCK_MAX + 2];
};

block[0] se utiliza para la longitud y el último byte está reservado. Si utiliza las funciones de nivel superior, esta estructura será rellenada para usted, por lo que no tendrá que preocuparse por los detalles. Solo si llama directamente a i2c_smbus_access(), deberá rellenarla usted mismo.
