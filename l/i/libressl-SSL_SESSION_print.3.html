libressl-SSL_SESSION_print(3)

Paquete: libressl

Licencias: ISC, custom:OpenSSL

SSL_SESSION_PRINT(3) Manual de funciones de biblioteca SSL_SESSION_PRINT(3)

NOMBRE

SSL_SESSION_print, SSL_SESSION_print_fp — imprimir algunas propiedades de un objeto SSL_SESSION

SINOPSIS

biblioteca “libssl” libcrypto
#include <openssl/ssl.h>

int
SSL_SESSION_print(BIO *bp, const SSL_SESSION *session);

int
SSL_SESSION_print_fp(FILE *fp, const SSL_SESSION *session);

DESCRIPCIÓN

SSL_SESSION_print() imprime algunas propiedades de session en un formato legible para humanos en el BIO *bp, incluyendo la versión del protocolo, el nombre del cifrado, el ID de sesión, el contexto del ID de sesión, la clave maestra, la pista de tiempo de vida de la clave de sesión, la clave de sesión, la hora de inicio, el tiempo de espera y el código de retorno de verificación.

SSL_SESSION_print_fp() hace lo mismo que SSL_SESSION_print() excepto que imprime en el FILE *fp.

VALORES DE RETORNO

SSL_SESSION_print() y SSL_SESSION_print_fp() devuelven 1 para éxito o 0 para fallo.

En algunos casos, la razón del fallo se puede determinar con ERR_get_error(3).

VER TAMBIÉN

d2i_SSL_SESSION(3), PEM_read_SSL_SESSION(3), ssl(3), SSL_get_session(3), SSL_SESSION_free(3), SSL_SESSION_get_ex_new_index(3), SSL_SESSION_get_time(3), SSL_SESSION_new(3)

HISTORIA

SSL_SESSION_print() apareció por primera vez en SSLeay 0.5.2. SSL_SESSION_print_fp() apareció por primera vez en SSLeay 0.6.0. Ambas funciones han estado disponibles desde OpenBSD 2.4.
