lindex(n) Comandos integrados de Tcl lindex(n)

NOMBRE

lindex - Recupera un elemento de una lista

SINOPSIS

lindex lista ?índice ...?

DESCRIPCIÓN

El comando lindex acepta un parámetro, lista, que trata como una lista de Tcl. También acepta cero o más índices en la lista. Los índices se pueden presentar consecutivamente en la línea de comandos, o agrupados en una lista de Tcl y presentados como un solo argumento.

Si no se presentan índices, el comando toma la forma:

lindex lista

o

lindex lista {}

En este caso, el valor de retorno de lindex es simplemente el valor del parámetro lista.

Cuando se presenta un solo índice, el comando lindex trata lista como una lista de Tcl y devuelve el elemento número índice de la misma (0 se refiere al primer elemento de la lista). Al extraer el elemento, lindex observa las mismas reglas con respecto a las llaves, comillas y barras invertidas que el intérprete de comandos de Tcl; sin embargo, la sustitución de variables y la sustitución de comandos no ocurren. Si índice es negativo o mayor o igual al número de elementos en valor, se devuelve una cadena vacía. La interpretación de cada valor de índice simple es la misma que para el comando string index, admitiendo aritmética simple de índices e índices relativos al final de la lista.

Si se suministran argumentos de índice adicionales, cada argumento se utiliza por turno para seleccionar un elemento de la operación de indexación anterior, permitiendo al script seleccionar elementos de sublistas. El comando,

lindex $a 1 2 3

o

lindex $a {1 2 3}

es sinónimo de

lindex [lindex [lindex $a 1] 2] 3

EJEMPLOS

Las listas se pueden indexar desde cualquier extremo:

lindex {a b c} 0
      → a
lindex {a b c} 2
      → c
lindex {a b c} end
      → c
lindex {a b c} end-1
      → b

Las listas o secuencias de índices permiten la selección en listas de listas:

lindex {a b c}
      → a b c
lindex {a b c} {}
      → a b c
lindex {{a b c} {d e f} {g h i}} 2 1
      → h
lindex {{a b c} {d e f} {g h i}} {2 1}
      → h
lindex {{{a b} {c d}} {{e f} {g h}}} 1 1 0
      → g
lindex {{{a b} {c d}} {{e f} {g h}}} {1 1 0}
      → g

Los índices de lista también pueden realizar cálculos limitados, sumando o restando cantidades fijas de otros índices:

set idx 1
lindex {a b c d e f} $idx+2
      → d
set idx 3
lindex {a b c d e f} $idx+2
      → f
