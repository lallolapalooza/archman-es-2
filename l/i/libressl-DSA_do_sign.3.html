libressl-DSA_do_sign(3)

Paquete: libressl

Licencias: ISC, custom:OpenSSL

DSA_DO_SIGN(3) Manual de funciones de biblioteca DSA_DO_SIGN(3)

NOMBRE

DSA_do_sign, DSA_do_verify — operaciones de firma DSA en bruto

SINOPSIS

biblioteca “libcrypto”
#include <openssl/dsa.h>

DSA_SIG *
DSA_do_sign(const unsigned char *dgst, int dlen, DSA *dsa);

int
DSA_do_verify(const unsigned char *dgst, int dgst_len, DSA_SIG *sig, DSA *dsa);

DESCRIPCIÓN

DSA_do_sign() calcula una firma digital sobre el resumen del mensaje de dlen bytes dgst utilizando la clave privada dsa y la devuelve en una estructura DSA_SIG recién asignada.

DSA_sign_setup(3) puede usarse para precalcular parte de la operación de firma en caso de que la generación de la firma sea crítica en cuanto al tiempo.

DSA_do_verify() verifica que la firma sig coincide con un resumen del mensaje dado dgst de tamaño dgst_len. dsa es la clave pública del firmante.

VALORES DE RETORNO

DSA_do_sign() devuelve la firma o NULL en caso de error. DSA_do_verify() devuelve 1 para una firma válida, 0 para una firma incorrecta y -1 en caso de error. Los códigos de error se pueden obtener mediante ERR_get_error(3).

VER TAMBIÉN

DSA_get0_key(3), DSA_meth_set_sign(3), DSA_new(3), DSA_SIG_new(3), DSA_sign(3)

HISTORIA

DSA_do_sign() y DSA_do_verify() aparecieron por primera vez en OpenSSL 0.9.3 y han estado disponibles desde OpenBSD 2.6.
