libssh2_version(3)

Paquete: libssh2

Licencias: BSD

libssh2_version(3) libssh2 libssh2_version(3)

NOMBRE

libssh2_version - devuelve el número de versión de libssh2

SINOPSIS

#include <libssh2.h>
const char *
libssh2_version(int required_version);

DESCRIPCIÓN

Si required_version es menor o igual al número de versión de libssh2 en uso, se devuelve el número de versión de libssh2 como un puntero a una cadena terminada en cero.

required_version debe ser el número de versión construido por la definición LIBSSH2_VERSION_NUM en el archivo de cabecera público libssh2.h, que es un número de 24 bits en el formato 0xMMmmpp. MM para mayor, mm para menor y pp para el número de parche.

VALOR DE RETORNO

Se devuelve el número de versión de libssh2 como un puntero a una cadena terminada en cero o NULL si no se cumple required_version.

EJEMPLO

Para asegurarse de que se ejecuta con la versión correcta de libssh2:

if(!libssh2_version(LIBSSH2_VERSION_NUM)) {
  fprintf(stderr, "Versión de libssh2 en tiempo de ejecución demasiado antigua.");
  exit(1);
}

Obtener incondicionalmente el número de versión:

printf("Versión de libssh2: %s", libssh2_version(0));

DISPONIBILIDAD

Esta función se añadió en libssh2 1.1; en versiones anteriores no había forma de extraer esta información en tiempo de ejecución.
