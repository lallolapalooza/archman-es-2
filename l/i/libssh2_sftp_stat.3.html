libssh2_sftp_stat(3)

Paquete: libssh2

Licencias: BSD

libssh2_sftp_stat(3) libssh2 libssh2_sftp_stat(3)

NOMBRE

libssh2_sftp_stat - macro de conveniencia para llamadas a libssh2_sftp_fstat_ex(3)

SINOPSIS

#include <libssh2.h>
#include <libssh2_sftp.h>
int
libssh2_sftp_stat(LIBSSH2_SFTP *sftp, const char *path,
                  LIBSSH2_SFTP_ATTRIBUTES *attrs);

DESCRIPCIÓN

Esto es una macro definida en un archivo de cabecera público de libssh2 que utiliza la función subyacente libssh2_sftp_fstat_ex(3).

VALOR DE RETORNO

Ver libssh2_sftp_fstat_ex(3)

ERRORES

Ver libssh2_sftp_fstat_ex(3)

VER TAMBIÉN
