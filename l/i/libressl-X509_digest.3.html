libressl-X509_digest(3)

Paquete: libressl

Licencias: ISC, custom:OpenSSL

X509_DIGEST(3) Manual de funciones de biblioteca X509_DIGEST(3)

NOMBRE

X509_digest, X509_CRL_digest, X509_pubkey_digest, X509_NAME_digest, X509_REQ_digest, PKCS7_ISSUER_AND_SERIAL_digest — obtener resúmenes de varios objetos

SINOPSIS

biblioteca “libcrypto”
#include <openssl/x509.h>

int
X509_digest(const X509 *data, const EVP_MD *type, unsigned char *md, unsigned int *len);

int
X509_CRL_digest(const X509_CRL *data, const EVP_MD *type, unsigned char *md, unsigned int *len);

int
X509_pubkey_digest(const X509 *data, const EVP_MD *type, unsigned char *md, unsigned int *len);

int
X509_REQ_digest(const X509_REQ *data, const EVP_MD *type, unsigned char *md, unsigned int *len);

int
X509_NAME_digest(const X509_NAME *data, const EVP_MD *type, unsigned char *md, unsigned int *len);

#include <openssl/pkcs7.h>

int
PKCS7_ISSUER_AND_SERIAL_digest(PKCS7_ISSUER_AND_SERIAL *data, const EVP_MD *type, unsigned char *md, unsigned int *len);

DESCRIPCIÓN

X509_pubkey_digest() devuelve un resumen de la representación DER de la clave pública contenida en data. Todas las demás funciones descritas aquí devuelven un resumen de la representación DER de todo su objeto data.

El parámetro type especifica el resumen a utilizar, como EVP_sha1(3). md es un puntero al búfer donde se copiará el resumen y se asume que es lo suficientemente grande; se sugiere un tamaño de al menos EVP_MAX_MD_SIZE bytes. El parámetro len, si no es NULL, apunta a un lugar donde se almacenará el tamaño del resumen.

VALORES DE RETORNO

Estas funciones devuelven 1 para éxito o 0 para fallo.

VER TAMBIÉN

EVP_get_digestbyname(3), X509_cmp(3), X509_CRL_new(3), X509_NAME_new(3), X509_new(3), X509_REQ_new(3)

HISTORIAL

X509_digest(), X509_NAME_digest(), y PKCS7_ISSUER_AND_SERIAL_digest() aparecieron por primera vez en SSLeay 0.6.5 y han estado disponibles desde OpenBSD 2.4.

X509_CRL_digest() y X509_REQ_digest() aparecieron por primera vez en OpenSSL 0.9.6 y han estado disponibles desde OpenBSD 2.9.

X509_pubkey_digest() apareció por primera vez en OpenSSL 0.9.7 y ha estado disponible desde OpenBSD 3.2.
