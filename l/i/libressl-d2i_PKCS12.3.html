DESCRIPCIÓN

Estas funciones decodifican y codifican estructuras PKCS#12. Para detalles sobre la semántica, ejemplos, advertencias y errores, ver ASN1_item_d2i(3).

d2i_PKCS12() y i2d_PKCS12() decodifican y codifican una estructura ASN.1 PFX (intercambio de información personal) definida en la sección 4 de RFC 7292. d2i_PKCS12_bio(), i2d_PKCS12_bio(), d2i_PKCS12_fp(), y i2d_PKCS12_fp() son similares excepto que decodifican o codifican usando un puntero BIO o FILE.

d2i_PKCS12_MAC_DATA() y i2d_PKCS12_MAC_DATA() decodifican y codifican una estructura ASN.1 MacData definida en la sección 4 de RFC 7292.

d2i_PKCS12_SAFEBAG() y i2d_PKCS12_SAFEBAG() decodifican y codifican una estructura ASN.1 SafeBag definida en la sección 4.2 de RFC 7292.

d2i_PKCS12_BAGS() y i2d_PKCS12_BAGS() decodifican y codifican el campo bagValue de una estructura ASN.1 SafeBag.

VALORES DE RETORNO

d2i_PKCS12(), d2i_PKCS12_bio(), y d2i_PKCS12_fp() devuelven un objeto PKCS12 o NULL si ocurre un error.

d2i_PKCS12_MAC_DATA(), d2i_PKCS12_SAFEBAG(), y d2i_PKCS12_BAGS() devuelven un objeto PKCS12_MAC_DATA, PKCS12_SAFEBAG, o PKCS12_BAGS, respectivamente, o NULL si ocurre un error.

i2d_PKCS12(), i2d_PKCS12_MAC_DATA(), i2d_PKCS12_SAFEBAG(), y i2d_PKCS12_BAGS() devuelven el número de bytes codificados con éxito o un valor negativo si ocurre un error.

i2d_PKCS12_bio() y i2d_PKCS12_fp() devuelven 1 para éxito o 0 si ocurre un error.

    D2I_PKCS12(3)

    LibreSSL 3.7.4

    NOMBRE

    d2i_PKCS12, d2i_PKCS12_fp, d2i_PKCS12_bio - Decodifica un objeto PKCS#12.

    DESCRIPCIÓN

    La estructura PKCS#12 se utiliza para almacenar certificados y claves privadas. La función d2i_PKCS12() decodifica una estructura PKCS#12 a partir de un buffer de memoria que contiene datos codificados en DER.

    La función d2i_PKCS12_fp() lee datos codificados en DER de un fichero, los decodifica y devuelve un puntero a la estructura PKCS#12 resultante.

    La función d2i_PKCS12_bio() lee datos codificados en DER de un objeto BIO, los decodifica y devuelve un puntero a la estructura PKCS#12 resultante.

    Estas funciones son útiles para leer datos PKCS#12 de archivos o flujos de red, y luego procesarlos o utilizarlos dentro de una aplicación.

    Los argumentos de estas funciones son:

    *pp
    Un puntero a un puntero a la estructura PKCS#12. Si la estructura ya existe, se reutilizará. Si es NULL, se asignará nueva memoria.
    *fp
    Un puntero a un puntero a la estructura PKCS#12. Si la estructura ya existe, se reutilizará. Si es NULL, se asignará nueva memoria.
    bp
    Un puntero a un objeto BIO desde el que se leerán los datos.

    Estas funciones devuelven un puntero a la estructura PKCS#12 decodificada en caso de éxito, o NULL en caso de error.

    VALORES DE RETORNO

    d2i_PKCS12(), d2i_PKCS12_fp(), y d2i_PKCS12_bio() devuelven un puntero a la estructura PKCS12 decodificada en caso de éxito, o NULL en caso de error.

    VER TAMBIÉN

    i2d_PKCS12(3), PKCS12_create(3), PKCS12_parse(3)

    ESTÁNDARES

    PKCS#12 (Public-Key Cryptography Standards #12)

    HISTORIA

    Estas funciones se han incluido en LibreSSL desde la versión 2.6.
