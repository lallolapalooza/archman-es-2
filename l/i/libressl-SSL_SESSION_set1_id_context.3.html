libressl-SSL_SESSION_set1_id_context(3)

Paquete: libressl

Licencias: ISC, custom:OpenSSL

SSL_SESSION_SET1_ID_CONTEXT(3) Manual de funciones de biblioteca SSL_SESSION_SET1_ID_CONTEXT(3)

NOMBRE

SSL_SESSION_get0_id_context, SSL_SESSION_set1_id_context — obtener y establecer el contexto de ID SSL asociado a una sesión

SINOPSIS

biblioteca “libssl” libcrypto
#include <openssl/ssl.h>

const unsigned char *
SSL_SESSION_get0_id_context(const SSL_SESSION *s, unsigned int *len);

int
SSL_SESSION_set1_id_context(SSL_SESSION *s, const unsigned char *sid_ctx, unsigned int sid_ctx_len);

DESCRIPCIÓN

SSL_SESSION_get0_id_context() devuelve el contexto de ID asociado con s. La longitud del contexto de ID en bytes se escribe en *len si len no es NULL.

SSL_SESSION_set1_id_context() toma una copia del contexto de ID proporcionado en sid_ctx y lo asocia con la sesión s. La longitud del contexto de ID está dada por sid_ctx_len y no debe exceder SSL_MAX_SID_CTX_LENGTH bytes.

VALORES DE RETORNO

SSL_SESSION_get0_id_context() devuelve un puntero interno a un objeto mantenido dentro de s que no debe ser liberado por el llamante.

SSL_SESSION_set1_id_context() devuelve 1 en caso de éxito o 0 en caso de error.

VER TAMBIÉN

ssl(3), SSL_CTX_set_session_id_context(3), SSL_get_session(3), SSL_SESSION_new(3)

HISTORIAL

SSL_SESSION_set1_id_context() apareció por primera vez en OpenSSL 1.0.1 y ha estado disponible desde OpenBSD 5.3.

SSL_SESSION_get0_id_context() apareció por primera vez en OpenSSL 1.1.0 y ha estado disponible desde OpenBSD 6.3.
