NOMBRE

libwacom-list-local-devices - utilidad para listar dispositivos de tableta

SINOPSIS

libwacom-list-local-devices [--format=oneline|datafile] [--database /ruta/a/datadir]

DESCRIPCIÓN

libwacom-list-local-devices es una utilidad de depuración para listar los dispositivos de tableta conectados identificados por libwacom. Generalmente se utiliza para verificar si un archivo de datos de libwacom es correcto, está presente y/o se aplica a un dispositivo específico.

OPCIONES

--format=oneline|datafile
Establece el formato de salida a utilizar. Si es oneline, el formato de salida es una línea que comprende el nombre del dispositivo y los nodos de evento. Si es datafile, el formato de salida coincide con los archivos de datos de la tableta. El valor predeterminado es oneline.
--database /ruta/a/datadir
Establece la ruta del directorio de datos a utilizar. Esto solo es útil al probar con una ruta de datos modificada. Solo los desarrolladores de libwacom necesitan esta opción.

NOTAS

El kernel de Linux proporciona nodos separados /dev/input/event* para el lápiz, el pad y la parte táctil de la tableta. Estos nodos de dispositivo se enumeran como parte de la salida de esta herramienta.

Esta herramienta no puede distinguir entre múltiples dispositivos idénticos. Solo se listará un dispositivo de este tipo, con todos los nodos de evento de todos los dispositivos que sean del mismo tipo.
