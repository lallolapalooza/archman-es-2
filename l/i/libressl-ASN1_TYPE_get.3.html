DESCRIPCIÓN

El tipo de datos ASN1_TYPE y la constante de identificador de tipo V_ASN1_ANY representan el tipo ANY de ASN.1. Un objeto ASN1_TYPE puede almacenar un valor ASN.1 de tipo arbitrario, incluidos tipos construidos como una secuencia. También recuerda internamente qué tipo contiene actualmente.

ASN1_TYPE_new() asigna e inicializa un objeto ASN1_TYPE vacío de tipo V_ASN1_UNDEF.

ASN1_TYPE_free() libera a, incluido el valor almacenado en él, si lo hay. Si a es un puntero NULL, no se realiza ninguna acción.

ASN1_TYPE_get() devuelve el tipo que contiene actualmente a, representado por una de las constantes V_ASN1_* definidas en <openssl/asn1.h>.

ASN1_TYPE_set() libera el valor contenido en a, si lo hay, y establece el valor y el tipo que ahora contiene a. Esta función utiliza el puntero value internamente, por lo que no debe liberarse después de la llamada.

ASN1_TYPE_set1() establece el tipo que contiene a en type y su valor en una copia de value. Si la copia tiene éxito, se libera el valor anterior contenido en a. Si la copia falla, a permanece sin cambios.

El tipo y el significado del argumento value de ASN1_TYPE_set() y ASN1_TYPE_set1() están determinados por el argumento type. Si type es V_ASN1_NULL, se ignora value. Si type es V_ASN1_BOOLEAN, el booleano se establece en VERDADERO si value no es NULL. Si type es V_ASN1_OBJECT, entonces value es una estructura ASN1_OBJECT. De lo contrario, type es una estructura ASN1_STRING. Si type corresponde a un tipo primitivo o un tipo de cadena, entonces el contenido de ASN1_STRING contiene los octetos de contenido del tipo. Si type corresponde a un tipo construido o un tipo etiquetado (V_ASN1_SEQUENCE, V_ASN1_SET, o V_ASN1_OTHER), entonces ASN1_STRING contiene la codificación ASN.1 completa verbatim, incluidos los octetos de etiqueta y longitud.

ASN1_TYPE_set_octetstring() asigna un nuevo objeto ASN1_OCTET_STRING, copia len bytes de data en él usando ASN1_STRING_set(3), y reemplaza el valor de a con él llamando a ASN1_TYPE_set() con un tipo de V_ASN1_OCTET_STRING.

ASN1_TYPE_get_octetstring() copia el contenido del objeto ASN1_OCTET_STRING contenido en a, pero no más de buflen bytes, en el buffer proporcionado por el llamador.

ASN1_TYPE_set_int_octetstring() libera el valor contenido en a, si lo hay, establece su tipo en V_ASN1_SEQUENCE, y establece su valor en una secuencia ASN.1 de dos elementos que consta de un objeto ASN.1 INTEGER con el valor num y un objeto ASN.1 OCTET STRING que contiene una copia de los len bytes apuntados por data.

ASN1_TYPE_get_int_octetstring() copia el valor entero del primer elemento de la secuencia ASN.1 a a *num a menos que num sea un puntero NULL y copia el valor de cadena de octetos del segundo elemento, pero no más de buflen bytes, en el buffer proporcionado por el llamador a menos que buffer sea un puntero NULL.

ASN1_TYPE_cmp() comprueba que a y b contengan el mismo tipo, el mismo valor y estén codificados de la misma manera.

Si los tipos coinciden y los valores tienen el mismo significado pero están codificados de manera diferente, se consideran diferentes. Por ejemplo, un valor booleano se representa utilizando un único octeto de contenido. Según BER, cualquier octeto distinto de cero representa el valor VERDADERO, pero ASN1_TYPE_cmp() solo informará una coincidencia si el octeto de contenido es el mismo.

NAME

ASN1_TYPE_get, ASN1_TYPE_set, ASN1_TYPE_new, ASN1_TYPE_free, ASN1_TYPE_cmp, ASN1_TYPE_get_octetstring, ASN1_TYPE_set1, ASN1_TYPE_set_octetstring, ASN1_TYPE_get_int_octetstring, ASN1_TYPE_set_int_octetstring – ASN.1 type handling

SYNOPSIS

#include <openssl/asn1.h>

ASN1_TYPE *ASN1_TYPE_new(void);

void ASN1_TYPE_free(ASN1_TYPE *a);

int ASN1_TYPE_get(const ASN1_TYPE *a);

int ASN1_TYPE_set(ASN1_TYPE *a, int type, void *value);

int ASN1_TYPE_set1(ASN1_TYPE *a, int type, const void *value);

int ASN1_TYPE_get_octetstring(const ASN1_TYPE *a, unsigned char *buffer, size_t buflen);

int ASN1_TYPE_set_octetstring(ASN1_TYPE *a, const unsigned char *buffer, size_t len);

int ASN1_TYPE_get_int_octetstring(const ASN1_TYPE *a, unsigned char *buffer, size_t buflen);

int ASN1_TYPE_set_int_octetstring(ASN1_TYPE *a, int type, const unsigned char *buffer, size_t len);

int ASN1_TYPE_cmp(const ASN1_TYPE *a, const ASN1_TYPE *b);

DESCRIPTION

The ASN1_TYPE structure is used to represent an ASN.1 value of any type. It consists of an integer type identifier and a union holding the value itself. The type identifier is one of the V_ASN1_* constants defined in <openssl/asn1.h>.

ASN1_TYPE_new() allocates and initialises a new ASN1_TYPE structure.

ASN1_TYPE_free() frees the memory associated with a.

ASN1_TYPE_get() returns the ASN.1 type of the value contained in a.

ASN1_TYPE_set() sets the type and value of a. The value argument is a pointer to the value, and its interpretation depends on the type. The caller is responsible for managing the memory of the value. If value is NULL, the type is set to V_ASN1_NULL.

ASN1_TYPE_set1() is similar to ASN1_TYPE_set(), but it duplicates the value. The caller does not need to manage the memory of the value.

ASN1_TYPE_get_octetstring() extracts the value of an ASN.1 OCTET STRING from a into the provided buffer of size buflen. It returns the number of bytes copied. If the OCTET STRING is larger than buflen, the content is truncated and the return value will be greater than buflen. If a does not contain an OCTET STRING, -1 is returned.

ASN1_TYPE_set_octetstring() sets the type of a to OCTET STRING and copies the contents of buffer with length len into it.

ASN1_TYPE_get_int_octetstring() extracts the value of an ASN.1 OCTET STRING from a SEQUENCE type in a. This is typically used for INTEGER types that are encoded as OCTET STRINGS. It copies the content into buffer of size buflen and returns the number of bytes copied. If the OCTET STRING is larger than buflen, the content is truncated and the return value will be greater than buflen. If a does not contain a SEQUENCE of the expected type or if decoding fails, -1 is returned.

ASN1_TYPE_set_int_octetstring() sets the type of a to the specified type (which should be an integer type like V_ASN1_INTEGER) and wraps the provided buffer of length len as an OCTET STRING value within a SEQUENCE.

ASN1_TYPE_cmp() compares two ASN1_TYPE structures a and b. It returns 0 if they are equal, and non-zero otherwise.

A special case arises when comparing two absent OPTIONAL fields. If both are NULL, they are considered equal. However, passing NULL values could also indicate a programming error (e.g., an unparsable type returning NULL). Therefore, applications should handle the case of two absent values separately.

RETURN VALUES

ASN1_TYPE_new() returns the new ASN1_TYPE object or NULL if an error occurs.

ASN1_TYPE_get() returns the type currently held by a or 0 if an error occurs. The latter can happen if a does not contain a value even though its type is not V_ASN1_NULL. For example, it will always happen for empty objects newly constructed with ASN1_TYPE_new().

ASN1_TYPE_set1(), ASN1_TYPE_set_octetstring(), and ASN1_TYPE_set_int_octetstring() return 1 on success or 0 on failure.

ASN1_TYPE_get_octetstring() returns the number of data bytes contained in the ASN1_OCTET_STRING object contained in a or -1 if a is not of the type V_ASN1_OCTET_STRING or does not contain any object. If the return value is greater than the buflen argument, the content was truncated when copied to the buffer.

ASN1_TYPE_get_int_octetstring() returns the number of data bytes contained in the ASN1_OCTET_STRING object that is the second element of the ASN.1 sequence a or -1 if a is not of the type V_ASN1_SEQUENCE or if decoding fails. If the return value is greater than the buflen argument, the content was truncated when copied to the buffer.

ASN1_TYPE_cmp() returns 0 for a match or non-zero for a mismatch.

HISTORY

ASN1_TYPE_new() and ASN1_TYPE_free() first appeared in SSLeay 0.5.1, ASN1_TYPE_get() and ASN1_TYPE_set() in SSLeay 0.8.0, and ASN1_TYPE_set_octetstring(), ASN1_TYPE_get_octetstring(), ASN1_TYPE_set_int_octetstring(), and ASN1_TYPE_get_int_octetstring() in SSLeay 0.9.0. These functions have been available since OpenBSD 2.4.

ASN1_TYPE_set1() first appeared in OpenSSL 0.9.8h and has been available since OpenBSD 4.5.

ASN1_TYPE_cmp() first appeared in OpenSSL 0.9.8zd, 1.0.0p, and 1.0.1k and has been available since OpenBSD 4.9.
