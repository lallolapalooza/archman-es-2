DESCRIPCIÓN

libmemcached implementa un lenguaje personalizado para configurar y modificar servidores. Al pasar una cadena de opciones, puede generar un objeto memcached_st que puede utilizar directamente en su aplicación.

Opciones generales:

--SERVER=<nombre_servidor>:<puerto_opcional>/?<peso_opcional>
Proporcionar un nombre de servidor a ser utilizado por el cliente.

Proporcionar un peso provocará el ponderado con todos los hosts, asignando un peso predeterminado de 1 a cada servidor.

--SOCKET="<ruta_archivo>/?<peso_opcional>"
Proporcionar una ruta de archivo a un archivo de socket UNIX. Proporcionar un peso provocará el ponderado con todos los hosts, asignando un peso predeterminado de 1 a cada servidor.
--VERIFICAR-CLAVE
Verificar que las claves que se están utilizando se ajustan al diseño del protocolo que se está utilizando.
--ELIMINAR-SERVIDORES-FALLIDOS
Habilitar el comportamiento MEMCACHED_BEHAVIOR_REMOVE_FAILED_SERVERS.
--PROTOCOLO-BINARIO
Forzar que todas las conexiones utilicen el protocolo binario.
--BUFFER-SOLICITUDES
Consulte MEMCACHED_BEHAVIOR_BUFFER_REQUESTS.
--ARCHIVO-CONFIGURACION=
Proporcionar un archivo de configuración a ser utilizado para cargar solicitudes. Tenga en cuenta que al utilizar un archivo de configuración, libmemcached restablecerá memcached_st basándose únicamente en la información contenida en el archivo.
--TIEMPO-ESPERA-CONEXION=
Consulte memcached_behavior_set() para MEMCACHED_BEHAVIOR_CONNECT_TIMEOUT.
--DISTRIBUCION=
Establecer el modelo de distribución utilizado por el cliente. Consulte memcached_behavior_set() para más detalles.
--HASH=
Establecer el algoritmo de hash utilizado para colocar claves en los servidores.
--HASH-CON-NAMESPACE
Cuando está habilitado, el prefijo de clave se agregará a la clave al determinar en qué servidor almacenar los datos.
--SIN-RESPUESTA
Habilita la opción "sin respuesta" para todas las llamadas que la soporten. Se recomienda encarecidamente utilizar esta opción solo con el protocolo binario.
--NÚMERO-DE-RÉPLICAS=
Establecer el número de servidores a los que se replicarán las claves.
--ALEATORIZAR-LECTURA-RÉPLICA
Seleccionar aleatoriamente el servidor dentro del grupo de replicación para leer.
--ORDENAR-HOSTS
Al agregar nuevos servidores, calcular siempre su distribución basándose en el orden de nombres ordenado.
--SOPORTE-CAS
Consulte memcached_behavior_set() para MEMCACHED_BEHAVIOR_SUPPORT_CAS
--USAR-UDP
Consulte memcached_behavior_set() para MEMCACHED_BEHAVIOR_USE_UDP
--NAMESPACE=
Un namespace es un contenedor que proporciona contexto para las claves, solo otras solicitudes que conozcan el namespace pueden acceder a estos valores. Esto se logra anteponiendo el valor del namespace a todas las claves.

Opciones del pool Memcached:

--POOL-MIN
Tamaño inicial del pool.
--POOL-MAX
Maximizar el tamaño del pool.

Opciones de E/S:

--TCP-NODELAY
Consulte memcached_behavior_set() para MEMCACHED_BEHAVIOR_TCP_NODELAY
--TCP-MANTENER-CONEXION
Consulte memcached_behavior_set() para MEMCACHED_BEHAVIOR_TCP_KEEPALIVE
--TIEMPO-ESPERA-REINTENTO=
Consulte memcached_behavior_set() para MEMCACHED_BEHAVIOR_RETRY_TIMEOUT
--LIMITE-FALLOS-SERVIDOR=
Consulte memcached_behavior_set() para MEMCACHED_BEHAVIOR_SERVER_FAILURE_LIMIT
--TIEMPO-ESPERA-ENVÍO=
Consulte memcached_behavior_set() para MEMCACHED_BEHAVIOR_SND_TIMEOUT
--TAMAÑO-RECEPCION-SOCKET=
Consulte memcached_behavior_set() para MEMCACHED_BEHAVIOR_SOCKE

NAME

memcached - configuration file parser for libmemcached

SYNOPSIS

#include <libmemcached/memcached.h>

memcached_st *memcached(const char *configuration_string, size_t configuration_string_length);

DESCRIPTION

The memcached() function takes a string containing configuration parameters and parses it to initialize a memcached_st structure. This structure is then used by the rest of the libmemcached API functions.

The configuration string is composed of a series of options separated by whitespace. Options may be prefixed with a double dash (--).

The following options are supported:

--BINARY-PROTOCOL
Enable binary protocol.
--COMPRESSION=ALGORTIHM
Enable compression with the specified algorithm (e.g. fastlz, zlib). If this is not specified, compression is disabled.
--COMPRESSION-FACTOR=FLOAT
Compression factor (0 to 9). Default is 0.
--COMPRESSION-MIN-SIZE=SIZE
Minimum size of data to compress. Default is 2048 bytes.
--DEBUG=STRING
Enable debugging. Possible values include all, allocator, time, server, parser, io, socket, watch.
--FAILURE-UNSIGNED
Disable unsigned failure.
--HASH=HASH
Set hashing algorithm. Valid values are jenkins, murmur, fnv1a_32, fnv1a_64, fnv1a_128.
--MAX-ARRAY-SIZE=SIZE
Maximum number of elements to store in a value.
--MAX-ITEM-SIZE=SIZE
Maximum size of a single item.
--MAX-KEY-SIZE=SIZE
Maximum length of a key.
--MAX-MEMBERS=NUM
Maximum number of members in a value.
--MAX-SIZE=SIZE
Maximum size of all items.
--MAX-VALUE-SIZE=SIZE
Maximum size of a value.
--NORETRY
Disable retry on failure.
--ONE-WAY
Enable one-way operations.
--POLL-TIMEOUT=MICROSECONDS
Set timeout for poll.
--RETRY-TIMEOUT=MICROSECONDS
Set timeout for retries.
--SERVER=SERVER-ADDRESS
Add a server to the pool. SERVER-ADDRESS can be of the form hostname:port or ip_address:port.
--SOCKET=SOCKET-PATH
Connect to a memcached server via a Unix socket.
--TCP-NODELAY
Enable TCP_NODELAY.
--TCP-KEEPALIVE
Enable TCP keepalive.
--UDP
Use UDP instead of TCP.
--USER-DETECT
Detect user information.
--VERIFY-KEY
Verify key.
--SOCKET-RECV-SIZE=
See memcached_behavior_set() for MEMCACHED_BEHAVIOR_SOCKET_RECV_SIZE
--SOCKET-SEND-SIZE=
See memcached_behavior_set() for MEMCACHED_BEHAVIOR_SOCKET_SEND_SIZE
--POLL-TIMEOUT=
Set the timeout used by poll(3).
--IO-BYTES-WATERMARK=
--IO-KEY-PREFETCH=
--IO-MSG-WATERMARK=
--TCP-KEEPIDLE
--RCV-TIMEOUT=

Other Options:

INCLUDE
Include a file in configuration. Unlike --CONFIGURE-FILE= this will not reset memcached_st.
RESET
Reset memcached_st and continue to process.
END
End configuration processing.
ERROR
End configuration processing and throw an error.

ENVIRONMENT

LIBMEMCACHED

RETURN VALUE

memcached() returns a pointer to the memcached_st that was created (or initialized). On an allocation failure, it returns NULL.
