BN_NEW(3) Manual de funciones de biblioteca BN_NEW(3)

NOMBRE

BN_new, BN_clear, BN_free, BN_clear_free — asignan y liberan BIGNUMs

SINOPSIS

biblioteca “libcrypto”
#include <openssl/bn.h>

BIGNUM *
BN_new(void);

void
BN_clear(BIGNUM *a);

void
BN_free(BIGNUM *a);

void
BN_clear_free(BIGNUM *a);

DESCRIPCIÓN

La biblioteca BN realiza operaciones aritméticas en enteros de tamaño arbitrario. Fue escrita para su uso en criptografía de clave pública, como RSA y Diffie-Hellman.

Utiliza asignación dinámica de memoria para almacenar sus estructuras de datos. Eso significa que no hay límite en el tamaño de los números manipulados por estas funciones, pero los valores de retorno siempre deben verificarse en caso de que ocurra un error de asignación de memoria.

El objeto básico en esta biblioteca es un BIGNUM. Se utiliza para contener un solo entero grande.

BN_new() asigna e inicializa una estructura BIGNUM, en particular estableciendo el valor a cero y los indicadores a BN_FLG_MALLOCED. El indicador relevante para la seguridad BN_FLG_CONSTTIME no se establece por defecto.

BN_clear() se utiliza para destruir datos sensibles como claves cuando ya no se necesitan. Borra la memoria utilizada por a y la establece al valor 0.

BN_free() libera los componentes del BIGNUM y, si fue creado por BN_new(), también la propia estructura. BN_clear_free() sobrescribe además los datos antes de que la memoria sea devuelta al sistema. Si a es un puntero NULL, no ocurre ninguna acción.

VALORES DE RETORNO

BN_new() devuelve un puntero al BIGNUM. Si la asignación falla, devuelve NULL y establece un código de error que se puede obtener mediante ERR_get_error(3).
