LIBGEARMAN(3) Gearmand LIBGEARMAN(3)

NOMBRE

libgearman - Documentación de Gearmand, https://gearman.org/gearmand/

SINOPSIS

#include <libgearman/gearman.h>

Enlazar -lgearman

DESCRIPCIÓN

La biblioteca cliente/trabajador de Gearman es una pequeña biblioteca cliente, segura para hilos, para el protocolo gearman. El código ha sido escrito pensando en permitir tanto el uso web como el integrado. Maneja el trabajo detrás de dirigir claves particulares a servidores específicos que usted especifica (y los valores se emparejan según el orden de los servidores que usted proporciona). Implementa ambas interfaces, la de cliente y la de trabajador.

Todas las operaciones se realizan contra un cliente, es decir, gearman_client_st o un trabajador, es decir, gearman_worker_st.

Las estructuras de cliente y trabajador pueden ser asignadas dinámicamente o estáticamente. Luego deben ser inicializadas por gearman_client_create() o gearman_worker_create().

Se han escrito funciones para encapsular todas las estructuras de la biblioteca. Se recomienda no operar directamente contra la estructura.

Casi todas las funciones devuelven un valor de tipo gearman_return_t. Este valor puede ser traducido a una cadena imprimible con gearman_strerror().

Las estructuras gearman_client_st y gearman_worker_st son seguras para hilos, pero cada hilo debe contener su propia estructura (es decir, si desea compartirlas entre hilos, debe proporcionar su propio bloqueo). No se utilizan variables globales en esta biblioteca.

Si está trabajando con GNU autotools, querrá agregar lo siguiente a su configure.ac para incluir correctamente libgearman en su aplicación.

PKG_CHECK_MODULES(DEPS, libgearman >= 0.8.0) AC_SUBST(DEPS_CFLAGS) AC_SUBST(DEPS_LIBS)

¡Esperamos que lo disfrute!

CONSTANTES

Se han proporcionado varias constantes en la biblioteca.

GEARMAN_DEFAULT_TCP_PORT

El puerto predeterminado utilizado por gearmand(3).

GEARMAN_DEFAULT_TCP_SERVICE

El servicio predeterminado utilizado por gearmand(3).

LIBGEARMAN_VERSION_STRING

Valor de cadena de la versión de libgearman, como "0.20.4"

LIBGEARMAN_VERSION_HEX

Valor hexadecimal del número de versión. "0x00048000" Esto se puede usar para comparar versiones basándose en el número.

GEARMAN_UNIQUE_SIZE

El mayor número de caracteres que se pueden usar para un valor único.

GEARMAN_JOB_HANDLE_SIZE

El mayor número de caracteres que se utilizará para un identificador de trabajo. Consulte gearman_job_handle_t para obtener información adicional.

HILOS Y PROCESOS

Al usar hilos o procesos bifurcados, es importante mantener una instancia de gearman_client_st o gearman_worker_st por proceso o hilo. Sin crear sus propias estructuras de bloqueo, no puede compartir una única gearman_client_st o gearman_worker_st.
