DESCRIPCIÓN

OCSP_RESPONSE_new() asigna e inicializa un objeto OCSP_RESPONSE vacío, que representa una estructura ASN.1 OCSPResponse definida en RFC 6960. OCSP_RESPONSE_free() libera resp.

OCSP_RESPBYTES_new() asigna e inicializa un objeto OCSP_RESPBYTES vacío, que representa una estructura ASN.1 ResponseBytes definida en RFC 6960. Dicho objeto se utiliza dentro de OCSP_RESPONSE. OCSP_RESPBYTES_free() libera respbytes.

OCSP_BASICRESP_new() asigna e inicializa un objeto OCSP_BASICRESP vacío, que representa una estructura ASN.1 BasicOCSPResponse definida en RFC 6960. OCSP_RESPBYTES contiene la forma DER codificada de un objeto OCSP_BASICRESP. OCSP_BASICRESP_free() libera bs.

OCSP_RESPDATA_new() asigna e inicializa un objeto OCSP_RESPDATA vacío, que representa una estructura ASN.1 ResponseData definida en RFC 6960. Dicho objeto se utiliza dentro de OCSP_BASICRESP. OCSP_RESPDATA_free() libera respdata.

OCSP_RESPID_new() asigna e inicializa un objeto OCSP_RESPID vacío, que representa una estructura ASN.1 ResponderID definida en RFC 6960. Dicho objeto se utiliza dentro de OCSP_RESPDATA. OCSP_RESPID_free() libera respid.

OCSP_response_create() crea un objeto OCSP_RESPONSE para status e incluyendo opcionalmente la respuesta básica bs.

OCSP_response_status() devuelve el estado de la respuesta OCSP de resp. Devuelve uno de los valores OCSP_RESPONSE_STATUS_SUCCESSFUL, OCSP_RESPONSE_STATUS_MALFORMEDREQUEST, OCSP_RESPONSE_STATUS_INTERNALERROR, OCSP_RESPONSE_STATUS_TRYLATER, OCSP_RESPONSE_STATUS_SIGREQUIRED, o OCSP_RESPONSE_STATUS_UNAUTHORIZED.

OCSP_response_status_str() convierte uno de los códigos de estado devueltos por OCSP_response_status() a una cadena de una sola palabra.

OCSP_response_get1_basic() decodifica y devuelve el objeto OCSP_BASICRESP contenido en resp. Solo se llama si el estado de una respuesta es OCSP_RESPONSE_STATUS_SUCCESSFUL.

OCSP_basic_sign() firma la respuesta OCSP bs utilizando el certificado signer, la clave privada key, el digest dgst, y los certificados adicionales certs. Si la opción flags OCSP_NOCERTS está establecida, entonces no se incluirán certificados en la solicitud. Si la opción flags OCSP_RESPID_KEY está establecida, entonces el respondedor se identifica por ID de clave en lugar de por nombre.

VALORES DEVUELTOS

OCSP_RESPONSE_new() y OCSP_response_create() devuelven un puntero a un objeto OCSP_RESPONSE o NULL si ocurrió un error.

OCSP_BASICRESP_new() y OCSP_response_get1_basic() devuelven un puntero a un objeto OCSP_BASICRESP o NULL si ocurrió un error.

OCSP_RESPBYTES_new(), OCSP_RESPDATA_new(), y OCSP_RESPID_new() devuelven un puntero a un objeto respectivo o NULL si ocurrió un error.

OCSP_response_status() devuelve un código de estado entero.

OCSP_response_status_str() devuelve una cadena que describe el código de estado.

OCSP_basic_sign() devuelve 1 si la firma fue exitosa, y 0 en caso contrario.

OCSP_RESPONSE_free(), OCSP_RESPBYTES_free(), OCSP_BASICRESP_free(), OCSP_RESPDATA_free(), y OCSP_RESPID_free() no devuelven ningún valor.

VER TAMBIÉN

OCSP_REQUEST_new(3), X509_STORE_CTX_new(3)

OCSP_response_status() devuelve un valor de estado.

OCSP_response_status_str() devuelve un puntero a una cadena estática.

OCSP_basic_sign() devuelve 1 si tiene éxito o 0 si falla.
