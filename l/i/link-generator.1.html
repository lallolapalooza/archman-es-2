LINK-GENERATOR(1) Manual de Comandos Generales LINK-GENERATOR(1)

NOMBRE

link-generator - genera frases en lenguaje natural usando Link Grammar

SINOPSIS

link-generator --help
link-generator --version

DESCRIPCIÓN

link-generator es una herramienta de línea de comandos para generar frases aleatorias cuya sintaxis está determinada por el diccionario de link-grammar especificado.

EJEMPLO

link-generator

ANTECEDENTES

La teoría de Link Grammar se explica en muchos artículos académicos. En el primero de ellos, Daniel Sleator y Davy Temperley, "Parsing English with a Link Grammar" (1991), los autores definieron un nuevo sistema gramatical formal llamado "link grammar". Una secuencia de palabras pertenece al lenguaje de una link grammar si existe una forma de dibujar "enlaces" entre las palabras de tal manera que se satisfagan los requisitos locales de cada palabra, los enlaces no se crucen y las palabras formen un grafo conexo consistente. Los autores codificaron la gramática inglesa en dicho sistema y escribieron la herramienta de línea de comandos link-parser para analizar el inglés usando esta gramática.

El motor que realiza el análisis es independiente de los diccionarios que describen un idioma. Actualmente, los diccionarios más completos y desarrollados son para los idiomas inglés y ruso, aunque existen diccionarios experimentales e incompletos para alemán y otros ocho idiomas.

VISTA GENERAL

link-generator genera frases.

OPCIONES

--help
Imprime el uso y sale.
--version
Imprime la versión del programa y los detalles de configuración, y sale.
--usage
Imprime una breve sinopsis de las opciones.
-l idioma|ubicación_dict, --language=idioma|ubicación_dict
Especifica el idioma a usar, o la ruta del archivo del directorio del diccionario a usar.
-s longitud, --length=longitud
Si longitud es 0, lee una plantilla de frase. Puede consistir en palabras completamente escritas así como comodines. El comodín \* representa cualquier palabra del diccionario. También se reconocen especificaciones de comodines como prefijo\* y \*.n.

De lo contrario, especifica la longitud de las frases a generar. Todas las frases generadas tendrán exactamente esta longitud.

-c conteo, --count=conteo
Especifica el número de frases a generar. Si este número es menor que el número de enlaces posibles, se generará un subconjunto aleatorio de enlaces posibles y se imprimirá una frase representativa para cada enlace. Las palabras de la frase representativa se eligen al azar del conjunto de palabras asociadas con cada disyunto en ese enlace. Si el conteo es mayor que el número de enlaces posibles, se imprimirá una frase representativa para cada enlace.

Si la opción -x está establecida, y si el conteo es mayor que el número de enlaces posibles, entonces se imprimirá más de una frase representativa para cada enlace. Cada frase consistirá en elecciones de palabras extraídas aleatoriamente del conjunto de palabras asociadas con cada disyunto. Se imprimirá un número aproximadamente igual de frases para cada enlace; si el conteo es lo suficientemente alto, se imprimirán todas las elecciones de palabras posibles. ¡Tenga en cuenta que esto típicamente resulta en una explosión combinatoria!

-x, --explode
Si está establecido, y el conteo es mayor que el número de enlaces posibles, entonces se imprimirán más de una frase por cada enlace. Cada frase tendrá una elección de palabra aleatoria distinta para ese enlace.
-d, --disjuncts
Muestra los disyuntos de enlace.
--no-walls
No se une a muros en palabras comodín.
-r, --random
Usa números aleatorios no repetibles.
-u, --unused
Muestra los disyuntos no utilizados.

VER TAMBIÉN

El enlace-parser es una herramienta de línea de comandos para analizar frases. Proporciona información adicional sobre la implementación de link-grammar.

La información sobre la API de la biblioteca compartida de link-grammar y los tipos de enlaces utilizados en el análisis está disponible en el sitio web de Link Grammar.

Se pueden encontrar artículos revisados por pares que explican Link Grammar en el sitio original de CMU.

El código fuente de link-generator y la biblioteca de link-grammar se encuentra en GitHub.

La lista de correo para la discusión de Link Grammar está en grupo de Google link-grammar.
