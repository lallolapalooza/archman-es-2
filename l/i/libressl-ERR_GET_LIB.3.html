ERR_GET_LIB(3) Manual de funciones de la biblioteca ERR_GET_LIB(3)

NOMBRE

ERR_GET_LIB, ERR_GET_FUNC, ERR_GET_REASON, ERR_FATAL_ERROR — obtener códigos de biblioteca, función y razón para errores de OpenSSL

SINOPSIS

biblioteca «libcrypto»
#include <openssl/err.h>

int
ERR_GET_LIB(unsigned long e);

int
ERR_GET_FUNC(unsigned long e);

int
ERR_GET_REASON(unsigned long e);

int
ERR_FATAL_ERROR(unsigned long e);

DESCRIPCIÓN

El código de error devuelto por ERR_get_error(3) consta de un número de biblioteca, un código de función y un código de razón. ERR_GET_LIB(), ERR_GET_FUNC(), y ERR_GET_REASON() se pueden usar para extraerlos.

El número de biblioteca y el código de función describen dónde ocurrió el error, mientras que el código de razón es la información sobre qué salió mal.

Cada sub-biblioteca de OpenSSL tiene un número de biblioteca único; los códigos de función y razón son únicos dentro de cada sub-biblioteca. Tenga en cuenta que diferentes bibliotecas pueden usar el mismo valor para indicar diferentes funciones y razones.

ERR_R_* los códigos de razón como ERR_R_MALLOC_FAILURE son globalmente únicos. Sin embargo, al comprobar los códigos de razón específicos de la sub-biblioteca, asegúrese de comparar también el número de biblioteca.

ERR_FATAL_ERROR() indica si un código de error dado es un error fatal.

Estas funciones están implementadas como macros.

VALORES DE RETORNO

ERR_GET_LIB(), ERR_GET_FUNC(), y ERR_GET_REASON() devuelven el número de biblioteca, el código de función y el código de razón, respectivamente.

ERR_FATAL_ERROR() devuelve un valor distinto de cero si el error es fatal o 0 en caso contrario.

VER TAMBIÉN

ERR(3), ERR_get_error(3)

HISTORIA

ERR_GET_LIB(), ERR_GET_FUNC(), ERR_GET_REASON(), y ERR_FATAL_ERROR() aparecieron por primera vez en SSLeay 0.4.4 y han estado disponibles desde OpenBSD 2.4.
