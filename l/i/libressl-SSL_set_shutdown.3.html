libressl-SSL_set_shutdown(3)

Paquete: libressl

Licencias: ISC, custom:OpenSSL

SSL_SET_SHUTDOWN(3) Manual de funciones de biblioteca SSL_SET_SHUTDOWN(3)

NOMBRE

SSL_set_shutdown, SSL_get_shutdown — manipular el estado de cierre de una conexión SSL

SINOPSIS

biblioteca “libssl” libcrypto
#include <openssl/ssl.h>

void
SSL_set_shutdown(SSL *ssl, int mode);

int
SSL_get_shutdown(const SSL *ssl);

DESCRIPCIÓN

SSL_set_shutdown() establece el estado de cierre de ssl a mode.

SSL_get_shutdown() devuelve el modo de cierre de ssl.

El estado de cierre de una conexión ssl es una máscara de bits de:

0
Ningún ajuste de cierre, todavía.
SSL_SENT_SHUTDOWN
Se envió una alerta de cierre de “notificación de cierre” al par; la conexión se considera cerrada y la sesión está cerrada y correcta.
SSL_RECEIVED_SHUTDOWN
Se recibió una alerta de cierre del par, ya sea una “notificación de cierre” normal o un error fatal.

SSL_SENT_SHUTDOWN y SSL_RECEIVED_SHUTDOWN pueden establecerse al mismo tiempo.

El estado de cierre de la conexión se utiliza para determinar el estado de la sesión ssl. Si la sesión todavía está abierta cuando se llama a SSL_clear(3) o SSL_free(3), se considera incorrecta y se elimina de acuerdo con RFC 2246. La condición real para una sesión cerrada correctamente es SSL_SENT_SHUTDOWN (según el RFC de TLS, es aceptable solo enviar la alerta de “notificación de cierre” pero no esperar la respuesta del par cuando la conexión subyacente está cerrada). SSL_set_shutdown() se puede usar para establecer este estado sin enviar una alerta de cierre al par (ver SSL_shutdown(3)).

Si se recibió una “notificación de cierre”, se establecerá SSL_RECEIVED_SHUTDOWN, pero para establecer SSL_SENT_SHUTDOWN, la aplicación aún debe llamar a SSL_shutdown(3) o a SSL_set_shutdown() ella misma.

VALORES DE RETORNO

SSL_get_shutdown() devuelve la configuración actual.

VER TAMBIÉN

ssl(3), SSL_clear(3), SSL_CTX_set_quiet_shutdown(3), SSL_free(3), SSL_shutdown(3)

HISTORIA

SSL_set_shutdown() y SSL_get_shutdown() aparecieron por primera vez en SSLeay 0.8.0 y han estado disponibles desde OpenBSD 2.4.
