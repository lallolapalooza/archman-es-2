libressl-SSL_CTX_set_keylog_callback(3)

Paquete: libressl

Licencias: ISC, custom:OpenSSL

SSL_CTX_SET_KEYLOG_CALLBACK(3) Manual de Funciones de Biblioteca SSL_CTX_SET_KEYLOG_CALLBACK(3)

NOMBRE

SSL_CTX_set_keylog_callback, SSL_CTX_get_keylog_callback — establecer y obtener la devolución de llamada no utilizada para el registro de claves

SINOPSIS

biblioteca “libssl” libcrypto
#include <openssl/ssl.h>

typedef void
(*SSL_CTX_keylog_cb_func)(const SSL *ssl, const char *line);

void
SSL_CTX_set_keylog_callback(SSL_CTX *ctx, SSL_CTX_keylog_cb_func cb);

SSL_CTX_keylog_cb_func
SSL_CTX_get_keylog_callback(const SSL_CTX *ctx);

DESCRIPCIÓN

SSL_CTX_set_keylog_callback() establece la devolución de llamada para el registro de claves TLS. Esta devolución de llamada nunca se llama en LibreSSL.

SSL_CTX_get_keylog_callback() recupera la devolución de llamada de registro de claves TLS establecida previamente.

Estas funciones se proporcionan solo por compatibilidad con OpenSSL.

VALORES DE RETORNO

SSL_CTX_get_keylog_callback() devuelve la devolución de llamada de registro de claves TLS previamente establecida, o NULL si no se ha establecido ninguna devolución de llamada.

VEA TAMBIÉN

ssl(3), SSL_CTX_new(3)

HISTORIA

Estas funciones aparecieron por primera vez en OpenSSL 1.1.1 y han estado disponibles desde OpenBSD 7.1.
