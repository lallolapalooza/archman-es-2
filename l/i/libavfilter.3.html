NOMBRE

libavfilter - biblioteca de filtrado multimedia

DESCRIPCIÓN

La biblioteca libavfilter proporciona un marco genérico de filtrado de audio/vídeo que contiene varios filtros, fuentes y sumideros.

VER TAMBIÉN

ffmpeg(1), ffplay(1), ffprobe(1), ffmpeg-filters(1), libavutil(3), libswscale(3), libswresample(3), libavcodec(3), libavformat(3), libavdevice(3)

AUTORES

Los desarrolladores de FFmpeg.

Para obtener detalles sobre la autoría, consulte el historial de Git del proyecto (https://git.ffmpeg.org/ffmpeg), por ejemplo, escribiendo el comando git log en el directorio de origen de FFmpeg, o navegando por el repositorio en línea en https://git.ffmpeg.org/ffmpeg.

Los mantenedores de los componentes específicos se enumeran en el archivo MAINTAINERS en el árbol de código fuente.
