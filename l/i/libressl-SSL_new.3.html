libressl-SSL_new(3)

Paquete: libressl

Licencias: ISC, custom:OpenSSL

SSL_NEW(3) Manual de funciones de la biblioteca SSL_NEW(3)

NOMBRE

SSL_new, SSL_up_ref — crea una nueva estructura SSL para una conexión

SINOPSIS

biblioteca “libssl” libcrypto
#include <openssl/ssl.h>

SSL *
SSL_new(SSL_CTX *ctx);

int
SSL_up_ref(SSL *ssl);

DESCRIPCIÓN

SSL_new() crea una nueva estructura SSL que se necesita para almacenar los datos de una conexión TLS/SSL. La nueva estructura hereda la configuración del contexto subyacente ctx: método de conexión, opciones, configuraciones de verificación, configuraciones de tiempo de espera, nivel de seguridad. El contador de referencias de la nueva estructura se establece en 1.

SSL_up_ref() incrementa el contador de referencias de ssl en 1.

VALORES DE RETORNO

Los siguientes valores de retorno pueden ocurrir:

NULL
La creación de una nueva estructura SSL falló. Compruebe la pila de errores para averiguar el motivo.
Puntero a una estructura SSL estructura
El valor de retorno apunta a una estructura SSL asignada.

SSL_up_ref() devuelve 1 en caso de éxito o 0 en caso de fallo.

VER TAMBIÉN

ssl(3), SSL_clear(3), SSL_CTX_set_options(3), SSL_CTX_set_security_level(3), SSL_free(3), SSL_get_SSL_CTX(3)

HISTORIA

SSL_new() apareció en SSLeay 0.4 o anterior y ha estado disponible desde OpenBSD 2.4.

SSL_up_ref() apareció por primera vez en OpenSSL 1.1.0 y ha estado disponible desde OpenBSD 6.3.
