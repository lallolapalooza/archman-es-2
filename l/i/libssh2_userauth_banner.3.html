NOMBRE

libssh2_userauth_banner - obtener el mensaje de banner de autenticación de usuario del servidor

SINOPSIS

#include <libssh2.h>
int
libssh2_userauth_banner(LIBSSH2_SESSION *session, char **banner);

DESCRIPCIÓN

session - Instancia de sesión devuelta por libssh2_session_init_ex(3)

banner - Debe apuntar a un puntero que se llenará con el mensaje del banner.

Después de que se haya intentado una autenticación, como una solicitud **SSH_USERAUTH_NONE** enviada por libssh2_userauth_list(3), esta función puede ser llamada para recuperar el banner de autenticación de usuario enviado por el servidor. Si no se envía ningún banner de este tipo, o si aún no se ha intentado una autenticación, devuelve LIBSSH2_ERROR_MISSING_USERAUTH_BANNER.

VALOR DE RETORNO

En caso de éxito, devuelve 0 y una cadena terminada en NUL codificada en UTF-8 se almacena en *banner*. Esta cadena es administrada internamente por libssh2 y se liberará al finalizar la sesión. En caso de fallo, devuelve LIBSSH2_ERROR_MISSING_USERAUTH_BANNER.

VER TAMBIÉN

libssh2_session_init_ex(3), libssh2_userauth_list(3)
