ICONV_CLOSE(3) Manual de funciones de biblioteca ICONV_CLOSE(3)

NOMBRE

iconv_close - libera el descriptor para la conversión de conjuntos de caracteres

SINOPSIS

#include <iconv.h>

int iconv_close (iconv_t cd);

DESCRIPCIÓN

La función iconv_close libera un descriptor de conversión cd previamente asignado usando iconv_open.

VALOR DE RETORNO

Si tiene éxito, la función iconv_close devuelve 0. En caso de error, establece errno y devuelve -1.

CONFORMIDAD

POSIX:2024
