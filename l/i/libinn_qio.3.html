NOMBRE

qio - Rutinas de I/O rápido para leer archivos

SINOPSIS

#include <inn/qio.h>
QIOSTATE *QIOopen(const char *name);
QIOSTATE *QIOfdopen(int fd);
void QIOclose(QIOSTATE *qp);
char *QIOread(QIOSTATE *qp);
int QIOfileno(QIOSTATE *qp);
size_t QIOlength(QIOSTATE *qp);
int QIOrewind(QIOSTATE *qp);
off_t QIOtell(QIOSTATE *qp);
bool QIOerror(QIOSTATE *qp);
bool QIOtoolong(QIOSTATE *qp);

DESCRIPCIÓN

Las rutinas descritas en esta página del manual son parte de libinn(3). Se utilizan para proporcionar acceso de lectura rápido a archivos; las rutinas QIO utilizan buffering adaptado al tamaño de bloque del dispositivo, similar a stdio, pero con una sintaxis más conveniente para leer líneas terminadas en nueva línea. QIO es la abreviatura de "Quick I/O" (un nombre un poco engañoso, ya que QIO proporciona acceso de solo lectura a archivos únicamente).

La estructura QIOSTATE devuelta por QIOopen y QIOfdopen es el análogo a la estructura FILE de stdio y debe ser tratada como una caja negra por todos los usuarios de estas rutinas. Solo la API anterior debe ser utilizada.

QIOopen abre el archivo dado para lectura con un tamaño de buffer de 32KiB. Devuelve un puntero para usar en llamadas posteriores, o NULL en caso de error. QIOfdopen realiza la misma operación excepto en un descriptor de archivo ya abierto (fd debe designar un archivo abierto para lectura).

QIOclose cierra el archivo abierto y libera cualquier recurso utilizado por la estructura QIOSTATE. El puntero QIOSTATE no debe ser utilizado de nuevo después de haber sido pasado a esta función.

QIOread lee la siguiente línea terminada en nueva línea en el archivo y devuelve un puntero a ella, con la nueva línea final reemplazada por un nulo. El puntero devuelto es un puntero dentro de un buffer en el objeto QIOSTATE y por lo tanto seguirá siendo válido hasta que se llame a QIOclose en ese objeto. Si se alcanza el fin de archivo (EOF), ocurre un error, o si la línea es más larga que el tamaño del buffer (32KiB), se devuelve NULL en su lugar. Para distinguir entre los casos de error, use QIOerror y QIOtoolong.

QIOfileno devuelve el descriptor del archivo abierto.

QIOlength devuelve la longitud en bytes de la última línea devuelta por QIOread. Su valor de retorno solo está definido después de una llamada exitosa a QIOread.

QIOrewind establece el puntero de lectura al principio del archivo y lee el primer bloque del archivo en previsión de lecturas futuras. Devuelve 0 si tiene éxito y -1 en caso de error.

QIOtell devuelve el valor actual del puntero de lectura (el desplazamiento de lseek(2) en el que comenzará la siguiente línea).

QIOerror devuelve verdadero si hubo un error en la última llamada a QIOread, falso en caso contrario. QIOtoolong devuelve verdadero si hubo un error y el error fue que la línea era demasiado larga. Si QIOread devuelve NULL, estas funciones deben ser llamadas para determinar lo que sucedió. Si QIOread devolvió NULL y QIOerror es falso, se alcanzó el fin de archivo (EOF). Tenga en cuenta que si QIOtoolong devuelve verdadero, la siguiente llamada a QIOread intentará leer el resto de la línea y probablemente devolverá una línea parcial; los usuarios de esta biblioteca generalmente deben tratar las líneas largas como errores fatales.

EJEMPLOS

Este bloque de código abre /etc/motd y lo lee línea por línea, imprimiendo cada línea precedida por su desplazamiento en el archivo.

QIOSTATE *qp;
off_t offset;
char *p;
qp = QIOopen("/etc/motd");
if (qp == NULL) {
    perror("Error de apertura");
    exit(1);
}
for (p = QIOread(qp); p != NULL; p = QIOread(qp))
    printf("%ld: %s\n", (unsigned long) QIOtell(qp), p);
if (QIOerror(qp)) {
    perror("Error de lectura");
    exit(1);
}
QIOclose(qp);
