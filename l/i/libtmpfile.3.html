NOMBRE

pm_tmpfile() - crear un archivo temporal sin nombre

SINOPSIS

#include <netpbm/pm.h>
FILE *
pm_tmpfile(void);

EJEMPLO

Este simple ejemplo crea un archivo temporal, le escribe 'hola mundo' y luego lo lee para imprimir ese contenido.

#include <netpbm/pm.h>
FILE * myfileP;
myfile = pm_tmpfile();
fprintf(myfile, 'hola mundo\n');
fseek(myfileP, 0, SEEK_SET);
fread(buffer, sizeof(buffer), 1, myfileP);
fprintf(STDOUT, 'el archivo temporal contiene '%s'\n', buffer);
fclose(myfileP);

DESCRIPCIÓN

Esta función de biblioteca es parte de Netpbm(1)

pm_tmpfile() crea y abre un archivo temporal sin nombre. Es básicamente lo mismo que la función tmpfile() de la biblioteca C estándar, excepto que utiliza la variable de entorno TMPFILE para decidir dónde crear el archivo temporal. Si TMPFILE no está configurada o está configurada con algo inutilizable (por ejemplo, demasiado largo), pm_tmpfile() recurre al valor del símbolo de la biblioteca C estándar P_tmpdir, al igual que tmpfile().

A diferencia de tmpfile(), pm_tmpfile() nunca devuelve NULL. Si falla, emite un mensaje en la salida estándar de error y aborta el programa, como la mayoría de las rutinas de libnetpbm.

Si necesita referirse al archivo temporal por nombre, utilice pm_make_tmpfile() en su lugar.

HISTORIAL

pm_tmpfile() se introdujo en Netpbm 10.20 (enero 2004).
