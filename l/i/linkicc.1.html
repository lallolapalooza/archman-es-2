linkicc(1)

Paquete: lcms2

Licencias: MIT

LINKICC(1) Manual de comandos generales LINKICC(1)

NOMBRE

linkicc - generador de enlaces de dispositivo little cms.

SINOPSIS

linkicc [opciones] perfiles

DESCRIPCIÓN

lcms es un motor CMM independiente que se ocupa de la gestión del color. Implementa una transformación rápida entre perfiles ICC. linkicc es un generador de enlaces de dispositivo little cms.

Une dos o más perfiles en un único perfil de enlace de dispositivo. Los espacios de color deben coincidir, excepto Lab/XYZ, que pueden intercambiarse.

OPCIONES

-a NUM
Estado de adaptación del observador (solo col. abs.), (0..1.0, valor flotante) [por defecto es 1.0].
-b
Compensación de punto negro.
-c precisión
Precisión (0=Baja resolución, 1=Normal, 2=Alta resolución) [por defecto es 1].
-d descripción
Texto de descripción (se pueden usar comillas).
-h NUM
Muestra un resumen de opciones y ejemplos (0=ayuda, 1=Perfiles integrados, 2=Ejemplos, 3=Información de contacto)
-k límite_tinta
Límite de tinta en % (solo CMYK), (0..400.0, valor flotante) [por defecto 400.0].
-l
Usa curvas de linealización (puede afectar la precisión).
-n puntos_red
Forma alternativa de establecer la precisión, número de puntos CLUT.
-o perfil
Perfil de enlace de dispositivo de salida [por defecto es 'devicelink.icm'].
-r versión_perfil
Versión del perfil. (PRECAUCIÓN: puede cambiar la implementación del perfil), (2.0..4.3, valor flotante) [por defecto es 4.3].
-t NUM
Intención de renderizado
0=Perceptual [por defecto]
1=Colorimétrico relativo
2=Saturación
3=Colorimétrico absoluto
10=Perceptual preservando tinta negra
11=Colorimétrico relativo preservando tinta negra
12=Saturación preservando tinta negra
13=Perceptual preservando plano negro
14=Colorimétrico relativo preservando plano negro
15=Saturación preservando plano negro
-v nivel_verbosidad
Nivel de verbosidad, (0=Ninguno, 1=Normal, 2=Alto, 3=Muy alto) [por defecto es 0].
-x
Creativamente, adivina la clase de dispositivo del perfil resultante.
-y derechos_autor
Aviso de derechos de autor (se pueden usar comillas) ["Sin derechos de autor, úselo libremente"].
-8
Crea enlace de dispositivo de 8 bits.

PERFILES INTEGRADOS

*Lab2  -- CIEL*a*b v2 basado en D50
*Lab4  -- CIEL*a*b v4 basado en D50
*Lab   -- CIEL*a*b v4 basado en D50
*XYZ   -- CIE XYZ (PCS)
*sRGB  -- Espacio de color sRGB
*Gray22 - Monocromo de Gamma 2.2
*Gray30 - Monocromo de Gamma 3.0
*null   - Negro monocromo para toda la entrada
*Lin2222- Linealización CMYK de gamma 2.2 en cada canal

EJEMPLOS

Para crear 'devicelink.icm' a partir de a.icc a b.icc:
	linkicc a.icc b.icc
Para crear 'out.icc' de sRGB a cmyk.icc:
	linkicc -o out.icc *sRGB cmyk.icc
Para crear un perfil de entrada sRGB que trabaje en Lab:
	linkicc -x -o sRGBLab.icc *sRGB *Lab
Para crear un perfil de salida XYZ -> sRGB:
	linkicc -x -o sRGBLab.icc *XYZ *sRGB
Para crear un perfil abstracto que realice una simulación de sobreimpresión para cmyk.icc:
	linkicc -t1 -x -o softproof.icc *Lab cmyk.icc cmyk.icc *Lab
Para crear un sRGB de entrada 'más gris':
	linkicc -x -o grayer.icc *sRGB gray.icc gray.icc *Lab
Para incrustar el límite de tinta en un perfil de salida CMYK:
	linkicc -x -o cmyklimited.icc -k 250 cmyk.icc *Lab
