libressl-SSL_free(3)

Paquete: libressl

Licencias: ISC, custom:OpenSSL

SSL_FREE(3) Manual de funciones de biblioteca SSL_FREE(3)

NOMBRE

SSL_free — liberar una estructura SSL asignada

SINOPSIS

biblioteca “libssl” libcrypto
#include <openssl/ssl.h>

void
SSL_free(SSL *ssl);

DESCRIPCIÓN

SSL_free() decrementa el contador de referencias de ssl, y elimina la estructura SSL apuntada por ssl y libera la memoria asignada si el contador de referencias ha llegado a 0. Si ssl es un puntero NULL, no ocurre ninguna acción.

SSL_free() también llama a los procedimientos de free(3) para elementos afectados indirectamente, si procede: el búfer BIO, los BIO de lectura y escritura, listas de cifrado creadas especialmente para este ssl, la SSL_SESSION. No libere explícitamente estos elementos liberados indirectamente antes o después de llamar a SSL_free(), ya que intentar liberar cosas dos veces puede provocar fallos en el programa.

La sesión ssl tiene contadores de referencias de dos usuarios: el objeto SSL, para el cual el contador de referencias es eliminado por SSL_free() y la caché de sesiones interna. Si la sesión se considera errónea, porque no se llamó a SSL_shutdown(3) para la conexión y no se usó SSL_set_shutdown(3) para establecer el estado SSL_SENT_SHUTDOWN, la sesión también se eliminará de la caché de sesiones según lo requerido por RFC 2246.

VER TAMBIÉN

ssl(3), SSL_clear(3), SSL_new(3), SSL_set_shutdown(3), SSL_shutdown(3)

HISTORIAL

SSL_free() apareció en SSLeay 0.4 o anterior y ha estado disponible desde OpenBSD 2.4.
