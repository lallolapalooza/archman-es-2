NOMBRE

libnbd-security - información sobre problemas de seguridad pasados en libnbd

DESCRIPCIÓN

Esta página detalla problemas de seguridad pasados encontrados en libnbd.

Para saber cómo informar sobre nuevos problemas de seguridad, consulte el archivo "SECURITY" en el directorio raíz del código fuente, también disponible aquí en línea: https://gitlab.com/nbdkit/libnbd/blob/master/SECURITY

CVE-2019-14842 ataque de degradación de protocolo al usar "LIBNBD_TLS_REQUIRE"

Vea el anuncio completo y los enlaces a la mitigación, pruebas y correcciones aquí: https://www.redhat.com/archives/libguestfs/2019-September/msg00128.html

vulnerabilidad de ejecución remota de código

Vea el anuncio completo aquí: https://www.redhat.com/archives/libguestfs/2019-October/msg00060.html

CVE-2021-20286 denegación de servicio al usar nbd_set_opt_mode(3)

Vea el anuncio completo aquí: https://listman.redhat.com/archives/libguestfs/2021-March/msg00092.html

CVE-2022-0485 corrupción silenciosa de datos al usar nbdcopy(1)

Vea el anuncio completo aquí: https://listman.redhat.com/archives/libguestfs/2022-February/msg00104.html

denegación de servicio de pruebas de integración con estado de bloque

Vea el anuncio completo aquí: https://listman.redhat.com/archives/libguestfs/2023-July/032035.html

CVE-2023-5215 resultado de tamaño negativo de nbd_get_size(3)

Vea el anuncio completo aquí: https://listman.redhat.com/archives/libguestfs/2023-September/032711.html

CVE-2023-5871 fallo de aserción para flags de 64 bits pasados a nbd_block_status(3)

Vea el anuncio completo aquí: https://lists.libguestfs.org/archives/list/guestfs@lists.libguestfs.org/thread/5CRC7LRTN35WPZZ4BT6NAMH4JGMF47IK/

CVE-2024-7383 múltiples fallos en la verificación del certificado del servidor TLS

Vea el anuncio completo aquí: https://lists.libguestfs.org/archives/list/guestfs@lists.libguestfs.org/thread/LHR3BW6RJ7K4BJBQIYV3GTZLSY27VZO2/
