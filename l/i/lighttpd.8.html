NOMBRE

lighttpd - un servidor web rápido, seguro y flexible

SINOPSIS

lighttpd [-ptDvVh] -f archivo de configuración [-m directorio de módulos]

DESCRIPCIÓN

lighttpd (pronunciado 'lighty') es un demonio HTTP avanzado que tiene como objetivo ser seguro, rápido, compatible y muy flexible. Ha sido optimizado para un alto rendimiento. Su conjunto de características incluye, entre otras, FastCGI, CGI, autenticación HTTP básica y digest, compresión de salida, reescritura de URL.

Esta página del manual solo enumera los argumentos de la línea de comandos. Para obtener detalles sobre cómo configurar lighttpd y sus módulos, consulte los archivos en el directorio de documentación.

OPCIONES

Se admiten las siguientes opciones:

-f  archivo de configuración
Carga el archivo de configuración archivo de configuración. Opcionalmente, use -f - para leer la configuración desde la entrada estándar; -f - es incompatible con -1.
-m  directorio de módulos
Use directorio de módulos como el directorio que contiene los módulos, en lugar del predeterminado.
-p
Imprime el archivo de configuración analizado en su forma interna y sale.
-t
Comprueba si el archivo de configuración tiene errores de sintaxis y sale.
-tt
Comprueba si el archivo de configuración tiene errores de sintaxis, carga e inicializa módulos y sale.
-D
No demonizar (no pasar a segundo plano). El valor predeterminado es demonizar.
-i  secs
Activa el apagado gradual del demonio después de secs de inactividad.
-1
Procesa una sola solicitud (una) en el socket de entrada estándar y luego sale.
-v
Muestra la versión y sale.
-V
Muestra las características de compilación y sale.
-h
Muestra un breve mensaje de ayuda y sale.

ARCHIVOS

/etc/lighttpd/lighttpd.conf
La ubicación estándar para el archivo de configuración.
/run/lighttpd.pid
La ubicación estándar para el PID del proceso lighttpd en ejecución.
