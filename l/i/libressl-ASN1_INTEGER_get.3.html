DESCRIPCIÓN

Estas funciones convierten objetos ASN1_INTEGER y ASN1_ENUMERATED hacia y desde otros tipos.

ASN1_INTEGER_get_uint64() y ASN1_INTEGER_get_int64() almacenan el valor de a en *out_val si tienen éxito.

La función obsoleta ASN1_INTEGER_get() convierte a al tipo long.

ASN1_INTEGER_set_uint64(), ASN1_INTEGER_set_int64(), y ASN1_INTEGER_set() establecen el tipo de a a V_ASN1_INTEGER o V_ASN1_NEG_INTEGER dependiendo del signo de v y establecen el valor de a a v.

ASN1_INTEGER_cmp() compara los números enteros con signo representados por a1 y a2.

ASN1_INTEGER_dup() hace exactamente lo mismo que ASN1_STRING_dup(3) sin proporcionar ninguna seguridad de tipo, excepto que falla si la ASN1_STRING_length(3) de a es 0.

BN_to_ASN1_INTEGER() convierte bn a un ASN1_INTEGER. Si ai es NULL, se devuelve un nuevo objeto ASN1_INTEGER. De lo contrario, se usa el objeto existente ai

ASN1_INTEGER_to_BN() convierte ai en un BIGNUM. Si bn es NULL, se devuelve un nuevo objeto BIGNUM. De lo contrario, se usa el objeto existente bn.

ASN1_ENUMERATED_get_int64(), ASN1_ENUMERATED_get(), ASN1_ENUMERATED_set_int64(), ASN1_ENUMERATED_set(), BN_to_ASN1_ENUMERATED(), y ASN1_ENUMERATED_to_BN() se comportan como sus contrapartes ASN1_INTEGER excepto que operan sobre un objeto ASN1_ENUMERATED.

VALORES DE RETORNO

ASN1_INTEGER_get_uint64() devuelve 1 en caso de éxito o 0 si a no es del tipo V_ASN1_INTEGER o es mayor que UINT64_MAX.

ASN1_INTEGER_get_int64() devuelve 1 en caso de éxito o 0 si a no es del tipo V_ASN1_INTEGER o V_ASN1_NEG_INTEGER, es menor que INT64_MIN o mayor que INT64_MAX.

ASN1_INTEGER_get() y ASN1_ENUMERATED_get() devuelven el valor convertido, 0 si a es NULL, o -1 en caso de error, lo cual es ambiguo porque -1 es un valor legítimo para un ASN1_INTEGER.

ASN1_INTEGER_set_uint64(), ASN1_INTEGER_set_int64(), ASN1_INTEGER_set(), ASN1_ENUMERATED_set_int64(), y ASN1_ENUMERATED_set() devuelven 1 para éxito o 0 para fallo. Solo fallan si ocurre un error de asignación de memoria.

ASN1_INTEGER_cmp() devuelve un valor mayor que, igual a, o menor que 0 si el número entero con signo representado por a es mayor que, igual a, o menor que el número entero con signo representado por a2, respectivamente.

ASN1_INTEGER_dup() devuelve un puntero a una copia duplicada de a, o NULL en caso de error.

BN_to_ASN1_INTEGER() y BN_to_ASN1_ENUMERATED() devuelven el puntero ai si tienen éxito, o NULL en caso de error.

ASN1_INTEGER_to_BN() y ASN1_ENUMERATED_to_BN() devuelven el puntero bn si tienen éxito, o NULL en caso de error.

DIAGNÓSTICOS

Las funciones que pueden fallar, como las que asignan memoria, devuelven NULL o 0 en caso de error.

VER TAMBIÉN

ASN1_STRING_get_object(3), ASN1_INTEGER_print(3), BN_new(3)

ASN1_INTEGER_get(3) — libressl — Arch Linux

NAME

ASN1_INTEGER_get, ASN1_INTEGER_set, ASN1_INTEGER_cmp, ASN1_INTEGER_dup, ASN1_INTEGER_get_uint64, ASN1_INTEGER_get_int64, ASN1_INTEGER_set_uint64, ASN1_INTEGER_set_int64, ASN1_ENUMERATED_get, ASN1_ENUMERATED_set, ASN1_ENUMERATED_get_int64, ASN1_ENUMERATED_set_int64, BN_to_ASN1_INTEGER, BN_to_ASN1_ENUMERATED, ASN1_INTEGER_to_BN, ASN1_ENUMERATED_to_BN - ASN.1 INTEGER y ENUMERATED

SYNOPSIS

#include <openssl/asn1.h>
#include <openssl/bn.h>

long ASN1_INTEGER_get(const ASN1_INTEGER *a);
long ASN1_ENUMERATED_get(const ASN1_ENUMERATED *a);

int ASN1_INTEGER_set(ASN1_INTEGER *a, long v);
int ASN1_ENUMERATED_set(ASN1_ENUMERATED *a, long v);

int ASN1_INTEGER_set_uint64(ASN1_INTEGER *a, uint64_t v);
int ASN1_INTEGER_set_int64(ASN1_INTEGER *a, int64_t v);
int ASN1_ENUMERATED_set_int64(ASN1_ENUMERATED *a, int64_t v);

int ASN1_INTEGER_get_uint64(uint64_t *pt, const ASN1_INTEGER *a);
int ASN1_INTEGER_get_int64(int64_t *pt, const ASN1_INTEGER *a);
int ASN1_ENUMERATED_get_int64(int64_t *pt, const ASN1_ENUMERATED *a);

int ASN1_INTEGER_cmp(const ASN1_INTEGER *a2, const ASN1_INTEGER *a1);
ASN1_INTEGER *ASN1_INTEGER_dup(const ASN1_INTEGER *a);
ASN1_INTEGER *BN_to_ASN1_INTEGER(const BIGNUM *bn, ASN1_INTEGER *a);
ASN1_ENUMERATED *BN_to_ASN1_ENUMERATED(const BIGNUM *bn, ASN1_ENUMERATED *a);
BIGNUM *ASN1_INTEGER_to_BN(const ASN1_INTEGER *a, BIGNUM *bn);
BIGNUM *ASN1_ENUMERATED_to_BN(const ASN1_ENUMERATED *a, BIGNUM *bn);

DESCRIPTION

These functions handle ASN.1 INTEGER and ENUMERATED types.

ASN1_INTEGER_get() and ASN1_ENUMERATED_get() return the value of the ASN.1 INTEGER or ENUMERATED a as a C long. They are intended for values that fit within a C long. If the value does not fit, the behaviour is undefined.

ASN1_INTEGER_set() and ASN1_ENUMERATED_set() set the ASN.1 INTEGER or ENUMERATED a to the value specified by the C long v.

ASN1_INTEGER_set_uint64() and ASN1_INTEGER_set_int64() set the ASN.1 INTEGER a to the value specified by the C uint64_t or int64_t v, respectively. ASN1_ENUMERATED_set_int64() sets the ASN.1 ENUMERATED a to the value specified by the C int64_t v.

ASN1_INTEGER_get_uint64() attempts to get the value of the ASN.1 INTEGER a as a C uint64_t. The value is stored in pt. ASN1_INTEGER_get_int64() attempts to get the value as a C int64_t. ASN1_ENUMERATED_get_int64() attempts to get the value as a C int64_t.

ASN1_INTEGER_cmp() compares the signed integer number represented by a1 with the signed integer number represented by a2. It returns a value greater than, equal to, or less than 0, if a1 is greater than, equal to, or less than a2, respectively.

ASN1_INTEGER_dup() returns a pointer to a newly allocated ASN1_STRING structure or NULL if a is a NULL pointer, if the length of a is 0, or if memory allocation fails.

BN_to_ASN1_INTEGER() and BN_to_ASN1_ENUMERATED() return an ASN1_INTEGER or ASN1_ENUMERATED object, respectively, or NULL if an error occurs. They only fail due to memory allocation errors.

ASN1_INTEGER_to_BN() and ASN1_ENUMERATED_to_BN() return a BIGNUM object of NULL if an error occurs. They can fail if the passed type is incorrect (due to a programming error) or due to memory allocation failures.

SEE ALSO

ASN1_INTEGER_new(3), ASN1_STRING_length(3)

HISTORY

ASN1_INTEGER_set() first appeared in SSLeay 0.5.1. ASN1_INTEGER_get(), BN_to_ASN1_INTEGER(), and ASN1_INTEGER_to_BN() first appeared in SSLeay 0.6.0. ASN1_INTEGER_cmp() and ASN1_INTEGER_dup() first appeared in SSLeay 0.6.5. These functions have been available since OpenBSD 2.3.

ASN1_ENUMERATED_get(), ASN1_ENUMERATED_set(), BN_to_ASN1_ENUMERATED(), and ASN1_ENUMERATED_to_BN() first appeared in OpenSSL 0.9.2b and have been available since OpenBSD 2.6.

ASN1_INTEGER_get_uint64(), ASN1_INTEGER_get_int64(), ASN1_INTEGER_set_uint64(), ASN1_INTEGER_set_int64(), ASN1_ENUMERATED_get_int64(), and ASN1_ENUMERATED_set_int64() first appeared in OpenSSL 1.1.0 and have been available since OpenBSD 7.2.

CAVEATS

In general an ASN1_INTEGER or ASN1_ENUMERATED type can contain an integer of almost arbitrary size and so cannot always be represented by a C long type. The ambiguous return values of ASN1_INTEGER_get() and ASN1_ENUMERATED_get() imply that these functions should be avoided if possible.

BUGS

ASN1_INTEGER_cmp(), ASN1_INTEGER_dup(), and ASN1_INTEGER_to_BN() do not check whether their arguments are really of the type V_ASN1_INTEGER or V_ASN1_NEG_INTEGER. They may report success even if their arguments are of a wrong type. Consequently, even in case of success, the return value of ASN1_INTEGER_dup() is not guaranteed to be of the type V_ASN1_INTEGER or V_ASN1_NEG_INTEGER either.

Similarly, ASN1_ENUMERATED_to_BN() does not check whether its argument is really of the type V_ASN1_ENUMERATED or V_ASN1_NEG_ENUMERATED and may report success even if the argument is of a wrong type.
