Paquete: libressl

Licencias: ISC, custom:OpenSSL

SSL_CTX_SET_DEFAULT_PASSWD_CB(3) Manual de funciones de biblioteca SSL_CTX_SET_DEFAULT_PASSWD_CB(3)

NOMBRE

SSL_CTX_set_default_passwd_cb, SSL_CTX_set_default_passwd_cb_userdata, SSL_CTX_get_default_passwd_cb, SSL_CTX_get_default_passwd_cb_userdata — establecer u obtener la devolución de llamada de contraseña para el manejo de archivos PEM cifrados

SINOPSIS

biblioteca “libssl” libcrypto
#include <openssl/ssl.h>

void
SSL_CTX_set_default_passwd_cb(SSL_CTX *ctx, pem_password_cb *cb);

void
SSL_CTX_set_default_passwd_cb_userdata(SSL_CTX *ctx, void *userdata);

pem_password_cb *
SSL_CTX_get_default_passwd_cb(SSL_CTX *ctx);

void *
SSL_CTX_get_default_passwd_cb_userdata(SSL_CTX *ctx);

DESCRIPCIÓN

SSL_CTX_set_default_passwd_cb() establece la devolución de llamada de contraseña para cargar un certificado o clave privada desde formato PEM cifrado. En particular, la devolución de llamada es utilizada por SSL_CTX_use_certificate_file(3), SSL_use_certificate_file(3), SSL_CTX_use_certificate_chain_file(3), SSL_use_certificate_chain_file(3), SSL_CTX_use_certificate_chain_mem(3), SSL_CTX_use_PrivateKey_file(3), SSL_use_PrivateKey_file(3), SSL_CTX_use_RSAPrivateKey_file(3), y SSL_use_RSAPrivateKey_file(3).

El tipo de puntero de función del argumento cb está documentado en la página del manual pem_password_cb(3). Si SSL_CTX_set_default_passwd_cb() no se llama en ctx o si se llama con un argumento cb de NULL, PEM_def_callback(3) se utiliza en su lugar.

SSL_CTX_set_default_passwd_cb_userdata() establece un puntero a userdata que se proporcionará a la devolución de llamada de contraseña en la invocación.

Dado que el cb pasado a SSL_CTX_set_default_passwd_cb() solo se utilizará para leer y descifrar y no para escribir y cifrar, la biblioteca solo lo llamará con un argumento verify de 0.

Si un programa de aplicación solo necesita leer y descifrar una única clave privada, puede ser práctico que la devolución de llamada maneje el diálogo de contraseña de forma interactiva. Esto ocurre por defecto si no se llama ni SSL_CTX_set_default_passwd_cb() ni SSL_CTX_set_default_passwd_cb_userdata(). En ese caso, la biblioteca utiliza PEM_def_callback(3) con un argumento userdata de NULL.

Si hay que manejar varias claves, puede ser práctico solicitar la contraseña una vez, por ejemplo, usando UI_UTIL_read_pw_string(3), luego mantenerla en memoria y usarla varias veces pasando un puntero a ella a SSL_CTX_set_default_passwd_cb_userdata(). PEM_def_callback(3) también es capaz de manejar este caso, por lo que tampoco es necesario llamar a SSL_CTX_set_default_passwd_cb() en este caso.

Otros elementos en formato PEM (certificados) también pueden estar cifrados; sin embargo, es atípico, ya que la información del certificado se considera pública.

VALORES DE RETORNO

SSL_CTX_get_default_passwd_cb() devuelve un puntero de función a la devolución de llamada de contraseña actualmente establecida en ctx, o NULL si no se ha establecido ninguna.

SSL_CTX_get_default_passwd_cb_userdata() devuelve un puntero a los datos de usuario actualmente establecidos en ctx, o NULL si no se ha establecido ninguno.

EJEMPLOS

El siguiente ejemplo proporciona un subconjunto de la funcionalidad de PEM_def_callback(3), excepto que PEM_def_callback(3) no añade un terminador NULO y copia hasta size bytes en lugar de size - 1 bytes. Interpreta userdata como una cadena terminada en NULO y la copia en el búfer password, truncando la copia si no cabe.

int
trivial_passwd_cb(char *password, int size, int verify, void *userdata)
{
	strlcpy(password, userdata, size);
	return strlen(password);
}

VER TAMBIÉN

    libressl-SSL_CTX_set_default_passwd_cb.3

    SSL_CTX_set_default_passwd_cb(3ssl)

    SSL_CTX_set_default_passwd_cb - configurar la contraseña por defecto callback.

    NOMBRE

    SSL_CTX_set_default_passwd_cb - configurar la contraseña por defecto callback.

    SINOPSIS

    #include <openssl/ssl.h>

void SSL_CTX_set_default_passwd_cb(SSL_CTX *ctx, pem_password_cb *cb);
pem_password_cb *SSL_CTX_get_default_passwd_cb(SSL_CTX *ctx);
void SSL_CTX_set_default_passwd_cb_userdata(SSL_CTX *ctx, void *userdata);
void *SSL_CTX_get_default_passwd_cb_userdata(SSL_CTX *ctx);

    DESCRIPCIÓN

    La función SSL_CTX_set_default_passwd_cb configura una callback de contraseña que se utilizará cuando se necesite una contraseña para descifrar claves privadas o para obtener datos de archivos PEM.

    Cuando OpenSSL necesita una contraseña, llama a la callback configurada. La callback debe devolver la contraseña como una cadena de caracteres y tener la siguiente firma:

    int password_callback(char *buf, int size, int rwflag, void *userdata);

    • buf: Un buffer donde escribir la contraseña.

    • size: El tamaño del buffer.

    • rwflag: Un indicador que muestra si la contraseña se necesita para lectura (normalmente 0) o escritura (normalmente 1).

    • userdata: Datos definidos por el usuario que se pasan a la callback.

    La callback debe devolver el número de caracteres escritos en el buffer buf, o 0 si no se pudo obtener una contraseña.

    La función SSL_CTX_get_default_passwd_cb devuelve la callback de contraseña actualmente configurada para el SSL_CTX.

    Las funciones SSL_CTX_set_default_passwd_cb_userdata y SSL_CTX_get_default_passwd_cb_userdata se utilizan para establecer y obtener datos definidos por el usuario que se pasan a la callback de contraseña.

    VALORES DE RETORNO

    SSL_CTX_get_default_passwd_cb devuelve la callback de contraseña configurada o NULL si no se ha configurado ninguna.

    SSL_CTX_get_default_passwd_cb_userdata devuelve los datos definidos por el usuario asociados a la callback de contraseña, o NULL si no se han configurado.

    EJEMPLOS

    A continuación se muestra un ejemplo de una callback de contraseña que siempre devuelve la misma contraseña:

    int my_passwd_cb(char *buf, int size, int rwflag, void *userdata) {
    const char *password = "mysecretpassword";
    int len = strlen(password);
    if (len > size) {
        len = size;
    }
    memcpy(buf, password, len);
    return len;
}

// ...

SSL_CTX *ctx = SSL_CTX_new(TLS_method());
SSL_CTX_set_default_passwd_cb(ctx, my_passwd_cb);
SSL_CTX_set_default_passwd_cb_userdata(ctx, NULL); // Sin datos de usuario

    VER TAMBIÉN

    SSL_CTX_new(3ssl), PEM_read_PrivateKey(3ssl)

    HISTORIA

    Estas funciones aparecieron por primera vez en OpenSSL 0.9.8.
