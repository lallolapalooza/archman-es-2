libressl-DH_size(3)

Paquete: libressl

Licencias: ISC, custom:OpenSSL

DH_SIZE(3) Manual de funciones de biblioteca DH_SIZE(3)

NOMBRE

DH_size, DH_bits — obtener el tamaño del primo de Diffie-Hellman

SINOPSIS

biblioteca “libcrypto”
#include <openssl/dh.h>

int
DH_size(const DH *dh);

int
DH_bits(const DH *dh);

DESCRIPCIÓN

DH_size() devuelve el tamaño del primo de Diffie-Hellman en bytes. Se puede usar para determinar cuánta memoria se debe asignar para el secreto compartido calculado por DH_compute_key(3).

DH_bits() devuelve el número de bits significativos en la clave.

dh y dh->p no deben ser NULL.

VER TAMBIÉN

BN_num_bytes(3), DH_generate_key(3), DH_get0_key(3), DH_new(3), DH_security_bits(3)

HISTORIA

DH_size() apareció por primera vez en SSLeay 0.5.1 y ha estado disponible desde OpenBSD 2.4.

DH_bits() apareció por primera vez en OpenSSL 1.1.0 y ha estado disponible desde OpenBSD 6.3.
