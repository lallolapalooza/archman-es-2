libressl-X509_keyid_set1(3)

Paquete: libressl

Licencias: ISC, custom:OpenSSL

X509_KEYID_SET1(3) Manual de Funciones de Biblioteca X509_KEYID_SET1(3)

NOMBRE

X509_keyid_set1, X509_keyid_get0, X509_alias_set1, X509_alias_get0 — datos auxiliares de certificado para PKCS#12

SINOPSIS

biblioteca “libcrypto”
#include <openssl/x509.h>

int
X509_keyid_set1(X509 *x, const unsigned char *data, int len);

unsigned char *
X509_keyid_get0(X509 *x, int *plen);

int
X509_alias_set1(X509 *x, const unsigned char *data, int len);

unsigned char *
X509_alias_get0(X509 *x, int *plen);

DESCRIPCIÓN

Estas funciones almacenan datos auxiliares no estándar en x y los recuperan.

Los len bytes de data almacenados usando X509_keyid_set1() se escribirán en el atributo localKeyID de la estructura PKCS#12 si PKCS12_create(3) se llama más tarde sobre x, y los data almacenados usando X509_alias_set1() se escribirán en el atributo friendlyName. Si data apunta a una cadena terminada en NUL, se puede pasar -1 como argumento len para que len se calcule internamente usando strlen(3). Si se pasa un puntero NULL como argumento data, los datos auxiliares respectivos almacenados en x, si los hay, se eliminan de x y se liberan.

Por el contrario, PKCS12_parse(3) recupera estos atributos de una estructura PKCS#12 de manera que posteriormente se pueda acceder a ellos con X509_keyid_get0() y X509_alias_get0(). A menos que se pase NULL para el argumento plen, estas funciones almacenan el tamaño del búfer devuelto en bytes en *plen. Después de la llamada, el búfer devuelto no está necesariamente terminado en NUL, pero puede contener bytes NUL internos.

El diseño de la API es muy incompleto; dada la complejidad de PKCS#12, eso es probablemente un activo en lugar de un defecto. El estándar PKCS#12 define muchos atributos que no se pueden almacenar en objetos X509.

Para asociar certificados con nombres alternativos e identificadores de clave, las extensiones de certificado X.509 se usan más comúnmente que los atributos PKCS#12, por ejemplo, usando X509_EXTENSION_create_by_NID(3) con NID_subject_alt_name o NID_subject_key_identifier.

VALORES DE RETORNO

X509_keyid_set1() y X509_alias_set1() devuelven 1 si data es NULL o si los data de entrada se copiaron correctamente en x, o 0 si data no es NULL pero no se pudo copiar porque x es NULL o falló la asignación de memoria.

X509_keyid_get0() y X509_alias_get0() devuelven un puntero interno a una matriz de bytes o NULL si x no contiene datos auxiliares del tipo solicitado.

VER TAMBIÉN

ASN1_STRING_set(3), X509_CERT_AUX_new(3), X509_EXTENSION_new(3), X509_new(3), X509V3_get_d2i(3)

HISTORIA

X509_alias_set1() y X509_alias_get0() aparecieron por primera vez en OpenSSL 0.9.5 y han estado disponibles desde OpenBSD 2.7.

X509_keyid_set1() apareció por primera vez en OpenSSL 0.9.6 y ha estado disponible desde OpenBSD 2.9.

X509_keyid_get0() apareció por primera vez en OpenSSL 0.9.8 y ha estado disponible desde OpenBSD 4.5.
