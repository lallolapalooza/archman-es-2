libressl-SSL_CTX_set_tmp_rsa_callback(3)

Paquete: libressl

Licencias: ISC, custom:OpenSSL

SSL_CTX_SET_TMP_RSA_CALLBACK(3) Manual de funciones de biblioteca SSL_CTX_SET_TMP_RSA_CALLBACK(3)

NOMBRE

SSL_CTX_set_tmp_rsa_callback, SSL_CTX_set_tmp_rsa, SSL_CTX_need_tmp_RSA, SSL_set_tmp_rsa_callback, SSL_set_tmp_rsa, SSL_need_tmp_RSA — manejar claves RSA para intercambio efímero

SINOPSIS

biblioteca “libssl” libcrypto
#include <openssl/ssl.h>

void
SSL_CTX_set_tmp_rsa_callback(SSL_CTX *ctx, RSA *(*tmp_rsa_callback)(SSL *ssl, int is_export, int keylength));

long
SSL_CTX_set_tmp_rsa(SSL_CTX *ctx, RSA *rsa);

long
SSL_CTX_need_tmp_RSA(SSL_CTX *ctx);

void
SSL_set_tmp_rsa_callback(SSL_CTX *ctx, RSA *(*tmp_rsa_callback)(SSL *ssl, int is_export, int keylength));

long
SSL_set_tmp_rsa(SSL *ssl, RSA *rsa);

long
SSL_need_tmp_RSA(SSL *ssl);

DESCRIPCIÓN

Dado que solo importaban para el intercambio efímero de claves RSA de seguridad deliberadamente precaria, exigido por las restricciones históricas de exportación de EE. UU., todas estas funciones están obsoletas y no tienen ningún efecto, excepto que SSL_CTX_set_tmp_rsa_callback(), SSL_CTX_set_tmp_rsa(), SSL_set_tmp_rsa_callback(), y SSL_set_tmp_rsa() emiten mensajes de error cuando se llaman.

VALORES DE RETORNO

Estas funciones siempre devuelven 0, lo que indica un fallo.

VER TAMBIÉN

ssl(3), SSL_CTX_set_cipher_list(3), SSL_CTX_set_options(3), SSL_CTX_set_tmp_dh_callback(3), SSL_new(3), SSL_set_tmp_ecdh(3)

HISTORIA

SSL_CTX_set_tmp_rsa_callback(), SSL_CTX_set_tmp_rsa(), y SSL_CTX_need_tmp_RSA() aparecieron por primera vez en SSLeay 0.8.0 y han estado disponibles desde OpenBSD 2.4.

SSL_set_tmp_rsa_callback(), SSL_set_tmp_rsa(), y SSL_need_tmp_RSA() aparecieron por primera vez en OpenSSL 0.9.2b y han estado disponibles desde OpenBSD 2.6.
