libssh2_sftp_seek64(3)

Paquete: libssh2

Licencias: BSD

libssh2_sftp_seek64(3) libssh2 libssh2_sftp_seek64(3)

NOMBRE

libssh2_sftp_seek64 - establece la posición de lectura/escritura dentro de un archivo

SINOPSIS

#include <libssh2.h>
#include <libssh2_sftp.h>
void
libssh2_sftp_seek64(LIBSSH2_SFTP_HANDLE *handle,
                    libssh2_uint64_t offset);

DESCRIPCIÓN

handle - Identificador de archivo SFTP como se devuelve por libssh2_sftp_open_ex(3)

offset - Número de bytes desde el principio del archivo para buscar.

Mueve el puntero interno del manejador de archivos a una ubicación arbitraria. libssh2 implementa punteros de archivo como un concepto localizado para hacer que el acceso a archivos parezca más similar a POSIX. No se intercambian paquetes con el servidor durante una operación de búsqueda. El puntero de archivo localizado se utiliza como desplazamiento de conveniencia durante las operaciones de lectura/escritura.

NO DEBE buscar mientras escribe o lee un archivo con SFTP, ya que los elementos internos utilizan paquetes pendientes y cambiar la "posición del archivo" durante la transmisión dará lugar a problemas.
