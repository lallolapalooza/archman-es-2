libssh2_sftp_symlink_ex(3)

Paquete: libssh2

Licencias: BSD

libssh2_sftp_symlink_ex(3) libssh2 libssh2_sftp_symlink_ex(3)

NOMBRE

libssh2_sftp_symlink_ex - leer o establecer un enlace simbólico

SINOPSIS

#include <libssh2.h>
#include <libssh2_sftp.h>
int
libssh2_sftp_symlink_ex(LIBSSH2_SFTP *sftp, const char *path,
                        unsigned int path_len, char *target,
                        unsigned int target_len, int link_type);

DESCRIPCIÓN

Crear un enlace simbólico o leer información de un enlace simbólico del lado remoto.

sftp - Instancia SFTP obtenida de libssh2_sftp_init(3)

path - Objeto del sistema de archivos remoto desde el cual crear un enlace simbólico o para resolver.

path_len - Longitud del nombre del objeto del sistema de archivos remoto desde el cual crear un enlace simbólico o para resolver.

target - un puntero a un buffer. El buffer tiene diferentes usos dependiendo de a qué se establezca el argumento link_type.
LIBSSH2_SFTP_SYMLINK: Objeto del sistema de archivos al que enlazar.
LIBSSH2_SFTP_READLINK: Buffer preasignado para resolver el destino del enlace simbólico.
LIBSSH2_SFTP_REALPATH: Buffer preasignado para resolver el destino realpath.

target_len - Longitud del nombre del objeto destino del sistema de archivos remoto.

link_type - Una de las tres constantes mencionadas anteriormente que determina el comportamiento resultante de esta función.

Estas son macros de conveniencia:

libssh2_sftp_symlink(3) : Crea un enlace simbólico entre dos objetos del sistema de archivos.
libssh2_sftp_readlink(3) : Resuelve un objeto de enlace simbólico del sistema de archivos a su próximo destino.
libssh2_sftp_realpath(3) : Resuelve una ruta de archivo compleja, relativa o enlazada a su destino efectivo.

VALOR DE RETORNO

Al usar LIBSSH2_SFTP_SYMLINK, esta función devuelve 0 en caso de éxito o un valor negativo en caso de fallo.

Al usar LIBSSH2_SFTP_READLINK o LIBSSH2_SFTP_REALPATH, devuelve el número de bytes que copió en el buffer de destino (sin incluir el cero terminador) o un valor negativo en caso de fallo.

Devuelve LIBSSH2_ERROR_EAGAIN cuando de otro modo bloquearía. Aunque LIBSSH2_ERROR_EAGAIN es un número negativo, en realidad no es un fallo.

A partir de la versión 1.2.8, se devuelve LIBSSH2_ERROR_BUFFER_TOO_SMALL si el buffer 'target' proporcionado es demasiado pequeño para contener el nombre del objeto solicitado.

ERROR

Pasar un buffer demasiado pequeño al recibir datos solo resulta en que libssh2 1.2.7 o versiones anteriores no copien la cantidad total de datos, ¡y no es posible que la aplicación sepa cuándo ocurre!

ERRORES

LIBSSH2_ERROR_ALLOC - Una llamada interna de asignación de memoria falló.

LIBSSH2_ERROR_SOCKET_SEND - No se pudieron enviar datos en el socket.

LIBSSH2_ERROR_SOCKET_TIMEOUT -

LIBSSH2_ERROR_SFTP_PROTOCOL - Se recibió una respuesta de protocolo SFTP inválida en el socket, o una operación SFTP causó que el servidor devolviera un código de error.
