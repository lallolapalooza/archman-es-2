LIBIEEE1284(3) Introducción LIBIEEE1284(3)

NOMBRE

libieee1284 - biblioteca de comunicaciones IEEE1284

SINOPSIS

    #include <ieee1284.h>
    cc archivos... -lieee1284

DESCRIPCIÓN GENERAL

La biblioteca libieee1284 es una biblioteca para acceder a dispositivos de puerto paralelo.

El modelo presentado al usuario es bastante abstracto: una lista de puertos paralelos con nombres arbitrarios, con funciones para acceder a ellos de diversas maneras, desde operaciones bit a bit hasta transferencia de datos en bloque en uno de los protocolos sancionados por IEEE 1284.

Aunque la biblioteca reside en el espacio de usuario, la penalización de velocidad puede no ser tan mala como podrías pensar inicialmente, ya que el sistema operativo puede proporcionar asistencia con las operaciones de transferencia de datos en bloque; de hecho, el sistema operativo puede incluso utilizar asistencia de hardware para realizar el trabajo. Por lo tanto, usando libieee1284, son posibles las transferencias ECP usando DMA.

La secuencia normal de eventos será que la aplicación

1.llama a ieee1284_find_ports para obtener una lista de puertos disponibles
2.luego a ieee1284_get_deviceid para buscar un dispositivo en cada puerto que le interese
3.y luego a ieee1284_open para abrir cada puerto en el que encuentre un dispositivo que pueda controlar.
4.La lista de puertos devuelta por ieee1284_find_ports puede desecharse ahora usando ieee1284_free_ports.
5.Luego, cuando quiera controlar el dispositivo, llamará a ieee1284_claim para evitar que otros controladores utilicen el puerto
6.luego quizás realice algunas transferencias de datos
7.y luego ieee1284_release cuando haya terminado con ese comando en particular. Esta secuencia de reclamar-controlar-liberar se repetirá cada vez que quiera indicar al dispositivo que haga algo.
8.Finalmente, cuando la aplicación haya terminado con el dispositivo, llamará a ieee1284_close.

Normalmente, un puerto necesita ser reclamado antes de poder ser utilizado. Esto es para evitar que múltiples controladores se pisen unos a otros si ambos quieren usar el mismo puerto. La excepción a esta regla es la recopilación de ID de Dispositivo IEEE 1284, que tiene una secuencia implícita de abrir-reclamar-liberar-cerrar. La razón de esto es que puede ser posible recopilar un ID de Dispositivo del sistema operativo, sin molestar al dispositivo con ello.

CONFIGURACIÓN

Cuando se llama a ieee1284_find_ports por primera vez, la biblioteca buscará un archivo de configuración, /etc/ieee1284.conf.

Los comentarios comienzan con un carácter '#' y se extienden hasta el final de la línea. Todo lo demás son tokens de formato libre. Una barra inclinada inversa '\' no citada (o entre comillas dobles) preserva el valor literal del siguiente carácter, y se pueden usar comillas simples y dobles para preservar los espacios en blanco. Las llaves y los signos de igual se reconocen como tokens, a menos que estén citados o escapados.

La única instrucción de configuración que se reconoce actualmente es “disallow method ppdev”, para evitar el uso del controlador ppdev de Linux.

ENTORNO

Puede habilitar la salida de depuración de la biblioteca estableciendo la variable de entorno LIBIEEE1284_DEBUG a cualquier valor.

ARCHIVOS

/etc/ieee1284.conf

Archivo de configuración.
