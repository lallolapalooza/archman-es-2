libcaca-style - Estilo de codificación de Libcaca

Directrices generales

Una regla general bastante segura es: mira lo que ya se ha hecho e intenta hacer lo mismo.

  • Se deben evitar las tabulaciones y reemplazarlas con ocho espacios.
  • La indentación son generalmente 4 espacios.
  • Las líneas deben ajustarse como máximo a 79 caracteres.
  • No dejes espacios en blanco al final de las líneas.
  • No uses espacios múltiples para nada más que la indentación.
  • Código que genera advertencias == código de cerdo == dos bofetadas en tu cara

Estilo de codificación C

Intenta usar nombres cortos siempre que sea posible (i para índices, w para ancho (width), cv para canvas...). Las macros son siempre en mayúsculas, los nombres de variables y funciones son siempre en minúsculas. Usa el guión bajo para separar palabras dentro de los nombres:

#define BROKEN 0
#define MAX(x, y) ((x > y) ? (x) : (y))
unsigned int x, y, w, h;
char *font_name;
void frobulate_every_three_seconds(void);

const es un sufijo. Es char const *foo, no const char *foo.

Usa espacios después de las comas y entre los operadores. No uses espacios después de un paréntesis de apertura ni antes de uno de cierre:

a += 2;
b = (a * (c + d));
x = min(x1, x2, x3);

No pongas un espacio entre las funciones y el paréntesis de apertura correspondiente:

int function(int);

Se puede insertar un espacio después de palabras clave como for, while o if, pero se recomienda la coherencia con el resto de la página:

if(a == b)
    return;
if (p == NULL)

No pongas paréntesis alrededor de los valores de retorno:

return a + (b & x) + d[10];

Los corchetes de apertura deben estar en su propia línea, alineados con el bloque actual. Los corchetes son opcionales para líneas únicas:

int function(int a)
{
    if(a & 0x84)
        return a;
    if(a < 0)
    {
        return -a;
    }
    else
    {
        a /= 2;
        switch(a)
        {
            case 0:
            case 1:
                return -1;
                break;
            default:
                return a;
        }
    }
}
