libssh2_userauth_publickey_sk(3)

Paquete: libssh2

Licencias: BSD

libssh2_userauth_publickey_sk(3) libssh2 libssh2_userauth_publickey_sk(3)

NOMBRE

libssh2_userauth_publickey_sk - autenticar una sesión con un autenticador FIDO2

SINOPSIS

#include <libssh2.h>
int
libssh2_userauth_publickey_sk(LIBSSH2_SESSION *session,
                              const char *username,
                              size_t username_len,
                              const unsigned char *publickeydata,
                              size_t publickeydata_len,
                              const char *privatekeydata,
                              size_t privatekeydata_len,
                              const char *passphrase,
                              LIBSSH2_USERAUTH_SK_SIGN_FUNC((*sign_callback)),
                              void **abstract);

LLAMADA A FUNCIÓN

#define LIBSSH2_SK_PRESENCE_REQUIRED     0x01
#define LIBSSH2_SK_VERIFICATION_REQUIRED 0x04
typedef struct _LIBSSH2_SK_SIG_INFO {
    uint8_t flags;
    uint32_t counter;
    unsigned char *sig_r;
    size_t sig_r_len;
    unsigned char *sig_s;
    size_t sig_s_len;
} LIBSSH2_SK_SIG_INFO;
int name(LIBSSH2_SESSION *session, LIBSSH2_SK_SIG_INFO *sig_info,
         const unsigned char *data, size_t data_len, int algorithm,
         uint8_t flags, const char *application,
         const unsigned char *key_handle, size_t handle_len,
         void **abstract);

DESCRIPCIÓN

session - Instancia de sesión como la devuelta por libssh2_session_init_ex(3)

username - Nombre del usuario para el que se intentará la autenticación.

username_len - Longitud del parámetro username.

publickeydata - Búfer que contiene el contenido de un archivo de clave pública. Si es NULL, la clave pública se extraerá de privatekeydata. Al usar autenticación con certificado, este búfer debe contener los datos del certificado público.

publickeydata_len - Longitud de los datos de la clave pública.

privatekeydata - Búfer que contiene el contenido de un archivo de clave privada.

privatekeydata_len - Longitud de los datos de la clave privada.

passphrase - Frase de contraseña a usar al decodificar el archivo de clave privada.

sign_callback - Función de devolución de llamada para comunicarse con el autenticador FIDO2.

abstract - Datos proporcionados por el usuario para pasar a la función de devolución de llamada.

Intenta la autenticación FIDO2. usando los algoritmos de intercambio de claves sk-ssh-ed25519@openssh.com o sk-ecdsa-sha2-nistp256@openssh.com.

Esta función solo se admite cuando libssh2 está respaldado por OpenSSL.

DESCRIPCIÓN DE LA LLAMADA A FUNCIÓN

session - Instancia de sesión como la devuelta por libssh2_session_init_ex(3)

sig_info - Completado por la función de devolución de llamada con la firma e información adicional del autenticador.

data - Los datos a firmar.

data_len - La longitud del parámetro data.

algorithm - El algoritmo de firma a usar. Los valores posibles son LIBSSH2_HOSTKEY_TYPE_ED25519 y LIBSSH2_HOSTKEY_TYPE_ECDSA_256.

flags - Una máscara de bits que especifica opciones para el autenticador. Cuando se establece LIBSSH2_SK_PRESENCE_REQUIRED, el autenticador requiere un toque. Cuando se establece LIBSSH2_SK_VERIFICATION_REQUIRED, el autenticador requiere un PIN. Muchos servidores y autenticadores no funcionan correctamente cuando LIBSSH2_SK_PRESENCE_REQUIRED no está establecido.

application - Una cadena definida por el usuario a usar como nombre RP para el autenticador. Generalmente "ssh:".

key_handle - El manejador de clave a usar para la lista de permitidos del autenticador.

handle_len - La longitud del parámetro key_handle.

abstract - Datos definidos por el usuario. Cuando se requiere un PIN, use esto para pasar el PIN, o un puntero a función para recuperar el PIN.

La sign_callback es responsable de comunicarse con el autenticador de hardware para generar una firma. En caso de éxito, la información de la firma debe colocarse en el parámetro `sig_info sig_info` y la función de devolución de llamada debe devolver 0. En caso de fallo, debe devolver un número negativo.

Los campos de LIBSSH2_SK_SIG_INFO son los siguientes.

flags - Una máscara de bits que especifica opciones para el autenticador. Esto debe leerse del autenticador y no simplemente copiarse de los flags pasados a la función de devolución de llamada.

counter - Un valor devuelto por el autenticador.

sig_r - Para firmas Ed25519, esto contiene la firma completa, tal como se devuelve directamente del autenticador. Para firmas ECDSA, esto contiene el componente r de la firma en una representación binaria big-endian. Para ambos algoritmos, use LIBSSH2_ALLOC para asignar memoria. El llamador la liberará.

sig_r_len - La longitud del parámetro sig_r.

sig_s - Para firmas ECDSA, esto contiene el componente s de la firma en una representación binaria big-endian. Use LIBSSH2_ALLOC para asignar memoria. El llamador la liberará. Para firmas Ed25519, establezca esto en NULL.

sig_s_len - La longitud del parámetro sig_s.

VALOR DE RETORNO

Devuelve 0 en caso de éxito o un valor negativo en caso de fallo. Devuelve LIBSSH2_ERROR_EAGAIN cuando de lo contrario se bloquearía. Aunque LIBSSH2_ERROR_EAGAIN es un número negativo, no es realmente un fallo en sí mismo.

ERRORES

Algunos de los errores que esta función puede devolver incluyen:

LIBSSH2_ERROR_ALLOC - Una llamada interna de asignación de memoria falló.

LIBSSH2_ERROR_SOCKET_SEND - No se pueden enviar datos en el socket.

LIBSSH2_ERROR_AUTHENTICATION_FAILED - Falló, nombre de usuario/clave inválido.

DISPONIBILIDAD

Añadido en libssh2 1.10.0
