Descripción detallada

Estas funciones proporcionan las rutinas básicas de libcaca para la inicialización de la biblioteca, la recuperación de información del sistema y la configuración.

Documentación de funciones

__extern caca_canvas_t * caca_create_canvas (int width, int height)

Inicializa las estructuras internas de libcaca y el backend que se utilizará para las operaciones gráficas posteriores. Debe ser la primera función de libcaca que se llame en una función. caca_free_canvas() debe llamarse al final del programa para liberar todos los recursos asignados.

Tanto el cursor como el manejador del lienzo se inicializan en la esquina superior izquierda.

Si ocurre un error, se devuelve NULL y se establece errno en consecuencia:

  • EINVAL El ancho o alto especificado no es válido.
  • EOVERFLOW El ancho y alto especificados desbordaron.
  • ENOMEM No hay suficiente memoria para el tamaño de lienzo solicitado.

Parámetros

width El ancho de lienzo deseado
height La altura de lienzo deseada

Devoluciones

Un manejador de lienzo de libcaca en caso de éxito, NULL si ocurrió un error.

Referencias CACA_DEFAULT, caca_set_color_ansi() y CACA_TRANSPARENT.

Referenciado por caca_conio_movetext(), caca_create_display_with_driver(), caca_export_area_to_memory(), caca_import_area_from_file(), caca_import_area_from_memory() y caca_set_canvas_boundaries().

__extern int caca_manage_canvas (caca_canvas_t * cv, int(* callback )(void *), void * p)

Bloquea un lienzo para evitar que se redimensione. Si no es NULL, el puntero de función callback se llamará en cada llamada a caca_set_canvas_size y si el valor devuelto es cero, la solicitud de redimensionamiento del lienzo será denegada.

Esta función solo es útil para controladores de pantalla como la biblioteca libcaca.

Si ocurre un error, se devuelve -1 y se establece errno en consecuencia:

•
EBUSY El lienzo ya está siendo gestionado.

Parámetros

cv Un lienzo de libcaca.
callback Un puntero de función de callback opcional.
p El argumento que se pasará a callback.

Devoluciones

0 en caso de éxito, -1 si ocurrió un error.

Referenciado por caca_create_display_with_driver().

__extern int caca_unmanage_canvas (caca_canvas_t * cv, int(* callback )(void *), void * p)

Desbloquea un lienzo previamente bloqueado por caca_manage_canvas(). Por razones de seguridad, los argumentos de callback y datos de callback deben ser los mismos que para la llamada a caca_manage_canvas().

Esta función solo es útil para controladores de pantalla como la biblioteca libcaca.

Si ocurre un error, se devuelve -1 y se establece errno en consecuencia:

•
EINVAL El lienzo no está gestionado, o los argumentos del callback no coinciden.

Parámetros

cv un lienzo de libcaca.
callback el argumento callback pasado previamente a caca_manage_canvas().
p el argumento p pasado previamente a caca_manage_canvas().

Devoluciones

0 en caso de éxito, -1 si ocurrió un error.

Referenciado por caca_create_display_with_driver() y caca_free_display().

__extern int caca_set_canvas_size (caca_canvas_t * cv, int width, int height)

Establece el ancho y alto del lienzo, en celdas de caracteres.

El contenido del lienzo se conserva hasta el tamaño del nuevo lienzo. Las celdas de caracteres recién asignadas a la derecha y/o en la parte inferior del lienzo se rellenan con espacios.

Si como resultado del redimensionamiento las coordenadas del cursor caen fuera de los nuevos límites del lienzo, se reajustan. Por ejemplo, si la coordenada X actual del cursor es 11 y el ancho solicitado es 10, la nueva coordenada X del cursor será 10.

Es un error intentar redimensionar el lienzo si se ha adjuntado un controlador de salida al lienzo usando caca_create_display(). Necesitas eliminar el controlador de salida usando caca_free_display() antes de poder cambiar el tamaño del lienzo nuevamente. Sin embargo, el controlador de salida de caca puede causar un redimensionamiento del lienzo a través de la interacción del usuario. Consulta la documentación de caca_event() para más información sobre esto.

Si ocurre un error, se devuelve -1 y se establece errno en consecuencia:

  • EINVAL El ancho o alto especificado no es válido.
  • EOVERFLOW El ancho y alto especificados desbordaron.
  • EBUSY El lienzo está en uso por un controlador de pantalla y no se puede redimensionar.
  • ENOMEM No hay suficiente memoria para el tamaño de lienzo solicitado. Si esto sucede, el manejador del lienzo se vuelve inválido y no debe usarse.

Parámetros

cv Un lienzo de libcaca.
width El ancho de lienzo deseado.
height La altura de lienzo deseada.

Devoluciones

0 en caso de éxito, -1 si ocurrió un error.

Referenciado por caca_canvas_set_figfont(), caca_flush_figlet() y caca_put_figchar().

__extern uint32_t const * caca_get_canvas_chars (caca_canvas_t const * cv)

Devuelve un puntero al array de caracteres del lienzo. Este array contiene width * height elementos, donde width y height son los valores devueltos por caca_get_canvas_width() y caca_get_canvas_height(). Cada elemento es un entero de 32 bits sin signo, donde los 21 bits inferiores representan el código de carácter Unicode, y los 11 bits superiores representan el atributo de carácter.

El contenido del array no debe ser modificado por el usuario. La modificación de los valores en este array no tiene ningún efecto.

Parámetros

cv Un lienzo de libcaca.

Devoluciones

Un puntero al array de caracteres del lienzo.

Referenciado por caca_get_attr(), caca_get_char(), caca_set_attr() y caca_set_char().

__extern uint32_t const * caca_get_canvas_attrs (caca_canvas_t const * cv)

Devuelve un puntero al array de atributos del lienzo. Este array contiene width * height elementos, donde width y height son los valores devueltos por caca_get_canvas_width() y caca_get_canvas_height(). Cada elemento es un entero de 32 bits sin signo que representa el atributo de carácter.

El contenido del array no debe ser modificado por el usuario. La modificación de los valores en este array no tiene ningún efecto.

Parámetros

cv Un lienzo de libcaca.

Devoluciones

Un puntero al array de atributos del lienzo.

Referenciado por caca_get_attr() y caca_set_attr().

NAME

libcaca — Curses-like functions for ASCII art.

SYNOPSIS

#include <caca.h>

__extern   int caca_get_canvas_width (caca_canvas_t const * cv);

Detailed Description

The libcaca library is a graphics library that outputs text instead of pixels. It uses the ncurses library (or compatible) to draw in a terminal window, or any other output device. It can be used for debugging, for games, or for any application that needs text-based graphics.

__extern int caca_free_canvas (caca_canvas_t * cv)

Free all resources allocated by caca_create_canvas(). The canvas pointer becomes invalid and must no longer be used unless a new call to caca_create_canvas() is made.

If an error occurs, -1 is returned and errno is set accordingly:

•
EBUSY The canvas is in use by a display driver and cannot be freed.

cv A libcaca canvas.

Returns

0 in case of success, -1 if an error occurred.
