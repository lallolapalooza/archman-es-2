listbox - Crear y manipular widgets de lista de elementos 'listbox'

OPCIONES ESPECÍFICAS DEL WIDGET

Nombre de línea de comandos:	-activestyle
Nombre de base de datos:	activeStyle
Clase de base de datos:	ActiveStyle
Especifica el estilo en el que se dibujará el elemento activo. Debe ser uno de dotbox (mostrar un anillo de foco alrededor del elemento activo), none (ninguna indicación especial del elemento activo) o underline (subrayar el elemento activo). El valor predeterminado es underline en Windows y dotbox en otros lugares.
Nombre de línea de comandos:	-height
Nombre de base de datos:	height
Clase de base de datos:	Height
Especifica la altura deseada para la ventana, en líneas. Si es cero o menos, la altura deseada para la ventana será lo suficientemente grande como para contener todos los elementos de la lista.
Nombre de línea de comandos:	-listvariable
Nombre de base de datos:	listVariable
Clase de base de datos:	Variable
Especifica el nombre de una variable global. El valor de la variable es una lista que se mostrará dentro del widget; si el valor de la variable cambia, el widget se actualizará automáticamente para reflejar el nuevo valor. Los intentos de asignar una variable con un valor de lista no válido a -listvariable causarán un error. Los intentos de anular una variable en uso como -listvariable fallarán pero no generarán un error.
Nombre de línea de comandos:	-selectmode
Nombre de base de datos:	selectMode
Clase de base de datos:	SelectMode
Especifica uno de varios estilos para manipular la selección. El valor de la opción puede ser arbitrario, pero las vinculaciones predeterminadas esperan que sea single, browse, multiple o extended; el valor predeterminado es browse.
Nombre de línea de comandos:	-state
Nombre de base de datos:	state
Clase de base de datos:	State
Especifica uno de los dos estados del listbox: normal o disabled. Si el listbox está deshabilitado, no se pueden insertar ni eliminar elementos, los elementos se dibujan en el color -disabledforeground y la selección no se puede modificar y no se muestra (aunque la información de selección se conserva).
Nombre de línea de comandos:	-width
Nombre de base de datos:	width
Clase de base de datos:	Width
Especifica el ancho deseado para la ventana en caracteres. Si la fuente no tiene un ancho uniforme, se utiliza el ancho del carácter “0” al traducir de unidades de caracteres a unidades de pantalla. Si es cero o menos, el ancho deseado para la ventana será lo suficientemente grande como para contener todos los elementos de la lista.

DESCRIPCIÓN

El comando listbox crea una nueva ventana (proporcionada por el argumento rutaNombre) y la convierte en un widget listbox. Se pueden especificar opciones adicionales, descritas anteriormente, en la línea de comandos o en la base de datos de opciones para configurar aspectos del listbox, como sus colores, fuente, texto y relieve. El comando listbox devuelve su argumento rutaNombre. En el momento en que se invoca este comando, no debe existir una ventana llamada rutaNombre, pero el padre de rutaNombre debe existir.

Un listbox es un widget que muestra una lista de cadenas, una por línea. Cuando se crea por primera vez, un nuevo listbox no tiene elementos. Los elementos se pueden agregar o eliminar utilizando los comandos de widget descritos a continuación. Además, uno o más elementos pueden ser seleccionados como se describe a continuación. Si un listbox está exportando su selección (consulte la opción -exportselection), observará los protocolos X11 estándar para manejar la selección. Las selecciones de Listbox están disponibles como tipo STRING; el valor de la selección será el texto de los elementos seleccionados, con saltos de línea separando los elementos.

No es necesario que todos los elementos se muestren en la ventana del listbox a la vez; los comandos descritos a continuación se pueden utilizar para cambiar la vista en la ventana. Los Listbox permiten desplazarse en ambas direcciones utilizando las opciones estándar -xscrollcommand y -yscrollcommand. También admiten escaneo, como se describe a continuación.

ÍNDICES

Muchos de los comandos de widget para listbox toman uno o más índices como argumentos. Un índice especifica un elemento particular de la lista, de cualquiera de las siguientes maneras:

número
Especifica el elemento como un índice numérico, donde 0 corresponde al primer elemento de la lista.
active
Indica el elemento que tiene el cursor de ubicación. Este elemento se mostrará como se especifica en -activestyle cuando el listbox tiene el foco del teclado, y se especifica con el comando de widget activate.
anchor
Indica el punto de anclaje para la selección, que se establece con el comando de widget selection anchor.
end
Indica el final de la lista. Para la mayoría de los comandos, esto se refiere al último elemento de la lista, pero para algunos comandos como index e insert, se refiere al elemento justo después del último.
@x,y
Indica el elemento que cubre el punto en la ventana de la lista especificado por x e y (en coordenadas de píxeles). Si ningún elemento cubre ese punto, se utiliza el elemento más cercano a ese punto.

En las descripciones de los comandos de widget a continuación, los argumentos llamados index, first y last siempre contienen índices de texto en una de las formas anteriores.

COMANDO DE WIDGET

El comando listbox crea un nuevo comando Tcl cuyo nombre es rutaNombre. Este comando se puede utilizar para invocar varias operaciones en el widget. Tiene la siguiente forma general:

Opción y los args determinan el comportamiento exacto del comando. Los siguientes comandos son posibles para los widgets listbox:
rutaNombre activate index
Establece el elemento activo al indicado por index. Si index está fuera del rango de elementos en la lista, se activa el elemento más cercano. El elemento activo se dibuja según lo especificado por -activestyle cuando el widget tiene el foco de entrada, y su índice se puede recuperar con el índice active.
rutaNombre bbox index
Devuelve una lista de cuatro números que describen el cuadro delimitador del texto en el elemento dado por index. Los dos primeros elementos de la lista dan las coordenadas x e y de la esquina superior izquierda del área de pantalla que cubre el texto (especificado en píxeles en relación con el widget) y los dos últimos elementos dan el ancho y la altura del área, en píxeles. Si ninguna parte del elemento dado por index es visible en la pantalla, o si index se refiere a un elemento inexistente, el resultado es una cadena vacía; si el elemento es parcialmente visible, el resultado da el área completa del elemento, incluidas las partes que no son visibles.
rutaNombre cget option
Devuelve el valor actual de la opción de configuración dada por option. Option puede tener cualquiera de los valores aceptados por el comando listbox.

NAME

listbox — a widget that displays a list of strings

SYNOPSIS

button ?options?

STANDARD OPTIONS

See the options manual entry for details on the standard options for the button widget.

WIDGET-SPECIFIC OPTIONS

Command-line, syntax, and description see the options manual entry.

-activestipple       -height             -selectbackground
-background         -highlightbackground -selectborderwidth
-bg                 -highlightcolor     -selectforeground
-borderwidth        -highlightthickness -selectmode
-bd                 -image              -setgrid
-cursor             -justify            -shiny
-disabledforeground -listvariable       -state
-exportselection    -relief             -takefocus
-font               -setgrid            -tooltip
-fg                 -width              -xscrollcommand
-foreground         -wrap               -yscrollcommand

DESCRIPTION

The listbox widget is used to display a list of strings, one string per line. The application can associate a Tcl variable with the listbox, so that changes to the variable update the listbox contents and selections in the listbox update the variable. The listbox supports single-element selections, multiple-element selections, and browse-selection. It also supports horizontal and vertical scrolling.

INDICES

Many listbox commands refer to list elements using indices. Indices can be specified in several ways:

first
The index first always refers to the first element in the listbox (element 0).
last
The index last always refers to the last element in the listbox.
number
The index number refers to the element with that index (0 for the first, 1 for the second, etc.).
@x,y
The index @x,y refers to the element nearest to the screen coordinates x,y. The coordinates are relative to the listbox window.
+offset
An index followed by +offset or -offset refers to the element that is offset elements after or before the first element. For example, 0+1 refers to the second element.
last-offset
Similarly, last-offset refers to the element offset elements before the last element.
index line
In this variant, index can be any of the above index formats. The command returns the index of the listbox element at the beginning of the line containing the element specified by index.
index char
In this variant, index can be any of the above index formats. The command returns the index of the listbox element at the character position specified by index.

Indices can also be specified using the special names anchor and current. anchor refers to the position of the selection anchor (which is set by button 1 clicks in extended mode), and current refers to the element the mouse cursor is currently over.

WIDGET COMMAND

The name of the listbox widget's command is the same as the name of the widget's window, pathName. It can be used to invoke various operations on the listbox widget. The following commands are available for listboxes:

pathName activate index
Make the element specified by index the active element. This is the element that will be selected or deselected if the Select key or space bar is pressed. The active element is usually drawn differently from other elements (e.g. inverted colors).
pathName anchor index
Move the selection anchor to the element specified by index, without changing the selection.
pathName bbox ?index?
Returns the bounding box of the element specified by index in screen coordinates. If index is omitted, it defaults to the active element. The returned value is a list of four numbers: the x-coordinate of the left edge, the y-coordinate of the top edge, the width, and the height of the bounding box. If the specified element is not visible on the screen, an empty string is returned.
pathName curselection
Returns a list of the indices of all selected elements, in order from first to last.
pathName delete first ?last?
Delete the element(s) specified by the index or index range first to last. If last is omitted, only the single element specified by first is deleted. If first is first and last is omitted, the first element is deleted. If first is last and last is omitted, the last element is deleted.
pathName get first ?last?
Returns a list containing the contents of the elements specified by the index or index range first to last. If last is omitted, it defaults to first, so the command returns the contents of a single element. If first is first and last is omitted, the first element is returned. If first is last and last is omitted, the last element is returned.
pathName getcurselection
Same as curselection.
pathName getvalue
Returns the value of the listbox's associated Tcl variable, if any.
pathName index i
Returns the numeric index corresponding to the listbox index i. This is useful for converting between different index representations (e.g., screen coordinates to numeric indices).
pathName insert index item ?item ...?
Insert one or more items into the listbox just before the element specified by index. If index is end, the items are appended to the end of the list. If index is first, the items are prepended to the beginning of the list.
pathName itemcget index option
Returns the value of the given configuration option for the element specified by index. Possible options are -background, -fg, -font, -selectbackground, -selectforeground.
pathName itemconfigure index ?options?

Configures the given element(s) in the listbox, using the same options as itemcget.
pathName see index
Make the element specified by index visible in the listbox. If the element is already visible, this command does nothing. If the element is not visible, the listbox is scrolled appropriately so that the element appears at the top (or as close to the top as possible).
pathName selection option ?arg arg ...?
Perform various operations related to selection. The possible options are:
clear first ?last?
         Deselects the elements in the range first to last. If last
         is omitted, only the element first is deselected. If first
         is omitted, all elements are deselected.
exists index
         Returns 1 if the element specified by index is currently selected,
         0 otherwise.
incorporate index
         This command is the inverse of see. It returns 1 if the element
         specified by index is currently visible in the window, 0 otherwise.
set first ?last?
         Selects the elements in the range first to last. If last
         is omitted, only the element first is selected. If first
         is omitted, all elements are selected.
pathName size
Returns the number of elements currently in the listbox.
pathName xview ?args?
This command is used to manage the listbox's horizontal view. It can take various forms, depending on the arguments provided. See the xview manual entry for details.
pathName xview moveto fraction
Adjust the view so that the element given by fraction appears at the left edge of the window. Fraction is a value between 0 and 1.
pathName xview scroll number what
Scroll the view left or right by number units specified by what. what can be units (characters) or pages (window width).
pathName xview set first ?last?
Adjusts the view to display the elements between first and last. Used to synchronize with external scrollbars.
pathName yview ?args?
This command is used to manage the listbox's vertical view. It can take various forms, depending on the arguments provided. See the yview manual entry for details.
pathName yview moveto fraction
Adjust the view so that the element given by fraction appears at the top of the window. Fraction is a value between 0 and 1.
pathName yview scroll number what
Scroll the view up or down by number units specified by what. what can be units (lines) or pages (window height).
pathName yview set first ?last?
Adjusts the view to display the elements between first and last. Used to synchronize with external scrollbars.

DEFAULT BINDINGS

Tk automatically creates class bindings for listboxes that give them Motif-like behavior. Much of the behavior of a listbox is determined by its -selectmode option, which selects one of four ways of dealing with the selection.

If the selection mode is single or browse, at most one element can be selected in the listbox at once. In both modes, clicking button 1 on an element selects it and deselects any other selected item. In browse mode it is also possible to drag the selection with button 1. On button 1, the listbox will also take focus if it has a normal state.

If the selection mode is multiple or extended, any number of elements may be selected at once, including discontiguous ranges. In multiple mode, clicking button 1 on an element toggles its selection state without affecting any other elements. In extended mode, pressing button 1 on an element selects it, deselects everything else, and sets the anchor to the element under the mouse; dragging the mouse with button 1 down extends the selection to include all the elements between the anchor and the element under the mouse, inclusive.

Most people will probably want to use browse mode for single selections and extended mode for multiple selections; the other modes appear to be useful only in special situations.

Any time the set of selected item(s) in the listbox is updated by the user through the keyboard or mouse, the virtual event <<ListboxSelect>> will be generated. This virtual event will not be generated when adjusting the selection with the pathName selection command. It is easiest to bind to this event to be made aware of any user changes to listbox selection.

In addition to the above behavior, the following additional behavior is defined by the default bindings:

[1]
In extended mode, the selected range can be adjusted by pressing button 1 with the Shift key down: this modifies the selection to consist of the elements between the anchor and the element under the mouse, inclusive. The un-anchored end of this new selection can also be dragged with the button down.
[2]
In extended mode, pressing button 1 with the Control key down starts a toggle operation: the anchor is set to the element under the mouse, and its selection state is reversed. The selection state of other elements is not changed. If the mouse is dragged with button 1 down, then the selection state of all elements between the anchor and the element under the mouse is set to match that of the anchor element; the selection state of all other elements remains what it was before the toggle operation began.
[3]
If the mouse leaves the listbox window with button 1 down, the window scrolls away from the mouse, making information visible that used to be off-screen on the side of the mouse. The scrolling continues until the mouse re-enters the window, the button is released, or the end of the listbox is reached.
[4]
Mouse button 2 may be used for scanning. If it is pressed and dragged over the listbox, the contents of the listbox drag at high speed in the direction the mouse moves.
[5]
If the Up or Down key is pressed, the location cursor (active element) moves up or down one element. If the selection mode is browse or extended then the new active element is also selected and all other elements are deselected. In extended mode the new active element becomes the selection anchor.
[6]
In extended mode, Shift-Up and Shift-Down move the location cursor (active element) up or down one element and also extend the selection to that element in a fashion similar to dragging with mouse button 1.
[7]
The Left and Right keys scroll the listbox view left and right by the width of the character 0. Control-Left and Control-Right scroll the listbox view left and right by the width of the window. Control-Prior and Control-Next also scroll left and right by the width of the window.
[8]
The Prior and Next keys scroll the listbox view up and down by one page (the height of the window).
[9]
The Home and End keys scroll the listbox horizontally to the left and right edges, respectively.
[10]
Control-Home sets the location cursor to the first element in the listbox, selects that element, and deselects everything else in the listbox.
[11]
Control-End sets the location cursor to the last element in the listbox, selects that element, and deselects everything else in the listbox.
[12]
In extended mode, Control-Shift-Home extends the selection to the first element in the listbox and Control-Shift-End extends the selection to the last element.
[13]
In multiple mode, Control-Shift-Home moves the location cursor to the first element in the listbox and Control-Shift-End moves the location cursor to the last element.
[14]
The space and Select keys make a selection at the location cursor (active element) just as if mouse button 1 had been pressed over this element.
[15]
In extended mode, Control-Shift-space and Shift-Select extend the selection to the active element just as if button 1 had been pressed with the Shift key down.
[16]
In extended mode, the Escape key cancels the most recent selection and restores all the elements in the selected range to their previous selection state.
[17]
Control-slash selects everything in the widget, except in single and browse modes, in which case it selects the active element and deselects everything else.
[18]
Control-backslash deselects everything in the widget, except in browse mode where it has no effect.
[19]
The F16 key (labelled Copy on many Sun workstations) or Meta-w copies the selection in the widget to the clipboard, if there is a selection.

The behavior of listboxes can be changed by defining new bindings for individual widgets or by redefining the class bindings.
