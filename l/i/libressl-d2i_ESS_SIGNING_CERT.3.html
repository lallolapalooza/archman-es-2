NOMBRE

d2i_ESS_SIGNING_CERT, i2d_ESS_SIGNING_CERT, d2i_ESS_CERT_ID, i2d_ESS_CERT_ID, d2i_ESS_ISSUER_SERIAL, i2d_ESS_ISSUER_SERIAL — decodifica y codifica certificados de firma para S/MIME

SINOPSIS

biblioteca “libcrypto”
#include <openssl/ts.h>

int

ESS_ISSUER_SERIAL *
d2i_ESS_ISSUER_SERIAL(ESS_ISSUER_SERIAL **val_out, const unsigned char **der_in, long length);

int
i2d_ESS_ISSUER_SERIAL(const ESS_ISSUER_SERIAL *val_in, unsigned char **der_out);

DESCRIPCIÓN

Estas funciones decodifican y codifican estructuras de atributos de certificados de firma. Para obtener detalles sobre la semántica, ejemplos, advertencias y errores, consulte ASN1_item_d2i(3).

d2i_ESS_SIGNING_CERT() y i2d_ESS_SIGNING_CERT() decodifican y codifican una estructura ASN.1 SigningCertificate definida en la RFC 2634 sección 5.4.

d2i_ESS_CERT_ID() y i2d_ESS_CERT_ID() decodifican y codifican una estructura ASN.1 ESSCertID definida en la RFC 2634 sección 5.4.1.

d2i_ESS_ISSUER_SERIAL() y i2d_ESS_ISSUER_SERIAL() decodifican y codifican una estructura ASN.1 IssuerSerial definida en la RFC 2634 sección 5.4.1.

VALORES DE RETORNO

d2i_ESS_SIGNING_CERT(), d2i_ESS_CERT_ID(), y d2i_ESS_ISSUER_SERIAL() devuelven un objeto ESS_SIGNING_CERT, ESS_CERT_ID, o ESS_ISSUER_SERIAL, respectivamente, o NULL si ocurre un error.

i2d_ESS_SIGNING_CERT(), i2d_ESS_CERT_ID(), y i2d_ESS_ISSUER_SERIAL() devuelven el número de bytes codificados con éxito o un valor negativo si ocurre un error.

VER TAMBIÉN

ASN1_item_d2i(3), ESS_SIGNING_CERT_new(3)

ESTÁNDARES

RFC 2634: Enhanced Security Services for S/MIME, sección 5: Signing Certificate Attribute

HISTORIA

Estas funciones aparecieron por primera vez en OpenSSL 1.0.0 y han estado disponibles desde OpenBSD 4.9.
