NOMBRE

libpipewire-module-raop-discover - Descubrimiento RAOP

DESCRIPCIÓN

Crea automáticamente dispositivos de salida RAOP (Airplay) basados en información de zeroconf.

Este módulo cargará module-raop-sink para cada stream anunciado que coincida con la regla con la acción create-stream.

Si no se proporcionan stream.rules, creará una salida para todos los streams anunciados.

NOMBRE DEL MÓDULO

libpipewire-module-raop-discover

OPCIONES DEL MÓDULO

Opciones específicas del comportamiento de este módulo

  • roap.discover-local = permite el descubrimiento de servicios locales también. Falso por defecto.
  • raop.latency.ms = latencia para todos los streams en microsegundos. Esto se puede sobrescribir en las reglas de stream.
  • stream.rules = <reglas>: coincide con reglas, usa acciones create-stream. Ver Salida AirPlay para propiedades del módulo.

EJEMPLO DE CONFIGURACIÓN

# ~/.config/pipewire/pipewire.conf.d/my-raop-discover.conf
context.modules = [
{   name = libpipewire-module-raop-discover
    args = {
        #roap.discover-local = false;
        #raop.latency.ms = 1000
        stream.rules = [
            {   matches = [
                    {    raop.ip = "~.*"
                         #raop.port = 1000
                         #raop.name = ""
                         #raop.hostname = ""
                         #raop.domain = ""
                         #raop.device = ""
                         #raop.transport = "udp" | "tcp"
                         #raop.encryption.type = "none" | "RSA" | "auth_setup" | "fp_sap25"
                         #raop.audio.codec = "PCM" | "ALAC" | "AAC" | "AAC-ELD"
                         #audio.channels = 2
                         #audio.format = "S16" | "S24" | "S32"
                         #audio.rate = 44100
                         #device.model = ""
                    }
                ]
                actions = {
                    create-stream = {
                        #raop.password = ""
                        stream.props = {
                            #target.object = ""
                            #media.class = "Audio/Sink"
                        }
                    }
                }
            }
        ]
    }
}
]
