NOMBRE

libpipewire-module-example-source - Fuente de ejemplo

DESCRIPCIÓN

La fuente de ejemplo es un buen punto de partida para escribir una fuente personalizada.

Consulte el código fuente para obtener más información.

NOMBRE DEL MÓDULO

libpipewire-module-example-source

OPCIONES DEL MÓDULO

  • node.name: un nombre único para el stream
  • node.description: un nombre legible por humanos para el stream
  • stream.props = {}: propiedades que se pasarán al stream

OPCIONES GENERALES

Opciones con comportamiento conocido.

  • remote.name
  • audio.format
  • audio.rate
  • audio.channels
  • audio.position
  • media.name
  • node.latency
  • node.name
  • node.description
  • node.group
  • node.virtual
  • media.class

EJEMPLO DE CONFIGURACIÓN

# ~/.config/pipewire/pipewire.conf.d/my-example-source.conf
context.modules = [
{   name = libpipewire-module-example-source
    args = {
        node.name = "example_source"
        node.description = "Mi Fuente de Ejemplo"
        stream.props = {
            audio.position = [ FL FR ]
        }
    }
}
]
