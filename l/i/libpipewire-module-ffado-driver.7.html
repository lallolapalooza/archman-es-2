NOMBRE

libpipewire-module-ffado-driver - Controlador de audio firewire FFADO

DESCRIPCIÓN

El módulo ffado-driver proporciona una fuente o sumidero utilizando la biblioteca libffado para leer y escribir en dispositivos de audio firewire.

NOMBRE DEL MÓDULO

libpipewire-module-ffado-driver

OPCIONES DEL MÓDULO

  • driver.mode: el modo del controlador, sink|source|duplex, por defecto duplex
  • ffado.devices: arreglo de dispositivos a abrir, por defecto "hw:0"
  • ffado.period-size: tamaño del periodo, por defecto 1024. Un valor de 0 usará la duración del grafo.
  • ffado.period-num: número de periodos, por defecto 3
  • ffado.sample-rate: tasa de muestreo, por defecto 48000. Un valor de 0 usará la tasa del grafo.
  • ffado.slave-mode: modo esclavo
  • ffado.snoop-mode: modo snoop
  • ffado.verbose: nivel de verbosidad de ffado
  • ffado.rtprio: prioridad de tiempo real de ffado, esto es por defecto la prioridad del servidor PipeWire + 5
  • ffado.realtime: modo de tiempo real de ffado. esto requiere rlimits correctamente configurados para adquirir programación FIFO en la prioridad ffado.rtprio
  • latency.internal.input: latencia de entrada adicional en frames
  • latency.internal.output: latencia de salida adicional en frames
  • source.props: Propiedades adicionales para el filtro fuente
  • sink.props: Propiedades adicionales para el filtro sumidero

OPCIONES GENERALES

Opciones con comportamiento conocido.

  • remote.name
  • audio.position
  • node.name
  • node.description
  • node.group
  • node.virtual
  • media.class
  • target.object para especificar el node.name o serial.id remoto al que enlazar

            # propiedades adicionales del sumidero
        }
    }
