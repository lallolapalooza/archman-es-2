libressl-ERR_print_errors(3)

Paquete: libressl

Licencias: ISC, custom:OpenSSL

ERR_PRINT_ERRORS(3) Manual de funciones de biblioteca ERR_PRINT_ERRORS(3)

NOMBRE

ERR_print_errors, ERR_print_errors_fp, ERR_print_errors_cb — imprime mensajes de error de OpenSSL

SINOPSIS

biblioteca “libcrypto”
#include <openssl/err.h>

void
ERR_print_errors(BIO *bp);

void
ERR_print_errors_fp(FILE *fp);

void
ERR_print_errors_cb(int (*cb)(const char *str, size_t len, void *u), void *u);

DESCRIPCIÓN

ERR_print_errors() es una función de conveniencia que imprime las cadenas de error de todos los errores que OpenSSL ha registrado en bp, vaciando así la cola de errores.

ERR_print_errors_fp() es lo mismo, excepto que la salida va a un FILE.

ERR_print_errors_cb() es lo mismo, excepto que la función de devolución de llamada, cb, se llama para cada línea de error con la cadena, longitud y datos de usuario u como parámetros de la devolución de llamada.

Las cadenas de error tienen el siguiente formato:

[pid]:error:[código de error]:[nombre de la biblioteca]:[nombre de la función]:[cadena de razón]:
[nombre del archivo]:[línea]:[mensaje de texto opcional]

El código de error es un número hexadecimal de 8 dígitos. El nombre de la biblioteca, el nombre de la función y la cadena de razón son texto ASCII, al igual que el mensaje de texto opcional si se estableció para el código de error respectivo.

Si no hay una cadena de texto registrada para el código de error dado, la cadena de error contendrá el código numérico.

VER TAMBIÉN

ERR(3), ERR_error_string(3), ERR_get_error(3), ERR_load_crypto_strings(3), SSL_load_error_strings(3)

HISTORIA

ERR_print_errors() apareció por primera vez en SSLeay 0.4.5. ERR_print_errors_fp() apareció por primera vez en SSLeay 0.6.0. Ambas funciones han estado disponibles desde OpenBSD 2.4.

ERR_print_errors_cb() apareció por primera vez en OpenSSL 0.9.7 y ha estado disponible desde OpenBSD 3.2.
