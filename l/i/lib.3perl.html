lib(3perl) Guía de referencia del programador de Perl lib(3perl)

NOMBRE

lib - manipular @INC en tiempo de compilación

SINOPSIS

use lib LISTA;
no lib LISTA;

DESCRIPCIÓN

Este es un módulo pequeño y simple que simplifica la manipulación de @INC en tiempo de compilación.

Típicamente se usa para agregar directorios adicionales a la ruta de búsqueda de Perl para que las sentencias posteriores "use" o "require" encuentren módulos que no se encuentran en la ruta de búsqueda predeterminada de Perl.

Agregar directorios a @INC

Los parámetros para "use lib" se agregan al principio de la ruta de búsqueda de Perl. Decir

use lib LISTA;

es *casi* lo mismo que decir

BEGIN { unshift(@INC, LISTA) }

Para cada directorio en LISTA (llamado $dir aquí), el módulo lib también verifica si existe un directorio llamado $dir/$nombre_arquitectura/auto. Si es así, se supone que el directorio $dir/$nombre_arquitectura es un directorio correspondiente específico de la arquitectura y se agrega a @INC antes de $dir. lib.pm también verifica si existen directorios llamados $dir/$version y $dir/$version/$nombre_arquitectura y agrega estos directorios a @INC.

El valor actual de $nombre_arquitectura se puede encontrar con este comando:

perl -V:archname

El comando correspondiente para obtener el valor actual de $version es:

perl -V:version

Para evitar fugas de memoria, se eliminan todas las entradas duplicadas al final de @INC.

Eliminar directorios de @INC

Normalmente, solo deberías agregar directorios a @INC. Si necesitas eliminar directorios de @INC, ten cuidado de eliminar solo aquellos que agregaste tú mismo o de los que estás seguro de que no son necesarios para otros módulos en tu script. Otros módulos pueden haber agregado directorios que necesitan para su correcto funcionamiento.

La sentencia "no lib" elimina todas las instancias de cada directorio nombrado de @INC.

Para cada directorio en LISTA (llamado $dir aquí), el módulo lib también verifica si existe un directorio llamado $dir/$nombre_arquitectura/auto. Si es así, se supone que el directorio $dir/$nombre_arquitectura es un directorio correspondiente específico de la arquitectura y también se elimina de @INC. lib.pm también verifica si existen directorios llamados $dir/$version y $dir/$version/$nombre_arquitectura y elimina estos directorios de @INC.

Restaurar @INC original

Cuando el módulo lib se carga por primera vez, registra el valor actual de @INC en un array @lib::ORIG_INC. Para restaurar @INC a ese valor, puedes decir

@INC = @lib::ORIG_INC;

ADVERTENCIAS

Para mantener lib.pm pequeño y simple, solo funciona con rutas de archivos de Unix. Esto no significa que solo funcione en Unix, sino que los usuarios no Unix deben primero traducir sus rutas de archivos a convenciones de Unix.

# Los usuarios de VMS que quieran poner [.stuff.moo] en
# su @INC escribirían
use lib 'stuff/moo';

NOTAS

En el futuro, este módulo probablemente usará File::Spec para determinar rutas, como lo hace ahora para Mac OS (donde funcionan las rutas estilo Unix o estilo Mac, y las rutas estilo Unix se convierten correctamente a rutas estilo Mac antes de agregarse a @INC).

Si intentas agregar un archivo a @INC de la siguiente manera:

use lib 'este_es_un_archivo.txt';

"lib" te advertirá sobre esto. Las únicas excepciones son los archivos con la extensión ".par" que están destinados a usarse como bibliotecas.

VER TAMBIÉN

FindBin - módulo opcional que trata con rutas relativas al archivo fuente.

PAR - módulo opcional que puede tratar archivos ".par" como bibliotecas de Perl.
