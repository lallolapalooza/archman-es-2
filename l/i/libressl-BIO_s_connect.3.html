DESCRIPCIÓN

BIO_s_connect() devuelve el método BIO de conexión. Esto es un envoltorio alrededor de las rutinas de conexión de sockets TCP/IP de la plataforma.

Usando BIOs de conexión, se pueden establecer conexiones TCP/IP y transferir datos usando solo rutinas BIO. De esta manera, cualquier operación específica de la plataforma es ocultada por la abstracción BIO.

Las operaciones de lectura y escritura en un BIO de conexión realizarán E/S en la conexión subyacente. Si no hay una conexión establecida y el puerto y el nombre de host (ver abajo) están configurados correctamente, primero se establecerá una conexión.

Los BIOs de conexión soportan BIO_puts(3) pero no BIO_gets(3).

Si la bandera de cierre está establecida en un BIO de conexión, entonces cualquier conexión activa se cerrará y el socket se cerrará cuando el BIO se libere.

Llamar a BIO_reset(3) en un BIO de conexión cerrará cualquier conexión activa y reiniciará el BIO a un estado donde pueda conectarse al mismo host nuevamente.

BIO_get_fd(3) coloca el socket subyacente en c si no es NULL y también devuelve el socket. Si c no es NULL, debe ser de tipo int *.

BIO_set_info_callback(3) y BIO_callback_ctrl(3) con un cmd de BIO_CTRL_SET_CALLBACK guardan el puntero a la función cb internamente en b y BIO_get_info_callback(3) recupera este puntero de función. Si se instala una función de devolución de llamada de información de este tipo, se invoca cada vez que ocurre un cambio de estado o un error en la máquina de estados del BIO de conexión. Los argumentos de la función de devolución de llamada incluyen el nuevo state en caso de un cambio de estado o el antiguo state en caso de un error y el valor res que la máquina de estados devolvería a cualquier operación que la invocó si no se hubiera instalado ninguna función de devolución de llamada de información. Si se instala una función de devolución de llamada de información, la máquina de estados devuelve el valor de retorno de la función de devolución de llamada de información en su lugar. En consecuencia, se supone que la función de devolución de llamada de información generalmente devuelve res. El efecto preciso del valor de retorno depende de desde qué operación se invocó la máquina de estados. Por lo general, se usa -1 para indicar un fallo y los valores de retorno menores o iguales a cero abortan la operación en cuestión, mientras que los valores positivos indican éxito y permiten que la operación continúe.

Las constantes de state pasadas a la función de devolución de llamada se nombran según la operación que debe realizarse a continuación. Se enumeran aquí en el orden en que se pasan los estados:

BIO_CONN_S_BEFORE
El BIO está inactivo y aún no se ha iniciado ninguna conexión.
BIO_CONN_S_GET_IP
El nombre de host al que conectarse necesita ser convertido a una dirección IP.
BIO_CONN_S_GET_PORT
El nombre del servicio al que conectarse necesita ser convertido a un número de puerto TCP.
BIO_CONN_S_CREATE_SOCKET
El socket TCP necesita ser creado con la llamada al sistema socket(2).
BIO_CONN_S_NBIO
Es posible que sea necesario configurar opciones de socket usando fcntl(2) y setsockopt(2).
BIO_CONN_S_CONNECT
La conexión necesita ser iniciada con la llamada al sistema connect(2).
BIO_CONN_S_BLOCKED_CONNECT
La llamada al sistema connect(2) habría bloqueado y necesita ser intentada nuevamente.
BIO_CONN_S_OK
La conexión se ha establecido y ahora se puede usar para transferir datos.

BIO_set_conn_hostname() usa la cadena name para establecer el nombre de host. El nombre de host puede ser una dirección IP. El nombre de host también puede incluir el puerto en el formato nombre_host:puerto. También es aceptable usar los formatos nombre_host/cualquier/otra/ruta o nombre_host:puerto/cualquier/otra/ruta.

BIO_set_conn_port() establece el puerto a port. port se busca como servicio usando getaddrinfo(3).

BIO_set_conn_ip() establece la dirección IP a ip usando formato binario, es decir, cuatro bytes que especifican la dirección IP en formato big-endian.

BIO_set_conn_int_port() establece el puerto usando port. port debe ser de tipo int *.

BIO_get_conn_hostname() devuelve el nombre de host del BIO de conexión o NULL si el BIO está inicializado pero no hay nombre de host establecido. BIO_get_conn_port() devuelve el puerto de conexión o NULL si no está configurado.

BIO_get_conn_ip() devuelve la dirección IP de conexión como una cadena o NULL si no está configurada.

BIO_get_conn_int_port() devuelve el puerto de conexión como un entero o -1 si no está configurado.

BIO_set_nbio() configura el BIO de conexión para operar en modo no bloqueante si n es distinto de cero, o en modo bloqueante si n es cero. Por defecto, los BIOs de conexión operan en modo bloqueante.

BIO_do_connect() intenta establecer una conexión al host y puerto configurados previamente. Devuelve 1 si la conexión se establece con éxito, 0 si la operación aún está en progreso (en modo no bloqueante) y -1 en caso de error.

BIO_new_connect(3) crea y devuelve un nuevo BIO de conexión inicializado con el nombre de host y el puerto especificados en name. El formato de name es hostname:port.

El BIO de conexión usa la función getaddrinfo(3) para resolver el nombre de host y el servicio/puerto. Si name contiene caracteres inválidos o si la resolución de direcciones falla, se devuelve NULL.

VALORES DE RETORNO

BIO_s_connect() devuelve el método BIO. Las funciones de configuración BIO_set_*() devuelven 1 si tienen éxito, 0 en caso de error.

Las funciones de obtención BIO_get_*() devuelven el valor solicitado o NULL en caso de error o si no está configurado.

BIO_new_connect() devuelve un puntero al nuevo BIO de conexión o NULL si ocurre un error.

BIO_do_connect() devuelve 1 en caso de éxito, 0 si la operación está en progreso (en modo no bloqueante) y -1 en caso de error.

EJEMPLO

Para establecer una conexión a un servidor web en el puerto 80:

#include <openssl/bio.h>
#include <stdio.h>

int main() {
    BIO *bio;
    const char *host = "example.com";
    const char *port = "80";
    char buf[256];
    int len;

    bio = BIO_new_connect_ex(host, port, BIO_TYPE_SOURCE_SINK);
    if (!bio) {
        fprintf(stderr, "Error creating BIO.\n");
        return 1;
    }

    if (BIO_do_connect(bio) <= 0) {
        fprintf(stderr, "Error connecting to %s:%s\n", host, port);
        BIO_free_all(bio);
        return 1;
    }

    printf("Connected to %s:%s\n", host, port);

    // ... realizar operaciones de lectura/escritura ...

    BIO_free_all(bio);
    return 0;
}

BIO_get_conn_port() devuelve el puerto como una cadena. Este valor de retorno es un puntero interno que no debe modificarse.

BIO_get_conn_ip() devuelve la dirección IP en formato binario.

BIO_get_conn_int_port() devuelve el puerto como un int.

BIO_set_nbio() establece el indicador de E/S no bloqueante a n. Si n es cero, se establece E/S bloqueante. Si n es 1, se establece E/S no bloqueante. La E/S bloqueante es la predeterminada. La llamada a BIO_set_nbio() debe realizarse antes de que se establezca la conexión porque la E/S no bloqueante se establece durante el proceso de conexión.

BIO_new_connect() combina BIO_new(3) y BIO_set_conn_hostname() en una sola llamada. Crea un nuevo BIO de conexión con name.

BIO_do_connect() intenta conectar el BIO proporcionado. Devuelve 1 si la conexión se estableció correctamente. Se devuelve un valor cero o negativo si la conexión no pudo establecerse. La llamada BIO_should_retry(3) debe usarse para BIOs de conexión no bloqueantes para determinar si la llamada debe reintentarse.

Si se establece E/S bloqueante, un valor no positivo de cualquier llamada de E/S se debe a una condición de error, aunque un retorno cero normalmente significará que la conexión se cerró.

Si el nombre del puerto se proporciona como parte del nombre del host, esto anulará cualquier valor establecido con BIO_set_conn_port(). Esto puede ser indeseable si la aplicación no desea permitir la conexión a puertos arbitrarios. Esto se puede evitar verificando la presencia del carácter ‘:’ en el nombre del host pasado y ya sea indicando un error o truncando la cadena en ese punto.

Los valores devueltos por BIO_get_conn_hostname(), BIO_get_conn_port(), BIO_get_conn_ip(), y BIO_get_conn_int_port() se actualizan cuando se intenta una conexión. Antes de cualquier intento de conexión, los valores devueltos son los establecidos por la propia aplicación.

Las aplicaciones no tienen que llamar a BIO_do_connect() pero pueden desear hacerlo para separar el proceso de conexión del procesamiento de otras E/S.

Si se establece E/S no bloqueante, se solicitarán reintentos según corresponda.

Además de BIO_should_read(3) y BIO_should_write(3), también es posible que BIO_should_io_special(3) sea verdadero durante el proceso de conexión inicial con la razón BIO_RR_CONNECT. Si se devuelve esto, es una indicación de que un intento de conexión se bloquearía. La aplicación debe tomar las medidas adecuadas para esperar hasta que el socket subyacente se haya conectado y reintentar la llamada.

Cuando una cadena que contiene un BIO de conexión se copia con BIO_dup_chain(3), BIO_set_conn_hostname(), BIO_set_conn_port(), BIO_set_nbio(), y BIO_set_info_callback(3) se llaman internamente para copiar automáticamente el nombre del host, el puerto, el indicador de E/S no bloqueante y la devolución de llamada de información del objeto BIO original al nuevo.

VALORES DE RETORNO

BIO_s_connect() devuelve el método BIO de conexión.

Cuando se llama en un objeto BIO de conexión, BIO_method_type(3) devuelve la constante BIO_TYPE_CONNECT y BIO_method_name(3) devuelve un puntero a la cadena estática "socket connect".

BIO_get_fd(3) devuelve el socket o -1 si el BIO no ha sido inicializado.

BIO_set_conn_hostname(), BIO_set_conn_port(), BIO_set_conn_ip(), y BIO_set_conn_int_port() siempre devuelven 1.

BIO_get_conn_hostname() devuelve el nombre del host conectado o NULL si no hay ninguno establecido.

BIO_get_conn_port() devuelve una cadena que representa el puerto conectado o NULL si no está establecido.

BIO_get_conn_ip() devuelve un puntero a la dirección IP conectada en formato binario o todos ceros si no está establecida.

BIO_get_conn_int_port() devuelve el puerto conectado o 0 si no se estableció ninguno.

BIO_set_nbio() siempre devuelve 1.

BIO_do_connect() devuelve 1 si la conexión se estableció correctamente y 0 o -1 si la conexión falló.

EJEMPLOS

Este ejemplo se conecta a un servidor web en el host local e intenta recuperar una página y copiar el resultado a la salida estándar.

BIO *cbio, *out;
int len;
char tmpbuf[1024];

ERR_load_crypto_strings();
cbio = BIO_new_connect("localhost:http");
out = BIO_new_fp(stdout, BIO_NOCLOSE);
if (BIO_do_connect(cbio) <= 0) {
	fprintf(stderr, "Error conectando al servidor\n");
	ERR_print_errors_fp(stderr);
	/* lo que sea ... */
}
BIO_puts(cbio, "GET / HTTP/1.0\n\n");
for(;;) {
	len = BIO_read(cbio, tmpbuf, 1024);
	if (len <= 0)
		break;
	BIO_write(out, tmpbuf, len);
}
BIO_free(cbio);
BIO_free(out);
