libressl-EVP_CIPHER_CTX_set_flags(3)

Paquete: libressl

Licencias: ISC, custom:OpenSSL

EVP_CIPHER_CTX_SET_FLAGS(3) Manual de funciones de biblioteca EVP_CIPHER_CTX_SET_FLAGS(3)

NOMBRE

EVP_CIPHER_CTX_set_flags, EVP_CIPHER_CTX_clear_flags, EVP_CIPHER_CTX_test_flags, EVP_CIPHER_CTX_rand_key, EVP_CIPHER_param_to_asn1, EVP_CIPHER_asn1_to_param, EVP_CIPHER_CTX_get_app_data, EVP_CIPHER_CTX_set_app_data — configuración inusual del contexto de cifrado EVP

SINOPSIS

biblioteca “libcrypto”
#include <openssl/evp.h>

void
EVP_CIPHER_CTX_set_flags(EVP_CIPHER_CTX *ctx, int flags);

void
EVP_CIPHER_CTX_clear_flags(EVP_CIPHER_CTX *ctx, int flags);

int
EVP_CIPHER_CTX_test_flags(EVP_CIPHER_CTX *ctx, int flags);

int
EVP_CIPHER_CTX_rand_key(EVP_CIPHER_CTX *ctx, unsigned char *key);

int
EVP_CIPHER_param_to_asn1(EVP_CIPHER_CTX *c, ASN1_TYPE *type);

int
EVP_CIPHER_asn1_to_param(EVP_CIPHER_CTX *c, ASN1_TYPE *type);

void *
EVP_CIPHER_CTX_get_app_data(const EVP_CIPHER_CTX *ctx);

void
EVP_CIPHER_CTX_set_app_data(const EVP_CIPHER_CTX *ctx, void *data);

DESCRIPCIÓN

EVP_CIPHER_CTX_set_flags() habilita los flags dados en ctx. EVP_CIPHER_CTX_clear_flags() deshabilita los flags dados en ctx. EVP_CIPHER_CTX_test_flags() comprueba si alguno de los flags dados está actualmente establecido en ctx, devolviendo el subconjunto de flags que están establecidos, o 0 si ninguno de ellos está establecido. Actualmente, el único flag de contexto de cifrado admitido es EVP_CIPHER_CTX_FLAG_WRAP_ALLOW; véase EVP_aes_128_wrap(3) para más detalles.

EVP_CIPHER_CTX_rand_key() genera una clave aleatoria de la longitud apropiada basada en el contexto de cifrado. El EVP_CIPHER puede proporcionar su propia rutina de generación de claves aleatorias para admitir claves de un formulario específico. El argumento key debe apuntar a un buffer al menos tan grande como el valor devuelto por EVP_CIPHER_CTX_key_length(3).

EVP_CIPHER_param_to_asn1() establece el parámetro de AlgorithmIdentifier ASN.1 basado en el cifrado pasado. Esto típicamente incluirá cualquier parámetro y un IV. El IV del cifrado (si existe) debe estar establecido cuando se realiza esta llamada. Esta llamada debe hacerse antes de que el cifrado sea realmente "utilizado" (antes de cualquier llamada a EVP_EncryptUpdate(3) o EVP_DecryptUpdate(3), por ejemplo). Esta función puede fallar si el cifrado no tiene soporte ASN.1.

EVP_CIPHER_asn1_to_param() establece los parámetros del cifrado basados en un parámetro de AlgorithmIdentifier ASN.1. El efecto preciso depende del cifrado. En el caso de RC2, por ejemplo, establecerá el IV y la longitud efectiva de la clave. Esta función debe llamarse después de que se establezca el tipo de cifrado base pero antes de que se establezca la clave. Por ejemplo, EVP_CipherInit(3) se llamará con el IV y la clave establecidos a NULL, se llamará a EVP_CIPHER_asn1_to_param() y finalmente se volverá a llamar a EVP_CipherInit(3) con todos los parámetros excepto la clave establecidos a NULL. Es posible que esta función falle si el cifrado no tiene soporte ASN.1 o los parámetros no se pueden establecer (por ejemplo, la longitud efectiva de la clave RC2 no es compatible).

VALORES DE RETORNO

EVP_CIPHER_CTX_rand_key() devuelve 1 en caso de éxito o 0 en caso de fallo.

EVP_CIPHER_param_to_asn1() y EVP_CIPHER_asn1_to_param() devuelven un valor mayor que cero en caso de éxito y cero o un número negativo en caso de fallo.

VER TAMBIÉN

evp(3), EVP_CIPHER_CTX_ctrl(3), EVP_CIPHER_CTX_get_cipher_data(3), EVP_CIPHER_nid(3), EVP_EncryptInit(3)

HISTORIA

EVP_CIPHER_CTX_set_app_data() y EVP_CIPHER_CTX_get_app_data() aparecieron por primera vez en SSLeay 0.8.0. EVP_CIPHER_param_to_asn1() y EVP_CIPHER_asn1_to_param() aparecieron por primera vez en SSLeay 0.9.0. Estas funciones han estado disponibles desde OpenBSD 2.4.

EVP_CIPHER_CTX_rand_key() apareció por primera vez en OpenSSL 0.9.8 y ha estado disponible desde OpenBSD 4.5.

ERRORES

El código ASN.1 está incompleto (y a veces es inexacto). Solo se ha probado para ciertos cifrados S/MIME comunes (RC2, DES, triple DES) en modo CBC.
