DESCRIPCIÓN

La estructura X509_OBJECT es un envoltorio superficial alrededor de un objeto de certificado X509 o una lista de revocación de certificados X509_CRL. El tipo de objeto almacenado en cualquier momento dado puede inspeccionarse con X509_OBJECT_get_type().

Cada objeto X509_STORE utiliza una pila de estructuras X509_OBJECT como su área de almacenamiento principal.

X509_OBJECT_new() asigna una nueva estructura X509_OBJECT. Establece el tipo de objeto a X509_LU_NONE y el puntero al certificado o CRL a NULL.

Si obj contiene un certificado X509, X509_OBJECT_free() llama a X509_free(3) sobre ese objeto interno. Si obj contiene una lista de revocación de certificados X509_CRL, llama a X509_CRL_free(3) sobre esa lista interna. Luego, X509_OBJECT_free() libera el almacenamiento utilizado para el propio obj.

Si type es X509_LU_X509, X509_OBJECT_idx_by_subject() y X509_OBJECT_retrieve_by_subject() buscan en la pila dada un certificado con el nombre de sujeto name. Si type es X509_LU_CRL, buscan una lista de revocación de certificados con el nombre del emisor name en su lugar.

Si obj contiene un certificado, X509_OBJECT_retrieve_match() busca en la pila dada un certificado con un nombre de sujeto coincidente; si contiene una lista de revocación de certificados, busca una lista de revocación de certificados con un nombre de emisor coincidente en su lugar; de lo contrario, busca un X509_OBJECT con un tipo coincidente.

VALORES DE RETORNO

X509_OBJECT_get_type() devuelve X509_LU_X509 si obj contiene un certificado, X509_LU_CRL si contiene una lista de revocación de certificados, o X509_LU_NONE si no contiene ninguno.

X509_OBJECT_new() devuelve el nuevo objeto o NULL si falla la asignación de memoria.

X509_OBJECT_get0_X509() devuelve un puntero interno al certificado contenido en obj o NULL si obj es NULL o no contiene ningún certificado.

X509_OBJECT_get0_X509_CRL() devuelve un puntero interno a la lista de revocación de certificados contenida en obj o NULL si obj es NULL o no contiene ninguna lista de revocación de certificados.

X509_OBJECT_idx_by_subject() devuelve el índice basado en cero del primer certificado o lista de revocación coincidente en la pila o -1 si type no es X509_LU_X509 ni X509_LU_CRL o si no se encuentra ninguna coincidencia.

X509_OBJECT_retrieve_by_subject() devuelve el primer certificado o lista de revocación coincidente en la pila o NULL si type no es X509_LU_X509 ni X509_LU_CRL o si no se encuentra ninguna coincidencia.

X509_OBJECT_retrieve_match() devuelve el primer X509_OBJECT coincidente o NULL si stack o obj es NULL o no se encuentra ninguna coincidencia.

HISTORIA

X509_OBJECT_idx_by_subject(), X509_OBJECT_retrieve_by_subject(), y X509_OBJECT_retrieve_match() aparecieron por primera vez en OpenSSL 0.9.6 y han estado disponibles desde OpenBSD 2.9.

X509_OBJECT_get_type(), X509_OBJECT_get0_X509(), y X509_OBJECT_get0_X509_CRL() aparecieron por primera vez en OpenSSL 1.1.0 y han estado disponibles desde OpenBSD 6.3.

X509_OBJECT_new() y X509_OBJECT_free() aparecieron por primera vez en OpenSSL 1.1.0 y han estado disponibles desde OpenBSD 7.1.
