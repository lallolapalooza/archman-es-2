NOMBRE

libnbd-release-notes-1.14 - notas de la versión de libnbd 1.14

DESCRIPCIÓN

Estas son las notas de la versión de la versión estable de libnbd 1.14. Describe los cambios principales desde la versión 1.12.

libnbd 1.14.0 fue lanzado el 1 de agosto de 2022.

Seguridad

No se encontraron problemas de seguridad en esta versión.

Si encuentra un problema de seguridad, lea SECURITY en el código fuente (en línea aquí: https://gitlab.com/nbdkit/libnbd/blob/master/SECURITY). Para conocer problemas de seguridad anteriores en libnbd, consulte libnbd-security(3).

Nuevas APIs

No se añadieron nuevas APIs en esta versión.

Mejoras en APIs existentes

Optimizaciones en nbd_pread_structured(3) (Eric Blake).

Muchas mejoras de rendimiento en los enlaces de Python: "nbd.pread" ahora evita una asignación y copia adicional de memoria. Ahora se pueden pasar buffers a "nbd.Buffer.from_bytearray". Nuevos métodos "nbd.Buffer.{to,from}_buffer" permiten el control sobre la copia y el uso compartido de "nbd.Buffer". Cualquier objeto similar a buffer se puede usar en "nbd.aio_{pread,pwrite}". Ahora funciona "len(nbd.Buffer(n))". Mejorados los mensajes de error cuando se pasan tipos incorrectos a varias APIs. Solucionado el uso de "PyGILState". (Eric Blake)

El "AioBuffer" de Golang ahora llama a panic en caso de uso incorrecto (Nir Soffer).

En las pruebas de golang, se usa "GOTRACEBACK=crash" para obtener volcados completos en caso de fallos.

kTLS ahora debería funcionar (transparentemente) cuando esté disponible en el kernel y GnuTLS. El uso de kTLS se indicará en la salida de depuración. (Daiki Ueno, František Krenželok)

Herramientas

Nueva herramienta nbddump(1) que puede generar un volcado hexadecimal eficiente del contenido de un servidor NBD.

nbdcopy(1) ahora respeta el tamaño de bloque mínimo/preferido del servidor NBD al copiar, lo que debería hacerlo más eficiente y evitar problemas con algunas configuraciones de qemu-nbd donde se debe respetar el tamaño de bloque mínimo para un funcionamiento correcto.

Pruebas

Nuevas pruebas para el soporte de URI "nbd+vsock://".

Otras mejoras y correcciones de errores

Se corrigió un raro interbloqueo TLS al leer de servidores lentos y soporte para apagado limpio al conectarse a qemu-nbd sobre TLS (gracias Michael Ablassmeier).

La biblioteca ahora usa la bandera de GnuTLS "GNUTLS_NO_SIGNAL" (si está disponible), que asegura que las conexiones TLS no deberían hacer que el programa principal salga con "SIGPIPE" en ciertos casos de fallo del servidor. (Libnbd ha usado durante mucho tiempo "MSG_NOSIGNAL" en conexiones no TLS, que tiene un efecto similar.)

Se realizaron varias mejoras en el fuzzing, incluido el soporte para el modo AFL++ clang-LTO, ASAN, permitiendo capturar casos de prueba semilla y pruebas extendidas de APIs.

Se corrigieron las pruebas para que funcionen en RHEL 7 y FreeBSD.

Documentación

No hubo cambios en esta versión.

Compilación

Se añadió la macro "ARRAY_SIZE" para simplificar el dimensionamiento de arrays estáticos (gracias Laszlo Ersek).

Se corrigieron varios errores encontrados por Coverity.
