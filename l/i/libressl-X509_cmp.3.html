libressl-X509_cmp(3)

Paquete: libressl

Licencias: ISC, custom:OpenSSL

X509_CMP(3) Manual de Funciones de Biblioteca X509_CMP(3)

NOMBRE

X509_cmp, X509_NAME_cmp, X509_issuer_and_serial_cmp, X509_issuer_name_cmp, X509_subject_name_cmp, X509_CRL_cmp, X509_CRL_match — comparar certificados X.509 y valores relacionados

SINOPSIS

biblioteca “libcrypto”
#include <openssl/x509.h>

int
X509_cmp(const X509 *a, const X509 *b);

int
X509_NAME_cmp(const X509_NAME *a, const X509_NAME *b);

int
X509_issuer_and_serial_cmp(const X509 *a, const X509 *b);

int
X509_issuer_name_cmp(const X509 *a, const X509 *b);

int
X509_subject_name_cmp(const X509 *a, const X509 *b);

int
X509_CRL_cmp(const X509_CRL *a, const X509_CRL *b);

int
X509_CRL_match(const X509_CRL *a, const X509_CRL *b);

DESCRIPCIÓN

X509_cmp() compara dos certificados X.509 usando memcmp(3) en los hashes de sus representaciones canónicas (DER) generadas con X509_digest(3). La función de hash es específica de la implementación: LibreSSL usa SHA-512, otras implementaciones usan SHA-1.

X509_NAME_cmp() compara dos objetos Name de X.501 usando sus representaciones canónicas (DER) generadas con i2d_X509_NAME(3).

X509_issuer_and_serial_cmp() compara los campos issuer y serialNumber de dos estructuras TBSCertificate, usando X509_NAME_cmp() para los campos issuer.

X509_issuer_name_cmp() compara los campos issuer de dos estructuras TBSCertificate usando X509_NAME_cmp().

X509_subject_name_cmp() compara los campos subject de dos estructuras TBSCertificate usando X509_NAME_cmp().

X509_CRL_cmp() tiene un nombre incorrecto; solo compara los campos issuer de dos estructuras TBSCertList usando X509_NAME_cmp().

X509_CRL_match() compara dos listas de revocación de certificados usando memcmp(3) en los hashes de sus representaciones canónicas (DER) generadas con X509_CRL_digest(3). La función de hash es específica de la implementación: LibreSSL usa SHA-512, otras implementaciones usan SHA-1.

VALORES DE RETORNO

Todas estas funciones devuelven 0 para indicar una coincidencia o un valor distinto de cero para indicar una discrepancia.

X509_NAME_cmp(), X509_issuer_and_serial_cmp(), X509_issuer_name_cmp(), X509_subject_name_cmp() y X509_CRL_cmp() pueden devolver -2 para indicar un error.

VER TAMBIÉN

i2d_X509_NAME(3), X509_CRL_new(3), X509_digest(3), X509_NAME_new(3), X509_new(3)

ESTÁNDARES

RFC 5280: Internet X.509 Public Key Infrastructure Certificate and Certificate Revocation List (CRL) Profile

  • sección 4.1: Campos básicos del certificado
  • sección 5.1: Campos de la CRL

HISTORIA

X509_issuer_and_serial_cmp(), X509_issuer_name_cmp(), y X509_subject_name_cmp() aparecieron por primera vez en SSLeay 0.5.1 y X509_NAME_cmp() y X509_CRL_cmp() en SSLeay 0.8.0. Estas funciones han estado disponibles desde OpenBSD 2.4.

X509_cmp() apareció por primera vez en OpenSSL 0.9.5 y ha estado disponible desde OpenBSD 2.7.

X509_CRL_match() apareció por primera vez en OpenSSL 1.0.0 y ha estado disponible desde OpenBSD 4.9.

ERRORES

Para X509_NAME_CMP(), X509_issuer_and_serial_cmp(), X509_issuer_name_cmp(), X509_subject_name_cmp() y X509_CRL_cmp(), el valor de retorno -2 a veces indica una discrepancia y a veces un error.
