PKCS7_GET_SIGNER_INFO(3) Manual de funciones de biblioteca PKCS7_GET_SIGNER_INFO(3)

NOMBRE

PKCS7_get_signer_info — recuperar signerInfos de un objeto SignedData

SINOPSIS

biblioteca “libcrypto”
#include <openssl/pkcs7.h>

STACK_OF(PKCS7_SIGNER_INFO) *
PKCS7_get_signer_info(PKCS7 *p7);

DESCRIPCIÓN

Esta función recupera el conjunto de estructuras SignerInfo del campo signerInfos de p7.

Estos pueden ser manipulados posteriormente con las funciones documentadas en PKCS7_add_attribute(3).

VALORES DE RETORNO

PKCS7_get_signer_info() devuelve un puntero interno a un objeto STACK_OF(PKCS7_SIGNER_INFO) o NULL en caso de fallo. Falla si p7 es NULL, si no tiene contenido, o si es de un tipo distinto a SignedData o SignedAndEnvelopedData.

VER TAMBIÉN

PKCS7_add_attribute(3), PKCS7_final(3), PKCS7_new(3), PKCS7_sign(3), PKCS7_sign_add_signer(3)

HISTORIA
