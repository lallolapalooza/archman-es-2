NOMBRE

libpipewire-module-pipe-tunnel - Túnel de tubería Unix

DESCRIPCIÓN

El módulo pipe-tunnel proporciona una fuente o sumidero que tuneliza todo el audio hacia o desde una tubería Unix respectivamente.

NOMBRE DEL MÓDULO

libpipewire-module-pipe-tunnel

OPCIONES DEL MÓDULO

  • tunnel.mode: el túnel deseado a crear. (Reproducción por defecto)
  • tunnel.may-pause: si se permite que el flujo del túnel se pause en xrun
  • pipe.filename: el nombre del archivo de la tubería.
  • stream.props: Propiedades adicionales para el flujo local.

Cuando tunnel.mode es capture, se crea un flujo de captura en la fuente por defecto. Las muestras capturadas de la fuente se escribirán en la tubería.

Cuando tunnel.mode es sink, se crea un nodo sumidero. Las muestras reproducidas en el sumidero se escribirán en la tubería.

Cuando tunnel.mode es playback, se crea un flujo de reproducción en el sumidero por defecto. Las muestras leídas de la tubería se reproducirán en el sumidero.

Cuando tunnel.mode es source, se crea un nodo fuente. Las muestras leídas de la tubería estarán disponibles en la fuente.

tunnel.may-pause permite que el flujo del túnel se inactive (pause) cuando no hay datos en la fifo o cuando la fifo está llena. Para los modos de túnel capture y playback, esto es verdadero por defecto. Para los modos de túnel source y sink, esto es falso por defecto. Un flujo en pausa consumirá cero CPU y se reanudará cuando la fifo vuelva a ser legible o escribible.

Cuando pipe.filename no se proporciona, se creará una fifo por defecto en /tmp/fifo_input o /tmp/fifo_output que podrá ser escrita y leída respectivamente, dependiendo del tunnel.mode seleccionado.

OPCIONES GENERALES

Opciones con comportamiento conocido.

  • remote.name
  • audio.format
  • audio.rate
  • audio.channels
  • audio.position
  • node.latency
  • node.name
  • node.description
  • node.group
  • node.virtual
  • media.class
  • target.object para especificar el nombre remoto o ID serial al que enlazar

Cuando no se especifica de otra manera, la tubería aceptará o producirá un flujo de muestras de 16 bits, estéreo, 48 KHz.

EJEMPLO DE CONFIGURACIÓN DE UN FLUJO DE REPRODUCCIÓN CON TUBERÍA

# ~/.config/pipewire/pipewire.conf.d/my-pipe-tunnel.conf
context.modules = [
{   name = libpipewire-module-pipe-tunnel
    args = {
        tunnel.mode = playback
        #tunnel.may-pause = true
        # Establecer el nombre de la tubería a la que tunelizar
        pipe.filename = "/tmp/fifo_output"
        #audio.format=<formato de muestra>
        #audio.rate=<tasa de muestreo>
        #audio.channels=<número de canales>
        #audio.position=<mapa de canales>
        #target.object=<nodo de destino remoto>
        stream.props = {
            # propiedades adicionales del sumidero
        }
    }
}
]
