ASN1_STRING_PRINT_EX(3) Manual de funciones de biblioteca ASN1_STRING_PRINT_EX(3)

NOMBRE

ASN1_STRING_print_ex, ASN1_STRING_print_ex_fp, ASN1_STRING_print, ASN1_tag2str — rutinas de salida de ASN1_STRING

SINOPSIS

biblioteca “libcrypto”
#include <openssl/asn1.h>

int
ASN1_STRING_print_ex(BIO *out, const ASN1_STRING *str, unsigned long flags);

int
ASN1_STRING_print_ex_fp(FILE *fp, const ASN1_STRING *str, unsigned long flags);

int
ASN1_STRING_print(BIO *out, const ASN1_STRING *str);

const char *
ASN1_tag2str(int tag);

DESCRIPCIÓN

Estas funciones muestran una estructura ASN1_STRING. ASN1_STRING se utiliza para representar todos los tipos de cadenas ASN.1.

ASN1_STRING_print_ex() muestra str en out, el formato viene determinado por las opciones flags. ASN1_STRING_print_ex_fp() es idéntica excepto que muestra en fp en su lugar.

ASN1_STRING_print() imprime str en out pero usando un formato diferente a ASN1_STRING_print_ex(). Reemplaza los caracteres no imprimibles (excepto CR, LF) con ‘.’.

ASN1_tag2str() devuelve un nombre legible por humanos de la etiqueta ASN.1 tag especificada.

ASN1_STRING_print() es una función obsoleta que debe evitarse; utilice ASN1_STRING_print_ex() en su lugar.

Aunque hay un gran número de opciones, ASN1_STRFLGS_RFC2253 es a menudo adecuada, o en terminales UTF-8, ASN1_STRFLGS_RFC2253 y ~ASN1_STRFLGS_ESC_MSB.

El conjunto completo de opciones admitidas para flags se enumera a continuación.

Se pueden escapar varios caracteres. Si ASN1_STRFLGS_ESC_2253 está configurado, se escapan los caracteres determinados por RFC 2253. Si ASN1_STRFLGS_ESC_CTRL está configurado, se escapan los caracteres de control. Si ASN1_STRFLGS_ESC_MSB está configurado, se escapan los caracteres con el bit MSB configurado: esta opción no debe usarse si el terminal interpreta correctamente las secuencias UTF-8.

El escape toma varias formas. Si el carácter que se está escapando es un carácter de 16 bits, se utiliza la forma "\UXXXX" que usa exactamente cuatro caracteres para la representación hexadecimal. Si es de 32 bits, se utiliza "\WXXXXXXXX" que usa ocho caracteres de su representación hexadecimal. Estas formas solo se usarán si la conversión a UTF-8 no está configurada (ver más abajo).

Los caracteres imprimibles normalmente se escapan usando el carácter de barra invertida (‘\’). Si ASN1_STRFLGS_ESC_QUOTE está configurado, entonces toda la cadena se rodea con comillas dobles: esto es posiblemente más legible que la notación de barra invertida. Otros caracteres usan "\XX" usando exactamente dos caracteres de su representación hexadecimal.

Si ASN1_STRFLGS_UTF8_CONVERT está configurado, los caracteres se convierten primero al formato UTF-8. Si el terminal admite la visualización de secuencias UTF-8, esta opción mostrará correctamente los caracteres multibyte.

Si ASN1_STRFLGS_IGNORE_TYPE está configurado, el tipo de cadena no se interpreta en absoluto: se asume que todo es un byte por carácter. Esto es principalmente para fines de depuración y puede dar lugar a una salida confusa en cadenas de varios caracteres.

Si ASN1_STRFLGS_SHOW_TYPE está configurado, entonces el propio tipo de cadena se imprime antes de su valor (por ejemplo, "BMPSTRING"), utilizando ASN1_tag2str().

En lugar de ser interpretado, el contenido de una cadena puede ser "volcado": esto simplemente muestra el valor de la cadena usando la forma #XXXX utilizando formato hexadecimal para cada octeto.

Si ASN1_STRFLGS_DUMP_ALL está configurado, se vuelca cualquier tipo.

Normalmente, los tipos de cadena que no son de caracteres (como OCTET STRING) se asumen como un byte por carácter; si ASN1_STRFLGS_DUMP_UNKNOWN está configurado, se volcarán en su lugar.

Cuando un tipo se vuelca normalmente, solo se imprimen los octetos de contenido; si ASN1_STRFLGS_DUMP_DER está configurado, se vuelca la codificación completa en su lugar (incluyendo los octetos de etiqueta y longitud).

ASN1_STRFLGS_RFC2253 incluye todas las banderas requeridas por RFC 2253. Es equivalente a ASN1_STRFLGS_ESC_2253 | ASN1_STRFLGS_ESC_CTRL | ASN1_STRFLGS_ESC_MSB | ASN1_STRFLGS_UTF8_CONVERT | ASN1_STRFLGS_DUMP_UNKNOWN | ASN1_STRFLGS_DUMP_DER.

VALORES DE RETORNO

ASN1_STRING_print_ex() y ASN1_STRING_print_ex_fp() devuelven el número de caracteres escritos o -1 si ocurrió un error.

ASN1_STRING_print() devuelve 1 si tiene éxito o 0 si hay un error.

ASN1_tag2str() devuelve una cadena estática.

VER TAMBIÉN

ASN1_parse_dump(3), ASN1_STRING_new(3), X509_NAME_print_ex(3), X509_signature_dump(3)

HISTORIA

NOMBRE

ASN1_STRING_print_ex - Imprime un ASN1_STRING.

SINAPSIS

#include <openssl/asn1.h>

int ASN1_STRING_print_ex(BIO *bp, ASN1_STRING *a, unsigned long flags);
int ASN1_STRING_print(BIO *bp, const ASN1_STRING *a);
int ASN1_UTCTIME_print(BIO *bp, const ASN1_UTCTIME *a);
int ASN1_GENERALIZEDTIME_print(BIO *bp, const ASN1_GENERALIZEDTIME *a);

DESCRIPCIÓN

ASN1_STRING_print_ex imprime el contenido del ASN1_STRING a en el BIO bp. El parámetro flags controla el formato de salida. Las siguientes banderas se pueden OR'd juntas:

ASN1_STRFLGS_UTF8_CONVERT

Intenta convertir el string a UTF8 si es posible. Esto es útil si el string original tiene una codificación diferente.

ASN1_STRFLGS_SHOW_TYPE

Prefija la salida con el tipo ASN.1 del string. Por ejemplo, "BMPSTRING(content)".

ASN1_STRFLGS_DUMP_ALL

Imprime todos los caracteres en formato hexadecimal si no son imprimibles. Útil para depuración.

ASN1_STRFLGS_NOCONST

Añade un sufijo a los strings que no son constantes. Esto significa que no se espera que sean modificados por el llamador. Este flag se utiliza internamente en libssl.

ASN1_STRING_print es una versión simplificada que imprime el contenido de a sin ninguna bandera especial. Es equivalente a llamar a ASN1_STRING_print_ex con flags establecido a 0.

ASN1_UTCTIME_print imprime un ASN1_UTCTIME en un formato legible. El formato es "YYMMDDHHMMSSZ" o "YYMMDDHHMMSS+HH'MM'".

ASN1_GENERALIZEDTIME_print imprime un ASN1_GENERALIZEDTIME en un formato legible. El formato es "YYYYMMDDHHMMSSZ" o "YYYYMMDDHHMMSS.ffffff+HH'MM'".

VALORES DE RETORNO

Todas estas funciones devuelven 1 en caso de éxito, o 0 en caso de error.

VER TAMBIÉN

ASN1_STRING_new(3), BIO_new(3).

HISTORIA

Las funciones ASN1_STRING_print_ex, ASN1_STRING_print, ASN1_UTCTIME_print y ASN1_GENERALIZEDTIME_print estuvieron disponibles desde OpenSSL 0.9.7.
