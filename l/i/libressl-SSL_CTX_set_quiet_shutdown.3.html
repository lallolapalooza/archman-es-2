libressl-SSL_CTX_set_quiet_shutdown(3)

Paquete: libressl

Licencias: ISC, custom:OpenSSL

SSL_CTX_SET_QUIET_SHUTDOWN(3) Manual de funciones de la biblioteca SSL_CTX_SET_QUIET_SHUTDOWN(3)

NOMBRE

SSL_CTX_set_quiet_shutdown, SSL_CTX_get_quiet_shutdown, SSL_set_quiet_shutdown, SSL_get_quiet_shutdown — manipular el comportamiento de cierre

SINOPSIS

biblioteca “libssl” libcrypto
#include <openssl/ssl.h>

void
SSL_CTX_set_quiet_shutdown(SSL_CTX *ctx, int mode);

int
SSL_CTX_get_quiet_shutdown(const SSL_CTX *ctx);

void
SSL_set_quiet_shutdown(SSL *ssl, int mode);

int
SSL_get_quiet_shutdown(const SSL *ssl);

DESCRIPCIÓN

SSL_CTX_set_quiet_shutdown() establece la bandera de “cierre silencioso” para ctx a mode. Los objetos SSL creados a partir de ctx heredan el mode válido en el momento en que se llama a SSL_new(3). mode puede ser 0 o 1.

SSL_CTX_get_quiet_shutdown() devuelve la configuración de “cierre silencioso” de ctx.

SSL_set_quiet_shutdown() establece la bandera de “cierre silencioso” para ssl a mode. La configuración permanece válida hasta que ssl se elimina con SSL_free(3) o se llama de nuevo a SSL_set_quiet_shutdown(). No se modifica cuando se llama a SSL_clear(3). mode puede ser 0 o 1.

SSL_get_quiet_shutdown() devuelve la configuración de “cierre silencioso” de ssl.

Normalmente, cuando se finaliza una conexión SSL, las partes deben enviar mensajes de alerta de “notificación de cierre” usando SSL_shutdown(3) para un cierre limpio.

Al establecer la bandera de “cierre silencioso” a 1, SSL_shutdown(3) establecerá las banderas internas a SSL_SENT_SHUTDOWN|SSL_RECEIVED_SHUTDOWN (luego SSL_shutdown(3) se comporta como SSL_set_shutdown(3) llamado con SSL_SENT_SHUTDOWN|SSL_RECEIVED_SHUTDOWN). Por lo tanto, la sesión se considera cerrada, pero no se envía ninguna alerta de “notificación de cierre” al par. Este comportamiento viola el estándar TLS.

El valor predeterminado es el comportamiento normal de cierre según lo descrito por el estándar TLS.

VALORES DE RETORNO

SSL_CTX_get_quiet_shutdown() y SSL_get_quiet_shutdown() devuelven la configuración actual.

VER TAMBIÉN

ssl(3), SSL_clear(3), SSL_free(3), SSL_new(3), SSL_set_shutdown(3), SSL_shutdown(3)
