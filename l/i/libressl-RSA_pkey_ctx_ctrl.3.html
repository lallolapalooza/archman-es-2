DESCRIPCIÓN

La función RSA_pkey_ctx_ctrl() es un envoltorio superficial de EVP_PKEY_CTX_ctrl(3) que solo tiene éxito si ctx coincide con EVP_PKEY_RSA o EVP_PKEY_RSA_PSS.

Todas las "funciones" restantes se implementan como macros.

La macro EVP_PKEY_CTX_set_rsa_padding() establece el modo de relleno RSA para ctx. El parámetro pad puede tomar el valor RSA_PKCS1_PADDING para relleno PKCS#1, RSA_NO_PADDING para sin relleno, RSA_PKCS1_OAEP_PADDING para relleno OAEP (solo cifrado y descifrado), RSA_X931_PADDING para relleno X9.31 (solo operaciones de firma) y RSA_PKCS1_PSS_PADDING (solo firma y verificación). Solo el último puede usarse con claves del tipo EVP_PKEY_RSA_PSS.

Dos modos de relleno RSA se comportan de manera diferente si se utiliza EVP_PKEY_CTX_set_signature_md(3). Si esta macro se llama para relleno PKCS#1, el búfer de texto plano es un valor de resumen real y se encapsula en una estructura DigestInfo de acuerdo con PKCS#1 al firmar, y se espera (y se elimina) esta estructura al verificar. Si este control no se utiliza con RSA y relleno PKCS#1, los datos proporcionados se utilizan directamente y no se encapsulan. En el caso del relleno X9.31 para RSA, se agrega o verifica el byte del identificador del algoritmo y se elimina si se llama a este control. Si no se llama, se espera que el primer byte del búfer de texto plano sea el byte del identificador del algoritmo.

La macro EVP_PKEY_CTX_get_rsa_padding() recupera el modo de relleno RSA para ctx.

La macro EVP_PKEY_CTX_set_rsa_keygen_bits() establece la longitud de clave RSA para la generación de claves RSA o RSA-PSS a mbits. El valor más pequeño admitido es 512 bits. Si no se especifica, se utilizan 1024 bits.

La macro EVP_PKEY_CTX_set_rsa_keygen_pubexp() establece el valor del exponente público para la generación de claves RSA o RSA-PSS a pubexp. Actualmente, debe ser un entero impar. El puntero pubexp es utilizado internamente por esta función, por lo que no debe modificarse ni liberarse después de la llamada. Si no se llama a esta macro, se utiliza 65537.

La macro EVP_PKEY_CTX_set_rsa_mgf1_md() establece el resumen MGF1 para los esquemas de relleno RSA a md. A menos que se especifique explícitamente, se utiliza el resumen de firma. El modo de relleno debe haberse establecido en RSA_PKCS1_OAEP_PADDING o RSA_PKCS1_PSS_PADDING. Si la clave es del tipo EVP_PKEY_RSA_PSS y tiene restricciones de uso, ocurre un error si se intenta establecer el resumen en algo diferente al valor restringido.

La macro EVP_PKEY_CTX_get_rsa_mgf1_md() recupera el resumen MGF1 para ctx. A menos que se especifique explícitamente, se utiliza el resumen de firma. El modo de relleno debe haberse establecido en RSA_PKCS1_OAEP_PADDING o RSA_PKCS1_PSS_PADDING.

Relleno óptimo de cifrado asimétrico

Las siguientes macros requieren que el modo de relleno se haya establecido en RSA_PKCS1_OAEP_PADDING.

La macro EVP_PKEY_CTX_set_rsa_oaep_md() establece el tipo de resumen de mensaje utilizado en RSA OAEP a md.

DESCRIPTION

These functions are used to control RSA key generation and operations using an EVP_PKEY_CTX context. They are used to set or get various parameters associated with RSA keys and operations.

Key generation

The following parameters can be set during key generation:

EVP_PKEY_CTX_set_rsa_padding()
Sets the padding mode to be used for RSA operations. The possible values for pad are RSA_PKCS1_PADDING, RSA_SSLV23_PADDING, RSA_NO_PADDING, RSA_ Peneral_PADDING, RSA_PKCS1_OAEP_PADDING and RSA_PKCS1_PSS_PADDING.
EVP_PKEY_CTX_set_rsa_keygen_bits()
Sets the number of bits in the RSA key to be generated to bits.
EVP_PKEY_CTX_set_rsa_keygen_pubexp()
Sets the public exponent to be used for the RSA key to be generated. The default value is RSA_F4 (65537).

RSA_PKCS1_OAEP_PADDING

The following macros are used when the padding mode is set to RSA_PKCS1_OAEP_PADDING.

EVP_PKEY_CTX_set_rsa_oaep_md()
Sets the message digest algorithm to be used for RSA OAEP padding to md.
EVP_PKEY_CTX_get_rsa_oaep_md()
Gets the message digest algorithm used in RSA OAEP padding into *pmd.
EVP_PKEY_CTX_set0_rsa_oaep_label()
Sets the RSA OAEP label to label and its length to len. If label is NULL or len is 0, the label is cleared. The library takes ownership of the label so the caller should not free the original memory pointed to by label.
EVP_PKEY_CTX_get0_rsa_oaep_label()
Gets the RSA OAEP label into *plabel. The return value is the label length. The resulting pointer is owned by the library and should not be freed by the caller.

Probabilistic signature scheme

The following macros require that the padding mode was set to RSA_PKCS1_PSS_PADDING.

EVP_PKEY_CTX_set_rsa_pss_saltlen()
Sets the RSA PSS salt length to len. Three special values are supported: RSA_PSS_SALTLEN_DIGEST sets the salt length to the digest length. RSA_PSS_SALTLEN_MAX sets the salt length to the maximum permissible value. When signing, RSA_PSS_SALTLEN_AUTO sets the salt length to the maximum permissible value. When verifying, RSA_PSS_SALTLEN_AUTO causes the salt length to be automatically determined based on the PSS block structure. If this macro is not called, a salt length value of RSA_PSS_SALTLEN_AUTO is used by default.
EVP_PKEY_CTX_get_rsa_pss_saltlen()
Retrieves the RSA PSS salt length for ctx.
EVP_PKEY_CTX_set_rsa_pss_keygen_md()
Restricts the digest algorithm the generated key can use to md.
EVP_PKEY_CTX_set_rsa_pss_keygen_mgf1_md()
Restricts the MGF1 algorithm the generated key can use to md.
EVP_PKEY_CTX_set_rsa_pss_keygen_saltlen()
Restricts the minimum salt length to saltlen.

Optional parameter restrictions can be specified when generating a PSS key. If any restrictions are set using the macros described above, then all parameters are restricted. For example, setting a minimum salt length also restricts the digest and MGF1 algorithms. If any restrictions are in place, then they are reflected in the corresponding parameters of the public key when (for example) a certificate request is signed.

If the key has usage restrictions and an attempt is made to set the salt length below the minimum value, an error occurs. Also, if the key has usage restrictions, RSA_PSS_SALTLEN_AUTO is not supported for verification.

RETURN VALUES

These functions return a positive value for success or 0 or a negative value for failure. In particular, a return value of -2 indicates the operation is not supported by the public key algorithm.
