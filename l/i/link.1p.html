LINK(1P) Manual del Programador POSIX LINK(1P)

PRÓLOGO

Esta página del manual forma parte del Manual del Programador POSIX. La implementación de esta interfaz en Linux puede diferir (consulte la página del manual de Linux correspondiente para obtener detalles sobre el comportamiento en Linux), o la interfaz puede no estar implementada en Linux.

NOMBRE

link — llama a la función link()

SINOPSIS

link archivo1 archivo2

DESCRIPCIÓN

La utilidad link realizará la llamada a la función:

link(archivo1, archivo2);

Un usuario puede necesitar privilegios apropiados para invocar la utilidad link.

OPCIONES

Ninguna.

OPERANDOS

Se admitirán los siguientes operandos:

archivo1
La ruta de un archivo existente.
archivo2
La ruta de la nueva entrada de directorio que se creará.

STDIN

No se utiliza.

ARCHIVOS DE ENTRADA

No se utiliza.

VARIABLES DE ENTORNO

Las siguientes variables de entorno afectarán la ejecución de link:

LANG
Proporciona un valor predeterminado para las variables de internacionalización que no están establecidas o están vacías. (Consulte el volumen de Definiciones Base de POSIX.1‐2017, Sección 8.2, Variables de internacionalización para conocer la precedencia de las variables de internacionalización utilizadas para determinar los valores de las categorías de localización).
LC_ALL
Si se establece en un valor de cadena no vacío, anula los valores de todas las demás variables de internacionalización.
LC_CTYPE
Determina la localización para la interpretación de secuencias de bytes de datos de texto como caracteres (por ejemplo, caracteres de un solo byte frente a caracteres multibyte en los argumentos).
LC_MESSAGES

Determina la localización que debe utilizarse para afectar al formato y contenido de los mensajes de diagnóstico escritos en la salida estándar.
NLSPATH
Determina la ubicación de los catálogos de mensajes para el procesamiento de LC_MESSAGES.

EVENTOS ASÍNCRONOS

Predeterminado.

STDOUT

Ninguno.

STDERR

La salida estándar de error solo se utilizará para mensajes diagnósticos.

    link(1p)

    Crear enlaces duros.
    1997-04-11

    SINOPSIS

    link

    DESCRIPCIÓN

    La utilidad link creará un enlace duro (hard link) entre el archivo especificado por el segundo argumento posicional y el archivo especificado por el primer argumento posicional. Los detalles de la implementación de los enlaces duros se describen en la especificación del Sistema de Archivos (file system).

    La utilidad link creará un enlace duro entre un archivo nuevo y un archivo existente. El nombre del nuevo archivo se especifica por el segundo argumento posicional. El nombre del archivo existente se especifica por el primer argumento posicional.

    Si el primer argumento posicional no es un archivo regular existente, link fallará.

    Si el segundo argumento posicional existe, link fallará.

    Por defecto, la utilidad link creará un enlace duro entre el archivo especificado por el segundo argumento posicional y el archivo especificado por el primer argumento posicional.

    La utilidad link solo debe permitir la creación de enlaces duros dentro del mismo sistema de archivos. Si los argumentos posicionales especifican archivos en diferentes sistemas de archivos, link fallará.

    OPERANDOS

    nombre_archivo_existente

    Un nombre de archivo que se refiere a un archivo regular existente.

    nombre_archivo_nuevo

    Un nombre de archivo para el nuevo enlace duro.

    EJEMPLOS

    Para crear un enlace duro llamado link_nuevo al archivo archivo_existente:

    link archivo_existente link_nuevo

    FUNDAMENTO

    La utilidad link proporciona una forma de crear enlaces duros entre archivos. Los enlaces duros son importantes para la manipulación de archivos y la organización del sistema. Esta utilidad se basa en la funcionalidad existente del sistema operativo para crear enlaces duros.

    DIRECCIONES FUTURAS

    En el futuro, se podrían considerar opciones adicionales para personalizar el comportamiento de la utilidad link, como la posibilidad de sobrescribir archivos existentes o manejar enlaces simbólicos.

    VER TAMBIÉN

    ln(1), unlink(2)
