EVP_SHA1(3) Manual de Funciones de Biblioteca EVP_SHA1(3)

NOMBRE

EVP_sha1, EVP_md5, EVP_md5_sha1, EVP_md4 — algoritmos de resumen de mensajes heredados

SINOPSIS

biblioteca “libcrypto”
#include <openssl/evp.h>

const EVP_MD *
EVP_sha1(void);

const EVP_MD *
EVP_md5(void);

const EVP_MD *
EVP_md5_sha1(void);

const EVP_MD *
EVP_md4(void);

DESCRIPCIÓN

Los siguientes algoritmos de resumen de mensajes están rotos criptográficamente. Ninguno de ellos debe usarse en código nuevo a menos que no haya otra opción.

EVP_sha1() implementa el algoritmo SHA-1 y produce 160 bits de salida a partir de una entrada dada. Ejemplos de protocolos y software que aún lo requieren incluyen OCSP, DNS y el sistema de control de versiones git.

EVP_md5() implementa el algoritmo MD5 y produce 128 bits de salida a partir de una entrada dada. Todavía se utiliza ocasionalmente cuando no se requiere seguridad pero un algoritmo hash rápido es beneficioso.

EVP_md5_sha1() produce resúmenes de mensajes MD5 y SHA-1 concatenados. No utilice esto a menos que sea necesario para el protocolo histórico SSLv3.

EVP_md4() implementa el algoritmo MD4 y produce 128 bits de salida a partir de una entrada dada. Ha sido marcado como "histórico" por el Grupo de Trabajo de Ingeniería de Internet desde 2011.

VALORES DE RETORNO

Estas funciones devuelven punteros a objetos estáticos EVP_MD que implementan las funciones hash.

VER TAMBIÉN

evp(3), EVP_DigestInit(3)

HISTORIAL

EVP_sha1() y EVP_md5() aparecieron por primera vez en SSLeay 0.5.1 y han estado disponibles desde OpenBSD 2.4.

EVP_md4() apareció por primera vez en OpenSSL 0.9.6 y ha estado disponible desde OpenBSD 2.9.

EVP_md5_sha1() apareció por primera vez en OpenSSL 1.1.0 y ha estado disponible desde OpenBSD 6.3.
