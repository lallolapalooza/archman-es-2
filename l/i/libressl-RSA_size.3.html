RSA_SIZE(3) Manual de funciones de la biblioteca RSA_SIZE(3)

NOMBRE

RSA_size, RSA_bits — obtener el tamaño del módulo RSA

SINOPSIS

biblioteca “libcrypto”
#include <openssl/rsa.h>

int
RSA_size(const RSA *rsa);

int
RSA_bits(const RSA *rsa);

DESCRIPCIÓN

RSA_size() devuelve el tamaño del módulo RSA en bytes. Se puede usar para determinar cuánta memoria se debe asignar para un valor cifrado con RSA.

RSA_bits() devuelve el número de bits significativos.

rsa y rsa->n no deben ser NULL.

VALORES DE RETORNO

El tamaño.

VER TAMBIÉN

BN_num_bits(3), RSA_get0_key(3), RSA_new(3), RSA_security_bits(3)

HISTORIA

RSA_size() apareció por primera vez en SSLeay 0.4.4 y ha estado disponible desde OpenBSD 2.4.

RSA_bits() apareció por primera vez en OpenSSL 1.1.0 y ha estado disponible desde OpenBSD 6.3.
