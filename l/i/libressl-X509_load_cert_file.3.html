libressl-X509_load_cert_file(3)

Paquete: libressl

Licencias: ISC, custom:OpenSSL

X509_LOAD_CERT_FILE(3) Manual de funciones de la biblioteca X509_LOAD_CERT_FILE(3)

NOMBRE

X509_load_cert_file, X509_load_crl_file, X509_load_cert_crl_file — leer, decodificar y almacenar en caché certificados y CRLs

SINOPSIS

biblioteca “libcrypto”
#include <openssl/x509_vfy.h>

int
X509_load_cert_file(X509_LOOKUP *ctx, const char *file, int type);

int
X509_load_crl_file(X509_LOOKUP *ctx, const char *file, int type);

int
X509_load_cert_crl_file(X509_LOOKUP *ctx, const char *file, int type);

DESCRIPCIÓN

X509_load_cert_file() con un type de X509_FILETYPE_PEM lee uno o más certificados en formato PEM del archivo dado file usando PEM_read_bio_X509_AUX(3); con un tipo de X509_FILETYPE_ASN1, si lee un certificado en formato DER usando d2i_X509_bio(3). Los certificados leídos se añaden al objeto de caché de memoria X509_STORE asociado con el ctx dado usando X509_STORE_add_cert(3).

X509_load_crl_file() con un type de X509_FILETYPE_PEM lee una o más listas de revocación de certificados en formato PEM del archivo dado file usando PEM_read_bio_X509_CRL(3); con un tipo de X509_FILETYPE_ASN1, si lee una lista de revocación de certificados en formato DER usando d2i_X509_CRL_bio(3). Las listas de revocación de certificados leídas se añaden al objeto de caché de memoria X509_STORE asociado con el ctx dado usando X509_STORE_add_crl(3).

X509_load_cert_crl_file() con un type de X509_FILETYPE_PEM lee uno o más certificados y/o listas de revocación de certificados en formato PEM del archivo dado file usando PEM_X509_INFO_read_bio(3) y los añade al objeto de caché de memoria X509_STORE asociado con el ctx dado usando X509_STORE_add_cert(3) y X509_STORE_add_crl(3), respectivamente.

X509_load_cert_crl_file() con un type de X509_FILETYPE_ASN1 es equivalente a X509_load_cert_file() y no puede usarse para leer una lista de revocación de certificados.

VALORES DE RETORNO

Estas funciones devuelven el número de objetos cargados o 0 si hay un error.

VER TAMBIÉN

d2i_X509_bio(3), PEM_read_PrivateKey(3), X509_LOOKUP_new(3), X509_OBJECT_get0_X509(3), X509_STORE_load_locations(3), X509_STORE_new(3)

HISTORIA

X509_load_cert_file() apareció por primera vez en SSLeay 0.8.0 y X509_load_crl_file() en SSLeay 0.9.0. Estas funciones han estado disponibles desde OpenBSD 2.4.

X509_load_cert_crl_file() apareció por primera vez en OpenSSL 0.9.5 y ha estado disponible desde OpenBSD 2.7.
