libressl-EVP_PKEY_size(3)

Paquete: libressl

Licencias: ISC, custom:OpenSSL

EVP_PKEY_SIZE(3) Manual de Funciones de Biblioteca EVP_PKEY_SIZE(3)

NOMBRE

EVP_PKEY_size, EVP_PKEY_bits, EVP_PKEY_security_bits — Funciones de información de EVP_PKEY

SINOPSIS

biblioteca “libcrypto”
#include <openssl/evp.h>

int
EVP_PKEY_size(const EVP_PKEY *pkey);

int
EVP_PKEY_bits(const EVP_PKEY *pkey);

int
EVP_PKEY_security_bits(const EVP_PKEY *pkey);

DESCRIPCIÓN

EVP_PKEY_size() devuelve el tamaño máximo en bytes necesario para el búfer de salida para casi cualquier operación que se pueda realizar con pkey. El uso principal es con EVP_SignFinal(3) y EVP_SealInit(3). El tamaño devuelto también es lo suficientemente grande para el búfer de salida de EVP_PKEY_sign(3), EVP_PKEY_encrypt(3), EVP_PKEY_decrypt(3) y EVP_PKEY_derive(3).

A menos que la documentación de la operación indique lo contrario, el tamaño devuelto por EVP_PKEY_size() es solo un límite superior y el contenido final del búfer de destino puede ser menor. Por lo tanto, es crucial tener en cuenta el tamaño indicado por la función que realiza la operación. Por ejemplo, EVP_PKEY_sign(3) devuelve esa longitud en el argumento *siglen.

Se desaconseja el uso de EVP_PKEY_size() con EVP_DigestSignFinal(3).

La mayoría de las funciones que utilizan un búfer de salida admiten pasar NULL para el búfer y un puntero a un entero para obtener el tamaño exacto que esta llamada a función entrega en el contexto en el que se llama. Esto permite que esas funciones se llamen dos veces, una para conocer el tamaño exacto del búfer, luego asignar el búfer entre medias y llamar a esa función de nuevo para realmente generar los datos. Para esas funciones, no es estrictamente necesario llamar a EVP_PKEY_size() para conocer el tamaño del búfer, pero aún puede ser útil en casos en los que se desea conocer el límite superior de antemano.

EVP_PKEY_size() es compatible con los siguientes algoritmos:

el mismo resultado que de:
CMAC EVP_MAX_BLOCK_LENGTH = 32
DH DH_size(3)
DSA DSA_size(3)
EC ECDSA_size(3)
ED25519 64, pero véase más abajo
HMAC EVP_MAX_MD_SIZE = 64
RSA RSA_size(3)
X25519 X25519_KEYLEN = 32

Para EVP_PKEY_ED25519, la situación es especial: aunque el tamaño de la clave es ED25519_KEYLEN = 32 bytes, EVP_PKEY_size() devuelve 64 porque la firma es más larga que las claves.

EVP_PKEY_bits() devuelve la longitud criptográfica del criptosistema al que pertenece la clave en pkey, en bits. La definición de longitud criptográfica es específica para el criptosistema de la clave. Los siguientes algoritmos son compatibles:

longitud criptográfica = el mismo resultado que de:
bits significativos en ...
DH el parámetro de dominio público p DH_bits(3)
DSA el parámetro de dominio público p DSA_bits(3)
EC el orden del grupo EC_GROUP_order_bits(3)
ED25519 253 —
RSA el módulo público RSA_bits(3)
X25519 253 —

EVP_PKEY_security_bits() devuelve la fortaleza de seguridad medida en bits de la pkey dada, según se define en NIST SP800-57. Los siguientes algoritmos son compatibles:

el mismo resultado que de:
DH DH_security_bits(3)
DSA DSA_security_bits(3)
EC EC_GROUP_order_bits(3) dividido por 2
ED25519 128
RSA RSA_security_bits(3)
X25519 128

Para claves EC, si el resultado es mayor que 80, se redondea a 256, 192, 128, 112 o 80.

VALORES DEVUELTOS

EVP_PKEY_size() y EVP_PKEY_bits() devuelven un número positivo o 0 si este tamaño no está disponible.

EVP_PKEY_security_bits() devuelve un número en el rango de 0 a 256 inclusive o -2 si esta función no es compatible con el algoritmo utilizado por pkey. Devuelve 0 si pkey es NULL.

VER TAMBIÉN

EVP_PKEY_decrypt(3), EVP_PKEY_derive(3), EVP_PKEY_encrypt(3), EVP_PKEY_new(3), EVP_PKEY_sign(3), EVP_SealInit(3), EVP_SignFinal(3)

HISTORIA

EVP_PKEY_size() apareció por primera vez en SSLeay 0.6.0 y EVP_PKEY_bits() en SSLeay 0.9.0. Ambas funciones han estado disponibles desde OpenBSD 2.4.

EVP_PKEY_security_bits() apareció por primera vez en OpenSSL 1.1.0 y ha estado disponible desde OpenBSD 7.2.
