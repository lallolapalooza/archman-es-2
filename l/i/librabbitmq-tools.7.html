LIBRABBITMQ-TOOLS(7) Cliente C de RabbitMQ LIBRABBITMQ-TOOLS(7)

NOMBRE

librabbitmq-tools - Herramientas AMQP de línea de comandos

DESCRIPCIÓN

Un conjunto de herramientas AMQP de línea de comandos basadas en librabbitmq. Esta página describe las opciones comunes y las convenciones utilizadas por todas las herramientas.

OPCIONES COMUNES

-s, --server=hostname:port

El nombre del host (o dirección) al que conectarse. Por defecto es localhost. El número de puerto también se puede especificar; si se omite, se usa el número de puerto AMQP estándar (5672).

--vhost=vhost

El vhost AMQP a especificar al conectarse. Por defecto es /.

--username=nombredeusuario

El nombre de usuario para autenticarse en el servidor AMQP. Por defecto es guest.

--password=contraseña

La contraseña para autenticarse en el servidor AMQP. Por defecto es guest.

VER TAMBIÉN

amqp-publish(1), amqp-consume(1), amqp-get(1)

El equipo de RabbitMQ <<info@rabbitmq.com>>
