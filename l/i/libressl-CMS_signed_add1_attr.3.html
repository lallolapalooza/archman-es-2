DESCRIPCIÓN

Un objeto CMS_SignerInfo tiene dos conjuntos opcionales de atributos X.501: un conjunto de atributos firmados en el array signedAttrs y un conjunto de atributos no firmados en el array unsignedAttrs. Las funciones CMS_signed_*() y CMS_unsigned_*() son similares, excepto que CMS_signed_*() modifica el conjunto de atributos firmados del objeto CMS_SignerInfo y CMS_unsigned_*() modifica el conjunto de atributos no firmados del objeto CMS_SignerInfo. Por brevedad, solo se describen las funciones CMS_signed_*().

CMS_signed_add1_attr() añade una copia profunda de attr al array signedAttrs de si, asignando un nuevo array si es necesario.

CMS_signed_add1_attr_by_NID(), CMS_signed_add1_attr_by_OBJ(), y CMS_signed_add1_attr_by_txt() crean un nuevo objeto de Atributo X.501 usando X509_ATTRIBUTE_create_by_NID(3), X509_ATTRIBUTE_create_by_OBJ(3), o X509_ATTRIBUTE_create_by_txt(3), respectivamente, y lo añaden al array signedAttrs de si.

CMS_signed_delete_attr() elimina el elemento con el índice base cero loc en el array signedAttrs de si.

CMS_signed_get0_data_by_OBJ(), CMS_signed_get_attr_by_NID(), y CMS_signed_get_attr_by_OBJ() buscan en el array comenzando después del índice start_after. Fallan si no se encuentra ningún objeto coincidente. CMS_signed_get0_data_by_OBJ() también falla si los datos no son del type solicitado.

Este sitio no está asociado de ninguna forma con Arch Linux ni afiliado a este proyecto. El contenido es únicamente una traducción de las páginas del manual de Arch publicadas en man.archlinux.org.

DESCRIPCIÓN

Añade un atributo nuevo al campo signedAttrs del mensaje CMS. El atributo se crea usando X509_ATTRIBUTE_create_by_OBJ(3) con el objeto obj y el valor value.

Añade un atributo nuevo al campo signedAttrs del mensaje CMS. El atributo se crea usando X509_ATTRIBUTE_create_by_NID(3) con el NID nid y el valor value.

Añade un atributo nuevo al campo signedAttrs del mensaje CMS. El atributo se crea usando X509_ATTRIBUTE_create_by_OBJ(3) con el objeto obj y el valor value. El tipo del valor se deduce del objeto obj.

Añade un atributo nuevo al campo signedAttrs del mensaje CMS. El atributo se crea usando X509_ATTRIBUTE_create_by_txt(3) con el tipo de atributo type, el tipo de valor value_type, y el valor value.

Añade un atributo nuevo al campo unsignedAttrs del mensaje CMS. El atributo se crea usando X509_ATTRIBUTE_create_by_OBJ(3) con el objeto obj y el valor value.

Añade un atributo nuevo al campo unsignedAttrs del mensaje CMS. El atributo se crea usando X509_ATTRIBUTE_create_by_NID(3) con el NID nid y el valor value.

Añade un atributo nuevo al campo unsignedAttrs del mensaje CMS. El atributo se crea usando X509_ATTRIBUTE_create_by_OBJ(3) con el objeto obj y el valor value. El tipo del valor se deduce del objeto obj.

Añade un atributo nuevo al campo unsignedAttrs del mensaje CMS. El atributo se crea usando X509_ATTRIBUTE_create_by_txt(3) con el tipo de atributo type, el tipo de valor value_type, y el valor value.

Elimina el atributo en la posición loc del array signedAttrs del mensaje CMS. Devuelve el atributo eliminado.

Elimina el atributo en la posición loc del array unsignedAttrs del mensaje CMS. Devuelve el atributo eliminado.

Busca un atributo en el array signedAttrs del mensaje CMS. Devuelve el índice del primer atributo cuyo NID coincide con nid y es mayor que start_after. Si start_after es menor que 0, se busca desde el principio del array. Si no se encuentra ningún atributo, se devuelve -1.

Busca un atributo en el array signedAttrs del mensaje CMS. Devuelve el índice del primer atributo cuyo OID coincide con oid y es mayor que start_after. Si start_after es menor que 0, se busca desde el principio del array. Si no se encuentra ningún atributo, se devuelve -1.

Busca un atributo en el array unsignedAttrs del mensaje CMS. Devuelve el índice del primer atributo cuyo NID coincide con nid y es mayor que start_after. Si start_after es menor que 0, se busca desde el principio del array. Si no se encuentra ningún atributo, se devuelve -1.

Busca un atributo en el array unsignedAttrs del mensaje CMS. Devuelve el índice del primer atributo cuyo OID coincide con oid y es mayor que start_after. Si start_after es menor que 0, se busca desde el principio del array. Si no se encuentra ningún atributo, se devuelve -1.

Además, el argumento start_after de CMS_signed_get0_data_by_OBJ() se interpreta de forma especial. Si start_after es -2 o menor, la función también falla si el array signedAttrs de si, contiene más de un objeto coincidente. Si start_after es -3 o menor, también falla a menos que el objeto coincidente contenga exactamente un valor.

CMS_signed_get_attr() devuelve el elemento del array en el índice basado en cero loc. Falla si el argumento loc es negativo o mayor o igual que el número de objetos en el array.

CMS_signed_get_attr_count() devuelve el número de objetos actualmente almacenados en el array signedAttrs de si.

VALORES DE RETORNO

CMS_signed_add1_attr(), CMS_signed_add1_attr_by_NID(), CMS_signed_add1_attr_by_OBJ(), CMS_signed_add1_attr_by_txt(), CMS_unsigned_add1_attr(), CMS_unsigned_add1_attr_by_NID(), CMS_unsigned_add1_attr_by_OBJ(), y CMS_unsigned_add1_attr_by_txt() devuelven 1 para éxito o 0 si ocurre un error.

CMS_signed_delete_attr() devuelve el elemento eliminado o NULL si el array signedAttrs es NULL, o si el argumento loc solicitado es negativo, o mayor o igual que el número de objetos en él.

CMS_unsigned_delete_attr() devuelve el elemento eliminado o NULL si el array unsignedAttrs es NULL, o si el argumento loc solicitado es negativo, o mayor o igual que el número de objetos en él.

CMS_signed_get0_data_by_OBJ() y CMS_unsigned_get0_data_by_OBJ() devuelven un puntero interno a los datos contenidos en el valor del primer objeto que tiene un índice mayor que start_after y un tipo que coincide con type, o NULL en caso de fallo.

CMS_signed_get_attr() y CMS_unsigned_get_attr() devuelven un puntero interno o NULL en caso de fallo.

CMS_signed_get_attr_by_NID(), CMS_signed_get_attr_by_OBJ(), CMS_unsigned_get_attr_by_NID(), y CMS_unsigned_get_attr_by_OBJ() devuelven el índice del primer objeto en el array que tiene un índice mayor que start_after y un tipo que coincide con nid o oid, respectivamente, o -1 en caso de fallo. Además, CMS_signed_get_attr_by_OBJ() y CMS_unsigned_get_attr_by_OBJ() devuelven -2 si OBJ_nid2obj(3) falla en el nid solicitado.

CMS_signed_get_attr_count() y CMS_unsigned_get_attr_count() devuelven el número de elementos del array o -1 en caso de fallo.
