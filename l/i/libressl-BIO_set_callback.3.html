DESCRIPCIÓN

BIO_set_callback_ex() y BIO_get_callback_ex() establecen y recuperan la devolución de llamada BIO. La devolución de llamada se llama durante la mayoría de las operaciones BIO de alto nivel. Puede ser utilizada con fines de depuración para rastrear operaciones en un BIO o para modificar su funcionamiento.

BIO_set_callback() y BIO_get_callback() son funciones obsoletas que establecen y recuperan la devolución de llamada BIO de estilo antiguo, que solo se utiliza si no se ha establecido ninguna devolución de llamada de estilo nuevo con BIO_set_callback_ex().

BIO_set_callback_arg() almacena el puntero internamente en b y BIO_get_callback_arg() lo recupera de b. El nombre de estas dos funciones es muy engañoso: el puntero nunca se pasa como argumento a ninguna función de devolución de llamada. Pero, por supuesto, las funciones de devolución de llamada pueden llamar a BIO_get_callback_arg() y acceder al puntero, al igual que cualquier otro código.

BIO_debug_callback() es una función de devolución de llamada de depuración estándar que imprime información relacionada con cada operación BIO. Si se llamó a BIO_set_callback_arg() con un argumento distinto de NULL, la información se envía al BIO al que apunta el puntero; de lo contrario, se utiliza la salida de error estándar.

Los argumentos de las funciones de devolución de llamada son los siguientes:

b
El BIO al que está adjunta la devolución de llamada.
oper
La operación que se está realizando, que es una de BIO_CB_CTRL, BIO_CB_FREE, BIO_CB_GETS, BIO_CB_PUTS, BIO_CB_READ o BIO_CB_WRITE. Para algunas operaciones, la devolución de llamada se llama dos veces, una antes y otra después de la operación real. En este último caso, oper se combina mediante OR bit a bit con BIO_CB_RETURN.
argp, argi, argl
El significado de estos tres argumentos depende del valor de oper, es decir, de la operación que se está realizando.
len
La longitud de los datos solicitados para leer o escribir. Esto solo es útil si oper es BIO_CB_READ, BIO_CB_WRITE o BIO_CB_GETS.
ret
Cuando oper no incluye BIO_CB_RETURN, es decir, cuando se invoca la devolución de llamada antes de una operación, el valor pasado a la devolución de llamada a través de ret es siempre 1. En este caso, si la devolución de llamada devuelve un valor negativo, la biblioteca aborta la operación solicitada y, en su lugar, devuelve el valor de retorno negativo de la devolución de llamada a la aplicación. Si la devolución de llamada devuelve un valor no negativo, ese valor de retorno es ignorado por la biblioteca y la operación se realiza normalmente.

Cuando oper incluye BIO_CB_RETURN, es decir, cuando se invoca la devolución de llamada después de una operación, el valor pasado a la devolución de llamada a través de ret es el valor de retorno que la operación devolvería a la aplicación si no hubiera una devolución de llamada presente. Cuando hay una devolución de llamada, la operación solo pasa este valor a la devolución de llamada y, en su lugar, devuelve el valor de retorno de la devolución de llamada a la aplicación.

processed
La ubicación apuntada se actualiza con el número de bytes realmente leídos o escritos. Solo se utiliza para BIO_CB_READ, BIO_CB_WRITE, BIO_CB_GETS y BIO_CB_PUTS.

La devolución de llamada normalmente debería simplemente devolver ret cuando haya terminado de procesar, a menos que desee específicamente abortar la operación o modificar el valor devuelto a la aplicación.

Las devoluciones de llamada se realizan de la siguiente manera:

En BIO_free(BIO *b):
antes de la operación de liberación:
cb_ex(b, BIO_CB_FREE, NULL, 0, 0, 0, 1, NULL)
o cb(b, BIO_CB_FREE, NULL,    0, 0, 1)
En BIO_read(BIO *b, void *out, int outl):
antes de la operación de lectura:
cb_ex(b, BIO_CB_READ, out, outl, 0, 0, 1, NULL)
o cb(b, BIO_CB_READ, out, outl,    0, 1)

después de la operación de lectura:
cb_ex(b, BIO_CB_READ|BIO_CB_RETURN, out, outl, 0, 0, ret, &bytes)
o cb(b, BIO_CB_READ|BIO_CB_RETURN, out, outl,    0, ret)
En BIO_write(BIO *b, const void *in, int inl):
antes de la operación de escritura:
cb_ex(b, BIO_CB_WRITE, in, inl, 0, 0, 1, NULL)
o cb(b, BIO_CB_WRITE, in, inl,    0, 1)

después de la operación de escritura:
cb_ex(b, BIO_CB_WRITE|BIO_CB_RETURN, in, inl, 0, 0, ret, &bytes)
o cb(b, BIO_CB_WRITE|BIO_CB_RETURN, in, inl,    0, ret)
En BIO_gets(BIO *b, char *out, int outl):

NAME

BIO_set_callback, BIO_get_callback, BIO_set_callback_arg, BIO_get_callback_arg, BIO_callback_fn_ex, BIO_callback_fn, BIO_debug_callback, BIO_set_callback_ex, BIO_get_callback_ex - establecer y obtener una función de retorno de llamada BIO

SYNOPSIS

#include <openssl/bio.h>

typedef void
    (*BIO_callback_fn)(BIO *b, int type, const char *buf, int len, int ret, void *user);

typedef void
    (*BIO_callback_fn_ex)(BIO *b, int type, const char *buf, int len, int ret, void *user, void *arg);

void BIO_set_callback(BIO *b, BIO_callback_fn *cb);
BIO_callback_fn *BIO_get_callback(BIO *b);

void BIO_set_callback_arg(BIO *b, void *arg);
void *BIO_get_callback_arg(BIO *b);

void BIO_set_callback_ex(BIO *b, BIO_callback_fn_ex *cb);
BIO_callback_fn_ex *BIO_get_callback_ex(BIO *b);

int BIO_debug_callback(BIO *b, int type, const char *buf, int len, int ret, void *user, void *arg);

DESCRIPTION

Estas funciones permiten instalar un manejador de retorno de llamada (callback) en un BIO. El manejador de retorno de llamada se invoca antes y después de ciertas operaciones en el BIO. Esto es útil para propósitos de depuración o para implementar una E/S personalizada que se puede registrar en un BIO existente.

BIO_set_callback() instala la función cb como el manejador de retorno de llamada para el BIO b. La función de retorno de llamada existente se elimina, y cualquier argumento de retorno de llamada se establece en NULL.

BIO_get_callback() devuelve el manejador de retorno de llamada instalado actualmente para el BIO b.

BIO_set_callback_arg() instala un puntero arg que se pasa a la función de retorno de llamada cada vez que se invoca.

BIO_get_callback_arg() devuelve el argumento de retorno de llamada establecido actualmente para el BIO b.

BIO_set_callback_ex() instala la función cb como el manejador de retorno de llamada extendido para el BIO b. Esto se llama BIO_callback_fn_ex. La función de retorno de llamada existente se elimina, y cualquier argumento de retorno de llamada se establece en NULL.

BIO_get_callback_ex() devuelve el manejador de retorno de llamada extendido instalado actualmente para el BIO b.

Los manejadores de retorno de llamada BIO_callback_fn y BIO_callback_fn_ex se invocan con los siguientes argumentos:

In BIO_read(BIO *b, char *out, int outl):
antes de la operación de lectura:
cb_ex(b, BIO_CB_GETS, out, outl, 0, 0, 1, NULL)
o cb(b, BIO_CB_GETS, out, outl,    0, 1)

después de la operación de lectura:
cb_ex(b, BIO_CB_GETS|BIO_CB_RETURN, out, outl, 0, 0, ret, &bytes)
o cb(b, BIO_CB_GETS|BIO_CB_RETURN, out, outl,    0, ret)
In BIO_puts(BIO *b, const char *in):
antes de la operación de escritura:
cb_ex(b, BIO_CB_PUTS, in, 0, 0, 0, 1, NULL)
o cb(b, BIO_CB_PUTS, in,    0, 0, 1)

después de la operación de escritura:
cb_ex(b, BIO_CB_PUTS|BIO_CB_RETURN, in, 0, 0, 0, ret, &bytes)
o cb(b, BIO_CB_PUTS|BIO_CB_RETURN, in,    0, 0, ret)
In BIO_ctrl(BIO *b, int cmd, long larg, void *parg):
antes de la operación de control:
cb_ex(b, BIO_CB_CTRL, parg, 0, cmd, larg, 1, NULL)
o cb(b, BIO_CB_CTRL, parg,    cmd, larg, 1)

después de la operación de control:
cb_ex(b, BIO_CB_CTRL|BIO_CB_RETURN, parg, 0, cmd, larg, ret, NULL)
o cb(b, BIO_CB_CTRL|BIO_CB_RETURN, parg,    cmd, larg, ret)
In BIO_callback_ctrl(BIO *b, int cmd, BIO_info_cb *fp):
antes de la operación de control:
cb_ex(b, BIO_CB_CTRL, fp, 0, cmd, 0, 1, NULL)
o cb(b, BIO_CB_CTRL, fp,    cmd, 0, 1)

después de la operación de control:
cb_ex(b, BIO_CB_CTRL|BIO_CB_RETURN, fp, 0, cmd, 0, ret, NULL)
o cb(b, BIO_CB_CTRL|BIO_CB_RETURN, fp,    cmd, 0, ret)

BIO_debug_callback() es una función de ejemplo que implementa un manejador de retorno de llamada que imprime información sobre las operaciones del BIO. Puede usarse como un manejador de retorno de llamada para depurar el uso de BIO.

RETURN VALUES

BIO_get_callback_ex() devuelve un puntero a la función cb_ex instalada previamente con BIO_set_callback_ex(), o NULL si no se instaló ningún retorno de llamada.

BIO_get_callback() devuelve un puntero a la función cb instalada previamente con BIO_set_callback(), o NULL si no se instaló ningún retorno de llamada.

BIO_get_callback_arg() devuelve el puntero pointer establecido previamente con BIO_set_callback_arg(), o NULL si no se estableció ningún puntero.

BIO_debug_callback() devuelve ret si el bit BIO_CB_RETURN está establecido en cmd, o 1 en caso contrario.

EXAMPLES

La función BIO_debug_callback() es un buen ejemplo. Su código fuente se encuentra en el archivo crypto/bio/bio_cb.c.

HISTORY

BIO_set_callback(), BIO_get_callback(), BIO_set_callback_arg(), y BIO_debug_callback() aparecieron por primera vez en SSLeay 0.6.0. BIO_get_callback_arg() apareció por primera vez en SSLeay 0.8.0. Estas funciones han estado disponibles desde OpenBSD 2.4.

BIO_callback_fn() apareció por primera vez en OpenSSL 1.1.0. BIO_callback_fn_ex(), BIO_set_callback_ex(), y BIO_get_callback_ex() aparecieron por primera vez en OpenSSL 1.1.1. Estas funciones han estado disponibles desde OpenBSD 7.1.
