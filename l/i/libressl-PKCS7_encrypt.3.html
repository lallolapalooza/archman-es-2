libressl-PKCS7_encrypt(3)

Paquete: libressl

Licencias: ISC, custom:OpenSSL

PKCS7_ENCRYPT(3) Manual de funciones de biblioteca PKCS7_ENCRYPT(3)

NOMBRE

PKCS7_encrypt — crea una estructura PKCS#7 envelopedData

SINOPSIS

biblioteca “libcrypto”
#include <openssl/pkcs7.h>

PKCS7 *
PKCS7_encrypt(STACK_OF(X509) *certs, BIO *in, const EVP_CIPHER *cipher, int flags);

DESCRIPCIÓN

PKCS7_encrypt() crea y devuelve una estructura PKCS#7 envelopedData. certs es una lista de certificados de destinatario. in es el contenido a cifrar. cipher es el cifrador simétrico a utilizar. flags es un conjunto opcional de indicadores.

Solo se admiten claves RSA en PKCS#7 y envelopedData, por lo que los certificados de destinatario proporcionados a esta función deben contener todos claves públicas RSA, aunque no necesariamente deben estar firmados utilizando el algoritmo RSA.

El algoritmo pasado en el parámetro cipher debe admitir la codificación ASN.1 de sus parámetros.

Muchos navegadores implementan una opción de "firmar y cifrar" que es simplemente un envelopedData S/MIME que contiene un mensaje firmado S/MIME. Esto se puede producir fácilmente almacenando el mensaje firmado S/MIME en un BIO de memoria y pasándolo a PKCS7_encrypt().

Los siguientes indicadores se pueden pasar en el parámetro flags.

Si se establece el indicador PKCS7_TEXT, se anteponen cabeceras MIME de tipo text/plain a los datos.

Normalmente, el contenido proporcionado se traduce al formato canónico MIME (según lo requieren las especificaciones S/MIME). Si se establece PKCS7_BINARY, no se realiza ninguna traducción. Esta opción debe usarse si los datos proporcionados están en formato binario; de lo contrario, la traducción los corromperá. Si se establece PKCS7_BINARY, se ignora PKCS7_TEXT.

Si se establece el indicador PKCS7_STREAM, se genera una estructura PKCS7 parcial adecuada para E/S en streaming: no se leen datos de in.

Si se establece el indicador PKCS7_STREAM, la estructura PKCS7 devuelta no está completa y la salida de sus contenidos a través de una función que no finaliza correctamente la estructura PKCS7 dará resultados impredecibles.

Varias funciones, incluidas PKCS7_final(3), SMIME_write_PKCS7(3), PEM_write_bio_PKCS7_stream(3), y i2d_PKCS7_bio_stream(3) finalizan la estructura. Alternativamente, la finalización se puede realizar obteniendo el BIO ASN.1 en streaming directamente usando BIO_new_PKCS7().

VALORES DE RETORNO

PKCS7_encrypt() devuelve una estructura PKCS7 o NULL si ocurrió un error. El error se puede obtener de ERR_get_error(3).

VER TAMBIÉN

PKCS7_decrypt(3), PKCS7_final(3), PKCS7_new(3), PKCS7_sign(3)

HISTORIAL

PKCS7_encrypt() apareció por primera vez en OpenSSL 0.9.5 y ha estado disponible desde OpenBSD 2.7.

El indicador PKCS7_STREAM fue admitido por primera vez en OpenSSL 1.0.0.
