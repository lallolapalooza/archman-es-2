libssh2_trace_sethandler(3)

Paquete: libssh2

Licencias: BSD

libssh2_trace_sethandler(3) libssh2 libssh2_trace_sethandler(3)

NOMBRE

libssh2_trace_sethandler - establece un manejador de salida de traza

SINOPSIS

#include <libssh2.h>
typedef void (*libssh2_trace_handler_func)(LIBSSH2_SESSION *session,
                                           void *context,
                                           const char *data,
                                           size_t length);
int
libssh2_trace_sethandler(LIBSSH2_SESSION *session,
                         void *context,
                         libssh2_trace_handler_func callback);

DESCRIPCIÓN

libssh2_trace_sethandler instala un manejador de salida de traza para su aplicación. Por defecto, cuando la traza se ha activado mediante una llamada a libssh2_trace(), toda la salida se escribe en stderr. Llamando a este método y pasando un puntero de función que coincida con el prototipo libssh2_trace_handler_func, libssh2 llamará de vuelta a medida que genera la salida de traza. Esto se puede usar para capturar la salida de traza y ponerla en un archivo de registro o en una ventana de diagnóstico. Esta función no tiene ningún efecto a menos que libssh2 se haya compilado para soportar esta opción, y una típica "build de lanzamiento" podría no hacerlo.

context puede usarse para pasar datos definidos por el usuario de forma arbitraria de vuelta al callback cuando se invoca.

DISPONIBILIDAD

Añadido en la versión 1.2.3 de libssh2
