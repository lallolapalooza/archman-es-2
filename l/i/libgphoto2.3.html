NOMBRE

libgphoto2 - biblioteca multiplataforma para cámaras digitales

SINOPSIS

#include <gphoto2/gphoto2.h>

DESCRIPCIÓN

La biblioteca gphoto2 proporciona a las aplicaciones acceso a una variedad de cámaras.

Esta página man se ampliará con documentación generada automáticamente de los tipos de interfaz y métodos utilizados para la comunicación entre la biblioteca gphoto2 y un frontend.

ARCHIVOS

~/.gphoto/settings
Aquí las aplicaciones gphoto2 pueden almacenar su configuración utilizada para acceder a gphoto2.

Para rastrear errores, puede agregar el parámetro --debug a la línea de comandos de gphoto2 y, si se trata de problemas USB, establecer la variable de entorno USB_DEBUG=1.

VARIABLES DE ENTORNO

CAMLIBS
Si está establecida, define el directorio donde la biblioteca libgphoto2 busca sus controladores de cámara (camlibs). Solo necesita establecer esto en sistemas Windows y en instalaciones defectuosas/de prueba.
IOLIBS
Si está establecida, define el directorio donde la biblioteca libgphoto2_port busca sus controladores de E/S (iolibs). Solo necesita establecer esto en sistemas Windows y en instalaciones defectuosas/de prueba.
LD_DEBUG
Establézcala a all para recibir mucha información de depuración con respecto a la carga de bibliotecas en sistemas basados en ld.
USB_DEBUG
Si está establecida, define el nivel de depuración numérico con el que la biblioteca libusb imprimirá mensajes. Para obtener alguna salida de depuración, establézcala a 1.
