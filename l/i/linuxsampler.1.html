NOMBRE

linuxsampler - sampler modular capaz de streaming

SINOPSIS

linuxsampler [OPCIONES]

DESCRIPCIÓN

LinuxSampler es un sampler modular capaz de streaming. Actualmente soporta los formatos de sampler Gigasampler/GigaStudio (.gig), SoundFont v2 (.sf2) y SFZ v2 (.sfz).

El sampler está diseñado como backend, es decir, una aplicación de consola similar a un servidor. Necesitarás una aplicación frontend como QSampler o JSampler/Fantasia, que proporcionan una interfaz gráfica de usuario (GUI) para controlar el sampler y gestionar las sesiones del sampler de manera conveniente. Si lo prefieres, también puedes controlar el sampler desde la línea de comandos, por ejemplo, utilizando la aplicación de shell lscp(1) que viene con LinuxSampler, la cual proporciona resaltado de color compatible con LSCP, autocompletado y más. Dado que la interfaz de red LSCP se basa en un protocolo de texto legible por humanos, también puedes enviar comandos LSCP por cualquier otro medio al sampler, por ejemplo, utilizando telnet(1) o netcat(1). Puedes encontrar ejemplos e información detallada sobre el protocolo de red de LinuxSampler (LSCP) en http://linuxsampler.org/documentation.html#lscp_spec

Se admiten varios sistemas de drivers de audio y MIDI, como ALSA (audio y MIDI), JACK (audio y MIDI), ASIO, CoreAudio, CoreMIDI, Arts, MidiShare y MME. LinuxSampler también se puede ejecutar como un plugin de instrumento virtual. Los siguientes formatos de plugin de instrumento son actualmente compatibles: AudioUnit (AU), DSSI, LV2 y VST. También puedes cargar plugins de efectos en el sampler. Actualmente, solo se admite el formato de plugin LADSPA para efectos internos del sampler.

Si estás utilizando sonidos en formato Gigasampler/GigaStudio, es posible que también quieras instalar la aplicación gráfica de edición de instrumentos llamada "gigedit", que puede ser lanzada directamente por LinuxSampler, permitiendo editar instrumentos en tiempo real (los cambios son inmediatamente audibles, sin necesidad de recargar los archivos de sonido en el sampler).

OPCIONES

--ejecutar-despues-de-iniciar
Ejecuta los comandos de shell proporcionados después de que la inicialización de la aplicación se haya completado. Puedes usar esto para restaurar automáticamente una sesión de sampler anterior al iniciar, por ejemplo, enviando un archivo LSCP previamente guardado vía netcat(1) al sampler.
--ayuda
Imprime la ayuda de la línea de comandos y sale.
--version
Imprime la información de la versión y sale.
--perfil
Esta opción ya no es compatible, ya que el código de perfilado correspondiente está roto actualmente. Comportamiento original: Muestra mensajes de benchmark en la consola. Esto refleja la eficiencia actual como un recuento teórico de voces (BogoVoice), que es algo así como un límite teórico de la cantidad de voces que se pueden renderizar en el escenario dado. No incluye todos los aspectos del sampler, por eso este valor suele ser más alto de lo que realmente puedes lograr en tu máquina. Ten en cuenta también que este valor depende del parche de instrumento que estés usando y de lo que estés tocando. Para una prueba de rendimiento compacta del núcleo de síntesis, independiente de los drivers y archivos de instrumentos, es posible que desees usar el que viene con los archivos fuente del sampler (directorio "benchmarks" de los archivos fuente).
--sin-optimizar
Deshabilita las optimizaciones de ensamblado. Normalmente, el sampler detectará las características específicas de la CPU como MMX y SSE en tiempo de ejecución y usará un código optimizado de ensamblado apropiado en ese caso. Con este interruptor, puedes deshabilitar esta función y forzar al sampler a omitir las optimizaciones de ensamblado en tiempo de ejecución.
--estadisticas
Muestra el recuento de voces y flujos de disco periódicamente en la consola.
--direccion-lscp DIRECCIÓN_IP
Define la dirección IP en la que debe escuchar el servidor LSCP (por defecto: cualquiera).
--puerto-lscp NÚMERO
Define el puerto TCP en el que debe escuchar el servidor LSCP (por defecto: 8888).
--crear-db-instrumentos [ARCHIVO]
Crea un archivo de base de datos con el nombre de archivo dado que puede ser utilizado por el sistema de base de datos de instrumentos del sampler para mantener la colección de bibliotecas de instrumentos del usuario. Cuando se proporciona este argumento, el sampler solo creará el archivo de la DB de instrumentos y saldrá. Si se omite el argumento de archivo opcional, se utilizará una ubicación predeterminada para el archivo de la DB de instrumentos.
--ubicacion-db-instrumentos ARCHIVO
Anula la ubicación del archivo de base de datos que el sampler debe utilizar para su sistema de base de datos de instrumentos (por defecto: /var/lib/linuxsampler/instruments.db).

VARIABLES DE ENTORNO

LINUXSAMPLER_PLUGIN_DIR
Permite anular el directorio donde LinuxSampler debe buscar los plugins de editor de instrumentos.
LADSPA_PATH
Permite anular el directorio donde LinuxSampler debe buscar los plugins de efectos LADSPA. Se pueden dar varias rutas, separadas por el carácter de dos puntos (":") en sistemas POSIX (es decir, Linux y Mac), o separadas por el carácter de punto y coma (";") en sistemas Windows.
