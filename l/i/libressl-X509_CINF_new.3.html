X509_CINF_NEW(3) Manual de Funciones de Biblioteca X509_CINF_NEW(3)

NOMBRE

X509_CINF_new, X509_CINF_free, X509_VAL_new, X509_VAL_free, X509_CERT_AUX_new, X509_CERT_AUX_free — objetos de información de certificados X.509

SINOPSIS

biblioteca “libcrypto”
#include <openssl/x509.h>

X509_CINF *
X509_CINF_new(void);

void
X509_CINF_free(X509_CINF *inf);

X509_VAL *
X509_VAL_new(void);

void
X509_VAL_free(X509_VAL *val);

X509_CERT_AUX *
X509_CERT_AUX_new(void);

void
X509_CERT_AUX_free(X509_CERT_AUX *aux);

DESCRIPCIÓN

X509_CINF_new() asigna y inicializa un objeto X509_CINF vacío, representando una estructura TBSCertificate ASN.1 definida en la sección 4.1 de RFC 5280. Se utiliza dentro del objeto X509 y contiene la información principal del certificado X.509, incluyendo el sujeto, clave pública, emisor, número de serie, período de validez y extensiones. X509_CINF_free() libera inf.

X509_VAL_new() asigna y inicializa un objeto X509_VAL vacío, representando una estructura Validity ASN.1 definida en la sección 4.1 de RFC 5280. Se utiliza dentro del objeto X509_CINF y contiene el período de validez del certificado. X509_VAL_free() libera val.

X509_CERT_AUX_new() asigna y inicializa una estructura X509_CERT_AUX vacía. Puede utilizarse dentro de un objeto X509 para almacenar datos auxiliares opcionales no estándar añadidos a un certificado, por ejemplo, nombres alias amigables y datos de confianza. X509_CERT_AUX_free() libera aux.

VALORES DE RETORNO

X509_CINF_new(), X509_VAL_new(), y X509_CERT_AUX_new() devuelven el nuevo objeto X509_CINF, X509_VAL, o X509_CERT_AUX, respectivamente, o NULL si ocurre un error.

VER TAMBIÉN

d2i_X509_CINF(3), X509_add1_trust_object(3), X509_CERT_AUX_print(3), X509_keyid_set1(3), X509_new(3)

ESTÁNDARES

RFC 5280: Perfil de Certificado y Lista de Revocación de Certificados (CRL) de Infraestructura de Clave Pública Internet X.509

HISTORIA

X509_CINF_new(), X509_CINF_free(), X509_VAL_new(), y X509_VAL_free() aparecieron en SSLeay 0.4 o anterior y han estado disponibles desde OpenBSD 2.4.

X509_CERT_AUX_new() y X509_CERT_AUX_free() aparecieron por primera vez en OpenSSL 0.9.5 y han estado disponibles desde OpenBSD 2.7.
