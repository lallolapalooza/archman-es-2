LIBKECCAK_KECCAKSUM_FD(3) Manual de funciones de la biblioteca LIBKECCAK_KECCAKSUM_FD(3)

NOMBRE

libkeccak_keccaksum_fd - Calcula la suma hash Keccak de un archivo

SINOPSIS

#include <libkeccak.h>
int libkeccak_keccaksum_fd(int fd, struct libkeccak_state *state, const struct libkeccak_spec *spec, void *hashsum);

Enlace con -lkeccak.

DESCRIPCIÓN

La función libkeccak_keccaksum_fd() calcula una suma hash Keccak de un archivo, cuyo descriptor de archivo se especifica por fd (y debe estar al principio del archivo). La sintonización del algoritmo hash se especifica por *spec.

El hash se almacena en forma binaria en hashsum. hashsum debe tener un tamaño de asignación de al menos (((spec->output + 7) / 8) * sizeof(char)).

*state no debe estar inicializado. libkeccak_keccaksum_fd() inicializa *state por sí misma. Por lo tanto, habría una fuga de memoria si *state ya estuviera inicializado.

VALORES DE RETORNO

La función libkeccak_keccaksum_fd() devuelve 0 en caso de éxito. En caso de error, se devuelve -1 y se establece errno para describir el error.

ERRORES

La función libkeccak_keccaksum_fd() puede fallar por cualquier motivo, excepto aquellos que resulten en que errno se establezca en EINTR, especificados para las funciones read(2), malloc(3) y realloc(3).

NOTAS

Tenga en cuenta que libkeccak_keccaksum_fd() calcula el hash del archivo hasta que se llega al final. Para tuberías y sockets, esto significa hasta que se cierra el archivo. Pero para los dispositivos de carácter, esto suele significar nunca. Por lo tanto, intentar calcular el hash de archivos en /dev suele ser una mala idea. libkeccak_keccaksum_fd() no verifica la longitud del archivo ni el tipo de archivo antes de calcular el hash, ya que esto podría limitar lo que puede hacer y hacer que la biblioteca sea más compleja.

libkeccak_keccaksum_fd() no se detiene si se interrumpe (read(2) devuelve EINTR.)

libkeccak_keccaksum_fd() asume que toda la información no es sensible y, por lo tanto, no realizará ninguna eliminación segura de la información.

libkeccak_keccaksum_fd() no valida la sintonización del algoritmo.

EJEMPLO

Este ejemplo calcula el hash Keccak[b = 1024, c = 576, n = 256] de la entrada estándar y muestra el hash, en formato hexadecimal, en la salida estándar.

struct libkeccak_state state;
struct libkeccak_spec spec;
char binhash[256 / 8];
char hexhash[256 / 8 * 2 + 1];
spec.bitrate = 1024;
spec.capacity = 576;
spec.output = 256;
if (libkeccak_keccaksum_fd(STDIN_FILENO, &state, &spec, binhash) < 0)
	goto fail;
libkeccak_behex_lower(hexhash, binhash, sizeof(binhash));
printf("%s\n", hexhash);
libkeccak_state_destroy(&state);
