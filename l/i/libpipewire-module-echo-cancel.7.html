NOMBRE

libpipewire-module-echo-cancel - Cancelación de eco

DESCRIPCIÓN

El módulo echo-cancel realiza la cancelación de eco.

El módulo crea nodos de origen y sumidero de captura echo-cancel virtuales y las transmisiones asociadas.

El módulo echo-cancel se utiliza principalmente en aplicaciones de videoconferencia o audioconferencia. Cuando los otros participantes hablan y el audio se reproduce a través de los altavoces, la señal es capturada de nuevo por el micrófono y enviada de vuelta a los otros participantes (junto con lo que usted está hablando), lo que resulta en un eco. Esto es molesto porque los otros participantes escucharán su propio eco de usted.

Conceptualmente, el cancelador de eco está compuesto por 4 transmisiones:

.--------.     .---------.     .--------.     .----------.     .-------.
|  mic   | --> | captura | --> |        | --> |  fuente  | --> |  app  |
                               | cancel |
.--------.     .---------.     |        |     .----------.     .---------.
|  app   | --> |  sumid. | --> |        | --> | reprodu  | --> | altavoz |
  • Una transmisión de captura que capta el audio de un micrófono.
  • Un Sumidero que toma la señal que contiene los datos que deben ser cancelados de la transmisión de captura. Aquí es donde la aplicación (aplicación de videoconferencia) envía el audio y contiene la señal de los otros participantes que están hablando y que necesita ser cancelada.
  • Una transmisión de reproducción que simplemente pasa la señal del Sumidero al altavoz. Esto es para que pueda escuchar a los otros participantes. También es la señal que es captada por el micrófono y que eventualmente necesita ser eliminada nuevamente.
  • Una Fuente que expone los datos con cancelación de eco capturados de la transmisión de captura. Los datos de la transmisión de sumidero y de la transmisión de captura se correlacionan y la señal de la transmisión de sumidero se elimina de los datos de la transmisión de captura. Estos datos luego van a la aplicación (la aplicación de conferencia) y ya no contienen el eco de los otros participantes.

NOMBRE DEL MÓDULO

libpipewire-module-echo-cancel

OPCIONES DEL MÓDULO

Opciones específicas del comportamiento de este módulo

  • capture.props = {}: propiedades que se pasarán a la transmisión de captura
  • source.props = {}: propiedades que se pasarán a la transmisión de fuente
  • sink.props = {}: propiedades que se pasarán a la transmisión de sumidero
  • playback.props = {}: propiedades que se pasarán a la transmisión de reproducción
  • library.name = <str>: la biblioteca de cancelación de eco. Actualmente soportado: aec/libspa-aec-webrtc. Déjelo sin definir para usar el método predeterminado (aec/libspa-aec-webrtc).
  • aec.args = <str>: argumentos que se pasarán al método de cancelación de eco
  • monitor.mode: En lugar de crear un sumidero, crear una transmisión que capture de los puertos del monitor del sumidero predeterminado.

Opciones con comportamiento bien conocido:

EJEMPLO DE CONFIGURACIÓN

 # ~/.config/pipewire/pipewire.conf.d/my-echo-cancel.conf
 context.modules = [
  {   name = libpipewire-module-echo-cancel
      args = {
          # library.name  = aec/libspa-aec-webrtc
          # node.latency = 1024/48000
          # monitor.mode = false
          capture.props = {
             node.name = "Echo Cancellation Capture"
          }
          source.props = {
             node.name = "Echo Cancellation Source"
          }
          sink.props = {
             node.name = "Echo Cancellation Sink"
          }
          playback.props = {
             node.name = "Echo Cancellation Playback"
          }
      }
  }
]
