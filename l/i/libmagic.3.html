DESCRIPCIÓN

Estas funciones operan sobre el archivo de base de datos de números mágicos que se describe en magic(5).

La función magic_open() crea un puntero de cookie mágico y lo devuelve. Devuelve NULL si hubo un error al asignar la cookie mágica. El argumento flags especifica cómo deben comportarse las otras funciones mágicas:

MAGIC_NONE
Sin manejo especial.
MAGIC_DEBUG
Imprimir mensajes de depuración en stderr.
MAGIC_SYMLINK
Si el archivo consultado es un enlace simbólico, seguirlo.
MAGIC_COMPRESS
Si el archivo está comprimido, descomprimirlo y examinar su contenido.
MAGIC_DEVICES
Si el archivo es un dispositivo especial de bloque o carácter, abrir el dispositivo e intentar examinar su contenido.
MAGIC_MIME_TYPE
Devolver una cadena de tipo MIME, en lugar de una descripción textual.
MAGIC_MIME_ENCODING
Devolver una codificación MIME, en lugar de una descripción textual.
MAGIC_MIME
Un atajo para MAGIC_MIME_TYPE | MAGIC_MIME_ENCODING.
MAGIC_CONTIN
Devolver todas las coincidencias, no solo la primera.
MAGIC_CHECK
Verificar la consistencia de la base de datos mágica e imprimir advertencias en stderr.
MAGIC_PRESERVE_ATIME
En sistemas que soportan utime(3) o utimes(2), intentar preservar el tiempo de acceso de los archivos analizados.
MAGIC_RAW
No traducir caracteres no imprimibles a una representación octal \ooo.
MAGIC_ERROR
Tratar los errores del sistema operativo al intentar abrir archivos y seguir enlaces simbólicos como errores reales, en lugar de imprimirlos en el buffer mágico.
MAGIC_APPLE
Devolver el creador y tipo de Apple.
MAGIC_EXTENSION
Devolver una lista separada por barras de extensiones para este tipo de archivo.
MAGIC_COMPRESS_TRANSP
No informar sobre la compresión, solo informar sobre los datos descomprimidos.
MAGIC_NO_CHECK_APPTYPE
No verificar el tipo de aplicación EMX (solo en EMX).
MAGIC_NO_COMPRESS_FORK
No permitir descompresores que usan fork.
MAGIC_NO_CHECK_CDF
No obtener archivos compuestos...

La función magic_close() libera el cookie mágico y todos los recursos asociados a él.

La función magic_error() devuelve un puntero a una cadena que describe el último error que ocurrió con el cookie mágico dado. Si no ha ocurrido ningún error, devuelve NULL.

La función magic_errno() devuelve el valor de la variable global errno que causó el último error del sistema operativo para el cookie mágico dado. Si no ha ocurrido ningún error del sistema operativo, devuelve 0.

La función magic_descriptor() devuelve una descripción del tipo de archivo que representa el descriptor de archivo fd. Si ocurre un error, devuelve NULL.

La función magic_file() devuelve una descripción del tipo de archivo que representa el nombre de archivo filename. Si ocurre un error, devuelve NULL.

La función magic_buffer() devuelve una descripción del tipo de datos que se encuentran en el buffer buffer con longitud length. Si ocurre un error, devuelve NULL.

La función magic_getflags() devuelve las banderas actuales que se establecen para el cookie mágico dado.

La función magic_setflags() establece las banderas especificadas por flags para el cookie mágico dado. Devuelve 0 si tiene éxito, o -1 si ocurre un error.

La función magic_check() comprueba la consistencia de la base de datos mágica especificada por filename. Devuelve 0 si la base de datos está bien, o -1 si se encuentran inconsistencias o si ocurre un error.

La función magic_compile() compila la base de datos mágica especificada por filename en un formato binario que puede ser cargado más rápidamente. Devuelve 0 si la compilación es exitosa, o -1 si ocurre un error.

La función magic_list() lista los archivos de base de datos mágica que se encuentran en el sistema. Devuelve 0 si la operación es exitosa, o -1 si ocurre un error.

La función magic_load() carga la base de datos mágica especificada por filename. Si filename es NULL, se intentará cargar la base de datos predeterminada. Devuelve 0 si la carga es exitosa, o -1 si ocurre un error.

La función magic_load_buffers() carga una base de datos mágica desde una matriz de buffers de memoria. buffers es una matriz de punteros a buffers, sizes es una matriz de tamaños de buffers, y nbuffers es el número de buffers en las matrices. Devuelve 0 si la carga es exitosa, o -1 si ocurre un error.

La función magic_setparam() establece un parámetro para el cookie mágico dado. param es el parámetro a establecer y value es un puntero al valor del parámetro. Devuelve 0 si tiene éxito, o -1 si ocurre un error.

La función magic_getparam() obtiene el valor de un parámetro para el cookie mágico dado. param es el parámetro a obtener y value es un puntero a la ubicación donde se almacenará el valor del parámetro. Devuelve 0 si tiene éxito, o -1 si ocurre un error.

La función magic_version() devuelve el número de versión de la biblioteca libmagic. Puede ser usado para verificar la compatibilidad con la base de datos mágica.

La función magic_getpath() devuelve la ruta de la base de datos mágica dada. Si magicfile es NULL, se usará la base de datos predeterminada. action puede ser MAGIC_PATH_LOAD, MAGIC_PATH_CHECK, MAGIC_PATH_COMPILE, o MAGIC_PATH_LIST para especificar la acción que se está realizando. Devuelve un puntero a la ruta de la base de datos mágica, o NULL si ocurre un error.

La función magic_close() cierra la base de datos de magic(5) y libera cualquier recurso utilizado.

La función magic_error() devuelve una explicación textual del último error, o NULL si no hubo error.

La función magic_errno() devuelve el último número de error del sistema operativo (errno(2)) que fue encontrado por una llamada al sistema.

La función magic_file() devuelve una descripción textual del contenido del argumento filename, o NULL si ocurrió un error. Si el filename es NULL, entonces se utiliza stdin.

La función magic_descriptor() devuelve una descripción textual del contenido del argumento fd, o NULL si ocurrió un error.

La función magic_buffer() devuelve una descripción textual del contenido del argumento buffer con un tamaño de length bytes.

La función magic_getflags() devuelve un valor que representa las flags actuales establecidas.

La función magic_setflags() establece las flags descritas anteriormente. Tenga en cuenta que usar ambas flags MIME juntas también puede devolver información adicional sobre el juego de caracteres.

La función magic_check() se puede utilizar para verificar la validez de las entradas en los archivos de base de datos separados por dos puntos pasados como filename, o NULL para la base de datos predeterminada. Devuelve 0 en caso de éxito y -1 en caso de fallo.

La función magic_compile() se puede utilizar para compilar la lista de archivos de base de datos separados por dos puntos pasados como filename, o NULL para la base de datos predeterminada. Devuelve 0 en caso de éxito y -1 en caso de fallo. Los archivos compilados creados tienen el nombre del basename(1) de cada archivo argumento con ".mgc" añadido al final.

La función magic_list() vuelca todas las entradas mágicas en un formato legible para humanos, volcando primero las entradas que coinciden con archivos binarios y luego las que coinciden con archivos de texto. Toma un argumento opcional filename que es una lista de archivos de base de datos separados por dos puntos, o NULL para la base de datos predeterminada.

La función magic_load() debe utilizarse para cargar la lista de archivos de base de datos separados por dos puntos pasada como filename, o NULL para el archivo de base de datos predeterminado antes de que se puedan realizar consultas mágicas.

El archivo de base de datos predeterminado tiene el nombre de la variable de entorno MAGIC. Si esa variable no está configurada, el nombre del archivo de base de datos predeterminado es /usr/share/file/misc/magic. magic_load() añade ".mgc" al nombre del archivo de base de datos según corresponda.

La función magic_load_buffers() toma un array de tamaño nbuffers de buffers con un tamaño respectivo para cada uno en el array de sizes cargado con el contenido de las bases de datos mágicas desde el sistema de archivos. Esta función se puede usar en entornos donde la biblioteca mágica no tiene acceso directo al sistema de archivos, pero puede acceder a la base de datos mágica a través de memoria compartida u otros medios IPC.

Las funciones magic_getparam() y magic_setparam() permiten obtener y establecer varios límites relacionados con la biblioteca mágica.

NAME

libmagic - magic number and file type determination library

LIBRARY

libmagic, -lmagic

SYNOPSIS

#include <magic.h>

magic_t magic_open(int flags);

int magic_close(magic_t cookie);

int magic_load(magic_t cookie, const char *filename);

int magic_compile(magic_t cookie, const char *filename);

int magic_check(magic_t cookie, const char *filename);

int magic_setflags(magic_t cookie, int flags);

int magic_getflags(magic_t cookie);

const char * magic_buffer(magic_t cookie, const void *buf, size_t length);

const char * magic_file(magic_t cookie, const char *filename);

const char * magic_getpath(magic_t cookie);

const char * magic_error(magic_t cookie);

int magic_errno(magic_t cookie);

int magic_version(void);

int magic_list(magic_t cookie, const char *filename);

DESCRIPTION

The libmagic library is a shared library that attempts to determine the type of a file based on its contents. It uses a database of magic numbers to perform this task.

The magic_open() function initializes and returns a magic cookie that should be used for all subsequent calls. The flags argument can be set to any of the following values ORed together:

MAGIC_NONE
No special flags.
MAGIC_DEBUG
Turn on debug messages to stderr.
MAGIC_CHECK
Perform validity checks on the magic file entries.
MAGIC_PRESERVE_ATIME
Preserve the access time of the file.
MAGIC_SYMLINKS
Follow symbolic links.
MAGIC_COMPRESS
Look inside compressed files.
MAGIC_DEVICES
Look at the contents of devices instead of just statistics them.
MAGIC_MIME
Return a MIME type string instead of a text description.
MAGIC_MIME_TYPE
Return only the MIME type string, without any description.
MAGIC_MIME_ENCODING
Return the MIME encoding of the file.
MAGIC_CONTINUE
Return all matches, not just the first one.
MAGIC_RECURSE
Look at the contents of files found in archives.
MAGIC_BRIEF
Only return the BRIEF information from the magic file.
MAGIC_SPECIAL_COMPLIANCE
Return some information necessary for the special compliance test.
MAGIC_APPLE
Return file type information used by Apple.
MAGIC_NO_CHECK_COMPRESS
Don't check for compressed files.
MAGIC_NO_CHECK_TAR
Don't check for tar files.
MAGIC_NO_CHECK_ASCII
Don't check for ascii files.
MAGIC_NO_CHECK_FORTRAN
Don't check for fortran files.
MAGIC_NO_CHECK_TOKENS
Don't check for tokenized files.
MAGIC_NO_CHECK_ENDIAN
Don't check for endianness.
MAGIC_NO_CHECK_Md5
Don't check for MD5 sums.
MAGIC_NO_CHECK_SHA1
Don't check for SHA1 sums.
MAGIC_NO_CHECK_SHA256
Don't check for SHA256 sums.
MAGIC_NO_CHECK_TEXT
Don't check for text files.
MAGIC_NO_CHECK_JSON
Don't check for JSON files.

The magic_close() function closes the magic cookie.

The magic_load() function loads the magic database specified by filename. If filename is NULL, the default magic database is loaded.

The magic_compile() function compiles the magic database specified by filename into the default magic database format. If filename is NULL, the default magic database is used.

The magic_check() function checks the magic database specified by filename for validity. If filename is NULL, the default magic database is used.

The magic_setflags() function sets the flags for the magic cookie. It returns the previous flags.

The magic_getflags() function returns the current flags for the magic cookie.

The magic_buffer() function determines the type of the data in the buffer buf of length length. It returns a string describing the file type, or NULL on error.

The magic_file() function determines the type of the file specified by filename. It returns a string describing the file type, or NULL on error.

The magic_getpath() function returns the path to the magic file used by the magic cookie. If no magic file was explicitly loaded, the system default magic database path is returned. Otherwise, only the system default magic database path is included.

RETURN VALUES

The function magic_open() returns a magic cookie on success and NULL on failure setting errno to an appropriate value. It will set errno to EINVAL if an unsupported value for flags was given. The magic_list(), magic_load(), magic_compile(), and magic_check() functions return 0 on success and -1 on failure. The magic_buffer(), magic_getpath(), and magic_file(), functions return a string on success and NULL on failure. The magic_error() function returns a textual description of the errors of the above functions, or NULL if there was no error. The magic_version() always returns the version number of the library. Finally, magic_setflags() returns -1 on systems that don't support utime(3), or utimes(2) when MAGIC_PRESERVE_ATIME is set.

FILES

/usr/share/file/misc/magic
The non-compiled default magic database.
/usr/share/file/misc/magic.mgc
The compiled default magic database.

SEE ALSO

file(1), magic(5)

BUGS

The results from magic_buffer() and magic_file() where the buffer and the file contain the same data can produce different results, because in the magic_file() case, the program can lseek(2) and stat(2) the file descriptor.
