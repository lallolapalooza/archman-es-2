D2I_X509_REQ(3) Manual de funciones de biblioteca D2I_X509_REQ(3)

NOMBRE

d2i_X509_REQ, i2d_X509_REQ, d2i_X509_REQ_bio, d2i_X509_REQ_fp, i2d_X509_REQ_bio, i2d_X509_REQ_fp, d2i_X509_REQ_INFO, i2d_X509_REQ_INFO — decodificar y codificar solicitudes de certificación PKCS#10

SINOPSIS

biblioteca “libcrypto”
#include <openssl/x509.h>

X509_REQ *
d2i_X509_REQ(X509_REQ **val_out, const unsigned char **der_in, long length);

int
i2d_X509_REQ(X509_REQ *val_in, unsigned char **der_out);

X509_REQ *
d2i_X509_REQ_bio(BIO *in_bio, X509_REQ **val_out);

X509_REQ *
d2i_X509_REQ_fp(FILE *in_fp, X509_REQ **val_out);

int
i2d_X509_REQ_bio(BIO *out_bio, X509_REQ *val_in);

int
i2d_X509_REQ_fp(FILE *out_fp, X509_REQ *val_in);

X509_REQ_INFO *
d2i_X509_REQ_INFO(X509_REQ_INFO **val_out, const unsigned char **der_in, long length);

int
i2d_X509_REQ_INFO(X509_REQ_INFO *val_in, unsigned char **der_out);

DESCRIPCIÓN

Estas funciones decodifican y codifican solicitudes de certificación PKCS#10. Para obtener detalles sobre la semántica, ejemplos, advertencias y errores, consulte ASN1_item_d2i(3).

d2i_X509_REQ() y i2d_X509_REQ() decodifican y codifican una estructura CertificationRequest ASN.1 definida en la sección 4.2 de RFC 2986. d2i_X509_REQ_bio(), d2i_X509_REQ_fp(), i2d_X509_REQ_bio(), y i2d_X509_REQ_fp() son similares excepto que decodifican o codifican usando un puntero BIO o FILE.

d2i_X509_REQ_INFO() y i2d_X509_REQ_INFO() decodifican y codifican una estructura CertificationRequestInfo ASN.1 definida en la sección 4.1 de RFC 2986.

VALORES DE RETORNO

d2i_X509_REQ(), d2i_X509_REQ_bio(), y d2i_X509_REQ_fp() devuelven un objeto X509_REQ o NULL si ocurre un error.

d2i_X509_REQ_INFO() devuelve un objeto X509_REQ_INFO o NULL si ocurre un error.

i2d_X509_REQ() y i2d_X509_REQ_INFO() devuelven el número de bytes codificados con éxito o un valor negativo si ocurre un error.

i2d_X509_REQ_bio() y i2d_X509_REQ_fp() devuelven 1 para éxito o 0 si ocurre un error.

VER TAMBIÉN

ASN1_item_d2i(3), PEM_read_X509_REQ(3), X509_REQ_new(3)

ESTÁNDARES

RFC 2986: PKCS #10: Especificación de la sintaxis de la solicitud de certificación

HISTORIA

d2i_X509_REQ(), i2d_X509_REQ(), d2i_X509_REQ_fp(), i2d_X509_REQ_fp(), d2i_X509_REQ_INFO(), y i2d_X509_REQ_INFO() aparecieron por primera vez en SSLeay 0.5.1. d2i_X509_REQ_bio() y i2d_X509_REQ_bio() aparecieron por primera vez en SSLeay 0.6.0. Estas funciones han estado disponibles desde OpenBSD 2.4.
