NOMBRE

libpipewire-module-roc-source - Fuente ROC

DESCRIPCIÓN

El módulo roc-source crea una fuente de PipeWire que recibe muestras de un remitente ROC y las pasa al receptor al que está conectado.

Luego, se puede conectar a cualquier dispositivo de audio.

NOMBRE DEL MÓDULO

libpipewire-module-roc-source

OPCIONES DEL MÓDULO

Opciones específicas del comportamiento de este módulo

  • source.props = {}: propiedades que se pasarán al stream de origen
  • source.name = <str>: node.name de la fuente
  • local.ip = <str>: IP local del remitente
  • local.source.port = <str>: puerto TCP/UDP local del receptor para paquetes de origen
  • local.repair.port = <str>: puerto TCP/UDP local del receptor para paquetes de receptor
  • local.control.port = <str>: puerto TCP/UDP local del receptor para paquetes de control
  • sess.latency.msec = <str>: latencia de red objetivo en milisegundos
  • roc.resampler.backend = <str>: Valores posibles: default, builtin, speex, speexdec.
  • roc.resampler.profile = <str>: Valores posibles: default, high, medium, low.
  • roc.latency-tuner.backend = <str>: Valores posibles: default, niq
  • roc.latency-tuner.profile = <str>: Valores posibles: default, intact, responsive, gradual
  • fec.code = <str>: Valores posibles: default, disable, rs8m, ldpc
  • resampler.profile = <str>: Obsoleto, use roc.resampler.profile

OPCIONES GENERALES

Opciones con comportamiento bien conocido:

  • node.name
  • node.description
  • media.name

EJEMPLO DE CONFIGURACIÓN

 # ~/.config/pipewire/pipewire.conf.d/my-roc-source.conf
 context.modules = [
  {   name = libpipewire-module-roc-source
      args = {
          local.ip = 0.0.0.0
          #roc.resampler.backend = default
          roc.resampler.profile = medium
          #roc.latency-tuner.backend = default
          #roc.latency-tuner.profile = default
          fec.code = disable
          sess.latency.msec = 5000
          local.source.port = 10001
          local.repair.port = 10002
          local.control.port = 10003
          source.name = "ROC Source"
          source.props = {
             node.name = "roc-source"
          }
      }
  }
]
