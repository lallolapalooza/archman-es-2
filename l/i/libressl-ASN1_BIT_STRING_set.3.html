libressl-ASN1_BIT_STRING_set(3)

Paquete: libressl

Licencias: ISC, custom:OpenSSL

ASN1_BIT_STRING_SET(3) Manual de funciones de biblioteca ASN1_BIT_STRING_SET(3)

NOMBRE

ASN1_BIT_STRING_set, ASN1_BIT_STRING_set_bit, ASN1_BIT_STRING_get_bit — Acceso a cadenas de bits ASN.1

SINOPSIS

biblioteca “libcrypto”
#include <openssl/asn1.h>

int
ASN1_BIT_STRING_set(ASN1_BIT_STRING *bitstr, unsigned char *data, int len);

int
ASN1_BIT_STRING_set_bit(ASN1_BIT_STRING *bitstr, int bitnumber, int set);

int
ASN1_BIT_STRING_get_bit(ASN1_BIT_STRING *bitstr, int bitnumber);

DESCRIPCIÓN

ASN1_BIT_STRING_set() establece el atributo de longitud de bitstr a len y copia ese número de bytes de data en bitstr, sobrescribiendo cualquier dato anterior, simplemente llamando a ASN1_STRING_set(3). Esta función no realiza ninguna validación. En particular, no verifica si bitstr es realmente del tipo V_ASN1_BIT_STRING ni, incluso si lo es, si los argumentos data y len tienen sentido para esta cadena de bits en particular.

Si el argumento set no es cero, ASN1_BIT_STRING_set_bit() establece el bit con el bitnumber dado en bitstr; de lo contrario, borra ese bit. Un bitnumber de 0 se dirige al bit más significativo en el primer byte de datos de bitstr, 7 al bit menos significativo en el mismo byte, 8 al bit más significativo en el segundo byte de datos, y así sucesivamente.

Si se solicita establecer un bit más allá del último byte de datos existente, se agregan bytes adicionales a bitstr según sea necesario. Después de borrar un bit, se eliminan los bytes NUL finales de bitstr.

ASN1_BIT_STRING_get_bit() verifica si el bit con el bitnumber dado está establecido en bitstr.

VALORES DE RETORNO

ASN1_BIT_STRING_set() devuelve 1 si tiene éxito o 0 si falla la asignación de memoria o si data es NULL y len es -1 en la misma llamada.

ASN1_BIT_STRING_set_bit() devuelve 1 si tiene éxito o 0 si bitstr es NULL o si falla la asignación de memoria.

ASN1_BIT_STRING_get_bit() devuelve 1 si el bit con el bitnumber dado está establecido en bitstr o 0 si bitstr es NULL, si bitnumber apunta más allá del último byte de datos en bitstr, o si el bit solicitado no está establecido.

VER TAMBIÉN

ASN1_BIT_STRING_new(3), ASN1_STRING_set(3), d2i_ASN1_BIT_STRING(3), v2i_ASN1_BIT_STRING(3)

HISTORIA

ASN1_BIT_STRING_set() apareció por primera vez en SSLeay 0.6.5. ASN1_BIT_STRING_set_bit() y ASN1_BIT_STRING_get_bit() aparecieron por primera vez en SSLeay 0.9.0. Estas funciones han estado disponibles desde OpenBSD 2.4.
