libressl-X509_signature_dump(3)

Paquete: libressl

Licencias: ISC, custom:OpenSSL

X509_SIGNATURE_DUMP(3) Manual de funciones de la biblioteca X509_SIGNATURE_DUMP(3)

NOMBRE

X509_signature_dump, X509_signature_print — imprimir cadenas ASN.1 de forma legible

SINOPSIS

biblioteca “libcrypto”;
#include <openssl/x509.h>

int
X509_signature_dump(BIO *bio, const ASN1_STRING *signature, int indent);

int
X509_signature_print(BIO *bio, const X509_ALGOR *algorithm, const ASN1_STRING *signature);

DESCRIPCIÓN

X509_signature_dump() escribe los bytes de datos contenidos en la signature en bio en formato hexadecimal con dos puntos entre bytes, 18 bytes por línea de salida, cada línea indentada con indent caracteres de espacio.

X509_signature_print() escribe el nombre del algorithm de la firma, o, si no se conoce un nombre para él, su identificador de objeto (OID) en bio utilizando i2a_ASN1_OBJECT(3). Después de eso, si se puede recuperar un objeto de método para el algoritmo con EVP_PKEY_asn1_find(3) y si ese objeto define un método de impresión, se utiliza ese método de impresión para imprimir la signature. De lo contrario, a menos que la signature sea NULL, se imprime utilizando X509_signature_dump().

VALORES DE RETORNO

Estas funciones devuelven 1 en caso de éxito o 0 en caso de fallo. Fallan y regresan tan pronto como falla cualquier operación de escritura.

VEA TAMBIÉN

ASN1_STRING_new(3), ASN1_STRING_print_ex(3), BIO_new(3), EVP_PKEY_asn1_find(3), OBJ_find_sigid_algs(3), X509_ALGOR_new(3), X509_get0_signature(3)

HISTORIA

X509_signature_print() apareció por primera vez en OpenSSL 0.9.7 y ha estado disponible desde OpenBSD 3.2.

X509_signature_dump() apareció por primera vez en OpenSSL 1.0.1 y ha estado disponible desde OpenBSD 5.3.
