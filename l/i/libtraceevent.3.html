DESCRIPTION

La librería libtraceevent(3) proporciona APIs para acceder a eventos de tracepoint del kernel, ubicados en el sistema de archivos tracefs bajo el directorio events.

ENVIRONMENT

TRACEEVENT_PLUGIN_DIR
        Directorio adicional de plugins. Todos los archivos de objeto compartido, ubicados en este directorio, serán cargados como plugins de traceevent.

FILES

event-parse.h
        Archivo de cabecera a incluir para tener acceso a las APIs de la librería.
trace-seq.h
        Archivo de cabecera a incluir para tener acceso a las APIs relacionadas con secuencias de traza.
        Las secuencias de traza se utilizan para permitir que una función llame a otras funciones
        para crear una cadena de datos a utilizar.
-ltraceevent
        Opción del enlazador a añadir al compilar un programa que usa la librería.
