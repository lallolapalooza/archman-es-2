libressl-CMS_get0_SignerInfos(3)

Paquete: libressl

Licencias: ISC, custom:OpenSSL

CMS_GET0_SIGNERINFOS(3) Manual de funciones de biblioteca CMS_GET0_SIGNERINFOS(3)

NOMBRE

CMS_get0_SignerInfos, CMS_SignerInfo_get_version, CMS_SignerInfo_get0_signer_id, CMS_SignerInfo_get0_signature, CMS_SignerInfo_cert_cmp, CMS_SignerInfo_set1_signer_cert — Funciones de firmante de CMS SignedData

SINOPSIS

biblioteca “libcrypto”
#include <openssl/cms.h>

STACK_OF(CMS_SignerInfo) *
CMS_get0_SignerInfos(CMS_ContentInfo *cms);

int
CMS_SignerInfo_get_version(CMS_SignerInfo *si, long *version);

int
CMS_SignerInfo_get0_signer_id(CMS_SignerInfo *si, ASN1_OCTET_STRING **keyid, X509_NAME **issuer, ASN1_INTEGER **sno);

ASN1_OCTET_STRING *
CMS_SignerInfo_get0_signature(CMS_SignerInfo *si);

int
CMS_SignerInfo_cert_cmp(CMS_SignerInfo *si, X509 *certificate);

void
CMS_SignerInfo_set1_signer_cert(CMS_SignerInfo *si, X509 *signer);

DESCRIPCIÓN

CMS_get0_SignerInfos() devuelve todas las estructuras SignerInfo asociadas con la estructura SignedData cms.

CMS_SignerInfo_get_version() establece *version al número de versión de sintaxis de la estructura SignerInfo si.

CMS_SignerInfo_get0_signer_id() recupera el SignerIdentifier del certificado asociado con la estructura SignerInfo si. Se establecerá el SubjectKeyIdentifier en keyid o tanto el nombre del emisor como el número de serie en issuer y sno.

CMS_SignerInfo_get0_signature() recupera el campo signature de si. Se permite al programa de aplicación modificar los datos a los que apunta.

CMS_SignerInfo_cert_cmp() compara el certificate con el identificador del firmante de si.

CMS_SignerInfo_set1_signer_cert() establece el certificado del firmante de si a signer.

El propósito principal de estas funciones es permitir que una aplicación busque certificados de firmante utilizando cualquier técnica apropiada cuando el método más simple de CMS_verify(3) no sea adecuado.

En el uso típico, una aplicación recupera todas las estructuras CMS_SignerInfo usando CMS_get0_SignerInfos() y recupera la información del identificador usando CMS. Luego obtendrá el certificado del firmante por algún medio no especificado (o devolverá un error si no se puede encontrar) y lo establecerá usando CMS_SignerInfo_set1_signer_cert(). Una vez que se hayan establecido todos los certificados de firmante, se puede usar CMS_verify(3).

VALORES DE RETORNO

CMS_get0_SignerInfos() devuelve un puntero interno a todas las estructuras CMS_SignerInfo, o NULL si no hay firmantes o si cms no es del tipo SignedData.

CMS_SignerInfo_get_version() siempre tiene éxito y devuelve 1.

CMS_SignerInfo_get0_signer_id() devuelve 1 para éxito o 0 para fracaso.

CMS_SignerInfo_get0_signature() devuelve un puntero interno a la firma.

CMS_SignerInfo_cert_cmp() devuelve 0 para una coincidencia o un valor distinto de cero en caso contrario.

Cualquier error se puede obtener de ERR_get_error(3).

VER TAMBIÉN

CMS_ContentInfo_new(3), CMS_signed_add1_attr(3), CMS_verify(3)

HISTORIAL

CMS_get0_SignerInfos(), CMS_SignerInfo_get0_signer_id(), CMS_SignerInfo_cert_cmp(), y CMS_SignerInfo_set1_signer_cert() aparecieron por primera vez en OpenSSL 0.9.8h y CMS_SignerInfo_get0_signature() en OpenSSL 1.0.2. Estas funciones han estado disponibles desde OpenBSD 6.7.

CMS_SignerInfo_get_version() apareció por primera vez en OpenBSD 7.4.
