libressl-EVP_PKEY_encrypt(3)

Paquete: libressl

Licencias: ISC, custom:OpenSSL

EVP_PKEY_ENCRYPT(3) Manual de funciones de biblioteca EVP_PKEY_ENCRYPT(3)

NOMBRE

EVP_PKEY_encrypt_init, EVP_PKEY_encrypt — cifrar usando un algoritmo de clave pública

SINOPSIS

biblioteca “libcrypto”
#include <openssl/evp.h>

int
EVP_PKEY_encrypt_init(EVP_PKEY_CTX *ctx);

int
EVP_PKEY_encrypt(EVP_PKEY_CTX *ctx, unsigned char *out, size_t *outlen, const unsigned char *in, size_t inlen);

DESCRIPCIÓN

La función EVP_PKEY_encrypt_init() inicializa un contexto de algoritmo de clave pública usando la clave ctx->pkey para una operación de cifrado.

La función EVP_PKEY_encrypt() realiza una operación de cifrado de clave pública usando ctx. Los datos a cifrar se especifican usando los parámetros in y inlen. Si out es NULL, entonces el tamaño máximo del búfer de salida se escribe en el parámetro outlen. Si out no es NULL, entonces antes de la llamada, el parámetro outlen debe contener la longitud del búfer out. Si la llamada es exitosa, los datos cifrados se escriben en out y la cantidad de datos escritos en outlen.

Después de la llamada a EVP_PKEY_encrypt_init(), se pueden realizar operaciones de control específicas del algoritmo para establecer los parámetros apropiados para la operación.

La función EVP_PKEY_encrypt() puede llamarse más de una vez en el mismo contexto si se realizan varias operaciones usando los mismos parámetros.

VALORES DE RETORNO

EVP_PKEY_encrypt_init() y EVP_PKEY_encrypt() devuelven 1 en caso de éxito y 0 o un valor negativo en caso de fallo. En particular, un valor de retorno de -2 indica que la operación no es compatible con el algoritmo de clave pública.

EJEMPLOS

Cifrar datos usando OAEP (para claves RSA). Ver también PEM_read_PUBKEY(3) y d2i_X509(3) para medios para cargar una clave pública. También puede establecer simplemente “eng” a NULL para comenzar con la implementación RSA predeterminada de OpenSSL:

#include <openssl/evp.h>
#include <openssl/rsa.h>

EVP_PKEY_CTX *ctx;
unsigned char *out, *in;
size_t outlen, inlen;
EVP_PKEY *key;
/* NOTA: Asume que key, in, inlen ya están configurados
 * y que key es una clave pública RSA
 */
ctx = EVP_PKEY_CTX_new(key, NULL);
if (!ctx)
	/* Ocurrió un error */
if (EVP_PKEY_encrypt_init(ctx) <= 0)
	/* Error */
if (EVP_PKEY_CTX_set_rsa_padding(ctx, RSA_PKCS1_OAEP_PADDING) <= 0)
	/* Error */

/* Determinar la longitud del búfer */
if (EVP_PKEY_encrypt(ctx, NULL, &outlen, in, inlen) <= 0)
	/* Error */

out = malloc(outlen);

if (!out)
	/* Fallo de malloc */

if (EVP_PKEY_encrypt(ctx, out, &outlen, in, inlen) <= 0)
	/* Error */

/* Los datos cifrados son outlen bytes escritos en el búfer out */

VER TAMBIÉN

EVP_PKEY_CTX_new(3), EVP_PKEY_decrypt(3), EVP_PKEY_derive(3), EVP_PKEY_sign(3), EVP_PKEY_verify(3), EVP_PKEY_verify_recover(3)

HISTORIAL
