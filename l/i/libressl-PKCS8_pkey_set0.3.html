libressl-PKCS8_pkey_set0(3)

Paquete: libressl

Licencias: ISC, custom:OpenSSL

PKCS8_PKEY_SET0(3) Manual de funciones de biblioteca PKCS8_PKEY_SET0(3)

NOMBRE

PKCS8_pkey_set0, PKCS8_pkey_get0, PKCS8_pkey_add1_attr_by_NID, PKCS8_pkey_get0_attrs — modificar e inspeccionar objetos PKCS#8 PrivateKeyInfo

SINOPSIS

biblioteca “libcrypto”
#include <openssl/x509.h>

int
PKCS8_pkey_set0(PKCS8_PRIV_KEY_INFO *keyinfo, ASN1_OBJECT *aobj, int version, int ptype, void *pval, unsigned char *data, int len);

int
PKCS8_pkey_get0(const ASN1_OBJECT **paobj, const unsigned char **pdata, int *plen, const X509_ALGOR **palgor, const PKCS8_PRIV_KEY_INFO *keyinfo);

int
PKCS8_pkey_add1_attr_by_NID(PKCS8_PRIV_KEY_INFO *keyinfo, int nid, int type, const unsigned char *data, int len);

const STACK_OF(X509_ATTRIBUTE) *
PKCS8_pkey_get0_attrs(const PKCS8_PRIV_KEY_INFO *keyinfo);

DESCRIPCIÓN

PKCS8_pkey_set0() inicializa el objeto keyinfo. El algoritmo se establece en aobj con el tipo de parámetro asociado ptype y el valor de parámetro pval utilizando X509_ALGOR_set0(3), reemplazando cualquier información previa sobre el algoritmo. A menos que data sea NULL, la clave privada codificada se establece en los len bytes que comienzan en data utilizando ASN1_STRING_set0(3), sin realizar ninguna validación. Si data es NULL, los datos de la clave permanecen sin cambios. Si el argumento version es mayor o igual a 0, reemplaza cualquier versión existente; de lo contrario, la versión permanece sin cambios. Si keyinfo contiene atributos, estos permanecen sin cambios.

PKCS8_pkey_get0() recupera información del objeto keyinfo. Los punteros internos al OID del algoritmo, al AlgorithmIdentifier, y a la clave privada codificada se almacenan en *paobj, *palgor, y *pdata, respectivamente. Se pueden pasar punteros NULL para cualquiera de estos tres argumentos si la información respectiva no es necesaria. A menos que pdata sea NULL, *plen se establece en el número de bytes en *pdata.

PKCS8_pkey_add1_attr_by_NID() crea un nuevo objeto de Atributo X.501 utilizando X509_ATTRIBUTE_create_by_NID(3) y lo añade a los atributos de keyinfo.

VALORES DE RETORNO

PKCS8_pkey_set0() y PKCS8_pkey_add1_attr_by_NID() devuelven 1 en caso de éxito o 0 en caso de fallo.

PKCS8_pkey_get0() siempre devuelve 1.

PKCS8_pkey_get0_attrs() devuelve un puntero interno al array de atributos asociado con keyinfo o NULL si no hay atributos establecidos.

VEA TAMBIÉN

ASN1_STRING_set0(3), EVP_PKCS82PKEY(3), OBJ_nid2obj(3), PKCS8_PRIV_KEY_INFO_new(3), STACK_OF(3), X509_ALGOR_new(3), X509_ATTRIBUTE_create_by_NID(3), X509_ATTRIBUTE_new(3)

HISTORIAL

PKCS8_pkey_set0() y PKCS8_pkey_get0() aparecieron por primera vez en OpenSSL 1.0.0 y han estado disponibles desde OpenBSD 4.9.

PKCS8_pkey_add1_attr_by_NID() y PKCS8_pkey_get0_attrs() aparecieron por primera vez en OpenSSL 1.1.0 y han estado disponibles desde OpenBSD 6.4.
