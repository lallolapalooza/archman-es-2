libressl-ERR_load_crypto_strings(3)

Paquete: libressl

Licencias: ISC, custom:OpenSSL

ERR_LOAD_CRYPTO_STRINGS(3) Manual de funciones de la biblioteca ERR_LOAD_CRYPTO_STRINGS(3)

NOMBRE

ERR_load_crypto_strings, ERR_free_strings, SSL_load_error_strings — cargar y liberar cadenas de error de OpenSSL

SINOPSIS

biblioteca “libcrypto”
#include <openssl/err.h>

void
ERR_load_crypto_strings(void);

void
ERR_free_strings(void);

biblioteca “libssl” libcrypto
#include <openssl/ssl.h>

void
SSL_load_error_strings(void);

DESCRIPCIÓN

Estas funciones están obsoletas. Nunca es útil que ningún programa de aplicación las llame explícitamente. La biblioteca las llama automáticamente internamente siempre que es necesario.

ERR_load_crypto_strings() registra las cadenas de error para todas las funciones de crypto(3). SSL_load_error_strings() hace lo mismo, pero también registra las cadenas de error de ssl(3).

Si las cadenas de error ya se habían cargado antes, no se realiza ninguna acción.

ERR_free_strings() libera todas las cadenas de error cargadas previamente.

VER TAMBIÉN

ERR(3), ERR_error_string(3), OPENSSL_config(3)

HISTORIA

ERR_load_crypto_strings() y SSL_load_error_strings() aparecieron por primera vez en SSLeay 0.4.4. ERR_free_strings() apareció por primera vez en SSLeay 0.5.1. Estas funciones han estado disponibles desde OpenBSD 2.4.

ERRORES

Aunque las cadenas de error ya están compiladas en el código objeto de la biblioteca como cadenas estáticas, estas funciones las almacenan de nuevo utilizando memoria asignada dinámicamente en el heap. Esto puede fallar si no hay suficiente memoria disponible, pero estas funciones no informan de tales errores. En su lugar, fallan silenciosamente, posiblemente habiendo registrado ninguna o solo una parte de las cadenas solicitadas.
