libressl-PKCS7_decrypt(3)

Paquete: libressl

Licencias: ISC, custom:OpenSSL

PKCS7_DECRYPT(3) Manual de funciones de biblioteca PKCS7_DECRYPT(3)

NOMBRE

PKCS7_decrypt — descifra el contenido de una estructura envelopedData PKCS#7

SINOPSIS

biblioteca “libcrypto”
#include <openssl/pkcs7.h>

int
PKCS7_decrypt(PKCS7 *p7, EVP_PKEY *pkey, X509 *cert, BIO *data, int flags);

DESCRIPCIÓN

PKCS7_decrypt() extrae y descifra el contenido de una estructura envelopedData PKCS#7. pkey es la clave privada del destinatario, cert es el certificado del destinatario, data es un BIO al que se escribirá el contenido y flags es un conjunto opcional de indicadores.

Aunque el certificado del destinatario no es necesario para descifrar los datos, sí lo es para localizar a los destinatarios adecuados en la estructura PKCS#7.

Si se establece el indicador PKCS7_TEXT flag, se eliminan las cabeceras MIME de tipo text/plain del contenido. Si el contenido no es de tipo text/plain, se devuelve un error.

VALORES DE RETORNO

PKCS7_decrypt() devuelve 1 en caso de éxito o 0 en caso de fallo.

El error se puede obtener de ERR_get_error(3).

VER TAMBIÉN

PKCS7_encrypt(3), PKCS7_new(3), PKCS7_verify(3)

HISTORIA

PKCS7_decrypt() apareció por primera vez en OpenSSL 0.9.5 y ha estado disponible desde OpenBSD 2.7.

ERRORES

PKCS7_decrypt() debe recibir la clave y el certificado del destinatario correctos. Sería mejor si pudiera buscar la clave y el certificado correctos en una base de datos.

La falta de procesamiento en una sola pasada y la necesidad de mantener todos los datos en memoria, como se menciona en PKCS7_sign(3), también se aplican a PKCS7_decrypt().
