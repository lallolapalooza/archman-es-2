libressl-RSA_generate_key(3)

Paquete: libressl

Licencias: ISC, custom:OpenSSL

RSA_GENERATE_KEY(3) Manual de funciones de biblioteca RSA_GENERATE_KEY(3)

NOMBRE

RSA_generate_key_ex, RSA_generate_key — generar par de claves RSA

SINOPSIS

biblioteca “libcrypto”
#include <openssl/rsa.h>

int
RSA_generate_key_ex(RSA *rsa, int bits, BIGNUM *e, BN_GENCB *cb);

Obsoleto:


RSA *
RSA_generate_key(int num, unsigned long e, void (*callback)(int, int, void *), void *cb_arg);

DESCRIPCIÓN

RSA_generate_key_ex() genera un par de claves y lo almacena en rsa.

El tamaño del módulo será de longitud bits, y el exponente público será e. Los tamaños de clave con num < 1024 deben considerarse inseguros. El exponente es un número impar, típicamente 3, 17 o 65537.

Se puede usar una función de devolución de llamada para proporcionar información sobre el progreso de la generación de claves. Si cb no es NULL, se llamará de la siguiente manera utilizando la función BN_GENCB_call(3):

  • Mientras se genera un número primo aleatorio, se llama como se describe en BN_generate_prime(3).
  • Cuando el n-ésimo número primo generado aleatoriamente se rechaza por no ser adecuado para la clave, se llama BN_GENCB_call(cb, 2, n).
  • Cuando se encuentra un primo aleatorio p tal que p-1 es primo relativo a e, se llama como BN_GENCB_call(cb, 3, 0).

El proceso se repite luego para el primo q con BN_GENCB_call(cb, 3, 1).

RSA_generate_key() está obsoleto. Las nuevas aplicaciones deben usar RSA_generate_key_ex() en su lugar. RSA_generate_key() funciona de la misma manera que RSA_generate_key_ex() excepto que usa devoluciones de llamada de "estilo antiguo". Consulte BN_generate_prime(3) para obtener más detalles.

VALORES DE RETORNO

RSA_generate_key_ex() devuelve 1 en caso de éxito o 0 en caso de error. RSA_generate_key() devuelve la clave en caso de éxito o NULL en caso de error.

Los códigos de error se pueden obtener mediante ERR_get_error(3).

VER TAMBIÉN

BN_generate_prime(3), RSA_get0_key(3), RSA_meth_set_keygen(3), RSA_new(3)

HISTORIA

RSA_generate_key() apareció en SSLeay 0.4 o anterior y se le añadió su argumento cb_arg en SSLeay 0.9.0. Ha estado disponible desde OpenBSD 2.4.

RSA_generate_key_ex() apareció por primera vez en OpenSSL 0.9.8 y ha estado disponible desde OpenBSD 4.5.

ERRORES

BN_GENCB_call(cb, 2, x) se utiliza con dos significados diferentes.

RSA_generate_key() entra en un bucle infinito para valores de entrada ilegales.
