DESCRIPCIÓN

Estas funciones decodifican y codifican estructuras de datos PKCS#7. Para obtener detalles sobre la semántica, ejemplos, advertencias y errores, consulte ASN1_item_d2i(3).

d2i_PKCS7() y i2d_PKCS7() decodifican y codifican una estructura ASN.1 ContentInfo definida en la sección 7 de RFC 2315. d2i_PKCS7_bio(), i2d_PKCS7_bio(), d2i_PKCS7_fp(), y i2d_PKCS7_fp() son similares excepto que decodifican o codifican usando un puntero BIO o FILE.

d2i_PKCS7_DIGEST() y i2d_PKCS7_DIGEST() decodifican y codifican una estructura ASN.1 DigestedData definida en la sección 12 de RFC 2315.

d2i_PKCS7_ENCRYPT() y i2d_PKCS7_ENCRYPT() decodifican y codifican una estructura ASN.1 EncryptedData definida en la sección 13 de RFC 2315.

d2i_PKCS7_ENC_CONTENT() y i2d_PKCS7_ENC_CONTENT() decodifican y codifican una estructura ASN.1 EncryptedContentInfo definida en la sección 10.1 de RFC 2315.

d2i_PKCS7_ENVELOPE() y i2d_PKCS7_ENVELOPE() decodifican y codifican una estructura ASN.1 EnvelopedData definida en la sección 10 de RFC 2315.

DESCRIPTION

d2i_PKCS7(), d2i_PKCS7_bio(), and d2i_PKCS7_fp() decode a DER encoded PKCS#7 message from in (or bp or fp) into a PKCS7 structure. If ppkcs7 is not NULL, the decoded structure is stored there. If ppkcs7 is NULL, a new PKCS7 structure is allocated. The in pointer is updated to point to the first byte after the decoded structure. len is the length of the DER data to be decoded. If len is 0, then the input is read until end-of-file or an error occurs. The length of the decoded structure is returned by i2d_PKCS7(), i2d_PKCS7_bio(), and i2d_PKCS7_fp().

i2d_PKCS7() encodes the PKCS7 structure pkcs7 into DER format and writes it to out. If out is not NULL, the encoded data is written to the buffer pointed to by out. The caller is responsible for allocating sufficient memory for the buffer. If out is NULL, then the memory required is allocated by the function. The caller must call OPENSSL_free() to free this memory. The number of bytes written is returned. If an error occurs, a negative value is returned.

d2i_PKCS7_SIGNED() and i2d_PKCS7_SIGNED() decode and encode an ASN.1 SignedData structure defined in RFC 2315 section 9.

d2i_PKCS7_ENCRYPT() and i2d_PKCS7_ENCRYPT() decode and encode an ASN.1 EnvelopedData structure defined in RFC 2315 section 10.

d2i_PKCS7_ENVELOPE() and i2d_PKCS7_ENVELOPE() decode and encode an ASN.1 EncryptedData structure defined in RFC 2315 section 10.1.

d2i_PKCS7_SIGN_ENVELOPE() and i2d_PKCS7_SIGN_ENVELOPE() decode and encode an ASN.1 SignedAndEnvelopedData structure defined in RFC 2315 section 11.

d2i_PKCS7_DIGEST() and i2d_PKCS7_DIGEST() decode and encode an ASN.1 DigestedData structure defined in RFC 2315 section 9.1.

d2i_PKCS7_ENC_CONTENT() and i2d_PKCS7_ENC_CONTENT() decode and encode an ASN.1 EncryptedContent structure defined in RFC 2315 section 10.1.

d2i_PKCS7_ISSUER_AND_SERIAL() and i2d_PKCS7_ISSUER_AND_SERIAL() decode and encode an ASN.1 IssuerAndSerialNumber structure defined in RFC 2315 section 6.7.

d2i_PKCS7_RECIP_INFO() and i2d_PKCS7_RECIP_INFO() decode and encode an ASN.1 RecipientInfo structure defined in RFC 2315 section 10.2.

d2i_PKCS7_SIGNER_INFO() and i2d_PKCS7_SIGNER_INFO() decode and encode an ASN.1 SignerInfo structure defined in RFC 2315 section 9.2.

RETURN VALUES

d2i_PKCS7(), d2i_PKCS7_bio(), and d2i_PKCS7_fp() return a PKCS7 object or NULL if an error occurs.

d2i_PKCS7_DIGEST(), d2i_PKCS7_ENCRYPT(), d2i_PKCS7_ENC_CONTENT(), d2i_PKCS7_ENVELOPE(), d2i_PKCS7_ISSUER_AND_SERIAL(), d2i_PKCS7_RECIP_INFO(), d2i_PKCS7_SIGNED(), d2i_PKCS7_SIGNER_INFO(), and d2i_PKCS7_SIGN_ENVELOPE() return an object of the respective type or NULL if an error occurs.

i2d_PKCS7(), i2d_PKCS7_DIGEST(), i2d_PKCS7_ENCRYPT(), i2d_PKCS7_ENC_CONTENT(), i2d_PKCS7_ENVELOPE(), i2d_PKCS7_ISSUER_AND_SERIAL(), i2d_PKCS7_RECIP_INFO(), i2d_PKCS7_SIGNED(), i2d_PKCS7_SIGNER_INFO(), and i2d_PKCS7_SIGN_ENVELOPE() return the number of bytes successfully encoded or a negative value if an error occurs.

i2d_PKCS7_bio() and i2d_PKCS7_fp() return 1 for success or 0 if an error occurs.
