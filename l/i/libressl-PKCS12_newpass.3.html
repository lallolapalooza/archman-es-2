libressl-PKCS12_newpass(3)

Paquete: libressl

Licencias: ISC, custom:OpenSSL

PKCS12_NEWPASS(3) Manual de funciones de la biblioteca PKCS12_NEWPASS(3)

NOMBRE

PKCS12_newpass — cambiar la contraseña de una estructura PKCS#12

SINOPSIS

biblioteca “libcrypto”
#include <openssl/pkcs12.h>

int
PKCS12_newpass(PKCS12 *p12, const char *oldpass, const char *newpass);

DESCRIPCIÓN

PKCS12_newpass() cambia la contraseña de una estructura PKCS#12.

p12 es un puntero a una estructura PKCS#12. oldpass es la contraseña existente y newpass es la nueva contraseña.

Si la estructura PKCS#12 no tiene contraseña, utilice la cadena vacía "" para oldpass. Pasar NULL para oldpass provoca un fallo de PKCS12_newpass().

Si se utiliza la contraseña incorrecta para oldpass, la función fallará con un error de verificación MAC. En casos raros, la estructura PKCS#12 no contiene un MAC: en este caso, normalmente fallará con un error de relleno de descifrado.

VALORES DE RETORNO

Al completarse con éxito, se devuelve 1; de lo contrario, se devuelve 0 y se puede recuperar un código de error con ERR_get_error(3).

EJEMPLOS

Este ejemplo carga un archivo PKCS#12, cambia su contraseña y escribe el resultado en un nuevo archivo.

#include <stdio.h>
#include <stdlib.h>
#include <openssl/pem.h>
#include <openssl/err.h>
#include <openssl/pkcs12.h>

int main(int argc, char **argv)
{
	FILE *fp;
	PKCS12 *p12;
	if (argc != 5) {
		fprintf(stderr,
		    "Uso: pkread p12file contraseña nuevacontraseña archivo_salida\n");
		return 1;
	}
	if ((fp = fopen(argv[1], "rb")) == NULL) {
		fprintf(stderr, "Error al abrir el archivo %s\n", argv[1]);
		return 1;
	}
	p12 = d2i_PKCS12_fp(fp, NULL);
	fclose(fp);
	if (p12 == NULL) {
		fprintf(stderr, "Error al leer el archivo PKCS#12\n");
		ERR_print_errors_fp(stderr);
		return 1;
	}
	if (PKCS12_newpass(p12, argv[2], argv[3]) == 0) {
		fprintf(stderr, "Error al cambiar la contraseña\n");
		ERR_print_errors_fp(stderr);
		PKCS12_free(p12);
		return 1;
	}
	if ((fp = fopen(argv[4], "wb")) == NULL) {
		fprintf(stderr, "Error al abrir el archivo %s\n", argv[4]);
		PKCS12_free(p12);
		return 1;
	}
	i2d_PKCS12_fp(fp, p12);
	PKCS12_free(p12);
	fclose(fp);
	return 0;
}

VEASE TAMBIÉN

PKCS12_create(3), PKCS12_new(3)

HISTORIA

PKCS12_newpass() apareció por primera vez en OpenSSL 0.9.5 y ha estado disponible desde OpenBSD 2.7.

ERRORES

El formato de la contraseña es una cadena ASCII terminada en NUL que se convierte internamente a formato Unicode. Como resultado, algunas contraseñas no pueden proporcionarse a esta función.
