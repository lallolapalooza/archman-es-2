NOMBRE

libpipewire-module-rtp-source - Origen RTP

DESCRIPCIÓN

El módulo rtp-source crea una fuente PipeWire que recibe paquetes RTP de audio y MIDI.

Este módulo generalmente se carga desde SAP Announce and create RTP streams para que los parámetros source.ip y source.port y el formato coincidan con los del remitente.

NOMBRE DEL MÓDULO

libpipewire-module-rtp-source

OPCIONES DEL MÓDULO

Opciones específicas para el comportamiento de este módulo

  • local.ifname = <str>: nombre de la interfaz a utilizar
  • source.ip = <str>: la dirección IP de origen, por defecto 224.0.0.56. Establezca esta opción a la dirección IP desde la que desea recibir paquetes o a 0.0.0.0 para recibir de cualquier dirección de origen.
  • source.port = <int>: el puerto de origen
  • node.always-process = <bool>: verdadero para recibir incluso cuando no se está ejecutando
  • sess.latency.msec = <float>: latencia de red objetivo en milisegundos, por defecto 100
  • sess.ignore-ssrc = <bool>: ignorar SSRC, por defecto falso
  • sess.media = <string>: el tipo de medio audio|midi|opus, por defecto audio
  • stream.may-pause = <bool>: pausar el stream cuando no se recibe ningún dato, por defecto falso
  • stream.props = {}: propiedades a pasar al stream

OPCIONES GENERALES

Opciones con comportamiento conocido:

  • remote.name
  • audio.format
  • audio.rate
  • audio.channels
  • audio.position
  • media.name
  • media.class
  • node.name
  • node.description
  • node.group
  • node.latency
  • node.virtual

EJEMPLO DE CONFIGURACIÓN

# ~/.config/pipewire/pipewire.conf.d/my-rtp-source.conf
context.modules = [
{   name = libpipewire-module-rtp-source
    args = {
        #local.ifname = eth0
        #source.ip = 224.0.0.56
        #source.port = 0
        sess.latency.msec = 100
        #sess.ignore-ssrc = false
        #node.always-process = false
        #sess.media = "audio"
        #audio.format = "S16BE"
        #audio.rate = 48000
        #audio.channels = 2
        #audio.position = [ FL FR ]
        stream.props = {
           #media.class = "Audio/Source"
           node.name = "rtp-source"
        }
    }
}
]
