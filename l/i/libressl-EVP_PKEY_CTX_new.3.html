libressl-EVP_PKEY_CTX_new(3)

Paquete: libressl

Licencias: ISC, custom:OpenSSL

EVP_PKEY_CTX_NEW(3) Manual de funciones de la biblioteca EVP_PKEY_CTX_NEW(3)

NOMBRE

EVP_PKEY_CTX_new, EVP_PKEY_CTX_new_id, EVP_PKEY_CTX_dup, EVP_PKEY_CTX_free — funciones de contexto de algoritmo de clave pública

SINOPSIS

biblioteca “libcrypto”
#include <openssl/evp.h>

EVP_PKEY_CTX *
EVP_PKEY_CTX_new(EVP_PKEY *pkey, ENGINE *engine);

EVP_PKEY_CTX *
EVP_PKEY_CTX_new_id(int id, ENGINE *engine);

EVP_PKEY_CTX *
EVP_PKEY_CTX_dup(EVP_PKEY_CTX *ctx);

void
EVP_PKEY_CTX_free(EVP_PKEY_CTX *ctx);

DESCRIPCIÓN

La función EVP_PKEY_CTX_new() asigna un contexto de algoritmo de clave pública utilizando el algoritmo especificado en pkey. El argumento ENGINE *engine siempre se ignora y se recomienda pasar NULL.

La función EVP_PKEY_CTX_new_id() asigna un contexto de algoritmo de clave pública utilizando el algoritmo especificado por id. El argumento ENGINE *engine siempre se ignora y se recomienda pasar NULL. Se usa normalmente cuando no hay una estructura EVP_PKEY asociada a las operaciones, por ejemplo, durante la generación de parámetros de generación de claves para algunos algoritmos. El argumento id puede ser cualquiera de las constantes que EVP_PKEY_base_id(3) y EVP_PKEY_id(3) pueden devolver.

EVP_PKEY_CTX_dup() duplica el contexto ctx.

EVP_PKEY_CTX_free() libera el contexto ctx. Si ctx es un puntero NULL, no se realiza ninguna acción.

VALORES DE RETORNO

EVP_PKEY_CTX_new(), EVP_PKEY_CTX_new_id(), y EVP_PKEY_CTX_dup() devuelven la estructura EVP_PKEY_CTX recién asignada o NULL si ocurrió un error.

VER TAMBIÉN

EVP_DigestSignInit(3), EVP_DigestVerifyInit(3), EVP_PKEY_base_id(3), EVP_PKEY_CTX_ctrl(3), EVP_PKEY_CTX_get_operation(3), EVP_PKEY_CTX_hkdf_mode(3), EVP_PKEY_decrypt(3), EVP_PKEY_derive(3), EVP_PKEY_encrypt(3), EVP_PKEY_keygen(3), EVP_PKEY_new(3), EVP_PKEY_sign(3), EVP_PKEY_verify(3), EVP_PKEY_verify_recover(3), RSA_pkey_ctx_ctrl(3), X25519(3)

HISTORIAL

Estas funciones aparecieron por primera vez en OpenSSL 1.0.0 y han estado disponibles desde OpenBSD 4.9.

ADVERTENCIAS

La estructura EVP_PKEY_CTX es un contexto de algoritmo de clave pública opaco utilizado por la API de clave pública de alto nivel de OpenSSL. Los contextos NO SE PUEDEN compartir entre hilos. No está permitido utilizar el mismo contexto simultáneamente en dos hilos.
