EVP_PKEY_VERIFY_RECOVER(3) Manual de funciones de biblioteca EVP_PKEY_VERIFY_RECOVER(3)

NOMBRE

EVP_PKEY_verify_recover_init, EVP_PKEY_verify_recover — recuperar la firma utilizando un algoritmo de clave pública

SINOPSIS

biblioteca “libcrypto”
#include <openssl/evp.h>

int
EVP_PKEY_verify_recover_init(EVP_PKEY_CTX *ctx);

int
EVP_PKEY_verify_recover(EVP_PKEY_CTX *ctx, unsigned char *rout, size_t *routlen, const unsigned char *sig, size_t siglen);

DESCRIPCIÓN

La función EVP_PKEY_verify_recover_init() inicializa un contexto de algoritmo de clave pública utilizando la clave ctx->pkey para una operación de recuperación de firma.

La función EVP_PKEY_verify_recover() recupera datos firmados utilizando ctx. La firma se especifica utilizando los parámetros sig y siglen. Si rout es NULL, entonces el tamaño máximo del búfer de salida se escribe en el parámetro routlen. Si rout no es NULL, entonces antes de la llamada, el parámetro routlen debe contener la longitud del búfer rout. Si la llamada es exitosa, los datos recuperados se escriben en rout y la cantidad de datos se escribe en routlen.

Normalmente, una aplicación solo está interesada en si una operación de verificación de firma es exitosa. En esos casos, se debe usar la función EVP_PKEY_verify(3).

Sin embargo, a veces es útil obtener los datos firmados originalmente utilizando una operación de firma. Solo ciertos algoritmos de clave pública pueden recuperar una firma de esta manera (por ejemplo, RSA en modo de relleno PKCS).

Después de la llamada a EVP_PKEY_verify_recover_init(), se pueden realizar operaciones de control específicas del algoritmo para establecer cualquier parámetro apropiado para la operación.

La función EVP_PKEY_verify_recover() puede llamarse más de una vez en el mismo contexto si se realizan varias operaciones utilizando los mismos parámetros.

VALORES DE RETORNO

EVP_PKEY_verify_recover_init() y EVP_PKEY_verify_recover() devuelven 1 en caso de éxito y 0 o un valor negativo en caso de fallo. En particular, un valor de retorno de -2 indica que la operación no es compatible con el algoritmo de clave pública.

EJEMPLOS

Recuperar el digest originalmente firmado usando PKCS#1 y el digest SHA-256:

#include <openssl/evp.h>
#include <openssl/rsa.h>

EVP_PKEY_CTX *ctx;
unsigned char *rout, *sig;
size_t routlen, siglen;
EVP_PKEY *verify_key;

/*
 * Asume que verify_key, sig y siglen ya están configurados
 * y que verify_key es una clave pública RSA.
 */
ctx = EVP_PKEY_CTX_new(verify_key, NULL);
if (!ctx)
	/* Ocurrió un error */
if (EVP_PKEY_verify_recover_init(ctx) <= 0)
	/* Error */
if (EVP_PKEY_CTX_set_rsa_padding(ctx, RSA_PKCS1_PADDING) <= 0)
	/* Error */
if (EVP_PKEY_CTX_set_signature_md(ctx, EVP_sha256()) <= 0)
	/* Error */

/* Determinar la longitud del búfer */
if (EVP_PKEY_verify_recover(ctx, NULL, &routlen, sig, siglen) <= 0)
	/* Error */

rout = malloc(routlen);

if (!rout)
	/* Fallo de malloc */

if (EVP_PKEY_verify_recover(ctx, rout, &routlen, sig, siglen) <= 0)
	/* Error */

/* Los datos recuperados son routlen bytes escritos en el búfer rout */
