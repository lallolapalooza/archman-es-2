NOMBRE

libpipewire-module-roc-sink - Sumidero ROC

DESCRIPCIÓN

El módulo roc-sink crea un sumidero de PipeWire que envía muestras a una dirección receptora preconfigurada.

A continuación, se puede conectar un flujo de audio de cualquier aplicación en ejecución a ese sumidero o hacerlo el sumidero predeterminado.

NOMBRE DEL MÓDULO

libpipewire-module-roc-sink

OPCIONES DEL MÓDULO

Opciones específicas para el comportamiento de este módulo

  • sink.props = {}: propiedades que se pasarán al flujo de sumidero
  • sink.name = <str>: node.name del sumidero
  • remote.ip = <str>: ip del receptor remoto
  • remote.source.port = <str>: puerto TCP/UDP del receptor remoto para paquetes fuente
  • remote.repair.port = <str>: puerto TCP/UDP del receptor remoto para paquetes del receptor
  • remote.control.port = <str>: puerto TCP/UDP del receptor remoto para paquetes de control
  • fec.code = <str>: Valores posibles: disable, rs8m, ldpc

OPCIONES GENERALES

Opciones con comportamiento bien conocido:

  • node.name
  • node.description
  • media.name

EJEMPLO DE CONFIGURACIÓN

 # ~/.config/pipewire/pipewire.conf.d/my-roc-sink.conf
 context.modules = [
  {   name = libpipewire-module-roc-sink
      args = {
          fec.code = disable
          remote.ip = 192.168.0.244
          remote.source.port = 10001
          remote.repair.port = 10002
          remote.control.port = 10003
          sink.name = "Sumidero ROC"
          sink.props = {
             node.name = "roc-sink"
          }
      }
  }
]
