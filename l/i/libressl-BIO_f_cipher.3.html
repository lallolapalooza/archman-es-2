BIO_f_cipher(3) Manual de funciones de biblioteca BIO_f_cipher(3)

NOMBRE

BIO_f_cipher, BIO_set_cipher, BIO_get_cipher_status, BIO_get_cipher_ctx — filtro BIO de cifrado

SINOPSIS

biblioteca “libcrypto”
#include <openssl/bio.h>
#include <openssl/evp.h>

const BIO_METHOD *
BIO_f_cipher(void);

int
BIO_set_cipher(BIO *b, const EVP_CIPHER *cipher, unsigned char *key, unsigned char *iv, int enc);

long
BIO_get_cipher_status(BIO *b);

long
BIO_get_cipher_ctx(BIO *b, EVP_CIPHER_CTX **pctx);

DESCRIPCIÓN

BIO_f_cipher() devuelve el método BIO de cifrado. Este es un BIO de filtro que cifra cualquier dato escrito a través de él, y descifra cualquier dato leído de él. Es un envoltorio BIO para las rutinas de cifrado EVP_CipherInit(3), EVP_CipherUpdate(3), y EVP_CipherFinal(3).

Los BIOs de cifrado no admiten BIO_gets(3) o BIO_puts(3).

BIO_flush(3) en un BIO de cifrado que se está escribiendo se utiliza para señalar que no se van a cifrar más datos: esto se utiliza para vaciar y posiblemente rellenar el bloque final a través del BIO.

BIO_set_cipher() establece el cifrado del BIO b a cipher usando la clave key y el IV iv. enc debe establecerse en 1 para cifrado y cero para descifrado.

Al leer de un BIO de cifrado, el bloque final se descifra y se verifica automáticamente cuando se detecta EOF. BIO_get_cipher_status() es una macro de BIO_ctrl(3) que se puede llamar para determinar si la operación de descifrado fue exitosa.

BIO_get_cipher_ctx() es una macro de BIO_ctrl(3) que recupera el contexto de cifrado BIO interno. El contexto recuperado se puede utilizar junto con las rutinas de cifrado estándar para configurarlo. Esto es útil cuando BIO_set_cipher() no es lo suficientemente flexible para las necesidades de la aplicación.

Cuando una cadena que contiene un BIO de cifrado se copia con BIO_dup_chain(3), el contexto de cifrado se copia automáticamente del objeto BIO existente al nuevo y el indicador de inicialización que se puede recuperar con BIO_get_init(3) se establece en 1.

Al cifrar, se debe llamar a BIO_flush(3) para vaciar el bloque final a través del BIO. Si no se hace, el bloque final fallará un descifrado posterior.

Al descifrar, un error en el bloque final se señala mediante un valor de retorno cero de la operación de lectura. Un descifrado exitoso seguido de EOF también devolverá cero para la última lectura. Se debe llamar a BIO_get_cipher_status() para determinar si el descifrado fue exitoso.

Como siempre, si se necesita soporte para BIO_gets(3) o BIO_puts(3), se puede lograr precediendo el BIO de cifrado con un BIO de almacenamiento en búfer.

BIO_ctrl(3) los argumentos cmd corresponden a macros de la siguiente manera:

cmd constante macro correspondiente
BIO_C_GET_CIPHER_CTX BIO_get_cipher_ctx()
BIO_C_GET_CIPHER_STATUS BIO_get_cipher_status()
BIO_CTRL_FLUSH BIO_flush(3)
BIO_CTRL_PENDING BIO_pending(3)
BIO_CTRL_RESET BIO_reset(3)
BIO_CTRL_WPENDING BIO_wpending(3)

VALORES DE RETORNO

BIO_f_cipher() devuelve el método BIO de cifrado.

Cuando se llama en un objeto BIO de cifrado, BIO_method_type(3) devuelve la constante BIO_TYPE_CIPHER y BIO_method_name(3) devuelve un puntero a la cadena estática "cipher".

BIO_set_cipher() devuelve 1 en caso de éxito y 0 en caso de error.

BIO_get_cipher_status() devuelve 1 para un descifrado exitoso y 0 para fallo.

BIO_get_cipher_ctx() actualmente siempre devuelve 1.

VER TAMBIÉN

BIO_new(3), EVP_EncryptInit(3)

HISTORIA

BIO_f_cipher(), BIO_set_cipher(), y BIO_get_cipher_status() aparecieron por primera vez en SSLeay 0.6.5 y han estado disponibles desde OpenBSD 2.4.

BIO_get_cipher_ctx() apareció por primera vez en SSLeay 0.9.1 y ha estado disponible desde OpenBSD 2.6.

BIO_f_cipher(3) - libressl

NOMBRE

BIO_f_cipher — BIO filtro de cifrado/descifrado.

SINOPSIS

#include <openssl/bio.h>

BIO_METHOD *
       BIO_f_cipher(void);

DESCRIPCIÓN

El filtro BIO BIO_f_cipher permite cifrar y descifrar datos. Se utiliza encadenando un BIO de cifrado o descifrado a un BIO existente. El BIO de cifrado/descifrado se inicializa con el cifrado deseado, una clave y un vector de inicialización (IV). Tanto los datos que entran en el BIO como los datos que salen de él se cifran o descifran según corresponda.

Este filtro BIO admite las siguientes operaciones:

  • BIO_CTRL_SET_CIPHER: Establece el cifrado, la clave y el IV. El argumento de esta operación debe ser un puntero a una estructura BIO_CIPHER_INFO, definida en <openssl/bio.h>: 
    typedef struct bio_cipher_info_st {
    const EVP_CIPHER *cipher;
    unsigned char *key;
    size_t key_len;
    unsigned char *iv;
    size_t iv_len;
} BIO_CIPHER_INFO;
    Tenga en cuenta que el filtro BIO BIO_f_cipher toma la propiedad de la memoria asignada para key y iv.
  • BIO_CTRL_GET_CIPHER_CTX: Obtiene el contexto EVP del cifrado.
  • BIO_CTRL_EOF: Devuelve 1 si el BIO está en el estado EOF, 0 en caso contrario. Esto está relacionado con si el último bloque de datos se ha procesado.
  • BIO_CTRL_SET_CLOSE, BIO_CTRL_SET_FILE, BIO_CTRL_INFO, etc.: Estas operaciones de control son transmitidas al BIO subyacente.

VALORES DE RETORNO

BIO_f_cipher() devuelve un puntero al objeto BIO_METHOD para el filtro de cifrado.

VER TAMBIÉN

BIO_new(3), EVP_CIPHER_CTX_new(3), EVP_EncryptInit(3), EVP_DecryptInit(3)

HISTORIA

El filtro BIO BIO_f_cipher apareció por primera vez en OpenSSL 0.9.8.
