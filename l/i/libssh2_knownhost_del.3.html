Licencias: BSD

libssh2_knownhost_del(3) libssh2 libssh2_knownhost_del(3)

NOMBRE

libssh2_knownhost_del - eliminar una entrada de host conocido

SINOPSIS

#include <libssh2.h>
int
libssh2_knownhost_del(LIBSSH2_KNOWNHOSTS *hosts,
                      struct libssh2_knownhost *entry);

DESCRIPCIÓN

Elimina una entrada de host conocido de la colección de hosts conocidos.

entry es un puntero a una estructura que puedes extraer con libssh2_knownhost_check(3) o libssh2_knownhost_get(3).

VALOR DE RETORNO

Devuelve un código de error regular de libssh2, donde los valores negativos son códigos de error y 0 indica éxito.

DISPONIBILIDAD

Añadido en libssh2 1.2

VER TAMBIÉN
