libressl-ERR_get_error(3)

Paquete: libressl

Licencias: ISC, custom:OpenSSL

ERR_GET_ERROR(3) Manual de funciones de biblioteca ERR_GET_ERROR(3)

NOMBRE

ERR_get_error, ERR_peek_error, ERR_peek_last_error, ERR_get_error_line, ERR_peek_error_line, ERR_peek_last_error_line, ERR_get_error_line_data, ERR_peek_error_line_data, ERR_peek_last_error_line_data — obtener código y datos de error de OpenSSL

SINOPSIS

biblioteca “libcrypto”
#include <openssl/err.h>

unsigned long
ERR_get_error(void);

unsigned long
ERR_peek_error(void);

unsigned long
ERR_peek_last_error(void);

unsigned long
ERR_get_error_line(const char **file, int *line);

unsigned long
ERR_peek_error_line(const char **file, int *line);

unsigned long
ERR_peek_last_error_line(const char **file, int *line);

unsigned long
ERR_get_error_line_data(const char **file, int *line, const char **data, int *flags);

unsigned long
ERR_peek_error_line_data(const char **file, int *line, const char **data, int *flags);

unsigned long
ERR_peek_last_error_line_data(const char **file, int *line, const char **data, int *flags);

DESCRIPCIÓN

ERR_get_error() devuelve el código de error más antiguo de la cola de errores del hilo y elimina la entrada. Esta función se puede llamar repetidamente hasta que no queden más códigos de error que devolver.

ERR_peek_error() devuelve el código de error más antiguo de la cola de errores del hilo sin modificarlo.

ERR_peek_last_error() devuelve el código de error más reciente de la cola de errores del hilo sin modificarlo.

Consulte ERR_GET_LIB(3) para obtener información sobre la ubicación y la razón del error, y ERR_error_string(3) para mensajes de error legibles por humanos.

ERR_get_error_line(), ERR_peek_error_line(), y ERR_peek_last_error_line() son iguales a las anteriores, pero además almacenan el nombre del archivo y el número de línea donde ocurrió el error en *file y *line, a menos que estos sean NULL.

ERR_get_error_line_data(), ERR_peek_error_line_data(), y ERR_peek_last_error_line_data() almacenan datos adicionales y banderas asociadas con el código de error en *data y *flags, a menos que estos sean NULL. *data contiene una cadena si *flags&ERR_TXT_STRING es verdadero.

NO DEBE una aplicación liberar el puntero *data (o cualquier otro puntero devuelto por estas funciones) con free(3), ya que la biblioteca de errores se encarga de la liberación automáticamente.

VALORES DE RETORNO

El código de error, o 0 si no hay ningún error en la cola.

VER TAMBIÉN

ERR(3), ERR_error_string(3), ERR_GET_LIB(3)

HISTORIAL

ERR_get_error() y ERR_peek_error() aparecieron por primera vez en SSLeay 0.4.4. ERR_get_error_line() y ERR_peek_error_line() aparecieron por primera vez en SSLeay 0.6.0. ERR_get_error_line_data() y ERR_peek_error_line_data() aparecieron por primera vez en SSLeay 0.9.0. Todas estas funciones han estado disponibles desde OpenBSD 2.4.

ERR_peek_last_error(), ERR_peek_last_error_line(), y ERR_peek_last_error_line_data() aparecieron por primera vez en OpenSSL 0.9.7 y han estado disponibles desde OpenBSD 3.2.
