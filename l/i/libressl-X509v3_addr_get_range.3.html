libressl-X509v3_addr_get_range(3)

Paquete: libressl

Licencias: ISC, custom:OpenSSL

X509V3_ADDR_GET_RANGE(3) Manual de funciones de la biblioteca X509V3_ADDR_GET_RANGE(3)

NOMBRE

X509v3_addr_get_afi, X509v3_addr_get_range — ayudantes de análisis para la extensión de delegación de direcciones IP

SINOPSIS

biblioteca “libcrypto”
#include <openssl/x509v3.h>

unsigned
X509v3_addr_get_afi(const IPAddressFamily *af);

int
X509v3_addr_get_range(IPAddressOrRange *aor, const unsigned afi, unsigned char *min, unsigned char *max, const int length);

DESCRIPCIÓN

X509v3_addr_get_afi() devuelve el identificador de familia de direcciones (AFI) de af.

X509v3_addr_get_range() convierte las direcciones mínima y máxima en el prefijo o rango de direcciones aor de la codificación interna a direcciones IP en orden de bytes de red y coloca copias en los arrays min y max, de tamaño length. El length debe ser lo suficientemente grande para albergar una dirección para afi, que es al menos 4 para IANA_AFI_IPV4 y al menos 16 para IANA_AFI_IPV6.

VALORES DE RETORNO

X509v3_addr_get_afi() devuelve el AFI codificado en af o 0 si af no contiene un AFI válido, o si el AFI no es IPv4 o IPv6.

X509v3_addr_get_range() devuelve el número de bytes copiados en min y max o 0 en caso de error. Ocurre un error si aor está malformado, si afi no es IANA_AFI_IPV4 o IANA_AFI_IPV6, si min o max es NULL, o si length es menor que 4 o 16, respectivamente.

VER TAMBIÉN

crypto(3), inet_ntop(3), IPAddressRange_new(3), X509_new(3), X509v3_addr_add_inherit(3)

ESTÁNDARES

RFC 3779: Extensiones X.509 para Direcciones IP e Identificadores de AS:

  • sección 2: Extensión de delegación de direcciones IP
  • sección 2.2.3.3: Elemento addressFamily
  • sección 2.2.3.7: Tipo IPAddressOrRange
  • sección 2.2.3.8: Elemento addressPrefix y Tipo IPAddress

Números de Familia de Direcciones, https://www.iana.org/assignments/address-family-numbers.

HISTORIAL

Estas funciones aparecieron por primera vez en OpenSSL 0.9.8e y han estado disponibles desde OpenBSD 7.1.

ERRORES

No hay un accesor para el SAFI de af.

Un error de X509v3_addr_get_afi() es indistinguible del AFI reservado 0 establecido en af.

No está del todo claro cómo se supone que un llamante debe obtener un objeto IPAddressFamily o un objeto IPAddressOrRange sin acceder a varias estructuras documentadas en IPAddressRange_new(3).
