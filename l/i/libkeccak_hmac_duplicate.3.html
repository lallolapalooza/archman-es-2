NOMBRE

libkeccak_hmac_duplicate - Asigna un duplicado de un estado de hash HMAC

SINOPSIS

#include <libkeccak.h>
struct libkeccak_hmac_state *libkeccak_hmac_duplicate(const struct libkeccak_hmac_state *src);

Enlazar con -lkeccak.

DESCRIPCIÓN

La función libkeccak_hmac_duplicate() asigna un nuevo estado de hash y lo inicializa para que sea idéntico a *src. Esto incluye todos los miembros de la estructura struct libkeccak_hmac_state, incluyendo el estado de la esponja y el búfer de fragmentos de mensaje.

VALORES DE RETORNO

La función libkeccak_hmac_duplicate() devuelve un libkeccak_hmac_t* recién asignado (de un elemento inicializado) en caso de éxito. En caso de error, se devuelve NULL y se establece errno para describir el error.

ERRORES

La función libkeccak_hmac_duplicate() puede fallar por cualquier motivo especificado para la función malloc(3).

VER TAMBIÉN

libkeccak_hmac_copy(3), libkeccak_hmac_create(3)
