libressl-RAND_bytes(3)

Paquete: libressl

Licencias: ISC, custom:OpenSSL

RAND_BYTES(3) Manual de Funciones de Biblioteca RAND_BYTES(3)

NOMBRE

RAND_bytes, RAND_pseudo_bytes — generar datos aleatorios

SINOPSIS

biblioteca “libcrypto”
#include <openssl/rand.h>

int
RAND_bytes(unsigned char *buf, int num);

int
RAND_pseudo_bytes(unsigned char *buf, int num);

DESCRIPCIÓN

Estas funciones están obsoletas y solo se conservan por compatibilidad con programas de aplicación heredados. Use arc4random_buf(3) en su lugar.

RAND_bytes() coloca num bytes pseudoaleatorios criptográficamente seguros en buf.

RAND_pseudo_bytes() coloca num bytes pseudoaleatorios en buf. Las secuencias de bytes pseudoaleatorios generadas por RAND_pseudo_bytes() serán únicas si tienen una longitud suficiente, pero no son necesariamente impredecibles. Se pueden utilizar para fines no criptográficos y para ciertos fines en protocolos criptográficos, pero generalmente no para la generación de claves, etc.

VALORES DE RETORNO

RAND_bytes() devuelve 1. RAND_pseudo_bytes() devuelve 1.

HISTORIA

RAND_bytes() apareció por primera vez en SSLeay 0.5.1 y ha estado disponible desde OpenBSD 2.4. Tiene un valor de retorno desde OpenSSL 0.9.5 y OpenBSD 2.7.

RAND_pseudo_bytes() apareció por primera vez en OpenSSL 0.9.5 y ha estado disponible desde OpenBSD 2.7.
