libkeccak_degeneralise_spec(3)

Paquete: libkeccak

Licencias: custom:ISC

LIBKECCAK_DEGENERALISE_SPEC(3) Manual de funciones de biblioteca LIBKECCAK_DEGENERALISE_SPEC(3)

NOMBRE

libkeccak_degeneralise_spec - Establece todos los parámetros de especificación en automático

SINOPSIS

#include <libkeccak.h>
int libkeccak_degeneralise_spec(struct libkeccak_generalised_spec *spec, struct libkeccak_spec *output_spec);

Enlazar con -lkeccak.

DESCRIPCIÓN

La función libkeccak_degeneralise_spec() resolverá los parámetros automáticos en *spec y traducirá los parámetros a *output_spec, de modo que pueda ser utilizada para el hash.

La función modificará tanto *spec como *output_spec.

Debería llamar a la función libkeccak_spec_check(3) después de llamar a libkeccak_degeneralise_spec().

struct libkeccak_generalised_spec {
	long int bitrate;    /* bitrate (en bits) */
	long int capacity;   /* capacity (en bits) */
	long int output;     /* tamaño de salida (en bits) */
	long int state_size; /* tamaño de estado (en bits) */
	long int word_size;  /* tamaño de palabra (en bits) */
};

VALORES DE RETORNO

La función libkeccak_degeneralise_spec() devuelve 0 si la configuración es utilizable. De lo contrario, devolverá una de las siguientes constantes.

LIBKECCAK_GENERALISED_SPEC_ERROR_STATE_NONPOSITIVE
El tamaño de estado especificado no es positivo.
LIBKECCAK_GENERALISED_SPEC_ERROR_STATE_TOO_LARGE
El tamaño de estado especificado superó el límite soportado (actualmente 1600 bits).
LIBKECCAK_GENERALISED_SPEC_ERROR_STATE_MOD_25
El tamaño de estado especificado, en bits, no fue equivalente a 0 módulo 25. Esto significa que el tamaño de estado no puede cubrir todos los carriles de manera equivalente.
LIBKECCAK_GENERALISED_SPEC_ERROR_WORD_NONPOSITIVE
El tamaño de palabra especificado no es positivo.
LIBKECCAK_GENERALISED_SPEC_ERROR_WORD_TOO_LARGE
El tamaño de palabra especificado superó el límite soportado (actualmente 64 bits).
LIBKECCAK_GENERALISED_SPEC_ERROR_STATE_WORD_INCOHERENCY
El tamaño de estado especificado no es exactamente 25 veces mayor que el tamaño de palabra.
LIBKECCAK_GENERALISED_SPEC_ERROR_CAPACITY_NONPOSITIVE
La capacidad especificada no es positiva.
LIBKECCAK_GENERALISED_SPEC_ERROR_CAPACITY_MOD_8
La capacidad especificada no fue equivalente a 0 módulo 8, es decir, no estaba en bytes completos.
LIBKECCAK_GENERALISED_SPEC_ERROR_BITRATE_NONPOSITIVE
El bitrate especificado no es positivo.
LIBKECCAK_GENERALISED_SPEC_ERROR_BITRATE_MOD_8
El bitrate especificado no fue equivalente a 0 módulo 8, es decir, no estaba en bytes completos.
LIBKECCAK_GENERALISED_SPEC_ERROR_OUTPUT_NONPOSITIVE
El tamaño de salida especificado no es positivo.
LIBKECCAK_GENERALISED_SPEC_ERROR_STATE_BITRATE_CAPACITY_INCONSISTENCY
La suma del bitrate y la capacidad no es igual al tamaño de estado (25 veces el tamaño de palabra).

Tenga en cuenta que puede haber más de un error. Solo se devuelve el primero detectado.

ERRORES

La función libkeccak_degeneralise_spec() no puede fallar.

EJEMPLO

Este ejemplo configura un struct libkeccak_spec para especificar la configuración de Keccak[c = 512]:

int r;
struct libkeccak_spec spec;
struct libkeccak_generalised_spec gspec;
libkeccak_generalised_spec_initialise(&gspec);
gspec.capacity = 512;
if ((r = libkeccak_degeneralise_spec(&gspec, &spec)))
    goto fail_degeneralise_spec;
if ((r = libkeccak_spec_check(&spec)));
    goto fail_spec_check;
