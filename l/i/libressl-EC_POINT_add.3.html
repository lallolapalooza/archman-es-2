libressl-EC_POINT_add(3)

Paquete: libressl

Licencias: ISC, custom:OpenSSL

EC_POINT_ADD(3) Manual de funciones de biblioteca EC_POINT_ADD(3)

NOMBRE

EC_POINT_add, EC_POINT_dbl, EC_POINT_invert, EC_POINT_is_at_infinity, EC_POINT_is_on_curve, EC_POINT_cmp, EC_POINT_make_affine, EC_POINT_mul — realizar operaciones matemáticas y pruebas en objetos EC_POINT

SINOPSIS

biblioteca “libcrypto”
#include <openssl/ec.h>
#include <openssl/bn.h>

int
EC_POINT_add(const EC_GROUP *group, EC_POINT *r, const EC_POINT *a, const EC_POINT *b, BN_CTX *ctx);

int
EC_POINT_dbl(const EC_GROUP *group, EC_POINT *r, const EC_POINT *a, BN_CTX *ctx);

int
EC_POINT_invert(const EC_GROUP *group, EC_POINT *a, BN_CTX *ctx);

int
EC_POINT_is_at_infinity(const EC_GROUP *group, const EC_POINT *p);

int
EC_POINT_is_on_curve(const EC_GROUP *group, const EC_POINT *point, BN_CTX *ctx);

int
EC_POINT_cmp(const EC_GROUP *group, const EC_POINT *a, const EC_POINT *b, BN_CTX *ctx);

int
EC_POINT_make_affine(const EC_GROUP *group, EC_POINT *point, BN_CTX *ctx);

int
EC_POINT_mul(const EC_GROUP *group, EC_POINT *r, const BIGNUM *n, const EC_POINT *q, const BIGNUM *m, BN_CTX *ctx);

DESCRIPCIÓN

Estas funciones operan sobre objetos EC_POINT creados por EC_POINT_new(3).

EC_POINT_add() suma los dos puntos a y b y coloca el resultado en r. De manera similar, EC_POINT_dbl() duplica el punto a y coloca el resultado en r. En ambos casos, es válido que r sea uno de a o b.

EC_POINT_invert() calcula la inversa del punto suministrado a. El resultado se vuelve a colocar en a.

La función EC_POINT_is_at_infinity() comprueba si el punto suministrado está en el infinito o no.

EC_POINT_is_on_curve() comprueba si el punto suministrado está en la curva o no.

EC_POINT_cmp() compara los dos puntos suministrados y comprueba si son iguales o no.

EC_POINT_mul() calcula el valor

generador * n + q * m

y almacena el resultado en r. El valor n puede ser NULL, en cuyo caso el resultado es solo

q * m.

Ver EC_GROUP_new_curve_GFp(3) para obtener información sobre el generador.

VALORES DE RETORNO

Las siguientes funciones devuelven 1 en caso de éxito o 0 en caso de error: EC_POINT_add(), EC_POINT_dbl(), EC_POINT_invert(), EC_POINT_make_affine(), y EC_POINT_mul()

EC_POINT_is_at_infinity() devuelve 1 si el punto está en el infinito o 0 en caso contrario.

EC_POINT_is_on_curve() devuelve 1 si el punto está en la curva, 0 si no lo está, o -1 en caso de error.

EC_POINT_cmp() devuelve 1 si los puntos no son iguales, 0 si lo son, o -1 en caso de error.
