NOMBRE

librrd - Funciones de la biblioteca RRD

DESCRIPCIÓN

librrd contiene la mayor parte de la funcionalidad de RRDtool. Las utilidades de línea de comandos y los enlaces de idioma suelen ser simplemente envoltorios alrededor del código contenido en librrd.

Esta página del manual documenta la API de librrd.

NOTA: Este documento está en progreso y debe considerarse incompleto mientras esta advertencia persista. Para obtener más información sobre las funciones de librrd, consulte siempre el código fuente.

FUNCIONES NÚCLEO

rrd_dump_cb_r(char *filename, int opt_header, rrd_output_callback_t cb, void *user)
En algunas situaciones, es necesario obtener la salida de "rrd_dump" sin escribirla en un archivo o en la salida estándar. En tales casos, una aplicación puede solicitar a rrd_dump_cb_r que llame a una función definida por el usuario cada vez que haya salida que almacenar en algún lugar. Esto se puede utilizar para, por ejemplo, alimentar directamente un analizador XML con la salida volcada o transferir la cadena resultante en memoria.

Los argumentos para rrd_dump_cb_r son los mismos que para rrd_dump_opt_r, excepto que el parámetro del nombre de archivo de salida se reemplaza por la función de devolución de llamada definida por el usuario y un parámetro adicional para la función de devolución de llamada que se pasa sin modificar, es decir, para almacenar información sobre el estado de la devolución de llamada necesario para que la función de devolución de llamada definida por el usuario funcione correctamente.

Las versiones recientes de rrd_dump_opt_r utilizan internamente este mecanismo de devolución de llamada para escribir su salida en el archivo proporcionado por el usuario.

size_t rrd_dump_opt_cb_fileout(
    const void *data,
    size_t len,
    void *user)
{
    return fwrite(data, 1, len, (FILE *)user);
}

La llamada asociada para rrd_dump_cb_r se ve así:

res = rrd_dump_cb_r(filename, opt_header,
    rrd_dump_opt_cb_fileout, (void *)out_file);

donde el último parámetro especifica el manejador de archivo al que debe escribir rrd_dump_opt_cb_fileout. No hay ninguna condición específica para que la devolución de llamada detecte cuándo se llama por primera vez, ni cuándo se llama por última vez. Si necesita esto para la inicialización y la limpieza, debe realizar esas tareas antes y después de llamar a rrd_dump_cb_r respectivamente.

rrd_fetch_cb_register(rrd_fetch_cb_t c)
Si sus datos no residen en archivos rrd, pero le gustaría dibujar gráficos utilizando la funcionalidad rrd_graph, puede proporcionar su propia función rrd_fetch y registrarla utilizando la función rrd_fetch_cb_register.

La firma y la API del argumento deben ser equivalentes a las de la función de devolución de llamada y deben ser equivalentes a las de rrd_fetch_fn en rrd_fetch.c.

Para activar la función de devolución de llamada puede usar el nombre de archivo pseudo cb//free_form_text.

Tenga en cuenta que rrdtool graph no solicitará datos del mismo rrd dos veces. Lo determina construyendo una clave a partir de los valores suministrados a la función fetch. Si los valores son los mismos, se utilizará la respuesta anterior.

FUNCIONES DE UTILIDAD

rrd_random()
Genera números aleatorios al igual que random(). Esto garantiza aún más que el generador de números aleatorios se inicialice exactamente una vez por proceso.
rrd_strtodbl
un conversor de cadena a doble consciente de rrd que establece rrd_error si hay un problema y utiliza el código de retorno exclusivamente para informar del estado de la conversión.
rrd_strtod
funciona como el strtod normal, pero es independiente de la configuración regional (y seguro para hilos)
rrd_snprintf
funciona como el snprintf normal, pero es independiente de la configuración regional (y seguro para hilos)
rrd_add_ptr(void ***dest, size_t *dest_size, void *src)
Redimensiona dinámicamente la matriz apuntada por "dest". "dest_size" es un puntero al tamaño actual de "dest". Tras un realloc() exitoso, "dest_size" se incrementa en 1 y el puntero "src" se almacena al final del nuevo "dest". Devuelve 1 en caso de éxito, 0 en caso de fallo. 
type **arr = NULL;
type *elem = "whatever";
size_t arr_size = 0;
if (!rrd_add_ptr(&arr, &arr_size, elem))
    handle_failure();
rrd_add_ptr_chunk(void ***dest, size_t *dest_size, void *src, size_t *alloc, size_t chunk)
Al igual que "rrd_add_ptr", excepto que el destino se asigna en bloques de "chunk". "alloc" apunta al número de entradas asignadas, mientras que "dest_size" apunta al número de punteros válidos. Si se necesitan más punteros, se asignan "chunk" punteros y "alloc" se incrementa en consecuencia. "alloc" debe ser >= "dest_size".

Este método mejora el rendimiento en hosts con "realloc()" costosos.

rrd_add_strdup(char ***dest, size_t *dest_size, char *src)
Al igual que "rrd_add_ptr", excepto que añade un "strdup" de la cadena de origen. 
char **arr = NULL;
size_t arr_size = NULL;
char *str  = "example text";
if (!rrd_add_strdup(&arr, &arr_size, str))
    handle_failure();
rrd_add_strdup_chunk(char ***dest, size_t *dest_size, char *src, size_t *alloc, size_t chunk)
Al igual que "rrd_add_strdup", excepto que el destino se asigna en bloques de "chunk". "alloc" apunta al número de entradas asignadas, mientras que "dest_size" apunta al número de punteros válidos. Si se necesitan más punteros, se asignan "chunk" punteros y "alloc" se incrementa en consecuencia. "alloc" debe ser >= "dest_size".
rrd_free_ptrs(void ***src, size_t *cnt)
Libera una matriz de punteros asignados por "rrd_add_ptr" o "rrd_add_strdup". También libera el puntero de la matriz en sí. Al regresar, el puntero de origen será NULL y el contador será cero. 
/* creado como arriba */
rrd_free_ptrs(&arr, &arr_size);
/* aquí, arr == NULL && arr_size == 0 */
rrd_mkdir_p(const char *pathname, mode_t mode)
Crea el directorio llamado "pathname" incluyendo todos sus directorios padre (similar a "mkdir -p" en la línea de comandos - vea mkdir(1) para más información). El argumento "mode" especifica los permisos a usar. Es modificado por el "umask" del proceso. Vea mkdir(2) para más detalles.

La función devuelve 0 en caso de éxito, un valor negativo en caso contrario. En caso de error, "errno" se establece en consecuencia. Aparte de los errores documentados en mkdir(2), la función puede fallar con los siguientes errores:

EINVAL
El argumento "pathname" era inválido.

Este sitio no está asociado de ninguna forma con Arch Linux ni afiliado a este proyecto. El contenido es únicamente una traducción de las páginas del manual de Arch publicadas en man.archlinux.org.

ENOTEMPTY
"pathname" es "NULL" o la cadena vacía.
ENOMEM
No había suficiente memoria disponible.
cualquier error devuelto por stat(2)

A diferencia de mkdir(2), la función no falla si "pathname" ya existe y es un directorio.

rrd_scaled_duration (const char * token, unsigned long divisor, unsigned long * valuep)
Analiza un token en un contexto donde contiene un recuento (de segundos o instancias PDP), o una duración que se puede convertir a un recuento representando la duración en segundos y dividiendo por algún factor de escala. Por ejemplo, si un usuario expresara nativamente un archivo de 3 días de muestras recolectadas cada 2 minutos, el intervalo de muestra se puede representar por "2m" en lugar de 120, y la duración del archivo por "3d" (para ser dividido por 120) en lugar de 2160 (3*24*60*60 / 120). Ver más ejemplos en "STEP, HEARTBEAT, and Rows As Durations" en rrdcreate.

"token" debe ser un número con un sufijo opcional de un solo carácter que codifica el factor de escala:

"s"
indica segundos
"m"
indica minutos. El valor se multiplica por 60.
"h"
indica horas. El valor se multiplica por 3600 (o "60m").
"d"
indica días. El valor se multiplica por 86400 (o "24h").
"w"
indica semanas. El valor se multiplica por 604800 (o "7d").
"M"
indica meses. El valor se multiplica por 2678400 (o "31d"). (Nota: este factor acomoda el número máximo de días en un mes.)
"y"
indica años. El valor se multiplica por 31622400 (o "366d"). (Nota: este factor acomoda los años bisiestos.)

"divisor" es un valor positivo que representa la duración en segundos de un intervalo del cual el resultado deseado cuenta.

"valuep" es un puntero a donde se almacenará el valor decodificado si la conversión es exitosa.

Los caracteres iniciales de "token" deben ser la representación en base 10 de un entero positivo, o la conversión falla.

Si el resto de "token" está vacío (sin sufijo), es un recuento y no se realiza ningún escalado.

Si "token" tiene uno de los sufijos anteriores, el recuento se multiplica para convertirlo a una duración en segundos. El número resultante de segundos se divide por "divisor" para producir un recuento de intervalos, cada uno con una duración de "divisor" segundos. Si la división produjera un resto (por ejemplo, "5m" (300 segundos) dividido por "90s"), la conversión no es válida.

Si "token" tiene caracteres finales no reconocidos, la conversión falla.

La función devuelve un puntero nulo si la conversión fue exitosa y "valuep" ha sido actualizado al valor escalado. En caso de fallo, devuelve un diagnóstico de texto adecuado para su uso en mensajes de error al usuario.

FUNCIONES DEL CLIENTE

Las siguientes funciones se utilizan para conectarse a una instancia de rrdcached, ya sea a través de una dirección unix o inet, y crear, actualizar o recopilar estadísticas sobre un archivo de base de datos RRD especificado.

Hay dos interfaces diferentes: La familia de funciones rrd_client_ opera sobre un objeto cliente proporcionado por el usuario (rrd_client_t) y admite conexiones concurrentes a instancias de rrdcache. La familia más simple de funciones rrdc_ maneja las conexiones de forma transparente pero solo se puede utilizar para una conexión a la vez.

Todas las siguientes funciones y tipos de datos se especifican en el archivo de encabezado "rrd_client.h".

rrd_client_new(const char *daemon_addr)
Crea un nuevo objeto de conexión de cliente. Si se especifica, conéctese al demonio en "daemon_addr". La conexión se puede cambiar posteriormente llamando a rrd_client_connect.
rrd_client_destroy(rrd_client_t *client)
Cierra una conexión de cliente y destruye el objeto liberando toda la memoria asignada dinámicamente. Después de llamar a esta función, "client" ya no se puede usar.
rrd_client_connect(rrd_client_t *client, const char *daemon_addr)
rrdc_connect(const char *daemon_addr)
Conéctese a una instancia de rrdcached en ejecución, especificada a través de "daemon_addr". Se cerrará cualquier conexión anterior. Si "daemon_addr" es "NULL", se utilizará por defecto la dirección del entorno "ENV_RRDCACHED_ADDRESS".
rrd_client_is_connected(rrd_client_t *client)
Devuelve un entero booleano si el cliente está conectado al servidor.
rrd_client_address(rrd_client_t *client)
Devuelve la dirección del servidor perteneciente a la conexión actual.
rrdc_is_connected(const char *daemon_addr)
Devuelve un entero booleano para determinar si el cliente está conectado al demonio rrdcache especificado por el parámetro "daemon_addr".
rrd_client_ping(rrd_client_t *client)
rrdc_ping
Comprueba la conexión del cliente haciendo ping al lado remoto.
rrdc_is_any_connected
Devuelve un entero booleano si alguna conexión de demonio está activa.
rrd_client_disconnect(rrd_client_t *client)
rrdc_disconnect
Desconéctese de forma elegante de la conexión de demonio actual.
rrd_client_update(rrd_client_t *client, const char *filename, int values_num, const char * const *values)
rrdc_update(const char *filename, int values_num, const char * const *values)
Actualiza el RRD "filename" a través de rrdcached. Donde "values_num" es el número de valores a actualizar y "values" son los nuevos valores a agregar.
rrd_client_info(rrd_client_t *client, const char *filename)
rrdc_info(const char *filename)
Obtiene información del rrd del archivo RRD "filename" del demonio de caché conectado. Esta función devuelve una estructura rrd_info_t del siguiente formato: 
typedef struct rrd_blob_t {
    unsigned long size; /* tamaño del blob */
    unsigned char *ptr; /* puntero */
} rrd_blob_t;
typedef enum rrd_info_type { RD_I_VAL = 0,
    RD_I_CNT,
    RD_I_STR,
    RD_I_INT,
    RD_I_BLO
} rrd_info_type_t;
typedef union rrd_infoval {
    unsigned long u_cnt;
    rrd_value_t u_val;
    char     *u_str;
    int       u_int;
    rrd_blob_t u_blo;
} rrd_infoval_t;
typedef struct rrd_info_t {
    char     *key;
    rrd_info_type_t type;
    rrd_infoval_t value;
    struct rrd_info_t *next;
} rrd_info_t;
rrd_client_last(rrd_client_t *client, const char *filename)
rrdc_last(const char *filename)
Obtiene la época Unix de la última vez que se actualizó el RRD "filename".
rrd_client_first(rrd_client_t *client, const char *filename, int rraindex)
rrdc_first(const char *filename, int rraindex)
Obtiene el primer valor de la primera muestra del RRD "filename", del índice RRA (Round Robin Archive) "rraindex". El número de índice RRA se puede determinar extrayendo el rrd_info_t del RRD.
rrd_client_create(rrd_client_t *client, const char *filename, unsigned long pdp_step, time_t last_up, int no_overwrite, int argc, const char **argv)
rrdc_create(const char *filename, unsigned long pdp_step, time_t last_up, int no_overwrite, int argc, const char **argv)
Crea la base de datos RRD de la ruta "filename". El RRD tendrá un tamaño de paso de "pfp_step", la marca de tiempo de época Unix desde la cual comenzar a recopilar datos. El número de fuentes de datos y R
RAs "argc" y las definiciones de las fuentes de datos y RRA "argv". Por último, si se debe sobrescribir o no una RRD existente si se encuentra una con el mismo nombre de archivo; "no_overwrite".
rrdc_create_r2(rrd_client_t *client, const char *filename, unsigned long pdp_step, time_t last_up, int no_overwrite, const char **sources, const char *template, int argc, const char **argv)
rrdc_create_r2(const char *filename, unsigned long pdp_step, time_t last_up, int no_overwrite, const char **sources, const char *template, int argc, const char **argv)
Crea una base de datos RRD en el demonio. rrdc_create_r2 tiene los mismos parámetros que rrdc_create con dos parámetros adicionales: "sources" y "template".

donde "template" es la ruta del archivo a una plantilla de archivo RRD, con el formato definido en rrdcreate(1),

El parámetro "sources" define series de rutas de archivo con datos definidos, para prellenar la RRD. Consulte rrdcreate(1) para más detalles.

rrd_client_flush(rrd_client_t *client, const char *filename)
rrdc_flush(const char *filename)
Limpia la RRD actualmente en caché en el demonio especificado a través de "filename".
rrd_client_forget(rrd_client_t *client, const char *filename)
rrdc_forget(const char *filename)
Descarta los datos en caché del archivo RRD especificado a través de "filename".
rrdc_flush_if_daemon(const char *daemon_addr, const char *filename)
Limpia la RRD especificada dada por "filename" solo si el demonio "daemon_addr" está activo y conectado.
rrd_client_fetch(rrd_client_t *client, const char *filename, const char *cf, time_t *ret_start, time_t *ret_end, unsigned long *ret_step, unsigned long *ret_ds_num, char ***ret_ds_names, rrd_value_t **ret_data)
rrdc_fetch(const char *filename, const char *cf, time_t *ret_start, time_t *ret_end, unsigned long *ret_step, unsigned long *ret_ds_num, char ***ret_ds_names, rrd_value_t **ret_data)
Realiza una operación de obtención en la Base de Datos RRD especificada dada por "filename", donde "cf" es la función de consolidación, "ret_start" es la hora de inicio dada por la época de Unix, "ret_end" es la hora de fin. "ret_step" es el tamaño del paso en segundos, "ret_ds_num" el número de fuentes de datos en la RRD, "ret_ds_names" los nombres de las fuentes de datos, y un puntero a un objeto rrd_value_t para transferir los datos.
rrdc_stats_get(rrd_client_t *client, rrdc_stats_t **ret_stats)
rrdc_stats_get(rrdc_stats_t **ret_stats)
Obtiene estadísticas del demonio conectado, a través de una lista enlazada de la siguiente estructura: 
struct rrdc_stats_s {
    const char *name;
    uint16_t type;
    #define RRDC_STATS_TYPE_GAUGE   0x0001
    #define RRDC_STATS_TYPE_COUNTER 0x0002
    uint16_t flags;
    union {
        uint64_t counter;
        double   gauge;
    } value;
    struct rrdc_stats_s *next;
};
typedef struct rrdc_stats_s rrdc_stats_t;
rrdc_stats_free(rrdc_stats_t *ret_stats)
Libera la estructura de estadísticas asignada mediante rrdc_stats_get.
