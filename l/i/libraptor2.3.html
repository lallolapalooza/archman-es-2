NOMBRE

libraptor2 - Biblioteca de sintaxis RDF Raptor 2.0

SINOPSIS

#include <raptor2.h>
world=raptor_new_world();
raptor_parser *p=raptor_new_parser(world,rdfxml);
raptor_set_statement_handler(p,NULL,print_triples);
raptor_uri *file_uri=raptor_new_uri(world,http://example.org/);
raptor_parser_parse_file(p,file_uri,base_uri);
raptor_parser_parse_uri(p,uri,NULL);
raptor_free_parser(p);
raptor_free_uri(file_uri);
raptor_free_world(world);
cc prog.c -o prog `pkg-config raptor2 --cflags` `pkg-config raptor2 --libs`

DESCRIPCIÓN

La biblioteca Raptor proporciona una interfaz de alto nivel a un conjunto de analizadores y serializadores que generan tripletas de Resource Description Framework (RDF) analizando sintaxis o serializando las tripletas en sintaxis.

Las sintaxis de análisis admitidas incluyen RDF/XML, N-Triples, Turtle, TRiG, RSS tag soup (incluyendo todos los RSS y Atom), GRDDL, RDF/JSON, RDFa y las sintaxis de serialización incluyen RDF/XML (3 variedades), N-Quads, N-Triples, Turtle, RSS 1.0, Atom 1.0, GraphViz DOT y RDF/JSON. El analizador RDF/XML puede utilizar analizadores XML expat o libxml para proporcionar el flujo de eventos SAX. Las funciones de la biblioteca están organizadas en un estilo orientado a objetos con constructores, destructores y llamadas a métodos. Las sentencias y los mensajes de error se entregan a través de funciones de devolución de llamada.

Raptor también contiene clases para admitir las tripletas de grafos RDF: un objeto de sentencia que contiene objetos de término y soporte para referencias URI de RDF tanto para analizarlas como para resolver/recuperar URIs.

Contiene algunas clases de utilidad como una abstracción de flujo de E/S para admitir la lectura y escritura desde y hacia una variedad de ubicaciones, árboles AVL, buffers de cadenas y secuencias.

Raptor utiliza cadenas Unicode para literales RDF y URIs y las conserva en toda la biblioteca. Utiliza la codificación UTF-8 de Unicode en la API para pasar o devolver cadenas Unicode. La intención es que la conservación de Unicode para las URIs admita los Identificadores de Recursos Internacionalizados (IRIs).
