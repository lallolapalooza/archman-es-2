Paquete: libtar

libtar_hash_new(3) Llamadas a la biblioteca C libtar_hash_new(3)

NOMBRE

libtar_hash_new, libtar_hash_free, libtar_hash_next, libtar_hash_prev, libtar_hash_getkey, libtar_hash_search, libtar_hash_add, libtar_hash_del - rutinas de tabla hash

SINOPSIS

#include <libtar.h>

libtar_hash_t *libtar_hash_new(int num, int (*hashfunc)());
void libtar_hash_free(libtar_hash_t *h, void (*freefunc)());
int libtar_hash_next(libtar_hash_t *h, libtar_hashptr_t *hp);
int libtar_hash_prev(libtar_hash_t *h, libtar_hashptr_t *hp);
int libtar_hash_search(libtar_hash_t *h, libtar_hashptr_t *hp, void *data, int (*matchfunc)());
int libtar_hash_getkey(libtar_hash_t *h, libtar_hashptr_t *hp, void *data, int (*matchfunc)());
int libtar_hash_add(libtar_hash_t *h, void *data);
int libtar_hash_del(libtar_hash_t *h, libtar_hashptr_t *hp);

DESCRIPCIÓN

La función libtar_hash_new() crea una nueva tabla hash con num cubetas y utilizando la función hash apuntada por hashfunc. Si hashfunc es NULL, se utiliza una función hash predeterminada diseñada para cadenas ASCII de 7 bits.

La función libtar_hash_free() desasigna toda la memoria asociada con la estructura hash h. Si freefunc no es NULL, se llama para liberar la memoria asociada con cada nodo en el hash.

Las funciones libtar_hash_next() y libtar_hash_prev() se utilizan para iterar a través de la tabla hash. La estructura libtar_hashptr_t tiene dos campos: bucket, que indica la cubeta actual en el hash, y node, que es un puntero al nodo actual en la cubeta actual. Para comenzar al principio o al final del hash, el llamante debe inicializar hp.bucket a -1 y hp.node a NULL.

La función libtar_hash_search() busca iterativamente a través del hash h hasta que encuentra un nodo cuyos contenidos coinciden con data utilizando la función de coincidencia matchfunc. La búsqueda comienza en la ubicación apuntada por hp.

La función libtar_hash_getkey() utiliza la función hash asociada con h para determinar en qué cubeta debe estar data, y busca solo en esa cubeta un nodo coincidente utilizando matchfunc. La búsqueda comienza en la ubicación apuntada por hp.

La función libtar_hash_add() agrega data a la tabla hash h.

La función libtar_hash_del() elimina el nodo al que se refiere hp.

VALOR DE RETORNO

La función libtar_hash_new() devuelve un puntero a la nueva estructura hash, o NULL en caso de error.

Las funciones libtar_hash_next() y libtar_hash_prev() devuelven 1 cuando se devuelven datos válidos y 0 al final de la tabla hash.

Las funciones libtar_hash_getkey() y libtar_hash_search() devuelven 1 cuando se encuentra una coincidencia, o 0 en caso contrario.

La función libtar_hash_add() devuelve 0 en caso de éxito, o -1 en caso de error (y establece errno).

La función libtar_hash_del() devuelve 0 en caso de éxito, o -1 en caso de error (y establece errno).
