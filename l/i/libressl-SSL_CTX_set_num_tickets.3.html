libressl-SSL_CTX_set_num_tickets(3)

Paquete: libressl

Licencias: ISC, custom:OpenSSL

SSL_CTX_SET_NUM_TICKETS(3) Manual de funciones de la biblioteca SSL_CTX_SET_NUM_TICKETS(3)

NOMBRE

SSL_CTX_set_num_tickets, SSL_CTX_get_num_tickets, SSL_set_num_tickets, SSL_get_num_tickets — establecer y obtener el número de tickets de sesión TLS 1.3 a enviar

SINOPSIS

biblioteca “libssl” libcrypto
#include <openssl/ssl.h>

int
SSL_CTX_set_num_tickets(SSL_CTX *ctx, size_t num_tickets);

size_t
SSL_CTX_get_num_tickets(const SSL_CTX *ctx);

int
SSL_set_num_tickets(SSL *ssl, size_t num_tickets);

size_t
SSL_get_num_tickets(const SSL *ssl);

DESCRIPCIÓN

Estas funciones establecen y recuperan el número configurado de tickets de sesión para ctx y ssl, respectivamente.

Se proporcionan solo para compatibilidad con OpenSSL y no tienen efecto en LibreSSL.

VALORES DE RETORNO

SSL_CTX_set_num_tickets() y SSL_set_num_tickets() siempre devuelven 1.

SSL_CTX_get_num_tickets() y SSL_get_num_tickets() devuelven el número de tickets establecido previamente, o 0 si no se ha establecido.

VER TAMBIÉN

ssl(3), SSL_CTX_new(3)

HISTORIAL

Estas funciones aparecieron por primera vez en OpenSSL 1.1.1 y han estado disponibles desde OpenBSD 7.1.
