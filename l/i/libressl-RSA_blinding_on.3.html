libressl-RSA_blinding_on(3)

Paquete: libressl

Licencias: ISC, custom:OpenSSL

RSA_BLINDING_ON(3) Manual de Funciones de Biblioteca RSA_BLINDING_ON(3)

NOMBRE

RSA_blinding_on, RSA_blinding_off — protege la operación RSA de ataques de temporización

SINOPSIS

biblioteca “libcrypto”
#include <openssl/rsa.h>

int
RSA_blinding_on(RSA *rsa, BN_CTX *ctx);

void
RSA_blinding_off(RSA *rsa);

DESCRIPCIÓN

RSA es vulnerable a ataques de temporización. En un entorno donde los atacantes pueden medir el tiempo de las operaciones de descifrado o firma RSA, se debe usar el "blinding" (cegamiento) para proteger la operación RSA de dicho ataque.

RSA_blinding_on() activa el cegamiento para la clave rsa y genera un factor de cegamiento aleatorio. ctx es NULL o un BN_CTX preasignado e inicializado.

RSA_blinding_off() desactiva el cegamiento y libera la memoria utilizada para el factor de cegamiento.

VALORES DE RETORNO

RSA_blinding_on() devuelve 1 en caso de éxito y 0 si ocurrió un error.

VER TAMBIÉN

RSA_new(3)

HISTORIA

RSA_blinding_on() y RSA_blinding_off() aparecieron por primera vez en SSLeay 0.9.0 y han estado disponibles desde OpenBSD 2.4.
