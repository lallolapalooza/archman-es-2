NOMBRE

libpipewire-module-zeroconf-discover - Descubrimiento Zeroconf

DESCRIPCIÓN

Utiliza zeroconf para detectar y cargar module-pulse-tunnel con los parámetros correctos.

Esto creará automáticamente sinks (salidas) y sources (entradas) para transmitir audio hacia/desde servidores PulseAudio remotos. También funciona con module-protocol-pulse.

NOMBRE DEL MÓDULO

libpipewire-module-zeroconf-discover

OPCIONES DEL MÓDULO

  • pulse.discover-local = permite el descubrimiento de servicios locales también. false por defecto.
  • pulse.latency: la latencia a la latencia de extremo a extremo en milisegundos a mantener (Valor por defecto 200 ms).

EJEMPLO DE CONFIGURACIÓN

# ~/.config/pipewire/pipewire.conf.d/my-zeroconf-discover.conf
context.modules = [
{   name = libpipewire-module-zeroconf-discover
    args = { }
}
]
