NOMBRE

libmemcached - Biblioteca cliente C/C++ para memcached

SINOPSIS

#include <libmemcached/memcached.h>
Compilar y enlazar con -lmemcached


----



libmemcached fue diseñada para proporcionar la mayor cantidad de opciones para usar Memcached. Algunas de las características proporcionadas:

1.
Soporte de transporte asíncrono y síncrono.
2.
Hashing y distribución consistentes.
3.
Algoritmo de hashing ajustable para hacer coincidir claves.
4.
Acceso al soporte de objetos grandes.
5.
Replicación local.
6.
Una guía de referencia completa y documentación de la API.
7.
Herramientas para gestionar tus redes de Memcached.

DESCRIPCIÓN

libmemcached es una pequeña biblioteca cliente segura para hilos para el protocolo memcached. Todo el código ha sido escrito para permitir su uso tanto en web como en sistemas embebidos. Maneja el trabajo detrás del enrutamiento de claves individuales a servidores específicos especificados por el desarrollador (y los valores se emparejan basándose en el orden de los servidores tal como los proporciona el usuario). Implementa un método modular y consistente de distribución de objetos.

Existen múltiples métodos de enrutamiento y hashing implementados. Consulta la página del manual de memcached_behavior_set() para más información.

Todas las operaciones se realizan contra una estructura memcached_st. Estas estructuras pueden ser asignadas dinámicamente o asignadas estáticamente y luego inicializadas por memcached_create(). Se han escrito funciones para encapsular la memcached_st. No se recomienda operar directamente sobre la estructura.

Casi todas las funciones devuelven un valor memcached_return_t. Este valor puede ser traducido a una cadena imprimible con memcached_strerror().

Los objetos se almacenan en servidores calculando el hash de las claves. El valor del hash mapea la clave a un servidor particular. Todos los clientes entienden cómo funciona este hashing, por lo que es posible enviar y recuperar datos de un servidor de forma fiable.

Opcionalmente, se pueden usar claves de grupo para agrupar conjuntos de objetos con servidores.

Se admiten espacios de nombres, y se pueden utilizar para particionar cachés de modo que múltiples aplicaciones puedan usar los mismos servidores memcached.

Algunas características de la biblioteca deben habilitarse a través de memcached_behavior_set().

HILOS Y PROCESOS

No se utilizan variables globales en esta biblioteca.

Las estructuras memcached_st son seguras para hilos, pero al usar hilos o procesos bifurcados es importante mantener una instancia de memcached_st por proceso o hilo. Sin crear tus propias estructuras de bloqueo, no puedes compartir una única memcached_st. Sin embargo, puedes llamar a memcached_quit() en una memcached_st y luego usar la estructura clonada resultante.

SYSTEMTAP

libmemcached puede compilarse para soportar Systemtap en Linux cuando se habilita en tiempo de compilación.
