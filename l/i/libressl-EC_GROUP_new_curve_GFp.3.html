DESCRIPCIÓN

Con la excepción de las funciones de obtención (getters), las funciones de este manual no deberían ser usadas. Utilice EC_GROUP_new_by_curve_name(3) en su lugar.

La biblioteca EC utiliza objetos EC_GROUP para representar curvas elípticas en forma de Weierstrass. Estas curvas se definen sobre el campo primo de orden p mediante la ecuación de Weierstrass

y^2 = x^3 + ax + b

donde a y b son tales que el discriminante 4a^3 - 27b^2 es distinto de cero. Consisten en puntos afines, que son pares de elementos del campo (x, y) que satisfacen la ecuación de Weierstrass, y un punto en el infinito adicional.

Los puntos en una curva elíptica forman un grupo. Las aplicaciones criptográficas suelen depender de la elección de un generador cuyos múltiplos forman un subgrupo cíclico de un cierto orden. Por el teorema de Lagrange, el número de puntos en la curva elíptica es el producto de orden y otro entero llamado cofactor. El teorema de Hasse es la desigualdad

|orden * cofactor - (p + 1)| <= 2 sqrt(p)

que implica un límite superior para orden en términos de p y permite el cálculo del cofactor siempre que orden sea lo suficientemente grande.

EC_GROUP_new_curve_GFp() instancia un nuevo objeto EC_GROUP sobre el campo primo de tamaño p con la ecuación de Weierstrass dada por los coeficientes a y b. El ctx opcional se utiliza para transformar los otros argumentos en la representación interna. Es responsabilidad del llamador asegurarse de que p sea un número primo mayor que tres y que el discriminante sea distinto de cero. Esto se puede hacer con EC_GROUP_check_discriminant(3) o como parte de EC_GROUP_check(3) después de EC_GROUP_set_generator().

EC_GROUP_set_curve() establece los parámetros de la curva de group a p, a, b utilizando el ctx opcional y se aplican los comentarios en EC_GROUP_new_curve_GFp(). El generador, orden o cofactor existentes en group se dejan sin modificar y probablemente se vuelvan inválidos. Por lo tanto, deben establecerse valores legítimos usando EC_GROUP_set_generator().

EC_GROUP_get_curve() copia los parámetros de la curva de group en p, a, y b propiedad del llamador, posiblemente utilizando el ctx para la conversión desde representaciones internas. Excepto por group, todos los argumentos son opcionales.

EC_GROUP_set_generator() realiza comprobaciones de validez basadas en el teorema de Hasse y copia generator, order y el cofactor opcional en group, reemplazando todas las entradas existentes. Es responsabilidad del llamador asegurarse de que generator sea un punto en la curva y que order sea su orden, lo cual se puede lograr parcialmente con una llamada posterior a EC_GROUP_check(3). Si cofactor es NULL, puede ser calculado en curvas de interés criptográfico, en cuyo caso cofactor se establece en el valor calculado, de lo contrario se establece en cero.

EC_GROUP_get0_generator() devuelve un puntero interno al generador de group, que puede ser NULL si no se ha establecido ningún generador.

EC_GROUP_get_degree() devuelve la longitud en bits del primo p establecido en group.

EC_GROUP_get_order() copia el valor del libressl EC_GROUP_new_curve_GFp(3) - Arch Linux

DESCRIPTION

EC_GROUP_new_curve_GFp() allocates and returns a new EC_GROUP object representing an elliptic curve defined over a prime field GF(p). The curve is defined by the equation y^2 = x^3 + ax + b (mod p).

EC_GROUP_set_curve_GFp() sets the curve parameters p, a, and b for the group group. p must be a prime number. ctx is a big number context used for internal calculations.

EC_GROUP_get_curve_GFp() retrieves the curve parameters p, a, and b from the group group. The caller must allocate the BIGNUMs pointed to by p, a, and b. If ctx is not NULL, it is used for internal calculations. Otherwise, a new context is allocated internally.

EC_GROUP_set_generator() sets the generator point, order, and cofactor for the group group. The generator must be a point on the curve defined by group. The order and cofactor are positive integers. The ctx argument is used for internal calculations.

EC_GROUP_get0_generator() returns an internal pointer to the generator of the group group. The returned pointer must not be freed by the caller. If no generator has been set, it returns NULL.

EC_GROUP_get_order() copies the value of the group's order into the caller-owned order, returning failure if the group's order is zero. The ctx argument is ignored.

EC_GROUP_order_bits() returns the number of bits in the group's order, which is the result of calling BN_num_bits(3) on order. Unlike EC_GROUP_get_order(), it does not fail if order is zero.

EC_GROUP_get_cofactor() copies the value of the group's cofactor into the caller-owned cofactor, returning failure if the group's cofactor is zero. The ctx argument is ignored.

The deprecated EC_GROUP_clear_free() uses explicit_bzero(3) and freezero(3) to clear and free all data associated with group. If group is NULL, no action occurs. Since there is no secret data in group, this API is useless. In LibreSSL, EC_GROUP_free(3) and EC_GROUP_clear_free() behave identically.

EC_GROUP_set_curve_GFp() and EC_GROUP_get_curve_GFp() are deprecated aliases for EC_GROUP_set_curve() and EC_GROUP_get_curve(), respectively.

RETURN VALUES

EC_GROUP_new_curve_GFp() returns a newly allocated group or NULL if memory allocation fails, or if some minimal sanity checks on p, a, and b fail.

EC_GROUP_set_curve() and EC_GROUP_set_curve_GFp() return 1 on success and 0 on failure. Failure conditions include that p is smaller than or equal to three, or even, or memory allocation failure.

EC_GROUP_get_curve() and EC_GROUP_get_curve_GFp() return 1 on success and 0 on memory allocation failure.

EC_GROUP_set_generator() returns 1 on success and 0 on memory allocation failure, or if order or cofactor are larger than Hasse's theorem allows.

EC_GROUP_get0_generator() returns an internal pointer to the generator or NULL if none was set on group.

EC_GROUP_get_order() returns 1 on success or 0 on memory allocation failure or if the order is zero.

EC_GROUP_get_cofactor() returns 1 on success or 0 on memory allocation failure or if the cofactor is zero.

EC_GROUP_get_degree(), and EC_GROUP_order_bits() return the number of bits in the group's p, and order, respectively.

BUGS

Too many. The API is unergonomic and the design is very poor even by OpenSSL's standards. Naming is inconsistent, especially in regard to the _GFp suffix and the _get_ infix. Function signatures are inconsistent. In particular, functions that should have a BN_CTX argument don't have one and functions that don't need it have one.
