libressl-SSL_CTX_set_session_id_context(3)

Paquete: libressl

Licencias: ISC, custom:OpenSSL

SSL_CTX_SET_SESSION_ID_CONTEXT(3) Manual de funciones de biblioteca SSL_CTX_SET_SESSION_ID_CONTEXT(3)

NOMBRE

SSL_CTX_set_session_id_context, SSL_set_session_id_context — establece el contexto dentro del cual la sesión puede ser reutilizada (solo lado del servidor)

SINOPSIS

biblioteca “libssl” libcrypto
#include <openssl/ssl.h>

int
SSL_CTX_set_session_id_context(SSL_CTX *ctx, const unsigned char *sid_ctx, unsigned int sid_ctx_len);

int
SSL_set_session_id_context(SSL *ssl, const unsigned char *sid_ctx, unsigned int sid_ctx_len);

DESCRIPCIÓN

SSL_CTX_set_session_id_context() establece el contexto sid_ctx de longitud sid_ctx_len dentro del cual una sesión puede ser reutilizada para el objeto ctx.

SSL_set_session_id_context() establece el contexto sid_ctx de longitud sid_ctx_len dentro del cual una sesión puede ser reutilizada para el objeto ssl.

Las sesiones se generan dentro de un contexto determinado. Al exportar/importar sesiones con i2d_SSL_SESSION(3) y d2i_SSL_SESSION(3), sería posible reimportar una sesión generada desde otro contexto (por ejemplo, otra aplicación), lo que podría provocar un mal funcionamiento. Por lo tanto, cada aplicación debe establecer su propio contexto de ID de sesión sid_ctx que se utiliza para distinguir los contextos y se almacena en las sesiones exportadas. El sid_ctx puede ser cualquier tipo de dato binario con una longitud dada; por lo tanto, es posible utilizar, por ejemplo, el nombre de la aplicación, el nombre del host, el nombre del servicio...

El contexto del ID de sesión se convierte en parte de la sesión. El contexto del ID de sesión lo establece el servidor SSL/TLS. Las funciones SSL_CTX_set_session_id_context() y SSL_set_session_id_context() son, por lo tanto, útiles solo en el lado del servidor.

Los clientes de OpenSSL comprobarán el contexto del ID de sesión devuelto por el servidor al reutilizar una sesión.

La longitud máxima del sid_ctx está limitada a SSL_MAX_SSL_SESSION_ID_LENGTH.

ADVERTENCIAS

Si el contexto del ID de sesión no se establece en un servidor SSL/TLS y se utilizan certificados de cliente, las sesiones almacenadas no se reutilizarán, sino que se marcará un error fatal y la negociación fallará.

Si un servidor devuelve un contexto de ID de sesión diferente a un cliente OpenSSL al reutilizar una sesión, se marcará un error y la negociación fallará. Los servidores OpenSSL siempre devolverán el contexto de ID de sesión correcto, ya que un servidor OpenSSL comprueba el contexto de ID de sesión él mismo antes de reutilizar una sesión como se describe anteriormente.

VALORES DE RETORNO

SSL_CTX_set_session_id_context() y SSL_set_session_id_context() devuelven los siguientes valores:

0
La longitud sid_ctx_len del contexto del ID de sesión sid_ctx superó la longitud máxima permitida de SSL_MAX_SSL_SESSION_ID_LENGTH. El error se registra en la pila de errores.
1
La operación se realizó con éxito.

VER TAMBIÉN

ssl(3), SSL_SESSION_set1_id_context(3)

HISTORIAL

SSL_set_session_id_context() apareció por primera vez en OpenSSL 0.9.2b. SSL_CTX_set_session_id_context() apareció por primera vez en OpenSSL 0.9.3. Ambas funciones han estado disponibles desde OpenBSD 2.6.
