NOMBRE

libnbd-release-notes-1.6 - notas de lanzamiento para libnbd 1.6

DESCRIPCIÓN

Estas son las notas de lanzamiento para la versión estable de libnbd 1.6. Describen los principales cambios desde la 1.4.

libnbd 1.6.0 fue lanzado el 7 de enero de 2021.

Seguridad

No se encontraron problemas de seguridad en este lanzamiento.

Si encuentra un problema de seguridad, por favor lea SECURITY en el código fuente (en línea aquí: https://gitlab.com/nbdkit/libnbd/blob/master/SECURITY). Para informarse sobre problemas de seguridad anteriores en libnbd, consulte libnbd-security(3).

Nuevas APIs

nbd_set_strict_mode(3)
nbd_get_strict_mode(3)
Esta API le permite controlar cómo libnbd maneja las solicitudes del programa que considera que desencadenarían un comportamiento indefinido en el servidor (como enviar comandos desconocidos, solicitudes de tamaño cero o fuera de rango, etc.). Normalmente, libnbd es muy estricto y le impedirá enviar dichas solicitudes, pero puede usar esta API para relajar estas restricciones, dejando que el servidor las maneje o las rechace. Algunos servidores pueden fallar si hace esto.
nbd_get_nr_meta_contexts(3)
nbd_get_meta_context(3)
nbd_clear_meta_contexts(3)
Estas APIs permiten revisar o borrar los contextos de metadatos solicitados.
nbd_opt_list_meta_context(3)
nbd_aio_opt_list_meta_context(3)
Solicita que el servidor liste los contextos de metadatos disponibles. Solo puede usar esto en modo opt.

Agradecimientos: Eric Blake por todas las nuevas APIs.

Mejoras en APIs existentes

nbd_shutdown(3) nueva bandera "LIBNBD_SHUTDOWN_ABANDON_PENDING" descarta cualquier comando en curso que aún no se haya enviado al servidor (Eric Blake).

Todas las APIs que tienen parámetros de bandera (máscara de bits) ahora definen una constante "LIBNBD_*_MASK" que le permite saber qué bits representan banderas válidas en tiempo de compilación (Eric Blake).

Nuevas características

El rendimiento de la herramienta nbdcopy(1) ha mejorado enormemente. Además, soporta numerosas características nuevas.

Nueva opción --map de nbdinfo(1) que muestra las extensiones asignadas y dispersas de un servidor NBD. Esto también puede mostrar otra información, como mapas de bits sucios.

Herramientas

nbdfuse(1) ahora puede montar la exportación NBD sobre cualquier archivo regular, no tiene que montar sobre un directorio.

nbdsh(1) ahora produce un mensaje de error agradable si la URI en la opción -u o el comando en la opción -c son incorrectos (Eric Blake).

Nueva opción --opt-mode de nbdsh(1) que solicita el modo opt en el manejador antes de conectarse.

La opción --list de nbdinfo(1) ahora muestra los contextos de metadatos compatibles del servidor (Eric Blake).

La salida de nbdinfo(1) ahora se imprime de forma atómica, es decir, imprimirá la salida completa o un mensaje de error, pero no una salida parcial seguida de un error.

nbdinfo(1) ahora puede decodificar el metacontexto "qemu:allocation-depth" (Eric Blake).

Otras mejoras y correcciones de errores

Múltiples mejoras en el manejo del protocolo NBD (Eric Blake).

Corrección del manejo de booleanos en los enlaces de Python (Eric Blake).

Corrección del manejo de parámetros de banderas en los enlaces de OCaml (Eric Blake).

Correcciones de estilo de Python (Eric Blake).

Corrección de múltiples fugas de memoria (Eric Blake).

Los enlaces de OCaml ahora incluyen documentación generada por ocamldoc, si ocamldoc está instalado en tiempo de compilación.

La biblioteca "vector" de nbdkit ahora es utilizada por libnbd, simplificando lugares donde antes se usaba realloc(3).
