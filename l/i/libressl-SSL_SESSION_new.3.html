SSL_SESSION_NEW(3) Manual de funciones de biblioteca SSL_SESSION_NEW(3)

NOMBRE

SSL_SESSION_new — construye un nuevo objeto SSL_SESSION

SINOPSIS

biblioteca “libssl” libcrypto
#include <openssl/ssl.h>

SSL_SESSION *
SSL_SESSION_new(void);

DESCRIPCIÓN

SSL_SESSION_new() asigna e inicializa un nuevo objeto SSL_SESSION. El contador de referencias se establece en 1, la hora actual, y el tiempo de espera en cinco minutos.

Cuando el objeto ya no sea necesario, se puede destruir con SSL_SESSION_free(3).

SSL_SESSION_new() se utiliza internamente, por ejemplo, por SSL_connect(3).

VALORES DE RETORNO

SSL_SESSION_new() devuelve el nuevo objeto SSL_SESSION o NULL si hay memoria insuficiente disponible.

Después de un fallo, ERR_get_error(3) devuelve ERR_R_MALLOC_FAILURE.
