OCSP_CERT_TO_ID(3) Manual de Funciones de Biblioteca OCSP_CERT_TO_ID(3)

NOMBRE

OCSP_CERTID_new, OCSP_CERTID_free, OCSP_cert_to_id, OCSP_cert_id_new, OCSP_id_issuer_cmp, OCSP_id_cmp, OCSP_id_get0_info — Funciones de utilidad de ID de certificado OCSP

SINOPSIS

biblioteca “libcrypto”
#include <openssl/ocsp.h>

OCSP_CERTID *
OCSP_CERTID_new(void);

void
OCSP_CERTID_free(OCSP_CERTID *id);

OCSP_CERTID *
OCSP_cert_to_id(const EVP_MD *dgst, const X509 *subject, const X509 *issuer);

OCSP_CERTID *
OCSP_cert_id_new(const EVP_MD *dgst, const X509_NAME *issuerName, const ASN1_BIT_STRING *issuerKey, const ASN1_INTEGER *serialNumber);

int
OCSP_id_issuer_cmp(OCSP_CERTID *a, OCSP_CERTID *b);

int
OCSP_id_cmp(OCSP_CERTID *a, OCSP_CERTID *b);

int
OCSP_id_get0_info(ASN1_OCTET_STRING **piNameHash, ASN1_OBJECT **pmd, ASN1_OCTET_STRING **pikeyHash, ASN1_INTEGER **pserial, OCSP_CERTID *cid);

DESCRIPCIÓN

OCSP_CERTID_new() asigna e inicializa un objeto OCSP_CERTID vacío, que representa una estructura CertID ASN.1 definida en RFC 6960. Puede almacenar hashes del nombre distinguido y la clave pública de un emisor junto con el número de serie de un certificado. Es utilizado por el objeto OCSP_ONEREQ descrito en OCSP_ONEREQ_new(3) y por el objeto OCSP_SINGLERESP descrito en OCSP_SINGLERESP_new(3). OCSP_CERTID_free() libera id.

OCSP_cert_to_id() crea y devuelve un nuevo objeto OCSP_CERTID utilizando el digest de mensaje dgst para el certificado subject con el emisor issuer. Si dgst es NULL, se utiliza SHA-1.

OCSP_cert_id_new() crea y devuelve un nuevo OCSP_CERTID utilizando dgst y el nombre del emisor issuerName, el hash de la clave del emisor issuerKey y el número de serie serialNumber.

OCSP_id_issuer_cmp() compara los algoritmos de hash, los nombres distinguido del emisor hasheados y las claves públicas hasheadas de los OCSP_CERTID a y b.

OCSP_id_cmp() compara los OCSP_CERTID a y b utilizando OCSP_id_issuer_cmp() seguido de una comparación de los números de serie de los certificados con ASN1_INTEGER_cmp(3).

OCSP_id_get0_info() devuelve el hash del nombre del emisor, el OID del hash, el hash de la clave del emisor y el número de serie contenidos en cid. Si alguno de los valores no es necesario, el parámetro correspondiente puede establecerse a NULL. Los valores devueltos por OCSP_id_get0_info() son punteros internos y no deben ser liberados por una aplicación: serán liberados cuando el objeto OCSP_CERTID correspondiente sea liberado.

Los clientes OCSP típicamente solo usarán OCSP_cert_to_id() o OCSP_cert_id_new(): las otras funciones son utilizadas por las aplicaciones del respondedor.

VALORES DE RETORNO

OCSP_CERTID_new(), OCSP_cert_to_id(), y OCSP_cert_id_new() devuelven ya sea un puntero a un objeto OCSP_CERTID válido o NULL si ocurrió un error.

OCSP_id_cmp() y OCSP_id_issuer_cmp() devuelven 0 para una coincidencia o un valor distinto de cero en caso contrario.

OCSP_id_get0_info() devuelve 1 para éxito o 0 para fallo.
