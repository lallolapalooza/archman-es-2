EXTENDED_KEY_USAGE_NEW(3) Manual de funciones de biblioteca EXTENDED_KEY_USAGE_NEW(3)

NOMBRE

EXTENDED_KEY_USAGE_new, EXTENDED_KEY_USAGE_free — Restricciones de uso de claves X.509

SINOPSIS

biblioteca “libcrypto”
#include <openssl/x509v3.h>

EXTENDED_KEY_USAGE
EXTENDED_KEY_USAGE_new(void);

void
EXTENDED_KEY_USAGE_free(EXTENDED_KEY_USAGE *eku);

DESCRIPCIÓN

Al utilizar la extensión de uso de claves, la extensión de uso de claves extendido o ambas, los certificados de entidad final X509 pueden indicar que la clave contenida en ellos solo está destinada a ser utilizada para los fines especificados. Si ambas extensiones están presentes, solo se pretenden los usos compatibles con ambas extensiones.

EXTENDED_KEY_USAGE_new() asigna e inicializa un objeto EXTENDED_KEY_USAGE vacío, que es un STACK_OF(ASN1_OBJECT) y representa una estructura ExtKeyUsageSyntax ASN.1 definida en RFC 5280 sección 4.2.1.12. Puede contener identificadores de propósito de clave.

EXTENDED_KEY_USAGE_free() libera eku.

La extensión de uso de claves utiliza el tipo de datos ASN.1 BIT STRING y no requiere ningún objeto dedicado.

VALORES DE RETORNO

EXTENDED_KEY_USAGE_new() devuelve el nuevo objeto EXTENDED_KEY_USAGE o NULL si ocurre un error.

VER TAMBIÉN

ESTÁNDARES

  • sección 4.2.1.12: Uso de claves extendido
