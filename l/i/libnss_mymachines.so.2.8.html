NOMBRE

nss-mymachines, libnss_mymachines.so.2 - Resolución de nombres de host para instancias de contenedor locales

SINOPSIS

libnss_mymachines.so.2

DESCRIPCIÓN

nss-mymachines es un módulo plug-in para la funcionalidad del conmutador de servicios de nombres GNU (NSS) de la biblioteca C GNU (glibc), que proporciona resolución de nombres de host para los nombres de los contenedores que se ejecutan localmente y que están registrados con systemd-machined.service(8). Los nombres de los contenedores se resuelven a las direcciones IP del contenedor específico, ordenados por su alcance. Esta funcionalidad solo se aplica a los contenedores que utilizan espacios de nombres de red (consulte la descripción de --private-network en systemd-nspawn(1)). Tenga en cuenta que el nombre que se resuelve es el registrado con systemd-machined, que puede ser diferente del nombre de host configurado dentro del contenedor.

Tenga en cuenta que este módulo NSS solo pone a disposición los nombres de los contenedores que se ejecutan inmediatamente debajo del contexto del sistema actual. No proporciona resolución de nombres de host para contenedores que se ejecutan junto al contexto del sistema invocador, o para contenedores más arriba o más abajo en la jerarquía de contenedores. Es decir, en el sistema anfitrión, proporciona resolución de nombres de host para los contenedores que se ejecutan inmediatamente debajo del entorno del sistema anfitrión. Sin embargo, cuando se utiliza dentro de un entorno de contenedor, no podrá proporcionar resolución de nombres para los contenedores que se ejecutan en el anfitrión (ya que estos son hermanos y no hijos del entorno de contenedor actual), sino solo para los contenedores anidados que se ejecutan inmediatamente debajo de su propio entorno de contenedor.

Para activar el módulo NSS, agregue "mymachines" a la línea que comienza con "hosts:" en /etc/nsswitch.conf.

Se recomienda colocar "mymachines" antes de la entrada "resolve" o "dns" de la línea "hosts:" de /etc/nsswitch.conf para asegurarse de que sus asignaciones tengan preferencia sobre otros resolvedores como DNS.

CONFIGURACIÓN EN /ETC/NSSWITCH.CONF

Aquí hay un ejemplo de archivo /etc/nsswitch.conf que habilita correctamente nss-mymachines:

passwd:         files systemd
group:          files [SUCCESS=merge] systemd
shadow:         files systemd
gshadow:        files systemd
hosts:          mymachines resolve [!UNAVAIL=return] files myhostname dns
networks:       files
protocols:      db files
services:       db files
ethers:         db files
rpc:            db files
netgroup:       nis
