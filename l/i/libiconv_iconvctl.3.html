libiconv_iconvctl(3)

Paquete: libiconv

Licencias: LGPL-2.1-only, GPL-3.0-only

ICONVCTL(3) Manual de funciones de biblioteca ICONVCTL(3)

NOMBRE

iconvctl - controla el comportamiento de iconv

SINOPSIS

#include <iconv.h>

int iconvctl (iconv_t cd , int request, void * argument);

DESCRIPCIÓN

El argumento cd debe ser un descriptor de conversión creado usando la función iconv_open.

iconvctl consulta o ajusta el comportamiento de la función iconv, cuando se invoca con el descriptor de conversión especificado, dependiendo del valor de la solicitud.

VALORES DE SOLICITUD

Los siguientes son valores permitidos para el parámetro request.

ICONV_TRIVIALP
argument debe ser un int * que recibirá 1 si la conversión es trivial, o 0 en caso contrario.
ICONV_GET_TRANSLITERATE
argument debe ser un int * que recibirá 1 si la transliteración está habilitada en la conversión, o 0 en caso contrario.
ICONV_SET_TRANSLITERATE
argument debe ser un const int *, apuntando a un valor int. Se utiliza un valor distinto de cero para habilitar la transliteración en la conversión. Un valor cero la deshabilita.
ICONV_GET_DISCARD_INVALID
argument debe ser un int * que recibirá 1 si la opción "descartar secuencias multibyte inválidas de la entrada y continuar" está habilitada en la conversión, o 0 en caso contrario.
ICONV_SET_DISCARD_INVALID
argument debe ser un const int *, apuntando a un valor int. Se utiliza un valor distinto de cero para habilitar la opción "descartar secuencias multibyte inválidas de la entrada y continuar" en la conversión. Un valor cero la deshabilita.
ICONV_GET_DISCARD_NON_IDENTICAL
argument debe ser un int * que recibirá 1 si la opción "descartar caracteres que no se pueden representar en el conjunto de caracteres de destino y continuar" está habilitada en la conversión, o 0 en caso contrario.
ICONV_SET_DISCARD_NON_IDENTICAL
argument debe ser un const int *, apuntando a un valor int. Se utiliza un valor distinto de cero para habilitar la opción "descartar caracteres que no se pueden representar en el conjunto de caracteres de destino y continuar" en la conversión. Un valor cero la deshabilita.
ICONV_GET_DISCARD_ILSEQ
argument debe ser un int * que recibirá 1 si ambas opciones de "descartar" están habilitadas en la conversión, o 0 en caso contrario.
ICONV_SET_DISCARD_ILSEQ
argument debe ser un const int *, apuntando a un valor int. Se utiliza un valor distinto de cero para habilitar ambas opciones de "descartar" en la conversión. Un valor cero las deshabilita.
ICONV_GET_FROM_SURFACE
argument debe ser un unsigned int * que recibirá la superficie del lado de origen (lado de entrada) de la conversión.
ICONV_SET_FROM_SURFACE
argument debe ser un const unsigned int *, apuntando a un valor unsigned int. Este valor se instala como la superficie del lado de origen (lado de entrada) de la conversión. El valor es una máscara de bits. Cero denota ninguna superficie. El valor ICONV_SURFACE_EBCDIC_ZOS_UNIX tiene un efecto en las codificaciones EBCDIC: el salto de línea EBCDIC 0x15 se mapeará a LF en lugar de NEL.
ICONV_GET_TO_SURFACE
argument debe ser un unsigned int * que recibirá la superficie del lado de destino (lado de salida) de la conversión.
ICONV_SET_TO_SURFACE
argument debe ser un const unsigned int *, apuntando a un valor unsigned int. Este valor se instala como la superficie del lado de destino (lado de salida) de la conversión. El valor es una máscara de bits. Cero denota ninguna superficie. El valor ICONV_SURFACE_EBCDIC_ZOS_UNIX tiene un efecto en las codificaciones EBCDIC: LF, en lugar de NEL, se mapeará al salto de línea EBCDIC 0x15.

VALOR DE RETORNO

La función iconvctl devuelve 0 si tiene éxito. En caso de error, establece errno y devuelve -1.

ERRORES

Los siguientes errores pueden ocurrir, entre otros:

EINVAL
La solicitud no es válida.

CONFORME A

Esta función solo está implementada en GNU libiconv y no en otras implementaciones de iconv. No está respaldada por un estándar. Puedes probar su presencia a través de (_LIBICONV_VERSION >= 0x0108).
