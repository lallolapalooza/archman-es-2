NOMBRE

libpipewire-module-protocol-simple - Protocolo Simple

DESCRIPCIÓN

El protocolo simple proporciona un flujo de audio bidireccional en un socket de red.

Está destinado a ser utilizado con la aplicación reproductor del protocolo simple, disponible en Android para reproducir y grabar un flujo.

Cada cliente que se conecta creará un flujo de captura y/o reproducción, dependiendo de las opciones de configuración.

También se puede utilizar para alimentar datos de audio a otros clientes, como el servidor snapcast.

NOMBRE DEL MÓDULO

libpipewire-module-protocol-simple

OPCIONES DEL MÓDULO

  • capture: booleano si la captura está habilitada. Esto creará un flujo de captura o un sumidero para cada cliente conectado.
  • playback: booleano si la reproducción está habilitada. Esto creará un flujo de reproducción o una fuente para cada cliente conectado.
  • local.ifname = <str>: nombre de la interfaz a usar
  • local.ifaddress = <str>: dirección de la interfaz a usar
  • server.address = []: un array de direcciones de servidor en las que escuchar como tcp:(<ip>)<puerto>.
  • capture.props: propiedades opcionales para el flujo de captura
  • playback.props: propiedades opcionales para el flujo de reproducción

OPCIONES GENERALES

Opciones con comportamiento conocido.

  • remote.name
  • audio.rate
  • audio.format
  • audio.channels
  • audio.position
  • node.latency
  • node.rate
  • stream.capture.sink
  • node.name
  • target.object

Por defecto, el servidor trabajará con muestras estéreo de 16 bits a 44.1KHz.

EJEMPLO DE CONFIGURACIÓN

# ~/.config/pipewire/pipewire.conf.d/my-protocol-simple.conf
context.modules = [
{   name = libpipewire-module-protocol-simple
    args = {
        # Proporcionar flujo de captura, los clientes pueden capturar datos de PipeWire
        capture = true
        #
        # Proporcionar flujo de reproducción, el cliente puede enviar datos a PipeWire para la reproducción
        playback = true
        #
        #audio.rate = 44100
        #audio.format = S16
        #audio.channels = 2
        #audio.position = [ FL FR ]
        #
        # Las direcciones en las que este servidor escucha las nuevas
        # conexiones de clientes
        server.address = [
            "tcp:4711"
        ]
        capture.props = {
            # El nombre o id del nodo a usar para la captura.
            #target.object = null
            #
            # Para hacer que el flujo de captura capture los puertos del monitor
            #stream.capture.sink = false
            #
            # Hacer de esto un sumidero en lugar de un flujo de captura
            #media.class = Audio/Sink
        }
        playback.props = {
            # El nombre o id del nodo a usar para la reproducción.
            #target.object = null
            #
            # Hacer de esto una fuente en lugar de un flujo de reproducción
            #media.class = Audio/Source
        }
    }
}
]

EJEMPLO DE CONFIGURACIÓN PARA UN SERVIDOR SNAPCAST

 context.modules = [
 {   name = libpipewire-module-protocol-simple
     args = {
         # Proporcionar sumidero
         capture = true
         audio.rate = 48000
         audio.format = S16
         audio.channels = 2
         audio.position = [ FL FR ]
         # Las direcciones en las que este servidor escucha las nuevas
         # conexiones de clientes
         server.address = [
             "tcp:4711"
         ]
         capture.props = {
             # Hacer de esto un sumidero en lugar de un flujo de captura
             media.class = Audio/Sink
         }
     }
 }
 ]
 En el servidor snapcast, agregue lo siguiente al archivo `snapserver.conf`:
\code{.unparsed}
 [stream]
 sampleformat =  48000:16:2
 source = tcp://127.0.0.1:4711?name=PipeWireSnapcast&mode=client

Snapcast intentará conectarse al servidor protocol-simple y obtener las muestras de él. Snapcast intenta reconectarse cuando la conexión se rompe de alguna manera.
