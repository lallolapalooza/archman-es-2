libressl-SSL_CTX_set_timeout(3)

Paquete: libressl

Licencias: ISC, custom:OpenSSL

SSL_CTX_SET_TIMEOUT(3) Manual de funciones de la biblioteca SSL_CTX_SET_TIMEOUT(3)

NOMBRE

SSL_CTX_set_timeout, SSL_CTX_get_timeout — manipular valores de tiempo de espera para el almacenamiento en caché de sesiones

SINÓPSIS

biblioteca “libssl” libcrypto
#include <openssl/ssl.h>

long
SSL_CTX_set_timeout(SSL_CTX *ctx, long t);

long
SSL_CTX_get_timeout(SSL_CTX *ctx);

DESCRIPCIÓN

SSL_CTX_set_timeout() establece el tiempo de espera para las sesiones recién creadas para ctx a t. El valor de tiempo de espera t debe darse en segundos.

SSL_CTX_get_timeout() devuelve el valor de tiempo de espera actualmente establecido para ctx.

Cada vez que se crea una nueva sesión, se le asigna una vida útil máxima. Esta vida útil se especifica almacenando la hora de creación de la sesión y el valor de tiempo de espera válido en ese momento. Si la hora actual es posterior a la hora de creación más el tiempo de espera, la sesión no se reutiliza.

Debido a esta implementación, todas las sesiones se comportan de acuerdo con el valor de tiempo de espera válido en el momento de la negociación de la sesión. Los cambios en el valor de tiempo de espera no afectan a las sesiones ya establecidas.

La hora de expiración de una sesión individual se puede modificar utilizando la familia de funciones SSL_SESSION_get_time(3).

Las sesiones expiradas se eliminan de la caché de sesiones interna, cada vez que SSL_CTX_flush_sessions(3) se llama, ya sea directamente por la aplicación o automáticamente (ver SSL_CTX_set_session_cache_mode(3)).

El valor predeterminado para el tiempo de espera de la sesión se decide por protocolo; ver SSL_get_default_timeout(3). Todos los protocolos actualmente compatibles tienen el mismo valor de tiempo de espera predeterminado de 300 segundos.

VALORES DE RETORNO

SSL_CTX_set_timeout() devuelve el valor de tiempo de espera establecido previamente.

SSL_CTX_get_timeout() devuelve el valor de tiempo de espera establecido actualmente.

VER TAMBIÉN

ssl(3), SSL_CTX_flush_sessions(3), SSL_CTX_set_session_cache_mode(3), SSL_get_default_timeout(3), SSL_SESSION_get_time(3)

HISTORIAL

SSL_CTX_set_timeout() y SSL_CTX_get_timeout() aparecieron por primera vez en SSLeay 0.6.1 y han estado disponibles desde OpenBSD 2.4.
