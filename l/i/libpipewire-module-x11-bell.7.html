NOMBRE

libpipewire-module-x11-bell - Campana X11

DESCRIPCIÓN

El módulo x11-bell intercepta los eventos de campana de X11 y utiliza libcanberra para reproducir un sonido.

NOMBRE DEL MÓDULO

libpipewire-module-x11-bell

OPCIONES DEL MÓDULO

  • sink.name = <str>: nombre del nodo del sink al que conectarse
  • sample.name = <str>: el nombre de la muestra a reproducir, por defecto 'bell-window-system'
  • x11.display = <str>: la pantalla X11 a usar
  • x11.xauthority = <str>: la cadena XAuthority de X11 colocada en el entorno XAUTHORITY

OPCIONES GENERALES

No hay opciones generales para este módulo.

EJEMPLO DE CONFIGURACIÓN

context.modules = [
 {   name = libpipewire-module-x11-bell }
     args = {
         #sink.name = @DEFAULT_SINK@
         sample.name = "bell-window-system"
         #x11.display = ":1"
         #x11.xauthority = "test"
]
