libressl-d2i_CMS_ContentInfo(3)

Paquete: libressl

Licencias: ISC, custom:OpenSSL

D2I_CMS_CONTENTINFO(3) Manual de Funciones de Biblioteca D2I_CMS_CONTENTINFO(3)

NOMBRE

d2i_CMS_ContentInfo, i2d_CMS_ContentInfo, d2i_CMS_bio, i2d_CMS_bio, d2i_CMS_ReceiptRequest, i2d_CMS_ReceiptRequest — decodifica y codifica datos de sintaxis de mensajes criptográficos (CMS)

SINOPSIS

biblioteca “libcrypto”
#include <openssl/cms.h>

CMS_ContentInfo *
d2i_CMS_ContentInfo(CMS_ContentInfo **val_out, const unsigned char **der_in, long length);

int
i2d_CMS_ContentInfo(CMS_ContentInfo *val_in, unsigned char **out);

CMS_ContentInfo *
d2i_CMS_bio(BIO *in_bio, CMS_ContentInfo **val_out);

int
i2d_CMS_bio(BIO *out_bio, CMS_ContentInfo *val_in);

CMS_ReceiptRequest *
d2i_CMS_ReceiptRequest(CMS_ReceiptRequest **val_out, const unsigned char **der_in, long length);

int
i2d_CMS_ReceiptRequest(CMS_ReceiptRequest *val_in, unsigned char **out);

DESCRIPCIÓN

Estas funciones decodifican y codifican estructuras de datos de sintaxis de mensajes criptográficos (Cryptographic Message Syntax). Para obtener detalles sobre la semántica, ejemplos, advertencias y errores, consulte ASN1_item_d2i(3).

d2i_CMS_ContentInfo() y i2d_CMS_ContentInfo() decodifican y codifican una estructura CMS_ContentInfo definida en la RFC 5652, sección 3. d2i_CMS_bio() y i2d_CMS_bio() son similares excepto que decodifican o codifican usando un puntero BIO.

d2i_CMS_ReceiptRequest() y i2d_CMS_ReceiptRequest() decodifican y codifican una estructura CMS_ReceiptRequest definida en la RFC 2634, sección 2.7.

VALORES DE RETORNO

d2i_CMS_ContentInfo() y d2i_CMS_bio() devuelven una estructura CMS_ContentInfo válida o NULL si ocurre un error.

d2i_CMS_ReceiptRequest() devuelve una estructura CMS_ReceiptRequest válida o NULL si ocurre un error.

i2d_CMS_ContentInfo() y i2d_CMS_ReceiptRequest() devuelven el número de bytes codificados con éxito o un valor negativo si ocurre un error.

i2d_CMS_bio() devuelve 1 para éxito o 0 si ocurre un error.

Para todas las funciones, el código de error se puede obtener llamando a ERR_get_error(3).

VER TAMBIÉN

ASN1_item_d2i(3), CMS_ContentInfo_new(3), CMS_get0_type(3), CMS_ReceiptRequest_create0(3), i2d_CMS_bio_stream(3)

ESTÁNDARES

RFC 5652: Cryptographic Message Syntax, sección 3: Sintaxis General

RFC 2634: Enhanced Security Services for S/MIME, sección 2.7: Sintaxis de solicitud de recibo
