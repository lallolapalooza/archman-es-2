libressl-SSL_set_bio(3)

Paquete: libressl

Licencias: ISC, custom:OpenSSL

SSL_SET_BIO(3) Manual de funciones de biblioteca SSL_SET_BIO(3)

NOMBRE

SSL_set_bio — conecta el objeto SSL con un BIO

SINOPSIS

biblioteca “libssl” libcrypto
#include <openssl/ssl.h>

void
SSL_set_bio(SSL *ssl, BIO *rbio, BIO *wbio);

DESCRIPCIÓN

SSL_set_bio() conecta los BIOs rbio y wbio para las operaciones de lectura y escritura del lado TLS/SSL (cifrado) de ssl.

El motor SSL hereda el comportamiento de rbio y wbio, respectivamente. Si un BIO no es bloqueante, el ssl también tendrá un comportamiento no bloqueante.

Si ya había un BIO conectado a ssl, se llamará a BIO_free(3) (tanto para el lado de lectura como para el de escritura, si son diferentes).

VER TAMBIÉN

BIO_new(3), ssl(3), SSL_accept(3), SSL_connect(3), SSL_get_rbio(3), SSL_shutdown(3)

HISTORIA

SSL_set_bio() apareció por primera vez en SSLeay 0.6.0 y ha estado disponible desde OpenBSD 2.4.
