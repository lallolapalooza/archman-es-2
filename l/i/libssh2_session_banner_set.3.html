libssh2_session_banner_set(3)

Paquete: libssh2

Licencias: BSD

libssh2_session_banner_set(3) libssh2 libssh2_session_banner_set(3)

NOMBRE

libssh2_session_banner_set - establece el banner del protocolo SSH para el cliente local

SINOPSIS

#include <libssh2.h>
int
libssh2_session_banner_set(LIBSSH2_SESSION *session, const char *banner);

DESCRIPCIÓN

session - Instancia de sesión como la devuelta por libssh2_session_init_ex(3)

banner - Un puntero a una cadena terminada en nulo que contiene el banner definido por el usuario

Establece el banner que se enviará al host remoto cuando se inicie la sesión SSH con libssh2_session_handshake(3) Esto es opcional; se enviará un banner correspondiente al protocolo y a la versión de libssh2 de forma predeterminada.

VALOR DE RETORNO

Devuelve 0 en caso de éxito o un valor negativo en caso de fallo. Devuelve LIBSSH2_ERROR_EAGAIN cuando de otro modo se bloquearía. Aunque LIBSSH2_ERROR_EAGAIN es un número negativo, no es realmente un fallo en sí mismo.

ERRORES

LIBSSH2_ERROR_ALLOC - Una llamada interna de asignación de memoria falló.

DISPONIBILIDAD

Añadido en 1.4.0.

Antes de 1.4.0, esta función se conocía como libssh2_banner_set(3)

VER TAMBIÉN

libssh2_session_handshake(3), libssh2_session_banner_get(3)
