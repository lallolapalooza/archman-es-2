OBJ_FIND_SIGID_ALGS(3) Manual de funciones de biblioteca OBJ_FIND_SIGID_ALGS(3)

NOMBRE

OBJ_find_sigid_algs, OBJ_find_sigid_by_algs — mapeos de algoritmos de firma

SINOPSIS

biblioteca “libcrypto”
#include <openssl/objects.h>

int
OBJ_find_sigid_algs(int signature, int *pdigest, int *pencryption);

int
OBJ_find_sigid_by_algs(int *psignature, int digest, int encryption);

DESCRIPCIÓN

OBJ_find_sigid_algs() busca el algoritmo de firma. Si se encuentra, el algoritmo de resumen asociado se almacena en *pdigest a menos que pdigest sea un puntero NULL, y el algoritmo de cifrado asociado se almacena en *pencryption a menos que pencryption sea un puntero NULL.

OBJ_find_sigid_by_algs() busca el par (digest, encryption). Si se encuentra, el algoritmo de firma asociado se almacena en *psignature a menos que psignature sea un puntero NULL.

VALORES DE RETORNO

OBJ_find_sigid_algs() devuelve 1 si se encuentra una definición del algoritmo de firma o 0 si una definición del algoritmo de firma no está incorporada en la biblioteca.

OBJ_find_sigid_by_algs() devuelve 1 si se define un algoritmo de firma que utiliza los algoritmos de digest y encryption especificados, o 0 si la definición de dicho algoritmo no está incorporada en la biblioteca.

VER TAMBIÉN

OBJ_create(3), OBJ_nid2obj(3)

HISTORIAL

Estas funciones aparecieron por primera vez en OpenSSL 1.0.0 y han estado disponibles desde OpenBSD 4.9.
