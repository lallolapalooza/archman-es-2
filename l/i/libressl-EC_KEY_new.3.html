DESCRIPCIÓN

Un EC_KEY representa una clave pública y (opcionalmente) una clave privada asociada. La clave pública es un punto en una curva representado por un EC_POINT, ver EC_POINT_new(3). La clave privada es simplemente un BIGNUM, ver BN_new(3).

Se puede construir una nueva EC_KEY (sin curva asociada) llamando a EC_KEY_new(). El recuento de referencias para la EC_KEY recién creada se establece inicialmente en 1. Se puede asociar una curva con la EC_KEY llamando a EC_KEY_set_group().

Alternativamente, se puede construir una nueva EC_KEY llamando a EC_KEY_new_by_curve_name() y proporcionando el nid de la curva asociada. Consulte EC_GROUP_new_by_curve_name(3) para obtener una descripción de los nombres de las curvas. Esta función simplemente envuelve llamadas a EC_KEY_new() y EC_GROUP_new_by_curve_name().

Llamar a EC_KEY_free() decrementa el recuento de referencias del objeto EC_KEY y, si ha caído a cero, libera la memoria asociada a él. Si key es un puntero NULL, no se realiza ninguna acción.

EC_KEY_copy() copia el contenido de la EC_KEY en dst desde src.

EC_KEY_dup() crea un nuevo objeto EC_KEY y copia src en él.

EC_KEY_up_ref() incrementa el recuento de referencias asociado con el objeto EC_KEY.

EC_KEY_generate_key() genera una nueva clave pública y privada para el objeto key proporcionado. key debe tener un objeto EC_GROUP asociado antes de llamar a esta función. La clave privada es un entero aleatorio (0 < priv_key < order, donde order es el orden del objeto EC_GROUP). La clave pública es un EC_POINT en la curva calculado multiplicando el generador de la curva por la clave privada.

EC_KEY_check_key() realiza varias comprobaciones de validez en el objeto EC_KEY para confirmar que es válido.

EC_KEY_set_public_key_affine_coordinates() establece la clave pública de key utilizando las coordenadas afines x e y. Los valores x e y son transferidos al objeto EC_KEY.

La función EC_KEY_print() imprime la clave key en el flujo bp. Si off es distinto de cero, entonces se imprimen datos adicionales.

La función EC_KEY_print_fp() es similar a EC_KEY_print(), pero imprime en un FILE fp en lugar de un BIO.

Las funciones EC_KEY_get_flags(), EC_KEY_set_flags(), y EC_KEY_clear_flags() se utilizan para obtener y establecer banderas asociadas con el objeto EC_KEY.

Las funciones EC_KEY_get_enc_flags() y EC_KEY_set_enc_flags() se utilizan para obtener y establecer banderas de cifrado para claves privadas.

Las funciones EC_KEY_get_conv_form() y EC_KEY_set_conv_form() se utilizan para obtener y establecer el formulario de conversión de puntos para codificación/decodificación de claves.

La función EC_KEY_set_asn1_flag() se utiliza para establecer una bandera relacionada con la codificación ASN1.

La función EC_KEY_precompute_mult() precalcula los múltiplos del generador de la curva. Esto puede acelerar las operaciones posteriores, pero aumenta el uso de memoria y el tiempo de inicialización. La bandera EC_FLAG_OPTIMIZE puede establecerse en el objeto EC_KEY para habilitar esta optimización.

El resto de las funciones son funciones de acceso para obtener o establecer componentes de un EC_KEY.

VALORES DEVUELTOS

EC_KEY_new(), EC_KEY_new_by_curve_name(), EC_KEY_dup(), y EC_KEY_copy() devuelven un puntero a un nuevo objeto EC_KEY en caso de éxito, o NULL en caso de error.

EC_KEY_up_ref() devuelve 1 en caso de éxito, o 0 en caso de error.

EC_KEY_set_group(), EC_KEY_set_private_key(), EC_KEY_set_public_key(), EC_KEY_set_public_key_affine_coordinates(), EC_KEY_precompute_mult(), EC_KEY_generate_key() y EC_KEY_check_key() devuelven 1 en caso de éxito, o 0 en caso de error.

EC_KEY_get_flags() devuelve las banderas actuales.

EC_KEY_get_enc_flags() devuelve las banderas de cifrado actuales.

EC_KEY_get_conv_form() devuelve la forma de conversión actual.

EC_KEY_get0_group() devuelve la EC_GROUP asociada. No se debe liberar el puntero devuelto.

EC_KEY_get0_private_key() devuelve el BIGNUM de la clave privada. No se debe liberar el puntero devuelto.

EC_KEY_get0_public_key() devuelve el EC_POINT de la clave pública. No se debe liberar el puntero devuelto.

EC_KEY_print() y EC_KEY_print_fp() devuelven 1 en caso de éxito, o 0 en caso de error.

DESCRIPTION

The function EC_KEY_set_public_key_affine_coordinates() sets the public key for key based on its affine coordinates, i.e. it constructs an EC_POINT object based on the supplied x and y values and sets the public key to be this EC_POINT. It also performs certain sanity checks on the key to confirm that it is valid.

The functions EC_KEY_get0_group(), EC_KEY_set_group(), EC_KEY_get0_private_key(), EC_KEY_set_private_key(), EC_KEY_get0_public_key(), and EC_KEY_set_public_key() get and set the EC_GROUP object, the private key and the EC_POINT public key for the key, respectively. The setters copy the group and key objects without sanity checks and it is the caller's responsibility to ensure that the resulting key is valid, for example using EC_KEY_check_key().

The functions EC_KEY_get_enc_flags() and EC_KEY_set_enc_flags() get and set the value of the encoding flags for the key. There are two encoding flags currently defined: EC_PKEY_NO_PARAMETERS and EC_PKEY_NO_PUBKEY. These flags define the behaviour of how the key is converted into ASN.1 in a call to i2d_ECPrivateKey(). If EC_PKEY_NO_PARAMETERS is set then the public parameters for the curve are not encoded along with the private key. If EC_PKEY_NO_PUBKEY is set then the public key is not encoded along with the private key.

The format of the external representation of the public key written by i2d_ECPrivateKey(3), such as whether it is stored in a compressed form or not, is described by the point_conversion_form. See EC_POINT_point2oct(3) for a description of point_conversion_form.

When reading a private key encoded without an associated public key, for example if EC_PKEY_NO_PUBKEY was used, d2i_ECPrivateKey(3) generates the missing public key automatically. Private keys encoded without parameters, for example if EC_PKEY_NO_PARAMETERS was used, cannot be loaded using d2i_ECPrivateKey(3).

The functions EC_KEY_get_conv_form() and EC_KEY_set_conv_form() get and set the point_conversion_form for the key. For a description of point_conversion_form refer to EC_POINT_point2oct(3).

EC_KEY_set_flags() sets the flags in the flags parameter on the EC_KEY object. Any flags that are already set are left set. The currently defined standard flags are EC_FLAG_NON_FIPS_ALLOW and EC_FLAG_FIPS_CHECKED. In addition there is the ECDH-specific flag EC_FLAG_COFACTOR_ECDH. EC_KEY_get_flags() returns the current flags that are set for this EC_KEY. EC_KEY_clear_flags() clears the flags indicated by the flags parameter. All other flags are left in their existing state.

EC_KEY_set_asn1_flag() sets the asn1_flag on the underlying EC_GROUP object (if set). Refer to EC_GROUP_get_curve_name(3) for further information on the asn1_flag.

EC_KEY_precompute_mult() stores multiples of the underlying EC_GROUP generator for faster point multiplication. See also EC_POINT_add(3).

EC_KEY_print() and EC_KEY_print_fp() print out the content of key to the BIO bp or to the FILE pointer fp, respectively. Each line is indented by indent spaces.

RETURN VALUES

EC_KEY_new(), EC_KEY_new_by_curve_name(), and EC_KEY_dup() return a pointer to the newly created EC_KEY object or NULL on error.

EC_KEY_get_flags() returns the flags associated with the EC_KEY object.

EC_KEY_copy() returns a pointer to the destination key or NULL on error. In the latter case, part of the content may already have been copied.

EC_KEY_up_ref(), EC_KEY_set_group(), EC_KEY_set_private_key(), EC_KEY_set_public_key(), EC_KEY_precompute_mult(), EC_KEY_generate_key(), EC_KEY_check_key(), EC_KEY_set_public_key_affine_coordinates(), EC_KEY_print(), and EC_KEY_print_fp() return 1 on success or 0 on error.

EC_KEY_get0_group() returns the EC_GROUP associated with the EC_KEY.

EC_KEY_get0_private_key() and EC_KEY_get0_public_key() return the private or public keys, respectively, associated with the EC_KEY.

EC_KEY_get_enc_flags() returns the value of the current encoding flags for the EC_KEY.

EC_KEY_get_conv_form() returns the point_conversion_form for the EC_KEY.

NAME

EC_KEY_new, EC_KEY_new_by_curve, EC_KEY_free, EC_KEY_copy, EC_KEY_dup - create and destroy EC_KEY objects

SYNOPSIS

 #include <openssl/ec.h>

 EC_KEY *EC_KEY_new(void);
 EC_KEY *EC_KEY_new_by_curve(int nid);
 void EC_KEY_free(EC_KEY *key);
 int EC_KEY_copy(EC_KEY *dst, const EC_KEY *src);
 EC_KEY *EC_KEY_dup(const EC_KEY *src);

DESCRIPTION

The EC_KEY object represents an Elliptic Curve (EC) key pair. It can contain a private key and/or a public key.

EC_KEY_new() allocates and initializes a new, empty EC_KEY object. The object created by this function is not associated with any particular curve. To set the curve, EC_KEY_set_group() or EC_KEY_set_public_key() etc. should be used.

EC_KEY_new_by_curve() allocates and initializes a new EC_KEY object and associates it with the curve identified by the NID (Numeric ID) nid. For a list of available curve NIDs, see EC_GROUP_list_curves(3).

EC_KEY_free() frees the EC_KEY object key and any associated resources. If key is NULL, nothing is done.

EC_KEY_copy() copies the contents of the EC_KEY object src to the EC_KEY object dst. dst must have been allocated previously, for example by EC_KEY_new() or EC_KEY_new_by_curve(). It is not permitted to copy onto itself.

EC_KEY_dup() creates a new EC_KEY object and copies the contents of src into it.

RETURN VALUES

EC_KEY_new(), EC_KEY_new_by_curve() return a pointer to the newly allocated EC_KEY object, or NULL on failure.

EC_KEY_free() returns void.

EC_KEY_copy() returns 1 on success, and 0 on failure.

EC_KEY_dup() returns a pointer to the newly duplicated EC_KEY object, or NULL on failure.

EC_GROUP_new(3), EC_KEY_set_public_key(3)
