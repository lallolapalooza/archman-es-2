lconv(3type) lconv(3type)

NOMBRE

lconv - información de formato numérico

BIBLIOTECA

Biblioteca C estándar (libc)

SINOPSIS

#include <locale.h>
struct lconv {                /* Valores en la locale "C": */
    char *decimal_point;      /* "." */
    char *thousands_sep;      /* "" */
    char *grouping;           /* "" */
    char *mon_decimal_point;  /* "" */
    char *mon_thousands_sep;  /* "" */
    char *mon_grouping;       /* "" */
    char *positive_sign;      /* "" */
    char *negative_sign;      /* "" */
    char *currency_symbol;    /* "" */
    char  frac_digits;        /* CHAR_MAX */
    char  p_cs_precedes;      /* CHAR_MAX */
    char  n_cs_precedes;      /* CHAR_MAX */
    char  p_sep_by_space;     /* CHAR_MAX */
    char  n_sep_by_space;     /* CHAR_MAX */
    char  p_sign_posn;        /* CHAR_MAX */
    char  n_sign_posn;        /* CHAR_MAX */
    char *int_curr_symbol;    /* "" */
    char  int_frac_digits;    /* CHAR_MAX */
    char  int_p_cs_precedes;  /* CHAR_MAX */
    char  int_n_cs_precedes;  /* CHAR_MAX */
    char  int_p_sep_by_space; /* CHAR_MAX */
    char  int_n_sep_by_space; /* CHAR_MAX */
    char  int_p_sign_posn;    /* CHAR_MAX */
    char  int_n_sign_posn;    /* CHAR_MAX */
};

DESCRIPCIÓN

Contiene miembros relacionados con el formato de valores numéricos. En la locale "C", sus miembros tienen los valores mostrados en los comentarios anteriores.

ESTÁNDARES

C11, POSIX.1-2024.

HISTORIA

POSIX.1-2001.

VER TAMBIÉN

setlocale(3), localeconv(3), charsets(7), locale(7)
