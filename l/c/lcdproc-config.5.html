NOMBRE

lcdproc-config - formato de los archivos de configuración de LCDproc

SINTAXIS

La sintaxis de los archivos de configuración de LCDproc es de estilo archivo INI.

Son archivos de texto de 8 bits divididos en secciones, cada una que contiene cero o más pares clave-valor. Las secciones se introducen con etiquetas de sección que comienzan con '[' y terminan con ']', y los pares clave-valor consisten en un nombre de clave, un signo '=' y un valor cada uno.

Los nombres de clave son secuencias de caracteres que no son espacios, que no comienzan con '[' y que no contienen '=' ni '\n', mientras que los valores son cadenas similares a las del shell. Es decir, son o bien secuencias simples de caracteres que no son espacios, o cadenas entre comillas dobles con sintaxis estilo C (excepto la falta de soporte para secuencias de escape '\NNN' y '\xNN') o una mezcla de ambas formas.

Las etiquetas de sección y los nombres de clave no distinguen entre mayúsculas y minúsculas y pueden aparecer más de una vez. Las claves de secciones duplicadas se fusionarán en una sola sección, mientras que los valores de claves duplicadas en una sección se añadirán para formar un array de valores para esa clave. (En el programa, todos los valores de una clave se pueden recuperar individualmente)

Se ignoran los espacios alrededor de las etiquetas de sección, claves y valores. Las líneas que comienzan con ';' o '#' se consideran comentarios y también se ignoran.

Si bien todo lo anterior es bastante común para casi todas las implementaciones de archivos INI, hay algunas características especiales que hacen que los archivos de configuración de LCDproc sean especiales:

  • Las etiquetas de sección pueden contener cualquier carácter excepto ']', '\n' o '\0'. Sin embargo, todos los caracteres se interpretan literalmente (es decir, ni se citan ni se escapan).
  • Los nombres de clave pueden contener cualquier carácter que no sea un espacio excepto '\n' o '\0'. Sin embargo, todos los caracteres se interpretan literalmente (es decir, ni se citan ni se escapan).
  • Se permiten comentarios después de las etiquetas de sección y los pares de valores de clave
  • Los valores pueden ser una mezcla de cadenas entre comillas y sin comillas, similar a como se interpretan las cadenas en el shell. Por ejemplo, el valor 'cadena" con "espacios"\t!' se analizará como 'cadena con espacios<TAB>!' donde <TAB> representa el carácter TAB.

En caso de un error de análisis, el resto de la línea se ignora y el análisis continúa con la siguiente línea.

EJEMPLO

Aquí hay un ejemplo funcional de un LCDd.conf (formateado de forma algo extraña para mostrar las características):

# la sección del servidor
[server]
Bind=127.0.0.1
Port=13666
User="nobody"
#Foreground=no
#ReportLevel=3
#ReportToSyslog=yes
Driver="mi Driver Curses"
DriverPath=/usr/lib/lcdproc/
WaitTime= "5"
ServerScreen=no
# asignar teclas a funciones especiales #
ToggleRotateKey = Enter
PrevScreenKey = Left
NextScreenKey = Right
# ScrollUpKey = Up
 #ScrollDownKey=Down
# sección de menú: definir teclas para usar en el menú del servidor #
	 [menu]
MenuKey = Escape	# ESC cambia al menú del servidor
EnterKey =Enter
UpKey= Up	
DownKey="Down"
 LeftKey= "Left"
 RightKey = "Right"
# configuración del driver curses #
[mi Driver curses]	# sí, uso el driver curse
File= "curses.so"
Size="20"x"4"		# dimensiones de la pantalla LCD
TopLeftX=7		# posición de la pantalla: coordenada X
TopLeftY=7		# posición de la pantalla: coordenada Y
Foreground=blue		# color de primer plano
Background=cyan		# color de fondo cuando la luz de fondo está apagada
Backlight=red		# color de fondo cuando la luz de fondo está encendida

ARCHIVOS

Estos son los archivos de configuración predeterminados para las diversas partes de la suite LCDproc:

/etc/LCDd.conf
configuración del demonio servidor LCDd
/etc/lcdproc.conf
configuración del cliente de monitoreo del sistema lcdproc
/etc/lcdexec.conf
configuración del cliente iniciador de programas lcdexec
/etc/lcdvc.conf
configuración del cliente de consola virtual lcdvc
