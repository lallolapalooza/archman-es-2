NOMBRE

lcdvc - consola virtual de LCDproc

SINOPSIS

lcdvc [-fh] [-a dirección] [-c archivo] [-p puerto] [-r nivel] [-s booleano]

DESCRIPCIÓN

Este programa muestra el contenido de una consola del sistema en una pantalla LCD controlada por LCDd. Como la consola suele ser más grande que una pantalla LCD, el área mostrada en la pantalla LCD puede desplazarse usando las teclas conectadas a la pantalla.

Adicionalmente, tiene una función de autodesplazamiento, que está activada por defecto y solo puede desactivarse usando el menú de lcdvc.

Por defecto, utiliza los dispositivos /dev/vcs y /dev/vcsa como la consola a mostrar. Otros dispositivos de consola pueden configurarse en el archivo de configuración /etc/lcdvc.conf. Las teclas utilizadas para desplazarse también pueden configurarse en el archivo de configuración.

OPCIONES

Las siguientes opciones pueden configurarse también en el archivo de configuración /etc/lcdvc.conf, pero las proporcionadas en la línea de comandos tienen precedencia:

-a dirección
Nombre DNS o dirección IP del servidor LCDd (por defecto localhost).
-c archivo
Especificar archivo de configuración.
-f
Ejecutar en primer plano.
-h
Mostrar ayuda y salir.
-p puerto
Puerto del servidor LCDd (por defecto 13666).
-r nivel
Establecer el nivel de reporte (0-5, por defecto: 2)
-s booleano
Reportar a syslog (1) o stderr (0, por defecto).

ARCHIVOS

/etc/lcdvc.conf
/dev/vcs
/dev/vcsa
