NOMBRE

lcdexec - Cliente de LCDproc para ejecutar comandos desde el menú de LCDd

SINOPSIS

lcdexec [-hf] [-c config] [-a dir] [-p puerto] [-r nivel] [-s booleano]

DESCRIPCIÓN

lcdexec se conecta a LCDd (el servidor de LCDproc) y añade un submenú al menú principal de LCDd que permite al usuario seleccionar comandos a ser ejecutados. Puede acceder al menú presionando la tecla de menú configurada para LCDd.

OPCIONES

lcdexec entiende las siguientes opciones de línea de comandos, que anulan las opciones correspondientes dadas en el archivo de configuración:

-c archivo
Establece el nombre del archivo de configuración a leer, /etc/lcdexec.conf por defecto.
-a dirección
Establece la dirección del host donde se está ejecutando LCDd, localhost por defecto.
-p puerto
Establece el puerto en el que LCDd acepta conexiones, 13666 por defecto.
-f
Ejecutar en primer plano.
-r nivel
Establece el nivel de reporte a nivel, que es un entero que representa los niveles de reporte de 0 (solo errores críticos) a 5 (mensajes de depuración). El valor por defecto es 2 (solo errores y advertencias).
-s booleano
Reportar a syslog (1) o a stdout (0, por defecto).

USO

Además de las opciones de línea de comandos listadas anteriormente, lcdexec también toma opciones de un archivo de configuración.

Se espera que este archivo tenga un formato similar a un "archivo INI" con secciones introducidas por encabezados de sección entre corchetes y líneas de opciones que consisten en pares clave=valor.

Los nombres de sección y opción solo pueden contener caracteres del rango [a-zA-Z0-9_], mientras que las cadenas de valor pueden contener cualquier carácter imprimible. Las cadenas de valor con caracteres fuera del rango [a-zA-Z0-9_] deben ir entre comillas dobles. Para obtener una comilla doble o barras invertidas en la cadena, deben ser escapadas precediéndolas con una barra invertida.

El archivo de configuración de lcdexec necesita al menos dos secciones:

[lcdexec]
para las opciones generales
[MainMenu]
para el nivel superior de la jerarquía de menús a mostrar.

La sección [lcdexec] soporta las siguientes opciones:

Address=servidor
El nombre del host o la dirección IP del servidor LCDd al que conectarse. Si no se proporciona, servidor por defecto es localhost.
Port=puerto
Puerto del servidor al que conectarse. El valor por defecto para puerto es 13666, el puerto de LCDproc.
ReportLevel=nivel
Establece el nivel de reporte a nivel, que es un entero que representa los niveles de reporte de 0 (solo errores críticos) a 5 (mensajes de depuración). El valor por defecto es 2 (solo errores y advertencias).
ReportToSyslog=booleano
Indica si reportar a syslog (TRUE) o a stderr (FALSE).
Foreground=booleano
Indica si se ejecutará en primer plano (TRUE) o en segundo plano (FALSE). Si no se proporciona, el valor por defecto es FALSE para el modo demonio.
DisplayName=Pantalla
Establece el nombre de visualización para el menú principal. Si no se proporciona, por defecto es lcdexec HOST, donde HOST es el nombre de host del sistema en el que se está ejecutando lcdexec.
Shell=/ruta/al/shell
Establece el shell a usar al ejecutar programas. Si no se proporciona, lcdexec intenta leer la variable de entorno SHELL. Si falla, por defecto es /bin/sh. Tenga en cuenta que el shell dado aquí debe entender la opción -c seguida de la línea de comandos a ejecutar.

La sección [MainMenu] y las secciones a las que se refiere definen la jerarquía de menús a mostrar. Cada menú y cada entrada de menú en la jerarquía de menús se define como su propia sección. Si una sección dada es un submenú o una entrada de comando se define por las claves de opción que ocurren en la sección.

Las secciones de menú / entradas de menú pueden contener las siguientes opciones:

Entry=entrada
Define una entrada de menú entrada que se especifica además en la sección [entrada].

Las secciones que contienen una o más opciones Entry= son menús.

Exec=comando
Define el comando del sistema comando a ejecutar cuando se selecciona esta entrada.

Las secciones que contienen una opción Exec= son entradas de comando.

DisplayName=nombre
El nombre de la entrada de menú a mostrar en la pantalla LCD. Si esta opción no se proporciona, se utiliza el nombre del encabezado de sección (sin los corchetes).
Feedback=booleano
En las entradas de comando, esta opción indica si se debe informar al usuario de la finalización de los comandos mediante una pantalla de alerta en la pantalla. Si no se proporciona, el valor por defecto es no.

ARCHIVOS

lcdexec.conf

EJEMPLOS

En el archivo de configuración:

## opciones generales para lcdexec ##
[lcdexec]
# dirección del servidor LCDd al que conectarse
Address=localhost
# Puerto del servidor al que conectarse
Port=13666
# establecer nivel de reporte
ReportLevel=2
# ¿reportar a syslog?
ReportToSyslog=false
# ejecutar en primer plano [por defecto: false; legal: true, false]
Foreground=false
# nombre de pantalla para el menú principal [por defecto: lcdexec HOST]
#DisplayName=lcdexec
# definición del menú principal
[MainMenu]
# las líneas Entry=... (una para cada entrada de menú) indican que es una definición de menú
Entry=EjectCD
Entry=ShutdownMenu
# definición de un comando
[EjectCD]
# nombre a mostrar en el menú en lugar del nombre de la sección
DisplayName="Expulsar CD-ROM"
# la línea Exec=... indica que es un comando
Exec="umount /cdrom; cdeject"
# definición de un menú
[ShutdownMenu]
DisplayName="Menú de apagado"
# un menú contiene una línea Entry=... para cada entrada de menú
Entry=Shutdown5min
Entry=Reboot5min
Entry=CancelShutdown
Entry=ShutdownNow
Entry=RebootNow
[Shutdown5min]
DisplayName="Apagar en 5 minutos"
Exec="shutdown -h +5"
Feedback=yes
[Reboot5min]
DisplayName="Reiniciar en 5 minutos"
Exec="shutdown -r +5"
Feedback=yes
[CancelShutdown]
DisplayName="Cancelar apagado/reinicio"
Exec="shutdown -c"
Feedback=yes
[ShutdownNow]
DisplayName="Apagar ahora"
Exec="shutdown -h now"
[RebootNow]
DisplayName="Reiniciar ahora"
Exec="shutdown -r now"

Inicie lcdexec con: lcdexec -c /usr/local/etc/lcdexec.conf

Esto le permitirá expulsar el CD-ROM abriendo el menú de LCDd, seleccionando "lcdexec" y seleccionando "Expulsar CD-ROM". Además, le permite realizar varios apagados, entre ellos el "Apagar en 5 minutos" abriendo el menú de LCDd, seleccionando "lcdexec", seleccionando "Menú de apagado" y seleccionando "Apagar en 5 minutos".
