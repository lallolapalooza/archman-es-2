NOMBRE

lc - Compilador de licencias Mono

SINOPSIS

lc -c nombrearchivo -t ensamblado_objetivo [-i referencia...] [-v] [-o ruta_salida] [-nologo]

DESCRIPCIÓN

La herramienta lc es un compilador de licencias para Mono. Se utiliza para convertir un archivo licenses.licx en un recurso que puede ser incrustado en un ejecutable.

Al usar componentes comerciales para .NET, a menudo requieren un recurso de licencia en tiempo de ejecución para asegurarse de que el desarrollador tenía licencia para usar ese control. La forma más común de asegurarse de que el componente estaba debidamente licenciado es mediante el uso de recursos de licencia. En tiempo de compilación, el desarrollador utiliza la herramienta lc para convertir un archivo licenses.licx en un archivo programanombre.exe.licenses y lo incrusta como un recurso administrado durante la compilación.

OPCIONES EN TIEMPO DE EJECUCIÓN

Las siguientes opciones están disponibles:

--lista_componentes=nombrearchivo, -c nombrearchivo
Esta opción se utiliza para especificar el archivo de entrada, el archivo licenses.licx para el cual se creará un recurso de licencia. Esta opción es obligatoria. El compilador de licencias leerá cada línea de este archivo e intentará cargar los tipos especificados en esa línea.
--objetivo=nombre_ensamblado, -t ensamblado_objetivo
Nombre completo del ensamblado con extensión de archivo para el ensamblado objetivo. El compilador de licencias lo utiliza como clave al compilar las licencias. Debe coincidir con el ensamblado en el que se incrustará el recurso. Esta opción es obligatoria.
--cargar=referencia, -i referencia
Referencia de ensamblado a cargar antes de intentar compilar una licencia. Esta opción es necesaria para ensamblados cuyas referencias no están en el GAC. Los compiladores deben pasar todas las referencias al compilador de licencias.
--verboso,, -v
Proporciona una salida más detallada sobre el proceso de compilación de licencias.
--ayuda, -h
Muestra las instrucciones de uso.
--directorio_salida=ruta, -o ruta
Ruta de archivo destino para el recurso de licencias. Por defecto, el compilador de licencias emite el recurso en el directorio actual. El nombre del archivo siempre coincidirá con el ensamblado objetivo pasado a --objetivo con .licenses añadido.
--sin_logo
No emite el logotipo "Mono License Compiler" en la salida estándar mientras compila.

ARCHIVOS DE LICENCIA

El formato para los archivos de licencia (licenses.licx) es el siguiente:

# comentario
namespace.tipo, nombresamblado
namespace.tipo, nombresamblado-completo

Todas las líneas que comienzan con # se ignoran. La primera forma requiere que el ensamblado se haya cargado a través de la opción --cargar, -i pero no requiere el nombre completo del ensamblado, solo la primera parte.

La segunda forma requiere el nombre completo del ensamblado, incluyendo la configuración regional, la versión y el token de clave pública.
