NOMBRE

lcdproc - cliente de información de estado del sistema

SINOPSIS

lcdproc [-hfv] [-c config] [-s host] [-p puerto] [-e retraso] [pantalla ...]

DESCRIPCIÓN

lcdproc es el cliente en la suite LCDproc que muestra información sobre el estado del sistema local en una pantalla LCD conectada a un demonio servidor LCDd.

Debido a la arquitectura cliente-servidor, no importa si el demonio LCDd se ejecuta en la máquina local o en un sistema remoto.

La mayoría de las configuraciones de lcdproc se configuran a través de su archivo de configuración /etc/lcdproc.conf, algunas de ellas pueden ser anuladas usando opciones de línea de comandos.

Antes de ejecutar lcdproc, debe leer detenidamente ese archivo y modificar las configuraciones en él según sus necesidades.

Cuando se compila adecuadamente, algunos aspectos de lcdproc pueden incluso configurarse en tiempo de ejecución usando un menú en la pantalla LCD.

Actualmente, solo se admiten Linux, las variantes BSD FreeBSD, NetBSD, OpenBSD y Darwin, así como Solaris, pero no todas las funciones pueden estar disponibles en todas las plataformas.

OPCIONES

lcdproc entiende las siguientes opciones de línea de comandos:

-c config
Usar un archivo de configuración diferente a /etc/LCDd.conf
-s host
Conectar al servidor LCDd en host, en lugar de al especificado en el parámetro Server en la sección [lcdproc] del archivo de configuración. Si no se proporciona aquí y no se especifica en el archivo de configuración o si el archivo de configuración predeterminado no existe, se utiliza por defecto 'localhost'.
-p puerto
Usar el puerto puerto al conectar al servidor LCDd en host. Esta opción anula el parámetro Port en la sección [lcdproc] del archivo de configuración. Sin un archivo de configuración predeterminado o cuando no se establece en el archivo de configuración, se utiliza por defecto el puerto LCDproc 13666.
-f
Ejecutar en primer plano, anulando el parámetro Foreground en la sección [lcdproc] del archivo de configuración. El valor predeterminado, si no está en el archivo de configuración o sin archivo de configuración, es demonizar lcdproc ya que está diseñado para mostrar la información del sistema en segundo plano.
-e retraso
Esperar retraso en centésimas de segundo entre la actualización de pantallas en un ciclo de actualización. Esta opción anula el parámetro Delay en la sección [lcdproc] del archivo de configuración. Cuando no se proporciona y no está en el archivo de configuración, se utiliza por defecto 0.
-h
Mostrar pantalla de ayuda.
-v
Imprimir la versión de lcdproc y salir.
pantalla
puede ser uno de los siguientes:
C CPU
mostrar uso detallado de la CPU
P SMP-CPU
resumen del uso de la CPU: una línea por CPU, especialmente útil en sistemas SMP.
G CPUGraph
histograma de CPU
L Load
histograma de carga

S ProcSize

D Disk

B Battery

U Uptime

N MiniClock
reloj minimalista
A About
página de créditos

En la línea de comandos, puede usar el nombre corto o el nombre largo de la pantalla. En el archivo de configuración, se utilizan los nombres largos como etiquetas de sección para configurar las pantallas adicionalmente.

También puede prefijar los nombres de pantalla con un signo de exclamación '!' para deshabilitar una pantalla que se activó en el archivo de configuración en lugar de activar una deshabilitada.

EJEMPLOS

lcdproc C M D '!L'

Con la línea de comandos especificada anteriormente, lcdproc carga el archivo de configuración predeterminado, se conecta al servidor LCDd especificado en él y luego muestra las siguientes pantallas además de las activadas en el archivo de configuración en la pantalla LCD:

  • Uso detallado de la CPU
  • Uso de memoria y swap
  • Nivel de llenado de los sistemas de archivos montados

La pantalla

*
Histograma de carga

está deshabilitada y, por lo tanto, no se muestra en la pantalla. (Las comillas no forman parte de la sintaxis de la línea de comandos de lcdproc; son necesarias para deshabilitar la interpretación especial del signo de exclamación por parte del shell).

    NAME

    lcdproc - controlador de pantalla LCD

    SYNOPSIS

    lcdproc [-f configfile] [-d] [-a]

    DESCRIPTION

    lcdproc es un demonio de software que permite controlar una variedad de pantallas LCD desde un ordenador con Linux. Estas pantallas suelen ser comunes en sistemas de hardware integrados, como sistemas de cine en casa, servidores o incluso ordenadores de sobremesa personalizados.

    El demonio se comunica con las aplicaciones de usuario a través de un socket de dominio Unix, permitiendo que múltiples aplicaciones muestren información en la pantalla LCD simultáneamente. Gestiona la pantalla, la entrada de botones (si los hay) y la salida de texto o gráficos.

    OPTIONS

    • -f configfile: Especifica un archivo de configuración alternativo. Si no se proporciona, se utiliza el archivo de configuración predeterminado (normalmente /etc/lcdproc.conf).
    • -d: Ejecuta lcdproc como un demonio (en segundo plano).
    • -a: Permite que lcdproc se ejecute en modo de depuración (verbose), mostrando más información sobre sus operaciones.

    EXAMPLES

    Para iniciar lcdproc como un demonio usando el archivo de configuración predeterminado:

    sudo lcdproc -d

    Para iniciar lcdproc como un demonio con un archivo de configuración específico:

    sudo lcdproc -f /etc/mi_lcdproc.conf -d

    Para ejecutar lcdproc en primer plano con salida de depuración:

    lcdproc -a

    SEE ALSO

    lcdproc.conf(5), lcdproc-tools(1)
