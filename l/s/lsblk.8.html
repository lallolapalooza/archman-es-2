LSBLK(8) Administración del Sistema LSBLK(8)

NOMBRE

lsblk - listar dispositivos de bloque

SINOPSIS

lsblk [opciones] [dispositivo...]

DESCRIPCIÓN

lsblk lista información sobre todos los dispositivos de bloque disponibles o especificados. El comando lsblk lee el sistema de archivos sysfs y la base de datos de udev para recopilar información. Si la base de datos de udev no está disponible o lsblk está compilado sin soporte de udev, intenta leer ETIQUETAS, UUIDs y tipos de sistema de archivos del dispositivo de bloque. En este caso, se requieren permisos de root.

Por defecto, el comando imprime todos los dispositivos de bloque (excepto los discos RAM) en un formato de árbol. El mismo dispositivo puede aparecer repetido en el árbol si está relacionado con otros dispositivos. Se recomienda la opción --merge para configuraciones más complejas para agrupar dispositivos y describir relaciones complejas N:M.

La salida en formato de árbol (o el array children[] en la salida JSON) solo se habilita si la columna NAME está presente en la salida o cuando se usa la opción de línea de comandos --tree. Ver también --nodeps y --list para controlar el formato del árbol.

La salida predeterminada, así como la salida predeterminada de opciones como --fs y --topology, está sujeta a cambios. Por lo tanto, siempre que sea posible, debe evitar usar las salidas predeterminadas en sus scripts. Defina siempre las columnas esperadas explícitamente usando --output lista-de-columnas y --list en entornos donde se requiera una salida estable.

Use lsblk --list-columns para obtener una lista de todas las columnas disponibles.

Tenga en cuenta que lsblk puede ejecutarse en un momento en que udev aún no tiene toda la información sobre dispositivos añadidos o modificados recientemente. En este caso, se recomienda usar udevadm settle antes de lsblk para sincronizarse con udev.

La relación entre los dispositivos de bloque y los sistemas de archivos no siempre es uno a uno. El sistema de archivos puede usar más dispositivos de bloque, o el mismo sistema de archivos puede ser accesible por más rutas. Esta es la razón por la que lsblk proporciona las columnas MOUNTPOINT y MOUNTPOINTS (plural). La columna MOUNTPOINT muestra solo un punto de montaje (generalmente la última instancia montada del sistema de archivos), y la columna MOUNTPOINTS muestra en una celda multilínea todos los puntos de montaje asociados con el dispositivo.

OPCIONES

-A, --noempty

No imprimir dispositivos vacíos.

-a, --all

Deshabilitar todos los filtros integrados y listar todos los dispositivos vacíos y los dispositivos de disco RAM también.

-b, --bytes

Imprimir los tamaños en bytes en lugar de en un formato legible por humanos.

Por defecto, la unidad en la que se expresan los tamaños es byte, y los prefijos de unidad están en potencias de 2^10 (1024). Las abreviaturas de los símbolos se muestran truncadas para lograr una mejor legibilidad, mostrando solo la primera letra de ellas; ejemplos: "1 KiB" y "1 MiB" se muestran respectivamente como "1 K" y "1 M", omitiendo a propósito la mención "iB", que forma parte de estas abreviaturas.

-H, --list-columns

Listar las columnas disponibles, usar con --json o --raw para obtener la salida en formato legible por máquina.

-D, --discard

Imprimir información sobre las capacidades de descarte (TRIM, UNMAP) para cada dispositivo.

-d, --nodeps

No imprimir dispositivos contenedores ni esclavos. Por ejemplo, lsblk --nodeps /dev/sda imprime información solo sobre el dispositivo sda.

-E, --dedup columna

Usar columna como clave de deduplicación para deduplicar el árbol de salida. Si la clave no está disponible para el dispositivo, o si el dispositivo es una partición y el dispositivo de disco completo padre proporciona la misma clave, el dispositivo siempre se imprime.

El caso de uso habitual es deduplicar la salida en dispositivos multi-ruta del sistema, por ejemplo, con -E WWN.

-e, --exclude lista

Excluir los dispositivos especificados por la lista separada por comas de números de dispositivo principales. Tenga en cuenta que los discos RAM (principal=1) se excluyen por defecto si no se especifica --all. El filtro se aplica solo a los dispositivos de nivel superior. Esto puede ser confuso para el formato de salida --list donde la jerarquía de los dispositivos no es obvia.

-f, --fs

Imprimir información sobre los sistemas de archivos. Esta opción es equivalente a -o NAME,FSTYPE,FSVER,LABEL,UUID,FSAVAIL,FSUSE%,MOUNTPOINTS. La información autorizada sobre sistemas de archivos y raids la proporciona el comando blkid(8).

--hyperlink[=modo]

Imprimir las rutas de los puntos de montaje como hipervínculos de terminal. El modo se puede establecer en "always", "never" o "auto". El argumento opcional when se puede establecer en "auto", "never" o "always". Si se omite el argumento when, se establecerá por defecto en "auto". La configuración "auto" significa que los hipervínculos solo se usarán si la salida está en una terminal.

-I, --include lista

Incluir los dispositivos especificados por la lista separada por comas de números de dispositivo principales. El filtro se aplica solo a los dispositivos de nivel superior. Esto puede ser confuso para el formato de salida --list donde la jerarquía de los dispositivos no es obvia.

-i, --ascii

Usar caracteres ASCII para el formato del árbol.

-J, --json

Usar formato de salida JSON. Se recomienda encarecidamente utilizar --output y también --tree si es necesario. Tenga en cuenta que children[] solo se utiliza si se usan las columnas NAME o --tree.

-l, --list

Producir la salida en forma de lista. La salida no proporciona información sobre las relaciones entre los dispositivos y, desde la versión 2.34, cada dispositivo se imprime solo una vez si no se especifican --pairs o --raw (las salidas analizables se mantienen de forma compatible con versiones anteriores).

-M, --merge

Agrupar los padres de los subárboles para proporcionar una salida más legible para dispositivos RAID y Multi-path. Se requiere la salida en formato de árbol.

-m, --perms

Imprimir información sobre el propietario, grupo y modo del dispositivo. Esta opción es equivalente a -o NAME,SIZE,OWNER,GROUP,MODE.

-N, --nvme

Imprimir información solo sobre dispositivos NVMe.

-v, --virtio

Imprimir información solo sobre dispositivos virtio.

-n, --noheadings

No imprimir la línea de encabezado.

-o, --output lista

Especificar qué columnas de salida imprimir. Usar --list-columns para obtener una lista de todas las columnas soportadas. Las columnas pueden afectar la salida en formato de árbol. El valor predeterminado es usar árbol para la columna 'NAME' (ver también --tree).

La lista predeterminada de columnas puede extenderse si se especifica lista en el formato +lista (por ejemplo, lsblk -o +UUID).

-O, --output-all

Imprimir todas las columnas disponibles.

-P, --pairs

Producir la salida en forma de pares clave="valor". Las líneas de salida todavía están ordenadas por dependencias. Todos los caracteres de valor potencialmente inseguros se escapan en formato hexadecimal (\x<código>). Ver también la opción --shell.

-p, --paths

Imprimir rutas completas de los dispositivos.

-Q, --filter expresión

Imprimir solo los dispositivos que cumplen las condiciones especificadas por la expr. El filtro se evalúa antes de que lsblk recopile datos para todas las columnas de salida. Solo se recuperan del sistema los datos necesarios para la evaluación perezosa de la expresión. Este enfoque puede mejorar el rendimiento en comparación con el filtrado posterior, como suelen hacer herramientas como grep(1).

Esta característica es EXPERIMENTAL. Ver también scols-filter(5). Por ejemplo, para excluir sda y sdb, pero imprimir todo lo demás ('!~' es un operador de coincidencia de expresiones regulares negativas):

OPTIONS

--filter expr

Filtra las líneas de salida que coinciden con la expresión. La expresión se evalúa en el contexto de la estructura de datos que se está imprimiendo. Consulte también scols-filter(5).
lsblk --filter 'NAME !~ "sd[ab]"'

--highlight expr

Colorea las líneas que coinciden con la expresión. Esta función es EXPERIMENTAL. Consulte también scols-filter(5).

--ct name [: param [: function ]]

Define un contador personalizado. Los contadores se imprimen después de la salida estándar. El name es el nombre personalizado del contador, el param opcional es el nombre de la columna que se utilizará para el contador, y la function opcional especifica la función de agregación. Las funciones admitidas son: count, min, max o sum. El valor predeterminado es count.

Si el param no se especifica, el contador cuenta el número de líneas. Esta función es EXPERIMENTAL. Consulte también --ct-filter.

Por ejemplo, --ct MyCounter:SIZE:sum contará el resumen de SIZE de todas las líneas; y para contar el número de discos SATA, es posible utilizar:

lsblk --ct-filter 'TYPE=="disk" && TRAN=="sata"' --ct "Number of SATA devices"

--ct-filter expr

Define una restricción para el siguiente contador. Esta función es EXPERIMENTAL. Consulte también --ct y scols-filter(5). Por ejemplo, agrega tamaños por tipo de dispositivo:
lsblk --ct-filter 'TYPE=="part"' --ct Partitions:SIZE:sum \
      --ct-filter 'TYPE=="disk"' --ct WholeDisks:SIZE:sum

-r, --raw

Produce la salida en formato crudo. Las líneas de salida todavía están ordenadas por dependencias. Todos los caracteres potencialmente inseguros se escapan en hexadecimal (\x<code>) en las columnas NAME, KNAME, LABEL, PARTLABEL y MOUNTPOINT.

-S, --scsi

Muestra información solo sobre dispositivos SCSI. Se ignoran todas las particiones, esclavos y dispositivos contenedores.

-s, --inverse

Imprime las dependencias en orden inverso. Si se solicita la salida --list, las líneas seguirán ordenadas por dependencias.

-T, --tree[=column]

Fuerza el formato de salida en árbol. Si se especifica column, se imprime un árbol en esa columna. El valor predeterminado es la columna NAME.

-t, --topology

Muestra información sobre la topología de dispositivos de bloque. Esta opción es equivalente a

-o NAME,ALIGNMENT,MIN-IO,OPT-IO,PHY-SEC,LOG-SEC,ROTA,SCHED,RQ-SIZE,RA,WSAME.

-w, --width number

Especifica el ancho de salida como un número de caracteres. El valor predeterminado es el número de columnas de la terminal y, si no se ejecuta en una terminal, el ancho de salida no está restringido por defecto. Esta opción también fuerza a lsblk a asumir que los caracteres de control de la terminal y los caracteres inseguros no están permitidos. El caso de uso esperado es, por ejemplo, cuando lsblk es utilizado por el comando watch(1).

-x, --sort column

Ordena las líneas de salida por column. Esta opción habilita el formato de salida --list por defecto. Es posible usar la opción --tree para forzar la salida en árbol y luego las ramas del árbol se ordenan por la column.

-y, --shell

El nombre de la columna se modificará para que contenga solo caracteres permitidos para identificadores de variables de shell, por ejemplo, MIN_IO y FSUSE_PCT en lugar de MIN-IO y FSUSE%. Esto es útil, por ejemplo, con --pairs. Tenga en cuenta que esta función se habilitó automáticamente para --pairs en la versión 2.37, pero debido a problemas de compatibilidad, ahora es necesario solicitar este comportamiento con --shell.

-z, --zoned

Imprime la información relacionada con zonas para cada dispositivo.

--sysroot directory

Recopila datos para una instancia de Linux distinta de la instancia desde la que se ejecuta el comando lsblk. El directorio especificado es la raíz del sistema de la instancia de Linux a inspeccionar. Los nodos de dispositivo reales en el directorio de destino pueden ser reemplazados por archivos de texto con atributos udev.

--properties-by list

Esta opción especifica los métodos utilizados por lsblk para recopilar información sobre sistemas de archivos y tablas de particiones. La lista es una lista separada por comas de nombres de métodos. La configuración predeterminada es "file,udev,blkid". Los métodos admitidos son:

udev

Lee datos de la base de datos de udev. Si no tiene éxito, continúa con el siguiente método de sondeo.

blkid

Lee datos directamente del dispositivo usando libblkid. Si no tiene éxito, continúa con el siguiente método de sondeo.

file

Lee datos de un archivo. Este método solo se utiliza si se especifica la opción --sysroot. Este método siempre detiene el sondeo si se utiliza.

none

No sondea. Este método siempre detiene el sondeo.

-h, --help

Muestra el texto de ayuda y sale.

-V, --version

Muestra la versión y sale.

ESTADO DE SALIDA

0

éxito

1

fallo

32

no se encontraron dispositivos especificados

64

se encontraron algunos dispositivos especificados, otros no

ENTORNO

LSBLK_DEBUG=all

habilita la salida de depuración de lsblk.

LIBBLKID_DEBUG=all

habilita la salida de depuración de libblkid.

LIBMOUNT_DEBUG=all

habilita la salida de depuración de libmount.

LIBSMARTCOLS_DEBUG=all

habilita la salida de depuración de libsmartcols.

LIBSMARTCOLS_DEBUG_PADDING=on

usa caracteres de relleno visibles.

NOTAS

Para las particiones, alguna información (por ejemplo, atributos de cola) se hereda del dispositivo principal.

El comando lsblk necesita poder buscar cada dispositivo de bloque por números mayor:menor, lo que se hace utilizando /sys/dev/block. Este directorio sysfs de bloques apareció en el kernel 2.6.27 (octubre de 2008). En caso de problemas con un kernel suficientemente nuevo, compruebe que CONFIG_SYSFS estaba habilitado en el momento de la compilación del kernel.
