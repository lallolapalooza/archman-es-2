LSBTR(1) Manual de Btrbk LSBTR(1)

NOMBRE

lsbtr - listar subvolúmenes btrfs

SINOPSIS

lsbtr [-h|--help] [--version]
      [-l|--long] [-u|--uuid] [-1|--single-column] [--raw]
      [--format <formato-salida>]
      [-v|--verbose]
      [-c|--config <archivo>]
      [--override <opcion_config>=<valor>]
      [[--] <ruta>|<url>...]

DESCRIPCIÓN

Lista subvolúmenes btrfs y sus puntos de montaje visibles en el sistema de archivos debajo de <ruta>.

lsbtr es parte de btrbk (básicamente un atajo para "btrbk ls"), y toma algunas opciones de configuración global de btrbk.conf(5) si están presentes.

lsbtr requiere privilegios de root para ejecutarse correctamente. Alternativamente, considere usar los backends "btrfs-progs-sudo" o "btrfs-progs-btrbk", los cuales permiten ejecutar lsbtr como un usuario normal. Consulte la opción de configuración backend en btrbk.conf(5) para más detalles.

OPCIONES

-h, --help

Imprime la sinopsis y una lista de los comandos.

--version

Imprime la versión de btrbk.

-l, --long

Imprime la salida en formato de tabla larga (además imprime la ruta del subvolumen).

-u, --uuid

Imprime la tabla UUID (relaciones padre/recibidas).

-1, --single-column

Imprime solo la columna de ruta (delimitada por nueva línea).

--raw

Imprime pares de clave="valor" separados por espacios (legible por máquina).

--format table|long|raw|col:[h:]<columnas>

Imprime la salida en el formato especificado. Si se establece en "raw", imprime pares de clave="valor" separados por espacios (legible por máquina).

Si se establece en "col:", imprime solo las <columnas> especificadas (lista separada por comas). Las líneas de encabezado se omiten si está presente el modificador "h:". Las columnas prefijadas con "-" se colapsan si están vacías. Las columnas postfijadas con ":RALIGN" están alineadas a la derecha.

-v, --verbose

Aumenta el nivel de verbosidad.

-c, --config <archivo>

Lee la configuración desde <archivo>.

--override <opcion_config>=<valor>

Anula una opción de configuración <opcion_config> con <valor>.

ARCHIVOS

/etc/btrbk.conf, /etc/btrbk/btrbk.conf

Archivo de configuración por defecto. El formato del archivo y las opciones de configuración se describen en btrbk.conf(5).

ESTADO DE SALIDA

lsbtr devuelve los siguientes códigos de error:

0

No ocurrieron problemas.

1

Código de error genérico.

2

Error de análisis: al analizar las opciones de línea de comandos o el archivo de configuración.

255

Error del script.

DISPONIBILIDAD

Consulte la página del proyecto btrbk https://digint.ch/btrbk/ para más detalles.

VER TAMBIÉN

btrbk(1), btrbk.conf(5), btrfs(8)
