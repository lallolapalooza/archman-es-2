NOMBRE

lsroll - Lista los rollrecs en un archivo rollrec de DNSSEC-Tools

SINOPSIS

lsroll [opciones] <archivos-rollrec>

DESCRIPCIÓN

Este script lista el contenido de los archivos rollrec especificados. Todos los archivos rollrec se cargan antes de mostrar la salida. Si algún rollrec tiene nombres duplicados, ya sea dentro de un archivo o entre varios archivos, el rollrec posterior será el cuyos datos se mostrarán.

FORMATOS DE SALIDA

La salida mostrada para cada zona en un archivo rollrec depende de los registros seleccionados, los atributos seleccionados y el formato de salida seleccionado. Cada opción en estos grupos de opciones se describe en detalle en la siguiente sección. Los tres formatos de salida base, junto con el formato predeterminado -skip, se describen aquí.

La opción -terse indica que se desea una cantidad mínima de salida; la opción -long indica que se desea una gran cantidad de salida. Las opciones de selección de registros y selección de atributos se pueden usar en conjunto con -terse para mostrar exactamente el conjunto de campos rollrec necesarios.

El formato de salida predeterminado es el que se utiliza cuando no se proporciona ni -terse ni -long, y es un punto intermedio entre la salida concisa y la larga.

Si se proporciona la opción -skip, entonces el formato de salida predeterminado es un poco más restringido que el predeterminado normal. Algunos campos de rollrec no tienen sentido en el contexto de los registros de salto, y por lo tanto se muestran como "---". Estos campos son la fase de rotación de KSK, la fase de rotación de ZSK, el valor TTL y el inicio de la fase.

La siguiente tabla muestra los campos mostrados para cada formato de salida.

campo de rollrec    predeterminado        conciso        largo       salto
-------------        ----------        -------        -----       ----
nombre de rollrec     sí             sí          sí        sí
tipo de rollrec       no             no          sí        no
nombre de zona        no             no          sí        sí
archivo de zona       sí             no          sí        sí
grupo de zona         no             no          sí        no
archivo de keyrec     sí             no          sí        sí
fase KSK              sí             no          sí        no
fase ZSK              sí             no          sí        no
administrador         no             no          sí        no
directorio            no             no          sí        no
nivel de registro     no             no          sí        no
valor TTL             no             no          sí        no
bandera de visualización no             no          sí        no
inicio de fase        no             no          sí        no
última rotación KSK   no             no          sí        no
última rotación ZSK   no             no          sí        no
argumentos de zonesigner no             no          sí        no

El campo de nombre del rollrec a menudo es el mismo que su nombre de zona, pero no necesariamente. El nombre del rollrec puede contener espacios, mientras que el nombre de la zona no. Por esta razón, lsroll muestra el nombre del rollrec entre comillas, incluso si el nombre no contiene espacios. Esto está destinado a permitir un análisis más fácil por parte de otros programas.

Si se proporciona la opción -info, se mostrará el registro especial de info rollrec. Si el archivo rollrec tiene este registro informativo, anotado con el nombre info rollrec, se imprimirán los contenidos del registro <info rollrec>. Si se dan varios archivos rollrec en la línea de comandos, los registros info rollrec de cada archivo se antepondrán con el nombre del archivo rollrec.

OPCIONES

Hay tres tipos de opciones reconocidas por lsroll: opciones de selección de registros, opciones de selección de atributos y opciones de formato de salida. Cada tipo se describe en las subsecciones a continuación.

Opciones de Selección de Registros

Estas opciones seleccionan los registros que serán mostrados por lsroll. Por defecto, se mostrarán todos los registros; la selección de una u otra de estas opciones restringirá los registros mostrados.

Para simplificar el código de lsroll y mantenerlo fácilmente comprensible, estas opciones son mutuamente excluyentes.

-roll
Lista todos los registros "roll" en el archivo rollrec.
-skip
Lista todos los registros "skip" en el archivo rollrec.
-info
Lista todos los campos del registro "info" del archivo rollrec.

Opciones de Selección de Atributos

Estas opciones seleccionan los atributos de los registros que serán mostrados por lsroll.

-type
Incluye el tipo de cada registro rollrec en la salida. El tipo será "roll" o "skip".
-zonename
Se incluye el nombre de zona del registro en la salida. El nombre de zona es distinto del nombre rollrec del registro, que siempre se incluye en la salida. Si bien estos dos campos a menudo son los mismos, no tienen por qué serlo. En zonas de división de zona, los nombres de rollrec deben ser diferentes, mientras que el campo zonename es el mismo.
-zonefile
Se incluye el archivo de zona del registro en la salida. Este campo forma parte de la salida predeterminada.
-zg
Se incluye el grupo de zona del registro en la salida, entre comillas dobles. Si una entrada de rollrec no contiene un grupo de zona, se proporciona el valor "". Si el grupo de zona de un registro contiene espacios en blanco al principio o al final, se eliminarán de la salida.
-keyrec
Se incluye el archivo keyrec del registro en la salida. Este campo forma parte de la salida predeterminada.
-kskphase
Se incluyen las fases de rotación de KSK del registro en la salida. Si esta opción se proporciona con la opción -zskphase, la salida seguirá el formato descrito para la opción -phases. Este campo forma parte de la salida predeterminada.
-zskphase
Se incluyen las fases de rotación de ZSK del registro en la salida. Si esta opción se proporciona con la opción -kskphase, la salida seguirá el formato descrito para la opción -phases. Este campo forma parte de la salida predeterminada.
-phases
Se incluyen las fases de rotación de KSK y ZSK del registro en la salida. La lista se proporciona con la fase KSK primero, seguida de la fase ZSK.

Ejemplos de salida de esta opción son:

fase KSK   fase ZSK       salida
    0           0            0/0
    3           0            3/0
    0           5            0/5
-admin
Se incluye el valor del administrador del registro en la salida. Si no se incluye un valor de administrador en un rollrec, se proporcionará el valor "(defadmin)".
-directory
Se incluye el nombre del directorio que contiene los archivos de la zona en la salida. Si no se incluye un directorio de zona en un rollrec, se proporcionará el valor "(defdir)".
-loglevel
El nivel de registro de rollerd para esta zona. Este valor puede proporcionarse en el archivo rollrec en forma textual o numérica. Se mostrará la forma textual del nivel de registro, no la numérica. Si no se incluye un valor de nivel de registro en un rollrec, se proporcionará el valor "(deflog)". Si se incluye un valor de nivel de registro no definido en un rollrec, se proporcionará el valor "(unknownlog)".
-ttl
Se incluye el valor TTL del registro en la salida.
-phase_start
La fecha y hora de inicio de la fase de rotación se incluye en la salida.
-last_ksk
La fecha y hora de la última rotación de KSK se incluye en la salida.
-last_zsk
La fecha y hora de la última rotación de ZSK se incluye en la salida.
-zonesigner_args
Los argumentos de zonesigner para la zona se incluyen en la salida.
-all
Imprime todos los campos de rollrec reconocidos por lsroll.

Opciones de Formato de Salida

-terse
La salida se formatea de manera concisa. Solo se imprime el nombre de rollrec, el nombre de zona y el archivo de zona y el archivo keyrec. La opción -all se ignora si se proporciona esta opción.
-long
La salida se formatea de manera detallada. Se imprimen todos los campos de rollrec excepto el campo de tipo de registro.
-skip
Similar a la opción -long, pero algunos campos que no son significativos para los registros de salto se suprimen y en su lugar se imprime "---". Estos campos son la fase KSK, la fase ZSK, el valor TTL y el inicio de la fase.

EJEMPLOS

Para listar todos los registros de rotación en el archivo my_rollrec_file, se utiliza el siguiente comando:

lsroll -roll my_rollrec_file

Para listar todos los registros de salto en el archivo my_rollrec_file, pero solo mostrar el nombre del registro, el nombre de la zona y el archivo de la zona, se utiliza el siguiente comando:

lsroll -skip -zonename -zonefile my_rollrec_file

Para listar todos los registros de rotación y salto en el archivo my_rollrec_file, pero solo mostrar los nombres de rollrec, los nombres de zona y los archivos de zona y archivos de keyrec, se utiliza el siguiente comando:

lsroll -zonefile -keyrec my_rollrec_file

Para listar todos los registros de rotación y salto en el archivo my_rollrec_file en formato largo, se utiliza el siguiente comando:

lsroll -long my_rollrec_file

Para listar todos los registros de rotación y salto en el archivo my_rollrec_file en formato de salto, se utiliza el siguiente comando:

lsroll -skip my_rollrec_file

Para listar todos los registros de rotación y salto en ambos archivos my_rollrec_file y your_rollrec_file en formato largo, se utiliza el siguiente comando:

lsroll -long my_rollrec_file your_rollrec_file

NAME

lsroll

list DNSSEC-Tools key rollover records

SYNOPSIS

lsroll [-a arg] [-c count] [-d] [-g group] [-H] [-h] [-l] [-n name] [-p] [-r file] [-s] [-t] [-V] [keyfile ...]

DESCRIPTION

The lsroll utility is used to list information about the key rollover records stored in a rollrec(5) file. It can search for specific keys or all keys, and can output the information in a variety of formats.

A key rollover record contains information about the keys used for a zone, including the keys themselves, the dates of their rollovers, and other operational parameters.

OPTIONS

The following options are available for lsroll:

Key Selection Options

-a arg
Specifies a user-defined argument for the record. This option can be specified multiple times. If specified, only records matching all specified arguments are returned.
-c count
Specifies the maximum number of records to return. If not specified, all matching records are returned.
-d
The record's display flag, used by blinkenlights, is included in the output.
-g group
Specifies a zonegroup to search within. If not specified, all zonegroups are searched.
-n name
Specifies the name of the record to search for. This can be a zone name or a key tag. If not specified, all records are returned.
-p
The record's rollover phase is included in the output. If no rollover has yet been performed for this zone, an empty date is given.
-lastksk
The record's last KSK rollover date is included in the output. If no KSK rollover has yet been performed for this zone, an empty date is given.
-lastzsk
The record's last ZSK rollover date is included in the output. If no ZSK rollover has yet been performed for this zone, an empty date is given.
-zsargs
The record's user-defined zonesigner arguments are included in the output. If no arguments have been set for this zone, then the value "(none)" is given.
-zonegroup
The zonegroups defined in the rollrec are listed, enclosed in double quotes. All other rollrec fields are ignored. If the -long option is specified, then each zonegroup name will be accompanied by the number of rollrec entries in that zonegroup.

Output-format Options

These options select the type of output that will be given by lsroll.

-count
Only a count of matching keyrecs in the rollrec file is given.
-headers
Display explanatory column headers.
-terse
Terse output is given. Only the record name and any other fields specifically selected are included in the output.
-long
Long output is given. All record fields are included.
-help
Display a usage message.
-Version
Displays the version information for lsroll and the DNSSEC-Tools package.
