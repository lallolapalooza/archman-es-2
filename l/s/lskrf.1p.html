NOMBRE

lskrf - Lista los keyrecs en un archivo keyrec de DNSSEC-Tools

SINOPSIS

lskrf [opciones] <archivos-keyrec>

DESCRIPCIÓN

lskrf lista el contenido de los archivos keyrec especificados. Todos los archivos keyrec se cargan antes de que se muestre la salida. Si algún keyrec tiene nombres duplicados, ya sea dentro de un archivo o entre varios archivos, el keyrec posterior será el que muestre sus datos.

lskrf tiene tres formatos de salida base. En niveles ascendentes de detalle, estos formatos son salida concisa, formato predeterminado y formato largo. La salida concisa se proporciona cuando se especifica la opción -terse; la salida larga se proporciona cuando se especifica la opción -long.

La salida mostrada para cada registro en un archivo keyrec depende de los registros seleccionados, los atributos seleccionados y el formato de salida seleccionado. Cada opción en estos grupos de opciones se describe en detalle en la sección OPCIONES; los tres formatos de salida básicos se describen en la sección FORMATOS DE SALIDA.

FORMATOS DE SALIDA

Los archivos keyrec contienen tres tipos de registros keyrec: registros de zona, registros de conjunto de firma y registros de clave. Cada tipo de registro keyrec contiene campos keyrec relacionados con ese tipo. Los registros keyrec de zona contienen datos sobre todas las claves asociadas con una zona particular; los registros keyrec de conjunto contienen datos sobre todas las claves asociadas con un conjunto de firma particular; los registros keyrec de clave contienen longitudes de clave y algoritmos para cada clave particular. (Existe el caso de los conjuntos de firma subordinados revocados y obsoletos. Estos se almacenan en registros keyrec de clave, pero contienen la entrada set_type que las keyrec de clave no tienen). Los datos a imprimir deben especificarse seleccionando alguna combinación de las opciones -zone, -sets, -keys y -all. También hay opciones para especificar tipos específicos de claves a imprimir.

Los tres formatos de salida base son el formato predeterminado, el formato conciso y el formato largo. La opción -terse indica que se desea una cantidad mínima de salida; la opción -long indica que se desea una gran cantidad de salida. Las opciones de selección de registros y selección de atributos se pueden usar junto con -terse para mostrar exactamente el conjunto de campos keyrec necesarios. El formato de salida predeterminado es un punto intermedio entre la salida concisa y la larga, y es el que se utiliza cuando no se proporciona ni -terse ni -long.

OPCIONES

lskrf toma tres tipos de opciones: opciones de selección de registros, opciones de atributos de registro y opciones de estilo de salida. Estos conjuntos de opciones se detallan a continuación.

Las opciones de selección de registros son opciones requeridas; se debe seleccionar al menos una opción de selección de registros. Las opciones de atributos de registro y las opciones de estilo de salida son opciones opcionales; se puede seleccionar cualquier número de estas opciones.

EJEMPLOS

A continuación se presentan algunos ejemplos de cómo usar lskrf:

Para mostrar todas las zonas y conjuntos de claves en el archivo db.example.com:

lskrf -zones -sets -keys db.example.com
Para mostrar todas las claves KSK y ZSK publicadas en los archivos db.example.com y db.example.net:

lskrf -kpub -zpub db.example.com db.example.net
Para mostrar todos los datos de los registros de zona en el archivo db.example.com en formato largo:

lskrf -long -zones db.example.com
Para mostrar solo los nombres de las zonas y sus fechas de firma en el archivo db.example.com:

lskrf -zname -signdate db.example.com

Opciones de Selección de Registros

Estas opciones seleccionan subconjuntos de los keyrecs dentro de un archivo keyrec.

-obs
Esta opción muestra las claves KSK y ZSK obsoletas en un archivo keyrec. Esta opción es un método abreviado que especifica las opciones -kobs y -zobs.
-rev
Esta opción muestra las claves KSK y ZSK revocadas en un archivo keyrec. Esta opción es un método abreviado que especifica las opciones -krev y -zrev.
-invalid
Esta opción muestra las claves KSK y ZSK obsoletas y revocadas en un archivo keyrec. Esta opción es un método abreviado que especifica las opciones -obs y -rev.

Opciones de Atributo de Registro

Estas opciones seleccionan subconjuntos de los keyrecs elegidos por las opciones de selección de registros.

-valid
Esta opción muestra las zonas válidas en un archivo keyrec. Implica la opción -zones.
-expired>
Esta opción muestra las zonas expiradas en un archivo keyrec. Implica la opción -zones.
-ref
Esta opción muestra los keyrecs de conjuntos de firma referenciados y los keyrecs de clave referenciados en un archivo keyrec, dependiendo de otras opciones seleccionadas.

El estado referenciado depende de lo siguiente:

* Los conjuntos de firma se consideran referenciados si están
  listados en un keyrec de zona.
* Las KSK se consideran referenciadas si están listadas
  en un keyrec de conjunto de firma que está listado en un keyrec de zona.
* Las ZSK se consideran referenciadas si están listadas
  en un keyrec de conjunto de firma que está listado en un keyrec de zona.

Esta opción puede usarse con las opciones -sets o -keys. Si no se usa con ninguna opción de selección de registros, se asume que se han especificado tanto -sets como -keys.

-unref
Esta opción muestra los keyrecs de conjuntos de firma no referenciados o los keyrecs de clave no referenciados en un archivo keyrec, dependiendo de otras opciones seleccionadas.

El estado no referenciado depende de lo siguiente:

* Los conjuntos de firma se consideran no referenciados si no están
  listados en un keyrec de zona.
* Las KSK se consideran no referenciadas si no están listadas
  en un keyrec de conjunto de firma que está listado en un keyrec de zona.
* Las ZSK se consideran no referenciadas si no están listadas
  en un keyrec de conjunto de firma que está listado en un keyrec de zona.
* Las ZSK obsoletas se verifican, independientemente de si el
  flag -obs fue especificado o no.

Esta opción puede usarse con las opciones -sets o -keys. Si no se usa con ninguna opción de selección de registros, se asume que se han especificado tanto -sets como -keys.

Opciones de Atributo de Conjunto

Estas opciones permiten incluir campos específicos del conjunto en la salida. Si se combinan con la opción -terse, solo se imprimirán los campos deseados específicamente. Estas opciones deben usarse con la opción -sets.

Si el procesamiento RFC5011 está habilitado, hay un manejo especial del keyrec de conjunto de claves KSK revocadas de la zona. El campo "kskrev" en el keyrec de la zona apunta a un keyrec de conjunto, marcado como de tipo "kskrev". Este keyrec de conjunto, a su vez, apunta a una serie de otros keyrecs de conjunto, todos los cuales también están marcados como de tipo "kskrev". El grupo de todas las claves KSK revocadas se encuentra consultando ese conjunto subsidiario de keyrecs de conjunto "kskrev". Cuando las edades de estas claves revocadas exceden sus períodos de revocación, se marcan como obsoletas ("kskobs"). Si esto ocurre como parte de un rollover normal, estas claves revocadas y los keyrecs de conjunto se eliminan de la cadena de keyrecs revocados activos. Si esto le ocurre a una clave que forma parte de un conjunto más grande de claves, se elimina de ese conjunto de firma y se coloca en su propio nuevo conjunto de firma. lskrf muestra el tipo del conjunto "kskrev" (listado en el keyrec de zona) como "KSK-REV", y todos los demás keyrecs de KSK revocados se listan como "KSK-rev".

NAME

lskrf - List keys (and zones) from DNSSEC-Tools key record files

SYNOPSIS

lskrf [ -h | -h-zones | -h-sets | -h-keys | -Version ] [ -count | -nodate | -headers | -label | -long | -terse | -Version ] [ -z zonespec ... ] [ -k keyspec ... ] [ -s setspec ... ] [ keyrecfile ... ]

DESCRIPTION

The DNSSEC-Tools package provides tools for managing DNSSEC keys and signed zones. The primary method for storing this information is in a key record file, described in file-keyrec(5).

The lskrf utility is used to read and display information from these key record files.

Zone-Attribute Options

-z zonespec
Selects zones matching the specified zone specification. See the Zone Specifications section for details on how to specify zones.
-z-creation
Display the zone's creation date.
-z-dsign
Display the zone's last DNSSEC signing date.
-z-key
Display the zone's keys.
-z-ksk
Display the zone's Key Signing Keys (KSKs).
-z-lifespan
Display the zone's key lifespan (in seconds). This lifespan is only related to the time between key rollover. There is no other lifespan associated with a zone.
-z-path
Display the zone's path.
-z-random
Display the zone's random number generator.
-z-sigdate
Display the zone's signing date.
-z-zonefile
Display the zone's zone file.
-z-zone
Display the zone's name.

Set-Attribute Options

-s setspec
Selects key sets matching the specified set specification. See the Set Specifications section for details on how to specify key sets.
-s-creation
Display the set's creation date.
-s-dsign
Display the set's last DNSSEC signing date.
-s-key
Display the set's keys.
-s-ksk
Display the set's Key Signing Keys (KSKs).
-s-lifespan
Display the set's key lifespan (in seconds). This lifespan is only related to the time between key rollover. There is no other lifespan associated with a set.
-s-path
Display the set's path.
-s-random
Display the set's random number generator.
-s-sigdate
Display the set's signing date.
-s-zone
Display the set's zone.
-s-zonefile
Display the set's zone file.

Key-Attribute Options

-k keyspec
Selects keys matching the specified key specification. See the Key Specifications section for details on how to specify keys.
-k-creation
Display the key's creation date.
-k-dsign
Display the key's last DNSSEC signing date.
-k-lifespan
Display the key's lifespan (in seconds). This lifespan is only related to the time between key rollover. There is no other lifespan associated with a key.
-k-path
Display the key's path.
-k-random
Display the key's random number generator.
-k-signdate
Display the key's signing date.
-k-zone
Display the key's zonefile.

Output-Format Options

These options define how the keyrec information will be displayed.

Without any of these options, the zone name, zone file, zone-signing date, and a label will be displayed for zones. For types, the key name, the key's zone, the key's generation date, and a label will be displayed if these options aren't given.

-count
The count of matching records will be displayed, but the matching records will not be.
-nodate
The key's generation date will not be printed if this flag is given.
-headers
Display explanatory column headers. If this flag is given, then entry labels will not be printed unless explicitly requested by use of the -label option.
-label
A label for the keyrec's type will be given.
-long
The long form of output will be given. See the OUTPUT FORMATS section for details on data printed for each type of keyrec record.

Long zone output can get very wide, depending on the data.

-terse
This options displays only the name of the zones or keys selected by other options.
-Version
Displays the version information for lskrf and the DNSSEC-Tools package.
-help
Display a usage message and exit.
-h-zones
Display the zone-attribute options and exit.
-h-sets
Display the set-attribute options and exit.
-h-keys
Display the key-attribute options and exit.
