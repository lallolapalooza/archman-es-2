NOMBRE

lsmtd - listar dispositivos de tecnología de memoria

SINOPSIS

lsmtd [opciones] [dispositivo...]

DESCRIPCIÓN

lsmtd lista información sobre todos los dispositivos MTD y UBI disponibles o especificados. El comando lsmtd lee el sistema de archivos sysfs para recopilar información. Alternativamente, se utilizan el sistema de archivos procfs y las interfaces ioctl, en caso de que el sistema de archivos sysfs no esté disponible.

El comando imprime todos los dispositivos MTD y UBI en un formato de lista formateado de forma atractiva por defecto.

La salida por defecto está sujeta a cambios. Por lo tanto, siempre que sea posible, debe evitar usar las salidas por defecto en sus scripts. Defina siempre explícitamente las columnas esperadas utilizando --output lista-de-columnas en entornos donde se requiera una salida estable.

Utilice lsmtd --help para obtener una lista de todas las columnas disponibles.

OPCIONES

-b, --bytes
Imprimir columnas con cantidades de tamaño (por ejemplo, tamaño del bloque de borrado) en bytes en lugar de un formato legible por humanos.
-h, --help
Mostrar un texto de ayuda y salir.
-i, --ascii
Usar solo caracteres ascii para la impresión formateada.
-J, --json
Usar formato de salida JSON. Todos los caracteres potencialmente inseguros en valores de cadena se escapan con secuencias de escape JSON o se escapan en hexadecimal (\u<código>).
-l, --list
Usar un formato de salida de lista formateado de forma atractiva (por defecto).
-m, --no-ubi
No mostrar información sobre dispositivos o volúmenes UBI.
-n, --noheadings
No imprimir encabezados de columna al usar formato de salida raw o list.
-o, --output lista
Especificar qué columnas de salida imprimir. Usar --help para obtener una lista de todas las columnas compatibles.

La lista de columnas por defecto puede ser extendida si lista se especifica en el formato +lista (por ejemplo, lsmtd -o +EB-SIZE).

-O, --output-all
Imprimir todas las columnas disponibles.
-P, --pairs
Producir salida en forma de pares clave="valor". Todos los caracteres potencialmente inseguros se escapan en hexadecimal (\x<código>).
-r, --raw
Producir salida en formato raw. Todos los caracteres potencialmente inseguros se escapan en hexadecimal (\x<código>).
-u, --si-units
Mostrar tamaños legibles por humanos como potencias de diez en lugar de potencias de dos.
-V, --version
Imprimir información de la versión y salir.
-x, --sort columna
Ordenar las líneas de salida por columna.

NOTAS

Si la opción --bytes no se especifica, el formato de salida JSON imprime los tamaños como valores de cadena incluso si no tienen sufijo.
