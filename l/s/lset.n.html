lset(n)

Paquete: tcl

Licencias: TCL

lset(n) Comandos integrados de Tcl lset(n)

NOMBRE

lset - Cambia un elemento en una lista

SINOPSIS

lset nombreVar ?índice ...? nuevoValor

DESCRIPCIÓN

El comando lset acepta un parámetro, nombreVar, que interpreta como el nombre de una variable que contiene una lista Tcl. También acepta cero o más índices en la lista. Los índices pueden presentarse consecutivamente en la línea de comandos, o agrupados en una lista Tcl y presentados como un solo argumento. Finalmente, acepta un nuevo valor para un elemento de nombreVar.

Si no se presentan índices, el comando toma la forma:

lset nombreVar nuevoValor

o

lset nombreVar {} nuevoValor

En este caso, nuevoValor reemplaza el valor antiguo de la variable nombreVar.

Cuando se presenta un solo índice, el comando lset trata el contenido de la variable nombreVar como una lista Tcl. Accede al elemento índice en ella (0 se refiere al primer elemento de la lista). Al interpretar la lista, lset observa las mismas reglas con respecto a llaves, comillas y barras invertidas que el intérprete de comandos Tcl; sin embargo, la sustitución de variables y la sustitución de comandos no ocurren. El comando construye una nueva lista en la que el elemento designado es reemplazado por nuevoValor. Esta nueva lista se almacena en la variable nombreVar, y también es el valor de retorno del comando lset.

Si índice es negativo o mayor que el número de elementos en $nombreVar, entonces ocurre un error.

Si índice es igual al número de elementos en $nombreVar, entonces el elemento dado se añade al final de la lista.

La interpretación de cada valor de índice simple es la misma que para el comando string index, admitiendo aritmética de índices simple e índices relativos al final de la lista.

Si se proporcionan índices adicionales, cada argumento se utiliza en turno para acceder a un elemento dentro de una sublista designada por la operación de indexación anterior, lo que permite al script modificar elementos en sublistas (o añadir elementos a sublistas). El comando,

lset a 1 2 nuevoValor

o

lset a {1 2} nuevoValor

reemplaza el elemento 2 de la sublista 1 con nuevoValor.

El entero que aparece en cada argumento índice debe ser mayor o igual que cero. El entero que aparece en cada argumento índice debe ser menor o igual a la longitud de la lista correspondiente. En otras palabras, el comando lset solo puede cambiar el tamaño de una lista añadiendo un elemento (estableciendo el que está después del final actual). Si un índice está fuera del rango permitido, se informa un error.

EJEMPLOS

En cada uno de estos ejemplos, el valor inicial de x es:

set x [list [list a b c] [list d e f] [list g h i]]
      → {a b c} {d e f} {g h i}

El valor de retorno indicado también se convierte en el nuevo valor de x (excepto en el último caso, que es un error que deja el valor de x sin cambios).

lset x {j k l}
      → j k l
lset x {} {j k l}
      → j k l
lset x 0 j
      → j {d e f} {g h i}
lset x 2 j
      → {a b c} {d e f} j
lset x end j
      → {a b c} {d e f} j
lset x end-1 j
      → {a b c} j {g h i}
lset x 2 1 j
      → {a b c} {d e f} {g j i}
lset x {2 1} j
      → {a b c} {d e f} {g j i}
lset x {2 3} j
      → el índice de la lista está fuera de rango

En los siguientes ejemplos, el valor inicial de x es:

set x [list [list [list a b] [list c d]] \
            [list [list e f] [list g h]]]
      → {{a b} {c d}} {{e f} {g h}}

El valor de retorno indicado también se convierte en el nuevo valor de x.

lset x 1 1 0 j
      → {{a b} {c d}} {{e f} {j h}}
lset x {1 1 0} j
      → {{a b} {c d}} {{e f} {j h}}
