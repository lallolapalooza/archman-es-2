NOMBRE

lspst - lista datos de archivos PST (Carpetas Personales de MS Outlook)

SINOPSIS

lspst [-V] [-d archivo-depuracion] [-f formato-fecha] [-l] [-h] archivo.pst

OPCIONES

-V

Muestra la versión del programa y sale.

-d archivo-depuracion

Especifica el nombre del archivo de registro de depuración. El archivo de registro ahora es un archivo de texto ASCII, en lugar del archivo binario utilizado en versiones anteriores.

-f formato-fecha

Selecciona el formato de fecha para la lista en formato largo. Por defecto es "%F %T".

-l

Utiliza la lista en formato largo para mostrar las cabeceras de Fecha, CC y BCC.

-h

Muestra un resumen de las opciones y sale.

DESCRIPCIÓN

lspst es un programa que puede leer un archivo PST (Carpetas Personales) de Outlook y producir una lista simple de los datos (contactos, asuntos de correo electrónico, etc.).
