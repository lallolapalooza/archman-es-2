lsort(n)

Paquete: tcl

Licencias: TCL

lsort(n) Comandos integrados de Tcl lsort(n)

NOMBRE

lsort - Ordenar los elementos de una lista

SINOPSIS

lsort ?opciones? lista

DESCRIPCIÓN

Este comando ordena los elementos de lista, devolviendo una nueva lista en orden ordenado. La implementación del comando lsort utiliza el algoritmo de ordenación por mezcla (merge-sort), que es una ordenación estable con características de rendimiento O(n log n).

Por defecto, se utiliza la ordenación ASCII y el resultado se devuelve en orden ascendente. Sin embargo, cualquiera de las siguientes opciones puede especificarse antes de lista para controlar el proceso de ordenación (se aceptan abreviaturas únicas):

-ascii
Utiliza comparación de cadenas con orden de intercalación de puntos de código Unicode (el nombre es por razones de compatibilidad con versiones anteriores). Este es el valor predeterminado.
-dictionary
Utiliza comparación de estilo diccionario. Es lo mismo que -ascii excepto que (a) la capitalización se ignora, excepto como desempate, y (b) si dos cadenas contienen números incrustados, los números se comparan como enteros, no como caracteres. Por ejemplo, en modo -dictionary, bigBoy se ordena entre bigbang y bigboy, y x10y se ordena entre x9y y x11y. Anula la opción -nocase.
-integer
Convierte los elementos de la lista en enteros y utiliza comparación de enteros.
-real
Convierte los elementos de la lista en valores de punto flotante y utiliza comparación de punto flotante.
-command comando
Utiliza comando como comando de comparación. Para comparar dos elementos, evalúa un script Tcl que consta de comando con los dos elementos añadidos como argumentos adicionales. El script debe devolver un entero menor que, igual a, o mayor que cero si el primer elemento debe considerarse menor que, igual a, o mayor que el segundo, respectivamente.
-increasing
Ordena la lista en orden ascendente (elementos “más pequeños” primero). Este es el valor predeterminado.
-decreasing
Ordena la lista en orden descendente (elementos “más grandes” primero).
-indices
Devuelve una lista de índices en lista en orden ordenado en lugar de los propios valores.
-index listaÍndices
Si se especifica esta opción, cada uno de los elementos de lista debe ser en sí mismo una sublista Tcl correcta (a menos que se utilice -stride). En lugar de ordenar basándose en sublistas completas, lsort extraerá el elemento listaÍndices de cada sublista (como si el elemento general y el listaÍndices se pasaran a lindex) y ordenará basándose en el elemento dado. Por ejemplo,
lsort -integer -index 1 \
      {{First 24} {Second 18} {Third 30}}

devuelve {Second 18} {First 24} {Third 30},

lsort -index fin-1 \
        {{a 1 e i} {b 2 3 f g} {c 4 5 6 d h}}

devuelve {c 4 5 6 d h} {a 1 e i} {b 2 3 f g}, y

lsort -index {0 1} {
    {{b i g} 12345}
    {{d e m o} 34512}
    {{c o d e} 54321}
}

devuelve {{d e m o} 34512} {{b i g} 12345} {{c o d e} 54321} (porque e se ordena antes que i, que se ordena antes que o.) Esta opción es mucho más eficiente que usar -command para lograr el mismo efecto.

-stride longitudPaso
Si se especifica esta opción, la lista se trata como si consistiera en grupos de longitudPaso elementos y los grupos se ordenan por su primer elemento o, si se utiliza la opción -index, por el elemento dentro de cada grupo dado por el primer índice pasado a -index (que luego es ignorado por -index). Los elementos permanecen siempre en la misma posición dentro de su grupo.

La longitud de la lista debe ser un múltiplo entero de longitudPaso, que a su vez debe ser al menos 2.

Por ejemplo,

lsort -stride 2 {zanahoria 10 manzana 50 plátano 25}

devuelve “manzana 50 plátano 25 zanahoria 10”, y

lsort -stride 2 -index 1 -integer {zanahoria 10 manzana 50 plátano 25}

devuelve “zanahoria 10 plátano 25 manzana 50”.

-nocase
Hace que las comparaciones se manejen de forma insensible a mayúsculas y minúsculas. No tiene efecto si se combina con las opciones -dictionary, -integer o -real.
-unique
Si se especifica esta opción, solo se conservará el último conjunto de elementos duplicados encontrados en la lista. Tenga en cuenta que los duplicados se determinan en relación con la comparación utilizada en la ordenación. Por lo tanto, si se utiliza -index 0, {1 a} y {1 b} se considerarían duplicados y solo se conservaría el segundo elemento, {1 b}.

NOTAS

Las opciones de lsort solo controlan el tipo de comparación que se utiliza y no limitan necesariamente lo que son realmente los valores en sí. Esta distinción solo es perceptible cuando la lista a ordenar tiene menos de dos elementos.

El comando lsort es reentrante, lo que significa que es seguro utilizarlo como parte de la implementación de un comando utilizado en la opción -command.

EJEMPLOS

Ordenar una lista usando ordenación ASCII:

% lsort {a10 B2 b1 a1 a2}
B2 a1 a10 a2 b1

Ordenar una lista usando ordenación de diccionario:

% lsort -dictionary {a10 B2 b1 a1 a2}
a1 a2 a10 b1 B2

Ordenar listas de enteros:

% lsort -integer {5 3 1 2 11 4}
1 2 3 4 5 11
% lsort -integer {1 2 0x5 7 0 4 -1}
-1 0 1 2 4 0x5 7

Ordenar listas de números de punto flotante:

% lsort -real {5 3 1 2 11 4}
1 2 3 4 5 11
% lsort -real {.5 0.07e1 0.4 6e-1}
0.4 .5 6e-1 0.07e1

Ordenar usando índices:

% # Nótese el carácter de espacio antes de la c
% lsort {{a 5} { c 3} {b 4} {e 1} {d 2}}
{ c 3} {a 5} {b 4} {d 2} {e 1}
% lsort -index 0 {{a 5} { c 3} {b 4} {e 1} {d 2}}
{a 5} {b 4} { c 3} {d 2} {e 1}
% lsort -index 1 {{a 5} { c 3} {b 4} {e 1} {d 2}}
{e 1} {d 2} { c 3} {b 4} {a 5}

Ordenar un diccionario:

% set d [dict create c d a b h i f g c e]
c e a b h i f g
% lsort -stride 2 $d
a b c e f g h i

Ordenar usando pasos (striding) y múltiples índices:

% # Nótese que el primer valor de índice es relativo al grupo
% lsort -stride 3 -index {0 1} \
     {{Bob Smith} 25 Audi {Jane Doe} 40 Ford}
{{Jane Doe} 40 Ford {Bob Smith} 25 Audi}

Eliminar valores duplicados usando ordenación:

% lsort -unique {a b c a b c a b c}
a b c

Ordenación más compleja usando una función de comparación:

% proc comparar {a b} {
    set a0 [lindex $a 0]
    set b0 [lindex $b 0]
    if {$a0 < $b0} {
        return -1
    } elseif {$a0 > $b0} {
        return 1
    }
    return [string compare [lindex $a 1] [lindex $b 1]]
}
% lsort -command comparar \
        {{3 apple} {0x2 carrot} {1 dingo} {2 banana}}
{1 dingo} {2 banana} {0x2 carrot} {3 apple}
