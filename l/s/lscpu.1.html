LSCPU(1) Comandos de usuario LSCPU(1)

NOMBRE

lscpu - muestra información sobre la arquitectura de la CPU

SINOPSIS

lscpu [opciones]

DESCRIPCIÓN

lscpu recopila información sobre la arquitectura de la CPU desde sysfs, /proc/cpuinfo y cualquier biblioteca específica de la arquitectura aplicable (por ejemplo, librtas en Powerpc). La salida del comando se puede optimizar para análisis o para una fácil lectura por humanos. La información incluye, por ejemplo, el número de CPUs, hilos, núcleos, sockets y nodos de Memoria No Uniforme (NUMA). También hay información sobre las cachés de la CPU y el uso compartido de caché, familia, modelo, bogoMIPS, orden de bytes y paso.

El formato de salida predeterminado en terminal está sujeto a cambios y puede optimizarse para una mejor legibilidad. La salida para no terminales (por ejemplo, tuberías) nunca se ve afectada por esta optimización y siempre está en formato "Campo: dato\n". Use, por ejemplo, "lscpu | less" para ver la salida predeterminada sin optimizaciones.

En entornos virtualizados, la información de la arquitectura de la CPU mostrada refleja la configuración del sistema operativo invitado, que típicamente difiere del sistema físico (host). En arquitecturas que admiten la recuperación de información de topología física, lscpu también muestra el número de sockets físicos, chips y núcleos en el sistema host.

Las opciones que resultan en una tabla de salida tienen un argumento lista. Utilice este argumento para personalizar la salida del comando. Especifique una lista separada por comas de etiquetas de columna para limitar la tabla de salida solo a las columnas especificadas, dispuestas en el orden especificado. Consulte COLUMNAS para obtener una lista de etiquetas de columna válidas. Las etiquetas de columna no distinguen mayúsculas y minúsculas.

No todas las columnas son compatibles con todas las arquitecturas. Si se especifica una columna no compatible, lscpu imprime la columna pero no proporciona datos para ella.

Los tamaños de caché se informan como un resumen de todas las CPUs. Las versiones anteriores a la v2.34 informaban tamaños por núcleo, pero esta salida era confusa debido a la topología complicada de las CPU y la forma en que las cachés se comparten entre las CPU. Para más detalles sobre las cachés, consulte --cache. Desde la versión v2.37, lscpu sigue los ID de caché según lo proporcionado por el kernel de Linux y no siempre comienza desde cero.

OPCIONES

-a, --all

Incluir líneas para CPUs en línea y fuera de línea en la salida (predeterminado para -e). Esta opción solo puede especificarse junto con la opción -e o -p.

-B, --bytes

Imprimir los tamaños en bytes en lugar de en formato legible por humanos.

Por defecto, la unidad en la que se expresan los tamaños es el byte, y los prefijos de unidad están en potencias de 2^10 (1024). Las abreviaturas de los símbolos se muestran truncadas para lograr una mejor legibilidad, al mostrar solo la primera letra de ellas; ejemplos: "1 KiB" y "1 MiB" se muestran respectivamente como "1 K" y "1 M", omitiendo a propósito la mención "iB", que forma parte de estas abreviaturas.

-b, --online

Limitar la salida a las CPUs en línea (predeterminado para -p). Esta opción solo puede especificarse junto con la opción -e o -p.

-C, --caches[=lista]

Mostrar detalles sobre las cachés de la CPU. Para obtener detalles sobre la información disponible, consulte la salida de --help.

Si se omite el argumento lista, todas las columnas para las cuales hay datos disponibles se incluyen en la salida del comando.

Al especificar el argumento lista, la cadena de la opción, el signo igual (=) y la lista no deben contener espacios en blanco u otros espacios en blanco. Ejemplos: -C=NOMBRE,UN-TAMAÑO o --caches=NOMBRE,UN-TAMAÑO.

La lista predeterminada de columnas puede extenderse si la lista se especifica en el formato +lista (por ejemplo, lscpu -C=+POLÍTICA-ASIGNACIÓN).

-c, --offline

Limitar la salida a las CPUs fuera de línea. Esta opción solo puede especificarse junto con la opción -e o -p.

--hierarchic[=cuándo]

Usar subsecciones en la salida de resumen. Para compatibilidad con versiones anteriores, el valor predeterminado es usar subsecciones solo cuando la salida es en una terminal y salida aplanada en una no terminal. El argumento opcional cuándo puede ser nunca, siempre o auto. Si se omite el argumento cuándo, el valor predeterminado es "siempre".

-e, --extended[=lista]

Mostrar la información de la CPU en formato legible por humanos.

Si se omite el argumento lista, se incluyen las columnas predeterminadas en la salida del comando. La salida predeterminada está sujeta a cambios.

Al especificar el argumento lista, la cadena de la opción, el signo igual (=) y la lista no deben contener espacios en blanco u otros espacios en blanco. Ejemplos: '-e=cpu,nodo' o '--extended=cpu,nodo'.

La lista predeterminada de columnas puede extenderse si la lista se especifica en el formato +lista (por ejemplo, lscpu -e=+MHZ).

-J, --json

Usar formato de salida JSON para el resumen predeterminado o la salida extendida (ver --extended). Para compatibilidad con versiones anteriores, la salida JSON sigue el comportamiento de resumen predeterminado para no terminales (por ejemplo, tuberías) donde faltan las subsecciones. Ver también --hierarchic.

-p, --parse[=lista]

Optimizar la salida del comando para un análisis fácil.

Si se omite el argumento lista, la salida del comando es compatible con versiones anteriores de lscpu. En este formato compatible, se utilizan dos comas para separar las columnas de caché de la CPU. Si no se identifican cachés de CPU, se omite la columna de caché. Si se utiliza el argumento lista, las columnas de caché se separan con dos puntos (:).

Al especificar el argumento lista, la cadena de la opción, el signo igual (=) y la lista no deben contener espacios en blanco u otros espacios en blanco. Ejemplos: '-p=cpu,nodo' o '--parse=cpu,nodo'.

La lista predeterminada de columnas puede extenderse si la lista se especifica en el formato +lista (por ejemplo, lscpu -p=+MHZ).

-r, --raw

Producir la salida en su formato crudo. Esta opción solo es aplicable para las salidas --extended, --parse y --caches.

-s, --sysroot directorio

Recopilar datos de CPU para una instancia de Linux distinta de la instancia desde la que se emite el comando lscpu. El directorio especificado es la raíz del sistema de la instancia de Linux a inspeccionar.

-x, --hex

Usar máscaras hexadecimales para conjuntos de CPU (por ejemplo, "ff"). El valor predeterminado es imprimir los conjuntos en formato de lista (por ejemplo, 0,1). Tenga en cuenta que antes de la versión 2.30, la máscara se imprimía con el prefijo 0x.

-y, --physical

Mostrar ID físicos para todas las columnas con elementos de topología (núcleo, socket, etc.). A diferencia de los ID lógicos, que son asignados por lscpu, los ID físicos son valores específicos de la plataforma proporcionados por el kernel. Los ID físicos no son necesariamente únicos y es posible que no estén organizados secuencialmente. Si el kernel no pudo recuperar un ID físico para un elemento, lscpu imprime el carácter guion (-).

Los números lógicos de CPU no se ven afectados por esta opción.

--output-all

Salida de todas las columnas disponibles. Esta opción debe combinarse con --extended, --parse o --caches.

ERRORES

La descripción general básica de los modelos de CPU se basa en heurísticas, teniendo en cuenta diferencias como los nombres de los modelos de CPU y los ID de implementador. En algunos casos (inusuales), las CPU pueden diferenciarse por marcas o BogoMIPS, pero estas diferencias se ignoran en la descripción general de lscpu.

A veces, en Xen Dom0, el kernel informa datos incorrectos.

En hardware virtual, el número de núcleos por socket, etc., puede ser incorrecto.
