NOMBRE

lstmeval - Programa de evaluación para redes basadas en LSTM.

SINOPSIS

lstmeval --model lang.lstm|nombremodelo_checkpoint|nombremodelo_N.NN_NN_NN.checkpoint [--traineddata lang/lang.traineddata] --eval_listfile lang.eval_files.txt [--verbosity N] [--max_image_MB NNNN]

DESCRIPCIÓN

lstmeval(1) evalúa redes basadas en LSTM. Se puede proporcionar como entrada para la evaluación un modelo de reconocimiento o un punto de control de entrenamiento, junto con una lista de archivos lstmf. Si se evalúa un punto de control de entrenamiento, también se debe especificar --traineddata. También se pueden usar puntos de control de entrenamiento intermedios.

OPCIONES

--model ARCHIVO

Nombre del archivo del modelo (entrenamiento o reconocimiento) (tipo:cadena por defecto:)

--traineddata ARCHIVO

Si el modelo es un punto de control de entrenamiento, entonces traineddata debe ser el archivo traineddata que se proporcionó al entrenador (tipo:cadena por defecto:)

--eval_listfile ARCHIVO

Archivo que lista los archivos de muestra en formato de entrenamiento lstmf. (tipo:cadena por defecto:)

--max_image_MB ENTERO

Memoria máxima a usar para imágenes. (tipo:entero por defecto:2000)

--verbosity ENTERO

Cantidad de información diagnóstica a mostrar (0-2). (tipo:entero por defecto:1)

HISTORIA

lstmeval(1) estuvo disponible por primera vez para tesseract4.00.00alpha.
