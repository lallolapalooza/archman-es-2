LSIRQ(1) Comandos de usuario LSIRQ(1)

NOMBRE

lsirq - utilidad para mostrar información de interrupciones del kernel

SINOPSIS

lsirq [opciones]

DESCRIPCIÓN

Muestra información de contadores de interrupciones del kernel.

La salida predeterminada está sujeta a cambios. Por lo tanto, siempre que sea posible, debe evitar usar salidas predeterminadas en sus scripts. Defina siempre explícitamente las columnas esperadas usando --output.

OPCIONES

-n, --noheadings

No imprimir encabezados.

-o, --output lista

Especifique qué columnas de salida imprimir. Utilice --help para obtener una lista de todas las columnas admitidas. La lista predeterminada de columnas puede extenderse si la lista se especifica en el formato +lista.

-s, --sort columna

Especifique los criterios de ordenación por nombre de columna. Consulte la salida de --help para obtener los nombres de las columnas.

-J, --json

Usar formato de salida JSON.

-P, --pairs

Producir salida en forma de pares clave="valor". Todos los caracteres potencialmente inseguros se escapan en hexadecimal (\x<código>).

-S, --softirq

Mostrar información de softirqs.

-t, --threshold min

Mostrar solo las IRQ con contadores por encima del umbral especificado. Se admiten valores legibles por humanos (por ejemplo, 1.2K).

-C, --cpu-list lista

Mostrar solo contadores de interrupciones en la lista de CPU especificada.

-h, --help

Mostrar texto de ayuda y salir.

-V, --version

Mostrar versión y salir.
