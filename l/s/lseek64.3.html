lseek64(3) Manual de Funciones de Biblioteca lseek64(3)

NOMBRE

lseek64(3) - reposiciona el desplazamiento de archivo de lectura/escritura de 64 bits

BIBLIOTECA

Biblioteca C estándar (libc, -lc)

SINOPSIS

#define _LARGEFILE64_SOURCE     /* Ver feature_test_macros(7) */
#include <sys/types.h>
#include <unistd.h>
off64_t lseek64(int fd, off64_t offset, int whence);

DESCRIPCIÓN

Las funciones de la familia lseek() reposicionan el desplazamiento del archivo abierto asociado con el descriptor de archivo fd a offset bytes relativos al inicio, posición actual o fin del archivo, cuando whence tiene el valor SEEK_SET, SEEK_CUR o SEEK_END, respectivamente.

Para más detalles, valor de retorno y errores, ver lseek(2).

Hay cuatro interfaces disponibles: lseek(), lseek64(), llseek() y _llseek().

lseek()

Prototipo:


off_t lseek(int fd, off_t offset, int whence);

La función de envoltura lseek() de la biblioteca C utiliza el tipo off_t. Este es un tipo con signo de 32 bits en arquitecturas de 32 bits, a menos que se compile con


#define _FILE_OFFSET_BITS 64

en cuyo caso es un tipo con signo de 64 bits.

lseek64()

Prototipo:


off64_t lseek64(int fd, off64_t offset, int whence);

La función de biblioteca lseek64() utiliza un tipo de 64 bits incluso cuando off_t es un tipo de 32 bits. Su prototipo (y el tipo off64_t) solo está disponible cuando se compila con


#define _LARGEFILE64_SOURCE

La función lseek64() está disponible desde glibc 2.1.

llseek()

Prototipo:


loff_t llseek(int fd, loff_t offset, int whence);

El tipo loff_t es un tipo con signo de 64 bits. La función de biblioteca llseek() está disponible en glibc y funciona sin definiciones especiales. Sin embargo, las cabeceras de glibc no proporcionan un prototipo. Los usuarios deben añadir el prototipo anterior, o algo equivalente, a su propio código fuente. Cuando los usuarios se quejaron de la pérdida de datos causada por una compilación errónea de e2fsck(8), glibc 2.1.3 añadió la advertencia en tiempo de enlace


"la función `llseek´ puede ser peligrosa; usa `lseek64´ en su lugar."

Esto hace que esta función sea inutilizable si se desea una compilación sin advertencias.

Desde glibc 2.28, este símbolo de función ya no está disponible para aplicaciones enlazadas recientemente.

_llseek()

En arquitecturas de 32 bits, esta es la llamada al sistema que se utiliza (por las funciones de envoltura de la biblioteca C) para implementar todas las funciones anteriores. El prototipo es:


int _llseek(int fd, off_t offset_hi, off_t offset_lo,
            loff_t *result, int whence);

Para más detalles, ver llseek(2).

Los sistemas de 64 bits no necesitan una llamada al sistema _llseek(). En su lugar, tienen una llamada al sistema lseek(2) que soporta desplazamientos de archivo de 64 bits.

ATRIBUTOS

Para una explicación de los términos utilizados en esta sección, ver attributes(7).

Interfaz Atributo Valor
lseek64 () Seguridad de hilos MT-Safe

NOTAS

lseek64() es una de las funciones especificadas en la especificación Large File Summit (LFS) que se completó en 1996. El propósito de la especificación era proporcionar soporte transicional que permitiera a las aplicaciones en sistemas de 32 bits acceder a archivos cuyo tamaño excede el que se puede representar con un tipo off_t de 32 bits. Como se mencionó anteriormente, este símbolo es expuesto por los archivos de cabecera si se define el macro de prueba de características _LARGEFILE64_SOURCE. Alternativamente, en un sistema de 32 bits, el símbolo lseek se aliñea a lseek64 si el macro _FILE_OFFSET_BITS se define con el valor 64.
