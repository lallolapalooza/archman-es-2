lsusb(8) Utilidades USB de Linux lsusb(8)

NOMBRE

lsusb - listar dispositivos USB

SINOPSIS

lsusb [ opciones ]

DESCRIPCIÓN

lsusb es una utilidad para mostrar información sobre los buses USB del sistema y los dispositivos conectados a ellos. Utiliza la base de datos de hardware de udev para asociar un nombre completo legible por humanos con el ID del proveedor y el ID del producto.

OPCIONES

-v, --verbose
Indica a lsusb que sea detallado y muestre información detallada sobre los dispositivos mostrados. Esto incluye descriptores de configuración para la velocidad actual del dispositivo. Se mostrarán descriptores de clase, cuando estén disponibles, para las clases de dispositivos USB, incluyendo concentradores (hub), audio, HID, comunicaciones y tarjetas inteligentes (chipcard). Se puede usar con la opción -t.
-s [[bus]:][devnum]
Muestra solo dispositivos en el bus y/o devnum especificado. Ambos IDs se dan en decimal y pueden omitirse.
-d [vendor]:[product]
Muestra solo dispositivos con el ID de proveedor y producto especificado. Ambos IDs se dan en hexadecimal.
-D dispositivo
No escanea el directorio /dev/bus/usb, en su lugar, muestra solo información sobre el dispositivo cuyo archivo de dispositivo se proporciona. El archivo de dispositivo debe ser algo como /dev/bus/usb/001/001. Esta opción muestra información detallada como la opción -v; debes ser root para hacer esto.
-t, --tree
Indica a lsusb que muestre la jerarquía física de dispositivos USB como un árbol. La verbosidad se puede aumentar dos veces con la opción -v.
-V, --version
Imprime información de la versión en la salida estándar y luego sale exitosamente.

VALOR DE RETORNO

Si no se encuentra el dispositivo especificado, se devuelve un código de salida distinto de cero.

VER TAMBIÉN

lspci(8), usbview(8).
