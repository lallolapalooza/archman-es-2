LSHW(1) LSHW(1)

NOMBRE

lshw - listar hardware

SINOPSIS

lshw [ -version ]

lshw [ -help ]

lshw [ -X ]

lshw [ [ -html ] [ -short ] [ -xml ] [ -json ] [ -businfo ] ] [ -dump archivo ] [ -class clase... ] [ -disable prueba... ] [ -enable prueba... ] [ -sanitize ] [ -numeric ] [ -quiet ] [ -notime ]

DESCRIPCIÓN

lshw es una pequeña herramienta para extraer información detallada sobre la configuración de hardware de la máquina. Puede reportar la configuración exacta de memoria, versión de firmware, configuración de placa base, versión y velocidad de CPU, configuración de caché, velocidad del bus, etc. en sistemas x86 o IA-64 compatibles con DMI y en algunas máquinas PowerPC (PowerMac G4 se sabe que funciona).

Actualmente soporta DMI (solo x86 e IA-64), árbol de dispositivos OpenFirmware (solo PowerPC), PCI/AGP, CPUID (x86), IDE/ATA/ATAPI, PCMCIA (solo probado en x86), SCSI y USB.

-version
Muestra la versión de lshw y sale.
-help
Muestra las opciones de línea de comandos disponibles y sale.
-X
Inicia la GUI X11 (si está disponible).
-html
Genera el árbol de dispositivos como una página HTML.
-xml
Genera el árbol de dispositivos como un árbol XML.
-json
Genera el árbol de dispositivos como un objeto JSON (JavaScript Object Notation).
-short
Genera el árbol de dispositivos mostrando las rutas del hardware, muy parecido a la salida de ioscan de HP-UX.
-businfo
Genera la lista de dispositivos mostrando información del bus, detallando las direcciones SCSI, USB, IDE y PCI.
-dump archivo
Muestra la salida y guarda la información recopilada en un archivo (base de datos SQLite).
-class clase
Solo muestra la clase de hardware dada. La clase se puede encontrar usando lshw -short o lshw -businfo.
-C clase
Alias para -class clase.
-enable prueba
-disable prueba
Habilita o deshabilita una prueba. La prueba puede ser dmi (para extensiones DMI/SMBIOS), device-tree (para árbol de dispositivos OpenFirmware), spd (para la detección de presencia en serie de memoria), memory (para heurísticas de estimación del tamaño de memoria), cpuinfo (para detección de CPU reportada por el kernel), cpuid (para detección de CPU), pci (para acceso PCI/AGP), isapnp (para extensiones ISA PnP), pcmcia (para PCMCIA/PCCARD), ide (para IDE/ATAPI), usb (para dispositivos USB), scsi (para SCSI) o network (para detección de interfaces de red).
-quiet
No mostrar estado.
-sanitize
Elimina información potencialmente sensible de la salida (direcciones IP, números de serie, etc.).
-numeric
También muestra IDs numéricos (para dispositivos PCI y USB).
-notime
Excluye atributos volátiles (marcas de tiempo) de la salida.

ERRORES

lshw actualmente no detecta dispositivos Firewire (IEEE1394).

No todas las arquitecturas soportadas por GNU/Linux están completamente soportadas (por ejemplo, detección de CPU).

Las interfaces SCSI "virtuales" utilizadas para la emulación SCSI sobre IDE aún no se reportan correctamente.

NOTAS

lshw debe ejecutarse como superusuario o solo informará información parcial.

ARCHIVOS

/usr/local/share/pci.ids
/usr/share/pci.ids
/etc/pci.ids
/usr/share/hwdata/pci.ids
Una lista de todos los ID PCI conocidos (vendedores, dispositivos, clases y subclases). Si se compila con soporte zlib, lshw buscará primero pci.ids.gz, y luego pci.ids.
/proc/bus/pci/*
Se utiliza para acceder a la configuración de los buses y dispositivos PCI instalados.
/proc/ide/*
Se utiliza para acceder a la configuración de los buses y dispositivos IDE instalados.
/proc/scsi/*, /dev/sg*
Se utiliza para acceder a la configuración de los dispositivos SCSI instalados.
/dev/cpu/*/cpuid
Se utiliza en plataformas x86 para acceder a la configuración específica de la CPU.
/proc/device-tree/*
Se utiliza en plataformas PowerPC para acceder a la configuración de OpenFirmware.
/proc/bus/usb/*
Se utiliza para acceder a la configuración de los buses y dispositivos USB instalados.
/sys/*
Se utiliza en kernels 2.6 para acceder a la información de configuración de hardware/controladores.

EJEMPLOS

lshw -short
Lista el hardware en un formato compacto.
lshw -class disk -class storage
Lista todos los discos y controladores de almacenamiento en el sistema.
lshw -html -class network
Lista todas las interfaces de red en formato HTML.
lshw -disable dmi
No usar DMI para detectar hardware.
