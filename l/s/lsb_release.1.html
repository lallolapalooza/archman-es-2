NOMBRE

FSG - página del manual para FSG lsb_release v2.0

SINOPSIS

lsb_release [OPCIÓN]...

DESCRIPCIÓN

FSG lsb_release v2.0 imprime información LSB (Linux Standard Base) y de Distribución.

Sin especificar ninguna OPCIÓN, por defecto se usa -v.

OPCIONES

-v, --version

Muestra la versión de la especificación LSB con la que es compatible la distribución.

-i, --id

Muestra el identificador de cadena del distribuidor.

-d, --description

Muestra la descripción de texto de una sola línea de la distribución.

-r, --release

Muestra el número de versión de la distribución.

-c, --codename

Muestra el nombre en clave según la versión de la distribución.

-a, --all

Muestra toda la información anterior.

-s, --short

Usa el formato de salida corto para la información solicitada por otras opciones (o versión si no hay ninguna).

-h, --help

Muestra este mensaje.

ARCHIVOS

Si la instalación cumple con LSB, el archivo "/etc/lsb-release" debería contener el campo LSB_VERSION. El valor del campo debería ser una lista separada por dos puntos de versiones de módulos compatibles que indiquen los módulos de la especificación LSB con los que la instalación es compatible. Si la instalación no es compatible, el campo anterior no debería estar presente.

Los campos opcionales son DISTRIB_ID, DISTRIB_RELEASE, DISTRIB_CODENAME, DISTRIB_DESCRIPTION y pueden usarse para anular la información que se analiza del archivo "/etc/distrib-release".

Si existe el directorio "/etc/lsb-release.d", se buscarán nombres de archivo que se tomarán como cadenas adicionales de módulo-versión para añadir a LSB_VERSION.

El archivo "/etc/distrib-release" contiene una línea de descripción que se analiza para obtener información (especialmente en sistemas actualmente no compatibles con LSB).

El estilo de línea requerido es:
"Distribuidor release x.x (NombreEnClave)"

Donde Distribuidor puede ser un par de palabras, pero luego se concatenan (es decir, Linux Foo BarLinux Linux -> FooBarLinux),
x.x comienza con un dígito seguido de cualquier carácter que no sea espacio en blanco, NombreEnClave también se concatenará (solo limpieza de espacios en blanco).

release no puede usarse como palabra clave en DISTRIB_DESCRIPTION si no desea anular los datos de "/etc/distrib-release".

Aviso: Para admitir la falta de información en las distribuciones Debian (ver el archivo "/etc/debian_version"), algunas se han añadido directamente al script lsb_release.

EJEMPLOS

Si el archivo "/etc/lsb-release" contiene:

LSB_VERSION="core-2.0-ia64:core-2.0-noarch"
DISTRIB_DESCRIPTION="Me gusta usar mi distrib"

y el directorio "/etc/lsb-release.d" contiene:

graphics-2.0-ia64 graphics-2.0-noarch

y el archivo "/etc/foobar-release" contiene:

Mi Linux Distrib release 1.0RC4 (Pruébalo)

Entonces los resultados de varias opciones serán:

$ ./lsb_release --all
Versión LSB: core-2.0-ia64:core-2.0-noarch:graphics-2.0-ia64:graphics-2.0-noarch
ID del Distribuidor: MiDistrib
Descripción: Me gusta usar mi distrib
Versión: 1.0RC4
Nombre en clave: Pruébalo

$ ./lsb_release -a -s
1.0 MiDistrib "Me gusta usar mi distrib" 1.0RC4 Pruébalo

Si el archivo "/etc/lsb-release" está ausente (lo que indica que esta no es una distribución compatible con LSB), el resultado será:

$ ./lsb_release -a
Versión LSB: n/a
ID del Distribuidor: MiDistrib
Descripción: Mi Linux Distrib release 1.0RC4 (Pruébalo)
Versión: 1.0RC4
Nombre en clave: Pruébalo

REPORTE DE ERRORES

Reporte errores en http://bugs.linuxbase.org. Por favor, incluya un ejemplo completo y autocontenido que permita reproducir el error, y mencione qué versión de lsb_release está utilizando.
