NOMBRE

lsfd - listar descriptores de archivo

SINOPSIS

lsfd [opción]

DESCRIPCIÓN

lsfd pretende ser un reemplazo moderno para lsof(8) en sistemas Linux. A diferencia de lsof, lsfd está especializado para el kernel de Linux; soporta características específicas de Linux como namespaces con un código más simple. lsfd no es un reemplazo directo para lsof; son diferentes en la interfaz de línea de comandos y en los formatos de salida.

La salida predeterminada está sujeta a cambios. Por lo tanto, siempre que sea posible, debes evitar usar las salidas predeterminadas en tus scripts. Define siempre explícitamente las columnas esperadas usando --output lista-de-columnas en entornos donde se requiera una salida estable.

lsfd utiliza Libsmartcols para el formato de salida y el filtrado. Consulta la descripción de la opción --output para personalizar el formato de salida, y la opción --filter para el filtrado. Usa lsfd --list-columns para obtener una lista de todas las columnas disponibles.

OPCIONES

-l, --threads

Listar a nivel de hilos.

-J, --json

Usar formato de salida JSON.

-n, --noheadings

No imprimir encabezados.

-o, --output lista

Especificar qué columnas de salida imprimir. Consulta la sección COLUMNAS DE SALIDA para obtener detalles sobre las columnas disponibles.

La lista predeterminada de columnas puede extenderse si lista se especifica en el formato +lista (por ejemplo, lsfd -o +DELETED).

-r, --raw

Usar formato de salida raw (crudo).

--notruncate

No truncar texto en las columnas.

-p, --pid pids

Recopilar información solo para los procesos especificados. pids es una lista de pids. Se pueden usar comas o espacios como separadores. Puedes usar esta opción con pidof(1). Consulta EJEMPLOS DE FILTRADO.

Tanto la opción -Q con una expresión que incluye PID, por ejemplo -Q (PID == 1), como la opción -p, por ejemplo -p 1, pueden imprimir la misma salida, pero usar la opción -p es mucho más eficiente porque la opción -p funciona en una etapa mucho más temprana del procesamiento que la opción -Q.

-i[4|6], --inet[=4|=6]

Listar solo sockets IPv4 y/o IPv6.

-Q, --filter expr

Imprimir solo los archivos que coincidan con la condición representada por la expr. Consulta también scols-filter(5) y EJEMPLOS DE FILTRADO.

-C, --counter etiqueta:expr_filtro

Definir un contador personalizado utilizado en la salida --summary. lsfd crea un contador llamado etiqueta. Durante la recopilación de información, lsfd cuenta los archivos que coinciden con expr_filtro y almacena el número contado en el contador llamado etiqueta. lsfd aplica los filtros definidos con las opciones --filter antes de contar; los archivos excluidos por los filtros no se cuentan.

Consulta scols-filter(5) sobre expr_filtro. etiqueta no debe incluir { ni :. Puedes definir múltiples contadores especificando esta opción varias veces.

Consulta también EJEMPLOS DE CONTADORES.

--summary[=cuándo]

Esta opción controla la salida de las líneas de resumen. El argumento opcional cuándo puede ser only, append o never. Si se omite el argumento cuándo, el valor predeterminado es only.

El resumen informa sobre los contadores. Un contador consta de una etiqueta y un valor entero. --counter es la opción para definir un contador. Si el usuario no define ningún contador, lsfd utiliza las definiciones de los contadores incorporados predefinidos (contadores predeterminados) para generar la salida del resumen.

PRECAUCIÓN: Usar --summary y --json puede hacer que la salida sea incorrecta. Solo combinar --summary=only y --json es válido.

--debug-filter

Volcar la estructura de datos interna para el filtro y salir. Esto es útil solo para los desarrolladores de lsfd.

--dump-counters

Volcar la definición de los contadores utilizados en la salida --summary.

--hyperlink[=modo]

Imprimir rutas como hipervínculos de terminal. El modo puede establecerse en "always", "never", o "auto". El argumento opcional cuándo puede establecerse en "auto", "never", o "always". Si se omite el argumento cuándo, el valor predeterminado será "auto". La configuración "auto" significa que los hipervínculos solo se usarán si la salida está en una terminal.

-H, --list-columns

Listar las columnas disponibles que puedes especificar en la opción --output.

-h, --help

Mostrar el texto de ayuda y salir.

-V, --version

Mostrar la versión y salir.

List files associated with PID 1 and PID 2 processes: .RS .ipp . .nf # lsfd -Q '(PID == 1) or (PID == 2)' .fi . .ipp . .nf # lsfd -Q '(PID == 1) || (PID == 2)' .fi . .ipp . .nf # lsfd --pid 1,2 .fi . Whitespaces can be used instead of a comma: .RS .ipp . .nf # lsfd --pid '1 2' .fi . Utilize .BR pidof(1) for list the files associated with "firefox": .RS .ipp . .nf # lsfd --pid "$(pidof firefox)" .fi . List the 1st file descriptor opened by PID 1 process: .RS .ipp . .nf # lsfd -Q '(PID == 1) and (FD == 1)' .fi . .ipp . .nf # lsfd -Q '(PID == 1) && (FD == 1)' .fi . List all running executables: .RS .ipp . .nf # lsfd -Q 'ASSOC == "exe"' .fi . .ipp . .nf # lsfd -Q 'ASSOC eq "exe"' .fi . Do the same but print only file names: .RS .ipp . .nf # lsfd -o NAME -Q 'ASSOC eq "exe"' | sort -u .fi . List deleted files associated to processes: .RS .ipp . .nf # lsfd -Q 'DELETED' .fi . List non-regular files: .RS .ipp . .nf # lsfd -Q 'TYPE != "REG"' .fi . List block devices: .RS .ipp . .nf # lsfd -Q 'DEVTYPE == "blk"' .fi . .ipp . .nf # lsfd -Q 'TYPE == "BLK"' .fi . List files including "dconf" directory in their names: .RS .ipp . .nf # lsfd -Q 'NAME =~ ".*/dconf/.*"' .fi . List files opened in a QEMU virtual machine: .RS .ipp . .nf # lsfd -Q '(COMMAND =~ ".*qemu.*") and (FD >= 0)' .fi . List timerfd files expired within 0.5 seconds: .RS .ipp . .nf # lsfd -Q '(TIMERFD.remaining < 0.5) and (TIMERFD.remaining > 0.0)' .fi . List processes communicating via unix stream sockets: .RS .ipp . .nf # lsfd -Q 'TYPE == "UNIX-STREAM" && UNIX.PATH =~ ".+"' -oUNIX.PATH,PID,COMMAND,FD,SOCK.STATE,ENDPOINTS .fi . List processes communicating via a specified unix stream socket: .RS .ipp . .nf # lsfd -Q 'TYPE == "UNIX-STREAM" && UNIX.PATH == "@/tmp/.X11-unix/X0"' -oUNIX.PATH,PID,COMMAND,FD,SOCK.STATE,ENDPOINTS .fi . .SH COUNTER EXAMPLES Report the numbers of netlink socket descriptors and unix socket descriptors: .RS .ipp . .nf # lsfd --summary=only \ -C 'netlink sockets':'(NAME =~ "NETLINK:.*")' \ -C 'unix sockets':'(NAME =~ "UNIX:.*")' VALUE COUNTER 57 netlink sockets 1552 unix sockets .fi . Do the same but print in JSON format: .RS .ipp . .nf # lsfd --summary=only --json \ -C 'netlink sockets':'(NAME =~ "NETLINK:.*")' \ -C 'unix sockets':'(NAME =~ "UNIX:.*")' { "lsfd-summary": [ { "value": 15, "counter": "netlink sockets" },{ "value": 798, "counter": "unix sockets" } ] } .fi . .SH HISTORY The .B lsfd command is part of the util-linux package since v2.38. .SH AUTHORS . .TP .I Masatake YAMATO <yamato@redhat.com>, .TP .I Karel Zak <kzak@redhat.com> .SH SEE ALSO .BR bpftool (8), bpstools (8), lslocks (8), lsof (8), pidof (1), proc (5), scols-filter (5), socket (2), ss (8), stat (2), vsock (7) .SH REPORTING BUGS For bug reports, use the .IR issue tracker . .SH AVAILABILITY The .B lsfd command is part of the util-linux package which can be downloaded from .IR Linux Kernel Archive . . .TH LSFD 8 "2025-09-22" "util-linux 2.41.2" "lsfd"
