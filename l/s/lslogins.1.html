LSLOGINS(1) Comandos de usuario LSLOGINS(1)

NOMBRE

lslogins - muestra información sobre usuarios conocidos en el sistema

SINOPSIS

lslogins [opciones] [-s|-u[=UID]] [-g grupos] [-l accesos] [nombre_usuario]

DESCRIPCIÓN

Examina los registros wtmp y btmp, /etc/shadow (si es necesario) y /passwd y muestra los datos deseados.

El argumento opcional nombre_usuario obliga a lslogins a mostrar todos los detalles disponibles solo sobre el usuario especificado. En este caso, el formato de salida es diferente que en el caso de -l o -g y se informa de un nombre_usuario desconocido como un error.

La acción predeterminada es listar información sobre todos los usuarios del sistema.

OPCIONES

Los argumentos obligatorios para las opciones largas también son obligatorios para las opciones cortas.

-a, --expiracion-cuenta

Muestra datos sobre la fecha del último cambio de contraseña y la fecha de expiración de la cuenta (ver shadow(5) para más información). (Requiere privilegios de root.)

--archivo-btmp ruta

Ruta alternativa para btmp.

-c, --separado-por-dos-puntos

Separa la información de cada usuario con dos puntos en lugar de una nueva línea.

-e, --exportar

Muestra los datos en el formato NOMBRE=VALOR. Ver también la opción --shell.

-f, --fallidos

Muestra datos sobre los últimos intentos de inicio de sesión fallidos de los usuarios.

-G, --grupos-suplementarios

Muestra información sobre grupos suplementarios.

-g, --grupos grupos

Solo muestra datos de usuarios que pertenecen a grupos. Se pueden especificar varios grupos; la lista debe estar separada por comas. Los nombres de grupo desconocidos se ignoran.

Tenga en cuenta que la relación entre usuario y grupo puede ser invisible para el grupo principal si el usuario no está explícitamente especificado como miembro del grupo (por ejemplo, en /etc/group). Si el comando lslogins busca grupos, solo utiliza la base de datos de grupos, y la base de datos de usuarios con GID principal no se utiliza en absoluto.

-L, --ultimo

Muestra datos que contienen información sobre las últimas sesiones de inicio de sesión de los usuarios.

-l, --accesos accesos

Solo muestra datos de usuarios con un acceso especificado en accesos (nombres de usuario o IDs de usuario). Se pueden especificar varios accesos; la lista debe estar separada por comas. Los nombres de acceso desconocidos se ignoran.

-n, --nueva-linea

Muestra cada dato de información en una línea separada.

--sin-encabezados

No imprime una línea de encabezado.

--no-truncar

No trunca la salida.

-o, --salida lista

Especifica qué columnas de salida imprimir. La lista de columnas predeterminada puede extenderse si se especifica lista en el formato +lista.

--salida-todo

Muestra todas las columnas disponibles. --ayuda para obtener una lista de todas las columnas compatibles.

-p, --contraseña

Muestra información relacionada con el inicio de sesión por contraseña (ver también -afL).

-r, --crudo

Salida cruda (sin formato de columnas).

-s, --cuentas-sistema

Muestra cuentas del sistema. Estas son por defecto todas las cuentas con un UID entre 101 y 999 (inclusive), con la excepción de nobody o nfsnobody (UID 65534). Este valor predeterminado codificado puede ser sobrescrito por los parámetros SYS_UID_MIN y SYS_UID_MAX en el archivo /etc/login.defs.

--formato-tiempo tipo

Muestra fechas en formato corto, completo o iso. El predeterminado es corto, este formato de tiempo está diseñado para ser eficiente en espacio y legible por humanos.

-u, --cuentas-usuario

Muestra cuentas de usuario. Estas son por defecto todas las cuentas con UID superior a 1000 (inclusive), con la excepción de nobody o nfsnobody (UID 65534). Este valor predeterminado codificado puede ser sobrescrito por los parámetros UID_MIN y UID_MAX en el archivo /etc/login.defs.

-h, --ayuda

Muestra el texto de ayuda y sale.

-V, --version

Muestra la versión y sale.

--archivo-wtmp ruta

Ruta alternativa para wtmp.

--archivo-lastlog ruta

Ruta alternativa para lastlog(8).

-y, --shell

El nombre de la columna se modificará para contener solo caracteres permitidos para identificadores de variables de shell. Esto es utilizable, por ejemplo, con --exportar. Tenga en cuenta que esta característica se habilitó automáticamente para --exportar en la versión 2.37, pero debido a problemas de compatibilidad, ahora es necesario solicitar este comportamiento mediante --shell.

-Z, --contexto

Muestra el contexto de seguridad de los usuarios.

-z, --imprimir0

Delimita las entradas de usuario con un carácter nulo, en lugar de una nueva línea.

ESTADO DE SALIDA

0

si OK,

1

si se especificaron argumentos incorrectos,

2

si ocurre un error grave (por ejemplo, un registro corrupto).

NOTAS

Los umbrales predeterminados de UID se leen de /etc/login.defs.

Estado de contraseña

Múltiples campos describen el estado de la contraseña.

"Contraseña bloqueada"

La contraseña está prefijada por '!!', y el usuario no puede iniciar sesión aunque la contraseña esté configurada o vacía. Esto es común para cuentas nuevas sin contraseña configurada.

"Contraseña no requerida (vacía)"

La contraseña no está configurada (falta el hash); esto es común para cuentas de sistema bloqueadas. No requerir una contraseña no significa que el usuario pueda iniciar sesión sin contraseña. Depende del estado de "bloqueo" de la contraseña.

"Inicio de sesión por contraseña deshabilitado"

'yes' significa que no hay una contraseña válida. Falta el hash de la contraseña, o el método de hash es desconocido o contiene caracteres inválidos.

HISTORIA

La utilidad lslogins está inspirada en la utilidad logins, que apareció por primera vez en FreeBSD 4.10.
