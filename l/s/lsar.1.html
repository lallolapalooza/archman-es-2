LSAR(1) Comandos de usuario LSAR(1)

NOMBRE

lsar - listar contenido de archivos de archivo

SINOPSIS

lsar [OPCIÓN]... ARCHIVO...

DESCRIPCIÓN

Lista el contenido de los ARCHIVOs.

OPCIONES

-l, -long
Imprime más información sobre cada archivo en el archivo.
-L, -verylong
Imprime toda la información disponible sobre cada archivo en el archivo.
-t, -test
Prueba la integridad de los archivos en el archivo, si es posible.
-p, -password CONTRASEÑA
La contraseña a usar para descifrar archivos protegidos.
-e, -encoding CODIFICACIÓN
La codificación a usar para los nombres de archivo en el archivo, cuando no se conoce. Si no se especifica, el programa intenta detectar automáticamente la codificación utilizada. Use "help" o "list" como argumento para obtener una lista de todas las codificaciones admitidas.
-E, -password-encoding CODIFICACIÓN
La codificación a usar para la contraseña del archivo, cuando no se conoce. Si no se especifica, se utiliza la codificación dada por la opción -encoding o la codificación detectada automáticamente.
-pe, -print-encoding
Imprime la codificación detectada automáticamente y el factor de confianza después de la lista de archivos.
-i, -indexes
En lugar de especificar los archivos a listar como nombres de archivo o patrones comodín, especifícalos como índices.
-j, -json
Imprime la lista en formato JSON.
-ja, -json-ascii
Imprime la lista en formato JSON, codificado como texto ASCII puro.
-nr, -no-recursion
No intentes listar el contenido de los archivos contenidos en otros archivos. Por ejemplo, al listar un archivo .tar.gz, solo lista el archivo .tar y no su contenido.
-h, -help
Muestra información de ayuda.
-v, -version
Imprime la versión y sale.
