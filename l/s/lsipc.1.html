LSIPC(1) Comandos de usuario LSIPC(1)

NOMBRE

lsipc - mostrar información sobre las facilidades de IPC empleadas actualmente en el sistema

SINOPSIS

lsipc [opciones]

DESCRIPCIÓN

lsipc muestra información sobre las facilidades de comunicación entre procesos (IPC) POSIX y System V para las cuales el proceso que llama tiene acceso de lectura.

La salida predeterminada, así como la salida predeterminada de las opciones con columnas de salida predefinidas (como --shmems, etc.), está sujeta a cambios. Por lo tanto, siempre que sea posible, debe evitar usar salidas predeterminadas en sus scripts. Defina siempre explícitamente las columnas esperadas utilizando --output lista-de-columnas en entornos donde se requiera una salida estable.

OPCIONES

-i, --id id

Muestra detalles completos de un solo elemento de recurso (System V) identificado por id. Esta opción debe combinarse con una de las tres opciones de recurso: -m, -q o -s. Es posible anular el formato de salida predeterminado para esta opción con la opción --list, --raw, --json o --export.

-N, --name nombre

Muestra detalles completos de un solo elemento de recurso (POSIX) identificado por nombre. Esta opción debe combinarse con una de las tres opciones de recurso: -M, -Q o -S. Es posible anular el formato de salida predeterminado para esta opción con la opción --list, --raw, --json o --export.

-g, --global

Muestra el uso y los límites a nivel de sistema de los recursos IPC. Esta opción puede combinarse con una de las tres opciones de recurso: -m, -q o -s. El valor predeterminado es mostrar información sobre todos los recursos.

-h, --help

Muestra el texto de ayuda y sale.

-V, --version

Muestra la versión y sale.

Opciones de recurso

-m, --shmems

Escribe información sobre los segmentos de memoria compartida activos de System V.

-M, --posix-shmems

Escribe información sobre los segmentos de memoria compartida activos de POSIX.

-q, --queues

Escribe información sobre las colas de mensajes activas de System V.

-Q, --posix-mqueues

Escribe información sobre las colas de mensajes activas de POSIX.

-s, --semaphores

Escribe información sobre los conjuntos de semáforos activos de System V.

-S, --posix-semaphores

Escribe información sobre los semáforos con nombre activos de POSIX.

Formato de salida

-c, --creator

Muestra el creador y el propietario.

-e, --export

Produce salida en forma de pares clave="valor". Todos los caracteres de valor potencialmente inseguros se escapan en hexadecimal (\x<código>). Ver también la opción --shell.

-J, --json

Utiliza el formato de salida JSON.

-l, --list

Utiliza el formato de salida de lista. Este es el valor predeterminado, excepto cuando se utiliza --id.

-n, --newline

Muestra cada pieza de información en una línea separada.

--noheadings

No imprime una línea de encabezado.

--notruncate

No trunca la salida.

-o, --output lista

Especifica qué columnas de salida imprimir. Utilice --help para obtener una lista de todas las columnas admitidas.

-b, --bytes

Imprime el tamaño en bytes en lugar de en formato legible por humanos.

-r, --raw

Salida sin formato (sin columnas).

-t, --time

Escribe información de tiempo. La hora de la última operación de control que cambió los permisos de acceso para todas las facilidades, la hora de las últimas operaciones msgsnd(2) y msgrcv(2) en las colas de mensajes, la hora de las últimas operaciones shmat(2) y shmdt(2) en la memoria compartida, y la hora de la última operación semop(2) en los semáforos.

--time-format tipo

Muestra las fechas en formato corto, completo o iso. El valor predeterminado es corto, este formato de tiempo está diseñado para ser eficiente en espacio y legible por humanos.

-P, --numeric-perms

Imprime los permisos numéricos en la columna PERMS.

-y, --shell

El nombre de la columna se modificará para que contenga solo caracteres permitidos para identificadores de variables de shell. Esto es utilizable, por ejemplo, con --export. Tenga en cuenta que esta función se habilitó automáticamente para --export en la versión 2.37, pero debido a problemas de compatibilidad, ahora es necesario solicitar este comportamiento con --shell.

ESTADO DE SALIDA

0

si OK,

1

si se especificaron argumentos incorrectos,

2

si ocurre un error grave.

NOMBRE

lsipc - mostrar información sobre IPC

SINOPSIS

DESCRIPCIÓN

lsipc muestra información sobre los recursos de comunicación entre procesos (IPC).

OPCIONES

Sin opciones, lsipc muestra información sobre las colas de mensajes, memoria compartida y semáforos.

-m, --shmems
Mostrar información sobre memoria compartida.
-s, --semaphores
Mostrar información sobre semáforos.
-q, --queues
Mostrar información sobre colas de mensajes.
-l, --listening
Mostrar sockets que están escuchando.
-a, --all
Mostrar toda la información de IPC.
-p, --processes
Mostrar información sobre los procesos que crearon los recursos de IPC.
-u, --users
Mostrar información sobre los usuarios que crearon los recursos de IPC.
-h, --help
Mostrar mensaje de ayuda y salir.
-V, --version
Mostrar información sobre la versión y salir.

ESTADO DE SALIDA

Devuelve 0 si la ejecución es exitosa, o un valor distinto de cero en caso de error.

HISTORIA

Este comando está disponible desde version 2.32 de util-linux.

AUTORES

Escrito por Karel Zak y otros.
