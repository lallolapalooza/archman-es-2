NOMBRE

lsrealm - Lista los ámbitos en un archivo de ámbitos de DNSSEC-Tools

SINOPSIS

lsrealm [opciones] <archivos-de-ámbito>

DESCRIPCIÓN

Este script lista el contenido de los archivos de ámbito especificados. Todos los archivos de ámbito se cargan antes de mostrar la salida. Si algún ámbito tiene nombres duplicados, ya sea dentro de un archivo o entre varios archivos, el ámbito posterior será el que muestre sus datos.

La salida que se muestra para cada ámbito en un archivo de ámbito depende de los registros seleccionados, los atributos seleccionados y el formato de salida seleccionado. Cada opción de estos grupos de opciones se describe en detalle en la siguiente sección. Los tres formatos de salida base se describen aquí.

La opción -terse indica que se desea una cantidad mínima de salida; la opción -long indica que se desea una gran cantidad de salida. Las opciones de selección de registros y selección de atributos se pueden usar en conjunto con -terse para mostrar exactamente el conjunto de campos de ámbito necesarios.

El formato de salida predeterminado es el que se usa cuando no se proporciona ni -terse ni -long, y es un punto intermedio entre la salida concisa y la larga.

La siguiente tabla muestra los campos mostrados para cada formato de salida.

campo del ámbito      predeterminado        conciso        largo
-----------------      ------------        -------        -----
nombre del ámbito         sí               sí            sí
estado                    sí               no            sí
directorio de config      no               no            sí
directorio del ámbito     no               no            sí
archivo de rollrec        no               no            sí
administrador             no               no            sí
directorio                no               no            sí
bandera de visualización  no               no            sí
gestor                    no               no            sí
argumentos del gestor     no               no            sí
usuario                   no               no            sí

OPCIONES

Hay tres tipos de opciones reconocidas por lsrealm: opciones de selección de registros, opciones de selección de atributos y opciones de formato de salida. Cada tipo se describe en las subsecciones siguientes.

Opciones de selección de registros

Estas opciones seleccionan los registros que mostrará lsrealm. Por defecto, se mostrarán todos los registros; la selección de una u otra de estas opciones restringirá los registros mostrados.

Estas opciones son mutuamente excluyentes.

-active
Lista todos los registros activos en el archivo de ámbito.
-inactive
Lista todos los registros inactivos en el archivo de ámbito.

Opciones de selección de atributos

Estas opciones seleccionan los atributos de los registros que mostrará lsrealm.

-admin
Se incluye en la salida el valor del administrador del registro. Si el valor del administrador no está incluido en un ámbito, se proporcionará el valor "(defadmin)".
-args
Argumentos definidos por el usuario del registro para el gestor de rotación del ámbito.
-configdir
Se incluye en la salida el directorio de configuración del registro. Este valor será solo el nombre del archivo, a menos que se proporcione la opción -fullpaths. En ese caso, se imprimirá la ruta completa.
-display
Se incluye en la salida la bandera de visualización del registro, utilizada por grandvizier.
-manager
El campo gestor del registro, que indica qué gestor de rotación se utiliza para el ámbito. El valor predeterminado es rollerd, pero las instalaciones individuales pueden usar otros gestores.
-realmdir
Se incluye en la salida el directorio del ámbito del registro. Este valor será solo el nombre del archivo, a menos que se proporcione la opción -fullpaths. En ese caso, se imprimirá la ruta completa.
-rollrec
Se incluye en la salida el archivo rollrec del registro. Este valor será solo el nombre del archivo, a menos que se proporcione la opción -fullpaths. En ese caso, se imprimirá la ruta completa.
-state
Incluye el estado de cada registro de ámbito en la salida. El estado será "activo" o "inactivo". Este campo forma parte de la salida predeterminada.
-user
El campo de usuario del registro, que es el usuario con el que se ejecutará el gestor del ámbito. Este campo aún no está implementado.

Opciones de formato de salida

Estas opciones seleccionan el tipo de salida que proporcionará lsrealm.

-count
Solo se proporciona un recuento de los ámbitos coincidentes en el archivo de ámbito.
-fullpaths
Muestra los datos de la ruta como la ruta completa dada en el archivo de ámbito. Si no se especifica esta opción, solo se mostrará el nombre del archivo.
-headers
Muestra encabezados de columna explicativos.
-terse
Salida concisa. Solo se incluyen en la salida el nombre del registro y cualquier otro campo seleccionado específicamente.
-long
Salida larga. Se incluyen todos los campos del registro.
-help
Muestra un mensaje de uso.
-Version
Muestra la información de la versión de lsrealm y el paquete DNSSEC-Tools.
