LSCLOCKS(1) Comandos de usuario LSCLOCKS(1)

NOMBRE

lsclocks - mostrar relojes del sistema

SINOPSIS

lsclocks [opción]

DESCRIPCIÓN

lsclocks es un comando simple para mostrar los relojes del sistema.

Permite mostrar información como la hora actual y la resolución de relojes como CLOCK_MONOTONIC, CLOCK_REALTIME y CLOCK_BOOTTIME.

OPCIONES

-J, --json

Usar formato de salida JSON.

-n, --noheadings

No imprimir encabezados.

-o, --output lista

Especificar qué columnas de salida imprimir. Consulte la sección COLUMNAS DE SALIDA para obtener detalles de las columnas disponibles.

--output-all

Imprimir todas las columnas.

-r, --raw

Usar formato de salida crudo (raw).

-r, --time reloj

Mostrar la hora actual de un reloj específico.

--no-discover-dynamic

No intentar descubrir relojes dinámicos.

-d, --dynamic-clock ruta

Mostrar también el reloj dinámico especificado. Se puede especificar varias veces.

--no-discover-rtc

No intentar descubrir RTC.

-x, --rtc ruta

Mostrar también el RTC especificado. Se puede especificar varias veces.

-c, --cpu-clock pid

Mostrar también el reloj de CPU del proceso especificado. Se puede especificar varias veces.

-h, --help

Mostrar texto de ayuda y salir.

-V, --version

Mostrar versión y salir.

COLUMNAS DE SALIDA

Cada columna tiene un tipo. Los tipos están rodeados por < y >.

TYPE <string>

Tipo de reloj.

ID <number>

ID numérico del reloj.

CLOCK <string>

Nombre en formato CLOCK_

NAME <string>

Nombre más corto y fácil de leer.

TIME <number>

Marca de tiempo actual del reloj según lo devuelto por clock_gettime().

ISO_TIME <string>

Versión de TIME con formato ISO8601.

RESOL_RAW <number>

Resolución del reloj según lo devuelto por clock_getres(2).

RESOL <number>

Versión legible por humanos de RESOL_RAW.

REL_TIME <string>

Tiempo TIME formateado como un rango de tiempo.

NS_OFFSET <number>

Desplazamiento del espacio de nombres actual al espacio de nombres padre, leído desde /proc/self/timens_offsets.
