Paquete: patchutils

Licencias: GPL

LSDIFF(1) Páginas del manual LSDIFF(1)

NOMBRE

lsdiff - muestra qué archivos son modificados por un parche

SINOPSIS

lsdiff [[-n] | [--line-number]] [[-p n] | [--strip-match=n]] [--strip=n] [--addprefix=PREFIX] [[-s] | [--status]] [[-E] | [--empty-files-as-removed]] [[-i PATTERN] | [--include=PATTERN]] [[-x PATTERN] | [--exclude=PATTERN]] [[-z] | [--decompress]] [[-# RANGE] | [--hunks=RANGE]] [--lines=RANGE] [[-FRANGE] | [--files=RANGE]] [[-H] | [--with-filename]] [[-h] | [--no-filename]] [[-v] | [--verbose]...] [archivo...]

lsdiff {[--help] | [--version] | [--filter ...] | [--grep ...]}

DESCRIPCIÓN

Lista los archivos modificados por un parche.

Puedes usar formatos de diferencias unificados y de contexto con este programa.

OPCIONES

-n, --line-number

Muestra el número de línea donde comienza cada parche. Si se solicita salida detallada (usando -nv), cada "hunk" (trozo) de cada parche se lista también.

Para cada archivo que se modifica, se genera una línea que contiene el número de línea del inicio del parche, seguido de un carácter de tabulación, seguido del nombre del archivo que se modifica. Si se da -v una vez, siguiendo cada una de estas líneas habrá una línea por cada "hunk", consistente en un carácter de tabulación, el número de línea donde comienza el "hunk", otra tabulación, la cadena "Hunk #", y el número del "hunk" (comenzando en 1).

Si se da -v dos veces en conjunción con -n (es decir, -nvv), el formato es ligeramente diferente: se muestra texto descriptivo a nivel de "hunk" después de cada número de "hunk", y se habilita la opción --number-files.

-N, --number-files

Se enumeran los archivos, comenzando en 1, antes de cada nombre de archivo.

-# RANGO, --hunks=RANGO

Solo lista los "hunks" dentro del RANGO especificado. Los "hunks" se numeran a partir de 1, y el rango es una lista separada por comas de números o tramos "primero-último", opcionalmente precedido por un modificador 'x' que invierte todo el rango; se puede omitir el primero o el último del tramo para indicar sin límite en esa dirección.

--lines=RANGO

Solo lista los "hunks" que contienen líneas del archivo original que se encuentran dentro del RANGO especificado. Las líneas se numeran a partir de 1, y el rango es una lista separada por comas de números o tramos "primero-último", opcionalmente precedido por un modificador 'x' que invierte todo el rango; se puede omitir el primero o el último del tramo para indicar sin límite en esa dirección.

-F=RANGO, --files=RANGO

Solo lista los archivos indicados por el RANGO especificado. Los archivos se numeran a partir de 1 en el orden en que aparecen en la entrada del parche, y el rango es una lista separada por comas de números o tramos "primero-último", opcionalmente precedido por un modificador 'x' que invierte todo el rango; se puede omitir el primero o el último del tramo para indicar sin límite en esa dirección.

-p n, --strip-match=n

Al coincidir, ignora los primeros n componentes de la ruta del archivo.

--strip=n

Elimina los primeros n componentes de la ruta del archivo antes de mostrarla.

--addprefix=PREFIX

Antepone el prefijo PREFIX a la ruta del archivo antes de mostrarla.

-s, --status

Muestra adiciones, modificaciones y eliminaciones de archivos. Una adición de archivo se indica con un "+", una eliminación con un "-", y una modificación con un "!".

-E, --empty-files-as-removed

Trata los archivos vacíos como ausentes a efectos de mostrar adiciones, modificaciones y eliminaciones de archivos.

-i PATRÓN, --include=PATRÓN

Incluye solo archivos que coinciden con el PATRÓN.

-x PATRÓN, --exclude=PATRÓN

Excluye archivos que coinciden con el PATRÓN.

-z, --decompress

Descromprime archivos con extensiones .gz y .bz2.

-H, --with-filename

Imprime el nombre del archivo de parche que contiene cada parche.

-h, --no-filename

Suprime el nombre del archivo de parche que contiene cada parche.

-v, --verbose

Salida detallada.

--help

Muestra un breve mensaje de uso.

--version

Muestra el número de versión de lsdiff.

--filter

Compórtate como filterdiff(1) en su lugar.

--grep

Compórtate como grepdiff(1) en su lugar.

VER TAMBIÉN

filterdiff(1), grepdiff(1), patchview(1)

EJEMPLOS

Para ordenar el orden de los archivos tocados en un parche, puedes usar:

lsdiff parche | sort -u | \
  xargs -rn1 filterdiff parche -i

Para mostrar solo los archivos agregados en un parche:

lsdiff -s parche | grep '^+' | \
  cut -c2- | xargs -rn1 filterdiff parche -i

Para mostrar las cabeceras de todos los "hunks" de archivos:

lsdiff -n parche | (while read n file
  do sed -ne "$n,$(($n+1))p" parche
done)
