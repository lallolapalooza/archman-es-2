LS(1) Comandos de usuario LS(1)

NOMBRE

ls - lista el contenido de un directorio

SINOPSIS

ls [OPCIÓN]... [ARCHIVO]...

DESCRIPCIÓN

Lista información sobre los ARCHIVOS (el directorio actual por defecto). Ordena las entradas alfabéticamente si no se especifica ninguna de las opciones -cftuvSUX ni --sort.

Los argumentos obligatorios para las opciones largas son obligatorios también para las opciones cortas.

-a, --all
no ignora las entradas que empiezan por .
-A, --almost-all
no lista los implícitos . y ..
--author
con -l, imprime el autor de cada archivo
-b, --escape
imprime escapes estilo C para caracteres no gráficos
--block-size=TAMAÑO
con -l, escala los tamaños por TAMAÑO al imprimirlos; ej.: '--block-size=M'; ver el formato de TAMAÑO abajo
-B, --ignore-backups
no lista las entradas implícitas que terminan en ~
-c
con -lt: ordena por y muestra el ctime (tiempo del último cambio de información de estado del archivo); con -l: muestra el ctime y ordena por nombre; de lo contrario: ordena por ctime, el más reciente primero
-C
lista las entradas por columnas
--color[=CUÁNDO]
colorea la salida CUÁNDO; más información abajo
-d, --directory
lista los directorios mismos, no su contenido
-D, --dired
genera salida diseñada para el modo dired de Emacs
-f
igual que -a -U
-F, --classify[=CUÁNDO]
añade un indicador (uno de */=>@|) a las entradas CUÁNDO
--file-type
igual, excepto que no añade '*'
--format=PALABRA
across, horizontal (-x), comas (-m), largo (-l), una columna (-1), verboso (-l), vertical (-C)
--full-time
como -l --time-style=full-iso
-g
como -l, pero no lista el propietario
--group-directories-first
agrupa los directorios antes que los archivos
-G, --no-group
en un listado largo, no imprime los nombres de grupo
-h, --human-readable
con -l y -s, imprime tamaños como 1K 234M 2G etc.
--si
igual, pero usa potencias de 1000 en lugar de 1024
-H, --dereference-command-line
sigue los enlaces simbólicos listados en la línea de comandos
--dereference-command-line-symlink-to-dir
sigue cada enlace simbólico de la línea de comandos que apunta a un directorio
--hide=PATRÓN
no lista las entradas implícitas que coinciden con el PATRÓN de shell (anulado por -a o -A)
--hyperlink[=CUÁNDO]
enlaza los nombres de archivo CUÁNDO
--indicator-style=PALABRA
añade un indicador con el estilo PALABRA a los nombres de entrada: none (por defecto), slash (-p), file-type (--file-type), classify (-F)
-i, --inode
imprime el número de índice de cada archivo
-I, --ignore=PATRÓN
no lista las entradas implícitas que coinciden con el PATRÓN de shell
-k, --kibibytes
por defecto usa bloques de 1024 bytes para el uso del sistema de archivos; solo se usa con -s y totales por directorio
-l
usa un formato de listado largo
-L, --dereference
al mostrar información de archivo para un enlace simbólico, muestra información del archivo al que apunta el enlace en lugar del propio enlace
-m
llena el ancho con una lista de entradas separada por comas
-n, --numeric-uid-gid
como -l, pero lista los IDs numéricos de usuario y grupo
-N, --literal
imprime los nombres de entrada sin comillas
-o
como -l, pero no lista la información de grupo
-p, --indicator-style=slash
añade el indicador / a los directorios
-q, --hide-control-chars
imprime ? en lugar de caracteres no gráficos
--show-control-chars
muestra los caracteres no gráficos tal cual (por defecto, a menos que el programa sea 'ls' y la salida sea una terminal)
-Q, --quote-name
incluye los nombres de entrada entre comillas dobles
--quoting-style=PALABRA
usa el estilo de comillas PALABRA para los nombres de entrada: literal, locale, shell, shell-always, shell-escape, shell-escape-always, c, escape (anula la variable de entorno QUOTING_STYLE)
-r, --reverse
invierte el orden al ordenar
-R, --recursive
lista los subdirectorios recursivamente
-s, --size
imprime el tamaño asignado de cada archivo, en bloques
-S
ordena por tamaño de archivo, el más grande primero
--sort=PALABRA
cambia el ordenamiento por defecto 'name' a PALABRA: none (-U), size (-S), time (-t), version (-v), extension (-X), name, width
--time=PALABRA
selecciona qué marca de tiempo se usa para mostrar o ordenar; tiempo de acceso (-u): atime, access, use; tiempo de cambio de metadatos (-c): ctime, status; tiempo de modificación (por defecto): mtime, modification; tiempo de creación: birth, creation;
con -l, PALABRA determina qué tiempo mostrar; con --sort=time, ordena por PALABRA (el más reciente primero)
--time-style=ESTILO_DE_TIEMPO
tiempo/formato; ver la descripción de TIME_STYLE abajo
-t
con -l: ordena por y muestra la hora de modificación; de lo contrario: ordena por hora de modificación, el más reciente primero
-T, --tabsize=TAMAÑO
asume que las pestañas de salida están fijadas en TAMAÑO (por defecto 8)
-u
con -lt: sort by and show access time; with -l: show access time and sort by name; otherwise: sort by access time, newest first
-U
no ordenar; lista en el orden del sistema de archivos
-v
natural sort of (version) numbers within text
-V, --version-script
list entries by version
-w, --width=NUMERO
assume screen width instead of current value
-x
like -C, but list entries horizontally
-X
sort by entry extension
-1
list one file per line

Sin opciones, o ls, lista el contenido del directorio actual en columnas, ordenado alfabéticamente.

Las opciones que toman un argumento opcional en paréntesis (como --color=CUÁNDO) pueden ser invocadas con o sin el argumento.

CUÁNDO
si CUÁNDO es omitted o 'always', colorea siempre. Si es 'auto', colorea si la salida estándar es una terminal. Si es 'never', no colorea nunca.
TAMAÑO
TAMAÑO es un número entero seguido opcionalmente de un multiplicador: b=512, kB=1000, K=1024, MB=1000*1000, M=1024*1024, GB,G, TB,T, PB,P, EB,E, ZB,Z, YB,Y.
ESTILO_DE_TIEMPO
En un listado largo (-l), muestra el tiempo de archivo en el formato especificado. Los formatos de tiempo reconocidos son:
  • 'full' que es igual a 'long-iso'.
  • 'long' que es igual a 'iso' con el año omitido para archivos recientes.
  • 'iso', 'long-iso': 2023-07-20 17:45
  • 'locale': el estilo de fecha y hora de tu configuración regional.
  • 'posix-like': Wed Jul 20 17:45:04 2023
  • 'short': 7 days ago
  • 'full-iso', 'iso-ls': 2023-07-20 17:45:04.123456789 +0100

Si --full-time se usa, el estilo de tiempo es 'full-iso'.

Un prefijo "TIME_STYLE=" en la variable de entorno TZ también afecta el formato de tiempo. Por ejemplo, TZ="posix-cat".

La opción --sort=WORD puede anular el ordenamiento predeterminado. El ordenamiento predeterminado es por nombre.

Las opciones que anulan el ordenamiento son -c, -t, -S, -v, -X.

Las opciones que anulan la selección del tiempo son -c, -u.

EXIT STATUS

ls 0 si todo funciona, 1 si hay un error, 2 si un archivo especificado no se puede acceder o 3 si se produce un error de línea de comandos.

ls

list directory contents

SYNOPSIS

ls [OPTION...] [FILE...

DESCRIPTION

List information about the FILEs (the current directory by default).

  Alias: ll='ls -alF'
  Alias: l='ls -CF'

Mandatory arguments to long options are also mandatory for the short options.

-a, --all do not ignore entries starting with .

-A, --almost-all do not list implied . and ..

-b, --escape print C-style escapes for nongraphic characters

show hexadecimal values, plus a `*' for each other byte

-B, --ignore-backups do not list implied entries ending with ~

-c with -lt: sort by, and show, ctime (time of last modification of file status information); with -l: show ctime and sort by name; otherwise: sort by ctime, newest first

-C list entries by columns

--color[=WHEN] colorize the output

WHEN defaults to 'auto'. Always is 'always' or 'yes'. Never is 'never' or 'no'.

-d, --directory list directories themselves, rather than their contents

-D, --dired with -l: print the date in short format (with -l: print YYYY-MM-DD)

-f do not sort, enable -aU, disable -ls --color

-F, --classify[=SUFFIXES] append indicator with each file

Extra suffixes will be added to filenames to indicate their type. Existing suffixes match -append=\SUFFIXES. Default suffixes: /* for directories, / for symbolic links, * for executables, @ for every other type. This option overrides -F.

-g like -l but not group

-G, --no-group do not print group

-h, --human-readable with -l: print sizes like 1K 234M 2G etc.

-H, --dereference-command-line follow symbolic links listed on the command line

follow each symbolic link to a directory named on the command line, out of a non-empty list of FILEs

-i, --inode print the index number of each file

-I, --ignore=PATTERN do not list implied entries matching shell PATTERN

-k like -l --block-size=1K

-l, --long use a long listing format

-L, --dereference follow symbolic links

-m fill width with a comma separated list of entries

-n, --numeric-uid-gid like -l but use numeric UIDs and GIDs instead of names

-N, --literal never quote file names

-o like -l but print owner in youser format only

-O, --outer-space do not list implied entries starting with.

-p, --file-type[=SUFFIXES] append indicator with each file

Only one dot OF SUFFIXES

-P, --hide-control-chars print C-style escapes for nongraphic characters

-q, --hide-control-chars print ? instead of nongraphic characters

-Q, --quote-name enclose file names in double quotes

-r, --reverse reverse while sorting

-R, --recursive list subdirectories recursively

-s, --size print the allocated size of each file, in blocks

-S sort by file size, largest first

--sort=WORD sort by WORD instead of name: none (-U), size (-S), time (-t), version (-v), extension (-X)

-t with -l: sort by, and show, modification time, newest first; with -lt: sort by, and show, access time; with -l: show access time and sort by name; otherwise: sort by modification time, newest first

--time[=WORD] with -l, call stat() once, this may change the order WORD is one of: atime, access, use, mtime, modify, change

--time-style=STYLE with -l, show times using STYLE; see TIME_STYLE below

-u with -lt: sort by, and show, access time; with -l: show access time and sort by name; otherwise: sort by access time, newest first

-U do not sort directory entries

-v natural sort of (version) numbers within text

-w, --width=COLS set output width to COLS. 0 means no limit

-x list entries by lines instead of by columns

-X sort alphabetically by entry extension

-Z, --context print any security context of each file

--zero end each output line with NUL, not newline

-1 list one file per line

--help display this help and exit

--version output version information and exit

-l
use a long listing format
-t
sort by modification time, newest first
--time=WORD
with -l, call stat() once, this may change the order
TIME_STYLE
with -l, show times using STYLE; see TIME_STYLE below

The SIZE argument is an integer and optional unit (example: 10K is 10*1024). Units are K,M,G,T,P,E,Z,Y,R,Q (powers of 1024) or KB,MB,... (powers of 1000). Binary prefixes can be used, too: KiB=K, MiB=M, and so on.

The TIME_STYLE argument can be full-iso, long-iso, iso, locale, or +FORMAT. FORMAT is interpreted like in date(1). If FORMAT is FORMAT1<newline>FORMAT2, then FORMAT1 applies to non-recent files and FORMAT2 to recent files. TIME_STYLE prefixed with 'posix-' takes effect only outside the POSIX locale. Also the TIME_STYLE environment variable sets the default style to use.

The WHEN argument defaults to 'always' and can also be 'auto' or 'never'.

Using color to distinguish file types is disabled both by default and with --color=never. With --color=auto, ls emits color codes only when standard output is connected to a terminal. The LS_COLORS environment variable can change the settings. Use the dircolors(1) command to set it.

Exit status:

0
if OK,
1
if minor problems (e.g., cannot access subdirectory),
2
if serious trouble (e.g., cannot access command-line argument).
