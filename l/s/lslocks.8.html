LSLOCKS(8) Administración del Sistema LSLOCKS(8)

NOMBRE

lslocks - listar bloqueos locales del sistema

SINOPSIS

lslocks [opciones]

DESCRIPCIÓN

lslocks lista información sobre todos los bloqueos de archivos actualmente mantenidos en un sistema Linux.

OPCIONES

-b, --bytes

Imprime los tamaños en bytes en lugar de en formato legible por humanos.

Por defecto, la unidad en la que se expresan los tamaños es byte, y los prefijos de unidad están en potencias de 2^10 (1024). Las abreviaturas de los símbolos se presentan truncadas para lograr una mejor legibilidad, exhibiendo solo la primera letra de ellos; ejemplos: "1 KiB" y "1 MiB" se presentan respectivamente como "1 K" y "1 M", omitiendo a propósito la mención "iB", que forma parte de estas abreviaturas.

-H, --list-columns

Lista las columnas disponibles, usa con --json o --raw para obtener la salida en formato legible por máquina.

-i, --noinaccessible

Ignora los archivos de bloqueo que son inaccesibles para el usuario actual.

-J, --json

Utiliza el formato de salida JSON.

-n, --noheadings

No imprime una línea de encabezado.

-o, --output lista

Especifica qué columnas de salida imprimir. Usa --help para obtener una lista de todas las columnas soportadas.

La lista de columnas por defecto puede ser extendida si se especifica lista en el formato +lista (por ejemplo, lslocks -o +BLOCKER).

--output-all

Imprime todas las columnas disponibles.

-p, --pid pid

Muestra solo los bloqueos mantenidos por el proceso con este pid.

-r, --raw

Utiliza el formato de salida sin procesar.

-u, --notruncate

No trunca el texto en las columnas.

-h, --help

Muestra el texto de ayuda y sale.

-V, --version

Muestra la versión y sale.

SALIDA

COMMAND

El nombre del comando del proceso que mantiene el bloqueo.

PID

El ID del proceso.

TYPE

El tipo de bloqueo; puede ser LEASE (creado con fcntl(2)), FLOCK (creado con flock(2)), POSIX (creado con fcntl(2) y lockf(3)) o OFDLCK (creado con fcntl(2)).

SIZE

Tamaño del archivo bloqueado.

INODE

El número de inodo.

MAJ:MIN

El número de dispositivo mayor:menor.

MODE

Los permisos de acceso del bloqueo (lectura, escritura). Si el proceso está bloqueado esperando el bloqueo, entonces el modo se sufija con un '*' (asterisco).

M

Si el bloqueo es obligatorio; 0 significa no (lo que significa que el bloqueo es solo consultivo), 1 significa sí. (Ver fcntl(2)).

START

Desplazamiento de bytes relativo del bloqueo.

END

Desplazamiento final del bloqueo.

PATH

Ruta completa del bloqueo. Si no se encuentra ninguna, o no hay permisos para leer la ruta, se recurrirá al punto de montaje del dispositivo y se añadirá "..." a la ruta. La ruta puede ser truncada; usa --notruncate para obtener la ruta completa.

BLOCKER

El PID del proceso que bloquea el bloqueo.

HOLDERS

El/los poseedor(es) del bloqueo. El formato del poseedor es PID,COMMAND,FD. Si un bloqueo es un bloqueo orientado a la descripción de archivo abierto, puede haber más de un poseedor para el bloqueo. Ver NOTAS abajo.

NOTAS

El comando lslocks está destinado a reemplazar al comando lslk(8), escrito originalmente por Victor A. Abell <abe@purdue.edu> y sin mantenimiento desde 2001.

"El proceso que mantiene el bloqueo" para leases, bloqueos FLOCK y bloqueos OFD es un concepto falso. Están asociados con la descripción de archivo abierto en la que se adquieren. Con fork(2) y/o cmsg(3), múltiples procesos pueden compartir una descripción de archivo abierto. Por lo tanto, el proceso poseedor de un lease (o un bloqueo) no se determina de forma única. lslocks muestra uno de los procesos poseedores en las columnas COMMAND y PID.
