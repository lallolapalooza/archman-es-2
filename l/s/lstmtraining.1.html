NOMBRE

lstmtraining - Programa de entrenamiento para redes basadas en LSTM.

SINOPSIS

lstmtraining --continue_from dir_salida_entrenamiento/continue_from_idioma.lstm --old_traineddata dir_mejor_datos/continue_from_idioma.traineddata --traineddata dir_salida_entrenamiento/idioma/idioma.traineddata --max_iterations NNN --debug_interval 0|-1 --train_listfile dir_salida_entrenamiento/archivos_entrenamiento_idioma.txt --model_output dir_salida_entrenamiento/nuevo_modelo_lstm

DESCRIPCIÓN

lstmtraining(1) entrena redes basadas en LSTM usando una lista de archivos lstmf y un archivo traineddata de inicio como entrada principal. No se recomienda que los usuarios entrenen desde cero. En su lugar, se pueden usar opciones de ajuste fino (fine-tuning) (el comando de ejemplo se muestra en la sinopsis anterior) o de reemplazo de capas. Se aplican diferentes opciones a diferentes tipos de entrenamiento. Lea la [documentación de entrenamiento](https://tesseract-ocr.github.io/tessdoc/TrainingTesseract-4.00.html) para obtener detalles.

OPCIONES

'--debug_interval '

Frecuencia con la que se muestra la alineación. (tipo:int predeterminado:0)

'--net_mode '

Controla el comportamiento de la red. (tipo:int predeterminado:192)

'--perfect_sample_delay '

Cuántas muestras imperfectas entre las perfectas. (tipo:int predeterminado:0)

'--max_image_MB '

Memoria máxima a usar para imágenes. (tipo:int predeterminado:6000)

'--append_index '

Índice en la Red continue_from en el que adjuntar la nueva red definida por net_spec (tipo:int predeterminado:-1)

'--max_iterations '

Si se establece, salir después de este número de iteraciones. Un valor negativo se interpreta como épocas, 0 significa iteraciones infinitas. (tipo:int predeterminado:0)

'--target_error_rate '

Tasa de error final en porcentaje. (tipo:double predeterminado:0.01)

'--weight_range '

Rango de pesos aleatorios iniciales. (tipo:double predeterminado:0.1)

'--learning_rate '

Factor de peso para nuevos deltas. (tipo:double predeterminado:0.001)

'--momentum '

Factor de decaimiento para deltas repetidos. (tipo:double predeterminado:0.5)

'--adam_beta '

Factor de decaimiento para deltas repetidos. (tipo:double predeterminado:0.999)

'--stop_training '

Simplemente convierte el modelo de entrenamiento en un modelo en tiempo de ejecución. (tipo:bool predeterminado:false)

'--convert_to_int '

Convierte el modelo de reconocimiento en un modelo entero. (tipo:bool predeterminado:false)

'--sequential_training '

Usa los archivos de entrenamiento secuencialmente en lugar de por orden de ronda. (tipo:bool predeterminado:false)

'--debug_network '

Obtiene información sobre la distribución de los valores de los pesos (tipo:bool predeterminado:false)

'--randomly_rotate '

Entrena OSD y gira aleatoriamente las muestras de entrenamiento boca abajo (tipo:bool predeterminado:false)

'--net_spec '

Especificación de la red (tipo:string predeterminado:)

'--continue_from '

Modelo existente para extender (tipo:string predeterminado:)

'--model_output '

Nombre base para los modelos de salida (tipo:string predeterminado:lstmtrain)

'--train_listfile '

Archivo que lista los archivos de entrenamiento en formato de entrenamiento lstmf. (tipo:string predeterminado:)

'--eval_listfile '

Archivo que lista los archivos de evaluación en formato de entrenamiento lstmf. (tipo:string predeterminado:)

'--traineddata '

traineddata de inicio con Dawgs/Unicharset/Recoder combinados para el modelo de idioma (tipo:string predeterminado:)

'--old_traineddata '

Al cambiar el conjunto de caracteres, esto especifica el traineddata con el conjunto de caracteres antiguo que se va a reemplazar (tipo:string predeterminado:)
