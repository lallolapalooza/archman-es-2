NOMBRE

ls++.conf - archivo de configuración de ls++

DESCRIPCIÓN

ls++.conf es el archivo de configuración para ls++(1). ls++ primero lo busca en ~/.config/ls++/ls++.conf, luego en ~/.ls++.conf, luego en ./ls++.conf y finalmente en /etc/ls++.conf.

Las líneas que comienzan con el carácter '#' son comentarios. Todas las demás líneas no vacías son código Perl activo. Esto otorga mucho poder al usuario final, pero también permite cometer errores.

Por favor, no cometas errores.

ENTORNO

@d
Array que contiene los caracteres a usar para delimitar las columnas.
@c
Array que contiene los colores a utilizar.
$colorscheme
Esquema de colores a utilizar.
%ls_colors
Un hash donde sus claves son patrones (posiblemente expresiones regulares válidas) a comparar con los archivos. Los valores deben ser atributos o colores que se añadirán a la salida.

Esto hace lo mismo que LS_COLORS, excepto que puedes comparar con el nombre de archivo completo, y no solo con la extensión. Usando LS_COLORS, nunca podrías comparar README o Makefile, por ejemplo. Esos dos se comparan por defecto.

El valor especial IGNORE ignorará todos los archivos que coincidan con el patrón de la clave.
