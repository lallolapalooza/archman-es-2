LSEARCH(3P) Manual del programador POSIX LSEARCH(3P)

PRÓLOGO

Esta página del manual forma parte del Manual del programador POSIX. La implementación de Linux de esta interfaz puede diferir (consulte la página del manual de Linux correspondiente para obtener detalles sobre el comportamiento de Linux), o la interfaz puede no estar implementada en Linux.

NOMBRE

lsearch, lfind — búsqueda lineal y actualización

SINOPSIS

#include <search.h>
void *lsearch(const void *key, void *base, size_t *nelp, size_t width,
    int (*compar)(const void *, const void *));
void *lfind(const void *key, const void *base, size_t *nelp,
    size_t width, int (*compar)(const void *, const void *));

DESCRIPCIÓN

La función lsearch() buscará linealmente en la tabla y devolverá un puntero dentro de la tabla para la entrada coincidente. Si la entrada no existe, se añadirá al final de la tabla. El argumento key apunta a la entrada que se va a buscar en la tabla. El argumento base apunta al primer elemento de la tabla. El argumento width es el tamaño de un elemento en bytes. El argumento nelp apunta a un entero que contiene el número actual de elementos en la tabla. El entero al que apunta nelp se incrementará si la entrada se añade a la tabla. El argumento compar apunta a una función de comparación que la aplicación debe proporcionar (por ejemplo, strcmp()). Se llama con dos argumentos que apuntan a los elementos que se comparan. La aplicación debe asegurarse de que la función devuelva 0 si los elementos son iguales y distinto de cero en caso contrario.

La función lfind() será equivalente a lsearch(), excepto que si la entrada no se encuentra, no se añadirá a la tabla. En su lugar, se devolverá un puntero nulo.

VALOR DE RETORNO

Si la entrada buscada se encuentra, tanto lsearch() como lfind() devolverán un puntero a ella. De lo contrario, lfind() devolverá un puntero nulo y lsearch() devolverá un puntero al elemento recién añadido.

Ambas funciones devolverán un puntero nulo en caso de error.

ERRORES

No se definen errores.

EJEMPLOS

Almacenamiento de cadenas en una tabla

Este fragmento lee como máximo TABSIZE cadenas de longitud menor o igual a ELSIZE y las almacena en una tabla, eliminando duplicados.

#include <stdio.h>
#include <string.h>
#include <search.h>
#define TABSIZE 50
#define ELSIZE 120
...
    char line[ELSIZE], tab[TABSIZE][ELSIZE];
    size_t nel = 0;
    ...
    while (fgets(line, ELSIZE, stdin) != NULL && nel < TABSIZE)
        (void) lsearch(line, tab, &nel,
            ELSIZE, (int (*)(const void *, const void *)) strcmp);
    ...

Búsqueda de una entrada coincidente

El siguiente ejemplo busca cualquier línea que diga "Thisisatest.". 

#include <search.h>
#include <string.h>
...
char line[ELSIZE], tab[TABSIZE][ELSIZE];
size_t nel = 0;
char *findline;
void *entry;
findline = "This is a test.\n";
entry = lfind(findline, tab, &nel, ELSIZE, (
    int (*)(const void *, const void *)) strcmp);

USO DE LA APLICACIÓN

La función de comparación no necesita comparar cada byte, por lo que los datos arbitrarios pueden estar contenidos en los elementos además de los valores que se comparan.

Pueden producirse resultados indefinidos si no hay suficiente espacio en la tabla para añadir un nuevo elemento.
