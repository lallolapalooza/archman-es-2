NOMBRE

lsearch - Ver si una lista contiene un elemento particular

SINOPSIS

lsearch ?opciones? lista patrón

DESCRIPCIÓN

Este comando busca en los elementos de lista para ver si alguno de ellos coincide con patrón. Si es así, el comando devuelve el índice del primer elemento coincidente (a menos que se especifiquen las opciones -all o -inline). Si no, el comando devuelve -1 o (si se especifican las opciones -all o -inline) la cadena vacía. Los argumentos opción indican cómo se compararán los elementos de la lista con patrón y deben tener uno de los valores que se indican a continuación:

OPCIONES DE ESTILO DE COINCIDENCIA

Si se omiten todas las opciones de estilo de coincidencia, el estilo de coincidencia predeterminado es -glob. Si se especifica más de un estilo de coincidencia, el último estilo de coincidencia dado tiene precedencia.

-exact
Patrón es una cadena literal que se compara para igualdad exacta contra cada elemento de la lista.
-glob
Patrón es un patrón de estilo glob que se compara contra cada elemento de la lista utilizando las mismas reglas que el comando string match.
-regexp
Patrón se trata como una expresión regular y se compara contra cada elemento de la lista utilizando las reglas descritas en la página de referencia re_syntax.
-sorted
Los elementos de la lista están en orden ordenado. Si se especifica esta opción, lsearch utilizará un algoritmo de búsqueda más eficiente para buscar en lista. Si no se especifican otras opciones, se asume que lista está ordenada en orden ascendente y que contiene cadenas ASCII. Esta opción es mutuamente exclusiva con -glob y -regexp, y se trata exactamente como -exact cuando se especifican -all o -not.

OPCIONES GENERALES MODIFICADORAS

Estas opciones se pueden proporcionar con todos los estilos de coincidencia.

-all
Cambia el resultado a la lista de todos los índices coincidentes (o todos los valores coincidentes si también se especifica -inline). Si se devuelven índices, los índices estarán en orden numérico ascendente. Si se devuelven valores, el orden de los valores será el orden de esos valores dentro de la lista de entrada.
-inline
Se devuelve el valor coincidente en lugar de su índice (o una cadena vacía si ningún valor coincide). Si también se especifica -all, entonces el resultado del comando es la lista de todos los valores que coincidieron.
-not
Esto niega el sentido de la coincidencia, devolviendo el índice del primer valor no coincidente de la lista.
-start índice
La lista se busca a partir de la posición índice. La interpretación del valor índice es la misma que para el comando string index, soportando aritmética de índices simple e índices relativos al final de la lista.

OPCIONES DE DESCRIPCIÓN DE CONTENIDO

Estas opciones describen cómo interpretar los elementos de la lista que se está buscando. Solo son significativas cuando se utilizan con las opciones -exact y -sorted. Si se especifica más de una, la última tiene precedencia. El valor predeterminado es -ascii.

-ascii
Los elementos de la lista se examinarán como cadenas Unicode (el nombre es por razones de compatibilidad retroactiva).
-dictionary
Los elementos de la lista se compararán utilizando comparaciones de estilo diccionario (ver lsort para una descripción más completa). Tenga en cuenta que esto solo marca una diferencia significativa con la opción -ascii cuando se proporciona la opción -sorted, ya que los valores solo son iguales según el diccionario cuando son exactamente iguales.
-integer
Los elementos de la lista se compararán como enteros.
-nocase
Hace que las comparaciones se manejen de forma insensible a mayúsculas y minúsculas. No tiene ningún efecto si se combina con las opciones -dictionary, -integer o -real.
-real
Los elementos de la lista se compararán como valores de punto flotante.

OPCIONES DE LISTA ORDENADA

Estas opciones (solo significativas con la opción -sorted) especifican cómo se ordena la lista. Si se proporciona más de una, la última tiene precedencia. La opción predeterminada es -increasing.

-decreasing
Los elementos de la lista se ordenan en orden decreciente. Esta opción solo es significativa cuando se usa con -sorted.
-increasing
Los elementos de la lista se ordenan en orden creciente. Esta opción solo es significativa cuando se usa con -sorted.
-bisect
Búsqueda inexacta cuando los elementos de la lista están en orden ordenado. Para una lista creciente, se devuelve el último índice donde el elemento es menor o igual al patrón. Para una lista decreciente, se devuelve el último índice donde el elemento es mayor o igual al patrón. Si el patrón está antes del primer elemento o la lista está vacía, se devuelve -1. Esta opción implica -sorted y no se puede usar con -all o -not.

OPCIONES DE LISTAS ANIDADAS

Estas opciones se utilizan para buscar en listas de listas. Pueden usarse con cualquier otra opción.

-index listaÍndices
Esta opción está diseñada para usarse al buscar dentro de listas anidadas. El argumento listaÍndices proporciona una ruta de índices (similar a la que podría usarse con los comandos lindex o lset) dentro de cada elemento para permitir la ubicación del término que se compara.
-subindices
Si se proporciona esta opción, el resultado del índice de este comando (o cada resultado del índice cuando también se especifica -all) será una ruta completa (adecuada para usar con lindex o lset) dentro de la lista general hasta el término encontrado. Esta opción no tiene ningún efecto a menos que también se especifique -index, y es solo un atajo de conveniencia.

EJEMPLOS

Búsqueda básica:

lsearch {a b c d e} c
      → 2
lsearch -all {a b c a b c} c
      → 2 5

Usando lsearch para filtrar listas:

lsearch -inline {a20 b35 c47} b*
      → b35
lsearch -inline -not {a20 b35 c47} b*
      → a20
lsearch -all -inline -not {a20 b35 c47} b*
      → a20 c47
lsearch -all -not {a20 b35 c47} b*
      → 0 2

Esto puede incluso realizar una operación de eliminación "similar a conjuntos":

lsearch -all -inline -not -exact {a b c a d e a f g a} a
      → b c d e f g

La búsqueda puede comenzar en medio de la lista:

lsearch -start 3 {a b c a b c} c
      → 5

También es posible buscar dentro de elementos:

lsearch -index 1 -all -inline {{abc abc} {abc bcd} {abc cde}} *bc*
      → {abc abc} {abc bcd}
