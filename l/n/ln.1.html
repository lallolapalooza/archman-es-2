LN(1) Comandos de usuario LN(1)

NOMBRE

ln - crear enlaces entre archivos

SINOPSIS

ln [OPCIÓN]... [-T] OBJETIVO ENLACE_NOMBRE
ln [OPCIÓN]... OBJETIVO
ln [OPCIÓN]... OBJETIVO... DIRECTORIO
ln [OPCIÓN]... -t DIRECTORIO OBJETIVO...

DESCRIPCIÓN

En la 1ra forma, crea un enlace a OBJETIVO con el nombre ENLACE_NOMBRE. En la 2da forma, crea un enlace a OBJETIVO en el directorio actual. En la 3ra y 4ta forma, crea enlaces a cada OBJETIVO en DIRECTORIO. Crea enlaces duros por defecto, enlaces simbólicos con --symbolic. Por defecto, cada destino (nombre del nuevo enlace) no debe existir previamente. Al crear enlaces duros, cada OBJETIVO debe existir. Los enlaces simbólicos pueden contener texto arbitrario; si se resuelven posteriormente, un enlace relativo se interpreta en relación a su directorio padre.

Los argumentos obligatorios para las opciones largas son también obligatorios para las opciones cortas.

--backup[=CONTROL]
crear una copia de seguridad de cada archivo de destino existente
-b
igual que --backup pero no acepta argumento
-d, -F, --directory
permite al superusuario intentar enlazar directorios de forma dura (esto probablemente fallará debido a restricciones del sistema, incluso para el superusuario)
-f, --force
elimina los archivos de destino existentes
-i, --interactive
pregunta si se deben eliminar los destinos
-L, --logical
desreferencia los OBJETIVOS que son enlaces simbólicos
-n, --no-dereference
trata ENLACE_NOMBRE como un archivo normal si es un enlace simbólico a un directorio
-P, --physical
crea enlaces duros directamente a enlaces simbólicos
-r, --relative
con -s, crea enlaces relativos a la ubicación del enlace
-s, --symbolic
crea enlaces simbólicos en lugar de enlaces duros
-S, --suffix=SUFIJO
anula el sufijo de copia de seguridad habitual
-t, --target-directory=DIRECTORIO
especifica el DIRECTORIO en el que crear los enlaces
-T, --no-target-directory
trata ENLACE_NOMBRE como un archivo normal siempre
-v, --verbose
imprime el nombre de cada archivo enlazado
--help
muestra esta ayuda y sale
--version
muestra información de versión y sale

El sufijo de copia de seguridad es '~', a menos que se establezca con --suffix o SIMPLE_BACKUP_SUFFIX. El método de control de versiones se puede seleccionar a través de la opción --backup o de la variable de entorno VERSION_CONTROL. Estos son los valores:

ninguno, off
nunca crear copias de seguridad (incluso si se proporciona --backup)
numerado, t
crear copias de seguridad numeradas
existente, nil
numeradas si existen copias de seguridad numeradas, simples en caso contrario
simple, never
siempre crear copias de seguridad simples

Usar -s ignora -L y -P. De lo contrario, la última opción especificada controla el comportamiento cuando un OBJETIVO es un enlace simbólico, por defecto es -P.

    ln(1)

    ln - make links

    SYNOPSIS

    ln [-s] [-f | -i] [-T] target link
    ln [-s] [-f | -i] target... directory
    ln [-s] [-f | -i] target link
    ln [-s] [-f | -i] target... directory

    DESCRIPTION

    This manual page documents the ln command.

    ln creates links between files. A link is a pointer to another file. There are two types of links: hard links and symbolic links.

    Hard links are entries in the file system that point directly to the data on the disk. If you create a hard link to a file, it's essentially another name for the same file. Any changes made to the file through one name will be reflected when accessing it through the other name. Hard links cannot span across different file systems.

    Symbolic links (also known as soft links or symlinks) are special files that contain a path to another file or directory. When you access a symbolic link, the system follows the path stored within it to reach the target. Symbolic links can span across different file systems and can also point to directories. Deleting a symbolic link does not affect the target file or directory.

    OPTIONS

    • -s, --symbolic: Create a symbolic link instead of a hard link.
    • -f, --force: Remove existing destination files or directories by default when they are specified as a link.
    • -i, --interactive: Prompt before attempting to remove a nonexistent destination file or directory.
    • -T, --no-target-directory: Treat each link as a normal file.

    EXAMPLES

    Create a symbolic link named my_link pointing to original_file:

    ln -s original_file my_link

    Create a hard link named link_to_file pointing to file.txt:

    ln file.txt link_to_file

    Create multiple links in the /data directory:

    ln file1.txt file2.txt /data
