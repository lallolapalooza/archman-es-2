LNAV(1) Manual de Comandos Generales LNAV(1)

NOMBRE

lnav - visor de archivos de registro para la terminal

SINOPSIS

lnav [opciones] [archivo_registro1 archivo_registro2 ...]

DESCRIPCIÓN

El Navegador de Archivos de Registro, lnav, es un visor de archivos de registro para la terminal. Dados un conjunto de archivos/directorios, lnav hará lo siguiente:

- descomprime según sea necesario;
- detecta su formato;
- fusiona los archivos por tiempo en una única vista;
- sigue los archivos, rastrea renombres, encuentra nuevos archivos en directorios;
- construye un índice de errores y advertencias;
- imprime bonitas líneas JSON.

ATAJOS DE TECLADO

?
Ver/salir del texto de ayuda en línea.
q
Salir del programa.

OPCIONES

-h
Imprime la ayuda y sale.
-H
Muestra el texto de ayuda interno.
-I ruta
Añade el directorio de configuración dado a la ruta de búsqueda.
-W
Imprime advertencias relacionadas con la configuración de lnav.
-u
Actualiza los formatos instalados desde repositorios git.
-d archivo
Escribe mensajes de depuración en el archivo dado.
-V
Imprime información de la versión.
-r
Carga archivos recursivamente desde los directorios dados.
-R
Carga también los archivos de registro rotados más antiguos.
-c comando
Ejecuta un comando después de que los archivos hayan sido cargados.
-f ruta
Ejecuta los comandos en el archivo dado.
-e comando
Ejecuta una línea de comandos de shell.
-t
Antepone marcas de tiempo a las líneas de datos que se leen por la entrada estándar.
-n
Ejecuta sin la interfaz de usuario curses. (modo sin cabeza)
-N
No abre el archivo syslog predeterminado si no se proporcionan archivos.
-q
Modo silencioso. No imprime los mensajes de registro después de ejecutar todos los comandos.

Argumentos opcionales:

archivo_registro1
Los archivos o directorios de registro a ver. Si se proporciona un directorio, se cargarán todos los archivos de ese directorio.

OPCIONES DE MODO DE GESTIÓN

-i
Instala los archivos de formato dados en el directorio $HOME/.lnav/formats/installed y sale.
-m
Cambia al modo de línea de comandos de gestión. Este modo se utiliza para trabajar con la configuración de lnav.
-C
Verifica la configuración y sale. Se cargarán y verificarán los archivos de formato de registro. Se cargarán y verificarán los archivos proporcionados en la línea de comandos para asegurarse de que coinciden con un formato de registro.

EJEMPLOS

Para cargar y seguir el archivo syslog:

lnav

Para cargar todos los archivos en /var/log:

lnav /var/log

Para ver la salida de make con marcas de tiempo antepuestas:

make 2>&1 | lnav -t
