LNSTAT(8) Manual del Administrador del Sistema LNSTAT(8)

NOMBRE

lnstat - estadísticas unificadas de red de Linux

SINOPSIS

lnstat [opciones]

DESCRIPCIÓN

Esta página del manual documenta brevemente el comando lnstat.

lnstat es un reemplazo generalizado y más completo en características para el antiguo programa rtstat. Se utiliza comúnmente para imprimir periódicamente una selección de valores estadísticos exportados por el kernel. Además de las estadísticas de la caché de enrutamiento, admite cualquier tipo de estadísticas que el kernel de Linux exporte a través de un archivo en /proc/net/stat/.
Cada archivo en /proc/net/stat/ contiene una línea de encabezado que enumera los nombres de las columnas. Estos nombres son utilizados por lnstat como claves para seleccionar qué estadísticas imprimir. Para cada CPU presente en el sistema, sigue una línea que enumera los valores reales para cada columna del archivo. lnstat suma estos valores (que de hecho son contadores) antes de imprimirlos. Después de cada intervalo, solo se imprime la diferencia con el último valor.

Los archivos y columnas pueden seleccionarse utilizando los parámetros -f y -k. Por defecto, se imprimen todas las columnas de todos los archivos.

OPCIONES

lnstat admite las siguientes opciones.

-h, --help
Muestra un resumen de las opciones.
-V, --version
Muestra la versión del programa.
-c, --count <contador>
Imprime <contador> número de intervalos.
-d, --dump
Descarga la lista de archivos/claves disponibles.
-f, --file <archivo>
Archivo de estadísticas a usar, puede especificarse varias veces. Por defecto, se escanean todos los archivos en /proc/net/stat/.
-i, --interval <intervalo>
Establece el intervalo a 'intervalo' segundos.
-j, --json
Muestra los resultados en formato JSON.
-k, --keys c,c,c,...
Muestra solo las claves especificadas. Cada clave c tiene el formato [archivo:]clave. Si se proporciona <archivo>, la búsqueda de la clave dada se limita a ese archivo. De lo contrario, se utiliza el primer archivo que contiene la clave buscada.
-s, --subject [0-2]
Especifica la visualización del asunto/encabezado. '0' significa que no hay encabezado en absoluto, '1' imprime un encabezado solo al inicio del programa y '2' imprime un encabezado cada 20 líneas.
-w, --width n,n,n,...
Ancho para cada campo.

EJEMPLOS DE USO

# lnstat -d
Obtiene una lista de archivos de estadísticas compatibles.
# lnstat -k arp_cache:entries,rt_cache:in_hit,arp_cache:destroys
Selecciona los archivos y claves especificados.
# lnstat -i 10
Utiliza un intervalo de 10 segundos.
# lnstat -f ip_conntrack
Utiliza solo el archivo especificado para estadísticas.
# lnstat -s 0
No imprime ningún encabezado en absoluto.
# lnstat -s 20
Imprime un encabezado al inicio y cada 20 líneas.
# lnstat -c -1 -i 1 -f rt_cache -k entries,in_hit,in_slow_tot
Muestra estadísticas para las claves entries, in_hit e in_slow_tot del campo rt_cache cada segundo.

ARCHIVOS

/proc/net/stat/arp_cache, /proc/net/stat/ndisc_cache
Estadísticas sobre la caché de vecinos y ARP. arp_cache es para IPv4, ndisc_cache es lo mismo para IPv6.

entries Número de entradas en la tabla de vecinos.

allocs Cuántas entradas de vecinos se han asignado.

destroys Cuántas entradas de vecinos se han eliminado.

hash_grows Cuántas veces ha aumentado la tabla de vecinos (hash).

lookups Cuántas búsquedas se han realizado.

hits Cuántas lookups (búsquedas) han sido exitosas.

res_failed Cuántas búsquedas de vecinos han fallado.

rcv_probes_mcast Cuántas solicitaciones de vecinos multicast se han recibido. (Solo IPv6.)

rcv_probes_ucast Cuántas solicitaciones de vecinos unicast se han recibido. (Solo IPv6.)

periodic_gc_runs Cuántas ejecuciones de recolección de basura se han ejecutado.

forced_gc_runs Cuántas ejecuciones forzadas de recolección de basura se han ejecutado. Ocurre al agregar una entrada y la tabla está demasiado llena.

unresolved_discards Cuántas entradas de la tabla de vecinos se han descartado debido a fallos en la búsqueda.

table_fulls Número de desbordamientos de tabla. Ocurre si la tabla está llena y la ejecución forzada de GC (ver forced_gc_runs) ha fallado.

/proc/net/stat/ip_conntrack, /proc/net/stat/nf_conntrack
Contadores relacionados con conntrack. ip_conntrack es para compatibilidad con versiones anteriores de userspace y muestra los mismos datos que nf_conntrack.

entries Número de entradas en la tabla conntrack.

searched Número de búsquedas en la tabla conntrack realizadas.

found Número de entradas searched (buscadas) que fueron exitosas.

new Número de entradas conntrack agregadas que no se esperaban antes.

invalid Número de paquetes vistos que no se pueden rastrear.

ignore Número de paquetes vistos que ya están conectados a una entrada conntrack.

delete Número de entradas conntrack que se han eliminado.

delete_list Número de entradas conntrack que se han puesto en la lista de eliminación.

insert Número de entradas insertadas en la lista.

insert_failed Número de entradas para las que se intentó insertar en la lista pero falló (ocurre si la misma entrada ya está presente).

drop Número de paquetes descartados debido a fallos en conntrack. O bien falló la asignación de una nueva entrada conntrack, o el ayudante del protocolo descartó el paquete.

early_drop Número de entradas conntrack descartadas para dar espacio a otras nuevas, si se alcanzó el tamaño máximo de tabla.

icmp_error Número de paquetes que no se pudieron rastrear debido a una situación de error. Esto es un subconjunto de invalid.

expect_new Número de entradas conntrack agregadas después de que ya existía una expectativa para ellas.

expect_create Número de expectativas agregadas.

expect_delete Número de expectativas eliminadas.

search_restart Número de búsquedas en la tabla conntrack que tuvieron que reiniciarse debido a redimensionamientos de la tabla hash.

/proc/net/stat/rt_cache
Estadísticas de la caché de enrutamiento.

entries Número de entradas en la caché de enrutamiento.

in_hit Número de aciertos de la caché de enrutamiento para paquetes entrantes. Deprecado desde la eliminación de la caché de rutas IP, por lo tanto, siempre cero.

in_slow_tot Número de entradas de caché de enrutamiento agregadas para tráfico de entrada.

in_slow_mc Número de entradas de caché de enrutamiento multicast agregadas para tráfico de entrada.

in_no_route Número de paquetes de entrada para los cuales no se encontró ninguna entrada en la tabla de enrutamiento.

in_brd Número de paquetes de difusión de entrada coincidentes.

in_martian_dst Número de paquetes de destino marciano entrantes.

in_martian_src Número de paquetes de origen marciano entrantes.

out_hit Número de aciertos de la caché de enrutamiento para paquetes salientes. Deprecado desde la eliminación de la caché de rutas IP, por lo tanto, siempre cero.

out_slow_tot Número de entradas de caché de enrutamiento agregadas para tráfico de salida.

out_slow_mc Número de entradas de caché de enrutamiento multicast agregadas para tráfico de salida.

lnstat(8) — Arch Linux

NAME

lnstat - show statistics for the Linux kernel network code

SYNOPSIS

lnstat [ OPTIONS ]

DESCRIPTION

lnstat displays statistics about the internal data structures used by the Linux kernel's network code. These statistics can be useful for diagnosing network performance problems.

OPTIONS

No options are currently supported.

USAGE EXAMPLES

To display the network statistics, simply run:

$ lnstat

FILES

The statistics are read from the kernel via the /proc/net/snmp file.

gc_goal
Number of garbage collector goals. Deprecated since IP route cache removal, therefore always zero.
gc_goal_miss
Number of garbage collector goal misses. Deprecated since IP route cache removal, therefore always zero.
gc_dst_overflow
Number of destination cache overflows. Deprecated since IP route cache removal, therefore always zero.
in_hlist_search
Number of hash table list traversals for input traffic. Deprecated since IP route cache removal, therefore always zero.
out_hlist_search
Number of hash table list traversals for output traffic. Deprecated since IP route cache removal, therefore always zero.
