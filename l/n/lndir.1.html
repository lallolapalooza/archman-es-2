NOMBRE

lndir - crea un directorio sombra de enlaces simbólicos a otro árbol de directorios

SINOPSIS

lndir [ -silent ] [ -ignorelinks ] [ -withrevinfo ] desde_dir [ a_dir ]

DESCRIPCIÓN

El programa lndir realiza una copia sombra a_dir de un árbol de directorios desde_dir, excepto que la sombra no se rellena con archivos reales sino en su lugar con enlaces simbólicos que apuntan a los archivos reales en el árbol de directorios desde_dir. Esto suele ser útil para mantener el código fuente para diferentes arquitecturas de máquinas. Creas un directorio sombra que contiene enlaces al código fuente real, que normalmente habrás montado desde una máquina remota. Puedes compilar en el árbol sombra, y los archivos objeto estarán en el directorio sombra, mientras que los archivos fuente en el directorio sombra son solo enlaces simbólicos a los archivos reales.

Este esquema tiene la ventaja de que si actualizas el código fuente, no necesitas propagar el cambio a otras arquitecturas manualmente, ya que todo el código fuente en todos los directorios sombra son enlaces simbólicos a la cosa real: simplemente haz cd al directorio sombra y recompila.

El argumento a_dir es opcional y por defecto es el directorio actual. El argumento desde_dir puede ser relativo (por ejemplo, ../src) y es relativo a a_dir (no al directorio actual).

Ten en cuenta que los directorios BitKeeper, CVS, CVS.adm, .git, .hg, RCS, SCCS y .svn solo se sombrean si se especifica la bandera -withrevinfo. Los archivos con nombres que terminan en ~ nunca se sombrean.

Si agregas archivos, simplemente ejecuta lndir de nuevo. Los nuevos archivos se agregarán silenciosamente. Los archivos antiguos se verificarán para asegurarte de que tienen el enlace correcto.

Eliminar archivos es un problema más doloroso; los enlaces simbólicos simplemente apuntarán a la nada.

Si un archivo en desde_dir es un enlace simbólico, lndir creará el mismo enlace en a_dir en lugar de crear un enlace de vuelta a la entrada (enlace simbólico) en desde_dir. La bandera -ignorelinks cambia este comportamiento.

OPCIONES

-silent
Normalmente lndir muestra el nombre de cada subdirectorio a medida que desciende en él. La opción -silent suprime estos mensajes de estado.
-ignorelinks
Hace que el programa no trate los enlaces simbólicos en desde_dir de forma especial. El enlace creado en a_dir apuntará de vuelta al archivo (enlace simbólico) correspondiente en desde_dir. Si el enlace apunta a un directorio, esto es casi con seguridad lo incorrecto.
Esta opción existe principalmente para emular el comportamiento que tenía la versión C de lndir en X11R6. Su uso no se recomienda.
-withrevinfo
Hace que los subdirectorios de cualquier sistema de control de código fuente (aquellos llamados BitKeeper, CVS, CVS.adm, .git, .hg, RCS, SCCS o .svn) se traten como cualquier otro directorio, en lugar de ser ignorados.

DIAGNÓSTICOS

El programa muestra el nombre de cada subdirectorio que ingresa, seguido de dos puntos. La opción -silent suprime estos mensajes.

Se muestra un mensaje de advertencia si no se puede crear el enlace simbólico. El problema habitual es que ya existe un archivo regular con el mismo nombre.

Si el enlace ya existe pero no apunta al archivo correcto, el programa imprime el nombre del enlace y la ubicación a la que apunta.
