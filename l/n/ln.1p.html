LN(1P) Manual del Programador de POSIX LN(1P)

PROLOG

Esta página del manual es parte del Manual del Programador de POSIX. La implementación de esta interfaz en Linux puede diferir (consulte la página del manual de Linux correspondiente para conocer los detalles del comportamiento de Linux), o la interfaz puede no estar implementada en Linux.

NOMBRE

ln — enlaza archivos

SINOPSIS

ln [-fs] [-L|-P] archivo_origen archivo_destino
ln [-fs] [-L|-P] archivo_origen... directorio_destino

DESCRIPCIÓN

En la primera forma de la sinopsis, la utilidad ln creará una nueva entrada de directorio (enlace) en la ruta de destino especificada por el operando archivo_destino. Si se especifica la opción -s, se creará un enlace simbólico para el archivo especificado por el operando archivo_origen. Se asumirá esta primera forma de sinopsis cuando el último operando no nombre un directorio existente; si se especifican más de dos operandos y el último no es un directorio existente, se producirá un error.

En la segunda forma de la sinopsis, la utilidad ln creará una nueva entrada de directorio (enlace), o si se especifica la opción -s un enlace simbólico, para cada archivo especificado por un operando archivo_origen, en una ruta de destino en el directorio existente denominado directorio_destino.

Si el último operando especifica un archivo existente de un tipo no especificado por el volumen de Interfaces del Sistema de POSIX.1‐2017, el comportamiento es definido por la implementación.

La ruta de destino correspondiente para cada archivo_origen será la concatenación del nombre de ruta del directorio de destino, un carácter <barra> si el nombre de ruta del directorio de destino no terminaba en una <barra>, y el último componente del nombre de ruta del archivo_origen. Se asumirá la segunda forma de sinopsis cuando el último operando nombre un directorio existente.

Para cada archivo_origen:

1.
Si la ruta de destino existe y fue creada por un paso anterior, es indeterminado si ln escribirá un mensaje de diagnóstico en el error estándar, no hará nada más con el archivo_origen actual y continuará con los archivos archivo_origen restantes; o continuará procesando el archivo_origen actual. Si la ruta de destino existe:
a.
Si la opción -f no está especificada, ln escribirá un mensaje de diagnóstico en el error estándar, no hará nada más con el archivo_origen actual y continuará con los archivos archivo_origen restantes.
b.
Si la ruta de destino nombra la misma entrada de directorio que el archivo_origen actual, ln escribirá un mensaje de diagnóstico en el error estándar, no hará nada más con el archivo_origen actual y continuará con los archivos archivo_origen restantes.
c.
Se realizarán acciones equivalentes a la función unlink() definida en el volumen de Interfaces del Sistema de POSIX.1‐2017, invocada utilizando la ruta de destino como argumento path. Si esto falla por cualquier motivo, ln escribirá un mensaje de diagnóstico en el error estándar, no hará nada más con el archivo_origen actual y continuará con los archivos archivo_origen restantes.
2.
Si se especifica la opción -s, se realizarán acciones equivalentes a la función symlink() con archivo_origen como argumento path1 y la ruta de destino como argumento path2. La utilidad ln no hará nada más con archivo_origen y continuará con los archivos restantes.
3.
Si archivo_origen es un enlace simbólico:
a.
Si la opción -P está en efecto, se realizarán acciones equivalentes a la función linkat() con archivo_origen como argumento path1, la ruta de destino como argumento path2, AT_FDCWD como argumentos fd1 y fd2, y cero como argumento flag.
b.
Si la opción -L está en efecto, se realizarán acciones equivalentes a la función linkat() con archivo_origen como argumento path1, la ruta de destino como argumento path2, AT_FDCWD como argumentos fd1 y fd2, y AT_SYMLINK_FOLLOW como argumento flag.

La utilidad ln no hará nada más con archivo_origen y continuará con los archivos restantes.

4.
Se realizarán acciones equivalentes a la función link() definida en el volumen de Interfaces del Sistema de POSIX.1‐2017 utilizando archivo_origen como argumento path1, y la ruta de destino como argumento path2.

OPCIONES

La utilidad ln se conformará al volumen de Definiciones Base de POSIX.1‐2017, Sección 12.2, Directrices de Sintaxis de Utilidades.

Las siguientes opciones serán soportadas:

-f
Forzar la eliminación de nombres de ruta de destino existentes para permitir el enlace.
-L
Para cada operando archivo_origen que nombre un archivo de tipo enlace simbólico, crear un enlace (duro) al archivo referenciado por el enlace simbólico.
-P
Para cada operando archivo_origen que nombre un archivo de tipo enlace simbólico, crear un enlace (duro) al propio enlace simbólico.
-s
Crear enlaces simbólicos en lugar de enlaces duros. Si se especifica la opción -s, las opciones -L y -P se ignorarán silenciosamente.

Especificar más de una de las opciones mutuamente exclusivas -L y -P no se considerará un error. La última opción especificada determinará el comportamiento de la utilidad (a menos que la opción -s cause que sea ignorada).

Si la opción -s no está especificada y ninguna de las opciones -L ni -P está especificada, se definirá por la implementación cuál de las opciones -L y -P se utilizará por defecto.

OPERANDOS

Los siguientes operandos serán soportados:

archivo_origen
Un nombre de ruta de un archivo para enlazar. Si se especifica la opción -s, no se harán restricciones sobre el tipo de archivo o su existencia. Si la opción -s no está especificada, se definirá por la implementación si se puede enlazar un directorio.
archivo_destino
El nombre de ruta de la nueva entrada de directorio que se creará.
directorio_destino
Un nombre de ruta de un directorio existente en el cual se crearán las nuevas entradas de directorio.

STDIN

No utilizado.

ARCHIVOS DE ENTRADA

Ninguno.

VARIABLES DE ENTORNO

Las siguientes variables de entorno afectarán la ejecución de ln:

LANG
Proporcionar un valor predeterminado para las variables de internacionalización que no estén establecidas o estén vacías. (Consulte el volumen de Definiciones Base de POSIX.1‐2017, Sección 8.2, Variables de Internacionalización para conocer la precedencia de las variables de internacionalización utilizadas para determinar los valores de las categorías de localización.)
LC_ALL
Si se establece en un valor de cadena no vacío, anulará los valores de todas las demás variables de internacionalización.
LC_CTYPE
Determinar la localización para la interpretación de secuencias de bytes de datos de texto como caracteres (por ejemplo, caracteres de un solo byte en contraposición a caracteres multibyte en argumentos).
