LTTNG_UST_TRACELOG(3) LTTng Manual LTTNG_UST_TRACELOG(3)

NOMBRE

lttng_ust_tracelog, lttng_ust_vtracelog - Interfaz de LTTng-UST similar a printf(3) con un nivel de registro

SINOPSIS

#include <lttng/tracelog.h>
#define lttng_ust_tracelog(level, fmt, ...)
#define lttng_ust_vtracelog(level, fmt, ap)

Enlazar con:

•-llttng-ust
•Si defines _LGPL_SOURCE antes de incluir <lttng/tracelog.h> (directa o indirectamente): -llttng-ust-common

DESCRIPCIÓN

La API lttng_ust_tracelog() y lttng_ust_vtracelog() de LTTng-UST te permite rastrear tu aplicación con la ayuda de macros simples similares a printf(3) y vprintf(3), con un parámetro adicional para el nivel de registro deseado.

El argumento fmt se pasa directamente como el parámetro fmt de vasprintf(3), así como:

Para lttng_ust_tracelog()

Los parámetros opcionales que siguen a fmt.

Para lttng_ust_vtracelog()

El parámetro ap como el parámetro ap de vasprintf(3) (tipo va_list).

El propósito de lttng_ust_tracelog() y lttng_ust_vtracelog() es facilitar la migración de registros a rastreo.

Los valores disponibles para el parámetro level son:

LTTNG_UST_TRACEPOINT_LOGLEVEL_EMERG

El sistema es inutilizable.

LTTNG_UST_TRACEPOINT_LOGLEVEL_ALERT

Se debe tomar acción inmediatamente.

LTTNG_UST_TRACEPOINT_LOGLEVEL_CRIT

Condiciones críticas.

LTTNG_UST_TRACEPOINT_LOGLEVEL_ERR

Condiciones de error.

LTTNG_UST_TRACEPOINT_LOGLEVEL_WARNING

Condiciones de advertencia.

LTTNG_UST_TRACEPOINT_LOGLEVEL_NOTICE

Condición normal, pero significativa.

LTTNG_UST_TRACEPOINT_LOGLEVEL_INFO

Mensaje informativo.

LTTNG_UST_TRACEPOINT_LOGLEVEL_DEBUG_SYSTEM

Información de depuración con alcance a nivel de sistema (conjunto de programas).

LTTNG_UST_TRACEPOINT_LOGLEVEL_DEBUG_PROGRAM

Información de depuración con alcance a nivel de programa (conjunto de procesos).

LTTNG_UST_TRACEPOINT_LOGLEVEL_DEBUG_PROCESS

Información de depuración con alcance a nivel de proceso (conjunto de módulos).

LTTNG_UST_TRACEPOINT_LOGLEVEL_DEBUG_MODULE

Información de depuración con alcance a nivel de módulo (ejecutable/biblioteca) (conjunto de unidades).

LTTNG_UST_TRACEPOINT_LOGLEVEL_DEBUG_UNIT

Información de depuración con alcance a nivel de unidad de compilación (conjunto de funciones).

LTTNG_UST_TRACEPOINT_LOGLEVEL_DEBUG_FUNCTION

Información de depuración con alcance a nivel de función.

LTTNG_UST_TRACEPOINT_LOGLEVEL_DEBUG_LINE

Información de depuración con alcance a nivel de línea (nivel de registro predeterminado).

LTTNG_UST_TRACEPOINT_LOGLEVEL_DEBUG

Mensaje a nivel de depuración.

Para usar lttng_ust_tracelog() o lttng_ust_vtracelog(), incluye <lttng/tracelog.h> donde lo necesites y enlaza tu aplicación con liblttng-ust y liblttng-ust-common. Consulta la sección EJEMPLO más abajo para un ejemplo de uso completo.

Una vez que tu aplicación esté instrumentada con llamadas a lttng_ust_tracelog() y/o lttng_ust_vtracelog() y lista para ejecutarse, usa lttng-enable-event(1) para habilitar el evento lttng_ust_tracelog:*. Puedes aislar niveles de registro específicos con las opciones --loglevel y --loglevel-only de este comando.

Los eventos lttng_ust_tracelog() y lttng_ust_vtracelog() contienen los siguientes campos:

Nombre del campo Descripción
line Línea en el archivo fuente donde se llamó a lttng_ust_tracelog().
file Archivo fuente desde el cual se llamó a lttng_ust_tracelog().
func Nombre de la función desde la cual se llamó a lttng_ust_tracelog().
msg Salida de cadena formateada.

Si no necesitas adjuntar un nivel de registro específico a una llamada de lttng_ust_tracelog()/lttng_ust_vtracelog(), usa lttng_ust_tracef(3) en su lugar.

Consulta también la sección LIMITACIONES más abajo para limitaciones importantes a considerar al usar lttng_ust_tracelog() o lttng_ust_vtracelog().

EJEMPLO

Aquí tienes un ejemplo de uso de lttng_ust_tracelog():

#include <stdlib.h>
#include <lttng/tracelog.h>
int main(int argc, char *argv[])
{
    int i;
    if (argc < 2) {
        lttng_ust_tracelog(LTTNG_UST_TRACEPOINT_LOGLEVEL_CRIT,
                           "No hay suficientes argumentos: %d", argc);
        return EXIT_FAILURE;
    }
    lttng_ust_tracelog(LTTNG_UST_TRACEPOINT_LOGLEVEL_INFO,
                       "Iniciando la aplicación con %d argumentos", argc);
    for (i = 0; i < argc; i++) {
        lttng_ust_tracelog(LTTNG_UST_TRACEPOINT_LOGLEVEL_DEBUG,
                           "Argumento %d: %s", i, argv[i]);
    }
    lttng_ust_tracelog(LTTNG_UST_TRACEPOINT_LOGLEVEL_INFO,
                       "Saliendo de la aplicación");
    return EXIT_SUCCESS;
}

Este archivo fuente de C, guardado como app.c, se puede compilar en un programa de la siguiente manera:

$ cc -o app app.c -llttng-ust -llttng-ust-common

Puedes crear una sesión de rastreo LTTng, habilitar todos los eventos de lttng_ust_tracelog() y iniciar la sesión de rastreo creada de la siguiente manera:

$ lttng create my-session
$ lttng enable-event --userspace 'lttng_ust_tracelog:*'
$ lttng start

O puedes habilitar los eventos de lttng_ust_tracelog() que coincidan con un nivel de registro al menos tan severo como un nivel de registro dado:

$ lttng enable-event --userspace 'lttng_ust_tracelog:*' \
                     --loglevel=INFO

A continuación, inicia el programa a rastrear:

$ ./app a few arguments passed to this application

Finalmente, detén la sesión de rastreo e inspecciona los eventos grabados:

$ lttng stop
$ lttng view

LIMITACIONES

Las macros de utilidad lttng_ust_tracelog() y lttng_ust_vtracelog() se desarrollaron para hacer que el rastreo en el espacio de usuario sea súper simple, aunque con desventajas notables en comparación con proveedores de puntos de rastreo completos y personalizados:

•Todos los eventos generados tienen los mismos nombres de proveedor/evento.
•No hay verificación estática de tipos.
•El único campo de evento con datos de usuario que realmente obtienes, llamado msg, es una cadena que potencialmente contiene los valores que pasaste a la macro usando tu propio formato. Esto también significa que no puedes usar filtrado con una expresión personalizada en tiempo de ejecución porque no hay campos aislados.
•Dado que lttng_ust_tracelog() y lttng_ust_vtracelog() utilizan la función vasprintf(3) de la biblioteca estándar de C en segundo plano para formatear las cadenas en tiempo de ejecución, su rendimiento esperado es menor que el uso de proveedores de puntos de rastreo personalizados con campos tipados, que no requieren una conversión a una cadena.
•En general, una cadena que contiene la representación textual de los campos de datos de usuario no es tan compacta como los campos binarios en el rastreo resultante.

Por lo tanto, lttng_ust_tracelog()/lttng_ust_vtracelog() son útiles para la creación rápida de prototipos y la depuración, pero no deben considerarse para ninguna instrumentación de aplicación permanente/seria.

lttng_ust_tracelog(3)

NAME

lttng_ust_tracelog - emit a tracepoint event with a formatted string

SYNOPSIS

#include <lttng/tracef.h>

void lttng_ust_tracelog(const char *format, ...);

DESCRIPTION

The lttng_ust_tracelog macro is a convenience wrapper around lttng_ust_tracef(3). It takes a format string and a variable number of arguments, formats them into a string, and then emits a tracepoint event with that string.

This macro is intended to be used with tracepoints that have a format string field.

EXAMPLE

The following example shows how to emit a tracepoint event with a formatted string:

#include <lttng/tracef.h>

void function(int value)
{
    lttng_ust_tracelog("Processing value: %d", value);
    /* ... */
}

LIMITATIONS

lttng_ust_tracelog() does not have a STAP_PROBEV() call, because STAP_PROBEV() does not support va_list. If you need it, you should emit this call yourself.

See lttng-ust(3) to learn more about custom tracepoint providers.
