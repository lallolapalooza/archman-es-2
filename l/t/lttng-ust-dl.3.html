NOMBRE

lttng-ust-dl - Rastreo del enlazador dinámico (utilidad de LTTng-UST)

SINOPSIS

Lanza tu aplicación pre-cargando liblttng-ust-dl.so:

$ LD_PRELOAD=liblttng-ust-dl.so mi-app

DESCRIPCIÓN

Cuando la biblioteca liblttng-ust-dl.so se precarga antes de que comience una aplicación dada, hace que todas las llamadas a dlopen(3) y dlclose(3) en dicha aplicación se rastreen con LTTng-UST (ver lttng-ust(3)).

Consulta lttng(1) para saber más sobre cómo controlar las sesiones de rastreo de LTTng.


Importante

Esta utilidad de LTTng-UST también puede emitir eventos de carga/descarga de bibliotecas compartidas (ver Rastreo de carga/descarga de bibliotecas compartidas en lttng-ust(3)). NO debes usar los registros de eventos generados por esta utilidad de LTTng-UST (precedidos por lttng_ust_dl:) para rastrear la carga y descarga de bibliotecas compartidas, especialmente en situaciones donde una biblioteca cargada dinámicamente carga sus propias dependencias. En su lugar, precarga liblttng-ust-dl.so, pero utiliza los registros de eventos de carga/descarga de bibliotecas compartidas, que son más fiables, para tu análisis de rastreo.

Los siguientes eventos de LTTng-UST están disponibles al usar esta biblioteca.

lttng_ust_dl:dlopen

Emitido cuando se llama a dlopen(3).

Campos:

Nombre del campo Descripción
baddr Dirección base de la biblioteca cargada.
memsz Tamaño de la biblioteca cargada en memoria.
flags Marcas pasadas a dlopen(3).
path Ruta del archivo de la biblioteca cargada.
has_build_id Si la biblioteca cargada tiene o no un ID de compilación. Si este campo es 1, puedes esperar que un registro de evento lttng_ust_dl:build_id siga a este (no necesariamente de inmediato).
has_debug_link Si la biblioteca cargada tiene o no información de enlace de depuración. Si este campo es 1, puedes esperar que un registro de evento lttng_ust_dl:debug_link siga a este (no necesariamente de inmediato).

lttng_ust_dl:dlmopen

Emitido cuando se llama a dlmopen(3).

Campos:

Nombre del campo Descripción
baddr Dirección base de la biblioteca cargada.
memsz Tamaño de la biblioteca cargada en memoria.
nsid ID del espacio de nombres en el que se carga la biblioteca (como se pasa a dlmopen(3)).
flags Marcas pasadas a dlmopen(3).
path Ruta del archivo de la biblioteca cargada.
has_build_id Si la biblioteca cargada tiene o no un ID de compilación. Si este campo es 1, puedes esperar que un registro de evento lttng_ust_dl:build_id siga a este (no necesariamente de inmediato).
has_debug_link Si la biblioteca cargada tiene o no información de enlace de depuración. Si este campo es 1, puedes esperar que un registro de evento lttng_ust_dl:debug_link siga a este (no necesariamente de inmediato).

lttng_ust_dl:dlclose

Emitido cuando se llama a dlclose(3).

Campos:

Nombre del campo Descripción
baddr Dirección base de la biblioteca cargada.

lttng_ust_dl:debug_link

Emitido cuando se encuentra información de enlace de depuración al cargar una biblioteca con dlopen(3). Ver Información de depuración en archivos separados https://sourceware.org/gdb/onlinedocs/gdb/Separate-Debug-Files.html para más información sobre enlaces de depuración.

Campos:

Nombre del campo Descripción
baddr Dirección base de la biblioteca cargada.
filename Nombre del archivo de enlace de depuración.
crc CRC del archivo de enlace de depuración.

lttng_ust_dl:build_id

Emitido cuando se encuentra un ID de compilación al cargar una biblioteca con dlopen(3). Ver Información de depuración en archivos separados https://sourceware.org/gdb/onlinedocs/gdb/Separate-Debug-Files.html para más información sobre IDs de compilación.

Campos:

Nombre del campo Descripción
baddr Dirección base de la biblioteca cargada.
build_id ID de compilación.

NAME

lttng-ust-dl — LTTng user space tracer dynamic library

SYNOPSIS

#include <lttng/tracef.h>

#include <lttng/trace.h>

#include <lttng/trap.h>

#include <lttng/log.h>

#include <lttng/events.h>

DESCRIPTION

The LTTng-UST (Linux Trace Toolkit Next - User Space Tracer) dynamic library provides the API for instrumenting C/C++ user space applications. This library is linked to your application at runtime using the dlopen call.

It allows you to emit tracepoints, log messages, and generate events in your applications.

See lttng-ust(3) for more details on the LTTng-UST instrumentation API.
