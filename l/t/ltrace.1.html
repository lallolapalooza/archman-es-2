LTRACE(1) Comandos de usuario LTRACE(1)

NOMBRE

ltrace - Un rastreador de llamadas a bibliotecas

SINOPSIS

ltrace [-e filtro|-L] [-l|--library=patrón_biblioteca] [-x filtro] [-S] [-b|--no-signals] [-i] [-w|--where=nr] [-r|-t|-tt|-ttt] [-T] [-F nombre_archivo] [-A maxelts] [-s tamaño_str] [-C|--demangle] [-a|--align columna] [-n|--indent nr] [-o|--output nombre_archivo] [-D|--debug máscara] [-u nombre_usuario] [-f] [-p pid] [[--] comando [arg ...]]

ltrace -c [-e filtro|-L] [-l|--library=patrón_biblioteca] [-x filtro] [-S] [-o|--output nombre_archivo] [-f] [-p pid] [[--] comando [arg ...]]

ltrace -V|--version

ltrace -h|--help

DESCRIPCIÓN

ltrace es un programa que simplemente ejecuta el comando especificado hasta que este termina. Intercepta y registra las llamadas a bibliotecas dinámicas que son realizadas por el proceso ejecutado y las señales que recibe dicho proceso. También puede interceptar e imprimir las llamadas al sistema ejecutadas por el programa.

Su uso es muy similar a strace(1).

OPCIONES

-a, --align columna
Alinea los valores de retorno en una columna específica (la columna predeterminada es 5/8 de la anchura de la pantalla).
-A maxelts
Número máximo de elementos de array para imprimir antes de suprimir el resto con puntos suspensivos ("..."). Esto también limita el número de expansiones recursivas de estructuras.
-b, --no-signals
Desactiva la impresión de señales recibidas por el proceso rastreado.
-c
Cuenta el tiempo y las llamadas para cada llamada a biblioteca y reporta un resumen al final del programa.
-C, --demangle
Decodifica (demangle) los nombres de símbolos de bajo nivel en nombres de nivel de usuario. Además de eliminar cualquier prefijo de guion bajo inicial utilizado por el sistema, esto hace que los nombres de funciones de C++ sean legibles.
-D, --debug máscara
Muestra la salida de depuración del propio ltrace. máscara es un número con significado interno que no está realmente bien definido. Una máscara de 77 muestra todos los mensajes de depuración, que es lo que usualmente se necesita.
-e filtro
Una expresión calificadora que modifica qué llamadas a bibliotecas rastrear. El formato de la expresión de filtro se describe en la sección EXPRESIONES DE FILTRO. Si aparecen varias opciones -e en la línea de comandos, se rastrean las llamadas a bibliotecas que coinciden con cualquiera de ellas. Si no se proporciona -e, se asume @MAIN como predeterminado.
-f
Rastrea procesos hijos a medida que son creados por los procesos actualmente rastreados como resultado de las llamadas al sistema fork(2) o clone(2). El nuevo proceso se adjunta inmediatamente.
-F nombre_archivo
Carga un archivo de configuración alternativo. Normalmente, se leen /etc/ltrace.conf y ~/.ltrace.conf (este último solo si existe). Use esta opción para cargar el archivo o archivos dados en lugar de esos dos archivos predeterminados. Consulte ltrace.conf(5) para obtener detalles sobre la sintaxis de los archivos de configuración de ltrace.
-h, --help
Muestra un resumen de las opciones de ltrace y sale.
-i
Imprime el puntero de instrucción en el momento de la llamada a la biblioteca.
-l, --library patrón_biblioteca
Muestra solo llamadas a funciones implementadas por bibliotecas que coinciden con patrón_biblioteca. Se pueden especificar varios patrones de bibliotecas con varias instancias de esta opción. La sintaxis de patrón_biblioteca se describe en la sección EXPRESIONES DE FILTRO.

Tenga en cuenta que aunque esta opción selecciona llamadas que podrían dirigirse a las bibliotecas seleccionadas, no hay garantía real de que la llamada no se dirija a otro lugar debido a, por ejemplo, LD_PRELOAD o simplemente al orden de las dependencias. Si desea asegurarse de que los símbolos en una biblioteca dada se llamen realmente, use -x @patrón_biblioteca en su lugar.

-L
Cuando no se proporciona la opción -e, no asuma la acción predeterminada de @MAIN.
-n, --indent nr
Indenta la salida del rastreo en nr espacios por cada nivel de anidamiento de llamadas. El uso de esta opción hace que la visualización del flujo del programa sea fácil de seguir. Esto indenta inútilmente también las funciones que nunca retornan, como las funciones de servicio para lanzar excepciones en el tiempo de ejecución de C++.
-o, --output nombre_archivo
Escribe la salida del rastreo en el archivo nombre_archivo en lugar de en stderr.
-p pid
Adjunta al proceso con el ID de proceso pid y comienza a rastrear. Esta opción se puede usar junto con la especificación de un comando para ejecutar. Es posible adjuntar a varios procesos especificando más de una opción -p.
-r
Imprime una marca de tiempo relativa con cada línea del rastreo. Esto registra la diferencia de tiempo entre el inicio de líneas sucesivas.
-s tamaño_str
Especifica el tamaño máximo de cadena a imprimir (el valor predeterminado es 32).
-S
Muestra llamadas al sistema además de llamadas a bibliotecas.
-t
Prefija cada línea del rastreo con la hora del día.
-tt
Si se especifica dos veces, la hora impresa incluirá los microsegundos.
-ttt
Si se especifica tres veces, la hora impresa incluirá los microsegundos y la parte inicial se imprimirá como el número de segundos desde la época.
-T
Muestra el tiempo empleado dentro de cada llamada. Esto registra la diferencia de tiempo entre el inicio y el final de cada llamada.
-u nombre_usuario
Ejecuta el comando con el ID de usuario, ID de grupo y grupos suplementarios de nombre_usuario. Esta opción solo es útil cuando se ejecuta como root y permite la ejecución correcta de binarios setuid y/o setgid.
-w, --where nr
Muestra el backtrace de nr marcos de pila para cada función rastreada. Esta opción solo está habilitada si el soporte libunwind se habilitó en tiempo de compilación.
-x filtro
Una expresión calificadora que modifica qué puntos de entrada de la tabla de símbolos rastrear. El formato de la expresión de filtro se describe en la sección EXPRESIONES DE FILTRO. Si aparecen varias opciones -x en la línea de comandos, se rastrean los símbolos que coinciden con cualquiera de ellas. No se rastrean puntos de entrada si no se proporciona ninguno.
-V, --version
Muestra el número de versión de ltrace y sale.

EXPRESIONES DE FILTRO

La expresión de filtro es una cadena de reglas basadas en glob o expresiones regulares que se utilizan para seleccionar símbolos a rastrear de las bibliotecas que utiliza el proceso. La mayor parte es intuitiva, por lo que, como ejemplo, lo siguiente rastrearía las llamadas a malloc y free, excepto aquellas realizadas por libc:

-e malloc+free-@libc.so*

Esto se lee: rastrear malloc y free, pero no rastrear nada que provenga de libc. Semi-formalmente, la sintaxis del ejemplo anterior se parece aproximadamente a esto:

{[+-][patrón_símbolo][@patrón_biblioteca]}

patrón_símbolo se utiliza para hacer coincidir nombres de símbolos, patrón_biblioteca para hacer coincidir SONAMEs de bibliotecas. Ambos son globs implícitos, pero también pueden ser expresiones regulares (ver más abajo). La sintaxis de glob soporta los metacaracteres * y ? y las clases de caracteres, de forma similar a lo que soporta el glob básico de bash. ^ y $ se reconocen para significar, respectivamente, el inicio y el fin del nombre dado.

Tanto patrón_símbolo como patrón_biblioteca deben coincidir con el nombre completo. Si solo desea hacer coincidir una parte del nombre, rodéelo con uno o dos asteriscos * según corresponda. BUGS

Tiene la mayoría de los errores indicados en strace(1).

Solo funciona en Linux y en un pequeño subconjunto de arquitecturas.

Si desea informar de un error, envíe un mensaje a la lista de correo (ltrace-devel@lists.alioth.debian.org), o use el programa reportbug(1) si se encuentra en la distribución Debian GNU/Linux.
