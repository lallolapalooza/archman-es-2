ltximg(1) Manual de comandos generales ltximg(1)

NOMBRE

ltximg - Entornos LaTeX a imagen y archivos independientes

SINOPSIS

ltximg [<opciones>] [--] <nombre_archivo>.<tex|ltx>

DESCRIPCIÓN

ltximg automatiza el proceso de extracción y conversión de entornos de un archivo LaTeX a formatos de imagen y archivos standalone utilizando ghostscript y poppler-utils. Genera un archivo con solo los entornos extraídos y otro con todos los entornos extraídos convertidos a "\includegraphics".

Por defecto, los entornos extraídos son:

preview pspicture tikzpicture pgfpicture psgraph postscript PSTexample

OPCIONES

Las opciones que aceptan un valor requieren un espacio en blanco o un "=" entre la opción y el valor. Se pueden agrupar múltiples opciones cortas y si la última opción toma una lista separada por comas, necesitará "--" al final. No se admiten rutas relativas o absolutas para directorios y archivos.

Si se usa sin [<opciones>], los entornos extraídos se convierten al formato de imagen pdf y se guardan en el directorio "./images" usando "pdflatex" y el paquete preview para el proceso.

Opciones generales del script:

-h, --help
Muestra la ayuda de la línea de comandos y sale.
-v, --version
Muestra la versión actual y sale.
-V, --verbose
Imprime información detallada.
-l, --log
Escribe un archivo ".log" con información de depuración.
-t, --tif
Crea archivos ".tif" usando ghostscript.
-b, --bmp
Crea archivos ".bmp" usando ghostscript.
-j, --jpg
Crea archivos ".jpg" usando ghostscript.
-p, --png
Crea archivos ".png" usando ghostscript.
-e, --eps
Crea archivos ".eps" usando pdftops.
-s, --svg
Crea archivos ".svg" usando pdftocairo.
-P, --ppm
Crea archivos ".ppm" usando pdftoppm.
-g, --gray
Escala de grises para imágenes usando ghostscript.
-f, --force
Captura "\psset" y "\tikzset" para extraer.
-n, --noprew
Crea archivos de imagen sin el paquete preview.
-r entero, --runs=entero
Establece el número de veces que el compilador se ejecutará en el archivo entrada para la extracción de entornos (predeterminado: 1).
-d entero, --dpi=entero
Resolución de puntos por pulgada para imágenes (predeterminado: 150).
-m entero, --margins=entero
Establece márgenes en bp para pdfcrop (predeterminado: 0).
-o nombre_archivo, --output=nombre_archivo
Crea el archivo de salida.
--imgdir=nombre_dir
Establece el nombre del directorio donde guardar imágenes y archivos (predeterminado: images).
--prefix=cadena
Establece el prefijo a añadir a cada archivo generado (predeterminado: fig).
--myverb=nombre_macro
Añade "\macroname" a la búsqueda literal en línea (predeterminado: myverb).
--clean=doc|pst|tkz|all|off
Elimina texto específico de bloques en el archivo de salida (predeterminado: doc).
--zip
Comprime los archivos generados en formato ".zip".
--tar
Comprime los archivos generados en formato ".tar.gz".
--srcenv
Crea archivos solo con el código de los entornos.
--subenv
Crea archivos independientes para los entornos.
--shell
Habilita "\write18{COMANDO SHELL}".
--latex
Utiliza "latex>dvips>ps2pdf" para el compilador de entrada y "pdflatex" para la salida del compilador.
--dvips
Utiliza "latex>dvips>ps2pdf" para el compilador de entrada y "latex>dvips>ps2pdf" para la salida del compilador.
--dvilua
Utiliza "dvilualatex>dvips>ps2pdf" para el compilador de entrada y "lualatex" para la salida del compilador.
--dvipdf
Utiliza "latex>dvipdfmx" para el compilador de entrada y "latex>dvipdfmx" para la salida del compilador.
--xetex
Utiliza "xelatex" para la entrada y salida del compilador.
--luatex
Utiliza "lualatex" para la entrada y salida del compilador.
--arara
Utiliza "arara" para la entrada y salida del compilador.
--latexmk
Utiliza "latexmk" para el archivo de salida del compilador.
--norun
Ejecuta el script, pero no crea archivos de imagen.
--nopdf
No crea archivos de imagen ".pdf".
--nocrop
No ejecuta pdfcrop.
--extrenv=env1,env2,...
Añade nuevos entornos para extraer.
--skipenv=env1,env2,...
Omite algunos entornos predeterminados para extraer.
--verbenv=env1,env2,...
Añade nuevos entornos literales.
--writenv=env1,env2,...
Añade nuevos entornos de escritura literal.
--deltenv=env1,env2,...
Elimina entornos en el archivo de salida.

EJEMPLO

ltximg --latex -e -p --subenv -o test-out.ltx test-in.ltx

Crea un directorio "./images" (si no existe) con todos los entornos extraídos convertidos a ".pdf",

EJEMPLO

Este comando crea los archivos ".eps", ".png" y archivos independientes, un archivo test-in-fig-all.ltx con todos los entornos extraídos y el archivo test-out.ltx con todos los entornos convertidos a "\includegraphics" usando "latex>dvips>ps2pdf" y el paquete preview para test-in.ltx y "pdflatex" para test-out.ltx.
