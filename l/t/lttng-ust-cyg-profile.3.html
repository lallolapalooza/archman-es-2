LTTNG-UST-CYG-PRO(3) Manual de LTTng LTTNG-UST-CYG-PRO(3)

NOMBRE

lttng-ust-cyg-profile - Rastreo de funciones (ayudante de LTTng-UST)

SINOPSIS

Compila tu aplicación con la opción del compilador -finstrument-functions.

Inicia tu aplicación precargando liblttng-ust-cyg-profile-fast.so para un rastreo de funciones rápido:

$ LD_PRELOAD=liblttng-ust-cyg-profile-fast.so mi-app

Inicia tu aplicación precargando liblttng-ust-cyg-profile.so para un rastreo de funciones más lento y verboso:

$ LD_PRELOAD=liblttng-ust-cyg-profile.so mi-app

DESCRIPCIÓN

Cuando la biblioteca liblttng-ust-cyg-profile.so o liblttng-ust-cyg-profile-fast.so se precarga antes de que comience una aplicación dada, todos los puntos de entrada y retorno de funciones son rastreados por LTTng-UST (ver lttng-ust(3)), siempre que dicha aplicación se haya compilado con la opción del compilador -finstrument-functions.

Consulta lttng(1) para obtener más información sobre cómo controlar las sesiones de rastreo de LTTng.

El rastreo de funciones con LTTng-UST viene en dos sabores, cada uno proporcionando un equilibrio diferente entre rendimiento y robustez:

liblttng-ust-cyg-profile-fast.so

Esta es una variante ligera que solo debe usarse donde se pueda *garantizar* que el flujo completo de eventos se registra sin eventos faltantes. Se omite cualquier tipo de información duplicada.

En cada entrada de función, la dirección de la función llamada se registra en un evento LTTng-UST. Las salidas de función se registran como otro evento LTTng-UST vacío.

Consulta la sección Rastreo rápido de funciones a continuación para ver la lista completa de eventos emitidos y sus campos.

liblttng-ust-cyg-profile.so

Esta es una variante más robusta que también funciona para casos de uso donde los eventos podrían ser descartados o no registrados desde el inicio de la aplicación. En estos casos, el analizador de rastreo necesita información adicional para poder reconstruir el flujo del programa.

En cada entrada *y* salida de función, la dirección de la función llamada *y* la dirección del punto de llamada se registran en un evento LTTng-UST.

Consulta la sección Rastreo detallado de funciones a continuación para ver la lista completa de eventos emitidos y sus campos.

USO

Para utilizar el rastreo de funciones LTTng-UST, debes asegurarte de que las fuentes de tu aplicación se compilen con la opción del compilador -finstrument-functions.

Puede ser necesario limitar el número de archivos fuente donde se utiliza esta opción para evitar una cantidad excesiva de datos de rastreo en tiempo de ejecución. Por lo general, hay indicadores de compilador adicionales que permiten especificar una selección más detallada de la instrumentación de funciones.

Para cada función instrumentada, el ejecutable contendrá llamadas a hooks de funciones de perfilado (después de la entrada de la función, llamado __cyg_profile_func_enter(), y justo antes de la salida de la función, llamado __cyg_profile_func_exit()).

Al precargar (usando la variable de entorno LD_PRELOAD) una de las bibliotecas compartidas proporcionadas, estos hooks de funciones se definen para emitir eventos LTTng (como se describe a continuación).


Nota

El uso de esta función puede generar una **cantidad masiva** de datos de rastreo en la aplicación instrumentada. El tiempo de ejecución de la aplicación también se ve considerablemente afectado. Ten cuidado en sistemas con recursos limitados.

RASTREO RÁPIDO DE FUNCIONES

Los siguientes eventos LTTng-UST están disponibles al usar liblttng-ust-cyg-profile-fast.so. Su nivel de registro se establece en LTTNG_UST_TRACEPOINT_LOGLEVEL_DEBUG_FUNCTION.

lttng_ust_cyg_profile_fast:func_entry

Emitido cuando se entra en una función de la aplicación, o más específicamente, cuando se llama a __cyg_profile_func_enter().

Campos:

Nombre del campo Descripción
func_addr Dirección de la función.

lttng_ust_cyg_profile_fast:func_exit

Emitido cuando una función de la aplicación retorna, o más específicamente, cuando se llama a __cyg_profile_func_exit().

Este evento no tiene campos. Dado que la biblioteca liblttng-ust-cyg-profile-fast.so solo debe usarse cuando se puede garantizar que el flujo completo de eventos se registra sin eventos faltantes, se puede usar un enfoque basado en pila, por hilo, en el lado del analizador de rastreo para emparejar los eventos de entrada y retorno de funciones.

RASTREO DETALLADO DE FUNCIONES

Los siguientes eventos LTTng-UST están disponibles al usar liblttng-ust-cyg-profile.so. Su nivel de registro se establece en LTTNG_UST_TRACEPOINT_LOGLEVEL_DEBUG_FUNCTION.

lttng_ust_cyg_profile:func_entry

Emitido cuando se entra en una función de la aplicación, o más específicamente, cuando se llama a __cyg_profile_func_enter().

Campos:

Nombre del campo Descripción
func_addr Dirección de la función.
call_site Dirección desde la cual se llamó a esta función.

lttng_ust_cyg_profile:func_exit

Emitido cuando una función de la aplicación retorna, o más específicamente, cuando se llama a __cyg_profile_func_exit().

Campos:

Nombre del campo Descripción
func_addr Dirección de la función.
call_site Dirección desde la cual se llamó a esta función.

NAME

lttng-ust-cyg-profile - LTTng-UST Cyg profile

SYNOPSIS

#include <lttng/tracelog.h>

void lttng_cyg_profile(void);

void lttng_cyg_profile_start(void);

void lttng_cyg_profile_stop(void);

void lttng_cyg_profile_init(void);

void lttng_cyg_profile_exit(void);

void lttng_cyg_profile_sample(void);

void lttng_cyg_profile_reset(void);

void lttng_cyg_profile_dump(void);

DESCRIPTION

The LTTng-UST Cyg profile is a mechanism to gather profile data from a user-space application using LTTng-UST. It allows you to collect call stack information at regular intervals or on demand, and to save this data to the LTTng trace files.

The functions provided are:

lttng_cyg_profile
Starts or stops the Cyg profile depending on its current state.
lttng_cyg_profile_start
Starts the Cyg profile.
lttng_cyg_profile_stop
Stops the Cyg profile.
lttng_cyg_profile_init
Initializes the Cyg profile. This function should be called before any other Cyg profile functions.
lttng_cyg_profile_exit
Shuts down the Cyg profile. This function should be called before the application exits.
lttng_cyg_profile_sample
Triggers a profile sample. This function can be called manually to collect a profile sample at a specific point in time.
lttng_cyg_profile_reset
Resets the collected profile data.
lttng_cyg_profile_dump
Dumps the collected profile data to the LTTng trace files.
