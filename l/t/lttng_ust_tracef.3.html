lttng_ust_tracef(3)

Paquete: lttng-ust

Licencias: LGPL2.1, GPL2, MIT

LTTNG_UST_TRACEF(3) Manual de LTTng LTTNG_UST_TRACEF(3)

NOMBRE

lttng_ust_tracef, lttng_ust_vtracef - Interfaz LTTng-UST similar a printf(3)

SINOPSIS

#include <lttng/tracef.h>
#define lttng_ust_tracef(fmt, ...)
#define lttng_ust_vtracef(fmt, ap)

Enlace con:

•-llttng-ust
•Si defines _LGPL_SOURCE antes de incluir <lttng/tracef.h> (directa o indirectamente): -llttng-ust-common

DESCRIPCIÓN

La API LTTng-UST lttng_ust_tracef() y lttng_ust_vtracef() te permite rastrear tu aplicación con la ayuda de macros simples similares a printf(3) y vprintf(3).

El argumento fmt se pasa directamente como el parámetro fmt de vasprintf(3), así como:

Para lttng_ust_tracef()

Los parámetros opcionales que siguen a fmt.

Para lttng_ust_vtracef()

El parámetro ap como el parámetro ap de vasprintf(3) (tipo va_list).

Para usar lttng_ust_tracef() o lttng_ust_vtracef(), incluye <lttng/tracef.h> donde lo necesites y enlaza tu aplicación con liblttng-ust y liblttng-ust-common. Ve la sección EJEMPLO más abajo para un ejemplo de uso completo.

Una vez que tu aplicación esté instrumentada con llamadas a lttng_ust_tracef() y/o lttng_ust_vtracef() y lista para ejecutarse, usa lttng-enable-event(1) para habilitar el evento lttng_ust_tracef:*.

Los eventos lttng_ust_tracef() y lttng_ust_vtracef() contienen un único campo, llamado msg, que es la cadena de salida formateada.

Si necesitas adjuntar un nivel de registro específico a una llamada a lttng_ust_tracef()/lttng_ust_vtracef(), usa lttng_ust_tracelog(3) y lttng_ust_vtracelog(3) en su lugar.

Consulta también la sección LIMITACIONES más abajo para limitaciones importantes a considerar al usar lttng_ust_tracef() o lttng_ust_vtracef().

EJEMPLO

Aquí tienes un ejemplo de uso de lttng_ust_tracef():

#include <stdlib.h>
#include <lttng/tracef.h>
int main(void)
{
    int i;
    for (i = 0; i < 25; i++) {
        lttng_ust_tracef("mi mensaje: %s, este entero: %d",
                         "un mensaje", i);
    }
    return EXIT_SUCCESS;
}

Este archivo fuente C, guardado como app.c, se puede compilar en un programa así:

$ cc -o app app.c -llttng-ust -llttng-ust-common

Puedes crear una sesión de rastreo LTTng, habilitar los eventos lttng_ust_tracef() y comenzar la sesión de rastreo creada así:

$ lttng create my-session
$ lttng enable-event --userspace 'lttng_ust_tracef:*'
$ lttng start

A continuación, inicia el programa a rastrear:

$ ./app

Finalmente, detén la sesión de rastreo e inspecciona los eventos grabados:

$ lttng stop
$ lttng view

LIMITACIONES

Las macros de utilidad lttng_ust_tracef() y lttng_ust_vtracef() se desarrollaron para hacer el rastreo del espacio de usuario súper simple, aunque con desventajas notables en comparación con proveedores de tracepoints personalizados y completos:

•Todos los eventos generados tienen los mismos nombres de proveedor/evento.
•No hay comprobación estática de tipos.
•El único campo de evento con datos de usuario que realmente obtienes, llamado msg, es una cadena que potencialmente contiene los valores que pasaste a la macro usando tu propio formato. Esto también significa que no puedes usar el filtrado con una expresión personalizada en tiempo de ejecución porque no hay campos aislados.
•Dado que lttng_ust_tracef() y lttng_ust_vtracef() usan la función vasprintf(3) de la biblioteca estándar de C en segundo plano para formatear las cadenas en tiempo de ejecución, su rendimiento esperado es menor que el uso de proveedores de tracepoints personalizados con campos tipados, que no requieren una conversión a una cadena.
•En general, una cadena que contiene la representación textual de los campos de datos de usuario no es tan compacta como los campos binarios en el rastreo resultante.

Por lo tanto, lttng_ust_tracef()/lttng_ust_vtracef() son útiles para prototipado rápido y depuración, pero no deben ser considerados para ninguna instrumentación de aplicación permanente/seria.

lttng_ust_vtracef() no tiene una llamada STAP_PROBEV(), porque STAP_PROBEV() no soporta va_list. Si lo necesitas, deberías emitir esta llamada tú mismo.

Consulta lttng-ust(3) para aprender más sobre los proveedores de tracepoints personalizados.
