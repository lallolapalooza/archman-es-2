NOMBRE

lttng-gen-tp - Genera código de proveedor de puntos de traza LTTng-UST

SINOPSIS

lttng-gen-tp [--verbose] [--output=ARCHIVO.c]
             [--output=ARCHIVO.h] [--output=ARCHIVO.o] PLANTILLA

DESCRIPCIÓN

La herramienta lttng-gen-tp simplifica la generación de archivos de proveedor de puntos de traza LTTng-UST. Toma un archivo de plantilla simple, PLANTILLA, y genera el código C necesario para usar los puntos de traza definidos en tu aplicación. Consulta la sección Formato del archivo de plantilla a continuación para obtener más información sobre el formato de PLANTILLA.

Actualmente, lttng-gen-tp puede generar los archivos .h, .c y .o asociados con tu proveedor de puntos de traza. El archivo .h generado se puede incluir directamente en tu aplicación. Puedes dejar que lttng-gen-tp genere el archivo .o o compilar el archivo .c tú mismo. Consulta lttng-ust(3) para obtener más información sobre la compilación de proveedores de puntos de traza LTTng-UST.

Por defecto, lttng-gen-tp genera los archivos .h, .c y .o, cuyo nombre base es el nombre base de PLANTILLA. Puedes generar uno o más tipos de archivo específicos con la opción --output, repetida si es necesario.

Formato del archivo de plantilla

El archivo de plantilla, que normalmente tiene la extensión .tp, contiene una lista de definiciones LTTNG_UST_TRACEPOINT_EVENT() y otras entradas de definición opcionales, como LTTNG_UST_TRACEPOINT_LOGLEVEL(). Consulta lttng-ust(3) para la lista completa de definiciones disponibles.

Las definiciones LTTNG_UST_TRACEPOINT_EVENT() se escriben como las escribirías en un archivo de cabecera de proveedor de plantilla LTTng-UST. Se admiten comentarios en C (/* */ y //), así como líneas que comienzan con #.


Nota

El nombre del proveedor (el primer argumento de LTTNG_UST_TRACEPOINT_EVENT()) debe ser el mismo en todas las macros LTTNG_UST_TRACEPOINT_EVENT() de PLANTILLA.

Aquí tienes un ejemplo:

LTTNG_UST_TRACEPOINT_EVENT(
    // Nombre del proveedor de punto de traza
    mi_proveedor,
    // Nombre del punto de traza/evento
    mi_evento,
    // Argumentos del punto de traza (entrada)
    LTTNG_UST_TP_ARGS(char *, texto),
    // Campos del punto de traza/evento (salida)
    LTTNG_UST_TP_FIELDS(
        lttng_ust_field_string(mensaje, texto)
    )
)

OPCIONES

-o, --output=ARCHIVO

No generes archivos predeterminados: genera ARCHIVO.

La extensión de ARCHIVO determina qué se genera, entre .h, .c y .o. Esta opción se puede usar más de una vez para generar diferentes tipos de archivo.

-v, --verbose

Aumenta la verbosidad.

-h, --help

Muestra la ayuda del comando.

VARIABLES DE ENTORNO

CC

Compilador C a utilizar. Predeterminado: cc, luego gcc si cc no se encuentra. Esta opción solo es relevante al generar el archivo .o.

CFLAGS

Indicadores y opciones pasados directamente al compilador ($CC). Esta opción solo es relevante al generar el archivo .o.
