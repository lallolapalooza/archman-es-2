a64l(3) Manual de funciones de biblioteca a64l(3)

NOMBRE

a64l, l64a - convertir entre long y base-64

BIBLIOTECA

Biblioteca C estándar (libc, -lc)

SINOPSIS

#include <stdlib.h>
long a64l(const char *str64);
char *l64a(long value);
Requisitos de Macro de Prueba de Funciones para glibc (ver feature_test_macros(7)):

a64l(), l64a():

    _XOPEN_SOURCE >= 500
        || /* glibc >= 2.19: */ _DEFAULT_SOURCE
        || /* glibc <= 2.19: */ _SVID_SOURCE

DESCRIPCIÓN

Estas funciones proporcionan una conversión entre enteros long de 32 bits y cadenas ASCII de base-64 little-endian (de longitud cero a seis). Si la cadena utilizada como argumento para a64l() tiene una longitud mayor que seis, solo se utilizan los primeros seis bytes. Si el tipo long tiene más de 32 bits, entonces l64a() utiliza solo los 32 bits de orden bajo de value, y a64l() extiende el signo de su resultado de 32 bits.

Los 64 dígitos en el sistema base-64 son:

'.'	representa un 0
'/'	representa un 1
0-9	representan  2-11
A-Z	representan 12-37
a-z	representan 38-63

Así que 123 = 59*64^0 + 1*64^1 = "v/".

ATRIBUTOS

Para una explicación de los términos utilizados en esta sección, consulte attributes(7).

Interfaz Atributo Valor
l64a () Seguridad en hilos MT-Unsafe race:l64a
a64l () Seguridad en hilos MT-Safe

ESTÁNDARES

POSIX.1-2008.

HISTORIAL

POSIX.1-2001.

NOTAS

El valor devuelto por l64a() puede ser un puntero a un búfer estático, posiblemente sobrescrito por llamadas posteriores.

El comportamiento de l64a() no está definido cuando value es negativo. Si value es cero, devuelve una cadena vacía.

Estas funciones están rotas antes de glibc 2.2.5 (pone el dígito más significativo primero).

Esta no es la codificación utilizada por uuencode(1).

VER TAMBIÉN

uuencode(1), strtoul(3)
