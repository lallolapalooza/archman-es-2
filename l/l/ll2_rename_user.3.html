LL2_RENAME_USER(3) Manual del programador LL2_RENAME_USER(3)

NOMBRE

ll2_rename_user - Renombra una entrada de usuario.

SINOPSIS

#include <lastlog2.h>

int ll2_rename_user (struct ll2_context *context, const char *user, const char *newname, char **error);

DESCRIPCIÓN

Cambia el nombre de usuario de user a newname de una entrada en la base de datos, definida por context. Todas las demás entradas con el usuario user serán eliminadas. Si context es NULL, se tomará la base de datos predeterminada, definida en LL2_DEFAULT_DATABASE.

char    *error = NULL;
const   char *user = "root";
const   char *new_user = "notroot";
int ret = ll2_rename_user (NULL, user, new_user, &error);

VALOR DE RETORNO

Devuelve 0 si tiene éxito, -ENOMEM o -1 en caso de otro fallo. error contiene una cadena de error si el valor de retorno es -1. No se garantiza que error contenga una cadena de error, también podría ser NULL. error debe ser liberado por el llamador.
