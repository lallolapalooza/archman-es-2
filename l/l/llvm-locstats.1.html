NOMBRE

llvm-locstats - calcula estadísticas sobre la ubicación de depuración DWARF

SINOPSIS

llvm-locstats [opciones] [nombre_archivo]

DESCRIPCIÓN

llvm-locstats funciona como un envoltorio para llvm-dwarfdump. Analiza las estadísticas de llvm-dwarfdump con respecto a la ubicación de depuración, mostrando la información de forma más legible.

La línea 0% muestra el número y el porcentaje de DIEs sin información de ubicación, mientras que la línea 100% muestra la información para los DIEs donde hay información de ubicación en todos los bytes de la sección de código (donde la variable o el parámetro está en el ámbito). La línea [50%,60%) muestra el número y el porcentaje de DIEs donde la información de ubicación cubre entre el 50 y el 60 por ciento de su ámbito.

OPCIONES

--only-variables
calcula las estadísticas de ubicación solo para variables locales
--only-formal-parameters
calcula las estadísticas de ubicación solo para parámetros formales
--ignore-debug-entry-values
ignora las estadísticas de ubicación en ubicaciones que contienen la operación DWARF de valores de entrada de depuración
--draw-plot
crea un histograma de los cubos de ubicación generados (requiere matplotlib)
--compare
compara la cobertura de ubicación de depuración en dos archivos proporcionados y crea un gráfico que muestra la diferencia (requiere matplotlib)

ESTADO DE SALIDA

llvm-locstats devuelve 0 si el archivo de entrada se analizó correctamente. De lo contrario, devuelve 1.

EJEMPLO 1

Imprime la cobertura de ubicación en la salida estándar.

llvm-locstats a.out
  =================================================
            Estadísticas de ubicación de depuración
  =================================================
        cov%          muestras       porcentaje(~)
  -------------------------------------------------
     0%                    1              16%
     (0%,10%)              0               0%
     [10%,20%)             0               0%
     [20%,30%)             0               0%
     [30%,40%)             0               0%
     [40%,50%)             0               0%
     [50%,60%)             1              16%
     [60%,70%)             0               0%
     [70%,80%)             0               0%
     [80%,90%)             1              16%
     [90%,100%)            0               0%
     100%                  3              50%
  =================================================
  -número de variables de depuración procesadas: 6
  -rangos de PC cubiertos: 81%
  -------------------------------------------------
  -disponibilidad total: 83%
  =================================================

EJEMPLO 2

Genera un gráfico como un archivo de imagen.

llvm-locstats --draw-plot file1.out

EJEMPLO 3

Genera un gráfico como un archivo de imagen que muestra la diferencia en la cobertura de ubicación de depuración.

llvm-locstats --compare file1.out file1.withentryvals.out
