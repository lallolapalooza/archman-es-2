NOMBRE

llvm-objdump - Volcador de archivos de objeto de LLVM

SINOPSIS

llvm-objdump [comandos] [opciones] [nombres_de_archivo...]

DESCRIPCIÓN

La utilidad llvm-objdump imprime el contenido de los archivos de objeto e imágenes enlazadas finales nombrados en la línea de comandos. Si no se especifica ningún nombre de archivo, llvm-objdump intentará leer de a.out. Si se usa - como nombre de archivo, llvm-objdump procesará un archivo en su flujo de entrada estándar.

COMANDOS

Se requiere al menos uno de los siguientes comandos, y algunos comandos pueden combinarse con otros comandos:

-a, --archive-headers
Mostrar la información contenida en las cabeceras de un archivo.
-d, --disassemble
Desensamblar todas las secciones ejecutables encontradas en los archivos de entrada. En algunas arquitecturas (AArch64, PowerPC, x86), todas las instrucciones conocidas se desensamblan por defecto. En las demás, se necesita --mcpu o --mattr para habilitar algunos conjuntos de instrucciones. Las instrucciones deshabilitadas se muestran como <desconocido>.
-D, --disassemble-all
Desensamblar todas las secciones encontradas en los archivos de entrada.
--disassemble-symbols=<simbolo1[,simbolo2,...]>
Desensamblar solo los símbolos especificados. Toma nombres de símbolos desenmascarados cuando se especifica --demangle, de lo contrario toma nombres de símbolos enmascarados. Implica --disassemble.
--dwarf=<valor>
Volcar las secciones de depuración DWARF especificadas. Los valores soportados son:

frames - .debug_frame

-f, --file-headers
Mostrar el contenido de la cabecera general del archivo.
--fault-map-section
Mostrar el contenido de la sección de mapa de fallos.
-h, --headers, --section-headers
Mostrar resúmenes de las cabeceras de cada sección.
--help
Mostrar información de uso y salir. No se acumula con otros comandos.
-p, --private-headers
Mostrar cabeceras de archivo específicas del formato.
-r, --reloc
Mostrar las entradas de reubicación en el archivo.
-R, --dynamic-reloc
Mostrar las entradas de reubicación dinámicas en el archivo.
--raw-clang-ast
Volcar el contenido binario crudo de la sección AST de clang.
-s, --full-contents
Mostrar el contenido de cada sección.
-t, --syms
Mostrar la tabla de símbolos.
-T, --dynamic-syms
Mostrar el contenido de la tabla de símbolos dinámicos.
-u, --unwind-info
Mostrar la información de desenrollado de las entradas.

Esta operación actualmente solo es compatible con archivos de objeto COFF y Mach-O.

-v, --version
Mostrar la versión del ejecutable llvm-objdump. No se acumula con otros comandos.
-x, --all-headers
Mostrar toda la información de cabecera disponible. Equivalente a especificar --archive-headers, --file-headers, --private-headers, --reloc, --section-headers y --syms.

OPCIONES

llvm-objdump soporta las siguientes opciones:

--adjust-vma=<desplazamiento>
Aumentar la dirección mostrada en el desensamblado o la impresión de cabeceras de sección por el desplazamiento especificado.
--arch-name=<cadena>
Especificar la arquitectura de destino al desensamblar. Usar --version para una lista de destinos disponibles.
--build-id=<cadena>
Buscar el objeto usando el ID de construcción dado, especificado como una cadena hexadecimal. El objeto encontrado se maneja como si fuera un nombre de archivo de entrada.
-C, --demangle
Desenmascarar nombres de símbolos en la salida.
--debug-file-directory <ruta>
Proporcionar una ruta a un directorio con un subdirectorio .build-id para buscar información de depuración para binarios pelados. Múltiples instancias de este argumento se buscan en el orden dado.
--debuginfod, --no-debuginfod
Si se intentarán o no las búsquedas de debuginfod para binarios de depuración. A menos que se especifique, debuginfod solo se habilita si libcurl fue compilado (LLVM_ENABLE_CURL) y al menos una URL de servidor fue proporcionada por la variable de entorno DEBUGINFOD_URLS.
--debug-vars=<formato>
Imprimir las ubicaciones (en registros o memoria) de las variables a nivel de fuente junto con el desensamblado. formato puede ser unicode o ascii, por defecto es unicode si se omite.
--debug-vars-indent=<ancho>
Distancia para sangrar la visualización de variables a nivel de fuente, relativa al inicio del desensamblado. Por defecto son 52 caracteres.
-j, --section=<seccion1[,seccion2,...]>
Realizar comandos solo en las secciones especificadas. Para Mach-O usar segmento,seccion para especificar el nombre de la sección.
-l, --line-numbers
Al desensamblar, mostrar números de línea de origen. Implica --disassemble.
-M, --disassembler-options=<opt1[,opt2,...]>
Pasar opciones de desensamblador específicas del destino. Opciones disponibles:
  • reg-names-std: Solo ARM (por defecto). Imprime en la documentación del conjunto de instrucciones 's' de ARM, con r13/r14/r15 reemplazados por sp/lr/pc.
  • reg-names-raw: Solo ARM. Usa r seguido del número de registro.
  • no-aliases: Solo AArch64 y RISC-V. Imprime el mnemónico de instrucción cruda en lugar del mnemónico de instrucción pseudo.
  • numeric: Solo RISC-V. Imprime nombres de registro crudos en lugar de mnemónicos ABI. (por ejemplo, imprime x1 en lugar de ra)

  • intel: x86 solamente. Imprime en sintaxis Intel.
    • --disassembler-color=<modo>
    Habilita o deshabilita la salida en color del desensamblador.
    • off: Deshabilita la salida en color del desensamblador.
    • on: Habilita la salida en color del desensamblador.
    • terminal: Habilita la salida en color del desensamblador si la terminal lo soporta (por defecto).
    --mcpu=<nombre-cpu>
    Dirige a un tipo de CPU específico para el desensamblado. Especifica --mcpu=help para mostrar las CPUs disponibles.
    --mattr=<a1,+a2,-a3,...>
    Habilita/deshabilita atributos específicos del objetivo. Especifica --mattr=help para mostrar los atributos disponibles.
    -mllvm <arg>
    Especifica un argumento para pasar a la biblioteca CommandLine de LLVM.
    --no-leading-addr, --no-addresses
    Al desensamblar, no imprime direcciones iniciales para instrucciones o relocaciones en línea.
    --no-print-imm-hex
    No usa formato hexadecimal para valores inmediatos en la salida del desensamblado.
    --no-show-raw-insn
    Al desensamblar, no imprime los bytes crudos de cada instrucción.
    --offloading
    Muestra el contenido de las secciones de descarga de LLVM y los paquetes de descarga HIP.
    --prefix=<prefijo>
    Al desensamblar con la opción --source, antepone prefijo a las rutas absolutas.
    --prefix-strip=<nivel>
    Al desensamblar con la opción --source, elimina nivel directorios iniciales de las rutas absolutas. Esta opción no tiene efecto sin --prefix.
    --print-imm-hex
    Usa formato hexadecimal al imprimir valores inmediatos en la salida del desensamblado (por defecto).
    -S, --source
    Al desensamblar, muestra el código fuente intercalado con el desensamblado. Implica --disassemble.
    --show-all-symbols
    Muestra todos los símbolos durante el desensamblado, incluso si múltiples símbolos están definidos en la misma ubicación.
    --show-lma
    Muestra la columna LMA al volcar las cabeceras de sección ELF. Por defecto está desactivada a menos que alguna sección tenga VMA y LMA diferentes.
    --start-address=<dirección>
    Al desensamblar, solo desensambla desde la dirección especificada.

    Al imprimir relocaciones, solo imprime las relocaciones que corrigen los desplazamientos desde al menos dirección.

    Al imprimir símbolos, solo imprime símbolos con un valor de al menos dirección.

    --stop-address=<dirección>
    Al desensamblar, solo desensambla hasta, pero sin incluir, la dirección especificada.

    Al imprimir relocaciones, solo imprime las relocaciones que corrigen los desplazamientos hasta dirección.

    Al imprimir símbolos, solo imprime símbolos con un valor hasta dirección.

    --symbolize-operands
    Al desensamblar, simboliza un operando de destino de salto para imprimir una etiqueta en lugar de una dirección real.

    Al imprimir una referencia a símbolo global relativa al PC, la imprime como un desplazamiento desde el símbolo principal.

    Cuando una sección de mapa de direcciones de bloques básicos está presente (es decir, el archivo objeto se construye con -fbasic-block-address-map), se recuperan las etiquetas de esa sección en su lugar. Si un mapa de análisis pgo está presente junto con el mapa de bloques básicos, cualquier análisis disponible se imprime después de la etiqueta de bloque relevante. Por defecto, cualquier análisis con una representación especial (es decir, BlockFrequency, BranchProbability, etc.) se imprime como valores hexadecimales crudos.

    Solo compatible con AArch64, BPF, PowerPC y X86.

    Ejemplo:
    Una instrucción de salto no simbolizada con un destino local y acceso a memoria relativo al PC como
    cmp eax, dword ptr [rip + 4112]
jge 0x20117e <_start+0x25>

    podría convertirse en

    <L0>:
  cmp eax, dword ptr <g>
  jge      <L0>
    --pretty-pgo-analysis-map
    Al usar --symbolize-operands con mapa de direcciones de bloques básicos y mapa de análisis pgo, imprime los análisis usando el mismo formato que sus pases de análisis usarían. Un ejemplo de formato bonito sería imprimir frecuencias de bloques relativas al bloque de entrada, lo mismo que BFI.

    Solo funciona cuando --symbolize-operands está habilitado.

    --triple=<cadena>
    Triple de destino para desensamblar, ver --version para destinos disponibles.
    -w, --wide
    Ignorado por compatibilidad con GNU objdump.
    --x86-asm-syntax=<estilo>
    Obsoleto. Cuando se usa con --disassemble, elige el estilo de código a emitir desde el backend X86. Los valores soportados son:
    att
    Ensamblado estilo AT&T
    intel
    Ensamblado estilo Intel

    El estilo de desensamblado por defecto es att.

    -z, --disassemble-zeroes
    No omite bloques de ceros al desensamblar.
    @<ARCHIVO>
    Lee opciones de línea de comandos y comandos del archivo de respuesta <ARCHIVO>.

    OPCIONES Y COMANDOS SOLO PARA MACH-O

    --arch=<arquitectura>
    Especifica la arquitectura a desensamblar. ver --version para arquitecturas disponibles.
    --archive-member-offsets
    Imprime el desplazamiento a cada miembro del archivo para archivos Mach-O (requiere --archive-headers).
    --bind
    Muestra información de enlace
    --data-in-code
    Muestra la tabla de datos en código.
    --dis-symname=<nombre>
    Desensambla solo las instrucciones del símbolo especificado.
    --chained-fixups
    Imprime información de arreglos encadenados.
    --dyld-info
    Imprime información de enlace y reubicación utilizada por dyld para resolver referencias externas en un binario enlazado final.
    --dylibs-used
    Muestra las bibliotecas compartidas utilizadas para los archivos enlazados.
    --dsym=<cadena>
    Usa el archivo .dSYM para obtener información de depuración.
    --dylib-id
    Muestra el ID de la biblioteca compartida para archivos dylib.
    --exports-trie
    Muestra los símbolos exportados.
    --function-starts [=<addrs|names|both>]
    Imprime la tabla de inicios de funciones para objetos Mach-O. Ya sea addrs (por defecto) para imprimir solo las direcciones de las funciones, names para imprimir solo los nombres de las funciones (cuando estén disponibles), o both para imprimir los nombres junto a las direcciones.
    -g
    Imprime información de línea desde la información de depuración si está disponible.
    --full-leading-addr
    Imprime la dirección completa inicial
    --arch=arch
    Display object file information for the specified architecture.
    --archive-header
    Display the archive header information.
    --bind
    Display binding information.
    --code-view
    Display CodeView debug information.
    --data-value
    Print data values in disassembly output.
    --demangle
    Demangle C++ symbol names.
    --disassemble
    Disassemble the contents of the specified sections.
    --disassemble-flavor=flavor
    Use the specified disassembler flavor. Supported flavors are intel and att.
    -d, --disassemble
    Synonym for --disassemble.
    --dynamic-table
    Display the dynamic symbol table.
    --dylibs
    Display the dynamic library information.
    --exports
    Display the exported symbol information.
    --file-headers
    Display the file header information.
    -f
    Synonym for --file-headers.
    --full-leading-headers
    Print all leading headers.
    -g
    Display the debug symbol table.
    --headers
    Synonym for --file-headers.
    --indirect-symbols
    Display the indirect symbol table.
    --info-plist
    Display the info plist section as strings.
    --lazy-bind
    Display lazy binding info.
    --link-opt-hints
    Display the linker optimization hints.
    -m, --macho
    Use Mach-O specific object file parser. Commands and other options may behave differently when used with --macho.
    --no-leading-headers
    Do not print any leading headers.
    --no-symbolic-operands
    Do not print symbolic operands when disassembling.
    --non-verbose
    Display the information for Mach-O objects in non-verbose or numeric form.
    --objc-meta-data
    Display the Objective-C runtime meta data.
    --private-header
    Display only the first format specific file header.
    --rebase
    Display rebasing information.
    --rpaths
    Display runtime search paths for the binary.
    --universal-headers
    Display universal headers.
    --weak-bind
    Display weak binding information.

    XCOFF ONLY OPTIONS AND COMMANDS

    --symbol-description
    Add symbol description to disassembly output.
    --traceback-table
    Decode traceback table in disassembly output. Implies --disassemble.
