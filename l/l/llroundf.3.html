lround(3) Manual de funciones de biblioteca lround(3)

NOMBRE

lround, lroundf, lroundl, llround, llroundf, llroundl - redondear al entero más cercano

BIBLIOTECA

Biblioteca matemática (libm, -lm)

SINOPSIS

#include <math.h>
long lround(double x);
long lroundf(float x);
long lroundl(long double x);
long long llround(double x);
long long llroundf(float x);
long long llroundl(long double x);
Requisitos de Macro de Prueba de Funciones para glibc (ver feature_test_macros(7)):

Todas las funciones mostradas anteriormente:

    _ISOC99_SOURCE o _POSIX_C_SOURCE >= 200112L

DESCRIPCIÓN

Estas funciones redondean su argumento al valor entero más cercano, redondeando los casos intermedios (a medio camino) alejándose de cero, sin importar la dirección de redondeo actual (ver fenv(3)).

Tenga en cuenta que, a diferencia de las funciones round(3) y ceil(3), el tipo de retorno de estas funciones difiere del de sus argumentos.

VALOR DE RETORNO

Estas funciones devuelven el valor entero redondeado.

Si x es un NaN o un infinito, o si el valor redondeado es demasiado grande para ser almacenado en un long (long long en el caso de las funciones ll*), se produce un error de dominio y el valor de retorno no está especificado.

ERRORES

Consulte math_error(7) para obtener información sobre cómo determinar si se ha producido un error al llamar a estas funciones.

Los siguientes errores pueden ocurrir:

Error de dominio: x es un NaN o infinito, o el valor redondeado es demasiado grande
Se produce una excepción de punto flotante inválida (FE_INVALID).

Estas funciones no establecen errno.

ATRIBUTOS

Para obtener una explicación de los términos utilizados en esta sección, consulte attributes(7).

Interfaz Atributo Valor
lround (), lroundf (), lroundl (), llround (), llroundf (), llroundl () Seguridad de hilos MT-Safe

ESTÁNDARES

C11, POSIX.1-2008.

HISTORIA

glibc 2.1. C99, POSIX.1-2001.
