LL2_READ_ENTRY(3) Manual del programador LL2_READ_ENTRY(3)

NOMBRE

ll2_read_entry - Lee una entrada de la base de datos y la devuelve.

SINOPSIS

#include <lastlog2.h>

int ll2_read_entry (struct ll2_context *context, const char *user, int64_t *ll_time, char tty, char rhost, char pam_service, char error);

DESCRIPCIÓN

Lee la primera entrada de la base de datos, definida en context, para el usuario user. Si context es NULL, se tomará la base de datos predeterminada, definida en LL2_DEFAULT_DATABASE.

char    *error = NULL;
const   char *user = "root";
int64_t res_time;
char    *res_tty = NULL;
char    *res_rhost = NULL;
char    *res_service = NULL;
int ret = ll2_read_entry (NULL, user, &res_time, &res_tty, &res_rhost, &res_service, &error);

VALOR DEVUELTO

Devuelve 0 en caso de éxito, -ENOMEM o -1 en caso de otro fallo. error contiene una cadena de error si el valor de retorno es -1. No se garantiza que error contenga una cadena de error, podría ser NULL. error debe ser liberado por el llamador. Si la base de datos lastlog2 no existe en absoluto, se establece el errno ENOENT y se puede comprobar.

Los valores evaluados se devuelven a través de ll_time, tty, rhost y pam_service.
