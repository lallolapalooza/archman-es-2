NOMBRE

llvm-libtool-darwin - Herramienta LLVM para crear bibliotecas para Darwin

SINOPSIS

llvm-libtool-darwin [opciones] <archivos de entrada>

DESCRIPCIÓN

llvm-libtool-darwin es una herramienta para crear bibliotecas estáticas y dinámicas para Darwin.

Para la mayoría de los escenarios, funciona como un reemplazo directo para el libtool de cctools.

OPCIONES

llvm-libtool-darwin soporta las siguientes opciones:

-arch_only <arquitectura>
Construye una biblioteca estática solo para la <arquitectura> especificada e ignora todas las demás arquitecturas en los archivos.
-D
Usa cero para marcas de tiempo y UID/GID. Esto está activado por defecto.
-filelist <lista_archivos[,dir_nombre]>
Lee nombres de archivos de entrada desde <lista_archivos>. Los nombres de archivo se especifican en <lista_archivos> uno por línea, separados solo por saltos de línea. Los espacios en blanco en una línea se asumen que forman parte del nombre del archivo. Si también se especifica el nombre del directorio, dir_nombre, entonces se antepone a cada nombre de archivo en la <lista_archivos>.
-h, -help
Muestra la ayuda y el uso para este comando.
-l <x>
Busca la biblioteca libx.a en la ruta de búsqueda de bibliotecas. Si la cadena <x> termina en '.o', entonces se busca la biblioteca 'x' sin anteponer 'lib' ni añadir '.a'. Si se encuentra la biblioteca, se añade a la lista de archivos de entrada. De lo contrario, se genera un error.
-L <dir>
Añade <dir> a la lista de directorios en los que buscar bibliotecas. Los directorios se buscan en el orden en que se especifican con -L y antes de la ruta de búsqueda predeterminada. La ruta de búsqueda predeterminada incluye los directorios /lib, /usr/lib y /usr/local/lib.
-no_warning_for_no_symbols
No advertir sobre archivos que no tienen símbolos.
-warnings_as_errors
Genera un estado de salida no nulo si se emite alguna advertencia.
-o <nombre_archivo>
Especifica el nombre del archivo de salida. Debe especificarse exactamente una vez.
-static
Produce una biblioteca estática a partir de los archivos de entrada.
-U
Usa marcas de tiempo y UID/GID reales.
-V
Muestra la versión de este programa y realiza cualquier operación especificada.
-version
Muestra la versión de este programa y sale inmediatamente.

ESTADO DE SALIDA

llvm-libtool-darwin sale con un código de salida no nulo si hay un error. De lo contrario, sale con código 0.

ERRORES

Para reportar errores, por favor visita <https://github.com/llvm/llvm-project/issues/>.
