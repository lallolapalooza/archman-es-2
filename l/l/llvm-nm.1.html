NOMBRE

llvm-nm - lista la tabla de símbolos de archivos de objetos y bitcode de LLVM

SINOPSIS

llvm-nm [opciones] [nombres de archivo...]

DESCRIPCIÓN

La utilidad llvm-nm lista los nombres de los símbolos de los archivos de bitcode, archivos de objetos y archivos de bibliotecas de LLVM. Cada símbolo se lista junto con información simple sobre su procedencia. Si no se especifica ningún nombre de archivo, se utiliza a.out como entrada. Si se utiliza - como nombre de archivo, llvm-nm leerá un archivo de su flujo de entrada estándar.

El formato de salida predeterminado de llvm-nm es el formato tradicional BSD de nm. Cada registro de salida consta de una dirección hexadecimal opcional de 8 dígitos, seguida de un carácter de código de tipo, seguido de un nombre, para cada símbolo. Se imprime un registro por línea; los campos están separados por espacios. Cuando se omite la dirección, se reemplaza por 8 espacios.

Los caracteres de código de tipo admitidos son los siguientes. Donde se enumeran caracteres en minúscula y mayúscula para el mismo significado, un carácter en minúscula representa un símbolo local, mientras que un carácter en mayúscula representa un símbolo global (externo):

a, A

Símbolo absoluto.

b, B

Objeto de datos no inicializado (bss).

C

Símbolo común. Múltiples definiciones se enlazan juntas en una definición.

d, D

Objeto de datos escribible.

i, I

COFF: Símbolo .idata o símbolo en una sección con IMAGE_SCN_LNK_INFO establecida.

n

ELF: Símbolo local de una sección no asignable.

COFF: Símbolo de depuración.

N

ELF: Símbolo de sección de depuración o símbolo global de una sección no asignable.

s, S

COFF: Símbolo de sección.

Mach-O: Símbolo absoluto o símbolo de una sección que no sea __TEXT_EXEC __text, __TEXT __text, __DATA __data, o __DATA __bss.

r, R

Objeto de datos de solo lectura.

t, T

Objeto de código (texto).

u

ELF: Símbolo único de GNU.

U

El objeto nombrado no está definido en este archivo.

v

ELF: Objeto débil no definido. No es un error de enlace si el objeto no está definido.

V

ELF: Símbolo de objeto débil definido. Esta definición solo se utilizará si no existen definiciones regulares en un enlace. Si existen múltiples definiciones débiles y ninguna definición regular, se utilizará una de las definiciones débiles.

w

Símbolo débil no definido distinto de un símbolo de objeto ELF. No es un error de enlace si el símbolo no está definido.

W

Símbolo débil definido distinto de un símbolo de objeto ELF. Esta definición solo se utilizará si no existen definiciones regulares en un enlace. Si existen múltiples definiciones débiles y ninguna definición regular, se utilizará una de las definiciones débiles.

-

Mach-O: Símbolo N_STAB.

?

Algo irreconocible.

Dado que los archivos de bitcode de LLVM suelen contener objetos que no se consideran que tengan direcciones hasta que se enlazan en una imagen ejecutable o se compilan dinámicamente "just-in-time", llvm-nm no imprime una dirección para ningún símbolo en un archivo de bitcode de LLVM, incluso para símbolos que están definidos en el archivo de bitcode.

OPCIONES

-B
Utilizar el formato de salida BSD. Alias para --format=bsd.
-X
Especifica el tipo de archivo de objeto XCOFF, archivo de objeto ELF o archivo de objeto IR de la línea de comandos o de los archivos de biblioteca que llvm-nm debe examinar. El modo debe ser uno de los siguientes:
32
Procesa solo archivos de objeto de 32 bits.
64
Procesa solo archivos de objeto de 64 bits.
32_64
Procesa archivos de objeto de 32 y 64 bits.
cualquiera
Procesa todos los archivos de objeto compatibles.

En el sistema operativo AIX, el valor predeterminado es procesar solo archivos de objeto de 32 bits e ignorar los de 64 bits. Esto se puede cambiar estableciendo la variable de entorno OBJECT_MODE. Por ejemplo, OBJECT_MODE=64 hace que llvm-nm procese objetos de 64 bits e ignore los de 32 bits. La opción -X anula la variable OBJECT_MODE.

En otros sistemas operativos, el valor predeterminado es procesar todos los archivos de objeto: la variable de entorno OBJECT_MODE no es compatible.

--simbolos-depuracion, -a
Muestra todos los símbolos, incluso aquellos que normalmente se suprimen.
--solo-definidos, -U
Imprime solo los símbolos definidos en este archivo.
--desenmascarar, -C
Desenmascara los nombres de símbolos.
--dinamico, -D
Muestra símbolos dinámicos en lugar de símbolos normales.
--exportar-simbolos
Imprime símbolos ordenados con su visibilidad (si es aplicable), eliminando duplicados.
--externo, -g
Imprime solo los símbolos cuyas definiciones son externas; es decir, accesibles desde otros archivos.
--formato=<formato>, -f
Selecciona un formato de salida; formato puede ser sysv, posix, darwin, bsd o solo-simbolos. El valor predeterminado es bsd.
--ayuda, -h
Imprime un resumen de las opciones de la línea de comandos y sus significados.
-j
Imprime solo los nombres de los símbolos. Alias para --formato=solo-simbolos.
--numeros-linea, -l
Utiliza la información de depuración para imprimir los nombres de archivo y los números de línea donde se definen los símbolos. En su lugar, se imprime la ubicación de la primera relocalización de los símbolos no definidos.
-m
Utiliza el formato Darwin. Alias para --formato=darwin.
--no-desenmascarar
No desenmascarar los nombres de símbolos. Este es el valor predeterminado.
--no-llvm-bc
Deshabilita el lector de bitcode de LLVM.
--no-ordenar, -p
Muestra los símbolos en el orden en que se encontraron.
--no-debiles, -W
No imprime símbolos débiles.
--ordenar-numerico, -n, -v
Ordena los símbolos numéricamente (primero por dirección, luego por nombre).
--ordenar
Ordena los símbolos alfabéticamente por nombre.
--simbolos
Imprime solo los símbolos que no son de depuración.
--simbolos-definidos
Imprime solo los símbolos que están definidos.
--simbolos-externos
Imprime solo los símbolos definidos externamente.
--simbolos-no-debiles
Imprime solo los símbolos no débiles.
--simbolos-no-locales
Imprime solo los símbolos no locales.
--simbolos-no-simbolos-depuracion
Imprime solo los símbolos que no son de depuración.
--simbolos-no-undef
Imprime solo los símbolos definidos.
--simbolos-undef
Imprime solo los símbolos no definidos.
--sysv, -S
Utiliza el formato de salida System V Release 4.
--undefined-only, -u
Imprime solo los símbolos no definidos en este archivo.
--version, -V
Muestra la versión de la herramienta e información de licencia.
--weak
Imprime solo símbolos débiles.
--windows-obj
Interpreta los archivos de entrada como archivos objeto COFF de Windows.
--posix
Utiliza el formato de salida POSIX.
--darwin
Utiliza el formato de salida Darwin.
--just-symbols
Imprime solo los nombres de los símbolos.

llvm-nm(1) - Arch Linux man pages

NAME

llvm-nm

list symbols from object files

SYNOPSIS

llvm-nm [option...] file...

DESCRIPTION

The llvm-nm utility displays symbols from object files. The default behavior is to print the symbol table for each object file listed.

This utility is compliant with the POSIX standard and supports the GNU extension.

OPTIONS

-A
Same as --print-file-name.
-a
Same as --debug-syms.
-C
Demangle symbol names. By default, symbol names are not demangled.
--debug-syms
Only print debug symbols.
--defined-only
Only print defined symbols.
--dynamic-syms
Print dynamic symbols instead of external symbols.
--extern-sort
Sort symbols by name.
--format=format
Use the specified object file format. Valid values are: default, sysv, posix.
--help
Print a summary of available options to stdout.
--line-numbers
Print line numbers for the symbols. This option is not applicable for Mach-O and XCOFF object files.
-m
Same as --demangle.
-o
Same as --print-file-name.
-P
Use POSIX.2 output format. Alias for --format=posix.
--print-armap
Print the archive symbol table, in addition to the symbols.
--print-file-name
Precede each symbol with the file it came from.
--print-size
Print symbol size as well as address. This option is not applicable for Mach-O object files.
-q
Same as --quiet.
--quiet
Suppress diagnostic messages about missing symbols.
--radix=RADIX
Specify the radix of the symbol address(es). Values accepted are d (decimal), x (hexadecimal) and o (octal).
-r
Sort symbols in reverse order.
-S
Same as --print-size.
--size-sort
Sort symbols by size.
--special-syms
Do not filter special symbols from the output.
-t
Same as --radix.
-u
Same as --undefined-only.
--undefined-only
Only print undefined symbols.
-V
Display the version of the llvm-nm executable, then exit.
--version
Display the version of the llvm-nm executable, then exit.
--addr-sort
Sort symbols by address.
--portability, -P
Use POSIX.2 output format. Alias for --format=posix.
--print-armap
Print the archive symbol table, in addition to the symbols.
--print-file-name, -A, -o
Precede each symbol with the file it came from.
--print-size, -S
Show symbol size as well as address (not applicable for Mach-O).
--quiet
Suppress 'no symbols' diagnostic.
--radix=<RADIX>, -t
Specify the radix of the symbol address(es). Values accepted are d (decimal), x (hexadecimal) and o (octal).
--reverse-sort, -r
Sort symbols in reverse order.
--size-sort
Sort symbols by size.
--special-syms
Do not filter special symbols from the output.
--undefined-only, -u
Print only undefined symbols.
--version, -V
Display the version of the llvm-nm executable, then exit. Does not stack with other commands.
@<FILE>
Read command-line options from response file <FILE>.

MACH-O SPECIFIC OPTIONS

--add-dyldinfo
Add symbols from the dyldinfo, if they are not already in the symbol table. This is the default.
--add-inlinedinfo
Add symbols from the inlined libraries, TBD file inputs only.
--arch=<arch1[,arch2,...]>
Dump the symbols from the specified architecture(s).
--dyldinfo-only
Dump only symbols from the dyldinfo.
--no-dyldinfo
Do not add any symbols from the dyldinfo.
-s <segment> <section>
Dump only symbols from this segment and section name.
-x
Print symbol entry in hex.

XCOFF SPECIFIC OPTIONS

--no-rsrc
Exclude resource file symbols (__rsrc) from export symbol list.

BUGS

•
llvm-nm does not support the full set of arguments that GNU nm does.

EXIT STATUS

llvm-nm exits with an exit code of zero.
