NOMBRE

llvm-addr2line - un reemplazo directo para addr2line

SINOPSIS

llvm-addr2line [opciones]

DESCRIPCIÓN

llvm-addr2line es un alias para la herramienta llvm-symbolizer(1) <llvm-symbolizer.html> con diferentes valores predeterminados. El objetivo es que sea un reemplazo directo del addr2line de GNU.

Aquí hay algunas de esas diferencias:

  • llvm-addr2line interpreta todas las direcciones como hexadecimales e ignora un prefijo opcional de 0x, mientras que llvm-symbolizer intenta determinar la base a partir del prefijo del literal y usa decimal por defecto si no hay prefijo.
  • llvm-addr2line por defecto no imprime nombres de función. Usa -f <llvm-symbolizer.html#llvm-symbolizer-opt-f> para habilitar eso.
  • llvm-addr2line por defecto no desmangling los nombres de función. Usa -C <llvm-symbolizer.html#llvm-symbolizer-opt-c> para activar el desmangling.
  • llvm-addr2line por defecto no imprime marcos insertados. Usa -i <llvm-symbolizer.html#llvm-symbolizer-opt-i> para mostrar marcos insertados para una ubicación de código fuente en una función insertada.
  • llvm-addr2line utiliza --output-style=GNU <llvm-symbolizer.html#llvm-symbolizer-opt-output-style> por defecto.
  • llvm-addr2line analiza las opciones de la variable de entorno LLVM_ADDR2LINE_OPTS en lugar de LLVM_SYMBOLIZER_OPTS.
  • llvm-addr2line acepta una dirección con un prefijo '+', por ejemplo, +0x00777fff. Esto es tratado como un nombre de símbolo por llvm-symbolizer.

VER TAMBIÉN
