LL2_UPDATE_LOGIN_TIME(3) Manual de programadores LL2_UPDATE_LOGIN_TIME(3)

NOMBRE

ll2_update_login_time - Escribe una entrada *nueva* con la hora de inicio actualizada.

SINOPSIS

#include <lastlog2.h>

int ll2_update_login_time (struct ll2_context *context, const char *user, int64_t ll_time, char **error);

DESCRIPCIÓN

Escribe una nueva entrada en la base de datos, definida en context, para el usuario user. La hora se establece mediante ll_time, mientras que los otros valores se toman de una entrada ya existente. Si context es NULL, se utilizará la base de datos por defecto, definida en LL2_DEFAULT_DATABASE.

char    *error = NULL;
const   char *user = "root";
int64_t login_time = time(0); // Obtener la hora del sistema;
int ret = ll2_update_login_time (NULL, user, login_time, &error);

VALOR DE RETORNO

Devuelve 0 en caso de éxito, -ENOMEM o -1 en caso de otro fallo. error contiene una cadena de error si el valor de retorno es -1. No se garantiza que error contenga una cadena de error, también podría ser NULL. El llamante debe liberar error.
