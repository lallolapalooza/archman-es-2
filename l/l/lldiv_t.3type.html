div_t(3type) div_t(3type)

NOMBRE

div_t, ldiv_t, lldiv_t, imaxdiv_t - cociente y resto de una división entera

BIBLIOTECA

Biblioteca estándar C (libc)

SINOPSIS

#include <stdlib.h>
typedef struct {
    int quot; /* Cociente */
    int rem;  /* Resto */
} div_t;
typedef struct {
    long quot; /* Cociente */
    long rem;  /* Resto */
} ldiv_t;
typedef struct {
    long long quot; /* Cociente */
    long long rem;  /* Resto */
} lldiv_t;
#include <inttypes.h>
typedef struct {
    intmax_t quot; /* Cociente */
    intmax_t rem;  /* Resto */
} imaxdiv_t;

DESCRIPCIÓN

[[l]l]div_t es el tipo del valor devuelto por la función [[l]l]div(3).

imaxdiv_t es el tipo del valor devuelto por la función imaxdiv(3).

ESTANDARES

C11, POSIX.1-2024.

HISTORIA

C99, POSIX.1-2001.

VER TAMBIÉN

div(3), imaxdiv(3), ldiv(3), lldiv(3)
