_llseek(2) Manual de llamadas al sistema _llseek(2)

NOMBRE

_llseek - reposiciona el desplazamiento de lectura/escritura de un archivo

BIBLIOTECA

Biblioteca C estándar (libc, -lc)

SINOPSIS

#include <sys/syscall.h>      /* Definición de las constantes SYS_* */
#include <unistd.h>
int syscall(SYS__llseek, unsigned int fd, unsigned long offset_high,
            unsigned long offset_low, loff_t *result,
            unsigned int whence);

Nota: glibc no proporciona una envoltura para _llseek(), haciendo necesario el uso de syscall(2).

DESCRIPCIÓN

Nota: para obtener información sobre la función de biblioteca llseek(3), consulte lseek64(3).

La llamada al sistema _llseek() reposiciona el desplazamiento de la descripción de archivo abierta asociada con el descriptor de archivo fd al valor

(offset_high << 32) | offset_low

Este nuevo desplazamiento es un desplazamiento en bytes relativo al principio del archivo, el desplazamiento de archivo actual o el final del archivo, dependiendo de si whence es SEEK_SET, SEEK_CUR o SEEK_END, respectivamente.

El nuevo desplazamiento de archivo se devuelve en el argumento result. El tipo loff_t es un tipo con signo de 64 bits.

Esta llamada al sistema existe en varias plataformas de 32 bits para admitir la búsqueda de grandes desplazamientos de archivo.

VALOR DE RETORNO

Al completarse con éxito, _llseek() devuelve 0. De lo contrario, se devuelve un valor de -1 y se establece errno para indicar el error.

ERRORES

EBADF
fd no es un descriptor de archivo abierto.
EFAULT
Problema al copiar los resultados al espacio de usuario.
EINVAL
whence es inválido.

VERSIÓNES

Probablemente desee utilizar la función de envoltura lseek(2) en su lugar.

ESTÁNDARES

Linux.

VER TAMBIÉN

lseek(2), open(2), lseek64(3)
