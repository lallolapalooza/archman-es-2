NOMBRE

llvm-reduce - Reductor automático de casos de prueba de LLVM.

SINOPSIS

llvm-reduce [opciones] [entrada...]

DESCRIPCIÓN

La herramienta llvm-reduce es un proyecto que se puede usar para reducir el tamaño de los casos de prueba de LLVM. Funciona eliminando código redundante o innecesario de los casos de prueba de LLVM, mientras sigue preservando su capacidad para detectar errores.

Si entrada es "-", llvm-reduce lee de la entrada estándar. De lo contrario, leerá de los nombres de archivo especificados.

LLVM-Reduce es una herramienta útil para reducir el tamaño y la complejidad de los casos de prueba de LLVM, lo que facilita la identificación y la depuración de problemas en la infraestructura del compilador de LLVM.

OPCIONES GENÉRICAS

--help
Muestra las opciones disponibles (--help-hidden para más).
--abort-on-invalid-reduction
Abortar si alguna reducción resulta en IR inválido.
--in-place
¡ADVERTENCIA: Esta opción reemplazará su archivo de entrada con la versión reducida!
--ir-passes=<cadena>
Una descripción textual de la tubería de pases, igual que lo que se pasa a opt -passes.
-j <uint>
Número máximo de hilos a usar para procesar fragmentos. Establecer a 1 para deshabilitar el paralelismo.
--max-pass-iterations=<int>
Número máximo de veces para ejecutar el conjunto completo de pases delta (predeterminado=5).
--mtriple=<cadena>
Establecer el triple de destino.
--preserve-debug-environment
No deshabilitar las características usadas para depurar fallos (informes de fallos, llvm-symbolizer y volcados de memoria).
--print-delta-passes
Imprimir la lista de pases delta, que se pueden pasar a --delta-passes como una lista separada por comas.
--skip-delta-passes=<cadena>
Pases delta que no se ejecutarán, separados por comas. Por defecto, se ejecutan todos los pases delta.
--starting-granularity-level=<uint>
Número de veces para dividir los fragmentos antes de la primera prueba.

Nota: La granularidad se refiere al nivel de detalle en el que opera el proceso de reducción. Una granularidad menor significa que el proceso de reducción opera a un nivel más general, mientras que una granularidad mayor significa que opera a un nivel más detallado.

--test=<cadena>
Nombre de la prueba de "interesante-za" que se ejecutará.
--test-arg=<cadena>
Argumentos pasados a la prueba de "interesante-za".
--verbose
Imprimir información de depuración adicional.
--write-tmp-files-as-bitcode
Escribir siempre los archivos temporales como bitcode en lugar de IR textual.
-x={ir|mir}
Lenguaje de entrada como ir o mir.

ESTADO DE SALIDA

llvm-reduce devuelve 0 en operación normal. Devuelve un código de salida distinto de cero si hubo algún error. Devuelve 2 si la prueba de interesante-za reportó que la entrada inicial no era interesante.

EJEMPLO

llvm-reduce se puede usar para simplificar una prueba que provoca un bloqueo del compilador.

Por ejemplo, supongamos que opt está fallando en el archivo IR test.ll con el mensaje de error Assertion failed at line 1234 of WhateverFile.cpp, al ejecutarse en -O2.

El caso de prueba de test.ll se puede reducir invocando el siguiente comando:

$(LLVM_BUILD_FOLDER)/bin/llvm-reduce --test=script.sh <ruta a>/test.ll

El script de shell pasado a la opción test consiste en lo siguiente:

$(LLVM_BUILD_FOLDER)/bin/opt -O2 -disable-output $1 \
  |& grep "Assertion failed at line 1234 of WhateverFile.cpp"

(En este script, grep sale con 0 si encuentra la cadena y ese se convierte en el estado de todo el script.)

Este ejemplo se puede generalizar a otras herramientas que procesan archivos IR, por ejemplo llc.
