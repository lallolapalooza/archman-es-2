NOMBRE

llvm-stress - genera archivos .ll aleatorios

SINOPSIS

llvm-stress [-size=tamañoarchivo] [-seed=semilla-inicial] [-o=archivo-salida]

DESCRIPCIÓN

La herramienta llvm-stress se utiliza para generar archivos .ll aleatorios que pueden ser utilizados para probar diferentes componentes de LLVM.

OPCIONES

-o nombre-archivo
Especifica el nombre del archivo de salida.
-size tamaño
Especifica el tamaño del archivo .ll generado.
-seed semilla
Especifica la semilla que se utilizará para las instrucciones generadas aleatoriamente.

ESTADO DE SALIDA

llvm-stress devuelve 0.
