NOMBRE

llvm-dwarfutil - Una herramienta para copiar y manipular información de depuración

SINOPSIS

llvm-dwarfutil [opciones] entrada salida

DESCRIPCIÓN

llvm-dwarfutil es una herramienta para copiar y manipular información de depuración.

En su uso básico, realiza una copia semántica de la entrada a la salida. Si se especifican opciones, la salida puede modificarse durante el proceso, por ejemplo, eliminando información de depuración no utilizada.

Si se especifica "-" para el archivo de entrada, la entrada se lee del flujo de entrada estándar del programa. Si se especifica "-" para el archivo de salida, la salida se escribe en el flujo de salida estándar del programa.

La herramienta todavía está en desarrollo activo.

OPCIONES DE LÍNEA DE COMANDOS

--garbage-collection
Elimina partes de la información de depuración relacionadas con secciones descartadas. Cuando el enlazador realiza la recolección de basura de secciones, la información de depuración abandonada queda atrás. Dicha información de depuración abandonada hace referencia a rangos de direcciones utilizando valores de marcadores de posición (tombstone). Por lo tanto, cuando se especifica esta opción, la herramienta elimina la información de depuración que está marcada con el valor de marcador de posición.

Esta opción está habilitada por defecto.

--odr-deduplication
Elimina tipos duplicados (si la "Regla de Una Definición" es compatible con el lenguaje fuente). Conserva la primera definición de tipo y elimina otras definiciones, reduciendo potencialmente de forma significativa el tamaño de la información de depuración de salida.

Esta opción está habilitada por defecto.

--help, -h
Imprime un resumen de las opciones de la línea de comandos.
--no-garbage-collection
Deshabilita --garbage-collection.
--no-odr-deduplication
Deshabilita --odr-deduplication.
--no-separate-debug-file
Deshabilita --separate-debug-file.
--num-threads=<n>, -j
Especifica el número máximo (n) de hilos simultáneos a utilizar para el procesamiento.
--separate-debug-file
Genera un archivo separado que contiene la información de depuración de salida. Usar llvm-dwarfutil con esta opción equivale al siguiente conjunto de comandos:
:program:`llvm-objcopy` --only-keep-debug in-file out-file.debug
:program:`llvm-objcopy` --strip-debug in-file out-file
:program:`llvm-objcopy` --add-gnu-debuglink=out-file.debug out-file
--tombstone=<value>
<valor> puede ser uno de los siguientes valores:
  • bfd: cero para todas las direcciones y [1,1] para rangos de direcciones y exec de DWARF v4 (o inferior).
  • maxpc: -1 para todas las direcciones y -2 para rangos de direcciones de DWARF v4 (o inferior).
  • universal: ambos bfd y maxpc.
  • exec: coincide con los rangos de direcciones de las secciones ejecutables.

El valor universal se usa por defecto.

--verbose
Habilita el registro detallado. Esta opción deshabilita el modo multihilo.
--verify
Ejecuta el verificador DWARF en la información de depuración DWARF de salida.
--version
Imprime la versión de este programa.

FORMATOS SOPORTADOS

Los siguientes formatos son actualmente compatibles con llvm-dwarfutil:

ELF

ESTADO DE SALIDA

llvm-dwarfutil sale con un código de salida distinto de cero si hay un error. De lo contrario, sale con el código 0.
