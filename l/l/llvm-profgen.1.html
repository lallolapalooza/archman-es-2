NOMBRE

llvm-profgen - Herramienta de generación de perfiles SPGO de LLVM

SINOPSIS

llvm-profgen [comandos] [opciones]

DESCRIPCIÓN

La utilidad llvm-profgen genera un archivo de datos de perfil a partir de los archivos de datos de script de perf proporcionados para la optimización guiada por perfiles basada en muestras (SPGO).

COMANDOS

Se requiere al menos uno de los siguientes comandos:

--perfscript=<string[,string,...]>
Ruta del rastreo perf-script creado por la herramienta perf de Linux con el comando script (el perf.data original debe ser perfilado con -b).
--binary=<string[,string,...]>
Ruta de los archivos binarios perfilados de entrada.
--output=<string>
Ruta del archivo de perfil de salida.

OPCIONES

llvm-profgen admite las siguientes opciones:

--format=[text|binary|extbinary|compbinary|gcc]
Especifica el formato del perfil generado. Los <format> admitidos son text, binary, extbinary, compbinary, gcc; consulta llvm-profdata para obtener más descripciones del formato.
--show-mmap-events
Muestra los eventos mmap.
--show-disassembly
Muestra el código desensamblado.
--x86-asm-syntax=[att|intel]
Especifica si se debe mostrar el código ensamblador en sintaxis AT&T (la predeterminada) o en sintaxis Intel.
