NOMBRE

llvm-install-name-tool - Herramienta LLVM para manipular nombres de instalación y rpaths

SINOPSIS

llvm-install-name-tool [opciones] entrada

DESCRIPCIÓN

llvm-install-name-tool es una herramienta para manipular nombres de instalación de bibliotecas compartidas dinámicas y rpaths listados en un binario Mach-O.

Para la mayoría de los escenarios, funciona como un reemplazo directo para install_name_tool de Apple.

OPCIONES

Se requiere al menos una de las siguientes opciones, y algunas opciones se pueden combinar con otras opciones. Las opciones -add_rpath, -delete_rpath y -rpath se pueden combinar en una invocación solo si no comparten el mismo valor de <rpath>.

-add_rpath <rpath>
Añade un rpath llamado <rpath> al binario especificado. Se puede especificar varias veces para añadir múltiples rpaths. Lanza un error si <rpath> ya está listado en el binario.
-change <nombre_instalacion_antiguo> <nombre_instalacion_nuevo>
Cambia un nombre de instalación <nombre_instalacion_antiguo> por <nombre_instalacion_nuevo> en el binario especificado. Se puede especificar varias veces para cambiar múltiples nombres de instalación de bibliotecas compartidas dependientes. La opción se ignora si <nombre_instalacion_antiguo> no está listado en el binario especificado.
-delete_rpath <rpath>
Elimina un rpath llamado <rpath> del binario especificado. Se puede especificar varias veces para eliminar múltiples rpaths. Lanza un error si <rpath> no está listado en el binario.
-delete_all_rpaths
Elimina todos los rpaths del binario.
--help, -h
Imprime un resumen de las opciones de línea de comandos.
-id <nombre>
Cambia el nombre de identificación de la biblioteca compartida bajo LC_ID_DYLIB por <nombre> en el binario especificado. Si se especifica varias veces, solo se selecciona la última opción -id. La opción se ignora si el binario Mach-O especificado no es una biblioteca compartida dinámica.
-rpath <rpath_antiguo> <rpath_nuevo>
Cambia un rpath llamado <rpath_antiguo> por <rpath_nuevo> en el binario especificado. Se puede especificar varias veces para cambiar múltiples rpaths. Lanza un error si <rpath_antiguo> no está listado en el binario o si <rpath_nuevo> ya está listado en el binario.
--version, -V
Muestra la versión del ejecutable llvm-install-name-tool.

CÓDIGO DE SALIDA

llvm-install-name-tool sale con un código de salida distinto de cero si hay un error. De lo contrario, sale con el código 0.

ERRORES CONOCIDOS

Para reportar errores, visite <https://github.com/llvm/llvm-project/labels/tools:llvm-objcopy/strip/>.
