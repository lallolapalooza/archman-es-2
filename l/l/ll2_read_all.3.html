LL2_READ_ALL(3) Manual del programador LL2_READ_ALL(3)

NOMBRE

ll2_read_all - Lee todas las entradas de la base de datos y llama a la función de devolución de llamada para cada entrada.

SINOPSIS

#include <lastlog2.h> int ll2_read_all (struct ll2_context *context, int (*callback)(const char *user, int64_t ll_time, const char *tty, const char *rhost, const char *pam_service, const char *cb_error), char **error);

DESCRIPCIÓN

Lee todas las entradas de la base de datos, definida en context, y llama a la función de devolución de llamada callback para cada entrada. Si context es NULL, se tomará la base de datos predeterminada, definida en LL2_DEFAULT_DATABASE.

char  *error = NULL;
const char *user = "root";
static int
callback (const char *res_user, int64_t ll_time, const char *res_tty,
          const char *res_rhost, const char *res_service, const char *cb_error)
{
   /* devolviendo != 0 si no hay más entradas que deban ser manejadas por la devolución de llamada */
   return 0;
}
int ret = ll2_read_all (NULL, callback, &error);

VALOR DEVUELTO

Devuelve 0 en caso de éxito, -ENOMEM u -1 en caso de otro fallo. error contiene una cadena de error si el valor de retorno es -1. No se garantiza que error contenga una cadena de error, también podría ser NULL. El llamador debe liberar error. Si la base de datos lastlog2 no existe en absoluto, se establece errno ENOENT y se puede comprobar.
