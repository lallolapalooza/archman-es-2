LLRINT(3P) Manual de Programador POSIX LLRINT(3P)

PRÓLOGO

Esta página del manual forma parte del Manual de Programador POSIX. La implementación de Linux de esta interfaz puede diferir (consulte la página del manual de Linux correspondiente para conocer los detalles del comportamiento de Linux), o la interfaz puede no estar implementada en Linux.

NOMBRE

llrint, llrintf, llrintl — redondear al valor entero más cercano utilizando la dirección de redondeo actual

SINOPSIS

#include <math.h>
long long llrint(double x);
long long llrintf(float x);
long long llrintl(long double x);

DESCRIPCIÓN

La funcionalidad descrita en esta página de referencia está alineada con el estándar ISO C. Cualquier conflicto entre los requisitos descritos aquí y el estándar ISO C es no intencional. Este volumen de POSIX.1‐2017 remite al estándar ISO C.

Estas funciones redondearán su argumento al valor entero más cercano, redondeando según la dirección de redondeo actual.

Una aplicación que desee comprobar situaciones de error debe establecer errno a cero y llamar a feclearexcept(FE_ALL_EXCEPT) antes de llamar a estas funciones. Al regresar, si errno no es cero o fetestexcept(FE_INVALID | FE_DIVBYZERO | FE_OVERFLOW | FE_UNDERFLOW) no es cero, se ha producido un error.

VALOR DE RETORNO

Al completarse con éxito, estas funciones devolverán el valor entero redondeado.

Si x es NaN, se producirá un error de dominio y se devolverá un valor no especificado.

Si x es +Inf, se producirá un error de dominio y se devolverá un valor no especificado.

Si x es -Inf, se producirá un error de dominio y se devolverá un valor no especificado.

Si el valor correcto es positivo y demasiado grande para representarlo como un long long, se devolverá un valor no especificado. En sistemas que soportan la opción de punto flotante IEC 60559, se producirá un error de dominio; de lo contrario, puede producirse un error de dominio.

Si el valor correcto es negativo y demasiado grande para representarlo como un long long, se devolverá un valor no especificado. En sistemas que soportan la opción de punto flotante IEC 60559, se producirá un error de dominio; de lo contrario, puede producirse un error de dominio.

ERRORES

Estas funciones fallarán si:

Error de Dominio
El argumento x es NaN o ±Inf, o el valor correcto no es representable como un entero.

Si la expresión entera (math_errhandling & MATH_ERRNO) es distinta de cero, entonces errno se establecerá en [EDOM]. Si la expresión entera (math_errhandling & MATH_ERREXCEPT) es distinta de cero, entonces se activará la excepción de punto flotante inválida.

Estas funciones pueden fallar si:

Error de Dominio
El valor correcto no es representable como un entero.

Si la expresión entera (math_errhandling & MATH_ERRNO) es distinta de cero, entonces errno se establecerá en [EDOM]. Si la expresión entera (math_errhandling & MATH_ERREXCEPT) es distinta de cero, entonces se activará la excepción de punto flotante inválida.

Las siguientes secciones son informativas.

EJEMPLOS

Ninguno.

USO DE APLICACIONES

En caso de error, las expresiones (math_errhandling & MATH_ERRNO) y (math_errhandling & MATH_ERREXCEPT) son independientes entre sí, pero al menos una de ellas debe ser distinta de cero.

RACIONALE

Estas funciones proporcionan conversiones de punto flotante a entero. Redondean según la dirección de redondeo actual. Si el valor redondeado está fuera del rango del tipo de retorno, el resultado numérico no está especificado y se activa la excepción de punto flotante inválida. Cuando no activan ninguna otra excepción de punto flotante y el resultado difiere del argumento, activan la excepción de punto flotante inexacta.
