NOMBRE

llvm-opt-report - generar informe de optimización desde YAML

SINOPSIS

llvm-opt-report [opciones] [entrada]

DESCRIPCIÓN

llvm-opt-report es una herramienta para generar un informe de optimización a partir de archivos de registro de optimización en formato YAML.

Necesitas crear un archivo de registro de optimización en formato YAML antes de ejecutar llvm-opt-report.

Proporciona información sobre el tiempo de ejecución, el uso de memoria y otros detalles de cada pasada de optimización.

$ clang -c foo.c -o foo.o -O3 -fsave-optimization-record

Luego, creas un informe usando el comando llvm-opt-report con el archivo de registro de optimización YAML foo.opt.yaml como entrada.

$ llvm-opt-report foo.opt.yaml -o foo.lst

foo.lst es el informe de optimización generado.

< foo.c
 1          | void bar();
 2          | void foo() { bar(); }
 3          |
 4          | void Test(int *res, int *c, int *d, int *p, int n) {
 5          |   int i;
 6          |
 7          | #pragma clang loop vectorize(assume_safety)
 8     V4,1 |   for (i = 0; i < 1600; i++) {
 9          |     res[i] = (p[i] == 0) ? res[i] : res[i] + d[i];
10          |   }
11          |
12  U16     |   for (i = 0; i < 16; i++) {
13          |     res[i] = (p[i] == 0) ? res[i] : res[i] + d[i];
14          |   }
15          |
16 I        |   foo();
17          |
18          |   foo(); bar(); foo();
   I        |   ^
   I        |                 ^
19          | }
20          |

Los símbolos impresos en el lado izquierdo del programa indican qué tipo de optimización se realizó. Los significados de los símbolos son los siguientes:

  • I: La función se ha insertado en línea (inlined).
  • U: El bucle se ha desenrollado (unrolled). El número siguiente indica el factor de desenrollado.
  • V: El bucle se ha vectorizado. Los números siguientes indican la longitud del vector y el factor de entrelazado.

Nota:

Si una línea de código específica se imprime dos veces, significa que la misma pasada de optimización se aplicó a esa línea de código dos veces, y la pasada pudo optimizar aún más el código en la segunda iteración.

OPCIONES

Si entrada es "-" u se omite, llvm-opt-report lee de la entrada estándar. De lo contrario, leerá del archivo especificado.

Si la opción -o se omite, entonces llvm-opt-report enviará su salida a la salida estándar. Si la opción -o especifica "-", entonces la salida también se enviará a la salida estándar.

--help
Muestra las opciones disponibles.
--version
Muestra la versión de este programa.
--format=<cadena>
El formato del archivo de registro de optimización. El argumento es uno de los siguientes:
  • yaml
  • bitstream
--no-demangle
No decodificar nombres de funciones.
-o=<cadena>
Archivo de salida.
-r=<cadena>
Raíz para rutas de entrada relativas.
-s
No incluir factores de vectorización, etc.

ESTADO DE SALIDA

llvm-opt-report devuelve 0 en caso de éxito. De lo contrario, se imprime un mensaje de error en la salida estándar y la herramienta devuelve 1.
