NOMBRE

llvm-strings - imprime cadenas

SINOPSIS

llvm-strings [opciones] [entrada...]

DESCRIPCIÓN

llvm-strings es una herramienta destinada a ser un reemplazo directo de strings de GNU, que busca cadenas imprimibles en archivos y las escribe en el flujo de salida estándar. Una cadena imprimible es cualquier secuencia de cuatro (por defecto) o más caracteres ASCII imprimibles. El final del archivo, o cualquier otro byte, termina la secuencia actual.

llvm-strings busca cadenas en cada archivo de entrada especificado. A diferencia de strings de GNU, busca en todo el archivo de entrada, independientemente del formato del archivo, en lugar de restringir la búsqueda a ciertas secciones de los archivos objeto. Si se especifica "-" como entrada, o no se especifica ninguna entrada, el programa lee del flujo de entrada estándar.

EJEMPLO

$ cat input.txt
bars
foo
wibble blob
$ llvm-strings input.txt
bars
wibble blob

OPCIONES

--all, -a
Ignorado silenciosamente. Presente por compatibilidad con strings de GNU.
--bytes=<longitud>, -n
Establece el número mínimo de caracteres ASCII imprimibles necesarios para que una secuencia de bytes se considere una cadena. El valor predeterminado es 4.
--help, -h
Muestra un resumen de las opciones de la línea de comandos.
--print-file-name, -f
Muestra el nombre del archivo contenedor antes de cada cadena.

Ejemplo:

$ llvm-strings --print-file-name test.o test.elf
test.o: _Z5hellov
test.o: some_bss
test.o: test.cpp
test.o: main
test.elf: test.cpp
test.elf: test2.cpp
test.elf: _Z5hellov
test.elf: main
test.elf: some_bss
--radix=<base>, -t
Muestra el desplazamiento dentro del archivo de cada cadena, antes de la cadena y utilizando la base especificada. Los valores válidos de <base> son o, d y x para octal, decimal y hexadecimal respectivamente.

Ejemplo:

$ llvm-strings --radix=o test.o
    554 _Z5hellov
    566 .rela.text
    571 .comment
    572 some_bss
    573 .bss
    574 test.cpp
    575 main
$ llvm-strings --radix=d test.o
    340 _Z5hellov
    352 .rela.text
    357 .comment
    358 some_bss
    359 .bss
    360 test.cpp
    361 main
$ llvm-strings -t x test.o
    15c _Z5hellov
    164 .rela.text
    169 .comment
    16a some_bss
    16b .bss
    16c test.cpp
    16d main
--version
Muestra la versión del ejecutable llvm-strings.
@<ARCHIVO>
Lee las opciones de la línea de comandos desde el archivo de respuesta <ARCHIVO>.

ESTADO DE SALIDA

llvm-strings sale con un código de salida distinto de cero si hay un error. De lo contrario, sale con el código 0.

ERRORES

Para reportar errores, visite <https://github.com/llvm/llvm-project/labels/tools:llvm-strings/>.
