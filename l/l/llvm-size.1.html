NOMBRE

llvm-size - imprime información de tamaño

SINOPSIS

llvm-size [opciones] [entrada...]

DESCRIPCIÓN

llvm-size es una herramienta que imprime información de tamaño para archivos binarios. Está diseñado para ser un reemplazo directo de size de GNU.

La herramienta imprime información de tamaño para cada entrada especificada. Si no se especifica ninguna entrada, el programa imprime información de tamaño para a.out. Si se especifica "-" como archivo de entrada, llvm-size lee un archivo del flujo de entrada estándar. Si una entrada es un archivo, se mostrará información de tamaño para todos sus miembros.

OPCIONES

-A
Equivalente a --format con el valor sysv.
--arch=<arch>
Arquitectura(s) de binarios universales Mach-O para las que se mostrará información.
-B
Equivalente a --format con el valor berkeley.
--common
Incluye tamaños de símbolos comunes ELF en el tamaño bss para el formato de salida berkeley, o como una entrada de sección separada para la salida sysv. Si no se especifica, estos símbolos se ignoran.
-d
Equivalente a --radix con el valor 10.
-l
Muestra información detallada de direcciones y desplazamientos para segmentos y secciones en archivos Mach-O en formato darwin.
--format=<formato>
Establece el formato de salida al <formato> especificado. Los formatos <formato> disponibles son berkeley (el predeterminado), sysv y darwin.

La salida Berkeley resume los tamaños de texto, datos y bss en cada archivo, como se muestra a continuación para un par típico de archivos ELF:

$ llvm-size --format=berkeley test.o test2.o
   text    data     bss     dec     hex filename
    182      16       5     203      cb test.elf
     82       8       1      91      5b test2.o

Para archivos Mach-O, el formato de salida es ligeramente diferente:

$ llvm-size --format=berkeley macho.obj macho2.obj
__TEXT  __DATA  __OBJC  others  dec     hex
4       8       0       0       12      c       macho.obj
16      32      0       0       48      30      macho2.obj

La salida Sysv muestra información de tamaño y dirección para la mayoría de las secciones, con cada archivo listado por separado:

$ llvm-size --format=sysv test.elf test2.o
   test.elf  :
   section       size      addr
   .eh_frame       92   2097496
   .text           90   2101248
   .data           16   2105344
   .bss             5   2105360
   .comment       209         0
   Total          412
   test2.o  :
   section             size   addr
   .text                 26      0
   .data                  8      0
   .bss                   1      0
   .comment             106      0
   .note.GNU-stack        0      0
   .eh_frame             56      0
   .llvm_addrsig          2      0
   Total                199

El formato darwin solo afecta a los archivos de entrada Mach-O. Si se especifica una entrada de un formato de archivo diferente, llvm-size recurre al formato berkeley. Al producir el formato darwin, la herramienta muestra información sobre segmentos y secciones:

$ llvm-size --format=darwin macho.obj macho2.obj
   macho.obj:
   Segment : 12
           Section (__TEXT, __text): 4
           Section (__DATA, __data): 8
           total 12
   total 12
   macho2.obj:
   Segment : 48
           Section (__TEXT, __text): 16
           Section (__DATA, __data): 32
           total 48
   total 48
--help, -h
Muestra un resumen de las opciones de la línea de comandos.
-m
Equivalente a --format con el valor darwin.
-o
Equivalente a --radix con el valor 8.
--radix=<valor>
Muestra información de tamaño en la base especificada. Los valores permitidos son 8, 10 (el predeterminado) y 16 para salida octal, decimal y hexadecimal respectivamente.

Ejemplo:

$ llvm-size --radix=8 test.o
   text    data     bss     oct     hex filename
   0152      04      04     162      72 test.o
$ llvm-size --radix=10 test.o
   text    data     bss     dec     hex filename
    106       4       4     114      72 test.o
$ llvm-size --radix=16 test.o
   text    data     bss     dec     hex filename
   0x6a     0x4     0x4     114      72 test.o
--totals, -t
Se aplica solo al formato de salida berkeley. Muestra los totales para todos los campos listados, además de los listados de archivos individuales.

Ejemplo:

$ llvm-size --totals test.elf test2.o
   text    data     bss     dec     hex filename
    182      16       5     203      cb test.elf
     82       8       1      91      5b test2.o
    264      24       6     294     126 (TOTALS)
--version
Muestra la versión del ejecutable llvm-size.
-x
Equivalente a --radix con el valor 16.
@<ARCHIVO>
Lee las opciones de la línea de comandos desde el archivo de respuesta <ARCHIVO>.

ESTADO DE SALIDA

llvm-size sale con un código de salida distinto de cero si hay un error. De lo contrario, sale con el código 0.

ERRORES

Para reportar errores, visite <https://github.com/llvm/llvm-project/labels/tools:llvm-size/>.

    llvm-size(1)

    Muestra los tamaños de las secciones de archivos objeto. — LLVM command reference

    NAME

    llvm-size — muestra los tamaños de las secciones de archivos objeto.

    SYNOPSIS

    llvm-size [-A] [-B] [-o Format] [--radix=Radix] [-t] [--common] [--defined-only] [--extern-only] [--format=Format] [--help] [--linkage] [--merge-section] [--natural-size] [--no-sort] [--print-armap] [--print-file-names] [--print-load-command-segments] [--print-regular] [--radix=Radix] [--section-align] [--special-syms] [--sort-section] [--synthetic] [--target-str] [--total-size] [--verdefs] [--verneed] [--version] [--with-symbol-list=File] [--x86-interpret] [file...]

    DESCRIPTION

    llvm-size es una utilidad que muestra los tamaños de las secciones, símbolos y totales de los archivos objeto proporcionados. Es parte de la suite de herramientas LLVM y se comporta de manera similar a la utilidad size estándar.

    llvm-size puede imprimir el tamaño de los archivos objeto en una variedad de formatos, incluyendo una lista de secciones, una lista de símbolos, y un resumen total. También puede clasificar la salida según diferentes criterios.

    La utilidad admite varios formatos de salida, como sysv, berkeley, y darwin. También puede mostrar información sobre símbolos comunes, definidos y externos.

    OPTIONS

    -A, --format=berkeley
    Muestra los tamaños de las secciones en el formato tradicional de Berkeley.
    -B, --format=sysv
    Muestra los tamaños de las secciones en el formato System V.
    --common
    Muestra el tamaño de los símbolos comunes.
    --defined-only
    Muestra solo los símbolos definidos.
    --extern-only
    Muestra solo los símbolos externos.
    --format=Format
    Especifica el formato de salida. Los formatos disponibles son sysv, berkeley, y darwin.
    --help
    Muestra un mensaje de ayuda y sale.
    --radix=Radix
    Especifica la base para mostrar los números. El valor predeterminado es 10.
    -t, --totals
    Muestra los tamaños totales de las secciones.
    --version
    Muestra la información de la versión de llvm-size y sale.

    EXIT STATUS

    llvm-size sale con 0 si tiene éxito, y con un valor distinto de cero si ocurre un error.

    BUGS

    Los errores pueden ser reportados en GitHub.
