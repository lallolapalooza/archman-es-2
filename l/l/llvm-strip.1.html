NOMBRE

llvm-strip - herramienta para eliminar secciones de objetos

SINOPSIS

llvm-strip [opciones] entradas...

DESCRIPCIÓN

llvm-strip es una herramienta para eliminar secciones y símbolos de archivos de objeto. Si no se especifican otras opciones de eliminación o remoción, se habilitará --strip-all.

Por defecto, los archivos de entrada se modifican en el lugar. Si se especifica "-" para el archivo de entrada, la entrada se lee del flujo de entrada estándar del programa.

Si la entrada es un archivo (archive), cualquier operación solicitada se aplicará individualmente a cada miembro del archivo.

La herramienta todavía está en desarrollo activo, pero en la mayoría de los escenarios funciona como un reemplazo directo del strip de GNU.

OPCIONES GENÉRICAS Y MULTIPLATAFORMA

Las siguientes opciones son agnósticas del formato del archivo, o se aplican a múltiples formatos de archivo.

--disable-deterministic-archives, -U
Utiliza valores reales para UIDs, GIDs y marcas de tiempo al actualizar las cabeceras de los miembros del archivo.
--discard-all, -x
Elimina la mayoría de los símbolos locales no referenciados por relocalizaciones de la salida. Diferentes formatos de archivo pueden limitar esto a un subconjunto de los símbolos locales. Por ejemplo, los símbolos de archivo y sección en objetos ELF no se descartarán. Además, elimina todas las secciones de depuración.
--enable-deterministic-archives, -D
Habilita el modo determinista al eliminar archivos (archives), es decir, utiliza 0 para los UIDs, GIDs y campos de marca de tiempo de las cabeceras de los miembros del archivo. Habilitado por defecto.
--help, -h
Imprime un resumen de las opciones de la línea de comandos.
--no-strip-all
Deshabilita --strip-all.
-o <archivo>
Escribe la salida en <archivo>. No se pueden utilizar múltiples archivos de entrada en combinación con -o.
--only-keep-debug
Produce un archivo de depuración como salida que solo conserva el contenido de las secciones útiles para la depuración.

Para objetos ELF, esto elimina el contenido de las secciones SHF_ALLOC que no son SHT_NOTE convirtiéndolas en SHT_NOBITS y reduciendo los encabezados del programa cuando sea posible.

--regex
Si se especifica, los nombres de símbolos y secciones especificados por otras opciones se tratan como patrones de expresiones regulares extendidas POSIX.
--remove-section <sección>, -R
Elimina la sección especificada de la salida. Se puede especificar varias veces para eliminar varias secciones simultáneamente.
--strip-all-gnu
Elimina todos los símbolos, secciones de depuración y relocalizaciones de la salida. Esta opción es equivalente a la opción --strip-all de strip de GNU.
--strip-all, -s
Para objetos ELF, elimina de la salida todos los símbolos y secciones no asignables que no estén dentro de segmentos, excepto las secciones .gnu.warning, .ARM.attribute y la tabla de nombres de sección.

Para objetos COFF, elimina todos los símbolos, secciones de depuración y relocalizaciones de la salida.

--strip-debug, -d, -g, -S
Elimina todas las secciones de depuración de la salida.
--strip-symbol <símbolo>, -N
Elimina todos los símbolos con el nombre <símbolo> de la salida. Se puede especificar varias veces para eliminar varios símbolos.
--strip-unneeded
Elimina de la salida todos los símbolos locales o indefinidos que no sean necesarios para las relocalizaciones. También elimina todas las secciones de depuración.
--version, -V
Muestra la versión del ejecutable llvm-strip.
--wildcard, -w
Permite la sintaxis de comodines para las opciones relacionadas con símbolos. Habilitado por defecto para las opciones relacionadas con secciones. Incompatible con --regex.

La sintaxis de comodines permite los siguientes símbolos especiales:

Carácter Significado Equivalente
* Cualquier número de caracteres .*
? Cualquier carácter individual .
\ Escapar el siguiente carácter \
[a-z] Clase de caracteres [a-z]
[!a-z], [^a-z] Clase de caracteres negada [^a-z]

Adicionalmente, iniciar un comodín con '!' evitará una coincidencia, incluso si otra opción coincide. Por ejemplo, -w -N '*' -N '!x' eliminará todos los símbolos excepto x.

El orden de los comodines no importa. Por ejemplo, -w -N '*' -N '!x' es lo mismo que -w -N '!x' -N '*'.

@<ARCHIVO>
Lee las opciones de la línea de comandos y los comandos del archivo de respuestas <ARCHIVO>.

OPCIONES ESPECÍFICAS DE ELF

Las siguientes opciones solo se implementan para objetos ELF. Si se utilizan con otros objetos, llvm-strip emitirá un error o las ignorará silenciosamente.

--allow-broken-links
Permite a llvm-strip eliminar secciones incluso si dejara referencias de sección inválidas. Cualquier campo sh_link inválido se establecerá a cero.
--discard-locals, -X
Elimina los símbolos locales que comienzan con ".L" no referenciados por relocalizaciones de la salida.
--keep-file-symbols
Conserva los símbolos de tipo STT_FILE, incluso si de otro modo serían eliminados.
--keep-section <sección>
Al eliminar secciones de la salida, no elimine las secciones llamadas <sección>. Se puede especificar varias veces para conservar múltiples secciones.
--keep-symbol <símbolo>, -
Conserva los símbolos llamados <símbolo>, incluso si de otro modo serían eliminados. Se puede especificar varias veces para conservar múltiples símbolos.

NAME

llvm-strip

strip symbols from LLVM bitcode files

SYNOPSIS

llvm-strip [ --strip-all | -s ] [ --strip-debug ] [ -N name | --strip-symbol name ] [ -K name | --keep-symbol name ] [ -p | --preserve-dates ] [ --strip-sections ] [ -T ] [ input_file [ output_file ] ]

DESCRIPTION

The llvm-strip command is part of the LLVM toolchain and is used to remove symbols from object files. It operates on LLVM bitcode files and can remove debugging information, all symbols, or specific symbols based on the provided options. If an output file is not specified, the modified content will be written to standard output.

GENERIC AND CROSS-PLATFORM OPTIONS

--strip-all, -s
Remove all symbol table entries except for those relating to relocations.
--strip-debug
Remove debugging information from the output.
--strip-symbol=name, -N name
Do not write the symbols named name to the output. This option can be specified multiple times to remove multiple symbols.
--keep-symbol=name, -K name
When removing symbols from the output, do not remove symbols named name. Can be specified multiple times to keep multiple symbols.
--preserve-dates, -p
Preserve access and modification timestamps in the output.
--strip-sections
Remove from the output all section headers and all section data not within segments. Note that many tools will not be able to use an object without section headers.
-T
Remove Swift symbols.

ELF-SPECIFIC OPTIONS

Note: The options below are typically relevant for ELF object files, which may not be the primary target for llvm-strip when dealing with LLVM bitcode. However, if llvm-strip is used to process object files that have been converted from bitcode, these options might apply.

--strip-debug
Remove debugging information in the stripped object file. This is equivalent to -s, but also removes unneeded sections.
--strip-symbol=name, -N name
Do not write any symbols whose name is name to the output file. This option may be specified more than once to specify multiple symbols.
--keep-symbol=name, -K name
When removing symbols from the output, do not remove symbols named name. Can be specified multiple times to keep multiple symbols.
--preserve-dates, -p
Preserve access and modification timestamps in the output.
--strip-sections
Remove from the output all section headers and all section data not within segments. Note that many tools will not be able to use an object without section headers.
-T
Remove Swift symbols.

EXIT STATUS

llvm-strip exits with a non-zero exit code if there is an error. Otherwise, it exits with code 0.
