NOMBRE

llvm-otool - Herramienta de volcado de Mach-O

SINOPSIS

llvm-otool [opción...] [archivo...]

DESCRIPCIÓN

llvm-otool es una herramienta para volcar archivos Mach-O.

Intenta ser compatible con la línea de comandos y con la salida del otool de macOS.

OPCIONES

-arch <valor>
Selecciona una "slice" de un archivo Mach-O universal.
-chained_fixups
Imprime información de "chained fixups".
-C
Imprime sugerencias de optimización del enlazador.
-dyld_info
Imprime información de enlace y rebote.
-D
Imprime el ID de la biblioteca compartida.
-d
Imprime la sección de datos.
-f
Imprime cabeceras universales.
-G
Imprime la tabla de datos en código.
--help-hidden
Imprime ayuda para indicadores ocultos.
--help
Imprime ayuda.
-h
Imprime la cabecera Mach.
-I
Imprime la tabla de símbolos indirectos.
-j
Imprime los bytes del opcode.
-L
Imprime las bibliotecas compartidas usadas.
-l
Imprime comandos de carga.
-mcpu=<valor>
Selecciona la CPU para el desensamblado.
-o
Imprime el segmento de Objective-C.
-P
Imprime la sección __TEXT,__info_plist como cadenas.
-p <nombre de función>
Inicia el desensamblado en <nombre de función>.
-r
Imprime entradas de reubicación.
-s <nombreseg> <nombresec>
Imprime el contenido de la sección.
-t
Imprime la sección de texto.
--version
Imprime la versión.
-V
Simboliza los operandos desensamblados (implica -v).
-v
Salida detallada / desensambla al imprimir secciones de texto.
-X
Omite direcciones iniciales o cabeceras.
-x
Imprime todas las secciones de texto.
@<ARCHIVO>
Lee opciones de línea de comandos y comandos desde el archivo de respuestas <ARCHIVO>.

ESTADO DE SALIDA

llvm-otool sale con un código de salida distinto de cero si hay un error. De lo contrario, sale con el código 0.

ERRORES CONOCIDOS

Para informar de errores, visite <https://github.com/llvm/llvm-project/labels/tools:llvm-objdump/>.
