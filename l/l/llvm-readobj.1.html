NOMBRE

llvm-readobj - Lector de objetos LLVM

SINOPSIS

llvm-readobj [opciones] [entrada...]

DESCRIPCIÓN

La herramienta llvm-readobj muestra información de bajo nivel específica del formato sobre uno o más archivos de objeto.

Si entrada es "-", llvm-readobj lee desde la entrada estándar. De lo contrario, leerá desde los nombres de archivo especificados.

DIFERENCIAS CON LLVM-READELF

llvm-readelf es un alias para la herramienta llvm-readobj <llvm-readobj.html> con una interfaz de línea de comandos ligeramente diferente y una salida compatible con GNU. A continuación se presenta una lista de diferencias entre llvm-readelf y llvm-readobj:

  • llvm-readelf utiliza GNU para la opción --elf-output-style por defecto. llvm-readobj utiliza LLVM.
  • llvm-readelf permite agrupar indicadores de una sola letra (por ejemplo, llvm-readelf -SW es lo mismo que llvm-readelf -S -W). llvm-readobj no permite agrupaciones.
  • llvm-readelf proporciona -s como alias de --symbols, para compatibilidad con GNU readelf, mientras que en llvm-readobj es un alias de --section-headers.
  • llvm-readobj proporciona -t como alias de --symbols. llvm-readelf no lo hace.
  • llvm-readobj proporciona --sr, --sd, --st y --dt como alias de --section-relocations, --section-data, --section-symbols y --dyn-symbols respectivamente. llvm-readelf no proporciona estos alias, para evitar conflictos con indicadores agrupados.

OPCIONES GENERALES Y MULTIFORMATO

Estas opciones son aplicables a más de un formato de archivo, o no están relacionadas con formatos de archivo.

--all
Equivalente a especificar todas las opciones de visualización principales relevantes para el formato del archivo.
--addrsig
Muestra la tabla de significancia de direcciones.
--decompress, -z
Descarga el contenido de las secciones descomprimidas cuando se usa con -x o -p. Si las secciones no están comprimidas, se muestran tal cual.
--demangle, -C
Muestra nombres de símbolos desenredados en la salida. Esta opción es solo para los formatos de archivo ELF y XCOFF.
--expand-relocs
Cuando se usa con --relocs, muestra cada reubicación en un formato expandido de varias líneas.
--file-header, -h
Muestra los encabezados del archivo.
--headers, -e
Equivalente a establecer: --file-header, --program-headers y --sections.
--help
Muestra un resumen de las opciones de línea de comandos.
--hex-dump=<sección[,sección,...]>, -x
Muestra las secciones especificadas como bytes hexadecimales. sección puede ser un índice de sección o un nombre de sección.
--memtag

Muestra información sobre la etiquetación de memoria presente en el binario. Esto incluye varias entradas dinámicas específicas de memtag, secciones de descriptores globales decodificadas y notas ELF específicas de Android decodificadas.

--needed-libs
Muestra las bibliotecas necesarias.
--no-demangle
No desenredar los nombres de símbolos en la salida. Esta opción es solo para los formatos de archivo ELF y XCOFF. La opción está habilitada por defecto.
--relocations, --relocs, -r
Muestra las entradas de reubicación en el archivo.
--sections, --section-headers, -S
Muestra todas las secciones.
--section-data, --sd
Cuando se usa con --sections, muestra los datos de la sección para cada sección mostrada. Esta opción no tiene ningún efecto para la salida de estilo GNU.
--section-relocations, --sr
Cuando se usa con --sections, muestra las reubicaciones para cada sección mostrada. Esta opción no tiene ningún efecto para la salida de estilo GNU.
--section-symbols, --st
Cuando se usa con --sections, muestra los símbolos para cada sección mostrada. Esta opción no tiene ningún efecto para la salida de estilo GNU.
--sort-symbols=<clave_ordenación[,clave_ordenación]>
Especifica las claves para ordenar los símbolos antes de mostrar el symtab. Los valores válidos para clave_ordenación son name y type.
--stackmap
Muestra el contenido de la sección stackmap.
--string-dump=<sección[,sección,...]>, -p
Muestra las secciones especificadas como una lista de cadenas. sección puede ser un índice de sección o un nombre de sección.
--string-table
Muestra el contenido de la tabla de cadenas.
--symbols, --syms, -s
Muestra la tabla de símbolos.
--unwind, -u
Muestra información de desenrollado.
--version
Muestra la versión del ejecutable llvm-readobj.
@<ARCHIVO>
Lee las opciones de línea de comandos desde el archivo de respuesta <ARCHIVO>.

OPCIONES ESPECÍFICAS DE ELF

Las siguientes opciones solo se implementan para el formato de archivo ELF.

--arch-specific, -A
Muestra información específica de la arquitectura, por ejemplo, la sección de atributos ARM en ARM.
--bb-addr-map
Muestra el contenido de las secciones del mapa de direcciones de bloques básicos, que contienen la dirección de cada función, junto con el desplazamiento relativo de cada bloque básico.

Cuando hay mapas de análisis pgo presentes, todos los análisis se imprimen como su valor en bruto.

--pretty-pgo-analysis-map
Cuando hay mapas de análisis pgo presentes en el mapa de direcciones de bloques básicos

DESCRIPTION

llvm-readobj is a tool that displays information about Mach-O, PE/COFF, ELF, and XCOFF object files. It can display various sections, symbols, relocations, and other information. This tool is designed to be a replacement for objdump and readelf.

The command line arguments are grouped by the type of information they display.

GENERAL OPTIONS

-a, --all
Print all information that can be read from the object file. This is equivalent to specifying all of the flags below that print information.
-d, --dynamic-table
Print the dynamic table.

-g, --section-groups
Print section groups.
-h, --section-headers
Print the section headers.

Print the heap information.

-s, --sections
Print the contents of all sections.
-t, --syms

--architecture=<value>
Only process files with the specified architecture. See the -arch option in lld(1) for a list of architectures.

ELF SPECIFIC OPTIONS

The following options are implemented only for the ELF file format.

--section-details
Print section details. This includes things like section headers, relocation entries, and symbol table entries. The exact information printed depends on the section type. For sections with special formats (i.e. BlockFrequency, BranchProbability, etc.) analyses with special formats (i.e. BlockFrequency, BranchProbability, etc.) are printed using the same format as their respective analysis pass.

Requires --bb-addr-map to have an effect.

--dependent-libraries
Display the dependent libraries section.
--dyn-relocations
Display the dynamic relocation entries.
--dyn-symbols, --dyn-syms
Display the dynamic symbol table.
--dynamic-table, --dynamic
Display the dynamic table.
--cg-profile
Display the callgraph profile section.
--histogram
Display a bucket list histogram for dynamic symbol hash tables.
--elf-linker-options
Display the linker options section.
--elf-output-style=<value>
Format ELF information in the specified style. Valid options are LLVM, GNU, and JSON. LLVM output (the default) is an expanded and structured format. GNU output mimics the equivalent GNU readelf output. JSON is JSON formatted output intended for machine consumption.
--section-groups, -g
Display section groups.
--gnu-hash-table
Display the GNU hash table for dynamic symbols.
--hash-symbols
Display the expanded hash table with dynamic symbol data.
--hash-table
Display the hash table for dynamic symbols.
--memtag
Display information about memory tagging present in the binary. This includes various dynamic entries, decoded global descriptor sections, and decoded Android-specific ELF notes.
--notes, -n
Display all notes.
--pretty-print
When used with --elf-output-style, JSON output will be formatted in a more readable format.
--program-headers, --segments, -l
Display the program headers.
--section-mapping
Display the section to segment mapping.
--stack-sizes
Display the contents of the stack sizes section(s), i.e. pairs of function names and the size of their stack frames. Currently only implemented for GNU style output.
--version-info, -V
Display version sections.

--macho-dsymtab

--codeview-merged-types

--codeview-subsection-bytes
Dump raw contents of CodeView debug sections and records.
--coff-basereloc

--coff-debug-directory
Display the debug directory.
--coff-tls-directory
Display the TLS directory.
--coff-directives
Display the .drectve section.
--coff-exports
Display the export table.
--coff-imports
Display the import table.
--coff-load-config
Display the load config.
--coff-resources

XCOFF SPECIFIC OPTIONS

The following options are implemented only for the XCOFF file format.

--auxiliary-header
Display XCOFF Auxiliary header.
--exception-section
Display XCOFF exception section entries.
--loader-section-header
Display XCOFF loader section header.
--loader-section-symbols
Display symbol table of loader section.
--loader-section-relocations
Display relocation entries of loader section.

EXIT STATUS

llvm-readobj returns 0 under normal operation. It returns a non-zero exit code if there were any errors.
