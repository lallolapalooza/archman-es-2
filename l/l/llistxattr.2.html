listxattr(2) Manual de Llamadas al Sistema listxattr(2)

NOMBRE

listxattr(2), llistxattr(2), flistxattr(2) - listar nombres de atributos extendidos

BIBLIOTECA

Biblioteca C estándar (libc, -lc)

SINOPSIS

#include <sys/xattr.h>
ssize_t listxattr(const char *path, char *_Nullable list, size_t size);
ssize_t llistxattr(const char *path, char *_Nullable list, size_t size);
ssize_t flistxattr(int fd, char *_Nullable list, size_t size);

DESCRIPCIÓN

Los atributos extendidos son pares nombre:valor asociados con nodos inodo (archivos, directorios, enlaces simbólicos, etc.). Son extensiones de los atributos normales que están asociados con todos los nodos inodo en el sistema (es decir, los datos de stat(2)). Una descripción completa de los conceptos de atributos extendidos se puede encontrar en xattr(7).

listxattr() recupera la lista de nombres de atributos extendidos asociados con la ruta path dada en el sistema de archivos. La lista recuperada se coloca en list, un búfer asignado por el llamante cuyo tamaño (en bytes) se especifica en el argumento size. La lista es el conjunto de nombres (terminados en nulo), uno después del otro. Los nombres de los atributos extendidos a los que el proceso llamante no tiene acceso pueden omitirse de la lista. Se devuelve la longitud de la lista de nombres de atributos.

llistxattr() es idéntica a listxattr(), excepto en el caso de un enlace simbólico, donde se recupera la lista de nombres de atributos extendidos asociados con el propio enlace, no con el archivo al que apunta.

flistxattr() es idéntica a listxattr(), solo se interroga el archivo abierto al que hace referencia fd (tal como lo devuelve open(2)) en lugar de path.

Un solo nombre de atributo extendido es una cadena terminada en nulo. El nombre incluye un prefijo de espacio de nombres; puede haber varios espacios de nombres, disjuntos, asociados con un nodo inodo individual.

Si size se especifica como cero, estas llamadas devuelven el tamaño actual de la lista de nombres de atributos extendidos (y dejan list sin cambios). Esto se puede usar para determinar el tamaño del búfer que se debe proporcionar en una llamada posterior. (Pero, tenga en cuenta que existe la posibilidad de que el conjunto de atributos extendidos pueda cambiar entre las dos llamadas, por lo que todavía es necesario verificar el estado de retorno de la segunda llamada).

Ejemplo

La lista de nombres se devuelve como un array no ordenado de cadenas de caracteres terminadas en nulo (los nombres de atributos están separados por bytes nulos ('\0')), así:


user.nombre1\0system.nombre1\0user.nombre2\0

Los sistemas de archivos que implementan ACL de POSIX utilizando atributos extendidos podrían devolver una lista como esta:


system.posix_acl_access\0system.posix_acl_default\0

VALOR DE RETORNO

En caso de éxito, se devuelve un número no negativo que indica el tamaño de la lista de nombres de atributos extendidos. En caso de error, se devuelve -1 y se establece errno para indicar el error.

ERRORES

E2BIG
El tamaño de la lista de nombres de atributos extendidos es mayor que el tamaño máximo permitido; la lista no se puede recuperar. Esto puede suceder en sistemas de archivos que soportan un número ilimitado de atributos extendidos por archivo, como XFS, por ejemplo. Ver BUGS.
ENOTSUP
Los atributos extendidos no son compatibles con el sistema de archivos, o están deshabilitados.
ERANGE
El size del búfer list es demasiado pequeño para contener el resultado.

Además, los errores documentados en stat(2) también pueden ocurrir.

ESTÁNDARES

Linux.

HISTORIA

Linux 2.4, glibc 2.3.

BUGS

Como se indica en xattr(7), el VFS impone un límite de 64 kB al tamaño de la lista de nombres de atributos extendidos devuelta por listxattr(). Si el tamaño total de los nombres de atributos adjuntos a un archivo supera este límite, ya no es posible recuperar la lista de nombres de atributos.

EJEMPLOS

El siguiente programa demuestra el uso de listxattr() y getxattr(2). Para el archivo cuya ruta se proporciona como argumento de línea de comandos, lista todos los atributos extendidos del archivo y sus valores.

Para mantener el código simple, el programa asume que las claves y valores de los atributos son constantes durante la ejecución del programa. Un programa de producción debería esperar y manejar cambios durante la ejecución del programa. Por ejemplo, el número de bytes requeridos para las claves de atributos podría aumentar entre las dos llamadas a listxattr(). Una aplicación podría manejar esta posibilidad utilizando un bucle que reintente la llamada (quizás hasta un número máximo predeterminado de intentos) con un búfer más grande cada vez que falle con el error ERANGE. Las llamadas a getxattr(2) podrían manejarse de manera similar.

La siguiente salida fue registrada primero creando un archivo, estableciendo algunos atributos extendidos del archivo y luego listando los atributos con el programa de ejemplo.

Salida de ejemplo


$ touch /tmp/foo;
$ setfattr -n user.fred -v chocolate /tmp/foo;
$ setfattr -n user.frieda -v bar /tmp/foo;
$ setfattr -n user.empty /tmp/foo;
$ ./listxattr /tmp/foo;
user.fred: chocolate
user.frieda: bar
user.empty: <no value>

Código fuente del programa (listxattr.c)

#include <stdio.h>
#include <stdlib.h>
#include <string.h>
#include <sys/xattr.h>
int
main(int argc, char *argv[])
{
    char     *buf, *key, *val;
    ssize_t  buflen, keylen, vallen;
    if (argc != 2) {
        fprintf(stderr, "Uso: %s path\n", argv[0]);
        exit(EXIT_FAILURE);
    }
    /*
     * Determinar la longitud del búfer necesario.
     */
    buflen = listxattr(argv[1], NULL, 0);
    if (buflen == -1) {
        perror("listxattr");
        exit(EXIT_FAILURE);
    }
    if (buflen == 0) {
        printf("%s no tiene atributos.\n", argv[1]);
        exit(EXIT_SUCCESS);
    }
    /*
     * Asignar el búfer.
     */
    buf = malloc(buflen);
    if (buf == NULL) {
        perror("malloc");
        exit(EXIT_FAILURE);
    }
    /*
     * Copiar la lista de claves de atributos al búfer.
     */
    buflen = listxattr(argv[1], buf, buflen);
    if (buflen == -1) {
        perror("listxattr");
        exit(EXIT_FAILURE);
    }
    /*
     * Recorrer la lista de cadenas terminadas en cero con las
     * claves de atributos.  Usar la longitud restante del búfer para determinar
     * el final de la lista.
     */
    key = buf;
    while (buflen > 0) {
        /*
         * Salir la clave del atributo.
         */
        printf("%s: ", key);
        /*
         * Determinar la longitud del valor.
         */
        vallen = getxattr(argv[1], key, NULL, 0);
        if (vallen == -1)
            perror("getxattr");
        if (vallen > 0) {
            /*
             * Asignar búfer de valor.
             * Se necesita un byte adicional para añadir 0x00.
             */
            val = malloc(vallen + 1);
            if (val == NULL) {
                perror("malloc");
                exit(EXIT_FAILURE);
            }
            /*
             * Copiar el valor al búfer.
             */
            vallen = getxattr(argv[1], key, val, vallen);
            if (vallen == -1) {
                perror("getxattr");
            } else {
                /*
                 * Salir el valor del atributo.
                 */
                val[vallen] = 0;
                printf("%s", val);
            }
        }
        printf("\n");
        /*
         * Pasar a la siguiente clave de atributo.
         */
        keylen = strlen(key) + 1;
        buflen -= keylen;
        key += keylen;
    }
    free(buf);
    exit(EXIT_SUCCESS);
}
llistxattr(2)

NAME

llistxattr, llistxattr64 - enumerar atributos extendidos de un archivo

LIBRARY

Librería de C estándar (libc, -lc)

SYNOPSIS

#define _XOPEN_SOURCE 500 /* Opcional: Para obtener llistxattr */
#include <sys/types.h>
#include <sys/xattr.h>

ssize_t llistxattr(const char *path, char *list, size_t size);
ssize_t llistxattr64(const char *path, char *list, size_t size);

DESCRIPTION

La llamada al sistema llistxattr devuelve una lista de los nombres de los atributos extendidos asociados con el archivo que se especifica en path. Si el archivo es un enlace simbólico, se enumeran los atributos del propio enlace.

Si size es 0, llistxattr devuelve el número total de bytes necesarios para contener todos los nombres de los atributos extendidos. Si size es mayor que 0, el buffer apuntado por list se llena con los nombres de los atributos extendidos.

Los nombres de los atributos se devuelven como una secuencia de cadenas terminadas en nulo, sin ningún terminador adicional al final de la lista.

Si el buffer es demasiado pequeño para contener todos los nombres de los atributos, llistxattr devuelve el valor de size y no se modifica el contenido del buffer. Si el buffer es lo suficientemente grande, llistxattr devuelve el número total de bytes escritos en el buffer.

El argumento path es la ruta del archivo cuyos atributos extendidos se van a enumerar.

El argumento list es un puntero a un buffer donde se escribirán los nombres de los atributos extendidos. Cada nombre de atributo está separado por un carácter nulo ('\0').

El argumento size es el tamaño del buffer apuntado por list.

llistxattr64 es una versión de llistxattr que se utiliza para sistemas donde los tipos de datos de archivo de 64 bits son necesarios.

RETURN VALUE

En caso de éxito, llistxattr devuelve el número de bytes en el buffer list que contienen los nombres de los atributos, o el tamaño total de bytes necesarios si size es 0. En caso de error, devuelve -1 y errno se establece para indicar el error.

ERRORS

Se pueden establecer los siguientes valores de errno:

E2BIG
El buffer proporcionado es demasiado pequeño para contener todos los nombres de los atributos.
EACCES
No se tienen permisos de lectura para el directorio o archivo especificado.
EBADF
Un descriptor de archivo es inválido.
EFAULT
El argumento path o list apunta fuera del espacio de direcciones accesible.
EINVAL
El sistema de archivos no soporta atributos extendidos, o el argumento path es inválido.
EISDIR
El argumento path especifica un directorio.
ELOOP
Demasiados enlaces simbólicos se resolvieron al seguir path.
ENAMETOOLONG
La longitud del argumento path supera PATH_MAX.
ENOENT
El archivo no existe.
ENOMEM
Memoria insuficiente disponible.
ENOTDIR
Un componente de path no es un directorio.
ENOTSUP
El sistema de archivos no soporta atributos extendidos.
EOVERFLOW
El archivo es demasiado grande para ser representado en el sistema de archivos.
EPERM
No se tienen permisos suficientes para acceder a los atributos extendidos.
EROFS
El archivo reside en un sistema de archivos de solo lectura.
RT_NOACCESS
No se tienen permisos de acceso en tiempo real.

STANDARDS

Estas funciones son parte de la especificación POSIX.1-2001 y posteriores.

HISTORY

La llamada al sistema llistxattr apareció por primera vez en Linux en la versión 2.6.

BUGS

En versiones anteriores del kernel de Linux, el valor de retorno de llistxattr podía ser incorrecto si se utilizaba un tamaño de buffer que no era exactamente el necesario y el buffer estaba lleno.

EXAMPLES

Para listar los atributos extendidos de un archivo llamado myfile.txt:

    char buf[1024];
    ssize_t len;

    len = llistxattr("myfile.txt", buf, sizeof(buf));
    if (len == -1) {
        perror("llistxattr");
        exit(EXIT_FAILURE);
    }

    if (len == 0) {
        printf("No extended attributes.\n");
    } else {
        char *p, *end;
        p = buf;
        end = p + len;
        printf("Extended attributes:\n");
        while (p < end) {
            printf("  %s\n", p);
            p += strlen(p) + 1;
        }
    }

El código de ejemplo asume que no hay más de 1024 bytes de nombres de atributos.

Si el buffer es demasiado pequeño, es posible que deba llamar a llistxattr dos veces. La primera llamada con size = 0 para obtener el tamaño necesario, asignar un buffer de ese tamaño y luego hacer una segunda llamada con el buffer asignado.

    ssize_t list_size;

    list_size = llistxattr("myfile.txt", NULL, 0);
    if (list_size == -1) {
        perror("llistxattr (size inquiry)");
        exit(EXIT_FAILURE);
    }

    if (list_size == 0) {
        printf("No extended attributes.\n");
    } else {
        char *list = malloc(list_size);
        if (list == NULL) {
            perror("malloc");
            exit(EXIT_FAILURE);
        }

        ssize_t len = llistxattr("myfile.txt", list, list_size);
        if (len == -1) {
            perror("llistxattr (actual retrieval)");
            free(list);
            exit(EXIT_FAILURE);
        }

        if (len > list_size) {
            /* Esto no debería ocurrir si la llamada inicial a list_size fue correcta */
            fprintf(stderr, "Error: Buffer returned was smaller than initially reported.\n");
            free(list);
            exit(EXIT_FAILURE);
        }

        /* Procesar la lista de atributos */
        char *p, *end;
        p = list;
        end = p + len;
        printf("Extended attributes:\n");
        while (p < end) {
            printf("  %s\n", p);
            p += strlen(p) + 1;
        }

        free(list);
    }
