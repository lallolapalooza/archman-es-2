NOMBRE

llvm-config - Imprime opciones de compilación de LLVM

SINOPSIS

llvm-config opción [componentes...]

DESCRIPCIÓN

llvm-config facilita la compilación de aplicaciones que utilizan LLVM. Puede imprimir las opciones del compilador, las opciones del enlazador y las bibliotecas de objetos necesarias para enlazar con LLVM.

EJEMPLOS

Para enlazar con el JIT:

g++ `llvm-config --cxxflags` -o HowToUseJIT.o -c HowToUseJIT.cpp
g++ `llvm-config --ldflags` -o HowToUseJIT HowToUseJIT.o \
    `llvm-config --libs engine bcreader scalaropts`

OPCIONES

--assertion-mode

Imprime el modo de aserción utilizado al compilar LLVM (ON o OFF).

--bindir

Imprime el directorio de instalación de los binarios de LLVM.

--build-mode

Imprime el modo de compilación utilizado al compilar LLVM (por ejemplo, Debug o Release).

--build-system

Imprime el sistema de compilación utilizado para compilar LLVM (por ejemplo, cmake o gn).

--cflags

Imprime las opciones del compilador C necesarias para usar las cabeceras de LLVM.

--cmakedir

Imprime el directorio de instalación de los módulos CMake de LLVM.

--components

Imprime todos los nombres de componentes válidos.

--cppflags

Imprime las opciones del preprocesador C necesarias para usar las cabeceras de LLVM.

--cxxflags

Imprime las opciones del compilador C++ necesarias para usar las cabeceras de LLVM.

--has-rtti

Imprime si LLVM fue compilado con RTTI (YES o NO).

--help

Imprime un resumen de los argumentos de llvm-config.

--host-target

Imprime el triple de destino utilizado para configurar LLVM.

--ignore-libllvm

Ignora libLLVM y enlaza en su lugar bibliotecas de componentes.

--includedir

Imprime el directorio de instalación de las cabeceras de LLVM.

--ldflags

Imprime las opciones necesarias para enlazar con las bibliotecas de LLVM.

--libdir

Imprime el directorio de instalación de las bibliotecas de LLVM.

--libfiles

Similar a --libs, pero imprime la ruta completa de cada archivo de biblioteca. Esto es útil al crear dependencias de makefile, para asegurar que una herramienta se relacione si alguna biblioteca que utiliza cambia.

--libnames

Similar a --libs, pero imprime los nombres de archivo desnudos de las bibliotecas sin -l o rutas. Útil para enlazar con una copia de LLVM aún no instalada.

--libs

Imprime todas las bibliotecas necesarias para enlazar con los componentes de LLVM especificados, incluidas sus dependencias.

--link-shared

Enlaza los componentes como bibliotecas compartidas.

--link-static

Enlaza las bibliotecas de componentes de forma estática.

--obj-root

Imprime la raíz de objetos utilizada para compilar LLVM.

--prefix

Imprime el prefijo de instalación de LLVM.

--shared-mode

Imprime cómo se pueden enlazar colectivamente los componentes proporcionados (shared o static).

--system-libs

Imprime todas las bibliotecas del sistema necesarias para enlazar con los componentes de LLVM especificados, incluidas sus dependencias.

--targets-built

Imprime los nombres de los componentes para todos los objetivos compatibles con esta copia de LLVM.

--version

Imprime el número de versión de LLVM.

COMPONENTES

Para imprimir una lista de todos los componentes disponibles, ejecuta llvm-config --components. En la mayoría de los casos, los componentes corresponden directamente a las bibliotecas de LLVM. Los componentes "virtuales" útiles incluyen:

all

Incluye todas las bibliotecas de LLVM. Es el valor por defecto si no se especifican componentes.

backend

Incluye un backend nativo o el backend C.

engine

Incluye un JIT nativo o el intérprete de bitcode.

ESTADO DE SALIDA

Si llvm-config tiene éxito, saldrá con 0. De lo contrario, si ocurre un error, saldrá con un valor distinto de cero.
