NOMBRE

llvm-extract - extrae una función de un módulo LLVM

SINOPSIS

llvm-extract [opciones] --func nombre-de-función [nombre-de-archivo]

DESCRIPCIÓN

El comando llvm-extract toma el nombre de una función y la extrae del archivo de código de bits LLVM especificado. Se utiliza principalmente como una herramienta de depuración para reducir casos de prueba de programas más grandes que están activando un error.

Además de extraer el código de bits de la función especificada, llvm-extract también eliminará variables globales inalcanzables, prototipos y tipos no utilizados.

El comando llvm-extract lee su entrada de la entrada estándar si se omite el nombre de archivo o si el nombre de archivo es -. La salida siempre se escribe en la salida estándar, a menos que se especifique la opción -o (ver más abajo).

OPCIONES

--alias nombre-alias

Extrae el alias llamado nombre-de-función del código de bits LLVM. Puede especificarse varias veces para extraer varios alias a la vez.

--ralias expresion-regular-alias

Extrae el alias que coincide con expresion-regular-alias del código de bits LLVM. Se extraerán todos los alias que coincidan con la expresión regular. Puede especificarse varias veces.

--bb especificador-bloque-basico

Extrae el(los) bloque(s) básico(s) especificado(s) en especificador-bloque-basico. Puede especificarse varias veces. Cada par de especificadores <función:bb[;bb]> creará una función. Si se especifican varios bloques básicos en un par, el primer bloque de la secuencia debe dominar a los demás.

--delete

Elimina los Globales especificados del Módulo.

-f

Habilita la salida binaria en terminales. Normalmente, llvm-extract se negará a escribir salida de código de bits sin procesar si el flujo de salida es una terminal. Con esta opción, llvm-extract escribirá código de bits sin procesar independientemente del dispositivo de salida.

--func nombre-de-función

Extrae la función llamada nombre-de-función del código de bits LLVM. Puede especificarse varias veces para extraer varias funciones a la vez.

--rfunc expresion-regular-funcion

Extrae la(s) función(es) que coincide(n) con expresion-regular-funcion del código de bits LLVM. Se extraerán todas las funciones que coincidan con la expresión regular. Puede especificarse varias veces.

--glob nombre-global

Extrae la variable global llamada nombre-global del código de bits LLVM. Puede especificarse varias veces para extraer varias variables globales a la vez.

--rglob expresion-regular-global

Extrae la(s) variable(s) global(es) que coincide(n) con expresion-regular-global del código de bits LLVM. Se extraerán todas las variables globales que coincidan con la expresión regular. Puede especificarse varias veces.

--keep-const-init

Preserva los valores de las constantes globales.

--recursive

Extrae recursivamente todas las funciones llamadas

-help

Imprime un resumen de las opciones de la línea de comandos.

-o nombre-de-archivo

Especifica el nombre del archivo de salida. Si el nombre de archivo es "-" (el valor predeterminado), entonces llvm-extract envía su salida a la salida estándar.

-S

Escribe la salida en el lenguaje intermedio LLVM (en lugar de código de bits).

CÓDIGO DE SALIDA

Si llvm-extract tiene éxito, saldrá con 0. De lo contrario, si ocurre un error, saldrá con un valor distinto de cero.
