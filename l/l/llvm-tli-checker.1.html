NOMBRE

llvm-tli-checker - Comprobador de TargetLibraryInfo vs librería

SINOPSIS

llvm-tli-checker [opciones] [archivo-de-libreria...]

DESCRIPCIÓN

llvm-tli-checker compara la opinión de TargetLibraryInfo sobre la disponibilidad de funciones de librería con el conjunto de funciones exportadas por los archivos de librería especificados, informando de cualquier desacuerdo entre la opinión de TLI y si la función está realmente presente. Esto es principalmente útil para los vendedores para asegurar que la TLI de su objetivo es correcta, y que el compilador no "optimizará" alguna secuencia de código en una llamada a librería que no está realmente disponible.

EJEMPLO

$ llvm-tli-checker --triple x86_64-scei-ps4 example.so
TLI conoce 466 símbolos, 235 disponibles para 'x86_64-scei-ps4'
Buscando símbolos en 'example.so'
Se encontraron 235 símbolos de función globales en 'example.so'
Se encontró un total general de 235 símbolos de librería
<< TLI sí SDK no:  '_ZdaPv' aka operator delete[](void*)
>> TLI no  SDK sí: '_ZdaPvj' aka operator delete[](void*, unsigned int)
<< Total TLI sí SDK no:  1
>> Total TLI no  SDK sí: 1
== Total TLI sí SDK sí: 234
FALLO: La TLI de LLVM no coincide con las librerías del SDK.

OPCIONES

--dump-tli
Imprime "disponible"/"no disponible" para cada función de librería, según la información de TargetLibraryInfo para el triple especificado, y sale. Esta opción no lee ningún archivo de entrada.
--help, -h
Imprime un resumen de las opciones de línea de comandos y sale.
--libdir=<directorio>
Un directorio base para anteponer a cada ruta de archivo de librería. Esto es útil cuando hay varios archivos de librería todos en el mismo directorio, o una lista de nombres de archivo de entrada se mantiene en un archivo de respuesta.
--report=<nivel>
La cantidad de información a reportar. <nivel> puede ser summary (resumen), discrepancy (discrepancia) o full (completo). Un informe de resumen da solo el recuento de símbolos que coinciden y los que no; discrepancia lista los símbolos que no coinciden; y completo lista todos los símbolos conocidos por TLI, que coinciden o no. El valor predeterminado es discrepancy (discrepancia).
--separate
Lee y reporta un resumen para cada archivo de librería por separado. Esto puede ser útil para identificar archivos de librería que no aportan nada que TLI conozca. Implica --report=summary (puede ser anulado).
--triple=<triple>
El triple a usar para inicializar TargetLibraryInfo.
@<ARCHIVO>
Lee las opciones de línea de comandos y/o los nombres de librería desde el archivo de respuesta <ARCHIVO>.

ESTADO DE SALIDA

llvm-tli-checker retorna 0 incluso si hay discrepancias. Retorna un código de salida distinto de cero si hay una opción no reconocida, o si no se proporcionan archivos de entrada.
