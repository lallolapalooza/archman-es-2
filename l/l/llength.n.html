llength(n) Comandos integrados de Tcl llength(n)

NOMBRE

llength - Contar el número de elementos de una lista

SINOPSIS

llength lista

DESCRIPCIÓN

Trata lista como una lista y devuelve una cadena decimal con el número de elementos que contiene.

EJEMPLOS

El resultado es el número de elementos:

% llength {a b c d e}
5
% llength {a b c}
3
% llength {}
0

Los elementos no están garantizados que sean exactamente palabras en el sentido de un diccionario, especialmente cuando se usa el uso de comillas:

% llength {a b {c d} e}
4
% llength {a b { } c d e}
6

Una lista vacía no es necesariamente una cadena vacía:

% set var { }; puts "[string length $var],[llength $var]"
1,0
