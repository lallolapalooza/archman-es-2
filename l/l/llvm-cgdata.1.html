NOMBRE

llvm-cgdata - Herramienta de datos de generación de código de LLVM

SINOPSIS

llvm-cgdata [comandos] [opciones] (<binarios>|<.cgdata>)

DESCRIPCIÓN

La utilidad :program:llvm-cgdata analiza los datos brutos de generación de código incrustados en archivos binarios compilados y los fusiona en un único archivo .cgdata. También puede inspeccionar y manipular archivos .cgdata. Actualmente, la herramienta admite el guardado y la restauración de árboles hash delineados y mapas de funciones estables, lo que permite un delineado de funciones y una fusión de funciones más eficientes entre módulos en compilaciones posteriores. El diseño es extensible, lo que permite la incorporación de resúmenes de generación de código y técnicas de optimización adicionales.

COMANDOS

Se requiere al menos uno de los siguientes comandos:

--convert
Convierte un archivo .cgdata de un formato a otro.
--merge
Fusiona múltiples datos brutos de generación de código en binarios en un único archivo .cgdata.
--show
Muestra información resumida sobre un archivo .cgdata.

OPCIONES

llvm-cgdata admite las siguientes opciones:

--format=[text|binary]
Especifica el formato del archivo .cgdata de salida.
--output=<cadena>
Especifica el nombre del archivo de salida.
--cgdata-version
Imprime la versión de la herramienta llvm-cgdata.

EJEMPLOS

Para convertir un archivo .cgdata de formato binario a texto:
$ llvm-cgdata --convert --format=text input.cgdata --output=output.data
Para fusionar múltiples datos brutos de generación de código en archivos objeto en un único archivo .cgdata:
$ llvm-cgdata --merge file1.o file2.o --output=merged.cgdata
Para mostrar información resumida sobre un archivo .cgdata:
$ llvm-cgdata --show input.cgdata
