NOMBRE

llvm-dwarfdump - volcar y verificar información de depuración DWARF

SINOPSIS

llvm-dwarfdump [opciones] [archivo ...]

DESCRIPCIÓN

llvm-dwarfdump analiza las secciones DWARF en archivos objeto, archivos y paquetes .dSYM e imprime su contenido en formato legible por humanos. Solo se imprime la sección .debug_info a menos que se especifique una de las opciones específicas de sección o --all.

Si no se especifica ningún archivo de entrada, se utiliza a.out. Si se usa - como archivo de entrada, llvm-dwarfdump lee la entrada de su flujo de entrada estándar.

OPCIONES

-a, --all
Volcar todas las secciones DWARF soportadas.
--arch=<arquitectura>
Volcar la información de depuración DWARF para la arquitectura de CPU especificada. Las arquitecturas pueden especificarse por nombre o por número. Esta opción se puede especificar varias veces, una por cada arquitectura deseada. Todas las arquitecturas de CPU se imprimirán por defecto.
-c, --show-children
Mostrar los hijos de una entrada de información de depuración al imprimir selectivamente con el argumento =<offset> de --debug-info, o opciones como --find o --name.
--color
Usar colores en la salida.
--error-display=<valor>
Establecer el nivel de detalle y resumen a mostrar al verificar. Implica --verify. Los valores soportados son:

quiet - Solo mostrar si ocurrieron errores. summary - Mostrar solo un resumen de los errores encontrados. details - Mostrar cada error en detalle pero sin resumen. full - Mostrar cada error así como un resumen. [por defecto]

-f <nombre>, --find=<nombre>
Buscar la cadena exacta <nombre> en las tablas de aceleración e imprimir las entradas de información de depuración coincidentes. Cuando no hay tablas de aceleración o el nombre del DIE que buscas no se encuentra en las tablas de aceleración, intenta usar la opción más lenta pero más completa --name.
-F, --show-form
Mostrar los tipos de formulario DWARF después de los tipos de atributo DWARF.
-h, --help
Mostrar ayuda y uso para este comando.
--help-list
Mostrar ayuda y uso para este comando sin agrupar las opciones en categorías.
-i, --ignore-case
Ignorar distinciones de mayúsculas y minúsculas al usar --name.
-n <nombre>, --name=<nombre>
Encontrar e imprimir todas las entradas de información de depuración cuyo nombre (atributo DW_AT_name) sea <nombre>.
--lookup=<dirección>
Buscar <dirección> en la información de depuración e imprimir los detalles del archivo, función, bloque y tabla de líneas.
-o <ruta>
Redirigir la salida a un archivo especificado por <ruta>, donde - es el flujo de salida estándar.
-p, --show-parents
Mostrar los padres de una entrada de información de depuración al imprimir selectivamente con el argumento =<offset> de --debug-info, o opciones como --find o --name.
--parent-recurse-depth=<N>
Al mostrar los padres de las entradas de información de depuración, solo muéstralos hasta una profundidad máxima de <N>.
--quiet
Usar con --verify para no emitir a STDOUT.
-r <N>, --recurse-depth=<N>
Al mostrar las entradas de información de depuración, solo mostrar los hijos hasta una profundidad máxima de <N>.
--show-section-sizes
Mostrar los tamaños de todas las secciones de depuración, expresados en bytes.
--show-sources
Imprimir todos los archivos fuente mencionados en la información de depuración. Se proporcionan rutas absolutas siempre que sea posible.
--statistics
Recopilar métricas de calidad de la información de depuración e imprimir los resultados como una salida JSON de una sola línea legible por máquina. El formato de salida se describe en la siguiente sección (FORMATO DE SALIDA DE ESTADÍSTICAS).
--summarize-types
Abreviar la descripción de las entradas de unidades de tipo.
-x, --regex
Tratar las cadenas <nombre> como expresiones regulares al buscar con --name. Si también se especifica --ignore-case, la expresión regular no distinguirá entre mayúsculas y minúsculas.
-u, --uuid
Mostrar el UUID para cada arquitectura.
--diff
Volcar la salida en un formato más amigable para comparar la salida DWARF de dos archivos diferentes.
-v, --verbose
Mostrar información detallada al volcar. Esto puede ayudar a depurar problemas de DWARF.
--verify
Verificar la estructura de la información DWARF verificando las cadenas de unidades de compilación, el gráfico de relaciones DIE, los rangos de direcciones y más.
--verify-json=<ruta>
Emitir un resumen de errores en formato JSON al archivo especificado por <ruta>. Implica --verify. El formato de salida se describe en la siguiente sección (FORMATO DE SALIDA JSON DE VERIFICACIÓN).
--version
Mostrar la versión de la herramienta.
--debug-abbrev, --debug-addr, --debug-aranges, --debug-cu-index, --debug-frame [=<offset>], --debug-gnu-pubnames, --debug-gnu-pubtypes, --debug-info [=<offset>], --debug-line [=<offset>], --debug-str-offsets, --debug-loc [=<offset>], --debug-loclists [=<offset>], --debug-macro, --debug-names, --debug-pubnames, --debug-pubtypes, --debug-ranges, --debug-rnglists, --debug-str, --debug-str-offsets, --debug-tu-index, --debug-types [=<offset>], --eh-frame [=<offset>], --gdb-index, --apple-names, --apple-types, --apple-namespaces, --apple-objc
Volcar la sección DWARF especificada por nombre. Por defecto, solo se muestra la sección .debug_info. Algunas entradas admiten la adición de un =<offset> como forma de proporcionar un desplazamiento opcional de la entrada exacta a volcar dentro de la sección respectiva. OPTIONS

llvm-dwarfdump accepts the following options:

-a
--show-all
Dump all debugging information sections. This is equivalent to using --debug-abbrev, --debug-aranges, --debug-info, --debug-line, --debug-loc, --debug-macinfo, --debug-pubnames, --debug-ranges, --debug-str, and --debug-str-str.
-b
--debug-abbrev
Dump the .debug_abbrev section.
-i
--debug-info
Dump the .debug_info section.
-l
--debug-line
Dump the .debug_line section.
-o
--debug-loc
Dump the .debug_loc section.
-m
--debug-macinfo
Dump the .debug_macinfo section.
-p
--debug-pubnames
Dump the .debug_pubnames section.
-r
--debug-ranges
Dump the .debug_ranges section.
-s
--debug-str
Dump the .debug_str section.
-S
--debug-str-str
Dump the .debug_str_str section.
-z
--debug-str-offsets
Dump the .debug_str_offsets section.
-x
--debug-rnglists
Dump the .debug_rnglists section.
-q
--debug-loclists
Dump the .debug_loclists section.
-a
--show-all-info
Dump all sections related to debugging information.
-A
--debug-aranges
Dump the .debug_aranges section.
-F
--eh-frame
Dump the .eh_frame section.
-f
--debug-frame
Dump the .debug_frame section. This option is equivalent to --eh-frame.
-g
--gen-references
Generate references for every debug info entry. This option implies --debug-info.
-h
--help
Print a synopsis of command line options.
-j
--verify-json[=SECTION]
Validate the DWARF JSON output and print a summary of errors. If SECTION is specified, only that section will be validated. Otherwise, all DWARF sections will be validated.
-k
--keep-aggregated-types
Do not aggregate types. This option implies --debug-info.
-N
--no-sort-dyndesc
Do not sort dynamic descriptor entries. This option implies --debug-info.
-l
--lookup-files
Lookup for the source files in the current directory. This option implies --debug-line.
-d
--dump-section SECTION[:OFFSET[:SIZE]]
Dump the specified SECTION. If OFFSET and SIZE are specified, only the entry at that offset will be dumped, else the entire section will be dumped.
-d
--debug-macro
Prints both the .debug_macro and the .debug_macinfo sections.
--debug-frame and --eh-frame
Options are aliases, in cases where both sections are present one command outputs both.
@<FILE>
Read command-line options from <FILE>.

FORMAT OF STATISTICS OUTPUT

The --statistics option generates single-line JSON output representing quality metrics of the processed debug info. These metrics are useful to compare changes between two compilers, particularly for judging the effect that a change to the compiler has on the debug info quality.

The output is formatted as key-value pairs. The first pair contains a version number. The following naming scheme is used for the keys:

  • variables ==> local variables and parameters
  • local vars ==> local variables
  • params ==> formal parameters

For aggregated values, the following keys are used:

  • sum_of_all_variables(...) ==> the sum applied to all variables
  • #bytes ==> the number of bytes
  • #variables - entry values ... ==> the number of variables excluding the entry values etc.

FORMAT OF VERIFY JSON OUTPUT

The format of the JSON output created by the --verify-json is:

{
  "error-categories": {
    "<first category description>": {"count": 1234},
    "<next category description>": {"count": 4321}
  },
  "error-count": 5555
}

The following is generated if there are no errors reported:

{
  "error-categories": {},
  "error-count": 0
}

EXIT STATUS

llvm-dwarfdump returns 0 if the input files were parsed and dumped successfully. Otherwise, it returns 1.
