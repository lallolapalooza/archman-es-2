NOMBRE

llvm-readelf - Lector de objetos LLVM al estilo GNU

SINOPSIS

llvm-readelf [opciones] [entrada...]

DESCRIPCIÓN

La herramienta llvm-readelf muestra información de bajo nivel específica del formato sobre uno o más archivos objeto.

Si entrada es "-", llvm-readelf lee de la entrada estándar. De lo contrario, leerá de los nombres de archivo especificados.

OPCIONES

--all, -a
Equivalente a especificar todas las opciones de visualización principales relevantes para el formato del archivo.
--addrsig
Muestra la tabla de significancia de direcciones.
--arch-specific, -A
Muestra información específica de la arquitectura, por ejemplo, la sección de atributos ARM en ARM.
--bb-addr-map
Muestra el contenido de la(s) sección(es) de mapa de direcciones de bloques básicos, que contienen la dirección de cada función, junto con el desplazamiento relativo de cada bloque básico.
--decompress, -z
Descarga el contenido de la sección descomprimida cuando se usa con -x o -p. Si la(s) sección(es) no están comprimidas, se muestran tal cual.
--demangle, -C
Muestra los nombres de símbolos desenmascarados en la salida.
--dependent-libraries
Muestra la sección de bibliotecas dependientes.
--dyn-relocations
Muestra las entradas de reubicación dinámica.
--dyn-symbols, --dyn-syms
Muestra la tabla de símbolos dinámica.
--dynamic-table, --dynamic, -d
Muestra la tabla dinámica.
--cg-profile
Muestra la sección de perfil del grafo de llamadas.
--histogram, -I
Muestra una lista de cubetas para tablas de hash de símbolos dinámicos.
--elf-linker-options
Muestra la sección de opciones del enlazador.
--elf-output-style=<valor>
Formatea la información ELF en el estilo especificado. Las opciones válidas son LLVM, GNU y JSON. La salida LLVM es un formato ampliado y estructurado. La salida GNU (la predeterminada) imita la salida equivalente de readelf de GNU. JSON es una salida con formato JSON destinada al consumo por máquinas.
--extra-sym-info
Muestra información adicional (nombre de sección) al mostrar símbolos.
--section-groups, -g
Muestra grupos de secciones.
--expand-relocs
Cuando se usa con --relocations, muestra cada reubicación en un formato ampliado de varias líneas.
--file-header, -h
Muestra las cabeceras de archivo.
--gnu-hash-table
Muestra la tabla hash de GNU para símbolos dinámicos.
--hash-symbols
Muestra la tabla hash ampliada con datos de símbolos dinámicos.
--hash-table
Muestra la tabla hash para símbolos dinámicos.
--headers, -e
Equivalente a establecer: --file-header, --program-headers y --sections.
--help
Muestra un resumen de las opciones de la línea de comandos.
--hex-dump=<sección[,sección,...]>, -x
Muestra la(s) sección(es) especificada(s) como bytes hexadecimales. sección puede ser un índice de sección o un nombre de sección.
--memtag
Muestra información sobre el etiquetado de memoria presente en el binario. Esto incluye varias entradas dinámicas específicas de memtag, secciones de descriptores globales decodificadas y notas ELF específicas de Android decodificadas.
--needed-libs
Muestra las bibliotecas necesarias.
--no-demangle
No muestra los nombres de símbolos desenmascarados en la salida. Activado por defecto.
--notes, -n
Muestra todas las notas.
--pretty-print
Cuando se usa con --elf-output-style, la salida JSON se formateará de manera más legible.
--program-headers, --segments, -l
Muestra las cabeceras de programa.
--relocations, --relocs, -r
Muestra las entradas de reubicación en el archivo.
--sections, --section-headers, -S
Muestra todas las secciones.
--section-data
Cuando se usa con --sections, muestra los datos de la sección para cada sección mostrada. Esta opción no tiene efecto para la salida estilo GNU.
--section-details, -t
Muestra todos los detalles de la sección. Se usa como alternativa a --sections.
--section-mapping
Muestra el mapeo de sección a segmento.
--section-relocations
Cuando se usa con --sections, muestra las reubicaciones para cada sección mostrada. Esta opción no tiene efecto para la salida estilo GNU.
--section-symbols
Cuando se usa con --sections, muestra los símbolos para cada sección mostrada. Esta opción no tiene efecto para la salida estilo GNU.
--stackmap
Muestra el contenido del mapa de pila

EJEMPLOS

Mostrar toda la información de un archivo ELF:

llvm-readelf --all your_object_file.o

Mostrar la tabla de símbolos dinámica y la tabla de cadenas de símbolos dinámicos:

llvm-readelf --dyn-syms --dyn-str-index your_object_file.o

Mostrar la sección de texto como hexadecimal:

llvm-readelf --hex-dump=.text your_object_file.o

Mostrar cabeceras, secciones y programas de un archivo, con salida al estilo GNU:

llvm-readelf -e -S -l --elf-output-style=GNU your_object_file.o

OPCIONES

-a
Equivalente a --all.
--all
Imprime toda la información de la sección. Esto es equivalente a especificar las opciones -h, -l, -S, -s, y -d.
-c
Imprime la información de la tabla de relajación.
-d
Imprime la tabla de símbolos dinámicos.
--dependency-file
Imprime la tabla de dependencias.
--dynamic, -D
Imprime la información de la sección dinámica. Esto incluye la tabla dinámica de símbolos, las dependencias dinámicas, la información de relocación dinámica, etc.
-e
Imprime la tabla de reubicación.
--ethers, -e
Imprime la tabla de símbolos de Ether (solo para archivos Solaris).
-f
Imprime la tabla de cabeceras de archivo.
-g
Imprime la tabla de símbolos de depuración (si está presente).
--headers, -h
Imprime la tabla de cabeceras de sección.
-i
Imprime la tabla de información de introducción (si está presente).
--relocs, -l
Imprime la tabla de reubicaciones.
-n
Imprime la tabla de reubicaciones de texto y datos (obsoleta, use -l).
-o
Imprime la tabla de símbolos de .gnu.linkonce.
-p
Imprime la tabla de símbolos dinámicos.
-r
Imprime la tabla de relajaciones.
--symbols, --syms, -s
Imprime la tabla de símbolos.
--section, -A
Imprime el contenido de la sección especificada. Use un nombre o índice de sección. Por ejemplo, -A .text.
--stack-sizes
Muestra el contenido de la(s) sección(es) de tamaños de pila, es decir, pares de nombres de función y el tamaño de sus marcos de pila. Actualmente solo implementado para el estilo de salida GNU.
--string-dump=<sección[,sección,...]>, -p
Muestra la(s) sección(es) especificada(s) como una lista de cadenas. sección puede ser un índice o nombre de sección.
-t
Imprime la tabla de texto.
--unwind, -u
Imprime información de desenrollado.
-v
Imprime la información de la versión.
--version
Imprime la versión del ejecutable llvm-readelf.
--version-info, -V
Imprime secciones de versión.
--wide, -W
Ignorado para compatibilidad con GNU readelf. La salida ya es similar a cuando se usa -W con GNU readelf.
@<FILE>
Lee las opciones de la línea de comandos desde el archivo de respuesta <FILE>.

ESTADO DE SALIDA

llvm-readelf retorna 0 en operación normal. Retorna un código de salida distinto de cero si hubo algún error.
