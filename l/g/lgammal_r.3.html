lgamma(3) Manual de funciones de biblioteca lgamma(3)

NOMBRE

lgamma, lgammaf, lgammal, lgamma_r, lgammaf_r, lgammal_r, signgam - función logaritmo gamma

BIBLIOTECA

Biblioteca matemática (libm, -lm)

SINOPSIS

#include <math.h>
double lgamma(double x);
float lgammaf(float x);
long double lgammal(long double x);
double lgamma_r(double x, int *signp);
float lgammaf_r(float x, int *signp);
long double lgammal_r(long double x, int *signp);
extern int signgam;

DESCRIPCIÓN

Para la definición de la función Gamma, ver tgamma(3).

Las funciones lgamma(), lgammaf() y lgammal() devuelven el logaritmo natural del valor absoluto de la función Gamma. El signo de la función Gamma se devuelve en el entero externo signgam declarado en <math.h>. Es 1 cuando la función Gamma es positiva o cero, -1 cuando es negativa.

Dado que el uso de una ubicación constante signgam no es seguro para hilos, se han introducido las funciones lgamma_r(), lgammaf_r() y lgammal_r(); devuelven el signo a través del argumento signp.

VALOR DE RETORNO

En caso de éxito, estas funciones devuelven el logaritmo natural de Gamma(x).

Si x es NaN, se devuelve NaN.

Si x es 1 o 2, se devuelve +0.

Si x es infinito positivo o infinito negativo, se devuelve infinito positivo.

Si x es un entero no positivo, ocurre un error de polo y las funciones devuelven +HUGE_VAL, +HUGE_VALF o +HUGE_VALL, respectivamente.

Si el resultado excede los límites, ocurre un error de rango y las funciones devuelven HUGE_VAL, HUGE_VALF o HUGE_VALL, respectivamente, con el signo matemático correcto.

ERRORES

Consulte math_error(7) para obtener información sobre cómo determinar si ha ocurrido un error al llamar a estas funciones.

Los siguientes errores pueden ocurrir:

Error de polo: x es un entero no positivo
errno se establece en ERANGE (pero consulte BUGS). Se genera una excepción de punto flotante de división por cero (FE_DIVBYZERO).
Error de rango: desbordamiento del resultado
errno se establece en ERANGE. Se genera una excepción de punto flotante de desbordamiento (FE_OVERFLOW).

ERRORES CONOCIDOS

En glibc 2.9 y anteriores, cuando ocurre un error de polo, errno se establece en EDOM; en lugar del ERANGE exigido por POSIX. Desde glibc 2.10, glibc hace lo correcto.
