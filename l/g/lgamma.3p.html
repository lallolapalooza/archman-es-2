NOMBRE

lgamma, lgammaf, lgammal, signgam — función log-gamma

SINOPSIS

#include <math.h>
double lgamma(double x);
float lgammaf(float x);
long double lgammal(long double x);
extern int signgam;

DESCRIPCIÓN

La funcionalidad descrita en esta página de referencia se alinea con el estándar ISO C. Cualquier conflicto entre los requisitos descritos aquí y el estándar ISO C es involuntario. Este volumen de POSIX.1‐2017 se remite al estándar ISO C.

Estas funciones calcularán log_e │Γ(x)│ donde Γ(x) se define como ∫0∞e^ −tt^ x−1dt . El argumento x no necesita ser un entero no positivo ( Γ(x) se define sobre los reales, excepto los enteros no positivos).

Si x es NaN, -Inf o un entero negativo, el valor de signgam no está especificado.

Estas funciones no tienen por qué ser seguras para hilos.

Una aplicación que desee comprobar situaciones de error debe establecer errno a cero y llamar a feclearexcept(FE_ALL_EXCEPT) antes de llamar a estas funciones. Al regresar, si errno es distinto de cero o fetestexcept(FE_INVALID | FE_DIVBYZERO | FE_OVERFLOW | FE_UNDERFLOW) es distinto de cero, ha ocurrido un error.

VALOR DE RETORNO

Al completarse con éxito, estas funciones devolverán el gamma logarítmico de x.

Si x es un entero no positivo, ocurrirá un error de polo y lgamma(), lgammaf(), y lgammal() devolverán +HUGE_VAL, +HUGE_VALF, y +HUGE_VALL, respectivamente.

Si el valor correcto causara un desbordamiento, ocurrirá un error de rango y lgamma(), lgammaf(), y lgammal() devolverán ±HUGE_VAL, ±HUGE_VALF, y ±HUGE_VALL (teniendo el mismo signo que el valor correcto), respectivamente.

Si x es NaN, se devolverá un NaN.

Si x es 1 o 2, se devolverá +0.

Si x es ±Inf, se devolverá +Inf.

ERRORES

Estas funciones fallarán si:

Error de polo
El argumento x es un entero negativo o cero.

Si la expresión entera (math_errhandling & MATH_ERRNO) es distinta de cero, entonces errno se establecerá en [ERANGE]. Si la expresión entera (math_errhandling & MATH_ERREXCEPT) es distinta de cero, entonces se generará la excepción flotante de división por cero.

Error de rango
El resultado desborda.

Si la expresión entera (math_errhandling & MATH_ERRNO) es distinta de cero, entonces errno se establecerá en [ERANGE]. Si la expresión entera (math_errhandling & MATH_ERREXCEPT) es distinta de cero, entonces se generará la excepción flotante de desbordamiento.

Las siguientes secciones son informativas.

EJEMPLOS

Ninguno.

USO DE LA APLICACIÓN

En caso de error, las expresiones (math_errhandling & MATH_ERRNO) y (math_errhandling & MATH_ERREXCEPT) son independientes entre sí, pero al menos una de ellas debe ser distinta de cero.

NOMBRE

lgamma, lgamma_r - Función gamma logarítmica

SINOPSIS

#include <math.h>

double lgamma(double x);
float lgammaf(float x);
long double lgammaf(long double x);

double lgamma_r(double x, int *signgamp);
float lgammaf_r(float x, int *signgamp);
long double lgammaf_r(long double x, int *signgamp);

DESCRIPCIÓN

La función lgamma() calcula el logaritmo natural del valor absoluto de la función gamma, $\Gamma(x)$.

La función gamma se define como:

$$ \Gamma(x) = \int_0^\infty t^{x-1} e^{-t} dt $$

Para $x > 0$. La función se puede extender a valores complejos usando la fórmula de reflexión:

$$ \Gamma(z) \Gamma(1-z) = \frac{\pi}{\sin(\pi z)} $$

La función lgamma() se define para todos los números reales excepto los enteros no positivos ($0, -1, -2, \dots$).

La función lgamma_r() es una versión reentrante de lgamma(). Devuelve el mismo valor que lgamma() y además el signo de $\Gamma(x)$ en la variable apuntada por signgamp. El valor devuelto es $\ln(|\Gamma(x)|)$. Si $\Gamma(x)$ es positivo, signgamp se establecerá en 1. Si $\Gamma(x)$ es negativo, signgamp se establecerá en -1.

VALOR DEVUELTO

En caso de éxito, lgamma() devuelve el logaritmo natural del valor absoluto de la función gamma de x. Para lgamma_r(), se devuelve el mismo valor y el signo se almacena en la variable apuntada por signgamp.

En caso de error:

  • Si x es 0 o un entero negativo, se produce un error de dominio, se devuelve HUGE_VAL, HUGE_VALF o HUGE_VALL, y errno se establece en EDOM.
  • Si x es NaN, se devuelve NaN y, opcionalmente, errno se establece en EDOM.
  • Si el resultado es demasiado grande para ser representado (desbordamiento), se produce un error de rango, se devuelve HUGE_VAL, HUGE_VALF o HUGE_VALL, y errno se establece en ERANGE.

EJEMPLOS

El siguiente programa de ejemplo muestra cómo usar lgamma() y lgamma_r():

#include <stdio.h>
#include <math.h>
#include <errno.h>

int main(void) {
double x = 5.0;
double y, y_abs;
int sign;

errno = 0;
y = lgamma(x);
if (errno == EDOM) {
fprintf(stderr, "Error de dominio: lgamma(%.1f)\n", x);
return 1;
} else if (errno == ERANGE) {
fprintf(stderr, "Error de rango: lgamma(%.1f)\n", x);
return 1;
}
printf("lgamma(%.1f) = %f\n", x, y);

errno = 0;
y_abs = lgamma_r(x, &sign);
if (errno == EDOM) {
fprintf(stderr, "Error de dominio: lgamma_r(%.1f)\n", x);
return 1;
} else if (errno == ERANGE) {
fprintf(stderr, "Error de rango: lgamma_r(%.1f)\n", x);
return 1;
}
printf("lgamma_r(%.1f) = %f, sign = %d\n", x, y_abs, sign);

return 0;
}

CONFORME A

La función lgamma() está definida por POSIX.1-2008.

La función lgamma_r() está definida por POSIX.1-2001 y POSIX.1-2008.
