NOMBRE

lpinfo - muestra dispositivos o controladores disponibles (obsoleto)

SINOPSIS

lpinfo [ -h servidor[:puerto] ] [ -E ] [ -l ] [ --device-id cadena-id-dispositivo ] [ --exclude-schemes lista-esquemas ] [ --include-schemes lista-esquemas ] [ --language localidad ] [ --make-and-model nombre ] [ --product nombre ] -m
lpinfo [ -h servidor[:puerto] ] [ -E ] [ -l ] [ --exclude-schemes lista-esquemas ] [ --include-schemes lista-esquemas ] [ --timeout segundos ] -v

DESCRIPCIÓN

lpinfo lista los dispositivos o controladores disponibles conocidos por el servidor CUPS. La primera forma (-m) lista los controladores disponibles, mientras que la segunda forma (-v) lista los dispositivos disponibles.

OPCIONES

lpinfo acepta las siguientes opciones:

-E
Fuerza el cifrado al conectar al servidor.
-h servidor[:puerto]
Selecciona un servidor alternativo. Nota: Esta opción debe aparecer antes que todas las demás.
-l
Muestra un listado "largo" de dispositivos o controladores.
--device-id cadena-id-dispositivo
Especifica el ID de dispositivo IEEE-1284 a coincidir al listar controladores con la opción -m.
--exclude-schemes lista-esquemas
Especifica una lista separada por comas de esquemas de PPD o de dispositivo que deben excluirse de los resultados. Los archivos PPD estáticos utilizan el esquema "file".
--include-schemes lista-esquemas
Especifica una lista separada por comas de esquemas de PPD o de dispositivo que deben incluirse en los resultados. Los archivos PPD estáticos utilizan el esquema "file".
--language localidad
Especifica el idioma a coincidir al listar controladores con la opción -m.
--make-and-model nombre
Especifica la marca y el modelo a coincidir al listar controladores con la opción -m.
--product nombre
Especifica el producto a coincidir al listar controladores con la opción -m.
--timeout segundos
Especifica el tiempo de espera al listar dispositivos con la opción -v.

CONFORMANDO A

El comando lpinfo es exclusivo de CUPS.

EJEMPLOS

Listar todos los dispositivos:

    lpinfo -v

Listar todos los controladores:

    lpinfo -m

Listar controladores que coincidan con "HP LaserJet":

    lpinfo --make-and-model "HP LaserJet" -m

NOTAS

Los controladores y backends de impresoras CUPS están obsoletos y ya no serán compatibles en una futura versión de características de CUPS. Las impresoras que no soporten IPP pueden ser compatibles utilizando aplicaciones como ippeveprinter(1).
