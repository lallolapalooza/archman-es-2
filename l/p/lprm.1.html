NOMBRE

lprm - cancelar trabajos de impresión

SINOPSIS

lprm [ -h nombre-host[:puerto] ] [ -E ] [ -U nombre-usuario ] [ -P destino[/instancia] ] [ - ] [ id-trabajo(s) ]

DESCRIPCIÓN

lprm cancela trabajos de impresión que se han puesto en cola para imprimir. Si no se proporcionan argumentos, se cancela el trabajo actual en el destino predeterminado. Puede especificar uno o más números de identificación de trabajo para cancelar esos trabajos o usar la opción - para cancelar todos los trabajos.

OPCIONES

El comando lprm soporta las siguientes opciones:

-E
Fuerza el cifrado al conectarse al servidor.
-P destino[/instancia]
Especifica la impresora o clase de destino.
-U nombre-usuario
Especifica un nombre de usuario alternativo.
-h servidor[:puerto]
Especifica un servidor alternativo. Nota: Esta opción debe aparecer antes que todas las demás.

CONFORME A

La versión de lprm de CUPS es compatible con el comando estándar de Berkeley del mismo nombre.

EJEMPLOS

Cancelar el trabajo actual en la impresora predeterminada:

    lprm

Cancelar el trabajo 1234:

    lprm 1234

Cancelar todos los trabajos:

    lprm -
