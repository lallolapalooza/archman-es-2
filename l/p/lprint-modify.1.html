NOMBRE

lprint-modify - modifica una cola de impresión.

SINOPSIS

lprint modify -d IMPRESORA [ -o OPCION=VALOR ]
lprint modify -u IMPRESORA-URI [ -o OPCION=VALOR ]

DESCRIPCIÓN

Este comando modifica una cola de impresión de etiquetas existente.

OPCIONES

Las siguientes opciones son reconocidas por lprint modify:

-d NOMBRE-IMPRESORA
Especifica el nombre de la cola de impresión.
-o OPCION=VALOR
Especifica el valor predeterminado para el nombre de opción dado. Consulte lprint-submit(1) para obtener una lista de opciones compatibles.
-o label-mode-configured=VALOR
Especifica el modo de impresión de etiquetas: "applicator", "cutter", "cutter-delayed", "kiosk", "peel-off", "peel-off-prepeel", "rewind", "rfid", o "tear-off".
-o label-tear-offset-configured=NNNpul
-o label-tear-offset-configured=NNNmm
Especifica el desplazamiento de desgarro de la etiqueta en pulgadas ("NNNpul") o milímetros ("NNNmm").
-o printer-darkness=NNN
Especifica la configuración de oscuridad base para todos los trabajos de impresión como un porcentaje. 0 representa la impresión más clara mientras que 100 representa la impresión más oscura .
-o printer-geo-location=geo:=LATLON
Especifica la ubicación geográfica de la impresora como una URI "geo:".
-o printer-location=UBICACIÓN
Especifica la ubicación legible por humanos, por ejemplo, "Rack 42".
-o printer-organization=ORGANIZACIÓN
Especifica el nombre de la organización, por ejemplo, "Acme, Inc.".
-o printer-organizational-unit=UNIDAD
Especifica la unidad organizacional, por ejemplo, "Departamento de Envíos".
-u URI-IMPRESORA
Especifica una URI "ipp:" o "ipps:" para una impresora remota.
