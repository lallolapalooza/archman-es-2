NOMBRE

lprint-options - obtener las opciones admitidas para una cola de impresión.

SINOPSIS

lprint options [ -d IMPRESORA ] [ -u URI-IMPRESORA ]

DESCRIPCIÓN

Este comando obtiene las opciones admitidas para una cola de impresión.

OPCIONES

Las siguientes opciones son reconocidas por lprint default:

-d IMPRESORA
Especifica la nueva impresora predeterminada.
-u URI-IMPRESORA
Especifica una URI «ipp:» o «ipps:» para una impresora remota.

VER TAMBIÉN

lprint(1), lprint-add(1), lprint-modify(1), lprint-printers(1), lprint-submit(1).
