lp(4) Manual de controladores de dispositivos lp(4)

NOMBRE

lp - dispositivos de impresora de línea

SINOPSIS

#include <linux/lp.h>

CONFIGURACIÓN

lp[0–2] son dispositivos de caracteres para impresoras de línea paralelas; tienen el número mayor 6 y los números menores 0–2. Los números menores corresponden a las direcciones base de los puertos de impresora 0x03bc, 0x0378 y 0x0278. Usualmente tienen modo 220 y son propiedad del usuario root y el grupo lp. Puede usar los puertos de impresora con sondeo o con interrupciones. Se recomiendan las interrupciones cuando se espera un alto tráfico, por ejemplo, para impresoras láser. Para impresoras matriciales típicas, el sondeo suele ser suficiente. El valor predeterminado es sondeo.

DESCRIPCIÓN

Las siguientes llamadas ioctl(2) son compatibles:

int ioctl(int fd, LPTIME, int arg)
Establece el tiempo que el controlador espera antes de volver a comprobar la impresora cuando el búfer de la impresora parece estar lleno a arg. Si tiene una impresora rápida, disminuya este número; si tiene una impresora lenta, auméntelo. Está en centésimas de segundo, el valor predeterminado 2 es 0.02 segundos. Solo influye en el controlador de sondeo.
int ioctl(int fd, LPCHAR, int arg)
Establece el número máximo de iteraciones de espera activa que realiza el controlador de sondeo mientras espera que la impresora esté lista para recibir un carácter a arg. Si la impresión es demasiado lenta, aumente este número; si el sistema se vuelve demasiado lento, disminuya este número. El valor predeterminado es 1000. Solo influye en el controlador de sondeo.
int ioctl(int fd, LPABORT, int arg)
Si arg es 0, el controlador de la impresora reintentará en caso de errores, de lo contrario abortará. El valor predeterminado es 0.
int ioctl(int fd, LPABORTOPEN, int arg)
Si arg es 0, open(2) se abortará en caso de error, de lo contrario el error se ignorará. El valor predeterminado es ignorarlo.
int ioctl(int fd, LPCAREFUL, int arg)
Si arg es 0, entonces las señales de falta de papel, fuera de línea y error deben ser falsas en todas las escrituras; de lo contrario, se ignoran. El valor predeterminado es ignorarlas.
int ioctl(int fd, LPWAIT, int arg)
Establece el número de iteraciones de espera activa para esperar antes de dar el pulso a la impresora para que acepte un carácter recién escrito, y el número de iteraciones para esperar antes de desactivar el pulso de nuevo, a arg. La especificación dice que este tiempo debe ser de 0.5 microsegundos, pero la experiencia ha demostrado que el retardo causado por el código ya es suficiente. Por esta razón, el valor predeterminado es 0. Esto se utiliza tanto para el controlador de sondeo como para el de interrupciones.
int ioctl(int fd, LPSETIRQ, int arg)
Esta ioctl(2) requiere privilegios de superusuario. Toma un int que contiene la nueva IRQ como argumento. Como efecto secundario, la impresora se reiniciará. Cuando arg es 0, se utilizará el controlador de sondeo, que es también el valor predeterminado.
int ioctl(int fd, LPGETIRQ, int *arg)
Almacena la IRQ utilizada actualmente en arg.
int ioctl(int fd, LPGETSTATUS, int *arg)
Almacena el valor del puerto de estado en arg. Los bits tienen el siguiente significado:
LP_PBUSY entrada ocupada invertida, activa alta
LP_PACK entrada de acuse de recibo sin cambios, activa baja
LP_POUTPA entrada sin papel sin cambios, activa alta
LP_PSELECD entrada seleccionada sin cambios, activa alta
LP_PERRORP entrada de error sin cambios, activa baja
Consulte el manual de su impresora para conocer el significado de las señales. Tenga en cuenta que también pueden estar activados bits no documentados, dependiendo de su impresora.
int ioctl(int fd, LPRESET)
Reinicia la impresora. No se utiliza ningún argumento.

ARCHIVOS

/dev/lp*

VER TAMBIÉN
