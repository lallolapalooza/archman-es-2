NOMBRE

lpoptions - mostrar o establecer opciones eY por defecto de la impresora

SINOPSIS

lpoptions [ -h servidor[:puerto] ] [ -E ] -d destino[/instancia] [ -l ]
lpoptions [ -h servidor[:puerto] ] [ -E ] [ -p destino[/instancia] ] -o opción[=valor] ...
lpoptions [ -h servidor[:puerto] ] [ -E ] [ -p destino[/instancia] ] -r opción
lpoptions [ -h servidor[:puerto] ] [ -E ] -x destino[/instancia]

DESCRIPCIÓN

lpoptions muestra o establece opciones eY por defecto de la impresora. Si no se especifica ninguna impresora usando la opción -p, se usa la impresora por defecto, tal como se describe en lp(1).

Si no se especifican las opciones -l, -o, o -r, las opciones actuales se informan en la salida estándar.

Las opciones establecidas con el comando lpoptions son usadas por los comandos lp(1) y lpr(1) al enviar trabajos.

Cuando lo ejecuta el usuario root, lpoptions obtiene y establece las opciones eY por defecto e instancias para todos los usuarios en el archivo /etc/cups/lpoptions. De lo contrario, los valores por defecto por usuario se gestionan en el archivo ~/.cups/lpoptions.

OPCIONES

lpoptions soporta las siguientes opciones:

-E
Habilita el cifrado al comunicarse con el servidor CUPS.
-d destino[/instancia]
Establece la impresora por defecto del usuario a destino. Si se suministra instancia, entonces se usa esa instancia particular. Esta opción anula la impresora por defecto del sistema para el usuario actual.
-h servidor[:puerto]
Usa un servidor alternativo. Nota: Esta opción debe ocurrir antes que todas las demás.
-l
Lista las opciones específicas de la impresora y su configuración actual.
-o opción[=valor]
Especifica una nueva opción para el destino nombrado.
-p destino[/instancia]
Establece el destino y la instancia, si se especifican, para las opciones que siguen. Si la instancia nombrada no existe, se crea. Los destinos solo pueden crearse usando el programa lpadmin(8).
-r opción
Elimina la opción especificada del destino nombrado.
-x destino[/instancia]
Elimina las opciones para el destino e instancia nombrados, si se especifican. Si la instancia nombrada no existe, esto no hace nada. Los destinos solo pueden eliminarse usando el comando lpadmin(8).

ARCHIVOS

~/.cups/lpoptions - opciones eY por defecto e instancias creadas por usuarios no-root.
/etc/cups/lpoptions - opciones eY por defecto e instancias a nivel de sistema creadas por el usuario root.

CONFORME A

El comando lpoptions es exclusivo de CUPS.

VER TAMBIÉN
