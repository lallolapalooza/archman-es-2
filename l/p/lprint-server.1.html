NOMBRE

lprint-server - iniciar un servidor de impresión de etiquetas.

SINOPSIS

lprint server [ -o OPCIÓN=VALOR ]

DESCRIPCIÓN

Este comando inicia un servidor de impresión de etiquetas. Normalmente, un servidor se inicia automáticamente según sea necesario, sin embargo, puede ejecutar el servidor manualmente para escuchar en una dirección de red pública y/o habilitar diferentes opciones de registro.

OPCIONES

Las siguientes opciones son reconocidas por lprint server:

-o admin-group=GRUPO
Especifica que la configuración remota se autentica contra el grupo con nombre. Si no se especifica o se proporciona el valor "none", cualquier usuario autenticado podrá configurar lprint remotamente.
-o auth-service=SERVICIO
Especifica el servicio PAM a utilizar para autenticar las solicitudes de configuración remota. Si no se especifica o se proporciona el valor "none", solo se podrán agregar, modificar o eliminar impresoras localmente.
-o listen-hostname=NOMBRE_HOST
Escucha las conexiones IPP en el nombre de host/dirección(es) especificados. Si no se especifica, utiliza las direcciones comodín para permitir conexiones desde cualquier dirección.
-o log-file=-
Especifica que todos los mensajes se escriban en la salida de error estándar.
-o log-file=syslog
Especifica que todos los mensajes se envíen al servicio syslog.
-o log-file=NOMBRE_ARCHIVO
Especifica que todos los mensajes se escriban en el archivo nombrado. Si el archivo ya existe, se agregarán mensajes al final. El archivo de registro predeterminado es ""$TMPDIR/lprintUID.log"" .
-o log-level=error
Especifica que solo se deben registrar los mensajes de error. Esta es la opción predeterminada.
-o log-level=info
Especifica que se deben registrar los mensajes de error e informativos.
-o log-level=debug
Especifica que se deben registrar todos los mensajes.
-o server-hostname=NOMBRE_HOST
Especifica el nombre de host que se anunciará para el servidor. El valor predeterminado es el nombre de host del sistema.
-o server-options=OPCIONES
Especifica una lista de opciones del servidor separadas por comas. Consulte "OPCIONES DEL SERVIDOR" a continuación.
-o server-port=PUERTO
Escucha las conexiones IPP en el puerto especificado. Si no se especifica, se elige un puerto aleatorio entre 9000 y 9999.
-o spool-directory=DIRECTORIO
Especifica un directorio que contiene los archivos de impresión pendientes. Si no se especifica, se utiliza un subdirectorio en el directorio temporal del sistema.

OPCIONES DEL SERVIDOR

Por defecto, lprint server utiliza las opciones "multi-queue" y "web-interface". La opción -o server-options=OPCIONES se puede utilizar para anular las opciones predeterminadas, donde "OPCIONES" es una lista separada por comas de cualquiera de las siguientes:

dnssd-host
Al resolver conflictos, agrega el nombre de host DNS-SD en lugar de un número de serie o UUID.
no-multi-queue
No admite múltiples colas de impresión.
raw-socket
Proporciona un socket en bruto ("JetDirect") para cada impresora en el puerto 91xx.
usb-printer
Habilita un dispositivo de impresora USB para la impresora predeterminada (solo Linux para Raspberry Pi y SBC similares integrados).
no-web-interface
Deshabilita la interfaz web.
web-log
Habilita la página web del archivo de registro.
web-network
Habilita la página web de configuración de red.
web-remote
Habilita la gestión remota de colas.
web-security
Habilita la página web de configuración de usuario/contraseña.
web-tls
Habilita la página web de configuración TLS.
no-tls
Deshabilita el soporte TLS.
