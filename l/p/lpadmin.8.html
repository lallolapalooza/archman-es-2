NOMBRE

lpadmin - configurar impresoras y clases de cups

SINOPSIS

lpadmin [ -E ] [ -U nombredeusuario ] [ -h servidor[:puerto] ] -d destino
lpadmin [ -E ] [ -U nombredeusuario ] [ -h servidor[:puerto] ] -p destino [ -R nombre-predeterminado ] opción(es)
lpadmin [ -E ] [ -U nombredeusuario ] [ -h servidor[:puerto] ] -x destino

DESCRIPCIÓN

lpadmin configura colas de impresión y clases proporcionadas por CUPS. También puede usarse para establecer la impresora o clase predeterminada del servidor.

Cuando se especifica antes de las opciones -d, -p o -x, la opción -E fuerza la encriptación al conectarse al servidor.

La primera forma del comando (-d) establece la impresora o clase predeterminada a destino. Los trabajos de impresión posteriores enviados a través de los comandos lp(1) o lpr(1) usarán este destino a menos que el usuario especifique lo contrario con el comando lpoptions(1).

La segunda forma del comando (-p) configura la impresora o clase con nombre. Las opciones adicionales se describen a continuación.

La tercera forma del comando (-x) elimina la impresora o clase destino. Cualquier trabajo pendiente para el destino será eliminado y cualquier trabajo que se esté imprimiendo será abortado.

OPCIONES

Se reconocen las siguientes opciones al configurar una cola de impresión:

-c clase
Añade la impresora con nombre a la clase. Si la clase no existe, se crea automáticamente.
-m modelo
Establece un archivo PPD estándar para la impresora desde el directorio modelo o usando una de las interfaces de controlador. Utilice la opción -m con el comando lpinfo(8) para obtener una lista de modelos soportados. El modelo "raw" elimina cualquier archivo PPD existente y el modelo "everywhere" consulta la impresora referenciada por el device-uri IPP especificado. Nota: Los modelos distintos de "everywhere" están obsoletos y no serán soportados en una futura versión de CUPS.
-o cupsIPPSupplies=true
-o cupsIPPSupplies=false
Especifica si se deben reportar los valores de nivel de suministro IPP.
-o cupsSNMPSupplies=true
-o cupsSNMPSupplies=false
Especifica si se deben reportar los valores de nivel de suministro SNMP (RFC 3805).
-o job-k-limit=valor
Establece el límite de kilobytes para cuotas por usuario. El valor es un número entero de kilobytes; un kilobyte son 1024 bytes.
-o job-page-limit=valor
Establece el límite de páginas para cuotas por usuario. El valor es el número entero de páginas que se pueden imprimir; las páginas a doble cara se cuentan como dos páginas.
-o job-quota-period=valor
Establece el período de contabilidad para cuotas por usuario. El valor es un número entero de segundos; 86.400 segundos hay en un día.
-o job-sheets-default=banner
-o job-sheets-default=banner,banner
Establece la página(s) de banner predeterminada(s) a usar para los trabajos de impresión.
-o nombre=valor
Establece una opción PPD para la impresora. Las opciones PPD se pueden listar usando la opción -l con el comando lpoptions(1).
-o nombre-default=valor
Establece una opción predeterminada en el lado del servidor para el destino. Cualquier opción en tiempo de impresión puede ser establecida como predeterminada, por ejemplo, "-o number-up-default=2" para establecer el valor de la opción "number-up" a 2.
-o port-monitor=nombre
Establece el programa de comunicación binaria a usar al imprimir, "none", "bcp" o "tbcp". El programa predeterminado es "none". El monitor de puerto especificado debe estar listado en el archivo PPD de la impresora.
-o printer-error-policy=nombre
Establece la política para errores como impresoras que no se pueden encontrar o acceder, no soportan el formato que se está imprimiendo, fallan durante el envío de los datos de impresión, o causan que uno o más filtros fallen. El nombre debe ser uno de "abort-job" (abortar el trabajo en caso de error), "retry-job" (reintentar el trabajo en un momento futuro), "retry-current-job" (reintentar el trabajo actual inmediatamente), o "stop-printer" (detener la impresora en caso de error). La política de error predeterminada es "stop-printer" para impresoras y "retry-current-job" para clases.
-o printer-is-shared=true
-o printer-is-shared=false
Establece el destino a compartido/publicado o no compartido/no publicado. Los destinos compartidos/publicados son anunciados públicamente por el servidor en la LAN basándose en la configuración de navegación en cupsd.conf, mientras que los destinos no compartidos/no publicados no son anunciados. El valor predeterminado es "true".
-o printer-op-policy=nombre
Establece la política de operaciones IPP asociada con el destino. El nombre debe estar definido en cupsd.conf en una sección Policy. La política de operaciones predeterminada es "default".
-R nombre-predeterminado
Elimina la opción con nombre de la impresora.
-r clase
Elimina la impresora con nombre de la clase. Si la clase resultante queda vacía, se elimina.
-u allow:{usuario|@grupo}{,usuario|,@grupo}*
-u deny:{usuario|@grupo}{,usuario|,@grupo}*
-u allow:all
-u deny:none
Establece el control de acceso a nivel de usuario en un destino. Los nombres que comienzan con "@" se interpretan como grupos de UNIX. Las dos últimas formas desactivan el control de acceso a nivel de usuario. Nota: El usuario 'root' no tiene acceso especial; usar "-u allow:foo,bar" permitirá a los usuarios 'foo' y 'bar' acceder a la impresora pero NO a 'root'.
-v "device-uri"
Establece el atributo device-uri de la cola de la impresora. Use la opción -v con el comando lpinfo(8) para obtener una lista de URI y esquemas de dispositivos soportados.
-D "info"
Proporciona una descripción textual del destino.
-E
Cuando se especifica antes de las opciones -d, -p o -x, fuerza el uso de encriptación TLS en la conexión al planificador. De lo contrario, habilita el destino y acepta trabajos; esto es lo mismo que ejecutar los programas cupsaccept(8) y cupsenable(8) en el destino.
-L "ubicación"
Proporciona una ubicación textual del destino.

lpadmin(8) — CUPS

NOMBRE

lpadmin — configurar colas de impresión CUPS

SINOPSIS

lpadmin [ -U nombredeusuario ] [ -h servidor[:puerto] ] [ -v ] [ -X ] [ opciones ] impresora...

DESCRIPCIÓN

El comando lpadmin se utiliza para configurar el sistema de impresión CUPS.

Se puede utilizar para añadir, eliminar o modificar impresoras, clases, filtros, trabajos de respaldo, juegos de opciones y políticas de configuración.

Los cambios realizados con lpadmin se guardan en los archivos de configuración del sistema de impresión CUPS (normalmente en /etc/cups/).

La información sobre los cambios realizados con lpadmin se comunica al demonio del programador de CUPS (cupsd(8)) para que se apliquen de inmediato.

OPCIONES

-A autenticación
Especifica el esquema de autenticación para la impresora. Los valores comunes incluyen Básica, Resumen y OAuthUC.
-c
Crea una nueva clase de impresión.
-d impresora
Establece la impresora predeterminada.
-E
Acepta trabajos de impresión para la impresora o clase especificada.
-F archivo
Especifica el archivo de configuración de la interfaz. Nota: los scripts de interfaz no son compatibles con CUPS. Los archivos PPD y los controladores de impresora están obsoletos y no se admitirán en una futura versión de CUPS.
-i archivo
Establece el archivo de configuración de la interfaz.
-m modelo
Especifica el modelo de controlador de impresora. Use lpinfo -m para listar los modelos disponibles.
-M
Elimina una impresora o clase.
-O atributo[=valor]
Establece un atributo de configuración de impresora.
-p impresora
Especifica el nombre de la impresora o clase.
-R lista de trabajos
Reimprime los trabajos de la lista especificada.
-S dispositivo-uri
Especifica el URI del dispositivo para la impresora. Por ejemplo, usb://Brother/HL-L2350DW?serial=12345 o socket://192.168.1.100:9100.
-U nombredeusuario
Especifica el nombre de usuario para conectarse al servidor CUPS.
-v dispositivo-uri
Especifica el URI del dispositivo para la impresora. Por ejemplo, usb://Brother/HL-L2350DW?serial=12345 o socket://192.168.1.100:9100.
-x
Elimina la impresora o clase especificada.

OPCIONES OBSOLETAS

-P archivo-ppd
Especifica un archivo de Descripción de Impresora PostScript (PPD) a utilizar con la impresora. Nota: Los archivos PPD y los controladores de impresora están obsoletos y no se admitirán en una futura versión de CUPS.

CONFORMANDO A

A diferencia del sistema de impresión System V, CUPS permite que los nombres de las impresoras contengan cualquier carácter imprimible excepto ESPACIO, TAB, "/" o "#". Además, los nombres de impresoras y clases no distinguen entre mayúsculas y minúsculas.

Finalmente, la versión CUPS de lpadmin puede solicitar al usuario una contraseña de acceso dependiendo de la configuración del sistema de impresión. Esto difiere de la versión System V que requiere que el usuario root ejecute este comando.

NOTAS

Los controladores e interfaces de impresora CUPS están obsoletos y ya no serán compatibles en una futura versión de CUPS. Las impresoras que no admiten IPP se pueden admitir utilizando aplicaciones como ippeveprinter(1).

La versión CUPS de lpadmin no admite todas las opciones de configuración del sistema de impresión System V o Solaris.

Los scripts de interfaz no se admiten por motivos de seguridad.

El doble significado de la opción -E es una desafortunada rareza histórica.

El comando lpadmin se comunica con el programador (cupsd(8)) para realizar cambios en la configuración del sistema de impresión. Esta información de configuración se almacena en varios archivos, incluidos printers.conf y classes.conf. Estos archivos no deben editarse directamente y son un detalle de implementación de CUPS que puede cambiar en cualquier momento.

EJEMPLO

Crea una cola de impresión IPP Everywhere:

    lpadmin -p miimpresora -E -v ipp://miimpresora.local/ipp/print -m everywhere
