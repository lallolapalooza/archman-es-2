NOMBRE

lprint-submit - enviar un archivo para imprimir.

SINOPSIS

lprint [ submit ] [ -d IMPRESORA ] [ -u URI-DE-IMPRESORA ] [ -n COPIAS ] [ -o OPCIÓN=VALOR ] [ -t TÍTULO ] [ ARCHIVO [ ... ARCHIVO ] ]
lprint [ submit ] [ -d IMPRESORA ] [ -u URI-DE-IMPRESORA ] [ -n COPIAS ] [ -o OPCIÓN=VALOR ] [ -t TÍTULO ] -

DESCRIPCIÓN

Este comando envía uno o más archivos para imprimir. La primera forma imprime los archivos nombrados. La segunda forma copia el archivo de impresión desde la entrada estándar.

OPCIONES

Las siguientes opciones son reconocidas por lprint submit:

-d IMPRESORA
Especifica el nombre de la cola de la impresora. Si no se especifica, se usa la impresora predeterminada.
-n COPIAS
Especifica el número de copias.
-o media=NOMBRE-DEL-TAMAÑO
Especifica el tamaño de la etiqueta.
-o media-source=NOMBRE-DEL-ROLLO
Especifica el rollo de etiquetas.
-o media-top-offset=NNNin
-o media-top-offset=NNNmm
Especifica la distancia para desplazar la impresión desde la parte superior de la etiqueta en pulgadas ("NNNin") o milímetros ("NNNmm").
-o media-tracking=continuous
-o media-tracking=mark
-o media-tracking=web
Especifica cómo se rastrean las etiquetas en el soporte portador: "continuous" para papel de recibo o etiquetas continuas, "mark" para etiquetas separadas por una marca visible en el soporte portador, o "web" para etiquetas separadas por un agujero en el soporte portador.
-o media-type=continuous
-o media-type=labels
Especifica el tipo de medio del rollo que se está utilizando: "continuous" para etiquetas continuas o papel de recibo, o "labels" para etiquetas cortadas en un soporte portador.
-o orientation-requested=portrait
Imprimir imágenes en orientación vertical.
-o orientation-requested=landscape
Imprimir imágenes en orientación horizontal (90 grados en sentido antihorario).
-o orientation-requested=reverse-portrait
Imprimir imágenes en orientación vertical inversa (al revés).
-o orientation-requested=reverse-landscape
Imprimir imágenes en orientación horizontal inversa (90 grados en sentido horario).
-o orientation-requested=none
Imprimir imágenes en orientación automática (vertical u horizontal).
-o print-color-mode=bi-level
Imprimir solo blanco o negro al imprimir imágenes.
-o print-color-mode=monochrome
Tonos de gris al imprimir imágenes. -o print-content-optimize=auto Optimiza la impresión automáticamente según el tipo y contenido del archivo. -o print-content-optimize=graphic Optimiza la impresión solo para gráficos. -o print-content-optimize=photo Optimiza la impresión para fotos. -o print-content-optimize=text Optimiza la impresión para texto. -o print-content-optimize=text-and-graphic Optimiza la impresión para texto y gráficos.
-o print-darkness=NNN
Especifica la oscuridad de impresión de -100 (más claro) a 100 (más oscuro).
-o print-quality=draft
Imprimir con calidad borrador.
-o print-quality=normal
Imprimir con calidad normal.
-o print-quality=high
Imprimir con calidad alta/mejor.
-o print-speed=NNNin
-o print-speed=NNNmm
Especifica la velocidad de impresión en pulgadas ("NNNin") o milímetros ("NNNmm") por segundo.
-o printer-resolution=NNNdpi
Especifica la resolución de impresión en puntos por pulgada.
-t TÍTULO
Especifica el nombre del trabajo de impresión.
-u URI-DE-IMPRESORA
Especifica una URI "ipp:" o "ipps:" para una impresora remota.
