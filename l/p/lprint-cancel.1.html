NOMBRE

lprint-cancel - cancelar uno o más trabajos de impresión.

SINOPSIS

lprint cancel [ -d IMPRESORA ] [ -u URI-IMPRESORA ] [ -j ID-TRABAJO ]
lprint cancel [ -d IMPRESORA ] [ -u URI-IMPRESORA ] -a

DESCRIPCIÓN

Este comando cancela uno o más trabajos de impresión. En la primera forma, se cancela el trabajo que se está imprimiendo actualmente o el trabajo especificado. En la segunda forma, se cancelan todos los trabajos de impresión.

OPCIONES

Las siguientes opciones son reconocidas por lprint cancel:

-a
Cancelar todos los trabajos de impresión.
-d IMPRESORA
Especifica el nombre de la cola de la impresora. Si no se especifica, se utiliza la impresora predeterminada.
-j ID-TRABAJO
Especifica el número del trabajo de impresión.
-u URI-IMPRESORA
Especifica una URI "ipp:" o "ipps:" para una impresora remota.

VER TAMBIÉN

lprint-default(1), lprint-jobs(1), lprint-submit(1).
