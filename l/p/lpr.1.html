NOMBRE

lpr - imprimir archivos

SINOPSIS

lpr [ -H servidor[:puerto] ] [ -E ] [ -U nombre-usuario ] [ -P destino[/instancia] ] [ -# num-copias [ -h ] [ -l ] [ -m ] [ -o opcion[=valor] ] [ -p ] [ -q ] [ -r ] [ -C título ] [ -J título ] [ -T título ] [ archivo(s) ]

DESCRIPCIÓN

lpr envía archivos para su impresión. Los archivos nombrados en la línea de comandos se envían a la impresora designada o al destino predeterminado si no se especifica ninguno. Si no se listan archivos en la línea de comandos, lpr lee el archivo de impresión de la entrada estándar.

EL DESTINO PREDETERMINADO

CUPS proporciona muchas maneras de configurar el destino predeterminado. Las variables de entorno LPDEST y PRINTER se consultan primero. Si ninguna de las dos está establecida, se utiliza la configuración predeterminada actual establecida con el comando lpoptions(1), seguida de la configuración predeterminada establecida con el comando lpadmin(8).

OPCIONES

lpr reconoce las siguientes opciones:

-E
Fuerza la encriptación al conectarse al servidor.
-H servidor[:puerto]
Especifica un servidor alternativo. Nota: Esta opción debe aparecer antes que todas las demás.
-C "nombre"
-J "nombre"
-T "nombre"
Establece el nombre/título del trabajo.
-P destino[/instancia]
Imprime los archivos en la impresora nombrada.
-U nombre-usuario
Especifica un nombre de usuario alternativo.
-# copias
Establece el número de copias a imprimir.
-h
Desactiva la impresión de encabezados. Esta opción es equivalente a -o job-sheets=none.
-l
Especifica que el archivo de impresión ya está formateado para el destino y debe enviarse sin filtrado. Esta opción es equivalente a -o raw.
-m
Envía un correo electrónico al finalizar el trabajo.
-o opción[=valor]
Establece una opción de trabajo. Ver "OPCIONES COMUNES DE TRABAJO" a continuación.
-p
Especifica que el archivo de impresión debe formatearse con un encabezado sombreado con la fecha, hora, nombre del trabajo y número de página. Esta opción es equivalente a -o prettyprint y solo es útil al imprimir archivos de texto.
-q
Retiene el trabajo para su impresión.
-r
Especifica que los archivos de impresión nombrados deben eliminarse después de enviarlos.

OPCIONES COMUNES DE TRABAJO

Además de las opciones específicas de la impresora reportadas por el comando lpoptions(1), las siguientes opciones genéricas están disponibles:

-o job-sheets=nombre
Imprime una página de portada (encabezado) con el documento. El "nombre" puede ser "classified", "confidential", "secret", "standard", "topsecret" o "unclassified".
-o media=tamaño
Establece el tamaño de la página a tamaño. La mayoría de las impresoras admiten al menos los nombres de tamaño "a4", "letter" y "legal".
-o number-up={2|4|6|9|16}
Imprime 2, 4, 6, 9 o 16 páginas del documento (entrada) en cada página de salida.
-o orientation-requested=4
Imprime el trabajo en formato horizontal (rotado 90 grados en sentido antihorario).
-o orientation-requested=5
Imprime el trabajo en formato horizontal (rotado 90 grados en sentido horario).
-o orientation-requested=6
Imprime el trabajo en retrato inverso (rotado 180 grados).
-o print-quality=3
-o print-quality=4
-o print-quality=5
Especifica la calidad de salida: borrador (3), normal (4) o mejor (5).
-o sides=one-sided
Imprime por una cara del papel.
-o sides=two-sided-long-edge
Imprime por ambas caras del papel para salida en formato retrato.
-o sides=two-sided-short-edge
Imprime por ambas caras del papel para salida en formato horizontal.

NOTAS

Las opciones -c, -d, -f, -g, -i, -n, -t, -v y -w no son compatibles con CUPS y generan un mensaje de advertencia si se utilizan.

EJEMPLOS

Imprimir dos copias de un documento en la impresora predeterminada:

    lpr -# 2 nombre-archivo

Imprimir un documento legal a doble cara en una impresora llamada "foo":

    lpr -P foo -o media=legal -o sides=two-sided-long-edge nombre-archivo

Imprimir un documento de presentación 2 en 1 en una impresora llamada "foo":

    lpr -P foo -o number-up=2 nombre-archivo
