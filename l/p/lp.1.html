NOMBRE

lp - imprimir archivos

SINOPSIS

lp [ -h nombre-servidor[:puerto] ] [ -E ] [ -U nombre-usuario ] [ -c ] [ -d destino[/instancia] ] [ -m ] [ -n num-copias ] [ -o opción[=valor] ] [ -q prioridad ] [ -s ] [ -t título ] [ -H manejo ] [ -P lista-páginas ] [ -- ] [ archivo(s) ]
lp [ -h nombre-servidor[:puerto] ] [ -E ] [ -U nombre-usuario ] [ -c ] [ -i id-trabajo ] [ -n num-copias ] [ -o opción[=valor] ] [ -q prioridad ] [ -t título ] [ -H manejo ] [ -P lista-páginas ]

DESCRIPCIÓN

lp envía archivos para imprimir o modifica un trabajo pendiente. Use un nombre de archivo de "-" para forzar la impresión desde la entrada estándar.

EL DESTINO PREDETERMINADO

CUPS proporciona muchas formas de establecer el destino predeterminado. Las variables de entorno LPDEST y PRINTER se consultan primero. Si ninguna está establecida, se utiliza el valor predeterminado actual establecido con el comando lpoptions(1), seguido del valor predeterminado establecido con el comando lpadmin(8).

OPCIONES

Las siguientes opciones son reconocidas por lp:

--
Marca el final de las opciones; úselo para imprimir un archivo cuyo nombre comience con un guion (-).
-E
Fuerza el cifrado al conectarse al servidor.
-U nombre-usuario
Especifica el nombre de usuario a utilizar al conectarse al servidor.
-c
Esta opción se proporciona solo por compatibilidad con versiones anteriores. En sistemas que la soportan, esta opción fuerza la copia del archivo de impresión al directorio de la cola antes de imprimir. En CUPS, los archivos de impresión siempre se envían al programador a través de IPP, lo que tiene el mismo efecto.
-d destino
Imprime archivos en la impresora con el nombre especificado.
-h nombre-servidor[:puerto]
Elige un servidor alternativo. Nota: Esta opción debe aparecer antes que todas las demás.
-i id-trabajo
Especifica un trabajo existente para modificar.
-m
Envía un correo electrónico cuando el trabajo se complete.
-n copias
Establece el número de copias a imprimir.
-o "nombre=valor [ ... nombre=valor ]"
Establece una o más opciones de trabajo. Ver "OPCIONES COMUNES DE TRABAJO" abajo.
-q prioridad
Establece la prioridad del trabajo de 1 (más baja) a 100 (más alta). La prioridad predeterminada es 50.
-s
No informar los IDs de trabajo resultantes (modo silencioso).
-t "nombre"
Establece el nombre del trabajo.
-H hh:mm
-H hold
-H immediate
-H restart
-H resume
Especifica cuándo se debe imprimir el trabajo. Un valor de immediate imprimirá el archivo inmediatamente, un valor de hold mantendrá el trabajo en espera indefinidamente, y un valor de tiempo UTC (HH:MM) mantendrá el trabajo en espera hasta la hora UTC especificada (no local). Use un valor de resume con la opción -i para reanudar un trabajo en espera. Use un valor de restart con la opción -i para reiniciar un trabajo completado.
-P lista-páginas
Especifica qué páginas imprimir en el documento. La lista puede contener una lista de números y rangos (#-#) separados por comas, por ejemplo, "1,3-5,16". Los números de página se refieren a las páginas de salida y no a las páginas originales del documento; opciones como "number-up" pueden afectar la numeración de las páginas.

OPCIONES COMUNES DE TRABAJO

Además de las opciones específicas de la impresora informadas por el comando lpoptions(1), las siguientes opciones genéricas están disponibles:

-o job-sheets=nombre
Imprime una página de portada (banner) con el documento. El "nombre" puede ser "classified", "confidential", "secret", "standard", "topsecret" o "unclassified".
-o media=tamaño
Establece el tamaño de página a tamaño. La mayoría de las impresoras soportan al menos los nombres de tamaño "a4", "letter" y "legal".
-o number-up={2|4|6|9|16}
Imprime 2, 4, 6, 9 o 16 páginas del documento (entrada) en cada página de salida.
-o orientation-requested=4
Imprime el trabajo en formato horizontal (rotado 90 grados en sentido antihorario).
-o orientation-requested=5
Imprime el trabajo en formato horizontal (rotado 90 grados en sentido horario).
-o orientation-requested=6
Imprime el trabajo en retrato inverso (rotado 180 grados).
-o print-as-raster
Imprime el trabajo como ráster.
-o print-quality=3
-o print-quality=4
-o print-quality=5
Especifica la calidad de salida: borrador (3), normal (4) o mejor (5).
-o sides=one-sided
Imprime por una cara del papel.
-o sides=two-sided-long-edge
Imprime por ambas caras del papel para salida en formato retrato.
-o sides=two-sided-short-edge
Imprime por ambas caras del papel para salida en formato horizontal.

CUMPLIMIENTO

A diferencia del sistema de impresión System V, CUPS permite que los nombres de impresora contengan cualquier carácter imprimible excepto ESPACIO, TAB, "/" o "#". Además, los nombres de impresora y clase *no* distinguen entre mayúsculas y minúsculas.

La opción -q acepta un rango de valores diferente al del comando lp de Solaris, coincidiendo con los valores de prioridad de trabajo IPP (1-100, 100 es la prioridad más alta) en lugar de los valores de Solaris (0-39, 0 es la prioridad más alta).

EJEMPLOS

Imprimir dos copias de un documento en la impresora predeterminada:

    lp -n 2 archivo

Imprimir un documento legal a doble cara en una impresora llamada "foo":

    lp -d foo -o media=legal -o sides=two-sided-long-edge archivo

Imprimir un documento de presentación a doble cara (2-up) en una impresora llamada "bar":

    lp -d bar -o number-up=2 archivo
