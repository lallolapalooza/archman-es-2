NOMBRE

lprint-add - añade una cola de impresión.

SINOPSIS

lprint add [ -u URI-SISTEMA ] -d IMPRESORA -m NOMBRE-CONTROLADOR -v URI-DISPOSITIVO [ -o OPCION=VALOR ]

DESCRIPCIÓN

Este comando crea una cola de impresión de etiquetas utilizando el nombre, controlador y controlador especificados.

OPCIONES

Las siguientes opciones son reconocidas por lprint add:

-d IMPRESORA
Especifica el nombre de la cola de impresión.
-m NOMBRE-CONTROLADOR
Especifica el nombre del controlador de la impresora. Consulte lprint-drivers(1) para el comando que lista los controladores de impresora disponibles.
-o OPCION=VALOR
Especifica el valor predeterminado para el nombre de opción dado. Consulte lprint-submit(1) para una lista de opciones soportadas.
-o label-mode-configured=VALOR
Especifica el modo de impresión de etiquetas: "applicator", "cutter", "cutter-delayed", "kiosk", "peel-off", "peel-off-prepeel", "rewind", "rfid", o "tear-off".
-o label-tear-offset-configured=NNNpul
-o label-tear-offset-configured=NNNmm
Especifica el desplazamiento de corte de etiqueta en pulgadas ("NNNpul") o milímetros ("NNNmm").
-o printer-darkness=NNN
Especifica la configuración de oscuridad base para todos los trabajos de impresión como un porcentaje. 0 representa la impresión más clara mientras que 100 representa la impresión más oscura.
-o printer-geo-location=geo:=LATLON
Especifica la ubicación geográfica de la impresora como una URI "geo:".
-o printer-location=UBICACIÓN
Especifica la ubicación legible por humanos, por ejemplo "Rack 42".
-o printer-organization=ORGANIZACIÓN
Especifica el nombre de la organización, por ejemplo "Acme, S.A.".
-o printer-organizational-unit=UNIDAD
Especifica la unidad organizacional, por ejemplo "Departamento de Envíos".
-u URI-SISTEMA
Especifica un servidor LPrint remoto a usar. La "URI-SISTEMA" tiene el formato "ipps://HOSTNAME:PUERTO/ipp/system".
-v URI-DISPOSITIVO
Especifica el dispositivo para la cola de impresión. El valor puede ser una URI de socket: como "socket://11.22.33.44" o una URI usb: como las listadas por el comando lprint-devices(1).
