NOMBRE

lprint-default - establece u obtiene la cola de impresión predeterminada.

SINOPSIS

lprint default [ -d IMPRESORA ] [ -u URI-IMPRESORA ]

DESCRIPCIÓN

Este comando obtiene o establece la cola de impresión predeterminada. Cuando se ejecuta sin opciones, la impresora predeterminada actual se escribe en la salida estándar. De lo contrario, se cambia la impresora predeterminada.

OPCIONES

Las siguientes opciones son reconocidas por lprint default:

-d IMPRESORA
Especifica la nueva cola de impresión predeterminada.
-u URI-IMPRESORA
Especifica una URI de "ipp:" o "ipps:" para una impresora remota.

VER TAMBIÉN

lprint(1), lprint-add(1), lprint-modify(1), lprint-printers(1).
