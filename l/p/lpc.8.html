NOMBRE

lpc - programa de control de impresoras de línea (obsoleto)

SINOPSIS

lpc [ comando [ parámetro(s) ] ]

DESCRIPCIÓN

lpc proporciona un control limitado sobre las colas de impresoras y clases proporcionadas por CUPS. También se puede utilizar para consultar el estado de las colas.

Si no se especifica ningún comando en la línea de comandos, lpc muestra un indicador y acepta comandos de la entrada estándar.

COMANDOS

El programa lpc acepta un subconjunto de comandos aceptados por el programa lpc de Berkeley del mismo nombre:

exit
Sale del intérprete de comandos.
help [comando]
? [comando]
Muestra un breve mensaje de ayuda.
quit
Sale del intérprete de comandos.
status [cola]
Muestra el estado de una o más colas de impresoras o clases.

NOTAS

Este programa está obsoleto y será eliminado en una futura versión característica de CUPS.

Dado que lpc está orientado al sistema de impresión Berkeley, es imposible utilizar lpc para configurar colas de impresoras o clases proporcionadas por CUPS. Para configurar colas de impresoras o clases, debes usar el comando lpadmin(8) u otro cliente compatible con CUPS con esa funcionalidad.
