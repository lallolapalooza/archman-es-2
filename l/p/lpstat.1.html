NOMBRE

lpstat - mostrar información de estado de cups

SINOPSIS

lpstat [ -h nombre_host[:puerto] ] [ -E ] [ -H ] [ -U nombre_usuario ] [ -l ] [ -W trabajos_a_mostrar ] [ -a [ destinos ] ] [ -c [ clases ] ] [ -d ] [ -e ] [ -o [ destinos ] ] [ -p [ impresoras ] ] [ -r ] [ -R ] [ -s ] [ -t ] [ -u [ usuarios ] ] [ -v [ impresoras ] ]

DESCRIPCIÓN

lpstat muestra información de estado sobre las clases, trabajos e impresoras actuales. Cuando se ejecuta sin argumentos, lpstat listará los trabajos activos en cola del usuario actual.

OPCIONES

El comando lpstat soporta las siguientes opciones:

-E
Fuerza el cifrado al conectarse al servidor.
-H
Muestra el nombre del host del servidor y el puerto.
-R
Muestra la clasificación de los trabajos de impresión.
-U nombre_usuario
Especifica un nombre de usuario alternativo.
-W trabajos_a_mostrar
Especifica qué trabajos mostrar: "all", "successful", "completed" o "not-completed" (el valor predeterminado). Esta opción debe aparecer antes de la opción -o y/o cualquier nombre de impresora, de lo contrario, se usará el valor predeterminado ("not-completed") en la solicitud al planificador.
-a [impresoras]
Muestra el estado de aceptación de las colas de impresión. Si no se especifican impresoras, se listan todas.
-c [clases]
Muestra las clases de impresoras y las impresoras que pertenecen a ellas. Si no se especifican clases, se listan todas.
-d
Muestra el destino predeterminado actual.
-e
Muestra todos los destinos disponibles en la red local.
-h servidor[:puerto]
Especifica un servidor alternativo. Nota: Esta opción debe aparecer antes que todas las demás.
-l
Muestra un listado largo de impresoras, clases o trabajos.
-o [destinos]
Muestra los trabajos en cola en los destinos especificados. Si no se especifican destinos, se muestran todos los trabajos.
-p [impresoras]
Muestra las impresoras y si están habilitadas para imprimir. Si no se especifican impresoras, se listan todas.
-r
Muestra si el servidor CUPS está en ejecución.
-s
Muestra un resumen del estado, incluyendo el destino predeterminado, una lista de clases y sus impresoras miembro, y una lista de impresoras y sus dispositivos asociados. Esto es equivalente a usar las opciones -d, -c y -v.
-t
Muestra toda la información de estado. Esto es equivalente a usar las opciones -r, -d, -c, -v, -a, -p y -o.
-u [usuarios]
Muestra una lista de trabajos de impresión en cola por los usuarios especificados. Si no se especifican usuarios, lista los trabajos en cola por el usuario actual.
-v [impresoras]
Muestra las impresoras y a qué dispositivo están conectadas. Si no se especifican impresoras, se listan todas.

CONFORMANDO A

A diferencia del sistema de impresión System V, CUPS permite que los nombres de las impresoras contengan cualquier carácter imprimible excepto ESPACIO, TAB, "/" y "#". Además, los nombres de las impresoras y clases no distinguen entre mayúsculas y minúsculas.

Las opciones -h, -e, -E, -U y -W son exclusivas de CUPS.

Las opciones -f, -P y -S de Solaris se ignoran silenciosamente.
