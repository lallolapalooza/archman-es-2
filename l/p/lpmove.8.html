NOMBRE

lpmove - mover un trabajo o todos los trabajos a un nuevo destino

SINOPSIS

lpmove [ -h servidor[:puerto] ] [ -E ] [ -U nombredeusuario ] trabajo destino
lpmove [ -h servidor[:puerto] ] [ -E ] [ -U nombredeusuario ] fuente destino

DESCRIPCIÓN

lpmove mueve el trabajo especificado o todos los trabajos desde fuente a destino. trabajo puede ser el número de ID del trabajo o el destino antiguo y el ID del trabajo.

OPCIONES

El comando lpmove soporta las siguientes opciones:

-E
Fuerza el cifrado al conectarse al servidor.
-U nombredeusuario
Especifica un nombre de usuario alternativo.
-h servidor[:puerto]
Especifica un servidor alternativo. Nota: Esta opción debe aparecer antes que todas las demás.

EJEMPLOS

Mover el trabajo 123 desde "impresoraantigua" a "impresoranueva":

    lpmove 123 impresora-nueva
            o
    lpmove impresora-antigua-123 impresora-nueva

Mover todos los trabajos desde "impresoraantigua" a "impresoranueva":

    lpmove impresora-antigua impresora-nueva
