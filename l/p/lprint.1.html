NOMBRE

lprint - una aplicación de impresora de etiquetas

SINOPSIS

lprint [ SUBCOMANDO ] [ OPCIONES ] [ ARCHIVOS ]

DESCRIPCIÓN

lprint es una aplicación de impresora de etiquetas que puede ejecutarse de forma independiente o como un servicio de red IPP Everywhere dedicado. lprint soporta la impresión de imágenes PNG, archivos ráster Apple/PWG y archivos de etiquetas específicos de la impresora en impresoras de etiquetas USB y de red. Si no se especifica ningún subcomando, se asume "submit".

SUBCOMANDOS

Los siguientes subcomandos son reconocidos por lprint:

add
Añadir una cola de impresión.
cancel
Cancelar uno o más trabajos de impresión.
default
Establecer la cola de impresión predeterminada.
delete
Eliminar una cola de impresión.
devices
Listar impresoras conectadas.
drivers
Listar los controladores soportados.
jobs
Listar trabajos de impresión pendientes.
modify
Modificar una cola de impresión.
options
Listar las opciones soportadas.
printers
Listar las colas de impresión.
server
Iniciar un servidor.
shutdown
Apagar un servidor en ejecución.
status
Mostrar el estado de una impresora o de todas las impresoras.
submit
Enviar un archivo para imprimir.
