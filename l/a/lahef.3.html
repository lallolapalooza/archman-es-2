CLAHEF calcula una factorización parcial de una matriz Hermítica indefinida compleja utilizando el método de pivoteo diagonal de Bunch-Kaufman (algoritmo bloqueado, llamando a BLAS de Nivel 3).

Propósito:

!>
!> CLAHEF calcula una factorización parcial de una matriz Hermítica compleja A
!> utilizando el método de pivoteo diagonal de Bunch-Kaufman. La
!> factorización parcial tiene la forma:
!>
!> A  =  ( I  U12 ) ( A11  0  ) (  I      0     )  si UPLO = 'U', o:
!>       ( 0  U22 ) (  0   D  ) ( U12**H U22**H )
!>
!> A  =  ( L11  0 ) (  D   0  ) ( L11**H L21**H )  si UPLO = 'L'
!>       ( L21  I ) (  0  A22 ) (  0      I     )
!>
!> donde el orden de D es como máximo NB. El orden real se devuelve en
!> el argumento KB, y es NB o NB-1, o N si N <= NB.
!> Nótese que U**H denota la transpuesta conjugada de U.
!>
!> CLAHEF es una subrutina auxiliar llamada por CHETRF. Utiliza código bloqueado
!> (llamando a BLAS de Nivel 3) para actualizar la submatriz A11 (si UPLO = 'U') o
!> A22 (si UPLO = 'L').
!>

Parámetros

UPLO 
!>          UPLO es CARACTER*1
!>          Especifica si la parte triangular superior o inferior de la
!>          matriz Hermítica A está almacenada:
!>          = 'U':  Triangular superior
!>          = 'L':  Triangular inferior
!>

N

!>          N es ENTERO
!>          El orden de la matriz A.  N >= 0.
!>

NB

!>          NB es ENTERO
!>          El número máximo de columnas de la matriz A que deben
!>          factorizarse.  NB debe ser al menos 2 para permitir bloques
!>          de pivote de 2x2.
!>

KB

!>          KB es ENTERO
!>          El número de columnas de A que fueron realmente factorizadas.
!>          KB es NB-1 o NB, o N si N <= NB.
!>

A

!>          A es una matriz COMPLEJA, de dimensión (LDA,N)
!>          En la entrada, la matriz Hermítica A.  Si UPLO = 'U', la parte
!>          triangular superior principal de n x n de A contiene la parte
!>          triangular superior de la matriz A, y la parte estrictamente
!>          triangular inferior de A no se referencia. Si UPLO = 'L', la
!>          parte triangular inferior principal de n x n de A contiene la parte
!>          triangular inferior de la matriz A, y la parte estrictamente
!>          triangular superior de A no se referencia.
!>          En la salida, A contiene detalles de la factorización parcial.
!>

LDA

!>          LDA es ENTERO
!>          La dimensión principal del array A.  LDA >= max(1,N).
!>

IPIV

!>          IPIV es un array ENTERO, de dimensión (N)
!>          Detalles de los intercambios y la estructura de bloques de D.
!>
!>          Si UPLO = 'U':
!>             Solo los últimos KB elementos de IPIV se establecen.
!>
!>             Si IPIV(k) > 0, entonces las filas y columnas k e IPIV(k) fueron
!>             intercambiadas y D(k,k) es un bloque diagonal de 1x1.
!>
!>             Si IPIV(k) = IPIV(k-1) < 0, entonces las filas y columnas
!>             k-1 e -IPIV(k) fueron intercambiadas y D(k-1:k,k-1:k)
!>             es un bloque diagonal de 2x2.
!>
!>          Si UPLO = 'L':
!>             Solo los primeros KB elementos de IPIV se establecen.
!>
!>             Si IPIV(k) > 0, entonces las filas y columnas k e IPIV(k) fueron
!>             intercambiadas y D(k,k) es un bloque diagonal de 1x1.
!>
!>             Si IPIV(k) = IPIV(k+1) < 0, entonces las filas y columnas
!>             k+1 e -IPIV(k) fueron intercambiadas y D(k:k+1,k:k+1)
!>             es un bloque diagonal de 2x2.
!>

W

!>          W es un array COMPLEJO, de dimensión (LDW,NB)
!>

LDW

!>          LDW es ENTERO
!>          La dimensión principal del array W.  LDW >= max(1,N).
!>

INFO

!>          INFO es ENTERO
!>          = 0: salida exitosa
!>          > 0: si INFO = k, D(k,k) es exactamente cero. La factorización
!>               se ha completado, pero la matriz diagonal por bloques D es
!>               exactamente singular.
!>

NAME

c, d, s lasyf - computes a partial factorization of a symmetric indefinite matrix

SYNOPSIS

SUBROUTINE CLASYF( UPLO, N, NB, KB, A, LDA, IPIV, W, LDW, INFO )
    CHARACTER(LEN=1) UPLO
    INTEGER          N, NB, KB, LDA, IPIV( * ), LDW, INFO
    COMPLEX(KIND=8)  A( LDA, * ), W( LDW, * )

SUBROUTINE DLASYF( UPLO, N, NB, KB, A, LDA, IPIV, W, LDW, INFO )
    CHARACTER(LEN=1) UPLO
    INTEGER          N, NB, KB, LDA, IPIV( * ), LDW, INFO
    DOUBLE PRECISION A( LDA, * ), W( LDW, * )

SUBROUTINE SLASYF( UPLO, N, NB, KB, A, LDA, IPIV, W, LDW, INFO )
    CHARACTER(LEN=1) UPLO
    INTEGER          N, NB, KB, LDA, IPIV( * ), LDW, INFO
    REAL             A( LDA, * ), W( LDW, * )

DESCRIPTION

The routines compute a partial factorization of a symmetric indefinite matrix A using the Bunch-Kaufman diagonal pivoting method. The factorization has the form:

if UPLO = 'U': 

 A = ( I  U12 ) ( A11  0  ) (  I       0    )
        ( 0  U22 ) (  0   D  ) ( U12**T U22**T )

if UPLO = 'L': 

 A = ( L11  0 ) (  D   0  ) ( L11**T L21**T )
        ( L21  I ) (  0  A22 ) (  0       I    )

where the order of D is at most NB. The actual order is returned in the argument KB, and is either NB or NB-1, or N if N <= NB.

These routines are auxiliary routines called by C, D, S SYTRF. They use blocked code (calling Level 3 BLAS) to update the submatrix A11 (if UPLO = 'U') or A22 (if UPLO = 'L').

PARAMETERS

UPLO

UPLO is CHARACTER*1. On entry, UPLO specifies whether the upper or lower triangular part of the symmetric matrix A is stored.

  • = 'U': Upper triangular
  • = 'L': Lower triangular
N

N is INTEGER. On entry, N is the order of the matrix A. N >= 0.

NB

NB is INTEGER. On entry, NB is the maximum number of columns of the matrix A that should be factored. NB should be at least 2 to allow for 2-by-2 pivot blocks.

KB

KB is INTEGER. On exit, KB is the number of columns of A that were actually factored. KB is either NB-1 or NB, or N if N <= NB.

A

A is array of type (C), (D), or (S). On entry, the symmetric matrix A. If UPLO = 'U', the leading N-by-N upper triangular part of A contains the upper triangular part of the matrix A, and the strictly lower triangular part of A is not referenced. If UPLO = 'L', the leading N-by-N lower triangular part of A contains the lower triangular part of the matrix A, and the strictly upper triangular part of A is not referenced. On exit, A contains details of the partial factorization.

LDA

LDA is INTEGER. On entry, LDA is the leading dimension of the array A. LDA >= max(1,N).

IPIV

IPIV is INTEGER array, dimension (*). Details of the interchanges and the block structure of D.

If UPLO = 'U': Only the last KB elements of IPIV are set.

  • If IPIV(k) > 0, then rows and columns k and IPIV(k) were interchanged and D(k,k) is a 1-by-1 diagonal block.
  • If IPIV(k) = IPIV(k-1) < 0, then rows and columns k-1 and -IPIV(k) were interchanged and D(k-1:k,k-1:k) is a 2-by-2 diagonal block.

If UPLO = 'L': Only the first KB elements of IPIV are set.

  • If IPIV(k) > 0, then rows and columns k and IPIV(k) were interchanged and D(k,k) is a 1-by-1 diagonal block.
  • If IPIV(k) = IPIV(k+1) < 0, then rows and columns k+1 and -IPIV(k) were interchanged and D(k:k+1,k:k+1) is a 2-by-2 diagonal block.
W

W is array of type (C), (D), or (S). On exit, W contains details of the partial factorization.

LDW

LDW is INTEGER. On entry, LDW is the leading dimension of the array W. LDW >= max(1,N).

INFO

INFO is INTEGER. On exit, INFO is:

  • = 0: successful exit
  • > 0: if INFO = k, D(k,k) is exactly zero. The factorization has been completed, but the block diagonal matrix D is exactly singular.

Propósito:

!>
!> ZLAHEF calcula una factorización parcial de una matriz Hermitiana
!> compleja A usando el método de pivoteo diagonal de Bunch-Kaufman. La
!> factorización parcial tiene la forma:
!>

!>       ( 0  U22 ) (  0   D  ) ( U12**H U22**H )

NAME


ZLASYF -  ZLASYF computes a factorization of a general rectangular matrix A.






SYNOPSIS


 SUBROUTINE ZLASYF( UPLO, N, KB, A, LDA, IPIV, C, LDC, INFO )

     CHARACTER * 1      UPLO
     INTEGER            KB
     INTEGER            LDA
     INTEGER            LDC
     INTEGER            N
     COMPLEX*16         A( LDA, * )
     COMPLEX*16         C( LDC, * )
     INTEGER            IPIV( * )
     INTEGER            INFO







Detailed Description


ZLASYF computes the factorization of a general rectangular matrix A
    in the form:


    A = P * U * D * U**H * P**H   if UPLO = 'U',



or


    A = P * L * D * L**H * P**H   if UPLO = 'L',



where P is a permutation matrix, U is an upper triangular
    trapezoidal matrix with unit diagonal, L is a lower triangular
    trapezoidal matrix with unit diagonal, and D is a block diagonal
    matrix with.


    Entries of D are 1-by-1 or 2-by-2 diagonal matrices.



The       factorization is computed by the Blocked Bunch-Kaufman
    partitioning method. This method is described in chapter 10 of the
    LAPACK Users' Guide.


Arguments




UPLO


CHARACTER*1.

Specifies whether the matrix A is upper or lower trapezoidal.
      = 'U': Upper trapezoidal


= 'L': Lower trapezoidal.




N


INTEGER.


The order of the matrix A. N >= 0.


KB


INTEGER.


The minimum number of columns/rows of A that must be factorized.
      1 <= KB <= N.


A


COMPLEX*16 array, dimension (LDA, K)


On entry, the M-by-N matrix A.


On exit, the previous values of A are overwritten by information
      from the factorization.


LDA


INTEGER.


The leading dimension of the array A. LDA >= max(1,N).


IPIV


INTEGER array, dimension (N)


Details of the interchanges and the block structure of D.

If UPLO = 'U': Only the last KB elements of IPIV are set.

If IPIV(k) > 0, then rows and columns k and IPIV(k) were
      interchanged and D(k,k) is a 1-by-1 diagonal block.


If IPIV(k) = IPIV(k-1) < 0, then rows and columns
      k-1 and -IPIV(k) were interchanged and D(k-1:k,k-1:k)
      is a 2-by-2 diagonal block.




If UPLO = 'L': Only the first KB elements of IPIV are set.

If IPIV(k) > 0, then rows and columns k and IPIV(k) were
      interchanged and D(k,k) is a 1-by-1 diagonal block.


If IPIV(k) = IPIV(k+1) < 0, then rows and columns
      k+1 and -IPIV(k) were interchanged and D(k:k+1,k:k+1)
      is a 2-by-2 diagonal block.




C


COMPLEX*16 array, dimension (LDC,NB)


LDC


INTEGER.


The leading dimension of the array C. LDW >= max(1,N).


INFO


INTEGER.




= 0: successful exit


> 0: if INFO = k, D(k,k) is exactly zero. The factorization
      has been completed, but the block diagonal matrix D is
      exactly singular.
