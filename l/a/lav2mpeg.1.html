lav2mpeg(1) manual de MJPEG tools lav2mpeg(1)

NOMBRE

lav2mpeg - conversión fácil de archivos lav a mpeg

SINOPSIS

lav2mpeg [ opciones ] archivo_lav1 [archivo_lav2 ... archivo_lavN]

DESCRIPCIÓN

lav2mpeg es un script de shell para facilitar el uso de las utilidades de mjpeg, proporcionando una forma conveniente de convertir de archivos MJPEG a formatos de archivo MPEG populares. Soporta salida en VCD, VCD de tasa media y alta, SVCD, SVCD de tasa alta, y mpeg1 y mpeg2 genéricos.

Los archivos de entrada pueden ser cualquier combinación de archivos AVI (.avi), Quicktime (.qt) o editlist, siempre que sean legibles por lavtools (por ejemplo, AVI/Quicktime codificado en MJPEG o AVI DV tipo 2).

OPCIONES

-s/S
Desactivar/activar estéreo (predeterminado: automático)
-k/K
Desactivar/activar la conservación de archivos crudos (predeterminado: desactivado)
-f/F
Desactivar/activar el uso de fifos (predeterminado: desactivado)
-l/L
Desactivar/activar el registro de todo el proceso (predeterminado: desactivado)
-n/N
Desactivar/activar el "registro ruidoso" (predeterminado: desactivado)
-y/Y
Desactivar/activar el uso de yuvdenoise (predeterminado: desactivado)
-m
uno de los MODOS (ver abajo) (predeterminado: vcd)
-e
calidad de codificación: 0, 1 o 2 (predeterminado: 2)
-o
archivo de salida (el valor predeterminado es el nombre del primer archivo de entrada .mpg)
-b
tasa de bits de video en kbps (solo se usa cuando -o es "mpeg1" o "mpeg2")
-a
tasa de bits de audio en kbps (solo se usa cuando -o no es "vcd*")
-q
calidad para mpeg2enc (solo se usa cuando -o es "mpeg1" o "mpeg2")
-d
dimensiones XxY (solo se usa cuando -o es "mpeg1" o "mpeg2") el valor predeterminado es el mismo que la entrada

MODOS

vcd -- VCD estándar (352x240 o 352x288)

vcd_medium -- VCD con video de 1550kbps (352x240 o 352x288)

vcd_high -- VCD con video de 1800kbps (352x240 o 352x288)

svcd -- SVCD estándar (480x480 o 480x576)

svcd_high -- 3000kbps(máx) vbr @qual=5 (480x480 o 480x576)

mpeg1 -- respeta las flags -a -b -q -d, resolución predeterminada igual que la entrada

mpeg2 -- respeta las flags -a -b -q -d, resolución predeterminada igual que la entrada

ARCHIVOS

~/.lav2mpegrc

archivo de configuración del usuario. Es fuente de bash y puede modificar cualquiera de las variables de entorno mencionadas en la sección ENTORNO, o establecer la variable LAV2MPEG_OPTIONS para agregar opciones predeterminadas.

ENTORNO

NICEVAL
el valor de nice de cada comando, establecido usando 'nice -n comando'
YUVSCALER
modifica qué comando se llama para yuvscaler
LAV2WAV
modifica qué comando se llama para lav2wav
MPLEX
modifica qué comando se llama para mplex
YUVDENOISE
modifica qué comando se llama para yuvdenoise
MPEG2ENC
modifica qué comando se llama para mpeg2enC
AUDIOENC
audioenc es similar a los anteriores, sin embargo, si se establece en 'mp2enc', usará mp2enc en lugar de toolame y establecerá las flags adecuadamente.
NOISYLOGFILE
establece el archivo utilizado para el registro ruidoso (-N), el valor predeterminado es archivo_salida.log
QUIETLOG
establece el archivo utilizado para el registro silencioso. el valor predeterminado es lav2mpeg.log; si se establece en "", solo registrará en la pantalla
LOGDATE
el valor predeterminado es 1, establecido en 0 para no registrar la fecha en el registro o la salida (ver man date para más información)
LOGDATESTR
se pasará a 'date' para describir qué formato de hora usar. Solo se usa si LOGDATE no es 0
LOGCOMMANDS
si se establece en un valor distinto de cero, registrará en el registro silencioso los comandos utilizados. Los comandos siempre se registran en NOISYLOGFILE si se utilizan
LOGONLY
si se establece en un valor distinto de cero, solo registrará los comandos que utilizaría, pero no ejecutará ningún comando
LAV2MPEGRC
el archivo lav2mpegrc. Solo es beneficioso si se establece desde la variable de entorno.
VCD_MEDIUM_BR
tasa de bits de video para el modo=vcd_medium
VCD_HIGH_BR
tasa de bits de video para el modo=vcd_high
SVCD_HIGH_BR
tasa de bits de video para el modo=svcd_high
SVCD_HIGH_QUAL
calidad usada (-q 0-30 a mpeg2enc) para SVCD_HIGH
SVCD_HIGH_BUFFSIZE
tamaño de búfer (-V a mpeg2enc) usado para svcd_high, el valor predeterminado es 100
EXTRA_LAV2YUV
establece argumentos de línea de comandos adicionales para lav2yuv, que se agregarán al final
EXTRA_YUVSCALER
establece argumentos de línea de comandos adicionales para yuvscaler, que se agregarán al final
EXTRA_MPEG2ENC
establece argumentos de línea de comandos adicionales para mpeg2enc, que se agregarán al final
EXTRA_LAV2WAV
establece argumentos de línea de comandos adicionales para lav2wav, que se agregarán al final
EXTRA_AUDIOENC
establece argumentos de línea de comandos adicionales para mp2enc o toolame (dependiendo de AUDIOENC), que se agregarán al final
EXTRA_MPLEX
establece argumentos de línea de comandos adicionales para mplex, que se agregarán al final
EXTRA_YUVDENOISE
establece argumentos de línea de comandos adicionales para yuvdenoise, que se agregarán al final

DIAGNÓSTICOS

Para ver simplemente los comandos que lav2mpeg habría llamado, ejecute 'LOGONLY=1 lav2mpeg ...'

ERRORES

Posiblemente. Por favor, informe al autor.

EJEMPLOS

crea un mpeg compatible con VCD independientemente del nombre del archivo de entrada.mpg
lav2mpeg archivo.avi
crea un mpeg SVCD de alta tasa desde la entrada llamada salida.mpg
lav2mpeg -o salida.mpg -m svcd_high archivo.avi
usa lav2yuv.new en lugar de lav2yuv y agrega el flag '-M MMX' a
yuvscaler:
LAV2YUV="lav2yuv.new" EXTRA_YUVSCALER="-M MMX" lav2mpeg archivo.avi
Por favor, lea otros ejemplos incluidos en la documentación para el uso de
.lav2mpegrc
