Propósito:

!>
!> CLAGS2 calcula matrices unitarias 2x2 U, V y Q, tales
!> que si ( UPPER ) entonces

!>           U**H *A*Q = U**H *( A1 A2 )*Q = ( x  0  )
!>                             ( 0  A3 )     ( x  x  )
!> y
!>           V**H*B*Q = V**H *( B1 B2 )*Q = ( x  0  )
!>                            ( 0  B3 )     ( x  x  )
!>
!> o si ( .NOT.UPPER ) entonces
!>
!>           U**H *A*Q = U**H *( A1 0  )*Q = ( x  x  )
!>                             ( A2 A3 )     ( 0  x  )
!> y
!>           V**H *B*Q = V**H *( B1 0  )*Q = ( x  x  )
!>                             ( B2 B3 )     ( 0  x  )
!> donde
!>
!>   U = (   CSU    SNU ), V = (  CSV    SNV ),
!>       ( -SNU**H  CSU )      ( -SNV**H CSV )
!>
!>   Q = (   CSQ    SNQ )
!>       ( -SNQ**H  CSQ )
!>
!> Las filas de A y B transformadas son paralelas. Además, si la
!> matriz de entrada 2x2 A no es cero, entonces la entrada (1,1)

!> entonces el elemento (2,2) transformado de B no es cero, excepto cuando las

!> cero.

NAME

lags2, zlags2 - apply a 2-by-2 orthogonal/unitary transformation to a 2-by-2 matrix

SYNOPSIS

 subroutine lags2 ( logical upper, real a1, real a2, real a3, real b1, real b2, real b3, real csu, real snu, real csv, real snv, real csq, real snq )

 subroutine zlags2 ( logical upper, double precision a1, complex*16 a2, double precision a3, double precision b1, complex*16 b2, double precision b3, double precision csu, complex*16 snu, double precision csv, complex*16 snv, double precision csq, complex*16 snq )

Description

The subroutine SLAGS2 computes 2-by-2 orthogonal matrices U, V, and Q, and applies them to matrices A and B such that the rows of the transformed A and B are parallel.

The subroutine ZLAGS2 computes 2-by-2 unitary matrices U, V and Q, such that if ( UPPER ) then

U**H *A*Q = U**H *( A1 A2 )*Q = ( x  0  )
                          ( 0  A3 )     ( x  x  )
and
V**H*B*Q = V**H *( B1 B2 )*Q = ( x  0  )
                           ( 0  B3 )     ( x  x  )

or if ( .NOT.UPPER ) then

U**H *A*Q = U**H *( A1 0  )*Q = ( x  x  )
                            ( A2 A3 )     ( 0  x  )
and
V**H *B*Q = V**H *( B1 0  )*Q = ( x  x  )
                            ( B2 B3 )     ( 0  x  )

where

U = (   CSU    SNU ), V = (  CSV    SNV ),
    ( -SNU**H  CSU )      ( -SNV**H CSV )

Q = (   CSQ    SNQ )
    ( -SNQ**H  CSQ )

The rows of the transformed A and B are parallel. Moreover, if the input 2-by-2 matrix A is not zero, then the transformed (1,1) entry of A is not zero. If the input matrices A and B are both not zero, then the transformed (2,2) element of B is not zero, except when the first rows of input A and B are parallel and the second rows are zero.
