CLA_GBRFSX_EXTENDED mejora la solución calculada de un sistema de ecuaciones lineales para matrices generales de banda realizando un refinamiento iterativo de precisión extra y proporciona cotas de error y estimaciones de error hacia atrás para la solución.

Propósito:

!>
!> CLA_GBRFSX_EXTENDED mejora la solución calculada de un sistema de
!> ecuaciones lineales realizando un refinamiento iterativo de precisión extra
!> y proporciona cotas de error y estimaciones de error hacia atrás para la solución.
!> Esta subrutina es llamada por CGBRFSX para realizar el refinamiento iterativo.
!> Además de la cota de error normwise, el código proporciona la cota de error
!> componente a componente máxima si es posible. Consulte los comentarios para
!> ERR_BNDS_NORM y ERR_BNDS_COMP para obtener detalles de las cotas de error.
!> Tenga en cuenta que esta subrutina solo es responsable de establecer los
!> segundos campos de ERR_BNDS_NORM y ERR_BNDS_COMP.
!>

Parámetros

PREC_TYPE 
!>          PREC_TYPE es INTEGER
!>     Especifica la precisión intermedia a utilizar en el refinamiento.
!>     El valor se define por ILAPREC(P) donde P es un CHARACTER y P
!>          = 'S':  Simple
!>          = 'D':  Doble
!>          = 'I':  Indígena
!>          = 'X' o 'E':  Extra
!>

TRANS_TYPE

!>          TRANS_TYPE es INTEGER
!>     Especifica la operación de transposición en A.
!>     El valor se define por ILATRANS(T) donde T es un CHARACTER y T
!>          = 'N':  Sin transposición
!>          = 'T':  Transpuesta
!>          = 'C':  Transpuesta conjugada
!>

N

!>          N es INTEGER
!>     El número de ecuaciones lineales, es decir, el orden de la
!>     matriz A.  N >= 0.
!>

KL

!>          KL es INTEGER
!>     El número de subdiagonales dentro de la banda de A.  KL >= 0.
!>

KU

!>          KU es INTEGER
!>     El número de superdiagonales dentro de la banda de A.  KU >= 0
!>

NRHS

!>          NRHS es INTEGER
!>     El número de lados derechos, es decir, el número de columnas de la
!>     matriz B.
!>

AB

!>          AB es array COMPLEX, dimension (LDAB,N)
!>     A la entrada, la matriz AB de N por N.
!>

LDAB

!>          LDAB es INTEGER
!>     La dimensión principal del array AB.  LDAB >= max(1,N).
!>

AFB

!>          AFB es array COMPLEX, dimension (LDAF,N)
!>     Los factores L y U de la factorización
!>     A = P*L*U calculada por CGBTRF.
!>

LDAFB

!>          LDAFB es INTEGER
!>     La dimensión principal del array AF.  LDAF >= max(1,N).
!>

IPIV

!>          IPIV es array INTEGER, dimension (N)
!>     Los índices de pivote de la factorización A = P*L*U
!>     calculada por CGBTRF; la fila i de la matriz se intercambió
!>     con la fila IPIV(i).
!>

COLEQU

!>          COLEQU es LOGICAL
!>     Si es .TRUE. entonces se realizó una equilibrio de columna en A antes de llamar
!>     a esta rutina. Esto es necesario para calcular la solución y las cotas de error
!>     correctamente.
!>

C

!>          C es array REAL, dimension (N)
!>     Los factores de escala de columna para A. Si COLEQU = .FALSE.,
!>     C no se accede. Si C se introduce, cada elemento de C debe ser una potencia
!>     de la base para garantizar una solución y estimaciones de error fiables.
!>     La escala por potencias de la base no causa errores de redondeo a menos que
!>     el resultado sea subdesbordado o sobredesbordado. Los errores de redondeo durante
!>     la escala conducen a refinar con una matriz que no es equivalente a la
!>     matriz de entrada, produciendo estimaciones de error que pueden no ser
!>     fiables.
!>

B

!>          B es array COMPLEX, dimension (LDB,NRHS)
!>     La matriz del lado derecho B.
!>

LDB

!>          LDB es INTEGER
!>     La dimensión principal del array B.  LDB >= max(1,N).
!>

Y

!>          Y es array COMPLEX, dimension (LDY,NRHS)
!>     A la entrada, la matriz solución X, calculada por CGBTRS.
!>     A la salida, la matriz solución mejorada Y.
!>

LDY

!>          LDY es INTEGER
!>     La dimensión principal del array



NOMBRE


dla_gbrfsx_extended - IMPROVES THE COMPUTED SOLUTION TO A SYSTEM OF LINEAR EQUATIONS FOR GENERAL BANDED MATRICES BY PERFORMING EXTRA-PRECISE ITERATIVE REFINEMENT AND PROVIDES ERROR BOUNDS AND BACKWARD ERROR ESTIMATES FOR THE SOLUTION.

DESCRIPCIÓN


DLA_GBRFSX_EXTENDED mejora la solución calculada de un sistema de ecuaciones lineales para matrices generales de banda mediante la realización de un refinamiento iterativo de precisión extra y proporciona cotas de error y estimaciones de error hacia atrás para la solución.


Propósito:




!>
!>  (See purpose statement in the CLAss description).
!>





Parámetros:




PREC_TYPE


PREC_TYPE es INTEGER. Tipo de precisión del cómputo de refinamiento.




TRANS_TYPE


TRANS_TYPE es INTEGER. Tipo de transposición que se utilizará.




N


N es INTEGER.
    
Orden de la matriz A. N >= 0.




KL


KL es INTEGER.
    
Número de superdiagonales en la matriz A. KL >= 0.




KU


KU es INTEGER.
    
Número de subdiagonales en la matriz A. KU >= 0.




NRHS


NRHS es INTEGER.
    
Número de sistemas a resolver, es decir, el número de columnas del vector B. NRHS >= 0.




AB


AB es DOUBLE PRECISION array, dimensión (LDAB, N).
    
Matriz de banda de entrada.




LDAB


LDAB es INTEGER.
    
Longitud de la línea de AB. LDAB >= max(1, KL+1).




AFB


AFB es DOUBLE PRECISION array, dimensión (LDAFB, N).
    
Factorización de la matriz AB.




LDAFB


LDAFB es INTEGER.
    
Longitud de la línea de AFB. LDAFB >= max(1, KL+1).




IPIV


IPIV es INTEGER array, dimensión (N).
    
Detalles de la factorización LU de la matriz de banda.




COLEQU


COLEQU es LOGICAL.
    
Si es .TRUE., la matriz de banda A se ha escalado por filas y columnas.




C


C es DOUBLE PRECISION array, dimensión (N).
    
Vectores de escalado de columnas, si COLEQU es .TRUE..




B


B es DOUBLE PRECISION array, dimensión (LDB, NRHS).
    
En la entrada, la matriz B de lados derechos (o la solución calculada, si se usa para refinamiento).

    
En la salida, la matriz B se sobrescribe con la solución refinada X.




LDB


LDB es INTEGER.
    
Longitud de la línea de B. LDB >= max(1, N).




Y


Y es DOUBLE PRECISION array, dimensión (LDY, NRHS).
    
En la entrada, la solución calculada X.

    
En la salida, el vector de refinamiento.




LDY


LDY es INTEGER.
    
Longitud de la línea de Y. LDY >= max(1, N).




BERR_OUT


BERR_OUT es DOUBLE PRECISION array, dimensión (NRHS).
    
En la salida, BERR_OUT(j) contiene el error relativo hacia atrás componente a componente para el lado derecho j de la fórmula

    
max(i) ( abs(RES(i)) / ( abs(op(A_s))*abs(Y) + abs(B_s) )(i) )

    
donde abs(Z) es el valor absoluto componente a componente de la matriz o vector Z. Esto se calcula mediante CLA_LIN_BERR.




N_NORMS


N_NORMS es INTEGER.
    
Determina qué cotas de error devolver (ver ERR_BNDS_NORM y ERR_BNDS_COMP).

    
Si N_NORMS >= 1, devuelve cotas de error normwise.

    
Si N_NORMS >= 2, devuelve cotas de error componentwise.




ERR_BNDS_NORM


ERR_BNDS_NORM es DOUBLE PRECISION array, dimensión (NRHS, N_ERR_BNDS).
    
Para cada lado derecho, esta matriz contiene información sobre varias cotas de error y números de condición correspondientes al error relativo normwise, que se define como sigue:

    
Error relativo normwise en el i-ésimo vector solución:

    
max_j (abs(XTRUE(j,i) - X(j,i)))

    
------------------------------

    
max_j abs(X(j,i))

    
La matriz está indexada por el tipo de información de error según se describe a continuación. Actualmente se devuelven hasta tres piezas de información.

    
El primer índice en ERR_BNDS_NORM(i,:) corresponde al i-ésimo lado derecho.

    
El segundo índice en ERR_BNDS_NORM(:,err) contiene los tres campos siguientes:

    
err = 1 booleano. Confiar en la respuesta si el

    
número de condición recíproco es menor que el umbral

    
sqrt(n) * slamch('Epsilon').

    
err = 2 cota de error: El error hacia adelante estimado,

    
casi con certeza dentro de un factor de 10 del error real

    
siempre que la siguiente entrada sea mayor que el umbral

    
sqrt(n) * slamch('Epsilon'). Esta cota de error solo debe

    
confiarse si el booleano anterior es verdadero.

    
err = 3 Número de condición recíproco: Estimación normwise

    
número de condición recíproco. Comparado con el umbral

    
sqrt(n) * slamch('Epsilon') para determinar si la estimación

    
del error es . Estos números de condición recíprocos

    
son 1 / (norm(Z^{-1},inf) * norm(Z,inf)) para alguna

    
matriz Z escalada apropiadamente.

    
Sea Z = S*A, donde S escala cada fila por una potencia de

    
la base para que todas las sumas de filas absolutas de Z sean aproximadamente 1.

    
Esta subrutina solo es responsable de establecer el segundo campo.

    
Ver Lapack Working Note 165 para más detalles y precauciones adicionales.




ERR_BNDS_COMP


ERR_BNDS_COMP es DOUBLE PRECISION array, dimensión (NRHS, N_ERR_BNDS).
    
Para cada lado derecho, esta matriz contiene información sobre

    
varias cotas de error y números de condición correspondientes al

    
error relativo componentwise, que se define como sigue:

    
Error relativo componentwise en el i-ésimo vector solución:

    
abs(XTRUE(j,i) - X(j,i))

    
max_j ----------------------

    
abs(X(j,i))

    
La matriz está indexada por el lado derecho i (del que depende el

    
error relativo componentwise), y el tipo de información de error

    
según se describe a continuación. Actualmente se devuelven hasta tres

    
piezas de información para cada lado derecho. Si

    
no se solicita precisión componentwise (PARAMS(3) = 0.0), entonces

    
ERR_BNDS_COMP no se accede. Si N_ERR_BNDS < 3, entonces como máximo

    
se devuelven las primeras (:,N_ERR_BNDS) entradas.

    
El primer índice en ERR_BNDS_COMP(i,:) corresponde al i-ésimo

    
lado derecho.

    
El segundo índice en ERR_BNDS_COMP(:,err) contiene los tres

    
campos siguientes:

    
err = 1 booleano. Confiar en la respuesta si el

    
número de condición recíproco es menor que el umbral

    
sqrt(n) * slamch('Epsilon').

    
err = 2 cota de error: El error hacia adelante estimado,

    
casi con certeza dentro de un factor de 10 del error real

    
siempre que la siguiente entrada sea mayor que el umbral

    
sqrt(n) * slamch('Epsilon'). Esta cota de error solo debe

    
confiarse si el booleano anterior es verdadero.

    
err = 3 Número de condición recíproco: Estimación componentwise

    
número de condición recíproco. Comparado con el umbral

    
sqrt(n) * slamch('Epsilon') para determinar si la estimación

    
del error es . Estos números de condición recíprocos

    
son 1 / (norm(Z^{-1},inf) * norm(Z,inf)) para alguna

    
matriz Z escalada apropiadamente.

    
Sea Z = S*(A*diag(x)), donde x es la solución para el

    
lado derecho actual y S escala cada fila de

    
A*diag(x) por una potencia de la base para que todas las sumas de filas absolutas de Z sean aproximadamente 1.

    
Esta subrutina solo es responsable de establecer el segundo campo.

    
Ver Lapack Working Note 165 para más detalles y precauciones adicionales.




RES


RES es DOUBLE PRECISION array, dimensión (N).
    
Espacio de trabajo para contener el residuo intermedio.




AYB


AYB es DOUBLE PRECISION array, dimensión (N).
    
Espacio de trabajo.




DY


DY es DOUBLE PRECISION array, dimensión (N).
    
Espacio de trabajo para contener la solución intermedio.




Y_TAIL


Y_TAIL es DOUBLE PRECISION array, dimensión (N).
    
Espacio de trabajo para contener las partes finales de la solución intermedia.




RCOND


RCOND es DOUBLE PRECISION.
    
Número de condición escalado recíproco. Esta es una estimación del

    
número de condición de Skeel recíproco de la matriz A después

    
de la   (si se realizó). Si este es menor que la precisión de la

    
máquina (en particular, si es cero), la matriz es singular

    
a precisión de trabajo. Tenga en cuenta que el error aún puede ser pequeño incluso

    
si este número es muy pequeño y la matriz parece estar mal

    
condicionada.




ITHRESH


ITHRESH es INTEGER.
    
El número máximo de cómputos de residuos permitidos para

    
refinamiento. El valor predeterminado es 10. Para 'agresivo', establécelo en 100 para

    
permitir la convergencia utilizando factorizaciones aproximadas o

    
factorizaciones distintas de LU. Si la factorización utiliza una

    
técnica distinta de la eliminación gaussiana, las garantías en

    
ERR_BNDS_NORM y ERR_BNDS_COMP pueden ya no ser fiables.




RTHRESH


RTHRESH es DOUBLE PRECISION.
    
Determina cuándo detener el refinamiento si la estimación del error deja de

    
disminuir. El refinamiento se detendrá cuando la siguiente solución ya no

    
satisfaga norm(dx_{i+1}) < RTHRESH * norm(dx_i) donde norm(Z) es

    
la norma infinita de Z. RTHRESH satisface 0 < RTHRESH <= 1. El

    
valor predeterminado es 0.5. Para 'agresivo', establécelo en 0.9 para permitir

    
la convergencia en matrices extremadamente mal condicionadas. Ver LAWN 165

    
para más detalles.




DZ_UB


DZ_UB es DOUBLE PRECISION.
    
Determina cuándo empezar a considerar la convergencia componentwise.

    
La convergencia componentwise solo se considera después de que cada componente

    
de la solución Y es estable, lo que definimos como el cambio relativo

    
en cada componente es menor que DZ_UB. El valor predeterminado

    
es 0.25, requiriendo que el primer bit sea estable. Ver LAWN 165 para

    
más detalles.




IGNORE_CWISE


IGNORE_CWISE es LOGICAL.
    
Si es .TRUE., ignora la convergencia componentwise. Valor predeterminado

    
es .FALSE..




INFO


INFO es INTEGER.
    
= 0: Salida exitosa.

    
< 0: si INFO = -i, el i-ésimo argumento de CGBTRS tuvo un valor ilegal

DGBTRS(


Name


dgbtrs — solves a system of linear equations in a general
    banded matrix, with iterative refinement.


Synopsis




    SUBROUTINE DGBTRS( TRANS, N, KL, KU, NRHS, AB, LDAB, IPIV, B, LDB, INFO )

        CHARACTER          TRANS
        INTEGER            KL, KU, INFO, N, NRHS
        INTEGER            IPIV( * )
        DOUBLE PRECISION   AB( LDAB, * ), B( LDB, * )
        INTEGER            LDAB, LDB





Description


The routine solves a system of linear equations Ax = B for a
    general band matrix A of bandwidth (KL, KU) with KL sub-diagonals and KU
    super-diagonals. Appropriate matrix factorizations are provided by DGBTRF.


This routine is expected to be called by dgbtrfs to compute and return the error bounds on the solution of the system
    of equations.


If iterative refinement is used (see dgbtrfs),
    dgbtrs is called by dgbtrfs to solve the system of equations.


The solution is computed by solving the equivalent triangular system,
    or by applying the iterative refinement process to a solution obtained from
    the triangular system.


Parameters


TRANS




TRANS is CHARACTER*1


Specifies the form of the system of equations:


       'N':  Ax = B     (No transpose)
       'T':  ATx = B (Transpose)
       'C':  AHx = B (Conjugate transpose)





N




N is INTEGER


The order of the matrix A.  0 <= N.




KL




KL is INTEGER


The number of sub-diagonals of the matrix A. 0 <= KL < N.




KU




KU is INTEGER


The number of super-diagonals of the matrix A. 0 <= KU < N.




NRHS




NRHS is INTEGER


The number of right-hand sides, i.e., the number of columns in the
    arrays B and Y. 0 <= NRHS.




AB




AB is DOUBLE PRECISION array, dimension (LDAB,N)


On entry, the factors L and U from the factorization of A as
    computed by dgbtrf. For the `NO TRANSPOSE` case, the matrix AB
    is stored in the upper triangle of the array AB. For the `TRANSPOSE`
    or `CONJUGATE TRANSPOSE` cases, the matrix AB is stored in the lower
    triangle of the array AB.




LDAB




LDAB is INTEGER


The leading dimension of the array AB. LDAB >= max(1,N).




IPIV




IPIV is INTEGER array, dimension (N)


The pivot indices from the factorization. A row I was interchanged
    with row IPIV(I), for 1 <= I <= N. IPIV(I) < 0 indicates that row I was
    interchanged with row -IPIV(I).




B




B is DOUBLE PRECISION array, dimension (LDB,NRHS)


On entry, the right-hand side matrix of the system to be solved.
    On exit, if dgbtrfs is called, the solution matrix X to the
    system Ax = B.




LDB




LDB is INTEGER


The leading dimension of the array B.




INFO




INFO is INTEGER


If INFO = 0, a successful computation has been performed.


If INFO < 0, the i-th argument had an illegal value. If INFO = -i,
    then the i-th argument to the subroutine was illegal.

Further Details




The band storage format is as follows: If AB is an N by N matrix,
    then AB is represented by a (KL+KU+1) by N matrix.


The diagonal and super-diagonals of A are stored in rows KU to KL+KU
    of AB, and the sub-diagonals are stored in rows 0 to KU-1 of AB.


The elements of the matrix A are stored as follows: (See "LAPACK Users'
    Guide", Chapter 11)


       A(i,j) is stored at AB(i - j + KU + 1, j)



The routine solves the system Ax = B by first solving the triangular
    system L*U*x = P*B for U*x = P-1*L-1*P*B, and then computing
    x = U-1*(P-1*L-1*P*B).


If the iterative refinement option is used, this routine calls itself
    recursively.


The storage scheme for the factored matrix is intended to economize on
    space. A full N by N matrix is required.


Example:


To solve the system Ax = B, where


    A = [  1  2  0  0 ]
        [  1  3  2  0 ]
        [  0  1  4  3 ]
        [  0  0  1  5 ]

    B = [  2 ]
        [  4 ]
        [  6 ]
        [  7 ]



We have N = 4, KL = 1, KU = 1. The matrix AB is stored as:


    AB = [ (0)  1   3   1 ]   (row 0, represents the super-diagonal)
         [ 1    3   4   5 ]   (row 1, represents the main diagonal)
         [ 1    2   3 (0) ]   (row 2, represents the sub-diagonal)



The LU factorization is computed by DGBTRF. The pivot indices IPIV
    are obtained.


The code then solves the system Ax = B using DGBTRS.

Detailed Description


This subroutine is the driver for the extended recomputation of error
    bounds in solving a system of linear equations with a general band matrix.


It is a wrapper to ZGBRFSX, XGBCON, XGBRFS, XGBRFSX and XPBTRS,
    XPBEqu, XPBEquR


This routine is called by the routines that solve the general band
    linear system


This subroutine is an extended version of the LAPACK routine ZGBRFS.
    It computes the normwise residual, normwise error bound, and the
    reciprocal condition number, and additionally computes the componentwise
    residual, componentwise error bound, and the reciprocal condition number
    for the system of equations Ax = B.


In addition, it provides an option for iterative refinement, which
    may be used to improve the accuracy of the computed solution.


The routine computes error bounds in the two following situations:


    
    
  1. Normwise relative error: This measures the relative error in the
        solution vector in the infinity norm.
    2. 
    
  2. Componentwise relative error: This measures the relative error in
        each component of the solution vector.
    3. 



The routine also computes two different condition estimates:


    
    
  1. Normwise condition estimate: This is an estimate of the 1-norm
        condition number of the matrix A after equilibration.
    2. 
    
  2. Componentwise condition estimate: This is an estimate of the
        componentwise condition number of the matrix A after equilibration.
    3. 



If the matrix A is scaled before the LU factorization, the error
    bounds and condition estimates are computed for the scaled matrix A_s.


The routine uses iterative refinement to improve the computed
    solution X.
