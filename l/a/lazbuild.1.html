lazbuild(1) Constructor de proyectos de Lazarus lazbuild(1)

NOMBRE

lazbuild - Programa de construcción de proyectos y paquetes de Lazarus.

SINOPSIS

lazbuild [opciones] nombre_archivo...

DESCRIPCIÓN

lazbuild construye un proyecto o paquete de Lazarus. Compila proyectos (.lpi) y paquetes (.lpk). Verifica y compila automáticamente los paquetes requeridos.

USO

lazbuild es una herramienta de línea de comandos que construye proyectos y paquetes de Lazarus. Verifica recursivamente todas las dependencias y compila primero los paquetes necesarios. Utiliza el compilador Free Pascal compiler (fpc) para compilar.

OPCIONES

-h, --help
Muestra un breve mensaje de ayuda.
-B, --build-all
Construye todos los archivos del proyecto/paquete. Tiene el mismo efecto que la opción -B de fpc(1).
-r, --recursive
Aplica las banderas de construcción (-B) a las dependencias también.
-d, --skip-dependencies
No compilar dependencias.
--build-ide=<opciones>
Compilar el IDE (es decir, el ejecutable de Lazarus). La lista de paquetes de instalación se lee del directorio de configuración. Las <opciones> pueden estar vacías.
-v, --version
Mostrar la versión y salir.
--pcp=<ruta>, --primary-config-path=<ruta>
Directorio de configuración principal, donde Lazarus almacena sus archivos de configuración. Por defecto es /home/mazen/.lazarus
--scp=<ruta>, --secondary-config-path=<ruta>
Directorio de configuración secundario, donde Lazarus busca archivos de plantilla de configuración. Por defecto es /etc/lazarus
--os=<sistema-operativo>, --operating-system=<sistema-operativo>
Sobrescribir el sistema operativo del proyecto. Por ejemplo, win32 o linux.
--ws=<setdeventanas>, --widgetset=<setdeventanas>
Sobrescribir el set de ventanas del proyecto. Por ejemplo, gtk, gtk2, qt, win32 o carbon.
--cpu=<cpu>
Sobrescribir la CPU del proyecto. Por ejemplo, i386, x86_64, powerpc, powerpc_64, etc.
--build-mode=<modo de construcción del proyecto>, --bm=<modo de construcción del proyecto>
Sobrescribir el modo de construcción del proyecto.
--compiler=<ppcXXX>
Sobrescribir el compilador predeterminado. Por ejemplo, ppc386, ppcx64, ppcppc, etc.
--language=<idioma>
Sobrescribir el idioma. Por ejemplo, --language=de. Para valores posibles, consulte los archivos en el directorio de idiomas de Lazarus.

Archivos .lpi y .lpk

Los archivos .lpi y .lpk se crean y editan mejor con el IDE de Lazarus. Los archivos están en formato xml. No hay razón para editarlos manualmente, excepto en casos muy raros como renombrar cientos de archivos.
