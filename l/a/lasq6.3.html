subrutina dlasq6 (integer i0, integer n0, double precision, dimension( * ) z, integer pp, double precision dmin, double precision dmin1, double precision dmin2, double precision dn, double precision dnm1, double precision dnm2)

DLASQ6 calcula una transformada dqd en forma de ping-pong. Utilizada por sbdsqr y sstegr.

Propósito:

!>
!> DLASQ6 calcula una transformada dqd (desplazamiento igual a cero) en
!> forma de ping-pong, con protección contra subdesbordamiento y desbordamiento.
!>

Parámetros

I0 
!>          I0 es INTEGER
!>        Primer índice.
!>

N0

!>          N0 es INTEGER
!>        Último índice.
!>

Z

!>          Z es un array de DOUBLE PRECISION, dimension ( 4*N )
!>        Z contiene el array qd. EMIN se almacena en Z(4*N0) para evitar
!>        un argumento adicional.
!>

PP

!>          PP es INTEGER
!>        PP=0 para ping, PP=1 para pong.
!>

DMIN

!>          DMIN es DOUBLE PRECISION
!>        Valor mínimo de d.
!>

DMIN1

!>          DMIN1 es DOUBLE PRECISION
!>        Valor mínimo de d, excluyendo D( N0 ).
!>

DMIN2

!>          DMIN2 es DOUBLE PRECISION
!>        Valor mínimo de d, excluyendo D( N0 ) y D( N0-1 ).
!>

DN

!>          DN es DOUBLE PRECISION
!>        d(N0), el último valor de d.
!>

DNM1

!>          DNM1 es DOUBLE PRECISION
!>        d(N0-1).
!>

DNM2

!>          DNM2 es DOUBLE PRECISION
!>        d(N0-2).
!>
