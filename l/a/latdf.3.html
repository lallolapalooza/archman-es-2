subrutina clatdf (integer ijob, integer n, complex, dimension( ldz, * ) z, integer ldz, complex, dimension( * ) rhs, real rdsum, real rdscal, integer, dimension( * ) ipiv, integer, dimension( * ) jpiv)

CLATDF utiliza la factorización LU de la matriz n por n calculada por sgetc2 y calcula una contribución a la estimación Dif recíproca.

Propósito:

!>
!> CLATDF calcula la contribución a la estimación Dif recíproca
!> resolviendo para x en Z * x = b, donde b se elige de modo que la norma
!> de x sea lo más grande posible. Se asume que la descomposición LU
!> de Z ha sido calculada por CGETC2. En la entrada RHS = f contiene la
!> contribución de subsistemas resueltos previamente, y en la salida RHS = x.
!>
!> La factorización de Z devuelta por CGETC2 tiene la forma
!> Z = P * L * U * Q, donde P y Q son matrices de permutación. L es triangular inferior con elementos diagonales unitarios y U es triangular superior.
!>

Parámetros

IJOB 
!>          IJOB es INTEGER
!>          IJOB = 2: Primero calcula un vector nulo aproximado e
!>              de Z usando CGECON, e se normaliza y resuelve para
!>              Zx = +-e - f con el signo que da el mayor valor de
!>              2-norm(x). Aproximadamente 5 veces más costoso que el predeterminado.
!>          IJOB .ne. 2: Estrategia de Look Ahead local donde
!>              todas las entradas del r.h.s. b se eligen como +1 o
!>              -1. Predeterminado.
!>

N

!>          N es INTEGER
!>          El número de columnas de la matriz Z.
!>

Z

!>          Z es un array COMPLEX, dimensión (LDZ, N)
!>          En la entrada, la parte LU de la factorización de la matriz n x n
!>          Z calculada por CGETC2: Z = P * L * U * Q
!>

LDZ

!>          LDZ es INTEGER
!>          La dimensión principal del array Z. LDA >= max(1, N).
!>

RHS

!>          RHS es un array COMPLEX, dimensión (N).
!>          En la entrada, RHS contiene contribuciones de otros subsistemas.
!>          En la salida, RHS contiene la solución del subsistema con
!>          entradas según el valor de IJOB (ver arriba).
!>

RDSUM

!>          RDSUM es REAL
!>          En la entrada, la suma de cuadrados de las contribuciones calculadas a
!>          la estimación Dif bajo cálculo por CTGSYL, donde el
!>          factor de escala RDSCAL (ver abajo) ha sido extraído.
!>          En la salida, la suma de cuadrados correspondiente actualizada con las
!>          contribuciones del subsistema actual.
!>          Si TRANS = 'T', RDSUM no se toca.
!>          NOTA: RDSUM solo tiene sentido cuando CTGSY2 es llamado por CTGSYL.
!>

RDSCAL

!>          RDSCAL es REAL
!>          En la entrada, factor de escala usado para prevenir overflow en RDSUM.
!>          En la salida, RDSCAL se actualiza respecto a las contribuciones actuales
!>          en RDSUM.
!>          Si TRANS = 'T', RDSCAL no se toca.
!>          NOTA: RDSCAL solo tiene sentido cuando CTGSY2 es llamado por
!>          CTGSYL.
!>

IPIV

!>          IPIV es un array INTEGER, dimensión (N).
!>          Los índices de pivote; para 1 <= i <= N, la fila i de la
!>          matriz ha sido intercambiada con la fila IPIV(i).
!>

JPIV

!>          JPIV es un array INTEGER, dimensión (N).
!>          Los índices de pivote; para 1 <= j <= N, la columna j de la
!>          matriz ha sido intercambiada con la columna JPIV(j).
!>

subroutine   dlatdf (integer ijob, integer n, double precision, dimension( ldz, * ) z, integer   ldz, double precision, dimension( * ) rhs, double precision rdsum, double precision   rdscal, integer, dimension( * ) ipiv, integer, dimension( * ) jpiv)


DLATDF uses the LU factorization of the n-by-n matrix
    computed by dgetc2 and computes a contribution to the reciprocal
    Dif-estimate.


Purpose:




!>
!> DLATDF computes the contribution to the reciprocal Dif-estimate
!> by solving for x in Z * x = b, where b is chosen such that the norm
!> of x is as large as possible. It is assumed that LU decomposition
!> of Z has been computed by DGETC2. On entry RHS = f holds the
!> contribution from earlier solved sub-systems, and on return RHS = x.
!>
!> The factorization of Z returned by DGETC2 has the form
!> Z = P * L * U * Q, where P and Q are permutation matrices. L is lower
!> triangular with unit diagonal elements and U is upper triangular.
!> 




Parameters


IJOB

!>          IJOB is INTEGER
!>          IJOB = 2: First compute an approximative null-vector e
!>              of Z using DGECON, e is normalized and solve for
!>              Zx = +-e - f with the sign giving the greater value of
!>              2-norm(x).  About 5 times as expensive as Default.
!>          IJOB .ne. 2: Local look ahead strategy where
!>              all entries of the r.h.s. b is chosen as either +1 or
!>              -1.  Default.
!> 


N


!>          N is INTEGER
!>          The number of columns of the matrix Z.
!> 


Z


!>          Z is DOUBLE PRECISION array, dimension (LDZ, N)
!>          On entry, the LU part of the factorization of the n-by-n
!>          matrix Z computed by DGETC2:  Z = P * L * U * Q
!> 


LDZ


!>          LDA is INTEGER
!>          The leading dimension of the array Z.  LDA >= max(1, N).
!> 


RHS


!>          RHS is DOUBLE PRECISION array, dimension (N)
!>          On entry, RHS contains contributions from other subsystems.
!>          On exit, RHS contains the solution of the subsystem with
!>          entries according to the value of IJOB (see above).
!> 


RDSUM


!>          RDSUM is DOUBLE PRECISION
!>          On entry, the sum of squares of computed contributions to
!>          the Dif-estimate under computation by DTGSYL, where the
!>          scaling factor RDSCAL (see below) has been factored out.
!>          On exit, the corresponding sum of squares updated with the
!>          contributions from the current sub-system.
!>          If TRANS = 'T' RDSUM is not touched.
!>          NOTE: RDSUM only makes sense when DTGSY2 is called by DTGSYL.
!> 


RDSCAL


!>          RDSCAL is DOUBLE PRECISION
!>          On entry, scaling factor used to prevent overflow in RDSUM.
!>          On exit, RDSCAL is updated w.r.t. the current contributions
!>          in RDSUM.
!>          If TRANS = 'T', RDSCAL is not touched.
!>          NOTE: RDSCAL only makes sense when DTGSY2 is called by
!>                DTGSYL.
!> 


IPIV


!>          IPIV is INTEGER array, dimension (N).
!>          The pivot indices; for 1 <= i <= N, row i of the
!>          matrix has been interchanged with row IPIV(i).
!> 


JPIV


!>          JPIV is INTEGER array, dimension (N).
!>          The pivot indices; for 1 <= j <= N, column j of the
!>          matrix has been interchanged with column JPIV(j).
!>

NAME


latdf — approximate the solution of the condensed generalized
  Sylvester equation






SYNOPSIS


SUBROUTINE ZLATDF( TRANS, N, A, LDA, B, LDB, C, LDC, Q, LDQ,
                   Z, LDZ, TOL, IFAIL, WORK, LWORK, INFO )
  CHARACTER(LEN=1) :: TRANS
  INTEGER :: N, LDA, LDB, LDC, LDQ, LDZ, LWORK, INFO
  COMPLEX*16 :: A(LDA,*), B(LDB,*), C(LDC,*), Q(LDQ,*),
               Z(LDZ,*), WORK(LWORK)
  INTEGER :: IFAIL(*)
  DOUBLE PRECISION :: TOL







Detailed
  Description


ZLATDF computes an approximate solution to the condensed
    generalized Sylvester equation:



    
If TRANS = 'N':

    
A*Z*B' - Q*Z*D' = C

    
If TRANS = 'T':

    
A'*Z*B - Q'*Z*D = C




where A, B, Q, D are upper triangular matrices, and Z, C are
    matrices with dimensions N x N.


The problem is assumed to be non-singular. ZLATDF is intended
    to be called by ZTGSYL.


Arguments:


TRANS


TRANS is CHARACTER*1
          On entry, TRANS specifies the form of the Sylvester
          equation:
          'N' => A*Z*B' - Q*Z*D' = C
          'T' => A'*Z*B - Q'*Z*D = C
          'C' => A'*Z*B' - Q'*Z*D' = C (Not supported by ZLATDF)



N


N is INTEGER
          On entry, N is the order of the matrices A, B, Q, D and Z.
          N must be at least 0.



A


A is COMPLEX*16 array, dimension (LDA, n).
          On entry, the leading n x n upper triangular part of A must
          contain the matrix A.



LDA


LDA is INTEGER
          On entry, LDA is the leading dimension of the array A.
          LDA must be at least max(1, n).



B


B is COMPLEX*16 array, dimension (LDB, n).
          On entry, the leading n x n upper triangular part of B must
          contain the matrix B.



LDB


LDB is INTEGER
          On entry, LDB is the leading dimension of the array B.
          LDB must be at least max(1, n).



C


C is COMPLEX*16 array, dimension (LDC, n).
          On entry, C contains the right hand side matrix C.
          On exit, C is overwritten by the solution matrix Z.



LDC


LDC is INTEGER
          On entry, LDC is the leading dimension of the array C.
          LDC must be at least max(1, n).



Q


Q is COMPLEX*16 array, dimension (LDQ, n).
          On entry, the leading n x n upper triangular part of Q must
          contain the matrix Q.



LDQ


LDQ is INTEGER
          On entry, LDQ is the leading dimension of the array Q.
          LDQ must be at least max(1, n).



Z


Z is COMPLEX*16 array, dimension (LDZ, n).
          On entry, the leading n x n upper triangular part of Z must
          contain the matrix D.
          On exit, Z is used as workspace.



LDZ


LDZ is INTEGER
          On entry, LDZ is the leading dimension of the array Z.
          LDZ must be at least max(1, n).



TOL


TOL is DOUBLE PRECISION
          On entry, TOL is the tolerance for determining the condition
          number of a matrix. The routine returns the value of the
          minimum of the diagonal entries of the upper triangular factor
          of the scaled condition estimate.



IFAIL


IFAIL is INTEGER array, dimension (n).
          On exit, IFAIL contains the indices of the first row of each
          block in the block factorization of the matrix A.



WORK


WORK is COMPLEX*16 array, dimension (LWORK).
          On exit, the imaginary parts of the entries of WORK contain
          the diagonal entries of the upper triangular factor of the
          scaled condition estimate.



LWORK


LWORK is INTEGER
          On entry, LWORK is the dimension of the array WORK.
          On exit, LWORK is returned with the dimension required for
          a correct allocation.
          LWORK must be at least n*n.



INFO


INFO is INTEGER
          On exit, INFO is set as follows:
          = 0:  Successful exit
          > 0:  If INFO = k, then the k-th diagonal block of A is
                singular and the solution may not be accurate.







Function
  Documentation


RDSUM


!>          RDSUM is DOUBLE PRECISION
!>          On entry, the sum of squares of elements of Z, scaled by
!>          RDSCAL.
!>          On exit, the updated sum of squares of elements of Z,
!>          incorporating the contributions from the current
!>          sub-system. The scaling factor RDSCAL (see below) has been
!>          factored out.
!>          If TRANS = 'T' RDSUM is not touched.
!>          NOTE: RDSUM only makes sense when ZTGSY2 is called by CTGSYL.
!> 


RDSCAL


!>          RDSCAL is DOUBLE PRECISION
!>          On entry, scaling factor used to prevent overflow in RDSUM.
!>          On exit, RDSCAL is updated w.r.t. the current contributions
