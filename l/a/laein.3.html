subrutina claein (logical rightv, logical noinit, integer n, complex, dimension( ldh, * ) h, integer ldh, complex w, complex, dimension( * ) v, complex, dimension( ldb, * ) b, integer ldb, real, dimension( * ) rwork, real eps3, real smlnum, integer info)

CLAEIN calcula un vector propio derecho o izquierdo especificado de una matriz de Hessenberg superior mediante iteración inversa.

Propósito:

!>
!> CLAEIN utiliza iteración inversa para encontrar un vector propio derecho
!> o izquierdo correspondiente al valor propio W de una matriz H de Hessenberg
!> superior compleja.
!>

Parámetros

RIGHTV 
!>          RIGHTV es LOGICAL
!>          = .TRUE. : calcular vector propio derecho;
!>          = .FALSE.: calcular vector propio izquierdo.
!>

NOINIT

!>          NOINIT es LOGICAL
!>          = .TRUE. : no se suministra vector inicial en V
!>          = .FALSE.: se suministra vector inicial en V.
!>

N

!>          N es INTEGER
!>          Orden de la matriz H. N >= 0.
!>

H

!>          H es array COMPLEX, dimensión (LDH,N)
!>          La matriz de Hessenberg superior H.
!>

LDH

!>          LDH es INTEGER
!>          La dimensión principal del array H. LDH >= max(1,N).
!>

W

!>          W es COMPLEX
!>          El valor propio de H cuyo vector propio derecho o izquierdo
!>          correspondiente se va a calcular.
!>

V

!>          V es array COMPLEX, dimensión (N)
!>          A la entrada, si NOINIT = .FALSE., V debe contener un vector
!>          de inicio para la iteración inversa; de lo contrario, V no
!>          necesita ser establecido.
!>          A la salida, V contiene el vector propio calculado, normalizado
!>          de modo que el componente de mayor magnitud tenga magnitud 1;
!>          aquí la magnitud de un número complejo (x,y) se toma como
!>          |x| + |y|.
!>

B

!>          B es array COMPLEX, dimensión (LDB,N)
!>

LDB

!>          LDB es INTEGER
!>          La dimensión principal del array B. LDB >= max(1,N).
!>

RWORK

!>          RWORK es array REAL, dimensión (N)
!>

EPS3

!>          EPS3 es REAL
!>          Un valor pequeño dependiente de la máquina que se usa para
!>          perturbar valores propios cercanos y para reemplazar pivotes
!>          cero.
!>

SMLNUM

!>          SMLNUM es REAL
!>          Un valor dependiente de la máquina cercano al umbral de
!>          subdesbordamiento.
!>

INFO

!>          INFO es INTEGER
!>          = 0:  salida exitosa
!>          = 1:  la iteración inversa no convergió; V se establece al
!>                último iterado.
!>

Propósito:

!>
!> DLAEIN utiliza iteración inversa para encontrar un vector propio derecho
!> o izquierdo correspondiente al valor propio (WR,WI) de una matriz H de

Parámetros

RIGHTV 
!>          RIGHTV es LOGICAL

!>          N es INTEGER

!>

H

!>          H es array DOUBLE PRECISION, dimensión (LDH,N)
!>          La matriz de Hessenberg superior H.
!>

LDH

!>          LDH es INTEGER
!>          La dimensión principal del array H. LDH >= max(1,N).
!>

WR

!>          WR es DOUBLE PRECISION
!>

WI

!>          WI es DOUBLE PRECISION
!>          Las partes real e imaginaria del valor propio de H cuyo
!>          vector propio derecho o izquierdo correspondiente se va a
!>          calcular.
!>

VR

!>          VR es array DOUBLE PRECISION, dimensión (N)
!>

VI

!>          VI es array DOUBLE PRECISION, dimensión (N)

!>          valor propio real WR; si NOINIT = .FALSE. y WI.ne.0.0, VR y VI
!>          deben contener las partes real e imaginaria de un vector inicial
!>          complejo para la iteración inversa usando el valor propio
!>          complejo (WR,WI); de lo contrario, VR y VI no necesitan ser
!>          establecidos.
!>          A la salida, si WI = 0.0 (valor propio real), VR contiene el
!>          vector propio real calculado; si WI.ne.0.0 (valor propio
!>          complejo), VR y VI contienen las partes real e imaginaria del
!>          vector propio complejo calculado. El vector propio se normaliza
!>          de modo que el componente de mayor magnitud tenga magnitud 1;
!>          aquí la magnitud de un número complejo (x,y) se toma como

!>

!>          Un valor pequeño dependiente de la máquina que se usa para
!>          perturbar valores propios cercanos y para reemplazar pivotes
!>          cero.
!>

SMLNUM

!>          SMLNUM es DOUBLE PRECISION
!>          Un valor dependiente de la máquina cercano al umbral de
!>          subdesbordamiento.
!>

BIGNUM

!>          BIGNUM es DOUBLE PRECISION
!>          Un valor dependiente de la máquina cercano al umbral de
!>          desbordamiento.
!>

INFO

!>          INFO es INTEGER
!>          = 0:  salida exitosa
!>          = 1:  la iteración inversa no convergió; (VR,VI) se establece al
!>                último iterado.

LAPACK
DBLAEIN(3)

NAME

DBLAEIN - computes a specified right or left eigenvector of a real upper Hessenberg matrix by inverse iteration.

SYNOPSIS

      subroutine dblaein(rightv, noinit, n, h, ldh, wr, wi, vr, vi, b, ldb,
               work, eps3, smlnum, bignum, info)

Description

DBLAEIN uses inverse iteration to find a right or left eigenvector corresponding to the eigenvalue (WR,WI) of a real upper Hessenberg matrix H.

Purpose:

!>
!> DBLAEIN uses inverse iteration to find a right or left eigenvector
!> corresponding to the eigenvalue (WR,WI) of a real upper Hessenberg
!> matrix H.
!>

Parameters:

RIGHTV 
!>          RIGHTV is LOGICAL
!>          = .TRUE. : compute right eigenvector;
!>          = .FALSE.: compute left eigenvector.
!>

NOINIT

!>          NOINIT is LOGICAL
!>          = .TRUE. : no initial vector supplied in (VR,VI).
!>          = .FALSE.: initial vector supplied in (VR,VI).
!>

N

!>          N is INTEGER
!>          The order of the matrix H.  N >= 0.
!>

H

!>          H is DOUBLE PRECISION array, dimension (LDH,N)
!>          The upper Hessenberg matrix H.
!>

LDH

!>          LDH is INTEGER
!>          The leading dimension of the array H.  LDH >= max(1,N).
!>

WR

!>          WR is DOUBLE PRECISION
!>

WI

!>          WI is DOUBLE PRECISION
!>          The real and imaginary parts of the eigenvalue of H whose
!>          corresponding right or left eigenvector is to be computed.
!>

VR

!>          VR is DOUBLE PRECISION array, dimension (N)
!>

VI

!>          VI is DOUBLE PRECISION array, dimension (N)
!>          On entry, if NOINIT = .FALSE. and WI = 0.0, VR must contain
!>          a real starting vector for inverse iteration using the real
!>          eigenvalue WR; if NOINIT = .FALSE. and WI.ne.0.0, VR and VI
!>          must contain the real and imaginary parts of a complex
!>          starting vector for inverse iteration using the complex
!>          eigenvalue (WR,WI); otherwise VR and VI need not be set.
!>          On exit, if WI = 0.0 (real eigenvalue), VR contains the
!>          computed real eigenvector; if WI.ne.0.0 (complex eigenvalue),
!>          VR and VI contain the real and imaginary parts of the
!>          computed complex eigenvector. The eigenvector is normalized
!>          so that the component of largest magnitude has magnitude 1;
!>          here the magnitude of a complex number (x,y) is taken to be
!>          |x| + |y|.
!>          VI is not referenced if WI = 0.0.
!>

B

!>          B is DOUBLE PRECISION array, dimension (LDB,N)
!>

LDB

!>          The leading dimension of the array B.  LDB >= N+1.
!>

WORK

!>          WORK is DOUBLE PRECISION array, dimension (N)
!>

EPS3

!>          EPS3 is DOUBLE PRECISION
!>          A small machine-dependent value which is used to perturb
!>          close eigenvalues, and to replace zero pivots.
!>

SMLNUM

!>          SMLNUM is DOUBLE PRECISION
!>          A machine-dependent value close to the underflow threshold.
!>

BIGNUM

!>          BIGNUM is DOUBLE PRECISION
!>          A machine-dependent value close to the overflow threshold.
!>

INFO

!>          INFO is INTEGER
!>          = 0:  successful exit
!>          = 1:  inverse iteration did not converge; VR is set to the
!>                last iterate, and so is VI if WI.ne.0.0.
!>

Name

laein - laein

Synopsis

#include <laein.h>

int laein(int sockfd, const char *buf, int len);

Detailed Description

The laein function sends a message of length len from the buffer buf to the socket sockfd.

The function returns the number of bytes sent, or -1 if an error occurred.

Function Documentation

  • int laein(int sockfd, const char *buf, int len);
    • sockfd: The socket file descriptor.
    • buf: The buffer containing the message to send.
    • len: The length of the message in bytes.
    • Returns: The number of bytes sent, or -1 if an error occurred.
