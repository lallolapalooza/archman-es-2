LATEX2MAN(1) Herramientas de documentación LATEX2MAN(1)

NOMBRE

latex2man es una herramienta para traducir páginas del manual de UNIX escritas con LaTeX a un formato entendido por el comando man(1) de UNIX. Alternativamente, también se puede producir código HTML, TexInfo o LaTeX. La salida de partes del texto puede suprimirse utilizando la función de texto condicional (para esto, se puede usar la generación de LaTeX).

SINOPSIS

latex2man [-tarchivo_traduccion] [-carchivo_CSS] [-H] [-T] [-M] [-L] [-Cnombre] [-acaracter] archivo_entrada archivo_salida

DESCRIPCIÓN

Latex2man lee el archivo archivo_entrada y escribe archivo_salida. La entrada debe ser un documento LaTeX que utilice el paquete LaTeX latex2man. Latex2man traduce ese documento al formato de troff(1) utilizando el paquete de macros -man.

Usando la opción -H, se puede producir código HTML, en lugar de troff(1). Con esta opción, opcionalmente, puede especificar un archivo_CSS como argumento. CSS (Hojas de estilo en cascada) le permite controlar la apariencia de la página HTML resultante. Consulte más abajo los nombres de las clases CSS que se incluyen en las etiquetas HTML como atributos.

Usando la opción -T, se puede producir código TexInfo, en lugar de troff(1).

Usando la opción -M, se produce entrada para troff(1).

Usando la opción -L, se produce salida LaTeX, en lugar de troff(1).

OPCIONES

-tarchivo_traduccion

Traducción de macros LaTeX definidas por el usuario.
-carchivo_CSS

Si usa -H, también puede especificar un archivo que contenga hojas de estilo CSS. El enlace al archivo CSS se inserta en la salida HTML generada utilizando el nombre de archivo archivo_CSS especificado.
-M

Produce salida adecuada para el comando man(1) (por defecto).
-H

En lugar de producir una salida adecuada para el comando man(1), se produce código HTML (a pesar del nombre del comando).
-T

En lugar de producir una salida adecuada para el comando man(1), se produce código TexInfo (a pesar del nombre del comando). El archivo .texi generado puede ser procesado con makeinfo(1) (para producir un archivo .info) que a su vez puede ser instalado usando install-info(1). Se proporcionan las etiquetas Info @dircategory y @direntry.
-L

El código fuente LaTeX se escribe en el archivo_salida. Esto es útil en conjunción con la opción -Cnombre.
-Cnombre

Imprime el texto condicional para nombre. Si se deben dar varios nombres, use comillas: -C'nombre1 nombre2 ...'
Los siguientes nombres se definen automáticamente:
*
-H define HTML
*
-T define TEXI
*
-M define MAN
*
-L define LATEX
-acaracter

Se usa solo en conjunción con -T.
Contexto:
TexInfo ignora todos los espacios antes de la primera palabra en una nueva línea. Para producir un espacio adicional antes de esa palabra (usando \SP), se debe imprimir algún carácter antes del espacio adicional. Por defecto, es un . (punto). El caracter especifica una alternativa para ese primer carácter. Dar un espacio a -a suprime la indentación de una línea.
Nota: solo para el primer \SP de una serie se imprime ese caracter.
-h

Muestra un texto de ayuda.
-V

Muestra información de la versión.

COMANDOS LATEX

El paquete LaTeX latex2man se utiliza para escribir las páginas del manual con LaTeX. Dado que traducimos a otros formatos de texto, no todo el contenido de LaTeX se puede traducir.

OPCIONES DEL PAQUETE

El paquete latex2man acepta las siguientes opciones:

fancy
usa el paquete LaTeX fancyheadings.
fancyhdr
usa el paquete LaTeX fancyhdr.
nofancy
no se utilizan ni el paquete LaTeX fancyheadings ni fancyhdr.

La opción por defecto puede especificarse en el archivo latex2man.cfg.

ENTORNOS ESPECÍFICOS DEL PAQUETE

El paquete proporciona los siguientes entornos:

\begin{Name}{capítulo}{nombre}{autor}{info}{título}
El entorno Name toma cinco argumentos: 1. el capítulo de la página del manual, 2. el nombre de la página del manual, 3. el autor, 4. información breve sobre la herramienta impresa en el pie de página del manual, y 5. un texto que se utiliza como título, para HTML y LaTeX (se ignora para la salida de la página del manual o TeXinfo. El entorno Name debe ser el primer entorno del documento. El procesamiento comienza con este entorno. Se ignora cualquier texto anterior (excepción: los comandos setVersion y setDate). (Nota: todos los argumentos de \begin{Name} deben escribirse en una sola línea).
\begin{Table}[ancho]{columnas}
El entorno Table toma dos argumentos: el primero opcional especifica un ancho de la última columna, el segundo indica el número de columnas. Por ejemplo:

\begin{Table}[2cm]{3}
Aquí & va & yo \\\hline
A 1 & A 2 & A 3 1 2 3 4 5 A 3 1 2 3 4 5 \\
B 1 & B 2 & B 3 \\
\end{Table}

se compondrá como:

Aquí va yo
A 1 A 2 A 3 1 2 3 4 5 A 3 1 2 3 4 5
B 1 B 2 B 3

Si no se proporciona un argumento opcional de ancho, todas las entradas se componen justificadas a la izquierda. El ancho es una longitud medida absolutamente en cm. Procesando con LaTeX, una columna p{ancho} se compone como la última columna. La traducción a comandos de troff(1) resulta en una especificación de columna lw(ancho). La traducción a HTML y TexInfo ignora el parámetro de ancho.

\hline puede ser utilizado.

Si la página man se formatea con troff(1) y se utilizan tablas, se debe llamar al preprocesador tbl(1), generalmente proporcionando un -t a la llamada de troff(1). Al ver la página man generada usando man(1), tbl(1) se llama automáticamente.

MACROS ESPECÍFICOS DEL PAQUETE

Se proporcionan los siguientes comandos:

\Opt{opción}
Opción: \Opt{-o} se compondrá como -o.
\Arg{argumento}
Argumento: \Arg{nombrearchivo} se compondrá como nombrearchivo.
\OptArg{opción}{argumento}
Opción con Argumento:
\OptArg{-o}{nombrearchivo} se compondrá como -onombrearchivo.
\OptoArg{opción}{argumento}
Opción con Argumento Opcional:
\OptoArg{-o}{nombrearchivo} se compondrá como -o[nombrearchivo].
\oOpt{opción}
Opción opcional, por ejemplo, \oOpt{-o} se compondrá como [-o].
\oArg{argumento}

\oOptArg{-o}{nombrearchivo} se compondrá como [-onombrearchivo].
\oOptoArg{opción}{argumento}

\oOptoArg{-o}{nombrearchivo} se compondrá como [-o[nombrearchivo]].
\File{nombrearchivo}
se utiliza para componer nombres de archivo, por ejemplo, \File{nombrearchivo} se compondrá como nombrearchivo.
\Prog{prog}
se utiliza para componer nombres de programas, por ejemplo, \Prog{latex2man} se compondrá como latex2man.
\Cmd{comando}{capítulo}

latex2man [-Cname] [-ttransfile] [-ooutputfile] [-Iincludefile] [-|inputfile]

latex2man converts LaTeX man pages to various other formats like plain text, HTML or TexInfo.

The following LaTeX macros are used by latex2man:

Specifies the name of the man page (e.g. Name{ls}).

Specifies the version of the man page.

Specifies the section number of the man page.

Specifies the date of the man page.

Abstract
Contains the abstract of the man page.
Bugs

Contains the description of the command.

Contains examples of usage.

This is an example.

Contains a list of related man pages.
