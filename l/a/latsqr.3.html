CLATSQR

Propósito:

!>
!> CLATSQR calcula una factorización QR bloqueada de Tall-Skinny (alta y delgada) de
!> una matriz compleja M por N, A, para M >= N:
!>
!>    A = Q * ( R ),
!>            ( 0 )
!>
!> donde:
!>
!>    Q es una matriz ortogonal M por M, almacenada a la salida en forma implícita
!>    en los elementos debajo de la diagonal de la matriz A y en
!>    los elementos de la matriz T;
!>
!>    R es una matriz triangular superior N por N, almacenada a la salida en
!>    los elementos en y sobre la diagonal de la matriz A.
!>
!>    0 es una matriz cero (M-N) por N, y no se almacena.
!>
!>

Parámetros

M 
!>          M es ENTERO
!>          El número de filas de la matriz A.  M >= 0.
!>

N

!>          N es ENTERO
!>          El número de columnas de la matriz A. M >= N >= 0.
!>

MB

!>          MB es ENTERO
!>          El tamaño de bloque de fila a usar en la QR bloqueada.
!>          MB > N.
!>

NB

!>          NB es ENTERO
!>          El tamaño de bloque de columna a usar en la QR bloqueada.
!>          N >= NB >= 1.
!>

A

!>          A es matriz COMPLEJA, dimensión (LDA,N)
!>          En la entrada, la matriz M por N, A.
!>          A la salida, los elementos en y sobre la diagonal
!>          de la matriz contienen la matriz triangular superior R de N por N;
!>          los elementos debajo de la diagonal representan Q por las columnas
!>          de V bloqueada (ver Detalles Adicionales).
!>

LDA

!>          LDA es ENTERO
!>          La dimensión principal de la matriz A.  LDA >= max(1,M).
!>

T

!>          T es matriz COMPLEJA,
!>          dimensión (LDT, N * Número_de_bloques_de_fila)
!>          donde Número_de_bloques_de_fila = CEIL((M-N)/(MB-N))
!>          Los reflectores de bloque triangulares superiores bloqueados almacenados en forma compacta
!>          como una secuencia de bloques triangulares superiores.
!>          Ver Detalles Adicionales abajo.
!>

LDT

!>          LDT es ENTERO
!>          La dimensión principal de la matriz T.  LDT >= NB.
!>

WORK

!>          (espacio de trabajo) matriz COMPLEJA, dimensión (MAX(1,LWORK))
!>          A la salida, si INFO = 0, WORK(1) devuelve el LWORK mínimo.
!>

LWORK

!>          LWORK es ENTERO
!>          La dimensión de la matriz WORK.
!>          LWORK >= 1, si MIN(M,N) = 0, y LWORK >= NB*N en caso contrario.
!>
!>          Si LWORK = -1, entonces se asume una consulta de espacio de trabajo; la rutina
!>          solo calcula el tamaño mínimo de la matriz WORK, devuelve
!>          este valor como la primera entrada de la matriz WORK, y no se emite ningún mensaje de error
!>          relacionado con LWORK por XERBLA.
!>

INFO

!>          INFO es ENTERO
!>          = 0:  salida exitosa
!>          < 0:  si INFO = -i, el argumento i-ésimo tuvo un valor ilegal
!>

Detalles Adicionales:

!> QR de Tall-Skinny (TSQR) realiza QR mediante una secuencia de transformaciones ortogonales,
!> representando Q como un producto de otras matrices ortogonales
!>   Q = Q(1) * Q(2) * . . . * Q(k)
!> donde cada Q(i) pone a cero las entradas subdiagonales de un bloque de MB filas de A:
!>   Q(1) pone a cero las entradas subdiagonales de las filas 1:MB de A
!>   Q(2) pone a cero las filas MB-N inferiores de las filas [1:N,MB+1:2*MB-N] de A
!>   Q(3) pone a cero las filas MB-N inferiores de las filas [1:N,2*MB-N+1:3*MB-2*N] de A
!>   . . .
!>
!> Q(1) se calcula mediante GEQRT, que representa Q(1) mediante vectores de Householder
!> almacenados debajo de la diagonal de las filas 1:MB de A, y mediante reflectores de bloque
!> triangulares superiores, almacenados en la matriz T(1:LDT,1:N).
!> Para más información, ver Detalles Adicionales en GEQRT.
!>
!> Q(i) para i>1 se calcula mediante TPQRT, que representa Q(i) mediante vectores de Householder
!> almacenados en las filas [(i-1)*(MB-N)+N+1:i*(MB-N)+N] de A, y mediante reflectores de bloque
!> triangulares superiores, almacenados en la matriz T(1:LDT,(i-1)*N+1:i*N).
!> La última Q(k) puede usar menos filas.
!> Para más información, ver Detalles Adicionales en TPQRT.
!>
!> Para más detalles del algoritmo general, ver la descripción de
!> TSQR Secuencial en la Sección 2.2 de [1].
!>
!> [1] “Communication-Optimal Parallel and Sequential QR and LU Factorizations,”
!>     J. Demmel, L. Grigori, M. Hoemmen, J. Langou,
!>     SIAM J. Sci. Comput, vol. 34, no. 1, 2012
!>

NAME
       DLATSQR - computes the QR factorization of a real M-by-N matrix A
       for M >= N.

SYNOPSIS

       subroutine dlatsqr(integer m, integer n, integer mb, integer nb,
                          double precision, dimension( lda, * ) a, integer lda,
                          double precision, dimension( ldt, * ) t, integer ldt,
                          double precision, dimension( * ) work, integer lwork,
                          integer info)

       subroutine slatsqr(integer m, integer n, integer mb, integer nb,
                          real, dimension( lda, * ) a, integer lda,
                          real, dimension( ldt, * ) t, integer ldt,
                          real, dimension( * ) work, integer lwork,
                          integer info)

       subroutine zlatsqr(integer m, integer n, integer mb, integer nb,
                          complex*16, dimension( lda, * ) a, integer lda,
                          complex*16, dimension( ldt, * ) t, integer ldt,
                          complex*16, dimension( * ) work, integer lwork,
                          integer info)

DESCRIPTION
       DLATSQR computes a blocked Tall-Skinny QR factorization of a real
       M-by-N matrix A for M >= N:

          A = Q * ( R ),
                  ( 0 )

       where:

          Q is a M-by-M orthogonal matrix, stored on exit in an implicit
          form in the elements below the diagonal of the array A and in
          the elements of the array T;

          R is an upper-triangular N-by-N matrix, stored on exit in
          the elements on and above the diagonal of the array A.

          0 is a (M-N)-by-N zero matrix, and is not stored.

       SLATSQR computes a blocked Tall-Skinny QR factorization of a real
       M-by-N matrix A for M >= N.

       ZLATSQR computes a blocked Tall-Skinny QR factorization of a
       complex M-by-N matrix A for M >= N.

PARAMETERS

       M, N
              M is INTEGER
              The number of rows of the matrix A. M >= 0.
              N is INTEGER
              The number of columns of the matrix A. M >= N >= 0.

       MB, NB
              MB is INTEGER
              The row block size to be used in the blocked QR.
              MB > N.
              NB is INTEGER
              The column block size to be used in the blocked QR.
              N >= NB >= 1.

       A
              A is DOUBLE PRECISION, REAL, or COMPLEX*16 array, dimension
              (LDA,N)
              On entry, the M-by-N matrix A.
              On exit, the elements on and above the diagonal
              of the array contain the N-by-N upper triangular matrix R;
              the elements below the diagonal represent Q by the columns
              of blocked V (see Further Details).

       LDA
              LDA is INTEGER
              The leading dimension of the array A. LDA >= max(1,M).

       T
              T is DOUBLE PRECISION, REAL, or COMPLEX*16 array,
              dimension (LDT, N * Number_of_row_blocks)
              where Number_of_row_blocks = CEIL((M-N)/(MB-N))
              The blocked upper triangular block reflectors stored in compact form
              as a sequence of upper triangular blocks.
              See Further Details below.

       LDT
              LDT is INTEGER
              The leading dimension of the array T. LDT >= NB.

       WORK
              WORK is DOUBLE PRECISION, REAL, or COMPLEX*16 array, dimension
              (MAX(1,LWORK))
              On exit, if INFO = 0, WORK(1) returns the minimal LWORK.

       LWORK
              LWORK is INTEGER
              The dimension of the array WORK.
              LWORK >= 1, if MIN(M,N) = 0, and LWORK >= NB*N, otherwise.

              If LWORK = -1, then a workspace query is assumed; the routine
              only calculates the minimal size of the WORK array, returns
              this value as the first entry of the WORK array, and no error
              message related to LWORK is issued by XERBLA.

       INFO
              INFO is INTEGER
              = 0:  successful exit
              < 0:  if INFO = -i, the i-th argument had an illegal value

AUTHOR
       Univ. of Tennessee
       Univ. of California Berkeley
       Univ. of Colorado Denver
       NAG Ltd.

Further Details:
       Tall-Skinny QR (TSQR) performs QR by a sequence of orthogonal transformations,
       representing Q as a product of other orthogonal matrices
         Q = Q(1) * Q(2) * . . . * Q(k)
       where each Q(i) zeros out subdiagonal entries of a block of MB rows of A:
         Q(1) zeros out the subdiagonal entries of rows 1:MB of A
         Q(2) zeros out the bottom MB-N rows of rows [1:N,MB+1:2*MB-N] of A
         Q(3) zeros out the bottom MB-N rows of rows [1:N,2*MB-N+1:3*MB-2*N] of A
         . . .

       Q(1) is computed by GEQRT, which represents Q(1) by Householder vectors
       stored under the diagonal of rows 1:MB of A, and by upper triangular
       block reflectors, stored in array T(1:LDT,1:N).
       For more information see Further Details in GEQRT.

       Q(i) for i>1 is computed by TPQRT, which represents Q(i) by Householder vectors
       stored in rows [(i-1)*(MB-N)+N+1:i*(MB-N)+N] of A, and by upper triangular
       block reflectors, stored in array T(1:LDT,(i-1)*N+1:i*N).
       The last Q(k) may use fewer rows.
       For more information see Further Details in TPQRT.

       For more details of the overall algorithm, see the description of
       Sequential TSQR in Section 2.2 of [1].

       [1] “Communication-Optimal Parallel and Sequential QR and LU Factorizations,”
          J. Demmel, L. Grigori, M. Hoemmen, J. Langou,
          SIAM J. Sci. Comput, vol. 34, no. 1, 2012

NAME


latsqr - reconstructs the matrix Q from a previous QR factorization computed by TSQR algorithms.






SYNOPSIS


SUBROUTINE LATSQR(A, TA, T, LDT, WORK, LWORK, INFO)
    IMPLICIT NONE
    INTEGER LDT, LWORK, INFO
    COMPLEX*16 A( * )
    COMPLEX*16 TA( * )
    COMPLEX*16 T( LDT, * )
    COMPLEX*16 WORK( * )







Detailed Description


LATSQR computes the Q factor of a sparse QR factorization that has been
    computed by the TSQR algorithms. The TSQR algorithms are a family of QR
    factorization routines designed to be communication-optimal for various
    architectures.


The input matrix A is overwritten by the Q factor. The input array TA
    is used to store the Householder vectors used to compute Q.


The output array T is used to store the upper triangular block
    reflectors.


The algorithm used by LATSQR is based on the work of Demmel, et al.
    It uses a sequence of Householder transformations to zero out subdiagonal
    elements in a block-wise fashion, similar to GEQRT and TPQRT.






Function Documentation




A


(input/output) COMPLEX*16 array, dimension (MAX(1,M*N))
    On entry, A contains the matrix R from the QR factorization. On exit, A
    contains the matrix Q.


The matrix A is assumed to be partitioned into NB x N blocks. The
    Householder vectors are stored in the lower triangular part of the array
    under the diagonal.


TA


(input) COMPLEX*16 array, dimension (MAX(1,LTA))
    The array TA stores the Householder vectors used to compute Q.


The dimensions of TA depend on the algorithm used to compute the
    QR factorization. See Further Details below.


T


(output) COMPLEX*16 array, dimension (LDT,N)
    The array T stores the upper triangular block reflectors that represent the
    orthogonal matrix Q.


LDT


(input) INTEGER
    The leading dimension of the array T. LDT >= NB.


WORK


(workspace) COMPLEX*16 array, dimension (MAX(1,LWORK))
    On exit, if INFO = 0, WORK(1) returns the minimal LWORK.


LWORK


(input) INTEGER
    The dimension of the array WORK. LWORK >= 1, if MIN(M,N) = 0, and LWORK
    >= NB*N, otherwise.


If LWORK = -1, then a workspace query is assumed; the routine only
    calculates the minimal size of the WORK array, returns this value as the
    first entry of the WORK array, and no error message related to LWORK is
    issued by XERBLA.


INFO


(output) INTEGER
    = 0: successful exit
    < 0: if INFO = -i, the i-th argument had an illegal value
