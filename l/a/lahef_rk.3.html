CLAHEF_RK calcula una factorización parcial de una matriz Hermítica compleja indefinida utilizando el método de pivoteo diagonal acotado de Bunch-Kaufman (rook).

Propósito:

!> CLAHEF_RK calcula una factorización parcial de una matriz Hermítica
!> compleja A utilizando el método de pivoteo diagonal acotado de
!> Bunch-Kaufman (rook). La factorización parcial tiene la forma:
!>
!> A  =  ( I  U12 ) ( A11  0  ) (  I       0    )  si UPLO = 'U', o:
!>       ( 0  U22 ) (  0   D  ) ( U12**H U22**H )
!>
!> A  =  ( L11  0 ) (  D   0  ) ( L11**H L21**H )  si UPLO = 'L',
!>       ( L21  I ) (  0  A22 ) (  0       I    )
!>
!> donde el orden de D es como máximo NB. El orden real se devuelve en
!> el argumento KB, y es NB o NB-1, o N si N <= NB.
!>
!> CLAHEF_RK es una subrutina auxiliar llamada por CHETRF_RK. Utiliza
!> código bloqueado (llamando a BLAS de Nivel 3) para actualizar la submatriz
!> A11 (si UPLO = 'U') o A22 (si UPLO = 'L').
!>

!>          UPLO es CHARACTER*1
!>          Especifica si la parte triangular superior o inferior de la
!>          matriz Hermítica A está almacenada:
!>          = 'U':  Triangular superior
!>          = 'L':  Triangular inferior
!>

N

!>          N es INTEGER
!>          El orden de la matriz A.  N >= 0.
!>

NB

!>          NB es INTEGER
!>          El número máximo de columnas de la matriz A que deben
!>          factorizarse.  NB debe ser al menos 2 para permitir bloques
!>          de pivote de 2x2.
!>

KB

!>          KB es INTEGER
!>          El número de columnas de A que se factorizaron realmente.
!>          KB es NB-1 o NB, o N si N <= NB.
!>

A

!>          A es un array COMPLEX de dimensión (LDA,N)

!>            se referencia.
!>
!>            Si UPLO = 'L': la parte triangular inferior N por N líder
!>            de A contiene la parte triangular inferior de la matriz A,
!>            y la parte estrictamente triangular superior de A no
!>            se referencia.
!>
!>          En la salida, contiene:
!>            a) SÓLO elementos diagonales de la matriz diagonal por bloques
!>               Hermítica D en la diagonal de A, es decir, D(k,k) = A(k,k);
!>               (los elementos supradiagonales (o subdiagonales) de D
!>                se almacenan en la salida en el array E), y
!>            b) Si UPLO = 'U': factor U en la parte supradiagonal de A.
!>               Si UPLO = 'L': factor L en la parte subdiagonal de A.
!>

LDA

!>          LDA es INTEGER
!>          La dimensión líder del array A.  LDA >= max(1,N).
!>

E

!>          E es un array COMPLEX de dimensión (N)
!>          En la salida, contiene los elementos supradiagonales (o subdiagonales)
!>          de la matriz diagonal por bloques Hermítica D
!>          con bloques diagonales de 1x1 o 2x2, donde
!>          Si UPLO = 'U': E(i) = D(i-1,i), i=2:N, E(1) se establece en 0;
!>          Si UPLO = 'L': E(i) = D(i+1,i), i=1:N-1, E(N) se establece en 0.
!>
!>          NOTA: Para un bloque diagonal de 1x1 D(k), donde
!>          1 <= k <= N, el elemento E(k) se establece en 0 en ambos
!>          casos UPLO = 'U' o UPLO = 'L'.
!>

IPIV

!>          IPIV es un array INTEGER de dimensión (N)
!>          IPIV describe la matriz de permutación P en la factorización
!>          de la matriz A de la siguiente manera. El valor absoluto de IPIV(k)
!>          representa el índice de fila y columna que fueron
!>          intercambiados con la k-ésima fila y columna. El valor de UPLO
!>          describe el orden en que se aplicaron los intercambios.
!>          Además, el signo de IPIV representa la estructura de bloques de
!>          la matriz diagonal por bloques Hermítica D con bloques diagonales
!>          de 1x1 o 2x2 que corresponden a 1 o 2 intercambios
!>          en cada paso de factorización.
!>
!>          Si UPLO = 'U',
!>          (en orden de factorización, k disminuye de N a 1):
!>            a) Una única entrada positiva IPIV(k) > 0 significa:
!>               D(k,k) es un bloque diagonal de 1x1.
!>               Si IPIV(k) != k, las filas y columnas k e IPIV(k) fueron
!>               intercambiadas en la submatriz A(1:N,N-KB+1:N);
!>               Si IPIV(k) = k, no ocurrió ningún intercambio.
!>
!>
!>            b) Un par de entradas consecutivas negativas
!>               IPIV(k) < 0 y IPIV(k-1) < 0 significa:
!>               D(k-1:k,k-1:k) es un bloque diagonal de 2x2.
!>               (NOTA: las entradas negativas en IPIV aparecen SÓLO en pares).

!>                  k y -IPIV(k) fueron intercambiadas
!>                  en la matriz A(1:N,N-KB+1:N).
!>                  Si -IPIV(k) = k, no ocurrió ningún intercambio.
!>               2) Si -IPIV(k-1) != k-1, las filas y columnas
!>                  k-1 y -IPIV(k-1) fueron intercambiadas
!>                  en la submatriz A(1:N,N-KB+1:N).
!>                  Si -IPIV(k-1) = k-1, no ocurrió ningún intercambio.
!>
!>            c) En ambos casos a) y b) siempre se cumple ABS( IPIV(k) ) <= k.
!>
!>            d) NOTA: Cualquier entrada IPIV(k) es siempre DISTINTA DE CERO en la salida.
!>
!>          Si UPLO = 'L',
!>          (en orden de factorización, k aumenta de 1 a N):
!>            a) Una única entrada positiva IPIV(k) > 0 significa:
!>               D(k,k) es un bloque diagonal de 1x1.
!>               Si IPIV(k) != k, las filas y columnas k e IPIV(k) fueron
!>               intercambiadas en la submatriz A(1:N,1:KB).
!>               Si IPIV(k) = k, no ocurrió ningún intercambio.
!>
!>            b) Un par de entradas consecutivas negativas
!>               IPIV(k) < 0 y IPIV(k+1) < 0 significa:
!>               D(k:k+1,k:k+1) es un bloque diagonal de 2x2.
!>               (NOTA: las entradas negativas en IPIV aparecen SÓLO en pares).
!>               1) Si -IPIV(k) != k, las filas y columnas
!>                  k y -IPIV(k) fueron intercambiadas
!>                  en la submatriz A(1:N,1:KB).
!>                  Si -IPIV(k) = k, no ocurrió ningún intercambio.

Purpose: CLASYF_RK computes a partial factorization of a complex symmetric matrix A using the bounded Bunch-Kaufman (rook) diagonal pivoting method. The partial factorization has the form: A = ( I U12 ) ( A11 0 ) ( I 0 ) if UPLO = 'U', or: ( 0 U22 ) ( 0 D ) ( U12**T U22**T ) A = ( L11 0 ) ( D 0 ) ( L11**T L21**T ) if UPLO = 'L', ( L21 I ) ( 0 A22 ) ( 0 I ) where the order of D is at most NB. The actual order is returned in the argument KB, and is either NB or NB-1, or N if N <= NB. CLASYF_RK is an auxiliary routine called by CSYTRF_RK. It uses blocked code (calling Level 3 BLAS) to update the submatrix A11 (if UPLO = 'U') or A22 (if UPLO = 'L'). Parameters UPLO UPLO is CHARACTER*1 Specifies whether the upper or lower triangular part of the symmetric matrix A is stored: = 'U': Upper triangular = 'L': Lower triangular N N is INTEGER The order of the matrix A. N >= 0. NB NB is INTEGER The maximum number of columns of the matrix A that should be factored. NB should be at least 2 to allow for 2-by-2 pivot blocks. KB KB is INTEGER The number of columns of A that were actually factored. KB is either NB-1 or NB, or N if N <= NB. A A is COMPLEX array, dimension (LDA,N) On entry, the symmetric matrix A. If UPLO = 'U': the leading N-by-N upper triangular part of A contains the upper triangular part of the matrix A, and the strictly lower triangular part of A is not referenced. If UPLO = 'L': the leading N-by-N lower triangular part of A contains the lower triangular part of the matrix A, and the strictly upper triangular part of A is not referenced. SLASYF_RK Computes a partial factorization of a real symmetric matrix using the bounded Bunch-Kaufman (rook) diagonal pivoting method. The partial factorization has the form:

A  =  ( I  U12 ) ( A11  0  ) (  I       0    )  if UPLO = 'U', or:
      ( 0  U22 ) (  0   D  ) ( U12**T U22**T )

A  =  ( L11  0 ) (  D   0  ) ( L11**T L21**T )  if UPLO = 'L',
      ( L21  I ) (  0  A22 ) (  0       I    )

where the order of D is at most NB. The actual order is returned in the argument KB, and is either NB or NB-1, or N if N <= NB.

SLASYF_RK is an auxiliary routine called by SSYTRF_RK. It uses blocked code (calling Level 3 BLAS) to update the submatrix A11 (if UPLO = 'U') or A22 (if UPLO = 'L').

Detailed Description

This routine is deprecated. Use "zasyf" instead.

This routine computes the factorization of a complex symmetric/Hermitian matrix A in the form

    A = P * U * D * U**H * P**H

or

    A = P * L * D * L**H * P**H

where U is a structured upper triangular matrix, L is a structured lower triangular matrix, D is a symmetric/Hermitian block diagonal matrix with 1-by-1 or 2-by-2 diagonal blocks.

P is a permutation matrix. U and L are not triangular matrices but block triangular matrices. The aim of the routine is to compute the factorization of A and then to use it to solve systems of linear equations.

In the two implementations described in this section, U and L are not strictly upper or lower triangular matrices. The entries of U below the k-th superdiagonal are zero, and the entries of L above the k-th subdiagonal are zero. The diagonal entries of U and L are all one. D is a symmetric/Hermitian block diagonal matrix with 1-by-1 or 2-by-2 blocks.

The matrix D is computed by the routine. The entries of U and L are computed implicitly by the routine. The matrix P is computed implicitly by the routine.

The array IPIV is used to store the permutation matrix P, and the block diagonal matrix D.

The absolute value of IPIV(k) represents the index of row and column that were interchanged with the k-th row and column. The value of UPLO describes the order in which the interchanges were applied.
