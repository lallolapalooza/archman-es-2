Documentación de la función

subrutina dlaed3 (integer k, integer n, integer n1, double precision, dimension( * ) d, double precision, dimension( ldq, * ) q, integer ldq, double precision rho, double precision, dimension( * ) dlambda, double precision, dimension( * ) q2, integer, dimension( * ) indx, integer, dimension( * ) ctot, double precision, dimension( * ) w, double precision, dimension( * ) s, integer info)

DLAED3 utilizada por DSTEDC. Encuentra las raíces de la ecuación secular y actualiza los vectores propios. Utilizada cuando la matriz original es tridiagonal.

Propósito:

!>
!> DLAED3 encuentra las raíces de la ecuación secular, tal como se define por
!> los valores en D, W y RHO, entre 1 y K. Realiza las llamadas apropiadas
!> a DLAED4 y luego actualiza los vectores propios multiplicando la matriz
!> de vectores propios del par de sistemas de ecuaciones propios que se
!> combinan por la matriz de vectores propios del sistema KxK que se
!> resuelve aquí.
!>
!>

Parámetros

K 
!>          K es INTEGER
!>          El número de términos en la función racional que debe ser
!>          resuelta por DLAED4.  K >= 0.
!>

N

!>          N es INTEGER
!>          El número de filas y columnas en la matriz Q.
!>          N >= K (la deflación puede resultar en N>K).
!>

N1

!>          N1 es INTEGER
!>          La ubicación del último valor propio en la submatriz principal.
!>          min(1,N) <= N1 <= N/2.
!>

D

!>          D es un array DOUBLE PRECISION, de dimensión (N)
!>          D(I) contiene los valores propios actualizados para
!>          1 <= I <= K.
!>

Q

!>          Q es un array DOUBLE PRECISION, de dimensión (LDQ,N)
!>          Inicialmente, las primeras K columnas se utilizan como espacio de
!>          trabajo. En la salida, las columnas 1 a K contienen los vectores
!>          propios actualizados.
!>

LDQ

!>          LDQ es INTEGER
!>          La dimensión principal del array Q.  LDQ >= max(1,N).
!>

RHO

!>          RHO es DOUBLE PRECISION
!>          El valor del parámetro en la ecuación de actualización de rango
!>          uno. Se requiere RHO >= 0.
!>

DLAMBDA

!>          DLAMBDA es un array DOUBLE PRECISION, de dimensión (K)
!>          Los primeros K elementos de este array contienen las raíces
!>          antiguas del problema de actualización desinflado. Estos son los
!>          polos de la ecuación secular.
!>

Q2

!>          Q2 es un array DOUBLE PRECISION, de dimensión (LDQ2*N)
!>          Las primeras K columnas de esta matriz contienen los vectores
!>          propios no desinflados para el problema dividido.
!>

INDX

!>          INDX es un array INTEGER, de dimensión (N)
!>          La permutación utilizada para organizar las columnas de la matriz
!>          Q desinflada en tres grupos (ver DLAED2). Las filas de los
!>          vectores propios encontrados por DLAED4 deben ser permutadas
!>          de manera similar antes de que se pueda realizar la multiplicación
!>          de matrices.
!>

CTOT

!>          CTOT es un array INTEGER, de dimensión (4)
!>          Un recuento del número total de los diversos tipos de columnas
!>          en Q, como se describe en INDX. El cuarto tipo de columna es
!>          cualquier columna que haya sido desinflada.
!>

W

!>          W es un array DOUBLE PRECISION, de dimensión (K)
!>          Los primeros K elementos de este array contienen los componentes
!>          del vector de actualización ajustado por deflación. Se destruye
!>          en la salida.
!>

S

!>          S es un array DOUBLE PRECISION, de dimensión (N1 + 1)*K
!>          Contendrá los vectores propios de la matriz reparada que se
!>          multiplicarán por los vectores propios acumulados previamente
!>          para actualizar el sistema.
!>

INFO

!>          INFO es INTEGER
!>          = 0:  salida exitosa.
!>          < 0:  si INFO = -i, el i-ésimo argumento tenía un valor ilegal.
!>          > 0:  si INFO = 1, un valor propio no convergió.
!>
