lavtrans(1) Manual de MJPEG tools lavtrans(1)

NOMBRE

lavtrans - Convertir vídeos MJPEG a otros formatos de vídeo MJPEG

SINOPSIS

lavtrans -o archivo_salida -f a|q|i|w [-i num] archivo_lav1 [archivo_lav2 ... archivo_lavN]

DESCRIPCIÓN

lavtrans se puede usar para convertir los vídeos grabados de un formato de "contenedor" MJPEG a otro. También se puede usar para dividir las secuencias o realizar ediciones destructivas.

Al igual que todas las demás herramientas de mjpegtools(1), lavtrans también acepta un archivo de lista de edición en lugar de archivos de vídeo reales. Esto permite usarlo para construir una copia independiente de la secuencia de vídeo editada descrita en la lista de edición.

Tenga en cuenta que lavtrans solo puede cambiar el tipo de contenedor de vídeo MJPEG, no el formato. Como tal, no es posible usarlo para combinar secuencias de diferentes formatos.

OPCIONES

lavtrans acepta las siguientes opciones:

-f [a|q|m|i|w]
Especifica el formato de salida que se debe guardar.
a - salida a archivo AVI
q - salida a archivo Quicktime
i - salida de imágenes JPEG individuales,
w - salida de archivo WAV (¡solo sonido!)
-i num
Convertir un solo fotograma a un archivo JPEG.
-o archivo_salida
Especifica el nombre del archivo de salida. Si desea que la salida sean imágenes JPEG individuales, la cadena del archivo de salida debe ser un formato de cadena válido.
nombre_archivo
Se aceptan múltiples nombres de archivo de entrada, así como la mezcla de archivos de lista de edición y otros archivos de vídeo.

ERRORES

Parece haber problemas con la transcodificación de películas Quicktime grandes. Otra cosa es que con las películas entrelazadas solo se extrae un campo. Por lo tanto, obtienes imágenes con el tamaño horizontal completo y la mitad del tamaño vertical.
