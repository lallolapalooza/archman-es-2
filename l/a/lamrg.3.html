subrutina dlamrg (entero n1, entero n2, doble precisión, dimensión( * ) a, entero dtrd1, entero dtrd2, entero, dimensión( * ) index)

DLAMRG crea una lista de permutación para fusionar las entradas de dos conjuntos ordenados independientemente en un único conjunto ordenado en orden ascendente.

Propósito:

!>
!> DLAMRG creará una lista de permutación que fusionará los elementos
!> de A (que está compuesto por dos conjuntos ordenados independientemente) en un
!> único conjunto que está ordenado en orden ascendente.
!>

Parámetros

N1 
!>          N1 es ENTERO
!>

N2

!>          N2 es ENTERO
!>         Estos argumentos contienen las longitudes respectivas de las dos
!>         listas ordenadas a fusionar.
!>

A

!>          A es un array de DOBLE PRECISIÓN, dimensión (N1+N2)
!>         Los primeros N1 elementos de A contienen una lista de números que
!>         están ordenados en orden ascendente o descendente. Igualmente
!>         para los últimos N2 elementos.
!>

DTRD1

!>          DTRD1 es ENTERO
!>

DTRD2

!>          DTRD2 es ENTERO
!>         Estos son los saltos que se darán a través del array A.
!>         Los saltos permitidos son 1 y -1. Indican si un subconjunto
!>         de A está ordenado en orden ascendente (DTRDx = 1) o descendente
!>         (DTRDx = -1).
!>

INDEX

!>          INDEX es un array de ENTEROS, dimensión (N1+N2)
!>         A la salida, este array contendrá una permutación tal que
!>         si B( I ) = A( INDEX( I ) ) para I=1,N1+N2, entonces B estará
!>         ordenado en orden ascendente.
!>
