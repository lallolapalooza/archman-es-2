NOMBRE

lament - anima la configuración de Lament

SINOPSIS

lament [--display host:display.screen] [--window] [--root] [--window-id numero][--install] [--visual visual] [--delay microsegundos] [--fps] [--texture] [--no-texture] [--wireframe]

DESCRIPCIÓN

El programa lament dibuja una animación de una caja de puzle particular resolviéndose repetidamente.

OPCIONES

lament acepta las siguientes opciones:

--window
Dibuja en una ventana recién creada. Este es el valor predeterminado.
--root
Dibuja en la ventana raíz.
--window-id numero
Dibuja en la ventana especificada.
--install
Instala un mapa de colores privado para la ventana.
--visual visual
Especifica qué visual usar. Los valores legales son el nombre de una clase visual, o el número de ID (decimal o hexadecimal) de un visual específico.
--texture
Usa mapas de texturas. Este es el valor predeterminado.
--no-texture
No uses mapas de texturas. Esto es aburrido y está mal.
--wireframe
Dibuja solo contornos.
--delay microsegundos
Cuánto pausar entre fotogramas. El valor predeterminado es 20000, o 0.02 segundos.
--fps
Muestra la velocidad de fotogramas actual, la carga de la CPU y el recuento de polígonos.

ENTORNO

DISPLAY
para obtener el host y el número de pantalla predeterminados.
XENVIRONMENT
para obtener el nombre de un archivo de recursos que anula los recursos globales almacenados en la propiedad RESOURCE_MANAGER.
XSCREENSAVER_WINDOW
El ID de ventana a usar con --root.

ERRORES

Este truco es glacialmente lento en máquinas que carecen de soporte de texturas por hardware.

Ocasionalmente abre puertas, admitiendo teólogos de la Orden del Rasguño.
