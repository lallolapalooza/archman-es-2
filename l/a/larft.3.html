CLARFT forma el factor triangular T de un reflector de bloque H = I - vtvH

Propósito:

!>
!> CLARFT forma el factor triangular T de un reflector de bloque complejo H
!> de orden n, que se define como un producto de k reflectores elementales.
!>
!> Si DIRECT = 'F', H = H(1) H(2) . . . H(k) y T es triangular superior;
!>
!> Si DIRECT = 'B', H = H(k) . . . H(2) H(1) y T es triangular inferior.
!>
!> Si STOREV = 'C', el vector que define el reflector elemental
!> H(i) se almacena en la i-ésima columna de la matriz V, y
!>
!>    H  =  I - V * T * V**H
!>
!> Si STOREV = 'R', el vector que define el reflector elemental
!> H(i) se almacena en la i-ésima fila de la matriz V, y
!>
!>    H  =  I - V**H * T * V
!>

Parámetros

DIRECT 
!>          DIRECT es CHARACTER*1
!>          Especifica el orden en el que se multiplican los reflectores
!>          elementales para formar el reflector de bloque:
!>          = 'F': H = H(1) H(2) . . . H(k) (Adelante)
!>          = 'B': H = H(k) . . . H(2) H(1) (Atrás)
!>

STOREV

!>          STOREV es CHARACTER*1
!>          Especifica cómo se almacenan los vectores que definen los
!>          reflectores elementales (ver también Detalles Adicionales):
!>          = 'C': por columnas
!>          = 'R': por filas
!>

N

!>          N es INTEGER
!>          El orden del reflector de bloque H. N >= 0.
!>

K

!>          K es INTEGER
!>          El orden del factor triangular T (= el número de
!>          reflectores elementales). K >= 1.
!>

V

!>          V es una matriz COMPLEX, dimensión
!>                               (LDV,K) si STOREV = 'C'
!>                               (LDV,N) si STOREV = 'R'
!>          La matriz V. Ver detalles adicionales.
!>

LDV

!>          LDV es INTEGER
!>          La dimensión principal de la matriz V.
!>          Si STOREV = 'C', LDV >= max(1,N); si STOREV = 'R', LDV >= K.
!>

TAU

!>          TAU es una matriz COMPLEX, dimensión (K)
!>          TAU(i) debe contener el factor escalar del reflector
!>          elemental H(i).
!>

T

!>          T es una matriz COMPLEX, dimensión (LDT,K)
!>          El factor triangular T de k por k del reflector de bloque.
!>          Si DIRECT = 'F', T es triangular superior; si DIRECT = 'B', T es
!>          triangular inferior. El resto de la matriz no se utiliza.
!>

LDT

!>          LDT es INTEGER
!>          La dimensión principal de la matriz T. LDT >= K.
!>

LARFT(3) LAPACK "Linear Algebra Package" LARFT(3)

NAME

larft, larfb - forms the triangular factor of a block reflector or applies a block reflector.

SYNOPSIS 

SUBROUTINE LARFT(JOBU, LAYOUT, N, K, A, LDA, TAU, T, LDT)

SUBROUTINE LARFB(SIDE, TRANS, LAYOUT, DIRECT, STOREZ, N, M, K,
                 V, LDV, TAU, T, LDT, C, LDC, WORK, LDWORK)

Detailed Description

This routine is part of the LAPACK routines for performing the reduced QR factorization of a rectangular matrix A, which is partitioned into a block matrix. The reduction is based on Householder reflectors. The blocked algorithm is described in Chapter 3 of the LAPACK Users' Guide.

LARFT forms the triangular factor T of a block reflector H = I - tau * V * V' where V is a rectangular matrix.

LARFB applies a block reflector H or its transpose H' to a real rectangular matrix.

Function Documentation

LARFT

LARFT performs the following steps:

  1. Compute the triangular factor T of the block reflector H = I - tau * V * T.
  2. Store T.

Parameters:

  • JOBU (input) CHARACTER*1
    • 'X': The matrix U is not needed.
    • 'U': U is computed and returned.
  • LAYOUT (input) CHARACTER*1
    • 'R': Row-major storage
    • 'C': Column-major storage
  • N (input) INTEGER The number of columns of the matrix V.
  • K (input) INTEGER The number of rows of the matrix V.
  • A (input) DOUBLE PRECISION array, dimension (LDA,K) On entry, the matrix V.
  • LDA (input) INTEGER The leading dimension of the array A.
  • TAU (input) DOUBLE PRECISION array, dimension (K) The scalar factors of the elementary reflectors.
  • T (output) DOUBLE PRECISION array, dimension (LDT,K) On exit, T is the upper triangular factor of the block reflector.
  • LDT (input) INTEGER The leading dimension of the array T.
LARFB

LARFB applies the block reflector H to the matrix C as follows:

If SIDE = 'L' (Left) C = H * C

If SIDE = 'R' (Right) C = C * H

where H = I - tau * V * T * V' is a block reflector.

Parameters:

  • SIDE (input) CHARACTER*1
    • 'L': Apply H from the left.
    • 'R': Apply H from the right.
  • TRANS (input) CHARACTER*1
    • 'N': Apply H.
    • 'T': Apply the transpose of H.
  • LAYOUT (input) CHARACTER*1
    • 'R': Row-major storage
    • 'C': Column-major storage
  • DIRECT (input) CHARACTER*1
    • 'F': H is formed by forward application of reflectors.
    • 'B': H is formed by backward application of reflectors.
  • STOREZ (input) CHARACTER*1
    • 'R': The Z matrix is stored in row-major format.
    • 'C': The Z matrix is stored in column-major format.
  • N (input) INTEGER The number of rows of C.
  • M (input) INTEGER The number of columns of C.
  • K (input) INTEGER The number of rows of V.
  • V (input) DOUBLE PRECISION array, dimension (LDV,K) The matrix V.
  • LDV (input) INTEGER The leading dimension of the array V.
  • TAU (input) DOUBLE PRECISION array, dimension (K) The scalar factors of the elementary reflectors.
  • T (input) DOUBLE PRECISION array, dimension (LDT,K) The upper triangular factor of the block reflector.
  • LDT (input) INTEGER The leading dimension of the array T.
  • C (input/output) DOUBLE PRECISION array, dimension (LDC,M) On entry, the matrix to which the transformation is applied. On exit, the transformed matrix.
  • LDC (input) INTEGER The leading dimension of the array C.
  • WORK (workspace) DOUBLE PRECISION array, dimension (LDWORK,M)
  • LDWORK (input) INTEGER The leading dimension of the array WORK.
