CLA_GEAMV calcula el producto de una matriz y un vector usando una matriz general para calcular cotas de error.

Propósito:

!>
!> CLA_GEAMV  realiza una de las siguientes operaciones de matriz-vector:
!>
!>         y := alpha*abs(A)*abs(x) + beta*abs(y),
!>    o    y := alpha*abs(A)**T*abs(x) + beta*abs(y),
!>
!> donde alpha y beta son escalares, x e y son vectores y A es una
!> matriz de m por n.
!>
!> Esta función se utiliza principalmente para calcular cotas de error.
!> Para protegerse contra el subdesbordamiento durante la evaluación, los
!> componentes del vector resultante se perturban lejos de cero en (N+1)
!> veces el umbral de subdesbordamiento. Para evitar errores innecesariamente
!> grandes para la estructura de bloques incrustada en matrices generales,
!> los componentes cero no se perturban. Un componente cero se considera
!> si todas las multiplicaciones involucradas en el cálculo de ese componente
!> tienen al menos un multiplicando cero.
!>

Parámetros

TRANS 
!>          TRANS es ENTERO
!>           En la entrada, TRANS especifica la operación a realizar como
!>           sigue:
!>
!>             BLAS_NO_TRANS      y := alpha*abs(A)*abs(x) + beta*abs(y)
!>             BLAS_TRANS         y := alpha*abs(A**T)*abs(x) + beta*abs(y)
!>             BLAS_CONJ_TRANS    y := alpha*abs(A**T)*abs(x) + beta*abs(y)
!>
!>           Sin cambios en la salida.
!>

M

!>          M es ENTERO
!>           En la entrada, M especifica el número de filas de la matriz A.
!>           M debe ser al menos cero.
!>           Sin cambios en la salida.
!>

N

!>          N es ENTERO
!>           En la entrada, N especifica el número de columnas de la matriz A.
!>           N debe ser al menos cero.
!>           Sin cambios en la salida.
!>

ALPHA

!>          ALPHA es REAL
!>           En la entrada, ALPHA especifica el escalar alpha.
!>           Sin cambios en la salida.
!>

A

!>          A es un array COMPLEJO, dimensión (LDA,n)
!>           Antes de la entrada, la parte principal de m por n del array A debe
!>           contener la matriz de coeficientes.
!>           Sin cambios en la salida.
!>

LDA

!>          LDA es ENTERO
!>           En la entrada, LDA especifica la primera dimensión de A tal como está
!>           declarada en el programa (sub)llamador. LDA debe ser al menos
!>           max( 1, m ).
!>           Sin cambios en la salida.
!>

X

!>          X es un array COMPLEJO, dimensión
!>           ( 1 + ( n - 1 )*abs( INCX ) ) cuando TRANS = 'N' o 'n'
!>           y al menos
!>           ( 1 + ( m - 1 )*abs( INCX ) ) en caso contrario.
!>           Antes de la entrada, el array X incrementado debe contener el
!>           vector x.
!>           Sin cambios en la salida.
!>

INCX

!>          INCX es ENTERO
!>           En la entrada, INCX especifica el incremento para los elementos de
!>           X. INCX no debe ser cero.
!>           Sin cambios en la salida.
!>

BETA

!>          BETA es REAL
!>           En la entrada, BETA especifica el escalar beta. Cuando BETA se
!>           proporciona como cero, Y no necesita establecerse en la entrada.
!>           Sin cambios en la salida.
!>

Y

!>          Y es un array REAL, dimensión
!>           ( 1 + ( m - 1 )*abs( INCY ) ) cuando TRANS = 'N' o 'n'
!>           y al menos
!>           ( 1 + ( n - 1 )*abs( INCY ) ) en caso contrario.
!>           Antes de la entrada con BETA distinto de cero, el array Y incrementado
!>           debe contener el vector y. En la salida, Y se sobrescribe con el
!>           vector y actualizado.
!>           Si m o n es cero, entonces Y no se referencia y la función
!>           realiza un retorno rápido.
!>

INCY

!>          INCY es ENTERO
!>           En la entrada, INCY especifica el incremento para los elementos de
!>           Y. INCY no debe ser cero.
!>           Sin cambios en la salida.
!>
!>  Rutina Blas de nivel 2.
!>

dla_geamv(3)

dla_geamv — calculates a matrix-vector product using a general matrix to calculate error bounds.

Synopsis

    subroutine dla_geamv(trans, m, n, alpha, a, lda, x, incx, beta, y, incy)

       integer, intent(in)            :: m, n, lda, incx, incy
       double precision, intent(in)   :: alpha, beta
       double precision, intent(inout):: a(lda, *), x(*), y(*)
       integer, intent(in)            :: trans

Description

dla_geamv performs one of the matrix-vector operations

y := alpha*abs(A)*abs(x) + beta*abs(y)

or

y := alpha*abs(A**T)*abs(x) + beta*abs(y)

where alpha and beta are scalars, x and y are vectors, and A is an m by n matrix. This function is primarily used in calculating error bounds. To protect against underflow during evaluation, components in the resulting vector are perturbed away from zero by (N+1) times the underflow threshold. To prevent unnecessarily large errors for block-structure embedded in general matrices, zero components are not perturbed. A zero entry is considered if all multiplications involved in computing that entry have at least one zero multiplicand.

Parameters

TRANS (INTEGER) On entry, TRANS specifies the operation to be performed as follows:

BLAS_NO_TRANS y := alpha*abs(A)*abs(x) + beta*abs(y)

BLAS_TRANS y := alpha*abs(A**T)*abs(x) + beta*abs(y)

BLAS_CONJ_TRANS y := alpha*abs(A**T)*abs(x) + beta*abs(y)

Unchanged on exit.

M (INTEGER) On entry, M specifies the number of rows of the matrix A. M must be at least zero. Unchanged on exit.

N (INTEGER) On entry, N specifies the number of columns of the matrix A. N must be at least zero. Unchanged on exit.

ALPHA (DOUBLE PRECISION) On entry, ALPHA specifies the scalar alpha. Unchanged on exit.

A A is DOUBLE PRECISION array, dimension ( LDA, n ) Before entry, the leading m by n part of the array A must contain the matrix of coefficients. Unchanged on exit.

LDA LDA is INTEGER On entry, LDA specifies the first dimension of A as declared in the calling (sub)program. LDA must be at least max( 1, m ). Unchanged on exit.

X X is DOUBLE PRECISION array, dimension ( 1 + ( n - 1 )*abs( INCX ) ) when TRANS = 'N' or 'n' and at least ( 1 + ( m - 1 )*abs( INCX ) ) otherwise. Before entry, the incremented array X must contain the vector x. Unchanged on exit.

INCX INCX is INTEGER On entry, INCX specifies the increment for the elements of X. INCX must not be zero. Unchanged on exit.

BETA BETA is DOUBLE PRECISION On entry, BETA specifies the scalar beta. When BETA is supplied as zero then Y need not be set on input. Unchanged on exit.

Y Y is DOUBLE PRECISION array, dimension at least ( 1 + ( m - 1 )*abs( INCY ) ) when TRANS = 'N' or 'n' and at least ( 1 + ( n - 1 )*abs( INCY ) ) otherwise. Before entry with BETA non-zero, the incremented array Y must contain the vector y. On exit, Y is overwritten by the updated vector y. If either m or n is zero, then Y not referenced and the function performs a quick return.

INCY INCY is INTEGER On entry, INCY specifies the increment for the elements of Y. INCY must not be zero. Unchanged on exit.

Level 2 Blas routine.
