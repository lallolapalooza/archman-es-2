subrutina dlaed1 (entero n, doble precisión, dimensión( * ) d, doble precisión, dimensión( ldq, * ) q, entero ldq, entero, dimensión( * ) indxq, doble precisión rho, entero cutpnt, doble precisión, dimensión( * ) work, entero, dimensión( * ) iwork, entero info)

DLAED1 utilizada por DSTEDC. Calcula el sistema de ecuaciones actualizado de una matriz diagonal después de la modificación por una matriz simétrica de rango uno. Se utiliza cuando la matriz original es tridiagonal.

Propósito:

!>
!> DLAED1 calcula el sistema de ecuaciones actualizado de una matriz
!> diagonal después de la modificación por una matriz simétrica de rango
!> uno. Esta subrutina se utiliza solo para el problema de valores
!> propios que requiere todos los valores propios y vectores propios de
!> una matriz tridiagonal. DLAED7 maneja el caso en el que se desean solo
!> los valores propios o los valores propios y vectores propios de una
!> matriz simétrica completa (que fue reducida a forma tridiagonal).
!>
!>   T = Q(in) ( D(in) + RHO * Z*Z**T ) Q**T(in) = Q(out) * D(out) * Q**T(out)
!>
!>    donde Z = Q**T*u, u es un vector de longitud N con unos en los
!>    elementos CUTPNT y CUTPNT + 1 y ceros en otros lugares.
!>
!>    Los vectores propios de la matriz original se almacenan en Q, y los
!>    valores propios están en D. El algoritmo consta de tres etapas:
!>
!>       La primera etapa consiste en desinflar el tamaño del problema
!>       cuando hay valores propios múltiples o si hay un cero en el
!>       vector Z. Por cada ocurrencia de este tipo, la dimensión del
!>       problema de la ecuación secular se reduce en uno. Esta etapa
!>       la realiza la subrutina DLAED2.
!>
!>       La segunda etapa consiste en calcular los valores propios
!>       actualizados. Esto se hace encontrando las raíces de la ecuación
!>       secular a través de la subrutina DLAED4 (llamada por DLAED3).
!>       Esta subrutina también calcula los vectores propios del problema
!>       actual.
!>
!>       La etapa final consiste en calcular los vectores propios
!>       actualizados directamente usando los valores propios
!>       actualizados. Los vectores propios del problema actual se
!>       multiplican con los vectores propios del problema general.
!>

Parámetros

N 
!>          N es ENTERO
!>         La dimensión de la matriz tridiagonal simétrica.  N >= 0.
!>

D

!>          D es array de DOBLE PRECISIÓN, dimensión (N)
!>         En la entrada, los valores propios de la matriz perturbada de
!>         rango 1.
!>         En la salida, los valores propios de la matriz reparada.
!>

Q

!>          Q es array de DOBLE PRECISIÓN, dimensión (LDQ,N)
!>         En la entrada, los vectores propios de la matriz perturbada de
!>         rango 1.
!>         En la salida, los vectores propios de la matriz tridiagonal
!>         reparada.
!>

LDQ

!>          LDQ es ENTERO
!>         La dimensión principal del array Q.  LDQ >= max(1,N).
!>

INDXQ

!>          INDXQ es array de ENTEROS, dimensión (N)
!>         En la entrada, la permutación que ordena por separado los dos
!>         subproblemas en D en orden ascendente.
!>         En la salida, la permutación que reintegrará los subproblemas
!>         en orden ordenado,
!>         es decir, D( INDXQ( I = 1, N ) ) estará en orden ascendente.
!>

RHO

!>          RHO es DOBLE PRECISIÓN
!>         La entrada subdiagonal utilizada para crear la modificación de
!>         rango 1.
!>

CUTPNT

!>          CUTPNT es ENTERO
!>         La ubicación del último valor propio en la submatriz principal.
!>         min(1,N) <= CUTPNT <= N/2.
!>

WORK

!>          WORK es array de DOBLE PRECISIÓN, dimensión (4*N + N**2)
!>

IWORK

!>          IWORK es array de ENTEROS, dimensión (4*N)
!>

INFO

!>          INFO es ENTERO
!>          = 0:  salida exitosa.
!>          < 0:  si INFO = -i, el i-ésimo argumento tenía un valor ilegal.
!>          > 0:  si INFO = 1, un valor propio no convergió
!>

Detailed Description


This subroutine calls the other routines that complete
    the representation of an orthonormal eigenvector matrix P,
    by forming the full orthonormal matrices for the eigenvectors
    of the symmetric tridiagonal matrix T.


Specifically, we must update the vectors in D and Q.


T = Q D Q^T


where Q is orthonormal and D is diagonal.


Thus, T is symmetric tridiagonal.


We assume that



    

    T = b_1 v_1 u_1^T + b_2 u_2 v_2^T + ... + b_n u_n v_n^T
    




where



    

    v_i = Q_i




and



    

    u_i = Q_i




with



    

    Q = [Q_1, Q_2, ..., Q_n]




and



    

    D = diag(d_1, d_2, ..., d_n)




The matrix T has rank-1 modification
    

    T = T_0 - rho*z*z^T




where



    

    T_0 = diag(d_1, ..., d_{p-1}, d_{p+1}, ..., d_n)




and the vector z has all but the p-th entry zero.


The eigenvalues and eigenvectors f T are computed by LAED4.


LAED1 computes the updated eigenvalue and eigenvector matrix P
    for the matrix T.



    

    T = P D P^T




where P is an orthonormal matrix.

Function Documentation




laed1


subroutine laed1(N, D, Q, LDQ, INDXQ, RHO, CUTPNT, WORK, IWORK, INFO)


Performs the final eigenvector computation for a symmetric tridiagonal matrix
    T after the eigenvalues have been computed by LAED4.




N




N is INTEGER


The dimension of the symmetric tridiagonal matrix T.




D




D is REAL array, dimension (N)


On entry, the eigenvalues of the rank-1-perturbed matrix.


On exit, the eigenvalues of the repaired matrix.




Q




Q is REAL array, dimension (LDQ,N)


On entry, the eigenvectors of the rank-1-perturbed matrix.


On exit, the eigenvectors of the repaired tridiagonal matrix.




LDQ




LDQ is INTEGER


The leading dimension of the array Q. LDQ >= max(1,N).




INDXQ




INDXQ is INTEGER array, dimension (N)


On entry, the permutation which separately sorts the two
    subproblems in D into ascending order.


On exit, the permutation which will reintegrate the
    subproblems back into sorted order,
    i.e. D( INDXQ( I = 1, N ) ) will be in ascending order.




RHO




RHO is REAL


The subdiagonal entry used to create the rank-1 modification.




CUTPNT




CUTPNT is INTEGER


The location of the last eigenvalue in the leading sub-matrix.


min(1,N) <= CUTPNT <= N/2.




WORK




WORK is REAL array, dimension (4*N + N**2)




IWORK




IWORK is INTEGER array, dimension (4*N)




INFO




INFO is INTEGER


= 0: successful exit.


< 0: if INFO = -i, the i-th argument had an illegal value.


> 0: if INFO = 1, an eigenvalue did not converge
