DOCUMENTACIÓN DE LA FUNCIÓN

función real clanhb (carácter norma, carácter uplo, entero n, entero k, complejo, dimensión( ldab, * ) ab, entero ldab, real, dimensión( * ) work)

CLANHB devuelve el valor de la norma 1, o la norma de Frobenius, o la norma infinito, o el elemento de mayor valor absoluto de una matriz bandeada Hermítica.

Propósito:

!>
!> CLANHB  devuelve el valor de la norma uno,  o la norma de Frobenius, o
!> la norma infinito,  o el elemento de  mayor valor absoluto de una
!> matriz Hermítica bandeada A de tamaño n por n,  con k super-diagonales.
!>

Retorna

CLANHB 
!>
!>    CLANHB = ( max(abs(A(i,j))), NORMA = 'M' o 'm'
!>             (
!>             ( norm1(A),         NORMA = '1', 'O' o 'o'
!>             (
!>             ( normI(A),         NORMA = 'I' o 'i'
!>             (
!>             ( normF(A),         NORMA = 'F', 'f', 'E' o 'e'
!>
!> donde  norm1  denota la  norma uno de una matriz (suma máxima de columnas),
!> normI  denota la  norma infinito  de una matriz  (suma máxima de filas) y
!> normF  denota la  norma de Frobenius de una matriz (raíz cuadrada de la suma de
!> cuadrados).  Tenga en cuenta que  max(abs(A(i,j)))  no es una norma matricial consistente.
!>

Parámetros

NORMA 
!>          NORMA es CHARACTER*1
!>          Especifica el valor a devolver en CLANHB como se describe
!>          arriba.
!>

UPLO

!>          UPLO es CHARACTER*1
!>          Especifica si se proporciona la parte triangular superior o inferior de la
!>          matriz bandeada A.
!>          = 'U':  Triangular superior
!>          = 'L':  Triangular inferior
!>

N

!>          N es INTEGER
!>          El orden de la matriz A.  N >= 0.  Cuando N = 0, CLANHB se
!>          establece a cero.
!>

K

!>          K es INTEGER
!>          El número de super-diagonales o sub-diagonales de la
!>          matriz bandeada A.  K >= 0.
!>

AB

!>          AB es un array COMPLEX de dimensión (LDAB,N)
!>          La parte superior o inferior de la matriz bandeada Hermítica A,
!>          almacenada en las primeras K+1 filas de AB. La j-ésima columna de A se
!>          almacena en la j-ésima columna del array AB de la siguiente manera:
!>          si UPLO = 'U', AB(k+1+i-j,j) = A(i,j) para max(1,j-k)<=i<=j;
!>          si UPLO = 'L', AB(1+i-j,j)   = A(i,j) para j<=i<=min(n,j+k).
!>          Tenga en cuenta que las partes imaginarias de los elementos diagonales no
!>          necesitan ser establecidas y se asumen como cero.
!>

LDAB

!>          LDAB es INTEGER
!>          La dimensión principal del array AB.  LDAB >= K+1.
!>

WORK

!>          WORK es un array REAL de dimensión (MAX(1,LWORK)),
!>          donde LWORK >= N cuando NORMA = 'I' o '1' o 'O'; en caso contrario,
!>          WORK no se referencia.
!>

double precision function dlansb (character norm, character uplo, integer n, integer k, double precision, dimension( ldab, * ) ab, integer ldab, double precision, dimension( * ) work)

DLANSB returns the value of the 1-norm, or the Frobenius norm, or the infinity norm, or the element of largest absolute value of a symmetric band matrix.

Purpose:

!>
!> DLANSB  returns the value of the one norm,  or the Frobenius norm, or
!> the  infinity norm,  or the element of  largest absolute value  of an
!> n by n symmetric band matrix A,  with k super-diagonals.
!>

Returns

DLANSB 
!>
!>    DLANSB = ( max(abs(A(i,j))), NORM = 'M' or 'm'
!>             (
!>             ( norm1(A),         NORM = '1', 'O' or 'o'
!>             (
!>             ( normI(A),         NORM = 'I' or 'i'
!>             (
!>             ( normF(A),         NORM = 'F', 'f', 'E' or 'e'
!>
!> where  norm1  denotes the  one norm of a matrix (maximum column sum),
!> normI  denotes the  infinity norm  of a matrix  (maximum row sum) and
!> normF  denotes the  Frobenius norm of a matrix (square root of sum of
!> squares).  Note that  max(abs(A(i,j)))  is not a consistent matrix norm.
!>

Parameters

NORM 
!>          NORM is CHARACTER*1
!>          Specifies the value to be returned in DLANSB as described
!>          above.
!>

UPLO

!>          UPLO is CHARACTER*1
!>          Specifies whether the upper or lower triangular part of the
!>          band matrix A is supplied.
!>          = 'U':  Upper triangular part is supplied
!>          = 'L':  Lower triangular part is supplied
!>

N

!>          N is INTEGER
!>          The order of the matrix A.  N >= 0.  When N = 0, DLANSB is
!>          set to zero.
!>

K

!>          K is INTEGER
!>          The number of super-diagonals or sub-diagonals of the
!>          band matrix A.  K >= 0.
!>

AB

!>          AB is DOUBLE PRECISION array, dimension (LDAB,N)
!>          The upper or lower triangle of the symmetric band matrix A,
!>          stored in the first K+1 rows of AB.  The j-th column of A is
!>          stored in the j-th column of the array AB as follows:
!>          if UPLO = 'U', AB(k+1+i-j,j) = A(i,j) for max(1,j-k)<=i<=j;
!>          if UPLO = 'L', AB(1+i-j,j)   = A(i,j) for j<=i<=min(n,j+k).
!>

LDAB

!>          LDAB is INTEGER
!>          The leading dimension of the array AB.  LDAB >= K+1.
!>

WORK

!>          WORK is DOUBLE PRECISION array, dimension (MAX(1,LWORK)),
!>          where LWORK >= N when NORM = 'I' or '1' or 'O'; otherwise,
!>          WORK is not referenced.
!>
