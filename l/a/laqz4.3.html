DLAQZ4

Propósito:

!>
!> DLAQZ4 Ejecuta un único barrido QZ multishift
!>

Parámetros

ILSCHUR 
!>          ILSCHUR es LOGICAL
!>              Determina si se debe actualizar o no la forma de Schur completa
!>

ILQ

!>          ILQ es LOGICAL
!>              Determina si se debe actualizar o no la matriz Q
!>

ILZ

!>          ILZ es LOGICAL
!>              Determina si se debe actualizar o no la matriz Z
!>

N

!>          N es INTEGER
!>          El orden de las matrices A, B, Q y Z. N >= 0.
!>

ILO

!>          ILO es INTEGER
!>

IHI

!>          IHI es INTEGER
!>

NSHIFTS

!>          NSHIFTS es INTEGER
!>          El número deseado de desplazamientos a utilizar
!>

NBLOCK_DESIRED

!>          NBLOCK_DESIRED es INTEGER
!>          El tamaño deseado de las ventanas computacionales
!>

SR

!>          SR es array de DOUBLE PRECISION
!>          las partes reales de los desplazamientos a utilizar.
!>

SI

!>          SI es array de DOUBLE PRECISION
!>          las partes imaginarias de los desplazamientos a utilizar.
!>

SS

!>          SS es array de DOUBLE PRECISION
!>          la escala de los desplazamientos a utilizar.
!>

A

!>          A es array de DOUBLE PRECISION, dimension (LDA, N)
!>

LDA

!>          LDA es INTEGER
!>          La dimensión principal del array A. LDA >= max( 1, N ).
!>

B

!>          B es array de DOUBLE PRECISION, dimension (LDB, N)
!>

LDB

!>          LDB es INTEGER
!>          La dimensión principal del array B. LDB >= max( 1, N ).
!>

Q

!>          Q es array de DOUBLE PRECISION, dimension (LDQ, N)
!>

LDQ

!>          LDQ es INTEGER
!>

Z

!>          Z es array de DOUBLE PRECISION, dimension (LDZ, N)
!>

LDZ

!>          LDZ es INTEGER
!>

QC

!>          QC es array de DOUBLE PRECISION, dimension (LDQC, NBLOCK_DESIRED)
!>

LDQC

!>          LDQC es INTEGER
!>

ZC

!>          ZC es array de DOUBLE PRECISION, dimension (LDZC, NBLOCK_DESIRED)
!>

LDZC

!>          LDZ es INTEGER
!>

WORK

!>          WORK es array de DOUBLE PRECISION, dimension (MAX(1,LWORK))
!>          A la salida, si INFO >= 0, WORK(1) devuelve el LWORK óptimo.
!>

LWORK

!>          LWORK es INTEGER
!>          La dimensión del array WORK. LWORK >= max(1,N).
!>
!>          Si LWORK = -1, entonces se asume una consulta de espacio de trabajo; la rutina
!>          solo calcula el tamaño óptimo del array WORK, devuelve
!>          este valor como la primera entrada del array WORK, y XERBLA no emite
!>          ningún mensaje de error relacionado con LWORK.
!>

INFO

!>          INFO es INTEGER
!>          = 0: salida exitosa
!>          < 0: si INFO = -i, el i-ésimo argumento tenía un valor ilegal
!>
