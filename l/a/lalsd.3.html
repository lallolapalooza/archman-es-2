subrutina clalsd (carácter uplo, entero smlsiz, entero n, entero nrhs, real, dimensión( * ) d, real, dimensión( * ) e, complejo, dimensión( ldb, * ) b, entero ldb, real rcond, entero rank, complejo, dimensión( * ) work, real, dimensión( * ) rwork, entero, dimensión( * ) iwork, entero info)

CLALSD usa la descomposición en valores singulares de A para resolver el problema de mínimos cuadrados.

Propósito:

!>
!> CLALSD usa la descomposición en valores singulares de A para resolver
!> el problema de mínimos cuadrados de encontrar X que minimice la norma
!> euclidiana de cada columna de A*X-B, donde A es N por N superior
!> bidiagonal, y X y B son N por NRHS. La solución X sobrescribe a B.
!>
!> Los valores singulares de A menores que RCOND por el valor singular
!> más grande se tratan como cero al resolver el problema de mínimos
!> cuadrados; en este caso se devuelve una solución de norma mínima.
!> Los valores singulares reales se devuelven en D en orden ascendente.
!>
!>

Parámetros

UPLO 
!>          UPLO es CARACTER*1
!>         = 'U': D y E definen una matriz bidiagonal superior.
!>         = 'L': D y E definen una matriz bidiagonal inferior.
!>

SMLSIZ

!>          SMLSIZ es ENTERO
!>         El tamaño máximo de los subproblemas en la parte inferior del
!>         árbol de cálculo.
!>

N

!>          N es ENTERO
!>         La dimensión de la matriz bidiagonal. N >= 0.
!>

NRHS

!>          NRHS es ENTERO
!>         El número de columnas de B. NRHS debe ser al menos 1.
!>

D

!>          D es un array REAL de dimensión (N)
!>         En la entrada D contiene la diagonal principal de la matriz
!>         bidiagonal. En la salida, si INFO = 0, D contiene sus valores
!>         singulares.
!>

E

!>          E es un array REAL de dimensión (N-1)
!>         Contiene las entradas de la superdiagonal de la matriz
!>         bidiagonal. En la salida, E ha sido destruido.
!>

B

!>          B es un array COMPLEJO de dimensión (LDB,NRHS)
!>         En la entrada, B contiene los lados derechos del problema de
!>         mínimos cuadrados. En la salida, B contiene la solución X.
!>

LDB

!>          LDB es ENTERO
!>         La dimensión principal de B en la subrutina de llamada.
!>         LDB debe ser al menos max(1,N).
!>

RCOND

!>          RCOND es REAL
!>         Los valores singulares de A menores o iguales a RCOND por
!>         el valor singular más grande se tratan como cero al resolver
!>         el problema de mínimos cuadrados. Si RCOND es negativo,
!>         se utiliza la precisión de la máquina en su lugar.
!>         Por ejemplo, si diag(S)*X=B fuera el problema de mínimos
!>         cuadrados, donde diag(S) es una matriz diagonal de valores
!>         singulares, la solución sería X(i) = B(i) / S(i) si S(i) es
!>         mayor que RCOND*max(S), y X(i) = 0 si S(i) es menor o igual
!>         a RCOND*max(S).
!>

RANK

!>          RANK es ENTERO
!>         El número de valores singulares de A mayores que RCOND por
!>         el valor singular más grande.
!>

WORK

!>          WORK es un array COMPLEJO de dimensión (N * NRHS).
!>

RWORK

!>          RWORK es un array REAL de dimensión al menos
!>         (9*N + 2*N*SMLSIZ + 8*N*NLVL + 3*SMLSIZ*NRHS +
!>         MAX( (SMLSIZ+1)**2, N*(1+NRHS) + 2*NRHS ),
!>         donde
!>         NLVL = MAX( 0, INT( LOG_2( MIN( M,N )/(SMLSIZ+1) ) ) + 1 )
!>

IWORK

!>          IWORK es un array ENTERO de dimensión (3*N*NLVL + 11*N).
!>

INFO

!>          INFO es ENTERO
!>         = 0:  salida exitosa.
!>         < 0:  si INFO = -i, el argumento i tuvo un valor ilegal.
!>         > 0:  El algoritmo no pudo calcular un valor singular mientras
!>               trabajaba en la submatriz ubicada en las filas y columnas
!>               INFO/(N+1) hasta MOD(INFO,N+1).
!>

Subroutines dlalsd subroutine dlalsd (character uplo, integer smlsiz, integer n, integer nrhs, double precision, dimension( * ) d, double precision, dimension( * ) e, double precision, dimension( ldb, * ) b, integer ldb, double precision rcond, integer rank, double precision, dimension( * ) work, integer, dimension( * ) iwork, integer info) DLALSD uses the singular value decomposition of A to solve the least squares problem. DLALSD uses the singular value decomposition of A to solve the least squares problem of finding X to minimize the Euclidean norm of each column of A*X-B, where A is N-by-N upper bidiagonal, and X and B are N-by-NRHS. The solution X overwrites B. The singular values of A smaller than RCOND times the largest singular value are treated as zero in solving the least squares problem; in this case a minimum norm solution is returned. The actual singular values are returned in D in ascending order. UPLO CHARACTER*1 = 'U': D and E define an upper bidiagonal matrix. = 'L': D and E define a lower bidiagonal matrix. SMLSIZ INTEGER The maximum size of the subproblems at the bottom of the computation tree. N INTEGER The dimension of the bidiagonal matrix. N >= 0. NRHS INTEGER The number of columns of B. NRHS must be at least 1. D DOUBLE PRECISION array, dimension (N) On entry D contains the main diagonal of the bidiagonal matrix. On exit, if INFO = 0, D contains its singular values. E DOUBLE PRECISION array, dimension (N-1) Contains the super-diagonal entries of the bidiagonal matrix. On exit, E has been destroyed. B DOUBLE PRECISION array, dimension (LDB,NRHS) On input, B contains the right hand sides of the least squares problem. On output, B contains the solution X. LDB INTEGER The leading dimension of B in the calling subprogram. LDB must be at least max(1,N). RCOND DOUBLE PRECISION The singular values of A less than or equal to RCOND times the largest singular value are treated as zero in solving the least squares problem. If RCOND is negative, machine precision is used instead. For example, if diag(S)*X=B were the least squares problem, where diag(S) is a diagonal matrix of singular values, the solution would be X(i) = B(i) / S(i) if S(i) is greater than RCOND*max(S), and X(i) = 0 if S(i) is less than or equal to RCOND*max(S). RANK INTEGER The number of singular values of A greater than RCOND times the largest singular value. WORK DOUBLE PRECISION array, dimension at least (9*N + 2*N*SMLSIZ + 8*N*NLVL + N*NRHS + (SMLSIZ+1)**2), where NLVL = max(0, INT(log_2 (N/(SMLSIZ+1))) + 1). IWORK INTEGER array, dimension at least (3*N*NLVL + 11*N) INFO INTEGER = 0: successful exit. < 0: if INFO = -i, the i-th argument had an illegal value. > 0: The algorithm failed to compute a singular value while working on the submatrix lying in rows and columns INFO/(N+1) through MOD(INFO,N+1).
