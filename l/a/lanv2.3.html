subrutina dlanv2 (doble precision a, doble precision b, doble precision c, doble precision d, doble precision rt1r, doble precision rt1i, doble precision rt2r, doble precision rt2i, doble precision cs, doble precision sn)

DLANV2 calcula la factorización de Schur de una matriz real 2x2 no simétrica en forma estándar.

Propósito:

!>
!> DLANV2 calcula la factorización de Schur de una matriz real 2x2 no simétrica
!> en forma estándar:
!>
!>      [ A  B ] = [ CS -SN ] [ AA  BB ] [ CS  SN ]
!>      [ C  D ]   [ SN  CS ] [ CC  DD ] [-SN  CS ]
!>
!> donde o bien
!> 1) CC = 0 para que AA y DD sean valores propios reales de la matriz, o
!> 2) AA = DD y BB*CC < 0, para que AA + o - sqrt(BB*CC) sean valores propios
!> complejos conjugados.
!>

Parámetros

A 
!>          A es DOBLE PRECISION
!>

B

!>          B es DOBLE PRECISION
!>

C

!>          C es DOBLE PRECISION
!>

D

!>          D es DOBLE PRECISION
!>          A la entrada, los elementos de la matriz de entrada.
!>          A la salida, se sobrescriben con los elementos de la forma
!>          de Schur estandarizada.
!>

RT1R

!>          RT1R es DOBLE PRECISION
!>

RT1I

!>          RT1I es DOBLE PRECISION
!>

RT2R

!>          RT2R es DOBLE PRECISION
!>

RT2I

!>          RT2I es DOBLE PRECISION
!>          Las partes real e imaginaria de los valores propios. Si los
!>          valores propios son un par conjugado complejo, RT1I > 0.
!>

CS

!>          CS es DOBLE PRECISION
!>

SN

!>          SN es DOBLE PRECISION
!>          Parámetros de la matriz de rotación.
!>

!>

!>  Rumania, para reducir el riesgo de errores de cancelación,
!>  al calcular valores propios reales, y para asegurar, si es posible, que
!>  abs(RT1R) >= abs(RT2R).
!>
