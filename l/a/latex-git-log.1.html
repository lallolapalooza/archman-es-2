latex-git-log - Genera el historial de versiones de un proyecto git como código fuente LaTeX.

Sinopsis

latex-git-log [opciones] [archivo] ...

Opciones:

--author          establecer esto si desea incluir al autor
--width           establecer el ancho en cm del campo del mensaje de commit en la tabla LaTeX
--git-c-add       establecer una URL base para enlazar a un commit
--user            establecer un usuario de github para derivar la URL base
--repo            establecer un repositorio de github para derivar la URL base
--lang            idioma de la leyenda y todas las cadenas de salida
--version, -v     imprimir la versión de este script
--help            breve mensaje de ayuda
--man             documentación completa
--range           especificar un rango de revisiones de git

Opciones

--width
Establece el ancho en cm de la columna del mensaje de commit en la tabla LaTeX. Si no se establece este parámetro, la tabla no se limita verticalmente. Esto significa que si tiene un mensaje de commit muy largo, la tabla probablemente no cabrá en la página y obtendrá un mensaje de error de "Overfull" de TeX.

En este caso, debe especificar el ancho de la columna que contiene los mensajes de commit. Normalmente utilizo algo como --width=14 para DIN A4 en horizontal.

--git-c-add
Establece una URL base para enlazar a un commit. Este script intentará automáticamente utilizar la URL base de github.
--lang
Establece el idioma de la leyenda y todas las cadenas de salida. Por defecto, se utiliza el idioma de su sistema, pero puede anularlo con este parámetro.

Actualmente, este script solo admite inglés y alemán. Si necesita una traducción a otro idioma, puede crear un archivo .po o puedo registrar este proyecto en uno de esos sitios web de traducción en línea.

Ejemplo

Puede usarlo así:

latex-git-log --width=6 --lang=en > example-output.tex

Dependencias

De este script

Este script requiere los siguientes módulos de Perl:

IPC::System::Simple
Locale::Maketext::Simple

Todo lo demás debería estar ya instalado.

Para compilar la salida

La tabla utiliza el paquete longtable y los enlaces a un recurso web para cada commit utilizan la macro \href de hyperref. Por lo tanto, estos dos paquetes deben cargarse.

Además, debe definir la macro \longtableendfoot, que se expandirá en la parte inferior de cada página si la tabla continúa en la siguiente página. Puede definirla a un mensaje localizado para informar al lector que esta tabla no está completa y que continuará.

Descripción

Este programa generará todo el historial de versiones como una tabla escrita en LaTeX si se ejecuta dentro de un repositorio git. Cuando se proporcionan argumentos de archivo, solo se generará el historial que haya modificado esos archivos.

La intención es que redirija la salida estándar de este script a un archivo que luego pueda incluirse en su documento LaTeX principal.

Dado que la tabla puede ser muy grande, es posible que desee colocarla en una página apaisada.
