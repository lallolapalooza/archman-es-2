subrutina dlasq2 (entero n, doble precisión, dimensión( * ) z, entero info)

DLASQ2 calcula todos los valores propios de la matriz tridiagonal simétrica definida positiva asociada al Array qd Z con alta precisión relativa. Utilizado por sbdsqr y sstegr.

Propósito:

!>
!> DLASQ2 calcula todos los valores propios de la matriz tridiagonal simétrica
!> definida positiva asociada al array qd Z con alta precisión relativa.
!>
!> Para ver la relación de Z con la matriz tridiagonal, sea L una
!> matriz bidiagonal inferior unitaria con subdiagonales Z(2,4,6,,..) y
!> sea U una matriz bidiagonal superior con 1s arriba y diagonal
!> Z(1,3,5,,..). La tridiagonal es L*U o, si lo prefiere, la
!> tridiagonal simétrica a la que es similar.
!>
!> Nota: DLASQ2 define una variable lógica, IEEE, que es verdadera
!> en máquinas que siguen el estándar de punto flotante ieee-754 en su
!> manejo de infinitos y NaNs, y falsa en caso contrario. Esta variable
!> se pasa a DLASQ3.
!>

Parámetros

N 
!>          N es ENTERO
!>        El número de filas y columnas de la matriz. N >= 0.
!>

Z

!>          Z es array de DOBLE PRECISION, dimensión ( 4*N )
!>        A la entrada Z contiene el array qd. A la salida, las entradas 1 a N
!>        contienen los valores propios en orden decreciente, Z( 2*N+1 )
!>        contiene la traza, y Z( 2*N+2 ) contiene la suma de los valores
!>        propios. Si N > 2, entonces Z( 2*N+3 ) contiene el contador
!>        de iteraciones, Z( 2*N+4 ) contiene NDIVS/NIN^2, y Z( 2*N+5 )
!>        contiene el porcentaje de desplazamientos que fallaron.
!>

INFO

!>          INFO es ENTERO
!>        = 0: salida exitosa
!>        < 0: si el i-ésimo argumento es un escalar y tenía un valor
!>             ilegal, entonces INFO = -i, si el i-ésimo argumento es
!>             un array y la entrada j tenía un valor ilegal, entonces
!>             INFO = -(i*100+j)
!>        > 0: el algoritmo falló
!>              = 1, se marcó una división por un valor positivo en E
!>              = 2, el bloque actual de Z no se diagonalizó después de
!>                   100*N iteraciones (en el bucle while interno). A la
!>                   salida Z contiene un array qd con los mismos valores
!>                   propios que el Z dado.
!>              = 3, no se cumplió el criterio de terminación del bucle
!>                   while externo (el programa creó más de N bloques no
!>                   reducidos)
!>

Univ. of Tennessee

Univ. of California Berkeley

Univ. of Colorado Denver

NAG Ltd.

Detalles Adicionales:

!>
!>  Variables Locales: I0:N0 define un segmento no reducido actual de Z.
!>  Los desplazamientos se acumulan en SIGMA. El contador de iteraciones está en ITER.
!>  El cambio de búfer se controla con PP (alterna entre 0 y 1).
!>
