subrutina clarfx (character side, integer m, integer n, complex, dimension( * ) v, complex tau, complex, dimension( ldc, * ) c, integer ldc, complex, dimension( * ) work)

CLARFX aplica un reflector elemental complejo a una matriz compleja m por n, desde la izquierda o la derecha. H se representa en la forma


H = I - tau * v * v**H

donde tau es un escalar complejo y v es un vector complejo.

Si tau = 0, entonces H se considera la matriz identidad.

Esta versión utiliza código en línea si H tiene orden < 11.

Propósito:

!>
!> CLARFX aplica un reflector elemental complejo H a una matriz compleja m por n
!> C, desde la izquierda o la derecha. H se representa en la forma
!>
!>       H = I - tau * v * v**H
!>
!> donde tau es un escalar complejo y v es un vector complejo.
!>
!> Si tau = 0, entonces H se toma como la matriz unitaria
!>
!> Esta versión usa código en línea si H tiene orden < 11.
!>

Parámetros

SIDE 
!>          SIDE es CHARACTER*1
!>          = 'L': forma  H * C
!>          = 'R': forma  C * H
!>

M

!>          M es INTEGER
!>          El número de filas de la matriz C.
!>

N

!>          N es INTEGER
!>          El número de columnas de la matriz C.
!>

V

!>          V es array COMPLEX, dimensión (M) si SIDE = 'L'
!>                                        o (N) si SIDE = 'R'
!>          El vector v en la representación de H.
!>

TAU

!>          TAU es COMPLEX
!>          El valor tau en la representación de H.
!>

C

!>          C es array COMPLEX, dimensión (LDC,N)
!>          En la entrada, la matriz C de m por n.
!>          En la salida, C se sobrescribe con la matriz H * C si SIDE = 'L',
!>          o C * H si SIDE = 'R'.
!>

LDC

!>          LDC es INTEGER
!>          La dimensión principal del array C. LDC >= max(1,M).
!>

WORK

!>          WORK es array COMPLEX, dimensión (N) si SIDE = 'L'
!>                                            o (M) si SIDE = 'R'
!>          WORK no se referencia si H tiene orden < 11.
!>
