subrutina dlasy2 (logical ltranl, logical ltranr, integer isgn, integer n1, integer n2, double precision, dimension( ldtl, * ) tl, integer ldtl, double precision, dimension( ldtr, * ) tr, integer ldtr, double precision, dimension( ldb, * ) b, integer ldb, double precision scale, double precision, dimension( ldx, * ) x, integer ldx, double precision xnorm, integer info)

DLASY2 resuelve la ecuación matricial de Sylvester donde las matrices son de orden 1 o 2.

Propósito:

!>
!> DLASY2 resuelve para la matriz X de N1 por N2, 1 <= N1,N2 <= 2, en
!>
!>        op(TL)*X + ISGN*X*op(TR) = SCALE*B,
!>
!> donde TL es N1 por N1, TR es N2 por N2, B es N1 por N2, e ISGN = 1 o
!> -1.  op(T) = T o T**T, donde T**T denota la transpuesta de T.
!>

Parámetros

LTRANL 
!>          LTRANL es LOGICAL
!>          En la entrada, LTRANL especifica op(TL):
!>             = .FALSE., op(TL) = TL,
!>             = .TRUE., op(TL) = TL**T.
!>

LTRANR

!>          LTRANR es LOGICAL
!>          En la entrada, LTRANR especifica op(TR):
!>            = .FALSE., op(TR) = TR,
!>            = .TRUE., op(TR) = TR**T.
!>

ISGN

!>          ISGN es INTEGER
!>          En la entrada, ISGN especifica el signo de la ecuación
!>          como se describió anteriormente. ISGN solo puede ser 1 o -1.
!>

N1

!>          N1 es INTEGER
!>          En la entrada, N1 especifica el orden de la matriz TL.
!>          N1 solo puede ser 0, 1 o 2.
!>

N2

!>          N2 es INTEGER
!>          En la entrada, N2 especifica el orden de la matriz TR.
!>          N2 solo puede ser 0, 1 o 2.
!>

TL

!>          TL es un array de DOUBLE PRECISION, dimensión (LDTL,2)
!>          En la entrada, TL contiene una matriz N1 por N1.
!>

LDTL

!>          LDTL es INTEGER
!>          La dimensión principal de la matriz TL. LDTL >= max(1,N1).
!>

TR

!>          TR es un array de DOUBLE PRECISION, dimensión (LDTR,2)
!>          En la entrada, TR contiene una matriz N2 por N2.
!>

LDTR

!>          LDTR es INTEGER
!>          La dimensión principal de la matriz TR. LDTR >= max(1,N2).
!>

B

!>          B es un array de DOUBLE PRECISION, dimensión (LDB,2)
!>          En la entrada, la matriz N1 por N2 B contiene el lado derecho
!>          de la ecuación.
!>

LDB

!>          LDB es INTEGER
!>          La dimensión principal de la matriz B. LDB >= max(1,N1).
!>

SCALE

!>          SCALE es DOUBLE PRECISION
!>          En la salida, SCALE contiene el factor de escala. SCALE se elige
!>          menor o igual que 1 para evitar que la solución desborde.
!>

X

!>          X es un array de DOUBLE PRECISION, dimensión (LDX,2)
!>          En la salida, X contiene la solución N1 por N2.
!>

LDX

!>          LDX es INTEGER
!>          La dimensión principal de la matriz X. LDX >= max(1,N1).
!>

XNORM

!>          XNORM es DOUBLE PRECISION
!>          En la salida, XNORM es la norma infinita de la solución.
!>

INFO

!>          INFO es INTEGER
!>          En la salida, INFO se establece en
!>             0: salida exitosa.
!>             1: TL y TR tienen valores propios demasiado cercanos, por lo que TL o
!>                TR se perturba para obtener una ecuación no singular.
!>          NOTA: En aras de la velocidad, esta subrutina no
!>                verifica las entradas en busca de errores.
!>

Detailed Description


This routine is deprecated. Use SGELSY instead.


SLASY2 computes the solution to the system of equations:


    A*X*B + C*X*D = E,



where A, B, C, D and E are real matrices, and X is the real
    solution matrix.


A is N1 x N1, B is N2 x N2, C is N1 x N1, D is N2 x N2, E is
    N1 x N2, and X is N1 x N2.


This routine is called by DGESV, CGESV, ZGESV, etc. to solve
    the systems of equations.


The problem is solved by reducing the problem to a preliminary
    triangular system of the form:


    (A - lambda*I)*X*(B - mu*I) = E',



where lambda and mu are eigenvalues of A and B respectively. This
    is done by calculating the Schur forms of A and B. Then the system is
    solved for X.


The calculation is done in the following steps:


    
  
  1. 
    
    Compute the Schur forms of A and B:
    
    
     A = Q*T*Q^T
 B = Z*P*Z^T

    
    
    where T and P are upper triangular matrices.
    
  
    2. 
  
  2. 
    
    Apply the transformation to the system:
    
    
     Q*(A*X*B + C*X*D)*Z^T = Q*E*Z^T

    
    
    Let
    
    
     X = Q*Y*Z^T

    
    
    then the system becomes:
    
    
     T*Y*P + Q*C*Z^T*Y*P*Z^T*Z^T = Q*E*Z^T

    
    
    Let
    
    
     C' = Q*C*Z^T

    
    
    then the system becomes:
    
    
     T*Y*P + C'*Y*P = Q*E*Z^T

    
    
    Let
    
    
     E' = Q*E*Z^T

    
    
    then the system becomes:
    
    
     T*Y*P + C'*Y*P = E'

    
    
    This is a Sylvester equation of the form:
    
    
     T*Y*P + C'*Y*P = E'.

    
  
    3. 
  
  3. 
    
    Solve the Sylvester equation for Y.
    
    
    The solution Y is computed using the Bartels-Stewart algorithm.
    
  
    4. 
  
  4. 
    
    Compute X from Y:
    
    
     X = Q*Y*Z^T

    
  
    5. 








Function Documentation


Parameters



  
TRANS

  

    
CHARACTER*1.
    

    
Specifies the form of the system of equations:

    
     = 'N': Solve  A*X*B + C*X*D = E,
     = 'T': Solve A^T*X*B^T + C^T*X*D^T = E,
     = 'C': Solve A^H*X*B^H + C^H*X*D^H = E,


  

  
ILARGE

  

    
INTEGER.
    

    
Specifies whether A or B is the larger matrix in the
        dimension of the problem. This is used to potentially improve the
        accuracy of the solution.

    
     = 1: The first dimension of A is larger than the first dimension of C.
     = 2: The first dimension of C is larger than the first dimension of A.


  

  
ILITE

  

    
INTEGER.
    

    
Specifies whether to use a modified version of the Bartels-Stewart
        algorithm. This is used to potentially improve the accuracy of the
        solution.

    
     = 1: Use the modified Bartels-Stewart algorithm.
     = 2: Use the standard Bartels-Stewart algorithm.


  

  
ILASCL

  

    
INTEGER.
    

    
Specifies whether to scale the matrices A, B, C, and D to
        prevent overflow or underflow. This is used to potentially improve the
        accuracy of the solution.

    
     = 1: Scale the matrices.
     = 2: Do not scale the matrices.


  

  
INT

  

    
INTEGER.
    

    
Specifies whether to compute the Schur forms of A and B. This
        is used to potentially improve the accuracy of the solution.

    
     = 1: Compute the Schur forms.
     = 2: Do not compute the Schur forms.


  

  
INF

  

    
INTEGER.
    

    
Specifies whether to compute the infinity-norm of the solution.
        This is used to potentially improve the accuracy of the solution.

    
     = 1: Compute the infinity-norm.
     = 2: Do not compute the infinity-norm.


  

  
A

  

    
REAL array, dimension (LDA,N1).
    

    
The N1 x N1 matrix A.

  

  
LDA

  

    
INTEGER.
    

    
The leading dimension of the matrix A. LDA >= max(1,N1).

  

  
B

  

    
REAL array, dimension (LDB,N2).
    

    
The N2 x N2 matrix B.

  

  
LDB

  

    
INTEGER.
    

    
The leading dimension of the matrix B. LDB >= max(1,N2).

  

  
C

  

    
REAL array, dimension (LDC,N1).
    

    
The N1 x N1 matrix C.

  

  
LDC

  

    
INTEGER.
    

    
The leading dimension of the matrix C. LDC >= max(1,N1).

  

  
D

  

    
REAL array, dimension (LCD,N2).
    

    
The N2 x N2 matrix D.

  

  
LCD

  

    
INTEGER.
    

    
The leading dimension of the matrix D. LCD >= max(1,N2).

  

  
SCALE

  

    
REAL.
    

    
On exit, SCALE contains the scale factor. SCALE is chosen
        less than or equal to 1 to prevent the solution overflowing.
    

  

  
X

  

    
REAL array, dimension (LDX,2)
    

    
On exit, X contains the N1 by N2 solution.
    

  

  
LDX

  

    
INTEGER.
    

    
The leading dimension of the matrix X. LDX >= max(1,N1).
    

  

  
XNORM

  

    
REAL.
    

    
On exit, XNORM is the infinity-norm of the solution.
    

  

  
INFO

  

    
INTEGER.
    

    
On exit, INFO is set to
    

    
       0: successful exit.
       1: TL and TR have too close eigenvalues, so TL or
          TR is perturbed to get a nonsingular equation.
      NOTE: In the interests of speed, this routine does not
            check the inputs for errors.
