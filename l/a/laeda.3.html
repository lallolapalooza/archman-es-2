DLAEDA utilizada por DSTEDC. Calcula el vector Z que determina la modificación de rango uno de la matriz diagonal. Se utiliza cuando la matriz original es densa.

Propósito:

!>
!> DLAEDA calcula el vector Z correspondiente al paso de fusión en el
!> paso CURLVLth del proceso de fusión para el problema CURPBMth.
!>

Parámetros

N 
!>          N es ENTERO
!>         La dimensión de la matriz tridiagonal simétrica.  N >= 0.
!>

TLVLS

!>          TLVLS es ENTERO
!>         El número total de niveles de fusión en el árbol general de
!>         divide y vencerás.
!>

CURLVL

!>          CURLVL es ENTERO
!>         El nivel actual en la subrutina general de fusión,
!>         0 <= curlvl <= tlvls.
!>

CURPBM

!>          CURPBM es ENTERO
!>         El problema actual en el nivel actual de la subrutina general
!>         de fusión (contando de arriba a la izquierda a abajo a la
!>         derecha).
!>

PRMPTR

!>          PRMPTR es arreglo ENTERO, dimensión (N lg N)
!>         Contiene una lista de punteros que indican dónde en PERM se
!>         almacena la permutación de un nivel. PRMPTR(i+1) - PRMPTR(i)
!>         indica el tamaño de la permutación e incidentalmente el tamaño
!>         del problema completo, sin deflación.
!>

PERM

!>          PERM es arreglo ENTERO, dimensión (N lg N)
!>         Contiene las permutaciones (de deflación y ordenación) que se
!>         aplicarán a cada bloque de eigenvectores.
!>

GIVPTR

!>          GIVPTR es arreglo ENTERO, dimensión (N lg N)
!>         Contiene una lista de punteros que indican dónde en GIVCOL se
!>         almacenan las rotaciones de Givens de un nivel. GIVPTR(i+1) -
!>         GIVPTR(i) indica el número de rotaciones de Givens.
!>

GIVCOL

!>          GIVCOL es arreglo ENTERO, dimensión (2, N lg N)
!>         Cada par de números indica un par de columnas para que tengan
!>         lugar en una rotación de Givens.
!>

GIVNUM

!>          GIVNUM es arreglo DOUBLE PRECISION, dimensión (2, N lg N)
!>         Cada número indica el valor S a ser utilizado en la rotación
!>         de Givens correspondiente.
!>

Q

!>          Q es arreglo DOUBLE PRECISION, dimensión (N**2)
!>         Contiene los bloques de eigenvectores cuadrados de niveles
!>         anteriores, las posiciones de inicio de los bloques se dan por
!>         QPTR.
!>

QPTR

!>          QPTR es arreglo ENTERO, dimensión (N+2)
!>         Contiene una lista de punteros que indican dónde en Q se
!>         almacena un bloque de eigenvectores. SQRT( QPTR(i+1) - QPTR(i) )
!>         indica el tamaño del bloque.
!>

Z

!>          Z es arreglo DOUBLE PRECISION, dimensión (N)
!>         En la salida, este vector contiene el vector de actualización
!>         (la última fila de la primera matriz de sub-eigenvectores y la
!>         primera fila de la segunda matriz de sub-eigenvectores).
!>

ZTEMP

!>          ZTEMP es arreglo DOUBLE PRECISION, dimensión (N)
!>

INFO

!>          INFO es ENTERO
!>          = 0:  salida exitosa.
!>          < 0:  si INFO = -i, el i-ésimo argumento tenía un valor
!>                ilegal.
!>

NAME

LAEDA - Subroutine

SYNOPSIS

 SUBROUTINE LAEDA(
                N, R, LDR, LS, NLS, RMIN, RMNS, SML, SR2, SR2MIN, SR2NS,
                GIVCOL, GIVPTR, GIVNUM, Q, QPTR, Z, ZTEMP, INFO
                )
  CHARACTER*1 R, SML
  INTEGER N, LDR, LS, NLS, INFO
  INTEGER GIVCOL(2, *), GIVPTR(*)
  REAL RMIN, RMNS, SR2, SR2MIN, SR2NS
  REAL GIVNUM(2, *), Q(*), QPTR(*), Z(*), ZTEMP(*)

Detailed Description

LAEDA computes the eigenvalues and eigenvectors of a real symmetric tridiagonal matrix.

This subroutine is part of the Relatively Robust Representations algorithm for computing the eigenvalues and eigenvectors of a symmetric tridiagonal matrix.

The algorithm proceeds in a level-by-level fashion. At each level, it computes the eigenpairs for a subproblem and updates the eigenpairs from the previous level.

The parameters with names ending in 'PTR' are pointers that indicate the starting positions of data blocks in arrays like GIVCOL, GIVNUM, and Q. This allows for efficient storage and access of data that may not be contiguous.

The parameters related to Givens rotations (GIVCOL, GIVPTR, GIVNUM) are used to store and apply the rotations that transform the matrix and its eigenvectors.

The parameters related to eigenblocks (Q, QPTR) store the eigenvectors computed at previous levels. The structure allows for storing multiple eigenblocks of varying sizes.

The vector Z is used to store the updating vector, which is crucial for updating the eigenvectors from one level to the next.

The parameter INFO is used for error reporting. A value of 0 indicates successful execution, while a negative value indicates an error related to the input arguments.

CHARACTER*1: Not used in this implementation.
`SR2`
REAL: Not used in this implementation.
`SR2MIN`
REAL: Not used in this implementation.
`SR2NS`
REAL: Not used in this implementation.
`GIVCOL`

INTEGER array, dimension (2, N lg N)

Each pair of numbers indicates a pair of columns to take place in a Givens rotation.

`GIVPTR`

INTEGER array, dimension (N+2)

Contains a list of pointers which indicate where in GIVCOL a level's Givens rotations are stored. GIVPTR(i+1) - GIVPTR(i) indicates the number of Givens rotations.

`GIVNUM`

REAL array, dimension (2, N lg N)

Each number indicates the S value to be used in the corresponding Givens rotation.

`Q`

REAL array, dimension (N**2)

Contains the square eigenblocks from previous levels, the starting positions for blocks are given by QPTR.

`QPTR`

INTEGER array, dimension (N+2)

Contains a list of pointers which indicate where in Q an eigenblock is stored. SQRT( QPTR(i+1) - QPTR(i) ) indicates the size of the block.

`Z`

REAL array, dimension (N)

On output this vector contains the updating vector (the last row of the first sub-eigenvector matrix and the first row of the second sub-eigenvector matrix).

`ZTEMP`

REAL array, dimension (N)

`INFO`

INTEGER

= 0: successful exit.

< 0: if INFO = -i, the i-th argument had an illegal value.
