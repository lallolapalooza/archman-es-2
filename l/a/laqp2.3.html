Documentación de la función

subrutina claqp2 (integer m, integer n, integer offset, complex, dimension( lda, * ) a, integer lda, integer, dimension( * ) jpvt, complex, dimension( * ) tau, real, dimension( * ) vn1, real, dimension( * ) vn2, complex, dimension( * ) work)

CLAQP2 calcula una factorización QR con pivoteo de columnas del bloque de la matriz.

Propósito:

!>
!> CLAQP2 calcula una factorización QR con pivoteo de columnas de
!> el bloque A(OFFSET+1:M,1:N).
!> El bloque A(1:OFFSET,1:N) se pivotea de forma acorde, pero no se factoriza.
!>

Parámetros

M 
!>          M es INTEGER
!>          El número de filas de la matriz A. M >= 0.
!>

N

!>          N es INTEGER
!>          El número de columnas de la matriz A. N >= 0.
!>

OFFSET

!>          OFFSET es INTEGER
!>          El número de filas de la matriz A que deben ser pivoteadas
!>          pero no factorizadas. OFFSET >= 0.
!>

A

!>          A es una matriz de tipo COMPLEX, de dimensión (LDA,N)
!>          En la entrada, la matriz M por N A.
!>          En la salida, la parte triangular superior del bloque A(OFFSET+1:M,1:N) es
!>          el factor triangular obtenido; los elementos en el bloque
!>          A(OFFSET+1:M,1:N) por debajo de la diagonal, junto con el
!>          array TAU, representan la matriz ortogonal Q como un producto de
!>          reflectores elementales. El bloque A(1:OFFSET,1:N) ha sido
!>          pivoteado de forma acorde, pero no factorizado.
!>

LDA

!>          LDA es INTEGER
!>          La dimensión principal del array A. LDA >= max(1,M).
!>

JPVT

!>          JPVT es un array de tipo INTEGER, de dimensión (N)
!>          En la entrada, si JPVT(i) .ne. 0, la i-ésima columna de A se permuta
!>          al frente de A*P (una columna líder); si JPVT(i) = 0,
!>          la i-ésima columna de A es una columna libre.
!>          En la salida, si JPVT(i) = k, entonces la i-ésima columna de A*P
!>          era la k-ésima columna de A.
!>

TAU

!>          TAU es un array de tipo COMPLEX, de dimensión (min(M,N))
!>          Los factores escalares de los reflectores elementales.
!>

VN1

!>          VN1 es un array de tipo REAL, de dimensión (N)
!>          El vector con las normas parciales de las columnas.
!>

VN2

!>          VN2 es un array de tipo REAL, de dimensión (N)
!>          El vector con las normas exactas de las columnas.
!>

WORK

!>          WORK es un array de tipo COMPLEX, de dimensión (N)
!>

Detailed Description

subroutine slaqp2 (integer m, integer n, integer offset, real, dimension( lda, * ) a, integer lda, integer, dimension( * ) jpvt, real, dimension( * ) tau, real, dimension( * ) vn1, real, dimension( * ) vn2, real, dimension( * ) work)

SLAQP2 computes a QR factorization with column pivoting of the matrix block.

Purpose:

!>
!> SLAQP2 computes a QR factorization with column pivoting of
!> the block A(OFFSET+1:M,1:N).
!> The block A(1:OFFSET,1:N) is accordingly pivoted, but not factorized.
!>

Parameters

M 
!>          M is INTEGER
!>          The number of rows of the matrix A. M >= 0.
!>

N

!>          N is INTEGER
!>          The number of columns of the matrix A. N >= 0.
!>

OFFSET

!>          OFFSET is INTEGER
!>          The number of rows of the matrix A that must be pivoted
!>          but no factorized. OFFSET >= 0.
!>

A

!>          A is REAL array, dimension (LDA,N)
!>          On entry, the M-by-N matrix A.
!>          On exit, the upper triangle of block A(OFFSET+1:M,1:N) is
!>          the triangular factor obtained; the elements in block
!>          A(OFFSET+1:M,1:N) below the diagonal, together with the
!>          array TAU, represent the orthogonal matrix Q as a product of
!>          elementary reflectors. Block A(1:OFFSET,1:N) has been
!>          accordingly pivoted, but no factorized.
!>

LDA

!>          LDA is INTEGER
!>          The leading dimension of the array A. LDA >= max(1,M).
!>

JPVT

!>          JPVT is INTEGER array, dimension (N)
!>          On entry, if JPVT(i) .ne. 0, the i-th column of A is permuted
!>          to the front of A*P (a leading column); if JPVT(i) = 0,
!>          the i-th column of A is a free column.
!>          On exit, if JPVT(i) = k, then the i-th column of A*P
!>          was the k-th column of A.
!>

TAU

!>          TAU is REAL array, dimension (min(M,N))
!>          The scalar factors of the elementary reflectors.
!>

VN1

!>          VN1 is REAL array, dimension (N)
!>          The vector with the partial column norms.
!>

VN2

!>          VN2 is REAL array, dimension (N)
!>          The vector with the exact column norms.
!>

WORK

!>          WORK is REAL array, dimension (N)
!>
