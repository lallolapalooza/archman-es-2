CLAED0 utilizado por CSTEDC. Calcula todos los valores propios y los vectores propios correspondientes de una matriz tridiagonal simétrica no reducida utilizando el método de divide y vencerás.

Propósito:

!>
!> Utilizando el método de divide y vencerás, CLAED0 calcula todos los
!> valores propios de una matriz tridiagonal simétrica que es un bloque
!> diagonal de los de la reducción de una matriz hermitiana densa o
!> de banda y los correspondientes vectores propios de la matriz densa o
!> de banda.
!>

Parámetros

QSIZ 
!>          QSIZ es INTEGER
!>         La dimensión de la matriz unitaria utilizada para reducir
!>         la matriz completa a tridiagonal.  QSIZ >= N si ICOMPQ = 1.
!>

N

!>          N es INTEGER
!>         La dimensión de la matriz tridiagonal simétrica.  N >= 0.
!>

D

!>          D es array REAL, dimensión (N)
!>         En la entrada, los elementos diagonales de la matriz
!>         tridiagonal.
!>         En la salida, los valores propios en orden ascendente.
!>

E

!>          E es array REAL, dimensión (N-1)
!>         En la entrada, los elementos fuera de la diagonal de la matriz
!>         tridiagonal.
!>         En la salida, E ha sido destruido.
!>

Q

!>          Q es array COMPLEX, dimensión (LDQ,N)
!>         En la entrada, Q debe contener una matriz QSIZ x N cuya
!>         columnas son ortonormales unitariamente. Es parte de la matriz
!>         unitaria que reduce la matriz hermitiana densa completa a una
!>         matriz tridiagonal simétrica (reducible).
!>

LDQ

!>          LDQ es INTEGER
!>         La dimensión principal del array Q.  LDQ >= max(1,N).
!>

IWORK

!>          IWORK es array INTEGER,
!>         la dimensión de IWORK debe ser al menos
!>                      6 + 6*N + 5*N*lg N
!>                      ( lg( N ) = entero más pequeño k
!>                                  tal que 2^k >= N )
!>

RWORK

!>          RWORK es array REAL,
!>                               dimensión (1 + 3*N + 2*N*lg N + 3*N**2)
!>                        ( lg( N ) = entero más pequeño k
!>                                    tal que 2^k >= N )
!>

QSTORE

!>          QSTORE es array COMPLEX, dimensión (LDQS, N)
!>         Se utiliza para almacenar partes de la matriz de
!>         vectores propios cuando ocurren multiplicaciones de la
!>         matriz de actualización.
!>

LDQS

!>          LDQS es INTEGER
!>         La dimensión principal del array QSTORE.
!>         LDQS >= max(1,N).
!>

INFO

!>          INFO es INTEGER
!>          = 0:  salida exitosa.
!>          < 0:  si INFO = -i, el i-ésimo argumento tenía un valor
!>                ilegal.
!>          > 0:  El algoritmo no pudo calcular un valor propio al
!>                trabajar en la submatriz ubicada en las filas y
!>                columnas INFO/(N+1) hasta mod(INFO,N+1).
!>

NAME


dlaed0, slaed0, zlaed0 - Computes all
  eigenvalues and corresponding eigenvectors of a symmetric tridiagonal matrix
  using the divide and conquer method.

DESCRIPTION


The routines dlaed0, slaed0, and zlaed0 are
  subroutines used by the master routines `xstedc` (standard) and `xstedr`
  (reduced). They compute all eigenvalues and corresponding eigenvectors of an
  unreduced symmetric tridiagonal matrix using the divide and conquer method.
  This is generally the most efficient method for computing all eigenvalues and
  eigenvectors of a dense symmetric or Hermitian matrix.


The divide and conquer method is composed of the following steps:


    
  
  1. Divide: The symmetric tridiagonal matrix T is split into
    two smaller tridiagonal matrices T1 and T2 of size N/2 x N/2.
    2. 
  
  2. Conquer: Recursively compute the eigenvalues and
    eigenvectors of T1 and T2.
    3. 
  
  3. Combine: Combine the solutions of the subproblems to
    obtain the eigenvalues and eigenvectors of T.
    4. 



The recursive process is stopped when the size of the subproblem
  is small enough, at which point a standard algorithm is used. The eigenvalues
  are computed using a specialized algorithm that avoids explicit deflation.
  After the eigenvalues are computed, the eigenvectors are computed using a
  variant of the divide and conquer algorithm.

NAME


LAED0 - This subroutine forms the initial vectors for the divide and
    conquer SVD.






SYNOPSIS


    SUBROUTINE LAED0(
        ICNTLS,
        RNTLS,
        IINFO,
        RINFO
    )
    INTEGER                          ICNTLS(20)
    REAL                             RNTLS(20)
    INTEGER                          IINFO(40)
    REAL                             RINFO(40)







Detailed Description


This subroutine forms the initial vectors for the divide and
    conquer SVD.


The divide and conquer SVD routine calls this subroutine to
    initialize the matrix with the initial vectors for the divide and conquer
    SVD. This routine computes the initial vectors for the SVD
    subproblem. It also computes the initial values for the diagonal
    elements of the matrix.


The problem is to find the singular values and the right singular
    vectors of the matrix A.


The singular value decomposition is a factorization of a real or
    complex matrix. There are various ways to define the SVD, but the most
    common definition is for the matrix A to be a rectangular matrix
    (i.e. m x n) with real or complex entries.


The SVD of A is a factorization of the form


    A = U Sigma V^T



where U is an m x m orthogonal matrix, V is an n x n orthogonal
    matrix, and Sigma is an m x n rectangular diagonal matrix with nonnegative
    real numbers on the diagonal.


The diagonal entries Sigma_ii = sigma_i are known as the singular
    values or latent values of A and non-negative.


The columns of U are the left singular vectors and the columns of V
    are the right singular vectors.


The routine initializes the matrix with the initial vectors for the
    divide and conquer SVD.


This routine is called by ZGEESX and ZGESVX.


The updating matrix multiplies take place.


LDQS


         LDQS is INTEGER
        The leading dimension of the array QSTORE.
        LDQS >= max(1,N).



INFO


         INFO is INTEGER
         = 0:  successful exit.
         < 0:  if INFO = -i, the i-th argument had an illegal value.
         > 0:  The algorithm failed to compute an eigenvalue while
               working on the submatrix lying in rows and columns
               INFO/(N+1) through mod(INFO,N+1).
