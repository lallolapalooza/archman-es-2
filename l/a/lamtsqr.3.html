CLAMTSQR

Propósito:

!>
!>      CLAMTSQR sobrescribe la matriz compleja general M por N, C, con
!>
!>
!>                 SIDE = 'L'     SIDE = 'R'
!> TRANS = 'N':      Q * C          C * Q
!> TRANS = 'C':      Q**H * C       C * Q**H
!>      donde Q es una matriz unitaria compleja definida como el producto
!>      de reflectores elementales en bloque calculados por la
!>      factorización QR delgada y alta (CLATSQR)
!>

Parámetros

SIDE 
!>          SIDE es CHARACTER*1
!>          = 'L': aplicar Q o Q**H desde la Izquierda;
!>          = 'R': aplicar Q o Q**H desde la Derecha.
!>

TRANS

!>          TRANS es CHARACTER*1
!>          = 'N':  Sin transponer, aplicar Q;
!>          = 'C':  Transpuesta Conjugada, aplicar Q**H.
!>

M

!>          M es INTEGER
!>          El número de filas de la matriz A.  M >=0.
!>

N

!>          N es INTEGER
!>          El número de columnas de la matriz C. N >= 0.
!>

K

!>          K es INTEGER
!>          El número de reflectores elementales cuyo producto define
!>          la matriz Q. M >= K >= 0;
!>
!>

MB

!>          MB es INTEGER
!>          El tamaño de bloque a utilizar en la QR en bloque.
!>          MB > N. (debe ser el mismo que CLATSQR)
!>

NB

!>          NB es INTEGER
!>          El tamaño de bloque de columna a utilizar en la QR en bloque.
!>          N >= NB >= 1.
!>

A

!>          A es un array COMPLEX, dimension (LDA,K)
!>          La i-ésima columna debe contener el vector que define el
!>          reflector elemental en bloque H(i), para i = 1,2,...,k, como
!>          retornado por CLATSQR en las primeras k columnas de
!>          su array argumento A.
!>

LDA

!>          LDA es INTEGER
!>          La dimensión principal del array A.
!>          Si SIDE = 'L', LDA >= max(1,M);
!>          si SIDE = 'R', LDA >= max(1,N).
!>

T

!>          T es un array COMPLEX, dimension
!>          ( N * Número de bloques(CEIL(M-K/MB-K)),
!>          Los reflectores de bloque triangulares superiores en bloque almacenados en forma compacta
!>          como una secuencia de bloques triangulares superiores. Ver más abajo
!>          para más detalles.
!>

LDT

!>          LDT es INTEGER
!>          La dimensión principal del array T. LDT >= NB.
!>

C

!>          C es un array COMPLEX, dimension (LDC,N)
!>          A la entrada, la matriz C de M por N.
!>          A la salida, C es sobrescrita por Q*C o Q**H*C o C*Q**H o C*Q.
!>

LDC

!>          LDC es INTEGER
!>          La dimensión principal del array C. LDC >= max(1,M).
!>

WORK

!>          (espacio de trabajo) array COMPLEX, dimension (MAX(1,LWORK))
!>          A la salida, si INFO = 0, WORK(1) devuelve el LWORK mínimo.
!>

LWORK

!>          LWORK es INTEGER
!>          La dimensión del array WORK.
!>          Si MIN(M,N,K) = 0, LWORK >= 1.
!>          Si SIDE = 'L', LWORK >= max(1,N*NB).
!>          Si SIDE = 'R', LWORK >= max(1,MB*NB).
!>
!>          Si LWORK = -1, entonces se asume una consulta de espacio de trabajo; la rutina
!>          solo calcula el tamaño mínimo del array WORK, devuelve
!>          este valor como la primera entrada del array WORK, y no se emite ningún mensaje
!>          de error relacionado con LWORK por XERBLA.
!>

INFO

!>          INFO es INTEGER
!>          = 0:  salida exitosa
!>          < 0:  si INFO = -i, el i-ésimo argumento tenía un valor ilegal
!>

Detalles adicionales:

!> Factorización QR delgada y alta (TSQR) realiza QR mediante una secuencia de transformaciones unitarias,
!> representando Q como un producto de otras matrices unitarias
!>   Q = Q(1) * Q(2) * . . . * Q(k)
!> donde cada Q(i) pone a cero las entradas subdiagonales de un bloque de MB filas de A:
!>   Q(1) pone a cero las entradas subdiagonales de las filas 1:MB de A
!>   Q(2) pone a cero las filas MB-N inferiores de las filas [1:N,MB+1:2*MB-N] de A
!>   Q(3) pone a cero las filas MB-N inferiores de las filas [1:N,2*MB-N+1:3*MB-2*N] de A
!>   . . .
!>
!> Q(1) se calcula por GEQRT, que representa Q(1) mediante vectores de Householder
!> almacenados debajo de la diagonal de las filas 1:MB de A, y mediante reflectores
!> de bloque triangulares superiores, almacenados en el array T(1:LDT,1:N).
!> Para más información, véase Detalles adicionales en GEQRT.
!>
!> Q(i) para i>1 se calcula por TPQRT, que representa Q(i) mediante vectores de Householder
!> almacenados en las filas [(i-1)*(MB-N)+N+1:i*(MB-N)+N] de A, y mediante reflectores
!> de bloque triangulares superiores, almacenados en el array T(1:LDT,(i-1)*N+1:i*N).
!> La última Q(k) puede usar menos filas.
!> Para más información, véase Detalles adicionales en TPQRT.
!>
!> Para más detalles sobre el algoritmo general, véase la descripción de
!> TSQR Secuencial en la Sección 2.2 de [1].
!>
!> [1] “Communication-Optimal Parallel and Sequential QR and LU Factorizations,”
!>     J. Demmel, L. Grigori, M. Hoemmen, J. Langou,
!>     SIAM J. Sci. Comput, vol. 34, no. 1, 2012
!>

NAME

lamtsqr - the recursive blocking update

SYNOPSIS

 subroutine slamtsqr (character side, character trans, integer m, integer n, integer k, integer mb, integer nb, real, dimension( lda, * ) a, integer lda, real, dimension( ldt, * ) t, integer ldt, real, dimension( ldc, * ) c, integer ldc, real, dimension( * ) work, integer lwork, integer info)
     complex*16, dimension( lda, * ) a, integer lda,
     complex*16, dimension( ldt, * ) t, integer ldt,
     complex*16, dimension( ldc, * ) c, integer ldc,
     complex*16, dimension( * ) work, integer lwork, integer info)

Detailed Description

This subroutine is the recursive blocking update step in the sequential TSQR algorithm. It applies the blocked elementary reflectors, generated by the ZLATSQR or ZLATSQR routine, to the matrix C.

The TSQR algorithm computes the QR factorization of an M-by-N matrix A, where M >> N. It uses a sequence of recursive steps to reduce the problem to a sequence of TSQR problems of size (MB-N)-by-N, which are solved by GEQRT. The elementary reflectors are then applied to an M-by-K matrix C, usually K=N, using the ZLATSQR routine.

For a detailed description of the overall algorithm, see the description of Sequential TSQR in Section 2.2 of [1].

[1] “Communication-Optimal Parallel and Sequential QR and LU Factorizations,” J. Demmel, L. Grigori, M. Hoemmen, J. Langou, SIAM J. Sci. Comput, vol. 34, no. 1, 2012.
