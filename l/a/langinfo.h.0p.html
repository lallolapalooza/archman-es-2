NOMBRE

langinfo.h — constantes de información de idioma

SINOPSIS

#include <langinfo.h>

DESCRIPCIÓN

El archivo de cabecera <langinfo.h> definirá las constantes simbólicas utilizadas para identificar elementos de datos langinfo (ver nl_langinfo()).

El archivo de cabecera <langinfo.h> definirá el tipo locale_t tal como se describe en <locale.h>.

El archivo de cabecera <langinfo.h> definirá el tipo nl_item tal como se describe en <nl_types.h>.

El archivo de cabecera <langinfo.h> definirá las siguientes constantes simbólicas con tipo nl_item. Las entradas bajo Categoría indican en qué categoría de setlocale() se define cada elemento.

NAME

langinfo.h

language information constants

SYNOPSIS

<langinfo.h>

<nl_types.h>

char *nl_langinfo(nl_item);
char *nl_langinfo_l(nl_item, locale_t);

DESCRIPTION

The <langinfo.h> header file shall define the following symbolic names for the items that can be returned by the nl_langinfo() and nl_langinfo_l() functions. These symbolic names shall be of type nl_item.

The symbolic constants related to the LC_TIME category are:

ABDAY_1, ABDAY_2, ABDAY_3, ABDAY_4, ABDAY_5, ABDAY_6, ABDAY_7
DAY_1, DAY_2, DAY_3, DAY_4, DAY_5, DAY_6, DAY_7
ABMON_1, ABMON_2, ABMON_3, ABMON_4, ABMON_5, ABMON_6, ABMON_7,
ABMON_8, ABMON_9, ABMON_10, ABMON_11, ABMON_12
MON_1, MON_2, MON_3, MON_4, MON_5, MON_6, MON_7,
MON_8, MON_9, MON_10, MON_11, MON_12
AM_STR
PM_STR
D_FMT
D_T_FMT
T_FMT
T_FMT_AMPM
ERA
ERA_D_FMT
ERA_D_T_FMT
ERA_T_FMT
ALT_DIGITS

The symbolic constants related to the LC_NUMERIC category are:

RADIXCHAR
THOUSEP

The symbolic constants related to the LC_MESSAGES category are:

YESEXPR
NOEXPR

The symbolic constants related to the LC_MONETARY category are:

CRNCYSTR

The symbolic constant related to the LC_CTYPE category is:

CODESET

The nl_langinfo() function shall return a pointer to a string describing the current locale corresponding to the argument item. The nl_langinfo_l() function shall return a pointer to a string describing the locale represented by loc corresponding to the argument item.

If the value of item is not a valid nl_item, or if the corresponding string is not defined in the current locale or the locale represented by loc, the behavior is unspecified.

The strings pointed to shall be in the character set specified by the LC_CTYPE category of the locale. The returned pointers shall remain valid until the locale is changed by a call to setlocale() or until the program terminates. The application shall not modify the strings pointed to.

The nl_langinfo() and nl_langinfo_l() functions may return pointers to static char arrays, which may be overwritten by subsequent calls to the same function or other functions that return pointers to static char arrays.

Inclusion of the <langinfo.h> header may also make visible all symbols from <nl_types.h>.

The following sections are informative.

APPLICATION USAGE

Wherever possible, users are advised to use functions compatible with those in the ISO C standard to access items of langinfo data. In particular, the strftime() function should be used to access date and time information defined in category LC_TIME. The localeconv() function should be used to access information corresponding to RADIXCHAR, THOUSEP, and CRNCYSTR.
