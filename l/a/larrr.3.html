subrutina dlarrr (entero n, doble precisión, dimensión( * ) d, doble precisión, dimensión( * ) e, entero info)

DLARRR realiza pruebas para decidir si la matriz tridiagonal simétrica T justifica cálculos costosos que garantizan alta precisión relativa en los autovalores.

Propósito:

!>
!> Realizar pruebas para decidir si la matriz tridiagonal simétrica T
!> justifica cálculos costosos que garantizan alta precisión relativa
!> en los autovalores.
!>

Parámetros

N 
!>          N es ENTERO
!>          El orden de la matriz. N > 0.
!>

D

!>          D es un array de DOBLE PRECISIÓN, dimensión (N)
!>          Los N elementos diagonales de la matriz tridiagonal T.
!>

E

!>          E es un array de DOBLE PRECISIÓN, dimensión (N)
!>          En la entrada, las primeras (N-1) entradas contienen los
!>          elementos subdiagonales de la matriz tridiagonal T; E(N) se
!>          establece en CERO.
!>

INFO

!>          INFO es ENTERO
!>          INFO = 0(predeterminado) : la matriz justifica cálculos que
!>                                     preservan la precisión relativa.
!>          INFO = 1                : la matriz justifica cálculos que
!>                                     garantizan solo precisión absoluta.
!>
