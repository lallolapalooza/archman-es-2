subrutina clapmt (logical forwrd, integer m, integer n, complex, dimension( ldx, * ) x, integer ldx, integer, dimension( * ) k)

CLAPMT realiza una permutación hacia adelante o hacia atrás de las columnas de una matriz.

Propósito:

!>
!> CLAPMT reorganiza las columnas de la matriz M por N, X, según lo especificado
!> por la permutación K(1),K(2),...,K(N) de los enteros 1,...,N.
!> Si FORWRD = .TRUE., permutación hacia adelante:
!>
!>      X(*,K(J)) se mueve a X(*,J) para J = 1,2,...,N.
!>
!> Si FORWRD = .FALSE., permutación hacia atrás:
!>
!>      X(*,J) se mueve a X(*,K(J)) para J = 1,2,...,N.
!>

Parámetros

FORWRD 
!>          FORWRD es LOGICAL
!>          = .TRUE., permutación hacia adelante
!>          = .FALSE., permutación hacia atrás
!>

M

!>          M es INTEGER
!>          El número de filas de la matriz X. M >= 0.
!>

N

!>          N es INTEGER
!>          El número de columnas de la matriz X. N >= 0.
!>

X

!>          X es un array COMPLEX, dimension (LDX,N)
!>          En la entrada, la matriz M por N, X.
!>          En la salida, X contiene la matriz permutada X.
!>

LDX

!>          LDX es INTEGER
!>          La dimensión principal del array X, LDX >= MAX(1,M).
!>

K

!>          K es un array INTEGER, dimension (N)
!>          En la entrada, K contiene el vector de permutación. K se utiliza como
!>          espacio de trabajo interno, pero se restablece a su valor original al
!>          salir.
!>

NAME

lapmt - LAPACK routine

SYNOPSIS

SUBROUTINE LAPMT(
             FORWARD, M, N, X, LDX, K
    )

From LAPACK version 3.12.0

Detailed Description

LAPMT applies a sequence of orthogonal transformations to an M x N matrix X. It is intended to be used in conjunction with the routines ZGEBAL and ZGBAL, which apply to the Schur decomposition, and ZSCHUR which applies to the Schur decomposition of a general matrix.

Arguments

FORWARD

CHARACTER*1.

.

Specifies whether to apply the forward or backward permutation.

= 'F': Forward permutation. K(i) is the permutation for row i,
          i.e., X(i,j) is moved to X(K(i),j).
= 'B': Backward permutation. K(i) is the permutation for row i,
          i.e., X(K(i),j) is moved to X(i,j).
M

INTEGER.

.

The number of rows of the matrix X. M >= 0.

N

INTEGER.

.

The number of columns of the matrix X. N >= 0.

X

COMPLEX*16 array, dimension (LDX,N).

.

On entry, the M by N matrix X.

On exit, X contains the permuted matrix X.

LDX

INTEGER.

.

The leading dimension of the array X, LDX >= MAX(1,M).

K

INTEGER array, dimension (N).

.

On entry, K contains the permutation vector. K is used as

internal workspace, but reset to its original value on

output.
