NOMBRE

lavalite - Simulación 3D OpenGL de una lámpara de lava.

SINOPSIS

lavalite [--display host:display.screen] [--window] [--root] [--window-id number] [--visual visual] [--delay microseconds] [--fps] [--style style ] [--spin xyz ] [--no-spin ] [--speed float ] [--resolution integer ] [--count integer ] [--no-smooth ] [--wireframe ] [--impatient ] [--lava-color color ] [--fluid-color color ] [--base-color color ] [--table-color color ] [--fluid-texture filename ] [--base-texture filename ] [--table-texture filename ]

DESCRIPCIÓN

El programa lavalite muestra una simulación 3D de la famosa lámpara del mismo nombre. Requiere un ordenador rápido con soporte OpenGL rápido.

OPCIONES

lavalite acepta las siguientes opciones:

--window
Dibuja en una ventana recién creada. Este es el valor por defecto.
--root
Dibuja en la ventana raíz.
--window-id number
Dibuja en la ventana especificada.
--visual visual
Especifica qué visual usar. Los valores legales son el nombre de una clase visual, o el número de ID (decimal o hexadecimal) de un visual específico.
--style style
Especifica qué modelo de lámpara dibujar. Los modelos disponibles son: Classic, Giant, Cone y Rocket. Por defecto: aleatorio.
--spin xyz
Alrededor de qué ejes debe girar automáticamente el modelo. Por defecto es "Z", lo que significa que rota horizontalmente, pero de lo contrario cabecea o rueda.
--no-spin
Igual que --spin ''.
--speed float
Un número que controla la frecuencia con la que se lanzan nuevas burbujas: puedes pensar en esto como relacionado con el calor de la bombilla en la base. Por defecto: 0.003.
--delay usecs
El retraso entre pasos de la animación; por defecto es 30000 (0.03 segundo).
--resolution integer
El tamaño de la cuadrícula a partir de la cual se crea la malla que se utiliza para poligonizar las burbujas. valores más altos darán burbujas con un aspecto muy suave, a expensas de la velocidad. Por defecto: 40.

Las opciones "-resolution 10 --no-smooth" tienen un aspecto interesante.

--fps
Muestra la tasa de fotogramas actual, la carga de la CPU y el recuento de polígonos.
--count integer
El número máximo de burbujas que pueden estar en movimiento a la vez. Por defecto: 3.
--no-smooth
Desactiva el suavizado: los objetos en la escena estarán facetados.
--wireframe
Renderiza todos los objetos en modo de alambre en lugar de sólidos.
--impatient
Proporciona esta opción si lo eres. Esto precalentará la lámpara, por lo que al iniciar, el primer fotograma mostrará una burbuja ya a medio camino por la lámpara.
--lava-color color
Especifica el color de las burbujas. Por defecto: rojo.
--fluid-color color
Especifica el color del fluido en el que flotan las burbujas. Por defecto: azul claro.
--base-color color
Especifica el color de la base de la lámpara y de la tapa superior de la botella. Por defecto: gris muy oscuro.
--table-color color
Especifica el color de la mesa sobre la que se encuentra la lámpara. Por defecto: negro (lo que significa que es invisible).
--fluid-texture filename
Un archivo de imagen para envolver el cristal.

Ten en cuenta que en la mayoría de los sistemas, las texturas GL deben tener dimensiones que sean potencias de dos.

Ten en cuenta también que tanto los colores como las texturas se aplican: por lo tanto, si aplicas una textura y no aparece, intenta especificar el color correspondiente como "blanco". De lo contrario, la combinación de ambos podría ser demasiado oscura para verla.

--base-texture filename
Un archivo de imagen para envolver la base de la lámpara y la tapa superior de la botella.
--table-texture texture
Un archivo de imagen para extender sobre la mesa sobre la que se encuentra la lámpara.

ENTORNO

DISPLAY
para obtener el host y el número de pantalla por defecto.
XENVIRONMENT
para obtener el nombre de un archivo de recursos que anula los recursos globales almacenados en la propiedad RESOURCE_MANAGER.
XSCREENSAVER_WINDOW
El ID de la ventana a usar con --root.

lavalite.6

DESCRIPTION

LavaLite es una herramienta de línea de comandos diseñada para simplificar el desarrollo y la gestión de sitios web construidos con el generador de sitios estáticos LavaLite. Permite a los usuarios crear nuevos proyectos, generar sitios estáticos, servir sitios localmente para previsualización y administrar dependencias.

OPTIONS

new <project-name>
Crea un nuevo proyecto de LavaLite con el nombre especificado.
build
Genera el sitio estático en el directorio de salida (normalmente public).
serve
Inicia un servidor web local para previsualizar el sitio. Normalmente se sirve desde el directorio de salida.
install <package-name>
Instala un paquete o tema de LavaLite.
help
Muestra información de ayuda sobre los comandos disponibles.

ENVIRONMENT

LAVALITE_DIR: Especifica el directorio de configuración de LavaLite. Si no está establecido, se utilizará el directorio de inicio del usuario.
