subrutina dlartgp (doble precisión f, doble precisión g, doble precisión cs, doble precisión sn, doble precisión r)

DLARTGP genera una rotación de plano para que la diagonal sea no negativa.

Propósito:

!>
!> DLARTGP genera una rotación de plano tal que
!>
!>    [  CS  SN  ]  .  [ F ]  =  [ R ]   donde CS**2 + SN**2 = 1.
!>    [ -SN  CS  ]     [ G ]     [ 0 ]
!>
!> Esta es una versión más lenta y precisa de la rutina DROTG de BLAS Nivel 1,
!> con las siguientes otras diferencias:
!>    F y G no se modifican al regresar.
!>    Si G=0, entonces CS=(+/-)1 y SN=0.
!>    Si F=0 y (G .ne. 0), entonces CS=0 y SN=(+/-)1.
!>
!> El signo se elige de modo que R >= 0.
!>

Parámetros

F 
!>          F es DOBLE PRECISION
!>          El primer componente del vector a rotar.
!>

G

!>          G es DOBLE PRECISION
!>          El segundo componente del vector a rotar.
!>

CS

!>          CS es DOBLE PRECISION
!>          El coseno de la rotación.
!>

SN

!>          SN es DOBLE PRECISION
!>          El seno de la rotación.
!>

R

!>          R es DOBLE PRECISION
!>          El componente no nulo del vector rotado.
!>
!>  Esta versión tiene algunas sentencias comentadas para seguridad de hilos
!>  (los parámetros de máquina se calculan en cada entrada). 10 feb 03, SJH.
!>
