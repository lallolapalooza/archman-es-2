DOCUMENTACIÓN DE LA FUNCIÓN

subrutina clatps (character uplo, character trans, character diag, character normin, integer n, complex, dimension( * ) ap, complex, dimension( * ) x, real scale, real, dimension( * ) cnorm, integer info)

CLATPS resuelve un sistema de ecuaciones triangular con la matriz almacenada en formato empaquetado.

Propósito:

!>
!> CLATPS resuelve uno de los sistemas triangulares
!>
!>    A * x = s*b,  A**T * x = s*b,  o  A**H * x = s*b,
!>
!> con escalado para prevenir desbordamientos, donde A es una matriz
!> triangular superior o inferior almacenada en formato empaquetado. Aquí
!> A**T denota la transpuesta de A, A**H denota la transpuesta conjugada de A,
!> x y b son vectores de n elementos, y s es un factor de escalado,
!> usualmente menor o igual a 1, elegido para que los componentes de x sean
!> menores que el umbral de desbordamiento. Si el problema no escalado no
!> causa desbordamiento, se llama a la rutina BLAS de Nivel 2 CTPSV. Si la
!> matriz A es singular (A(j,j) = 0 para algún j), entonces s se establece en 0
!> y se devuelve una solución no trivial a A*x = 0.
!>

Parámetros

UPLO 
!>          UPLO es CHARACTER*1
!>          Especifica si la matriz A es triangular superior o inferior.
!>          = 'U':  Triangular superior
!>          = 'L':  Triangular inferior
!>

TRANS

!>          TRANS es CHARACTER*1
!>          Especifica la operación aplicada a A.
!>          = 'N':  Resolver A * x = s*b     (Sin transpuesta)
!>          = 'T':  Resolver A**T * x = s*b  (Transpuesta)
!>          = 'C':  Resolver A**H * x = s*b  (Transpuesta conjugada)
!>

DIAG

!>          DIAG es CHARACTER*1
!>          Especifica si la matriz A es unitaria triangular o no.
!>          = 'N':  Triangular no unitaria
!>          = 'U':  Unitaria triangular
!>

NORMIN

!>          NORMIN es CHARACTER*1
!>          Especifica si CNORM ha sido establecido o no.
!>          = 'Y':  CNORM contiene las normas de las columnas en la entrada
!>          = 'N':  CNORM no está establecido en la entrada. A la salida,
!>                  las normas se calcularán y se almacenarán en CNORM.
!>

N

!>          N es INTEGER
!>          El orden de la matriz A.  N >= 0.
!>

AP

!>          AP es un array COMPLEX de dimensión (N*(N+1)/2)
!>          La matriz triangular superior o inferior A, empaquetada por
!>          columnas en un array lineal. La j-ésima columna de A se
!>          almacena en el array AP como sigue:
!>          si UPLO = 'U', AP(i + (j-1)*j/2) = A(i,j) para 1<=i<=j;
!>          si UPLO = 'L', AP(i + (j-1)*(2n-j)/2) = A(i,j) para j<=i<=n.
!>

X

!>          X es un array COMPLEX de dimensión (N)
!>          En la entrada, el lado derecho b del sistema triangular.
!>          A la salida, X se sobrescribe con el vector solución x.
!>

SCALE

!>          SCALE es REAL
!>          El factor de escalado s para el sistema triangular
!>             A * x = s*b,  A**T * x = s*b,  o  A**H * x = s*b.
!>          Si SCALE = 0, la matriz A es singular o está mal escalada, y
!>          el vector x es una solución exacta o aproximada a A*x = 0.
!>

CNORM

!>          CNORM es un array REAL de dimensión (N)
!>
!>          Si NORMIN = 'Y', CNORM es un argumento de entrada y CNORM(j)
!>          contiene las normas de la parte no diagonal de la j-ésima columna
!>          de A. Si TRANS = 'N', CNORM(j) debe ser mayor o igual a la
!>          norma infinito, y si TRANS = 'T' o 'C', CNORM(j) debe ser mayor
!>          o igual a la norma 1.
!>
!>          Si NORMIN = 'N', CNORM es un argumento de salida y CNORM(j)
!>          devuelve la norma 1 de la parte no diagonal de la j-ésima columna
!>          de A.
!>

INFO

!>          INFO es INTEGER
!>          = 0:  salida exitosa
!>          < 0:  si INFO = -k, el k-ésimo argumento tuvo un valor ilegal
!>

Detalles Adicionales:

!>
!>  Se calcula un límite aproximado de x; si este es menor que el
!>  desbordamiento, se llama a CTPSV, de lo contrario, se utiliza un código
!>  específico que verifica posibles desbordamientos o divisiones por cero
!>  en cada operación.
!>
!>  Se utiliza un esquema columna por columna para resolver A*x = b. El
!>  algoritmo básico si A es triangular inferior es
!>
!>       x[1:n] := b[1:n]
!>       para j = 1, ..., n
!>            x(j) := x(j) / A(j,j)
!>            x[j+1:n] := x[j+1:n] - x(j) * A[j+1:n,j]
!>       fin
!>
!>  Definimos límites para los componentes de x después de j iteraciones
!>  del bucle:
!>     M(j) = límite de x[1:j]
!>     G(j) = límite de x[j+1:n]
!>  Inicialmente, sea M(0) = 0 y G(0) = max{x(i), i=1,...,n}.
!>
!>  Entonces, para la iteración j+1, tenemos
!>     M(j+1) <= G(j) / | A(j+1,j+1) |
!>     G(j+1) <= G(j) + M(j+1) * | A[j+2:n,j+1] |
!>            <= G(j) ( 1 + CNORM(j+1) / | A(j+1,j+1) | )
!>
!>  donde CNORM(j+1) es mayor o igual a la norma infinito de la
!>  columna j+1 de A, sin contar la diagonal. Por lo tanto
!>
!>     G(j) <= G(0) producto ( 1 + CNORM(i) / | A(i,i) | )
!>                  1<=i<=j
!>  y
!>
!>     |x(j)| <= ( G(0) / |A(j,j)| ) producto ( 1 + CNORM(i) / |A(i,i)| )
!>                                   1<=i< j
!>
!>  Como |x(j)| <= M(j), usamos la rutina BLAS de Nivel 2 CTPSV si el
!>  recíproco del M(j) máximo, j=1,..,n, es mayor que
!>  max(desbordamiento inferior, 1/desbordamiento superior).
!>
!>  El límite de x(j) también se usa para determinar cuándo un paso en el
!>  método columna por columna se puede realizar sin temor a desbordamiento.
!>  Si el límite calculado es mayor que una constante grande, x se escala para
!>  prevenir el desbordamiento, pero si el límite se desborda, x se establece
!>  en 0, x(j) en 1, y scale en 0, y se encuentra una solución no trivial a
!>  A*x = 0.
!>
!>  De manera similar, se utiliza un esquema fila por fila para resolver
!>  A**T *x = b o A**H *x = b. El algoritmo básico para A triangular
!>  superior es
!>
!>       para j = 1, ..., n
!>            x(j) := ( b(j) - A[1:j-1,j]' * x[1:j-1] ) / A(j,j)
!>       fin
!>
!>  Calculamos simultáneamente dos límites
!>       G(j) = límite de ( b(i) - A[1:i-1,i]' * x[1:i-1] ), 1<=i<=j
!>       M(j) = límite de x(i), 1<=i<=j
!>
!>  Los valores iniciales son G(0) = 0, M(0) = max{b(i), i=1,..,n}, y
!>  añadimos la restricción G(j) >= G(j-1) y M(j) >= M(j-1) para j >= 1.
!>  Entonces, el límite de x(j) es
!>
!>       M(j) <= M(j-1) * ( 1 + CNORM(j) ) / | A(j,j) |
!>
!>            <= M(0) * producto ( ( 1 + CNORM(i) ) / |A(i,i)| )
!>                      1<=i<=j
!>
!>  y podemos llamar de forma segura a CTPSV si 1/M(n) y 1/G(n) son ambos
!>  mayores que max(desbordamiento inferior, 1/desbordamiento superior).
!>

DESCRIPTION

DLATPS solves a triangular system of equations with the matrix held in packed storage.

Purpose:

!>
!> DLATPS solves one of the triangular systems
!>
!>    A *x = s*b  or  A**T*x = s*b
!>
!> with scaling to prevent overflow, where A is an upper or lower
!> triangular matrix stored in packed form.  Here A**T denotes the
!> transpose of A, x and b are n-element vectors, and s is a scaling
!> factor, usually less than or equal to 1, chosen so that the
!> components of x will be less than the overflow threshold.  If the
!> unscaled problem will not cause overflow, the Level 2 BLAS routine
!> DTPSV is called. If the matrix A is singular (A(j,j) = 0 for some j),
!> then s is set to 0 and a non-trivial solution to A*x = 0 is returned.

!>
!>  A rough bound on x is computed; if that is less than overflow, DTPSV
!>  is called, otherwise, specific code is used which checks for possible
!>  overflow or divide-by-zero at every operation.
!>
!>  A columnwise scheme is used for solving A*x = b.  The basic algorithm
!>  if A is lower triangular is
!>
!>       x[1:n] := b[1:n]
!>       for j = 1, ..., n
!>            x(j) := x(j) / A(j,j)
!>            x[j+1:n] := x[j+1:n] - x(j) * A[j+1:n,j]
!>       end
!>
!>  Define bounds on the components of x after j iterations of the loop:
!>     M(j) = bound on x[1:j]
!>     G(j) = bound on x[j+1:n]
!>  Initially, let M(0) = 0 and G(0) = max{x(i), i=1,...,n}.
!>
!>  Then for iteration j+1 we have
!>     M(j+1) <= G(j) / | A(j+1,j+1) |
!>     G(j+1) <= G(j) + M(j+1) * | A[j+2:n,j+1] |
!>            <= G(j) ( 1 + CNORM(j+1) / | A(j+1,j+1) | )
!>
!>  where CNORM(j+1) is greater than or equal to the infinity-norm of
!>  column j+1 of A, not counting the diagonal.  Hence
!>
!>     G(j) <= G(0) product ( 1 + CNORM(i) / | A(i,i) | )

!>                                   1<=i< j

!>  reciprocal of the largest M(j), j=1,..,n, is larger than
!>  max(underflow, 1/overflow).
!>
!>  The bound on x(j) is also used to determine when a step in the
!>  columnwise method can be performed without fear of overflow.  If
!>  the computed bound is greater than a large constant, x is scaled to
!>  prevent overflow, but if the bound overflows, x is set to 0, x(j) to
!>  1, and scale to 0, and a non-trivial solution to A*x = 0 is found.

!>    M(j+1) <= G(j) / | A(j+1,j+1) |
!>    G(j+1) <= G(j) + M(j+1) * | A[j+2:n,j+1] |
!>           <= G(j) ( 1 + CNORM(j+1) / | A(j+1,j+1) | )
!>
!> donde CNORM(j+1) es mayor o igual que la infinito-norma de la columna
!> j+1 de A, sin contar la diagonal. Por lo tanto
!>
!>    G(j) <= G(0) producto ( 1 + CNORM(i) / | A(i,i) | )
!>                 1<=i<=j
!> y
!>
!>    |x(j)| <= ( G(0) / |A(j,j)| ) producto ( 1 + CNORM(i) / |A(i,i)| )
!>                                  1<=i< j
!>
!> Dado que |x(j)| <= M(j), usamos la rutina BLAS de Nivel 2 STPSV si el
!> recíproco del M(j) máximo, j=1,...,n, es mayor que
!> max(underflow, 1/overflow).
!>
!> El límite de x(j) también se utiliza para determinar cuándo se puede
!> realizar un paso en el método columna por columna sin temor a
!> desbordamiento. Si el límite calculado es mayor que una constante grande,
!> x se escala para prevenir el desbordamiento, pero si el límite se
!> desborda, x se establece en 0, x(j) en 1, y scale en 0, y se encuentra
!> una solución no trivial para A*x = 0.
!>
!> De manera similar, se utiliza un esquema fila por fila para resolver
!> A**T*x = b. El algoritmo básico para A triangular superior es
!>
!>      para j = 1, ..., n
!>           x(j) := ( b(j) - A[1:j-1,j]**T * x[1:j-1] ) / A(j,j)
!>      fin
!>
!> Calculamos simultáneamente dos límites
!>      G(j) = límite de ( b(i) - A[1:i-1,i]**T * x[1:i-1] ), 1<=i<=j
!>      M(j) = límite de x(i), 1<=i<=j
!>
!> Los valores iniciales son G(0) = 0, M(0) = max{b(i), i=1,..,n}, y
!> añadimos la restricción G(j) >= G(j-1) y M(j) >= M(j-1) para j >= 1.
!> Entonces el límite de x(j) es
!>
!>      M(j) <= M(j-1) * ( 1 + CNORM(j) ) / | A(j,j) |
!>
!>           <= M(0) * producto ( ( 1 + CNORM(i) ) / |A(i,i)| )
!>                     1<=i<=j
!>
!> y podemos llamar de forma segura a STPSV si 1/M(n) y 1/G(n) son ambos
!> mayores que max(underflow, 1/overflow).

subrutina ZLATPS (caracter UPLO, caracter TRANS, caracter DIAG, caracter NORMIN, entero N, complejo*16, dimension( * ) AP, complejo*16, dimension( * ) X, doble precision ESCALA, doble precision, dimension( * ) CNORM, entero INFO)

ZLATPS resuelve un sistema de ecuaciones triangular con la matriz en almacenamiento empaquetado.

Propósito:

!>
!> ZLATPS resuelve uno de los sistemas triangulares
!>
!>    A * x = s*b,  A**T * x = s*b,  o  A**H * x = s*b,
!>
!> con escalado para prevenir el desbordamiento, donde A es una matriz
!> triangular superior o inferior almacenada en forma empaquetada. Aquí
!> A**T denota la transpuesta de A, A**H denota la transpuesta conjugada
!> de A, x y b son vectores de n elementos, y s es un factor de escalado,
!> usualmente menor o igual que 1, elegido de modo que los componentes de
!> x sean menores que el umbral de desbordamiento. Si el problema no
!> escalado no causa desbordamiento, se llama a la rutina BLAS de Nivel 2
!> ZTPSV. Si la matriz A es singular (A(j,j) = 0 para algún j), entonces s
!> se establece en 0 y se devuelve una solución no trivial a A*x = 0.
!>

Parámetros

UPLO 
!>          UPLO es CHARACTER*1
!>          Especifica si la matriz A es triangular superior o inferior.
!>          = 'U':  Triangular superior
!>          = 'L':  Triangular inferior

TRANS

!>          TRANS es CHARACTER*1
!>          Especifica la operación aplicada a A.
!>          = 'N':  Resolver A * x = s*b     (Sin transponer)
!>          = 'T':  Resolver A**T * x = s*b  (Transpuesta)
!>          = 'C':  Resolver A**H * x = s*b  (Transpuesta conjugada)

DIAG

!>          DIAG es CHARACTER*1
!>          Especifica si la matriz A es unitriangular o no.
!>          = 'N':  Triangular no unitaria
!>          = 'U':  Triangular unitaria

NORMIN

!>          NORMIN es CHARACTER*1
!>          Especifica si CNORM ha sido establecido o no.
!>          = 'Y':  CNORM contiene las normas de las columnas en la entrada
!>          = 'N':  CNORM no está establecido en la entrada. En la salida,
!>                  las normas se calcularán y se almacenarán en CNORM.

N

!>          N es INTEGER
!>          El orden de la matriz A.  N >= 0.

AP

!>          AP es un array de COMPLEX*16, de dimensión (N*(N+1)/2)
!>          La matriz triangular superior o inferior A, empaquetada columna
!>          por columna en un array lineal. La j-ésima columna de A se
!>          almacena en el array AP de la siguiente manera:
!>          si UPLO = 'U', AP(i + (j-1)*j/2) = A(i,j) para 1<=i<=j;
!>          si UPLO = 'L', AP(i + (j-1)*(2n-j)/2) = A(i,j) para j<=i<=n.

X

!>          X es un array de COMPLEX*16, de dimensión (N)
!>          En la entrada, el lado derecho b del sistema triangular.
!>          En la salida, X se sobrescribe con el vector solución x.

SCALE

!>          SCALE es DOUBLE PRECISION
!>          El factor de escalado s para el sistema triangular
!>             A * x = s*b,  A**T * x = s*b,  o  A**H * x = s*b.
!>          Si SCALE = 0, la matriz A es singular o está mal escalada, y
!>          el vector x es una solución exacta o aproximada a A*x = 0.

CNORM

!>          CNORM es un array de DOUBLE PRECISION, de dimensión (N)
!>
!>          Si NORMIN = 'Y', CNORM es un argumento de entrada y CNORM(j)
!>          contiene la norma de la parte fuera de la diagonal de la j-ésima
!>          columna de A. Si TRANS = 'N', CNORM(j) debe ser mayor o igual
!>          que la infinito-norma, y si TRANS = 'T' o 'C', CNORM(j)
!>          debe ser mayor o igual que la 1-norma.
!>
!>          Si NORMIN = 'N', CNORM es un argumento de salida y CNORM(j)
!>          devuelve la 1-norma de la parte fuera de la diagonal de la j-ésima
!>          columna de A.

INFO

!>          INFO es INTEGER
!>          = 0:  salida exitosa
!>          < 0:  si INFO = -k, el k-ésimo argumento tuvo un valor ilegal
