subrutina claqhp (character uplo, integer n, complex, dimension( * ) ap, real, dimension( * ) s, real scond, real amax, character equed)

CLAQHP escala una matriz Hermitiana almacenada en formato empaquetado.

Propósito:

!>
!> CLAQHP equilibra una matriz Hermitiana A utilizando los factores de escala
!> en el vector S.
!>

Parámetros

UPLO 
!>          UPLO es CHARACTER*1
!>          Especifica si la parte triangular superior o inferior de la
!>          matriz Hermitiana A está almacenada.
!>          = 'U':  Triangular superior
!>          = 'L':  Triangular inferior
!>

N

!>          N es INTEGER
!>          El orden de la matriz A.  N >= 0.
!>

AP

!>          AP es un array COMPLEX, de dimensión (N*(N+1)/2)
!>          En la entrada, la parte triangular superior o inferior de la matriz
!>          Hermitiana A, empaquetada columna por columna en un array lineal. La
!>          j-ésima columna de A se almacena en el array AP como sigue:
!>          si UPLO = 'U', AP(i + (j-1)*j/2) = A(i,j) para 1<=i<=j;
!>          si UPLO = 'L', AP(i + (j-1)*(2n-j)/2) = A(i,j) para j<=i<=n.
!>
!>          En la salida, la matriz equilibrada:  diag(S) * A * diag(S), en
!>          el mismo formato de almacenamiento que A.
!>

S

!>          S es un array REAL, de dimensión (N)
!>          Los factores de escala para A.
!>

SCOND

!>          SCOND es REAL
!>          Razón entre el S(i) más pequeño y el S(i) más grande.
!>

AMAX

!>          AMAX es REAL
!>          Valor absoluto del elemento de matriz más grande.
!>

EQUED

!>          EQUED es CHARACTER*1
!>          Especifica si se realizó o no el equilibrado.
!>          = 'N':  No se realizó equilibrado.
!>          = 'Y':  Se realizó el equilibrado, es decir, A ha sido reemplazada por
!>                  diag(S) * A * diag(S).
!>

Parámetros Internos:

!>  THRESH es un valor umbral utilizado para decidir si se debe realizar el escalado
!>  basándose en la razón de los factores de escala. Si SCOND < THRESH,
!>  se realiza el escalado.
!>
!>  LARGE y SMALL son valores umbral utilizados para decidir si se debe realizar el
!>  escalado basándose en el tamaño absoluto del elemento de matriz más grande.
!>  Si AMAX > LARGE o AMAX < SMALL, se realiza el escalado.
!>

NAME

dlaqsp, slaqsp, zlaqhp, zlaqsp – equilibrates a general symmetric-definite matrix in packed storage.

DESCRIPTION

The routines dlaqsp, slaqsp, zlaqhp and zlaqsp are subroutines to equilibrate a symmetric/Hermitian matrix in packed storage, using scaling factors computed by sppequ.

These routines are only called by ``xGGSVP``, and are not intended for direct use by the user.

dlaqhp

dlaqhp equilibrates a symmetric matrix A using the scaling factors in the vector S.

Purpose:

!>
!> Dlaqhp equilibrates a symmetric matrix A using the scaling factors
!> in the vector S.
!>

Parameters:

UPLO 
!>          UPLO is CHARACTER*1
!>          Specifies whether the upper or lower triangular part of the
!>          symmetric matrix A is stored.
!>          = 'U':  Upper triangular
!>          = 'L':  Lower triangular
!>

N

!>          N is INTEGER
!>          The order of the matrix A.  N >= 0.
!>

AP

!>          AP is DOUBLE PRECISION array, dimension (N*(N+1)/2)
!>          On entry, the upper or lower triangle of the symmetric matrix
!>          A, packed columnwise in a linear array.  The j-th column of A
!>          is stored in the array AP as follows:
!>          if UPLO = 'U', AP(i + (j-1)*j/2) = A(i,j) for 1<=i<=j;
!>          if UPLO = 'L', AP(i + (j-1)*(2n-j)/2) = A(i,j) for j<=i<=n.
!>
!>          On exit, the equilibrated matrix:  diag(S) * A * diag(S), in
!>          the same storage format as A.
!>

S

!>          S is DOUBLE PRECISION array, dimension (N)
!>          The scale factors for A.
!>

SCOND

!>          SCOND is DOUBLE PRECISION
!>          Ratio of the smallest S(i) to the largest S(i).
!>

AMAX

!>          AMAX is DOUBLE PRECISION
!>          Absolute value of largest matrix entry.
!>

EQUED

!>          EQUED is CHARACTER*1
!>          Specifies whether or not equilibration was done.
!>          = 'N':  No equilibration.
!>          = 'Y':  Equilibration was done, i.e., A has been replaced by
!>                  diag(S) * A * diag(S).
!>

Internal Parameters:

!>  THRESH is a threshold value used to decide if scaling should be done
!>  based on the ratio of the scaling factors.  If SCOND < THRESH,
!>  scaling is done.
!>
!>  LARGE and SMALL are threshold values used to decide if scaling should
!>  be done based on the absolute size of the largest matrix element.
!>  If AMAX > LARGE or AMAX < SMALL, scaling is done.
!>

NAME

laqhp

scales a Hermitian matrix (equilibrated)

SYNOPSIS

SUBROUTINE LAQHP( UPLO, N, A, LDA, S, SEP )
  
    IMPLICIT NONE
  
    LOGICAL :: UPLO
    INTEGER :: N, LDA
    REAL :: A( LDA, * )
    REAL :: S( * )
    REAL :: SEP

Detailed Description

LAQHP scales a Hermitian matrix A by the diagonal matrix S.

Arguments:

UPLO
CHARACTER*1 Assume that A is Upper triangular or Lower triangular as described by UPLO.
N
INTEGER The number of columns of the matrix A. N ≥ 0.
A
DOUBLE PRECISION array, dimension (LDA,N) The matrix A to be scaled. A is N x N.
LDA
INTEGER The leading dimension of the array A.
S
DOUBLE PRECISION array, dimension (N) The scaling factors, with S(i) being the scale factor for the i-th row and i-th column.
SEP
DOUBLE PRECISION The equilibrium scaling factor computed by LAQSPY.

The matrix A is scaled by S so that the resulting matrix B has row sums and column sums equal in magnitude. This is done to avoid problems with large or small entries when solving linear systems.

The scaling is done by computing B = S * A * S, where S is a diagonal matrix with diagonal entries S(i). The result is stored back into A.

The operation is defined as follows:

      if UPLO = 'U' then
         do j = 1 to N
            do i = 1 to j
               A(i,j) = S(i) * A(i,j) * S(j)
            end do
         end do
      else
         do j = 1 to N
            do i = j to N
               A(i,j) = S(i) * A(i,j) * S(j)
            end do
         end do
      end if
