función real cla_porpvgrw (character*1 uplo, integer ncols, complex, dimension( lda, * ) a, integer lda, complex, dimension( ldaf, * ) af, integer ldaf, real, dimension( * ) work)

CLA_PORPVGRW calcula el factor de crecimiento recíproco del pivote norm(A)/norm(U) para una matriz simétrica o Hermítica definida positiva.

Propósito:

!>
!>
!> CLA_PORPVGRW calcula el factor de crecimiento recíproco del pivote
!> norm(A)/norm(U). Se utiliza la norma . Si esto es
!> mucho menor que 1, la estabilidad de la factorización LU de la
!> matriz (equilibrada) A podría ser pobre. Esto también significa que
!> la solución X, los números de condición estimados y los límites de
!> error podrían no ser fiables.
!>

Parámetros

UPLO 
!>          UPLO es CHARACTER*1
!>       = 'U': El triángulo superior de A está almacenado;
!>       = 'L': El triángulo inferior de A está almacenado.
!>

NCOLS

!>          NCOLS es INTEGER
!>     El número de columnas de la matriz A. NCOLS >= 0.
!>

A

!>          A es un array COMPLEX, de dimensión (LDA,N)
!>     En la entrada, la matriz A de N por N.
!>

LDA

!>          LDA es INTEGER
!>     La dimensión principal del array A. LDA >= max(1,N).
!>

AF

!>          AF es un array COMPLEX, de dimensión (LDAF,N)
!>     El factor triangular U o L de la factorización de Cholesky
!>     A = U**T*U o A = L*L**T, tal como se calcula por CPOTRF.
!>

LDAF

!>          LDAF es INTEGER
!>     La dimensión principal del array AF. LDAF >= max(1,N).
!>

WORK

!>          WORK es un array REAL, de dimensión (2*N)
!>
