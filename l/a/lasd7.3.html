DLASD7 fusiona los dos conjuntos de valores singulares en un único conjunto ordenado. Luego intenta reducir el tamaño del problema. Usado por sbdsdc.

Propósito:

!>
!> DLASD7 fusiona los dos conjuntos de valores singulares en un único
!> conjunto ordenado. Luego intenta reducir el tamaño del problema. Hay
!> dos formas en las que puede ocurrir la deflación: cuando dos o más valores
!> singulares están muy juntos o si hay una entrada diminuta en el vector Z.
!> Por cada ocurrencia de este tipo, el orden del problema de la ecuación
!> secular relacionada se reduce en uno.
!>
!> DLASD7 es llamado desde DLASD6.
!>

Parámetros

ICOMPQ 
!>          ICOMPQ es INTEGER
!>          Especifica si se van a calcular vectores singulares
!>          en forma compacta, como sigue:
!>          = 0: Calcular solo valores singulares.
!>          = 1: Calcular vectores singulares de la matriz
!>               bidiagonal superior en forma compacta.
!>

NL

!>          NL es INTEGER
!>         La dimensión de fila del bloque superior. NL >= 1.
!>

NR

!>          NR es INTEGER
!>         La dimensión de fila del bloque inferior. NR >= 1.
!>

SQRE

!>          SQRE es INTEGER
!>         = 0: el bloque inferior es una matriz cuadrada NR por NR.
!>         = 1: el bloque inferior es una matriz rectangular NR por (NR+1).
!>
!>         La matriz bidiagonal tiene
!>         N = NL + NR + 1 filas y
!>         M = N + SQRE >= N columnas.
!>

K

!>          K es INTEGER
!>         Contiene la dimensión de la matriz no deflactada, este es
!>         el orden de la ecuación secular relacionada. 1 <= K <=N.
!>

D

!>          D es un array de DOUBLE PRECISION, dimensión ( N )
!>         En la entrada D contiene los valores singulares de las dos submatrices
!>         a combinar. En la salida D contiene los últimos (N-K) valores
!>         singulares actualizados (los que fueron deflactados) ordenados
!>         en orden creciente.
!>

Z

!>          Z es un array de DOUBLE PRECISION, dimensión ( M )
!>         En la salida Z contiene el vector fila de actualización en la ecuación
!>         secular.
!>

ZW

!>          ZW es un array de DOUBLE PRECISION, dimensión ( M )
!>         Espacio de trabajo para Z.
!>

VF

!>          VF es un array de DOUBLE PRECISION, dimensión ( M )
!>         En la entrada, VF(1:NL+1) contiene los primeros componentes de todos
!>         los vectores singulares derechos del bloque superior; y VF(NL+2:M)
!>         contiene los primeros componentes de todos los vectores singulares
!>         derechos del bloque inferior. En la salida, VF contiene los primeros
!>         componentes de todos los vectores singulares derechos de la matriz
!>         bidiagonal.
!>

VFW

!>          VFW es un array de DOUBLE PRECISION, dimensión ( M )
!>         Espacio de trabajo para VF.
!>

VL

!>          VL es un array de DOUBLE PRECISION, dimensión ( M )
!>         En la entrada, VL(1:NL+1) contiene los últimos componentes de todos
!>         los vectores singulares derechos del bloque superior; y VL(NL+2:M)
!>         contiene los últimos componentes de todos los vectores singulares
!>         derechos del bloque inferior. En la salida, VL contiene los últimos
!>         componentes de todos los vectores singulares derechos de la matriz
!>         bidiagonal.
!>

VLW

!>          VLW es un array de DOUBLE PRECISION, dimensión ( M )
!>         Espacio de trabajo para VL.
!>

ALPHA

!>          ALPHA es DOUBLE PRECISION
!>         Contiene el elemento diagonal asociado con la fila añadida.
!>

BETA

!>          BETA es DOUBLE PRECISION
!>         Contiene el elemento fuera de la diagonal asociado con la fila
!>         añadida.
!>

DSIGMA

!>          DSIGMA es un array de DOUBLE PRECISION, dimensión ( N )
!>         Contiene una copia de los elementos diagonales (K-1 valores
!>         singulares y un cero) en la ecuación secular.
!>

IDX

!>          IDX es un array INTEGER, dimensión ( N )
!>         Contendrá la permutación utilizada para ordenar el contenido de
!>         D en orden ascendente.
!>

IDXP

!>          IDXP es un array INTEGER, dimensión ( N )
!>         Contendrá la permutación utilizada para colocar los valores
!>         deflactados de D al final del array. En la salida IDXP(2:K)
!>         apunta a los valores D no deflactados y IDXP(K+1:N)
!>         apunta a los valores singulares deflactados.
!>

IDXQ

!>          IDXQ es un array INTEGER, dimensión ( N )
!>         Contiene la permutación que ordena por separado los dos
!>         subproblemas en D en orden ascendente. Note que las entradas
!>         en la primera mitad de esta permutación deben primero moverse
!>         una posición hacia atrás; y las entradas en la segunda mitad
!>         deben tener primero NL+1 sumado a sus valores.
!>

PERM

!>          PERM es un array INTEGER, dimensión ( N )
!>         Las permutaciones (de deflación y ordenación) que se aplicarán
!>         a cada bloque singular. No referenciado si ICOMPQ = 0.
!>

GIVPTR

!>          GIVPTR es INTEGER
!>         El número de rotaciones de Givens que ocurrieron en este
!>         subproblema. No referenciado si ICOMPQ = 0.
!>

GIVCOL

NAME

dlasd7 - dlasd7 merges the two sets of singular values together into a single sorted set. Then it tries to deflate the size of the problem. Used by sbdsdc.

SYNOPSIS

subroutine dlasd7 (integer icompq, integer nl, integer nr, integer sqre, integer k, double precision, dimension( * ) d, double precision, dimension( * ) z, double precision, dimension( * ) zw, double precision, dimension( * ) vf, double precision, dimension( * ) vfw, double precision, dimension( * ) vl, double precision, dimension( * ) vlw, double precision alpha, double precision beta, double precision, dimension( * ) dsigma, integer, dimension( * ) idx, integer, dimension( * ) idxp, integer, dimension( * ) idxq, integer, dimension( * ) perm, integer givptr, integer, dimension( ldgcol, * ) givcol, integer ldgcol, double precision, dimension( ldgnum, * ) givnum, integer ldgnum, double precision c, double precision s, integer info)

Purpose

!>
!> SLASD7 merges the two sets of singular values together into a single
!> sorted set. Then it tries to deflate the size of the problem. There
!> are two ways in which deflation can occur:  when two or more singular
!> values are close together or if there is a tiny entry in the Z
!> vector. For each such occurrence the order of the related
!> secular equation problem is reduced by one.
!>
!> SLASD7 is called from SLASD6.
!>

Parameters

ICOMPQ

!>          ICOMPQ is INTEGER
!>          Specifies whether singular vectors are to be computed
!>          in compact form, as follows:
!>          = 0: Compute singular values only.
!>          = 1: Compute singular vectors of upper
!>               bidiagonal matrix in compact form.
!>

NL

!>          NL is INTEGER
!>         The row dimension of the upper block. NL >= 1.
!>

NR

!>          NR is INTEGER
!>         The row dimension of the lower block. NR >= 1.
!>

SQRE

!>          SQRE is INTEGER
!>         = 0: the lower block is an NR-by-NR square matrix.
!>         = 1: the lower block is an NR-by-(NR+1) rectangular matrix.
!>
!>         The bidiagonal matrix has
!>         N = NL + NR + 1 rows and
!>         M = N + SQRE >= N columns.
!>

K

!>          K is INTEGER
!>         Contains the dimension of the non-deflated matrix, this is
!>         the order of the related secular equation. 1 <= K <=N.
!>

D

!>          D is DOUBLE PRECISION array, dimension ( N )
!>         On entry D contains the singular values of the two submatrices
!>         to be combined. On exit D contains the trailing (N-K) updated
!>         singular values (those which were deflated) sorted into
!>         increasing order.
!>

Z

!>          Z is DOUBLE PRECISION array, dimension ( M )
!>         On exit Z contains the updating row vector in the secular
!>         equation.
!>

ZW

!>          ZW is DOUBLE PRECISION array, dimension ( M )
!>         Workspace for Z.
!>

VF

!>          VF is DOUBLE PRECISION array, dimension ( M )
!>         On entry, VF(1:NL+1) contains the first components of all
!>         right singular vectors of the upper block; and VF(NL+2:M)
!>         contains the first components of all right singular vectors
!>         of the lower block. On exit, VF contains the first components
!>         of all right singular vectors of the bidiagonal matrix.
!>

VFW

!>          VFW is DOUBLE PRECISION array, dimension ( M )
!>         Workspace for VF.
!>

VL

!>          VL is DOUBLE PRECISION array, dimension ( M )
!>         On entry, VL(1:NL+1) contains the  last components of all
!>         right singular vectors of the upper block; and VL(NL+2:M)
!>         contains the last components of all right singular vectors
!>         of the lower block. On exit, VL contains the last components
!>         of all right singular vectors of the bidiagonal matrix.
!>

VLW

!>          VLW is DOUBLE PRECISION array, dimension ( M )
!>         Workspace for VL.
!>

ALPHA

!>          ALPHA is DOUBLE PRECISION
!>         Contains the diagonal element associated with the added row.
!>

BETA

!>          BETA is DOUBLE PRECISION
!>         Contains the off-diagonal element associated with the added
!>         row.
!>

DSIGMA

!>          DSIGMA is DOUBLE PRECISION array, dimension ( N )
!>         Contains a copy of the diagonal elements (K-1 singular values
!>         and one zero) in the secular equation.
!>

IDX

!>          IDX is INTEGER array, dimension ( N )
!>         This will contain the permutation used to sort the contents of
!>         D into ascending order.
!>

IDXP

!>          IDXP is INTEGER array, dimension ( N )
!>         This will contain the permutation used to place deflated
!>         values of D at the end of the array. On output IDXP(2:K)
!>         points to the nondeflated D-values and IDXP(K+1:N)
!>         points to the deflated singular values.
!>

IDXQ

!>          IDXQ is INTEGER array, dimension ( N )
!>         This contains the permutation which separately sorts the two
!>         sub-problems in D into ascending order.  Note that entries in
!>         the first half of this permutation must first be moved one
!>         position backward; and entries in the second half
!>         must first have NL+1 added to their values.
!>

PERM

!>          PERM is INTEGER array, dimension ( N )
!>         The permutations (from deflation and sorting) to be applied
!>         to each singular block. Not referenced if ICOMPQ = 0.
!>

GIVPTR

!>          GIVPTR is INTEGER
!>         The number of Givens rotations which took place in this
!>         subproblem. Not referenced if ICOMPQ = 0.
!>

GIVCOL

!>          GIVCOL is INTEGER array, dimension ( LDGCOL, 2 )
!>         Each pair of numbers indicates a pair of columns to take place
!>         in a Givens rotation. Not referenced if ICOMPQ = 0.
!>

LDGCOL

!>          LDGCOL is INTEGER
!>         The leading dimension of GIVCOL, must be at least N.
!>

GIVNUM

!>          GIVNUM is DOUBLE PRECISION array, dimension ( LDGNUM, 2 )
!>         Each number indicates the C or S value to be used in the
!>         corresponding Givens rotation. Not referenced if ICOMPQ = 0.
!>

LDGNUM

!>          LDGNUM is INTEGER
!>         The leading dimension of GIVNUM, must be at least N.
!>

C

!>          C is DOUBLE PRECISION
!>         C contains garbage if SQRE =0 and the C-value of a Givens
!>         rotation related to the right null space if SQRE = 1.
!>

S

!>          S is DOUBLE PRECISION
!>         S contains garbage if SQRE =0 and the S-value of a Givens
!>         rotation related to the right null space if SQRE = 1.
!>

INFO

!>          INFO is INTEGER
!>         = 0:  successful exit.
!>         < 0:  if INFO = -i, the i-th argument had an illegal value.
!>
