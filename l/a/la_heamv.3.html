subrutina cla_heamv (integer uplo, integer n, real alpha, complex, dimension( lda, * ) a, integer lda, complex, dimension( * ) x, integer incx, real beta, real, dimension( * ) y, integer incy)

CLA_HEAMV calcula un producto matriz-vector utilizando una matriz indefinida Hermítica para calcular límites de error.

Propósito:

!>
!> CLA_SYAMV realiza la operación matriz-vector
!>
!>         y := alpha*abs(A)*abs(x) + beta*abs(y),
!>
!> donde alpha y beta son escalares, x e y son vectores y A es una
!> matriz simétrica de n por n.
!>
!> Esta función se utiliza principalmente para calcular límites de error.
!> Para proteger contra el desbordamiento durante la evaluación, los
!> componentes del vector resultante se perturban lejos de cero por (N+1)
!> veces el umbral de desbordamiento. Para evitar errores innecesariamente
!> grandes para estructuras de bloque incrustadas en matrices generales,
!> los componentes cero no se perturban. Se considera un cero
!> si todas las multiplicaciones involucradas
!> en el cálculo de esa entrada tienen al menos un multiplicando cero.
!>

Parámetros

UPLO 
!>          UPLO es INTEGER
!>           En la entrada, UPLO especifica si la parte triangular superior
!>           o inferior de la matriz A se va a referenciar como
!>           sigue:
!>
!>              UPLO = BLAS_UPPER   Solo se referenciará la parte triangular
!>                                  superior de A.
!>
!>              UPLO = BLAS_LOWER   Solo se referenciará la parte triangular
!>                                  inferior de A.
!>
!>           Sin cambios en la salida.
!>

N

!>          N es INTEGER
!>           En la entrada, N especifica el número de columnas de la matriz A.
!>           N debe ser al menos cero.
!>           Sin cambios en la salida.
!>

ALPHA

!>          ALPHA es REAL.
!>           En la entrada, ALPHA especifica el escalar alpha.
!>           Sin cambios en la salida.
!>

A

!>          A es una matriz COMPLEX, dimensión ( LDA, n ).
!>           Antes de la entrada, la parte principal m por n de la matriz A debe
!>           contener la matriz de coeficientes.
!>           Sin cambios en la salida.
!>

LDA

!>          LDA es INTEGER
!>           En la entrada, LDA especifica la primera dimensión de A tal como
!>           se declaró en el programa (sub)llamador. LDA debe ser al menos
!>           max( 1, n ).
!>           Sin cambios en la salida.
!>

X

!>          X es una matriz COMPLEX, dimensión
!>           ( 1 + ( n - 1 )*abs( INCX ) )
!>           Antes de la entrada, la matriz X incrementada debe contener
!>           el vector x.
!>           Sin cambios en la salida.
!>

INCX

!>          INCX es INTEGER
!>           En la entrada, INCX especifica el incremento para los elementos
!>           de X. INCX no debe ser cero.
!>           Sin cambios en la salida.
!>

BETA

!>          BETA es REAL.
!>           En la entrada, BETA especifica el escalar beta. Cuando BETA se
!>           suministra como cero, Y no necesita ser establecida en la entrada.
!>           Sin cambios en la salida.
!>

Y

!>          Y es una matriz REAL, dimensión
!>           ( 1 + ( n - 1 )*abs( INCY ) )
!>           Antes de la entrada con BETA distinto de cero, la matriz Y
!>           incrementada debe contener el vector y. En la salida, Y se
!>           sobrescribe con el vector y actualizado.
!>

INCY

!>          INCY es INTEGER
!>           En la entrada, INCY especifica el incremento para los elementos
!>           de Y. INCY no debe ser cero.
!>           Sin cambios en la salida.
!>

Signature

subroutine cla_syamv (integer uplo, integer n, complex alpha, complex, dimension( lda, * ) a, integer lda, complex, dimension( * ) x, integer incx, real beta, real, dimension( * ) y, integer incy)

CLA_SYAMV computes a matrix-vector product using a symmetric indefinite matrix to calculate error bounds.

Purpose:

!>
!> CLA_SYAMV  performs the matrix-vector operation
!>
!>         y := alpha*abs(A)*abs(x) + beta*abs(y),
!>
!> where alpha and beta are scalars, x and y are vectors and A is an
!> n by n symmetric matrix.
!>
!> This function is primarily used in calculating error bounds.
!> To protect against underflow during evaluation, components in
!> the resulting vector are perturbed away from zero by (N+1)
!> times the underflow threshold.  To prevent unnecessarily large
!> errors for block-structure embedded in general matrices,
!>  zero components are not perturbed.  A zero
!> entry is considered  if all multiplications involved
!> in computing that entry have at least one zero multiplicand.
!>

Parameters

UPLO 
!>          UPLO is INTEGER
!>           On entry, UPLO specifies whether the upper or lower
!>           triangular part of the array A is to be referenced as
!>           follows:
!>
!>              UPLO = BLAS_UPPER   Only the upper triangular part of A
!>                                  is to be referenced.
!>
!>              UPLO = BLAS_LOWER   Only the lower triangular part of A
!>                                  is to be referenced.
!>
!>           Unchanged on exit.
!>

N

!>          N is INTEGER
!>           On entry, N specifies the number of columns of the matrix A.
!>           N must be at least zero.
!>           Unchanged on exit.
!>

ALPHA

!>          ALPHA is COMPLEX .
!>           On entry, ALPHA specifies the scalar alpha.
!>           Unchanged on exit.
!>

A

!>          A is COMPLEX array, dimension ( LDA, n ).
!>           Before entry, the leading m by n part of the array A must
!>           contain the matrix of coefficients.
!>           Unchanged on exit.
!>

LDA

!>          LDA is INTEGER
!>           On entry, LDA specifies the first dimension of A as declared
!>           in the calling (sub) program. LDA must be at least
!>           max( 1, n ).
!>           Unchanged on exit.
!>

X

!>          X is COMPLEX array, dimension
!>           ( 1 + ( n - 1 )*abs( INCX ) )
!>           Before entry, the incremented array X must contain the
!>           vector x.
!>           Unchanged on exit.
!>

INCX

!>          INCX is INTEGER
!>           On entry, INCX specifies the increment for the elements of
!>           X. INCX must not be zero.
!>           Unchanged on exit.
!>

BETA

!>          BETA is REAL .
!>           On entry, BETA specifies the scalar beta. When BETA is
!>           supplied as zero then Y need not be set on input.
!>           Unchanged on exit.
!>

Y

!>          Y is REAL array, dimension
!>           ( 1 + ( n - 1 )*abs( INCY ) )
!>           Before entry with BETA non-zero, the incremented array Y
!>           must contain the vector y. On exit, Y is overwritten by the
!>           updated vector y.
!>

INCY

!>          INCY is INTEGER
!>           On entry, INCY specifies the increment for the elements of
!>           Y. INCY must not be zero.
!>           Unchanged on exit.
!>

subroutine zla_syamv (integer uplo, integer n, double precision alpha, complex*16, dimension( lda, * ) a, integer lda, complex*16, dimension( * ) x, integer incx, double precision beta, double precision, dimension( * ) y, integer incy)

ZLA_SYAMV calcula un producto matriz-vector utilizando una matriz simétrica indefinida para calcular límites de error.

Propósito:

!>
!> ZLA_SYAMV  realiza la operación matriz-vector
!>
!>         y := alpha*abs(A)*abs(x) + beta*abs(y),
!>
!> donde alpha y beta son escalares, x e y son vectores y A es una
!> matriz simétrica de n por n.
!>
!> Esta función se utiliza principalmente para calcular límites de error.
!> Para proteger contra el subdesbordamiento durante la evaluación, los componentes
!> en el vector resultante se perturban lejos de cero por (N+1)
!> veces el umbral de subdesbordamiento. Para evitar errores innecesariamente grandes
!> para estructuras de bloques incrustadas en matrices generales,
!> los componentes cero no se perturban. Una entrada cero
!> se considera si todas las multiplicaciones involucradas
!> en el cálculo de esa entrada tienen al menos un multiplicador cero.
!>

Parámetros

UPLO 
!>          UPLO es INTEGER
!>           En la entrada, UPLO especifica si la parte triangular superior o inferior
!>           del array A se va a referenciar de la siguiente manera:
!>
!>              UPLO = BLAS_UPPER   Solo se hará referencia a la parte triangular superior de A.
!>
!>              UPLO = BLAS_LOWER   Solo se hará referencia a la parte triangular inferior de A.
!>
!>           Sin cambios a la salida.
!>

N

!>          N es INTEGER
!>           En la entrada, N especifica el número de columnas de la matriz A.
!>           N debe ser al menos cero.
!>           Sin cambios a la salida.
!>

ALPHA

!>          ALPHA es DOUBLE PRECISION .
!>           En la entrada, ALPHA especifica el escalar alpha.
!>           Sin cambios a la salida.
!>

A

!>          A es un array COMPLEX*16, dimensión ( LDA, n ).
!>           Antes de la entrada, la parte principal m por n del array A debe
!>           contener la matriz de coeficientes.
!>           Sin cambios a la salida.
!>

LDA

!>          LDA es INTEGER
!>           En la entrada, LDA especifica la primera dimensión de A tal como se declaró
!>           en el programa (sub)llamador. LDA debe ser al menos
!>           max( 1, n ).
!>           Sin cambios a la salida.
!>

X

!>          X es un array COMPLEX*16, dimensión al menos
!>           ( 1 + ( n - 1 )*abs( INCX ) )
!>           Antes de la entrada, el array X incrementado debe contener el
!>           vector x.
!>           Sin cambios a la salida.
!>

INCX

!>          INCX es INTEGER
!>           En la entrada, INCX especifica el incremento para los elementos de
!>           X. INCX no debe ser cero.
!>           Sin cambios a la salida.
!>

BETA

!>          BETA es DOUBLE PRECISION .
!>           En la entrada, BETA especifica el escalar beta. Cuando BETA se
!>           suministra como cero, Y no necesita establecerse a la entrada.
!>           Sin cambios a la salida.
!>

Y

!>          Y es un array DOUBLE PRECISION, dimensión
!>           ( 1 + ( n - 1 )*abs( INCY ) )
!>           Antes de la entrada con BETA no cero, el array Y incrementado
!>           debe contener el vector y. A la salida, Y se sobrescribe con el
!>           vector y actualizado.
!>

INCY

!>          INCY es INTEGER
!>           En la entrada, INCY especifica el incremento para los elementos de
!>           Y. INCY no debe ser cero.
!>           Sin cambios a la salida.
!>
