LASTLOG(8) Comandos de administración del sistema LASTLOG(8)

NOMBRE

lastlog - informa sobre el último inicio de sesión de todos los usuarios o de un usuario dado

SINOPSIS

lastlog [opciones]

DESCRIPCIÓN

lastlog formatea e imprime el contenido del archivo de registro del último inicio de sesión, /var/log/lastlog. Se imprimirán el nombre de usuario, el puerto y la hora del último inicio de sesión. El comportamiento por defecto (sin flags) hace que se impriman las entradas de lastlog, ordenadas según su orden en /etc/passwd.

OPCIONES

Las opciones que se aplican al comando lastlog son:

-b, --before DÍAS

Imprime solo los registros de lastlog más antiguos que DÍAS.

-C, --clear

Borra el registro de lastlog de un usuario. Esta opción solo se puede usar junto con -u (--user)).

-h, --help

Muestra el mensaje de ayuda y sale.

-R, --root CHROOT_DIR

Aplica los cambios en el directorio CHROOT_DIR y usa los archivos de configuración del directorio CHROOT_DIR. Solo se admiten rutas absolutas.

-S, --set

Establece el registro de lastlog de un usuario a la hora actual. Esta opción solo se puede usar junto con -u (--user)).

-t, --time DÍAS

Imprime los registros de lastlog más recientes que DÍAS.

-u, --user USUARIO|RANGO

Imprime el registro de lastlog del usuario o usuarios especificados.

Los usuarios pueden especificarse por nombre de inicio de sesión, un ID de usuario numérico o un RANGO de usuarios. Este RANGO de usuarios se puede especificar con valores mínimo y máximo (UID_MIN-UID_MAX), un valor máximo (-UID_MAX), o un valor mínimo (UID_MIN-).

-a

Imprime los registros de lastlog de los usuarios que han iniciado sesión al menos una vez. Excluye los registros de usuarios con '**Nunca ha iniciado sesión**'.

Si el usuario nunca ha iniciado sesión, se mostrará el mensaje ** Nunca ha iniciado sesión** en lugar del puerto y la hora.

Solo se mostrarán las entradas para los usuarios actuales del sistema. Pueden existir otras entradas para usuarios que fueron eliminados previamente.

NOTA

El archivo lastlog es una base de datos que contiene información sobre el último inicio de sesión de cada usuario. No deberías rotarlo. Es un archivo disperso (sparse file), por lo que su tamaño en disco suele ser mucho menor que el que muestra "ls -l" (que puede indicar un archivo realmente grande si tienes usuarios en passwd con un UID alto). Puedes mostrar su tamaño real con "ls -s".

CONFIGURACIÓN

Las siguientes variables de configuración en /etc/login.defs cambian el comportamiento de esta herramienta:

LASTLOG_UID_MAX (número)

El ID de usuario más alto para el cual se deben actualizar las entradas de lastlog. Como los IDs de usuario más altos suelen ser rastreados por servicios remotos de identidad y autenticación de usuarios, no hay necesidad de crear un archivo lastlog disperso y grande para ellos.

Si no está presente la opción LASTLOG_UID_MAX en la configuración, significa que no hay límite de ID de usuario para escribir entradas en lastlog.

ARCHIVOS

/var/log/lastlog

Base de datos de las horas de los inicios de sesión anteriores de los usuarios.

ADVERTENCIAS

Grandes brechas en los números de UID harán que el programa lastlog se ejecute más tiempo sin mostrar nada en la pantalla (es decir, si en la base de datos lastlog no hay entradas para usuarios con UID entre 170 y 800, lastlog parecerá colgarse mientras procesa entradas con UIDs 171-799).

Tener UIDs altos puede crear problemas al manejar el archivo /var/log/lastlog con herramientas externas. Aunque el archivo real es disperso y no utiliza demasiado espacio, ciertas aplicaciones no están diseñadas para identificar archivos dispersos por defecto y pueden requerir una opción específica para manejarlos.
