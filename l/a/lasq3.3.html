subrutina dlasq3 (integer i0, integer n0, double precision, dimension( * ) z, integer pp, double precision dmin, double precision sigma, double precision desig, double precision qmax, integer nfail, integer iter, integer ndiv, logical ieee, integer ttype, double precision dmin1, double precision dmin2, double precision dn, double precision dn1, double precision dn2, double precision g, double precision tau)

DLASQ3 verifica la deflación, calcula un desplazamiento y llama a dqds. Usado por sbdsqr.

Propósito:

!>
!> DLASQ3 verifica la deflación, calcula un desplazamiento (TAU) y llama a dqds.
!> En caso de fallo, cambia los desplazamientos y lo intenta de nuevo hasta que la salida
!> sea positiva.
!>

Parámetros

I0 
!>          I0 es INTEGER
!>         Primer índice.
!>

N0

!>          N0 es INTEGER
!>         Último índice.
!>

Z

!>          Z es un array de DOUBLE PRECISION, dimension ( 4*N0 )
!>         Z contiene el array qd.
!>

PP

!>          PP es INTEGER
!>         PP=0 para ping, PP=1 para pong.
!>         PP=2 indica que se aplicó inversión al array Z
!>         y que las pruebas iniciales de deflación no deben
!>         realizarse.
!>

DMIN

!>          DMIN es DOUBLE PRECISION
!>         Valor mínimo de d.
!>

SIGMA

!>          SIGMA es DOUBLE PRECISION
!>         Suma de los desplazamientos utilizados en el segmento actual.
!>

DESIG

!>          DESIG es DOUBLE PRECISION
!>         Parte de orden inferior de SIGMA
!>

QMAX

!>          QMAX es DOUBLE PRECISION
!>         Valor máximo de q.
!>

NFAIL

!>          NFAIL es INTEGER
!>         Incrementa NFAIL en 1 cada vez que el desplazamiento fue demasiado grande.
!>

ITER

!>          ITER es INTEGER
!>         Incrementa ITER en 1 por cada iteración.
!>

NDIV

!>          NDIV es INTEGER
!>         Incrementa NDIV en 1 por cada división.
!>

IEEE

!>          IEEE es LOGICAL
!>         Indicador para aritmética IEEE o no IEEE (pasado a DLASQ5).
!>

TTYPE

!>          TTYPE es INTEGER
!>         Tipo de desplazamiento.
!>

DMIN1

!>          DMIN1 es DOUBLE PRECISION
!>

DMIN2

!>          DMIN2 es DOUBLE PRECISION
!>

DN

!>          DN es DOUBLE PRECISION
!>

DN1

!>          DN1 es DOUBLE PRECISION
!>

DN2

!>          DN2 es DOUBLE PRECISION
!>

G

!>          G es DOUBLE PRECISION
!>

TAU

!>          TAU es DOUBLE PRECISION
!>
!>         Estos se pasan como argumentos para guardar sus valores
!>         entre llamadas a DLASQ3.
!>
