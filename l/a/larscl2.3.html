subrutina clarscl2 (integer m, integer n, real, dimension( * ) d, complex, dimension( ldx, * ) x, integer ldx)

CLARSCL2 realiza un escalado recíproco diagonal en una matriz.

Propósito:

!>
!> CLARSCL2 realiza un escalado recíproco diagonal en una matriz:
!>   x <-- inv(D) * x
!> donde la matriz diagonal REAL D se almacena como un vector.
!>
!> Eventualmente será reemplazada por BLAS_cge_diag_scale en el nuevo
!> estándar BLAS.
!>

Parámetros

M 
!>          M es INTEGER
!>     El número de filas de D y X. M >= 0.
!>

N

!>          N es INTEGER
!>     El número de columnas de X. N >= 0.
!>

D

!>          D es array REAL, longitud M
!>     Matriz diagonal D, almacenada como un vector de longitud M.
!>

X

!>          X es array COMPLEX, dimension (LDX,N)
!>     En la entrada, la matriz X a escalar por D.
!>     En la salida, la matriz escalada.
!>

LDX

!>          LDX es INTEGER
!>     La dimensión principal de la matriz X. LDX >= M.
!>
