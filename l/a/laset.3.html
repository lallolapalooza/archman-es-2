subrutina claset (uplo de caracteres, m entero, n entero, alpha complejo, beta complejo, complejo, dimensión( lda, * ) a, lda entero)

CLASET inicializa los elementos fuera de la diagonal y los elementos de la diagonal de una matriz a valores dados.

Propósito:

!>
!> CLASET inicializa una matriz A de 2 dimensiones a BETA en la diagonal y
!> ALPHA en los elementos fuera de la diagonal.
!>

Parámetros

UPLO 
!>          UPLO es CHARACTER*1
!>          Especifica la parte de la matriz A a establecer.
!>          = 'U':      Se establece la parte triangular superior. El triángulo
!>                      inferior no se modifica.
!>          = 'L':      Se establece la parte triangular inferior. El triángulo
!>                      superior no se modifica.
!>          En caso contrario: Se establece toda la matriz A.
!>

M

!>          M es INTEGER
!>          En la entrada, M especifica el número de filas de A.
!>

N

!>          N es INTEGER
!>          En la entrada, N especifica el número de columnas de A.
!>

ALPHA

!>          ALPHA es COMPLEX
!>          Todos los elementos de la matriz fuera de la diagonal se establecen
     a ALPHA.
!>

BETA

!>          BETA es COMPLEX
!>          Todos los elementos de la diagonal se establecen a BETA.
!>

A

!>          A es una matriz COMPLEX, dimensión (LDA,N)
!>          En la entrada, la matriz m por n A.
!>          En la salida, A(i,j) = ALPHA, 1 <= i <= m, 1 <= j <= n, i.ne.j;
!>                   A(i,i) = BETA , 1 <= i <= min(m,n)
!>

LDA

!>          LDA es INTEGER
!>          La dimensión principal de la matriz A.  LDA >= max(1,M).
!>

DLASET inicializa los elementos fuera de la diagonal y los elementos de la diagonal de una matriz a valores dados.

Propósito:

!>
!> DLASET inicializa una matriz m por n A a BETA en la diagonal y
!> ALPHA en los elementos fuera de la diagonal.
!>

Parámetros

UPLO 
!>          UPLO es CHARACTER*1
!>          Especifica la parte de la matriz A a establecer.
!>          = 'U':      Se establece la parte triangular superior; la parte
     estrictamente triangular inferior de A no se modifica.
!>          = 'L':      Se establece la parte triangular inferior; la parte
     estrictamente triangular superior de A no se modifica.
!>          En caso contrario: Se establece toda la matriz A.
!>

M

!>          M es INTEGER
!>          El número de filas de la matriz A.  M >= 0.
!>

N

!>          N es INTEGER
!>          El número de columnas de la matriz A.  N >= 0.
!>

ALPHA

!>          ALPHA es DOUBLE PRECISION
!>          La constante a la que se establecerán los elementos fuera de la
     diagonal.
!>

BETA

!>          BETA es DOUBLE PRECISION
!>          La constante a la que se establecerán los elementos de la diagonal.
!>

A

!>          A es una matriz DOUBLE PRECISION, dimensión (LDA,N)
!>          En la salida, la submatriz principal m por n de A se establece de
     la siguiente manera:

!>          si UPLO = 'U', A(i,j) = ALPHA, 1<=i<=j-1, 1<=j<=n,
!>          si UPLO = 'L', A(i,j) = ALPHA, j+1<=i<=m, 1<=j<=n,
!>          en caso contrario,     A(i,j) = ALPHA, 1<=i<=m, 1<=j<=n, i.ne.j,
!>
!>          y, para todo UPLO, A(i,i) = BETA, 1<=i<=min(m,n).
!>

LDA

!>          LDA es INTEGER
!>          La dimensión principal de la matriz A.  LDA >= max(1,M).
!>

zlaset(3) - LAPACK

NAME

zlaset - subroutine zlaset (character uplo, integer m, integer n, complex*16 alpha, complex*16 beta, complex*16, dimension( lda, * ) a, integer lda)

SYNOPSIS

subroutine zlaset (character uplo, integer m, integer n, complex*16 alpha, complex*16 beta, complex*16, dimension( lda, * ) a, integer lda)

Detailed Description

ZLASET initializes the off-diagonal elements and the diagonal elements of a matrix to given values.

Purpose:

!>
!> ZLASET initializes a 2-D array A to BETA on the diagonal and
!> ALPHA on the offdiagonals.
!>

Function Documentation

Parameters

UPLO 
!>          UPLO is CHARACTER*1
!>          Specifies the part of the matrix A to be set.
!>          = 'U':      Upper triangular part is set. The lower triangle
!>                      is unchanged.
!>          = 'L':      Lower triangular part is set. The upper triangle
!>                      is unchanged.
!>          Otherwise:  All of the matrix A is set.
!>

M

!>          M is INTEGER
!>          On entry, M specifies the number of rows of A.
!>

N

!>          N is INTEGER
!>          On entry, N specifies the number of columns of A.
!>

ALPHA

!>          ALPHA is COMPLEX*16
!>          All the offdiagonal array elements are set to ALPHA.
!>

BETA

!>          BETA is COMPLEX*16
!>          All the diagonal array elements are set to BETA.
!>

A

!>          A is COMPLEX*16 array, dimension (LDA,N)
!>          On entry, the m by n matrix A.
!>          On exit, A(i,j) = ALPHA, 1 <= i <= m, 1 <= j <= n, i.ne.j;
!>                   A(i,i) = BETA , 1 <= i <= min(m,n)
!>

LDA

!>          LDA is INTEGER
!>          The leading dimension of the array A.  LDA >= max(1,M).
!>
