DLAEXC intercambia bloques diagonales adyacentes de una matriz cuasi-triangular superior real en forma canónica de Schur, mediante una transformación de similitud ortogonal.

Propósito

!>
!> DLAEXC intercambia los bloques diagonales adyacentes T11 y T22 de orden 1 o 2 en
!> una matriz cuasi-triangular superior T mediante una transformación de similitud
!> ortogonal.
!>
!> T debe estar en forma canónica de Schur, es decir, triangular superior por bloques
!> con bloques diagonales de 1x1 y 2x2; cada bloque diagonal de 2x2
!> tiene sus elementos diagonales iguales y sus elementos fuera de la diagonal de
!> signo opuesto.
!>

Parámetros

WANTQ 
!>          WANTQ es LOGICAL
!>          = .TRUE. : acumular la transformación en la matriz Q;
!>          = .FALSE.: no acumular la transformación.
!>

N

!>          N es INTEGER
!>          El orden de la matriz T. N >= 0.
!>

T

!>          T es array de DOUBLE PRECISION, dimension (LDT,N)
!>          En la entrada, la matriz cuasi-triangular superior T, en forma
!>          canónica de Schur.
!>          En la salida, la matriz T actualizada, de nuevo en forma canónica de Schur.
!>

LDT

!>          LDT es INTEGER
!>          La dimensión principal del array T. LDT >= max(1,N).
!>

Q

!>          Q es array de DOUBLE PRECISION, dimension (LDQ,N)
!>          En la entrada, si WANTQ es .TRUE., la matriz ortogonal Q.
!>          En la salida, si WANTQ es .TRUE., la matriz Q actualizada.
!>          Si WANTQ es .FALSE., Q no se referencia.
!>

LDQ

!>          LDQ es INTEGER
!>          La dimensión principal del array Q.
!>          LDQ >= 1; y si WANTQ es .TRUE., LDQ >= N.
!>

J1

!>          J1 es INTEGER
!>          El índice de la primera fila del primer bloque T11.
!>

N1

!>          N1 es INTEGER
!>          El orden del primer bloque T11. N1 = 0, 1 o 2.
!>

N2

!>          N2 es INTEGER
!>          El orden del segundo bloque T22. N2 = 0, 1 o 2.
!>

WORK

!>          WORK es array de DOUBLE PRECISION, dimension (N)
!>

INFO

!>          INFO es INTEGER
!>          = 0: salida exitosa
!>          = 1: la matriz transformada T estaría demasiado lejos de la forma de Schur;
!>               los bloques no se intercambian y T y Q permanecen sin cambios.
!>

Detailed Description

LAPACK (Linear Algebra PACKage) is a software library for numerical linear algebra. It provides routines for solving systems of linear equations, least-squares solutions of linear systems, eigenvalue problems and singular value decomposition problems. LAPACK is written in Fortran 95 and is intended to be highly efficient on a wide range of modern computer architectures. LAPACK has interfaces for C and Fortran.

LAPACK is built upon the highly respected EISPACK and LINPACK libraries. LAPACK routines perform a substantial fraction of the work in a typical numerical computation. LAPACK can be used on its own or as a subroutine library for higher-level matrix computation software.
