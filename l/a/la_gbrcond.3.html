función real cla_gbrcond_c (carácter trans, entero n, entero kl, entero ku, complejo, dimensión( ldab, * ) ab, entero ldab, complejo, dimensión( ldafb, * ) afb, entero ldafb, entero, dimensión( * ) ipiv, real, dimensión( * ) c, lógico capply, entero info, complejo, dimensión( * ) work, real, dimensión( * ) rwork)

CLA_GBRCOND_C calcula el número de condición de la norma infinito de op(A)*inv(diag(c)) para matrices generales de banda.

Propósito:

!>
!>    CLA_GBRCOND_C Calcula el número de condición de la norma infinito de
!>    op(A) * inv(diag(C)) donde C es un vector REAL.
!>

Parámetros

TRANS 
!>          TRANS es CHARACTER*1
!>     Especifica la forma del sistema de ecuaciones:
!>       = 'N':  A * X = B     (Sin transponer)
!>       = 'T':  A**T * X = B  (Transpuesta)
!>       = 'C':  A**H * X = B  (Transpuesta conjugada = Transpuesta)
!>

N

!>          N es INTEGER
!>     El número de ecuaciones lineales, es decir, el orden de la
!>     matriz A.  N >= 0.
!>

KL

!>          KL es INTEGER
!>     El número de subdiagonales dentro de la banda de A.  KL >= 0.
!>

KU

!>          KU es INTEGER
!>     El número de superdiagonales dentro de la banda de A.  KU >= 0.
!>

AB

!>          AB es arreglo COMPLEX, dimensión (LDAB,N)
!>     En la entrada, la matriz A en almacenamiento de banda, en las
!>     filas 1 a KL+KU+1.
!>     La columna j de A se almacena en la columna j del
!>     arreglo AB como sigue:
!>     AB(KU+1+i-j,j) = A(i,j) para max(1,j-KU)<=i<=min(N,j+kl)
!>

LDAB

!>          LDAB es INTEGER
!>     La dimensión principal del arreglo AB.  LDAB >= KL+KU+1.
!>

AFB

!>          AFB es arreglo COMPLEX, dimensión (LDAFB,N)
!>     Detalles de la factorización LU de la matriz de banda A, tal
!>     como se calcula por CGBTRF.  U se almacena como una matriz
!>     triangular superior de banda con KL+KU superdiagonales en las
!>     filas 1 a KL+KU+1, y los multiplicadores usados durante la
!>     factorización se almacenan en las filas KL+KU+2 a 2*KL+KU+1.
!>

LDAFB

!>          LDAFB es INTEGER
!>     La dimensión principal del arreglo AFB.  LDAFB >= 2*KL+KU+1.
!>

IPIV

!>          IPIV es arreglo INTEGER, dimensión (N)
!>     Los índices de pivote de la factorización A = P*L*U
!>     tal como se calcula por CGBTRF; la fila i de la matriz fue
!>     intercambiada con la fila IPIV(i).
!>

C

!>          C es arreglo REAL, dimensión (N)
!>     El vector C en la fórmula op(A) * inv(diag(C)).
!>

CAPPLY

!>          CAPPLY es LOGICAL
!>     Si es .TRUE. entonces accede al vector C en la fórmula anterior.
!>

INFO

!>          INFO es INTEGER
!>       = 0:  Salida exitosa.
!>     i > 0:  El i-ésimo argumento es inválido.
!>

WORK

!>          WORK es arreglo COMPLEX, dimensión (2*N).
!>     Espacio de trabajo.
!>

RWORK

!>          RWORK es arreglo REAL, dimensión (N).
!>     Espacio de trabajo.
!>

complex function cla_gbrcond (character trans, integer n, integer kl, integer ku, complex, dimension( ldab, * ) ab, integer ldab, complex, dimension( ldafb, * ) afb, integer ldafb, integer, dimension( * ) ipiv, integer cmode, complex, dimension( * ) c, integer info, complex, dimension( * ) work, real, dimension( * ) rwork)

CLA_GBRCOND estimates the Skeel condition number for a general banded matrix.

Purpose:

!>
!>    CLA_GBRCOND Estimates the Skeel condition number of  op(A) * op2(C)
!>    where op2 is determined by CMODE as follows
!>    CMODE =  1    op2(C) = C
!>    CMODE =  0    op2(C) = I
!>    CMODE = -1    op2(C) = inv(C)
!>    The Skeel condition number  cond(A) = norminf( |inv(A)||A| )
!>    is computed by computing scaling factors R such that
!>    diag(R)*A*op2(C) is row equilibrated and computing the standard
!>    infinity-norm condition number.
!>

Parameters

TRANS 
!>          TRANS is CHARACTER*1
!>     Specifies the form of the system of equations:
!>       = 'N':  A * X = B     (No transpose)
!>       = 'T':  A**T * X = B  (Transpose)
!>       = 'C':  A**H * X = B  (Conjugate Transpose = Transpose)
!>

N

!>          N is INTEGER
!>     The number of linear equations, i.e., the order of the
!>     matrix A.  N >= 0.
!>

KL

!>          KL is INTEGER
!>     The number of subdiagonals within the band of A.  KL >= 0.
!>

KU

!>          KU is INTEGER
!>     The number of superdiagonals within the band of A.  KU >= 0.
!>

AB

!>          AB is COMPLEX array, dimension (LDAB,N)
!>     On entry, the matrix A in band storage, in rows 1 to KL+KU+1.
!>     The j-th column of A is stored in the j-th column of the
!>     array AB as follows:
!>     AB(KU+1+i-j,j) = A(i,j) for max(1,j-KU)<=i<=min(N,j+kl)
!>

LDAB

!>          LDAB is INTEGER
!>     The leading dimension of the array AB.  LDAB >= KL+KU+1.
!>

AFB

!>          AFB is COMPLEX array, dimension (LDAFB,N)
!>     Details of the LU factorization of the band matrix A, as
!>     computed by CGBTRF.  U is stored as an upper triangular
!>     band matrix with KL+KU superdiagonals in rows 1 to KL+KU+1,
!>     and the multipliers used during the factorization are stored
!>     in rows KL+KU+2 to 2*KL+KU+1.
!>

LDAFB

!>          LDAFB is INTEGER
!>     The leading dimension of the array AFB.  LDAFB >= 2*KL+KU+1.
!>

IPIV

!>          IPIV is INTEGER array, dimension (N)
!>     The pivot indices from the factorization A = P*L*U
!>     as computed by CGBTRF; row i of the matrix was interchanged
!>     with row IPIV(i).
!>

CMODE

!>          CMODE is INTEGER
!>     Determines op2(C) in the formula op(A) * op2(C) as follows:
!>     CMODE =  1    op2(C) = C
!>     CMODE =  0    op2(C) = I
!>     CMODE = -1    op2(C) = inv(C)
!>

C

!>          C is COMPLEX array, dimension (N)
!>     The vector C in the formula op(A) * op2(C).
!>

INFO

!>          INFO is INTEGER
!>       = 0:  Successful exit.
!>     i > 0:  The ith argument is invalid.
!>

WORK

!>          WORK is COMPLEX array, dimension (5*N).
!>     Workspace.
!>

RWORK

!>          RWORK is REAL array, dimension (N).
!>     Workspace.
!>

NAME

zla_gbrcond_c, zla_gbrcond_x - computes the infinity norm condition number of a general banded matrix.

SYNOPSIS

double precision function zla_gbrcond_c (character trans, integer n, integer kl,
integer ku, complex*16, dimension( ldab, * ) ab, integer ldab, complex*16,
dimension( ldafb, * ) afb, integer ldafb, integer, dimension( * ) ipiv, double
precision, dimension( * ) c, logical capply, integer info, complex*16,
dimension( * ) work, double precision, dimension( * ) rwork)

double precision function zla_gbrcond_x (character trans, integer n, integer kl,
integer ku, complex*16, dimension( ldab, * ) ab, integer ldab, complex*16,
dimension( ldafb, * ) afb, integer ldafb, integer, dimension( * ) ipiv,
complex*16, dimension( * ) x, integer info, complex*16, dimension( * ) work,
double precision, dimension( * ) rwork)

Detailed Description

This routine is the driver level for computing the infinity norm condition number of a general banded matrix.

cond = 1.0 / ( op(A) * inv (diag(C)) )

where op(A) is one of 'N', 'T' or 'C', and C is a DOUBLE PRECISION vector.

or

cond = 1.0 / ( op(A) * diag(X) )

where X is a COMPLEX*16 vector.
