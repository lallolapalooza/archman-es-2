CLARFY

Propósito:

!>
!> CLARFY aplica un reflector elemental, o matriz de Householder, H,
!> a una matriz Hermítica n x n C, desde la izquierda y la derecha.
!>
!> H se representa en la forma
!>
!>    H = I - tau * v * v'
!>
!> donde tau es un escalar y v es un vector.
!>
!> Si tau es cero, entonces H se toma como la matriz unitaria.
!>

Parámetros

UPLO 
!>          UPLO es CARACTER*1
!>          Especifica si la parte triangular superior o inferior de la
!>          matriz Hermítica C está almacenada.
!>          = 'U':  Triángulo superior
!>          = 'L':  Triángulo inferior
!>

N

!>          N es ENTERO
!>          El número de filas y columnas de la matriz C.  N >= 0.
!>

V

!>          V es un array COMPLEJO, dimensión
!>                  (1 + (N-1)*abs(INCV))
!>          El vector v como se describe arriba.
!>

INCV

!>          INCV es ENTERO
!>          El incremento entre elementos sucesivos de v.  INCV no debe
!>          ser cero.
!>

TAU

!>          TAU es COMPLEJO
!>          El valor tau como se describe arriba.
!>

C

!>          C es un array COMPLEJO, dimensión (LDC, N)
!>          A la entrada, la matriz C.
!>          A la salida, C se sobrescribe con H * C * H'.
!>

LDC

!>          LDC es ENTERO
!>          La dimensión principal del array C.  LDC >= max( 1, N ).
!>

WORK

!>          WORK es un array COMPLEJO, dimensión (N)
!>
