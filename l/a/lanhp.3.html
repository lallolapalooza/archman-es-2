real función clanhp (carácter norma, carácter uplo, entero n, complejo, dimensión( * ) ap, real, dimensión( * ) trabajo)

CLANHP devuelve el valor de la norma 1, o la norma de Frobenius, o la norma infinito, o el elemento de valor absoluto más grande de una matriz hermítica compleja suministrada en forma empaquetada.

Propósito:

!>
!> CLANHP  devuelve el valor de la norma uno,  o la norma de Frobenius, o
!> la norma infinito,  o el  elemento de  valor absoluto más grande de una
!> matriz hermítica A,  suministrada en forma empaquetada.
!>

Retorna

CLANHP 
!>
!>    CLANHP = ( max(abs(A(i,j))), NORMA = 'M' o 'm'
!>             (
!>             ( norm1(A),         NORMA = '1', 'O' o 'o'
!>             (
!>             ( normI(A),         NORMA = 'I' o 'i'
!>             (
!>             ( normF(A),         NORMA = 'F', 'f', 'E' o 'e'
!>
!> donde  norm1  denota la  norma uno de una matriz (suma máxima de columnas),
!> normI  denota la  norma infinito  de una matriz  (suma máxima de filas) y
!> normF  denota la  norma de Frobenius de una matriz (raíz cuadrada de la suma de
!> cuadrados).  Nótese que  max(abs(A(i,j)))  no es una norma de matriz consistente.
!>

Parámetros

NORMA 
!>          NORMA es CHARACTER*1
!>          Especifica el valor a devolver en CLANHP como se describe
!>          arriba.
!>

UPLO

!>          UPLO es CHARACTER*1
!>          Especifica si se suministra la parte triangular superior o inferior
!>          de la matriz hermítica A.
!>          = 'U':  Se suministra la parte triangular superior
!>          = 'L':  Se suministra la parte triangular inferior
!>

N

!>          N es INTEGER
!>          El orden de la matriz A.  N >= 0.  Cuando N = 0, CLANHP se
!>          establece a cero.
!>

AP

!>          AP es un array COMPLEX, dimensión (N*(N+1)/2)
!>          La parte triangular superior o inferior de la matriz hermítica A,
!>          empaquetada por columnas en un array lineal.  La j-ésima columna de A
!>          se almacena en el array AP de la siguiente manera:
!>          si UPLO = 'U', AP(i + (j-1)*j/2) = A(i,j) para 1<=i<=j;
!>          si UPLO = 'L', AP(i + (j-1)*(2n-j)/2) = A(i,j) para j<=i<=n.
!>          Nótese que las partes imaginarias de los elementos diagonales no
!>          necesitan ser establecidas y se asumen cero.
!>

TRABAJO

!>          TRABAJO es un array REAL, dimensión (MAX(1,LWORK)),
!>          donde LWORK >= N cuando NORMA = 'I' o '1' o 'O'; de lo contrario,
!>          TRABAJO no se referencia.
!>

NAME

DLANSP, SLANSP, ZLANHP, ZLANSP - computes the value of the one norm, or the Frobenius norm, or the infinity norm, or the element of largest absolute value of a matrix supplied in packed form.

SYNOPSIS

  DOUBLE PRECISION FUNCTION DLANSP(NORM, UPLO, N, AP, WORK)
  CHARACTER(LEN=1) NORM, UPLO
  INTEGER N
  DOUBLE PRECISION AP( * ), WORK( * )

  REAL FUNCTION SLANSP(NORM, UPLO, N, AP, WORK)
  CHARACTER(LEN=1) NORM, UPLO
  INTEGER N
  REAL AP( * ), WORK( * )

  DOUBLE PRECISION FUNCTION ZLANHP(NORM, UPLO, N, AP, WORK)
  CHARACTER(LEN=1) NORM, UPLO
  INTEGER N
  COMPLEX*16 AP( * )
  DOUBLE PRECISION WORK( * )

  DOUBLE PRECISION FUNCTION ZLANSP(NORM, UPLO, N, AP, WORK)
  CHARACTER(LEN=1) NORM, UPLO
  INTEGER N
  COMPLEX*16 AP( * )
  DOUBLE PRECISION WORK( * )

DESCRIPTION

The routines compute the norm of a symmetric or Hermitian matrix A supplied in packed form. The possible values computed by each routine are defined as follows:

DLANSP and SLANSP (Real Symmetric Matrix in Packed Form)

DLANSP returns the value of the one norm, or the Frobenius norm, or the infinity norm, or the element of largest absolute value of a real symmetric matrix supplied in packed form.

Purpose:

!>
!> DLANSP  returns the value of the one norm,  or the Frobenius norm, or
!> the  infinity norm,  or the  element of  largest absolute value  of a
!> real symmetric matrix A,  supplied in packed form.
!>

Returns

DLANSP 
!>
!>    DLANSP = ( max(abs(A(i,j))), NORM = 'M' or 'm'
!>             (
!>             ( norm1(A),         NORM = '1', 'O' or 'o'
!>             (
!>             ( normI(A),         NORM = 'I' or 'i'
!>             (
!>             ( normF(A),         NORM = 'F', 'f', 'E' or 'e'
!>
!> where  norm1  denotes the  one norm of a matrix (maximum column sum),
!> normI  denotes the  infinity norm  of a matrix  (maximum row sum) and
!> normF  denotes the  Frobenius norm of a matrix (square root of sum of
!> squares).  Note that  max(abs(A(i,j)))  is not a consistent matrix norm.
!>

Parameters

NORM 
!>          NORM is CHARACTER*1
!>          Specifies the value to be returned in DLANSP as described
!>          above.
!>

UPLO

!>          UPLO is CHARACTER*1
!>          Specifies whether the upper or lower triangular part of the
!>          symmetric matrix A is supplied.
!>          = 'U':  Upper triangular part of A is supplied
!>          = 'L':  Lower triangular part of A is supplied
!>

N

!>          N is INTEGER
!>          The order of the matrix A.  N >= 0.  When N = 0, DLANSP is
!>          set to zero.
!>

AP

!>          AP is DOUBLE PRECISION array, dimension (N*(N+1)/2)
!>          The upper or lower triangle of the symmetric matrix A, packed
!>          columnwise in a linear array.  The j-th column of A is stored
!>          in the array AP as follows:
!>          if UPLO = 'U', AP(i + (j-1)*j/2) = A(i,j) for 1<=i<=j;
!>          if UPLO = 'L', AP(i + (j-1)*(2n-j)/2) = A(i,j) for j<=i<=n.
!>

WORK

!>          WORK is DOUBLE PRECISION array, dimension (MAX(1,LWORK)),
!>          where LWORK >= N when NORM = 'I' or '1' or 'O'; otherwise,
!>          WORK is not referenced.
!>

NAME

ZLANSP - Real number norm of a general complex Hermitian matrix, supplied in packed format.

SYNOPSIS

  REAL FUNCTION ZLANSP( NORM, UPLO, AP )

      CHARACTER(1)    UPLO
      CHARACTER(1)    NORM
      COMPLEX*16      AP( * )

      INTEGER         N

Optional parameters:

      COMPLEX*16      AP( * )
      INTEGER         N
      CHARACTER(1)    NORM, UPLO
      COMPLEX*16      AP( * )

Function: ZLANSP

Character*1 UPLO

Character*1 NORM

Complex*16 AP( * )

Integer N

Double precision WORK( * )

Detailed Description

ZLANSP computes the norm of a complex Hermitian matrix A. The matrix A is represented in packed format.

Norms computed:

  = 1  --  1-norm: MAX( SUM(abs(A(i,j)) for i=1..n) ) for j=1..n
  = 'O' --  Infinity-norm: MAX( SUM(abs(A(i,j)) for j=1..n) ) for i=1..n
  = 'F' --  Frobenius norm: sqrt( SUM(abs(A(i,j))**2) for i=1..n, j=1..n )
  = 'I' --  Infinity-norm: MAX( SUM(abs(A(i,j)) for j=1..n) ) for i=1..n
  = 'M' --  Maximum element: MAX( abs(A(i,j)) ) for i=1..n, j=1..n

Args:

NORM

  NORM is CHARACTER*1
          Specifies the value to be returned:
          = '1' or 'O' or 'I'       1-norm or infinity-norm
          = 'F'                     Frobenius norm
          = 'M'                     Maximum element norm

UPLO

  UPLO is CHARACTER*1
          Specifies whether the matrix A is upper or lower triangular:
          = 'U' or 'u'   A is upper triangular
          = 'L' or 'l'   A is lower triangular

AP

  AP is COMPLEX*16 array, dimension (N*(N+1)/2)
          The upper or lower triangle of the symmetric matrix A, packed
          columnwise in a linear array. The j-th column of A is stored
          in the array AP as follows:
          if UPLO = 'U', AP(i + (j-1)*j/2) = A(i,j) for 1<=i<=j;
          if UPLO = 'L', AP(i + (j-1)*(2n-j)/2) = A(i,j) for j<=i<=n.

WORK

  WORK is DOUBLE PRECISION array, dimension (MAX(1,LWORK)),
          where LWORK >= N when NORM = 'I' or '1' or 'O'; otherwise,
          WORK is not referenced.
