Documentación de la Función

subrutina clahr2 (entero n, entero k, entero nb, complejo, dimensión( lda, * ) a, entero lda, complejo, dimensión( nb ) tau, complejo, dimensión( ldt, nb ) t, entero ldt, complejo, dimensión( ldy, nb ) y, entero ldy)

CLAHR2 reduce las primeras NB columnas especificadas de una matriz general rectangular A compleja de forma que los elementos por debajo de la subdiagonal especificada sean cero, y devuelve matrices auxiliares necesarias para aplicar la transformación a la parte no reducida de A.

Propósito:

!>
!> CLAHR2 reduce las primeras NB columnas de una matriz general compleja n x (n-k+1)
!> A de modo que los elementos por debajo de la k-ésima subdiagonal sean cero. La
!> reducción se realiza mediante una transformación de similaridad unitaria
!> Q**H * A * Q. La subrutina devuelve las matrices V y T que determinan
!> Q como un reflector de bloque I - V*T*v**H, y también la matriz Y = A * V * T.
!>
!> Esta es una subrutina auxiliar llamada por CGEHRD.
!>

Parámetros

N 
!>          N es ENTERO
!>          El orden de la matriz A.
!>

K

!>          K es ENTERO
!>          El desplazamiento para la reducción. Los elementos por debajo de la k-ésima
!>          subdiagonal en las primeras NB columnas se reducen a cero.
!>          K < N.
!>

NB

!>          NB es ENTERO
!>          El número de columnas a reducir.
!>

A

!>          A es un array COMPLEJO, dimensión (LDA,N-K+1)
!>          En la entrada, la matriz general A de n x (n-k+1).
!>          En la salida, los elementos en y por encima de la k-ésima subdiagonal en
!>          las primeras NB columnas se sobrescriben con los elementos correspondientes
!>          de la matriz reducida; los elementos por debajo de la k-ésima
!>          subdiagonal, con el array TAU, representan la matriz Q como un
!>          producto de reflectores elementales. Las otras columnas de A no cambian.
!>          Ver Detalles Adicionales.
!>

LDA

!>          LDA es ENTERO
!>          La dimensión principal del array A.  LDA >= max(1,N).
!>

TAU

!>          TAU es un array COMPLEJO, dimensión (NB)
!>          Los factores escalares de los reflectores elementales. Ver Detalles
!>          Adicionales.
!>

T

!>          T es un array COMPLEJO, dimensión (LDT,NB)
!>          La matriz triangular superior T.
!>

LDT

!>          LDT es ENTERO
!>          La dimensión principal del array T.  LDT >= NB.
!>

Y

!>          Y es un array COMPLEJO, dimensión (LDY,NB)
!>          La matriz Y de n x nb.
!>

LDY

!>          LDY es ENTERO
!>          La dimensión principal del array Y. LDY >= N.
!>

Univ. of Tennessee

Univ. of California Berkeley

Univ. of Colorado Denver

NAG Ltd.

Detalles Adicionales:

!>
!> La matriz Q se representa como un producto de nb reflectores elementales
!>
!>     Q = H(1) H(2) . . . H(nb).
!>
!> Cada H(i) tiene la forma
!>
!>     H(i) = I - tau * v * v**H
!>
!> donde tau es un escalar complejo, y v es un vector complejo con
!> v(1:i+k-1) = 0, v(i+k) = 1; v(i+k+1:n) se almacena en la salida en
!> A(i+k+1:n,i), y tau en TAU(i).
!>
!> Los elementos de los vectores v forman la matriz V de (n-k+1) x nb
!> que se necesita, junto con T e Y, para aplicar la transformación a la
!> parte no reducida de la matriz, utilizando una actualización de la forma:
!> A := (I - V*T*V**H) * (A - Y*V**H).
!>
!> Los contenidos de A en la salida se ilustran con el siguiente ejemplo
!> con n = 7, k = 3 y nb = 2:
!>
!>    ( a   a   a   a   a )
!>    ( a   a   a   a   a )
!>    ( a   a   a   a   a )
!>    ( h   h   a   a   a )
!>    ( v1  h   a   a   a )
!>    ( v1  v2  a   a   a )
!>    ( v1  v2  a   a   a )
!>
!> donde 'a' denota un elemento de la matriz original A, 'h' denota un
!> elemento modificado de la matriz de Hessenberg superior H, y 'vi' denota un
!> elemento del vector que define H(i).
!>
!> Esta subrutina es una ligera modificación de CLAHRD de LAPACK-3.0
!> que incorpora mejoras propuestas por Quintana-Orti y Van de
!> Gejin. Tenga en cuenta que las entradas de A(1:K,2:NB) difieren de las
!> devueltas por la subrutina CLAHRD original de LAPACK-3.0. (Esta
!> subrutina no es compatible con versiones anteriores de CLAHRD de LAPACK-3.0).
!>

Referencias:

Gregorio Quintana-Orti y Robert van de Geijn, "Improving the performance of reduction to Hessenberg form," ACM Transactions on Mathematical Software, 32(2):180-194, junio de 2006.

LAPACK - zlahr2.f

NAME

zlahr2 - zlahr2

SYNOPSIS

    SUBROUTINE SLAHR2(N, K, NB, A, LDA, TAU, T, LDT, Y, LDY)

    INTEGER N
    INTEGER K
    INTEGER NB
    COMPLEX*16 A(LDA,*)
    INTEGER LDA
    COMPLEX*16 TAU(*)
    COMPLEX*16 T(LDT,*)
    INTEGER LDT
    COMPLEX*16 Y(LDY,*)
    INTEGER LDY

Detailed Description

This routine is deprecated. It is replaced by ZGEHRD.

This routine reduces a complex upper triangular-Hessenberg matrix A to upper triangular form by means of unitary transformations.

This is a level 2 routine.

It is used by ZGEHRD to implement the Householder transformation H(i), for i=1 to NB, such that:

    A := H(1) H(2) ... H(NB) * A

The remaining transformations are applied to the upper triangular-Hessenberg matrix A.

Arguments:

Function Documentation

N

!>          N is INTEGER
!>          The order of the matrix A. N >= 0.
!>

K

!>          K is INTEGER
!>          The number of columns of A to be reduced.
!>          K <= N.
!>

NB

!>          NB is INTEGER
!>          The number of blocks of columns to be reduced.
!>          NB <= N.
!>

A

!>          A is COMPLEX*16 array, dimension (LDA, N)
!>          On entry, the n-by-n matrix A.
!>          On exit, the elements below the k-th subdiagonal with the
!>          array TAU, represent the matrix Q as a product of elementary
!>          reflectors. The other columns of A are unchanged. See Further
!>          Details.
!>

LDA

!>          LDA is INTEGER
!>          The leading dimension of the array A. LDA >= max(1,N).
!>

TAU

!>          TAU is COMPLEX*16 array, dimension (NB)
!>          The scalar factors of the elementary reflectors. See Further
!>          Details.

Further Details:

!>
!>  The matrix Q is represented as a product of nb elementary reflectors
!>
!>     Q = H(1) H(2) . . . H(nb).
!>
!>  Each H(i) has the form
!>
!>     H(i) = I - tau * v * v**H
!>
!>  where tau is a complex scalar, and v is a complex vector with
!>  v(1:i+k-1) = 0, v(i+k) = 1; v(i+k+1:n) is stored on exit in
!>  A(i+k+1:n,i), and tau in TAU(i).
!>
!>  The elements of the vectors v together form the (n-k+1)-by-nb matrix
!>  V which is needed, with T and Y, to apply the transformation to the
!>  unreduced part of the matrix, using an update of the form:
!>  A := (I - V*T*V**H) * (A - Y*V**H).
!>
!>  The contents of A on exit are illustrated by the following example
!>  with n = 7, k = 3 and nb = 2:
!>
!>     ( a   a   a   a   a )
!>     ( a   a   a   a   a )
!>     ( a   a   a   a   a )
!>     ( h   h   a   a   a )
!>     ( v1  h   a   a   a )
!>     ( v1  v2  a   a   a )
!>     ( v1  v2  a   a   a )
!>
!>  where a denotes an element of the original matrix A, h denotes a
!>  modified element of the upper Hessenberg matrix H, and vi denotes an
!>  element of the vector defining H(i).
!>
!>  This subroutine is a slight modification of LAPACK-3.0's ZLAHRD
!>  incorporating improvements proposed by Quintana-Orti and Van de
!>  Gejin. Note that the entries of A(1:K,2:NB) differ from those
!>  returned by the original LAPACK-3.0's ZLAHRD routine. (This
!>  subroutine is not backward compatible with LAPACK-3.0's ZLAHRD.)
!>
