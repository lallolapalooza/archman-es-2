subrutina claqr3 (logical wantt, logical wantz, integer n, integer ktop, integer kbot, integer nw, complex, dimension( ldh, * ) h, integer ldh, integer iloz, integer ihiz, complex, dimension( ldz, * ) z, integer ldz, integer ns, integer nd, complex, dimension( * ) sh, complex, dimension( ldv, * ) v, integer ldv, integer nh, complex, dimension( ldt, * ) t, integer ldt, integer nv, complex, dimension( ldwv, * ) wv, integer ldwv, complex, dimension( * ) work, integer lwork)

CLAQR3 realiza la transformación de semejanza unitaria de una matriz de Hessenberg para detectar y desdeflar autovalores completamente convergidos de una submatriz principal final (desdeflado temprano agresivo).

Propósito:

!>
!>    Desdeflado temprano agresivo:
!>
!>    CLAQR3 acepta como entrada una matriz de Hessenberg superior
!>    H y realiza una transformación de semejanza unitaria
!>    diseñada para detectar y desdeflar autovalores completamente convergidos
!>    de una submatriz principal final. En la salida H ha sido sobrescrita
!>    por una nueva matriz de Hessenberg que es una perturbación de
!>    una transformación de semejanza unitaria de H. Se espera
!>    que la versión final de H tenga muchas entradas subdiagonales cero.
!>

Parámetros

WANTT 
!>          WANTT es LOGICAL
!>          Si .TRUE., entonces la matriz de Hessenberg H se actualiza
!>          completamente para que el factor triangular de Schur pueda
!>          ser computado (en cooperación con la subrutina llamante).
!>          Si .FALSE., entonces solo se actualiza suficiente de H para
!>          preservar los autovalores.
!>

WANTZ

!>          WANTZ es LOGICAL
!>          Si .TRUE., entonces la matriz unitaria Z se actualiza
!>          para que el factor de Schur unitario pueda ser computado
!>          (en cooperación con la subrutina llamante).
!>          Si .FALSE., entonces Z no se referencia.
!>

N

!>          N es INTEGER
!>          El orden de la matriz H y (si WANTZ es .TRUE.) el
!>          orden de la matriz unitaria Z.
!>

KTOP

!>          KTOP es INTEGER
!>          Se asume que KTOP = 1 o H(KTOP,KTOP-1)=0.
!>          KBOT y KTOP juntos determinan un bloque aislado
!>          a lo largo de la diagonal de la matriz de Hessenberg.
!>

KBOT

!>          KBOT es INTEGER
!>          Se asume sin comprobación que KBOT = N o H(KBOT+1,KBOT)=0.
!>          KBOT y KTOP juntos determinan un bloque aislado
!>          a lo largo de la diagonal de la matriz de Hessenberg.
!>

NW

!>          NW es INTEGER
!>          Tamaño de la ventana de deflación. 1 <= NW <= (KBOT-KTOP+1).
!>

H

!>          H es array COMPLEX, dimension (LDH,N)
!>          En la entrada, la sección N por N inicial de H almacena la
!>          matriz de Hessenberg sometida a deflación temprana agresiva.
!>          En la salida, H ha sido transformada por una semejanza unitaria
!>          transformación, perturbada, y devuelta
!>          a la forma de Hessenberg que (se espera) tiene algunas
!>          entradas subdiagonales cero.
!>

LDH

!>          LDH es INTEGER
!>          Dimensión principal de H tal como se declara en la subrutina
!>          llamante. N <= LDH
!>

ILOZ

!>          ILOZ es INTEGER
!>

IHIZ

!>          IHIZ es INTEGER
!>          Especifican las filas de Z a las que se deben aplicar las
!>          transformaciones si WANTZ es .TRUE.. 1 <= ILOZ <= IHIZ <= N.
!>

Z

!>          Z es array COMPLEX, dimension (LDZ,N)
!>          SI WANTZ es .TRUE., entonces en la salida, la semejanza unitaria
!>          transformación mencionada anteriormente ha sido
!>          acumulada en Z(ILOZ:IHIZ,ILOZ:IHIZ) desde la derecha.
!>          Si WANTZ es .FALSE., entonces Z no se referencia.
!>

LDZ

!>          LDZ es INTEGER
!>          La dimensión principal de Z tal como se declara en la
!>          subrutina llamante. 1 <= LDZ.
!>

NS

!>          NS es INTEGER
!>          El número de autovalores no convergidos (es decir, aproximados)
!>          devueltos en SR y SI que pueden ser utilizados como desplazamientos por la
!>          subrutina llamante.
!>

ND

!>          ND es INTEGER
!>          El número de autovalores convergidos descubiertos por esta
!>          subrutina.
!>

SH

!>          SH es array COMPLEX, dimension (KBOT)
!>          En la salida, autovalores aproximados que pueden
!>          ser utilizados para desplazamientos se almacenan en SH(KBOT-ND-NS+1)
!>          a través de SR(KBOT-ND). Autovalores convergidos se
!>          almacenan en SH(KBOT-ND+1) a través de SH(KBOT).
!>

V

!>          V es array COMPLEX, dimension (LDV,NW)
!>          Un array de trabajo NW por NW.
!>

LDV

!>          LDV es INTEGER
!>          La dimensión principal de V tal como se declara en la
!>          subrutina llamante. NW <= LDV
!>

NH

!>          NH es INTEGER
!>          El número de columnas de T. NH >= NW.
!>

T

!>          T es array COMPLEX, dimension (LDT,NW)
!>

LDT

!>          LDT es INTEGER
!>          La dimensión principal de T tal como se declara en la
!>          subrutina llamante. NW <= LDT
!>

NV

!>          NV es INTEGER
!>          El número de filas del array de trabajo WV disponibles para
!>          espacio de trabajo. NV >= NW.
!>

WV

!>          WV es array COMPLEX, dimension (LDWV,NW)
!>

LDWV

!>          LDWV es INTEGER
!>          La dimensión principal de W tal como se declara en la
!>          subrutina llamante. NW <= LDV
!>

WORK

!>          WORK es array COMPLEX, dimension (LWORK)
!>          O

subroutine claqr3 (logical wantt, logical wantz, integer n, integer ktop, integer kbot, integer nw, complex*16, dimension( ldh, * ) h, integer ldh, integer iloz, integer ihiz, complex*16, dimension( ldz, * ) z, integer ldz, integer ns, integer nd, double precision, dimension( * ) sr, double precision, dimension( * ) si, complex*16, dimension( ldv, * ) v, integer ldv, integer nh, complex*16, dimension( ldt, * ) t, integer ldt, integer nv, complex*16, dimension( ldwv, * ) wv, integer ldwv, complex*16, dimension( * ) work, integer lwork)

CLAQR3 performs the orthogonal similarity transformation of a Hessenberg matrix to detect and deflate fully converged eigenvalues from a trailing principal submatrix (aggressive early deflation).

Purpose:

!>
!>    Aggressive early deflation:
!>
!>    CLAQR3 accepts as input an upper Hessenberg matrix
!>    H and performs an orthogonal similarity transformation
!>    designed to detect and deflate fully converged eigenvalues from
!>    a trailing principal submatrix.  On output H has been over-
!>    written by a new Hessenberg matrix that is a perturbation of
!>    an orthogonal similarity transformation of H.  It is to be
!>    hoped that the final version of H has many zero subdiagonal
!>    entries.
!>

Parameters

WANTT 
!>          WANTT is LOGICAL
!>          If .TRUE., then the Hessenberg matrix H is fully updated
!>          so that the quasi-triangular Schur factor may be
!>          computed (in cooperation with the calling subroutine).
!>          If .FALSE., then only enough of H is updated to preserve
!>          the eigenvalues.
!>

WANTZ

!>          WANTZ is LOGICAL
!>          If .TRUE., then the orthogonal matrix Z is updated so
!>          so that the orthogonal Schur factor may be computed
!>          (in cooperation with the calling subroutine).
!>          If .FALSE., then Z is not referenced.
!>

N

!>          N is INTEGER
!>          The order of the matrix H and (if WANTZ is .TRUE.) the
!>          order of the orthogonal matrix Z.
!>

KTOP

!>          KTOP is INTEGER
!>          It is assumed that either KTOP = 1 or H(KTOP,KTOP-1)=0.
!>          KBOT and KTOP together determine an isolated block
!>          along the diagonal of the Hessenberg matrix.
!>

KBOT

!>          KBOT is INTEGER
!>          It is assumed without a check that either
!>          KBOT = N or H(KBOT+1,KBOT)=0.  KBOT and KTOP together
!>          determine an isolated block along the diagonal of the
!>          Hessenberg matrix.
!>

NW

!>          NW is INTEGER
!>          Deflation window size.  1 <= NW <= (KBOT-KTOP+1).
!>

H

!>          H is COMPLEX*16 array, dimension (LDH,N)
!>          On input the initial N-by-N section of H stores the
!>          Hessenberg matrix undergoing aggressive early deflation.
!>          On output H has been transformed by an orthogonal
!>          similarity transformation, perturbed, and the returned
!>          to Hessenberg form that (it is to be hoped) has some
!>          zero subdiagonal entries.
!>

LDH

!>          LDH is INTEGER
!>          Leading dimension of H just as declared in the calling
!>          subroutine.  N <= LDH
!>

ILOZ

!>          ILOZ is INTEGER
!>

IHIZ

!>          IHIZ is INTEGER
!>          Specify the rows of Z to which transformations must be
!>          applied if WANTZ is .TRUE.. 1 <= ILOZ <= IHIZ <= N.
!>

Z

!>          Z is COMPLEX*16 array, dimension (LDZ,N)
!>          IF WANTZ is .TRUE., then on output, the orthogonal
!>          similarity transformation mentioned above has been
!>          accumulated into Z(ILOZ:IHIZ,ILOZ:IHIZ) from the right.
!>          If WANTZ is .FALSE., then Z is unreferenced.
!>

LDZ

!>          LDZ is INTEGER
!>          The leading dimension of Z just as declared in the
!>          calling subroutine.  1 <= LDZ.
!>

NS

!>          NS is INTEGER
!>          The number of unconverged (ie approximate) eigenvalues
!>          returned in SR and SI that may be used as shifts by the
!>          calling subroutine.
!>

ND

!>          ND is INTEGER
!>          The number of converged eigenvalues uncovered by this
!>          subroutine.
!>

SR

!>          SR is DOUBLE PRECISION array, dimension (KBOT)
!>

SI

!>          SI is DOUBLE PRECISION array, dimension (KBOT)
!>          On output, the real and imaginary parts of approximate
!>          eigenvalues that may be used for shifts are stored in
!>          SR(KBOT-ND-NS+1) through SR(KBOT-ND) and
!>          SI(KBOT-ND-NS+1) through SI(KBOT-ND), respectively.
!>          The real and imaginary parts of converged eigenvalues
!>          are stored in SR(KBOT-ND+1) through SR(KBOT) and
!>          SI(KBOT-ND+1) through SI(KBOT), respectively.
!>

V

!>          V is COMPLEX*16 array, dimension (LDV,NW)
!>          An NW-by-NW work array.
!>

LDV

!>          LDV is INTEGER
!>          The leading dimension of V just as declared in the
!>          calling subroutine.  NW <= LDV
!>

NH

!>          NH is INTEGER
!>          The number of columns of T.  NH >= NW.
!>

T

!>          T is COMPLEX*16 array, dimension (LDT,NW)
!>

LDT

!>          LDT is INTEGER
!>          The leading dimension of T just as declared in the
!>          calling subroutine.  NW <= LDT
!>

NV

!>          NV is INTEGER
!>          The number of rows of work array WV available for
!>          workspace.  NV >= NW.
!>

WV

!>          WV is COMPLEX*16 array, dimension (LDWV,NW)
!>

LDWV

!>          LDWV is INTEGER
!>          The leading dimension of W just as declared in the
!>          calling subroutine.  NW <= LDV
!>

WORK

!>          WORK is COMPLEX*16 array, dimension (LWORK)
!>          On exit, WORK(1) is set to an estimate of the optimal value
!>          of LWORK for the given values of N, NW, KTOP and KBOT.
!>

LWORK

!>          LWORK is INTEGER
!>          The dimension of the work array WORK.  LWORK = 2*NW
!>          suffices, but greater efficiency may result from larger
!>          values of LWORK.
!>
!>          If LWORK = -1, then a workspace query is assumed; CLAQR3
!>          only estimates the optimal workspace size for the given
!>          values of N, NW, KTOP and KBOT.  The estimate is returned
!>          in WORK(1).  No error message related to LWORK is issued
!>          by XERBLA.  Neither H nor Z are accessed.
!>

Author

Univ. of California Berkeley

DESCRIPTION

SLAQR3 performs the orthogonal similarity transformation of a Hessenberg matrix to detect and deflate fully converged eigenvalues from a trailing principal submatrix (aggressive early deflation).

Purpose:

!>
!>    Aggressive early deflation:
!>
!>    SLAQR3 accepts as input an upper Hessenberg matrix
!>    H and performs an orthogonal similarity transformation
!>    designed to detect and deflate fully converged eigenvalues from
!>    a trailing principal submatrix.  On output H has been over-
!>    written by a new Hessenberg matrix that is a perturbation of
!>    an orthogonal similarity transformation of H.  It is to be
!>    hoped that the final version of H has many zero subdiagonal
!>    entries.
!>
