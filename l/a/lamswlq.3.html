subrutina clamswlq (character side, character trans, integer m, integer n, integer k, integer mb, integer nb, complex, dimension( lda, * ) a, integer lda, complex, dimension( ldt, * ) t, integer ldt, complex, dimension( ldc, * ) c, integer ldc, complex, dimension( * ) work, integer lwork, integer info)

CLAMSWLQ

Propósito:

!>
!>    CLAMSWLQ sobrescribe la matriz compleja general M por N, C, con
!>
!>
!>                    SIDE = 'L'     SIDE = 'R'
!>    TRANS = 'N':      Q * C          C * Q
!>    TRANS = 'T':      Q**H * C       C * Q**H
!>    donde Q es una matriz unitaria compleja definida como el producto de
!>    reflectores elementales bloqueados calculados por la factorización LQ
!>    corta y ancha (CLASWLQ).
!>

Parámetros

SIDE 
!>          SIDE es CHARACTER*1
!>          = 'L': aplicar Q o Q**H por la Izquierda;
!>          = 'R': aplicar Q o Q**H por la Derecha.
!>

TRANS

!>          TRANS es CHARACTER*1
!>          = 'N':  Sin transponer, aplicar Q;
!>          = 'C':  Transpuesta conjugada, aplicar Q**H.
!>

M

!>          M es INTEGER
!>          El número de filas de la matriz C. M >= 0.
!>

N

!>          N es INTEGER
!>          El número de columnas de la matriz C. N >= 0.
!>

K

!>          K es INTEGER
!>          El número de reflectores elementales cuyo producto define
!>          la matriz Q.
!>          M >= K >= 0;
!>
!>

MB

!>          MB es INTEGER
!>          El tamaño del bloque de filas a usar en la LQ bloqueada.
!>          M >= MB >= 1
!>

NB

!>          NB es INTEGER
!>          El tamaño del bloque de columnas a usar en la LQ bloqueada.
!>          NB > M.
!>

A

!>          A es un array COMPLEX, de dimensión
!>                               (LDA,M) si SIDE = 'L',
!>                               (LDA,N) si SIDE = 'R'
!>          La i-ésima fila debe contener el vector que define el reflector
!>          bloqueado elemental H(i), para i = 1,2,...,k, tal como es devuelto
!>          por CLASWLQ en las primeras k filas de su array argumento A.
!>

LDA

!>          LDA es INTEGER
!>          La dimensión principal del array A. LDA => max(1,K).
!>

T

!>          T es un array COMPLEX, de dimensión
!>          ( M * Número de bloques(CEIL(N-K/NB-K)),
!>          Los reflectores de bloque triangulares superiores bloqueados almacenados
!>          en forma compacta como una secuencia de bloques triangulares superiores.
!>          Ver más abajo para más detalles.
!>

LDT

!>          LDT es INTEGER
!>          La dimensión principal del array T. LDT >= MB.
!>

C

!>          C es un array COMPLEX, de dimensión (LDC,N)
!>          En la entrada, la matriz C de M por N.
!>          En la salida, C es sobrescrita por Q*C o Q**H*C o C*Q**H o C*Q.
!>

LDC

!>          LDC es INTEGER
!>          La dimensión principal del array C. LDC >= max(1,M).
!>

WORK

!>          (espacio de trabajo) array COMPLEX, de dimensión (MAX(1,LWORK))
!>          En la salida, si INFO = 0, WORK(1) devuelve el LWORK mínimo.
!>

LWORK

!>          LWORK es INTEGER
!>          La dimensión del array WORK.
!>          Si MIN(M,N,K) = 0, LWORK >= 1.
!>          Si SIDE = 'L', LWORK >= max(1,NB*MB).
!>          Si SIDE = 'R', LWORK >= max(1,M*MB).
!>
!>          Si LWORK = -1, entonces se asume una consulta de espacio de trabajo; la rutina
!>          sólo calcula el tamaño mínimo del array WORK, devuelve
!>          este valor como la primera entrada del array WORK, y XERBLA no emite ningún
!>          mensaje de error relacionado con LWORK.
!>

INFO

!>          INFO es INTEGER
!>          = 0:  salida exitosa
!>          < 0:  si INFO = -i, el i-ésimo argumento tenía un valor ilegal
!>

Detalles Adicionales:

!> La factorización LQ Corta y Ancha (SWLQ) realiza LQ mediante una secuencia de transformaciones unitarias,
!> representando Q como un producto de otras matrices unitarias
!>   Q = Q(1) * Q(2) * . . . * Q(k)
!> donde cada Q(i) pone a cero las entradas de la superdiagonal de un bloque de NB filas de A:
!>   Q(1) pone a cero las entradas de la superdiagonal de las filas 1:NB de A
!>   Q(2) pone a cero las filas MB-N inferiores de las filas [1:M,NB+1:2*NB-M] de A
!>   Q(3) pone a cero las filas MB-N inferiores de las filas [1:M,2*NB-M+1:3*NB-2*M] de A
!>   . . .
!>
!> Q(1) se calcula por GELQT, que representa Q(1) por vectores de Householder
!> almacenados debajo de la diagonal de las filas 1:MB de A, y por reflectores
!> de bloque triangulares superiores, almacenados en el array T(1:LDT,1:N).
!> Para más información, ver Detalles Adicionales en GELQT.
!>
!> Q(i) para i>1 se calcula por TPLQT, que representa Q(i) por vectores de Householder
!> almacenados en las columnas [(i-1)*(NB-M)+M+1:i*(NB-M)+M] de A, y por reflectores
!> de bloque triangulares superiores, almacenados en el array T(1:LDT,(i-1)*M+1:i*M).
!> La última Q(k) puede usar menos filas.
!> Para más información, ver Detalles Adicionales en TPLQT.
!>
!> Para más detalles sobre el algoritmo general, ver la descripción de
!> TSQR Secuencial en la Sección 2.2 de [1].
!>
!> [1] "Communication-Optimal Parallel and Sequential QR and LU Factorizations,"
!>     J. Demmel, L. Grigori, M. Hoemmen, J. Langou,
!>     SIAM J. Sci. Comput, vol. 34, no. 1, 2012
!>

!> Short-Wide LQ (SWLQ) performs LQ by a sequence of unitary transformations,
!> representing Q as a product of other unitary matrices
!>   Q = Q(1) * Q(2) * . . . * Q(k)
!> where each Q(i) zeros out upper diagonal entries of a block of NB rows of A:
!>   Q(1) zeros out the upper diagonal entries of rows 1:NB of A
!>   Q(2) zeros out the bottom MB-N rows of rows [1:M,NB+1:2*NB-M] of A
!>   Q(3) zeros out the bottom MB-N rows of rows [1:M,2*NB-M+1:3*NB-2*M] of A
!>   . . .
!>
!> Q(1) is computed by GELQT, which represents Q(1) by Householder vectors
!> stored under the diagonal of rows 1:MB of A, and by upper triangular
!> block reflectors, stored in array T(1:LDT,1:N).
!> For more information see Further Details in GELQT.
!>
!> Q(i) for i>1 is computed by TPLQT, which represents Q(i) by Householder vectors
!> stored in columns [(i-1)*(NB-M)+M+1:i*(NB-M)+M] of A, and by upper triangular
!> block reflectors, stored in array T(1:LDT,(i-1)*M+1:i*M).
!> The last Q(k) may use fewer rows.
!> For more information see Further Details in TPLQT.
!>
!> For more details of the overall algorithm, see the description of
!> Sequential TSQR in Section 2.2 of [1].
!>
!> [1] “Communication-Optimal Parallel and Sequential QR and LU Factorizations,”
!>     J. Demmel, L. Grigori, M. Hoemmen, J. Langou,
!>     SIAM J. Sci. Comput, vol. 34, no. 1, 2012
!>

LAMSWL is a generic programming interface for the
            double precision real, double precision complex, single precision real,
            and single precision complex versions of the routine.
