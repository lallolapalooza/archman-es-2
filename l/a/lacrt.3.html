DOCUMENTACIÓN DE FUNCIÓN

subrutina clacrt (entero n, complejo, dimensión( * ) cx, entero incx, complejo, dimensión( * ) cy, entero incy, complejo c, complejo s)

CLACRT realiza una transformación lineal de un par de vectores complejos.

Propósito:

!>
!> CLACRT realiza la operación
!>
!>    (  c  s )( x )  ==> ( x )
!>    ( -s  c )( y )      ( y )
!>
!> donde c y s son complejos y los vectores x e y son complejos.
!>

Parámetros

N 
!>          N es ENTERO
!>          El número de elementos en los vectores CX y CY.
!>

CX

!>          CX es un array COMPLEJO, dimensión (N)
!>          En la entrada, el vector x.
!>          En la salida, CX se sobrescribe con c*x + s*y.
!>

INCX

!>          INCX es ENTERO
!>          El incremento entre valores sucesivos de CX.  INCX <> 0.
!>

CY

!>          CY es un array COMPLEJO, dimensión (N)
!>          En la entrada, el vector y.
!>          En la salida, CY se sobrescribe con -s*x + c*y.
!>

INCY

!>          INCY es ENTERO
!>          El incremento entre valores sucesivos de CY.  INCY <> 0.
!>

C

!>          C es COMPLEJO
!>

S

!>          S es COMPLEJO
!>          C y S definen la matriz
!>             [  C   S  ].
!>             [ -S   C  ]
!>
