NOMBRE

labelframe - Crear y manipular widgets contenedores etiquetados 'labelframe'

SINOPSIS

labelframe rutaNombre ?opciones?

OPCIONES ESTÁNDAR

-borderwidth	-highlightbackground	-pady
-cursor	-highlightcolor	-relief
-font	-highlightthickness	-takefocus
-foreground	-padx	-text

Vea la entrada del manual options para obtener detalles sobre las opciones estándar.

OPCIONES ESPECÍFICAS DEL WIDGET

Nombre de línea de comandos:	-background
Nombre de base de datos:	background
Clase de base de datos:	Background
Esta opción es la misma que la opción estándar -background excepto que su valor también puede especificarse como una cadena vacía. En este caso, el widget no mostrará fondo ni borde, y no se consumirán colores de su mapa de colores para su fondo y borde.
Nombre de línea de comandos:	-class
Nombre de base de datos:	class
Clase de base de datos:	Class
Especifica una clase para la ventana. Esta clase se utilizará al consultar la base de datos de opciones para las otras opciones de la ventana, y también se utilizará posteriormente para otros fines, como enlaces. La opción -class no se puede cambiar con el comando de widget configure.
Nombre de línea de comandos:	-colormap
Nombre de base de datos:	colormap
Clase de base de datos:	Colormap
Especifica un mapa de colores a utilizar para la ventana. El valor puede ser new, en cuyo caso se crea un nuevo mapa de colores para la ventana y sus hijos, o el nombre de otra ventana (que debe estar en la misma pantalla y tener el mismo visual que rutaNombre), en cuyo caso la nueva ventana utilizará el mapa de colores de la ventana especificada. Si no se especifica la opción -colormap, la nueva ventana utiliza el mismo mapa de colores que su padre. Esta opción no se puede cambiar con el comando de widget configure.
Nombre de línea de comandos:	-height
Nombre de base de datos:	height
Clase de base de datos:	Height
Especifica la altura deseada para la ventana en cualquiera de los formatos aceptables para Tk_GetPixels. Si esta opción es menor o igual a cero, la ventana no solicitará ningún tamaño.
Nombre de línea de comandos:	-labelanchor
Nombre de base de datos:	labelAnchor
Clase de base de datos:	LabelAnchor
Especifica dónde colocar la etiqueta. La etiqueta solo se muestra si la opción -text no es una cadena vacía. Los valores válidos para esta opción son (listados en sentido horario) nw, n, ne, en, e, es, se, s, sw, ws, w y wn. El valor predeterminado es nw.
Nombre de línea de comandos:	-labelwidget
Nombre de base de datos:	labelWidget
Clase de base de datos:	LabelWidget
Especifica un widget a usar como etiqueta. Esto anula cualquier opción -text. El widget debe existir antes de ser utilizado como -labelwidget y si no es un descendiente de esta ventana, se elevará por encima de ella en el orden de apilamiento.
Nombre de línea de comandos:	-visual
Nombre de base de datos:	visual
Clase de base de datos:	Visual
Especifica información visual para la nueva ventana en cualquiera de los formatos aceptados por Tk_GetVisual. Si esta opción no se especifica, la nueva ventana utilizará el mismo visual que su padre. La opción -visual no se puede modificar con el comando de widget configure.
Nombre de línea de comandos:	-width
Nombre de base de datos:	width
Clase de base de datos:	Width
Especifica el ancho deseado para la ventana en cualquiera de los formatos aceptables para Tk_GetPixels. Si esta opción es menor o igual a cero, la ventana no solicitará ningún tamaño.

DESCRIPCIÓN

El comando labelframe crea una nueva ventana (dada por el argumento rutaNombre) y la convierte en un widget labelframe. Opciones adicionales, descritas anteriormente, pueden especificarse en la línea de comandos o en la base de datos de opciones para configurar aspectos del labelframe, como su color de fondo y su relieve. El comando labelframe devuelve el nombre de ruta de la nueva ventana.

Un labelframe es un widget simple. Su propósito principal es actuar como un espaciador o contenedor para diseños de ventana complejos. Tiene las características de un frame además de la capacidad de mostrar una etiqueta.

COMANDO DE WIDGET

El comando labelframe crea un nuevo comando Tcl cuyo nombre es el mismo que el nombre de ruta de la ventana del labelframe. Este comando puede usarse para invocar varias operaciones en el widget. Tiene la siguiente forma general:

rutaNombre opción ?arg arg ...?
rutaNombre es el nombre del comando, que es el mismo que el nombre de ruta del widget labelframe. Opción y los args determinan el comportamiento exacto del comando. Los siguientes comandos son posibles para widgets frame:
rutaNombre cget opción
Devuelve el valor actual de la opción de configuración dada por opción. Opción puede tener cualquiera de los valores aceptados por el comando labelframe.
rutaNombre configure ?opción? ?valor opción valor ...?
Consulta o modifica las opciones de configuración del widget. Si no se especifica ninguna opción, devuelve una lista que describe todas las opciones disponibles para rutaNombre (consulte Tk_ConfigureInfo para obtener información sobre el formato de esta lista). Si se especifica una opción sin ningún valor, el comando devuelve una lista que describe la opción con nombre (esta lista será idéntica a la sublista correspondiente del valor devuelto si no se especifica ninguna opción). Si se especifican uno o más pares de opción-valor, el comando modifica la(s) opción(es) del widget dada(s) con el(los) valor(es) dado(s); en este caso, el comando devuelve una cadena vacía. Opción puede tener cualquiera de los valores aceptados por el comando labelframe.

ENLACES

Al crear un nuevo labelframe, no tiene enlaces de eventos predeterminados: los labelframes no están pensados para ser interactivos.

EJEMPLO

Esto muestra cómo construir parte de una GUI para un vendedor de hamburguesas. Los widgets labelframe se utilizan para organizar las opciones disponibles según los tipos sobre los que se toman las decisiones.

grid [labelframe .burger -text "Hamburguesa"] \
     [labelframe .bun    -text "Pan"] -sticky news
grid [labelframe .cheese -text "Opción de Queso"] \
     [labelframe .pickle -text "Opción de Pepinillo"] -sticky news
foreach {tipo nombre valor} {
    burger Beef    beef
    burger Lamb    lamb
    burger Vegetarian beans
    bun    Plain   white
    bun    Sesame  seeds
    bun    Wholemeal brown
    cheese None    none
    cheese Cheddar cheddar
    cheese Edam    edam
    cheese Brie    brie
    cheese Gruy\u00e8re gruyere
    cheese "Monterey Jack" jack
    pickle None    none
    pickle Gherkins gherkins
    pickle Onions  onion
    pickle Chili   chili
} {
    set w [radiobutton .$tipo.$valor -text $nombre -anchor w \
            -variable $tipo -value $valor]
    pack $w -side top -fill x
}
set burger beef
set bun    white
set cheese none
set pickle none
