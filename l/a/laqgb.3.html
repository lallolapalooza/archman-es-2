CLAQGB escala una matriz de banda general, usando factores de escala de fila y columna calculados por sgbequ.

Propósito:

!>
!> CLAQGB equilibra una matriz de banda general M por N A con KL
!> subdiagonales y KU superdiagonales usando los factores de escala de
!> fila y columna en los vectores R y C.
!>

Parámetros

M 
!>          M es ENTERO
!>          El número de filas de la matriz A.  M >= 0.
!>

N

!>          N es ENTERO
!>          El número de columnas de la matriz A.  N >= 0.
!>

KL

!>          KL es ENTERO
!>          El número de subdiagonales dentro de la banda de A.  KL >= 0.
!>

KU

!>          KU es ENTERO
!>          El número de superdiagonales dentro de la banda de A.  KU >= 0.
!>

AB

!>          AB es una matriz COMPLEJA, dimensión (LDAB,N)
!>          En la entrada, la matriz A en almacenamiento de banda, en las filas 1
!>          a KL+KU+1.
!>          La j-ésima columna de A se almacena en la j-ésima columna de la
!>          matriz AB de la siguiente manera:
!>          AB(ku+1+i-j,j) = A(i,j) para max(1,j-ku) <=i<=min(m,j+kl)
!>
!>          En la salida, la matriz equilibrada, en el mismo formato de
!>          almacenamiento que A. Ver EQUED para la forma de la matriz
!>          equilibrada.
!>

LDAB

!>          LDAB es ENTERO
!>          La dimensión principal de la matriz AB.  LDA >= KL+KU+1.
!>

R

!>          R es una matriz REAL, dimensión (M)
!>          Los factores de escala de fila para A.
!>

C

!>          C es una matriz REAL, dimensión (N)
!>          Los factores de escala de columna para A.
!>

ROWCND

!>          ROWCND es REAL
!>          Ratio del R(i) más pequeño al R(i) más grande.
!>

COLCND

!>          COLCND es REAL
!>          Ratio del C(i) más pequeño al C(i) más grande.
!>

AMAX

!>          AMAX es REAL
!>          Valor absoluto de la entrada de matriz más grande.
!>

EQUED

!>          EQUED es CARACTER*1
!>          Especifica la forma de equilibrado que se realizó.
!>          = 'N':  Sin equilibrado
!>          = 'R':  Equilibrado de fila, es decir, A ha sido premultiplicada por
!>                  diag(R).
!>          = 'C':  Equilibrado de columna, es decir, A ha sido postmultiplicada
!>                  por diag(C).
!>          = 'B':  Equilibrado tanto de fila como de columna, es decir, A ha sido
!>                  reemplazada por diag(R) * A * diag(C).
!>

Parámetros Internos:

!>  THRESH es un valor umbral utilizado para decidir si se debe realizar
!>  el escalado de fila o columna basándose en la relación de los factores
!>  de escala de fila o columna. Si ROWCND < THRESH, se realiza el
!>  escalado de fila, y si COLCND < THRESH, se realiza el escalado de
!>  columna.
!>
!>  LARGE y SMALL son valores umbral utilizados para decidir si se debe
!>  realizar el escalado de fila basándose en el tamaño absoluto del
!>  elemento de matriz más grande. Si AMAX > LARGE o AMAX < SMALL, se
!>  realiza el escalado de fila.
!>

dlaqgb (integer m, integer n, integer kl, integer ku, double precision, dimension( ldab, * ) ab, integer ldab, double precision, dimension( * ) r, double precision, dimension( * ) c, double precision rowcnd, double precision colcnd, double precision amax, character equed)



 





Details


Purpose:




!>
!> DLAQGB equilibrates a general M by N band matrix A with KL
!> subdiagonals and KU superdiagonals using the row and scaling factors
!> in the vectors R and C.
!>
!> The equilibration is done by computing a diagonal matrix D such that
!> D*A*D is close to the identity matrix.
!>
!> This routine uses the formulas:
!>
!>   norm(A) = MAX( ABS(A(i,j)) )
!>
!>   infinity-norm = MAX( SUM( ABS(A(i,j)) for j=1 to n) for i=1 to m )
!>
!> A(i,j) is the element in row i and column j.
!>
!> DLAQGB is called by SGBEQU and ZGBEQU to compute the scaling factors
!> R and C.
!>
!> Whenever possible, the equilibration is done by dividing A by
!>      max(ABS(R(i))) and max(ABS(C(i))) respectively.
!>
!> If the maximum absolute value in R or C is close to zero, then the
!> inverse of the scaling factor is taken to be zero.
!>
!> A small value is added to each element of R and C if the maximum
!> absolute value is zero.
!>
!> Arguments:
!>
!> M   - INTEGER
!>       The number of rows of the matrix A. M >= 0.
!>
!> N   - INTEGER
!>       The number of columns of the matrix A. N >= 0.
!>
!> KL  - INTEGER
!>       The number of subdiagonals of the matrix A. KL >= 0.
!>
!> KU  - INTEGER
!>       The number of superdiagonals of the matrix A. KU >= 0.
!>
!> AB  - DOUBLE PRECISION array, dimension (LDAB, N)
!>       On entry, the matrix A in band storage, in rows 1 to KL+KU+1.
!>       The j-th column of A is stored in the j-th column of the
!>       array AB as follows:
!>       AB(ku+1+i-j,j) = A(i,j) for max(1,j-ku) <= i <= min(m,j+kl)
!>
!>       On exit, the equilibrated matrix, in the same storage format
!>       as A. See EQUED for the form of the equilibrated matrix.
!>
!> LDAB- INTEGER
!>       The leading dimension of the array AB. LDA >= KL+KU+1.
!>
!> R   - DOUBLE PRECISION array, dimension (M)
!>       The row scale factors for A.
!>
!> C   - DOUBLE PRECISION array, dimension (N)
!>       The column scale factors for A.
!>
!> ROWCND- DOUBLE PRECISION
!>       Ratio of the smallest R(i) to the largest R(i).
!>
!> COLCND- DOUBLE PRECISION
!>       Ratio of the smallest C(i) to the largest C(i).
!>
!> AMAX- DOUBLE PRECISION
!>       Absolute value of largest matrix entry.
!>
!> EQUED - CHARACTER*1
!>       Specifies the form of equilibration that was done.
!>       = 'N':  No equilibration
!>       = 'R':  Row equilibration, i.e., A has been premultiplied by
!>               diag(R).
!>       = 'C':  Column equilibration, i.e., A has been postmultiplied
!>               by diag(C).
!>       = 'B':  Both row and column equilibration, i.e., A has been
!>               replaced by diag(R) * A * diag(C).
!>





Internal Parameters:




!>  THRESH is a threshold value used to decide if row or column scaling
!>  should be done based on the ratio of the row or column scaling
!>  factors.  If ROWCND < THRESH, row scaling is done, and if
!>  COLCND < THRESH, column scaling is done.
!>
!>  LARGE and SMALL are threshold values used to decide if row scaling
!>  should be done based on the absolute size of the largest matrix
!>  element.  If AMAX > LARGE or AMAX < SMALL, row scaling is done.
!>
