CLABRD reduce las primeras nb filas y columnas de una matriz general a forma bidiagonal.

Propósito:

!>
!> CLABRD reduce las primeras NB filas y columnas de una matriz general compleja
!> m por n A a forma bidiagonal real superior o inferior mediante una transformación unitaria
!> Q**H * A * P, y devuelve las matrices X e Y que son necesarias para aplicar
!> la transformación a la parte no reducida de A.
!>
!> Si m >= n, A se reduce a forma bidiagonal superior; si m < n, a forma bidiagonal inferior.
!>
!> Esta es una subrutina auxiliar llamada por CGEBRD
!>

Parámetros

M 
!>          M es ENTERO
!>          El número de filas en la matriz A.
!>

N

!>          N es ENTERO
!>          El número de columnas en la matriz A.
!>

NB

!>          NB es ENTERO
!>          El número de filas y columnas principales de A a reducir.
!>

A

!>          A es array COMPLEX, dimension (LDA,N)
!>          En la entrada, la matriz general m por n a reducir.
!>          En la salida, las primeras NB filas y columnas de la matriz se
!>          sobrescriben; el resto del array no se modifica.
!>          Si m >= n, los elementos en y debajo de la diagonal en las primeras NB
!>            columnas, con el array TAUQ, representan la matriz unitaria
!>            Q como un producto de reflectores elementales; y
!>            los elementos sobre la diagonal en las primeras NB filas, con el
!>            array TAUP, representan la matriz unitaria P como un producto
!>            de reflectores elementales.
!>          Si m < n, los elementos debajo de la diagonal en las primeras NB
!>            columnas, con el array TAUQ, representan la matriz unitaria
!>            Q como un producto de reflectores elementales, y
!>            los elementos en y sobre la diagonal en las primeras NB filas,
!>            con el array TAUP, representan la matriz unitaria P como un producto
!>            de reflectores elementales.
!>          Ver Detalles Adicionales.
!>

LDA

!>          LDA es ENTERO
!>          La dimensión principal del array A. LDA >= max(1,M).
!>

D

!>          D es array REAL, dimension (NB)
!>          Los elementos diagonales de las primeras NB filas y columnas de
!>          la matriz reducida. D(i) = A(i,i).
!>

E

!>          E es array REAL, dimension (NB)
!>          Los elementos fuera de la diagonal de las primeras NB filas y columnas de
!>          la matriz reducida.
!>

TAUQ

!>          TAUQ es array COMPLEX, dimension (NB)
!>          Los factores escalares de los reflectores elementales que
!>          representan la matriz unitaria Q. Ver Detalles Adicionales.
!>

TAUP

!>          TAUP es array COMPLEX, dimension (NB)
!>          Los factores escalares de los reflectores elementales que
!>          representan la matriz unitaria P. Ver Detalles Adicionales.
!>

X

!>          X es array COMPLEX, dimension (LDX,NB)
!>          La matriz m-por-nb X necesaria para actualizar la parte no reducida
!>          de A.
!>

LDX

!>          LDX es ENTERO
!>          La dimensión principal del array X. LDX >= max(1,M).
!>

Y

!>          Y es array COMPLEX, dimension (LDY,NB)
!>          La matriz n-por-nb Y necesaria para actualizar la parte no reducida
!>          de A.
!>

LDY

!>          LDY es ENTERO
!>          La dimensión principal del array Y. LDY >= max(1,N).
!>

Detalles Adicionales:

!>
!>  Las matrices Q y P se representan como productos de reflectores
!>  elementales:
!>
!>     Q = H(1) H(2) . . . H(nb)  y  P = G(1) G(2) . . . G(nb)
!>
!>  Cada H(i) y G(i) tiene la forma:
!>
!>     H(i) = I - tauq * v * v**H  y G(i) = I - taup * u * u**H
!>
!>  donde tauq y taup son escalares complejos, y v y u son vectores complejos.
!>
!>  Si m >= n, v(1:i-1) = 0, v(i) = 1, y v(i:m) se almacena en la salida en
!>  A(i:m,i); u(1:i) = 0, u(i+1) = 1, y u(i+1:n) se almacena en la salida en
!>  A(i,i+1:n); tauq se almacena en TAUQ(i) y taup en TAUP(i).
!>
!>  Si m < n, v(1:i) = 0, v(i+1) = 1, y v(i+1:m) se almacena en la salida en
!>  A(i+2:m,i); u(1:i-1) = 0, u(i) = 1, y u(i:n) se almacena en la salida en
!>  A(i,i+1:n); tauq se almacena en TAUQ(i) y taup en TAUP(i).
!>
!>  Los elementos de los vectores v y u juntos forman la matriz m-por-nb
!>  V y la matriz nb-por-n U**H que se necesitan, con X e Y, para aplicar
!>  la transformación a la parte no reducida de la matriz, usando una actualización
!>  en bloque de la forma: A := A - V*Y**H - X*U**H.
!>
!>  Los contenidos de A en la salida se ilustran con los siguientes ejemplos
!>  con nb = 2:
!>
!>  m = 6 y n = 5 (m > n):          m = 5 y n = 6 (m < n):
!>
!>    (  1   1   u1  u1  u1 )           (  1   u1  u1  u1  u1  u1 )
!>    (  v1  1   1   u2  u2 )           (  1   1   u2  u2  u2  u2 )
!>    (  v1  v2  a   a   a  )           (  v1  1   a   a   a   a  )
!>    (  v1  v2  a   a   a  )           (  v1  v2  a   a   a   a  )
!>    (  v1  v2  a   a   a  )           (  v1  v2  a   a   a   a  )
!>    (  v1  v2  a   a   a  )
!>
!>  donde a denota un elemento de la matriz original que no se modifica,
!>  vi denota un elemento del vector que define H(i), y ui un elemento
!>  del vector que define G(i).
!>

DESCRIPTION

DLABRD reduces the first nb rows and columns of a real general matrix to a bidiagonal form.

Purpose:

!>
!> DLABRD reduces the first NB rows and columns of a real general
!> m by n matrix A to upper or lower bidiagonal form by an orthogonal
!> transformation Q**T * A * P, and returns the matrices X and Y which
!> are needed to apply the transformation to the unreduced part of A.
!>
!> If m >= n, A is reduced to upper bidiagonal form; if m < n, to lower
!> bidiagonal form.
!>
!> This is an auxiliary routine called by DGEBRD
!>
