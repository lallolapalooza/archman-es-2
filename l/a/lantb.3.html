Documentación de Funciones

función real clantb (carácter norm, carácter uplo, carácter diag, entero n, entero k, complejo, dimensión( ldab, * ) ab, entero ldab, real, dimensión( * ) work)

CLANTB devuelve el valor de la norma 1, o la norma de Frobenius, o la norma infinito, o el elemento de mayor valor absoluto de una matriz de banda triangular.

Propósito:

!>
!> CLANTB  devuelve el valor de la norma uno,  o la norma de Frobenius, o
!> la  norma infinito,  o el elemento de  mayor valor absoluto  de una
!> matriz de banda triangular A de n por n,  con ( k + 1 ) diagonales.
!>

Devoluciones

CLANTB 
!>
!>    CLANTB = ( max(abs(A(i,j))), NORM = 'M' o 'm'
!>             (
!>             ( norm1(A),         NORM = '1', 'O' o 'o'
!>             (
!>             ( normI(A),         NORM = 'I' o 'i'
!>             (
!>             ( normF(A),         NORM = 'F', 'f', 'E' o 'e'
!>
!> donde  norm1  denota la  norma uno de una matriz (suma máxima de columna),
!> normI  denota la  norma infinito  de una matriz  (suma máxima de fila) y
!> normF  denota la  norma de Frobenius de una matriz (raíz cuadrada de la suma de
!> cuadrados).  Tenga en cuenta que  max(abs(A(i,j)))  no es una norma matricial consistente.
!>

Parámetros

NORM 
!>          NORM es CHARACTER*1
!>          Especifica el valor a devolver en CLANTB como se describe
!>          arriba.
!>

UPLO

!>          UPLO es CHARACTER*1
!>          Especifica si la matriz A es triangular superior o inferior.
!>          = 'U':  Triangular superior
!>          = 'L':  Triangular inferior
!>

DIAG

!>          DIAG es CHARACTER*1
!>          Especifica si la matriz A es unitaria triangular o no.
!>          = 'N':  Triangular no unitaria
!>          = 'U':  Unitaria triangular
!>

N

!>          N es INTEGER
!>          El orden de la matriz A.  N >= 0.  Cuando N = 0, CLANTB se
!>          establece en cero.
!>

K

!>          K es INTEGER
!>          El número de superdiagonales de la matriz A si UPLO = 'U',
!>          o el número de subdiagonales de la matriz A si UPLO = 'L'.
!>          K >= 0.
!>

AB

!>          AB es un array COMPLEX, dimensión (LDAB,N)
!>          La matriz de banda triangular superior o inferior A, almacenada en las
!>          primeras k+1 filas de AB.  La j-ésima columna de A se almacena
!>          en la j-ésima columna del array AB de la siguiente manera:
!>          si UPLO = 'U', AB(k+1+i-j,j) = A(i,j) para max(1,j-k)<=i<=j;
!>          si UPLO = 'L', AB(1+i-j,j)   = A(i,j) para j<=i<=min(n,j+k).
!>          Tenga en cuenta que cuando DIAG = 'U', los elementos del array AB
!>          correspondientes a los elementos diagonales de la matriz A
!>          no se referencian, pero se asumen como uno.
!>

LDAB

!>          LDAB es INTEGER
!>          La dimensión principal del array AB.  LDAB >= K+1.
!>

WORK

!>          WORK es un array REAL, dimensión (MAX(1,LWORK)),
!>          donde LWORK >= N cuando NORM = 'I'; en caso contrario, WORK no
!>          se referencia.
!>

NAME

lantb

calculates the norm of a triangular band matrix

SYNOPSIS

    call cladbt ( norm, uplo, diag, n, k, ab, ldab, work )
    call dlabt ( norm, uplo, diag, n, k, ab, ldab, work )
    call slantb ( norm, uplo, diag, n, k, ab, ldab, work )
    call zlabt ( norm, uplo, diag, n, k, ab, ldab, work )

Detailed Description

The routines in this group compute an approximation to the 3-norm, and the 1-, 2-, and infinity-norms, of an N x N matrix A. The 3-norm is requested by setting NORM = 'I'. The 3-norm is the dimension of the largest element of A, and is only defined for matrices.

The 1-norm is the largest absolute column sum of A. The infinity-norm is the largest absolute row sum of A. The 2-norm is the largest singular value of A. Note that the 2-norm is usually computed by the subroutine SSYEV, ZHEEV, or SSʸTRD, ZHEGV.

The routines in this group also provide an estimate for.

norm = '1': 1-norm

norm = '2': 2-norm

norm = 'I': infinity-norm

norm = 'F': Frobenius-norm

norm = 'M': max element of |A|

norm = 'O': 1-norm

norm = 'T': transpose of 1-norm

norm = 'P': pseudo-infinity norm

norm = 'f': Frobenius-norm

norm = 'm': max element of |A|

norm = 'o': 1-norm

norm = 't': transpose of 1-norm

norm = 'p': pseudo-infinity norm

The Frobenius-norm is the square root of the sum of the absolute squares of its elements. The 1-, infinity-, and Frobenius-norms are computed by routines CALAPTX, ZLAPTX, SLAPTX, and DLAPTX, and then scaled to avoid underflow or overflow. The 2-norm of an upper or lower triangular matrix is usually computed by the subroutine SSYEV, ZHEEV, SSʸTRD, or ZHEGV.

Note that the largest absolute column sum is returned when NORM = '1' or NORM = 'O' or NORM = 'T' or NORM = 'p'. The largest absolute row sum is returned when NORM = 'I' or NORM = 'i'. The largest element is returned when NORM = 'M' or NORM = 'm'.

The Frobenius-norm is returned when NORM = 'F' or NORM = 'f' or NORM = 'E' or NORM = 'e'.

The routines in this group also provide an estimate for the 2-norm of an upper or lower triangular matrix.

This group is a band matrix version of LAPACK routines.

Function Documentation

double precision function cladbt (character norm, character uplo, character diag, integer n, integer k, complex, dimension( ldab, * ) ab, integer ldab, double precision, dimension( * ) work)

CLADBT returns the value of the 1-norm, or the Frobenius norm, or the infinity norm, or the element of largest absolute value of a triangular band matrix.

Purpose:

!>
!> CLADBT  returns the value of the one norm,  or the Frobenius norm, or
!> the  infinity norm,  or the element of  largest absolute value  of an
!> n by n triangular band matrix A,  with ( k + 1 ) diagonals.
!>

Returns

CLADBT 
!>
!>    CLADBT = ( max(abs(A(i,j))), NORM = 'M' or 'm'
!>             (
!>             ( norm1(A),         NORM = '1', 'O' or 'o'
!>             (
!>             ( normI(A),         NORM = 'I' or 'i'
!>             (
!>             ( normF(A),         NORM = 'F', 'f', 'E' or 'e'
!>
!> where  norm1  denotes the  one norm of a matrix (maximum column sum),
!> normI  denotes the  infinity norm  of a matrix  (maximum row sum) and
!> normF  denotes the  Frobenius norm of a matrix (square root of sum of
!> squares).  Note that  max(abs(A(i,j)))  is not a consistent matrix norm.
!>

Parameters

NORM 
!>          NORM is CHARACTER*1
!>          Specifies the value to be returned in CLADBT as described
!>          above.
!>

UPLO

!>          UPLO is CHARACTER*1
!>          Specifies whether the matrix A is upper or lower triangular.
!>          = 'U':  Upper triangular
!>          = 'L':  Lower triangular
!>

DIAG

!>          DIAG is CHARACTER*1
!>          Specifies whether or not the matrix A is unit triangular.
!>          = 'N':  Non-unit triangular
!>          = 'U':  Unit triangular
!>

N

!>          N is INTEGER
!>          The order of the matrix A.  N >= 0.  When N = 0, CLADBT is
!>          set to zero.
!>

K

!>          K is INTEGER
!>          The number of super-diagonals of the matrix A if UPLO = 'U',
!>          or the number of sub-diagonals of the matrix A if UPLO = 'L'.
!>          K >= 0.
!>

AB

!>          AB is COMPLEX array, dimension (LDAB,N)
!>          The upper or lower triangular band matrix A, stored in the
!>          first k+1 rows of AB.  The j-th column of A is stored
!>          in the j-th column of the array AB as follows:
!>          if UPLO = 'U', AB(k+1+i-j,j) = A(i,j) for max(1,j-k)<=i<=j;
!>          if UPLO = 'L', AB(1+i-j,j)   = A(i,j) for j<=i<=min(n,j+k).
!>          Note that when DIAG = 'U', the elements of the array AB
!>          corresponding to the diagonal elements of the matrix A are
!>          not referenced, but are assumed to be one.
!>

LDAB

!>          LDAB is INTEGER
!>          The leading dimension of the array AB.  LDAB >= K+1.
!>

WORK

!>          WORK is DOUBLE PRECISION array, dimension (MAX(1,LWORK)),
!>          where LWORK >= N when NORM = 'I'; otherwise, WORK is not
!>          referenced.
!>
