subrutina clargv (integer n, complex, dimension( * ) x, integer incx, complex, dimension( * ) y, integer incy, real, dimension( * ) c, integer incc)

CLARGV genera un vector de rotaciones de plano con cosenos reales y sines complejos.

Propósito:

!>
!> CLARGV genera un vector de rotaciones de plano complejas con cosenos reales,
!> determinado por los elementos de los vectores complejos x e y. Para i = 1,2,...,n
!>
!>    (        c(i)   s(i) ) ( x(i) ) = ( r(i) )
!>    ( -conjg(s(i))  c(i) ) ( y(i) ) = (   0  )
!>
!>    donde c(i)**2 + ABS(s(i))**2 = 1
!>
!> Se utilizan las siguientes convenciones (estas son las mismas que en CLARTG,
!> pero difieren de la rutina BLAS1 CROTG):
!>    Si y(i)=0, entonces c(i)=1 y s(i)=0.
!>    Si x(i)=0, entonces c(i)=0 y s(i) se elige de manera que r(i) sea real.
!>

Parámetros

N 
!>          N es ENTERO
!>          El número de rotaciones de plano a generar.
!>

X

!>          X es un array COMPLEJO, dimensión (1+(N-1)*INCX)
!>          En la entrada, el vector x.
!>          En la salida, x(i) se sobrescribe con r(i), para i = 1,...,n.
!>

INCX

!>          INCX es ENTERO
!>          El incremento entre elementos de X. INCX > 0.
!>

Y

!>          Y es un array COMPLEJO, dimensión (1+(N-1)*INCY)
!>          En la entrada, el vector y.
!>          En la salida, los sines de las rotaciones de plano.
!>

INCY

!>          INCY es ENTERO
!>          El incremento entre elementos de Y. INCY > 0.
!>

C

!>          C es un array REAL, dimensión (1+(N-1)*INCC)
!>          Los cosenos de las rotaciones de plano.
!>

INCC

!>          INCC es ENTERO
!>          El incremento entre elementos de C. INCC > 0.
!>

NAME

ZLARGV

generates a vector of plane rotations with real cosines and complex sines

SYNOPSIS

subroutine zlargv (n, x, incx, y, incy, c, incc)

  dimension( * ) y, integer incy, double precision, dimension( * ) c, integer
  incc)

Detailed Description

ZLARGV generates a vector of plane rotations with real cosines and complex sines.

Purpose:

!>
!> ZLARGV generates a vector of complex plane rotations with real
!> cosines, determined by elements of the complex vectors x and y.
!> For i = 1,2,...,n
!>
!>    (        c(i)   s(i) ) ( x(i) ) = ( r(i) )
!>    ( -conjg(s(i))  c(i) ) ( y(i) ) = (   0  )
!>
!>    where c(i)**2 + ABS(s(i))**2 = 1
!>
!> The following conventions are used (these are the same as in ZLARTG,
!> but differ from the BLAS1 routine ZROTG):
!>    If y(i)=0, then c(i)=1 and s(i)=0.
!>    If x(i)=0, then c(i)=0 and s(i) is chosen so that r(i) is real.
!>

Parameters

N 
!>          N is INTEGER
!>          The number of plane rotations to be generated.
!>
X 
!>          X is COMPLEX*16 array, dimension (1+(N-1)*INCX)
!>          On entry, the vector x.
!>          On exit, x(i) is overwritten by r(i), for i = 1,...,n.
!>
INCX 
!>          INCX is INTEGER
!>          The increment between elements of X. INCX > 0.
!>
Y 
!>          Y is COMPLEX*16 array, dimension (1+(N-1)*INCY)
!>          On entry, the vector y.
!>          On exit, the sines of the plane rotations.
!>
INCY 
!>          INCY is INTEGER
!>          The increment between elements of Y. INCY > 0.
!>
C 
!>          C is DOUBLE PRECISION array, dimension (1+(N-1)*INCC)
!>          The cosines of the plane rotations.
!>
INCC 
!>          INCC is INTEGER
!>          The increment between elements of C. INCC > 0.
!>
