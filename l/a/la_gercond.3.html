función real cla_gercond_c (carácter trans, entero n, complejo, dimensión( lda, * ) a, entero lda, complejo, dimensión( ldaf, * ) af, entero ldaf, entero, dimensión( * ) ipiv, real, dimensión( * ) c, lógico capply, entero info, complejo, dimensión( * ) work, real, dimensión( * ) rwork)

CLA_GERCOND_C calcula el número de condición de la norma infinito de op(A)*inv(diag(c)) para matrices generales.

Propósito:

!>
!>
!>    CLA_GERCOND_C calcula el número de condición de la norma infinito de
!>    op(A) * inv(diag(C)) donde C es un vector REAL.
!>

Parámetros

TRANS 
!>          TRANS es CHARACTER*1
!>     Especifica la forma del sistema de ecuaciones:
!>       = 'N':  A * X = B     (Sin transposición)
!>       = 'T':  A**T * X = B  (Transpuesta)
!>       = 'C':  A**H * X = B  (Transpuesta Conjugada = Transpuesta)
!>

N

!>          N es ENTERO
!>     El número de ecuaciones lineales, es decir, el orden de la
!>     matriz A.  N >= 0.
!>

A

!>          A es un array COMPLEJO, de dimensión (LDA,N)
!>     En la entrada, la matriz A de N por N.
!>

LDA

!>          LDA es ENTERO
!>     La dimensión principal del array A.  LDA >= max(1,N).
!>

AF

!>          AF es un array COMPLEJO, de dimensión (LDAF,N)
!>     Los factores L y U de la factorización
!>     A = P*L*U como se calculó con CGETRF.
!>

LDAF

!>          LDAF es ENTERO
!>     La dimensión principal del array AF.  LDAF >= max(1,N).
!>

IPIV

!>          IPIV es un array ENTERO, de dimensión (N)
!>     Los índices de pivote de la factorización A = P*L*U
!>     como se calculó con CGETRF; la fila i de la matriz se intercambió
!>     con la fila IPIV(i).
!>

C

!>          C es un array REAL, de dimensión (N)
!>     El vector C en la fórmula op(A) * inv(diag(C)).
!>

CAPPLY

!>          CAPPLY es LÓGICO
!>     Si es .TRUE., accede al vector C en la fórmula anterior.
!>

INFO

!>          INFO es ENTERO
!>       = 0:  Salida exitosa.
!>     i > 0:  El i-ésimo argumento es inválido.
!>

WORK

!>          WORK es un array COMPLEJO, de dimensión (2*N).
!>     Espacio de trabajo.
!>

RWORK

!>          RWORK es un array REAL, de dimensión (N).
!>     Espacio de trabajo.
!>

DLA_GERCOND estima el número de condición de Skeel para una matriz general.

Propósito:

!>
!>
!>    DLA_GERCOND estima el número de condición de Skeel de op(A) * C,
!>    donde C es una matriz diagonal definida por el vector X o
!>    la matriz diagonal definida por el vector C
!>
!>    donde el número de condición de Skeel se define como
!>
!>        cond_S(A) = max_{i,j} |A_ij * (A^-1)_ij|
!>
!>    Si CMODE = 1, C está definida por el vector X de la forma
!>    diag(X). Si CMODE = 2, C es una matriz diagonal definida por
!>    el vector C.
!>
!>    Los dos problemas lineales se resuelven mediante
!>    una solución de mínimos cuadrados de un sistema lineal Ax = b.
!>

Parámetros

TRANS 
!>          TRANS es CHARACTER*1
!>     Especifica la forma de la matriz.
!>     = 'N':  A    se utiliza.
!>     = 'T':  A**T se utiliza.
!>     = 'C':  A**H se utiliza.
!>

N

!>          N es ENTERO
!>     El número de filas y columnas de la matriz A.
!>

A

!>          A es un array DOBLE PRECISIÓN de dimensión (LDA,N).
!>     Matriz de coeficientes.
!>

LDA

!>          LDA es ENTERO
!>     El orden principal de A.
!>

AF

!>          AF es un array DOBLE PRECISIÓN de dimensión (LDAF,N).
!>     La factorización LU de A, A = P*L*U.
!>

LDAF

!>          LDAF es ENTERO
!>     El orden principal de AF.
!>

IPIV

!>          IPIV es un array ENTERO de dimensión (N).
!>     Los detalles de la pivota de la factorización LU.
!>

CMODE

!>          CMODE es ENTERO
!>     El tipo de vector o matriz C.
!>       = 1:  El sistema es op(A)*diag(X)
!>       = 2:  El sistema es op(A)*C
!>

C

!>          C es un array DOBLE PRECISIÓN de dimensión (N).
!>     Si CMODE = 1, entonces C se ignora. Si CMODE = 2, entonces
!>     C contiene los elementos de la matriz diagonal.
!>

INFO

!>          INFO es ENTERO
!>       = 0:  Salida exitosa.
!>       i>0:  El i-ésimo argumento es inválido.
!>       i<0:  El i-ésimo argumento es inválido.
!>

WORK

!>          WORK es un array DOBLE PRECISIÓN de dimensión (N).
!>     Espacio de trabajo.
!>

IWORK

!>          IWORK es un array ENTERO de dimensión (N).
!>     Espacio de trabajo.
!>

DESCRIPTION

The routines in this section estimate the Skeel condition number for a general matrix A. The condition number is computed for the problem op(A) * op2(C), where op(A) is A, AT, or AH, and op2(C) is C, I, or inv(C) depending on the value of CMODE.

The condition number is estimated by computing scaling factors R such that diag(R) * A is row equilibrated. This is done using the LU factorization of A with partial pivoting computed by DGETRF, SGETRF, or ZGETRF.

The routines compute the infinity norm of the matrix diag(R) * A * op2(C), and the infinity norm of its inverse.

The condition number is returned as the value of the function.

DIAGNOSTICS

In all routines, INFO is an integer and if the routine completes successfully, INFO = 0. Otherwise, INFO will be set to i, indicating that the i-th argument was invalid.
