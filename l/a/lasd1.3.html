DLASD1 calcula la SVD de una matriz B bidiagonal superior del tamaño especificado. Utilizado por sbdsdc.

Propósito:

!>
!> DLASD1 calcula la SVD de una matriz B bidiagonal superior de tamaño N-por-M,
!> donde N = NL + NR + 1 y M = N + SQRE. DLASD1 es llamada desde DLASD0.
!>
!> Una subrutina relacionada DLASD7 maneja el caso en el que se desean los
!> valores singulares (y los vectores singulares en forma factorizada).
!>
!> DLASD1 calcula la SVD de la siguiente manera:
!>
!>               ( D1(in)    0    0       0 )
!>   B = U(in) * (   Z1**T   a   Z2**T    b ) * VT(in)
!>               (   0       0   D2(in)   0 )
!>
!>     = U(out) * ( D(out) 0) * VT(out)
!>
!> donde Z**T = (Z1**T a Z2**T b) = u**T VT**T, y u es un vector de dimensión M
!> con ALPHA y BETA en las entradas NL+1 y NL+2 y ceros
!> en otras partes; y la entrada b está vacía si SQRE = 0.
!>
!> Los vectores singulares izquierdos de la matriz original se almacenan en U, y
!> la transpuesta de los vectores singulares derechos se almacenan en VT, y los
!> valores singulares están en D. El algoritmo consta de tres etapas:
!>
!>    La primera etapa consiste en desmantelar el tamaño del problema
!>    cuando hay múltiples valores singulares o cuando hay ceros en
!>    el vector Z. Por cada ocurrencia de este tipo, la dimensión del
!>    problema de la ecuación secular se reduce en uno. Esta etapa es
!>    realizada por la rutina DLASD2.
!>
!>    La segunda etapa consiste en calcular los valores singulares
!>    actualizados. Esto se hace encontrando las raíces cuadradas de las
!>    raíces de la ecuación secular a través de la rutina DLASD4 (llamada
!>    por DLASD3). Esta rutina también calcula los vectores singulares del
!>    problema actual.
!>
!>    La etapa final consiste en calcular los vectores singulares
!>    actualizados directamente utilizando los valores singulares actualizados.
!>    Los vectores singulares del problema actual se multiplican con los vectores
!>    singulares del problema general.
!>

!>         La dimensión de fila del bloque superior. NL >= 1.
!>

NR

!>          NR es INTEGER
!>         La dimensión de fila del bloque inferior. NR >= 1.
!>

SQRE

!>          SQRE es INTEGER
!>         = 0: el bloque inferior es una matriz cuadrada NR-por-NR.
!>         = 1: el bloque inferior es una matriz rectangular NR-por-(NR+1).
!>
!>         La matriz bidiagonal tiene dimensión de fila N = NL + NR + 1,
!>         y dimensión de columna M = N + SQRE.
!>

D

!>          D es array de DOUBLE PRECISION,
!>                        dimensión (N = NL+NR+1).
!>         En la entrada D(1:NL,1:NL) contiene los valores singulares del
!>         bloque superior; y D(NL+2:N) contiene los valores singulares del
!>         bloque inferior. En la salida D(1:N) contiene los valores singulares
!>         de la matriz modificada.
!>

ALPHA

!>          ALPHA es DOUBLE PRECISION
!>         Contiene el elemento diagonal asociado con la fila añadida.
!>

BETA

!>          BETA es DOUBLE PRECISION
!>         Contiene el elemento fuera de la diagonal asociado con la fila
!>         añadida.
!>

!>          U es array de DOUBLE PRECISION, dimensión(LDU,N)

!>         vectores singulares izquierdos de la matriz bidiagonal.
!>

LDU

!>

VT

!>          VT es array de DOUBLE PRECISION, dimensión(LDVT,M)

!>         En la entrada VT(1:NL+1, 1:NL+1)**T contiene los vectores singulares
!>         derechos del bloque superior; VT(NL+2:M, NL+2:M)**T contiene
!>         los vectores singulares derechos del bloque inferior. En la salida
!>         VT**T contiene los vectores singulares derechos de la
!>         matriz bidiagonal.
!>

LDVT

!>          LDVT es INTEGER
!>         La dimensión principal del array VT. LDVT >= max( 1, M ).

IDXQ

IWORK

WORK

!>          WORK es array de DOUBLE PRECISION, dimensión( 3*M**2 + 2*M )

INFO

!>          INFO es INTEGER
!>          = 0: salida exitosa.
!>          < 0: si INFO = -i, el i-ésimo argumento tenía un valor ilegal.
!>          > 0: si INFO = 1, un valor singular no convergió

Name

lasd1

update the singular value decomposition of a bidiagonal matrix

Synopsis

SUBROUTINE LASD1(NL, NR, SQRE, D, ALPHA, BETA, U, LDU, VT, LDVT, IDXQ,
                 IWORK, WORK, INFO)
CHARACTER        *   1
INTEGER          NL, NR, SQRE, LDU, LDVT, INFO
REAL             D( NL + NR + 1 ), ALPHA, BETA
REAL             U( LDU, NL + NR + 1 ), VT( LDVT, NL + NR + 1 + SQRE )
INTEGER          IDXQ( NL + NR + 1 ), IWORK( 4 * ( NL + NR + 1 ) )
REAL             WORK( 3 * (NL + NR + 1) * (NL + NR + 1 + SQRE) + 2*(NL + NR + 1) )

Detailed Description

This routine implements the core logic of the described algorithm for updating the singular value decomposition (SVD) of a bidiagonal matrix when a new row and column are added.

The initial bidiagonal matrix is assumed to have had its rows and columns permuted such that the diagonal elements are in increasing order. This routine first splits the bidiagonal matrix into two smaller bidiagonal matrices, updates the SVD of each of these smaller matrices, and then merges the results. The merging is done by solving a secular equation.

The representation of the bidiagonal matrix is:

      U * D * VT

where U and VT are orthogonal matrices, and D is a diagonal matrix containing the singular values in increasing order.

The matrix is represented in factored form as:

      (  D1   0  )
      ( 0     D2 )

where D1 is an NL-by-NL upper block diagonal matrix, and D2 is an NR-by-NR (or NR-by-(NR+1) if SQRE=1) lower block diagonal matrix. The algorithm updates the SVD of this matrix by considering the addition of a new row and column, represented by ALPHA and BETA.

!>     The initial bidiagonal matrix B is assumed to be of the form
!>     B =  ( B1  )
!>          (     )
!>          ( B2  )
!>
!>     where B1 is NL+1 by NL+1 and B2 is NR by NR+SQRE.
!>     The algorithm effectively computes the SVD of a new matrix B_tilde
!>     which is obtained by adding a row and column to B.
!>
!>     Let the original bidiagonal matrix be denoted by B.
!>     The updated matrix B_tilde is of the form
!>
!>     B_tilde = diag(B1, beta) + u * v_T
!>
!>     where B1 is an (N-1)x(N-1) bidiagonal matrix, N = NL + NR + 1,
!>     and u and v are vectors of length N.
!>
!>     The algorithm splits the bidiagonal matrix into two subproblems:
!>     An upper NL x NL bidiagonal matrix and a lower NR x (NR+SQRE)
!>     bidiagonal matrix.
!>     The SVD of these two subproblems are updated independently,
!>     and then the results are merged by solving a secular equation.
!>
!>     The equation is of the form:
!>
!>     Z**T * V = U * D
!>
!>     where Z**T = (Z1**T a Z2**T b)
!>           a is a vector of dimension NL+1 containing ALPHA in the
!>             NL+1 th entry and zeros elsewhere.
!>           b is a vector of dimension NR+SQRE. If SQRE = 1, then b contains
!>             BETA in the NRth entry and zeros elsewhere. If SQRE = 0,
!>             then b is empty.
!>
!>     The secular equation is solved for the singular values of B_tilde.
!>
!>     The relationship between the SVD of the original matrix and the
!>     updated matrix is given by:
!>
!>     VT(in) * ( D(in) 0 ) * U(in) = U(out) * D(out) * VT(out)
!>            (  0    D2(in) )
!>
!>     where Z**T = (Z1**T a Z2**T b) = u**T VT**T, and u is a vector of dimension M
!>     with ALPHA and BETA in the NL+1 and NL+2 th entries and zeros
!>     elsewhere; and the entry b is empty if SQRE = 0.
!>
!>     The left singular vectors of the original matrix are stored in U, and
!>     the transpose of the right singular vectors are stored in VT, and the
!>     singular values are in D.  The algorithm consists of three stages:
!>
!>        The first stage consists of deflating the size of the problem
!>        when there are multiple singular values or when there are zeros in
!>        the Z vector.  For each such occurrence the dimension of the
!>        secular equation problem is reduced by one.  This stage is
!>        performed by the routine SLASD2.
!>
!>        The second stage consists of calculating the updated
!>        singular values. This is done by finding the square roots of the
!>        roots of the secular equation via the routine SLASD4 (as called
!>        by SLASD3). This routine also calculates the singular vectors of
!>        the current problem.
!>
!>        The final stage consists of computing the updated singular vectors
!>        directly using the updated singular values.  The singular vectors
!>        for the current problem are multiplied with the singular vectors
!>        from the overall problem.
!>

Parameters

NL
!>          NL is INTEGER
!>         The row dimension of the upper block.  NL >= 1.
NR
!>          NR is INTEGER
!>         The row dimension of the lower block.  NR >= 1.
SQRE
!>          SQRE is INTEGER
!>         = 0: the lower block is an NR-by-NR square matrix.
!>         = 1: the lower block is an NR-by-(NR+1) rectangular matrix.
!>
!>         The bidiagonal matrix has row dimension N = NL + NR + 1,
!>         and column dimension M = N + SQRE.
D
!>          D is REAL array, dimension (NL+NR+1).
!>         N = NL+NR+1
!>         On entry D(1:NL,1:NL) contains the singular values of the
!>         upper block; and D(NL+2:N) contains the singular values of
!>         the lower block. On exit D(1:N) contains the singular values
!>         of the modified matrix.
ALPHA
!>          ALPHA is REAL
!>         Contains the diagonal element associated with the added row.
BETA
!>          BETA is REAL
!>         Contains the off-diagonal element associated with the added
!>         row.
U
!>          U is REAL array, dimension (LDU,N)
!>         On entry U(1:NL, 1:NL) contains the left singular vectors of
!>         the upper block; U(NL+2:N, NL+2:N) contains the left singular
!>         vectors of the lower block. On exit U contains the left
!>         singular vectors of the bidiagonal matrix.
LDU
!>          LDU is INTEGER
!>         The leading dimension of the array U.  LDU >= max( 1, N ).
VT
!>          VT is REAL array, dimension (LDVT,M)
!>         where M = N + SQRE.
!>         On entry VT(1:NL+1, 1:NL+1)**T contains the right singular
!>         vectors of the upper block; VT(NL+2:M, NL+2:M)**T contains
!>         the right singular vectors of the lower block. On exit
!>         VT**T contains the right singular vectors of the
!>         bidiagonal matrix.
LDVT
!>          LDVT is INTEGER
!>         The leading dimension of the array VT.  LDVT >= max( 1, M ).
IDXQ
!>          IDXQ is INTEGER array, dimension (N)
!>         This contains the permutation which will reintegrate the
!>         subproblem just solved back into sorted order, i.e.
!>         D( IDXQ( I = 1, N ) ) will be in ascending order.
IWORK
!>          IWORK is INTEGER array, dimension (4*N)
WORK
!>          WORK is REAL array, dimension (3*M**2+2*M)
INFO
!>          INFO is INTEGER
!>          = 0:  successful exit.
!>          < 0:  if INFO = -i, the i-th argument had an illegal value.
!>          > 0:  if INFO = 1, a singular value did not converge
