CLAED8 usada por CSTEDC. Combina valores propios y deflaciona la ecuación secular. Usada cuando la matriz original es densa.

Propósito:

!>
!> CLAED8 combina los dos conjuntos de valores propios en un único
!> conjunto ordenado. Luego intenta deflacionar el tamaño del problema.
!> Hay dos formas en las que puede ocurrir la deflación: cuando dos o más
!> valores propios están muy juntos o si hay un elemento minúsculo en el
!> vector Z. Por cada ocurrencia de este tipo, el orden del problema de la
!> ecuación secular relacionado se reduce en uno.
!>

Parámetros

K 
!>          K es ENTERO
!>         Contiene el número de valores propios no deflacionados.
!>         Este es el orden de la ecuación secular relacionada.
!>

N

!>          N es ENTERO
!>         La dimensión de la matriz simétrica tridiagonal.  N >= 0.
!>

QSIZ

!>          QSIZ es ENTERO
!>         La dimensión de la matriz unitaria utilizada para reducir
!>         la matriz densa o de banda a forma tridiagonal.
!>         QSIZ >= N si ICOMPQ = 1.
!>

Q

!>          Q es un array COMPLEJO, dimensión (LDQ,N)
!>         En la entrada, Q contiene los vectores propios del sistema
!>         parcialmente resuelto que ha sido previamente actualizado en
!>         multiplicaciones matriciales con otros sistemas propios
!>         parcialmente resueltos.
!>         En la salida, Q contiene los últimos (N-K) vectores propios
!>         actualizados (aquellos que fueron deflacionados) en sus últimas
!>         N-K columnas.
!>

LDQ

!>          LDQ es ENTERO
!>         La dimensión principal del array Q.  LDQ >= max( 1, N ).
!>

D

!>          D es un array REAL, dimensión (N)
!>         En la entrada, D contiene los valores propios de las dos
!>         submatrices a combinar.  En la salida, D contiene los últimos
!>         (N-K) valores propios actualizados (aquellos que fueron deflacionados)
!>         ordenados en orden creciente.
!>

RHO

!>          RHO es REAL
!>         Contiene el elemento fuera de la diagonal asociado con el corte
!>         de rango 1 que originalmente dividió las dos submatrices que ahora
!>         se están recombinando. RHO se modifica durante el cálculo al
!>         valor requerido por SLAED3.
!>

CUTPNT

!>          CUTPNT es ENTERO
!>         Contiene la ubicación del último valor propio en la submatriz
!>         delantera.  MIN(1,N) <= CUTPNT <= N.
!>

Z

!>          Z es un array REAL, dimensión (N)
!>         En la entrada, este vector contiene el vector de actualización (la
!>         última fila de la primera matriz de sub-vectores propios y la primera
!>         fila de la segunda matriz de sub-vectores propios). El contenido de Z
!>         se destruye durante el proceso de actualización.
!>

DLAMBDA

!>          DLAMBDA es un array REAL, dimensión (N)
!>         Contiene una copia de los primeros K valores propios que se usarán
!>         en SLAED3 para formar la ecuación secular.
!>

Q2

!>          Q2 es un array COMPLEJO, dimensión (LDQ2,N)
!>         Si ICOMPQ = 0, Q2 no se referencia. En caso contrario,
!>         Contiene una copia de los primeros K vectores propios que se usarán
!>         en SLAED7 en una multiplicación matricial (SGEMM) para actualizar los
!>         nuevos vectores propios.
!>

LDQ2

!>          LDQ2 es ENTERO
!>         La dimensión principal del array Q2.  LDQ2 >= max( 1, N ).
!>

W

!>          W es un array REAL, dimensión (N)
!>         Este contendrá los primeros k valores del vector z final
!>         alterado por deflación y se pasará a SLAED3.
!>

INDXP

!>          INDXP es un array ENTERO, dimensión (N)
!>         Este contendrá la permutación utilizada para colocar los valores
!>         de D deflacionados al final del array. En la salida, INDXP(1:K)
!>         apunta a los valores D no deflacionados e INDXP(K+1:N)
!>         apunta a los valores propios deflacionados.
!>

INDX

!>          INDX es un array ENTERO, dimensión (N)
!>         Este contendrá la permutación utilizada para ordenar el contenido de
!>         D en orden ascendente.
!>

INDXQ

!>          INDXQ es un array ENTERO, dimensión (N)
!>         Este contiene la permutación que ordena por separado los dos
!>         subproblemas en D en orden ascendente.  Tenga en cuenta que los elementos
!>         en la segunda mitad de esta permutación deben tener CUTPNT
!>         añadido a sus valores para ser precisos.
!>

PERM

!>          PERM es un array ENTERO, dimensión (N)
!>         Contiene las permutaciones (de deflación y ordenación) que se
!>         aplicarán a cada bloque de valores propios.
!>

GIVPTR

!>          GIVPTR es ENTERO
!>         Contiene el número de rotaciones de Givens que tuvieron lugar en
!>         este subproblema.
!>

GIVCOL

!>          GIVCOL es un array ENTERO, dimensión (2, N)
!>         Cada par de números indica un par de columnas que tomarán parte
!>         en una rotación de Givens.
!>

GIVNUM

!>          GIVNUM es un array REAL, dimensión (2, N)
!>         Cada número indica el valor S a usar en la
!>         rotación de Givens correspondiente.
!>

INFO

!>          INFO es ENTERO
!>          = 0:  salida exitosa.
!>          < 0:  si INFO = -i, el argumento i-ésimo tenía un valor ilegal.
!>

subroutine SLAED8 (REAL, dimension( LDQ, * ) Q, INTEGER LDQ, REAL, dimension( * ) D, REAL RHO, INTEGER CUTPNT, REAL, dimension( * ) Z, REAL, dimension( * ) DLAMBDA, REAL, dimension( LDQ2, * ) Q2, INTEGER LDQ2, REAL, dimension( * ) W, INTEGER, dimension( * ) INDXP, INTEGER, dimension( * ) INDX, INTEGER, dimension( * ) INDXQ, INTEGER, dimension( * ) PERM, INTEGER GIVPTR, INTEGER, dimension( 2, * ) GIVCOL, REAL, dimension( 2, * ) GIVNUM, INTEGER INFO)

SLAED8

SLAED8 is a subroutine that updates the eigenvalues and eigenvectors of a symmetric tridiagonal matrix.

Purpose:

!>
!> SLAED8 merges the two sets of eigenvalues together into a single
!> sorted set. Then it tries to deflate the size of the problem.
!> There are two ways in which deflation can occur: when two or more
!> eigenvalues are close together or if there is a tiny element in the
!> Z vector. For each such occurrence the order of the related secular
!> equation problem is reduced by one.
!>

Parameters

K 
!>          K is INTEGER
!>         Contains the number of non-deflated eigenvalues.
!>         This is the order of the related secular equation.
!>

N

!>          N is INTEGER
!>         The dimension of the symmetric tridiagonal matrix. N >= 0.
!>

QSiz

!>          QSiz is INTEGER
!>         The dimension of the unitary matrix used to reduce
!>         the dense or band matrix to tridiagonal form.
!>         QSiz >= N if ICOMPQ = 1.
!>

Q

!>          Q is REAL array, dimension (LDQ,N)
!>         On entry, Q contains the eigenvectors of the partially solved
!>         system which has been previously updated in matrix
!>         multiplies with other partially solved eigensystems.
!>         On exit, Q contains the trailing (N-K) updated eigenvectors
!>         (those which were deflated) in its last N-K columns.
!>

LDQ

!>          LDQ is INTEGER
!>         The leading dimension of the array Q. LDQ >= max(1,N).
!>

D

!>          D is REAL array, dimension (N)
!>         On entry, D contains the eigenvalues of the two submatrices to
!>         be combined. On exit, D contains the trailing (N-K) updated
!>         eigenvalues (those which were deflated) sorted into increasing
!>         order.
!>

RHO

!>          RHO is REAL
!>         Contains the off diagonal element associated with the rank-1
!>         cut which originally split the two submatrices which are now
!>         being recombined. RHO is modified during the computation to
!>         the value required by SLAED3.
!>

CUTPNT

!>          CUTPNT is INTEGER
!>         Contains the location of the last eigenvalue in the leading
!>         sub-matrix. MIN(1,N) <= CUTPNT <= N.
!>

Z

!>          Z is REAL array, dimension (N)
!>         On input this vector contains the updating vector (the last
!>         row of the first sub-eigenvector matrix and the first row of
!>         the second sub-eigenvector matrix). The contents of Z are
!>         destroyed during the updating process.
!>

DLAMBDA

!>          DLAMBDA is REAL array, dimension (N)
!>         Contains a copy of the first K eigenvalues which will be used
!>         by SLAED3 to form the secular equation.
!>

Q2

!>          Q2 is REAL array, dimension (LDQ2,N)
!>         If ICOMPQ = 0, Q2 is not referenced. Otherwise,
!>         a copy of the first K eigenvectors which will be used by
!>         SLAED7 in a matrix multiply (SGEMM) to update the new
!>         eigenvectors.
!>

LDQ2

!>          LDQ2 is INTEGER
!>         The leading dimension of the array Q2. LDQ2 >= max(1,N).
!>

W

!>          W is REAL array, dimension (N)
!>         The first k values of the final deflation-altered z-vector and
!>         will be passed to SLAED3.
!>

PERM

!>          PERM is INTEGER array, dimension (N)
!>         The permutations (from deflation and sorting) to be applied
!>         to each eigenblock.
!>

GIVPTR

!>          GIVPTR is INTEGER
!>         The number of Givens rotations which took place in this
!>         subproblem.
!>

GIVCOL

!>          GIVCOL is INTEGER array, dimension (2, N)
!>         Each pair of numbers indicates a pair of columns to take place
!>         in a Givens rotation.
!>

GIVNUM

!>          GIVNUM is REAL array, dimension (2, N)
!>         Each number indicates the S value to be used in the
!>         corresponding Givens rotation.
!>

INDXP

!>          INDXP is INTEGER array, dimension (N)
!>         The permutation used to place deflated values of D at the end
!>         of the array. INDXP(1:K) points to the nondeflated D-values
!>         and INDXP(K+1:N) points to the deflated eigenvalues.
!>

INDX

!>          INDX is INTEGER array, dimension (N)
!>         The permutation used to sort the contents of D into ascending
!>         order.
!>

INDXQ

!>          INDXQ is INTEGER array, dimension (N)
!>         The permutation which separately sorts the two sub-problems
!>         in D into ascending order. Note that elements in the second
!>         half of this permutation must first have CUTPNT added to
!>         their values in order to be accurate.
!>

INFO

!>          INFO is INTEGER
!>          = 0:  successful exit.
!>          < 0:  if INFO = -i, the i-th argument had an illegal value.
!>

Detailed Description

This subroutine finishes the task of computing the unsigned eigenvalues and eigenvectors of a symmetric tridiagonal matrix T. T is represented in factored form as T = Q * D * Q**T, where D is diagonal and Q is orthogonal. T may be a global matrix or the matrix of a subproblem in the divide and conquer approach to compute the eigenvalues and eigenvectors of a dense symmetric matrix.

LAED8 finishes the computation of the unsigned eigenvalues and eigenvectors of T. It is called by the main driver routine LAEDR.

Specifically, suppose T = T_1 T_2 ... T_p is the block tridiagonal matrix where T_i are the blocks obtained from the divide and conquer approach. The matrix T is represented by the diagonal entries D and the super- and sub-diagonal entries (QRTZ). LAED8 takes as input the results of the recursive calls to the subproblems and computes the unsigned eigenvalues and eigenvectors of T.

If the current subproblem corresponds to the initial matrix, then the unsigned eigenvalues and eigenvectors of the global matrix are computed.

Also, LAED8 can be used to compute the unsigned eigenvalues and eigenvectors of a single tridiagonal matrix. In this case, the input matrix is already in the form of a single block, and the recursive calls are not needed.

The unsigned eigenvalues are computed by LAED8. The eigenvalues are returned in the array D, sorted in increasing order.
