DOCUMENTACIÓN DE LA FUNCIÓN

función real cla_gbrpvgrw (entero n, entero kl, entero ku, entero ncols, complejo, dimensión( ldab, * ) ab, entero ldab, complejo, dimensión( ldafb, * ) afb, entero ldafb)

CLA_GBRPVGRW calcula el factor de crecimiento recíproco del pivote norm(A)/norm(U) para una matriz general de banda.

Propósito:

!>
!> CLA_GBRPVGRW calcula el factor de crecimiento recíproco del pivote
!> norm(A)/norm(U). Se utiliza la norma . Si esto es
!> mucho menor que 1, la estabilidad de la factorización LU de la
!> matriz (equilibrada) A podría ser pobre. Esto también significa que la
!> solución X, los números de condición estimados y los límites de error podrían ser
!> poco fiables.
!>

Parámetros

N 
!>          N es ENTERO
!>     El número de ecuaciones lineales, es decir, el orden de la
!>     matriz A.  N >= 0.
!>

KL

!>          KL es ENTERO
!>     El número de subdiagonales dentro de la banda de A.  KL >= 0.
!>

KU

!>          KU es ENTERO
!>     El número de superdiagonales dentro de la banda de A.  KU >= 0.
!>

NCOLS

!>          NCOLS es ENTERO
!>     El número de columnas de la matriz A.  NCOLS >= 0.
!>

AB

!>          AB es array COMPLEJO, dimensión (LDAB,N)
!>     En la entrada, la matriz A en almacenamiento de banda, en las filas 1 a KL+KU+1.
!>     La j-ésima columna de A se almacena en la j-ésima columna del
!>     array AB de la siguiente manera:
!>     AB(KU+1+i-j,j) = A(i,j) para max(1,j-KU)<=i<=min(N,j+kl)
!>

LDAB

!>          LDAB es ENTERO
!>     La dimensión principal del array AB.  LDAB >= KL+KU+1.
!>

AFB

!>          AFB es array COMPLEJO, dimensión (LDAFB,N)
!>     Detalles de la factorización LU de la matriz de banda A, como
!>     calculado por CGBTRF.  U se almacena como una matriz triangular superior
!>     de banda con KL+KU superdiagonales en las filas 1 a KL+KU+1,
!>     y los multiplicadores utilizados durante la factorización se almacenan
!>     en las filas KL+KU+2 a 2*KL+KU+1.
!>

LDAFB

!>          LDAFB es ENTERO
!>     La dimensión principal del array AFB.  LDAFB >= 2*KL+KU+1.
!>

NAME

                    
la_gbrpvgrw - SGBRQST, ZGBRQST compute the reciprocal pivot
                        growth factor norm(A)/norm(U) for a general banded matrix.

                

                

                    
SYNOPSIS

                    

                        
real function sla_gbrpvgrw (integer n, integer kl, integer ku, integer ncols, real, dimension( ldab, * ) ab, integer ldab, real, dimension( ldafb, * ) afb, integer ldafb)

double   complex function zla_gbrpvgrw (integer n, integer kl, integer ku, integer   ncols, double   complex, dimension( ldab, * ) ab, integer ldab, double   complex, dimension( ldafb, * ) afb, integer ldafb)

                    

                

                

                    
Detailed Description

                    
la_gbrpvgrw computes the reciprocal pivot growth
                        factor norm(A)/norm(U) for a general banded matrix.

                    
Purpose:

                    

                        
!>
!>sla_gbrpvgrw computes the reciprocal pivot growth factor
!> norm(A)/norm(U). The  norm is used. If this is
!> much less than 1, the stability of the LU factorization of the
!> (equilibrated) matrix A could be poor. This also means that the
!> solution X, estimated condition numbers, and error bounds could be
!> unreliable.
!>

                    

                    
Parameters

                    
N
                        
!>          N is INTEGER
!>     The number of linear equations, i.e., the order of the
!>     matrix A.  N >= 0.
!>

                        
KL

                        
!>          KL is INTEGER
!>     The number of subdiagonals within the band of A.  KL >= 0.
!>

                        
KU

                        
!>          KU is INTEGER
!>     The number of superdiagonals within the band of A.  KU >= 0.
!>

                        
NCOLS

                        
!>          NCOLS is INTEGER
!>     The number of columns of the matrix A.  NCOLS >= 0.
!>

                        
AB

                        
!>          AB is REAL array, dimension (LDAB,N)
!>     On entry, the matrix A in band storage, in rows 1 to KL+KU+1.
!>     The j-th column of A is stored in the j-th column of the
!>     array AB as follows:
!>     AB(KU+1+i-j,j) = A(i,j) for max(1,j-KU)<=i<=min(N,j+kl)
!>

                        
LDAB

                        
!>          LDAB is INTEGER
!>     The leading dimension of the array AB.  LDAB >= KL+KU+1.
!>

                        
AFB

                        
!>          AFB is REAL array, dimension (LDAFB,N)
!>     Details of the LU factorization of the band matrix A, as
!>     computed by SGBTRF.  U is stored as an upper triangular
!>     band matrix with KL+KU superdiagonals in rows 1 to KL+KU+1,
!>     and the multipliers used during the factorization are stored
!>     in rows KL+KU+2 to 2*KL+KU+1.
!>

                        
LDAFB

                        
!>          LDAFB is INTEGER
!>     The leading dimension of the array AFB.  LDAFB >= 2*KL+KU+1.
!>
