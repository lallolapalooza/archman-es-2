subrutina clauum (carácter uplo, entero n, complejo, dimensión( lda, * ) a, entero lda, entero info)

CLAUUM calcula el producto UUH o LHL, donde U y L son matrices triangulares superiores o inferiores (algoritmo en bloque).

Propósito:

!>
!> CLAUUM calcula el producto U * U**H o L**H * L, donde el factor triangular
!> U o L está almacenado en la parte triangular superior o inferior de
!> la matriz A.
!>
!> Si UPLO = 'U' o 'u', entonces el triángulo superior del resultado se almacena,
!> sobrescribiendo el factor U en A.
!> Si UPLO = 'L' o 'l', entonces el triángulo inferior del resultado se almacena,
!> sobrescribiendo el factor L en A.
!>
!> Esta es la forma en bloque del algoritmo, que llama a BLAS de Nivel 3.
!>

Parámetros

UPLO 
!>          UPLO es CHARACTER*1
!>          Especifica si el factor triangular almacenado en la matriz A
!>          es triangular superior o inferior:
!>          = 'U':  Triangular superior
!>          = 'L':  Triangular inferior
!>

N

!>          N es INTEGER
!>          El orden del factor triangular U o L.  N >= 0.
!>

A

!>          A es una matriz COMPLEX, dimensión (LDA,N)
!>          En la entrada, el factor triangular U o L.
!>          En la salida, si UPLO = 'U', el triángulo superior de A se
!>          sobrescribe con el triángulo superior del producto U * U**H;
!>          si UPLO = 'L', el triángulo inferior de A se sobrescribe con
!>          el triángulo inferior del producto L**H * L.
!>

LDA

!>          LDA es INTEGER
!>          La dimensión principal de la matriz A.  LDA >= max(1,N).
!>

INFO

!>          INFO es INTEGER
!>          = 0: finalización exitosa
!>          < 0: si INFO = -k, el k-ésimo argumento tuvo un valor ilegal
!>

NAME

zlauum - Computa el producto U * U**H o L**H * L, donde el factor triangular U o L está almacenado en la parte triangular superior o inferior de la matriz A.

SYNOPSIS

   SUBROUTINE ZLAUUM( UPLO, N, A, LDA, INFO )

     CHARACTER * 1 UPLO
     INTEGER N
     COMPLEX*16 A( LDA, * )
     INTEGER LDA
     INTEGER INFO

Description

ZLAUUM computa el producto U * U**H o L**H * L, donde el factor triangular U o L está almacenado en la parte triangular superior o inferior de la matriz A.

Si UPLO = 'U' o 'u', se almacena el triángulo superior del resultado, sobrescribiendo el factor U en A.

Si UPLO = 'L' o 'l', se almacena el triángulo inferior del resultado, sobrescribiendo el factor L en A.

Esta es la forma bloqueada del algoritmo, llamando a BLAS de Nivel 3.

Arguments

UPLO

UPLO es CHARACTER*1.

Especifica si el factor triangular almacenado en la matriz A es triangular superior o inferior:

    = 'U': Triangular superior
    = 'L': Triangular inferior
N

N es INTEGER.

El orden del factor triangular U o L. N >= 0.

A

A es COMPLEX*16 array, dimension (LDA,N).

En la entrada, el factor triangular U o L.

En la salida, si UPLO = 'U', el triángulo superior de A se sobrescribe con el triángulo superior del producto U * U**H; si UPLO = 'L', el triángulo inferior de A se sobrescribe con el triángulo inferior del producto L**H * L.

LDA

LDA es INTEGER.

La dimensión principal de la matriz A. LDA >= max(1,N).

INFO

INFO es INTEGER.

    = 0: éxito
    < 0: si INFO = -k, el k-ésimo argumento tenía un valor ilegal
