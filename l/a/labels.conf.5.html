LABELS.CONF(5) Manual de formatos de archivo LABELS.CONF(5)

NOMBRE

labels.conf - Configuración de etiquetas de Performance Co-Pilot

SINOPSIS

/etc/pcp/labels.conf

DESCRIPCIÓN

Varias herramientas y utilidades de Performance Co-Pilot (PCP) admiten el uso de etiquetas de métricas. Esta funcionalidad aplica un conjunto jerárquico de etiquetas a cada instancia de cada métrica, como se describe en pmLookupLabels(3).

Los demonios pmcd(1) y pmproxy(1) son particularmente importantes para el sistema de etiquetas, proporcionando respectivamente las etiquetas en tiempo real y luego descubriendo etiquetas grabadas (de archivo) y indexándolas para consultas de pmseries(1) utilizando un servicio de clave-valor distribuido como https://valkey.io/.

El archivo /etc/pcp/labels.conf es un único punto de configuración para el comportamiento que afecta a todas las etiquetas exportadas por pmcd o a través de herramientas que utilizan servicios de contexto local de PMAPI. Utiliza el formato común de archivo ``ini'' y cualquier variable que especifique que no está en una sección explícitamente entre corchetes se considera una variable [global].

Las variables de configuración disponibles son las siguientes:

machineid_hash=none|sha256
Cuando se especifica en la sección [global], controla la forma en que se exporta el machine-id(5) local como etiqueta. La configuración predeterminada (none) exporta una etiqueta de contexto "machineid" con un valor que refleja el contenido del archivo /etc/machine-id, en cualquier plataforma que proporcione este archivo. La alternativa (sha256) exporta en su lugar una etiqueta "machineid_sha256", y el valor es el hash SHA256 (unidireccional) del archivo.

VER TAMBIÉN

pmcd(1), pmproxy(1), pmseries(1), PMAPI(3), pmLookupLabels(3) y machine-id(5).
