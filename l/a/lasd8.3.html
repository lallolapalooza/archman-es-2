DOCUMENTACIÓN DE FUNCIÓN

subrutina dlasd8 (integer icompq, integer k, double precision, dimension( * ) d, double precision, dimension( * ) z, double precision, dimension( * ) vf, double precision, dimension( * ) vl, double precision, dimension( * ) difl, double precision, dimension( lddifr, * ) difr, integer lddifr, double precision, dimension( * ) dsigma, double precision, dimension( * ) work, integer info)

DLASD8 encuentra las raíces cuadradas de las raíces de la ecuación secular, y almacena, para cada elemento en D, la distancia a sus dos polos más cercanos. Usado por sbdsdc.

Propósito:

!>
!> DLASD8 encuentra las raíces cuadradas de las raíces de la ecuación
!> secular, según lo definido por los valores en DSIGMA y Z. Realiza las
!> llamadas apropiadas a DLASD4, y almacena, para cada elemento en D, la
!> distancia a sus dos polos más cercanos (elementos en DSIGMA). También
!> actualiza los arrays VF y VL, los componentes primero y último de todos
!> los vectores singulares derechos de la matriz bidiagonal original.
!>
!> DLASD8 es llamado desde DLASD6.
!>

Parámetros

ICOMPQ 
!>          ICOMPQ es INTEGER
!>          Especifica si los vectores singulares se van a calcular en
!>          forma factorizada en la rutina de llamada:
!>          = 0: Calcular solo valores singulares.
!>          = 1: Calcular también vectores singulares en forma factorizada.
!>

K

!>          K es INTEGER
!>          El número de términos en la función racional a ser resuelta
!>          por DLASD4.  K >= 1.
!>

D

!>          D es array DOUBLE PRECISION, dimension ( K )
!>          En la salida, D contiene los valores singulares actualizados.
!>

Z

!>          Z es array DOUBLE PRECISION, dimension ( K )
!>          En la entrada, los primeros K elementos de este array contienen los
!>          componentes del vector de fila de actualización ajustado por
!>          deflación.
!>          En la salida, Z se actualiza.
!>

VF

!>          VF es array DOUBLE PRECISION, dimension ( K )
!>          En la entrada, VF contiene información pasada a través de
!>          DBEDE8.
!>          En la salida, VF contiene los primeros K componentes de los
!>          primeros componentes de todos los vectores singulares
!>          derechos de la matriz bidiagonal.
!>

VL

!>          VL es array DOUBLE PRECISION, dimension ( K )
!>          En la entrada, VL contiene información pasada a través de
!>          DBEDE8.
!>          En la salida, VL contiene los primeros K componentes de los
!>          últimos componentes de todos los vectores singulares
!>          derechos de la matriz bidiagonal.
!>

DIFL

!>          DIFL es array DOUBLE PRECISION, dimension ( K )
!>          En la salida, DIFL(I) = D(I) - DSIGMA(I).
!>

DIFR

!>          DIFR es array DOUBLE PRECISION,
!>                   dimension ( LDDIFR, 2 ) si ICOMPQ = 1 y
!>                   dimension ( K ) si ICOMPQ = 0.
!>          En la salida, DIFR(I,1) = D(I) - DSIGMA(I+1), DIFR(K,1) no
!>          está definido y no será referenciado.
!>
!>          Si ICOMPQ = 1, DIFR(1:K,2) es un array que contiene los
!>          factores de normalización para la matriz de vectores
!>          singulares derechos.
!>

LDDIFR

!>          LDDIFR es INTEGER
!>          La dimensión principal de DIFR, debe ser al menos K.
!>

DSIGMA

!>          DSIGMA es array DOUBLE PRECISION, dimension ( K )
!>          En la entrada, los primeros K elementos de este array contienen las
!>          viejas raíces del problema de actualización desdeflado. Estos son los
!>          polos de la ecuación secular.
!>

WORK

!>          WORK es array DOUBLE PRECISION, dimension (3*K)
!>

INFO

!>          INFO es INTEGER
!>          = 0:  salida exitosa.
!>          < 0:  si INFO = -i, el i-ésimo argumento tuvo un valor ilegal.
!>          > 0:  si INFO = 1, un valor singular no convergió
!>

Detailed Description

                    
This subroutine is part of the divide and conquer algorithm for computing the singular value decomposition (SVD) of a bidiagonal matrix.

                    
Specifically, it handles the merge step of the algorithm, where the singular values and vectors of subproblems are combined to obtain the solution for the larger problem.
