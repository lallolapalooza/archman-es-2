DLASDQ calcula la SVD de una matriz bidiagonal real con diagonal d y fuera de diagonal e. Usado por sbdsdc.

Propósito:

!>
!> DLASDQ calcula la descomposición en valores singulares (SVD) de una matriz
!> bidiagonal real (superior o inferior) con diagonal D y fuera de diagonal
!> E, acumulando las transformaciones si se desea. Denotando B la
!> matriz bidiagonal de entrada, el algoritmo calcula matrices ortogonales
!> Q y P tales que B = Q * S * P**T (P**T denota la transpuesta
!> de P). Los valores singulares S se sobrescriben en D.
!>
!> La matriz de entrada U  se cambia a U  * Q  si se desea.
!> La matriz de entrada VT se cambia a P**T * VT si se desea.
!> La matriz de entrada C  se cambia a Q**T * C  si se desea.
!>
!> Ver  por J. Demmel y W. Kahan,
!> Nota de Trabajo de LAPACK #3, para una descripción detallada del algoritmo.
!>

Parámetros

UPLO 
!>          UPLO es CARÁCTER*1
!>        En la entrada, UPLO especifica si la matriz bidiagonal de entrada
!>        es superior o inferior bidiagonal, y si es cuadrada o
!>        no.
!>           UPLO = 'U' o 'u'   B es superior bidiagonal.
!>           UPLO = 'L' o 'l'   B es inferior bidiagonal.
!>

SQRE

!>          SQRE es ENTERO
!>        = 0: entonces la matriz de entrada es N por N.
!>        = 1: entonces la matriz de entrada es N por (N+1) si UPLU = 'U' y
!>             (N+1) por N si UPLU = 'L'.
!>
!>        La matriz bidiagonal tiene
!>        N = NL + NR + 1 filas y
!>        M = N + SQRE  >= N columnas.
!>

N

!>          N es ENTERO
!>        En la entrada, N especifica el número de filas y columnas
!>        en la matriz. N debe ser al menos 0.
!>

NCVT

!>          NCVT es ENTERO
!>        En la entrada, NCVT especifica el número de columnas de
!>        la matriz VT. NCVT debe ser al menos 0.
!>

NRU

!>          NRU es ENTERO
!>        En la entrada, NRU especifica el número de filas de
!>        la matriz U. NRU debe ser al menos 0.
!>

NCC

!>          NCC es ENTERO
!>        En la entrada, NCC especifica el número de columnas de
!>        la matriz C. NCC debe ser al menos 0.
!>

D

!>          D es array de DOBLE PRECISIÓN, dimensión (N)
!>        En la entrada, D contiene las entradas diagonales de la
!>        matriz bidiagonal cuya SVD se desea. En salida normal,
!>        D contiene los valores singulares en orden ascendente.
!>

E

!>          E es array de DOBLE PRECISIÓN.
!>        la dimensión es (N-1) si SQRE = 0 y N si SQRE = 1.
!>        En la entrada, las entradas de E contienen las entradas fuera de diagonal
!>        de la matriz bidiagonal cuya SVD se desea. En salida normal,
!>        E contendrá 0. Si el algoritmo no converge,
!>        D y E contendrán las entradas diagonales y superdiagonales
!>        de una matriz bidiagonal ortogonalmente equivalente a la dada
!>        como entrada.
!>

VT

!>          VT es array de DOBLE PRECISIÓN, dimensión (LDVT, NCVT)
!>        En la entrada, contiene una matriz que a la salida ha sido
!>        premultiplicada por P**T, dimensión N por NCVT si SQRE = 0
!>        y (N+1) por NCVT si SQRE = 1 (no referenciado si NCVT=0).
!>

LDVT

!>          LDVT es ENTERO
!>        En la entrada, LDVT especifica la dimensión principal de VT tal como
!>        se declara en el programa (sub)llamador. LDVT debe ser
!>        al menos 1. Si NCVT no es cero, LDVT también debe ser al menos N.
!>

U

!>          U es array de DOBLE PRECISIÓN, dimensión (LDU, N)
!>        En la entrada, contiene una matriz que a la salida ha sido
!>        postmultiplicada por Q, dimensión NRU por N si SQRE = 0
!>        y NRU por (N+1) si SQRE = 1 (no referenciado si NRU=0).
!>

LDU

!>          LDU es ENTERO
!>        En la entrada, LDU  especifica la dimensión principal de U tal como
!>        se declara en el programa (sub)llamador. LDU debe ser
!>        al menos max( 1, NRU ) .
!>

C

!>          C es array de DOBLE PRECISIÓN, dimensión (LDC, NCC)
!>        En la entrada, contiene una matriz N por NCC que a la salida
!>        ha sido premultiplicada por Q**T  dimensión N por NCC si SQRE = 0
!>        y (N+1) por NCC si SQRE = 1 (no referenciado si NCC=0).
!>

LDC

!>          LDC es ENTERO
!>        En la entrada, LDC  especifica la dimensión principal de C tal como
!>        se declara en el programa (sub)llamador. LDC debe ser
!>        al menos 1. Si NCC no es cero, LDC también debe ser al menos N.
!>

WORK

!>          WORK es array de DOBLE PRECISIÓN, dimensión (4*N)
!>        Espacio de trabajo. Solo se referencia si uno de NCVT, NRU, o NCC no
!>        es cero, y si N es al menos 2.
!>

INFO

!>          INFO es ENTERO
!>        En la salida, un valor de 0 indica una salida exitosa.
!>        Si INFO < 0, el argumento número -INFO es ilegal.
!>        Si INFO > 0, el algoritmo no convergió, y INFO
!>        especifica cuántas superdiagonales no convergieron.
!>

NAME

lasdq — lasdq

SYNOPSIS

SUBROUTINE LASDQ(
     UPLO, SQRE, N, NCVT, NRU, NCC, D, E, VT, LDVT, U, LDU, C, LDC, WORK,
     INFO
    )


      CHARACTER * 1 UPLO
      INTEGER SQRE, N, NCVT, NRU, NCC, LDVT, LDU, LDC, INFO
      REAL D(*), E(*), VT(*), U(*), C(*), WORK(*)

Detailed Description

This routine is part of the LAPACK routine LASDQ. It computes the singular value decomposition (SVD) of a bidiagonal matrix B = U * S * V**T, where S is a diagonal matrix containing the singular values, and U and V are orthogonal matrices. The algorithm is based on the QR iteration method for computing the SVD of a bidiagonal matrix.

The input matrix B is represented by its diagonal entries D and its off-diagonal entries E. The routine computes the singular values and overwrites the input D with them in ascending order. The off-diagonal entries E are zeroed out on normal exit.

The routine can also accumulate the transformations U and VT if desired. The input matrices U and VT are modified to store the accumulated orthogonal transformations. The input matrix C can also be transformed by Q**T.

The algorithm used is described in:

See by J. Demmel and W. Kahan, LAPACK Working Note #3, for a detailed
description of the algorithm.

The routine handles both upper and lower bidiagonal matrices. The parameter SQRE determines the shape of the input matrix, allowing for non-square matrices.

The routine returns an INFO flag to indicate success or failure. An INFO value of 0 indicates a successful execution. A negative INFO value indicates an illegal argument. A positive INFO value indicates that the algorithm did not converge within the specified number of iterations.

Function Documentation

 UPLO
          UPLO is CHARACTER*1
        On entry, UPLO specifies whether the input bidiagonal matrix
        is upper or lower bidiagonal, and whether it is square are
        not.
           UPLO = 'U' or 'u'   B is upper bidiagonal.
           UPLO = 'L' or 'l'   B is lower bidiagonal.


 SQRE
          SQRE is INTEGER
        = 0: then the input matrix is N-by-N.
        = 1: then the input matrix is N-by-(N+1) if UPLU = 'U' and
             (N+1)-by-N if UPLU = 'L'.

        The bidiagonal matrix has
        N = NL + NR + 1 rows and
        M = N + SQRE >= N columns.


 N
          N is INTEGER
        On entry, N specifies the number of rows and columns
        in the matrix. N must be at least 0.


 NCVT
          NCVT is INTEGER
        On entry, NCVT specifies the number of columns of
        the matrix VT. NCVT must be at least 0.


 NRU
          NRU is INTEGER
        On entry, NRU specifies the number of rows of
        the matrix U. NRU must be at least 0.


 NCC
          NCC is INTEGER
        On entry, NCC specifies the number of columns of
        the matrix C. NCC must be at least 0.


 D
          D is REAL array, dimension (N)
        On entry, D contains the diagonal entries of the
        bidiagonal matrix whose SVD is desired. On normal exit,
        D contains the singular values in ascending order.


 E
          E is REAL array.
        dimension is (N-1) if SQRE = 0 and N if SQRE = 1.
        On entry, the entries of E contain the offdiagonal entries
        of the bidiagonal matrix whose SVD is desired. On normal
        exit, E will contain 0. If the algorithm does not converge,
        D and E will contain the diagonal and superdiagonal entries
        of a bidiagonal matrix orthogonally equivalent to the one
        given as input.


 VT
          VT is REAL array, dimension (LDVT, NCVT)
        On entry, contains a matrix which on exit has been
        premultiplied by P**T, dimension N-by-NCVT if SQRE = 0
        and (N+1)-by-NCVT if SQRE = 1 (not referenced if NCVT=0).


 LDVT
          LDVT is INTEGER
        On entry, LDVT specifies the leading dimension of VT as
        declared in the calling (sub)program. LDVT must be at
        least 1. If NCVT is nonzero LDVT must also be at least N.


 U
          U is REAL array, dimension (LDU, N)
        On entry, contains a  matrix which on exit has been
        postmultiplied by Q, dimension NRU-by-N if SQRE = 0
        and NRU-by-(N+1) if SQRE = 1 (not referenced if NRU=0).


 LDU
          LDU is INTEGER
        On entry, LDU  specifies the leading dimension of U as
        declared in the calling (sub)program. LDU must be at
        least max( 1, NRU ) .


 C
          C is REAL array, dimension (LDC, NCC)
        On entry, contains an N-by-NCC matrix which on exit
        has been premultiplied by Q**T  dimension N-by-NCC if SQRE = 0
        and (N+1)-by-NCC if SQRE = 1 (not referenced if NCC=0).


 LDC
          LDC is INTEGER
        On entry, LDC  specifies the leading dimension of C as
        declared in the calling (sub)program. LDC must be at
        least 1. If NCC is nonzero, LDC must also be at least N.


 WORK
          WORK is REAL array, dimension (4*N)
        Workspace. Only referenced if one of NCVT, NRU, or NCC is
        nonzero, and if N is at least 2.


 INFO
          INFO is INTEGER
        On exit, a value of 0 indicates a successful exit.
        If INFO < 0, argument number -INFO is illegal.
        If INFO > 0, the algorithm did not converge, and INFO
        specifies how many superdiagonals did not converge.
