DOCUMENTACIÓN DE LA FUNCIÓN

subrutina clarfgp (integer n, complex alpha, complex, dimension( * ) x, integer incx, complex tau)

CLARFGP genera un reflector elemental (matriz de Householder) con beta no negativo.

Propósito:

!>
!> CLARFGP genera un reflector elemental complejo H de orden n, tal
!> que
!>
!>       H**H * ( alpha ) = ( beta ),   H**H * H = I.
!>              (   x   )   (   0  )
!>
!> donde alpha y beta son escalares, beta es real y no negativo, y
!> x es un vector complejo de n-1 elementos. H se representa en la forma
!>
!>       H = I - tau * ( 1 ) * ( 1 v**H ) ,
!>                     ( v )
!>
!> donde tau es un escalar complejo y v es un vector complejo de n-1
!> elementos. Nótese que H no es hermitiana.
!>
!> Si los elementos de x son todos cero y alpha es real, entonces tau = 0
!> y H se considera la matriz unidad.
!>

Parámetros

N 
!>          N es INTEGER
!>          El orden del reflector elemental.
!>

ALPHA

!>          ALPHA es COMPLEX
!>          En la entrada, el valor alpha.
!>          En la salida, se sobrescribe con el valor beta.
!>

X

!>          X es un array COMPLEX, de dimensión
!>                         (1+(N-2)*abs(INCX))
!>          En la entrada, el vector x.
!>          En la salida, se sobrescribe con el vector v.
!>

INCX

!>          INCX es INTEGER
!>          El incremento entre elementos de X. INCX > 0.
!>

TAU

!>          TAU es COMPLEX
!>          El valor tau.
!>

lapack - larfgp(3)

NAME

larfgp - LARFG_32 LARFG_64 constructs a Householder reflector

SYNOPSIS

    SUBROUTINE LARFGP( N, ALPHA, X, INCX, TAU )

This subroutine constructs a Householder reflector

    H = [ 1 - TAU * V * V^H ]
    0   V

where V is a vector of dimension N with leading entry 1 and subsequent entries defined by the vector X, and TAU is a scalar that determines the character of the elementary reflector.

The elements of the vector V are given by X, scaled such that V(1) = 1.

This routine is an internal routine for generating Householder reflectors.

Detailed Description

This subroutine is an internal routine whose argument list differs slightly from the public interface routine DLARFG.

The purpose of LARFGP is to compute the arguments required to define a elementary reflector H = I - tau*v*v^H which will transform the vector x to another vector y of the form

    [ beta ]
    [  0   ]
    [  0   ]
    [  ... ]
    [  0   ]

and the vector x to another vector y of the form

    [ beta ]
    [  0   ]
    [  0   ]
    [  ... ]
    [  0   ]

such that norm(x) = norm(y).

The vector v is returned in the array X, and the scalar tau is returned in the argument TAU.

The element X(1) is overwritten by beta.

The elements of the array X are used to form the vector v.

Arguments:

Function Documentation

N

!>          N is INTEGER
!>          The order of the elementary reflector.
!>

ALPHA

!>          ALPHA is COMPLEX*16
!>          On entry, the value alpha.
!>          On exit, it is overwritten with the value beta.
!>

X

!>          X is COMPLEX*16 array, dimension
!>                         (1+(N-2)*abs(INCX))
!>          On entry, the vector x.
!>          On exit, it is overwritten with the vector v.
!>

INCX

!>          INCX is INTEGER
!>          The increment between elements of X. INCX > 0.
!>

TAU

!>          TAU is COMPLEX*16
!>          The value tau.
!>
