subrutina dlasd3 (integer nl, integer nr, integer sqre, integer k, double precision, dimension( * ) d, double precision, dimension( ldq, * ) q, integer ldq, double precision, dimension( * ) dsigma, double precision, dimension( ldu, * ) u, integer ldu, double precision, dimension( ldu2, * ) u2, integer ldu2, double precision, dimension( ldvt, * ) vt, integer ldvt, double precision, dimension( ldvt2, * ) vt2, integer ldvt2, integer, dimension( * ) idxc, integer, dimension( * ) ctot, double precision, dimension( * ) z, integer info)

DLASD3 encuentra todas las raíces cuadradas de las raíces de la ecuación secular, según lo definido por los valores en D y Z, y luego actualiza los vectores singulares mediante multiplicación matricial. Usado por sbdsdc.

Propósito:

!>
!> DLASD3 encuentra todas las raíces cuadradas de las raíces de la
!> ecuación secular, según lo definido por los valores en D y Z. Realiza
!> las llamadas apropiadas a DLASD4 y luego actualiza los vectores singulares
!> mediante multiplicación matricial.
!>
!> DLASD3 es llamado desde DLASD1.
!>

Parámetros

NL 
!>          NL es INTEGER
!>         La dimensión de fila del bloque superior. NL >= 1.
!>

NR

!>          NR es INTEGER
!>         La dimensión de fila del bloque inferior. NR >= 1.
!>

SQRE

!>          SQRE es INTEGER
!>         = 0: el bloque inferior es una matriz cuadrada NR-por-NR.
!>         = 1: el bloque inferior es una matriz rectangular NR-por-(NR+1).
!>
!>         La matriz bidiagonal tiene N = NL + NR + 1 filas y
!>         M = N + SQRE >= N columnas.
!>

K

!>          K es INTEGER
!>         El tamaño de la ecuación secular, 1 =< K = < N.
!>

D

!>          D es un array de DOUBLE PRECISION, de dimensión(K)
!>         A la salida, las raíces cuadradas de las raíces de la ecuación secular,
!>         en orden ascendente.
!>

Q

!>          Q es un array de DOUBLE PRECISION, de dimensión (LDQ,K)
!>

LDQ

!>          LDQ es INTEGER
!>         La dimensión principal del array Q. LDQ >= K.
!>

DSIGMA

!>          DSIGMA es un array de DOUBLE PRECISION, de dimensión(K)
!>         Los primeros K elementos de este array contienen las antiguas raíces
!>         del problema de actualización desdeflado. Estos son los polos
!>         de la ecuación secular.
!>

U

!>          U es un array de DOUBLE PRECISION, de dimensión (LDU, N)
!>         Las últimas N - K columnas de esta matriz contienen los vectores
!>         singulares izquierdos desdeflados.
!>

LDU

!>          LDU es INTEGER
!>         La dimensión principal del array U. LDU >= N.
!>

U2

!>          U2 es un array de DOUBLE PRECISION, de dimensión (LDU2, N)
!>         Las primeras K columnas de esta matriz contienen los vectores
!>         singulares izquierdos no desdeflados para el problema dividido.
!>

LDU2

!>          LDU2 es INTEGER
!>         La dimensión principal del array U2. LDU2 >= N.
!>

VT

!>          VT es un array de DOUBLE PRECISION, de dimensión (LDVT, M)
!>         Las últimas M - K columnas de VT**T contienen los vectores
!>         singulares derechos desdeflados.
!>

LDVT

!>          LDVT es INTEGER
!>         La dimensión principal del array VT. LDVT >= N.
!>

VT2

!>          VT2 es un array de DOUBLE PRECISION, de dimensión (LDVT2, N)
!>         Las primeras K columnas de VT2**T contienen los vectores
!>         singulares derechos no desdeflados para el problema dividido.
!>

LDVT2

!>          LDVT2 es INTEGER
!>         La dimensión principal del array VT2. LDVT2 >= N.
!>

IDXC

!>          IDXC es un array de INTEGER, de dimensión ( N )
!>         La permutación utilizada para organizar las columnas de U (y las filas de
!>         VT) en tres grupos: el primer grupo contiene entradas no nulas
!>         solo en o por encima (o antes) de NL +1; el segundo
!>         contiene entradas no nulas solo en o por debajo (o después) de NL+2;
!>         y el tercero es denso. La primera columna de U y la fila de
!>         VT se tratan por separado, sin embargo.
!>
!>         Las filas de los vectores singulares encontrados por DLASD4
!>         deben ser permutadas de manera similar antes de que las multiplicaciones
!>         matriciales puedan llevarse a cabo.
!>

CTOT

!>          CTOT es un array de INTEGER, de dimensión ( 4 )
!>         Un recuento del número total de los diversos tipos de columnas
!>         en U (o filas en VT), como se describe en IDXC. El cuarto tipo de columna
!>         es cualquier columna que haya sido desdeflada.
!>

Z

!>          Z es un array de DOUBLE PRECISION, de dimensión (K)
!>         Los primeros K elementos de este array contienen los componentes
!>         del vector de fila de actualización ajustado por desdeflación.
!>

INFO

!>          INFO es INTEGER
!>         = 0: salida exitosa.
!>         < 0: si INFO = -i, el i-ésimo argumento tuvo un valor ilegal.
!>         > 0: si INFO = 1, un valor singular no convergió
!>

NAME

lasd3

calcula las raíces cuadradas de las raíces de la ecuación secular y actualiza los vectores singulares

SYNOPSIS

SUBROUTINE SLASD3(NL, NR, SQRE, K, D, Q, LDQ, DSIGMA, U, LDU, U2, LDU2, VT, LDVT, VT2, LDVT2, IDXC, CTOT, Z, INFO)

  INTEGER NL, NR, SQRE, K, LDQ, LDU, LDU2, LDVT, LDVT2, INFO

  REAL D(K), Q(LDQ,K), DSIGMA(K), U(LDU, *), U2(LDU2, *), VT(LDVT, *), VT2(LDVT2, *), Z(K)

Detailed Description

SLASD3 encuentra todas las raíces cuadradas de las raíces de la ecuación secular, tal como se definen por los valores en D y Z, y luego actualiza los vectores singulares mediante multiplicación de matrices. Utilizado por sbdsdc.

Purpose:

!>
!> SLASD3 encuentra todas las raíces cuadradas de las raíces de la ecuación
!> secular, tal como se definen por los valores en D y Z. Realiza las
!> llamadas apropiadas a SLASD4 y luego actualiza los vectores singulares
!> mediante multiplicación de matrices.
!>
!> SLASD3 es llamado desde SLASD1.
!>

Function Documentation

SLASD3 finds all square roots of the roots of the secular equation, as defined by the values in D and Z, and then updates the singular vectors by matrix multiplication. Used by sbdsdc.

Purpose:

!>
!> SLASD3 finds all the square roots of the roots of the secular
!> equation, as defined by the values in D and Z.  It makes the
!> appropriate calls to SLASD4 and then updates the singular
!> vectors by matrix multiplication.
!>
!> SLASD3 is called from SLASD1.
!>

Parameters

NL 
!>          NL is INTEGER
!>         The row dimension of the upper block.  NL >= 1.
!>

NR

!>          NR is INTEGER
!>         The row dimension of the lower block.  NR >= 1.
!>

SQRE

!>          SQRE is INTEGER
!>         = 0: the lower block is an NR-by-NR square matrix.
!>         = 1: the lower block is an NR-by-(NR+1) rectangular matrix.
!>
!>         The bidiagonal matrix has N = NL + NR + 1 rows and
!>         M = N + SQRE >= N columns.
!>

K

!>          K is INTEGER
!>         The size of the secular equation, 1 =< K = < N.
!>

D

!>          D is REAL array, dimension(K)
!>         On exit the square roots of the roots of the secular equation,
!>         in ascending order.
!>

Q

!>          Q is REAL array, dimension (LDQ,K)
!>

LDQ

!>          LDQ is INTEGER
!>         The leading dimension of the array Q.  LDQ >= K.
!>

DSIGMA

!>          DSIGMA is REAL array, dimension(K)
!>         The first K elements of this array contain the old roots
!>         of the deflated updating problem.  These are the poles
!>         of the secular equation.
!>

U

!>          U is REAL array, dimension (LDU, N)
!>         The last N - K columns of this matrix contain the deflated
!>         left singular vectors.
!>

LDU

!>          LDU is INTEGER
!>         The leading dimension of the array U.  LDU >= N.
!>

U2

!>          U2 is REAL array, dimension (LDU2, N)
!>         The first K columns of this matrix contain the non-deflated
!>         left singular vectors for the split problem.
!>

LDU2

!>          LDU2 is INTEGER
!>         The leading dimension of the array U2.  LDU2 >= N.
!>

VT

!>          VT is REAL array, dimension (LDVT, M)
!>         The last M - K columns of VT**T contain the deflated
!>         right singular vectors.
!>

LDVT

!>          LDVT is INTEGER
!>         The leading dimension of the array VT.  LDVT >= N.
!>

VT2

!>          VT2 is REAL array, dimension (LDVT2, N)
!>         The first K columns of VT2**T contain the non-deflated
!>         right singular vectors for the split problem.
!>

LDVT2

!>          LDVT2 is INTEGER
!>         The leading dimension of the array VT2.  LDVT2 >= N.
!>

IDXC

!>          IDXC is INTEGER array, dimension (N)
!>         The permutation used to arrange the columns of U (and rows of
!>         VT) into three groups:  the first group contains non-zero
!>         entries only at and above (or before) NL +1; the second
!>         contains non-zero entries only at and below (or after) NL+2;
!>         and the third is dense. The first column of U and the row of
!>         VT are treated separately, however.
!>
!>         The rows of the singular vectors found by SLASD4
!>         must be likewise permuted before the matrix multiplies can
!>         take place.
!>

CTOT

!>          CTOT is INTEGER array, dimension (4)
!>         A count of the total number of the various types of columns
!>         in U (or rows in VT), as described in IDXC. The fourth column
!>         type is any column which has been deflated.
!>

Z

!>          Z is REAL array, dimension (K)
!>         The first K elements of this array contain the components
!>         of the deflation-adjusted updating row vector.
!>

INFO

!>          INFO is INTEGER
!>         = 0:  successful exit.
!>         < 0:  if INFO = -i, the i-th argument had an illegal value.
!>         > 0:  if INFO = 1, a singular value did not converge
!>
