label(n)

Paquete: tk

Licencias: TCL

label(n) Tk Built-In Commands label(n)

NOMBRE

label - Crea y manipula widgets de texto o imagen 'label' no interactivos

SINÓPSIS

label pathName ?options?

OPCIONES ESTÁNDAR

-activebackground	-disabledforeground	-padx
-activeforeground	-font	-pady
-anchor	-foreground	-relief
-background	-highlightbackground	-takefocus
-bitmap	-highlightcolor	-text
-borderwidth	-highlightthickness	-textvariable
-compound	-image	-underline
-cursor	-justify	-wraplength

Consulte la entrada del manual options para obtener más detalles sobre las opciones estándar.

OPCIONES ESPECÍFICAS DEL WIDGET

Nombre en línea de comandos:	-height
Nombre en base de datos:	height
Clase de base de datos:	Height
Especifica una altura deseada para la etiqueta. Si se está mostrando una imagen o bitmap en la etiqueta, el valor se mide en unidades de pantalla (es decir, en cualquiera de las formas aceptadas por Tk_GetPixels); para texto, se mide en líneas de texto. Si no se especifica esta opción, la altura deseada de la etiqueta se calcula a partir del tamaño de la imagen, bitmap o texto que se está mostrando en ella.
Nombre en línea de comandos:	-state
Nombre en base de datos:	state
Clase de base de datos:	State
Especifica uno de los tres estados para la etiqueta: normal, active o disabled. En el estado normal, el botón se muestra utilizando las opciones -foreground y -background. En el estado activo, la etiqueta se muestra utilizando las opciones -activeforeground y -activebackground. En el estado deshabilitado, las opciones -disabledforeground y -background determinan cómo se muestra el botón.
Nombre en línea de comandos:	-width
Nombre en base de datos:	width
Clase de base de datos:	Width
Especifica un ancho deseado para la etiqueta. Si se está mostrando una imagen o bitmap en la etiqueta, el valor se mide en unidades de pantalla (es decir, en cualquiera de las formas aceptadas por Tk_GetPixels); para texto, se mide en caracteres. Si no se especifica esta opción, el ancho deseado de la etiqueta se calcula a partir del tamaño de la imagen, bitmap o texto que se está mostrando en ella.

DESCRIPCIÓN

El comando label crea una nueva ventana (dada por el argumento pathName) y la convierte en un widget de etiqueta. Opciones adicionales, descritas anteriormente, pueden especificarse en la línea de comandos o en la base de datos de opciones para configurar aspectos de la etiqueta, como sus colores, fuente, texto y relieve inicial. El comando label devuelve su argumento pathName. En el momento en que se invoca este comando, no debe existir una ventana llamada pathName, pero el padre de pathName debe existir.

Una etiqueta es un widget que muestra una cadena de texto, un bitmap o una imagen. Si se muestra texto, todo debe estar en una sola fuente, pero puede ocupar varias líneas en la pantalla (si contiene saltos de línea o si ocurre un ajuste de línea debido a la opción -wraplength) y uno de los caracteres puede ser opcionalmente subrayado usando la opción -underline. La etiqueta se puede manipular de algunas maneras sencillas, como cambiar su relieve o texto, utilizando los comandos descritos a continuación.

COMANDO DEL WIDGET

El comando label crea un nuevo comando Tcl cuyo nombre es pathName. Este comando se puede usar para invocar varias operaciones en el widget. Tiene la siguiente forma general:

pathName option ?arg arg ...?
Option y los args determinan el comportamiento exacto del comando. Los siguientes comandos son posibles para los widgets de etiqueta:
pathName cget option
Devuelve el valor actual de la opción de configuración dada por option. Option puede tener cualquiera de los valores aceptados por el comando label.
pathName configure ?option? ?value option value ...?
Consulta o modifica las opciones de configuración del widget. Si no se especifica ningún option, devuelve una lista que describe todas las opciones disponibles para pathName (consulte Tk_ConfigureInfo para obtener información sobre el formato de esta lista). Si se especifica option sin value, el comando devuelve una lista que describe la opción nombrada (esta lista será idéntica a la sublista correspondiente del valor devuelto si no se especifica ninguna option). Si se especifican uno o más pares option-value, el comando modifica la(s) opción(es) del widget dada(s) para que tengan el(los) valor(es) dado(s); en este caso, el comando devuelve una cadena vacía. Option puede tener cualquiera de los valores aceptados por el comando label.

ENLACES

Cuando se crea una nueva etiqueta, no tiene enlaces de eventos predeterminados: las etiquetas no están diseñadas para ser interactivas.

EJEMPLO

# Crear los widgets
label .t -text "Este widget está arriba"    -bg red
label .b -text "Este widget está abajo" -bg green
label .l -text "Izquierda\nLado\nDerecho"
label .r -text "Derecha\nLado\nIzquierdo"
text .mid
.mid insert end "Este diseño es como el BorderLayout de Java"
# Colocarlos
pack .t   -side top    -fill x
pack .b   -side bottom -fill x
pack .l   -side left   -fill y
pack .r   -side right  -fill y
pack .mid -expand 1    -fill both
