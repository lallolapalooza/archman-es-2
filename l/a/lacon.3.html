subrutina clacon (entero n, complejo, dimensión( n ) v, complejo, dimensión( n ) x, real est, entero kase)

CLACON estima la norma 1 de una matriz cuadrada, usando comunicación inversa para evaluar productos matriz-vector.

Propósito

!>
!> CLACON estima la norma 1 de una matriz compleja cuadrada A.
!> Se utiliza comunicación inversa para evaluar productos matriz-vector.
!>

Parámetros

N 
!>          N es ENTERO
!>         El orden de la matriz.  N >= 1.
!>

V

!>          V es un array COMPLEJO, dimensión (N)
!>         En la retorno final, V = A*W, donde EST = norm(V)/norm(W)
!>         (W no se retorna).
!>

X

!>          X es un array COMPLEJO, dimensión (N)
!>         En un retorno intermedio, X debe ser sobrescrito por
!>               A * X,   si KASE=1,
!>               A**H * X,  si KASE=2,
!>         donde A**H es la transpuesta conjugada de A, y CLACON debe ser
!>         llamada de nuevo con todos los otros parámetros sin cambios.
!>

EST

!>          EST es REAL
!>         En la entrada con KASE = 1 o 2 y JUMP = 3, EST debe ser
!>         sin cambios desde la llamada anterior a CLACON.
!>         En la salida, EST es una estimación (un límite inferior) para norm(A).
!>

KASE

!>          KASE es ENTERO
!>         En la llamada inicial a CLACON, KASE debe ser 0.
!>         En un retorno intermedio, KASE será 1 o 2, indicando
!>         si X debe ser sobrescrito por A * X  o A**H * X.
!>         En el retorno final desde CLACON, KASE volverá a ser 0.
!>

lacon(3) - LAPACK

NAME

lacon, slacon, dlacon, clacon, zlacon

estimate the norm of a matrix using reverse communication

SYNOPSIS

     SUBROUTINE LACON( N, V, X, EST, KASE )
         INTEGER          N
         REAL             V( * )
         REAL             X( * )
         REAL             EST
         INTEGER          KASE

     SUBROUTINE SLACON( N, V, X, EST, KASE )
         INTEGER          N
         REAL             V( * )
         REAL             X( * )
         REAL             EST
         INTEGER          KASE

     SUBROUTINE DLACON( N, V, X, EST, KASE )
         INTEGER          N
         DOUBLE PRECISION V( * )
         DOUBLE PRECISION X( * )
         DOUBLE PRECISION EST
         INTEGER          KASE

     SUBROUTINE CLACON( N, V, X, EST, KASE )
         INTEGER          N
         COMPLEX          V( * )
         COMPLEX          X( * )
         REAL             EST
         INTEGER          KASE

     SUBROUTINE ZLACON( N, V, X, EST, KASE )
         INTEGER          N
         COMPLEX*16       V( * )
         COMPLEX*16       X( * )
         DOUBLE PRECISION EST
         INTEGER          KASE

Detailed Description

LACON estimates the 1-norm of a square matrix A using reverse communication for evaluating matrix-vector products. This is a recursive version of the algorithm. The function is called with KASE = 0 initially. The function then returns with KASE = 1 or KASE = 2, and the matrix-vector product X = A*X or X = A**H*X is computed (where A**H is the conjugate transpose of A). The function is then called again with the updated X and the same value of KASE. This process is repeated until the function returns with KASE = 0, at which point the estimate EST is returned.

Function Documentation

subroutine clacon (integer n, complex, dimension( n ) v, complex, dimension( n ) x, real est, integer kase)

CLACON estimates the 1-norm of a complex matrix, using reverse communication for evaluating matrix-vector products.

Purpose:

!>
!> CLACON estimates the 1-norm of a square, complex matrix A.
!> Reverse communication is used for evaluating matrix-vector products.
!>

Parameters

N 
!>          N is INTEGER
!>         The order of the matrix.  N >= 1.
!>

V

!>          V is COMPLEX array, dimension (N)
!>         On the final return, V = A*W,  where  EST = norm(V)/norm(W)
!>         (W is not returned).
!>

X

!>          X is COMPLEX array, dimension (N)
!>         On an intermediate return, X should be overwritten by
!>               A * X,   if KASE=1,
!>               A**H * X,  if KASE=2,
!>         where A**H is the conjugate transpose of A, and CLACON must be
!>         re-called with all the other parameters unchanged.
!>

EST

!>          EST is REAL
!>         On entry with KASE = 1 or 2 and JUMP = 3, EST should be
!>         unchanged from the previous call to CLACON.
!>         On exit, EST is an estimate (a lower bound) for norm(A).
!>

KASE

!>          KASE is INTEGER
!>         On the initial call to CLACON, KASE should be 0.
!>         On an intermediate return, KASE will be 1 or 2, indicating
!>         whether X should be overwritten by A * X  or A**H * X.
!>         On the final return from CLACON, KASE will again be 0.
!>
