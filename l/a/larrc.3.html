subrutina dlarrc (character jobt, integer n, double precision vl, double precision vu, double precision, dimension( * ) d, double precision, dimension( * ) e, double precision pivmin, integer eigcnt, integer lcnt, integer rcnt, integer info)

DLARRC calcula el número de eigenvalores de la matriz tridiagonal simétrica.

Propósito:

!>
!> Encuentra el número de eigenvalores de la matriz tridiagonal simétrica T
!> que están en el intervalo (VL,VU] si JOBT = 'T', y de L D L^T
!> si JOBT = 'L'.
!>

Parámetros

JOBT 
!>          JOBT es CHARACTER*1
!>          = 'T':  Calcula el conteo de Sturm para la matriz T.
!>          = 'L':  Calcula el conteo de Sturm para la matriz L D L^T.
!>

N

!>          N es INTEGER
!>          El orden de la matriz. N > 0.
!>

VL

!>          VL es DOUBLE PRECISION
!>          El límite inferior para los eigenvalores.
!>

VU

!>          VU es DOUBLE PRECISION
!>          El límite superior para los eigenvalores.
!>

D

!>          D es un array de DOUBLE PRECISION, dimensión (N)
!>          JOBT = 'T': Los N elementos diagonales de la matriz tridiagonal T.
!>          JOBT = 'L': Los N elementos diagonales de la matriz diagonal D.
!>

E

!>          E es un array de DOUBLE PRECISION, dimensión (N)
!>          JOBT = 'T': Los N-1 elementos fuera de la diagonal de la matriz T.
!>          JOBT = 'L': Los N-1 elementos fuera de la diagonal de la matriz L.
!>

PIVMIN

!>          PIVMIN es DOUBLE PRECISION
!>          El pivote mínimo en la secuencia de Sturm para T.
!>

EIGCNT

!>          EIGCNT es INTEGER
!>          El número de eigenvalores de la matriz tridiagonal simétrica T
!>          que están en el intervalo (VL,VU]
!>

LCNT

!>          LCNT es INTEGER
!>

RCNT

!>          RCNT es INTEGER
!>          Los conteos negativos izquierdo y derecho del intervalo.
!>

INFO

!>          INFO es INTEGER
!>
