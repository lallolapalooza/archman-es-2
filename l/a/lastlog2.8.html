LASTLOG2(8) Comandos de usuario LASTLOG2(8)

NOMBRE

lastlog2 - muestra la fecha del último inicio de sesión de todos los usuarios o de uno específico

SINOPSIS

lastlog2 [opciones]

DESCRIPCIÓN

lastlog2 muestra el contenido de la base de datos del último inicio de sesión. Se imprimirán el *nombre de usuario*, *hora del último inicio de sesión*, *tty* y *host remoto*. El comportamiento por defecto (sin indicadores) hace que se impriman todas las entradas del último inicio de sesión, ordenadas según el orden en que se escribieron por primera vez en la base de datos.

En comparación con lastlog, este comando es seguro para el año 2038 y utiliza sqlite3 para almacenar la información, en lugar de un archivo disperso.

OPCIONES

-a, --activo

Imprime los registros del último inicio de sesión, excluyendo a los usuarios que nunca han iniciado sesión.

-b, --antes DÍAS

Imprime solo los registros del último inicio de sesión anteriores a DÍAS.

-C, --limpiar

Borra el registro del último inicio de sesión de un usuario. Esta opción solo se puede usar junto con -u (*--usuario*).

-d, *--base-de-datos ARCHIVO

Utiliza ARCHIVO como base de datos de lastlog2.

-h, --ayuda

Muestra el mensaje de ayuda y sale.

-i, --importar ARCHIVO

Importa datos del archivo antiguo lastlog ARCHIVO. Las entradas existentes en la base de datos de lastlog2 se sobrescribirán.

-r, --renombrar NUEVONOMBRE

Esta opción solo se puede usar junto con -u (--usuario).

-s, --servicio num

Muestra el servicio PAM utilizado para iniciar sesión en la última columna.

-S, --establecer

Establece el registro del último inicio de sesión de un usuario a la hora actual. Esta opción solo se puede usar junto con -u (--usuario).

-t, --tiempo DÍAS

Imprime solo los registros del último inicio de sesión más recientes que DÍAS.

-u, --usuarios USUARIOS

Imprime solo el registro del último inicio de sesión del usuario USUARIO.

-v, --versión

Muestra el número de versión y sale.

Si el usuario nunca ha iniciado sesión, se mostrará el mensaje Nunca inició sesión en la fila de la última hora de inicio de sesión.

Solo se mostrarán las entradas de los usuarios actuales del sistema. Otras entradas pueden existir para usuarios que fueron eliminados previamente.

ARCHIVOS

/var/lib/lastlog/lastlog2.db

Archivo de base de datos de registro de lastlog2
