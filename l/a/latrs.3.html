subrutina clatrs (character uplo, character trans, character diag, character normin, integer n, complex, dimension( lda, * ) a, integer lda, complex, dimension( * ) x, real scale, real, dimension( * ) cnorm, integer info)

CLATRS resuelve un sistema triangular de ecuaciones con el factor de escala establecido para evitar el desbordamiento.

Propósito:

!>
!> CLATRS resuelve uno de los sistemas triangulares
!>
!>    A * x = s*b,  A**T * x = s*b,  o  A**H * x = s*b,
!>
!> con escalado para prevenir el desbordamiento. Aquí A es una matriz triangular superior o inferior, A**T denota la transpuesta de A, A**H denota la transpuesta conjugada de A, x y b son vectores de n elementos, y s es un factor de escala, usualmente menor o igual a 1, elegido para que los componentes de x sean menores que el umbral de desbordamiento. Si el problema no escalado no causa desbordamiento, se llama a la rutina BLAS de Nivel 2 CTRSV. Si la matriz A es singular (A(j,j) = 0 para algún j), entonces s se establece en 0 y se devuelve una solución no trivial para A*x = 0.
!>

Parámetros

UPLO 
!>          UPLO es CHARACTER*1
!>          Especifica si la matriz A es triangular superior o inferior.
!>          = 'U':  Triangular superior
!>          = 'L':  Triangular inferior
!>

TRANS

!>          TRANS es CHARACTER*1
!>          Especifica la operación aplicada a A.
!>          = 'N':  Resolver A * x = s*b     (Sin transpuesta)
!>          = 'T':  Resolver A**T * x = s*b  (Transpuesta)
!>          = 'C':  Resolver A**H * x = s*b  (Transpuesta conjugada)
!>

DIAG

!>          DIAG es CHARACTER*1
!>          Especifica si la matriz A es unitaria triangular o no.
!>          = 'N':  No unitaria triangular
!>          = 'U':  Unitaria triangular
!>

NORMIN

!>          NORMIN es CHARACTER*1
!>          Especifica si CNORM ha sido establecido o no.
!>          = 'Y':  CNORM contiene las normas de columna en la entrada
!>          = 'N':  CNORM no está establecido en la entrada. A la salida, las normas se calcularán y se almacenarán en CNORM.
!>

N

!>          N es INTEGER
!>          El orden de la matriz A.  N >= 0.
!>

A

!>          A es un array COMPLEX, de dimensión (LDA,N)
!>          La matriz triangular A.  Si UPLO = 'U', la parte triangular superior superior de n por n de la matriz A contiene la matriz triangular superior, y la parte triangular estrictamente inferior de A no se referencia. Si UPLO = 'L', la parte triangular inferior superior de n por n de la matriz A contiene la matriz triangular inferior, y la parte triangular estrictamente superior de A no se referencia. Si DIAG = 'U', los elementos diagonales de A tampoco se referencian y se asumen que son 1.
!>

LDA

!>          LDA es INTEGER
!>          La dimensión principal del array A.  LDA >= max (1,N).
!>

X

!>          X es un array COMPLEX, de dimensión (N)
!>          En la entrada, el lado derecho b del sistema triangular.
!>          A la salida, X se sobrescribe con el vector solución x.
!>

SCALE

!>          SCALE es REAL
!>          El factor de escala s para el sistema triangular
!>             A * x = s*b,  A**T * x = s*b,  o  A**H * x = s*b.
!>          Si SCALE = 0, la matriz A es singular o mal escalada, y
!>          el vector x es una solución exacta o aproximada a A*x = 0.
!>

CNORM

!>          CNORM es un array REAL, de dimensión (N)
!>
!>          Si NORMIN = 'Y', CNORM es un argumento de entrada y CNORM(j)
!>          contiene la norma de la parte no diagonal de la j-ésima columna
!>          de A.  Si TRANS = 'N', CNORM(j) debe ser mayor o igual
!>          a la norma infinito, y si TRANS = 'T' o 'C', CNORM(j)
!>          debe ser mayor o igual a la norma 1.
!>
!>          Si NORMIN = 'N', CNORM es un argumento de salida y CNORM(j)
!>          devuelve la norma 1 de la parte no diagonal de la j-ésima columna
!>          de A.
!>

INFO

!>          INFO es INTEGER
!>          = 0:  salida exitosa
!>          < 0:  si INFO = -k, el k-ésimo argumento tenía un valor ilegal
!>

Detalles Adicionales:

!>
!> Se calcula un límite aproximado para x; si este es menor que el desbordamiento, se llama a CTRSV, de lo contrario, se utiliza código específico que verifica posibles desbordamientos o divisiones por cero en cada operación.
!>
!> Se utiliza un esquema columna por columna para resolver A*x = b. El algoritmo básico si A es triangular inferior es
!>
!>       x[1:n] := b[1:n]
!>       para j = 1, ..., n
!>            x(j) := x(j) / A(j,j)
!>            x[j+1:n] := x[j+1:n] - x(j) * A[j+1:n,j]
!>       fin
!>
!> Se definen límites para los componentes de x después de j iteraciones del bucle:
!>     M(j) = límite para x[1:j]
!>     G(j) = límite para x[j+1:n]
!> Inicialmente, sea M(0) = 0 y G(0) = max{x(i), i=1,...,n}.
!>
!> Luego, para la iteración j+1, tenemos
!>     M(j+1) <= G(j) / | A(j+1,j+1) |
!>     G(j+1) <= G(j) + M(j+1) * | A[j+2:n,j+1] |
!>            <= G(j) ( 1 + CNORM(j+1) / | A(j+1,j+1) | )
!>
!> donde CNORM(j+1) es mayor o igual a la norma infinito de la
!> columna j+1 de A, sin contar la diagonal. Por lo tanto
!>
!>     G(j) <= G(0) producto ( 1 + CNORM(i) / | A(i,i) | )
!>                  1<=i<=j
!> y
!>
!>     |x(j)| <= ( G(0) / |A(j,j)| ) producto ( 1 + CNORM(i) / |A(i,i)| )
!>                                   1<=i< j
!>
!> Dado que |x(j)| <= M(j), utilizamos la rutina BLAS de Nivel 2 CTRSV si el
!> recíproco del M(j) más grande, j=1,..,n, es mayor que
!> max(desbordamiento bajo, 1/desbordamiento).
!>
!> El límite de x(j) también se utiliza para determinar cuándo se puede realizar un paso en el
!> método columna por columna sin temor a desbordamiento. Si
!> el límite calculado es mayor que una constante grande, x se escala para
!> prevenir el desbordamiento, pero si el límite desborda, x se establece en 0, x(j) en
!> 1, y scale en 0, y se encuentra una solución no trivial para A*x = 0.
!>
!> De manera similar, se utiliza un esquema fila por fila para resolver A**T *x = b o
!> A**H *x = b. El algoritmo básico para A triangular superior es
!>
!>       para j = 1, ..., n
!>            x(j) := ( b(j) - A[1:j-1,j]' * x[1:j-1] ) / A(j,j)
!>       fin
!>
!> Calculamos simultáneamente dos límites
!>       G(j) = límite para ( b(i) - A[1:i-1,i]' * x[1:i-1] ), 1<=i<=j
!>       M(j) = límite para x(i), 1<=i<=j
!>
!> Los valores iniciales son G(0) = 0, M(0) = max{b(i), i=1,..,n}, y añadimos la
!> restricción G(j) >= G(j-1) y M(j) >= M(j-1) para j >= 1.
!> Entonces, el límite de x(j) es
!>
!>       M(j) <= M(j-1) * ( 1 + CNORM(j) ) / | A(j,j) |
!>
!>            <= M(0) * producto ( ( 1 + CNORM(i) ) / |A(i,i)| )
!>                      1<=i<=j
!>
!> y podemos llamar de forma segura a CTRSV si 1/M(n) y 1/G(n) son ambos mayores

Further Details:

!>
!>  A rough bound on x is computed; if that is less than overflow, STRSV
!>  is called, otherwise, specific code is used which checks for possible
!>  overflow or divide-by-zero at every operation.
!>
!>  A columnwise scheme is used for solving A*x = b.  The basic algorithm
!>  if A is lower triangular is
!>
!>       x[1:n] := b[1:n]
!>       for j = 1, ..., n
!>            x(j) := x(j) / A(j,j)
!>            x[j+1:n] := x[j+1:n] - x(j) * A[j+1:n,j]
!>       end
!>
!>  Define bounds on the components of x after j iterations of the loop:
!>     M(j) = bound on x[1:j]
!>     G(j) = bound on x[j+1:n]
!>  Initially, let M(0) = 0 and G(0) = max{x(i), i=1,...,n}.
!>
!>  Then for iteration j+1 we have
!>     M(j+1) <= G(j) / | A(j+1,j+1) |
!>     G(j+1) <= G(j) + M(j+1) * | A[j+2:n,j+1] |
!>            <= G(j) ( 1 + CNORM(j+1) / | A(j+1,j+1) | )
!>
!>  where CNORM(j+1) is greater than or equal to the infinity-norm of
!>  column j+1 of A, not counting the diagonal.  Hence
!>
!>     G(j) <= G(0) product ( 1 + CNORM(i) / | A(i,i) | )
!>                  1<=i<=j
!>  and
!>
!>     |x(j)| <= ( G(0) / |A(j,j)| ) product ( 1 + CNORM(i) / |A(i,i)| )
!>                                   1<=i< j
!>
!>  Since |x(j)| <= M(j), we use the Level 2 BLAS routine STRSV if the
!>  reciprocal of the largest M(j), j=1,..,n, is larger than
!>  max(underflow, 1/overflow).
!>
!>  The bound on x(j) is also used to determine when a step in the
!>  columnwise method can be performed without fear of overflow.  If
!>  the computed bound is greater than a large constant, x is scaled to
!>  prevent overflow, but if the bound overflows, x is set to 0, x(j) to
!>  1, and scale to 0, and a non-trivial solution to A*x = 0 is found.
!>
!>  Similarly, a row-wise scheme is used to solve A**T*x = b.  The basic
!>  algorithm for A upper triangular is
!>
!>       for j = 1, ..., n
!>            x(j) := ( b(j) - A[1:j-1,j]**T * x[1:j-1] ) / A(j,j)
!>       end
!>
!>  We simultaneously compute two bounds
!>       G(j) = bound on ( b(i) - A[1:i-1,i]**T * x[1:i-1] ), 1<=i<=j
!>       M(j) = bound on x(i), 1<=i<=j
!>
!>  The initial values are G(0) = 0, M(0) = max{b(i), i=1,..,n}, and we
!>  add the constraint G(j) >= G(j-1) and M(j) >= M(j-1) for j >= 1.
!>  Then the bound on x(j) is
!>
!>       M(j) <= M(j-1) * ( 1 + CNORM(j) ) / | A(j,j) |
!>
!>            <= M(0) * product ( ( 1 + CNORM(i) ) / |A(i,i)| )
!>                      1<=i<=j
!>
!>  and we can safely call STRSV if 1/M(n) and 1/G(n) are both greater
!>  than max(underflow, 1/overflow).
!>

subroutine xlatrs (character uplo, character trans, character diag, character normin, integer n, complex, dimension( lda, * ) a, integer lda, complex, dimension( * ) x, real scale, real, dimension( * ) cnorm, integer info)

XLATRS solves a triangular system of equations with the scale factor set to prevent overflow.

Purpose:

!>
!> XLATRS solves one of the triangular systems
!>
!>    A *x = s*b  or  A**H*x = s*b
!>
!> with scaling to prevent overflow.  Here A is an upper or lower
!> triangular matrix, A**H denotes the conjugate transpose of A, x and b are
!> n-element vectors, and s is a scaling factor, usually less than
!> or equal to 1, chosen so that the components of x will be less than
!> the overflow threshold.  If the unscaled problem will not cause
!> overflow, the Level 2 BLAS routine CTRSV is called.  If the matrix A
!> is singular (A(j,j) = 0 for some j), then s is set to 0 and a
!> non-trivial solution to A*x = 0 is returned.
!>

Parameters

UPLO 
!>          UPLO is CHARACTER*1
!>          Specifies whether the matrix A is upper or lower triangular.
!>          = 'U':  Upper triangular
!>          = 'L':  Lower triangular
!>

TRANS

!>          TRANS is CHARACTER*1
!>          Specifies the operation applied to A.
!>          = 'N':  Solve A * x = s*b  (No transpose)
!>          = 'T':  Solve A**T* x = s*b  (Transpose)
!>          = 'C':  Solve A**H* x = s*b  (Conjugate transpose)
!>

DIAG

!>          DIAG is CHARACTER*1
!>          Specifies whether or not the matrix A is unit triangular.
!>          = 'N':  Non-unit triangular
!>          = 'U':  Unit triangular
!>

NORMIN

!>          NORMIN is CHARACTER*1
!>          Specifies whether CNORM has been set or not.
!>          = 'Y':  CNORM contains the column norms on entry
!>          = 'N':  CNORM is not set on entry.  On exit, the norms will
!>                  be computed and stored in CNORM.
!>

N

!>          N is INTEGER
!>          The order of the matrix A.  N >= 0.
!>

A

!>          A is COMPLEX array, dimension (LDA,N)
!>          The triangular matrix A.  If UPLO = 'U', the leading n by n
!>          upper triangular part of the array A contains the upper
!>          triangular matrix, and the strictly lower triangular part of
!>          A is not referenced.  If UPLO = 'L', the leading n by n lower
!>          triangular part of the array A contains the lower triangular
!>          matrix, and the strictly upper triangular part of A is not

LDA

NAME

latrs - latrs

SYNOPSIS

Subroutine latrs( UPLO, TRANS, DIAG, NORMIN, N, A, LDA, X, LDX, SCALE, CNORM, WORK, INFO )

Detailed Description

  Purpose
  =======
  LATRS solves one of the linear systems

     A*x = b,   A**T*x = b,   or   A**H*x = b

  with a triangular matrix A, and optionally triangular solves with the
  transpose or conjugate transpose of A.

  In the matrix-rank determination, LATRS is a subroutine that solves a
  triangular system of linear equations.
  The implementation is based on the observation that the forward
  elimination and back substitution steps in solving a triangular system
  can be viewed as a sequence of matrix-vector multiplications and vector
  additions.
  This allows for the computation of bounds on the solution vector x,
  which can be used to determine if a scaling factor is needed to prevent
  overflow or underflow.

  Arguments
  =========
  UPLO    (input) CHARACTER*1
          Specifies whether the matrix A is upper or lower triangular.
          = 'U': A is upper triangular
          = 'L': A is lower triangular

  TRANS   (input) CHARACTER*1
          Specifies the form of the system of equations:
          = 'N': A*x = b (No transpose)
          = 'T': A**T*x = b (Transpose)
          = 'C': A**H*x = b (Conjugate transpose)

  DIAG    (input) CHARACTER*1
          Specifies whether or not the matrix A is strictly diagonal:
          = 'N': Diagonal elements are not necessarily 1.
          = 'U': Diagonal elements are all 1. (unit triangular)

  NORMIN  (input) CHARACTER*1
          Specifies whether or not the solution vector X contains
          normalization information.
          = 'N': The vector X contains normalization information.
          = 'S': The vector X does not contain normalization
                 information.

  N       (input) INTEGER
          The order of the upper or lower triangular matrix A. N >= 0.

  A       (input) DOUBLE PRECISION array, dimension (LDA,N)
          On entry with NORMIN = 'N', the coefficient matrix A.
          If UPLO = 'U', A is upper triangular.
          If UPLO = 'L', A is lower triangular.
          If DIAG = 'U', the diagonal elements of A are assumed to be 1.

  LDA     (input) INTEGER
          The leading dimension of the array A. LDA >= max(1,N).

  X       (input/output) DOUBLE PRECISION array, dimension (LDX,N)
          On entry with NORMIN = 'N', the right hand side vector b.
          On exit, the solution vector x.
          If NORMIN = 'S', X does not contain normalization
          information, and the subroutine computes the solution
          vector X.
          If NORMIN = 'N', X contains normalization information,
          and the subroutine scales X to prevent overflow or
          underflow.

  LDX     (input) INTEGER
          The leading dimension of the array X. LDX >= max(1,N).

  SCALE   (output) DOUBLE PRECISION
          On exit with NORMIN = 'N', SCALE is an output scalar such
          that the matrix `S*A' where `S' is the diagonal matrix
          with SCALE on the diagonal. The scaled solution is
          `S*x`, where `x` is the output solution vector X.
          SCALE is output only if NORMIN = 'N'.

  CNORM   (input) DOUBLE PRECISION array, dimension (N)
          On entry with NORMIN = 'N', CNORM contains the approximately
          estimated norms of each column of A.

  WORK    (workspace) DOUBLE PRECISION array, dimension (N)
          Workspace array.

  INFO    (output) INTEGER
          = 0: successful exit
          < 0: if INFO = -k, the k-th argument had an illegal value

  =====================================================================
  This routine is called by the routines ZGSVX, ZTRSV, ZTRSY, ZTRRI, etc.
  to solve a triangular system of equations.

  The matrix-rank determination is based on the condition number estimation
  of the matrix A. The condition number of a matrix A is defined as
  cond(A) = ||A|| * ||A**-1||.

  The routine LATRS computes an estimate of the condition number of A
  by using the forward elimination and back substitution steps.
  The algorithm used is described in the LAPACK User's Guide.

  The implementation uses two vectors, X and WORK, to compute the
  solution vector and the condition number estimate.
  The vector X is used to store the solution vector, and the vector WORK
  is used to store intermediate results.

  The routine checks for potential overflow and underflow during the
  computation and scales the matrix A if necessary.

  The following is a high-level description of the algorithm:

  1. If NORMIN = 'S', then the routine solves the triangular system
     A*x = b directly.

  2. If NORMIN = 'N', then the routine estimates the condition number
     of A and scales the matrix A if necessary to prevent overflow or
     underflow.

  The core idea is to compute bounds on the solution vector x and on the
  intermediate quantities computed during the forward elimination and
  back substitution.

  For a columnwise method to solve A*x = b where A is upper triangular:
  x(j) = ( b(j) - A[1:j-1,j]' * x[1:j-1] ) / A(j,j)

  The routine computes two bounds:
  - M(j): A bound on the magnitude of x(k) for k = 1, ..., j.
  - G(j): A bound on the magnitude of the term ( b(k) - A[1:k-1,k]' * x[1:k-1] )
          for k = 1, ..., j.

  The initial values are:
  M(0) = max |b(k)| for k = 1, ..., n
  G(0) = 0

  Then, for j = 1, ..., n:
  The bound on x(j) is given by:
  M(j) = max( M(j-1), | b(j) - A[1:j-1,j]' * x[1:j-1] | / | A(j,j) | )
       = max( M(j-1), G(j) / | A(j,j) | )

  The bound G(j) is computed using the previous bound G(j-1) and the
  term A[1:j-1,j]' * x[1:j-1]:
  G(j) = max( G(j-1), | A[1:j-1,j]' * x[1:j-1] | )

  The term A[1:j-1,j]' * x[1:j-1] can be bounded by:
  | A[1:j-1,j]' * x[1:j-1] | <= CNORM(j) * M(j-1)

  So, the bound on x(j) becomes:
  M(j) <= max( M(j-1), ( G(j-1) + CNORM(j) * M(j-1) ) / | A(j,j) | )

  The routine checks if the computed bound M(n) is too large. If
  1/M(n) is smaller than max(underflow, 1/overflow), then the matrix A
  is scaled to prevent overflow.

  The bound on x(j) is also used to determine when a step in the
  columnwise method can be performed without fear of overflow. If
  the computed bound is greater than a large constant, x is scaled to
  prevent overflow, but if the bound overflows, x is set to 0, x(j) to
  1, and scale to 0, and a non-trivial solution to A*x = 0 is found.

  Similarly, a row-wise scheme is used to solve A**T *x = b  or
  A**H *x = b.  The basic algorithm for A upper triangular is

       for j = 1, ..., n
            x(j) := ( b(j) - A[1:j-1,j]' * x[1:j-1] ) / A(j,j)
       end

  We simultaneously compute two bounds
       G(j) = bound on ( b(i) - A[1:i-1,i]' * x[1:i-1] ), 1<=i<=j
       M(j) = bound on x(i), 1<=i<=j

  The initial values are G(0) = 0, M(0) = max{b(i), i=1,..,n}, and we
  add the constraint G(j) >= G(j-1) and M(j) >= M(j-1) for j >= 1.
  Then the bound on x(j) is

       M(j) <= M(j-1) * ( 1 + CNORM(j) ) / | A(j,j) |

            <= M(0) * product ( ( 1 + CNORM(i) ) / |A(i,i)| )
                      1<=i<=j

  and we can safely call ZTRSV if 1/M(n) and 1/G(n) are both greater
  than max(underflow, 1/overflow).
