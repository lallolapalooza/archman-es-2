DESCRIPCIÓN DETALLADA

DOCUMENTACIÓN DE LA FUNCIÓN

subrutina clapll (integer n, complex, dimension( * ) x, integer incx, complex, dimension( * ) y, integer incy, real ssmin)

CLAPLL mide la dependencia lineal de dos vectores.

Propósito:

!>
!> Dados dos vectores columna X e Y, sea
!>
!>                      A = ( X Y ).
!>
!> La subrutina primero calcula la factorización QR de A = Q*R,
!> y luego calcula la SVD de la matriz triangular superior de 2x2 R.
!> El valor singular más pequeño de R se devuelve en SSMIN, que se utiliza
!> como medida de la dependencia lineal de los vectores X e Y.
!>

Parámetros

N 
!>          N es un ENTERO
!>          La longitud de los vectores X e Y.
!>

X

!>          X es un array COMPLEJO, dimensión (1+(N-1)*INCX)
!>          A la entrada, X contiene el vector N X.
!>          A la salida, X se sobrescribe.
!>

INCX

!>          INCX es un ENTERO
!>          El incremento entre elementos sucesivos de X. INCX > 0.
!>

Y

!>          Y es un array COMPLEJO, dimensión (1+(N-1)*INCY)
!>          A la entrada, Y contiene el vector N Y.
!>          A la salida, Y se sobrescribe.
!>

INCY

!>          INCY es un ENTERO
!>          El incremento entre elementos sucesivos de Y. INCY > 0.
!>

SSMIN

!>          SSMIN es REAL
!>          El valor singular más pequeño de la matriz N x 2 A = ( X Y ).
!>

lapll(3) - LAPACK

NAME

lapll - <no description>

SYNOPSIS

  SUBROUTINE ZLAPLL( N, X, INCX, Y, INCY, S )

Parameters:

N

N is INTEGER The number of elements in the vectors X and Y.

X

X is COMPLEX*16 array, dimension (1+(N-1)*INCX) On entry, the vector X.

INCX

INCX is INTEGER The increment between successive elements of X. INCX > 0.

Y

Y is COMPLEX*16 array, dimension (1+(N-1)*INCY) On entry, the vector Y.

INCY

INCY is INTEGER The increment between successive elements of Y. INCY > 0.

S

S is DOUBLE PRECISION On exit, the smallest singular value of the N-by-2 matrix A = ( X Y ).

Detailed Description

This subroutine computes the smallest singular value of the N-by-2 matrix A = ( X Y ).

Arguments:

N INTEGER The number of elements in the vectors X and Y.

X COMPLEX*16 array, dimension (1+(N-1)*INCX) On entry, the vector X.

INCX INTEGER The increment between successive elements of X. INCX > 0.

Y COMPLEX*16 array, dimension (1+(N-1)*INCY) On entry, the vector Y.

INCY INTEGER The increment between successive elements of Y. INCY > 0.

SSMIN DOUBLE PRECISION The smallest singular value of the N-by-2 matrix A = ( X Y ).

Function Documentation

SUBROUTINE ZLAPLL( N, X, INCX, Y, INCY, S )

N is INTEGER.
The number of elements in the vectors X and Y.

X is COMPLEX*16 array, dimension (1+(N-1)*INCX).
On entry, the vector X.

INCX is INTEGER.
The increment between successive elements of X. INCX > 0.

Y is COMPLEX*16 array, dimension (1+(N-1)*INCY).
On entry, the vector Y.

The increment between successive elements of Y. INCY > 0.

SSMIN is DOUBLE PRECISION.
The smallest singular value of the N-by-2 matrix A = ( X Y ).
