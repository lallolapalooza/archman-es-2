subrutina clartg (complex(wp) f, complex(wp) g, real(wp) c, complex(wp) s, complex(wp) r)

CLARTG genera una rotación de plano con coseno real y seno complejo.

Propósito

!>
!> CLARTG genera una rotación de plano tal que
!>
!>    [  C         S  ] . [ F ]  =  [ R ]
!>    [ -conjg(S)  C  ]   [ G ]     [ 0 ]
!>
!> donde C es real y C**2 + |S|**2 = 1.
!>
!> Las fórmulas matemáticas usadas para C y S son
!>
!>    sgn(x) = {  x / |x|,   x != 0
!>             {  1,         x  = 0
!>
!>    R = sgn(F) * sqrt(|F|**2 + |G|**2)
!>
!>    C = |F| / sqrt(|F|**2 + |G|**2)
!>
!>    S = sgn(F) * conjg(G) / sqrt(|F|**2 + |G|**2)
!>
!> Condiciones especiales:
!>    Si G=0, entonces C=1 y S=0.
!>    Si F=0, entonces C=0 y S se elige de tal manera que R sea real.
!>
!> Cuando F y G son reales, las fórmulas se simplifican a C = F/R y
!> S = G/R, y los valores devueltos de C, S y R deben ser
!> idénticos a los devueltos por SLARTG.
!>
!> El algoritmo utilizado para calcular estas cantidades incorpora escalado
!> para evitar desbordamiento o desbordamiento en el cálculo de la raíz
!> cuadrada de la suma de cuadrados.
!>
!> Esta es la misma subrutina CROTG de BLAS1, excepto que
!> F y G no se modifican al regresar.
!>
!> Abajo, wp=>sp representa precisión simple del módulo LA_CONSTANTS.
!>

Parámetros

F 
!>          F es COMPLEX(wp)
!>          El primer componente del vector a rotar.
!>

G

!>          G es COMPLEX(wp)
!>          El segundo componente del vector a rotar.
!>

C

!>          C es REAL(wp)
!>          El coseno de la rotación.
!>

S

!>          S es COMPLEX(wp)
!>          El seno de la rotación.
!>

R

!>          R es COMPLEX(wp)
!>          El componente distinto de cero del vector rotado.
!>

subrutina dlartg (real(wp) f, real(wp) g, real(wp) c, real(wp) s, real(wp) r)

DLARTG genera una rotación de plano con coseno real y seno real.

Propósito

!>
!> DLARTG genera una rotación de plano tal que
!>
!>    [  C  S  ]  .  [ F ]  =  [ R ]
!>    [ -S  C  ]     [ G ]     [ 0 ]
!>
!> donde C**2 + S**2 = 1.
!>
!> Las fórmulas matemáticas usadas para C y S son
!>    R = sign(F) * sqrt(F**2 + G**2)
!>    C = F / R
!>    S = G / R
!> Por lo tanto, C >= 0. El algoritmo utilizado para calcular estas
!> cantidades incorpora escalado para evitar desbordamiento o subdesbordamiento
!> al calcular la raíz cuadrada de la suma de cuadrados.
!>
!> Esta versión es discontinua en R en F = 0, pero devuelve el mismo
!> C y S que ZLARTG para entradas complejas (F,0) y (G,0).
!>
!> Esta es una versión más precisa de la subrutina DROTG de BLAS1,
!> con las siguientes otras diferencias:
!>    F y G no se modifican al regresar.
!>    Si G=0, entonces C=1 y S=0.
!>    Si F=0 y (G .ne. 0), entonces C=0 y S=sign(1,G) sin realizar ninguna
!>       operación de punto flotante (ahorra trabajo en DBDSQR cuando
!>       hay ceros en la diagonal).
!>
!> Abajo, wp=>dp representa precisión doble del módulo LA_CONSTANTS.
!>

Parámetros

F 
!>          F es REAL(wp)
!>          El primer componente del vector a rotar.
!>

G

!>          G es REAL(wp)
!>          El segundo componente del vector a rotar.
!>

C

!>          C es REAL(wp)
!>          El coseno de la rotación.
!>

S

!>          S es REAL(wp)
!>          El seno de la rotación.
!>

R

!>          R es REAL(wp)
!>          El componente distinto de cero del vector rotado.

subroutine lartg (real(wp) f, real(wp) g, real(wp) c, real(wp) s, real(wp) r)

LARTG generates a plane rotation.

Purpose:

!>
!> LARTG generates a plane rotation so that
!>
!>    [  C         S  ] . [ F ]  =  [ R ]
!>    [ -S         C  ]   [ G ]     [ 0 ]
!>
!> where C**2 + S**2 = 1.
!>
!> The mathematical formulas used for C and S are
!>
!>    R = sgn(F) * sqrt(F**2 + G**2)
!>    C = F / R
!>    S = G / R
!>
!> Special conditions:
!>    If F=0, then C=0 and S=1.
!>    If G=0, then C=1 and S=0.
!>
!> The algorithm used to compute these quantities incorporates scaling
!> to avoid overflow or underflow in computing the square root of the
!> sum of squares.
!>
!> Below, wp=>dp stands for double precision from LA_CONSTANTS module.
!>

Parameters

F 
!>          F is REAL(wp)
!>          The first component of vector to be rotated.
!>

G

!>          G is REAL(wp)
!>          The second component of vector to be rotated.
!>

C

!>          C is REAL(wp)
!>          The cosine of the rotation.
!>

S

!>          S is REAL(wp)
!>          The sine of the rotation.
!>

R

!>          R is REAL(wp)
!>          The nonzero component of the rotated vector.
!>
