DLASD6 calcula la SVD de una matriz bidiagonal superior actualizada B obtenida al fusionar dos más pequeñas añadiendo una fila. Usado por sbdsdc.

Propósito:

!>
!> DLASD6 calcula la SVD de una matriz bidiagonal superior actualizada B
!> obtenida al fusionar dos más pequeñas añadiendo una fila. Esta
!> subrutina se usa solo para el problema que requiere todos los valores singulares
!> y opcionalmente matrices de vectores singulares en forma factorizada.
!> B es una matriz de N por M con N = NL + NR + 1 y M = N + SQRE.
!> Una subrutina relacionada, DLASD1, maneja el caso en el que se desean todos los valores
!> singulares y vectores singulares de la matriz bidiagonal.
!>
!> DLASD6 calcula la SVD de la siguiente manera:
!>
!>               ( D1(ent)    0    0       0 )
!>   B = U(ent) * (   Z1**T   a   Z2**T    b ) * VT(ent)
!>               (   0       0   D2(ent)   0 )
!>
!>     = U(sal) * ( D(sal) 0) * VT(sal)
!>
!> donde Z**T = (Z1**T a Z2**T b) = u**T VT**T, y u es un vector de dimensión M
!> con ALPHA y BETA en las entradas NL+1 y NL+2 y ceros
!> en otros lugares; y la entrada b está vacía si SQRE = 0.
!>
!> Los valores singulares de B se pueden calcular utilizando D1, D2, los primeros
!> componentes de todos los vectores singulares derechos del bloque inferior, y
!> los últimos componentes de todos los vectores singulares derechos del
!> bloque superior. Estos componentes se almacenan y actualizan en VF y VL,
!> respectivamente, en DLASD6. Por lo tanto, U y VT no se referencian explícitamente.
!>
!> Los valores singulares se almacenan en D. El algoritmo consta de dos
!> etapas:
!>
!>       La primera etapa consiste en desinflar el tamaño del problema
!>       cuando hay múltiples valores singulares o si hay un cero
!>       en el vector Z. Por cada ocurrencia de este tipo, la dimensión de la
!>       ecuación secular se reduce en uno. Esta etapa
!>       es realizada por la subrutina DLASD7.
!>
!>       La segunda etapa consiste en calcular los valores
!>       singulares actualizados. Esto se hace encontrando las raíces de la
!>       ecuación secular a través de la subrutina DLASD4 (llamada por DLASD8).
!>       Esta subrutina también actualiza VF y VL y calcula las distancias
!>       entre los valores singulares actualizados y los valores antiguos.
!>
!> DLASD6 es llamado desde DLASDA.
!>

Detailed Description

This subroutine computes the remaining singular values and vectors that are not deflated.

In other words, another term of the bisection algorithm is completed. When the algorithm terminates, the error bound of the singular values is reduced.

The subroutine uses the first, second, and third rows of the array WORK to store the intermediate values.

The last column of WORK contains the differences of the singular values.

Also, it refines the singular values and the singular vectors in the subspace spanned by the first K right singular vectors of the matrix Z.

On entry, the array Z is used to store the deflation-adjusted updating row vector which is the first row of the matrix.

The array DIFL contains the distances between the I-th and (I+1)-th singular values and the I-th element of the vector Z.

The array DIFR contains the distances between the I-th and (I+1)-th singular values and the I-th element of the vector Z.

The array SW is used to store the sign information.

The array JPVT is used to store the pivoting information.

The parameter EVENK is used to indicate whether K is even or odd.

The parameter WORK is used to store the intermediate values.

The parameter INFO is used to indicate whether the algorithm terminates successfully or not.

LASD6

   SUBROUTINE LASD6( K, DIFL, DIFR, Z, SW, JPVT, EVENK,

Parameters

K
INTEGER

On entry, K is the dimension of the non-deflated matrix, which is the order of the related secular equation. 1 <= K <= N.

On exit, K is the number of singular values that are not deflated.

DIFL
REAL array, dimension ( K )

On exit, DIFL(I) is the distance between the I-th updated (undeflated) singular value and the I-th (undeflated) old singular value.

DIFR
REAL array, dimension ( LDDIFR, 2 ) if ICOMPQ = 1 and

dimension ( K ) if ICOMPQ = 0.

On exit, DIFR(I,1) = D(I) - DSIGMA(I+1), DIFR(K,1) is not defined and will not be referenced.

If ICOMPQ = 1, DIFR(1:K,2) is an array containing the normalizing factors for the right singular vector matrix.

See SLASD8 for details on DIFL and DIFR.

Z
REAL array, dimension ( M )

The first elements of this array contain the components of the deflation-adjusted updating row vector.

SW
INTEGER array, dimension ( K )

On exit, SW(I) indicates whether the I-th singular value is updated.

JPVT
INTEGER array, dimension ( N )

On entry, JPVT contains the permutation that is applied to the singular values and vectors.

On exit, JPVT is updated.

EVENK
LOGICAL

On entry, EVENK = .TRUE. if K is even, and .FALSE. otherwise.

WORK
REAL array, dimension ( 4 * M )

Work array.

INFO
INTEGER

= 0: successful exit.

< 0: if INFO = -i, the i-th argument had an illegal value.

> 0: if INFO = 1, a singular value did not converge

ICOMPQ
INTEGER

Specifies whether or not the singular vectors are computed.

ICOMPQ = 0: only the singular values are computed.

ICOMPQ = 1: the singular values and the right singular vectors are computed.

ICOMPQ = 2: the singular values and the left singular vectors are computed.

ICOMPQ = 3: the singular values and both left and right singular vectors are computed.

POLES
REAL array, dimension ( N )

The first K elements of POLES are the roots of the secular equation found using the bisection method. The remaining N-K elements contain garbage.

POLES(I) is the I-th updated (undeflated) singular value.

POLES(I) is used when ICOMPQ = 1.

If ICOMPQ = 1, the first K elements of POLES are the values obtained from solving the secular equation, and POLES(2,*) is an array containing the poles in the secular equation. Not referenced if ICOMPQ = 0.

DIFL
REAL array, dimension ( N )

On exit, DIFL(I) is the distance between I-th updated (undeflated) singular value and the I-th (undeflated) old singular value.

DIFR
REAL array,

dimension ( LDDIFR, 2 ) if ICOMPQ = 1 and dimension ( K ) if ICOMPQ = 0.

On exit, DIFR(I,1) = D(I) - DSIGMA(I+1), DIFR(K,1) is not defined and will not be referenced.

If ICOMPQ = 1, DIFR(1:K,2) is an array containing the normalizing factors for the right singular vector matrix.

See SLASD8 for details on DIFL and DIFR.

Z
REAL array, dimension ( M )

The first elements of this array contain the components of the deflation-adjusted updating row vector.

K
INTEGER

Contains the dimension of the non-deflated matrix, This is the order of the related secular equation. 1 <= K <=N.

C
REAL

C contains garbage if SQRE =0 and the C-value of a Givens rotation related to the right null space if SQRE = 1.

S
REAL

S contains garbage if SQRE =0 and the S-value of a Givens rotation related to the right null space if SQRE = 1.

WORK
REAL array, dimension ( 4 * M )
IWORK
INTEGER array, dimension ( 3 * N )

< 0: if INFO = -i, the i-th argument had an illegal value.

> 0: if INFO = 1, a singular value did not converge
