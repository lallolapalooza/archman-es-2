DOCUMENTACIÓN DE LA FUNCIÓN

subrutina clatbs (character uplo, character trans, character diag, character normin, integer n, integer kd, complex, dimension( ldab, * ) ab, integer ldab, complex, dimension( * ) x, real scale, real, dimension( * ) cnorm, integer info)

CLATBS resuelve un sistema triangular de bandas de ecuaciones.

Propósito:

!>
!> CLATBS resuelve uno de los sistemas triangulares
!>
!>    A * x = s*b,  A**T * x = s*b,  o  A**H * x = s*b,
!>
!> con escalado para prevenir desbordamiento, donde A es una matriz triangular
!> de bandas superior o inferior. Aquí A**T denota la transpuesta de A, x e b
!> son vectores de n elementos, y s es un factor de escalado, usualmente menor
!> o igual a 1, elegido de tal manera que los componentes de x sean menores que
!> el umbral de desbordamiento. Si el problema sin escalar no causa
!> desbordamiento, se llama a la rutina BLAS de Nivel 2 CTBSV. Si la matriz A
!> es singular (A(j,j) = 0 para algún j), entonces s se establece en 0 y se
!> devuelve una solución no trivial de A*x = 0.
!>

Parámetros

UPLO 
!>          UPLO es CHARACTER*1
!>          Especifica si la matriz A es triangular superior o inferior.
!>          = 'U':  Triangular superior
!>          = 'L':  Triangular inferior
!>

TRANS

!>          TRANS es CHARACTER*1
!>          Especifica la operación aplicada a A.
!>          = 'N':  Resolver A * x = s*b     (Sin transpuesta)
!>          = 'T':  Resolver A**T * x = s*b  (Transpuesta)
!>          = 'C':  Resolver A**H * x = s*b  (Transpuesta conjugada)
!>

DIAG

!>          DIAG es CHARACTER*1
!>          Especifica si la matriz A es unitaria triangular o no.
!>          = 'N':  No unitaria triangular
!>          = 'U':  Unitaria triangular
!>

NORMIN

!>          NORMIN es CHARACTER*1
!>          Especifica si CNORM ha sido establecido o no.
!>          = 'Y':  CNORM contiene las normas de las columnas en la entrada
!>          = 'N':  CNORM no está establecido en la entrada. En la salida, las normas se
!>                  calcularán y se almacenarán en CNORM.
!>

N

!>          N es INTEGER
!>          El orden de la matriz A.  N >= 0.
!>

KD

!>          KD es INTEGER
!>          El número de subdiagonales o superdiagonales en la
!>          matriz triangular A.  KD >= 0.
!>

AB

!>          AB es array COMPLEX, dimensión (LDAB,N)
!>          La matriz de banda triangular superior o inferior A, almacenada en las
!>          primeras KD+1 filas del array. La j-ésima columna de A se almacena
!>          en la j-ésima columna del array AB de la siguiente manera:
!>          si UPLO = 'U', AB(kd+1+i-j,j) = A(i,j) para max(1,j-kd)<=i<=j;
!>          si UPLO = 'L', AB(1+i-j,j)    = A(i,j) para j<=i<=min(n,j+kd).
!>

LDAB

!>          LDAB es INTEGER
!>          La dimensión principal del array AB.  LDAB >= KD+1.
!>

X

!>          X es array COMPLEX, dimensión (N)
!>          En la entrada, el lado derecho b del sistema triangular.
!>          En la salida, X se sobrescribe con el vector solución x.
!>

SCALE

!>          SCALE es REAL
!>          El factor de escalado s para el sistema triangular
!>             A * x = s*b,  A**T * x = s*b,  o  A**H * x = s*b.
!>          Si SCALE = 0, la matriz A es singular o está mal escalada, y
!>          el vector x es una solución exacta o aproximada a A*x = 0.
!>

CNORM

!>          CNORM es array REAL, dimensión (N)
!>
!>          Si NORMIN = 'Y', CNORM es un argumento de entrada y CNORM(j)
!>          contiene las normas de la parte no diagonal de la j-ésima columna
!>          de A. Si TRANS = 'N', CNORM(j) debe ser mayor o igual a
!>          la norma infinito, y si TRANS = 'T' o 'C', CNORM(j)
!>          debe ser mayor o igual a la norma 1.
!>
!>          Si NORMIN = 'N', CNORM es un argumento de salida y CNORM(j)
!>          devuelve la norma 1 de la parte no diagonal de la j-ésima columna
!>          de A.
!>

INFO

!>          INFO es INTEGER
!>          = 0:  salida exitosa
!>          < 0:  si INFO = -k, el k-ésimo argumento tuvo un valor ilegal
!>

Detalles Adicionales:

!>
!> Se calcula un límite aproximado para x; si este es menor que el desbordamiento,
!> se llama a CTBSV, de lo contrario, se utiliza un código específico que verifica
!> posibles desbordamientos o divisiones por cero en cada operación.
!>
!> Se utiliza un esquema columna por columna para resolver A*x = b. El algoritmo básico
!> si A es triangular inferior es
!>
!>       x[1:n] := b[1:n]
!>       para j = 1, ..., n
!>            x(j) := x(j) / A(j,j)
!>            x[j+1:n] := x[j+1:n] - x(j) * A[j+1:n,j]
!>       fin
!>
!> Definimos límites para los componentes de x después de j iteraciones del bucle:
!>     M(j) = límite para x[1:j]
!>     G(j) = límite para x[j+1:n]
!> Inicialmente, sea M(0) = 0 y G(0) = max{x(i), i=1,...,n}.
!>
!> Entonces, para la iteración j+1 tenemos
!>     M(j+1) <= G(j) / | A(j+1,j+1) |
!>     G(j+1) <= G(j) + M(j+1) * | A[j+2:n,j+1] |
!>            <= G(j) ( 1 + CNORM(j+1) / | A(j+1,j+1) | )
!>
!> donde CNORM(j+1) es mayor o igual a la norma infinito de
!> la columna j+1 de A, sin contar la diagonal. Por lo tanto
!>
!>     G(j) <= G(0) producto ( 1 + CNORM(i) / | A(i,i) | )
!>                  1<=i<=j
!> y
!>
!>     |x(j)| <= ( G(0) / |A(j,j)| ) producto ( 1 + CNORM(i) / |A(i,i)| )
!>                                   1<=i< j
!>
!> Dado que |x(j)| <= M(j), usamos la rutina BLAS de Nivel 2 CTBSV si el
!> recíproco del M(j) máximo, j=1,..,n, es mayor que
!> max(desbordamiento inferior, 1/desbordamiento superior).
!>
!> El límite para x(j) también se usa para determinar cuándo se puede realizar un paso en
!> el método columna por columna sin temor a desbordamiento. Si
!> el límite calculado es mayor que una constante grande, x se escala para
!> prevenir el desbordamiento, pero si el límite se desborda, x se establece en 0, x(j) en
!> 1, y scale en 0, y se encuentra una solución no trivial a A*x = 0.
!>
!> De manera similar, se utiliza un esquema fila por fila para resolver A**T *x = b o
!> A**H *x = b. El algoritmo básico para A triangular superior es
!>
!>       para j = 1, ..., n
!>            x(j) := ( b(j) - A[1:j-1,j]' * x[1:j-1] ) / A(j,j)
!>       fin
!>
!> Calculamos simultáneamente dos límites
!>       G(j) = límite para ( b(i) - A[1:i-1,i]' * x[1:i-1] ), 1<=i<=j
!>       M(j) = límite para x(i), 1<=i<=j
!>
!> Los valores iniciales son G(0) = 0, M(0) = max{b(i), i=1,..,n}, y añadimos
!> la restricción G(j) >= G(j-1) y M(j) >= M(j-1) para j >= 1.
!> Entonces, el límite para x(j) es
!>
!>       M(j) <= M(j-1) * ( 1 + CNORM(j) ) / | A(j,j) |
!>
!>            <= M(0) * producto ( ( 1 + CNORM(i) ) / |A(i,i)| )
!>                      1<=i<=j
!>
!> y podemos llamar de forma segura a CTBSV si 1/M(n) y 1/G(n) son ambos mayores
!> que max(desbordamiento inferior, 1/desbordamiento superior).
!>

          ='I': Infinity-norm

          ='M': Max element in rows/columns
          ='P': Norm based on scaling factor

  N: INTEGER. The number of columns of each block A(I,J) and of the vector C.
          N >= 0.

  MB: INTEGER. The number of rows of each diagonal block A(I,I) and of
          the vector B. MB >= 0.

  NB: INTEGER. The number of columns of each diagonal block A(I,I) and of
          the vector C. NB >= 0.

          diagonal blocks A(I,J) of A.

  LDAB: INTEGER. The leading dimension of the array AB. LDAB >= max(1,MB).

  B: INTEGER. Array, dimension (LDB, K), where K is the number of
          diagonal blocks. The entries of B store the blocks B(I,J) of
          the right-hand side matrix B.

  LDB: INTEGER. The leading dimension of the array B. LDB >= max(1,MB).

  C: INTEGER. Array, dimension (LDC, N). The entries of C store the
          solution vector X.

  LDC: INTEGER. The leading dimension of the array C. LDC >= max(1,M).

  RWORK: REAL for SLATBS
         DOUBLE PRECISION for DLATBS
         REAL for PLATBS (uses default precision)
         DOUBLE PRECISION for ZLATBS

          Array, dimension at least 2*max(M,N).

         = 0: successful exit
         < 0: if INFO = -i, the i-th argument had an illegal value.
         > 0: if INFO = i, the i-th diagonal block is singular and the

Note

  The structure of A is:
  A = [ A(1,1)  A(1,2)  ...  A(1,K)  ]
      [ 0       A(2,2)  ...  A(2,K)  ]
      [ :       :       ...  :       ]
      [ 0       0       ...  A(K,K)  ]
  where K = (N-1)/NB + 1.

  Each diagonal block A(I,I) is a MB x NB block.
  A(I,J) is MB x NB.
  B(I,J) is MB x NB.

  The routine solves a system of equations A*X = B, where A is a
  general upper or lower triangular band matrix.

  Each block A(I,J) is an MB x NB matrix.
  Each block B(I,J) is an MB x NB matrix.

  The system to be solved is:
  A(1,1)*X(1,1) = B(1,1)
  A(2,1)*X(1,1) + A(2,2)*X(2,1) = B(2,1)
  ...
  A(K,1)*X(1,1) + ... + A(K,K)*X(K,1) = B(K,1)

  And similarly for the columns of X and B.

  We can solve A*X = B or A**H*X = B.
  A is upper or lower triangular.
  A can be unit triangular or not.

  If NORMA = '1', 'O', 'I', or 'A', the routine computes the norm of
  the solution matrix X.

  If NORMA = 'P', the routine computes a scaling factor for the solution
  matrix X, which is used to prevent overflow or underflow in the
  solution steps.

  The basic algorithm for A upper triangular is:

       for j = 1, ..., n
            x(j) := ( b(j) - A[1:j-1,j]' * x[1:j-1] ) / A(j,j)
       end

  We simultaneously compute two bounds
       G(j) = bound on ( b(i) - A[1:i-1,i]' * x[1:i-1] ), 1<=i<=j
       M(j) = bound on x(i), 1<=i<=j

  The initial values are G(0) = 0, M(0) = max{b(i), i=1,..,n}, and we
  add the constraint G(j) >= G(j-1) and M(j) >= M(j-1) for j >= 1.
  Then the bound on x(j) is

       M(j) <= M(j-1) * ( 1 + CNORM(j) ) / | A(j,j) |
