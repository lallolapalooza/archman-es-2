subrutina clarz (character side, integer m, integer n, integer l, complex, dimension( * ) v, integer incv, complex tau, complex, dimension( ldc, * ) c, integer ldc, complex, dimension( * ) work)

CLARZ aplica un reflector elemental complejo (tal como se devuelve por stzrzf) a una matriz compleja general.

Propósito:

!>
!> CLARZ aplica un reflector elemental complejo H a una matriz compleja
!> M por N, C, desde la izquierda o la derecha. H se representa en la forma
!>
!>       H = I - tau * v * v**H
!>
!> donde tau es un escalar complejo y v es un vector complejo.
!>
!> Si tau = 0, entonces H se considera la matriz identidad.
!>
!> Para aplicar H**H (la transpuesta conjugada de H), proporcione conjg(tau) en lugar de
!> tau.
!>
!> H es un producto de k reflectores elementales tal como se devuelve por CTZRZF.
!>

Parámetros

SIDE 
!>          SIDE es CHARACTER*1
!>          = 'L': forma  H * C
!>          = 'R': forma  C * H
!>

M

!>          M es INTEGER
!>          El número de filas de la matriz C.
!>

N

!>          N es INTEGER
!>          El número de columnas de la matriz C.
!>

L

!>          L es INTEGER
!>          El número de entradas del vector V que contienen
!>          la parte significativa de los vectores de Householder.
!>          Si SIDE = 'L', M >= L >= 0, si SIDE = 'R', N >= L >= 0.
!>

V

!>          V es un array COMPLEX, dimension (1+(L-1)*abs(INCV))
!>          El vector v en la representación de H tal como se devuelve por
!>          CTZRZF. V no se utiliza si TAU = 0.
!>

INCV

!>          INCV es INTEGER
!>          El incremento entre elementos de v. INCV <> 0.
!>

TAU

!>          TAU es COMPLEX
!>          El valor tau en la representación de H.
!>

C

!>          C es un array COMPLEX, dimension (LDC,N)
!>          En la entrada, la matriz M por N, C.
!>          En la salida, C se sobrescribe con la matriz H * C si SIDE = 'L',
!>          o C * H si SIDE = 'R'.
!>

LDC

!>          LDC es INTEGER
!>          La dimensión principal del array C. LDC >= max(1,M).
!>

WORK

!>          WORK es un array COMPLEX, dimension
!>                         (N) si SIDE = 'L'
!>                      o (M) si SIDE = 'R'
!>

subroutine zlarz (character side, integer m, integer n, integer l, complex*16, dimension( * ) v, integer incv, complex*16 tau, complex*16, dimension( ldc, * ) c, integer ldc, complex*16, dimension( * ) work)

ZLARZ applies an elementary reflector (as returned by stzrzf) to a general matrix.

Purpose:

!>
!> ZLARZ applies a complex elementary reflector H to a complex
!> M-by-N matrix C, from either the left or the right. H is represented
!> in the form
!>
!>       H = I - tau * v * v**H
!>
!> where tau is a complex scalar and v is a complex vector.
!>
!> If tau = 0, then H is taken to be the unit matrix.
!>
!> To apply H**H (the conjugate transpose of H), supply conjg(tau) instead
!> tau.
!>
!> H is a product of k elementary reflectors as returned by ZTZRZF.
!>

Parameters

SIDE 
!>          SIDE is CHARACTER*1
!>          = 'L': form  H * C
!>          = 'R': form  C * H
!>

M

!>          M is INTEGER
!>          The number of rows of the matrix C.
!>

N

!>          N is INTEGER
!>          The number of columns of the matrix C.
!>

L

!>          L is INTEGER
!>          The number of entries of the vector V containing
!>          the meaningful part of the Householder vectors.
!>          If SIDE = 'L', M >= L >= 0, if SIDE = 'R', N >= L >= 0.
!>

V

!>          V is COMPLEX*16 array, dimension (1+(L-1)*abs(INCV))
!>          The vector v in the representation of H as returned by
!>          ZTZRZF. V is not used if TAU = 0.
!>

INCV

!>          INCV is INTEGER
!>          The increment between elements of v. INCV <> 0.
!>

TAU

!>          TAU is COMPLEX*16
!>          The value tau in the representation of H.
!>

C

!>          C is COMPLEX*16 array, dimension (LDC,N)
!>          On entry, the M-by-N matrix C.
!>          On exit, C is overwritten by the matrix H * C if SIDE = 'L',
!>          or C * H if SIDE = 'R'.
!>

LDC

!>          LDC is INTEGER
!>          The leading dimension of the array C. LDC >= max(1,M).
!>

WORK

!>          WORK is COMPLEX*16 array, dimension
!>                         (N) if SIDE = 'L'
!>                      or (M) if SIDE = 'R'
!>
