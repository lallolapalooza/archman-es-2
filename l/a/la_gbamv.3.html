subrutina cla_gbamv (integer trans, integer m, integer n, integer kl, integer ku, real alpha, complex, dimension( ldab, * ) ab, integer ldab, complex, dimension( * ) x, integer incx, real beta, real, dimension( * ) y, integer incy)

CLA_GBAMV realiza una operación de matriz-vector para calcular límites de error.

Propósito:

!>
!> CLA_GBAMV  realiza una de las operaciones de matriz-vector
!>
!>         y := alpha*abs(A)*abs(x) + beta*abs(y),
!>    o    y := alpha*abs(A)**T*abs(x) + beta*abs(y),
!>
!> donde alpha y beta son escalares, x e y son vectores y A es una
!> matriz de m por n.
!>
!> Esta función se utiliza principalmente para calcular límites de error.
!> Para proteger contra el subdesbordamiento durante la evaluación, los componentes
!> del vector resultante se perturban lejos de cero por (N+1)
!> veces el umbral de subdesbordamiento. Para evitar errores innecesariamente grandes
!> para estructuras de bloque incrustadas en matrices generales,
!> los componentes cero no se perturban. Un cero
!> entrada se considera si todas las multiplicaciones involucradas
!> en el cálculo de esa entrada tienen al menos un multiplicando cero.
!>

Parámetros

TRANS 
!>          TRANS es INTEGER
!>           A la entrada, TRANS especifica la operación a realizar como
!>           sigue:
!>
!>             BLAS_NO_TRANS      y := alpha*abs(A)*abs(x) + beta*abs(y)
!>             BLAS_TRANS         y := alpha*abs(A**T)*abs(x) + beta*abs(y)
!>             BLAS_CONJ_TRANS    y := alpha*abs(A**T)*abs(x) + beta*abs(y)
!>
!>           Sin cambios a la salida.
!>

M

!>          M es INTEGER
!>           A la entrada, M especifica el número de filas de la matriz A.
!>           M debe ser al menos cero.
!>           Sin cambios a la salida.
!>

N

!>          N es INTEGER
!>           A la entrada, N especifica el número de columnas de la matriz A.
!>           N debe ser al menos cero.
!>           Sin cambios a la salida.
!>

KL

!>          KL es INTEGER
!>           El número de subdiagonales dentro de la banda de A. KL >= 0.
!>

KU

!>          KU es INTEGER
!>           El número de superdiagonales dentro de la banda de A. KU >= 0.
!>

ALPHA

!>          ALPHA es REAL
!>           A la entrada, ALPHA especifica el escalar alpha.
!>           Sin cambios a la salida.
!>

AB

!>          AB es array COMPLEX, dimension (LDAB,n)
!>           Antes de la entrada, la parte principal de m por n del array AB debe
!>           contener la matriz de coeficientes.
!>           Sin cambios a la salida.
!>

LDAB

!>          LDAB es INTEGER
!>           A la entrada, LDAB especifica la primera dimensión de AB tal como se declara
!>           en el programa (sub)llamador. LDAB debe ser al menos
!>           max( 1, m ).
!>           Sin cambios a la salida.
!>

X

!>          X es array COMPLEX, dimension
!>           ( 1 + ( n - 1 )*abs( INCX ) ) cuando TRANS = 'N' o 'n'
!>           y al menos
!>           ( 1 + ( m - 1 )*abs( INCX ) ) en caso contrario.
!>           Antes de la entrada, el array X incrementado debe contener el
!>           vector x.
!>           Sin cambios a la salida.
!>

INCX

!>          INCX es INTEGER
!>           A la entrada, INCX especifica el incremento para los elementos de
!>           X. INCX no debe ser cero.
!>           Sin cambios a la salida.
!>

BETA

!>          BETA es REAL
!>           A la entrada, BETA especifica el escalar beta. Cuando BETA se
!>           proporciona como cero, Y no necesita estar configurado a la entrada.
!>           Sin cambios a la salida.
!>

Y

!>          Y es array REAL, dimension
!>           ( 1 + ( m - 1 )*abs( INCY ) ) cuando TRANS = 'N' o 'n'
!>           y al menos
!>           ( 1 + ( n - 1 )*abs( INCY ) ) en caso contrario.
!>           Antes de la entrada con BETA distinto de cero, el array Y incrementado
!>           debe contener el vector y. A la salida, Y se sobrescribe con el
!>           vector y actualizado.
!>           Si m o n es cero, entonces Y no se referencia y la función
!>           realiza un retorno rápido.
!>

INCY

!>          INCY es INTEGER
!>           A la entrada, INCY especifica el incremento para los elementos de
!>           Y. INCY no debe ser cero.
!>           Sin cambios a la salida.
!>
!>  Rutina de Blas Nivel 2.
!>

la_gbamv(3) - LAPACK

NAME

la_gbamv - performs a matrix-vector operation

SYNOPSIS

SUBROUTINE LA_GBAMV(
    CHARACTER*1  TRANS,
    INTEGER  M,
    INTEGER  K,
    INTEGER  L,
    DOUBLE PRECISION  ALPHA,
    COMPLEX*16  AB,
    INTEGER  LDAB,
    COMPLEX*16  X,
    INTEGER  INCX,
    DOUBLE PRECISION  BETA,
    DOUBLE PRECISION  Y,
    INTEGER  INCY
)

Detailed Description

This routine performs a matrix-vector operation for a general banded matrix, which is stored in a compact form.

The general banded matrix A, of dimension m by n, is represented in a storage scheme in which the M+KU superdiagonals of A are stored in M rows of the array AB. More precisely, if CT a(i,j) denotes the (i,j)-th element of the matrix A, then the

1<=i<=m, 1<=j<=n

the element a(i,j) is stored in the array AB at the following location:

AB(KU+1+i-j, j)

for max(1,j-KU)<=i<=min(m,j+L).

The operation is performed by the following: Y = alpha*A*X + beta*Y, where alpha and beta are scalars, X and Y are vectors, and A is an M-by-N general band matrix.

Parameters

TRANS

!>          TRANS is CHARACTER*1
!>           On entry, TRANS specifies the operation to be performed.
!>           Unchanged on exit.
!>           'N' specifies the operation Y = alpha*A*X + beta*Y.
!>           'T' specifies the operation Y = alpha*A**T*X + beta*Y.
!>           'C' specifies the operation Y = alpha*A**H*X + beta*Y.

M

!>          M is INTEGER
