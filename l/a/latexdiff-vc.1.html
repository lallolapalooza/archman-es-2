NOMBRE

latexdiff-vc - script envoltorio que llama a latexdiff para diferentes versiones de un archivo bajo gestión de versiones (CVS, RCS o SVN)

SINOPSIS

latexdiff-vc [ opciones de latexdiff ] [ opciones de latexdiff-vc ] -r [rev1] [-r rev2] archivo1.tex [ archivo2.tex ...]

o

latexdiff-vc [ opciones de latexdiff ] [ opciones de latexdiff-vc ][ --postscript | --pdf ] antiguo.tex nuevo.tex

DESCRIPCIÓN

latexdiff-vc es un script envoltorio que aplica latexdiff a un archivo, o a múltiples archivos bajo control de versiones (git, subversion (SVN), mercurial (hg), CVS, RCS), y opcionalmente ejecuta la secuencia de comandos "latex" y "dvips" o "pdflatex" necesaria para producir la salida pdf o postscript del archivo tex de diferencia. También puede ser aplicado a un par de archivos para automatizar la generación de un archivo de diferencia en formato postscript o pdf.

OPCIONES

--rcs, --svn, --cvs, --git o --hg
Establece el sistema de control de versiones utilizado. Si no se especifica ningún sistema de versiones, latexdiff-vc intentará adivinarlo.

latexdiff-cvs, latexdiff-rcs, etc. son variantes de latexdiff-vc que tienen por defecto el sistema de versionado respectivo. Sin embargo, este valor predeterminado aún puede ser anulado utilizando las opciones anteriores.

Tenga en cuenta que hg debe soportar la opción "--root" (versión >= 2.9)

-r, -r rev o --revision, --revision=rev
Elige la revisión (en RCS, CVS, SVN, GIT o HG). Se pueden especificar una o dos opciones de -r, y estas dan lugar a comportamientos diferentes:
latexdiff-vc -r archivo.tex ...
compara archivo.tex con la versión registrada más reciente.
latexdiff-vc -r rev1 archivo.tex ...
compara archivo.tex con la revisión rev1.
latexdiff-vc -r rev1 -r rev2 archivo.tex ...
compara las revisiones rev1 y rev2 de archivo.tex.

Se pueden especificar múltiples archivos para todas las opciones anteriores. Todos los archivos deben tener las extensiones ".tex", ".bbl", o ".flt".

latexdiff-vc antiguo.tex nuevo.tex
compara dos archivos.

El nombre del archivo de diferencia se genera automáticamente y se informa a la salida estándar.

-d o --dir -d ruta o --dir=ruta
En lugar de añadir la cadena "diff" y opcionalmente los números de versión dados al archivo de salida, esto antepondrá un nombre de directorio "diff" al nombre de archivo original, creando el directorio y subdirectorios si no existen. Esto es particularmente útil para clonar una jerarquía completa de directorios. Opcionalmente, se puede especificar una ruta de archivo ruta, que se antepone en lugar de "diff".
--flatten,--flatten=keep-intermediate
Si se combina con la opción "--git", "--svn" o "--hg" o los modos correspondientes, extrae las revisiones a comparar en un directorio temporal separado, y luego pasa la opción "--flatten" a latexdiff. El directorio en el que se invoca "latexdiff-vc" define el subárbol que se extraerá. Tenga en cuenta que si se necesitan archivos adicionales que no están incluidos en el procedimiento de aplanamiento (archivos de paquetes, gráficos incluidos), deben estar accesibles en el directorio actual. Si utiliza bibtex, se recomienda incluir el archivo ".bbl" en la gestión de versiones. Desde latexdiff-vc >=1.3.4 hay un intento de crear el archivo ".bbl" ejecutando bibtex en los subdirectorios recuperados; tenga en cuenta que bibtex se ejecuta en los subdirectorios temporales, por lo que los archivos .bib o .bst deben estar bajo gestión de versiones, o en las rutas de búsqueda globales para bibtex (variables de entorno del shell "BIBINPUTS" y "BSTINPUTS").

El uso genérico de esta función es: "latexdiff-vc --flatten -r rev1 [-r rev2] master.tex" donde master.tex es el archivo del proyecto que contiene el nivel más alto de inclusiones, etc.

Con "--flatten=keep-intermediate", las instantáneas de revisión intermedias se conservan en el directorio actual (El valor predeterminado es almacenarlas en un directorio temporal y eliminarlas después de generar el archivo diff.)

--only-changes
Procesa la salida de tal manera que solo se muestren las páginas con cambios. Esto requiere el uso del subtipo ZLABEL en latexdiff, que se establecerá automáticamente, pero cualquier opción -s establecida manualmente será anulada (también requiere que el paquete zref esté instalado). Esta opción también deshabilita los enlaces internos (tal como los implementa el paquete hyperref) y el marcado de gráficos. (tenga en cuenta que esta opción debe combinarse con --ps o --pdf para tener sentido)
--force
Sobrescribe los archivos diff existentes sin pedir confirmación. El comportamiento predeterminado es pedir confirmación antes de sobrescribir un archivo de diferencia existente.
--run
ejecuta el comando latex en el archivo diff después de su generación.
--dvi
ejecuta los comandos latex y dvixxx después de la generación del archivo diff.
-c archivo_configuracion =elemento --config var1=val1,var2=val2,... o -c var1=val1,..
Establece variables de configuración para latexdiff y latexdiff-vc. La opción puede repetirse para establecer diferentes variables (como alternativa a la lista separada por comas). Variables disponibles para latexdiff-vc:
Comando latexdiff "LATEXDIFF" (p. ej., latexdiff-fast, latexdiff-so). Este comando debe admitir las opciones "-draftmode" y "-interaction=batchmode"
Comando latex "LATEX" (p. ej., pdflatex, lualatex)
Comando "DVI2" para la conversión de archivos dvi (p. ej., dvips, dvipdf)
Comando "BIBTEX" que reemplaza a bibtex

Todas las demás variables de configuración se pasan a latexdiff. Los cambios de configuración establecidos explícitamente siempre anulan los cambios implícitos por las siguientes opciones de acceso directo --fast, --so, --ps y --pdf.

--fast o --so
Utiliza "latexdiff-fast" o "latexdiff-so", respectivamente (en lugar de "latexdiff").
--ps o --postscript
Genera salida postscript a partir del archivo de diferencia. Esto ejecutará la secuencia "latex; latex; dvips" en el archivo de diferencia (no utilices esta opción en los raros casos en que se requieran tres comandos "latex" si te preocupa la referencia correcta). Si el archivo de diferencia contiene una etiqueta "\bibliography", ejecuta la secuencia "latex; bibtex; latex; latex; dvips".
--pdf
Genera salida pdf latexdiff-vc(1) — Arch Linux man pages

NAME

latexdiff-vc — Tool to help with version controlled latex documents

SYNOPSIS

latexdiff-vc [general-options] [latexdiff-options] files...

DESCRIPTION

The latexdiff-vc script is a wrapper around the latexdiff(1) script, which itself is a wrapper around the Perl module LaTeX::Diff. It simplifies the process of creating a diff of latex documents that are under version control.

It helps to automate the common task of generating a comparison of two versions of a LaTeX document.

The default behaviour is to create a diff between the last committed version of the files in the version control system and the current working copy. Other revisions can be specified using the --revision option.

The script tries to detect which files are part of the document to be compared, by looking at the command line arguments.

For more details on how to use the generated diff file, see the documentation of latexdiff(1).

OPTIONS

--cachedir=DIR
Use directory DIR for caching intermediate files. Defaults to "$HOME/.latexdiff-vc".
--main-file=FILE
Specify the main LaTeX file. This is useful if the main file is not the first file listed on the command line, or if only one file is given.
--revision=REV
Compare the working copy against revision REV. If not specified, the last committed revision is used. REV can be a version string (e.g. "1.2.3"), a tag name, a branch name, or a revision number.
--revfile=FILE
Specify a file that contains the revision information. This is useful for systems where revision information cannot be obtained directly from the version control system, or for creating diffs of older revisions. The file should contain a list of filenames, each on a new line, followed by the revision information of that file, separated by a tab character.
--git-branch=BRANCH
Specify the git branch to compare against. If not specified, the current branch is used.
--mercurial-branch=BRANCH
Specify the mercurial branch to compare against. If not specified, the current branch is used.
--output-format=FORMAT
Specify the output format. Supported formats are "latex" (default), "tex", and "diff". The "diff" format outputs a standard diff file. The "latex" and "tex" formats output a LaTeX file that can be compiled to produce a PDF diff.
--compile
Compile the generated LaTeX diff file into a PDF. This will run the sequence "pdflatex; pdflatex" on the difference file, or "pdflatex; bibtex; pdflatex; pdflatex" for files requiring bibtex. Note that this is not just a shortcut for setting configuration variable but also triggers some special behaviour.
--show-config
Show values of configuration variables.
--help or -h
Show help text
--version
Show version number

All other options are passed on to "latexdiff". Note that it is not always easy for latexdiff to correctly assign arguments to options when short form (single letter) options are used so it is recommended to use long-form options.

SEE ALSO

latexdiff(1)

PORTABILITY

latexdiff-vc uses external commands and is therefore dependent on the system architecture; it has been tested mainly on Unix-like systems. It also requires a version control system and latex to be installed on the system to make use of all features. Modules from Perl 5.8 or higher are required.
