subrutina clacn2 (entero n, complejo, dimensión( * ) v, complejo, dimensión( * ) x, real est, entero kase, entero, dimensión( 3 ) isave)

CLACN2 estima la norma 1 de una matriz compleja cuadrada, utilizando comunicación inversa para evaluar productos matriz-vector.

Propósito:

!>
!> CLACN2 estima la norma 1 de una matriz compleja cuadrada A.
!> Se utiliza comunicación inversa para evaluar productos matriz-vector.
!>

Parámetros

N 
!>          N es ENTERO
!>         El orden de la matriz.  N >= 1.
!>

V

!>          V es un array COMPLEJO, dimensión (N)
!>         En el retorno final, V = A*W,  donde  EST = norm(V)/norm(W)
!>         (W no se devuelve).
!>

X

!>          X es un array COMPLEJO, dimensión (N)
!>         En un retorno intermedio, X debe ser sobrescrito por
!>               A * X,   si KASE=1,
!>               A**H * X,  si KASE=2,
!>         donde A**H es la transpuesta conjugada de A, y CLACN2 debe
!>         ser llamada de nuevo con todos los demás parámetros sin cambios.
!>

EST

!>          EST es REAL
!>         Al ingresar con KASE = 1 o 2 e ISAVE(1) = 3, EST debe ser
!>         sin cambios desde la llamada anterior a CLACN2.
!>         Al salir, EST es una estimación (un límite inferior) para norm(A).
!>

KASE

!>          KASE es ENTERO
!>         En la llamada inicial a CLACN2, KASE debe ser 0.
!>         En un retorno intermedio, KASE será 1 o 2, indicando
!>         si X debe ser sobrescrito por A * X  o A**H * X.
!>         En el retorno final desde CLACN2, KASE será nuevamente 0.
!>

ISAVE

!>          ISAVE es un array ENTERO, dimensión (3)
!>         ISAVE se utiliza para guardar variables entre llamadas a SLACN2
!>

lacn2 — estimate the 1-norm of a matrix

Detailed Description

lacn2 estimates the 1-norm of a matrix A. It is used by the subroutine CLASS, SLINRE, DLINRE, CLINRE, ZLINRE, and ZLACON.

Reverse communication is used for evaluating matrix-vector products.

Function Documentation

subroutine SLACN2 (INTEGER N, REAL V, DIMENSION( * ), REAL X, DIMENSION( * ), REAL EST, INTEGER KASE, INTEGER, DIMENSION( 3 ) ISAVE)

SLACN2 estimates the 1-norm of a square, real matrix A. Reverse communication is used for evaluating matrix-vector products.

Purpose:

!>
!> SLACN2 estimates the 1-norm of a square, real matrix A.
!> Reverse communication is used for evaluating matrix-vector products.
!>

Parameters

N

!>          N is INTEGER
!>         The order of the matrix.  N >= 1.
!>

V

!>          V is REAL array, dimension (N)
!>         On the final return, V = A*W,  where  EST = norm(V)/norm(W)
!>         (W is not returned).
!>

X

!>          X is REAL array, dimension (N)
!>         On an intermediate return, X should be overwritten by
!>               A * X,   if KASE=1,
!>               A**T * X,  if KASE=2,
!>         and SLACN2 must be re-called with all the other parameters
!>         unchanged.
!>

ISGN

!>          ISGN is INTEGER array, dimension (N)
!>

EST

!>          EST is REAL
!>         On entry with KASE = 1 or 2 and ISAVE(1) = 3, EST should be
!>         unchanged from the previous call to SLACN2.
!>         On exit, EST is an estimate (a lower bound) for norm(A).
!>

KASE

!>          KASE is INTEGER
!>         On the initial call to SLACN2, KASE should be 0.
!>         On an intermediate return, KASE will be 1 or 2, indicating
!>         whether X should be overwritten by A * X  or A**T * X.
!>         On the final return from SLACN2, KASE will again be 0.
!>

ISAVE

!>          ISAVE is INTEGER array, dimension (3)
!>         ISAVE is used to save variables between calls to SLACN2
!>

Author

Univ. of Tennessee

Univ. of California Berkeley

Univ. of Colorado Denver

NAG Ltd.

Further Details:

!>
!>  Originally named SONEST, dated March 16, 1988.
!>
!>  This is a thread safe version of SLACON, which uses the array ISAVE
!>  in place of a SAVE statement, as follows:
!>
!>     SLACON     SLACN2
!>      JUMP     ISAVE(1)
!>      J        ISAVE(2)
!>      ITER     ISAVE(3)
!>
