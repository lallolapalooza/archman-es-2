CLA_LIN_BERR calcula un error relativo hacia atrás componente a componente.

Propósito:

!>
!>    CLA_LIN_BERR calcula el error relativo hacia atrás componente a componente
!>    a partir de la fórmula
!>        max(i) ( abs(R(i)) / ( abs(op(A_s))*abs(Y) + abs(B_s) )(i) )
!>    donde abs(Z) es el valor absoluto componente a componente de la matriz
!>    o vector Z.
!>

Parámetros

N 
!>          N es ENTERO
!>     El número de ecuaciones lineales, es decir, el orden de la
!>     matriz A.  N >= 0.
!>

NZ

!>          NZ es ENTERO
!>     Añadimos (NZ+1)*SLAMCH( 'Safe minimum' ) a R(i) en el numerador para
!>     proteger contra residuos espuriamente cero. El valor por defecto es N.
!>

NRHS

!>          NRHS es ENTERO
!>     El número de lados derechos, es decir, el número de columnas
!>     de las matrices AYB, RES y BERR.  NRHS >= 0.
!>

RES

!>          RES es un array COMPLEJO, dimensión (N,NRHS)
!>     La matriz residual, es decir, la matriz R en la fórmula del error relativo
!>     hacia atrás anterior.
!>

AYB

!>          AYB es un array REAL, dimensión (N, NRHS)
!>     El denominador en la fórmula del error relativo hacia atrás anterior, es decir,
!>     la matriz abs(op(A_s))*abs(Y) + abs(B_s). Las matrices A, Y y B
!>     provienen del refinamiento iterativo (ver cla_gerfsx_extended.f).
!>

BERR

!>          BERR es un array REAL, dimensión (NRHS)
!>     El error relativo hacia atrás componente a componente de la fórmula anterior.
!>

NAME

zla_lin_berr

SYNOPSIS

SUBROUTINE ZLA_LIN_BERR( N, NZ, NRHS, RES, AYB, BERR )
  CHARACTER * 1 OK

  INTEGER N
  INTEGER NZ
  INTEGER NRHS
  COMPLEX*16 RES( N, NRHS )
  DOUBLE PRECISION AYB( N, NRHS )
  DOUBLE PRECISION BERR( NRHS )

Detailed Description

ZLA_LIN_BERR computes a component-wise relative backward error.

Purpose:

!>
!>    ZLA_LIN_BERR computes componentwise relative backward error from
!>    the formula
!>        max(i) ( abs(R(i)) / ( abs(op(A_s))*abs(Y) + abs(B_s) )(i) )
!>    where abs(Z) is the componentwise absolute value of the matrix
!>    or vector Z.
!>

Function Documentation

Parameters

N 
!>          N is INTEGER
!>     The number of linear equations, i.e., the order of the
!>     matrix A.  N >= 0.
!>

NZ

!>          NZ is INTEGER
!>     We add (NZ+1)*SLAMCH( 'Safe minimum' ) to R(i) in the numerator to
!>     guard against spuriously zero residuals. Default value is N.
!>

NRHS

!>          NRHS is INTEGER
!>     The number of right hand sides, i.e., the number of columns
!>     of the matrices AYB, RES, and BERR.  NRHS >= 0.
!>

RES

!>          RES is COMPLEX*16 array, dimension (N,NRHS)
!>     The residual matrix, i.e., the matrix R in the relative backward
!>     error formula above.
!>

AYB

!>          AYB is DOUBLE PRECISION array, dimension (N, NRHS)
!>     The denominator in the relative backward error formula above, i.e.,
!>     the matrix abs(op(A_s))*abs(Y) + abs(B_s). The matrices A, Y, and B
!>     are from iterative refinement (see zla_gerfsx_extended.f).
!>

BERR

!>          BERR is DOUBLE PRECISION array, dimension (NRHS)
!>     The componentwise relative backward error from the formula above.
!>
