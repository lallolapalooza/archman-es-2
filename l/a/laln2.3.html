NAME

SLALN2 - Solves SLALA, where A is NA x NA and NW is 1 or 2.

SYNOPSIS

Detailed Description

  This routine is a translation of the LAPACK routine ZLALN2.
  SLALN2 is called by SLATPS to compute an approximate solution
  X to the linear system
     ( ca A - w D ) X = B
  or
     ( ca A^T - w D ) X = B
  where A is an NA x NA matrix, D is an NA x NA diagonal matrix,
  w is a scalar, ca is a scalar, and X and B are NA x NW matrices.

  The routine SLALN2 is a simplified version of ZLALN2, where
  the complex arithmetic is replaced by real arithmetic.

  It is used to solve a linear system of the form

     (ca*A - w*D)*X = B

  where A is an NA x NA matrix, D is a diagonal matrix,
  w is a scalar, and X and B are NA x NW matrices.

  The matrix A is scaled by the scalar ca, and the diagonal
  matrix D is scaled by the scalar w. The matrix (ca*A - w*D)
  is then solved for X.

  The routine uses a scaled singular value decomposition (SVD) to
  compute the solution. It first computes the SVD of the matrix
  (ca*A - w*D) and then uses the singular values and singular
  vectors to compute the solution X.

  The routine also includes a perturbation mechanism to handle cases
  where the matrix (ca*A - w*D) is close to singular. In such
  cases, the matrix is perturbed slightly to ensure that it is
  well-conditioned.

  The routine returns the solution X, a scaling factor SCALE, and the
  infinity-norm of X (XNRM). The scaling factor SCALE is used to ensure
  that X can be computed without overflow. XNRM is the infinity-norm of
  X, which is used to estimate the condition number of the matrix.

  The routine also returns an INFO flag, which indicates whether an
  error occurred or whether the matrix had to be perturbed.

  The input parameters are:
    LTRANS: .TRUE. if A-transpose is to be used, .FALSE. otherwise.
    NA: The size of the matrix A.
    NW: The number of right-hand sides (1 for real, 2 for complex).
    SMIN: The desired lower bound on the singular values of (ca A - w D).
    CA: The scalar multiplier for A.
    A: The matrix A.
    LDA: The leading dimension of A.
    D1, D2: The diagonal elements of D.
    B: The right-hand side matrix B.
    LDB: The leading dimension of B.
    WR, WI: The real and imaginary parts of the scalar w.
    X: The solution matrix X (output).
    LDX: The leading dimension of X.
    SCALE: The scaling factor for B (output).
    XNRM: The infinity-norm of X (output).
    INFO: An error flag (output).

  The routine SLALN2 computes an approximate solution X to the equation
     (ca A - w D) X = B
  or
     (ca A^T - w D) X = B
  where A is NA x NA, D is a diagonal matrix with diagonal elements
  D1 and D2, w is a scalar, ca is a scalar, and X and B are NA x NW
  matrices. NW is 1 if w is real, and 2 if w is complex.

  The routine scales the matrix (ca A - w D) to prevent overflow or
  underflow during the computation of X. It also perturbs the matrix
  if its smallest singular value is less than SMIN.

  The singular values of (ca A - w D) are estimated using the infinity-norm
  approximation.

  All input quantities are assumed to be smaller than overflow by a
  reasonable factor.

  The perturbation of A is done in a way to avoid overflow and to ensure
  that the smallest singular value of the perturbed matrix is at least SMIN.
  The perturbation is at most a small multiple of max(SMIN, ulp*norm(ca A - w D)).
  The singular values are computed by infinity-norm approximations, and thus
  will only be correct to a factor of 2 or so.

  The routine SLALN2 aims to solve the equation (ca A - w D) X = B,
  where A is an NA x NA matrix, D is a diagonal matrix with diagonal elements
  D1 and D2, w is a scalar, ca is a scalar, and X and B are NA x NW matrices.
  NW is 1 if w is real, and 2 if w is complex.

  The routine computes a scaled version of B, denoted by B*SCALE, such that
  the solution X to the equation (ca A - w D) X = B*SCALE can be computed
  without overflow. The value of SCALE is returned.

  If the matrix (ca A - w D) is ill-conditioned (i.e., has very small singular
  values), the routine perturbs the matrix slightly to ensure that its
  smallest singular value is at least SMIN. This perturbation is done in
  such a way that it does not significantly affect the solution X.

  The routine returns the solution X, the scaling factor SCALE, and the
  infinity-norm of X (XNRM). INFO is an error flag.

  If w is complex, B and X are represented as NA x 2 matrices, where the
  first column is the real part and the second column is the imaginary part.
  If both singular values of (ca A - w D) are less than SMIN, then
  SMIN*identity will be used instead of (ca A - w D). If only one singular
  value is less than SMIN, one element of (ca A - w D) will be perturbed
  enough to make the smallest singular value roughly SMIN. If both singular
  values are at least SMIN, (ca A - w D) will not be perturbed. In any case,
  the perturbation will be at most some small multiple of max( SMIN, ulp*norm(ca A - w D) ).
  The singular values are computed by infinity-norm approximations, and thus
  will only be correct to a factor of 2 or so.

  Note: all input quantities are assumed to be smaller than overflow
  by a reasonable factor.  (See BIGNUM.)
