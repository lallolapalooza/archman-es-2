NOMBRE

latexminted - Ejecutable de Python para el paquete LaTeX minted

DESCRIPCIÓN

El paquete LaTeX minted codifica código con resaltado de sintaxis utilizando la biblioteca Pygments (https://pygments.org/). latexminted recibe código y configuraciones del paquete minted, realiza el resaltado de sintaxis y el formato del código, y luego pasa el código resaltado de vuelta a LaTeX para su tipografía.

latexminted está diseñado para ser lanzado desde dentro de LaTeX a través de \ShellEscape por el paquete minted. No está destinado a un uso directo.

Consulte la documentación de minted para obtener detalles de instalación y configuración (https://ctan.org/pkg/minted).
