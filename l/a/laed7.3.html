CLAED7 utilizada por CSTEDC. Calcula el sistema propio actualizado de una matriz diagonal después de ser modificada por una matriz simétrica de rango uno. Se utiliza cuando la matriz original es densa.

Propósito:

!>
!> CLAED7 calcula el sistema propio actualizado de
!> una matriz diagonal después de la modificación por una matriz simétrica de
!> rango uno. Esta
!> rutina se utiliza solo para el problema de valores propios que requiere todos
!> los valores propios y opcionalmente los vectores propios
!> de una matriz Hermítica densa o de banda que se ha reducido
!> a forma tridiagonal.
!>
!>   T = Q(in) ( D(in) + RHO * Z*Z**H ) Q**H(in) = Q(out) * D(out) * Q**H(out)
!>
!>   donde Z = Q**Hu, u es un vector de longitud N con unos en los
!>   elementos CUTPNT y CUTPNT + 1 y ceros en otros lugares.
!>
!>    Los vectores propios de la matriz original están almacenados en Q, y los
!>    valores propios están en D. El algoritmo consta de tres etapas:
!>
!>       La primera etapa consiste en desinflar el tamaño del problema
!>       cuando hay múltiples valores propios o si hay un cero en
!>       el vector Z. Por cada ocurrencia de este tipo, la dimensión del
!>       problema de la ecuación secular se reduce en uno. Esta etapa se
!>       realiza mediante la rutina SLAED2.
!>
!>       La segunda etapa consiste en calcular los valores propios
!>       actualizados. Esto se hace encontrando las raíces de la ecuación secular
!>       mediante la rutina SLAED4 (llamada por SLAED3).
!>       Esta rutina también calcula los vectores propios del problema
!>       actual.
!>
!>       La etapa final consiste en calcular los vectores propios
!>       actualizados directamente utilizando los valores propios actualizados.
!>       Los vectores propios para
!>       el problema actual se multiplican con los vectores propios del
!>       problema general.
!>

Parámetros

N 
!>          N es ENTERO
!>         La dimensión de la matriz tridiagonal simétrica. N >= 0.
!>

CUTPNT

!>          CUTPNT es ENTERO
!>         Contiene la ubicación del último valor propio en la submatriz
!>         principal. min(1,N) <= CUTPNT <= N.
!>

QSIZ

!>          QSIZ es ENTERO
!>         La dimensión de la matriz unitaria utilizada para reducir
!>         la matriz completa a forma tridiagonal. QSIZ >= N.
!>

TLVLS

!>          TLVLS es ENTERO
!>         El número total de niveles de fusión en el árbol general de
!>         dividir y conquistar.
!>

CURLVL

!>          CURLVL es ENTERO
!>         El problema actual en el nivel actual de la rutina de fusión general,
!>         0 <= curlvl <= tlvls.
!>

CURPBM

!>          CURPBM es ENTERO
!>         El problema actual en el nivel actual de la rutina de fusión general
!>         (contando de izquierda a derecha y de abajo a arriba).
!>

D

!>          D es array REAL, dimensión (N)
!>         En la entrada, los valores propios de la matriz perturbada de
!>         rango 1.
!>         En la salida, los valores propios de la matriz reparada.
!>

Q

!>          Q es array COMPLEJO, dimensión (LDQ,N)
!>         En la entrada, los vectores propios de la matriz perturbada de
!>         rango 1.
!>         En la salida, los vectores propios de la matriz tridiagonal reparada.
!>

LDQ

!>          LDQ es ENTERO
!>         La dimensión principal del array Q. LDQ >= max(1,N).
!>

RHO

!>          RHO es REAL
!>         Contiene el elemento subdiagonal utilizado para crear la modificación
!>         de rango 1.
!>

INDXQ

!>          INDXQ es array ENTERO, dimensión (N)
!>         Contiene la permutación que reintegrará el subproblema recién resuelto
!>         en el orden ordenado, es decir, D( INDXQ( I = 1, N ) ) estará en orden
!>         ascendente.
!>

IWORK

!>          IWORK es array ENTERO, dimensión (4*N)
!>

RWORK

!>          RWORK es array REAL,
!>                                 dimensión (3*N+2*QSIZ*N)
!>

WORK

!>          WORK es array COMPLEJO, dimensión (QSIZ*N)
!>

QSTORE

!>          QSTORE es array REAL, dimensión (N**2+1)
!>         Almacena los vectores propios de las submatrices encontradas durante
!>         el dividir y conquistar, empaquetadas juntas. QPTR apunta al
!>         inicio de las submatrices.
!>

QPTR

!>          QPTR es array ENTERO, dimensión (N+2)
!>         Lista de índices que apuntan al inicio de las submatrices almacenadas
!>         en QSTORE. Las submatrices se numeran comenzando desde la parte inferior
!>         izquierda del árbol de dividir y conquistar, de izquierda a
!>         derecha y de abajo hacia arriba.
!>

PRMPTR

!>          PRMPTR es array ENTERO, dimensión (N lg N)
!>         Contiene una lista de punteros que indican dónde en PERM se almacena
!>         la permutación de un nivel. PRMPTR(i+1) - PRMPTR(i)
!>         indica el tamaño de la permutación y también el tamaño del
!>         problema completo, sin deflación.
!>

PERM

!>          PERM es array ENTERO, dimensión (N lg N)
!>         Contiene las permutaciones (de la deflación y ordenación) que se
!>         aplicarán a cada bloque propio.
!>

GIVPTR

!>          GIVPTR es array ENTERO, dimensión (N lg N)
!>         Contiene una lista de punteros que indican dónde

subroutine claed7 (integer icompq, integer n, integer qsiz, integer tlvls, integer curlvl, integer curpbm, complex, dimension( * ) d, complex, dimension( ldq, * ) q, integer ldq, integer, dimension( * ) indxq, complex rho, integer cutpnt, complex, dimension( * ) qstore, integer, dimension( * ) qptr, integer, dimension( * ) prmptr, integer, dimension( * ) perm, integer, dimension( * ) givptr, integer, dimension( 2, * ) givcol, complex, dimension( 2, * ) givnum, complex, dimension( * ) work, integer, dimension( * ) iwork, integer info)

CLAED7 used by CSTEDC. Computes the updated eigensystem of a diagonal matrix after modification by a rank-one symmetric matrix. Used when the original matrix is dense.

Purpose:

!>
!> CLAED7 computes the updated eigensystem of a diagonal
!> matrix after modification by a rank-one symmetric matrix. This
!> routine is used only for the eigenproblem which requires all
!> eigenvalues and optionally eigenvectors of a dense symmetric matrix
!> that has been reduced to tridiagonal form.  CLAED1 handles
!> the case in which all eigenvalues and eigenvectors of a symmetric
!> tridiagonal matrix are desired.
!>
!>   T = Q(in) ( D(in) + RHO * Z*Z**T ) Q**T(in) = Q(out) * D(out) * Q**T(out)
!>
!>    where Z = Q**Tu, u is a vector of length N with ones in the
!>    CUTPNT and CUTPNT + 1 th elements and zeros elsewhere.
!>
!>    The eigenvectors of the original matrix are stored in Q, and the
!>    eigenvalues are in D.  The algorithm consists of three stages:
!>
!>       The first stage consists of deflating the size of the problem
!>       when there are multiple eigenvalues or if there is a zero in
!>       the Z vector.  For each such occurrence the dimension of the
!>       secular equation problem is reduced by one.  This stage is
!>       performed by the routine CLAED8.
!>
!>       The second stage consists of calculating the updated
!>       eigenvalues. This is done by finding the roots of the secular
!>       equation via the routine CLAED4 (as called by CLAED9).
!>       This routine also calculates the eigenvectors of the current
!>       problem.
!>
!>       The final stage consists of computing the updated eigenvectors
!>       directly using the updated eigenvalues.  The eigenvectors for
!>       the current problem are multiplied with the eigenvectors from
!>       the overall problem.
!>

Parameters

ICOMPQ 
!>          ICOMPQ is INTEGER
!>          = 0:  Compute eigenvalues only.
!>          = 1:  Compute eigenvectors of original dense symmetric matrix
!>                also.  On entry, Q contains the orthogonal matrix used
!>                to reduce the original matrix to tridiagonal form.
!>

N

!>          N is INTEGER
!>         The dimension of the symmetric tridiagonal matrix.  N >= 0.
!>

QSIZ

!>          QSIZ is INTEGER
!>         The dimension of the orthogonal matrix used to reduce
!>         the full matrix to tridiagonal form.  QSIZ >= N if ICOMPQ = 1.
!>

TLVLS

!>          TLVLS is INTEGER
!>         The total number of merging levels in the overall divide and
!>         conquer tree.
!>

CURLVL

!>          CURLVL is INTEGER
!>         The current level in the overall merge routine,
!>         0 <= CURLVL <= TLVLS.
!>

CURPBM

!>          CURPBM is INTEGER
!>         The current problem in the current level in the overall
!>         merge routine (counting from upper left to lower right).
!>

D

!>          D is COMPLEX array, dimension (N)
!>         On entry, the eigenvalues of the rank-1-perturbed matrix.
!>         On exit, the eigenvalues of the repaired matrix.
!>

Q

!>          Q is COMPLEX array, dimension (LDQ, N)
!>         On entry, the eigenvectors of the rank-1-perturbed matrix.
!>         On exit, the eigenvectors of the repaired tridiagonal matrix.
!>

LDQ

!>          LDQ is INTEGER
!>         The leading dimension of the array Q.  LDQ >= max(1,N).
!>

INDXQ

!>          INDXQ is INTEGER array, dimension (N)
!>         The permutation which will reintegrate the subproblem just
!>         solved back into sorted order, i.e., D( INDXQ( I = 1, N ) )
!>         will be in ascending order.
!>

RHO

!>          RHO is COMPLEX
!>         The subdiagonal element used to create the rank-1
!>         modification.
!>

CUTPNT

!>          CUTPNT is INTEGER
!>         Contains the location of the last eigenvalue in the leading
!>         sub-matrix.  min(1,N) <= CUTPNT <= N.
!>

QSTORE

!>          QSTORE is COMPLEX array, dimension (N**2+1)
!>         Stores eigenvectors of submatrices encountered during
!>         divide and conquer, packed together. QPTR points to
!>         beginning of the submatrices.
!>

QPTR

!>          QPTR is INTEGER array, dimension (N+2)
!>         List of indices pointing to beginning of submatrices stored
!>         in QSTORE. The submatrices are numbered starting at the
!>         bottom left of the divide and conquer tree, from left to
!>         right and bottom to top.
!>

PRMPTR

!>          PRMPTR is INTEGER array, dimension (N lg N)
!>         Contains a list of pointers which indicate where in PERM a
!>         level's permutation is stored.  PRMPTR(i+1) - PRMPTR(i)
!>         indicates the size of the permutation and also the size of
!>         the full, non-deflated problem.
!>

PERM

!>          PERM is INTEGER array, dimension (N lg N)
!>         Contains the permutations (from deflation and sorting) to be
!>         applied to each eigenblock.
!>

GIVPTR

!>          GIVPTR is INTEGER array, dimension (N lg N)
!>         Contains a list of pointers which indicate where in GIVCOL a
!>         level's Givens rotations are stored.  GIVPTR(i+1) - GIVPTR(i)
!>         indicates the number of Givens rotations.
!>

GIVCOL

!>          GIVCOL is INTEGER array, dimension (2, N lg N)
!>         Each pair of numbers indicates a pair of columns to take place
!>         in a Givens rotation.
!>

GIVNUM

!>          GIVNUM is COMPLEX array, dimension (2, N lg N)
!>         Each number indicates the S value to be used in the
!>         corresponding Givens rotation.
!>

WORK

!>          WORK is COMPLEX array, dimension (3*N+2*QSIZ*N)
!>

IWORK

!>          IWORK is INTEGER array, dimension (4*N)
!>

INFO

!>          INFO is INTEGER
!>          = 0:  successful exit.
!>          < 0:  if INFO = -i, the i-th argument had an illegal value.
!>          > 0:  if INFO = 1, an eigenvalue did not converge
!>

!>
!> SLAED7 computes the updated eigensystem of a diagonal
!> matrix after modification by a rank-one symmetric matrix. This
!> routine is used only for the eigenproblem which requires all
!> eigenvalues and optionally eigenvectors of a dense symmetric matrix
!> that has been reduced to tridiagonal form.  SLAED1 handles
