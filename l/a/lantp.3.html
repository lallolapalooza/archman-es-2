función real clantp (carácter norm, carácter uplo, carácter diag, entero n, complejo, dimensión( * ) ap, real, dimensión( * ) trabajo)

CLANTP devuelve el valor de la norma 1, o la norma de Frobenius, o la norma infinito, o el elemento de mayor valor absoluto de una matriz triangular suministrada en forma empaquetada.

Propósito:

!>
!> CLANTP  devuelve el valor de la norma uno,  o la norma de Frobenius, o
!> la norma infinito,  o el  elemento de  mayor valor absoluto  de una
!> matriz triangular A, suministrada en forma empaquetada.
!>

Devuelve

CLANTP 
!>
!>    CLANTP = ( max(abs(A(i,j))), NORMA = 'M' o 'm'
!>             (
!>             ( norma1(A),         NORMA = '1', 'O' o 'o'
!>             (
!>             ( normaI(A),         NORMA = 'I' o 'i'
!>             (
!>             ( normaF(A),         NORMA = 'F', 'f', 'E' o 'e'
!>
!> donde  norma1  denota la  norma uno de una matriz (suma máxima de columna),
!> normaI  denota la  norma infinito  de una matriz  (suma máxima de fila) y
!> normaF  denota la  norma de Frobenius de una matriz (raíz cuadrada de la suma de
!> cuadrados).  Tenga en cuenta que  max(abs(A(i,j)))  no es una norma matricial consistente.
!>

Parámetros

NORM 
!>          NORM es CHARACTER*1
!>          Especifica el valor a devolver en CLANTP como se describe
!>          arriba.
!>

UPLO

!>          UPLO es CHARACTER*1
!>          Especifica si la matriz A es triangular superior o inferior.
!>          = 'U':  Triangular superior
!>          = 'L':  Triangular inferior
!>

DIAG

!>          DIAG es CHARACTER*1
!>          Especifica si la matriz A es unitaria triangular o no.
!>          = 'N':  Triangular no unitaria
!>          = 'U':  Triangular unitaria
!>

N

!>          N es INTEGER
!>          El orden de la matriz A.  N >= 0.  Cuando N = 0, CLANTP es
!>          establecido a cero.
!>

AP

!>          AP es array COMPLEX, dimensión (N*(N+1)/2)
!>          La matriz triangular superior o inferior A, empaquetada por columnas en
!>          un array lineal.  La j-ésima columna de A se almacena en el array
!>          AP de la siguiente manera:
!>          si UPLO = 'U', AP(i + (j-1)*j/2) = A(i,j) para 1<=i<=j;
!>          si UPLO = 'L', AP(i + (j-1)*(2n-j)/2) = A(i,j) para j<=i<=n.
!>          Tenga en cuenta que cuando DIAG = 'U', los elementos del array AP
!>          correspondientes a los elementos diagonales de la matriz A
!>          no se referencian, pero se asumen que son uno.
!>

WORK

!>          WORK es array REAL, dimensión (MAX(1,LWORK)),
!>          donde LWORK >= N cuando NORMA = 'I'; de lo contrario, WORK no
!>          se referencia.
!>

lantp(3) - LAPACK

NAME

lantp - calculates the value of the 1-norm, or the Frobenius-norm, or the infinity norm, or the element of largest absolute value of a triangular matrix supplied in packed form.

SYNOPSIS

    function slantp(norm, uplo, diag, n, ap, work)

    real function slantp(norm, uplo, diag, n, ap, work)

    character norm
    character uplo
    character diag
    integer n
    real, dimension(:) ap
    real, dimension(:) work

    double precision function dlantp(norm, uplo, diag, n, ap, work)

    character norm
    character uplo
    character diag
    integer n
    double precision, dimension(:) ap
    double precision, dimension(:) work

    complex function clantp(norm, uplo, diag, n, ap, work)

    complex, dimension(:) ap
    real, dimension(:) work

    complex*16 function zlantp(norm, uplo, diag, n, ap, work)

    complex*16, dimension(:) ap
    double precision, dimension(:) work

Description

This subroutine calculates a matrix norm, or the largest absolute value of the elements of a triangular matrix.

The following matrix norms are supported:

  • 1-norm (maximum column sum):

    NORM = '1' or 'O'

  • Infinity-norm (maximum row sum):

    NORM = 'I' or 'i'

  • Frobenius-norm (square root of the sum of squares of the elements):

    NORM = 'F' or 'f' or 'E' or 'e'

  • 1-norm (maximum absolute column sum) for complex matrices:

    NORM = 'O' or 'o'

  • Infinity-norm (maximum absolute row sum) for complex matrices:

    NORM = 'I' or 'i'

The element of largest absolute value is returned when NORM = 'M' or 'm'.

The matrix is supplied in packed format.

In the case of complex matrices, the infinity-norm is the maximum row sum of the absolute values of the elements.

Note: The case NORM = 'M' or 'm' does not return a consistent matrix norm.

Purpose

SLANTP returns the value of the one norm, or the Frobenius norm, or the infinity norm, or the element of largest absolute value of a triangular matrix A, supplied in packed form.

ZLANTP returns the value of the one norm, or the Frobenius norm, or the infinity norm, or the element of largest absolute value of a triangular matrix A, supplied in packed form.

Returns

SLANTP

SLANTP = ( max(abs(A(i,j))), NORM = 'M' or 'm'
         (
         ( norm1(A),         NORM = '1', 'O' or 'o'
         (
         ( normI(A),         NORM = 'I' or 'i'
         (
         ( normF(A),         NORM = 'F', 'f', 'E' or 'e'

where norm1 denotes the one norm of a matrix (maximum column sum),
normI denotes the infinity norm of a matrix (maximum row sum) and
normF denotes the Frobenius norm of a matrix (square root of sum of
squares). Note that max(abs(A(i,j))) is not a consistent matrix norm.

ZLANTP

ZLANTP = ( max(abs(A(i,j))), NORM = 'M' or 'm'
         (
         ( norm1(A),         NORM = '1', 'O' or 'o'
         (
         ( normI(A),         NORM = 'I' or 'i'
         (
         ( normF(A),         NORM = 'F', 'f', 'E' or 'e'

where norm1 denotes the one norm of a matrix (maximum column sum),
normI denotes the infinity norm of a matrix (maximum row sum) and
normF denotes the Frobenius norm of a matrix (square root of sum of
squares). Note that max(abs(A(i,j))) is not a consistent matrix norm.

Parameters

NORM

NORM is CHARACTER*1
Specifies the value to be returned in SLANTP as described
above.

UPLO

UPLO is CHARACTER*1
Specifies whether the matrix A is upper or lower triangular.
= 'U':  Upper triangular
= 'L':  Lower triangular

DIAG

DIAG is CHARACTER*1
Specifies whether or not the matrix A is unit triangular.
= 'N':  Non-unit triangular
= 'U':  Unit triangular

N

N is INTEGER
The order of the matrix A.  N >= 0.  When N = 0, SLANTP is
set to zero.

AP

AP is REAL array, dimension (N*(N+1)/2)
The upper or lower triangular matrix A, packed columnwise in
a linear array.  The j-th column of A is stored in the array
AP as follows:
if UPLO = 'U', AP(i + (j-1)*j/2) = A(i,j) for 1<=i<=j;
if UPLO = 'L', AP(i + (j-1)*(2n-j)/2) = A(i,j) for j<=i<=n.
Note that when DIAG = 'U', the elements of the array AP
corresponding to the diagonal elements of the matrix A are
not referenced, but are assumed to be one.

WORK

WORK is REAL array, dimension (MAX(1,LWORK)),
where LWORK >= N when NORM = 'I'; otherwise, WORK is not
referenced.
