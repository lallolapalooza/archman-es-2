subrutina clacrm (integer m, integer n, complex, dimension( lda, * ) a, integer lda, real, dimension( ldb, * ) b, integer ldb, complex, dimension( ldc, * ) c, integer ldc, real, dimension( * ) rwork)

CLACRM multiplica una matriz compleja por una matriz real cuadrada.

Propósito:

!>
!> CLACRM realiza una multiplicación de matriz-matriz muy simple:
!>          C := A * B,
!> donde A es M por N y compleja; B es N por N y real;
!> C es M por N y compleja.
!>

Parámetros

M 
!>          M es INTEGER
!>          El número de filas de la matriz A y de la matriz C.
!>          M >= 0.
!>

N

!>          N es INTEGER
!>          El número de columnas y filas de la matriz B y
!>          el número de columnas de la matriz C.
!>          N >= 0.
!>

A

!>          A es un array COMPLEX, dimension (LDA, N)
!>          En la entrada, A contiene la matriz A de M por N.
!>

LDA

!>          LDA es INTEGER
!>          La dimensión principal del array A. LDA >=max(1,M).
!>

B

!>          B es un array REAL, dimension (LDB, N)
!>          En la entrada, B contiene la matriz B de N por N.
!>

LDB

!>          LDB es INTEGER
!>          La dimensión principal del array B. LDB >=max(1,N).
!>

C

!>          C es un array COMPLEX, dimension (LDC, N)
!>          En la salida, C contiene la matriz C de M por N.
!>

LDC

!>          LDC es INTEGER
!>          La dimensión principal del array C. LDC >=max(1,N).
!>

RWORK

!>          RWORK es un array REAL, dimension (2*M*N)
!>
