función compleja cladiv (complejo x, complejo y)

CLADIV realiza la división de números complejos en aritmética real, evitando desbordamientos innecesarios.

Propósito:

!>
!> CLADIV := X / Y, donde X e Y son complejos. El cálculo de X / Y
!> no se desbordará en un paso intermedio a menos que el resultado
!> se desborde.
!>

Y

NOMBRE

ladiv - calcula el cociente de dos números complejos.

SINOPSIS

SUBROUTINE LADIV( A, B, C, D )

Descripción detallada

LADIV calcula el cociente de dos números complejos.

(a + ib) / (c + id) = (a*c + b*d) / (c*c + d*d) + i * (b*c - a*d) / (c*c + d*d).

Este subroutine se define para evitar underflows y overflows que podrían ocurrir al calcular el numerador y el denominador de forma separada.
