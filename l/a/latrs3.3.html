subrutina clatrs3 (carácter uplo, carácter trans, carácter diag, carácter normin, entero n, entero nrhs, complejo, dimensión( lda, * ) a, entero lda, complejo, dimensión( ldx, * ) x, entero ldx, real, dimensión( * ) scale, real, dimensión( * ) cnorm, real, dimensión( * ) work, entero lwork, entero info)

CLATRS3 resuelve un sistema de ecuaciones triangular con los factores de escalado establecidos para prevenir desbordamientos.

Propósito:

!>
!> CLATRS3 resuelve uno de los sistemas triangulares
!>
!>    A * X = B * diag(scale),  A**T * X = B * diag(scale), o
!>    A**H * X = B * diag(scale)
!>
!> con escalado para prevenir desbordamientos. Aquí A es una matriz triangular
!> superior o inferior, A**T denota la transpuesta de A, A**H denota la
!> transpuesta conjugada de A. X y B son matrices n por nrhs y scale
!> es un vector de nrhs elementos de factores de escalado. Un factor de escalado scale(j)
!> es usualmente menor o igual a 1, elegido tal que X(:,j) sea menor
!> que el umbral de desbordamiento. Si la matriz A es singular (A(j,j) = 0
!> para algún j), entonces se devuelve una solución no trivial de A*X = 0. Si
!> el sistema está tan mal escalado que la solución no puede ser representada
!> como (1/scale(k))*X(:,k), entonces x(:,k) = 0 y se devuelve scale(k).
!>
!> Esta es una versión BLAS-3 de LATRS para resolver varios lados derechos
!> simultáneamente.
!>
!>

Parámetros

UPLO 
!>          UPLO es CHARACTER*1
!>          Especifica si la matriz A es triangular superior o inferior.
!>          = 'U':  Triangular superior
!>          = 'L':  Triangular inferior
!>

TRANS

!>          TRANS es CHARACTER*1
!>          Especifica la operación aplicada a A.
!>          = 'N':  Resolver A * x = s*b  (Sin transpuesta)
!>          = 'T':  Resolver A**T* x = s*b  (Transpuesta)
!>          = 'C':  Resolver A**T* x = s*b  (Transpuesta conjugada)
!>

DIAG

!>          DIAG es CHARACTER*1
!>          Especifica si la matriz A es unitaria triangular o no.
!>          = 'N':  No unitaria triangular
!>          = 'U':  Unitaria triangular
!>

NORMIN

!>          NORMIN es CHARACTER*1
!>          Especifica si CNORM ha sido establecido o no.
!>          = 'Y':  CNORM contiene las normas de columna en la entrada
!>          = 'N':  CNORM no está establecido en la entrada. A la salida, las normas serán
!>                  calculadas y almacenadas en CNORM.
!>

N

!>          N es INTEGER
!>          El orden de la matriz A.  N >= 0.
!>

NRHS

!>          NRHS es INTEGER
!>          El número de columnas de X.  NRHS >= 0.
!>

A

!>          A es array COMPLEX, dimensión (LDA,N)
!>          La matriz triangular A.  Si UPLO = 'U', la parte superior triangular
!>          principal de n por n del array A contiene la matriz triangular
!>          superior, y la parte estrictamente triangular inferior de
!>          A no se referencia. Si UPLO = 'L', la parte inferior triangular
!>          principal de n por n del array A contiene la matriz triangular
!>          inferior, y la parte estrictamente triangular superior de A no se
!>          referencia. Si DIAG = 'U', los elementos diagonales de A
!>          tampoco se referencian y se asumen que son 1.
!>

LDA

!>          LDA es INTEGER
!>          La dimensión principal del array A.  LDA >= max (1,N).
!>

X

!>          X es array COMPLEX, dimensión (LDX,NRHS)
!>          A la entrada, el lado derecho B del sistema triangular.
!>          A la salida, X se sobrescribe con la matriz solución X.
!>

LDX

!>          LDX es INTEGER
!>          La dimensión principal del array X.  LDX >= max (1,N).
!>

SCALE

!>          SCALE es array REAL, dimensión (NRHS)
!>          El factor de escalado s(k) es para el sistema triangular
!>          A * x(:,k) = s(k)*b(:,k)  o  A**T* x(:,k) = s(k)*b(:,k).
!>          Si SCALE = 0, la matriz A es singular o mal escalada.
!>          Si se encuentra A(j,j) = 0, se devuelve un vector no trivial x(:,k)
!>          que es una solución exacta o aproximada a A*x(:,k) = 0. Si el
!>          sistema está tan mal escalado que la solución no puede presentarse
!>          como x(:,k) * 1/s(k), entonces se devuelve x(:,k) = 0.
!>

CNORM

!>          CNORM es array REAL, dimensión (N)
!>
!>          Si NORMIN = 'Y', CNORM es un argumento de entrada y CNORM(j)
!>          contiene la norma de la parte no diagonal de la j-ésima columna
!>          de A. Si TRANS = 'N', CNORM(j) debe ser mayor o igual a
!>          la norma infinito, y si TRANS = 'T' o 'C', CNORM(j)
!>          debe ser mayor o igual a la norma 1.
!>
!>          Si NORMIN = 'N', CNORM es un argumento de salida y CNORM(j)
!>          devuelve la norma 1 de la parte no diagonal de la j-ésima columna
!>          de A.
!>

WORK

!>          WORK es array REAL, dimensión (MAX(1,LWORK)).
!>          A la salida, si INFO = 0, WORK(1) devuelve el tamaño óptimo de
!>          WORK.
!>

LWORK

!>          LWORK es INTEGER
!>          La dimensión del array WORK.
!>
!>          Si MIN(N,NRHS) = 0, LWORK >= 1, de lo contrario
!>          LWORK >= MAX(1, 2*NBA * MAX(NBA, MIN(NRHS, 32)), donde
!>          NBA = (N + NB - 1)/NB y NB es el tamaño de bloque óptimo.
!>
!>          Si LWORK = -1, entonces se asume una consulta de espacio de
!>          trabajo; la rutina solo calcula las dimensiones óptimas del
!>          array WORK, devuelve este valor como la primera entrada del
!>          array WORK, y XERBLA no emite ningún mensaje de error
!>          relacionado con LWORK.
!>

INFO

!>          INFO es INTEGER
!>          = 0:  salida exitosa
!>          < 0:  si INFO = -k, el k-ésimo argumento tenía un valor ilegal
!>

= 'L': Lower triangular

TRANS

TRANS is CHARACTER*1

Specifies the operation applied to A.

= 'N': Solve A * x = s*b (No transpose)

= 'T': Solve A**T * x = s*b (Transpose)

= 'C': Solve A**T * x = s*b (Conjugate transpose = Transpose)

DIAG

DIAG is CHARACTER*1

Specifies whether or not the matrix A is unit triangular.

= 'N': Non-unit triangular

= 'U': Unit triangular

NORMIN

NORMIN is CHARACTER*1

Specifies whether CNORM has been set or not.

= 'Y': CNORM contains the column norms on entry

= 'N': CNORM is not set on entry. On exit, the norms will be computed and stored in CNORM.

N

N is INTEGER

The order of the matrix A. N >= 0.

NRHS

NRHS is INTEGER

The number of columns of X. NRHS >= 0.

A

A is DOUBLE PRECISION or REAL array, dimension (LDA,N)

The triangular matrix A. If UPLO = 'U', the leading n by n upper triangular part of the array A contains the upper triangular matrix, and the strictly lower triangular part of A is not referenced. If UPLO = 'L', the leading n by n lower triangular part of the array A contains the lower triangular matrix, and the strictly upper triangular part of A is not referenced. If DIAG = 'U', the diagonal elements of A are also not referenced and are assumed to be 1.

LDA

LDA is INTEGER

The leading dimension of the array A. LDA >= max (1,N).

X

X is DOUBLE PRECISION or REAL array, dimension (LDX,NRHS)

On entry, the right hand side B of the triangular system. On exit, X is overwritten by the solution matrix X.

LDX

LDX is INTEGER

The leading dimension of the array X. LDX >= max (1,N).

SCALE

SCALE is DOUBLE PRECISION or REAL array, dimension (NRHS)

The scaling factor s(k) is for the triangular system

A * x(:,k) = s(k)*b(:,k) or A**T * x(:,k) = s(k)*b(:,k).

If SCALE = 0, the matrix A is singular or badly scaled.

If A(j,j) = 0 is encountered, a non-trivial vector x(:,k) that is an exact or approximate solution to A*x(:,k) = 0 is returned. If the system is so badly scaled that solution cannot be presented as x(:,k) * 1/s(k), then x(:,k) = 0 is returned.

CNORM

CNORM is DOUBLE PRECISION or REAL array, dimension (N)

If NORMIN = 'Y', CNORM is an input argument and CNORM(j) contains the norm of the off-diagonal part of the j-th column of A. If TRANS = 'N', CNORM(j) must be greater than or equal to the infinity-norm, and if TRANS = 'T' or 'C', CNORM(j) must be greater than or equal to the 1-norm.

If NORMIN = 'N', CNORM is an output argument and CNORM(j) returns the 1-norm of the off-diagonal part of the j-th column of A.

WORK

WORK is DOUBLE PRECISION or REAL array, dimension (MAX(1,LWORK)).

On exit, if INFO = 0, WORK(1) returns the optimal size of WORK.

LWORK

LWORK is INTEGER

The dimension of the array WORK.

If MIN(N,NRHS) = 0, LWORK >= 1, else LWORK >= MAX(1, 2*NBA * MAX(NBA, MIN(NRHS, 32)), where NBA = (N + NB - 1)/NB and NB is the optimal block size.

If LWORK = -1, then a workspace query is assumed; the routine only calculates the optimal dimensions of the WORK array, returns this value as the first entry of the WORK array, and no error message related to LWORK is issued by XERBLA.

INFO

INFO is INTEGER

= 0: successful exit

< 0: if INFO = -k, the k-th argument had an illegal value
