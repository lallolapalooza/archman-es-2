Lazarus(1) IDE RAD para Free Pascal Lazarus(1)

NOMBRE

Lazarus - es un Entorno de Desarrollo Rápido (RAD) para el Compilador Free Pascal (FPC) que incluye un Entorno de Desarrollo Integrado (IDE).

SINOPSIS

lazarus

DESCRIPCIÓN

Este binario es un entorno de desarrollo integrado para el Compilador Free Pascal (FPC), que es un compilador avanzado de Pascal compatible con Turbo Pascal y Delphi (7.0), y multi-target.

La IDE utiliza FPC(1)

Los principales objetivos soportados actualmente son Linux, Mac OS X, Freebsd y Windows.

Los otros objetivos se basan en versiones anteriores del compilador o aún están en desarrollo.

Esta página de manual es solo para consulta rápida. Lazarus viene con un manual en línea, que se actualiza constantemente, mientras que esta página de manual puede estar desactualizada.

USO

La interfaz de usuario de la IDE ha sido diseñada para ser similar a Delphi. Proporciona al usuario un editor amigable, pero bastante potente, un editor de formularios, un extenso sistema de ayuda en línea y un depurador.

Un sistema de ventanas es la base de la interfaz de usuario. El usuario normalmente abrirá algunas ventanas de editor de texto en las que diseñará su programa, durante el cual podrá verificar y depurar regularmente mediante atajos de teclado. La alta velocidad del compilador asegura que los programadores puedan hacer esto con frecuencia y, por lo tanto, permite un desarrollo rápido de código.

Archivos de ayuda

No se proporcionan archivos de ayuda por defecto. El usuario debe descargar la documentación de Lazarus y Free Pascal en formato HTML e instalarla en la IDE utilizando Ayuda->Configurar Ayuda. Los archivos también se pueden instalar en este menú y pueden ser útiles para el código fuente que se distribuye con archivos HTML como documentación.

AUTORES

Equipo de desarrollo de Lazarus (ver http://lazarus.freepascal.org )
