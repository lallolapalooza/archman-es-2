subrutina dlasrt (carácter id, entero n, doble precisión, dimensión( * ) d, entero info)

DLASRT ordena números en orden creciente o decreciente.

Propósito:

!>
!> Ordena los números en D en orden creciente (si ID = 'I') o
!> en orden decreciente (si ID = 'D').
!>
!> Usa Quick Sort, volviendo a Insertion sort en arrays de
!> tamaño <= 20. La dimensión de STACK limita N a aproximadamente 2**32.
!>

Parámetros

ID 
!>          ID es CARACTER*1
!>          = 'I': ordenar D en orden creciente;
!>          = 'D': ordenar D en orden decreciente.
!>

N

!>          N es ENTERO
!>          La longitud del array D.
!>

D

!>          D es un array de DOBLE PRECISIÓN, dimensión (N)
!>          En la entrada, el array a ordenar.
!>          En la salida, D ha sido ordenado en orden creciente
!>          (D(1) <= ... <= D(N)) o en orden decreciente
!>          (D(1) >= ... >= D(N)), dependiendo de ID.
!>

INFO

!>          INFO es ENTERO
!>          = 0:  salida exitosa
!>          < 0:  si INFO = -i, el i-ésimo argumento tenía un valor ilegal
!>
