NOMBRE

lassign - Asigna elementos de lista a variables

SINOPSIS

lassign lista ?nombreVar ...?

DESCRIPCIÓN

Este comando trata el valor lista como una lista y asigna elementos sucesivos de esa lista a las variables dadas por los argumentos nombreVar en orden. Si hay más nombres de variables que elementos de lista, las variables restantes se establecen a la cadena vacía. Si hay más elementos de lista que variables, se devuelve una lista de elementos no asignados.

EJEMPLOS

Una ilustración de cómo funciona la asignación múltiple y qué sucede cuando hay muy pocos o demasiados elementos.

lassign {a b c} x y z       ;# Retorno vacío
puts $x                     ;# Imprime "a"
puts $y                     ;# Imprime "b"
puts $z                     ;# Imprime "c"
lassign {d e} x y z         ;# Retorno vacío
puts $x                     ;# Imprime "d"
puts $y                     ;# Imprime "e"
puts $z                     ;# Imprime ""
lassign {f g h i} x y       ;# Retorna "h i"
puts $x                     ;# Imprime "f"
puts $y                     ;# Imprime "g"

El comando lassign tiene otros usos. Se puede utilizar para crear el análogo del comando “shift” en muchos lenguajes de shell de esta manera:

set ::argv [lassign $::argv argumentoALeer]
