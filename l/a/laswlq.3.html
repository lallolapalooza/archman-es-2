 INTEGER M, N, MB, NB, LDA, LDT, LWORK, INFO
 DOUBLE PRECISION A( LDA, * ), T( LDT, * ), WORK( * )







PROPÓSITO


La subroutine DLASWLQ calcula una factorización LQ bloqueada de "barra delgada" (Tall-Skinny LQ factorization) de una matriz real M-por-N A para M <= N:


    A = ( L  0 ) *  Q,



donde:


    Q es una matriz ortogonal N-por-N, almacenada a la salida en forma implícita
    en los elementos por encima de la diagonal del array A y en
    los elementos del array T;
    L es una matriz triangular inferior M-por-M almacenada a la salida en
    los elementos en y por debajo de la diagonal del array A.
    0 es una matriz cero M-por-(N-M), si M < N, y no se almacena.







PARÁMETROS




M


M es INTEGER


El número de filas de la matriz A. M >= 0.




N


N es INTEGER


El número de columnas de la matriz A. N >= M >= 0.




MB


MB es INTEGER


El tamaño del bloque de filas a utilizar en la factorización QR bloqueada.


M >= MB >= 1




NB


NB es INTEGER


El tamaño del bloque de columnas a utilizar en la factorización QR bloqueada.


NB > 0.




A


A es DOUBLE PRECISION array, dimension (LDA,N)


En la entrada, la matriz M-por-N A.


A la salida, los elementos en y por debajo de la diagonal
de la matriz contienen la matriz triangular inferior L de N-por-N;
los elementos por encima de la diagonal representan Q mediante las filas
de V bloqueada (ver Detalles Adicionales).




LDA


LDA es INTEGER


La dimensión principal del array A. LDA >= max(1,M).




T


T es DOUBLE PRECISION array,
dimension (LDT, N * Number_of_row_blocks)


donde Number_of_row_blocks = CEIL((N-M)/(NB-M))


Los reflectores de bloque triangulares superiores bloqueados almacenados en forma compacta
como una secuencia de bloques triangulares superiores.
Ver Detalles Adicionales abajo.




LDT


LDT es INTEGER


La dimensión principal del array T. LDT >= MB.




WORK


(espacio de trabajo) DOUBLE PRECISION array, dimension (MAX(1,LWORK))


A la salida, si INFO = 0, WORK(1) devuelve el LWORK mínimo.

LWORK >= 1, si MIN(M,N) = 0, y LWORK >= MB*M en caso contrario.

DETALLES ADICIONALES


Short-Wide LQ (SWLQ) realiza LQ mediante una secuencia de transformaciones ortogonales,
representando Q como un producto de otras matrices ortogonales
  Q = Q(1) * Q(2) * . . . * Q(k)
donde cada Q(i) pone a cero las entradas de la diagonal superior de un bloque de NB filas de A:
  Q(1) pone a cero las entradas de la diagonal superior de las filas 1:NB de A
  Q(2) pone a cero las filas MB-N inferiores de las filas [1:M,NB+1:2*NB-M] de A
  Q(3) pone a cero las filas MB-N inferiores de las filas [1:M,2*NB-M+1:3*NB-2*M] de A
  . . .
Q(1) se calcula mediante GELQT, que representa Q(1) mediante vectores de Householder
almacenados debajo de la diagonal de las filas 1:MB de A, y mediante reflectores de bloque
triangulares superiores, almacenados en el array T(1:LDT,1:N).
Para más información ver Detalles Adicionales en GELQT.
Q(i) para i>1 se calcula mediante TPLQT, que representa Q(i) mediante vectores de Householder
almacenados en las columnas [(i-1)*(NB-M)+M+1:i*(NB-M)+M] de A, y mediante reflectores de bloque
triangulares superiores, almacenados en el array T(1:LDT,(i-1)*M+1:i*M).
El último Q(k) puede usar menos filas.
Para más información ver Detalles Adicionales en TPQRT.
Para más detalles del algoritmo general, ver la descripción de
TSQR Secuencial en la Sección 2.2 de [1].
[1] “Communication-Optimal Parallel and Sequential QR and LU Factorizations,”
    J. Demmel, L. Grigori, M. Hoemmen, J. Langou,
    SIAM J. Sci. Comput, vol. 34, no. 1, 2012

NAME

                    
laswlq — Short-Wide LQ factorization

                

                

                    
SYNOPSIS

                    
laswlq(SIDE, M, N, K, A, LDA, B, LDB, T, LDT, WORK, LWORK, INFO)

                    

                        
C

                        
void laswlq(char side, integer M, integer N, integer K, complex*16, dimension(*) A, integer LDA, complex*16, dimension(*) B, integer LDB, complex*16, dimension(*) T, integer LDT, complex*16, dimension(*) WORK, integer LWORK, integer INFO)

                    

                    

                        
Fortran

                        
SUBROUTINE LASWLQ( SIDE, M, N, K, A, LDA, B, LDB, T, LDT, WORK, LWORK, INFO )

                        
CHARACTER * 1 SIDE
INTEGER M, N, K, LDA, LDB, LDT, LWORK, INFO
COMPLEX*16 A( LDA, * ), B( LDB, * ), T( LDT, * ), WORK( * )

                    

                

                

                    
Description

                    
The routine computes the Short-Wide LQ factorization of a
                        real matrix B and the related matrix A:
                        
    if SIDE = 'L' then B = T * Q
    if SIDE = 'R' then B = Q * T
                        

                        where Q is an orthogonal matrix and T is upper
                        triangular. A is used to form the transformations.

                    
This is an element of the recursive Short-Wide LQ
                        factorization.

                    
For details on how to invert the triangular
                        matrix T, see laswlr(3).

                

                

                    
Parameters

                    

                        
SIDE

                        

                            
CHARACTER*1.
                            
'L': the left side
                                factorization is applied, express B as T*Q.

                            
'R': the right side
                                factorization is applied, express B as Q*T.

                        

                        
M

                        

                            
INTEGER.

                            
The number of rows of B and the number
                                of rows of the first K columns of A.

                        

                        
N

                        

                            
INTEGER.

                            
The number of columns of B and the
                                number of columns of T.

                        

                        
K

                        

                            
INTEGER.

                            
The number of rows of T and the number
                                of columns of the first K columns of A.

                        

                        
A

                        

                            
COMPLEX*16 array, dimension
                                (LDA, K).

                            
On entry, the M-by-K matrix A.

                        

                        
LDA

                        

                            
INTEGER.

                            
The leading dimension of the array A.

                        

                        
B

                        

                            
COMPLEX*16 array, dimension
                                (LDB, N).

                            
On entry, the M-by-N matrix B.

                            
On exit, the factorization is based on
                                the elements of B.

                        

                        
LDB

                        

                            
INTEGER.

                            
The leading dimension of the array B.

                        

                        
T

                        

                            
COMPLEX*16 array, dimension
                                (LDT, N).

                            
The upper triangular matrix T. The relevant
                                elements of T are in the first K rows.

                        

                        
LDT

                        

                            
INTEGER.

                            
The leading dimension of the array T.
                            
LDT >= K.

                        

                        
WORK

                        

                            
(workspace) COMPLEX*16 array,
                                dimension (MAX(1,LWORK)).

                            
On exit, if INFO = 0,
                                WORK(1) returns the minimal LWORK.

                        

                        
LWORK

                        

                            
INTEGER.

                            
The dimension of the array WORK.

                            
LWORK >= 1, if MIN(M,N) = 0,
                                and LWORK >= M*K otherwise.

                            
If LWORK = -1, then a
                                workspace query is assumed; the routine only
                                calculates the minimal size of the WORK array,
                                returns this value as the first entry of the
                                WORK array, and no error message related to
                                LWORK is issued by XERBLA.

                        

                        
INFO

                        

                            
INTEGER.

                            
= 0: successful exit

                            
< 0: if INFO = -i, the
                                i-th argument had an illegal value

Further Details

                    

                        
Short-Wide LQ (SWLQ) performs LQ by a sequence of orthogonal transformations,
representing Q as a product of other orthogonal matrices
  Q = Q(1) * Q(2) * . . . * Q(k)
where each Q(i) zeros out upper diagonal entries of a block of NB rows of A:
  Q(1) zeros out the upper diagonal entries of rows 1:NB of A
  Q(2) zeros out the bottom MB-N rows of rows [1:M,NB+1:2*NB-M] of A
  Q(3) zeros out the bottom MB-N rows of rows [1:M,2*NB-M+1:3*NB-2*M] of A
  . . .
Q(1) is computed by GELQT, which represents Q(1) by Householder vectors
stored under the diagonal of rows 1:MB of A, and by upper triangular
block reflectors, stored in array T(1:LDT,1:N).
For more information see Further Details in GELQT.
Q(i) for i>1 is computed by TPLQT, which represents Q(i) by Householder vectors
stored in columns [(i-1)*(NB-M)+M+1:i*(NB-M)+M] of A, and by upper triangular
block reflectors, stored in array T(1:LDT,(i-1)*M+1:i*M).
The last Q(k) may use fewer rows.
For more information see Further Details in TPQRT.
For more details of the overall algorithm, see the description of
Sequential TSQR in Section 2.2 of [1].
[1] “Communication-Optimal Parallel and Sequential QR and LU Factorizations,”
    J. Demmel, L. Grigori, M. Hoemmen, J. Langou,
    SIAM J. Sci. Comput, vol. 34, no. 1, 2012
