subrutina clacgv (entero n, complejo, dimensión( * ) x, entero incx)

CLACGV conjuga un vector complejo.

Propósito:

!>
!> CLACGV conjuga un vector complejo de longitud N.
!>

Parámetros

N 
!>          N es ENTERO
!>          La longitud del vector X.  N >= 0.
!>

X

!>          X es un array COMPLEJO, dimensión
!>                         (1+(N-1)*abs(INCX))
!>          En la entrada, el vector de longitud N a conjugar.
!>          En la salida, X se sobrescribe con conjg(X).
!>

INCX

!>          INCX es ENTERO
!>          El espaciado entre elementos sucesivos de X.
!>
