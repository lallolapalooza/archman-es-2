subroutine clarzb (character side, character trans, character direct, character storev, integer m, integer n, integer k, integer l, complex, dimension( ldv, * ) v, integer ldv, complex, dimension( ldt, * ) t, integer ldt, complex, dimension( ldc, * ) c, integer ldc, complex, dimension( ldwork, * ) work, integer ldwork)

CLARZB applies a block reflector or its conjugate-transpose to a general matrix.

Purpose:

!>
!> CLARZB applies a complex block reflector H or its transpose H**H
!> to a complex distributed M-by-N  C from the left or the right.
!>
!> Currently, only STOREV = 'R' and DIRECT = 'B' are supported.
!>

Parameters

SIDE 
!>          SIDE is CHARACTER*1
!>          = 'L': apply H or H**H from the Left
!>          = 'R': apply H or H**H from the Right
!>

TRANS

!>          TRANS is CHARACTER*1
!>          = 'N': apply H (No transpose)
!>          = 'C': apply H**H (Conjugate transpose)
!>

DIRECT

!>          DIRECT is CHARACTER*1
!>          Indicates how H is formed from a product of elementary
!>          reflectors
!>          = 'F': H = H(1) H(2) . . . H(k) (Forward, not supported yet)
!>          = 'B': H = H(k) . . . H(2) H(1) (Backward)
!>

STOREV

!>          STOREV is CHARACTER*1
!>          Indicates how the vectors which define the elementary
!>          reflectors are stored:
!>          = 'C': Columnwise                        (not supported yet)
!>          = 'R': Rowwise
!>

M

!>          M is INTEGER
!>          The number of rows of the matrix C.
!>

N

!>          N is INTEGER
!>          The number of columns of the matrix C.
!>

K

!>          K is INTEGER
!>          The order of the matrix T (= the number of elementary
!>          reflectors whose product defines the block reflector).
!>

L

!>          L is INTEGER
!>          The number of columns of the matrix V containing the
!>          meaningful part of the Householder reflectors.
!>          If SIDE = 'L', M >= L >= 0, if SIDE = 'R', N >= L >= 0.
!>

V

!>          V is COMPLEX array, dimension (LDV,NV).
!>          If STOREV = 'C', NV = K; if STOREV = 'R', NV = L.
!>

LDV

!>          LDV is INTEGER
!>          The leading dimension of the array V.
!>          If STOREV = 'C', LDV >= L; if STOREV = 'R', LDV >= K.
!>

T

!>          T is COMPLEX array, dimension (LDT,K)
!>          The triangular K-by-K matrix T in the representation of the
!>          block reflector.
!>

LDT

!>          LDT is INTEGER
!>          The leading dimension of the array T. LDT >= K.
!>

C

!>          C is COMPLEX array, dimension (LDC,N)
!>          On entry, the M-by-N matrix C.
!>          On exit, C is overwritten by H*C or H**H*C or C*H or C*H**H.
!>

LDC

!>          LDC is INTEGER
!>          The leading dimension of the array C. LDC >= max(1,M).
!>

WORK

!>          WORK is COMPLEX array, dimension (LDWORK,K)
!>

LDWORK

!>          LDWORK is INTEGER
!>          The leading dimension of the array WORK.
!>          If SIDE = 'L', LDWORK >= max(1,N);
!>          if SIDE = 'R', LDWORK >= max(1,M).
!>

Detailed Description

This routine is part of the LAPACK library, which builds upon the BLAS.

The purpose of LARZB is to apply a block elementary re*flector, or a block diagonal matrix, to a real or complex matrix.

Arguments

SIDE
CHARACTER*1. On entry, SIDE specifies whether the block elementary re*flector or the block diagonal matrix is applied to
SIDE
LEFT or RIGHT.
SIDE
If SIDE = ‘L’, then the block elementary re*flector or matrix is applied to C from the left.
SIDE
If SIDE = ‘R’, then the block elementary re*flector or matrix is applied to C from the right.
TRANS
CHARACTER*1. On entry, TRANS specifies whether the block elementary re*flector or the block diagonal matrix is transposed before being applied.
TRANS
‘N’ or ‘T’.
DIRECT
CHARACTER*1. On entry, DIRECT specifies whether the block elementary re*flectors or block diagonal matrix are assumed to be defined in a left-to-right or right-to-left manner.
DIRECT
‘L’ or ‘R’.
FORWARD
CHARACTER*1. On entry, FORWARD specifies whether the vectors that define the block elementary re*flectors are assumed to be stored column-wise or row-wise.
FORWARD
‘F’ or ‘B’.
ROWMAJOR
CHARACTER*1. On entry, ROWMAJOR specifies whether the data is stored in row-major or column-major format.
ROWMAJOR
‘R’ or ‘C’.
M
INTEGER. On entry, M is the number of rows of the matrix C.
N
INTEGER. On entry, N is the number of columns of the matrix C.
K
INTEGER. On entry, K is the number of columns of the matrix A. If SIDE = ‘L’, K is the number of block elementary re*flectors, and M is the dimension of the vectors that define the re*flectors.
L
INTEGER. On entry, L is the dimension of the vectors that define the block elementary re*flectors.
A
COMPLEX*16 array, dimension (LDA,K) if DIRECT = ‘L’ or ROWMAJOR = ‘C’, or (LDA,M) if DIRECT = ‘R’ and ROWMAJOR = ‘R’. On entry, the vectors that define the block elementary re*flectors.
LDA
INTEGER. On entry, LDA is the leading dimension of the array A.
B
COMPLEX*16 array, dimension (LDB,L) if DIRECT = ‘R’ or ROWMAJOR = ‘C’, or (LDB,K) if DIRECT = ‘L’ and ROWMAJOR = ‘R’. On entry, the elements of the block diagonal matrix T.
LDB
INTEGER. On entry, LDB is the leading dimension of the array B.
T
COMPLEX*16 array, dimension (LDT,K) if DIRECT = ‘L’ or ROWMAJOR = ‘C’, or (LDT,M) if DIRECT = ‘R’ and ROWMAJOR = ‘R’. On entry, the block diagonal elements of the matrix T.
LDT
INTEGER. On entry, LDT is the leading dimension of the array T.
C
COMPLEX*16 array, dimension (LDC,N). On entry, the matrix to which the block elementary re*flector or block diagonal matrix is applied.
LDC
INTEGER. On entry, LDC is the leading dimension of the array C.

Module

Summary

LARZB applies a block reflector, or block Householder transformations,
to a real matrix.

Description

  Level 3 Basic.

Interface

  SUBROUTINE LARZB( SIDE, TRANS, DIRECT, FORWARD, ROWMAJOR,
 &                   M, N, K, L,
 &                   A, LDA, B, LDB,
 &                   T, LDT, C, LDC )

Parameters

  SIDE    (input) CHARACTER*1
          Specifies whether the block reflector is applied to
          the left or right of C.
          = ‘L’: apply to left
          = ‘R’: apply to right

  TRANS   (input) CHARACTER*1
          Specifies whether the matrix T is transposed before use.
          = ‘N’: do not transpose T
          = ‘T’: transpose T

  DIRECT  (input) CHARACTER*1
          Specifies whether the vectors which define the triangular
          matrix T are stored by the user in the form of a set of
          left vectors or right vectors.
          = ‘L’: left vectors
          = ‘R’: right vectors

  FORWARD (input) CHARACTER*1
          Specifies whether the block reflector is used in an
          explicit representation or implicitly.
          = ‘F’: use explicit representation
          = ‘B’: use implicit representation

  ROWMAJOR(input) CHARACTER*1
          Specifies whether the matrix C is in row-major or column-major
          format.
          = ‘R’: row-major
          = ‘C’: column-major

  M       (input) INTEGER
          The number of rows of the matrix C. M >= 0.

  N       (input) INTEGER
          The number of columns of the matrix C. N >= 0.

  K       (input) INTEGER
          The number of columns of the matrix A. K >= 0.
          If SIDE = ‘L’, K is the number of block reflectors
          and M is the dimension of the vectors that define the reflectors.
          If SIDE = ‘R’, K is the dimension of the vectors that define
          the reflectors and N is the number of block reflectors.

  L       (input) INTEGER
          The dimension of the vectors that define the block reflectors.
          If DIRECT = ‘L’, L is the number of rows of T.
          If DIRECT = ‘R’, L is the number of columns of T.

  A       (input) COMPLEX*16 array, dimension (LDA,K) if
          DIRECT = ‘L’ or ROWMAJOR = ‘C’, or (LDA,M) if
          DIRECT = ‘R’ and ROWMAJOR = ‘R’
          On entry, the vectors that define the block reflectors.

  LDA     (input) INTEGER
          The leading dimension of the array A.

  B       (input) COMPLEX*16 array, dimension (LDB,L) if
          DIRECT = ‘R’ or ROWMAJOR = ‘C’, or (LDB,K) if
          DIRECT = ‘L’ and ROWMAJOR = ‘R’
          On entry, the elements of the block diagonal matrix T.

  LDB     (input) INTEGER
          The leading dimension of the array B.

  T       (input) COMPLEX*16 array, dimension (LDT,K) if
          DIRECT = ‘L’ or ROWMAJOR = ‘C’, or (LDT,M) if
          DIRECT = ‘R’ and ROWMAJOR = ‘R’
          On entry, the block diagonal elements of the matrix T.

  LDT     (input) INTEGER
          The leading dimension of the array T.

  C       (output) COMPLEX*16 array, dimension (LDC,N)
          On exit, C is updated with the result of applying the block
          reflector or block diagonal matrix.

  LDC     (input) INTEGER
          The leading dimension of the array C.

Further Details

  The block reflectors are of the form H(i) = I - tau(i) v(i) v(i)**H,
  where v(i) is a vector and tau(i) is a scalar.
  This routine applies the product:
  product = H(k) * ... * H(1) * C (if SIDE = ‘L’)
  or
  product = C * H(k) * ... * H(1) (if SIDE = ‘R’)
  where H(i) is a block reflector.
