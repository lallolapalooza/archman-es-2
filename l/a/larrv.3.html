!>          deseado.

CLARRV -

SYNOPSIS

    subroutine clarrv(n, vl, vu, d, l, pivmin, isplit, m, dol, dou, minrgp,
                     rtol1, rtol2, w, werr, wgap, iblock, indexw, gers, z,
                     ldz, isuppz, work, iwork, info)

        character jobz

        integer :: dol, dou, info, iblock, indexw, isplit, isuppz, l, ldz, m, n
        real :: d, l, minrgp, rtol1, rtol2, vl, vu, w, werr, wgap
        complex, dimension( ldz, * ) :: z
        real, dimension( * ) :: work
        integer, dimension( * ) :: iwork

DESCRIPTION

CLARRV computes the eigenvectors of the complex tridiagonal matrix T = L D L**H given L, D and APPROXIMATIONS to the eigenvalues of L D L**H. The input eigenvalues should have been computed by ZLARRE.

Arguments

N
CHARACTER*1 JOBZ

Specifies whether to compute eigenvectors:

  • 'V': eigenvectors are computed and returned in Z.
  • 'N': eigenvectors are not computed.
VL
CHARACTER*1 RANGE

Specifies the range of eigenvalues in which to find eigenvectors.

  • 'A': all eigenvalues will be factored.
  • 'V': all eigenvalues lambda in the interval (VL, VU) will be selected (VL and VU are actual arguments).
  • 'I': the selected eigenvalues L(I) to R(I) will be factored (I and R are actual arguments).
VU
INTEGER N

The order of the matrix T. N >= 0.

D
COMPLEX array, dimension (N)

On entry, the N diagonal elements of the diagonal matrix D.

On exit, D may be overwritten.

L
COMPLEX array, dimension (N)

On entry, the (N-1) subdiagonal elements of the unit bidiagonal matrix L are in elements 1 to N-1 of L (if the matrix is not split.) At the end of each block is stored the corresponding shift as given by ZLARRE.

On exit, L is overwritten.

PIVMIN
REAL PIVMIN

The minimum pivot allowed in the Sturm sequence.

ISPLIT
INTEGER array, dimension (N)

The splitting points, at which T breaks up into blocks. The first block consists of rows/columns 1 to ISPLIT(1), the second of rows/columns ISPLIT(1)+1 through ISPLIT(2), etc.

M
INTEGER M

The number of elements of W used. If RANGE = 'A', M should equal N. If RANGE = 'V', M is the number of eigenvalues in (VL, VU). If RANGE = 'I', M = R-I+1. (0 <= M <= N).

DOL
INTEGER DOL

If RANGE = 'I', DOL and DOU specify the diagonal entries of the eigenvalues that are to be computed. (1 <= DOL <= DOU <= N).

DOU
INTEGER DOU

See DOL.

MINRGP
REAL MINRGP

Minimum gap between two consecutive eigenvalues.

RTOL1
REAL RTOL1

Relative tolerance for the bisection method. An interval [LEFT,RIGHT] has converged if RIGHT-LEFT < MAX( RTOL1*GAP, RTOL2*MAX(|LEFT|,|RIGHT|) ).

RTOL2
REAL RTOL2

Absolute tolerance for the bisection method. See RTOL1.

W
COMPLEX array, dimension (N)

The first M eigenvalues of the matrix T, sorted in increasing order. They should be stored in the order determined by ZLARRE. They are assumed to be the roots of the characteristic polynomial of the unshifted matrix.

On exit, W holds the eigenvalues of the UNshifted matrix.

WERR
REAL array, dimension (N)

The first M elements contain the semi-width of the uncertainty interval of the corresponding eigenvalue in W.

WGAP
REAL array, dimension (N)

The first M elements contain the gap of the eigenvalue interval. The gap is computed as the distance from the right boundary of the uncertainty interval of the current eigenvalue to the left boundary of the uncertainty interval of the the next eigenvalue.

IBLOCK
INTEGER array, dimension (N)

The first M elements contain the indices of the blocks (submatrices) associated with the corresponding eigenvalues in W; IBLOCK(i)=1 if eigenvalue W(i) belongs to the first block from the top, =2 if W(i) belongs to the second block, etc.

INDEXW
INTEGER array, dimension (N)

The first M elements contain the indices of the eigenvalues within each block (submatrix). For example, INDEXW(i)=10 and IBLOCK(i)=2 imply that the i-th eigenvalue W(i) is the 10th eigenvalue in the second block.

GERS
REAL array, dimension (2*N)

The N Gerschgorin intervals (the i-th Gerschgorin interval is (GERS(2*i-1), GERS(2*i)). The Gerschgorin intervals should be computed from the original UNshifted matrix.

Z
COMPLEX array, dimension (LDZ, max(1,M))

If INFO = 0 and JOBZ = 'V', the first M columns of Z contain the orthonormal eigenvectors of the matrix T corresponding to the input eigenvalues, with the i-th column of Z holding the eigenvector associated with W(i). Note that the eigenvectors may be truncated in each block due to the constraints of the block sizes.

If JOBZ = 'N', Z is not used.

The user must ensure that at least max(1,M) columns are supplied in the array Z.

LDZ
INTEGER LDZ

The leading dimension of the array Z. LDZ >= 1, and if JOBZ = 'V', LDZ >= max(1,N).

ISUPPZ
INTEGER array, dimension ( 2*max(1,M) )

The support of the eigenvectors in Z, i.e., the indices indicating the nonzero elements in Z. The I-th eigenvector is nonzero only in elements ISUPPZ( 2*I-1 ) through ISUPPZ( 2*I ).

WORK
REAL array, dimension (12*N)

Workspace array.

IWORK
INTEGER array, dimension (7*N)

Workspace array.

INFO
INTEGER

= 0: successful exit

> 0: A problem occurred in CLARRV.

< 0: One of the called subroutines signaled an internal problem. Needs inspection of the corresponding parameter IINFO for further information.

=-1: Problem in SLARRB when refining a child's eigenvalues.

=-2: Problem in SLARRF when computing the RRR of a child. When a child is inside a tight cluster, it can be difficult to find an RRR. A partial remedy from the user's point of view is to make the parameter MINRGP smaller and recompile. However, as the orthogonality of the computed vectors is proportional to 1/MINRGP, the user should be aware that he might be trading in precision when he decreases MINRGP.

=-3: Problem in SLARRB when refining a single eigenvalue after the Rayleigh correction was rejected.

= 5: The Rayleigh Quotient Iteration failed to converge to full accuracy in MAXITR steps.

Detailed Description

larrv is part of the LAPACK routine for finding eigenvalues and eigenvectors of a symmetric tridiagonal matrix.

This routine computes the selected eigenvalues and eigenvectors of a symmetric tridiagonal matrix T using the Lauchly-Krylov subspace algorithm.

The input matrix T is represented by its diagonal entries D and off-diagonal entries E.

The algorithm computes the eigenvalues within the specified range (vl, vu) and the corresponding eigenvectors.

The tolerance rtol determines the accuracy of the eigenvalue computation. A smaller value of rtol leads to higher accuracy but may increase the computation time.

The routine returns the number of eigenvalues found (`m`), the number of eigenvalues to the left of `vl` (`nl`), and the number of eigenvalues to the right of `vu` (`nr`).

The eigenvectors are returned in the arrays Q and Z. The support of the eigenvectors (the indices of the first non-zero entries) is provided in the array ISUPPZ.

The routine uses workspace arrays `work` and `iwork` for intermediate computations.
