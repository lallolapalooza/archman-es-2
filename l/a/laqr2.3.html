subrutina claqr2 (logical wantt, logical wantz, integer n, integer ktop, integer kbot, integer nw, complex, dimension( ldh, * ) h, integer ldh, integer iloz, integer ihiz, complex, dimension( ldz, * ) z, integer ldz, integer ns, integer nd, complex, dimension( * ) sh, complex, dimension( ldv, * ) v, integer ldv, integer nh, complex, dimension( ldt, * ) t, integer ldt, integer nv, complex, dimension( ldwv, * ) wv, integer ldwv, complex, dimension( * ) work, integer lwork)

CLAQR2 realiza la transformación de semejanza unitaria de una matriz de Hessenberg para detectar y desdeflar valores propios completamente convergidos de una submatriz principal final (desdeflamiento temprano agresivo).

Propósito:

!>
!>    CLAQR2 es idéntica a CLAQR3 excepto que evita la recursión
!>    llamando a CLAHQR en lugar de CLAQR4.
!>
!>    Desdeflamiento temprano agresivo:
!>
!>    Esta subrutina acepta como entrada una matriz de Hessenberg superior
!>    H y realiza una transformación de semejanza unitaria
!>    diseñada para detectar y desdeflar valores propios completamente convergidos
!>    de una submatriz principal final. En la salida H ha sido
!>    sobrescrita por una nueva matriz de Hessenberg que es una perturbación de
!>    una transformación de semejanza unitaria de H. Se espera que
!>    la versión final de H tenga muchas entradas subdiagonales cero.
!>

Parámetros

WANTT 
!>          WANTT es LOGICAL
!>          Si .TRUE., entonces la matriz de Hessenberg H se actualiza completamente
!>          para que el factor triangular de Schur pueda ser
!>          calculado (en cooperación con la subrutina que llama).
!>          Si .FALSE., entonces solo se actualiza suficiente de H para preservar
!>          los valores propios.
!>

WANTZ

!>          WANTZ es LOGICAL
!>          Si .TRUE., entonces la matriz unitaria Z se actualiza para
!>          que el factor de Schur unitario pueda ser calculado
!>          (en cooperación con la subrutina que llama).
!>          Si .FALSE., entonces Z no se referencia.
!>

N

!>          N es INTEGER
!>          El orden de la matriz H y (si WANTZ es .TRUE.) el
!>          orden de la matriz unitaria Z.
!>

KTOP

!>          KTOP es INTEGER
!>          Se asume que KTOP = 1 o H(KTOP,KTOP-1)=0.
!>          KBOT y KTOP juntos determinan un bloque aislado
!>          a lo largo de la diagonal de la matriz de Hessenberg.
!>

KBOT

!>          KBOT es INTEGER
!>          Se asume sin comprobación que KBOT = N o H(KBOT+1,KBOT)=0.
!>          KBOT y KTOP juntos determinan un bloque aislado
!>          a lo largo de la diagonal de la matriz de Hessenberg.
!>

NW

!>          NW es INTEGER
!>          Tamaño de la ventana de desdeflamiento. 1 <= NW <= (KBOT-KTOP+1).
!>

H

!>          H es array COMPLEX, dimension (LDH,N)
!>          En la entrada, la sección N por N inicial de H almacena la
!>          matriz de Hessenberg que se somete a desdeflamiento temprano
!>          agresivo.
!>          En la salida, H ha sido transformada por una semejanza
!>          unitaria, perturbada, y devuelta a forma de Hessenberg que (se espera)
!>          tiene algunas entradas subdiagonales cero.
!>

LDH

!>          LDH es INTEGER
!>          Dimensión principal de H tal como se declara en la subrutina que
!>          llama. N <= LDH
!>

ILOZ

!>          ILOZ es INTEGER
!>

IHIZ

!>          IHIZ es INTEGER
!>          Especifican las filas de Z a las que se deben aplicar las
!>          transformaciones si WANTZ es .TRUE.. 1 <= ILOZ <= IHIZ <= N.
!>

Z

!>          Z es array COMPLEX, dimension (LDZ,N)
!>          Si WANTZ es .TRUE., entonces en la salida, la transformación de
!>          semejanza unitaria mencionada anteriormente se ha acumulado en
!>          Z(ILOZ:IHIZ,ILOZ:IHIZ) por la derecha.
!>          Si WANTZ es .FALSE., entonces Z no se referencia.
!>

LDZ

!>          LDZ es INTEGER
!>          La dimensión principal de Z tal como se declara en la
!>          subrutina que llama. 1 <= LDZ.
!>

NS

!>          NS es INTEGER
!>          El número de valores propios no convergidos (es decir, aproximados)
!>          devueltos en SR y SI que pueden ser utilizados como desplazamientos por
!>          la subrutina que llama.
!>

ND

!>          ND es INTEGER
!>          El número de valores propios convergidos descubiertos por esta
!>          subrutina.
!>

SH

!>          SH es array COMPLEX, dimension (KBOT)
!>          En la salida, los valores propios aproximados que pueden
!>          ser utilizados para desplazamientos se almacenan en SH(KBOT-ND-NS+1)
!>          hasta SR(KBOT-ND). Los valores propios convergidos se
!>          almacenan en SH(KBOT-ND+1) hasta SH(KBOT).
!>

V

!>          V es array COMPLEX, dimension (LDV,NW)
!>          Un array de trabajo de NW por NW.
!>

LDV

!>          LDV es INTEGER
!>          La dimensión principal de V tal como se declara en la
!>          subrutina que llama. NW <= LDV
!>

NH

!>          NH es INTEGER
!>          El número de columnas de T. NH >= NW.
!>

T

!>          T es array COMPLEX, dimension (LDT,NW)
!>

LDT

!>          LDT es INTEGER
!>          La dimensión principal de T tal como se declara en la
!>          subrutina que llama. NW <= LDT
!>

NV

!>          NV es INTEGER
!>          El número de filas del array de trabajo WV disponibles para
!>          espacio de trabajo. NV >= NW.
!>

WV

!>          WV es array COMPLEX, dimension (LDWV,NW)
!>

LDWV

!>          LDWV es INTEGER
!>          La dimensión principal de W tal como se declara en la
!>          subrutina que llama. NW

SLAQR2 realiza la transformación de semejanza ortogonal de una matriz de Hessenberg para detectar y deflactar valores propios completamente convergidos de una submatriz principal de cola (deflactación temprana agresiva).

Propósito:

!>
!> SLAQR2 es idéntica a SLAQR3 excepto que evita
!> la recursión llamando a SLAHQR en lugar de SLAQR4.
!>
!> Deflactación temprana agresiva:
!>
!> Esta subrutina acepta como entrada una matriz de Hessenberg superior
!> H y realiza una transformación de semejanza ortogonal
!> diseñada para detectar y deflactar valores propios completamente
!> convergidos de una submatriz principal de cola. En la salida, H ha sido
!> sobrescrita por una nueva matriz de Hessenberg que es una perturbación de

ZLAQR2 realiza la transformación de semejanza unitaria de una matriz de Hessenberg para detectar y deflactar valores propios completamente convergidos de una submatriz principal de cola (deflactación temprana agresiva).

!>
!> ZLAQR2 acepta como entrada una matriz de Hessenberg superior

NAME

ZLAQR2

aggressively early deflation of unwanted fine structure in an upper Hessenberg matrix

Detailed Description

ZLAQR2 is a subroutine of the LARPACK routines for finding the eigenvalues and eigenvectors of a complex general matrix.

This routine is intended to be called from ZLAQR0 or ZLAQR1, from ZLAQR3 or ZLAQR4, or from ZLAQR5. It is used to aggressively early deflate unwanted fine structure in an upper Hessenberg matrix.

Arguments:

WANTT
WANTT is CHARACTER*1

Specifies whether the matrix T is desired.

WANTT = 'Y': The desired upper-Hessenberg matrix T.

WANTT = 'N': The upper-Hessenberg matrix T is not desired.

WANTZ
WANTZ is CHARACTER*1

Specifies whether the matrix Z is desired.

WANTZ = 'Y': The unitary matrix Z.

WANTZ = 'N': The unitary matrix Z is not desired.

KM
KM is INTEGER

The number of columns in the initial upper Hessenberg matrix H. 1 <= KM.

SN
SN is INTEGER

The number of shifts before dynamic resizing occurs. 1 <= SN <= KM.

SR
SR is DOUBLE PRECISION array, dimension (KM)

On output, the real parts of the approximate eigenvalues which have been computed. SR(I) = H(I,I) for I = ND+1, ..., KM.

SI
SI is DOUBLE PRECISION array, dimension (KM)

On output, the imaginary parts of the approximate eigenvalues which have been computed. SI(I) = H(I,I) for I = ND+1, ..., KM.

H
H is COMPLEX*16 array, dimension (LDH,KM)

On input the initial N-by-N section of H stores the Hessenberg matrix undergoing aggressive early deflation. On output H has been transformed by a unitary similarity transformation, perturbed, and the returned to Hessenberg form that (it is to be hoped) has some zero subdiagonal entries.

LDH
LDH is INTEGER

Leading dimension of H just as declared in the calling subroutine. N <= LDH

ILOZ
ILOZ is INTEGER

ILOZ and IHIZ specify the rows of Z to which transformations must be applied if WANTZ is .TRUE.. 1 <= ILOZ <= IHIZ <= N.

IHIZ
IHIZ is INTEGER

IHIZ and ILOZ specify the rows of Z to which transformations must be applied if WANTZ is .TRUE.. 1 <= ILOZ <= IHIZ <= N.

Z
Z is COMPLEX*16 array, dimension (LDZ,N)

IF WANTZ is .TRUE., then on output, the unitary similarity transformation mentioned above has been accumulated into Z(ILOZ:IHIZ,ILOZ:IHIZ) from the right. If WANTZ is .FALSE., then Z is unreferenced.

LDZ
LDZ is INTEGER

The leading dimension of Z just as declared in the calling subroutine. 1 <= LDZ.

TOL
TOL is DOUBLE PRECISION

Deflation tolerance.

NS
NS is INTEGER

The number of unconverged (ie approximate) eigenvalues returned in SR and SI that may be used as shifts by the calling subroutine.

ND
ND is INTEGER

The number of converged eigenvalues uncovered by this subroutine.

SH
SH is COMPLEX*16 array, dimension (KM)

On output, approximate eigenvalues that may be used for shifts are stored in SH(KM-ND-NS+1) through SR(KM-ND). Converged eigenvalues are stored in SH(KM-ND+1) through SH(KM).

V
V is COMPLEX*16 array, dimension (LDV,NW)

An NW-by-NW work array.

LDV
LDV is INTEGER

The leading dimension of V just as declared in the calling subroutine. NW <= LDV

NH
NH is INTEGER

The number of columns of T. NH >= NW.

T
T is COMPLEX*16 array, dimension (LDT,NW)
LDT
LDT is INTEGER

The leading dimension of T just as declared in the calling subroutine. NW <= LDT

NV
NV is INTEGER

The number of rows of work array WV available for workspace. NV >= NW.

WV
WV is COMPLEX*16 array, dimension (LDWV,NW)
LDWV
LDWV is INTEGER

The leading dimension of W just as declared in the calling subroutine. NW <= LDV

WORK
WORK is COMPLEX*16 array, dimension (LWORK)

On exit, WORK(1) is set to an estimate of the optimal value of LWORK for the given values of N, NW, KTOP and KBOT.

LWORK
LWORK is INTEGER

The dimension of the work array WORK. LWORK = 2*NW suffices, but greater efficiency may result from larger values of LWORK.

If LWORK = -1, then a workspace query is assumed; ZLAQR2 only estimates the optimal workspace size for the given values of N, NW, KTOP and KBOT. The estimate is returned in WORK(1). No error message related to LWORK is issued by XERBLA. Neither H nor Z are accessed.
