función real clange (carácter norma, entero m, entero n, complejo, dimensión( lda, * ) a, entero lda, real, dimensión( * ) work)

CLANGE devuelve el valor de la norma 1, norma de Frobenius, norma infinito, o el valor absoluto más grande de cualquier elemento de una matriz rectangular general.

Propósito:

!>
!> CLANGE  devuelve el valor de la norma uno,  o la norma de Frobenius, o
!> la  norma infinito,  o el  elemento de  mayor valor absoluto  de una
!> matriz compleja A.
!>

Devuelve

CLANGE 
!>
!>    CLANGE = ( max(abs(A(i,j))), NORMA = 'M' o 'm'
!>             (
!>             ( norm1(A),         NORMA = '1', 'O' o 'o'
!>             (
!>             ( normI(A),         NORMA = 'I' o 'i'
!>             (
!>             ( normF(A),         NORMA = 'F', 'f', 'E' o 'e'
!>
!> donde  norm1  denota la  norma uno de una matriz (suma máxima de columna),
!> normI  denota la  norma infinito  de una matriz  (suma máxima de fila) y
!> normF  denota la  norma de Frobenius de una matriz (raíz cuadrada de la suma
!> de cuadrados).  Tenga en cuenta que  max(abs(A(i,j)))  no es una norma de matriz
!> consistente.
!>

Parámetros

NORMA 
!>          NORMA es CARACTER*1
!>          Especifica el valor que se devolverá en CLANGE como se describe
!>          arriba.
!>

M

!>          M es ENTERO
!>          El número de filas de la matriz A.  M >= 0.  Cuando M = 0,
!>          CLANGE se establece en cero.
!>

N

!>          N es ENTERO
!>          El número de columnas de la matriz A.  N >= 0.  Cuando N = 0,
!>          CLANGE se establece en cero.
!>

A

!>          A es un array COMPLEJO, dimensión (LDA,N)
!>          La matriz A de m por n.
!>

LDA

!>          LDA es ENTERO
!>          La dimensión principal del array A.  LDA >= max(M,1).
!>

WORK

!>          WORK es un array REAL, dimensión (MAX(1,LWORK)),
!>          donde LWORK >= M cuando NORMA = 'I'; de lo contrario, WORK no se
!>          referencia.
!>
