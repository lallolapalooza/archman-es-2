función real cla_hercond_c (carácter uplo, entero n, complejo, dimensión( lda, * ) a, entero lda, complejo, dimensión( ldaf, * ) af, entero ldaf, entero, dimensión( * ) ipiv, real, dimensión( * ) c, lógico capply, entero info, complejo, dimensión( * ) work, real, dimensión( * ) rwork)

CLA_HERCOND_C calcula el número de condición de la norma infinito de op(A)*inv(diag(c)) para matrices hermíticas indefinidas.

Propósito:

!>
!>    CLA_HERCOND_C calcula el número de condición de la norma infinito de
!>    op(A) * inv(diag(C)) donde C es un vector REAL.
!>

Parámetros

UPLO 
!>          UPLO es CHARACTER*1
!>       = 'U':  El triángulo superior de A está almacenado;
!>       = 'L':  El triángulo inferior de A está almacenado.
!>

N

!>          N es INTEGER
!>     El número de ecuaciones lineales, es decir, el orden de la
!>     matriz A.  N >= 0.
!>

A

!>          A es un array COMPLEX, dimensión (LDA,N)
!>     En la entrada, la matriz N-por-N A
!>

LDA

!>          LDA es INTEGER
!>     La dimensión principal del array A.  LDA >= max(1,N).
!>

AF

!>          AF es un array COMPLEX, dimensión (LDAF,N)
!>     La matriz diagonal por bloques D y los multiplicadores utilizados para
!>     obtener el factor U o L tal como lo calcula CHETRF.
!>

LDAF

!>          LDAF es INTEGER
!>     La dimensión principal del array AF.  LDAF >= max(1,N).
!>

IPIV

!>          IPIV es un array INTEGER, dimensión (N)
!>     Detalles de los intercambios y la estructura de bloques de D
!>     tal como se determina por CHETRF.
!>

C

!>          C es un array REAL, dimensión (N)
!>     El vector C en la fórmula op(A) * inv(diag(C)).
!>

CAPPLY

!>          CAPPLY es LOGICAL
!>     Si es .TRUE. entonces se accede al vector C en la fórmula anterior.
!>

INFO

!>          INFO es INTEGER
!>       = 0:  Salida exitosa.
!>     i > 0:  El i-ésimo argumento es inválido.
!>

WORK

!>          WORK es un array COMPLEX, dimensión (2*N).
!>     Espacio de trabajo.
!>

RWORK

!>          RWORK es un array REAL, dimensión (N).
!>     Espacio de trabajo.
!>

DLA_SYRCOND estimates the Skeel condition number for a symmetric indefinite matrix.

Purpose:

!>
!>    DLA_SYRCOND estimates the Skeel condition number of  op(A) * op2(C)
!>    where op2 is determined by CMODE as follows
!>    CMODE =  1    op2(C) = C
!>    CMODE =  0    op2(C) = I
!>    CMODE = -1    op2(C) = inv(C)
!>    The Skeel condition number cond(A) = norminf( |inv(A)||A| )
!>    is computed by computing scaling factors R such that
!>    diag(R)*A*op2(C) is row equilibrated and computing the standard
!>    infinity-norm condition number.
!>

Parameters

UPLO 
!>          UPLO is CHARACTER*1
!>       = 'U':  Upper triangle of A is stored;
!>       = 'L':  Lower triangle of A is stored.
!>

N

!>          N is INTEGER
!>     The number of linear equations, i.e., the order of the
!>     matrix A.  N >= 0.
!>

A

!>          A is DOUBLE PRECISION array, dimension (LDA,N)
!>     On entry, the N-by-N matrix A.
!>

LDA

!>          LDA is INTEGER
!>     The leading dimension of the array A.  LDA >= max(1,N).
!>

AF

!>          AF is DOUBLE PRECISION array, dimension (LDAF,N)
!>     The block diagonal matrix D and the multipliers used to
!>     obtain the factor U or L as computed by DSYTRF.
!>

LDAF

!>          LDAF is INTEGER
!>     The leading dimension of the array AF.  LDAF >= max(1,N).
!>

IPIV

!>          IPIV is INTEGER array, dimension (N)
!>     Details of the interchanges and the block structure of D
!>     as determined by DSYTRF.
!>

CMODE

!>          CMODE is INTEGER

ZLA_HERCOND_C calcula el número de condición de la norma infinita de op(A)*inv(diag(c)) para matrices hermíticas indefinidas.

Propósito:

!>
!>    ZLA_HERCOND_C calcula el número de condición de la norma infinita de
!>    op(A) * inv(diag(C)) donde C es un vector de DOBLE PRECISIÓN.
!>

Parámetros

UPLO 
!>          UPLO es CHARACTER*1
!>       = 'U':  El triángulo superior de A está almacenado;
!>       = 'L':  El triángulo inferior de A está almacenado.
!>

N

!>          N es INTEGER
!>     El número de ecuaciones lineales, es decir, el orden de
!>     la matriz A.  N >= 0.
!>

A

!>          A es un array COMPLEX*16, de dimensión (LDA,N)
!>     En la entrada, la matriz N-por-N A
!>

LDA

!>          LDA es INTEGER
!>     La dimensión principal del array A.  LDA >= max(1,N).
!>

AF

!>          AF es un array COMPLEX*16, de dimensión (LDAF,N)
!>     La matriz diagonal por bloques D y los multiplicadores utilizados para
!>     obtener el factor U o L según lo calculado por ZHETRF.
!>

LDAF

!>          LDAF es INTEGER
!>     La dimensión principal del array AF.  LDAF >= max(1,N).
!>

IPIV

!>          IPIV es un array INTEGER, de dimensión (N)
!>     Detalles de los intercambios y la estructura de bloques de D
!>     según lo determinado por CHETRF.
!>

C

!>          C es un array DOUBLE PRECISION, de dimensión (N)
!>     El vector C en la fórmula op(A) * inv(diag(C)).
!>

CAPPLY

!>          CAPPLY es LOGICAL
!>     Si .TRUE. entonces accede al vector C en la fórmula anterior.
!>

INFO

!>          INFO es INTEGER
!>       = 0:  Salida exitosa.
!>     i > 0:  El i-ésimo argumento es inválido.
!>

WORK

!>          WORK es un array COMPLEX*16, de dimensión (2*N).
!>     Espacio de trabajo.
!>

RWORK

!>          RWORK es un array DOUBLE PRECISION, de dimensión (N).
!>     Espacio de trabajo.
!>
