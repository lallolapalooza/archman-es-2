subrutina claqr0 (logical wantt, logical wantz, integer n, integer ilo, integer ihi, complex, dimension( ldh, * ) h, integer ldh, complex, dimension( * ) w, integer iloz, integer ihiz, complex, dimension( ldz, * ) z, integer ldz, complex, dimension( * ) work, integer lwork, integer info)

CLAQR0 calcula los valores propios de una matriz de Hessenberg, y opcionalmente las matrices de la descomposición de Schur.

Propósito:

!>
!>    CLAQR0 calcula los valores propios de una matriz de Hessenberg H
!>    y, opcionalmente, las matrices T y Z de la descomposición de Schur
!>    H = Z T Z**H, donde T es una matriz triangular superior (la
!>    forma de Schur), y Z es la matriz unitaria de vectores de Schur.
!>
!>    Opcionalmente, Z puede ser premultiplicada por una matriz unitaria de entrada
!>    Q, de modo que esta subrutina pueda dar la factorización de Schur
!>    de una matriz A que ha sido reducida a la forma de Hessenberg H
!>    por la matriz unitaria Q:  A = Q*H*Q**H = (QZ)*H*(QZ)**H.
!>

Parámetros

WANTT 
!>          WANTT es LOGICAL
!>          = .TRUE. : se requiere la forma de Schur completa T;
!>          = .FALSE.: solo se requieren los valores propios.
!>

WANTZ

!>          WANTZ es LOGICAL
!>          = .TRUE. : se requiere la matriz de vectores de Schur Z;
!>          = .FALSE.: no se requieren vectores de Schur.
!>

N

!>          N es INTEGER
!>           El orden de la matriz H.  N >= 0.
!>

ILO

!>          ILO es INTEGER
!>

IHI

!>          IHI es INTEGER
!>           Se asume que H ya es triangular superior en las filas
!>           y columnas 1:ILO-1 e IHI+1:N y, si ILO > 1,
!>           H(ILO,ILO-1) es cero. ILO e IHI normalmente son establecidos por una
!>           llamada previa a CGEBAL, y luego pasados a CGEHRD cuando la
!>           matriz de salida de CGEBAL se reduce a la forma de Hessenberg.
!>           De lo contrario, ILO e IHI deben ser establecidos a 1 y N,
!>           respectivamente.  Si N > 0, entonces 1 <= ILO <= IHI <= N.
!>           Si N = 0, entonces ILO = 1 e IHI = 0.
!>

H

!>          H es array COMPLEX, dimension (LDH,N)
!>           En la entrada, la matriz de Hessenberg superior H.
!>           En la salida, si INFO = 0 y WANTT es .TRUE., entonces H
!>           contiene la matriz triangular superior T de la descomposición
!>           de Schur (la forma de Schur). Si INFO = 0 y WANT es
!>           .FALSE., entonces el contenido de H no está especificado en la salida.
!>           (El valor de salida de H cuando INFO > 0 se da bajo la
!>           descripción de INFO a continuación.)
!>
!>           Esta subrutina puede establecer explícitamente H(i,j) = 0 para i > j y
!>           j = 1, 2, ... ILO-1 o j = IHI+1, IHI+2, ... N.
!>

LDH

!>          LDH es INTEGER
!>           La dimensión principal del array H. LDH >= max(1,N).
!>

W

!>          W es array COMPLEX, dimension (N)
!>           Los valores propios calculados de H(ILO:IHI,ILO:IHI) se almacenan
!>           en W(ILO:IHI). Si WANTT es .TRUE., entonces los valores propios se
!>           almacenan en el mismo orden que en la diagonal de la forma de Schur
!>           devuelta en H, con W(i) = H(i,i).
!>

ILOZ

!>          ILOZ es INTEGER
!>

IHIZ

!>          IHIZ es INTEGER
!>           Especifican las filas de Z a las que se deben aplicar las
!>           transformaciones si WANTZ es .TRUE..
!>           1 <= ILOZ <= ILO; IHI <= IHIZ <= N.
!>

Z

!>          Z es array COMPLEX, dimension (LDZ,IHI)
!>           Si WANTZ es .FALSE., entonces Z no se referencia.
!>           Si WANTZ es .TRUE., entonces Z(ILO:IHI,ILOZ:IHIZ) se
!>           reemplaza por Z(ILO:IHI,ILOZ:IHIZ)*U donde U es el
!>           factor de Schur ortogonal de H(ILO:IHI,ILO:IHI).
!>           (El valor de salida de Z cuando INFO > 0 se da bajo
!>           la descripción de INFO a continuación.)
!>

LDZ

!>          LDZ es INTEGER
!>           La dimensión principal del array Z.  si WANTZ es .TRUE.
!>           entonces LDZ >= MAX(1,IHIZ).  De lo contrario, LDZ >= 1.
!>

WORK

!>          WORK es array COMPLEX, dimension LWORK
!>           En la salida, si LWORK = -1, WORK(1) devuelve una estimación de
!>           el valor óptimo para LWORK.
!>

LWORK

!>          LWORK es INTEGER
!>           La dimensión del array WORK.  LWORK >= max(1,N)
!>           es suficiente, pero LWORK típicamente hasta 6*N puede
!>           ser necesario para un rendimiento óptimo.  Se recomienda una consulta
!>           de espacio de trabajo para determinar el tamaño óptimo del espacio de trabajo.
!>
!>           Si LWORK = -1, entonces CLAQR0 realiza una consulta de espacio de trabajo.
!>           En este caso, CLAQR0 comprueba los parámetros de entrada y
!>           estima el tamaño óptimo del espacio de trabajo para los
!>           valores dados de N, ILO y IHI.  La estimación se devuelve
!>           en WORK(1).  XERBLA no emite ningún mensaje de error relacionado con LWORK.
!>           Ni H ni Z son accedidos.
!>

INFO

!>          INFO es INTEGER
!>             = 0:  salida exitosa
!>             > 0:  si INFO = i, CLAQR0 no pudo calcular todos los
!>                valores propios.  Los elementos 1:ilo-1 y i+1:n de WR
!>                y WI contienen aquellos valores propios que se han
!>                calculado con éxito.  (Los fallos son raros.)
!>
!>                Si INFO > 0 y WANT es .FALSE., entonces en la salida,
!>                los valores propios inconclusos restantes son los valores propios
!>                de la matriz de Hessenberg superior de filas
!>                y columnas ILO a INFO de la salida final
!>                valor de H.
!>
!>                Si INFO > 0 y WANTT es .TRUE., entonces en la salida
!>
!>           (*)  (valor inicial de H)*U  = U*(valor final de H)
!>
!>                donde U es una matriz unitaria.  El valor final
!>                de  H es de Hessenberg superior y triangular en
!>                filas y columnas INFO+1 a IHI.
!>
!>                Si INFO > 0 y WANTZ es .TRUE., entonces en la salida
!>
!>                  (valor final de Z(ILO:IHI,ILOZ:IHIZ)
!>                   =  (valor inicial de Z(ILO:IHI,ILOZ:IHIZ)*U
!>
!>                donde U es la matriz unitaria en (*) (independiente-
!>                mente del valor de WANTT.)
!>
!>                Si INFO > 0 y WANTZ es .FALSE., entonces Z no se
!>                accede.
!>

ZLAQR0 computes the eigenvalues of a Hessenberg matrix, and
optionally the matrices from the Schur decomposition.


Purpose:




!>
!>    SLAQR0 computes the eigenvalues of a Hessenberg matrix H
!>    and, optionally, the matrices T and Z from the Schur decomposition
!>    H = Z T Z**T, where T is an upper triangular matrix (the
!>    Schur form), and Z is the orthogonal matrix of Schur vectors.
!>
!>    Optionally Z may be postmultiplied into an input orthogonal
!>    matrix Q so that this routine can give the Schur factorization
!>    of a matrix A which has been reduced to the Hessenberg form H
!>    by the orthogonal matrix Q:  A = Q*H*Q**T = (QZ)*T*(QZ)**T.
!> 




Parameters


WANTT

!>          WANTT is LOGICAL
!>          = .TRUE. : the full Schur form T is required;
!>          = .FALSE.: only eigenvalues are required.
!> 


WANTZ


!>          WANTZ is LOGICAL
!>          = .TRUE. : the matrix of Schur vectors Z is required;
!>          = .FALSE.: Schur vectors are not required.
!> 


N


!>          N is INTEGER
!>           The order of the matrix H.  N >= 0.
!> 


ILO


!>          ILO is INTEGER
!> 


IHI


!>          IHI is INTEGER
!>           It is assumed that H is already upper triangular in rows
!>           and columns 1:ILO-1 and IHI+1:N and, if ILO > 1,
!>           H(ILO,ILO-1) is zero. ILO and IHI are normally set by a
!>           previous call to SGEBAL, and then passed to SGEHRD when the
!>           matrix output by SGEBAL is reduced to Hessenberg form.
!>           Otherwise, ILO and IHI should be set to 1 and N,
!>           respectively.  If N > 0, then 1 <= ILO <= IHI <= N.
!>           If N = 0, then ILO = 1 and IHI = 0.
!> 


H


!>          H is REAL array, dimension (LDH,N)
!>           On entry, the upper Hessenberg matrix H.
!>           On exit, if INFO = 0 and WANTT is .TRUE., then H contains
!>           the upper quasi-triangular matrix T from the Schur
!>           decomposition (the Schur form); 2-by-2 diagonal blocks
!>           (corresponding to complex conjugate pairs of eigenvalues)
!>           are returned in standard form, with H(i,i) = H(i+1,i+1)
!>           and H(i+1,i)*H(i,i+1) < 0. If INFO = 0 and WANTT is
!>           .FALSE., then the contents of H are unspecified on exit.
!>           (The output value of H when INFO > 0 is given under the
!>           description of INFO below.)
!>
!>           This subroutine may explicitly set H(i,j) = 0 for i > j and
!>           j = 1, 2, ... ILO-1 or j = IHI+1, IHI+2, ... N.
!> 


LDH


!>          LDH is INTEGER
!>           The leading dimension of the array H. LDH >= max(1,N).
!> 


WR


!>          WR is REAL array, dimension (IHI)
!> 


WI


!>          WI is REAL array, dimension (IHI)
!>           The real and imaginary parts, respectively, of the computed
!>           eigenvalues of H(ILO:IHI,ILO:IHI) are stored in WR(ILO:IHI)
!>           and WI(ILO:IHI). If two eigenvalues are computed as a
!>           complex conjugate pair, they are stored in consecutive
!>           elements of WR and WI, say the i-th and (i+1)th, with
!>           WI(i) > 0 and WI(i+1) < 0. If WANTT is .TRUE., then
!>           the eigenvalues are stored in the same order as on the
!>           diagonal of the Schur form returned in H, with
!>           WR(i) = H(i,i) and, if H(i:i+1,i:i+1) is a 2-by-2 diagonal
!>           block, WI(i) = sqrt(-H(i+1,i)*H(i,i+1)) and
!>           WI(i+1) = -WI(i).
!> 


ILOZ


!>          ILOZ is INTEGER
!> 


IHIZ


!>          IHIZ is INTEGER
!>           Specify the rows of Z to which transformations must be
!>           applied if WANTZ is .TRUE..
!>           1 <= ILOZ <= ILO; IHI <= IHIZ <= N.
!> 


Z


!>          Z is REAL array, dimension (LDZ,IHI)
!>           If WANTZ is .FALSE., then Z is not referenced.
!>           If WANTZ is .TRUE., then Z(ILO:IHI,ILOZ:IHIZ) is
!>           replaced by Z(ILO:IHI,ILOZ:IHIZ)*U where U is the
!>           orthogonal Schur factor of H(ILO:IHI,ILO:IHI).
!>           (The output value of Z when INFO > 0 is given under
!>           the description of INFO below.)
!> 


LDZ


!>          LDZ is INTEGER
!>           The leading dimension of the array Z.  if WANTZ is .TRUE.
!>           then LDZ >= MAX(1,IHIZ).  Otherwise, LDZ >= 1.
!> 


WORK


!>          WORK is REAL array, dimension LWORK
!>           On exit, if LWORK = -1, WORK(1) returns an estimate of
!>           the optimal value for LWORK.
!> 


LWORK


!>          LWORK is INTEGER
!>           The dimension of the array WORK.  LWORK >= max(1,N)
!>           is sufficient, but LWORK typically as large as 6*N may
!>           be required for optimal performance.  A workspace query
!>           to determine the optimal workspace size is recommended.
!>
!>           If LWORK = -1, then SLAQR0 does a workspace query.
!>           In this case, SLAQR0 checks the input parameters and
!>           estimates the optimal workspace size for the given
!>           values of N, ILO and IHI.  The estimate is returned
!>           in WORK(1).  No error message related to LWORK is
!>           issued by XERBLA.  Neither H nor Z are accessed.
!> 


INFO


!>          INFO is INTEGER
!>             = 0:  successful exit
!>             > 0:  if INFO = i, SLAQR0 failed to compute all of

ZLAQR0 computes the eigenvalues of a Hessenberg matrix, and optionally the matrices from the Schur decomposition.

Purpose:

!>
!>    ZLAQR0 computes the eigenvalues of a Hessenberg matrix H
!>    and, optionally, the matrices T and Z from the Schur decomposition
!>    H = Z T Z**H, where T is an upper triangular matrix (the
!>    Schur form), and Z is the unitary matrix of Schur vectors.
!>
!>    Optionally Z may be postmultiplied into an input unitary
!>    matrix Q so that this routine can give the Schur factorization
!>    of a matrix A which has been reduced to the Hessenberg form H
!>    by the unitary matrix Q:  A = Q*H*Q**H = (QZ)*H*(QZ)**H.
!>
