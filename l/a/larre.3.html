DLARRE dada la matriz tridiagonal T, establece elementos fuera de la diagonal pequeños a cero y para cada bloque no reducido Ti, encuentra representaciones base y valores propios.

Propósito:

!>
!> Para encontrar los valores propios deseados de una matriz dada
!> tridiagonal real simétrica T, DLARRE establece cualquier elemento
!> fuera de la diagonal a cero, y para cada bloque no reducido T_i,
!> encuentra (a) un desplazamiento adecuado en un extremo del espectro
!> del bloque, (b) la representación base, T_i - sigma_i I = L_i D_i L_i^T,
!> y (c) los valores propios de cada L_i D_i L_i^T.
!> Las representaciones y valores propios encontrados son utilizados por
!> DSTEMR para calcular los vectores propios de T.
!> La precisión varía dependiendo de si se utiliza la bisección para
!> encontrar unos pocos valores propios o el algoritmo dqds (subrutina DLASQ2)
!> para calcular todos y luego descartar los no deseados.
!> Como beneficio adicional, DLARRE también produce los n intervalos
!> de Gerschgorin para las matrices L_i D_i L_i^T.
!>

Parámetros

RANGE 
!>          RANGE es CHARACTER*1
!>          = 'A': ()   se encontrarán todos los valores propios.
!>          = 'V': () se encontrarán todos los valores propios en el intervalo
!>                           semiabierto (VL, VU].
!>          = 'I': () se encontrarán los valores propios del IL-ésimo al IU-ésimo
!>                           (de la matriz completa).
!>

N

!>          N es INTEGER
!>          El orden de la matriz. N > 0.
!>

VL

!>          VL es DOUBLE PRECISION
!>          Si RANGE='V', el límite inferior para los valores propios.
!>          Los valores propios menores o iguales a VL, o mayores que VU,
!>          no serán devueltos.  VL < VU.
!>          Si RANGE='I' o ='A', DLARRE calcula límites en la parte deseada
!>          del espectro.
!>

VU

!>          VU es DOUBLE PRECISION
!>          Si RANGE='V', el límite superior para los valores propios.
!>          Los valores propios menores o iguales a VL, o mayores que VU,
!>          no serán devueltos.  VL < VU.
!>          Si RANGE='I' o ='A', DLARRE calcula límites en la parte deseada
!>          del espectro.
!>

IL

!>          IL es INTEGER
!>          Si RANGE='I', el índice del
!>          valor propio más pequeño que será devuelto.
!>          1 <= IL <= IU <= N.
!>

IU

!>          IU es INTEGER
!>          Si RANGE='I', el índice del
!>          valor propio más grande que será devuelto.
!>          1 <= IL <= IU <= N.
!>

D

!>          D es array DOUBLE PRECISION, dimension (N)
!>          En la entrada, los N elementos diagonales de la matriz
!>          tridiagonal T.
!>          En la salida, los N elementos diagonales de las matrices
!>          diagonales D_i.
!>

E

!>          E es array DOUBLE PRECISION, dimension (N)
!>          En la entrada, las primeras (N-1) entradas contienen los
!>          elementos subdiagonales de la matriz tridiagonal T;
!>          E(N) no necesita ser establecido.
!>          En la salida, E contiene los elementos subdiagonales de las
!>          matrices bidiagonales unitarias L_i. Las entradas E( ISPLIT( I ) ),
!>          1 <= I <= NSPLIT, contienen los puntos base sigma_i en la salida.
!>

E2

!>          E2 es array DOUBLE PRECISION, dimension (N)
!>          En la entrada, las primeras (N-1) entradas contienen los CUADRADOS de los
!>          elementos subdiagonales de la matriz tridiagonal T;
!>          E2(N) no necesita ser establecido.
!>          En la salida, las entradas E2( ISPLIT( I ) ),
!>          1 <= I <= NSPLIT, han sido establecidas a cero
!>

RTOL1

!>          RTOL1 es DOUBLE PRECISION
!>

RTOL2

!>          RTOL2 es DOUBLE PRECISION
!>           Parámetros para la bisección.
!>           Un intervalo [LEFT,RIGHT] ha convergido si
!>           RIGHT-LEFT < MAX( RTOL1*GAP, RTOL2*MAX(|LEFT|,|RIGHT|) )
!>

SPLTOL

!>          SPLTOL es DOUBLE PRECISION
!>          El umbral para la división.
!>

NSPLIT

!>          NSPLIT es INTEGER
!>          El número de bloques en los que T se divide. 1 <= NSPLIT <= N.
!>

ISPLIT

!>          ISPLIT es array INTEGER, dimension (N)
!>          Los puntos de división, en los que T se divide en bloques.
!>          El primer bloque consiste en las filas/columnas 1 a ISPLIT(1),
!>          el segundo en las filas/columnas ISPLIT(1)+1 hasta ISPLIT(2),
!>          etc., y el NSPLIT-ésimo consiste en las filas/columnas
!>          ISPLIT(NSPLIT-1)+1 hasta ISPLIT(NSPLIT)=N.
!>

M

!>          M es INTEGER
!>          El número total de valores propios (de todos los L_i D_i L_i^T)
!>          encontrados.
!>

W

!>          W es array DOUBLE PRECISION, dimension (N)
!>          Las primeras M entradas contienen los valores propios. Los
!>          valores propios de cada uno de los bloques, L_i D_i L_i^T,
!>          están ordenados en orden ascendente (DLARRE puede usar las
!>          N-M entradas restantes como espacio de trabajo).
!>

WERR

!>          WERR es array DOUBLE PRECISION, dimension (N)
!>          El límite de error en el valor propio correspondiente en W.
!>

WGAP

!>          WGAP es array DOUBLE PRECISION, dimension (N)
!>          La separación del valor propio vecino derecho en W.
!>          La brecha es solo con respecto a los valores propios del mismo
!>          bloque, ya que cada bloque tiene su propio árbol de
!>          representación.
!>          Excepción: en el extremo derecho de un bloque, almacenamos la brecha
!>          izquierda
!>

IBLOCK

!>          IBLOCK es array INTEGER, dimension (N)
!>          Los índices de los bloques (submatrices)
REPORTING of the eigenvalues and their error bounds. !>

subroutine dlarre (character range, integer n, real vl, real vu, integer il, integer iu, real, dimension( * ) d, real, dimension( * ) e, real, dimension( * ) e2, real rtol1, real rtol2, real spltol, integer nsplit, integer, dimension( * ) isplit, integer m, real, dimension( * ) w, real, dimension( * ) werr, real, dimension( * ) wgap, integer, dimension( * ) iblock, integer, dimension( * ) indexw, real, dimension( * ) gers, real pivmin, real, dimension( * ) work, integer, dimension( * ) iwork, integer info)

DLARRE given the tridiagonal matrix T, sets small off-diagonal elements to zero and for each unreduced block Ti, finds base representations and eigenvalues.

Purpose:

!>
!> To find the desired eigenvalues of a given real symmetric
!> tridiagonal matrix T, DLARRE sets any off-diagonal
!> elements to zero, and for each unreduced block T_i, it finds
!> (a) a suitable shift at one end of the block's spectrum,
!> (b) the base representation, T_i - sigma_i I = L_i D_i L_i^T, and
!> (c) eigenvalues of each L_i D_i L_i^T.
!> The representations and eigenvalues found are then used by
!> DSTEMR to compute the eigenvectors of T.
!> The accuracy varies depending on whether bisection is used to
!> find a few eigenvalues or the dqds algorithm (subroutine DLASQ2) to
!> compute all and then discard any unwanted one.
!> As an added benefit, DLARRE also outputs the n
!> Gerschgorin intervals for the matrices L_i D_i L_i^T.
!>

Parameters

RANGE 
!>          RANGE is CHARACTER*1
!>          = 'A': ()   all eigenvalues will be found.
!>          = 'V': () all eigenvalues in the half-open interval
!>                           (VL, VU] will be found.
!>          = 'I': () the IL-th through IU-th eigenvalues (of the
!>                           entire matrix) will be found.
!>

N

!>          N is INTEGER
!>          The order of the matrix. N > 0.
!>

VL

!>          VL is DOUBLE PRECISION
!>          If RANGE='V', the lower bound for the eigenvalues.
!>          Eigenvalues less than or equal to VL, or greater than VU,
!>          will not be returned.  VL < VU.
!>          If RANGE='I' or ='A', DLARRE computes bounds on the desired
!>          part of the spectrum.
!>

VU

!>          VU is DOUBLE PRECISION
!>          If RANGE='V', the upper bound for the eigenvalues.
!>          Eigenvalues less than or equal to VL, or greater than VU,
!>          will not be returned.  VL < VU.
!>          If RANGE='I' or ='A', DLARRE computes bounds on the desired
!>          part of the spectrum.
!>

IL

!>          IL is INTEGER
!>          If RANGE='I', the index of the
!>          smallest eigenvalue to be returned.
!>          1 <= IL <= IU <= N.
!>

IU

!>          IU is INTEGER
!>          If RANGE='I', the index of the
!>          largest eigenvalue to be returned.
!>          1 <= IL <= IU <= N.
!>

D

!>          D is DOUBLE PRECISION array, dimension (N)
!>          On entry, the N diagonal elements of the tridiagonal
!>          matrix T.
!>          On exit, the N diagonal elements of the diagonal
!>          matrices D_i.
!>

E

!>          E is DOUBLE PRECISION array, dimension (N)
!>          On entry, the first (N-1) entries contain the subdiagonal
!>          elements of the tridiagonal matrix T; E(N) need not be set.
!>          On exit, E contains the subdiagonal elements of the unit
!>          bidiagonal matrices L_i. The entries E( ISPLIT( I ) ),
!>          1 <= I <= NSPLIT, contain the base points sigma_i on output.
!>

E2

!>          E2 is DOUBLE PRECISION array, dimension (N)
!>          On entry, the first (N-1) entries contain the SQUARES of the
!>          subdiagonal elements of the tridiagonal matrix T;
!>          E2(N) need not be set.
!>          On exit, the entries E2( ISPLIT( I ) ),
!>          1 <= I <= NSPLIT, have been set to zero
!>

RTOL1

!>          RTOL1 is DOUBLE PRECISION
!>

RTOL2

!>          RTOL2 is DOUBLE PRECISION
!>           Parameters for bisection.
!>           An interval [LEFT,RIGHT] has converged if
!>           RIGHT-LEFT < MAX( RTOL1*GAP, RTOL2*MAX(|LEFT|,|RIGHT|) )
!>

SPLTOL

!>          SPLTOL is DOUBLE PRECISION
!>          The threshold for splitting.
!>

NSPLIT

!>          NSPLIT is INTEGER
!>          The number of blocks T splits into. 1 <= NSPLIT <= N.
!>

ISPLIT

!>          ISPLIT is INTEGER array, dimension (N)
!>          The splitting points, at which T breaks up into blocks.
!>          The first block consists of rows/columns 1 to ISPLIT(1),
!>          the second of rows/columns ISPLIT(1)+1 through ISPLIT(2),
!>          etc., and the NSPLIT-th consists of rows/columns
!>          ISPLIT(NSPLIT-1)+1 through ISPLIT(NSPLIT)=N.
!>

M

!>          M is INTEGER
!>          The total number of eigenvalues (of all L_i D_i L_i^T)
!>          found.
!>

W

!>          W is DOUBLE PRECISION array, dimension (N)
!>          The first M elements contain the eigenvalues. The
!>          eigenvalues of each of the blocks, L_i D_i L_i^T, are
!>          sorted in ascending order ( DLARRE may use the
!>          remaining N-M elements as workspace).
!>

WERR

!>          WERR is DOUBLE PRECISION array, dimension (N)
!>          The error bound on the corresponding eigenvalue in W.
!>

WGAP

!>          WGAP is DOUBLE PRECISION array, dimension (N)
!>          The separation from the right neighbor eigenvalue in W.
!>          The gap is only with respect to the eigenvalues of the same block
!>          as each block has its own representation tree.
!>          Exception: at the right end of a block we store the left gap
!>

IBLOCK

!>          IBLOCK is INTEGER array, dimension (N)
!>          The indices of the blocks (submatrices) associated with the
!>          corresponding eigenvalues in W; IBLOCK(i)=1 if eigenvalue
!>          W(i) belongs to the first block from the top, =2 if W(i)
!>          belongs to the second block, etc.
!>

INDEXW

!>          INDEXW is INTEGER array, dimension (N)
!>          The indices of the eigenvalues within each block (submatrix);
!>          for example, INDEXW(i)= 10 and IBLOCK(i)=2 imply that the
!>          i-th eigenvalue W(i) is the 10-th eigenvalue in block 2
!>

GERS

!>          GERS is DOUBLE PRECISION array, dimension (2*N)
!>          The N Gerschgorin intervals (the i-th Gerschgorin interval
!>          is (GERS(2*i-1), GERS(2*i)).
!>

PIVMIN

!>          PIVMIN is DOUBLE PRECISION
!>          The minimum pivot in the Sturm sequence for T.
!>

WORK

!>          WORK is DOUBLE PRECISION array, dimension (6*N)
!>          Workspace.
!>

IWORK

!>          IWORK is INTEGER array, dimension (5*N)
!>          Workspace.
!>

INFO

!>          INFO is INTEGER
!>          = 0:  successful exit
!>          > 0:  A problem occurred in DLARRE.
!>          < 0:  One of the called subroutines signaled an internal problem.
!>                Needs inspection of the corresponding parameter IINFO
!>                for further information.
!>
!>          =-1:  Problem in DLARRD.
!>          = 2:  No base representation could be found in MAXTRY iterations.
!>                Increasing MAXTRY and recompilation might be a remedy.
!>          =-3:  Problem in DLARRB when computing the refined root
!>                representation for DLASQ2.
!>          =-4:  Problem in DLARRB when preforming bisection on the
!>                desired part of the spectrum.
!>          =-5:  Problem in DLASQ2.
!>          =-6:  Problem in DLASQ2.
!>

LARRE(3) LAPACK

NAME

LARRE - LAPACK routine for computing the 1-norm of a triangular matrix.

SYNOPSIS

  SUBROUTINE LARRE ( N, V, LDV, WORK, WORK2, INFO )
      
      INTEGER          N
      REAL             V( LDV, * )
      INTEGER          LDV
      REAL             WORK( * )
      REAL             WORK2( * )
      INTEGER          INFO

Detailed Description

LARRE computes the 1-norm of a triangular matrix A.

This routine is part of the LAPACK library.

!>  This subroutine computes the 1-norm of the matrix A, which is defined
!>  as the maximum absolute column sum of the matrix.
!>
!>  Arguments:
!>
!>  N:             The order of the matrix A. N >= 0.
!>
!>  V:             On entry, the matrix A.
!>                 On exit, V is overwritten with the result.
!>
!>  LDV:           The leading dimension of the array V. LDV >= max(1,N).
!>
!>  WORK:          Workspace array of size N.
!>
!>  WORK2:         Workspace array of size N.
!>
!>  INFO:          On exit, INFO = 0 if the subroutine completed successfully,
!>                 and INFO < 0 if an error occurred.
!>
!>  The 1-norm is computed as:
!>
!>     ||A||_1 = max_{j=1,...,n} sum_{i=1}^{n} |a_{ij}|
!>
!>  The algorithm used is based on the one described in:
!>
!>     R.B. Barnet, D.F. Griffiths, and M. W. Lewis,
!>     "A note on the 1-norm of a triangular matrix",
!>     ACM Trans. Math. Software 15 (1989), pp. 240-247.
!>
!>  The routine is designed to be efficient and accurate, especially for
!>  large matrices.
!>
!>  The computation involves two passes:
!>
!>  1. Compute the absolute values of the elements of A and store them in WORK.
!>     Then compute the column sums and store them in WORK.
!>
!>  2. Compute the maximum of the column sums in WORK.
!>
!>  The use of WORK2 is for potential future enhancements or alternative
!>  algorithms, but in the current implementation, it is not actively used.
!>
!>  Error handling:
!>  If N < 0, INFO is set to -1.
!>  If LDV < max(1,N), INFO is set to -2.
!>  Otherwise, INFO is set to 0 upon successful completion.
!>
!>  Example:
!>
!>     Consider the matrix A =
!>     [ 1.0  2.0 ]
!>     [ 3.0  4.0 ]
!>
!>     The 1-norm is max(|1.0|+|3.0|, |2.0|+|4.0|) = max(4.0, 6.0) = 6.0.
!>
