subrutina claic1 (integer job, integer j, complex, dimension( j ) x, real sest, complex, dimension( j ) w, complex gamma, real sestpr, complex s, complex c)

CLAIC1 aplica un paso de estimación de condición incremental.

Propósito

!>
!> CLAIC1 aplica un paso de estimación de condición incremental en
!> su versión más simple:
!>
!> Sea x, twonorm(x) = 1, un vector singular aproximado de una matriz triangular inferior j por j
!> L, tal que
!>          twonorm(L*x) = sest
!> Entonces CLAIC1 calcula sestpr, s, c tales que
!> el vector
!>                 [ s*x ]
!>          xhat = [  c  ]
!> es un vector singular aproximado de
!>                 [ L      0  ]
!>          Lhat = [ w**H gamma ]
!> en el sentido de que
!>          twonorm(Lhat*xhat) = sestpr.
!>
!> Dependiendo de JOB, se calcula una estimación del valor singular más grande o más pequeño.
!>
!> Nótese que [s c]**H y sestpr**2 es un par propio del sistema
!>
!>     diag(sest*sest, 0) + [alpha  gamma] * [ conjg(alpha) ]
!>                                           [ conjg(gamma) ]
!>
!> donde  alpha =  x**H*w.
!>

Parámetros

JOB 
!>          JOB es INTEGER
!>          = 1: se calcula una estimación del valor singular más grande.
!>          = 2: se calcula una estimación del valor singular más pequeño.
!>

J

!>          J es INTEGER
!>          Longitud de X y W
!>

X

!>          X es un array COMPLEX, dimensión (J)
!>          El vector j x.
!>

SEST

!>          SEST es REAL
!>          Valor singular estimado de la matriz L de j por j
!>

W

!>          W es un array COMPLEX, dimensión (J)
!>          El vector j w.
!>

GAMMA

!>          GAMMA es COMPLEX
!>          El elemento diagonal gamma.
!>

SESTPR

!>          SESTPR es REAL
!>          Valor singular estimado de la matriz Lhat de (j+1) por (j+1).
!>

S

!>          S es COMPLEX
!>          Seno necesario para formar xhat.
!>

C

!>          C es COMPLEX
!>          Coseno necesario para formar xhat.
!>
