subrutina claqhe (character uplo, integer n, complex, dimension( lda, * ) a, integer lda, real, dimension( * ) s, real scond, real amax, character equed)

CLAQHE escala una matriz Hermítica.

Propósito:

!>
!> CLAQHE equilibra una matriz Hermítica A usando los factores de escala
!> en el vector S.
!>

Parámetros

UPLO 
!>          UPLO es CHARACTER*1
!>          Especifica si la parte triangular superior o inferior de la
!>          matriz Hermítica A está almacenada.
!>          = 'U':  Triangular superior
!>          = 'L':  Triangular inferior
!>

N

!>          N es INTEGER
!>          El orden de la matriz A.  N >= 0.
!>

A

!>          A es arreglo COMPLEX, dimensión (LDA,N)
!>          En la entrada, la matriz Hermítica A.  Si UPLO = 'U', la parte
!>          superior de n por n de A contiene la parte triangular superior
!>          de la matriz A, y la parte estrictamente triangular inferior
!>          de A no se referencia. Si UPLO = 'L', la parte inferior de n por n
!>          de A contiene la parte triangular inferior de la matriz A, y la
!>          parte estrictamente triangular superior de A no se referencia.
!>
!>          En la salida, si EQUED = 'Y', la matriz equilibrada:
!>          diag(S) * A * diag(S).
!>

LDA

!>          LDA es INTEGER
!>          La dimensión principal del arreglo A.  LDA >= max(N,1).
!>

S

!>          S es arreglo REAL, dimensión (N)
!>          Los factores de escala para A.
!>

SCOND

!>          SCOND es REAL
!>          Relación entre el S(i) más pequeño y el S(i) más grande.
!>

AMAX

!>          AMAX es REAL
!>          Valor absoluto del elemento de matriz más grande.
!>

EQUED

!>          EQUED es CHARACTER*1
!>          Especifica si se realizó o no la equilibración.
!>          = 'N':  No se realizó equilibración.
!>          = 'Y':  Se realizó la equilibración, es decir, A ha sido reemplazada por
!>                  diag(S) * A * diag(S).
!>

Parámetros Internos:

!>  THRESH es un valor umbral utilizado para decidir si se debe realizar el escalado
!>  basado en la relación de los factores de escala.  Si SCOND < THRESH,
!>  se realiza el escalado.
!>
!>  LARGE y SMALL son valores umbral utilizados para decidir si se debe
!>  realizar el escalado basado en el tamaño absoluto del elemento de matriz más grande.
!>  Si AMAX > LARGE o AMAX < SMALL, se realiza el escalado.
!>

laqsy.f(3) - LAPACK - NVIDIA HPC SDK Documentation

NAME

laqsy.f

computes the L, D, and Q factors for the factorization of a symmetric indefinite matrix

SYNOPSIS

SUBROUTINE LAQSY(
    UPLO, N, A, LDA, S, SCOND, AMA X, EQUED, WORK, INFO
)
CHARACTER * 1 UPLO
INTEGER N, LDA, INFO
REAL * 8 A( LDA, * ), S( * ), SCOND, AMAX, WORK( * )
CHARACTER * 1 EQUED

laqsy.f
LDA is INTEGER
The leading dimension of the array A.
LDA >= max(N,1).

S is REAL * 8 array, dimension (N)
The scale factors for A.

SCOND is REAL * 8
Ratio of the smallest S(i) to the largest S(i).

AMAX is REAL * 8
Absolute value of largest matrix entry.

EQUED is CHARACTER * 1
Specifies whether or not equilibration was done.
= 'N': No equilibration.
= 'Y': Equilibration was done, i.e., A has been replaced by
diag(S) * A * diag(S).

WORK is REAL * 8 array, dimension (N)
Workspace.

INFO is INTEGER
= 0: successful exit
< 0: if INFO = -i, the i-th argument had an illegal value.
> 0: if INFO = i, the i-th diagonal element of the

Detailed Description

This routine is called by csytrf and zsytrf to compute the L, D, and Q factors for the factorization of a symmetric indefinite matrix. laqsy checks whether the symmetric matrix A is badly scaled. If so, laqsy is called by the driver routine csytrf or zsytrf to scale the matrix A. The scaling is done by computing a diagonal matrix S such that
S*A*S is close to the identity matrix.

Function Documentation

UPLO

UPLO is CHARACTER*1
Specifies whether the matrix A is upper or lower triangular.
= 'U': Upper triangular
= 'L': Lower triangular

N

N is INTEGER
The number of columns of the matrix A. N >= 0.

A

A is DOUBLE PRECISION array, dimension (LDA, N)
On entry, the N-by-N symmetric matrix A.
On exit, if EQUED = 'Y', the scaled matrix diag(S)*A*diag(S).
The leading n by n lower triangular part of A contains the lower
triangular part of the matrix A, and the strictly upper
triangular part of A is not referenced.

On exit, if EQUED = 'Y', the equilibrated matrix:
diag(S) * A * diag(S).

LDA

LDA is INTEGER
The leading dimension of the array A. LDA >= max(N,1).

S

S is DOUBLE PRECISION array, dimension (N)
The scale factors for A.

SCOND

SCOND is DOUBLE PRECISION
Ratio of the smallest S(i) to the largest S(i).

AMAX

AMAX is DOUBLE PRECISION
Absolute value of largest matrix entry.

EQUED

EQUED is CHARACTER*1
Specifies whether or not equilibration was done.
= 'N': No equilibration.
= 'Y': Equilibration was done, i.e., A has been replaced by
diag(S) * A * diag(S).

Internal Parameters:

THRESH is a threshold value used to decide if scaling should be done
based on the ratio of the scaling factors. If SCOND < THRESH,
scaling is done.

LARGE and SMALL are threshold values used to decide if scaling should
be done based on the absolute size of the largest matrix element.
If AMAX > LARGE or AMAX < SMALL, scaling is done.
