CLARZT forma el factor triangular T de un reflector de bloque complejo H = I - vtvH.

Propósito:

!>
!> CLARZT forma el factor triangular T de un reflector de bloque complejo
!> H de orden > n, que se define como un producto de k reflectores
!> elementales.
!>
!> Si DIRECT = 'F', H = H(1) H(2) . . . H(k) y T es triangular superior;
!>
!> Si DIRECT = 'B', H = H(k) . . . H(2) H(1) y T es triangular inferior.
!>
!> Si STOREV = 'C', el vector que define el reflector elemental
!> H(i) se almacena en la i-ésima columna de la matriz V, y
!>
!>    H  =  I - V * T * V**H
!>
!> Si STOREV = 'R', el vector que define el reflector elemental
!> H(i) se almacena en la i-ésima fila de la matriz V, y
!>
!>    H  =  I - V**H * T * V
!>
!> Actualmente, solo se admiten STOREV = 'R' y DIRECT = 'B'.
!>

Parámetros

DIRECT 
!>          DIRECT es CHARACTER*1
!>          Especifica el orden en el que se multiplican los reflectores
!>          elementales para formar el reflector de bloque:
!>          = 'F': H = H(1) H(2) . . . H(k) (Adelante, aún no soportado)
!>          = 'B': H = H(k) . . . H(2) H(1) (Atrás)
!>

STOREV

!>          STOREV es CHARACTER*1
!>          Especifica cómo se almacenan los vectores que definen los
!>          reflectores elementales (ver también Detalles adicionales):
!>          = 'C': por columnas (aún no soportado)
!>          = 'R': por filas
!>

N

!>          N es INTEGER
!>          El orden del reflector de bloque H. N >= 0.
!>

K

!>          K es INTEGER
!>          El orden del factor triangular T (= el número de reflectores
!>          elementales). K >= 1.
!>

V

!>          V es una matriz COMPLEX, de dimensión
!>                               (LDV,K) si STOREV = 'C'
!>                               (LDV,N) si STOREV = 'R'
!>          La matriz V. Ver detalles adicionales.
!>

LDV

!>          LDV es INTEGER
!>          La dimensión principal de la matriz V.
!>          Si STOREV = 'C', LDV >= max(1,N); si STOREV = 'R', LDV >= K.
!>

TAU

!>          TAU es una matriz COMPLEX, de dimensión (K)
!>          TAU(i) debe contener el factor escalar del reflector
!>          elemental H(i).
!>

T

!>          T es una matriz COMPLEX, de dimensión (LDT,K)
!>          El factor triangular T de k por k del reflector de bloque.
!>          Si DIRECT = 'F', T es triangular superior; si DIRECT = 'B', T es
!>          triangular inferior. El resto de la matriz no se utiliza.
!>

LDT

!>          LDT es INTEGER
!>          La dimensión principal de la matriz T. LDT >= K.
!>

DESCRIPTION


DLARZT forms the triangular factor T of a block reflector H
    = I - vtvH.


Purpose:




!>
!> DLARZT forms the triangular factor T of a real block reflector
!> H of order > n, which is defined as a product of k elementary
!> reflectors.
!>
!> If DIRECT = 'F', H = H(1) H(2) . . . H(k) and T is upper triangular;
!>
!> If DIRECT = 'B', H = H(k) . . . H(2) H(1) and T is lower triangular.
!>
!> If STOREV = 'C', the vector which defines the elementary reflector
!> H(i) is stored in the i-th column of the array V, and
!>
!>    H  =  I - V * T * V**T
!>
!> If STOREV = 'R', the vector which defines the elementary reflector
!> H(i) is stored in the i-th row of the array V, and
!>
!>    H  =  I - V**T * T * V
!>
!> Currently, only STOREV = 'R' and DIRECT = 'B' are supported.
!> 




Parameters


DIRECT

!>          DIRECT is CHARACTER*1
!>          Specifies the order in which the elementary reflectors are
!>          multiplied to form the block reflector:
!>          = 'F': H = H(1) H(2) . . . H(k) (Forward, not supported yet)
!>          = 'B': H = H(k) . . . H(2) H(1) (Backward)
!> 


STOREV


!>          STOREV is CHARACTER*1
!>          Specifies how the vectors which define the elementary
!>          reflectors are stored (see also Further Details):
!>          = 'C': columnwise                        (not supported yet)
!>          = 'R': rowwise
!> 


N


!>          N is INTEGER
!>          The order of the block reflector H. N >= 0.
!> 


K


!>          K is INTEGER
!>          The order of the triangular factor T (= the number of
!>          elementary reflectors). K >= 1.
!> 


V


!>          V is DOUBLE PRECISION array, dimension
!>                               (LDV,K) if STOREV = 'C'
!>                               (LDV,N) if STOREV = 'R'
!>          The matrix V. See further details.
!> 


LDV


!>          LDV is INTEGER
!>          The leading dimension of the array V.
!>          If STOREV = 'C', LDV >= max(1,N); if STOREV = 'R', LDV >= K.
!> 


TAU


!>          TAU is DOUBLE PRECISION array, dimension (K)
!>          TAU(i) must contain the scalar factor of the elementary
!>          reflector H(i).
!> 


T


!>          T is DOUBLE PRECISION array, dimension (LDT,K)
!>          The k by k triangular factor T of the block reflector.
!>          If DIRECT = 'F', T is upper triangular; if DIRECT = 'B', T is
!>          lower triangular. The rest of the array is not used.
!> 


LDT


!>          LDT is INTEGER
!>          The leading dimension of the array T. LDT >= K.
!>
