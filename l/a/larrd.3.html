DLARRD calcula los valores propios de una matriz tridiagonal simétrica con la precisión adecuada.

Propósito:

!>
!> DLARRD calcula los valores propios de una matriz tridiagonal
!> simétrica T con la precisión adecuada. Este es un código auxiliar que
!> se llama desde DSTEMR.
!> El usuario puede solicitar todos los valores propios, todos los valores
!> propios en el intervalo semiabierto (VL, VU], o los valores propios
!> del IL-ésimo al IU-ésimo.
!>
!> Para evitar el desbordamiento, la matriz debe escalarse de modo que su
!> elemento más grande no supere overflow**(1/2) * underflow**(1/4) en valor
!> absoluto, y para la máxima precisión, no debe ser mucho menor que eso.
!>
!> Véase W. Kahan, Report CS41, Computer Science Dept., Stanford
!> University, 21 de julio de 1966.
!>

!>                                Sturm sequence to be non-monotonic.
!>                        Cure:   recalculate, using RANGE='A', and pick
!>                                out eigenvalues IL:IU.  In some cases,
!>                                increasing the PARAMETER  may
!>                                make things work.

!>                        initially used was too small.  No eigenvalues

subroutine slarrd (character range, character order, integer n, real vl, real vu, integer il, integer iu, real, dimension( * ) gers, real reltol, real, dimension( * ) d, real, dimension( * ) e, real, dimension( * ) e2, real pivmin, integer nsplit, integer, dimension( * ) isplit, integer m, real, dimension( * ) w, real, dimension( * ) werr, real wl, real wu, integer, dimension( * ) iblock, integer, dimension( * ) indexw, real, dimension( * ) work, integer, dimension( * ) iwork, integer info)

SLARRD calcula los valores propios de una matriz tridiagonal simétrica con la precisión adecuada. Este es un código auxiliar que se llamará desde SSTEMR. El usuario puede solicitar todos los valores propios, todos los valores propios en el intervalo semiabierto (VL, VU], o los valores propios del IL-ésimo al IU-ésimo. Para evitar desbordamientos, la matriz debe escalarse para que su elemento más grande no exceda el valor absoluto de overflow**(1/2) * underflow**(1/4), y para una mayor precisión, no debe ser mucho menor que eso. Consulte W. Kahan, Informe CS41, Departamento de Ciencias de la Computación, Universidad de Stanford, 21 de julio de 1966.
