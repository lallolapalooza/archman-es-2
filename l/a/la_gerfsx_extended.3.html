CLA_GERFSX_EXTENDED

Propósito:

!>
!>
!> CLA_GERFSX_EXTENDED mejora la solución calculada de un sistema de
!> ecuaciones lineales realizando un refinamiento iterativo de precisión extra
!> y proporciona límites de error y estimaciones de error hacia atrás para la solución.
!> Esta subrutina es llamada por CGERFSX para realizar el refinamiento iterativo.
!> Además del límite de error normwise, el código proporciona el límite de error
!> componente a componente máximo si es posible. Consulte los comentarios para ERRS_N
!> y ERRS_C para obtener detalles sobre los límites de error. Tenga en cuenta que esta
!> subrutina solo es responsable de establecer los segundos campos de
!> ERRS_N y ERRS_C.
!>

Parámetros

PREC_TYPE 
!>          PREC_TYPE es INTEGER
!>     Especifica la precisión intermedia a utilizar en el refinamiento.
!>     El valor se define por ILAPREC(P) donde P es un CHARACTER y P
!>          = 'S':  Simple
!>          = 'D':  Doble
!>          = 'I':  Indígena
!>          = 'X' o 'E':  Extra
!>

TRANS_TYPE

!>          TRANS_TYPE es INTEGER
!>     Especifica la operación de transposición en A.
!>     El valor se define por ILATRANS(T) donde T es un CHARACTER y T
!>          = 'N':  Sin transposición
!>          = 'T':  Transpuesta
!>          = 'C':  Transpuesta conjugada
!>

N

!>          N es INTEGER
!>     El número de ecuaciones lineales, es decir, el orden de la
!>     matriz A.  N >= 0.
!>

NRHS

!>          NRHS es INTEGER
!>     El número de lados derechos, es decir, el número de columnas de la
!>     matriz B.
!>

A

!>          A es un array COMPLEX, dimensión (LDA,N)
!>     En la entrada, la matriz N por N A.
!>

LDA

!>          LDA es INTEGER
!>     La dimensión principal del array A.  LDA >= max(1,N).
!>

AF

!>          AF es un array COMPLEX, dimensión (LDAF,N)
!>     Los factores L y U de la factorización
!>     A = P*L*U calculada por CGETRF.
!>

LDAF

!>          LDAF es INTEGER
!>     La dimensión principal del array AF.  LDAF >= max(1,N).
!>

IPIV

!>          IPIV es un array INTEGER, dimensión (N)
!>     Los índices de pivote de la factorización A = P*L*U
!>     calculada por CGETRF; la fila i de la matriz fue intercambiada
!>     con la fila IPIV(i).
!>

COLEQU

!>          COLEQU es LOGICAL
!>     Si es .TRUE., se realizó una   equilibración de columnas en A antes de llamar
!>     a esta rutina. Esto es necesario para calcular la solución y los límites de error
!>     correctamente.
!>

C

!>          C es un array REAL, dimensión (N)
!>     Los factores de escala de columna para A. Si COLEQU = .FALSE., C
!>     no se accede. Si se introduce C, cada elemento de C debe ser una potencia
!>     de la base para garantizar una solución y estimaciones de error fiables.
!>     La escala por potencias de la base no causa errores de redondeo a menos
!>     que el resultado sea subdesbordado o sobredesbordado. Los errores de redondeo durante la escala
!>     conducen al refinamiento con una matriz que no es equivalente a la
!>     matriz de entrada, produciendo estimaciones de error que pueden no ser
!>     fiables.
!>

B

!>          B es un array COMPLEX, dimensión (LDB,NRHS)
!>     La matriz del lado derecho B.
!>

LDB

!>          LDB es INTEGER
!>     La dimensión principal del array B.  LDB >= max(1,N).
!>

Y

!>          Y es un array COMPLEX, dimensión (LDY,NRHS)
!>     En la entrada, la matriz solución X, calculada por CGETRS.
!>     En la salida, la matriz solución mejorada Y.
!>

LDY

!>          LDY es INTEGER
!>     La dimensión principal del array Y.  LDY >= max(1,N).
!>

BERR_OUT

!>          BERR_OUT es un array REAL, dimensión (NRHS)
!>     En la salida, BERR_OUT(j) contiene el error relativo hacia atrás componente a componente
!>     para el lado derecho j de la fórmula
!>         max(i) ( abs(RES(i)) / ( abs(op(A_s))*abs(Y) + abs(B_s) )(i) )
!>     donde abs(Z) es el valor absoluto componente a componente de la matriz
!>     o vector Z. Esto se calcula por CLA_LIN_BERR.
!>

N_NORMS

!>          N_NORMS es INTEGER
!>     Determina qué límites de error se devuelven (ver ERRS_N
!>     y ERRS_C).
!>     Si N_NORMS >= 1, se devuelven límites de error normwise.
!>     Si N_NORMS >= 2, se devuelven límites de error componente a componente.
!>

ERRS_N

!>          ERRS_N es un array REAL, dimensión (NRHS, N_ERR_BNDS)
!>     Para cada lado derecho, esta matriz contiene información sobre
!>     varios límites de error y números de condición correspondientes al
!>     error relativo normwise, que se define como sigue:
!>
!>     Error relativo normwise en el i-ésimo vector solución:
!>             max_j (abs(XTRUE(j,i) - X(j,i)))
!>            ----
-------------------------- !> max_j abs(X(j,i)) !> !> La matriz se indexa por el tipo de información de error descrita !> a continuación. Actualmente hay hasta tres piezas de información !> devueltas. !> !> El primer índice en ERRS_N(i,:) corresponde al i-ésimo !> lado derecho. !> !> El segundo índice en ERRS_N(:,err) contiene los siguientes !> tres campos: !> err = 1 booleano. Confiar en la respuesta si el !> número de condición recíproco es menor que el umbral !> sqrt(n) * slamch('Epsilon'). !> !> err = 2 cota de error: El error hacia adelante estimado, !> casi con certeza dentro de un factor de 10 del error real !> siempre que la siguiente entrada sea mayor que el umbral !> sqrt(n) * slamch('Epsilon'). Esta cota de error solo debe !> confiarse si el booleano anterior es verdadero. !> !> err = 3 Número de condición recíproco: Estimado normwise !> número de condición recíproco. Comparado con el umbral !> sqrt(n) * slamch('Epsilon') para determinar si la estimación !> del error es . Estos números de condición recíprocos !> son 1 / (norm(Z^{-1},inf) * norm(Z,inf)) para alguna !> matriz Z apropiadamente escalada. !> Sea Z = S*A, donde S escala cada fila por una potencia de la !> base para que todas las sumas de filas absolutas de Z sean !> aproximadamente 1. !> !> Esta subrutina solo es responsable de establecer el segundo campo !> anterior. !> Consulte Lapack Working Note 165 para más detalles y precauciones !> adicionales. !>

ERRS_C

!>          ERRS_C es una matriz REAL, de dimensión (NRHS, N_ERR_BNDS)
!>     Para cada lado derecho, esta matriz contiene información sobre
!>     varias cotas de error y números de condición correspondientes al
!>     error relativo componente a componente, que se define como sigue:
!>
!>     Error relativo componente a componente en el i-ésimo vector solución:
!>                    abs(XTRUE(j,i) - X(j,i))
!>             max_j ----------------------
!>                         abs(X(j,i))
!>
!>     La matriz se indexa por el lado derecho i (del cual depende el
!>     error relativo componente a componente), y el tipo de información
!>     de error como se describe a continuación. Actualmente hay hasta tres
!>     piezas de información devueltas para cada lado derecho. Si
!>     la precisión componente a componente no se solicita (PARAMS(3) = 0.0),
!>     entonces ERRS_C no se accede. Si N_ERR_BNDS < 3, entonces como máximo
!>     se devuelven las primeras (:,N_ERR_BNDS) entradas.
!>
!>     El primer índice en ERRS_C(i,:) corresponde al i-ésimo
!>     lado derecho.
!>
!>     El segundo índice en ERRS_C(:,err) contiene los siguientes
!>     tres campos:
!>     err = 1  booleano. Confiar en la respuesta si el
!>              número de condición recíproco es menor que el umbral
!>              sqrt(n) * slamch('Epsilon').
!>
!>     err = 2  cota de error: El error hacia adelante estimado,
!>              casi con certeza dentro de un factor de 10 del error real
!>              siempre que la siguiente entrada sea mayor que el umbral
!>              sqrt(n) * slamch('Epsilon'). Esta cota de error solo debe
!>              confiarse si el booleano anterior es verdadero.
!>
!>     err = 3  Número de condición recíproco: Estimado componente a
!>              componente del número de condición recíproco. Comparado con
!>              el umbral sqrt(n) * slamch('Epsilon') para determinar si la
!>              estimación del error es . Estos números de condición
!>              recíprocos son 1 / (norm(Z^{-1},inf) * norm(Z,inf)) para alguna
!>              matriz Z apropiadamente escalada.
!>              Sea Z = S*(A*diag(x)), donde x es la solución para el
!>              lado derecho actual y S escala cada fila de
!>              A*diag(x) por una potencia de la base para que todas las
!>              sumas de filas absolutas de Z sean aproximadamente 1.
!>
!>     Esta subrutina solo es responsable de establecer el segundo campo
!>     anterior.
!>     Consulte Lapack Working Note 165 para más detalles y precauciones
!>     adicionales.
!>

RES

!>          RES es una matriz COMPLEX, de dimensión (N)
!>     Espacio de trabajo para contener el residuo intermedio.
!>

AYB

!>          AYB es una matriz REAL, de dimensión (N)
!>     Espacio de trabajo.
!>

DY

!>          DY es una matriz COMPLEX, de dimensión (N)
!>     Espacio de trabajo para contener la solución intermedia.
!>

Y_TAIL

!>          Y_TAIL es una matriz COMPLEX, de dimensión (N)
!>     Espacio de trabajo para contener las partes finales de la solución intermedia.
!>

RCOND

!>          RCOND es REAL
!>     Número de condición escalado recíproco. Esta es una estimación del
!>     número de condición de Skeel recíproco de la matriz A después de
!>     la 
¡>     equilibración (si se realizó). Si es menor que la precisión de la
!>     máquina (en particular, si es cero), la matriz es singular
!>     a la precisión de trabajo. Tenga en cuenta que el error aún puede
!>     ser pequeño incluso si este número es muy pequeño y la matriz parece
!>     mal condicionada.
!>

ITHRESH

!>          ITHRESH es INTEGER
!>     El número máximo de cómputos de residuos permitidos para
!>     el refinamiento. El valor predeterminado es 10. Para 'agresivo'
!>     establecer en 100 para permitir la convergencia usando
!>     factorizaciones aproximadas o factorizaciones distintas de LU. Si la
!>     factorización utiliza una técnica distinta de la eliminación gaussiana,
!>     las garantías en ERRS_N y ERRS_C pueden ya no ser confiables.
!>

RTHRESH

!>          RTHRESH es REAL
!>     Determina cuándo detener el refinamiento si la estimación del error deja
!>     de disminuir. El refinamiento se detendrá cuando la siguiente solución ya no
!>     satisfaga norm(dx_{i+1}) < RTHRESH * norm(dx_i), donde norm(Z) es
!>     la norma infinito de Z. RTHRESH satisface 0 < RTHRESH <= 1. El
!>     valor predeterminado es 0.5. Para 'agresivo' establecer en 0.9 para permitir
!>     la convergencia en matrices extremadamente mal condicionadas. Consulte LAWN 165
!>     para más detalles.
!>

DZ_UB

!>          DZ_UB es REAL
!>     Determina cuándo comenzar a considerar la convergencia componente a
!>     componente. La convergencia componente a componente solo se considera
!>     después de que cada componente de la solución Y sea estable, lo que
!>     definimos como el cambio relativo en cada componente sea menor que DZ_UB.
!>     El valor predeterminado es 0.25, lo que requiere que el primer bit sea
!>     estable. Consulte LAWN 165 para más detalles.
!>

IGNORE_CWISE

!>          IGNORE_CWISE es LOGICAL
!>     Si es .TRUE., entonces ignorar la convergencia componente a
!>     componente. Valor predeterminado es .FALSE..
!>

INFO

!>          INFO es INTEGER
!>       = 0:  Salida exitosa.
!>       < 0:  Si INFO = -i, el i-ésimo argumento de CGETRS tuvo un valor
!>             ilegal.
!>

SUBROUTINE DLA_GERFSX_EXTENDED (PREC_TYPE, TRANS_TYPE, N, NRHS, A, LDA, AF, LDAF, IPIV, COLEQU, C, B, LDB, Y, LDY, BERR_OUT, N_NORMS, ERRS_N, ERRS_C, RES, AYB, DY, Y_TAIL, RCOND, ITHRESH, RTHRESH, DZ_UB, IGNORE_CWISE, INFO)

PREC_TYPE

PREC_TYPE es INTEGER
    Este parámetro indica la precisión numérica que se utilizará.
    PREC_TYPE = 0 para precisión simple.
    PREC_TYPE = 1 para precisión doble.

TRANS_TYPE

TRANS_TYPE es INTEGER
    Este parámetro indica el tipo de transposición que se utilizará.
    TRANS_TYPE = 0 para A.
    TRANS_TYPE = 1 para A^T.
    TRANS_TYPE = 2 para A^H.

N

N es INTEGER
    El orden de las ecuaciones lineales, es decir, el orden de la
    matriz A. N >= 0.

NRHS

NRHS es INTEGER
    El número de lados derechos, es decir, el número de columnas de la
    matriz B.

A

A es un array de DOUBLE PRECISION, dimensión (LDA,N)
    En la entrada, la matriz A de N por N.

LDA

LDA es INTEGER
    La dimensión principal del array A. LDA >= max(1,N).

AF

AF es un array de DOUBLE PRECISION, dimensión (LDAF,N)
    Los factores L y U de la factorización
    A = P*L*U calculados por DGETRF.

LDAF

LDAF es INTEGER
    La dimensión principal del array AF. LDAF >= max(1,N).

IPIV

IPIV es un array de INTEGER, dimensión (N)
    Los índices de pivote de la factorización A = P*L*U
    calculados por DGETRF; la fila i de la matriz fue intercambiada
    con la fila IPIV(i).

COLEQU

COLEQU es LOGICAL
    Si es .TRUE. entonces se realizó la equilibración de columnas a A antes de llamar
    a esta rutina. Esto es necesario para calcular la solución y los límites de error correctamente.

C

C es un array de DOUBLE PRECISION, dimensión (N)
    Los factores de escala de columna para A. Si COLEQU = .FALSE., C
    no se accede. Si C se proporciona como entrada, cada elemento de C debe ser una potencia
    de la base para asegurar una solución y estimaciones de error confiables.
    Escalar por potencias de la base no causa errores de redondeo a menos
    que el resultado tenga un desbordamiento inferior o superior. Los errores de redondeo durante el escalado
    llevan a refinar con una matriz que no es equivalente a la
    matriz de entrada, produciendo estimaciones de error que pueden no ser
    confiables.

B

B es un array de DOUBLE PRECISION, dimensión (LDB,NRHS)
    La matriz del lado derecho B.

LDB

LDB es INTEGER
    La dimensión principal del array B. LDB >= max(1,N).

Y

Y es un array de DOUBLE PRECISION, dimensión (LDY,NRHS)
    En la entrada, la matriz solución X, calculada por DGETRS.
    En la salida, la matriz solución mejorada Y.

LDY

LDY es INTEGER
    La dimensión principal del array Y. LDY >= max(1,N).

BERR_OUT

BERR_OUT es un array de DOUBLE PRECISION, dimensión (NRHS)
    En la salida, BERR_OUT(j) contiene el error relativo retroactivo componente a componente
    para el lado derecho j de la fórmula
    max(i) ( abs(RES(i)) / ( abs(op(A_s))*abs(Y) + abs(B_s) )(i) )
    donde abs(Z) es el valor absoluto componente a componente de la matriz
    o vector Z. Esto se calcula mediante DLA_LIN_BERR.

N_NORMS

N_NORMS es INTEGER
    Determina qué límites de error se devuelven (ver ERRS_N
    y ERRS_C).
    Si N_NORMS >= 1 devuelve límites de error normwise.
    Si N_NORMS >= 2 devuelve límites de error componente a componente.

ERRS_N

ERRS_N es un array de DOUBLE PRECISION, dimensión (NRHS, N_ERR_BNDS)
    Para cada lado derecho, este array contiene información sobre
    varios límites de error y números de condición correspondientes al
    error relativo normwise, que se define de la siguiente manera:
    Error relativo normwise en el i-ésimo vector solución:
            max_j (abs(XTRUE(j,i) - X(j,i)))
           ------------------------------
                 max_j abs(X(j,i))
    El array se indexa por el tipo de información de error como se describe
    a continuación. Actualmente hay hasta tres piezas de información
    devueltas.
    El primer índice en ERRS_N(i,:) corresponde al i-ésimo
    lado derecho.
    El segundo índice en ERRS_N(:,err) contiene los siguientes
    tres campos:
    err = 1  booleano. Confiar en la respuesta si el
             número de condición recíproco es menor que el umbral
             sqrt(n) * slamch('Epsilon').
    err = 2  límite de error: El error directo estimado,
             casi con certeza dentro de un factor de 10 del error real
             siempre que la siguiente entrada sea mayor que el umbral
             sqrt(n) * slamch('Epsilon'). Este límite de error solo debe
             confiarse si el booleano anterior es verdadero.
    err = 3  Número de condición recíproco: Normwise estimado
             número de condición recíproco. Comparado con el umbral
             sqrt(n) * slamch('Epsilon') para determinar si la estimación de error
             es . Estos números de condición recíprocos
             son 1 / (norm(Z^{-1},inf) * norm(Z,inf)) para alguna
             matriz Z apropiadamente escalada.
             Sea Z = S*A, donde S escala cada fila por una potencia de la
             base para que todas las sumas de valores absolutos de las filas de Z sean aproximadamente 1.
    Esta subrutina solo es responsable de establecer el segundo campo
    arriba.
    Ver Lapack Working Note 165 para más detalles y precauciones adicionales.

ERRS_C

ERRS_C es un array de DOUBLE PRECISION, dimensión (NRHS, N_ERR_BNDS)
    Para cada lado derecho, este array contiene información sobre
    varios límites de error y números de condición correspondientes al
    error relativo componente a componente, que se define de la siguiente manera:
    Error relativo componente a componente en el i-ésimo vector solución:
                   abs(XTRUE(j,i) - X(j,i))
            max_j ----------------------
                        abs(X(j,i))
    El array se indexa por el lado derecho i (del cual depende el
    error relativo componente a componente), y el tipo de información de error como se describe a continuación. Actualmente hay hasta tres

This subroutine is called by the routines like ZGESVX, ZPOSVX, etc. to compute the error bounds and condition number for the system of linear equations A*X = B.

Detailed Description

This routine is the central part of the extended error-bounding routines in LAPACK. It computes the norm-wise relative error bounds, component-wise relative error bounds, and reciprocal condition numbers for the solution X to the system of linear equations A*X = B.

The routine requires the input matrix A, its factored form AF, and the pivot indices IPIV. The right hand side B and the computed solution X are also required.

The routine returns:

  • FERR: norm-wise forward error estimate.
  • BERR: component-wise forward error estimate.
  • TIME: timing information for the routine.
  • PARAMS: parameters used in the computation.
  • ERRS_N: norm-wise error bounds and condition numbers.
  • ERRS_C: component-wise error bounds and condition numbers.
  • RCOND: reciprocal condition number.

The routine also uses several workspace arrays (WORK, IWORK, RES, AYB, DY, Y_TAIL) and accepts several tuning parameters (ITHRESH, RTHRESH, DZ_UB, IGNORE_CWISE).

The value of INFO indicates whether the routine completed successfully.
