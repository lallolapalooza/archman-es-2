subrutina classq (entero n, complejo(wp), dimensión(*) x, entero incx, real(wp) scale, real(wp) sumsq)

CLASSQ actualiza una suma de cuadrados representada en forma escalada.

Propósito:

!>
!> CLASSQ devuelve los valores scale_out y sumsq_out tales que
!>
!>    (scale_out**2)*sumsq_out = x( 1 )**2 +...+ x( n )**2 + (scale**2)*sumsq,
!>
!> donde x( i ) = X( 1 + ( i - 1 )*INCX ). Se asume que el valor de sumsq es
!> no negativo.
!>
!> scale y sumsq deben ser suministrados en SCALE y SUMSQ y
!> scale_out y sumsq_out se sobrescriben en SCALE y SUMSQ respectivamente.
!>
!>

Parámetros

N 
!>          N es ENTERO
!>          El número de elementos a utilizar del vector x.
!>

X

!>          X es un array COMPLEJO, dimensión (1+(N-1)*abs(INCX))
!>          El vector para el cual se calcula una suma de cuadrados escalada.
!>             x( i ) = X( 1 + ( i - 1 )*INCX ), 1 <= i <= n.
!>

INCX

!>          INCX es ENTERO
!>          El incremento entre valores sucesivos del vector x.
!>          Si INCX > 0, X(1+(i-1)*INCX) = x(i) para 1 <= i <= n
!>          Si INCX < 0, X(1-(n-i)*INCX) = x(i) para 1 <= i <= n
!>          Si INCX = 0, x no es un vector, por lo que no es necesario llamar
!>          a esta subrutina. Si la llama de todos modos, contará x(1)
!>          en la norma del vector N veces.
!>

SCALE

!>          SCALE es REAL
!>          En la entrada, el valor scale en la ecuación anterior.
!>          En la salida, SCALE se sobrescribe con scale_out, el factor de
!>          escalado para la suma de cuadrados.
!>

SUMSQ

!>          SUMSQ es REAL
!>          En la entrada, el valor sumsq en la ecuación anterior.
!>          En la salida, SUMSQ se sobrescribe con sumsq_out, la suma básica de
!>          cuadrados de la cual se ha extraído scale_out.
!>

lassq (3)


LAPACK manual






NAME


lassq - updates a sum of squares represented in scaled form.






SYNOPSIS


       SUBROUTINE SLASSQ( N, X, INCX, SCALE, SUMSQ )



       SUBROUTINE DLASSQ( N, X, INCX, SCALE, SUMSQ )



       SUBROUTINE CLASSQ( N, X, INCX, SCALE, SUMSQ )



       SUBROUTINE ZLASSQ( N, X, INCX, SCALE, SUMSQ )







Detailed Description


SLASSQ updates a sum of squares represented in scaled
    form.


Purpose:




!>
!>  SLASSQ returns the values scale_out and sumsq_out such that
!>
!>     (scale_out**2)*sumsq_out = x( 1 )**2 +...+ x( n )**2 + (scale**2)*sumsq,
!>
!>  where x( i ) = X( 1 + ( i - 1 )*INCX ). The value of sumsq is
!>  assumed to be non-negative.
!>
!>  scale and sumsq must be supplied in SCALE and SUMSQ and
!>  scale_out and sumsq_out are overwritten on SCALE and SUMSQ respectively.
!>





Parameters


N

!>          N is INTEGER
!>          The number of elements to be used from the vector x.



X


!>          X is REAL array, dimension (1+(N-1)*abs(INCX))
!>          The vector for which a scaled sum of squares is computed.
!>             x( i ) = X( 1 + ( i - 1 )*INCX ), 1 <= i <= n.



INCX


!>          INCX is INTEGER
!>          The increment between successive values of the vector x.
!>          If INCX > 0, X(1+(i-1)*INCX) = x(i) for 1 <= i <= n
!>          If INCX < 0, X(1-(n-i)*INCX) = x(i) for 1 <= i <= n
!>          If INCX = 0, x isn't a vector so there is no need to call
!>          this subroutine. If you call it anyway, it will count x(1)
!>          in the vector norm N times.



SCALE


!>          SCALE is REAL
!>          On entry, the value scale in the equation above.
!>          On exit, SCALE is overwritten by scale_out, the scaling factor
!>          for the sum of squares.



SUMSQ


!>          SUMSQ is REAL
!>          On entry, the value sumsq in the equation above.
!>          On exit, SUMSQ is overwritten by sumsq_out, the basic sum of
!>          squares from which scale_out has been factored out.
