función real clanhs (carácter norma, entero n, complejo, dimensión( lda, * ) a, entero lda, real, dimensión( * ) trabajo)

CLANHS devuelve el valor de la norma 1, norma de Frobenius, norma infinito, o el valor absoluto más grande de cualquier elemento de una matriz de Hessenberg superior.

Propósito:

!>
!> CLANHS  devuelve el valor de la norma uno,  o la norma de Frobenius, o
!> la  norma infinito,  o el  elemento de  valor absoluto más grande  de una
!> matriz de Hessenberg A.
!>

Devuelve

CLANHS 
!>
!>    CLANHS = ( max(abs(A(i,j))), NORMA = 'M' o 'm'
!>             (
!>             ( norm1(A),         NORMA = '1', 'O' o 'o'
!>             (
!>             ( normI(A),         NORMA = 'I' o 'i'
!>             (
!>             ( normF(A),         NORMA = 'F', 'f', 'E' o 'e'
!>
!> donde  norm1  denota la  norma uno de una matriz (suma máxima de columna),
!> normI  denota la  norma infinito  de una matriz  (suma máxima de fila) y
!> normF  denota la  norma de Frobenius de una matriz (raíz cuadrada de la suma de
!> cuadrados).  Tenga en cuenta que  max(abs(A(i,j)))  no es una norma matricial consistente.
!>

Parámetros

NORMA 
!>          NORMA es CHARACTER*1
!>          Especifica el valor a devolver en CLANHS como se describe
!>          arriba.
!>

N

!>          N es INTEGER
!>          El orden de la matriz A.  N >= 0.  Cuando N = 0, CLANHS se
!>          establece a cero.
!>

A

!>          A es un array COMPLEX, dimensión (LDA,N)
!>          La matriz de Hessenberg superior n por n A; la parte de A debajo de
!>          la primera subdiagonal no se referencia.
!>

LDA

!>          LDA es INTEGER
!>          La dimensión principal del array A.  LDA >= max(N,1).
!>

TRABAJO

!>          TRABAJO es un array REAL, dimensión (MAX(1,LWORK)),
!>          donde LWORK >= N cuando NORMA = 'I'; de lo contrario, TRABAJO no se
!>          referencia.
!>

NAME

DLANHS – returns the value of the 1-norm, Frobenius norm, infinity-norm, or the largest absolute value of any element of an upper Hessenberg matrix.

SYNOPSIS

  FUNCTION DLANHS(NORM, N, A, LDA, WORK)
  CHARACTER(*) :: NORM

  REAL, DIMENSION (LDA, *) :: A
  INTEGER :: LDA

  FUNCTION SLANHS(NORM, N, A, LDA, WORK)
  CHARACTER(*) :: NORM
  INTEGER :: N
  REAL, DIMENSION (LDA, *) :: A

  REAL, DIMENSION (*) :: WORK
  REAL :: SLANHS

  FUNCTION ZLANHS(NORM, N, A, LDA, WORK)
  CHARACTER(*) :: NORM
  INTEGER :: N
  COMPLEX*16, DIMENSION (LDA, *) :: A
  INTEGER :: LDA
  DOUBLE PRECISION, DIMENSION (*) :: WORK
  DOUBLE PRECISION :: ZLANHS

  FUNCTION CLANHS(NORM, N, A, LDA, WORK)
  CHARACTER(*) :: NORM
  INTEGER :: N
  COMPLEX, DIMENSION (LDA, *) :: A
  INTEGER :: LDA
  REAL, DIMENSION (*) :: WORK
  REAL :: CLANHS

Detailed Description

This routine is part of the LAPACK routines that compute matrix norms.

Purpose:

 DLANHS returns the value of the 1-norm, Frobenius norm, infinity-norm,
 or the largest absolute value of any element of an upper Hessenberg
 matrix.

Function Documentation

real function dlanhs (character norm, integer n, real, dimension( lda, * ) a, integer lda, real, dimension( * ) work)

DLANHS returns the value of the 1-norm, Frobenius norm, infinity-norm, or the largest absolute value of any element of an upper Hessenberg matrix.

Purpose:

!>
!> DLANHS  returns the value of the one norm,  or the Frobenius norm, or
!> the  infinity norm,  or the  element of  largest absolute value  of a
!> Hessenberg matrix A.
!>

Returns

DLANHS 
!>
!>    DLANHS = ( max(abs(A(i,j))), NORM = 'M' or 'm'
!>             (
!>             ( norm1(A),         NORM = '1', 'O' or 'o'
!>             (
!>             ( normI(A),         NORM = 'I' or 'i'
!>             (
!>             ( normF(A),         NORM = 'F', 'f', 'E' or 'e'
!>
!> where  norm1  denotes the  one norm of a matrix (maximum column sum),
!> normI  denotes the  infinity norm  of a matrix  (maximum row sum) and
!> normF  denotes the  Frobenius norm of a matrix (square root of sum of
!> squares).  Note that  max(abs(A(i,j)))  is not a consistent matrix norm.
!>

Parameters

NORM 
!>          NORM is CHARACTER*1
!>          Specifies the value to be returned in DLANHS as described
!>          above.
!>

N

!>          N is INTEGER
!>          The order of the matrix A.  N >= 0.  When N = 0, DLANHS is
!>          set to zero.
!>

A

!>          A is REAL array, dimension (LDA,N)
!>          The n by n upper Hessenberg matrix A; the part of A below the
!>          first sub-diagonal is not referenced.
!>

LDA

!>          LDA is INTEGER
!>          The leading dimension of the array A.  LDA >= max(N,1).
!>

WORK

!>          WORK is REAL array, dimension (MAX(1,LWORK)),
!>          where LWORK >= N when NORM = 'I'; otherwise, WORK is not
!>          referenced.
!>
