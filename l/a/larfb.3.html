CLARFB aplica un reflector de bloque H o su transpuesta conjugada H**H a una matriz rectangular general M por N C, desde la izquierda o la derecha.

Propósito:

!>
!> CLARFB aplica un reflector de bloque complejo H o su transpuesta conjugada H**H
!> a una matriz C compleja de M por N, desde la izquierda o la derecha.
!>

Parámetros

SIDE 
!>          SIDE es CHARACTER*1
!>          = 'L': aplicar H o H**H desde la Izquierda
!>          = 'R': aplicar H o H**H desde la Derecha
!>

TRANS

!>          TRANS es CHARACTER*1
!>          = 'N': aplicar H (Sin transpuesta)
!>          = 'C': aplicar H**H (Transpuesta conjugada)
!>

DIRECT

!>          DIRECT es CHARACTER*1
!>          Indica cómo se forma H a partir de un producto de
!>          reflectores elementales
!>          = 'F': H = H(1) H(2) . . . H(k) (Adelante)
!>          = 'B': H = H(k) . . . H(2) H(1) (Atrás)
!>

STOREV

!>          STOREV es CHARACTER*1
!>          Indica cómo se almacenan los vectores que definen los
!>          reflectores elementales:
!>          = 'C': Por columnas
!>          = 'R': Por filas
!>

M

!>          M es INTEGER
!>          El número de filas de la matriz C.
!>

N

!>          N es INTEGER
!>          El número de columnas de la matriz C.
!>

K

!>          K es INTEGER
!>          El orden de la matriz T (= el número de reflectores
!>          elementales cuyo producto define el reflector de bloque).
!>          Si SIDE = 'L', M >= K >= 0;
!>          si SIDE = 'R', N >= K >= 0.
!>

V

!>          V es array COMPLEX, dimensión
!>                                (LDV,K) si STOREV = 'C'
!>                                (LDV,M) si STOREV = 'R' y SIDE = 'L'
!>                                (LDV,N) si STOREV = 'R' y SIDE = 'R'
!>          La matriz V. Ver Detalles Adicionales.
!>

LDV

!>          LDV es INTEGER
!>          La dimensión principal del array V.
!>          Si STOREV = 'C' y SIDE = 'L', LDV >= max(1,M);
!>          Si STOREV = 'C' y SIDE = 'R', LDV >= max(1,N);
!>          Si STOREV = 'R', LDV >= K.
!>

T

!>          T es array COMPLEX, dimensión (LDT,K)
!>          La matriz triangular T de K por K en la representación del
!>          reflector de bloque.
!>

LDT

!>          LDT es INTEGER
!>          La dimensión principal del array T. LDT >= K.
!>

C

!>          C es array COMPLEX, dimensión (LDC,N)
!>          En la entrada, la matriz C de M por N.
!>          En la salida, C se sobrescribe con H*C o H**H*C o C*H o C*H**H.
!>

LDC

!>          LDC es INTEGER
!>          La dimensión principal del array C. LDC >= max(1,M).
!>

WORK

!>          WORK es array COMPLEX, dimensión (LDWORK,K)
!>

LDWORK

!>          LDWORK es INTEGER
!>          La dimensión principal del array WORK.
!>          Si SIDE = 'L', LDWORK >= max(1,N);
!>          Si SIDE = 'R', LDWORK >= max(1,M).
!>

LAPACK manual




Nombre


larfb — La rutina larfb aplica una
    transformación de bloque de Householder a una matriz.






Sinopsis


    SUBROUTINE LARFB( SIDE, TRANS, DIRECT, STOREV, M, N, K, V, LDV, T, LDT,
                       C, LDC, WORK, LDWORK )

        CHARACTER          SIDE, TRANS, DIRECT, STOREV
        INTEGER            M, N, K, LDV, LDT, LDC, LDWORK
        COMPLEX*16         V( LDV, * ), T( LDT, * ), C( LDC, * ), WORK( LDWORK, * )







Descripción detallada


LARFB aplica una transformación de bloque de Householder
    a una matriz.


Esta rutina se utiliza como paso de subtrama en las factorizaciones
    de matriz densa, como la factorización QR o la factorización de Cholesky.


LARFB es una rutina de nivel 3 BLAS.




Parámetros




SIDE


SIDE es CHARACTER*1


SIDE especifica si la transformación de bloque se aplica
    a la izquierda o a la derecha.


= 'L': aplica la transformación de bloque de la izquierda,
    es decir, H o HH*C.


= 'R': aplica la transformación de bloque de la derecha,
    es decir, C*H o C*HH.


= 'B': aplica la transformación de bloque de la izquierda y
    de la derecha.




TRANS


TRANS es CHARACTER*1


TRANS especifica si se aplica H o HH.


= 'N': aplica H.


= 'C': aplica HH.




DIRECT


DIRECT es CHARACTER*1


DIRECT especifica si los bloques de transformadores
    elementales se acumulan de izquierda a derecha o de derecha a izquierda.


= 'F': acumula de izquierda a derecha. H = H(1)*H(2)*...*H(K).


= 'B': acumula de derecha a izquierda. H = H(K)*...*H(2)*H(1).




STOREV


STOREV es CHARACTER*1


STOREV indica cómo se almacenan los vectores que definen
    los transformadores elementales:


= 'C': en columnas.


= 'R': en filas.




M


M es INTEGER


El número de filas de la matriz C.




N


N es INTEGER


El número de columnas de la matriz C.




K


K es INTEGER


El orden de la matriz T (= el número de transformadores elementales
    cuyo producto define el transformador de bloque).


Si SIDE = 'L', M >= K >= 0.


Si SIDE = 'R', N >= K >= 0.




V


V es un array COMPLEX*16, de dimensión




        (LDV,K) si STOREV = 'C'
        (LDV,M) si STOREV = 'R' y SIDE = 'L'
        (LDV,N) si STOREV = 'R' y SIDE = 'R'



Ver Detalles Adicionales.






LDV


LDV es INTEGER


La dimensión principal del array V.


Si STOREV = 'C' y SIDE = 'L', LDV >= max(1,M).


Si STOREV = 'C' y SIDE = 'R', LDV >= max(1,N).


Si STOREV = 'R', LDV >= K.




T


T es un array COMPLEX*16, de dimensión (LDT,K)


La matriz triangular T de K por K en la representación del
    transformador de bloque.




LDT


LDT es INTEGER


La dimensión principal de T. LDT >= K.




C


C es un array COMPLEX*16, de dimensión (LDC,N)


A la entrada, la matriz C de M por N.


A la salida, C se sobrescribe con H*C o HH*C o C*H o C*HH.




LDC


LDC es INTEGER


La dimensión principal de C. LDC >= max(1,M).




WORK


WORK es un array COMPLEX*16, de dimensión (LDWORK,K)




LDWORK


LDWORK es INTEGER


La dimensión principal de WORK.


Si SIDE = 'L', LDWORK >= max(1,N).


Si SIDE = 'R', LDWORK >= max(1,M).

        k = 3. La parte triangular de V (incluida su diagonal) no se
        referencia.

                          (  1 v2 v3 )                     ( v3 v3 v3 v3  1 )
