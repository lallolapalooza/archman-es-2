subrutina claev2 (complex a, complex b, complex c, real rt1, real rt2, real cs1, complex sn1)

CLAEV2 calcula los valores propios y vectores propios de una matriz hermitiana de 2x2.

Propósito:

!>
!> CLAEV2 calcula la eidendecomposición de una matriz Hermitiana de 2x2
!>    [  A         B  ]
!>    [  CONJG(B)  C  ].
!> Al regresar, RT1 es el valor propio de mayor valor absoluto, RT2 es el
!> valor propio de menor valor absoluto, y (CS1,SN1) es el vector propio
!> derecho unitario para RT1, dando la descomposición
!>
!> [ CS1  CONJG(SN1) ] [    A     B ] [ CS1 -CONJG(SN1) ] = [ RT1  0  ]
!> [-SN1     CS1     ] [ CONJG(B) C ] [ SN1     CS1     ]   [  0  RT2 ].
!>

Parámetros

A 
!>          A es COMPLEX
!>         El elemento (1,1) de la matriz de 2x2.
!>

B

!>          B es COMPLEX
!>         El elemento (1,2) y el conjugado del elemento (2,1) de
!>         la matriz de 2x2.
!>

C

!>          C es COMPLEX
!>         El elemento (2,2) de la matriz de 2x2.
!>

RT1

!>          RT1 es REAL
!>         El valor propio de mayor valor absoluto.
!>

RT2

!>          RT2 es REAL
!>         El valor propio de menor valor absoluto.
!>

CS1

!>          CS1 es REAL
!>

SN1

!>          SN1 es COMPLEX
!>         El vector (CS1, SN1) es un vector propio derecho unitario para RT1.
!>

Detalles Adicionales:

!>  RT1 es preciso a unas pocas ULP, salvo desbordamiento/subdesbordamiento.
!>
!>  RT2 puede ser impreciso si hay una cancelación masiva en el
!>  determinante A*C-B*B; se necesitaría aritmética de mayor precisión o
!>  redondeada correctamente o truncada correctamente para calcular RT2
!>  con precisión en todos los casos.
!>
!>  CS1 y SN1 son precisos a unas pocas ULP, salvo desbordamiento/subdesbordamiento.
!>
!>  El desbordamiento solo es posible si RT1 está a un factor de 5 del
!>  desbordamiento. El subdesbordamiento es inofensivo si los datos de
!>  entrada son 0 o exceden
!>     underflow_threshold / macheps.
!>

NAME


laev2 - computes the eigenvalues and eigenvectors of a 2-by-2
    real symmetric matrix.






SYNOPSIS


subroutine   slaev2(real a, real b, real c, real rt1, real rt2, real cs1, real sn1)
subroutine   dlaev2(double precision a, double precision b, double precision c, double precision rt1, double precision rt2, double precision cs1, double precision sn1)
subroutine   claev2(complex a, complex b, complex c, real rt1, real rt2, real cs1, complex sn1)
subroutine   zlaev2(complex*16 a, complex*16 b, complex*16 c, double precision rt1, double precision rt2, double precision cs1, complex*16 sn1)







Detailed Description


This subroutine computes the eigenvalues and eigenvectors of a
    2-by-2 real symmetric or complex Hermitian matrix.


The function `slaev2` computes the eigenvalues and eigenvectors for
    a 2x2 real symmetric matrix.




!>
!> SLAEV2 computes the eigendecomposition of a 2-by-2 symmetric matrix
!>    [ A  B ]
!>    [ B  C ].
!> On return, RT1 is the eigenvalue of larger absolute value, RT2 is the
!> eigenvalue of smaller absolute value, and (CS1,SN1) is the unit right
!> eigenvector for RT1, giving the decomposition
!>
!> [ CS1  -SN1 ] [ A B ] [ CS1 SN1 ] = [ RT1  0  ]
!> [ SN1   CS1 ] [ B C ] [ -SN1 CS1 ]   [  0  RT2 ].
!> 




The function `dlaev2` is the double precision version of `slaev2`.


The function `claev2` computes the eigenvalues and eigenvectors for
    a 2x2 complex matrix.




!>
!> CLAEV2 computes the eigendecomposition of a 2-by-2 Hermitian matrix
!>    [  A     B  ]
!>    [ CONJG(B) C ].
!> On return, RT1 is the eigenvalue of larger absolute value, RT2 is the
!> eigenvalue of smaller absolute value, and (CS1,SN1) is the unit right
!> eigenvector for RT1, giving the decomposition
!>
!> [ CS1  CONJG(SN1) ] [    A     B ] [ CS1 -CONJG(SN1) ] = [ RT1  0  ]
!> [-SN1     CS1     ] [ CONJG(B) C ] [ SN1     CS1     ]   [  0  RT2 ].
!> 




The function `zlaev2` is the double precision version of `claev2`.




subroutine slaev2 (real a, real b, real c, real rt1, real rt2, real cs1, real sn1)


SLAEV2 computes the eigenvalues and eigenvectors of a
    2-by-2 real symmetric matrix.


Purpose:




!>
!> SLAEV2 computes the eigendecomposition of a 2-by-2 symmetric matrix
!>    [ A  B ]
!>    [ B  C ].
!> On return, RT1 is the eigenvalue of larger absolute value, RT2 is the
!> eigenvalue of smaller absolute value, and (CS1,SN1) is the unit right
!> eigenvector for RT1, giving the decomposition
!>
!> [ CS1  -SN1 ] [ A B ] [ CS1 SN1 ] = [ RT1  0  ]
!> [ SN1   CS1 ] [ B C ] [ -SN1 CS1 ]   [  0  RT2 ].
!> 




Parameters


A

!>          A is REAL
!>         The (1,1) element of the 2-by-2 matrix.
!> 


B


!>          B is REAL
!>         The (1,2) and (2,1) elements of the 2-by-2 matrix.
!> 


C


!>          C is REAL
!>         The (2,2) element of the 2-by-2 matrix.
!> 


RT1


!>          RT1 is REAL
!>         The eigenvalue of larger absolute value.
!> 


RT2


!>          RT2 is REAL
!>         The eigenvalue of smaller absolute value.
!> 


CS1


!>          CS1 is REAL
!> 


SN1


!>          SN1 is REAL
!>         The vector (CS1, SN1) is a unit right eigenvector for RT1.
!> 




Author


Univ. of Tennessee

Univ. of California Berkeley


Univ. of Colorado Denver


NAG Ltd.




Further Details:




!>
!>  RT1 is accurate to a few ulps barring over/underflow.
!>
!>  RT2 may be inaccurate if there is massive cancellation in the
!>  determinant A*C-B*B; higher precision or correctly rounded or
!>  correctly truncated arithmetic would be needed to compute RT2
!>  accurately in all cases.
!>
!>  CS1 and SN1 are accurate to a few ulps barring over/underflow.
!>
!>  Overflow is possible only if RT1 is within a factor of 5 of overflow.
!>  Underflow is harmless if the input data is 0 or exceeds
!>     underflow_threshold / macheps.
!>
