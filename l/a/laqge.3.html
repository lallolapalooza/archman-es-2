subrutina claqge (integer m, integer n, complex, dimension( lda, * ) a, integer lda, real, dimension( * ) r, real, dimension( * ) c, real rowcnd, real colcnd, real amax, character equed)

CLAQGE escala una matriz rectangular general, utilizando factores de escala de fila y columna calculados por sgeequ.

Propósito:

!>
!> CLAQGE equilibra una matriz general M por N, A, utilizando los factores de
!> escala de fila y columna en los vectores R y C.
!>

Parámetros

M 
!>          M es ENTERO
!>          El número de filas de la matriz A.  M >= 0.
!>

N

!>          N es ENTERO
!>          El número de columnas de la matriz A.  N >= 0.
!>

A

!>          A es un array de tipo COMPLEX, de dimensión (LDA,N)
!>          En la entrada, la matriz A de M por N.
!>          En la salida, la matriz equilibrada. Ver EQUED para la forma de
!>          la matriz equilibrada.
!>

LDA

!>          LDA es ENTERO
!>          La dimensión principal del array A.  LDA >= max(M,1).
!>

R

!>          R es un array de tipo REAL, de dimensión (M)
!>          Los factores de escala de fila para A.
!>

C

!>          C es un array de tipo REAL, de dimensión (N)
!>          Los factores de escala de columna para A.
!>

ROWCND

!>          ROWCND es REAL
!>          Razón del R(i) más pequeño al R(i) más grande.
!>

COLCND

!>          COLCND es REAL
!>          Razón del C(i) más pequeño al C(i) más grande.
!>

AMAX

!>          AMAX es REAL
!>          Valor absoluto de la entrada más grande de la matriz.
!>

EQUED

!>          EQUED es CHARACTER*1
!>          Especifica la forma de equilibrado que se realizó.
!>          = 'N':  Sin equilibrado
!>          = 'R':  Equilibrado de filas, es decir, A ha sido premultiplicada
!>                  por diag(R).
!>          = 'C':  Equilibrado de columnas, es decir, A ha sido postmultiplicada
!>                  por diag(C).
!>          = 'B':  Equilibrado tanto de filas como de columnas, es decir, A ha sido
!>                  reemplazada por diag(R) * A * diag(C).
!>

Parámetros Internos:

!>  THRESH es un valor umbral utilizado para decidir si se debe realizar el
!>  escalado de filas o columnas basándose en la razón de los factores de
!>  escala de fila o columna.  Si ROWCND < THRESH, se realiza el escalado de
!>  filas, y si COLCND < THRESH, se realiza el escalado de columnas.
!>
!>  LARGE y SMALL son valores umbral utilizados para decidir si se debe
!>  realizar el escalado de filas basándose en el tamaño absoluto del elemento
!>  más grande de la matriz.  Si AMAX > LARGE o AMAX < SMALL, se realiza el
!>  escalado de filas.
!>

NAME

laqge - Scales a general rectangular matrix

SYNOPSIS

subroutine   slaqge (integer m, integer n, real, dimension( lda, * ) a, integer lda, real,
          dimension( * ) r, real, dimension( * ) c, real rowcnd, real colcnd, real amax,
          character equed)
subroutine   zlaqge (integer m, integer n, complex*16, dimension( lda, * ) a, integer lda,
          double precision, dimension( * ) r, double precision, dimension( * ) c, double
          precision rowcnd, double precision colcnd, double precision amax, character
          equed)

Detailed Description

SLAQGE scales a general rectangular matrix, using row and column scaling factors computed by sgeequ.

Purpose:

!>
!> SLAQGE equilibrates a general M by N matrix A using the row and
!> column scaling factors in the vectors R and C.
!>

Parameters

M 
!>          M is INTEGER
!>          The number of rows of the matrix A.  M >= 0.
!>

N

!>          N is INTEGER
!>          The number of columns of the matrix A.  N >= 0.
!>

A

!>          A is REAL array, dimension (LDA,N)
!>          On entry, the M by N matrix A.
!>          On exit, the equilibrated matrix.  See EQUED for the form of
!>          the equilibrated matrix.
!>

LDA

!>          LDA is INTEGER
!>          The leading dimension of the array A.  LDA >= max(M,1).
!>

R

!>          R is REAL array, dimension (M)
!>          The row scale factors for A.
!>

C

!>          C is REAL array, dimension (N)
!>          The column scale factors for A.
!>

ROWCND

!>          ROWCND is REAL
!>          Ratio of the smallest R(i) to the largest R(i).
!>

COLCND

!>          COLCND is REAL
!>          Ratio of the smallest C(i) to the largest C(i).
!>

AMAX

!>          AMAX is REAL
!>          Absolute value of largest matrix entry.
!>

EQUED

!>          EQUED is CHARACTER*1
!>          Specifies the form of equilibration that was done.
!>          = 'N':  No equilibration
!>          = 'R':  Row equilibration, i.e., A has been premultiplied by
!>                  diag(R).
!>          = 'C':  Column equilibration, i.e., A has been postmultiplied
!>                  by diag(C).
!>          = 'B':  Both row and column equilibration, i.e., A has been
!>                  replaced by diag(R) * A * diag(C).
!>

Internal Parameters:

!>  THRESH is a threshold value used to decide if row or column scaling
!>  should be done based on the ratio of the row or column scaling
!>  factors.  If ROWCND < THRESH, row scaling is done, and if
!>  COLCND < THRESH, column scaling is done.
!>
!>  LARGE and SMALL are threshold values used to decide if row scaling
!>  should be done based on the absolute size of the largest matrix
!>  element.  If AMAX > LARGE or AMAX < SMALL, row scaling is done.
!>
