subrutina clascl (carácter type, entero kl, entero ku, real cfrom, real cto, entero m, entero n, complejo, dimensión( lda, * ) a, entero lda, entero info)

CLASCL multiplica la matriz compleja M por N, A, por el escalar real CTO/CFROM. Esto se hace sin desbordamiento superior/inferior, siempre que el resultado final CTO*A(I,J)/CFROM no se desborde.

Propósito:

!>
!> CLASCL multiplica la matriz compleja M por N, A, por el escalar real
!> CTO/CFROM. Esto se hace sin desbordamiento superior/inferior, siempre que
!> el resultado final CTO*A(I,J)/CFROM no se desborde. TYPE especifica que
!> A puede ser completa, triangular superior, triangular inferior,
!> upper Hessenberg o banda.
!>

Parámetros

TYPE 
!>          TYPE es CHARACTER*1
!>          TYPE indexa el tipo de almacenamiento de la matriz de entrada.
!>          = 'G':  A es una matriz completa.
!>          = 'L':  A es una matriz triangular inferior.
!>          = 'U':  A es una matriz triangular superior.
!>          = 'H':  A es una matriz upper Hessenberg.
!>          = 'B':  A es una matriz de banda simétrica con ancho de banda
!>                  inferior KL y ancho de banda superior KU y con solo la
!>                  mitad inferior almacenada.
!>          = 'Q':  A es una matriz de banda simétrica con ancho de banda
!>                  inferior KL y ancho de banda superior KU y con solo la
!>                  mitad superior almacenada.
!>          = 'Z':  A es una matriz de banda con ancho de banda inferior KL
!>                  y ancho de banda superior KU. Consulte CGBTRF para
!>                  detalles de almacenamiento.
!>

KL

!>          KL es INTEGER
!>          El ancho de banda inferior de A. Se referencia solo si TYPE = 'B',
!>          'Q' o 'Z'.
!>

KU

!>          KU es INTEGER
!>          El ancho de banda superior de A. Se referencia solo si TYPE = 'B',
!>          'Q' o 'Z'.
!>

CFROM

!>          CFROM es REAL
!>

CTO

!>          CTO es REAL
!>
!>          La matriz A se multiplica por CTO/CFROM. A(I,J) se calcula
!>          sin desbordamiento superior/inferior si el resultado final
!>          CTO*A(I,J)/CFROM puede representarse sin desbordamiento
!>          superior/inferior. CFROM debe ser distinto de cero.
!>

M

!>          M es INTEGER
!>          El número de filas de la matriz A. M >= 0.
!>

N

!>          N es INTEGER
!>          El número de columnas de la matriz A. N >= 0.
!>

A

!>          A es un array COMPLEJO, dimensión (LDA,N)
!>          La matriz a multiplicar por CTO/CFROM. Consulte TYPE para el
!>          tipo de almacenamiento.
!>

LDA

!>          LDA es INTEGER
!>          La dimensión principal del array A.
!>          Si TYPE = 'G', 'L', 'U', 'H', LDA >= max(1,M);
!>             TYPE = 'B', LDA >= KL+1;
!>             TYPE = 'Q', LDA >= KU+1;
!>             TYPE = 'Z', LDA >= 2*KL+KU+1.
!>

INFO

!>          INFO es INTEGER
!>          0  - salida exitosa
!>          <0 - si INFO = -i, el argumento i-ésimo tenía un valor ilegal.
!>
