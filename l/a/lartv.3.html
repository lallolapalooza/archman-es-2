DOCUMENTACIÓN DE LA FUNCIÓN

subrutina clartv (integer n, complex, dimension( * ) x, integer incx, complex, dimension( * ) y, integer incy, real, dimension( * ) c, complex, dimension( * ) s, integer incc)

CLARTV aplica un vector de rotaciones de plano complejas con cosenos reales a los elementos de los vectores complejos x e y.

Propósito:

!>
!> CLARTV aplica un vector de rotaciones de plano complejas con cosenos reales
!> a los elementos de los vectores complejos x e y. Para i = 1,2,...,n
!>
!>    ( x(i) ) := (        c(i)   s(i) ) ( x(i) )
!>    ( y(i) )    ( -conjg(s(i))  c(i) ) ( y(i) )
!>

Parámetros

N 
!>          N es INTEGER
!>          El número de rotaciones de plano a aplicar.
!>

X

!>          X es un array COMPLEX, dimension (1+(N-1)*INCX)
!>          El vector x.
!>

INCX

!>          INCX es INTEGER
!>          El incremento entre elementos de X. INCX > 0.
!>

Y

!>          Y es un array COMPLEX, dimension (1+(N-1)*INCY)
!>          El vector y.
!>

INCY

!>          INCY es INTEGER
!>          El incremento entre elementos de Y. INCY > 0.
!>

C

!>          C es un array REAL, dimension (1+(N-1)*INCC)
!>          Los cosenos de las rotaciones de plano.
!>

S

!>          S es un array COMPLEX, dimension (1+(N-1)*INCC)
!>          Los senos de las rotaciones de plano.
!>

INCC

!>          INCC es INTEGER
!>          El incremento entre elementos de C y S. INCC > 0.
!>
