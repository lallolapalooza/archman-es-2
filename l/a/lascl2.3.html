Documentación de la Función

subrutina clascl2 (integer m, integer n, real, dimension( * ) d, complex, dimension( ldx, * ) x, integer ldx)

CLASCL2 realiza el escalado diagonal de una matriz.

Propósito:

!>
!> CLASCL2 realiza un escalado diagonal en una matriz:
!>   x <-- D * x
!> donde la matriz REAL diagonal D se almacena como una matriz.
!>
!> Eventualmente será reemplazada por BLAS_cge_diag_scale en el nuevo
!> estándar BLAS.
!>

Parámetros

M 
!>          M es INTEGER
!>     El número de filas de D y X. M >= 0.
!>

N

!>          N es INTEGER
!>     El número de columnas de X. N >= 0.
!>

D

!>          D es un array REAL, longitud M
!>     Matriz diagonal D, almacenada como un vector de longitud M.
!>

X

!>          X es un array COMPLEX, dimensión (LDX,N)
!>     En la entrada, la matriz X a escalar por D.
!>     En la salida, la matriz escalada.
!>

LDX

!>          LDX es INTEGER
!>     La dimensión principal de la matriz X. LDX >= M.
!>
