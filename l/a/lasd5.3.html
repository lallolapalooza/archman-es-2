subrutina dlasd5 (integer i, double precision, dimension( 2 ) d, double precision, dimension( 2 ) z, double precision, dimension( 2 ) delta, double precision rho, double precision dsigma, double precision, dimension( 2 ) work)

DLASD5 calcula la raíz cuadrada de la i-ésima eigenvalue de una modificación positiva simétrica de rango uno de una matriz diagonal de 2x2. Usada por sbdsdc.

Propósito:

!>
!> Esta subrutina calcula la raíz cuadrada de la I-ésima eigenvalue
!> de una modificación positiva simétrica de rango uno de una matriz diagonal
!> de 2x2
!>
!>            diag( D ) * diag( D ) +  RHO * Z * transpuesta(Z) .
!>
!> Se asume que las entradas diagonales en el array D satisfacen
!>
!>            0 <= D(i) < D(j)  para  i < j .
!>
!> También asumimos RHO > 0 y que la norma euclidiana del vector
!> Z es uno.
!>

Parámetros

I 
!>          I es INTEGER
!>         El índice de la eigenvalue a calcular.  I = 1 o I = 2.
!>

D

!>          D es un array de DOUBLE PRECISION, dimension ( 2 )
!>         Las eigenvalues originales.  Asumimos 0 <= D(1) < D(2).
!>

Z

!>          Z es un array de DOUBLE PRECISION, dimension ( 2 )
!>         Los componentes del vector de actualización.
!>

DELTA

!>          DELTA es un array de DOUBLE PRECISION, dimension ( 2 )
!>         Contiene (D(j) - sigma_I) en su componente j.
!>         El vector DELTA contiene la información necesaria
!>         para construir los eigenvectores.
!>

RHO

!>          RHO es DOUBLE PRECISION
!>         El escalar en la fórmula de actualización simétrica.
!>

DSIGMA

!>          DSIGMA es DOUBLE PRECISION
!>         La sigma_I calculada, la I-ésima eigenvalue actualizada.
!>

WORK

!>          WORK es un array de DOUBLE PRECISION, dimension ( 2 )
!>         WORK contiene (D(j) + sigma_I) en su componente j.
!>
