NOMBRE

iso_8859-14 - Conjunto de caracteres ISO/IEC 8859-14 codificado en octal, decimal y hexadecimal

DESCRIPCIÓN

El estándar ISO/IEC 8859 incluye varias extensiones de 8 bits al conjunto de caracteres ASCII (también conocido como ISO/IEC 646-IRV). ISO/IEC 8859-14 codifica los caracteres utilizados en las lenguas celtas.

Alfabetos ISO/IEC 8859

El conjunto completo de alfabetos ISO/IEC 8859 incluye:

ISO/IEC 8859-1 Lenguas de Europa occidental (Latin-1)
ISO/IEC 8859-2 Lenguas de Europa central y oriental (Latin-2)
ISO/IEC 8859-3 Lenguas del sudeste de Europa y varias (Latin-3)
ISO/IEC 8859-4 Lenguas escandinavas/bálticas (Latin-4)
ISO/IEC 8859-5 Latín/Cirílico
ISO/IEC 8859-6 Latín/Árabe
ISO/IEC 8859-7 Latín/Griego
ISO/IEC 8859-8 Latín/Hebreo
ISO/IEC 8859-9 Modificación de Latin-1 para turco (Latin-5)
ISO/IEC 8859-10 Lenguas laponas/nórdicas/esquimales (Latin-6)
ISO/IEC 8859-11 Latín/Tailandés
ISO/IEC 8859-13 Lenguas de la cuenca del Báltico (Latin-7)
ISO/IEC 8859-14 Celta (Latin-8)
ISO/IEC 8859-15 Lenguas de Europa occidental (Latin-9)
ISO/IEC 8859-16 Rumano (Latin-10)

NAME

latin8 - ISO/IEC 8859-14:1998 character set

DESCRIPTION

ISO/IEC 8859-14:1998 defines a character set for the Welsh language, as well as additional characters for Breton, Cornish, Estonian, Faroese, Irish, Scottish Gaelic, and Sami languages. It is a superset of the ASCII character set.

The character set consists of 256 characters. The first 128 characters are identical to those defined by ISO/IEC 8859-1 (Latin-1). The characters from 160 (0xA0) to 255 (0xFF) are specific to this character set.

The following table lists the characters from 160 (0xA0) to 255 (0xFF). The columns are:

  • Hexadecimal value of the character.
  • The character itself, if printable.
  • The Unicode code point.
  • The official Unicode name of the character.
