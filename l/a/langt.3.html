Descripción Detallada

Documentación de Funciones

función real clangt (carácter norma, entero n, complejo, dimensión( * ) dl, complejo, dimensión( * ) d, complejo, dimensión( * ) du)

CLANGT devuelve el valor de la norma 1, norma de Frobenius, norma infinito o el valor absoluto más grande de cualquier elemento de una matriz tridiagonal general.

Propósito:

!>
!> CLANGT  devuelve el valor de la norma uno,  o la norma de Frobenius, o
!> la norma infinito,  o el elemento de  mayor valor absoluto  de una
!> matriz tridiagonal compleja A.
!>

Retorna

CLANGT 
!>
!>    CLANGT = ( max(abs(A(i,j))), NORM = 'M' o 'm'
!>             (
!>             ( norm1(A),         NORM = '1', 'O' o 'o'
!>             (
!>             ( normI(A),         NORM = 'I' o 'i'
!>             (
!>             ( normF(A),         NORM = 'F', 'f', 'E' o 'e'
!>
!> donde  norm1  denota la  norma uno de una matriz (suma máxima de columna),
!> normI  denota la  norma infinito  de una matriz  (suma máxima de fila) y
!> normF  denota la  norma de Frobenius  de una matriz (raíz cuadrada de la suma de
!> cuadrados).  Tenga en cuenta que  max(abs(A(i,j)))  no es una norma de matriz consistente.
!>

Parámetros

NORM 
!>          NORM es CHARACTER*1
!>          Especifica el valor que se devolverá en CLANGT como se describe
!>          arriba.
!>

N

!>          N es INTEGER
!>          El orden de la matriz A.  N >= 0.  Cuando N = 0, CLANGT se
!>          establece a cero.
!>

DL

!>          DL es un array COMPLEX, dimensión (N-1)
!>          Los elementos sub-diagonales (n-1) de A.
!>

D

!>          D es un array COMPLEX, dimensión (N)
!>          Los elementos diagonales de A.
!>

DU

!>          DU es un array COMPLEX, dimensión (N-1)
!>          Los elementos super-diagonales (n-1) de A.
!>
