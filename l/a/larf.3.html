subrutina clarf (carácter side, entero m, entero n, complejo, dimensión( * ) v, entero incv, complejo tau, complejo, dimensión( ldc, * ) c, entero ldc, complejo, dimensión( * ) work)

CLARF aplica un reflector elemental complejo a una matriz rectangular general compleja.

Propósito:

!>
!> CLARF aplica un reflector elemental complejo H a una matriz C compleja M
!> por N, desde la izquierda o la derecha. H se representa en la forma
!>
!>       H = I - tau * v * v**H
!>
!> donde tau es un escalar complejo y v es un vector complejo.
!>
!> Si tau = 0, entonces H se toma como la matriz identidad.
!>
!> Para aplicar H**H (la traspuesta conjugada de H), suministre conjg(tau)
!> en lugar de tau.
!>

Parámetros

SIDE 
!>          SIDE es CHARACTER*1
!>          = 'L': forma  H * C
!>          = 'R': forma  C * H
!>

M

!>          M es INTEGER
!>          El número de filas de la matriz C.
!>

N

!>          N es INTEGER
!>          El número de columnas de la matriz C.
!>

V

!>          V es un array COMPLEX, de dimensión
!>                     (1 + (M-1)*abs(INCV)) si SIDE = 'L'
!>                  o (1 + (N-1)*abs(INCV)) si SIDE = 'R'
!>          El vector v en la representación de H. V no se usa si
!>          TAU = 0.
!>

INCV

!>          INCV es INTEGER
!>          El incremento entre elementos de v. INCV <> 0.
!>

TAU

!>          TAU es COMPLEX
!>          El valor tau en la representación de H.
!>

C

!>          C es un array COMPLEX, de dimensión (LDC,N)
!>          En la entrada, la matriz C de M por N.
!>          En la salida, C se sobrescribe con la matriz H * C si SIDE = 'L',
!>          o C * H si SIDE = 'R'.
!>

LDC

!>          LDC es INTEGER
!>          La dimensión principal del array C. LDC >= max(1,M).
!>

WORK

!>          WORK es un array COMPLEX, de dimensión
!>                         (N) si SIDE = 'L'
!>                      o (M) si SIDE = 'R'
!>

subroutine dlarf (character side, integer m, integer n, double precision, dimension( * ) v, integer incv, double precision tau, double precision, dimension( ldc, * ) c, integer ldc, double precision, dimension( * ) work)

DLARF applies an elementary reflector to a general rectangular matrix.

Purpose:

!>
!> DLARF applies a real elementary reflector H to a real m by n matrix
!> C, from either the left or the right. H is represented in the form
!>
!>       H = I - tau * v * v**T
!>
!> where tau is a real scalar and v is a real vector.
!>
!> If tau = 0, then H is taken to be the unit matrix.
!>

Parameters

SIDE 
!>          SIDE is CHARACTER*1
!>          = 'L': form  H * C
!>          = 'R': form  C * H
!>

M

!>          M is INTEGER
!>          The number of rows of the matrix C.
!>

N

!>          N is INTEGER
!>          The number of columns of the matrix C.
!>

V

!>          V is DOUBLE PRECISION array, dimension
!>                     (1 + (M-1)*abs(INCV)) if SIDE = 'L'
!>                  or (1 + (N-1)*abs(INCV)) if SIDE = 'R'
!>          The vector v in the representation of H. V is not used if
!>          TAU = 0.
!>

INCV

!>          INCV is INTEGER
!>          The increment between elements of v. INCV <> 0.
!>

TAU

!>          TAU is DOUBLE PRECISION
!>          The value tau in the representation of H.
!>

C

!>          C is DOUBLE PRECISION array, dimension (LDC,N)
!>          On entry, the m by n matrix C.
!>          On exit, C is overwritten by the matrix H * C if SIDE = 'L',
!>          or C * H if SIDE = 'R'.
!>

LDC

!>          LDC is INTEGER
!>          The leading dimension of the array C. LDC >= max(1,M).
!>

WORK

!>          WORK is DOUBLE PRECISION array, dimension
!>                         (N) if SIDE = 'L'
!>                      or (M) if SIDE = 'R'
!>

Purpose:

!>
!> ZLARF1F applies a complex elementary reflector H to a real m by n matrix
!> C, from either the left or the right. H is represented in t

NAME

larf - Performs a rank-1 update of a general matrix.

SYNOPSIS

 SUBROUTINE LARF( SIDE, M, N, V, INCV, TAU, C, LDC, WORK )
>
> CHARACTER SIDE
> INTEGER M, N, INCV, LDC
> COMPLEX*16 V( * ), TAU, C( LDC, * ), WORK( * )

Detailed Description

This routine is an internal routine of the LAPACK queens.

The general rank-1 update is in the form:

!>
!>       H = I - tau * v * v**H
!>
!> where tau is a complex scalar and v is a complex vector.
!>
!> If tau = 0, then H is taken to be the unit matrix.
!>
!> To apply H**H, supply conjg(tau) instead
!> tau.
!>
