NOMBRE

lappend - Añadir elementos de lista a una variable

SINOPSIS

lappend nombreVar ?valor valor valor ...?

DESCRIPCIÓN

Este comando trata la variable dada por nombreVar como una lista y añade cada uno de los argumentos valor a esa lista como un elemento separado, con espacios entre elementos. Si nombreVar no existe, se crea como una lista con los elementos dados por los argumentos valor. Lappend es similar a append excepto que los valores se añaden como elementos de lista en lugar de texto plano. Este comando proporciona una forma relativamente eficiente de construir listas grandes. Por ejemplo, «lappend a $b» es mucho más eficiente que «set a [concat $a [list $b]]» cuando $a es largo.

EJEMPLO

Usando lappend para construir una lista de números.

% set var 1
1
% lappend var 2
1 2
% lappend var 3 4 5
1 2 3 4 5
