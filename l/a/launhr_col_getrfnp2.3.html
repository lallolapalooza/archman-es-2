CLAUNHR_COL_GETRFNP2

Propósito:

!>
!> CLAUNHR_COL_GETRFNP2 calcula la factorización LU modificada sin
!> pivoteo de una matriz general compleja M-por-N, A. La factorización tiene
!> la forma:
!>
!>     A - S = L * U,
!>
!> donde:
!>    S es una matriz diagonal de signos m-por-n con diagonal D, de modo que
!>    D(i) = S(i,i), 1 <= i <= min(M,N). La diagonal D se construye
!>    como D(i)=-SIGN(A(i,i)), donde A(i,i) es el valor después de realizar
!>    i-1 pasos de eliminación Gaussiana. Esto significa que el elemento diagonal
!>    en cada paso de la eliminación Gaussiana tiene al menos valor absoluto uno
!>    (para que la división por cero no sea posible durante la división por el
!>    elemento diagonal);
!>
!>    L es una matriz triangular inferior M-por-N con elementos unitarios en la
!>    diagonal (trapezoidal inferior si M > N);
!>
!>    y U es una matriz triangular superior M-por-N
!>    (trapezoidal superior si M < N).
!>
!> Esta subrutina es una subrutina auxiliar utilizada en la subrutina de
!> reconstrucción de Householder CUNHR_COL. En CUNHR_COL, esta subrutina se
!> aplica a una matriz M-por-N, A, con columnas ortonormales, donde cada
!> elemento está acotado por uno en valor absoluto. Con la elección de
!> la matriz S anterior, se puede demostrar que el elemento diagonal en cada
!> paso de la eliminación Gaussiana es el mayor (en valor absoluto) en
!> la columna en o debajo de la diagonal, por lo que no se requiere pivoteo
!> para la estabilidad numérica [1].
!>
!> Para más detalles sobre el algoritmo de reconstrucción de Householder,
!> incluyendo la factorización LU modificada, véase [1].
!>
!> Esta es la versión recursiva del algoritmo de factorización LU.
!> Denotando A - S como B. El algoritmo divide la matriz B en cuatro
!> submatrices:
!>
!>        [  B11 | B12  ]  donde B11 es n1 por n1,
!>    B = [ -----|----- ]        B21 es (m-n1) por n1,
!>        [  B21 | B22  ]        B12 es n1 por n2,
!>                               B22 es (m-n1) por n2,
!>                               con n1 = min(m,n)/2, n2 = n-n1.
!>
!>
!> La subrutina se llama a sí misma para factorizar B11, resuelve para B21,
!> resuelve para B12, actualiza B22, y luego se llama a sí misma para factorizar B22.
!>
!> Para más detalles sobre el algoritmo LU recursivo, véase [2].
!>
!> CLAUNHR_COL_GETRFNP2 es llamada para factorizar un bloque por la
!> subrutina bloqueada CLAUNHR_COL_GETRFNP, la cual utiliza código bloqueado
!> que llama a BLAS de Nivel 3 para actualizar la submatriz. Sin embargo,
!> CLAUNHR_COL_GETRFNP2 es autosuficiente y puede ser utilizada sin CLAUNHR_COL_GETRFNP.
!>
!> [1] ,
!>     G. Ballard, J. Demmel, L. Grigori, M. Jacquelin, H.D. Nguyen,
!>     E. Solomonik, J. Parallel Distrib. Comput.,
!>     vol. 85, pp. 3-31, 2015.
!>
!> [2] , F. Gustavson, IBM J. of Res. and Dev.,
!>     vol. 41, no. 6, pp. 737-755, 1997.
!>

Parámetros

M 
!>          M es ENTERO
!>          El número de filas de la matriz A.  M >= 0.
!>

N

!>          N es ENTERO
!>          El número de columnas de la matriz A.  N >= 0.
!>

A

!>          A es una matriz de tipo COMPLEX, dimension (LDA,N)
!>          En la entrada, la matriz M-por-N a factorizar.
!>          En la salida, los factores L y U de la factorización
!>          A-S=L*U; los elementos unitarios de la diagonal de L no se almacenan.
!>

LDA

!>          LDA es ENTERO
!>          La dimensión principal del array A.  LDA >= max(1,M).
!>

D

!>          D es un array de tipo COMPLEX, dimension min(M,N)
!>          Los elementos diagonales de la matriz de signos diagonal S de tamaño
!>          M-por-N, D(i) = S(i,i), donde 1 <= i <= min(M,N). Los elementos
!>          solo pueden ser ( +1.0, 0.0 ) o (-1.0, 0.0 ).
!>

INFO

!>          INFO es ENTERO
!>          = 0:  salida exitosa
!>          < 0:  si INFO = -i, el i-ésimo argumento tuvo un valor ilegal
!>

recursive   subroutine zlaorhr_col_getrfnp2 (integer m, integer n, complex*16, dimension(   lda, * ) a, integer lda, complex*16, dimension( * ) d, integer info)


ZLAORHR_COL_GETRFNP2


Purpose:




!>
!> ZLAORHR_COL_GETRFNP2 computes the modified LU factorization without
!> pivoting of a complex general M-by-N matrix A. The factorization has
!> the form:
!>
!>     A - S = L * U,
!>
!> where:
!>    S is a m-by-n diagonal sign matrix with the diagonal D, so that
!>    D(i) = S(i,i), 1 <= i <= min(M,N). The diagonal D is constructed
!>    as D(i)=-SIGN(A(i,i)), where A(i,i) is the value after performing
!>    i-1 steps of Gaussian elimination. This means that the diagonal
!>    element at each step of  Gaussian elimination is at
!>    least one in absolute value (so that division-by-zero not
!>    possible during the division by the diagonal element);
!>
!>    L is a M-by-N lower triangular matrix with unit diagonal elements
!>    (lower trapezoidal if M > N);
!>
!>    and U is a M-by-N upper triangular matrix
!>    (upper trapezoidal if M < N).
!>
!> This routine is an auxiliary routine used in the Householder
!> reconstruction routine ZHR_COL. In ZHR_COL, this routine is
!> applied to an M-by-N matrix A with orthonormal columns, where each
!> element is bounded by one in absolute value. With the choice of
!> the matrix S above, one can show that the diagonal element at each
!> step of Gaussian elimination is the largest (in absolute value) in
!> the column on or below the diagonal, so that no pivoting is required
!> for numerical stability [1].
!>
!> For more details on the Householder reconstruction algorithm,
!> including the modified LU factorization, see [1].
!>
!> This is the recursive version of the LU factorization algorithm.
!> Denote A - S by B. The algorithm divides the matrix B into four
!> submatrices:
!>
!>        [  B11 | B12  ]  where B11 is n1 by n1,
!>    B = [ -----|----- ]        B21 is (m-n1) by n1,
!>        [  B21 | B22  ]        B12 is n1 by n2,
!>                               B22 is (m-n1) by n2,
!>                               with n1 = min(m,n)/2, n2 = n-n1.
!>
!>
!> The subroutine calls itself to factor B11, solves for B21,
!> solves for B12, updates B22, then calls itself to factor B22.
!>
!> For more details on the recursive LU algorithm, see [2].
!>
!> ZLAORHR_COL_GETRFNP2 is called to factorize a block by the blocked
!> routine ZLAORHR_COL_GETRFNP, which uses blocked code calling
!> Level 3 BLAS to update the submatrix. However, ZLAORHR_COL_GETRFNP2
!> is self-sufficient and can be used without ZLAORHR_COL_GETRFNP.
!>
!> [1] ,
!>     G. Ballard, J. Demmel, L. Grigori, M. Jacquelin, H.D. Nguyen,
!>     E. Solomonik, J. Parallel Distrib. Comput.,
!>     vol. 85, pp. 3-31, 2015.
!>
!> [2] , F. Gustavson, IBM J. of Res. and Dev.,
!>     vol. 41, no. 6, pp. 737-755, 1997.
!> 




Parameters


M

!>          M is INTEGER
!>          The number of rows of the matrix A.  M >= 0.
!> 


N


!>          N is INTEGER
!>          The number of columns of the matrix A.  N >= 0.
!> 


A


!>          A is COMPLEX*16 array, dimension (LDA,N)
!>          On entry, the M-by-N matrix to be factored.
!>          On exit, the factors L and U from the factorization
!>          A-S=L*U; the unit diagonal elements of L are not stored.
!> 


LDA


!>          LDA is INTEGER
!>          The leading dimension of the array A.  LDA >= max(1,M).
!> 


D


!>          D is COMPLEX*16 array, dimension min(M,N)
!>          The diagonal elements of the diagonal M-by-N sign matrix S,
!>          D(i) = S(i,i), where 1 <= i <= min(M,N). The elements can
!>          be only ( +1.0, 0.0 )
!> 


INFO


!>          INFO is INTEGER
!>          = 0:  successful exit
!>          < 0:  if INFO = -i, the i-th argument had an illegal value
