CLALS0 aplica factores multiplicadores inversos en la resolución del problema de mínimos cuadrados utilizando el enfoque SVD de divide y vencerás. Usado por sgelsd.

Propósito:

!>
!> CLALS0 aplica inversamente los factores multiplicadores de la matriz de
!> vectores singulares izquierdos o derechos de una matriz diagonal
!> añadida a la matriz del lado derecho B al resolver el problema de
!> mínimos cuadrados utilizando el enfoque SVD de divide y vencerás.
!>
!> Para la matriz de vectores singulares izquierdos, se involucran tres tipos
!> de matrices ortogonales:
!>
!> (1L) Rotaciones de Givens: el número de tales rotaciones es GIVPTR; los
!>      pares de columnas/filas a los que se aplicaron están almacenados en GIVCOL;
!>      y los valores C y S de estas rotaciones están almacenados en GIVNUM.
!>
!> (2L) Permutación. La fila (NL+1) de B se moverá a la primera fila, y para
!>      J=2:N, la fila PERM(J) de B se moverá a la fila J.
!>
!> (3L) La matriz de vectores singulares izquierdos de la matriz restante.
!>
!> Para la matriz de vectores singulares derechos, se involucran cuatro tipos
!> de matrices ortogonales:
!>
!> (1R) La matriz de vectores singulares derechos de la matriz restante.
!>
!> (2R) Si SQRE = 1, una rotación de Givens adicional para generar el espacio
!>      nulo derecho.
!>
!> (3R) La transformación inversa de (2L).
!>
!> (4R) La transformación inversa de (1L).
!>

Parámetros

ICOMPQ 
!>          ICOMPQ es ENTERO
!>         Especifica si se computan los vectores singulares en
!>         forma factorizada:
!>         = 0: Matriz de vectores singulares izquierdos.
!>         = 1: Matriz de vectores singulares derechos.
!>

NL

!>          NL es ENTERO
!>         La dimensión de fila del bloque superior. NL >= 1.
!>

NR

!>          NR es ENTERO
!>         La dimensión de fila del bloque inferior. NR >= 1.
!>

SQRE

!>          SQRE es ENTERO
!>         = 0: el bloque inferior es una matriz cuadrada NRxNR.
!>         = 1: el bloque inferior es una matriz rectangular NRx(NR+1).
!>
!>         La matriz bidimensional tiene dimensión de fila N = NL + NR + 1,
!>         y dimensión de columna M = N + SQRE.
!>

NRHS

!>          NRHS es ENTERO
!>         El número de columnas de B y BX. NRHS debe ser al menos 1.
!>

B

!>          B es un array COMPLEJO, dimensión ( LDB, NRHS )
!>         En la entrada, B contiene los lados derechos del problema de
!>         mínimos cuadrados en las filas 1 hasta M. En la salida, B contiene
!>         la solución X en las filas 1 hasta N.
!>

LDB

!>          LDB es ENTERO
!>         La dimensión principal de B. LDB debe ser al menos
!>         max(1,MAX( M, N ) ).
!>

BX

!>          BX es un array COMPLEJO, dimensión ( LDBX, NRHS )
!>

LDBX

!>          LDBX es ENTERO
!>         La dimensión principal de BX.
!>

PERM

!>          PERM es un array ENTERO, dimensión ( N )
!>         Las permutaciones (de deflación y ordenamiento) aplicadas
!>         a los dos bloques.
!>

GIVPTR

!>          GIVPTR es ENTERO
!>         El número de rotaciones de Givens que tuvieron lugar en
!>         este subproblema.
!>

GIVCOL

!>          GIVCOL es un array ENTERO, dimensión ( LDGCOL, 2 )
!>         Cada par de números indica un par de filas/columnas
!>         involucradas en una rotación de Givens.
!>

LDGCOL

!>          LDGCOL es ENTERO
!>         La dimensión principal de GIVCOL, debe ser al menos N.
!>

GIVNUM

!>          GIVNUM es un array REAL, dimensión ( LDGNUM, 2 )
!>         Cada número indica el valor C o S utilizado en la
!>         rotación de Givens correspondiente.
!>

LDGNUM

!>          LDGNUM es ENTERO
!>         La dimensión principal de los arrays DIFR, POLES y
!>         GIVNUM, debe ser al menos K.
!>

POLES

!>          POLES es un array REAL, dimensión ( LDGNUM, 2 )
!>         En la entrada, POLES(1:K, 1) contiene los nuevos valores
!>         singulares obtenidos al resolver la ecuación secular, y
!>         POLES(1:K, 2) es un array que contiene los polos en la
!>         ecuación secular.
!>

DIFL

!>          DIFL es un array REAL, dimensión ( K ).
!>         En la entrada, DIFL(I) es la distancia entre el I-ésimo valor
!>         singular actualizado (sin desdeflar) y el I-ésimo valor
!>         singular antiguo (sin desdeflar).
!>

DIFR

!>          DIFR es un array REAL, dimensión ( LDGNUM, 2 ).
!>         En la entrada, DIFR(I, 1) contiene las distancias entre el I-ésimo
!>         valor singular actualizado (sin desdeflar) y el (I+1)-ésimo
!>         valor singular antiguo (sin desdeflar). Y DIFR(I, 2) es el
!>         factor de normalización para el I-ésimo vector singular derecho.
!>

Z

!>          Z es un array REAL, dimensión ( K )
!>         Contiene los componentes de la fila actualizada de vector de
!>         actualización ajustada por deflación.
!>

K

!>          K es ENTERO
!>         Contiene la dimensión de la matriz sin desdeflar,
!>         Este es el orden de la ecuación secular relacionada. 1 <= K <= N.
!>

C

!>          C es REAL
!>         C contiene basura si SQRE = 0 y el valor C de una rotación
!>         de Givens relacionada con el espacio nulo derecho si SQRE = 1.
!>

S

!>          S es REAL
!>         S contiene basura si S

subroutine clals0 (integer icompq, integer nl, integer nr, integer sqre, integer nrhs, complex, dimension( ldb, * ) b, integer ldb, complex, dimension( ldbx, * ) bx, integer ldbx, integer, dimension( * ) perm, integer givptr, integer, dimension( ldgcol, * ) givcol, integer ldgcol, complex, dimension( ldgnum, * ) givnum, integer ldgnum, complex, dimension( ldgnum, * ) poles, complex, dimension( * ) difl, complex, dimension( ldgnum, * ) difr, complex, dimension( * ) z, integer k, complex c, complex s, complex, dimension( * ) work, integer info)

CLALS0 applies back multiplying factors in solving the least squares problem using divide and conquer SVD approach. Used by sgelsd.

Purpose:

!>
!> CLALS0 applies back the multiplying factors of either the left or the
!> right singular vector matrix of a diagonal matrix appended by a row
!> to the right hand side matrix B in solving the least squares problem
!> using the divide-and-conquer SVD approach.
!>
!> For the left singular vector matrix, three types of orthogonal
!> matrices are involved:
!>
!> (1L) Givens rotations: the number of such rotations is GIVPTR; the
!>      pairs of columns/rows they were applied to are stored in GIVCOL;
!>      and the C- and S-values of these rotations are stored in GIVNUM.
!>
!> (2L) Permutation. The (NL+1)-st row of B is to be moved to the first
!>      row, and for J=2:N, PERM(J)-th row of B is to be moved to the
!>      J-th row.
!>
!> (3L) The left singular vector matrix of the remaining matrix.
!>
!> For the right singular vector matrix, four types of orthogonal
!> matrices are involved:
!>
!> (1R) The right singular vector matrix of the remaining matrix.
!>
!> (2R) If SQRE = 1, one extra Givens rotation to generate the right
!>      null space.
!>
!> (3R) The inverse transformation of (2L).
!>
!> (4R) The inverse transformation of (1L).
!>

Parameters

ICOMPQ 
!>          ICOMPQ is INTEGER
!>         Specifies whether singular vectors are to be computed in
!>         factored form:
!>         = 0: Left singular vector matrix.
!>         = 1: Right singular vector matrix.
!>

NL

!>          NL is INTEGER
!>         The row dimension of the upper block. NL >= 1.
!>

NR

!>          NR is INTEGER
!>         The row dimension of the lower block. NR >= 1.
!>

SQRE

!>          SQRE is INTEGER
!>         = 0: the lower block is an NR-by-NR square matrix.
!>         = 1: the lower block is an NR-by-(NR+1) rectangular matrix.
!>
!>         The bidiagonal matrix has row dimension N = NL + NR + 1,
!>         and column dimension M = N + SQRE.
!>

NRHS

!>          NRHS is INTEGER
!>         The number of columns of B and BX. NRHS must be at least 1.
!>

B

!>          B is COMPLEX array, dimension ( LDB, NRHS )
!>         On input, B contains the right hand sides of the least
!>         squares problem in rows 1 through M. On output, B contains
!>         the solution X in rows 1 through N.
!>

LDB

!>          LDB is INTEGER
!>         The leading dimension of B. LDB must be at least
!>         max(1,MAX( M, N ) ).
!>

BX

!>          BX is COMPLEX array, dimension ( LDBX, NRHS )
!>

LDBX

!>          LDBX is INTEGER
!>         The leading dimension of BX.
!>

PERM

!>          PERM is INTEGER array, dimension ( N )
!>         The permutations (from deflation and sorting) applied
!>         to the two blocks.
!>

GIVPTR

!>          GIVPTR is INTEGER
!>         The number of Givens rotations which took place in this
!>         subproblem.
!>

GIVCOL

!>          GIVCOL is INTEGER array, dimension ( LDGCOL, 2 )
!>         Each pair of numbers indicates a pair of rows/columns
!>         involved in a Givens rotation.
!>

LDGCOL

!>          LDGCOL is INTEGER
!>         The leading dimension of GIVCOL, must be at least N.
!>

GIVNUM

!>          GIVNUM is COMPLEX array, dimension ( LDGNUM, 2 )
!>         Each number indicates the C or S value used in the
!>         corresponding Givens rotation.
!>

LDGNUM

!>          LDGNUM is INTEGER
!>         The leading dimension of arrays DIFR, POLES and
!>         GIVNUM, must be at least K.
!>

POLES

!>          POLES is COMPLEX array, dimension ( LDGNUM, 2 )
!>         On entry, POLES(1:K, 1) contains the new singular
!>         values obtained from solving the secular equation, and
!>         POLES(1:K, 2) is an array containing the poles in the secular
!>         equation.
!>

DIFL

!>          DIFL is COMPLEX array, dimension ( K ).
!>         On entry, DIFL(I) is the distance between I-th updated
!>         (undeflated) singular value and the I-th (undeflated) old
!>         singular value.
!>

DIFR

!>          DIFR is COMPLEX array, dimension ( LDGNUM, 2 ).
!>         On entry, DIFR(I, 1) contains the distances between I-th
!>         updated (undeflated) singular value and the I+1-th
!>         (undeflated) old singular value. And DIFR(I, 2) is the
!>         normalizing factor for the I-th right singular vector.
!>

Z

!>          Z is COMPLEX array, dimension ( K )
!>         Contain the components of the deflation-adjusted updating row
!>         vector.
!>

K

!>          K is INTEGER
!>         Contains the dimension of the non-deflated matrix,
!>         This is the order of the related secular equation. 1 <= K <=N.
!>

C

!>          C is COMPLEX
!>         C contains garbage if SQRE =0 and the C-value of a Givens
!>         rotation related to the right null space if SQRE = 1.
!>

S

!>          S is COMPLEX
!>         S contains garbage if SQRE =0 and the S-value of a Givens
!>         rotation related to the right null space if SQRE = 1.
!>

WORK

!>          WORK is COMPLEX array, dimension ( K )
!>

INFO

!>          INFO is INTEGER
!>          = 0:  successful exit.
!>          < 0:  if INFO = -i, the i-th argument had an illegal value.
!>

NAME

slals0 -

SLALS0 applies back the multiplying factors of either the left or the right singular vector matrix of a diagonal matrix appended by a row to the right hand side matrix B in solving the least squares problem using the divide-and-conquer SVD approach.

SYNOPSIS

SUBROUTINE SLALS0(ICOMPQ, NL, NR, SQRE, NRHS, B, LDB, BX, LDBX, PERM, GIVPTR, GIVCOL, LDGCOL, GIVNUM, LDGNUM, POLES, DIFL, DIFR, Z, K, C, S, WORK, INFO)
INTEGER ICOMPQ, NL, NR, SQRE, NRHS, LDB, LDBX, PERM, GIVPTR, GIVCOL, LDGCOL, GIVNUM, LDGNUM, POLES, DIFL, DIFR, Z, K, C, S, WORK, INFO
REAL B, BX, GIVNUM, POLES, DIFL, DIFR, Z, C, S, WORK
INTEGER LDGCOL, LDGNUM

DESCRIPTION

SLALS0 applies back the multiplying factors of either the left or the right singular vector matrix of a diagonal matrix appended by a row to the right hand side matrix B in solving the least squares problem using the divide-and-conquer SVD approach.

For the left singular vector matrix, three types of orthogonal matrices are involved:

(1L) Givens rotations: the number of such rotations is GIVPTR; the pairs of columns/rows they were applied to are stored in GIVCOL; and the C- and S-values of these rotations are stored in GIVNUM.

(2L) Permutation. The (NL+1)-st row of B is to be moved to the first row, and for J=2:N, PERM(J)-th row of B is to be moved to the J-th row.

(3L) The left singular vector matrix of the remaining matrix.

For the right singular vector matrix, four types of orthogonal matrices are involved:

(1R) The right singular vector matrix of the remaining matrix.

(2R) If SQRE = 1, one extra Givens rotation to generate the right null space.

(3R) The inverse transformation of (2L).

(4R) The inverse transformation of (1L).
