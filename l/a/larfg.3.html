DOCUMENTACIÓN DE LA FUNCIÓN

subrutina clarfg (integer n, complex alpha, complex, dimension( * ) x, integer incx, complex tau)

CLARFG genera un reflector elemental complejo H de orden n, tal que

Propósito:

!>
!> CLARFG genera un reflector elemental complejo H de orden n, tal
!> que
!>
!>       H**H * ( alpha ) = ( beta ),   H**H * H = I.
!>              (   x   )   (   0  )
!>
!> donde alpha y beta son escalares, con beta real, y x es un vector
!> complejo de (n-1) elementos. H se representa en la forma
!>
!>       H = I - tau * ( 1 ) * ( 1 v**H ) ,
!>                     ( v )
!>
!> donde tau es un escalar complejo y v es un vector complejo de
!> (n-1) elementos. Nótese que H no es hermitiana.
!>
!> Si los elementos de x son todos cero y alpha es real, entonces tau = 0
!> y H se toma como la matriz unidad.
!>
!> De lo contrario,  1 <= real(tau) <= 2  y  abs(tau-1) <= 1 .
!>

Parámetros

N 
!>          N es INTEGER
!>          El orden del reflector elemental.
!>

ALPHA

!>          ALPHA es COMPLEX
!>          En la entrada, el valor alpha.
!>          En la salida, se sobrescribe con el valor beta.
!>

X

!>          X es un array COMPLEX, de dimensión
!>                         (1+(N-2)*abs(INCX))
!>          En la entrada, el vector x.
!>          En la salida, se sobrescribe con el vector v.
!>

INCX

!>          INCX es INTEGER
!>          El incremento entre los elementos de X. INCX > 0.
!>

TAU

!>          TAU es COMPLEX
!>          El valor tau.
!>

NAME

zlarfg - zlarfg genera un vector de Householder reflectante para transformar un escalar en un elemento, y un vector de entrada en un vector transformado.

SYNOPSIS

SUBROUTINE ZLARFG(
    N, ALPHA, X, INCX, TAU )
        INTEGER N
        COMPLEX*16 ALPHA
        COMPLEX*16 X( * )
        INTEGER INCX
        COMPLEX*16 TAU

Detailed Description

Esta rutina se utiliza por defecto como un subprograma de ZGEHRD, ZGELQF, ZGELQG, ZGEQLF, ZGEQLG, ZGERQF, ZGERQG, ZGESSQ, ZGSQRQ, ZGTTRF y ZGTTSF.

El propósito de esta rutina es generar un vector de Householder reflectante de tal forma que si

   x = [ alpha ]
       [   x   ]

y

   v = [ -tau*alpha ]
       [      y     ]

donde x es un vector (N-1) por 1, y

   y = x + tau*alpha*v

entonces

   v = [ alpha ]
       [   x   ]

se transforma en

   v = [ beta ]
       [  0   ]

donde beta es un escalar, y

   y = 0.

Se logra esto con una transformación de Householder

   H*x = v.

La transformación de Householder se representa como

   H = I - tau*v*v^H.

donde v es un vector de Householder y tau es un escalar. La norma de v es la norma L2.

Por lo tanto:

   x + tau*v*v^H*x = v.

Si v se elige como

   v = x + sign(x(1))*||x||*e1,

donde e1 es el primer vector unitario canónico, entonces

   H*x = [ -sign(x(1))*||x|| ]
         [          0          ]

En la práctica, para evitar perder precisión cuando alpha es pequeño, la representación utilizada es:

   v = alpha*x(1) + x(2) = alpha*(x(1) + beta/alpha*x(2))

donde

   beta = sign(alpha)*||x||.

La rutina calcula tau y v, y devuelve alpha con el valor de beta.

Argumentos:

N
INTEGER. El número de elementos en el vector x.
ALPHA
COMPLEX*16. En la entrada, el valor de alpha. En la salida, se sobrescribe con el valor de beta.
X
COMPLEX*16 array, dimension (1+(N-2)*abs(INCX)). En la entrada, el vector x. En la salida, se sobrescribe con el vector v.
INCX
INTEGER. El incremento entre elementos de X. INCX > 0.
TAU
COMPLEX*16. El valor de tau.
