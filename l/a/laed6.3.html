subrutina dlaed6 (integer kniter, logical orgati, double precision rho, double precision, dimension( 3 ) d, double precision, dimension( 3 ) z, double precision finit, double precision tau, integer info)

DLAED6 utilizada por DSTEDC. Calcula un paso de Newton en la solución de la ecuación secular.

Propósito:

!>
!> DLAED6 calcula la raíz positiva o negativa (más cercana al origen)
!> de
!>                  z(1)        z(2)        z(3)
!> f(x) =   rho + --------- + ---------- + ---------
!>                 d(1)-x      d(2)-x      d(3)-x
!>
!> Se asume que
!>
!>       si ORGATI = .true. la raíz está entre d(2) y d(3);
!>       de lo contrario, está entre d(1) y d(2)
!>
!> Esta subrutina será llamada por DLAED4 cuando sea necesario. En la mayoría
!> de los casos, la raíz buscada es la de menor magnitud, aunque podría no serlo
!> en algunas situaciones extremadamente raras.
!>

Parámetros

KNITER 
!>          KNITER es INTEGER
!>               Consultar DLAED4 para su significado.
!>

ORGATI

!>          ORGATI es LOGICAL
!>               Si ORGATI es verdadero, la raíz necesaria está entre d(2) y
!>               d(3); de lo contrario, está entre d(1) y d(2). Ver
!>               DLAED4 para más detalles.
!>

RHO

!>          RHO es DOUBLE PRECISION
!>               Consultar la ecuación f(x) arriba.
!>

D

!>          D es un array de DOUBLE PRECISION, dimensión (3)
!>               D satisface d(1) < d(2) < d(3).
!>

Z

!>          Z es un array de DOUBLE PRECISION, dimensión (3)
!>               Cada uno de los elementos en z debe ser positivo.
!>

FINIT

!>          FINIT es DOUBLE PRECISION
!>               El valor de f en 0. Es más preciso que el calculado
!>               dentro de esta subrutina (si alguien quiere hacerlo).
!>

TAU

!>          TAU es DOUBLE PRECISION
!>               La raíz de la ecuación f(x).
!>

INFO

!>          INFO es INTEGER
!>               = 0: salida exitosa
!>               > 0: si INFO = 1, fallo de convergencia
!>

NAME

tents - Generate text-based tents pattern.

SYNOPSIS

tents [-b] [-l length] [-w width] [-s seed]

Detailed Description

The tents command generates a text-based tents pattern. The pattern is composed of characters that resemble tents. The appearance of the pattern can be modified using various options.

Options

-b
Use background characters. This option fills the entire screen with tents pattern, instead of just printing the tents.
-l length
Set the length of the tents. The default is 10.
-w width
Set the width of the tents. The default is 10.
-s seed
Set the random seed for pattern generation. This allows for reproducible patterns.

Function Documentation

This section is not applicable for the tents command as it is a user-facing utility and does not provide functions for direct use in other programs.
