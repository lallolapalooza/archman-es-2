DLASDA calcula la descomposición en valores singulares (SVD) de una matriz real superior bidiagonal con diagonal d y fuera de diagonal e. Usado por sbdsdc.

Propósito:

!>
!> Usando un enfoque de divide y vencerás, DLASDA calcula la descomposición
!> en valores singulares (SVD) de una matriz real superior bidiagonal N-por-M
!> B con diagonal D y fuera de diagonal E, donde M = N + SQRE. El algoritmo
!> calcula los valores singulares en la SVD B = U * S * VT. Las matrices
!> ortogonales U y VT se calculan opcionalmente en forma compacta.
!>
!> Una subrutina relacionada, DLASD0, calcula los valores singulares y los
!> vectores singulares en forma explícita.
!>

!>          ICOMPQ es INTEGER

!>         en forma compacta, como sigue:
!>         = 0: Calcular solo los valores singulares.

!>              en forma compacta.
!>

Description

dlasda and slasda compute the singular value decomposition (SVD) of a real upper bidiagonal matrix B with diagonal D and off-diagonal E. They are used by sbdsdc and dbdsdc. The singular values are computed using a divide and conquer approach. The algorithm computes the singular values in the SVD B = U * S * VT. The orthogonal matrices U and VT are optionally computed in compact form.

A related subroutine, slasdq (dlasdq), computes the singular values and the singular vectors in explicit form.

Parameters

IC (INTEGER)
Specifies whether singular vectors are to be computed in compact form, as follows:

  • = 0: Compute singular values only.
  • = 1: Compute singular vectors of upper bidiagonal matrix in compact form.

SMLSIZ (INTEGER)
The maximum size of the subproblems at the bottom of the computation tree.

N (INTEGER)
The row dimension of the upper bidiagonal matrix. This is also the dimension of the main diagonal array D.

SQRE (INTEGER)
Specifies the column dimension of the bidiagonal matrix.
= 0: The bidiagonal matrix has column dimension M = N;
= 1: The bidiagonal matrix has column dimension M = N + 1.

D (DOUBLE PRECISION or REAL array, dimension (*))
On entry D contains the main diagonal of the bidiagonal matrix. On exit D, if INFO = 0, contains its singular values.

E (DOUBLE PRECISION or REAL array, dimension (*))
Contains the subdiagonal entries of the bidiagonal matrix. On exit, E has been destroyed.

U (DOUBLE PRECISION or REAL array, dimension (LDU, *))
If IC = 1, U has dimension (LDU, SMLSIZ). On exit, U contains the left singular vector matrices of all subproblems at the bottom level. If IC = 0, U is not referenced.

LDU (INTEGER)
The leading dimension of arrays U, VT, DIFL, DIFR, POLES, GIVNUM, and Z. LDU must be greater than N.

VT (DOUBLE PRECISION or REAL array, dimension (LDU, *))
If IC = 1, VT has dimension (LDU, SMLSIZ+1). On exit, VT**T contains the right singular vector matrices of all subproblems at the bottom level. If IC = 0, VT is not referenced.

K (INTEGER array, dimension (*))
If IC = 1, K has dimension N. If IC = 0, K has dimension 1. On exit, K(I) is the dimension of the I-th secular equation on the computation tree.

DIFL (DOUBLE PRECISION or REAL array, dimension (LDU, *))
If IC = 1, DIFL has dimension (LDU, NLVL) where NLVL = floor(log_2(N/SMLSIZ))). On exit, DIFL(1:N, I) records distances between singular values on the I-th level and singular values on the (I-1)-th level. If IC = 0, DIFL is not referenced.

DIFR (DOUBLE PRECISION or REAL array, dimension (LDU, *))
If IC = 1, DIFR has dimension (LDU, 2*NLVL). On exit, DIFR(1:N, 2*I-1) and DIFR(1:N, 2*I) record the normalizing factors for the left and right singular vector matrices, respectively. If IC = 0, DIFR has dimension N.

Z (DOUBLE PRECISION or REAL array, dimension (LDU, *))
If IC = 1, Z has dimension (LDU, NLVL). The first K elements of Z(1, I) contain the components of the deflation-adjusted updating row vector for subproblems on the I-th level. If IC = 0, Z has dimension N.

POLES (DOUBLE PRECISION or REAL array, dimension (LDU, *))
If IC = 1, POLES has dimension (LDU, 2*NLVL). On exit, POLES(1, 2*I-1) and POLES(1, 2*I) contain the new and old singular values involved in the secular equations on the I-th level. If IC = 0, POLES is not referenced.

GIVPTR (INTEGER array, dimension (*))
If IC = 1, GIVPTR has dimension N. On exit, GIVPTR(I) records the number of Givens rotations performed on the I-th problem on the computation tree. If IC = 0, GIVPTR is not referenced.

GIVCOL (INTEGER array, dimension (LDGCOL, *))
If IC = 1, GIVCOL has dimension (LDGCOL, 2*NLVL). On exit, for each I, GIVCOL(1, 2*I-1) and GIVCOL(1, 2*I) record the locations of Givens rotations performed on the I-th level on the computation tree. If IC = 0, GIVCOL is not referenced.

LDGCOL (INTEGER)
The leading dimension of arrays GIVCOL and PERM. LDGCOL must be greater than N.

PERM (INTEGER array, dimension (LDGCOL, *))
If IC = 1, PERM has dimension (LDGCOL, NLVL). On exit, PERM(1, I) records permutations done on the I-th level of the computation tree. If IC = 0, PERM is not referenced.

GIVNUM (DOUBLE PRECISION or REAL array, dimension (LDU, *))
If IC = 1, GIVNUM has dimension (LDU, 2*NLVL). On exit, for each I, GIVNUM(1, 2*I-1) and GIVNUM(1, 2*I) record the C- and S-values of Givens rotations performed on the I-th level on the computation tree. If IC = 0, GIVNUM is not referenced.

C (DOUBLE PRECISION or REAL array, dimension (*))
If IC = 1, C has dimension N. If IC = 0, C has dimension 1. If IC = 1 and the I-th subproblem is not square, on exit, C(I) contains the C-value of a Givens rotation related to the right null space of the I-th subproblem.

S (DOUBLE PRECISION or REAL array, dimension (*))
If IC = 1, S has dimension N. If IC = 0, S has dimension 1. If IC = 1 and the I-th subproblem is not square, on exit, S(I) contains the S-value of a Givens rotation related to the right null space of the I-th subproblem.

WORK (DOUBLE PRECISION or REAL array, dimension (*))
Work array. The dimension is (6*N + (SMLSIZ+1)*(SMLSIZ+1)).

IWORK (INTEGER array, dimension (*))
Work array. The dimension is (7*N).

INFO (INTEGER)
= 0: Successful exit.
< 0: If INFO = -i, the i-th argument had an illegal value.
> 0: If INFO = 1, a singular value did not converge.

Further Information

The dimensions of the arrays are passed explicitly in parameters whose names are not self-explanatory, such as LDGCOL, LDU, and SMLSIZ.

The following is the general form of the bidiagonal matrix:

B = Sigma_1 * ( D_1 E_1 ... )

           (   A_1 ...  )

where Sigma_1 = 1 if SQRE = 0 and Sigma_1 = diag(1, ..., 1, -1) if SQRE = 1. A_I represents the submatrices of the computation tree.

The dimension of the matrix is M = N+SQRE.

The arrays DIFL, DIFR, Z, POLES, GIVPTR, GIVCOL, PERM, GIVNUM, C, and S are used for the compact storage of the computed singular vectors. They are only referenced if IC = 1.

The dimension of the arrays:

  • DIFL has dimensions (LDU, NLVL)
  • DIFR has dimensions (LDU, 2*NLVL)
  • Z has dimensions (LDU, NLVL)
  • POLES has dimensions (LDU, 2*NLVL)
  • GIVPTR has dimension N
  • GIVCOL has dimensions (LDGCOL, 2*NLVL)
  • PERM has dimensions (LDGCOL, NLVL)
  • GIVNUM has dimensions (LDU, 2*NLVL)
  • C has dimension N
  • S has dimension N

where NLVL = floor(log_2(N/SMLSIZ)).

If IC = 0:

  • DIFR has dimension N
  • Z has dimension N
  • C has dimension 1
  • S has dimension 1
