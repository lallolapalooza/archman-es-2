Documentación de la Función

función real clangb (carácter norm, entero n, entero kl, entero ku, complejo, dimensión(ldab, *) ab, entero ldab, real, dimensión(*) work)

CLANGB devuelve el valor de la norma 1, norma de Frobenius, norma infinito o el valor absoluto más grande de cualquier elemento de una matriz de banda general.

Propósito:

!>
!> CLANGB  devuelve el valor de la norma uno,  o la norma de Frobenius, o
!> la norma infinito,  o el elemento de  mayor valor absoluto  de una
!> matriz de banda A de n por n,  con kl sub-diagonales y ku super-diagonales.
!>

Devuelve

CLANGB 
!>
!>    CLANGB = ( max(abs(A(i,j))), NORM = 'M' o 'm'
!>             (
!>             ( norm1(A),         NORM = '1', 'O' o 'o'
!>             (
!>             ( normI(A),         NORM = 'I' o 'i'
!>             (
!>             ( normF(A),         NORM = 'F', 'f', 'E' o 'e'
!>
!> donde  norm1  denota la norma uno de una matriz (suma máxima de columna),
!> normI  denota la norma infinito  de una matriz  (suma máxima de fila) y
!> normF  denota la norma de Frobenius  de una matriz (raíz cuadrada de la suma de
!> cuadrados).  Nótese que  max(abs(A(i,j)))  no es una norma matricial consistente.
!>

Parámetros

NORM 
!>          NORM es CHARACTER*1
!>          Especifica el valor a devolver en CLANGB como se describe
!>          arriba.
!>

N

!>          N es INTEGER
!>          El orden de la matriz A.  N >= 0.  Cuando N = 0, CLANGB se
!>          establece a cero.
!>

KL

!>          KL es INTEGER
!>          El número de sub-diagonales de la matriz A.  KL >= 0.
!>

KU

!>          KU es INTEGER
!>          El número de super-diagonales de la matriz A.  KU >= 0.
!>

AB

!>          AB es un array COMPLEX, de dimensión (LDAB,N)
!>          La matriz de banda A, almacenada en las filas 1 a KL+KU+1. La j-ésima
!>          columna de A se almacena en la j-ésima columna del array AB como
!>          sigue:
!>          AB(ku+1+i-j,j) = A(i,j) para max(1,j-ku)<=i<=min(n,j+kl).
!>

LDAB

!>          LDAB es INTEGER
!>          La dimensión principal del array AB.  LDAB >= KL+KU+1.
!>

WORK

!>          WORK es un array REAL, de dimensión (MAX(1,LWORK)),
!>          donde LWORK >= N cuando NORM = 'I'; de lo contrario, WORK no
!>          se referencia.
!>
