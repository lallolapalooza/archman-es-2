NOMBRE

labwc - archivos de tema

TEMA

El motor de temas tiene como objetivo ser compatible con openbox y los temas se buscarán en el siguiente orden:

  • ${XDG_DATA_HOME:-$HOME/.local/share}/themes/<nombre-tema>/labwc/
  • $HOME/.themes/<nombre-tema>/labwc/
  • /usr/share/themes/<nombre-tema>/labwc/
  • /usr/local/share/themes/<nombre-tema>/labwc/
  • /opt/share/themes/<nombre-tema>/labwc/
  • ${XDG_DATA_HOME:-$HOME/.local/share}/themes/<nombre-tema>/openbox-3/
  • $HOME/.themes/<nombre-tema>/openbox-3/
  • /usr/share/themes/<nombre-tema>/openbox-3/
  • /usr/local/share/themes/<nombre-tema>/openbox-3/
  • /opt/share/themes/<nombre-tema>/openbox-3/

Cuando $XDG_DATA_HOME está definido, reemplaza (en lugar de aumentar) $HOME/.local/share. Lo mismo ocurre con $XDG_DATA_DIRS y /usr/share/.

La elección de un tema se realiza editando la clave <name> en la sección <theme> del archivo de configuración rc.xml (labwc-config(5)).

Un tema consta de un archivo themerc y, opcionalmente, algunos iconos de barra de título (denominados botones).

La configuración del tema especificada en themerc puede ser reemplazada creando un archivo 'themerc-override' en el directorio de configuración, que normalmente es $HOME/.config/labwc/ pero puede ser algunas otras ubicaciones como se describe en labwc-config(5).

TIPOS DE DATOS

color

Los colores se pueden especificar por nombre o valor hexadecimal Rojo-Verde-Azul (RGB):

nombre de color se refiere a "nombre de color X11", por ejemplo: 'white', 'grey40', 'pink' y 'peach puff'. Más información se puede encontrar aquí:

  • http://en.wikipedia.org/wiki/Web_colors#X11_color_names
  • http://en.wikipedia.org/wiki/X11_color_names
  • https://github.com/labwc/labwc/blob/master/src/common/rgb.txt

valor RGB

  • #rrggbb (valores RGB hexadecimales)
  • #rrggbb aaa (igual pero con porcentaje de valor alfa decimal)
  • #rrggbbaa (igual pero con valor alfa en línea en codificación hexadecimal)
  • #rgb (valores RGB hexadecimales donde #fff es un atajo para #f0f0f0) (desde 0.9.0)

Nota: la notación #rrggbb aaa está obsoleta a partir de labwc 0.7.2 y puede eliminarse en futuras versiones.

justificación

La justificación determina la alineación horizontal del texto. Las opciones válidas son Izquierda, Centro y Derecha.

texturas

Las texturas determinan el aspecto visual de un elemento. Se especifican a través de una cadena de texto con un número de campos. La capitalización no es significativa. El formato es el siguiente:
(Sólido | Degradado <tipo>)
.. donde | significa "o".
•
Sólido significa que el fondo de la textura se rellena con un solo color. La textura debe ir acompañada de un único campo de color. Por ejemplo:
window.*.title.bg: Sólido
window.*.title.bg.color: #f8f5f2
•
Degradado significa que el fondo de la textura se rellena con un degradado de un color a otro. Cuando se especifica Degradado, debe ir seguido del tipo de degradado. También debe ir acompañado de los campos color y colorTo. Los tipos de degradado válidos son: (1) Vertical donde el degradado va desde el borde superior hasta el inferior (2) SplitVertical donde el degradado se divide por la mitad y va hacia los bordes superior e inferior. Los degradados SplitVertical tienen dos campos de color adicionales y opcionales: color.splitTo y colorTo.splitTo. Estos colores son los colores claros utilizados en los extremos superior e inferior del degradado SplitVertical. Cuando se omiten, los valores predeterminados para estos son color x 5/4 y colorTo x 17/16. Ejemplos:
# Degradado vertical
window.*.title.bg: Degradado Vertical
window.*.title.bg.color: #658fb5
window.*.title.bg.colorTo: #4d6982
# Degradado SplitVertical
window.*.title.bg: Degradado SplitVertical
window.*.title.bg.color: #658fb5
window.*.title.bg.color.splitTo: #7595b9
window.*.title.bg.colorTo: #4d6982
window.*.title.bg.colorTo.splitTo: #557485

ELEMENTOS DEL TEMA

border.width

Ancho de línea (entero) del borde dibujado alrededor de los marcos de la ventana. El valor predeterminado es 1.

window.titlebar.padding.width

Tamaño del relleno horizontal de la barra de título, en píxeles, entre el borde y el primer botón a la izquierda/derecha. El valor predeterminado es 0.

window.titlebar.padding.height

Tamaño del relleno vertical de la barra de título, en píxeles. El valor predeterminado es 0.

window.active.border.color

Color del borde de la ventana activa. El valor predeterminado es #aaaaaa.

window.inactive.border.color

Color del borde de la ventana inactiva. El valor predeterminado es #aaaaaa.

window.active.indicator.toggled-keybind.color

Indicador de estado para la acción ToggleKeybinds. Puede establecerse con el mismo valor que el de window.active.border.color para deshabilitar el indicador de estado. El valor predeterminado es #ff0000.

window.active.title.bg

Textura para la barra de título de la ventana enfocada. Consulte la sección de texturas más arriba. El valor predeterminado es Sólido

window.active.title.bg.color

Color de fondo para la barra de título de la ventana enfocada. Consulte la sección de texturas para campos de color adicionales asociados con degradados. El valor predeterminado es #e1dedb.

window.inactive.title.bg

Textura para las barras de título de las ventanas no enfocadas. Consulte la sección de texturas más arriba. El valor predeterminado es Sólido

window.inactive.title.bg.color

Color de fondo para las barras de título de las ventanas no enfocadas. Consulte la sección de texturas para campos de color adicionales asociados con degradados. El valor predeterminado es #f6f5f4.

window.active.label.text.color

Color del texto para la barra de título de la ventana enfocada. El valor predeterminado es #000000.

window.inactive.label.text.color

Color del texto para las barras de título de las ventanas no enfocadas. El valor predeterminado es #000000.

window.label.text.justify

Especifica cómo se alinean los títulos de las ventanas en la barra de título tanto para ventanas enfocadas como no enfocadas. Tipo justificación. El valor predeterminado es Centro.

window.button.width

Ancho de un botón de la barra de título, en píxeles. El valor predeterminado es 26.

window.button.height

Altura de un botón de la barra de título, en píxeles. El valor predeterminado es 26.

window.button.spacing

Espacio entre los botones de la barra de título, en píxeles. El valor predeterminado es 0.

window.button.hover.bg.corner-radius

Radio del efecto de pasar el ratón por encima de un botón de la barra de título, en píxeles. El valor predeterminado es 0.

Nota: para un efecto circular al pasar el ratón, establezca window.button.width y window.button.height iguales y window.button.hover.bg.corner-radius a la mitad de ellos.

window.active.button.unpressed.image.color

Color de las imágenes en los botones de la barra de título en su estado predeterminado, sin presionar. Este elemento es para la ventana enfocada. El valor predeterminado es #000000.

window.inactive.button.unpressed.image.color

Color de las imágenes en los botones de la barra de título en su estado predeterminado, sin presionar. Este elemento es para las ventanas no enfocadas. El valor predeterminado es #000000.

Nota: Los elementos de botón (es decir, window.[in]active.button.*) pueden definirse de forma única para cada tipo de botón ("menu", "iconify", "max", "shade", "desk" o "close") añadiendo el tipo después del nodo "button". Por ejemplo:

•
window.active.button.iconify.unpressed.image.color indica el color del botón de minimizar para ventanas activas; mientras que
•
window.inactive.button.close.unpressed.image.color indica el color del botón de cerrar para ventanas inactivas.

NAME

labwc-theme - Theme configuration file for labwc

THEME

The theme configuration file is a text file that allows the customization of the appearance of labwc elements, such as titlebars, buttons, and borders.

The theme file is located at ~/.config/labwc/theme by default, but can be overridden by the THEME environment variable.

The theme file consists of key-value pairs. Comments start with # and extend to the end of the line.

DATA TYPES

The following data types are used in the theme file:

Integer
A whole number.
Color
A color value, specified in hexadecimal format (e.g., #RRGGBB) or by name (e.g., red).
String
A sequence of characters enclosed in double quotes (e.g., "Hello, World!").

THEME ELEMENTS

The following elements can be customized in the theme file:

titlebar.height

Height of the titlebar in pixels. Default is 20.

titlebar.color

Color of the titlebar. Default is #cccccc (light gray).

titlebar.text_color

Color of the text in the titlebar. Default is #000000 (black).

titlebar.font

Font used for the titlebar text. Default is system default.

titlebar.border.width

Width of the titlebar border in pixels. Default is 1.

titlebar.border.color

Color of the titlebar border. Default is #000000 (black).

window.border.width

Width of the window border in pixels. Default is 1.

window.border.color

Color of the window border. Default is #000000 (black).

window.background.color

Color of the window background. Default is #ffffff (white).

magnifier.border.width

Width of the magnifier window border in pixels. Default is 1.

magnifier.border.color

Color of the magnfier window border. Default is #ff0000 (red).

BUTTONS

Las imágenes usadas para los iconos de la barra de título se denominan botones.

Los formatos de imagen listados abajo son soportados. Están listados en orden de precedencia, donde el primer formato en la lista se busca primero.

  • png
  • svg
  • xbm

Por defecto, los botones son xbm (X Bitmaps) de 1 bit. Estas son máscaras donde 0=claro y 1=con color. Los archivos de imagen xbm se colocan en el mismo directorio que el archivo themerc dentro de un tema particular. Los siguientes botones xbm son soportados:

  • max.xbm
  • iconify.xbm
  • close.xbm
  • menu.xbm
  • max_toggled.xbm
  • desk.xbm
  • desk_toggled.xbm
  • shade.xbm
  • shade_toggled.xbm

Se pueden definir iconos adicionales para que se muestren cuando el puntero del ratón esté sobre el botón en cuestión:

  • max_hover.xbm
  • iconify_hover.xbm
  • close_hover.xbm
  • menu_hover.xbm
  • max_toggled_hover.xbm
  • desk_hover.xbm
  • desk_toggle_hover.xbm
  • shade_hover.xbm
  • shade_toggle_hover.xbm

Una ventaja de los botones xbm sobre otros formatos es que cambian de color según el tema. Otros formatos usan los sufijos "-active" y "-inactive" para alinearse con los colores respectivos de la barra de título. Por ejemplo: "close-active.png"

Por razones de compatibilidad, los siguientes nombres alternativos son soportados para archivos xbm:

•
max_hover_toggled.xbm para max_toggled_hover.xbm

Al usar iconos png o svg, para una experiencia de tema completa se deberían añadir todos los siguientes iconos:
