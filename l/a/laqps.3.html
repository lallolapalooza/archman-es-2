CLAQPS calcula un paso de la factorización QR con pivote de columnas de una matriz real m-por-n A utilizando BLAS nivel 3.

Propósito:

!>
!> CLAQPS calcula un paso de la factorización QR con pivote de columnas
!> de una matriz compleja M-por-N A utilizando BLAS-3. Intenta factorizar
!> NB columnas de A comenzando desde la fila OFFSET+1, y actualiza toda
!> la matriz con BLAS-3 xGEMM.
!>
!> En algunos casos, debido a cancelaciones catastróficas, no puede
!> factorizar NB columnas. Por lo tanto, el número real de columnas factorizadas
!> se devuelve en KB.
!>
!> El bloque A(1:OFFSET,1:N) se pivotea en consecuencia, pero no se factoriza.
!>

Parámetros

M 
!>          M es INTEGER
!>          El número de filas de la matriz A. M >= 0.
!>

N

!>          N es INTEGER
!>          El número de columnas de la matriz A. N >= 0
!>

OFFSET

!>          OFFSET es INTEGER
!>          El número de filas de A que han sido factorizadas en
!>          pasos anteriores.
!>

NB

!>          NB es INTEGER
!>          El número de columnas a factorizar.
!>

KB

!>          KB es INTEGER
!>          El número de columnas realmente factorizadas.
!>

A

!>          A es una matriz COMPLEX, dimensión (LDA,N)
!>          En la entrada, la matriz M-por-N A.
!>          En la salida, el bloque A(OFFSET+1:M,1:KB) es el factor
!>          triangular obtenido y el bloque A(1:OFFSET,1:N) ha sido
!>          pivoteado en consecuencia, pero no factorizado.
!>          El resto de la matriz, bloque A(OFFSET+1:M,KB+1:N) ha
!>          sido actualizado.
!>

LDA

!>          LDA es INTEGER
!>          La dimensión principal del array A. LDA >= max(1,M).
!>

JPVT

!>          JPVT es un array INTEGER, dimensión (N)
!>          JPVT(I) = K <==> La columna K de la matriz completa A ha sido
!>          permutada a la posición I en AP.
!>

TAU

!>          TAU es un array COMPLEX, dimensión (KB)
!>          Los factores escalares de los reflectores elementales.
!>

VN1

!>          VN1 es un array REAL, dimensión (N)
!>          El vector con las normas parciales de las columnas.
!>

VN2

!>          VN2 es un array REAL, dimensión (N)
!>          El vector con las normas exactas de las columnas.
!>

AUXV

!>          AUXV es un array COMPLEX, dimensión (NB)
!>          Vector auxiliar.
!>

F

!>          F es un array COMPLEX, dimensión (LDF,NB)
!>          Matriz F**H = L * Y**H * A.
!>

LDF

!>          LDF es INTEGER
!>          La dimensión principal del array F. LDF >= max(1,N).
!>

NAME

laqps - Solves a general band matrix, or its transpose, using the RI/R2 block QR factorization, with column pivoting.

SYNOPSIS

SUBROUTINE LAQPS( M, N, NB, A, LDA, DUMMY, LDDUMMY, SELECT, D, T, LDT, WORK, INFO )
    INTEGER M, N, NB, LDA, LDDUMMY, LDT, INFO
    LOGICAL SELECT( * )
    REAL D( * ), WORK( * )
    REAL A( LDA, * ), T( LDT, * )
    REAL DUMMY( * )

Detailed_Description

LAQPS solves the equation

A*X = B

when A is an M x N band matrix of rank N. The solution is returned in D and T, where the M x N matrix X is split into D (M x NB) and T (NB x N). LAQPS uses the RI/R2 block QR factorization, with column pivoting.

Function_Documentation

M INTEGER

The number of rows of the matrix A. M >= 0.

N INTEGER

The number of columns of the matrix A. M >= N.

NB INTEGER

The width of the band of the matrix A. NB >= 1.

A REAL array, dimension (LDA,N)

On entry, the M x N band matrix A.

On exit, the upper triangle of A and its subdiagonals is overwritten by the output of the QR factorization. The strictly lower part of A is not used.

LDA INTEGER

The leading dimension of the array A. LDA >= M.

DUMMY REAL array, dimension (LDDUMMY, N)

On entry, DUMMY contains the M x N matrix B. On exit, DUMMY contains the M x N matrix X.

LDDUMMY INTEGER

The leading dimension of the array DUMMY.

SELECT LOGICAL array, dimension (N)

On entry, SELECT specifies the columns of A that are linearly independent. A column j is selected if SELECT(J) is true.

On exit, SELECT is unspecified.

D REAL array, dimension (M)

On entry, D contains the first M entries of the right-hand side vector B. On exit, D contains the first M entries of the solution vector X.

T REAL array, dimension (LDT,N)

On entry, T contains the NB x N upper triangular band matrix R.

On exit, T contains the NB x N upper triangular matrix R.

LDT INTEGER

The leading dimension of the array T. LDT >= NB.

WORK REAL array, dimension (max(M,N))

Workspace array.

INFO INTEGER

= 0: Successfull exit. < 0: If INFO = -i, the i-th argument had an illegal value.
