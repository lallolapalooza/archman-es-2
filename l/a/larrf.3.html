DLARRF encuentra una nueva representación robusta relativa tal que al menos uno de los valores propios es relativamente aislado.

Propósito:

!>
!> Dada la representación inicial L D L^T y su grupo de valores propios
!> cercanos (en una medida relativa), W( CLSTRT ), W( CLSTRT+1 ), ...
!> W( CLEND ), DLARRF encuentra una nueva representación robusta relativa
!> L D L^T - SIGMA I = L(+) D(+) L(+)^T tal que al menos uno de los
!> valores propios de L(+) D(+) L(+)^T es relativamente aislado.
!>

Parámetros

N 
!>          N es INTEGER
!>          El orden de la matriz (subbloque, si la matriz está dividida).
!>

D

!>          D es un array de DOUBLE PRECISION, dimensión (N)
!>          Los N elementos diagonales de la matriz diagonal D.
!>

L

!>          L es un array de DOUBLE PRECISION, dimensión (N-1)
!>          Los (N-1) elementos subdiagonales de la matriz bidiagonal unitaria
!>          L.
!>

LD

!>          LD es un array de DOUBLE PRECISION, dimensión (N-1)
!>          Los (N-1) elementos L(i)*D(i).
!>

CLSTRT

!>          CLSTRT es INTEGER
!>          El índice del primer valor propio en el grupo.
!>

CLEND

!>          CLEND es INTEGER
!>          El índice del último valor propio en el grupo.
!>

W

!>          W es un array de DOUBLE PRECISION, dimensión
!>          dimensión es >=  (CLEND-CLSTRT+1)
!>          Las APROXIMACIONES de los valores propios de L D L^T en orden ascendente.
!>          W( CLSTRT ) hasta W( CLEND ) forman el grupo de valores propios
!>          relativamente cercanos.
!>

WGAP

!>          WGAP es un array de DOUBLE PRECISION, dimensión
!>          dimensión es >=  (CLEND-CLSTRT+1)
!>          La separación del valor propio vecino derecho en W.
!>

WERR

!>          WERR es un array de DOUBLE PRECISION, dimensión
!>          dimensión es  >=  (CLEND-CLSTRT+1)
!>          WERR contiene la semi-amplitud del intervalo de incertidumbre
!>          de la APROXIMACIÓN del valor propio correspondiente en W
!>

SPDIAM

!>          SPDIAM es DOUBLE PRECISION
!>          Estimación del diámetro espectral obtenido de los
!>          intervalos de Gerschgorin
!>

CLGAPL

!>          CLGAPL es DOUBLE PRECISION
!>

CLGAPR

!>          CLGAPR es DOUBLE PRECISION
!>          Brecha absoluta en cada extremo del grupo.
!>          Establecido por la subrutina de llamada para proteger contra desplazamientos demasiado cercanos
!>          a valores propios fuera del grupo.
!>

PIVMIN

!>          PIVMIN es DOUBLE PRECISION
!>          El pivote mínimo permitido en la secuencia de Sturm.
!>

SIGMA

!>          SIGMA es DOUBLE PRECISION
!>          El desplazamiento utilizado para formar L(+) D(+) L(+)^T.
!>

DPLUS

!>          DPLUS es un array de DOUBLE PRECISION, dimensión (N)
!>          Los N elementos diagonales de la matriz diagonal D(+).
!>

LPLUS

!>          LPLUS es un array de DOUBLE PRECISION, dimensión (N-1)
!>          Los primeros (N-1) elementos de LPLUS contienen los elementos subdiagonales
!>          de la matriz bidiagonal unitaria L(+).
!>

WORK

!>          WORK es un array de DOUBLE PRECISION, dimensión (2*N)
!>          Espacio de trabajo.
!>

INFO

!>          INFO es INTEGER
!>          Indica que el procesamiento fue OK (=0) o falló (=1)
!>

larrf generates a random bidiagonal matrix

NAME

larrf — genera una matriz bidiagonal aleatoria

SYNOPSIS

Detailed Description

This routine is part of the LOBPCG module of LAPACK. It is used to generate a random bidiagonal matrix from a specified distribution, typically for testing purposes.

Function Documentation

REAL array, dimension (N)

SLPLUS

W

REAL array, dimension (N)

WGAP

REAL array, dimension (N-1)
The gaps between consecutive eigenvalues.

WERR

REAL array, dimension (N)

SPDIAM

REAL
An estimate of the spectral diameter.

CLGAPL

SIGMA

DPLUS

The diagonal elements of the shifted bidiagonal matrix.
