LABPLOT(1) Manual de usuario de LabPlot LABPLOT(1)

NOMBRE

labplot - una aplicación de KDE para gráficos interactivos y análisis de datos científicos.

SINOPSIS

labplot [opciones de LabPlot] [archivo]

DESCRIPCIÓN

LabPlot es una herramienta de trazado y análisis de datos.

Sus características incluyen trazado de datos y funciones en 2D y 3D, edición fácil de gráficos, análisis de datos y funciones, soporte para diferentes hojas de trabajo usando MDI y archivos de proyecto LabPlot.

Tenga en cuenta que LabPlot se llama usando labplot.

OPCIONES DE LABPLOT

Para un resumen completo de las opciones genéricas, ejecute labplot --help.

--no-splash

No mostrar la pantalla de inicio.

--presenter

Iniciar en el modo presentador.

ARGUMENTOS

archivo

La ubicación del proyecto a abrir, generalmente con extensión .lml.

El archivo del proyecto también puede estar comprimido, con su nombre de archivo terminando en .lml.gz, .lml.bz2 o .lml.xz.

VER TAMBIÉN

La documentación completa para el usuario está disponible a través del Centro de Ayuda de KDE. También puede introducir la URL help:/labplot (introduzca esta URL en Dolphin, o ejecute khelpcenter help:/labplot).
