DOCUMENTACIÓN DE LA FUNCIÓN

subrutina clatrz (entero m, entero n, entero l, complejo, dimensión( lda, * ) a, entero lda, complejo, dimensión( * ) tau, complejo, dimensión( * ) work)

CLATRZ factoriza una matriz trapezoidal superior mediante transformaciones unitarias.

Propósito:

!>
!> CLATRZ factoriza la matriz trapezoidal superior compleja M por (M+L)
!> [ A1 A2 ] = [ A(1:M,1:M) A(1:M,N-L+1:N) ] como ( R  0 ) * Z mediante
!> transformaciones unitarias, donde Z es una matriz unitaria (M+L)-por-(M+L) y
!> R y A1 son matrices triangulares superiores M-por-M.
!>

Parámetros

M 
!>          M es ENTERO
!>          El número de filas de la matriz A.  M >= 0.
!>

N

!>          N es ENTERO
!>          El número de columnas de la matriz A.  N >= 0.
!>

L

!>          L es ENTERO
!>          El número de columnas de la matriz A que contienen la
!>          parte significativa de los vectores de Householder. N-M >= L >= 0.
!>

A

!>          A es array COMPLEJO, dimensión (LDA,N)
!>          En la entrada, la parte trapezoidal superior M-por-N principal de
!>          la matriz A debe contener la matriz a factorizar.
!>          En la salida, la parte triangular superior M-por-M principal de A
!>          contiene la matriz triangular superior R, y los elementos N-L+1 a
!>          N de las primeras M filas de A, junto con el array TAU, representan la
!>          matriz unitaria Z como un producto de M reflectores elementales.
!>

LDA

!>          LDA es ENTERO
!>          La dimensión principal del array A.  LDA >= max(1,M).
!>

TAU

!>          TAU es array COMPLEJO, dimensión (M)
!>          Los factores escalares de los reflectores elementales.
!>

WORK

!>          WORK es array COMPLEJO, dimensión (M)
!>

Detalles Adicionales:

!>
!>  La factorización se obtiene por el método de Householder. La kth
!>  matriz de transformación, Z( k ), que se utiliza para introducir ceros en
!>  la ( m - k + 1 )-ésima fila de A, se da en la forma
!>
!>     Z( k ) = ( I     0   ),
!>              ( 0  T( k ) )
!>
!>  donde
!>
!>     T( k ) = I - tau*u( k )*u( k )**H,   u( k ) = (   1    ),
!>                                                 (   0    )
!>                                                 ( z( k ) )
!>
!>  tau es un escalar y z( k ) es un vector de l elementos. tau y z( k )
!>  se eligen para aniquilar los elementos de la k-ésima fila de A2.
!>
!>  El escalar tau se devuelve en el k-ésimo elemento de TAU y el vector
!>  u( k ) en la k-ésima fila de A2, de tal manera que los elementos de z( k )
!>  estén en a( k, l + 1 ), ..., a( k, n ). Los elementos de R se devuelven en
!>  la parte triangular superior de A1.
!>
!>  Z se da por
!>
!>     Z =  Z( 1 ) * Z( 2 ) * ... * Z( m ).
!>

NAME

slatrz, zlatrz - factoriza una matriz superior trapezoidal mediante transformaciones ortogonales.

SYNOPSIS

subroutine slatrz (integer m, integer n, integer l, real, dimension( lda, * ) a,
                 integer lda, real, dimension( * ) tau, real, dimension( * ) work)
subroutine zlatrz (integer m, integer n, integer l, complex*16, dimension( lda, * ) a,
                 integer lda, complex*16, dimension( * ) tau, complex*16, dimension( * )
                 work)

Detailed Description

SLATRZ factoriza una matriz superior trapezoidal real mediante transformaciones ortogonales.

Purpose:

!>
!> SLATRZ factoriza la matriz superior trapezoidal real M-por-(M+L)
!> [ A1 A2 ] = [ A(1:M,1:M) A(1:M,N-L+1:N) ] como ( R 0 ) * Z, mediante
!> transformaciones ortogonales. Z es una matriz ortogonal (M+L)-por-(M+L)
!> y R y A1 son matrices triangulares superiores M-por-M.
!>

Parameters

M

!>          M is INTEGER
!>          El número de filas de la matriz A. M >= 0.
!>

N

!>          N is INTEGER
!>          El número de columnas de la matriz A. N >= 0.
!>

L

!>          L is INTEGER
!>          El número de columnas de la matriz A que contienen la
!>          parte significativa de los vectores de Householder. N-M >= L >= 0.
!>

A

!>          A is REAL array, dimension (LDA,N)
!>          En la entrada, la parte superior trapezoidal M-por-N líder de la
!>          matriz A debe contener la matriz a factorizar.
!>          En la salida, la parte triangular superior M-por-M líder de A
!>          contiene la matriz triangular superior R, y los elementos N-L+1 a
!>          N de las primeras M filas de A, junto con la matriz TAU, representan la
!>          matriz ortogonal Z como un producto de M transformadores elementales.
!>

LDA

!>          LDA is INTEGER
!>          La dimensión líder de la matriz A. LDA >= max(1,M).
!>

TAU

!>          TAU is REAL array, dimension (M)
!>          Los factores escalares de los transformadores elementales.
!>

WORK

!>          WORK is REAL array, dimension (M)
!>
