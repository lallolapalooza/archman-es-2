subrutina dlasq4 (integer i0, integer n0, double precision, dimension( * ) z, integer pp, integer n0in, double precision dmin, double precision dmin1, double precision dmin2, double precision dn, double precision dn1, double precision dn2, double precision tau, integer ttype, double precision g)

DLASQ4 calcula una aproximación TAU al menor autovalor usando valores de d de la transformación previa. Usado por sbdsqr.

Propósito:

!>
!> DLASQ4 calcula una aproximación TAU al menor autovalor
!> usando valores de d de la transformación previa.
!>

Parámetros

I0 
!>          I0 es INTEGER
!>        Primer índice.
!>

N0

!>          N0 es INTEGER
!>        Último índice.
!>

Z

!>          Z es un array de DOUBLE PRECISION, dimensión ( 4*N0 )
!>        Z contiene el array qd.
!>

PP

!>          PP es INTEGER
!>        PP=0 para ping, PP=1 para pong.
!>

N0IN

!>          N0IN es INTEGER
!>        El valor de N0 al inicio de EIGTEST.
!>

DMIN

!>          DMIN es DOUBLE PRECISION
!>        Valor mínimo de d.
!>

DMIN1

!>          DMIN1 es DOUBLE PRECISION
!>        Valor mínimo de d, excluyendo D( N0 ).
!>

DMIN2

!>          DMIN2 es DOUBLE PRECISION
!>        Valor mínimo de d, excluyendo D( N0 ) y D( N0-1 ).
!>

DN

!>          DN es DOUBLE PRECISION
!>        d(N)
!>

DN1

!>          DN1 es DOUBLE PRECISION
!>        d(N-1)
!>

DN2

!>          DN2 es DOUBLE PRECISION
!>        d(N-2)
!>

TAU

!>          TAU es DOUBLE PRECISION
!>        Este es el desplazamiento.
!>

TTYPE

!>          TTYPE es INTEGER
!>        Tipo de desplazamiento.
!>

G

!>          G es DOUBLE PRECISION
!>        G se pasa como argumento para guardar su valor entre
!>        llamadas a DLASQ4.
!>
