LAST(1) Comandos de usuario LAST(1)

NOMBRE

last, lastb - mostrar un listado de los últimos usuarios conectados

SINOPSIS

last [opciones] [nombredeusuario...] [tty...]

lastb [opciones] [nombredeusuario...] [tty...]

DESCRIPCIÓN

last busca hacia atrás en el archivo /var/log/wtmp (o el archivo designado por la opción -f) y muestra una lista de todos los usuarios conectados (y desconectados) desde que se creó dicho archivo. Se pueden proporcionar uno o más nombresdeusuario y/o ttys, en cuyo caso last mostrará solo las entradas que coincidan con esos argumentos. Los nombres de los ttys se pueden abreviar, por lo tanto, last 0 es lo mismo que last tty0.

Al capturar una señal SIGINT (generada por la tecla de interrupción, generalmente control-C) o una señal SIGQUIT, last mostrará hasta dónde ha buscado en el archivo; en el caso de la señal SIGINT, last terminará.

El usuario pseudo reboot se conecta cada vez que el sistema se reinicia. Por lo tanto, last reboot mostrará un registro de todos los reinicios desde que se creó el archivo de registro.

lastb es lo mismo que last, excepto que por defecto muestra un registro del archivo /var/log/btmp, que contiene todos los intentos de inicio de sesión fallidos.

OPCIONES

-a, --hostlast

Muestra el nombre del host en la última columna. Útil en combinación con la opción --dns.

-d, --dns

Para inicios de sesión no locales, Linux almacena no solo el nombre del host remoto, sino también su número IP. Esta opción traduce el número IP de vuelta a un nombre de host.

-f, --file archivo

Indica a last que use un archivo específico en lugar de /var/log/wtmp. La opción --file se puede especificar múltiples veces, y se procesarán todos los archivos especificados.

-F, --fulltimes

Imprime las fechas y horas completas de inicio y cierre de sesión.

-i, --ip

Similar a --dns, pero muestra el número IP del host en lugar del nombre.

-número; -n, --limit número

Indica a last cuántas líneas mostrar.

-p, --present tiempo

Muestra los usuarios que estaban presentes en el tiempo especificado. Esto es similar a usar las opciones --since y --until juntas con el mismo tiempo.

-R, --nohostname

Suprime la visualización del campo del nombre del host.

-s, --since tiempo

Muestra el estado de los inicios de sesión desde el tiempo especificado. Esto es útil, por ejemplo, para determinar fácilmente quién estaba conectado en un momento determinado. La opción a menudo se combina con --until.

-t, --until tiempo

Muestra el estado de los inicios de sesión hasta el tiempo especificado.

-T, --tab-separated

Utiliza caracteres de tabulación ASCII para separar las columnas en la salida en lugar de espacios.

--time-format formato

Define el formato de la marca de tiempo de salida como uno de notime, short, full o iso. La variante notime no imprimirá ninguna marca de tiempo, short es el predeterminado y full es lo mismo que la opción --fulltimes. La variante iso mostrará la marca de tiempo en formato ISO-8601. El formato ISO contiene información de zona horaria, lo que lo hace preferible cuando las impresiones se investigan fuera del sistema.

-w, --fullnames

Muestra los nombres de usuario completos y los nombres de dominio / direcciones IP en la salida. Los nombres de dominio y las direcciones IP se truncan a 16 caracteres, y los nombres de usuario se truncan a 8 caracteres cuando esta bandera no se especifica. Se establece un asterisco como el último carácter de los campos truncados.

-x, --system

Muestra las entradas de apagado del sistema y los cambios de nivel de ejecución.

-h, --help

Muestra el texto de ayuda y sale.

-V, --version

Muestra la versión y sale.

FORMATOS DE TIEMPO

Las opciones que toman el argumento tiempo entienden los siguientes formatos:

AAAAMMDDhhmmss
AAAA-MM-DD hh:mm:ss
AAAA-MM-DD hh:mm (los segundos se establecerán en 00)
AAAA-MM-DD (la hora se establecerá en 00:00:00)
hh:mm:ss (la fecha se establecerá en hoy)
hh:mm (la fecha se establecerá en hoy, los segundos en 00)
now
yesterday (la hora se establece en 00:00:00)
today (la hora se establece en 00:00:00)
tomorrow (la hora se establece en 00:00:00)
+5min
-5days

ARCHIVOS

/var/log/wtmp, /var/log/btmp

NOTAS

Los archivos wtmp y btmp podrían no encontrarse. El sistema solo registra información en estos archivos si están presentes. Este es un problema de configuración local. Si desea que se utilicen los archivos, se pueden crear con un simple comando touch(1) (por ejemplo, touch /var/log/wtmp).

Una entrada vacía es un tipo válido de entrada de wtmp. Significa que un archivo vacío o un archivo con ceros no se interpreta como un error.

El formato del archivo utmp utiliza tamaños fijos de cadenas, lo que significa que las cadenas muy largas son imposibles de almacenar en el archivo e imposibles de mostrar por last. Los límites habituales son 32 bytes para un nombre de usuario y línea, y 256 bytes para un nombre de host.
