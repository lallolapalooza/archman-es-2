subrutina clapmr (logical forwrd, integer m, integer n, complex, dimension( ldx, * ) x, integer ldx, integer, dimension( * ) k)

CLAPMR reorganiza las filas de una matriz según lo especificado por un vector de permutación.

Propósito:

!>
!> CLAPMR reorganiza las filas de la matriz M por N, X, según lo especificado
!> por la permutación K(1),K(2),...,K(M) de los enteros 1,...,M.
!> Si FORWRD = .TRUE., permutación hacia adelante:
!>
!>      X(K(I),*) se mueve a X(I,*) para I = 1,2,...,M.
!>
!> Si FORWRD = .FALSE., permutación hacia atrás:
!>
!>      X(I,*) se mueve a X(K(I),*) para I = 1,2,...,M.
!>

Parámetros

FORWRD 
!>          FORWRD es LOGICAL
!>          = .TRUE., permutación hacia adelante
!>          = .FALSE., permutación hacia atrás
!>

M

!>          M es INTEGER
!>          El número de filas de la matriz X. M >= 0.
!>

N

!>          N es INTEGER
!>          El número de columnas de la matriz X. N >= 0.
!>

X

!>          X es un array COMPLEX, dimension (LDX,N)
!>          En la entrada, la matriz M por N, X.
!>          En la salida, X contiene la matriz permutada X.
!>

LDX

!>          LDX es INTEGER
!>          La dimensión principal del array X, LDX >= MAX(1,M).
!>

K

!>          K es un array INTEGER, dimension (M)
!>          En la entrada, K contiene el vector de permutación. K se usa como
!>          espacio de trabajo interno, pero se restablece a su valor original en
!>          la salida.
!>

LAPACK - ZLAPMR(3)

NAME

ZLAPMR - apply a permutation to a complex matrix

SYNOPSIS

SUBROUTINE ZLAPMR(
    ROWVEC, M, N, X, LDX, K
    )

CHARACTER ROWVEC
INTEGER M, N, LDX
COMPLEX*16 X( LDX, * )
INTEGER K( * )

Detailed Description

ZLAPMR applies a Householder matrix H, or a sequence of Householder matrices to a real matrix X. H is a unitary matrix defined by the outer product h*h', and is composed of a sequence of Householder blocks.

The Householder vectors are stored in the array K.

Arguments:

-- ROWVEC

 !>          ROWVEC is CHARACTER*1
 !>          = 'R': row and column indices are swapped.
 !>          = 'C': row and column indices are not swapped.
 !>

-- M

 !>          M is INTEGER
 !>          The number of rows of the matrix X. M >= 0.
 !>

-- N

 !>          N is INTEGER
 !>          The number of columns of the matrix X. N >= 0.
 !>

-- X

 !>          X is COMPLEX*16 array, dimension (LDX,N)
 !>          On entry, the M by N matrix X.
 !>          On exit, X contains the permuted matrix X.
 !>

-- LDX

 !>          LDX is INTEGER
 !>          The leading dimension of the array X, LDX >= MAX(1,M).
 !>

-- K

 !>          K is INTEGER array, dimension (M)
 !>          On entry, K contains the permutation vector. K is used as
 !>          internal workspace, but reset to its original value on
 !>          output.
 !>
