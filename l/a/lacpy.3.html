subrutina clacpy (character uplo, integer m, integer n, complex, dimension( lda, * ) a, integer lda, complex, dimension( ldb, * ) b, integer ldb)

CLACPY copia toda o parte de una matriz bidimensional a otra.

Propósito:

!>
!> CLACPY copia toda o parte de una matriz bidimensional A a otra
!> matriz B.
!>

Parámetros

UPLO 
!>          UPLO es CHARACTER*1
!>          Especifica la parte de la matriz A a copiar en B.
!>          = 'U':      Parte triangular superior
!>          = 'L':      Parte triangular inferior
!>          Otro:       Toda la matriz A
!>

M

!>          M es INTEGER
!>          El número de filas de la matriz A.  M >= 0.
!>

N

!>          N es INTEGER
!>          El número de columnas de la matriz A.  N >= 0.
!>

A

!>          A es un array de COMPLEX, dimension (LDA,N)
!>          La matriz A de m por n.  Si UPLO = 'U', solo se accede a la
!>          trapezoide superior; si UPLO = 'L', solo se accede a la
!>          trapezoide inferior.
!>

LDA

!>          LDA es INTEGER
!>          La dimensión principal del array A.  LDA >= max(1,M).
!>

B

!>          B es un array de COMPLEX, dimension (LDB,N)
!>          A la salida, B = A en las ubicaciones especificadas por UPLO.
!>

LDB

!>          LDB es INTEGER
!>          La dimensión principal del array B.  LDB >= max(1,M).
!>

LACPY(3)

NAME

lacpy - copies a rectangular portion of a matrix to another matrix.

SYNOPSIS

 SUBROUTINE LACPY(
    UPLO, M, N, A, LDA, B, LDB )

    CHARACTER(1)           :: UPLO
    INTEGER                :: LDA, LDB, M, N
    COMPLEX*16             :: A( LDA, * ), B( LDB, * )

Detailed Description

LACPY copies a rectangular portion of the matrix A to another rectangular portion of the matrix B.

A specifies the upper or lower triangle of the matrix A to be copied, and B specifies the upper or lower triangle of the matrix B. The elements of the other triangle are not accessed.

The elements of the two matrices may be overwritten.

====================================================================

Function Documentation

UPLO

!>          UPLO is CHARACTER*1
!>          Specifies the part of the matrix A to be copied and               
!>          copied into B.                                                     
!>          = 'U':  Upper triangle of A is to be copied into the upper         
!>                  triangle of B.                                             
!>          = 'L':  Lower triangle of A is to be copied into the lower         
!>                  triangle of B.                                             
!>          = 'A':  All elements of A are to be copied into all elements       
!>                  of B.                                                      
!>

M

!>          M is INTEGER
!>          The number of rows of the matrix A.  M >= 0.
!>

N

!>          N is INTEGER
!>          The number of columns of the matrix A.  N >= 0.
!>

A

!>          A is COMPLEX*16 array, dimension (LDA,N)
!>          The m by n matrix A.  If UPLO = 'U', only the upper trapezium
!>          is accessed; if UPLO = 'L', only the lower trapezium is
!>          accessed.
!>

LDA

!>          LDA is INTEGER
!>          The leading dimension of the array A.  LDA >= max(1,M).
!>

B

!>          B is COMPLEX*16 array, dimension (LDB,N)
!>          On exit, B = A in the locations specified by UPLO.
!>

LDB

!>          LDB is INTEGER
!>          The leading dimension of the array B.  LDB >= max(1,M).
!>
