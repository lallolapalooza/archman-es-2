subrutina dlaed4 (integer n, integer i, double precision, dimension( * ) d, double precision, dimension( * ) z, double precision, dimension( * ) delta, double precision rho, double precision dlam, integer info)

DLAED4 utilizado por DSTEDC. Encuentra una única raíz de la ecuación secular.

Propósito:

!>
!> Esta subrutina calcula el I-ésimo valor propio actualizado de una modificación
!> de rango uno simétrica a una matriz diagonal cuyos elementos están
!> dados en el array d, y tal que
!>
!>            D(i) < D(j)  para  i < j
!>
!> y que RHO > 0. Esto está organizado por la rutina de llamada y no supone
!> una pérdida de generalidad. El sistema modificado de rango uno es por lo tanto
!>
!>            diag( D )  +  RHO * Z * Z_transpose.
!>
!> donde asumimos que la norma euclidiana de Z es 1.
!>
!> El método consiste en aproximar las funciones racionales en la
!> ecuación secular por funciones racionales interpoladoras más simples.
!>

Parámetros

N 
!>          N es ENTERO
!>         La longitud de todos los arrays.
!>

I

!>          I es ENTERO
!>         El índice del valor propio a calcular.  1 <= I <= N.
!>

D

!>          D es un array de DOBLE PRECISIÓN, dimensión (N)
!>         Los valores propios originales. Se asume que están en orden,
!>         D(I) < D(J) para I < J.
!>

Z

!>          Z es un array de DOBLE PRECISIÓN, dimensión (N)
!>         Los componentes del vector de actualización.
!>

DELTA

!>          DELTA es un array de DOBLE PRECISIÓN, dimensión (N)
!>         Si N > 2, DELTA contiene (D(j) - lambda_I) en su j-ésimo
!>         componente. Si N = 1, entonces DELTA(1) = 1. Si N = 2, consulte DLAED5
!>         para obtener detalles. El vector DELTA contiene la información necesaria
!>         para construir los vectores propios mediante DLAED3 y DLAED9.
!>

RHO

!>          RHO es DOBLE PRECISIÓN
!>         El escalar en la fórmula de actualización simétrica.
!>

DLAM

!>          DLAM es DOBLE PRECISIÓN
!>         El lambda_I calculado, el I-ésimo valor propio actualizado.
!>

INFO

!>          INFO es ENTERO
!>         = 0:  salida exitosa
!>         > 0:  si INFO = 1, el proceso de actualización falló.
!>

Parámetros Internos:

!>  La variable lógica ORGATI (origin-at-i?) se utiliza para distinguir
!>  si D(i) o D(i+1) se trata como el origen.
!>
!>            ORGATI = .true.    origen en i
!>            ORGATI = .false.   origen en i+1
!>
!>   La variable lógica SWTCH3 (switch-for-3-poles?) sirve para indicar
!>   si estamos trabajando con TRES polos.
!>
!>   MAXIT es el número máximo de iteraciones permitidas para cada
!>   valor propio.
!>

NAME

laed4 - solves the 1-dimensional, homogeneous, linear, constant-coefficient, recurrence relation

SYNOPSIS

SUBROUTINE laed4(N, AMP, PARM, RES, UPPER, LL, LR, SR, SC, INFO)

INTEGER N

DOUBLE PRECISION AMP

DOUBLE PRECISION PARM(3)

DOUBLE PRECISION RES(3)

LOGICAL UPPER

DOUBLE PRECISION LL(N)

DOUBLE PRECISION LR(N)

DOUBLE PRECISION SR(3)

DOUBLE PRECISION SC(3)

INTEGER INFO

Detailed Description

laed4 solves the 1-dimensional, homogeneous, linear, constant-coefficient, recurrence relation of order 3, which arises in solving the initial value problem for the scalar tridiagonalizable linear system of ODEs

du/dt = Au, u(0) = u0

where A is a symmetric tridiagonal matrix. laed4 is used by the subroutine laed1.

Author: Univ. of Tennessee Univ. of California Berkeley Lawrence Livermore National Laboratory

September 2007

This routine is a modification of laed3. The modification is designed to prevent the repeated calculation of zeros, which previously occurred when the eigenvalues are close to one of the diagonal entries of the matrix A.

Arguments:

N: (input) The dimension of the matrix A. N >= 1.

AMP: (input) The scaling factor, which is Amp = sqrt(1/Eigval(i)).

PARM: (input) Vector PARM(1:3) which stores the initial values of the recurrence relation.

RES: (output) Vector RES(1:3) which stores the values of the recurrence relation at the final step.

UPPER: (input) Logical flag which is .TRUE. if the recurrence relation is evaluated from top to bottom and .FALSE. if it is evaluated from bottom to top.

LL: (input) Vector LL(1:N) which stores the initial values of the recurrence relation.

LR: (input) Vector LR(1:N) which stores the initial values of the recurrence relation.

SR: (output) Vector SR(1:3) which stores the initial values of the recurrence relation.

SC: (output) Vector SC(1:3) which stores the initial values of the recurrence relation.

INFO: (output) INTEGER.

INFO = 0: successful computation.

INFO = -1: Recurrence relation is not satisfied.

INFO = -2: Recurrence relation is not satisfied.

INFO = -3: Recurrence relation is not satisfied.
