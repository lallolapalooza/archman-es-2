Documentación de la función

subrutina clar2v (integer n, complex, dimension( * ) x, complex, dimension( * ) y, complex, dimension( * ) z, integer incx, real, dimension( * ) c, complex, dimension( * ) s, integer incc)

CLAR2V aplica un vector de rotaciones de plano complejas con cosenos reales desde ambos lados a una secuencia de matrices hermitianas complejas de 2x2.

Propósito:

!>
!> CLAR2V aplica un vector de rotaciones de plano complejas con cosenos reales
!> desde ambos lados a una secuencia de matrices hermitianas complejas de 2x2,
!> definidas por los elementos de los vectores x, y y z. Para i = 1,2,...,n
!>
!>    (       x(i)  z(i) ) :=
!>    ( conjg(z(i)) y(i) )
!>
!>      (  c(i) conjg(s(i)) ) (       x(i)  z(i) ) ( c(i) -conjg(s(i)) )
!>      ( -s(i)       c(i)  ) ( conjg(z(i)) y(i) ) ( s(i)        c(i)  )
!>

Parámetros

N 
!>          N es INTEGER
!>          El número de rotaciones de plano a aplicar.
!>

X

!>          X es un array COMPLEX, dimension (1+(N-1)*INCX)
!>          El vector x; se asume que los elementos de x son reales.
!>

Y

!>          Y es un array COMPLEX, dimension (1+(N-1)*INCX)
!>          El vector y; se asume que los elementos de y son reales.
!>

Z

!>          Z es un array COMPLEX, dimension (1+(N-1)*INCX)
!>          El vector z.
!>

INCX

!>          INCX es INTEGER
!>          El incremento entre elementos de X, Y y Z. INCX > 0.
!>

C

!>          C es un array REAL, dimension (1+(N-1)*INCC)
!>          Los cosenos de las rotaciones de plano.
!>

S

!>          S es un array COMPLEX, dimension (1+(N-1)*INCC)
!>          Los senos de las rotaciones de plano.
!>

INCC

!>          INCC es INTEGER
!>          El incremento entre elementos de C y S. INCC > 0.
!>

lar2v(3) - LAPACK

NAME

lar2v — applies a vector of plane rotations with real cosines and complex sines from both sides to a sequence of 2-by-2 symmetric/Hermitian matrices.

SYNOPSIS

SUBROUTINE SLAR2V(N, X, INCX, Y, INCY, C, INCC, S, INCC)

  INTEGER N
  REAL X(1+(N-1)*INCX), Y(1+(N-1)*INCC)
  INTEGER INCX, INCC
  DOUBLE PRECISION C(1+(N-1)*INCC)
  REAL S(1+(N-1)*INCC)

SUBROUTINE ZLAR2V(N, X, INCX, Y, INCY, C, INCC, S, INCC)

  INTEGER N
  COMPLEX*16 X(1+(N-1)*INCX), Y(1+(N-1)*INCC)
  INTEGER INCX, INCC
  DOUBLE PRECISION C(1+(N-1)*INCC)
  COMPLEX*16 S(1+(N-1)*INCC)

Detailed Description

Purpose:

SLAR2V applies a vector of plane rotations with real cosines and complex sines
from both sides to a sequence of 2-by-2 symmetric/Hermitian matrices.
For i = 1,2,...,n

   (       x(i)  z(i) ) :=
   ( conjg(z(i)) y(i) )

     (  c(i) conjg(s(i)) ) (       x(i)  z(i) ) ( c(i) -conjg(s(i)) )
     ( -s(i)       c(i)  ) ( conjg(z(i)) y(i) ) ( s(i)        c(i)  )

ZLAR2V applies a vector of complex plane rotations with real cosines
from both sides to a sequence of 2-by-2 complex Hermitian matrices,
defined by the elements of the vectors x, y and z. For i = 1,2,...,n

   (       x(i)  z(i) ) :=
   ( conjg(z(i)) y(i) )

     (  c(i) conjg(s(i)) ) (       x(i)  z(i) ) ( c(i) -conjg(s(i)) )
     ( -s(i)       c(i)  ) ( conjg(z(i)) y(i) ) ( s(i)        c(i)  )
