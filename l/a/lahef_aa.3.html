CLAHEF_AA

Propósito:

!>
!> CLAHEF_AA factoriza un panel de una matriz hermítica compleja A usando
!> el algoritmo de Aasen. El panel consiste en un conjunto de NB filas de A
!> cuando UPLO es U, o un conjunto de NB columnas cuando UPLO es L.
!>
!> Para factorizar el panel, el algoritmo de Aasen requiere la última fila, o
!> columna, del panel anterior. La primera fila, o columna, de A se establece
!> como la primera fila, o columna, de una matriz identidad, que se utiliza
!> para factorizar el primer panel.
!>
!> La fila J resultante de U, o la columna J de L, se almacena en la fila
!> (J-1) o columna de A (sin las diagonales unitarias), mientras que la
!> diagonal y subdiagonal de A se sobrescriben con las de T.
!>
!>

Parámetros

UPLO 
!>          UPLO es CHARACTER*1
!>          = 'U':  Se almacena el triángulo superior de A;
!>          = 'L':  Se almacena el triángulo inferior de A.
!>

J1

!>          J1 es INTEGER
!>          La ubicación de la primera fila, o columna, del panel
!>          dentro de la submatriz de A, pasada a esta rutina, por ejemplo,
!>          cuando se llama desde CHETRF_AA, para el primer panel, J1 es 1,
!>          mientras que para los paneles restantes, J1 es 2.
!>

M

!>          M es INTEGER
!>          La dimensión de la submatriz. M >= 0.
!>

NB

!>          NB es INTEGER
!>          La dimensión del panel a factorizar.
!>

A

!>          A es un array COMPLEX, de dimensiones (LDA,M) para
!>          el primer panel, mientras que de dimensiones (LDA,M+1) para
!>          los paneles restantes.
!>
!>          En la entrada, A contiene la última fila o columna
!>          del panel anterior, y la submatriz final de A
!>          a factorizar, excepto para el primer panel, solo
!>          se pasa el panel.
!>
!>          En la salida, el panel principal está factorizado.
!>

LDA

!>          LDA es INTEGER
!>          La dimensión principal del array A. LDA >= max(1,N).
!>

IPIV

!>          IPIV es un array INTEGER, de dimensión (N)
!>          Detalles de los intercambios de filas y columnas,
!>          la fila y columna k se intercambiaron con la fila y
!>          columna IPIV(k).
!>

H

!>          H es un espacio de trabajo COMPLEX, de dimensión (LDH,NB).
!>
!>

LDH

!>          LDH es INTEGER
!>          La dimensión principal del espacio de trabajo H. LDH >= max(1,M).
!>

WORK

!>          WORK es un espacio de trabajo COMPLEX, de dimensión (M).
!>

NAME

dlasyf_aa, slasyf_aa, zlasyf_aa - factorization of a panel of a symmetric or Hermitian matrix using Aasen's algorithm

SYNOPSIS

Fortran

subroutine dlasyf_aa (uplo, j1, m, nb, a, lda, ipiv, h, ldh, work)
character uplo
integer j1, m, nb, lda, ldh
double precision a(lda, *)
integer ipiv(*)
double precision h(ldh, *)
double precision work(*)

subroutine slasyf_aa (uplo, j1, m, nb, a, lda, ipiv, h, ldh, work)
character uplo
integer j1, m, nb, lda, ldh
real a(lda, *)
integer ipiv(*)
real h(ldh, *)
real work(*)

subroutine zlasyf_aa (uplo, j1, m, nb, a, lda, ipiv, h, ldh, work)
character uplo
integer j1, m, nb, lda, ldh
complex*16 a(lda, *)
integer ipiv(*)
complex*16 h(ldh, *)
complex*16 work(*)

DESCRIPTION

The routines dlasyf_aa, slasyf_aa, and zlasyf_aa factorize a panel of a real symmetric (d, s) or complex Hermitian (z) matrix A using Aasen's algorithm. The panel consists of a set of NB rows of A when UPLO is 'U', or a set of NB columns when UPLO is 'L'.

In order to factorize the panel, Aasen's algorithm requires the last row, or column, of the previous panel. The first row, or column, of A is set to be the first row, or column, of an identity matrix, which is used to factorize the first panel.

The resulting J-th row of U, or J-th column of L, is stored in the (J-1)-th row, or column, of A (without the unit diagonals), while the diagonal and subdiagonal of A are overwritten by those of T.

PARAMETERS

UPLO

UPLO is CHARACTER*1
= 'U': Upper triangle of A is stored;
= 'L': Lower triangle of A is stored.

J1

J1 is INTEGER
The location of the first row, or column, of the panel within the submatrix of A, passed to this routine, e.g., when called by DSYTRF_AA, for the first panel, J1 is 1, while for the remaining panels, J1 is 2.

M

M is INTEGER
The dimension of the submatrix. M >= 0.

NB

NB is INTEGER
The dimension of the panel to be factorized.

A

A is DOUBLE PRECISION array, dimension (LDA,M) for the first panel, while dimension (LDA,M+1) for the remaining panels.
On entry, A contains the last row, or column, of the previous panel, and the trailing submatrix of A to be factorized, except for the first panel, only the panel is passed.
On exit, the leading panel is factorized.

LDA

LDA is INTEGER
The leading dimension of the array A. LDA >= max(1,M).

IPIV

IPIV is INTEGER array, dimension (M)
Details of the row and column interchanges, the row and column k were interchanged with the row and column IPIV(k).

H

H is DOUBLE PRECISION workspace, dimension (LDH,NB).

LDH

LDH is INTEGER
The leading dimension of the workspace H. LDH >= max(1,M).

WORK

WORK is DOUBLE PRECISION workspace, dimension (M).

SEE

The Aasen's algorithm is described in:

J. K. Cullum and R. A. Willoughby, "A Lanczos algorithm for computing the smallest or largest eigenvalues of a large, sparse, symmetric, band matrix," *J. Comp. Phys.*, vol. 34, pp. 362-374, 1980.

and also in:

N. J. Higham, "A new block L D L^T factorization is stable," *SIAM J. Matrix Anal. Appl.*, vol. 10, pp. 587-599, 1989.

In addition, the routine uses routines from the LAPACK routines.

DLASYF_AA

Purpose:

!>
!> DLATRF_AA factorizes a panel of a real symmetric matrix A using
!> the Aasen's algorithm. The panel consists of a set of NB rows of A
!> when UPLO is U, or a set of NB columns when UPLO is L.
!>
!> In order to factorize the panel, the Aasen's algorithm requires the
!> last row, or column, of the previous panel. The first row, or column,
!> of A is set to be the first row, or column, of an identity matrix,
!> which is used to factorize the first panel.
!>
!> The resulting J-th row of U, or J-th column of L, is stored in the
!> (J-1)-th row, or column, of A (without the unit diagonals), while
!> the diagonal and subdiagonal of A are overwritten by those of T.
!>
!>

Parameters

UPLO 
!>          UPLO is CHARACTER*1
!>          = 'U':  Upper triangle of A is stored;
!>          = 'L':  Lower triangle of A is stored.
!>

J1

!>          J1 is INTEGER
!>          The location of the first row, or column, of the panel
!>          within the submatrix of A, passed to this routine, e.g.,
!>          when called by DSYTRF_AA, for the first panel, J1 is 1,
!>          while for the remaining panels, J1 is 2.
!>

M

!>          M is INTEGER
!>          The dimension of the submatrix. M >= 0.
!>

NB

!>          NB is INTEGER
!>          The dimension of the panel to be facotorized.
!>

A

!>          A is DOUBLE PRECISION array, dimension (LDA,M) for
!>          the first panel, while dimension (LDA,M+1) for the
!>          remaining panels.
!>
!>          On entry, A contains the last row, or column, of
!>          the previous panel, and the trailing submatrix of A
!>          to be factorized, except for the first panel, only
!>          the panel is passed.
!>
!>          On exit, the leading panel is factorized.
!>

LDA

!>          LDA is INTEGER
!>          The leading dimension of the array A.  LDA >= max(1,M).
!>

IPIV

!>          IPIV is INTEGER array, dimension (M)
!>          Details of the row and column interchanges,
!>          the row and column k were interchanged with the row and
!>          column IPIV(k).
!>

H

!>          H is DOUBLE PRECISION workspace, dimension (LDH,NB).
!>
!>

LDH

!>          LDH is INTEGER
!>          The leading dimension of the workspace H. LDH >= max(1,M).
!>

WORK

!>          WORK is DOUBLE PRECISION workspace, dimension (M).
!>

zlasyf_aa(3)

NAME

zlasyf_aa — factorizes a panel of a complex symmetric matrix

SYNOPSIS

SUBROUTINE ZLASYF_AA(UPLO, J1, M, NB, A, LDA, IPIV, H, LDH, WORK)
    CHARACTER UPLO
    INTEGER J1, M, NB, LDA, IPIV(*), LDH

    COMPLEX*16 A(LDA, *), H(LDH, *), WORK(*)

Detailed Description

ZLASYF_AA factorizes a panel of a complex symmetric matrix A using the Aasen's algorithm. The panel consists of a set of NB rows of A when UPLO is U, or a set of NB columns when UPLO is L.

In order to factorize the panel, the Aasen's algorithm requires the last row, or column, of the previous panel. The first row, or column, of A is set to be the first row, or column, of an identity matrix, which is used to factorize the first panel.

The resulting J-th row of U, or J-th column of L, is stored in the (J-1)-th row, or column, of A (without the unit diagonals), while the diagonal and subdiagonal of A are overwritten by those of T.
