NAME

la_gerpvgrw - this provides a row-wise interface to la_gerpv.

SYNOPSIS

SUBROUTINE LA_GERPVGRW(
    M, N, A, LDA, AF, LDAF, IPIV, WORK, LWORK, INFO)
INTEGER :: M, N, LDA, LDAF, INFO
INTEGER, DIMENSION(:), INTENT(IN) :: IPIV
COMPLEX*16 :: A(LDA, *)
COMPLEX*16 :: AF(LDAF, *)
COMPLEX*16, DIMENSION(:), ALLOCATABLE :: WORK
INTEGER :: LWORK

Detailed Description

la_gerpvgrw performs the following steps:

  1. Computes the L*P*Q*R factorization of the matrix A.

  2. Copies the factors L and U from the array AF.

  3. Applies the row permutations P and Q to the array A.

  4. Applies the row permutations R to the array A.

It is intended as a row-wise interface to the LAPACK routine ZGERQP.

The problem is solved by calling the LAPACK routine ZGERQP and then applying the row permutations P, Q and R to the array A.

The function ZGERQP computes the L*P*Q*R factorization of a general M-by-N matrix A and thus

A = L*P*Q*R

where:

  • P is an M-by-M permutation matrix, selected by a partial pivotal strategy.

  • L is an M-by-K lower trapezoidal matrix with subdiagonal entries of modulus at most 1.

  • Q is a K-by-N upper triangular matrix with non-zero diagonal entries.

  • R is an N-by-N upper triangular matrix.

  • K = min(M, N).

The factorization is computed by the recursive block method ZGERQPRRR.

The matrix L is represented by the entries in A below the diagonal.

The matrix Q is represented by the entries in AF above the diagonal.

The matrix R is represented by the entries in AF on and above the diagonal.

The permutation matrices P, Q, and R are represented by the pivot indices returned in IPIV.

The algorithm computes the factorization

A = P L R

in place, where P is a unit upper triangular matrix, and R is a trapezoidal matrix. The LU factorization is then updated by applying the pivots.

The function ZGERQP overwrites the array A with the factors L and U. The entries above the diagonal of AF contain the matrix U, and the subdiagonal entries of AF contain the unit lower triangular matrix L.

The permutation vector IPIV records the pivotal exchanges during the factorization.

The LAPACK routines that call this routine are ZGELQF, ZGEQPF, ZGERQPRRR, ZGERQPRN, ZGERQPS, ZGERQPT.

Function Documentation

M

M is INTEGER

The number of rows of the matrix A.

M >= 0.

N

N is INTEGER

The number of columns of the matrix A.

N >= 0.

A

A is COMPLEX*16 array, dimension (LDA,N)

On entry, the M-by-N matrix A.

On exit, the factors L and U from the factorization

A = P*L*U as computed by ZGETRF.

LDA

LDA is INTEGER

The leading dimension of the array A. LDA >= max(1,M).

AF

AF is COMPLEX*16 array, dimension (LDAF,N)

The factors L and U from the factorization

A = P*L*U as computed by ZGETRF.

LDAF

LDAF is INTEGER

The leading dimension of the array AF. LDAF >= max(1,N).

IPIV

IPIV is INTEGER array, dimension (min(M,N))

The pivot indices of the factorization.

IPIV[i] = k

means that the row i was swapped with row k.

WORK

WORK is COMPLEX*16 array, dimension (LWORK)

On exit, WORK(1) = LWORK.

LWORK

LWORK is INTEGER

The dimension of the array WORK. LWORK >= max(1,N).

For optimum performance, LWORK is in the range: LWORK >= max(1,N) * nb, where nb is the block size.

INFO

INFO is INTEGER

= 0: successful exit. < 0: if INFO = -i, the i-th argument had an illegal value. > 0: if INFO = i, the i-th diagonal element of U is zero. L*U is singular.
