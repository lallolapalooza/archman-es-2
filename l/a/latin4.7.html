NOMBRE

iso_8859-4 - Conjunto de caracteres ISO/IEC 8859-4 codificado en octal, decimal y hexadecimal

DESCRIPCIÓN

El estándar ISO/IEC 8859 incluye varias extensiones de 8 bits al conjunto de caracteres ASCII (también conocido como ISO/IEC 646-IRV). ISO/IEC 8859-4 codifica los caracteres utilizados en las lenguas escandinavas y bálticas.

Alfabetos ISO/IEC 8859

El conjunto completo de alfabetos ISO/IEC 8859 incluye:

ISO/IEC 8859-1 Idiomas de Europa Occidental (Latin-1)
ISO/IEC 8859-2 Idiomas de Europa Central y Oriental (Latin-2)
ISO/IEC 8859-3 Idiomas del Sudeste de Europa y misceláneos (Latin-3)
ISO/IEC 8859-4 Idiomas escandinavos/bálticos (Latin-4)
ISO/IEC 8859-5 Latín/Cirílico
ISO/IEC 8859-6 Latín/Árabe
ISO/IEC 8859-7 Latín/Griego
ISO/IEC 8859-8 Latín/Hebreo
ISO/IEC 8859-9 Modificación de Latin-1 para turco (Latin-5)
ISO/IEC 8859-10 Idiomas lapón/nórdico/esquimales (Latin-6)
ISO/IEC 8859-11 Latín/Tailandés
ISO/IEC 8859-13 Idiomas del Báltico (Latin-7)
ISO/IEC 8859-14 Celta (Latin-8)
ISO/IEC 8859-15 Idiomas de Europa Occidental (Latin-9)
ISO/IEC 8859-16 Rumano (Latin-10)

NAME

latin4 - ISO/IEC 8859-4 character set

DESCRIPTION

ISO/IEC 8859-4 defines the 8-bit character set known as Latin-4. It is intended for the languages of Northern Europe. It covers Danish, Estonian, Latvian, Lithuanian, Finnish, Sami, and Swedish.

The character set is a superset of ASCII and occupies the upper 128 characters (codepoints 128 through 255) of the 8-bit space.
