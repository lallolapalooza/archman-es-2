NOMBRE

l3sys-query

SINOPSIS

l3sys-query <cmd> [<opciones>] [<argumentos>]

DESCRIPCIÓN

El script l3sys-query proporciona un método para que las ejecuciones de TeX obtengan información del sistema a través de escapes de shell a Lua. Las facilidades son más limitadas que el script similar texosquery de Java, pero como utiliza Lua, l3sys-query puede usarse 'tal cual' con cualquier sistema TeX instalado. El script está escrito teniendo en cuenta los requisitos de seguridad de TeX Live; por lo tanto, es adecuado para su uso con escape de shell restringido, la configuración estándar al instalar un sistema TeX.

COMANDOS

Los <cmd> válidos son:
ls Imprime una lista basada en los <argumentos> y <opciones>
pwd Imprime el directorio de trabajo actual

OPCIONES

Las <opciones> válidas son:
--exclude [<arg_x>] Excluye entradas de la lista de directorios
--help|-h Imprime este mensaje y sale
--ignore-case Ignora mayúsculas/minúsculas al ordenar la lista de directorios
--pattern|-p Trata los (arg_x) como un patrón de Lua
--recursive|-r Activa la lista de directorios recursiva
--reverse Invierte el orden de clasificación
--sort [name|date] Método utilizado para ordenar la lista de directorios
--type [d|f] Selecciona solo los directorios o archivos en una lista
--version|-v Imprime información de la versión y sale
