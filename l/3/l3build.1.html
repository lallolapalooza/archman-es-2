L3BUILD(1) Manual de Comandos Generales L3BUILD(1)

NOMBRE

l3build

SINOPSIS


Uso l3build <objetivo> [<opciones>] [<nombres>]

DESCRIPCIÓN

El módulo "l3build" está diseñado para soportar el desarrollo de código LaTeX de alta calidad proporcionando:


* Un sistema de pruebas unitarias


* Compilación automática de fuentes de código


* Un sistema de empaquetado fiable para lanzamientos de CTAN

El paquete consta de un script Lua para ejecutar las tareas y un archivo ".tex" que proporciona el entorno de pruebas. Estos se desarrollaron originalmente para dar soporte al desarrollo de LaTeX, pero están diseñados para que otros puedan utilizarlos fácilmente. Se proporciona documentación completa.

COMANDOS

Los objetivos válidos son:
check Ejecuta todas las pruebas automatizadas
clean Limpia el árbol de directorios
ctan Crea un archivo listo para CTAN
doc Compila los archivos de documentación
install Instala archivos en el árbol local texmf
manifest Crea un archivo de manifiesto
save Guarda el registro de validación de pruebas
tag Actualiza las etiquetas de versión en los archivos
uninstall Desinstala archivos del árbol local texmf
unpack Descomprime los archivos fuente en el árbol de compilación
upload Envía el archivo a CTAN para su lanzamiento público

OPCIONES

Las opciones válidas son:
--config|-c Establece la(s) configuración(es) utilizada(s) para ejecutar las pruebas
--date|-d Establece la fecha a insertar en las fuentes
--debug Ejecuta el objetivo en modo de depuración
--dev Utiliza el formato LaTeX de desarrollo
--dirty Omite la limpieza del área de pruebas
--dry-run Ejecución de prueba para instalación o carga
--email Dirección de correo electrónico del cargador de CTAN
--engine|-e Establece el(los) motor(es) a utilizar para ejecutar la prueba
--epoch Establece la época para pruebas y compilación
--file|-F Toma el anuncio de carga del archivo proporcionado
--first Nombre de la primera prueba a ejecutar
--full Instala todos los archivos
--halt-on-error|-H Detiene la ejecución de pruebas tras el primer fallo
--help|-h Imprime este mensaje y sale
--last Nombre de la última prueba a ejecutar
--message|-m Texto para el mensaje de anuncio de carga
--quiet|-q Suprime la salida de TeX al descomprimir
--rerun Omite la configuración: simplemente vuelve a ejecutar las pruebas
--show-log-on-error Muestra el registro completo del fallo con 'halt-on-error'
--show-saves|-S Muestra la invocación para actualizar los archivos .tlg fallidos
--shuffle Mezcla el orden de las pruebas
--stdengine|-s Ejecuta pruebas con el motor std (dependiente de la configuración)
--texmfhome Ubicación del árbol texmf del usuario
--version Imprime información de la versión y sale
