NOMBRE

lwp-dump - Ver qué encabezados y contenido se devuelven para una URL

SINOPSIS

lwp-dump [ opciones ] URL

DESCRIPCIÓN

El programa lwp-dump obtendrá el recurso identificado por la URL y luego volcará el objeto de respuesta a STDOUT. Esto mostrará los encabezados devueltos y la parte inicial del contenido, escapados para que sea seguro mostrar incluso contenido binario. La sintaxis de escape utilizada es la misma que para las cadenas entrecomilladas dobles de Perl. Si no hay contenido, se muestra la cadena "(no content)" en su lugar.

Se reconocen las siguientes opciones:

--agent cadena
Anula la cadena del agente de usuario pasada al servidor.
--keep-client-headers
LWP genera internamente varios encabezados "Client-*" que son eliminados por lwp-dump para mostrar los encabezados exactamente como los proporcionó el servidor. Esta opción suprimirá esto.
--max-length n
Cuánto contenido mostrar. El valor predeterminado es 512. Establécelo a 0 para ilimitado.

Si el contenido es más largo, la cadena se trunca en el límite y se añade la cadena "...\n(### more bytes not shown)".

--method cadena
Utiliza el método dado para la solicitud en lugar del predeterminado "GET".
--parse-head
Por defecto, lwp-dump no intentará inicializar encabezados mirando la sección head de los documentos HTML. Esta opción la habilita. Esto corresponde a "parse_head" en LWP::UserAgent.
--request
También volcar la solicitud enviada.

VER TAMBIÉN

lwp-request, LWP, "dump" en HTTP::Message
