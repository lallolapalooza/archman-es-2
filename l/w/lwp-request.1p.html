NOMBRE

lwp-request - Agente de usuario simple de línea de comandos

SINOPSIS

lwp-request [-afPuUsSedvhx] [-m método] [-b URL base] [-t tiempo de espera]
[-i if-modified-since] [-c tipo de contenido]
[-C credenciales] [-p URL de proxy] [-o formato] url...

DESCRIPCIÓN

Este programa puede ser utilizado para enviar peticiones a servidores WWW y a su sistema de archivos local. El contenido de la petición para los métodos POST, PUT y PATCH se lee desde stdin. El contenido de la respuesta se imprime en stdout. Los mensajes de error se imprimen en stderr. El programa devuelve un valor de estado indicando el número de URLs que fallaron.

Las opciones son:

-m <método>
Establece el método a utilizar para la petición. Si esta opción no se usa, el método se deriva del nombre del programa.
-f
Fuerza la petición, incluso si el programa cree que el método es ilegal. El servidor podría rechazar la petición eventualmente.
-b <uri>
Esta URI se usará como URI base para resolver todas las URIs relativas dadas como argumento.
-t <tiempo de espera>
Establece el valor de tiempo de espera para las peticiones. El tiempo de espera es la cantidad de tiempo que el programa esperará una respuesta del servidor remoto antes de fallar. La unidad predeterminada para el valor de tiempo de espera son segundos. Puede añadir "m" o "h" al valor de tiempo de espera para que sean minutos u horas, respectivamente. El tiempo de espera predeterminado es '3m', es decir, 3 minutos.
-i <tiempo>
Establece la cabecera If-Modified-Since en la petición. Si tiempo es el nombre de un archivo, usa la marca de tiempo de modificación de este archivo. Si tiempo no es un archivo, se analiza como una fecha literal. Consulte HTTP::Date para ver los formatos reconocidos.
-c <tipo de contenido>
Establece el Content-Type para la petición. Esta opción solo está permitida para peticiones que toman contenido, es decir, POST, PUT y PATCH. Puede forzar que los métodos tomen contenido usando la opción "-f" junto con "-c". El Content-Type predeterminado para POST es "application/x-www-form-urlencoded". El Content-type predeterminado para los otros es "text/plain".
-p <URL de proxy>
Establece el proxy a utilizar para las peticiones. El programa también carga la configuración del proxy desde el entorno. Puede deshabilitar esto con la opción "-P".
-P
No cargue la configuración del proxy desde el entorno.
-H <cabecera>
Envía esta cabecera HTTP con cada petición. Puede especificar varias, p.ej.: 
lwp-request \
    -H 'Referer: http://other.url/' \
    -H 'Host: somehost' \
    http://this.url/

Si el nombre de la cabecera va precedido por dos puntos, no se canonicará (Ver "NOMBRES DE CAMPO NO CANONIZADOS" en HTTP::Headers).

-C <nombre de usuario>:<contraseña>
Proporciona credenciales para documentos protegidos por autenticación básica. Si el documento está protegido y no especificó el nombre de usuario y la contraseña con esta opción, se le pedirá que proporcione estos valores.

Las siguientes opciones controlan lo que se muestra por el programa:

-u
Imprime el método de la petición y la URL absoluta a medida que se realizan las peticiones.
-U
Imprime las cabeceras de la petición además del método de la petición y la URL absoluta.
-s
Imprime el código de estado de la respuesta. Esta opción siempre está activa para las peticiones HEAD.
-S
Imprime la cadena de estado de la respuesta. Esto muestra las peticiones de redirección y autorización que son manejadas por la biblioteca.
-e
Imprime las cabeceras de la respuesta. Esta opción siempre está activa para las peticiones HEAD.
-E
Imprime la cadena de estado de la respuesta con las cabeceras de respuesta completas.
-d
No imprima el contenido de la respuesta.
-o <formato>
Procesa el contenido HTML de varias maneras antes de imprimirlo. Si el tipo de contenido de la respuesta no es HTML, entonces esta opción no tiene efecto. Los valores de formato legales son; "text", "ps", "links", "html" y "dump".

Si especifica el formato "text", el HTML se formateará como texto plano "latin1". Si especifica el formato "ps", se formateará como Postscript.

El formato "links" generará todos los enlaces encontrados en el documento HTML. Los enlaces relativos se expandirán a absolutos.

El formato "html" reformateará el código HTML y el formato "dump" simplemente volcará el árbol de sintaxis HTML.

Tenga en cuenta que la distribución "HTML-Tree" debe estar instalada para que esta opción funcione. Además, la distribución "HTML-Format" debe estar instalada para que "-o text" o "-o ps" funcionen.

-v
Imprime el número de versión del programa y sale.
-h
Imprime el mensaje de uso y sale.
-a
Establece el modo texto (ascii) para la entrada y salida de contenido. Si esta opción no se usa, la entrada y salida de contenido se realiza en modo binario.

Dado que este programa está implementado utilizando la biblioteca LWP, solo admitirá los protocolos que LWP soporta.
