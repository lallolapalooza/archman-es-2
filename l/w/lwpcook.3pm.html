NAME

lwpcook - El libro de cocina de libwww-perl

DESCRIPTION

Este documento contiene algunos ejemplos que muestran el uso típico de la biblioteca libwww-perl. Deberías consultar la documentación de los módulos individuales para obtener más detalles.

Todos los ejemplos deberían ser programas ejecutables. Puedes, en la mayoría de los casos, probar las secciones de código enviando el texto del programa directamente a perl.

GET

Es muy fácil usar esta biblioteca para simplemente obtener documentos de la red. El módulo LWP::Simple proporciona la función get() que devuelve el documento especificado por su argumento URL:

use LWP::Simple;
$doc = get 'http://search.cpan.org/dist/libwww-perl/';

o, como un one-liner de perl usando la función getprint():

perl -MLWP::Simple -e 'getprint "http://search.cpan.org/dist/libwww-perl/"'

o, ¿qué tal obtener el último perl ejecutando este comando?:

perl -MLWP::Simple -e '
  getstore "ftp://ftp.sunet.se/pub/lang/perl/CPAN/src/latest.tar.gz",
           "perl.tar.gz"'

Probablemente primero querrás encontrar un sitio CPAN más cercano ejecutando algo como el siguiente comando:

perl -MLWP::Simple -e 'getprint "http://www.cpan.org/SITES.html"'

¡Suficiente de estas cosas simples! La interfaz orientada a objetos de LWP te da más control sobre la solicitud enviada al servidor. Usando esta interfaz tienes control total sobre las cabeceras enviadas y cómo quieres manejar la respuesta devuelta.

use LWP::UserAgent;
$ua = LWP::UserAgent->new;
$ua->agent("$0/0.1 " . $ua->agent);
# $ua->agent("Mozilla/8.0") # pretendemos ser un navegador muy capaz
$req = HTTP::Request->new(
   GET => 'http://search.cpan.org/dist/libwww-perl/');
$req->header('Accept' => 'text/html');
# enviar la solicitud
$res = $ua->request($req);
# comprobar el resultado
if ($res->is_success) {
   print $res->decoded_content;
}
else {
   print "Error: " . $res->status_line . "\n";
}

El programa lwp-request (alias GET) que se distribuye con la biblioteca también puede usarse para obtener documentos de servidores WWW.

HEAD

Si solo quieres comprobar si un documento está presente (es decir, si la URL es válida) intenta ejecutar código que se parezca a esto:

use LWP::Simple;
if (head($url)) {
   # ok, el documento existe
}

La función head() realmente devuelve una lista de meta-información sobre el documento. Los tres primeros valores de la lista devuelta son el tipo de documento, el tamaño del documento y la antigüedad del documento.

Se requiere un mayor control sobre la solicitud o acceso a todos los valores de cabecera devueltos para usar la interfaz orientada a objetos descrita para GET arriba. Simplemente reemplaza GET con HEAD.

POST

No hay una interfaz de procedimiento simple para enviar datos a un servidor WWW. Debes usar la interfaz orientada a objetos para esto. La operación POST más común es acceder a una aplicación de formulario WWW:

use LWP::UserAgent;
$ua = LWP::UserAgent->new;
my $req = HTTP::Request->new(
    POST => 'https://rt.cpan.org/Public/Dist/Display.html');
$req->content_type('application/x-www-form-urlencoded');
$req->content('Status=Active&Name=libwww-perl');
my $res = $ua->request($req);
print $res->as_string;

Las personas perezosas usan el módulo HTTP::Request::Common para configurar un mensaje de solicitud POST adecuado (maneja todos los problemas de escape) y tiene un valor predeterminado adecuado para el content_type:

use HTTP::Request::Common qw(POST);
use LWP::UserAgent;
$ua = LWP::UserAgent->new;
my $req = POST 'https://rt.cpan.org/Public/Dist/Display.html',
              [ Status => 'Active', Name => 'libwww-perl' ];
print $ua->request($req)->as_string;

El programa lwp-request (alias POST) que se distribuye con la biblioteca también puede usarse para enviar datos.

PROXIES

Algunos sitios usan proxies para pasar por máquinas cortafuegos, o simplemente como caché para mejorar el rendimiento. Los proxies también se pueden usar para acceder a recursos a través de protocolos no soportados directamente (o mal soportados :-) por la biblioteca libwww-perl.

Debes inicializar la configuración de tu proxy antes de empezar a enviar solicitudes:

use LWP::UserAgent;
$ua = LWP::UserAgent->new;
$ua->env_proxy; # inicializar desde variables de entorno
# o
$ua->proxy(ftp  => 'http://proxy.myorg.com');
$ua->proxy(wais => 'http://proxy.myorg.com');
$ua->no_proxy(qw(no se fi));
my $req = HTTP::Request->new(GET => 'wais://xxx.com/');
print $ua->request($req)->as_string;

La interfaz LWP::Simple llamará a env_proxy() automáticamente por ti. Las aplicaciones que usan el método $ua->env_proxy() normalmente no usarán los métodos $ua->proxy() y $ua->no_proxy().

Algunos proxies también requieren que les envíes un nombre de usuario/contraseña para permitir el paso de las solicitudes. Deberías poder añadir la cabecera requerida, con algo como esto:

use LWP::UserAgent;
$ua = LWP::UserAgent->new;
$ua->proxy(['http', 'ftp'] => 'http://username:password@proxy.myorg.com');
$req = HTTP::Request->new('GET',"http://www.perl.com");
$res = $ua->request($req);
print $res->decoded_content if $res->is_success;

Reemplaza "proxy.myorg.com", "username" y "password" con algo adecuado para tu sitio.

ACCESO A DOCUMENTOS PROTEGIDOS

Los documentos protegidos por autorización básica se pueden acceder fácilmente así:

use LWP::UserAgent;
$ua = LWP::UserAgent->new;
$req = HTTP::Request->new(GET => 'http://www.linpro.no/secret/');
$req->authorization_basic('aas', 'mypassword');
print $ua->request($req)->as_string;

La otra alternativa es proporcionar una subclase de LWP::UserAgent que anule el método get_basic_credentials(). Estudia el programa lwp-request para un ejemplo de esto.

COOKIES

A algunos sitios les gusta jugar con las cookies. Por defecto, LWP ignora las cookies proporcionadas por los servidores que visita. LWP recopilará cookies y responderá a las solicitudes de cookies si configuras un cookie jar. LWP no proporciona un cookie jar por sí mismo, pero si instalas HTTP::CookieJar::LWP, se puede usar así:

use LWP::UserAgent;
use HTTP::CookieJar::LWP;
$ua = LWP::UserAgent->new(
    cookie_jar => HTTP::CookieJar::LWP->new,
);
# y luego envía solicitudes como solías hacerlo
$res = $ua->request(HTTP::Request->new(GET => "http://no.yahoo.com/"));
print $res->status_line, "\n";

HTTPS

Las URL con el esquema https se acceden exactamente de la misma manera que con el esquema http, siempre que se haya instalado correctamente un módulo de interfaz SSL para LWP (consulta el archivo README.SSL que se encuentra en la distribución de libwww-perl para más detalles). Si no hay una interfaz SSL instalada para que LWP la use, obtendrás errores de "501 Protocol scheme 'https' is not supported" al acceder a dichas URL.

Aquí tienes un ejemplo de cómo obtener e imprimir una página WWW usando SSL:

use LWP::UserAgent;
my $ua = LWP::UserAgent->new;
my $req = HTTP::Request->new(GET => 'https://www.helsinki.fi/');
my $res = $ua->request($req);
if ($res->is_success) {
    print $res->as_string;
}
else {
    print "Failed: ", $res->status_line, "\n";
}

MIRRORING

Si quieres hacer mirror de documentos de un servidor WWW, intenta ejecutar código similar a este a intervalos regulares:

use LWP::Simple;
%mirrors = (
   'http://www.sn.no/'                       => 'sn.html',
   'http://www.perl.com/'                    => 'perl.html',
   'http://search.cpan.org/distlibwww-perl/' => 'lwp.html',
   'gopher://gopher.sn.no/'                  => 'gopher.html',
);
while (($url, $localfile) = each(%mirrors)) {
   mirror($url, $localfile);
}

O, como un one-liner de perl:

perl -MLWP::Simple -e 'mirror("http://www.perl.com/", "perl.html")';

El documento no se transferirá a menos que se haya actualizado.

DOCUMENTOS GRANDES

Si el documento que desea obtener es demasiado grande para mantenerlo en memoria, tiene dos alternativas. Puede indicar a la biblioteca que escriba el contenido del documento en un archivo (segundo argumento de $ua->request() es un nombre de archivo):

use LWP::UserAgent;
$ua = LWP::UserAgent->new;
my $req = HTTP::Request->new(GET =>
    'http://www.cpan.org/CPAN/authors/id/O/OA/OALDERS/libwww-perl-6.26.tar.gz');
$res = $ua->request($req, "libwww-perl.tar.gz");
if ($res->is_success) {
   print "ok\n";
}
else {
   print $res->status_line, "\n";
}

O puede procesar el documento a medida que llega (el segundo argumento de $ua->request() es una referencia de código):

use LWP::UserAgent;
$ua = LWP::UserAgent->new;
$URL = 'ftp://ftp.isc.org/pub/rfc/rfc-index.txt';
my $expected_length;
my $bytes_received = 0;
my $res =
   $ua->request(HTTP::Request->new(GET => $URL),
             sub {
                 my($chunk, $res) = @_;
                 $bytes_received += length($chunk);
                 unless (defined $expected_length) {
                    $expected_length = $res->content_length || 0;
                 }
                 if ($expected_length) {
                      printf STDERR "%d%% - ",
                                100 * $bytes_received / $expected_length;
                 }
                 print STDERR "$bytes_received bytes received\n";
                 # XXX Realmente debería hacer algo con el chunk en sí
                 # print $chunk;
             });
 print $res->status_line, "\n";
