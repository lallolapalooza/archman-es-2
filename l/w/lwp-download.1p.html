LWP-DOWNLOAD(1) Documentación de Perl aportada por el usuario LWP-DOWNLOAD(1)

NOMBRE

lwp-download - Obtener archivos grandes de la web

SINOPSIS

lwp-download [-a] [-s] <url> [<ruta local>]
Opciones:
  -a   guardar el archivo en modo ASCII
  -s   usar cabeceras HTTP para adivinar el nombre de archivo de salida

DESCRIPCIÓN

El programa lwp-download guardará el archivo en url en un archivo local.

Si no se especifica ruta local, se asume el directorio actual.

Si ruta local es un directorio, se añade el último segmento de la ruta de la url para formar un nombre de archivo local. Si la ruta de la url termina en barra, se usa el nombre "index". Con la opción -s, se recoge el último segmento del nombre de archivo de fuentes proporcionadas por el servidor, como la cabecera Content-Disposition o cualquier URL de redirección. También se puede añadir una extensión de archivo para que coincida con el Content-Type informado por el servidor. Si ya existe un archivo con el nombre de archivo generado, entonces lwp-download preguntará antes de sobrescribirlo y fallará si su entrada estándar no es una terminal. Esta forma de invocación también fallará si no se puede derivar ningún nombre de archivo aceptable de las fuentes mencionadas anteriormente.

Si ruta local no es un directorio, simplemente se utiliza como la ruta a la que guardar. Si el archivo ya existe, se sobrescribe.

El programa lwp-download está implementado utilizando la biblioteca libwww-perl. Es más adecuado para descargar archivos grandes que el programa lwp-request porque no almacena el archivo en memoria. Otro beneficio es que te mantendrá informado sobre su progreso y que no tienes muchas opciones de las que preocuparte.

Utilice la opción "-a" para guardar el archivo en modo texto (ASCII). Podría marcar la diferencia en sistemas tipo DOS.

EJEMPLO

Obtener la versión más reciente y genial de Perl:

$ lwp-download http://www.perl.com/CPAN/src/latest.tar.gz
Guardando en 'latest.tar.gz'...
11.4 MB recibidos en 8 segundos (1.43 MB/sec)
