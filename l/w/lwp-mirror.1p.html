NOMBRE

lwp-mirror - Utilidad de espejo simple

SINOPSIS

lwp-mirror [-v] [-t timeout] <url> <archivo local>

DESCRIPCIÓN

Este programa se puede utilizar para reflejar un documento desde un servidor WWW. El documento solo se transfiere si la copia remota es más reciente que la copia local. Si la copia local es más reciente, no sucede nada.

Use la opción "-v" para imprimir el número de versión de este programa.

El valor de tiempo de espera especificado con la opción "-t". El valor de tiempo de espera es el tiempo que el programa esperará una respuesta del servidor remoto antes de fallar. La unidad predeterminada para el valor de tiempo de espera son segundos. Puede agregar "m" o "h" al valor de tiempo de espera para que sean minutos u horas, respectivamente.

Dado que este programa está implementado utilizando la biblioteca LWP, solo admite los protocolos que LWP admite.

VEASE TAMBIÉN

lwp-request, LWP
