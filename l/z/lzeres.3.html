Propósito:

!>
!> Programa de prueba para BLAS de Nivel 2 COMPLEX*16.
!>
!> El programa debe ser dirigido por un archivo de datos corto. Los primeros 18 registros
!> se leen usando entrada de lista dirigida, los últimos 17 registros
!> se leen usando el formato ( A6, L2 ). Un ejemplo anotado de un archivo de datos
!> se puede obtener eliminando los primeros 3 caracteres de las siguientes 35 líneas:
!> 'zblat2.out'      NOMBRE DEL ARCHIVO DE SALIDA DEL RESUMEN
!> 6                 NÚMERO DE UNIDAD DEL ARCHIVO DE RESUMEN
!> 'CBLA2T.SNAP'     NOMBRE DEL ARCHIVO DE SALIDA DEL INSTANTÁNEA
!> -1                NÚMERO DE UNIDAD DEL ARCHIVO DE INSTANTÁNEA (NO USADO SI .LT. 0)
!> F        BANDERA LÓGICA, T PARA REBOBINAR EL ARCHIVO DE INSTANTÁNEA DESPUÉS DE CADA REGISTRO.
!> F        BANDERA LÓGICA, T PARA DETENERSE EN CASOS DE FALLO.
!> T        BANDERA LÓGICA, T PARA PROBAR LAS SALIDAS DE ERROR.
!> 16.0     VALOR UMBRAL DE LA RELACIÓN DE PRUEBA

uplo = 'L' or 'l': Lower triangular.
n
INTEGER.
On entry, n is the order of the matrix A.
a
COMPLEX*16.
On entry, the symmetric positive definite matrix A.
lda
INTEGER.
On entry, lda is the leading dimension of the array A.
lwork
INTEGER.
On entry, lwork is the dimension of the array WA.
wa
COMPLEX*16.
On exit, if info = 0, the array WA contains the Cholesky factor L of A (if uplo = 'L'), or the Cholesky factor U of A (if uplo = 'U') in terms of which the factorization of A is performed.
info
INTEGER.
On exit, info is an integer if entry was not successful.
