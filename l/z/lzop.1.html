NOMBRE

lzop - comprimir o descomprimir archivos

RESUMEN

lzop es un compresor de archivos muy similar a gzip. lzop favorece la velocidad sobre la relación de compresión.

SINOPSIS

lzop [ comando ] [ opciones ] [ nombre_archivo ...  ]

lzop [-dxlthIVL19] [-qvcfFnNPkU] [-o archivo] [-p[ruta]] [-S sufijo] [nombre_archivo ...]

DESCRIPCIÓN

lzop reduce el tamaño de los archivos nombrados. Siempre que sea posible, cada archivo se comprime en uno con la extensión .lzo, manteniendo los mismos permisos, acceso y tiempos de modificación. Si no se especifican archivos, o si el nombre de archivo es "-", lzop intenta comprimir la entrada estándar a la salida estándar. lzop solo intentará comprimir archivos regulares o enlaces simbólicos a archivos regulares. En particular, ignorará los directorios.

Si el nombre del archivo comprimido es demasiado largo para su sistema de archivos, lzop lo trunca.

Los archivos comprimidos se pueden restaurar a su forma original usando lzop -d. lzop -d toma una lista de archivos en su línea de comandos y descomprime cada archivo cuyo nombre termina en .lzo y que comienza con el número mágico correcto a un archivo descomprimido sin la extensión original. lzop -d también reconoce la extensión especial .tzo como atajo para .tar.lzo. Al comprimir, lzop utiliza la extensión .tzo si es necesario en lugar de truncar un archivo con extensión .tar.

lzop almacena el nombre original del archivo, el modo y la marca de tiempo en el archivo comprimido. Estos pueden ser utilizados al descomprimir el archivo con la opción -d. Esto es útil cuando el nombre del archivo comprimido fue truncado o cuando la marca de tiempo no se preservó después de una transferencia de archivos.

lzop preserva la propiedad, el modo y la marca de tiempo de los archivos al comprimir. Al descomprimir, lzop restaura el modo y la marca de tiempo si están presentes en los archivos comprimidos. Consulte las opciones -n, -N, --no-mode y --no-time para más información.

lzop siempre mantiene los archivos originales sin cambios a menos que utilice la opción -U.

lzop utiliza la biblioteca LZO data compression library para los servicios de compresión. La cantidad de compresión obtenida depende del tamaño de la entrada y la distribución de subcadenas comunes. Típicamente, el texto como código fuente o inglés se comprime al 40-50% del tamaño original, y los archivos grandes generalmente se comprimen mucho mejor que los pequeños. La velocidad de compresión y descompresión es generalmente mucho más rápida que la lograda por gzip, pero la relación de compresión es peor.

NIVELES DE COMPRESIÓN

lzop ofrece los siguientes niveles de compresión del algoritmo LZO1X:

-3
el nivel por defecto ofrece una compresión bastante rápida. -2, -3, -4, -5 y -6 son actualmente equivalentes; esto puede cambiar en una futura versión.
-1, --fast
puede ser un poco más rápido en algunos casos, pero la mayoría de las veces no notarás la diferencia
-7, -8, -9, --best
estos niveles de compresión están destinados principalmente a generar datos precomprimidos; especialmente -9 puede ser algo lento

La descompresión es muy rápida para todos los niveles de compresión, y la velocidad de descompresión no se ve afectada por el nivel de compresión.

COMANDO PRINCIPAL

Si no se proporciona ningún otro comando, lzop utiliza la compresión por defecto (usando el nivel de compresión -3).

-#, --fast, --best
Regula la velocidad de compresión usando el dígito especificado #, donde -1 o --fast indica el método de compresión más rápido (menos compresión) y -9 o --best indica el método de compresión más lento (mejor compresión). El nivel de compresión por defecto es -3.
-d, --decompress, --uncompress
Descomprimir. Cada archivo se colocará en el mismo directorio que el archivo comprimido.
-x, --extract
Extraer archivos comprimidos al directorio de trabajo actual. Esto es lo mismo que '-dPp'.
-t, --test
Probar. Comprobar la integridad del archivo comprimido.
-l, --list
Para cada archivo comprimido, listar los siguientes campos: 
método: método de compresión
comprimido: tamaño del archivo comprimido
descomp.: tamaño del archivo descomprimido
ratio: relación de compresión
nombre_descomprimido: nombre del archivo descomprimido

En combinación con la opción --verbose, también se muestran los siguientes campos:

fecha y hora: marca de tiempo del archivo descomprimido

Con --name, el nombre y la fecha y hora descomprimidos son los almacenados en el archivo comprimido si están presentes.

Con --verbose, las sumas totales de tamaño y la relación de compresión para todos los archivos también se muestran. Con --quiet, las líneas de título y totales no se muestran.

Tenga en cuenta que lzop define la relación de compresión como tamaño_comprimido / tamaño_descomprimido.

--ls, --ls=FLAGS
Listar cada archivo comprimido en un formato similar a ls -ln.

Las siguientes banderas se reconocen actualmente:
F Añadir un '*' para los archivos ejecutables.
G Inhibir la visualización de información de grupo.
Q Encerrar los nombres de archivo entre comillas dobles.

--info
Para cada archivo comprimido, listar los campos internos de la cabecera.
-I, --sysinfo
Mostrar información sobre el sistema y salir.
-L, --license
Mostrar la licencia de lzop y salir.
-h, -H, --help
Mostrar una pantalla de ayuda y salir.
-V
Versión. Mostrar el número de versión y las opciones de compilación y salir.
--version
Versión. Mostrar el número de versión y salir.

OPCIONES

-c, --stdout, --to-stdout
Escribir la salida en la salida estándar. Si hay varios archivos de entrada, la salida consiste en una secuencia de miembros independientemente (des)comprimidos. Para obtener una mejor compresión, concatene todos los archivos de entrada antes de comprimirlos.
-o ARCHIVO, --output=ARCHIVO
Escribir la salida en el archivo ARCHIVO. Si hay varios archivos de entrada, la salida consiste en una secuencia de miembros independientemente (des)comprimidos.
-p, -pDIR, --path=DIR
Escribir los archivos de salida en el directorio DIR en lugar del directorio determinado por el archivo de entrada. Si se omite DIR, entonces se escribe en el directorio de trabajo actual.
-f, --force
Forzar a lzop a 
- sobrescribir archivos existentes
- (des)comprimir desde stdin incluso si parece un terminal
- (des)comprimir a stdout incluso si parece un terminal
- permitir la opción -c en combinación con -U

Usar -f dos o más veces fuerza cosas como

- comprimir archivos que ya tienen un sufijo .lzo
- intentar descomprimir archivos que no tienen un sufijo válido
- intentar manejar archivos comprimidos con indicadores de cabecera desconocidos

Úselo con precaución.

-F, --no-checksum
No almacenar ni verificar una suma de verificación del archivo descomprimido al comprimir o descomprimir. Esto acelera un poco la operación de lzop (especialmente al descomprimir), pero como la corrupción de datos no notada puede ocurrir en caso de archivos comprimidos dañados, el uso de esta opción no se recomienda en general. Además, siempre se almacena una suma de verificación al comprimir con uno de los niveles de compresión lentos (-7, -8 o -9), independientemente de esta opción.
-n, --no-name
Al descomprimir, no restaurar el nombre original del archivo si está presente (eliminar solo el sufijo lzop del nombre del archivo comprimido). Esta opción es la predeterminada en UNIX.

OPCIONES DE SALIDA

-N, --name
Al descomprimir, restaura el nombre de archivo original si está presente. Esta opción es útil en sistemas que tienen un límite en la longitud del nombre de archivo. Si el nombre original guardado en el archivo comprimido no es adecuado para su sistema de archivos, se construye un nuevo nombre a partir del original para hacerlo legal. Esta opción es la predeterminada en DOS, Windows y OS/2.
-P
Al descomprimir, restaura el nombre de la ruta y el archivo originales si están presentes. Al comprimir, almacena el nombre de la ruta (y limpio) relativo. Esta opción es principalmente útil cuando se usa el modo de archivo; consulte los ejemplos de uso a continuación.
--no-mode
Al descomprimir, no restaura el modo (permisos) original guardado en el archivo comprimido.
--no-time
Al descomprimir, no restaura la marca de tiempo original guardada en el archivo comprimido.
-S .suf, --suffix=.suf
Utiliza el sufijo .suf en lugar de .lzo. El sufijo no debe contener múltiples puntos ni caracteres especiales como '+' o '*', y se deben evitar sufijos distintos de .lzo para evitar confusiones cuando los archivos se transfieren a otros sistemas.
-k, --keep
No elimine los archivos de entrada. Esta es la opción predeterminada.
-U, --unlink, --delete
Elimina los archivos de entrada después de una compresión o descompresión exitosa. Utilice esta opción para que lzop se comporte como gzip y bzip2. Tenga en cuenta que dar explícitamente -k anula -U.
--crc32
Utiliza una suma de verificación crc32 en lugar de una suma de verificación adler32.
--no-warn
Suprime todas las advertencias.
--ignore-warn
Suprime todas las advertencias y nunca sale con el estado de salida 2.
-q, --quiet, --silent
Suprime todas las advertencias y disminuye la verbosidad de algunos comandos como --list o --test.
-v, --verbose
Verboso. Muestra el nombre de cada archivo comprimido o descomprimido. Se pueden usar múltiples -v para aumentar la verbosidad de algunos comandos como --list o --test.
--
Indica que este es el final de las opciones. Cualquier nombre de archivo después de -- no se interpretará como una opción, incluso si comienza con un guión.

OTRAS OPCIONES

--no-stdin
No intente leer la entrada estándar (pero un nombre de archivo "-" todavía anulará esta opción). En versiones antiguas de lzop, esta opción era necesaria cuando se usaba en trabajos cron (que no tienen una terminal controladora).
--filter=NÚMERO
Raramente útil. Preprocesa los datos con un filtro especial "multimedia" antes de comprimir para mejorar la relación de compresión. NÚMERO debe ser un número decimal de 1 a 16, inclusive. Usar un filtro ralentiza bastante tanto la compresión como la descompresión, y la relación de compresión generalmente tampoco mejora mucho... Sin embargo, es posible que se agreguen filtros más efectivos en el futuro.

Puedes probar --filter=1 con datos como muestras de sonido de 8 bits, --filter=2 con muestras de 16 bits o imágenes de profundidad 16, etc.

El desenfiltrado durante la descompresión se maneja automáticamente.

-C, --checksum
Obsoleto. Solo por compatibilidad con versiones muy antiguas, ya que lzop ahora usa una suma de verificación por defecto. Esta opción se eliminará en una versión futura.
--no-color
No usar secuencias de escape de color.
--mono
Asumir una terminal ANSI mono. Esta es la opción predeterminada en UNIX (si la compatibilidad con la consola está compilada).
--color
Asumir una terminal ANSI a color o intentar acceso a pantalla completa. Esta es la opción predeterminada en DOS y en una consola virtual de Linux (si la compatibilidad con la consola está compilada).

USO AVANZADO

lzop te permite tratar tus archivos de muchas maneras flexibles. Aquí tienes algunos ejemplos de uso:

modo de copia de seguridad
tar --use-compress-program=lzop -cf archive.tar.lzo files..
Este es el modo recomendado para crear copias de seguridad.
Requiere GNU tar o una versión compatible que acepte la
opción '--use-compress-program=XXX'.
modo de archivo único: comprimir/descomprimir cada archivo individualmente
crear
  lzop a.c             -> crear a.c.lzo
  lzop a.c b.c         -> crear a.c.lzo & b.c.lzo
  lzop -U a.c b.c      -> crear a.c.lzo & b.c.lzo y eliminar a.c & b.c
  lzop *.c
extraer
  lzop -d a.c.lzo      -> restaurar a.c
  lzop -df a.c.lzo     -> restaurar a.c, sobrescribir si ya existe
  lzop -d *.lzo
listar
  lzop -l a.c.lzo
  lzop -l *.lzo
  lzop -lv *.lzo       -> ser verboso
probar
  lzop -t a.c.lzo
  lzop -tq *.lzo       -> ser silencioso
modo de tubería: comprimir/descomprimir desde stdin a stdout
crear
  lzop < a.c > y.lzo
  cat a.c | lzop > y.lzo
  tar -cf - *.c | lzop > y.tar.lzo     -> crear un archivo tar comprimido
extraer
  lzop -d < y.lzo > a.c
  lzop -d < y.tar.lzo | tar -xvf -     -> extraer un archivo tar
listar
  lzop -l < y.lzo
  cat y.lzo | lzop -l
  lzop -d < y.tar.lzo | tar -tvf -     -> listar un archivo tar
probar
  lzop -t < y.lzo
  cat y.lzo | lzop -t
modo stdout: comprimir/descomprimir a stdout
crear
  lzop -c a.c > y.lzo
extraer
  lzop -dc y.lzo > a.c
  lzop -dc y.tar.lzo | tar -xvf -      -> extraer un archivo tar
listar
  lzop -dc y.tar.lzo | tar -tvf -      -> listar un archivo tar
modo de archivo: comprimir/extraer múltiples archivos en un solo archivo de archivo
crear
  lzop a.c b.c -o sources.lzo          -> crear un archivo
  lzop -P src/*.c -o sources.lzo       -> crear un archivo, almacenar el nombre de la ruta
  lzop -c *.c > sources.lzo            -> otra forma de crear un archivo
  lzop -c *.h >> sources.lzo           -> añadir archivos al archivo
extraer
  lzop -dN sources.lzo
  lzop -x ../src/sources.lzo           -> extraer al directorio actual
  lzop -x -p/tmp < ../src/sources.lzo  -> extraer al directorio /tmp
listar
  lzop -lNv sources.lzo
probar
  lzop -t sources.lzo
  lzop -tvv sources.lzo                -> ser muy verboso

Si deseas crear un único archivo con múltiples miembros para que los miembros puedan extraerse de forma independiente más tarde, deberías preferir un archivador con todas las funciones como tar. La última versión de GNU tar admite la opción --use-compress-program=lzop para invocar lzop de forma transparente. lzop está diseñado como un complemento de tar, no como un reemplazo.

ENTORNO

La variable de entorno LZOP puede contener un conjunto de opciones predeterminadas para lzop. Estas opciones se interpretan primero y pueden ser anuladas por parámetros explícitos de la línea de comandos. Por ejemplo:

para sh/ksh/zsh:    LZOP="-1v --name"; export LZOP
para csh/tcsh:      setenv LZOP "-1v --name"
para DOS/Windows:   set LZOP=-1v --name

En Vax/VMS, el nombre de la variable de entorno es LZOP_OPT, para evitar un conflicto con el símbolo establecido para la invocación del programa.

No todas las opciones son válidas en la variable de entorno; lzop te lo dirá.

DIAGNÓSTICOS

El estado de salida es normalmente 0; si ocurre un error, el estado de salida es 1. Si ocurre una advertencia, el estado de salida es 2 (a menos que la opción --ignore-warn esté activa).

Los diagnósticos de lzop están diseñados para ser autoexplicativos.
