NOMBRE

ldns_verify, ldns_verify_rrsig, ldns_verify_rrsig_keylist, ldns_verify_rrsig_keylist_notime, ldns_verify_notime - verificar rrsigs

SINOPSIS

#include <stdint.h>
#include <stdbool.h>

#include <ldns/ldns.h>

ldns_status ldns_verify(ldns_rr_list *rrset, ldns_rr_list *rrsig, const ldns_rr_list *keys, ldns_rr_list *good_keys);

ldns_status ldns_verify_rrsig(ldns_rr_list *rrset, ldns_rr *rrsig, ldns_rr *key);

ldns_status ldns_verify_rrsig_keylist(ldns_rr_list *rrset, ldns_rr *rrsig, const ldns_rr_list *keys, ldns_rr_list *good_keys);

ldns_status ldns_verify_rrsig_keylist_notime(const ldns_rr_list *rrset, const ldns_rr *rrsig, const ldns_rr_list *keys, ldns_rr_list *good_keys);

ldns_status ldns_verify_notime(ldns_rr_list *rrset, ldns_rr_list *rrsig, const ldns_rr_list *keys, ldns_rr_list *good_keys);

DESCRIPCION

ldns_verify() Verifica una lista de firmas para un conjunto de rrsets.

rrset: el conjunto de rrsets a verificar
rrsig: una lista de firmas a comprobar
keys: una lista de claves para comprobar
good_keys: si esta es una lista (inicializada), se añade a ella el puntero a las claves de keys que validan una de las firmas
Devuelve el estado LDNS_STATUS_OK si hay al menos una clave correcta

ldns_verify_rrsig() verifica una rrsig con 1 clave
rrset: el conjunto de rrsets
rrsig: la rrsig a verificar
key: la clave a usar
Devuelve un mensaje de estado indicando si la verificación tuvo éxito.

ldns_verify_rrsig_keylist() Verifica una rrsig. Se intentan todas las claves del conjunto de claves.
rrset: el conjunto de rrsets a comprobar
rrsig: la firma del conjunto de rrsets
keys: las claves a intentar
good_keys: si esta es una lista (inicializada), se añade a ella el puntero a las claves de keys que validan una de las firmas
Devuelve una lista de claves que validan la rrsig + conjunto de rrsets. Devuelve el estado LDNS_STATUS_OK si al menos una clave coincidió. De lo contrario, un error.

ldns_verify_rrsig_keylist_notime() Verifica una rrsig. Se intentan todas las claves del conjunto de claves. No se verifica la hora.
rrset: el conjunto de rrsets a comprobar
rrsig: la firma del conjunto de rrsets
keys: las claves a intentar
good_keys: si esta es una lista (inicializada), se añade a ella el puntero a las claves de keys que validan una de las firmas
Devuelve una lista de claves que validan la rrsig + conjunto de rrsets. Devuelve el estado LDNS_STATUS_OK si al menos una clave coincidió. De lo contrario, un error.

ldns_verify_notime() Verifica una lista de firmas para un conjunto de rrsets, pero ignora la hora. La fecha de inicio y expiración no se comprueban.

rrset: el conjunto de rrsets a verificar
rrsig: una lista de firmas a comprobar
keys: una lista de claves para comprobar
good_keys: si esta es una lista (inicializada), se añade a ella el puntero a las claves de keys que validan una de las firmas
Devuelve el estado LDNS_STATUS_OK si hay al menos una clave correcta
