LDAP_TLS(3) Manual de funciones de biblioteca LDAP_TLS(3)

NOMBRE

ldap_start_tls, ldap_start_tls_s, ldap_tls_inplace, ldap_install_tls - Rutinas de inicialización TLS de LDAP

BIBLIOTECA

OpenLDAP LDAP (libldap, -lldap)

SINOPSIS

#include <ldap.h>

int ldap_start_tls(LDAP *ld);

int ldap_start_tls_s(LDAP *ld, LDAPControl **serverctrls, LDAPControl **clientctrls);

int ldap_tls_inplace(LDAP *ld);

int ldap_install_tls(LDAP *ld);

DESCRIPCIÓN

Estas rutinas se utilizan para iniciar el procesamiento TLS en una sesión LDAP. ldap_start_tls_s() envía una solicitud StartTLS a un servidor, espera la respuesta y luego instala los manejadores TLS en la sesión si la solicitud tuvo éxito. La rutina devuelve LDAP_SUCCESS si todo salió bien, de lo contrario, devuelve un código de error LDAP. ldap_start_tls() envía una solicitud StartTLS a un servidor y no hace nada más. Devuelve LDAP_SUCCESS si la solicitud se envió correctamente. ldap_tls_inplace() devuelve 1 si se han instalado manejadores TLS en la sesión especificada, 0 en caso contrario. ldap_install_tls() instala los manejadores TLS en la sesión dada. Devuelve LDAP_LOCAL_ERROR si TLS ya está instalado.

VER TAMBIÉN

ldap(3), ldap_error(3)
