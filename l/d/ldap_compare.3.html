ldap_compare(3)

Paquete: libldap

Licencias: custom

LDAP_COMPARE(3) Manual de funciones de biblioteca LDAP_COMPARE(3)

NOMBRE

ldap_compare, ldap_compare_s, ldap_compare_ext, ldap_compare_ext_s - Realizar una operación de comparación LDAP.

BIBLIOTECA

OpenLDAP LDAP (libldap, -lldap)

SINOPSIS

#include <ldap.h>
int ldap_compare_ext(
LDAP *ld,
char *dn,
char *attr,
const struct berval *bvalue,
LDAPControl **serverctrls,
LDAPControl **clientctrls,
int *msgidp );
int ldap_compare_ext_s(
LDAP *ld,
char *dn,
char *attr,
const struct berval *bvalue,
LDAPControl **serverctrls,
LDAPControl **clientctrls );

DESCRIPCIÓN

La rutina ldap_compare_ext_s() se utiliza para realizar una operación de comparación LDAP de forma síncrona. Toma dn, el DN de la entrada sobre la que realizar la comparación, y attr y value, la descripción del atributo y el valor a comparar con los que se encuentran en la entrada. Devuelve un código, que será LDAP_COMPARE_TRUE si la entrada contiene el valor del atributo y LDAP_COMPARE_FALSE si no lo contiene. En caso contrario, se devuelve un código de error que indica la naturaleza del problema. Consulte ldap(3) para obtener detalles.

La rutina ldap_compare_ext() se utiliza para realizar una operación de comparación LDAP de forma asíncrona. Toma los mismos parámetros que ldap_compare_ext_s(), pero proporciona el ID del mensaje de la solicitud que inició en el entero apuntado por msgidp. El resultado de la comparación se puede obtener mediante una llamada posterior a ldap_result(3).

Ambas rutinas permiten especificar controles de servidor y cliente para extender la solicitud de comparación.

INTERFACES OBSOLETAS

Las rutinas ldap_compare() y ldap_compare_s() están obsoletas en favor de ldap_compare_ext() y ldap_compare_ext_s(), respectivamente.

Las interfaces obsoletas generalmente permanecen en la biblioteca. La macro LDAP_DEPRECATED puede definirse a un valor distinto de cero (por ejemplo, -DLDAP_DEPRECATED=1) al compilar un programa diseñado para usar interfaces obsoletas. Se recomienda que los desarrolladores que escriban programas nuevos, o actualicen programas antiguos, eviten el uso de interfaces obsoletas. Con el tiempo, se espera que la documentación (y, finalmente, el soporte) para las interfaces obsoletas se elimine.

VER TAMBIÉN

ldap(3), ldap_error(3)
