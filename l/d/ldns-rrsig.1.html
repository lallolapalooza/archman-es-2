NOMBRE

ldns-rrsig - imprime las fechas de creación y expiración en formato legible para humanos

SINOPSIS

ldns-rrsig dominio [ tipo ]

DESCRIPCIÓN

ldns-rrsig se utiliza para imprimir la fecha de expiración y creación de un RRSIG. El primer argumento es un nombre de dominio. ldns-rrsig consultará los servidores autoritativos para ese dominio para obtener una lista de RRSIGs. Luego imprimirá las fechas de creación y expiración para el RRSIG que cubre el registro SOA.

Si se proporciona el segundo argumento tipo, se mostrará el RRSIG que cubre ese tipo.

AUTOR
