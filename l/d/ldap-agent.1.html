NOMBRE

ldap-agent - Agente SNMP para Directory Server

SINOPSIS

ldap-agent [-D]<archivo-de-configuracion>

DESCRIPCIÓN

ldap-agent es un subagente SNMP para Directory Server

OPCIONES

-D
Habilitar depuración
<archivo-config>
Archivo de configuración para el agente ldap

VER TAMBIÉN

snmpd(8)

USO

Uso de ejemplo:

ldap-agent /etc/dirsrv/config/ldap-agent.conf

AUTOR

ldap-agent fue escrito por el Proyecto 389.

REPORTAR ERRORES

Reportar errores a https://github.com/389ds/389-ds-base/issues/new
