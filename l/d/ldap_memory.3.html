ldap_memory(3)

Paquete: libldap

Licencias: custom

LDAP_MEMORY(3) Manual de funciones de biblioteca LDAP_MEMORY(3)

NOMBRE

ldap_memfree, ldap_memvfree, ldap_memalloc, ldap_memcalloc, ldap_memrealloc, ldap_strdup - Rutinas de asignación de memoria LDAP

BIBLIOTECA

OpenLDAP LDAP (libldap, -lldap)

SINOPSIS

#include <ldap.h>

void ldap_memfree(void *p);

void ldap_memvfree(void **v);

void *ldap_memalloc(ber_len_t s);

void *ldap_memcalloc(ber_len_t n, ber_len_t s);

void *ldap_memrealloc(void *p, ber_len_t s);

char *ldap_strdup(LDAP_CONST char *p);

DESCRIPCIÓN

Estas rutinas se utilizan para asignar/liberar memoria utilizada/devuelta por la biblioteca LDAP. ldap_memalloc(), ldap_memcalloc(), ldap_memrealloc(), y ldap_memfree() se utilizan exactamente como las rutinas estándar malloc(3), calloc(3), realloc(3), y free(3), respectivamente. La rutina ldap_memvfree() se utiliza para liberar un array asignado dinámicamente de punteros a objetos asignados dinámicamente arbitrarios. La rutina ldap_strdup() se utiliza exactamente como la rutina estándar strdup(3).
