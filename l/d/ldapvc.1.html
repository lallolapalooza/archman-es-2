LDAPVC(1) Manual de Comandos Generales LDAPVC(1)

NOMBRE

ldapvc - Herramienta de verificación de credenciales LDAP

SINOPSIS

ldapvc [-V[V]] [-d nivel_depuracion] [-a] [-b] [-n] [-v] [-x] [-D binddn] [-W] [-w contraseña] [-y archivo_contraseña] [-H ldapuri] [-e [!]ext[=param_ext]] [-E [!]ext[=param_ext]] [-o opt[=param_opt]] [-O propiedades-seguridad] [-I] [-Q] [-N] [-U authcid] [-R realm] [-X authzid] [-Y mech] [-Z[Z]] Nombre Distinguido [Credenciales]

DESCRIPCIÓN

ldapvc implementa la operación extendida LDAP de "Verificar Credenciales".

La operación Verificar Credenciales se comporta como un LDAP Bind pero no tiene impacto en la sesión LDAP subyacente.

OPCIONES

-V[V]
Imprime información de la versión. Si se proporciona -VV, solo se imprime la información de la versión.
-d nivel_depuracion
Establece el nivel de depuración LDAP a nivel_depuracion. ldapvc debe ser compilado con LDAP_DEBUG definido para que esta opción tenga algún efecto.
-a
Imprime el authzID resultante de una verificación exitosa de credenciales.
-b
Imprime los resultados del control ppolicy después de la verificación de credenciales.
-n
Muestra lo que se haría, pero sin realizar la operación. Útil para depuración junto con -v.
-v
Ejecuta en modo detallado, con muchos diagnósticos escritos a la salida estándar.
-x
Utiliza autenticación simple en lugar de SASL.
-D binddn
Utiliza el Nombre Distinguido binddn para enlazar al directorio LDAP. Para enlaces SASL, se espera que el servidor ignore este valor.
-W
Solicita autenticación simple. Se utiliza en lugar de especificar la contraseña en la línea de comandos.
-w contraseña
Utiliza contraseña como la contraseña para la autenticación simple.
-y archivo_contraseña
Utiliza el contenido completo de archivo_contraseña como la contraseña para la autenticación simple.
-H ldapuri
Especifica URI(s) que hacen referencia a los servidores ldap; solo se permiten los campos protocolo/host/puerto; se espera una lista de URI, separadas por espacios o comas.
-e [!]ext[=param_ext]
-E [!]ext[=param_ext]

Especifica extensiones generales con -e y extensiones de Verificación de Credenciales con -E. ´!´ indica criticidad.

Extensiones generales:

  [!]assert=<filtro>    (un Filtro RFC 4515)
  [!]bauthzid           (control authzid RFC 3829)
  [!]chaining[=<resolve>[/<cont>]]
  [!]manageDSAit
  [!]noop
  ppolicy
  [!]postread[=<attrs>] (una lista de atributos separada por comas)
  [!]preread[=<attrs>]  (una lista de atributos separada por comas)
  [!]relax
  sessiontracking[=<usuario>]
  abandon,cancel,ignore (SIGINT envía abandon/cancel,
  o ignora la respuesta; si es crítico, no espera SIGINT.
  no son realmente controles)

Extensiones de Verificación de Credenciales:

Las siguientes opciones establecen parámetros SASL en la solicitud de Verificación de Credenciales:

  authcid=<authcid>    (Identidad de Autenticación SASL "dn:<dn>" o "u:<usuario>")
  authzid=<authzid>    (Identidad de Autorización SASL "dn:<dn>" o "u:<usuario>")
  mech=<mech>          (Mecanismo SASL predeterminado, por ejemplo, Simple)
  realm=<realm>        (Realm SASL, predeterminado a ninguno)
  sasl=a[utomático]|i[nteractivo]|q[uieto]  (El modo SASL se establece en automático si se proporciona cualquier otra opción -E, de lo contrario, ninguno)
  secprops=<secprops>  (Propiedades de Seguridad SASL)
-o opt[=param_opt]

Especifica cualquier opción de ldap.conf(5) o una de las siguientes:

  nettimeout=<timeout>  (en segundos, o "none" o "max")
  ldif_wrap=<width>     (en columnas, o "no" para no envolver)

La opción -o puede pasarse aquí, consulta ldap.conf(5) para más detalles.

-O propiedades-seguridad
Especifica las propiedades de seguridad SASL.
-I
Habilita el modo Interactivo SASL. Siempre solicita. El valor predeterminado es solicitar solo cuando sea necesario.
-Q
Habilita el modo Silencioso SASL. Nunca solicita.
-N
No utiliza DNS inverso para canonizar el nombre de host SASL.
-U authcid
Especifica el ID de autenticación para el enlace SASL. La forma del ID depende del mecanismo SASL real utilizado.
-R realm
Especifica el realm del ID de autenticación para el enlace SASL. La forma del realm depende del mecanismo SASL real utilizado.
-X authzid
Especifica el ID de autorización solicitado para el enlace SASL. authzid debe tener uno de los siguientes formatos: dn:<nombre distinguido> o u:<nombre de usuario>
-Y mech
Especifica el mecanismo SASL que se utilizará para la autenticación. Si no se especifica, el programa elegirá el mejor mecanismo que el servidor conozca.
-Z[Z]
Emite la operación extendida StartTLS (Transport Layer Security). Si utilizas -ZZ, el comando requerirá que la operación sea exitosa.

EJEMPLO

    ldapvc -x "uid=Alice,ou=People,dc=example,dc=com"

ldap.conf(5), ldap(3), ldap_extended_operation(3)

NOMBRE

ldapvc - Visualiza la base de datos de un servicio LDAP.

SINOPSIS

ldapvc [opciones]

DESCRIPCIÓN

ldapvc es una herramienta que permite visualizar la base de datos de un servicio LDAP. Proporciona una interfaz interactiva para navegar por el árbol de directorios, buscar entradas y ver sus atributos.

OPCIONES

ldapvc soporta las siguientes opciones:

  • -h, --host <host>: Especifica el host del servidor LDAP.
  • -p, --port <puerto>: Especifica el puerto del servidor LDAP. El valor predeterminado es 389.
  • -b, --binddn <dn>: Especifica el Distinguished Name (DN) a utilizar para la conexión.
  • -w, --bindpw <contraseña>: Especifica la contraseña a utilizar para la conexión.
  • -D, --basedn <dn>: Especifica el DN base desde el cual comenzar la navegación.
  • -V, --version: Muestra la información de la versión y sale.
  • -v, --verbose: Habilita la salida detallada.
  • -d, --debug <nivel>: Establece el nivel de depuración.
  • -?, --help: Muestra un mensaje de ayuda y sale.

EJEMPLO

Para conectarse a un servidor LDAP en ldap.example.com en el puerto 389, utilizando el DN cn=admin,dc=example,dc=com y su contraseña, y comenzar la navegación desde dc=example,dc=com, ejecute: 

$ ldapvc -h ldap.example.com -p 389 -D cn=admin,dc=example,dc=com -w 'secret' -b dc=example,dc=com

ldapsearch(1), man(1).
