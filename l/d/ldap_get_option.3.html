LDAP_GET_OPTION(3) Manual de Funciones de Biblioteca LDAP_GET_OPTION(3)

NOMBRE

ldap_get_option, ldap_set_option - Rutinas de manejo de opciones LDAP

BIBLIOTECA

OpenLDAP LDAP (libldap, -lldap)

SINOPSIS

#include <ldap.h>
int ldap_get_option(LDAP *ld, int option, void *outvalue);
int ldap_set_option(LDAP *ld, int option, const void *invalue);

DESCRIPCIÓN

Estas rutinas proporcionan acceso a opciones almacenadas en un manejador LDAP o como opciones globales, donde sea aplicable. Hacen uso de una interfaz neutral, donde el tipo del valor recuperado por ldap_get_option(3) o establecido por ldap_set_option(3) se convierte a void *. El tipo real se determina en base al valor del argumento option. Las opciones globales se establecen/recuperan pasando un manejador LDAP NULL. Los manejadores LDAP heredan sus ajustes predeterminados de las opciones globales vigentes en el momento en que se crea el manejador.

LDAP_OPT_API_FEATURE_INFO
Rellena una LDAPAPIFeatureInfo; outvalue debe ser un LDAPAPIFeatureInfo *, apuntando a una estructura ya asignada. El campo ldapaif_info_version de la estructura debe inicializarse a LDAP_FEATURE_INFO_VERSION antes de realizar la llamada. El campo ldapaif_name debe establecerse al nombre de una característica a consultar. Esta es una opción de solo lectura.
LDAP_OPT_API_INFO
Rellena una LDAPAPIInfo; outvalue debe ser un LDAPAPIInfo *, apuntando a una estructura ya asignada. El campo ldapai_info_version de la estructura debe inicializarse a LDAP_API_INFO_VERSION antes de realizar la llamada. Si la versión pasada no coincide con la versión actual de la biblioteca, el número de versión esperado se almacenará en la estructura y la llamada fallará. El llamador es responsable de liberar los elementos de la matriz ldapai_extensions y la propia matriz usando ldap_memfree(3). El llamador también debe liberar ldapi_vendor_name. Esta es una opción de solo lectura.
LDAP_OPT_CLIENT_CONTROLS
Establece/obtiene los controles del lado del cliente que se utilizarán para todas las operaciones. Esto ahora está obsoleto ya que la API C LDAP moderna proporciona reemplazos para la mayoría de las operaciones que aceptan controles del lado del cliente como argumentos explícitos; véase por ejemplo ldap_search_ext(3), ldap_add_ext(3), ldap_modify_ext(3) y así sucesivamente. outvalue debe ser LDAPControl ***, y el llamador es responsable de liberar los controles devueltos, si los hay, llamando a ldap_controls_free(3), mientras que invalue debe ser LDAPControl *const *; la biblioteca duplica los controles pasados a través de invalue.
LDAP_OPT_CONNECT_ASYNC
Establece/obtiene el estado del indicador de conexión asíncrona. invalue debe ser LDAP_OPT_OFF o LDAP_OPT_ON; outvalue debe ser int *. Cuando se establece, la biblioteca llamará a connect(2) y devolverá, sin esperar respuesta. Esto deja el manejador en estado de conexión. Las llamadas posteriores a las rutinas de la biblioteca sondearán la finalización de la conexión antes de realizar más operaciones. Como consecuencia, las llamadas a la biblioteca que necesitan establecer una conexión con un DSA no se bloquean ni siquiera para el tiempo de espera de la red (opción LDAP_OPT_NETWORK_TIMEOUT). Esta opción es específica de OpenLDAP.
LDAP_OPT_CONNECT_CB
Esta opción permite establecer una devolución de llamada de conexión. invalue debe ser un const struct ldap_conncb *. Las devoluciones de llamada se ejecutan en orden de último en entrar, primero en salir. Las devoluciones de llamada específicas del manejador se ejecutan primero, seguidas por las globales. Justo antes de liberar la estructura de devolución de llamada, se pasa un NULL Sockbuf al manejador de devolución de llamada lc_del. Llamar a ldap_get_option(3) para esta opción elimina la devolución de llamada cuyo puntero coincide con outvalue. Esta opción es específica de OpenLDAP.
LDAP_OPT_DEBUG_LEVEL
Establece/obtiene el nivel de depuración de la biblioteca cliente. invalue debe ser un const int *; outvalue debe ser un int *. Los niveles de depuración válidos son LDAP_DEBUG_ANY, LDAP_DEBUG_ARGS, LDAP_DEBUG_BER, LDAP_DEBUG_CONNS, LDAP_DEBUG_NONE, LDAP_DEBUG_PACKETS, LDAP_DEBUG_PARSE y LDAP_DEBUG_TRACE. Esta opción es específica de OpenLDAP.
LDAP_OPT_DEFBASE
Establece/obtiene una cadena que contiene el DN que se utilizará como base predeterminada para las operaciones de búsqueda. outvalue debe ser un char **, y el llamador es responsable de liberar la cadena devuelta llamando a ldap_memfree(3), mientras que invalue debe ser un const char *; la biblioteca duplica la cadena correspondiente. Esta opción es específica de OpenLDAP.
LDAP_OPT_DEREF
Establece/obtiene el valor que define cuándo debe ocurrir la resolución de alias. invalue debe ser const int *; outvalue debe ser int *. No pueden ser NULL. El valor de *invalue debe ser uno de LDAP_DEREF_NEVER (el predeterminado), LDAP_DEREF_SEARCHING, LDAP_DEREF_FINDING o LDAP_DEREF_ALWAYS. Tenga en cuenta que esta siempre ha sido la única forma de determinar la resolución de alias dentro de las operaciones de búsqueda.
LDAP_OPT_DESC
Devuelve el descriptor de archivo asociado al búfer de socket del manejador LDAP pasado como ld; outvalue debe ser un int *. Esta es una opción específica del manejador, de solo lectura.
LDAP_OPT_DIAGNOSTIC_MESSAGE
Establece/obtiene una cadena que contiene la cadena de error asociada al manejador LDAP. Esta opción se conocía anteriormente como LDAP_OPT_ERROR_STRING. outvalue debe ser un char **, y el llamador es responsable de liberar la cadena devuelta llamando a ldap_memfree(3), mientras que invalue debe ser un char *; la biblioteca duplica la cadena correspondiente.
LDAP_OPT_HOST_NAME
Establece/obtiene una lista de hosts separada por espacios que será contactada por la biblioteca al intentar establecer una conexión. Esto ahora está obsoleto en favor de LDAP_OPT_URI. outvalue debe ser un char **, y el llamador es responsable de liberar la cadena resultante llamando a ldap_memfree(3), mientras que invalue debe ser un const char *; la biblioteca duplica la cadena correspondiente.
LDAP_OPT_MATCHED_DN
Establece/obtiene una cadena que contiene el DN coincidente asociado al manejador LDAP. outvalue debe ser un char **, y el llamador es responsable de liberar la cadena devuelta llamando a ldap_memfree(3), mientras que invalue debe ser un const char *; la biblioteca duplica la cadena correspondiente.
LDAP_OPT_NETWORK_TIMEOUT
Establece/obtiene el valor del tiempo de espera de red después del cual poll(2)/select(2) después de una llamada a connect(2) devuelve en caso de no actividad. outvalue debe ser un struct timeval ** (el llamador tiene que liberar *outvalue usando ldap_memfree(3)), y invalue debe ser un const struct timeval *. No pueden ser NULL. Usar una estructura con los segundos establecidos en -1 resulta en un tiempo de espera infinito, que es el predeterminado. Esta opción es específica de OpenLDAP.
LDAP_OPT_PROTOCOL_VERSION

OPTIONS

Las siguientes opciones pueden ser configuradas con la función ldap_set_option(3).

LDAP_OPT_API_INFO
Obtiene información sobre la versión de la API; outvalue debe ser un LDAPAPIInfo(3) *. El llamador es responsable de liberar la memoria devuelta llamando a ldap_memfree(3). Esta opción es específica de OpenLDAP.
LDAP_OPT_DESC
Devuelve el descriptor de archivo asociado al socket LDAP. outvalue debe ser un int *. Esta es una opción de solo lectura específica del manejador.
LDAP_OPT_DEREF
Establece/obtiene el modo de desreferenciación de alias. invalue debe ser const int *, y outvalue debe ser int *. Los posibles valores para invalue son LDAP_DEREF_NEVER, LDAP_DEREF_SEARCHING, LDAP_DEREF_FINDING, LDAP_DEREF_ALWAYS.
LDAP_OPT_ERROR_NUMBER
Establece/obtiene el número de error LDAP asociado al manejador. Anteriormente conocido como LDAP_OPT_RESULT_CODE. invalue debe ser un const int *. outvalue debe ser un int *.
LDAP_OPT_HOST_NAME
Establece/obtiene el nombre del host del servidor LDAP. outvalue debe ser un char ** y el llamador es responsable de liberar la cadena devuelta llamando a ldap_memfree(3). invalue debe ser un const char *; la biblioteca duplica la cadena correspondiente.
LDAP_OPT_PROTOCOL_VERSION
Establece/obtiene la versión del protocolo LDAP a utilizar. invalue debe ser const int *, mientras que outvalue debe ser int *.
LDAP_OPT_REFERRAL_URLS
Establece/obtiene un array que contiene las URIs de referencia asociadas al manejador LDAP. outvalue debe ser un char ***, y el llamador es responsable de liberar la cadena devuelta llamando a ldap_memvfree(3), mientras que invalue debe ser un char *const * terminado en NULL; la biblioteca duplica la cadena correspondiente. Esta opción es específica de OpenLDAP.
LDAP_OPT_REFERRALS
Determina si la biblioteca debe seguir implícitamente las referencias o no. invalue debe ser const int *; su valor debe ser LDAP_OPT_OFF o LDAP_OPT_ON. outvalue debe ser int *.
LDAP_OPT_RESTART
Determina si la biblioteca debe reiniciar implícitamente las conexiones (FIXME). invalue debe ser const int *; su valor debe ser LDAP_OPT_OFF o LDAP_OPT_ON. outvalue debe ser int *.
LDAP_OPT_RESULT_CODE
Establece/obtiene el código de resultado LDAP asociado al manejador. Esta opción era conocida anteriormente como LDAP_OPT_ERROR_NUMBER. invalue debe ser un const int *. outvalue debe ser un int *.
LDAP_OPT_SERVER_CONTROLS
Establece/obtiene los controles del lado del servidor que se utilizarán para todas las operaciones. Esto está ahora obsoleto, ya que la API C moderna de LDAP proporciona reemplazos para todas las operaciones principales que aceptan controles del lado del servidor como argumentos explícitos; véase, por ejemplo, ldap_search_ext(3), ldap_add_ext(3), ldap_modify_ext(3) y así sucesivamente. outvalue debe ser LDAPControl ***, y el llamador es responsable de liberar los controles devueltos, si los hay, llamando a ldap_controls_free(3), mientras que invalue debe ser LDAPControl *const *; la biblioteca duplica los controles pasados a través de invalue.
LDAP_OPT_SESSION_REFCNT
Devuelve el contador de referencias asociado al manejador LDAP pasado como ld; outvalue debe ser un int *. Esta es una opción de solo lectura específica del manejador. Esta opción es específica de OpenLDAP.
LDAP_OPT_SIZELIMIT
Establece/obtiene el valor que define el número máximo de entradas a devolver en una operación de búsqueda. invalue debe ser const int *, mientras que outvalue debe ser int *; no pueden ser NULL.
LDAP_OPT_SOCKBUF
Devuelve un puntero al búfer del socket del manejador LDAP pasado como ld; outvalue debe ser un Sockbuf **. Esta es una opción de solo lectura específica del manejador. Esta opción es específica de OpenLDAP.
LDAP_OPT_SOCKET_BIND_ADDRESSES
Establece/obtiene una lista separada por espacios de direcciones IP utilizadas como interfaz de enlace al servidor remoto al intentar establecer una conexión. Solo se permite una dirección IPv4 válida y/o una dirección IPv6 válida en la lista. outvalue debe ser un char **, y el llamador es responsable de liberar la cadena devuelta llamando a ldap_memfree(3), mientras que invalue debe ser un const char *; la biblioteca duplica la cadena correspondiente.
LDAP_OPT_TIMELIMIT
Establece/obtiene el valor que define el límite de tiempo después del cual una operación de búsqueda debe ser terminada por el servidor. invalue debe ser const int *, mientras que outvalue debe ser int *, y no pueden ser NULL.
LDAP_OPT_TIMEOUT
Establece/obtiene un valor de tiempo de espera para las llamadas síncronas de la API. outvalue debe ser un struct timeval ** (el llamador tiene que liberar *outvalue usando ldap_memfree(3)), e invalue debe ser un struct timeval *, y no pueden ser NULL. Usar una struct con segundos establecidos a -1 resulta en un tiempo de espera infinito, que es el valor predeterminado. Esta opción es específica de OpenLDAP.
LDAP_OPT_URI
Establece/obtiene una lista separada por comas o espacios de URIs a las que la biblioteca se dirigirá al intentar establecer una conexión. outvalue debe ser un char **, y el llamador es responsable de liberar la cadena resultante llamando a ldap_memfree(3), mientras que invalue debe ser un const char *; la biblioteca analiza la cadena en una lista de estructuras LDAPURLDesc, por lo que la invocación de ldap_set_option(3) puede fallar si el análisis de la URL falla. Las URIs solo pueden contener los campos schema, host y port. Esta opción es específica de OpenLDAP.
LDAP_OPT_KEEPCONN
Instruye a ldap_result(3) para que mantenga la conexión abierta en caso de error de lectura o si se recibe un Aviso de Desconexión. En estos casos, la conexión debe ser cerrada por el llamador. Esta opción es específica de OpenLDAP.
LDAP_OPT_TCP_USER_TIMEOUT
Permite configurar TCP_USER_TIMEOUT en milisegundos en la conexión, anulando la configuración del sistema operativo. Esta opción es específica de OpenLDAP y solo se admite en Linux 2.6.37 o superior. invalue debe ser un const unsigned int *; outvalue debe ser un unsigned int *.

SASL OPTIONS

Las opciones SASL son específicas de OpenLDAP y, a menos que se indique lo contrario, requieren que se pase un manejador LDAP.

LDAP_OPT_X_SASL_AUTHCID
Obtiene la identidad de autenticación SASL; outvalue debe ser un char **, su contenido debe ser liberado por el llamador usando ldap_memfree(3).
LDAP_OPT_X_SASL_AUTHZID
Obtiene la identidad de autorización SASL; outvalue debe ser un char **, su contenido debe ser liberado por el llamador usando ldap_memfree(3).
LDAP_OPT_X_SASL_MAXBUFSIZE
Obtiene/establece el tamaño máximo del búfer SASL; invalue debe ser const ber_len_t *, mientras que outvalue debe ser ber_len_t *. Véase también LDAP_OPT_X_SASL_SECPROPS.
LDAP_OPT_X_SASL_MECH
Obtiene el mecanismo SASL; outvalue debe ser un char **, su contenido debe ser liberado por el llamador usando ldap_memfree(3).
LDAP_OPT_X_SASL_MECHLIST
Obtiene la lista de mecanismos disponibles, en forma de un array de cadenas terminado en NULL; outvalue debe ser char ***. El llamador no debe liberarlo ni modificarlo. Esta opción puede ser utilizada globalmente.
LDAP_OPT_X_SASL_NOCANON
Establece/obtiene el flag NOCANON. Cuando no está establecido, el nombre del host se canoniza. invalue debe ser const int *; su valor debe ser LDAP_OPT_OFF o LDAP_OPT_ON. outvalue debe ser int *.
LDAP_OPT_X_SASL_REALM
Obtiene el reino SASL; outvalue debe ser un char **, su contenido debe ser liberado por el llamador usando ldap_memfree(3).
LDAP_OPT_X_SASL_SECPROPS
Establece las propiedades de seguridad SASL; invalue debe ser un char *, que contiene una lista de propiedades separadas por comas. Los valores legales son: none, nodict, noplain, noactive, passcred, forwardsec, noanonymous, minssf=<minssf>, maxssf=<maxssf>, maxbufsize=<maxbufsize>.
LDAP_OPT_X_SASL_SSF
Obtiene el SSF SASL; outvalue debe ser un ber_len_t *.
LDAP_OPT_X_SASL_SSF_EXTERNAL
Establece el valor SSF SASL relacionado con una autenticación realizada utilizando un mecanismo EXTERNAL; invalue debe ser un const ber_len_t *.
LDAP_OPT_X_SASL_SSF_MAX
Obtiene/establece el SSF máximo SASL; invalue debe ser const ber_len_t *, mientras que outvalue debe ser ber_len_t *. Véase también LDAP_OPT_X_SASL_SECPROPS.
LDAP_OPT_X_SASL_SSF_MIN
Obtiene/establece el SSF mínimo SASL; invalue debe ser const ber_len_t *, mientras que outvalue debe ser ber_len_t *. Véase también LDAP_OPT_X_SASL_SECPROPS.
LDAP_OPT_X_SASL_USERNAME
Obtiene el nombre de usuario SASL; outvalue debe ser un char **. Su contenido debe ser liberado por el llamador usando ldap_memfree(3).
LDAP_OPT_X_SASL_CBINDING
Establece/obtiene el tipo de enlace de canal a utilizar en SASL, uno de LDAP_OPT_X_SASL_CBINDING_NONE (el predeterminado), LDAP_OPT_X_SASL_CBINDING_TLS_UNIQUE el tipo "tls-unique" de RFC 5929.
