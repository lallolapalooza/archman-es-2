ldap_add(3)

Paquete: libldap

Licencias: custom

LDAP_ADD(3) Manual de funciones de la biblioteca LDAP_ADD(3)

NOMBRE

ldap_add_ext, ldap_add_ext_s - Realizar una operación de añadir LDAP

BIBLIOTECA

OpenLDAP LDAP (libldap, -lldap)

SINOPSIS

#include <ldap.h>

int ldap_add_ext(
LDAP *ld,
const char *dn,
LDAPMod **attrs,
LDAPControl **sctrls,
LDAPControl **cctrls,
int *msgidp );
int ldap_add_ext_s(
LDAP *ld,
const char *dn,
LDAPMod **attrs,
LDAPControl *sctrls,
LDAPControl *cctrls );

DESCRIPCIÓN

La rutina ldap_add_ext_s() se utiliza para realizar una operación de añadir LDAP. Toma dn, el DN de la entrada a añadir, y attrs, una matriz terminada en nulo de los atributos de la entrada. La estructura LDAPMod se utiliza para representar atributos, con los campos mod_type y mod_values utilizados como se describe en ldap_modify_ext(3), y el campo ldap_op se utiliza solo si necesita especificar la opción LDAP_MOD_BVALUES. De lo contrario, debe establecerse en cero.

Tenga en cuenta que todas las entradas excepto la especificada por el último componente en el DN dado deben existir. ldap_add_ext_s() devuelve un código que indica el éxito o, en caso de fallo, indicando la naturaleza del fallo de la operación. Consulte ldap_error(3) para obtener más detalles.

La rutina ldap_add_ext() funciona igual que ldap_add_ext_s(), pero es asíncrona. Devuelve el ID del mensaje de la solicitud que inició. El resultado de esta operación se puede obtener llamando a ldap_result(3).

INTERFACES OBSOLETAS

Las rutinas ldap_add() y ldap_add_s() están obsoletas en favor de las rutinas ldap_add_ext() y ldap_add_ext_s(), respectivamente.

Las interfaces obsoletas generalmente permanecen en la biblioteca. La macro LDAP_DEPRECATED puede definirse a un valor distinto de cero (por ejemplo, -DLDAP_DEPRECATED=1) al compilar un programa diseñado para usar interfaces obsoletas. Se recomienda que los desarrolladores que escriban programas nuevos, o que actualicen programas antiguos, eviten el uso de interfaces obsoletas. Con el tiempo, se espera que la documentación (y, finalmente, el soporte) para las interfaces obsoletas se elimine.

VER TAMBIÉN
