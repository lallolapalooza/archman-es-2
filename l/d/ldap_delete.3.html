ldap_delete(3)

Paquete: libldap

Licencias: custom

LDAP_DELETE(3) Manual de funciones de la biblioteca LDAP_DELETE(3)

NOMBRE

ldap_delete, ldap_delete_s, ldap_delete_ext, ldap_delete_ext_s - Realizar una operación de eliminación LDAP.

BIBLIOTECA

OpenLDAP LDAP (libldap, -lldap)

SINOPSIS

#include <ldap.h>
int ldap_delete_s(ld, dn)
LDAP *ld;
char *dn;
int ldap_delete(ld, dn)
LDAP *ld;
char *dn;
int ldap_delete_ext(ld, dn, serverctrls, clientctrls, msgidp)
LDAP *ld;
char *dn;
LDAPControl **serverctrls, **clientctrls;
int *msgidp;
int ldap_delete_ext_s(ld, dn, serverctrls, clientctrls)
LDAP *ld;
char *dn;
LDAPControl **serverctrls, **clientctrls;

DESCRIPCION

La rutina ldap_delete_s() se utiliza para realizar una operación de eliminación LDAP de forma síncrona. Toma dn, el DN de la entrada a eliminar. Devuelve un código de error LDAP, que indica el éxito o el fallo de la operación.

La rutina ldap_delete() se utiliza para realizar una operación de eliminación LDAP de forma asíncrona. Toma los mismos parámetros que ldap_delete_s(), pero devuelve el ID del mensaje de la solicitud que inició. El resultado de la eliminación se puede obtener mediante una llamada posterior a ldap_result(3).

La rutina ldap_delete_ext() permite especificar controles del servidor y del cliente para extender la solicitud de eliminación. Esta rutina es asíncrona como ldap_delete(), pero su valor de retorno es un código de error LDAP. Almacena el ID del mensaje de la solicitud en el entero al que apunta msgidp.

La rutina ldap_delete_ext_s() es la versión síncrona de ldap_delete_ext(). También devuelve un código de error LDAP que indica el éxito o el fallo de la operación.

ERRORES

ldap_delete_s() devuelve un código de error LDAP que puede ser interpretado llamando a uno de ldap_perror(3) y similares. ldap_delete() devuelve -1 si algo salió mal al iniciar la solicitud. Devuelve el ID de mensaje no negativo de la solicitud si todo salió bien.

ldap_delete_ext() y ldap_delete_ext_s() devuelven algún valor distinto de cero si algo salió mal al iniciar la solicitud, de lo contrario devuelven 0.

VER TAMBIÉN

ldap(3), ldap_error(3)
