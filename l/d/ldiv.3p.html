LDIV(3P) Manual del programador POSIX LDIV(3P)

PRÓLOGO

Esta página del manual forma parte del Manual del programador POSIX. La implementación de esta interfaz en Linux puede diferir (consulte la página del manual de Linux correspondiente para conocer los detalles del comportamiento en Linux), o la interfaz puede no estar implementada en Linux.

NOMBRE

ldiv, lldiv — calcular cociente y resto de una división larga

SINOPSIS

#include <stdlib.h>
ldiv_t ldiv(long numer, long denom);
lldiv_t lldiv(long long numer, long long denom);

DESCRIPCIÓN

La funcionalidad descrita en esta página de referencia está alineada con el estándar ISO C. Cualquier conflicto entre los requisitos descritos aquí y el estándar ISO C es involuntario. Este volumen de POSIX.1-2017 remite al estándar ISO C.

Estas funciones calcularán el cociente y el resto de la división del numerador numer por el denominador denom. Si la división es inexacta, el cociente resultante es el entero long (para la función ldiv()) o entero long long (para la función lldiv()) de menor magnitud que sea más cercano al cociente algebraico. Si el resultado no se puede representar, el comportamiento es indefinido; de lo contrario, quot * denom + rem será igual a numer.

VALOR DE RETORNO

La función ldiv() devolverá una estructura de tipo ldiv_t, que comprenderá tanto el cociente como el resto. La estructura incluirá los siguientes miembros, en cualquier orden:

long   quot;    /* Cociente */
long   rem;     /* Resto */

La función lldiv() devolverá una estructura de tipo lldiv_t, que comprenderá tanto el cociente como el resto. La estructura incluirá los siguientes miembros, en cualquier orden:

long long   quot;    /* Cociente */
long long   rem;     /* Resto */

ERRORES

No se definen errores.
