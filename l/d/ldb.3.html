NOMBRE

ldb - Una biblioteca de base de datos ligera

SINOPSIS

#include <ldb.h>

DESCRIPCIÓN

ldb es una biblioteca y API de base de datos embebida ligera. Con una interfaz de programación muy similar a LDAP, ldb puede almacenar sus datos ya sea en una base de datos tdb(3) o en una base de datos LDAP real.

Cuando se utiliza con el backend tdb, ldb no requiere ningún demonio de base de datos. En su lugar, las llamadas a funciones de ldb son procesadas inmediatamente por la biblioteca ldb, que realiza E/S directamente en la base de datos, mientras permite múltiples lectores/escritores utilizando bloqueos de rango de bytes del sistema operativo. Esto conduce a una API con muy baja sobrecarga, a menudo resultando en velocidades de más de 10 veces lo que se puede lograr con una arquitectura LDAP más tradicional.

En una taxonomía de bases de datos, ldb se situaría a medio camino entre las bases de datos de pares clave/valor (como berkeley db o tdb) y una base de datos LDAP completa. Con una API orientada a atributos estructurados como LDAP y buenas capacidades de indexación, ldb puede ser utilizado para aplicaciones bastante sofisticadas que necesitan una base de datos ligera, sin la sobrecarga administrativa de una instalación LDAP completa.

Incluido con ldb hay una serie de herramientas de línea de comandos útiles para manipular una base de datos ldb. Estas herramientas son similares en estilo a las herramientas de línea de comandos ldap equivalentes.

En su modo de operación por defecto con un backend tdb, ldb también puede ser visto como un "LDAP sin esquema". Por defecto, ldb no requiere un esquema, lo que reduce enormemente la complejidad de empezar con bases de datos ldb. A medida que la complejidad de tu aplicación crece, puedes aprovechar algunos de los atributos opcionales similares a esquemas que ofrece ldb, o puedes migrar al uso de la API LDAP completa manteniendo tu código ldb existente.

Si eres nuevo en ldb, te sugiero que empieces con las páginas del manual de ldbsearch(1) y ldbedit(1), y experimentes con una base de datos local. Luego, te sugiero que consultes las páginas del manual de ldb_connect(3) y ldb_search(3).

HERRAMIENTAS

•ldbsearch(1) - utilidad de búsqueda ldb en línea de comandos
•ldbedit(1) - edita toda o parte de una base de datos ldb usando tu editor favorito
•ldbadd(1) - agrega registros a una base de datos ldb utilizando entrada con formato LDIF
•ldbdel(1) - elimina registros de una base de datos ldb
•ldbmodify(1) - modifica registros en una base de datos ldb utilizando entrada con formato LDIF

FUNCIONES

•ldb_connect(3) - conecta a un backend ldb
•ldb_search(3) - realiza una búsqueda en la base de datos
•ldb_add(3) - agrega un registro a la base de datos
•ldb_delete(3) - elimina un registro de la base de datos
•ldb_modify(3) - modifica un registro en la base de datos
•ldb_errstring(3) - recupera información de error extendida de la última operación
•ldb_ldif_write(3) - escribe un mensaje con formato LDIF
•ldb_ldif_write_file(3) - escribe un mensaje con formato LDIF a un archivo
•ldb_ldif_read(3) - lee un mensaje con formato LDIF
•ldb_ldif_read_free(3) - libera el resultado de una ldb_ldif_read()
•ldb_ldif_read_file(3) - lee un mensaje LDIF de un archivo
•ldb_ldif_read_string(3) - lee un mensaje LDIF de una cadena
•ldb_msg_find_element(3) - encuentra un elemento en un ldb_message
•ldb_val_equal_exact(3) - compara dos estructuras ldb_val
•ldb_msg_find_val(3) - encuentra un elemento por valor
•ldb_msg_add_empty(3) - agrega un elemento de mensaje vacío a un ldb_message
•ldb_msg_add(3) - agrega un elemento de mensaje no vacío a un ldb_message
•ldb_msg_element_compare(3) - compara dos estructuras ldb_message_element
•ldb_msg_find_int(3) - devuelve un valor entero de un ldb_message
•ldb_msg_find_uint(3) - devuelve un valor entero sin signo de un ldb_message
•ldb_msg_find_double(3) - devuelve un valor doble de un ldb_message
•ldb_msg_find_string(3) - devuelve un valor de cadena de un ldb_message
•ldb_set_alloc(3) - establece la función de asignación de memoria a utilizar por ldb
•ldb_set_debug(3) - establece un controlador de depuración a utilizar por ldb
•ldb_set_debug_stderr(3) - establece un controlador de depuración para la salida de stderr

VARIABLES DE ENTORNO

•LDB_URL - conecta a la URL proporcionada (solo herramientas de línea de comandos)
•LDB_MODULES_PATH - ruta desde donde cargar módulos ldb
•LDB_MODULES_ENABLE_DEEPBIND - habilita RTLD_DEEPBIND al cargar módulos ldb
