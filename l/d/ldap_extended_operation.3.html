ldap_extended_operation(3)

Paquete: libldap

Licencias: custom

LDAP_EXTENDED_OPERATION(3) Manual de funciones de la biblioteca LDAP_EXTENDED_OPERATION(3)

NOMBRE

ldap_extended_operation, ldap_extended_operation_s - Extiende las operaciones LDAP al servidor LDAP.

BIBLIOTECA

OpenLDAP LDAP (libldap, -lldap)

SINOPSIS

#include <ldap.h>
int ldap_extended_operation(
LDAP *ld,
const char *requestoid,
const struct berval *requestdata,
LDAPControl **sctrls,
LDAPControl **cctrls,
int *msgidp );
int ldap_extended_operation_s(
LDAP *ld,
const char *requestoid,
const struct berval *requestdata,
LDAPControl **sctrls,
LDAPControl **cctrls,
char **retoidp,
struct berval **retdatap );

DESCRIPCIÓN

La rutina ldap_extended_operation_s() se utiliza para realizar de forma síncrona una operación LDAP extendida. Toma requestoid, que apunta a una cadena OID en formato decimal punteado que identifica la operación extendida a realizar. requestdata son los datos necesarios para la solicitud, sctrls es una matriz de estructuras LDAPControl a utilizar con esta operación extendida, cctrls es una matriz de estructuras LDAPControl que enumeran los controles del cliente a utilizar con esta operación extendida.

El parámetro de salida retoidp apunta a una cadena OID en formato decimal punteado devuelta por el servidor LDAP. La memoria utilizada por la cadena debe liberarse con la función ldap_memfree(3). El parámetro de salida retdatap apunta a un puntero a una estructura berval que contiene los datos devueltos. Si el servidor no devuelve datos, el puntero se establece en NULL. La memoria utilizada por esta estructura debe liberarse con la función ber_bvfree(3).

ldap_extended_operation() funciona igual que ldap_extended_operation_s(), pero la operación es asíncrona. Proporciona el ID del mensaje de la solicitud que inició en el entero al que apunta msgidp. El resultado de esta operación se puede obtener llamando a ldap_result(3).

VER TAMBIÉN

ber_bvfree(3), ldap_memfree(3), ldap_parse_extended_result(3), ldap_result(3)
