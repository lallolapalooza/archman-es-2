FBB::LDC(3bobcat) Convierte (grandes) valores numéricos a caracteres FBB::LDC(3bobcat)

NOMBRE

FBB::LDC - Convierte (grandes) valores numéricos a caracteres

SINOPSIS

#include <bobcat/LDC>
Opción de enlazado: -lbobcat

DESCRIPCIÓN

Los objetos de la clase LDC (Conversor de Números Grandes) convierten (grandes) valores numéricos (como los valores manejados por la clase BigInt (cf. bigint(3bobcat))) a representaciones de caracteres usando bases desde 2 hasta 36. Para bases mayores que 10 se utilizan letras, de a a z, para representar los valores (decimales) 10 a 36. Al especificar bases fuera de este rango se lanza una excepción.

Alternativamente, los dígitos del número convertido pueden proporcionarse en un argumento std::string, donde el primer carácter de la cadena (en el índice 0) se utiliza para el valor 0, el siguiente carácter para el valor 1, etc., hasta el último carácter de la cadena. En ese caso, la longitud de la cadena define el sistema numérico que se utiliza para convertir el (gran) valor numérico. Usualmente los primeros 10 caracteres serán "0123456789", pero LDC no lo impone. En su lugar, se puede especificar cualquier serie de caracteres, en cuyo caso el carácter en el índice idx se utiliza para representar el valor idx en la cadena del valor convertido. Por ejemplo, al especificar "abcdefghij", el valor hexadecimal "deadbeef" se convierte a "dhdfjciffj" en lugar de "3735928559", que es la representación de dígitos decimales normalmente utilizada. Las cadenas de dígitos deben contener al menos dos caracteres o se lanzará una excepción.

ESPACIO DE NOMBRES

FBB
Todos los constructores, miembros, operadores y manipuladores mencionados en esta página del manual están definidos en el espacio de nombres FBB.

HEREDA DE

-

CONSTRUCTORES

o
LDC():
El constructor predeterminado inicializa su valor a 0;
o
LDC(std::string const &hexNr, size_t radix = 10):
Los bytes de la cadena hexNr contienen la representación de caracteres de un valor hexadecimal, que se convierte a su representación equivalente utilizando el sistema numérico radix. La cadena hexNr no debe comenzar con 0x, sino que su primer carácter debe ser el dígito más significativo del valor. Por ejemplo, LDC ldc{ "12345" } se convierte al decimal 74565 (en este ejemplo "12345" se convierte primero a un std::string, que luego se pasa al constructor de ldc). hexNr no puede estar vacío o se lanzará una excepción;
o
LDC(std::string const &hexNr, std::string const &digits):
Igual que el constructor anterior, pero el sistema numérico se infiere de la longitud de digits, usando su primer carácter para representar el valor 0, y su último carácter para representar el último dígito del sistema numérico inferido;
o
LDC(size_t nBytes, char const *bytes, size_t radix = 10):
Los bytes de la cadena bytes contienen la representación de caracteres de un valor hexadecimal, que se convierte a su representación equivalente utilizando radix. La cadena bytes no debe comenzar con 0x, sino que su primer carácter debe ser el dígito más significativo del valor. Por ejemplo, LDC{ 5, "12345" } se convierte al decimal 74565. nBytes debe ser al menos 1 o se lanzará una excepción;
o
LDC(size_t nBytes, char const *bytes, std::string const &digits):
Igual que el constructor anterior, pero el sistema numérico y los caracteres de los dígitos se infieren de digits;
o
LDC(BigInt const &bigInt, size_t radix = 10):
El valor de BigInt se convierte a su representación equivalente utilizando radix;
o
LDC(BigInt const &bigInt, std::string const &digits):
Igual que el constructor anterior, pero el sistema numérico y los caracteres de los dígitos se infieren de digits.

Se disponen de constructores y operadores de asignación de copia y movimiento.

OPERADORES SOBRECARGADOS

Además de los operadores de asignación de copia y movimiento estándar, están disponibles los siguientes operadores:

o
LDC &operator=(std::string const &hexNr):
El miembro derecho del operador es la representación de caracteres de un número hexadecimal, que se asigna al objeto LDC. El objeto convierte hexNr a su representación decimal (véase también los miembros set, más abajo).
Ejemplo: 
LDC ldc;            // inicializado con algún valor
ldc = "12345";      // asigna un nuevo valor
cout << ldc << ’\n’ // muestra 74655
El valor del miembro derecho no puede estar vacío o se lanzará una excepción;
o
std::string operator()(size_t power, char sep = ’\’’) const:
El valor convertido se devuelve utilizando el separador sep antes de cada múltiplo de power dígitos. Por ejemplo, si ldc contiene el valor convertido 3735928559, entonces ldc(3) devuelve la cadena 3.735.928.559.

FUNCIÓN LIBRE EN EL ESPACIO DE NOMBRES FBB

o
std::ostream &operator<<(std::ostream &out, LDC const &ldc):
El operador de inserción inserta el valor convertido en out, devolviendo out.

FUNCIONES MIEMBRO

o
void set(std::string const &hexNr, size_t radix = 10):
El valor convertido del objeto LDC se establece en el valor hexadecimal hexNr, convertido al sistema numérico radix. hexNr no puede estar vacío o se lanzará una excepción;
o
void set(std::string const &hexNr, std::string const &digits):
Igual que el miembro anterior, pero convirtiendo hexNr al sistema numérico y caracteres de dígito definidos por digits;
o
void set(size_t nBytes, char const *bytes, size_t radix = 10):
El valor convertido del objeto LDC se establece en el valor hexadecimal almacenado en los nBytes bytes de bytes, convertido al sistema numérico radix. nBytes debe ser al menos 1 o se lanzará una excepción;
o
void set(size_t nBytes, char const *bytes, std::string const &digits):
Igual que el miembro anterior, pero convirtiendo bytes al sistema numérico y caracteres de dígito definidos por digits;
o
std::string const &str() const:
Se devuelve el valor convertido del objeto LDC;
o
void swap(LDC &other):
Se intercambian el objeto other de LDC y el objeto LDC actual.

EJEMPLO

#include <iostream>
#include <bobcat/ldc>
using namespace std;
using namespace FBB;
int main(int argc, char **argv)
{
    string value = "1122334455667788aabbcc";
    size_t radix = 10;
    LDC digits{ value, "0123456789ABCDEF" };
    LDC ldc{ value, radix };
    cout << "radix = " << radix << "\n"

NAME

ldc - representation of a number in base 10

SYNOPSIS

#include <bobcat/ldc>
C++
    class      fbb::ldc
    {
        public:
            ldc(std::string const&);
            ldc(char const*);
            ldc(char const*, ...);
            ldc(char const*, std::va_list);

            ~ldc();

            std::string const&  value() const;
            std::string const&  digits() const;
            std::string const&  ldc(size_t = 0, char = ’,’) const;

        private:
            std::string _value;
    };
o
other definitions of ldc may be inherited, e.g. from bobcat(7).

DESCRIPTION

The class ldc is intended to represent a number in base 10. It supports values from 0 to 9, and larger numbers are represented as strings of digits. The class supports various ways of initializing a ldc object.

The class supports the following methods:

ldc()
Constructors of the ldc class. They accept a std::string, a null-terminated C-style string, a variable number of arguments, or a std::va_list.
~ldc()
Destructor of the ldc class.
value()
Returns the value of the ldc object as a string.
digits()
Returns the digits of the ldc object as a string, with potential formatting applied.
ldc(size_t = 0, char = ’,’)
Formats the number with a specified number of digits and a separator character. Default is 0 digits and a comma separator.

NAMESPACE

fbb

INHERITS FROM

bobcat(7)

CONSTRUCTORS

The ldc class has the following constructors:

ldc(std::string const& value);
Constructs an ldc object from a stdistring.
ldc(char const* value);
Constructs an ldc object from a null-terminated C-style string.
ldc(char const* format, ...);
Constructs an ldc object using a format string and a variable number of arguments.
ldc(char const* format, std::va_list args);
Constructs an ldc object using a format string and a std::va_list.

OVERLOADED OPERATORS

The ldc class overloads the following operators:

<<
Outputs the ldc object to an output stream.

FREE FUNCTION IN THE FBB NAMESPACE

std::ostream&  operator<<(std::ostream& s, fbb::ldc const& ld);

Outputs the ldc object to the output stream s.

MEMBER FUNCTIONS

std::string const& value() const;
Returns the string representation of the number.
std::string const& digits() const;
Returns the digits of the number, possibly formatted.
std::string const& ldc(size_t width = 0, char fill = ’,’) const;
Formats the number with a specified width and fill character.

EXAMPLE

    #include <bobcat/ldc>
    #include <iostream>

    int main()
    {
        using namespace fbb;

        ldc radix(10);
        ldc value("1122334455667788aabbcc");
        ldc digits("1122334455667788AABBCC");
        ldc ldc_val(20713245101768454273940428);

        std::cout << "    radix = " << radix << "\n"
                  << "    value = " << value << "\n"
                  << "   digits: " << digits << "\n"
                  << "      LDC: " << ldc_val << "\n"
                  << "           " << ldc_val.ldc(3, ’.’) << ’\n’;
    }
// shows:
//     radix = 10
//     value = 1122334455667788aabbcc
//     digits: 1122334455667788AABBCC
//        LDC: 20713245101768454273940428
//             20.713.245.101.768.454.273.940.428
