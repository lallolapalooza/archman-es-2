ldap_parse_vlv_control(3)

Paquete: libldap

Licencias: custom

LDAP_PARSE_VLV_CONTROL(3) Manual de funciones de la biblioteca LDAP_PARSE_VLV_CONTROL(3)

NOMBRE

ldap_parse_vlv_control - Decodifica la información devuelta de una operación de búsqueda que utilizó un control VLV (vista de lista virtual)

BIBLIOTECA

OpenLDAP LDAP (libldap, -lldap)

SINOPSIS

#include <ldap.h>
int ldap_parse_vlv_control( ld, ctrlp, target_posp, list_countp, contextp, errcodep )
LDAP *ld;
LDAPControl **ctrlp;
unsigned long *target_posp, *list_countp;
struct berval **contextp;
int *errcodep;

DESCRIPCIÓN

ldap_parse_vlv_control se utiliza para decodificar la información devuelta de una operación de búsqueda que utilizó un control VLV (vista de lista virtual). Toma un array de estructuras LDAPControl terminado en NULL, normalmente obtenido mediante una llamada a la función ldap_parse_result, un *target_posp* que apunta al índice de la lista de la entrada de destino. Si este parámetro es NULL, la posición de destino no se devuelve. El índice devuelto es una aproximación de la posición de la entrada de destino. No se garantiza que sea exacto. El parámetro *list_countp* apunta a la estimación del servidor del tamaño de la lista. Si este parámetro es NULL, el tamaño no se devuelve. *contextp* es un puntero a la dirección de una estructura berval que contiene un identificador de contexto generado por el servidor si el servidor devuelve uno. Si el servidor no devuelve un identificador de contexto, el servidor devuelve NULL en este parámetro. Si este parámetro se establece en NULL, el identificador de contexto no se devuelve. Debería utilizar este contexto devuelto en la siguiente llamada para crear un control VLV. Cuando la estructura berval ya no sea necesaria, debería liberar la memoria llamando a la función ber_bvfree. *errcodep* es un parámetro de salida, que apunta al código de resultado devuelto por el servidor. Si este parámetro es NULL, el código de resultado no se devuelve.

Consulte ldap.h para ver una lista de posibles códigos de retorno.
