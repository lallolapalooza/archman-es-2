DESCRIPCIÓN

ldns_pkt
Paquete DNS

Esta estructura contiene un paquete DNS completo (ya sea una consulta o una respuesta)

Es la representación completa de lo que realmente envía a un
servidor de nombres, y lo que este responde (asumiendo que usted es el cliente aquí).
struct ldns_struct_pkt
{
Sección de cabecera:
ldns_hdr *_header;
/* elementos adicionales necesarios en un paquete */
rdf (A o AAAA) con la dirección IP del servidor de origen:
ldns_rdf *_answerfrom;
Marca de tiempo de cuándo se envió o creó el paquete:
struct timeval timestamp;
La duración de la consulta a la que este paquete es una respuesta:
uint32_t _querytime;
El tamaño del formato en el cable del paquete en octetos:
size_t _size;
Opcional tsig rr:
ldns_rr *_tsig_rr;
Tamaño del búfer disponible de EDNS0, ver RFC2671:
uint16_t _edns_udp_size;
EDNS0 Código de respuesta extendido:
uint8_t _edns_extended_rcode;
EDNS Versión:
uint8_t _edns_version;
/* Bandera de presencia OPT pseudo-RR */
uint8_t _edns_present;
Bits de datos EDNS reservados:
uint16_t _edns_z;
Datos rdata de EDNS arbitrarios:
ldns_rdf *_edns_data;
Datos EDNS estructurados:
ldns_edns_option_list *_edns_list;
Sección de pregunta:
ldns_rr_list *_question;
Sección de respuesta:
ldns_rr_list *_answer;
Sección de autoridad:
ldns_rr_list *_authority;
Sección adicional:
ldns_rr_list *_additional;
};
typedef struct ldns_struct_pkt ldns_pkt;
