NOMBRE

ldbadd - Utilidad de línea de comandos para agregar registros a una LDB

SINOPSIS

ldbadd [-h] [-H URL-LDB] [archivo-ldif1] [archivo-ldif2] [...]

DESCRIPCIÓN

ldbadd agrega registros a una base de datos ldb(3). Lee los archivos ldif(5) especificados en la línea de comandos y agrega los registros de estos archivos a la base de datos LDB, que se especifica mediante la opción -H o la variable de entorno LDB_URL.

Si se especifica - como archivo ldb, la entrada ldif se lee de la entrada estándar.

OPCIONES

-h

Muestra la lista de opciones disponibles.

-H <url-ldb>

URL LDB a la que conectarse. Consulte ldb(3) para obtener más detalles.

ENTORNO

LDB_URL

URL LDB a la que conectarse (puede ser anulada usando la opción de línea de comandos -H).

VERSIÓN

ldb(3), ldbmodify, ldbdel, ldif(5)
