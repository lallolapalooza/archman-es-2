LDAP_URL(3) Manual de Funciones de Biblioteca LDAP_URL(3)

NOMBRE

ldap_is_ldap_url, ldap_url_parse, ldap_free_urldesc - Rutinas de Localizador Uniforme de Recursos (URL) LDAP

BIBLIOTECA

OpenLDAP LDAP (libldap, -lldap)

SINOPSIS

#include <ldap.h>
int ldap_is_ldap_url( const char *url )
int ldap_url_parse( const char *url, LDAPURLDesc **ludpp )
typedef struct ldap_url_desc {
    char *      lud_scheme;     /* Esquema URI */
    char *      lud_host;       /* Host LDAP a contactar */
    int         lud_port;       /* Puerto en el host */
    char *      lud_dn;         /* Base para la búsqueda */
    char **     lud_attrs;      /* Lista de atributos */
    int         lud_scope;      /* Un valor LDAP_SCOPE_... */
    char *      lud_filter;     /* Filtro de búsqueda LDAP */
    char **     lud_exts;       /* Extensiones LDAP */
    int         lud_crit_exts;  /* verdadero si alguna extensión es crítica */
    /* puede contener campos adicionales para uso interno */
} LDAPURLDesc;
void ldap_free_urldesc( LDAPURLDesc *ludp );

DESCRIPCIÓN

Estas rutinas soportan el uso de URLs (Localizadores Uniformes de Recursos) LDAP según se detalla en RFC 4516. Las URLs LDAP tienen este aspecto:

  ldap://hostport/dn[?attrs[?scope[?filter[?exts]]]]
donde:
  hostport es un nombre de host con un opcional ":numerodepuerto"
  dn es la base de búsqueda
  attrs es una lista separada por comas de atributos a solicitar
  scope es una de estas tres cadenas:
    base one sub (predeterminado=base)
  filter es el filtro
  exts son conjuntos reconocidos de extensiones LDAP y/o de API.
Ejemplo:
  ldap://ldap.example.net/dc=example,dc=net?cn,sn?sub?(cn=*)

Las URLs que están envueltas en corchetes angulares y/o precedidas por "URL:" también se toleran. Esquemas LDAP alternativos como ldaps:// y ldapi:// también pueden ser analizados utilizando las rutinas a continuación.

ldap_is_ldap_url() devuelve un valor distinto de cero si url parece una URL LDAP (en contraposición a otro tipo de URL). Puede ser utilizada como una comprobación rápida de una URL LDAP; la rutina ldap_url_parse() debe ser utilizada si se necesita una comprobación más exhaustiva.

ldap_url_parse() descompone una URL LDAP pasada en url en sus partes componentes. Si tiene éxito, se devuelve cero, se asigna, se rellena y se establece ludpp para que apunte a ella una descripción de URL LDAP. Si ocurre un error, se devuelve un código de error de URL distinto de cero.

ldap_free_urldesc() debe ser llamada para liberar una descripción de URL LDAP que se obtuvo de una llamada a ldap_url_parse().
