ldns-keygen(1)

Paquete: ldns

ldns-keygen(1) Manual de Comandos Generales ldns-keygen(1)

NOMBRE

ldns-keygen - generar un par de claves DNSSEC

SINOPSIS

ldns-keygen [ OPCIÓN ] DOMINIO

DESCRIPCIÓN

ldns-keygen se utiliza para generar un par de claves pública/privada. Al ejecutarse, creará 3 archivos; un archivo .key con la clave pública DNSKEY, un archivo .private con los datos de la clave privada y un .ds con el registro DS de la clave pública DNSKEY.

ldns-keygen también puede utilizarse para crear claves simétricas (para TSIG) seleccionando el algoritmo apropiado: hmac-md5.sig-alg.reg.int, hmac-sha1, hmac-sha224, hmac-sha256, hmac-sha384 o hmac-sha512. En ese caso no se creará ningún registro DS ni archivo .ds.

ldns-keygen imprime el nombre base de los archivos de clave: K<nombre>+<alg>+<id>

OPCIONES

-a <algoritmo>
Crear una clave con este algoritmo. Especificar 'list' aquí proporciona una lista de algoritmos soportados. También se aceptan varios nombres alias (de versiones anteriores y otro software), la lista proporciona nombres de la RFC. También se acepta el número plano del algoritmo.
-b <bits>
Usar esta cantidad de bits para la longitud de la clave.
-k
Cuando se proporciona, genera una clave de firma de claves. Esto simplemente establece el campo de flags a 257 en lugar de 256 en el registro DNSKEY RR en el archivo .key.
-r dispositivo
Hace que ldns-keygen use este archivo para sembrar el generador aleatorio. Por defecto será /dev/random.
-s
ldns-keygen creará enlaces simbólicos llamados .private a la nueva clave privada generada, .key a la clave pública DNSKEY y .ds al archivo que contiene los datos del registro DS.
-f
Forzar la sobrescritura de enlaces simbólicos si existen.
-v
Mostrar la versión y salir.
