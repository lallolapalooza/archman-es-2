DESCRIPCIÓN

ldns_pkt
Paquete DNS

Esta estructura contiene un paquete DNS completo (ya sea una consulta o una respuesta)

Es la representación completa de lo que realmente envías a un
servidor de nombres, y lo que este devuelve (asumiendo que eres el cliente aquí).
struct ldns_struct_pkt
{
Sección de cabecera:
ldns_hdr *_header;
/* elementos adicionales necesarios en un paquete */
rdf (A o AAAA) con la dirección IP del servidor del que proviene:
ldns_rdf *_answerfrom;
Marca de tiempo del momento en que se envió o creó el paquete:
struct timeval timestamp;
La duración de la consulta a la que responde este paquete:
uint32_t _querytime;
El tamaño del formato de cableado del paquete en octetos:
size_t _size;
RR tsig opcional:
ldns_rr *_tsig_rr;
Tamaño del búfer disponible para EDNS0, ver RFC2671:
uint16_t _edns_udp_size;
Rcode extendido de EDNS0:
uint8_t _edns_extended_rcode;
Versión EDNS:
uint8_t _edns_version;
/* Indicador de presencia de pseudo-RR OPT */
uint8_t _edns_present;
Bits de datos EDNS reservados:
uint16_t _edns_z;
Datos EDNS arbitrarios:
ldns_rdf *_edns_data;
Datos EDNS estructurados:
ldns_edns_option_list *_edns_list;
Sección de preguntas:
ldns_rr_list *_question;
Sección de respuestas:
ldns_rr_list *_answer;
Sección de autoridad:
ldns_rr_list *_authority;
Sección adicional:
ldns_rr_list *_additional;
};
typedef struct ldns_struct_pkt ldns_pkt;
