DESCRIPCIÓN

ldns_zone
Zona DNS

Una lista de RR's con información
adicional que proviene del RR SOA
Nota: aún no se ha hecho nada para que esto sea eficiente.
struct ldns_struct_zone
{
el soa define una zona:
ldns_rr *_soa;
/* básicamente una zona es una lista de rr's */
ldns_rr_list *_rrs;
/* podríamos cambiar esto a un árbol b, etc., etc. hacer */
};
typedef struct ldns_struct_zone ldns_zone;

ldns_zone_new() crea una nueva estructura ldns_zone
Devuelve un puntero a una estructura ldns_zone

ldns_zone_free() Libera la memoria asignada para la zona y la estructura rr_list dentro de ella.
zone: la zona a liberar

ldns_zone_deep_free() Libera la memoria asignada para la zona, el RR soa dentro de ella, y la estructura rr_list dentro de ella, incluyendo los RR's contenidos en ella. etc.
zone: la zona a liberar

ldns_zone_new_frm_fp() Crea una nueva zona a partir de un archivo
z: la nueva zona
*fp: el puntero al archivo a usar
*origin: el origen de la zona
ttl: ttl predeterminado a usar
c: clase predeterminada a usar (IN)

Devuelve un mensaje ldns_status con un error o LDNS_STATUS_OK

ldns_zone_new_frm_fp_l() Crea una nueva zona a partir de un archivo, manteniendo un registro de los números de línea.
z: la nueva zona
*fp: el puntero al archivo a usar
*origin: el origen de la zona
ttl: ttl predeterminado a usar
c: clase predeterminada a usar (IN)
line_nr: se usa para mensajes de error, para llegar al número de línea.

Devuelve un mensaje ldns_status con un error o LDNS_STATUS_OK

ldns_zone_print() Imprime una estructura de zona * en la salida. Tenga en cuenta que el registro SOA se incluye en esta salida.
output: el descriptor de archivo al que imprimir
z: la zona a imprimir

ldns_zone_print_fmt() Imprime una estructura de zona * en la salida. Tenga en cuenta que el registro SOA se incluye en esta salida.
output: el descriptor de archivo al que imprimir
fmt: formato de la representación textual
z: la zona a imprimir
