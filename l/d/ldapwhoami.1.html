Paquete: openldap

Licencias: custom

LDAPWHOAMI(1) Manual de comandos generales LDAPWHOAMI(1)

NOMBRE

ldapwhoami - herramienta LDAP de consulta de identidad

SINOPSIS

ldapwhoami [-V[V]] [-d niveldebug] [-n] [-v] [-x] [-D dnbind] [-W] [-w contraseña] [-y archivocontraseña] [-H uri-ldap] [-e [!]ext[=paramext]] [-E [!]ext[=paramext]] [-o opt[=paramopt]] [-O propiedades-seguridad] [-I] [-Q] [-N] [-U cidaut] [-R reino] [-X authzid] [-Y mecanismo] [-Z[Z]]

DESCRIPCIÓN

ldapwhoami implementa la operación extendida LDAP "Who Am I?" (¿Quién soy?).

ldapwhoami abre una conexión a un servidor LDAP, se enlaza y realiza una operación whoami.

OPCIONES

-V[V]
Muestra la información de la versión. Si se proporciona -VV, solo se muestra la información de la versión.
-d niveldebug
Establece el nivel de depuración LDAP a niveldebug. ldapwhoami debe estar compilado con LDAP_DEBUG definido para que esta opción tenga algún efecto.
-n
Muestra lo que se haría, pero sin realizar realmente la operación whoami. Útil para depuración junto con -v.
-v
Ejecuta en modo detallado, con muchos diagnósticos escritos en la salida estándar.
-x
Utiliza autenticación simple en lugar de SASL.
-D dnbind
Utiliza el Distinguished Name (DN) dnbind para enlazarse al directorio LDAP. Para enlaces SASL, se espera que el servidor ignore este valor.
-W
Pide la contraseña de autenticación simple. Se utiliza en lugar de especificar la contraseña en la línea de comandos.
-w contraseña
Utiliza contraseña como la contraseña para la autenticación simple.
-y archivocontraseña
Utiliza el contenido completo de archivocontraseña como la contraseña para la autenticación simple.
-H uri-ldap
Especifica una o más URIs que apuntan a los servidores LDAP; solo se permiten los campos de protocolo/host/puerto; se espera una lista de URIs, separadas por espacios en blanco o comas.
-e [!]ext[=paramext]
-E [!]ext[=paramext]

Especifica extensiones generales con -e y extensiones whoami con -E. ´!´ indica criticidad.

Extensiones generales:

  [!]assert=<filtro>    (un filtro RFC 4515)
  !authzid=<authzid>    ("dn:<dn>" o "u:<usuario>")
  [!]bauthzid           (control RFC 3829 authzid)
  [!]chaining[=<resolver>[/<cont>]]
  [!]manageDSAit
  [!]noop
  ppolicy
  [!]postread[=<attrs>] (una lista de atributos separada por comas)
  [!]preread[=<attrs>]  (una lista de atributos separada por comas)
  [!]relax
  sessiontracking[=<nombreusuario>]
  abandon,cancel,ignore (SIGINT envía abandon/cancel,
  o ignora la respuesta; si es crítico, no espera a SIGINT.
  no son realmente controles)

Extensiones WhoAmI:

  (ninguna)
-o opt[=paramopt]

Especifica cualquier opción de ldap.conf(5) o una de las siguientes:

  nettimeout=<tiempo>  (en segundos, o "none" o "max")
  ldif_wrap=<ancho>     (en columnas, o "no" para no envolver)

Opción -o que se puede pasar aquí, consulta ldap.conf(5) para más detalles.

-O propiedades-seguridad
Especifica las propiedades de seguridad SASL.
-I
Habilita el modo interactivo SASL. Siempre pide la entrada. Por defecto, solo pide entrada cuando es necesario.
-Q
Habilita el modo silencioso SASL. Nunca pide entrada.
-N
No utiliza DNS inverso para canonizar el nombre de host SASL.
-U cidaut
Especifica el ID de autenticación para el enlace SASL. La forma del ID depende del mecanismo SASL real utilizado.
-R reino
Especifica el reino del ID de autenticación para el enlace SASL. La forma del reino depende del mecanismo SASL real utilizado.
-X authzid
Especifica el ID de autorización solicitado para el enlace SASL. authzid debe tener uno de los siguientes formatos: dn:<nombre distinguido> o u:<nombredeusuario>
-Y mecanismo
Especifica el mecanismo SASL que se utilizará para la autenticación. Si no se especifica, el programa elegirá el mejor mecanismo que el servidor conozca.
-Z[Z]
Emite la operación extendida StartTLS (Transport Layer Security). Si usa -ZZ, el comando requerirá que la operación sea exitosa.

EJEMPLO

    ldapwhoami -x -D "cn=Manager,dc=example,dc=com" -W

Nombre

ami - una utilidad para la gestión de paquetes de Arch Linux.

Sintaxis

ami [opciones] comando [argumentos]

Descripción

ami es una herramienta de línea de comandos diseñada para facilitar la gestión de paquetes en Arch Linux. Permite instalar, actualizar, eliminar y buscar paquetes, así como gestionar repositorios y realizar otras tareas relacionadas con los paquetes.

Opciones

-h, --help: Muestra un mensaje de ayuda y sale.

-v, --version: Muestra la información de la versión y sale.

-S, --sync: Sincroniza las bases de datos de los paquetes e instala paquetes.

-Sy, --refresh: Sincroniza las bases de datos de los paquetes.

-Su, --upgrade: Actualiza los paquetes instalados.

-Syu, --sysupgrade: Sincroniza las bases de datos de los paquetes y actualiza los paquetes instalados.

-Ss, --search <palabra(s) clave>: Busca paquetes en los repositorios.

-Si, --info <paquete>: Muestra información detallada sobre un paquete.

-Sg, --group <nombre_grupo>: Instala o lista paquetes de un grupo.

-Sc, --clean: Limpia la caché de paquetes descargados.

-Scc, --clean-all: Elimina todos los paquetes de la caché.

-R, --remove <paquete>: Elimina un paquete.

-Rs, --recursive-remove <paquete>: Elimina un paquete y sus dependencias que ya no son necesarias.

-Rn, --nosave <paquete>: Elimina un paquete y sus archivos de configuración.

-Q, --query <paquete>: Consulta paquetes instalados.

-Ql, --list <paquete>: Lista los archivos de un paquete instalado.

-Qi, --info <paquete>: Muestra información sobre un paquete instalado.

-Qm, --foreign: Lista los paquetes instalados desde fuera de los repositorios oficiales.

Ejemplos

Instalar un paquete: ami -S firefox

Actualizar el sistema: ami -Syu

Buscar un paquete: ami -Ss vim

Eliminar un paquete: ami -R nano

Limpiar la caché de paquetes: ami -Sc
