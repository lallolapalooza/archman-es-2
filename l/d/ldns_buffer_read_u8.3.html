ldns_buffer_read_u8(3)

ldns API manual LDNS buffer manipulation ldns_buffer_read_u8()

NOMBRE

ldns_buffer_read_u8 - lee un byte sin firmar de un búfer

SINOPSIS


#include <stdint.h>
#include <stdbool.h>

#include "ldns/buffer.h"

uint8_t
ldns_buffer_read_u8(ldns_buffer *buffer);

DESCRIPCIÓN

Lee un byte sin firmar del búfer proporcionado. El puntero de lectura del búfer se incrementará en 1.

ARGUMENTOS

buffer
El búfer del que se leerá.

RETORNO

El byte leído.

VER TAMBIÉN

ldns_buffer_new, ldns_buffer_free, ldns_buffer_limit, ldns_buffer_read

OBSERVACIONES

Esta función no realiza comprobaciones de límites. Si se llama cuando el búfer está vacío o el puntero de lectura está al final, el comportamiento no está definido.
