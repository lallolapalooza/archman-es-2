DESCRIPCIÓN

ldns_rr_descriptor
Contiene toda la información sobre los tipos de registros de recursos.

Esta estructura contiene, para todos los tipos de rr, los campos rdata que están definidos.
struct ldns_struct_rr_descriptor
{
Tipo del RR que se describe aquí:
ldns_rr_type _type;
Nombre textual del tipo de RR.
const char *_name;
Número mínimo de campos rdata en los RR de este tipo.
uint8_t _minimum;
Número máximo de campos rdata en los RR de este tipo.
uint8_t _maximum;
Especificación del formato de cableado para el rr, es decir, los tipos de campos rdata en su orden respectivo.
const ldns_rdf_type *_wireformat;
Tipos de rdf especiales:
ldns_rdf_type _variable;
Especifica si se puede usar compresión para dnames en este tipo de RR.
ldns_rr_compress _compress;
El número de DNAMEs en la cadena _wireformat, para análisis.
uint8_t _dname_count;
};
typedef struct ldns_struct_rr_descriptor ldns_rr_descriptor;

ldns_rr_descript() devuelve el descriptor del registro de recursos para el tipo de rr dado.

type: el valor del tipo del tipo de rr
Devuelve el ldns_rr_descriptor para este tipo

ldns_rr_descriptor_minimum() devuelve el número mínimo de campos rdata del tipo de rr que describe este descriptor.

descriptor: para un tipo de rr
Devuelve el número mínimo de campos rdata

ldns_rr_descriptor_maximum() devuelve el número máximo de campos rdata del tipo de rr que describe este descriptor.

descriptor: para un tipo de rr
Devuelve el número máximo de campos rdata

ldns_rr_descriptor_field_type() devuelve el tipo rdf para el número de campo rdata dado del tipo de rr para el descriptor dado.

descriptor: para un tipo de rr
field: el número de campo
Devuelve el tipo rdf para el campo
