DESCRIPCIÓN

ldns_pkt_edns() devuelve true si este paquete necesita y usa un RR EDNS para ser enviado. En este momento, la única razón es un tamaño de paquete esperado mayor a 512 bytes, pero, por ejemplo, DNSSEC también sería una buena razón.
