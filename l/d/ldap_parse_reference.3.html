NOMBRE

ldap_parse_reference - Extrae referencias y controles de un mensaje de referencia

BIBLIOTECA

OpenLDAP LDAP (libldap, -lldap)

SINOPSIS

#include <ldap.h>
int ldap_parse_reference( LDAP *ld, LDAPMessage *reference,
	char ***referralsp, LDAPControl ***serverctrlsp,
	int freeit )

DESCRIPCIÓN

La rutina ldap_parse_reference() se utiliza para extraer referencias y controles de un mensaje de referencia. El parámetro reference es un mensaje de referencia tal como lo devuelve una llamada a ldap_first_reference(3), ldap_next_reference(3), ldap_first_message(3), ldap_next_message(3), o ldap_result(3).

El parámetro referralsp se rellenará con una matriz asignada de cadenas de caracteres. Las cadenas son copias de las referencias contenidas en el mensaje analizado. La matriz debe liberarse llamando a ldap_value_free(3). Si referralsp es NULL, no se devuelven referencias. Si no se devolvieron referencias, *referralsp se establece en NULL.

El parámetro serverctrlsp se rellenará con una matriz asignada de controles copiados del mensaje analizado. La matriz debe liberarse llamando a ldap_controls_free(3). Si serverctrlsp es NULL, no se devuelven controles. Si no se devolvieron controles, *serverctrlsp se establece en NULL.

El parámetro freeit determina si el mensaje analizado se libera o no después de la extracción. Cualquier valor distinto de cero provocará la liberación del mensaje. La rutina ldap_msgfree(3) también se puede utilizar para liberar el mensaje más tarde.

ERRORES

En caso de éxito, se devuelve LDAP_SUCCESS. De lo contrario, los valores de los parámetros referralsp y serverctrlsp no están definidos.

VER TAMBIÉN

ldap(3), ldap_first_reference(3), ldap_first_message(3), ldap_result(3), ldap_get_values(3), ldap_controls_free(3)
