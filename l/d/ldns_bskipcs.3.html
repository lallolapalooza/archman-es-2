ldns(3) Manual de funciones de biblioteca ldns(3)

NOMBRE

ldns_bget_token, ldns_bgetc, ldns_bskipcs - obtener tokens de buffers

SINOPSIS

#include <stdint.h>
#include <stdbool.h>

#include <ldns/ldns.h>

ssize_t ldns_bget_token(ldns_buffer *b, char *token, const char *delim, size_t limit);

int ldns_bgetc(ldns_buffer *buffer);

void ldns_bskipcs(ldns_buffer *buffer, const char *s);

DESCRIPCIÓN

ldns_bget_token() devuelve un token/carácter del buffer b. Esta función maneja ( y ) en el buffer, e los ignora cuando los encuentra.
*b: el buffer del que leer
*token: el token se coloca aquí
*delim: caracteres en los que debe detenerse el análisis
*limit: cuánto leer. Si es 0 se usa el máximo incorporado
Devuelve 0 en caso de error o EOF de b. De lo contrario, devuelve la longitud de lo leído.

ldns_bgetc() devuelve el siguiente carácter de un buffer. Avanza el puntero de posición 1. Cuando se alcanza el final del buffer, devuelve EOF. Este es el equivalente del buffer para getc().
*buffer: buffer del que leer
Devuelve EOF en caso de fallo, de lo contrario devuelve el carácter.

ldns_bskipcs() omite todos los caracteres de la cadena dada en el buffer, moviendo la posición al primer carácter que no está en *s.
*buffer: buffer a utilizar
*s: caracteres a omitir
Devuelve void
