LDO65(1) Manual de comandos generales LDO65(1)

NOMBRE

ldo65 - enlazador para archivos objeto o65

SINOPSIS

ldo65 [OPCIÓN]... ARCHIVO...

DESCRIPCIÓN

ldo65 es un enlazador para archivos en formato objeto o65, anteriormente ld65 pero renombrado para evitar conflictos con el paquete cc65 (un producto separado).

OPCIONES

-b? dirección
Reubica el segmento ? en dirección. ? debe ser t, d, b o z para indicar el segmento de texto, datos, bss o cero respectivamente. Consulte la página del manual de xa(1) para obtener una explicación.
-o nombrearchivo
Establece el nombre del archivo de salida. El valor predeterminado es a.o65.
-L nombre
Permite que la etiqueta nombre permanezca indefinida, incluso después del enlazado. Esta opción puede especificarse varias veces para múltiples etiquetas.
-U
Permite que cualquier etiqueta permanezca indefinida, incluso después del enlazado.
-G
Suprime la escritura de globales.
-g nombre
Exporta solo la global nombre. Esta opción puede especificarse varias veces para múltiples globales.
--help
Muestra un resumen de las opciones.
--version
Muestra la versión del programa.
