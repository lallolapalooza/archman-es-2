NOMBRE

ldns_rdf_new, ldns_rdf_clone, ldns_rdf_new_frm_data, ldns_rdf_new_frm_str, ldns_rdf_new_frm_fp, ldns_rdf_free, ldns_rdf_deep_free, ldns_rdf_print - creación, destrucción e impresión de ldns_rdf

SINOPSIS

#include <stdint.h>
#include <stdbool.h>

#include <ldns/ldns.h>

ldns_rdf* ldns_rdf_new(ldns_rdf_type type, size_t size, void *data);

ldns_rdf* ldns_rdf_clone(const ldns_rdf *rd);

ldns_rdf* ldns_rdf_new_frm_data(ldns_rdf_type type, size_t size, const void *data);

ldns_rdf* ldns_rdf_new_frm_str(ldns_rdf_type type, const char *str);

ldns_status ldns_rdf_new_frm_fp(ldns_rdf **r, ldns_rdf_type type, FILE *fp);

void ldns_rdf_free(ldns_rdf *rd);

void ldns_rdf_deep_free(ldns_rdf *rd);

void ldns_rdf_print(FILE *output, const ldns_rdf *rdf);

DESCRIPCIÓN

ldns_rdf_new() asigna una nueva estructura rdf y la rellena. Esta función NO copia el contenido del búfer, a diferencia de ldns_rdf_new_frm_data()
type: tipo del rdf
size: tamaño del búfer
data: puntero al búfer a copiar
Devuelve la nueva estructura rdf o NULL en caso de fallo

ldns_rdf_clone() clona una estructura rdf. Los datos se copian.
rd: rdf a copiar
Devuelve una nueva estructura rdf

ldns_rdf_new_frm_data() asigna una nueva estructura rdf y la rellena. Esta función _sí_ copia el contenido del búfer, a diferencia de ldns_rdf_new()
type: tipo del rdf
size: tamaño del búfer
data: puntero al búfer a copiar
Devuelve la nueva estructura rdf o NULL en caso de fallo

ldns_rdf_new_frm_str() crea un nuevo rdf a partir de una cadena.
type: tipo a usar
str: cadena a usar
Devuelve ldns_rdf* o NULL en caso de error

ldns_rdf_new_frm_fp() crea un nuevo rdf a partir de un archivo que contiene una cadena.
r: el nuevo rdf
type: tipo a usar
fp: el puntero de archivo a usar
Devuelve LDNS_STATUS_OK o el error

ldns_rdf_free() libera una estructura rdf, dejando intacto el puntero de datos.
rd: puntero a liberar
Devuelve void

ldns_rdf_deep_free() libera una estructura rdf _y_ libera los datos. El rdf debe haber sido creado con _new_frm_data
rd: la estructura rdf a liberar
Devuelve void

ldns_rdf_print() Imprime los datos en el campo rdata al flujo de archivo dado (en formato de presentación)

output: el flujo de archivo a donde imprimir
rdf: el campo rdata a imprimir
Devuelve void
