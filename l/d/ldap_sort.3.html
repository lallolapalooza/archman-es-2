LDAP_SORT(3) Manual de funciones de biblioteca LDAP_SORT(3)

NOMBRE

ldap_sort_entries, ldap_sort_values, ldap_sort_strcasecmp - Rutinas de ordenación LDAP (obsoleto)

BIBLIOTECA

OpenLDAP LDAP (libldap, -lldap)

DESCRIPCIÓN

Las funciones ldap_sort_entries(), ldap_sort_values() y ldap_sort_strcasecmp() están obsoletas.

Las interfaces obsoletas generalmente permanecen en la biblioteca. La macro LDAP_DEPRECATED se puede definir a un valor distinto de cero (por ejemplo, -DLDAP_DEPRECATED=1) al compilar un programa diseñado para usar interfaces obsoletas. Se recomienda que los desarrolladores que escriben programas nuevos, o actualizan programas antiguos, eviten el uso de interfaces obsoletas. Con el tiempo, se espera que la documentación (y, eventualmente, el soporte) para interfaces obsoletas sea eliminada.

VER TAMBIÉN

ldap(3)
