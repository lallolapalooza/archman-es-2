Paquete: openldap

Licencias: custom

LDAPCOMPARE(1) Manual de Comandos Generales LDAPCOMPARE(1)

NOMBRE

ldapcompare - Herramienta de comparación LDAP

SINOPSIS

ldapcompare [-V[V]] [-d nivel_depuracion] [-n] [-v] [-z] [-M[M]] [-x] [-D dn_enlace] [-W] [-w contraseña] [-y archivo_contraseña] [-H uri_ldap] [-P {2|3}] [-e [!]ext[=parametro_ext]] [-E [!]ext[=parametro_ext]] [-o opcion[=parametro_opcion]] [-O propiedades-seguridad] [-I] [-Q] [-N] [-U cid_autenticacion] [-R dominio] [-X autorizacion] [-Y mecanismo] [-Z[Z]] DN {atributo:valor | atributo::valor_b64}

DESCRIPCIÓN

ldapcompare es una interfaz accesible desde la shell para la llamada a la biblioteca ldap_compare_ext(3).

ldapcompare abre una conexión a un servidor LDAP, se enlaza y realiza una comparación utilizando los parámetros especificados. El DN debe ser un nombre distinguido en el directorio. Attr debe ser un atributo conocido. Si se sigue de dos puntos, se debe proporcionar el valor de la aserción como una cadena. Si se sigue de dos puntos dobles, se proporciona la codificación base64 del valor. El código de resultado de la comparación se proporciona como código de salida y, a menos que se ejecute con -z, el programa imprime TRUE, FALSE o UNDEFINED en la salida estándar.

OPCIONES

-V[V]
Muestra información de la versión. Si se proporciona -VV, solo se muestra la información de la versión.
-d nivel_depuracion
Establece el nivel de depuración LDAP a nivel_depuracion. ldapcompare debe compilarse con LDAP_DEBUG definido para que esta opción tenga algún efecto.
-n
Muestra lo que se haría, pero sin realizar la comparación. Útil para depurar junto con -v.
-v
Ejecuta en modo detallado, con muchos diagnósticos escritos en la salida estándar.
-z
Ejecuta en modo silencioso, no se escribe ninguna salida. Debe comprobar el estado de retorno. Útil en scripts de shell.
-M[M]
Habilita el control DSA IT de gestión. -MM hace que el control sea crítico.
-x
Utiliza autenticación simple en lugar de SASL.
-D dn_enlace
Utiliza el Nombre Distinguido dn_enlace para enlazarse al directorio LDAP. Para enlaces SASL, se espera que el servidor ignore este valor.
-W
Pide la contraseña de autenticación simple. Se utiliza en lugar de especificar la contraseña en la línea de comandos.
-w contraseña
Utiliza contraseña como contraseña para la autenticación simple.
-y archivo_contraseña
Utiliza el contenido completo de archivo_contraseña como contraseña para la autenticación simple. Tenga en cuenta que completo significa que cualquier espacio en blanco inicial o final, incluidas las nuevas líneas, se considerará parte de la contraseña y, a diferencia de otros programas, no se eliminarán. Como consecuencia, las contraseñas almacenadas en archivos por comandos como echo(1) no se comportarán como se espera, ya que echo(1) por defecto añade una nueva línea final a la cadena mostrada. La forma portátil recomendada para almacenar una contraseña en texto plano en un archivo para usar con esta opción es usar slappasswd(8) con {CLEARTEXT} como hash y la opción -n.
-H uri_ldap
Especifica una o más URI que hacen referencia al(los) servidor(es) ldap; solo se permiten los campos protocolo/host/puerto; se espera una lista de URI, separadas por espacios o comas.
-P {2|3}
Especifica la versión del protocolo LDAP a utilizar.
-e [!]ext[=parametro_ext]
-E [!]ext[=parametro_ext]

Especifica extensiones generales con -e y extensiones de comparación con -E. ´!´ indica criticidad.

Extensiones generales:

  [!]assert=<filtro>    (un Filtro RFC 4515)
  !authzid=<authzid>    ("dn:<dn>" o "u:<usuario>")
  [!]bauthzid           (control authzid RFC 3829)
  [!]chaining[=<resolucion>[/<cont>]]
  [!]manageDSAit
  [!]noop
  ppolicy
  [!]postread[=<attrs>] (una lista de atributos separados por comas)
  [!]preread[=<attrs>]  (una lista de atributos separados por comas)
  [!]relax
  sessiontracking[=<nombreusuario>]
  abandon,cancel,ignore (SIGINT envía abandon/cancel,
  o ignora la respuesta; si es crítico, no espera a SIGINT.
  no son realmente controles)

Extensiones de comparación:

  !dontUseCopy
-o opcion[=parametro_opcion]

Especifica cualquier opción de ldap.conf(5) o una de las siguientes:

  nettimeout=<tiempo_espera>  (en segundos, o "none" o "max")
  ldif_wrap=<ancho>     (en columnas, o "no" para no envolver)
-O propiedades-seguridad
Especifica propiedades de seguridad SASL.
-I
Habilita el modo interactivo SASL. Siempre pide. Por defecto es pedir solo cuando sea necesario.
-Q
Habilita el modo silencioso SASL. Nunca pide.
-N
No utiliza DNS inverso para canonizar el nombre de host SASL.
-U cid_autenticacion
Especifica el ID de autenticación para el enlace SASL. La forma del ID depende del mecanismo SASL real utilizado.
-R dominio
Especifica el dominio del ID de autenticación para el enlace SASL. La forma del dominio depende del mecanismo SASL real utilizado.
-X autorizacion
Especifica el ID de autorización solicitado para el enlace SASL. autorizacion debe tener uno de los siguientes formatos: dn:<nombre distinguido> o u:<nombre de usuario>
-Y mecanismo
Especifica el mecanismo SASL que se utilizará para la autenticación. Si no se especifica, el programa elegirá el mejor mecanismo que conozca el servidor.
-Z[Z]
Emite la operación extendida StartTLS (Transport Layer Security). Si usa -ZZ, el comando requerirá que la operación sea exitosa.

EJEMPLOS

    ldapcompare "uid=babs,dc=example,dc=com"  sn:Jensen
    ldapcompare "uid=babs,dc=example,dc=com"  sn::SmVuc2Vu

son todos equivalentes.

LIMITACIONES

Requerir que el valor se pase en la línea de comandos es limitante e introduce algunas preocupaciones de seguridad. El comando debería soportar un mecanismo para especificar la ubicación (nombre de archivo o URL) desde la que leer el valor.
