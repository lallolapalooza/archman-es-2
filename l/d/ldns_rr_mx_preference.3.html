ldns_rr_mx_preference(3)

Paquete: ldns

Licencias: custom:BSD

ldns(3) Manual de funciones de biblioteca ldns(3)

NOMBRE

ldns_rr_mx_preference, ldns_rr_mx_exchange - obtener campos de rdata de RR MX

SINOPSIS

#include <stdint.h>
#include <stdbool.h>

#include <ldns/ldns.h>

ldns_rdf* ldns_rr_mx_preference(const ldns_rr *r);

ldns_rdf* ldns_rr_mx_exchange(const ldns_rr *r);

DESCRIPCIÓN

ldns_rr_mx_preference() devuelve la preferencia MX de un RR LDNS_RR_TYPE_MX
r: el registro de recursos
Devuelve un ldns_rdf* con la preferencia o NULL en caso de error

ldns_rr_mx_exchange() devuelve el host MX de un RR LDNS_RR_TYPE_MX
r: el registro de recursos
Devuelve un ldns_rdf* con el nombre del host MX o NULL en caso de error
