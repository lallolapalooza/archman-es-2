NOMBRE

ldbedit - Edita bases de datos LDB usando tu editor preferido

SINOPSIS

ldbedit [-?] [--uso] [-s base|uno|sub] [-b basedn] [-a] [-e editor] [-H LDB-URL] [expresión] [atributos...]

DESCRIPCIÓN

ldbedit es una utilidad que te permite editar entradas LDB (en archivos de base de datos o servidores LDAP) usando tu editor preferido. ldbedit genera un archivo LDIF basado en tu consulta, te permite editar el LDIF y luego fusiona ese LDIF de nuevo en el backend de LDB.

OPCIONES

-?, --ayuda

Muestra la lista de opciones disponibles y una frase que describe qué hace cada opción.

--uso

Muestra la lista de opciones disponibles. Esto es similar a la opción de ayuda, sin embargo, no proporciona ninguna descripción, por lo que es más corta.

-H <ldb-url>

URL LDB a la que conectarse. Para bases de datos tdb y lmdb, tendrá el formato tdb://archivo o mdb://archivo, respectivamente. La URL ldb://archivo intentará detectar el formato del archivo automáticamente. Para una conexión LDAP a través de sockets de dominio Unix, será del formato ldapi://socket. Para una conexión LDAP (potencialmente remota) a través de TCP, será del formato ldap://nombrehost, o ldaps://nombrehost para una conexión protegida con TLS.

-s uno|sub|base

Ámbito de búsqueda a utilizar. Un nivel, subárbol o base.

-a, -todas

Edita todos los registros. Esto te permite aplicar el mismo cambio a varios registros a la vez. Probablemente querrás combinar esto con una expresión del tipo "objectclass=*".

-e editor, --editor editor

Especifica el editor que se debe usar (anula las variables de entorno VISUAL y EDITOR). Si esta opción no se usa y ni VISUAL ni EDITOR están configuradas, se usará el editor vi.

-b basedn

Especifica el Nombre Distinguido Base a usar.

-v, --verboso

Hace que ldbedit sea más verboso sobre las operaciones que se están realizando. Sin esta opción, ldbedit solo proporcionará una línea de resumen del cambio.

AMBIENTE

LDB_URL

URL LDB a la que conectarse. Esto puede ser anulado usando la opción de línea de comandos -H.

VISUAL y EDITOR

Variables de entorno utilizadas para determinar qué editor usar. VISUAL tiene prioridad sobre EDITOR, y ambas son anuladas por la opción de línea de comandos -e.
