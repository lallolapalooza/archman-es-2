LDMTOOL(1) Comandos de usuario LDMTOOL(1)

NOMBRE

ldmtool - Una herramienta para gestionar discos dinámicos de Microsoft Windows

SINOPSIS

ldmtool [opciones]

ldmtool [opciones] scan [dispositivo...]

ldmtool [opciones] show diskgroup {disco grupo GUID}

ldmtool [opciones] show {volumen | particion | disco} {disco grupo GUID} {nombre objeto}

ldmtool [opciones] {create | remove} all

ldmtool [opciones] {create | remove} volumen {disco grupo GUID} {nombre volumen}

OPCIONES

-d|--device dispositivo

Escanea automáticamente el dispositivo.

DESCRIPCION

ldmtool es una herramienta para gestionar discos dinámicos de Microsoft Windows, que utilizan los metadatos LDM de Microsoft. Puede inspeccionarlos y también crear y eliminar dispositivos de bloque de device-mapper que pueden ser montados.

Aunque un sistema de archivos puede ser montado en modo lectura/escritura y su contenido modificado, ldmtool no es capaz de modificar los metadatos LDM en sí mismos. Es decir, no puede crear, eliminar o editar discos dinámicos.

Tampoco es capaz de montar volúmenes RAID5 a los que les falta una partición, aunque puede montar volúmenes espejados a los que les falta una partición. Sin embargo, no se recomienda montar un volumen con una partición faltante, ya que ldmtool no actualiza los metadatos LDM de ninguna manera. Esto significa que Windows no tendrá forma de determinar que las particiones no están sincronizadas cuando se monten posteriormente, lo que podría resultar en corrupción.

INVOCACION

ldmtool puede invocarse como un shell para ejecutar múltiples acciones, o para ejecutar una sola acción y salir. Si se proporciona una acción en la línea de comandos, se ejecutará en modo de acción única. Si no se proporciona ninguna acción, se iniciará un shell.

Modo shell

Cuando se invoca como shell, ldmtool no escaneará ningún dispositivo de bloque por defecto. Si se proporcionan dispositivos de bloque en la línea de comandos con la opción -d, estos serán escaneados. De lo contrario, los dispositivos de bloque deben ser escaneados explícitamente con la acción scan.

Sal del modo shell enviando un EOF, o con las acciones quit o exit.

Modo acción única

Cuando se invoca para ejecutar una sola acción, todos los dispositivos de bloque serán escaneados por defecto. En este caso, si se especifican dispositivos de bloque con la opción -d, solo esos dispositivos de bloque serán escaneados.

RESULTADOS

ldmtool devuelve resultados como datos en formato JSON. Los datos precisos devueltos se describen en detalle a continuación. Si un comando falla, no devolverá ningún dato JSON, sino que mostrará un mensaje de error. En modo shell, el fallo puede detectarse por la ausencia de un resultado en formato JSON. En modo de acción única, el llamador puede además comprobar el código de salida del comando.

ACCIONES

scan [dispositivo...]

Escanea todos los [dispositivos] en busca de metadatos LDM.

Devuelve una lista de todos los GUIDs de grupos de discos conocidos. Tenga en cuenta que no devuelve solo los grupos de discos recién descubiertos.

show diskgroup {GUID}

Devuelve información detallada sobre un único grupo de discos.

Devuelve:

name

El nombre legible del grupo de discos

guid

El GUID asignado por Windows del grupo de discos

volumes

Una lista de los nombres de todos los volúmenes en el grupo de discos

disks

Una lista de los nombres de todos los discos en el grupo de discos

show volumen {disco grupo GUID} {nombre volumen}

Devuelve información detallada sobre un volumen.

Devuelve:

name

El nombre del volumen

guid

El GUID asignado por Windows del volumen

type

El tipo de volumen. Uno de: simple , spanned , striped , mirrored , raid5

size

El tamaño del volumen en sectores

chunk-size

El tamaño del bloque, en sectores, utilizado por volúmenes striped y raid5. Para otros tipos de volumen será 0.

hint

La pista de montaje del volumen. Este valor especifica cómo espera Windows que se monte el volumen. Para un volumen con una letra de unidad asignada, podría ser 'E:'.

device

El dispositivo host de device-mapper creado para este volumen, si lo hay (por ejemplo, /dev/mapper/ldm_vol_Machine-Dg0_Volume1)

partitions

Una lista de los nombres de las particiones que constituyen este volumen.

show particion {disco grupo GUID} {nombre particion}

Devuelve información detallada sobre una partición.

Devuelve:

name

El nombre de la partición

start

El desplazamiento, en sectores, del inicio de la partición desde el principio del disco

size

El tamaño de la partición en sectores

disk

El nombre del disco en el que se encuentra la partición

show disco {disco grupo GUID} {nombre disco}

Devuelve información detallada sobre un disco.

Devuelve:

name

El nombre legible del disco

guid

El GUID del disco

present

Si el disco ha sido descubierto durante el escaneo: true o false

Si el disco está presente, además devuelve:

device

El nombre del dispositivo host (por ejemplo, /dev/sda)

data-start

El sector de inicio de la porción de datos del disco

data-size

El tamaño, en sectores, de la porción de datos del disco

metadata-start

El sector de inicio de la porción de metadatos del disco

metadata-size

El tamaño, en sectores, de la porción de metadatos del disco

create {volumen { disco grupo GUID } { nombre volumen } | all}

Crea un dispositivo device-mapper para el volumen especificado o para todos los volúmenes en todos los grupos de discos detectados.

Devuelve una lista de los nombres de los dispositivos device-mapper que fueron creados por esta acción. Tenga en cuenta que si ya existía un dispositivo para un volumen, no se incluirá en esta lista.

NAME

ldmtool

manage LDM disk groups and volumes

SYNOPSIS

ldmtool all | scan [/dev/loop[0-9]*] | diskgroup <disk&nbsp;group&nbsp;GUID&nbsp;|&nbsp;name> | volume <disk&nbsp;group&nbsp;GUID&nbsp;|&nbsp;name> [<volume&nbsp;name>] | partition <disk&nbsp;group&nbsp;GUID&nbsp;|&nbsp;name> <partition&nbsp;name> | disk <disk&nbsp;group&nbsp;GUID&nbsp;|&nbsp;name> <disk&nbsp;name> | create volume <disk&nbsp;group&nbsp;GUID&nbsp;|&nbsp;name> <volume&nbsp;name> | create all | remove <disk&nbsp;group&nbsp;GUID&nbsp;|&nbsp;name> <volume&nbsp;name> | remove all | help [<command>]

OPTIONS

No options are available for this command.

DESCRIPTION

The ldmtool command provides a shell and a set of commands for managing Dynamic Storage Technology (LDM) metadata for the purposes of retrieving and creating device-mapper devices.

LDM is a volume manager that is part of the Sun StorageTek Common Array Manager software.

The commands operate on LDM disk groups and LDM volumes. A disk group is a collection of disks, and a volume is a logical storage object created from one or more disks within a disk group.

The tool can discover LDM metadata on raw disks, display information about disk groups, volumes, and partitions, and create or remove device-mapper devices for LDM volumes.

INVOCATION

The ldmtool can be invoked in one of two ways:

  • ldmtool shell : Starts an interactive shell where commands can be entered.

  • ldmtool <command> : Executes a single command and exits.

When invoked without the shell command, ldmtool expects a single command to execute.

RESULTS

All commands that query information about LDM structures return a JSON formatted string representing the requested object or objects. Commands that create or remove devices return a list of the names of the device-mapper devices that were created or removed.

ACTIONS

scan

Scan the specified block devices (or all by default) for LDM metadata. Returns a list of disk group GUIDs detected.

diskgroup { disk group GUID | disk group name }

Display information about the specified disk group.

volume { disk group GUID | disk group name } { volume name }

Display information about the specified volume within the specified disk group.

partition { disk group GUID | disk group name } { partition name }

Display information about the specified partition within the specified disk group.

disk { disk group GUID | disk group name } { disk name }

Display information about the specified disk within the specified disk group.

create volume { disk group GUID | disk group name } { volume name }

Create a device-mapper device for the specified volume. Returns the name of the created device-mapper device.

create all

Create device-mapper devices for all discovered LDM volumes in all detected disk groups. Returns a list of the names of the created device-mapper devices.

remove volume { <disk&nbsp;group&nbsp;GUID&nbsp;|&nbsp;name> } { <volume&nbsp;name> } | all

Remove device-mapper devices for either the specified volume or all volumes in all detected disk groups.

Returns a list of the device-mapper device names which were removed by this action. Note that if no device existed for a volume it will not be returned in this list.

EXAMPLES

The following examples form a sequence from a single session of ldmtool running in shell mode.

Scan all loop devices for LDM metadata:

ldm> scan /dev/loop[0-9]*
[
  "03c0c4fc-8b6f-402b-9431-4be2e5823b1c",
  "06495a84-fbfd-11e1-8cf9-52540061f5db"
]

Two disk groups were detected. The list contains their GUIDs.

Show detailed information about one of the disk groups:

ldm> show diskgroup 06495a84-fbfd-11e1-8cf9-52540061f5db
{
  "name" : "WIN-ERRDJSBDAVF-Dg0",
  "guid" : "06495a84-fbfd-11e1-8cf9-52540061f5db",
  "volumes" : [
    "Volume4",
    "Volume1",
    "Volume2",
    "Volume3",
    "Volume5"
  ],
  "disks" : [
    "Disk1",
    "Disk2",
    "Disk3",
    "Disk4",
    "Disk5",
    "Disk6",
    "Disk7",
    "Disk8",
    "Disk9"
  ]
}

Show detailed information about one of the volumes in the disk group:

ldm> show volume 06495a84-fbfd-11e1-8cf9-52540061f5db Volume1
{
  "name" : "Volume1",
  "guid" : "c08309e9-1d30-43e5-8dc3-fcec8be76fcc",
  "type" : "spanned",
  "size" : 129024,
  "chunk-size" : 0,
  "hint" : "E:",
  "device" : "ldm_vol_WIN-ERRDJSBDAVF-Dg0_Volume1",
  "partitions" : [
    "Disk1-01",
    "Disk2-01"
  ]
}

Show detailed information about one of the partitions in the volume:

ldm> show partition 06495a84-fbfd-11e1-8cf9-52540061f5db Disk1-01
{
  "name" : "Disk1-01",
  "start" : 65,
  "size" : 96256,
  "disk" : "Disk1"
}

Show detailed information about the disk containing the partition:

ldm> show disk 06495a84-fbfd-11e1-8cf9-52540061f5db Disk1
{
  "name" : "Disk1",
  "guid" : "06495a85-fbfd-11e1-8cf9-52540061f5db",
  "present" : true,
  "device" : "/dev/loop15",
  "data-start" : 63,
  "data-size" : 100289,
  "metadata-start" : 100352,
  "metadata-size" : 2048
}

Create a device-mapper device for a volume:

ldm> create volume 06495a84-fbfd-11e1-8cf9-52540061f5db Volume1
[
  "ldm_vol_WIN-ERRDJSBDAVF-Dg0_Volume1"
]

A new device-mapper device has been created, called ldm_vol_WIN-ERRDJSBDAVF-Dg0_Volume1. Depending on how udev is configured, it will probably now be available as /dev/mapper/ldm_vol_WIN-ERRDJSBDAVF-Dg0_Volume1.

Note that returned name of the created device-mapper device is unmangled and thus can contains not-whitelisted characters. User-space device-mapper tools (like dmsetup) and libdevmapper library accept unmangled names (if properly configured) but take extra care composing path to a created device yourself. Consider using "device" field of the show volume command output.

Create device-mapper devices for all volumes in both disk groups:

ldm> create all
[
  "ldm_vol_Red-nzv8x6obywgDg0_Volume2",
  "ldm_vol_Red-nzv8x6obywgDg0_Volume1",
  "ldm_vol_Red-nzv8x6obywgDg0_Volume4",
  "ldm_vol_Red-nzv8x6obywgDg0_Stripe1",
  "ldm_vol_Red-nzv8x6obywgDg0_Raid1",
  "ldm_vol_Red-nzv8x6obywgDg0_Volume3",
  "ldm_vol_WIN-ERRDJSBDAVF-Dg0_Volume4",
  "ldm_vol_WIN-ERRDJSBDAVF-Dg0_Volume2",
  "ldm_vol_WIN-ERRDJSBDAVF-Dg0_Volume3",
  "ldm_vol_WIN-ERRDJSBDAVF-Dg0_Volume5"
]

Note that ldm_vol_WIN-ERRDJSBDAVF-Dg0_Volume1 is not in the list of devices which were created as it already existed.

Remove the device-mapper device for a single volume:

ldm> remove volume 06495a84-fbfd-11e1-8cf9-52540061f5db Volume2
[
  "ldm_vol_WIN-ERRDJSBDAVF-Dg0_Volume2"
]

ldm> remove all
[
  "ldm_vol_Red-nzv8x6obywgDg0_Volume2",
  "ldm_vol_Red-nzv8x6obywgDg0_Volume1",
  "ldm_vol_Red-nzv8x6obywgDg0_Volume4",
  "ldm_vol_Red-nzv8x6obywgDg0_Stripe1",
  "ldm_vol_Red-nzv8x6obywgDg0_Raid1",
  "ldm_vol_Red-nzv8x6obywgDg0_Volume3",
  "ldm_vol_WIN-ERRDJSBDAVF-Dg0_Volume4",
  "ldm_vol_WIN-ERRDJSBDAVF-Dg0_Volume1",
  "ldm_vol_WIN-ERRDJSBDAVF-Dg0_Volume3",
  "ldm_vol_WIN-ERRDJSBDAVF-Dg0_Volume5"
]

Note that ldm_vol_WIN-ERRDJSBDAVF-Dg0_Volume2 is not in the list of devices which were removed, as it was removed previously.
