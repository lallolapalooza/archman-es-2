dpa(1) Manual de Comandos Generales dpa(1)

NOMBRE

dpa - Analizador de Paquetes DNS. Analiza paquetes DNS en archivos de rastreo ip

SINOPSIS

dpa [ OPCIÓN ] ARCHIVO-DE-RASTREO

DESCRIPCIÓN

dpa se utiliza para analizar paquetes DNS en archivos de rastreo. Tiene 3 opciones principales: contar, filtrar y contar únicos (es decir, contar todas las ocurrencias diferentes).

OPCIONES

-c lista-de-expresiones
Cuenta las ocurrencias de expresiones coincidentes
-f expresión
Filtrar: solo procesa paquetes que coinciden con la expresión
-h
Mostrar uso
-p
Muestra el número total de paquetes DNS correctos y el porcentaje de los valores -u y -c (del total de coincidencias en el filtro -f. Si no se proporciona filtro, los porcentajes son sobre todos los paquetes DNS correctos)
-of archivo
Escribe todos los paquetes que coinciden con la bandera -f en el archivo, como datos pcap.
-ofh archivo
Escribe todos los paquetes que coinciden con la bandera -f en el archivo, en formato hexadecimal, legible por drill.
-s
Mostrar nombres de coincidencias posibles
-s nombre-de-coincidencia
Mostrar operadores y valores de coincidencia posibles para el nombre
-sf
Solo evalúa los paquetes (en formato de representación) que coinciden con el filtro -f. Si no se proporcionó -f, evalúa todos los paquetes DNS correctos.
-u lista-de-nombres-de-coincidencia
Cuenta cada ocurrencia de cada valor del nombre de coincidencia (por ejemplo, cuenta todos los tamaños de paquete, ver EJEMPLOS en ldns-dpa(1)).
-ua
Para cada nombre de coincidencia en -u, muestra el valor promedio de todas las coincidencias. El comportamiento para tipos de coincidencia que no tienen un valor entero no está definido.
-uac
Para cada nombre de coincidencia en -u, muestra el número promedio de veces que se encontró este valor.
-um número
Solo muestra los resultados de -u para valores que ocurrieron más de <número> veces.
-v nivel
Establece la verbosidad al nivel (1-5, siendo 5 el más alto). Se usa principalmente para depuración.
-notip archivo
Escribe los paquetes que no fueron reconocidos como paquetes IP en el archivo (como datos pcap).
-baddns archivo
Escribe los paquetes DNS que estaban demasiado corruptos para ser analizados en el archivo (como datos pcap).
-version
Mostrar versión y salir

LISTA Y COINCIDENCIAS

Una <lista-de-nombres-de-coincidencia> es una lista separada por comas de nombres de coincidencia (usa -s para ver los nombres de coincidencia posibles). Una <lista-de-expresiones> es una lista separada por comas de expresiones.

Una expresión tiene la siguiente forma: <expr>: (<expr>)
<expr> | <expr>
<expr> & <expr>
<coincidencia>

<coincidencia>: <nombre-de-coincidencia> <operador> <valor>

<operador>: = igual a <valor> != no igual a <valor> > mayor que <valor> < menor que <valor> >= mayor o igual que <valor> <= menor o igual que <valor> ~= contiene <valor>

Consulta la opción -s para ver los nombres de coincidencia, operadores y valores posibles.

EJEMPLOS

ldns-dpa -u packetsize -p test.tr
Cuenta todos los tamaños de paquete diferentes en test.tr y muestra los porcentajes.
ldns-dpa -f "edns=1&qr=0" -of edns.tr test.tr
Filtra todas las consultas con edns habilitado en test.tr y las guarda en edns.tr
ldns-dpa -f edns=1 -c tc=1 -u rcode test.tr
Para todos los paquetes edns, cuenta el número de paquetes truncados y todos sus códigos rcode en test.tr.
ldns-dpa -c tc=1,qr=0,qr=1,opcode=QUERY test.tr
Para todos los paquetes, cuenta el número de paquetes truncados, el número de paquetes con qr=0, el número de paquetes con qr=1 y el número de consultas en test.tr.
ldns-dpa -u packetsize -ua test.tr
Muestra todos los tamaños de paquete y el tamaño promedio del paquete por paquete.
ldns-dpa -u srcaddress -uac test.tr
Muestra todas las direcciones de origen de los paquetes y el número promedio de paquetes enviados desde esa dirección.
sudo tcpdump -i eth0 -s 0 -U -w - port 53 | ldns-dpa -f qr=0 -sf
Imprime todas las consultas de paquetes vistas en la interfaz especificada.
