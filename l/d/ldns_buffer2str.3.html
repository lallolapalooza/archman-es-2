DESCRIPCIÓN

ldns_buffer
implementación de búferes para facilitar operaciones

Los búferes de ldns pueden contener información arbitraria, por octeto. Puede escribir
en el final actual de un búfer, leer desde la posición actual y
acceder a cualquier dato dentro de él.

Un ejemplo de uso de búferes se encuentra en el código fuente de \ref host2str.c
struct ldns_struct_buffer
{
La posición actual utilizada para lectura/escritura:
size_t _position;

El límite de lectura/escritura:
size_t _limit;

La cantidad de datos que el búfer puede contener:
size_t _capacity;

Los datos contenidos en el búfer:
uint8_t *_data;

Si el búfer es fijo, no se puede redimensionar:
unsigned _fixed : 1;

/** El estado actual del búfer. Si la escritura en el búfer falla
* por cualquier motivo, este valor se cambia. De esta manera, puede
* realizar múltiples escrituras en secuencia y verificar el éxito
* posteriormente. */
ldns_status _status;
};
typedef struct ldns_struct_buffer ldns_buffer;

ldns_buffer_new() crea un nuevo búfer con la capacidad especificada.

capacity: el tamaño (en bytes) a asignar para el búfer
Devuelve el búfer creado

ldns_buffer_new_frm_data() crea un búfer con los datos especificados. Los datos SE COPIAN y se realizan asignaciones de MEMORIA. El búfer no es fijo y se puede redimensionar usando buffer_reserve().

buffer: puntero al búfer donde colocar los datos
data: los datos a encapsular en el búfer
size: el tamaño de los datos

ldns_buffer_clear() vacía el búfer y lo prepara para la escritura. El límite del búfer se establece en la capacidad y la posición se establece en 0.
buffer: el búfer a vaciar

ldns_buffer_printf() imprime en el búfer, aumentando la capacidad si es necesario usando buffer_reserve(). La posición del búfer se establece en el '\\0' terminador. Devuelve el número de caracteres escritos (sin incluir el '\\0' terminador) o -1 si falla.

ldns_buffer_free() libera el búfer.
*buffer: el búfer a liberar
Devuelve void

ldns_buffer_copy() Copia el contenido del búfer 'from' al búfer 'result' y luego voltea el búfer 'result'. Los datos se truncarán silenciosamente si el búfer 'result' es demasiado pequeño.
*result: búfer resultante al que se copia.
*from: qué copiar a result.

ldns_buffer_export() Hace que el búfer sea fijo y devuelve un puntero a los datos. El llamador es responsable de liberar el resultado.
*buffer: el búfer a exportar
Devuelve void

ldns_buffer_export2str() Exporta y devuelve los datos del búfer como una cadena de caracteres char * terminada en nulo. La cadena devuelta debe ser liberada por el llamador. El búfer debe estar en modo de escritura y, por lo tanto, no debe haber sido volteado. El búfer es fijo después de que esta función retorna.

buffer: búfer que contiene datos char *
Devuelve datos char * terminados en nulo, o NULL en caso de error

ldns_buffer2str() Devuelve una copia de los datos del búfer como una cadena de caracteres char * terminada en nulo. La cadena devuelta debe ser liberada por el llamador. El búfer debe estar en modo de escritura y, por lo tanto, no debe haber sido volteado.

buffer: búfer que contiene datos char *
Devuelve datos char * terminados en nulo, o NULL en caso de error
