ldap_first_reference(3)

Paquete: libldap

Licencias: custom

LDAP_FIRST_REFERENCE(3) Manual de funciones de biblioteca LDAP_FIRST_REFERENCE(3)

NOMBRE

ldap_first_reference, ldap_next_reference, ldap_count_references - Iterar a través de referencias de continuación en una cadena de resultados

BIBLIOTECA

OpenLDAP LDAP (libldap, -lldap)

SINOPSIS

#include <ldap.h>
int ldap_count_references( LDAP *ld, LDAPMessage *result )
LDAPMessage *ldap_first_reference( LDAP *ld, LDAPMessage *result )
LDAPMessage *ldap_next_reference( LDAP *ld, LDAPMessage *reference )

DESCRIPCIÓN

Estas rutinas se utilizan para iterar a través de las referencias de continuación en una cadena de resultados recibida de ldap_result(3) o de las rutinas de operación de búsqueda LDAP síncronas.

La rutina ldap_first_reference() se utiliza para recuperar el primer mensaje de referencia en una cadena de resultados. Toma el result tal como lo devuelve una llamada a ldap_result(3), ldap_search_s(3) o ldap_search_st(3) y devuelve un puntero al primer mensaje de referencia en la cadena de resultados.

Este puntero debe proporcionarse en una llamada posterior a ldap_next_reference() para obtener el siguiente mensaje de referencia, cuyo resultado debe proporcionarse a la siguiente llamada a ldap_next_reference(), etc. ldap_next_reference() devolverá NULL cuando no queden más mensajes de referencia. Los mensajes de referencia devueltos por estas llamadas son utilizados por ldap_parse_reference(3) para extraer referencias y controles.

Se puede obtener un recuento del número de mensajes de referencia en el resultado de la búsqueda llamando a ldap_count_references(). También se puede utilizar para contar el número de mensajes de referencia restantes en una cadena de resultados.

ERRORES

Si ocurre un error en ldap_first_reference() o ldap_next_reference(), se devuelve NULL. Si ocurre un error en ldap_count_references(), se devuelve -1.

VER TAMBIÉN

ldap(3), ldap_result(3), ldap_search(3), ldap_parse_reference(3)
