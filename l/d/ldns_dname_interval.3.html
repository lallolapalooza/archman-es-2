NOMBRE

ldns_dname_compare, ldns_dname_interval - comparar dos dnames

SINOPSIS

#include <stdint.h>
#include <stdbool.h>

#include <ldns/ldns.h>

int ldns_dname_compare(const ldns_rdf *dname1, const ldns_rdf *dname2);

int ldns_dname_interval(const ldns_rdf *prev, const ldns_rdf *middle, const ldns_rdf *next);

DESCRIPCIÓN

ldns_dname_compare() Compara los dos rdf de dname según el algoritmo de ordenación en RFC4034 Sección 6.
dname1: Primer rdf de dname a comparar
dname2: Segundo rdf de dname a comparar
Devuelve -1 si dname1 precede a dname2, 1 si dname1 sigue a dname2, y 0 si son iguales.

ldns_dname_interval() comprueba si middle se encuentra en el intervalo definido por prev y next prev <= middle < next. Esto es útil para la comprobación nsec
prev: el dname anterior
middle: el dname a comprobar
next: el dname siguiente devuelve 0 en caso de error o desconocido, -1 cuando middle está en el intervalo, +1 cuando no lo está
