NOMBRE

ldns_verify, ldns_verify_rrsig, ldns_verify_rrsig_keylist, ldns_verify_rrsig_keylist_notime, ldns_verify_notime - verificar rrsigs

SINOPSIS

#include <stdint.h>
#include <stdbool.h>

#include <ldns/ldns.h>

ldns_status ldns_verify(ldns_rr_list *rrset, ldns_rr_list *rrsig, const ldns_rr_list *keys, ldns_rr_list *good_keys);

ldns_status ldns_verify_rrsig(ldns_rr_list *rrset, ldns_rr *rrsig, ldns_rr *key);

ldns_status ldns_verify_rrsig_keylist(ldns_rr_list *rrset, ldns_rr *rrsig, const ldns_rr_list *keys, ldns_rr_list *good_keys);

ldns_status ldns_verify_rrsig_keylist_notime(const ldns_rr_list *rrset, const ldns_rr *rrsig, const ldns_rr_list *keys, ldns_rr_list *good_keys);

ldns_status ldns_verify_notime(ldns_rr_list *rrset, ldns_rr_list *rrsig, const ldns_rr_list *keys, ldns_rr_list *good_keys);

DESCRIPCIÓN

ldns_verify() Verifica una lista de firmas para un rrset.

rrset: el rrset a verificar
rrsig: una lista de firmas a comprobar
keys: una lista de claves con las que comprobar
good_keys: si esta es una lista (inicializada), el puntero a las claves de keys que validan una de las firmas se añaden a ella
Devuelve el estado LDNS_STATUS_OK si hay al menos una clave correcta

ldns_verify_rrsig() verifica un rrsig con 1 clave
rrset: el rrset
rrsig: el rrsig a verificar
key: la clave a utilizar
Devuelve un mensaje de estado indicando si la verificación tuvo éxito.

ldns_verify_rrsig_keylist() Verifica un rrsig. Se prueban todas las claves del conjunto de claves.
rrset: el rrset a comprobar
rrsig: la firma del rrset
keys: las claves a probar
good_keys: si esta es una lista (inicializada), el puntero a las claves de keys que validan una de las firmas se añaden a ella
Devuelve una lista de claves que validan el rrsig + rrset. Devuelve el estado LDNS_STATUS_OK si al menos una clave coincidió. De lo contrario, un error.

ldns_verify_rrsig_keylist_notime() Verifica un rrsig. Se prueban todas las claves del conjunto de claves. El tiempo no se comprueba.
rrset: el rrset a comprobar
rrsig: la firma del rrset
keys: las claves a probar
good_keys: si esta es una lista (inicializada), el puntero a las claves de keys que validan una de las firmas se añaden a ella
Devuelve una lista de claves que validan el rrsig + rrset. Devuelve el estado LDNS_STATUS_OK si al menos una clave coincidió. De lo contrario, un error.

ldns_verify_notime() Verifica una lista de firmas para un rrset, pero ignora el tiempo. No se comprueban la fecha de inicio ni la de caducidad.

rrset: el rrset a verificar
rrsig: una lista de firmas a comprobar
keys: una lista de claves con las que comprobar
good_keys: si esta es una lista (inicializada), el puntero a las claves de keys que validan una de las firmas se añaden a ella
Devuelve el estado LDNS_STATUS_OK si hay al menos una clave correcta
