NOMBRE

ldns-resolver - intenta crear un resolvedor a partir de un archivo resolv.conf.

SINOPSIS

ldns-resolver archivo

DESCRIPCIÓN

ldns-resolver intenta crear un resolvedor a partir de un archivo resolv.conf. Esto solo es útil para probar la robustez de la biblioteca con datos de entrada.

OPCIONES

ldns-resolver toma un nombre de archivo de resolv.conf como entrada. Por ejemplo, ldns-resolver /etc/resolv.conf mostrará si el archivo se puede analizar correctamente.

AUTOR

Escrito por el equipo de ldns como ejemplo de uso de ldns.
