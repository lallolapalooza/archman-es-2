ldap_first_message(3)

Paquete: libldap

Licencias: custom

LDAP_FIRST_MESSAGE(3) Manual de funciones de biblioteca LDAP_FIRST_MESSAGE(3)

NOMBRE

ldap_first_message, ldap_next_message, ldap_count_messages - Iterar a través de mensajes en una cadena de resultados

BIBLIOTECA

OpenLDAP LDAP (libldap, -lldap)

SINOPSIS

#include <ldap.h>
int ldap_count_messages( LDAP *ld, LDAPMessage *result )
LDAPMessage *ldap_first_message( LDAP *ld, LDAPMessage *result )
LDAPMessage *ldap_next_message( LDAP *ld, LDAPMessage *message )

DESCRIPCIÓN

Estas rutinas se utilizan para iterar a través de los mensajes de una cadena de resultados recibida de ldap_result(3). Para operaciones de búsqueda, la cadena de resultados puede contener mensajes de referencia, entrada y resultado. La función ldap_msgtype(3) se puede utilizar para distinguir entre los diferentes tipos de mensajes.

La rutina ldap_first_message() se utiliza para recuperar el primer mensaje de una cadena de resultados. Toma el result tal como lo devuelve una llamada a ldap_result(3), ldap_search_s(3) o ldap_search_st(3) y devuelve un puntero al primer mensaje en la cadena de resultados.

Este puntero debe proporcionarse en una llamada posterior a ldap_next_message() para obtener el siguiente mensaje, cuyo resultado debe proporcionarse a la siguiente llamada a ldap_next_message(), etc. ldap_next_message() devolverá NULL cuando no haya más mensajes.

Estas funciones son útiles cuando se utilizan rutinas como ldap_parse_result(3) que solo operan en el primer resultado de la cadena.

Se puede obtener un recuento del número de mensajes en la cadena de resultados llamando a ldap_count_messages(). También se puede utilizar para contar el número de mensajes restantes en una cadena si se llama con un mensaje, entrada o referencia devuelto por ldap_first_message() , ldap_next_message() , ldap_first_entry(3), ldap_next_entry(3), ldap_first_reference(3), ldap_next_reference(3).

ERRORES

Si ocurre un error en ldap_first_message() o ldap_next_message(), se devuelve NULL. Si ocurre un error en ldap_count_messages(), se devuelve -1.

VER TAMBIÉN

ldap(3), ldap_search(3), ldap_result(3), ldap_parse_result(3), ldap_first_entry(3), ldap_first_reference(3)
