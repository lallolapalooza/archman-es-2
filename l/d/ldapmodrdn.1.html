ldapmodrdn(1)

Paquete: openldap

LDAPMODRDN(1) Manual de Comandos Generales LDAPMODRDN(1)

NOMBRE

ldapmodrdn - Herramienta para renombrar entradas LDAP

SINOPSIS

ldapmodrdn [-V[V]] [-d nivel_depuracion] [-n] [-v] [-r] [-s nuevo_superior] [-c] [-f archivo] [-M[M]] [-x] [-D dn_enlace] [-W] [-w contraseña] [-y archivopasswd] [-H uri_ldap] [-P {2|3}] [-e [!]ext[=param_ext]] [-E [!]ext[=param_ext]] [-o opcion[=param_opcion]] [-O propiedades-seguridad] [-I] [-Q] [-N] [-U id_autenticacion] [-R dominio] [-X autorizacion_id] [-Y mecanismo] [-Z[Z]] [dn rdn]

DESCRIPCIÓN

ldapmodrdn es una interfaz accesible desde la línea de comandos para la llamada a la biblioteca ldap_rename(3).

ldapmodrdn abre una conexión a un servidor LDAP, se enlaza y modifica el RDN de las entradas. La información de la entrada se lee de la entrada estándar, del archivo archivo mediante la opción -f, o del par de línea de comandos dn y rdn.

OPCIONES

-V[V]
Imprime información de la versión. Si se proporciona -VV, solo se imprime la información de la versión.
-d nivel_depuracion
Establece el nivel de depuración LDAP a nivel_depuracion. ldapmodrdn debe compilarse con LDAP_DEBUG definido para que esta opción tenga algún efecto.
-n
Muestra lo que se haría, pero sin cambiar realmente las entradas. Útil para depuración junto con -v.
-v
Utiliza el modo verboso, con muchos diagnósticos escritos en la salida estándar.
-r
Elimina los valores antiguos del RDN de la entrada. El valor predeterminado es mantener los valores antiguos.
-s nuevo_superior
Especifica un nuevo superior para la entrada. (Es decir, mueve la entrada objetivo y la convierte en hijo del nuevo superior). Esta opción no es compatible con LDAPv2.
-c
Modo de operación continua. Los errores se informan, pero ldapmodrdn continuará con las modificaciones. El valor predeterminado es salir después de informar un error.
-f archivo
Lee la información de modificación de la entrada del archivo en lugar de la entrada estándar o la línea de comandos.
-M[M]
Habilita el control Manage DSA IT. -MM hace que el control sea crítico.
-x
Utiliza autenticación simple en lugar de SASL.
-D dn_enlace
Utiliza el Distinguished Name (DN) dn_enlace para enlazar con el directorio LDAP. Para enlaces SASL, se espera que el servidor ignore este valor.
-W
Solicita autenticación simple. Se utiliza en lugar de especificar la contraseña en la línea de comandos.
-w contraseña
Utiliza contraseña como contraseña para la autenticación simple.
-y archivopasswd
Utiliza el contenido completo de archivopasswd como contraseña para la autenticación simple.
-H uri_ldap
Especifica URI(s) que hacen referencia a los servidores LDAP; solo se permiten los campos protocolo/host/puerto; se espera una lista de URIs, separadas por espacios en blanco o comas.
-P {2|3}
Especifica la versión del protocolo LDAP a utilizar.
-e [!]ext[=param_ext]
-E [!]ext[=param_ext]

Especifica extensiones generales con -e y extensiones de modrdn con -E. ´!´ indica criticidad.

Extensiones generales:

  [!]assert=<filtro>    (un filtro RFC 4515)
  !authzid=<id_autorizacion>    ("dn:<dn>" o "u:<usuario>")
  [!]bauthzid           (Control RFC 3829 id_autorizacion)
  [!]chaining[=<resolucion>[/<cont>]]
  [!]manageDSAit
  [!]noop
  ppolicy
  [!]postread[=<atributos>] (una lista de atributos separados por comas)
  [!]preread[=<atributos>]  (una lista de atributos separados por comas)
  [!]relax
  sessiontracking[=<nombre_usuario>]
  abandon,cancel,ignore (SIGINT envía abandon/cancel,
  o ignora la respuesta; si es crítico, no espera a SIGINT.
  no son realmente controles)

Extensiones de Modrdn:

  (ninguna)
-o opcion[=param_opcion]

Especifica cualquier opción de ldap.conf(5) o una de las siguientes:

  nettimeout=<tiempo_espera>  (en segundos, o "none" o "max")
  ldif_wrap=<ancho>     (en columnas, o "no" para no envolver)
-O propiedades-seguridad
Especifica propiedades de seguridad SASL.
-I
Habilita el modo interactivo SASL. Siempre solicita. El valor predeterminado es solicitar solo cuando sea necesario.
-Q
Habilita el modo silencioso SASL. Nunca solicita.
-N
No utiliza DNS inverso para canonizar el nombre de host SASL.
-U id_autenticacion
Especifica el ID de autenticación para el enlace SASL. La forma del ID depende del mecanismo SASL real utilizado.
-R dominio
Especifica el dominio del ID de autenticación para el enlace SASL. La forma del dominio depende del mecanismo SASL real utilizado.
-X autorizacion_id
Especifica el ID de autorización solicitado para el enlace SASL. autorizacion_id debe tener uno de los siguientes formatos: dn:<nombre_distinguido> o u:<nombre_de_usuario>
-Y mecanismo
Especifica el mecanismo SASL que se utilizará para la autenticación. Si no se especifica, el programa elegirá el mejor mecanismo que conozca el servidor.
-Z[Z]
Emite la operación extendida StartTLS (Transport Layer Security). Si utiliza -ZZ, el comando requerirá que la operación sea exitosa.

FORMATO DE ENTRADA

Si se proporcionan los argumentos de línea de comandos dn y rdn, rdn reemplazará el RDN de la entrada especificada por el DN, dn.

De lo contrario, el contenido de archivo (o la entrada estándar si no se proporciona la opción -f) debe consistir en una o más entradas.

    Nombre Distinguido (DN)
    Nombre Distinguido Relativo (RDN)

Se pueden usar una o más líneas en blanco para separar cada par DN/RDN.

EJEMPLO

Suponiendo que el archivo /tmp/entrymods existe y tiene el siguiente contenido:

    cn=Modificar Me,dc=example,dc=com
    cn=El Nuevo Yo

el comando:

    ldapmodrdn -r -f /tmp/entrymods

cambiará el RDN de la entrada "Modificar Me" de "Modificar Me" a "El Nuevo Yo" y se eliminará el cn antiguo, "Modificar Me".

DIAGNÓSTICOS

El estado de salida es 0 si no ocurren errores. Los errores resultan en un estado de salida distinto de cero y un mensaje de diagnóstico escrito en la salida de error estándar.
