ldap_first_attribute(3)

Paquete: libldap

Licencias: custom

LDAP_FIRST_ATTRIBUTE(3) Manual de funciones de la biblioteca LDAP_FIRST_ATTRIBUTE(3)

NOMBRE

ldap_first_attribute, ldap_next_attribute - recorrer los atributos de una entrada LDAP

LIBRERÍA

OpenLDAP LDAP (libldap, -lldap)

SINOPSIS

#include <ldap.h>
char *ldap_first_attribute(
	LDAP *ld, LDAPMessage *entry, BerElement **berptr )
char *ldap_next_attribute(
	LDAP *ld, LDAPMessage *entry, BerElement *ber )
int ldap_get_attribute_ber(
	LDAP *ld, LDAPMessage *entry, BerElement *ber,
	BerValue *attr, BerVarray *vals )

DESCRIPCIÓN

Las rutinas ldap_first_attribute(), ldap_next_attribute() y ldap_get_attribute_ber() se utilizan para recorrer los atributos de una entrada LDAP. ldap_first_attribute() toma una entry tal como la devuelve ldap_first_entry(3) o ldap_next_entry(3) y devuelve un puntero a una cadena de caracteres que contiene la primera descripción de atributo en la entrada. ldap_next_attribute() devuelve la siguiente descripción de atributo en la entrada.

También devuelve, en berptr, un puntero a un BerElement que ha asignado para realizar un seguimiento de su posición actual. Este puntero debe pasarse a llamadas posteriores a ldap_next_attribute() y se utiliza para recorrer efectivamente los atributos de la entrada. El llamador es el único responsable de liberar el BerElement apuntado por berptr cuando ya no sea necesario, llamando a ber_free(3). Al llamar a ber_free(3) en este caso, asegúrese de que el segundo argumento sea 0.

Los nombres de atributos devueltos son adecuados para incluirlos en una llamada a ldap_get_values(3) para recuperar los valores del atributo.

La rutina ldap_get_attribute_ber() permite iterar sobre todos los atributos in situ, sin asignar memoria para mantener el texto del nombre del atributo o sus valores, si se solicita. El caso de uso es similar a ldap_next_attribute(), excepto que el nombre del atributo se devuelve en attr y, si vals no es NULL, la lista de valores se almacena allí. Ambos apuntan al mensaje LDAP y solo son válidos mientras la entrada sea válida. El llamador sigue siendo responsable de liberar vals con ldap_memfree(3), si se utiliza.

ERRORES

Si ocurre un error, se devuelve NULL y el campo ld_errno en el parámetro ld se establece para indicar el error. Consulte ldap_error(3) para una descripción de los posibles códigos de error.

NOTAS

ldap_first_attribute() y ldap_next_attribute() devuelven memoria asignada dinámicamente que debe ser liberada por el llamador a través de ldap_memfree(3). Para ldap_get_attribute_ber(), solo el puntero vals real necesita ser liberado con ldap_memfree(3), otros datos se contabilizan como parte de ber.

VER TAMBIÉN

ldap(3), ldap_first_entry(3), ldap_get_values(3), ldap_error(3)
