NOMBRE

ldns-mx - mostrar el(los) registro(s) mx de un dominio

SINOPSIS

ldns-mx DOMINIO

DESCRIPCIÓN

ldns-mx se utiliza para mostrar información mx de un dominio.

OPCIONES

ldns-mx no tiene opciones.

AUTOR

Escrito por el equipo de ldns como ejemplo de uso de ldns.
