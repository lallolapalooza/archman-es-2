LDEXP(3P) Manual de Programador de POSIX LDEXP(3P)

PROLOG

Esta página del manual es parte del Manual de Programador de POSIX. La implementación de esta interfaz en Linux puede diferir (consulte la página del manual de Linux correspondiente para conocer los detalles del comportamiento en Linux), o la interfaz puede no estar implementada en Linux.

NOMBRE

ldexp, ldexpf, ldexpl — carga el exponente de un número de punto flotante

SINOPSIS

#include <math.h>
double ldexp(double x, int exp);
float ldexpf(float x, int exp);
long double ldexpl(long double x, int exp);

DESCRIPCIÓN

La funcionalidad descrita en esta página de referencia está alineada con el estándar ISO C. Cualquier conflicto entre los requisitos descritos aquí y el estándar ISO C es involuntario. Este volumen de POSIX.1‐2017 se remite al estándar ISO C.

Estas funciones calcularán la cantidad x * 2exp.

Una aplicación que desee verificar situaciones de error debe establecer errno a cero y llamar a feclearexcept(FE_ALL_EXCEPT) antes de llamar a estas funciones. Al regresar, si errno es distinto de cero o fetestexcept(FE_INVALID | FE_DIVBYZERO | FE_OVERFLOW | FE_UNDERFLOW) es distinto de cero, ha ocurrido un error.

VALOR DE RETORNO

Al completarse con éxito, estas funciones devolverán x multiplicado por 2, elevado a la potencia exp.

Si estas funciones causaran un desbordamiento, ocurrirá un error de rango y ldexp(), ldexpf() y ldexpl() devolverán ±HUGE_VAL, ±HUGE_VALF y ±HUGE_VALL (según el signo de x), respectivamente.

Si el valor correcto causara un subdesbordamiento, y no es representable, puede ocurrir un error de rango, y ldexp(), ldexpf() y ldexpl() devolverán 0.0, o (si no se admite el punto flotante IEC 60559) un valor definido por la implementación no mayor en magnitud que DBL_MIN, FLT_MIN y LDBL_MIN, respectivamente.

Si x es NaN, se devolverá un NaN.

Si x es ±0 o ±Inf, se devolverá x.

Si exp es 0, se devolverá x.

Si el valor correcto causara un subdesbordamiento, y es representable, puede ocurrir un error de rango y se devolverá el valor correcto.

ERRORES

Estas funciones fallarán si:

Error de rango
El resultado se desborda.

Si la expresión entera (math_errhandling & MATH_ERRNO) es distinta de cero, entonces errno se establecerá en [ERANGE]. Si la expresión entera (math_errhandling & MATH_ERREXCEPT) es distinta de cero, entonces se activará la excepción de punto flotante de desbordamiento.

Estas funciones pueden fallar si:

Error de rango
El resultado sufre un subdesbordamiento.

Si la expresión entera (math_errhandling & MATH_ERRNO) es distinta de cero, entonces errno se establecerá en [ERANGE]. Si la expresión entera (math_errhandling & MATH_ERREXCEPT) es distinta de cero, entonces se activará la excepción de punto flotante de subdesbordamiento.

USO DE LA APLICACIÓN

En caso de error, las expresiones (math_errhandling & MATH_ERRNO) y (math_errhandling & MATH_ERREXCEPT) son independientes entre sí, pero al menos una de ellas debe ser distinta de cero.
