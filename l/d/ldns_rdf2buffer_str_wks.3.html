NAME

ldns_rdf2buffer_str_wks - convert a buffer to a string representation of a DNS record

SYNOPSIS

#include <ldns/ldns.h>
ssize_t ldns_rdf2buffer_str_wks(char *buffer, size_t len, const ldns_rdf *rdf);

DESCRIPTION

The function ldns_rdf2buffer_str_wks converts a ldns_rdf into a buffer, to a string representation. This function does not add any trailing whitespace.

This function is identical to ldns_rdf2buffer_str except that it does not append any trailing whitespace.
