LDAPPASSWD(1) Manual de Comandos Generales LDAPPASSWD(1)

NOMBRE

ldappasswd - cambiar la contraseña de una entrada LDAP

SINOPSIS

ldappasswd [-V[V]] [-d nivel_debug] [-n] [-v] [-A] [-a contraseña_antigua] [-t archivo_contraseña_antigua] [-S] [-s contraseña_nueva] [-T archivo_contraseña_nueva] [-x] [-D dn_enlace] [-W] [-w contraseña] [-y archivo_contraseña] [-H uri_ldap] [-e [!]ext[=param_ext]] [-E [!]ext[=param_ext]] [-o opt[=param_opt]] [-O propiedades_seguridad] [-I] [-Q] [-N] [-U cid_autenticacion] [-R dominio] [-X zid_autenticacion] [-Y mecanismo] [-Z[Z]] [usuario]

DESCRIPCIÓN

ldappasswd es una herramienta para establecer la contraseña de un usuario LDAP. ldappasswd utiliza la operación extendida de Modificación de Contraseña (RFC 3062) de LDAPv3.

ldappasswd establece la contraseña asociada al usuario [o a un usuario especificado opcionalmente]. Si la nueva contraseña no se especifica en la línea de comandos y el usuario no habilita la solicitud, se le pedirá al servidor que genere una contraseña para el usuario.

ldappasswd no está diseñado ni pretende ser un reemplazo para passwd(1) y no debe instalarse como tal.

OPCIONES

-V[V]
Mostrar información de la versión. Si se proporciona -VV, solo se mostrará la información de la versión.
-d nivel_debug
Establecer el nivel de depuración LDAP a nivel_debug. ldappasswd debe compilarse con LDAP_DEBUG definido para que esta opción tenga algún efecto.
-n
No establecer la contraseña. (Puede ser útil cuando se usa junto con -v o -d)
-v
Aumentar la verbosidad de la salida. Se puede especificar varias veces.
-A
Solicitar la contraseña antigua. Esto se usa en lugar de especificar la contraseña en la línea de comandos.
-a contraseña_antigua
Establecer la contraseña antigua a contraseña_antigua.
-t archivo_contraseña_antigua
Establecer la contraseña antigua al contenido de archivo_contraseña_antigua.
-S
Solicitar la nueva contraseña. Esto se usa en lugar de especificar la contraseña en la línea de comandos.
-s contraseña_nueva
Establecer la nueva contraseña a contraseña_nueva.
-T archivo_contraseña_nueva
Establecer la nueva contraseña al contenido de archivo_contraseña_nueva.
-x
Usar autenticación simple en lugar de SASL.
-D dn_enlace
Usar el Nombre Distinguido dn_enlace para enlazar con el directorio LDAP. Para enlaces SASL, se espera que el servidor ignore este valor.
-W
Solicitar la contraseña de enlace. Esto se usa en lugar de especificar la contraseña en la línea de comandos.
-w contraseña
Usar contraseña como la contraseña para enlazar.
-y archivo_contraseña
Usar el contenido completo de archivo_contraseña como la contraseña para autenticación simple.
-H uri_ldap
Especificar URI(s) que se refieren al(los) servidor(es) ldap; solo se permiten los campos protocolo/host/puerto; se espera una lista de URI, separadas por espacios en blanco o comas.
-e [!]ext[=param_ext]
-E [!]ext[=param_ext]

Especificar extensiones generales con -e y extensiones de modificación de contraseña con -E. ´!´ indica criticidad.

Extensiones generales:

  [!]assert=<filtro>    (un filtro RFC 4515)
  !authzid=<authzid>    ("dn:<dn>" o "u:<usuario>")
  [!]bauthzid           (control authzid RFC 3829)
  [!]chaining[=<resolución>[/<cont>]]
  [!]manageDSAit
  [!]noop
  ppolicy
  [!]postread[=<attrs>] (una lista de atributos separada por comas)
  [!]preread[=<attrs>]  (una lista de atributos separada por comas)
  [!]relax
  sessiontracking[=<nombre_usuario>]
  abandon,cancel,ignore (SIGINT envía abandon/cancel,
  o ignora la respuesta; si es crítico, no espera a SIGINT.
  no son realmente controles)

Extensiones de Modificación de Contraseña:

  (ninguna)
-o opt[=param_opt]]

Especificar cualquier opción de ldap.conf(5) o una de las siguientes:

  nettimeout=<timeout>  (en segundos, o "none" o "max")
  ldif_wrap=<ancho>     (en columnas, o "no" para no envolver)
-O propiedades_seguridad
Especificar propiedades de seguridad SASL.
-I
Habilitar el modo Interactivo SASL. Siempre solicitar. Por defecto, solicitar solo cuando sea necesario.
-Q
Habilitar el modo Silencioso SASL. Nunca solicitar.
-N
No usar DNS inverso para canonizar el nombre de host SASL.
-U cid_autenticacion
Especificar el ID de autenticación para el enlace SASL. La forma del ID depende del mecanismo SASL real utilizado.
-R dominio
Especificar el dominio del ID de autenticación para el enlace SASL. La forma del dominio depende del mecanismo SASL real utilizado.
-X zid_autenticacion
Especificar el ID de autorización solicitado para el enlace SASL. zid_autenticacion debe ser uno de los siguientes formatos: dn:<nombre distinguido> o u:<nombre_de_usuario>.
-Y mecanismo
Especificar el mecanismo SASL a utilizar para la autenticación. Si no se especifica, el programa elegirá el mejor mecanismo que conozca el servidor.
-Z[Z]
Emitir la operación extendida StartTLS (Transport Layer Security). Si usa -ZZ, el comando requerirá que la operación sea exitosa

VER TAMBIÉN
