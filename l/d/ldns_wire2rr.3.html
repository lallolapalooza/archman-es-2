NOMBRE

ldns_wire2rr, ldns_wire2pkt, ldns_wire2rdf, ldns_wire2dname - convertir desde formato de cable a tipo de host

SINOPSIS

#include <stdint.h>
#include <stdbool.h>

#include <ldns/ldns.h>

ldns_status ldns_wire2rr(ldns_rr **rr, const uint8_t *wire, size_t max, size_t *pos, ldns_pkt_section section);

ldns_status ldns_wire2pkt(ldns_pkt **packet, const uint8_t *data, size_t len);

ldns_status ldns_wire2rdf(ldns_rr *rr, const uint8_t *wire, size_t max, size_t *pos);

ldns_status ldns_wire2dname(ldns_rdf **dname, const uint8_t *wire, size_t max, size_t *pos);

DESCRIPCIÓN

ldns_wire2rr() convierte los datos en el array de bytes uint8_t (en formato de cable) a un registro de recurso DNS. Esta función inicializará y asignará espacio de memoria para la estructura rr. La longitud de los datos de cable de este rr se suma al valor de *pos.

rr: puntero a la estructura para almacenar el valor rdata
wire: puntero al buffer con los datos
max: la longitud del buffer de datos (en bytes)
pos: la posición del rr en el buffer (es decir, el número de bytes desde el inicio del buffer)
section: la sección del paquete para la que está destinado el rr
Devuelve LDNS_STATUS_OK si todo tiene éxito, error en caso contrario

ldns_wire2pkt() convierte los datos en el array de bytes uint8_t (en formato de cable) a un paquete DNS. Esta función inicializará y asignará espacio de memoria para la estructura del paquete.

packet: puntero a la estructura para almacenar el paquete
data: puntero al buffer con los datos
len: la longitud del buffer de datos (en bytes)
Devuelve LDNS_STATUS_OK si todo tiene éxito, error en caso contrario

ldns_wire2rdf() convierte los datos en el array de bytes uint8_t (en formato de cable) a campos de datos DNS rdata, y los añade a la lista de rdfs del rr dado. Esta función inicializará y asignará espacio de memoria para las estructuras dname. La longitud de los datos de cable de estos rdfs se suma al valor de *pos.

Se leen todos los rdfs que pertenecen al RR; el rr no debe tener rdfs aún. Se devuelve un error si el formato no se puede analizar.

rr: puntero a la estructura ldns_rr para almacenar el valor rdata
wire: puntero al buffer con los datos
max: la longitud del buffer de datos (en bytes)
pos: la posición del rdf en el buffer (es decir, el número de bytes desde el inicio del buffer)
Devuelve LDNS_STATUS_OK si todo tiene éxito, error en caso contrario

ldns_wire2dname() convierte los datos en el array de bytes uint8_t (en formato de cable) a un campo rdata dname DNS. Esta función inicializará y asignará espacio de memoria para la estructura dname. La longitud de los datos de cable de este rdf se suma al valor de *pos.

dname: puntero a la estructura para almacenar el valor rdata
wire: puntero al buffer con los datos
max: la longitud del buffer de datos (en bytes)
pos: la posición del rdf en el buffer (es decir, el número de bytes desde el inicio del buffer)
Devuelve LDNS_STATUS_OK si todo tiene éxito, error en caso contrario
