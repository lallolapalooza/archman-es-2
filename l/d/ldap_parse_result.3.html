ldap_parse_result(3)

Paquete: libldap

Licencias: custom

LDAP_PARSE_RESULT(3) Manual de funciones de biblioteca LDAP_PARSE_RESULT(3)

NOMBRE

ldap_parse_result - Análisis de resultados

BIBLIOTECA

OpenLDAP LDAP (libldap, -lldap)

SINOPSIS

#include <ldap.h>
int ldap_parse_result( LDAP *ld, LDAPMessage *result,
	int *errcodep, char **matcheddnp, char **errmsgp,
	char ***referralsp, LDAPControl ***serverctrlsp,
	int freeit )
int ldap_parse_sasl_bind_result( LDAP *ld, LDAPMessage *result,
	struct berval **servercredp, int freeit )
int ldap_parse_extended_result( LDAP *ld, LDAPMessage *result,
	char **retoidp, struct berval **retdatap, int freeit )
int ldap_parse_intermediate( LDAP *ld, LDAPMessage *result,
	char **retoidp, struct berval **retdatap,
	LDAPControl ***serverctrlsp, int freeit )

DESCRIPCIÓN

Estas rutinas se utilizan para extraer información de un mensaje de resultado. Operarán sobre el primer mensaje de resultado en una cadena de resultados de búsqueda (saltando otros tipos de mensajes). Toman el result devuelto por una llamada a ldap_result(3), ldap_search_s(3) o ldap_search_st(3). Además de ldap_parse_result(), las rutinas ldap_parse_sasl_bind_result() y ldap_parse_extended_result() se utilizan para obtener toda la información de resultado de las operaciones de enlace y extendidas SASL. Para extraer información de respuestas intermedias, se puede usar ldap_parse_intermediate().

El parámetro errcodep se rellenará con el código de resultado del mensaje de resultado.

El servidor puede proporcionar una cadena de DN coincidente en el mensaje, lo que indica cuánto se reconoció un nombre en una solicitud. El parámetro matcheddnp se rellenará con esta cadena si se proporciona, de lo contrario será NULL. Si se devuelve una cadena, debe liberarse usando ldap_memfree(3).

El parámetro errmsgp se rellenará con el campo del mensaje de error del mensaje analizado. Esta cadena debe liberarse usando ldap_memfree(3).

El parámetro referralsp se rellenará con una matriz asignada de cadenas de referencia del mensaje analizado. Esta matriz debe liberarse usando ldap_memvfree(3). Si no se devolvieron referencias, *referralsp se establece en NULL.

El parámetro serverctrlsp se rellenará con una matriz asignada de controles copiados del mensaje analizado. La matriz debe liberarse usando ldap_controls_free(3). Si no se devolvieron controles, *serverctrlsp se establece en NULL.

El parámetro freeit determina si el mensaje analizado se libera o no después de la extracción. Cualquier valor distinto de cero hará que se libere el mensaje. La rutina ldap_msgfree(3) también se puede utilizar para liberar el mensaje más tarde.

Para los resultados de enlace SASL, el parámetro servercredp se rellenará con una estructura berval asignada que contiene las credenciales del servidor si están presentes. La estructura debe liberarse usando ber_bvfree(3).

Para los resultados extendidos y las respuestas intermedias, el parámetro retoidp se rellenará con la representación de texto OID punteada del nombre de la respuesta de la operación extendida. La cadena debe liberarse usando ldap_memfree(3). Si no se devolvió ningún OID, *retoidp se establece en NULL.

Para los resultados extendidos y las respuestas intermedias, el parámetro retdatap se rellenará con un puntero a una estructura berval que contiene los datos de la respuesta de la operación extendida. La estructura debe liberarse usando ber_bvfree(3). Si no se devolvieron datos, *retdatap se establece en NULL.

Para todos los parámetros de resultado anteriores, se pueden usar valores NULL en las llamadas para ignorar ciertos campos.

ERRORES

En caso de éxito, se devuelve LDAP_SUCCESS. De lo contrario, los valores de los parámetros de resultado no están definidos.

VER TAMBIÉN
