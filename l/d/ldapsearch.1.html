LDAPSEARCH(1) Manual de comandos generales LDAPSEARCH(1)

NOMBRE

ldapsearch - Herramienta de búsqueda LDAP

SINOPSIS

ldapsearch [-V[V]] [-d nivel_depuracion] [-n] [-v] [-c] [-u] [-t[t]] [-T ruta] [-F prefijo] [-A] [-L[L[L]]] [-S atributo] [-b base_busqueda] [-s {base|one|sub|children}] [-a {never|always|search|find}] [-l limite_tiempo] [-z limite_tamano] [-f archivo] [-M[M]] [-x] [-D dn_enlace] [-W] [-w contrasena] [-y archivopasswd] [-H uri_ldap] [-P {2|3}] [-e [!]ext[=parametro_ext]] [-E [!]ext[=parametro_ext]] [-o opt[=parametro_opt]] [-O propiedades-seguridad] [-I] [-Q] [-N] [-U cid_autenticacion] [-R dominio] [-X zid_autenticacion] [-Y mecanismo] [-Z[Z]] filtro [attrs...]

DESCRIPCION

ldapsearch es una interfaz accesible desde la línea de comandos para la llamada a la biblioteca ldap_search_ext(3).

ldapsearch abre una conexión a un servidor LDAP, se enlaza y realiza una búsqueda utilizando los parámetros especificados. El filtro debe conformarse a la representación de cadena para filtros de búsqueda según se define en RFC 4515. Si no se proporciona, se utiliza el filtro predeterminado, (objectClass=*).

Si ldapsearch encuentra una o más entradas, se devuelven los atributos especificados por attrs. Si se lista *, se devuelven todos los atributos de usuario. Si se lista +, se devuelven todos los atributos operacionales. Si no se listan attrs, se devuelven todos los atributos de usuario. Si solo se lista 1.1, no se devolverán atributos.

Los resultados de la búsqueda se muestran utilizando una versión extendida de LDIF. La opción -L controla el formato de la salida.

OPCIONES

-V[V]
Imprime información de la versión. Si se proporciona -VV, sale después de proporcionar la información de la versión. De lo contrario, procede con la búsqueda especificada.
-d nivel_depuracion
Establece el nivel de depuración LDAP a nivel_depuracion. ldapsearch debe compilarse con LDAP_DEBUG definido para que esta opción tenga algún efecto.
-n
Muestra lo que se haría, pero sin realizar realmente la búsqueda. Útil para depurar junto con -v.
-v
Ejecuta en modo detallado, con muchos diagnósticos escritos en la salida estándar.
-c
Modo de operación continua. Los errores se informan, pero ldapsearch continuará con las búsquedas. El valor predeterminado es salir después de informar un error. Solo útil junto con -f.
-u
Incluye el nombre amigable para el usuario (User Friendly Name) del Distinguished Name (DN) en la salida.
-t[t]
Un solo -t escribe los valores no imprimibles recuperados en un conjunto de archivos temporales. Esto es útil para tratar con valores que contienen datos no de caracteres como jpegPhoto o audio. Un segundo -t escribe todos los valores recuperados en archivos.
-T ruta
Escribe archivos temporales en el directorio especificado por ruta (predeterminado: directorio temporal predeterminado del sistema). Las variables de entorno TMPDIR, TMP o TEMP anularán la ruta predeterminada.
-F prefijo
Prefijo de URL para archivos temporales. El valor predeterminado es file://ruta donde ruta es el directorio temporal predeterminado del sistema o el valor especificado con -T.
-A
Recupera solo atributos (sin valores). Esto es útil cuando solo desea ver si un atributo está presente en una entrada y no está interesado en los valores específicos.
-L
Los resultados de la búsqueda se muestran en formato LDIF (LDAP Data Interchange Format) detallado en ldif(5). Un solo -L restringe la salida a LDIFv1.
Un segundo -L deshabilita los comentarios. Un tercer -L deshabilita la impresión de la versión LDIF. El valor predeterminado es usar una versión extendida de LDIF.
-S atributo
Ordena las entradas devueltas basándose en atributo. El valor predeterminado es no ordenar las entradas devueltas. Si atributo es una cadena de longitud cero (""), las entradas se ordenan por los componentes de su Distinguished Name. Consulte ldap_sort(3) para más detalles. Tenga en cuenta que ldapsearch normalmente imprime las entradas a medida que las recibe. El uso de la opción -S anula este comportamiento, provocando que todas las entradas se recuperen, luego se ordenen y luego se impriman.
-b base_busqueda
Utiliza base_busqueda como punto de partida para la búsqueda en lugar del valor predeterminado.
-s {base|one|sub|children}
Especifica el alcance de la búsqueda como uno de base, one, sub o children para especificar un objeto base, un nivel, un subárbol o una búsqueda de hijos. El valor predeterminado es sub. Nota: el alcance children requiere la extensión de funcionalidad subordinada de LDAPv3.
-a {never|always|search|find}
Especifica cómo se resuelven los alias. Debe ser uno de never, always, search o find para especificar que los alias nunca se resuelven, siempre se resuelven, se resuelven al buscar o se resuelven solo al localizar el objeto base para la búsqueda. El valor predeterminado es no resolver alias nunca.
-l limite_tiempo
espera como máximo limite_tiempo segundos para que una búsqueda se complete. Un límite de tiempo de 0 (cero) o none significa sin límite. Un límite de tiempo de max significa el entero máximo admisible por el protocolo. Un servidor puede imponer un límite de tiempo máximo que solo el usuario root puede anular.
-z limite_tamano
recupera como máximo limite_tamano entradas para una búsqueda. Un límite de tamaño de 0 (cero) o none significa sin límite. Un límite de tamaño de max significa el entero máximo admisible por el protocolo. Un servidor puede imponer un límite de tamaño máximo que solo el usuario root puede anular.
-f archivo
Lee una serie de líneas del archivo, realizando una búsqueda LDAP por cada línea. En este caso, el filtro dado en la línea de comandos se trata como un patrón donde la primera y única ocurrencia de %s se reemplaza con una línea del archivo. Cualquier otra ocurrencia del carácter % en el patrón se considerará un error. Donde se desee que el filtro de búsqueda incluya un carácter %, el carácter debe codificarse como \25 (ver RFC 4515). Si archivo es un solo carácter -, entonces las líneas se leen de la entrada estándar. ldapsearch saldrá cuando se devuelva el primer resultado de búsqueda no exitoso, a menos que se use -c.
-M[M]
Habilita el control manage DSA IT. -MM hace que el control sea crítico.
-x
Utiliza autenticación simple en lugar de SASL.
-D dn_enlace
Utiliza el Distinguished Name dn_enlace para enlazarse al directorio LDAP. Para enlaces SASL, se espera que el servidor ignore este valor.
-W
Solicita autenticación simple. Esto se usa en lugar de especificar la contraseña en la línea de comandos.
-w contrasena
Utiliza contrasena como la
