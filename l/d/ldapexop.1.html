LDAPEXOP(1) Manual de comandos generales LDAPEXOP(1)

NOMBRE

ldapexop - emite operaciones extendidas LDAP

SINOPSIS

ldapexop [-V[V]] [-d nivel_depuracion] [-n] [-v] [-f archivo] [-x] [-D binddn] [-W] [-w contraseña] [-y archivocontraseña] [-H URI] [-e [!]ext[=parametro_ext]] [-o opt[=parametro_opt]] [-O propiedades-seguridad] [-I] [-Q] [-N] [-U authcid] [-R dominio] [-X authzid] [-Y mech] [-Z[Z]] {oid | oid:datos | oid::datos_b64 | whoami | cancelar id_cancelar | refrescar DN [ttl]}

DESCRIPCIÓN

ldapexop emite la operación extendida LDAP especificada por oid o una de las palabras clave especiales whoami, cancelar, o refrescar.

Se pueden pasar datos adicionales para la operación extendida al servidor usando datos o codificados en base-64 como datos_b64 en el caso de oid, o usando los parámetros adicionales en el caso de las operaciones extendidas con nombre especial mencionadas anteriormente.

Tenga en cuenta que ldapexop se comporta de manera diferente para la misma operación extendida cuando se proporciona como un OID o como una operación con nombre especial:

Llamar a ldapexop con el OID de la operación extendida whoami (RFC 4532)

  ldapexop [<opciones>] 1.3.6.1.4.1.4203.1.11.3
produce 
  # respuesta de operación extendida
  data:: <datos de respuesta codificados en base64>
mientras que llamarla con la palabra clave whoami 
  ldapexop [<opciones>] whoami
resulta en 
  dn:<identidad del cliente>

OPCIONES

-V[V]
Muestra información de la versión. Si se proporciona-VV, solo se muestra la información de la versión.
-d nivel_depuracion
Establece el nivel de depuración LDAP a nivel_depuracion.
-n
Muestra lo que se haría pero no lo hace realmente. Útil para depurar en conjunción con -v.
-v
Ejecuta en modo verboso, con muchos diagnósticos escritos en la salida estándar.
-f archivo
Lee operaciones desde archivo.
-x
Usa autenticación simple en lugar de SASL.
-D binddn
Usa el Nombre Distinguido binddn para conectarse al directorio LDAP.
-W
Solicita autenticación simple. Se usa en lugar de especificar la contraseña en la línea de comandos.
-w contraseña
Usa contraseña como contraseña para la autenticación simple.
-y archivocontraseña
Usa el contenido completo de archivocontraseña como contraseña para la autenticación simple.
-H URI
Especifica URI(s) que hacen referencia a los servidor(es) ldap; solo se permiten los campos protocolo/host/puerto; se espera una lista de URI, separada por espacios en blanco o comas.
-e [!]ext[=parametro_ext]
Especifica extensiones generales. ´!´ indica criticidad. 
  [!]assert=<filtro>    (un filtro RFC 4515)
  !authzid=<authzid>    ("dn:<dn>" o "u:<usuario>")
  [!]bauthzid           (control authzid RFC 3829)
  [!]chaining[=<resolve>[/<cont>]]
  [!]manageDSAit
  [!]noop
  ppolicy
  [!]postread[=<attrs>] (una lista de atributos separada por comas)
  [!]preread[=<attrs>]  (una lista de atributos separada por comas)
  [!]relax
  sessiontracking[=<usuario>]
  abandon,cancel,ignore (SIGINT envía abandon/cancelar,
  o ignora la respuesta; si es crítico, no espera SIGINT.
  no son realmente controles)
-o opt[=parametro_opt]

Especifica cualquier opción de ldap.conf(5) o una de las siguientes:

  nettimeout=<timeout>  (en segundos, o "none" o "max")
  ldif_wrap=<ancho>     (en columnas, o "no" para no envolver)
-O propiedades-seguridad
Especifica propiedades de seguridad SASL.
-I
Habilita el modo interactivo SASL. Solicita siempre. Por defecto, solo solicita cuando es necesario.
-Q
Habilita el modo silencioso SASL. Nunca solicita.
-N
No usar DNS inverso para canonizar el nombre de host SASL.
-U authcid
Especifica el ID de autenticación para la conexión SASL. La forma del ID depende del mecanismo SASL real utilizado.
-R dominio
Especifica el dominio del ID de autenticación para la conexión SASL. La forma del dominio depende del mecanismo SASL real utilizado.
-X authzid
Especifica el ID de autorización solicitado para la conexión SASL. authzid debe tener uno de los siguientes formatos: dn:<nombre distinguido> o u:<nombre de usuario>
-Y mech
Especifica el mecanismo SASL que se utilizará para la autenticación. Sin esta opción, el programa elegirá el mejor mecanismo que conozca el servidor.
-Z[Z]
Emite la operación extendida StartTLS (Transport Layer Security). Proporcionarla dos veces (-ZZ) requerirá que la operación sea exitosa.

DIAGNÓSTICOS

El estado de salida es cero si no ocurren errores. Los errores resultan en un estado de salida distinto de cero y un mensaje de diagnóstico escrito en el error estándar.

ldapexop(1)

NAME

ldapexop - perform LDAP extended operations

SYNOPSIS

ldapexop [-v] [-d level] [-b binddn [-w passwd | -W] | -D binddn [-w passwd | -W]] [-H ldapuri] [-f conffile] [-s scope] [-L ldapschemaname] [-l ldapschemafile] [-a attrtype [-A value]] [-O oid [-o value]] [-N controloid [-n controlvalue]] [filter [attrs ...]]

DESCRIPTION

The ldapexop command is a command-line utility to perform LDAP extended operations. It can be used to invoke arbitrary extended operations or to perform common operations such as searching, adding, deleting, modifying, and comparing entries. The command allows you to specify the LDAP server, bind credentials, search scope, base DN, filter, and attributes.

OPTIONS

-v
Verbose output.
-d level
Debug level (0-255).
-b binddn
Distinguished name to bind with.
-w passwd
Password for bind DN.
-W
Prompt for password for bind DN.
-D binddn
Distinguished name to bind with (alternative to -b).
-H ldapuri
LDAP URI for the server (e.g., ldap://localhost:389).
-f conffile
Configuration file.
-s scope
Search scope (base, one, sub).
-L ldapschemaname
LDAP schema name.
-l ldapschemafile
LDAP schema file.
-a attrtype
Attribute type for search.
-A value
Attribute value for search.
-O oid
Object identifier for extended operation.
-o value
Value for extended operation.
-N controloid
Control OID for extended operation.
-n controlvalue
Control value for extended operation.
filter
Search filter.
attrs ...
Attributes to retrieve.

DIAGNOSTICS

Diagnostic messages will be sent to standard error.

ldapexop(1)

NOMBRE

ldapexop - realiza operaciones extendidas de LDAP

SINOPSIS

ldapexop [-v] [-d nivel] [-b dn_enlazar [-w contraseña | -W] | -D dn_enlazar [-w contraseña | -W]] [-H uri_ldap] [-f archivo_conf] [-s ámbito] [-L nombre_esquema_ldap] [-l archivo_esquema_ldap] [-a tipo_atributo [-A valor]] [-O oid [-o valor]] [-N oid_control [-n valor_control]] [filtro [attrs ...]]

DESCRIPCIÓN

El comando ldapexop es una utilidad de línea de comandos para realizar operaciones extendidas de LDAP. Se puede utilizar para invocar operaciones extendidas arbitrarias o para realizar operaciones comunes como buscar, agregar, eliminar, modificar y comparar entradas. El comando le permite especificar el servidor LDAP, las credenciales de enlace, el ámbito de búsqueda, el DN base, el filtro y los atributos.

OPCIONES

-v
Salida detallada.
-d nivel
Nivel de depuración (0-255).
-b dn_enlazar
Nombre distinguido para enlazar.
-w contraseña
Contraseña para el DN de enlace.
-W
Solicitar contraseña para el DN de enlace.
-D dn_enlazar
Nombre distinguido para enlazar (alternativa a -b).
-H uri_ldap
URI LDAP para el servidor (por ejemplo, ldap://localhost:389).
-f archivo_conf
Archivo de configuración.
-s ámbito
Ámbito de búsqueda (base, one, sub).
-L nombre_esquema_ldap
Nombre del esquema LDAP.
-l archivo_esquema_ldap
Archivo de esquema LDAP.
-a tipo_atributo
Tipo de atributo para la búsqueda.
-A valor
Valor del atributo para la búsqueda.
-O oid
Identificador de objeto para la operación extendida.
-o valor
Valor para la operación extendida.
-N oid_control
OID de control para la operación extendida.
-n valor_control
Valor de control para la operación extendida.
filtro
Filtro de búsqueda.
attrs ...
Atributos a recuperar.

DIAGNÓSTICOS

Los mensajes de diagnóstico se enviarán a la salida de error estándar.

VER TAMBIÉN
