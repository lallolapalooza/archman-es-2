LDAPURL(1) Manual de Comandos Generales LDAPURL(1)

NOMBRE

ldapurl - Herramienta de formato de URL LDAP

SINOPSIS

ldapurl [-a attrs] [-b searchbase] [-e [!]ext[=extparam]] [-E [!]ext[=extparam]] [-f filter] [-H ldapuri] [-h ldaphost] [-p ldapport] [-s {base|one|sub|children}] [-S scheme]

DESCRIPCIÓN

ldapurl es un comando que permite componer o descomponer URI LDAP.

Cuando se invoca con la opción -H, ldapurl extrae los componentes del argumento de opción ldapuri, descomprimiendo los caracteres escapados con hexadecimal según sea necesario. Básicamente, actúa como una interfaz para la llamada ldap_url_parse(3). De lo contrario, construye una URI LDAP basada en los componentes pasados con las opciones apropiadas, realizando la operación inversa. La opción -H es incompatible con las opciones -a, -b, -E, -f, -H, -h, -p, -S, y -s.

OPCIONES

-a attrs
Establece una lista de selectores de atributos separados por comas.
-b searchbase
Establece la base de búsqueda.
-e [!]ext[=extparam]

Especifica extensiones generales con -e ´!´ indica criticidad.

Extensiones generales:

  [!]assert=<filter>    (un Filtro RFC 4515)
  !authzid=<authzid>    ("dn:<dn>" o "u:<user>")
  [!]bauthzid           (Control RFC 3829 authzid)
  [!]chaining[=<resolve>[/<cont>]]
  [!]manageDSAit
  [!]noop
  ppolicy
  [!]postread[=<attrs>] (una lista de atributos separados por comas)
  [!]preread[=<attrs>]  (una lista de atributos separados por comas)
  [!]relax
  sessiontracking[=<username>]
  abandon,cancel,ignore (SIGINT envía abandon/cancel,
  o ignora la respuesta; si es crítico, no espera a SIGINT.
  realmente no son controles)
-E [!]ext[=extparam]
Establece extensiones de URL; incompatible con -H.
-f filter
Establece el filtro de URL. No se realiza ninguna comprobación particular de conformidad con los filtros LDAP RFC 4515, pero el valor se escapa hexadecimalmente según sea necesario.
-H ldapuri
Especifica la URI a descomponer.
-h ldaphost
Establece el host.
-p ldapport
Establece el puerto TCP.
-S scheme
Establece el esquema de la URL. Los valores predeterminados para otros campos, como ldapport, pueden depender del valor de scheme.
-s {base|one|sub|children}
Especifica el alcance de la búsqueda como base, one, sub o children para especificar un objeto base, un nivel, un subárbol o una búsqueda de hijos. El valor predeterminado es sub. Nota: el alcance children requiere la extensión de característica subordinada LDAPv3.

FORMATO DE SALIDA

Si se utiliza la opción -H, la ldapuri proporcionada se descompone en sus componentes, que se imprimen en la salida estándar en un formato similar a LDIF.

De lo contrario, la URI construida utilizando los valores pasados con las otras opciones se imprime en la salida estándar.

EJEMPLO

El siguiente comando:

    ldapurl -h ldap.example.com -b dc=example,dc=com -s sub -f "(cn=Some One)"

devuelve

    ldap://ldap.example.com:389/dc=example,dc=com??sub?(cn=Some%20One)

El comando:

    ldapurl -H ldap://ldap.example.com:389/dc=example,dc=com??sub?(cn=Some%20One)

devuelve

    scheme: ldap
    host: ldap.example.com
    port: 389
    dn: dc=example,dc=com
    scope: sub
    filter: (cn=Some One)

DIAGNÓSTICO

El estado de salida es cero si no ocurren errores. Los errores dan lugar a un estado de salida distinto de cero y a un mensaje de diagnóstico escrito en la salida de error estándar.
