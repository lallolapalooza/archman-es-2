ldns-verify-zone(1)

Paquete: ldns

Licencias: custom:BSD

ldns-verifyzone(1) Manual de Comandos Generales ldns-verifyzone(1)

NOMBRE

ldns-verify-zone - lee una zona firmada con DNSSEC y la verifica.

SINOPSIS

ldns-verify-zone ARCHIVO_ZONA

DESCRIPCIÓN

ldns-verify-zone lee un archivo de zona DNS y lo verifica.

Los registros de recursos RRSIG se verifican con el conjunto DNSKEY en el ápice de la zona.

Cada nombre se verifica para NSEC(3), si procede.

Si hay registros de recursos ZONEMD presentes, uno de ellos debe coincidir con el contenido de la zona.

OPCIONES

-h
Muestra el uso y sale.
-a
Solo ápice, verifica solo el ápice de la zona.
-e período
Las firmas no pueden expirar dentro de este período. Por defecto no se usa período.
-i período
Las firmas deben haber estado válidas al menos durante este tiempo. Por defecto, las firmas solo deben ser válidas ahora.
-k archivo
Un archivo que contiene una clave DNSKEY o un registro DS confiable. Esta opción puede darse más de una vez.

Alternativamente, si no se especifica -k, y existe una clave de confianza predeterminada (/etc/trusted-key.key) que contiene un registro DNSKEY o DS válido, se utilizará como clave de confianza.

-p [0-100]
Verifica solo este porcentaje de la zona. Los nombres a verificar se determinan aleatoriamente. Por defecto es 100.
-S
Sigue la(s) firma(s) hasta una clave conocida. Se puede acceder a la red para validar las DNSKEYs de la zona. (implica -k)
-t AAAAMMDDhhmmss | [+|-]desfase
Establece la hora de validación ya sea por un valor de hora absoluto o como un desfase en segundos desde la hora actual.
-v
Muestra la versión y sale.
-V número
Establece el nivel de verbosidad (por defecto 3):


0: Silencioso.
1: Imprime el resultado y cualquier error.
2: Igual que 1 por ahora.
3: Imprime el resultado, cualquier error y los nombres que se
están verificando.
4: Igual que 3 por ahora.
5: Imprime la zona después de haberla leído, el resultado,
cualquier error y los nombres que se están verificando.

-Z
Requiere la presencia de un registro ZONEMD válido. Cuando se da una vez, esta opción permitirá verificar solo el registro ZONEMD de una zona sin firmar. Cuando se da más de una vez, la zona también debe estar firmada correctamente con DNSSEC.
-ZZZ
Cuando se da tres veces la opción -Z, el registro ZONEMD a verificar se considera "desacoplado" y no necesita tener firmas válidas.

Los períodos se dan en formato de duración ISO 8601:

P[n]Y[n]M[n]DT[n]H[n]M[n]S

Si no se proporciona archivo, se lee la entrada estándar.

ARCHIVOS

/etc/trusted-key.key
El archivo del que se cargan las claves confiables para el seguimiento de firmas, cuando no se proporciona la opción -k.
