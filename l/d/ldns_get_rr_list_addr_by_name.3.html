ldns_get_rr_list_addr_by_name(3)

Paquete: ldns

Licencias: custom:BSD

ldns(3) Manual de funciones de biblioteca ldns(3)

NOMBRE

ldns_get_rr_list_addr_by_name, ldns_get_rr_list_name_by_addr - obtener direcciones por nombre o nombres por dirección

SINOPSIS

#include <stdint.h>
#include <stdbool.h>

#include <ldns/ldns.h>

ldns_rr_list* ldns_get_rr_list_addr_by_name(ldns_resolver *r, const ldns_rdf *name, ldns_rr_class c, uint16_t flags);

ldns_rr_list* ldns_get_rr_list_name_by_addr(ldns_resolver *r, const ldns_rdf *addr, ldns_rr_class c, uint16_t flags);

DESCRIPCIÓN

ldns_get_rr_list_addr_by_name() Preguntar al resolvedor por el nombre y devolver todos los registros de dirección
r: el resolvedor a usar
name: el nombre a buscar
c: la clase a usar
flags: dar algunas banderas opcionales a la consulta

ldns_get_rr_list_name_by_addr() preguntar al resolvedor por la dirección y devolver el nombre
r: el resolvedor a usar
addr: la dirección a buscar
c: la clase a usar
flags: dar algunas banderas opcionales a la consulta
