ldns-keyfetcher(1) Manual de comandos generales ldns-keyfetcher(1)

NOMBRE

ldns-keyfetcher - recupera las DNSSEC DNSKEY de una zona

SINOPSIS

ldns-keyfetcher [ OPCIONES ] DOMINIO

DESCRIPCIÓN

ldns-keyfetcher se utiliza para recuperar las DNSKEY de una zona.

Primero encuentra todos los servidores de nombres autoritativos de la zona rastreándola desde la raíz hacia abajo. Luego se consulta a todos los servidores de nombres autoritativos (usando TCP) para obtener el conjunto de registros RR DNSKEY del ápice de la zona. Si los resultados son todos iguales, se imprime el conjunto de registros de claves.

OPCIONES

-4 Solo usar IPv4

-6 Solo usar IPv6

-h Mostrar texto de ayuda y salir

-i Modo inseguro; solo habrá una consulta para las DNSKEYS. No habrá comprobación cruzada de todos los servidores de nombres autoritativos.

-v nivel de verbosidad

Establece el nivel de verbosidad. Los siguientes niveles están disponibles:


0: predeterminado, solo imprime el conjunto de registros RR DNSKEY encontrado, o un error en caso de fallo.
1: Muestra los servidores de nombres que se consultan
2: Muestra más información sobre lo que se comprueba
3: Muestra los resultados intermedios (conjuntos de registros de autoridad y dnskey)
4: Imprime los paquetes de respuesta que se devuelven

-r archivo

Usa el archivo como archivo de pistas raíz, debe contener registros A en formato de presentación. El valor predeterminado es /etc/named.root. Puede obtener este archivo de http://www.internic.net/zones/named.root.

-s No imprimir las claves en stdout, sino almacenarlas en archivos.

Los nombres de archivo tendrán el formato K<archivo>.+<alg>.+<keytag>.key
