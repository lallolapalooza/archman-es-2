DESCRIPCIÓN

ldns_buffer
implementación de buffers para facilitar operaciones

Los ldns_buffers pueden contener información arbitraria, por octeto. Puedes escribir
al final actual de un buffer, leer desde la posición actual y
acceder a cualquier dato dentro de él.

Un ejemplo de uso de buffers se encuentra en el código fuente de \ref host2str.c
struct ldns_struct_buffer
{
La posición actual usada para leer/escribir:
size_t _position;

El límite de lectura/escritura:
size_t _limit;

La cantidad de datos que el buffer puede contener:
size_t _capacity;

Los datos contenidos en el buffer:
uint8_t *_data;

Si el buffer es fijo, no se puede redimensionar:
unsigned _fixed : 1;

/** El estado actual del buffer. Si escribir en el buffer falla por
* cualquier motivo, este valor se cambia. De esta forma, puedes realizar
* múltiples escrituras en secuencia y comprobar el éxito después. */
ldns_status _status;
};
typedef struct ldns_struct_buffer ldns_buffer;

ldns_buffer_new() crea un nuevo buffer con la capacidad especificada.

capacity: el tamaño (en bytes) a asignar para el buffer
Devuelve el buffer creado

ldns_buffer_new_frm_data() crea un buffer con los datos especificados. Los datos SON copiados y se realizan asignaciones de MEMORIA. El buffer no es fijo y se puede redimensionar usando buffer_reserve().

buffer: puntero al buffer donde se colocarán los datos
data: los datos a encapsular en el buffer
size: el tamaño de los datos

ldns_buffer_clear() limpia el buffer y lo prepara para escribir. El límite del buffer se establece a la capacidad y la posición a 0.
buffer: el buffer a limpiar

ldns_buffer_printf() imprime en el buffer, aumentando la capacidad si es necesario usando buffer_reserve(). La posición del buffer se establece al '\\0' terminador. Devuelve el número de caracteres escritos (sin incluir el '\\0' terminador) o -1 en caso de fallo.

ldns_buffer_free() libera el buffer.
*buffer: el buffer a liberar
Devuelve void

ldns_buffer_copy() Copia el contenido del buffer 'from' al buffer 'result' y luego voltea el buffer 'result'. Los datos se truncarán silenciosamente si el buffer 'result' es demasiado pequeño.
*result: buffer resultante al que se copia.
*from: qué copiar a result.

ldns_buffer_export() Hace que el buffer sea fijo y devuelve un puntero a los datos. El llamador es responsable de liberar el resultado.
*buffer: el buffer a exportar
Devuelve void

ldns_buffer_export2str() Exporta y devuelve los datos en el buffer como una cadena char * terminada en nulo. La cadena devuelta debe ser liberada por el llamador. El buffer debe estar en modo de escritura y por lo tanto no debe haber sido volteado. El buffer se fija después de que esta función retorna.

buffer: buffer que contiene datos de tipo char *
Devuelve datos char * terminados en nulo, o NULL en caso de error

ldns_buffer2str() Devuelve una copia de los datos en el buffer como una cadena char * terminada en nulo. La cadena devuelta debe ser liberada por el llamador. El buffer debe estar en modo de escritura y por lo tanto no debe haber sido volteado.

buffer: buffer que contiene datos de tipo char *
Devuelve datos char * terminados en nulo, o NULL en caso de error
