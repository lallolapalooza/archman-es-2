ldns_dnssec_rrsets_new, ldns_dnssec_rrsets_free, ldns_dnssec_rrsets_type, ldns_dnssec_rrsets_set_type, ldns_dnssec_rrsets_add_rr, ldns_dnssec_rrsets_print - funciones para ldns_dnssec_rrsets

#include <stdint.h>
#include <stdbool.h>

#include <ldns/ldns.h>

void ldns_dnssec_rrsets_free(ldns_dnssec_rrsets *rrsets);

DESCRIPCIÓN

ldns_dnssec_rrsets_new() Crea una nueva lista (entrada) de RRsets
Devuelve la estructura recién asignada

ldns_dnssec_rrsets_free() Libera la lista de rrsets y sus rrs, pero *no* los registros ldns_rr en los sets

rrsets: la estructura de datos a liberar

ldns_dnssec_rrsets_type() Devuelve el tipo de rr del rrset (que es la cabeza de la lista dada)

rrsets: el rrset del que obtener el tipo
Devuelve el tipo de rr

ldns_dnssec_rrsets_set_type() Establece el tipo de RR del rrset (que es la cabeza de la lista dada)

rrsets: el rrset al que establecer el tipo
type: el tipo a establecer
Devuelve LDNS_STATUS_OK si la operación es exitosa

ldns_dnssec_rrsets_add_rr() Añade un ldns_rr al RRset correspondiente en la lista dada de RRsets. Si no está presente, lo añade como un nuevo RRset con 1 registro.

rrsets: la lista de rrsets a la que añadir el RR
rr: el rr a añadir a la lista de rrsets
Devuelve LDNS_STATUS_OK si la operación es exitosa

ldns_dnssec_rrsets_print() Imprime la lista dada de rrsets en el descriptor de archivo proporcionado

out: el descriptor de archivo en el que imprimir
rrsets: la lista de RRsets a imprimir
follow: si se establece en falso, solo imprime el primer RRset
