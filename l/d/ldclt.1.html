LDCLT(1) Manual de Comandos Generales LDCLT(1)

NOMBRE

ldclt - programa de prueba de carga para LDAP

SINOPSIS

ldclt [-qQvV] [-E <errores máximos>] [-b <DN base>] [-h <host>] [-p <puerto>] [-t <tiempo de espera>] [-D <DN de enlace>] [-w <contraseña>] [-o <opción SASL>] [-e <parámetros de ejecución>] [-a <pendientes máximos>] [-n <número de hilos>] [-i <número de veces>] [-N <número de muestras>] [-I <número de error>] [-T <total>] [-r <bajo> -R <alto>] [-f <filtro>] [-s <ámbito>] [-S <consumidor>] [-P<puerto del proveedor>] [-W <segundos de espera>] [-Z <archivo de certificado>]

DESCRIPCIÓN

Esta herramienta es un cliente LDAP enfocado en validar la fiabilidad del producto bajo una amplia variedad de condiciones de estrés.

OPCIONES

Las opciones válidas son:

-a
Modo asíncrono, con operaciones pendientes máximas.
-b
Proporciona el DN base a utilizar. Por defecto "dc=example,dc=com".
-D
DN de enlace. Ver -w
-E
Errores máximos permitidos. Por defecto 1000.
-f
Filtro para búsquedas.
-h
Host al que conectarse. Por defecto "localhost".
-H
URL de Ldap a la que conectarse. Ejemplo: ldap://localhost:389. Esto tiene precedencia sobre -h y -p.
-i
Número de veces que se permite la inactividad. Por defecto 3 (30 segundos)
-I
Ignorar errores (ver -E). Por defecto ninguno.
-n
Número de hilos. Por defecto 10.
-N
Número de muestras (10 segundos cada una). Por defecto infinito.
-o
Opción SASL.
-p
Puerto del servidor. Por defecto 389.
-P
Puerto del proveedor (para verificar replicación). Por defecto 16000.
-q
Modo silencioso. Ver opción -I.
-Q
Modo súper silencioso.
-r
Valor bajo del rango.
-R
Valor alto del rango.
-s
Ámbito. Puede ser base, subtree (subárbol) o one (uno). Por defecto subtree.
-S
Consumidor a verificar.
-t
Tiempo de espera de las operaciones LDAP. Por defecto 30 segundos.
-T
Número total de operaciones por hilo. Por defecto infinito.
-v
Verborrea.
-V
Mucha verborrea.
-w
Contraseña de enlace. Ver -D.
-W
Espera entre dos operaciones. Por defecto 0 segundos.
-Z
archivo de certificado. Activa SSL y usa archivo de certificado como base de datos de certificados
-e
Parámetros de ejecución:
add entradas de ldap_add().
append entradas al archivo ldif generado.
ascii usa cadenas de 7 bits ascii.
attreplace=nombre:máscara reemplaza el atributo de una entrada existente.
attrlist=nombre:nombre:nombre especifica la lista de atributos a recuperar.
attrsonly=0|1 parámetro de ldap_search(). Establece 0 para leer valores.
bindeach ldap_bind() para cada operación.
bindonly solo enlaza/desenlaza, no se realiza ninguna otra operación.
close cerrará() el descriptor de archivo, en lugar de ldap_unbind().
cltcertname=nombre nombre del certificado de cliente SSL
commoncounter todos los hilos comparten el mismo contador.
counteach cuenta cada operación, no solo las exitosas.
delete entradas de ldap_delete().
dontsleeponserverdown se ejecutará muy rápido si el servidor está caído.
emailPerson objectclass=emailPerson (solo con -e add).
esearch búsqueda exacta.
genldif=nombre de archivo genera un archivo ldif.
imagesdir=ruta especifica dónde están las imágenes.
incr valores incrementales.
inetOrgPerson objectclass=inetOrgPerson (solo con -e add).
keydbfile=archivo nombre del archivo de la base de datos de claves.
keydbpin=contraseña contraseña para acceder a la base de datos de claves.
noglobalstats no imprime estadísticas globales periódicas.
noloop no repite los números incrementales.
object=archivo construye un objeto a partir de un archivo de entrada.
person objectclass=person (solo con -e add).
random filtros aleatorios, etc.
randomattrlist=nombre:nombre:nombre selección aleatoria de atributos de la lista.
randombase DN base aleatorio.
randombaselow=valor valor bajo para el generador aleatorio.
randombasehigh=valor valor alto para el generador aleatorio.
randombinddn DN de enlace aleatorio.
randombinddnfromfile=archivo recupera el DN y la contraseña de enlace de un archivo.
randombinddnlow=valor valor bajo para el generador aleatorio.
randombinddnhigh=valor valor alto para el generador aleatorio.
rdn=nombreattr:valor alternativa para -f.
referral=on|off|rebind cambia el comportamiento de referencia.
scalab01 activa el escenario scalab01.
scalab01_cnxduration duración máxima de la conexión.
scalab01_maxcnxnb tamaño del pool de módems.
scalab01_wait sleep() entre 2 intentos de conexión.
smoothshutdown el hilo principal espera hasta que los hilos trabajadores salgan.
string crea cadenas aleatorias en lugar de números aleatorios.
v2 ldap v2.
withnewparent renombra con el nuevo padre especificado como argumento.
randomauthid Authid SASL aleatorio.
randomauthidlow=valor valor bajo para Authid SASL aleatorio.
randomauthidhigh=valor valor alto para Authid SASL aleatorio.

EJEMPLOS

Para poblar una base de datos con 1000 objetos de usuario, crea un archivo template.ldif que contenga:

objectClass: top
objectclass: person
objectClass: organizationalPerson
objectClass: inetorgperson
objectClass: posixAccount
objectClass: shadowAccount
sn: user[A]
cn: user[A]
givenName: user[A]
description: description[A]
userPassword: password[A]
mail: user[A]@example.com
uidNumber: 1[A]
gidNumber: 1[A]
shadowMin: 0
shadowMax: 99999
shadowInactive: 30
shadowWarning: 7
homeDirectory: /home/uid[A]

Esto se puede cargar en la base de datos utilizando:

ldclt -h localhost -p 389 -D "cn=Directory Manager" -w password -b "ou=people,dc=example,dc=com" -I 68 -e add,commoncounter -e "object=/tmp/template.ldif,rdn=uid:user[A=INCRNNOLOOP(0;999;4)]"

Usando estos usuarios creados, puedes probar el enlace a las cuentas con:

ldclt -h localhost -p 389 -e bindeach,bindonly -D uid=user0XXX,dc=example,dc=com -w password0XXX -e randombinddn,randombinddnlow=0,randombinddnhigh=0999 -e esearch -f "(&(objectClass=posixAccount)(uid=user*)(uidNumber=*)(gidNumber=*))"

NAME

ldclt - ldap connection classifier

SYNOPSIS

ldclt [options]

DESCRIPTION

ldclt is a tool that connects to a LDAP server and collects data about its performance by measuring the connection time. This tool is useful for testing and monitoring the performance of LDAP servers.

OPTIONS

This utility recognizes the following options:

-D binddn
The distinguished name to bind to the LDAP server.
-w password
The password for the bind DN.
-h host
The hostname or IP address of the LDAP server.
-p port
The port number of the LDAP server.
-b basedn
The base DN for the search.
-n number
The number of connections to test.
-t time
The timeout for each connection attempt.

EXAMPLES

Connect to an LDAP server on host ldap.example.com on port 389, using bind DN cn=admin,dc=example,dc=com with password secret, and perform 100 connection tests with a timeout of 5 seconds:

        ldclt -h ldap.example.com -p 389 -D "cn=admin,dc=example,dc=com" -w secret -n 100 -t 5
