LDBMODIFY(1) Herramientas de administración del sistema LDBMODIFY(1)

NOMBRE

ldbmodify - Modificar registros en una base de datos LDB

SINOPSIS

ldbmodify [-H URL-LDB] [archivo-ldif]

DESCRIPCIÓN

ldbmodify cambia, añade y elimina registros en una base de datos LDB. Los cambios que deben hacerse en la base de datos LDB se leen del archivo LDIF especificado. Si se especifica - como nombre de archivo, la entrada se lee desde la entrada estándar.

Por ahora, consulte ldapmodify(1) para obtener detalles sobre el formato del archivo LDIF.

OPCIONES

-H <url-ldb>

URL LDB a la que conectarse. Consulte ldb(3) para obtener detalles.

AMBIENTE

LDB_URL

URL LDB a la que conectarse (puede ser anulada usando la opción de línea de comandos -H).

VERSIÓN
