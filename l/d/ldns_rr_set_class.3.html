ldns_rr_set_class(3)

Paquete: ldns

Licencias: custom:BSD

ldns(3) Manual de funciones de biblioteca ldns(3)

NOMBRE

ldns_rr_set_owner, ldns_rr_set_ttl, ldns_rr_set_type, ldns_rr_set_rd_count, ldns_rr_set_class, ldns_rr_set_rdf - establecer atributos de ldns_rr

SINOPSIS

#include <stdint.h>
#include <stdbool.h>

#include <ldns/ldns.h>

void ldns_rr_set_owner(ldns_rr *rr, ldns_rdf *owner);

void ldns_rr_set_ttl(ldns_rr *rr, uint32_t ttl);

void ldns_rr_set_type(ldns_rr *rr, ldns_rr_type rr_type);

void ldns_rr_set_rd_count(ldns_rr *rr, size_t count);

void ldns_rr_set_class(ldns_rr *rr, ldns_rr_class rr_class);

ldns_rdf* ldns_rr_set_rdf(ldns_rr *rr, const ldns_rdf *f, size_t position);

DESCRIPCIÓN

ldns_rr_set_owner() establece el propietario en la estructura rr.
*rr: rr a operar
*owner: establecer a este propietario
Devuelve void

ldns_rr_set_ttl() establece el ttl en la estructura rr.
*rr: rr a operar
ttl: establecer a este ttl
Devuelve void

ldns_rr_set_type() establece el tipo en el rr.
*rr: rr a operar
rr_type: establecer a este tipo
Devuelve void

ldns_rr_set_rd_count() establece el rd_count en el rr.
*rr: rr a operar
count: establecer a este conteo
Devuelve void

ldns_rr_set_class() establece la clase en el rr.
*rr: rr a operar
rr_class: establecer a esta clase
Devuelve void

ldns_rr_set_rdf() establece un miembro rdf, se establecerá en la posición dada. El valor antiguo se devuelve, como un pop.
*rr: el rr a operar
*f: el rdf a establecer
position: la posición para establecer el rdf
Devuelve el valor antiguo en el rr, NULL en caso de fallo
