DESCRIPCIÓN

ldns_dnssec_trust_tree_new() Crea una nueva estructura dnssec_trust_tree (vacía).

Devuelve ldns_dnssec_trust_tree *

ldns_dnssec_trust_tree_free() Libera la dnssec_trust_tree recursivamente.

No hay una liberación profunda; todos los datos en el árbol de confianza consisten en punteros a una cadena de datos (data_chain).

árbol: El árbol a liberar.

ldns_dnssec_trust_tree_depth() Devuelve la profundidad del árbol de confianza.

árbol: árbol para calcular la profundidad
Devuelve la profundidad del árbol.

ldns_dnssec_derive_trust_tree() Genera un dnssec_trust_tree para el rr dado a partir de la cadena de datos dada.

Esto no clona los datos reales; no liberes la cadena de datos antes de terminar con este árbol.

*cadena_datos: La cadena de la que derivar el árbol de confianza.
*rr: El RR sobre el que tratará este árbol.
Devuelve ldns_dnssec_trust_tree *

ldns_dnssec_trust_tree_contains_keys() Devuelve OK si hay una ruta de confianza en el árbol hacia uno de los RR DNSKEY o DS de la lista dada.

\param *árbol El árbol de confianza a buscar. \param *claves Una ldns_rr_list de RRs DNSKEY y DS para buscar.

Devuelve LDNS_STATUS_OK si hay una ruta de confianza hacia una de las claves, o el *primer* error encontrado si no hubo rutas.

ldns_dnssec_trust_tree_print() Imprime la estructura dnssec_trust_tree al flujo de archivo dado.

Si el estado de un enlace no es LDNS_STATUS_OK; se imprimen también el estado y las firmas relevantes.

*salida: El flujo de archivo al que imprimir.
árbol: El árbol de confianza a imprimir.
pestañas: Añade pestañas*2 espacios al principio de cada línea.
extendido: Si es verdadero, añade pequeñas líneas explicativas a la salida.

ldns_dnssec_trust_tree_print_sm()

ldns_dnssec_trust_tree_add_parent() Añade un árbol de confianza como padre para el árbol de confianza dado.

*árbol: El árbol al que añadir el padre.
*padre: El árbol padre a añadir.
*firma_padre: La RRSIG relevante para esta conexión padre/hijo.
estado_padre: El estado DNSSEC para este padre, hijo y RRSIG.
Devuelve LDNS_STATUS_OK si la adición tiene éxito, error en caso contrario.

ldns_dnssec_derive_trust_tree_normal_rrset() Subfunción para derive_trust_tree que se utiliza para un rrset 'normal'.

nuevo_árbol: El árbol de confianza que estamos construyendo.
cadena_datos: La cadena de datos que contiene los datos para el árbol de confianza.
rr_firma_actual: La firma actualmente relevante.

ldns_dnssec_derive_trust_tree_dnskey_rrset() Subfunción para derive_trust_tree que se utiliza para rrsets DNSKEY.

nuevo_árbol: El árbol de confianza que estamos construyendo.
cadena_datos: La cadena de datos que contiene los datos para el árbol de confianza.
rr_actual: El RR DNSKEY actualmente relevante.
rr_firma_actual: La firma actualmente relevante.

ldns_dnssec_derive_trust_tree_ds_rrset() Subfunción para derive_trust_tree que se utiliza para rrsets DS.

nuevo_árbol: El árbol de confianza que estamos construyendo.
cadena_datos: La cadena de datos que contiene los datos para el árbol de confianza.
rr_actual: El RR DS actualmente relevante.

ldns_dnssec_derive_trust_tree_no_sig() Subfunción para derive_trust_tree que se utiliza cuando no hay firmas.

nuevo_árbol: El árbol de confianza que estamos construyendo.
cadena_datos: La cadena de datos que contiene los datos para el árbol de confianza.
