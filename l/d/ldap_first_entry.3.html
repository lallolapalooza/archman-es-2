ldap_first_entry(3)

Paquete: libldap

Licencias: custom

LDAP_FIRST_ENTRY(3) Manual de funciones de biblioteca LDAP_FIRST_ENTRY(3)

NOMBRE

ldap_first_entry, ldap_next_entry, ldap_count_entries - Rutinas de conteo y análisis de entradas de resultados LDAP

BIBLIOTECA

OpenLDAP LDAP (libldap, -lldap)

SINOPSIS

#include <ldap.h>
int ldap_count_entries( LDAP *ld, LDAPMessage *result )
LDAPMessage *ldap_first_entry( LDAP *ld, LDAPMessage *result )
LDAPMessage *ldap_next_entry( LDAP *ld, LDAPMessage *entry )

DESCRIPCIÓN

Estas rutinas se utilizan para analizar los resultados recibidos de ldap_result(3) o las rutinas de operación de búsqueda LDAP sincrónica ldap_search_s(3) y ldap_search_st(3).

La rutina ldap_first_entry() se utiliza para recuperar la primera entrada en una cadena de resultados de búsqueda. Toma el result tal como lo devuelve una llamada a ldap_result(3) o ldap_search_s(3) o ldap_search_st(3) y devuelve un puntero a la primera entrada del resultado.

Este puntero debe proporcionarse en una llamada posterior a ldap_next_entry() para obtener la siguiente entrada, cuyo resultado debe proporcionarse a la siguiente llamada a ldap_next_entry(), etc. ldap_next_entry() devolverá NULL cuando no haya más entradas. Las entradas devueltas de estas llamadas se utilizan en llamadas a las rutinas descritas en ldap_get_dn(3), ldap_first_attribute(3), ldap_get_values(3), etc.

Se puede obtener un recuento del número de entradas en el resultado de la búsqueda llamando a ldap_count_entries().

ERRORES

Si ocurre un error en ldap_first_entry() o ldap_next_entry(), se devuelve NULL y el campo ld_errno en el parámetro ld se establece para indicar el error. Si ocurre un error en ldap_count_entries(), se devuelve -1 y ld_errno se establece adecuadamente. Consulte ldap_error(3) para obtener una descripción de los posibles códigos de error.

VER TAMBIÉN

ldap(3), ldap_result(3), ldap_search(3), ldap_first_attribute(3), ldap_get_values(3), ldap_get_dn(3)
