LDAPDELETE(1) Manual de comandos generales LDAPDELETE(1)

NOMBRE

ldapdelete - Herramienta para eliminar entradas LDAP

SINOPSIS

ldapdelete [-V[V]] [-d nivel_depuracion] [-n] [-v] [-c] [-f archivo] [-r] [-z limite_tamano] [-M[M]] [-x] [-D binddn] [-W] [-w contrasena] [-y archivocontrasena] [-H uri_ldap] [-P {2|3}] [-e [!]ext[=parametro_ext]] [-E [!]ext[=parametro_ext]] [-o opcion[=parametro_opcion]] [-O propiedades-seguridad] [-I] [-Q] [-N] [-U authcid] [-R dominio] [-X authzid] [-Y mecanismo] [-Z[Z]] [DN [...]]

DESCRIPCIÓN

ldapdelete es una interfaz accesible desde la línea de comandos para la llamada a la biblioteca ldap_delete_ext(3).

ldapdelete abre una conexión a un servidor LDAP, se enlaza y elimina una o más entradas. Si se proporcionan uno o más argumentos DN, se eliminan las entradas con esos Nombres Distinguidos. Cada DN debe proporcionarse utilizando la representación de cadena LDAPv3 tal como se define en RFC 4514. Si no se proporcionan argumentos DN, se lee una lista de DN desde la entrada estándar (o desde archivo si se usa la bandera -f).

OPCIONES

-V[V]
Muestra información de la versión. Si se proporciona -VV, solo se muestra la información de la versión.
-d nivel_depuracion
Establece el nivel de depuración LDAP a nivel_depuracion. ldapdelete debe compilarse con LDAP_DEBUG definido para que esta opción tenga algún efecto.
-n
Muestra lo que se haría, pero sin eliminar realmente las entradas. Útil para depurar junto con -v.
-v
Usa el modo detallado, con muchos diagnósticos escritos en la salida estándar.
-c
Modo de operación continua. Los errores se informan, pero ldapdelete continuará con las eliminaciones. El valor predeterminado es salir después de informar un error.
-f archivo
Lee una serie de DN del archivo, uno por línea, realizando una eliminación LDAP por cada uno.
-r
Realiza una eliminación recursiva. Si el DN especificado no es una hoja, se eliminan sus hijos y todos sus hijos en el árbol. No se realiza verificación, por lo que si agrega este modificador, ldapdelete eliminará felizmente grandes porciones de su árbol. Úselo con precaución.
-z limite_tamano
Usa limite_tamano al buscar hijos DN para eliminar, para eludir cualquier límite del lado del servidor. Solo útil en conjunción con -r.
-M[M]
Habilita el control de gestor DSA IT. -MM hace que el control sea crítico.
-x
Utiliza autenticación simple en lugar de SASL.
-D binddn
Utiliza el Nombre Distinguido binddn para enlazar con el directorio LDAP. Para enlates SASL, se espera que el servidor ignore este valor.
-W
Solicita autenticación simple. Se usa en lugar de especificar la contraseña en la línea de comandos.
-w contrasena
Utiliza contrasena como contraseña para la autenticación simple.
-y archivocontrasena
Utiliza el contenido completo de archivocontrasena como contraseña para la autenticación simple.
-H uri_ldap
Especifica URI(s) que hacen referencia al(los) servidor(es) LDAP; solo los campos de protocolo/host/puerto están permitidos; se espera una lista de URI, separadas por espacios en blanco o comas.
-P {2|3}
Especifica la versión del protocolo LDAP a utilizar.
-e [!]ext[=parametro_ext]
-E [!]ext[=parametro_ext]

Especifica extensiones generales con -e y extensiones de eliminación con -E. ´!´ indica criticidad.

Extensiones generales:

  [!]assert=<filtro>    (un filtro RFC 4515)
  !authzid=<authzid>    ("dn:<dn>" o "u:<usuario>")
  [!]bauthzid           (control RFC 3829 authzid)
  [!]chaining[=<resolver>[/<cont>]]
  [!]manageDSAit
  [!]noop
  ppolicy
  [!]postread[=<attrs>] (una lista de atributos separada por comas)
  [!]preread[=<attrs>]  (una lista de atributos separada por comas)
  [!]relax
  sessiontracking[=<nombreusuario>]
  abandon,cancel,ignore (SIGINT envía abandon/cancel,
  o ignora la respuesta; si es crítico, no espera a SIGINT.
  no son realmente controles)

Extensiones de eliminación:

  (ninguna)
-o opcion[=parametro_opcion]

Especifica cualquier opción de ldap.conf(5) o una de las siguientes:

  nettimeout=<tiempo_espera>  (en segundos, o "none" o "max")
  ldif_wrap=<ancho>     (en columnas, o "no" para no envolver)
-O propiedades-seguridad
Especifica propiedades de seguridad SASL.
-I
Habilita el modo Interactivo SASL. Siempre solicita. El valor predeterminado es solicitar solo cuando sea necesario.
-Q
Habilita el modo Silencioso SASL. Nunca solicita.
-N
No utiliza DNS inverso para canonizar el nombre de host SASL.
-U authcid
Especifica el ID de autenticación para el enlace SASL. La forma de la identidad depende del mecanismo SASL real utilizado.
-R dominio
Especifica el dominio del ID de autenticación para el enlace SASL. La forma del dominio depende del mecanismo SASL real utilizado.
-X authzid
Especifica el ID de autorización solicitado para el enlace SASL. authzid debe tener uno de los siguientes formatos: dn:<nombre distinguido> o u:<nombredeusuario>
-Y mecanismo
Especifica el mecanismo SASL a utilizar para la autenticación. Si no se especifica, el programa elegirá el mejor mecanismo que conozca el servidor.
-Z[Z]
Emite la operación extendida StartTLS (Transport Layer Security). Si usa -ZZ, el comando requerirá que la operación sea exitosa.

EJEMPLO

El siguiente comando:

    ldapdelete "cn=Borrar Me,dc=ejemplo,dc=com"

intentará eliminar la entrada llamada "cn=Borrar Me,dc=ejemplo,dc=com". Por supuesto, probablemente sería necesario proporcionar credenciales de autenticación.

DIAGNÓSTICO

El estado de salida es 0 si no ocurren errores. Los errores resultan en un estado de salida distinto de cero y un mensaje de diagnóstico escrito en la salida de error estándar.
