NAME

ldns_pkt_additional - retrieve additional section of a DNS packet

SYNOPSIS

#include <ldns/pkt.h>

struct ldns_rr_list * ldns_pkt_additional(const struct ldns_pkt *pkt);

DESCRIPTION

The ldns_pkt_additional() function will return a pointer to the additional section of the given DNS packet.

REMARKS

If the packet has no additional records, an empty (but valid) ldns_rr_list will be returned.

This function does not allocate new memory. The returned pointer is valid as long as the packet exists.
