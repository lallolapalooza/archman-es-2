NOMBRE

ldns-walk - Recupera el contenido de una zona firmada con DNSSEC

SINOPSIS

ldns-walk [ OPCIÓN ] ZONA

DESCRIPCIÓN

ldns-walk se utiliza para recuperar el contenido de una zona firmada con DNSSEC. Lo hace a través de NSEC-walking (siguiendo la cadena de registros NSEC) y 'adivinando' el siguiente nombre de propietario inexistente para cada NSEC.

Tenga en cuenta que puede quedarse atascado en algunos registros comodín cuando se utiliza a través de un reenviador en caché. Este problema se puede evitar consultando directamente al servidor de nombres autoritativo (con el argumento @).

Por supuesto, el servidor de nombres que se utiliza debe ser compatible con DNSSEC.

OPCIONES

-4
Usar solo IPv4.
-6
Usar solo IPv6.
-f
Realiza un recorrido de zona 'completo'; por defecto, ldns-walk solo mostrará los nombres y los tipos presentes en esos nombres. Si se proporciona esta opción, se imprimirán todos los registros de recursos.
-s nombre
Inicia el recorrido con este nombre de propietario. Útil para continuar el recorrido de una zona grande.
-v nivel de verbosidad
Nivel de verbosidad [1-5].
@ servidor de nombres
Envía las consultas a este servidor de nombres.

ERRORES CONOCIDOS

La función de recorrido completo de zona aún no está completa, no imprime correctamente los registros de delegación

AUTOR

Escrito por Jelte Jansen como ejemplo de uso de ldns.
