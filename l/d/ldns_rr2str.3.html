ldns_rr2str(3)

Paquete: ldns

Licencias: custom:BSD

ldns(3) Manual de Funciones de Biblioteca ldns(3)

NOMBRE

ldns_rr2str, ldns_pkt2str, ldns_rdf2str, ldns_rr_list2str, ldns_key2str - funciones para conversiones a cadena

SINOPSIS

#include <stdint.h>
#include <stdbool.h>

#include <ldns/ldns.h>

char* ldns_rr2str(const ldns_rr *rr);

char* ldns_pkt2str(const ldns_pkt *pkt);

char* ldns_rdf2str(const ldns_rdf *rdf);

char* ldns_rr_list2str(const ldns_rr_list *rr_list);

char* ldns_key2str(const ldns_key *k);

DESCRIPCIÓN

ldns_rr2str() Convierte los datos del registro de recurso al formato de presentación y lo devuelve como un char *. Recuerda liberarlo.

rr: El campo rdata a convertir
Devuelve una cadena terminada en nulo (char *) o NULL en caso de error

ldns_pkt2str() Convierte los datos del paquete DNS al formato de presentación y lo devuelve como un char *. Recuerda liberarlo.

pkt: El campo rdata a convertir
Devuelve una cadena terminada en nulo (char *) o NULL en caso de error

ldns_rdf2str() Convierte los datos del campo rdata al formato de presentación y lo devuelve como un char *. Recuerda liberarlo.

rdf: El campo rdata a convertir
Devuelve una cadena terminada en nulo (char *) o NULL en caso de error

ldns_rr_list2str() Convierte una lista de registros de recurso al formato de presentación y lo devuelve como un char *. Recuerda liberarlo.

rr_list: la lista de registros de recurso a convertir a texto
Devuelve una cadena terminada en nulo (char *) o NULL en caso de error

ldns_key2str() Convierte una clave privada al formato de presentación de texto y lo devuelve como un char *. Recuerda liberarlo.

k: la clave a convertir a texto
Devuelve una cadena terminada en nulo (char *) o NULL en caso de error
