ldap_error(3)

Paquete: libldap

Licencias: custom

LDAP_ERROR(3) Manual de funciones de biblioteca LDAP_ERROR(3)

NOMBRE

ldap_perror, ld_errno, ldap_result2error, ldap_errlist, ldap_err2string - Rutinas de manejo de errores del protocolo LDAP

BIBLIOTECA

OpenLDAP LDAP (libldap, -lldap)

SINOPSIS

#include <ldap.h>
char *ldap_err2string( int err );

DESCRIPCIÓN

La rutina ldap_err2string() proporciona una descripción breve de los diversos códigos devueltos por las rutinas de esta biblioteca. La cadena devuelta es un puntero a un área estática que no debe modificarse.

Estos códigos son negativos, lo que indica un código de error de la API; positivos, lo que indica un código de resultado LDAP distinto de «éxito» (0); o cero, lo que indica tanto el uso exitoso de la API como el código de resultado LDAP «éxito» (0).

El código asociado con una sesión LDAP es accesible usando ldap_get_option(3) y ldap_set_option(3) con la opción LDAP_OPT_RESULT_CODE (anteriormente llamada LDAP_OPT_ERROR_NUMBER).

CÓDIGOS DE RESULTADO DEL PROTOCOLO

Esta sección proporciona una lista parcial de códigos de protocolo reconocidos por la biblioteca. Dado que LDAP es extensible, se pueden devolver valores adicionales. Se puede obtener una lista completa de los códigos de resultado LDAP *registrados* de la *Internet Assigned Numbers Authority* http://www.iana.org.

LDAP_SUCCESS
La solicitud fue exitosa.
LDAP_OPERATIONS_ERROR
Ocurrió un error en las operaciones.
LDAP_PROTOCOL_ERROR
Se detectó una violación del protocolo.
LDAP_TIMELIMIT_EXCEEDED
Se excedió el límite de tiempo de LDAP.
LDAP_SIZELIMIT_EXCEEDED
Se excedió el límite de tamaño de LDAP.
LDAP_COMPARE_FALSE
Una operación de comparación devolvió falso.
LDAP_COMPARE_TRUE
Una operación de comparación devolvió verdadero.
LDAP_STRONG_AUTH_NOT_SUPPORTED
El servidor LDAP no admite autenticación fuerte.
LDAP_STRONG_AUTH_REQUIRED
Se requiere autenticación fuerte para la operación.
LDAP_PARTIAL_RESULTS
Solo se devolvieron resultados parciales.
LDAP_NO_SUCH_ATTRIBUTE
El tipo de atributo especificado no existe en la entrada.
LDAP_UNDEFINED_TYPE
El tipo de atributo especificado es inválido.
LDAP_INAPPROPRIATE_MATCHING
El tipo de filtro no es compatible con el atributo especificado.
LDAP_CONSTRAINT_VIOLATION
Un valor de atributo especificado viola alguna restricción (por ejemplo, una dirección postal tiene demasiadas líneas o una línea es demasiado larga).
LDAP_TYPE_OR_VALUE_EXISTS
El tipo de atributo o el valor del atributo especificado ya existe en la entrada.
LDAP_INVALID_SYNTAX
Se especificó un valor de atributo inválido.
LDAP_NO_SUCH_OBJECT
El objeto especificado no existe en el Directorio.
LDAP_ALIAS_PROBLEM
Un alias en el Directorio apunta a una entrada inexistente.
LDAP_INVALID_DN_SYNTAX
Se especificó un DN sintácticamente inválido.
LDAP_IS_LEAF
El objeto especificado es una hoja.
LDAP_ALIAS_DEREF_PROBLEM
Se encontró un problema al desreferenciar un alias.
LDAP_INAPPROPRIATE_AUTH
Se especificó autenticación inapropiada (por ejemplo, se especificó LDAP_AUTH_SIMPLE y la entrada no tiene un atributo userPassword).
LDAP_INVALID_CREDENTIALS
Se presentaron credenciales inválidas (por ejemplo, contraseña incorrecta).
LDAP_INSUFFICIENT_ACCESS
El usuario tiene acceso insuficiente para realizar la operación.
LDAP_BUSY
El DSA está ocupado.
LDAP_UNAVAILABLE
El DSA no está disponible.
LDAP_UNWILLING_TO_PERFORM
El DSA no está dispuesto a realizar la operación.
LDAP_LOOP_DETECT
Se detectó un bucle.
LDAP_NAMING_VIOLATION
Ocurrió una violación de nomenclatura.
LDAP_OBJECT_CLASS_VIOLATION
Ocurrió una violación de clase de objeto (por ejemplo, faltaba un atributo «obligatorio» en la entrada).
LDAP_NOT_ALLOWED_ON_NONLEAF
La operación no está permitida en un objeto no hoja.
LDAP_NOT_ALLOWED_ON_RDN
La operación no está permitida en un RDN.
LDAP_ALREADY_EXISTS
La entrada ya existe.
LDAP_NO_OBJECT_CLASS_MODS
No se permiten modificaciones de clase de objeto.
LDAP_OTHER
Ocurrió un error desconocido.

CÓDIGOS DE ERROR DE LA API

Esta sección proporciona una lista completa de los códigos de error de la API reconocidos por la biblioteca. Tenga en cuenta que LDAP_SUCCESS indica el éxito de una llamada a la API además de representar la devolución del resultCode LDAP «éxito».

LDAP_SERVER_DOWN
La biblioteca LDAP no puede contactar al servidor LDAP.
LDAP_LOCAL_ERROR
Ocurrió algún error local. Esto suele ser una asignación de memoria dinámica fallida.
LDAP_ENCODING_ERROR
Se encontró un error al codificar parámetros para enviarlos al servidor LDAP.
LDAP_DECODING_ERROR
Se encontró un error al decodificar un resultado del servidor LDAP.
LDAP_TIMEOUT
Se excedió un límite de tiempo mientras se esperaba un resultado.
LDAP_AUTH_UNKNOWN
El método de autenticación especificado para ldap_bind() no se conoce.
LDAP_FILTER_ERROR
Se proporcionó un filtro inválido a ldap_search() (por ejemplo, paréntesis desequilibrados).
LDAP_PARAM_ERROR
Se llamó a una rutina ldap con un parámetro incorrecto.
LDAP_NO_MEMORY
Una llamada de asignación de memoria (por ejemplo, malloc(3) u otro asignador de memoria dinámica) falló en una rutina de la biblioteca ldap.
LDAP_USER_CANCELED
Indica que el usuario canceló la operación.
LDAP_CONNECT_ERROR
Indica un problema de conexión.
LDAP_NOT_SUPPORTED
Indica que la rutina se llamó de una manera no admitida por la biblioteca.
LDAP_CONTROL_NOT_FOUND
Indica que el control proporcionado es desconocido para la biblioteca cliente.
LDAP_NO_RESULTS_RETURNED
Indica que no se devolvieron resultados.
LDAP_MORE_RESULTS_TO_RETURN
Indica que se pueden devolver más resultados.
LDAP_CLIENT_LOOP
Indica que la biblioteca ha detectado un bucle en su procesamiento.
LDAP_REFERRAL_LIMIT_EXCEEDED
Indica que se ha superado el límite de referencias.

OBSOLETO

Las interfaces obsoletas generalmente permanecen en la biblioteca. La macro LDAP_DEPRECATED se puede definir a un valor distinto de cero (por ejemplo, -DLDAP_DEPRECATED=1) al compilar programas diseñados para usar interfaces obsoletas. Se recomienda que los desarrolladores que escriban programas nuevos o actualicen programas antiguos eviten el uso de interfaces obsoletas. Con el tiempo, se espera que la documentación (y, finalmente, el soporte) para las interfaces obsoletas se elimine.
