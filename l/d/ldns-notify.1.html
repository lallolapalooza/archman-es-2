NOMBRE

ldns-notify - notifica a los servidores DNS que hay actualizaciones disponibles

SINOPSIS

ldns-notify [opciones] -z zona servidores

DESCRIPCIÓN

ldns-notify envía un mensaje NOTIFY a los servidores DNS. Esto les indica que hay una zona actualizada disponible en los servidores maestros. Puede realizar firmas TSIG y puede añadir un número de serie SOA de la zona actualizada. Si un servidor ya tiene ese número de serie, ignorará el mensaje.

OPCIONES

-z zona
La zona que se actualiza.
-I dirección
IP de origen desde la que enviar la consulta.
-h
Mostrar uso y salir
-v
Mostrar la versión y salir
-s serial
Añadir un registro SOA que indique el número de serie de la zona actualizada.
-p puerto
Usar puerto como puerto de destino (por defecto el puerto DNS 53) para los paquetes UDP.
-y clave:datos[:algoritmo]
Usar la clave TSIG y los datos base64 dados, y opcionalmente un algoritmo para firmar el NOTIFY. El algoritmo por defecto es hmac-md5.sig-alg.reg.int.
-d
Mostrar información detallada de depuración. La consulta que se envía y la consulta que se recibe.
-r num
Especificar el número máximo de reintentos antes de que notify deje de intentar enviar el paquete UDP.

CÓDIGO DE SALIDA

El programa sale con un código de salida 0 si todos los servidores respondieron con un acuse de recibo al mensaje de notificación, y un código de salida de fallo en caso contrario.

AUTOR

Escrito por el equipo de ldns como ejemplo de uso de ldns.
