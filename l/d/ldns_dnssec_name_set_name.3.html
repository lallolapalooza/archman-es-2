DESCRIPCIÓN

ldns_dnssec_name_new() Crea una nueva estructura de datos para un nombre dnssec
Devuelve la estructura asignada

ldns_dnssec_name_new_frm_rr() Crea una nueva estructura de datos para un nombre dnssec para el RR dado

rr: el RR del cual derivar propiedades y añadir al nombre

ldns_dnssec_name_free() Libera la estructura del nombre y sus rrs y rrsets. Los registros ldns_rr individuales dentro de ella no se liberan

name: la estructura a liberar

ldns_dnssec_name_name() Devuelve el nombre de dominio de la estructura dnssec_name dada

name: el nombre dnssec del cual obtener el nombre de dominio
Devuelve el nombre de dominio

ldns_dnssec_name_set_name() Establece el nombre de dominio de la estructura dnssec_name dada

name: el nombre dnssec al cual establecer el nombre de dominio
dname: el nombre de dominio a establecer. Estos datos *no* se copian.

ldns_dnssec_name_set_nsec() Establece el RR NSEC(3) de la estructura dnssec_name dada

name: el nombre dnssec al cual establecer el nombre de dominio
nsec: el rr nsec a establecer. Estos datos *no* se copian.

ldns_dnssec_name_cmp() Compara los nombres de dominio de los dos argumentos en su orden canónico.

a: El primer dnssec_name a comparar
b: El segundo dnssec_name a comparar
Devuelve -1 si el nombre de dominio de a viene antes que el de b en orden canónico, 1 si es al revés, y 0 si son iguales

ldns_dnssec_name_add_rr() Inserta el rr dado en el lugar correcto en el dnssec_name actual. No se realiza ninguna comprobación de si el nombre coincide.

name: El ldns_dnssec_name al cual añadir el RR
rr: El RR a añadir
Devuelve LDNS_STATUS_OK en caso de éxito, un código de error en caso contrario

ldns_dnssec_name_find_rrset() Busca el RRset con el tipo dado dentro de esta estructura de nombre

name: el nombre en el cual buscar el RRset
type: el tipo de RRset a buscar
Devuelve el RRset, o NULL si no está presente

ldns_dnssec_name_print() Imprime los RR de la estructura dnssec_name al descriptor de archivo dado

out: el descriptor de archivo al cual imprimir
name: la estructura de nombre cuyos contenidos se imprimirán
