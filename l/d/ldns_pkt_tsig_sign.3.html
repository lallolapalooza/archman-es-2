NOMBRE

ldns_pkt_tsig_verify, ldns_pkt_tsig_sign - firma y verificación TSIG

SINOPSIS

#include <stdint.h>
#include <stdbool.h>

#include <ldns/ldns.h>

bool ldns_pkt_tsig_verify(ldns_pkt *pkt, const uint8_t *wire, size_t wire_size, const char *key_name, const char *key_data, const ldns_rdf *mac);

ldns_status ldns_pkt_tsig_sign(ldns_pkt *pkt, const char *key_name, const char *key_data, uint16_t fudge, const char *algorithm_name, const ldns_rdf *query_mac);

DESCRIPCIÓN

ldns_pkt_tsig_verify() verifica el registro TSIG para el paquete y la clave dados. El alambre (wire) también debe proporcionarse porque TSIG no firma paquetes normalizados.
pkt: el paquete a verificar
wire: necesario para verificar el MAC
wire_size: tamaño del alambre
key_name: el nombre de la clave compartida
key_data: la clave en formato base64
mac: MAC original
Devuelve verdadero si TSIG es correcto, falso si no, o si TSIG no está establecido.

ldns_pkt_tsig_sign() crea un registro TSIG para el paquete y la clave dados.
pkt: el paquete a firmar
key_name: el nombre de la clave compartida
key_data: la clave en formato base64
fudge: segundos de error permitidos en el tiempo firmado
algorithm_name: el nombre del algoritmo utilizado
query_mac: se añade al resumen si no es NULL (por lo tanto, NULL es para firmar consultas, no NULL es para firmar respuestas)
Devuelve el estado (OK si es éxito).
