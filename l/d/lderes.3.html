Propósito:

!>
!> Programa de prueba para el Nivel 2 de Blas de DOBLE PRECISIÓN.
!>
!> El programa debe ser controlado por un archivo de datos corto. Los primeros 18 registros
!> se leen usando entrada de lista dirigida, los últimos 16 registros
!> se leen usando el formato ( A6, L2 ). Un ejemplo anotado de un archivo de datos
!> se puede obtener eliminando los primeros 3 caracteres de las siguientes 34 líneas:
!> 'dblat2.out'      NOMBRE DEL ARCHIVO DE SALIDA DEL RESUMEN
!> 6                 NÚMERO DE UNIDAD DEL ARCHIVO DE RESUMEN
!> 'DBLAT2.SNAP'     NOMBRE DEL ARCHIVO DE SALIDA DE INSTANTÁNEA
!> -1                NÚMERO DE UNIDAD DEL ARCHIVO DE INSTANTÁNEA (NO SE USA SI .LT. 0)
!> F        INDICADOR LÓGICO, T PARA REBOBINAR EL ARCHIVO DE INSTANTÁNEA DESPUÉS DE CADA REGISTRO.
