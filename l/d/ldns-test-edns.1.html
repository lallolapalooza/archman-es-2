NOMBRE

ldns-test-edns - prueba si la caché DNS soporta EDNS y DNSSEC.

SINOPSIS

ldns-test-edns [ -i ] { ip }

DESCRIPCIÓN

ldns-test-edns prueba una caché DNS y comprueba si soporta EDNS0 y los tipos DNSSEC para que pueda ser utilizada como una caché DNS con soporte DNSSEC. Envía dos consultas a la caché, una para la clave raíz y otra para un registro DS. Estas deben tener éxito, la respuesta debe tener EDNS, ese tipo y firmas.

Si la dirección IP es buena para DNSSEC, se imprime con 'OK'. De lo contrario, se da una breve descripción del fallo. Si se indica OK, la caché debería ser adecuada para usar como caché para un validador DNSSEC configurado localmente.

La herramienta asume que la raíz está firmada y que Suecia está firmada. Además, las consultas se envían con la bandera CD, la herramienta no comprueba que los resultados se validen, sino que pueden ser validados.

OPCIONES

La opción -i habilita un modo en el que las direcciones IP que funcionan se imprimen una tras otra, sin otras explicaciones, y si ninguna funciona o no hay direcciones IP en la entrada, se imprime 'off'.

ldns-test-edns toma una o más direcciones IP, las comprueba en orden. Se pueden dar direcciones IPv4 e IPv6. El valor de salida es para la última dirección IP comprobada: 0 es OK, 1 es fallo, 2 es algún tipo de fallo de red.
