NOMBRE

ldns-key2ds - transforma un RR DNSKEY a un RR DS

SINOPSIS

ldns-key2ds archivo

DESCRIPCIÓN

ldns-key2ds se usa para transformar un RR DNSKEY público a un RR DS. Al ejecutarse, leerá el archivo que contiene un RR DNSKEY y creará un archivo .ds con el RR DS.

Imprime el nombre base para este archivo (K<nombre>+<alg>+<id>).

Por defecto, elige un algoritmo similar al algoritmo de la clave, SHA1 para RSASHA1, y así sucesivamente.

OPCIONES

-f
Ignora el flag SEP (es decir, crea registros DS para cualquier clave)
-n
Escribe el registro de recursos DS resultante en la salida estándar en lugar de un archivo
-1
Usa SHA1 como función hash.
-2
Usa SHA256 como función hash
-g
Usa GOST como función hash
-4
Usa SHA384 como función hash

AUTOR
