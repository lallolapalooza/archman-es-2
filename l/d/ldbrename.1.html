LDBRENAME(1) Herramientas de administración del sistema LDBRENAME(1)

NOMBRE

ldbrename - Edita bases de datos LDB con tu editor favorito

SINOPSIS

ldbrename [-h] [-o opciones] {dn_antiguo} {dn_nuevo}

DESCRIPCIÓN

ldbrename es una utilidad que te permite renombrar árboles en una base de datos LDB basándose en el DN. Esta utilidad toma dos argumentos: el nombre DN original del elemento superior y el DN al que se desea cambiar.

OPCIONES

-h

Muestra la lista de opciones disponibles.

-H <url-ldb>

URL LDB a la que conectarse. Ver ldb(3) para más detalles.

-o opciones

Opciones ldb adicionales, como módulos.

ENTORNO

LDB_URL

URL LDB a la que conectarse (puede ser anulada usando la opción de línea de comandos -H).
