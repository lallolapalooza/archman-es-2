ldns_fget_token(3)

Paquete: ldns

Licencias: custom:BSD

ldns(3) Manual de Funciones de Biblioteca ldns(3)

NOMBRE

ldns_fget_token, ldns_fskipcs - obtener tokens de archivos

SINOPSIS

#include <stdint.h>
#include <stdbool.h>

#include <ldns/ldns.h>

ssize_t ldns_fget_token(FILE *f, char *token, const char *delim, size_t limit);

void ldns_fskipcs(FILE *fp, const char *s);

DESCRIPCIÓN

ldns_fget_token() devuelve un token/carácter del flujo F. Esta función maneja ( y ) en el flujo, e los ignora cuando se encuentran
*f: el archivo del que leer
*token: el token leído se guarda aquí
*delim: caracteres en los que debe detenerse el análisis
*limit: cuánto leer. Si es 0 se usa el máximo incorporado
Devuelve 0 en caso de error o fin de archivo del flujo F. De lo contrario, devuelve la longitud de lo leído.

ldns_fskipcs() omite todos los caracteres de la cadena dada en fp, moviendo la posición al primer carácter que no está en *s.
*fp: archivo a utilizar
*s: caracteres a omitir
Devuelve void
