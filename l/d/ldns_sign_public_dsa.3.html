ldns_sign_public_dsa(3)

Paquete: ldns

Licencias: custom:BSD

ldns(3) Manual de funciones de biblioteca ldns(3)

NOMBRE

ldns_sign_public_dsa, ldns_sign_public_rsamd5, ldns_sign_public_rsasha1 - firmar un buffer

SINOPSIS

#include <stdint.h>
#include <stdbool.h>

#include <ldns/ldns.h>

ldns_rdf* ldns_sign_public_dsa(ldns_buffer *to_sign, DSA *key);

ldns_rdf* ldns_sign_public_rsamd5(ldns_buffer *to_sign, RSA *key);

ldns_rdf* ldns_sign_public_rsasha1(ldns_buffer *to_sign, RSA *key);

DESCRIPCIÓN

ldns_sign_public_dsa() Firma un buffer con la clave DSA (hash con SHA1)

to_sign: El ldns_buffer que contiene los datos crudos que se van a firmar
key: La estructura de clave DSA para firmar
Devuelve un ldns_rdf para el RRSIG ldns_rr

ldns_sign_public_rsamd5() Firma un buffer con la clave RSA (hash con MD5)
to_sign: buffer con los datos
key: la clave a usar
Devuelve un ldns_rdf con los datos firmados

ldns_sign_public_rsasha1() Firma un buffer con la clave RSA (hash con SHA1)
to_sign: buffer con los datos
key: la clave a usar
Devuelve un ldns_rdf con los datos firmados
