ldap_result(3)

Paquete: libldap

Licencias: custom

LDAP_RESULT(3) Manual de funciones de la biblioteca LDAP_RESULT(3)

NOMBRE

ldap_result - Espera el resultado de una operación LDAP

BIBLIOTECA

OpenLDAP LDAP (libldap, -lldap)

SINOPSIS

#include <ldap.h>
int ldap_result( LDAP *ld, int msgid, int all,
	struct timeval *timeout, LDAPMessage **result );
int ldap_msgfree( LDAPMessage *msg );
int ldap_msgtype( LDAPMessage *msg );
int ldapid( LDAPMessage *msg );

DESCRIPCIÓN

La rutina ldap_result() se utiliza para esperar y devolver el resultado de una operación iniciada previamente por una de las rutinas de operación asíncrona LDAP (por ejemplo, ldap_search_ext(3), ldap_modify_ext(3), etc.). Esas rutinas devuelven -1 en caso de error, y un identificador de invocación al iniciar con éxito la operación. El identificador de invocación es elegido por la biblioteca y está garantizado que sea único en toda la sesión LDAP. Puede ser utilizado para solicitar el resultado de una operación específica de ldap_result() a través del parámetro msgid.

La rutina ldap_result() bloqueará o no, dependiendo de la configuración del parámetro timeout. Si timeout no es un puntero NULL, especifica un intervalo máximo para esperar a que se complete la selección. Si timeout es un puntero NULL, se utiliza el valor LDAP_OPT_TIMEOUT establecido por ldap_set_option(3). Con la configuración por defecto, la selección se bloquea indefinidamente. Para efectuar una encuesta, el argumento timeout debe ser un puntero no NULL, apuntando a una estructura timeval de valor cero. Para obtener el comportamiento de la configuración por defecto, ignorando cualquier valor establecido por ldap_set_option(3), establezca a -1 el campo tv_sec del parámetro timeout. Véase select(2) para más detalles.

Si se requiere el resultado de una operación específica, msgid debe establecerse en el identificador de invocación devuelto cuando se inició la operación; de lo contrario, deben suministrarse LDAP_RES_ANY o LDAP_RES_UNSOLICITED para esperar cualquier respuesta o una respuesta no solicitada.

El parámetro all, si es distinto de cero, hace que ldap_result() devuelva todas las respuestas con msgid, de lo contrario solo se devuelve la siguiente respuesta. Esto se utiliza comúnmente para obtener todas las respuestas de una operación de búsqueda.

Una respuesta de búsqueda se compone de cero o más entradas de búsqueda, cero o más referencias de búsqueda, y cero o más respuestas parciales extendidas seguidas de un resultado de búsqueda. Si all se establece a 0, las entradas de búsqueda se devolverán una a la vez a medida que lleguen, a través de llamadas separadas a ldap_result(). Si se establece a 1, la respuesta de búsqueda solo se devolverá en su totalidad, es decir, después de que todas las entradas, todas las referencias, todas las respuestas parciales extendidas y el resultado final de la búsqueda hayan sido recibidos.

VALOR DE RETORNO

En caso de éxito, se devuelve el tipo del resultado recibido y el parámetro result contendrá el resultado de la operación; de lo contrario, el parámetro result no está definido. Este resultado debe pasarse a las rutinas de análisis de LDAP, ldap_first_message(3) y similares, para su interpretación.

Los tipos de resultado posibles devueltos son:

LDAP_RES_BIND (0x61)
LDAP_RES_SEARCH_ENTRY (0x64)
LDAP_RES_SEARCH_REFERENCE (0x73)
LDAP_RES_SEARCH_RESULT (0x65)
LDAP_RES_MODIFY (0x67)
LDAP_RES_ADD (0x69)
LDAP_RES_DELETE (0x6b)
LDAP_RES_MODDN (0x6d)
LDAP_RES_COMPARE (0x6f)
LDAP_RES_EXTENDED (0x78)
LDAP_RES_INTERMEDIATE (0x79)

La rutina ldap_msgfree() se utiliza para liberar la memoria asignada para los resultados por ldap_result() o ldap_search_ext_s(3) y similares. Toma un puntero al resultado o a la cadena de resultados a liberar y devuelve el tipo del último mensaje de la cadena. Si el parámetro es NULL, la función no hace nada y devuelve cero.

La rutina ldap_msgtype() devuelve el tipo de un mensaje.

La rutina ldap_msgid() devuelve el ID del mensaje de un mensaje.

ERRORES

ldap_result() devuelve -1 si ocurre algo malo y cero si se excedió el tiempo de espera especificado. ldap_msgtype() y ldap_msgid() devuelven -1 en caso de error.

VÉASE TAMBIÉN

ldap(3), ldap_first_message(3), select(2)
