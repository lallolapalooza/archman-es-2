ldns_native2rdf_int8, ldns_native2rdf_int16, ldns_native2rdf_int32, ldns_native2rdf_int16_data, ldns_rdf2native_int8, ldns_rdf2native_int16, ldns_rdf2native_int32, ldns_rdf2native_sockaddr_storage, ldns_rdf2native_time_t - funciones de conversión numérica de rdf

#include <stdint.h>
#include <stdbool.h>

#include <ldns/ldns.h>

ldns_rdf* ldns_native2rdf_int8(ldns_rdf_type type, uint8_t value);

ldns_rdf* ldns_native2rdf_int16(ldns_rdf_type type, uint16_t value);

uint32_t ldns_rdf2native_int32(const ldns_rdf *rd);


ldns_rdf2native_sockaddr_storage();

DESCRIPCIÓN

ldns_native2rdf_int8() devuelve el rdf que contiene la representación nativa de uint8_t.
type: el tipo ldns_rdf a usar
value: el uint8_t a usar
Devuelve ldns_rdf* con el valor convertido

ldns_native2rdf_int16() devuelve el rdf que contiene la representación nativa de uint16_t.
type: el tipo ldns_rdf a usar
value: el uint16_t a usar
Devuelve ldns_rdf* con el valor convertido

ldns_native2rdf_int32() devuelve un rdf que contiene el valor int32 dado.

Dado que varios tipos de rdf pueden contener un int32, se debe especificar el tipo
type: el tipo ldns_rdf a usar
value: el uint32_t a usar
Devuelve ldns_rdf* con el valor convertido

ldns_native2rdf_int16_data() devuelve un rdf int16_data que contiene los datos de la matriz dada, precedidos por un int16 que especifica la longitud.

La memoria se copia y se devuelve un LDNS_RDF_TYPE_INT16DATA
size: el tamaño de los datos
*data: puntero a los datos reales

Devuelve ldns_rd* el rdf con los datos

ldns_rdf2native_int8() devuelve la representación nativa de uint8_t del rdf.
rd: el ldns_rdf sobre el que operar
Devuelve uint8_t el valor extraído

ldns_rdf2native_int16() devuelve la representación nativa de uint16_t del rdf.
rd: el ldns_rdf sobre el que operar
Devuelve uint16_t el valor extraído

ldns_rdf2native_int32() devuelve la representación nativa de uint32_t del rdf.
rd: el ldns_rdf sobre el que operar
Devuelve uint32_t el valor extraído

ldns_rdf2native_sockaddr_storage()

ldns_rdf2native_time_t() devuelve la representación nativa de time_t del rdf.
rd: el ldns_rdf sobre el que operar
Devuelve time_t el valor extraído (actualmente 32 bits)
