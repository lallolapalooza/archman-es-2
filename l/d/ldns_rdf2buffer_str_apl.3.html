NAME

ldns_rdf2buffer_str_apl - convert an RDF to a string and place it into a buffer.

SYNOPSIS

ldns_rdf2buffer_str_apl(ldns_buffer *buf, ldns_rdf *rdf, int expand);

DESCRIPTION

Convert an RDF (Resource Data Field) to a string and place it into a buffer. The conversion uses the standard DNS presentation format. For example, an IP address will be represented as its textual representation. When expand is set to 1, unknown record types will be printed as integers. Otherwise they will be represented in hexadecimal. This function appends the string representation to the buffer.
