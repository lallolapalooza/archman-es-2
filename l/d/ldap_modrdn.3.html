NOMBRE

ldap_modrdn, ldap_modrdn_s, ldap_modrdn2, ldap_modrdn2_s - Realizar una operación LDAP de modificar RDN

BIBLIOTECA

DESCRIPCION

Las rutinas ldap_modrdn() y ldap_modrdn_s() realizan una operación LDAP de modificar RDN. Ambas toman dn, el DN de la entrada cuyo RDN se va a cambiar, y newrdn, el nuevo RDN que se le dará a la entrada. El RDN antiguo de la entrada nunca se conserva como un atributo de la entrada. ldap_modrdn() es asíncrona y devuelve el ID del mensaje de la operación que inicia. ldap_modrdn_s() es síncrona y devuelve el código de error LDAP que indica el éxito o el fracaso de la operación. El uso de estas rutinas está obsoleto. Utilice las versiones descritas a continuación en su lugar.

Las rutinas ldap_modrdn2() y ldap_modrdn2_s() también realizan una operación LDAP de modificar RDN, tomando los mismos parámetros que los anteriores. Además, ambas toman el parámetro deleteoldrdn que se utiliza como valor booleano para indicar si los valores del RDN antiguo deben eliminarse o no de la entrada.

ERRORES

Las versiones síncronas (_s) de estas rutinas devuelven un código de error LDAP, ya sea LDAP_SUCCESS o un error si hubo algún problema. Las versiones asíncronas devuelven -1 en caso de problemas, estableciendo el campo ld_errno de ld. Véase ldap_error(3) para más detalles.
