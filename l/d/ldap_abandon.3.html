LDAP_ABANDON(3) Manual de funciones de biblioteca LDAP_ABANDON(3)

NOMBRE

ldap_abandon_ext - Abandona una operación LDAP en curso

BIBLIOTECA

OpenLDAP LDAP (libldap, -lldap)

SINOPSIS


#include <ldap.h>
int ldap_abandon_ext(
LDAP *ld,
Bint msgid,
LDAPControl **sctrls,
LDAPControl **cctrls );

DESCRIPCIÓN

La rutina ldap_abandon_ext() se utiliza para enviar una solicitud LDAP Abandon para una operación en curso. El msgid pasado debe ser el ID del mensaje de una operación LDAP pendiente, tal como lo devuelve ldap_search_ext(3).

ldap_abandon_ext() comprueba si el resultado de la operación ya ha llegado. Si es así, lo elimina de la cola de mensajes pendientes. Si no, envía una solicitud LDAP abandon a el servidor LDAP.

El llamador puede esperar que el resultado de una operación abandonada no se devuelva en una llamada futura a ldap_result(3).

ldap_abandon_ext() permite pasar controles de servidor y cliente a través de los parámetros sctrls y cctrls, respectivamente.

ldap_abandon_ext() devuelve un código que indica éxito o, en caso de error, la naturaleza del error. Consulte ldap_error(3) para obtener detalles.

INTERFACES EN DESUSO

La rutina ldap_abandon() está en desuso en favor de la rutina ldap_abandon_ext().

Las interfaces en desuso generalmente permanecen en la biblioteca. La macro LDAP_DEPRECATED puede definirse a un valor distinto de cero (por ejemplo, -DLDAP_DEPRECATED=1) al compilar programas diseñados para usar interfaces en desuso. Se recomienda que los desarrolladores que escriban programas nuevos, o actualicen programas antiguos, eviten el uso de interfaces en desuso. Con el tiempo, se espera que la documentación (y, eventualmente, el soporte) para las interfaces en desuso se elimine.

VER TAMBIÉN

ldap(3), ldap_error(3), ldap_result(3), ldap_search_ext(3)
