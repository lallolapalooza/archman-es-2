ldap_rename(3)

Paquete: libldap

Licencias: custom

LDAP_RENAME(3) Manual de funciones de la biblioteca LDAP_RENAME(3)

NOMBRE

ldap_rename, ldap_rename_s - Renombra la entrada especificada.

BIBLIOTECA

OpenLDAP LDAP (libldap, -lldap)

SINOPSIS

#include <ldap.h>
int ldap_rename( ld, dn, newrdn, newparent, deleteoldrdn, sctrls[], cctrls[], msgidp );
LDAP *ld;
const char *dn, *newrdn, *newparent;
int deleteoldrdn;
LDAPControl *sctrls[], *cctrls[];
int *msgidp);
int ldap_rename_s( ld, dn, newrdn, newparent, deleteoldrdn, sctrls[], cctrls[] );
LDAP *ld;
const char *dn, *newrdn, *newparent;
int deleteoldrdn;
LDAPControl *sctrls[], *cctrls[];

DESCRIPCIÓN

Estas rutinas se utilizan para realizar una operación de renombre en LDAP. La función cambia el componente hoja del nombre distinguido de una entrada y opcionalmente mueve la entrada a un contenedor padre nuevo. El ldap_rename_s realiza una operación de renombre de forma síncrona. El método toma dn, que apunta al nombre distinguido de la entrada cuyo atributo se está comparando, newparent, el nombre distinguido del nuevo padre de la entrada. Si este parámetro es NULL, solo se cambia el RDN. El DN raíz se especifica pasando una cadena de longitud cero, "". deleteoldrdn especifica si el RDN antiguo debe conservarse o eliminarse. Cero indica que el RDN antiguo debe conservarse. Si elige esta opción, el atributo contendrá ambos nombres (el antiguo y el nuevo). Un valor distinto de cero indica que el RDN antiguo debe eliminarse. serverctrls apunta a una matriz de estructuras LDAPControl que enumeran los controles del cliente que se utilizarán con esta operación extendida. Utilice NULL para especificar ningún control de cliente. clientctrls apunta a una matriz de estructuras LDAPControl que enumeran los controles del cliente que se utilizarán con la búsqueda.

ldap_rename funciona igual que ldap_rename_s, pero la operación es asíncrona. Devuelve el ID del mensaje de la solicitud que inició. El resultado de esta operación se puede obtener llamando a ldap_result(3).

ERRORES

ldap_rename() devuelve -1 en caso de error al iniciar la solicitud, y establecerá el campo ld_errno en el parámetro ld para indicar el error. ldap_rename_s() devuelve el código de error LDAP resultante de la operación de renombre.

VER TAMBIÉN

ldap(3), ldap_modify(3)
