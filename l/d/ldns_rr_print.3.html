NOMBRE

ldns_rr_new, ldns_rr_new_frm_type, ldns_rr_new_frm_str, ldns_rr_new_frm_fp, ldns_rr_free, ldns_rr_print - Creación, destrucción e impresión de ldns_rr

SINOPSIS

#include <stdint.h>
#include <stdbool.h>

#include <ldns/ldns.h>

ldns_rr* ldns_rr_new(void);

ldns_rr* ldns_rr_new_frm_type(ldns_rr_type t);

ldns_status ldns_rr_new_frm_str(ldns_rr **n, const char *str, uint32_t default_ttl, const ldns_rdf *origin, ldns_rdf **prev);

ldns_status ldns_rr_new_frm_fp(ldns_rr **rr, FILE *fp, uint32_t *default_ttl, ldns_rdf **origin, ldns_rdf **prev);

void ldns_rr_free(ldns_rr *rr);

void ldns_rr_print(FILE *output, const ldns_rr *rr);

DESCRIPCIÓN

ldns_rr_new() crea una nueva estructura rr.
Devuelve ldns_rr *

ldns_rr_new_frm_type() crea una nueva estructura rr, basada en el tipo dado. Asigna suficiente espacio para contener todos los rdf's

ldns_rr_new_frm_str() crea un rr a partir de una cadena. La cadena debe ser un rr completamente completado, como nombre_propietario &lt;espacio&gt; TTL &lt;espacio&gt; CLASE &lt;espacio&gt; TIPO &lt;espacio&gt; RDATA.
n: el rr a devolver
str: la cadena a convertir
default_ttl: valor ttl por defecto para el rr. Si es 0 se usará DEF_TTL
origin: cuando el propietario es relativo, añada esto. El llamante debe hacer ldns_rdf_deep_free de él.
prev: el nombre de propietario anterior. si este valor no es NULL, la función lo sobrescribe con el nombre de propietario encontrado en esta cadena. El llamante debe hacer ldns_rdf_deep_free de él.
Devuelve un mensaje de estado que describe un error o LDNS_STATUS_OK

ldns_rr_new_frm_fp() crea un nuevo rr a partir de un archivo que contiene una cadena.
rr: el nuevo rr
fp: el puntero de archivo a usar
default_ttl: puntero a un ttl por defecto para el rr. Si es NULL se usará DEF_TTL el puntero se actualizará si el archivo contiene una directiva $TTL
origin: cuando el propietario es relativo, añada esto el puntero se actualizará si el archivo contiene una directiva $ORIGIN El llamante debe hacer ldns_rdf_deep_free de él.
prev: cuando el propietario son espacios en blanco use esto como el * nombre de propietario el puntero se actualizará después de la llamada El llamante debe hacer ldns_rdf_deep_free de él.
Devuelve un ldns_status con un error o LDNS_STATUS_OK

ldns_rr_free() libera una estructura RR
*rr: el RR a liberar
Devuelve void

ldns_rr_print() Imprime los datos del registro de recursos en el flujo de archivo dado (en formato de presentación)

output: el flujo de archivo donde imprimir
rr: el registro de recursos a imprimir
Devuelve void
