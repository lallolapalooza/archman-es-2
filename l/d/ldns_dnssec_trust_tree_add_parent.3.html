DESCRIPCIÓN

ldns_dnssec_trust_tree_new() Crea una nueva estructura dnssec_trust_tree (vacía)

Devuelve ldns_dnssec_trust_tree *

ldns_dnssec_trust_tree_free() Libera la dnssec_trust_tree recursivamente

No hay liberación profunda; todos los datos en el árbol de confianza consisten en punteros a una data_chain

tree: El árbol a liberar

ldns_dnssec_trust_tree_depth() devuelve la profundidad del árbol de confianza

tree: árbol para calcular la profundidad
Devuelve La profundidad del árbol

ldns_dnssec_derive_trust_tree() Genera un dnssec_trust_tree para el rr dado a partir de la data_chain dada

Esto no clona los datos reales; No libere la data_chain antes de terminar con este árbol

*data_chain: La cadena de la cual derivar el árbol de confianza
*rr: El RR sobre el que tratará este árbol
Devuelve ldns_dnssec_trust_tree *

ldns_dnssec_trust_tree_contains_keys() Devuelve OK si existe una ruta de confianza en el árbol hacia uno de los RRs DNSKEY o DS en la lista dada

\param *tree El árbol de confianza a buscar \param *keys Una ldns_rr_list de RRs DNSKEY y DS para buscar

Devuelve LDNS_STATUS_OK si existe una ruta de confianza hacia una de las claves, o el *primer* error encontrado si no hubo rutas

ldns_dnssec_trust_tree_print() Imprime la estructura dnssec_trust_tree al flujo de archivo dado.

Si el estado de un enlace no es LDNS_STATUS_OK; el estado y las firmas relevantes también se imprimen

*out: El flujo de archivo para imprimir
tree: El árbol de confianza a imprimir
tabs: Anteponer cada línea con tabs*2 espacios
extended: Si es verdadero, agregar pequeñas líneas explicativas a la salida

ldns_dnssec_trust_tree_print_sm()

ldns_dnssec_trust_tree_add_parent() Agrega un árbol de confianza como padre para el árbol de confianza dado

*tree: El árbol al que agregar el padre
*parent: El árbol padre a agregar
*parent_signature: La firma RRSIG relevante para esta conexión padre/hijo
parent_status: El estado DNSSEC para este padre, hijo y RRSIG
Devuelve LDNS_STATUS_OK si la adición tiene éxito, error de lo contrario

ldns_dnssec_derive_trust_tree_normal_rrset() Función secundaria para derive_trust_tree que se utiliza para un rrset 'normal'

new_tree: El árbol de confianza que estamos construyendo
data_chain: La cadena de datos que contiene los datos para el árbol de confianza
cur_sig_rr: La firma actualmente relevante

ldns_dnssec_derive_trust_tree_dnskey_rrset() Función secundaria para derive_trust_tree que se utiliza para rrsets DNSKEY

new_tree: El árbol de confianza que estamos construyendo
data_chain: La cadena de datos que contiene los datos para el árbol de confianza
cur_rr: El RR DNSKEY actualmente relevante
cur_sig_rr: La firma actualmente relevante

ldns_dnssec_derive_trust_tree_ds_rrset() Función secundaria para derive_trust_tree que se utiliza para rrsets DS

new_tree: El árbol de confianza que estamos construyendo
data_chain: La cadena de datos que contiene los datos para el árbol de confianza
cur_rr: El RR DS actualmente relevante

ldns_dnssec_derive_trust_tree_no_sig() Función secundaria para derive_trust_tree que se utiliza cuando no hay firmas

new_tree: El árbol de confianza que estamos construyendo
data_chain: La cadena de datos que contiene los datos para el árbol de confianza
