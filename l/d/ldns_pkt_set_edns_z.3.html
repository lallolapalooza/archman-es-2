DESCRIPCIÓN

ldns_pkt_edns() devuelve verdadero si este paquete necesita una RR EDNS para ser enviado. En este momento, la única razón es un tamaño de paquete esperado mayor a 512 bytes, pero, por ejemplo, DNSSEC sería una buena razón también.
