NOMBRE

ldns-update - enviar un paquete de actualización dinámica

SINOPSIS

ldns-update nombre [ zona ] [ ip ] [ tsig_nombre tsig_alg tsig_hmac ]

DESCRIPCIÓN

ldns-update se utiliza para enviar un paquete de actualización dinámica.

OPCIONES

nombre
El nombre de dominio a asociar con la ip dada.
zona
Cuando se proporciona, utiliza esta zona en lugar de intentar encontrar y procesar el registro SOA del dominio.
ip
Envía la actualización a esta dirección IP. O, cuando se da el texto literal none (ninguno), elimina cualquier dirección anterior.
tsig_nombre tsig_alg tsig_hmac
Utiliza TSIG (rfc2845) para autenticar.

EJEMPLO

ldns-update my.example.org 1.2.3.4
