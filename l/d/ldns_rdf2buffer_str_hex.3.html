ldns_rdf2buffer_str_hex(3) - mandoc

NAME

ldns_rdf2buffer_str_hex - convert a numerically encoded resource record data (RDATA) to a string

SYNOPSIS

#include <ldns/util.h>

ssize_t ldns_rdf2buffer_str_hex(char *buffer, size_t buffer_size, const ldns_rdf *rdf);

DESCRIPTION

Convert a numerically encoded resource record data (RDATA) to a string.

The function will write the string representation of the rdf into the buffer buffer with a maximum size of buffer_size. The result is always null-terminated.

The rdf needs to be of type LDNS_RDF_TYPE_INT8, LDNS_RDF_TYPE_INT16, LDNS_RDF_TYPE_INT32, LDNS_RDF_TYPE_UINT8, LDNS_RDF_TYPE_UINT16, LDNS_RDF_TYPE_UINT32, LDNS_RDF_TYPE_UINT64, or LDNS_RDF_TYPE_NSEC.

Returns the number of characters written, not including the null terminator. Returns -1 if the buffer is too small.
