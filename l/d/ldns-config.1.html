NOMBRE

ldns-config - mostrar las opciones del compilador y del enlazador para el uso de ldns.

SINOPSIS

ldns-config [ OPCIONES ]

DESCRIPCIÓN

Al escribir programas que usan ldns, tienes que indicarle al compilador dónde buscar los archivos de inclusión y qué bibliotecas enlazar desde qué ubicación. ldns-config se puede usar para averiguar qué opciones usar con el compilador C y el enlazador.

OPCIONES

--cflags
Mostrar las opciones del compilador C necesarias para compilar con ldns
--libs
Mostrar las opciones para enlazar con ldns
--version
Muestra la versión de ldns de la biblioteca ldns instalada
--libversion
Muestra la versión de la API binaria de la biblioteca ldns instalada
--help
Mostrar la descripción de uso de ldns-config

AUTOR

Escrito por el equipo de ldns.

REPORTAR ERRORES

Reportar errores a <dns-team@nlnetlabs.nl>.
