ldap_controls(3)

Paquete: libldap

Licencias: custom

LDAP_CONTROLS(3) Manual de funciones de la biblioteca LDAP_CONTROLS(3)

NOMBRE

ldap_control_create, ldap_control_find, ldap_control_dup, ldap_controls_dup, ldap_control_free, ldap_controls_free - Rutinas de manipulación de controles LDAP

BIBLIOTECA

OpenLDAP LDAP (libldap, -lldap)

SINTAXIS

#include <ldap.h>

int ldap_control_create(const char *oid, int iscritical, struct berval *value, int dupval, LDAPControl **ctrlp);

LDAPControl *ldap_control_find( const char *oid, LDAPControl **ctrls, LDAPControl ***nextctrlp);

LDAPControl *ldap_control_dup(LDAPControl *ctrl);

LDAPControl **ldap_controls_dup(LDAPControl **ctrls);

void ldap_control_free(LDAPControl *ctrl);

void ldap_controls_free(LDAPControl **ctrls);

DESCRIPCIÓN

Estas rutinas se utilizan para manipular estructuras utilizadas para controles LDAP.

ldap_control_create() crea un control con el oid especificado utilizando el contenido del parámetro value para el valor del control, si lo hay. El contenido de value se duplica si dupval no es cero. El parámetro iscritical debe ser distinto de cero para un control crítico. El control creado se devuelve en el parámetro ctrlp. La rutina devuelve LDAP_SUCCESS si tiene éxito o algún otro código de error si falla. El contenido de value, para los tipos de control compatibles, puede prepararse utilizando las utilidades proporcionadas por esta implementación de libldap, generalmente en la forma ldap_create_<nombre>_control_value(). De lo contrario, puede codificarse en BER utilizando las funcionalidades de liblber.

ldap_control_find() busca en la matriz terminada en NULL ctrls un control cuyo OID coincida con el parámetro oid. La rutina devuelve un puntero al control si lo encuentra, NULL en caso contrario. Si el parámetro nextctrlp no es NULL, al regresar apuntará al siguiente control en la matriz y podrá pasarse a la rutina ldap_control_find() para llamadas posteriores, para encontrar más ocurrencias del mismo tipo de control. Se desaconseja el uso de esta función; la forma recomendada de manejar los controles en las respuestas consiste en recorrer la matriz de controles, tratándolos a cada uno en el orden devuelto, ya que podría importar.

ldap_control_dup() duplica una estructura de control individual y ldap_controls_dup() duplica una matriz de controles terminada en NULL.

ldap_control_free() libera una estructura de control individual y ldap_controls_free() libera una matriz de controles terminada en NULL.
