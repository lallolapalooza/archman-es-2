DESCRIPCIÓN

La función ldns_pkt_authority devuelve el nombre del dominio de la sección de autoridad de un paquete DNS.

SINOPSIS

#include <ldns/pkt.h>

ldns_rdf *
ldns_pkt_authority(const ldns_pkt *pkt);

DESCRIPCIÓN DETALLADA

Esta función accede a la información del paquete DNS proporcionado por el argumento pkt y extrae el registro de recurso (RR) de la sección de autoridad. El resultado es un puntero a una estructura ldns_rdf que representa el nombre del dominio de la autoridad. Si el paquete no tiene una sección de autoridad o está vacío, la función puede devolver NULL o un puntero a una estructura ldns_rdf vacía, dependiendo de la implementación interna de ldns.

PARÁMETROS

  • pkt: Un puntero constante a la estructura ldns_pkt que representa el paquete DNS a inspeccionar.

VALOR DE RETORNO

Devuelve un puntero a una estructura ldns_rdf que contiene el nombre del dominio de la sección de autoridad, o NULL si no está presente.

EJEMPLO

#include <ldns/ldns.h>
#include <stdio.h>

int main() {
    ldns_pkt *pkt;
    ldns_rdf *authority_name;

    // Crear un paquete DNS de ejemplo (esto es simplificado)
    // En una aplicación real, obtendrías el paquete de una consulta DNS
    pkt = ldns_pkt_new();
    // Añadir una entrada de ejemplo a la sección de autoridad (esto es solo para demostración)
    ldns_rr_list_push_rr(ldns_pkt_authority_list(pkt), ldns_rr_new_frm_str("example.com. IN SOA ns1.example.com."));

    authority_name = ldns_pkt_authority(pkt);

    if (authority_name) {
        char *str_name = ldns_rdf2str(authority_name);
        printf("Nombre de la autoridad: %s\n", str_name);
        free(str_name);
    } else {
        printf("No se encontró nombre de autoridad.\n");
    }

    ldns_pkt_free(pkt);
    return 0;
}
