ldns_dnssec_rrs_print(3)

Paquete: ldns

Licencias: custom:BSD

ldns(3) Manual de funciones de biblioteca ldns(3)

NOMBRE

ldns_dnssec_rrs_new, ldns_dnssec_rrs_free, ldns_dnssec_rrs_add_rr, ldns_dnssec_rrs_print - funciones para ldns_dnssecrrs

SINOPSIS

#include <stdint.h>
#include <stdbool.h>

#include <ldns/ldns.h>


ldns_dnssec_rrs_new();

void ldns_dnssec_rrs_free(ldns_dnssec_rrs *rrs);

ldns_status ldns_dnssec_rrs_add_rr(ldns_dnssec_rrs *rrs, ldns_rr *rr);

void ldns_dnssec_rrs_print(FILE *out, const ldns_dnssec_rrs *rrs);

DESCRIPCIÓN

ldns_dnssec_rrs_new()

ldns_dnssec_rrs_free() Libera la lista de rrs, pero *no* los registros ldns_rr individuales contenidos en la lista

rrs: la estructura de datos a liberar

ldns_dnssec_rrs_add_rr() Añade un RR a la lista de RRs. La lista permanecerá ordenada. Si ya existe un RR igual, este RR no se añadirá.

rrs: la lista a la que añadir
rr: el RR a añadir
Devuelve LDNS_STATUS_OK en caso de éxito

ldns_dnssec_rrs_print() Imprime los rrs dados al descriptor de archivo

out: el descriptor de archivo al que imprimir
rrs: la lista de RRs a imprimir
