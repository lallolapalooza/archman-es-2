Devuelve ldns_dnssec_trust_tree *

ldns_dnssec_trust_tree_free() Libera la dnssec_trust_tree recursivamente

No hay liberación profunda; todos los datos en el árbol de confianza consisten en punteros a una data_chain

tree: El árbol a liberar

ldns_dnssec_trust_tree_depth() devuelve la profundidad del árbol de confianza

Devuelve La profundidad del árbol

ldns_dnssec_derive_trust_tree() Genera una dnssec_trust_tree para el rr dado a partir de la data_chain dada

Esto no clona los datos reales; No liberes la data_chain antes de haber terminado con este árbol

*data_chain: La cadena de la que derivar el árbol de confianza
*rr: El RR sobre el que será este árbol
Devuelve ldns_dnssec_trust_tree *

ldns_dnssec_trust_tree_contains_keys() Devuelve OK si hay una ruta de confianza en el árbol hacia uno de los RR DNSKEY o DS en la lista dada

\param *tree El árbol de confianza a buscar \param *keys Una ldns_rr_list de RRs DNSKEY y DS a buscar

Devuelve LDNS_STATUS_OK si hay una ruta de confianza hacia una de las claves, o el *primer* error encontrado si no hubo rutas

ldns_dnssec_trust_tree_print() Imprime la estructura dnssec_trust_tree en el flujo de archivo dado.

Si el estado de un enlace no es LDNS_STATUS_OK; se imprimen también el estado y las firmas relevantes

*out: El flujo de archivo donde imprimir
tree: El árbol de confianza a imprimir
tabs: Añade tabs*2 espacios al principio de cada línea
extended: Si es verdadero, añade pequeñas líneas explicativas a la salida

Acerca de Arch Linux

Arch Linux es una distribución de Linux independiente y flexible, diseñada para usuarios expertos que desean una experiencia personalizada y sin complicaciones. Se adhiere a principios de simplicidad, modernidad, pragmatismo, centralidad del usuario y versatilidad.

La filosofía de Arch Linux gira en torno a mantener el software lo más simple posible, permitiendo a los usuarios construir su sistema desde cero y adaptarlo a sus necesidades. Esto significa que no viene con una gran cantidad de aplicaciones preinstaladas, sino que los usuarios eligen e instalan el software que desean.

Características principales:

  • Simplicidad: Un sistema base minimalista y código limpio.
  • Modernidad: Software actualizado a las últimas versiones estables.
  • Pragmatismo: Soluciones prácticas y eficientes.
  • Centralidad del usuario: El usuario tiene control total sobre su sistema.
  • Versatilidad: Adecuado para una amplia gama de usos, desde servidores hasta estaciones de trabajo de escritorio.

Gestor de paquetes: Pacman

Arch Linux utiliza pacman, un gestor de paquetes avanzado que facilita la instalación, actualización y eliminación de software de forma eficiente. Permite gestionar dependencias y mantener el sistema al día con un solo comando.

Arch User Repository (AUR)

El AUR es un repositorio impulsado por la comunidad que contiene descripciones de paquetes (PKGBUILDs) que permiten a los usuarios compilar software adicional desde el código fuente utilizando la misma herramienta makepkg y las mismas capacidades de gestión de dependencias que pacman. Es una fuente inmensa de software no oficial.

Documentación: Arch Wiki

La Arch Wiki es una de las bases de conocimiento más completas y respetadas en el mundo de Linux. Proporciona guías de instalación detalladas, información sobre la configuración del sistema, resolución de problemas y tutoriales sobre una gran variedad de temas relacionados con Arch Linux.
