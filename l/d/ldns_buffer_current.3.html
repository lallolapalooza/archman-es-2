ldns_buffer_current(3)

Paquete: ldns

Licencias: custom:BSD

ldns(3) Manual de funciones de biblioteca ldns(3)

NOMBRE

ldns_buffer_limit, ldns_buffer_set_limit, ldns_buffer_capacity, ldns_buffer_set_capacity, ldns_buffer_reserve, ldns_buffer_at, ldns_buffer_begin, ldns_buffer_end, ldns_buffer_current - límites y punteros de búfer

SINOPSIS

#include <stdint.h>
#include <stdbool.h>

#include <ldns/ldns.h>

size_t ldns_buffer_limit(const ldns_buffer *buffer);

void ldns_buffer_set_limit(ldns_buffer *buffer, size_t limit);

size_t ldns_buffer_capacity(const ldns_buffer *buffer);

bool ldns_buffer_set_capacity(ldns_buffer *buffer, size_t capacity);

bool ldns_buffer_reserve(ldns_buffer *buffer, size_t amount);

uint8_t * ldns_buffer_at(const ldns_buffer *buffer, size_t at);

uint8_t * ldns_buffer_begin(const ldns_buffer *buffer);

uint8_t * ldns_buffer_end(const ldns_buffer *buffer);

uint8_t * ldns_buffer_current(const ldns_buffer *buffer);

DESCRIPCIÓN

ldns_buffer_limit() devuelve el tamaño máximo del búfer \param[in] buffer
Devuelve el tamaño

ldns_buffer_set_limit() cambia el límite del búfer. Si la posición del búfer es mayor que el nuevo límite, la posición se establece en el límite.
buffer: el búfer
limit: el nuevo límite

ldns_buffer_capacity() devuelve el número de bytes que puede contener el búfer.
buffer: el búfer
Devuelve el número de bytes

ldns_buffer_set_capacity() cambia la capacidad del búfer. Los datos se reasignan, por lo que los punteros a los datos pueden dejar de ser válidos. El límite del búfer se establece en la nueva capacidad del búfer.
buffer: el búfer
capacity: la capacidad a usar
Devuelve si esto falló o tuvo éxito

ldns_buffer_reserve() asegura que BUFFER pueda contener al menos CANTIDAD de bytes más. La capacidad del búfer se incrementa si es necesario usando buffer_set_capacity().

El límite del búfer siempre se establece en la capacidad (posiblemente incrementada).
buffer: el búfer
amount: cantidad a usar
Devuelve si esto falló o tuvo éxito

ldns_buffer_at() devuelve un puntero a los datos en la posición indicada.
buffer: el búfer
at: posición
Devuelve el puntero a los datos

ldns_buffer_begin() devuelve un puntero al principio del búfer (los datos en la posición 0).
buffer: el búfer
Devuelve el puntero

ldns_buffer_end() devuelve un puntero al final del búfer (los datos en el límite del búfer).
buffer: el búfer
Devuelve el puntero

ldns_buffer_current() devuelve un puntero a los datos en la posición actual del búfer.
buffer: el búfer
Devuelve el puntero
