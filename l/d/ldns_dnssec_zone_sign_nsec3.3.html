DESCRIPCIÓN

ldns_dnssec_zone_sign() firma la zona dada con las claves dadas

zone: la zona a firmar
key_list: la lista de claves para firmar la zona
new_rrs: los registros de recursos de nueva creación se añaden a esta lista, para liberarlos más tarde
func: función de devolución de llamada que decide qué hacer con las firmas antiguas. Esta función toma un ldns_rr* y un argumento void *arg opcional, y devuelve uno de cuatro valores: LDNS_SIGNATURE_LEAVE_ADD_NEW: dejar la firma y añadir una nueva para la clave correspondiente LDNS_SIGNATURE_REMOVE_ADD_NEW: eliminar la firma y reemplazarla por una nueva de la misma clave LDNS_SIGNATURE_LEAVE_NO_ADD: dejar la firma y no añadir una nueva con la clave correspondiente LDNS_SIGNATURE_REMOVE_NO_ADD: eliminar la firma y no reemplazarla

arg: argumento opcional para la función de devolución de llamada
Devuelve LDNS_STATUS_OK en caso de éxito, un código de error en caso contrario

ldns_dnssec_zone_sign_nsec3() firma la zona dada con la nueva zona dada, con NSEC3

zone: la zona a firmar
key_list: la lista de claves para firmar la zona
new_rrs: los registros de recursos de nueva creación se añaden a esta lista, para liberarlos más tarde
func: función de devolución de llamada que decide qué hacer con las firmas antiguas
arg: argumento opcional para la función de devolución de llamada
algorithm: el algoritmo de hash NSEC3 a utilizar
flags: banderas NSEC3
iterations: el número de iteraciones de hash NSEC3 a utilizar
salt_length: la longitud (en octetos) de la sal NSEC3
salt: los datos de la sal NSEC3
Devuelve LDNS_STATUS_OK en caso de éxito, un código de error en caso contrario

ldns_dnssec_zone_mark_glue()

ldns_dnssec_name_node_next_nonglue() Encuentra el primer nodo dnssec_name en el árbol rbtree que no está ocluido. Sí devuelve nombres que están parcialmente ocluidos.

node: el primer nodo a comprobar
Devuelve el primer nodo que no ha sido marcado como pegamento (glue), o NULL si no se encuentra (TODO: ¿hacerlo LDNS_RBTREE_NULL?)

ldns_dnssec_zone_create_nsecs() Añade registros NSEC a la dnssec_zone dada

zone: la zona a la que añadir los registros
new_rrs: los ldns_rr creados por esta función se añaden a esta lista de rr, para que el llamador pueda liberarlos más tarde
Devuelve LDNS_STATUS_OK en caso de éxito, un código de error en caso contrario

ldns_dnssec_remove_signatures() elimina firmas si la función de devolución de llamada lo indica

signatures: lista de firmas a comprobar, y posiblemente eliminar, dependiendo del valor de la devolución de llamada
key_list: estas se marcan para ser utilizadas o no, en el valor de retorno de la devolución de llamada
func: esta función se llama para especificar qué hacer con cada firma (y su clave correspondiente)
arg: Argumento opcional para la función de devolución de llamada
Devuelve un puntero a los nuevos rrs de firmas (el original pasado a esta función puede haber sido eliminado)

ldns_dnssec_zone_create_rrsigs() Añade firmas a la zona

zone: la zona a la que añadir Registros de Recursos RRSIG
new_rrs: los RRs RRSIG que se crean también se añaden a esta lista, para que el llamador pueda liberarlos más tarde
key_list: lista de claves con las que firmar.
func: Función de devolución de llamada para decidir qué claves usar y qué hacer con las firmas antiguas
arg: Argumento opcional para la función de devolución de llamada
Devuelve LDNS_STATUS_OK en caso de éxito, error en caso contrario
