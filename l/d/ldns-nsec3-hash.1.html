NOMBRE

ldns-nsec3-hash - imprime el hash NSEC3 para un nombre de dominio

SINOPSIS

ldns-nsec3-hash <nombre_dominio>

DESCRIPCIÓN

ldns-nsec3-hash se utiliza para imprimir el hash NSEC3 para el nombre de dominio dado.

OPCIONES

-a número
Utiliza el número de algoritmo dado para el cálculo del hash. Por defecto es 1 (SHA-1).
-s salt
Utiliza la sal (salt) dada para el cálculo del hash. El valor de la sal debe estar en formato hexadecimal.
-t conteo
Utiliza el conteo de iteraciones para el cálculo del hash.

AUTOR

Escrito por el equipo de ldns como un ejemplo de uso de ldns.
