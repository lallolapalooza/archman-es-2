ldns_dname_label(3)

Paquete: ldns

Licencias: custom:BSD

ldns(3) Manual de funciones de biblioteca ldns(3)

NOMBRE

ldns_dname_is_subdomain, ldns_dname_str_absolute, ldns_dname_label - comprobar propiedades de los dnames

SINOPSIS

#include <stdint.h>
#include <stdbool.h>

#include <ldns/ldns.h>

bool ldns_dname_is_subdomain(const ldns_rdf *sub, const ldns_rdf *parent);

bool ldns_dname_str_absolute(const char *dname_str);

ldns_rdf * ldns_dname_label(const ldns_rdf *rdf, uint8_t labelpos);

DESCRIPCIÓN

ldns_dname_is_subdomain() prueba si el nombre sub se encuentra bajo parent (es decir, si es un subdominio de parent). Esta función devolverá falso si los dnames dados son iguales.
sub: el nombre a probar
parent: el nombre del padre
Devuelve verdadero si sub está bajo parent, de lo contrario falso

ldns_dname_str_absolute() Comprueba si el dname dado la cadena es absoluta (es decir, termina con un '.')
*dname_str: una cadena que representa el dname
Devuelve verdadero o falso

ldns_dname_label() busca dentro del rdf y si es un LDNS_RDF_TYPE_DNAME intenta recuperar una etiqueta específica. Las etiquetas se numeran a partir de 0 (la más a la izquierda).
rdf: el rdf a buscar
labelpos: devuelve la etiqueta con este número
Devuelve un ldns_rdf* con la etiqueta como nombre o NULL en caso de error
