LDAPMODIFY(1) Manual de Comandos Generales LDAPMODIFY(1)

NOMBRE

ldapmodify, ldapadd - herramientas para modificar y añadir entradas LDAP

SINOPSIS

ldapmodify [-V[V]] [-d niveldebug] [-n] [-v] [-a] [-c] [-f archivo] [-j nrolinea] [-S archivo] [-M[M]] [-x] [-D binddn] [-W] [-w contraseña] [-y archivocontraseña] [-H ldapuri] [-P {2|3}] [-e [!]ext[=paramext]] [-E [!]ext[=paramext]] [-o opt[=paramopt]] [-O propiedades-seguridad] [-I] [-Q] [-N] [-U authcid] [-R realm] [-X authzid] [-Y mech] [-Z[Z]]

ldapadd [-V[V]] [-d niveldebug] [-n] [-v] [-c] [-f archivo] [-j nrolinea] [-S archivo] [-M[M]] [-x] [-D binddn] [-W] [-w contraseña] [-y archivocontraseña] [-H ldapuri] [-P {2|3}] [-e [!]ext[=paramext]] [-E [!]ext[=paramext]] [-o opt[=paramopt]] [-O propiedades-seguridad] [-I] [-Q] [-N] [-U authcid] [-R realm] [-X authzid] [-Y mech] [-Z[Z]]

DESCRIPCIÓN

ldapmodify es una interfaz accesible desde la línea de comandos para las llamadas a la biblioteca ldap_add_ext(3), ldap_modify_ext(3), ldap_delete_ext(3) y ldap_rename(3). ldapadd se implementa como un enlace físico a la herramienta ldapmodify. Cuando se invoca como ldapadd, la opción -a (añadir nueva entrada) se activa automáticamente.

ldapmodify abre una conexión a un servidor LDAP, se enlaza y modifica o añade entradas. La información de la entrada se lee de la entrada estándar o del archivo mediante el uso de la opción -f.

OPCIONES

-V[V]
Imprime información de la versión. Si se proporciona -VV, solo se imprime la información de la versión.
-d niveldebug
Establece el nivel de depuración LDAP a niveldebug. ldapmodify debe compilarse con LDAP_DEBUG definido para que esta opción tenga algún efecto.
-n
Muestra lo que se haría, pero no modifica las entradas. Útil para depurar junto con -v.
-v
Utiliza el modo detallado, con muchos diagnósticos escritos en la salida estándar.
-a
Añade nuevas entradas. El valor predeterminado para ldapmodify es modificar entradas existentes. Si se invoca como ldapadd, esta opción siempre está activada.
-c
Modo de operación continua. Los errores se informan, pero ldapmodify continuará con las modificaciones. El valor predeterminado es salir después de informar un error.
-f archivo
Lee la información de modificación de entrada de archivo en lugar de la entrada estándar.
-j nrolinea
Salta al número de línea especificado en el archivo LDIF antes de procesar ninguna entrada. Esto permite reanudar una carga que se interrumpió debido a errores en el LDIF de entrada después de corregir los errores.
-S archivo
Los registros añadidos o modificados que se omitieron debido a un error se escriben en archivo y el mensaje de error devuelto por el servidor se añade como un comentario. Muy útil en combinación con -c.
-M[M]
Habilita el control manage DSA IT. -MM hace que el control sea crítico.
-x
Utiliza autenticación simple en lugar de SASL.
-D binddn
Utiliza el Nombre Distinguido binddn para enlazarse al directorio LDAP. Para enlaces SASL, se espera que el servidor ignore este valor.
-W
Pregunta por la autenticación simple. Se utiliza en lugar de especificar la contraseña en la línea de comandos.
-w contraseña
Utiliza contraseña como la contraseña para la autenticación simple.
-y archivocontraseña
Utiliza el contenido completo de archivocontraseña como la contraseña para la autenticación simple.
-H ldapuri
Especifica URI(s) que hacen referencia al(los) servidor(es) LDAP; solo se permiten los campos de protocolo/host/puerto; se espera una lista de URIs, separadas por espacios en blanco o comas.
-P {2|3}
Especifica la versión del protocolo LDAP a utilizar.
-e [!]ext[=paramext]
-E [!]ext[=paramext]

Especifica extensiones generales con -e y extensiones de modificación con -E. ´!´ indica criticidad.

Extensiones generales:

  [!]assert=<filtro>    (un filtro RFC 4515)
  !authzid=<authzid>    ("dn:<dn>" o "u:<usuario>")
  [!]bauthzid           (control authzid RFC 3829)
  [!]chaining[=<resuelve>[/<cont>]]
  [!]manageDSAit
  [!]noop
  ppolicy
  [!]postread[=<attrs>] (una lista de atributos separada por comas)
  [!]preread[=<attrs>]  (una lista de atributos separada por comas)
  [!]relax
  sessiontracking[=<nombreusuario>]
  abandon,cancel,ignore (SIGINT envía abandon/cancel,
  o ignora la respuesta; si es crítico, no espera a SIGINT.
  no son realmente controles)

Extensiones de modificación:

  [!]txn[=abort|commit]
-o opt[=paramopt]]

Especifica cualquier opción de ldap.conf(5) o una de las siguientes:

  nettimeout=<timeout>  (en segundos, o "none" o "max")
  ldif_wrap=<ancho>     (en columnas, o "no" para no envolver)
-O propiedades-seguridad
Especifica propiedades de seguridad SASL.
-I
Habilita el modo interactivo SASL. Siempre pregunta. El valor predeterminado es preguntar solo cuando sea necesario.
-Q
Habilita el modo silencioso SASL. Nunca pregunta.
-N
No utiliza DNS inverso para canonizar el nombre de host SASL.
-U authcid
Especifica el ID de autenticación para el enlace SASL. La forma del ID depende del mecanismo SASL real utilizado.
-R realm
Especifica el dominio del ID de autenticación para el enlace SASL. La forma del dominio depende del mecanismo SASL real utilizado.
-X authzid
Especifica el ID de autorización solicitado para el enlace SASL. authzid debe tener uno de los siguientes formatos: dn:<nombre distinguido> o u:<nombredeusuario>
-Y mech
Especifica el mecanismo SASL que se utilizará para la autenticación. Si no se especifica, el programa elegirá el mejor mecanismo que conozca el servidor.
-Z[Z]
Emite la operación extendida StartTLS (Transport Layer Security). Si utilizas -ZZ
, el comando requerirá que la operación sea exitosa.

FORMATO DE ENTRADA

El contenido de archivo (o la entrada estándar si no se proporciona el flag -f en la línea de comandos) debe cumplir con el formato definido en ldif(5) (LDIF según lo definido en RFC 2849).

EJEMPLOS

Suponiendo que el archivo /tmp/entrymods existe y tiene el siguiente contenido:

    dn: cn=Modifícame,dc=ejemplo,dc=com
    changetype: modify
    replace: mail
    mail: modificado@ejemplo.com
    -
    add: title
    title: Gran Jefe
    -
    add: jpegPhoto
    jpegPhoto:< file:///tmp/modme.jpeg
    -
    delete: description
    -

El comando:

    ldapmodify -f /tmp/entrymods

reemplazará el contenido del atributo mail de la entrada "Modifícame" con el valor "modificado@ejemplo.com", añadirá un title de "Gran Jefe" y el contenido del archivo "/tmp/modme.jpeg" como jpegPhoto, y eliminará completamente el atributo description.

Suponiendo que el archivo /tmp/newentry existe y tiene el siguiente contenido:

    dn: cn=Barbara Jensen,dc=ejemplo,dc=com
    objectClass: person
    cn: Barbara Jensen
    cn: Babs Jensen
    sn: Jensen
    title: la gerente mítica más famosa del mundo
    mail: bjensen@ejemplo.com
    uid: bjensen

El comando:

    ldapadd -f /tmp/newentry

añadirá una nueva entrada para Babs Jensen, utilizando los valores del archivo /tmp/newentry.

Suponiendo que el archivo /tmp/entrymods existe y tiene el siguiente contenido:

    dn: cn=Barbara Jensen,dc=ejemplo,dc=com
    changetype: delete

El comando:

    ldapmodify -f /tmp/entrymods

eliminará la entrada de Babs Jensen.

DIAGNÓSTICOS

El estado de salida será cero si no ocurren errores. Los errores resultarán en un estado de salida distinto de cero y la escritura de un mensaje de diagnóstico en el error estándar.
