ldns_zone_set_rrs(3)

Paquete: ldns

Licencias: custom:BSD

ldns(3) Manual de funciones de biblioteca ldns(3)

NOMBRE

ldns_zone_set_rrs, ldns_zone_set_soa - establecer el contenido de ldns_zone

SINOPSIS

#include <stdint.h>
#include <stdbool.h>

#include <ldns/ldns.h>

void ldns_zone_set_rrs(ldns_zone *z, ldns_rr_list *rrlist);

void ldns_zone_set_soa(ldns_zone *z, ldns_rr *soa);

DESCRIPCIÓN

ldns_zone_set_rrs() Establece el contenido de la zona
z: la zona a la que se le asignará la nueva lista RR
rrlist: la lista RR a utilizar

ldns_zone_set_soa() Establece el registro SOA de la zona
z: la zona a la que se le asignará el nuevo SOA
soa: el SOA a establecer
