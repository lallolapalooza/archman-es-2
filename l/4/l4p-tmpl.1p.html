NOMBRE

l4p-tmpl - Imprime una configuración de plantilla Log4perl

SINOPSIS

l4p-tmpl >l4p.conf

DESCRIPCIÓN

l4p-tmpl imprime el texto de una configuración de plantilla Log4perl para iniciar un nuevo archivo de configuración de Log4perl.
