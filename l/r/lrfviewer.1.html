Cada vez que pases argumentos a lrfviewer que contengan espacios, encierra los argumentos entre comillas. Por ejemplo: "/alguna ruta/con espacios"

[OPCIONES]

--disable-hyphenation
Desactivar la separación de sílabas. Debería acelerar significativamente la renderización.
--help, -h
mostrar este mensaje de ayuda y salir
--profile
Perfilar el renderizador LRF
--verbose
Imprimir más información sobre el proceso de renderización
--version
mostrar el número de versión del programa y salir
--visual-debug
Activar ayudas visuales para depurar el motor de renderización
--white-background
Por defecto, el fondo es blanco roto ya que lo encuentro más agradable a la vista. Usa esta opción para hacer el fondo blanco puro.

    LRFVIEWER(1)

    NAME

    lrfviewer - display LRF files.

    SYNOPSIS

    lrfviewer [options] file...

    DESCRIPTION

    lrfviewer is a simple viewer for Sony’s SBFD format, commonly known as LRF.

    It is a fork of fbgs, which is a viewer for the same format. The original fbgs project has been inactive for many years, and lrfviewer aims to provide a more updated and maintained version.

    OPTIONS

    -h, --help
    Show help message and exit.
    -v, --version
    Show version information and exit.
    -p, --pages PAGES
    Specify the pages to view. PAGES can be a single page number, a range (e.g. 1-10), or a comma-separated list (e.g. 1,3,5-7).
    -f, --fullscreen
    Start the viewer in fullscreen mode.
    -s, --scroll SCROLL
    Set the scroll behavior. SCROLL can be 'vertical' or 'horizontal'. Default is 'vertical'.

    USAGE

    To open a file named example.lrf:

    lrfviewer example.lrf

    To open a specific page range:

    lrfviewer -p 5-10 example.lrf

    CONTROLS

    While the viewer is active:

    • Arrow keys: Navigate pages.
    • Page Up / Page Down: Go to the previous/next page.
    • Home / End: Go to the first/last page.
    • Spacebar: Go to the next page.
    • b: Go to the previous page.
    • q: Quit the viewer.
    • f: Toggle fullscreen mode.
