NOMBRE

lr_log2mail - envía un informe generado a partir de un archivo de registro por correo electrónico

SINOPSIS

lr_log2mail [opciones] servicio direcciones...

lr_log2report --version

lr_log2report --help [convertidores-dlf|formatos-salida|plantillas-informe]

OPCIONES

--help [sección]
Si no se proporciona ningún argumento, imprime información de uso y sale. El argumento puede ser uno de los siguientes:
convertidores-dlf
Imprime la lista de convertidores DLF disponibles y sale.
formatos-salida
Imprime la lista de formatos de salida disponibles y sale.
plantillas-informe
Imprime la lista de plantillas de informe disponibles y sale.
--version
Imprime la versión de Lire y sale.
--output-format|-o formato de salida
Selecciona el formato de salida en el que se generará el informe.
--template nombre
Utiliza la configuración de informe llamada nombre para generar el informe.
--log-file archivo_log
Selecciona el archivo de registro que se procesará en lugar de STDIN.
--subject|-s asunto
Establece el asunto del mensaje de correo electrónico. Por defecto es 'Tu informe de formato'.
--extra-file archivo
Un archivo de texto adicional que se enviará junto con el informe. Si el formato de salida es txt, se adjuntará al informe.

DESCRIPCIÓN

El comando lr_log2mail es similar al comando lr_log2report(1) con la diferencia de que el informe se envía por correo electrónico. El archivo de registro se lee desde STDIN o desde el archivo especificado usando la opción --log-file. El formato del archivo de registro se especifica usando el argumento convertidor_dlf. Utiliza la opción --help-dlf-converters para obtener una lista de todos los convertidores DLF disponibles actualmente. El resto de los argumentos se interpretan como direcciones de correo electrónico a las que se enviará el informe. En caso de que el registro se pase en formato comprimido, se descomprime sobre la marcha, utilizando gzip(1).

El informe se encapsulará en un correo electrónico MIME apropiado para el formato de salida. Por ejemplo, los informes ASCII se enviarán en línea, los informes PDF se enviarán como un archivo adjunto y los informes HTML deberían aparecer en línea en un lector de correo compatible con HTML.

Las cabeceras From y Reply-To en los correos electrónicos salientes se establecen con los valores de las variables de configuración lr_mail_from y lr_mail_replyto.

EJEMPLO

% lr_log2mail -s "Informe de bind8" bind8_query \
    root "Joe Usuario <joe@example.com>" < /var/log/query.log
