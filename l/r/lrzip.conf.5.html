NOMBRE

lrzip.conf - Archivo de configuración para lrzip

DESCRIPCIÓN

Si se utiliza, este archivo será leído por el programa lrzip, analizado y las opciones se pasarán al programa. Algunas opciones pueden ser anuladas en la línea de comandos. Otras son fijas.

El archivo de configuración debe llamarse lrzip.conf. El programa lrzip buscará el archivo automáticamente en uno de los tres lugares:

$PWD - Directorio actual
/etc/lrzip
$HOME/.lrzip
Los parámetros se establecen en el formato PARÁMETRO=VALOR, donde cualquier línea
que comience con un # o que esté en blanco será ignorada.
Los valores de los parámetros no distinguen entre mayúsculas y minúsculas, excepto
donde se especifique.

EJEMPLO DE ARCHIVO DE CONFIGURACIÓN

# Esto es un comentario.
# Tamaño de ventana de compresión en MB. Normalmente seleccionado por el programa. (-w)
# VENTANA = 20
# Nivel de compresión 1-9 (7 por defecto). (-L)
# NIVELDECOMPRESION = 7
# Usar ajuste -U, RAM ilimitada. Sí o No
# ILIMITADO = NO
# Método de compresión, rzip, gzip, bzip2, lzo, o lzma (por defecto), o zpaq. (-n -g -b -l --lzma -z)
# Si se especifica aquí, las opciones de línea de comandos no son utilizables.
# METODODECOMPRESION = lzma
# Realizar prueba LZO. Por defecto = SÍ (-T )
# PRUEBALZO = NO
# Comprobación de hash en la descompresión, (-c)
# COMPROBACIONHASH = SÍ
# Mostrar valor HASH en la compresión incluso si la verbosidad está desactivada, SÍ (-H)
# MOSTRARHASH = SÍ
# Directorio de salida por defecto (-O)
# DIRECTORIOSALIDA = ubicación
# Verbosidad, SÍ o MÁXIMO (v, vv)
# VERBOSIDAD = max
# Mostrar progreso a medida que se analiza el archivo, SÍ o no (NO = opción -q)
# MOSTRARPROGRESO = SÍ
# Establecer Niceness. 19 es el valor por defecto. El rango permitido es de -20 a 19 (-N)
# NICE = 19
# Conservar archivos de salida rotos o dañados, SÍ (-K)
# CONSERVARROTOS = SÍ
# Eliminar archivo fuente después de la compresión (-D)
# este parámetro y valor distinguen entre mayúsculas y minúsculas
# el valor debe ser SÍ para activar
# ELIMINARARCHIVOS = NO
# Reemplazar archivo lrzip existente al comprimir (-f)
# este parámetro y valor distinguen entre mayúsculas y minúsculas
# el valor debe ser SÍ para activar
# REEMPLAZARARCHIVO = SÍ 
# Anular el directorio temporal. Solo válido cuando se usa stdin/out o Prueba
# TMPDIR = /tmp
# Si usar cifrado en la compresión SÍ, NO (-e)
# CIFRAR = NO

NOTAS

Tenga cuidado al usar ELIMINARARCHIVOS o REEMPLAZARARCHIVO, ya que no se le advertirá y ¡lrzip simplemente eliminará la fuente o reemplazará el archivo de salida!
