lr_deanonymize(1)

Paquete: lire

Licencias: GPL-2.0-only

LR_DEANONYMIZE.IN(1) Documentación de Lire de LogReport LR_DEANONYMIZE.IN(1)

NOMBRE

lr_deanonymize - restaura datos anonimizados, utilizando un volcado como el producido por lr_anonymize(1)

SINOPSIS

lr_deanonymize nombre_base_archivo_volcado

DESCRIPCIÓN

lr_deanonymize se usa típicamente al recibir informes anonimizados de un respondedor. Consulte la sección "Procesamiento de los resultados del respondedor" en el capítulo "Uso de un respondedor" del Manual del Usuario de Lire para ver ejemplos de uso.

lr_deanonymize lee un archivo que contiene direcciones de correo electrónico, números IP y nombres de host anonimizados (típicamente un informe, generado a partir de un archivo de registro de un servicio de Internet) desde la entrada estándar, y imprime una versión "desanonimizada" de este archivo a la salida estándar. Lee su información para hacer esto a partir de un conjunto de bases de datos Berkeley DB, almacenadas en archivos cuyos nombres se derivan de nombre_base_archivo_volcado, como se produce por lr_anonymize(1).

EJEMPLO

Un 'archivo de registro' como por ejemplo:

blaat fkrf 1.2.3.4.in-addr.arpa] pietje@bigcompany.com bla 1 2 3 lj;agas;gag
blaat 1.2.3.4 fkrf 3.2.3.4.in-addr.arpa] bla 1 www.hotsex.com 2 3 lj;agas;gag 
jan@blaat.frut.com agagag
blaat fkrf 4.2.3.4.in-addr.arpa] bla pietje@bigcompany.com www.hotsex.com 
234.34.2.0 jan@blaat.frut.com 4.2.3.4.in-addr.arpa1 2 3 lj;agas;gag
blaat fkrf tweede 3.2.3.4.in-addr.arpa] bla 1.2.3.4 1 blablabla.com 
2 mdcc.cx 
3 lj;agas;gag

se anonimizará a:

blaat fkrf 1.0.0.10.in-addr.arpa] john.doe.1@example.com bla 1 2 3 lj;agas;gag
blaat 10.0.0.1 fkrf 2.0.0.10.in-addr.arpa] bla 1 1.example.com 2 3 lj;agas;gag 
john.doe.2@example.com agagag
blaat fkrf 3.0.0.10.in-addr.arpa] bla john.doe.1@example.com 1.example.com 
10.0.0.2 john.doe.2@example.com 3.0.0.10.in-addr.arpa1 2 3 lj;agas;gag
blaat fkrf tweede 2.0.0.10.in-addr.arpa] bla 10.0.0.1 1 2.example.com 
2 3.example.com 
3 lj;agas;gag

El volcado se verá así:

ip 234.34.2.0 10.0.0.2
ip 1.2.3.4 10.0.0.1
inaddr 3.2.3.4.in-addr.arpa 2.0.0.10.in-addr.arpa
inaddr 1.2.3.4.in-addr.arpa 1.0.0.10.in-addr.arpa
inaddr 4.2.3.4.in-addr.arpa 3.0.0.10.in-addr.arpa
domain mdcc.cx 3.example.com
domain blablabla.com 2.example.com
domain www.hotsex.com 1.example.com
email jan@blaat.frut.com john.doe.2@example.com
email pietje@bigcompany.com john.doe.1@example.com
