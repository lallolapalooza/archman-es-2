lrint(3) Manual de Funciones de Librería lrint(3)

NOMBRE

lrint, lrintf, lrintl, llrint, llrintf, llrintl - redondear al entero más cercano

LIBRERÍA

Librería matemática (libm, -lm)

SINOPSIS

#include <math.h>
long lrint(double x);
long lrintf(float x);
long lrintl(long double x);
long long llrint(double x);
long long llrintf(float x);
long long llrintl(long double x);
Requisitos de Macro de Prueba de Funcionalidad para glibc (ver feature_test_macros(7)):

Todas las funciones mostradas arriba:

    _ISOC99_SOURCE || _POSIX_C_SOURCE >= 200112L

DESCRIPCIÓN

Estas funciones redondean su argumento al valor entero más cercano, usando la dirección de redondeo actual (ver fesetround(3)).

Tenga en cuenta que a diferencia de las funciones de la familia rint(3), el tipo de retorno de estas funciones difiere del de sus argumentos.

VALOR DE RETORNO

Estas funciones devuelven el valor entero redondeado.

Si x es un NaN o un infinito, o si el valor redondeado es demasiado grande para ser almacenado en un long (long long en el caso de las funciones ll*), entonces ocurre un error de dominio y el valor de retorno no está especificado.

ERRORES

Ver math_error(7) para información sobre cómo determinar si ha ocurrido un error al llamar a estas funciones.

Los siguientes errores pueden ocurrir:

Error de dominio: x es un NaN o infinito, o el valor redondeado es demasiado grande
Se genera una excepción de punto flotante inválida (FE_INVALID).

Estas funciones no establecen errno.

ATRIBUTOS

Para una explicación de los términos utilizados en esta sección, ver attributes(7).

Interfaz Atributo Valor
lrint (), lrintf (), lrintl (), llrint (), llrintf (), llrintl () Seguridad en hilos MT-Safe

ESTÁNDARES

C11, POSIX.1-2008.

HISTORIA

glibc 2.1. C99, POSIX.1-2001.
