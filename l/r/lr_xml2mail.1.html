NOMBRE

lr_xml2mail - Formatea un informe XML y lo envía por correo electrónico

SINOPSIS

lr_xml2mail [opciones] informe.xml destinatario...

lr_xml2mail --version

lr_xml2mail --help [dlf-conversores|formatos-salida|plantillas-informe]

OPCIONES

--help [sección]
Si no se proporciona ningún argumento, imprime información de uso y sale. El argumento puede ser una de las siguientes opciones:
dlf-conversores
Imprime la lista de conversores DLF disponibles y sale.
formatos-salida
Imprime la lista de formatos de salida disponibles y sale.
plantillas-informe
Imprime la lista de plantillas de informes disponibles y sale.
--output-format formato de salida
Selecciona el formato de salida en el que se generará el informe.
--template nombre
Utiliza la plantilla de configuración de informes llamada nombre para fusionar los informes. Esta opción es obligatoria cuando se utiliza la opción --merge para fusionar informes.
--merge archivo_informe
Fusiona archivo_informe antes de formatear el informe. Esta opción se puede utilizar varias veces para fusionar más de dos informes.
--subject asunto
Establece el asunto del mensaje de correo electrónico. Por defecto es 'Tu informe formato'.
--extra-file archivo
Un archivo de texto adicional que se enviará junto con el informe. Si el formato de salida es txt, se adjuntará al informe.

DESCRIPCIÓN

lr_xml2mail formatea los informes XML generados por Lire a varios formatos de salida y los envía por correo electrónico a los destinatarios especificados como argumentos restantes.

El comando se asegurará de que el informe esté encapsulado en MIME correctamente según el formato de salida elegido. Por ejemplo, un informe PDF se enviará como archivo adjunto y la salida (X)HTML aparecerá como un mensaje de correo electrónico HTML. El tipo de contenido del mensaje MIME también se establecerá correctamente.

Las cabeceras From y Reply-To se inicializan a partir de las variables de configuración "lr_from" y "lr_reply_to".
