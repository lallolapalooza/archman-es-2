removexattr(2) Manual de llamadas al sistema removexattr(2)

NOMBRE

removexattr, lremovexattr, fremovexattr - eliminar un atributo extendido

BIBLIOTECA

Biblioteca C estándar (libc, -lc)

SINOPSIS

#include <sys/xattr.h>
int removexattr(const char *path, const char *name);
int lremovexattr(const char *path, const char *name);
int fremovexattr(int fd, const char *name);

DESCRIPCIÓN

Los atributos extendidos son pares de nombre:valor asociados con los inodos (archivos, directorios, enlaces simbólicos, etc.). Son extensiones de los atributos normales que se asocian con todos los inodos del sistema (es decir, los datos de stat(2)). Se puede encontrar una descripción completa de los conceptos de atributos extendidos en xattr(7).

removexattr() elimina el atributo extendido identificado por name y asociado con la ruta dada path en el sistema de archivos.

lremovexattr() es idéntica a removexattr(), excepto en el caso de un enlace simbólico, donde el atributo extendido se elimina del propio enlace, no del archivo al que apunta.

fremovexattr() es idéntica a removexattr(), solo que el atributo extendido se elimina del archivo abierto al que se refiere fd (devuelto por open(2)) en lugar de path.

Un nombre de atributo extendido es una cadena terminada en nulo. El name incluye un prefijo de espacio de nombres; puede haber varios espacios de nombres, disjuntos, asociados a un inodo individual.

VALOR DE RETORNO

En caso de éxito, se devuelve cero. En caso de error, se devuelve -1 y errno se establece para indicar el error.

ERRORES

ENODATA
El atributo nombrado no existe.
ENOTSUP
Los atributos extendidos no son compatibles con el sistema de archivos, o están deshabilitados.

Además, también pueden ocurrir los errores documentados en stat(2).

ESTÁNDARES

Linux.

HISTORIA

Linux 2.4, glibc 2.3.
