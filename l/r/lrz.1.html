NOMBRE

lrz - variante de línea de comandos compatible con gzip de lrzip

SINOPSIS

lrz [opciones] archivo

DESCRIPCIÓN

lrz es idéntico a la aplicación lrzip, sin embargo, sus opciones de línea de comandos y su comportamiento se han hecho lo más compatibles posible con gzip.

OPCIONES

Opciones generales

--stdout
-c
Salida a STDOUT.
--check
-C
Comprueba la integridad del archivo escrito al descomprimir.
--decompress
-d
Descomprimir.
--encrypt[=contraseña]
-e
Protección con contraseña mediante cifrado sha512/aes128 al comprimir.
--help
-h
-?
Muestra la ayuda.
--hash
-H
Muestra información de integridad hash md5.
--info
-i
Muestra información del archivo comprimido.
--license
-L
Muestra la versión del software y la licencia.
--progress
-P
Muestra el progreso de la compresión.
--recursive
-r
Opera recursivamente en directorios.
--test
-t
Prueba la integridad del archivo comprimido.
--verbose
-v[vv]
Aumenta la verbosidad.
--version
-V
Muestra la versión.

Opciones que afectan la salida

--force
-f
Fuerza la sobrescritura de archivos existentes.
--keep
-k
No elimina los archivos fuente al descomprimir/comprimir.
--keep-broken
-K
Mantiene los archivos de salida rotos o dañados.
--outfile nombre
-o nombre
Especifica el nombre y/o la ruta del archivo de salida.
--outdir dir
-O dir
Especifica el directorio de salida cuando no se usa -o.
--suffix sufijo
-S sufijo
Especifica el sufijo comprimido (por defecto '.lrz').

Opciones que afectan la compresión

--bzip2
-b
Compresión Bzip2.
--gzip
-g
Compresión Gzip usando zlib.
--lzo
-l
Compresión Lzo (ultrarrápida).
--lzma
Compresión Lzma (por defecto).
--no-compress
-n
Sin compresión de backend - prepara para otro compresor.
--zpaq
-z
Compresión Zpaq (la mejor, compresión extrema, extremadamente lenta).

Opciones de bajo nivel

-1 .. -9
--level nivel
-L nivel
Establece el nivel de compresión lzma/bzip2/gzip (1-9, por defecto 7).
--fast
Alias para -1.
--best
Alias para -9.
--nice-level valor
-N valor
Establece el valor de nice a valor (por defecto 0).
--threads valor
-P valor
Establece el número de procesadores para anular la cantidad de hilos.
--maxram tamaño
-m tamaño
Establece la RAM máxima disponible como tamaño * 100 MB. Anula la cantidad detectada de RAM disponible.
--threshold
-T
Deshabilita la prueba de compresibilidad LZ4.
--unlimited
-U
Usa un tamaño de ventana ilimitado más allá del tamaño de la RAM (potencialmente mucho más lento).
--window tamaño
-w tamaño
Establece el tamaño máximo de la ventana de compresión como tamaño * 100 MB. El valor por defecto se elige mediante heurística dependiente de la RAM y la compresión elegida.

Ver también lrzip(1)

AMBIENTE

lrz utiliza el mismo entorno y archivos de configuración que lrzip(1)
