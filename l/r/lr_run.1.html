NOMBRE

lr_run - ejecuta un programa Lire y maneja la salida de registro

SINOPSIS

lr_run programa argumentos

DESCRIPCIÓN

lr_run ejecuta programa y redirige la salida stderr del programa a logger(1). Analiza la salida de registro del programa y establece las banderas de logger(1) correspondientemente.

lr_run obtiene la configuración de sysconfdir/lire/defaults. En caso de que 'lr_logging_method' esté configurado a 'stderr', logger(1) no se involucra: la salida de registro se redirige a stderr. En caso de que 'lr_debug' esté configurado como una cadena vacía, los mensajes con nivel de registro debug e info se suprimen. La variable de configuración 'lr_logging_facility' se utiliza para encontrar la instalación de logger(1).

NOTAS

La salida del programa en stderr debe tener el formato superservicio servicio id nombre_programa nivel mensaje. El nivel debe ser uno de: emerg (el sistema es inutilizable), alert (se debe tomar acción inmediatamente), crit (condiciones críticas), err (condiciones de error), warning (condiciones de advertencia), notice (condición normal pero significativa), info (mensaje informativo), debug (mensaje a nivel de depuración). Ver syslog(3).

El id se puede usar para etiquetar cada trabajo de Lire, de modo que se puedan rastrear. nombre_programa debe ser el nombre del programa que generó la línea de registro.

EJEMPLOS

Para procesar un registro de Postfix y mostrar el informe como texto, use

$ lr_run lr_log2report postfix < /var/log/mail.log

Para procesar un registro de Postfix y crear el informe en HTML (empaquetado en un archivo tar), use:

$ lr_run lr_log2report -o html postfix < /var/log/mail.log > postfix.tar
