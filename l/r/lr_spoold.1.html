NOMBRE

lr_spoold - demonio, invocando lr_spool para todos los servicios periódicamente

SINOPSIS

lr_spoold

DESCRIPCIÓN

lr_spoold es típicamente invocado desde un script de inicio después de arrancar el sistema.

Debería iniciarse como

lr_run lr_spoold

bajo la cuenta de usuario de Lire. Esto se utiliza para mantener un respondedor en línea en ejecución. Consulte la sección "Instalación del respondedor" en el capítulo "Instalación de Lire" del Manual del Usuario de Lire para obtener detalles.

lr_spoold invoca lr_check_service(1) para obtener una lista de servicios, que se utilizan como direcciones para un respondedor en línea. Para cada dirección $service en esta lista, ejecuta

lr_spool $spooldir lr_processmail $service

periódicamente. $spooldir se construye utilizando profile_lean y la dirección.

Típicamente, spooldir es un subdirectorio `new' de Maildir, como por ejemplo

.../var/spool/lire/$address/Maildir/new/

.

En efecto, hacemos posible invocar lr_processmail con los argumentos correctos para cada mensaje, de modo que los archivos de registro en los mensajes sean procesados por el convertidor 2dlf correcto.

VER TAMBIÉN

lr_spool(1), lr_processmail(1)
