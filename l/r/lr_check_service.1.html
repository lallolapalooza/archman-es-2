NOMBRE

lr_check_service - comprueba la existencia del servicio Lire

SINOPSIS

lr_check_service servicio

lr_check_service -l

DESCRIPCIÓN

lr_check_service comprueba si el servicio servicio es soportado en Lire, es decir, si existe un conversor DLF registrado con ese nombre.

Cuando se llama con la opción -l (de `list', lista), lr_check_service lista todos los conversores DLF registrados.

Como todos los scripts de Lire, es posible que desees llamar a este script a través de lr_run(1), para tratar de forma razonable la salida de depuración y registro de este script.

Puede que prefieras las opciones --help de lr_log2report(1) para listar los servicios disponibles: este comando crea un formato más amigable para el usuario de la lista.

EJEMPLO

Llama a este script en scripts de shell como:

LR_SERVICE="$1"
LR_SERVICE=`lr_check_service "$LR_SERVICE" || true`
if test -z "$LR_SERVICE"
then
   echo >&2 "$tag err lr_check_service falló"
   exit 1
fi
# ahora usa $LR_SERVICE

.
