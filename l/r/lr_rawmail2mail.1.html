NOMBRE

lr_rawmail2mail - Desanonimiza y formatea un informe de un mensaje de correo electrónico

SINOPSIS

lr_rawmail2mail [opciones] prefijo_volcado direcciones...

lr_rawmail2mail -h

lr_rawmail2mail -v

OPCIONES

-h
Muestra información de uso y sale.
-i
Genera gráficos para todos los informes que lo admiten. Normalmente, los gráficos solo se generarán si la variable LR_INCLUDEIMAGES está establecida en 1.
-o formato_salida
Uno de pdf, html, html_page, xhtml, xhtml_page, txt, docbookx, rtf y xml. Por defecto, se genera una salida de texto simple.
-v
Muestra la versión de Lire y sale.

DESCRIPCIÓN

lr_rawmail2mail se puede utilizar para procesar automáticamente una respuesta de un Contestador en línea que contenga un informe XML. Extraerá el informe (que debería tener un tipo de contenido text/xml) y lo desanonimizará. Luego utilizará el comando lr_xml2mail(1) para formatear y enviar el informe a los destinatarios especificados en la línea de comandos.

El argumento prefijo_volcado es utilizado por lr_deanonymize(1) para encontrar la base de datos que se utilizó en el proceso de anonimización.

La variable de entorno TMPDIR, tal como se define en sysconfdir/defaults, se utiliza para almacenar archivos temporales; si LR_KEEP se establece en una cadena no vacía, se conservan los archivos temporales.
