LROUND(3P) Manual del programador de POSIX LROUND(3P)

PRÓLOGO

Esta página del manual forma parte del Manual del programador de POSIX. La implementación de esta interfaz en Linux puede diferir (consulte la página del manual de Linux correspondiente para conocer los detalles del comportamiento en Linux), o la interfaz puede no estar implementada en Linux.

NOMBRE

lround, lroundf, lroundl — redondear al valor entero más cercano

SINOPSIS

#include <math.h>
long lround(double x);
long lroundf(float x);
long lroundl(long double x);

DESCRIPCIÓN

La funcionalidad descrita en esta página de referencia está alineada con el estándar ISO C. Cualquier conflicto entre los requisitos descritos aquí y el estándar ISO C es involuntario. Este volumen de POSIX.1‐2017 remite al estándar ISO C.

Estas funciones redondearán su argumento al valor entero más cercano, redondeando los casos intermedios (a medio camino) alejándose de cero, independientemente de la dirección de redondeo actual.

Una aplicación que desee comprobar situaciones de error debe establecer errno a cero y llamar a feclearexcept(FE_ALL_EXCEPT) antes de llamar a estas funciones. Al regresar, si errno no es cero o si fetestexcept(FE_INVALID | FE_DIVBYZERO | FE_OVERFLOW | FE_UNDERFLOW) no es cero, se ha producido un error.

VALOR DE RETORNO

Al completarse con éxito, estas funciones devolverán el valor entero redondeado.

Si x es NaN, se producirá un error de dominio y se devolverá un valor no especificado.

Si x es +Inf, se producirá un error de dominio y se devolverá un valor no especificado.

Si x es -Inf, se producirá un error de dominio y se devolverá un valor no especificado.

Si el valor correcto es positivo y demasiado grande para ser representado como un long, se devolverá un valor no especificado. En sistemas que admiten la opción de punto flotante IEC 60559, se producirá un error de dominio; de lo contrario, puede producirse un error de dominio.

Si el valor correcto es negativo y demasiado grande para ser representado como un long, se devolverá un valor no especificado. En sistemas que admiten la opción de punto flotante IEC 60559, se producirá un error de dominio; de lo contrario, puede producirse un error de dominio.

ERRORES

Estas funciones fallarán si:

Error de Dominio
El argumento x es NaN o ±Inf, o el valor correcto no es representable como un entero.

Si la expresión entera (math_errhandling & MATH_ERRNO) no es cero, entonces errno se establecerá en [EDOM]. Si la expresión entera (math_errhandling & MATH_ERREXCEPT) no es cero, entonces se activará la excepción de punto flotante inválida.

Estas funciones pueden fallar si:

Error de Dominio
El valor correcto no es representable como un entero.

Si la expresión entera (math_errhandling & MATH_ERRNO) no es cero, entonces errno se establecerá en [EDOM]. Si la expresión entera (math_errhandling & MATH_ERREXCEPT) no es cero, entonces se activará la excepción de punto flotante inválida.

Las siguientes secciones son informativas.

EJEMPLOS

Ninguno.

USO DE LA APLICACIÓN

En caso de error, las expresiones (math_errhandling & MATH_ERRNO) y (math_errhandling & MATH_ERREXCEPT) son independientes entre sí, pero al menos una de ellas debe ser distinta de cero.

FUNDAMENTO

Estas funciones difieren de las funciones lrint() en la dirección de redondeo predeterminada, con las funciones lround() redondeando los casos intermedios alejándose de cero y sin necesidad de activar la excepción de punto flotante inexacta para argumentos no enteros que se redondean dentro del rango del tipo de retorno.
