NOMBRE

lr_log2report - genera un informe a partir de un archivo de registro

SINOPSIS

lr_log2report [opciones] convertidor_dlf [ archivo_registro ] [ archivo_salida ]

lr_log2report --version

lr_log2report --help [convertidores-dlf|formatos-salida|plantillas-informe]

OPCIONES

--help [sección]
Si no se proporciona ningún argumento, imprime información de uso y sale. El argumento puede ser uno de los siguientes:
convertidores-dlf
Imprime la lista de convertidores DLF disponibles y sale.
formatos-salida
Imprime la lista de formatos de salida disponibles y sale.
plantillas-informe
Imprime la lista de plantillas de informe disponibles y sale.
--version
Imprime la versión de Lire y sale.
--output-format|-o formato de salida
Selecciona el formato de salida en el que se generará el informe.
--template|-t nombre
Utiliza la configuración de informe llamada nombre para generar el informe.

DESCRIPCIÓN

lr_log2report lee un archivo de registro de STDIN o del argumento especificado y generará un informe Lire formateado en STDOUT o en el archivo de salida archivo_salida. El formato del archivo de registro se especifica utilizando el argumento convertidor_dlf. Utilice la opción --help convertidores-dlf para obtener una lista de todos los convertidores DLF disponibles actualmente.

En caso de que el registro se pase en un formato comprimido, se descomprime sobre la marcha, utilizando gzip(1).

ADVERTENCIA: Este comando genera datos binarios en la terminal para todos los formatos de salida excepto txt y xml. Debe redirigir la salida estándar a un archivo cuando utilice esos formatos de salida.

En el caso de que formato de salida sea html, el argumento archivo_salida se interpretará como un nombre de directorio. Este directorio se creará si es necesario y contendrá los diversos archivos html. En caso de que se omita este argumento, se generará un archivo tar(1) en STDOUT (pero consulte la sección de ERRORES).

ADVERTENCIA: Ejecutar este comando en archivos de registro grandes generalmente significa que necesitará mucho espacio libre en disco. Consulte Lire::LrCommand(3pm) para obtener detalles.

EJEMPLOS

Para procesar un registro de Postfix y mostrar el informe como texto, use

$ lr_log2report postfix /var/log/mail.log

Para procesar un registro de Postfix y crear un informe HTML en un directorio, use

$ lr_log2report -o html postfix /var/log/mail.log reporte-postfix

ERRORES

Si

--output html

se especifica, se deben especificar tanto archivo_registro como archivo_salida. Se admite la especificación de "-" (o "/dev/stdin") como archivo_registro. Así que esto

$ tai64nfrac < /var/log/qmail-send/current | \
   lr_log2report qmail --output html - /tmp/reporte

funcionará.
