NOMBRE

lr_environment - Exportar la configuración de Lire en forma de script de shell

SINOPSIS

eval `lr_environment`

DESCRIPCIÓN

El comando lr_environment se utiliza para importar la configuración de Lire en scripts de shell de Lire.

Todas las variables de configuración de Lire se escribirán en un formato que el shell pueda evaluar.

Los scripts de shell normalmente no tienen que usar este comando, ya que lo hace el archivo defaults que es fuente de cada comando.

Los nombres antiguos utilizados cuando la configuración se realizaba en scripts de shell también son exportados por este script para compatibilidad con versiones anteriores.
