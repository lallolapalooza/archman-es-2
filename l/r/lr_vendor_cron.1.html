NOMBRE

lr_vendor_cron - genera informes de Lire a partir de todos los archivos de registro conocidos en el sistema

SINOPSIS

lr_vendor_cron diario|semanal|mensual

DESCRIPCIÓN

lr_vendor_cron está diseñado para ser invocado por cron. En sistemas que soportan /etc/cron.d/, este script puede ser invocado creando /etc/cron.d/lire, el cual debería leer, por ejemplo:

02 5 * * * root /usr/sbin/lr_vendor_cron diario
22 5 * * 0 root /usr/sbin/lr_vendor_cron semanal
42 5 1 * * root /usr/sbin/lr_vendor_cron mensual

lr_vendor_cron lee los archivos /etc/sysconfig/lire.d/*.cfg y /etc/default/lire.d/*.cfg. Debería existir un archivo para cada archivo de registro. Los archivos deberían establecer las siguientes variables de shell:

daemon
el nombre de un binario que generó el registro específico. Esto se utiliza para probar si el archivo cfg es adecuado para el sistema actual. Si deseas generar un registro para el cual no hay demonio presente en el sistema actual, simplemente usa un marcador de posición como "daemon=/bin/true".
service
un servicio de Lire, por ejemplo, sendmail,
logfile
por ejemplo, /var/log/mail.log.1.gz,
filter
por ejemplo, 'gzip -dc' o 'zcat | grep sendmail', y
rotateperiod
uno de los argumentos soportados de lr_vendor_cron.
extraopts
opcional: opciones adicionales pasadas a lr_log2mail(1). Establece esto, por ejemplo, a '--template www_local'.

Después de analizar los archivos de configuración, lr_vendor_cron invoca lr_log2mail(1) en el archivo de registro filtrado con `filter'. La lectura y filtrado del registro se realizan como root, lr_log2mail se ejecuta como usuario lire, utilizando su(1). La salida se alimenta a logger(1).

SEGURIDAD

Se supone que lr_vendor_cron se ejecuta como root. Sin embargo, tenga en cuenta que este script se distribuye SIN NINGUNA GARANTÍA. Si no desea ejecutar dicho script como root, asegúrese de que su usuario lire tenga acceso de lectura a todos los archivos de registro que desee procesar y adapte este script. Suministramos este script principalmente para personas que compilan paquetes. En muchas distribuciones Unix y GNU/Linux, es difícil forzar la legibilidad de los archivos de registro por parte del usuario lire. Este script es principalmente una forma de solucionar esto.

VARIABLES DE ENTORNO

lr_vendor_cron respeta DEBUG, CONFDIR, PRIORITY (para la llamada a logger(1)), y LIREUSER. ¡Cuidado! PRIORITY tal como se usa aquí es independiente de LR_FACILITY tal como se establece en /etc/lire/defaults. Este script no utiliza ninguna de las configuraciones en /etc/lire/defaults.
