NOMBRE

lr_xml2report - Formatea un informe XML al formato de salida apropiado

SINOPSIS

lr_xml2report [opciones] [archivo_informe] [archivo_salida]

lr_xml2report --version

lr_xml2report --help [convertidores-dlf|formatos-salida|plantillas-informe]

OPCIONES

--help [sección]
Si no se proporciona ningún argumento, imprime información de uso y sale. El argumento puede ser uno de los siguientes:
convertidores-dlf
Imprime la lista de convertidores DLF disponibles y sale.
formatos-salida
Imprime la lista de formatos de salida disponibles y sale.
plantillas-informe
Imprime la lista de plantillas de configuración de informes disponibles y sale.
--output-format formato_salida
Selecciona el formato de salida en el que generar el informe.
--template nombre
Utiliza la plantilla de configuración de informes llamada nombre para fusionar los informes. Esta opción es obligatoria cuando se utiliza la opción --merge para fusionar informes.
--merge archivo_informe
Fusiona archivo_informe antes de formatear el informe. Esta opción se puede usar varias veces para fusionar más de dos informes.

DESCRIPCIÓN

lr_xml2report convierte los informes XML generados por Lire a varios formatos de salida.

El script se puede ejecutar como, por ejemplo:

lr_xml2report --output-format pdf --template print_default \
  --merge report.2.xml --merge report.1.xmlreport.3.xml > report.pdf

(en modo de múltiples archivos de entrada XML) o como

ejecutar lr_xml2report --output-format txt report.xml report.txt

(en modo de archivo de entrada XML único).
