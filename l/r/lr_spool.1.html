NOMBRE

lr_spool - alimentar archivos en un directorio de cola a un comando

SINOPSIS

lr_spool dirección_cola comando

DESCRIPCIÓN

Para cada archivo f en el directorio dirección_cola, lr_spool genera un LR_ID único, lo exporta como una variable de shell y ejecuta

comando < f

. Antes de ejecutar comando, f se mueve a $TMPDIR. Si comando sale con éxito, f se elimina (se asume que comando guarda la entrada estándar en un archivo, si así lo considera apropiado), de lo contrario, f se mueve a LR_FAILEDDIR.

En caso de que alguno de dirección_cola, TMPDIR o LR_FAILEDDIR no exista, se crea sobre la marcha.

Este script es invocado por lr_spoold(1), que utiliza lr_processmail(1) como comando.

ERRORES

El directorio dirección_cola se crea utilizando mkdir -p simple. Si dirección_cola debe ser parte de una estructura Maildir, solo se crea .../new/. Esto no es suficiente para un Maildir válido. En tal sistema, uno debe verificar manualmente si dirección_cola es parte de un Maildir válido y crearlo manualmente.

VER TAMBIÉN

lr_spoold(1), el Manual del Usuario de Lire, especialmente la sección Resumen.
