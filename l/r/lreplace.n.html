lreplace(n)

Paquete: tcl

Licencias: TCL

lreplace(n) Comandos integrados de Tcl lreplace(n)

NOMBRE

lreplace - Reemplaza elementos en una lista con nuevos elementos

SINOPSIS

lreplace lista primer último ?elemento elemento ...?

DESCRIPCIÓN

lreplace devuelve una nueva lista formada reemplazando cero o más elementos de lista con los argumentos elemento. primer y último son valores de índice que especifican los elementos primero y último del rango a reemplazar. Los valores de índice primer y último se interpretan igual que los valores de índice para el comando string index, admitiendo aritmética de índices simple e índices relativos al final de la lista. 0 se refiere al primer elemento de la lista y end se refiere al último elemento de la lista.

Si primer o último es menor que cero, se considera que se refiere a antes del primer elemento de la lista. Esto permite que lreplace añada elementos al principio de lista. Si primer o último indica una posición mayor que el índice del último elemento de la lista, se trata como si fuera un índice uno mayor que el último elemento. Esto permite que lreplace añada elementos al final de lista.

Si último es menor que primer, entonces los elementos especificados se insertarán en la lista antes del elemento especificado por primer sin eliminar ningún elemento.

Los argumentos elemento especifican cero o más elementos nuevos que se añadirán a la lista en lugar de los que fueron eliminados. Cada argumento elemento se convertirá en un elemento separado de la lista. Si no se especifican argumentos elemento, entonces los elementos entre primer y último simplemente se eliminan.

EJEMPLOS

Reemplazando un elemento de una lista por otro:

% lreplace {a b c d e} 1 1 foo
a foo c d e

Reemplazando dos elementos de una lista por tres:

% lreplace {a b c d e} 1 2 tres más elementos
a tres más elementos d e

Eliminando el último elemento de una lista en una variable:

% set var {a b c d e}
a b c d e
% set var [lreplace $var end end]
a b c d

Un procedimiento para eliminar un elemento dado de una lista:

proc lremove {listVariable value} {
    upvar 1 $listVariable var
    set idx [lsearch -exact $var $value]
    set var [lreplace $var $idx $idx]
}

Añadiendo elementos a la lista; ten en cuenta que end+2 se tratará inicialmente como si fuera 6 aquí, pero tanto ese como 12345 son mayores que el índice del último elemento, por lo que se comportan de forma idéntica:

% set var {a b c d e}
a b c d e
% set var [lreplace $var 12345 end+2 f g h i]
a b c d e f g h i
