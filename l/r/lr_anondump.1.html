NOMBRE

lr_anondump - volcar la base de datos creada por lr_anonymize(1)

SINOPSIS

lr_anondump archivo_db

DESCRIPCIÓN

lr_anondump toma el nombre de un archivo Berkeley DB (por ejemplo, /tmp/dump.email, creado por lr_anonymize(1)) como argumento y vuelca el contenido de este archivo a la salida estándar. Esto puede ser útil para depurar, o en caso de que simplemente tenga curiosidad.

VER TAMBIÉN

lr_anonymize(1), lr_deanonymize(1)
