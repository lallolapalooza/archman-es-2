NOMBRE

lr_report_cfg2xml - Convierte la configuración de informes antigua a XML

SINOPSIS

lr_report_cfg2xml I<superservicio> I<nombre> I<archivo_cfg_informe> > I<archivo_espec_xml>

DESCRIPCIÓN

El comando lr_report_cfg2xml convierte un archivo de configuración de informes como el utilizado en Lire versión 1.5 y anteriores a una plantilla de configuración de informes.

El script toma tres argumentos obligatorios:

superservicio
El superservicio utilizado por el archivo de configuración de informes.
nombre
El nombre de la plantilla que se generará.
archivo_cfg_informe
El archivo de configuración de informes a convertir.

Escribe en STDOUT un archivo de especificación de configuración de Lire. Este archivo de especificación contiene un elemento de configuración de informes llamado nombre. Su valor por defecto será idéntico al contenido del archivo de configuración de informes. Si instala este archivo en el sharedir/lire/templates, podrá instanciar configuraciones de informes utilizando esa plantilla desde la interfaz de lire(1).
