drand48_r(3) Manual de Funciones de Biblioteca drand48_r(3)

NOMBRE

drand48_r, erand48_r, lrand48_r, nrand48_r, mrand48_r, jrand48_r, srand48_r, seed48_r, lcong48_r - generar números pseudoaleatorios distribuidos uniformemente de forma reentrante

BIBLIOTECA

Biblioteca C estándar (libc, -lc)

SINOPSIS

#include <stdlib.h>
int drand48_r(struct drand48_data *restrict buffer,
              double *restrict result);
int erand48_r(unsigned short xsubi[3],
              struct drand48_data *restrict buffer,
              double *restrict result);
int lrand48_r(struct drand48_data *restrict buffer,
              long *restrict result);
int nrand48_r(unsigned short xsubi[3],
              struct drand48_data *restrict buffer,
              long *restrict result);
int mrand48_r(struct drand48_data *restrict buffer,
              long *restrict result);
int jrand48_r(unsigned short xsubi[3],
              struct drand48_data *restrict buffer,
              long *restrict result);
int srand48_r(long int seedval, struct drand48_data *buffer);
int seed48_r(unsigned short seed16v[3], struct drand48_data *buffer);
int lcong48_r(unsigned short param[7], struct drand48_data *buffer);
Requisitos de Macro de Prueba de Funciones para glibc (ver feature_test_macros(7)):

Todas las funciones mostradas:

    /* glibc >= 2.19: */ _DEFAULT_SOURCE
        || /* glibc <= 2.19: */ _SVID_SOURCE || _BSD_SOURCE

DESCRIPCIÓN

Estas funciones son los análogos reentrantes de las funciones descritas en drand48(3). En lugar de modificar el estado global del generador aleatorio, utilizan el búfer de datos suministrado.

Antes del primer uso, esta estructura debe inicializarse, por ejemplo, rellenándola con ceros o llamando a una de las funciones srand48_r(), seed48_r() o lcong48_r().

VALOR DE RETORNO

El valor de retorno es 0.

ESTÁNDARES

GNU.
