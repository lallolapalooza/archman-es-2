lrange(n)

Paquete: tcl

Licencias: TCL

lrange(n) Comandos integrados de Tcl lrange(n)

NOMBRE

lrange - Devolver uno o más elementos adyacentes de una lista

SINOPSIS

lrange lista primer último

DESCRIPCIÓN

Lista debe ser una lista Tcl válida. Este comando devolverá una nueva lista que consta de los elementos primer a último, inclusive. Los valores de índice primer y último se interpretan igual que los valores de índice para el comando string index, admitiendo aritmética simple de índices e índices relativos al final de la lista. Si primer es menor que cero, se trata como si fuera cero. Si último es mayor o igual que el número de elementos en la lista, entonces se trata como si fuera end. Si primer es mayor que último, se devolverá una cadena vacía. Nota: “lrange lista primer primer” no siempre produce el mismo resultado que “lindex lista primer” (aunque a menudo lo hace para campos simples que no están entre llaves); sin embargo, produce exactamente los mismos resultados que “list [lindex lista primer]”

EJEMPLOS

Seleccionar los dos primeros elementos:

% lrange {a b c d e} 0 1
a b

Seleccionar los últimos tres elementos:

% lrange {a b c d e} end-2 end
c d e

Seleccionar todo excepto el primer y el último elemento:

% lrange {a b c d e} 1 end-1
b c d

Seleccionar un solo elemento con lrange no es lo mismo que hacerlo con lindex:

% set var {some {elements to} select}
some {elements to} select
% lindex $var 1
elements to
% lrange $var 1 1
{elements to}
