NOMBRE

lr_processmail - lee un mensaje de correo electrónico e invoca lr_log2mail(1)

SINOPSIS

lr_processmail servicio

DESCRIPCIÓN

lr_processmail lee un mensaje de correo electrónico desde STDIN, analiza el mensaje utilizando lr_getbody(1) e invoca lr_log2mail(1) para procesar el archivo de registro extraído.

La variable de entorno LR_ID se utiliza como identificador, que aparece en los mensajes de depuración y en los nombres de los archivos temporales, para que los trabajos de Lire puedan ser rastreados. Un trabajo de Lire se identifica actualmente con un mensaje de correo electrónico o un archivo de registro.

Este script es invocado por lr_spool(1).

Los archivos especificados en las variables de configuración lr_mail_signature y lr_mail_disclaimer se envían junto con el informe generado.

Si ocurre un error en el proceso de generación del informe, se enviará un mensaje de correo electrónico explicando las posibles causas del error a las direcciones de correo electrónico.

El formato -o xml es útil en el caso de que el archivo de registro se haya anonimizado, para que pueda ser desanonimizado antes de ser formateado utilizando lr_xml2report(1) o lr_xml2mail(1). Al usar ese formato, el archivo especificado en la variable de configuración lr_mail_explanation se incluirá en el mensaje saliente.

EJEMPLO

$ lr_processmail combined < /var/spool/lire/done/985327208.21242.mailhost

VER TAMBIÉN
