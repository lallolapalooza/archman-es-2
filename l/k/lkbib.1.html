lkbib(1) Manual de Comandos Generales lkbib(1)

Nombre

lkbib - buscar bases de datos bibliográficas

Sinopsis

lkbib [-n] [-i campos] [-p archivo] ... [-t n] clave ...
lkbib --help
lkbib -v
lkbib --version

Descripción

lkbib busca en bases de datos bibliográficas referencias que contengan las palabras clave clave y escribe cualquier referencia encontrada en el flujo de salida estándar. Lee las bases de datos proporcionadas por las opciones -p y luego (a menos que se indique -n) una base de datos predeterminada. La base de datos predeterminada se toma de la variable de entorno REFER si está configurada, de lo contrario es /usr/dict/papers/Ind. Para cada archivo de base de datos a buscar, si existe un archivo de índice .i creado por indxbib(1), entonces se buscará en él en su lugar; cada índice puede cubrir múltiples bases de datos.

Opciones

--help muestra un mensaje de uso, mientras que -v y --version muestran información de la versión; todas salen después.

-i cadena
Al buscar archivos para los que no existe índice, ignora el contenido de los campos cuyos nombres están en cadena.
-n
Suprime la búsqueda en la base de datos predeterminada.
-p archivo
Busca en archivo. Se pueden usar múltiples opciones -p.
-t n
Requiere que solo se proporcionen los primeros n caracteres de las claves. El valor predeterminado es 6.

Entorno

REFER
Base de datos predeterminada.

Archivos

/usr/dict/papers/Ind
Base de datos predeterminada que se utilizará si la variable de entorno REFER no está configurada.
archivo.i
Archivos de índice.

Ver también

“Some Applications of Inverted Indexes on the Unix System”, por M. E. Lesk, 1978, AT&T Bell Laboratories Computing Science Technical Report No. 69.
