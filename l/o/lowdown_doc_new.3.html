LOWDOWN_DOC_NEW(3) Manual de funciones de biblioteca LOWDOWN_DOC_NEW(3)

NOMBRE

lowdown_doc_new — asigna un analizador de Markdown

BIBLIOTECA

biblioteca “liblowdown”

SINOPSIS

#include <sys/queue.h>
#include <stdio.h>
#include <lowdown.h>

struct lowdown_doc *
lowdown_doc_new(const struct lowdown_opts *opts);

DESCRIPCIÓN

Asigna una instancia del analizador de Markdown con la configuración opts. Si opts es NULL, se asume que todos los valores son cero excepto la profundidad máxima de análisis, que está fijada en 128.

La instancia devuelta puede usarse con múltiples invocaciones de lowdown_doc_parse(3).

VALORES DEVUELTOS

Devuelve un puntero al analizador o NULL en caso de fallo de asignación de memoria. El puntero devuelto debe liberarse con una llamada a lowdown_doc_free(3).

Los valores de puntero en opts, como los de meta y metaovr, se copian, por lo que no necesitan persistir una vez que se pasan a lowdown_doc_new().

EJEMPLOS

Lo siguiente analiza b si tiene longitud bsz y descarta el resultado.

struct lowdown_doc *doc;
struct lowdown_node *n;

if ((doc = lowdown_doc_new(NULL)) == NULL)
	err(1, NULL);
if ((n = lowdown_doc_parse(doc, NULL, b, bsz, NULL)) == NULL)
	err(1, NULL);

lowdown_node_free(n);
lowdown_doc_free(doc);

VER TAMBIÉN

lowdown(3), lowdown_doc_free(3), lowdown_doc_parse(3)
