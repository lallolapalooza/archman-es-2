lowdown_nroff_free(3)

Paquete: lowdown

Licencias: ISC

LOWDOWN_NROFF_FREE(3) Manual de funciones de biblioteca LOWDOWN_NROFF_FREE(3)

NOMBRE

lowdown_nroff_free — liberar un renderizador roff de Markdown

BIBLIOTECA

biblioteca “liblowdown”

SINOPSIS

#include <sys/queue.h>
#include <stdio.h>
#include <lowdown.h>

void
lowdown_nroff_free(void *arg);

DESCRIPCIÓN

Libera el renderizador roff creado con lowdown_nroff_new(3). Si arg es NULL, la función no hace nada.

EJEMPLOS

Lo siguiente analiza b de longitud bsz y genera la salida en formato groff_ms(7).

struct lowdown_buf *out;
struct lowdown_doc *doc;
struct lowdown_node *n;
void *rndr;

if ((doc = lowdown_doc_new(NULL)) == NULL)
	err(1, NULL);
if ((n = lowdown_doc_parse(doc, NULL, b, bsz, NULL)) == NULL)
	err(1, NULL);
if ((out = lowdown_buf_new(256)) == NULL)
	err(1, NULL);
if ((rndr = lowdown_nroff_new(NULL)) == NULL)
	err(1, NULL);
if (!lowdown_nroff_rndr(out, rndr, n))
	err(1, NULL);

fwrite(out->data, 1, out->size, stdout);

lowdown_nroff_free(rndr);
lowdown_buf_free(out);
lowdown_node_free(n);
lowdown_doc_free(doc);

VER TAMBIÉN

lowdown(3), lowdown_nroff_new(3)

Esto utiliza tanto las macros man originales de troff para Version 7 AT&T UNIX, definidas en man(7), como las extensiones man-ext de groff. Ambas están implementadas en mandoc.

Las macros ms de troff están definidas en groff_ms(7), con las extensiones mspdf de groff descritas en "Portable Document Format Publishing with GNU Troff" por Keith Marshall. Ninguna está implementada en mandoc.
