lowdown_term_new(3)

Paquete: lowdown

Licencias: ISC

LOWDOWN_TERM_NEW(3) Manual de Funciones de Biblioteca LOWDOWN_TERM_NEW(3)

NOMBRE

lowdown_term_new — asigna un renderizador de terminal Markdown

BIBLIOTECA

biblioteca “liblowdown”

SINOPSIS

#include <sys/queue.h>
#include <stdio.h>
#include <lowdown.h>

void *
lowdown_term_new(const struct lowdown_opts *opts);

DESCRIPCIÓN

Asigna un renderizador de terminal utilizando variables en la estructura struct lowdown_opts_term. Sus campos están documentados en lowdown(3). El puntero devuelto puede usarse con múltiples invocaciones de lowdown_term_rndr(3) y debe liberarse con lowdown_term_free(3).

Los bits reconocidos en opts->oflags son LOWDOWN_TERM_SHORTLINK, LOWDOWN_TERM_NOCOLOUR y LOWDOWN_TERM_NOLINK.

VALORES DE RETORNO

Devuelve un puntero al renderizador o NULL en caso de fallo de memoria. El puntero devuelto debe liberarse con lowdown_term_free(3).

EJEMPLOS

Lo siguiente analiza b de longitud bsz y genera salida en formato de terminal ANSI.

struct lowdown_buf *out;
struct lowdown_doc *doc;
struct lowdown_node *n;
void *rndr;

if (setlocale(LC_CTYPE, "en_US.UTF-8") == NULL)
	err(1, NULL);

if ((doc = lowdown_doc_new(NULL)) == NULL)
	err(1, NULL);
if ((n = lowdown_doc_parse(doc, NULL, b, bsz, NULL)) == NULL)
	err(1, NULL);
if ((out = lowdown_buf_new(256)) == NULL)
	err(1, NULL);
if ((rndr = lowdown_term_new(NULL)) == NULL)
	err(1, NULL);
if (!lowdown_term_rndr(out, rndr, n))
	err(1, NULL);

fwrite(out->data, 1, out->size, stdout);

lowdown_term_free(rndr);
lowdown_buf_free(out);
lowdown_node_free(n);
lowdown_doc_free(doc);

VER TAMBIÉN

lowdown(3), lowdown_term_free(3), lowdown_term_rndr(3)

ESTÁNDARES

Los códigos de escape ANSI se describen en ISO/IEC 6429, anteriormente ECMA-48.

Los hipervínculos se formatean según lo definido por las secuencias de enlace OSC (Comando del Sistema Operativo), que se ignorarán para los terminales ECMA-48 que no estén configurados para mostrar enlaces.
