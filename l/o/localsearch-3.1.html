LOCALSEARCH-3(1) Manual de LocalSearch LOCALSEARCH-3(1)

NOMBRE

localsearch-3 - Indexador del sistema de archivos.

SINOPSIS

localsearch-3 [OPCIÓN...]

DESCRIPCIÓN

localsearch-3 no está pensado para ser ejecutado por el usuario, ya que es iniciado por systemd cuando el usuario inicia sesión. Por supuesto, también puede iniciarse manualmente con fines de depuración. No se puede ejecutar más de una instancia de esto al mismo tiempo.

localsearch-3 extrae información solo sobre aplicaciones y archivos.

OPCIONES

-?, --help

Muestra un resumen de las opciones.

-V, --version

Devuelve la versión de este binario.

-n, --no-daemon

Indica al indexador que salga una vez que haya terminado todo el indexado y la base de datos esté actualizada. Este no es el modo de operación predeterminado para el indexador; normalmente permanece activo como un demonio para monitorear las actualizaciones de archivos que puedan ocurrir con el tiempo. Esta opción deja sin efecto la opción --initial-sleep.

-e, --eligible=ARCHIVO

Verifica si ARCHIVO es elegible para ser procesado según las reglas de configuración actuales. Además de esto, verificará si ARCHIVO será monitoreado para detectar cambios. Esto funciona tanto con argumentos de ARCHIVO inexistentes como existentes.

INTEGRACIÓN DE ESCRITORIO

Los entornos de escritorio que hacen uso de localsearch-3 deberían iniciar la unidad de usuario localsearch-3.service al inicio. Por ejemplo, las sesiones gestionadas por gnome-session pueden agregar este servicio como una dependencia Wants= en su archivo gnome-session@name.target.d/session.conf.

Esto permite a las sesiones deshabilitar el indexado en segundo plano del sistema de archivos (simplemente no iniciando localsearch-3.service) en situaciones donde no es necesario (es decir, sesiones especiales de quiosco).
