LOCALSEARCH-STATUS(1) Manual de LocalSearch LOCALSEARCH-STATUS(1)

NOMBRE

localsearch-status - Proporciona estado y estadísticas sobre los datos indexados

SINOPSIS

localsearch status
localsearch status [[expresión1]...]
localsearch status --stat [-a]

DESCRIPCIÓN

Muestra el estado del índice actual y el conjunto de datos. También se muestra un resumen de los fallos registrados durante la indexación de metadatos de archivos.

Proporcionar una expresión de búsqueda listará los detalles completos de los fallos registrados que coincidan con el nombre del archivo.

Con la opción --stat, se muestran estadísticas sobre las clases RDF y cuántas de cada una existen para el conjunto de datos que se ha indexado. Por ejemplo, "10 Carpetas".

OPCIONES

--stat

Lista estadísticas de clases RDF almacenadas (por ejemplo, "nfo:Document" o "nfo:Folder") por grafo.

-f, --follow

Sigue los cambios de estado de los demonios a medida que ocurren. Esta es una vista de alto nivel de lo que está sucediendo. Verá el nombre de cada demonio y un estado con el progreso en ese estado. Esto requiere Ctrl+C para detener y volver a la línea de comandos.

-w, --watch

Observa los cambios que ocurren en la base de datos en tiempo real. Esto requiere Ctrl+C para detener y volver a la línea de comandos.

Esta opción se implica si se proporcionan términos de búsqueda para filtrar TODAS las estadísticas posibles.

VéASE TAMBIÉN

localsearch daemon(1), localsearch info(1).
