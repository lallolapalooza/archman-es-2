off_t(3type) off_t(3type)

NOMBRE

off_t, off64_t, loff_t - tamaños de archivo

BIBLIOTECA

Biblioteca C estándar (libc)

SINOPSIS

#include <sys/types.h>
typedef /* ... */  off_t;
#define _LARGEFILE64_SOURCE
#include <sys/types.h>
typedef /* ... */  off64_t;
#define _GNU_SOURCE
#include <sys/types.h>
typedef /* ... */  loff_t;

DESCRIPCIÓN

off_t se utiliza para describir tamaños de archivo. Es un tipo entero con signo.

off64_t es una versión de 64 bits del tipo, utilizada en glibc.

loff_t es una versión de 64 bits del tipo, introducida por el kernel de Linux.

ESTANDARES

off_t
POSIX.1-2024.
off64_t
GNU y algunos BSD.
loff_t
Linux.

VERSIONES

off_t
POSIX.1-2001.

<aio.h> y <stdio.h> definen off_t desde POSIX.1-2008.

NOTAS

En algunas arquitecturas, el ancho de off_t se puede controlar con la macro de prueba de características _FILE_OFFSET_BITS.

Las siguientes cabeceras también proporcionan off_t: <aio.h>, <fcntl.h>, <stdio.h>, <sys/mman.h>, <sys/stat.h> y <unistd.h>.
