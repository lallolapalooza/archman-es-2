logb(3) Manual de funciones de biblioteca logb(3)

NOMBRE

logb, logbf, logbl - obtener el exponente de un valor de punto flotante

BIBLIOTECA

Biblioteca matemática (libm, -lm)

SINOPSIS

#include <math.h>
double logb(double x);
float logbf(float x);
long double logbl(long double x);
Requisitos de macros de prueba de características para glibc (ver feature_test_macros(7)):

logb():

    _ISOC99_SOURCE || _POSIX_C_SOURCE >= 200112L
        || _XOPEN_SOURCE >= 500
        || /* Desde glibc 2.19: */ _DEFAULT_SOURCE
        || /* glibc <= 2.19: */ _BSD_SOURCE || _SVID_SOURCE

logbf(), logbl():

    _ISOC99_SOURCE || _POSIX_C_SOURCE >= 200112L
        || /* Desde glibc 2.19: */ _DEFAULT_SOURCE
        || /* glibc <= 2.19: */ _BSD_SOURCE || _SVID_SOURCE

DESCRIPCIÓN

Estas funciones extraen el exponente de la representación interna de punto flotante de x y lo devuelven como un valor de punto flotante. La constante entera FLT_RADIX, definida en <float.h>, indica la base utilizada para la representación de punto flotante del sistema. Si FLT_RADIX es 2, logb(x) es similar a floor(log2(fabs(x))), excepto que este último puede dar un entero incorrecto debido al redondeo intermedio.

Si x es subnormal, logb() devuelve el exponente que x tendría si estuviera normalizado.

VALOR DE RETORNO

En caso de éxito, estas funciones devuelven el exponente de x.

Si x es un NaN, se devuelve un NaN.

Si x es cero, entonces ocurre un error de polo y las funciones devuelven -HUGE_VAL, -HUGE_VALF o -HUGE_VALL, respectivamente.

Si x es infinito negativo o infinito positivo, se devuelve infinito positivo.

ERRORES

Consulte math_error(7) para obtener información sobre cómo determinar si ha ocurrido un error al llamar a estas funciones.

Los siguientes errores pueden ocurrir:

Error de polo: x es 0
Se genera una excepción de punto flotante de división por cero (FE_DIVBYZERO).

Estas funciones no establecen errno.

ATRIBUTOS

Para una explicación de los términos utilizados en esta sección, consulte attributes(7).

Interfaz Atributo Valor
logb (), logbf (), logbl () Seguridad en hilos MT-Safe
