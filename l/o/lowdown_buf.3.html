LOWDOWN_BUF(3) Manual de funciones de la biblioteca LOWDOWN_BUF(3)

NOMBRE

lowdown_buf — analizar un búfer de Markdown en salida formateada

BIBLIOTECA

biblioteca “liblowdown”

SINOPSIS

#include <sys/queue.h>
#include <stdio.h>
#include <lowdown.h>

int
lowdown_buf(const struct lowdown_opts *opts, const char *buf, size_t bufsz, char **ret, size_t *retsz, struct lowdown_metaq *metaq);

DESCRIPCIÓN

Analiza un búfer de lowdown(5) buf de tamaño bufsz en un búfer de salida ret de tamaño retsz según una configuración opts. El formato de salida se especifica en opts->type. Si LOWDOWN_METADATA está establecido en opts->feat y metaq no es NULL, metaq se rellena con metadatos renderizados en el formato de salida dado.

El llamante es responsable de liberar ret y metaq.

VALORES DE RETORNO

Retorna cero en caso de fallo, distinto de cero en caso de éxito. En caso de fallo, los valores apuntados por res y rsz no están definidos.

EJEMPLOS

El siguiente código analiza la entrada estándar en un documento HTML5 autónomo. Habilita notas al pie, enlaces automáticos, tablas, superíndices, tachado, bloques de código delimitados, commonmark, listas de definición, atributos de imagen extendidos y procesamiento de metadatos. La salida pasa a través de HTML crudo y tiene tipografía inteligente.

struct lowdown_opts opts;
char *buf = NULL, *obuf;
char rbuf[1024];
size_t sz, bufsz = 0, obufsz;

while (!(feof(stdin) || ferror(stdin))) {
	sz = fread(rbuf, 1, sizeof(rbuf), stdin);
	if (sz == 0)
		err(1, "fread");
	buf = realloc(buf, bufsz + sz);
	if (buf == NULL)
		err(1, NULL);
	memcpy(buf + bufsz, rbuf, sz);
	bufsz += sz;
}

if (ferror(stdin))
	err(1, "fread");

memset(&opts, 0, sizeof(struct lowdown_opts));
opts.type = LOWDOWN_HTML;
opts.feat = LOWDOWN_FOOTNOTES |
	LOWDOWN_AUTOLINK |
	LOWDOWN_TABLES |
	LOWDOWN_SUPER |
	LOWDOWN_STRIKE |
	LOWDOWN_FENCED |
	LOWDOWN_COMMONMARK |
	LOWDOWN_DEFLIST |
	LOWDOWN_IMG_EXT |
	LOWDOWN_METADATA;
opts.oflags = LOWDOWN_HTML_HEAD_IDS |
	LOWDOWN_HTML_NUM_ENT |
	LOWDOWN_HTML_OWASP |
	LOWDOWN_SMARTY |
	LOWDOWN_STANDALONE;
if (!lowdown_buf(&opts, buf, bufsz, &obuf, &obufsz, NULL))
	errx(1, "lowdown_buf");
fwrite(buf, 1, bufsz, stdout);
free(buf);
free(obuf);
