LOWDOWN_FILE_DIFF(3) Manual de funciones de biblioteca LOWDOWN_FILE_DIFF(3)

NOMBRE

lowdown_file_diff — analiza y compara archivos Markdown en una salida con formato

BIBLIOTECA

biblioteca “liblowdown”

SINOPSIS

#include <sys/queue.h>
#include <stdio.h>
#include <lowdown.h>

int
lowdown_file_diff(const struct lowdown_opts *opts, FILE *fnew, FILE *fold, char **ret, size_t *retsz);

DESCRIPCIÓN

Analiza los flujos de archivos lowdown(5) fnew y fold y produce un script de edición en ret de tamaño retsz según las configuraciones opts. El formato de salida se especifica mediante opts->type.

En caso de éxito, el llamador es responsable de liberar ret.

VALORES DE RETORNO

Devuelve cero en caso de fallo, distinto de cero en caso de éxito. El fallo ocurre cuando la lectura del archivo falla o por agotamiento de memoria. En caso de fallo, el contenido de ret y retsz no está definido.
