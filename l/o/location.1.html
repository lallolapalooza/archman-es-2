NOMBRE

location - Consulta la base de datos de ubicaciones

SINOPSIS

location export --directory=DIR [--format=FORMAT] [--family=ipv6|ipv4] [ASN|CC ...]
location get-as ASN [ASN...]
location list-countries [--show-name] [--show-continent]
location list-networks-by-as ASN
location list-networks-by-cc CODIGO_PAIS
location list-networks-by-flags [--anonymous-proxy|--satellite-provider|--anycast|--drop]
location lookup DIRECCION [DIRECCION...]
location search-as CADENA
location update [--cron=daily|weekly|monthly]
location verify
location version

DESCRIPCION

location recupera información de la base de datos de ubicaciones. Estos datos se pueden utilizar para determinar la ubicación de alguien en Internet y para construir conjuntos de reglas de firewall para bloquear el acceso desde ciertos AS o países.

OPCIONES

--database ARCHIVO, -d ARCHIVO

La ruta de la base de datos que se está abriendo.

Si se omite esta opción, se abrirá la base de datos del sistema.

--quiet

Habilitar modo silencioso

--debug

Habilitar modo de depuración

COMANDOS

export [--directory=DIR] [--format=FORMAT] [--family=ipv6|ipv4] [ASN|CC ...]

Este comando exporta la base de datos completa al directorio dado.

La salida se puede filtrar exportando solo una familia de direcciones determinada, o pasando una lista de códigos de país y/o ASNs. El valor por defecto es exportar todos los países conocidos.

El formato de salida se puede elegir con el parámetro --format. Para los formatos posibles, consulte a continuación.

Si se omite la opción --directory, la salida se escribirá en la salida estándar, lo cual es útil si desea cargar exportaciones personalizadas directamente en nftables o ipset.

get-as ASN [ASN...]

Este comando devuelve el nombre de la organización propietaria del Sistema Autónomo.

list-countries [--show-name] [--show-continent]

Lista todos los países conocidos por la base de datos.

Con los parámetros opcionales --show-name y --show-continent, también se imprimirá el nombre y el código de continente.

list-networks-by-as [--family=[ipv6|ipv4]] [--format=FORMATO] ASN

Lista todas las redes que pertenecen a este Sistema Autónomo.

El parámetro --family se puede usar para filtrar la salida a solo direcciones IPv6 o IPv4.

El parámetro --format puede cambiar la salida para que pueda ser cargada directamente en otro software. Para detalles, ver abajo.

list-networks-by-cc [--family=[ipv6|ipv4]] [--format=FORMATO] CODIGO_PAIS

Lista todas las redes que pertenecen a un país.

El país debe estar codificado en notación ISO3166 Alpha-2.

Ver arriba para el uso de los parámetros --family y --format.

list-networks-by-flags [--family=[ipv6|ipv4]] [--format=FORMATO] [--anonymous-proxy|--satellite-provider|--anycast|--drop]

Lista todas las redes que tienen una bandera específica.

Ver arriba para el uso de los parámetros --family y --format.

list-bogons [--family=[ipv6|ipv4]] [--format=FORMATO]

Lista todos los bogones (es decir, redes que son desconocidas para la base de datos).

Ver arriba para el uso de los parámetros --family y --format.

lookup DIRECCION [DIRECCION...]

Este comando devuelve la red en la que se encontró la dirección IP dada, así como su Sistema Autónomo si esa información está disponible.

search-as CADENA

Lista todos los Sistemas Autónomos que coinciden con la cadena dada.

La búsqueda se realizará sin distinción entre mayúsculas y minúsculas.

update

Este comando intentará actualizar la base de datos local.

Terminará con un código de retorno de cero si la base de datos se ha actualizado correctamente. 1 en caso de error, 2 en llamada inválida y 3 si la base de datos ya era la última versión.

La opción --cron permite limitar las actualizaciones a una vez al día (daily), una vez a la semana (weekly), o una vez al mes (monthly). Si la tarea se llama, pero la base de datos se ha actualizado recientemente, se omitirá una actualización.

verify

Verifica la base de datos descargada.

version

Muestra la información de la versión de la base de datos descargada.

--help

Muestra un breve texto de ayuda sobre el uso de este programa.

--version

Muestra la versión del programa y sale.

CODIGOS DE SALIDA

El comando location normalmente saldrá con el código cero. Si ha habido un problema y la acción solicitada no se ha podido realizar, el código de salida será distinto de cero.

FORMATOS

Algunos comandos permiten especificar el formato de salida. Esto es útil si los datos exportados deben importarse en un filtro de paquetes, por ejemplo. Los siguientes formatos son entendidos:

•list (por defecto): Simplemente lista todas las redes, una por línea.
•ipset: Para ipset.
•nftables: Para nftables.
•xt_geoip: Devuelve una lista de redes para ser cargadas en el módulo del kernel xt_geoip.

COMO FUNCIONA

El descargador comprueba un registro DNS de la última versión de la base de datos. Luego intentará descargar un archivo con esa versión de un servidor espejo. Si el archivo descargado está desactualizado, se probará el siguiente espejo hasta que se encuentre un archivo lo suficientemente reciente.

REPORTES DE ERRORES

Por favor, reporte todos los errores al rastreador de errores en https://bugzilla.ipfire.org/; consulte https://wiki.ipfire.org/devel/bugzilla para más detalles.
