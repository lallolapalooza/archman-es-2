NOMBRE

localtime - Archivo de configuración de zona horaria local

SINOPSIS

/etc/localtime -> ../usr/share/zoneinfo/...

DESCRIPCIÓN

El archivo /etc/localtime configura la zona horaria a nivel de sistema del sistema local que las aplicaciones utilizan para presentarla al usuario. Debe ser un enlace simbólico absoluto o relativo que apunte a /usr/share/zoneinfo/, seguido de un identificador de zona horaria como "Europe/Berlin" o "Etc/UTC". El enlace resultante debe conducir a los datos binarios de zona horaria tzfile(5) correspondientes a la zona horaria configurada.

Debido a que el identificador de zona horaria se extrae del nombre del destino del enlace simbólico de /etc/localtime, este archivo no puede ser un archivo normal o un enlace duro.

Si falta /etc/localtime, se utiliza la zona horaria predeterminada "UTC".

La zona horaria puede ser anulada para programas individuales utilizando la variable de entorno $TZ. Ver environ(7).

Puede usar timedatectl(1) para cambiar la configuración de este archivo desde la línea de comandos en tiempo de ejecución. Use systemd-firstboot(1) para inicializar la zona horaria en imágenes de sistema montadas (pero no iniciadas).

VER TAMBIÉN

systemd(1), tzset(3), localtime(3), timedatectl(1), systemd-timedated.service(8), systemd-firstboot(1)
