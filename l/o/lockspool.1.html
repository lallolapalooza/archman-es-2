LOCKSPOOL(1) Manual de comandos generales LOCKSPOOL(1)

NOMBRE

lockspool — bloquea el buzón del sistema del usuario

SINOPSIS

lockspool [nombre_usuario]

DESCRIPCIÓN

lockspool es útil para que un programa cliente de correo obtenga el bloqueo adecuado. lockspool obtiene un archivo nombre_usuario.lock para el usuario que llama y lo conserva hasta que se cierre la entrada estándar o se reciba una señal como SIGINT, SIGTERM o SIGHUP. Además, el superusuario puede especificar el nombre de un usuario para bloquear un buzón diferente.

Si lockspool puede crear el archivo de bloqueo, se escribirá "1" en la salida estándar; de lo contrario, se escribirá "0" y se escribirá un mensaje de error en la salida de error estándar. lockspool intentará obtener el bloqueo hasta 10 veces (esperando un corto período entre intentos).

El uso típico es para un agente de correo de usuario (como mail(1)) para abrir una tubería a lockspool cuando necesite bloquear el buzón del usuario. Cerrar la tubería hará que lockspool libere el bloqueo.

ARCHIVOS

/var/mail/nombre_usuario.lock
archivo de bloqueo del buzón del usuario

ESTADO DE SALIDA

La utilidad lockspool sale con 0 en caso de éxito y con 1 si ocurre un error.

VER TAMBIÉN

mail(1), mail.local(8), smtpd(8)

HISTORIA

El programa lockspool apareció en OpenBSD 2.4.
