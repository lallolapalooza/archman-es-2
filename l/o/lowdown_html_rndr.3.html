lowdown_html_rndr(3)

Paquete: lowdown

Licencias: ISC

LOWDOWN_HTML_RNDR(3) Manual de funciones de la biblioteca LOWDOWN_HTML_RNDR(3)

NOMBRE

lowdown_html_rndr — renderiza Markdown a HTML

BIBLIOTECA

biblioteca “liblowdown”

SINOPSIS

#include <sys/queue.h>
#include <stdio.h>
#include <lowdown.h>

int
lowdown_html_rndr(struct lowdown_buf *out, void *arg, const struct lowdown_node *n);

DESCRIPCIÓN

Renderiza un árbol de nodos n creado por lowdown_doc_parse(3) o lowdown_diff(3) usando el renderizador HTML arg devuelto por lowdown_html_new(3). La salida se escribe en out, que debe ser inicializado y liberado por el llamador.

La salida consiste en un documento HTML5 UTF-8.

VALORES DE RETORNO

Devuelve cero en caso de fallo al asignar memoria, distinto de cero en caso de éxito.

EJEMPLOS

Lo siguiente analiza b de longitud bsz y produce salida en formato HTML.

struct lowdown_buf *out;
struct lowdown_doc *doc;
struct lowdown_node *n;
void *rndr;

if ((doc = lowdown_doc_new(NULL)) == NULL)
	err(1, NULL);
if ((n = lowdown_doc_parse(doc, NULL, b, bsz, NULL)) == NULL)
	err(1, NULL);
if ((out = lowdown_buf_new(256)) == NULL)
	err(1, NULL);
if ((rndr = lowdown_html_new(NULL)) == NULL)
	err(1, NULL);
if (!lowdown_html_rndr(out, rndr, n))
	err(1, NULL);

fwrite(out->data, 1, out->size, stdout);

lowdown_html_free(rndr);
lowdown_buf_free(out);
lowdown_node_free(n);
lowdown_doc_free(doc);

VER TAMBIÉN

lowdown(3), lowdown_html_free(3), lowdown_html_new(3)

ESTÁNDARES

El estándar HTML5 referenciado es HTML5.2. La salida es compatible con estándares HTML5 anteriores.
