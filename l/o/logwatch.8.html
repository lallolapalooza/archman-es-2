LOGWATCH(8) Manuales de Usuario LOGWATCH(8)

NOMBRE

logwatch - Analizador e informador de logs del sistema

SINOPSIS

logwatch [--detalle nivel ] [--logfile grupo-de-archivos-de-log ] [--service nombre-del-servicio ] [--mailto dirección ] [--archives] [--rango rango ] [--debug nivel ] [--filename nombre-de-archivo ] [--logdir directorio ] [--hostlimit hosts ] [--hostname nombre-de-host ] [--html_wrap número de caracteres ] [--hostformat opciones basadas en host ] [--output tipo-de-salida ] [--format formato-de-informe ] [--subject asunto-del-email ] [--encode codificación a usar ] [--numeric] [--version] [--help|--usage]

DESCRIPCIÓN

Logwatch es un sistema personalizable y extensible de monitorización de logs. Examinará tus logs durante un período de tiempo determinado y generará un informe en las áreas y con el detalle que desees. Logwatch se utiliza para Linux y muchos tipos de UNIX.

OPCIONES

--detalle nivel
Este es el nivel de detalle del informe. nivel puede ser un entero positivo, o alto, medio, bajo, que corresponden a los enteros 10, 5 y 0, respectivamente.
--logfile grupo-de-archivos-de-log
Esto forzará a Logwatch a procesar solo el conjunto de archivos de log definidos por grupo-de-archivos-de-log (por ejemplo, messages, xferlog, ...). Logwatch procesará, por lo tanto, todos los servicios que utilizan esos archivos de log. Esta opción se puede especificar varias veces para indicar múltiples grupos de archivos de log.
--service nombre-del-servicio
Esto forzará a Logwatch a procesar solo el servicio especificado en nombre-del-servicio (por ejemplo, login, pam, identd, ...). Logwatch procesará, por lo tanto, también cualquier grupo de archivos de log necesario para procesar estos servicios. Esta opción se puede especificar varias veces para indicar múltiples servicios a procesar. Un nombre-del-servicio útil es All, que procesará todos los servicios (y grupos de archivos de log) para los que tengas filtros instalados.
--mailto dirección
Envía los resultados por correo a la dirección de correo o usuario especificado en dirección.
--rango rango
Puedes especificar un rango de fechas para procesar. Los rangos comunes son Ayer, Hoy, Todos, y Ayuda. Las opciones adicionales se listan al invocarlo con el parámetro Ayuda.
--archives
Cada grupo de archivos de log tiene archivos de log básicos (por ejemplo, /var/log/messages) así como archivos de log archivados (por ejemplo, /var/log/messages.? o /var/log/messages.?.gz). Cuando se usa con "--rango todos", esta opción hará que Logwatch busque en los archivos archivados además de los archivos de log regulares. Para otros valores de --rango, Logwatch buscará en los archivos archivados apropiados.
--debug nivel
Para fines de depuración. nivel generalmente varía de 0 a 100. Esto saturará tu salida, por lo que probablemente solo querrás usarlo al depurar. Los valores de 100 o más conservarán los archivos temporales (por defecto, creados bajo /var/cache/logwatch, a menos que se especifique como tmpdir en el archivo logwatch.conf).
--filename nombre-de-archivo
Guarda la salida en nombre-de-archivo en lugar de mostrarla o enviarla por correo.
--logdir directorio
Busca primero en directorio los subdirectorios de logs o archivos de logs antes de buscar en los directorios por defecto.
--hostlimit host1,host2
Limita el informe al nombre de host - host1, host2.
--hostname nombre-de-host
Usa nombre-de-host para los informes en lugar del nombre de host de este sistema. Además, si HostLimit está configurado en el archivo de configuración logwatch.conf (ver MÁS INFORMACIÓN, abajo), entonces solo se procesarán los logs de este nombre de host (cuando sea apropiado).
--html_wrap num-caracteres
Número de caracteres a los que se ajustará la salida html. El valor por defecto es 80.
--hostformat split
Usa el enfoque split al formatear el informe para múltiples hosts - none [predeterminado], split, splitmail.
--output tipo-de-salida
Genera el informe usando tipo-de-salida - stdout [predeterminado], mail, file.
--format formato
Formatea el informe usando formato - text [predeterminado], html.
--subject asunto-del-email
Personaliza el asunto del correo enviado por Logwatch. La opción --output debe estar configurada como mail.
--encode codificación
Codifica el informe usando codificación - none [predeterminado], base64, 7bit, 8bit [igual que 'none'].
--numeric
Inhibe búsquedas de nombres adicionales, mostrando direcciones IP numéricamente.
--usage
Muestra información de uso
--help
igual que --usage.

ARCHIVOS

/usr/share/logwatch/
Este directorio contiene todos los ejecutables y archivos de configuración de perl distribuidos con logwatch.
/etc/logwatch
Este directorio contiene archivos de configuración locales que anulan la configuración predeterminada. Ver MÁS INFORMACIÓN abajo para más información.

EJEMPLOS

logwatch --service ftpd-xferlog --range all --detail high --archives

Esto imprimirá todas las transferencias FTP que están almacenadas en todos los xferlogs actuales y archivados.
logwatch --service pam_pwdb --range yesterday --detail high
Esto imprimirá información de inicio de sesión del día anterior...

logwatch - Herramienta de análisis de logs

NOMBRE

logwatch - Herramienta de análisis de logs

SINOPSIS

logwatch [-a ] [-o ] [-p ] [-s ] [-e ] [-l ] [-f ] [-d ] [-h ] [-u ] [-m ] [-t ]

DESCRIPCIÓN

logwatch es un script Perl que se utiliza para analizar los archivos de registro del sistema y generar informes de resumen por correo electrónico. Está diseñado para ejecutarse de forma automática a través de cron, lo que permite a los administradores mantenerse informados sobre la actividad del sistema sin tener que revisar manualmente los archivos de registro.

logwatch lee los archivos de registro del sistema y los analiza utilizando una serie de scripts "scripts" (archivos de configuración) que se encuentran en el directorio /usr/share/logwatch/scripts/. Estos scripts buscan patrones específicos en los registros y generan información útil para el administrador.

OPCIONES

-a
Especifica un archivo de registro adicional para analizar.
-o
Especifica un archivo para guardar la salida del informe.
-p
Especifica el nombre de un proceso para filtrar los registros.
-s
Especifica el nombre de un servicio para filtrar los registros.
-e
Especifica el rango de tiempo para el análisis. Los valores posibles son yesterday, today, this_month, last_month, this_year, last_year.
-l
Especifica el nivel mínimo de detalle para los mensajes de registro. Los valores posibles son low, med, high.
-f
Especifica un archivo de configuración personalizado.
-d
Especifica el nivel de depuración para el script. Útil para la solución de problemas.
-h
Especifica el nombre de host para el informe.
-u
Especifica el nombre de usuario para el informe.
-m
Especifica el medio para enviar el informe. Los valores posibles son mail, stdout.
-t
Especifica el tiempo en minutos que se retienen los informes antiguos.

ARCHIVOS

/etc/logwatch/logwatch.conf
Archivo de configuración principal de logwatch.
/usr/share/logwatch/scripts/
Directorio que contiene los scripts de análisis de logs.

EJEMPLOS

Para generar un informe de registro detallado para ayer y enviarlo por correo electrónico:

logwatch -e yesterday -l high

Para analizar un archivo de registro específico y guardar la salida en un archivo:

logwatch -a /var/log/myapp.log -o /tmp/myapp_report.txt

MÁS INFORMACIÓN

Para obtener más información sobre logwatch, consulte la página del manual o la documentación oficial.

man logwatch
