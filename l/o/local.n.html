local(n)

Paquete: tcl

Licencias: TCL

local(n) [incr Tcl] local(n)

NOMBRE

itcl::local - crea un objeto local a un procedimiento

SINOPSIS

itcl::local nombreClase nombreObj ?arg arg ...?

DESCRIPCIÓN

El comando local crea un objeto de [incr Tcl] que es local al marco de llamada actual. Cuando el marco de llamada desaparece, el objeto se elimina automáticamente. Este comando es útil para crear objetos que son locales a un procedimiento.

Como efecto secundario, este comando crea una variable llamada "itcl-local-xxx", donde xxx es el nombre del objeto que se crea. Esta variable detecta cuándo se destruye el marco de llamada y elimina automáticamente el objeto asociado.

EJEMPLO

En el siguiente ejemplo, un simple objeto "contador" se utiliza dentro del procedimiento "test". El contador se crea como un objeto local, por lo que se elimina automáticamente cada vez que el procedimiento finaliza. Las sentencias puts incluidas en el constructor/destructor muestran el objeto yendo y viniendo a medida que se llama al procedimiento.

itcl::class counter {
    private variable count 0
    constructor {} {
        puts "creado: $this"
    }
    destructor {
        puts "eliminado: $this"
    }
    method bump {{by 1}} {
        incr count $by
    }
    method get {} {
        return $count
    }
}
proc test {val} {
    local counter x
    for {set i 0} {$i < $val} {incr i} {
        x bump
    }
    return [x get]
}
set result [test 5]
puts "test: $result"
set result [test 10]
puts "test: $result"
puts "objetos: [itcl::find objects *]"
