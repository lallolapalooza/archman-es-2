NOMBRE

loc_database_lookup - Buscar una red en la base de datos

SINOPSIS

#include <libloc/database.h>

int loc_database_lookup(struct loc_database* db, const struct in6_addr* address, struct loc_network** network);

int loc_database_lookup_from_string(struct loc_database* db, const char* string, struct loc_network** network);

DESCRIPCIÓN

Las funciones de búsqueda intentan encontrar una red en la base de datos.

loc_database_lookup toma la dirección IP en formato de struct in6_addr, que puede ser una dirección IPv6 normal o una dirección IPv4 mapeada.

loc_database_lookup_string toma la dirección IP como una cadena de texto y la analizará automáticamente.

VALOR DE RETORNO

En caso de éxito, se devuelve cero. De lo contrario, se devuelve un valor distinto de cero y se establece errno en consecuencia.
