NOMBRE

logresolve - Resuelve direcciones IP a nombres de host en archivos de registro de Apache

SINOPSIS

logresolve [ -s nombre_archivo ] [ -c ] < archivo_acceso > archivo_acceso.nuevo

RESUMEN

logresolve es un programa de postprocesamiento para resolver direcciones IP en los archivos de registro de acceso de Apache. Para minimizar el impacto en su servidor de nombres, logresolve tiene su propia tabla hash interna de caché. Esto significa que cada número IP solo se buscará la primera vez que se encuentre en el archivo de registro.

Toma un archivo de registro de Apache en la entrada estándar. Las direcciones IP deben ser lo primero en cada línea y deben estar separadas del resto de la línea por un espacio.

OPCIONES

-s nombre_archivo
Especifica un nombre de archivo para registrar estadísticas.
-c
Esto hace que logresolve aplique algunas comprobaciones de DNS: después de encontrar el nombre de host a partir de la dirección IP, busca las direcciones IP del nombre de host y comprueba que una de ellas coincida con la dirección original.
