locale.h(0p) Manual del programador POSIX locale.h(0p)

PRÓLOGO

Esta página del manual forma parte del Manual del programador POSIX. La implementación de Linux de esta interfaz puede diferir (consulte la página del manual de Linux correspondiente para conocer los detalles del comportamiento de Linux), o la interfaz puede no estar implementada en Linux.

NOMBRE

locale.h — macros de categoría

SINOPSIS

#include <locale.h>

DESCRIPCIÓN

Parte de la funcionalidad descrita en esta página de referencia extiende el estándar ISO C. Las aplicaciones deberán definir el macro de prueba de características apropiado (consulte el volumen de Interfaces del Sistema de POSIX.1-2017, Sección 2.2, El Entorno de Compilación) para permitir la visibilidad de estos símbolos en esta cabecera.

La cabecera <locale.h> definirá la estructura lconv, la cual incluirá al menos los siguientes miembros. (Consulte las definiciones de LC_MONETARY en la Sección 7.3.3, LC_MONETARY y la Sección 7.3.4, LC_NUMERIC.)

char    *currency_symbol
char    *decimal_point
char     frac_digits
char    *grouping
char    *int_curr_symbol
char     int_frac_digits
char     int_n_cs_precedes
char     int_n_sep_by_space
char     int_n_sign_posn
char     int_p_cs_precedes
char     int_p_sep_by_space
char     int_p_sign_posn
char    *mon_decimal_point
char    *mon_grouping
char    *mon_thousands_sep
char    *negative_sign
char     n_cs_precedes
char     n_sep_by_space
char     n_sign_posn
char    *positive_sign
char     p_cs_precedes
char     p_sep_by_space
char     p_sign_posn
char    *thousands_sep

La cabecera <locale.h> definirá NULL (tal como se describe en <stddef.h>) y al menos lo siguiente como macros:

LC_ALL
LC_COLLATE
LC_CTYPE
LC_MESSAGES
LC_MONETARY
LC_NUMERIC
LC_TIME

que se expandirán a expresiones constantes enteras con valores distintos para usarlas como primer argumento de la función setlocale().

Definiciones de macros adicionales, que comiencen con los caracteres LC_ y una letra mayúscula, también pueden ser especificadas por la implementación.

La cabecera <locale.h> contendrá al menos las macros siguientes que representan máscaras de bits para usarlas con la función newlocale() para cada categoría de localización soportada: LC_COLLATE_MASK LC_CTYPE_MASK LC_MESSAGES_MASK LC_MONETARY_MASK LC_NUMERIC_MASK LC_TIME_MASK

Además, se definirá una macro para establecer los bits para todas las categorías establecidas: LC_ALL_MASK

La cabecera <locale.h> definirá LC_GLOBAL_LOCALE, un descriptor de objeto de localización especial utilizado por las funciones duplocale() y uselocale().

La cabecera <locale.h> definirá el tipo locale_t, que representa un objeto de localización.

Lo siguiente se declarará como funciones y también puede definirse como macros. Se proporcionarán prototipos de función para su uso con compiladores estándar ISO C.

locale_t      duplocale(locale_t);
void          freelocale(locale_t);
struct lconv *localeconv(void);
locale_t      newlocale(int, const char *, locale_t);
char         *setlocale(int, const char *);
locale_t      uselocale (locale_t);

Las siguientes secciones son informativas.

USO DE APLICACIONES

Ninguno.

RATICIONALE

Se sugiere que cada nombre de macro de categoría para su uso en setlocale() tenga un nombre de macro correspondiente que termine en _MASK para su uso en newlocale().
