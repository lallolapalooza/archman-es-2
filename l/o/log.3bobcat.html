FBB::Log(3bobcat) Mensajes de registro FBB::Log(3bobcat)

NOMBRE

FBB::Log - std::ostream para manejar mensajes de registro

SINOPSIS

#include <bobcat/log>
Opción de enlazado: -lbobcat

DESCRIPCIÓN

La clase FBB::Log define un std::ostream que utiliza un std::streambuf FBB::LogBuf. Se utiliza para enviar mensajes de registro al stream (r)syslog o a un archivo (configurable). Consulte la página del manual logbuf(3bobcat) para obtener detalles sobre LogBuf.

Qué (partes de) los mensajes se registran realmente se puede configurar usando FBB::level en combinación con el miembro setLevel del objeto Log o usando el operador de función en combinación con el miembro str (ver los miembros operator() y str). Por defecto, toda la información que se inserta en un objeto Log se registra.

Los objetos de la clase level (cf. level(3bobcat)) pueden insertarse especificando `fuerzas’ de inserción para la información que se inserta posteriormente en los objetos Log. Solo si estas `fuerzas’ superan las `resistencias’ de inserción del objeto Log (ver el miembro setLevel) se registra la información.

Una única declaración de inserción de registro puede contener múltiples llamadas a level. Si es así, cada llamada a level actualiza la `fuerza’ de las inserciones posteriores a la llamada a level.

La información insertada en los objetos Log sin insertar objetos level (o antes del primer objeto level) siempre se registra (ver también la sección Ejemplos).

Alternativamente, la información puede registrarse utilizando caracteres selectores de categoría. El miembro str(std::string const &active) define los caracteres que se pueden usar para definir un proceso de registro no jerárquico. Por ejemplo, str("abc") define los caracteres identificadores de registro ’a’, ’b’, y ’c’ que luego se pueden usar para definir declaraciones de registro para cada una de esas categorías. Estos caracteres identificadores de registro se pueden redefinir, activando solo aquellas declaraciones de registro cuyos caracteres identificadores se especificaron en la última llamada al miembro str.

Aunque tanto el registro jerárquico como el no jerárquico pueden usarse en un solo programa, operan de manera mutuamente excluyente: una vez que se define el registro jerárquico, las categorías no jerárquicas se borran, y una vez que se definen las categorías no jerárquicas, el nivel de resistencia jerárquica se establece en su valor máximo, suprimiendo efectivamente el registro jerárquico.

Por defecto, los mensajes registrados se anteponen con marcas de tiempo. Después de las marcas de tiempo, se inserta un delimitador (por defecto, un solo carácter de espacio). Los delimitadores se adjuntan inmediatamente a las marcas de tiempo y los mensajes insertados se adjuntan inmediatamente a los delimitadores. Al especificar texto como delimitadores, considere comenzar y terminar el texto del delimitador con caracteres de espacio para separar visualmente el delimitador de la marca de tiempo y de la información insertada posteriormente.

HEREDA DE

std::ostream

ENUMERACIONES

La enumeración TimeStamps se define en el espacio de nombres FBB, principalmente para inicializar objetos FBB::LogBuf. También se utiliza con los miembros de Log. Tiene los siguientes valores:

o
NOTIMESTAMPS:
Los mensajes de registro no tendrán marcas de tiempo antepuestas.
o
TIMESTAMPS:
Los mensajes de registro tendrán marcas de tiempo antepuestas.
o
UTCTIMESTAMPS:
Los mensajes de registro tendrán marcas de tiempo que muestren la hora UTC antepuestas.

La enumeración LogManipulator se utiliza para manejar situaciones especiales o excepcionales a través de manipuladores. Se define en el espacio de nombres FBB y tiene los siguientes dos valores:

o
FATAL:
Al insertar FATAL en un objeto Log se lanza una excepción FBB::Exception (ver operator<< a continuación);
o
nl:
Al insertar nl en un objeto Log se inserta un carácter \n en la línea actual. Si se solicitan marcas de tiempo, la siguiente línea no comenzará con una marca de tiempo. Se utiliza para permitir que un único mensaje de registro ocupe varias líneas de texto. La siguiente línea registrada no se indenta sobre el ancho de la marca de tiempo omitida. Si se prefiere eso: la marca de tiempo ocupa 15 posiciones de carácter (sin contar el ancho del delimitador, ver la sección CONSTRUCTORES a continuación). Si una especificación de level está activa, permanece activa en las inserciones posteriores a nl.
o
fnl:
Al insertar fnl (nueva línea forzada) en un objeto Log, la línea actual termina incluso si la `fuerza’ de inserción activa actual (establecida por level) es inferior al nivel de `resistencia’ del objeto Log. Si una especificación de level está activa, permanece activa en las inserciones posteriores a fnl.
o
endl o \n:
Al insertar endl o \n, la línea actual finaliza y la siguiente línea registrada comienza con una marca de tiempo (a menos que las marcas de tiempo estén suprimidas). El manipulador endl es el manipulador estándar de ostream: cuando se inserta en un objeto Log, su buffer se vacía. El ámbito de una especificación de level termina en \n o endl. Por ejemplo, 
log.setLevel(2);
log << level(1) << "primera línea\n"
       "segunda línea\n";
da como resultado el registro de segunda línea (precedida por una marca de tiempo).

CONSTRUCTORES

o
Log():
El constructor predeterminado crea un objeto Log que aún no está asociado con un stream para registrar mensajes. El miembro open (ver más abajo) se puede utilizar para definir dicho stream. Por defecto, todos los mensajes van precedidos de una marca de tiempo (ver la descripción del miembro setTimestamp a continuación), y se inserta un solo carácter de espacio como delimitador inmediatamente después de la marca de tiempo. El miembro open puede utilizarse para modificar el delimitador predeterminado.
o
Log(std::ostream &out, char const *delim = " "):
Este constructor crea un objeto Log que registra sus mensajes en el objeto std::ostream proporcionado. Por defecto, todos los mensajes van precedidos de una marca de tiempo (ver la descripción del miembro setTimestamp a continuación). El parámetro delim se inserta inmediatamente después de la marca de tiempo. Si no se debe utilizar un delimitador, se puede especificar una cadena vacía o un puntero nulo.
o
FBB::Log(std::string const &filename, std::ios::openmode mode = std::ios::out | std::ios::app, char const *delim = " "):
Este constructor crea un objeto Log que registra sus mensajes en el archivo especificado. Si filename == "&1", los mensajes de registro se escriben en el stream de salida estándar. Si filename == "&2", los mensajes de registro se escriben en el stream de error estándar. Por defecto, el archivo se crea si no existe, y todos los mensajes se adjuntan al stream. También por defecto, todos los mensajes van precedidos de marcas de tiempo (ver la descripción del miembro setTimestamp a continuación). El parámetro delim se inserta inmediatamente después de la marca de tiempo. Si no se debe utilizar un delimitador, se puede especificar una cadena vacía o un puntero nulo.

Los constructores de copia y movimiento (y los operadores de asignación) no están disponibles.

std::ostream están disponibles, ya que Log hereda de esta clase.

o
size_t level() const:
Este miembro devuelve el nivel de registro establecido actualmente (es decir, el valor establecido en la última llamada a setLevel()). Por defecto, el nivel se establece en cero, lo que significa que toda la información se inserta en el flujo de registro;
o
std::ostream &level(size_t useLevel):
Este miembro define el nivel de registro de los mensajes que se van a insertar. Los mensajes se insertan cuando useLevel es al menos igual al nivel especificado por setLevel. El nivel máximo es std::numeric_limits<size_t>::max(). Si ni siquiera tales mensajes deben insertarse en el ostream, entonces el flujo debe ser desactivado, usando off() (ver abajo). El nivel especificado por este miembro permanece activo hasta que otra llamada a level lo cambie. Alternativamente, el nivel de los mensajes insertados puede especificarse insertando un manipulador FBB::level en un objeto Log (ver level(3bobcat));
o
void off():
Evita que se generen mensajes de registro. Se cancela llamando a on (ver abajo);
o
void on(size_t logLevel = 0):
Reactiva el registro (por ejemplo, después de que se haya llamado previamente a off), estableciendo el nivel que la información insertada debe tener como mínimo (a logLevel). Después de on y a menos que se especifique lo contrario (por ejemplo, usando level), toda la información insertada es aceptada por el objeto Log;
o
void open(std::string const &filename, std::ios::openmode mode = std::ios::out | std::ios::app, char const *delim = " "):
Este miembro (re)asocia un objeto Log con el archivo nombrado. Si filename == "&1" los mensajes de registro se escribirán en el flujo de salida estándar. Si filename == "&2" los mensajes de registro se escribirán en el flujo de error estándar. Por defecto, el archivo se crea si no existe, y todos los mensajes se añaden al flujo. También por defecto, todos los mensajes van precedidos de marcas de tiempo (ver la descripción del miembro setTimestamp más abajo). El parámetro delim se inserta inmediatamente después de la marca de tiempo. Si no se debe utilizar un delimitador, se puede especificar una cadena vacía o un puntero 0;
o
void setLevel(size_t resistance):
Define la 'resistencia' al insertar información en un objeto Log. La información se inserta si el nivel establecido por el miembro level es al menos igual a resistance. Después de setLevel y a menos que se especifique lo contrario (por ejemplo, usando level), toda la información insertada es aceptada por el objeto Log. setLevel no reactiva el registro después de llamar a off. Para reactivar el registro después de llamar a off, se debe llamar a on;
o
void setTimestamp(FBB::TimeStamps stamp, char const *delim = " "):
La función miembro (des)activa la adición de marcas de tiempo. Use el valor FBB::TIMESTAMPS para añadir marcas de tiempo, FBB::NOTIMESTAMPS suprime las marcas de tiempo. Una marca de tiempo consta de 15 caracteres que muestran el nombre abreviado del mes, dos dígitos que especifican el día del mes y la hora (local o UTC) del mensaje actual, como aparece habitualmente en los mensajes de los archivos de /var/log. Por ejemplo, Aug 05 13:52:23. El parámetro delim se inserta inmediatamente después de la marca de tiempo. Si un delimitador es inapropiado, se puede especificar una cadena vacía o un puntero 0. Al especificar stamps como FBB::NOTIMESTAMPS, también se ignora delim.
o
std::string const &str() const:
Se devuelve el conjunto de caracteres actualmente establecido que puede ser especificado por el operador de llamada a función de Log para insertar una entrada de registro. Por defecto, no se especifican caracteres;
o
void str(std::string const &chars):
El argumento de este miembro es una std::string que define los caracteres que pueden ser especificados por el operador de llamada a función de Log para insertar una entrada de registro. Si el operador de llamada a función especifica un carácter que no está especificado en chars, entonces ese mensaje de registro se ignora. Por defecto, no se especifican caracteres.

MIEMBROS ESTÁTICOS

o
FBB::Log &initialize(std::string const &filename, std::ios::openmode mode = std::ios::out | std::ios::app, char const *delim = " "):
Devuelve una referencia a un objeto Log estático. Solo puede ser llamado una vez, o se lanzará una excepción FBB::Exception. Asocia un objeto Log estático con el archivo nombrado.
Si filename == "&1" los mensajes de registro se escribirán en el flujo de salida estándar. Si filename == "&2" los mensajes de registro se escribirán en el flujo de error estándar. Por defecto, el archivo se crea si no existe, y todos los mensajes se añaden al flujo. También por defecto, todos los mensajes van precedidos de marcas de tiempo (ver la descripción del miembro setTimestamp más abajo). El parámetro delim se inserta inmediatamente después de la marca de tiempo. Si no se debe utilizar un delimitador, se puede especificar una cadena vacía o un puntero 0;
o
FBB::Log &instance():
Devuelve una referencia a un objeto Log estático, disponible después de llamar a Log::initialize. Si se llama antes de Log::initialize(), se lanzará una excepción FBB::Exception.

OPERADORES SOBRECARGADOS

o
Log &operator()(char ch):
Si el argumento de la función se encuentra en los caracteres especificados en el miembro str, las inserciones subsiguientes hasta (e incluyendo) la inserción de std::endl o el manipulador fnl o FATAL LogManipulator se registran. Si el argumento de la función no se encuentra en los caracteres especificados en el miembro str, entonces las inserciones subsiguientes se ignoran. Al llamar a este miembro, las inserciones jerárquicas se suprimen hasta que se llame al miembro setLevel;
o
Log &operator<<(Log &, LogManipulator):
Este operador inserta un LogManipulator en un objeto Log. Al insertar FBB::FATAL, se lanza una FBB::Exception; al insertar FBB::nl, la línea se termina, y la siguiente inserción no comenzará con una marca de tiempo; al insertar FBB::fnl, la línea se termina, y la siguiente inserción comenzará con una marca de tiempo (si es aplicable). Después de llamar a este operador de inserción con el manipulador FATAL o fnl LogManipulator, las inserciones basadas en categorías de valores se suprimen hasta que se llame al operador de llamada a función;
o
Log &operator<<(Log &log, Type const &type):
Este operador se define como una plantilla, donde Type representa cualquier tipo que pueda ser insertado en un std::ostream. El valor type se inserta en el objeto Log;
o
Log &operator<<(Log &log, Type &(*fun)(Type &type)):
En este operador, fun representa los manipuladores estándar de ostream y ios_base, permitiendo la inserción de manipuladores como std::endl y std::setw en objetos Log;
o
std::ostream &::operator<<(std::ostream &str, FBB::LogManipulator):
Este operador se define fuera del espacio de nombres FBB. Se mantiene para compatibilidad retroactiva con versiones anteriores de bobcat, y llama a operator<<(Log, LogManipulatr) cuando &str puede ser convertido dinámicamente a un Log *. Si no, el operador no realiza ninguna acción.

EJEMPLO

#include <iostream>
#include <iomanip>
//#include <bobcat/log>
#include "../log"
#include <bobcat/level>
using namespace std;
using namespace FBB;
int main()
{
//    Log &log = Log::initialize("&1"); // usa el objeto Log estático
    Log log;                        // definiendo explícitamente un objeto Log
//    log.open("/tmp/out");           // o de una vez: Log log{ "/tmp/out" }
    log << "Este mensaje se escribe en cout" << nl <<
           setw(16) << ’ ’ << "ocupa múltiples líneas\n";
    log.off();
    log << "Este mensaje no se muestra\n";
    log << "Este mensaje no se muestra\n";
    log << fnl;
    log << "Este mensaje no se muestra\n";
    log.on(2);
    log << "Este mensaje se muestra\n";
    log << level(0) << "no se muestra" << level(2) << "se muestra en el nivel 2\n";
    log << level(3) << "en el nivel(3)" << level(1) << "no se muestra" << fnl;
    log << "nueva línea separada\n";
    log << level(2) << "de vuelta al negocio\n";
    log << "línea final\n";
    log.str("ab");
    log(’a’) << "hola a!" << endl;
    log(’b’) << "hola b!" << nl <<
                setw(16) << ’ ’ << "hasta ahora, todo bien" << endl;
    log << "no se muestra" << endl;
    log(’c’) << "no se muestra\n";
    log << "no se muestra\n";
    log.setLevel(2);
    log << level(2) << "de vuelta al negocio\n";
}

BUGS

Los manipuladores nl y fnl son recibidos por los LogBufs de los objetos Log como, respectivamente, los caracteres 0 y 1. Dado que los archivos de registro en la práctica solo reciben caracteres imprimibles, esto no debería causar ningún problema.
