NOMBRE

loc_database_get_country - Obtener información del país de la base de datos

SINOPSIS

#include <libloc/database.h>

int loc_database_get_country(struct loc_database* db, struct loc_country** country, const char* code);

DESCRIPCIÓN

Esta función obtiene información sobre el país con el código coincidente code.

VALOR DE RETORNO

En caso de éxito, se devuelve cero. De lo contrario, se devuelve un valor distinto de cero y errno se establece en consecuencia.

VER TAMBIÉN

libloc(3)
