LOWDOWN_BUF_DIFF(3) Manual de funciones de biblioteca LOWDOWN_BUF_DIFF(3)

NOMBRE

lowdown_buf — analiza y compara búferes Markdown en salida formateada

BIBLIOTECA

biblioteca “liblowdown”

SINOPSIS

#include <sys/queue.h>
#include <stdio.h>
#include <lowdown.h>

int
lowdown_buf_diff(const struct lowdown_opts *opts, const char *new, size_t newsz, const char *old, size_t oldsz, char **ret, size_t *retsz);

DESCRIPCIÓN

Analiza los búferes lowdown(5) new de tamaño newsz y old de tamaño oldsz y produce un script de edición en ret de tamaño retsz según las configuraciones opts. El script define las diferencias de old a new. El formato de salida está especificado por opts->type.

El llamador es responsable de liberar ret.

VALORES DE RETORNO

Devuelve cero en caso de fallo, no cero en caso de éxito. El fallo ocurre por agotamiento de memoria.
