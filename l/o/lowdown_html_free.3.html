lowdown_html_free(3)

Paquete: lowdown

Licencias: ISC

LOWDOWN_HTML_FREE(3) Manual de funciones de biblioteca LOWDOWN_HTML_FREE(3)

NOMBRE

lowdown_html_free — liberar un renderizador HTML de Markdown

BIBLIOTECA

biblioteca “liblowdown”

SINOPSIS

#include <sys/queue.h>
#include <stdio.h>
#include <lowdown.h>

void
lowdown_html_free(void *arg);

DESCRIPCIÓN

Libera el renderizador HTML creado con lowdown_html_new(3). Si arg es NULL, la función no hace nada.

EJEMPLOS

Lo siguiente analiza b de longitud bsz y produce una salida en formato HTML.

struct lowdown_buf *out;
struct lowdown_doc *doc;
struct lowdown_node *n;
void *rndr;

if ((doc = lowdown_doc_new(NULL)) == NULL)
	err(1, NULL);
if ((n = lowdown_doc_parse(doc, NULL, b, bsz, NULL)) == NULL)
	err(1, NULL);
if ((out = lowdown_buf_new(256)) == NULL)
	err(1, NULL);
if ((rndr = lowdown_html_new(NULL)) == NULL)
	err(1, NULL);
if (!lowdown_html_rndr(out, rndr, n))
	err(1, NULL);

fwrite(out->data, 1, out->size, stdout);

lowdown_html_free(rndr);
lowdown_buf_free(out);
lowdown_node_free(n);
lowdown_doc_free(doc);

VER TAMBIÉN

lowdown(3), lowdown_html_new(3)

ESTANDARES

El estándar de HTML5 referenciado es HTML5.2. La salida es compatible con estándares HTML5 anteriores.
