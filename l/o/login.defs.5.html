LOGIN.DEFS(5) Formatos de Archivo y Configuración LOGIN.DEFS(5)

NOMBRE

login.defs - configuración del conjunto de contraseñas shadow

DESCRIPCIÓN

El archivo /etc/login.defs define la configuración específica del sitio para el conjunto de contraseñas shadow. Este archivo es necesario. La ausencia de este archivo no impedirá el funcionamiento del sistema, pero probablemente resultará en un funcionamiento indeseable.

Este archivo es un archivo de texto legible, cada línea del archivo describe un parámetro de configuración. Las líneas consisten en un nombre de configuración y un valor, separados por espacios en blanco. Las líneas en blanco y las líneas de comentarios se ignoran. Los comentarios se introducen con un signo de almohadilla ("#") y el signo de almohadilla debe ser el primer carácter que no sea un espacio en blanco de la línea.

Los valores de los parámetros pueden ser de cuatro tipos: cadenas, booleanos, números y números largos. Una cadena está compuesta por cualquier carácter imprimible. Un booleano debe ser el valor sí o no. A un parámetro booleano no definido o con un valor distinto de estos se le dará el valor no. Los números (tanto regulares como largos) pueden ser valores decimales, valores octales (preceder el valor con 0) o valores hexadecimales (preceder el valor con 0x). El valor máximo de los parámetros numéricos regulares y largos depende de la máquina.

Se proporcionan los siguientes elementos de configuración:

CHFN_RESTRICT (cadena)

Este parámetro especifica qué valores en el campo gecos del archivo /etc/passwd pueden ser modificados por usuarios regulares usando el programa chfn. Puede ser cualquier combinación de las letras f, r, w, h, para nombre completo, número de habitación, teléfono del trabajo y teléfono personal, respectivamente. Por compatibilidad con versiones anteriores, sí es equivalente a rwh y no es equivalente a frwh. Si no se especifica, solo el superusuario puede realizar cualquier cambio. La configuración más restrictiva se logra mejor no instalando chfn SUID.

CREATE_HOME (booleano)

Indica si se debe crear un directorio personal por defecto para los nuevos usuarios.

Esta configuración no se aplica a los usuarios del sistema y puede ser anulada en la línea de comandos.

DEFAULT_HOME (booleano)

Indica si se permite el inicio de sesión si no podemos acceder al directorio personal. Por defecto es no.

Si se establece en sí, el usuario iniciará sesión en el directorio raíz (/) si no es posible acceder a su directorio personal.

ENCRYPT_METHOD (cadena)

Define el algoritmo de cifrado por defecto del sistema para cifrar contraseñas (si no se especifican algoritmos en la línea de comandos).

Puede tomar uno de estos valores: DES (por defecto), MD5, SHA256, SHA512, YESCRYPT. MD5 y DES no deben usarse para hashes nuevos, consulte crypt(5) para ver recomendaciones.

Nota: este parámetro anula la variable MD5_CRYPT_ENAB.

Nota: Esto solo afecta la generación de contraseñas de grupo. La generación de contraseñas de usuario se realiza mediante PAM y está sujeta a la configuración de PAM. Se recomienda establecer esta variable de manera coherente con la configuración de PAM.

ENV_PATH (cadena)

Si se establece, se usará para definir la variable de entorno PATH cuando un usuario regular inicie sesión. El valor es una lista de rutas separadas por dos puntos (por ejemplo, /bin:/usr/bin) y puede ser precedido por PATH=. El valor por defecto es PATH=/bin:/usr/bin.

ENV_SUPATH (cadena)

Si se establece, se usará para definir la variable de entorno PATH cuando el superusuario inicie sesión. El valor es una lista de rutas separadas por dos puntos (por ejemplo, /sbin:/bin:/usr/sbin:/usr/bin) y puede ser precedido por PATH=. El valor por defecto es PATH=/sbin:/bin:/usr/sbin:/usr/bin.

FAIL_DELAY (número)

Retraso en segundos antes de permitir otro intento después de un fallo de inicio de sesión.

GID_MAX (número), GID_MIN (número)

Rango de IDs de grupo utilizados para la creación de grupos regulares por useradd, groupadd o newusers.

El valor por defecto para GID_MIN (respectivamente GID_MAX) es 1000 (respectivamente 60000).

HOME_MODE (número)

El modo para los nuevos directorios personales. Si no se especifica, se utiliza la UMASK para crear el modo.

useradd y newusers usan esto para establecer el modo del directorio personal que crean.

HUSHLOGIN_FILE (cadena)

Si se define, este archivo puede inhibir todo el parloteo habitual durante la secuencia de inicio de sesión. Si se especifica una ruta completa, el modo silencioso se activará si el nombre de usuario o el shell del usuario se encuentran en el archivo. Si no es una ruta completa, el modo silencioso se activará si el archivo existe en el directorio personal del usuario.

LASTLOG_UID_MAX (número)

El número de ID de usuario más alto para el cual se deben actualizar las entradas de lastlog. Dado que los IDs de usuario más altos generalmente son rastreados por servicios de identidad y autenticación de usuarios remotos, no hay necesidad de crear un archivo lastlog grande y disperso para ellos.

La ausencia de la opción LASTLOG_UID_MAX en la configuración significa que no hay límite de ID de usuario para escribir entradas de lastlog.

LOG_UNKFAIL_ENAB (booleano)

Habilita la visualización de nombres de usuario desconocidos cuando se registran fallos de inicio de sesión.

Nota: registrar nombres de usuario desconocidos puede ser un problema de seguridad si un usuario introduce su contraseña en lugar de su nombre de inicio de sesión.

LOGIN_RETRIES (número)

Número máximo de reintentos de inicio de sesión en caso de contraseña incorrecta.

Esto probablemente será anulado por PAM, ya que el módulo predeterminado pam_unix tiene su propio límite interno de 3 reintentos. Sin embargo, este es un respaldo seguro en caso de que esté utilizando un módulo de autenticación que no aplique PAM_MAXTRIES.

LOGIN_TIMEOUT (número)

Tiempo máximo en segundos para el inicio de sesión.

MAIL_DIR (cadena)

El directorio de correo spool. Esto es necesario para manipular el buzón cuando su cuenta de usuario correspondiente se modifica o elimina. Si no se especifica, se utiliza un valor predeterminado en tiempo de compilación. El parámetro CREATE_MAIL_SPOOL en /etc/default/useradd determina si se debe crear el correo spool.

MAIL_FILE (cadena)

Define la ubicación de los archivos de correo spool de los usuarios en relación con su directorio personal.

Las variables MAIL_DIR y MAIL_FILE son utilizadas por useradd, usermod y userdel para crear, mover o eliminar el correo spool del usuario.

MAX_MEMBERS_PER_GROUP (número)

Miembros máximos por entrada de grupo. Cuando se alcanza el máximo, se inicia una nueva entrada de grupo (línea) en /etc/group (con el mismo nombre, la misma contraseña y el mismo GID).

El valor por defecto es 0, lo que significa que no hay límites en el número de miembros de un grupo.

Esta característica (grupo dividido) permite limitar la longitud de las líneas en el archivo de grupo. Esto es útil para garantizar que las líneas de los grupos NIS no superen los 1024 caracteres.

Si necesita aplicar un límite de este tipo, puede usar 25.

Nota: los grupos divididos pueden no ser compatibles con todas las herramientas (incluso dentro del conjunto de herramientas Shadow). No debe usar esta variable a menos que realmente la necesite.

NONEXISTENT (cadena)

Si una cuenta del sistema intencionalmente no tiene un directorio personal que exista, esta cadena puede proporcionarse en la entrada /etc/passwd para la cuenta para indicarlo. El resultado es que pwck no emitirá una advertencia inútil para esta cuenta.

PASS_MAX_DAYS (número)

El número máximo de días que se puede usar una contraseña. Si la contraseña es anterior a esto, se forzará un cambio de contraseña. Si no se especifica, se asumirá -1 (lo que deshabilita la restricción).

PASS_MIN_DAYS (número)

El número mínimo de días permitidos entre cambios de contraseña. Cualquier intento de cambio de contraseña anterior a esto será rechazado. Si no se especifica, se asumirá 0 (lo que deshabilita la restricción).

PASS_WARN_AGE (número)

El número de días de advertencia que se dan antes de que una contraseña expire. Un cero significa que la advertencia se da solo el día de la expiración, un valor de -1 significa que no se dan advertencias. Si no se especifica,

PASS_MAX_DAYS, PASS_MIN_DAYS y PASS_WARN_AGE

solo se utilizan en el momento de la creación de la cuenta. Cualquier cambio en esta configuración no afectará a las cuentas existentes.

SHA_CRYPT_MIN_ROUNDS (número), SHA_CRYPT_MAX_ROUNDS (número)

Cuando ENCRYPT_METHOD se establece en SHA256 o SHA512, esto define el número de rondas SHA utilizadas por el algoritmo de encriptación por defecto (cuando el número de rondas no se especifica en la línea de comandos).

Con muchas rondas, es más difícil forzar la contraseña. Pero ten en cuenta también que se necesitarán más recursos de CPU para autenticar a los usuarios.

Si no se especifica, la libc elegirá el número de rondas por defecto (5000), que es órdenes de magnitud demasiado bajo para el hardware moderno.

Los valores deben estar dentro del rango 1000-999,999,999.

Si solo se establece uno de los valores SHA_CRYPT_MIN_ROUNDS o SHA_CRYPT_MAX_ROUNDS, se utilizará ese valor.

Si SHA_CRYPT_MIN_ROUNDS > SHA_CRYPT_MAX_ROUNDS, se utilizará el valor más alto.

Nota: Esto solo afecta a la generación de contraseñas de grupo. La generación de contraseñas de usuario la realiza PAM y está sujeta a la configuración de PAM. Se recomienda establecer esta variable de forma coherente con la configuración de PAM.

SUB_GID_MIN (número), SUB_GID_MAX (número), SUB_GID_COUNT (número)

Si existe /etc/subuid, los comandos useradd y newusers (a menos que el usuario ya tenga IDs de grupo subordinados) asignan SUB_GID_COUNT IDs de grupo no utilizados del rango SUB_GID_MIN a SUB_GID_MAX para cada nuevo usuario.

Los valores por defecto para SUB_GID_MIN, SUB_GID_MAX, SUB_GID_COUNT son respectivamente 100000, 600100000 y 65536.

SUB_UID_MIN (número), SUB_UID_MAX (número), SUB_UID_COUNT (número)

Si existe /etc/subuid, los comandos useradd y newusers (a menos que el usuario ya tenga IDs de usuario subordinados) asignan SUB_UID_COUNT IDs de usuario no utilizados del rango SUB_UID_MIN a SUB_UID_MAX para cada nuevo usuario.

Los valores por defecto para SUB_UID_MIN, SUB_UID_MAX, SUB_UID_COUNT son respectivamente 100000, 600100000 y 65536.

SYS_GID_MAX (número), SYS_GID_MIN (número)

Rango de IDs de grupo utilizados para la creación de grupos de sistema por useradd, groupadd, o newusers.

El valor por defecto para SYS_GID_MIN (resp. SYS_GID_MAX) es 101 (resp. GID_MIN-1).

SYS_UID_MAX (número), SYS_UID_MIN (número)

Rango de IDs de usuario utilizados para la creación de usuarios de sistema por useradd o newusers.

El valor por defecto para SYS_UID_MIN (resp. SYS_UID_MAX) es 101 (resp. UID_MIN-1).

SYSLOG_SG_ENAB (booleano)

Habilita el registro por "syslog" de la actividad de sg.

TTYGROUP (cadena), TTYPERM (número)

Los permisos de la terminal: la tty de inicio de sesión será propiedad del grupo TTYGROUP, y los permisos se establecerán en TTYPERM.

TTYGROUP puede ser el nombre de un grupo o un identificador numérico de grupo.

Si TTYGROUP no está definido, entonces la propiedad del grupo de la terminal se establece en el grupo primario del usuario. Si TTYPERM no está definido, entonces los permisos se establecen en 0600.

Si tienes un programa write que es "setgid" a un grupo especial que posee las terminales, define TTYGROUP al número de grupo y TTYPERM a 0620. De lo contrario, deja TTYGROUP comentado y asigna TTYPERM a 622 o 600.

UID_MAX (número), UID_MIN (número)

Rango de IDs de usuario utilizados para la creación de usuarios regulares por useradd o newusers.

El valor por defecto para UID_MIN (resp. UID_MAX) es 1000 (resp. 60000).

UMASK (número)

La máscara de creación de modo de archivo se inicializa a este valor. Si no se especifica, la máscara se inicializará a 022.

useradd y newusers utilizan esta máscara para establecer el modo del directorio personal que crean si HOME_MODE no está establecido.

También es utilizada por pam_umask como valor umask por defecto.

USERDEL_CMD (cadena)

Si se define, este comando se ejecuta al eliminar un usuario. Debería eliminar cualquier trabajo at/cron/impresión, etc. propiedad del usuario a eliminar (pasado como primer argumento).

El código de retorno del script no se tiene en cuenta.

Aquí tienes un script de ejemplo, que elimina los trabajos cron, at e impresión del usuario:

#! /bin/sh
# Comprobar el argumento requerido.
if [ $# != 1 ]; then
	echo "Usage: $0 username"
	exit 1
fi
# Eliminar trabajos cron.
crontab -r -u $1
# Eliminar trabajos at.
# Nota que eliminará cualquier trabajo propiedad del mismo UID,
# incluso si fue compartido por un nombre de usuario diferente.
AT_SPOOL_DIR=/var/spool/cron/atjobs
find $AT_SPOOL_DIR -name "[^.]*" -type f -user $1 -delete \;
# Eliminar trabajos de impresión.
lprm $1
# Todo hecho.
exit 0

USERGROUPS_ENAB (booleano)

Si se establece en yes, userdel eliminará el grupo del usuario si ya no contiene miembros, y useradd creará por defecto un grupo con el nombre del usuario.

YESCRYPT_COST_FACTOR (número)

Cuando ENCRYPT_METHOD se establece en YESCRYPT, esto define el factor de coste utilizado por el algoritmo de encriptación por defecto (cuando el factor de coste no se especifica en la línea de comandos).

Con un factor de coste alto, es más difícil forzar la contraseña. Pero ten en cuenta también que se necesitarán más recursos de CPU para autenticar a los usuarios.

El valor debe estar dentro del rango 1-11.

Nota: Esto solo afecta a la generación de contraseñas de grupo. La generación de contraseñas de usuario la realiza PAM y está sujeta a la configuración de PAM. Se recomienda establecer esta variable de forma coherente con la configuración de PAM.

BUGS

Gran parte de la funcionalidad que antes proporcionaba la suite de contraseñas shadow ahora es manejada por PAM. Por lo tanto, /etc/login.defs ya no es utilizado por passwd(1), o se utiliza menos por login(1) y su(1). Consulte los archivos de configuración de PAM correspondientes en su lugar.

LOGIN.DEFS(5)

login.defs — Archivo de configuración para los programas de inicio de sesión

login.defs

DESCRIPCIÓN

El archivo /etc/login.defs contiene la configuración para los programas relacionados con el inicio de sesión, como login, getty, y otros. Este archivo controla varias opciones, como la creación de directorios de inicio de sesión, la creación de grupos y los permisos de los archivos y directorios creados.

FORMATO

El archivo login.defs consiste en líneas de la forma clave valor. Las líneas que comienzan con # se consideran comentarios. Las claves no distinguen entre mayúsculas y minúsculas.

CLAVES

MAIL_DIR
Define el directorio donde se almacenan los buzones de correo de los usuarios. El valor predeterminado es /var/mail.
MAIL_FILE
Define el nombre del archivo de correo de un usuario. Se antepone al nombre de usuario. El valor predeterminado es .mail.
MOVE_HOME
Si se establece en yes, al crear un nuevo usuario, si el directorio de inicio especificado ya existe, el programa intentará moverlo al nuevo directorio de inicio del usuario. El valor predeterminado es no.
PASS_MAX_DAYS
Define el número máximo de días que una contraseña puede ser válida. Si se establece en un valor negativo, la caducidad de la contraseña se deshabilita. El valor predeterminado es 99999.
PASS_MIN_DAYS
Define el número mínimo de días que deben transcurrir entre cambios de contraseña. Si se establece en 0 o un valor negativo, no hay restricción. El valor predeterminado es 0.
PASS_WARN_AGE
Define el número de días antes de que expire una contraseña para advertir al usuario. Si se establece en 0 o un valor negativo, la advertencia se deshabilita. El valor predeterminado es 7.
UID_MIN
Define el UID mínimo para los usuarios normales. Los usuarios con UID inferior a UID_MIN se consideran usuarios del sistema. El valor predeterminado es 1000.
UID_MAX
Define el UID máximo para los usuarios normales. Los usuarios con UID superior a UID_MAX se consideran usuarios del sistema. El valor predeterminado es 60000.
GID_MIN
Define el GID mínimo para los grupos normales. Los grupos con GID inferior a GID_MIN se consideran grupos del sistema. El valor predeterminado es 1000.
GID_MAX
Define el GID máximo para los grupos normales. Los grupos con GID superior a GID_MAX se consideran grupos del sistema. El valor predeterminado es 60000.
CREATE_HOME
Si se establece en yes, al crear un nuevo usuario, se crea su directorio de inicio si no existe. El valor predeterminado es yes.
UMASK
Define la máscara de creación de archivos (umask) para los archivos y directorios creados por los programas de inicio de sesión. El valor predeterminado es 022.

EJEMPLOS

Un ejemplo de un archivo login.defs: 

# /etc/login.defs
MAIL_DIR        /var/mail
MAIL_FILE       .mail
PASS_MAX_DAYS   99999
PASS_MIN_DAYS   0
PASS_WARN_AGE   7
UID_MIN         1000
UID_MAX         60000
GID_MIN         1000
GID_MAX         60000
CREATE_HOME     yes
UMASK           022
