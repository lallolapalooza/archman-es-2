LOCALSEARCH(1) Manual de LocalSearch LOCALSEARCH(1)

NOMBRE

localsearch - Controlar y consultar el indexador LocalSearch

SINOPSIS

localsearch COMANDO

DESCRIPCIÓN

El indexador LocalSearch es un servicio en segundo plano. Esta utilidad de línea de comandos permite controlarlo, así como consultar su estado o buscar datos específicos.

COMANDOS

help

Muestra ayuda sobre subcomandos.

extract

Extrae metadatos de un archivo.

index

Lista y cambia las carpetas indexadas.

info

Recupera información disponible para archivos y recursos.

inhibit

Inhibe temporalmente la indexación.

reset

Borra los datos indexados.

search

Busca contenido.

status

Proporciona el estado y estadísticas de los datos indexados.

tag

Añade, elimina y lista etiquetas.

test-sandbox

Sandbox para un entorno de prueba.
