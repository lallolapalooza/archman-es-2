FBB::LocalClientSocket(3bobcat) Socket de cliente de dominio Unix FBB::LocalClientSocket(3bobcat)

NOMBRE

FBB::LocalClientSocket - Socket de cliente que se conecta a un servidor en el Dominio Unix

SINOPSIS

#include <bobcat/localclientsocket>
Opción de enlace: -lbobcat

DESCRIPCIÓN

Se puede crear un FBB::LocalClientSocket para conectarse a un proceso servidor en el Dominio Unix. El socket proporcionado por FBB:LocalClientSocket puede usarse para inicializar un std::istream y/o std::ostream. El std::istream se utiliza para leer información del proceso servidor al que se conecta FBB::LocalClientSocket. El std::ostream se utiliza para enviar información al proceso servidor al que se conecta FBB::LocalClientSocket. Dado que un socket puede considerarse un descriptor de archivo, las clases disponibles FBB::IFdStream, FBB::IFdStreamBuf, FBB::OFdStream y FBB::OFdStreamBuf pueden usarse provechosamente aquí. Tenga en cuenta que tener un socket disponible no significa que defina el protocolo de comunicación. Es (todavía) responsabilidad del programador cumplir con un protocolo existente o implementar un protocolo a medida. Esta última situación implica que la secuencia de operaciones de entrada y salida está definida por el programador.

ESPACIO DE NOMBRES

FBB
Todos los constructores, miembros, operadores y manipuladores mencionados en esta página del manual están definidos en el espacio de nombres FBB.

HEREDA DE

FBB::LocalSocketBase

CONSTRUCTOR

o
LocalClientSocket():
Este constructor simplemente crea un objeto FBB::LocalClientSocket. Antes de que pueda usarse, se debe llamar a su miembro open().
o
LocalClientSocket(std::string const &name):
Este constructor inicializa un objeto FBB::LocalClientSocket, utilizando el socket con nombre de Dominio Unix para conectarse al servidor mediante el socket con nombre de Dominio Unix. Se lanza una FBB::Exception si el socket no pudo ser construido. La construcción del socket no significa que se haya establecido una conexión. Para conectarse al servidor, se debe usar el miembro connect() (ver más abajo).

Los constructores de copia y movimiento (y los operadores de asignación) no están disponibles.

FUNCIÓN MIEMBRO

o
int connect():
Este miembro devuelve un socket que puede usarse para comunicarse con el proceso servidor. Se lanza una excepción FBB::Exception si la conexión no pudo establecerse.
o
open(std::string const &name):
Esta función miembro prepara el objeto FBB::LocalClientSocket, construido previamente usando el constructor predeterminado, para su uso. El socket con nombre de Dominio Unix se utiliza para conectarse al servidor mediante el socket con nombre de Dominio Unix. Se lanza una FBB::Exception si el socket no pudo ser construido. La construcción del socket no significa que se haya establecido una conexión. Para conectarse al servidor, se debe usar el miembro connect().

EJEMPLO

Ver también el ejemplo de localserversocket(3bobcat).

    #include <iostream>
    #include <bobcat/localclientsocket>
    #include <bobcat/ifdstream>
    #include <bobcat/ofdstream>
    using namespace std;
    using namespace FBB;
    int main(int argc, char **argv)
    try
    {
        if (argc == 1)
        {
            cerr << "Proporcione el nombre de archivo que representa el socket de dominio unix\n";
            return 1;
        }
        LocalClientSocket client(argv[1]);
        int fd = client.connect();
        string line;
        cout << "Conectando al socket " << fd << endl;
        IFdStream in(fd);                 // stream para leer
        OFdStream out(fd);                // stream para escribir
        while (true)
        {
                                    // Preguntar por una línea de texto, detener si está vacía / no hay
            cout << "? ";
            if (!getline(cin, line) || line.length() == 0)
                return 0;
            cout << "Línea leída: " << line << endl;
                                    // Devolver la línea al servidor
            out << line.c_str() << endl;
            cout << "Línea escrita\n";
                                    // Esperar una respuesta del servidor
            getline(in, line);
            cout << "Respuesta: " << line << endl;
        }
    }
    catch (Exception const &err)
    {
        cerr << err.what() << "\n" <<
                "No se puede conectar a " << argv[1] << ", puerto " << argv[2] << endl;
        return 1;
    }

NAME

localclientsocket - Cliente de socket local.

SYNOPSIS

#include <bobcat/localclientsocket>

Herencia:

LocalClientSocket : LocalSocket : IOChannel : Object

Instanciación:

LocalClientSocket(const char *path);
LocalClientSocket(const std::string &path);

DESCRIPTION

Esta clase encapsula un socket de cliente de dominio UNIX. Los sockets de dominio UNIX son usados para la comunicación entre procesos en la misma máquina.

NAMESPACE

Bobcat

INHERITS FROM

LocalSocket, IOChannel, Object.

CONSTRUCTOR

LocalClientSocket(const char *path);
Construye un objeto LocalClientSocket que se conectará al socket especificado por path. El socket será de tipo AF_UNIX.
LocalClientSocket(const std::string &path);
Construye un objeto LocalClientSocket que se conectará al socket especificado por path. El socket será de tipo AF_UNIX.

MEMBER FUNCTION

Aparte de los miembros heredados de LocalSocket, IOChannel y Object, no hay funciones miembro específicas de esta clase.

EXAMPLE

$bobcat/demo/localsocket
