ctime(3) Manual de funciones de biblioteca ctime(3)

NOMBRE

asctime, ctime, gmtime, localtime, mktime, asctime_r, ctime_r, gmtime_r, localtime_r - transformar fecha y hora a tiempo desglosado o ASCII

BIBLIOTECA

Biblioteca C estándar (libc, -lc)

DESCRIPCIÓN

Las funciones ctime(), gmtime() y localtime() toman un argumento de tipo de datos time_t, que representa el tiempo calendárico. Cuando se interpreta como un valor de tiempo absoluto, representa el número de segundos transcurridos desde la Época, 1970-01-01 00:00:00 +0000 (UTC).

Las funciones asctime() y mktime() toman un argumento que representa el tiempo desglosado, que es una representación separada en año, mes, día, etc.

El tiempo desglosado se almacena en la estructura tm, descrita en tm(3type).

La llamada ctime(t) es equivalente a asctime(localtime(t)). Convierte el tiempo calendárico t en una cadena terminada en nulo del formato


"Wed Jun 30 21:49:08 1993\n"

Las abreviaturas de los días de la semana son "Sun", "Mon", "Tue", "Wed", "Thu", "Fri" y "Sat". Las abreviaturas de los meses son "Jan", "Feb", "Mar", "Apr", "May", "Jun", "Jul", "Aug", "Sep", "Oct", "Nov" y "Dec". El valor de retorno apunta a una cadena asignada estáticamente que puede ser sobrescrita por llamadas posteriores a cualquiera de las funciones de fecha y hora. La función también establece las variables externas tzname, timezone y daylight como si hubiera llamado a tzset(3). La versión reentrante ctime_r() hace lo mismo, pero almacena la cadena en un búfer proporcionado por el usuario que debe tener espacio para al menos 26 bytes. No necesita establecer tzname, timezone y daylight.

La función gmtime() convierte el tiempo calendárico timep a una representación de tiempo desglosado, expresada en Tiempo Universal Coordinado (UTC). Puede devolver NULL cuando el año no cabe en un entero. El valor de retorno apunta a una estructura asignada estáticamente que puede ser sobrescrita por llamadas posteriores a cualquiera de las funciones de fecha y hora. La función gmtime_r() hace lo mismo, pero almacena los datos en una estructura proporcionada por el usuario.

La función localtime() convierte el tiempo calendárico timep a una representación de tiempo desglosado, expresada en relación con la zona horaria especificada por el usuario. La función también establece las variables externas tzname, timezone y daylight como si hubiera llamado a tzset(3). El valor de retorno apunta a una estructura asignada estáticamente que puede ser sobrescrita por llamadas posteriores a cualquiera de las funciones de fecha y hora. La función localtime_r() hace lo mismo, pero almacena los datos en una estructura proporcionada por el usuario. No necesita establecer tzname, timezone y daylight.

La función asctime() convierte el valor de tiempo desglosado tm en una cadena terminada en nulo con el mismo formato que ctime(). El valor de retorno apunta a una cadena asignada estáticamente que puede ser sobrescrita por llamadas posteriores a cualquiera de las funciones de fecha y hora. La función asctime_r() hace lo mismo, pero almacena la cadena en un búfer proporcionado por el usuario que debe tener espacio para al menos 26 bytes.

La función mktime() convierte una estructura de tiempo desglosado, expresada como hora local, a una representación de tiempo calendárico. La función ignora los valores proporcionados por el llamador en los campos tm_wday y tm_yday. El valor especificado en el campo tm_isdst informa a mktime() si el horario de verano (DST) está en vigor o no para la hora proporcionada en la estructura tm: un valor positivo significa que DST está en vigor; cero significa que DST no está en vigor; y un valor negativo significa que mktime() debe (utilizar información de zona horaria y bases de datos del sistema para) intentar determinar si DST está en vigor en el momento especificado. Ver timegm(3) para un equivalente en UTC de esta función.

La función mktime() modifica los campos de la estructura tm de la siguiente manera: tm_wday y tm_yday se establecen con valores determinados a partir del contenido de los otros campos; si los miembros de la estructura están fuera de su intervalo válido, se normalizarán (de modo que, por ejemplo, 40 de octubre se convierta en 9 de noviembre); tm_isdst se establece (independientemente de su valor inicial) en un valor positivo o en 0, respectivamente, para indicar si DST está o no en vigor en el momento especificado. La función también establece las variables externas tzname, timezone y daylight como si hubiera llamado a tzset(3).

Si el tiempo desglosado especificado no se puede representar como tiempo calendárico (segundos desde la Época), mktime() devuelve (time_t) -1 y no modifica los miembros de la estructura de tiempo desglosado.

VALOR DE RETORNO

En caso de éxito, gmtime() y localtime() devuelven un puntero a una struct tm.

En caso de éxito, gmtime_r() y localtime_r() devuelven la dirección de la estructura apuntada por result.

En caso de éxito, asctime() y ctime() devuelven un puntero a una cadena.

En caso de éxito, asctime_r() y ctime_r() devuelven un puntero a la cadena apuntada por buf.

En caso de éxito, mktime() devuelve el tiempo calendárico (segundos desde la Época), expresado como un valor de tipo time_t.

En caso de error, mktime() devuelve el valor (time_t) -1 y deja el miembro tm->tm_wday sin modificar. Las funciones restantes devuelven NULL en caso de error. En caso de error, errno se establece para indicar el error.

ERRORES

EOVERFLOW
El resultado no se puede representar.

DESCRIPCIÓN

La función mktime() convierte la hora representada por la estructura tm apuntada por tp en un valor time_t. La hora puede especificarse en cualquier zona horaria; mktime() usa la variable de entorno TZ para determinar la zona horaria. Si TZ no está configurada, se utiliza la zona horaria predeterminada del sistema.

Si tm_isdst es positivo, se considera que el horario de verano está en vigor. Si tm_isdst es cero, se considera que el horario de verano no está en vigor. Si tm_isdst es negativo, la función intentará determinar si el horario de verano estaba en vigor en el momento especificado.

mktime() normaliza la estructura tm y luego calcula el valor time_t. Los campos de la estructura tm que están fuera de rango (por ejemplo, tm_mday=0 o tm_hour=25) se normalizan y el valor de tm_isdst se ajusta según sea necesario.

A diferencia de otras funciones de tiempo, mktime() no llama a tzset(3). Por lo tanto, si la zona horaria o la información del horario de verano ha cambiado desde la última llamada a mktime(), se recomienda llamar a tzset(3) antes de llamar a mktime().

La función timegm() es lo opuesto a gmtime(). Convierte un valor time_t (que representa el tiempo en UTC) en una estructura tm en la zona horaria UTC. La función gmtime_r() también convierte un valor time_t en una estructura tm en la zona horaria UTC, pero lo hace de manera segura para hilos, escribiendo el resultado en el búfer proporcionado por el llamador.

La función timegm() puede comportarse de forma diferente dependiendo de si se ha llamado a tzset(3) y de la configuración de la variable de entorno TZ. Para un comportamiento portable, se recomienda llamar a tzset(3) antes de llamar a timegm().

La función localtime() convierte un valor time_t en una estructura tm que representa la hora local. La función localtime_r() es la versión segura para hilos de localtime().

Según POSIX.1, se requiere que localtime() se comporte como si se hubiera llamado a tzset(3), mientras que localtime_r() no tiene este requisito. Para código portable, se debería llamar a tzset(3) antes de localtime_r().

PRECAUCIONES

Seguridad de hilos

Las cuatro funciones asctime(), ctime(), gmtime() y localtime() devuelven un puntero a datos estáticos y por lo tanto no son seguras para hilos. Las versiones seguras para hilos, asctime_r(), ctime_r(), gmtime_r() y localtime_r(), están especificadas por SUSv2.

POSIX.1 dice: "Las funciones asctime(), ctime(), gmtime() y localtime() devolverán valores en uno de dos objetos estáticos: una estructura de tiempo desglosada y un array de tipo char. La ejecución de cualquiera de las funciones que devuelvan un puntero a uno de estos tipos de objeto puede sobrescribir la información en cualquier objeto del mismo tipo al que apunte el valor devuelto por cualquier llamada previa a cualquiera de ellas." Esto puede ocurrir en la implementación de glibc.

mktime()

(time_t) -1 puede representar una hora válida (un segundo antes de la Época). Para determinar si mktime() falló, se debe usar el campo tm->tm_wday. Ver el programa de ejemplo en EJEMPLOS.

El manejo de un tm_isdst no negativo en mktime() está pobremente especificado, y pasar un valor incorrecto para la hora especificada produce resultados no especificados. Dado que mktime() es una de las pocas funciones que sabe cuándo está en vigor el horario de verano, proporcionar un valor correcto puede ser difícil. Una solución para esto es llamar a mktime() dos veces, una con tm_isdst establecido en cero y otra con tm_isdst establecido en un valor positivo, y descartando los resultados de la llamada que lo cambia. Si ninguna de las llamadas cambia tm_isdst, entonces la hora especificada probablemente ocurre durante un período de retroceso donde el horario de verano comienza o termina, y ambos resultados son válidos pero representan dos horas diferentes. Si ambas llamadas lo cambian, eso podría indicar una transición de avance forzado, o alguna otra razón por la cual la hora especificada no existe.

La especificación de zonas horarias y horario de verano depende de los gobiernos regionales, cambia a menudo y puede incluir discontinuidades más allá de la capacidad de mktime para documentar un resultado. Por ejemplo, un cambio en la definición de la zona horaria puede hacer que una hora del reloj se repita o se salte sin un cambio correspondiente en el horario de verano.

Código fuente del programa: mktime.c

#include <err.h>
#include <errno.h>
#include <stdint.h>
#include <stdio.h>
#include <stdlib.h>
#include <string.h>
#include <time.h>
#define is_signed(T)  ((T) -1 < 1)
static time_t my_mktime(struct tm *tp);
int
main(int argc, char *argv[])
{
    char       **p;
    time_t     t;
    struct tm  tm;
    if (argc != 8) {
        fprintf(stderr, "Usage: %s yyyy mm dd HH MM SS isdst\n", argv[0]);
        exit(EXIT_FAILURE);
    }
    p = &argv[1];
    tm.tm_year  = atoi(*p++) - 1900;
    tm.tm_mon   = atoi(*p++) - 1;
    tm.tm_mday  = atoi(*p++);
    tm.tm_hour  = atoi(*p++);
    tm.tm_min   = atoi(*p++);
    tm.tm_sec   = atoi(*p++);
    tm.tm_isdst = atoi(*p++);
    errno = 0;
    tm.tm_wday = -1;
    t = my_mktime(&tm);
    if (tm.tm_wday == -1)
        err(EXIT_FAILURE, "mktime");
    if (errno == EINVAL || errno == ENOTUNIQ)
        warn("my_mktime");
    if (is_signed(time_t))
        printf("%jd\n", (intmax_t) t);
    else
        printf("%ju\n", (uintmax_t) t);
    exit(EXIT_SUCCESS);
}
static time_t
my_mktime(struct tm *tp)
{
    int            e, isdst;
    time_t         t;
    struct tm      tm;
    unsigned char  wday[sizeof(tp->tm_wday)];
    e = errno;
    tm = *tp;
    isdst = tp->tm_isdst;
    memcpy(wday, &tp->tm_wday, sizeof(wday));
    tp->tm_wday = -1;
    t = mktime(tp);
    if (tp->tm_wday == -1) {
        memcpy(&tp->tm_wday, wday, sizeof(wday));
        return -1;
    }
    if (isdst == -1)
        tm.tm_isdst = tp->tm_isdst;
    if (   tm.tm_sec   != tp->tm_sec
        || tm.tm_min   != tp->tm_min
        || tm.tm_hour  != tp->tm_hour
        || tm.tm_mday  != tp->tm_mday
        || tm.tm_mon   != tp->tm_mon
        || tm.tm_year  != tp->tm_year
        || tm.tm_isdst != tp->tm_isdst)
    {
        errno = EINVAL;
        return t;
    }
    if (isdst != -1)
        goto out;
    tm = *tp;
    tm.tm_isdst = !tm.tm_isdst;
    tm.tm_wday = -1;
    mktime(&tm);
    if (tm.tm_wday == -1)
        goto out;
    if (tm.tm_isdst != tp->tm_isdst) {
        errno = ENOTUNIQ;
        return t;
    }
out:
    errno = e;
    return t;
}

NOMBRE

localtime, localtime_r, localtime_rz - convertir tiempo de calendario a estructura tm

SINOPSIS

#include <time.h>

struct tm *localtime(const time_t *timep);
struct tm *localtime_r(const time_t *restrict timep, struct tm *restrict result);
struct tm *localtime_rz(const time_t *restrict timep, struct tm *restrict result, const char *restrict zone);

DESCRIPCIÓN

La función localtime convierte el valor de tiempo timep (que apunta a un valor de tipo time_t), representado como segundos desde la Época, a una expresión de tiempo local. Convierte la hora a la hora local para la zona horaria especificada por la variable de entorno TZ. Si TZ no está configurada, la hora local se calcula a partir de la hora universal coordinada (UTC) utilizando las reglas de la hora local del sistema.

El valor devuelto apunta a una estructura tm que contiene los componentes de fecha y hora en la hora local. Esta estructura está definida en <time.h> y contiene, como mínimo, los siguientes campos:

int tm_sec;       /* segundos después de la hora (0-60) */
                    int tm_min;       /* minutos después de la hora (0-59) */
                    int tm_hour;      /* horas desde la medianoche (0-23) */
                    int tm_mday;      /* día del mes (1-31) */
                    int tm_mon;       /* meses desde el año (0-11) */
                    int tm_year;      /* años desde 1900 */
                    int tm_wday;      /* días desde el domingo (0-6) */
                    int tm_yday;      /* días desde el comienzo del año (0-365) */
                    int tm_isdst;     /* pulso de ahorro de luz diurna */

El campo tm_isdst es positivo si la hora de ahorro de luz diurna está en vigor en el momento especificado, cero si no lo está, y negativo si se desconoce.

localtime_r es la versión reentrante de localtime. Devuelve un puntero a la estructura tm proporcionada por el usuario en result. No utiliza ni modifica una variable estática global.

localtime_rz es similar a localtime_r, pero ignora la variable de entorno TZ y utiliza en su lugar la zona horaria especificada por el argumento zone. El argumento zone debe ser un nombre de zona horaria válido (por ejemplo, "Europe/London", "America/New_York"). Para obtener una lista de zonas horarias válidas, consulte el archivo /usr/share/zoneinfo/.

VALOR DE RETORNO

En caso de éxito, localtime y localtime_r devuelven un puntero a la estructura tm. En caso de error, se devuelve un puntero nulo y se establece errno para indicar el error.

localtime_rz siempre devuelve un puntero a la estructura tm proporcionada por el usuario en result. Los errores se manejan estableciendo errno.

ERRORES

Las siguientes condiciones pueden establecerse en errno:

  • EINVAL: El argumento timep no es válido.
  • ENOMEM: No hay memoria suficiente para asignar la estructura tm.
  • EOVERFLOW: El valor de tiempo no se puede representar como un tiempo local.

Además, localtime_rz puede establecer errno en:

  • EINVAL: El argumento zone no es un nombre de zona horaria válido.

HISTORIA

La función localtime se remonta a la versión 3 de AT&T UNIX.

La función localtime_r se añadió en POSIX.1-2001.

La función localtime_rz se añadió en GNU C Library.

ADVERTENCIAS

El puntero devuelto por localtime apunta a una estructura estática que puede ser sobrescrita por llamadas posteriores a otras funciones de conversión de tiempo.

localtime_r y localtime_rz evitan este problema proporcionando un puntero a una estructura de usuario, pero el usuario debe asegurarse de que la estructura proporcionada es válida y persistirá durante el tiempo que sea necesario.

EJEMPLOS

Ejemplo 1: Uso básico de localtime

#include <stdio.h>
                    #include <time.h>

                    int main() {
                        time_t t = time(NULL);
                        struct tm *local_time = localtime(&t);

                        if (local_time == NULL) {
                            perror("localtime");
                            return 1;
                        }

                        char buffer[100];
                        strftime(buffer, sizeof(buffer), "%c", local_time);
                        printf("Hora local actual: %s\n", buffer);

                        return 0;
                    }

Ejemplo 2: Uso de localtime_r

#include <stdio.h>
                    #include <time.h>

                    int main() {
                        time_t t = time(NULL);
                        struct tm local_time_struct;
                        struct tm *local_time = localtime_r(&t, &local_time_struct);

                        if (local_time == NULL) {
                            perror("localtime_r");
                            return 1;
                        }

                        char buffer[100];
                        strftime(buffer, sizeof(buffer), "%c", local_time);
                        printf("Hora local actual (reentrante): %s\n", buffer);

                        return 0;
                    }

Ejemplo 3: Uso de localtime_rz

#include <stdio.h>
                    #include <time.h>

                    int main() {
                        time_t t = time(NULL);
                        struct tm local_time_struct;
                        // Especificar la zona horaria de Nueva York
                        struct tm *local_time = localtime_rz(&t, &local_time_struct, "America/New_York");

                        if (local_time == NULL) {
                            perror("localtime_rz");
                            return 1;
                        }

                        char buffer[100];
                        strftime(buffer, sizeof(buffer), "%c %Z", local_time); // %Z para el nombre de la zona horaria
                        printf("Hora local en Nueva York: %s\n", buffer);

                        return 0;
                    }
