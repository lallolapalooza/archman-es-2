localedef(1) Manual de Comandos Generales localedef(1)

NOMBRE

localedef - compilar archivos de definición de localización

SINOPSIS

localedef [opciones] rutasalida
localedef --add-to-archive [opciones] rutacompilada
localedef --delete-from-archive [opciones] nombrelocal ...
localedef --list-archive [opciones]
localedef --help
localedef --usage
localedef --version

DESCRIPCIÓN

El programa localedef lee los archivos charmap y input indicados, los compila a una forma binaria que las funciones de localización de la biblioteca C puedan usar rápidamente (por ejemplo, setlocale(3), localeconv(3), etc.), y coloca la salida en rutasalida.

El argumento rutasalida se interpreta de la siguiente manera:

•
Si rutasalida contiene una barra ('/'), se interpreta como el nombre del directorio donde se almacenarán las definiciones de localización compiladas. En este caso, hay un archivo de salida separado para cada categoría de localización (LC_TIME, LC_NUMERIC, y así sucesivamente).
•
Si se utiliza la opción --no-archive, rutasalida es el nombre de un subdirectorio en /usr/lib/locale donde se colocan los archivos compilados por categoría.
•
En caso contrario, rutasalida es el nombre de una localización y los datos de localización compilados se añaden al archivo de archivo /usr/lib/locale/locale-archive. Un archivo de localización es un archivo mapeado en memoria que contiene todas las localizaciones proporcionadas por el sistema; es utilizado por todos los programas localizados cuando la variable de entorno LOCPATH no está establecida.

En cualquier caso, localedef aborta si el directorio en el que intenta escribir los archivos de localización no ha sido creado previamente.

Si no se proporciona ningún archivocharmap, se usa por defecto el valor ANSI_X3.4-1968 (para ASCII). Si no se proporciona ningún archivoentrada, o si se proporciona como un guion (-), localedef lee de la entrada estándar.

OPCIONES

Opciones de selección de operación

Algunas opciones indican a localedef que haga algo distinto a compilar definiciones de localización. Solo una de estas opciones debe usarse a la vez.

--add-to-archive
Añade los directorios rutacompilada al archivo de archivo de localización. Los directorios deberían haber sido creados por ejecuciones previas de localedef, usando --no-archive.
--delete-from-archive
Elimina las localizaciones nombradas del archivo de archivo de localización.
--list-archive
Lista las localizaciones contenidas en el archivo de archivo de localización.

Otras opciones

Algunas de las siguientes opciones solo tienen sentido para ciertas operaciones; en general, debería ser evidente cuáles son. Nótese que -f y -c están invertidas de lo que cabría esperar; es decir, -f no es lo mismo que --force.

-f archivocharmap
--charmap=archivocharmap
Especifica el archivo que define el conjunto de caracteres que se usa en el archivo de entrada. Si archivocharmap contiene una barra ('/'), se interpreta como el nombre del mapa de caracteres. De lo contrario, el archivo se busca en el directorio actual y en el directorio por defecto para mapas de caracteres. Si la variable de entorno I18NPATH está establecida, también se buscan $I18NPATH/charmaps/ y $I18NPATH/ después del directorio actual. El directorio por defecto para mapas de caracteres se imprime con localedef --help.
-i archivoentrada
--inputfile=archivoentrada
Especifica el archivo de definición de localización a compilar. El archivo se busca en el directorio actual y en el directorio por defecto para archivos de definición de localización. Si la variable de entorno I18NPATH está establecida, también se buscan $I18NPATH/locales/ y $I18NPATH después del directorio actual. El directorio por defecto para archivos de definición de localización se imprime con localedef --help.
-u archivorepertorio
--repertoire-map=archivorepertorio
Lee mapeos de nombres simbólicos a puntos de código Unicode de archivorepertorio. Si archivorepertorio contiene una barra ('/'), se interpreta como la ruta del mapa de repertorio. De lo contrario, el archivo se busca en el directorio actual y en el directorio por defecto para mapas de repertorio. Si la variable de entorno I18NPATH está establecida, también se buscan $I18NPATH/repertoiremaps/ y $I18NPATH después del directorio actual. El directorio por defecto para mapas de repertorio se imprime con localedef --help.
-A archivoalias
--alias-file=archivoalias
Usa archivoalias para buscar alias de nombres de localización. No hay un archivo de alias por defecto.
--force
-c
Escribe los archivos de salida incluso si se generaron advertencias sobre el archivo de entrada.
--verbose
-v
Genera advertencias adicionales sobre errores que normalmente se ignoran.
--big-endian
Genera salida big-endian.
--little-endian
Genera salida little-endian.
--no-archive
No uses el archivo de archivo de localización; en su lugar, crea rutasalida como un subdirectorio en el mismo directorio que el archivo de archivo de localización, y crea archivos de salida separados para las categorías de localización en él. Esto es útil para evitar que las actualizaciones del archivo de archivo de localización del sistema sobrescriban las localizaciones personalizadas creadas con localedef.
--no-hard-links
No crees enlaces duros entre localizaciones instaladas.
--no-warnings=advertencias
Lista separada por comas de advertencias a deshabilitar. Las advertencias soportadas son ascii y intcurrsym.
--posix
Conforme estrictamente a POSIX. Implica --verbose. Esta opción actualmente no tiene ningún otro efecto. La conformidad POSIX se asume si la variable de entorno POSIXLY_CORRECT está establecida.
--prefix=rutadeacceso
Establece el prefijo a anteponer a la ruta completa del archivo de archivo. Por defecto, el prefijo está vacío. Si se establece el prefijo a foo, el archivo de archivo se colocará en foo/usr/lib/locale/locale-archive.
--quiet
Suprime todas las notificaciones y advertencias, e informa solo de errores fatales.
--replace
Reemplaza una localización en el archivo de archivo de localización. Sin la opción --replace, si la localización ya existe en el archivo de archivo, se añade al final del archivo, sin ser reemplazada.
--usage
Imprime un mensaje de uso y sale.
--version
Imprime información sobre la versión y sale.

VER TAMBIÉN

locale(7), setlocale(3)

FALLOS

Si localedef se ejecuta con un sistema de archivos que no soporta enlaces duros, como por ejemplo algunos sistemas de archivos montados en red, la construcción del archivo de archivo de localización falla con un error.

Si el archivo de archivo de localización es un archivo mapeado en memoria, la construcción del archivo puede fallar si el tamaño del archivo es mayor que la memoria disponible.

OPCIONES

--posix
Utiliza la especificación POSIX para la creación de locales. Esto desactiva las extensiones del sistema y emite un error si el local ya está en el archivo de archivo.
--force
Sobrescribe los archivos existentes si la opción --force se usa, un error se produce si el locale ya está en el archivo del mismo.
--aliasfile=aliasfile
Especifica el archivo que contiene los alias de nombres de locale. Si esta opción no se usa, se utiliza el archivo de alias predeterminado.
-f charmap, --charmap=charmap
Especifica el archivo de mapa de caracteres a usar. Si esta opción no se usa, se utiliza el mapa de caracteres predeterminado.
-i definefile, --definefile=definefile
Especifica el archivo de definición de locale a usar. Si esta opción no se usa, se utiliza el archivo de definición de locale predeterminado.
--locale-archive=locale-archive
Especifica el archivo de archivo de locale a usar. Si esta opción no se usa, se utiliza el archivo de archivo de locale predeterminado. Si el archivo especificado no existe, se crea. Si esta opción no se especifica y el archivo de archivo predeterminado no existe, se crea. Si esta opción no se especifica y el archivo de archivo predeterminado ya existe, se añade el locale al archivo existente. Si se especifica esta opción, si el locale ya está en el archivo del mismo, se produce un error.
--warnings=warnings
Lista separada por comas de advertencias a habilitar. Las advertencias soportadas son ascii e intcurrsym.
--help
-?
Imprime un resumen de uso y sale. También imprime las rutas predeterminadas utilizadas por localedef.
--usage
Imprime un resumen de uso corto y sale.
--version
-V
Imprime el número de versión, la licencia y el descargo de responsabilidad de garantía de localedef.

ESTADO DE SALIDA

Uno de los siguientes valores de salida puede ser devuelto por localedef:

0
Comando completado exitosamente.
1
Ocurrieron advertencias o errores, se escribieron archivos de salida.
4
Se encontraron errores, no se creó ninguna salida.

AMBIENTE

POSIXLY_CORRECT
Se asume el flag --posix si esta variable de entorno está establecida.
I18NPATH
Una lista separada por dos puntos de directorios de búsqueda de archivos.

ARCHIVOS

/usr/share/i18n/charmaps
Ruta habitual del mapa de caracteres predeterminado.
/usr/share/i18n/locales
Ruta habitual de los archivos de definición de locale.
/usr/share/i18n/repertoiremaps
Ruta habitual del mapa de repertorio.
/usr/lib/locale/locale-archive
Ubicación habitual del archivo de archivo de locale predeterminado.
/usr/lib/locale
Ruta habitual de los archivos de datos de locale individuales compilados.
outputpath/LC_ADDRESS
Un archivo de salida que contiene información sobre el formato de direcciones y elementos relacionados con la geografía.
outputpath/LC_COLLATE
Un archivo de salida que contiene información sobre las reglas para comparar cadenas.
outputpath/LC_CTYPE
Un archivo de salida que contiene información sobre las clases de caracteres.
outputpath/LC_IDENTIFICATION
Un archivo de salida que contiene metadatos sobre el locale.
outputpath/LC_MEASUREMENT
Un archivo de salida que contiene información sobre las mediciones del locale (métrico frente a consuetudinario de EE. UU.).
outputpath/LC_MESSAGES/SYS_LC_MESSAGES
Un archivo de salida que contiene información sobre el idioma en el que se deben imprimir los mensajes y cómo se ve una respuesta afirmativa o negativa.
outputpath/LC_MONETARY
Un archivo de salida que contiene información sobre el formato de valores monetarios.
outputpath/LC_NAME
Un archivo de salida que contiene información sobre saludos para personas.
outputpath/LC_NUMERIC
Un archivo de salida que contiene información sobre el formato de valores numéricos no monetarios.
outputpath/LC_PAPER
Un archivo de salida que contiene información sobre configuraciones relacionadas con el tamaño de papel estándar.
outputpath/LC_TELEPHONE
Un archivo de salida que contiene información sobre los formatos a usar con servicios telefónicos.
outputpath/LC_TIME
Un archivo de salida que contiene información sobre el formato de valores de fecha y hora.

ESTANDARES

POSIX.1-2008.

EJEMPLOS

Compila los archivos de locale para finés en el conjunto de caracteres UTF-8 y añádelo al archivo de archivo de locale predeterminado con el nombre fi_FI.UTF-8:


localedef -f UTF-8 -i fi_FI fi_FI.UTF-8

El siguiente ejemplo hace lo mismo, pero genera archivos en el directorio fi_FI.UTF-8, que luego pueden ser utilizados por los programas cuando la variable de entorno LOCPATH está establecida al directorio actual (nota que el último argumento debe contener una barra):


localedef -f UTF-8 -i fi_FI ./fi_FI.UTF-8
