Definición en la línea 166 del archivo lo_types.h.

typedef int(* lo_bundle_start_handler) (lo_timetag time, void *user_data)

Una función de devolución de llamada para recibir notificación de que un paquete está siendo despachado por el servidor o el hilo del servidor. Esta devolución de llamada permite a las aplicaciones ser conscientes de los paquetes entrantes y preservar el orden y la atomicidad de los mensajes en los paquetes.

Si se instala con lo_server_add_bundle_handlers, esta devolución de llamada se realizará con time establecido en la etiqueta de tiempo del paquete, y user_data establecido en el parámetro user_data pasado a lo_server_add_bundle_handlers.

Tenga en cuenta que los paquetes pueden estar anidados, en cuyo caso las llamadas a las devoluciones de llamada de inicio y fin de paquete también estarán anidadas. La aplicación puede realizar un seguimiento de los paquetes anidados de forma similar a una pila, tratando la devolución de llamada de inicio como "push" y la devolución de llamada de fin como "pop". Por ejemplo, un paquete que contenga dos paquetes dispararía 6 devoluciones de llamada: inicio, inicio, fin, inicio, fin, fin.

typedef void(* lo_err_handler) (int num, const char *msg, const char *where)

Una función de devolución de llamada para recibir notificación de un error en un servidor o hilo de servidor. En la devolución de llamada, los parámetros se establecerán en los siguientes valores:

Parámetros

num Un número de error que puede usarse para identificar esta condición.
msg Un mensaje de error que describe la condición.
where Una cadena que describe el lugar donde ocurrió el error, típicamente una llamada a una función o una ruta de método.

Typedef Documentation

typedef void(* lo_arg) (_lo_arg_type, union lo_atom_value)

This is a type for a handler function. A handler function is called when a message is received by the server. The function is called with the following parameters:

Parameters

path The path of the message.
types The types of the arguments of the message.
argv An array of arguments.
argc The number of arguments.
msg The raw message.
user_data The user data passed to the server.

The return value of the handler function indicates whether the message has been handled. If the return value is 0, the message has been handled and will not be passed to any other handlers. If the return value is non-zero, the message has not been handled and will be passed to other handlers.

typedef void(* lo_server_thread_cleanup_callback) (lo_server_thread s, void *user_data)

A callback function to perform cleanup when the server thread is started. If installed with lo_server_thread_set_callbacks, this callback will be called in the server thread, after the server has stopped listening and processing events, before it quits. user_data is set to the user_data parameter passed to lo_server_thread_add_functions.

typedef int(* lo_server_thread_init_callback) (lo_server_thread s, void *user_data)

A callback function to perform initialization when the server thread is started. If installed with lo_server_thread_set_callbacks, this callback will be called in the server thread, just before the server starts listening for events. user_data is set to the user_data parameter passed to lo_server_thread_add_functions.

If the return value is non-zero, the thread start will be aborted.
