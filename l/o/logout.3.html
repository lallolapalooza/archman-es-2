login(3) Manual de funciones de biblioteca login(3)

NOMBRE

login, logout - escribir entradas utmp y wtmp

BIBLIOTECA

Biblioteca de utilidades del sistema (libutil, -lutil)

SINOPSIS

#include <utmp.h>
void login(const struct utmp *ut);
int logout(const char *ut_line);

DESCRIPCIÓN

El archivo utmp registra quién está usando actualmente el sistema. El archivo wtmp registra todos los inicios y cierres de sesión. Ver utmp(5).

La función login() toma la struct utmp, ut, suministrada y la escribe tanto en el archivo utmp como en el archivo wtmp.

La función logout() borra la entrada en el archivo utmp de nuevo.

Detalles de GNU

Más precisamente, login() toma la estructura de argumento ut, rellena el campo ut->ut_type (si existe tal campo) con el valor USER_PROCESS, y rellena el campo ut->ut_pid (si existe tal campo) con el ID de proceso del proceso que llama. Luego intenta rellenar el campo ut->ut_line. Toma la primera de stdin, stdout, stderr que sea un terminal, y almacena la ruta correspondiente sin un posible prefijo /dev/ en este campo, y luego escribe la estructura en el archivo utmp. Por otro lado, si no se encontró ningún nombre de terminal, este campo se rellena con "???" y la estructura no se escribe en el archivo utmp. Después de esto, la estructura se escribe en el archivo wtmp.

La función logout() busca en el archivo utmp una entrada que coincida con el argumento ut_line. Si se encuentra un registro, se actualiza poniendo a cero los campos ut_name y ut_host, actualizando el campo de marca de tiempo ut_tv y estableciendo ut_type (si existe tal campo) a DEAD_PROCESS.

VALOR DE RETORNO

La función logout() devuelve 1 si la entrada se escribió correctamente en la base de datos, o 0 si ocurrió un error.

ARCHIVOS

/var/run/utmp
base de datos de contabilidad de usuarios, configurada a través de _PATH_UTMP en <paths.h>
/var/log/wtmp
archivo de registro de contabilidad de usuarios, configurado a través de _PATH_WTMP en <paths.h>

ATRIBUTOS

Para una explicación de los términos utilizados en esta sección, consulte attributes(7).

Interfaz Atributo Valor
login (), logout () Seguridad de hilos MT-Unsafe race:utent sig:ALRM timer

En la tabla anterior, utent en race:utent significa que si alguna de las funciones setutent(3), getutent(3), o endutent(3) se utilizan en paralelo en hilos diferentes de un programa, podrían ocurrir condiciones de carrera de datos. login() y logout() llaman a esas funciones, por lo que utilizamos race:utent para recordar a los usuarios.

VERSIONES

El miembro ut_user de struct utmp se llama ut_name en BSD. Por lo tanto, ut_name se define como un alias para ut_user en <utmp.h>.

ESTÁNDARES

BSD.

VER TAMBIÉN

getutent(3), utmp(5)
