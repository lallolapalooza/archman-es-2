LOWDOWN_NROFF_NEW(3) Manual de funciones de biblioteca LOWDOWN_NROFF_NEW(3)

NOMBRE

lowdown_nroff_new — asigna un renderizador roff para documentos lowdown

BIBLIOTECA

biblioteca “liblowdown”

SINOPSIS

#include <sys/queue.h>
#include <stdio.h>
#include <lowdown.h>

void *
lowdown_nroff_new(const struct lowdown_opts *opts);

DESCRIPCIÓN

Asigna un renderizador roff usando opts->oflags y opts->type, o cero y LOWDODN_NROFF, respectivamente, si opts es NULL. Estos se documentan en lowdown(3). El puntero devuelto puede usarse con múltiples invocaciones de lowdown_nroff_rndr(3) y debe liberarse con lowdown_nroff_free(3).

Los bits reconocidos en opts->oflags son LOWDOWN_NROFF_ENDNOTES, LOWDOWN_NROFF_GROFF, LOWDOWN_NROFF_NOLINK, LOWDOWN_NROFF_NUMBERED, LOWDOWN_NROFF_SHORTLINK, LOWDOWN_NROFF_SKIP_HTML, y LOWDOWN_STANDALONE.

Los valores reconocidos en opts->type son LOWDOWN_MAN y LOWDODN_NROFF: cualquier otra cosa activa LOWDODN_NROFF.

Si LOWDOWN_NROFF_GROFF está establecido en modo LOWDOWN_MAN, se usan macros del paquete man-ext así como el man original. Estos son compatibles tanto con groff como con mandoc. Si está en modo LOWDODN_NROFF, se utilizan extensiones GNU a ms junto con mspdf. Estos solo son compatibles con groff.

LOWDOWN_NROFF_ENDNOTES retrasa la impresión de notas al pie hasta el final de un documento. No afecta a los documentos LOWDOWN_MAN, que estructuralmente solo admiten notas al final.

El renderizador asignado utilizará fuentes de ancho constante "CR" (regular), "CB" (negrita), "CI" (itálica) y "CBI" (negrita-itálica). Sobrescribe los valores predeterminados con variables en la estructura struct lowdown_opts_nroff.

VALORES DE RETORNO

Devuelve un puntero al renderizador o NULL en caso de fallo de memoria. El puntero devuelto debe liberarse con lowdown_nroff_free(3).

EJEMPLOS

Lo siguiente analiza b de longitud bsz y genera la salida en formato groff_ms(7).

struct lowdown_buf *out;
struct lowdown_doc *doc;
struct lowdown_node *n;
void *rndr;

if ((doc = lowdown_doc_new(NULL)) == NULL)
	err(1, NULL);
if ((n = lowdown_doc_parse(doc, NULL, b, bsz, NULL)) == NULL)
	err(1, NULL);
if ((out = lowdown_buf_new(256)) == NULL)
	err(1, NULL);
if ((rndr = lowdown_nroff_new(NULL)) == NULL)
	err(1, NULL);
if (!lowdown_nroff_rndr(out, rndr, n))
	err(1, NULL);

fwrite(out->data, 1, out->size, stdout);

lowdown_nroff_free(rndr);
lowdown_buf_free(out);
lowdown_node_free(n);
lowdown_doc_free(doc);

VER TAMBIÉN

lowdown(3), lowdown_nroff_free(3), lowdown_nroff_rndr(3),

Esto utiliza tanto las macros originales de troff man para Version 7 AT&T UNIX, definidas en man(7), como las extensiones groff man-ext. Ambas están implementadas en mandoc.

Las macros troff ms se definen en groff_ms(7), con las extensiones groff mspdf descritas en "Portable Document Format Publishing with GNU Troff" de Keith Marshall. Ninguna está implementada en mandoc.

ADVERTENCIAS

Las fuentes de ancho constante predeterminadas pueden no estar disponibles para el dispositivo de salida del formateador (por ejemplo, el terminal). En este caso, el formateador puede mostrar una advertencia e ignorar la fuente.
