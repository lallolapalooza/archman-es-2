NOMBRE

logwatch.conf, ignore.conf, override.conf - archivos de configuración de logwatch

DESCRIPCIÓN

logwatch.conf - ( /etc/logwatch/conf/logwatch.conf ) - puede contener las opciones de configuración locales. La lista de ajustes válidos y sus valores predeterminados se encuentran en /usr/share/logwatch/default.conf/logwatch.conf.

ignore.conf - ( /etc/logwatch/conf/ignore.conf ) es la lista de expresiones regulares. El conjunto de logs descritos por este conjunto es ignorado por logwatch.

override.conf - ( /etc/logwatch/conf/override.conf ) contiene los ajustes que anulan la configuración estándar de archivos de log o servicios específicos. La sintaxis es la misma que en los archivos de log/servicio.

ARCHIVOS

/etc/logwatch/conf/logwatch.conf /etc/logwatch/conf/ignore.conf /etc/logwatch/conf/override.conf /usr/share/logwatch/default.conf/logwatch.conf
