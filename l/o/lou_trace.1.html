LOU_TRACE(1) Comandos de usuario LOU_TRACE(1)

NOMBRE

lou_trace - Una herramienta para listar todas las reglas que se usaron para una traducción de Braille

SINOPSIS

lou_trace [OPCIONES] TABLA[,TABLA,...]

DESCRIPCIÓN

Examina y depura tablas de traducción de Braille. Este programa te permite inspeccionar las tablas de traducción de liblouis imprimiendo la lista de reglas de traducción aplicadas para una entrada dada.

-h, --help
muestra esta ayuda y sale
-v, --version
muestra la información de la versión y sale
-f, --forward
traducción hacia adelante usando la tabla dada
-b, --backward
traducción hacia atrás usando la tabla dada
--noContractions
No usar contracciones
--dotsIO
Mostrar patrones de puntos
--ucBrl
Usar patrones de Braille Unicode
--noUndefined
Deshabilitar la salida de números de puntos indefinidos durante la retrotraducción
--partialTrans
Usar retrotraducción parcial. Si no se especifican ni -f ni -b, se asume traducción hacia adelante.
