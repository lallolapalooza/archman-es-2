LOWDOWN(3) Manual de Funciones de Biblioteca LOWDOWN(3)

NOMBRE

lowdown — biblioteca traductora simple de markdown

BIBLIOTECA

biblioteca “liblowdown”

SINOPSIS

#include <sys/queue.h>
#include <stdio.h>
#include <lowdown.h>

struct lowdown_meta
struct lowdown_node
struct lowdown_opts

DESCRIPCIÓN

Esta biblioteca analiza lowdown(5) en varios formatos de salida.

La biblioteca consta primero de una interfaz de alto nivel que incluye lowdown_buf(3), lowdown_buf_diff(3), lowdown_file(3), y lowdown_file_diff(3).

Las funciones de alto nivel interactúan con funciones de bajo nivel que realizan el análisis y el formateo. Estas consisten en lowdown_doc_new(3), lowdown_doc_parse(3), y lowdown_doc_free(3) para analizar documentos lowdown(5) en un árbol de sintaxis abstracta.

Las funciones front-end para liberar, asignar y renderizar son las siguientes.

  • HTML5:
    • lowdown_html_free(3)
    • lowdown_html_new(3)
    • lowdown_html_rndr(3)
  • gemini:
    • lowdown_gemini_free(3)
    • lowdown_gemini_new(3)
    • lowdown_gemini_rndr(3)
  • LaTeX:
    • lowdown_latex_free(3)
    • lowdown_latex_new(3)
    • lowdown_latex_rndr(3)
  • OpenDocument:
    • lowdown_odt_free(3)
    • lowdown_odt_new(3)
    • lowdown_odt_rndr(3)
  • roff:
    • lowdown_nroff_free(3)
    • lowdown_nroff_new(3)
    • lowdown_nroff_rndr(3)
  • terminal UTF-8:
    • lowdown_term_free(3)
    • lowdown_term_new(3)
    • lowdown_term_rndr(3)
  • depuración:
    • lowdown_tree_rndr(3)

Para compilar y enlazar, usa pkg-config(1):

% cc `pkg-config --cflags lowdown` -c -o sample.o sample.c
% cc -o sample sample.o `pkg-config --libs lowdown`

Promesas Pledge

La biblioteca lowdown está construida para operar en entornos sensibles a la seguridad, como aquellos que usan pledge(2) en OpenBSD. La única promesa requerida es stdio para lowdown_file_diff(3) y lowdown_file(3): ambos requieren acceso al flujo para leer la entrada.

TIPOS

Todas las funciones de lowdown utilizan una o más de las siguientes estructuras.

La estructura principal para configurar el análisis y la salida es struct lowdown_opts. Tiene los siguientes campos:

enum lowdown_type type
El medio de salida:
LOWDOWN_HTML
HTML5
LOWDOWN_LATEX
LaTeX
LOWDOWN_MAN
macros roff -man
LOWDOWN_FODT
OpenDocument "plano" (ODT)
LOWDOWN_TERM
salida de terminal UTF-8 compatible con ANSI
LOWDOWN_GEMINI
formato "gemtext" de Gemini
LOWDOWN_NROFF
macros roff -ms
LOWDOWN_TREE
árbol de sintaxis (depuración)
unsigned int feat
Características en tiempo de análisis. Este campo de bits puede tener los siguientes bits OR'ados:
LOWDOWN_ATTRS
Analiza atributos de enlaces, encabezados e imágenes adicionales de PHP.
LOWDOWN_AUTOLINK
Analiza enlaces relativos o fragmentos de enlaces http, https, ftp, mailto.
LOWDOWN_CALLOUTS
Analiza llamadas (moniciones) MDN/GFM.
LOWDOWN_COMMONMARK
Ajusta el análisis de entrada a la especificación CommonMark. Esto también utiliza el primer valor de lista ordenada en lugar de empezar todas las listas en uno. Esta característica es experimental e incompleta.
LOWDOWN_DEFLIST
Analiza listas de definición adicionales de PHP. Actualmente se limita a listas de una sola clave.
LOWDOWN_FENCED
Analiza bloques de código GFM cercados (específicos del lenguaje).
LOWDOWN_FOOTNOTES
Analiza notas al pie estilo MMD. Solo admite el estilo de nota al pie referenciada, no el estilo "en línea".
LOWDOWN_HILITE
Analiza secuencias resaltadas. Estas están deshabilitadas por defecto porque pueden ser interpretadas erróneamente como encabezados de sección.
LOWDOWN_IMG_EXT
Obsoleto. Usa LOWDOWN_ATTRS en su lugar.
LOWDOWN_MANTITLE
Reconoce ma

NAME

lowdown ― A fast Markdown translator.

LIBRARY

liblowdown, -llowdown

SYNOPSIS

lowdown







DESCRIPTION


The lowdown utility is a fast Markdown
    translator. It parses Markdown and converts it to HTML, and can also be
    used to generate Nroff, LaTeX, and other formats.


This page describes the library functions for lowdown.
    See lowdown(5) for the command-line
    utility.






TYPES


This section describes the various data types used by the
    lowdown library.






ABSTRACT SYNTAX TREE


The lowdown library parses Markdown into an
    abstract syntax tree (AST). This AST can then be rendered into various
    output formats.
