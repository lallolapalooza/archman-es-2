LOCALTIME(3P) Manual del programador POSIX LOCALTIME(3P)

PRÓLOGO

Esta página del manual forma parte del Manual del programador POSIX. La implementación de esta interfaz en Linux puede diferir (consulte la página del manual de Linux correspondiente para conocer los detalles del comportamiento de Linux), o la interfaz puede no estar implementada en Linux.

NOMBRE

localtime, localtime_r — convertir un valor de tiempo a una hora local desglosada

SINOPSIS

#include <time.h>
struct tm *localtime(const time_t *timer);
struct tm *localtime_r(const time_t *restrict timer,
    struct tm *restrict result);

DESCRIPCIÓN

Para localtime(): La funcionalidad descrita en esta página de referencia está alineada con el estándar ISO C. Cualquier conflicto entre los requisitos descritos aquí y el estándar ISO C es involuntario. Este volumen de POSIX.1‐2017 se remite al estándar ISO C.

La función localtime() convertirá la hora en segundos desde la Época apuntada por timer en una hora desglosada, expresada como hora local. La función corrige la zona horaria y cualquier ajuste de hora estacional. La información de la zona horaria local se utiliza como si localtime() llamara a tzset().

La relación entre una hora en segundos desde la Época utilizada como argumento para localtime() y la estructura tm (definida en la cabecera <time.h>) es que el resultado será según lo especificado en la expresión dada en la definición de segundos desde la Época (consulte el volumen de Definiciones Base de POSIX.1‐2017, Sección 4.16, Segundos desde la Época) corregido por la zona horaria y cualquier ajuste de hora estacional, donde los nombres en la estructura y en la expresión corresponden.

La misma relación se aplicará a localtime_r().

La función localtime() no es necesariamente segura para hilos (thread-safe).

Las funciones asctime(), ctime(), gmtime() y localtime() devolverán valores en uno de dos objetos estáticos: una estructura de tiempo desglosada y un array de tipo char. La ejecución de cualquiera de las funciones puede sobrescribir la información devuelta en cualquiera de estos objetos por cualquiera de las otras funciones.

La función localtime_r() convertirá la hora en segundos desde la Época apuntada por timer en una hora desglosada almacenada en la estructura a la que apunta result. La función localtime_r() también devolverá un puntero a esa misma estructura.

A diferencia de localtime(), no se requiere que localtime_r() establezca tzname. Si localtime_r() establece tzname, también establecerá daylight y timezone. Si localtime_r() no establece tzname, no establecerá daylight y no establecerá timezone.

VALOR DE RETORNO

Al completarse con éxito, la función localtime() devolverá un puntero a la estructura de tiempo desglosada. Si se detecta un error, localtime() devolverá un puntero nulo y establecerá errno para indicar el error.

Al completarse con éxito, localtime_r() devolverá un puntero a la estructura apuntada por el argumento result. Si se detecta un error, localtime_r() devolverá un puntero nulo y establecerá errno para indicar el error.

ERRORES

Las funciones localtime() y localtime_r() fallarán si:

EOVERFLOW
El resultado no se puede representar.

EJEMPLOS

Obtener la fecha y hora local

El siguiente ejemplo utiliza la función time() para calcular el tiempo transcurrido, en segundos, desde el 1 de enero de 1970 0:00 UTC (la Época), localtime() para convertir ese valor a una hora desglosada, y asctime() para convertir los valores de hora desglosada en una cadena imprimible.

#include <stdio.h>
#include <time.h>
int main(void)
{
    time_t result;

    result = time(NULL);
    printf("%s%ju secs since the Epoch\n",
        asctime(localtime(&result)),
            (uintmax_t)result);
    return(0);
}

Este ejemplo escribe la hora actual en stdout con un formato como este:

Mié Jun 26 10:32:15 1996
835810335 secs since the Epoch

Obtener la hora de modificación de un archivo

El siguiente ejemplo imprime la marca de tiempo de la última modificación de datos en la zona horaria local para un archivo dado.

#include <stdio.h>
#include <time.h>
#include <sys/stat.h>
int
print_file_time(const char *pathname)
{
    struct stat statbuf;
    struct tm *tm;
    char timestr[BUFSIZ];

    if(stat(pathname, &statbuf) == -1)
        return -1;
    if((tm = localtime(&statbuf.st_mtime)) == NULL)
        return -1;
    if(strftime(timestr, sizeof(timestr), "%Y-%m-%d %H:%M:%S", tm) == 0)
        return -1;
    printf("%s: %s.%09ld\n", pathname, timestr, statbuf.st_mtim.tv_nsec);
    return 0;
}

Cronometrar un evento

El siguiente ejemplo obtiene la hora actual, la convierte en una cadena usando localtime() y asctime(), y la imprime en la salida estándar usando fputs(). Luego imprime los minutos hasta un evento que se está cronometrando.

#include <time.h>
#include <stdio.h>
...
time_t now;
int minutes_to_event;
...
time(&now);
printf("The time is ");
fputs(asctime(localtime(&now)), stdout);
printf("There are still %d minutes to the event.\n",
    minutes_to_event);
...

USO DE LA APLICACIÓN

La función localtime_r() es segura para hilos (thread-safe) y devuelve valores en un búfer proporcionado por el usuario en lugar de usar potencialmente un área de datos estática que podría ser sobrescrita en cada llamada.
