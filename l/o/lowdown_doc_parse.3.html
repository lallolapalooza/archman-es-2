Paquete: lowdown

Licencias: ISC

LOWDOWN_DOC_PARSE(3) Manual de funciones de biblioteca LOWDOWN_DOC_PARSE(3)

NOMBRE

lowdown_doc_parse — analiza un documento Markdown en un AST

BIBLIOTECA

biblioteca “liblowdown”

SINOPSIS

#include <sys/queue.h>
#include <stdio.h>
#include <lowdown.h>

struct lowdown_node *
lowdown_doc_parse(struct lowdown_doc *doc, size_t *maxn, const char *input, size_t inputsz, struct lowdown_metaq *metaq);

DESCRIPCIÓN

Analiza un documento lowdown(5) input de longitud inputsz en un AST con el analizador doc. El argumento maxn, si no es NULL, se establece en uno más que el identificador de nodo más alto. Su valor no está definido si la función devuelve NULL.

Si metaq no es NULL, se rellena con metadatos del documento (si los hay). Los nombres de las claves de metadatos se normalizan y se ignoran los nombres duplicados. Los resultados deben liberarse con lowdown_metaq_free(3).

Esta función puede invocarse varias veces con un único doc y diferentes entradas.

VALORES DE RETORNO

Devuelve la raíz del árbol de análisis o NULL en caso de fallo de asignación de memoria. Si no es NULL, el nodo devuelto es siempre de tipo LOWDOWN_ROOT.

EJEMPLOS

El siguiente código analiza b de longitud bsz. Primero asigna el analizador, luego el documento, luego el renderizador (se usa HTML en este caso). Luego pasa la salida al renderizador, la imprime y libera los recursos. Ante cualquier error de memoria, sale con err(3).

struct lowdown_doc *doc;
struct lowdown_node *n;
struct lowdown_buf *ob;
void *rndr;

if ((doc = lowdown_doc_new(NULL)) == NULL)
	err(1, NULL);
if ((n = lowdown_doc_parse(doc, NULL, b, bsz, NULL)) == NULL)
	err(1, NULL);
if ((rndr = lowdown_html_new(NULL)) == NULL)
	err(1, NULL);
if ((ob = lowdown_buf_new(1024)) == NULL)
	err(1, NULL);
if (!lowdown_html_rndr(ob, rndr, n))
	err(1, NULL);

fwrite(stdout, 1, ob->size, ob->data);

lowdown_buf_free(ob);
lowdown_html_rndr_free(rndr);
lowdown_node_free(n);
lowdown_doc_free(doc);
