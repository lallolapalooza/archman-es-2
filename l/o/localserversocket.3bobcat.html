FBB::LocalServerSocket(3bobcat) Socket de servidor de dominio Unix FBB::LocalServerSocket(3bobcat)

NOMBRE

FBB::LocalServerSocket - Socket de servidor de dominio Unix que acepta solicitudes de conexión

SINOPSIS

#include <bobcat/localserversocket>
Opción de enlace: -lbobcat

DESCRIPCIÓN

Un FBB::LocalServerSocket define un socket de servidor de dominio Unix, escuchando solicitudes de conexión del host local utilizando un socket de dominio Unix. Las solicitudes de conexión se pueden aceptar en modo bloqueante o no bloqueante. Cuando se acepta una conexión, se devuelve un socket que puede usarse para leer información o escribir información al cliente que solicita la conexión. El socket que se pone a disposición es un descriptor de archivo que puede usarse para inicializar un std::istream y/o std::ostream. El std::istream se utiliza para leer información del proceso cliente; el std::ostream se utiliza para enviar información al proceso cliente. Dado que un socket puede considerarse un descriptor de archivo, las clases disponibles FBB::IFdStream, FBB::IFdStreamBuf, FBB::OFdStream y FBB::OFdStreamBuf pueden ser útiles aquí. Tenga en cuenta que tener un socket disponible no significa que esto defina el protocolo de comunicación. Es (todavía) responsabilidad del programador cumplir con un protocolo existente o implementar un protocolo hecho a medida. Esta última situación implica que la secuencia de operaciones de entrada y salida está definida por el programador.

ESPACIO DE NOMBRES

FBB
Todos los constructores, miembros, operadores y manipuladores mencionados en esta página del manual están definidos en el espacio de nombres FBB.

HEREDA DE

FBB::LocalSocketBase

ENUMERACIÓN

La siguiente enumeración está definida en la clase FBB::LocalServerSocket:

enum Socket
Esta enumeración contiene dos valores:

o
KEEP:
Cuando este valor se especifica en el momento de la construcción, el archivo que representa el Socket de Dominio Unix no se elimina cuando se destruye el LocalServerSocket.
o
UNLINK:
Cuando este valor se especifica en el momento de la construcción, el archivo que representa el Socket de Dominio Unix se elimina cuando se destruye el LocalServerSocket. Como un socket no se puede reutilizar, este es el valor predeterminado utilizado con el constructor de LocalServerSocket.

CONSTRUCTOR

o
LocalServerSocket():
Este constructor crea un objeto FBB::LocalServerSocket vacío (no funcional). Antes de que pueda ser utilizado, se debe llamar al miembro open() (ver más abajo).
o
LocalServerSocket(string const &name, Socket action = UNLINK) throw (Exception):
Este constructor inicializa un objeto FBB::LocalServerSocket, que escuchará las solicitudes de conexión utilizando el socket de dominio Unix con nombre. Se lanza una FBB::Exception si no se pudo construir el socket. Si el constructor recibe un segundo argumento FBB::LocalServerSocket::KEEP, el socket construido no se elimina cuando se destruye el objeto FBB::LocalServerSocket. La construcción del socket no significa que el objeto FBB::LocalServerSocket esté realmente escuchando conexiones. Para empezar a escuchar, se debe llamar al miembro listen().

Los constructores de copia y movimiento (y los operadores de asignación) no están disponibles.

FUNCIONES MIEMBRO

o
size_t accept():
El miembro accept() devuelve un size_t que es un descriptor de archivo (socket) que puede usarse para comunicarse con el cliente que solicita la conexión. En programas más complejos, el descriptor de archivo (socket) devuelto podría pasarse a una clase derivada de FBB::Fork, manejando la comunicación con el hijo como un proceso separado (hijo).
o
void listen(size_t backlog = 5, bool blocking = true):
El miembro listen() define la forma en que el FBB::LocalServerSocket escuchará a los clientes que solicitan una conexión. Solo se puede usar una vez con un FBB::LocalServerSocket. Se lanza un objeto FBB::Exception si la escucha falla.
El parámetro backlog del miembro listen() define el tamaño de la cola interna del FBB::LocalServerSocket en la que las solicitudes de conexión pueden almacenarse esperando su turno para ser atendidas. Cuando hay backlog solicitudes en espera y llega otra solicitud, esta se pierde.
El segundo parámetro del miembro, blocking, se utiliza para controlar el modo de bloqueo. Por defecto, se utiliza el bloqueo, y listen() esperará hasta que se establezca una conexión. Esto está bien en situaciones en las que los clientes se conectan con poca frecuencia y durante intervalos de tiempo relativamente cortos. De lo contrario, en programas más complejos, un objeto FBB::Selector puede usarse para detectar entrada en el socket del servidor y/o en varios sockets de cliente.
o
void open(string const &name, Socket action = UNLINK):
Este miembro prepara un objeto FBB::LocalServerSocket para su uso. Solo debe usarse en combinación con el constructor predeterminado. Después de open(), el objeto FBB:::LocalServerSocket podrá escuchar solicitudes de conexión utilizando el socket de dominio Unix con nombre. Se lanza una FBB::Exception si no se pudo construir el socket. Si se proporciona un segundo argumento FBB::LocalServerSocket::KEEP, el socket construido no se elimina cuando se destruye el objeto FBB::LocalServerSocket. La construcción del socket no significa que el objeto FBB::LocalServerSocket esté realmente escuchando conexiones. Para empezar a escuchar, se debe llamar al miembro listen() a continuación.

EJEMPLO

Ver también el ejemplo de localclientsocket(3bobcat).

    #include <iostream>
    #include <bobcat/localserversocket>
    #include <bobcat/ifdstream>
    #include <bobcat/ofdstream>
    using namespace std;
    using namespace FBB;
    int main(int argc, char **argv)
    try
    {
        if (argc == 1)
        {
            cerr << "Proporcione el nombre de archivo local, por ejemplo, /tmp/uds\n";
            return 1;
        }
        LocalServerSocket server(argv[1]);
        cerr << "servidor usando `" << argv[1] << "’" << endl;
        cout <<
            "El servidor termina cuando recibe una sola `q’ en una línea\n"
            "Una conexión termina cuando ya no se recibe entrada\n"
            "Luego es posible otra conexión" << endl;
        server.listen();                // escuchar en modo bloqueante
        while (true)
        {
            int fd = server.accept();
            cerr << "FD del cliente = " << fd << ", " << endl;
            IFdStream in(fd);           // stream para leer del cliente
            OFdStream out(fd);          // stream para escribir al cliente
            string cmd;
            while (getline(in, cmd))
            {
                cout << "Recibido: " << cmd << endl;
                out << "Recibido: " << cmd << "\r" << endl;
                if (cmd[0] == ’q’)
                    return 0;
            }
            cout << "Listo para otra conexión\n";
        }
    }
    catch (Exception const &err)
    {
        cerr <<
            err.what() << endl <<
            "No se puede abrir el socket del servidor en el puerto " << argv[1] <<
            "" << endl;
        return -1;
    }
