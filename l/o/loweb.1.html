loweb(1) Comandos de Usuario loweb(1)

Nombre

libreoffice - Suite ofimática LibreOffice

SINOPSIS

libreoffice [--accept=cadena-aceptar] [--base] [--calc] [--convert-to extension_archivo_salida[:nombre_filtro_salida] [--outdir directorio_salida] archivo]... [--display pantalla] [--draw] [--global] [--headless] [--help|-h|-?] [--impress] [--invisible] [--infilter="<filtro>"] [--math] [--minimized] [-n archivo]... [--nodefault] [--nolockcheck] [--nologo] [--norestore] [-o archivo]... [-p archivo...] [--print-to-file [--printer-name nombre_impresora] [--outdir directorio_salida] archivo]... [--pt nombre_impresora archivo...] [--show archivo_Impress]... [--unaccept=cadena-aceptar] [--terminate_after_init] [--view archivo]... [--web] [--writer] [archivo...]
lobase
localc
lodraw
lofromtemplate
loimpress
lomath
loweb
lowriter

DESCRIPCIÓN

LibreOffice (LO para abreviar) es una suite ofimática multiplataforma. Se derivó de OpenOffice.org 3.3 Beta el 28 de septiembre de 2010.

libreoffice es un script de shell que configura el entorno y pasa los argumentos de la línea de comandos al binario soffice.bin.

Alternativamente, los siguientes scripts auxiliares inician el módulo correspondiente:

sbase, scalc, sdraw, simpress, smath, sofficerc, swriter

OPCIONES

--accept=cadena-aceptar
Especifica una cadena de conexión UNO-URL para crear un aceptador UNO a través del cual otros programas pueden conectarse para acceder a la API. Tenga en cuenta que el acceso a la API permite la ejecución de comandos arbitrarios. La sintaxis de una cadena de conexión UNO-URL es: uno:tipo-conexión,parámetros;nombre-protocolo,parámetros;NombreObjeto
--base
Inicia el asistente para un nuevo documento Base.
--calc
Inicia con un nuevo documento Calc.
--convert-to extension_archivo_salida[:nombre_filtro_salida] [--outdir directorio_salida] archivo...
Convierte archivos por lotes. Si no se especifica --outdir, el directorio de trabajo actual se utiliza como directorio de salida para los archivos convertidos. Implica --headless.

Ejemplos:

--convert-to pdf *.doc

Convierte todos los archivos .doc a PDF.

--convert-to pdf:writer_pdf_Export --outdir /home/usuario *.doc

Convierte todos los archivos .doc a PDF utilizando la configuración del cuadro de diálogo de exportación de PDF de Writer y guardándolos en /home/usuario.

--display pantalla
Esta opción especifica el servidor X a utilizar; ver X(7)
--draw
Inicia con un nuevo documento Draw.
--global
Inicia con un nuevo documento Global.
--headless
Inicia en modo "headless", lo que permite usar la aplicación sin interfaz de usuario.

Este modo especial se puede utilizar cuando la aplicación es controlada por clientes externos a través de la API.

Implica --invisible e ignora estrictamente cualquier entorno GUI. --quickstart no funciona con este parámetro.

--help|-h|-?
Enumera los parámetros de la línea de comandos de LibreOffice.
--impress
Inicia con un nuevo documento Impress.
--invisible
Inicia en modo invisible.

Ni el logotipo de inicio ni la ventana inicial del programa serán visibles. LO se puede controlar y se pueden abrir documentos y cuadros de diálogo a través de la API.

Cuando se inicia con este parámetro, solo se puede salir utilizando el administrador de tareas (Windows) o el comando kill (sistemas basados en UNIX).

--quickstart no funciona con este parámetro.

--infilter="<filtro>"
Fuerza un tipo de filtro de entrada si es posible. Por ejemplo --infilter="Calc Office Open XML" solamente
--math
Inicia con un nuevo documento Math.
--minimized
Mantiene minimizada la pantalla de inicio.
-n plantilla...
Crea un nuevo documento a partir de las plantillas dadas.
--nodefault
Inicia LO sin crear un nuevo documento. La próxima vez que inicie LO, se mostrará la pantalla de bienvenida.

Se usa junto con --nologo por los quick starters. Tenga en cuenta que --quickstart ya no se admite desde OpenOffice.org 2.0.0.

--nolockcheck
Deshabilita la comprobación de instancias remotas que utilizan la instalación.
--nologo
Deshabilita la pantalla de inicio al iniciar el programa.
--norestore
Deshabilita la restauración y recuperación de archivos después de un fallo del sistema. Es posible que LO intente restaurar un archivo que sigue fallando, si eso sucede, --norestore es la única forma de iniciar LO.
--nosplash
Deshabilita la pantalla de inicio al iniciar el programa.
-o archivo...
Abre los archivos dados para editar, incluso plantillas.

Sin -o, un archivo de plantilla crearía un nuevo documento derivado de esa plantilla.

-p archivo...
Imprime los archivos dados en la impresora predeterminada y finaliza. La pantalla de inicio no aparece.

Si el nombre del archivo contiene espacios, debe ir entre comillas dobles.

--print-to-file [--printer-name nombre_impresora] [--outdir directorio_salida] archivo...
Imprime archivos por lotes a un archivo. Si no se especifica --printer-name, se utiliza la impresora predeterminada. Si no se especifica --outdir, el directorio de trabajo actual se utiliza como directorio de salida para los archivos convertidos.

Ejemplos:

--print-to-file *.doc

Imprime todos los archivos .doc en el directorio de trabajo actual utilizando la impresora predeterminada.

--print-to-file --printer-name impresora_baja_resolucion --outdir /home/usuario *.doc

Imprime todos los archivos .doc en el directorio /home/usuario utilizando la impresora de baja resolución.

--pt nombre_impresora archivo...
Imprime los archivos dados en la impresora nombre_impresora y finaliza. La pantalla de inicio no aparece.

Si un nombre de archivo contiene espacios, debe ir entre comillas dobles.

--quickstart --quickstart=no
Inicia LO con su quick starter. --quickstart deshabilita el quick starter.

No funciona con --invisible o --headless.

--show archivo_Impress...
Abre los archivos Impress dados, inicia la presentación y finaliza después de que hayan terminado.
--unaccept=cadena-aceptar
Cierra un aceptador que fue creado con la opción --accept.

Use --unaccept=all para cerrar todos los aceptadores abiertos.

Termina la aplicación después de la inicialización. Esto es útil para realizar pruebas de la GUI, o para instalar extensiones, etc.
--view archivo...
Abre los archivos dados en modo de solo lectura.
--web
Inicia con un nuevo documento de Writer en modo HTML.
--writer
Inicia con un nuevo documento Writer.

NAME

loweb - LibreOffice Web

SYNOPSIS

loweb [--help | -H] [--version] [-V] [--license [component] | -L [component]] [Options] [--] [Files...]

DESCRIPTION

LibreOffice is a free and powerful office suite. Its components are Writer, Calc, Impress, Draw, Math and Base. LibreOffice is a fork of OpenOffice.org.

loweb is the component for HTML editing.

OPTIONS

--accept <url>
Accepts incoming UNO connections from <url>. This is an expert option.
--as-window
Starts LibreOffice as a single application window. This will inhibit startup of new shell windows.
--base
Starts with a new Base document.
--calc
Starts with a new Calc document.
--convert-to output_extension[:output_filter_name] [-outdir output_dir]
Converts the given Files to the specified output_extension. If -outdir is not specified, the files are converted in the current directory. If output_filter_name is specified, it must be identical to the filter name used for the conversion. The conversion API will use the filter associated with the given output extension. Use --show-filter-names to see all available filter names.
--display display
Use the specified X-server display.
--draw
Starts with a new Draw document.
--extend url
Connects to an existing SO`/`UNO object at url. This is an expert option.
--filter-options "options"
Selects or defines the filter properties for the conversion. For example, use 
--filter-options "fdo#12345,fdo#67890"
to specify filter properties for the conversion. Check the documentation for the specific filter you are using.
--help-key key
Displays help for the given key.
--help-window window
Displays help for the given window.
--imprint
Prints the license information and exits.
--invisible
Starts LibreOffice without any window opening. The splash screen is also inhibited.
--langpair xx[-yy][:zz[-uu]]
Sets the language for the template. The default is xx. For example, `de` for German, `en-US` for American English. The optional second language pair is used for complex text layout (CTL).
--logo (dialog | no_logo)
Specifies whether the logo on the splash screen should be displayed or not.
--man section
Shows the man page for the given section.
--math
Starts with a new Math document.
--minimized
Starts LibreOffice minimized.
--norestore
Inhibits the auto-recovery mechanism. Use this option if you want to prevent LibreOffice from restoring documents from a previous session.
--nologo
Disables the splash screen.
--norun
Does not start any component. For internal use only.
--osargv <arg...>
Passes arguments to the UNO component.
--print-only [file...]
Prints the specified files and exits.
--pt printer_name
Sets the default printer.
