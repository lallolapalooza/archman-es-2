lowdown_latex_new(3)

Paquete: lowdown

Licencias: ISC

LOWDOWN_LATEX_NEW(3) Manual de funciones de la biblioteca LOWDOWN_LATEX_NEW(3)

NOMBRE

lowdown_latex_new — asigna un renderizador LaTeX de Markdown

BIBLIOTECA

biblioteca “liblowdown”

SINOPSIS

#include <sys/queue.h>
#include <stdio.h>
#include <lowdown.h>

void *
lowdown_latex_new(const struct lowdown_opts *opts);

DESCRIPCIÓN

Asigna un renderizador LaTeX utilizando opts->flags, o cero si opts es NULL. Este campo está documentado en lowdown(3). El puntero devuelto puede usarse con múltiples invocaciones de lowdown_latex_rndr(3) y debe liberarse con lowdown_latex_free(3).

Los bits reconocidos en opts->oflags son LOWDOWN_LATEX_NUMBERED, LOWDOWN_LATEX_SKIP_HTML, y LOWDOWN_STANDALONE.

VALORES DE RETORNO

Devuelve un puntero al renderizador o NULL en caso de fallo de memoria. El puntero devuelto debe liberarse con lowdown_latex_free(3).

EJEMPLOS

Lo siguiente analiza b de longitud bsz y genera la salida en formato LaTeX.

struct lowdown_buf *out;
struct lowdown_doc *doc;
struct lowdown_node *n;
void *rndr;

if ((doc = lowdown_doc_new(NULL)) == NULL)
	err(1, NULL);
if ((n = lowdown_doc_parse(doc, NULL, b, bsz, NULL)) == NULL)
	err(1, NULL);
if ((out = lowdown_buf_new(256)) == NULL)
	err(1, NULL);
if ((rndr = lowdown_latex_new(NULL)) == NULL)
	err(1, NULL);
if (!lowdown_latex_rndr(out, rndr, n))
	err(1, NULL);

fwrite(out->data, 1, out->size, stdout);

lowdown_latex_free(rndr);
lowdown_buf_free(out);
lowdown_node_free(n);
lowdown_doc_free(doc);

VER TAMBIÉN

lowdown(3), lowdown_latex_free(3), lowdown_latex_rndr(3)
