locale_t(3type) locale_t(3type)

NOMBRE

locale_t - objeto de configuración regional

BIBLIOTECA

Biblioteca C estándar (libc)

SINOPSIS

#include <locale.h>
typedef /* ... */  locale_t;

DESCRIPCIÓN

locale_t es un tipo utilizado para almacenar un objeto de configuración regional.

ESTÁNDARES

POSIX.1-2024.

HISTORIA

POSIX.1-2008.

NOTAS

Las siguientes cabeceras también proporcionan este tipo: <ctype.h>, <langinfo.h>, <monetary.h>, <string.h>, <strings.h>, <time.h>, <wchar.h>, <wctype.h>.

VER TAMBIÉN

duplocale(3), freelocale(3), newlocale(3), setlocale(3), uselocale(3), locale(5), locale(7)
