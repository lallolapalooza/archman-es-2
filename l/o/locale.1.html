locale(1) Manual de comandos generales locale(1)

NOMBRE

locale - obtener información específica de la configuración regional

SINOPSIS

locale [opción]
locale [opción] -a
locale [opción] -m
locale [opción] nombre ...

DESCRIPCIÓN

El comando locale muestra información sobre la configuración regional actual, o todas las configuraciones regionales, en la salida estándar.

Cuando se invoca sin argumentos, locale muestra la configuración regional actual para cada categoría de configuración regional (ver locale(5)), basándose en la configuración de las variables de entorno que controlan la configuración regional (ver locale(7)). Los valores para las variables establecidas en el entorno se imprimen sin comillas dobles, los valores implícitos se imprimen con comillas dobles.

Si se especifica alguna de las opciones -a o -m (o una de sus equivalentes de formato largo), el comportamiento es el siguiente:

--all-locales
-a
Muestra una lista de todas las configuraciones regionales disponibles. La opción -v hace que los metadatos LC_IDENTIFICATION sobre cada configuración regional se incluyan en la salida.
--charmaps
-m
Muestra los mapas de caracteres (archivos de descripción de conjuntos de caracteres) disponibles. Para mostrar el conjunto de caracteres actual para la configuración regional, use locale -c charmap.

El comando locale también puede recibir uno o más argumentos, que son los nombres de palabras clave de configuración regional (por ejemplo, date_fmt, ctype-class-names, yesexpr, o decimal_point) o categorías de configuración regional (por ejemplo, LC_CTYPE o LC_TIME). Para cada argumento, se muestra lo siguiente:

•
Para una palabra clave de configuración regional, el valor de esa palabra clave que se mostrará.
•
Para una categoría de configuración regional, se mostrarán los valores de todas las palabras clave de esa categoría.

Cuando se proporcionan argumentos, las siguientes opciones son significativas:

--category-name
-c
Para un argumento de nombre de categoría, escribe el nombre de la categoría de configuración regional en una línea separada antes de la lista de valores de palabras clave para esa categoría.
Para un argumento de nombre de palabra clave, escribe el nombre de la categoría de configuración regional para esta palabra clave en una línea separada antes del valor de la palabra clave.
Esta opción mejora la legibilidad cuando se especifican múltiples argumentos de nombre. Se puede combinar con la opción -k.
--keyword-name
-k
Para cada palabra clave cuyo valor se está mostrando, incluye también el nombre de esa palabra clave, de modo que la salida tenga el formato:

palabra clave="valor"

El comando locale también conoce las siguientes opciones:

--verbose
-v
Muestra información adicional para algunas combinaciones de opciones de línea de comandos y argumentos.
--help
-?
Muestra un resumen de las opciones y argumentos de la línea de comandos y sale.
--usage
Muestra un mensaje de uso corto y sale.
--version
-V
Muestra la versión del programa y sale.

ARCHIVOS

/usr/lib/locale/locale-archive
Ubicación habitual del archivo de configuración regional por defecto.
/usr/share/i18n/locales
Ruta habitual por defecto para los archivos de definición de configuración regional.

ESTÁNDARES

POSIX.1-2008.

HISTORIA

POSIX.1-2001.

EJEMPLOS

$ locale;
LANG=es_ES.UTF-8
LC_CTYPE="es_ES.UTF-8"
LC_NUMERIC="es_ES.UTF-8"
LC_TIME="es_ES.UTF-8"
LC_COLLATE="es_ES.UTF-8"
LC_MONETARY="es_ES.UTF-8"
LC_MESSAGES="es_ES.UTF-8"
LC_PAPER="es_ES.UTF-8"
LC_NAME="es_ES.UTF-8"
LC_ADDRESS="es_ES.UTF-8"
LC_TELEPHONE="es_ES.UTF-8"
LC_MEASUREMENT="es_ES.UTF-8"
LC_IDENTIFICATION="es_ES.UTF-8"
LC_ALL=
$ locale date_fmt;
%a %b %e %H:%M:%S %Z %Y
$ locale -k date_fmt;
date_fmt="%a %b %e %H:%M:%S %Z %Y"
$ locale -ck date_fmt;
LC_TIME
date_fmt="%a %b %e %H:%M:%S %Z %Y"
$ locale LC_TELEPHONE;
+%c (%a) %l
(%a) %l
11
1
UTF-8
$ locale -k LC_TELEPHONE;
tel_int_fmt="+%c (%a) %l"
tel_dom_fmt="(%a) %l"
int_select="11"
int_prefix="1"
telephone-codeset="UTF-8"

El siguiente ejemplo compila una configuración regional personalizada del directorio ./wrk con la utilidad localedef(1) en el directorio $HOME/.locale, luego prueba el resultado con el comando date(1), y luego establece las variables de entorno LOCPATH y LANG en el archivo de perfil de shell para que la configuración regional personalizada se utilice en las siguientes sesiones del usuario:

$ mkdir -p $HOME/.locale;
$ I18NPATH=./wrk/ localedef -f UTF-8 -i fi_SE $HOME/.locale/fi_SE.UTF-8;
$ LOCPATH=$HOME/.locale LC_ALL=fi_SE.UTF-8 date;
$ echo "export LOCPATH=\$HOME/.locale" >> $HOME/.bashrc;
$ echo "export LANG=fi_SE.UTF-8" >> $HOME/.bashrc;
