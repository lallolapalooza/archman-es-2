log(3) Manual de Funciones de Biblioteca log(3)

NOMBRE

log, logf, logl - función logaritmo natural

BIBLIOTECA

Biblioteca matemática (libm, -lm)

SINOPSIS

#include <math.h>
double log(double x);
float logf(float x);
long double logl(long double x);
Requisitos de la macro de prueba de características para glibc (ver feature_test_macros(7)):

logf(), logl():

    _ISOC99_SOURCE || _POSIX_C_SOURCE >= 200112L
        || /* Desde glibc 2.19: */ _DEFAULT_SOURCE
        || /* glibc <= 2.19: */ _BSD_SOURCE || _SVID_SOURCE

DESCRIPCIÓN

Estas funciones devuelven el logaritmo natural de x.

VALOR DE RETORNO

En caso de éxito, estas funciones devuelven el logaritmo natural de x.

Si x es un NaN, se devuelve un NaN.

Si x es 1, el resultado es +0.

Si x es infinito positivo, se devuelve infinito positivo.

Si x es cero, entonces ocurre un error de polo y las funciones devuelven -HUGE_VAL, -HUGE_VALF o -HUGE_VALL, respectivamente.

Si x es negativo (incluyendo infinito negativo), entonces ocurre un error de dominio y se devuelve un NaN (no es un número).

ERRORES

Consulte math_error(7) para obtener información sobre cómo determinar si ha ocurrido un error al llamar a estas funciones.

Los siguientes errores pueden ocurrir:

Error de dominio: x es negativo
errno se establece en EDOM. Se genera una excepción de punto flotante inválida (FE_INVALID).
Error de polo: x es cero
errno se establece en ERANGE. Se genera una excepción de punto flotante de división por cero (FE_DIVBYZERO).

ATRIBUTOS

Para una explicación de los términos utilizados en esta sección, consulte attributes(7).

Interfaz Atributo Valor
log (), logf (), logl () Seguridad en hilos MT-Safe

ESTANDARES

C11, POSIX.1-2008.

HISTORIAL

C99, POSIX.1-2001.

La variante que devuelve double también cumple con SVr4, 4.3BSD, C89.

ERRORES CONOCIDOS

En glibc 2.5 y anteriores, tomar el log() de un NaN produce una excepción de punto flotante inválida (FE_INVALID) errónea.

VER TAMBIÉN

cbrt(3), clog(3), log10(3), log1p(3), log2(3), sqrt(3)
