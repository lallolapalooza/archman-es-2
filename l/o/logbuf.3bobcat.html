FBB::LogBuf(3bobcat) flujo de mensajes de registro FBB::LogBuf(3bobcat)

NOMBRE

FBB::LogBuf - std::streambuf manejando mensajes de registro

SINOPSIS

#include <bobcat/logbuf>
Opción de enlace: -lbobcat

DESCRIPCIÓN

FBB::LogBuf es una clase derivada de std::streambuf que maneja mensajes de registro. El flujo al que se registran, las marcas de tiempo y los niveles de registro se pueden configurar tanto en el momento de la construcción como posteriormente. Se puede usar FBB::LogBuf para inicializar un std::ostream.

ESPACIO DE NOMBRES

FBB
Todos los constructores, miembros, operadores y manipuladores mencionados en esta página del manual están definidos en el espacio de nombres FBB.

HEREDA DE

std::streambuf

ENUMERACIONES

La enumeración TimeStamps está definida en el espacio de nombres FBB para ser utilizada al inicializar objetos FBB::LogBuf. Tiene los siguientes valores:

o
NOTIMESTAMPS:
Los mensajes de registro no tendrán marcas de tiempo antepuestas.
o
TIMESTAMPS:
Los mensajes de registro tendrán marcas de tiempo antepuestas.
o
UTCTIMESTAMPS:
Los mensajes de registro tendrán marcas de tiempo que muestren la hora UTC antepuestas.

La enumeración Active se utiliza para distinguir entre suspender la inserción de mensajes cuando el nivel de un mensaje no supera un nivel mínimo y suspender todas las inserciones de mensajes (por ejemplo, al suspender la inserción de mensajes en objetos FBB::Log después de llamar a su miembro off):

o
OFF:
Se suspenden todas las inserciones en el objeto LogBuf;
o
NOT_ACTIVE:
Se suspenden las inserciones de mensajes en el objeto LogBuf si sus niveles son menores que un mínimo especificado (como se establece, por ejemplo, con Log::setLevel).
o
ACTIVE:
Se insertan mensajes

CONSTRUCTORES

o
LogBuf(TimeStamps timestamps = TIMESTAMPS, bool active = true, char const *delim = " "):
Este constructor construye un objeto FBB::LogBuf que escribe sus mensajes de registro en std::cerr. Si el parámetro active se inicializa a false, no se registrarán mensajes hasta que la actividad del buffer se active (ver setActive() más abajo). El parámetro delim se inserta inmediatamente después de la marca de tiempo. Si un delimitador no es apropiado, se puede especificar una cadena vacía o un puntero 0. Cuando stamps == FBB::NOTIMESTAMPS, delim se ignora. Una marca de tiempo consiste en el mes, el día del mes y la hora (local) del mensaje actual, como aparece normalmente en los mensajes de los archivos de /var/log. Por ejemplo, Ago 5 13:52:23;
o
LogBuf(std::ostream &stream, TimeStamps timestamps = TIMESTAMPS, bool active = true, char const *delim = " "):
Este constructor construye un objeto FBB::LogBuf que escribe sus mensajes de registro en el flujo utilizado para inicializar su parámetro stream. Si el parámetro active se inicializa a false, no se registrarán mensajes hasta que la actividad del buffer se active (ver setActive() más abajo). El parámetro delim se inserta inmediatamente después de la marca de tiempo. Si un delimitador no es apropiado, se puede especificar una cadena vacía o un puntero 0. Cuando stamps == FBB::NOTIMESTAMPS, delim se ignora. Una marca de tiempo consiste en el mes, el día del mes y la hora (local) del mensaje actual, como aparece normalmente en los mensajes de los archivos de /var/log. Por ejemplo, Ago 5 13:52:23.

Los constructores de copia y movimiento (y los operadores de asignación) no están disponibles.

FUNCIONES MIEMBRO PÚBLICAS

Todos los miembros de std::streambuf están disponibles, ya que FBB::LogBuf hereda de esta clase.

o
bool active() const:
Devuelve true si los mensajes de registro se están procesando actualmente;
o
bool empty() const:
Devuelve true si el buffer del objeto está actualmente vacío (inicialmente o después de insertar un carácter de nueva línea);
o
void setStream(std::ostream &stream):
Este miembro puede usarse para cambiar el flujo al que se registran. Es responsabilidad del programador asegurarse de que el flujo externo permanezca disponible durante el tiempo que se inserten mensajes de registro en él;
o
void settimestamp(FBB::TimeStamps timestamps, char const *delim = " "):
La función miembro (des)activa la anteposición de marcas de tiempo. Use el valor FBB::TIMESTAMPS para anteponer marcas de tiempo, FBB::NOTIMESTAMPS suprime las marcas de tiempo. Una marca de tiempo consiste en el mes, el día del mes y la hora (local) del mensaje actual, como aparece normalmente en los mensajes de los archivos de /var/log. Por ejemplo, Ago 5 13:52:23. El parámetro delim se inserta inmediatamente después de la marca de tiempo. Si un delimitador no es apropiado, se puede especificar una cadena vacía o un puntero 0. Cuando stamps == FBB::NOTIMESTAMPS, delim se ignora;
o
void setActive(bool active):
A menos que el estado Active del objeto actual sea OFF, este miembro puede usarse para (des)activar el registro. El argumento true activa el registro, el argumento false lo desactiva. Si el estado Active actual es OFF, entonces este miembro no cambia el estado de actividad del objeto. Este miembro normalmente lo llaman los miembros de FBB::Log::level;
o
void setActive(Active active):
La función miembro (des)activa el registro. El argumento ACTIVE activa el registro, el argumento OFF suprime completamente el registro, el argumento NOT_ACTIVE también suprime el registro, pero aquí setActive(true) también puede usarse para reactivar el registro;
o
void setEmpty(bool empty):
Este miembro puede llamarse para asegurar que se inserte una marca de tiempo antes de la siguiente inserción. Se llama como setEmpty(true) cuando se inserta un carácter de nueva línea (\n), asegurando que se anteponga otra marca de tiempo antes de la siguiente inserción.

EJEMPLO

#include <iostream>
#include <iomanip>
#include <bobcat/log>
#include <bobcat/level>
using namespace std;
using namespace FBB;
int main()
{
    LogBuf buffer(cout, FBB::TIMESTAMPS);
    ostream log(&buffer);
    log << "Este mensaje se escribe en cout" << nl <<
           setw(16) << ’ ’ << "ocupando varias líneas\n";
    buffer.setActive(false);
    log << "una línea\n";
    log << "más líneas ";
    log << fnl;
    log << "otra\n";
    buffer.setActive(true);
    log << "y activo de nuevo\n";
    log << "otro mensaje de registro\n";
}
