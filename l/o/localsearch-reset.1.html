LOCALSEARCH-RESET(1) Manual de LocalSearch LOCALSEARCH-RESET(1)

NOMBRE

localsearch-reset - Borrar los datos indexados

SINOPSIS

localsearch reset [--filesystem] [--file ARCHIVO]

DESCRIPCIÓN

El comando reset modificará su configuración o índice de forma irreversible y debe usarse con cuidado. Aparte de las etiquetas, los datos reales (por ejemplo, archivos) no se verán afectados por este comando.

El "índice" es un enlace entre su contenido (local o remoto) y cómo se puede encontrar rápidamente utilizando una serie de consultas diferentes. Internamente, esto se hace utilizando una base de datos.

Eliminar todos los datos y comenzar de nuevo desde el principio con un conjunto de datos vacío (que es un uso común de este comando) hará que LocalSearch se comporte como si acabara de ser instalado.

OPCIONES

-s, --filesystem

Elimina los datos del sistema de archivos indexados. El indexador volverá a crear automáticamente su caché del sistema de archivos cuando se reinicie. Esta opción es la predeterminada si no se proporcionan argumentos.

-f, --file ARCHIVO

Restablece toda la información indexada sobre ARCHIVO, funciona recursivamente para directorios. No se hará nada si ARCHIVO no está indexado actualmente. Después de la eliminación, se emitirá inmediatamente una solicitud para volver a indexar estos datos.

VER TAMBIÉN

localsearch-daemon(1). localsearch-3(1).
