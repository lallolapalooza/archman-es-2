lowdown_gemini_new(3)

Paquete: lowdown

Licencias: ISC

LOWDOWN_GEMINI_NEW(3) Manual de funciones de biblioteca LOWDOWN_GEMINI_NEW(3)

NOMBRE

lowdown_gemini_new — asigna un renderizador de Markdown para Gemini

BIBLIOTECA

biblioteca “liblowdown”

SINOPSIS

#include <sys/queue.h>
#include <stdio.h>
#include <lowdown.h>

void *
lowdown_gemini_new(const struct lowdown_opts *opts);

DESCRIPCIÓN

Asigna un renderizador Gemini utilizando opts->oflags, o cero si opts es NULL. El puntero devuelto puede usarse con múltiples invocaciones de lowdown_gemini_rndr(3) y debe liberarse con lowdown_gemini_free(3).

Los bits reconocidos en opts->oflags son LOWDOWN_GEMINI_LINK_IN, LOWDOWN_GEMINI_LINK_END, LOWDOWN_GEMINI_LINK_NOREF, LOWDOWN_GEMINI_LINK_ROMAN, LOWDOWN_GEMINI_METADATA y LOWDOWN_STANDALONE. Estos se documentan en lowdown(3).

VALORES DE RETORNO

Devuelve un puntero al renderizador o NULL en caso de fallo de memoria. El puntero devuelto debe liberarse con lowdown_gemini_free(3).

EJEMPLOS

Lo siguiente analiza b de longitud bsz y genera la salida en formato Gemini.

struct lowdown_buf *out;
struct lowdown_doc *doc;
struct lowdown_node *n;
void *rndr;

if (setlocale(LC_CTYPE, "en_US.UTF-8") == NULL)
	err(1, NULL);
if ((doc = lowdown_doc_new(NULL)) == NULL)
	err(1, NULL);
if ((n = lowdown_doc_parse(doc, NULL, b, bsz, NULL)) == NULL)
	err(1, NULL);
if ((out = lowdown_buf_new(256)) == NULL)
	err(1, NULL);
if ((rndr = lowdown_gemini_new(NULL)) == NULL)
	err(1, NULL);
if (!lowdown_gemini_rndr(out, rndr, n))
	err(1, NULL);

fwrite(out->data, 1, out->size, stdout);

lowdown_gemini_free(rndr);
lowdown_buf_free(out);
lowdown_node_free(n);
lowdown_doc_free(doc);

VER TAMBIÉN

lowdown(3), lowdown_gemini_free(3), lowdown_gemini_rndr(3)

ESTÁNDARES

El formato "gemtext" de Gemini está documentado en Project Gemini. La versión en el momento de escribir esto es 0.24.1.
