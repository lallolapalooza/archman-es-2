DESCRIPCIÓN

LibreOffice (LO en adelante) es una suite ofimática multiplataforma. Se derivó de OpenOffice.org 3.3 Beta el 28 de septiembre de 2010.

libreoffice es un script de shell que configura el entorno y pasa los argumentos de la línea de comandos al binario soffice.bin.

Alternativamente, los siguientes scripts auxiliares inician el módulo respectivo:

sbase, scalc, sdraw, simpress, smath, sofficerc, swriter

OPCIONES

--accept=cadena-aceptación
Especifica una cadena de conexión UNO-URL para crear un aceptador UNO a través del cual otros programas pueden conectarse para acceder a la API. Tenga en cuenta que el acceso a la API permite la ejecución de comandos arbitrarios. La sintaxis de una cadena de conexión UNO-URL es: uno:tipo-conexión,parámetros;nombre-protocolo,parámetros;NombreObjeto
--base
Inicia el asistente para un nuevo documento Base.
--calc
Inicia con un nuevo documento Calc.
--convert-to extensión_archivo_salida[:nombre_filtro_salida] [--outdir directorio_salida] archivo...
Convierte archivos por lotes. Si no se especifica --outdir, el directorio de trabajo actual se utiliza como directorio de salida para los archivos convertidos. Implica --headless.

Ejemplos:

--convert-to pdf *.doc

Convierte todos los archivos .doc a PDF.

--convert-to pdf:writer_pdf_Export --outdir /home/usuario *.doc

Convierte todos los archivos .doc a PDF utilizando la configuración del cuadro de diálogo de exportación de PDF de Writer y guardándolos en /home/usuario.

--display pantalla
Esta opción especifica el servidor X a utilizar; ver X(7)
--draw
Inicia con un nuevo documento Draw.
--global
Inicia con un nuevo documento Global.
--headless
Inicia en modo "headless", lo que permite usar la aplicación sin interfaz de usuario.

Este modo especial se puede utilizar cuando la aplicación es controlada por clientes externos a través de la API.

Implica --invisible e ignora estrictamente cualquier entorno gráfico. --quickstart no funciona con este parámetro.

--help|-h|-?
Lista los parámetros de la línea de comandos de LibreOffice.
--impress
Inicia con un nuevo documento Impress.
--invisible
Inicia en modo invisible.

Ni el logotipo de inicio ni la ventana inicial del programa serán visibles. LO puede ser controlado y los documentos y diálogos pueden ser abiertos a través de la API.

Cuando se inicia con este parámetro, solo se puede salir usando el administrador de tareas (Windows) o el comando kill (sistemas basados en UNIX).

--quickstart no funciona con este parámetro.

--infilter="<filtro>"
Fuerza un tipo de filtro de entrada si es posible. Por ejemplo, --infilter="Calc Office Open XML" solamente.
--math
Inicia con un nuevo documento Math.
--minimized
Mantiene la pantalla de inicio minimizada.
-n plantilla...
Crea el nuevo documento a partir de las plantillas dadas.
--nodefault
Inicia LO sin crear un nuevo documento. La próxima vez que inicie LO, se mostrará la pantalla de bienvenida.

Se usa junto con --nologo por los iniciadores rápidos. Tenga en cuenta que --quickstart ya no se admite desde OpenOffice.org 2.0.0.

--nolockcheck
Deshabilita la comprobación de instancias remotas que utilizan la instalación.
--nologo
Deshabilita la pantalla de inicio al iniciar el programa.
--norestore
Deshabilita la recuperación de reinicio y archivos después de un fallo del sistema. Es posible que LO intente restaurar un archivo que sigue fallando, si eso sucede, --norestore es la única forma de iniciar LO.
--nosplash
Deshabilita la pantalla de inicio al iniciar el programa.
-o archivo...
Abre los archivos dados para edición, incluso plantillas.

Sin -o, un archivo de plantilla crearía un nuevo documento derivado de esa plantilla.

-p archivo...
Imprime los archivos dados en la impresora predeterminada y termina. La pantalla de inicio no aparece.

Si el nombre del archivo contiene espacios, debe ir entre comillas.

--print-to-file [--printer-name nombre_impresora] [--outdir directorio_salida] archivo...
Imprime archivos por lotes a un archivo. Si no se especifica --printer-name, se utiliza la impresora predeterminada. Si no se especifica --outdir, el directorio de trabajo actual se utiliza como directorio de salida para los archivos convertidos.

Ejemplos:

--print-to-file *.doc

Imprime todos los archivos .doc en el directorio de trabajo actual utilizando la impresora predeterminada.

--print-to-file --printer-name impresora_baja_resolucion --outdir /home/usuario *.doc

Imprime todos los archivos .doc en el directorio /home/usuario utilizando la impresora_baja_resolucion.

--pt nombre_impresora archivo...
Imprime los archivos dados en la impresora nombre_impresora y termina. La pantalla de inicio no aparece.

Si un nombre de archivo contiene espacios, debe ir entre comillas.

--quickstart --quickstart=no
Inicia LO con su iniciador rápido. --quickstart deshabilita el iniciador rápido.

No funciona con --invisible o --headless.

--show archivo_Impress...
Abre los archivos Impress dados, inicia la presentación y sale después de que hayan finalizado.
--unaccept=cadena-aceptación
Cierra un aceptador que se creó con la opción --accept.

Utilice --unaccept=all para cerrar todos los aceptadores abiertos.

OPCIONES

--terminate_after_init
Inicia LO y termina después de que registra algunos servicios UNO. No muestra la pantalla de presentación durante el inicio.
--view archivo...
Abre los archivos dados en modo de solo lectura, creando una copia temporal de ellos en $TMPDIR.
--web
Inicia con un nuevo documento HTML.
--writer
Inicia con un nuevo documento de Writer.
