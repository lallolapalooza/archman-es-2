lockf(3) Manual de funciones de biblioteca lockf(3)

NOMBRE

lockf - aplicar, probar o eliminar un bloqueo POSIX en un archivo abierto

BIBLIOTECA

Biblioteca C estándar (libc, -lc)

SINOPSIS

#include <unistd.h>
int lockf(int fd, int op, off_t size);
Requisitos de macro de prueba de características para glibc (consulte feature_test_macros(7)):

lockf():

    _XOPEN_SOURCE >= 500
        || /* glibc >= 2.19: */ _DEFAULT_SOURCE
        || /* glibc <= 2.19: */ _BSD_SOURCE || _SVID_SOURCE

DESCRIPCIÓN

Aplica, prueba o elimina un bloqueo POSIX en una sección de un archivo abierto. El archivo se especifica mediante fd, un descriptor de archivo abierto para escritura, la acción mediante op, y la sección consta de las posiciones de bytes pos..pos+size-1 si size es positivo, y pos-size..pos-1 si size es negativo, donde pos es la posición actual del archivo y, si size es cero, la sección se extiende desde la posición actual del archivo hasta el infinito, abarcando las posiciones actuales y futuras del final del archivo. En todos los casos, la sección puede extenderse más allá del final del archivo actual.

En Linux, lockf() es solo una interfaz sobre los bloqueos de fcntl(2). Muchos otros sistemas implementan lockf() de esta manera, pero tenga en cuenta que POSIX.1 deja sin especificar la relación entre los bloqueos de lockf() y fcntl(2). Una aplicación portable probablemente debería evitar mezclar llamadas a estas interfaces.

Las operaciones válidas se enumeran a continuación:

F_LOCK
Establece un bloqueo exclusivo en la sección especificada del archivo. Si (parte de) esta sección ya está bloqueada, la llamada se bloquea hasta que se libera el bloqueo anterior. Si esta sección se solapa con una sección bloqueada anteriormente, ambas se fusionan. Los bloqueos de archivo se liberan tan pronto como el proceso que mantiene los bloqueos cierra algún descriptor de archivo para el archivo. Un proceso hijo no hereda estos bloqueos.
F_TLOCK
Igual que F_LOCK pero la llamada nunca se bloquea y devuelve un error si el archivo ya está bloqueado.
F_ULOCK
Desbloquea la sección indicada del archivo. Esto puede hacer que una sección bloqueada se divida en dos secciones bloqueadas.
F_TEST
Prueba el bloqueo: devuelve 0 si la sección especificada no está bloqueada o está bloqueada por este proceso; devuelve -1, establece errno en EAGAIN (EACCES en algunos otros sistemas), si otro proceso mantiene un bloqueo.

VALOR DE RETORNO

Al éxito, se devuelve cero. En caso de error, se devuelve -1 y errno se establece para indicar el error.

ERRORES

EACCES o EAGAIN
El archivo está bloqueado y se especificó F_TLOCK o F_TEST, o la operación está prohibida porque el archivo ha sido mapeado en memoria por otro proceso.
EBADF
fd no es un descriptor de archivo abierto; o op es F_LOCK o F_TLOCK y fd no es un descriptor de archivo escribible.
EDEADLK
op era F_LOCK y esta operación de bloqueo causaría un interbloqueo.
EINTR
Mientras se esperaba para adquirir un bloqueo, la llamada fue interrumpida por la entrega de una señal capturada por un manejador; consulte signal(7).
EINVAL
Se especificó una operación inválida en op.
ENOLCK
Demasiados bloqueos de segmento abiertos, la tabla de bloqueos está llena.
