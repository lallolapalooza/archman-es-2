LOG10(3P) Manual del programador POSIX LOG10(3P)

PRÓLOGO

Esta página del manual es parte del Manual del Programador POSIX. La implementación de Linux de esta interfaz puede diferir (consulte la página del manual de Linux correspondiente para conocer los detalles del comportamiento de Linux), o la interfaz puede no estar implementada en Linux.

NOMBRE

log10, log10f, log10l — función logaritmo base 10

SINOPSIS

#include <math.h>
double log10(double x);
float log10f(float x);
long double log10l(long double x);

DESCRIPCIÓN

La funcionalidad descrita en esta página de referencia está alineada con el estándar ISO C. Cualquier conflicto entre los requisitos descritos aquí y el estándar ISO C es no intencional. Este volumen de POSIX.1‐2017 se remite al estándar ISO C.

Estas funciones calcularán el logaritmo base 10 de su argumento x, log10(x).

Una aplicación que desee verificar situaciones de error debe establecer errno a cero y llamar a feclearexcept(FE_ALL_EXCEPT) antes de llamar a estas funciones. Al regresar, si errno es distinto de cero o fetestexcept(FE_INVALID | FE_DIVBYZERO | FE_OVERFLOW | FE_UNDERFLOW) es distinto de cero, ha ocurrido un error.

VALOR DE RETORNO

Al completarse con éxito, estas funciones devolverán el logaritmo base 10 de x.

Si x es ±0, ocurrirá un error de polo y log10(), log10f() y log10l() devolverán -HUGE_VAL, -HUGE_VALF y -HUGE_VALL, respectivamente.

Para valores finitos de x que sean menores que 0, o si x es -Inf, ocurrirá un error de dominio, y se devolverá un NaN (si se admite) o un valor definido por la implementación.

Si x es NaN, se devolverá un NaN.

Si x es 1, se devolverá +0.

Si x es +Inf, se devolverá +Inf.

ERRORES

Estas funciones fallarán si:

Error de Dominio
El valor finito de x es negativo, o x es -Inf.

Si la expresión entera (math_errhandling & MATH_ERRNO) es distinta de cero, entonces errno se establecerá en [EDOM]. Si la expresión entera (math_errhandling & MATH_ERREXCEPT) es distinta de cero, entonces se activará la excepción flotante inválida.

Error de Polo
El valor de x es cero.

Si la expresión entera (math_errhandling & MATH_ERRNO) es distinta de cero, entonces errno se establecerá en [ERANGE]. Si la expresión entera (math_errhandling & MATH_ERREXCEPT) es distinta de cero, entonces se activará la excepción de división por cero flotante.
