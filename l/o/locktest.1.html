LOCKTEST(1) Suite de pruebas LOCKTEST(1)

NOMBRE

locktest - Encuentra diferencias en el bloqueo entre dos servidores SMB

SINOPSIS

locktest {//servidor1/recurso1} {//servidor2/recurso2} [-U usuario%contraseña] [-U usuario%contraseña] [-s semilla] [-o numoper] [-a] [-O] [-E] [-Z] [-R rango] [-B base] [-M min]

DESCRIPCIÓN

locktest es una utilidad para detectar diferencias en el comportamiento de bloqueo entre servidores SMB. Ejecutará un conjunto aleatorio de operaciones de bloqueo contra //servidor1/recurso1 y luego el mismo conjunto aleatorio contra //servidor2/recurso2 y mostrará las diferencias en las respuestas que obtiene.

Esta utilidad es utilizada por el equipo de Samba para encontrar diferencias de comportamiento entre Samba y los servidores de Windows.

OPCIONES

-U usuario%contraseña

Especifica el usuario y la contraseña a usar al iniciar sesión en los recursos compartidos. Este parámetro se puede especificar dos veces (una para el primer servidor, otra para el segundo).

-s semilla

Inicia el generador de números aleatorios con el valor especificado.

-o numoper

Establece el número de operaciones a realizar.

-a

Imprime las operaciones que se están realizando.

-A

Retrocede para encontrar el número mínimo de operaciones requeridas para que la respuesta a una llamada determinada difiera.

-O

Habilita oplocks.

-u

Oculta los fallos de desbloqueo.

-E

Habilita la comprobación exacta del código de error.

-Z

Habilita el bloqueo cero/cero.

-R rango

Establece el rango de bloqueo.

-B base

Establece la base de bloqueo.

-M min

Establece la longitud mínima del bloqueo.

-k

Usa Kerberos.
