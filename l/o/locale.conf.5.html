NOMBRE

locale.conf - Archivo de configuración para ajustes de locale

SINOPSIS

/etc/locale.conf

DESCRIPCIÓN

El archivo /etc/locale.conf configura los ajustes de locale a nivel de sistema. Es leído al inicio por systemd(1).

El formato de locale.conf es una lista separada por saltos de línea de asignaciones de variables compatibles con shell, similar a las variables de entorno, ignorando comentarios y líneas vacías. Es posible obtener la configuración de scripts de shell, sin embargo, más allá de meras asignaciones de variables, no se admiten características de shell, lo que permite a las aplicaciones leer el archivo sin implementar un motor de ejecución compatible con shell. Consulte os-release(5) para una descripción detallada del formato.

Tenga en cuenta que las opciones de línea de comandos del kernel locale.LANG=, locale.LANGUAGE=, locale.LC_CTYPE=, locale.LC_NUMERIC=, locale.LC_TIME=, locale.LC_COLLATE=, locale.LC_MONETARY=, locale.LC_MESSAGES=, locale.LC_PAPER=, locale.LC_NAME=, locale.LC_ADDRESS=, locale.LC_TELEPHONE=, locale.LC_MEASUREMENT=, locale.LC_IDENTIFICATION= pueden utilizarse para anular los ajustes de locale al arrancar.

Los ajustes de locale configurados en /etc/locale.conf son a nivel de sistema y son heredados por todos los servicios o usuarios, a menos que sean anulados o desestablecidos por programas o usuarios individuales.

Dependiendo del sistema operativo, otros archivos de configuración podrían ser revisados para la configuración de locale, sin embargo, solo como plan de respaldo.

/etc/locale.conf puede actualizarse usando systemd-localed.service(8). localectl(1) puede utilizarse para modificar los ajustes en este archivo en tiempo de ejecución desde la línea de comandos. Utilice systemd-firstboot(1) para personalizarlos en imágenes de sistema montadas (pero no arrancadas).

OPCIONES

Los siguientes ajustes de locale pueden ser establecidos usando /etc/locale.conf: LANG=, LANGUAGE=, LC_CTYPE=, LC_NUMERIC=, LC_TIME=, LC_COLLATE=, LC_MONETARY=, LC_MESSAGES=, LC_PAPER=, LC_NAME=, LC_ADDRESS=, LC_TELEPHONE=, LC_MEASUREMENT=, LC_IDENTIFICATION=. Tenga en cuenta que LC_ALL no puede ser configurado en este archivo. Para más detalles sobre el significado y la semántica de estos ajustes, consulte locale(7).

EJEMPLO

Ejemplo 1. Locale alemán con mensajes en inglés

/etc/locale.conf:

# Ajustes personalizados
LANG=de_DE.UTF-8
LC_MESSAGES=en_US.UTF-8
