Paquete: lowdown

LOWDOWN_DOC_FREE(3) Manual de funciones de la biblioteca LOWDOWN_DOC_FREE(3)

NOMBRE

lowdown_doc_free — libera una instancia del analizador de Markdown

BIBLIOTECA

biblioteca “liblowdown”

SINOPSIS

#include <sys/queue.h>
#include <stdio.h>
#include <lowdown.h>

void
lowdown_doc_free(struct lowdown_doc *doc);

DESCRIPCIÓN

Libera un analizador creado con lowdown_doc_new(3). Si doc es NULL, la función no hace nada.

VER TAMBIÉN

lowdown(3), lowdown_doc_new(3)
