FBB::LocalSocketBase(3bobcat) Clase base para sockets de Dominio Unix FBB::LocalSocketBase(3bobcat)

NOMBRE

FBB::LocalSocketBase - Clase base para clases que construyen sockets de Dominio Unix

SINOPSIS

#include <bobcat/localsocketbase>
Opción de enlace: -lbobcat

DESCRIPCIÓN

Esta clase es una clase base para las clases FBB::LocalServerSocket y FBB::LocalClientSocket. Dado que está diseñada como una clase base, su constructor es protegido. Todos sus miembros restantes también son protegidos.

ESPACIO DE NOMBRES

FBB
Todos los constructores, miembros, operadores y manipuladores mencionados en esta página del manual están definidos en el espacio de nombres FBB.

HEREDA DE

-

CONSTRUCTOR PROTEGIDO

o
LocalSocketBase():
El constructor por defecto simplemente construye un objeto FBB::LocalSocketBase. Antes de que el objeto pueda ser utilizado, primero se debe llamar a su miembro open().
o
LocalSocketBase(string const &name):
Este constructor crea una LocalSocketBase utilizando el archivo especificado en name como interfaz de socket de dominio Unix. Si el socket no pudo ser construido, se lanza una excepción FBB::Exception.

Los constructores de copia y movimiento (y los operadores de asignación) no están disponibles.

FUNCIONES MIEMBRO PROTEGIDAS

o
open(string const &name):
Este miembro inicializa un objeto LocalSocketBase después de su construcción utilizando el constructor por defecto. El archivo especificado en name se utiliza como interfaz de socket de dominio Unix. Si el socket no pudo ser construido, se lanza una excepción FBB::Exception.
o
size_t size() const:
Accesor que devuelve el tamaño de sockaddr_un (dirección) del objeto.
o
int socket() const:
Este accesor devuelve el valor del socket de FBB::LocalSocketBase.
o
sockaddr const *sockaddrPtr() const:
Accesor que devuelve el puntero a sockaddr del objeto.
