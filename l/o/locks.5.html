NOMBRE

locks - archivo de bloqueo de libzypp

DESCRIPCIÓN

El archivo /etc/zypp/locks es leído por libzypp al inicio si zypp.conf lo permite. Las entradas se utilizan para el bloqueo inicial de paquetes. Bloquear un paquete significa no permitir su instalación o desinstalación.

Las entradas válidas son de la forma:

atributo: valor

Donde los atributos y sus valores se describen a continuación.

Los bloqueos están separados por líneas vacías.

ATRIBUTOS

Todos los atributos están en minúsculas.

repo

especifica la restricción del repositorio. Solo se acepta el alias.
Por defecto, todos los repositorios coinciden.

type

restricción del tipo de resoluble. Los valores pueden ser package, patch, pattern, product y srcpackage.
Por defecto, todos los tipos coinciden.

case_sensitive

si las cadenas se comparan con distinción de mayúsculas y minúsculas. Los valores son true, false, on, off.
El valor predeterminado no distingue mayúsculas y minúsculas.

install_status

estado del objeto. Los estados posibles son installed, not-installed y all. Si se especifican varios estados de instalación, se utiliza el último. Los valores son installed para todos los paquetes instalados, non-installed para los paquetes que se pueden instalar o reinstalar, y all para ambos.
El valor predeterminado es all.

match_type

tipo de coincidencia de cadenas en los valores. No afecta a type y repo, que deben especificarse exactamente. Los valores son exact, substring, regex para expresiones regulares, glob para coincidencias como en la línea de comandos, y word.
El valor predeterminado es substring.

query_string

Cadena a hacer coincidir en múltiples atributos. Debería restringirse con otro atributo de valor vacío (se recomienda, ya que sin restricción puede haber problemas de rendimiento).

version

Restringe el bloqueo solo a ciertas versiones. Contiene dos partes: un operador opcional y la versión.
El operador es ==, !=, <, >, ⇐, >=. Si no se especifica operador, se usa ==.
La versión tiene el formato [epoch:]version[-release].
Ejemplo: version: < 0:0.11.4-2

solvable_name

nombre del objeto (ej. zypper)

solvable_summary

resumen del objeto

solvable_arch

arquitectura del objeto (ej. x86_64, i586)

solvable_description

descripción del objeto

solvable_eula

texto de la licencia de los objetos que requieren la aceptación de la licencia por parte del usuario

solvable_license

licencia del paquete (solo para paquetes) (ej. GPL2)

solvable_keywords

palabras clave que especifican el paquete (solo para paquetes)

solvable_authors

autores del paquete (solo para paquetes)

solvable_group

grupo de paquetes (solo para paquetes) (ej. Development/Tools/Version Control)

update_reference_type

referencia para la actualización (ej. bugzilla, cve) (solo para parches)

EJEMPLOS

Paquete Exacto

Esta es la forma en que lo hace la interfaz de YaST. Bloquea k3b (ej. no quieres actualizarlo).
-----locks-----
type: package
solvable_name: k3b
match_type: exact
case_sensitive: on

Comodín de Paquete

Esto es lo que hace "zypper addlock cross-*-gcc-icecream-backend".
-----locks-----
type: package
solvable_name: cross-*-gcc-icecream-backend
match_type: glob
case_sensitive: on

Bloqueo Versionado

No instalar nuevo GCC. Este formato se utiliza al convertir desde el formato de bloqueo de openSUSE-10.3.
-----locks-----
solvable_name: gcc
match_type: glob
version: > 4.2

Cualquier cosa llamada KDE

Bloquea todo lo que contenga kde en el nombre.
-----locks-----
solvable_name: kde

Cualquier cosa que mencione KDE

Bloquea todo lo que contenga kde en el nombre, resumen o descripción.
-----locks-----
query_string: kde
solvable_name:
solvable_summary:
solvable_description:
