log2(3) Manual de Funciones de Librería log2(3)

NOMBRE

log2, log2f, log2l - función logarítmica de base 2

LIBRERÍA

Librería matemática (libm, -lm)

SINOPSIS

#include <math.h>
double log2(double x);
float log2f(float x);
long double log2l(long double x);
Requisitos de Macro de Prueba de Funcionalidad para glibc (ver feature_test_macros(7)):

log2(), log2f(), log2l():

    _ISOC99_SOURCE || _POSIX_C_SOURCE >= 200112L

DESCRIPCIÓN

Estas funciones devuelven el logaritmo en base 2 de x.

VALOR DE RETORNO

En caso de éxito, estas funciones devuelven el logaritmo en base 2 de x.

Para casos especiales, incluyendo cuando x es 0, 1, negativo, infinito o NaN, ver log(3).

ERRORES

Ver math_error(7) para obtener información sobre cómo determinar si ha ocurrido un error al llamar a estas funciones.

Para una discusión de los errores que pueden ocurrir con estas funciones, ver log(3).

ATRIBUTOS

Para una explicación de los términos utilizados en esta sección, ver attributes(7).

Interfaz Atributo Valor
log2 (), log2f (), log2l () Seguridad en hilos MT-Safe

ESTÁNDARES

C11, POSIX.1-2008.

HISTORIA

glibc 2.1. C99, POSIX.1-2001.

La variante que devuelve double también se ajusta a SVr4, 4.3BSD.

VER TAMBIÉN

cbrt(3), clog2(3), log(3), log10(3), sqrt(3)
