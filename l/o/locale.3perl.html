locale(3perl) Guía de referencia del programador de Perl locale(3perl)

NOMBRE

locale - Pragma de Perl para usar o evitar locales POSIX para operaciones integradas

SINOPSIS

my @x1 = sort @y;      # Orden de clasificación de punto de código nativo de la plataforma/Unicode
{
    use locale;
    my @x2 = sort @y;  # Orden de clasificación definido por el locale
}
my @x3 = sort @y;      # Orden de clasificación de punto de código nativo de la plataforma/Unicode
                       # de nuevo
# Los parámetros para el pragma son para solucionar deficiencias en el manejo
# de locales que desde entonces se han corregido, y por lo tanto, es probable
# que ya no sean útiles
use locale qw(:ctype :collate);    # Usar el locale solo para la clasificación de caracteres
                                   # (\w, \d, etc.), y para operaciones de comparación de
                                   # cadenas como '$a le $b' y ordenación.
use locale ':not_characters';      # Usar el locale para todo excepto para la clasificación
                                   # de caracteres y las operaciones de comparación de cadenas
use locale ':!numeric';            # Usar el locale para todo excepto para las operaciones
                                   # relacionadas con números
use locale ':not_numeric';         # Igual
no locale;             # Desactivar el manejo de locales para el resto del
                       # ámbito.

DESCRIPCIÓN

Este pragma indica al compilador que habilite (o deshabilite) el uso de locales POSIX para operaciones integradas (por ejemplo, "LC_CTYPE" para expresiones regulares, "LC_COLLATE" para comparación de cadenas y "LC_NUMERIC" para formato de números). Cada "use locale" o "no locale" afecta a las sentencias hasta el final del BLOCK que las contiene.

El pragma se documenta como parte de perllocale.
