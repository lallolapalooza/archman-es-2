LOG2PCAP(1) Comandos de usuario LOG2PCAP(1)

NOMBRE

log2pcap - Extraer rastros de red de los archivos de registro de Samba

SINOPSIS

log2pcap [-h] [-q] [archivo_log] [archivo_pcap]

DESCRIPCIÓN

Esta herramienta forma parte del conjunto de utilidades samba(7).

log2pcap lee un archivo de registro de samba y genera un archivo pcap (legible por la mayoría de los analizadores, como ethereal o tcpdump) basado en los volcado de paquetes en el archivo de registro.

El archivo de registro debe tener un nivel de registro de al menos 5 para obtener la cabecera/parámetros SMB correctos, 10 para obtener los primeros 512 bytes de datos del paquete y 50 para obtener el paquete completo.

OPCIONES

-h

Si se especifica este parámetro, el archivo de salida será un volcado hexadecimal, en un formato que puede ser leído por la utilidad text2pcap.

-q

Silencioso. No se mostrarán mensajes de advertencia sobre datos faltantes o incompletos.

archivo_log

Archivo de registro de Samba. log2pcap intentará leer el registro desde la entrada estándar si no se especifica el archivo de registro.

archivo_pcap

Nombre del archivo de salida donde se escribirán los datos pcap (o hexdump). Si no se especifica este argumento, los datos de salida se escribirán en la salida estándar.

-?|--help

Imprime un resumen de las opciones de la línea de comandos.

EJEMPLOS

Extraer todo el tráfico de red de todos los archivos de registro de samba:

$ log2pcap < /var/log/* > trace.pcap

Convertir a pcap usando text2pcap:

$ log2pcap -h samba.log | text2pcap -T 139,139 - trace.pcap

VERSIÓN

Esta página del manual forma parte de la versión 4.23.3 del conjunto de utilidades de Samba.

ERRORES

Solo se extraen datos SMB de los registros de samba, no LDAP, NetBIOS lookup u otros datos.

Las cabeceras TCP e IP generadas no contienen una suma de verificación válida.

VER TAMBIÉN

text2pcap(1), ethereal(1)
