lookbib(1) Manual de comandos generales lookbib(1)

Nombre

lookbib - buscar en bases de datos bibliográficas

Sinopsis

lookbib [-i cadena] [-t n] archivo ...
lookbib --ayuda
lookbib -v
lookbib --version

Descripción

lookbib escribe una indicación en el flujo de error estándar (a menos que el flujo de entrada estándar no sea una terminal), lee desde la entrada estándar una línea que contiene un conjunto de palabras clave, busca en cada base de datos bibliográfica archivo referencias que contengan esas palabras clave, escribe las referencias encontradas en el flujo de salida estándar y repite este proceso hasta el final de la entrada. Para cada base de datos archivo a buscar, si existe un archivo de índice archivo.i creado por indxbib(1), entonces se buscará en él en su lugar; cada índice puede cubrir múltiples bases de datos.

Opciones

--ayuda muestra un mensaje de uso, mientras que -v y --version muestran información de la versión; todas salen después.

-i cadena
Al buscar en archivos para los que no existe índice, ignora el contenido de los campos cuyos nombres están en cadena.
-t n
Requiere que solo se proporcionen los primeros n caracteres de las claves. El valor predeterminado es 6.

Archivos

archivo.i
Archivos de índice.

Ver también

“Some Applications of Inverted Indexes on the Unix System”, por M. E. Lesk, 1978, AT&T Bell Laboratories Computing Science Technical Report No. 69.
