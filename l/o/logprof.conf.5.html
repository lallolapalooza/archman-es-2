LOGPROF.CONF(5) AppArmor LOGPROF.CONF(5)

NOMBRE

logprof.conf - archivo de configuración para opciones avanzadas que modifican el comportamiento del programa AppArmor aa-logprof(1).

DESCRIPCIÓN

El programa aa-logprof(1) puede ser configurado para tener ciertos comportamientos predeterminados mediante el contenido de logprof.conf.

La sección [qualifiers] lista programas específicos que deberían tener un subconjunto de la lista completa ix/px/ux al preguntar qué modo usar para ejecutarlo.

Dado que crear un perfil separado para /bin/bash es peligroso, podemos especificar que para /bin/bash, solo (I)nherit (heredar), (U)nconstrained (no restringido) y (D)eny (denegar) sean las opciones permitidas y solo estas aparecerán en el prompt cuando preguntemos sobre añadirlo a un perfil.

De manera similar, si alguien actualmente ejecuta /bin/mount en modo ix o px, las cosas no funcionarán, por lo que podemos proporcionar solo las opciones (U)nconstrained y (D)eny.

Y ciertas aplicaciones como grep, awk, sed, cp y mkdir siempre deberían heredar el perfil padre en lugar de tener su propio perfil o ejecutarse sin restricciones, por lo que para ellas podemos especificar que solo (I)nherit y (D)eny sean las opciones permitidas.

Cualquier programa que no esté listado en la sección qualifiers recibe el conjunto completo de opciones (I)nherit / (P)rofile / (U)nconstrained / (D)eny.

Si el usuario está haciendo algo complicado y quiere un comportamiento diferente, puede ajustar o eliminar la línea correspondiente en el archivo de configuración.

La sección [defaulthat] lista programas conscientes de changehat y qué hat usará aa-logprof(1) para colapsar las entradas de ese programa si el usuario especifica que el acceso debe permitirse, pero no debe tener su propio hat.

La sección [globs] permite la modificación del motor de reglas de logprof con respecto a las sugerencias de globbing con las que se le pedirá al usuario.

El formato de cada línea es: "<glob perl> = <glob apparmor>"

Cuando aa-logprof(1) pregunta sobre una ruta específica, si el glob perl coincide con la ruta, reemplaza la parte de la ruta que coincidió con el glob apparmor correspondiente y lo agrega a la lista de sugerencias de globbing.

Las líneas que comienzan con # son comentarios y se ignoran.

EJEMPLO

[qualifiers]
  # las cosas probablemente estarán dolorosamente rotas si bash tiene su propio perfil
  /bin/bash  = iu
  # mount no funciona si está confinado
  /bin/mount = u
  # estas utilidades auxiliares deberían heredar el perfil padre y
  # no deberían tener sus propios perfiles
  /bin/awk   = i
  /bin/grep  = i
  /bin/sed   = i
[defaulthat]
  /usr/sbin/sshd           = EXEC
  /usr/sbin/httpd2         = DEFAULT_URI
  /usr/sbin/httpd2-prefork = DEFAULT_URI
[globs]
  # /foo/bar/lib/libbaz.so -> /foo/bar/lib/lib*
  /lib/lib[^\/]+so[^\/]*$  = /lib/lib*so*
  # eliminar números de versión del kernel de los accesos a módulos del kernel
  ^/lib/modules/[^\/]+\/   = /lib/modules/*/
  # eliminar números de pid de los accesos a /proc
  ^/proc/\d+/              = /proc/*/
