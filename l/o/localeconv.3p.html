PROLOG

Esta página del manual forma parte del Manual del programador POSIX. La implementación de esta interfaz en Linux puede diferir (consulte la página del manual de Linux correspondiente para conocer los detalles del comportamiento de Linux), o la interfaz puede no estar implementada en Linux.

NOMBRE

localeconv — devuelve información específica de la configuración regional

SINOPSIS

#include <locale.h>
struct lconv *localeconv(void);

DESCRIPCIÓN

La funcionalidad descrita en esta página de referencia está alineada con el estándar ISO C. Cualquier conflicto entre los requisitos descritos aquí y el estándar ISO C es involuntario. Este volumen de POSIX.1‐2017 se remite al estándar ISO C.

La función localeconv() establecerá los componentes de un objeto de tipo struct lconv con los valores apropiados para el formato de cantidades numéricas (monetarias y de otro tipo) según las reglas de la configuración regional actual.

Los miembros de la estructura con tipo char * son punteros a cadenas, cualquiera de las cuales (excepto decimal_point) puede apuntar a "", para indicar que el valor no está disponible en la configuración regional actual o tiene longitud cero. Los miembros con tipo char son números no negativos, cualquiera de los cuales puede ser {CHAR_MAX} para indicar que el valor no está disponible en la configuración regional actual.

Los miembros incluyen los siguientes:

char *decimal_point

El carácter del separador decimal utilizado para formatear cantidades no monetarias.
char *thousands_sep

El carácter utilizado para separar grupos de dígitos antes del carácter decimal_point en cantidades no monetarias formateadas.
char *grouping

Una cadena cuyos elementos, tomados como enteros de un byte, indican el tamaño de cada grupo de dígitos en cantidades no monetarias formateadas.
char *int_curr_symbol

El símbolo de moneda internacional aplicable a la configuración regional actual. Los tres primeros caracteres contienen el símbolo de moneda internacional alfabético de acuerdo con los especificados en el estándar ISO 4217:2001. El cuarto carácter (inmediatamente antes del byte nulo) es el carácter utilizado para separar el símbolo de moneda internacional de la cantidad monetaria.
char *currency_symbol

El símbolo de moneda local aplicable a la configuración regional actual.
char *mon_decimal_point

El carácter del separador decimal utilizado para formatear cantidades monetarias.
char *mon_thousands_sep

El separador de grupos de dígitos antes del decimal_point en cantidades monetarias formateadas.
char *mon_grouping

Una cadena cuyos elementos, tomados como enteros de un byte, indican el tamaño de cada grupo de dígitos en cantidades monetarias formateadas.
char *positive_sign

La cadena utilizada para indicar una cantidad monetaria formateada de valor no negativo.
char *negative_sign

La cadena utilizada para indicar una cantidad monetaria formateada de valor negativo.
char int_frac_digits

El número de dígitos fraccionarios (los que están después del separador decimal) que se mostrarán en una cantidad monetaria formateada internacionalmente.
char frac_digits

El número de dígitos fraccionarios (los que están después del separador decimal) que se mostrarán en una cantidad monetaria formateada.
char p_cs_precedes

Establecido en 1 si el currency_symbol precede al valor para una cantidad monetaria formateada no negativa. Establecido en 0 si el símbolo sucede al valor.
char p_sep_by_space

Establecido en un valor que indica la separación del currency_symbol, la cadena de signo y el valor para una cantidad monetaria formateada no negativa.
char n_cs_precedes

Establecido en 1 si el currency_symbol precede al valor para una cantidad monetaria formateada negativa. Establecido en 0 si el símbolo sucede al valor.
char n_sep_by_space

Establecido en un valor que indica la separación del currency_symbol, la cadena de signo y el valor para una cantidad monetaria formateada negativa.
char p_sign_posn

Establecido en un valor que indica la posición del positive_sign para una cantidad monetaria formateada no negativa.
char n_sign_posn

Establecido en un valor que indica la posición del negative_sign para una cantidad monetaria formateada negativa.
char int_p_cs_precedes

Establecido en 1 o 0 si el int_curr_symbol precede o sucede respectivamente al valor para una cantidad monetaria formateada internacionalmente no negativa.
char int_n_cs_precedes

Establecido en 1 o 0 si el int_curr_symbol precede o sucede respectivamente al valor para una cantidad monetaria formateada internacionalmente negativa.
char int_p_sep_by_space

Establecido en un valor que indica la separación del int_curr_symbol, la cadena de signo y el valor para una cantidad monetaria formateada internacionalmente no negativa.
char int_n_sep_by_space

Establecido en un valor que indica la separación del int_curr_symbol, la cadena de signo y el valor para una cantidad monetaria formateada internacionalmente negativa.
char int_p_sign_posn

Establecido en un valor que indica la posición del positive_sign para una cantidad monetaria formateada internacionalmente no negativa.
char int_n_sign_posn

Establecido en un valor que indica la posición del negative_sign para una cantidad monetaria formateada internacionalmente negativa.

Los elementos de grouping y mon_grouping se interpretan según lo siguiente:

{CHAR_MAX}
No se realizará más agrupamiento.
0
El elemento anterior se utilizará repetidamente para el resto de los dígitos.
otro
El valor entero es el número de dígitos que componen el grupo actual. Se examina el siguiente elemento para determinar el tamaño del siguiente grupo de dígitos antes del grupo actual.

Los valores de p_sep_by_space, n_sep_by_space, int_p_sep_by_space e int_n_sep_by_space se interpretan según lo siguiente:

0
No hay espacio que separe el símbolo de moneda y el valor.
1
Si el símbolo de moneda y la cadena de signo son adyacentes, un espacio los separa del valor; de lo contrario, un espacio separa el símbolo de moneda del valor.
2
Si el símbolo de moneda y la cadena de signo son adyacentes, un espacio los separa; de lo contrario, un espacio separa la cadena de signo del valor.

Para int_p_sep_by_space e int_n_sep_by_space, el cuarto carácter de int_curr_symbol se utiliza en lugar de un espacio.

La implementación se comportará como si ninguna función en este volumen de POSIX.1‐2017 llamara a localeconv().

La función localeconv() no necesita ser segura para hilos.

VALOR DE RETORNO

La función localeconv() devolverá un puntero al objeto rellenado. La aplicación no modificará la estructura a la que apunta el valor de retorno, ni ninguna área de almacenamiento a la que apunten los punteros dentro de la estructura. El puntero devuelto, y los punteros dentro de la estructura, pueden invalidarse o la estructura o las áreas de almacenamiento pueden ser sobrescritas por una llamada posterior a localeconv(). Además, el puntero devuelto, y los punteros dentro de la estructura, pueden invalidarse o la estructura o las áreas de almacenamiento pueden ser sobrescritas por llamadas posteriores a setlocale() con las categorías LC_ALL, LC_MONETARY o LC_NUMERIC, o por llamadas a uselocale() que cambian las categorías LC_MONETARY o LC_NUMERIC. El puntero devuelto, los punteros dentro de la estructura, la estructura y las áreas de almacenamiento también pueden invalidarse si el hilo que llama es terminado.

ERRORES

No se definen errores.

NAME

localeconv

get locale conventions

SYNOPSIS

#include <langinfo.h>

#include <locale.h>

struct lconv *localeconv(void);

DESCRIPTION

The localeconv() function constructs a lconv structure in which each member is set to the appropriate value corresponding to the current locale of the program. The members of the lconv structure are:

decimal_point
The string used as the decimal point in monetary and non-monetary values.
thousands_sep
The string used to separate groups of digits to the left of the decimal point in non-monetary values.
grouping
A string where each character represents the number of digits in a group of non-monetary values. For example, "\3\3" means that groups of three digits are separated by thousands_sep.
int_curr_symbol
The international currency symbol, consisting of no more than four characters: a two-letter ISO 4217 country code, followed by a currency symbol, or by a blank. For example, "USD ". For monetary values.
currency_symbol
The local currency symbol. For example, "$". For monetary values.
mon_decimal_point
The decimal point used for monetary values.
mon_thousands_sep
The separator for monetary values.
mon_grouping
The grouping of digits for monetary values.
positive_sign
The sign for non-negative monetary values.
negative_sign
The sign for negative monetary values.
int_frac_digits
The number of fractional digits used for the int_curr_symbol format.
frac_digits
The number of fractional digits used for the currency_symbol format.
p_cs_precedes
A value indicating whether the currency_symbol precedes the non-negative value it applies to.
p_sep_by_space
A value indicating whether the currency_symbol is separated by a space from the non-negative value it applies to.
n_cs_precedes
A value indicating whether the currency_symbol precedes the negative negative_sign for negative monetary values.
n_sep_by_space
A value indicating whether the currency_symbol is separated by a space from the negative sign and the negative value it applies to.
p_sign_posn
A value indicating the position of the positive_sign for non-negative monetary values.
n_sign_posn
A value indicating the position of the negative_sign for negative monetary values.

The values of the grouping and mon_grouping members are determined by interpreting the string as an array of group sizes. The first character in the string gives the number of digits in the rightmost group adjacent to the decimal point. The second character gives the size of the next group to the left, and so on. If the last element read is non-positive, it is repeated indefinitely. If the string is empty, no grouping is performed.

The values of the p_cs_precedes, p_sep_by_space, n_cs_precedes, n_sep_by_space, p_sign_posn, and n_sign_posn members are interpreted as follows:

0
Symbol is not preceded by the sign.
1
Symbol is preceded by the sign.
0
No space separates the symbol from the value.
1
A space separates the symbol from the value.
2
A space separates the symbol from the value if the symbol is to the right of the value.
0
Parentheses surround the quantity and the numeric value.
1
The sign string precedes the quantity and the numeric value.
2
The sign string precedes the quantity.
3
The sign string is appended to the quantity.
4
The sign string follows the quantity.

The contents of the structure are pointers to static strings. The caller must not modify the contents of the structure. The pointers remain valid until the next call to setlocale() that modifies the LC_MONETARY locale category, or until the program terminates.

RETURN VALUE

The localeconv() function returns a pointer to a statically allocated lconv structure containing the locale conventions.

ERRORS

None.

EXAMPLES

None.

APPLICATION USAGE

The structure pointed to by the return value of localeconv() may be overwritten by a subsequent call to setlocale() that affects the LC_MONETARY locale category. Applications that need to preserve the values across such calls should copy the contents of the structure immediately.
