NOMBRE

lo_server_config - Una estructura de configuración para inicializar lo_server usando lo_server_new_from_config().

SINOPSIS

#include <lo_lowlevel.h>

Descripción detallada

Una estructura de configuración para inicializar lo_server usando lo_server_new_from_config().

El código del usuario es responsable de asignar y liberar la memoria apuntada por esta estructura, incluidas las cadenas para grupo, puerto, interfaz, IP, etc. La estructura y los campos relevantes serán copiados por liblo cuando sea necesario, por lo tanto, se puede liberar después de su uso. El campo tamaño debe establecerse en sizeof(lo_server_config). Los campos que se establezcan en 0 se ignorarán.
