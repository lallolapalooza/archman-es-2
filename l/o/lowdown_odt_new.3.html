lowdown_odt_new(3)

Paquete: lowdown

Licencias: ISC

LOWDOWN_ODT_NEW(3) Manual de funciones de la biblioteca LOWDOWN_ODT_NEW(3)

NOMBRE

lowdown_odt_new — asigna un renderizador Markdown OpenDocument

BIBLIOTECA

biblioteca “liblowdown”

SINOPSIS

#include <sys/queue.h>
#include <stdio.h>
#include <lowdown.h>

void *
lowdown_odt_new(const struct lowdown_opts *opts);

DESCRIPCIÓN

Asigna un renderizador OpenDocument usando opts->flags, o cero si opts es NULL. Este campo se documenta en lowdown(3). El puntero devuelto puede ser utilizado con múltiples invocaciones de lowdown_odt_rndr(3) y debe ser liberado con lowdown_odt_free(3).

Los bits reconocidos en opts->oflags son LOWDOWN_ODT_SKIP_HTML y LOWDOWN_STANDALONE.

El campo opts->odt.sty, si no es NULL, anula los elementos <office:font-face-decls>, <office:scripts>, y <office:styles> por defecto del documento.

VALORES DE RETORNO

Devuelve un puntero al renderizador o NULL en caso de fallo de memoria. El puntero devuelto debe ser liberado con lowdown_odt_free(3).

EJEMPLOS

Lo siguiente analiza b de longitud bsz y genera en formato OpenDocument “plano”.

struct lowdown_buf *out;
struct lowdown_doc *doc;
struct lowdown_node *n;
void *rndr;

if ((doc = lowdown_doc_new(NULL)) == NULL)
	err(1, NULL);
if ((n = lowdown_doc_parse(doc, NULL, b, bsz, NULL)) == NULL)
	err(1, NULL);
if ((out = lowdown_buf_new(256)) == NULL)
	err(1, NULL);
if ((rndr = lowdown_odt_new(NULL)) == NULL)
	err(1, NULL);
if (!lowdown_odt_rndr(out, rndr, n))
	err(1, NULL);

fwrite(out->data, 1, out->size, stdout);

lowdown_odt_free(rndr);
lowdown_buf_free(out);
lowdown_node_free(n);
lowdown_doc_free(doc);

VéASE TAMBIÉN

lowdown(3), lowdown_odt_free(3), lowdown_odt_rndr(3)

ESTÁNDARES

El estándar OpenDocument referenciado es 1.3.
