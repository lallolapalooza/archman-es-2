LOGCONV.PL(1) Manual de Comandos Generales LOGCONV.PL(1)

NOMBRE

logconv.pl - analiza archivos de registro de acceso del Servidor de Directorios

SINOPSIS

logconv.pl [-h] [-d <DN raíz>] [-s <límite de tamaño>] [-v] [-V] [-S <hora de inicio>] [-E <hora de fin>] [-T <tiempo mínimo de ejecución>] [-efcibaltnxgjuU] [ registro de acceso ... ... ]

DESCRIPCIÓN

Analiza archivos de registro de acceso del Servidor de Directorios para obtener información específica definida en la línea de comandos.

OPCIONES

A continuación se incluye un resumen de las opciones:

-h, --help
ayuda/uso
-d, --rootDN <DN de Administradores del Directorio>
POR DEFECTO -> cn=directory manager
-D, --data <Ubicación para archivos de datos temporales>
POR DEFECTO -> /tmp
CONSEJO -> Si hay suficiente RAM, se puede usar un disco RAM en su lugar:


mkdir /dev/shm/logconv, y usar este directorio para el valor de "-D".

-s, --sizeLimit <Número de resultados a devolver por categoría>
POR DEFECTO -> 20
-X, --excludeIP <Dirección IP a excluir de las estadísticas de conexión>
Por ejemplo, balanceadores de carga
-v, --version mostrar versión de la herramienta
Imprime la versión de la herramienta
-S, --startTime <hora desde la que empezar a analizar el archivo de registro>
Hora desde la que empezar a analizar el archivo de registro. Ej. [28/Mar/2002:13:14:22 -0800]
-E, --endTime <hora hasta la que dejar de analizar el archivo de registro>
Hora hasta la que dejar de analizar el archivo de registro. Ej. [28/Mar/2002:13:24:62 -0800]
-T, --minEtime <tiempo mínimo de ejecución para reportar búsquedas sin índice>
El tiempo mínimo de ejecución requerido para registrar y reportar una búsqueda sin índice. Por defecto es cero.
-M, --reportFileMins <archivo de salida CSV>
Esta opción crea un informe CSV para hojas de cálculo.
-m, --reportFileSecs <archivo de salida CSV>
Esta opción crea un informe CSV para hojas de cálculo.
-B, --bind <TODOS | ANÓNIMO | DN de Bind >
Esto genera un informe basado en todos los DN de bind, binds anónimos o un DN específico.
-V, --verbose <activar salida detallada - incluye todas las estadísticas listadas a continuación excepto U>
Salida detallada
-[efcibaltnxgjuU]

e Estadísticas de códigos de error
f Estadísticas de inicios de sesión fallidos
c Estadísticas de códigos de conexión
i Estadísticas de clientes
b Estadísticas de Bind
a Estadísticas de base de búsqueda
l Estadísticas de filtro de búsqueda
t Estadísticas de tiempo de ejecución
n Estadísticas de número de entradas
x Operaciones extendidas
r Estadísticas de atributos más solicitados
g Estadísticas de operaciones abandonadas
j Recomendaciones
u Estadísticas de búsquedas sin índice (muy detallado)
y Estadísticas de latencia de conexión
p Estadísticas de ID de conexión abierta
U Resumen de búsquedas sin índice

USO

Ejemplos:

logconv.pl -s 10 -V access
logconv.pl -d "cn=directory manager" /var/log/dirsrv/slapd-host/access*
logconv.pl -s 50 -ibgju access*
logconv.pl -S "[28/Mar/2002:13:14:22 -0800]" -E "[28/Mar/2002:13:50:05 -0800]" -e access
