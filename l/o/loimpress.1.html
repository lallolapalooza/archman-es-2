Nombre

libreoffice - Suite ofimática LibreOffice

SINOPSIS

DESCRIPCIÓN

LibreOffice (LO para abreviar) es una suite ofimática multiplataforma. Se derivó de OpenOffice.org 3.3 Beta el 28 de septiembre de 2010.

libreoffice es un script de shell que configura el entorno y pasa los argumentos de la línea de comandos al binario soffice.bin.

Alternativamente, los siguientes scripts auxiliares inician el módulo respectivo:

sbase, scalc, sdraw, simpress, smath, sofficerc, swriter

OPCIONES

--accept=cadena-aceptacion
Especifica una cadena de conexión UNO-URL para crear un aceptador UNO a través del cual otros programas pueden conectarse para acceder a la API. Tenga en cuenta que el acceso a la API permite la ejecución de comandos arbitrarios. La sintaxis de una cadena de conexión UNO-URL es: uno:tipo-conexion,params;nombre-protocolo,params;NombreObjeto
--base
Inicia el asistente para un nuevo documento Base.
--calc
Inicia con un nuevo documento Calc.
--convert-to extensión_archivo_salida[:nombre-filtro-salida] [--outdir directorio_salida] archivo...
Convierte archivos por lotes. Si no se especifica --outdir, el directorio de trabajo actual se utiliza como directorio de salida para los archivos convertidos. Implica --headless.

Ejemplos:

--convert-to pdf *.doc

Convierte todos los archivos .doc a PDF.

--convert-to pdf:writer_pdf_Export --outdir /home/usuario *.doc

Convierte todos los archivos .doc a PDF utilizando la configuración del diálogo de exportación de PDF de Writer y guardándolos en /home/usuario.

--display pantalla
Esta opción especifica el servidor X a utilizar; consulte X(7)
--draw
Inicia con un nuevo documento Draw.
--global
Inicia con un nuevo documento Global.
--headless
Inicia en modo "headless" (sin interfaz gráfica), lo que permite utilizar la aplicación sin una interfaz de usuario.

Este modo especial puede usarse cuando la aplicación es controlada por clientes externos a través de la API.

Implica --invisible e ignora estrictamente cualquier entorno GUI. --quickstart no funciona con este parámetro.

--help|-h|-?
Enumera los parámetros de la línea de comandos de LibreOffice.
--impress
Inicia con un nuevo documento Impress.
--invisible
Inicia en modo invisible.

Ni el logotipo de inicio ni la ventana inicial del programa serán visibles. LO puede ser controlado y los documentos y diálogos pueden ser abiertos a través de la API.

Cuando se inicia con este parámetro, solo se puede cerrar usando el administrador de tareas (Windows) o el comando kill (sistemas basados en UNIX).

--quickstart no funciona con este parámetro.

--infilter="<filtro>"
Fuerza un tipo de filtro de entrada si es posible. Por ejemplo --infilter="Calc Office Open XML" solamente
--math
Inicia con un nuevo documento Math.
--minimized
Mantiene la pantalla de presentación minimizada.
-n plantilla...
Crea un nuevo documento a partir de las plantillas dadas.
--nodefault
Inicia LO sin crear un nuevo documento. La próxima vez que inicie LO, se mostrará la pantalla de bienvenida.

Se usa junto con --nologo por los iniciadores rápidos. Tenga en cuenta que --quickstart ya no se admite desde OpenOffice.org 2.0.0.

--nolockcheck
Deshabilita la comprobación de instancias remotas que utilizan la instalación.
--nologo
Deshabilita la pantalla de presentación al iniciar el programa.
--norestore
Deshabilita la restauración y recuperación de archivos después de un fallo del sistema. Es posible que LO intente restaurar un archivo en el que sigue fallando; si esto ocurre, --norestore es la única forma de iniciar LO.
--nosplash
Deshabilita la pantalla de presentación al iniciar el programa.
-o archivo...
Abre los archivos dados para edición, incluso las plantillas.

Sin -o, un archivo de plantilla crearía un nuevo documento derivado de esa plantilla.

-p archivo...
Imprime los archivos dados en la impresora predeterminada y finaliza. La pantalla de presentación no aparece.

Si el nombre del archivo contiene espacios, debe ir entre comillas.

--print-to-file [--printer-name nombre-impresora] [--outdir directorio_salida] archivo...
Imprime archivos por lotes en un archivo. Si no se especifica --printer-name, se utiliza la impresora predeterminada. Si no se especifica --outdir, el directorio de trabajo actual se utiliza como directorio de salida para los archivos convertidos.

Ejemplos:

--print-to-file *.doc

Imprime todos los archivos .doc en el directorio de trabajo actual utilizando la impresora predeterminada.

--print-to-file --printer-name impresora_nasty_baja_resolucion --outdir /home/usuario *.doc

Imprime todos los archivos .doc en el directorio /home/usuario utilizando la impresora_nasty_baja_resolucion.

--pt nombre-impresora archivo...
Imprime los archivos dados en la impresora nombre-impresora y finaliza. La pantalla de presentación no aparece.

Si un nombre de archivo contiene espacios, debe ir entre comillas.

--quickstart --quickstart=no
Inicia LO con su iniciador rápido. --quickstart deshabilita el iniciador rápido.

No funciona con --invisible o --headless.

--show archivo-Impress...
Abre los archivos Impress dados, inicia la presentación y se cierra después de que hayan finalizado.
--unaccept=cadena-aceptacion
Cierra un aceptador que se creó con la opción --accept.

Use --unaccept=all para cerrar todos los aceptadores abiertos.

--terminate_after_init
Sale inmediatamente después de que se inicialice la aplicación (sin cargar ningún documento).

Esto es útil para registrar extensiones y para fines de pruebas.

--view archivo...
Abre los archivos dados para visualización.
--web
Inicia con un nuevo documento Web.
--writer
Inicia con un nuevo documento Writer.

loimpress(1) — LibreOffice Fresh

Name

loimpress ‐ Start LibreOffice Impress

SYNOPSIS

loimpress [options] [file] ...

DESCRIPTION

This command starts LibreOffice Impress.

OPTIONS

--calc
Starts with a new Calc document.
--draw
Starts with a new Draw document.
--embed
Embeds the LO instance into a parent window.
--example-screen
Show the splash screen during startup.
--extract
Extracts resources from a document.
--help
Shows the help message.
--iconify
Starts LO minimized (iconified).
--impress
Starts with a new Impress document.
--lang lang
Sets the language.
--logo
Show the splash screen during startup.
--nolockcheck
Disables the file locking check.
--norestore
Disables the automatic document restore.
--nologo
Doesn't show the splash screen during startup.
--print [file]
Prints the specified document.
--quit-after-load
Exits LibreOffice after loading the document.
--readme [file]
Shows the readme file.
--remove
Removes the specified document.
--replace
Replaces the existing document.
--scan
Scans the document for errors.
--shared
Starts LO in shared mode.
--show-splash-on-startup
Shows the splash screen during startup.
--splash-file file
Uses the specified file as the splash screen.
--template file
Uses the specified file as a template.
--terminate_after_init
Starts LO and terminates after it registers some UNO services. Doesn't show the splash during startup.
--view file...
Opens the given files read-only creating a temporary copy of them at $TMPDIR.
--web
Starts with a new HTML document.
--writer
Starts with a new Writer document.
