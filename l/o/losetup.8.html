LOSETUP(8) Administración del Sistema LOSETUP(8)

NOMBRE

losetup - configurar y controlar dispositivos de bucle

SINTAXIS

Obtener información:

losetup [dispositivo_bucle]

losetup -l [-a]

losetup -j archivo [-o desplazamiento]

Desconectar un dispositivo de bucle:

losetup -d dispositivo_bucle ...

Desconectar todos los dispositivos de bucle asociados:

losetup -D

Configurar un dispositivo de bucle:

losetup [-o desplazamiento] [--sizelimit tamaño] [--sector-size tamaño] [--loop-ref nombre] [-Pr] [--show] -f|dispositivo_bucle archivo

Redimensionar un dispositivo de bucle:

losetup -c dispositivo_bucle

DESCRIPCIÓN

losetup se utiliza para asociar dispositivos de bucle con archivos regulares o dispositivos de bloque, para desconectar dispositivos de bucle y para consultar el estado de un dispositivo de bucle. Si solo se da el argumento dispositivo_bucle, se muestra el estado del dispositivo de bucle correspondiente. Si no se proporciona ninguna opción, se muestran todos los dispositivos de bucle.

Tenga en cuenta que el antiguo formato de salida (es decir, losetup -a) con cadenas delimitadas por comas está obsoleto en favor del formato de salida --list.

Es posible crear más dispositivos de bucle independientes para el mismo archivo de soporte. Esta configuración puede ser peligrosa, puede causar pérdida de datos, corrupción y sobrescrituras. Use --nooverlap con --find durante la configuración para evitar este problema.

La configuración del dispositivo de bucle no es una operación atómica cuando se usa con --find, y losetup no protege esta operación con ningún bloqueo. El número de intentos está internamente restringido a un máximo de 16. Se recomienda usar, por ejemplo, flock(1) para evitar colisiones en casos de uso fuertemente paralelos.

OPCIONES

Los argumentos tamaño y desplazamiento pueden ir seguidos de los sufijos multiplicadores KiB (=1024), MiB (=1024*1024), y así sucesivamente para GiB, TiB, PiB, EiB, ZiB y YiB (el "iB" es opcional, por ejemplo, "K" tiene el mismo significado que "KiB") o los sufijos KB (=1000), MB (=1000*1000), y así sucesivamente para GB, TB, PB, EB, ZB y YB.

-a, --all

Muestra el estado de todos los dispositivos de bucle. Tenga en cuenta que no toda la información es accesible para usuarios no root. Consulte también --list. El antiguo formato de salida (tal como se imprime sin --list) está obsoleto.

-d, --detach dispositivo_bucle...

Desconecta el archivo o dispositivo asociado con el/los dispositivo/s de bucle especificado/s. Tenga en cuenta que desde el kernel v3.7 de Linux se utiliza la "destrucción de dispositivo diferida". La operación de desconexión ya no devuelve el error EBUSY si el dispositivo está activamente en uso por el sistema, sino que se marca con la bandera de autocorrección y se destruye más tarde. Incluso si el dispositivo no está en uso, el dispositivo de bucle puede destruirse más tarde. Si necesita esperar a la eliminación completa del dispositivo de bucle, llame a udevadm settle después de losetup.

-D, --detach-all

Desconecta todos los dispositivos de bucle asociados.

-f, --find [archivo]

Busca el primer dispositivo de bucle no utilizado. Si está presente un argumento archivo, utiliza el dispositivo encontrado como dispositivo de bucle. De lo contrario, solo imprime su nombre.

--show

Muestra el nombre del dispositivo de bucle asignado si están presentes la opción -f y un argumento archivo.

-L, --nooverlap

Comprueba si hay conflictos entre dispositivos de bucle para evitar situaciones en las que el mismo archivo de soporte sea compartido entre más de un dispositivo de bucle. Si el archivo ya está en uso por otro dispositivo, reutiliza el dispositivo en lugar de uno nuevo. La opción solo tiene sentido con --find.

-j, --associated archivo [-o desplazamiento]

Muestra el estado de todos los dispositivos de bucle asociados con el archivo dado.

-o, --offset desplazamiento

El inicio de los datos se mueve desplazamiento bytes dentro del archivo o dispositivo especificado. El desplazamiento puede ir seguido de los sufijos multiplicadores; véase más arriba.

--loop-ref cadena

Establece la cadena de referencia. La compatibilidad hacia atrás por defecto es usar el nombre del archivo de soporte como referencia en la llamada ioctl de configuración del bucle (también llamada lo_file_name). Esta opción puede sobrescribir este comportamiento predeterminado y establecer la referencia en la cadena. Udevd puede usar la referencia en /dev/loop/by-ref. El kernel de Linux no utiliza la referencia en absoluto, pero podría ser utilizada por algunas utilidades antiguas que no pueden leer el archivo de soporte de sysfs. La referencia solo es legible para el usuario root (ver --output +REF) y está restringida a 64 bytes.

--sizelimit tamaño

El final de los datos se establece en no más de tamaño bytes después del inicio de los datos. El tamaño puede ir seguido de los sufijos multiplicadores; véase más arriba.

-b, --sector-size tamaño

Establece el tamaño lógico del sector del dispositivo de bucle en bytes (desde Linux 4.14). La opción puede usarse al crear un nuevo dispositivo de bucle así como un comando independiente para modificar el tamaño del sector de un dispositivo de bucle ya existente.

-c, --set-capacity dispositivo_bucle

Fuerza al controlador de bucle a releer el tamaño del archivo asociado con el dispositivo de bucle especificado.

-P, --partscan

Fuerza al kernel a escanear la tabla de particiones en un dispositivo de bucle recién creado. Tenga en cuenta que el análisis de la tabla de particiones depende de los tamaños de sector. El tamaño de sector predeterminado es de 512 bytes; de lo contrario, deberá usar la opción --sector-size junto con --partscan.

-r, --read-only

Configura un dispositivo de bucle de solo lectura.

--direct-io[=on|off]

Habilita o deshabilita la E/S directa para el archivo de soporte. El valor predeterminado es off. Especificar --direct-io o --direct-io=on lo habilitará. Sin embargo, se puede proporcionar --direct-io=off para deshabilitarlo explícitamente.

-v, --verbose

Modo detallado.

-l, --list

Si se especifica un dispositivo de bucle o la opción -a, imprime las columnas predeterminadas para el dispositivo de bucle especificado o para todos los dispositivos de bucle; el valor predeterminado es imprimir información sobre todos los dispositivos. Consulte también --output, --noheadings, --raw y --json.

-O, --output columna[,columna]...

Especifica las columnas que se imprimirán para el formato de salida --list. Use --help para obtener una lista de todas las columnas compatibles.

--output-all

Imprime todas las columnas disponibles.

-n, --noheadings

No imprime encabezados para el formato de salida --list.

--raw

Utiliza el formato de salida --list en bruto.

-J, --json

Utiliza el formato JSON para la salida --list.

CIFRADO

Cryptoloop ya no es compatible, en favor de dm-crypt. Para más detalles, consulte cryptsetup(8).

ESTADO DE SALIDA

losetup devuelve 0 si tiene éxito, un valor distinto de cero si falla. Cuando losetup muestra el estado de un dispositivo de bucle, devuelve 1 si el dispositivo no está configurado y 2 si ocurrió un error que impide determinar el estado del dispositivo.

NOTAS

Desde la versión 2.37, losetup utiliza la llamada ioctl LOOP_CONFIGURE para configurar un nuevo dispositivo de bucle en una única llamada ioctl. Las versiones anteriores utilizan las llamadas ioctl LOOP_SET_FD y LOOP_SET_STATUS64 para hacer lo mismo.

VEASE TAMBIÉN

mount(8), dmsetup(8), cryptsetup(8)

EJEMPLO

Los siguientes comandos se pueden usar como ejemplo de uso del dispositivo loop.

# dd if=/dev/zero of=~/file.img bs=1024k count=10
# losetup --find --show ~/file.img
/dev/loop0
# mkfs -t ext2 /dev/loop0
# mount /dev/loop0 /mnt
...
# umount /dev/loop0
# losetup --detach /dev/loop0
