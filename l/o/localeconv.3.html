localeconv(3) Manual de Funciones de Biblioteca localeconv(3)

NOMBRE

localeconv - obtener información de formato numérico

BIBLIOTECA

Biblioteca C estándar (libc, -lc)

SINOPSIS

#include <locale.h>
struct lconv *localeconv(void);

DESCRIPCIÓN

La función localeconv() devuelve un puntero a una struct lconv para la configuración regional actual. Esta estructura se muestra en locale(7), y contiene todos los valores asociados con las categorías de configuración regional LC_NUMERIC y LC_MONETARY. Los programas también pueden usar las funciones printf(3) y strfmon(3), que se comportan de acuerdo con la configuración regional activa.

VALOR DE RETORNO

La función localeconv() devuelve un puntero a una struct lconv rellenada. Esta estructura puede estar (en glibc, *está*) asignada estáticamente y puede ser sobrescrita por llamadas posteriores. Según POSIX, el llamador no debe modificar el contenido de esta estructura. La función localeconv() siempre tiene éxito.

ATRIBUTOS

Para una explicación de los términos utilizados en esta sección, consulte attributes(7).

Interfaz Atributo Valor
localeconv () Seguridad en hilos MT-Unsafe race:localeconv locale

ESTANDARES

C11.

HISTORIA

C89.

ERRORES

La familia de funciones printf(3) puede o no respetar la configuración regional actual.

VER TAMBIÉN

locale(1), localedef(1), isalpha(3), nl_langinfo(3), setlocale(3), strcoll(3), strftime(3), locale(7)
