log1p(3) Manual de Funciones de Biblioteca log1p(3)

NOMBRE

log1p, log1pf, log1pl - logaritmo de 1 más argumento

BIBLIOTECA

Biblioteca matemática (libm, -lm)

SINOPSIS

#include <math.h>
double log1p(double x);
float log1pf(float x);
long double log1pl(long double x);
Requisitos de Macro de Prueba de Funciones para glibc (ver feature_test_macros(7)):
log1p():
    _ISOC99_SOURCE || _POSIX_C_SOURCE >= 200112L
        || _XOPEN_SOURCE >= 500
        || /* Desde glibc 2.19: */ _DEFAULT_SOURCE
        || /* glibc <= 2.19: */ _BSD_SOURCE || _SVID_SOURCE

log1pf(), log1pl():

    _ISOC99_SOURCE || _POSIX_C_SOURCE >= 200112L
        || /* Desde glibc 2.19: */ _DEFAULT_SOURCE
        || /* glibc <= 2.19: */ _BSD_SOURCE || _SVID_SOURCE

DESCRIPCIÓN

Estas funciones devuelven un valor equivalente a


log(1 + x)

El resultado se calcula de una manera que es precisa incluso si el valor de x está cerca de cero.

VALOR DE RETORNO

En caso de éxito, estas funciones devuelven el logaritmo natural de (1 + x).

Si x es un NaN, se devuelve un NaN.

Si x es infinito positivo, se devuelve infinito positivo.

Si x es -1, ocurre un error de polo y las funciones devuelven -HUGE_VAL, -HUGE_VALF o -HUGE_VALL, respectivamente.

Si x es menor que -1 (incluido el infinito negativo), ocurre un error de dominio y se devuelve un NaN (no es un número).

ERRORES

Ver math_error(7) para obtener información sobre cómo determinar si ha ocurrido un error al llamar a estas funciones.

Los siguientes errores pueden ocurrir:

Error de dominio: x es menor que -1.
errno se establece en EDOM (pero ver BUGS). Se genera una excepción de punto flotante no válida (FE_INVALID).
Error de polo: x es -1.
errno se establece en ERANGE (pero ver BUGS). Se genera una excepción de punto flotante de división por cero (FE_DIVBYZERO).

ATRIBUTOS

Para una explicación de los términos utilizados en esta sección, ver attributes(7).

Interfaz Atributo Valor
log1p (), log1pf (), log1pl () Seguridad de hilos MT-Safe

ESTÁNDARES

C11, POSIX.1-2008.

HISTORIAL

C99, POSIX.1-2001.

BUGS

Antes de glibc 2.22, la implementación de glibc no establecía errno en EDOM cuando ocurría un error de dominio.

Antes de glibc 2.22, la implementación de glibc no establecía errno en ERANGE cuando ocurría un error de rango.

VER TAMBIÉN

exp(3), expm1(3), log(3)
