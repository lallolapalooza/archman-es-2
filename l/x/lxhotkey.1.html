NOMBRE

LXHotkey - Un configurador ligero de atajos de teclado globales

SINOPSIS

lxhotkey [ comando ]

DESCRIPCIÓN

LXHotkey es una aplicación universal para el Entorno de Escritorio Ligero X11 (LXDE) que permite ver y cambiar los atajos de teclado globales para las acciones del Gestor de Ventanas, incluyendo las que inician aplicaciones.

OPCIONES

Interfaz de línea de comandos:

global [acción]
muestra las teclas enlazadas a la(s) acción(es)
global acción tecla
enlaza una tecla a la acción
app [ejecución]
muestra las teclas enlazadas a la línea de ejecución
app ejecución tecla
enlaza una tecla a alguna línea de ejecución
app ejecución --
desenlaza todas las teclas de la línea de ejecución
show tecla
muestra la acción enlazada a una tecla

Interfaz gráfica:

--gui= tipo
inicia con la GUI de tipo

GESTORES DE VENTANAS SOPORTADOS

Openbox
