NOMBRE

lxqt-policykit-agent - Agente Polkit para el entorno de escritorio LXQt

SINOPSIS

lxqt-policykit-agent

DESCRIPCIÓN

Este módulo gestiona PolicyKit para LXQt. El agente de autenticación asegura que el usuario de la sesión verifique su identidad autenticándose como sí mismo o como un administrador.

Los módulos LXQt son herramientas independientes del escritorio y operan como demonios para el usuario local en operaciones específicas del escritorio.

COMPORTAMIENTO

El módulo detecta la escalada de privilegios en recursos compartidos y presenta un diálogo de seguridad solicitando la contraseña del usuario para proceder con la acción.

ARRANQUE AUTOMÁTICO

El módulo solo se muestra en el escritorio LXQt, pero es posible crear una acción de arranque automático en otros entornos de escritorio.
