NOMBRE

lxc-unshare - Ejecuta una tarea en un nuevo conjunto de namespaces.

SINOPSIS


lxc-unshare
{-s, --namespaces namespaces} [-u, --user usuario] [-H, --hostname nombrehost] [-i, --ifname nombrefich] [-d, --daemon] [-M, --remount] {comando}

DESCRIPCIÓN

lxc-unshare puede ser utilizado para ejecutar una tarea en un conjunto clonado de namespaces. Este comando se proporciona principalmente con fines de prueba. A pesar de su nombre, siempre utiliza clone en lugar de unshare para crear la nueva tarea con namespaces nuevos. Aparte de probar regresiones del kernel, esto no debería hacer ninguna diferencia.

OPCIONES

-s, --namespaces namespaces
Especifica los namespaces a los que adjuntarse, como una lista separada por barras verticales, p.ej., NETWORK|IPC. Los valores permitidos son MOUNT, PID, UTSNAME, IPC, USER y NETWORK. Esto permite cambiar el contexto del proceso, por ejemplo, al namespace de red del contenedor mientras se retienen los otros namespaces como los del host. (El símbolo de barra vertical necesita ser escapado, p.ej., MOUNT\|PID o entre comillas, p.ej., "MOUNT|PID").
-u, --user usuario
Especifica un identificador de usuario al que debe convertirse la nueva tarea.
-H, --hostname nombrehost
Establece el nombre del host en el nuevo contenedor. Solo permitido si el namespace UTSNAME está configurado.
-i, --ifname interfaz
Mueve la interfaz nombrada al contenedor. Solo permitido si el namespace NETWORK está configurado. Puedes especificar este argumento varias veces para mover varias interfaces al contenedor.
-d, --daemon
Daemonizar (no esperar a que el contenedor salga antes de salir)
-M, --remount
Monta los sistemas de archivos por defecto (/proc /dev/shm y /dev/mqueue) en el contenedor. Solo permitido si el namespace MOUNT está configurado.

EJEMPLOS

Para iniciar un nuevo shell con su propio namespace UTS (nombre de host),

          lxc-unshare -s UTSNAME /bin/bash

Si el nombre del host se cambia en ese shell, el cambio no se reflejará en el host.

Para iniciar un shell en un nuevo namespace de red, pid y montaje, 

          lxc-unshare -s "NETWORK|PID|MOUNT" /bin/bash

El shell resultante tendrá el pid 1 y no verá ninguna interfaz de red. Después de remontar /proc en ese shell,

          mount -t proc proc /proc

la salida de ps mostrará que no hay otros procesos en el namespace.

Para iniciar un shell en un nuevo namespace de red, pid, montaje y nombre de host.

          lxc-unshare -s "NETWORK|PID|MOUNT|UTSNAME" -M -H mihostname -i veth1 /bin/bash

El shell resultante tendrá el pid 1 y verá dos interfaces de red (lo y veth1). El nombre del host será "mihostname" y /proc habrá sido remontado. La salida de ps mostrará que no hay otros procesos en el namespace.
