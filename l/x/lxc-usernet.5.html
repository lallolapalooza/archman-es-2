NOMBRE

lxc-usernet - archivo de administración de red de usuario no privilegiado.

DESCRIPCIÓN

/etc/lxc/lxc-usernet controla los límites que el programa lxc-user-nic impone a las interfaces de red que un usuario no privilegiado puede crear.

CONFIGURACIÓN

Este archivo consta de múltiples entradas, una por línea, con el formato:

usuario tipo bridge número

o

@grupo tipo bridge número

Donde

usuario
es el nombre de usuario al que se aplica esta entrada.
@grupo
es el nombre del grupo al que se aplica esta entrada.
tipo
es el tipo de interfaz de red que se permite. Actualmente solo se admite veth.
bridge
es el puente al que se pueden adjuntar las interfaces de red, por ejemplo lxcbr0.
número
es el número o la cuota de interfaces de red del tipo dado que el usuario o grupo dado puede adjuntar al puente dado, por ejemplo 2.

Dado que un usuario puede especificarse tanto por nombre de usuario como por uno o más grupos de usuarios, es posible que varias líneas de configuración permitan a ese usuario crear interfaces de red. En tales casos, cualquier interfaz creada se cuenta hacia las cuotas del usuario o grupo en el orden en que aparecen en el archivo. Si la cuota de una línea se agota, se analizarán las restantes hasta que se encuentre una o se llegue al final del archivo.
