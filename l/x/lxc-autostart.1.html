NOMBRE

lxc-autostart - iniciar/detener/matar contenedores de inicio automático

SINOPSIS


lxc-autostart
[-k] [-L] [-r] [-s] [-a] [-A] [-g grupos] [-t tiempo_espera]

DESCRIPCIÓN

lxc-autostart procesa contenedores con lxc.start.auto establecido. Permite al usuario iniciar, apagar, matar y reiniciar contenedores en el orden correcto, esperando el tiempo adecuado. Admite filtrado por lxc.group o simplemente se ejecuta contra todos los contenedores definidos. También puede ser utilizado por herramientas externas en modo de lista donde no se realizará ninguna acción y se mostrará la lista de contenedores afectados (y, si es relevante, los retrasos).

Las opciones [-r], [-s] y [-k] especifican la acción a realizar. Si no se especifica ninguna, se iniciarán los contenedores. [-a] y [-g] se utilizan para especificar qué contenedores se verán afectados. Por defecto, solo se verán afectados los contenedores sin lxc.group establecido. [-t TIEMPO_ESPERA] especifica el tiempo máximo a esperar para que el contenedor complete el apagado o reinicio.

OPCIONES

-r,--reboot
Solicita un reinicio del contenedor.
-s,--shutdown
Solicita un apagado limpio. Si se proporciona un [-t tiempo_espera] mayor que 0 y el contenedor no se apaga dentro de este período, se matará como con la opción [-k kill].
-k,--kill
En lugar de solicitar un apagado limpio del contenedor, mata explícitamente todas las tareas del contenedor.
-L,--list
En lugar de realizar la acción, solo imprime el nombre del contenedor y los retrasos de espera hasta iniciar el siguiente contenedor.
-t,--timeout TIEMPO_ESPERA
Espera TIEMPO_ESPERA segundos antes de detener forzosamente el contenedor.
-g,--groups GRUPO
Lista separada por comas de grupos a seleccionar (por defecto los que no tienen lxc.group - el grupo NULL). Esta opción puede especificarse varias veces y los argumentos se concatenarán. El grupo NULL o vacío puede especificarse como una coma inicial, una coma final, una doble coma incrustada o un argumento vacío donde se debe procesar el grupo NULL. Los grupos se procesan en el orden especificado en la línea de comandos. Múltiples invocaciones de la opción -g pueden mezclarse libremente con las listas separadas por comas y se combinarán en el orden especificado.
-a,--all
Ignora lxc.group y selecciona todos los contenedores de inicio automático.
-A,--ignore-auto
Ignora el flag lxc.start.auto. Combinado con -a, seleccionará todos los contenedores del sistema.

INICIO AUTOMÁTICO Y ARRANQUE DEL SISTEMA

El comando lxc-autostart se utiliza como parte del servicio del sistema LXC, cuando está habilitado para ejecutarse al arrancar y al apagar el sistema anfitrión. Se utiliza para seleccionar qué contenedores iniciar, en qué orden y con qué retraso entre cada inicio al arrancar el sistema anfitrión.

Cada contenedor puede formar parte de cualquier número de grupos o de ninguno. Dos grupos son especiales. Uno es el grupo NULL, es decir, el contenedor no pertenece a ningún grupo. El otro grupo es el grupo "onboot".

Cuando el sistema arranca con el servicio LXC habilitado, primero intentará arrancar los contenedores con lxc.start.auto == 1 que sean miembros del grupo "onboot". El inicio será en orden de lxc.start.order. Si se ha especificado un lxc.start.delay, se respetará ese retraso antes de intentar iniciar el siguiente contenedor para dar tiempo al contenedor actual a comenzar la inicialización y reducir la sobrecarga del sistema anfitrión. Después de iniciar los miembros del grupo "onboot", el sistema LXC procederá a iniciar los contenedores con lxc.start.auto == 1 que no sean miembros de ningún grupo (el grupo NULL) y procederá como con el grupo onboot.

EJEMPLOS DE GRUPOS DE INICIO

-g "onboot,"
Inicia primero el grupo "onboot" y luego el grupo NULL.

Esto es equivalente a: -g onboot -g "".

-g "dns,web,,onboot"
Inicia primero el grupo "dns", luego el grupo "web", luego el grupo NULL seguido del grupo "onboot".

Esto es equivalente a: -g dns,web -g ,onboot o -g dns -g web -g "" -g onboot.
