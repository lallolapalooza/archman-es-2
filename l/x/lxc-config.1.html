NOMBRE

lxc-config - consultar la configuración del sistema LXC

SINOPSIS


lxc-config
[-l] [elemento]

DESCRIPCIÓN

lxc-config consulta la configuración del sistema lxc y te permite listar las claves válidas o consultar claves individuales para obtener su valor.

OPCIONES

-l
Listar todas las claves soportadas.
elemento
Consultar el valor de la clave especificada.
