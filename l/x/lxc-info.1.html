lxc-info(1) lxc-info(1)

NOMBRE

lxc-info - consultar información sobre un contenedor

SINOPSIS


lxc-info
{-n nombre} [-c CLAVE] [-s] [-p] [-i] [-S] [-H]

DESCRIPCIÓN

lxc-info consulta y muestra información sobre un contenedor.

OPCIONES

-c, --config CLAVE
Imprime una clave de configuración del contenedor. Esta opción puede ser dada múltiples veces para imprimir varios pares de clave = valor.
-s, --state
Solo imprime el estado del contenedor.
-p, --pid
Solo imprime el PID del contenedor.
-i, --ips
Solo imprime las direcciones IP del contenedor.
-S, --stats
Solo imprime las estadísticas del contenedor. Tenga en cuenta que por razones de rendimiento, el kernel no contabiliza el uso de memoria del kernel a menos que se establezca un límite de memoria del kernel. Si no se establece un límite, lxc-info mostrará el uso de memoria del kernel como 0. Se puede establecer un límite especificando 
            lxc.cgroup.memory.kmem.limit_in_bytes = número

en su archivo de configuración del contenedor, consulte lxc.conf(5).

-H, --no-humanize
Imprime las estadísticas del contenedor en formato crudo, no humanizado. El valor predeterminado es imprimir las estadísticas en formato humanizado.

OPCIONES COMUNES

Estas opciones son comunes a la mayoría de los comandos lxc.

-?, -h, --help
Imprime un mensaje de uso más largo de lo normal.
--usage
Muestra el mensaje de uso
-q, --quiet
silenciar activado
-P, --lxcpath=RUTA
Usa una ruta alternativa para los contenedores. El valor predeterminado es /var/lib/lxc.
-o, --logfile=ARCHIVO
Salida a un ARCHIVO de registro alternativo. El valor predeterminado es sin registro.
-l, --logpriority=NIVEL
Establece la prioridad del registro a NIVEL. La prioridad de registro predeterminada es ERROR. Los valores posibles son: FATAL, ALERT, CRIT, WARN, ERROR, NOTICE, INFO, DEBUG, TRACE.

Tenga en cuenta que esta opción establece la prioridad de los eventos registrados en el archivo de registro alternativo. No tiene efecto en los eventos de ERROR registrados en stderr.

-n, --name=NOMBRE
Usa el identificador de contenedor NOMBRE. El formato del identificador de contenedor es una cadena alfanumérica.
--rcfile=ARCHIVO
Especifica el archivo de configuración para configurar las funcionalidades de virtualización y aislamiento para el contenedor.

Este archivo de configuración, si está presente, se utilizará incluso si ya existe un archivo de configuración en el contenedor creado previamente (a través de lxc-create).

--version
Muestra el número de versión.

EJEMPLOS

lxc-info -n foo
Muestra información para foo.
lxc-info -n 'ubuntu.*'
Muestra información para todos los contenedores cuyos nombres comiencen con ubuntu.
lxc-info -n foo -c lxc.net.0.veth.pair
Imprime el nombre del par veth de foo.
