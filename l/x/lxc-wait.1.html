NOMBRE

lxc-wait - esperar a que un contenedor alcance un estado específico

SINOPSIS


lxc-wait
{-n nombre} {-s estados}

DESCRIPCIÓN

lxc-wait espera a que un contenedor alcance un estado específico antes de salir, lo cual es útil para scripts.

OPCIONES

-s, --state estados
Especifica el(los) estado(s) del contenedor a esperar. Los estados del contenedor pueden ser combinados con OR para especificar varios estados.
-t, --timeout tiempo_espera
Tiempo de espera en segundos para que se alcance el estado deseado.

OPCIONES COMUNES

Estas opciones son comunes a la mayoría de los comandos de lxc.

-?, -h, --help
Imprime un mensaje de uso más largo de lo normal.
--usage
Muestra el mensaje de uso
-q, --quiet
silenciar activado
-P, --lxcpath=RUTA
Usar una ruta alternativa para los contenedores. La predeterminada es /var/lib/lxc.
-o, --logfile=ARCHIVO
Salida a un archivo de registro alternativo ARCHIVO. El valor predeterminado es no registrar.
-l, --logpriority=NIVEL
Establece la prioridad del registro a NIVEL. La prioridad de registro predeterminada es ERROR. Los valores posibles son: FATAL, ALERT, CRIT, WARN, ERROR, NOTICE, INFO, DEBUG, TRACE.

Tenga en cuenta que esta opción establece la prioridad de los eventos registrados en el archivo de registro alternativo. No tiene efecto en los eventos de ERROR registrados en stderr.

-n, --name=NOMBRE
Usar el identificador de contenedor NOMBRE. El formato del identificador del contenedor es una cadena alfanumérica.
--rcfile=ARCHIVO
Especifica el archivo de configuración para configurar las funcionalidades de virtualización y aislamiento para el contenedor.

Este archivo de configuración, si está presente, se usará incluso si ya existe un archivo de configuración en el contenedor creado previamente (mediante lxc-create).

--version
Muestra el número de versión.

EJEMPLOS

lxc-wait -n foo -s RUNNING
sale cuando se alcanza 'RUNNING'.
lxc-wait -n foo -s 'RUNNING|STOPPED'
sale cuando se alcanza el estado 'RUNNING' o 'STOPPED'.

DIAGNÓSTICO

El contenedor no fue encontrado
El contenedor especificado no fue creado previamente con el comando lxc-create.
