NOMBRE

lxpanelctl - controlador para lxpanel.

SINOPSIS

lxpanelctl {comando}

DESCRIPCIÓN

Esta página del manual documenta brevemente el comando lxpanelctl.

lxpanelctl es un programa que controla lxpanel.

COMANDOS

menu

Muestra el menú del sistema.

run

Muestra el diálogo de ejecución.

config

Muestra el diálogo de configuración del panel. Si hay más de un panel configurado, no está definido qué diálogo de configuración de panel se mostrará.

restart

Reinicia lxpanel.

exit

Sale de lxpanel.

command [--panel=[N:]borde] plugin comando

Envía un comando a un plugin. Opcionalmente, se puede establecer el número de monitor N (en rango de 1 a 8) y el borde (izquierdo, derecho, superior o inferior), de lo contrario, el comando se enviará al primer plugin encontrado en cualquier panel.
