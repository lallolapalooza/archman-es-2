NOMBRE

lxqt-wayland-session - Sesión Wayland para LXQt

DESCRIPCIÓN

Este módulo proporciona los archivos necesarios para la sesión Wayland del entorno de escritorio LXQt y habilita la página de configuración de Wayland en lxqt-config-session.

ARCHIVOS

startlxqtwayland: Script que inicia el compositor y configura la disposición del teclado.

Archivo de entrada de escritorio que declara startlxqtwayland como binario necesario para iniciar sesiones LXQt en Wayland. Se proporciona por ejemplo a los gestores de pantalla.

Archivos de configuración básicos para compositores compatibles cuando sea necesario: Hyprland, kwin_wayland, labwc, niri, river, sway, wayfire.

COMPOSITORES NO SOPORTADOS

Cualquier compositor puede ser lanzado por startlxqtwayland, pero para iniciar y salir de la sesión LXQt, se debe añadir una línea lxqt-session && <comando_de_salida_del_compositor> a su configuración de autoinicio.

NOTAS

Algunas herramientas de configuración de lxqt no soportan Wayland actualmente y esas configuraciones deben realizarse en la configuración del compositor:

* lxqt-globalkeys

* lxqt-config-monitor (aunque kwin_wayland está mayormente soportado)

* lxqt-config-input

Limitaciones en lxqt-panel:

* El soporte de espacios de trabajo en el plugin de barra de tareas de lxqt-panel solo se soporta en kwin_wayland.

* El plugin Showdesktop y el cambiador de espacios de trabajo solo se soportan actualmente en kwin_wayland.

* Los plugins kbindicator y qeyes no se soportan actualmente en Wayland.

REPORTE DE ERRORES

Reporta errores en https://github.com/lxqt/lxqt-wayland-session/issues
