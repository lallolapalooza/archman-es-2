lxc-execute(1) lxc-execute(1)

NOMBRE

lxc-execute - ejecuta una aplicación dentro de un contenedor.

SINOPSIS


lxc-execute
{-n nombre} [-d] [-f archivo_config] [-s CLAVE=VALOR] [-u, --uid uid] [-g, --gid gid] [-- comando]

DESCRIPCIÓN

lxc-execute ejecuta el comando especificado dentro del contenedor especificado por nombre.

Configurará el contenedor de acuerdo con la configuración previamente definida con el comando lxc-create o con el parámetro de archivo de configuración. Si no se define ninguna configuración, se utiliza el aislamiento predeterminado.

Este comando se utiliza principalmente cuando se desea lanzar rápidamente una aplicación en un entorno aislado.

El comando lxc-execute ejecutará el comando especificado en el contenedor a través de un proceso intermedio, lxc-init. Este lxc-init, después de lanzar el comando especificado, esperará su finalización y la de todos los demás procesos reparentados (para soportar demonios en el contenedor). En otras palabras, en el contenedor, lxc-init tendrá el PID 1 y el primer proceso de la aplicación tendrá el PID 2.

El lxc-init mencionado anteriormente está diseñado para reenviar las señales recibidas al comando iniciado.

OPCIONES

-f, --rcfile archivo_config
Especifica el archivo de configuración para configurar las funcionalidades de virtualización y aislamiento para el contenedor.

Este archivo de configuración, si está presente, se utilizará incluso si ya existe un archivo de configuración en el contenedor creado previamente (a través de lxc-create).

-s, --define CLAVE=VALOR
Asigna el valor VALOR a la variable de configuración CLAVE. Esto anula cualquier asignación realizada en archivo_config.
-d, --daemon
Ejecuta el contenedor como un demonio. Como el contenedor no tiene tty, si ocurre un error, no se mostrará nada; se puede usar el archivo de log para verificar el error.
-u, --uid uid
Ejecuta el comando con el ID de usuario (usa valor numérico) uid dentro del contenedor.
--g, --gid gid
Ejecuta el comando con el ID de grupo (usa valor numérico) gid dentro del contenedor.
--
Indica el fin de las opciones y deshabilita el procesamiento posterior de opciones. Cualquier argumento después de -- se trata como argumento para comando.

Esta opción es útil cuando se desean especificar opciones para comando y no se quiere que lxc-execute las interprete.

OPCIONES COMUNES

Estas opciones son comunes a la mayoría de los comandos de lxc.

-?, -h, --help
Imprime un mensaje de uso más largo de lo normal.
--usage
Muestra el mensaje de uso.
-q, --quiet
Silencia la salida.
-P, --lxcpath=RUTA
Utiliza una ruta alternativa para los contenedores. La ruta predeterminada es /var/lib/lxc.
-o, --logfile=ARCHIVO
Salida a un ARCHIVO de log alternativo. El valor predeterminado es sin log.
-l, --logpriority=NIVEL
Establece la prioridad del log a NIVEL. La prioridad del log predeterminada es ERROR. Los valores posibles son: FATAL, ALERT, CRIT, WARN, ERROR, NOTICE, INFO, DEBUG, TRACE.

Tenga en cuenta que esta opción establece la prioridad de los eventos de log en el archivo de log alternativo. No tiene efecto sobre los eventos ERROR registrados en stderr.

-n, --name=NOMBRE
Usa el identificador de contenedor NOMBRE. El formato del identificador de contenedor es una cadena alfanumérica.
--rcfile=ARCHIVO
Especifica el archivo de configuración para configurar las funcionalidades de virtualización y aislamiento para el contenedor.

Este archivo de configuración, si está presente, se utilizará incluso si ya existe un archivo de configuración en el contenedor creado previamente (a través de lxc-create).

--version
Muestra el número de versión.

DIAGNÓSTICO

El contenedor está ocupado
El contenedor especificado ya está ejecutando una aplicación. Debería detenerlo antes de reutilizar este contenedor o crear uno nuevo.
