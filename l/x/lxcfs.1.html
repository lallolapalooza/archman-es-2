NOMBRE

lxcfs - "Sistema de archivos de virtualización del sistema para contenedores"

SINOPSIS

lxcfs <directorio>

DESCRIPCIÓN

lxcfs es un sistema de archivos de virtualización de proc, sys y cgroup basado en FUSE.

Opciones :

-d, --debug
Ejecutar lxcfs con la depuración activada
-f, --foreground
Ejecutar lxcfs en primer plano
-h, --help
Imprimir ayuda

-l, --enable-loadavg Activar la virtualización de loadavg

-o
Opciones para pasar directamente a través de fuse
-p, --pidfile=ARCHIVO
Ruta a usar para almacenar el pid de lxcfs. El archivo pid por defecto es /run/lxcfs.pid
-u, --disable-swap
Desactivar la virtualización de swap
-v, --version
Imprimir la versión de lxcfs
--enable-cfs
Activar la virtualización de CPU a través de shares de CPU
--enable-pidfd
Usar pidfd para el seguimiento de procesos
--enable-cgroup
Activar el código de emulación de cgroup
--runtime-dir=DIR
Ruta a usar como directorio de ejecución. Por defecto es /run
