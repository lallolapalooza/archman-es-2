NOMBRE

lxc-cgroup - gestiona el grupo de control asociado a un contenedor

SINOPSIS


lxc-cgroup
{-n nombre} {objeto-de-estado} [valor]

DESCRIPCIÓN

lxc-cgroup obtiene o establece el valor de un objeto-de-estado (por ejemplo, 'cpuset.cpus') en el cgroup del contenedor para el subsistema correspondiente (por ejemplo, 'cpuset'). Si no se especifica [valor], se muestra el valor actual del objeto-de-estado; de lo contrario, se establece.

Tenga en cuenta que lxc-cgroup no comprueba si el objeto-de-estado es válido para el kernel en ejecución, ni si el subsistema correspondiente está contenido en alguna jerarquía de cgroup montada.

OPCIONES

objeto-de-estado
Especifica el nombre del objeto de estado.
[valor]
Especifica el valor a asignar al objeto de estado.

OPCIONES COMUNES

Estas opciones son comunes a la mayoría de los comandos de lxc.

-?, -h, --help
Imprime un mensaje de uso más largo de lo normal.
--usage
Muestra el mensaje de uso.
-q, --quiet
silenciar.
-P, --lxcpath=RUTA
Utiliza una ruta alternativa para el contenedor. La ruta por defecto es /var/lib/lxc.
-o, --logfile=ARCHIVO
Escribe la salida en un ARCHIVO de registro alternativo. Por defecto, no hay registro.
-l, --logpriority=NIVEL
Establece la prioridad del registro en NIVEL. La prioridad de registro por defecto es ERROR. Los valores posibles son: FATAL, ALERT, CRIT, WARN, ERROR, NOTICE, INFO, DEBUG, TRACE.

Tenga en cuenta que esta opción establece la prioridad de los eventos registrados en el archivo de registro alternativo. No tiene efecto en los eventos ERROR registrados en stderr.

-n, --name=NOMBRE
Utiliza el identificador de contenedor NOMBRE. El formato del identificador de contenedor es una cadena alfanumérica.
--rcfile=ARCHIVO
Especifica el archivo de configuración para configurar las funcionalidades de virtualización y aislamiento para el contenedor.

Este archivo de configuración, si está presente, se utilizará incluso si ya existe un archivo de configuración en el contenedor creado previamente (a través de lxc-create).

--version
Muestra el número de versión.

EJEMPLOS

lxc-cgroup -n foo devices.list
muestra los dispositivos permitidos para su uso.
lxc-cgroup -n foo cpuset.cpus "0,3"
asigna los procesadores 0 y 3 al contenedor.

DIAGNÓSTICO

El contenedor no se encontró
El contenedor no se está ejecutando.
