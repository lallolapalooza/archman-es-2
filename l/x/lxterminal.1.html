NOMBRE

lxterminal - un emulador de terminal ligero basado en GTK+ para el escritorio LXDE.

SINOPSIS

lxterminal [opciones...]

DESCRIPCIÓN

Esta página del manual documenta brevemente el comando lxterminal.

lxterminal es un programa que proporciona un emulador de terminal para el escritorio, usualmente para LXDE.

OPCIONES

Este programa sigue la sintaxis habitual de la línea de comandos de GNU, con opciones largas que comienzan con dos guiones (`-'). A continuación se incluye un resumen de las opciones.

-e CADENA --command=CADENA --command CADENA

Esta opción especifica el programa (y sus argumentos de línea de comandos) que se ejecutará en la terminal. Excepto en la forma --command=, esta debe ser la última opción en la línea de comandos.

--geometry=CARACTERESxLÍNEAS

Establece el tamaño de la terminal en caracteres y líneas.

-l --loginshell

Ejecuta el shell de inicio de sesión.

--no-remote

Inicia una ventana de lxterminal en un proceso que está separado de todas las demás ventanas de lxterminal. Asegura que las variables de entorno se hereden del proceso que lo lanza (como el proceso de shell del usuario).

-t NOMBRE[,NOMBRE[, NOMBRE[...]]] --title=NOMBRE[,NOMBRE[, NOMBRE[...]]] --tabs= NOMBRE[, NOMBRE[, NOMBRE[...]]]

Establece el título de la terminal. Usa coma para múltiples pestañas.

--working-directory=DIRECTORIO

Establece el directorio de trabajo de la terminal.

--profile=NOMBRE

Si se establece, entonces todas las instancias de lxterminal invocadas de la misma manera compartirán un archivo de configuración llamado lxterminal-NOMBRE.conf.
