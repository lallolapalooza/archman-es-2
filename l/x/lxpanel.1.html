NOMBRE

lxpanel - un panel GTK2 ligero para el escritorio LXDE.

SINOPSIS

lxpanel [ opciones ]

DESCRIPCIÓN

Esta página del manual documenta brevemente el comando lxpanel.

lxpanel es un programa que proporciona un panel para el escritorio, normalmente para LXDE. Es un panel de escritorio ligero basado en GTK+ 2.x.

Características

•Menú de aplicaciones fácil de usar generado automáticamente a partir de archivos .desktop en el sistema.
•Barra de lanzadores (pequeños iconos para lanzar aplicaciones)
•Barra de tareas que soporta la indicación de `urgencia' de ICCCM/EWMH (las ventanas de Pidgin IM pueden parpadear con nuevos mensajes entrantes)
•Área de notificación (bandeja del sistema)
•Reloj digital
•Diálogo Ejecutar (escribe el comando para ejecutar, sin abrir una terminal)
•Complemento de icono de estado de red (opcional)
•Complemento de control de volumen (opcional)
•lxpanelctl, un controlador externo que permite controlar lxpanel en otros programas. Por ejemplo, "lxpanelctl run" mostrará el diálogo Ejecutar en lxpanel, y "lxpanelctl menu" mostrará el menú de aplicaciones. Esto es útil en combinaciones de teclas proporcionadas por los gestores de ventanas.

OPCIONES

Este programa sigue la sintaxis habitual de la línea de comandos de GNU, con opciones largas que comienzan con dos guiones (`-'). A continuación se incluye un resumen de las opciones.

-h --help

Muestra la ayuda sobre las opciones.

-v --version

Muestra la versión del programa.

-p NOMBRE, --profile NOMBRE

Establece el perfil a cargar.

ARCHIVOS

~/.config/lxpanel/PERFIL/

Directorio de archivos de configuración, se puede editar mediante el diálogo de preferencias.

~/.config/lxpanel/PERFIL/gtkrc

Archivo RC opcional de GTK+ 2.0 para alterar la apariencia, se puede usar para crear un estilo de panel personalizado.

VER TAMBIÉN
