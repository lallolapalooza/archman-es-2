NOMBRE

lxc.system.conf - Archivo de configuración del sistema LXC

DESCRIPCIÓN

La configuración del sistema se encuentra en /etc/lxc/lxc.conf o ~/.config/lxc/lxc.conf para contenedores no privilegiados.

Este archivo de configuración se utiliza para establecer valores como las rutas de búsqueda predeterminadas y la configuración del backend de almacenamiento para LXC.

RUTAS DE CONFIGURACIÓN

lxc.lxcpath
La ubicación donde se almacenan todos los contenedores.
lxc.default_config
La ruta a la configuración predeterminada del contenedor.

GRUPOS DE CONTROL

lxc.cgroup.use
Lista separada por comas de los controladores de cgroup a configurar. Si no se especifica ninguno, se utilizarán todos los controladores disponibles.
lxc.cgroup.pattern
Cadena de formato utilizada para generar la ruta del cgroup (por ejemplo, lxc/%n).

LVM

lxc.bdev.lvm.vg
Nombre del grupo de volúmenes LVM predeterminado.
lxc.bdev.lvm.thin_pool
Nombre del pool delgado LVM predeterminado.

ZFS

lxc.bdev.zfs.root
Nombre raíz ZFS predeterminado.
