lxc-start(1)

Paquete: lxc

Licencias: LGPL

lxc-start(1) lxc-start(1)

NOMBRE

lxc-start - ejecuta una aplicación dentro de un contenedor.

SINOPSIS


lxc-start
{-n nombre} [-f archivo_config] [-c dispositivo_consola] [-L archivo_log_consola] [-d] [-F] [-p archivo_pid] [-s CLAVE=VALOR] [-C] [--share-[net|ipc|uts] nombre|pid] [comando]

DESCRIPCIÓN

lxc-start ejecuta el comando especificado dentro del contenedor especificado por nombre.

Configurará el contenedor de acuerdo con la configuración previamente definida con el comando lxc-create o con el parámetro de archivo de configuración. Si no se define ninguna configuración, se utilizará el aislamiento predeterminado.

Si no se especifica ningún comando, lxc-start utilizará el comando definido en lxc.init.cmd o, si no está establecido, el comando predeterminado "/sbin/init" para ejecutar un contenedor del sistema.

OPCIONES

-d, --daemon
Ejecuta el contenedor como un demonio. Como el contenedor no tiene más tty, si ocurre un error no se mostrará nada, se puede usar el archivo de log para comprobar el error. (Este es el modo predeterminado)
-F, --foreground
Ejecuta el contenedor en primer plano. En este modo, la consola del contenedor se adjuntará al tty actual y las señales se enrutarán directamente al contenedor.
-p, --pidfile archivo_pid
Crea un archivo con el identificador de proceso.
-f, --rcfile archivo_config
Especifica el archivo de configuración para configurar las funcionalidades de virtualización y aislamiento para el contenedor.

Este archivo de configuración, si está presente, se utilizará incluso si ya existe un archivo de configuración en el contenedor previamente creado (a través de lxc-create).

-c, --console dispositivo_consola
Especifica un dispositivo para usar para la consola del contenedor, por ejemplo, /dev/tty8. Si no se especifica esta opción, se utilizará el terminal actual a menos que se especifique -d.
-L, --console-log archivo_log_consola
Especifica un archivo para registrar la salida de la consola del contenedor.
-s, --define CLAVE=VALOR
Asigna el valor VALOR a la variable de configuración CLAVE. Esto anula cualquier asignación realizada en archivo_config.
-C, --close-all-fds
Si se heredan descriptores de archivo, ciérralos. Si no se especifica esta opción, lxc-start fallará. Nota: --daemon implica --close-all-fds.
--share-net nombre|pid
Hereda un espacio de nombres de red de un contenedor con el nombre o un pid. El espacio de nombres de red continuará siendo administrado por el propietario original. La configuración de red del contenedor que se inicia se ignora y los scripts de subida/bajada no se ejecutarán.
--share-ipc nombre|pid
Hereda un espacio de nombres IPC de un contenedor con el nombre o un pid.
--share-uts nombre|pid
Hereda un espacio de nombres UTS de un contenedor con el nombre o un pid. El LXC que se inicia no establecerá el nombre de host, pero el sistema operativo del contenedor puede hacerlo de todos modos.

OPCIONES COMUNES

Estas opciones son comunes a la mayoría de los comandos de lxc.

-?, -h, --help
Imprime un mensaje de uso más largo de lo normal.
--usage
Muestra el mensaje de uso
-q, --quiet
silenciar activado
-P, --lxcpath=RUTA
Utiliza una ruta alternativa para los contenedores. La predeterminada es /var/lib/lxc.
-o, --logfile=ARCHIVO
Salida a un ARCHIVO de log alternativo. El predeterminado es sin log.
-l, --logpriority=NIVEL
Establece la prioridad del log a NIVEL. La prioridad de log predeterminada es ERROR. Los valores posibles son: FATAL, ALERT, CRIT, WARN, ERROR, NOTICE, INFO, DEBUG, TRACE.

Tenga en cuenta que esta opción establece la prioridad de los eventos de log en el archivo de log alternativo. No tiene efecto en los eventos ERROR que se registran en stderr.

-n, --name=NOMBRE
Usa el identificador de contenedor NOMBRE. El formato del identificador de contenedor es una cadena alfanumérica.
--rcfile=ARCHIVO
Especifica el archivo de configuración para configurar las funcionalidades de virtualización y aislamiento para el contenedor.

Este archivo de configuración, si está presente, se utilizará incluso si ya existe un archivo de configuración en el contenedor previamente creado (a través de lxc-create).

--version
Muestra el número de versión.

DIAGNÓSTICO

El contenedor está ocupado
El contenedor especificado ya está ejecutando una aplicación. Debería detenerlo antes de reutilizar este contenedor o crear uno nuevo.

xc-start(1)

xc-start - Starts an X server for the XCB development library.

Synopsis

xc-start [options]

Description

The xc-start command starts an X server, typically for testing or development purposes related to the XCB (X protocol C-language Binding) library. It provides a minimal X server environment.

Options

This command does not currently accept any command-line options.

Environment

No specific environment variables are required for xc-start.

See Also

  • xcb(3) - Documentation for the XCB library.

Example

To start the X server, simply run: 

xc-start

This will launch the X server, allowing XCB applications to connect to it.
