LXSHORTCUT(1) Manual de lxshortcut LXSHORTCUT(1)

NOMBRE

lxshortcut - editor de archivos de entrada de escritorio

SINOPSIS

lxshortcut [ -i archivo-entrada ] [ -o archivo-salida ]

DESCRIPCIÓN

lxshortcut es una aplicación sencilla que utiliza la ventana de diálogo de propiedades de archivos de LibFM para cambiar las propiedades de una entrada de escritorio: icono, nombre para mostrar, ruta y argumentos de ejecución, etc.

OPCIONES

Se debe especificar al menos una opción y si no se especifica archivo-salida, se utilizará archivo-entrada para generar el resultado, ya sea una ruta completa o una ruta en el directorio de datos de usuario especificado por XDG para las entradas del menú.

-i archivo-entrada, --input=archivo-entrada
utiliza archivo-entrada como origen para la edición, puede ser una entrada de menú XDG si no se especifica una ruta completa o una ruta personalizada a algún archivo.
-o archivo-salida, --output=archivo-salida
escribe el resultado en archivo-salida

VER TAMBIÉN

Especificación de entrada de escritorio XDG
