LXQT-RUNNER(1) Módulo LXQt LXQT-RUNNER(1)

NOMBRE

lxqt-runner - módulo lanzador de aplicaciones de LXQt, el Entorno de Escritorio Ligero

SINOPSIS

lxqt-runner

DESCRIPCIÓN

Este módulo permite lanzar cualquier aplicación escribiendo el atajo configurado, ofrece acceso rápido para cerrar sesión, apagar y otras funciones. También se incluye una calculadora: por ejemplo 2*4+10/2=.

COMPORTAMIENTO

A medida que escribes, aparecerán sugerencias. Una vez que aparezca la aplicación que deseas ejecutar, puedes navegar hasta ella usando el ratón o las teclas de flecha de tu teclado. Presionar Enter o hacer clic en ella lanzará la aplicación. El atajo de activación se puede cambiar desde el menú de configuración, lxqt-globalkeyshortcuts (X11) o en el compositor (Wayland).

ARRANQUE AUTOMÁTICO

Este módulo solo se muestra en el entorno de escritorio LXQt, pero se puede usar en otros entornos de escritorio añadiéndolo al arranque automático.

REPORTE DE ERRORES

Reporta errores en https://github.com/lxqt/lxqt-runner/issues

VER TAMBIÉN

LXQt está adaptado para usuarios que valoran la simplicidad, la velocidad y una interfaz intuitiva.
También se puede usar con máquinas menos potentes. Ver también:

lxqt-session(1)

lxqt-config-session(1)
