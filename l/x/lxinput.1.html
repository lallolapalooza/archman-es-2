NOMBRE

lxinput - un programa ligero para configurar el teclado y el ratón

SINOPSIS

lxinput

DESCRIPCIÓN

Esta página del manual documenta brevemente el comando lxinput.

lxinput es un programa para configurar el teclado y el ratón para el escritorio, generalmente para LXDE.
