LXQT-CONFIG-APPEARANCE(1) Configuración de Apariencia de LXQt LXQT-CONFIG-APPEARANCE(1)

NOMBRE

lxqt-config-appearance - Aplicación gráfica de apariencia de LXQt: El Entorno de Escritorio Ligero Qt

SINOPSIS

lxqt-config-appearance

DESCRIPCIÓN

Con esta aplicación puedes configurar y personalizar la apariencia gráfica de Qt / LXQt. Las opciones incluyen la configuración del estilo de los widgets, la paleta de colores, la barra de herramientas de la aplicación, el tema de iconos, el tema de LXQt, la fuente, el cursor y, opcionalmente, el estilo GTK 2/3.

En Linux/Unix, la apariencia de una aplicación gráfica depende del toolkit en el que se basa. Para LXQt, la apariencia general de muchas aplicaciones depende del framework gráfico de Qt. La aplicación lxqt-config-appearance proporciona todos los aspectos para configurar la apariencia del escritorio LXQt.

Todos los aspectos principales restantes de la apariencia de LXQt dependen del estilo de widget de Qt activo, ya que el entorno de escritorio LXQt se basa en el framework de Qt.

OPCIONES

-v, --version Muestra información de la versión.
-h, --help Muestra ayuda sobre las opciones de la línea de comandos.
--help-all Muestra ayuda, incluyendo las opciones genéricas de Qt.
