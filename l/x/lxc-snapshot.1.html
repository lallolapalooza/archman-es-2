NOMBRE

lxc-snapshot - Crear una instantánea de un contenedor existente.

SINOPSIS


lxc-snapshot
{-n, --name nombre} [-c, --comment archivo]

lxc-snapshot
{-n, --name nombre} {-d, -destroy nombre-instantanea}

lxc-snapshot
{-n, --name nombre} {-L, --list } [-C, --showcomments ]

lxc-snapshot
{-n, --name nombre} {-r, -restore nombre-instantanea} [-N, --newname nombrenuevo]

DESCRIPCIÓN

lxc-snapshot crea, lista y restaura instantáneas de contenedores.

Las instantáneas se almacenan como contenedores instantaneados bajo la ruta de configuración del contenedor. Por ejemplo, si la ruta de configuración del contenedor es /var/lib/lxc y el contenedor es c1, la primera instantánea se almacenará como el contenedor snap0 bajo la ruta /var/lib/lxc/c1/snaps. Si /var/lib/lxcsnaps, utilizado por LXC 1.0, ya existe, se seguirá utilizando.

OPCIONES

-c,--comment archivo-comentario
Asocia el comentario en archivo-comentario con la instantánea recién creada.
-d,--destroy nombre-instantanea
Destruye la instantánea nombrada. Si la instantánea nombrada es ALL, todas las instantáneas serán destruidas.
-L,--list
Lista las instantáneas existentes.
-C,--showcomments
Muestra los comentarios de las instantáneas en las listas de instantáneas.
-r,--restore nombre-instantanea
Restaura la instantánea nombrada, lo que significa que se crea un nuevo contenedor completo que es una copia de la instantánea.
-N, --newname
Al restaurar una instantánea, el último argumento opcional si no se proporciona explícitamente a través de --newname es el nombre que se usará para el contenedor restaurado. Si el nuevo nombre es idéntico al nombre original del contenedor, el contenedor original será destruido y el contenedor restaurado ocupará su lugar. Tenga en cuenta que la eliminación de la instantánea original no es posible en el caso de instantáneas basadas en overlayfs o zfs.

OPCIONES COMUNES

Estas opciones son comunes a la mayoría de los comandos de lxc.

-?, -h, --help
Imprime un mensaje de uso más largo de lo normal.
--usage
Muestra el mensaje de uso
-q, --quiet
silenciar
-P, --lxcpath=RUTA
Usa una ruta alternativa para el contenedor. La predeterminada es /var/lib/lxc.
-o, --logfile=ARCHIVO
Salida a un ARCHIVO de registro alternativo. La predeterminada es no registrar.
-l, --logpriority=NIVEL
Establece la prioridad del registro a NIVEL. La prioridad de registro predeterminada es ERROR. Los valores posibles son: FATAL, ALERT, CRIT, WARN, ERROR, NOTICE, INFO, DEBUG, TRACE.

Tenga en cuenta que esta opción establece la prioridad de los eventos registrados en el archivo de registro alternativo. No tiene efecto en los eventos ERROR registrados en stderr.

-n, --name=NOMBRE
Usa el identificador de contenedor NOMBRE. El formato del identificador de contenedor es una cadena alfanumérica.
--rcfile=ARCHIVO
Especifica el archivo de configuración para configurar las funcionalidades de virtualización y aislamiento para el contenedor.

Este archivo de configuración, si está presente, se usará incluso si ya existe un archivo de configuración en el contenedor creado previamente (a través de lxc-create).

--version
Muestra el número de versión.
