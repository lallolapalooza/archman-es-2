NOMBRE

lxqt-config-session - Configuración de aplicaciones de LXQt: El Entorno de Escritorio Ligero de Qt

SINOPSIS

lxqt-config-session

DESCRIPCIÓN

Esta aplicación maneja la selección del gestor de ventanas de LXQt en X11, el inicio automático de módulos y otras aplicaciones de LXQt, la configuración del escalado de Qt, la confirmación para la salida de sesión, el bloqueo de pantalla, además de las rutas de directorios de usuario XDG y la configuración avanzada del entorno.

Si el módulo lxqt-wayland-session está instalado, se habilitarán las configuraciones relacionadas con Wayland para seleccionar el compositor y el comando de bloqueo de pantalla.

REPORTAR ERRORES

Reportar errores a https://github.com/lxqt/lxqt-session/issues

VER TAMBIÉN
