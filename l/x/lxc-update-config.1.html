NOMBRE

lxc-update-config - actualizar un archivo de configuración heredado anterior a LXC 2.1

SINOPSIS


lxc-update-config
{-c config}

DESCRIPCIÓN

lxc-update-config detecta cualquier clave de configuración heredada en el archivo config proporcionado y las reemplazará con las nuevas claves de configuración apropiadas.

lxc-update-config primero creará una copia de seguridad del archivo config antiguo en el mismo directorio y lo nombrará config.backup y luego actualizará el archivo config original en su lugar. En caso de que la actualización falle al aplicarse o genere un archivo config inválido que no pueda ser utilizado para iniciar un contenedor, los usuarios podrán comparar config con config.backup e intentar reparar manualmente cualquier clave de configuración inválida o simplemente revertir al archivo de configuración heredado copiando config.backup a config.

Cualquier fallo de lxc-update-config para generar un archivo config utilizable es un error y debe ser reportado al desarrollador principal.

OPCIONES

-c, --config
Ruta al archivo de configuración a actualizar.
-h, --help
