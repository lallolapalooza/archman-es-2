NOMBRE

lxc.conf - Archivos de configuración para LXC.

DESCRIPCIÓN

La configuración de LXC se divide en dos partes. Configuración del contenedor y configuración del sistema.

CONFIGURACIÓN DEL CONTENEDOR

La configuración del contenedor se mantiene en el archivo config almacenado en el directorio del contenedor.

Una configuración básica se genera en el momento de la creación del contenedor con los valores predeterminados recomendados para la plantilla elegida, así como claves predeterminadas adicionales provenientes del archivo default.conf.

Ese archivo default.conf se encuentra en /etc/lxc/default.conf o, para contenedores no privilegiados, en ~/.config/lxc/default.conf.

Los detalles sobre la sintaxis de este archivo se pueden encontrar en: lxc.container.conf(5)

CONFIGURACIÓN DEL SISTEMA

La configuración del sistema se encuentra en /etc/lxc/lxc.conf o en ~/.config/lxc/lxc.conf para contenedores no privilegiados.

Este archivo de configuración se utiliza para establecer valores como las rutas de búsqueda predeterminadas y la configuración del backend de almacenamiento para LXC.

Los detalles sobre la sintaxis de este archivo se pueden encontrar en: lxc.system.conf(5)

VER TAMBIÉN

lxc(1), lxc.container.conf(5), lxc.system.conf(5), lxc-usernet(5)
