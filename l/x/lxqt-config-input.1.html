LXQT-CONFIG-INPUT(1) Configuración de Entrada de LXQt LXQT-CONFIG-INPUT(1)

NOMBRE

lxqt-config-input - Aplicación de LXQt: The Lightweight Qt Desktop Environment

SINOPSIS

lxqt-config-input

DESCRIPCIÓN

Esta es una aplicación gráfica sencilla para la configuración del teclado, ratón y panel táctil. (Actualmente, solo puede ejecutarse bajo X11.)

OPCIONES

-s, --show-page <nombre> Elegir la página a mostrar.
--load-touchpad Cargar la última configuración del panel táctil.
-v, --version Muestra información de la versión.
-h, --help Muestra ayuda sobre las opciones de la línea de comandos.
--help-all Muestra la ayuda, incluidas las opciones genéricas de Qt

REPORTAR ERRORES

Reporta errores en https://github.com/lxqt/lxqt-config/issues

VER TAMBIÉN

LXQt ha sido adaptado para usuarios que valoran la simplicidad, la velocidad y una interfaz intuitiva, también destinado a máquinas menos potentes. Ver también:

lxqt-config(1) Centro de Configuración de LXQt
