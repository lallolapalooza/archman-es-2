lxqt-sudo(1) Módulo LXQt lxqt-sudo(1)

NOMBRE

lxqt-sudo, lxsu, lxdoas - ejecutar un comando como usuario privilegiado

SINOPSIS

lxqt-sudo opción [comando [argumentos]]
lxsu [opción] [comando [argumentos]]
lxsudo [opción] [comando [argumentos]]
lxdoas [opción] [comando [argumentos]]

DESCRIPCIÓN

lxqt-sudo (y los enlaces simbólicos lxsu, lxsudo, lxdoas) es una interfaz gráfica QT para el sudo(8), su(1) o doas(1) simple (para solicitar la contraseña opcionalmente en formato gráfico).
Cuando se invoca, simplemente crea un proceso hijo sudo, su o doas con el comando solicitado (y argumentos opcionales). Si sudo/su/doas solicita la contraseña del usuario, se muestra el cuadro de diálogo de contraseña gráfico y (después de enviarla) la contraseña se proporciona al backend.

OPCIONES

opción es una de las siguientes:
-h|--help Imprime la ayuda.
-v|--version Imprime información de la versión.
-q|--quiet Hace que lxqt-sudo sea menos verboso.
-s|--su Utiliza su como backend (el predeterminado para lxqt-sudo y lxsudo es sudo, para lxsu es su, para lxdoas es doas).
-d|--sudo Utiliza sudo como backend (el predeterminado para lxqt-sudo y lxsudo es sudo, para lxsu es su, para lxdoas es doas).
-a|--doas Utiliza doas como backend (el predeterminado para lxqt-sudo y lxsudo es sudo, para lxsu es su, para lxdoas es doas).

REPORTE DE ERRORES
