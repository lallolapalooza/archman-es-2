NOMBRE

lxqt-openssh-askpass - Módulo de acceso a contraseñas de ssh de LXQt: el entorno de escritorio Qt más rápido y ligero

SINOPSIS

lxqt-openssh-askpass [Actualmente no hay argumentos de línea de comandos]

DESCRIPCIÓN

Este módulo maneja el acceso a contraseñas de seguridad de openssh para LXQt. El módulo askpass de openssh realizará tareas de seguridad sobre privilegios de acceso escalados.

Los módulos LXQt son herramientas independientes del escritorio y funcionan como demonios para el usuario local en operaciones específicas del escritorio.

LXQt es un entorno de escritorio avanzado, fácil de usar y rápido basado en tecnologías Qt, que incluye varios componentes principales del escritorio, todos ellos opcionales:


* Panel
* Escritorio
* Lanzador de aplicaciones
* Centro de configuración
* Gestor de sesión
* Gestor Polkit
* Acceso a contraseñas SSH (este)
* Gestor del gestor de pantalla

Estos componentes realizan acciones similares a las disponibles en otros entornos de escritorio, y sus nombres son autoexplicativos. Por lo general, no se inician manualmente sino automáticamente, al elegir una sesión de LXQt en el Gestor de Pantalla.

COMPORTAMIENTO

El módulo detectado en el acceso a privilegios compartidos, y mantiene un diálogo de seguridad que solicita la clave del usuario necesaria para acceder a otra máquina host.

Este módulo se encuentra en una etapa muy temprana y no está habilitado por defecto, por lo que debes añadir una variable de entorno mediante la aplicación lxqt-settings como SSH_ASKPASS= con el valor lxqt-openssh-askpass, y se requieren los paquetes openssl y openssh-client.

INICIO AUTOMÁTICO

El módulo solo se muestra en el escritorio LXQt, pero puedes crear una acción de inicio automático para tu entorno de escritorio preferido.
