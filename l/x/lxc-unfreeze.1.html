NOMBRE

lxc-unfreeze - descongelar todos los procesos del contenedor

SINOPSIS


lxc-unfreeze
{-n nombre}

DESCRIPCIÓN

lxc-unfreeze descongelará todos los procesos previamente congelados por el comando lxc-freeze.

OPCIONES COMUNES

Estas opciones son comunes a la mayoría de los comandos de lxc.

-?, -h, --help
Imprimir un mensaje de uso más largo de lo normal.
--usage
Mostrar el mensaje de uso
-q, --quiet
silenciar activado
-P, --lxcpath=RUTA
Usar una ruta alternativa para los contenedores. La ruta predeterminada es /var/lib/lxc.
-o, --logfile=ARCHIVO
Salida a un ARCHIVO de registro alternativo. El registro predeterminado es ninguno.
-l, --logpriority=NIVEL
Establecer la prioridad del registro a NIVEL. El nivel de prioridad predeterminado es ERROR. Los valores posibles son: FATAL, ALERT, CRIT, WARN, ERROR, NOTICE, INFO, DEBUG, TRACE.

Tenga en cuenta que esta opción establece la prioridad de los eventos registrados en el archivo de registro alternativo. No tiene efecto en el registro de eventos ERROR en la salida de error estándar.

-n, --name=NOMBRE
Usar el identificador de contenedor NOMBRE. El formato del identificador de contenedor es una cadena alfanumérica.
--rcfile=ARCHIVO
Especificar el archivo de configuración para configurar las funcionalidades de virtualización y aislamiento para el contenedor.

Este archivo de configuración, si existe, se utilizará incluso si ya existe un archivo de configuración en el contenedor creado previamente (a través de lxc-create).

--version
Mostrar el número de versión.

DIAGNÓSTICO

El contenedor no se encontró
El contenedor especificado no se creó previamente con el comando lxc-create.
