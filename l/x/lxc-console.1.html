NOMBRE

lxc-console - Inicia una consola para el contenedor especificado

SINOPSIS


lxc-console
{-n nombre} [-e carácter de escape] [-t número de tty]

DESCRIPCIÓN

Si el servicio tty ha sido configurado y está disponible para el contenedor especificado como parámetro, este comando iniciará una consola que permitirá iniciar sesión en el contenedor.

Los tty disponibles son ranuras libres ocupadas por este comando. Esto significa que si el contenedor tiene cuatro ttys disponibles y el comando se ha ejecutado cuatro veces, cada uno ocupando un tty diferente, el quinto comando fallará porque no habrá ninguna consola disponible.

El comando se conectará a un tty. Si la conexión se pierde o se rompe, el comando se puede lanzar de nuevo y recuperar el tty en el estado en que estaba antes de la desconexión.

Se puede dar un número de tty de 0 para adjuntarse a la `/dev/console` del contenedor en lugar de su `dev/tty<número de tty>`.

Se puede usar una secuencia de escape de teclado para desconectarse del tty y salir de lxc-console. La secuencia de escape predeterminada es <Ctrl+a q>.

OPCIONES

-e, --escape carácter de escape
Especifica el prefijo de la secuencia de escape a usar en lugar de <Ctrl a>. Esto puede darse como '^letra' o simplemente 'letra'. Por ejemplo, para usar <Ctrl+b q> como secuencia de escape, usa -e '^b'.
-t, --tty número de tty
Especifica el número de tty al que conectarse o 0 para la consola. Si no se especifica, el contenedor elegirá automáticamente el siguiente número de tty disponible.

OPCIONES COMUNES

Estas opciones son comunes a la mayoría de los comandos de lxc.

-?, -h, --help
Imprime un mensaje de uso más largo de lo normal.
--usage
Muestra el mensaje de uso
-q, --quiet
silenciar
-P, --lxcpath=RUTA
Usa una ruta alternativa para el contenedor. La predeterminada es /var/lib/lxc.
-o, --logfile=ARCHIVO
Salida a un ARCHIVO de registro alternativo. El predeterminado es sin registro.
-l, --logpriority=NIVEL
Establece la prioridad del registro a NIVEL. La prioridad de registro predeterminada es ERROR. Los valores posibles son: FATAL, ALERT, CRIT, WARN, ERROR, NOTICE, INFO, DEBUG, TRACE.

Tenga en cuenta que esta opción establece la prioridad de los eventos de registro en el archivo de registro alternativo. No tiene efecto en el registro de eventos de ERROR en stderr.

-n, --name=NOMBRE
Usa el identificador de contenedor NOMBRE. El formato del identificador de contenedor es una cadena alfanumérica.
--rcfile=ARCHIVO
Especifica el archivo de configuración para configurar las funcionalidades de virtualización y aislamiento para el contenedor.

Este archivo de configuración, si está presente, se usará incluso si ya existe un archivo de configuración en el contenedor creado previamente (a través de lxc-create).

--version
Muestra el número de versión.

DIAGNÓSTICO

servicio tty denegado
No hay tty disponible o no hay suficiente privilegio para usar la consola. Por ejemplo, el contenedor pertenece al usuario "foo" y "bar" intenta abrir una consola para él.
