LXT2MINER(1) Minería de datos de archivos de volcado LXT2MINER(1)

NOMBRE

lxt2miner - Minería de datos de archivos LXT2

SINTAXIS

lxt2miner [opción]... [ARCHIVO_LXT2]

DESCRIPCIÓN

Extrae datos específicos de archivos LXT2 y genera archivos de guardado de gtkwave a la salida estándar para su recarga futura.

OPCIONES

-d,--dumpfile <nombre_archivo>
Especifica el archivo de volcado de entrada LXT2.
-m,--match <valor>
Especifica datos de coincidencia "bitwise" (binario, real, cadena)
-x,--hex <valor>
Especifica datos de coincidencia hexadecimales que se convertirán automáticamente a binarios para las búsquedas.
-n,--namesonly
Indica que solo se imprimirán los nombres de las facetas en un formato compatible con el archivo de guardado de gtkwave. Al hacer esto, el archivo puede usarse para especificar qué trazas importar a gtkwave.
-c,--comprehensive
Indica que los resultados no deben detenerse después de la primera coincidencia. Esto se puede usar para extraer todos los valores coincidentes en la traza.
-h,--help
Muestra la pantalla de ayuda.

EJEMPLOS

lxt2miner dumpfile.lxt2 --hex 20470000 -n

Esto intenta hacer coincidir el valor hexadecimal 20470000 en todas las facetas y, cuando se encuentra el valor, solo se imprime el nombre de la faceta a la salida estándar para generar un archivo de guardado compatible con gtkwave.

LIMITACIONES

lxt2miner solo imprime la primera vez que se encuentra un valor para una red específica. Esto se hace para reducir el tamaño de los archivos de salida y para ayudar a seguir datos como direcciones a través de un modelo de simulación.
