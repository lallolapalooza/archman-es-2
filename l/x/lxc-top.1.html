NOMBRE

lxc-top - monitorizar estadísticas de contenedores

SINOPSIS


lxc-top
[--help] [--delay retraso] [--sort ordenar_por] [--reverse]

DESCRIPCIÓN

lxc-top muestra estadísticas de contenedores. La salida se actualiza cada retraso segundos y se ordena según el valor ordenar_por proporcionado. lxc-top mostrará tantos contenedores como quepan en su terminal. Presione 'q' para salir. Presione una de las letras de la clave de ordenación para ordenar por esa estadística. Presionar la letra de la clave de ordenación una segunda vez invierte el orden de clasificación.

OPCIONES

-d, --delay retraso
Cantidad de tiempo en segundos para retrasar entre actualizaciones de pantalla. El valor predeterminado es 3 segundos.
-s, --sort ordenar_por
Ordenar los contenedores por nombre, uso de CPU o uso de memoria. El argumento ordenar_por debe ser una de las letras n,c,b,m,k para ordenar por nombre, uso de CPU, E/S de bloque, memoria o uso de memoria del kernel respectivamente. El valor predeterminado es 'n'.
-r, --reverse
Invertir el orden de clasificación predeterminado. Por defecto, los nombres se ordenan en orden alfabético ascendente y los valores se ordenan en cantidades descendentes (es decir, el valor más alto primero).

EJEMPLO

lxc-top --delay 1 --sort m
Mostrar contenedores, actualizando cada segundo, ordenados por uso de memoria.

NOTAS

Por razones de rendimiento, el kernel no contabiliza el uso de memoria del kernel a menos que se establezca un límite de memoria del kernel. Si no se establece un límite, lxc-top mostrará el uso de memoria del kernel como 0. Si no se están contabilizando contenedores, la columna KMem no se mostrará. Se puede establecer un límite especificando

      lxc.cgroup.memory.kmem.limit_in_bytes = número

en el archivo de configuración de su contenedor, consulte lxc.conf(5).
