lxsession-edit(1) Manual de comandos generales lxsession-edit(1)

NOMBRE

lxsession-edit - una GUI simple para editar sesiones de LXDE que sigue las especificaciones de autostart de FreeDesktop.Org

SINOPSIS

lxsession-edit [ DE ]

DESCRIPCIÓN

lxsession-edit es una aplicación para cambiar la lista de aplicaciones que se ejecutarán al inicio de la sesión. El nombre de la sesión puede obtenerse desde la línea de comandos, desde las variables de entorno XDG_CURRENT_DESKTOP o DESKTOP_SESSION, de lo contrario se asume "LXDE".

OPCIONES

DE
proporciona el nombre de la sesión de escritorio para editar la lista de autostart

ENTORNO

XDG_CURRENT_DESKTOP
variable predeterminada para obtener el nombre de la sesión
DESKTOP_SESSION
variable de respaldo para obtener el nombre de la sesión
