NOMBRE

lxc-monitor - monitorizar el estado del contenedor

SINOPSIS


lxc-monitor
[-n nombre] [-Q nombre]

DESCRIPCIÓN

lxc-monitor monitoriza el estado de los contenedores. El argumento nombre puede ser utilizado para especificar qué contenedores monitorizar. Es una expresión regular, conforme a posix2, por lo que es posible monitorizar todos los contenedores, varios de ellos o solo uno. Si no se especifica, nombre por defecto será '.*', lo que monitorizará todos los contenedores en lxcpath.

La opción -P, --lxcpath=RUTA puede especificarse varias veces para monitorizar más de una ruta de contenedor. Tenga en cuenta, sin embargo, que los contenedores con el mismo nombre en rutas múltiples serán indistinguibles en la salida.

OPCIONES

-Q, --quit
Solicita al demonio lxc-monitord en cada lxcpath dado que finalice. Después de recibir este comando, lxc-monitord saldrá inmediatamente tan pronto como no tenga clientes en lugar de esperar los 30 segundos normales para nuevos clientes. Esto es útil si necesita desmontar el sistema de archivos en el que se encuentra lxcpath.

OPCIONES COMUNES

Estas opciones son comunes a la mayoría de los comandos lxc.

-?, -h, --help
Imprime un mensaje de uso más largo de lo normal.
--usage
Muestra el mensaje de uso
-q, --quiet
silenciar
-P, --lxcpath=RUTA
Usa una ruta de contenedor alternativa. La ruta por defecto es /var/lib/lxc.
-o, --logfile=ARCHIVO
Salida a un ARCHIVO de registro alternativo. Por defecto no hay registro.
-l, --logpriority=NIVEL
Establece la prioridad del registro a NIVEL. La prioridad del registro por defecto es ERROR. Los valores posibles son: FATAL, ALERT, CRIT, WARN, ERROR, NOTICE, INFO, DEBUG, TRACE.

Tenga en cuenta que esta opción establece la prioridad del registro de eventos en el archivo de registro alternativo. No tiene efecto en el registro de eventos de ERROR en stderr.

-n, --name=NOMBRE
Usa el identificador de contenedor NOMBRE. El formato del identificador de contenedor es una cadena alfanumérica.
--rcfile=ARCHIVO
Especifica el archivo de configuración para configurar las funcionalidades de virtualización y aislamiento para el contenedor.

Este archivo de configuración, si está presente, se utilizará incluso si ya existe un archivo de configuración en el contenedor creado previamente (mediante lxc-create).

--version
Muestra el número de versión.

EJEMPLOS

lxc-monitor -n foo
monitorizará los diferentes estados para el contenedor foo.
lxc-monitor -n 'foo|bar'
monitorizará los diferentes estados para los contenedores foo y bar.
lxc-monitor -n '[fb].*'
monitorizará los diferentes estados para los contenedores cuyo nombre comience con la letra 'f' o 'b'.
lxc-monitor -n '.*'
monitorizará los diferentes estados para todos los contenedores.

DIAGNÓSTICO

El contenedor no fue encontrado
El contenedor especificado no fue creado previamente con el comando lxc-create.
