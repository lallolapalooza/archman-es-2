NOMBRE

lxc-user-nic - Gestionar NICs en otro espacio de nombres de red

SINOPSIS


lxc-user-nic
create {lxcpath} {nombre} {pid} {tipo} {bridge} {nombre_nic_contenedor}

lxc-user-nic
delete {lxcpath} {nombre} {ruta al espacio de nombres de red} {tipo} {bridge} {nombre_nic_contenedor}

DESCRIPCIÓN

lxc-user-nic es un programa setuid-root con el que los usuarios no privilegiados pueden gestionar interfaces de red para ser utilizadas por un contenedor lxc.

Consultará el archivo de configuración /etc/lxc/lxc-usernet para determinar el número de interfaces que el usuario que llama tiene permitido crear, y a qué puente pueden adjuntarlas. Rastrea el número de interfaces que cada usuario ha creado usando el archivo /run/lxc/nics. Asegura que el usuario que llama tenga privilegios sobre el espacio de nombres de red al que se adjuntará la interfaz. lxc-user-nic también permite eliminar dispositivos de red. Actualmente, solo se pueden eliminar puertos ovs.

OPCIONES

lxcpath
La ruta del contenedor. Actualmente no se utiliza.
nombre
El nombre del contenedor. Actualmente no se utiliza.
pid
El ID del proceso para la tarea a cuyo espacio de nombres de red se debe adjuntar la interfaz.
tipo
El tipo de interfaz de red a adjuntar. Actualmente solo se soporta veth. Con este tipo, se crean dos interfaces que representan cada extremo del túnel. Un extremo se adjuntará al puente especificado, mientras que el otro se pasará al contenedor.
bridge
El puente al que se adjuntará la interfaz de red, por ejemplo, lxcbr0.
nombre_nic_contenedor
El nombre de interfaz deseado en el contenedor. Será eth0 si no se especifica.
ruta al espacio de nombres de red
Una ruta para abrir y obtener un descriptor de archivo para el espacio de nombres de red de destino. Esto solo es relevante cuando se elimina un dispositivo veth.

VER TAMBIÉN

lxc(1), lxc-start(1), lxc-usernet(5)
