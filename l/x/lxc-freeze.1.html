NOMBRE

lxc-freeze - congela todos los procesos del contenedor

SINOPSIS


lxc-freeze
{-n nombre}

DESCRIPCIÓN

lxc-freeze congela todos los procesos que se ejecutan dentro del contenedor. Los procesos se bloquearán hasta que sean descongelados explícitamente por el comando lxc-unfreeze. Este comando es útil para los gestores de lotes para programar un grupo de procesos.

OPCIONES COMUNES

Estas opciones son comunes a la mayoría de los comandos lxc.

-?, -h, --help
Imprime un mensaje de uso más largo de lo normal.
--usage
Muestra el mensaje de uso
-q, --quiet
silenciar
-P, --lxcpath=RUTA
Utiliza una ruta de contenedor alternativa. La predeterminada es /var/lib/lxc.
-o, --logfile=ARCHIVO
Salida a un ARCHIVO de registro alternativo. La predeterminada es no registrar.
-l, --logpriority=NIVEL
Establece la prioridad del registro a NIVEL. La prioridad de registro predeterminada es ERROR. Los valores posibles son: FATAL, ALERT, CRIT, WARN, ERROR, NOTICE, INFO, DEBUG, TRACE.

Tenga en cuenta que esta opción establece la prioridad de los eventos registrados en el archivo de registro alternativo. No tiene efecto en los eventos ERROR registrados en stderr.

-n, --name=NOMBRE
Utiliza el identificador de contenedor NOMBRE. El formato del identificador de contenedor es una cadena alfanumérica.
--rcfile=ARCHIVO
Especifica el archivo de configuración para configurar las funcionalidades de virtualización y aislamiento para el contenedor.

Este archivo de configuración, si está presente, se utilizará incluso si ya existe un archivo de configuración en el contenedor creado previamente (a través de lxc-create).

--version
Muestra el número de versión.

DIAGNÓSTICO

El contenedor no se encontró
El contenedor especificado no fue creado previamente con el comando lxc-create.
