LXQT-CONFIG(1) Centro de Configuración de LXQt LXQT-CONFIG(1)

NOMBRE

lxqt-config - Centro de Configuración de LXQt para todos los módulos y aplicaciones relacionados

SINOPSIS

lxqt-config

DESCRIPCIÓN

Esta aplicación es un centro de configuración para todas las aplicaciones relacionadas con el entorno y todo el software de configuración instalado y registrado por el entorno de escritorio LXQt.

APLICACIONES DE CONFIGURACIÓN LXQt

LXQt tiene varias aplicaciones de configuración:


* Configuración de entrada: (lxqt-config-input)
* Configuración de brillo: (lxqt-config-brightness)
* Configuración de apariencia: (lxqt-config-appearance)
* Configuración de sesión: (lxqt-config-session)
* Configuración de notificaciones: (lxqt-config-notificationd)
* Configuración de monitor: (lxqt-config-monitor)
* Configuración de localización: (lxqt-config-locale)
* Configuración de administración de energía: (lxqt-config-powermanagement)
* Configuración de asociaciones de archivos: (lxqt-config-file-associations)
* Configuración de atajos globales: (lxqt-config-globalkeyshortcuts)
* Configuración del escritorio: (pcmanfm-qt --desktop-pref=general)

Adicionalmente, si están presentes, otras aplicaciones de configuración que no son de LXQt aparecerán en el Centro de Configuración bajo las categorías "Otras Configuraciones" y "Configuraciones del Sistema".

Estas aplicaciones también se pueden encontrar en el menú de Configuraciones o Preferencias; por favor, consulte las páginas de manual respectivas.

OPCIONES

-v, --version Muestra información de la versión.
-h, --help Muestra ayuda sobre las opciones de línea de comandos.
--help-all Muestra ayuda, incluyendo opciones genéricas de Qt.

REPORTE DE ERRORES

Reporte errores en https://github.com/lxqt/lxqt-config/issues

VER TAMBIÉN

LXQt ha sido adaptado para usuarios que valoran la simplicidad, la velocidad y una interfaz intuitiva. LXQt está también pensado para máquinas menos potentes. Ver:


* Configuración de entrada: lxqt-config-input(1)
* Configuración de apariencia: lxqt-config-appearance(1)
* Configuración de sesión: lxqt-config-session(1)
* Configuración de notificaciones: lxqt-config-notificationd(1)
