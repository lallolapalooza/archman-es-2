LEI-IMPORT(1) manual de usuario de public-inbox LEI-IMPORT(1)

NOMBRE

lei import - importación única de mensajes en el almacén local

SINOPSIS

lei import [OPCIONES] UBICACIÓN [UBICACIÓN...] [+L:ETIQUETA]

lei import [OPCIONES] (--stdin|-)

DESCRIPCIÓN

Importa mensajes al almacenamiento local de lei(1) (alias lei/store). "UBICACIÓN" es una fuente de mensajes: un directorio (Maildir), un archivo o una URL ("imap://", "imaps://", "nntp://" o "nntps://"). Las URL que requieren autenticación utilizan git-credential(1) para rellenar el nombre de usuario y la contraseña.

Para un archivo regular, la "UBICACIÓN" debe tener un prefijo "<formato>:" que especifique uno de los siguientes formatos: "mboxrd", "mboxcl2", "mboxcl" o "mboxo".

OPCIONES

-F FORMATO_MAIL
--in-format=FORMATO_MAIL
Formato de entrada de mensajes. A menos que los mensajes se proporcionen en la entrada estándar, se prefiere utilizar un prefijo de formato con "UBICACIÓN".
--stdin
Leer mensajes de la entrada estándar.
--lock
Método(s) de bloqueo de mbox(5) a utilizar: "dotlock", "fcntl", "flock" o "none".

Predeterminado: fcntl,dotlock

+L:ETIQUETA
Añade la "ETIQUETA" dada a todos los mensajes importados, donde "ETIQUETA" es un valor arbitrario definido por el usuario que consta de minúsculas y dígitos. Véase lei-tag(1) para más información sobre etiquetas.

Por ejemplo, especificar "+L:inbox" aplica la etiqueta "inbox" a todos los mensajes que se están importando.

Se puede especificar varias veces para aplicar varias etiquetas.

Predeterminado: none

+kw:PALABRA_CLAVE
Aplica "PALABRA_CLAVE" a todos los mensajes que se están importando, además de cualquier palabra clave por mensaje del almacén (a menos que se especifique "--no-kw"). Véase lei-tag(1) para más información sobre palabras clave.

Se puede especificar varias veces para aplicar varias palabras clave.

Predeterminado: none

--no-kw
No importar palabras clave de mensajes (o "flags" en terminología IMAP).
--no-incremental
Importar artículos IMAP y NNTP ya vistos.
--torsocks=auto|no|yes
--no-torsocks
Si se envuelven los comandos git(1) y curl(1) con torsocks(1).

Predeterminado: "auto"

--proxy=PROTOCOLO://HOST[:PUERTO]
Utilizar el proxy especificado (por ejemplo, "socks5h://0:9050").

Considere imap.proxy y nntp.proxy, que se pueden configurar de forma persistente por host en lei-config(1).

--noisy
Advertir sobre cabeceras de correo mal formadas. No es particularmente útil, pero era el valor predeterminado antes de public-inbox 2.0.0. Nuevo en public-inbox 2.0.0.

Consulte lei-config(1) para varias opciones "imap.*" y "nntp.*".
