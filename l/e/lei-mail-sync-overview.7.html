LEI-MAIL-SYNC-OVERVIEW(7) Manual de usuario de public-inbox LEI-MAIL-SYNC-OVERVIEW(7)

NOMBRE

lei - una visión general de la sincronización de correo de lei

DESCRIPCIÓN

lei(1) proporciona varios comandos de nivel de plomería para sincronizar correo y palabras clave (banderas) entre lei/store y almacenes IMAP y Maildir existentes. Nada de lo documentado en esta página del manual es necesario para el uso diario con externos.

La sincronización de correo y palabras clave es actualmente un proceso torpe. Se realizarán trabajos futuros para mejorarla y añadir soporte para IMAP IDLE.

FLUJO DE TRABAJO TÍPICO

# importar correo de la bandeja de entrada IMAP de un usuario y darle la etiqueta "inbox":
lei import +L:inbox imaps://user@example.com/INBOX
# volcar archivos etiquetados "inbox" de la última semana a un Maildir
lei q L:inbox rt:last.week.. -o /tmp/results
# Abrir /tmp/results en tu agente de correo favorito. Si inotify o kevent
# funciona, los cambios de palabras clave (por ejemplo, marcar mensajes como `vistos') se
# sincronizan automáticamente.
# Si la cola de inotify se desborda, o si lei-daemon falla,
# "lei index" informará a lei sobre los cambios de palabras clave:
lei index /tmp/results
# Opcional: limpiar entradas obsoletas de mail_sync.sqlite3
lei refresh-mail-sync /tmp/results
# para exportar cambios de palabras clave de vuelta a IMAP
lei export-kw imaps://user@example.com/INBOX
