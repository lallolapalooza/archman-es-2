LEI-BLOB(1) manual de usuario de public-inbox LEI-BLOB(1)

NOMBRE

lei blob - muestra un blob de git, reconstruyéndolo desde el correo si es necesario

SINOPSIS

lei blob [OPCIONES] OID

DESCRIPCIÓN

Muestra un blob de git. El blob puede corresponder a un mensaje de la tienda local, cualquier externo local o blobs asociados con un repositorio git de proyecto (si se ejecuta desde un directorio (de trabajo) de git). Para blobs que no existen, intentará recrear el blob usando correos de parche.

OPCIONES

--git-dir=DIR
Especifica un directorio .git/ adicional para escanear. Esta opción puede darse varias veces.

Por defecto: la salida de "git rev-parse --git-dir"

--no-cwd
No buscar en el repositorio git del directorio de trabajo actual.
--no-mail
No buscar en el almacenamiento de correo para "OID". Esto está implícito por "--oid-a", "--path-a" y "--path-b".
-A OID-A
--oid-a=OID-A
Proporciona el ID del objeto pre-imagen como una pista para reconstruir "OID".
-a PATH-A
--path-a=PATH-A
Proporciona la ruta del archivo de pre-imagen como una pista para reconstruir "OID".
-b PATH-B
--path-b=PATH-B
Proporciona la ruta del archivo de post-imagen como una pista para reconstruir "OID".
-v
--verbose
Proporciona más retroalimentación en stderr.

Las siguientes opciones también son compatibles y se describen en lei-q(1).

--remote
Los externos remotos solo se consultan cuando el blob necesita ser reconstruido a partir de correos de parche.
--no-local
--no-external
-I LOCATION, --include=LOCATION
--exclude=LOCATION
--only=LOCATION
--no-import-remote
--torsocks=auto|no|yes
--no-torsocks
--proxy=PROTOCOL://HOST[:PORT]
