less(3perl) Guía de referencia para programadores de Perl less(3perl)

NOMBRE

less - pragma de Perl para solicitar menos de algo

SINOPSIS

use less 'CPU';

DESCRIPCIÓN

Este es un pragma de usuario. Si tienes mucha suerte, algún código que estés utilizando sabrá que pediste menos uso de CPU o memoria o espacio en disco o... simplemente no podemos saberlo. Consulta la documentación de todo lo que estés usando actualmente.

Para sugerencias generales, intenta solicitar "CPU" o "memory".

use less 'memory';
use less 'CPU';
use less 'fat';

Si no pides nada en particular, estarás pidiendo menos 'please' (por favor).

use less 'please';

PARA AUTORES DE MÓDULOS

El módulo "less" ha estado en el núcleo como un módulo "de broma" durante mucho tiempo y no ha tenido ninguna forma real de comunicar información a nada. Gracias a Nicholas Clark, tenemos pragmas de usuario (ver perlpragma) y ahora "less" puede hacer algo.

Probablemente puedes esperar que tus usuarios adivinen que pueden solicitar menos CPU o memoria o simplemente "menos" en general.

Si el usuario no especificó nada, se interpreta como que usó la etiqueta "please". Depende de ti hacer que esto sea útil.

# equivalente
use less;
use less 'please';

"BOOLEAN = less->of( FEATURE )"

El método de clase "less->of( NAME )" devuelve un booleano para decirte si tu usuario solicitó menos de algo.

if ( less->of( 'CPU' ) ) {
    ...
}
elsif ( less->of( 'memory' ) ) {
}

"FEATURES = less->of()"

Si no pides ninguna característica, obtienes la lista de características que el usuario solicitó que sean amables. Esto tiene el agradable efecto secundario de que si no respetas nada en particular, simplemente puedes pedirlo y usarlo como un booleano.

if ( less->of ) {
    ...
}
else {
    ...
}

ADVERTENCIAS

Probablemente esto no hace nada.
Esto solo funciona en la versión 5.10+
Al menos es compatible con versiones anteriores al no hacer mucho.
