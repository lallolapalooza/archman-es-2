LES(8) Comandos de Mantenimiento LES(8)

NOMBRE

les, bus - demonios de servicio de emulación LAN ATM

SINOPSIS

les [-d módulo] [-m módulo] [-f archivo_de_configuración]

bus [-d módulo] [-m módulo] [-f archivo_de_configuración]

DESCRIPCIÓN

El Servicio LE consta de tres componentes: Servidor de Configuración de Emulación LAN (lecs(8)), Servidor de Emulación LAN (les) y Servidor de Difusión y Desconocidos (bus).

Les realiza la función de coordinación de control para la LAN emulada. Los clientes LE registran las direcciones MAC y/o los descriptores de ruta que representan en les, y más tarde le consultan cuando desean resolver direcciones MAC/descriptores de ruta en direcciones ATM. Otros mensajes de control LE que deben distribuirse a todos los clientes en ELAN también se envían a les. Les reenvía estos mensajes utilizando el VCC de Distribución de Control que ha establecido con cada cliente en ELAN.

Bus maneja los datos enviados por los clientes a direcciones MAC de difusión y multidifusión, y algunos de los datos dirigidos a direcciones unicast. El Cliente LE tiene la posibilidad de enviar datos dirigidos a una dirección unicast a bus antes de que se haya resuelto la dirección ATM del destino y se haya establecido el VCC de Datos Directos.

Ejemplo de archivo de configuración para les y bus:


[main]
memdebug=True
debug=True
[load]
#memdebug=True
#debug=True
[conn]
debug=True
#S1, dirección ATM del Servidor LE
#S1=:47:00:23:00:00:00:03:00:00:01:00:02:01:00:20:ea:00:05:aa:00
S1=:47:00:23:00:00:00:03:03:00:01:00:02:01:00:20:ea:00:0a:e9:01
#S2, Tipo de LAN
S2="802.3"
#S3, Tamaño máximo de trama
S3=1516
#S4, Tiempo de espera de unión, s
S4=15
#S5, Antigüedad máxima de trama, s
S5=6
#S6, Dirección ATM de BUS
S6=:47:00:23:00:00:00:03:03:00:01:00:02:01:00:20:ea:00:0a:e9:02 #viulu
#S6=0,0,170
#ELANNAME="asdf"
El archivo de configuración contiene el nombre de cada módulo entre corchetes, seguido de definiciones de variables para ese módulo. Las definiciones son del tipo variable=valor, donde el valor puede ser un entero, un valor booleano (True/False), una cadena entre comillas dobles ("cadena") o una dirección ATM en formato hexadecimal. Las variables que se pueden configurar son los mensajes de depuración/depuración de memoria para cada módulo y las variables S1-S6 según se definen en la especificación LE. 
S1=Dirección del Servidor LE. Esta dirección se utiliza en la señalización ATM.
S2=Tipo de LAN emulada. Los valores válidos son "802.3".
S3=Tamaño máximo de trama. El valor válido es 1516.
S4=Tiempo de espera de unión. Tiempo en segundos que el Servidor LE espera
   la SOLICITUD DE UNIÓN LE antes de cerrar una conexión.
S5=Antigüedad máxima de trama. Actualmente no se utiliza.
S6=Dirección del BUS. Esta dirección se utiliza en la señalización ATM.
ELANNAME= Nombre de la LAN emulada

SIGHUP provoca el reinicio del servidor. Se liberan todos los recursos y se inicia el servidor. SIGUSR1 provoca que el servidor vuelque su estado interno. SIGUSR2 apaga el servidor (con suerte) de forma elegante.

OPCIONES

-d módulo
Activa los mensajes de depuración para un módulo. "All" activa la depuración para todos los módulos.
-m módulo
Activa los mensajes de depuración de memoria para un módulo. "All" activa la depuración para todos los módulos.
-f archivo_de_configuración
Utiliza el archivo de configuración especificado en lugar de .lanevars.

ARCHIVOS

.lanevars
archivo de configuración

ERRORES

Los servidores no establecen conexiones punto a multipunto con los clientes LE como indica la especificación, lo que significa que algunos clientes LE no funcionarán con estos servidores.

Solo admite ELANs de tipo IEEE 802.3 / Ethernet.
