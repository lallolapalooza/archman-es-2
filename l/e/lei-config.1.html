NOMBRE

lei-config - wrapper de git-config para el archivo de configuración de lei

SINOPSIS

lei config <nombre> [[<valor>] [<patrón-de-valor>]]

lei config -l | --list

lei config -e | --edit

DESCRIPCIÓN

Llama a git-config(1) con "$XDG_CONFIG_HOME/lei/config" como archivo de configuración. Todos los "OPCIONES" se pasan, pero aquellos que anulan el archivo de configuración no están permitidos.

Todas las opciones de "imap" y "nntp" se pueden especificar por host o (si se usa git 2.26+) con comodines:

[imap "imap://*.onion"]
        proxy = socks5h://127.0.0.1:9050
[nntp "nntp://example.com"]
        proxy = socks5h://127.0.0.1:1080

VARIABLES

external.*
Gestionado por lei-add-external(1) y lei-forget-external(1)
imap.proxy
nntp.proxy
La dirección proxy "socks5h://". Las versiones anteriores de SOCKS pueden ser compatibles si hay demanda del usuario.
imap.starttls
nntp.starttls
Habilita o deshabilita STARTTLS en hosts que no sean imaps:// y nntps://. Por defecto, STARTTLS está habilitado si está disponible, a menos que se conecte a un .onion de Tor o a localhost.
imap.compress
nntp.compress
Habilita la compresión a nivel de protocolo. Esto puede ser incompatible o estar roto con algunos servidores.

Nota: El soporte de compresión de Net::NNTP está pendiente: https://rt.cpan.org/Ticket/Display.html?id=129967

imap.debug
nntp.debug
Habilita la salida de depuración de las bibliotecas subyacentes de IMAP y NNTP, actualmente Mail::IMAPClient y Net::NNTP, respectivamente. Si imap.proxy o nntp.proxy apuntan a un proxy SOCKS, también se habilitará la salida de depuración para IO::Socket::Socks.

Desactivar imap.compress puede ser necesario para la legibilidad.

imap.timeout
nntp.timeout
El tiempo de espera de lectura para las respuestas.

Por defecto: 600 segundos (IMAP); 120 segundos (NNTP)

imap.fetchBatchSize
Número de mensajes completos a descargar a la vez. Valores más grandes reducen los viajes de ida y vuelta de red a costa de un mayor uso de memoria, especialmente al recuperar mensajes grandes.

Las respuestas pequeñas para las banderas IMAP se descargan con 10000 veces este valor.

Por defecto: 1

color.SLOT
Las ranuras de color "quoted", "hdrdefault", "status", "attachment" son compatibles con los formatos de salida "-f text" y "-f reply" de lei-lcat(1) y lei-q(1).

También se analizarán los archivos .git/config por proyecto y los archivos globales ~/.gitconfig para la coloración de diferencias. Las ranuras de color de diff de git ("color.diff.SLOT") soportadas son "new", "old", "meta", "frag", "func" y "context".

OPCIONES

La mayoría de los interruptores de línea de comandos de git-config(1) son aceptados por "lei config" tal cual. Las opciones que se usan con más frecuencia se espera que sean:

-e
--edit
Abre un editor para editar el archivo de configuración de lei.
-l
--list
Lista todas las variables establecidas en el archivo de configuración, junto con sus valores.
