LEIN(1) Manual de Comandos Generales LEIN(1)

NOMBRE

lein - Automatiza proyectos Clojure

SINOPSIS

lein [-o] [-U] [TAREA [ARGUMENTOS]]
lein [-h|--help]
lein [-v|--version]

DESCRIPCIÓN

Leiningen sirve para automatizar proyectos Clojure sin que se te prenda fuego el pelo.

Trabajar en proyectos Clojure con herramientas diseñadas para Java puede ser un ejercicio de frustración. Con Leiningen, solo escribes Clojure.

TAREAS

lein help mostrará la lista completa de tareas, mientras que lein help TAREA muestra el uso para una específica.

lein help tutorial tiene un recorrido detallado de las diversas tareas, pero las más comúnmente utilizadas son:

lein new NOMBRE
genera un nuevo esqueleto de proyecto
lein test [PRUEBAS]
ejecuta las pruebas en los espacios de nombres PRUEBAS, o todas las pruebas
lein repl
lanza una sesión interactiva de REPL en un servidor REPL en red
lein uberjar
empaqueta el proyecto y sus dependencias como un archivo .jar independiente
lein install
instala un proyecto en tu repositorio local
lein deploy [REPOSITORIO]
despliega una biblioteca en un repositorio remoto
Otras tareas disponibles incluyen:
lein change
Reescribe project.clj aplicando una función.
lein check
Verifica la sintaxis y advierte sobre reflexiones.
lein classpath
Imprime la ruta de clases del proyecto actual.
lein clean
Elimina todos los archivos del directorio target-path del proyecto.
lein compile
Compila código fuente Clojure en archivos .class.
lein deps
Descarga todas las dependencias.
lein do [TAREA], ...
Tarea de orden superior para realizar otras tareas en sucesión.
lein jar
Empaqueta todos los archivos del proyecto en un archivo jar.
lein javac
Compila archivos fuente Java.
lein pom
Escribe un archivo pom.xml en disco para interoperabilidad con Maven.
lein release
Ejecuta :release-tasks.
lein retest
Ejecuta solo los espacios de nombres de prueba que fallaron la última vez.
lein run
Ejecuta una función -main con argumentos opcionales de línea de comandos.
lein search
Busca en repositorios remotos de Maven los jars coincidentes.
lein show-profiles
Lista todos los perfiles disponibles o muestra uno si se le proporciona un argumento.
lein trampoline [TAREA]
Ejecuta una tarea sin anidar la JVM del proyecto dentro de la de Leiningen.
lein update-in
Realiza transformaciones arbitrarias en tu mapa de proyecto.
lein vcs
Interactúa con el sistema de control de versiones.
lein version
Imprime la versión de Leiningen y la JVM actual.
lein with-profile [PERFIL] [TAREA]
Aplica la tarea dada con el(los) perfil(es) especificado(s).

OPCIONES

-o
Ejecuta una tarea sin conexión.
-U
Ejecuta una tarea forzando la actualización de snapshots.
-h, --help
Imprime esta ayuda o la ayuda para una tarea específica.
-v, --version
Imprime la versión de Leiningen.

CONFIGURACIÓN

Leiningen lee su configuración desde el archivo project.clj en la raíz de tu proyecto. Utiliza lein new para crear un proyecto nuevo desde el cual trabajar, o consulta la lista exhaustiva de opciones de configuración con lein help sample.

Puedes personalizar tu mapa de proyecto aún más con perfiles; consulta lein help profiles.

ERRORES

Consulta https://codeberg.org/leiningen/leiningen/issues para ver si tu problema es un error conocido. Si no lo es, por favor, abre un nuevo incidente en ese sitio. Por favor, incluye la salida de lein version así como tu archivo project.clj y la mayor cantidad de código relevante de tu proyecto que sea posible.
