NOMBRE

lei-ls-mail-source - listar carpetas de origen de correo IMAP o NNTP

SINOPSIS

lei ls-mail-source [OPCIONES] URL

DESCRIPCIÓN

Lista información sobre el origen de correo IMAP o NNTP en "URL". Este comando rellena la caché utilizada para la autocompletación del shell Bash y es útil para escribir invocaciones de lei-import(1).

OPCIONES

-z
-0
Usar "\0" (NUL) en lugar de salto de línea (CR) para delimitar líneas.
-l
Formatear la salida como JSON e incluir más información.
--pretty
Formatear la salida JSON de forma legible. Si stdout está abierto a un tty, "--pretty" está habilitado por defecto.
--ascii
Escapar caracteres no ASCII.
--url
Mostrar la URL completa del grupo de noticias o carpeta IMAP.
