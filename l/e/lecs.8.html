LECS(8) Comandos de mantenimiento LECS(8)

NOMBRE

lecs, bus - demonios del servicio de emulación de red LAN (LAN Emulation)

SINOPSIS

lecs [-l direccion_escucha] [-f archivo_configuracion] [-d ]

DESCRIPCIÓN

El Servicio de LAN Emulation (LE Service) consta de tres componentes: el Servidor de Configuración de LAN Emulation (lecs), el Servidor de LAN Emulation ( les(8)) y el Servidor de Difusión y Desconocidos ( bus(8)).

Lecs implementa la distribución de LECs (LAN Emulation Clients) a diferentes LANs emuladas. Esto se hace proporcionando diferentes direcciones ATM del Servidor de LAN Emulation a los LECs. La distribución se basa en la base de datos de configuración de lecs y la información proporcionada por el cliente LE. No es necesario que exista un lecs para todas las LANs emuladas. Es posible omitir esta fase de configuración indicando directamente la dirección ATM del les(8) al LEC.

Ejemplo de archivo de configuración para lecs: 

# Nuestra dirección ATM (debe incluirse para diferenciarnos de 
# por ejemplo, LEC)
# Debe estar antes de las definiciones ELAN
470023000000030300010002010020ea000ae905
# El nombre de la ELAN está entre corchetes.
# Los parámetros siguientes son para LE de tipo Ethernet (Linux y casi todos 
# los demás clientes LE)
[tut-lane1]
# Dirección del LES
LES:=470023000000030300010002010020ea000ae901
# 802_3 o 802_5 (802_3 = Ethernet)
Type:=802_3
# 1515, 4544, 9234 o 18190 (1516= Ethernet)
Max_Frame:=1516
# Dirección ATM para los hosts dirigidos a esta ELAN. 
# El comodín es x o X.
470023000000030300010002010020ea0005aax0
470023000000030000010002010020ea0005bx00
47.002300000003030001000201.00603E2FDX23.00
470023000000030300010002010020ea000Xxx00
DEFAULT
# Otra ELAN, que tiene un nombre vacío
[asdf]
# Esta directiva establece esta ELAN como la predeterminada, es decir, se 
# incluirá si la solicitud de configuración del LEC no coincide con 
# otras ELANs
#DEFAULT
LES= 470023000000030300010002010020ea000ae902
Type=Ethernet

Las reglas para encontrar definiciones de ELAN utilizando la información proporcionada en LE_CONFIGURE_REQUEST y el archivo de configuración son las siguientes:


1. Encuentra una entrada donde el NOMBRE_ELAN coincida exactamente y la 
   dirección ATM del LEC se encuentre en la definición de ELAN. 
   Estas deben coincidir exactamente con la información dada en 
   LE_CONFIGURE_REQUEST. Si se encuentra NOMBRE_ELAN, pero la dirección ATM 
   no coincide, rechaza con el motivo "Permiso denegado".
2. Busca la primera ELAN que coincida en tipo de LAN emulada, 
   tamaño máximo de trama y dirección ATM del LEC.
3. Si no se encontró una ELAN coincidente, devuelve las definiciones de ELAN 
   predeterminadas.
4. No hay coincidencia, por lo que la solicitud es rechazada con el motivo 
   "Sin configuración".
SIGHUP reinicia el servidor.

OPCIONES

-d
Lee el archivo de configuración, muestra su contenido y sale.
-l direccion_escucha
Utiliza la direccion_escucha para esperar conexiones.
-f archivo_configuracion
Utiliza el archivo de configuración especificado en lugar de .lecs_conf.

ARCHIVOS

.lecs_conf
archivo de configuración
