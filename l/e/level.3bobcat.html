FBB::level(3bobcat) Manipulador de logs FBB::level(3bobcat)

NOMBRE

FBB::level - Manipulador que establece el nivel de log de los objetos FBB::Log

SINOPSIS

#include <bobcat/level>
Opción de enlace: -lbobcat

DESCRIPCIÓN

Un objeto FBB::level se utiliza para especificar las `fuerzas' de inserción de información que se inserta en los objetos FBB::Log. Al insertarse en objetos Log, define la `fuerza' de las inserciones subsiguientes (o llamadas write) en esos objetos Log.

Por el contrario, los objetos Log pueden especificar `resistencias' de inserción a través de sus miembros setLevel. Si la `fuerza' del level es igual o superior a la `resistencia' del objeto Log, se realiza la inserción; de lo contrario, la inserción se ignora. Una única sentencia de inserción puede contener múltiples llamadas a level. Si es así, cada llamada a level actualiza la `fuerza' de las inserciones que siguen a la llamada a level.

Por defecto, las inserciones en objetos Log no precedidas por inserciones de level se completan.

Cuando un objeto level se inserta en otro tipo de objeto std::ostream, el objeto level no realiza ninguna acción.

CONSTRUCTORES

o
level(size_t force):
Este constructor se utiliza en sentencias de inserción, normalmente insertándolo como un objeto anónimo en un objeto FBB::Log.

Los constructores y operadores de asignación de copia y movimiento (y operadores de asignación) están disponibles.

OPERADOR SOBRECARGADO

o
std::ostream &::operator<<(std::ostream &ostr, FBB::level const &force):
Si ostr puede ser convertido a un objeto FBB::Log, entonces las inserciones subsiguientes se realizan si force supera el miembro setLevel del objeto Log especificado como su `resistencia'. Si ostr en realidad no se refiere a un objeto Log, entonces ostr se devuelve sin ninguna acción adicional, y ostr maneja las inserciones subsiguientes de su manera predeterminada.

EJEMPLO

#include <iostream>
#include <iomanip>
//#include <bobcat/log>
#include "../log"
#include <bobcat/level>
using namespace std;
using namespace FBB;
int main()
{
//    Log &log = Log::initialize("&1"); // usa el objeto Log estático
    Log log;                        // definiendo explícitamente un objeto Log
//    log.open("/tmp/out");           // o de una vez: Log log{ "/tmp/out" }
    log << "Este mensaje se escribe en cout" << nl <<
           setw(16) << ’ ’ << "ocupando múltiples líneas\n";
    log.off();
    log << "Este mensaje no se muestra\n";
    log << "Este mensaje no se muestra\n";
    log << fnl;
    log << "Este mensaje no se muestra\n";
    log.on(2);
    log << "Este mensaje se muestra\n";
    log << level(0) << "no se muestra" << level(2) << "se muestra en el nivel 2\n";
    log << level(3) << "en el nivel(3)" << level(1) << "no se muestra" << fnl;
    log << "nueva línea separada\n";
    log << level(2) << "de nuevo en servicio\n";
    log << "línea final\n";
    log.str("ab");
    log(’a’) << "¡hola a!" << endl;
    log(’b’) << "¡hola b!" << nl <<
                setw(16) << ’ ’ << "hasta ahora, todo bien" << endl;
    log << "no se muestra" << endl;
    log(’c’) << "no se muestra\n";
    log << "no se muestra\n";
    log.setLevel(2);
    log << level(2) << "de nuevo en servicio\n";
}
