NOMBRE

lftpget - obtener un archivo con lftp(1)

SINOPSIS

lftpget [-c] [-d] [-v] URL [URL...]

DESCRIPCIÓN

Esta página del manual documenta brevemente el comando lftpget.

lftpget es un script de shell para descargar por URL, llama a `lftp -c'. Soporta el mismo conjunto de protocolos que lftp, incluyendo ftp, http, fish, sftp.

OPCIONES

-c
Continuar una descarga anterior.
-d
Salida de depuración.
-v
Mensajes detallados.

VER TAMBIÉN

lftp(1), wget(1).
