NOMBRE

lftp.conf - el archivo de configuración global para lftp

DESCRIPCIÓN

el archivo de configuración /etc/lftp.conf cambia el comportamiento predeterminado de lftp y afecta la configuración de todos los usuarios. Las opciones específicas del usuario deben establecerse en el archivo ~/.lftprc o ~/.lftp/rc. Estos archivos de configuración se leen cuando lftp se inicia y los parámetros definidos en ellos entran en vigor en ese momento.

Además de las opciones de configuración de lftp, se pueden definir alias y comandos 'set' en cualquiera de estos archivos de configuración. Consulte las secciones de Comandos y Configuraciones de la página del manual de lftp para obtener más detalles.
