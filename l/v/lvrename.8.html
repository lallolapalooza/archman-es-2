LVRENAME(8) Manual del Administrador del Sistema LVRENAME(8)

NOMBRE

lvrename — Renombrar un volumen lógico

SINOPSIS

lvrename argumentos_posicionales
[ argumentos_opcionales ]

DESCRIPCIÓN

lvrename renombra un LV existente o un LV histórico (ver lvremove para información sobre LV históricos).

USO

lvrename VG LV LV_nuevo

[ OPCIONES_COMUNES ]

—

lvrename LV LV_nuevo

[ OPCIONES_COMUNES ]

—

Opciones comunes para el comando:

[ -A|--autobackup y|n ]
[ --noudevsync ]
[ --reportformat basic|json|json_std ]

[ -h|--help ]

OPCIONES

-A|--autobackup y|n
Especifica si las metadatos deben ser respaldadas automáticamente después de un cambio. ¡Se recomienda encarecidamente habilitar esto! Consulte vgcfgbackup(8) para más información.
--commandprofile String
El perfil de comando a utilizar para la configuración del comando. Consulte lvm.conf(5) para más información sobre perfiles.
--config String
Configuraciones para el comando. Estas anulan los ajustes de lvm.conf(5). El argumento String utiliza el mismo formato que lvm.conf(5), o puede usar la sintaxis de sección/campo. Consulte lvm.conf(5) para más información sobre la configuración.
-d|--debug ...
Establece el nivel de depuración. Repita de 1 a 6 veces para aumentar el detalle de los mensajes enviados al archivo de registro y/o a syslog (si está configurado).
--devices PV
Restringe los dispositivos que son visibles y accesibles para el comando. Los dispositivos no listados parecerán faltar. Esta opción se puede repetir, o acepta una lista de dispositivos separada por comas. Esto anula el archivo de dispositivos.
--devicesfile String
Un archivo que lista los dispositivos que LVM debe usar. El archivo debe existir en /etc/lvm/devices/ y se gestiona con el comando lvmdevices(8). Esto anula la configuración devices/devicesfile y devices/use_devicesfile de lvm.conf(5).
--driverloaded y|n
Si se establece en no, el comando no intentará usar el mapeador de dispositivos. Para pruebas y depuración.
-h|--help
Muestra el texto de ayuda.
--journal String
Registra información en el registro de systemd. Esta información es adicional a la información habilitada por la configuración de registro/journal de lvm.conf. comando: registra información sobre el comando. salida: registra la salida predeterminada del comando. depuración: registra la depuración completa del comando.
--lockopt String
Se utiliza para pasar opciones para casos especiales a lvmlockd. Consulte lvmlockd(8) para más información.
--longhelp
Muestra el texto de ayuda extendido.
--nohints
No usar el archivo de sugerencias para localizar dispositivos para PVs. Un comando puede leer más dispositivos para encontrar PVs cuando no se usan sugerencias. El comando seguirá realizando la invalidación estándar del archivo de sugerencias cuando sea apropiado.
--nolocking
Deshabilita el bloqueo. Úselo con precaución, los comandos concurrentes pueden producir resultados incorrectos.
--noudevsync
Deshabilita la sincronización de udev. El proceso no esperará la notificación de udev. Continuará independientemente de cualquier posible procesamiento de udev en segundo plano. Solo use esto si udev no se está ejecutando o tiene reglas que ignoran los dispositivos que crea LVM.
--profile String
Un alias para --commandprofile o --metadataprofile, dependiendo del comando.
-q|--quiet ...
Suprime la salida y los mensajes de registro. Anula --debug y --verbose. Repita una vez para suprimir también cualquier pregunta con la respuesta 'no'.
--reportformat basic|json|json_std
Anula el formato de salida actual para los informes, que se define globalmente mediante la configuración report/output_format en lvm.conf(5). basic es el formato original con columnas y filas. Si hay más de un informe por comando, cada informe se prefija con el nombre del informe para su identificación. json produce la salida del informe en formato JSON. json_std produce la salida del informe en formato JSON que es más compatible con el estándar JSON. Consulte lvmreport(7) para más información.
-t|--test
Ejecutar en modo de prueba. Los comandos no actualizarán los metadatos. Esto se implementa deshabilitando toda escritura de metadatos pero devolviendo éxito a la función llamante. Esto puede generar mensajes de error inusuales en operaciones de múltiples etapas si una herramienta depende de leer metadatos que cree que han cambiado pero no lo han hecho.
-v|--verbose ...
Establece el nivel de verbosidad. Repita de 1 a 4 veces para aumentar el detalle de los mensajes enviados a stdout y stderr.
--version
Muestra información de la versión.
-y|--yes
No preguntar por confirmación interactivamente, sino asumir siempre la respuesta sí. Usar con extrema precaución. (Para un no automático, ver -qq.)

VARIABLES

VG
Nombre del Grupo de Volúmenes. Consulte lvm(8) para nombres válidos.
LV
Nombre del Volumen Lógico. Consulte lvm(8) para nombres válidos. Un argumento posicional LV generalmente incluye el nombre del VG y el nombre del LV, por ejemplo, VG/LV.
String
Consulte la descripción de la opción para obtener información sobre el contenido del string.
Size[UNIT]
Size es un número de entrada que acepta una unidad opcional. Las unidades de entrada siempre se tratan como valores base dos, independientemente de las mayúsculas, por ejemplo, 'k' y 'K' se refieren a 1024. La unidad de entrada predeterminada se especifica con una letra, seguida de |UNIT. UNIT representa otras unidades de entrada posibles: b|B es bytes, s|S es sectores de 512 bytes, k|K es KiB, m|M es MiB, g|G es GiB, t|T es TiB, p|P es PiB, e|E es EiB. lvrename(8)

NAME

lvrename LVM

SYNOPSIS

lvrename [options] {OldLogicalVolumeName} {NewLogicalVolumeName}

lvrename [options] {VolumeGroupName} {OldLogicalVolumeName} {NewLogicalVolumeName}

DESCRIPTION

Allows you to rename an existing logical volume.

The logical volume can be specified by its name, or by its full path (e.g. "/dev/vg01/lv01").

The new name can be a simple name, or a path.

USAGE

This command supports the following generic options: -a, -A, -k, -p, -t, -v, -h, --version, --help.

OPTIONS

See lvm(8) for common options.

VARIABLES

LVM_VG_NAME
If this environment variable is set, it is used as the default VG name (see lvm(8)).

ENVIRONMENT VARIABLES

See lvm(8) for information about environment variables used by lvm. For example, LVM_VG_NAME can generally be substituted for a required VG parameter.

EXAMPLES

Rename "lvold" to "lvnew":
lvrename /dev/vg02/lvold vg02/lvnew

An alternate syntax to rename "lvold" to "lvnew":
lvrename vg02 lvold lvnew
