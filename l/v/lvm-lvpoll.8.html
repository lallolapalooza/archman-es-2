NOMBRE

lvm lvpoll — Continuar una operación de sondeo ya iniciada en un volumen lógico

SINOPSIS

lvm lvpoll argumentos_opcionales argumentos_posicionales
[ argumentos_opcionales ]

DESCRIPCIÓN

lvm lvpoll es un comando interno utilizado por lvmpolld(8) para monitorizar y completar operaciones de lvconvert(8) y pvmove(8). lvpoll en sí mismo no inicia estas operaciones y normalmente no necesita ser ejecutado directamente.

USO

lvm lvpoll --polloperation pvmove|convert|merge|merge_thin LV ...

[ -A|--autobackup y|n ]
[ -i|--interval Número ]
[ --abort ]
[ --handlemissingpvs ]
[ OPCIONES_COMUNES ]

-t|--test

-v|--verbose ...
Establecer nivel detallado. Repetir de 1 a 4 veces para aumentar el detalle de los mensajes enviados a stdout y stderr.

lvm-lvpoll(8) — LVM TOOLS

NAME

lvm-lvpoll — Allows polling of LVM operations.

SYNOPSIS

lvm lvpoll [-a | --all] [-H | --handlesnapshots] [-h | --help] [-v | --verbose] [-y | --yes] [--abort] [--abortall] [--handlesnapshots] [--handlemissingpvs] [--polloperation <operation>] [--polldevice <device>] [--polluuid <uuid>] [--pollvg <vg_name>] [--polllv <lv_name>] [--polllvpath <lv_path>] [--polloperationid <operation_id>] [--pollprocessid <process_id>] [--pollstate <state>] [--polltag <tag>] [--pollvgname <vg_name>] [--polllvname <lv_name>]

DESCRIPTION

lvm lvpoll is used to poll LVM operations. An operation is something that may take a long time to complete, such as a pvmove operation, a mirror conversion, or a snapshot merge. The operation can be started with the appropriate LVM command (e.g. pvmove, lvconvert, lvcreate) and then polled with lvm lvpoll.

The --polloperation option selects the type of operation to poll. Supported operations are:

pvmove
Poll a physical volume move operation.
convert
Poll a mirror conversion or snapshot creation.
merge
Poll a snapshot merge operation.
merge_thin
Poll a thin snapshot merge operation.
The target of the operation is specified using one of the --poll* options, or by specifying the LV name directly after the operation type.

The polling can be continued by running lvm lvpoll without any options. This will check all active operations.

The operation can be aborted using the --abort or --abortall options.

USAGE

Start an operation, e.g.:
pvmove /dev/sdb1

Poll the operation until it completes:

lvm lvpoll --polloperation pvmove vg01/lv01

Or, if the operation created a temporary LV:

pvmove --replace=vg01/lv01 /dev/sdc1

lvm lvpoll --polloperation pvmove vg01/pvmove-vg01-lv01

Abort the operation:

lvm lvpoll --polloperation pvmove vg01/pvmove-vg01-lv01 --abort

OPTIONS

See lvm(8) for common options.

The following options are specific to lvm lvpoll.

--abort
Abort the specified operation.
--abortall
Abort all active operations.
-a, --all
Poll all active operations. This is the default if no operation is specified.
-H, --handlesnapshots
Also poll snapshot operations. This is implied by --polloperation convert.
--handlemissingpvs
Continue polling even if some PVs are missing. This is useful for mirror repair operations where a disk may have failed.
--polloperation <operation>
Specify the type of operation to poll. See DESCRIPTION for supported operations.
--polldevice <device>
Poll operations on the specified device.
--polluuid <uuid>
Poll operations associated with the specified UUID.
--pollvg <vg_name>
Poll operations within the specified volume group.
--polllv <lv_name>
Poll operations on the specified logical volume.
--polllvpath <lv_path>
Poll operations on the logical volume at the specified path.
--polloperationid <operation_id>
Poll operations with the specified operation ID.
--pollprocessid <process_id>
Poll operations with the specified process ID.
--pollstate <state>
Poll operations in the specified state.
--polltag <tag>
Poll operations with the specified tag.
--pollvgname <vg_name>
Same as --pollvg.
--polllvname <lv_name>
Same as --polllv.

VARIABLES

The following LVM configuration parameters can be set with lvm.conf(5):

polling_interval
The interval in seconds between polls.
pvmove_polling_interval
The interval in seconds between polls for pvmove operations.
pvmove_ops_max
The maximum number of pvmove operations to poll.
vg_ops_max
The maximum number of VG operations to poll.

ENVIRONMENT VARIABLES

See lvm.conf(5) for environment variables, with the exception of the following.

NOTES

To find the name of the pvmove LV that was created by an original pvmove /dev/name command, use the command:
lvs -a -S move_pv=/dev/name.

EXAMPLES

Continue polling a pvmove operation.
lvm lvpoll --polloperation pvmove vg00/pvmove0

Abort a pvmove operation.
lvm lvpoll --polloperation pvmove --abort vg00/pvmove0

Continue polling a mirror conversion.
lvm lvpoll --polloperation convert vg00/lvmirror

Continue mirror repair.
lvm lvpoll --polloperation convert vg/damaged_mirror --handlemissingpvs

Continue snapshot merge.
lvm lvpoll --polloperation merge vg/snapshot_old

Continue thin snapshot merge.
lvm lvpoll --polloperation merge_thin vg/thin_snapshot
