NOMBRE

lvscan — Listar todos los volúmenes lógicos en todos los grupos de volúmenes

SINOPSIS

lvscan
[ argumentos_opciones ]

DESCRIPCIÓN

lvscan escanea todos los VG o todos los dispositivos de bloque LVM soportados en el sistema en busca de LVs. La salida consiste en una línea por cada LV indicando si está activo, si es una instantánea o un origen, el tamaño del dispositivo y su política de asignación. Utilice lvs(8) o lvdisplay(8) para obtener información más completa sobre los LVs.

USO

lvscan

[ -a|--all ]
[ --ignorelockingfailure ]
[ --readonly ]
[ --reportformat basic|json|json_std ]
[ OPCIONES_COMUNES ]

OPCIONES

-a|--all
Mostrar información sobre LVs internos. Estos son componentes de LVs normales, como espejos, que no son accesibles de forma independiente, por ejemplo, no montables.
--commandprofile Cadena
El perfil de comando a utilizar para la configuración del comando. Consulte lvm.conf(5) para más información sobre perfiles.
--config Cadena
Configuraciones para el comando. Estas anulan la configuración de lvm.conf(5). El argumento Cadena utiliza el mismo formato que lvm.conf(5), o puede utilizar la sintaxis de sección/campo. Consulte lvm.conf(5) para más información sobre la configuración.
-d|--debug ...
Establecer el nivel de depuración. Repetir de 1 a 6 veces para aumentar el detalle de los mensajes enviados al archivo de registro y/o syslog (si está configurado).
--devices PV
Restringe los dispositivos que son visibles y accesibles para el comando. Los dispositivos no listados aparecerán como ausentes. Esta opción puede repetirse o aceptar una lista de dispositivos separada por comas. Esto anula el archivo de dispositivos.
--devicesfile Cadena
Un archivo que lista los dispositivos que LVM debe utilizar. El archivo debe existir en /etc/lvm/devices/ y se gestiona con el comando lvmdevices(8). Esto anula la configuración devices/devicesfile y devices/use_devicesfile de lvm.conf(5).
--driverloaded y|n
Si se establece en no, el comando no intentará utilizar device-mapper. Para pruebas y depuración.
-h|--help
Mostrar texto de ayuda.
--ignorelockingfailure
Permite que un comando continúe con operaciones de metadatos de solo lectura después de fallos de bloqueo.
--journal Cadena
Registrar información en el registro de systemd. Esta información es adicional a la información habilitada por la configuración de registro/registro de lvm.conf. comando: registrar información sobre el comando. salida: registrar la salida predeterminada del comando. depurar: registrar la depuración completa del comando.
--lockopt Cadena
Se utiliza para pasar opciones para casos especiales a lvmlockd. Consulte lvmlockd(8) para más información.
--longhelp
Mostrar texto de ayuda largo.
--nohints
No utilizar el archivo de pistas para localizar dispositivos para PVs. Un comando puede leer más dispositivos para encontrar PVs cuando no se utilizan pistas. El comando seguirá realizando la invalidación estándar del archivo de pistas donde sea apropiado.
--nolocking
Deshabilitar el bloqueo. Usar con precaución, los comandos concurrentes pueden producir resultados incorrectos.
--profile Cadena
Un alias para --commandprofile o --metadataprofile, dependiendo del comando.
-q|--quiet ...
Suprimir la salida y los mensajes de registro. Anula --debug y --verbose. Repetir una vez para suprimir también cualquier pregunta con respuesta 'no'.
--readonly
Evitar que el comando realice cambios, incluyendo la activación y las actualizaciones de metadatos. (Ver --permission r para LVs de solo lectura.)
--reportformat basic|json|json_std
Anula el formato de salida actual para informes, que se define globalmente mediante la configuración report/output_format en lvm.conf(5). basic es el formato original con columnas y filas. Si hay más de un informe por comando, cada informe se precede con el nombre del informe para su identificación. json produce la salida del informe en formato JSON. json_std produce la salida del informe en formato JSON que es más compatible con el estándar JSON. Consulte lvmreport(7) para más información.
-t|--test
Ejecutar en modo de prueba. Los comandos no actualizarán los metadatos. Esto se implementa deshabilitando toda escritura de metadatos, pero devolviendo éxito a la función que llama. Esto puede llevar a mensajes de error inusuales en operaciones de múltiples etapas si una herramienta depende de leer metadatos que cree que han cambiado pero no lo han hecho.
-v|--verbose ...
Establecer el nivel de verbosidad. Repetir de 1 a 4 veces para aumentar el detalle de los mensajes enviados a stdout y stderr.
--version
Mostrar información de la versión.
-y|--yes
No solicitar confirmación interactivamente, sino asumir siempre la respuesta sí. Usar con extrema precaución. (Para un no automático, ver -qq.)

VARIABLES

Cadena
Consulte la descripción de la opción para obtener información sobre el contenido de la cadena.
Tamaño[UNIDAD]
Tamaño es un número de entrada que acepta una unidad opcional. Las unidades de entrada siempre se tratan como valores base dos, independientemente de la capitalización, por ejemplo, 'k' y 'K' se refieren a 1024. La unidad de entrada predeterminada se especifica con una letra, seguida de |UNIDAD. UNIDAD representa otras unidades de entrada posibles: b|B son bytes, s|S son sectores de 512 bytes, k|K son KiB, m|M son MiB, g|G son GiB, t|T son TiB, p|P son PiB, e|E son EiB. (Esto no debe confundirse con el control de salida --units, donde las letras mayúsculas significan múltiplos de 1000.)
