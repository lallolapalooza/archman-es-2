NOMBRE

lvmconfig — Mostrar y manipular información de configuración

SINOPSIS

lvmconfig
[ argumentos_opcionales ]
[ argumentos_posicionales ]

DESCRIPCIÓN

lvmconfig, lvm config, lvm dumpconfig (por razones de compatibilidad, se eliminará gradualmente) producen una salida formateada del árbol de configuración de LVM. Las fuentes de los datos de configuración incluyen lvm.conf(5) y la configuración de la línea de comandos de --config.

OPCIONES

--atversion Cadena
Especifica una versión de LVM en formato x.y.z, donde x es la versión principal, y es la versión secundaria y z es el nivel de parche (por ejemplo, 2.2.106). Al mostrar la configuración, solo se considerarán las configuraciones reconocidas por esta versión de LVM. Esto se puede usar para mostrar una configuración que una versión determinada de LVM entiende y que no contiene configuraciones más nuevas para las cuales LVM emitiría un mensaje de advertencia al verificar la configuración.
--commandprofile Cadena
El perfil de comando a utilizar para la configuración del comando. Consulte lvm.conf(5) para obtener más información sobre los perfiles.
--config Cadena
Configuraciones de comando para el comando. Estas anulan la configuración de lvm.conf(5). El argumento Cadena utiliza el mismo formato que lvm.conf(5), o puede usar la sintaxis de sección/campo. Consulte lvm.conf(5) para obtener más información sobre la configuración.
-d|--debug ...
Establece el nivel de depuración. Repetir de 1 a 6 veces para aumentar el detalle de los mensajes enviados al archivo de registro y/o syslog (si está configurado).
--devices PV
Restringe los dispositivos que son visibles y accesibles para el comando. Los dispositivos no listados parecerán faltar. Esta opción se puede repetir o aceptar una lista separada por comas de dispositivos. Esto anula el archivo de dispositivos.
--devicesfile Cadena
Un archivo que enumera los dispositivos que LVM debe usar. El archivo debe existir en /etc/lvm/devices/ y se gestiona con el comando lvmdevices(8). Esto anula la configuración de lvm.conf(5) devices/devicesfile y devices/use_devicesfile.
--driverloaded y|n
Si se establece en no, el comando no intentará usar device-mapper. Para pruebas y depuración.
-f|--file Cadena
Escribe la salida en el archivo con nombre.
-h|--help
Muestra el texto de ayuda.
--ignoreadvanced
Excluye las configuraciones avanzadas de la salida.
--ignorelocal
Ignora la sección local. La sección local debe definirse en el archivo lvmlocal.conf y debe contener configuraciones específicas del host local que no deben copiarse a otros hosts.
--ignoreunsupported
Excluye las configuraciones no admitidas de la salida. Estas configuraciones se utilizan solo para fines de depuración y desarrollo o su soporte aún no está completo y no están destinadas a ser utilizadas en producción. Los tipos current y diff incluyen configuraciones no admitidas en su salida por defecto, todos los demás tipos ignoran las configuraciones no admitidas.
--journal Cadena
Registra información en el registro del sistema systemd. Esta información es adicional a la información habilitada por la configuración log/journal de lvm.conf. command: registra información sobre el comando. output: registra la salida por defecto del comando. debug: registra la depuración completa del comando.
-l|--list
Imprime una lista de configuraciones en lugar de un árbol de configuraciones estructurado. Si se usa sin otras opciones, esto es lo mismo que --typeconfig list --withsummary.
--lockopt Cadena
Se utiliza para pasar opciones para casos especiales a lvmlockd. Consulte lvmlockd(8) para obtener más información.
--longhelp
Muestra el texto de ayuda largo.
--mergedconfig
Cuando el comando se ejecuta con --config y/o --commandprofile (o usando la variable de entorno LVM_COMMAND_PROFILE), --profile o --metadataprofile, fusiona todo el contenido de la "cascada de configuración" antes de mostrarlo. Sin fusionar, solo se muestra la configuración al principio de la cascada. Consulte lvm.conf(5) para obtener más información sobre la configuración.
--metadataprofile Cadena
El perfil de metadatos a utilizar para la configuración del comando. Consulte lvm.conf(5) para obtener más información sobre los perfiles.
--nohints
No utilice el archivo de sugerencias para localizar dispositivos para los PV. Un comando puede leer más dispositivos para encontrar PV cuando no se usan sugerencias. El comando seguirá realizando la invalidación estándar del archivo de sugerencias según corresponda.
--nolocking
Desactiva el bloqueo. Úselo con precaución, los comandos concurrentes pueden producir resultados incorrectos.
--profile Cadena
Un alias para --commandprofile o --metadataprofile, dependiendo del comando.
-q|--quiet ...
Suprime la salida y los mensajes de registro. Anula --debug y --verbose. Repita una vez para suprimir también cualquier aviso con respuesta 'no'.
--showdeprecated
Incluye configuraciones de configuración obsoletas en la salida. Estas configuraciones
están obsoletos después de una determinada versión. Si se especifica una versión concreta con --atversion, las configuraciones obsoletas se incluyen automáticamente si la versión especificada es anterior a la versión en la que las configuraciones fueron obsoletas. Los tipos current y diff incluyen las configuraciones obsoletas en su salida por defecto, todos los demás tipos ignoran las configuraciones obsoletas.
--showunsupported
Incluir configuraciones no soportadas en la salida. Estas configuraciones se utilizan solo para fines de depuración o desarrollo, o su soporte no está aún completo y no están destinadas a ser utilizadas en producción. Los tipos current y diff incluyen configuraciones no soportadas en su salida por defecto, todos los demás tipos ignoran las configuraciones no soportadas.
--sinceversion String
Especificar una versión de LVM en formato x.y.z donde x es la versión principal, y es la versión secundaria y z es el nivel de parche (ej. 2.2.106). Esta opción es aplicable actualmente solo con --typeconfig new para mostrar todas las configuraciones introducidas desde la versión dada.
-t|--test
Ejecutar en modo de prueba. Los comandos no actualizarán metadatos. Esto se implementa desactivando toda escritura de metadatos, pero devolviendo éxito a la función que llama. Esto puede llevar a mensajes de error inusuales en operaciones de varias etapas si una herramienta depende de leer metadatos que cree que han cambiado pero no lo han hecho.
--typeconfig current|default|diff|full|list|missing|new|profilable|profilable-command|profilable-metadata
current imprime las configuraciones que se aplicarían a un comando lvm (asumiendo que el comando no las anula en la línea de comandos). Esto incluye: configuraciones que han sido modificadas en los archivos de configuración de lvm, configuraciones que obtienen sus valores predeterminados de los archivos de configuración y configuraciones predeterminadas que no han sido comentadas en los archivos de configuración. default imprime todas las configuraciones con sus valores predeterminados. Los cambios realizados en los archivos de configuración de lvm no se reflejan en la salida. Algunas configuraciones obtienen sus valores predeterminados internamente y estas configuraciones se imprimen como comentarios. Otras configuraciones obtienen sus valores predeterminados de los archivos de configuración y estas configuraciones no se imprimen como comentarios. diff imprime solo las configuraciones que han sido modificadas respecto a sus valores predeterminados en los archivos de configuración (la diferencia entre current y default). full imprime cada configuración sin comentar y establecida al valor actual, es decir, cómo sería utilizada por un comando lvm. Esto incluye configuraciones modificadas en los archivos de configuración, configuraciones que normalmente obtienen valores predeterminados internamente y configuraciones que obtienen valores predeterminados de los archivos de configuración. list imprime todos los nombres de configuración sin valores. missing imprime configuraciones que faltan en los archivos de configuración de lvm. Una configuración faltante que normalmente obtiene su valor predeterminado de los archivos de configuración se imprime sin comentar y establecida al valor predeterminado interno. Las configuraciones que obtienen su valor predeterminado internamente y no están establecidas en los archivos de configuración se imprimen comentadas con el valor predeterminado interno. new imprime las configuraciones que se han añadido desde la versión de lvm especificada por --sinceversion. Se imprimen con sus valores predeterminados. profilable imprime configuraciones con sus valores predeterminados que se pueden establecer desde un perfil. profilable-command imprime configuraciones con sus valores predeterminados que se pueden establecer desde un perfil de comando. profilable-metadata imprime configuraciones con sus valores predeterminados que se pueden establecer desde un perfil de metadatos. También ver lvm.conf(5).
--unconfigured
Opción interna utilizada para generar el archivo de configuración durante la compilación.
--validate
Validar la configuración actual utilizada y salir con el código de retorno apropiado. La validación se realiza solo para la configuración en la parte frontal de la "cascada de configuración". Para validar todo el árbol de configuración fusionado, también se debe usar --mergedconfig. La validación se realiza incluso si lvm.conf(5) config/checks está deshabilitado.
--valuesonly
Al imprimir configuraciones, imprimir solo los valores sin las claves.
-v|--verbose ...
Establecer el nivel de verbosidad. Repetir de 1 a 4 veces para aumentar el detalle de los mensajes enviados a stdout y stderr.
--version
Mostrar información de la versión.
--withcomments
Mostrar un comentario completo para cada nodo de configuración. Para configuraciones obsoletas, también mostrar comentarios sobre la obsolescencia.
--withgeneralpreamble
Incluir preámbulo general del archivo de configuración.
--withlocalpreamble
Incluir preámbulo local del archivo de configuración.
--withspaces
Cuando sea apropiado, añadir más espacios en la salida para mejorar la legibilidad.
--withsummary
Mostrar un comentario de una línea para cada nodo de configuración.
--withversions
También mostrar un comentario que contenga la versión de introducción para cada nodo de configuración. Si la configuración está obsoleta, también mostrar la versión desde la cual está obsoleta.
-y|--yes
No solicitar confirmación de forma interactiva, sino asumir siempre la respuesta sí. Usar con extrema precaución. (Para un no automático, ver -qq.)

VARIABLES

String
Ver la descripción de la opción para obtener información sobre el contenido de la cadena.
Size[UNIT]
Size es un número de entrada que acepta una unidad opcional. Las unidades de entrada siempre se tratan como valores base dos, independientemente de mayúsculas/minúsculas, por ejemplo, 'k' y 'K' se refieren ambos a 1024. La unidad de entrada predeterminada se especifica por letra, seguida de |UNIT. UNIT representa otras unidades de entrada posibles: b|B son bytes, s|S son sectores de 512 bytes, k|K son KiB, m|M son MiB, g|G son GiB, t|T son TiB, p|P son PiB, e|E son EiB. (Esto no debe confundirse con el control de salida --units, donde las letras mayúsculas significan múltiplos de 1000.)

VARIABLES DE ENTORNO

Ver lvm(8) para obtener información sobre las variables de entorno utilizadas por lvm. Por ejemplo, LVM_VG_NAME puede sustituirse generalmente por un parámetro VG requerido.
