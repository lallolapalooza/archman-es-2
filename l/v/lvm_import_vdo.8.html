NOMBRE

lvm_import_vdo — utilidad para importar volúmenes VDO a un nuevo grupo de volúmenes

SINOPSIS

lvm_import_vdo [opciones] dispositivo

DESCRIPCIÓN

La utilidad lvm_import_vdo importa volúmenes VDO creados y gestionados por el gestor vdo(8) a un LV VDO gestionado por lvm2(8). Esto se realiza moviendo la superbloque VDO 2MiB y creando metadatos lvm2 al frente de este dispositivo. La operación no es reversible, por lo tanto, después de la conversión a lvm2, el acceso a los datos VDO solo es posible con comandos de lvm2(8), el gestor vdo(8) ya no controla dicho volumen.

OPCIONES

-f|--force
Ignorar algunas comprobaciones de seguridad.
-h|--help
Mostrar el texto de ayuda.
-n|--name
Especifica el nombre del LV VDO convertido. Cuando no se especifica el nombre, se selecciona un nombre automático. En caso de que el volumen VDO convertido ya esté usando un LV como dispositivo de backend, se utiliza el nombre de este LV para el LV VDO. En este caso, el nombre del grupo de volúmenes también debe permanecer igual. El nombre automático puede cambiar entre versiones y actualmente selecciona "vdolv" como nombre de LV y el nombre de VG se selecciona de la secuencia "vdovg", "vdovg1", ...
-v|--verbose
Ser más detallado.
-y|--yes
Responder "sí" a cualquier pregunta.
--dry-run
Imprimir detalladamente los comandos sin ejecutarlos.
--no-snapshot
Con esta opción, la herramienta de conversión no utilizará una instantánea (almacenamiento COW) para la conversión en tu sistema de archivos $TMPDIR y manipulará directamente el dispositivo VDO in situ. Advertencia: el uso de instantáneas hace que toda la conversión sea transaccional y la instantánea puede fusionarse simplemente una vez que toda la conversión haya procedido con éxito. En caso de error, la instantánea simplemente se elimina. Sin el uso de instantáneas, existe un mayor riesgo de problemas de recuperabilidad en caso de que ocurra algún error inesperado.
--vdo-config
Archivo de configuración para el gestor VDO. Se puede usar para especificar la configuración para el gestor vdo.

DIAGNÓSTICOS

Al finalizar con éxito, el código de estado es 0. Se utiliza un código de estado 1 para fallos.

EJEMPLOS

Convertir el volumen VDO creado por el gestor vdo en el volumen lógico LV1 dentro del grupo de volúmenes VG1.

# lvm_import_vdo --name VG1/LV1 /dev/mapper/vdo-volume

VARIABLES DE ENTORNO

TMPDIR
El nombre del directorio temporal para los puntos de montaje. Por defecto es "/tmp".
DM_DEV_DIR
El nombre del directorio de dispositivos. Por defecto es "/dev" y debe ser una ruta absoluta.
DM_UUID_PREFIX
Especifica el prefijo UUID para el volumen de instantánea utilizado durante la conversión de vdo.
LVM_BINARY
Permite anular el comando llamado desde lvm. Por defecto es "lvm".
VDO_BINARY
Permite anular el comando llamado desde vdo. Por defecto es "vdo".
