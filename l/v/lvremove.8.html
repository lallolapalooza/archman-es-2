NOMBRE

lvremove — Elimina volúmenes lógicos del sistema

SINOPSIS

lvremove args_posicionales
[ args_opcionales ]

DESCRIPCIÓN

lvremove elimina uno o más LVs. Para LVs estándar, esto devuelve las extensiones lógicas que fueron utilizadas por el LV al VG para ser utilizadas por otros LVs.

Se solicitará confirmación antes de desactivar cualquier LV activo previo a la eliminación. Los LVs no pueden ser desactivados o eliminados mientras estén abiertos (por ejemplo, si contienen un sistema de archivos montado). La eliminación de un LV de origen también eliminará todas las instantáneas dependientes.

Cuando se utiliza una única opción de fuerza, los LVs se eliminan sin confirmación, y el comando intentará desactivar los LVs no utilizados.

Para eliminar LVs dañados, pueden requerirse dos opciones de fuerza (-ff).

LVs Históricos

Si la configuración metadata/record_lvs_history está habilitada y el LV que se está eliminando forma parte del historial de al menos un LV que aún está presente, se conservará una representación simplificada del LV. Esto incluye la hora de eliminación (campo de informe lv_time_removed), la hora de creación (lv_time), el nombre (lv_name), el UUID del LV (lv_uuid) y el nombre del VG (vg_name). Esto permite que informes posteriores vean la cadena de ascendencia de los volúmenes de instantáneas delgadas, incluso después de que algunos LVs intermedios hayan sido eliminados. Los nombres de dichos LVs históricos adquieren un guion como prefijo (por ejemplo, '-lvol1') y no pueden ser reactivados. Use lvremove por segunda vez, con el guion, para eliminar el registro del antiguo LV completamente.

OPCIONES

-A|--autobackup y|n
Especifica si las metadatos deben ser respaldadas automáticamente después de un cambio. ¡Se recomienda encarecidamente habilitar esto! Consulte vgcfgbackup(8) para más información.
--commandprofile Cadena
El perfil de comando a utilizar para la configuración del comando. Consulte lvm.conf(5) para más información sobre perfiles.
--config Cadena
Configuraciones del comando. Estas anulan la configuración de lvm.conf(5). El argumento Cadena utiliza el mismo formato que lvm.conf(5), o puede usar la sintaxis de sección/campo. Consulte lvm.conf(5) para más información sobre la configuración.
-d|--debug ...
Establece el nivel de depuración. Repetir de 1 a 6 veces para aumentar el detalle de los mensajes enviados al archivo de registro y/o a syslog (si está configurado).
--devices PV
Restringe los dispositivos que son visibles y accesibles para el comando. Los dispositivos no listados parecerán faltar. Esta opción se puede repetir, o acepta una lista de dispositivos separada por comas. Esto anula el archivo de dispositivos.
--devicesfile Cadena
Un archivo que lista los dispositivos que LVM debe utilizar. El archivo debe existir en /etc/lvm/devices/ y se gestiona con el comando lvmdevices(8). Esto anula la configuración devices/devicesfile y devices/use_devicesfile de lvm.conf(5).
--driverloaded y|n
Si se establece en no, el comando no intentará usar device-mapper. Para pruebas y depuración.
-f|--force ...
Anula varias comprobaciones, confirmaciones y protecciones. Usar con extrema precaución.
-h|--help
Muestra el texto de ayuda.
--journal Cadena
Registra información en el journal de systemd. Esta información es adicional a la información habilitada por la configuración de registro/journal de lvm.conf. comando: registra información sobre el comando. salida: registra la salida predeterminada del comando. depuración: registra la depuración completa del comando.
--lockopt Cadena
Se utiliza para pasar opciones para casos especiales a lvmlockd. Consulte lvmlockd(8) para más información.
--longhelp
Muestra el texto de ayuda extendido.
--nohints
No utilizar el archivo de pistas para localizar dispositivos para los PVs. Un comando puede leer más dispositivos para encontrar PVs cuando no se usan pistas. El comando aún realizará la invalidación estándar del archivo de pistas cuando sea apropiado.
--nohistory
No registrar el historial de los LVs que se están eliminando. Esto no tiene efecto a menos que la configuración metadata/record_lvs_history esté habilitada.
--nolocking
Deshabilita el bloqueo. Usar con precaución, los comandos concurrentes pueden producir resultados incorrectos.
--noudevsync
Deshabilita la sincronización de udev. El proceso no esperará la notificación de udev. Continuará independientemente de cualquier posible procesamiento de udev en segundo plano. Solo use esto si udev no se está ejecutando o tiene reglas que ignoran los dispositivos que LVM crea.
--profile Cadena
Un alias para --commandprofile o --metadataprofile, dependiendo del comando.
-q|--quiet ...
Suprime la salida y los mensajes de registro. Anula --debug y --verbose. Repetir una vez también suprime cualquier solicitud con respuesta 'no'.
--reportformat basic|json|json_std
Anula el formato de salida actual para informes, que se define globalmente por la configuración report/output_format en lvm.conf(5). basic es el formato original con columnas y filas. Si hay más de un informe por comando, cada informe se prefija con el nombre del informe para su identificación. json produce la salida del informe en formato JSON. json_std produce la salida del informe en formato JSON que es más compatible con el estándar JSON. Consulte lvmreport(7) para más información.
-S|--select Cadena
Selecciona objetos para procesamiento e informes basándose en criterios especificados. La sintaxis de los criterios se describe en --select help y lvmreport(7). Para comandos de informes, se muestra una fila por cada objeto que coincide con los criterios. Consulte --options help para ver los campos de objetos seleccionables. Las filas pueden mostrarse con un campo adicional "selected" (-o selected) que muestra 1 si la fila coincide con la selección y 0 ot

OPTIONS

-f|--force
Do not prompt for confirmation interactively but always assume the answer yes. Use with extreme caution. (For automatic no, see -qq.)
-M|--metadatascan LV|vg|all
If the metadata scan is needed, it is enabled by default. This option can be used to disable it. This is for commands which process LVM entities. The selection is used to choose items to process.
LV
Logical volumes.
vg
Volume groups.
all
All entities.
-m|--monitor LV|vg|all
If the metadata scan is needed, it is enabled by default. This option can be used to disable it. This is for commands which process LVM entities. The selection is used to choose items to process.
-t|--test
Run in test mode. Commands will not update metadata. This is implemented by disabling all metadata writing but nevertheless returning success to the calling function. This may lead to unusual error messages in multi-stage operations if a tool relies on reading back metadata it believes has changed but hasn't.
-v|--verbose ...
Set verbose level. Repeat from 1 to 4 times to increase the detail of messages sent to stdout and stderr.
--version
Display version information.
-y|--yes
Do not prompt for confirmation interactively but always assume the answer yes. Use with extreme caution. (For automatic no, see -qq.)

VARIABLES

VG
Volume Group name. See lvm(8) for valid names.
LV
Logical Volume name. See lvm(8) for valid names. An LV positional arg generally includes the VG name and LV name, e.g. VG/LV.
Tag
Tag name. See lvm(8) for information about tag names and using tags in place of a VG, LV or PV.
Select
Select indicates that a required positional parameter can be omitted if the --select option is used. No arg appears in this position.
String
See the option description for information about the string content.
Size[UNIT]
Size is an input number that accepts an optional unit. Input units are always treated as base two values, regardless of capitalization, e.g. 'k' and 'K' both refer to 1024. The default input unit is specified by letter, followed by |UNIT. UNIT represents other possible input units: b|B is bytes, s|S is sectors of 512 bytes, k|K is KiB, m|M is MiB, g|G is GiB, t|T is TiB, p|P is PiB, e|E is EiB. (This should not be confused with the output control --units, where capital letters mean multiple of 1000.)

ENVIRONMENT VARIABLES

See lvm(8) for information about environment variables used by lvm. For example, LVM_VG_NAME can generally be substituted for a required VG parameter.

EXAMPLES

Remove an active LV without asking for confirmation.
lvremove -f vg00/lvol1

Remove all LVs the specified VG.
lvremove vg00
