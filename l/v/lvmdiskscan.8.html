NOMBRE

lvmdiskscan — Listar dispositivos que pueden ser utilizados como volúmenes físicos.

SINOPSIS

lvmdiskscan
[ argumentos_opcionales ]

DESCRIPCIÓN

lvmdiskscan escanea todos los discos SCSI, IDE (E), múltiples dispositivos y un montón de otros dispositivos de bloque en el sistema buscando PVs de LVM. El tamaño reportado es el tamaño real del dispositivo. Define un filtro en lvm.conf(5) para restringir el escaneo y evitar un CD ROM, por ejemplo.

Este comando está obsoleto, usa pvs en su lugar.

OPCIONES

--commandprofile Cadena
El perfil de comando a usar para la configuración del comando. Ver lvm.conf(5) para más información sobre perfiles.
--config Cadena
Configuraciones del comando. Estas reemplazan los ajustes de lvm.conf(5). El argumento Cadena usa el mismo formato que lvm.conf(5), o puede usar la sintaxis de sección/campo. Ver lvm.conf(5) para más información sobre la configuración.
-d|--debug ...
Establece el nivel de depuración. Repite de 1 a 6 veces para aumentar el detalle de los mensajes enviados al archivo de registro y/o syslog (si está configurado).
--devices PV
Restringe los dispositivos que son visibles y accesibles para el comando. Los dispositivos no listados aparecerán como ausentes. Esta opción puede repetirse, o aceptar una lista de dispositivos separados por comas. Esto reemplaza el archivo de dispositivos.
--devicesfile Cadena
Un archivo que lista los dispositivos que LVM debe usar. El archivo debe existir en /etc/lvm/devices/ y se gestiona con el comando lvmdevices(8). Esto reemplaza los ajustes devices/devicesfile y devices/use_devicesfile de lvm.conf(5).
--driverloaded y|n
Si se establece en no, el comando no intentará usar device-mapper. Para pruebas y depuración.
-h|--help
Muestra el texto de ayuda.
--journal Cadena
Registra información en el journal de systemd. Esta información se suma a la información habilitada por la configuración de registro/journal de lvm.comando: registra información sobre el comando. salida: registra la salida por defecto del comando. depuración: registra la depuración completa del comando.
--lockopt Cadena
Se utiliza para pasar opciones para casos especiales a lvmlockd. Ver lvmlockd(8) para más información.
--longhelp
Muestra el texto de ayuda largo.
-l|--lvmpartition
Solo reporta PVs.
--nohints
No usar el archivo de sugerencias para localizar dispositivos para PVs. Un comando puede leer más dispositivos para encontrar PVs cuando no se usan sugerencias. El comando aún realizará la invalidación estándar del archivo de sugerencias donde sea apropiado.
--nolocking
Deshabilita el bloqueo. Usar con precaución, comandos concurrentes pueden producir resultados incorrectos.
--profile Cadena
Un alias para --commandprofile o --metadataprofile, dependiendo del comando.
-q|--quiet ...
Suprime la salida y los mensajes de registro. Reemplaza --debug y --verbose. Repite una vez para suprimir también cualquier solicitud con respuesta 'no'.
--readonly
Evita que el comando realice cambios, incluyendo activaciones y actualizaciones de metadatos. (Ver --permission r para LVs de solo lectura.)
-t|--test
Ejecutar en modo de prueba. Los comandos no actualizarán los metadatos. Esto se implementa deshabilitando toda escritura de metadatos pero devolviendo éxito a la función de llamada. Esto puede llevar a mensajes de error inusuales en operaciones de múltiples etapas si una herramienta depende de leer metadatos que cree que han cambiado pero no lo han hecho.
-v|--verbose ...
Establece el nivel de verbosidad. Repite de 1 a 4 veces para aumentar el detalle de los mensajes enviados a stdout y stderr.
--version
Muestra información de la versión.
-y|--yes
No solicitar confirmación interactivamente, sino asumir siempre la respuesta sí. Usar con extrema precaución. (Para un no automático, ver -qq.)

VARIABLES

Cadena
Ver la descripción de la opción para obtener información sobre el contenido de la cadena.
Tamaño[UNIDAD]
Tamaño es un número de entrada que acepta una unidad opcional. Las unidades de entrada siempre se tratan como valores de base dos, independientemente de si están en mayúsculas o minúsculas, por ejemplo, 'k' y 'K' se refieren a 1024. La unidad de entrada predeterminada se especifica con una letra, seguida de |UNIDAD. UNIDAD representa otras unidades de entrada posibles: b|B es bytes, s|S son sectores de 512 bytes, k|K es KiB, m|M es MiB, g|G es GiB, t|T es TiB, p|P es PiB, e|E es EiB. (Esto no debe confundirse con el control de salida --units, donde las letras mayúsculas significan múltiplos de 1000.)
