LVM.CONF(5) Manual de formatos de archivo LVM.CONF(5)

NOMBRE

lvm.conf — Archivo de configuración para LVM2

SINOPSIS

/etc/lvm/lvm.conf

DESCRIPCIÓN

lvm.conf se carga durante la fase de inicialización de lvm(8). Este archivo puede, a su vez, cargar otros archivos: las configuraciones leídas posteriormente anulan las anteriores. Las marcas de tiempo de los archivos se comprueban entre comandos y si alguna ha cambiado, se recargan todos los archivos.

Para una descripción de cada configuración de lvm.conf(5), ejecute:

lvmconfig --typeconfig default --withcomments --withspaces

Los valores definidos en lvm.conf pueden ser anulados por cualquiera de estos métodos de configuración extendidos:

anulación directa de la configuración en la línea de comandos
La opción de línea de comandos --config ConfigurationString toma ConfigurationString como una representación de cadena directa de la configuración para anular la configuración existente. ConfigurationString tiene exactamente el mismo formato que se usa en cualquier archivo de configuración de LVM.
configuración de perfil

Un perfil es un conjunto de configuraciones personalizables seleccionadas que tienen como objetivo lograr ciertas características en diversos entornos o usos. Se utiliza para anular la configuración existente. Normalmente, el nombre del perfil debe reflejar ese entorno o uso.

Hay dos grupos de perfiles reconocidos: perfiles de comando y perfiles de metadatos.

El perfil de comando se utiliza para anular configuraciones seleccionadas en el nivel global del comando LVM; se aplica al principio de la ejecución del comando LVM y se utiliza durante todo el tiempo de ejecución del comando LVM. El perfil de comando se aplica utilizando la opción de línea de comandos --commandprofile NombrePerfil que es reconocida por todos los comandos LVM2.

El perfil de metadatos se utiliza para anular configuraciones seleccionadas en el nivel del Grupo de Volúmenes/Volumen Lógico; se aplica de forma independiente para cada Grupo de Volúmenes/Volumen Lógico que se esté procesando. Como tal, cada Grupo de Volúmenes/Volumen Lógico puede almacenar el nombre del perfil utilizado en sus metadatos, por lo que la próxima vez que se procese el Grupo de Volúmenes/Volumen Lógico, se aplicará automáticamente el perfil. Si el Grupo de Volúmenes y alguno de sus Volúmenes Lógicos tienen perfiles diferentes definidos, se prefiere el perfil definido para el Volumen Lógico. El perfil de metadatos se puede adjuntar/desadjuntar utilizando los comandos lvchange y vgchange y sus opciones --metadataprofile NombrePerfil y --detachprofile, o la opción --metadataprofile durante la creación al usar los comandos vgcreate o lvcreate. Los comandos de reporte vgs y lvs proporcionan opciones de salida -o vg_profile y -o lv_profile para mostrar el perfil de metadatos adjunto actualmente a un Grupo de Volúmenes o un Volumen Lógico.

El conjunto de opciones permitidas para los perfiles de comando es mutuamente excluyente en comparación con el conjunto de opciones permitidas para los perfiles de metadatos. Las configuraciones que pertenecen a cualquiera de estos dos conjuntos no se pueden mezclar y las herramientas LVM rechazarán tales perfiles.

LVM en sí mismo proporciona algunos perfiles de configuración predefinidos. A los usuarios se les permite agregar más perfiles con valores diferentes si es necesario. Para este propósito, existe command_profile_template.profile (para perfiles de comando) y metadata_profile_template.profile (para perfiles de metadatos) que contienen todas las configuraciones personalizables por perfiles de cierto tipo. Se anima a los usuarios a copiar estos perfiles de plantilla y editarlos según sea necesario. Alternativamente, se pueden usar lvmconfig --file <NombrePerfil.profile> --type profilable-command <sección> o lvmconfig --file <NombrePerfil.profile> --type profilable-metadata <sección> para generar una configuración con configuraciones perfilables de cualquiera de los tipos para una sección dada y guardarla en un nuevo NombrePerfil.profile (si no se especifica la sección, se informan todas las configuraciones perfilables).

Los perfiles se almacenan en el directorio /etc/lvm/profile por defecto. Esta ubicación se puede cambiar usando la configuración config/profile_dir. Cada configuración de perfil se almacena en el archivo NombrePerfil.profile en el directorio de perfiles. Al hacer referencia al perfil, se omite el sufijo .profile.

configuración de etiqueta

Ver la descripción de la configuración tags a continuación.

Cuando se utilizan varios métodos de configuración al mismo tiempo y LVM busca el valor de una configuración particular, recorre esta cascada de configuración de izquierda a derecha:

anulación directa de la config en la línea de comandos → configuración de perfil de comando → configuración de perfil de metadatos → configuración de etiqueta → lvmlocal.conf → lvm.conf

Ninguna parte de esta cascada es obligatoria. Si no se encuentra ningún valor de configuración al final de la cascada, se utiliza un valor por defecto para esa configuración. Utilice lvmconfig para comprobar qué configuraciones están en uso y cuáles son los valores por defecto.

SINTAXIS

Esta sección describe la sintaxis del archivo de configuración.

Los espacios en blanco no son significativos a menos que estén entre comillas. Esto proporciona una amplia variedad de estilos de indentación aceptables. Los comentarios comienzan con # y continúan hasta el final de la línea. Se tratan como espacios en blanco.

Aquí hay una gramática informal:

archivo = valor*
Un archivo de configuración consiste en un conjunto de valores.
valor = sección | asignación
Un valor puede ser una nueva sección o una asignación.
sección = identificador '{' valor* '}'
Una sección agrupa valores asociados. Si la misma sección se encuentra varias veces, el contenido de todas las instancias se concatena en el orden de aparición.
Se denota por un nombre y se delimita con corchetes. ej.
backup {
...
}
asignación = identificador '=' ( array | tipo )

Una asignación asocia un tipo con un identificador. Si el identificador contiene barras inclinadas, estas se interpretan como delimitadores de ruta. La instrucción sección/clave = valor es equivalente a sección { clave = valor }. Si se encuentran varias instancias de la misma clave, solo se utiliza el último valor (y se emite una advertencia).
ej. level = 7
array = '[' ( tipo ',')* tipo ']' | '[' ']'
Se admiten arrays inhomogéneos.
Los elementos deben separarse por comas.
Un array vacío es aceptable.
Un array con un solo elemento se interpretará correctamente si faltan los corchetes del array.
tipo =
entero|flotante|cadena entero = [0-9]*
flotante = [0-9]*'.'[0-9]*
cadena = '"' .* '"'
Las cadenas con espacios deben ir entre comillas dobles; las palabras individuales que comiencen con una letra se pueden dejar sin comillas.

CONFIGURACIONES

El comando lvmconfig imprime las configuraciones de LVM de varias maneras. Consulte la página man lvmconfig(8).

Comando para imprimir una lista de todas las configuraciones posibles, con sus valores por defecto:
lvmconfig --type default

Comando para imprimir una lista de todas las configuraciones posibles, con sus valores por defecto y una descripción completa de cada una como comentario:
lvmconfig --type default --withcomments

Comando para imprimir todas las configuraciones posibles, con sus valores actuales (se muestran los valores configurados y no por defecto):
lvmconfig --type current
