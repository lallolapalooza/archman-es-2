DESCRIPCIÓN

lvdisplay muestra los atributos de los LV, como tamaño, estado de lectura/escritura, información de instantáneas, etc.

lvs(8) es una alternativa preferida que muestra la misma información y más, utilizando un formato de salida más compacto y configurable.

USO

lvdisplay

[ -m|--maps ]
[ OPCIONES_COMUNES ]
[ VG|LV|Tag ... ]

—

Muestra la salida en columnas como lvs.

lvdisplay -C|--columns

[ -o|--options String ]
[ -O|--sort String ]
[ -S|--select String ]
[ --aligned ]
[ --binary ]
[ --configreport log|vg|lv|pv|pvseg|seg ]
[ --headings none|abbrev|full|0|1|2 ]
[ --logonly ]
[ --nameprefixes ]
[ --noheadings ]
[ --nosuffix ]

OPCIONES

--aligned
Usar con --separator para alinear las columnas de salida.
-a|--all
Mostrar información sobre LV internos. Estos son componentes de LV normales, como espejos, que no son accesibles de forma independiente, por ejemplo, no montables.
--binary
Usar valores binarios "0" o "1" en lugar de valores literales descriptivos para las columnas que tienen exactamente dos valores válidos para informar (sin contar el valor "unknown" que denota que el valor no pudo ser determinado).
-c|--colon
Generar salida separada por dos puntos para facilitar el análisis en scripts o programas. Ver también lvs(8) que proporciona un control considerablemente mayor sobre la salida. Los valores son:
  • Nombre del volumen lógico
  • Nombre del grupo de volúmenes
  • Acceso del volumen lógico
  • Estado del volumen lógico
  • Número de volumen lógico interno
  • Número de aperturas del volumen lógico
  • Tamaño del volumen lógico en sectores
  • Extents lógicos actuales asociados al volumen lógico
  • Extents lógicos asignados del volumen lógico
  • Política de asignación del volumen lógico
  • Sectores de lectura anticipada del volumen lógico
  • Número de dispositivo principal del volumen lógico
  • Número de dispositivo secundario del volumen lógico
-C|--columns
Mostrar salida en columnas. El equivalente de lvs(8). Las opciones listadas son las mismas que las opciones dadas en lvs(8).
--commandprofile String
El perfil de comando a utilizar para la configuración del comando. Ver lvm.conf(5) para más información sobre perfiles.
--config String
Configuraciones para el comando. Estas anulan la configuración de lvm.conf(5). El argumento String usa el mismo formato que lvm.conf(5), o puede usar la sintaxis sección/campo. Ver lvm.conf(5) para más información sobre configuración.
--configreport log|vg|lv|pv|pvseg|seg
Ver lvmreport(7).
-d|--debug ...
Establecer el nivel de depuración. Repetir de 1 a 6 veces para aumentar el detalle de los mensajes enviados al archivo de registro y/o syslog (si está configurado).
--devices

OPCIONES

-a|--all
Operar en todos los Volúmenes Físicos, Grupos de Volúmenes y Volúmenes Lógicos. Esta opción puede ser utilizada para especificar que la operación debe aplicarse a todos los objetos de un tipo dado (por ejemplo, todos los VGs, todos los LVs, todos los PVs).
-c|--checkdata
Comprobar si los datos contienen patrones de datos dañados. Cuando se combina con --repair, intentará reparar cualquier bloque de datos dañado encontrado.
--checklogically
Comprueba el PV por la presencia de metadatos LVM. LVM intentará localizar los metadatos LVM basándose en las convenciones de LVM (y posiblemente en la información de LVM del sistema de archivos). Si se encuentran metadatos, se informará sobre ellos. Si se encuentra más de un conjunto de metadatos, se informará sobre todos ellos. Esta opción se puede utilizar para encontrar metadatos LVM que de otro modo serían invisibles.
--commandprofile String
Permite pasar un perfil de configuración para un comando específico. El perfil se lee del archivo de configuración de LVM. Véase lvm.conf(5) para más información sobre los perfiles.
--config String
Permite pasar parámetros de configuración al comando. Estos parámetros se aplican como si estuvieran en el archivo lvm.conf(5). La cadena debe tener el formato de un archivo de configuración de LVM.
-d|--debug ...
Establece el nivel de depuración. Repetir de 1 a 4 veces para aumentar el detalle de los mensajes enviados a stdout y stderr.
-d|--devices String
Restringe los dispositivos que son visibles y accesibles para el comando. Los dispositivos no listados parecerán faltar. Esta opción se puede repetir, o acepta una lista de dispositivos separados por comas. Esto anula el archivo de dispositivos.
--devicesfile String
Un archivo que lista los dispositivos que LVM debe usar. El archivo debe existir en /etc/lvm/devices/ y se gestiona con el comando lvmdevices(8). Esto anula los ajustes del archivo lvm.conf(5) devices/devicesfile y devices/use_devicesfile.
--driverloaded y|n
Si se establece en no, el comando no intentará usar device-mapper. Para pruebas y depuración.
--foreign
Informar/mostrar VGs extranjeros que de otro modo serían omitidos. Véase lvmsystemid(7) para más información sobre VGs extranjeros.
--headings none|abbrev|full|0|1|2
Tipo de encabezados a usar en la salida del informe. none o 0: Sin encabezados. abbrev o 1: Abreviaturas de nombres de columna. full o 2: Nombres de columna completos.
-h|--help
Mostrar texto de ayuda.
-H|--history
Incluir LVs históricos en la salida. (Esto no tiene efecto a menos que los LVs fueran eliminados mientras lvm.conf(5) metadata/record_lvs_history estaba habilitado).
--ignorelockingfailure
Permite que un comando continúe con operaciones de metadatos de solo lectura después de fallos de bloqueo.
--journal String
Registrar información en el journal de systemd. Esta información es adicional a la información habilitada por la configuración de registro/journal de lvm.conf. comando: registrar información sobre el comando. salida: registrar la salida predeterminada del comando. depuración: registrar la depuración completa del comando.
--lockopt String
Se utiliza para pasar opciones para casos especiales a lvmlockd. Véase lvmlockd(8) para más información.
--logonly
Suprimir el informe del comando y mostrar solo el informe de registro.
--longhelp
Mostrar texto de ayuda detallado.
-m|--maps
Mostrar el mapeo de extents lógicos a PVs y extents físicos. Para mapear extents físicos a extents lógicos, usar: pvs --segments -o+lv_name,seg_start_pe,segtype
--nameprefixes
Añadir un prefijo "LVM2_" más el nombre del campo a la salida. Útil con --noheadings para producir una lista de pares campo=valor que pueden ser utilizados para establecer variables de entorno (por ejemplo, en reglas udev).
--noheadings
Suprimir la línea de encabezados que normalmente es la primera línea de salida. Útil si se busca en la salida (grep).
--nohints
No utilizar el archivo de pistas para localizar dispositivos para PVs. Un comando puede leer más dispositivos para encontrar PVs cuando no se usan pistas. El comando aún realizará la invalidación estándar del archivo de pistas cuando sea apropiado.
--nolocking
Deshabilitar el bloqueo. Usar con precaución, los comandos concurrentes pueden producir resultados incorrectos.
--nosuffix
Suprimir el sufijo en los tamaños de salida. Usar con --units (excepto h y H) si se procesa la salida.
-o|--options String
Lista ordenada y separada por comas de los campos a mostrar en columnas. La sintaxis del argumento String es: [+|-|#]Campo1[,Campo2 ...] El prefijo + añadirá los campos especificados a los campos predeterminados, - eliminará los campos especificados de los campos predeterminados, y # compactará los campos especificados (eliminándolos cuando estén vacíos para todas las filas.) Usar -o help para ver la lista de todos los campos disponibles. Usar listas separadas de campos para añadir, eliminar o compactar repitiendo la opción -o: -o+campo1,campo2 -o-campo3,campo4 -o#campo5. Estas listas se evalúan de izquierda a derecha. Usar el nombre del campo lv_all para ver todos los campos de LV, vg_all todos los campos de VG, pv_all todos los campos de PV, seg_all todos los campos de segmento de LV, y pvseg_all todos los campos de segmento de PV. Véase la sección de informes de lvm.conf(5) para más opciones de configuración. Véase lvmreport(7) para más información sobre informes.
--profile String
Un alias para --commandprofile o --metadataprofile, dependiendo del comando.
-q|--quiet ...
Suprimir la salida y los mensajes de registro. Anula --debug y --verbose. Repetir una vez para suprimir también cualquier indicación con respuesta 'no'.
--readonly
Evitar que el comando realice cambios, incluyendo la activación y las actualizaciones de metadatos. (Véase --permission r para LVs de solo lectura.)
--reportformat basic|json|json_std
Anula el formato de salida actual para informes, el cual está definido globalmente por la configuración report/output_format en lvm.conf(5). basic es el formato original con columnas y filas. Si hay más de un informe por comando, cada informe se prefiere con el nombre del informe para su identificación. json produce la salida del informe en formato JSON. json_std produce la salida del informe en formato JSON que es más compatible con el estándar JSON. Véase lvmreport(7) para más información.
--rows
Columnas de salida como filas.
--segments
Usar columnas predeterminadas que enfatizan la información del segmento.
-S|--select String
Seleccionar objetos para procesamiento e informes basándose en criterios especificados. La sintaxis del criterio se describe en --select help y lvmreport(7). Para comandos de informes, se muestra una fila por cada objeto que coincide con el criterio. Véase --options help para los campos de objetos seleccionables. Las filas se pueden mostrar con un campo adicional "selected" (-o selected) que muestra 1 si la fila coincide con la selección y 0 en caso contrario. Para comandos no de informes que procesan entidades LVM, la selección se utiliza para elegir los elementos a procesar.
--separator String
Cadena a usar para separar cada columna. Útil si se busca en la salida (grep).
--shared
Informar/mostrar VGs compartidos que de otro modo serían omitidos cuando lvmlockd no se está utilizando en el host. Véase lvmlockd(8) para más información sobre VGs compartidos.
-O|--sort String
Lista ordenada y separada por comas de las columnas por las que ordenar. Reemplaza la selección predeterminada. Anteponer a cualquier columna un - para una ordenación inversa en esa columna.
-t|--test
Ejecutar en modo de prueba. Los comandos no actualizarán los metadatos. Esto se implementa deshabilitando toda escritura de metadatos, pero devolviendo éxito a la función que llama. Esto puede llevar a mensajes de error inusuales en operaciones de múltiples etapas si una herramienta depende de leer metadatos que cree que han cambiado pero no lo han hecho.
--unbuffered
Producir la salida inmediatamente sin ordenar ni alinear correctamente las columnas.
--units [Número]r|R|h|H|b|B|s|S|k|K|m|M|g|G|t|T|p|P|e|E
Todos los tamaños se muestran en estas unidades: legible por humanos (r) con indicador de redondeo '<', (h)umano legible, (b)ytes, (s)ectores, (k)ilobytes, (m)egabytes, (g)igabytes, (t)erabytes, (p)etabytes, (e)xabytes. Usar mayúsculas para usar múltiplos de 1000 (S.I.) en lugar de 1024. Se pueden especificar unidades personalizadas, por ejemplo, --units 3M.
--unquoted
Cuando se usa con --nameprefixes, los valores de salida en los pares campo=valor no estarán entre comillas.
-v|--verbose ...
Establecer el nivel de verbosidad. Repetir de 1 a 4 veces para aumentar el detalle de los mensajes enviados a stdout y stderr.
--version
Mostrar información de la versión.
-y|--yes
No solicitar confirmación interactivamente, sino asumir siempre la respuesta sí. Usar con extrema precaución. (Para un no automático, véase -qq.)

VARIABLES

VG
Nombre del Grupo de Volúmenes. Véase lvm(8) para nombres válidos.
LV
Nombre del Volumen Lógico. Véase lvm(8) para nombres válidos. Un argumento posicional LV generalmente incluye el nombre del VG y el nombre del LV, por ejemplo, VG/LV.
Tag
Nombre de la etiqueta. Véase lvm(8) para información sobre nombres de etiquetas y el uso de etiquetas en lugar de un VG, LV o PV.
String
Véase la descripción de la opción para obtener información sobre el contenido de la cadena.
Size[UNIT]
Size es un número de entrada que acepta una unidad opcional. Las unidades de entrada siempre se tratan como valores base dos, independientemente de las mayúsculas/minúsculas, por ejemplo, 'k' y 'K' se refieren a 1024. La unidad de entrada predeterminada se especifica por letra, seguida de |U
lvdisplay(8) - Página del manual de Linux

VARIABLES

NIT. UNIT representa otras unidades de entrada posibles:
b|B son bytes, s|S son sectores de 512 bytes,
k|K es KiB, m|M es MiB, g|G es GiB, t|T es TiB, p|P es PiB, e|E es EiB. (Esto no debe confundirse con el control de salida --units, donde las letras mayúsculas significan múltiplos de 1000.)

VARIABLES DE ENTORNO

Consulte lvm(8) para obtener información sobre las variables de entorno utilizadas por lvm. Por ejemplo, LVM_VG_NAME generalmente puede sustituir a un parámetro VG requerido.
