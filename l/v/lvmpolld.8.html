NOMBRE

lvmpolld — Demonio de sondeo de LVM

SINOPSIS

lvmpolld
[-B|--binary ruta_binario_lvm] [-f|--foreground] [-h|--help] [-l|--log all|wire|debug] [-p|--pidfile ruta_archivo_pid] [-s|--socket ruta_socket] [-t|--timeout valor_timeout] [-V|--version]
lvmpolld
[--dump]

DESCRIPCIÓN

lvmpolld es un demonio de sondeo para LVM. El demonio recibe solicitudes de sondeo de operaciones ya inicializadas originadas en la herramienta de línea de comandos LVM2. Las solicitudes de sondeo se originan en los comandos lvconvert, pvmove, lvchange o vgchange de LVM2.

El propósito de lvmpolld es reducir el número de procesos en segundo plano iniciados por operación de sondeo única. Debería haber solo uno. También elimina la posibilidad de terminación no solicitada del proceso en segundo plano por factores externos.

lvmpolld es utilizado por LVM solo si está habilitado en lvm.conf(5) especificando la configuración global/use_lvmpolld. Si esto no está definido explícitamente en la configuración de LVM, se utiliza la configuración predeterminada en su lugar (ver la salida del comando lvmconfig --type default global/use_lvmpolld).

OPCIONES

Para ejecutar el demonio en un entorno de prueba, se deben cambiar tanto la ruta_archivo_pid como la ruta_socket de los valores predeterminados.

-B|--binary ruta_binario_lvm
Ruta opcional a un binario LVM alternativo (predeterminado: /usr/bin/lvm). Úselo solo para fines de prueba.
--dump
Contactar al demonio lvmpolld en ejecución para obtener el estado completo e imprimirlo en formato bruto.
-f|--foreground
No crear un proceso hijo, ejecutar en primer plano.
-h|--help
Mostrar información de ayuda.
-l|--log all|wire|debug
Seleccionar el tipo de mensajes de registro a generar. Los mensajes se registran mediante syslog. Adicionalmente, cuando se proporciona -f, también se envían al error estándar. Hay dos clases de mensajes: wire y debug. Seleccionar 'all' proporciona ambos y es equivalente a una lista separada por comas -l wire,debug.
-p|--pidfile ruta_archivo_pid
Ruta al archivo pid. Esto anula tanto el valor predeterminado interno (/run/lvmpolld.pid) como la variable de entorno LVM_LVMPOLLD_PIDFILE. Este archivo se utiliza para evitar que más de una instancia del demonio se ejecute simultáneamente.
-s|--socket ruta_socket
Ruta al archivo socket. Esto anula tanto el valor predeterminado interno (/run/lvm/lvmpolld.socket) como la variable de entorno LVM_LVMPOLLD_SOCKET.
-t|--timeout valor_timeout
El demonio puede apagarse después de estar inactivo durante el tiempo indicado (en segundos). Cuando la opción se omite o el valor proporcionado es cero, el demonio nunca se apaga por inactividad.
-V|--version
Mostrar la versión del demonio lvmpolld.

VARIABLES DE ENTORNO

LVM_LVMPOLLD_PIDFILE
Ruta para el archivo pid.
LVM_LVMPOLLD_SOCKET
Ruta para el archivo socket.

VER TAMBIÉN

lvm(8), lvm.conf(5), lvchange(8), lvconvert(8), pvmove(8), vgchange(8)
