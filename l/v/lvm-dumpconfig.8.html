NOMBRE

lvmconfig — Muestra y manipula información de configuración

SINOPSIS

lvmconfig
[ argumentos_opcionales ]
[ argumentos_posicionales ]

DESCRIPCIÓN

lvmconfig, lvm config, lvm dumpconfig (por razones de compatibilidad, se eliminarán gradualmente) producen una salida formateada del árbol de configuración de LVM. Las fuentes de los datos de configuración incluyen lvm.conf(5) y la configuración de línea de comandos de --config.

OPCIONES

--enversion Cadena
Especifica una versión de LVM en formato x.y.z donde x es la versión principal, y es la versión secundaria y z es el nivel de parche (por ejemplo, 2.2.106). Cuando se muestra la configuración, solo se considerarán los ajustes de configuración reconocidos en esta versión de LVM. Esto puede usarse para mostrar una configuración que una versión determinada de LVM entiende y que no contiene configuraciones más nuevas para las cuales LVM emitiría un mensaje de advertencia al verificar la configuración.
--perfilcomando Cadena
El perfil de comando a utilizar para la configuración del comando. Consulte lvm.conf(5) para obtener más información sobre los perfiles.
--config Cadena
Configuraciones del comando. Estas anulan la configuración de lvm.conf(5). El argumento Cadena utiliza el mismo formato que lvm.conf(5), o puede usar la sintaxis de sección/campo. Consulte lvm.conf(5) para obtener más información sobre la configuración.
-d|--debug ...
Establece el nivel de depuración. Repetir de 1 a 6 veces para aumentar el detalle de los mensajes enviados al archivo de registro y/o a syslog (si está configurado).
--dispositivos PV
Restringe los dispositivos que son visibles y accesibles para el comando. Los dispositivos no listados parecerán faltar. Esta opción se puede repetir o aceptar una lista de dispositivos separada por comas. Esto anula el archivo de dispositivos.
--archivo-dispositivos Cadena
Un archivo que enumera los dispositivos que LVM debe utilizar. El archivo debe existir en /etc/lvm/devices/ y se gestiona con el comando lvmdevices(8). Esto anula los ajustes devices/devicesfile y devices/use_devicesfile de lvm.conf(5).
--drivercargado s|n
Si se establece en no, el comando no intentará utilizar device-mapper. Para pruebas y depuración.
-f|--archivo Cadena
Escribe la salida en el archivo nombrado.
-h|--help
Muestra el texto de ayuda.
--ignorardv
Excluye los ajustes de configuración avanzados de la salida.
--ignorarvaloreslocales
Ignora la sección local. La sección local debe definirse en el archivo lvmlocal.conf y debe contener ajustes de configuración específicos del host local que no deben copiarse a otros hosts.
--ignorarno-soportados
Excluye los ajustes de configuración no soportados de la salida. Estos ajustes se utilizan solo para fines de depuración y desarrollo, o su soporte aún no está completo y no están destinados a ser utilizados en producción. Los tipos actual y diff incluyen ajustes no soportados en su salida por defecto, todos los demás tipos ignoran los ajustes no soportados.
--journal Cadena
Registra información en el journal de systemd. Esta información es adicional a la información habilitada por el ajuste log/journal de lvm.conf. comando: registra información sobre el comando. salida: registra la salida predeterminada del comando. depurar: registra la depuración completa del comando.
-l|--lista
Imprime una lista de ajustes de configuración en lugar de un árbol de ajustes de configuración estructurado. Si se usa sin otras opciones, esto es lo mismo que --tipoconfiguracion lista --conresumen.
--lockopt Cadena
Se utiliza para pasar opciones para casos especiales a lvmlockd. Consulte lvmlockd(8) para obtener más información.
--longhelp
Muestra el texto de ayuda extendido.
--configuracionfusionada
Cuando el comando se ejecuta con --config y/o --perfilcomando (o usando la variable de entorno LVM_COMMAND_PROFILE), --perfil, o --perfilmetadatos, fusiona todo el contenido de la "cascada de configuración" antes de mostrarlo. Sin fusionar, solo se muestra la configuración al principio de la cascada. Consulte lvm.conf(5) para obtener más información sobre la configuración.
--perfilmetadatos Cadena
El perfil de metadatos a utilizar para la configuración del comando. Consulte lvm.conf(5) para obtener más información sobre los perfiles.
--sin-hints
No utilice el archivo de pistas para localizar dispositivos para PVs. Un comando puede leer más dispositivos para encontrar PVs cuando no se utilizan las pistas. El comando seguirá realizando la invalidación estándar del archivo de pistas cuando sea apropiado.
--sin-bloqueo
Deshabilita el bloqueo. Úselo con precaución, los comandos concurrentes pueden producir resultados incorrectos.
--perfil Cadena
Un alias para --perfilcomando o --perfilmetadatos, dependiendo del comando.
-q|--quiet ...
Suprime la salida y los mensajes de registro. Anula --debug y --verbose. Repetir una vez para también suprimir cualquier aviso con respuesta 'no'.
--mostrarobsoletos
Incluye los ajustes de configuración obsoletos en la salida. Estos ajustes.

Este sitio no está asociado de ninguna forma con Arch Linux ni afiliado a este proyecto. El contenido es únicamente una traducción de las páginas del manual de Arch publicadas en man.archlinux.org.

OPTIONS

--allversions
Show configuration settings from all LVM versions, not just the current one. This option is for debugging or compatibility checking only. It can be used with --typeconfig list, full, or diff.
--atversion String
Specify an LVM version in x.y.z format where x is the major version, the y is the minor version and z is the patchlevel (e.g. 2.2.106). This option is useful when checking or displaying configuration settings for a specific LVM version. It affects the output of options like --showdeprecated and --typeconfig. Deprecated settings are automatically included if the specified version is lower than the version in which the settings were deprecated. The current and diff types include deprecated settings in their output by default, all the other types ignore deprecated settings.
--column[UNIT]
Display output in columns, where UNIT specifies the width of the columns. See Size[UNIT] for details on UNIT.
--config String
Use String to override or supplement the default LVM configuration (usually in lvm.conf(5)). The String format is a comma-separated list of parameters, e.g. global/locking_type=1,global/prioritize_writeable_discards=1.
--configpath String
Specify an alternative configuration file path. This is useful for testing or managing multiple configurations.
--devicesfile String
Specify an alternative devices file. This file contains a list of devices that LVM should scan. If not specified, LVM uses the default devices file (usually /etc/lvm/devices.tab).
--dumpconfig [SPECIAL_OPTION]
Print the current LVM configuration. The SPECIAL_OPTION can be one of the following:
allversions
Show configuration settings from all LVM versions.
atversion
Show configuration settings for a specific LVM version.
showdeprecated
Include deprecated configuration settings.
showunsupported
Include unsupported configuration settings.
sinceversion
Show configuration settings introduced since a specific LVM version.
typeconfig
Specify the type of configuration to display.
withcomments
Include comments for each configuration node.
withgeneralpreamble
Include general configuration file preamble.
withlocalpreamble
Include local configuration file preamble.
withspaces
Add extra spaces for better readability.
withsummary
Include a one-line summary for each configuration node.
withversions
Include the version of introduction for each configuration node.
See also lvm.conf(5).
-h|--help
Display help information. Use with no arguments to show the full command list. Use with an option name to show detailed help for that option.
-?|--help
Display help information. Use with no arguments to show the full command list. Use with an option name to show detailed help for that option.
--mergedconfig
When using --validate, this option ensures that the entire merged configuration tree is validated, not just the configuration at the front of the "config cascade".
--nullok
Allow null values for configuration parameters. This can be useful when overriding settings with empty values.
-q|--quiet
Suppress informational messages. Error messages will still be displayed.
--showdeprecated
Include deprecated configuration settings in the output. Deprecated settings are those that are no longer recommended for use and may be removed in future LVM versions. If a concrete version is specified with --atversion, deprecated settings are automatically included if the specified version is lower than the version in which the settings were deprecated. The current and diff types include deprecated settings in their output by default, all the other types ignore deprecated settings.
--showunsupported
Include unsupported configuration settings in the output. These settings are either used for debugging or development purposes only, or their support is not yet complete and they are not meant to be used in production. The current and diff types include unsupported settings in their output by default, all the other types ignore unsupported settings.
--sinceversion String
Specify an LVM version in x.y.z format where x is the major version, the y is the minor version and z is the patchlevel (e.g. 2.2.106). This option is currently applicable only with --typeconfig new to display all configuration settings introduced since given version.
-t|--test
Run in test mode. Commands will not update metadata. This is implemented by disabling all metadata writing but nevertheless returning success to the calling function. This may lead to unusual error messages in multi-stage operations if a tool relies on reading back metadata it believes has changed but hasn't.
--typeconfig current|default|diff|full|list|missing|new|profilable|profilable-command|profilable-metadata
current prints the config settings that would be applied to an lvm command (assuming the command does not override them on the command line.) This includes: settings that have been modified in lvm config files, settings that get their default values from config files, and default settings that have been uncommented in config files. default prints all settings with their default values. Changes made in lvm config files are not reflected in the output. Some settings get their default values internally, and these settings are printed as comments. Other settings get their default values from config files, and these settings are not printed as comments. diff prints only config settings that have been modified from their default values in config files (the difference between current and default.) full prints every setting uncommented and set to the current value, i.e. how it would be used by an lvm command. This includes settings modified in config files, settings that usually get defaults internally, and settings that get defaults from config files. list prints all config names without values. missing prints settings that are missing from the lvm config files. A missing setting that usually gets its default from config files is printed uncommented and set to the internal default. Settings that get their default internally and are not set in config files are printed commented with the internal default. new prints config settings that have been added since the lvm version specified by --sinceversion. They are printed with their default values. profilable prints settings with their default values that can be set from a profile. profilable-command prints settings with their default values that can be set from a command profile. profilable-metadata prints settings with their default values that can be set from a metadata profile. Also see lvm.conf(5).
--unconfigured
Internal option used for generating config file during build.
--validate
Validate current configuration used and exit with appropriate return code. The validation is done only for the configuration at the front of the "config cascade". To validate the whole merged configuration tree, also use --mergedconfig. The validation is done even if lvm.conf(5) config/checks is disabled.
--valuesonly
When printing config settings, print only values without keys.
-v|--verbose ...
Set verbose level. Repeat from 1 to 4 times to increase the detail of messages sent to stdout and stderr.
--version
Display version information.
--withcomments
Display a full comment for each configuration node. For deprecated settings, also display comments about deprecation.
--withgeneralpreamble
Include general config file preamble.
--withlocalpreamble
Include local config file preamble.
--withspaces
Where appropriate, add more spaces in output for better readability.
--withsummary
Display a one line comment for each configuration node.
--withversions
Also display a comment containing the version of introduction for each configuration node. If the setting is deprecated, also display the version since which it is deprecated.
-y|--yes
Do not prompt for confirmation interactively but always assume the answer yes. Use with extreme caution. (For automatic no, see -qq.)

VARIABLES

String
See the option description for information about the string content.
Size[UNIT]
Size is an input number that accepts an optional unit. Input units are always treated as base two values, regardless of capitalization, e.g. 'k' and 'K' both refer to 1024. The default input unit is specified by letter, followed by |UNIT. UNIT represents other possible input units: b|B is bytes, s|S is sectors of 512 bytes, k|K is KiB, m|M is MiB, g|G is GiB, t|T is TiB, p|P is PiB, e|E is EiB. (This should not be confused with the output control --units, where capital letters mean multiple of 1000.)

ENVIRONMENT VARIABLES

NOMBRE

lvm-dumpconfig — Volcar la configuración de LVM2.

SINOPSIS

lvm-dumpconfig [-l|--long] [-t|--type <type>] [-f|--force]

DESCRIPCIÓN

lvm-dumpconfig volcará el contenido del archivo de configuración de LVM2 (lvm.conf) y los archivos incluidos en él a la salida estándar.

La salida puede ser controlada usando las opciones --long y --type.

Si se usa la opción --long, se mostrará la configuración completa, incluyendo los valores por defecto no definidos en el archivo de configuración. De lo contrario, solo se mostrarán los valores que hayan sido definidos explícitamente en los archivos de configuración.

La opción --type puede ser usada para filtrar la salida a un tipo específico de configuración. Los tipos soportados son:

  • profile: Muestra los perfiles de configuración del sistema y del usuario.
  • cache: Muestra la configuración de la caché de metadatos.
  • global: Muestra la configuración global.
  • devices: Muestra la configuración relacionada con los dispositivos.
  • filters: Muestra la configuración de los filtros de dispositivos.
  • backup: Muestra la configuración relacionada con las copias de seguridad.
  • logging: Muestra la configuración relacionada con el registro.
  • repository: Muestra la configuración relacionada con el repositorio de metadatos.
  • snapshot: Muestra la configuración relacionada con las instantáneas.
  • segment: Muestra la configuración relacionada con los segmentos.
  • dmeventd: Muestra la configuración relacionada con dmeventd.
  • systemd: Muestra la configuración relacionada con systemd.
  • fs: Muestra la configuración relacionada con los sistemas de archivos.
  • libreport: Muestra la configuración relacionada con libreport.
  • preferred_names: Muestra la configuración de nombres preferidos.

La opción --force permite sobrescribir los archivos de configuración existentes cuando se está importando una configuración.

USO

lvm-dumpconfig puede ser utilizado para obtener una copia de seguridad de la configuración actual de LVM o para diagnosticar problemas de configuración.

Ejemplo para obtener la configuración completa:

lvm-dumpconfig --long

Ejemplo para obtener solo la configuración de filtros:

lvm-dumpconfig --type filters

OPCIONES

-l, --long
Muestra la configuración completa, incluyendo los valores por defecto.
-t, --type <type>
Filtra la salida a un tipo específico de configuración.
-f, --force
Permite sobrescribir los archivos de configuración existentes (usado principalmente con la importación).
-h, --help
Muestra un mensaje de ayuda y sale.

VARIABLES

No hay variables específicas de lvm-dumpconfig. Se basa en las variables definidas en lvm.conf.

VARIABLES DE ENTORNO

LVM_CONFIG: Especifica la ruta al archivo de configuración de LVM. Si no se define, se usa la ruta por defecto (/etc/lvm/lvm.conf).

LVM_SUPPRESS_LOCK_EVENTS: Si se establece, LVM suprimirá los eventos de bloqueo.

lvm.conf(5), lvmconfig(8)
