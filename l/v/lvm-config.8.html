NOMBRE

lvmconfig — Muestra y manipula información de configuración

SINOPSIS

lvmconfig
[ argumentos_opcionales ]
[ argumentos_posicionales ]

DESCRIPCIÓN

lvmconfig, lvm config, lvm dumpconfig (por razones de compatibilidad, se eliminarán gradualmente) producen una salida formateada del árbol de configuración de LVM. Las fuentes de los datos de configuración incluyen lvm.conf(5) y las configuraciones de línea de comandos de --config.

OPCIONES

--atversion Cadena
Especifica una versión de LVM en formato x.y.z donde x es la versión mayor, y es la versión menor y z es el nivel de parche (por ejemplo, 2.2.106). Cuando se muestra la configuración, solo se considerarán los ajustes de configuración reconocidos en esta versión de LVM. Esto se puede usar para mostrar una configuración que una determinada versión de LVM entiende y que no contiene configuraciones más nuevas para las cuales LVM emitiría un mensaje de advertencia al verificar la configuración.
--commandprofile Cadena
El perfil de comando a utilizar para la configuración del comando. Consulte lvm.conf(5) para obtener más información sobre los perfiles.
--config Cadena
Ajustes de configuración para el comando. Estos anulan los ajustes de lvm.conf(5). El argumento Cadena utiliza el mismo formato que lvm.conf(5), o puede usar la sintaxis de sección/campo. Consulte lvm.conf(5) para obtener más información sobre la configuración.
-d|--debug ...
Establece el nivel de depuración. Repita de 1 a 6 veces para aumentar el detalle de los mensajes enviados al archivo de registro y/o a syslog (si está configurado).
--devices PV
Restringe los dispositivos que son visibles y accesibles para el comando. Los dispositivos no listados parecerán faltar. Esta opción se puede repetir o acepta una lista de dispositivos separada por comas. Esto anula el archivo de dispositivos.
--devicesfile Cadena
Un archivo que lista los dispositivos que LVM debe usar. El archivo debe existir en /etc/lvm/devices/ y se gestiona con el comando lvmdevices(8). Esto anula la configuración de lvm.conf(5) devices/devicesfile y devices/use_devicesfile.
--driverloaded y|n
Si se establece en no, el comando no intentará utilizar device-mapper. Para pruebas y depuración.
-f|--file Cadena
Escribe la salida en el archivo con nombre.
-h|--help
Muestra el texto de ayuda.
--ignoreadvanced
Excluye los ajustes de configuración avanzados de la salida.
--ignorelocal
Ignora la sección local. La sección local debe definirse en el archivo lvmlocal.conf y debe contener ajustes de configuración específicos del host local que no deben copiarse a otros hosts.
--ignoreunsupported
Excluye los ajustes de configuración no compatibles de la salida. Estos ajustes se utilizan solo para fines de depuración y desarrollo, o su soporte aún no está completo y no están destinados a usarse en producción. Los tipos current y diff incluyen configuraciones no compatibles en su salida por defecto, todos los demás tipos ignoran las configuraciones no compatibles.
--journal Cadena
Registra información en el journal de systemd. Esta información es adicional a la información habilitada por la configuración log/journal de lvm.conf. command: registra información sobre el comando. output: registra la salida del comando por defecto. debug: registra la depuración completa del comando.
-l|--list
Imprime una lista de ajustes de configuración en lugar de un árbol de ajustes de configuración estructurado. Si se usa sin otras opciones, esto es lo mismo que --typeconfig list --withsummary.
--lockopt Cadena
Se utiliza para pasar opciones para casos especiales a lvmlockd. Consulte lvmlockd(8) para obtener más información.
--longhelp
Muestra el texto de ayuda largo.
--mergedconfig
Cuando el comando se ejecuta con --config y/o --commandprofile (o usando la variable de entorno LVM_COMMAND_PROFILE), --profile, o --metadataprofile, fusiona todo el contenido de la "cascada de configuración" antes de mostrarlo. Sin fusionar, solo se muestra la configuración al principio de la cascada. Consulte lvm.conf(5) para obtener más información sobre la configuración.
--metadataprofile Cadena
El perfil de metadatos a utilizar para la configuración del comando. Consulte lvm.conf(5) para obtener más información sobre los perfiles.
--nohints
No utilice el archivo de sugerencias para localizar dispositivos para los PVs. Un comando puede leer más dispositivos para encontrar PVs cuando no se usan sugerencias. El comando aún realizará la invalidación estándar del archivo de sugerencias cuando sea apropiado.
--nolocking
Deshabilita el bloqueo. Úselo con precaución, los comandos concurrentes pueden producir resultados incorrectos.
--profile Cadena
Un alias para --commandprofile o --metadataprofile, dependiendo del comando.
-q|--quiet ...
Suprime la salida y los mensajes de registro. Anula --debug y --verbose. Repita una vez para suprimir también cualquier indicación con la respuesta 'no'.

NOMBRE

lvm-config - Herramienta para gestionar la configuración de LVM

SINOPSIS

lvm-config [OPCIONES]

DESCRIPCIÓN

lvm-config es una utilidad de línea de comandos utilizada para visualizar y modificar la configuración de Logical Volume Manager (LVM) en sistemas Linux. Permite a los usuarios ver los parámetros de configuración actuales y aplicar cambios de manera controlada.

USO

El uso básico de lvm-config implica ejecutar el comando seguido de las opciones deseadas para especificar la acción a realizar (por ejemplo, leer o escribir configuración) y los parámetros a modificar.

OPCIONES

Las opciones disponibles para lvm-config incluyen, pero no se limitan a:

  • --read: Lee la configuración actual.
  • --write: Escribe una nueva configuración.
  • --set PARAMETRO=VALOR: Establece un parámetro de configuración específico.
  • --get PARAMETRO: Obtiene el valor de un parámetro de configuración específico.
  • --list: Lista todos los parámetros de configuración.
  • --help: Muestra la ayuda y sale.
  • --version: Muestra información sobre la versión y sale.

VARIABLES

lvm-config puede interactuar con varias variables de configuración de LVM, incluyendo, entre otras:

  • global/locking_type
  • global/fsck
  • devices/preferred_discover
  • devices/write_cache_state

Consulte la documentación de LVM para una lista completa de variables de configuración.

VARIABLES DE ENTORNO

No se conocen variables de entorno específicas que afecten directamente a lvm-config. Sin embargo, las variables estándar de entorno relacionadas con la configuración del sistema y los privilegios de usuario pueden ser relevantes.
