NOMBRE

ber_int_t, ber_uint_t, ber_len_t, ber_slen_t, ber_tag_t, struct berval, BerValue, BerVarray, BerElement, ber_bvfree, ber_bvecfree, ber_bvecadd, ber_bvarray_free, ber_bvarray_add, ber_bvdup, ber_dupbv, ber_bvstr, ber_bvstrdup, ber_str2bv, ber_alloc_t, ber_init, ber_init2, ber_free - Tipos y funciones de asignación LBER de OpenLDAP

BIBLIOTECA

OpenLDAP LBER (liblber, -llber)

SINOPSIS

#include <lber.h>

typedef impl_tag_t ber_tag_t;
typedef impl_int_t ber_int_t;
typedef impl_uint_t ber_uint_t;
typedef impl_len_t ber_len_t;
typedef impl_slen_t ber_slen_t;
typedef struct berval {
    ber_len_t bv_len;
    char *bv_val;
} BerValue, *BerVarray;
typedef struct berelement BerElement;

void ber_bvfree(struct berval *bv);

void ber_bvecfree(struct berval **bvec);

void ber_bvecadd(struct berval ***bvec, struct berval *bv);

void ber_bvarray_free(struct berval *bvarray);

void ber_bvarray_add(BerVarray *bvarray, BerValue *bv);

struct berval *ber_bvdup(const struct berval *bv);

struct berval *ber_dupbv(const struct berval *dst, struct berval *src);

struct berval *ber_bvstr(const char *str);

struct berval *ber_bvstrdup(const char *str);

struct berval *ber_str2bv(const char *str, ber_len_t len, int dup, struct berval *bv);

BerElement *ber_alloc_t(int options);

BerElement *ber_init(struct berval *bv);

void ber_init2(BerElement *ber, struct berval *bv, int options);

void ber_free(BerElement *ber, int freebuf);

DESCRIPCIÓN

Los siguientes son los tipos y estructuras básicos definidos para su uso con la biblioteca LBER (Lightweight BER).

ber_int_t es un entero con signo de al menos 32 bits. Comúnmente es equivalente a int. ber_uint_t es la variante sin signo de ber_int_t.

ber_len_t es un entero sin signo de al menos 32 bits utilizado para representar una longitud. Comúnmente es equivalente a un size_t. ber_slen_t es la variante con signo de ber_len_t.

ber_tag_t es un entero sin signo de al menos 32 bits utilizado para representar una etiqueta BER. Comúnmente es equivalente a un unsigned long.

Las definiciones reales de los tipos integrales impl_TYPE_t son específicas de la plataforma.

BerValue, comúnmente utilizado como struct berval, se utiliza para contener una secuencia arbitraria de octetos. bv_val apunta a bv_len octetos. bv_val no está necesariamente terminado por un octeto NULL (cero). ber_bvfree() libera un BerValue, apuntado por bv, devuelto por esta API. Si bv es NULL, la rutina no hace nada.

ber_bvecfree() libera un array de BerValues (y el array), apuntado por bvec, devuelto por esta API. Si bvec es NULL, la rutina no hace nada. ber_bvecadd() añade el puntero bv al array bvec. Se asigna espacio para el array según sea necesario. El final del array se marca con un puntero NULL.

ber_bvarray_free() libera un array de BerValues (y el array), apuntado por bvarray, devuelto por esta API. Si bvarray es NULL, la rutina no hace nada. ber_bvarray_add() añade el contenido del BerValue apuntado por bv al array bvarray. Se asigna espacio para el nuevo elemento según sea necesario. El final del array se marca con un BerValue con un campo bv_val NULL.

ber_bvdup() devuelve una copia de un BerValue. La rutina devuelve NULL en caso de error (por ejemplo, falta de memoria). El llamante debe usar ber_bvfree() para desasignar el BerValue resultante. ber_dupbv() copia un BerValue de src a dst. Si dst es NULL, se asignará un nuevo BerValue para contener la copia. La rutina devuelve NULL en caso de error, de lo contrario devuelve un puntero a la copia. Si dst es NULL, el llamante debe usar ber_bvfree() para desasignar el BerValue resultante, de lo contrario se debe usar ber_memfree() para desasignar el dst->bv_val. (La función ber_bvdup() se implementa internamente como ber_dupbv(NULL, bv). ber_bvdup() se proporciona solo por compatibilidad con un borrador caducado de la API C de LDAP; ber_dupbv() es la interfaz preferida).

ber_bvstr() devuelve un BerValue que contiene la cadena apuntada por str. ber_bvstrdup() devuelve un BerValue que contiene una copia de la cadena apuntada por str. ber_str2bv() devuelve un BerValue que contiene la cadena apuntada por str, cuya longitud puede especificarse opcionalmente en len. Si dup es distinto de cero, el BerValue contendrá una copia de str. Si len es cero, el número de bytes a copiar se determinará mediante strlen(3), de lo contrario se copiarán len bytes. Si bv es distinto de NULL, el resultado se almacenará en el BerValue dado, de lo contrario se asignará un nuevo BerValue para almacenar el resultado. NOTA: Tanto ber_bvstr() como ber_bvstrdup() se implementan como macros que utilizan ber_str2bv() en esta versión de la biblioteca.

BerElement es una estructura opaca utilizada para mantener información de estado utilizada en la codificación y decodificación. ber_alloc_t() se utiliza para crear una estructura BerElement vacía. Si se especifica LBER_USE_DER para el parámetro options, las longitudes de los datos escritos en el BerElement se codificarán en el número mínimo de octetos requeridos, de lo contrario siempre se escribirán como valores de cuatro bytes. ber_init() crea una estructura BerElement que se inicializa con una copia de los datos en su parámetro bv. ber_init2() inicializa un BerElement existente ber utilizando los datos del parámetro bv. Los datos se referencian directamente, no se copian. El parámetro options es el mismo que para ber_alloc_t(). ber_free() libera un BerElement apuntado por ber. Si ber es NULL, la rutina no hace nada. Si freebuf es cero, el búfer interno no se libera.
