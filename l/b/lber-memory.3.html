LBER_MEMORY(3) Manual de Funciones de Librería LBER_MEMORY(3)

NOMBRE

ber_memalloc, ber_memcalloc, ber_memrealloc, ber_memfree, ber_memvfree - Asignadores de memoria LBER de OpenLDAP

LIBRERÍA

OpenLDAP LBER (liblber, -llber)

SINOPSIS

#include <lber.h>

void *ber_memalloc(ber_len_t bytes);

void *ber_memcalloc(ber_len_t nelems, ber_len_t bytes);

void *ber_memrealloc(void *ptr, ber_len_t bytes);

void ber_memfree(void *ptr);

void ber_memvfree(void **vec);

DESCRIPCIÓN

Estas rutinas se utilizan para asignar/liberar memoria usada/devuelta por la librería Lightweight BER según lo requieran lber-encode(3) y lber-decode(3). ber_memalloc(), ber_memcalloc(), ber_memrealloc() y ber_memfree() se usan exactamente como las rutinas estándar malloc(3), calloc(3), realloc(3) y free(3), respectivamente. La rutina ber_memvfree() se utiliza para liberar un array asignado dinámicamente de punteros a objetos arbitrarios asignados dinámicamente.

VER TAMBIÉN

lber-decode(3), lber-encode(3), lber-types(3)
