NOMBRE

ber_get_next, ber_skip_tag, ber_peek_tag, ber_scanf, ber_get_int, ber_get_enum, ber_get_stringb, ber_get_stringa, ber_get_stringal, ber_get_stringbv, ber_get_null, ber_get_boolean, ber_get_bitstring, ber_first_element, ber_next_element - Rutinas de la biblioteca OpenLDAP LBER simplificadas de Reglas de Codificación Básica para decodificación

BIBLIOTECA

OpenLDAP LBER (liblber, -llber)

SINOPSIS

#include <lber.h>

ber_tag_t ber_get_next(Sockbuf *sb, ber_len_t *len, BerElement *ber);

ber_tag_t ber_skip_tag(BerElement *ber, ber_len_t *len);

ber_tag_t ber_peek_tag(BerElement *ber, ber_len_t *len);

ber_tag_t ber_scanf(BerElement *ber, const char *fmt, ...);

ber_tag_t ber_get_int(BerElement *ber, ber_int_t *num);

ber_tag_t ber_get_enum(BerElement *ber, ber_int_t *num);

ber_tag_t ber_get_stringb(BerElement *ber, char *buf, ber_len_t *len);

ber_tag_t ber_get_stringa(BerElement *ber, char **buf);

ber_tag_t ber_get_stringal(BerElement *ber, struct berval **bv);

ber_tag_t ber_get_stringbv(BerElement *ber, struct berval *bv, int alloc);

ber_tag_t ber_get_null(BerElement *ber);

ber_tag_t ber_get_boolean(BerElement *ber, ber_int_t *bool);

ber_tag_t ber_get_bitstringa(BerElement *ber, char **buf, ber_len_t *blen);

ber_tag_t ber_first_element(BerElement *ber, ber_len_t *len, char **cookie);

ber_tag_t ber_next_element(BerElement *ber, ber_len_t *len, const char *cookie);

DESCRIPCIÓN

Estas rutinas proporcionan una interfaz de subrutina a una implementación simplificada de las Reglas de Codificación Básica (BER) de ASN.1. La versión de BER que soportan estas rutinas es la definida para el protocolo LDAP. Las reglas de codificación son las mismas que las de BER, excepto que solo se utilizan longitudes de forma definida, y los bitstrings y octet strings siempre se codifican en forma primitiva. Esta página de manual describe las rutinas de decodificación de la biblioteca lber. Consulte lber-encode(3) para obtener detalles sobre las rutinas de codificación correspondientes. Consulte lber-types(3) para obtener información sobre tipos, asignadores y liberadores.

Normalmente, las únicas rutinas que necesitan ser llamadas por una aplicación son ber_get_next() para obtener el siguiente elemento BER y ber_scanf() para realizar la decodificación real. En algunos casos, ber_peek_tag() también puede necesitar ser llamada en uso normal. Las demás rutinas se proporcionan para aquellas aplicaciones que necesitan más control del que proporciona ber_scanf(). En general, estas rutinas devuelven la etiqueta del elemento decodificado, o LBER_ERROR si ocurrió un error.

La rutina ber_get_next() se utiliza para leer el siguiente elemento BER del Sockbuf dado, sb. Elimina y devuelve la etiqueta inicial, elimina y devuelve la longitud de todo el elemento en len, y configura ber para llamadas posteriores a ber_scanf() y similares para decodificar el elemento. Consulte lber-sockbuf(3) para obtener detalles sobre la implementación de Sockbuf del parámetro sb.

La rutina ber_scanf() se utiliza para decodificar un elemento BER de manera muy similar a como funciona scanf(3). Lee de ber, un puntero a un BerElement como el devuelto por ber_get_next(), interpreta los bytes de acuerdo con la cadena de formato fmt y almacena los resultados en sus argumentos adicionales. La cadena de formato contiene especificaciones de conversión que se utilizan para dirigir la interpretación del elemento BER. La cadena de formato puede contener los siguientes caracteres.

a
Octet string. Se debe suministrar un char **. Se asigna memoria, se llena con el contenido del octet string, se termina con nulo y se devuelve en el parámetro. El llamador debe liberar la cadena devuelta usando ber_memfree().
A
Octet string. Una variante de "a". Se debe suministrar un char **. Se asigna memoria, se llena con el contenido del octet string, se termina con nulo y se devuelve en el parámetro, a menos que el resultado sea una cadena de longitud cero; en ese caso, el arg se establece en NULL. El llamador debe liberar la cadena devuelta usando ber_memfree().
s
Octet string. Se debe suministrar un buffer char *, seguido de un puntero a un ber_len_t inicializado al tamaño del buffer. Al regresar, el octet string terminado en nulo se coloca en el buffer, y el ber_len_t se establece en el tamaño real del octet string.
O
Octet string. Se debe suministrar un struct ber_val **, que al regresar apunta a un struct berval asignado dinámicamente que contiene el octet string y su longitud. El llamador debe liberar la estructura devuelta usando ber_bvfree().
o
Octet string. Se debe suministrar un struct ber_val *, que al regresar contiene el octet string asignado dinámicamente y su longitud. El llamador debe liberar el octet string devuelto usando ber_memfree().
m
Octet string. Se debe suministrar un struct ber_val *, que al regresar contiene el octet string y su longitud. La cadena reside en memoria asignada al BerElement y no debe ser liberada por el llamador.
b
Booleano. Se debe suministrar un puntero a un ber_int_t.
e
Enumeración. Se debe suministrar un puntero a un ber_int_t.
i
Entero. Se debe suministrar un puntero a un ber_int_t.
B
Bitstring. Se debe suministrar un char **, que apuntará a los bits asignados dinámicamente, seguido de un ber_len_t *, que apuntará a la longitud (en bits) del bitstring devuelto.
n
Nulo. No se requiere ningún parámetro. El elemento simplemente se omite si se reconoce.
v
Secuencia de octet strings. Se debe suministrar un char ***, que al regresar apuntará a un array de char *'s asignado dinámicamente y terminado en nulo, que contiene los octet strings. Se devuelve NULL si la secuencia está vacía. El llamador debe liberar el array devuelto y los octet strings usando ber_memvfree().
V
Secuencia de octet strings con longitudes. Se debe suministrar un struct berval ***, que al regresar apuntará a un array de struct berval *'s asignado dinámicamente y terminado en nulo, que contiene los octet strings y sus longitudes. Se devuelve NULL si la secuencia está vacía. El llamador debe liberar las estructuras devueltas usando ber_bvecfree().
W
Secuencia de octet strings con longitudes. Se debe suministrar un BerVarray *, que al regresar apuntará a un array de struct berval asignado dinámicamente que contiene los octet strings y sus longitudes. El array está terminado por un struct berval con un puntero de cadena NULL bv_val. Se devuelve NULL si la secuencia está vacía. El llamador debe liberar las estructuras devueltas usando ber_bvarray_free().
M
Secuencia de octet strings con longitudes. Esta es una forma generalizada de los tres formatos anteriores. Se debe suministrar un void ** (ptr), seguido de un ber_len_t * (len) y un ber_len_t (off). Al regresar (ptr) apuntará a un array asignado dinámicamente cuyos elementos son todos del tamaño (*len). Se rellenará un struct berval comenzando en el offset (off) en cada elemento. Las cadenas de cada struct berval residen en memoria asignada al BerElement y no deben ser liberadas por el llamador. El array está terminado por un struct berval con un puntero de cadena NU
