lber-sockbuf(3)

Paquete: libldap

Licencias: custom

LBER_SOCKBUF(3) Manual de funciones de biblioteca LBER_SOCKBUF(3)

NOMBRE

ber_sockbuf_alloc, ber_sockbuf_free, ber_sockbuf_ctrl, ber_sockbuf_add_io, ber_sockbuf_remove_io, Sockbuf_IO - Infraestructura de E/S LBER de OpenLDAP

BIBLIOTECA

OpenLDAP LBER (liblber, -llber)

SINOPSIS

#include <lber.h>

Sockbuf *ber_sockbuf_alloc( void );

void ber_sockbuf_free( Sockbuf *sb );

int ber_sockbuf_ctrl( Sockbuf *sb, int opt, void *arg );

int ber_sockbuf_add_io( Sockbuf *sb, Sockbuf_IO *sbio, int layer, void *arg );

int ber_sockbuf_remove_io( Sockbuf *sb, Sockbuf_IO *sbio, int layer );

typedef struct sockbuf_io_desc {
int sbiod_level;
Sockbuf *sbiod_sb;
Sockbuf_IO *sbiod_io;
void *sbiod_pvt;
struct sockbuf_io_desc *sbiod_next;
} Sockbuf_IO_Desc;
typedef struct sockbuf_io {
int (*sbi_setup)( Sockbuf_IO_Desc *sbiod, void *arg );
int (*sbi_remove)( Sockbuf_IO_Desc *sbiod );
int (*sbi_ctrl)( Sockbuf_IO_Desc *sbiod, int opt, void *arg );
ber_slen_t (*sbi_read)( Sockbuf_IO_Desc *sbiod, void *buf, ber_len_t len );
ber_slen_t (*sbi_write)( Sockbuf_IO_Desc *sbiod, void *buf, ber_len_t len );
int (*sbi_close)( Sockbuf_IO_Desc *sbiod );
} Sockbuf_IO;

DESCRIPCION

Estas rutinas se utilizan para gestionar las operaciones de E/S de bajo nivel realizadas por la biblioteca Lightweight BER. Son llamadas implícitamente por otras bibliotecas y generalmente no necesitan ser llamadas directamente desde aplicaciones. El marco de E/S está modularizado y se pueden admitir nuevas capas de transporte definiendo adecuadamente una estructura Sockbuf_IO e instalándola en un Sockbuf existente. Las estructuras Sockbuf se asignan y liberan mediante ber_sockbuf_alloc() y ber_sockbuf_free(), respectivamente. La función ber_sockbuf_ctrl() se utiliza para obtener y establecer opciones relacionadas con un Sockbuf o con una capa de E/S específica del Sockbuf. Las funciones ber_sockbuf_add_io() y ber_sockbuf_remove_io() se utilizan para agregar y eliminar capas de E/S específicas en un Sockbuf.

Las opciones para ber_sockbuf_ctrl() incluyen:

LBER_SB_OPT_HAS_IO
Toma un argumento Sockbuf_IO * y devuelve 1 si el manejador dado está instalado en el Sockbuf, de lo contrario devuelve 0.
LBER_SB_OPT_GET_FD
Recupera el descriptor de archivo asociado al Sockbuf; arg debe ser un ber_socket_t *. El valor de retorno será 1 si había un descriptor válido, -1 en caso contrario.
LBER_SB_OPT_SET_FD
Establece el descriptor de archivo del Sockbuf al descriptor apuntado por arg; arg debe ser un ber_socket_t *. El valor de retorno siempre será 1.
LBER_SB_OPT_SET_NONBLOCK
Alterna el estado de no bloqueo del descriptor de archivo asociado al Sockbuf. arg debe ser NULL para deshabilitar y no NULL para habilitar el estado de no bloqueo. El valor de retorno será 1 para éxito, -1 en caso contrario.
LBER_SB_OPT_DRAIN
Vacía (lee y descarta) toda la entrada disponible en el Sockbuf. El valor de retorno será 1.
LBER_SB_OPT_NEEDS_READ
Devuelve un valor distinto de cero si hay entrada esperando ser leída.
LBER_SB_OPT_NEEDS_WRITE
Devuelve un valor distinto de cero si el Sockbuf está listo para ser escrito.
LBER_SB_OPT_GET_MAX_INCOMING
Devuelve el tamaño máximo permitido de un mensaje entrante; arg debe ser un ber_len_t *. El valor de retorno será 1.
LBER_SB_OPT_SET_MAX_INCOMING
Establece el tamaño máximo permitido de un mensaje entrante; arg debe ser un ber_len_t *. El valor de retorno será 1.

Las opciones no incluidas en esta lista se pasarán a cada manejador de Sockbuf_IO en orden hasta que uno de ellos las procese. Si la opción no es manejada, ber_sockbuf_ctrl() devolverá 0.

Se pueden apilar múltiples manejadores de Sockbuf_IO en múltiples capas para proporcionar diversas funcionalidades. Las capas definidas actualmente incluyen:

LBER_SBIOD_LEVEL_PROVIDER
la capa más baja, hablando directamente con una red
LBER_SBIOD_LEVEL_TRANSPORT
una capa intermedia
LBER_SBIOD_LEVEL_APPLICATION
una capa superior

Los manejadores Sockbuf_IO actualmente definidos en liblber incluyen:

ber_sockbuf_io_tcp
El proveedor predeterminado orientado a flujos
ber_sockbuf_io_fd
Un proveedor orientado a flujos para sockets IPC locales
ber_sockbuf_io_dgram
Un proveedor orientado a datagramas. Este manejador solo está presente si la biblioteca liblber fue compilada con LDAP_CONNECTIONLESS definido.
ber_sockbuf_io_readahead
Una capa de búfer, generalmente utilizada con un proveedor de datagramas para ocultar la semántica de datagramas a las capas superiores.
ber_sockbuf_io_debug
Un manejador genérico que muestra volcados hexadecimales de todo el tráfico. Este manejador puede insertarse varias veces en capas arbitrarias para mostrar el flujo de datos entre otros manejadores.

Pueden estar presentes manejadores adicionales en libldap si se activó el soporte para ellos:

ldap_pvt_sockbuf_io_sasl
Un manejador de capa de aplicación para codificación/decodificación SASL.
sb_tls_sbio
Un manejador de capa de transporte para codificación/decodificación SSL/TLS. Tenga en cuenta que este manejador es privado de la biblioteca y no se expone en la API.

Los manejadores proporcionados son instanciados implícitamente por libldap, y las aplicaciones generalmente no necesitarán manipularlos directamente.
