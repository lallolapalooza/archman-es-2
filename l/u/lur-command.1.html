NOMBRE

lur-command - lista, empareja y desempareja dispositivos Logitech Unifying

SINOPSIS

lur-command find
lur-command list <dispositivo>
lur-command open <dispositivo>
lur-command close <dispositivo>
lur-command disconnect <índice> <dispositivo>

DESCRIPCIÓN

Opciones comunes

-h
muestra un breve mensaje de ayuda.

Listar receptores

find
lista todos los receptores identificados en el sistema (escaneando dispositivos /dev/hidrawn).

Listar dispositivos conectados

list <dispositivo>
lista los dispositivos conectados al dispositivo receptor dado.

Emparejar dispositivos

open <dispositivo>
abre el receptor dado para emparejamiento, durante 30s.

Cerrar un receptor

close <dispositivo>
cierra el receptor dado, si está actualmente abierto para emparejamiento.

Desconectar un dispositivo

disconnect <índice> <dispositivo>
desconecta el dispositivo que coincide con el índice dado del receptor dado. El índice es tal como lo determina el comando list.
