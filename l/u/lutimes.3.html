futimes(3) Manual de funciones de biblioteca futimes(3)

NOMBRE

futimes, lutimes - cambiar las marcas de tiempo de un archivo

BIBLIOTECA

Biblioteca C estándar (libc, -lc)

SINOPSIS

#include <sys/time.h>
int futimes(int fd, const struct timeval tv[2]);
int lutimes(const char *path, const struct timeval tv[2]);
Requisitos de macros de prueba de características para glibc (ver feature_test_macros(7)):

futimes(), lutimes():

    Desde glibc 2.19:
        _DEFAULT_SOURCE
    glibc 2.19 y anteriores:
        _BSD_SOURCE

DESCRIPCIÓN

futimes() cambia las horas de acceso y modificación de un archivo de la misma manera que utimes(2), con la diferencia de que el archivo cuyas marcas de tiempo se van a cambiar se especifica a través de un descriptor de archivo, fd, en lugar de un nombre de ruta.

lutimes() cambia las horas de acceso y modificación de un archivo de la misma manera que utimes(2), con la diferencia de que si path se refiere a un enlace simbólico, el enlace no se resuelve: en su lugar, se cambian las marcas de tiempo del enlace simbólico.

VALOR DE RETORNO

En caso de éxito, se devuelve cero. En caso de error, se devuelve -1 y errno se establece para indicar el error.

ERRORES

Los errores son los de utimes(2), con las siguientes adiciones para futimes():

EBADF
fd no es un descriptor de archivo válido.
ENOSYS
No se pudo acceder al sistema de archivos /proc.

El siguiente error adicional puede ocurrir para lutimes():

ENOSYS
El kernel no admite esta llamada; se requiere Linux 2.6.22 o posterior.

ATRIBUTOS

Para obtener una explicación de los términos utilizados en esta sección, consulte attributes(7).

Interfaz Atributo Valor
futimes (), lutimes () Seguridad de hilos MT-Safe

ESTÁNDARES

Linux, BSD.

HISTORIA

futimes()
glibc 2.3.
lutimes()
glibc 2.6.

NOTAS

lutimes() se implementa utilizando la llamada al sistema utimensat(2).

VER TAMBIÉN

utime(2), utimensat(2), symlink(7)
