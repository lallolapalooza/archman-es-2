NOMBRE

lutris - plataforma de preservación de videojuegos

DESCRIPCIÓN

Uso:

lutris [OPCIÓN] URI

Ejecuta un juego directamente añadiendo el parámetro lutris:rungame/identificador-juego.
Si varios juegos comparten el mismo identificador, puedes usar el ID numérico (mostrado al ejecutar lutris --list-games) y añadir lutris:rungameid/id-numérico.
Para instalar un juego, añade lutris:install/identificador-juego.

Opciones de ayuda:

-h, --help
Muestra las opciones de ayuda
--help-all
Muestra todas las opciones de ayuda
--help-gapplication
Muestra las opciones de GApplication
--help-gtk
Muestra las opciones de GTK+

Opciones de aplicación:

-v, --version
Imprime la versión de Lutris y sale
-d, --debug
Muestra mensajes de depuración
-i, --install
Instala un juego desde un archivo yml
-b, --output-script
Genera un script bash para ejecutar un juego sin el cliente
-e, --exec
Ejecuta un programa con el entorno de ejecución de Lutris
-l, --list-games
Lista todos los juegos en la base de datos
-o, --installed
Lista solo los juegos instalados
-s, --list-steam-games
Lista los juegos de Steam disponibles
--list-steam-folders
Lista todas las carpetas de biblioteca de Steam conocidas
-j, --json
Muestra la lista de juegos en formato JSON
--reinstall
Reinstala el juego
--submit-issue
Envía un problema
--display=DISPLAY
Pantalla X a utilizar
