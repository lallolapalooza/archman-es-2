LUA(1) Manual de comandos generales LUA(1)

NOMBRE

lua - Intérprete de Lua

SINOPSIS

lua [ opciones ] [ script [ args ] ]

DESCRIPCIÓN

lua es el intérprete independiente de Lua. Carga y ejecuta programas de Lua, ya sea en forma de código fuente textual o en forma binaria precompilada. (Los binarios precompilados son generados por luac, el compilador de Lua). lua puede ser utilizado como intérprete por lotes y también de forma interactiva.

Las opciones dadas se manejan en orden y luego se carga y ejecuta el programa de Lua en el archivo script. Los args dados están disponibles para script como cadenas de texto en una tabla global llamada arg. Si no se dan opciones ni argumentos, se asume -v -i cuando la entrada estándar es una terminal; de lo contrario, se asume -.

En modo interactivo, lua solicita al usuario, lee líneas de la entrada estándar y las ejecuta a medida que se leen. Si una línea no contiene una declaración completa, se muestra un prompt secundario y se leen líneas hasta que se forma una declaración completa o se encuentra un error de sintaxis. Si una línea comienza con '=', entonces lua evalúa y muestra los valores de las expresiones en el resto de la línea.

Al principio, incluso antes de manejar la línea de comandos, lua comprueba el contenido de las variables de entorno LUA_INIT_5_2 o LUA_INIT, en ese orden. Si el contenido tiene el formato '@nombre_archivo', entonces se ejecuta nombre_archivo. De lo contrario, se asume que la cadena es una declaración de Lua y se ejecuta.

OPCIONES

-e stat
ejecuta la declaración stat.
-i
entra en modo interactivo después de ejecutar script.
-l nombre
ejecuta el equivalente de nombre=require('nombre') antes de ejecutar script.
-v
muestra información de la versión.
-E
ignora las variables de entorno.
--
deja de manejar opciones.
-
deja de manejar opciones y ejecuta la entrada estándar como un archivo.

VER TAMBIÉN

luac(1)
La documentación en lua.org, especialmente la sección 7 del manual de referencia.

DIAGNÓSTICOS

Los mensajes de error deben ser autoexplicativos.
