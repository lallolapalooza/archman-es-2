NOMBRE

lua - Intérprete de Lua

SINOPSIS

lua [ opciones ] [ script [ argumentos ] ]

DESCRIPCIÓN

lua es el intérprete independiente de Lua. Carga y ejecuta programas Lua, ya sea en forma de código fuente textual o en forma binaria precompilada. (Los binarios precompilados son generados por luac, el compilador de Lua.) lua puede ser usado como intérprete por lotes y también interactivamente.

Después de procesar las opciones, el programa Lua en el archivo script se carga y se ejecuta. Los argumentos están disponibles para script como cadenas en una tabla global llamada arg y también como argumentos para su función principal. Cuando se llama sin argumentos, lua se comporta como lua -v -i si la entrada estándar es una terminal, y como lua - en caso contrario.

En modo interactivo, lua solicita al usuario, lee líneas de la entrada estándar y las ejecuta a medida que se leen. Si la línea contiene una expresión, entonces la línea se evalúa y se imprime el resultado. Si una línea no contiene una instrucción completa, entonces se muestra un prompt secundario y se leen líneas hasta que se forma una instrucción completa o se encuentra un error de sintaxis.

Antes de procesar las opciones de la línea de comandos y los scripts, lua verifica el contenido de las variables de entorno LUA_INIT_5_4 y LUA_INIT, en ese orden. Si el contenido tiene el formato '@nombre_archivo', entonces se ejecuta nombre_archivo. De lo contrario, se asume que el contenido es una instrucción Lua y se ejecuta. Cuando LUA_INIT_5_4 está definida, se ignora LUA_INIT.

OPCIONES

-e est
ejecuta la instrucción est.
-i
entra en modo interactivo después de ejecutar script.
-l mod
requiere la biblioteca mod en la variable global mod.
-l g=mod
requiere la biblioteca mod en la variable global g.
-v
muestra información de la versión.
-E
ignora las variables de entorno.
-W
activa las advertencias.
--
deja de procesar opciones.
-
deja de procesar opciones y ejecuta la entrada estándar como un archivo.

VARIABLES DE ENTORNO

Las siguientes variables de entorno afectan la ejecución de lua. Cuando están definidas, las variantes específicas de la versión tienen prioridad y se ignoran las variantes neutras de la versión.

LUA_INIT, LUA_INIT_5_4
Código a ejecutar antes de las opciones de línea de comandos y los scripts.
LUA_PATH, LUA_PATH_5_4
Valor inicial de package.path, la ruta utilizada por require para buscar cargadores de Lua.
LUA_CPATH, LUA_CPATH_5_4
Valor inicial de package.cpath, la ruta utilizada por require para buscar cargadores de C.

ESTADO DE SALIDA

Si un script llama a os.exit, entonces lua sale con el estado de salida dado. De lo contrario, lua sale con EXIT_SUCCESS (0 en sistemas POSIX) si no hubo errores y con EXIT_FAILURE (1 en sistemas POSIX) si hubo errores. Los errores que se producen en modo interactivo no provocan salidas.

DIAGNÓSTICO

Los mensajes de error deberían ser autoexplicativos.
