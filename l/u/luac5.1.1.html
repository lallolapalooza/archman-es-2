LUAC(1) Manual de comandos generales LUAC(1)

NOMBRE

luac - Compilador de Lua

SINOPSIS

luac [ opciones ] [ archivos ]

DESCRIPCIÓN

luac es el compilador de Lua. Traduce programas escritos en el lenguaje de programación Lua a archivos binarios que posteriormente pueden ser cargados y ejecutados.

Las principales ventajas de precompilar fragmentos son: carga más rápida, protección del código fuente contra cambios accidentales por parte del usuario y verificación de sintaxis fuera de línea.

La precompilación no implica una ejecución más rápida, ya que en Lua los fragmentos siempre se compilan a códigos de bytes antes de ser ejecutados. luac simplemente permite que esos códigos de bytes se guarden en un archivo para su ejecución posterior.

Los fragmentos precompilados no son necesariamente más pequeños que el código fuente correspondiente. El objetivo principal de la precompilación es una carga más rápida.

Los archivos binarios creados por luac solo son portátiles entre arquitecturas con el mismo tamaño de palabra y orden de bytes.

luac produce un único archivo de salida que contiene los códigos de bytes de todos los archivos fuente dados. Por defecto, el archivo de salida se llama luac.out, pero puedes cambiarlo con la opción -o.

En la línea de comandos, puedes mezclar archivos de texto que contienen código fuente de Lua y archivos binarios que contienen fragmentos precompilados. Esto es útil para combinar varios fragmentos precompilados, incluso de plataformas diferentes (pero compatibles), en un único fragmento precompilado.

Puedes usar '-' para indicar la entrada estándar como un archivo fuente y '--' para señalar el final de las opciones (es decir, todos los argumentos restantes se tratarán como archivos, incluso si empiezan con '-').

Es probable que el formato interno de los archivos binarios producidos por luac cambie cuando se publique una nueva versión de Lua. Por lo tanto, guarda los archivos fuente de todos los programas de Lua que precompiles.

OPCIONES

Las opciones deben estar separadas.

-l
produce una lista del código de bytes compilado para la máquina virtual de Lua. Listar los códigos de bytes es útil para aprender sobre la máquina virtual de Lua. Si no se dan archivos, luac carga luac.out y lista su contenido.
-o archivo
salida a archivo, en lugar del predeterminado luac.out. (Puedes usar '-' para la salida estándar, pero no en plataformas que abren la salida estándar en modo texto). El archivo de salida puede ser un archivo fuente porque todos los archivos se cargan antes de que se escriba el archivo de salida. Ten cuidado de no sobrescribir archivos valiosos.
-p
carga archivos pero no genera ningún archivo de salida. Se usa principalmente para la verificación de sintaxis y para probar fragmentos precompilados: los archivos corruptos probablemente generarán errores al ser cargados. Lua siempre realiza una prueba de integridad exhaustiva en los fragmentos precompilados. El código de bytes que pasa esta prueba es completamente seguro, en el sentido de que no romperá el intérprete. Sin embargo, no hay garantía de que dicho código haga algo sensato. (No se pueden dar garantías, ya que el problema de la parada es irresoluble). Si no se dan archivos, luac carga luac.out y prueba su contenido. No se muestran mensajes si el archivo pasa la prueba de integridad.
-s
elimina la información de depuración antes de escribir el archivo de salida. Esto ahorra algo de espacio en fragmentos muy grandes, pero si ocurren errores al ejecutar un fragmento depurado, los mensajes de error pueden no contener toda la información que suelen tener. Por ejemplo, se pierden los números de línea y los nombres de las variables locales.
-v
muestra información de la versión.
