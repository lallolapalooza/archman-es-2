LUAOTFLOAD-TOOL(1) procesamiento de texto LUAOTFLOAD-TOOL(1)

NOMBRE

luaotfload-tool - genera y consulta la base de datos de nombres de fuentes de Luaotfload

SINOPSIS

luaotfload-tool [ -bcDfFiIlLnpqRSuvVhw ]

luaotfload-tool --update [ --force ] [ --quiet ] [ --verbose ]
[ --prefer-texmf ] [ --dry-run ] [ --formats=[+|-]EXTENSIONS ] [ --no-compress ] [ --no-strip ] [ --local ] [ --max-fonts=N ]
luaotfload-tool --find=NOMBRE_FUENTE [ --fuzzy ] [ --info ] [ --inspect ]
[ --no-reload ]

luaotfload-tool --flush-lookups

luaotfload-tool --cache=DIRECTIVA

luaotfload-tool --list=CRITERIO[:VALOR] [ --fields=C1,C2,...,Cn ]

luaotfload-tool --bisect=DIRECTIVA

luaotfload-tool --help

luaotfload-tool --version

luaotfload-tool --show-blacklist

luaotfload-tool --diagnose=CHEQUEO

luaotfload-tool --conf=ARCHIVO --dumpconf

DESCRIPCIÓN

luaotfload-tool accede a la base de datos de nombres de fuentes que es requerida por el paquete Luaotfload. Hay dos modos generales: update y query.

  • update: actualiza la base de datos o la reconstruye por completo;
  • query: resuelve un nombre de fuente o muestra coincidencias cercanas.

OPCIONES

modo update

--update, -u
Actualiza la base de datos; indexa fuentes nuevas.
--force, -f
Fuerza la reconstrucción de la base de datos; reindexa todas las fuentes.
--local, -L
Incluye archivos de fuentes en $PWD. Esta opción provocará que grandes partes de la base de datos se reconstruyan. Por lo tanto, es bastante ineficiente. Además, si se encuentran archivos de fuentes locales, se evita que la base de datos se guarde en disco, por lo que las fuentes locales deben ser analizadas con cada invocación de luaotfload-tool.
--no-reload, -n
Suprime las actualizaciones automáticas de la base de datos (por ejemplo, cuando --find recibe un nombre desconocido).
--no-compress, -c
No filtra la versión de texto plano del índice de fuentes a través de gzip. Útil para depurar si tu editor está compilado sin zlib.
--prefer-texmf, -p
Organiza la base de datos de nombres de archivo de manera que prefiera las fuentes en el árbol de TEXMF sobre las fuentes del sistema si están instaladas en ambos.
--formats=EXTENSIONES
Extensiones de los archivos de fuentes a indexar. Donde EXTENSIONES es una lista separada por comas de extensiones de archivo soportadas (otf, ttf, ttc). Si la lista está prefijada con un signo +, la lista dada se añade a la actualmente activa; - resta. Por defecto: otf,ttf,ttc. Ejemplos:
1.
--formats=-ttc,ttf omitiría las fuentes TrueType y las colecciones de fuentes;
2.
--formats=otf indexaría solo archivos OpenType;
3.
--formats=+afm incluye archivos Postscript binarios acompañados de un archivo AFM.

modo query

--find=NOMBRE
Resuelve un nombre de fuente; esto busca <nombre> en la base de datos e imprime el nombre del archivo al que se mapea. --find también entiende la sintaxis de solicitud, es decir, --find=file:foo.otf comprueba si foo.otf está indexado.
--fuzzy, -F
Muestra coincidencias aproximadas del nombre del archivo si la búsqueda no tuvo éxito (requiere --find).
--info, -i
Muestra información básica de un archivo de fuente resuelto (requiere --find).
--inspect, -I
Muestra información detallada cargando la fuente y analizando la tabla de fuentes; ¡muy lento! Para el significado de los campos devueltos, consulta la documentación de LuaTeX. (requiere --find).
--list=CRITERIO
Muestra entradas, donde CRITERIO es uno de los siguientes:
1.
el carácter *, seleccionando todas las entradas;
2.
un campo de una entrada de la base de datos, por ejemplo version o format*, según el cual se ordenará la salida. La información en una base de datos sin despojar (ver la opción --no-strip arriba) está anidada: los subcampos de un registro se pueden abordar usando el separador ->, por ejemplo, file->location, style->units_per_em, o names->sanitized->english->prefmodifiers. Nota: la sintaxis del shell requiere que los argumentos que contienen -> estén debidamente entrecomillados.
3.
una expresión de la forma campo:valor para limitar la salida a las entradas cuyo campo coincida con valor. El valor puede contener * para hacer coincidir un número arbitrario de caracteres.

Por ejemplo, para mostrar nombres de archivo y versiones correspondientes, ordenados por el formato de fuente:

./luaotfload-tool.lua --list="format" --fields="file->base,version"

Esto imprime:

otf latinmodern-math.otf  Version 1.958
otf lmromancaps10-oblique.otf 2.004
otf lmmono8-regular.otf 2.004
otf lmmonoproplt10-bold.otf 2.004
otf lmsans10-oblique.otf  2.004
otf lmromanslant8-regular.otf 2.004
otf lmroman12-italic.otf  2.004
otf lmsansdemicond10-oblique.otf  2.004
...
--fields=CAMPOS
Lista de campos separada por comas que deben imprimirse. La información en una base de datos sin despojar (ver la opción --no-strip arriba) está anidada: los subcampos de un registro se pueden abordar usando el separador ->, por ejemplo, file->location, style->units_per_em, o names->sanitized->english->subfamily. El valor por defecto es plainname,version*. (Solo significativo con --list).

cachés de fuentes y búsquedas

--flush-lookups
Borra la caché de nombres de fuentes (experimental).
--cache=DIRECTIVA
Control de caché, donde DIRECTIVA es una de las siguientes:
1.
purge -> elimina archivos Lua de la caché;
2.
erase -> elimina archivos Lua y Luc de la caché;
3.
show -> imprime estadísticas.

métodos de depuración

--show-blacklist, -b
Muestra archivos en lista negra (no directorios).
--dry-run, -D
No carga fuentes al actualizar la base de datos; solo escanea directorios. (Para depurar problemas relacionados con el sistema de archivos.)
--no-strip
No elimina información redundante después de construir la base de datos. Advertencia: esto aumentará el índice a aproximadamente dos o tres veces el tamaño normal.
--max-fonts=<

luaotfload-tool(1) — Arch Linux

NAME

luaotfload-tool - tool for managing the Luaotfload font database

SYNOPSIS

luaotfload-tool [OPTION…]

DESCRIPTION

The luaotfload-tool is a command-line utility for managing the Luaotfload font database. It can be used to update the database, perform bisection to track down problematic fonts, and to diagnose issues with the font loading mechanism.

updating

The database needs to be updated whenever new fonts are installed or removed, or when font configuration files are changed. The update process scans the relevant directories of the TeX distribution and builds a database of available fonts. The database is stored in a compressed Lua format and is used by Luaotfload to quickly find font files.

--update
Update the Luaotfload font database. This option scans the configured TeXMF directories for new or removed fonts and rebuilds the database accordingly. This may take a while, depending on the size of your font collection.
--force
Force an update of the font database, even if no changes are detected. This is useful if you suspect the database may be corrupted or out of sync.
--rebuild
Rebuild the font database from scratch. This option is similar to “update” but ensures that all existing font information is discarded before rebuilding. Use this if you encounter persistent issues with font loading.
--jobs=N
Process at most N font files, including fonts already indexed in the count.
--bisect=DIRECTIVE
Bisection of the font database. This mode is intended as assistance in debugging the Luatex engine, especially when tracking memleaks or buggy fonts.

DIRECTIVE can be one of the following:

1.
run -> Make luaotfload-tool respect the bisection progress when running. Combined with --update and possibly --force this will only process the files from the start up until the pivot and ignore the rest.
2.
start -> Start bisection: create a bisection state file and initialize the low, high, and pivot indices.
3.
stop -> Terminate the current bisection session by deleting the state file.
4.
good | bad -> Mark the section processed last as “good” or “bad”, respectively. The next bisection step will continue with the bad section.
5.
status -> Print status information about the current bisection session. Hint: Use with higher verbosity settings for more output.

A bisection session is initiated by issuing the start directive. This sets the pivot to the middle of the list of available font files. Now run luaotfload-tool with the --update flag set as well as --bisect=run: only the fonts up to the pivot will be considered. If that task exhibited the issue you are tracking, then tell Luaotfload using --bisect=bad. The next step of --bisect=run will continue bisection with the part of the files below the pivot. Likewise, issue --bisect=good in order to continue with the fonts above the pivot, assuming the tested part of the list did not trigger the bug.

Once the culprit font is tracked down, good or bad will have no effect anymore. run will always end up processing the single font file that was left. Use --bisect=stop to clear the bisection state.

miscellaneous

--verbose=N, -v
Set verbosity level to n or the number of repetitions of -v.
--quiet
No verbose output (log level set to zero).
--log=CHANNEL
Redirect log output (for database troubleshooting), where CHANNEL can be
1.
stdout -> all output will be dumped to the terminal (default); or
2.
file -> write to a file to the temporary directory (the name will be chosen automatically.
--version, -V
Show version numbers of components as well as some basic information and exit.
--help, -h
Show help message and exit.
--diagnose=CHECK
Run the diagnostic procedure CHECK. Available procedures are:
1.
files -> check Luaotfload files for modifications;
2.
permissions -> check permissions of cache directories and files;
3.
environment -> print relevant
environment and kpse variables;
4.
repository -> check the git repository for new releases,
5.
index -> check database, display information about it.

Procedures can be chained by concatenating with commas, e.g. --diagnose=files,permissions. Specify thorough to run all checks.

--conf=FILE
Read the configuration from FILE. See luaotfload.conf(%) for documentation concerning the format and available options.
--dumpconf
Print the currently active configuration; the output can be saved to a file and used for bootstrapping a custom configuration files.
--aliases
Dump the font name database as a kpathsea aliases file. This option is experimental and might go away.

FILES

The font name database is usually located in the directory texmf-var/luatex-cache/generic/names/ ($TEXMFCACHE as set in texmf.cnf) of your TeX Live distribution as a zlib-compressed file luaotfload-names.lua.gz. The experimental lookup cache will be created as luaotfload-lookup-cache.lua in the same directory. These Lua tables are not used directly by Luaotfload, though. Instead, they are compiled to Lua bytecode which is written to corresponding files with the extension .luc in the same directory. When modifying the files by hand keep in mind that only if the bytecode files are missing will Luaotfload use the plain version instead. Both kinds of files are safe to delete, at the cost of regenerating them with the next run of LuaTeX.
