LUAKIT(1) Comandos de usuario LUAKIT(1)

NOMBRE

Luakit - Framework de navegador rápido, pequeño, basado en WebKit, extensible con Lua.

SINOPSIS

luakit [OPCIÓN] [URI]

DESCRIPCIÓN

Luakit es un framework de navegador altamente configurable, basado en el motor de contenido web WebKit y el toolkit GTK+. Es muy rápido, extensible con Lua y tiene licencia GNU GPLv3. Está dirigido principalmente a usuarios avanzados, desarrolladores y cualquier persona que tenga demasiado tiempo libre y quiera tener un control detallado sobre el comportamiento y la interfaz de su navegador web.

Modos

Luakit puede ejecutarse en varios modos, que especifican cómo el usuario interactúa con el navegador.

Modo Normal
Este es el modo predeterminado cuando se inicia Luakit. Puede cargar URIs, abrir pestañas y ventanas, acceder a otros modos, etc.
Modo Todo
Modo meta especial en el que los enlaces están presentes en todos los modos.
Modo Inserción
Al seleccionar campos de formulario, Luakit entrará en modo de inserción, lo que le permitirá escribir texto en los campos de formulario sin activar accidentalmente los enlaces del modo normal.
Modo Pasar
Luakit pasará cada evento de teclado al WebView hasta que el usuario presione Escape. Esto es útil para usar atajos de páginas web.
Modo Comando
Ejecuta comandos. Cada acción en Luakit es un comando, por lo que básicamente puede hacer cualquier cosa desde allí.
Modo Lua
Ejecuta comandos Lua arbitrarios dentro del entorno de Luakit.

Scripts de usuario

Luakit es altamente extensible con scripts de usuario escritos en Lua. Estos scripts pueden proporcionar modos adicionales. Algunos están integrados por defecto. Necesitará cargar el script de usuario para usar sus funciones. Consulte la sección CONFIGURACIÓN para obtener más detalles.

OPCIONES

Opciones de ayuda

-h, --help
Mostrar opciones de ayuda.
--help-all
Mostrar todas las opciones de ayuda.
--help-gtk
Mostrar opciones de ayuda de GTK+.

Opciones de aplicación

-k, --check
Comprobar el archivo de configuración y salir.
-c, --config=ARCHIVO
Archivo de configuración a utilizar.
-n, --nonblock
Ejecutar Luakit en segundo plano (fork).
-U, --nounique
Ignorar enlaces de libunique.
-u, --uri=URI
URI(s) a cargar al inicio.
-v, --verbose
Imprimir salida de depuración.
-V, --version
Imprimir versión y salir.
--display=DISPLAY
Pantalla X a utilizar.

COMBINACIONES DE TECLAS

Luakit es totalmente utilizable con el teclado. Las combinaciones predeterminadas deberían resultar familiares para los usuarios de Emacs y Vim; sin embargo, muchos atajos de teclado y ratón se comparten con navegadores web populares.

Al presionar : se abrirá la línea de comandos. Puede introducir comandos desde allí. Puede ver la lista actual de combinaciones en la página de ayuda de Luakit con el comando

:help

comando.

Algunas combinaciones tienen una versión en mayúscula que se comportará de manera un poco diferente. Algunas vienen con scripts de usuario, por lo que deberá tener el script de usuario apropiado cargado para usarlo. A continuación, se incluye una lista de algunas combinaciones predeterminadas notables.

ZZ
Salir y guardar la sesión.
ZQ
Salir sin guardar la sesión.
o, O
Abrir URIs especificadas. Si es en mayúsculas, editar la URI actual.
t, T
Abrir URIs especificadas en una nueva pestaña. Si es en mayúsculas, editar la URI actual.
w, W
Abrir URIs especificadas en una nueva ventana. Si es en mayúsculas, editar la URI actual.

<Izquierda>, <Abajo>, <Arriba>, <Derecha>
h, j, k, l

Desplazar la página vertical y horizontalmente.

<Inicio>, <Fin>
gg, G

Ir al principio / final de la página.
[contador]%
Ir al [contador] por ciento de la página.
f, F
Entrar en modo de seguimiento. Usar números o texto para abrir los enlaces correspondientes. Usar las flechas para navegar entre los enlaces. Si es en mayúsculas, abrir en una nueva pestaña. Requiere el script de usuario follow.
i
Entrar en modo de inserción. En algunos casos, los campos de formulario pueden no recibir caracteres; presione una tecla de flecha para insertar caracteres correctamente.
gi
Entrar en modo de inserción en el primer campo de formulario. Requiere el script de usuario go_input.
<F11>
Alternar pantalla completa.
+, -
Cambiar el nivel de zoom.
=
Restaurar nivel de zoom.
p, P
Abrir URI desde el portapapeles. Si es en mayúsculas, abrir en una nueva pestaña.
y
Copiar la URI actual al portapapeles.
<Ctrl>x, <Ctrl>a
Decrementa / incrementa el último número en la URI. Esto es útil para hilos de foros o cualquier sitio web ordenado.
H, L
Ir atrás / adelante en el historial del navegador.

<Ctrl><Shift><Tab>, <Ctrl><Tab>
<Ctrl><PageDown>, <Ctrl><PageUp>
gT, gt

Ir a la pestaña anterior / siguiente.
<Alt>[0-9]
Ir a la pestaña #, donde # está entre 0 y 9.
<, >
Reordenar pestañas. Requiere el script de usuario taborder.
[contador]d
Cerrar [contador] pestañas.
u
Restaurar la última pestaña cerrada.
gy
Duplicar la pestaña actual.
gh, gH
Abrir página de inicio. Si es en mayúsculas, abrir en una nueva pestaña.
r, R
Recargar página actual. Si es en mayúsculas, omitir caché.
<Ctrl>c
Detener la carga de la página actual.
<Ctrl>z
Entrar en modo de pasar. Usar ESC para volver al modo normal.
M[a-zA-Z0-9]
Asociar la URI actual con la marca rápida #, donde # es una letra ASCII o un dígito. Requiere el script de usuario quickmarks.
go[a-zA-Z0-9], gn[a-zA-Z0-9], gw[a-zA-Z0-9]
Abrir la marca rápida especificada en la pestaña actual / nueva pestaña / nueva ventana. Requiere el script de usuario quickmarks.
B
Añadir la URI actual a los marcadores.
gb, gB

Abrir la página de marcadores en la pestaña actual / nueva pestaña.

KEYBINDINGS

All bindings are defined in the binds.lua file. They are stored in tables called modes. The following is a list of bindings which are set by default.

<C-o>
Open bookmarks manager. If uppercase, open in new tab.
/, ?
Search / reverse search for a string on current page.
n, N
Find next / previous result from search.

COMMANDS

All bindings actually refer to commands. However, some commands do not have bindings associated by default. If completion userscript is used, you can autocomplete commands by pressing <TAB> by default. Once again, you should consult the configuration files to get an exhaustive list. The currently available functions may be displayed from the help view, which you can open with the :help command.

Here follows some noteworthy commands:

:bookmarks
Display and search bookmarks.
:downloads
Open Download page, which displays all downloads along with their status.
:dump
Download current page.
:save
Save the complete page as a single mhtml file.
:help
Display all commands and bindings, along with their description. The help page also features some details about modes.
:history
Display and search history.
:inspect
Launch WebKit inspector. Use :inspect! to toggle off.
:nohlsearch
Disable search highlighting.
:qmarks
Display the quickmarks list.
:tabhistory
Display the tab history.
:view-source
Display page source code. Use :view-source! to toggle off.

FILES

Luakit will load configuration files from the following folders in priority order:

$XDG_CONFIG_HOME/luakit
$XDG_CONFIG_DIRS/luakit

Default configuration files:

binds.lua
The keyboard and mouse bindings.
globals.lua
General configuration, like home page, search engines, user agent, per-domain properties, cookies policy.
modes.lua
All default modes are set in this file.
rc.lua
Main configuration files. All other files are loaded from there.
theme.lua,
Colors definition.
webview.lua
WebKit related.
window.lua
Status bar, windows and tabs behaviour.

Embedded userscript will be loaded from $XDG_DATA_DIRS/luakit/lib.

All browsing-related files are stored in $XDG_DATA_HOME/luakit. All of are created if needed and if they do not exist. Depending on the userscripts you are using, you may find:

bookmarks.db
An SQLite3 database containing your complete bookmark list. If you want to synchronise your bookmarks between your different systems, just share this file. You can use a symbolic link if the file is not stored in the required folder.
cookies.db
This file contains all details needed for websites keeping track of your status, like login information. Delete this file once you are finished with browsing if you are not on your personal system.
history.db
Your browsing history. Delete this file once you are finished with browsing if you are not on your personal system.
quickmarks
A plain text file saving your quickmarks. The structure is extremely simple: each line is a single quickmark; first character is the quickmark shortcut and may be one of [a-zA-Z0-9]; second character is a space; the remaining part is the URI.

CONFIGURATION

If you do not want to stick to the default configuration and want to benefit from the flexibility and extensibility of Luakit, you can fully configure it from the Lua configuration files.

If you do not want to start from scratch, you may use default configuration files and tweak them to fit your needs. Use the following command to copy configuration file to your home folder:

cp -r $XDG_CONFIG_DIRS/luakit $XDG_CONFIG_HOME

You can now edit the new files. Configuration should be quite straightforward, even if you do not know much about Lua.
