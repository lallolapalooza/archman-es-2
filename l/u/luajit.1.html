NOMBRE

luajit - Compilador Just-In-Time para el lenguaje Lua

SINOPSIS

luajit [opciones]... [script [args]...]

SITIO WEB

https://luajit.org

DESCRIPCIÓN

Este es el programa de línea de comandos para ejecutar programas Lua con LuaJIT.

LuaJIT es un compilador just-in-time (JIT) para el lenguaje Lua. La máquina virtual (VM) se basa en un intérprete rápido combinado con un compilador de trazas. Puede mejorar significativamente el rendimiento de los programas Lua.

LuaJIT es compatible con la API y la ABI con la VM del intérprete estándar de Lua 5.1. Al incrustar la VM en una aplicación, la biblioteca compilada se puede usar como un reemplazo directo.

OPCIONES

-e fragmento
Ejecuta el fragmento de código Lua dado.
-l biblioteca
Carga la biblioteca con el nombre dado, igual que require("biblioteca").
-b ...
Guarda o lista bytecode. Ejecuta sin argumentos para obtener ayuda sobre las opciones.
-j comando
Realiza un comando de control de LuaJIT (espacio opcional después de -j).
-O[opt]
Controla las optimizaciones de LuaJIT.
-i
Ejecuta en modo interactivo.
-v
Muestra la versión de LuaJIT.
-E
Ignora las variables de entorno.
--
Deja de procesar opciones.
-
Lee el script desde stdin en su lugar.

Después de procesar todas las opciones, se ejecuta el script dado. Los argumentos se pasan a la tabla global arg.

El modo interactivo solo se inicia si no se proporciona ningún script ni opción -e. Se puede salir del modo interactivo con EOF (Ctrl-Z).

EJEMPLOS

luajit hello.lua world

Imprime "Hola mundo", asumiendo que hello.lua contiene:
print("Hola", arg[1])

luajit -e "local x=0; for i=1,1e9 do x=x+i end; print(x)"

Calcula la suma de los números del 1 al 1000000000.
Y termina en una cantidad de tiempo razonable también.

luajit -jv -e "for i=1,10 do for j=1,10 do for k=1,100 do end end end"

Ejecuta algunos bucles anidados y muestra las trazas resultantes.
