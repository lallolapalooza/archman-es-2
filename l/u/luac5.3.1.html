LUAC(1) Manual de comandos generales LUAC(1)

NOMBRE

luac - Compilador de Lua

SINOPSIS

luac [ opciones ] [ nombres de archivo ]

DESCRIPCIÓN

luac es el compilador de Lua. Traduce programas escritos en el lenguaje de programación Lua a archivos binarios que contienen fragmentos precompilados que pueden ser posteriormente cargados y ejecutados.

Las principales ventajas de precompilar fragmentos son: carga más rápida, protección del código fuente contra cambios accidentales por parte del usuario y verificación de sintaxis fuera de línea. La precompilación no implica una ejecución más rápida porque en Lua los fragmentos siempre se compilan a códigos de bytes antes de ser ejecutados. luac simplemente permite que esos códigos de bytes se guarden en un archivo para su ejecución posterior. Los fragmentos precompilados no son necesariamente más pequeños que el código fuente correspondiente. El objetivo principal de la precompilación es una carga más rápida.

En la línea de comandos, puedes mezclar archivos de texto que contengan código fuente de Lua y archivos binarios que contengan fragmentos precompilados. luac produce un único archivo de salida que contiene los códigos de bytes combinados para todos los archivos proporcionados. La ejecución del archivo combinado es equivalente a la ejecución de los archivos proporcionados. Por defecto, el archivo de salida se llama luac.out, pero puedes cambiarlo con la opción -o.

Los fragmentos precompilados *no* son portables entre diferentes arquitecturas. Además, es probable que el formato interno de los fragmentos precompilados cambie cuando se lance una nueva versión de Lua. Asegúrate de guardar los archivos fuente de todos los programas de Lua que precompiles.

OPCIONES

-l
produce un listado del código de bytes compilado para la máquina virtual de Lua. Listar los códigos de bytes es útil para aprender sobre la máquina virtual de Lua. Si no se proporcionan archivos, entonces luac carga luac.out y lista su contenido. Usa -l -l para un listado completo.
-o archivo
salida a archivo, en lugar del predeterminado luac.out. (Puedes usar '-' para la salida estándar, pero no en plataformas que abran la salida estándar en modo texto). El archivo de salida puede ser uno de los archivos proporcionados, ya que todos los archivos se cargan antes de escribir el archivo de salida. Ten cuidado de no sobrescribir archivos importantes.
-p
carga archivos pero no genera ningún archivo de salida. Se usa principalmente para la verificación de sintaxis y para probar fragmentos precompilados: los archivos corruptos probablemente generarán errores al cargarlos. Si no se proporcionan archivos, entonces luac carga luac.out y prueba su contenido. No se muestran mensajes si el archivo se carga sin errores.
-s
elimina la información de depuración antes de escribir el archivo de salida. Esto ahorra algo de espacio en fragmentos muy grandes, pero si ocurren errores al ejecutar un fragmento depurado, los mensajes de error pueden no contener la información completa que suelen tener. En particular, se pierden los números de línea y los nombres de las variables locales.
-v
muestra información de la versión.
--
deja de manejar opciones.
-
deja de manejar opciones y procesa la entrada estándar.
