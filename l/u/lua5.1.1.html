LUA(1) Manual de Comandos Generales LUA(1)

NOMBRE

lua - Intérprete de Lua

SINOPSIS

lua [ opciones ] [ script [ args ] ]

DESCRIPCIÓN

lua es el intérprete de Lua independiente. Carga y ejecuta programas Lua, ya sea en forma de código fuente textual o en forma binaria precompilada. (Los binarios precompilados son generados por luac, el compilador de Lua.) lua puede usarse como un intérprete por lotes y también interactivamente.

Las opciones dadas (ver abajo) se ejecutan y luego se carga y ejecuta el programa Lua en el archivo script. Los args dados están disponibles para script como cadenas en una tabla global llamada arg. Si estos argumentos contienen espacios u otros caracteres especiales para el shell, deben entrecomillarse (pero ten en cuenta que las comillas serán eliminadas por el shell). Los argumentos en arg comienzan en 0, que contiene la cadena 'script'. El índice del último argumento se almacena en arg.n. Los argumentos dados en la línea de comandos antes de script, incluido el nombre del intérprete, están disponibles en índices negativos en arg.

Al principio, incluso antes de procesar la línea de comandos, lua ejecuta el contenido de la variable de entorno LUA_INIT, si está definida. Si el valor de LUA_INIT tiene el formato '@archivo', entonces se ejecuta archivo. De lo contrario, la cadena se asume que es una instrucción de Lua y se ejecuta.

Las opciones comienzan con '-' y se describen a continuación. Puedes usar '--' para indicar el final de las opciones.

Si no se dan argumentos, se asume -v -i cuando la entrada estándar es una terminal; de lo contrario, se asume -.

En modo interactivo, lua solicita al usuario, lee líneas de la entrada estándar y las ejecuta a medida que se leen. Si una línea no contiene una instrucción completa, se muestra un prompt secundario y se leen líneas hasta que se forma una instrucción completa o se encuentra un error de sintaxis. Por lo tanto, una forma de interrumpir la lectura de una instrucción incompleta es forzar un error de sintaxis: agregar un ';' en medio de una instrucción es una forma segura de forzar un error de sintaxis (excepto dentro de cadenas multilínea y comentarios; estos deben cerrarse explícitamente). Si una línea comienza con '=', entonces lua muestra los valores de todas las expresiones en el resto de la línea. Las expresiones deben estar separadas por comas. El prompt primario es el valor de la variable global _PROMPT, si este valor es una cadena; de lo contrario, se usa el prompt predeterminado. De manera similar, el prompt secundario es el valor de la variable global _PROMPT2. Por lo tanto, para cambiar los prompts, establece la variable correspondiente a una cadena de tu elección. Puedes hacerlo después de llamar al intérprete o en la línea de comandos (pero en este caso debes tener cuidado con las comillas si la cadena del prompt contiene un espacio; de lo contrario, puedes confundir al shell.) Los prompts predeterminados son "> " y ">> ".

OPCIONES

-
carga y ejecuta la entrada estándar como un archivo, es decir, no interactivamente, incluso cuando la entrada estándar es una terminal.
-e stat
ejecuta la instrucción stat. Necesitas entrecomillar stat si contiene espacios, comillas u otros caracteres especiales para el shell.
-i
entra en modo interactivo después de que se ejecute script.
-l nombre
llama a require('nombre') antes de ejecutar script. Típicamente se usa para cargar bibliotecas.
-v
muestra información de la versión.
