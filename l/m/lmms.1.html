LMMS(1) Manual de comandos generales LMMS(1)

NOMBRE

lmms - software para una producción musical fácil

SINOPSIS

lmms [opciones globales...] [acción [parámetros de acción...]]

DESCRIPCIÓN

LMMS es una alternativa gratuita multiplataforma a programas comerciales como FL Studio®, que te permite producir música con tu ordenador. Esto incluye la creación de melodías y ritmos, la síntesis y mezcla de sonidos, y la organización de muestras. Puedes divertirte con tu teclado MIDI y mucho más; todo en una interfaz moderna y fácil de usar.

LMMS cuenta con componentes como un Editor de Canciones, un Editor de Ritmos y Líneas de Bajo, un Piano Roll, un Mezclador de Efectos (FX Mixer), así como muchos instrumentos y efectos potentes.

ACCIONES

<sin acción> [opciones...] [proyecto]
Inicia LMMS en modo GUI normal.
volcar entrada
Vuelca el XML del archivo comprimido (MMPZ) entrada.
renderizar proyecto [opciones...]
Renderiza el archivo de proyecto dado.
renderizarpistas proyecto [opciones...]
Renderiza cada pista a un archivo diferente.
actualizar entrada [salida]
Actualiza el archivo entrada y lo guarda como salida. La salida estándar se utiliza si no se especifica ningún archivo de salida.

OPCIONES GLOBALES

  --allowroot
Omite la comprobación de inicio del usuario root (usar con precaución).
-c, --config archivo de configuración
Obtiene la configuración de archivo de configuración en lugar de ~/.lmmsrc.xml (predeterminado).
-h, --help
Muestra la información de uso y sale.
-v, --version
Muestra la información de la versión y sale.

OPCIONES SI NO SE PROPORCIONA ACCIÓN

  --geometry geometría
Especifica el tamaño y la posición preferidos de la ventana principal.
La sintaxis de geometría es tamaño xxtamaño y+desplazamiento x+desplazamiento y.
Predeterminado: pantalla completa.
  --import entrada -e
Importa un archivo MIDI o Hydrogen entrada.

OPCIONES PARA RENDERIZAR Y RENDERIZARPISTAS

-a, --float
Utiliza una profundidad de bits de punto flotante de 32 bits.
-b, --bitrate tasa de bits
Especifica la tasa de bits de salida en KBit/s (solo para codificación OGG), el valor predeterminado es 160.
-f, --format formato
Especifica el formato de salida de la renderización, donde formato puede ser 'wav', 'ogg' o 'mp3'.
-i, --interpolation método
Especifica el método de interpolación; los valores posibles son linear, sincfastest (predeterminado), sincmedium, sincbest.

Si se especifica -e, lmms saldrá después de importar el archivo.

-l, --loop
Renderiza el archivo dado como un bucle, es decir, detiene la renderización exactamente al final de la canción. Los silencios adicionales o las colas de reverberación al final de la canción no se renderizan.
-m, --mode modo estéreo
Establece el modo estéreo utilizado para la exportación MP3. modo estéreo puede ser 's' (modo estéreo), 'j' (estéreo conjunto) o 'm' (mono). Si no se proporciona un modo, se utiliza 'j' como predeterminado.
-o, --output ruta
Renderiza en ruta.
Para --render, esto se interpreta como una ruta de archivo.
Para --render-tracks, esto se interpreta como la ruta a un directorio existente.
-p, --profile salida
Vuelca la información de perfilación en el archivo salida.
-s, --samplerate frecuencia de muestreo
Especifica la frecuencia de muestreo de salida en Hz; el rango es de 44100 (predeterminado) a 192000.
-x, --oversampling valor
Especifica el sobremuestreo; los valores posibles son: 1, 2 (predeterminado), 4, 8.
