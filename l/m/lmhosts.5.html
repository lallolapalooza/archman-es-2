LMHOSTS(5) Formatos de archivo y convenciones LMHOSTS(5)

NOMBRE

lmhosts - El archivo de hosts NetBIOS de Samba

SINOPSIS

lmhosts es el archivo de mapeo de nombres NetBIOS a direcciones IP de samba(7).

DESCRIPCIÓN

Este archivo forma parte del conjunto de samba(7).

lmhosts es el archivo de mapeo de nombres NetBIOS a direcciones IP de Samba. Es muy similar al formato del archivo /etc/hosts, excepto que el componente del nombre de host debe corresponder al formato de nombres NetBIOS.

FORMATO DEL ARCHIVO

Es un archivo ASCII que contiene una línea por nombre NetBIOS. Los dos campos de cada línea están separados entre sí por espacios en blanco. Cualquier entrada que comience con '#' se ignora. Cada línea en el archivo lmhosts contiene la siguiente información:

• Dirección IP - en formato decimal con puntos.
• Nombre NetBIOS - Este formato de nombre es un nombre de host máximo de quince caracteres, con un carácter '#' opcional al final seguido del tipo de nombre NetBIOS como dos dígitos hexadecimales.

Si se omite el '#' final, se devolverá la dirección IP dada para todos los nombres que coincidan con el nombre dado, independientemente del tipo de nombre NetBIOS en la consulta.

A continuación, un ejemplo:

#
# Archivo lmhosts de Samba de ejemplo.
#
192.9.200.1	TESTPC
192.9.200.20	NTSERVER#20
192.9.200.21	SAMBASERVER

Contiene tres mapeos de IP a nombre NetBIOS. El primero y el tercero se devolverán para cualquier consulta de los nombres "TESTPC" y "SAMBASERVER", respectivamente, independientemente del componente de tipo del nombre NetBIOS solicitado.

El segundo mapeo se devolverá solo cuando se consulte el tipo de nombre "0x20" para un nombre "NTSERVER". Cualquier otro tipo de nombre no se resolverá.

La ubicación predeterminada del archivo lmhosts está en el mismo directorio que el archivo smb.conf(5).

ARCHIVOS

lmhosts se carga desde el directorio de configuración. Esto suele ser /etc/samba o /usr/local/samba/lib.
