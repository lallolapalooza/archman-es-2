lmap(n) Comandos integrados de Tcl lmap(n)

NOMBRE

lmap - Itera sobre todos los elementos de una o más listas y recopila resultados

SINOPSIS

lmap nombre_variable lista cuerpo
lmap lista_variables1 lista1 ?lista_variables2 lista2 ...? cuerpo

DESCRIPCIÓN

El comando lmap implementa un bucle donde la(s) variable(s) del bucle toman valores de una o más listas, y el bucle devuelve una lista de resultados recopilados de cada iteración.

En el caso más simple, hay una variable de bucle, nombre_variable, y una lista, lista, que es una lista de valores para asignar a nombre_variable. El argumento cuerpo es un script Tcl. Por cada elemento de lista (en orden de primero a último), lmap asigna el contenido del elemento a nombre_variable como si el comando lindex se hubiera utilizado para extraer el elemento, luego llama al intérprete Tcl para ejecutar cuerpo. Si la ejecución del cuerpo se completa normalmente, el resultado del cuerpo se agrega a una lista acumuladora. lmap devuelve la lista acumuladora.

En el caso general, puede haber más de una lista de valores (por ejemplo, lista1 y lista2), y cada lista de valores puede estar asociada con una lista de variables de bucle (por ejemplo, lista_variables1 y lista_variables2). Durante cada iteración del bucle, las variables de cada lista_variables se asignan valores consecutivos de la lista correspondiente. Los valores en cada lista se usan en orden de primero a último, y cada valor se usa exactamente una vez. El número total de iteraciones del bucle es suficiente para utilizar todos los valores de todas las listas de valores. Si una lista de valores no contiene suficientes elementos para cada una de sus variables de bucle en cada iteración, se usan valores vacíos para los elementos faltantes.

Los comandos break y continue pueden invocarse dentro de cuerpo, con el mismo efecto que en los comandos for y foreach. En estos casos, el cuerpo no se completa normalmente y el resultado no se agrega a la lista acumuladora.

EJEMPLOS

Combinar listas:

set list1 {a b c d}
set list2 {1 2 3 4}
set zipped [lmap a $list1 b $list2 {list $a $b}]
# El valor de zipped es "{a 1} {b 2} {c 3} {d 4}"

Filtrar una lista para eliminar valores impares:

set values {1 2 3 4 5 6 7 8}
proc isEven {n} {expr {($n % 2) == 0}}
set goodOnes [lmap x $values {expr {
    [isEven $x] ? $x : [continue]
}}]
# El valor de goodOnes es "2 4 6 8"

Tomar un prefijo de una lista basado en el contenido de la lista:

set values {8 7 6 5 4 3 2 1}
proc isGood {counter} {expr {$n > 3}}
set prefix [lmap x $values {expr {
    [isGood $x] ? $x : [break]
}}]
# El valor de prefix es "8 7 6 5 4"
