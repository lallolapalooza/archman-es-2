NOMBRE

l2tp-secrets - archivo de secretos de L2TPD

DESCRIPCIÓN

El archivo l2tp-secrets contiene información de autenticación de respuesta a desafío para xl2tp, la implementación del protocolo l2tp. El formato del archivo se deriva del formato de archivo de secretos pap y chap utilizado en pppd.

El archivo de secretos se compone de cero o más líneas con 3 campos cada una. Cada línea representa un secreto de autenticación. Los 3 campos representan nuestro nombre de host, el nombre de host remoto y el secreto utilizado en el proceso de autenticación.

El primer campo es para nuestro nombre de host, se puede usar un "*" como comodín.

El segundo campo es para el nombre de host del sistema remoto. Nuevamente, se puede usar un "*" como comodín.

El tercer campo es el secreto utilizado si los dos campos anteriores coinciden con los nombres de host de los sistemas involucrados. Idealmente, el secreto debería tener 16 caracteres de longitud (la longitud de la salida de un digest MD5), y probablemente debería ser más largo para garantizar una seguridad suficiente. Sin embargo, no hay un requisito de longitud mínima.
