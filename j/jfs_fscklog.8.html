jfs_fscklog(8) Extraer/Mostrar registro de fsck JFS jfs_fscklog(8)

NOMBRE

jfs_fscklog - extraer un registro de servicio de fsck JFS a un archivo y/o formatear y mostrar el archivo extraído

SINOPSIS

jfs_fscklog [ -d ] [ -e dispositivo ] [ -f archivo.salida ] [ -p ] [ -V ]

DESCRIPCIÓN

jfs_fscklog con la opción -e dispositivo extrae el contenido del registro de servicio de fsck JFS más reciente o el inmediatamente anterior (especificado con la opción -p) del dispositivo especificado, y escribe la salida a un archivo. El nombre del archivo puede especificarse con la opción -f, o el nombre de archivo predeterminado es <pwd>fscklog.new. Si se usa la opción -p, el nombre de archivo predeterminado es <pwd>fscklog.old.

jfs_fscklog con la opción -d formatea y muestra el contenido del archivo extraído.

jfs_fscklog con las opciones -d y -e dispositivo extrae y muestra el registro de servicio de fsck JFS.

OPCIONES

-d
Formatear y mostrar un registro de servicio de fsck JFS extraído previamente.
-e dispositivo
Extraer el registro de servicio de fsck JFS del dispositivo y almacenarlo en un archivo. (dispositivo es el nombre del archivo especial correspondiente al dispositivo real del cual se extraerá el registro de fsck (por ejemplo, /dev/hdb1)).
-f nombre.archivo
Especificar el nombre del archivo, anulando el nombre de archivo predeterminado. Cuando se usa con -e dispositivo, nombre.archivo especifica el nombre del archivo en el que se extraerá el registro de fsck JFS. Cuando se usa con -d, nombre.archivo especifica el nombre del archivo extraído cuyo contenido se formateará y mostrará.

nombre.archivo debe tener 127 caracteres o menos de longitud.

nombre.archivo se creará en el directorio de trabajo actual a menos que esté completamente calificado.

-p
Extraer el registro anterior (en lugar del registro más reciente).
-V
Imprimir información de la versión y salir (independientemente de cualquier otra opción elegida).

EJEMPLOS


Extraer el registro de fsck JFS más reciente en /dev/hda5 a <pwd>fscklog.new:

jfs_fscklog -e /dev/hda5

Extraer el registro de fsck JFS más reciente en /dev/hdb3 a /temp/l9651107.log:

jfs_fscklog -e /dev/hdb3 -f /temp/l9651107.log

Mostrar el registro de fsck JFS que se extrajo en /temp/l9651107.log:

jfs_fscklog -d -f /temp/l9651107.log

Extraer y mostrar el registro de fsck JFS anterior desde /dev/hda8:

jfs_fscklog -e /dev/hda8 -d -p

INFORME DE ERRORES

Si encuentra un error en JFS o jfs_fscklog, por favor repórtelo a través del sistema de seguimiento de errores ("Sección de informe de errores") del sitio web del proyecto JFS:

http://jfs.sourceforge.net/

Por favor, envíe tanta información pertinente como sea posible, incluyendo cualquier mensaje de error de jfs_fscklog y la salida completa de la ejecución de jfs_fsck con la opción -v en el dispositivo JFS.
