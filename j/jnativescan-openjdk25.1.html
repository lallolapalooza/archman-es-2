jnativescan-openjdk25(1)

NOMBRE

jnativescan-openjdk25 - Escanea un archivo .class o .jar para buscar referencias a bibliotecas nativas.

SINOPSIS

jnativescan [OPCIONES] <archivo(s)>

DESCRIPCIÓN

El comando jnativescan es una utilidad que examina los archivos de clase de Java o los archivos JAR para identificar las bibliotecas nativas que se cargan utilizando System.loadLibrary o System.load.

Es útil para el desarrollo y la depuración de aplicaciones Java que dependen de código nativo, ayudando a identificar dependencias de bibliotecas faltantes o incorrectamente referenciadas.

OPCIONES PARA EL COMANDO JNATIVESCAN

Actualmente, no hay opciones de línea de comandos específicas documentadas para jnativescan. El comando funciona directamente sobre los archivos proporcionados como argumentos.

EJEMPLO DE USO DE jnativescan

Para escanear un archivo JAR llamado mi_aplicacion.jar en busca de referencias a bibliotecas nativas, usaría el siguiente comando:

jnativescan mi_aplicacion.jar

Si el archivo contiene referencias a bibliotecas nativas, jnativescan las listará en la salida estándar.
