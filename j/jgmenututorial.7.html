Lección 1 - Primeros pasos

Después de instalar jgmenu, inicia el menú ejecutando el siguiente comando

jgmenu_run

Deberías ver un menú del sistema Linux/BSD mostrando las aplicaciones instaladas. Consulta la lección 7 para más detalles.

Crea un archivo de configuración (~/.config/jgmenu/jgmenurc) ejecutando

jgmenu_run init

Los detalles completos de las opciones de configuración se encuentran en jgmenu(1) (jgmenu.1.html).

Al entrar en el modo interactivo y luego seleccionar `t', puedes probar algunas plantillas/temas predefinidos.

jgmenu_run init -i

Hay un pequeño número de opciones de configuración que pueden requerir intervención manual para que jgmenu se muestre correctamente en tu sistema.

position_mode
Existen varios métodos para posicionar el menú. Prueba fixed, ipc, center y pointer para ver cuál funciona mejor en tu sistema. Consulta jgmenu(1) para obtener detalles completos.
menu_margin_x y menu_margin_y
Si estás utilizando position_mode=fixed, es posible que necesites establecer estas dos variables. Dependiendo del gestor de ventanas y panel que uses, jgmenu puede ser capaz de encontrar automáticamente una posición vertical y horizontal adecuada, así que prueba sin establecer estas variables primero.
menu_halign y menu_valign
De nuevo, dependiendo de tu sistema, puede que necesites especificar manualmente la alineación horizontal y vertical del menú, pero prueba sin hacerlo primero.

Lección 2 - Arquitectura

El diseño de jgmenu es muy modular, proporcionando mucha flexibilidad en cómo se utiliza.

Cuando se inicia jgmenu, se ejecutan dos procesos para producir el menú.

┌────────────────┐
│ csv-generator  │
└────────────────┘
        |
        V
┌────────────────┐
│ graphical menu │
└────────────────┘

El primer proceso (csv-generator) produce el contenido del menú, mientras que el segundo genera el menú gráfico.

jgmenu_run(1) (jgmenu_run.1.html) es un script envoltorio multiusos que hace lo siguiente en pseudo código:

if (jgmenu ya está ejecutándose)
        mostrar menú
else
        iniciar una nueva instancia de jgmenu

Esto lo hace adecuado para usar con paneles y atajos de teclado.

Lección 3 - Scripting con jgmenu

A partir de este punto, se asume que entiendes el uso básico del shell, incluyendo la re-dirección (p. ej., <, >) y el encadenamiento (p. ej., |).

La sintaxis que se muestra a continuación (here-document) se utiliza para denotar la creación de un archivo de texto a partir de lo que esté entre los EOF. Por supuesto, puedes usar tu editor de texto favorito en su lugar.

cat >archivo <<EOF
foo
bar
EOF

Hay muchas maneras de ejecutar jgmenu. En la lección 1, viste jgmenu como una aplicación de larga duración. A medida que avancemos por las siguientes lecciones, ejecutaremos jgmenu como una aplicación de corta duración. Esto significa que se inicia desde cero cada vez que se llama.

Así que volvamos a lo básico. Prueba lo siguiente:

echo >foo.txt <<EOF
xterm
firefox
EOF

Si aún no te has acostumbrado a la sintaxis del here-document, solo significa que pones las palabras “xterm” y “firefox” en un archivo de texto (lo cual puedes hacer, por supuesto, usando un editor de texto). Luego ejecuta cualquiera de los siguientes:

cat foo.txt | jgmenu --simple --icon-size=0
jgmenu --vsimple --csv-file="foo.txt"

La opción --simple hace que jgmenu sea de corta duración y lea los elementos del menú desde stdin.

La opción --icon-size=0 desactiva los iconos (es decir, no solo los muestra en tamaño cero, sino que simplemente no los carga).

El argumento de línea de comandos --vsimple es lo mismo que --simple, pero también desactiva los iconos e ignora jgmenurc (si existe).

Si quieres que un menú sea lanzado por un único script, podrías construirlo así:

cat <<EOF >menu.sh
#!/bin/sh
(
printf "foo\n"
printf "bar\n"
) | jgmenu --vsimple
EOF
chmod +x menu.sh
./menu.sh

Lección 4 - Descripciones

Como viste en el ejemplo anterior, cada línea enviada a stdin se convierte en un elemento del menú. Cualquier línea que contenga dos campos separados por una coma se analiza como description,command. Considera los siguientes datos de menú CSV:

Terminal,xterm
Gestor de Archivos,pcmanfm

Esto te permite dar una descripción más significativa a cada elemento del menú.

Lección 5 - Iconos

Para mostrar iconos, necesitas poblar el tercer campo. Por defecto, jgmenu obtendrá el tema de iconos de xsettings (si está ejecutándose) o tint2rc (si existe). Al ejecutar con el argumento --simple, asegúrate de que icon_theme esté configurado en algo sensato en tu $HOME/.config/jgmenu/jgmenurc. Considera los siguientes datos de menú CSV:

Navegador,        firefox,               firefox
Gestor de archivos,   pcmanfm,               system-file-manager
Terminal,       xterm,                 utilities-terminal
Bloquear,           i3lock -c 000000,      system-lock-screen
Salir a pr

Lección 6 - Submenús

Los submenús se crean utilizando la sintaxis de los here-documents. Un submenú se indica con una línea que contiene el texto del menú seguido de dos puntos.

parent_menu:
  child_menu_1
  child_menu_2

jgmenu puede manejar submenús anidados, por lo que puede tener elementos dentro de submenús dentro de submenús, etc.

Ejemplo:

Apps:
  Terminal,xterm
  Web:
    Firefox,firefox
    Tor Browser,torbrowser
  Office:
    LibreOffice,libreoffice

Si no se especifica un comando, el elemento padre actuará como un submenú. Si el elemento padre tiene una descripción, se utilizará el texto del menú.

Lección 7 - Menús de aplicaciones XDG

jgmenu es capaz de interpretar los archivos de menú de aplicaciones XDG. Estos archivos se encuentran típicamente en `/usr/share/applications/` y suelen tener la extensión `.desktop`. Para ejecutar jgmenu con el menú XDG:

jgmenu_run --app-option=all

Esto mostrará todas las aplicaciones definidas en los archivos `.desktop`. Si solo quieres un subconjunto de estas aplicaciones, puedes especificar qué aplicaciones incluir en la línea de comandos.

Por ejemplo, para mostrar solo Firefox y Thunderbird:

jgmenu_run --app-option=firefox.desktop,thunderbird.desktop

También puedes usar expresiones regulares para filtrar.

jgmenu_run --app-option=~/.*\.desktop

jgmenu también puede leer menús personalizados desde `~/.config/jgmenu/applications.menu`. Esto te permite tener un menú de aplicaciones personalizadas además de las definidas por XDG.

Lección 8 - Opciones de configuración

jgmenu se puede configurar extensamente. El archivo de configuración predeterminado es `~/.config/jgmenu/jgmenurc`. Si no existe, jgmenu usará valores predeterminados sensatos. Algunas opciones importantes son:

menu_width
Establece el ancho del menú en píxeles.
menu_height
Establece la altura máxima del menú en píxeles. Si el contenido excede esta altura, se habilitará una barra de desplazamiento.
menu_border_width
Establece el ancho del borde del menú.
menu_border_color
Establece el color del borde del menú.
menu_bg_color
Establece el color de fondo del menú.
menu_fg_color
Establece el color del primer plano (texto) del menú.
menu_font
Establece la fuente utilizada para el texto del menú.
icon_size
Establece el tamaño de los iconos en píxeles.
icon_theme
Especifica el tema de iconos a utilizar. Si no se establece, jgmenu intentará detectarlo automáticamente.
menu_halign
Alineación horizontal del menú. Opciones: left, center, right.
menu_valign
Alineación vertical del menú. Opciones: top, center, bottom.
position_mode
Modo de posicionamiento del menú. Opciones: fixed, pointer, center, ipc.

Consulta jgmenu(1) para obtener una lista completa de todas las opciones de configuración.

Lección 9 - Añadir/Prefijar y Separadores

jgmenu permite añadir elementos al principio o al final de un menú existente. Esto es útil para añadir elementos personalizados a menús generados automáticamente, como el menú XDG.

Para añadir un elemento al principio del menú:

jgmenu_run --prepend="My Custom Item,my_command"

Para añadir un elemento al final del menú:

jgmenu_run --append="Another Item,another_command"

También puedes añadir separadores para organizar visualmente tu menú.

jgmenu_run --separator="My Separator"

Los separadores también pueden tener un comando asociado, que se ejecutará si se hace clic en el separador.

Lección 10 - Generadores CSV

jgmenu puede utilizar scripts externos para generar el contenido del menú en formato CSV. Estos scripts se especifican mediante la opción `--csv-generator`.

Por ejemplo, si tienes un script llamado `my_menu_generator.sh` que genera la salida CSV necesaria, puedes ejecutar jgmenu así:

jgmenu_run --csv-generator="/path/to/my_menu_generator.sh"

El script generador CSV debe imprimir cada elemento del menú en una línea separada, con los campos separados por comas (descripción, comando, icono).

Lección 11 - Búsqueda

jgmenu tiene una funcionalidad de búsqueda incorporada. Para activarla, ejecuta jgmenu con el modo de entrada interactivo y pulsa la tecla `/`.

jgmenu_run -i

Aparecerá un campo de texto en la parte superior del menú. Puedes escribir texto aquí para filtrar los elementos del menú que coinciden.

La búsqueda se realiza en las descripciones y comandos de los elementos del menú.

Lección 5 - Iconos

jgmenu recognizes the Icon Naming Specification, so jgmenu will search for the icon in the standard directories.

Alternatively, you can specify the full path to the icon:

My Item,/path/to/my/item.sh,/path/to/my/icon.png

Or, use a built-in icon:

Log Out,openbox --exit,system-log-out

Reboot,systemctl -i ; reboot, system-reboot

Poweroff,systemctl -i ; poweroff, system-shutdown

Lección 6 - Submenús

Hasta ahora hemos visto cómo producir un único menú "raíz". jgmenu entiende una pequeña cantidad de marcado y permite submenús mediante ^tag() y ^checkout(). Prueba esto:

Terminal,xterm
Gestor de Archivos,pcmanfm
Configuración,^checkout(settings)
^tag(settings)
Establecer Imagen de Fondo,nitrogen

En pseudocódigo, construye tu archivo CSV de la siguiente manera:

# el menú raíz
item0.0
item0.1
sub1,^checkout(1)
sub2,^checkout(2)
# el primer submenú
^tag(1)
item1.0
item1.1
# el segundo submenú
^tag(2)
item2.0
item2.1

^root() se puede usar en lugar de ^checkout() para abrir el submenú en la ventana padre.

Lección 7 - Menús de Aplicaciones XDG

XDG (freedesktop.org) ha definido una Especificación de Menú de Escritorio para Linux/BSD que es seguida por los grandes Entornos de Escritorio. Ver menu-spec (http://specifications.freedesktop.org/menu-spec/latest/) para más detalles. En resumen, hay tres tipos de archivos que definen un menú XDG:

.menu
Archivo XML que describe las categorías del menú y la estructura de directorios. Ubicado en /etc/xdg/menus/, o el equivalente de XDG_CONFIG_{HOME,DIRS}.
.directory
Describe los directorios del menú. Ubicado en /usr/share/desktop-directories/, o el equivalente de XDG_DATA_{HOME,DIRS}.
.desktop
Describe las aplicaciones y contiene la mayor parte de la información necesaria para construir un menú (por ejemplo, Nombre, comando Exec, Icono y Categoría). Ubicado en /usr/share/applications/, o el equivalente de XDG_DATA_{HOME,DIRS}.

La mayoría de las aplicaciones de escritorio proporcionan sus propios archivos .desktop asociados, mientras que los archivos .menu y .directory son suministrados por paquetes de menú, como libmenu-cache (LXDE) y libcargon (XFCE).

El módulo principal de jgmenu jgmenu-apps(1) (jgmenu-apps.1.html) proporciona un menú del sistema basado en archivos .desktop y datos de esquema incorporados o un archivo de esquema especificado, en lugar de los archivos .menu y .directory del sistema. Aunque esto se desvía de la especificación del menú XDG, es mucho más simple de entender y ajustar. También evita la dependencia de paquetes de menú.

Para un cumplimiento estricto de XDG, se puede usar el módulo opcional jgmenu-lx(1) (jgmenu-lx.1.html).

Ver la Lección 10 para instrucciones genéricas sobre módulos.

Lección 8 - Opciones de Configuración

En la lección 1 discutimos las opciones de configuración position_mode, menu_margin_x, menu_margin_y, menu_halign y menu_valign.

Aquí siguen algunas opciones más que podrías querer explorar. Para detalles completos, ver jgmenu(1) (jgmenu.1.html).

Estilo Rofi:

csv_no_dirs=1
csv_single_window=1
columns=2
menu_width=600
menu_valign=center
menu_halign=center

Sincronizar colores, fuente e iconos con el panel tint2

tint2_look=1

Lección 9 - Añadir/Preceder y Separadores

Al usar apps, pmenu o lx, puedes añadir elementos al menú en la parte superior e inferior del menú raíz editando append.csv y/o prepend.csv en ~/.config/jgmenu. Por ejemplo, prueba lo siguiente:

prepend.csv

Navegador, firefox, firefox
Gestor de Archivos, pcmanfm, system-file-manager
Terminal, xterm, utilities-terminal
^sep()

append.csv

^sep()
Suspender, systemctl -i ; suspend, system-log-out
Reiniciar, systemctl -i ; reboot, system-reboot
Apagar, systemctl -i ; poweroff, system-shutdown

En estos ejemplos hemos usado el marcado ^sep(), que inserta una línea separadora horizontal. De manera similar, ^sep(foo) inserta un separador de texto que muestra "foo".

Lección 10 - Generadores CSV

En lecciones anteriores, introdujimos apps, lx y pmenu. Estos módulos se conocen como "generadores CSV" y se invocan de la siguiente manera:

jgmenu_run <comando>

Los "generadores CSV" incorporados incluyen: apps y ob

Los "generadores CSV" opcionales incluyen: lx y pmenu

Están documentados por una página man o un simple mensaje --help.

man jgmenu-<comando>
jgmenu_run <comando> --help

Aquí siguen algunos ejemplos de cómo se pueden usar.

Especificar el generador CSV en el archivo de configuración estableciendo csv_cmd en ~/.config/jgmenu/jgmenurc

csv_cmd = pmenu

Especificar el generador CSV en la línea de comandos

jgmenu --csv-cmd="jgmenu_run pmenu"

Enviar la salida CSV a jgmenu (usando --simple para leer desde stdin)

jgmenu_run pmenu | jgmenu --simple

Crear un pipemenu usando el marcado ^pipe(). Considera este ejemplo

Terminal,xterm
Gestor de Archivos,pcmanfm
^pipe(jgmenu_run pmenu)

Lección 11 - Búsqueda

jgmenu tiene soporte para búsqueda, que se puede invocar simplemente escribiendo cuando el menú está abierto.

Se puede insertar un cuadro de búsqueda usando widgets. Por ejemplo, añade esto a ~/.config/jgmenu/prepend.csv:

@search,,3,3,150,20,2,left,top,auto,#000000 0,Escribe para Buscar

Asegúrate de ajustar el relleno del menú en consecuencia, por ejemplo

menu_padding_top=24

También se puede invocar una búsqueda asociando un widget con un comando ^filter().
