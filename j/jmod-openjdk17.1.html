DESCRIPCIÓ

N

Nota: Para la mayoría de las tareas de desarrollo, incluido el despliegue de módulos en la ruta de módulos o su publicación en un repositorio Maven, continúe empaquetando los módulos en archivos JAR modulares. El Herramienta jmod está destinada a módulos que tienen bibliotecas nativas u otros archivos de configuración, o para módulos que pretende vincular, con la herramienta jlink, a una imagen de tiempo de

ejecución.

El formato de archivo JMOD le permite agregar archivos distintos de archivos .class, metadatos y recursos. Este formato es transportable pero no ejecutable, lo que significa que puede usarlo en tiempo de compilación o de enlace, pero no en tiempo de

ejecución.

Muchas opciones de jmod implican especificar una ruta cuyo contenido se copia en los archivos JMOD resultantes. Estas opciones copian todo el contenido de la ruta especificada, incluidos los subdirectorios y su contenido, pero excluyen los archivos cuyos nombres coincidan con el patrón especificado por la opción --ex

clude.

Con la opción --hash-modules o el comando jmod hash, puede, en el descriptor de cada módulo, registrar hashes del contenido de los módulos que se les permite depender de él, así "atando" juntos estos módulos. Esto permite que un paquete se exporte a uno o más módulos con nombre

s específicos y a ningún otro a través de exportaciones calificadas. El tiempo de ejecución verifica si el hash registrado
de un módulo coincide con el resuelto en tiempo de ejecución; si no es así, el tiempo de ejecución devuelve un error.

OPCIONES ADICIONALES PARA JMOD

Además de las opciones descritas en Opciones para jmod, las siguientes son opciones adicionales que se pueden usar con el comando.

--do-not-resolve-by-default
Excluir del conjunto raíz predeterminado de módulos
--warn-if-resolved
Pista para que una herramienta emita una advertencia si el módulo se resuelve. Uno de los siguientes: `deprecated`, `deprecated-for-removal`, o `incubating`.

EJEMPLO CREACION JMOD

El siguiente es un ejemplo de creación de un archivo JMOD:


jmod create --class-path mods/com.greetings --cmds commands
    --config configfiles --header-files src/h --libs lib
    --main-class com.greetings.Main --man-pages man --module-version 1.0
    --os-arch "x86_x64" --os-name "Mac OS X"
    --os-version "10.10.5" greetingsmod

EJEMPLO HASH JMOD

El siguiente ejemplo demuestra lo que sucede cuando intentas enlazar un módulo hoja (en este ejemplo, ma) con un módulo requerido (mb), y el valor hash registrado en el módulo requerido no coincide con el del módulo hoja.

1.
Crea y compila los siguientes archivos .java:
•
jmodhashex/src/ma/module-info.java

module ma {
    requires mb;
}
•
jmodhashex/src/mb/module-info.java

module mb {
}
•
jmodhashex2/src/ma/module-info.java

module ma {
    requires mb;
}
•
jmodhashex2/src/mb/module-info.java

module mb {
}
2.
Crea un archivo JMOD para cada módulo. Crea los directorios jmodhashex/jmods y jmodhashex2/jmods, y luego ejecuta los siguientes comandos desde el directorio jmodhashex, y luego desde el directorio jmodhashex2:
•
jmod create --class-path mods/ma jmods/ma.jmod
•
jmod create --class-path mods/mb jmods/mb.jmod
3.
Opcionalmente, previsualiza el comando jmod hash. Ejecuta el siguiente comando desde el directorio jmodhashex:

jmod hash --dry-run -module-path jmods --hash-modules .*

El comando imprime lo siguiente:


Dry run:
mb
    hashes ma SHA-256 07667d5032004b37b42ec2bb81b46df380cf29e66962a16481ace2e71e74073a

Esto indica que el comando jmod hash (sin la opción --dry-run) registrará el valor hash del módulo hoja ma en el módulo mb.

4.
Registra los valores hash en los archivos de archivo JMOD contenidos en el directorio jmodhashex. Ejecuta el siguiente comando desde el directorio jmodhashex:

jmod hash --module-path jmods --hash-modules .*

El comando imprime lo siguiente:

Hashes are recorded in module mb

5.
Imprime información sobre cada archivo de archivo JMOD contenido en el directorio jmodhashex. Ejecuta los comandos resaltados desde el directorio jmodhashex:

jmod describe jmods/ma.jmod
ma
    requires mandated java.base
    requires mb
jmod describe jmods/mb.jmod
mb
    requires mandated java.base
    hashes ma SHA-256 07667d5032004b37b42ec2bb81b46df380cf29e66962a16481ace2e71e74073a
6.
Intenta crear una imagen de tiempo de ejecución que contenga el módulo ma del directorio jmodhashex2 pero el módulo mb del directorio jmodhashex. Ejecuta el siguiente comando desde el directorio jmodhashex2:
•
Linux y OS X:

jlink --module-path $JAVA_HOME/jmods:jmods/ma.jmod:../jmodhashex/jmods/mb.jmod --add-modules ma --output ma-app

•
Windows:

jlink --module-path %JAVA_HOME%/jmods;jmods/ma.jmod;../jmodhashex/jmods/mb.jmod --add-modules ma --output ma-app

El comando imprime un mensaje de error similar al siguiente:


Error: Hash of ma (a2d77889b0cb067df02a3abc39b01ac1151966157a68dc4241562c60499150d2) differs to
expected hash (07667d5032004b37b42ec2bb81b46df380cf29e66962a16481ace2e71e74073a) recorded in mb
