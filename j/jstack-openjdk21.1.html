JSTACK(1) Comandos JDK JSTACK(1)

NOMBRE

jstack - imprime rastreos de pila de Java de hilos de Java para un proceso de Java especificado

SINOPSIS

Nota: Este comando es experimental y no está soportado.

jstack [opciones] pid

opciones
Esto representa las opciones de línea de comandos de jstack. Ver Opciones para el comando jstack.
pid
El ID de proceso para el cual se imprime el rastreo de pila. El proceso debe ser un proceso Java. Para obtener una lista de procesos Java en ejecución en una máquina, usa el comando ps o, si los procesos JVM no se ejecutan en una instancia de docker separada, el comando jps.

DESCRIPCIÓN

El comando jstack imprime rastreos de pila de Java de hilos de Java para un proceso de Java especificado. Para cada marco de Java, se imprimen el nombre completo de la clase, el nombre del método, el índice de bytecode (BCI) y el número de línea, cuando están disponibles. Los nombres C++ ofuscados no se desofuscan. Para desofuscar nombres C++, la salida de este comando se puede canalizar a c++filt. Cuando el proceso especificado se está ejecutando en una JVM de 64 bits, es posible que necesites especificar la opción -J-d64, por ejemplo: jstack -J-d64 pid.

Nota:

Este comando no está soportado y podría no estar disponible en versiones futuras del JDK. En sistemas Windows donde el archivo dbgeng.dll no está presente, las Herramientas de depuración para Windows deben estar instaladas para que estas herramientas funcionen. La variable de entorno PATH debe contener la ubicación del jvm.dll que utiliza el proceso objetivo, o la ubicación desde la que se produjo el archivo de volcado del núcleo.

OPCIONES PARA EL COMANDO JSTACK

-l
La opción de listado largo imprime información adicional sobre los bloqueos.
-h o -help
Imprime un mensaje de ayuda.
