NOMBRE

jack_mixer - Un mezclador de audio multicanal gráfico para JACK

SINOPSIS

jack_mixer.py [-h] [-c ARCHIVO] [-d] [NOMBRE]

DESCRIPCIÓN

Esta página del manual documenta el comando jack_mixer.

jack_mixer es una aplicación de mezclador de audio multicanal para el JACK Audio Connection Kit con una interfaz gráfica de usuario y tiene un aspecto y manejo similar al de las consolas de mezcla de hardware.

OPCIONES

Argumentos posicionales:

NOMBRE establece el nombre del cliente JACK

Argumentos opcionales:

-h, --help
muestra este mensaje de ayuda y sale
-c FILE, --config FILE
carga la configuración del proyecto del mezclador desde ARCHIVO
-d, --debug
habilita los mensajes de registro de depuración

USO DE LA GUI

Después de iniciar jack_mixer, deberá crear al menos un canal de entrada y uno de salida a través de las entradas respectivas en el menú "Mixer" (ver sección MENÚ PRINCIPAL).

Luego conecte sus fuentes de audio a los puertos de entrada de audio JACK de jack_mixer (ver sección PUERTOS DE AUDIO Y MIDI DE JACK) utilizando jack_connect o herramientas gráficas como la ventana de conexiones de QJackCtl, Catia, Carla, etc. Conecte los puertos de salida del canal monitor o los puertos de salida de los canales de salida a los puertos de entrada de su interfaz de audio o cualquier otro puerto de entrada de audio JACK.

Luego ajuste los niveles de volumen de los canales de entrada y salida y el balance según sea necesario utilizando los controles deslizantes en cada tira de canal (ver sección ASOCIACIONES DE RATÓN para conocer formas de controlar los deslizadores y el enrutamiento).

PUERTOS DE AUDIO Y MIDI DE JACK

  • Para cada canal de entrada, jack_mixer creará un (si es un canal mono) o dos (estéreo) puertos de entrada de audio JACK. El(los) puerto(s) de entrada se nombrarán como la tira de canal de entrada, si es un canal mono, o con un sufijo " L" o " R" respectivamente, si es un canal estéreo.
  • Opcionalmente, para cada canal de entrada, crea un puerto de salida de audio directo, post-fader (mono) o par de puertos de salida (estéreo). Estos se nombran igual que sus puertos de entrada con " Out" o " Out L" / "Out R" appended.
  • Para cada canal de salida creará un puerto de salida de audio (mono) o dos (estéreo).
  • Adicionalmente creará un par de puertos de monitor de audio llamados "Monitor L" y "Monitor R".
  • Si jack_mixer fue compilado con soporte MIDI de JACK, también creará un puerto de entrada MIDI ("midi in") y uno de salida MIDI ("midi out").

MENÚ PRINCIPAL

Menú Principal:

Utilice el menú Mixer para:

  • Añadir un canal de entrada o salida.
  • Añadir un canal de salida.
  • Abrir un archivo con un diseño de mezclador preestablecido.
  • Guardar el diseño de mezclador actual en un archivo XML.
  • Salir de jack_mixer.

Utilice el menú Edit para:

  • Cambiar las propiedades de un canal de entrada o salida.
  • Eliminar un canal de entrada o salida.
  • Alternar todas las tiras de canal entre vista ancha y estrecha.
  • Limpiar el diseño del mezclador actual, es decir, eliminar todos los canales de entrada y salida.
  • Abrir el diálogo de preferencias de configuración.

Utilice el menú Help para mostrar el diálogo Acerca de de jack_mixer.

ASOCIACIONES DE RATÓN

Ventana principal:

•
Haga clic izquierdo y arrastre la línea divisoria vertical horizontalmente para establecer la distribución del tamaño de los paneles izquierdo y derecho para las tiras de canales de entrada y salida. Si un panel contiene más tiras de canal de las que caben en su tamaño horizontal, habrá barras de desplazamiento horizontales en la parte inferior del panel.

Encabezado de la tira de canal:

  • Haga doble clic en el encabezado de la tira de canal para abrir el diálogo de propiedades del canal.
  • Ctrl+clic izquierdo en el encabezado de la tira de canal para alternar la tira de canal entre vista ancha y estrecha.
  • Haga clic izquierdo y arrastre el encabezado de la tira de canal horizontalmente para reordenar las tiras de canal. Esto no afecta el orden de los puertos de salida JACK y los canales de entrada siempre se organizan en el lado izquierdo de la ventana principal de jack_mixer y los canales de salida en el lado derecho.

Grupos de control (canales de entrada):

Cada encabezado de canal de entrada tiene un grupo de control para cada canal de salida, que tiene el mismo color de fondo y etiqueta que el encabezado del canal de salida correspondiente.

Cada grupo de control de canal de salida muestra un botón pre/post-fader ("P") y un botón de mute ("M") y, opcionalmente, un botón de solo ("S").

  • Haga clic izquierdo en el botón pre/post-fader ("P") para alternar la señal enviada al canal de salida correspondiente entre la señal post-fader (apagado) y pre-fader (encendido) del canal de entrada.
  • Haga clic izquierdo en el botón mono ("M") para silenciar la señal del canal de entrada que va al canal de salida correspondiente.
  • Haga clic izquierdo en el botón solo ("S") para activar el solo del canal de entrada para el canal de salida correspondiente. es decir, solo la señal de este canal de entrada (más cualquier otro canal en solo) va a este canal de salida.

Lectura de volumen e indicador de pico:

  • Haga clic izquierdo en la lectura del nivel de volumen para introducir un valor manualmente y presione Enter para establecerlo.
  • Haga clic izquierdo/derecho en la lectura del nivel de volumen pico para restablecer la indicación de sobre-cero.
  • Haga clic central en la lectura del nivel de volumen pico para establecer el nivel de volumen de manera que el pico sea 0 dB con el nivel de entrada de señal actual.

Medidor de volumen:

•
Haga clic izquierdo en el botón pre-fader ("PRE") debajo del medidor de volumen para cambiar la señal que se mide, de post-fader (apagado) a pre-fader (encendido).

(aún no implementado)

Control deslizante de volumen:

  • Haga clic izquierdo y arrastre verticalmente en cualquier lugar del área del deslizador para establecer el nivel de volumen de salida del canal.
  • Gire la rueda del ratón hacia arriba o hacia abajo sobre el área del deslizador para aumentar o disminuir el nivel de volumen.
  • Haga clic derecho en cualquier lugar del área del deslizador para mover lentamente el nivel de volumen hacia la posición del clic.
  • Haga doble clic para establecer el nivel de volumen en -inf.
  • Ctrl+clic izquierdo para establecer el nivel de volumen en 0 dBFS.

Control deslizante de balance:

  • Haga clic izquierdo y arrastre horizontalmente en cualquier lugar del área del deslizador para establecer el balance entre el canal izquierdo y derecho de la señal de salida.
  • Gire la rueda del ratón hacia arriba o hacia abajo sobre el área del deslizador para mover el balance hacia la derecha o hacia la izquierda.
  • Haga clic derecho en cualquier lugar del área del deslizador para mover lentamente el balance hacia la posición del clic.
  • Haga doble clic para centrar el balance izquierdo/derecho.

Botones de canal:

  • Haga clic izquierdo en el botón mono ("M") para silenciar la señal del canal que va a todos los canales de salida (incluidos los salidas directas del canal).
  • Ctrl+clic izquierdo en el botón mono ("M") para un mute "exclusivo", es decir, la función de mute se activará en este canal de entrada o salida solamente y se desactivará en todos los demás canales de entrada o salida respectivamente.
  • Haga clic izquierdo en el botón solo ("S") para activar el solo de un canal de entrada, es decir, solo la señal de este canal va a todos los canales de salida (incluidas las salidas directas del canal).

    La función de solo es acumulativa, es decir, puede activar el solo en más de un canal de entrada y las señales de todos los canales en solo se

    enviarán a las salidas de monitor. Si presiona el botón solo de un canal de entrada, todas las demás señales de entrada (incluidas las que estaban previamente en solo) se silenciarán. Si presiona el botón solo de un canal de salida, todas las demás señales de entrada se silenciarán para esta salida.

GUI USAGE

The following list summarizes the available mouse and keyboard shortcuts within the GUI.

  • Left-click the mute ("M") button, to toggle muting. If muting is on, the signal from the channel is muted.
  • Left-click the solo ("S") button, to toggle soloing. If soloing is on, all channels, except the soloed one(s), will be muted.
  • Shift+left-click the solo ("S") button, to toggle soloing in "safe" mode. This means that if you are soloing channel A, and you shift+click on channel B, channel B will be added to the soloed channels. If you shift+click on channel A again, it will be removed from the soloed channels.
  • Ctrl+left-click the mute ("M") button acts like left-clicking but also synchronizes the muted state on all output channel control groups of the channel with the main channel mute button.

    Output channel control groups, where the mute function was already active before Ctrl+left-clicking the mute button are unaffected, i.e. it will stay activated.

  • When soloing is activated on one or more channels, a right-click on the solo button of any channel will activate soloing on all channels. This is useful when you want to solo all channels simultaneously. The solo function will be activated on all channels, and the solo state will be deactivated on all channels.
  • When muting is activated on one or more channels, a right-click on the mute button of any channel will mute all channels. This is useful when you want to mute all channels simultaneously. The mute function will be activated on all channels, and the mute state will be deactivated on all channels.
  • Clicking on the channel name will open a dialog, where you can rename the channel.
  • Left-click the "SM" button, to toggle the solo mode. The available modes are:
    • Off: No channel is soloed.
    • Normal: Soloing is activated on the selected channel(s).
    • Exclusive: Soloing is activated on the selected channel(s) only. All other channels will be muted.

    When the solo mode is set to Normal or Exclusive, the selected channels will be highlighted. The "SM" button will show the current mode. Note that the solo function will be activated on all output channels that are associated with the selected input channel. Soloing will also be activated on the "Monitor L/R" outputs.

    Output channels have no solo button.

  • Ctrl+left-click the solo ("SM") button for "exclusive" solo, i.e. the solo function will be activated on this channel only and deactivated on all other input channels.
  • Right-clicking the mute ("M") button acts like left-clicking but also synchronizes the muted state on all output channel control groups of the channel with the main channel mute button.

    Output channel control groups, where the mute function was already active before righ-clicking the mute button are unaffected, i.e. it will stay activated.

  • Right-clicking the solo ("S") button acts like left-clicking but also synchronizes the soloed state on all output channel control groups of the channel with the main channel solo button.

    Output channel control groups, where the solo function was already active before righ-clicking the solo button are unaffected, i.e. it will stay activated.

  • Left-click the monitor ("MON") button, to toggle monitoring. If monitoring is on, the (post-fader) signal from the channel is sent to the "Monitor L/R" outputs. The monitor function is exclusive, i.e. activating monitoring on a channel, will turn off monitoring on any other channel.

COMPATIBILITY

jack_mixer is fully compatible with the New Session Manager (NSM) protocol and provides Level 1 (L1) support for the LADISH protocol. When running as an NSM client, the mixer layout and current state will be saved in the NSM session. When started as an L1 client by LADISH, the mixer layout and current state will be saved in the LADISH studio session or project (the first time LADISH requests jack_mixer to save a project, it will open a "Save as" dialog).

FILES

<XDG_CONFIG_HOME>/jack_mixer/preferences.ini
This file stores global settings for jack_mixer.

ENVIRONMENT

LANGUAGE, LC_ALL, LC_MESSAGES, and LANG
The first of these environment variables set to a non-empty value is used to determine the language(s) for loading gettext translation files if the language is not set in the global settings. The value should be a colon separated list of language codes.
LOCALEDIR
With this environment variable, the base directory for the gettext translation files can be changed from the default set at compile time, which is usually <prefix>/share/locale.
JACK_MIXER_DEBUG
When this environment variable is set, the logging level in the Python layer is set to DEBUG unless it is overwritten by the -d|--debug command line switch.
NSM_URL
When this environment variable is set, jack_mixer will act as a New Session Manager (NSM) session client.

SIGNALS

SIGUSR1
In accordance with Level 1 support of LADISH, jack_mixer saves the current mixer layout and state on receiving a USR1 signal.
SIGINT | SIGTERM
When receiving an INT or TERM signal, jack_mixer will either exit the application immediately or, if enabled in the preferences, will show a confirmation dialog, allowing the user to either quit or cancel the action.
