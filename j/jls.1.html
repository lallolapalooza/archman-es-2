NOMBRE

jls - Listar el contenido del diario de un sistema de archivos

SINOPSIS

jls [-f tipo_sf ] [-vV] [-i tipo_img] [-o offset_img] [-b tamaño_sector_disp] imagen [imágenes] [inodo]

DESCRIPCIÓN

jls lista los registros y entradas en el diario de un sistema de archivos. Si se proporciona un inodo, buscará allí el diario. De lo contrario, usará la ubicación predeterminada. La salida lista el número de bloque del diario y una descripción.

ARGUMENTOS

-f tipo_sf
Especifica el tipo de sistema de archivos. Usa '-f list' para listar los tipos de sistemas de archivos soportados. Si no se especifica, se usan métodos de autodetección.
-i tipo_img
Identifica el tipo de archivo de imagen, como raw o split. Usa '-i list' para listar los tipos soportados. Si no se especifica, se usan métodos de autodetección.
-o offset_img
El desplazamiento de sector donde comienza el sistema de archivos en la imagen.
-b tamaño_sector_disp
El tamaño, en bytes, de los sectores del dispositivo subyacente. Si no se especifica, se usa el valor en el formato de imagen (si existe) o se asumen 512 bytes.
-V
Mostrar versión
-v
salida detallada
imagen [imágenes]
Una (o más si está dividida) imagen(es) de disco o partición cuyo formato se especifica con '-i'.
[inodo]
El inodo donde se puede encontrar el diario del sistema de archivos.

EJEMPLOS

jls -f linux-ext3 img.dd
