javaws(1) Manual de Comandos Generales javaws(1)

NOMBRE

javaws - un cliente Java Web Start

SINOPSIS

javaws [-opciones-ejecutar] archivo jnlp
javaws [-opciones-controlar]

DESCRIPCIÓN

javaws es una implementación de un cliente JNLP. Utiliza un archivo JNLP (Java Network Launch Protocol) para ejecutar de forma segura una aplicación Java remota o un applet Java. Esta implementación de javaws proviene del proyecto IcedTea y se basa en el proyecto NetX.

Un archivo JNLP es un archivo xml que describe cómo ejecutar de forma segura una aplicación Java remota o un applet Java.

OPCIONES

Al especificar opciones, el nombre del archivo jnlp puede ir después del comando, después de la opción -jnlp, después de una opción sin argumentos, o después de un argumento con una opción que toma un argumento. Un archivo html que lanza un jnlp puede especificarse después de la opción -html.
El archivo-jnlp puede ser una url o una ruta local.
El archivo JNLP solo debe especificarse una vez, ya sea como argumento principal, después de -jnlp o a través de un archivo html.

Opciones de control:

-about
Muestra una aplicación de ejemplo. (No se espera argumento)
-help
Imprime información sobre los comandos compatibles y el uso básico. (No se espera argumento)
-license
Muestra la licencia GPL y sale. (No se espera argumento)
-viewer
Muestra el visor de certificados confiables. (No se espera argumento)
-Xcacheids
Lista los IDs disponibles en la caché, que puedes usar para eliminar aplicaciones individuales. (No se espera argumento o uno)
-Xclearcache
Limpia la caché de aplicaciones JNLP. Si pasas un argumento, solo se elimina la aplicación especificada. (No se espera argumento o uno)

Opciones de ejecución:

-allowredirect
Sigue las redirecciones HTTP. (No se espera argumento)
-arg arg
Añade un argumento de aplicación antes de lanzar. (Se esperan uno o más argumentos)
-browser
Lanza el navegador incrustado. ¡Úsalo solo si es muy necesario! (Se esperan uno o más argumentos)
-headless
Deshabilita la ventana de descarga y otras interfaces de usuario. (No se espera argumento)
-html
Ubicación del archivo HTML para lanzar (url o archivo). Puedes usar el parámetro ALL o números (como 1 2 5) para seleccionar applets en la página. Aunque es experimental, este interruptor debería mantenerte a salvo. (Se esperan uno o más argumentos)
-jnlp
Ubicación del archivo JNLP para lanzar (url o archivo). (Se espera exactamente un argumento)
-nosecurity
Deshabilita el entorno de ejecución seguro. También necesitas deployment.security.itw.ignorecertissues para solucionar firmas corruptas. (No se espera argumento)
-noupdate
Deshabilita la comprobación de actualizaciones. (No se espera argumento)
-param nombre=valor
Añade un parámetro de applet antes de lanzar. (Se esperan uno o más argumentos)
-property nombre=valor
Establece una propiedad del sistema antes de lanzar. (Se esperan uno o más argumentos)
-startuptracker
Habilita el rastreador de tiempo de inicio. (No se espera argumento)
-strict
Habilita la comprobación estricta del formato del archivo JNLP. (No se espera argumento)
-update segundos
Comprueba si hay actualizaciones. (Se espera exactamente un argumento)
-verbose
Habilita la salida detallada. (No se espera argumento)
-version
Imprime la versión de IcedTea-Web y sale. (No se espera argumento)
-Xignoreheaders
Omite la verificación de encabezados de jar. (No se espera argumento)
-xml
Utiliza un analizador XML estricto para analizar el archivo JNLP. (No se espera argumento)
-Xnofork
No crea otra JVM. (No se espera argumento)
-Xoffline
Impide la conexión de red de ITW. Solo se utilizará la caché. La aplicación aún puede conectarse. (No se espera argumento)
-Xtrustnone
En lugar de preguntar al usuario, predetermina todas las respuestas como no. (No se espera argumento)

EJEMPLOS

javaws -about
Muestra información básica de ayuda y acerca de.
javaws -about -headless
Muestra información básica de ayuda y acerca de solo en la terminal.
javaws -Xnofork -Xignoreheaders -allowredirect -Xoffline http://mypage.web/dangerous.jnlp
Iniciará la aplicación dangerous.jnlp, originalmente de mypage.web, sin descargarla, sin verificación de encabezados y en una VM única forzada.
