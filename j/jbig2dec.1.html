NOMBRE

jbig2dec - Convertidor de formato de archivo especializado en decodificación JBIG2

SINOPSIS

jbig2dec [opciones] archivo.jbig2
jbig2dec [opciones] flujo-global flujo-página

DESCRIPCIÓN

El comando jbig2dec convierte archivos JBIG2 a archivos png o pbm.

Cuando se le pasa un único argumento de archivo, se interpreta como un flujo de archivo JBIG2, con organización secuencial o de acceso aleatorio.

Cuando se le pasan dos argumentos de flujo, se interpretan como las porciones global y específica de página de una organización incrustada, como se usa en PDF. Si una página en particular no hace referencia a ningún flujo de segmentos global, se puede pasar /dev/null como argumento flujo-global para solicitar el analizador incrustado.

OPCIONES

Las opciones son las siguientes:

-e, --embedded
Espera un flujo de bits incrustado sin encabezado de archivo.
-o archivo, --output archivo
Almacena la salida decodificada en archivo. Por defecto, utiliza el nombre del archivo de entrada con una extensión diferente. Se establece en - para la salida estándar.
-t tipo, --format tipo
Fuerza un formato de archivo de salida particular. Los admitidos son png y pbm.
-d, --dump
Imprime la estructura del archivo JBIG2 en lugar de decodificarla explícitamente.
-m, --hash
Imprime un hash del documento decodificado.
-q, --quiet
Suprime advertencias y otra información de diagnóstico.
-v, --verbose
Informa información adicional sobre el proceso de decodificación. Pase solo -v para obtener información sobre el archivo mientras se está decodificando. Esto es lo mismo que --verbose=2. Pase --verbose=3 o superior para obtener información de depuración.
-V, --version
Muestra la información de la versión del programa.
-h, --help
Muestra un resumen de uso.
