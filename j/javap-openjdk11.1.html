javap(1) Herramientas básicas javap(1)

NOMBRE

javap - Desensambla uno o más archivos de clase.

SINOPSIS

javap [opciones] archivo_clase...

opciones

Las opciones de línea de comandos. Ver Opciones.

archivo_clase

Una o más clases separadas por espacios a ser procesadas para anotaciones como DocFooter.class. Puedes especificar una clase que se pueda encontrar en la ruta de clases, por su nombre de archivo o con una URL como file:///home/user/myproject/src/DocFooter.class.

DESCRIPCIÓN

El comando javap desensambla uno o más archivos de clase. La salida depende de las opciones utilizadas. Cuando no se usan opciones, el comando javap imprime los campos y métodos públicos y protegidos del paquete de las clases pasadas. El comando javap imprime su salida en stdout.

OPCIONES

-help
--help
-?

Imprime un mensaje de ayuda para el comando javap.

-version

Imprime información de la versión.

-l

Imprime tablas de variables locales y de línea.

-public

Muestra solo clases y miembros públicos.

-protected

Muestra solo clases y miembros protegidos y públicos.

-private
-p

Muestra todas las clases y miembros.

-Jopción

Pasa la opción especificada a la JVM. Por ejemplo: 
javap -J-version
javap -J-Djava.security.manager -J-Djava.security.policy=MyPolicy MyClassName
Para más información sobre las opciones de la JVM, consulta la documentación del comando.

-s

Imprime las firmas de tipos internos.

-sysinfo

Muestra información del sistema (ruta, tamaño, fecha, hash MD5) de la clase que se está procesando.

-constants

Muestra las constantes static final.

-c

Imprime el código desensamblado, por ejemplo, las instrucciones que componen los bytecodes de Java, para cada uno de los métodos de la clase.

-verbose

Imprime el tamaño de la pila, el número de locales y argumentos para los métodos.

-classpath ruta

Especifica la ruta que el comando javap utiliza para buscar clases. Anula el valor predeterminado o la variable de entorno CLASSPATH cuando está configurada.

-bootclasspath ruta

Especifica la ruta desde la cual cargar las clases de arranque. Por defecto, las clases de arranque son las clases que implementan el núcleo de la plataforma Java ubicadas en jre/lib/rt.jar y varios otros archivos JAR.

-extdir dirs

Anula la ubicación donde se buscan las extensiones instaladas. La ubicación predeterminada para las extensiones es el valor de java.ext.dirs.

EJEMPLO

Compila la siguiente clase DocFooter:

import java.awt.*;
import java.applet.*;
 
public class DocFooter extends Applet {
        String date;
        String email;
 
        public void init() {
                resize(500,100);
                date = getParameter("LAST_UPDATED");
                email = getParameter("EMAIL");
        }
 
        public void paint(Graphics g) {
                g.drawString(date + " by ",100, 15);
                g.drawString(email,290,15);
        }
}
