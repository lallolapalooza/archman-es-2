NOMBRE

jose-jwe-enc - Cifra texto plano usando una o más JWK/contraseñas

SINOPSIS

jose jwe enc [-i JWE] -I PT -k JWK [-p] [-r RCP] [-o JWE] [-O CT] [-c]

DESCRIPCION

El comando jose jwe enc cifra datos usando una o más JWK (-k) o contraseñas (-p). Al especificar más de una JWK o contraseña, el descifrado se realizará con cualquiera de las claves proporcionadas.

Se puede crear un JWE desvinculado especificando la opción -O. En este caso, el texto cifrado decodificado se escribirá en la salida especificada y no se incluirá en el JWE.

Si solo se utiliza una clave (-k o -p), el JWE resultante puede ser emitido en Serialización Compacta JWE utilizando la opción -c.

Este comando utiliza un enfoque basado en plantillas para construir un JWE. Puede especificar plantillas del propio JWE (-i) o del Objeto Destinatario JWE (-r). Los atributos especificados en cualquiera de estas plantillas aparecerán sin modificar en la salida. Una excepción a esta regla es que la Cabecera Protegida JWE debe especificarse en su forma decodificada en la plantilla. Este comando la codificará automáticamente como parte del proceso de cifrado.

Si especifica un Parámetro de Cabecera JOSE (a través de las opciones -i o -r) que afecta a la construcción del JWE, este comando intentará comportarse de acuerdo con este parámetro como si fuera una configuración. Por ejemplo, especificar el parámetro "zip" en la Cabecera Protegida JWE hará que el texto plano se comprima antes de cifrarlo. Actualmente, jose modificará su comportamiento para los Parámetros de Cabecera JOSE "alg", "enc" y "zip" (ver RFC 7516 Sección 4.1.3), así como para los parámetros específicos del algoritmo para los algoritmos que soportamos (ver RFC 7518 Sección 4).

Sin embargo, no es necesario proporcionar ninguna plantilla: jose jwe enc rellenará automáticamente los parámetros "alg" y "enc" infiriendo los algoritmos correctos de las claves de entrada proporcionadas (JWK o contraseña). Por lo tanto, las opciones -i y -r generalmente deben usarse para proporcionar metadatos JWE extendidos.

OPCIONES

•-i JSON, --input=JSON : Analizar JWE desde JSON
•-i ARCHIVO, --input=ARCHIVO : Leer JWE desde ARCHIVO
•-i -, --input=-: Leer JWE desde entrada estándar
•-I ARCHIVO, --detached=ARCHIVO : Leer texto cifrado decodificado desde ARCHIVO
•-I -, --detached=- : Leer texto cifrado decodificado desde entrada estándar
•-r ARCHIVO, --recipient=ARCHIVO : Leer plantilla de destinatario JWE desde ARCHIVO
•-r -, --recipient=- : Leer plantilla de destinatario JWE desde entrada estándar
•-k ARCHIVO, --key=ARCHIVO : Leer JWK(Set) desde ARCHIVO
•-k -, --key=- : Leer JWK(Set) desde entrada estándar
•-p, --password : Solicitar una contraseña de cifrado
•-o ARCHIVO, --output=ARCHIVO : Escribir JWE en ARCHIVO
•-o -, --output=- : Escribir JWE a stdout (por defecto)
•-O ARCHIVO, --detach=ARCHIVO : Desvincular texto cifrado y decodificar a ARCHIVO
•-O -, --detach=- : Desvincular texto cifrado y decodificar a salida estándar
•-c, --compact : Emitir JWE usando serialización compacta

EJEMPLOS

Cifrar datos con una clave simétrica usando Serialización JSON JWE:

$ jose jwk gen -i '{"alg":"A128GCM"}' -o key.jwk
$ jose jwe enc -I msg.txt -k key.jwk -o msg.jwe

Cifrar datos con una contraseña usando Serialización Compacta JWE:

$ jose jwe enc -I msg.txt -p -c -o msg.jwe
