NOMBRE

jshell - evalúa interactivamente declaraciones, sentencias y expresiones del lenguaje de programación Java en un bucle leer-evaluar-imprimir (REPL)

SINOPSIS

jshell [opciones] [archivos-a-cargar]

opciones
Opciones de línea de comandos, separadas por espacios. Ver Opciones para jshell.
archivos-a-cargar
Uno o más scripts para ejecutar al iniciar la herramienta. Los scripts pueden contener fragmentos de código o comandos JShell válidos.

El script puede ser un archivo local o uno de los siguientes scripts predefinidos:

DEFAULT
Carga las entradas predeterminadas, que se utilizan comúnmente como importaciones.
JAVASE
Importa todos los paquetes de Java SE.
PRINTING
Define los métodos print, println y printf como métodos de jshell para su uso dentro de la herramienta.
TOOLING
Define javac, jar y otros métodos para ejecutar herramientas JDK a través de su interfaz de línea de comandos dentro de la herramienta jshell.

Para más de un script, usa un espacio para separar los nombres. Los scripts se ejecutan en el orden en que se ingresan en la línea de comandos. Los scripts de la línea de comandos se ejecutan después de los scripts de inicio. Para ejecutar un script después de que JShell se inicia, usa el comando /open.

Para aceptar entrada de la entrada estándar y suprimir la E/S interactiva, introduce un guión (-) para archivos-a-cargar. Esta opción habilita el uso de la herramienta jshell en cadenas de tuberías.

DESCRIPCIÓN

JShell proporciona una forma de evaluar interactivamente declaraciones, sentencias y expresiones del lenguaje de programación Java, lo que facilita el aprendizaje del lenguaje, la exploración de código y APIs desconocidas, y el prototipado de código complejo. Se aceptan sentencias Java, definiciones de variables, definiciones de métodos, definiciones de clases, sentencias de importación y expresiones. Los fragmentos de código ingresados se llaman snippets.

A medida que se ingresan los snippets, se evalúan y se proporciona retroalimentación. La retroalimentación varía desde los resultados y explicaciones de las acciones hasta nada, dependiendo del snippet ingresado y el modo de retroalimentación elegido. Los errores se describen independientemente del modo de retroalimentación. Comienza con el modo verboso para obtener la mayor retroalimentación mientras aprendes la herramienta.

Las opciones de línea de comandos están disponibles para configurar el entorno inicial cuando se inicia JShell. Dentro de JShell, los comandos están disponibles para modificar el entorno según sea necesario.

Se pueden cargar snippets existentes desde un archivo para inicializar una sesión de JShell, o en cualquier momento dentro de una sesión. Los snippets se pueden modificar dentro de la sesión para probar diferentes variaciones y realizar correcciones. Para conservar los snippets para su uso posterior, guárdalos en un archivo.

OPCIONES PARA JSHELL

--add-exports módulo/paquete
Especifica un paquete que se considerará exportado desde su módulo de definición.
--add-modules módulo[,módulo...]
Especifica los módulos raíz a resolver además del módulo inicial.
-Cbandera
Proporciona una bandera para pasar al compilador. Para pasar más de una bandera, proporciona una instancia de esta opción para cada bandera o argumento de bandera necesario.
--class-path ruta
Especifica los directorios y archivos en los que se buscan los archivos de clase. Esta opción anula la ruta en la variable de entorno CLASSPATH. Si la variable de entorno no está establecida y esta opción no se usa, entonces se busca el directorio actual. Para Linux y macOS, usa dos puntos (:) para separar los elementos de la ruta. Para Windows, usa punto y coma (;) para separar los elementos.
--enable-preview
Permite que el código dependa de las características de vista previa de esta versión.
--execution especificación
Especifica un motor de ejecución alternativo, donde especificación es una especificación de ExecutionControl. Consulta la documentación del paquete jdk.jshell.spi para conocer la sintaxis de la especificación.
--feedback modo
Establece el nivel inicial de retroalimentación proporcionada en respuesta a lo que se ingresa. El nivel inicial puede ser anulado dentro de una sesión usando el comando /set feedback modo. El valor predeterminado es normal.

Los siguientes valores son válidos para modo:

verbose
Proporciona retroalimentación detallada para las entradas. Se muestra información adicional sobre la acción realizada después del resultado de la acción. El siguiente prompt se separa de la retroalimentación con una línea en blanco.
normal
Proporciona una cantidad promedio de retroalimentación. El siguiente prompt se separa de la retroalimentación con una línea en blanco.
concise
Proporciona retroalimentación mínima. El siguiente prompt sigue inmediatamente al fragmento de código o a la retroalimentación.
silent
No proporciona retroalimentación. El siguiente prompt sigue inmediatamente al fragmento de código.
custom
Proporciona retroalimentación personalizada basada en cómo se define el modo. Los modos de retroalimentación personalizados se crean dentro de JShell usando el comando /set mode.
--help o -h o -?
Imprime un resumen de las opciones estándar y sale de la herramienta.
--help-extra o -X
Imprime un resumen de las opciones no estándar y sale de la herramienta. Las opciones no estándar pueden cambiar sin previo aviso.
-Jbandera
Proporciona una bandera para pasar al sistema de ejecución. Para pasar más de una bandera, proporciona una instancia de esta opción para cada bandera o argumento de bandera necesario.
--module-path ruta-módulos
Especifica dónde encontrar los módulos de la aplicación. Para Linux y macOS, usa dos puntos (:) para separar los elementos de la ruta. Para Windows, usa punto y coma (;) para separar los elementos.
--no-startup
Evita que los scripts de inicio se ejecuten cuando JShell se inicia. Usa esta opción para ejecutar solo los scripts ingresados en la línea de comandos cuando se inicia JShell, o para iniciar JShell sin ninguna información pre-cargada si no se ingresan scripts. Esta opción no se puede usar si se usa la opción --startup.
-q
Establece el modo de retroalimentación en conciso, lo que equivale a ingresar --feedback concise.
-Rbandera
Proporciona una bandera para pasar al sistema de ejecución remoto. Para pasar más de una bandera, proporciona una instancia de esta opción para cada bandera o argumento de bandera a pasar.
-s
Establece el modo de retroalimentación en silencioso, lo que equivale a ingresar --feedback silent.
--show-version
Imprime la información de la versión e inicia la herramienta.
--startup archivo
Anula el script de inicio predeterminado para esta sesión. El script puede contener fragmentos de código o comandos válidos.

El script puede ser un archivo local o uno de los siguientes scripts predefinidos:

DEFAULT
Carga las entradas predeterminadas, que se utilizan comúnmente como importaciones.
JAVASE
Importa todos los paquetes de Java SE.
PRINTING
Define los métodos print, println y printf como métodos de jshell para su uso dentro de la herramienta.
TOOLING
Define javac, jar y otros métodos para ejecutar herramientas JDK a través de su interfaz de línea de comandos dentro de la herramienta jshell.

Para más de un script, proporciona una instancia separada de esta opción para cada script. Los scripts de inicio se ejecutan cuando se inicia JShell por primera vez y cuando se reinicia la sesión con el comando /reset, /reload o /env. Los scripts de inicio se ejecutan en el orden en que se ingresan en la línea de comandos.

Esta opción no se puede usar si se usa la opción --no-startup.

-v
Establece el modo de retroalimentación en verboso, lo que equivale a ingresar --feedback verbose.
--version
Imprime la información de la versión y sale de la herramienta.

/establecer [configuración]
Establece información de configuración, incluido el editor externo, la configuración de inicio y el modo de retroalimentación. Este comando también se utiliza para crear un modo de retroalimentación personalizado con valores personalizados de prompt, formato y truncamiento. Si no se introduce ninguna configuración, se muestran la configuración actual del editor, la configuración de inicio y el modo de retroalimentación.

Los siguientes valores son válidos para configuración:

editor [opciones] [comando]
Establece el comando utilizado para iniciar un editor externo cuando se introduce el comando /editar. El comando puede incluir argumentos separados por espacios. Si no se introduce ningún comando u opción, se muestra la configuración actual.

Las siguientes opciones son válidas:

-predeterminado
Establece el editor en el editor predeterminado proporcionado con JShell. Esta opción no se puede usar si se introduce un comando para iniciar un editor.
-eliminar
Establece el editor en el que estaba activo cuando comenzó la sesión. Si se utiliza con la opción -conservar, se elimina la configuración del editor conservada y el editor se establece en la primera de las siguientes variables de entorno encontradas: JSHELLEDITOR, VISUAL o EDITOR. Si ninguna de las variables de entorno del editor está configurada, esta opción establece el editor en el editor predeterminado.

Esta opción no se puede usar si se introduce un comando para iniciar un editor.

-conservar
Conserva la configuración del editor entre sesiones. Si no se introduce ninguna otra opción ni comando, se guarda la configuración actual.
-esperar
Solicita al usuario que indique cuándo se ha completado la edición. De lo contrario, el control vuelve a JShell cuando el editor sale. Utilice esta opción si el editor que se está utilizando sale inmediatamente, por ejemplo, cuando ya existe una ventana de edición. Esta opción solo es válida cuando se introduce un comando para iniciar un editor.
retroalimentacion [modo]
Establece el modo de retroalimentación utilizado para responder a la entrada. Si no se introduce ningún modo, se muestra el modo actual.

Los siguientes modos son válidos: conciso, normal, silencioso, verboso y cualquier modo personalizado creado con el comando /establecer modo.

formato modo campo "cadena-formato" selector
Establece el formato de la retroalimentación proporcionada en respuesta a la entrada. Si no se introduce ningún modo, se muestran los formatos actuales de todos los campos para todos los modos de retroalimentación. Si solo se introduce un modo, se muestran los formatos actuales para ese modo. Si solo se introducen un modo y un campo, se muestran los formatos actuales para ese campo.

Para definir un formato, los siguientes argumentos son necesarios:

modo
Especifica un modo de retroalimentación al que se aplica el formato de respuesta. Solo se pueden modificar los modos personalizados creados con el comando /establecer modo.
campo
Especifica un campo específico del contexto al que se aplica el formato de respuesta. Los campos se describen en la ayuda en línea, a la que se accede desde JShell utilizando el comando /ayuda /establecer formato.
"cadena-formato"
Especifica la cadena que se utilizará como formato de respuesta para el campo y selector especificados. La estructura de la cadena de formato se describe en la ayuda en línea, a la que se accede desde JShell utilizando el comando /ayuda /establecer formato.
selector
Especifica el contexto en el que se aplica el formato de respuesta. Los selectores se describen en la ayuda en línea, a la que se accede desde JShell utilizando el comando /ayuda /establecer formato.
modo [nombre-modo] [modo-existente] [opciones]
Crea un modo de retroalimentación personalizado con el nombre de modo proporcionado. Si no se introduce ningún nombre de modo, se muestran la configuración de todos los modos, que incluye la configuración de modo, prompt, formato y truncamiento. Si se proporciona el nombre de un modo existente, se copian la configuración del modo existente al modo que se está creando.

Las siguientes opciones son válidas:

-comando|-silencioso
Especifica el nivel de retroalimentación que se muestra para los comandos al utilizar el modo. Esta opción es obligatoria al crear un modo de retroalimentación. Utilice -comando para mostrar información y retroalimentación de verificación para los comandos. Utilice -silencioso para mostrar solo la retroalimentación esencial para los comandos, como los mensajes de error.
-eliminar
Elimina el modo de retroalimentación con nombre para esta sesión. Se requiere el nombre del modo a eliminar. Para eliminar permanentemente un modo conservado, utilice la opción -conservar con esta opción. Los modos predefinidos no se pueden eliminar.
-conservar
Conserva el modo de retroalimentación con nombre entre sesiones. Se requiere el nombre del modo a conservar.

Configure el nuevo modo de retroalimentación utilizando los comandos /establecer prompt, /establecer formato y /establecer truncamiento.

Para empezar a usar el nuevo modo, utilice el comando /establecer retroalimentacion.

EJEMPLO DE CREACIÓN DE UN MODO DE RESPUESTA

PERSONALIZADO

El modo de respuesta determina el prompt que se muestra, los mensajes de respuesta que se proporcionan a medida que se introducen los fragmentos, y la longitud máxima de un valor mostrado. Se proporcionan modos de respuesta predefinidos. También se proporcionan comandos para crear modos de respuesta

personalizados.

Use el comando /set mode para crear un nuevo modo de respuesta. En el siguiente ejemplo, el nuevo modo, mymode, se basa en el modo de respuesta predefinido normal, y se muestra la respuesta de verificación de

comandos: 

jshell> /set mode mymode normal -command
|  Nuevo modo de respuesta creado: mymode

Debido a que el nuevo modo se basa en el modo normal, los prompts son los mismos. El siguiente ejemplo muestra cómo ver qué prompts se usan y luego cambia los prompts a cadenas personalizadas. La primera cadena representa el prompt estándar de JShell. La segunda cadena representa el prompt para líneas adicionales en fragmentos

multilínea. 

jshell> /set prompt mymode
|  /set prompt mymode "\njshell> " "   ...> "
jshell> /set prompt mymode "\nprompt$ " "   continue$ "

La longitud máxima de un valor mostrado se controla mediante la configuración de truncamiento. Diferentes tipos de valores pueden tener diferentes longitudes. El siguiente ejemplo establece un valor de truncamiento general de 72, y un valor de truncamiento de 500 para expresiones de valor de

variable: 

jshell> /set truncation mymode 72
jshell> /set truncation mymode 500 varvalue

La respuesta que se muestra después de introducir los fragmentos se controla mediante la configuración de formato y se basa en el tipo de fragmento introducido y en la acción tomada para ese fragmento. En el modo predefinido normal, la cadena creada se muestra cuando se crea un método. El siguiente ejemplo muestra cómo cambiar esa cadena a

definido: 

jshell> /set format mymode action "defined" added-primary

Use el comando /set feedback para comenzar a usar el modo de respuesta que acaba de crear. El siguiente ejemplo muestra el modo personalizado en

uso: 

jshell> /set feedback mymode
|  Modo de respuesta: mymode
prompt$ int square (int num1){
   continue$ return num1*num1;
   continue$ }
|  método square(int) definido
