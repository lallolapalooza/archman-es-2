NOMBRE

jgmenuunicode - Una visión general del uso de unicode en jgmenu

INTRODUCCIÓN

Los caracteres unicode pueden ser mostrados por jgmenu. Pueden ser utilizados en:

•
Datos CSV
•
Widgets
•
Archivo de configuración

A lo largo de este documento, los puntos de código unicode se referirán escribiendo u+ seguido de su número hexadecimal. En los ejemplos, se usará u+1234.

CARACTERES UNICODE EN TERMINAL

Los terminales manejan el unicode de forma diferente. Para un soporte completo, evite xterm y urxvt, y opte por algo basado en libvte como sakura o gnome-terminal. En una terminal, puede producir un carácter unicode emitiendo

printf '%b' '\\u1234'

En terminales libvte, puede presionar ctrl+shift+u y luego ingresar la secuencia hexadecimal.

CARACTERES UNICODE EN VIM

Mientras está en modo inserción, presione ctrl+V y luego escriba u1234.

Use el comando ga para mostrar el valor hexadecimal del carácter bajo el cursor.

SELECTORES DE VARIACIÓN

Algunos caracteres unicode pueden ser representados como emoji o texto. Caracteres invisibles especiales llamados selectores de variación pueden ser usados para forzar una presentación u otra. Añada el selector de presentación de texto (u+fe0e) o el selector de presentación de emoji (u+fe0f), para forzar texto o emoji respectivamente. Por ejemplo:

u+1f50d u+fe0f 🔍

u+1f50d u+fe0e 🔍︎
