JALV.QT5(1) Manual de Comandos Generales JALV.QT5(1)

NOMBRE

jalv.qt - Ejecuta un plugin LV2 como una aplicación JACK (versión Qt).

SINOPSIS

jalv.qt URI_DEL_PLUGIN

DESCRIPCIÓN

Esta es una versión de Jalv con una GUI implementada en Qt. Se utiliza principalmente para fines de prueba de desarrolladores; para un programa listo para producción, utiliza jalv.gtk.

VER TAMBIÉN

jalv(1), jalv.gtk(1), jalv.gtk3(1), lv2ls(1), jackd(1)
