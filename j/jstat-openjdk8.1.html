DESCRIPCIÓ

N

El comando jstat muestra estadísticas de rendimiento para una VM Java HotSpot instrumentada. La JVM de destino se identifica por su identificador de máquina virtual, o la opción vm

id
.

IDENTIFICADOR DE LA MÁQUINA

VIRTUAL

La sintaxis de la cadena vmid corresponde a la sintaxis de una

URI: 
[protocol:][//]lvmid[@ho
stname[:port]
/servername]

protoco

l
El protocolo de comunicación. Si el valor protocol se omite y no se especifica un nombre de host, entonces el protocolo predeterminado es un protocolo local optimizado específico de la plataforma. Si el valor protocol se omite y se especifica un nombre de host, entonces el protocolo predeterminado es rmi
.

lvmi

d
El identificador local de la máquina virtual para la JVM de destino. El lvmid es un valor específico de la plataforma que identifica de forma única una JVM en un sistema. El lvmid es el único componente requerido de un identificador de máquina virtual. El lvmid es típicamente, pero no necesariamente, el identificador de proceso del sistema operativo para el proceso JVM de destino. Puede usar el comando jps para determinar el lvmid. Además, puede determinar el lvmid en las plataformas Solaris, Linux y OS X con el comando ps, y en Windows con el Administrador de tareas de
Windows.

hostnam

e
Un nombre de host o dirección IP que indica el host de destino. Si el valor hostname se omite, entonces el host de destino es el host
local.

por

t
El puerto predeterminado para comunicarse con el servidor remoto. Si el valor hostname se omite o el valor protocol especifica un protocolo local optimizado, entonces el valor port se ignora. De lo contrario, el tratamiento del parámetro port es específico de la implementación. Para el protocolo predeterminado rmi, el valor port indica el número de puerto para el rmiregistry en el host remoto. Si el valor port se omite y el valor protocol indica rmi, entonces se usa el puerto rmiregistry predeterminado (1099)
.

servernam

e
El tratamiento del parámetro servername depende de la implementación. Para el protocolo local optimizado, este campo se ignora. Para el protocolo rmi, representa el nombre del
objeto remoto RMI
en el host remoto.

OPCIONE

S

El comando jstat admite dos tipos de opciones, opciones generales y opciones de salida. Las opciones generales hacen que el comando jstat muestre información de uso y versión simples. Las opciones de salida determinan el contenido y el formato de la salida

estadística.

Todas las opciones y su funcionalidad están sujetas a cambios o eliminación en versiones

futuras.

Opciones

generales

Si especifica una de las opciones generales, entonces no puede especificar ninguna otra opción o

parámetro.

-hel

p
Muestra un mensaje de
ayuda.

-option

s
Muestra una lista de o
pciones estáticas. Ver
Opciones de salida.

Opciones de

salida

Si no especifica una opción general, entonces puede especificar opciones de salida. Las opciones de salida determinan el contenido y el formato de la salida del comando jstat, y consisten en un único statOption, más cualquiera de las otras opciones de salida (-h, -t, y -J). El statOption debe ir

primero.

La salida se formatea como una tabla, con columnas separadas por espacios. Una fila de encabezado con títulos describe las columnas. Use la opción -h para establecer la frecuencia con la que se muestra el encabezado. Los nombres de los encabezados de las columnas son consistentes entre las diferentes opciones. En general, si dos opciones proporcionan una columna con el mismo nombre, entonces la fuente de datos de las dos columnas es la

misma.

Use la opción -t para mostrar una columna de marca de tiempo, etiquetada Timestamp como la primera columna de salida. La columna Timestamp contiene el tiempo transcurrido, en segundos, desde que la JVM de destino se inició. La resolución de la marca de tiempo depende de varios factores y está sujeta a variación debido a la programación de hilos retrasada en sistemas muy

cargados.

Use los parámetros interval y count para determinar con qué frecuencia y cuántas veces, respectivamente, el comando jstat muestra su

salida.

Nota: No escriba scripts para analizar la salida del comando jstat porque el formato podría cambiar en versiones futuras. Si escribe scripts que analicen la salida del comando jstat, espere tener que modificarlos para versiones futuras de esta

herramienta.
