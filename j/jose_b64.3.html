size_t jose_b64_dec (const json_t * i, void * o, size_t ol)

Decodifica una cadena JSON Base64 segura para URL a un búfer. Si o es NULL, se devuelve el número de bytes de salida necesarios.

Esta función nunca escribirá más de ol bytes. Si el búfer de salida es demasiado pequeño, ocurrirá un error.

Parámetros:

i La cadena JSON Base64 segura para URL de entrada.
o El búfer de salida (puede ser NULL).
ol El tamaño del búfer de salida.

Devoluciones:

El número de bytes que fueron (o serían) escritos. Si ocurre un error, se devuelve SIZE_MAX.

jose_io_t* jose_b64_dec_io (jose_io_t * next)

Crea un nuevo objeto IO que realiza la decodificación Base64 segura para URL. Todos los datos escritos en el objeto IO devuelto serán decodificados antes de pasarlos al siguiente objeto IO en la cadena.

Parámetros:

next El siguiente objeto IO en la cadena.

Devoluciones:

El nuevo objeto IO o NULL en caso de error.

size_t jose_b64_dec_buf (const void * i, size_t il, void * o, size_t ol)

Decodifica un búfer Base64 seguro para URL a un búfer de salida. Si o es NULL, se devuelve el número de bytes de salida necesarios.

Esta función nunca escribirá más de ol bytes. Si el búfer de salida es demasiado pequeño, ocurrirá un error.

Parámetros:

i El búfer Base64 seguro para URL de entrada.
il El tamaño de los datos en el búfer de entrada.
o El búfer de salida.
ol El tamaño del búfer de salida.

Devoluciones:

El número de bytes que fueron (o serían) escritos. Si ocurre un error, se devuelve SIZE_MAX.
