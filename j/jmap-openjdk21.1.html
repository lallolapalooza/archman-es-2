JMAP(1) Comandos JDK JMAP(1)

NOMBRE

jmap - imprime detalles de un proceso especificado

SINOPSIS

Nota: Este comando es experimental y no está soportado.

jmap [opciones] pid

opciones
Esto representa las opciones de línea de comandos de jmap. Ver Opciones del comando jmap.
pid
El ID del proceso para el cual se va a imprimir la información especificada por las opciones. El proceso debe ser un proceso Java. Para obtener una lista de procesos Java en ejecución en una máquina, utilice el comando ps o, si los procesos JVM no se están ejecutando en una instancia de docker separada, el comando jps.

DESCRIPCIÓN

El comando jmap imprime detalles de un proceso en ejecución especificado.

Nota:

Este comando no está soportado y podría no estar disponible en futuras versiones del JDK. En sistemas Windows donde el archivo dbgeng.dll no está presente, se deben instalar las Herramientas de depuración para Windows para que estas herramientas funcionen. La variable de entorno PATH debe contener la ubicación del archivo jvm.dll que utiliza el proceso destino o la ubicación desde la que se produjo el archivo de volcado de memoria.

OPCIONES DEL COMANDO JMAP

-clstats pid
Se conecta a un proceso en ejecución e imprime estadísticas de los cargadores de clases del heap de Java.
-finalizerinfo pid
Se conecta a un proceso en ejecución e imprime información sobre los objetos que esperan la finalización.
-histo[:live] pid
Se conecta a un proceso en ejecución e imprime un histograma del heap de objetos de Java. Si se especifica la subopción live, entonces solo cuenta los objetos vivos.
-dump:opciones_dump pid
Se conecta a un proceso en ejecución y vuelca el heap de Java. Las opciones_dump incluyen:
•
live --- Cuando se especifica, solo vuelca los objetos vivos; si no se especifica, entonces vuelca todos los objetos en el heap.
•
format=b --- Vuelca el heap de Java en formato binario hprof
•
file=nombre_archivo --- Vuelca el heap al archivo nombre_archivo

Ejemplo: jmap -dump:live,format=b,file=heap.bin pid
