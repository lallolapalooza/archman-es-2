jcmd(1) Herramientas de solución de problemas jcmd(1)

NOMBRE

jcmd - Envía solicitudes de comandos de diagnóstico a una Máquina Virtual Java (JVM) en ejecución.

SINOPSIS

jcmd [-l|-h|-help]
jcmd pid|clase-principal PerfCounter.print
jcmd pid|clase-principal -f nombre-archivo
jcmd pid|clase-principal comando[ argumentos]

DESCRIPCIÓN

La utilidad jcmd se utiliza para enviar solicitudes de comandos de diagnóstico a la JVM. Debe utilizarse en la misma máquina en la que se está ejecutando la JVM y tener los mismos identificadores de usuario y grupo efectivos que se utilizaron para iniciar la JVM.


Nota
Para invocar comandos de diagnóstico desde una máquina remota o con identificadores diferentes, puede utilizar la interfaz com.sun.management.DiagnosticCommandMBean. Para obtener más información sobre la interfaz DiagnosticCommandMBean, consulte la documentación de la API en http://docs.oracle.com/javase/8/docs/jre/api/management/extension/com/sun/management/DiagnosticCommandMBean.html

Si ejecuta jcmd sin argumentos o con la opción -l, imprimirá la lista de identificadores de procesos Java en ejecución con la clase principal y los argumentos de línea de comandos que se utilizaron para iniciar el proceso. Ejecutar jcmd con la opción -h o -help imprimirá el mensaje de ayuda de la herramienta.

Si especifica el identificador del proceso (pid) o la clase principal (clase-principal) como primer argumento, jcmd enviará la solicitud de comando de diagnóstico al proceso Java con el identificador especificado o a todos los procesos Java con el nombre de la clase principal especificada. También puede enviar la solicitud de comando de diagnóstico a todos los procesos Java disponibles especificando 0 como identificador del proceso. Utilice uno de los siguientes como solicitud de comando de diagnóstico:

PerfCounter.print

Imprime los contadores de rendimiento disponibles para el proceso Java especificado. La lista de contadores de rendimiento puede variar con el proceso Java.

-f nombre-archivo

El nombre del archivo desde el que leer los comandos de diagnóstico y enviarlos al proceso Java especificado. Se utiliza solo con la opción -f. Cada comando en el archivo debe escribirse en una sola línea. Las líneas que comienzan con un signo de número (#) se ignoran. El procesamiento del archivo finaliza cuando se han leído todas las líneas o cuando se lee una línea que contiene la palabra clave stop.

comando [argumentos]

El comando que se enviará al proceso Java especificado. La lista de comandos de diagnóstico disponibles para un proceso determinado se puede obtener enviando el comando help a este proceso. Cada comando de diagnóstico tiene su propio conjunto de argumentos. Para ver la descripción, la sintaxis y una lista de argumentos disponibles para un comando, utilice el nombre del comando como argumento del comando help.

Nota: Si algún argumento contiene espacios, debe rodearlo con comillas simples o dobles (' o "). Además, debe escapar las comillas simples o dobles con una barra invertida (\) para evitar que el intérprete de comandos del sistema operativo procese las comillas. Alternativamente, puede rodear estos argumentos con comillas simples y luego con comillas dobles (o con comillas dobles y luego con comillas simples).

OPCIONES

Las opciones son mutuamente excluyentes.

-f nombre-archivo

Lee los comandos del archivo especificado. Esta opción solo se puede usar si especifica el identificador del proceso o la clase principal como primer argumento. Cada comando en el archivo debe escribirse en una sola línea. Las líneas que comienzan con un signo de número (#) se ignoran. El procesamiento del archivo finaliza cuando se han leído todas las líneas o cuando se lee una línea que contiene la palabra clave stop.

-h
-help

Imprime un mensaje de ayuda.

-l

Imprime la lista de identificadores de procesos Java en ejecución con la clase principal y los argumentos de línea de comandos.
