JINFO(1) Comandos JDK JINFO(1)

NOMBRE

jinfo - genera información de configuración de Java para un proceso Java especificado

SINOPSIS

Nota: Este comando es experimental y no está soportado.

jinfo [opción] pid

opción
Esto representa las opciones de línea de comandos de jinfo. Consulte OPCIONES PARA EL COMANDO JINFO.
pid
El ID del proceso para el cual se va a imprimir la información de configuración. El proceso debe ser un proceso Java. Para obtener una lista de procesos Java en ejecución en una máquina, use el comando ps o, si los procesos JVM no se están ejecutando en una instancia separada de docker, el comando jps.

DESCRIPCIÓN

El comando jinfo imprime información de configuración de Java para un proceso Java especificado. La información de configuración incluye propiedades del sistema Java y opciones de línea de comandos de la JVM. Si el proceso especificado se está ejecutando en una JVM de 64 bits, puede que necesite especificar la opción -J-d64, por ejemplo:

jinfo -J-d64 -sysprops pid

Este comando no está soportado y puede que no esté disponible en versiones futuras del JDK. En sistemas Windows donde no está presente dbgeng.dll, las Herramientas de depuración para Windows deben estar instaladas para que estas herramientas funcionen. La variable de entorno PATH debe contener la ubicación de jvm.dll que utiliza el proceso destino o la ubicación desde la que se produjo el archivo de volcado central.

OPCIONES PARA EL COMANDO JINFO

Nota:

Si no se utiliza ninguna de las siguientes opciones, se imprimirán tanto las opciones de línea de comandos como los pares de nombre-valor de las propiedades del sistema.

-flag nombre
Imprime el nombre y el valor de la opción de línea de comandos especificada.
-flag [+|-]nombre
Habilita o deshabilita la opción booleana de línea de comandos especificada.
-flag nombre=valor
Establece la opción de línea de comandos especificada al valor especificado.
-flags
Imprime las opciones de línea de comandos pasadas a la JVM.
-sysprops
Imprime las propiedades del sistema Java como pares de nombre-valor.
-h o -help
Imprime un mensaje de ayuda.
