jfs_mkfs(8) Creación del sistema de archivos JFS jfs_mkfs(8)

NOMBRE

jfs_mkfs - crear una partición formateada con JFS

SINOPSIS

jfs_mkfs [opciones] dispositivo [ bloques ]

DESCRIPCIÓN

jfs_mkfs se utiliza para crear (formatear) una partición JFS. jfs_mkfs debe ejecutarse como root.

dispositivo es el nombre del archivo especial que corresponde al dispositivo real (por ejemplo, /dev/hdb1) en el que se creará un sistema de archivos JFS y/o un diario JFS. bloques es el número de bloques a utilizar para el sistema de archivos. Si se omite, jfs_mkfs calcula automáticamente el tamaño del sistema de archivos.

El tamaño de bloque predeterminado es 4096.

ADVERTENCIA

jfs_mkfs destruirá todos los datos del dispositivo especificado.

OPCIONES

-c
Comprueba el dispositivo en busca de bloques defectuosos antes de crear el sistema de archivos.
-j dispositivo_diario
Crea el diario JFS externo en dispositivo_diario, crea el sistema de archivos JFS en dispositivo y adjunta el diario externo al sistema de archivos.
-J opciones_diario
Crea el diario JFS en su propio dispositivo o adjunta un diario JFS externo al sistema de archivos JFS utilizando las opciones especificadas en la línea de comandos. Las siguientes opciones de diario son compatibles:
dispositivo_externo
Crea un diario JFS externo en el dispositivo dado.
dispositivo=diario_externo
Adjunta un diario JFS externo existente ubicado en diario_externo al sistema de archivos JFS que se creará en dispositivo. El diario externo ya debe haber sido creado usando el comando
jfs_mkfs -J dispositivo_externo diario_externo
Adjunta el diario externo al sistema de archivos que se está creando usando el comando
jfs_mkfs -J dispositivo=diario_externo dispositivo
En lugar de especificar un nombre de dispositivo directamente, diario_externo también se puede especificar mediante LABEL=etiqueta o UUID=UUID para localizar el diario externo por la etiqueta del volumen o el UUID almacenado en el superbloque de registro externo JFS al inicio del diario. Usa jfs_tune(8) para mostrar la etiqueta del volumen y el UUID de un dispositivo de diario. (Ver las opciones -l, -L y -U de jfs_tune(8).)
Solo se puede dar una de las opciones dispositivo_externo o dispositivo= por cada ejecución de jfs_mkfs.
-L etiqueta_volumen
Establece la etiqueta del volumen para el dispositivo recién formateado.
Si se usa -L etiqueta_volumen junto con -J dispositivo_externo, se establecerá la etiqueta del volumen del dispositivo de diario externo especificado a etiqueta_volumen. De lo contrario, se establecerá la etiqueta del volumen del sistema de archivos JFS a etiqueta_volumen.
-O
Proporciona soporte insensible a mayúsculas/minúsculas para compatibilidad con OS/2.
-q
Ejecución silenciosa - no pide confirmación antes de crear el sistema de archivos.
-s tamaño_registro
Establece el tamaño del registro (en megabytes) del registro en línea. Si no se usa la opción -s, el tamaño del registro predeterminado es el 0,4% del tamaño agregado.
-V
Imprime la información de la versión y sale (independientemente de cualquier otra opción elegida).

EJEMPLOS

Formatea la 3ª partición en el segundo disco duro con la etiqueta de volumen "JFS_hdb3":

jfs_mkfs -L JFS_hdb3 /dev/hdb3

Formatea la 5ª partición en el primer disco duro, verificando cada bloque creado:

jfs_mkfs -c /dev/hda5

Formatea la 3ª partición en el segundo disco duro como diario externo, formatea la 4ª partición en el primer disco duro como sistema de archivos JFS y adjunta el diario externo al sistema de archivos:

jfs_mkfs -j /dev/hdb3 /dev/hda4

INFORMES DE ERRORES

Si encuentra un error en JFS o jfs_mkfs, por favor repórtelo a través del sistema de seguimiento de errores (sección "Report Bugs") del sitio web del proyecto JFS:

http://jfs.sourceforge.net/

Por favor, envíe tanta información pertinente como sea posible, incluyendo cualquier mensaje de error resultante de la ejecución de jfs_mkfs.
