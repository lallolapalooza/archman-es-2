JWEBSERVER(1) JDK Commands JWEBSERVER(1)

NOMBRE

jwebserver - inicia el servidor web simple de Java

SINOPSIS

jwebserver [opciones]

opciones
Opciones de línea de comandos. Para una descripción detallada de las opciones, consulte Opciones.

DESCRIPCIÓN

La herramienta jwebserver proporciona un servidor HTTP mínimo, diseñado para ser utilizado en prototipos, pruebas y depuración. Sirve una única jerarquía de directorios y solo sirve archivos estáticos. Solo se admite HTTP/1.1; HTTP/2 y HTTPS no son compatibles.

Solo se sirven las solicitudes idempotentes HEAD y GET. Cualquier otra solicitud recibe una respuesta 501 - No implementado o 405 - No permitido. Las solicitudes GET se mapean al directorio que se está sirviendo, de la siguiente manera:

•
Si el recurso solicitado es un archivo, se sirve su contenido.
•
Si el recurso solicitado es un directorio que contiene un archivo índice, se sirve el contenido del archivo índice.
•
De lo contrario, se enumeran los nombres de todos los archivos y subdirectorios del directorio. Los enlaces simbólicos y los archivos ocultos no se enumeran ni se sirven.

Los tipos MIME se configuran automáticamente, utilizando la tabla integrada. Por ejemplo, los archivos .html se sirven como text/html y los archivos .java se sirven como text/plain.

jwebserver se encuentra en el módulo jdk.httpserver y, alternativamente, puede iniciarse con java -m jdk.httpserver. Se basa en la implementación del servidor web del paquete com.sun.net.httpserver. La clase com.sun.net.httpserver.SimpleFileServer proporciona una forma programática de recuperar el servidor y sus componentes para su reutilización y extensión.

USO


jwebserver [-b dirección_de_enlace] [-p puerto] [-d directorio]
           [-o none|info|verbose] [-h para mostrar opciones]
           [-version para mostrar información de versión]

OPCIONES

-h o -? o --help
Imprime el mensaje de ayuda y sale.
-b dir o --bind-address dir
Especifica la dirección a la que enlazar. Por defecto: 127.0.0.1 o ::1 (loopback). Para todas las interfaces use -b 0.0.0.0 o -b ::.
-d dir o --directory dir
Especifica el directorio a servir. Por defecto: directorio actual.
-o nivel o --output nivel
Especifica el formato de salida. none | info | verbose. Por defecto: info.
-p puerto o --port puerto
Especifica el puerto en el que escuchar. Por defecto: 8000.
-version o --version
Imprime la información de versión y sale.

Para detener el servidor, presione Ctrl + C.

INICIANDO EL SERVIDOR

El siguiente comando inicia el servidor web simple:


$ jwebserver

Si el inicio es exitoso, el servidor imprime un mensaje en System.out que enumera la dirección local y la ruta absoluta del directorio que se está sirviendo. Por ejemplo:


$ jwebserver
Enlazando a loopback por defecto. Para todas las interfaces usa "-b 0.0.0.0" o "-b ::".
Sirviendo /cwd y subdirectorios en 127.0.0.1 puerto 8000
URL http://127.0.0.1:8000/

CONFIGURACIÓN

Por defecto, el servidor se ejecuta en primer plano y se enlaza a la dirección de loopback y al puerto 8000. Esto se puede cambiar con las opciones -b y -p. Por ejemplo, para enlazar el servidor web simple a todas las interfaces, use:


$ jwebserver -b 0.0.0.0
Sirviendo /cwd y subdirectorios en 0.0.0.0 (todas las interfaces) puerto 8000
URL http://123.456.7.891:8000/

Tenga en cuenta que esto hace que el servidor web sea accesible para todos los hosts de la red. No haga esto a menos que esté seguro de que el servidor no puede filtrar ninguna información sensible.

Como otro ejemplo, use el siguiente comando para ejecutar en el puerto 9000:


$ jwebserver -p 9000

Por defecto, se sirven los archivos del directorio actual. Se puede especificar un directorio diferente con la opción -d.

Por defecto, cada solicitud se registra en la consola. La salida se ve así:


127.0.0.1 - - [10/Feb/2021:14:34:11 +0000] "GET /some/subdirectory/ HTTP/1.1" 200 -

La salida de registro se puede cambiar con la opción -o. La configuración predeterminada es info. La configuración verbose incluye además las cabeceras de solicitud y respuesta, así como la ruta absoluta del recurso solicitado.

DETENIENDO EL SERVIDOR

Una vez iniciado correctamente, el servidor se ejecuta hasta que se detiene. En plataformas Unix, el servidor se puede detener enviándole una señal SIGINT (Ctrl+C en una ventana de terminal).

OPCIÓN DE AYUDA

La opción -h muestra un mensaje de ayuda que describe el uso y las opciones de jwebserver.
