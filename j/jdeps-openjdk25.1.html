OPCIONES PARA FILTRAR DEPENDENCIAS

-p nombre_paquete, --package nombre_paquete
Encuentra dependencias que coincidan con el nombre del paquete especificado. Puedes especificar esta opción varias veces para diferentes paquetes. Las opciones -p y -e son mutuamente excluyentes.
-e expresión_regular, -regex expresión_regular, o --regex expresión_regular
Encuentra dependencias que coincidan con el patrón especificado. Las opciones -p y -e son mutuamente excluyentes.
--require nombre_módulo
Encuentra dependencias que coincidan con el nombre del módulo dado (se puede dar varias veces). Las opciones --package, --regex, y --require son mutuamente excluyentes.
-f expresión_regular o -filter expresión_regular
Filtra dependencias que coincidan con el patrón dado. Si se da varias veces, se seleccionará la última.
-filter:package
Filtra dependencias dentro del mismo paquete. Este es el valor por defecto.
-filter:archive
Filtra dependencias dentro del mismo archivo (archive).
-filter:module
Filtra dependencias dentro del mismo módulo.
-filter:none
Sin filtrado de -filter:package y -filter:archive. El filtrado especificado a través de la opción -filter todavía se aplica.
--missing-deps
Encuentra dependencias faltantes. Esta opción no se puede usar con las opciones -p, -e y -s.

OPCIONES PARA FILTRAR CLASES A SER ANALIZADAS

-include expresión_regular
Restringe el análisis a las clases que coincidan con el patrón. Esta opción filtra la lista de clases a analizar. Se puede usar junto con -p y -e, que aplican el patrón a las dependencias.
-R o --recursive
Recorre recursivamente todas las dependencias en tiempo de ejecución. La opción -R implica -filter:none. Si se especifican las opciones -p, -e, o -f, solo se analizan las dependencias coincidentes.
--no-recursive
No recorrer recursivamente las dependencias.
-I o --inverse
Analiza las dependencias según otras opciones dadas y luego encuentra todos los artefactos que dependen directa o indirectamente de los nodos coincidentes. Esto es equivalente a la inversa del análisis de la vista de tiempo de compilación y la suma de dependencias impresa. Esta opción debe usarse con las opciones --require, --package, o --regex.
--compile-time
Analiza la vista de tiempo de compilación de dependencias transitivas, como la vista de tiempo de compilación de la opción -R. Analiza las dependencias según otras opciones especificadas. Si se encuentra una dependencia desde un directorio, un archivo JAR o un módulo, se analizan todas las clases de ese archivo contenedor.
