NOMBRE

jstest - programa de prueba de joystick

SINOPSIS

jstest [--normal] [--old] [--event] [--nonblock] [--select] <nombre-dispositivo>

DESCRIPCIÓN

jstest se puede usar para probar todas las características de la API de joystick de Linux, incluyendo el acceso no bloqueante y mediante select(2), así como el modo de compatibilidad versión 0.x.

También está destinado a servir como una implementación de ejemplo para aquellos que deseen aprender a escribir sus propias aplicaciones que usen joystick.

OPCIONES

--normal
Modo de una línea que muestra el estado inmediato.
--old
Igual que --normal, usando la interfaz 0.x.
--event
Imprime los eventos a medida que llegan.
--nonblock
Igual que --event, en modo no bloqueante.
--select
Igual que --event, usando la llamada a select(2).

VER TAMBIÉN

fftest(1), jscal(1).
