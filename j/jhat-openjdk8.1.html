NOMBRE

jhat - Analiza la memoria heap de Java. Este comando es experimental y no está soportado.

SINOPSIS

jhat [ opciones ] archivo-de-volcado-heap
opciones
Las opciones de la línea de comandos. Ver Opciones.
archivo-de-volcado-heap
Archivo de volcado de memoria heap binaria de Java para explorar. Para un archivo de volcado que contenga múltiples volcados de memoria heap, puedes especificar cuál volcado en el archivo adjuntando #<número> al nombre del archivo, por ejemplo, miarchivo.hprof#3.

DESCRIPCIÓN

El comando jhat analiza un archivo de volcado de memoria heap de Java y inicia un servidor web. El comando jhat te permite explorar volcados de memoria heap con tu navegador web favorito. El comando jhat soporta consultas predefinidas como mostrar todas las instancias de una clase conocida MiClase, y el Lenguaje de Consulta de Objetos (OQL). OQL es similar a SQL, excepto para consultar volcados de memoria heap. La ayuda sobre OQL está disponible en la página de ayuda de OQL mostrada por el comando jhat. Con el puerto predeterminado, la ayuda de OQL está disponible en http://localhost:7000/oqlhelp/

Hay varias maneras de generar un volcado de memoria heap de Java:

•
Usa la opción jmap -dump para obtener un volcado de memoria heap en tiempo de ejecución. Ver jmap(1).
•
Usa la opción jconsole para obtener un volcado de memoria heap a través de HotSpotDiagnosticMXBean en tiempo de ejecución. Ver jconsole(1) y la descripción de la interfaz HotSpotDiagnosticMXBean en http://docs.oracle.com/javase/8/docs/jre/api/management/extension/com/sun/management/HotSpotDiagnosticMXBean.html
•
El volcado de memoria heap se genera cuando una OutOfMemoryError es lanzada especificando la opción de la Máquina Virtual Java (JVM) -XX:+HeapDumpOnOutOfMemoryError.
•
Usa el comando hprof. Ver la Herramienta de Perfilado de Heap/CPU HPROF en http://docs.oracle.com/javase/8/docs/technotes/samples/hprof.html

OPCIONES

-stack false|true

Desactiva el seguimiento de la pila de llamadas de asignación de objetos. Si la información del sitio de asignación no está disponible en el volcado de memoria heap, entonces tienes que establecer esta bandera a false. El valor predeterminado es true.
-refs false|true

Desactiva el seguimiento de referencias a objetos. El valor predeterminado es true. Por defecto, los punteros inversos, que son objetos que apuntan a un objeto específico como referentes o referencias entrantes, se calculan para todos los objetos en el heap.
-port número-de-puerto

Establece el puerto para el servidor HTTP de jhat. El valor predeterminado es 7000.
-exclude archivo-de-exclusión

Especifica un archivo que lista los miembros de datos que deben ser excluidos de la consulta de objetos alcanzables. Por ejemplo, si el archivo lista java.lang.String.value, entonces, siempre que se calculan la lista de objetos que son alcanzables desde un objeto específico o, no se consideran las rutas de referencia que involucran el campo java.lang.String.value.
-baseline archivo-de-exclusión

Especifica un volcado de memoria heap base. Los objetos en ambos volcados de memoria heap con el mismo ID de objeto se marcan como no nuevos. Otros objetos se marcan como nuevos. Esto es útil para comparar dos volcados de memoria heap diferentes.
-debug int

Establece el nivel de depuración para esta herramienta. Un nivel de 0 significa ninguna salida de depuración. Establece valores más altos para modos más verbosos.
-version

Informa el número de versión y sale
-h

Muestra un mensaje de ayuda y sale.
-help

Muestra un mensaje de ayuda y sale.
-Jbandera

Pasa bandera a la Máquina Virtual Java en la que se ejecuta el comando jhat. Por ejemplo, -J-Xmx512m para usar un tamaño máximo de heap de 512 MB.
