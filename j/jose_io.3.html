Documentación de typedefs

typedef jose_io_t jose_io_auto_t

Define un jose_io_t que llama a jose_io_decref() al final del ámbito. Por ejemplo:

void foo() {
    uint8_t *buf = NULL;
    size_t len = 0;
    jose_io_auto_t *io = jose_io_malloc(NULL, &buf, &len);
    // jose_io_decref() llamado implícitamente
}

Documentación de funciones

jose_io_t* jose_io_incref (jose_io_t * io)

Incrementa el contador de referencias de un objeto de E/S. Esta función siempre tiene éxito.

Parámetros:

io La entidad jose_io_t que estás usando.

Devuelve:

El valor de io (por conveniencia).

void jose_io_decref (jose_io_t * io)

Decrementa el contador de referencias de un objeto de E/S. Cuando el contador de referencias llega a cero, se llama a io->free().

Parámetros:

io La entidad jose_io_t que estás usando.

jose_io_t* jose_io_malloc (jose_cfg_t * cfg, void ** buf, size_t * len)

Crea un nuevo objeto de E/S que recopila datos en un búfer dinámico. El búfer dinámico se asigna en el puntero buf que proporcionaste y la longitud del búfer se almacena en len. El puntero al que apunta buf debe permanecer válido durante toda la duración del objeto de E/S devuelto.

El comportamiento predeterminado es que el objeto de E/S ponga a cero y libere el búfer cuando se libere. Esto significa que, por defecto, tú eres el propietario del puntero del búfer, pero el búfer en sí es propiedad del objeto de E/S. Sin embargo, puedes robar el búfer estableciendo el puntero del búfer a NULL.

Ver también:

jose_io_malloc_steal()

Parámetros:

cfg El contexto de configuración (opcional).
buf Un puntero a puntero de búfer.
len Un puntero a la longitud del búfer.

Devuelve:

El nuevo objeto de E/S o NULL en caso de error.

void* jose_io_malloc_steal (void ** buf)

Roba el búfer creado por el objeto de E/S jose_io_malloc(). Esta función de conveniencia simplemente devuelve el valor de *buf y luego establece *buf a NULL.

Ver también:

jose_io_malloc()

Parámetros:

buf Un puntero al puntero del búfer.

Devuelve:

El valor de *buf antes de que se establezca a NULL.

jose_io_t* jose_io_buffer (jose_cfg_t * cfg, void * buf, size_t * len)

Crea un nuevo objeto de E/S que recopila datos en un búfer estático. El tamaño de buf DEBE especificarse en la variable apuntada por len. Esta será la cantidad máxima de datos escritos. Sin embargo, después de que la función devuelva, la variable apuntada por len contendrá la longitud actual de los datos en el búfer.

A diferencia de jose_io_malloc(), tú eres el propietario del búfer y no se pone a cero ni se libera cuando se libera el objeto de E/S.

Parámetros:

cfg El contexto de configuración (opcional).
buf Un puntero a búfer.
len Un puntero a la longitud del búfer.

Devuelve:

El nuevo objeto de E/S o NULL en caso de error.

jose_io_t* jose_io_file (jose_cfg_t * cfg, FILE * file)

Crea un nuevo objeto de E/S que escribe datos en un FILE. Esta función NO toma posesión del FILE. Todavía eres responsable de llamar a fclose() en el momento apropiado.

Parámetros:

cfg El contexto de configuración (opcional).
file El archivo de salida que DEBE abrirse para escritura o anexión.

Devuelve:

El nuevo objeto de E/S o NULL en caso de error.

jose_io_t* jose_io_multiplex (jose_cfg_t * cfg, jose_io_t ** nexts, bool all)

Crea un nuevo objeto de E/S que multiplexa datos en múltiples objetos de E/S. Si all es verdadero, se requiere el éxito de todos los nexts. De lo contrario, todos los nexts excepto uno pueden fallar antes de que el error se propague hacia arriba.

Parámetros:

cfg El contexto de configuración (opcional).
nexts Un array de punteros de objetos de E/S terminado en NULL.
all Si se requiere o no el éxito de todos los nexts.

Devuelve:

El nuevo objeto de E/S o NULL en caso de error.

Name

jose - A simple utility to manage JSON objects.

Description

The jose utility is a command-line tool designed for easy manipulation and querying of JSON data. It supports reading JSON from files or standard input, applying transformations, and outputting the results in various formats.

Synopsis

jose [OPTIONS] [FILE]

Options

-h, --help
Show help message and exit.
-v, --version
Show program version and exit.
-p, --pretty
Output JSON in a pretty-printed format.
-q, --query
Specify a JMESPath query to extract data.
-s, --set
Set a key-value pair in the JSON object.
-d, --delete
Delete a key from the JSON object.

Examples

To pretty-print a JSON file: 

jose -p data.json

To query a specific value using JMESPath: 

jose -q "user.name" data.json

To set a value and print the result: 

jose -s "user.age=30" data.json

To delete a key: 

jose -d "user.email" data.json

Exit status

Returns 0 on success, and a non-zero value on failure.

jq(1), jshon(1)
