JRUNSCRIPT(1) Comandos JDK JRUNSCRIPT(1)

NOMBRE

jrunscript - ejecuta un shell de script de línea de comandos que admite modos interactivos y por lotes

SINOPSIS

Nota:

Esta herramienta es experimental y no es compatible. Está obsoleta y se eliminará en una futura versión.

jrunscript [opciones] [argumentos]

opciones
Representa las opciones de línea de comandos de jrunscript que se pueden utilizar. Consulte Opciones para el comando jrunscript.
argumentos
Los argumentos, cuando se utilizan, siguen inmediatamente después de las opciones o el nombre del comando. Consulte Argumentos.

DESCRIPCIÓN

El comando jrunscript es un shell de script independiente del lenguaje y de línea de comandos. El comando jrunscript admite tanto un modo interactivo (leer-evaluar-imprimir) como un modo de ejecución de scripts por lotes (opción -f). Por defecto, se utiliza JavaScript, pero la opción -l se puede utilizar para especificar un idioma diferente. Al utilizar Java para la comunicación entre lenguajes de script, el comando jrunscript admite un estilo de programación exploratorio.

Si se utiliza JavaScript, antes de evaluar un script definido por el usuario, el comando jrunscript inicializa ciertas funciones y objetos integrados, que se documentan en la Especificación de la API para funciones integradas de JavaScript de jrunscript.

OPCIONES PARA EL COMANDO JRUNSCRIPT

-cp ruta o -classpath ruta
Indica dónde se encuentran los archivos de clase que el script necesita acceder.
-Dnombre=valor
Establece una propiedad del sistema Java.
-Jflag
Pasa flag directamente a la Máquina Virtual Java donde se está ejecutando el comando jrunscript.
-l idioma
Utiliza el idioma de script especificado. Por defecto, se utiliza JavaScript. Para utilizar otros idiomas de script, debe especificar el JAR del motor de script correspondiente con la opción -cp o -classpath.
-e script
Evalúa el script especificado. Esta opción se puede utilizar para ejecutar scripts de una sola línea que se especifican completamente en la línea de comandos.
-encoding codificacion
Especifica la codificación de caracteres utilizada para leer archivos de script.
-f archivo-script
Evalúa el archivo de script especificado (modo por lotes).
-f -
Entra en modo interactivo para leer y evaluar un script desde la entrada estándar.
-help o -?
Muestra un mensaje de ayuda y sale.
-q
Enumera todos los motores de script disponibles y sale.

ARGUMENTOS

Si hay argumentos presentes y no se utiliza la opción -e o -f, entonces el primer argumento es el archivo de script y el resto de los argumentos, si los hay, se pasan como argumentos del script. Si se utilizan argumentos y la opción -e o -f, entonces todos los argumentos se pasan como argumentos del script. Si faltan los argumentos -e y -f, se utiliza el modo interactivo.

EJEMPLO DE EJECUCIÓN DE SCRIPTS EN LÍNEA

jrunscript -e "print('hola mundo')"

jrunscript -e "cat('http://www.example.com')"

EJEMPLO DE USO DE IDIOMA ESPECIFICADO Y EVALUACIÓN DEL ARCHIVO DE SCRIPT

jrunscript -l js -f test.js

EJEMPLO DE MODO INTERACTIVO

jrunscript
js> print('¡Hola Mundo\n');
¡Hola Mundo
js> 34 + 55
89.0
js> t = new java.lang.Thread(function() { print('¡Hola Mundo\n'); })
Thread[Thread-0,5,main]
js> t.start()
js> ¡Hola Mundo
js>

EJECUTAR ARCHIVO DE SCRIPT CON ARGUMENTOS DE SCRIPT

En este ejemplo, el archivo test.js es el archivo de script. Los argumentos arg1, arg2 y arg3 se pasan al script. El script puede acceder a estos argumentos con un array de argumentos.

jrunscript test.js arg1 arg2 arg3
