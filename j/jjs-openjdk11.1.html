NOMBRE

jjs - Invoca el motor Nashorn.

SINOPSIS

jjs [opciones] [archivos-de-script] [-- argumentos]

opciones

Una o más opciones del comando jjs, separadas por espacios. Para más información, ver Opciones.

archivos-de-script

Uno o más archivos de script que desea interpretar usando Nashorn, separados por espacios. Si no se especifican archivos, se inicia un shell interactivo.

argumentos

Todos los valores después del marcador de doble guion (--) se pasan al script o al shell interactivo como argumentos. Estos valores se pueden acceder utilizando la propiedad arguments (ver Ejemplo 3).

DESCRIPCIÓN

La herramienta de línea de comandos jjs se utiliza para invocar el motor Nashorn. Puede usarla para interpretar uno o varios archivos de script, o para ejecutar un shell interactivo.

OPCIONES

Las opciones del comando jjs controlan las condiciones bajo las cuales Nashorn interpreta los scripts.

-cp ruta
-classpath ruta

Especifica la ruta a los archivos de clase de soporte. Para establecer múltiples rutas, la opción se puede repetir, o puede separar cada ruta con dos puntos (:).

-Dnombre=valor

Establece una propiedad del sistema para ser pasada al script asignando un valor a un nombre de propiedad. El siguiente ejemplo muestra cómo invocar Nashorn en modo interactivo y asignar myValue a la propiedad llamada myKey: 
>> jjs -DmyKey=myValue
jjs> java.lang.System.getProperty("myKey")
myValue
jjs>
Esta opción se puede repetir para establecer múltiples propiedades.

-doe
--dump-on-error

Proporciona un rastreo de pila completo cuando ocurre un error. Por defecto, solo se imprime un mensaje de error breve.

-fv
--fullversion

Imprime la cadena de versión completa de Nashorn.

-fx

Lanza el script como una aplicación JavaFX.

-h
-help

Imprime la lista de opciones y sus descripciones.

--language=[es5]

Especifica la versión del lenguaje ECMAScript. La versión predeterminada es ES5.

-ot
--optimistic-types=[true|false]

Habilita o deshabilita las suposiciones de tipos optimistas con recompilación de desoptimización. Ejecutar con tipos optimistas dará como resultado una mayor velocidad final, pero puede aumentar el tiempo de calentamiento.

-scripting

Habilita las características de scripting del shell.

-strict

Habilita el modo estricto, que impone una adhesión más estricta al estándar (ECMAScript Edition 5.1), lo que facilita la detección de errores de codificación comunes.

-t=zona
-timezone=zona

Establece la zona horaria especificada para la ejecución del script. Anula la zona horaria establecida en el sistema operativo y utilizada por el objeto Date.

-v
-version

Imprime la cadena de versión de Nashorn.

EJEMPLOS

Ejemplo 1 Ejecutando un Script con Nashorn

jjs script.js

Ejemplo 2 Ejecutando Nashorn en Modo Interactivo

>> jjs
jjs> println("Hola, Mundo!")
Hola, Mundo!
jjs> quit()
>>

Ejemplo 3 Pasando Argumentos a Nashorn

>> jjs -- a b c
jjs> arguments.join(", ")
a, b, c
jjs>
