JHSDB(1) Comandos de JDK JHSDB(1)

NOMBRE

jhsdb - adjuntar a un proceso Java o iniciar un depurador de post-mortem para analizar el contenido de un volcado de memoria de una Máquina Virtual Java (JVM) que ha fallado.

SINOPSIS

jhsdb clhsdb [--pid pid | --exe ejecutable --core volcado_memoria]

jhsdb hsdb [--pid pid | --exe ejecutable --core volcado_memoria]

jhsdb debugd (--pid pid | --exe ejecutable --core volcado_memoria) [opciones]

jhsdb jstack (--pid pid | --exe ejecutable --core volcado_memoria | --connect [id_servidor@]host_debugd) [opciones]

jhsdb jmap (--pid pid | --exe ejecutable --core volcado_memoria | --connect [id_servidor@]host_debugd) [opciones]

jhsdb jinfo (--pid pid | --exe ejecutable --core volcado_memoria | --connect [id_servidor@]host_debugd) [opciones]

jhsdb jsnap (--pid pid | --exe ejecutable --core volcado_memoria | --connect [id_servidor@]host_debugd) [opciones]

pid
El ID del proceso al que debe adjuntarse la herramienta jhsdb. El proceso debe ser un proceso Java. Para obtener una lista de los procesos Java en ejecución en una máquina, utilice el comando ps o, si los procesos JVM no se están ejecutando en una instancia de docker separada, el comando jps.
ejecutable
El archivo ejecutable de Java a partir del cual se produjo el volcado de memoria.
volcado_memoria
El archivo de volcado de memoria al que debe adjuntarse la herramienta jhsdb.
[id_servidor@]host_debugd
Un ID de servidor opcional y la dirección del servidor de depuración remoto (debugd).
opciones
Las opciones de línea de comandos para un modo de jhsdb. Consulte Opciones para el modo debugd, Opciones para el modo jstack, Opciones para el modo jmap, Opciones para el modo jinfo y Opciones para el modo jsnap.

Nota:

Se debe proporcionar o el pid o el par de archivos ejecutable y volcado_memoria o el [id_servidor@]host_debugd para los modos debugd, jstack, jmap, jinfo y jsnap.

DESCRIPCIÓN

Puede utilizar la herramienta jhsdb para adjuntarse a un proceso Java o para iniciar un depurador de post-mortem para analizar el contenido de un volcado de memoria de una Máquina Virtual Java (JVM) que ha fallado. Este comando es experimental y no está soportado.

Nota:

Adjuntar la herramienta jhsdb a un proceso en vivo hará que el proceso se bloquee y probablemente se bloquee cuando el depurador se desconecte.

La herramienta jhsdb se puede iniciar en cualquiera de los siguientes modos:

jhsdb clhsdb
Inicia el depurador interactivo de línea de comandos.
jhsdb hsdb
Inicia el depurador interactivo GUI.
jhsdb debugd
Inicia el servidor de depuración remoto.
jhsdb jstack
Imprime información de pila y bloqueos.
jhsdb jmap
Imprime información del montón (heap).
jhsdb jinfo
Imprime información básica de la JVM.
jhsdb jsnap
Imprime información de contadores de rendimiento.
jhsdb comando --help
Muestra las opciones disponibles para el comando.

OPCIONES PARA EL MODO DEBUGd

--serverid id_servidor
Un ID único opcional para este servidor de depuración. Es necesario si se ejecutan varios servidores de depuración en la misma máquina.
--rmiport puerto
Establece el número de puerto al que se enlaza el conector RMI. Si no se especifica, se utiliza un puerto disponible aleatorio.
--registryport puerto
Establece el puerto del registro RMI. Esta opción anula la propiedad del sistema 'sun.jvm.hotspot.rmi.port'. Si no se especifica, se utiliza la propiedad del sistema. Si la propiedad del sistema no está establecida, se utiliza el puerto predeterminado 1099.
--hostname nombre_host
Establece el nombre de host al que se enlaza el conector RMI. El valor puede ser un nombre de host o una dirección IPv4/IPv6. Esta opción anula la propiedad del sistema 'java.rmi.server.hostname'. Si no se especifica, se utiliza la propiedad del sistema. Si la propiedad del sistema no está establecida, se utiliza un nombre de host del sistema.

OPCIONES PARA EL MODO JINFO

--flags
Imprime las banderas de la VM.
--sysprops
Imprime las propiedades del sistema Java.
sin opción
Imprime las banderas de la VM y las propiedades del sistema Java.

OPCIONES PARA EL MODO JMAP

sin opción
Imprime la misma información que Solaris pmap.
--heap
Imprime un resumen del montón (heap) de Java.
--binaryheap
Vuelca el montón (heap) de Java en formato binario hprof.
--dumpfile nombre
El nombre del archivo de volcado.
--histo
Imprime el histograma del montón de objetos Java.
--clstats
Imprime las estadísticas del cargador de clases.
--finalizerinfo
Imprime la información sobre los objetos en espera de finalización.

OPCIONES PARA EL MODO JSTACK

--locks
Imprime la información de los bloqueos de java.util.concurrent.
--mixed
Intenta imprimir marcos de Java y marcos nativos si la plataforma lo permite.

OPCIONES PARA EL MODO JSNAP

--all
Imprime todos los contadores de rendimiento.
