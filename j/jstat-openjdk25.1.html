JSTAT(1) Comandos JDK JSTAT(1)

NOMBRE

jstat - monitorizar estadísticas JVM

SINOPSIS

Nota: Este comando es experimental y no tiene soporte.

jstat opcionesGenerales

jstat opcionesSalida [-t] [-h lineas] vmid [intervalo [conteo]]

opcionesGenerales
Una única opción de línea de comandos general. Ver Opciones Generales.
opcionesSalida
Una opción reportada por la opción -options. Una o más opciones de salida que consisten en una única opcionEstadistica, más cualquiera de las opciones -t, -h, y -J. Ver Opciones de Salida para el comando jstat.
-t
Muestra una columna de marca de tiempo como la primera columna de salida. La marca de tiempo es el tiempo transcurrido desde la hora de inicio de la JVM de destino.
-h n
Muestra una cabecera de columna cada n muestras (filas de salida), donde n es un entero positivo. El valor predeterminado es 0, que muestra la cabecera de columna de la primera fila de datos.
vmid
Un identificador de máquina virtual, que es una cadena que indica la JVM de destino. Ver Identificador de Máquina Virtual.
intervalo
El intervalo de muestreo en las unidades especificadas, segundos (s) o milisegundos (ms). Las unidades predeterminadas son milisegundos. Debe ser un entero positivo. Cuando se especifica, el comando jstat produce su salida en cada intervalo.
conteo
El número de muestras a mostrar. El valor predeterminado es infinito, lo que provoca que el comando jstat muestre estadísticas hasta que la JVM de destino termine o se termine el comando jstat. Este valor debe ser un entero positivo.

DESCRIPCIÓN

El comando jstat muestra estadísticas de rendimiento para una VM HotSpot de Java instrumentada. La JVM de destino se identifica por su identificador de máquina virtual, o la opción vmid.

El comando jstat admite dos tipos de opciones: generales y de salida. Las opciones generales hacen que el comando jstat muestre información simple de uso y versión. Las opciones de salida determinan el contenido y el formato de la salida estadística.

Todas las opciones y su funcionalidad están sujetas a cambios o eliminación en futuras versiones.

OPCIONES GENERALES

Si especifica una de las opciones generales, no podrá especificar ninguna otra opción ni parámetro.

-help
Muestra un mensaje de ayuda.
-options
Muestra una lista de opciones estáticas. Ver Opciones de Salida para el comando jstat.

OPCIONES DE SALIDA PARA EL COMANDO JSTAT

Si no especifica una opción general, puede especificar opciones de salida. Las opciones de salida determinan el contenido y el formato de la salida del comando jstat, y consisten en una única opcionEstadistica, más cualquiera de las otras opciones de salida (-h, -t y -J). La opcionEstadistica debe ir primero.

La salida se formatea como una tabla, con columnas separadas por espacios. Una fila de encabezado con títulos describe las columnas. Use la opción -h para establecer la frecuencia con la que se muestra el encabezado. Los nombres de las cabeceras de las columnas son consistentes entre las diferentes opciones. En general, si dos opciones proporcionan una columna con el mismo nombre, la fuente de datos para las dos columnas es la misma.

Use la opción -t para mostrar una columna de marca de tiempo, etiquetada como Timestamp, como la primera columna de salida. La columna Timestamp contiene el tiempo transcurrido, en segundos, desde que se inició la JVM de destino. La resolución de la marca de tiempo depende de varios factores y está sujeta a variaciones debido a la planificación retrasada de hilos en sistemas muy cargados.

Use los parámetros de intervalo y conteo para determinar con qué frecuencia y cuántas veces, respectivamente, el comando jstat muestra su salida.

Nota:

No escriba scripts para analizar la salida del comando jstat porque el formato podría cambiar en futuras versiones. Si escribe scripts que analizan la salida del comando jstat, espere tener que modificarlos para futuras versiones de esta herramienta.

-opcionEstadistica
Determina la información estadística que muestra el comando jstat. La siguiente lista contiene las opciones disponibles. Use la opción general -options para mostrar la lista de opciones para una instalación de plataforma particular. Ver Opciones y Salida de Estadísticas.

class: Muestra estadísticas sobre el comportamiento del cargador de clases.

compiler: Muestra estadísticas sobre el comportamiento del compilador Just-In-Time de la VM HotSpot de Java.

gc: Muestra estadísticas sobre el comportamiento del montón recolectado por el recolector de basura.

gccapacity: Muestra estadísticas sobre las capacidades de las generaciones y sus espacios correspondientes.

gccause: Muestra un resumen sobre las estadísticas de recolección de basura (igual que -gcutil), con la causa de los últimos y actuales (cuando sea aplicable) eventos de recolección de basura.

gcnew: Muestra estadísticas sobre el comportamiento de la generación nueva.

gcnewcapacity: Muestra estadísticas sobre los tamaños de las generaciones nuevas y sus espacios correspondientes.

gcold: Muestra estadísticas sobre el comportamiento de la generación antigua y estadísticas del metaspace.

gcoldcapacity: Muestra estadísticas sobre los tamaños de la generación antigua.

gcmetacapacity: Muestra estadísticas sobre los tamaños del metaspace.

-JopcionJava
Pasa opcionJava al lanzador de aplicaciones Java. Por ejemplo, -J-Xms48m establece la memoria de inicio en 48 MB. Para una lista completa de opciones, ver java.

RESUMEN

jstat [general options] [gcutil | option vmid [interval [count]]]

DESCRIPCIÓN

La herramienta jstat (Java Virtual Machine Statistics) recopila y presenta información de monitorización de rendimiento de una JVM en ejecución. Se puede utilizar para observar la actividad de monitorización de una JVM local o remota.

La herramienta jstat se puede utilizar para recopilar estadísticas de monitorización de una JVM local o remota. La herramienta jstat utiliza las siguientes opciones generales:

OPCIONES GENERALES

options
Activa la información de monitorización para una JVM específica. Si no se especifica una opción, se mostrarán todas las opciones disponibles.
vmid
El identificador de la máquina virtual (VMID) para la JVM de destino. El formato del identificador de la máquina virtual es una cadena que corresponde a la sintaxis de un URI, como se describe en la sección VIRTUAL MACHINE IDENTIFIER.
interval count
El intervalo (en milisegundos) entre las muestras, y el recuento de muestras a tomar. Si solo se especifica el intervalo, se toman muestras indefinidamente.

OPCIONES DE SALIDA PARA EL COMANDO JSTAT

La herramienta jstat admite las siguientes opciones de salida para mostrar información específica de monitorización:

-gc
Estadísticas de Recolección de Basura (GC).
-gccapacity
Capacidades de las áreas de memoria (GC).
-gcnew
Estadísticas de la generación joven (GC).
-gcnewcapacity
Capacidades de la generación joven (GC).
-gcold
Estadísticas de la generación vieja (GC).
-gcoldcapacity
Capacidades de la generación vieja (GC).
-nonheap
Estadísticas de memoria no Heap.
-nonheapcapacity
Capacidades de memoria no Heap.
-class
Estadísticas de carga de clases.
-compiler
Estadísticas del compilador JIT.
-printcompilation
Información de compilación.

OPCIONES Y SALIDA DE ESTADÍSTICAS

Las opciones de estadísticas (`gcutil` o `option`) especifican el tipo de estadísticas que se mostrarán. La salida de cada opción de estadísticas incluye una descripción de las columnas y los campos de datos. El nombre del método es el método dentro de la clase especificada. El formato de estos dos campos es coherente con la opción -XX:+PrintCompilation de HotSpot.

IDENTIFICADOR DE MÁQUINA VIRTUAL

La sintaxis de la cadena vmid se corresponde con la sintaxis de una URI:

[protocolo:][//]lvmid[@hostname[:puerto][/nombre_servidor]

La sintaxis de la cadena vmid se corresponde con la sintaxis de una URI. La cadena vmid puede variar desde un simple entero que representa una JVM local hasta una construcción más compleja que especifica un protocolo de comunicación, un número de puerto y otros valores específicos de la implementación.

protocolo
El protocolo de comunicación. Si se omite el valor de protocolo y no se especifica un nombre de host, el protocolo predeterminado es un protocolo local optimizado específico de la plataforma. Si se omite el valor de protocolo y se especifica un nombre de host, el protocolo predeterminado es rmi.
lvmid
El identificador de máquina virtual local para la JVM de destino. El lvmid es un valor específico de la plataforma que identifica de forma única una JVM en un sistema. El lvmid es el único componente requerido de un identificador de máquina virtual. El lvmid es típicamente, pero no necesariamente, el identificador de proceso del sistema operativo para el proceso de la JVM de destino. Puede utilizar el comando jps para determinar el lvmid, siempre que el proceso de la JVM no se esté ejecutando en una instancia de docker separada. También puede determinar el lvmid en las plataformas Linux y macOS con el comando ps, y en Windows con el Administrador de Tareas de Windows.
hostname
Un nombre de host o dirección IP que indica el host de destino. Si se omite el valor de hostname, el host de destino es el host local.
puerto
El puerto predeterminado para la comunicación con el servidor remoto. Si se omite el valor de hostname o el valor de protocolo especifica un protocolo local optimizado, se ignora el valor de puerto. De lo contrario, el tratamiento del parámetro puerto depende de la implementación. Para el protocolo predeterminado rmi, el valor del puerto indica el número de puerto para el rmiregistry en el host remoto. Si se omite el valor de puerto y el valor de protocolo indica rmi, se utiliza el puerto predeterminado de rmiregistry (1099).
nombre_servidor
El tratamiento del parámetro nombre_servidor depende de la implementación. Para el protocolo local optimizado, este campo se ignora. Para el protocolo rmi, representa el nombre del objeto remoto RMI en el host remoto.

EJEMPLOS

Esta sección presenta algunos ejemplos de monitorización de una JVM local con un lvmid de 21891.

LA OPCIÓN GCUTIL

Este ejemplo se conecta al lvmid 21891 y toma 7 muestras a intervalos de 250 milisegundos y muestra la salida según lo especificado por la opción -gcutil.

La salida de este ejemplo muestra que ocurrió una recolección de la generación joven entre la tercera y la cuarta muestra. La recolección tardó 0.078 segundos y promovió objetos del espacio eden (E) al espacio viejo (O), lo que resultó en un aumento de la utilización del espacio viejo del 66.80% al 68.19%. Antes de la recolección, el espacio de supervivencia tenía una utilización del 97.02%, pero después de esta recolección tiene una utilización del 91.03%.

REPETIR LA CADENA DE ENCABEZADO DE COLUMNA

Este ejemplo se conecta al lvmid 21891 y toma muestras a intervalos de 250 milisegundos y muestra la salida según lo especificado por la opción -gcnew. Además, utiliza la opción -h3 para mostrar el encabezado de la columna después de cada 3 líneas de datos.

Además de mostrar la cadena de encabezado repetida, este ejemplo muestra que entre la segunda y la tercera muestra, ocurrió una GC joven. Su duración fue de 0.001 segundos. La recolección encontró suficientes datos activos que la utilización del espacio de supervivencia 0 (S0U) habría excedido el tamaño de supervivencia deseado (DSS). Como resultado, se promovieron objetos a la generación vieja (no visible en esta salida), y el umbral de tenencia (TT) se redujo de 31 a 2.

INCLUIR UNA MARCA DE TIEMPO PARA CADA MUESTRA

Este ejemplo se conecta al lvmid 21891 y toma 3 muestras a intervalos de 250 milisegundos. La opción -t se utiliza para generar una marca de tiempo para cada muestra en la primera columna.

La columna Timestamp informa el tiempo transcurrido en segundos desde el inicio de la JVM de destino. Además, la salida de -gcoldcapacity muestra la capacidad de la generación vieja (OGC) y la capacidad del espacio viejo (OC) aumentando a medida que el heap se expande para satisfacer las demandas de asignación o promoción. La capacidad de la generación vieja (OGC) ha crecido de 11,696 KB a 13,820 KB después de la octogésima primera recolección de basura completa (FGC). La capacidad máxima de la generación (y el espacio) es de 60,544 KB (OGCMX), por lo que todavía tiene espacio para expandirse.

MONITORIZAR INSTRUMENTACIÓN PARA UNA JVM REMOTA

Este ejemplo se conecta al lvmid 40496 en el sistema llamado remote.domain utilizando la opción -gcutil, con muestras tomadas cada segundo indefinidamente.

El lvmid se combina con el nombre del host remoto para construir un vmid de 40496@remote.domain. Este vmid da como resultado el uso del protocolo rmi para comunicarse con el servidor jstatd predeterminado en el host remoto. El servidor jstatd se localiza utilizando el comando rmiregistry en remote.domain que está enlazado al puerto predeterminado del comando rmiregistry (puerto 1099).

NAME

jstat - Monitor statistics for a Java Virtual Machine

SYNOPSIS

jstat [ -? -h ] [ -t ] [ -R ] [ -v ] [ -e ] [ -g ] [ -c ] [ -S { s,S,u,l,h,f,p,m,P} ] [ -o ] [ -J ] [ -Xint ] [ -Xcomp ] [ -Xmixed ] [ -f ] [ -n ] [ -m ] [ -P ] [ --add-header ] [ --no-header ] [ -H header ] [ -r ] [ -l ] [ -w width ] [ -T {i,c,m,k,p} ] [ -E {i,c,m,k,p} ] [ -F {i,c,m,k,p} ] [ -O {i,c,m,k,p} ] [ -C {i,c,m,k,p} ] [ -N {i,c,m,k,p} ] [ -I {i,c,m,k,p} ] [ -L {i,c,m,k,p} ] [ -K {i,c,m,k,p} ] [ -D {i,c,m,k,p} ] [ -J {i,c,m,k,p} ] [ -M {i,c,m,k,p} ] [ -A {i,c,m,k,p} ] [ -R {i,c,m,k,p} ] [ -S {i,c,m,k,p} ] [ -X {i,c,m,k,p} ] [ -Y {i,c,m,k,p} ] [ -Z {i,c,m,k,p} ] [ -x {i,c,m,k,p} ] [ -y {i,c,m,k,p} ] [ -z {i,c,m,k,p} ] [ -a {i,c,m,k,p} ] [ -b {i,c,m,k,p} ] [ -d {i,c,m,k,p} ] [ -f {i,c,m,k,p} ] [ -g {i,c,m,k,p} ] [ -h {i,c,m,k,p} ] [ -j {i,c,m,k,p} ] [ -k {i,c,m,k,p} ] [ -o {i,c,m,k,p} ] [ -p {i,c,m,k,p} ] [ -q {i,c,m,k,p} ] [ -r {i,c,m,k,p} ] [ -s {i,c,m,k,p} ] [ -u {i,c,m,k,p} ] [ -w {i,c,m,k,p} ] [ -x {i,c,m,k,p} ] [ -y {i,c,m,k,p} ] [ -z {i,c,m,k,p} ] [ <pid> [ <interval> [ <count> ] ] ]

DESCRIPTION

The jstat command displays statistics about the performance of a Java Virtual Machine (JVM). It can be used to monitor garbage collection, class loading, JIT compilation, and other aspects of JVM performance.

OPTIONS

-?, -h
Display help information.
-t
Display the time stamp of the output.
-R
Display the remaining space in the heap.
-v
Display virtual machine information.
-e
Display extended garbage collection statistics.
-g
Display garbage collection statistics per generation.
-c
Display class loader statistics.
-S { s,S,u,l,h,f,p,m,P}
Specify the type of garbage collector to monitor:
s - Serial
S - Parallel
u - Concurrent Mark Sweep (CMS)
l - G1 Garbage Collector
h - Z Garbage Collector
f - Epsilon GC
p - Shenandoah GC
m - Metaspace GC
P - G1 NewGen GC
-o
Output values in octal format.
-J
Pass the specified option to the `java` launcher.
-Xint
Display interpreter mode statistics.
-Xcomp
Display compiled mode statistics.
-Xmixed
Display mixed mode statistics.
-f
Display full garbage collection statistics.
-n
Display native memory statistics.
-m
Display Metaspace statistics.
-P
Display PermGen statistics.
--add-header
Add header to the output.
--no-header
Do not add header to the output.
-H header
Specify a custom header.
-r
Reset the statistics.
-l
Display load information.
-w width
Set the output width.
-T {i,c,m,k,p}
Selects the type of data to display:
i - Instrumentation
c - Class Loader
m - Metaspace
k - Compilation
p - Print compilation statistics
-E {i,c,m,k,p}
Enable instrumentation for the specified type.
-F {i,c,m,k,p}
Disable instrumentation for the specified type.

Clear instrumentation statistics.

No instrumentation for the specified type.

Initialize instrumentation for the specified type.

List available instrumentation types.
-K {i,c,m,k,p}
Keep instrumentation statistics.
-D {i,c,m,k,p}
Dump instrumentation statistics.

JIT compilation statistics.

Monitor instrumentation.

All instrumentation.

eXtended statistics.

The process ID of the Java Virtual Machine to monitor.
<interval>
The sampling interval in milliseconds.
<count>

EXAMPLES

Display GC statistics for a local JVM

jstat -gc 1234

Display GC statistics for a remote JVM

jstat -gc user@remotehost:1234

Display class loader statistics for a local JVM

jstat -class 1234

Display JIT compiler statistics for a local JVM

jstat -compiler 1234

Display all statistics for a local JVM

jstat -all 1234

Display statistics for a local JVM every second

jstat -gc 1234 1000

VM INSTRUMENTATION FOR A LOCAL JVM

To display VM instrumentation for a local JVM, use the -t option with the process ID.

jstat -t <pid>

VM INSTRUMENTATION FOR EACH SAMPLE

To display VM instrumentation for each sample, use the -t option with the process ID and the sampling interval.

jstat -t <pid> <interval>

MONITOR INSTRUMENTATION FOR A REMOTE JVM

To monitor instrumentation for a remote JVM, specify the remote host and process ID.
