JACK_PROPERTY(1) Manual de comandos generales JACK_PROPERTY(1)

NOMBRE

jack_property - cliente JACK para listar, establecer y eliminar información de metadatos

SINOPSIS

jack_property -l
jack_property [ -c | -p ] -l identificador
jack_property [ -c | -p ] -l identificador clave
jack_property [ -c | -p ] -s identificador clave valor [ tipo ]
jack_property [ -c | -p ] -d identificador
jack_property [ -c | -p ] -d identificador clave
jack_property -D

DESCRIPCIÓN

jack_property se puede utilizar para listar, establecer y eliminar cualquier metadato asociado con los puertos y clientes de un servidor JACK.

Hay tres formas principales de usar el comando. La opción -l se usa para listar metadatos existentes. La opción -s se usa para establecer metadatos. Las opciones -d/-D se usan para eliminar metadatos.

El identificador es normalmente un UUID (los UUID para puertos y clientes se pueden mostrar con jack_lsp(1)). Si se usa la opción -c, entonces identificador se interpretará como un nombre de cliente y su UUID se buscará internamente y se utilizará para la operación de metadatos relevante. Si se usa la opción -p, entonces identificador se interpretará como un nombre de puerto y su UUID se buscará internamente y se utilizará para la operación de metadatos relevante.

La clave es una cadena arbitraria que identifica los metadatos sobre los que se va a operar.

El valor es una cadena arbitraria que define el valor de los metadatos que se van a crear.

El tipo es un tipo MIME opcional, dado como una cadena. Un tipo vacío para un metadato dará como resultado que se interprete como "text/UTF-8".

OPCIONES

-l
lista todos los metadatos definidos actualmente
-l identificador
lista todos los metadatos definidos actualmente para identificador
-l identificador clave
muestra el valor de los metadatos asociados con la clave para identificador
-d identificador
elimina todos los metadatos para identificador
-d identificador clave
elimina los metadatos asociados con la clave para identificador
-D
elimina todos los metadatos definidos actualmente
-s identificador clave valor [ tipo ]
establece los metadatos asociados con la clave a valor para identificador, con su tipo establecido a tipo si se proporciona
-c
interpreta un identificador dado como un nombre de cliente en lugar de un UUID
-p
interpreta un identificador dado como un nombre de puerto en lugar de un UUID
