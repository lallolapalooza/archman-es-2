Descripción Detallada

JSON Web Signature (RFC 7515)

JSON Web Token (RFC 7519)

Un JSON Web Signature (JWS) es un formato de datos estándar para expresar firmas criptográficas en JSON. Las firmas se producen utilizando una JSON Web Key (JWK).

Por ejemplo, para crear una firma simple de una cadena utilizando una JWK (manejo de errores omitido):

json_t *sig(const char *str, const json_t *jwk) {
    json_auto_t *jws = json_pack("{s:o}", "payload",
                                 jose_b64_enc(str, strlen(str)));
    jose_jws_sig(NULL, jws, NULL, jwk);
    return json_incref(jws);
}

Del mismo modo, para verificar esta firma (de nuevo, manejo de errores omitido):

char *ver(const json_t *jws, const json_t *jwk) {
    char *str = NULL;
    size_t len = 0;
    if (!jose_jws_ver(NULL, jws, NULL, jwk))
        return NULL;
    len = jose_b64_dec(json_object_get(jws, "payload"), NULL, 0);
    str = calloc(1, len + 1);
    jose_b64_dec(json_object_get(jws, "payload"), str, len);
    return str;
}

Ver también:

https://tools.ietf.org/html/rfc7515

Un JSON Web Token (JWT) es un formato de datos estándar para expresar afirmaciones transferidas entre dos partes en JSON. El JWT está envuelto en cualquier número de Firmas (JWS) o Cifrados (JWE).

https://tools.ietf.org/html/rfc7515

bool jose_jws_sig (jose_cfg_t * cfg, json_t * jws, json_t * sig, const json_t * jwk)

Crea una o más firmas en un objeto JWS. El objeto JWS (jws) debe contener la propiedad 'payload'.

Todas las firmas creadas se añadirán a la JWS especificada por jws. Si la JWS resultante (jws) contuviera solo una firma, la JWS se representará en la sintaxis de serialización JSON de JWS Aplanada. De lo contrario, se representará en la sintaxis de serialización JSON de JWS General.

Si jwk contiene una JWK, se crea una única firma. En este caso, jws debe contener una plantilla de objeto de firma JWS o NULL. Puede especificar algoritmos u otros comportamientos de firma simplemente especificándolos en las cabeceras JOSE de la plantilla del objeto de firma JWS según se define en RFC 7515. Si falta una propiedad requerida, se utilizarán valores predeterminados razonables y se insertarán en las cabeceras JOSE; inferiéndolos de la JWK (jwk) siempre que sea posible.

Si jwk contiene una matriz de JWKs o un JWKSet, se crean múltiples firmas. En este caso, el parámetro sig debe contener uno de los siguientes valores:

1.
Una plantilla de objeto de firma JWS que se utilizará para todas las firmas. En este caso, se hará una copia por cada firma y sig no se modificará de ninguna manera.
2.
Una matriz de plantillas de objetos de firma JWS. Cada plantilla se utilizará con su JWK correspondiente de jwk. Si las matrices en sig y jwk tienen un tamaño diferente, ocurrirá un error.
3.
NULL. Esto tiene el mismo efecto que pasar NULL para cada clave separada.

Parámetros:

cfg El contexto de configuración (opcional).
jws El objeto JWS.
sig Las plantillas del objeto de firma JWS o NULL.
jwk La(s) JWK(s) o JWKSet utilizada(s) para crear las firmas.

Devuelve:

En caso de éxito, verdadero. De lo contrario, falso.

jose_io_t* jose_jws_sig_io (jose_cfg_t * cfg, json_t * jws, json_t * sig, const json_t * jwk)

Crea una o más firmas en un objeto JWS utilizando transmisión en flujo. Esta función se comporta sustancialmente como jose_jws_sig() excepto:

La carga útil no se especifica en la JWS (jws). Más bien, la carga útil se proporciona utilizando el objeto IO devuelto. La entrada al objeto IO devuelto no se codificará internamente en Base64. Por lo tanto, es posible que deba anteponer la cadena IO con el resultado de jose_b64_enc_io() (dependiendo de su situación).

Del mismo modo, la carga útil no se almacena en el objeto JWS (jws). Esto permite cargas útiles separadas y reduce el uso de memoria para firmas sobre cargas útiles grandes. Si desea adjuntar la carga útil, es su responsabilidad hacerlo manualmente.

Parámetros:

cfg El contexto de configuración (opcional).
jws El objeto JWS.
sig Las plantillas del objeto de firma JWS o NULL.
jwk La(s) JWK(s) o JWKSet utilizada(s) para crear las firmas.

Devuelve:

El nuevo objeto IO o NULL en caso de error.

bool jose_jws_ver (jose_cfg_t * cfg, const json_t * jws, const json_t * sig, const json_t * jwk, bool all)

Verifica las firmas de una o más JWK en un objeto JWS. El objeto JWS (jws) debe contener la propiedad 'payload'.

Si se especifica una única JWK (jwk), el parámetro all se ignora. En este caso, si desea verificar un objeto de firma JWS particular, puede especificarlo utilizando el parámetro sig. De lo contrario, puede simplemente pasar NULL para verificar cualquiera de los objetos de firma JWS en el objeto JWS.

Si jwk contiene una matriz de JWKs o un JWKSet, el parámetro all determina si se requiere una firma válida para cada JWK para validar correctamente la JWS. Por ejemplo, si establece all en falso, esta función tendrá éxito si se encuentra una firma válida para cualquiera de las JWKs proporcionadas. Al utilizar este modo de firma múltiple JWK, el parámetro sig debe contener uno de los siguientes valores:

1.
Un único objeto de firma JWS para validar contra todas/cualquiera de las JWKs proporcionadas.
2.
Una matriz de objetos de firma JWS. En este caso, cada objeto de firma JWS se mapeará a su JWK correspondiente de jwk. Si las matrices en sig y jwk tienen un tamaño diferente, ocurrirá un error.
3.
NULL. Esto tiene el mismo efecto que pasar NULL para cada clave separada.

Parámetros:

cfg El contexto de configuración (opcional).
jws El objeto JWS.
sig Los objetos de firma JWS a verificar o NULL.
jwk La(s) JWK(s) o JWKSet utilizada(s) para verificar las firmas.
all Si se requiere o no la validación de todas las JWKs.

Devuelve:

En caso de éxito, verdadero. De lo contrario, falso.

NAME

jose_jws_ver_stream

verifies signatures of one or more JWKs in a JWS object using streaming

SYNOPSIS

jose_io_t *jose_jws_ver_stream(jose_cfg_t *cfg, jose_jws_t *jws, jose_jws_sig_t *sig, jose_jwk_t *jwk, bool all);

Detailed Description

Verifies signatures of one or more JWKs in a JWS object using streaming. This function behaves substantially like jose_jws_ver() except:

The payload is not specified in the JWS (jws). Rather, the payload is provided using the returned IO object. The input to the returned IO object will not be internally Base64 encoded. So you may need to prepend the IO chain with the result of jose_b64_enc_io() (depending on your situation).

Final signature verification is delayed until jose_io_t::done() returns.

Parameters:

cfg The configuration context (optional).
jws The JWS object.
sig The JWS signature object(s) to verify or NULL.
jwk The JWK(s) or JWKSet used for verifying signatures.
all Whether or not to require validation of all JWKs.

Returns:

The new IO object or NULL on error.
