DESCRIPCIÓ

N

El comando jstat muestra estadísticas de rendimiento de una máquina virtual Java HotSpot instrumentada. La JVM de destino se identifica por su identificador de máquina virtual, u opción

vmid.

El comando jstat soporta dos tipos de opciones, opciones generales y opciones de salida. Las opciones generales hacen que el comando jstat muestre información simple de uso y de versión. Las opciones de salida determinan el contenido y el formato de la salida

estadística.

Todas las opciones y su funcionali

dad están sujetas a cambios o
eliminación en versiones futuras.

OPCIONES DE SALIDA PARA EL COMANDO

JSTAT

Si no especifica una opción general, entonces puede especificar opciones de salida. Las opciones de salida determinan el contenido y el formato de la salida del comando jstat, y consisten en un único statOption, más cualquiera de las otras opciones de salida (-h, -t y -J). El statOption debe ir

primero.

La salida se formatea como una tabla, con columnas separadas por espacios. Una fila de encabezado con títulos describe las columnas. Use la opción -h para establecer la frecuencia con la que se muestra el encabezado. Los nombres de los encabezados de columna son consistentes entre las diferentes opciones. En general, si dos opciones proporcionan una columna con el mismo nombre, entonces la fuente de datos de las dos columnas es la

misma.

Use la opción -t para mostrar una columna de marca de tiempo, etiquetada Timestamp como la primera columna de la salida. La columna Timestamp contiene el tiempo transcurrido, en segundos, desde que se inició la JVM de destino. La resolución de la marca de tiempo depende de varios factores y está sujeta a variación debido a la programación de hilos retrasada en sistemas muy

cargados.

Use los parámetros interval y count para determinar con qué frecuencia y cuántas veces, respectivamente, el comando jstat muestra su

salida.

herramienta.

IDENTIFICADOR DE LA MÁQUINA

VIRTUAL

La sintaxis de la cadena vmid corresponde a la sintaxis de una

URI:

[protocolo:][//]lvmid[@nombrehost[:[puerto][/nombredelservid

or
]

La sintaxis de la cadena vmid corresponde a la sintaxis de una URI. La cadena vmid puede variar desde un simple entero que representa una JVM local hasta una construcción más compleja que especifica un protocolo de comunicación, un número de puerto y otros valores específicos de la

implementación.
protoco
lo
El protocolo de comunicación. Si el valor del protocolo se omite y no se especifica un nombre de host, entonces el protocolo predeterminado es un protocolo local optimizado específico de la plataforma. Si el valor del protocolo se omite y se especifica un nombre de host, entonces el protocolo predeterminado es
rmi.
lvm
id
El identificador de la máquina virtual local para la JVM objetivo. El lvmid es un valor específico de la plataforma que identifica de forma única a una JVM en un sistema. El lvmid es el único componente requerido de un identificador de máquina virtual. El lvmid es típicamente, pero no necesariamente, el identificador de proceso del sistema operativo para el proceso JVM objetivo. Puede usar el comando jps para determinar el lvmid siempre que el proceso JVM no se esté ejecutando en una instancia de docker separada. También puede determinar el lvmid en las plataformas Linux y macOS con el comando ps y en Windows con el Administrador de tareas de
Windows.
nombreh
ost
Un nombre de host o dirección IP que indica el host objetivo. Si el valor del nombrehost se omite, entonces el host objetivo es el host
local.
pue
rto
El puerto predeterminado para comunicarse con el servidor remoto. Si el valor del nombrehost se omite o el valor del protocolo especifica un protocolo local optimizado, entonces el valor del puerto se ignora. De lo contrario, el tratamiento del parámetro puerto es específico de la implementación. Para el protocolo rmi predeterminado, el valor del puerto indica el número de puerto para el rmiregistry en el host remoto. Si el valor del puerto se omite y el valor del protocolo indica rmi, entonces se usa el puerto rmiregistry predeterminado (1099)
.
nombredelserv
idor
El tratamiento del parámetro nombredelservidor depende de la implementación. Para el protocolo local
optimizado, este campo se ignora. Par
a el protocolo rmi, representa el nombre de
