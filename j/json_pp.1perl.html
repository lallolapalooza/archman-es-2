NOMBRE

json_pp - Utilidad de línea de comandos de JSON::PP

SINOPSIS

json_pp [-v] [-f formato_origen] [-t formato_destino] [-json_opt opciones_a_json1[,opciones_a_json2[,...]]]

DESCRIPCIÓN

json_pp convierte entre algunos formatos de entrada y salida (uno de ellos es JSON). Este programa se copió de json_xs y se modificó.

El formato de entrada predeterminado es json y el formato de salida predeterminado es json con la opción pretty (formato bonito).

OPCIONES

-f

-f formato_origen

Lee datos en el formato dado desde STDIN.

Tipos de formato:

json
como JSON
eval
como código Perl

-t

Escribe datos en el formato dado a STDOUT.

null
sin acción.
json
como JSON
dumper
como Data::Dumper

-json_opt

Opciones para JSON::PP

Opciones aceptables son:

ascii latin1 utf8 pretty indent space_before space_after relaxed canonical allow_nonref
allow_singlequote allow_barekey allow_bignum loose escape_slash indent_length

Opciones múltiples deben estar separadas por comas:

Correcto: -json_opt pretty,canonical
Incorrecto: -json_opt pretty -json_opt canonical

-v

Opción detallada, pero actualmente sin acción.

-V

Imprime la versión y sale.

EJEMPLOS

$ perl -e'print q|{"foo":"あい","bar":1234567890000000000000000}|' |\
   json_pp -f json -t dumper -json_opt pretty,utf8,allow_bignum

$VAR1 = {
          'bar' => bless( {
                            'value' => [
                                         '0000000',
                                         '0000000',
                                         '5678900',
                                         '1234'
                                       ],
                            'sign' => '+'
                          }, 'Math::BigInt' ),
          'foo' => "\x{3042}\x{3044}"
        };
$ perl -e'print q|{"foo":"あい","bar":1234567890000000000000000}|' |\
   json_pp -f json -t dumper -json_opt pretty

$VAR1 = {
          'bar' => '1234567890000000000000000',
          'foo' => "\x{e3}\x{81}\x{82}\x{e3}\x{81}\x{84}"
        };
