jfs_fsck(8) Utilidad de JFS - comprobación del sistema de archivos jfs_fsck(8)

NOMBRE

jfs_fsck - inicia la reproducción del registro de transacciones de JFS, y comprueba y repara un dispositivo formateado con JFS

SINOPSIS

jfs_fsck [ -afnpvV ] [ -j dispositivo_journal ] [ --omit_journal_replay ] [ --replay_journal_only ] dispositivo

DESCRIPCIÓN

jfs_fsck se utiliza para reproducir el registro de transacciones de JFS, comprobar si hay errores en un dispositivo formateado con JFS y corregir cualquier error encontrado.

dispositivo es el nombre del archivo especial que corresponde al dispositivo real que se va a comprobar (por ejemplo, /dev/hdb1).

jfs_fsck debe ejecutarse como root.

ADVERTENCIA

jfs_fsck solo debe usarse para comprobar un sistema de archivos **sin montar** o un sistema de archivos montado en **SOLO LECTURA**. ¡Usar jfs_fsck para comprobar un sistema de archivos montado de otra forma que no sea en SOLO LECTURA podría dañar gravemente el sistema de archivos!

OPCIONES

Si no se seleccionan opciones, la predeterminada es -p.

-a
Modo de comprobación automática - Reproduce el registro de transacciones. No continúa el procesamiento de fsck a menos que el estado agregado esté sucio o la reproducción del registro falle. Funcionalmente equivalente a -p. El modo de comprobación automática es típicamente el modo predeterminado utilizado cuando se llama a jfs_fsck al arrancar.
-f
Reproduce el registro de transacciones y fuerza la comprobación incluso si el sistema de archivos parece limpio. Repara todos los problemas automáticamente.
-j dispositivo_journal
Especifica el dispositivo de journal.
-n
Abre el sistema de archivos en modo de solo lectura. No reproduce el registro de transacciones. Informa de errores, pero no los repara.
--omit_journal_replay
Omite la reproducción del registro de transacciones. Esta opción no debe usarse a menos que sea como último recurso (es decir, el registro se ha corrompido gravemente y su reproducción causa más problemas).
-p
Repara automáticamente ("preen") el sistema de archivos. Reproduce el registro de transacciones. No continúa el procesamiento de fsck a menos que el estado agregado esté sucio o la reproducción del registro falle. Funcionalmente equivalente a -a.
--replay_journal_only
Solo reproduce el registro de transacciones. No continúa con una comprobación completa del sistema de archivos si la reproducción falla o si el sistema de archivos sigue sucio incluso después de la reproducción del journal. En general, esta opción solo debe usarse con fines de depuración, ya que podría dejar el sistema de archivos en un estado no montable. Esta opción no se puede usar con -f, -n o --omit_journal_replay.
-v
Mensajes detallados - imprime detalles y sentencias de depuración en stdout.
-V
Imprime la información de la versión y sale (independientemente de cualquier otra opción elegida).

EJEMPLOS

Comprueba la 3ª partición del 2º disco duro, imprime información extendida en stdout, reproduce el registro de transacciones, fuerza una comprobación completa de jfs_fsck y da permiso para reparar todos los errores:

jfs_fsck -v -f /dev/hdb3

Comprueba la 5ª partición del 1º disco duro, e informa, pero no repara, cualquier error:

jfs_fsck -n /dev/hda5

CÓDIGO DE SALIDA

El código de salida devuelto por jfs_fsck representa una de las siguientes condiciones:

 0
Sin errores
 1
Errores del sistema de archivos corregidos y/o reproducción del registro de transacciones realizada con éxito
 2
Errores del sistema de archivos corregidos, se debería reiniciar el sistema si el sistema de archivos estaba montado
 4
Errores del sistema de archivos dejados sin corregir
 8
Error operativo
 16
Error de uso o sintaxis
 128
Error de biblioteca compartida

INFORME DE ERRORES

Si encuentra un error en JFS o jfs_fsck, por favor, repórtelo a través del sistema de seguimiento de errores (sección "Report Bugs") del sitio web del proyecto JFS:

http://jfs.sourceforge.net/

Por favor, envíe tanta información pertinente como sea posible, incluyendo la salida completa de la ejecución de jfs_fsck con la opción -v en el dispositivo JFS.
