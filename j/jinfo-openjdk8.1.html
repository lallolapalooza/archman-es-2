jinfo(1) Herramientas de Solución de Problemas jinfo(1)

NOMBRE

jinfo - Genera información de configuración. Este comando es experimental y no tiene soporte.

SINOPSIS

jinfo [ opción ] pid
jinfo [ opción ] ejecutable core
jinfo [ opción ] [ id-servidor ] nombre-host-o-IP-remoto
opción
Las opciones de línea de comandos. Ver Opciones.
pid
El ID del proceso para el cual se va a imprimir la información de configuración. El proceso debe ser un proceso Java. Para obtener una lista de procesos Java en ejecución en una máquina, use el comando jps(1).
ejecutable
El ejecutable de Java a partir del cual se produjo el volcado de memoria (core dump).
core
El archivo core para el cual se va a imprimir la información de configuración.
nombre-host-o-IP-remoto
El servidor de depuración remoto nombre-host o dirección IP. Ver jsadebugd(1).
id-servidor
Un ID único opcional para usar cuando varios servidores de depuración se ejecutan en el mismo host remoto.

DESCRIPCIÓN

El comando jinfo imprime información de configuración de Java para un proceso Java especificado, un archivo core o un servidor de depuración remoto. La información de configuración incluye las propiedades del sistema Java y las opciones de línea de comandos de la Máquina Virtual Java (JVM). Si el proceso especificado se está ejecutando en una JVM de 64 bits, es posible que necesite especificar la opción -J-d64, por ejemplo: jinfo-J-d64 -sysprops pid.

Esta utilidad no tiene soporte y podría no estar disponible en futuras versiones del JDK. En sistemas Windows donde dbgeng.dll no está presente, se deben instalar las Herramientas de Depuración para Windows para que estas herramientas funcionen. La variable de entorno PATH debe contener la ubicación de jvm.dll que utiliza el proceso objetivo o la ubicación desde la que se produjo el archivo de volcado de fallos. Por ejemplo, set PATH=%JDK_HOME%\jre\bin\client;%PATH%.

OPCIONES

sin-opción
Imprime tanto las opciones de línea de comandos como los pares de nombre-valor de las propiedades del sistema.
-flag nombre

Imprime el nombre y el valor de la opción de línea de comandos especificada.
-flag [+|-]nombre

habilita o deshabilita la opción de línea de comandos booleana especificada.
-flag nombre=valor

establece la opción de línea de comandos especificada a el valor especificado.
-flags

Imprime las opciones de línea de comandos pasadas a la JVM.
-sysprops

Imprime las propiedades del sistema Java como pares de nombre-valor.
-h

Imprime un mensaje de ayuda.
-help

Imprime un mensaje de ayuda.
