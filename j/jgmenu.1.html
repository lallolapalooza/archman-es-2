DESCRIPCIÓN

jgmenu es un menú simple para Linux/BSD. Lee datos de menú CSV de un archivo y genera un menú gráfico en una ventana X11.

Campos

Cada línea de datos de menú CSV se analiza en los siguientes campos, utilizando la coma como separador de campos:

(1)
descripción
(2)
comando
(3)
icono
(4)
directorio de trabajo
(5)
metadatos

Por ejemplo:

printf "Terminal,xterm\\nWeb Browser,firefox" | jgmenu --vsimple

Caracteres Especiales al inicio de línea

#
Ignorar línea
.
Una línea que comience con un punto seguido de un espacio, cargará el archivo especificado por la cadena que sigue al punto.
@
Tratar como widget.

Caracteres Especiales en los campos

,
Dado que las comas se utilizan como separadores de campos, los campos individuales solo pueden contener comas si están entre comillas triples. Por ejemplo:

foo,“““^pipe(find . -printf '%f,display %p,%p\n')”””

< > &
El campo de descripción se analiza como marcado Pango, por lo que <, > y & deben escaparse como &lt;, &gt; y &amp; respectivamente.
"
A diferencia de la mayoría de las implementaciones CSV, una sola instancia de una comilla doble (") no se considera un carácter especial. La razón es permitir a los usuarios escribir comandos con comillas dobles sin tener que escaparlos.
"""
Utilice tres comillas """ para comenzar y finalizar un valor completamente entre comillas. El principal caso de uso para esto es cuando se necesita una coma dentro de un valor.

Marcado

La sintaxis ^foo(bar) se utiliza para realizar la acción foo con el argumento bar. Nos referimos a bar como el valor interno.

El siguiente marcado es compatible en el campo descripción:

sep()
Define un separador. Si se proporciona un valor interno, el separador aparecerá como un título. Si no se proporciona un valor interno, el separador será simplemente una línea horizontal.

El siguiente marcado es compatible en el campo comando:

^tag()
Define el inicio de un nuevo nodo de estructura de menú.

Las líneas que siguen a ^tag(whatever) no se mostrarán en el menú de nivel superior, pero se pueden abrir usando ^checkout() o ^root().

item0.0
item0.1
submenu1,^checkout(1)
submenu2,^root(2)
^tag(1)
item1.0
item1.1
^tag(2)
item2.0
item2.1
^checkout()
Abre la etiqueta especificada por el valor interno como un submenú en una nueva ventana.
^root()
Abre la etiqueta especificada por el valor interno en la ventana raíz, reemplazando el menú actual.
^sub()
Dibuja una flecha de submenú. Esto puede ser útil para crear submenús con stay_alive=0. Por ejemplo:
item0.0
item0.1
submenu1,^sub(echo "item1.0" | jgmenu --simple)
^back()
Selecciona el menú padre.
^term()
Ejecuta el programa en la terminal.
^pipe()
Ejecuta un subproceso y selecciona un menú basado en su salida estándar.
^filter()
Invoca la búsqueda.
^quit()
Salir.

Las líneas que comienzan con `@` en los archivos CSV con formato de jgmenu se analizan de acuerdo con la siguiente sintaxis:

El tipo de widget, que puede ser uno de los siguientes:
rect
Rectángulo con un borde de 1px de grosor dibujado usando fgcol

Cuadro de búsqueda que muestra el filtro actual (lo que el usuario ha escrito) o el texto especificado si no se ha invocado ningún filtro.
icon
Icono
accion
La acción a realizar cuando se selecciona. Puede ser un comando de shell o una acción de menú como ^root().
x, y
Margen horizontal y vertical del widget
ancho, alto
Ancho y alto del widget
radio
Radio de la esquina

ARCHIVO DE CONFIGURACION

Si no se especifica ningún archivo con la opción –config-file=, se cumple la especificación XDG Base Directory. Es decir:

•
Configuración global en ${XDG_CONFIG_DIRS:-/etc/xdg}
•
Anulación de configuración del usuario en ${XDG_CONFIG_HOME:-$HOME/.config}

Para la mayoría de los usuarios, ~/.config/jgmenu/jgmenurc es adecuado.

Las variables de configuración globales se establecen en el siguiente orden (es decir, la parte inferior de la lista tiene mayor precedencia):

•

•
archivo de configuración de tint2rc (se puede especificar mediante la variable de entorno TINT2_CONFIG)
•

•
argumentos de la línea de comandos

Sintaxis

Las líneas que comienzan con # se ignoran.

Todas las demás líneas se reconocen como la configuración de variables en el formato

clave = valor

Los espacios en blanco se ignoran en su mayor parte.

Valores

A menos que se especifique lo contrario, los valores se tratan como cadenas simples.

A continuación se presentan algunos tipos específicos:

booleano
Cuando una variable toma un valor booleano, solo se aceptan 0 y 1. 0 significa falso; 1 significa verdadero.
entero
Cuando una variable toma un valor entero, solo se aceptan valores numéricos. Los únicos caracteres válidos son los dígitos (0-9) y el signo menos. Todas las variables enteras relacionadas con la geometría y la posición se interpretan como valores de píxeles a menos que se especifique lo contrario.
color
Cuando una variable toma un valor de color, solo se reconoce la sintaxis #rrggbb aa, donde rr, gg y bb representan valores hexadecimales (00-ff) para los colores rojo, verde y azul respectivamente; y aa representa el valor del canal alfa expresado como un porcentaje (0-100) (es decir, 100 significa sin transparencia y 0 significa completamente transparente). Por ejemplo, #ff0000 100 representa rojo sin transparencia, mientras que #000088 50 significa azul oscuro con 50% de transparencia.
ruta
Cuando una variable toma un valor de ruta, se evalúa como una cadena. Si el primer carácter es una tilde (~), se reemplazará por la variable de entorno $HOME tal como la expandiría un shell.

Si se establece en 1, el menú se "ocultará" en lugar de "salir" cuando ocurran los siguientes eventos: hacer clic en un elemento del menú; hacer clic fuera del menú; presionar escape. Cuando está en modo oculto, una señal USR1 "mostrará" el menú.
persistent = booleano (predeterminado 0)
Si se establece en 1, el menú no saldrá ni se ocultará cuando ocurran los siguientes eventos: hacer clic en un elemento del menú; hacer clic fuera del menú; presionar escape. Usar en conjunto con el marcado ^quit().

Si se establece en 1, jgmenu se iniciará en modo "oculto". Esto es útil para iniciar jgmenu durante el proceso de arranque y luego enviar un killall -SIGUSR1 jgmenu para mostrar el menú.

DESCRIPTION

jgmenu is a simple, highly configurable graphical menu application for the X Window System, intended as a replacement for the menu supplied by the FreeDesktop.org specification's menu specification.

The menu is generated from the file $HOME/.config/jgmenu/menu (default) and may be optionally appended to or prepended to from the files $HOME/.config/jgmenu/append.csv and $HOME/.config/jgmenu/prepend.csv respectively.

The menu may be run using the jgmenu_run(1) utility.

OPTIONS

‐d file
Sets the desktop file dir to file. Default is /usr/share/applications.
‐f file
Sets the menu file to file. Default is $HOME/.config/jgmenu/menu.
‐i file
Sets the prepend file to file. Default is $HOME/.config/jgmenu/prepend.csv.
‐I file
Sets the append file to file. Default is $HOME/.config/jgmenu/append.csv.
‐p file
Sets the pipe file to file. Default is $HOME/.config/jgmenu/pipe.
‐P file
Sets the parse file to file. Default is $HOME/.config/jgmenu/parse.
‐s file
Sets the startup file to file. Default is $HOME/.config/jgmenu/startup.
‐S file
Sets the hooks file to file. Default is $HOME/.config/jgmenu/hooks.
‐v
Verbose mode. Prints various debug information to stdout.
‐x file
Sets the config file to file. Default is $HOME/.config/jgmenu/jgmenurc.
‐X file
Sets the icon theme file to file. Default is $HOME/.config/jgmenu/icon.theme.
‐?
Show help message.

USER INTERFACE

The menu is displayed as a list of clickable entries. The menu can be navigated using the keyboard arrow keys or mouse. Selecting an entry launches the associated application.

jgmenu has a simple menu structure: root, menus, submenus, and items.

The menu may be presented in a vertical or horizontal layout.

Menu structure

Menu entries are defined in jgmenu configuration files, typically $HOME/.config/jgmenu/menu. Entries can be applications, submenus, or separators.

The format for entries in the menu file is:

label,command,icon

Where:

  • label is the text displayed in the menu.
  • command is the command to execute when the entry is selected.
  • icon is the icon to display for the entry (optional).

Entries can be nested to create submenus. For example:

Submenu,submenu_command,submenu_icon
    \tItem1,item1_command,item1_icon
    \tItem2,item2_command,item2_icon

The prepend.csv and append.csv files allow adding entries before and after the main menu entries, respectively.

Customization

jgmenu can be customized through the configuration file $HOME/.config/jgmenu/jgmenurc. This file uses a simple key=value syntax.

Key configuration options include:

menu_padding_top, menu_padding_bottom, menu_padding_left, menu_padding_right
Sets the padding around the entire menu.
item_margin_y, item_margin_x
Sets the vertical and horizontal margin around individual menu items.
item_padding_y, item_padding_x
Sets the vertical and horizontal padding inside menu items (between border and content).
color_norm_fg, color_norm_bg
Foreground and background colors for normal menu items.
color_sel_fg, color_sel_bg
Foreground and background colors for the selected menu item.
font
Sets the font used for the menu.
icon_size
Sets the size of the icons.

CONFIGURATION FILE

The jgmenu configuration is controlled by the file $HOME/.config/jgmenu/jgmenurc. This file uses a simple key=value format. Any uncommented lines in the file are parsed as settings.

For example:

# Set the font to 12pt Sans Serif
font=Sans Serif:size=12

# Set the normal background and foreground colors
color_norm_bg=#333333
color_norm_fg=#ffffff

# Set the selected background and foreground colors
color_sel_bg=#336699
color_sel_fg=#ffffff

# Set the padding around the menu
menu_padding_left=5
menu_padding_right=5
menu_padding_top=5
menu_padding_bottom=5

# Set the margin and padding for menu items
item_margin_y=2
item_margin_x=0
item_padding_y=3
item_padding_x=5

# Set the width of the arrow indicating a submenu
