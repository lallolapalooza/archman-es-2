NOMBRE

jgmenu-lx - genera datos de menú CSV con formato jgmenu

SINOPSIS

jgmenu_run lx

DESCRIPCIÓN

jgmenu_run lx genera datos de menú CSV con formato jgmenu para los menús de aplicaciones definidos por freedesktop.org, utilizando libmenu-cache de LXDE.

VARIABLES DE ENTORNO

XDG_MENU_PREFIX
Esto se puede usar para especificar un archivo .menu. Por ejemplo, XDG_MENU_PREFIX=lxde- cargará lxde-applications.menu
JGMENU_NO_DIRS
Si se establece, las aplicaciones se listarán sin una estructura de directorio
JGMENU_NO_PEND
No leer append.csv ni prepend.csv
JGMENU_NAME_FORMAT
Ver csv_name_format en jgmenu(1)

PROBLEMAS CONOCIDOS

xfce-applications.menu no se analiza correctamente.
