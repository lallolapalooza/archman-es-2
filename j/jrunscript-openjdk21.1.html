JRUNSCRIPT(1) Comandos JDK JRUNSCRIPT(1)

NOMBRE

jrunscript - ejecuta un shell de script de línea de comandos que admite modos interactivo y por lotes

SINOPSIS

Nota:

Esta herramienta es experimental y no tiene soporte oficial.

jrunscript [opciones] [argumentos]

opciones
Esto representa las opciones de línea de comandos de jrunscript que se pueden usar. Consulte Opciones para el comando jrunscript.
argumentos
Los argumentos, cuando se usan, siguen inmediatamente después de las opciones o el nombre del comando. Consulte Argumentos.

DESCRIPCIÓN

El comando jrunscript es un shell de script de línea de comandos independiente del lenguaje. El comando jrunscript admite tanto un modo interactivo (leer-evaluar-imprimir) como un modo de ejecución de scripts por lotes (opción -f). Por defecto, JavaScript es el lenguaje utilizado, pero la opción -l se puede usar para especificar un idioma diferente. Al utilizar Java para la comunicación con el lenguaje de scripting, el comando jrunscript admite un estilo de programación exploratorio.

Si se usa JavaScript, antes de evaluar un script definido por el usuario, el comando jrunscript inicializa ciertas funciones y objetos integrados, que se documentan en la Especificación de API para funciones integradas de JavaScript de jrunscript.

OPCIONES PARA EL COMANDO JRUNSCRIPT

-cp ruta o -classpath ruta
Indica dónde se encuentran los archivos de clase a los que el script necesita acceder.
-Dnombre=valor
Establece una propiedad del sistema Java.
-Jbandera
Pasa bandera directamente a la Máquina Virtual Java donde se está ejecutando el comando jrunscript.
-l lenguaje
Utiliza el lenguaje de scripting especificado. Por defecto, se utiliza JavaScript. Para usar otros lenguajes de scripting, debe especificar el archivo JAR del motor de script correspondiente con la opción -cp o -classpath.
-e script
Evalúa el script especificado. Esta opción se puede usar para ejecutar scripts de una sola línea que se especifican completamente en la línea de comandos.
-encoding codificación
Especifica la codificación de caracteres utilizada para leer los archivos de script.
-f archivo-script
Evalúa el archivo de script especificado (modo por lotes).
-f -
Entra en modo interactivo para leer y evaluar un script desde la entrada estándar.
-help o -?
Muestra un mensaje de ayuda y sale.
-q
Enumera todos los motores de script disponibles y sale.

ARGUMENTOS

Si hay argumentos presentes y no se usa la opción -e o -f, entonces el primer argumento es el archivo de script y el resto de los argumentos, si los hay, se pasan como argumentos del script. Si se usan argumentos y la opción -e o -f, entonces todos los argumentos se pasan como argumentos del script. Si faltan los argumentos -e y -f, se utiliza el modo interactivo.

EJEMPLO DE EJECUCIÓN DE SCRIPTS EN LÍNEA

jrunscript -e "print('hola mundo')"

jrunscript -e "cat('http://www.example.com')"

EJEMPLO DE USO DE LENGUAJE ESPECIFICADO Y EVALUACIÓN DEL ARCHIVO DE SCRIPT

jrunscript -l js -f test.js

EJEMPLO DE MODO INTERACTIVO


jrunscript
js> print('¡Hola Mundo\n!');
¡Hola Mundo
js> 34 + 55
89.0
js> t = new java.lang.Thread(function() { print('¡Hola Mundo\n!'); })
Thread[Thread-0,5,main]
js> t.start()
js> ¡Hola Mundo
js>

EJECUCIÓN DE ARCHIVO DE SCRIPT CON ARGUMENTOS DE SCRIPT

En este ejemplo, el archivo test.js es el archivo de script. Los argumentos arg1, arg2 y arg3 se pasan al script. El script puede acceder a estos argumentos con un array de argumentos.

jrunscript test.js arg1 arg2 arg3
