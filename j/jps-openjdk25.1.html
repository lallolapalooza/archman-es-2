Si se inicia con un hostid, entonces busca JVMs en el host indicado, usando el protocolo y el puerto especificados. Se asume que un proceso jstatd se está ejecutando en el host de destino. El comando jps informa el

El lvmid es típicamente, pero no necesariamente, el identificador de proceso del sistema operativo para el proceso JVM. Sin opciones, el comando jps lista el lvmid de cada aplicación Java seguido de la forma corta del nombre de la clase o del nombre del archivo jar de la aplicación. La forma corta del nombre de la clase o del nombre del archivo JAR omite la información del paquete de la clase o la información de la ruta del

archivo

JAR. El comando jps usa el lanzador de Java para encontrar el nombre de la clase y los argumentos pasados al método main. Si el JVM de destino se inicia con un lanzador personalizado, entonces el nombre de la clase o del archivo JAR, y los argumentos para el método main no están disponibles. En este caso, el comando jps emite la cadena Unknown para el nombre de la clase, o el nombre del archivo
