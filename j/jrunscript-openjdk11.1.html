DESCRIPCIÓ

N

El comando jrunscript es un shell de script de línea de comandos independiente del lenguaje. El comando jrunscript soporta tanto el modo interactivo (leer-evaluar-imprimir) como el modo por lotes (opción -f) de ejecución de scripts. Por defecto, se utiliza JavaScript como lenguaje, pero la opción -l se puede usar para especificar un lenguaje diferente. Utilizando la comunicación entre Java y el lenguaje de scripting, el comando jrunscript soporta un e

stilo de programa
ción exploratoria.

ARGUMENTO

S

Si hay argumentos presentes y si no se usa la opción -e o -f, entonces el primer argumento es el archivo de script y el resto de los argumentos, si los hay, se pasan al script. Si se usan argumentos y la opción -e o la opción -f, entonces todos los argumentos se pasan al script. Si faltan los argumentos, -e y -f, entonces se utiliza el modo interactivo. Los argumentos del script están disponibles para un script en una variable del motor llamada arguments de tipo array de

Str
ing.
