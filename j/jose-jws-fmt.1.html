NOMBRE

jose-jws-fmt - Convierte un JWS entre formatos de serialización

SINOPSIS

jose jws fmt -i JWS [-I PAY] [-o JWS] [-O PAY] [-c]

DESCRIPCIÓN

El comando jose jws fmt convierte un JWS a formatos de serialización alternativos. Por ejemplo, puede:

1. Adjuntar el payload a un JWS desvinculado.
2. Desvincular el payload de un JWS.
3. Convertir la Serialización Compacta de JWS a la Serialización JSON de JWS.
4. Convertir la Serialización JSON de JWS a la Serialización Compacta de JWS.

OPCIONES

•-i JSON, --input=JSON : Analizar JWS desde JSON
•-i ARCHIVO, --input=ARCHIVO : Leer JWS desde ARCHIVO
•-i -, --input=-: Leer JWS desde la entrada estándar
•-I ARCHIVO, --detached=ARCHIVO : Leer payload decodificado desde ARCHIVO
•-I -, --detached=- : Leer payload decodificado desde la entrada estándar
•-o ARCHIVO, --output=ARCHIVO : Escribir JWS a ARCHIVO
•-o -, --output=- : Escribir JWS a stdout (por defecto)
•-O ARCHIVO, --detach=ARCHIVO : Desvincular payload y decodificar a ARCHIVO
•-O -, --detach=- : Desvincular payload y decodificar a la salida estándar
•-c, --compact : Salir JWS usando serialización compacta

EJEMPLOS

Adjuntar payload a un JWS desvinculado y emitir Serialización Compacta de JWS:

$ jose jws fmt -i msg.jws -I msg.txt -o compact.jws -c

Desvincular payload de un JWS:

$ jose jws fmt -i msg.jws -o detached.jws -O msg.txt
