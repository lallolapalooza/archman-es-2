drand48(3) Manual de funciones de biblioteca drand48(3)

NOMBRE

drand48, erand48, lrand48, nrand48, mrand48, jrand48, srand48, seed48, lcong48 - generar números pseudoaleatorios distribuidos uniformemente

BIBLIOTECA

Biblioteca estándar de C (libc, -lc)

SINOPSIS

#include <stdlib.h>
double drand48(void);
double erand48(unsigned short xsubi[3]);
long lrand48(void);
long nrand48(unsigned short xsubi[3]);
long mrand48(void);
long jrand48(unsigned short xsubi[3]);
void srand48(long seedval);
unsigned short *seed48(unsigned short seed16v[3]);
void lcong48(unsigned short param[7]);
Requisitos de macro de prueba de características para glibc (ver feature_test_macros(7)):

Todas las funciones mostradas arriba:

    _XOPEN_SOURCE
        || /* glibc >= 2.19: */ _DEFAULT_SOURCE
        || /* glibc <= 2.19: */ _SVID_SOURCE

DESCRIPCIÓN

Estas funciones generan números pseudoaleatorios utilizando el algoritmo congruencial lineal y aritmética entera de 48 bits.

Las funciones drand48() y erand48() devuelven valores de punto flotante de doble precisión no negativos distribuidos uniformemente en el intervalo [0.0, 1.0).

Las funciones lrand48() y nrand48() devuelven enteros largos no negativos distribuidos uniformemente en el intervalo [0, 2^31).

Las funciones mrand48() y jrand48() devuelven enteros largos con signo distribuidos uniformemente en el intervalo [-2^31, 2^31).

Las funciones srand48(), seed48(), y lcong48() son funciones de inicialización, una de las cuales debe ser llamada antes de usar drand48(), lrand48(), o mrand48(). Las funciones erand48(), nrand48(), y jrand48() no requieren que se llame a una función de inicialización previamente.

Todas las funciones funcionan generando una secuencia de enteros de 48 bits, Xi, según la fórmula congruencial lineal:


Xn+1 = (aXn + c) mod m, donde n >= 0

El parámetro m = 2^48, por lo tanto se realiza aritmética entera de 48 bits. A menos que se llame a lcong48(), a y c se dan por:


a = 0x5DEECE66D
c = 0xB

El valor devuelto por cualquiera de las funciones drand48(), erand48(), lrand48(), nrand48(), mrand48(), o jrand48() se calcula generando primero el siguiente Xi de 48 bits en la secuencia. Luego, el número apropiado de bits, de acuerdo con el tipo de elemento de datos a devolver, se copia de los bits de orden superior de Xi y se transforma en el valor devuelto.

Las funciones drand48(), lrand48(), y mrand48() almacenan el último Xi de 48 bits generado en un búfer interno. Las funciones erand48(), nrand48(), y jrand48() requieren que el programa llamante proporcione almacenamiento para los valores Xi sucesivos en el argumento de matriz xsubi. Las funciones se inicializan colocando el valor inicial de Xi en la matriz antes de llamar a la función por primera vez.

La función inicializadora srand48() establece los 32 bits de orden superior de Xi al argumento seedval. Los 16 bits de orden inferior se establecen al valor arbitrario 0x330E.

La función inicializadora seed48() establece el valor de Xi al valor de 48 bits especificado en el argumento de matriz seed16v. El valor anterior de Xi se copia en un búfer interno y un puntero a este búfer es devuelto por seed48().

La función de inicialización lcong48() permite al usuario especificar valores iniciales para Xi, a, y c. Los elementos del argumento de matriz param[0-2] especifican Xi, param[3-5] especifican a, y param[6] especifica c. Después de llamar a lcong48(), una llamada posterior a srand48() o seed48() restaurará los valores estándar de a y c.

ATRIBUTOS

Para obtener una explicación de los términos utilizados en esta sección, consulte attributes(7).

Interfaz Atributo Valor

Las funciones anteriores registran información de estado global para el generador de números aleatorios, por lo que no son seguras para hilos.
