join(n) Comandos integrados de Tcl join(n)

NOMBRE

join - Crear una cadena uniendo los elementos de una lista

SINOPSIS

join lista ?cadenaUnion?

DESCRIPCIÓN

El argumento lista debe ser una lista de Tcl válida. Este comando devuelve la cadena formada al unir todos los elementos de lista juntos con cadenaUnion separando cada par adyacente de elementos. El argumento cadenaUnion se establece por defecto en un carácter de espacio.

EJEMPLOS

Crear una lista separada por comas:

set datos {1 2 3 4 5}
join $datos ", "
     → 1, 2, 3, 4, 5

Usar join para aplanar una lista por un solo nivel:

set datos {1 {2 3} 4 {5 {6 7} 8}}
join $datos
     → 1 2 3 4 5 {6 7} 8

VER TAMBIÉN

list(n), lappend(n), split(n)
