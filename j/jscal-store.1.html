NOMBRE

jscal-store - almacena la calibración del joystick

SINOPSIS

jscal-store <nombre-dispositivo>

DESCRIPCIÓN

jscal-store almacena la información de calibración y mapeo para el dispositivo joystick dado. Esta información puede ser restaurada más tarde usando el comando jscal-restore.

Se puede configurar una regla apropiada con udev para que cualquier configuración de calibración almacenada se restaure cuando se conecte el dispositivo relevante. Algunas distribuciones (al menos Debian, Ubuntu y Slackware) proporcionan paquetes de joystick que instalan dichas reglas automáticamente.

ARCHIVOS

/var/lib/joystick/joystick.state
Archivo utilizado para almacenar la configuración de calibración.

VER TAMBIÉN

jscal(1), jscal-restore(1).
