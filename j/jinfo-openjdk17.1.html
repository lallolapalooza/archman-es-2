JINFO(1) Comandos JDK JINFO(1)

NOMBRE

jinfo - genera información de configuración de Java para un proceso Java especificado

SINOPSIS

Nota: Este comando es experimental y no está soportado.

jinfo [opción] pid

opción
Esto representa las opciones de línea de comandos de jinfo. Ver OPCIONES PARA EL COMANDO JINFO.
pid
El ID del proceso para el cual se imprimirá la información de configuración. El proceso debe ser un proceso Java. Para obtener una lista de procesos Java en ejecución en una máquina, use el comando ps o, si los procesos JVM no se ejecutan en una instancia de docker separada, el comando jps.

DESCRIPCIÓN

El comando jinfo imprime información de configuración de Java para un proceso Java especificado. La información de configuración incluye propiedades del sistema Java y banderas de línea de comandos de la JVM. Si el proceso especificado se está ejecutando en una JVM de 64 bits, es posible que necesite especificar la opción -J-d64, por ejemplo:

jinfo -J-d64 -sysprops pid

Este comando no está soportado y podría no estar disponible en versiones futuras del JDK. En sistemas Windows donde dbgeng.dll no está presente, las Herramientas de depuración para Windows deben estar instaladas para que estas herramientas funcionen. La variable de entorno PATH debe contener la ubicación de jvm.dll que utiliza el proceso de destino o la ubicación desde la que se produjo el archivo de volcado de memoria principal.

OPCIONES PARA EL COMANDO JINFO

Nota:

Si no se utilizan ninguna de las siguientes opciones, se imprimirán tanto las banderas de línea de comandos como los pares de nombre-valor de propiedades del sistema.

-flag nombre
Imprime el nombre y el valor de la bandera de línea de comandos especificada.
-flag [+|-]nombre
Habilita o deshabilita la bandera booleana de línea de comandos especificada.
-flag nombre=valor
Establece la bandera de línea de comandos especificada al valor especificado.
-flags
Imprime las banderas de línea de comandos pasadas a la JVM.
-sysprops
Imprime las propiedades del sistema Java como pares de nombre-valor.
-h o -help
Imprime un mensaje de ayuda.
