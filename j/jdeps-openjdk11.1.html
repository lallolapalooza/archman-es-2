Paquete: jdk11-openjdk

jdeps(1) Herramientas básicas jdeps(1)

NOMBRE

jdeps - Analizador de dependencias de clases de Java.

SINOPSIS

jdeps [opciones] clases ...
opciones
Opciones de línea de comandos. Ver Opciones.
clases
Nombre de las clases a analizar. Puede especificar una clase que se pueda encontrar en la ruta de clases, por su nombre de archivo, un directorio o un archivo JAR.

DESCRIPCIÓN

El comando jdeps muestra las dependencias a nivel de paquete o de clase de los archivos de clase de Java. La clase de entrada puede ser un nombre de ruta a un archivo .class, un directorio, un archivo JAR, o puede ser un nombre de clase completamente calificado para analizar todos los archivos de clase. Las opciones determinan la salida. Por defecto, jdeps muestra las dependencias en la salida del sistema. Puede generar las dependencias en lenguaje DOT (ver la opción -dotoutput).

OPCIONES

-dotoutput <dir>

Directorio de destino para la salida de archivos DOT. Si se especifica, jdeps generará un archivo dot por cada archivo analizado llamado <nombre-del-archivo-archivo>.dot listando las dependencias, y también un archivo de resumen llamado summary.dot listando las dependencias entre los archivos.
-s, -summary

Imprime solo el resumen de dependencias.
-v, -verbose

Imprime todas las dependencias a nivel de clase.
-verbose:package

Imprime dependencias a nivel de paquete excluyendo dependencias dentro del mismo archivo.
-verbose:class

Imprime dependencias a nivel de clase excluyendo dependencias dentro del mismo archivo.
-cp <ruta>, -classpath <ruta>

Especifica dónde encontrar los archivos de clase.

Ver también Establecer la ruta de clases.

-p <nombre-paquete>, -package <nombre-paquete>

Encuentra dependencias en el paquete especificado. Puede especificar esta opción varias veces para diferentes paquetes. Las opciones -p y -e son mutuamente excluyentes.
-e <expresión-regular>, -regex <expresión-regular>

Encuentra dependencias en paquetes que coinciden con el patrón de expresión regular especificado. Las opciones -p y -e son mutuamente excluyentes.
-include <expresión-regular>

Restringe el análisis a las clases que coinciden con el patrón. Esta opción filtra la lista de clases a analizar. Se puede usar junto con -p y -e que aplican el patrón a las dependencias.
-jdkinternals

Encuentra dependencias a nivel de clase en las API internas de JDK. Por defecto, analiza todas las clases especificadas en la opción -classpath y en los archivos de entrada a menos que se especifique la opción -include. No se puede usar esta opción con las opciones -p, -e y -s.

Advertencia: Las API internas de JDK pueden no ser accesibles en versiones futuras.

-P, -profile

Muestra el perfil o el archivo que contiene un paquete.
-apionly

Restringe el análisis a las API, por ejemplo, dependencias de la firma de miembros públicos y protegidos de clases públicas, incluyendo el tipo de campo, tipos de parámetros de método, tipo devuelto y tipos de excepciones comprobadas.
-R, -recursive

Recorre recursivamente todas las dependencias.
-version

Imprime información de la versión.
-h, -?, -help

Imprime el mensaje de ayuda para jdeps.
