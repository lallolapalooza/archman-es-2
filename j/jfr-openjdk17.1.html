NOMBRE

jfr - analiza e imprime archivos de Flight Recorder

SINOPSIS

Para imprimir el contenido de una grabación de vuelo a la salida estándar:

jfr print [opciones] archivo

Para imprimir información de metadatos sobre eventos de grabación de vuelo:

jfr metadata archivo

Para ensamblar archivos de fragmentos en un archivo de grabación de vuelo:

jfr assemble repositorio archivo

Para desmontar un archivo de grabación de vuelo en archivos de fragmentos:

jfr disassmble [opciones] archivo

Para ver las estadísticas resumidas de un archivo de grabación de vuelo:

jfr summary archivo

opciones
Opcional: Especifica opciones de línea de comandos separadas por espacios. Consulte las secciones individuales de subcomponentes para ver descripciones de las opciones disponibles.
archivo
Especifica el nombre del archivo de grabación de vuelo de destino (.jfr).
repositorio
Especifica la ubicación de los archivos de fragmentos que se ensamblarán en una grabación de vuelo.

DESCRIPCIÓN

El comando jfr proporciona una herramienta para interactuar con archivos de flight recorder (.jfr). La función principal es filtrar, resumir y exportar archivos de flight recorder a un formato legible por humanos. También hay soporte para fusionar y dividir archivos de grabación.

Los archivos de Flight Recorder se crean y guardan como archivos con formato binario. Tener una herramienta que pueda extraer el contenido de un flight recorder y manipular el contenido y traducirlo a un formato legible por humanos ayuda a los desarrolladores a depurar problemas de rendimiento con aplicaciones Java.

jfr print subcomando

Use jfr print para imprimir el contenido de un archivo de grabación de vuelo a la salida estándar. La sintaxis es:

jfr print [--xml|--json] [--categories <filtros>] [--events <filtros>] [--stack-depth <profundidad>] <archivo>

donde:

--xml
Imprimir la grabación en formato XML
--json
Imprimir la grabación en formato JSON
--categories <filtros>
Seleccionar eventos que coincidan con un nombre de categoría. El filtro es una lista separada por comas de nombres, simples y/o calificados, y/o patrones glob entre comillas.
--events <filtros>
Seleccionar eventos que coincidan con un nombre de evento. El filtro es una lista separada por comas de nombres, simples y/o calificados, y/o patrones glob entre comillas.
--stack-depth <profundidad>
Número de marcos en los rastreos de pila, por defecto 5
<archivo>
Ubicación del archivo de grabación (.jfr)

El formato predeterminado para imprimir el contenido del archivo de grabación de vuelo es legible por humanos, a menos que se especifique xml o json. Estas opciones proporcionan una salida legible por máquina que puede ser procesada posteriormente por scripts creados por el usuario.

Use jfr --help print para ver ejemplos de uso de filtros.

Para reducir la cantidad de datos mostrados, es posible filtrar eventos o categorías de eventos. El filtro opera en el nombre simbólico de un evento, establecido usando la anotación @Name, o el nombre de la categoría, establecido usando la anotación @Category. Si se usan múltiples filtros, se incluirán eventos de ambos filtros. Si no se usa ningún filtro, se imprimirán todos los eventos. Si se usa una combinación de un filtro de categoría y un filtro de evento, los eventos seleccionados serán la unión de los dos filtros.

Por ejemplo, para mostrar todos los eventos de GC y el evento CPULoad, se podría usar el siguiente comando:

jfr print --categories GC --events CPULoad grabacion.jfr

Los valores de los eventos se formatean según los tipos de contenido que se utilizan. Por ejemplo, un campo con la anotación jdk.jfr.Percentage que tiene el valor 0.52 se formatea como 52%.

Los rastreos de pila están truncados por defecto a 5 marcos, pero el número se puede aumentar/disminuir usando la opción de línea de comandos --stack-depth.

jfr summary subcomando

Use jfr summary para imprimir estadísticas de una grabación. Por ejemplo, un resumen puede ilustrar el número de eventos registrados y cuánto espacio en disco utilizaron. Esto es útil para la depuración y la comprensión del impacto de la configuración de eventos.

La sintaxis es:

jfr summary <archivo>

donde:

<archivo>
Ubicación del archivo de grabación de vuelo (.jfr)

donde:

<archivo>
Ubicación del archivo de grabación de vuelo (.jfr)

jfr assemble subcomando

Use jfr assemble para ensamblar archivos de fragmentos en un archivo de grabación.

La sintaxis es:

jfr assemble <repositorio> <archivo>

donde:

<repositorio>
Directorio donde se encuentra el repositorio que contiene los archivos de fragmentos.
<archivo>
Ubicación del archivo de grabación de vuelo (.jfr)

La información de Flight Recorder se escribe en fragmentos. Un fragmento contiene toda la información necesaria para el análisis. Un fragmento típicamente contiene información útil para la depuración. Si una JVM debería fallar, estos fragmentos se pueden recuperar y usar para crear un archivo de grabación de vuelo usando este comando jfr assemble. jfr-openjdk17(1) — Arch Linux

NAME

jfr-openjdk17 - Oracle JDK Flight Recorder tool

SYNOPSIS

jfr [--help | help] [--version | version] [--verbose | -v] [--quiet | -q] [subcommand]

jfr subcommand [options]

DESCRIPTION

The jfr command is a tool for managing and analyzing Java Flight Recorder (JFR) files.

jfr assemble subcommand

Use jfr assemble to combine multiple JFR chunk files into a single JFR file. The syntax is:

jfr assemble [--output <file>] <files>...

where:

--output <file>
The name of the resulting JFR file. If not specified, the file is named based on the first input file.
<files>
One or more JFR chunk files to assemble. The files are assembled in the order they are provided.

The assemble subcommand can be useful for combining JFR recordings that have been split due to size limits or other reasons. Note that incomplete or corrupted chunk files are silently excluded.

jfr metadata subcommand

Use jfr metadata to dump the metadata from a JFR file. The syntax is:

jfr metadata [--output <file>] <file>

where:

--output <file>
The file to write the metadata to. If not specified, the metadata is written to standard output.
<file>
The JFR file to extract metadata from.

This subcommand is useful for understanding the structure and event definitions within a JFR file, especially when analyzing corrupted or incomplete recordings.

jfr print subcommand

Use jfr print to dump the recorded events from a JFR file. The syntax is:

jfr print [--events <event-list>] [--output <file>] [--settings <file>] <file>

where:

--events <event-list>
A comma-separated list of event types to print. If not specified, all events are printed.
--output <file>
The file to write the event data to. If not specified, the data is written to standard output.
--settings <file>
A file containing JFR settings. This is typically used to filter events based on the recording configuration.
<file>
The JFR file to print events from.

The print subcommand is the primary way to inspect the contents of a JFR recording. The output is typically text-based and human-readable, though the exact format depends on the event types.

jfr summary subcommand

Use jfr summary to generate a summary of the events in a JFR file. The syntax is:

jfr summary [--output <file>] <file>

where:

--output <file>
The file to write the summary to. If not specified, the summary is written to standard output.
<file>
The JFR file to generate a summary for.

The summary provides a high-level overview of the recording, including event counts, durations, and other relevant statistics. It is useful for quickly assessing the overall performance characteristics captured in the recording.

jfr disassemble subcommand

Use jfr disassemble to decompose a flight recording file into its chunk file pieces. The syntax is:

jfr disassemble [--max-chunks <chunks>] [--output <directory>] <file>

where:

--output <directory>
The location to write the disassembled file, by default the current directory
--max-chunks <chunks>
Maximum number of chunks per file, by default 5. The chunk size varies, but is typically around 15 MB.
--max-size <size>
Maximum number of bytes per file.
<file>
Location of the flight recording file (.jfr)

This function can be useful for repairing a broken file by removing the faulty chunk. It can also be used to reduce the size of a file that is too large to transfer. The resulting chunk files are named myfile_1.jfr, myfile_2.jfr, etc. If needed, the resulting file names will be padded with zeros to preserve chronological order. For example, the chunk file name is myfile_001.jfr if the recording consists of more than 100 chunks.

jfr version and help subcommands

Use jfr --version or jfr version to view the version string information for this jfr command.

To get help on any of the jfr subcommands, use:

jfr <--help|help> [subcommand]

where:

[subcommand] is any of:

•
print
•
metadata
•
summary
•
assemble
•
disassemble
