DESCRIPCIÓ

N

jshon analiza, lee y crea JSON. Está diseñado para ser lo más utilizable posible desde la shell y reemplaza analizadores ad hoc frágiles hechos con grep/sed/awk, así como analizadores de una línea pesados hechos con

perl/python.

jshon carga el texto json desde stdin, realiza acciones y luego muestra la última acción en stdout. Algunas opciones producen json, otras producen resúmenes de texto plano. Debido a que Bash tiene estructuras de datos anidadas muy pobres, jshon no devuelve el JSON como un objeto nativo como lo haría una biblioteca típica. En su lugar, jshon mantiene un historial de ediciones en una pi

la, y tú manipulas e
l elemento JSON más alto.

ACCIONE

S

Cada acción tiene la forma de una opción corta. Algunas requieren argumentos. Aunque muchas instancias de jshon pueden canalizarse entre sí, las acciones deben encadenarse secuencialmente para reducir llamadas. Todos los ejemplos usan esta muestra

json:

{"a":1,"b":[true,false,null,"str"],"c":{"d":4,"e":5}}
jshon [acciones] < muestra.

MANIPULACIÓN

Hay varias meta-opciones que no editan json directamente. Llama a estas como máximo una vez por

invocación.
-F
<ruta>
(archivo) lee de un archivo en lugar de stdin. La única opción de no manipulación que toma un
argumento.
-
P
(jsonp) elimina un callback jsonp antes de continuar
normalmente.
-
S
(ordenar) devuelve json ordenado por clave, en lugar del orden
original.
-
Q
(silencioso) desactiva el informe de errores en stderr, para que no tengas que esparcir "2> /dev/null" por todo tu
script.
-
V
(por valor) habilita el paso por valor en la pila del historial de ediciones. En casos extremos con miles de valores profundamente anidados esto puede resultar en que jshon se ejecute varias veces más lento mientras usa varias veces más memoria. Sin embargo, por valor es más seguro que por referencia y generalmente causa menos sorpresas. Por referencia está habilitado por defecto porque no hay riesgo durante operaciones de solo lectura y generalmente hace que editar json sea más conveniente.

jshon -e c -n 7 -i d -p -> c["d"] == 7
jshon -V -e c -n 7 -i d -p -> c["d"] == 5
jshon -V -e c -n 7 -i d -i c -> c["d"]

== 7

Con -V , los cambios deben ser insertados manualmente de vuelta a través de

la pila en lugar de simplemente extr
aer los valores intermedios.
-
C
(continuar) en errores potencialmente recuperables. Por ejemplo, extraer valores que no existen añadirá 'null' a la pila de ediciones en lugar de abortar. El comportamiento puede cambiar en el
futuro.
-
I
(in situ) edición de archivos. Requiere un archivo a modificar y por lo tanto solo funciona con -F. Esto está pensado para hacer cambios ligeras a un archivo json. Cuando se usa, la salida normal se suprime y se escribe el fondo de la pila de
ediciones.
-
0
(delimitadores nulos) Cambia el delimitador de -u de un salto de línea a un nulo. Esta opción solo afecta a -u porque es la única vez que un salto de línea puede aparecer legítimamente en la
salida.

HERRAMIENTAS

jshon siempre produce un campo por línea. Muchas herramientas unix esperan múltiples campos separados por tabuladores por línea. Pasa la salida por 'paste' para arreglar esto. Sin embargo, paste no puede manejar líneas vacías, así que rellénalas con un marcador de posición. Aquí hay un ejemplo:

Otras Herramientas

Hay cada vez más herramientas que producen salida JSON. A menudo, estas utilizan un híbrido de JSON/texto plano orientado a líneas, donde cada línea es una estructura JSON independiente. Lamentablemente, esto significa que la salida en su conjunto no es JSON legítimo. O bien itera a través de los datos línea por línea (llamando a jshon una vez por cada línea) o conviértelo a un array JSON legítimo. Por ejemplo:

while read line; do jshon <<< "$line"; done < <(journalctl -o json)

journalctl -o json | sed -e '1i[' -e '$!s/$/,/' -e '$a]' | jshon

GOLF

Si te importan las líneas de un solo carácter extremadamente cortas, los argumentos se pueden condensar cuando no causen ambigüedad. El ejemplo de -p(op) se puede reducir de la siguiente manera:

jshon -e c -e d -u -p -e e -u == jshon -ec -ed -upee -u

No recomiendo hacer esto (dificulta mucho la comprensión), pero algunas personas hacen golf a pesar de las consecuencias.
