JFR(1) Comandos de JDK JFR(1)

NOMBRE

jfr - imprime y manipula archivos Flight Recorder

SINOPSIS

Para imprimir el contenido de una grabación de vuelo en la salida estándar:

jfr print [opciones] archivo

Para mostrar datos de eventos agregados en la salida estándar:

jfr view [opciones] archivo

Para configurar un archivo de configuración .jfc:

jfr configure [opciones]

Para imprimir información de metadatos sobre los eventos de la grabación de vuelo:

jfr metadata [archivo]

Para ver las estadísticas resumidas de un archivo de grabación de vuelo:

jfr summary archivo

Para eliminar eventos de un archivo de grabación de vuelo:

jfr scrub [opciones] archivo

Para ensamblar archivos de fragmentos en un archivo de grabación de vuelo:

jfr assemble repositorio archivo

Para desmontar un archivo de grabación de vuelo en archivos de fragmentos:

jfr disassemble [opciones] archivo

opciones
Opcional: Especifica opciones de línea de comandos separadas por espacios. Consulte las secciones individuales de subcomponentes para obtener descripciones de las opciones disponibles.
archivo
Especifica el nombre del archivo de grabación de vuelo de destino (.jfr).
repositorio
Especifica la ubicación de los archivos de fragmentos que se ensamblarán en una grabación de vuelo.

DESCRIPCIÓN

El comando jfr proporciona una herramienta para interactuar con archivos de Flight Recorder (.jfr). La función principal es filtrar, resumir y generar archivos de grabación de vuelo en un formato legible por humanos. También hay soporte para limpiar, fusionar y dividir archivos de grabación.

Los archivos de grabación de vuelo se crean y guardan como archivos en formato binario. Tener una herramienta que pueda extraer el contenido de una grabación de vuelo y manipular el contenido y traducirlo a un formato legible por humanos ayuda a los desarrolladores a depurar problemas de rendimiento con aplicaciones Java.

jfr print subcomando

Use jfr print para imprimir el contenido de un archivo de grabación de vuelo en la salida estándar.

La sintaxis es:

jfr print [--xml|--json|--exact] [--categories <filtros>] [--events <filtros>] [--stack-depth <profundidad>] <archivo>

donde:

--xml
Imprime la grabación en formato XML.
--json
Imprime la grabación en formato JSON.
--exact
Imprime números y marcas de tiempo con formato bonito y precisión completa.
--categories <filtros>
Selecciona eventos que coinciden con un nombre de categoría. El filtro es una lista separada por comas de nombres, simples y/o calificados, y/o patrones glob entre comillas.
--events <filtros>
Selecciona eventos que coinciden con un nombre de evento. El filtro es una lista separada por comas de nombres, simples y/o calificados, y/o patrones glob entre comillas.
--stack-depth <profundidad>
Número de fotogramas en las trazas de pila, por defecto 5.
<archivo>
Ubicación del archivo de grabación (.jfr)

El formato predeterminado para imprimir el contenido del archivo de grabación de vuelo es legible por humanos, a menos que se especifique xml o json. Estas opciones proporcionan una salida legible por máquina que puede ser analizada o procesada por scripts creados por el usuario.

Use jfr --help print para ver ejemplos de uso de filtros.

Para reducir la cantidad de datos mostrados, es posible filtrar eventos o categorías de eventos. El filtro opera sobre el nombre simbólico de un evento, establecido usando la anotación @Name, o el nombre de la categoría, establecido usando la anotación @Category. Si se utilizan varios filtros, se incluirán eventos de ambos filtros. Si no se utiliza ningún filtro, se imprimirán todos los eventos. Si se utiliza una combinación de un filtro de categoría y un filtro de evento, los eventos seleccionados serán la unión de los dos filtros.

Por ejemplo, para mostrar todos los eventos de GC y el evento CPULoad, se podría usar el siguiente comando:

jfr print --categories GC --events CPULoad recording.jfr

Los valores de los eventos se formatean según los tipos de contenido que se utilicen. Por ejemplo, un campo con la anotación jdk.jfr.Percentage que tiene el valor 0.52 se formatea como 52%.

Las trazas de pila se truncan por defecto a 5 fotogramas, pero el número se puede aumentar/disminuir usando la opción de línea de comandos --stack-depth.

jfr view subcomando

Use jfr view para agregar y mostrar datos de eventos en la salida estándar.

La sintaxis es:

jfr view [--verbose] [--width <entero>] [--truncate <modo>] [--cell-height <entero>] <vista> <archivo>

donde:

--verbose
Muestra la consulta que compone la vista.
--width <entero>
El ancho de la vista en caracteres. El valor predeterminado depende de la vista.
--truncate <modo>
Cómo truncar el contenido que excede el espacio en una celda de tabla. El modo puede ser 'beginning' o 'end'. El valor predeterminado es 'end'.
--cell-height <entero>
Número máximo de filas en una celda de tabla. El valor predeterminado depende de la vista.
<vista>
Nombre de la vista o tipo de evento a mostrar. Use jfr --help view para ver una lista de vistas disponibles.
<archivo>
Ubicación del archivo de grabación (.jfr)

El parámetro <vista> puede ser un nombre de tipo de evento. Use jfr view types <archivo> para ver una lista. Para mostrar todas las vistas, use jfr view all-views <archivo>. Para mostrar todos los eventos, use jfr view all-events <archivo>.

subcomando

Use jfr assemble para ensamblar archivos de fragmentos en un archivo de

La información de la grabación de vuelo se escribe en fragmentos. Un fragmento contiene toda la información necesaria para el análisis. Un fragmento típicamente contiene eventos útiles para la resolución de problemas. Si un JVM se bloquea, estos fragmentos pueden recuperarse y usarse para crear un archivo de grabación de vuelo usando este comando jfr assemble. Estos archivos de fragmentos se concatenan en orden cronol

ógico y los archivos de fragmentos que no
están terminados (.part) se excluyen.
