JAVAP(1) Comandos JDK JAVAP(1)

NOMBRE

javap - desensamblar uno o más archivos de clase

SINOPSIS

javap [opciones] clases...

opciones
Especifica las opciones de línea de comandos. Consulte Opciones para javap.
clases
Especifica una o más clases separadas por espacios para ser procesadas para anotaciones. Puede especificar una clase que se puede encontrar en la ruta de clases por su nombre de archivo, URL o por su nombre de clase completamente calificado.

Ejemplos:

ruta/a/MiClase.class

jar:file:///ruta/a/MiJar.jar!/miPaquete/MiClase.class

java.lang.Object

DESCRIPCIÓN

El comando javap desensambla uno o más archivos de clase. La salida depende de las opciones utilizadas. Cuando no se utilizan opciones, el comando javap imprime los campos y métodos protegidos y públicos de las clases que se le pasan.

El comando javap no es consciente de las JAR de múltiples versiones. Usar la forma de ruta de clases del comando resulta en la visualización de la entrada base en todas las JAR, sean de múltiples versiones o no. Usando la forma de URL, puede usar la forma de URL de un argumento para especificar una versión específica de una clase para desensamblar.

El comando javap imprime su salida a stdout.

Nota:

En herramientas que soportan opciones de estilo --, las opciones estilo GNU pueden usar el signo de igual (=) en lugar de un espacio en blanco para separar el nombre de una opción de su valor.

OPCIONES PARA JAVAP

--help, -help , -h, o -?
Imprime un mensaje de ayuda para el comando javap.
-version
Imprime información de la versión.
-verbose o -v
Imprime información adicional sobre la clase seleccionada.
-l
Imprime tablas de líneas y variables locales.
-public
Muestra solo clases y miembros públicos.
-protected
Muestra solo clases y miembros protegidos y públicos.
-package
Muestra clases y miembros de paquete/protegidos/públicos (por defecto).
-private o -p
Muestra todas las clases y miembros.
-c
Imprime el código desensamblado, por ejemplo, las instrucciones que componen los bytecodes de Java, para cada uno de los métodos de la clase.
-s
Imprime las firmas de tipos internos.
-sysinfo
Muestra información del sistema (ruta, tamaño, fecha, hash SHA-256) de la clase que se está procesando.
-verify
Imprime información adicional de verificación de la clase.
-constants
Muestra constantes static final.
--module módulo o -m módulo
Especifica el módulo que contiene las clases a desensamblar.
--module-path ruta
Especifica dónde encontrar los módulos de la aplicación.
--system jdk
Especifica dónde encontrar los módulos del sistema.
--class-path ruta, -classpath ruta, o -cp ruta
Especifica la ruta que el comando javap utiliza para encontrar archivos de clase de usuario. Anula el valor predeterminado o la variable de entorno CLASSPATH cuando está configurada.
-bootclasspath ruta
Anula la ubicación de los archivos de clase de arranque.
--multi-release versión
Especifica la versión a seleccionar en archivos JAR de múltiples versiones.
-Jopción
Pasa la opción especificada a la JVM. Por ejemplo:
javap -J-version
javap -J-Djava.security.manager -J-Djava.security.policy=MyPolicy MiClase

Consulte Descripción general de las opciones de Java en java.

EJEMPLO DE JAVAP

Compile la siguiente clase HelloWorldFrame:

import java.awt.Graphics;
import javax.swing.JFrame;
import javax.swing.JPanel;
public class HelloWorldFrame extends JFrame {
   String message = "Hello World!";
   public HelloWorldFrame(){
        setContentPane(new JPanel(){
            @Override
            protected void paintComponent(Graphics g) {
                g.drawString(message, 15, 30);
            }
        });
        setSize(100, 100);
    }
    public static void main(String[] args) {
        HelloWorldFrame frame = new HelloWorldFrame();
        frame.setVisible(true);
    }
}

La salida del comando javap HelloWorldFrame.class produce lo siguiente:
