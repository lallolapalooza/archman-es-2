DESCRIPCIÓ

N

El comando jdeps muestra las dependencias a nivel de paquete o a nivel de clase de los archivos de clases Java. La clase de entrada puede ser un nombre de ruta a un archivo .class, un directorio, un archivo JAR, o puede ser un nombre de clase completamente calificado para analizar todos los archivos de clase. Las opciones determinan la salida. Por defecto, jdeps emite las dependencias a la salida del sistema. Puede generar las dependencias en lenguaje DOT (vea la opción -do

tout
put).
