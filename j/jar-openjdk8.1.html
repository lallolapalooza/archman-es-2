NOMBRE

jar - Manipula archivos JAR (Java Archive).

SINOPSIS

Crear archivo JAR

jar c[efmMnv0] [punto-de-entrada] [archivo-jar] [manifiesto] [-C dir] archivo ... [-Jopción ...] [@archivo-de-argumentos ...]

Actualizar archivo JAR

jar u[efmMnv0] [punto-de-entrada] [archivo-jar] [manifiesto] [-C dir] archivo ... [-Jopción ...] [@archivo-de-argumentos ...]

Extraer archivo JAR

jar x[vf] [archivo-jar] archivo ... [-Jopción ...] [@archivo-de-argumentos ...]

Listar contenido de archivo JAR

jar t[vf] [archivo-jar] archivo ... [-Jopción ...] [@archivo-de-argumentos ...]

Añadir índice a archivo JAR

jar i archivo-jar [-Jopción ...] [@archivo-de-argumentos ...]

DESCRIPCIÓN

El comando jar es una herramienta de archivo y compresión de propósito general, basada en el formato de compresión ZIP y ZLIB. Sin embargo, el comando jar fue diseñado principalmente para empaquetar applets o aplicaciones Java en un solo archivo. Cuando los componentes de un applet o aplicación (archivos, imágenes y sonidos) se combinan en un solo archivo, pueden ser descargados por un agente Java (como un navegador) en una única transacción HTTP, en lugar de requerir una nueva conexión para cada pieza. Esto mejora drásticamente los tiempos de descarga. El comando jar también comprime archivos, lo que mejora aún más el tiempo de descarga. El comando jar también permite que las entradas individuales en un archivo sean firmadas por el autor del applet para que su origen pueda ser autenticado. Un archivo JAR puede ser utilizado como una entrada en la ruta de clases (classpath), ya sea comprimido o no.

La sintaxis del comando jar se asemeja a la sintaxis del comando tar. Tiene varios modos de operación, definidos por uno de los argumentos de operación obligatorios. Otros argumentos son bien opciones que modifican el comportamiento de la operación, o operandos requeridos para realizar la operación.

ARGUMENTOS DE OPERACIÓN

Al usar el comando jar, debes seleccionar una operación a realizar especificando uno de los siguientes argumentos de operación. Puedes mezclarlos con otras opciones de una sola letra en la línea de comandos, pero usualmente el argumento de operación es el primer argumento especificado.

c
Crear un nuevo archivo JAR.
i
Generar información de índice para un archivo JAR.
t
Listar el contenido de un archivo JAR.
u
Actualizar un archivo JAR.
x
Extraer archivos de un archivo JAR.

OPCIONES

Utiliza las siguientes opciones para personalizar cómo se crea, actualiza, extrae o visualiza el archivo JAR:

e
Establece la clase especificada por el operando punto-de-entrada como el punto de entrada para una aplicación Java independiente empaquetada en un archivo JAR ejecutable. El uso de esta opción crea o sobrescribe el valor del atributo Main-Class en el archivo de manifiesto. La opción e puede ser utilizada al crear (c) o actualizar (u) el archivo JAR.

Por ejemplo, el siguiente comando crea el archivo Main.jar con el archivo Main.class donde el valor del atributo Main-Class en el manifiesto se establece en Main:

jar cfe Main.jar Main Main.class

El Entorno de Ejecución Java (JRE) puede llamar directamente a esta aplicación ejecutando el siguiente comando:

java -jar Main.jar

Si el nombre de la clase de punto de entrada está en un paquete, entonces puede usar el punto (.) o la barra (/) como delimitador. Por ejemplo, si Main.class está en un paquete llamado mydir, entonces el punto de entrada puede especificarse de una de las siguientes maneras:

jar -cfe Main.jar mydir/Main mydir/Main.class
jar -cfe Main.jar mydir.Main mydir/Main.class

Nota

Especificar juntas las opciones m y e cuando un manifiesto particular también contiene el atributo Main-Class resulta en una especificación ambigua de Main-Class. La ambigüedad lleva a un error y la operación de creación o actualización del comando jar se termina.

f
Establece el archivo especificado por el operando archivo-jar como el nombre del archivo JAR que se crea (c), actualiza (u), extrae (x) o visualiza (t). Omitir la opción f y el operando archivo-jar instruye al comando jar a aceptar el nombre del archivo JAR desde stdin (para x y t) o enviar el archivo JAR a stdout (para c y u).
m
Incluye nombres y valores de atributos del archivo especificado por el operando manifiesto en el archivo de manifiesto del comando jar (ubicado en el archivo en META-INF/MANIFEST.MF). El comando jar añade el nombre y valor del atributo al archivo JAR a menos que ya exista una entrada con el mismo nombre, en cuyo caso el comando jar actualiza el valor del atributo. La opción m puede ser utilizada al crear (c) o actualizar (u) el archivo JAR.

Puedes añadir pares de atributos de nombre-valor especiales al manifiesto que no estén contenidos en el archivo de manifiesto por defecto. Por ejemplo, puedes añadir atributos que especifiquen información del vendedor, información de lanzamiento, sellado de paquetes, o para hacer ejecutables las aplicaciones empaquetadas en JAR. Para ejemplos de uso de la opción m, ver Empaquetado de Programas en http://docs.oracle.com/javase/tutorial/deployment/jar/index.html

M
No crea una entrada de archivo de manifiesto (para c y u), o elimina una entrada de archivo de manifiesto cuando existe (para u). La opción M puede ser utilizada al crear (c) o actualizar (u) el archivo JAR.
n
Al crear (c) un archivo JAR, esta opción normaliza el archivo para que el contenido no se vea afectado por las operaciones de empaquetado y desempaquetado del comando pack200(1). Sin esta normalización, la firma de un JAR firmado puede volverse inválida.
v
Genera salida detallada a la salida estándar. Ver Ejemplos.
0
(Cero) Crea (c) o actualiza (u) el archivo JAR sin usar compresión ZIP.
-C dir

Al crear (c) o actualizar (u) un archivo JAR, esta opción cambia temporalmente el directorio mientras procesa los archivos especificados por los operandos archivo. Su operación está pensada para ser similar a la opción -C de la utilidad tar de UNIX. Por ejemplo, el siguiente comando cambia al directorio classes y añade el archivo Bar.class desde ese directorio a my.jar: 
jar uf my.jar -C classes Bar.class

El siguiente comando cambia al directorio classes y añade a my.jar todos los archivos dentro del directorio classes (sin crear un directorio classes en el archivo JAR), luego regresa al directorio original antes de cambiar al directorio bin para añadir Xyz.class a my.jar.

jar uf my.jar -C classes . -C bin Xyz.class

Si classes contenía los archivos bar1 y bar2, entonces el archivo JAR contendrá lo siguiente después de ejecutar el comando anterior:
