JACK-STDOUT(1) Manual de comandos generales JACK-STDOUT(1)

NOMBRE

jack-stdout - escribir datos de audio JACK a stdout

SINOPSIS

jack-stdout [OPCIONES] puerto1 [ puerto2 ...]

DESCRIPCIÓN

jack-stdout captura audio de JACK y escribe datos crudos a salida estándar.

El número de puertos dados determina el número de canales de audio que se utilizan. Si se da más de un canal, los datos de muestras de audio se intercalarán.

OPCIONES

-b, --bitdepth BITS
Especifica la profundidad de bits de cada muestra. Para codificación de enteros, pueden ser 16 o 24. El valor predeterminado es 16. Esta configuración solo se utiliza para codificación de enteros: las muestras de punto flotante siempre tendrán 32 bits de ancho.
-d, --duration SEG
Especifica el tiempo durante el cual se ejecutará jack-stdout en segundos. Un valor menor que 1 significa que se ejecutará indefinidamente. El valor predeterminado es 0.
-e, --encoding FORMATO
Establece el formato de salida de los datos: entero con signo, entero sin signo, punto flotante (predeterminado: con signo)
-n, --name NOMBRECLIENTE
Establece el nombre del cliente JACK (predeterminado: jstdout)
-h, --help
Imprime una breve información de uso
-L, --little-endian
Escribe datos little-endian o punto flotante en orden de bytes nativo (este es el valor predeterminado)
-B, --big-endian
Escribe datos big-endian o intercambia el orden de bytes de punto flotante
-q, --quiet
Inhibe la salida habitual. Esto afecta a la información y a las advertencias de desbordamiento de búfer, pero no a los errores de configuración.
-S, --bufsize MUESTRAS
Elige el tamaño del búfer interno en muestras. El tamaño predeterminado es 65536. El valor dado se multiplicará por el número de canales y la profundidad de bits para obtener el tamaño del búfer circular.

EJEMPLOS

  jack-stdout xmms_0:out_1 xmms_0:out_2 \
  | mono  ~/Desktop/Downloads/JustePort.exe - 10.0.1.6 0
  jack-stdout -b 24 -e unsigned -B system:capture_1 system:capture_2 \
  | sox -t raw -r 48k -e unsigned -b 24 -B -c 2 - /tmp/recording.wav
  jack-stdout system:capture_1 system:capture_2 \
  | oggenc -r -R 48000 -B 16 -C 2 - \
  > /tmp/recording.ogg
  jack-stdout system:capture_1 \
  | oggenc -r -R 48000 -B 16 -C 1 - \
  | oggfwd -p -n "mi transmisión en vivo" localhost 5900 hackme live.ogg
