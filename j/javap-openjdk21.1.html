JAVAP(1) Comandos del JDK JAVAP(1)

NOMBRE

javap - desensambla uno o más archivos de clase

SINOPSIS

javap [opciones] clases...

opciones
Especifica las opciones de la línea de comandos. Vea Opciones para javap.
clases
Especifica una o más clases separadas por espacios que serán procesadas para anotaciones. Puede especificar una clase que se encuentre en la ruta de clases por su nombre de archivo, URL, o por su nombre de clase completamente calificado.

Ejemplos:

ruta/a/MiClase.class

jar:file:///ruta/a/MiJar.jar!/mipkg/MiClase.class

java.lang.Object

DESCRIPCIÓN

El comando javap desensambla uno o más archivos de clase. La salida depende de las opciones utilizadas. Cuando no se usan opciones, el comando javap imprime los campos y métodos protegidos y públicos de las clases pasadas a él.

El comando javap no es consciente de los JAR multiversión. Usar la forma de ruta de clases del comando resulta en ver la entrada base en todos los archivos JAR, multiversión o no. Usando la forma de URL, puede usar la forma de URL de un argumento para especificar una versión específica de una clase a desensamblar.

El comando javap imprime su salida en stdout.

Nota:

En herramientas que soportan opciones con estilo --, las opciones con estilo GNU pueden usar el signo igual (=) en lugar de un espacio en blanco para separar el nombre de una opción de su valor.

OPCIONES PARA JAVAP

--help, -help , -h, o -?
Imprime un mensaje de ayuda para el comando javap.
-version
Imprime información de la versión.
-verbose o -v
Imprime información adicional sobre la clase seleccionada.
-l
Imprime las tablas de líneas y variables locales.
-public
Muestra solo clases y miembros públicos.
-protected
Muestra solo clases y miembros protegidos y públicos.
-package
Muestra clases y miembros de paquete/protected/públicos (por defecto).
-private o -p
Muestra todas las clases y miembros.
-c
Imprime el código desensamblado, por ejemplo, las instrucciones que componen los bytecodes de Java, para cada uno de los métodos en la clase.
-s
Imprime firmas de tipo internas.
-sysinfo
Muestra información del sistema (ruta, tamaño, fecha, hash SHA-256) de la clase que está siendo procesada.
-constants
Muestra constantes static final.
--module módulo o -m módulo
Especifica el módulo que contiene las clases a desensamblar.
--module-path ruta
Especifica dónde encontrar los módulos de la aplicación.
--system jdk
Especifica dónde encontrar los módulos del sistema.
--class-path ruta, -classpath ruta, o -cp ruta
Especifica la ruta que el comando javap usa para encontrar archivos de clase de usuario. Anula la predeterminada o la variable de entorno CLASSPATH cuando está establecida.
-bootclasspath ruta
Anula la ubicación de los archivos de clase de arranque.
--multi-release versión
Especifica la versión a seleccionar en archivos JAR multiversión.
-Jopción
Pasa la opción especificada a la JVM. Por ejemplo:

javap -J-version
javap -J-Djava.security.manager -J-Djava.security.policy=MiPolitica MiNombreDeClase

Vea Descripción general de las opciones de Java en java.

EJEMPLO DE JAVAP

Compile la siguiente clase HelloWorldFrame:


import java.awt.Graphics;
import javax.swing.JFrame;
import javax.swing.JPanel;
public class HelloWorldFrame extends JFrame {
   String message = "Hello World!";
   public HelloWorldFrame(){
        setContentPane(new JPanel(){
            @Override
            protected void paintComponent(Graphics g) {
                g.drawString(message, 15, 30);
            }
        });
        setSize(100, 100);
    }
    public static void main(String[] args) {
        HelloWorldFrame frame = new HelloWorldFrame();
        frame.setVisible(true);
    }
}

NOMBRE

javap - Interfaz de depuración de archivos de clase Java

SINOPSIS

javap [opciones] class

DESCRIPCIÓN

La herramienta javap, o "disassembler" de Java, examina las clases compiladas y muestra la representación de las clases especificadas en la salida estándar. Puede usar javap para ver qué métodos y constantes están en una clase y también para verificar que un archivo.class se esté creando según lo esperado. Por defecto, javap analiza los archivos.class del directorio actual.

La salida de javap es solo información sobre la clase especificada; no analiza los tipos que utiliza, ni los tipos que heredan o implementan. Por ejemplo, si una clase utilizajava.lang.String, javap no mostrará información sobreString; simplemente indicará que la clase usaString.

OPCIONES PARA JAVAP

-b
Emite advertencias sobre bytes de código bytecode que no son válidos. Por defecto, javap omite los bytes de código inválidos.
-c
Descompila el código de bytes de los métodos en la clase especificada a la salida estándar.
-classpath path
Especifica la ruta de búsqueda de archivos de clase. Separe los directorios y archivos.jar con: (en Unix) o; (en Windows).
-extdirs dirs
Especifica un directorio para buscar archivos.jar y.zip que contienen extensiones de la plataforma.
-help
Imprime un mensaje de uso y sale.
-h
Imprime el hash de la firma de la clase, solo para la clase especificada.
-l
Imprime las constantes y el número de línea de las instrucciones de depuración.
-public
Muestra solo los miembros públicos de las clases.
-protected
Muestra miembros protegidos, públicos y de paquete por defecto.
-package
Muestra miembros de paquete, protegidos y públicos por defecto.
-private
Muestra todos los campos y métodos.
-s
Muestra las firmas de los campos y métodos en el formato de firma dejavah.
-verify
Verifica el código de bytes del método especificado.
-v
Imprime información detallada sobre las constantes de campo, métodos y atributos de la clase.-v implica-protected.
