NOMBRE

jose-jwe-dec - Descifra un JWE utilizando los JWK proporcionados

SINOPSIS

jose jwe dec -i JWE [-I CT] -k JWK [-p] [-O PT]

DESCRIPCION

El comando jose jwe dec descifra un JWE utilizando una o más claves JWK (-k) o una contraseña (-p). El descifrado tiene éxito si alguna clave puede realizar el descifrado.

Si el JWE es un JWE separado, es decir, si el texto cifrado se almacena en formato binario externo al JWE, el texto cifrado se puede cargar utilizando el parámetro -I.

Tenga en cuenta que, al especificar la opción -O para emitir el texto plano, la salida del texto plano comienza antes de la validación del texto cifrado. Por lo tanto, debe comprobar el valor de retorno del comando antes de utilizar los datos.

OPCIONES

•-i JSON, --input=JSON : Analiza el JWE desde JSON
•-i ARCHIVO, --input=ARCHIVO : Lee el JWE desde un ARCHIVO
•-i -, --input=- : Lee el JWE desde la entrada estándar
•-I ARCHIVO, --detached=ARCHIVO : Lee el texto cifrado decodificado desde un ARCHIVO
•-I -, --detached=- : Lee el texto cifrado decodificado desde la entrada estándar
•-p, --password : Solicita una contraseña de descifrado, si es necesario
•-k ARCHIVO, --key=ARCHIVO : Lee JWK(Set) desde un ARCHIVO
•-k -, --key=- : Lee JWK(Set) desde la entrada estándar
•-O JSON, --detach=JSON : Analiza el JWE desde JSON
•-O ARCHIVO, --detach=ARCHIVO : Lee el JWE desde un ARCHIVO
•-O -, --detach=- : Lee el JWE desde la entrada estándar

EJEMPLOS

Descifra un JWE con un JWK:

$ jose jwe dec -i msg.jwe -k rsa.key -O msg.txt

Descifra un JWE con una contraseña:

$ jose jwe dec -i msg.jwe -p -O msg.txt
Por favor, introduzca la contraseña de descifrado:

Descifra un JWE con cualquiera de dos JWK:

$ jose jwe dec -i msg.jwe -k ec.jwk -k rsa.jwk -O msg.txt
