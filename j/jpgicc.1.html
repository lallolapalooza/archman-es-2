NOMBRE

jpgicc - aplicador de perfiles ICC de little cms para JPEG.

SINOPSIS

jpgicc [opciones] archivo_entrada.jpg archivo_salida.jpg

DESCRIPCIÓN

lcms es un motor CMM independiente, que se encarga de la gestión del color. Implementa una transformación rápida entre perfiles ICC. jpgicc es un aplicador de perfiles ICC de little cms para JPEG.

OPCIONES

-b
Compensación de punto negro.
-c NUM
Precalcula la transformación (0=Apagado, 1=Normal, 2=Alta resolución, 3=Baja resolución) [predeterminado: 1].
-d NUM
Estado de adaptación del observador (solo col. abs.), (valor flotante 0..1.0) [predeterminado: 0.0].
-e
Incrusta el perfil de destino.
-g
Marca los colores fuera de gama en la simulación de prueba.
-h NUM
Muestra resumen de opciones y ejemplos (0=ayuda, 1=Ejemplos, 2=Perfiles integrados, 3=Información de contacto)
-i perfil
Perfil de entrada (predeterminado: sRGB).
-l enlace
TODO: explicar esta opción.
-m NUM
Intención de simulación de prueba (0,1,2,3) [predeterminado: 0].
-n
Ignora el perfil incrustado.
-o perfil
Perfil de salida (predeterminado: sRGB).
-p perfil
Perfil de simulación de prueba.
-q NUM
Calidad de salida JPEG, (0..100) [predeterminado: 75].
-s nuevoperfil
Guarda el perfil incrustado como nuevoperfil.
-t NUM
Intención de renderizado
0=Perceptual [predeterminado]
1=Colorimétrica relativa
2=Saturación
3=Colorimétrica absoluta
10=Perceptual preservando tinta negra
11=Colorimétrica relativa preservando tinta negra
12=Saturación preservando tinta negra
13=Perceptual preservando plano negro
14=Colorimétrica relativa preservando plano negro
15=Saturación preservando plano negro
-v
Modo detallado.
-! NUM,NUM,NUM
Valores del canal marcador de fuera de gama (r,g,b) [predeterminado: 128,128,128].

PERFILES INTEGRADOS

*Lab2  -- CIEL*a*b basado en D50 v2
*Lab4  -- CIEL*a*b basado en D50 v4
*Lab   -- CIEL*a*b basado en D50 v4
*XYZ   -- CIE XYZ (PCS)
*sRGB  -- Espacio de color sRGB
*Gray22 - Monocromo de Gamma 2.2
*Gray30 - Monocromo de Gamma 3.0
*null   - Negro monocromo para toda la entrada
*Lin2222- Linealización CMYK de gamma 2.2 en cada canal

EJEMPLOS

Para corrección de color de escáner a sRGB:
	jpgicc -iscanner.icm in.jpg out.jpg
Para convertir de monitor1 a monitor2:
	jpgicc -imon1.icm -omon2.icm in.jpg out.jpg
Para hacer una separación CMYK:
	jpgicc -oprinter.icm inrgb.jpg outcmyk.jpg
Para recuperar sRGB de una separación CMYK:
	jpgicc -iprinter.icm incmyk.jpg outrgb.jpg
Para convertir de JPEG CIELab ITU/Fax a sRGB
	jpgicc -iitufax.icm in.jpg out.jpg
Para convertir de JPEG CIELab ITU/Fax a sRGB
	jpgicc in.jpg out.jpg
