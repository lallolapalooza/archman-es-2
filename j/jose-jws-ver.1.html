NOMBRE

jose-jws-ver - Verifica un JWS utilizando los JWKs proporcionados

SINOPSIS

jose jws ver -i JWS [-I PAY] -k JWK [-a] [-O PAY]

DESCRIPCIÓN GENERAL

El comando jose jws ver verifica una firma sobre una carga útil utilizando uno o más JWKs. Al especificar más de un JWK (-k), el programa tendrá éxito cuando cualquiera de los JWKs proporcionados verifique con éxito una firma. Alternativamente, si se proporciona la opción -a, el programa tendrá éxito solo cuando todos los JWKs verifiquen con éxito una firma.

Si el JWS es un JWS separado (detached), lo que significa que la carga útil se almacena en formato binario externo al propio JWS, la carga útil se puede cargar utilizando el parámetro -I.

Tenga en cuenta que, al especificar la opción -O para generar la carga útil, esta se genera independientemente de si la firma es válida o no. Por lo tanto, debe verificar el valor de retorno del comando antes de confiar en los datos.

OPCIONES

•-i JSON, --input=JSON : Analiza el JWS a partir de JSON
•-i ARCHIVO, --input=ARCHIVO : Lee el JWS desde ARCHIVO
•-i -, --input=- : Lee el JWS desde la entrada estándar
•-I ARCHIVO, --detached=ARCHIVO : Lee la carga útil decodificada desde ARCHIVO
•-I -, --detached=- : Lee la carga útil decodificada desde la entrada estándar
•-k ARCHIVO, --key=ARCHIVO : Lee JWK(Set) desde ARCHIVO
•-k -, --key=- : Lee JWK(Set) desde la entrada estándar
•-O ARCHIVO, --detach=ARCHIVO : Decodifica la carga útil a ARCHIVO
•-O -, --detach=- : Decodifica la carga útil a la salida estándar
•-a, --all : Asegura que el JWS se valide con todas las claves

EJEMPLOS

Verificar un JWS regular y generar la carga útil:

$ jose jws ver -i msg.jws -k key.jwk -O msg.txt

Verificar un JWS separado sin generar la carga útil:

$ jose jws ver -i msg.jws -I msg.txt -k key.jwk

Asegurar que un JWS está firmado con todas las claves especificadas:

$ jose jws ver -i msg.jws -k ec.jwk -k rsa.jwk -a
