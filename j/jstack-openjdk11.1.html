jstack(1) Herramientas de solución de problemas jstack(1)

NOMBRE

jstack - Imprime rastros de pila de hilos Java para un proceso Java, un archivo core o un servidor de depuración remoto. Este comando es experimental y no es compatible.

SINOPSIS

jstack [ opciones ] pid 
jstack [ opciones ] ejecutable core
jstack [ opciones ] [ id-servidor@ ] nombre-host-o-IP-remoto
opciones
Las opciones de la línea de comandos. Ver Opciones.
pid
El ID del proceso para el cual se imprime el rastro de pila. El proceso debe ser un proceso Java. Para obtener una lista de procesos Java en ejecución en una máquina, use el comando jps(1).
ejecutable
El ejecutable Java a partir del cual se produjo el volcado de núcleo.
core
El archivo core para el cual se debe imprimir el rastro de pila.
nombre-host-o-IP-remoto
El nombre de host o la dirección IP del servidor de depuración remoto. Ver jsadebugd(1).
id-servidor
Un ID único opcional para usar cuando varios servidores de depuración se ejecutan en el mismo host remoto.

DESCRIPCIÓN

El comando jstack imprime rastros de pila Java de hilos Java para un proceso Java, archivo core o servidor de depuración remoto especificado. Para cada marco Java, se imprime el nombre completo de la clase, el nombre del método, el índice de bytes (BCI) y el número de línea, cuando están disponibles. Con la opción -m, el comando jstack imprime marcos Java y nativos de todos los hilos con el contador de programa (PC). Para cada marco nativo, se imprime el símbolo nativo más cercano a PC, cuando está disponible. Los nombres con nombres ofuscados de C++ no se desofuscan. Para desofuscar nombres de C++, la salida de este comando puede canalizarse a c++filt. Cuando el proceso especificado se está ejecutando en una Máquina Virtual Java de 64 bits, es posible que deba especificar la opción -J-d64, por ejemplo: jstack -J-d64 -m pid.

Nota: Esta utilidad no es compatible y puede no estar disponible en futuras versiones de JDK. En sistemas Windows donde el archivo dbgeng.dll no está presente, las Herramientas de Depuración para Windows deben estar instaladas para que estas herramientas funcionen. La variable de entorno PATH debe contener la ubicación de jvm.dll que utiliza el proceso de destino, o la ubicación desde la que se produjo el archivo de volcado de bloqueo. Por ejemplo:

set PATH=<jdk>\jre\bin\client;%PATH%

OPCIONES

-F

Fuerza un volcado de pila cuando jstack [-l] pid no responde.
-l

Listado largo. Imprime información adicional sobre bloqueos, como una lista de sincronizadores poseíbles de java.util.concurrent. Ver la descripción de la clase AbstractOwnableSynchronizer en http://docs.oracle.com/javase/8/docs/api/java/util/concurrent/locks/AbstractOwnableSynchronizer.html
-m

Imprime un rastro de pila en modo mixto que tiene marcos Java y C/C++ nativos.
-h

Imprime un mensaje de ayuda.
-help

Imprime un mensaje de ayuda.

BUGS CONOCIDOS

En el rastro de pila en modo mixto, la opción -m no funciona con el servidor de depuración remoto.
