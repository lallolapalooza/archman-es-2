JSON2STEMS(1) Conversión de tipo de archivo JSON2STEMS(1)

NOMBRE

json2stems - Conversión de Verilator JSON a stems de rtlbrowse.

SINTAXIS

json2stems METAFILEENTRADA ARBOLFILEENTRADA FILEASALIDA

DESCRIPCIÓN

Convierte la representación AST JSON de Verilator a un archivo stems para su uso con rtlbrowse. Está destinado a reemplazar al obsoleto xml2stems(1), y en el futuro, las características avanzadas de la herramienta pueden utilizar datos adicionales proporcionados por el AST de Verilator.

EJEMPLOS

La siguiente es una cadena de comandos para compilar Verilog y luego abrir gtkwave y rtlbrowse juntos para la anotación del código fuente. Esto asume que el archivo des.fst ya se generó a partir de una simulación anterior.

verilator -Wno-fatal des.v -json-only --bbox-sys
json2stems obj_dir/Vdes.tree.meta.json obj_dir/Vdes.tree.json des.stems
gtkwave -t des.stems des.fst
