NOMBRE

jack_transport - cliente del toolkit JACK para el control del transporte

SINOPSIS

jack_transport

DESCRIPCIÓN

jack_transport es un cliente del toolkit para el JACK Audio Connection Kit. Proporciona control desde la línea de comandos sobre el sistema de transporte JACK. Escribe help en el prompt de comandos de jack_transport para ver los comandos disponibles.
