Descripción detallada

Claves Web JSON (RFC 7517)

Una Clave Web JSON (JWS) es un formato de datos estándar para expresar claves criptográficas en JSON.

Ver también:

https://tools.ietf.org/html/rfc7517

https://tools.ietf.org/html/rfc7638

Documentación de funciones

bool jose_jwk_gen (jose_cfg_t * cfg, json_t * jwk)

Genera una nueva JWK. La JWK se genera utilizando pistas de la entrada exactamente en el mismo formato en que se encontraría en la salida. Por ejemplo, la forma más común de generar una clave es especificar el algoritmo con el que desea utilizar la clave. Por ejemplo (manejo de errores omitido):

json_t *gen(void) {
    json_auto_t *jwk = json_pack("{s:s}", "alg", "ES256");
    jose_jwk_gen(NULL, jwk);
    return json_incref(jwk);
}

Se prefiere este método porque otros metadatos pueden inferirse del nombre del algoritmo, como el uso de la clave. Además, los metadatos del algoritmo se pueden utilizar para generar automáticamente encabezados correctos al crear firmas (JWS) o cifrados (JWE). Por lo tanto, siempre debe optar por crear claves por su uso de algoritmo.

Sin embargo, si sus requisitos difieren, también puede generar una clave utilizando parámetros crudos (de nuevo, manejo de errores omitido):

json_t *gen(void) {
    json_auto_t *jwk = json_pack("{s:s,s:s}", "kty", "EC", "crv", "P-256");
    jose_jwk_gen(NULL, jwk);
    return json_incref(jwk);
}
json_t *gen(void) {
    json_auto_t *jwk = json_pack("{s:s,s:i}", "kty", "RSA", "bits", 2048);
    jose_jwk_gen(NULL, jwk);
    return json_incref(jwk);
}
json_t *gen(void) {
    json_auto_t *jwk = json_pack("{s:s,s:i}", "kty", "oct", "bytes", 32);
    jose_jwk_gen(NULL, jwk);
    return json_incref(jwk);
}

En este caso, 'bits' y 'bytes' se eliminarán de la salida final.

Ver también:

https://www.iana.org/assignments/jose/jose.xhtml#web-signature-encryption-algorithms

Parámetros:

cfg El contexto de configuración (opcional).
jwk La JWK a generar.

Devuelve:

En caso de éxito, verdadero. De lo contrario, falso.

bool jose_jwk_pub (jose_cfg_t * cfg, json_t * jwk)

Elimina todo el material de clave privada de una JWK. Además, esta función eliminará cualquier operación de clave de la propiedad JWK key_ops (si está presente) que solo se aplique a la clave privada.

Esta función debe usarse antes de exportar claves a terceros.

Parámetros:

cfg El contexto de configuración (opcional).
jwk La JWK de la que eliminar claves privadas.

Devuelve:

En caso de éxito, verdadero. De lo contrario, falso.

bool jose_jwk_prm (jose_cfg_t * cfg, const json_t * jwk, bool req, const char * op)

Determina si una operación está permitida para una JWK. La operación a confirmar (op) siempre se especifica de acuerdo con la sintaxis de la propiedad JWK 'key_ops', incluso cuando la propiedad 'use' está definida en la JWK.

Esta función tiene dos modos de operación. Si req es falso, las JWK que no tienen metadatos de uso de clave serán aprobadas para esta operación. Sin embargo, si req es verdadero, estos metadatos serán requeridos para la aprobación.

Parámetros:

cfg El contexto de configuración (opcional).
jwk La JWK de la que eliminar claves privadas.
req Si los metadatos de uso de clave de la JWK son requeridos o no.
op La operación para la que se busca aprobación.

Devuelve:

Cuando la JWK es aprobada, verdadero. De lo contrario, falso.

json_t* jose_jwk_thp (jose_cfg_t * cfg, const json_t * jwk, const char * alg)

Calcula la huella digital de una JWK como una cadena JSON codificada en Base64 segura para URL. Esta función es un simple envoltorio para jose_jwk_thp_buf().

Ver también:

jose_jwk_thp_buf()

Parámetros:

cfg El contexto de configuración (opcional).
jwk La JWK para la que calcular la huella digital.
alg El algoritmo hash a usar.

Devuelve:

En caso de éxito, una cadena JSON recién asignada. De lo contrario, NULL.

size_t jose_jwk_thp_buf (jose_cfg_t * cfg, const json_t * jwk, const char * alg, uint8_t * thp, size_t len)

Calcula la huella digital de una JWK. Esta función calcula la huella digital de una JWK de acuerdo con el método definido por RFC 7638.

Si thp es NULL, esta función devuelve el tamaño del búfer requerido para la salida de la huella digital.

Ver también:

https://tools.ietf.org/html/rfc7638

Parámetros:

cfg El contexto de configuración (opcional).
jwk La JWK para la que calcular la huella digital.
alg El algoritmo hash a usar.
thp El búfer de hash de salida.
len El tamaño del búfer de hash de salida.

Devuelve:

En caso de éxito, el número de bytes escritos. De lo contrario, SIZE_MAX.

json_t* jose_jwk_exc (jose_cfg_t * cfg, const json_t * prv, const json_t * pub)

Realiza un intercambio de claves. El único algoritmo actualmente implementado es ECDH.

Parámetros:

cfg El contexto de configuración (opcional).
prv La JWK privada.
pub La JWK pública.

Devuelve:

En caso de éxito, el JWK resultante del intercambio de claves. De lo contrario, NULL.
