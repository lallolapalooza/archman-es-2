j0(3) Manual de funciones de biblioteca j0(3)

NOMBRE

j0, j0f, j0l, j1, j1f, j1l, jn, jnf, jnl - funciones de Bessel de primer tipo

BIBLIOTECA

Biblioteca matemática (libm, -lm)

SINOPSIS

#include <math.h>
double j0(double x);
double j1(double x);
double jn(int n, double x);
float j0f(float x);
float j1f(float x);
float jnf(int n, float x);
long double j0l(long double x);
long double j1l(long double x);
long double jnl(int n, long double x);
Requisitos de macro de prueba de características para glibc (ver feature_test_macros(7)):

j0(), j1(), jn():

    _XOPEN_SOURCE
        || /* Desde glibc 2.19: */ _DEFAULT_SOURCE
        || /* glibc <= 2.19: */ _SVID_SOURCE || _BSD_SOURCE

j0f(), j0l(), j1f(), j1l(), jnf(), jnl():

    _XOPEN_SOURCE >= 600
        || (_ISOC99_SOURCE && _XOPEN_SOURCE)
        || /* Desde glibc 2.19: */ _DEFAULT_SOURCE
        || /* glibc <= 2.19: */ _SVID_SOURCE || _BSD_SOURCE

DESCRIPCIÓN

Las funciones j0() y j1() devuelven funciones de Bessel de x de primer tipo de órdenes 0 y 1, respectivamente. La función jn() devuelve la función de Bessel de x de primer tipo de orden n.

Las funciones j0f(), j1f() y jnf() son versiones que toman y devuelven valores float. Las funciones j0l(), j1l() y jnl() son versiones que toman y devuelven valores long double.

VALOR DE RETORNO

En caso de éxito, estas funciones devuelven el valor de Bessel apropiado de primer tipo para x.

Si x es un NaN, se devuelve un NaN.

Si x es demasiado grande en magnitud, o el resultado sufre un desbordamiento inferior, ocurre un error de rango y el valor de retorno es 0.

ERRORES

Ver math_error(7) para obtener información sobre cómo determinar si ha ocurrido un error al llamar a estas funciones.

Los siguientes errores pueden ocurrir:

Error de rango: desbordamiento inferior del resultado o x es demasiado grande en magnitud
errno se establece en ERANGE.

Estas funciones no generan excepciones para fetestexcept(3).

BUGS

Hay errores de hasta 2e-16 en los valores devueltos por j0(), j1() y jn() para valores de x entre -8 y 8.
