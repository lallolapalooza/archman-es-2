JALV(1) Manual de Comandos Generales JALV(1)

NOMBRE

jalv - Ejecuta un plugin LV2 como una aplicación JACK (versión de consola).

SINOPSIS

jalv [OPCIÓN]... URI_DEL_PLUGIN

OPCIONES

-b TAMAÑO
Tamaño del buffer para la comunicación plugin <=> UI.
-c SYM=VAL
Establecer valor de control (ej. "vol=1.4").
-d
Volcar la comunicación plugin <=> UI.
-U URI
Cargar la UI con la URI dada.
-h
Imprimir las opciones de la línea de comandos.
-i
Ignorar la entrada en stdin (para uso en segundo plano).
-l DIRECTORIO
Cargar estado desde el directorio de estado.
-n NOMBRE
Nombre del cliente Jack
-p
Imprimir cambios de control de salida a stdout.
-s
Mostrar la UI del plugin si es posible.

Esta opción solo funciona cuando los plugins proporcionan una UI que se puede usar a través de la interfaz no incrustable showHide. Para otras UIs incrustables, usa jalv.gtk(1) o jalv.qt(1).

-t
Imprimir mensajes de rastreo del plugin
-x
Usar solo el nombre exacto del cliente Jack, y salir si ya está en uso

COMANDOS

El prompt de Jalv soporta varios comandos para control interactivo:


help Mostrar mensaje de ayuda
controls Imprimir valores de control configurables
monitors Imprimir valores de control de salida
presets Imprimir presets disponibles
preset URI Establecer preset
set ÍNDICE VALOR Establecer valor de control por índice de puerto
set SÍMBOLO VALOR Establecer valor de control por símbolo
SÍMBOLO = VALOR Establecer valor de control por símbolo
