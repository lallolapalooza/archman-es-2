JBOVERDRIVE(1) Comandos de usuario JBOVERDRIVE(1)

NOMBRE

jboverdrive - El emulador de preamplificador/overdrive B

SINOPSIS

jboverdrive [ OPCIONES ]

DESCRIPCIÓN

jboverdrive - el emulador de preamplificador/overdrive B

Utilidad para escribir datos de pico de audio a la salida estándar o a un archivo como texto plano o datos JSON.

OPCIONES

-h, --help
Imprimir texto de ayuda
-i, --input <nombre_puerto>
Conectar al puerto de entrada JACK
-o, --output <nombre_puerto>
Conectar la salida al puerto JACK dado
-p, --parameter <clave=valor>
Especificar parámetro inicial del efecto
-V, --version
Imprimir información de la versión

Los parámetros del efecto son todos valores flotantes 0..1. Las claves disponibles y sus valores predeterminados son los siguientes:

gainin:
Ganancia de entrada = 0.3567
bias:
Bias = 0.87399
feedback:
Retroalimentación = 0.5821
sagtobias:
Sag a Bias = 0.1880
postfeed:
Retroalimentación de postdiferencial = 1.0
globfeed:
Retroalimentación global = 0.5826
gainout:
Ganancia de salida = 0.07873

EJEMPLOS

jboverdrive -i system:capture_1 -o system:playback_1 -p bias=.5 -p feedback=0.9

jboverdrive -i system:capture_1 -o system:playback_1 -O 1234

oscsend localhost 1234 /boverdrive/bias f 0.9

oscsend localhost 1234 /boverdrive/gainout f 0.3

oscsend localhost 1234 /boverdrive/quit
