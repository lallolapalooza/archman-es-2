NOMBRE

jose-jwk-thp - Calcula la huella digital (thumbprint) de JWK

SINOPSIS

jose jwk thp -i JWK [-H ALG] [-o THP]

DESCRIPCIÓN

El comando jose jwk thp calcula la huella digital de uno o más JWKs.

OPCIONES

•-i JSON, --input=JSON : Analiza JWK(Set) desde JSON
•-i FILE, --input=FILE : Lee JWK(Set) desde FILE
•-i -, --input=- : Lee JWK(Set) de la entrada estándar
•-a ALG, --algorithm=ALG : Usa el algoritmo de hash especificado (distingue mayúsculas de minúsculas)
•-a ?, --algorithm=? : Lista los algoritmos de hash disponibles
•-o FILE, --output=FILE : Escribe la(s) huella(s) digital(es) en FILE
•-o -, --output=- : Escribe la(s) huella(s) digital(es) en la entrada estándar
•-f THP, --find=THP : Busca en las claves de entrada la JWK con la huella digital dada

EJEMPLOS

Calcular la huella digital S1 de una clave recién generada:

$ jose jwk gen -i '{"alg":"ES256"}' -a S1 | jose jwk thp -i-
BzmSH6W8a8LlbQ1mD0iBJdYj4x4

Calcular las huellas digitales S256 de un JWKSet que contiene dos claves:

$ jose jwk thp -i keys.jwkset -a S256
6HJwXEuRh8gAkTz4BodEvcEj_KXkgjc-7Qez3d4VNMs
jo_j_O5gqYpKcZKHPp3miTszAeV60MXHvdb_kkjjTWE

Encontrar la clave de entrada con la huella digital dada:

$ jose jwk thp -i keys.jwkset -f HYRNOxxOOHap0amTONoy1bHnS5M -o key.jwk
