JACK_NETSOURCE(1) Manual de Comandos Generales JACK_NETSOURCE(1)

NOMBRE

jack_netsource - Cliente Maestro de Netjack para un esclavo

SINOPSIS

jack_netsource [ -H nombre_host ] [ opciones ]

DESCRIPCIÓN

jack_netsource El lado Maestro de una conexión netjack. Representa el cliente jackd -dnet esclavo en el gráfico de jack maestro. La mayoría de los parámetros de conexión se configuran a través de netsource, y el esclavo se configurará según la opción de línea de comandos dada a jack_netsource.
Netjack permite conexiones de audio de baja latencia sobre redes IP generales. Cuando se usa opus para la compresión, incluso es posible establecer enlaces transatlánticos, con latencias no mucho mayores que el tiempo de ping real.
Pero el caso de uso principal es, por supuesto, una LAN, donde puede lograr una latencia de un período de jack.

OPCIONES

-h este texto de ayuda
-H host esclavo

Nombre del host del JACK esclavo
-o num canales

Número de canales de reproducción de audio
-i num canales

Número de canales de captura de audio
-O num canales

Número de canales de reproducción midi
-I num canales

Número de canales de captura midi
-n periodos

Latencia de red en períodos de JACK
-p puerto

Puerto UDP en el que está escuchando el esclavo
-r puerto de respuesta

Puerto UDP en el que estamos escuchando
-B puerto de enlace

puerto de respuesta, para uso en entornos NAT
-b profundidad_bits

Establecer el transporte para usar 16 bits o 8 bits
-P kbits

Usar codificación Opus con <kbits> por canal
-m mtu

Asumir esta mtu para el enlace
-R N

Redundancia: enviar paquetes N veces.
-e

omitir la conversión de endianness de host a red
-N nombre jack

Reporta un nombre de cliente diferente a jack
-s, --server nombre_servidor

Conectar al servidor jack llamado nombre_servidor
-h, --help

Mostrar el mensaje de ayuda/uso
-v, --version

Mostrar información de versión y salir

EJEMPLOS

ejecutar un enlace bidireccional de 4 canales de audio con un período de latencia y sin canales midi. Los datos de audio fluyen sin comprimir por el cable:
En hostA:

jackd -d alsa
jack_netsource -H hostB -n1 -i4 -o4 -I0 -O0

En hostB:

jackd -d net
