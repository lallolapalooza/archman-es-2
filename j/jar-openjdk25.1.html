JAR(1) Comandos JDK JAR(1)

NOMBRE

jar - crea un archivo para clases y recursos, y manipula o restaura clases o recursos individuales de un archivo

SINOPSIS

jar [OPCIÓN ...] [ [--release VERSIÓN] [-C dir] archivos] ...

DESCRIPCIÓN

El comando jar es una herramienta de archivado y compresión de propósito general, basada en los formatos de compresión ZIP y ZLIB. Inicialmente, el comando jar fue diseñado para empaquetar applets (no soportados desde JDK 11) o aplicaciones Java; sin embargo, a partir de JDK 9, los usuarios pueden usar el comando jar para crear JARs modulares. Para transporte y despliegue, suele ser más conveniente empaquetar módulos como JARs modulares.

La sintaxis del comando jar se asemeja a la sintaxis del comando tar. Tiene varios modos de operación principales, definidos por uno de los argumentos de operación obligatorios. Otros argumentos son opciones que modifican el comportamiento de la operación o son necesarios para realizar la operación.

Cuando los módulos o los componentes de una aplicación (archivos, imágenes y sonidos) se combinan en un solo archivo, pueden ser descargados por un agente Java (como un navegador) en una única transacción HTTP, en lugar de requerir una nueva conexión para cada pieza. Esto mejora drásticamente los tiempos de descarga. El comando jar también comprime los archivos, lo que mejora aún más el tiempo de descarga. El comando jar también permite firmar entradas individuales en un archivo para que su origen pueda ser autenticado. Un archivo JAR puede ser utilizado como una entrada de ruta de clase, independientemente de si está comprimido o no.

Un archivo se convierte en un JAR modular cuando se incluye un descriptor de módulo, module-info.class, en la raíz de los directorios dados o en la raíz del archivo .jar. Las siguientes operaciones descritas en Modificadores de Operación Válidos Solo en Modos de Creación y Actualización son válidas solo al crear o actualizar un JAR modular o actualizar un JAR no modular existente:

•
--module-version
•
--hash-modules
•
--module-path

Nota:

Todos los argumentos obligatorios u opcionales para las opciones largas son también obligatorios u opcionales para cualquier opción corta correspondiente.

MODOS DE OPERACIÓN PRINCIPALES

Al usar el comando jar, debe especificar la operación que desea realizar. Especifica el modo de operación para el comando jar incluyendo los argumentos de operación correspondientes descritos en esta sección. Puede mezclar un argumento de operación con otras opciones de una sola letra. Generalmente, el argumento de operación es el primer argumento especificado en la línea de comandos.

-c o --create
Crea el archivo.
-i ARCHIVO o --generate-index=ARCHIVO
Genera información de índice para el archivo JAR especificado. Esta opción está obsoleta y puede ser eliminada en una futura versión.
-t o --list
Lista la tabla de contenidos del archivo.
-u o --update
Actualiza un archivo JAR existente.
-x o --extract
Extrae los archivos nombrados (o todos) del archivo. Si un archivo con el mismo nombre aparece más de una vez en el archivo, cada copia será extraída, y las copias posteriores sobrescribirán (reemplazarán) a las anteriores a menos que se especifique -k.
-d o --describe-module
Imprime el descriptor del módulo o el nombre del módulo automático.
--validate
Valida el contenido del archivo JAR. Consulte la sección Integridad de un Archivo JAR más abajo para más detalles.

MODIFICADORES DE OPERACIÓN VÁLIDOS EN CUALQUIER MODO

Puede usar las siguientes opciones para personalizar las acciones de cualquier modo de operación incluido en el comando jar.

-C DIR
Cuando se usa con el modo de operación de creación, cambia al directorio especificado e incluye los archivos especificados al final de la línea de comandos.

jar [OPCIÓN ...] [ [--release VERSIÓN] [-C dir] archivos]

Cuando se usa con el modo de operación de extracción, especifica el directorio de destino donde se extraerá el archivo JAR. A diferencia del modo de operación de creación, esta opción solo se puede especificar una vez con el modo de operación de extracción.

-f ARCHIVO o --file=ARCHIVO
Especifica el nombre del archivo de archivado.
--release VERSIÓN
Crea un archivo JAR multiversión. Coloca todos los archivos especificados después de la opción en un directorio versionado del archivo JAR llamado META-INF/versions/VERSIÓN/, donde VERSIÓN debe ser un entero positivo cuyo valor sea 9 o mayor.

En tiempo de ejecución, cuando hay más de una versión de una clase en el JAR, el JDK utilizará la primera que encuentre, buscando inicialmente en el árbol de directorios cuyo número de VERSIÓN coincida con el número de versión principal del JDK. Luego buscará en los directorios con números de VERSIÓN sucesivamente menores y, finalmente, buscará en la raíz del JAR.

-v o --verbose
Envía o imprime salida detallada a la salida estándar.

MODIFICADORES DE OPERACIÓN VÁLIDOS SOLO EN MODOS DE CREACIÓN Y ACTUALIZACIÓN

Puede usar las siguientes opciones para personalizar las acciones de los modos de operación principales de creación y actualización:

-e NOMBRE_CLASE o --main-class=NOMBRE_CLASE
Especifica el punto de entrada de la aplicación para aplicaciones autónomas empaquetadas en un archivo JAR modular o ejecutable.
-m ARCHIVO o --manifest=ARCHIVO
Incluye la información del manifiesto del archivo de manifiesto dado.
-M o --no-manifest
No crea un archivo de manifiesto para las entradas.
--module-version=VERSIÓN
Especifica la versión del módulo al crear o actualizar un archivo JAR modular, o al actualizar un archivo JAR no modular.
--hash-modules=PATRÓN
Calcula y registra los hashes de los módulos que coinciden con el patrón dado y que dependen directa o indirectamente de un archivo JAR modular que se está creando o de un archivo JAR no modular que se está actualizando.
-p o --module-path
Especifica la ubicación de la dependencia del módulo para generar el hash.
@archivo
Lee las opciones de jar y los nombres de archivo de un archivo de texto como si hubieran sido proporcionados en la línea de comandos.

MODIFICADORES DE OPERACIÓN VÁLIDOS SOLO EN CREACIÓN, ACTUALIZACIÓN Y GENERACIÓN-

Puede usar las siguientes opciones para personalizar las acciones de los modos de operación principales de creación, actualización y generación de índices:

-k o --skip-nested
No extrae archivos anidados. Si se especifica esta opción, cuando se extrae un archivo ZIP que contiene otros archivos ZIP, los archivos ZIP anidados no se extraen.
-H or --no-hash-in-manifest
No añade información de hash a la entrada de manifiesto.

EJEMPLOS

Crear un archivo jar llamado mi_aplicacion.jar que contenga el archivo ClasePrincipal.class y el directorio recursos:

jar cf mi_aplicacion.jar ClasePrincipal.class recursos

Listar el contenido de mi_aplicacion.jar:

jar tf mi_aplicacion.jar

Extraer el contenido de mi_aplicacion.jar al directorio actual:

jar xf mi_aplicacion.jar

Crear un archivo JAR ejecutable que contenga el archivo mi_main.jar y tenga el punto de entrada mi.Main:

jar cfm mi_aplicacion_ejecutable.jar Manifiesto.txt -e mi.Main mi_main.jar
