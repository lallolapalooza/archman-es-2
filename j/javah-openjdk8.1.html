NOMBRE

javah - Genera archivos de cabecera y fuente C a partir de una clase Java.

SINOPSIS

javah [ opciones ] fnombre-completo-de-clase ...
opciones
Las opciones de línea de comandos. Ver Opciones.
nombre-completo-de-clase
La ubicación completa de las clases a convertir en archivos de cabecera y fuente C.

DESCRIPCIÓN

El comando javah genera archivos de cabecera y fuente C que son necesarios para implementar métodos nativos. Los archivos de cabecera y fuente generados son utilizados por programas C para referenciar las variables de instancia de un objeto desde código fuente nativo. El archivo .h contiene una definición de struct con un diseño que paraleliza el diseño de la clase correspondiente. Los campos en el struct corresponden a las variables de instancia en la clase.

El nombre del archivo de cabecera y la estructura declarada dentro de él se derivan del nombre de la clase. Cuando la clase pasada al comando javah está dentro de un paquete, el nombre del paquete se añade al principio de ambos, el nombre del archivo de cabecera y el nombre de la estructura. Se utilizan guiones bajos (_) como delimitadores de nombres.

Por defecto, el comando javah crea un archivo de cabecera para cada clase listada en la línea de comandos y coloca los archivos en el directorio actual. Use la opción -stubs para crear archivos fuente. Use la opción -o para concatenar los resultados de todas las clases listadas en un solo archivo.

La Interfaz Nativa de Java (JNI) no requiere información de cabecera ni archivos stub. El comando javah aún puede ser utilizado para generar prototipos de funciones de métodos nativos necesarios para métodos nativos de estilo JNI. El comando javah produce salida de estilo JNI por defecto y coloca el resultado en el archivo .h.

OPCIONES

-o archivo_salida

Concatena los archivos de cabecera o fuente resultantes para todas las clases listadas en la línea de comandos en un archivo de salida. Solo se puede usar uno de -o o -d.
-d directorio

Establece el directorio donde el comando javah guarda los archivos de cabecera o los archivos stub. Solo se puede usar uno de -d o -o.
-stubs

Hace que el comando javah genere declaraciones C a partir del archivo objeto de Java.
-verbose

Indica salida detallada y hace que el comando javah imprima un mensaje en stdout sobre el estado de los archivos generados.
-help

Imprime un mensaje de ayuda para el uso de javah.
-version

Imprime la información de la versión del comando javah.
-jni

Hace que el comando javah cree un archivo de salida que contenga prototipos de funciones de métodos nativos de estilo JNI. Esta es la salida por defecto; el uso de -jni es opcional.
-classpath ruta

Especifica la ruta que el comando javah utiliza para buscar clases. Anula el valor predeterminado o la variable de entorno CLASSPATH cuando está establecida. Los directorios están separados por dos puntos en Oracle Solaris y por punto y coma en Windows. El formato general para la ruta es:

Oracle Solaris:

.:tu-ruta

Ejemplo: .:/home/avh/clases:/usr/local/java/clases

Windows:

.;tu-ruta

Ejemplo: .;C:\usuarios\dac\clases;C:\herramientas\java\clases

Como una conveniencia especial, un elemento de ruta de clase que contiene un nombre base de * se considera equivalente a especificar una lista de todos los archivos en el directorio con la extensión .jar o .JAR.

Por ejemplo, si el directorio midir contiene a.jar y b.JAR, entonces el elemento de ruta de clase midir/* se expande a A.jar:b.JAR, excepto que el orden de los archivos jar no está especificado. Todos los archivos JAR en el directorio especificado, incluyendo los ocultos, se incluyen en la lista. Una entrada de ruta de clase que consiste en * se expande a una lista de todos los archivos JAR en el directorio actual. La variable de entorno CLASSPATH, donde se define, se expande de manera similar. Cualquier expansión de comodines de ruta de clase ocurre antes de que se inicie la Máquina Virtual Java (JVM). Un programa Java nunca verá comodines sin expandir, excepto al consultar el entorno. Por ejemplo, llamando a System.getenv("CLASSPATH").

-bootclasspath ruta

Especifica la ruta desde la cual cargar las clases de arranque. Por defecto, las clases de arranque son las clases que implementan la plataforma Java central ubicada en jre\lib\rt.jar y varios otros archivos JAR.
-old

Especifica que se deben generar archivos de cabecera al estilo del antiguo JDK 1.0.
-force

Especifica que los archivos de salida siempre deben ser escritos.
-Jopcion

Pasa opcion a la Máquina Virtual Java, donde opcion es una de las opciones descritas en la página de referencia para el lanzador de aplicaciones Java. Por ejemplo, -J-Xms48m establece la memoria de inicio en 48 MB. Ver java(1).
