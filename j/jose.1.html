NOMBRE

jose - Kit de herramientas para realizar la firma y el cifrado de objetos JSON

SINOPSIS

jose alg [-k KIND]

jose b64 dec -i B64 [-O BIN]

jose b64 enc -I BIN [-o B64]

jose jwe dec -i JWE [-I CT] -k JWK [-p] [-O PT]

jose jwe enc [-i JWE] -I PT -k JWK [-p] [-r RCP] [-o JWE] [-O CT] [-c]

jose jwe fmt -i JWE [-I CT] [-o JWE] [-O CT] [-c]

jose jwk exc [-i JWK] -l JWK -r JWK [-o JWK]

jose jwk gen -i JWK [-o JWK]

jose jwk pub -i JWK [-o JWK]

jose jwk thp -i JWK [-a ALG] [-o THP]

jose jwk use -i JWK [-a] [-r] -u OP

jose jws fmt -i JWS [-I PAY] [-o JWS] [-O PAY] [-c]

jose jws sig [-i JWS] [-I PAY] [-s SIG] -k JWK [-o JWS] [-O PAY] [-c]

jose jws ver -i JWS [-I PAY] -k JWK [-O PAY] [-a]

DESCRIPCIÓN

José es una implementación en lenguaje C de los estándares de firma y cifrado de objetos JSON de Javascript. Específicamente, José tiene como objetivo implementar los siguientes estándares:

•RFC 7515 - JSON Web Signature (JWS)
•RFC 7516 - JSON Web Encryption (JWE)
•RFC 7517 - JSON Web Key (JWK)
•RFC 7518 - JSON Web Algorithms (JWA)
•RFC 7519 - JSON Web Token (JWT)
•RFC 7520 - Ejemplos de protección de contenido utilizando JOSE
•RFC 7638 - JSON Web Key (JWK) Thumbprint

La utilidad de línea de comandos José proporciona funcionalidades para lo siguiente:

•Codificación y decodificación de Base64 segura para URL
•Generación y gestión de claves
•Cifrado y descifrado
•Firma y verificación
