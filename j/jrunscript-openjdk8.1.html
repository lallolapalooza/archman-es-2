NOMBRE

jrunscript - Ejecuta un shell de script de línea de comandos que admite modos interactivos y por lotes. Este comando es experimental y no está soportado.

SINOPSIS

jrunscript [opciones] [argumentos]
opciones
Las opciones de línea de comandos. Ver Opciones.
argumentos
Los argumentos, cuando se utilizan, siguen inmediatamente después de las opciones o el nombre del comando. Ver Argumentos.

DESCRIPCIÓN

El comando jrunscript es un shell de script de línea de comandos independiente del lenguaje. El comando jrunscript admite tanto un modo interactivo (leer-evaluar-imprimir) como un modo por lotes (opción -f) de ejecución de scripts. Por defecto, JavaScript es el lenguaje utilizado, pero la opción -l se puede usar para especificar un lenguaje diferente. Al utilizar Java para la comunicación entre lenguajes de script, el comando jrunscript admite un estilo de programación exploratorio.

OPCIONES

-classpath ruta

Indica dónde se encuentran los archivos de clase a los que el script necesita acceder.
-cp ruta

Igual que -classpathruta.
-Dnombre=valor

Establece una propiedad del sistema Java.
-Jindicador

Pasa el indicador directamente a la Máquina Virtual Java donde se ejecuta el comando jrunscript.
-I lenguaje

Utiliza el lenguaje de script especificado. Por defecto, se usa JavaScript. Para usar otros lenguajes de script, debes especificar el archivo JAR del motor de script correspondiente con la opción -cp o -classpath.
-e script

Evalúa el script especificado. Esta opción se puede usar para ejecutar scripts de una sola línea que se especifican completamente en la línea de comandos.
-encoding codificación

Especifica la codificación de caracteres utilizada para leer archivos de script.
-f archivo-script

Evalúa el archivo de script especificado (modo por lotes).
-f -

Lee y evalúa un script de la entrada estándar (modo interactivo).
-help

Muestra un mensaje de ayuda y sale.
-?

Muestra un mensaje de ayuda y sale.
-q

Lista todos los motores de script disponibles y sale.

ARGUMENTOS

Si hay argumentos presentes y no se usa la opción -e o -f, el primer argumento es el archivo de script y el resto de los argumentos, si los hay, se pasan al script. Si se usan argumentos y las opciones -e o -f, todos los argumentos se pasan al script. Si faltan argumentos, -e y -f, se utiliza el modo interactivo. Los argumentos del script están disponibles para un script en una variable del motor llamada arguments de tipo matriz String.

EJEMPLOS

EJECUTAR&#x00A0;ARCHIVO&#x00A0;DE&#x00A0;SCRIPT&#x00A0;CON&#x00A0;ARGUMENTOS&#x00A0;DE&#x00A0;SCRIPT

El archivo test.js es el archivo de script. Los argumentos arg1, arg2 y arg3 se pasan al script. El script puede acceder a estos argumentos con una matriz de argumentos.

jrunscript test.js arg1 arg2 arg3

VER&#x00A0;TAMBIÉN

Si se utiliza JavaScript, antes de evaluar un script definido por el usuario, el comando jrunscript inicializa ciertas funciones y objetos integrados. Estos elementos integrados de JavaScript se documentan en JsDoc-Toolkit en http://code.google.com/p/jsdoc-toolkit/
