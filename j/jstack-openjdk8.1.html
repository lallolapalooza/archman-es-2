jstack(1) Herramientas de resolución de problemas jstack(1)

NOMBRE

jstack - Imprime trazas de pila de hilos de Java para un proceso Java, archivo core o servidor de depuración remoto. Este comando es experimental y no está soportado.

SINOPSIS

jstack [ opciones ] pid 
jstack [ opciones ] ejecutable core
jstack [ opciones ] [ id-servidor@ ] nombre-host-o-IP-remota
opciones
Las opciones de línea de comandos. Ver Opciones.
pid
El ID del proceso para el que se imprime la traza de pila. El proceso debe ser un proceso Java. Para obtener una lista de procesos Java en ejecución en una máquina, utiliza el comando jps(1).
ejecutable
El ejecutable de Java a partir del cual se produjo el volcado core.
core
El archivo core para el que se va a imprimir la traza de pila.
nombre-host-o-IP-remota
El nombre de host o la dirección IP del servidor de depuración remoto. Ver jsadebugd(1).
id-servidor
Un ID único opcional para usar cuando varios servidores de depuración se ejecutan en el mismo host remoto.

DESCRIPCIÓN

El comando jstack imprime trazas de pila de Java de hilos de Java para un proceso Java, archivo core o servidor de depuración remoto especificado. Para cada marco de Java, se imprime el nombre completo de la clase, el nombre del método, el índice de bytes (BCI) y el número de línea, cuando están disponibles. Con la opción -m, el comando jstack imprime tanto los marcos de Java como los nativos de todos los hilos con el contador de programa (PC). Para cada marco nativo, se imprime el símbolo nativo más cercano al PC, cuando está disponible. Los nombres codificados de C++ no se decodifican. Para decodificar nombres de C++, la salida de este comando se puede canalizar a c++filt. Cuando el proceso especificado se ejecuta en una máquina virtual Java de 64 bits, es posible que necesites especificar la opción -J-d64, por ejemplo: jstack -J-d64 -m pid.

Nota: Esta utilidad no está soportada y podría no estar disponible en futuras versiones de JDK. En sistemas Windows donde el archivo dbgeng.dll no está presente, las Herramientas de depuración para Windows deben estar instaladas para que estas herramientas funcionen. La variable de entorno PATH debe contener la ubicación de jvm.dll que utiliza el proceso objetivo, o la ubicación desde la que se produjo el archivo de volcado de caída. Por ejemplo:

set PATH=<jdk>\jre\bin\client;%PATH%

OPCIONES

-F

Fuerza un volcado de pila cuando jstack [-l] pid no responde.
-l

Listado largo. Imprime información adicional sobre bloqueos, como una lista de sincronizadores propios de java.util.concurrent. Ver la descripción de la clase AbstractOwnableSynchronizer en http://docs.oracle.com/javase/8/docs/api/java/util/concurrent/locks/AbstractOwnableSynchronizer.html
-m

Imprime una traza de pila en modo mixto que tiene marcos tanto de Java como nativos C/C++.
-h

Imprime un mensaje de ayuda.
-help

Imprime un mensaje de ayuda.

ERRORES CONOCIDOS

En la traza de pila en modo mixto, la opción -m no funciona con el servidor de depuración remoto.
