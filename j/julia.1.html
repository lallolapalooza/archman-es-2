DESCRIPCIÓ

N

Julia es un lenguaje de programación dinámico de alto nivel y alto rendimiento para computación técnica, con una sintaxis familiar para los usuarios de otros entornos de computación técnica. Proporciona un compilador sofisticado, ejecución paralela distribuida, precisión numérica y una extensa biblioteca de funciones matemáticas. La biblioteca, escrita en gran parte en Julia misma, también integra bibliotecas maduras y de vanguardia en C y Fortran para álgebra lineal, generación de números aleatorios, procesamiento de señales y procesamiento de cadenas. Además, la comunidad de desarrolladores de Julia está contribuyendo con una serie de paquetes externos a través del gestor de paquetes integrado de Julia a un ritmo rápido. Los programas de Julia se organizan en torno a la despacho múltiple; definiendo funciones y sobrecargándolas para diferentes combinaciones de tipos de argumentos, que también pueden ser definidos por el usuario. Para una discusión más detallada de la justificación y las ventajas de Julia sobre otros sistemas, consulte el manual en línea: https://d

ocs.juli
alang.org

OPTIONS DE LIGNE DE COMMANDE

--track-allocation[={none*|user|all}]
Compte les octets alloués par chaque ligne source (omettre le réglage équivaut à `user`).
--track-allocation=@<path>
Compte les octets mais uniquement dans les fichiers qui correspondent au chemin/répertoire donné. Le préfixe `@` est requis pour sélectionner cette option. Un `@` sans chemin suivra le répertoire courant.
--code-coverage=tracefile.info
Ajoute des informations de couverture au fichier trace LCOV (le nom de fichier prend en charge les jetons de format).
--bug-report=KIND
Lance une session de rapport de bug. Il peut être utilisé pour démarrer un REPL, exécuter un script ou évaluer des expressions. Il essaie d'abord d'utiliser BugReporting.jl installé dans l'environnement actuel et se rabat sur la dernière version compatible de BugReporting.jl si ce n'est pas le cas. Pour plus d'informations, voir --bug-report=help.
--heap-size-hint=<size>
Force le ramasse-miettes si l'utilisation de la mémoire est supérieure à la valeur donnée. La valeur peut être spécifiée en octets, éventuellement dans les unités KB, MB, GB ou TB, ou en pourcentage de la mémoire physique avec %.
--compile={yes*|no|all|min}
Active ou désactive le compilateur JIT, ou demande une compilation exhaustive ou minimale.
--output-o <name>
Génère un fichier objet (y compris les données de l'image système).
--output-ji <name>
Génère un fichier de données d'image système (.ji).
--strip-metadata
Supprime les docstrings et les informations d'emplacement source de l'image système.
--strip-ir
Supprime la représentation intermédiaire (IR) des fonctions compilées.
--output-unopt-bc <name>
Génère du bitcode LLVM non optimisé (.bc).
--output-bc <name>
Génère du bitcode LLVM (.bc).
--output-asm <name>
Génère un fichier d'assemblage (.s).
--output-incremental={yes|no*}
Génère un fichier de sortie incrémental (plutôt que complet).
--trace-compile={stderr|name}
Imprime les instructions de précompilation pour les méthodes compilées pendant l'exécution ou les enregistre dans stderr ou dans un fichier. Les méthodes qui ont été recompilées sont imprimées en jaune ou avec un commentaire final si la couleur n'est pas prise en charge.
--trace-compile-timing=
Si --trace-compile est activé, affiche le temps que chaque compilation a pris en ms.
--trace-dispatch={stderr|name}
Imprime les instructions de précompilation pour les méthodes distribuées pendant l'exécution ou les enregistre dans stderr ou dans un fichier.
--task-metrics={yes|no*}
Active la collecte de métriques par tâche.
-image-codegen
Force la génération de code en mode imagerie.
--permalloc-pkgimg={yes|no*}
Copie la section de données des images de paquet en mémoire.
