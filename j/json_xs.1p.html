JSON_XS(1) Documentación de Perl aportada por el usuario JSON_XS(1)

NOMBRE

json_xs - Utilidad de línea de comandos de JSON::XS

SINOPSIS

json_xs [-v] [-f formato_entrada] [-t formato_salida]

DESCRIPCIÓN

json_xs convierte entre algunos formatos de entrada y salida (uno de ellos es JSON).

El formato de entrada predeterminado es "json" y el formato de salida predeterminado es "json-pretty".

OPCIONES

-v
Sé un poco más detallado.
-f formato_desde
Lee un archivo en el formato dado desde STDIN.

"formato_desde" puede ser uno de:

json - texto json codificado, ya sea utf-8, utf16-be/le, utf32-be/le
cbor - CBOR (RFC 7049, CBOR::XS), un tipo de JSON binario
storable - un valor congelado de Storable
storable-file - un archivo de Storable (Storable tiene dos formatos incompatibles)
bencode - usa Convert::Bencode, si está disponible (usado por archivos torrent, entre otros)
clzf - formato de Compress::LZF (requiere que ese módulo esté instalado)
eval - evalúa el código dado como Perl (no utf-8), básicamente lo inverso de "-t dump"
yaml - formato YAML (requiere que ese módulo esté instalado)
string - no intentes decodificar los datos del archivo
none - no se lee nada, crea un escalar "undef" - principalmente útil con "-e"
-t formato_a
Escribe el archivo en el formato dado a STDOUT.

"formato_a" puede ser uno de:

json, json-utf-8 - json, codificado en utf-8
json-pretty - igual que el anterior, pero con formato legible
json-utf-16le, json-utf-16be - utf-16 little endian/big endian
json-utf-32le, json-utf-32be - utf-32 little endian/big endian
cbor - CBOR (RFC 7049, CBOR::XS), un tipo de JSON binario
cbor-packed - CBOR usando extensiones para hacerlo más pequeño
storable - un valor congelado de Storable en formato de red
storable-file - un archivo de Storable en formato de red (Storable tiene dos formatos incompatibles)
bencode - usa Convert::Bencode, si está disponible (usado por archivos torrent, entre otros)
clzf - formato de Compress::LZF
yaml - formato de YAML::XS
dump - Data::Dump
dumper - Data::Dumper
string - escribe los datos como si fueran una cadena
none - no se escribe nada, principalmente útil junto con "-e"
Ten en cuenta que Data::Dumper no maneja estructuras de datos autorreferenciales correctamente; usa "dump" en su lugar.
-e código
Evalúa código perl después de leer los datos y antes de volver a escribirlos; puede usarse para filtrar, crear o extraer datos. Los datos que se han escrito están en $_, y lo que sea que haya ahí se escribe después.

EJEMPLOS

json_xs -t none <isitreally.json

"JSON Lint" - intenta analizar el archivo isitreally.json como JSON; si es JSON válido, el comando no imprime nada, de lo contrario, imprimirá un mensaje de error y saldrá con un estado de salida distinto de cero.

<src.json json_xs >pretty.json

Da formato legible al archivo JSON src.json en dst.json.

json_xs -f storable-file <file

Lee el archivo serializado de Storable file e imprime una versión JSON legible por humanos de él en STDOUT.

json_xs -f storable-file -t yaml <file

Igual que el anterior, pero escribe YAML en su lugar (sin usar JSON en absoluto :)

json_xs -f none -e '$_ = [1, 2, 3]'

Imprime el array de Perl como texto JSON codificado en UTF-8.

<torrentfile json_xs -f bencode -e '$_ = join "\n", map @$_, @{$_->{"announce-list"}}' -t string

Imprime la lista de rastreadores dentro de un archivo torrent.

lwp-request http://cpantesters.perl.org/show/JSON-XS.json | json_xs

Obtiene el resumen de resultados de cpan-testers "JSON::XS" y le da formato legible.
