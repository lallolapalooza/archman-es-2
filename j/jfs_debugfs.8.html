NOMBRE

jfs_debugfs - editor del sistema de archivos JFS de tipo shell

SINOPSIS

jfs_debugfs dispositivo

DESCRIPCIÓN

jfs_debugfs es un programa que puede usarse para realizar varias acciones de bajo nivel en un dispositivo formateado con JFS.

dispositivo es el nombre del archivo especial correspondiente al dispositivo real a editar (p. ej., /dev/hdb1).

jfs_debugfs debe ejecutarse como root.

NAME

jfs_debugfs - JFS filesystem interactive debugger

SYNOPSIS

jfs_debugfs [-f input-file] [-i] [-m] [-r] [-V] [-v] [-w] [-x] [device]

DESCRIPTION

The jfs_debugfs utility is a JFS filesystem interactive debugger. It allows you to navigate the JFS filesystem structure and display information about the filesystem, including inode information, and the contents of JFS journals. The tool is intended for use by JFS developers and system administrators when diagnosing filesystem problems.

The jfs_debugfs program operates in interactive mode unless the -f option is specified.

OPTIONS

-f input-file
Reads commands from input-file instead of standard input. This option can be used to script the debugger.
-i
Prints the journal inode number.
-m
Prints the inode number of the mount device.
-r
Opens the filesystem read-only.
-V
Prints the version information and exits.
-v
Verbose mode. Prints additional debugging information.
-w
Opens the filesystem read-write. This is the default.
-x
Opens the filesystem in 128-bit mode. This is the default.
device
The block device name of the JFS filesystem to debug.

INTERACTIVE MODE

When running interactively, jfs_debugfs presents a prompt (usually `debugfs: `) where you can enter commands. The program operates on the current working inode, which initially is the root directory of the filesystem.

COMMANDS

The following commands are available in interactive mode:

cat filename
Dump the contents of the specified file.
cd directory
Change the current working directory to directory.
chattr
Change file attributes.
dump filename [output-file]
Dump the specified file to output-file or standard output.
dump_inode inode-number
Dump information about the specified inode.
expand
Expand the filesystem.
help
Display a list of available commands.
inode inode-number
Set the current working inode to the specified inode number.
journal
Display information about the JFS journal.
ls [-l] [directory]
List the contents of the specified directory (or the current directory if none is specified). The -l option provides a long listing format.
log
Display information about the JFS log.
lsmap
List block map information.
mkdir directory-name
Create a new directory.
mknod filename [mode] [major] [minor]
Create a special file.
mv old-name new-name
Move or rename a file or directory.
open device
Open the specified JFS filesystem.
p
Print the current working inode number.
quit
Exit jfs_debugfs.
rm filename
Remove a file.
rmdir directory-name
Remove an empty directory.
setattr
Set file attributes.
stat
Display statistics about the filesystem.
tree
Display the filesystem tree structure.
whatis filename
Display the type of the specified file.
write filename [output-file]
Write the contents of the specified file to output-file or standard output.

In addition to the commands above, jfs_debugfs also supports a subcommand mode for navigating the JFS internal tree structure. This mode is entered by typing a number (representing a child node) or certain letters at the main prompt. The following subcommands are available within subcommand mode:

current_inode_number
Display information about the specified inode.
[file_set]

The current working inode is the inode of the filesystem's root directory - given in decimal

<file_set> currently must be zero

SUBCOMMANDS
l => visit left sibling
m => modify current node
p => visit parent node (not parent directory)
r => visit right sibling
[0-9] => visit the n'th child node
x => exit subcommand mode

REPORTING BUGS

If you find a bug in JFS or jfs_debugfs, please report it via the bug tracking system ("Report Bugs" section) of the JFS project web site:

http://jfs.sourceforge.net/

Please send as much pertinent information as possible, including the complete output of running jfs_fsck with the -v and -n options on the JFS device.
