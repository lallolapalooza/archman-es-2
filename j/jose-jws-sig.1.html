NOMBRE

jose-jws-sig - Firma una carga útil utilizando uno o más JWK

SINOPSIS

jose jws sig [-i JWS] [-I PAY] [-s SIG] -k JWK [-o JWS] [-O PAY] [-c]

DESCRIPCIÓN

El comando jose jws sig firma una carga útil utilizando uno o más JWK. La carga útil puede proporcionarse en su forma decodificada (-I) o incrustada en un JWS existente (-i).

Se puede crear un JWS separado especificando la opción -O. En este caso, la carga útil decodificada se escribirá en la salida especificada y no se incluirá en el JWS.

Si se utiliza una sola clave (-k), el JWS resultante puede ser salida en serialización compacta JWS utilizando la opción -c.

Este comando utiliza un enfoque basado en plantillas para construir un JWS. Puede especificar plantillas del propio JWS (-i) o del Objeto de Firma JWS (-r). Los atributos especificados en cualquiera de estas plantillas aparecerán sin modificar en la salida. Una excepción a esta regla es que la Cabecera Protegida JWS debe especificarse en su forma decodificada en la plantilla del Objeto de Firma JWS. Este comando la codificará automáticamente como parte del proceso de cifrado.

Si especifica un Parámetro de Cabecera JOSE (a través de las opciones -i o -r) que afecta a la construcción del JWE, este comando intentará comportarse de acuerdo con este parámetro como si fuera una configuración. Actualmente, jose modificará su comportamiento para el Parámetro de Cabecera JOSE "alg" (ver RFC 7515 Sección 4.1.1).

Sin embargo, no es necesario proporcionar ninguna plantilla: jose jwe enc rellenará automáticamente el parámetro "alg" infiriendo el algoritmo correcto de los JWK de entrada proporcionados. Por lo tanto, las opciones -i y -r generalmente deben usarse para proporcionar metadatos JWE extendidos.

Es posible especificar un JWS existente como entrada de plantilla JWS (-i). Esto permite añadir nuevas firmas a un JWS existente.

OPCIONES

•-i JSON, --input=JSON : Analiza la plantilla JWS desde JSON
•-i ARCHIVO, --input=ARCHIVO : Lee la plantilla JWS desde ARCHIVO
•-i -, --input=- : Lee la plantilla JWS desde la entrada estándar
•-I ARCHIVO, --detached=ARCHIVO : Lee la carga útil decodificada desde ARCHIVO
•-I -, --detached=- : Lee la carga útil decodificada desde la entrada estándar
•-s JSON, --signature=JSON : Analiza la plantilla de firma JWS desde JSON
•-s ARCHIVO, --signature=ARCHIVO : Lee la plantilla de firma JWS desde ARCHIVO
•-s -, --signature=- : Lee la plantilla de firma JWS desde la entrada estándar
•-k ARCHIVO, --key=ARCHIVO : Lee JWK(Set) desde ARCHIVO
•-k -, --key=- : Lee JWK(Set) desde la entrada estándar
•-o ARCHIVO, --output=ARCHIVO : Escribe JWS en ARCHIVO
•-o -, --output=- : Escribe JWS en stdout (por defecto)
•-O ARCHIVO, --detach=ARCHIVO : Separa la carga útil y la decodifica a ARCHIVO
•-O -, --detach=- : Separa la carga útil y la decodifica a la salida estándar
•-c, --compact : Salida JWS usando serialización compacta

EJEMPLOS

Firmar datos con una clave simétrica usando serialización JWE JSON:

$ jose jwk gen -i '{"alg":"HS256"}' -o key.jwk
$ jose jws sig -I msg.txt -k key.jwk -o msg.jws

Firmar datos usando serialización JWE compacta separada:

$ jose jws sig -I msg.txt -k key.jwk -O /dev/null -c -o msg.jws

Firmar con dos claves:

$ jose jwk gen -i '{"alg":"ES256"}' -o ec.jwk
$ jose jwk gen -i '{"alg":"RS256"}' -o rsa.jwk
$ jose jws sig -I msg.txt -k ec.jwk -k rsa.jwk -o msg.jws
