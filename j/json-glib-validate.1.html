NOMBRE

json-glib-validate - Herramienta de Validación de JSON

SINOPSIS

json-glib-validate [OPCIONES...] <ARCHIVO>

DESCRIPCIÓN

json-glib-validate ofrece una interfaz simple de línea de comandos para validar datos JSON. Le permite listar URIs que apuntan a datos JSON y verifica que los datos se ajusten a la sintaxis JSON.

Los recursos sobre los que operar se especifican mediante el argumento ARCHIVO.

Si los datos JSON son válidos, json-glib-validate terminará con un código de salida de 0; si los datos no son válidos, se imprimirá un error en stderr y json-glib-validate terminará con un código de salida distinto de cero.

OPCIONES

-h, --help

Imprime un mensaje de ayuda y sale.

CÓDIGO DE SALIDA

  • 0 Validación exitosa.
  • 1 Error de validación.
