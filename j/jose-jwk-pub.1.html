NOMBRE

jose-jwk-pub - Limpia claves privadas de un JWK

SINOPSIS

jose jwk pub -i JWK [-o JWK]

DESCRIPCIÓN

El comando jose jwk pub elimina todo el material de clave privada de una o más entradas JWK(Set). La salida contendrá solo material de clave pública.

Si el JWK contiene la propiedad "key_ops", se ajustará automáticamente para incluir solo las operaciones relevantes para claves públicas.

OPCIONES

•-i JSON, --input=JSON : Analiza JWK(Set) desde JSON
•-i ARCHIVO, --input=ARCHIVO : Lee JWK(Set) desde ARCHIVO
•-i -, --input=- : Lee JWK(Set) desde la entrada estándar
•-o ARCHIVO, --output=ARCHIVO : Escribe JWK(Set) en ARCHIVO
•-o -, --output=- : Escribe JWK(Set) en la salida estándar
•-s, --set : Siempre genera un JWKSet

EJEMPLOS

Limpiar material de clave privada de un JWK:

$ jose jwk gen -i '{"alg":"ES256"}' -o prv.jwk
$ cat prv.jwk
{"alg":"ES256","crv":"P-256","key_ops":["sign","verify"],"kty":"EC", ...}
$ jose jwk pub -i prv.jwk -o pub.jwk
$ cat pub.jwk
{"alg":"ES256","crv":"P-256","key_ops":["verify"],"kty":"EC", ...}
