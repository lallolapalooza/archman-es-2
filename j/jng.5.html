NOMBRE

jng - Subformato de JPEG Network Graphics (JNG)

DESCRIPCIÓN

JNG (JPEG Network Graphics) es un subformato del formato MNG (Multiple-image Network Graphics). Al igual que MNG, extiende las características del popular formato de imagen PNG (Portable Network Graphics).

Este subformato fue diseñado para soportar un método de compresión con pérdida. Se basa completamente en la especificación JPEG. Añade las altas relaciones de compresión de JPEG para imágenes fotográficas.

Como miembro de la familia Network Graphics, JNG se consideró adecuado como un formato independiente, ya que extiende el formato JPEG con características de corrección de color y transparencia.
