DESCRIPCIÓ

N

La utilidad jcmd se utiliza para enviar solicitudes de comandos de diagnóstico a la JVM. Debe usarse en la misma máquina en la que se está ejecutando la JVM, y tener los mismos identificadores efectivos de usuario y grupo que se utilizaron para iniciar la JVM. Cada comando de diagnóstico tiene su propio conjunto de argumentos. Para mostrar la descripción, la sintaxis y una lista de los argumentos disponibles para un comando de diagnóstico, use el nombre del comando como argumento. Por

ejemplo:

jcmd pid help coman

d
o

Si los argumentos contienen espacios, debe rodearlos con comillas simples o dobles (' o "). Además, debe escapar las comillas simples o dobles con una barra invertida (\) para evitar que el shell del sistema operativo procese las comillas. Alternativamente, puede rodear estos argumentos con comillas simples y luego con dobles (o con dobles y luego con simples)

.

Si especifica el identificador de proceso (pid) o la clase principal (clase-principal) como primer argumento, la utilidad jcmd envía la solicitud de comando de diagnóstico al proceso de Java con el identificador especificado o a todos los procesos de Java con

el nombre de clase principal especificado. También puede enviar la solicitud de comando de diag
nóstico a todos los procesos de Java disponibles especificando 0 como identificador de proceso.

Puedes especificar valores para múltiples configuraciones de eventos y opciones de .jfc separándolos con un espacio en blanco. En caso de conflicto entre un parámetro y una opción de .jfc, el parámetro tendrá prioridad. El delimitador de espacio en blanco se puede omitir para valores de período de tiempo, es decir, 20ms. Para más información sobre la sintaxis de configuración, consulta la Javadoc del paquete jdk.jfr.

jcmd(1) — Arch manual pages

NAME

jcmd — a portable tool for sending diagnostic command requests to a running Java Virtual Machine

SYNOPSIS

jcmd [ options ] <pid> <command> [ command_options ]
jcmd -l

DESCRIPTION

The jcmd utility is used to issue diagnostic command requests to a running Java Virtual Machine (JVM). The jcmd utility can obtain diagnostic information that can help in troubleshooting a Java application or the JVM itself. This utility is available on all platforms that support the Java SE Development Kit (JDK).

jcmd utility can be used to:

  • Get a list of running JVMs.
  • Get a list of available commands for a specific JVM.
  • Execute a specific command for a specific JVM.

The jcmd utility may be used to dump the heap, print thread information, or print the VM version, among other capabilities.

Example Usage:

To list all running JVMs:

jcmd -l

To list available commands for a given PID (e.g., 12345):

jcmd 12345 help

To print the heap of a given PID (e.g., 12345):

jcmd 12345 GC.heap_dump /path/to/heapdump.hprof

To print the thread dump of a given PID (e.g., 12345):

jcmd 12345 Thread.print

The jcmd utility may require the user running the command to have the same user ID as the process owner. On Linux and macOS systems, you may need to use sudo to run jcmd if the target process is not owned by the current user.
