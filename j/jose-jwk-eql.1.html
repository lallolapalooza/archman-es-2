NOMBRE

jose-jwk-eql - Comprueba si dos claves son iguales

SINOPSIS

jose jwk eql -i JWK -i JWK

DESCRIPCIÓN GENERAL

El comando jose jwk eql determina si dos claves son iguales. Compara las mismas propiedades definidas para su uso en una huella digital JWK (RFC 7638). Esto significa que los metadatos opcionales no se consideran para la comparación.

OPCIONES

•-i JSON, --input=JSON : Analiza JWK(Set) desde JSON
•-i ARCHIVO, --input=ARCHIVO : Lee JWK(Set) desde ARCHIVO
•-i -, --input=- : Lee JWK(Set) desde la entrada estándar

EJEMPLOS

Generar una clave, modificar metadatos opcionales y luego probar la igualdad:

$ jose jwk gen -i '{"alg":"ES256"}' -o key.jwk
$ jose fmt -j key.jwk -Od alg -o mod.jwk
$ jose jwk eql -i key.jwk -i mod.jwk
$ echo $?
0
