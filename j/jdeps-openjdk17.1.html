OPCIONES PARA MOSTRAR DEPENDENCIAS

--list-modules
Lista los módulos que contiene el archivo JAR o el directorio especificado. Solo se muestran los módulos de nivel superior y sus dependencias directas. No se muestra el gráfico completo de dependencias de los módulos.
--list-reduced-deps
Lista las dependencias del módulo sin listar los bordes de lectura implícitos del gráfico de módulos. Si el módulo M1 lee M2 y M2 requiere transitivamente M3, entonces la lectura de M3 por M1 está implícita y no se muestra en el gráfico.
--print-module-deps
Igual que --list-reduced-deps pero imprime una lista separada por comas de las dependencias de módulos. La salida puede ser utilizada por jlink --add-modules para crear una imagen personalizada que contenga esos módulos y sus dependencias transitivas.
--ignore-missing-deps
Ignora las dependencias faltantes.

OPCIONES PARA FILTRAR DEPENDENCIAS

-p nombre_paquete, -package nombre_paquete, o --package nombre_paquete
Encuentra dependencias que coincidan con el nombre de paquete especificado. Puede especificar esta opción varias veces para diferentes paquetes. Las opciones -p y -e son mutuamente excluyentes.
-e expresion_regular, -regex expresion_regular, o --regex expresion_regular
Encuentra dependencias que coincidan con el patrón especificado. Las opciones -p y -e son mutuamente excluyentes.
--require nombre_modulo
Encuentra dependencias que coincidan con el nombre del módulo dado (puede darse varias veces). Las opciones --package, --regex y --require son mutuamente excluyentes.
-f expresion_regular o -filter expresion_regular
Filtra dependencias que coincidan con el patrón dado. Si se da varias veces, se seleccionará la última.
-filter:package
Filtra dependencias dentro del mismo paquete. Este es el valor predeterminado.
-filter:archive
Filtra dependencias dentro del mismo archivo.
-filter:module
Filtra dependencias dentro del mismo módulo.
-filter:none
Sin filtrado de -filter:package y -filter:archive. El filtrado especificado a través de la opción -filter todavía se aplica.
--missing-deps
Encuentra dependencias faltantes. Esta opción no puede usarse con las opciones -p, -e y -s.

OPCIONES PARA FILTRAR CLASES A SER ANALIZADAS

-include expresion_regular
Restringe el análisis a las clases que coinciden con el patrón. Esta opción filtra la lista de clases a ser analizadas. Se puede usar junto con -p y -e, que aplican el patrón a las dependencias.
-P o -profile
Muestra el perfil que contiene un paquete.
-R o --recursive
Recorre recursivamente todas las dependencias de tiempo de ejecución. La opción -R implica -filter:none. Si se especifican las opciones -p, -e o -f, solo se analizan las dependencias que coinciden.
--no-recursive
No recorrer recursivamente las dependencias.
-I o --inverse
Analiza las dependencias según otras opciones dadas y luego encuentra todos los artefactos que dependen directa o indirectamente de los nodos que coinciden. Esto es equivalente a la inversa del análisis de vista de tiempo de compilación y al resumen de dependencias de impresión. Esta opción debe usarse con las opciones --require, --package o --regex.
--compile-time
Analiza la vista de tiempo de compilación de dependencias transitivas, como la vista de tiempo de compilación de la opción -R. Analiza las dependencias según otras opciones especificadas. Si se encuentra una dependencia de un directorio, un archivo JAR o un módulo, se analizan todas las clases en ese archivo contenedor.
