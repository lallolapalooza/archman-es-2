just(1) General Commands Manual just(1)

NOMBRE

just - 🤖 Simplemente un ejecutor de comandos - https://github.com/casey/just

SINOPSIS

just [--alias-style] [--ceiling] [--check] [--chooser] [--clear-shell-args] [--color] [--command-color] [--cygpath] [--dotenv-filename] [-E|--dotenv-path] [-n|--dry-run] [--dump-format] [--explain] [-g|--global-justfile] [--highlight] [-f|--justfile] [--list-heading] [--list-prefix] [--list-submodules] [--no-aliases] [--no-deps] [--no-dotenv] [--no-highlight] [--one] [-q|--quiet] [--allow-missing] [--set] [--shell] [--shell-arg] [--shell-command] [--tempdir] [--timestamp] [--timestamp-format] [-u|--unsorted] [--unstable] [-v|--verbose]... [-d|--working-directory] [--yes] [--changelog] [--choose] [-c|--command] [--completions] [--dump] [-e|--edit] [--evaluate] [--fmt] [--groups] [--init] [-l|--list] [--man] [-s|--show] [--summary] [--variables] [-h|--help] [-V|--version] [ARGUMENTOS]

DESCRIPCIÓN

🤖 Simplemente un ejecutor de comandos - https://github.com/casey/just

OPCIONES

--alias-style [predeterminado: right]
Establece el estilo de visualización de alias del comando list

[posibles valores: left, right, separate]

También se puede especificar con la variable de entorno JUST_ALIAS_STYLE.
--ceiling
No ascender por encima del directorio <CEILING> al buscar un justfile.
También se puede especificar con la variable de entorno JUST_CEILING.
--check
Ejecuta `--fmt` en modo 'check'. Sale con 0 si el justfile está formateado correctamente. Sale con 1 e imprime una diferencia si se requiere formato.
--chooser
Anula el binario invocado por `--choose`
También se puede especificar con la variable de entorno JUST_CHOOSER.
--clear-shell-args
Borra los argumentos del shell
--color [predeterminado: auto]
Imprime salida colorida

[posibles valores: always, auto, never]

También se puede especificar con la variable de entorno JUST_COLOR.
--command-color
Eco de las líneas de la receta en <COMMAND-COLOR>

[posibles valores: black, blue, cyan, green, purple, red, yellow]

También se puede especificar con la variable de entorno JUST_COMMAND_COLOR.
--cygpath [predeterminado: cygpath]
Usa el binario en <CYGPATH> para convertir entre rutas de Unix y Windows.
También se puede especificar con la variable de entorno JUST_CYGPATH.
--dotenv-filename
Busca el archivo de entorno llamado <DOTENV-FILENAME> en lugar de `.env`
-E, --dotenv-path
Carga <DOTENV-PATH> como archivo de entorno en lugar de buscar uno
-n, --dry-run
Imprime lo que just haría sin hacerlo
También se puede especificar con la variable de entorno JUST_DRY_RUN.
--dump-format <FORMATO> [predeterminado: just]
Vuelca el justfile como <FORMATO>

[posibles valores: json, just]

También se puede especificar con la variable de entorno JUST_DUMP_FORMAT.
--explain
Imprime el comentario de documentación de la receta antes de ejecutarla
También se puede especificar con la variable de entorno JUST_EXPLAIN.
-g, --global-justfile
Usa el justfile global
--highlight
Resalta las líneas de receta eco en negrita
También se puede especificar con la variable de entorno JUST_HIGHLIGHT.
-f, --justfile
Usa <JUSTFILE> como justfile
También se puede especificar con la variable de entorno JUST_JUSTFILE.
--list-heading <TEXTO> [predeterminado: Recipes disponibles:
] Imprime <TEXTO> antes de la lista
También se puede especificar con la variable de entorno JUST_LIST_HEADING.
--list-prefix <TEXTO> [predeterminado: ]
Imprime <TEXTO> antes de cada elemento de la lista
También se puede especificar con la variable de entorno JUST_LIST_PREFIX.
--list-submodules
Lista recetas en submódulos
También se puede especificar con la variable de entorno JUST_LIST_SUBMODULES.
--no-aliases
No mostrar alias en la lista
También se puede especificar con la variable de entorno JUST_NO_ALIASES.
--no-deps
No ejecutar dependencias de recetas
También se puede especificar con la variable de entorno JUST_NO_DEPS.
--no-dotenv
No cargar el archivo `.env`
También se puede especificar con la variable de entorno JUST_NO_DOTENV.
--no-highlight
No resaltar las líneas de receta eco en negrita
También se puede especificar con la variable de entorno JUST_NO_HIGHLIGHT.
--one
Prohibir que se invoquen varias recetas en la línea de comandos
También se puede especificar con la variable de entorno JUST_ONE.
-q, --quiet
Suprimir toda la salida
También se puede especificar con la variable de entorno JUST_QUIET.
--allow-missing
Ignorar errores de recetas y módulos faltantes
También se puede especificar con la variable de entorno JUST_ALLOW_MISSING.
--set <VARIABLE> <VALOR>
Anular <VARIABLE> con <VALOR>
--shell
Invoca <SHELL> para ejecutar recetas
--shell-arg
Invoca el shell con <SHELL-ARG> como argumento
--shell-command
Invoca <COMMAND> con el shell utilizado para ejecutar líneas de receta y comillas invertidas
--tempdir
Guarda archivos temporales en <TEMPDIR>.
También se puede especificar con la variable de entorno JUST_TEMPDIR.
