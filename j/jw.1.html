Un "target" que comienza con una marca de almohadilla "#" puede agregarse al nombre del archivo. Como resultado, solo se ejecuta la parte correspondiente de la hoja de estilos (la "especificación de estilo" cuyo "identificador" es igual al nombre del target). Un uso común de este mecanismo es definir targets "#html" y "#print" para activar la parte correspondiente de una hoja de estilos de reemplazo, que es común tanto para la conversión HTML como para la impresión.

Al reemplazar el nombre del archivo con "default", se utiliza la hoja de estilos predeterminada proporcionada con el frontend. Por ejemplo, el frontend docbook devuelve ./docbook.dsl#html (o ./docbook.dsl#print) en el directorio base SGML.

Al reemplazar el nombre del archivo con "none", no se utiliza ninguna hoja de estilos de reemplazo, ni siquiera la hoja de estilos predeterminada. La hoja de estilos que se utiliza también está determinada por el frontend. Por ejemplo, el frontend docbook devuelve el archivo html/docbook.dsl (o print/docbook.dsl) de Norman Walsh, que se encuentra en algún lugar debajo del directorio base SGML.

Si no se especifica ninguna opción --dsl, se utiliza "--dsl default".

-l archivo | --dcl archivo
Permite utilizar una declaración SGML personalizada en lugar de la predeterminada. El nombre del archivo de la declaración SGML predeterminada no se establece para archivos SGML, y se establece como xml.dcl en el directorio base SGML para archivos XML.
-s ruta | --sgmlbase ruta
Permite utilizar otra ubicación para el directorio base SGML. Este es el directorio debajo del cual se instalan todos los DTD SGML, hojas de estilos, entidades, etc. El valor predeterminado es /usr/share/sgml.
-p programa | --parser programa
Especifica el analizador a utilizar (Jade u OpenJade) si hay varios instalados. Si esta opción no se especifica, el script primero intenta usar Jade y luego intenta usar OpenJade.
-o directorio | --output directorio
Establece el directorio de salida donde se almacenarán todos los archivos resultantes. Si las hojas de estilos también definen un subdirectorio donde almacenar los archivos resultantes, el subdirectorio definido por las hojas de estilos se colocará debajo del subdirectorio definido por esta opción.
-V variable=[valor]
Establece una variable (a un valor, si se especifica uno).
-u | --nochunks
Genera un solo archivo grande. Esta opción solo es útil al generar HTML, porque la salida se puede dividir en varios archivos. Esta opción anula la configuración que se pueda realizar en las hojas de estilos.
-i seccion | --include seccion
Declara una sección marcada SGML como "include". Una sección marcada SGML es un tipo de parte condicional de un documento. Si se declara como "ignore", se ignorará; de lo contrario, se procesará. Un ejemplo de tal sección marcada sería:
            <DOCTYPE mydoc [
              <!ENTITY % confidential "ignore">
            ]>
            <mydoc>
              ...
              <![ %confidential [ Some confidential text... ]]>
              ...
            </mydoc>
-w tipo|list | --warning tipo|list
Habilita o deshabilita la visualización de tipos de advertencias dados. Se pueden ingresar varias opciones -w en la línea de comandos. Los tipos de advertencia que comienzan con "no-" deshabilita las advertencias correspondientes, los otros tipos las habilitan.

Si el tipo de advertencia se reemplaza con "list", se muestra una lista de los tipos de advertencia permitidos.

-e tipo|list | --error tipo|list
Deshabilita los tipos de errores dados. Se pueden ingresar varias opciones -e en la línea de comandos. Todos los tipos de error comienzan con "no-".

Si el tipo de error se reemplaza con "list", se muestra una lista de los tipos de error permitidos.

-h | --help
Imprime un breve mensaje de ayuda y sale.
-v | --version
Imprime el identificador de la versión y sale.
