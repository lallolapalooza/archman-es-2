JLINK(1) Comandos JDK JLINK(1)

NOMBRE

jlink - ensambla y optimiza un conjunto de módulos y sus dependencias en una imagen de tiempo de ejecución personalizada

SINOPSIS

jlink [opciones] --module-path rutamodulos --add-modules modulo [, modulo...]

opciones
Opciones de línea de comandos separadas por espacios. Ver Opciones de jlink.
rutamodulos
La ruta donde la herramienta jlink descubre módulos observables. Estos módulos pueden ser archivos JAR modulares, archivos JMOD o módulos desplegados.
modulo
Los nombres de los módulos a agregar a la imagen de tiempo de ejecución. La herramienta jlink agrega estos módulos y sus dependencias transitivas.

DESCRIPCIÓN

La herramienta jlink enlaza un conjunto de módulos, junto con sus dependencias transitivas, para crear una imagen de tiempo de ejecución personalizada.

Nota:

Los desarrolladores son responsables de actualizar sus imágenes de tiempo de ejecución personalizadas.

OPCIONES DE JLINK

--add-modules mod [, mod...]
Agrega los módulos nombrados, mod, al conjunto predeterminado de módulos raíz. El conjunto predeterminado de módulos raíz está vacío.
--bind-services
Enlaza módulos de proveedores de servicios y sus dependencias.
-c ={0|1|2} o --compress={0|1|2}
Habilita la compresión de recursos:
•
0: Sin compresión
•
1: Compartición de cadenas constantes
•
2: ZIP
--disable-plugin nombreplugin
Inhabilita el plugin especificado. Ver Plugins de jlink para la lista de plugins soportados.
--endian {little|big}
Especifica el orden de bytes de la imagen generada. El valor predeterminado es el formato de la arquitectura de tu sistema.
-h o --help
Imprime el mensaje de ayuda.
--ignore-signing-information
Suprime un error fatal cuando se enlazan archivos JAR modulares firmados en la imagen de tiempo de ejecución. Los archivos relacionados con la firma de los archivos JAR modulares firmados no se copian a la imagen de tiempo de ejecución.
--launcher comando=modulo o --launcher comando=modulo/principal
Especifica el nombre del comando lanzador para el módulo o el nombre del comando para el módulo y la clase principal (los nombres del módulo y la clase principal están separados por una barra inclinada (/)).
--limit-modules mod [, mod...]
Limita el universo de módulos observables a aquellos en el cierre transitivo de los módulos nombrados, mod, más el módulo principal, si existe, más cualquier módulo adicional especificado en la opción --add-modules.
--list-plugins
Lista los plugins disponibles, a los que puedes acceder a través de opciones de línea de comandos; ver Plugins de jlink.
-p o --module-path rutamodulos
Especifica la ruta de módulos.

Si esta opción no se especifica, la ruta de módulos predeterminada es $JAVA_HOME/jmods. Este directorio contiene el módulo java.base y los otros módulos estándar y del JDK. Si esta opción se especifica pero el módulo java.base no puede resolverse desde ella, el comando jlink agrega $JAVA_HOME/jmods a la ruta de módulos.

--no-header-files
Excluye archivos de encabezado.
--no-man-pages
Excluye páginas man.
--output ruta
Especifica la ubicación de la imagen de tiempo de ejecución generada.
--save-opts nombrearchivo
Guarda las opciones de jlink en el archivo especificado.
--suggest-providers [nombre, ...]
Sugiere proveedores que implementan los tipos de servicio dados desde la ruta de módulos.
--version
Imprime información de la versión.
@nombrearchivo
Lee las opciones desde el archivo especificado.

Un archivo de opciones es un archivo de texto que contiene las opciones y valores que normalmente ingresarías en un símbolo del sistema. Las opciones pueden aparecer en una línea o en varias líneas. No puedes especificar variables de entorno para nombres de ruta. Puedes comentar líneas anteponiendo un símbolo de almohadilla (#) al principio de la línea.

El siguiente es un ejemplo de un archivo de opciones para el comando jlink:


#Mié 07 dic 00:40:19 EST 2016
--module-path mlib
--add-modules com.greetings
--output greetingsapp

PLUGINS DE JLINK

Nota:

Los plugins no listados en esta sección no están soportados y están sujetos a cambios.

Para las opciones de plugin que requieren una lista-patrón, el valor es una lista separada por comas de elementos, donde cada elemento utiliza una de las siguientes formas:

•
patrón-glob
•
glob:patrón-glob
•
regex:patrón-regex
•
@nombrearchivo
•
nombrearchivo es el nombre de un archivo que contiene los patrones a utilizar, un patrón por línea.

Para obtener una lista completa de todos los plugins disponibles, ejecuta el comando jlink --list-plugins.
