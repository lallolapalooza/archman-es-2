NOMBRE

jj-file-chmod - Establece o elimina el bit ejecutable para rutas en el repositorio

SINOPSIS

jj file chmod [-r|--revision] [-R|--repository] [--ignore-working-copy] [--ignore-immutable] [--at-operation] [--debug] [--color] [--quiet] [--no-pager] [--config] [--config-file] [-h|--help] <MODO> <CONJUNTOS DE ARCHIVOS>

DESCRIPCIÓN

Establece o elimina el bit ejecutable para rutas en el repositorio.

A diferencia del `chmod` POSIX, `jj file chmod` también funciona en Windows, en archivos en conflicto y en revisiones arbitrarias.

OPCIONES

-r, --revision <REVSET> [por defecto: @]
La revisión a actualizar.
-h, --help
Imprime la ayuda (ver un resumen con '-h').
<MODO>

Posibles valores:

  • n: Hace que una ruta no sea ejecutable (alias: normal).
  • x: Hace que una ruta sea ejecutable (alias: executable).
<CONJUNTOS DE ARCHIVOS>
Rutas para las cuales cambiar el bit ejecutable.

OPCIONES GLOBALES

-R, --repository <REPOSITORIO>
Ruta del repositorio sobre el cual operar.

Por defecto, Jujutsu busca el directorio .jj/ más cercano en un ancestro del directorio de trabajo actual.

--ignore-working-copy
No guarda una instantánea de la copia de trabajo, ni la actualiza.

Por defecto, Jujutsu guarda una instantánea de la copia de trabajo al inicio de cada comando. La copia de trabajo también se actualiza al final del comando, si el comando modificó el commit de la copia de trabajo (`@`). Si desea evitar guardar una instantánea de la copia de trabajo y en su lugar ver un commit de la copia de trabajo posiblemente desactualizado, puede usar `--ignore-working-copy`. Esto puede ser útil, por ejemplo, en una línea de comandos, especialmente si tiene otro proceso que confirma la copia de trabajo.

Cargar el repositorio en una operación específica con `--at-operation` implica `--ignore-working-copy`.

--ignore-immutable
Permite reescribir commits inmutables.

Por defecto, Jujutsu evita reescribir commits en el conjunto configurado de commits inmutables. Esta opción deshabilita esa verificación y le permite reescribir cualquier commit excepto el commit raíz.

Esta opción solo afecta la verificación. No afecta el revset `immutable_heads()` ni la palabra clave de plantilla `immutable`.

--at-operation <OPERACION_EN_SECUENCIA>
Operación en la que cargar el repositorio.

Operación en la que cargar el repositorio. Por defecto, Jujutsu carga el repositorio en la operación más reciente, o en la fusión de las operaciones divergentes si las hay.

Puede usar `--at-op=<ID de operación>` para ver cómo era el repositorio en una operación anterior. Por ejemplo, `jj --at-op=<ID de operación> st` le mostrará lo que `jj st` habría mostrado cuando la operación dada acababa de finalizar. `--at-op=@` es prácticamente lo mismo que el valor por defecto, excepto que las operaciones divergentes nunca se fusionarán.

Use `jj op log` para encontrar el ID de operación que desea. Cualquier prefijo no ambiguo del ID de operación es suficiente.

Al cargar el repositorio en una operación anterior, se ignora la copia de trabajo, como si se hubiera especificado `--ignore-working-copy`.

Es posible ejecutar comandos mutantes al cargar el repositorio en una operación anterior. Hacerlo es equivalente a haber ejecutado comandos concurrentes que comenzaron en la operación anterior. Rara vez hay una razón para hacerlo, pero es posible.

--debug
Habilita el registro de depuración.
--color <CUANDO>
Cuándo colorear la salida.

[posibles valores: always, never, debug, auto]

--quiet
Silencia la salida no principal del comando.

Por ejemplo, `jj file list` seguirá listando archivos, pero no le dirá si la copia de trabajo fue guardada o si los descendientes fueron rebasados.

Las advertencias y los errores seguirán imprimiéndose.

--no-pager
Deshabilita el paginador.
--config <NOMBRE=VALOR>
Opciones de configuración adicionales (se pueden repetir).

El nombre debe especificarse como claves con puntos de TOML. El valor debe especificarse como una expresión TOML. Si el valor de cadena no está encerrado en ninguna construcción de TOML (como la notación de array), se pueden omitir las comillas.

--config-file <RUTA>
Archivos de configuración adicionales (se pueden repetir).
