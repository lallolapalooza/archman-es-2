jmap(1) Herramientas de resolución de problemas jmap(1)

NOMBRE

jmap - Imprime mapas de memoria de objetos compartidos o detalles de memoria heap para un proceso, archivo core o servidor de depuración remoto. Este comando es experimental y no es compatible.

SINOPSIS

jmap [ opciones ] pid
jmap [ opciones ] ejecutable core
jmap [ opciones ] [ pid ] id_servidor@ ] nombre_host_remoto_o_IP
opciones
Las opciones de la línea de comandos. Ver Opciones.
pid
El ID de proceso para el cual se imprimirá el mapa de memoria. El proceso debe ser un proceso Java. Para obtener una lista de procesos Java en ejecución en una máquina, use el comando jps(1).
ejecutable
El ejecutable Java a partir del cual se produjo el volcado de núcleo.
core
El archivo core para el cual se imprimirá el mapa de memoria.
nombre_host_remoto_o_IP
El servidor de depuración remoto nombre de host o dirección IP. Ver jsadebugd(1).
id_servidor
Un ID único opcional para usar cuando hay varios servidores de depuración en ejecución en el mismo host remoto.

DESCRIPCIÓN

El comando jmap imprime mapas de memoria de objetos compartidos o detalles de memoria heap de un proceso, archivo core o servidor de depuración remoto especificado. Si el proceso especificado se está ejecutando en una Máquina Virtual Java (JVM) de 64 bits, es posible que necesite especificar la opción -J-d64, por ejemplo: jmap-J-d64 -heap pid.

Nota: Esta utilidad no es compatible y podría no estar disponible en futuras versiones del JDK. En sistemas Windows donde el archivo dbgeng.dll no está presente, se deben instalar las Herramientas de Depuración para Windows para que estas herramientas funcionen. La variable de entorno PATH debe contener la ubicación del archivo jvm.dll que utiliza el proceso de destino o la ubicación desde la que se produjo el archivo de volcado de caída, por ejemplo: set PATH=%JDK_HOME%\jre\bin\client;%PATH%.

OPCIONES

<sin opción>
Cuando no se usa ninguna opción, el comando jmap imprime las asignaciones de objetos compartidos. Para cada objeto compartido cargado en la JVM de destino, se imprimen la dirección de inicio, el tamaño de la asignación y la ruta completa del archivo del objeto compartido. Este comportamiento es similar a la utilidad pmap de Oracle Solaris.
-dump:[vivo,] formato=b, archivo=nombre_archivo

Vuelca el heap de Java en formato binario hprof al nombre_archivo. La subopción vivo es opcional, pero cuando se especifica, solo se vuelcan los objetos activos en el heap. Para explorar el volcado del heap, puede usar el comando jhat(1) para leer el archivo generado.
-finalizerinfo

Imprime información sobre los objetos que están pendientes de finalización.
-heap

Imprime un resumen del heap del recolector de basura utilizado, la configuración del heap y el uso del heap por generación. Además, se imprimen el número y tamaño de las cadenas internadas.
- histo[:vivo]

Imprime un histograma del heap. Para cada clase de Java, se imprimen el número de objetos, el tamaño de memoria en bytes y los nombres de clase completos. Los nombres de clase internos de la JVM se imprimen con un prefijo de asterisco (*). Si se especifica la subopción vivo, solo se cuentan los objetos activos.
-clstats

Imprime estadísticas por cargador de clases del heap de Java. Para cada cargador de clases, se imprimen su nombre, nivel de actividad, dirección, cargador de clases padre y el número y tamaño de las clases que ha cargado.
-F

Forzar. Use esta opción con la opción jmap -dump o jmap -histo cuando el pid no responde. La subopción vivo no es compatible en este modo.
-h

Imprime un mensaje de ayuda.
-help

Imprime un mensaje de ayuda.
-Jbandera

Pasa bandera a la Máquina Virtual Java donde se está ejecutando el comando jmap.
