JWEBSERVER(1) Comandos del JDK JWEBSERVER(1)

NOMBRE

jwebserver - inicia el Servidor Web Simple de Java

SINOPSIS

jwebserver [opciones]

opciones
Opciones de línea de comandos. Para una descripción detallada de las opciones, véase Opciones.

DESCRIPCIÓN

La herramienta jwebserver proporciona un servidor HTTP mínimo, diseñado para ser utilizado para prototipado, pruebas y depuración. Sirve una única jerarquía de directorios y solo sirve archivos estáticos. Solo se admite HTTP/1.1; no se admiten HTTP/2 ni HTTPS.

Solo se atienden peticiones idempotentes HEAD y GET. Cualquier otra petición recibe una respuesta 501 - No Implementado o una 405 - No Permitido . Las peticiones GET se mapean al directorio que se está sirviendo, como sigue:

•
Si el recurso solicitado es un archivo, se sirve su contenido.
•
Si el recurso solicitado es un directorio que contiene un archivo índice, se sirve el contenido del archivo índice.
•
De lo contrario, se listan los nombres de todos los archivos y subdirectorios del directorio. Los enlaces simbólicos y los archivos ocultos no se listan ni se sirven.

Los tipos MIME se configuran automáticamente, utilizando la tabla incorporada. Por ejemplo, los archivos .html se sirven como text/html y los archivos .java se sirven como text/plain.

jwebserver se encuentra en el módulo jdk.httpserver, y puede iniciarse alternativamente con java -m jdk.httpserver. Se basa en la implementación del servidor web del paquete com.sun.net.httpserver . La clase com.sun.net.httpserver.SimpleFileServer proporciona una forma programática de obtener el servidor y sus componentes para su reutilización y extensión.

USO

jwebserver [-b dirección de enlace] [-p puerto] [-d directorio]
           [-o none|info|verbose] [-h para mostrar opciones]
           [-version para mostrar información de la versión]

OPCIONES

-h o -? o --help
Imprime el mensaje de ayuda y sale.
-b addr o --bind-address addr
Especifica la dirección a la que enlazar. Por defecto: 127.0.0.1 o ::1 (loopback). Para todas las interfaces use -b 0.0.0.0 o -b ::.
-d dir o --directory dir
Especifica el directorio a servir. Por defecto: directorio actual.
-o level o --output level
Especifica el formato de salida. none | info | verbose. Por defecto: info.
-p port o --port port
Especifica el puerto en el que escuchar. Por defecto: 8000.
-version o --version
Imprime la información de la versión y sale.

Para detener el servidor, pulse Ctrl + C.

INICIANDO EL SERVIDOR

El siguiente comando inicia el Servidor Web Simple:

$ jwebserver

Si el inicio es exitoso, el servidor imprime un mensaje en System.out listando la dirección local y la ruta absoluta del directorio que se está sirviendo. Por ejemplo:

$ jwebserver
Enlazando a loopback por defecto. Para todas las interfaces use "-b 0.0.0.0" o "-b ::".
Sirviendo /cwd y subdirectorios en 127.0.0.1 puerto 8000
URL http://127.0.0.1:8000/

CONFIGURACIÓN

Por defecto, el servidor se ejecuta en primer plano y se enlaza a la dirección loopback y al puerto 8000. Esto puede cambiarse con las opciones -b y -p . Por ejemplo, para enlazar el Servidor Web Simple a todas las interfaces, use:

$ jwebserver -b 0.0.0.0
Sirviendo /cwd y subdirectorios en 0.0.0.0 (todas las interfaces) puerto 8000
URL http://123.456.7.891:8000/

Tenga en cuenta que esto hace que el servidor web sea accesible para todos los hosts en la red. No haga esto a menos que esté seguro de que el servidor no puede filtrar ninguna información sensible.

Como otro ejemplo, use el siguiente comando para ejecutar en el puerto 9000:

$ jwebserver -p 9000

Por defecto, se sirven los archivos del directorio actual. Un directorio diferente puede especificarse con la opción -d .

Por defecto, cada petición se registra en la consola. La salida se ve así:

127.0.0.1 - - [10/Feb/2021:14:34:11 +0000] "GET /some/subdirectory/ HTTP/1.1" 200 -

La salida de registro puede cambiarse con la opción -o . La configuración por defecto es info. La configuración verbose incluye además las cabeceras de petición y respuesta, así como la ruta absoluta del recurso solicitado.

DETENIENDO EL SERVIDOR

Una vez iniciado exitosamente, el servidor se ejecuta hasta que se detiene. En las plataformas Unix, el servidor puede detenerse enviándole una señal SIGINT (Ctrl+C en una ventana de terminal).

    NOMBRE

    jwebserver - Servidor HTTP integrado de Java

    SINOPSIS

    jwebserver [OPCIONES]

    DESCRIPCIÓN

    El comando jwebserver inicia un servidor HTTP integrado simple. Es útil para servir archivos estáticos desde un directorio especificado.

    OPCIONES

    • --bind-address <dirección>: Especifica la dirección IP a la que se enlazará el servidor. El valor predeterminado es 0.0.0.0 (todas las interfaces).
    • --directory <ruta>: Especifica el directorio raíz desde el cual se servirán los archivos. El valor predeterminado es el directorio actual.
    • --port <puerto>: Especifica el número de puerto en el que escuchará el servidor. El valor predeterminado es 8080.
    • --help: Muestra un mensaje de ayuda y sale.

    EJEMPLOS

    Servir archivos del directorio actual en el puerto predeterminado (8080):

    jwebserver

    Servir archivos del directorio /var/www/html en el puerto 80:

    jwebserver --directory /var/www/html --port 80

    Servir archivos del directorio actual solo en la interfaz de loopback (localhost) en el puerto 8000:

    jwebserver --bind-address 127.0.0.1 --port 8000
