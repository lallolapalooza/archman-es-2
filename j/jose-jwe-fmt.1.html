NOMBRE

jose-jwe-fmt - Convierte un JWE entre formatos de serialización

SINOPSIS

jose jwe fmt -i JWE [-I CT] [-o JWE] [-O CT] [-c]

DESCRIPCIÓN

El comando jose jwe fmt convierte un JWE en formatos de serialización alternativos. Por ejemplo, puede:

1.Adjuntar texto cifrado a un JWE desacoplado.
2.Separar texto cifrado de un JWE.
3.Convertir la serialización compacta de JWE a la serialización JSON de JWE.
4.Convertir la serialización JSON de JWE a la serialización compacta de JWE.

OPCIONES

•-i JSON, --input=JSON : Analiza JWE desde JSON
•-i ARCHIVO, --input=ARCHIVO : Lee JWE desde ARCHIVO
•-i -, --input=-: Lee JWE desde la entrada estándar
•-I ARCHIVO, --detached=ARCHIVO : Lee el texto cifrado decodificado desde ARCHIVO
•-I -, --detached=- : Lee el texto cifrado decodificado desde la entrada estándar
•-o ARCHIVO, --output=ARCHIVO : Escribe JWE en ARCHIVO
•-o -, --output=- : Escribe JWE en stdout (por defecto)
•-O ARCHIVO, --detach=ARCHIVO : Separa el texto cifrado y lo decodifica en ARCHIVO
•-O -, --detach=- : Separa el texto cifrado y lo decodifica en la salida estándar
•-c, --compact : Genera la salida JWE usando serialización compacta

EJEMPLOS

Adjuntar texto cifrado a un JWE desacoplado y emitir serialización compacta de JWE:

$ jose jwe fmt -i msg.jwe -I msg.ct -o compact.jwe -c

Separar texto cifrado de un JWE:

$ jose jwe fmt -i msg.jwe -o detached.jwe -O detached.ct
