J0(3P) Manual del Programador POSIX J0(3P)

PROLOGO

Esta página del manual forma parte del Manual del Programador POSIX. La implementación de Linux de esta interfaz puede diferir (consulte la página del manual correspondiente de Linux para obtener detalles del comportamiento en Linux) o la interfaz puede no estar implementada en Linux.

NOMBRE

j0, j1, jn — funciones de Bessel de primer tipo

SINOPSIS

#include <math.h>
double j0(double x);
double j1(double x);
double jn(int n, double x);

DESCRIPCION

Las funciones j0(), j1() y jn() calcularán las funciones de Bessel de x de primer tipo de órdenes 0, 1 y n, respectivamente.

Una aplicación que desee comprobar situaciones de error debe establecer errno a cero y llamar a feclearexcept(FE_ALL_EXCEPT) antes de llamar a estas funciones. Al regresar, si errno no es cero o fetestexcept(FE_INVALID | FE_DIVBYZERO | FE_OVERFLOW | FE_UNDERFLOW) no es cero, se ha producido un error.

VALOR DE RETORNO

Tras una finalización satisfactoria, estas funciones devolverán el valor de Bessel relevante de x de primer tipo.

Si el argumento x es demasiado grande en magnitud, o el resultado correcto causaría un desbordamiento inferior, se devolverá 0 y puede ocurrir un error de rango.

Si x es NaN, se devolverá un NaN.

ERRORES

Estas funciones pueden fallar si:

Error de rango
El valor de x era demasiado grande en magnitud o se produjo un desbordamiento inferior.

Si la expresión entera (math_errhandling & MATH_ERRNO) no es cero, entonces errno se establecerá en [ERANGE]. Si la expresión entera (math_errhandling & MATH_ERREXCEPT) no es cero, entonces se activará la excepción de punto flotante de desbordamiento inferior.

No ocurrirán otros errores.

USO DE APLICACION
