Documentación de alias de tipos

typedef jose_cfg_t jose_cfg_auto_t

Define un jose_cfg_t que llama a jose_cfg_decref() al final del ámbito. Por ejemplo:

void foo() {
    jose_cfg_auto_t *cfg = jose_cfg();
    // jose_cfg_decref() llamado implícitamente
}

Documentación de funciones

jose_cfg_t* jose_cfg (void)

Crea una nueva instancia de configuración.

Retorna:

Una instancia de configuración recién asignada.

jose_cfg_t* jose_cfg_incref (jose_cfg_t * cfg)

Aumenta el contador de referencias de una instancia de configuración. Esta función siempre tiene éxito.

Parámetros:

cfg El contexto de configuración.

Retorna:

El valor de cfg (para conveniencia).

void jose_cfg_decref (jose_cfg_t * cfg)

Disminuye el contador de referencias de una instancia de configuración. Cuando el contador de referencias llega a cero, la instancia de configuración se libera.

Parámetros:

cfg El contexto de configuración.

void jose_cfg_set_err_func (jose_cfg_t * cfg, jose_cfg_err_t * err, void * misc)

Establece la función de manejo de errores para esta instancia de configuración. El valor de misc se pasará a la función de manejo de errores.

Puede pasar NULL a err para volver al manejador de errores predeterminado.

Parámetros:

cfg El contexto de configuración.
err La función de manejo de errores que desea habilitar.
misc Los datos diversos que desea pasar al manejador de errores.

void* jose_cfg_get_err_misc (jose_cfg_t * cfg)

Obtiene los datos diversos asociados con el manejador de errores actual.

Parámetros:

cfg El contexto de configuración.

Retorna:

Los datos diversos asociados con el manejador de errores.

void jose_cfg_err (jose_cfg_t * cfg, uint64_t err, const char * fmt, ...)

Envía un error. Se llamará al manejador de errores con el error proporcionado.

Parámetros:

cfg El contexto de configuración (opcional).
err El número correspondiente a este tipo de error.
fmt Una cadena de formato estilo printf().
... Los argumentos estilo printf().
