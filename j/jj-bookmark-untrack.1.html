NOMBRE

jj-bookmark-untrack - Dejar de rastrear marcadores remotos dados

SINOPSIS

jj bookmark untrack [-R|--repository] [--ignore-working-copy] [--ignore-immutable] [--at-operation] [--debug] [--color] [--quiet] [--no-pager] [--config] [--config-file] [-h|--help] <MARCADOR@REMOTO>

DESCRIPCIÓN

Dejar de rastrear marcadores remotos dados

Un marcador remoto que no se rastrea es solo un puntero al último marcador remoto traído. No se importará como un marcador local en futuras extracciones.

Si desea olvidar un marcador local y, al mismo tiempo, dejar de rastrear los marcadores remotos correspondientes, utilice `jj bookmark forget` en su lugar.

OPCIONES

-h, --help
Imprimir ayuda (ver un resumen con '-h')
<MARCADOR@REMOTO>
Marcadores remotos a dejar de rastrear

Por defecto, el nombre especificado coincide exactamente. Utilice el prefijo `glob:` para seleccionar marcadores por [patrón comodín].

Ejemplos: marcador@remoto, glob:main@*, glob:jjfan-*@upstream

[patrón comodín]: https://docs.jj-vcs.dev/latest/revsets/#string-patterns

OPCIONES GLOBALES

-R, --repository <REPOSITORIO>
Ruta al repositorio sobre el que operar

Por defecto, Jujutsu busca el directorio .jj/ más cercano en un ancestro del directorio de trabajo actual.

--ignore-working-copy
No hacer snapshot de la copia de trabajo y no actualizarla

Por defecto, Jujutsu hace un snapshot de la copia de trabajo al principio de cada comando. La copia de trabajo también se actualiza al final del comando, si el comando modificó el commit de la copia de trabajo (`@`). Si desea evitar hacer snapshot de la copia de trabajo y ver en su lugar un commit de copia de trabajo posiblemente desactualizado, puede utilizar `--ignore-working-copy`. Esto puede ser útil, por ejemplo, en una línea de comandos, especialmente si otro proceso hace commit de la copia de trabajo.

Cargar el repositorio en una operación específica con `--at-operation` implica `--ignore-working-copy`.

--ignore-immutable
Permitir reescribir commits inmutables

Por defecto, Jujutsu evita reescribir commits en el conjunto configurado de commits inmutables. Esta opción deshabilita esa verificación y le permite reescribir cualquier commit excepto el commit raíz.

Esta opción solo afecta a la verificación. No afecta al revset `immutable_heads()` ni a la palabra clave de plantilla `immutable`.

--at-operation <OPERACION_EN>
Operación en la que cargar el repo

Operación en la que cargar el repo. Por defecto, Jujutsu carga el repo en la operación más reciente, o en la fusión de operaciones divergentes si las hay.

Puede usar `--at-op=<ID de operación>` para ver cómo era el repo en una operación anterior. Por ejemplo, `jj --at-op=<ID de operación> st` le mostrará lo que `jj st` habría mostrado cuando la operación dada acababa de finalizar. `--at-op=@` es prácticamente lo mismo que el valor por defecto, excepto que las operaciones divergentes nunca se fusionarán.

Utilice `jj op log` para encontrar el ID de operación que desea. Cualquier prefijo no ambiguo del ID de operación es suficiente.

Al cargar el repo en una operación anterior, se ignorará la copia de trabajo, como si se hubiera especificado `--ignore-working-copy`.

Es posible ejecutar comandos mutables al cargar el repo en una operación anterior. Hacerlo es equivalente a haber ejecutado comandos concurrentes a partir de la operación anterior. Rara vez hay una razón para hacerlo, pero es posible.

--debug
Habilitar registro de depuración
--color <CUÁNDO>
Cuándo colorear la salida

[valores posibles: always, never, debug, auto]

--quiet
Silenciar la salida no principal del comando

Por ejemplo, `jj file list` seguirá listando archivos, pero no le dirá si se hizo snapshot de la copia de trabajo o si los descendientes fueron rebosados.

Las advertencias y errores seguirán imprimiéndose.

--no-pager
Deshabilitar el paginador
--config <NOMBRE=VALOR>
Opciones de configuración adicionales (se puede repetir)

El nombre debe especificarse como claves TOML con puntos. El valor debe especificarse como una expresión TOML. Si el valor de cadena no está delimitado por ninguna construcción TOML (como la notación de array), las comillas se pueden omitir.

--config-file <RUTA>
Archivos de configuración adicionales (se puede repetir)
