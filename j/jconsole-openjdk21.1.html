JCONSOLE(1) Comandos JDK JCONSOLE(1)

NOMBRE

jconsole - inicia una consola gráfica para monitorizar y gestionar aplicaciones Java

SINOPSIS

jconsole [-intervalo=n] [-notile] [-plugin ruta] [-version] [conexión ... ] [-Jargumentos_de_entrada]

jconsole -help

OPCIONES

-intervalo
Establece el intervalo de actualización a n segundos (el valor predeterminado es 4 segundos).
-notile
No organiza las ventanas en mosaico para dos o más conexiones.
-pluginpath ruta
Especifica la ruta que jconsole utiliza para buscar complementos. La ruta del complemento debe contener un archivo de configuración del proveedor llamado META-INF/services/com.sun.tools.jconsole.JConsolePlugin que contenga una línea para cada complemento. La línea especifica el nombre de clase completamente calificado de la clase que implementa la clase com.sun.tools.jconsole.JConsolePlugin.
-version
Imprime la versión del programa.
conexión = pid | host:puerto | URL_jmx
Una conexión se describe mediante pid, host:puerto o URL_jmx.
•
El valor pid es el ID de proceso de un proceso de destino. La JVM debe estar ejecutándose con el mismo ID de usuario que el ID de usuario que ejecuta el comando jconsole.
•
Los valores host:puerto son el nombre del sistema host en el que se está ejecutando la JVM y el número de puerto especificado por la propiedad del sistema com.sun.management.jmxremote.port cuando se inició la JVM.
•
El valor URL_jmx es la dirección del agente JMX al que conectarse, como se describe en JMXServiceURL.
-Jargumentos_de_entrada
Pasa argumentos_de_entrada a la JVM en la que se ejecuta el comando jconsole.
-help o --help
Muestra el mensaje de ayuda del comando.

DESCRIPCIÓN

El comando jconsole inicia una herramienta de consola gráfica que permite monitorizar y gestionar aplicaciones y máquinas virtuales Java en una máquina local o remota.

En Windows, el comando jconsole no se asocia con una ventana de consola. Sin embargo, muestra un cuadro de diálogo con información de error cuando el comando jconsole falla.
