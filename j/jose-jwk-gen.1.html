NOMBRE

jose-jwk-gen - Crea un JWK aleatorio para cada plantilla JWK de entrada

SINOPSIS

jose jwk gen -i JWK [-o JWK]

DESCRIPCIÓN GENERAL

El comando jose jwk gen genera una clave a partir de una o más plantillas JWK(Set). Si se proporciona una única plantilla como entrada, se generará un único JWK como salida. Sin embargo, si se proporcionan varias plantillas como entrada, se generará un JWKSet único que contendrá todas las claves.

La mejor manera de generar una clave es especificar el algoritmo con el que se utilizará en la propiedad "alg" de la plantilla JWK. Se debe preferir este método ya que, al generar a partir de un algoritmo, se emitirá automáticamente un parámetro "key_ops" apropiado. Además, tener un JWK con el algoritmo ya especificado ayudará a la inferencia del algoritmo al cifrar o firmar.

Alternativamente, puedes generar una clave especificando su propiedad JWK de tipo de clave ("kty"), junto con el parámetro de generación específico del tipo requerido. Consulta los ejemplos a continuación para ver cómo hacerlo para cada tipo de clave. Si el parámetro de generación específico del tipo no es estándar (por ejemplo: "bytes" y "bits"), se excluirá de la salida.

OPCIONES

•-i JSON, --input=JSON : Analiza la plantilla JWK(Set) a partir de JSON
•-i ARCHIVO, --input=ARCHIVO : Lee la plantilla JWK(Set) desde un ARCHIVO
•-i -, --input=- : Lee la plantilla JWK(Set) de la entrada estándar
•-o ARCHIVO, --output=ARCHIVO : Escribe el JWK(Set) en un ARCHIVO
•-o -, --output=- : Escribe el JWK(Set) en la salida estándar
•-s, --set : Siempre genera un JWKSet

EJEMPLOS

Genera tres claves, cada una apuntando a un algoritmo diferente:

$ jose jwk gen -i '{"alg":"HS256"}' -o oct.jwk
$ jose jwk gen -i '{"alg":"RS256"}' -o rsa.jwk
$ jose jwk gen -i '{"alg":"ES256"}' -o ec.jwk

Genera tres claves usando parámetros de clave en lugar de algoritmos:

$ jose jwk gen -i '{"kty":"oct","bytes":32}' -o oct.jwk
$ jose jwk gen -i '{"kty":"RSA","bits":4096}' -o rsa.jwk
$ jose jwk gen -i '{"kty":"EC","crv":"P-256"}' -o ec.jwk

Crea varias claves a la vez usando una plantilla JWKSet:

$ jose jwk gen \
  -i '{"keys":[{"alg":"HS256"},{"alg":"ES256"}]}' \
  -o keys.jwkset

Crea varias claves a la vez usando varias plantillas JWK:

$ jose jwk gen \
  -i '{"alg":"HS256"}' \
  -i '{"alg":"ES256"}' \
  -o keys.jwkset
