NOMBRE

jhsdb - adjuntarse a un proceso Java o iniciar un depurador postmortem para analizar el contenido de un volcado de memoria de una Máquina Virtual Java (JVM) que ha fallado

SINÓPSIS

ADVERTENCIA: El subcomando debugd y las opciones --connect están obsoletos. Se eliminarán en una futura versión.

jhsdb clhsdb [--pid pid | --exe ejecutable --core volcado_memoria]

jhsdb hsdb [--pid pid | --exe ejecutable --core volcado_memoria]

jhsdb debugd (--pid pid | --exe ejecutable --core volcado_memoria) [opciones]

jhsdb jstack (--pid pid | --exe ejecutable --core volcado_memoria | --connect [id_servidor@]host_debugd) [opciones]

jhsdb jmap (--pid pid | --exe ejecutable --core volcado_memoria | --connect [id_servidor@]host_debugd) [opciones]

jhsdb jinfo (--pid pid | --exe ejecutable --core volcado_memoria | --connect [id_servidor@]host_debugd) [opciones]

jhsdb jsnap (--pid pid | --exe ejecutable --core volcado_memoria | --connect [id_servidor@]host_debugd) [opciones]

pid
El ID del proceso al que debe adjuntarse la herramienta jhsdb. El proceso debe ser un proceso Java. Para obtener una lista de procesos Java en ejecución en una máquina, utilice el comando ps o, si los procesos JVM no se están ejecutando en una instancia de docker separada, el comando jps.
ejecutable
El archivo ejecutable de Java a partir del cual se produjo el volcado de memoria.
volcado_memoria
El archivo de volcado de memoria al que debe adjuntarse la herramienta jhsdb.
[id_servidor@]host_debugd
Un ID de servidor opcional y la dirección del servidor de depuración remoto (debugd).
opciones
Las opciones de línea de comandos para un modo de jhsdb. Consulte Opciones para el modo debugd, Opciones para el modo jstack, Opciones para el modo jmap, Opciones para el modo jinfo y Opciones para el modo jsnap.

Nota:

Se debe proporcionar el pid o el par de archivos ejecutable y core o el [id_servidor@]host_debugd para los modos debugd, jstack, jmap, jinfo y jsnap.

DESCRIPCIÓN

Puede utilizar la herramienta jhsdb para adjuntarse a un proceso Java o para iniciar un depurador postmortem para analizar el contenido de un volcado de memoria de una Máquina Virtual Java (JVM) que ha fallado. Este comando es experimental y no está soportado.

Nota:

Adjuntar la herramienta jhsdb a un proceso en vivo hará que el proceso se cuelgue y probablemente fallará cuando el depurador se desconecte.

La herramienta jhsdb se puede lanzar en cualquiera de los siguientes modos:

jhsdb clhsdb
Inicia el depurador interactivo de línea de comandos.
jhsdb hsdb
Inicia el depurador GUI interactivo.
jhsdb debugd
Inicia el servidor de depuración remoto.
jhsdb jstack
Imprime información de pila y de bloqueos.
jhsdb jmap
Imprime información del heap.
jhsdb jinfo
Imprime información básica de la JVM.
jhsdb jsnap
Imprime información de contadores de rendimiento.
jhsdb comando --help
Muestra las opciones disponibles para el comando.

OPCIONES PARA EL MODO DEBUGd

--serverid id_servidor
Un ID único opcional para este servidor de depuración. Esto es necesario si se ejecutan varios servidores de depuración en la misma máquina.
--rmiport puerto
Establece el número de puerto al que se enlaza el conector RMI. Si no se especifica, se utiliza un puerto aleatorio disponible.
--registryport puerto
Establece el puerto del registro RMI. Esta opción anula la propiedad del sistema 'sun.jvm.hotspot.rmi.port'. Si no se especifica, se utiliza la propiedad del sistema. Si la propiedad del sistema no está establecida, se utiliza el puerto predeterminado 1099.
--hostname nombre_host
Establece el nombre de host al que se enlaza el conector RMI. El valor podría ser un nombre de host o una dirección IPv4/IPv6. Esta opción anula la propiedad del sistema 'java.rmi.server.hostname'. Si no se especifica, se utiliza la propiedad del sistema. Si la propiedad del sistema no está establecida, se utiliza un nombre de host del sistema.

OPCIONES PARA EL MODO JINFO

--flags
Imprime los flags de la VM.
--sysprops
Imprime las propiedades del sistema Java.
sin opción
Imprime los flags de la VM y las propiedades del sistema Java.

OPCIONES PARA EL MODO JMAP

sin opción
Imprime la misma información que el pmap de Solaris.
--heap
Imprime el resumen del heap de java.
--binaryheap
Vuelca el heap de java en formato binario hprof.
--dumpfile nombre
El nombre del archivo de volcado.
--histo
Imprime el histograma del heap de objetos de java.
--clstats
Imprime las estadísticas del cargador de clases.
--finalizerinfo
Imprime la información sobre los objetos que esperan la finalización.
