NOMBRE

josm - Editor Java de OpenStreetMap

SINOPSIS

josm

DESCRIPCIÓN

JOSM es un editor para OpenStreetMap escrito en Java 8.

OpenStreetMap es un proyecto enfocado directamente en la creación y provisión de datos geográficos libres, como mapas de calles, para quien los necesite. Permite ver, editar y usar datos geográficos de forma colaborativa desde cualquier lugar del mundo. El proyecto se inició porque la mayoría de los mapas que consideras libres en realidad tienen restricciones legales o técnicas para su uso, impidiendo que las personas los utilicen de maneras creativas, productivas o inesperadas.

OPCIONES

-h, -?, --help
Mostrar ayuda
--geometry=<ancho>x<alto>(+|-)x(+|-)y
Argumento de geometría X estándar
[--download=]minlat,minlon,maxlat,maxlon
Descargar el cuadro delimitador
[--download=]<url>
Descargar la ubicación en la URL (con lat=x&lon=y&zoom=z)
[--download=]<nombre_archivo>
Abrir archivo (cualquier tipo de archivo que se pueda abrir con Archivo/Abrir)
--downloadgps=minlat,minlon,maxlat,maxlon
Descargar el cuadro delimitador como gps sin procesar
--selection=<cadena_de_búsqueda>
Seleccionar con la búsqueda dada
--[no-]maximizar
No [no] iniciar en modo maximizado
--reset-preferences
Restablecer las preferencias a los valores predeterminados
--load-preferences=<url-a-xml>
Cambiar las preferencias según el archivo XML
--set=<clave>=<valor>
Establecer la clave de preferencia a un valor
--language=<idioma>
Establecer el idioma
--version
Mostrar la versión de JOSM
--status-report
Mostrar informe de estado con información útil que se puede adjuntar a errores
--debug
Imprimir mensajes de depuración en la consola
--offline=<OSM_API|JOSM_WEBSITE|CACHE_UPDATES|CERTIFICATES|ALL>
Desactivar el acceso a los recursos especificados, separados por comas

ARCHIVOS

Los archivos de JOSM se guardan según la Especificación de Directorios Base XDG:

$HOME/.config/JOSM
Preferencias
$HOME/.local/share/JOSM
Datos de usuario
$HOME/.cache/JOSM
Caché
Si el directorio $HOME/.josm existe, todos los archivos se almacenarán allí.

PROPIEDADES DE JAVA

Las siguientes opciones se pueden establecer utilizando propiedades del sistema Java (es decir, -Dkey=value pasado a java, o especificado dentro de JAVA_OPTS).

josm.pref=<ruta>
Establecer el directorio de preferencias de JOSM.
josm.userdata=<ruta>
Establecer el directorio de datos de usuario de JOSM.
josm.cache=<ruta>
Establecer el directorio de caché de JOSM.
josm.home=<directorio_principal>
Reubicar los 3 directorios a <directorio_principal>. El directorio de caché estará en <directorio_principal>/cache.
josm.dir.name=<JOSM>
Cambiar el nombre del directorio de JOSM.

ENTORNO

JAVA_HOME
Especificar un entorno Java alternativo.
JAVA_OPTS
Especificar opciones de Java. Por ejemplo, para usar un servidor proxy HTTP con este programa, establezca esta variable de entorno a algo como JAVA_OPTS="-Dhttp.proxyHost=suURLDeProxy" antes de iniciar josm.

AUTOR

JOSM fue diseñado y codificado originalmente por Immanuel Scholz, y ahora es mantenido por la comunidad de OpenStreetMap.

El mantenedor actual de JOSM es Dirk Stöcker. Gran parte del trabajo de administración es realizado por Paul Hartmann y Vincent Privat.
