NOMBRE

jose jwk exc - Realiza un intercambio de claves utilizando las dos claves de entrada

SINOPSIS

jose jwk exc [-i JWK] -l JWK -r JWK [-o JWK]

DESCRIPCIÓN

El comando jose jwk exc realiza un intercambio de claves utilizando las dos claves de entrada y proporciona el resultado del intercambio como salida. El usuario puede especificar una plantilla JWK como entrada y las propiedades especificadas aparecerán sin modificar en el JWK de salida.

Un intercambio de claves requiere dos claves:

1.La clave local, que generalmente contiene material de clave privada.
2.La clave remota, que generalmente contiene material de clave pública.

El algoritmo para el intercambio se infiere de las entradas.

El algoritmo ECDH realiza una multiplicación estándar de curva elíptica de tal manera que el valor público de \p rem se multiplica por el valor privado de \p.

El algoritmo ECMR tiene tres modos de operación. Donde la clave local tiene una clave privada (la propiedad "d"), funciona exactamente como ECDH. Si la clave local no tiene una clave privada y la clave remota tiene una clave privada, se realiza una suma de curva elíptica sobre los dos valores. De lo contrario, si ni la clave local ni la clave remota tienen una clave privada, la clave remota se resta de la clave local utilizando la resta de curva elíptica. ¡Al usar ECMR, asegúrese de validar el contenido de sus entradas para evitar activar la operación incorrecta!

OPCIONES

•-i JSON, --input=JSON : Analiza la plantilla JWK desde JSON
•-i ARCHIVO, --input=ARCHIVO : Lee la plantilla JWK desde ARCHIVO
•-i -, --input=- : Lee la plantilla JWK desde la entrada estándar
•-o ARCHIVO, --output=ARCHIVO : Escribe JWK(Set) en ARCHIVO
•-o -, --output=- : Escribe JWK(Set) en la entrada estándar
•-l ARCHIVO, --local=ARCHIVO : Lee la JWK local desde ARCHIVO
•-l -, --local=- : Lee la JWK local desde la entrada estándar
•-r ARCHIVO, --remote=ARCHIVO : Lee la JWK remota desde ARCHIVO
•-r -, --remote=- : Lee la JWK remota desde la entrada estándar

EJEMPLOS

Realiza un intercambio de claves:

$ jose jwk gen -i '{"alg":"ECDH"}' -o local.jwk
$ jose jwk gen -i '{"alg":"ECDH"}' | jose jwk pub -i- -o remote.jwk
$ jose jwk exc -l local.jwk -r remote.jwk -o exchanged.jwk
