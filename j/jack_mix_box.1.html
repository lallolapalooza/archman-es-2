NOMBRE

jack_mix_box - Un mezclador de audio JACK minimalista con control de volumen MIDI

SINOPSIS

jack_mix_box [-n <nombre>] [-p] [-s] [-v <dB>] MIDI_CC...

DESCRIPCIÓN

Esta página del manual documenta el comando jack_mix_box.

jack_mix_box es una versión minimalista y sin GUI de jack_mixer. Crea un cliente JACK con puertos de salida estéreo y un número fijo de puertos de entrada mono o estéreo. El número de puertos de entrada y el mensaje de Cambio de Control MIDI que controla el nivel de volumen de cada uno se establecen a través de la línea de comandos. La señal de cada canal de entrada se mezcla en las salidas estéreo.

OPCIONES

Argumentos posicionales:

MIDI_CC... añade un canal de entrada controlado por MIDI_CC

Argumentos opcionales:

-h, --help
imprime este mensaje de ayuda
-n, --name
establece el nombre del cliente JACK
-p, --pickup
habilita el modo de captura MIDI (por defecto: saltar a valor)
-s, --stereo
hace que todos los canales de entrada sean estéreo con entrada izquierda+derecha
-v, --volume
ganancia de volumen inicial en dBFS (por defecto 0.0, es decir, ganancia unitaria)

USO

Cada argumento posicional se interpreta como un número de Cambio de Control MIDI y añade un canal mezclador con una (mono) o dos (estéreo) entradas, cuyo volumen puede ser controlado a través del Cambio de Control MIDI dado.

Utilice jack_connect o cualquier otro gestor de conexiones JACK para conectar otros clientes JACK o puertos del sistema a los puertos de entrada y salida.

Envíe una señal SIGUSR1 al proceso jack_mix_box para que los volúmenes actuales por canal de entrada se informen a la salida estándar.

PUERTOS DE AUDIO Y MIDI DE JACK

  • Para cada canal de entrada, jack_mix_box creará uno (si es un canal mono) o dos (estéreo) puertos de entrada de audio JACK. Los puertos de entrada se nombrarán "Channel <n>", donde "<n>" es el número del canal, y tendrán un sufijo " L" o " R", si el canal es estéreo.
  • Creará dos puertos de salida de audio JACK llamados "MAIN L" y "MAIN R".
  • También creará un puerto de entrada MIDI JACK ("midi in") y un puerto de salida MIDI ("midi out").

ENTORNO

LANGUAGE, LC_ALL, LC_MESSAGES y LANG
La primera de estas variables de entorno establecida a un valor no vacío se utiliza para determinar los idiomas para cargar los archivos de traducción gettext. El valor debe ser una lista de códigos de idioma separados por dos puntos.
LC_NUMERIC
El idioma establecido a través de esta variable de entorno determina el formato de número de punto flotante utilizado para analizar los niveles de volumen dados en la línea de comandos y para formatearlos en la salida. Si LC_NUMERIC no está establecido, su valor se hereda de una de las variables de entorno de idioma descritas anteriormente.
LOCALEDIR
Con esta variable de entorno, el directorio base para los archivos de traducción gettext se puede cambiar del valor predeterminado establecido en tiempo de compilación, que suele ser <prefix>/share/locale.

SEÑALES

SIGUSR1
Envíe SIGUSR1 al proceso jack_mix_box para que los volúmenes actuales por canal de entrada se informen.
