NOMBRE

jgmenu-i18n - soporte para la traducción de datos de menú CSV con formato jgmenu

SINOPSIS

jgmenu_run i18n <archivo-traducción>

jgmenu_run i18n --init [<archivo-traducción>]

DESCRIPCIÓN

jgmenu_run i18n lee datos de menú CSV con formato jgmenu desde stdin y los traduce, o crea un archivo de traducción estilo po

El argumento <archivo-traducción> puede ser un archivo o un directorio. Si es lo último, los archivos de traducción se buscarán en este directorio basándose en la variable de entorno $LANG, que se asumirá en el formato ll_CC.UTF8 donde ll es un código de idioma de dos letras ISO 639 y CC es un código de país de dos letras ISO 3166. Los archivos llamados ll_CC y ll se usarán en dicho orden.

OPCIONES

--init
Crear una plantilla de archivo de traducción estilo po con entradas msgid en blanco

EJEMPLOS

Crear plantilla de archivo de traducción para traducción manual

Los módulos jgmenu-apps(1) y jgmenu-ob(1) tienen soporte i18n incorporado. Para usar estas características, se requiere un archivo de traducción. A continuación se muestran ejemplos de cómo se puede crear un archivo de traducción:

Ejemplo 1.

jgmenu_run ob | jgmenu_run i18n --init >sv

Ejemplo 2.

jgmenu_run i18n --init <prepend.csv >sv

El resultado de los comandos anteriores sería un archivo de traducción esqueleto (sv en este caso) que contiene entradas como esta:

msgid "Web Browser"
msgstr ""

Traducir manualmente los campos msgstr vacíos.

Usar archivo de traducción

Si usa los módulos jgmenu-apps(1) o jgmenu-ob(1), simplemente establezca csv_i18n en jgmenurc para que apunte directamente a un archivo de traducción o a un directorio que contenga archivos de traducción.

En circunstancias especiales, puede desear incluir i18n en tuberías de comandos. A continuación se muestra un ejemplo de cómo se podría construir esto:

<comando-generador-csv> \
    | jgmenu_run i18n <archivo-traducción> \
    | jgmenu --vsimple
