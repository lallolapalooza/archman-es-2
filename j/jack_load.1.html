NOMBRE

jack_load - Cliente de la toolkit JACK para cargar clientes en proceso

SINOPSIS

jack_load [ -i cadena_inicializacion ] [ -s nombre_servidor ] [-w ] nombre_cliente nombre_so [ cadena_inicializacion ]

DESCRIPCIÓN

jack_load es un cliente de la toolkit JACK. Carga el plugin especificado y crea un cliente en proceso.

ARGUMENTOS

El nombre_cliente debe ser un nombre de cliente actualmente no utilizado.

El nombre_so es el nombre del archivo donde se almacena el código del cliente (típicamente, nombrecliente.so)

OPCIONES

-i, --init cadena_inicializacion

cadena de inicialización que se pasa al cliente en proceso. Nótese que esto también se puede especificar como el último argumento en la línea de comandos.
-s, --server nombre_servidor

Nombre del servidor JACK al que conectarse
-w, --wait
Espera una señal (ej. desde Ctrl-c) y luego descarga el cliente.
