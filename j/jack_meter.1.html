NOMBRE

jack_meter - Medidor de picos digital basado en consola para JACK

SINOPSIS

jack_meter [ -f frecuencia ] [ -r nivel-referencia ] [ -w ancho ] [-n ] [ <puerto>, ... ]
jack_meter -h

DESCRIPCIÓN

jack_meter es un medidor de picos digital (DPM) básico basado en consola. Lo escribí para comprobar rápidamente los niveles de señal remotos, sin tener que ejecutar X11 para usar un medidor gráfico atractivo como meterbridge.

El parámetro de puerto es opcional; si falta, tendrás que conectar el medidor a un puerto de entrada manualmente. Si se especifican varios puertos, las entradas se mezclan.

OPCIONES

-f frecuencia

Cuántas veces por segundo actualizar el medidor. El valor predeterminado es 8.
-r nivel-referencia

El nivel de señal de referencia para 0dB en el medidor.
-w ancho

El ancho del medidor (número de caracteres). El valor predeterminado es 79, uno menos que el ancho típico de la terminal. -n
Emite el nivel del medidor como un número en decibelios en lugar de una visualización de gráfico de barras.
