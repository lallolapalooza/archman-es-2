JALV.GTK3(1) Manual de comandos generales JALV.GTK3(1)

NOMBRE

jalv.gtk - Ejecuta un plugin LV2 como una aplicación JACK (versión Gtk3).

SINOPSIS

jalv.gtk [OPCIÓN]... URI_DEL_PLUGIN

OPCIONES

-b TAMAÑO
Tamaño del búfer para la comunicación plugin <=> UI.
-c SYM=VAL
Establece el valor de un control (p. ej., "vol=1.4").
-d, --dump
Volcar la comunicación plugin <=> UI.
-U URI
Cargar la UI con la URI dada.
-g, --generic-ui
Usar la UI genérica de Jalv y no la UI del plugin.
-h, --help
Imprimir las opciones de la línea de comandos.
-l DIR, --load DIR
Cargar estado desde el directorio de estado.
-p, --print-controls
Imprimir los cambios de salida de control en stdout.
-t, --trace
Imprimir mensajes de rastreo del plugin.

VER TAMBIÉN

jalv(1), jalv.gtk(1), jalv.qt5(1), lv2ls(1), jackd(1)
