NOMBRE

jadmaker - Generador de Archivos JAD

SINOPSIS

jadmaker [-f|--force] [-u|--url URL] <archivo.jar>...

DESCRIPCIÓN

Script para generar el archivo JAD a partir del archivo JAR.

Este programa sigue la sintaxis de línea de comandos habitual de GNU, con opciones largas que comienzan con dos guiones (-). A continuación se incluye un resumen de las opciones.

-h, --help
Muestra un resumen de las opciones.
-f, --force
Fuerza la reescritura del archivo JAD, incluso si ya existe.
-u, --url URL
Define la URL a incluir en el archivo JAD.
