JMAP(1) Comandos JDK JMAP(1)

NOMBRE

jmap - imprime detalles de un proceso especificado

SINOPSIS

Nota: Este comando es experimental y no está soportado.

jmap [opciones] pid

opciones
Esto representa las opciones de línea de comandos de jmap. Ver OPCIONES PARA EL COMANDO jmap.
pid
El ID del proceso para el cual se imprimirán los detalles especificados por las opciones. El proceso debe ser un proceso Java. Para obtener una lista de procesos Java en ejecución en una máquina, use el comando ps o, si los procesos JVM no se ejecutan en una instancia de docker separada, el comando jps.

DESCRIPCIÓN

El comando jmap imprime detalles de un proceso en ejecución especificado.

Nota:

Este comando no está soportado y podría no estar disponible en futuras versiones del JDK. En sistemas Windows donde el archivo dbgeng.dll no está presente, las Herramientas de Depuración para Windows deben estar instaladas para que estas herramientas funcionen. La variable de entorno PATH debe contener la ubicación del archivo jvm.dll que es utilizado por el proceso objetivo o la ubicación desde la cual se produjo el archivo de volcado principal (core dump).

OPCIONES PARA EL COMANDO jmap

-clstats pid
Se conecta a un proceso en ejecución e imprime estadísticas de los cargadores de clases del montón (heap) de Java.
-finalizerinfo pid
Se conecta a un proceso en ejecución e imprime información sobre objetos pendientes de finalización.
-histo[:live] pid
Se conecta a un proceso en ejecución e imprime un histograma del montón de objetos Java. Si se especifica la subopción live, entonces cuenta solo los objetos vivos.
-dump:opciones_dump pid
Se conecta a un proceso en ejecución y vuelca el montón de Java. Las opciones_dump incluyen:
•
live --- Cuando se especifica, solo vuelca los objetos vivos; si no se especifica, entonces vuelca todos los objetos en el montón.
•
format=b --- Vuelca el montón de Java en formato binario hprof.
•
file=nombre_archivo --- Vuelca el montón en nombre_archivo.

Ejemplo: jmap -dump:live,format=b,file=heap.bin pid
