NOMBRE

jgmenu_run - Un script de envoltura para jgmenu

SINOPSIS

jgmenu_run

jgmenu_run <comando>

jgmenu_run <opción>

DESCRIPCIÓN

Usar sin un comando o opción para lanzar el menú. Si una instancia de jgmenu ya se está ejecutando, esta se hará visible (=se mostrará), de lo contrario se iniciará una nueva instancia.

Usar con un comando para llamar a cualquier programa en $libexecdir/jgmenu el cual contiene programas ejecutables diseñados para ser ejecutados por jgmenu en lugar de directamente por los usuarios.

OPCIONES

--help
Imprime el mensaje de ayuda
--exec-path
Imprime la ruta a $libexecdir/jgmenu, que es donde se instalan los comandos de jgmenu.

EJEMPLOS

Lanzar el menú

jgmenu_run

Ejecuta lo siguiente para ver todos los comandos de jgmenu_run:

ls $(jgmenu_run --exec-path)
