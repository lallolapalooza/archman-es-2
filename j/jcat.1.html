JCAT(1) Manual de Comandos Generales JCAT(1)

NOMBRE

jcat - Muestra el contenido de un bloque en el diario del sistema de archivos.

SINOPSIS

jcat [-f tipo_fs ] [-vV] [-i tipo_img] [-o desplazamiento_img] [-b tamaño_sector_dev ] imagen [imágenes] ] [ inodo ] jblk

DESCRIPCIÓN

jcat muestra el contenido de un bloque del diario en el diario del sistema de archivos. Se puede proporcionar la dirección del inodo del diario o se utilizará la ubicación predeterminada. Tenga en cuenta que la dirección del bloque es una dirección de bloque del diario y no una del sistema de archivos. La salida bruta se envía a STDOUT.

ARGUMENTOS

-f tipo_fs
Especifica el tipo de sistema de archivos. Utilice '-f list' para listar los tipos de sistemas de archivos compatibles. Si no se proporciona, se utilizan métodos de autodetección.
-i tipo_img
Identifica el tipo de archivo de imagen, como raw. Utilice '-i list' para listar los tipos compatibles. Si no se proporciona, se utilizan métodos de autodetección.
-o desplazamiento_img
El desplazamiento de sector donde comienza el sistema de archivos en la imagen.
-b tamaño_sector_dev
El tamaño, en bytes, de los sectores del dispositivo subyacente. Si no se proporciona, se utiliza el valor del formato de imagen (si existe) o se asumen 512 bytes.
-V
Muestra la versión
-v
salida detallada
imagen [imágenes]
La imagen del disco o partición a leer, cuyo formato se proporciona con '-i'. Se pueden proporcionar varios nombres de archivo de imagen si la imagen está dividida en varios segmentos. Si solo se proporciona un archivo de imagen y su nombre es el primero de una secuencia (por ejemplo, si termina en '.001'), se incluirán automáticamente los segmentos de imagen posteriores.
[inodo]
El inodo donde se puede encontrar el diario del sistema de archivos.
jblk
El bloque de diario a mostrar.

EJEMPLOS

jcat -f linux-ext3 img.dd 34 | xxd
