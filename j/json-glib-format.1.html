NOMBRE

json-glib-format - Herramienta de formato JSON

SINOPSIS

json-glib-format [OPCIONES...] <ARCHIVO> [<ARCHIVO>...]

DESCRIPCIÓN

json-glib-format ofrece una interfaz de línea de comandos sencilla para dar formato a datos JSON. Lee una lista de archivos o URIs, aplica las reglas de formato especificadas a los datos JSON y emite el JSON formateado a la salida estándar o a un archivo.

Los recursos sobre los que operar se especifican mediante el argumento ARCHIVO.

OPCIONES

-h, --help

Imprime un mensaje de ayuda y sale.

--output=ARCHIVO

Redirige la salida al ARCHIVO en lugar de usar la salida estándar.

-p, --prettify

Mejora la legibilidad de la salida, añadiendo espacios e indentación. Este argumento es útil para mejorar la legibilidad de los datos JSON, a expensas de su tamaño.

--indent-spaces=ESPACIOS

Cambia el número de espacios utilizados para indentar los datos JSON, que por defecto es 2. Este argumento solo se considera si se utiliza --prettify.
