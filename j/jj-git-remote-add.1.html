NOMBRE

jj-git-remote-add - Añadir un remoto Git

SINOPSIS

jj git remote add [--fetch-tags] [-R|--repository] [--ignore-working-copy] [--ignore-immutable] [--at-operation] [--debug] [--color] [--quiet] [--no-pager] [--config] [--config-file] [-h|--help] <REMOTE> <URL>

DESCRIPCIÓN

Añadir un remoto Git

OPCIONES

--fetch-tags <FETCH_TAGS> [valor predeterminado: included]
Configurar cuándo buscar etiquetas

Valores posibles:

  • all: Buscar siempre todas las etiquetas
  • included: Buscar solo etiquetas que apunten a objetos que ya se están transmitiendo
  • none: No buscar ninguna etiqueta
-h, --help
Imprimir ayuda (ver un resumen con '-h')
<REMOTE>
El nombre del remoto
<URL>
La URL o ruta del remoto

La ruta local se resolverá a su forma absoluta.

OPCIONES GLOBALES

-R, --repository <REPOSITORY>
Ruta al repositorio sobre el que operar

Por defecto, Jujutsu busca el directorio .jj/ más cercano en un ancestro del directorio de trabajo actual.

--ignore-working-copy
No capturar una instantánea del directorio de trabajo y no actualizarlo

Por defecto, Jujutsu captura una instantánea del directorio de trabajo al principio de cada comando. El directorio de trabajo también se actualiza al final del comando, si el comando modificó el commit del directorio de trabajo (`@`). Si deseas evitar capturar una instantánea del directorio de trabajo y en su lugar ver un commit del directorio de trabajo posiblemente obsoleto, puedes usar `--ignore-working-copy`. Esto puede ser útil, por ejemplo, en un prompt de comando, especialmente si tienes otro proceso que confirma el directorio de trabajo.

Cargar el repositorio en una operación específica con `--at-operation` implica `--ignore-working-copy`.

--ignore-immutable
Permitir reescribir commits inmutables

Por defecto, Jujutsu evita reescribir commits en el conjunto configurado de commits inmutables. Esta opción deshabilita esa verificación y te permite reescribir cualquier commit excepto el commit raíz.

Esta opción solo afecta a la verificación. No afecta al revset `immutable_heads()` ni a la palabra clave de plantilla `immutable`.

--at-operation <AT_OPERATION>
Operación en la que cargar el repositorio

Operación en la que cargar el repositorio. Por defecto, Jujutsu carga el repositorio en la operación más reciente, o en la fusión de las operaciones divergentes si las hay.

Puedes usar `--at-op=<ID de operación>` para ver cómo era el repositorio en una operación anterior. Por ejemplo, `jj --at-op=<ID de operación> st` te mostrará lo que `jj st` habría mostrado cuando la operación dada acababa de finalizar. `--at-op=@` es prácticamente lo mismo que el valor predeterminado, excepto que las operaciones divergentes nunca se fusionarán.

Usa `jj op log` para encontrar el ID de operación que deseas. Cualquier prefijo no ambiguo del ID de operación es suficiente.

Al cargar el repositorio en una operación anterior, se ignorará el directorio de trabajo, como si se hubiera especificado `--ignore-working-copy`.

Es posible ejecutar comandos mutables al cargar el repositorio en una operación anterior. Hacer eso es equivalente a haber ejecutado comandos concurrentes que comenzaron en la operación anterior. Rara vez hay una razón para hacerlo, pero es posible.

--debug
Habilitar el registro de depuración
--color <WHEN>
Cuándo colorear la salida

[valores posibles: always, never, debug, auto]

--quiet
Silenciar la salida no primaria del comando

Por ejemplo, `jj file list` seguirá listando archivos, pero no te dirá si se capturó una instantánea del directorio de trabajo o si los descendientes fueron rebasados.

Las advertencias y errores seguirán imprimiéndose.

--no-pager
Deshabilitar el paginador
--config <NAME=VALUE>
Opciones de configuración adicionales (se pueden repetir)

El nombre debe especificarse como claves separadas por puntos de TOML. El valor debe especificarse como una expresión TOML. Si el valor de cadena no está encerrado por ningún constructo TOML (como la notación de array), las comillas se pueden omitir.

--config-file <PATH>
Archivos de configuración adicionales (se pueden repetir)
add
