JACK-STDIN(1) Manual de Comandos Generales JACK-STDIN(1)

NOMBRE

jack-stdin - escribe datos de audio JACK a la entrada estándar

SINOPSIS

jack-stdin [OPCIONES] puerto1 [ puerto2 ...]

DESCRIPCIÓN

jack-stdin lee datos de audio en bruto de la entrada estándar y los escribe en un puerto de audio JACK.

El número de puertos proporcionados determina el número de canales de audio que se utilizarán. Si se proporciona más de un canal, los datos de muestras de audio de entrada deben estar intercalados.

OPCIONES

-b, --bitdepth BITS
Especifica la profundidad de bits de cada muestra. Para la codificación de enteros, pueden ser 16 o 24. El valor predeterminado es 16. Esta configuración solo se utiliza para la codificación de enteros: las muestras de punto flotante siempre tendrán 32 bits de ancho.
-d, --duration SEG
Especifica el tiempo durante el cual se ejecutará jack-stdin en segundos. Un valor menor que 1 significa que se ejecutará indefinidamente. El valor predeterminado es 0, que lee hasta el final del archivo.
-e, --encoding FORMATO
Establece el formato de entrada de los datos: entero con signo, entero sin signo, punto flotante (predeterminado: con signo).
-n, --name NOMBRECLIENTE
Establece el nombre del cliente JACK (predeterminado: jstdin).
-f, --file NOMBREARCHIVO
Lee los datos del archivo proporcionado en lugar de la entrada estándar.
-h, --help
Imprime información de uso breve.
-p, --prebuffer PORCENTAJE
Pre-rellena el búfer antes de iniciar la salida de audio a JACK (predeterminado 50.0%). NOTA: desactiva el pre-relleno (-p 0) o usa un tamaño de búfer pequeño para reproducir muestras muy cortas.
-L, --little-endian
Los datos de entrada están en orden de bytes little-endian o en punto flotante de orden de bytes nativo (este es el valor predeterminado).
-B, --big-endian
Interpreta los datos de audio de entrada en orden de bytes big-endian o invierte el orden de bytes de punto flotante.
-q, --quiet
Inhibe la salida habitual. Esto afecta la información y las advertencias de desbordamiento del búfer, pero no los errores de configuración.
-S, --bufsize MUESTRAS
Elige el tamaño del búfer interno en muestras. El tamaño predeterminado es 65536. El valor dado se multiplicará por el número de canales y la profundidad de bits para obtener el tamaño del búfer circular. Nota: el tamaño del búfer debe ser mayor que el tamaño del período de JACK.

EJEMPLOS

  jack-stdout vlc_31994:out_1 vlc_31994:out_2 \
	| sox -t raw -r 48k -e signed -b 16 -c 2 - \
	      -t raw -r 48k -e signed -b 16 -c 2 - \
	   tremolo 5 100 \
	| ./jack-stdin system:playback_1 system:playback_2
  cat /dev/dsp \
	| jack-stdin system:playback_1 system:playback_2

PROBLEMAS CONOCIDOS

jack-stdin no es adecuado para reproducir archivos más cortos que el doble del tamaño del período de JACK.
