NOMBRE

jose-jwk-use - Valida una clave para el uso o usos especificados

SINOPSIS

jose jwk use -i JWK [-a] [-r] -u OP

DESCRIPCIÓN

El comando jose jwk use valida una o más entradas JWK(Set) para un conjunto dado de usos. Esto se validará contra las propiedades "use" y "key_ops" de cada JWK.

Por defecto, si un JWK no tiene restricciones, se permitirá una operación. Sin embargo, al especificar la opción -r, puedes asegurar que un JWK no se permitirá a menos que permita explícitamente la opción.

En operación normal, jose jwk use fallará si alguno de los JWKs no se valida. Sin embargo, si se utiliza la opción -o, jose jwk use escribirá un JWK(Set) que contiene todas las claves de entrada que se validan. Si ningún JWK se valida, el comando fallará.

OPCIONES

•-i JSON, --input=JSON : Analiza JWK(Set) desde JSON
•-i ARCHIVO, --input=ARCHIVO : Lee JWK(Set) desde ARCHIVO
•-i -, --input=- : Lee JWK(Set) de la entrada estándar
•-u sign, --use=sign : Valida la clave para firmar
•-u verify, --use=verify : Valida la clave para verificar
•-u encrypt, --use=encrypt : Valida la clave para cifrar
•-u decrypt, --use=decrypt : Valida la clave para descifrar
•-u wrapKey, --use=wrapKey : Valida la clave para envolver
•-u unwrapKey, --use=unwrapKey : Valida la clave para desenvolver
•-u deriveKey, --use=deriveKey : Valida la clave para derivar claves
•-u deriveBits, --use=deriveBits : Valida la clave para derivar bits
•-a, --all : Solo tiene éxito si todas las operaciones están permitidas
•-r, --required : Las operaciones deben estar explícitamente permitidas
•-o ARCHIVO, --output=ARCHIVO : Filtra claves a ARCHIVO como JWK(Set)
•-o -, --output=- : Filtra claves a la salida estándar como JWK(Set)
•-s, --set : Siempre genera un JWKSet

EJEMPLOS

Ejemplos de éxito y fallo de una clave privada y una pública:

$ jose jwk gen -i '{"alg":"ES256"}' -o prv.jwk
$ jose jwk pub -i prv.jwk -o pub.jwk
$ jose jwk use -i prv.jwk -u sign
$ echo $?
0
$ jose jwk use -i pub.jwk -u sign
$ echo $?
1
