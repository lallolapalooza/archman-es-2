NOMBRE

julia - dibuja fractales de conjuntos de julia giratorios y animados

SINOPSIS

julia [--display host:display.screen] [--foreground color] [--background color] [--window] [--root] [--window-id número][--mono] [--install] [--visual visual] [--ncolors entero] [--delay microsegundos] [--cycles entero] [--count entero]

[--fps]

DESCRIPCIÓN

El programa julia dibuja fractales de conjuntos de julia giratorios y animados.

Utiliza ifs {w0 = sqrt(x-c), w1 = -sqrt(x-c)} con iteración aleatoria para trazar el conjunto de julia, y parámetros variados sinusoidalmente para el conjunto, y traza parámetros con un círculo.

Una cosa a tener en cuenta es que count es la profundidad del árbol de búsqueda, por lo que el número de puntos calculados es (2^count)-1. Yo uso 8 o 9 en un dx266 y se ve bien. La variación sinusoidal del parámetro podría no ser tan interesante como podría ser, pero aún así da una idea del efecto del parámetro.

Arrastrar el ratón en la ventana utiliza la posición del ratón como punto de control para la generación del conjunto.

OPCIONES

julia acepta las siguientes opciones:

--window
Dibuja en una ventana recién creada. Esta es la opción por defecto.
--root
Dibuja en la ventana raíz.
--window-id número
Dibuja en la ventana especificada.
--mono
Si se está en una pantalla a color, simula estar en una pantalla monocroma.
--install
Instala un mapa de colores privado para la ventana.
--visual visual
Especifica qué visual utilizar. Los valores legales son el nombre de una clase visual, o el número de id (decimal o hexadecimal) de un visual específico.
--ncolors entero
Cuántos colores se deben usar (si es posible). Por defecto 200. Los colores utilizados recorren el matiz, haciendo N paradas alrededor de la rueda de colores.
--cycles entero
--count entero
--fps
Muestra la tasa de fotogramas actual y la carga de la CPU.

AMBIENTE

DISPLAY
para obtener el host y número de pantalla por defecto.
XENVIRONMENT
para obtener el nombre de un archivo de recursos que anule los recursos globales almacenados en la propiedad RESOURCE_MANAGER.
XSCREENSAVER_WINDOW
El ID de ventana a usar con --root.
