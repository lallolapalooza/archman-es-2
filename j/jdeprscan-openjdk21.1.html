jdeprscan es una herramienta de análisis estático proporcionada por el JDK que escanea un archivo JAR u otra agregación de archivos de clase en busca de usos de elementos de API obsoletos. Las API obsoletas identificadas por la herramienta jdeprscan son solo aquellas que están definidas por Java SE. Las API obsoletas definidas por bibliotecas

de

terceros no se reportan. Para escanear un archivo JAR o un conjunto de archivos de clase, primero debe asegurarse de que todas las clases de las que dependen las clases escaneadas estén presentes en la ruta de clases. Establezca la ruta de clases usando la opción --class-path descrita en Opciones para el comando jdeprscan. Normalmente, usaría la misma ruta de clases

que

la que usa al invocar su aplicación. Si jdeprscan no puede encontrar todas las clases dependientes, generará un mensaje de error por cada clase que falte. Estos mensajes de
