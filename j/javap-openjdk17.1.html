DESCRIPCIÓ

N

El comando javap desensambla uno o más archivos de clase. La salida depende de las opciones utilizadas. Cuando no se usan opciones, el comando javap imprime los campos y métodos protegidos y públicos de las clases que se le

pasan.

El comando javap no es consciente de los JAR de múltiples versiones. El uso de la forma de ruta de clases del comando resulta en ver la entrada base en todos los archivos JAR, sean de múltiples versiones o no. Usando la forma URL, puede usar la forma URL de un argumento para especificar una versión específica de una clase a

desensamblar.

El comando javap imprime su salida en stdout

.

:
