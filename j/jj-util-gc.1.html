NOMBRE

jj-util-gc - Ejecuta la recolección de basura dependiente del backend

SINOPSIS

jj util gc [--expire] [-R|--repository] [--ignore-working-copy] [--ignore-immutable] [--at-operation] [--debug] [--color] [--quiet] [--no-pager] [--config] [--config-file] [-h|--help]

DESCRIPCIÓN

Ejecuta la recolección de basura dependiente del backend.

Para recolectar la basura de operaciones antiguas y los commits/objetos referenciados por ellas, ejecuta `jj op abandon ..<alguna operación antigua>` antes de `jj util gc`.

OPCIONES

--expire <EXPIRE>
Umbral de tiempo

Por defecto, solo se eliminan objetos obsoletos y operaciones anteriores a 2 semanas.

Solo la cadena de texto "now" se puede pasar a este parámetro. El soporte para marcas de tiempo absolutas y relativas arbitrarias vendrá en una versión posterior.

-h, --help
Imprime la ayuda (ver un resumen con '-h')

OPCIONES GLOBALES

-R, --repository <REPOSITORY>
Ruta al repositorio sobre el que operar

Por defecto, Jujutsu busca el directorio .jj/ más cercano en un ancestro del directorio de trabajo actual.

--ignore-working-copy
No hagas snapshot de la copia de trabajo y no la actualices

Por defecto, Jujutsu hace snapshot de la copia de trabajo al principio de cada comando. La copia de trabajo también se actualiza al final del comando, si el comando modificó el commit de la copia de trabajo (`@`). Si deseas evitar hacer snapshot de la copia de trabajo y ver en su lugar un commit de copia de trabajo posiblemente obsoleto, puedes usar `--ignore-working-copy`. Esto puede ser útil, por ejemplo, en una línea de comandos, especialmente si tienes otro proceso que confirma la copia de trabajo.

Cargar el repositorio en una operación específica con `--at-operation` implica `--ignore-working-copy`.

--ignore-immutable
Permite reescribir commits inmutables

Por defecto, Jujutsu previene la reescritura de commits en el conjunto configurado de commits inmutables. Esta opción deshabilita esa comprobación y te permite reescribir cualquier commit excepto el commit raíz.

Esta opción solo afecta la comprobación. No afecta el revset `immutable_heads()` ni la palabra clave de plantilla `immutable`.

--at-operation <AT_OPERATION>
Operación en la que cargar el repo

Operación en la que cargar el repo. Por defecto, Jujutsu carga el repo en la operación más reciente, o en la fusión de las operaciones divergentes si las hay.

Puedes usar `--at-op=<ID de operación>` para ver cómo era el repo en una operación anterior. Por ejemplo, `jj --at-op=<ID de operación> st` te mostrará lo que `jj st` habría mostrado cuando la operación dada acababa de finalizar. `--at-op=@` es prácticamente lo mismo que el valor predeterminado, excepto que las operaciones divergentes nunca se fusionarán.

Usa `jj op log` para encontrar el ID de operación que deseas. Cualquier prefijo no ambiguo del ID de operación es suficiente.

Al cargar el repo en una operación anterior, se ignorará la copia de trabajo, como si se hubiera especificado `--ignore-working-copy`.

Es posible ejecutar comandos mutantes al cargar el repo en una operación anterior. Hacerlo es equivalente a haber ejecutado comandos concurrentes que comenzaron en la operación anterior. Rara vez hay una razón para hacerlo, pero es posible.

--debug
Habilita el registro de depuración
--color <WHEN>
Cuándo colorear la salida

[valores posibles: always, never, debug, auto]

--quiet
Silencia la salida no primaria del comando

Por ejemplo, `jj file list` seguirá listando archivos, pero no te dirá si la copia de trabajo se ha snapshotado o si los descendientes han sido rebasados.

Las advertencias y los errores seguirán imprimiéndose.

--no-pager
Deshabilita el paginador
--config <NAME=VALUE>
Opciones de configuración adicionales (se pueden repetir)

El nombre debe especificarse como claves punteadas de TOML. El valor debe especificarse como una expresión TOML. Si el valor de cadena no está delimitado por ninguna construcción de TOML (como la notación de array), se pueden omitir las comillas.

--config-file <PATH>
Archivos de configuración adicionales (se pueden repetir)
gc
