jconsole(1) Herramientas de resolución de problemas, perfilado, supervisión y gestión de Java jconsole(1)

NOMBRE

jconsole - Inicia una consola gráfica que permite supervisar y gestionar aplicaciones Java.

SINOPSIS

jconsole [ opciones ] [ conexión ... ]
opciones
Las opciones de línea de comandos. Ver Opciones.
conexión = pid | host:puerto | URL_jmx
El valor pid es el ID del proceso de una Máquina Virtual Java (JVM) local. La JVM debe estar ejecutándose con el mismo ID de usuario que el usuario que ejecuta el comando jconsole. Los valores host:puerto son el nombre del sistema host en el que se ejecuta la JVM y el número de puerto especificado por la propiedad del sistema com.sun.management.jmxremote.port cuando se inició la JVM. El valor URL_jmx es la dirección del agente JMX al que conectarse, según se describe en JMXServiceURL.

Para obtener más información sobre el parámetro conexión, consulte Monitorización y gestión utilizando la tecnología JMX en http://docs.oracle.com/javase/8/docs/technotes/guides/management/agent.html

Consulte también la descripción de la clase JMXServiceURL en http://docs.oracle.com/javase/8/docs/api/javax/management/remote/JMXServiceURL.html

DESCRIPCIÓN

El comando jconsole inicia una herramienta de consola gráfica que permite supervisar y gestionar aplicaciones y máquinas virtuales Java en una máquina local o remota.

En Windows, el comando jconsole no se asocia con una ventana de consola. Sin embargo, muestra un cuadro de diálogo con información de errores cuando el comando jconsole falla.

OPCIONES

-intervalo=n

Establece el intervalo de actualización en n segundos (el valor predeterminado es 4 segundos).
-notile

No organiza las ventanas inicialmente (para dos o más conexiones).
-rutadecomplementos complementos

Especifica una lista de directorios o archivos JAR en los que buscar complementos de JConsole. La ruta de complementos debe contener un archivo de configuración del proveedor llamado META-INF/services/com.sun.tools.jconsole.JConsolePlugin que contenga una línea por cada complemento. La línea especifica el nombre de clase completamente calificado de la clase que implementa la clase com.sun.tools.jconsole.JConsolePlugin.
-version

Muestra la información de la versión y sale.
-help

Muestra un mensaje de ayuda.
-Jindicador

Pasa indicador a la JVM en la que se ejecuta el comando jconsole.
