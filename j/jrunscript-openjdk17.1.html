JRUNSCRIPT(1) Comandos JDK JRUNSCRIPT(1)

NOMBRE

jrunscript - ejecuta un intérprete de scripts de línea de comandos que soporta modos interactivo y por lotes

SINOPSIS

Nota:

Esta herramienta es experimental y no tiene soporte.

jrunscript [opciones] [argumentos]

opciones
Esto representa las opciones de línea de comandos de jrunscript que se pueden usar. Ver Opciones para el comando jrunscript.
argumentos
Los argumentos, cuando se usan, siguen inmediatamente a las opciones o al nombre del comando. Ver Argumentos.

DESCRIPCIÓN

El comando jrunscript es un intérprete de scripts de línea de comandos independiente del lenguaje. El comando jrunscript soporta tanto un modo interactivo (leer-evaluar-imprimir) como un modo de ejecución de scripts por lotes (opción -f). Por defecto, JavaScript es el lenguaje utilizado, pero la opción -l se puede usar para especificar un lenguaje diferente. Al utilizar Java para la comunicación con el lenguaje de scripting, el comando jrunscript soporta un estilo de programación exploratoria.

Si se utiliza JavaScript, entonces antes de evaluar un script definido por el usuario, el comando jrunscript inicializa ciertas funciones y objetos incorporados, que están documentados en la Especificación de la API para funciones incorporadas de JavaScript de jrunscript.

OPCIONES PARA EL COMANDO JRUNSCRIPT

-cp ruta o -classpath ruta
Indica dónde se encuentran los archivos de clase a los que el script necesita acceder.
-Dnombre=valor
Establece una propiedad del sistema Java.
-Jflag
Pasa flag directamente a la Máquina Virtual Java donde se está ejecutando el comando jrunscript.
-l lenguaje
Utiliza el lenguaje de scripting especificado. Por defecto, se usa JavaScript. Para usar otros lenguajes de scripting, debes especificar el archivo JAR del motor de script correspondiente con la opción -cp o -classpath.
-e script
Evalúa el script especificado. Esta opción se puede usar para ejecutar scripts de una sola línea que se especifican completamente en la línea de comandos.
-encoding codificación
Especifica la codificación de caracteres utilizada para leer archivos de scripts.
-f archivo-script
Evalúa el archivo de script especificado (modo por lotes).
-f -
Entra en modo interactivo para leer y evaluar un script desde la entrada estándar.
-help o -?
Muestra un mensaje de ayuda y sale.
-q
Lista todos los motores de scripts disponibles y sale.

ARGUMENTOS

Si hay argumentos presentes y no se utiliza la opción -e o -f, entonces el primer argumento es el archivo de script y el resto de los argumentos, si los hay, se pasan como argumentos del script. Si se usan argumentos y la opción -e o -f, entonces todos los argumentos se pasan como argumentos del script. Si faltan los argumentos -e y -f, entonces se usa el modo interactivo.

EJEMPLO DE EJECUCIÓN DE SCRIPTS EN LÍNEA

jrunscript -e "print('hola mundo')"

jrunscript -e "cat('http://www.example.com')"

EJEMPLO DE USO DE UN LENGUAJE ESPECIFICADO Y EVALUACIÓN DEL ARCHIVO DE SCRIPT

jrunscript -l js -f test.js

EJECUTAR ARCHIVO DE SCRIPT CON ARGUMENTOS DE SCRIPT

En este ejemplo, el archivo test.js es el archivo de script. Los argumentos arg1, arg2 y arg3 se pasan al script. El script puede acceder a estos argumentos con un array de argumentos.

jrunscript test.js arg1 arg2 arg3

jrunscript-openjdk17(1)

NOMBRE

jrunscript - a script shell for Java

SINOPSIS

jrunscript [options] [script-file [script-args]]

DESCRIPCIÓN

The jrunscript command is a script shell for Java. It allows you to execute Java code from the command line, either interactively or by running script files. It supports multiple scripting languages, such as JavaScript (Rhino) and Groovy, if they are available on the classpath.

OPCIONES

The following options are available:

  • -e <script>: Executes the given <script> and exits.
  • -f <script-file>: Executes the specified <script-file> and exits.
  • -l <language>: Specifies the scripting language to use (e.g., "javascript", "groovy"). If not specified, the default is "javascript".
  • -p: Prints the result of the last expression evaluated in the script.
  • -q: Lists the available scripting languages.
  • --help: Displays help information and exits.
  • --version: Displays version information and exits.

EJEMPLOS

EJEMPLO DE USO DE LENGUAJE ESPECIFICADO Y EVALUACIÓN DEL ARCHIVO DE SCRIPT

To execute a JavaScript file named my_script.js using the JavaScript engine: 

jrunscript -l javascript -f my_script.js

EJEMPLO DE MODO INTERACTIVO

To start an interactive JavaScript session: 

jrunscript -l javascript
You can then type Java and JavaScript commands. Press Ctrl+D (or Ctrl+Z on Windows) to exit.

EJECUTA ARCHIVO DE SCRIPT CON ARGUMENTOS DE SCRIPT

To execute a script file and pass arguments to it: 

jrunscript my_script.js arg1 arg2
Inside my_script.js, you can access these arguments via the arguments array.
