NOMBRE

jack-dssi-host - un host simple de JACK para plugins DSSI

SINOPSIS

jack-dssi-host [-v] [-a] [-n] [-p <dirproj>] [-c <cnombre>] [-<i>] <nomlib>[:<etiqueta>] [...]

DESCRIPCIÓN

jack-dssi-host es un host DSSI simple que escucha eventos MIDI en un puerto del secuenciador ALSA, los entrega a plugins de sintetizador DSSI y emite el audio resultante a través de JACK.
jack-dssi-host puede alojar hasta 16 instancias de plugins de sintetizador DSSI, a cada una de las cuales se le asigna secuencialmente un canal MIDI del 1 al 16. Las salidas del plugin (si no se especifica `-a') se conectan secuencialmente a los puertos de salida físicos disponibles de JACK, volviendo al primer puerto de JACK cuando se agotan los puertos disponibles. Las interfaces de usuario (UIs) de los plugins se inician para cada instancia (si no se especifica '-n'.) jack-dssi-host saldrá cuando la última UI de plugin haya salido.
Como caso especial, si jack-dssi-host se inicia con un nombre distinto de `jack-dssi-host', y si ese nombre (más el sufijo '.so') se puede encontrar en la ruta de búsqueda de DSSI_PATH (ver ENTORNO a continuación) como una biblioteca compartida de plugin válida, y si no se proporcionan más argumentos en la línea de comandos, entonces el primer plugin de esa biblioteca se cargará automáticamente. Esto proporciona una forma conveniente de ejecutar un plugin simplemente creando un enlace simbólico del nombre base del plugin a jack-dssi-host.

OPCIONES

-v
Modo detallado.
-a
Deshabilita la conexión automática de salidas a las salidas físicas de JACK.
-n
Deshabilita el inicio automático de las interfaces de usuario (UIs) de los plugins.
-p <dirproj>
El directorio del proyecto que se pasará tanto al plugin como a la UI.
-c <cnombre>
El nombre del cliente a utilizar para ALSA y JACK.
-<i>
Número de instancias del siguiente plugin a ejecutar (máximo 16 en total, predeterminado 1).
<nomlib>
Nombre de la biblioteca compartida del plugin DSSI (.so) a cargar. Puede ser una ruta absoluta al archivo de la biblioteca, o simplemente el nombre del archivo, en cuyo caso se buscará en la ruta de búsqueda de DSSI (ver ENTORNO a continuación).
<etiqueta>
la etiqueta del plugin a cargar desde la biblioteca. Si se omite, se utiliza el primer plugin de la biblioteca.
[...]
Opcionalmente más recuentos de instancias, plugins y etiquetas.

EJEMPLO

jack-dssi-host -2 lib1.so -1 lib2.so:fuzzy
Ejecuta dos instancias del primer plugin encontrado en lib1.so, asignadas a los canales MIDI 1 y 2 y conectadas a las primeras salidas de JACK disponibles, y una instancia del plugin "fuzzy" en lib2.so en el canal MIDI 3 y conectada a la siguiente salida de JACK disponible.

ENTORNO

jack-dssi-host buscará bibliotecas compartidas de plugins en los directorios especificados por la variable de entorno DSSI_PATH, que es una lista de directorios separada por dos puntos. Si DSSI_PATH no está configurada, se utiliza una ruta de búsqueda predeterminada de /usr/lib/dssi, /usr/local/lib/dssi y (suponiendo que la variable de entorno HOME esté configurada) $HOME/.dssi.
