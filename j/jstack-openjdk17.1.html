JSTACK(1) Comandos JDK JSTACK(1)

NOMBRE

jstack - imprime rastreos de pila Java de hilos Java para un proceso Java especificado

SINOPSIS

Nota: Este comando es experimental y no es compatible.

jstack [opciones] pid

opciones
Esto representa las opciones de línea de comandos de jstack. Ver Opciones para el comando jstack.
pid
El ID de proceso para el cual se imprime el rastreo de pila. El proceso debe ser un proceso Java. Para obtener una lista de los procesos Java en ejecución en una máquina, usa el comando ps o, si los procesos JVM no se ejecutan en una instancia de docker separada, el comando jps.

DESCRIPCIÓN

El comando jstack imprime rastreos de pila Java de hilos Java para un proceso Java especificado. Para cada marco Java, se imprime el nombre completo de la clase, el nombre del método, el índice de bytecode (BCI) y el número de línea, cuando estén disponibles. Los nombres modificados de C++ no se desmodifican. Para desmodificar nombres de C++, la salida de este comando se puede canalizar a c++filt. Cuando el proceso especificado se ejecuta en una JVM de 64 bits, puede que necesites especificar la opción -J-d64, por ejemplo: jstack -J-d64 pid.

Nota:

Este comando no es compatible y podría no estar disponible en futuras versiones del JDK. En sistemas Windows donde el archivo dbgeng.dll no está presente, se deben instalar las Herramientas de depuración para Windows para que estas herramientas funcionen. La variable de entorno PATH debe contener la ubicación de jvm.dll que utiliza el proceso de destino, o la ubicación desde la que se produjo el archivo de volcado principal.

OPCIONES PARA EL COMANDO JSTACK

-l
La opción de listado largo imprime información adicional sobre los bloqueos.
-h o -help
Imprime un mensaje de ayuda.
