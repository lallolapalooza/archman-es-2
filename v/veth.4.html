veth(4) Manual de controladores de dispositivos veth(4)

NOMBRE

veth — Dispositivo de red Ethernet virtual

DESCRIPCIÓN

Los dispositivos veth son dispositivos Ethernet virtuales. Pueden actuar como túneles entre espacios de nombres de red para crear un puente hacia un dispositivo de red físico en otro espacio de nombres, pero también pueden usarse como dispositivos de red independientes.

Los dispositivos veth siempre se crean en pares interconectados. Un par puede crearse usando el comando:


# ip link add <nombre_p1> type veth peer name <nombre_p2>

En lo anterior, nombre_p1 y nombre_p2 son los nombres asignados a los dos extremos conectados.

Los paquetes transmitidos en un dispositivo del par se reciben inmediatamente en el otro dispositivo. Cuando cualquiera de los dispositivos está inactivo, el estado del enlace del par está inactivo.

Los pares de dispositivos veth son útiles para combinar las instalaciones de red del kernel de maneras interesantes. Un caso de uso particularmente interesante es colocar un extremo de un par veth en un espacio de nombres de red y el otro extremo en otro espacio de nombres de red, permitiendo así la comunicación entre espacios de nombres de red. Para hacer esto, se puede proporcionar el parámetro netns al crear las interfaces:


# ip link add <nombre_p1> netns <p1_ns> type veth peer <nombre_p2> netns <p2_ns>

o, para un par veth existente, mover un lado al otro espacio de nombres:


# ip link set <nombre_p2> netns <p2_ns>

ethtool(8) puede usarse para encontrar el par de una interfaz de red veth, usando comandos como:


# ip link add ve_A type veth peer name ve_B;   # Crea el par veth
# ethtool -S ve_A;         # Descubre el índice de interfaz del par
Estadísticas de la NIC:
     peer_ifindex: 16
# ip link | grep '^16:';   # Busca la interfaz
16: ve_B@ve_A: <BROADCAST,MULTICAST,M-DOWN> mtu 1500 qdisc ...
