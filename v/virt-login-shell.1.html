virt-login-shell(1) Soporte de Virtualización virt-login-shell(1)

Nombre

virt-login-shell - herramienta para ejecutar un shell dentro de un contenedor

SINÓPSIS

virt-login-shell [OPCIÓN]

DESCRIPCIÓN

El programa virt-login-shell es un shell setuid que se utiliza para unirse a un contenedor LXC que coincide con el nombre del usuario. Si el contenedor no se está ejecutando, virt-login-shell intentará iniciar el contenedor. virt-login-shell no tiene permitido ser ejecutado por root. Los usuarios normales se agregarán a un contenedor que coincida con su nombre de usuario, si existe, y están configurados en /etc/libvirt/virt-login-shell.conf.

La estructura básica de la mayoría de los usos de virt-login-shell es:

virt-login-shell

OPCIONES

-c CMD

Instruye al shell que ejecute CMD en lugar de presentar un prompt de shell interactivo.

-h, --help

Muestra la ayuda de la línea de comandos y sale.

-V, --version

Muestra la información de la versión y sale.

CONFIGURACIÓN

Por defecto, virt-login-shell ejecutará el programa /bin/sh para el usuario. Puede modificar este comportamiento definiendo la variable shell en /etc/libvirt/virt-login-shell.conf. por ejemplo:

shell = [ "/bin/bash" ]

Si la opción de configuración auto_shell está establecida, intentará detectar automáticamente el shell desde /etc/password dentro del contenedor. Esto solo debe hacerse si el contenedor tiene un directorio /etc separado del host, de lo contrario, terminará invocando recursivamente virt-login-shell. por ejemplo:

auto_shell = 1

Por defecto, no se permite a ningún usuario usar virt-login-shell, si desea permitir que ciertos usuarios usen virt-login-shell, debe modificar la variable allowed_users en /etc/libvirt/virt-login-shell.conf. por ejemplo:

allowed_users = [ "tom", "dick", "harry" ]

ESTADO DE SALIDA

virt-login-shell normalmente devuelve el estado de salida del comando que ejecutó. Si el comando fue terminado por una señal, pero esa señal no es fatal para virt-login-shell, devuelve el número de señal más 128.

Estado de salida generado por el propio virt-login-shell:

  • 0 Se utilizó una opción para obtener más información sobre este binario.
  • 125 Error genérico antes de intentar la ejecución del shell configurado; por ejemplo, si libvirtd no se está ejecutando.
  • 126 El shell configurado existe pero no se pudo ejecutar.
  • 127 No se pudo encontrar el shell configurado.
