VIDEO_FORMAT(7) Páginas del manual de DVDAuthor VIDEO_FORMAT(7)

NOMBRE

video_format - Propuesta para una especificación de preferencia de formato de video

DESCRIPCIÓN

Una serie de programas que crean o trabajan con material de video necesitan saber si deben generar su salida en formato NTSC o PAL. Los que he visto parecen tener una preferencia codificada para uno a menos que el usuario especifique el otro. Anular el predeterminado cada vez que quieras usar estos programas se vuelve tedioso.

Por lo tanto, debe haber una forma para que el usuario configure un único predeterminado que se aplique a todos estos programas. Este predeterminado debería ser configurable tanto a nivel de usuario como a nivel de sistema, con la configuración del usuario anulando la del sistema, como es habitual. Tiene sentido evitar el desorden de archivos ocultos (dotfiles) siguiendo, al menos hasta cierto punto, la Especificación de Directorios Base de XDG http://standards.freedesktop.org/basedir-spec/latest/.

La configuración de preferencia consistirá en la única palabra “NTSC” o “PAL” (sin comillas, podría ser insensible a mayúsculas y minúsculas). Esto se puede especificar de las siguientes maneras, en orden de prioridad decreciente:

•
Como el valor de la variable de entorno VIDEO_FORMAT
•
Como el contenido del archivo específico del usuario $XDG_CONFIG_HOME/video_format, con $XDG_CONFIG_HOME predeterminado a $HOME/.config si no está definido.
•
Como el contenido de un archivo a nivel de sistema dir/video_format, donde dir se toma sucesivamente de los elementos separados por dos puntos en el valor de $XDG_CONFIG_DIRS hasta que se encuentre el archivo, o si $XDG_CONFIG_DIRS no está definido, entonces el único directorio /etc.

La aplicación debe usar la primera de estas configuraciones que encuentre, buscando en el orden especificado.

Nota: la especificación de Directorios Base de XDG dice que los archivos de configuración a nivel de sistema deben ir en /etc/xdg. No estoy seguro de por qué es así, ya que muchas otras aplicaciones colocan la configuración a nivel de sistema en otros lugares de /etc. Particularmente porque la especificación no restringe de manera similar los datos compartidos de solo lectura a solo un subdirectorio de /usr/share.

DISCUSIÓN

¿Puede esta especificación aplicarse tanto a video de definición estándar como a alta definición? Para la definición estándar, hay una diferencia de tamaño de fotograma, siendo 720 por 480 para NTSC y 720 por 576 para PAL (en ambos casos, la relación de aspecto de la imagen mostrada es siempre 4:3). Pero esto no parece importar para la alta definición. Tanto para la definición estándar como para la alta definición, hay una diferencia de tasas de fotogramas, basadas en 29.97 fps para NTSC y 25 fps para PAL.

Tenga en cuenta también que si un archivo de configuración anterior en la búsqueda contiene una configuración inválida, la búsqueda no continúa incluso si otro archivo de configuración posterior podría contener una configuración válida. Esto permite al usuario anular un predeterminado del sistema con “sin predeterminado”. ¿Es esto importante? Creo que podría serlo.

IMPLEMENTACIÓN DE REFERENCIA

El siguiente código Python implementa una rutina llamada get_default_video_format que devuelve una de las cadenas “NTSC” o “PAL” indicando el formato predeterminado configurado por el usuario/sistema según la especificación anterior, o None si el predeterminado es inválido o no está configurado.

    class xdg_base_dir :
        "Implementación de partes relevantes de la especificación de Directorios Base de XDG" \
        " <http://standards.freedesktop.org/basedir-spec/latest/>."
        @classmethod
        def get_config_home(self) :
            "devuelve el directorio para almacenar archivos de configuración específicos del usuario."
            result = os.environ.get("XDG_CONFIG_HOME")
            if result == None :
                result = os.path.join(os.environ["HOME"], ".config")
            #end if
            return result
        #end get_config_home
        @classmethod
        def config_search_path(self) :
            "devuelve la lista de directorios de configuración a buscar (aparte del área del usuario)."
            return tuple(os.environ.get("XDG_CONFIG_DIRS", "/etc").split(":"))
              # nota: la especificación en realidad dice que el predeterminado debe ser /etc/xdg, pero /etc es la
              # ubicación convencional para archivos de configuración del sistema.
        #end config_search_path
        @classmethod
        def find_first_config_path(self, path) :
            "busca path en todas las ubicaciones de directorios de configuración en orden de prioridad decreciente," \
            " devolviendo la expansión donde se encuentra por primera vez, o None si no se encuentra."
            paths_to_try = iter((self.get_config_home(),) + self.config_search_path())
              # mayor prioridad primero
            while True :
                this_path = next(paths_to_try, None)
                if this_path == None :
                    break
                this_path = os.path.join(this_path, path)
                if os.path.exists(this_path) :
                    break
            #end while
            return this_path
        #end find_first_config_path
    #end xdg_base_dir
    valid_video_formats = frozenset(("NTSC", "PAL"))
    def get_default_video_format() :
        video_format = os.environ.get("VIDEO_FORMAT")
        if video_format == None :
            config_file = xdg_base_dir.find_first_config_path("video_format")
            if config_file != None :
                try :
                    video_format = open(config_file, "r").readline().strip()
                except OSError :
                    video_format = None
                #end try
            #end if
        #end if
        if video_format != None :
            video_format = video_format.upper()
            if video_format not in valid_video_formats :
                video_format = None
            #end if
        #end if
        return video_format
    #end get_default_video_format
