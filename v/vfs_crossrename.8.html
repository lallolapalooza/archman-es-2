VFS_CROSSRENAME(8) Herramientas de administración del sistema VFS_CROSSRENAME(8)

NOMBRE

vfs_crossrename - renombrar archivos en el lado del servidor entre límites de sistemas de archivos

SINOPSIS

objetos vfs = crossrename

DESCRIPCIÓN

Este módulo VFS forma parte del conjunto samba(7).

El módulo VFS vfs_crossrename permite operaciones de renombrado en el lado del servidor incluso si el origen y el destino están en dispositivos físicos diferentes. Un "mover" en el Explorador es generalmente una operación de renombrado si está dentro de una única compartición o dispositivo. Normalmente, dicha operación de renombrado devuelve NT_STATUS_NOT_SAME_DEVICE y el cliente tiene que mover el archivo mediante operaciones manuales de copia y eliminación. Si el renombrado por copia lo realiza el servidor, puede ser mucho más eficiente. vfs_crossrename intenta realizar esta operación de renombrado entre dispositivos en el lado del servidor.

Sin embargo, existen limitaciones que este módulo actualmente no resuelve:

Las ACLs de los archivos no se conservan,

los metadatos en EAs no se conservan,

los renombrados de subdirectorios enteros no se pueden hacer recursivamente; en ese caso, todavía devolvemos STATUS_NOT_SAME_DEVICE y dejamos que el cliente decida qué hacer,

las operaciones de renombrado de archivos muy grandes pueden provocar bloqueos en el cliente porque los clientes esperan que una operación de renombrado devuelva el resultado rápidamente.

Este módulo no es completamente apilable. Se puede combinar con otros módulos, pero debe ser el último módulo en la lista de objetos vfs. Accede directamente a los archivos en el sistema de archivos del sistema operativo.

OPCIONES

crossrename:sizelimit = BYTES

los renombrados entre dispositivos en el lado del servidor solo se realizan para archivos si el tamaño del archivo no es mayor que el tamaño definido en MiB para evitar tiempos de espera. El límite de tamaño por defecto es 20 (MiB)

EJEMPLOS

Para agregar renombrados entre dispositivos en el lado del servidor dentro de una compartición para todos los archivos de hasta 50 MB:

        [testshare]
	path = /data/mounts
	vfs objects = crossrename
	crossrename:sizelimit = 50
