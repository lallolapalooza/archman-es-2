NOMBRE

verilator_coverage - Analizador de cobertura de Verilator

SINOPSIS

verilator_coverage --help
verilator_coverage --version
verilator_coverage --annotate <obj>
verilator_coverage  -write merged.dat <datafiles>...
verilator_coverage  -write-info merged.info <datafiles>...

Verilator_coverage procesa informes de cobertura generados por modelos Verilated.

Para documentación, consulte https://verilator.org/guide/latest/exe_verilator_coverage.html.

RESUMEN DE ARGUMENTOS

<filename>    Especifica el nombre del archivo de datos de entrada, por defecto "coverage.dat"
--annotate <output_dir>       Nombre del directorio para la anotación de origen.
--annotate-all                Se deben mostrar todos los archivos.
--annotate-min <count>        Número mínimo de ocurrencias para lo no cubierto.
--annotate-points             Anota información de cada punto de cobertura.
--filter-type <regex>         Mantiene solo registros del tipo de cobertura dado.
--help                        Muestra este mensaje y la versión y sale.
--rank                        Calcula la importancia relativa de las pruebas.
--unlink                      Con --write, elimina todos los archivos de entrada.
--version                     Muestra la versión del programa y sale.
--write <filename>            Escribe los resultados agregados de cobertura.
--write-info <filename.info>  Escribe un archivo lcov .info.
+libext+<ext>+<ext>...        Extensiones para archivos Verilog.
+define+<var>+<value>         Define la variable dada.
-D<var>=<value>               Define la variable dada.
+incdir+<dir>                 Añade un directorio para encontrar archivos de inclusión.
-I<dir>                       Añade un directorio para encontrar archivos de inclusión.
-y <dir>                      Especifica el directorio de búsqueda de módulos.
