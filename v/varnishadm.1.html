NOMBRE

varnishadm - Controla una instancia de Varnish en ejecución

SINOPSIS

varnishadm [-h] [-n workdir] [-p] [-S secretfile] [-T [address]:port] [-t timeout] [comando [...]]

DESCRIPCIÓN

La utilidad varnishadm establece una conexión CLI con varnishd ya sea usando -n workdir o usando los argumentos -T y -S. Si se proporciona -n workdir, la ubicación del archivo secreto y la dirección:puerto se buscan en la memoria compartida. Si no se proporciona ninguno, varnishadm utiliza los valores predeterminados de -n documentados para varnishd(1).

Si se proporciona un comando, el comando y sus argumentos se envían a través de la conexión CLI y el resultado se devuelve en la salida estándar.

Si no se proporciona ningún argumento de comando, varnishadm pasará comandos y respuestas entre el socket CLI y la entrada/salida estándar.

OPCIONES

-h
Muestra el uso del programa y sale.
-n workdir
Especifica el directorio de trabajo de varnish de la instancia a la que conectarse. Consulte la documentación de la opción -n de varnishd(1) para obtener información adicional y valores predeterminados.
-p
Fuerza el modo pass y hace que la salida siga el protocolo VCLI. Esto deshabilita el historial de comandos/autocompletado y facilita que los programas analicen la(s) respuesta(s).
-S secretfile
Especifica el archivo secreto de autenticación. Este debería ser el mismo argumento -S que se dio a varnishd. Solo los procesos que puedan leer el contenido de este archivo podrán autenticar la conexión CLI.
-T <address:port>
Conéctese a la interfaz de administración en la dirección y puerto especificados.
-t timeout
Espere como máximo esta cantidad de segundos para que una operación finalice.

La sintaxis y el funcionamiento de la interfaz CLI real se describen en la página del manual varnish-cli(7). Los parámetros se describen en la página del manual varnishd(1).

Además, se puede obtener un resumen de los comandos emitiendo el comando help, y un resumen de los parámetros emitiendo el comando param.show.

ESTADO DE SALIDA

Si se proporciona un comando, el estado de salida de la utilidad varnishadm será cero si el comando tuvo éxito y no cero en caso contrario.

EJEMPLOS

Algunas formas en que puede usar varnishadm:

varnishadm -T localhost:999 -S /var/db/secret vcl.use foo
echo vcl.use foo | varnishadm -T localhost:999 -S /var/db/secret
echo vcl.use foo | ssh vhost varnishadm -T localhost:999 -S /var/db/secret
