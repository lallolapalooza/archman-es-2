VFS_BTRFS(8) Herramientas de administración del sistema VFS_BTRFS(8)

NOMBRE

vfs_btrfs - Utilizar características proporcionadas por el sistema de archivos Btrfs

SINOPSIS

objetos vfs = btrfs

DESCRIPCIÓN

Este módulo VFS forma parte del conjunto samba(8).

El módulo VFS vfs_btrfs expone características específicas de Btrfs para su uso por Samba.

Btrfs permite que varios archivos compartan los mismos datos en disco a través de rangos clonados. Cuando un cliente SMB emite una solicitud para copiar datos duplicados (a través de FSCTL_SRV_COPYCHUNK), este módulo mapea la solicitud a un IOCTL de rango de clonación de Btrfs, en lugar de realizar las lecturas y escrituras requeridas por una copia tradicional. Hacer esto ahorra capacidad de almacenamiento y reduce en gran medida la E/S del disco.

Este módulo también expone el soporte de compresión por archivo de Btrfs a los clientes SMB a través de los fsctl de obtención/establecimiento de compresión.

Las instantáneas de Btrfs pueden ser manipuladas por el servidor FSRVP de Samba. La manipulación de instantáneas utilizando este módulo se considera actualmente experimental, y por lo tanto está deshabilitada por defecto. En su lugar, se recomienda el módulo vfs_snapper para este propósito.

Este módulo es apilable.

OPCIONES

btrfs: manipular instantáneas = [sí|no]

Cuando se establece en sí, se habilitará el soporte experimental para la creación y eliminación de instantáneas a través de los IOCTLs de Btrfs correspondientes. El valor por defecto es no, lo que significa que dichas solicitudes se pasan a cualquier módulo VFS subyacente.

CONFIGURACIÓN

vfs_btrfs requiere que la ruta de recurso compartida subyacente sea un subvolumen de Btrfs.

[recurso compartido]
vfs objects = btrfs
btrfs: manipular instantáneas = no

Para usar la funcionalidad experimental de manipulación de instantáneas proporcionada por este módulo, debe estar habilitada explícitamente y el servidor FSRVP de Samba debe estar en ejecución.

El módulo vfs_shadow_copy puede usarse para exponer las instantáneas creadas por vfs_btrfs a Windows Explorer como "versiones anteriores" de archivos/directorios.

[global]
registry shares = yes
include = registry
[recurso compartido]
vfs objects = btrfs shadow_copy
btrfs: manipular instantáneas = yes
