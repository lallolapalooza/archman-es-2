NOMBRE

vmexec - Ejecuta un único comando en una máquina virtual rápida con configuración cero

SINOPSIS

vmexec [--log-level] [-h|--help] [-V|--version] <subcomandos>

DESCRIPCIÓN

Ejecuta un único comando en una máquina virtual rápida con configuración cero

OPCIONES

--log-level=NIVEL_LOG [por defecto: warn]
Registra mensajes por encima del nivel especificado (error, warn, info, debug, trace)
-h, --help
Imprime la ayuda
-V, --version
Imprime la versión

SUBCOMANDOS

vmexec-ps(1)
Lista las máquinas virtuales
vmexec-stop(1)
Detiene una máquina virtual enviando una señal SIGTERM
vmexec-exec(1)
Ejecuta un comando en una máquina virtual existente
vmexec-run(1)
Ejecuta un comando en una nueva máquina virtual
vmexec-ksm(1)
Comprueba y cambia el estado de KSM
vmexec-clean(1)
Limpia ejecuciones antiguas
vmexec-completions(1)
Genera el archivo de completado para un shell
vmexec-manpage(1)
Imprime la página del manual
