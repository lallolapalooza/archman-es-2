NOMBRE

voa-verify - Verifica un archivo utilizando verificadores y firmas adecuados.

SINOPSIS

voa verify [-o|--output-format] [-v|--verbose]... [-q|--quiet]... [-h|--help] <SO> <PROPÓSITO> <CONTEXTO> <TECNOLOGÍA> <ARCHIVO> [FIRMAS]

DESCRIPCIÓN

Verifica un archivo utilizando verificadores y firmas adecuados.

Devuelve un mensaje de estado en stdout.

Devuelve un código de salida distinto de cero y un mensaje de error en stderr, si la verificación de uno o más archivos de firma falla.

OPCIONES

-o, --output-format <FORMATO_SALIDA> [por defecto: text]
El formato de salida a utilizar.

Valores posibles:

  • json: El formato de salida JSON
  • text: El formato de salida de texto por defecto
También se puede especificar con la variable de entorno VOA_VERIFY_OUTPUT_FORMAT.
-v, --verbose
Aumenta la verbosidad del registro
-q, --quiet
Disminuye la verbosidad del registro
-h, --help
Imprime la ayuda (ver un resumen con '-h')
<SO>
El SO para el que se va a verificar.
También se puede especificar con la variable de entorno VOA_VERIFY_OS.
<PROPÓSITO>
El propósito para el que se va a verificar.
También se puede especificar con la variable de entorno VOA_VERIFY_PURPOSE.
<CONTEXTO>
El contexto para el que se va a verificar.
También se puede especificar con la variable de entorno VOA_VERIFY_CONTEXT.
<TECNOLOGÍA>
La tecnología con la que se va a verificar.

Actualmente solo se admite "openpgp".

También se puede especificar con la variable de entorno VOA_VERIFY_TECHNOLOGY.
<ARCHIVO>
El archivo a verificar.
También se puede especificar con la variable de entorno VOA_VERIFY_FILE.
[FIRMAS]
La firma con la que verificar un archivo.
También se puede especificar con la variable de entorno VOA_VERIFY_SIGNATURE.
