VALADOC(1) Comandos de usuario VALADOC(1)

NOMBRE

valadoc - Herramienta de documentación de Vala

SINOPSIS

valadoc [OPCIÓN]... ARCHIVO...

DESCRIPCIÓN

Valadoc es un generador de documentación para generar documentación de API a partir de código fuente de Vala basado en libvala.

Uso:

valadoc [OPCIÓN?] ARCHIVO... - Herramienta de documentación de Vala

Opciones de ayuda:

-h, --help
Muestra las opciones de ayuda

Opciones de aplicación:

-o, --directory=DIRECTORIO
Directorio de salida
-b, --basedir=DIRECTORIO
Directorio base de código fuente
-D, --define=SÍMBOLO...
Define SÍMBOLO
--profile=PERFIL
Dependencia mínima en tiempo de ejecución: 'gobject' (predeterminado) o 'posix' (libc mínima)
--enable-experimental
Habilita características experimentales
--enable-experimental-non-null
Habilita mejoras experimentales para tipos no nulos
--metadatadir=DIRECTORIO...
Busca archivos .metadata de GIR en DIRECTORIO
--girdir=DIRECTORIO...
Busca archivos .gir en DIRECTORIO
--vapidir=DIRECTORIO...
Busca enlaces de paquetes en DIRECTORIO
--pkg=PAQUETE...
Incluye enlace para PAQUETE
--driver
Nombre de un controlador o ruta a un controlador personalizado (OBSOLETO Y IGNORADO)
--importdir=DIRECTORIO...
Busca documentación externa en DIRECTORIO
--import=PAQUETE...
Incluye enlace para PAQUETE
--alternative-resource-dir=DIRECTORIO...
Directorios de recursos alternativos
--wiki=DIRECTORIO
Directorio de wiki
--deps
Agrega paquetes a la documentación
--doclet=PLUGIN
Nombre de un doclet incluido o ruta a un doclet personalizado
-X, --doclet-arg=ARG
Pasa argumentos al doclet
--no-protected
Elimina elementos protegidos de la documentación
--internal
Agrega elementos internos a la documentación
--private
Agrega elementos privados a la documentación
--use-svg-images
Genera gráficos de imágenes SVG en lugar de PNG
--package-name=NOMBRE
nombre del paquete
--package-version=VERSIÓN
versión del paquete
--gir=NOMBRE-VERSIÓN.gir
nombre del archivo del repositorio GObject-Introspection
--version
Muestra el número de versión
--force
forzar
--fatal-warnings
Trata las advertencias como fatales
--verbose
Muestra todas las advertencias
--no-color
Deshabilita la salida con color
--target-glib='MAYOR.MENOR', o 'auto'
Versión de destino de glib para la generación de código
