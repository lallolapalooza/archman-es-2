NAME

virkeycode — List of key codes

DESCRIPTION

This document lists the key codes for the virtual keyboard events that libvirt can generate. These key codes are derived from the Linux kernel's input event codes.

Key codes are generally represented as KEY_NAME, where NAME is an uppercase identifier. In addition to the symbolic name, the numeric value (decimal and hexadecimal) is also provided.
