va_list(3type) va_list(3type)

NOMBRE

va_list - lista de argumentos variables

LIBRERÍA

Biblioteca estándar de C (libc)

SINOPSIS

#include <stdarg.h>
typedef /* ... */  va_list;

DESCRIPCIÓN

Se utiliza en funciones con un número variable de argumentos de tipos variables. La función debe declarar un objeto de tipo va_list que es utilizado por las macros va_start(3), va_arg(3), va_copy(3) y va_end(3) para recorrer la lista de argumentos.

ESTÁNDARES

C11, POSIX.1-2024.

HISTORIA

C89, POSIX.1-2001.

NOTAS

Las siguientes cabeceras también proporcionan va_list: <stdio.h> y <wchar.h>.

VER TAMBIÉN

va_start(3), va_arg(3), va_copy(3), va_end(3)
