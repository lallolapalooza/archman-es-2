VFS_FULL_AUDIT(8) Herramientas de administración del sistema VFS_FULL_AUDIT(8)

NOMBRE

vfs_full_audit - registra las operaciones de VFS de Samba en el registro del sistema

SINOPSIS

objetos vfs = full_audit

DESCRIPCIÓN

Este módulo VFS forma parte del conjunto samba(7).

El módulo VFS vfs_full_audit registra operaciones seleccionadas del cliente en el registro del sistema usando syslog(3).

Además de estas operaciones, vfs_full_audit reconoce los nombres de operación especiales "all" (todo) y "none" (ninguno), que se refieren a todas las operaciones VFS y a ninguna de las operaciones VFS, respectivamente.

Si se utiliza un nombre de operación desconocido (por ejemplo, un nombre de operación está mal escrito), el módulo fallará al cargarse y se rechazarán las conexiones de los clientes a un recurso compartido que use este módulo.

vfs_full_audit registra las operaciones en un formato fijo que consiste en campos separados por caracteres '|'. El formato es:

smbd_audit: PREFIJO|OPERACIÓN|RESULTADO|ARCHIVO

Los campos del registro son:

•PREFIJO - el resultado de la cadena full_audit:prefix después de las sustituciones de variables
•OPERACIÓN - el nombre de la operación VFS
•RESULTADO - si la operación tuvo éxito o falló
•ARCHIVO - el nombre del archivo o directorio en el que se realizó la operación

Este módulo es apilable.

OPCIONES

full_audit:prefix = CADENA

Antepone STRING a los mensajes de auditoría. STRING se procesa para las variables de sustitución estándar listadas en smb.conf(5). El prefijo por defecto es "%u|%I".

full_audit:success = LISTA

LISTA es una lista de operaciones VFS que deben registrarse si tienen éxito. Las operaciones se especifican usando los nombres listados arriba. Las operaciones se pueden anular prefijando los nombres con "!". El valor por defecto es ninguna operación.

full_audit:failure = LISTA

LISTA es una lista de operaciones VFS que deben registrarse si fallaron. Las operaciones se especifican usando los nombres listados arriba. Las operaciones se pueden anular prefijando los nombres con "!". El valor por defecto es ninguna operación.

full_audit:facility = INSTALACIÓN

Registra mensajes en la syslog(3) instalación nombrada.

full_audit:priority = PRIORIDAD

Registra mensajes con la syslog(3) prioridad nombrada.

full_audit:syslog = true/false

Registra mensajes en syslog (por defecto) o como un mensaje de nivel de depuración 1.

full_audit:log_secdesc = true/false

Registra un formulario SDDL del descriptor de seguridad que llega cuando un cliente establece un ACL. Por defecto es false.

EJEMPLOS

Registra las operaciones de apertura de archivos y directorios en el recurso compartido [records] usando la instalación LOCAL7 y la prioridad ALERT, incluyendo el nombre de usuario y la dirección IP. El registro excluye la función VFS de apertura en caso de fallos:

        [records]
	path = /data/records
	vfs objects = full_audit
	full_audit:prefix = %u|%I
	full_audit:success = open opendir
	full_audit:failure = all !open
	full_audit:facility = LOCAL7
	full_audit:priority = ALERT
