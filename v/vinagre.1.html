VINAGRE(1) Manual de comandos generales VINAGRE(1)

NOMBRE

vinagre - un visor de escritorio remoto para el Escritorio GNOME

SINOPSIS

vinagre [OPCIONES] [servidor][::puerto|:pantalla]

DESCRIPCIÓN

vinagre es un visor de escritorio remoto para el escritorio GNOME. Puede soportar muchos protocolos utilizando un sistema de plugins. Los plugins actuales existen para VNC y SSH. Vinagre tiene muchas características, entre otras:

- Soporte para múltiples conexiones simultáneamente

- Soporte de marcadores e historial

- Integración con Avahi

- Integración con el llavero de GNOME

- Puedes conectarte a un servidor VNC haciendo doble clic en un archivo .vnc cuando usas nautilus.

OPCIONES

Opciones de Ayuda:

-?, --help
Mostrar opciones de ayuda

Opciones de Aplicación:

-F, --file=nombre_archivo
Abre un archivo .vnc
-f, --fullscreen
Abre Vinagre en modo de pantalla completa
--geometry=GEOMETRÍA
Especifica la geometría de la ventana de Vinagre en formato X11
-n, --new-window
Crea una nueva ventana de nivel superior en una instancia existente de Vinagre
--display=PANTALLA
Pantalla X a usar

Ejecuta 'vinagre --help' para ver una lista completa de las opciones de línea de comandos disponibles.

OPERANDOS

Se admiten los siguientes operandos:

[servidor][::puerto|:pantalla]
Especifica el servidor VNC al que conectarse. El servidor VNC puede ser un nombre de host o una dirección IP. Si el servidor es una dirección IPv6, debe estar encerrado entre corchetes. La dirección opcionalmente puede ir seguida de dos puntos (::) y el número de puerto VNC, o alternativamente de un punto (:) y la pantalla donde debe ejecutarse Vinagre. Si no se especifica un puerto, se usará el valor predeterminado de 5900. Si el valor es inferior a 1024, se le sumará 5900. Por ejemplo, ":0" significa "5900" y ":1" significa ":5901". Si solo se especifica un puerto, pero no el nombre del host, se asumirá localhost. Los valores posibles para la pantalla están entre 0 y 1024. Si se especifica un número de pantalla mayor que 1024, se asumirá que es un puerto. Tenga en cuenta que no puede especificar el puerto y la pantalla al mismo tiempo.

EJEMPLOS

Ejemplo 1: Iniciar vinagre desde la línea de comandos

example% vinagre

Ejemplo 2: Crear una nueva ventana de nivel superior

example% vinagre --new-window

Ejemplo 3: Conectarse a un servidor VNC y puerto especificados

example% vinagre snoopy::5900

Ejemplo 4: Conectarse a una dirección IP y puerto IPv4 especificados

example% vinagre 192.168.1.35::2700

Ejemplo 5: Conectarse a una dirección IPv6 y puerto especificados

example% vinagre [2001:0db8:0:0:0:0:1428:57ab]::2700

Ejemplo 6: Conectarse a un servidor VNC especificado por un archivo .vnc 

example% vinagre -F snoopy.vnc

Ejemplo 7: Conectarse a localhost en un puerto especificado en modo de pantalla completa

example% vinagre -f ::5900
