VFS_VIRUSFILTER(8) Herramientas de administración del sistema VFS_VIRUSFILTER(8)

NOMBRE

vfs_virusfilter - Escáner de virus al acceso

SINOPSIS

objetos vfs = virusfilter

DESCRIPCIÓN

Este es un conjunto de varios módulos VFS de Samba para escanear y filtrar archivos de virus en servicios de archivos de Samba con un escáner antivirus.

Este módulo es apilable.

OPCIONES

virusfilter:scanner

El motor de escaneo antivirus.
•sophos, el escáner Sophos AV
•fsav, el escáner F-Secure AV
•clamav, el escáner ClamAV
•dummy, escáner ficticio utilizado en pruebas. Compara con el parámetro archivos infectados y marca como infectado cualquier nombre que coincida.

virusfilter:socket path = RUTA

Ruta del socket local para el escáner de virus.

Si esta opción no está configurada, la ruta predeterminada depende del motor de escaneo AV configurado.

Para el backend sophos, el valor predeterminado es /var/run/savdi/sssp.sock.

Para el backend fsav, el valor predeterminado es /tmp/.fsav-0.

Para el backend clamav, el valor predeterminado es /var/run/clamav/clamd.ctl.

virusfilter:connect timeout = 30000

Controla cuánto tiempo esperar para conectarse con el proceso de escaneo de virus antes de agotar el tiempo de espera. El valor está en milisegundos.

Si esta opción no está configurada, el valor predeterminado es 30000.

virusfilter:io timeout = 60000

Controla cuánto tiempo esperar en las comunicaciones con el proceso de escaneo de virus antes de agotar el tiempo de espera. El valor está en milisegundos.

Si esta opción no está configurada, el valor predeterminado es 60000.

virusfilter:scan on open = yes

Esta opción controla si los archivos se escanean al abrirlos.

Si esta opción no está configurada, el valor predeterminado es yes.

virusfilter:scan on close = no

Esta opción controla si los archivos se escanean al cerrarlos.

Si esta opción no está configurada, el valor predeterminado es no.

virusfilter:max file size = 100000000

Este es el tamaño máximo de archivo, en bytes, que se escaneará.

Si esta opción no está configurada, el valor predeterminado es 100 MB.

virusfilter:min file size = 10

Este es el tamaño mínimo de archivo, en bytes, que se escaneará.

Si esta opción no está configurada, el valor predeterminado es 10.

virusfilter:infected file action = nothing

Qué hacer con un archivo infectado. Las opciones son nothing, quarantine, rename, delete (nada, poner en cuarentena, renombrar, eliminar).

Si esta opción no está configurada, el valor predeterminado es nothing.

virusfilter:infected file errno on open = EACCES

Qué valor de errno devolver al abrir si el archivo está infectado.

Si esta opción no está configurada, el valor predeterminado es EACCES.

virusfilter:infected file errno on close = 0

Qué valor de errno devolver al cerrar si el archivo está infectado.

Si esta opción no está configurada, el valor predeterminado es 0.

virusfilter:quarantine directory = RUTA

Dónde mover los archivos infectados. Esta ruta debe ser una ruta absoluta.

Si esta opción no está configurada, el valor predeterminado es ".quarantine" relativo a la ruta compartida.

virusfilter:quarantine prefix = virusfilter.

Prefijo para los archivos puestos en cuarentena.

Si esta opción no está configurada, el valor predeterminado es "virusfilter.".

virusfilter:quarantine suffix = .infected

Sufijo para los archivos puestos en cuarentena. Esta opción solo se usa si keep name es true. De lo contrario, se ignora.

Si esta opción no está configurada, el valor predeterminado es ".infected".

virusfilter:rename prefix = virusfilter.

Prefijo para los archivos infectados.

Si esta opción no está configurada, el valor predeterminado es "virusfilter.".

virusfilter:rename suffix = .infected

Sufijo para los archivos infectados.

Si esta opción no está configurada, el valor predeterminado es ".infected".

virusfilter:quarantine keep tree = yes

Si keep tree está configurado, la estructura de directorios relativa a la compartición se mantiene en el directorio de cuarentena.

Si esta opción no está configurada, el valor predeterminado es yes.

virusfilter:quarantine keep name = yes

¿Debería dejarse el nombre del archivo sin modificar, aparte de añadir un sufijo y/o prefijo y un nombre de sufijo aleatorio, tal como se define en virusfilter:rename prefix y virusfilter:rename suffix?

Si esta opción no está configurada, el valor predeterminado es yes.

virusfilter:infected file command = @SAMBA_DATADIR@/bin/virusfilter-notify --mail-to virusmaster@example.com --cc "%U@example.com" --from samba@example.com --subject-prefix "Samba: Archivo Infectado: "

Comando externo a ejecutar cuando se encuentra un archivo infectado.

Si esta opción no está configurada, el valor predeterminado es none.

virusfilter:scan archive = true

Esto define si se deben escanear o no los archivos comprimidos.

Sophos y F-Secure soportan esto y por defecto es false.

virusfilter:max nested scan archive = 1

Esto define la profundidad máxima para buscar archivos comprimidos anidados.

Sophos y F-Secure soportan esto y por defecto es 1.

virusfilter:scan mime = true

Esto define si se deben escanear o no los archivos mime.

Solo el escáner fsav soporta esta opción y por defecto es false.

virusfilter:scan error command = @SAMBA_DATADIR@/bin/virusfilter-notify --mail-to virusmaster@example.com --from samba@example.com --subject-prefix "Samba: Error de Escaneo: "

Comando externo a ejecutar en caso de error de escaneo.

Si esta opción no está configurada, el valor predeterminado es none.

virusfilter:exclude files = empty

Archivos a excluir del escaneo.

Si esta opción no está configurada, el valor predeterminado es empty.

virusfilter:infected files = empty

Archivos que el filtro de virus dummy marca como infectados.

Si esta opción no está configurada, el valor predeterminado es empty.

virusfilter:block access on error = false

Controla si el acceso debe ser bloqueado o no en caso de error de escaneo.

Si esta opción no está configurada, el valor predeterminado es false.

virusfilter:scan error errno on open = EACCES

Qué valor de errno devolver al abrir si hay un error en el escaneo del archivo y block access on error es true.

Si esta opción no está configurada, el valor predeterminado es EACCES.

virusfilter:scan error errno on close = 0

Qué valor de errno devolver al cerrar si hay un error en el escaneo del archivo y block access on error es true.

Si esta opción no está configurada, el valor predeterminado es 0.

virusfilter:cache entry limit = 100

El número máximo de entradas en la caché de resultados de escaneo. Debido a cómo funciona la caché de memoria de Samba, esto es aproximado.

Si esta opción no está configurada, el valor predeterminado es 100.

virusfilter:cache time limit = 10

El número máximo de segundos que un resultado de escaneo permanecerá en la caché de resultados. -1 deshabilita el límite. 0 deshabilita el caché.

Si esta opción no está configurada, el valor predeterminado es 10.

virusfilter:quarantine directory mode = 0755

Este es el modo octal para el directorio de cuarentena y sus subdirectorios tal como se crean.

Si esta opción no está configurada, el valor predeterminado es 0755 o S_IRUSR | S_IWUSR | S_IXUSR | S_IRGRP | S_IXGRP | S_IROTH | S_IXOTH.

Los permisos deben ser tales que todos los usuarios puedan leer y navegar. Es decir, no modifique esto a menos que sepa realmente lo que está haciendo.

virusfilter:block suspected file = false

Con esta opción activada, el malware sospechoso también será bloqueado. Solo el escáner fsav soporta esta opción.

Si esta opción no está configurada, el valor predeterminado es false.

NOTAS

NAME

vfs_virusfilter - Virus Filter VFS module

SYNOPSIS

vfs objects list (i.e. streams_depot must be called before virusfilter module).

DESCRIPTION

This module is intended for security in depth by providing virus scanning capability on the server. It is not intended to be used in lieu of proper client based security. Other modules for security may exist and may be desirable for security in depth on the server.

OPTIONS

This module does not have any options.

NOTES

This module requires the vfs_streams_depot(5) module to be loaded before it. This is due to the fact that it relies on the named data streams to store the virus scanning results.

The virus scanner is invoked by the vscan-client tool. You must ensure that this tool is installed and configured correctly on your system.

This module is intended for use with Samba version 4.8 and later.
