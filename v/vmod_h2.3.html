NOMBRE

vmod_h2 - Módulo para controlar el transporte HTTP2 integrado

SINOPSIS

import h2 [as nombre] [from "ruta"]
BOOL is()
DURATION rapid_reset([DURATION umbral])
INT rapid_reset_limit([INT numero])
DURATION rapid_reset_period([DURATION duracion])
REAL rapid_reset_budget()

DESCRIPCIÓN

Este VMOD contiene funciones para controlar el transporte HTTP2 integrado en Varnish-Cache.

BOOL is()

Restringido a: cliente.

Devuelve verdadero cuando se llama en una sesión manejada por el transporte HTTP2 integrado.

DURATION rapid_reset([DURATION umbral])

Restringido a: cliente.

Obtiene y opcionalmente establece el parámetro h2_rapid_reset (Ver varnishd(1)) solo para esta sesión HTTP2.

Devuelve -1 cuando se usa fuera del transporte HTTP2. De lo contrario, devuelve el valor anterior.

Si la llamada conduce a un cambio en los parámetros del límite de tasa, el presupuesto actual devuelto por h2.rapid_reset_budget() se reinicia.

INT rapid_reset_limit([INT numero])

Restringido a: cliente.

Obtiene y opcionalmente establece el parámetro h2_rapid_reset_limit (Ver varnishd(1)) solo para esta sesión HTTP2.

Devuelve -1 cuando se usa fuera del transporte HTTP2. De lo contrario, devuelve el valor anterior.

Si la llamada conduce a un cambio en los parámetros del límite de tasa, el presupuesto actual devuelto por h2.rapid_reset_budget() se reinicia.

DURATION rapid_reset_period([DURATION duracion])

Restringido a: cliente.

Obtiene y opcionalmente establece el parámetro h2_rapid_reset_period (Ver varnishd(1)) solo para esta sesión HTTP2.

Devuelve -1 cuando se usa fuera del transporte HTTP2. De lo contrario, devuelve el valor anterior.

Si la llamada conduce a un cambio en los parámetros del límite de tasa, el presupuesto actual devuelto por h2.rapid_reset_budget() se reinicia.

REAL rapid_reset_budget()

Restringido a: cliente.

Devuelve cuántos marcos RST clasificados como "rápidos" todavía puede enviar el cliente antes de que se cierre la sesión.
