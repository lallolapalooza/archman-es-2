NOMBRE

vcdxminfo - página del manual para vcdxminfo 2.0.0

SINOPSIS

vcdxminfo [OPCIÓN...]

DESCRIPCIÓN

-i, --informacion-generica
mostrar información genérica
-a, --volcar-aps
volcar datos APS
--aps-relajados
relajar restricciones APS
-o, --archivo-salida=ARCHIVO
archivo para la salida XML
-p, --progreso
mostrar progreso
-v, --verboso
ser verboso
-q, --silencioso
mostrar solo mensajes críticos
--gui
habilitar modo GUI
-V, --version
mostrar información de versión y derechos de autor y salir

Opciones de ayuda:

-?, --ayuda
Mostrar este mensaje de ayuda
--uso
Mostrar un breve mensaje de uso
