NOMBRE

vhs - Ejecuta un archivo de cinta dado y genera sus salidas.

SINOPSIS

vhs [opciones...] [argumento...]

DESCRIPCIÓN

VHS te permite escribir GIFs de terminal como código.

VHS lee archivos .tape y renderiza GIFs (vídeos).

Un archivo de cinta es un script compuesto por comandos que describen las acciones a realizar en el renderizado.

La siguiente es una lista de todos los comandos posibles en VHS:

  • Output <ruta>.(gif|webm|mp4)
  • Require <programa>
  • Set <ajuste> <valor>
  • Sleep <tiempo>
  • Type "<cadena>"
  • Ctrl [+Alt][+Shift]+<carácter>
  • Backspace [repetir]
  • Delete [repetir]
  • Insert [repetir]
  • Down [repetir]
  • Enter [repetir]
  • Left [repetir]
  • Right [repetir]
  • Tab [repetir]
  • Up [repetir]
  • PageUp [repetir]
  • PageDown [repetir]
  • Hide
  • Show
  • Wait[+Screen][@<tiempo_espera>] /<expresión_regular>/
  • Escape
  • Alt+<tecla>
  • Space [repetir]
  • Source <ruta>.tape
  • Screenshot <ruta>.png
  • Copy "<cadena>"
  • Paste

OPCIONES

-o, --output
nombre(s) de archivo de la salida de vídeo
-p, --publish
publica tu GIF en vhs.charm.sh y obtén una URL para compartir
-q, --quiet
silencioso, no registrar mensajes. Si se proporciona la opción publish, registrará la URL para compartir

COMANDOS

help [comando]
Ayuda sobre cualquier comando
new <nombre>
Crea un nuevo archivo de cinta con contenido y documentación de ejemplo
publish <gif>
Publica tu GIF en vhs.charm.sh y obtén una URL para compartir
record
Crea un nuevo archivo de cinta grabando tus acciones
OPCIONES
-s, --shell shell para grabar
serve
Inicia el servidor SSH de VHS
themes
Lista todos los temas disponibles, uno por línea
OPCIONES
--markdown salida en formato markdown
validate <archivo>...
Valida una ruta de archivo glob y analiza todos los archivos para asegurarse de que sean válidos sin ejecutarlos.

SALIDA

El comando Output (Salida) instruye a VHS dónde guardar la salida de la grabación.

Los nombres de archivo con las extensiones .gif, .webm, .mp4 tendrán los tipos de archivo respectivos.

AJUSTES

El comando Set (Ajustar) permite a VHS ajustar la configuración de la terminal, como fuentes, dimensiones y temas.

La siguiente es una lista de todos los comandos de ajuste posibles en VHS:

  • Set Shell <cadena>
  • Set FontSize <número>
  • Set FontFamily <cadena>
  • Set Height <número>
  • Set Width <número>
  • Set LetterSpacing <flotante>
  • Set LineHeight <flotante>
  • Set TypingSpeed <tiempo>
  • Set Theme <json|cadena>
  • Set Padding <número>
  • Set Framerate <número>
  • Set PlaybackSpeed <flotante>
  • Set WaitTimeout <tiempo>
  • Set WaitPattern <expresión_regular>
