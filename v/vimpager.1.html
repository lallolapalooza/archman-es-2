VIMPAGER(1) VIMPAGER(1)

NOMBRE

vimpager - reemplazo de less.sh

SINOPSIS

vimpager 'un archivo'

# o (esto no siempre resaltará la sintaxis tan bien)

cat 'un archivo' | vimpager

DEPENDENCIAS EN TIEMPO DE EJECUCIÓN

•
vim
•
sharutils o algún uudecode (opcional)

DEPENDENCIAS DE COMPILACIÓN

•
sharutils o algún uuencode
•
pandoc

INSTALACIÓN

git clone git://github.com/rkitover/vimpager
cd vimpager
sudo make install

Si obtuviste vimpager de la sección de scripts de vim.org, simplemente colócalo en algún lugar de tu PATH, por ejemplo:

cp vimpager ~/bin
chmod +x ~/bin/vimpager

En tu ~/.bashrc agrega lo siguiente:

export PAGER=/usr/local/bin/vimpager
alias less=$PAGER
alias zless=$PAGER

DESCRIPCIÓN

Un PAGINADOR usando less.vim con soporte para resaltar páginas de manual y muchas otras características. Funciona en la mayoría de los sistemas tipo UNIX, así como en Cygwin y MSYS.

En GitHub: http://github.com/rkitover/vimpager

Para usar un vimrc diferente con vimpager, coloca tus configuraciones en un archivo ~/.vimpagerrc o ~/.vim/vimpagerrc o en un archivo al que apunte la variable de entorno VIMPAGER_RC.

También puedes tener un archivo de configuración global para todos los usuarios en /etc/vimpagerrc, los usuarios pueden anularlo creando un ~/.vimpagerrc o un ~/.vim/vimpagerrc.

Estas son las teclas para paginar mientras estás en vimpager, son las mismas que en less en su mayor parte:

Tecla Acción Tecla Acción
Espacio Una página hacia adelante b Una página hacia atrás
d Media página hacia adelante u Media página hacia atrás
Enter Una línea hacia adelante k Una línea hacia atrás
G Fin del archivo g Inicio del archivo
N% porcentaje en el archivo ,h Mostrar esta ayuda
/patrón Buscar patrón ?patrón Buscar patrón hacia atrás
n siguiente coincidencia de patrón N Coincidencia de patrón anterior
:n Siguiente archivo :p Archivo anterior
q Salir ,v Alternar Modo Less

Para deshabilitar la carga de plugins, pon "set noloadplugins" en un archivo vimpagerrc.

También puedes activar la variable "vimpager" en tu vimrc para establecer configuraciones alternativas para vimpager.

Pon lo siguiente en tu .vimrc/vimpagerrc si quieres usar gvim/MacVim para tu ventana de paginador:

let vimpager_use_gvim = 1

Para desactivar la característica de pasar texto que es más pequeño que la altura de la terminal, usa esto:

let vimpager_passthrough = 0

Ver la sección "MODO DE PASO" más abajo.

Para iniciar vim con -X (sin conexión x11, inicio un poco más rápido) pon lo siguiente en tu .vimrc/vimpagerrc:

let vimpager_disable_x11 = 1

El desplazamiento de la pantalla (:help scrolloff), puede especificarse colocando lo siguiente en tu .vimrc/vimpagerrc (predeterminado = 5, deshabilitado = 0):

let vimpager_scrolloff = 5

El árbol de procesos de vimpager está disponible en la variable "vimpager_ptree", un ejemplo de uso es el siguiente:

if exists("vimpager")
  if exists("vimpager_ptree") && vimpager_ptree[-2] == 'wman'
    set ft=man
  endif
endif

Para deshabilitar el uso de AnsiEsc.vim para mostrar colores ANSI en el código fuente, establece:

let vimpager_disable_ansiesc = 1

ver la sección "SECUENCIAS DE ESCAPE ANSI Y SOBREESCRITURAS" para más detalles.

OPCIONES DE LÍNEA DE COMANDOS

+ | +G

Comenzar al final del archivo, igual que less.

-c cmd

Ejecutar un comando de vim después de abrir el archivo. Se admiten múltiples argumentos -c.

--cmd cmd

Ejecutar un comando de vim al entrar en vim antes que nada. Se admiten múltiples argumentos --cmd.

-u vimrc

Usar un .vimrc o .vimpagerrc alternativo.

SECUENCIAS DE ESCAPE ANSI Y SOBREESCRITURAS

Si tu código fuente utiliza códigos de escape ANSI, se usará el plugin AnsiEsc para mostrarlos, en lugar del resaltado normal de vim, sin embargo lee las advertencias a continuación. Si esto no es posible, se eliminarán y se usará el resaltado normal de vim en su lugar.

Las sobreescrituras como en las páginas de manual siempre se eliminarán.

vimpager incluye el plugin AnsiEsc (http://www.vim.org/scripts/script.php?script_id=4979) (se expande en tiempo de ejecución, no tienes que hacer nada para habilitarlo.)

Sin embargo, tu vim debe haber sido compilado con la característica 'conceal' habilitada. Para verificar, intenta:

:echo has("conceal")

si el resultado es '1' tienes conceal, si es '0' no lo tienes, y el plugin AnsiEsc no se habilitará.

Si estás en Mac, el vim del sistema no habilita esta característica, instala vim desde Homebrew.

Para deshabilitar el uso de AnsiEsc.vim, establece:

let vimpager_disable_ansiesc = 1

en tu .vimrc.

MODO DE PASO

Si el texto enviado al paginador es más pequeño que la ventana de la terminal, se mostrará sin vim como texto. Si tiene códigos ansi, se conservarán, de lo contrario, el texto se resaltará con vimcat.

Puedes desactivar esto poniendo:

let vimpager_passthrough = 0

El modo de paso requiere un shell POSIX con expansión aritmética, si existe uno en tu sistema y no se detecta, por favor envía un problema con la ruta y la versión de tu sistema operativo.

NOTAS SOBRE CYGWIN/MSYS/MSYS2

vimpager funciona correctamente con el gvim nativo de Windows, simplemente ponlo en tu PATH y establece la opción vimpager_use_gvim como se describe arriba.
