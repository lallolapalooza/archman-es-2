VFS_GLUSTERFS_FUSE(8) Herramientas de Administración del Sistema VFS_GLUSTERFS_FUSE(8)

NOMBRE

vfs_glusterfs_fuse - Utiliza las características proporcionadas por GlusterFS

SINOPSIS

objetos vfs = glusterfs_fuse

DESCRIPCIÓN

Este módulo VFS forma parte de la suite samba(8).

GlusterFS (http://www.gluster.org) es un sistema de archivos agrupado de código abierto capaz de escalar a varios petabytes. Con su cliente nativo basado en FUSE, GlusterFS está disponible como un sistema de archivos compatible con POSIX y, por lo tanto, puede ser compartido por Samba sin pasos adicionales.

El módulo VFS vfs_glusterfs_fuse proporciona una forma mejorada de acceder a un sistema de archivos Gluster utilizando un montaje Gluster FUSE. Ofrece soporte para la llamada VFS get_real_filename, que mejora el rendimiento del acceso a archivos al evitar múltiples llamadas costosas de búsqueda de coincidencia de mayúsculas y minúsculas para detectar la capitalización apropiada de un nombre de archivo existente.

Además, este módulo implementa un mecanismo sustituto de ID de archivo. El mecanismo predeterminado de ID de archivo no funciona correctamente para las reexportaciones de montajes Gluster FUSE, por lo que para evitar la pérdida de datos, los usuarios que exporten montajes Gluster FUSE con Samba deben habilitar este módulo.

Este módulo se puede combinar con otros módulos, pero debe ser el último módulo en la lista de objetos vfs. Los módulos añadidos a esta lista a la derecha de la entrada glusterfs pueden no tener ningún efecto.

CONFIGURACIÓN

Una configuración básica se ve así.

[compartir]
objetos vfs = glusterfs_fuse
ruta = /ruta/absoluta/del/montaje_fuse

Tenga en cuenta que vfs_glusterfs_fuse requiere un montaje Gluster. Para acceder directamente a glusterfs a través de la biblioteca GFAPI, utilice el módulo vfs_glusterfs.

OPCIONES

Este módulo actualmente no tiene opciones adicionales.
