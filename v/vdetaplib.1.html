VDETAPLIB(1) Manual de comandos generales VDETAPLIB(1)

NOMBRE

vdetaplib - Librería de emulación de interfaz tap de Ethernet distribuido virtual

SINOPSIS

Sin sinopsis

DESCRIPCIÓN

vdetaplib es una librería que emula la interfaz tap (interfaz de nivel 2 de tuntap, véase en las fuentes del kernel Documentation/networking/tun.c) y conecta interfaces virtuales tap a redes vde.

Para usarla, la librería libvdetab.so debe ser precargada (sintaxis sh, ksh o bash):


export LD_PRELOAD=/usr/lib/vde2/libvdetap.so
(sintaxis csh, tcsh):

setenv LD_PRELOAD /usr/lib/vde2/libvdetap.so

Si desea redirigir todas las solicitudes de tap a un único vde_switch, establezca la variable VDEALLTAP al socket vde.
(sintaxis sh, ksh o bash):


export VDEALLTAP=/tmp/vde.ctl
(sintaxis csh, tcsh):

setenv VDEALLTAP /tmp/vde.ctl

Es posible configurar cada interfaz individualmente a diferentes vde_switches estableciendo la variable de entorno con el mismo nombre de la interfaz.
(sintaxis sh, ksh o bash):


export tap0=/tmp/vde.ctl
export tap1=/tmp/myvde.ctl
export ppc=/tmp/ppc.ctl
(sintaxis csh, tcsh):

setenv tap0 /tmp/vde.ctl
setenv tap1 /tmp/myvde.ctl
setenv ppc /tmp/ppc.ctl

También es posible especificar el puerto, el grupo o el modo para una interfaz dada estableciendo variables de entorno como en el siguiente ejemplo.
(sintaxis sh, ksh o bash):


export tap0_port=5
export tap0_group=vde-net
export tap0_mode=0660
(sintaxis csh, tcsh):

setenv tap0_port 5
setenv tap0_group vde-net
setenv tap0_mode 0660

La variable para establecer la interfaz específica se verifica primero, luego VDEALLTAP. Por lo tanto, VDEALLTAP funciona como una opción predeterminada para el switch vde a utilizar. Si VDEALLTAP no está configurado y no hay una variable de entorno específica (y para las interfaces tun -- IFF_TUN), se utiliza la interfaz proporcionada por el kernel. En este último caso, se requiere acceso a /dev/net/tun, generalmente acceso de root.
