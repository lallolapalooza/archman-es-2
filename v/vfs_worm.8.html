VFS_WORM(8) Herramientas de administración del sistema VFS_WORM(8)

NOMBRE

vfs_worm - deshabilita la escritura para archivos antiguos

SINOPSIS

objetos vfs = worm

DESCRIPCIÓN

Este módulo VFS forma parte de la suite samba(7).

El módulo vfs_worm controla la capacidad de escritura de archivos y carpetas dependiendo de su tiempo de modificación y un período de gracia ajustable.

Si la hora de modificación de un archivo o directorio es anterior al período de gracia especificado, se denegará el acceso de escritura, independientemente de otros controles de acceso (por ejemplo, del sistema de archivos).

En caso de que no se supere el período de gracia, el módulo worm no afectará a ningún control de acceso.

OPCIONES

worm:grace_period = SEGUNDOS

Período en segundos que define el tiempo durante el cual el acceso de escritura se gestionará mediante los controles de acceso normales. Después de este período de gracia, el archivo o directorio se vuelve de solo lectura.

EJEMPLOS

Denegar el acceso de escritura a archivos y carpetas que tengan más de cinco minutos (300 segundos) de antigüedad:

[wormshare]
objetos vfs = worm
worm:grace_period = 300
