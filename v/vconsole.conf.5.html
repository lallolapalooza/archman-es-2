NOMBRE

vconsole.conf - Archivo de configuración para la consola virtual

SINOPSIS

/etc/vconsole.conf

DESCRIPCIÓN

El archivo /etc/vconsole.conf configura la consola virtual, es decir, el mapeo del teclado y la fuente de la consola. Se aplica al arrancar mediante udev usando el archivo 90-vconsole.rules. Puedes enmascarar seguramente este archivo si deseas evitar este tipo de inicialización.

El formato de vconsole.conf es una lista separada por saltos de línea de asignaciones de variables compatibles con el shell, similar a las variables de entorno, ignorando comentarios y líneas vacías. Es posible incluir la configuración desde scripts de shell, sin embargo, más allá de meras asignaciones de variables, no se admiten características del shell, lo que permite a las aplicaciones leer el archivo sin implementar un motor de ejecución compatible con el shell. Consulte os-release(5) para una descripción detallada del formato.

Tenga en cuenta que las opciones de la línea de comandos del kernel vconsole.keymap=, vconsole.keymap_toggle=, vconsole.font=, vconsole.font_map=, vconsole.font_unimap= pueden usarse para anular la configuración de la consola al arrancar.

Dependiendo del sistema operativo, es posible que también se consulten otros archivos de configuración para la configuración de la consola virtual, pero solo como recurso de reserva.

/etc/vconsole.conf generalmente se crea y actualiza usando systemd-localed.service(8). localectl(1) puede usarse para instruir a systemd-localed.service para consultar o actualizar la configuración.

OPCIONES

Se entienden las siguientes opciones:

KEYMAP=, KEYMAP_TOGGLE=

Configura la tabla de mapeo de teclas para el teclado. KEYMAP= por defecto es "us" si no se establece. Especialmente, si se especifica "@kernel", no se cargará ningún mapa de teclas, es decir, se usa el mapa de teclas predeterminado del kernel. KEYMAP_TOGGLE= se puede usar para configurar un segundo mapa de teclas de alternancia y por defecto no está establecido.

FONT=, FONT_MAP=, FONT_UNIMAP=

Configura la fuente de la consola, el mapa de la consola y el mapa de fuentes unicode.

LÍNEA DE COMANDOS DEL KERNEL

Algunos parámetros de configuración de vconsole.conf pueden ser anulados en la línea de comandos del kernel:

vconsole.keymap=, vconsole.keymap_toggle=

Anula KEYMAP= y KEYMAP_TOGGLE=.

Añadido en la versión 232.

vconsole.font=, vconsole.font_map=, vconsole.font_unimap=

Anula FONT=, FONT_MAP= y FONT_UNIMAP=.

Añadido en la versión 232.

EJEMPLO

Ejemplo 1. Teclado y consola en alemán

/etc/vconsole.conf:

KEYMAP=de-latin1
FONT=eurlatgr
