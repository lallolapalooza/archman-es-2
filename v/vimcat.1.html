NOMBRE

vimcat - resaltador de sintaxis basado en vim

SINOPSIS

vimcat algún_archivo

DESCRIPCIÓN

Concatena un archivo a la salida estándar, resaltando su sintaxis utilizando vim como backend.

En GitHub: http://github.com/rkitover/vimpager

Para usar un vimrc diferente con vimcat, coloca tus configuraciones en un archivo ~/.vimcatrc.

Para deshabilitar la carga de plugins, coloca "set noloadplugins" en un archivo ~/.vimcatrc.

OPCIONES DE LÍNEA DE COMANDOS

-c cmd

Ejecuta un comando de vim después de abrir el archivo. Se admiten múltiples argumentos -c.

--cmd cmd

Ejecuta un comando de vim al iniciar vim antes de cualquier otra cosa. Se admiten múltiples argumentos --cmd.

-u vimrc

Usa un .vimrc o .vimcatrc alternativo.
