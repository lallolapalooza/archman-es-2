NOMBRE

vkmark - Suite de benchmarks de Vulkan

SINOPSIS

vkmark [opciones]

DESCRIPCIÓN

vkmark es una suite de benchmarking de Vulkan extensible con escenas dirigidas y configurables.

OPCIONES

-b, --benchmark BENCHMARK
Un benchmark a ejecutar: 'escena(:opt1=val1)*' (la opción se puede usar múltiples veces)
-s, --size AxA
Tamaño de la ventana de salida (por defecto: 800x600)
--fullscreen
Ejecutar en modo pantalla completa (equivalente a --size -1x-1)
-p, --present-mode PM
Modo de presentación de Vulkan (por defecto: mailbox) [immediate, mailbox, fifo, fiforelaxed]
--pixel-format PF
Formato de píxeles de Vulkan (por defecto: elegir el mejor)
-l, --list-scenes
Mostrar información sobre las escenas disponibles y sus opciones
--show-all-options
Mostrar todos los valores de opciones de escena utilizados para los benchmarks (por defecto, solo se muestran las opciones establecidas explícitamente)
--winsys-dir DIR
Directorio en el que buscar plugins del sistema de ventanas
--data-dir DIR
Directorio en el que buscar archivos de datos de escena
--winsys WS
Plugin del sistema de ventanas a utilizar (por defecto: elegir el mejor) [xcb, wayland, kms]
--winsys-options OPTS
Opciones del sistema de ventanas como 'opt1=val1(:opt2=val2)*'
--run-forever
Ejecutar indefinidamente, repitiendo desde el último benchmark hasta el primero
-d, --debug
Mostrar mensajes de depuración
-D, --use-device
Usar dispositivo Vulkan con UUID especificado
-L, --list-devices
Listar dispositivos Vulkan
-h, --help
Mostrar ayuda

BENCHMARKS

vkmark ofrece un conjunto de escenas que se pueden usar para medir diversos aspectos del rendimiento de Vulkan. La forma en que cada escena se renderiza es configurable a través de un conjunto de opciones. Para obtener las escenas disponibles y sus opciones aceptables, puede usar la opción de línea de comandos -l, --list-scenes.

En vkmark, un benchmark se define como una escena más un conjunto de valores de opciones. Puede especificar la lista y el orden de los benchmarks a ejecutar utilizando la opción de línea de comandos -b, --benchmark (posiblemente varias veces). Si no se especifican benchmarks, se utiliza un conjunto predeterminado de benchmarks. Si no se especifica una opción de benchmark, asume su valor predeterminado (listado con -l, --list-scenes).

Como caso especial, se permite que una cadena de descripción de benchmark no contenga un nombre de escena (es decir, que comience con ':'). En este caso, los valores de opción especificados se utilizan como valores predeterminados para los benchmarks que siguen a esta cadena de descripción.

EJEMPLOS

Para ejecutar los benchmarks predeterminados:

vkmark

Para ejecutar un benchmark utilizando la escena 'vertex' con una 'duration' de '5.0' segundos y 'interleave' establecido en 'false':

vkmark -b vertex:duration=5.0:interleave=false

Para ejecutar una serie de benchmarks, use la opción de línea de comandos -b, --benchmark varias veces:

vkmark -b vertex:duration=5.0 -b clear:color=1.0,0.5,0 -b cube

Para establecer valores de opción predeterminados para los benchmarks y ejecutarlos:

vkmark -b :duration=2.0 -b vertex -b clear -b :duration=5.0 -b cube

Para establecer valores de opción predeterminados para los benchmarks predeterminados y ejecutarlos:

vkmark -b :duration=2.0
