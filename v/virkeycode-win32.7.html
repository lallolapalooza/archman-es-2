Name

virkeycode-win32 - Win32 keycode mapping

DESCRIPTION

The virkeycode-win32 command is used to query the Win32 keyboard scancode mappings for the libvirt library.

This utility is primarily used for debugging and understanding keyboard input translations between Windows and the underlying virtual machine environment.
