NOMBRE

valabind — conversor de interfaces de vala a swig

SINOPSIS

valabind [-h] [-x] [-v] [-V vapidir] [-o archivo_salida] [-m nombre_modulo] [-p perfil] [-N espacio_nombres] [-D SIMBOLO] [--swig] [--node-ffi] [--ctypes] [--gir] [--cxx] archivo_api_vala

DESCRIPCIÓN

Valabind es un programa escrito en Vala que tiene como objetivo generar interfaces para nodejs, c++ o SWIG (.i) a partir de archivos vapi generados por vala o creados manualmente.

SWIG abre la puerta a la creación de bindings para Python, Perl, ruby, lua y muchos otros lenguajes de scripting.

-h
mostrar mensaje de ayuda
-o SALIDA
especificar el nombre del archivo de salida
-m NOMBRE
especificar el nombre del módulo
-N NS
incluir el espacio de nombres dado para procesamiento
-D SIMBOLO
definir un símbolo preprocesador dentro del código Vala
-p PERFIL
seleccionar el perfil de Vala (posix, gobject, dova)
-x
generar código c++ para bindings de SWIG
-v
mostrar información de la versión
-V RUTA
especificar una ruta alternativa para vapidir

AMBIENTE

XDG_DATA_DIRS
Variable de entorno estándar de freedesktop para apuntar al directorio de prefijo compartido donde vala busca archivos vapi.
