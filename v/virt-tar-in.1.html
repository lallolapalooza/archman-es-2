NOMBRE

virt-tar-in - Desempaqueta un tarball en una imagen de disco de máquina virtual.

SINOPSIS

virt-tar-in -a disk.img data.tar /destino
virt-tar-in -d dominio data.tar /destino
zcat data.tar.gz | virt-tar-in -d dominio - /destino

ADVERTENCIA

Usar "virt-tar-in" en máquinas virtuales en vivo, o concurrentemente con otras herramientas de edición de discos, puede ser peligroso, causando potencialmente corrupción del disco. La máquina virtual debe ser apagada antes de usar este comando, y las imágenes de disco no deben ser editadas concurrentemente.

DESCRIPCIÓN

"virt-tar-in" desempaqueta un tarball no comprimido en una imagen de disco de máquina virtual o dominio libvirt nombrado.

El primer parámetro es el archivo tar. Usa "-" para leer el archivo tar desde la entrada estándar. El segundo parámetro es el directorio de destino absoluto donde desempaquetar.

EJEMPLOS

Sube un directorio de inicio a un invitado:

virt-tar-in -d MiInvitado homes.tar /home

SOLO UN SCRIPT DE ENVOLTURA ALREDEDOR DE GUESTFISH

Este comando es solo un script de envoltura simple alrededor del comando "tar-in" de guestfish(1). Para algo más complejo que una copia trivial, probablemente sea mejor usar guestfish directamente.

OPCIONES

Dado que el script de shell simplemente pasa las opciones directamente a guestfish, lee guestfish(1) para ver la lista completa de opciones.

VER TAMBIÉN
