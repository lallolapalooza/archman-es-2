VFS_DEFAULT_QUOTA(8) Herramientas de administración del sistema VFS_DEFAULT_QUOTA(8)

NOMBRE

vfs_default_quota - almacenar registros de cuota predeterminados para clientes de Windows

SINOPSIS

objetos vfs = default_quota

DESCRIPCIÓN

Este módulo VFS es parte del conjunto samba(7).

Muchas implementaciones comunes de cuotas solo almacenan cuotas para usuarios y grupos, pero no almacenan una cuota predeterminada. El módulo vfs_default_quota permite a Samba almacenar valores de cuota predeterminados que se pueden examinar utilizando la interfaz del Explorador de Windows.

Por defecto, Samba devuelve NO_LIMIT para la cuota predeterminada y se niega a actualizarlas. vfs_default_quota mapea la cuota predeterminada al registro de cuota de un usuario. Por defecto, se toma el usuario root porque los límites de cuota para root generalmente no se aplican.

Este módulo es apilable.

OPCIONES

default_quota:uid = UID

UID especifica el ID de usuario del registro de cuota donde se almacenan los valores de cuota de usuario predeterminados.

default_quota:gid = GID

GID especifica el ID de grupo del registro de cuota donde se almacenan los valores de cuota de grupo predeterminados.

default_quota:uid nolimit = BOOL

Si este parámetro es True, entonces el usuario cuyo registro de cuota está almacenando la cuota de usuario predeterminada se informará como que tiene una cuota de NO_LIMIT. De lo contrario, se informarán los valores almacenados.

default_quota:gid nolimit = BOOL

Si este parámetro es True, entonces el grupo cuyo registro de cuota está almacenando la cuota de grupo predeterminada se informará como que tiene una cuota de NO_LIMIT. De lo contrario, se informarán los valores almacenados.

EJEMPLOS

Almacenar el registro de cuota predeterminado en el registro de cuota del usuario con ID 65535 e informar que ese usuario no tiene límites de cuota:

        [global]
	vfs objects = default_quota
	default_quota:uid = 65535
	default_quota:uid nolimit = yes
