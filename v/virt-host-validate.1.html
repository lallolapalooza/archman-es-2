Nombre

virt-host-validate - valida la configuración de virtualización del host

SINAPSIS

virt-host-validate [OPCIONES...] [TIPO-HV]

DESCRIPCIÓN

Esta herramienta valida que el host esté configurado de manera adecuada para ejecutar los controladores de hipervisor de libvirt. Si se invoca sin argumentos, verificará la compatibilidad para todos los controladores de hipervisor que conozca. Opcionalmente, se le puede dar un tipo de hipervisor particular (qemu, lxc o bhyve) para restringir las verificaciones a las relevantes para esa tecnología de virtualización.

OPCIONES

-v, --version

Muestra la versión del comando

-h, --help

Muestra la ayuda de la línea de comandos

-q, --quiet

No muestres detalles de las comprobaciones individuales que se están realizando. Solo muestra la salida si una comprobación no pasa.

ESTADO DE SALIDA

Tras una validación exitosa, se establecerá un estado de salida de 0. En caso de fallo, se establecerá un estado distinto de cero.
