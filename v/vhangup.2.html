vhangup(2) Manual de llamadas al sistema vhangup(2)

NOMBRE

vhangup - colgar virtualmente la terminal actual

BIBLIOTECA

Biblioteca C estándar (libc, -lc)

SINOPSIS

#include <unistd.h>
int vhangup(void);
Requisitos de Macro de Prueba de Funcionalidad para glibc (ver feature_test_macros(7)):

vhangup():

    Desde glibc 2.21:
        _DEFAULT_SOURCE
    En glibc 2.19 y 2.20:
        _DEFAULT_SOURCE || (_XOPEN_SOURCE && _XOPEN_SOURCE < 500)
    Hasta glibc 2.19 inclusive:
        _BSD_SOURCE || (_XOPEN_SOURCE && _XOPEN_SOURCE < 500)

DESCRIPCIÓN

vhangup() simula una desconexión en la terminal actual. Esta llamada organiza que otros usuarios tengan una terminal “limpia” al iniciar sesión.

VALOR DE RETORNO

En caso de éxito, se devuelve cero. En caso de error, se devuelve -1 y errno se establece para indicar el error.

ERRORES

EPERM
El proceso que llama tiene privilegios insuficientes para llamar a vhangup(); se requiere la capacidad CAP_SYS_TTY_CONFIG.

ESTANDARES

Linux.

VER TAMBIÉN

init(1), capabilities(7)
