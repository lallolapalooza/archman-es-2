wprintf(3) Manual de Funciones de Biblioteca wprintf(3)

NOMBRE

wprintf, fwprintf, swprintf, vwprintf, vfwprintf, vswprintf - conversión de salida formateada de caracteres anchos

BIBLIOTECA

Biblioteca C estándar (libc, -lc)

SINOPSIS

#include <stdio.h>
#include <wchar.h>
int wprintf(const wchar_t *restrict format, ...);
int fwprintf(FILE *restrict stream,
             const wchar_t *restrict format, ...);
int swprintf(size_t n;
             wchar_t wcs[restrict n], size_t n,
             const wchar_t *restrict format, ...);
int vwprintf(const wchar_t *restrict format, va_list args);
int vfwprintf(FILE *restrict stream,
             const wchar_t *restrict format, va_list args);
int vswprintf(size_t n;
             wchar_t wcs[restrict n], size_t n,
             const wchar_t *restrict format, va_list args);
Requisitos de macro de prueba de características para glibc (ver feature_test_macros(7)):

Todas las funciones mostradas anteriormente:

    _XOPEN_SOURCE >= 500 || _ISOC99_SOURCE
        || _POSIX_C_SOURCE >= 200112L

DESCRIPCIÓN

La familia de funciones wprintf() es el equivalente de caracteres anchos de la familia de funciones printf(3). Realiza la conversión de salida formateada de caracteres anchos.

Las funciones wprintf() y vwprintf() realizan salida de caracteres anchos a stdout. stdout no debe estar orientado a bytes; ver fwide(3) para más información.

Las funciones fwprintf() y vfwprintf() realizan salida de caracteres anchos a stream. stream no debe estar orientado a bytes; ver fwide(3) para más información.

Las funciones swprintf() y vswprintf() realizan salida de caracteres anchos a una matriz de caracteres anchos. El programador debe asegurarse de que haya espacio para al menos n caracteres anchos en wcs.

Estas funciones son como las funciones printf(3), vprintf(3), fprintf(3), vfprintf(3), sprintf(3), vsprintf(3) excepto por las siguientes diferencias:

•
La cadena format es una cadena de caracteres anchos.
•
La salida consiste en caracteres anchos, no en bytes.
•
swprintf() y vswprintf() toman un argumento n, sprintf(3) y vsprintf(3) no lo hacen. (snprintf(3) y vsnprintf(3) toman un argumento n, pero estas funciones no devuelven -1 ante desbordamiento del búfer en Linux.)

El tratamiento de los caracteres de conversión c y s es diferente:

c
Si no hay un modificador l presente, el argumento int se convierte a un carácter ancho mediante una llamada a la función btowc(3), y se escribe el carácter ancho resultante. Si hay un modificador l presente, se escribe el argumento wint_t (carácter ancho).
s
Si no hay un modificador l presente: se espera que el argumento const char * sea un puntero a una matriz de tipo carácter (puntero a una cadena) que contiene una secuencia de caracteres multibyte que comienza en el estado de cambio inicial. Los caracteres de la matriz se convierten a caracteres anchos (cada uno mediante una llamada a la función mbrtowc(3) con un estado de conversión que comienza en el estado inicial antes del primer byte). Los caracteres anchos resultantes se escriben hasta el carácter ancho nulo terminador (L'\0') (sin incluirlo). Si se especifica una precisión, no se escriben más caracteres anchos que el número especificado. Tenga en cuenta que la precisión determina el número de caracteres anchos escritos, no el número de bytes o posiciones de pantalla. La matriz debe contener un byte nulo terminador ('\0'), a menos que se proporcione una precisión y esta sea tan pequeña que el número de caracteres anchos convertidos llegue a ella antes de que se alcance el final de la matriz. Si hay un modificador l presente: se espera que el argumento const wchar_t * sea un puntero a una matriz de caracteres anchos. Los caracteres anchos de la matriz se escriben hasta un carácter ancho nulo terminador (sin incluirlo). Si se especifica una precisión, no se escriben más que el número especificado. La matriz debe contener un carácter ancho nulo terminador, a menos que se proporcione una precisión y esta sea menor o igual al número de caracteres anchos en la matriz.

VALOR DE RETORNO

Las funciones devuelven el número de caracteres anchos escritos, excluyendo el carácter ancho nulo terminador en el caso de las funciones swprintf() y vswprintf(). En caso de error, se devuelve -1 y se establece errno para indicar el error.

ERRORES

Ver write(2) y putwc(3). Además, puede ocurrir el siguiente error:

EOVERFLOW
El valor a devolver es mayor que INT_MAX.

Las funciones fwprintf() y wprintf() pueden fallar además si:

ENOMEM
No hay suficiente espacio de almacenamiento disponible.

NOTAS

El comportamiento de wprintf() y similares depende de la categoría LC_CTYPE de la configuración regional actual.

Si la cadena format contiene caracteres anchos no ASCII, el programa funcionará correctamente solo si la categoría LC_CTYPE de la configuración regional actual en tiempo de ejecución es la misma que la categoría LC_CTYPE de la configuración regional actual en tiempo de compilación. Esto se debe a que la representación de wchar_t depende de la plataforma y la configuración regional. (glibc representa caracteres anchos utilizando su punto de código Unicode (ISO/IEC 10646), pero otras plataformas no lo hacen. Además, el uso de nombres de caracteres universales C99 del tipo \unnnn no resuelve este problema). Por lo tanto, en programas internacionalizados, la cadena format debe consistir solo en caracteres anchos ASCII, o debe construirse en tiempo de ejecución de forma internacionalizada (por ejemplo, utilizando gettext(3) o iconv(3), seguido de mbstowcs(3)).
