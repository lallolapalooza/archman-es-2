NOMBRE

varnishstat - estadísticas de Varnish Cache

SINOPSIS

varnishstat [-1] [-c] [-f <glob>] [-h] [-I <glob>] [-j] [-l] [-n <directorio_trabajo>] [-r] [-t <segundos|off>] [-V] [-X <glob>] [-x]

DESCRIPCIÓN

La utilidad varnishstat muestra estadísticas de una instancia de varnishd(1) en ejecución.

Las siguientes opciones están disponibles:

-1
En lugar de presentar una pantalla actualizada continuamente, imprime las estadísticas en la salida estándar. Este es el valor predeterminado cuando la salida estándar está siendo redirigida.
-c
Presenta una pantalla interactiva actualizada continuamente. Este es el valor predeterminado cuando la salida estándar no está redirigida.
-f <glob>
Glob de filtrado de campos heredado. Usa la barra invertida para escapar caracteres. Si el argumento comienza con '^' se usa como un glob exclusivo. Se pueden dar múltiples argumentos -f. Los globs de filtrado heredados se ejecutan junto con los globs de inclusión (argumentos -I) y los globs de exclusión (argumentos -X) en orden, según la primera coincidencia.
-h
Imprime el uso del programa y sale.
-I <glob>
Glob de inclusión de campos. Usa la barra invertida para escapar caracteres. Se pueden dar múltiples argumentos -I. Los globs de exclusión se ejecutan en orden junto con los globs de exclusión (-X) y los globs de filtrado heredados (-f) según la primera coincidencia.
-j
Imprime las estadísticas en la salida estándar como JSON.
-l
Lista los campos disponibles para usar con la opción -f.
-n <directorio_trabajo>
Especifica el directorio de trabajo de Varnish de la instancia a la que conectarse. Consulte la documentación de la opción -n de varnishd(1) para obtener información adicional y los valores predeterminados.
-r
Cambia entre medidores brutos o ajustados, siendo ajustados el valor predeterminado.
-t <segundos|off>
Tiempo de espera antes de devolver un error en la conexión VSM inicial. Si se establece, la conexión VSM se reintentará cada 0.5 segundos durante esta cantidad de segundos. Si es cero, la conexión se intentará solo una vez y fallará inmediatamente si no tiene éxito. Si se establece en "off", la conexión no fallará, permitiendo que la utilidad comience y espere indefinidamente a que aparezca la instancia de Varnish. El valor predeterminado es 5 segundos.
-V
Imprime la información de la versión y sale.
-X <glob>
Glob de exclusión de campos. Usa la barra invertida para escapar caracteres. Se pueden dar múltiples argumentos -X. Los globs de exclusión se ejecutan en orden junto con los globs de inclusión (-I) y los globs de filtrado heredados (-f) según la primera coincidencia.
-x
Imprime las estadísticas en la salida estándar como XML.
--optstring
Imprime el parámetro optstring para getopt(3) para ayudar a escribir scripts de envoltura.

MODO CURSES

Cuando no se dan las opciones -1, -j ni -x, la aplicación se inicia en modo curses. Esto muestra una vista continuamente actualizada de los valores de los contadores, junto con su descripción.

El área superior muestra información sobre el tiempo de actividad del proceso.

El área central muestra una lista de valores de contadores.

El área inferior muestra la descripción del contador seleccionado actualmente.

Al inicio, solo se muestran los contadores de nivel INFO.

Columnas

Las siguientes columnas se muestran, de izquierda a derecha:

Nombre
El nombre del contador.
Actual
El valor actual del contador.
Cambio
El cambio promedio por segundo durante el último intervalo de actualización.
Promedio
El valor promedio de este contador durante el tiempo de ejecución del demonio de Varnish, o un período si el contador no se puede promediar.
Prom_10
El promedio móvil durante los últimos 10 intervalos de actualización.
Prom_100
El promedio móvil durante los últimos 100 intervalos de actualización.
Prom_1000
El promedio móvil durante los últimos 1000 intervalos de actualización.

Atajos de teclado

<h>
Alterna la pantalla de ayuda.
<ARRIBA> o <k>
Navega por la lista de contadores una línea hacia arriba.
<ABAJO> o <j>
Navega por la lista de contadores una línea hacia abajo.
<PAGUP> o <b> o <CTRL-B>
Navega por la lista de contadores una página hacia arriba.
<PAGDOWN> o <ESPACIO> o <CTRL-F>
Navega por la lista de contadores una página hacia abajo.
<INICIO> o <g>
Navega por la lista de contadores hasta el principio.
<FIN> o <G>
Navega por la lista de contadores hasta el final.
<d>
Alterna entre mostrar y ocultar contadores no vistos. Los contadores no vistos son aquellos que han estado en cero durante todo el tiempo de ejecución de varnishstat. Por defecto, se ocultan los contadores no vistos.
<r>
Alterna entre mostrar medidores brutos y ajustados. Cuando un medidor se decrementa más rápido de lo que se incrementa, puede aparecer como un entero grande con su bit más significativo establecido. Por defecto, dichos valores se ajustan a cero.
<e>
Alterna el escalado de valores.
<v>
Aumenta la verbosidad. Por defecto, solo se muestran los contadores informativos.
<V>
Disminuye la verbosidad. Por defecto, solo se muestran los contadores informativos.
<q>
Salir.
<CTRL+T>
Muestrear ahora.
<0>
Reiniciar promedios.
<+>
Aumentar el intervalo de actualización.
< ->
Disminuir el intervalo de actualización.

SALIDAS

El formato de salida XML es:

<varnishstat timestamp="AAAA-MM-DDTHH:mm:SS">
  <stat>
    <name>NOMBRE DEL CAMPO</name>
    <value>VALOR DEL CAMPO</value>
    <flag>SEMÁNTICA DEL CAMPO</flag>
    <format>FORMATO DE VISUALIZACIÓN DEL CAMPO</format>
    <description>DESCRIPCIÓN DEL CAMPO</description>
  </stat>
  [..]
</varnishstat>

El formato de salida JSON es:

{
  "timestamp": "AAAA-MM-DDTHH:mm:SS",
  "NOMBRE DEL CAMPO": {
    "description": "DESCRIPCIÓN DEL CAMPO",
    "flag": "SEMÁNTICA DEL CAMPO", "format": "FORMATO DE VISUALIZACIÓN DEL CAMPO",
    "value": VALOR DEL CAMPO
  },
  "NOMBRE DEL CAMPO": {
    "description": "DESCRIPCIÓN DEL CAMPO",
    "flag": "SEMÁNTICA DEL CAMPO", "format": "FORMATO DE VISUALIZACIÓN DEL CAMPO",
    "value": VALOR DEL CAMPO
  },
  [..]
}

La marca de tiempo es la hora en que varnishstat generó el informe.

NAME

varnishstat — Varnish HTTP accelerator statistics

SYNOPSIS

varnishstat [-1] [-a] [-f FIELD,...] [-h] [-n name] [-o] [-P file] [-r file] [-T ip:port]

DESCRIPTION

The varnishstat utility displays statistics from a running Varnish cache process.

The statistics are presented in a table with the following columns:

NAME
The name of the statistic.
CUR
The current value of the statistic.
AVG
The average value of the statistic over time.
MAX
The maximum value of the statistic.
MIN
The minimum value of the statistic.

The following options are available:

-1
Print the statistics once and exit.
-a
Show all statistics, including those with a current value of zero.
-f FIELD,...
Only display the specified fields. Field names are separated by commas. This option can be specified multiple times.
-h
Show the statistics in a human-readable format.
-n name
Specify the Varnish instance name to connect to. If not specified, the default instance name is used.
-o
Omit the header line. This is useful for scripting.
-P file
Write the process ID of varnishstat to the specified file.
-r file
Read statistics from the specified file instead of connecting to a running Varnish process. This is useful for analyzing statistics dumps.
-T ip:port
Connect to the Varnish shared memory log using the specified address and port. The default is an abstract Unix domain socket named “/var/run/varnish.sock”.

CURSES MODE

When no options are specified, varnishstat runs in curses mode, displaying a continuously updating screen of statistics.

The following keys can be used in curses mode:

q
Quit.
a
Toggle showing all statistics (including zero values).
f
Filter fields. Prompts for a comma-separated list of fields to display.
h
Toggle human-readable output.
o
Toggle omitting the header line.

OUTPUTS

The output of varnishstat includes a wide variety of statistics, such as:

client_req
Number of client requests.
client_res
Number of client responses.
backend_req
Number of backend requests.
backend_res
Number of backend responses.
backend_fail
Number of backend failures.
backend_retry
Number of backend retries.
cache_hit
Number of cache hits.
cache_miss
Number of cache misses.
sess_mem
Number of sessions using memory.
sess_disk
Number of sessions using disk.
thread_poller
Number of poller threads.
thread_worker
Number of worker threads.
backend_conn
Number of backend connections.
backend_busy
Number of busy backend connections.
backend_free
Number of free backend connections.
backend_queued
Number of backend requests queued.
accept_fail
Number of accept failures.
client_drop
Number of client connections dropped.

The exact list of statistics may vary depending on the Varnish version and configuration.
