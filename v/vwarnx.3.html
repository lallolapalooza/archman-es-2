err(3) Manual de Funciones de Biblioteca err(3)

NOMBRE

err, verr, errx, verrx, warn, vwarn, warnx, vwarnx - mensajes de error formateados

BIBLIOTECA

Biblioteca estándar C (libc, -lc)

SINOPSIS

#include <err.h>
[[noreturn]] void err(int eval, const char *fmt, ...);
[[noreturn]] void errx(int eval, const char *fmt, ...);
void warn(const char *fmt, ...);
void warnx(const char *fmt, ...);
#include <stdarg.h>
[[noreturn]] void verr(int eval, const char *fmt, va_list args);
[[noreturn]] void verrx(int eval, const char *fmt, va_list args);
void vwarn(const char *fmt, va_list args);
void vwarnx(const char *fmt, va_list args);

DESCRIPCIÓN

La familia de funciones err() y warn() muestra un mensaje de error formateado en la salida de error estándar. En todos los casos, se muestra el último componente del nombre del programa, un carácter de dos puntos y un espacio. Si el argumento fmt no es NULL, se muestra el mensaje de error formateado similar a printf(3). La salida se termina con un carácter de nueva línea.

Las funciones err(), verr(), warn(), y vwarn() añaden un mensaje de error obtenido de strerror(3) basado en la variable global errno, precedido por otros dos puntos y un espacio a menos que el argumento fmt sea NULL.

Las funciones errx() y warnx() no añaden un mensaje de error.

Las funciones err(), verr(), errx(), y verrx() no devuelven valor, sino que salen con el valor del argumento eval.

EJEMPLOS

Mostrar la cadena de información de errno actual y salir:


p = malloc(size);
if (p == NULL)
    err(EXIT_FAILURE, NULL);
fd = open(file_name, O_RDONLY, 0);
if (fd == -1)
    err(EXIT_FAILURE, "%s", file_name);

Mostrar un mensaje de error y salir:


if (tm.tm_hour < START_TIME)
    errx(EXIT_FAILURE, "demasiado temprano, espere hasta las %s",
            start_time_string);

Advertir de un error:


fd = open(raw_device, O_RDONLY, 0);
if (fd == -1)
    warnx("%s: %s: intentando el dispositivo de bloque",
            raw_device, strerror(errno));
fd = open(block_device, O_RDONLY, 0);
if (fd == -1)
    err(EXIT_FAILURE, "%s", block_device);
