Nombre

virt-qemu-run - Ejecutar un huésped QEMU independiente

SINOPSIS

virt-qemu-run [OPCIÓN]... ARCHIVO-XML-HUÉSPED

DESCRIPCIÓN

Esta herramienta proporciona una forma de ejecutar un huésped QEMU independiente de tal manera que sea completamente independiente de libvirtd. Hace uso del soporte del controlador QEMU integrado para ejecutar la VM, colocando archivos bajo un árbol de directorios aislado. Cuando el huésped se ejecuta con esta herramienta, es invisible para libvirtd y, por lo tanto, también invisible para otras herramientas de libvirt como virsh.

El programa virt-qemu-run ejecutará la máquina virtual QEMU y luego se bloqueará hasta que el sistema operativo huésped se apague, momento en el cual saldrá.

Si el programa virt-qemu-run es interrumpido (por ejemplo, Ctrl-C), terminará inmediatamente la máquina virtual sin dar al sistema operativo huésped ninguna oportunidad de apagarse de forma segura.

NOTA: esta herramienta se considera actualmente experimental. Su uso y comportamiento aún están sujetos a cambios en futuras versiones de libvirt. Para obtener más información sobre su uso, consulte la documentación del controlador QEMU https://libvirt.org/drvqemu.html#embedded-driver.

OPCIONES

ARCHIVO-XML-HUÉSPED

La ruta completa al archivo XML que describe la máquina virtual huésped que se va a arrancar.

-r DIR, --root=DIR

Especificar el directorio raíz a utilizar para almacenar el estado asociado con la máquina virtual. El llamante es responsable de eliminar este directorio cuando ya no se requiera.

Si se omite este parámetro, se creará un directorio temporal aleatorio y su contenido se eliminará automáticamente al apagar la VM.

-s ARCHIVO-XML-SECRETO,ARCHIVO-VALOR-SECRETO, --secret=ARCHIVO-XML-SECRETO,ARCHIVO-VALOR-SECRETO

Especificar un secreto que se cargará en el controlador de secretos. ARCHIVO-XML-SECRETO es una ruta a la descripción XML del secreto, cuyo UUID debe coincidir con un secreto referenciado en el XML del dominio huésped. ARCHIVO-VALOR-SECRETO es una ruta que contiene el valor en bruto del secreto.

-v, --verbose

Mostrar información detallada sobre el inicio.

-h, --help

Mostrar la ayuda de la línea de comandos.

ESTADO DE SALIDA

Tras un apagado exitoso, se establecerá un estado de salida de 0. En caso de fallo, se establecerá un estado distinto de cero.
