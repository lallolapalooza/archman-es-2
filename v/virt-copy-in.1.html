virt-copy-in(1) Soporte de Virtualización virt-copy-in(1)

NOMBRE

virt-copy-in - Copiar archivos y directorios en una imagen de disco de máquina virtual.

SINOPSIS

virt-copy-in -a disk.img archivo|dir [archivo|dir ...] /destino
virt-copy-in -d dominio archivo|dir [archivo|dir ...] /destino

ADVERTENCIA

Usar "virt-copy-in" en máquinas virtuales en vivo, o concurrentemente con otras herramientas de edición de disco, puede ser peligroso, pudiendo causar corrupción del disco. La máquina virtual debe estar apagada antes de usar este comando, y las imágenes de disco no deben ser editadas concurrentemente.

DESCRIPCIÓN

"virt-copy-in" copia archivos y directorios del disco local a una imagen de disco de máquina virtual o a un dominio libvirt nombrado.

Puede proporcionar uno o más nombres de archivo y directorios en la línea de comandos. Los directorios se copian recursivamente. El último parámetro debe ser el directorio de destino en la imagen del disco, el cual debe ser una ruta absoluta que comience con un carácter /.

EJEMPLOS

Actualizar /etc/resolv.conf en un invitado:

virt-copy-in -d MiInvitado resolv.conf /etc

Subir un directorio de inicio a un invitado:

virt-copy-in -d MiInvitado skel /home

SIMPLEMENTE UN SCRIPT DE ENVOLTURA ALREDEDOR DE GUESTFISH

Este comando es solo un script de envoltura simple alrededor del comando "copy-in" de guestfish(1). Para algo más complejo que una copia trivial, probablemente sea mejor usar guestfish directamente.

OPCIONES

Dado que el script de shell simplemente pasa las opciones directamente a guestfish, lea guestfish(1) para ver la lista completa de opciones.

VER TAMBIÉN

guestfish(1), virt-cat(1), virt-copy-out(1), virt-edit(1), virt-tar-in(1), virt-tar-out(1), http://libguestfs.org/.
