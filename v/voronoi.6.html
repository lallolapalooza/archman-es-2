NOMBRE

voronoi - dibuja una teselación de Voronoi de color aleatorio

SINOPSIS

voronoi [--display host:display.screen] [--visual visual] [--window] [--root] [--window-id número] [--points int] [--point-size int] [--point-speed ratio] [--point-delay segundos] [--zoom-speed ratio] [--zoom-delay segundos] [--fps]

DESCRIPCIÓN

Dibuja una teselación de Voronoi de color aleatorio y, periódicamente, acerca la imagen y añade nuevos puntos. Los puntos existentes también vagan por el plano.

Hay un conjunto de puntos de control en el plano, cada uno en el centro de una celda coloreada. Cada píxel dentro de esa celda está más cerca de los puntos de control de esa celda que de cualquier otro punto de control. Eso es lo que determina las formas de las celdas.

Cuando se ejecuta en una ventana, puede hacer clic para insertar un nuevo punto en la posición del ratón. Hacer clic en un punto existente le permite arrastrarlo.

Esta implementación aprovecha el búfer de profundidad de OpenGL para calcular las celdas por nosotros, renderizando la intersección de conos superpuestos en un plano ortográfico.

OPCIONES

--visual visual
Especifica qué visual usar. Los valores legales son el nombre de una clase de visual, o el número de id (decimal o hexadecimal) de un visual específico.
--window
Dibuja en una ventana recién creada. Esta es la opción por defecto.
--root
Dibuja en la ventana raíz.
--window-id número
Dibuja en la ventana especificada.
--points int
Cuántos puntos añadir cada vez que se acerca la imagen.
--point-size int
Cuánto dibujar las estrellas, en píxeles. 0 para no mostrar estrellas.
--point-speed ratio
Qué tan rápido deben vagar los puntos. Menos de 1 para más lento, más de 1 para más rápido.
--point-delay segundos
Qué tan rápido insertar nuevos puntos, al añadirlos.
--zoom-speed ratio
Qué tan rápido acercar la imagen. Menos de 1 para más lento, más de 1 para más rápido.
--zoom-delay segundos
Acercar la imagen cada X segundos.
--fps
Mostrar la tasa de fotogramas actual, la carga de la CPU y el número de polígonos.

AMBIENTE

DISPLAY
para obtener el host y el número de pantalla por defecto.
XENVIRONMENT
para obtener el nombre de un archivo de recursos que anula los recursos globales almacenados en la propiedad RESOURCE_MANAGER.
XSCREENSAVER_WINDOW
El ID de ventana a usar con --root.
