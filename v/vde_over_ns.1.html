NOMBRE

vde_over_ns - Cable esteganográfico sobre protocolo NS para Ethernet Distribuida Virtual

SINOPSIS

vde_over_ns [-D] [-c dirección_servidor] [-s vde_plug] [-i ip.a.enlazar] nombre_dominio

DESCRIPCIÓN

Un vde_over_ns permite conectar dos vde_switches remotos a través de datagramas de consulta/respuesta NS esteganográficos. p. ej.:

dpipe vde_plug /tmp/s1 = vde_over_ns tun.midominio.vde

se enlaza al puerto udp 53 y escucha las consultas NS esteganográficas entrantes (modo servidor). Todo el tráfico de/hacia stdout/stdin se redirige al cliente a través de respuestas ns.

crea un cable entre dos vde_switches (con sockets /tmp/s1 y /tmp/s2 respectivamente). Este cable pierde el 10% de los paquetes en cada dirección.

El mismo servidor vde_over_dns se puede crear usando:

vde_over_ns -s /tmp/s1 tun.midominio.vde

La sintaxis es casi idéntica para el modo cliente, excepto que para que un cliente vde_over_ns se conecte a ese servidor, se debe especificar la opción -c servidor.

OPCIONES

-s vdeplug
Si se especifica, vde_over_ns se conectará al socket vde local vdeplug en lugar de stdin/stdout, utilizando la biblioteca libvdeplug.
-D
Desacopla la consola y envía el proceso al segundo plano.
-b ip.a.enlazar
El servidor NS solo se enlazará a la IP especificada, en lugar de a cualquier IP. Solo válido en modo servidor (sin -c).
-c direccion_servidor
Si se especifica, se habilita el modo cliente. Vde_over_ns intentará enviar solicitudes NS a direccion_servidor. Si no se especifica, el modo servidor está habilitado por defecto.
