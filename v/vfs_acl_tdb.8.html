VFS_ACL_TDB(8) Herramientas de administración del sistema VFS_ACL_TDB(8)

NOMBRE

vfs_acl_tdb - Guarda ACLs de NTFS en un archivo tdb

SINOPSIS

objetos vfs = acl_tdb

DESCRIPCIÓN

Este módulo VFS es parte del conjunto de herramientas samba(7).

El módulo VFS vfs_acl_tdb almacena Listas de Control de Acceso (ACLs) de NTFS en un archivo tdb. Esto permite la mapeo completo de las ACLs de Windows en servidores Samba.

La configuración de las ACLs se almacena en $LOCKDIR/file_ntacls.tdb.

Este módulo fuerza los siguientes parámetros:

•inherit acls = true
•dos filemode = true
•force unknown acl user = true

Este módulo se puede apilar.

OPCIONES

acl_tdb:ignore system acls = [yes|no]

Cuando se establece en yes, no se realizará un mapeo de mejor esfuerzo desde/hacia la capa de ACLs POSIX por este módulo. El valor predeterminado es no, lo que significa que Samba sigue configurando y evaluando tanto las ACLs del sistema como las ACLs de NT. Esto es mejor si necesita que sus ACLs del sistema se configuren también para acceso local o a través de NFS. Si solo accede a los datos a través de Samba, puede establecer esto en sí para lograr una mejor compatibilidad con las ACLs de NT.

Si acl_tdb:ignore system acls se establece en yes, se aplicarán las siguientes configuraciones adicionales:

•create mask = 0666
•directory mask = 0777
•map archive = no
•map hidden = no
•map readonly = no
•map system = no
•store dos attributes = yes

acl_tdb:default acl style = [posix|windows|everyone]

Este parámetro determina el tipo de ACL que se sintetiza en caso de que un archivo o directorio carezca de un xattr security.NTACL.

Cuando se establece en posix, se sintetizará una ACL basada en los permisos del modo POSIX para usuario, grupo y otros, con una ACE adicional para NT Authority\SYSTEM con derechos completos.

Cuando se establece en windows, se sintetiza una ACL de la misma manera que lo hace Windows, incluyendo solo los permisos para el propietario y NT Authority\SYSTEM.

Cuando se establece en everyone, se sintetiza una ACL que otorga permisos completos a todos (S-1-1-0).

El valor predeterminado para esta opción es posix.
