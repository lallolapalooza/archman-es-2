val_res_query(3)

Paquete: dnssec-tools

Licencias: BSD

val_res_query(3) Manual del programador val_res_query(3)

NOMBRE

val_res_query(), val_res_search() - Resolución de consultas DNS con validación DNSSEC

SINOPSIS

#include <validator/validator.h>
int val_res_query(const val_context_t *ctx,
                  const char *dname,
                  int class,
                  int type,
                  unsigned char *answer,
                  int anslen,
                  val_status_t *val_status);
int val_res_search(val_context_t * ctx,
          const char *dname,
          int class_h,
          int type,
          unsigned char * answer,
          int anslen,
          val_status_t * val_status);

DESCRIPCIÓN

La función val_res_query() realiza la validación DNSSEC de las consultas DNS. Es un sustituto consciente de DNSSEC de la función heredada res_query(3). val_res_search() realiza una operación similar a val_res_query(). Además, utiliza las rutas de búsqueda especificadas en el archivo /etc/resolv.conf para crear el nombre de dominio completamente calificado. val_res_search() es un sustituto consciente de DNSSEC de la función res_search(3).

El parámetro ctx es el contexto del validador y puede establecerse en NULL para la configuración predeterminada. Se puede encontrar más información sobre este campo en libval(3).

El parámetro dname especifica el nombre de dominio, class especifica la clase DNS y type especifica el tipo DNS.

Los valores de estado de validación para las funciones val_res_query() y val_res_search() se devuelven en sus respectivos campos val_status. p_val_status() devuelve una breve descripción en cadena del código de error. val_istrusted() determina si el código de estado indica que la respuesta puede ser confiable y val_isvalidated() determina si el código de estado indica que la respuesta fue validada. (Ver libval(3) para más información).

VALORES DE RETORNO

val_res_query() y val_res_search() devuelven el número de bytes recibidos en caso de éxito y -1 en caso de fallo.
