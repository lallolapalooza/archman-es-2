NOMBRE

vncsession - iniciar un servidor VNC

SINOPSIS

vncsession [-D] <nombre_usuario> <:número_de_pantalla>

DESCRIPCIÓN

vncsession se utiliza para iniciar un escritorio VNC (Virtual Network Computing). vncsession realiza todos los pasos necesarios para crear una nueva sesión de usuario, ejecutar Xvnc con las opciones apropiadas e iniciar un gestor de ventanas en el escritorio VNC.

vncsession rara vez se llama directamente y normalmente lo inicia el gestor de servicios del sistema.

OPCIÓN -D

vncsession por defecto se bifurca y se desvincula. Si se utiliza la opción -D, no se bifurca ni se desvincula. Esta opción se proporciona para su uso con gestores de servicios del sistema que requieren que los servicios se ejecuten en primer plano. Esta opción no está pensada para depuración en un shell de inicio de sesión desde una terminal o para ejecutar vncsession desde una terminal como usuario ordinario.

ARCHIVOS

Varios archivos relacionados con VNC se encuentran en el directorio $HOME/.config/tigervnc:

/etc/tigervnc/vncserver-config-defaults
El equivalente opcional a nivel de sistema de $HOME/.config/tigervnc/config. Si este archivo existe y define opciones para pasar a Xvnc, se utilizarán como valores predeterminados para los usuarios. El archivo $HOME/.config/tigervnc/config del usuario anula las configuraciones definidas en este archivo. El orden general de carga de los archivos de configuración es: este archivo, $HOME/.config/tigervnc/config y luego /etc/tigervnc/vncserver-config-mandatory. Ninguno es obligatorio.
/etc/tigervnc/vncserver-config-mandatory
El equivalente opcional a nivel de sistema de $HOME/.config/tigervnc/config. Si este archivo existe y define opciones para pasar a Xvnc, anularán cualquier opción idéntica definida en el $HOME/.config/tigervnc/config de un usuario. Este archivo ofrece un mecanismo para establecer alguna forma básica de política a nivel de sistema. ADVERTENCIA: Nada impide a los usuarios crear su propio script similar a vncsession que llame directamente a Xvnc para omitir cualquier opción definida en /etc/tigervnc/vncserver-config-mandatory. El orden general de carga de los archivos de configuración es: /etc/tigervnc/vncserver-config-defaults, $HOME/.config/tigervnc/config, y luego este archivo. Ninguno es obligatorio.
$XDG_CONFIG_HOME/tigervnc/config
$HOME/.config/tigervnc/config
Un archivo de configuración de servidor opcional en el que se enumeran las opciones para pasar a Xvnc para evitar codificarlas en la invocación física. Enumere las opciones en este archivo, una por línea. Para aquellas que requieren un argumento, simplemente separe la opción del argumento con un signo igual, por ejemplo: "geometry=2000x1200" o "securitytypes=vncauth,tlsvnc". Las opciones sin argumento se enumeran simplemente como una sola palabra, por ejemplo: "localhost" o "alwaysshared".

La opción especial session se puede utilizar para controlar qué tipo de sesión se iniciará. Esto debe coincidir con uno de los archivos en /usr/share/xsessions. Por ejemplo, si hay un archivo llamado "gnome.desktop", entonces se configuraría "session=gnome" para usar ese tipo de sesión.

$XDG_CONFIG_HOME/tigervnc/passwd
$HOME/.config/tigervnc/passwd
El archivo de contraseña VNC.
$XDG_STATE_HOME/tigervnc/Bhost:Bdisplay#.log
$HOME/.local/state/tigervnc/Bhost:Bdisplay#.log
El archivo de registro para Xvnc y la sesión.
