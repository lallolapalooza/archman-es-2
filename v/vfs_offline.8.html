VFS_OFFLINE(8) Herramientas de Administración del Sistema VFS_OFFLINE(8)

NOMBRE

vfs_offline - Marca todos los archivos como fuera de línea

SINOPSIS

objetos vfs = offline

DESCRIPCIÓN

Este módulo VFS forma parte del conjunto de herramientas samba(7).

El módulo vfs_offline marca todos los archivos en el recurso compartido como si tuvieran el atributo offline de DOS.

Los archivos con el atributo offline de DOS son manejados de manera diferente por el cliente SMB de Windows, así como por el Explorador de Windows. En particular, el Explorador de Windows no lee esos archivos con el único propósito de generar una miniatura, como lo hace normalmente. Esto puede mejorar la experiencia del usuario con algunos sistemas de archivos remotos.

EJEMPLOS

Marcar todos los archivos en un recurso compartido como fuera de línea:

        [remoto]
	objetos vfs = offline
