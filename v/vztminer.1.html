VZTMINER(1) Minería de datos de volcados VZTMINER(1)

NOMBRE

vztminer - Minería de datos de archivos VZT

SINTAXIS

vztminer [opción]... [ARCHIVO VZT]

DESCRIPCIÓN

Realiza minería de datos de archivos VZT para obtener valores de datos específicos y genera archivos de guardado de gtkwave en la salida estándar para su futura recarga.

OPCIONES

-d,--dumpfile <nombre de archivo>
Especifica el archivo de volcado de entrada VZT.
-m,--match <valor>
Especifica datos de coincidencia "bitwise" (binario, real, cadena).
-x,--hex <valor>
Especifica datos de coincidencia hexadecimales que se convertirán automáticamente a binarios para las búsquedas.
-n,--namesonly
Indica que solo se imprimirán los nombres de las instalaciones en un formato compatible con el archivo de guardado de gtkwave. Al hacer esto, el archivo se puede utilizar para especificar qué trazas se importarán en gtkwave.
-c,--comprehensive
Indica que los resultados no deben detenerse después de la primera coincidencia. Esto se puede utilizar para extraer todos los valores coincidentes en la traza.
-h,--help
Muestra la pantalla de ayuda.

EJEMPLOS

vztminer dumpfile.vzt --hex 20470000 -n

Esto intenta hacer coincidir el valor hexadecimal 20470000 en todas las instalaciones y, cuando se encuentra el valor, solo se imprime el nombre de la instalación en la salida estándar para generar un archivo de guardado compatible con gtkwave.

LIMITACIONES

vztminer solo imprime la primera vez que se encuentra un valor para una red específica. Esto se hace para reducir el tamaño de los archivos de salida y para ayudar a seguir datos como direcciones a través de un modelo de simulación. Tenga en cuenta también que el algoritmo del lector intenta reconstruir las redes "bitblasted" de nuevo en sus vectores originales, pero esto no siempre tiene éxito, especialmente en el caso en que las cadenas de bits individuales se vuelcan en un orden no secuencial.
