vis-menu(1) Manual de Comandos Generales vis-menu(1)

NOMBRE

vis-menu — Selecciona interactivamente un elemento de una lista

SINOPSIS

vis-menu [-i] [-t | -b] [-p indicador] [-l líneas] [inicial]

vis-menu [-v]

DESCRIPCIÓN

vis-menu permite a un usuario seleccionar interactivamente un elemento de una lista de opciones. Se lee una lista de elementos separados por saltos de línea desde la entrada estándar, luego la lista de elementos se dibuja directamente en la terminal para que el usuario pueda seleccionar uno. Finalmente, el elemento seleccionado se imprime en la salida estándar.

Para obtener información sobre cómo navegar por el menú, consulte USO más abajo.

-i
Utiliza comparación insensible a mayúsculas y minúsculas al filtrar elementos.
-t | -b
Normalmente, el menú se muestra en la línea actual de la terminal. Cuando se proporciona -t, el menú se dibujará siempre en la línea superior de la terminal. Cuando se proporciona -b, el menú se dibujará siempre en la línea inferior.
-p indicador
Muestra indicador antes de la lista de elementos.
-l líneas
Normalmente, la lista se muestra con todos los elementos uno al lado del otro en una sola línea, lo cual es eficiente en espacio pero no muestra muchos elementos a la vez, especialmente si algunos de ellos son largos. Cuando se proporciona -l, la lista se muestra con cada elemento en su propia línea, con una altura de líneas líneas. Si hay más de líneas elementos en la lista, el usuario puede desplazarse por ellos con las teclas de flecha, al igual que en el modo horizontal normal.
inicial
El usuario puede escribir en un campo de texto para filtrar la lista de elementos, además de desplazarse por ellos. Si se proporciona, inicial se utiliza como el contenido inicial del campo de texto.
-v
En lugar de mostrar un menú interactivo, vis-menu imprime su número de versión en la salida estándar y sale.

USO

vis-menu muestra el indicador (si lo hay), un campo de texto y una lista de elementos. Normalmente se presentan uno al lado del otro en una sola línea, pero si se da la opción -l, el indicador y el área de escritura estarán en la primera línea, y los elementos de la lista en las líneas siguientes.

Los siguientes comandos están disponibles:

Enter
selecciona el elemento de la lista actualmente resaltado y sale.
Control-\ o Control-]
selecciona el contenido actual del campo de texto (incluso si no aparece en la lista) y sale.
ESC ESC o Control-C
sale sin seleccionar ningún elemento.
Abajo o Control-N
se desplaza hacia adelante por los elementos de la lista disponibles.
Arriba o Control-P
se desplaza hacia atrás por los elementos de la lista disponibles.
Derecha o Control-F
mueve el cursor hacia adelante en el texto escrito, y se desplaza por los elementos de la lista disponibles.
Izquierda o Control-B
mueve el cursor hacia atrás en el texto escrito, y se desplaza por los elementos de la lista disponibles.
PageUp o Control-V
se desplaza para mostrar la página anterior de elementos de la lista.
PageDown o Meta-v
se desplaza para mostrar la siguiente página de elementos de la lista.
Inicio o Control-A
mueve el cursor al principio del campo de texto o se desplaza al primer elemento de la lista.
Fin o Control-E
mueve el cursor al final del campo de texto o se desplaza al último elemento de la lista.
Meta-b
mueve el cursor al principio de la palabra actual en el campo de texto.
Meta-f
mueve el cursor más allá del final de la palabra actual en el campo de texto.
Tab
copia el contenido del elemento de la lista seleccionado en el campo de texto. Esto es casi, pero no exactamente, como la autocompletación con tab.
Suprimir o Control-D
elimina el carácter en el campo de texto debajo del cursor.
Retroceso
elimina el carácter en el campo de texto a la izquierda del cursor.
Meta-d
elimina los caracteres en el campo de texto desde el carácter debajo del cursor hasta el siguiente espacio.
Control-K
elimina los caracteres en el campo de texto desde el carácter debajo del cursor hasta el final.
Control-U
elimina los caracteres en el campo de texto desde el principio hasta (pero sin incluir) el carácter debajo del cursor.
Control-W
elimina los caracteres en el campo de texto desde el espacio anterior hasta (pero sin incluir) el carácter debajo del cursor.

Todos los demás caracteres no de control se insertarán en el campo de texto en la posición actual del cursor.

Cuando hay texto en el campo de texto, solo se mostrarán los elementos de la lista que incluyan el texto dado. Si el texto contiene una o más espacios, cada cadena delimitada por espacios es un filtro separado y solo se mostrarán los elementos que coincidan con todos los filtros.

Si el usuario filtra todos los elementos de la lista y luego presiona Enter para seleccionar el elemento "actualmente resaltado", se devolverá el texto que escribió en su lugar.

EJEMPLOS

Aquí hay un script de shell que permite al usuario elegir un número del uno al 10:

NUMERO=$(seq 1 10 | vis-menu -p "Elige un número")
if [ $? -eq 0 ]; then
	echo "Elegiste: $NUMERO"
else
	echo "Te negaste a elegir un número, o ocurrió un error."
fi

DIAGNÓSTICO

La utilidad vis-menu sale con 0 si el usuario seleccionó exitosamente un elemento de la lista, y 1 si el usuario canceló.

vis-menu(1) - Arch Linux man pages

NOMBRE

vis-menu

SINOPSIS

vis-menu [-n] [-p prompt] [-i] [-m mutt-like] [-f font] [-k key] [-a accept-key] [-c cancel-key] [-s select-key] [-S toggle-keys] [-r reverse-key]

DESCRIPCIÓN

El menú interactivo de vis-menu lee elementos de la entrada estándar, permite al usuario buscar, seleccionar y mostrar la selección en la salida estándar.

Las siguientes opciones están disponibles:

-n
No mostrar el prompt.
-p prompt
Mostrar prompt en lugar de la cadena vacía por defecto.
-i
Ignorar mayúsculas/minúsculas durante la búsqueda.
-m mutt-like
Activar el modo mutt-like que utiliza teclas de atajo para la selección, cancelación, etc.
-f font
Especificar la fuente a utilizar en el menú.
-k key
Especificar la tecla para aceptar la selección.
-a accept-key
Especificar la tecla para aceptar la selección.
-c cancel-key
Especificar la tecla para cancelar el menú.
-s select-key
Especificar la tecla para seleccionar el elemento resaltado.
-S toggle-keys
Especificar la(s) tecla(s) para alternar la selección de un elemento.
-r reverse-key
Especificar la tecla para invertir la selección de los elementos.

USO

Por defecto, vis-menu lee elementos de la entrada estándar, uno por línea. El usuario puede empezar a escribir para filtrar la lista. Las teclas de flecha se pueden usar para navegar. Las teclas Enter o Tab aceptan la selección, y Esc cancela.

EJEMPLOS

Ejecutar el menú con la entrada de un archivo:

    $ ls | vis-menu -p "Select a file: "

Ejecutar el menú con la entrada de un comando y usar la tecla de tabulación para seleccionar:

    $ find . -type f | vis-menu -s <Tab>

Ejecutar el menú en modo mutt-like y usar Ctrl+Enter para aceptar:

    $ ls | vis-menu -m -a '<C-m>'

DIAGNÓSTICOS

La utilidad imprime un mensaje en la salida de error estándar y termina con un estado de salida mayor que 1. Las posibles condiciones de error incluyen no poder asignar memoria, no poder leer de la entrada estándar o ejecutarse sin una terminal controladora.

VER TAMBIÉN

dmenu(1), slmenu(1), vis(1)

HISTORIA

El modelo original para un menú de una sola línea que lee elementos de la entrada estándar fue dmenu(1), que implementa la idea para X11. dmenu está disponible en http://tools.suckless.org/dmenu/

El código fue posteriormente reelaborado para la salida de terminal ANSI como slmenu(1), que está disponible en https://bitbucket.org/rafaelgg/slmenu/

Dado que slmenu no parecía estar mantenido, se bifurcó para convertirse en vis-menu para ser distribuido con vis(1).
