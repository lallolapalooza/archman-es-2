NOMBRE

vlock - Programa de bloqueo de consola virtual

SINOPSIS

vlock

vlock [ -a,--all ] [ -c,--current ] [ -h,--help ] [ -v,--version ]

DESCRIPCIÓN

vlock es un programa para bloquear una o más sesiones en la consola de Linux. Esto es especialmente útil para máquinas Linux que tienen múltiples usuarios con acceso a la consola. Un usuario puede bloquear su(s) sesión(es) mientras permite que otros usuarios utilicen el sistema en otras consolas virtuales. Si se desea, se puede bloquear toda la consola y deshabilitar el cambio de consola virtual.

Por defecto, solo se bloquea la VC (consola virtual) actual. Con la opción -a,-all se bloquean todas las VCs. Las VCs bloqueadas no se pueden desbloquear sin la contraseña del invocador. Y, para los paranoicos, vlock hace que sea una experiencia difícil para aquellos que intentan adivinar la contraseña, por lo que el acceso no autorizado a la(s) sesión(es) es muy improbable.

¡Tenga en cuenta que es totalmente posible bloquearse completamente fuera de la consola con la opción -a,--all si no puede recordar su contraseña! A menos que pueda matar vlock iniciando sesión de forma remota a través de una terminal serie o red, un reinicio forzado es el único método para "desbloquear" la pantalla.

vlock funciona principalmente para sesiones de consola. Sin embargo, hay soporte para intentar bloquear sesiones no de consola, pero ese soporte no ha sido bien probado.

OPCIONES

-a,--all

Bloquear todas las sesiones de consola y deshabilitar el cambio de VC.

-c,--current

Bloquear la sesión actual (este es el valor predeterminado).

-h,--help

Imprimir un breve mensaje de ayuda.

-v,--version

Imprimir el número de versión de vlock.
