NOMBRE

vncconfig - configurar y controlar un servidor VNC

SINOPSIS

vncconfig [parámetros]
vncconfig [parámetros] -connect [-view-only] host[:puerto]
vncconfig [parámetros] -disconnect
vncconfig [parámetros] [-set] Xvnc-parametro=valor ...
vncconfig [parámetros] -list
vncconfig [parámetros] -get Xvnc-parametro
vncconfig [parámetros] -desc Xvnc-parametro

DESCRIPCIÓN

vncconfig se utiliza para configurar y controlar una instancia en ejecución de Xvnc, o cualquier otro servidor X con la extensión VNC. Tenga en cuenta que no se puede usar para controlar servidores VNC anteriores a la versión 4.

Cuando se ejecuta sin opciones, funciona como una especie de aplicación "auxiliar" para Xvnc. Su propósito principal cuando se ejecuta en este modo es consultar al usuario cómo deben manejarse las nuevas conexiones (siempre que esta función esté habilitada). La bandera -nowin se puede usar si siempre desea el soporte de consulta pero no desea saturar el escritorio con la ventana de configuración; alternativamente, la opción -iconic se puede usar para que se minimice por defecto.

Cuando se ejecuta en cualquier otro modo, vncconfig es un programa de un solo uso utilizado para configurar o controlar Xvnc según corresponda. Se puede usar para indicar a Xvnc que se conecte o desconecte de los espectadores que están escuchando, y para establecer y recuperar los parámetros de Xvnc.

Tenga en cuenta que la variable de entorno DISPLAY o la opción -display deben configurarse según corresponda para controlar Xvnc. Si lo ejecuta en un servidor X normal (o en un Xvnc de la versión 3), recibirá un mensaje de error que indica que no hay ninguna extensión VNC.

OPCIONES

-connect [-view-only] host[:puerto]
Indica a un servidor Xvnc que realice una conexión "inversa" a un visor VNC en escucha (normalmente las conexiones se realizan de otra manera: el visor se conecta al servidor). host es el host donde se está ejecutando el visor en escucha. Si no está escuchando en el puerto predeterminado de 5500, puede especificar host:puerto en su lugar. La opción -view-only especifica que el servidor debe ignorar todos los eventos de teclado o ratón enviados por el cliente.
-desc Xvnc-parametro
Imprime una breve descripción del parámetro Xvnc dado.
-disconnect
Esto hace que Xvnc se desconecte de todos los visores para que el escritorio VNC no se muestre en ningún lugar.
-get Xvnc-parametro
Imprime el valor actual del parámetro Xvnc dado.
-list
Enumera todos los parámetros compatibles con Xvnc.
[-set] Xvnc-parametro=valor
Establece un parámetro Xvnc al valor dado. Tenga en cuenta que algunos de los parámetros de Xvnc solo se leen una vez al inicio, por lo que cambiarlos de esta manera puede no tener ningún efecto.

PARÁMETROS

vncconfig también tiene sus propios parámetros que se pueden establecer en la línea de comandos. Estos no deben confundirse con los parámetros de Xvnc que se manipulan con las opciones -set, -get, -list y -desc.

Los parámetros se pueden activar con -parametro o desactivar con -parametro=0. Los parámetros que toman un valor se pueden especificar como -parametro valor. Otras formas válidas son parametro=valor -parametro=valor --parametro=valor. Los nombres de los parámetros no distinguen entre mayúsculas y minúsculas.

-display Xdisplay
Especifica el servidor Xvnc a controlar.
-iconic
Cuando se ejecuta como una aplicación "auxiliar", muestra la ventana minimizada al inicio.
-nowin
Cuando se ejecuta como una aplicación "auxiliar", no muestra ninguna ventana.
