val_getaddrinfo(3) Manual del programador val_getaddrinfo(3)

NOMBRE

val_getaddrinfo() - obtener la traducción de dirección y servicio de red validada por DNSSEC

SINOPSIS

#include <validator/validator.h>
int val_getaddrinfo(const struct val_context *ctx,
                    const char *nodename,
                    const char *servname,
                    const struct addrinfo *hints,
                    struct addrinfo **res,
                    val_status_t * val_status);
int val_getnameinfo(val_context_t * ctx,
                    const struct sockaddr *sa,
                    socklen_t salen,
                    char *host,
                    size_t hostlen,
                    char *serv,
                    size_t servlen,
                    int flags,
                    val_status_t * val_status);

DESCRIPCIÓN

val_getaddrinfo() y val_getnameinfo realizan la validación DNSSEC de las consultas DNS. Están pensadas como reemplazos conscientes de DNSSEC para getaddrinfo(3) y getnameinfo(3).

val_getaddrinfo() devuelve un valor de dirección de red de tipo struct addrinfo en el parámetro res. val_getnameinfo se utiliza para convertir una estructura sockaddr en un par de cadenas de nombre de host y servicio.

val_status proporciona el valor combinado del estado de validación para todas las respuestas devueltas por cada una de las funciones. val_istrusted() y val_isvalidated() pueden usarse para determinar la confiabilidad de los datos y p_val_status() puede usarse para mostrar el valor de estado al usuario en formato ASCII (ver libval(3) para más información).

El parámetro ctx especifica el contexto de validación, que puede establecerse en NULL para valores predeterminados (ver libval(3) y dnsval.conf para más detalles sobre contextos de validación y políticas de validación).

Los parámetros nodename, servname y hints tienen una sintaxis y semántica similares a los parámetros correspondientes para la función original getaddrinfo(). El parámetro res es similar al parámetro res para getaddrinfo(). Consulte la página del manual de getaddrinfo(3) para más detalles sobre estos parámetros.

VALORES DE RETORNO

La función val_getaddrinfo() devuelve 0 en caso de éxito y un código de error distinto de cero en caso de fallo. *res apuntará a una lista enlazada asignada dinámicamente de estructuras addrinfo en caso de éxito y será NULL si no había ninguna respuesta disponible.

El parámetro val_status proporciona una indicación de la confiabilidad de los datos. Si *res es NULL, este valor proporciona una indicación de si la no existencia de datos es confiable o no.

EJEMPLO

#include <stdio.h>
#include <stdlib.h>
#include <validator.h>
int main(int argc, char *argv[])
{
         struct addrinfo *ainfo = NULL;
         int retval;
         if (argc < 2) {
                 printf("Uso: %s <nombre de host>\n", argv[0]);
                 exit(1);
         }
         retval = val_getaddrinfo(NULL, argv[1], NULL, NULL, &ainfo);
         if ((retval == 0) && (ainfo != NULL)) {
                 printf("Estado de Validación = %d [%s]\n",
                        ainfo->ai_val_status,
                        p_val_status(ainfo->ai_val_status));
                 val_freeaddrinfo(ainfo);
         }
         return 0;
}
