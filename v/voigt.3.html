NOMBRE

voigt - Función de Voigt, convolución de Gaussiana y Lorenciana

SINOPSIS

#include <cerf.h>

double voigt ( double x, double sigma, double gamma );

DESCRIPCIÓN

La función voigt devuelve la convolución de Voigt

voigt(x,sigma,gamma) = integral G(t,sigma) L(x-t,gamma) dt

de una Gaussiana

G(x,sigma) = 1/sqrt(2*pi)/|sigma| * exp(-x^2/2/sigma^2)

y una Lorenciana

L(x,gamma) = |gamma| / pi / ( x^2 + gamma^2 ),

con la integral que se extiende de -infinito a +infinito.

Si sigma=0, se devuelve L(x,gamma). Por el contrario, si gamma=0, se devuelve G(x,sigma).

Si sigma=gamma=0, el valor de retorno es Inf para x=0, y 0 para cualquier otro x. Es aconsejable verificar los argumentos de entrada para excluir este caso irregular.

REFERENCIAS

La fórmula (7.4.13) en Abramowitz & Stegun (1964) relaciona la integral de convolución de Voigt con la función de Faddeeva w_of_z, en la que se basa esta implementación:

voigt(x,sigma,gamma) = Re[w(z)] / sqrt(2*pi) / |sigma|

con

z = (x+i*|gamma|) / sqrt(2) / |sigma|.
