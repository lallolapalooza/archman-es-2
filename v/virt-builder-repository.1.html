NOMBRE

virt-builder-repository - Crea fácilmente repositorios de origen para virt-builder

SINOPSIS

virt-builder-repository /ruta/al/repositorio
   [-i|--interactive] [--gpg-key CLAVEID]

DESCRIPCIÓN

Virt-builder es una herramienta para construir rápidamente nuevas máquinas virtuales. Puede configurarse para usar repositorios de plantillas. Sin embargo, crear y mantener un repositorio implica muchas tareas que pueden automatizarse. virt-builder-repository es una herramienta que ayuda a administrar estos repositorios.

Virt-builder-repository recorre los archivos en el directorio especificado como argumento, comprime los archivos con un nombre que termina en "qcow2", "raw", "img" o sin extensión, extrae datos de ellos y crea o actualiza el archivo "index".

Algunos de los datos relacionados con las imágenes necesarios para el archivo de índice no se pueden calcular a partir del archivo de imagen. virt-builder-repository primero intenta encontrarlos en el archivo de índice existente. Si los datos aún faltan después de esto, se solicitan en modo interactivo, de lo contrario, se activará un error.

Si se proporciona una "CLAVEID", el archivo de índice generado se firmará con esta clave GPG.

EJEMPLOS

Crear el repositorio inicial

Crea una carpeta y copia los archivos de plantilla de imagen de disco en ella. Luego ejecuta un comando como el siguiente:

virt-builder-repository --gpg-key "joe@hacker.org" -i /ruta/a/la/carpeta

Ten en cuenta que este comando de ejemplo se ejecuta en modo interactivo. Para ejecutar en modo automatizado, se debe crear un archivo de índice mínimo antes de ejecutar el comando que contenga secciones como esta:

[id_plantilla]
file=nombre_archivo_plantilla.qcow.xz

El valor del archivo debe coincidir con el nombre de la imagen extendido con el sufijo ".xz" si el parámetro --no-compression no se proporciona o el nombre de la imagen si no hay compresión involucrada. Otros datos opcionales se pueden prellenar. Los valores predeterminados se calculan inspeccionando la imagen del disco. Para más información, consulta "Creación y firma del archivo de índice" en virt-builder(1).

Actualizar imágenes en un repositorio existente

En este caso de uso, se necesita añadir una nueva imagen o una nueva revisión de una imagen existente al repositorio. Coloca los archivos de plantilla de imagen correspondientes en la carpeta del repositorio.

Para actualizar la revisión de una imagen, el archivo debe tener el mismo nombre que el existente (sin la extensión "xz").

Al igual que en el caso de uso de creación de repositorio, se puede añadir un fragmento mínimo al archivo de índice para el modo automatizado. Esto se puede hacer en el índice firmado, aunque pueda parecer una idea extraña: la herramienta volverá a firmar el índice.

Para eliminar una imagen del repositorio, simplemente elimina el archivo de imagen correspondiente antes de ejecutar virt-builder-repository.

Entonces, ejecutar el siguiente comando completará y actualizará el archivo de índice:

virt-builder-repository --gpg-key "joe@hacker.org" -i /ruta/a/la/carpeta

virt-builder-repository opera en una carpeta temporal dentro de la del repositorio. Si ocurre algo erróneo al ejecutar la herramienta, el repositorio se deja intacto.

OPCIONES

--help
Muestra la ayuda.
--gpg GPG
Especifica un binario gpg(1) (GNU Privacy Guard) alternativo. También puedes usar esto para añadir parámetros de gpg, por ejemplo, para especificar un directorio principal alternativo: 
virt-builder-repository --gpg "gpg --homedir /tmp" [...]

Esto también se puede usar para evitar que gpg pregunte la contraseña de la clave:

virt-builder-repository --gpg "gpg --passphrase-file /tmp/pass --batch" [...]
-K CLAVEID
--gpg-key CLAVEID
Especifica la clave GPG que se utilizará para firmar el archivo de índice del repositorio. Si no se proporciona, el índice quedará sin firmar. "CLAVEID" se utiliza para identificar la clave GPG a utilizar. Este valor se pasa a la opción --default-key de gpg y, por lo tanto, puede ser una dirección de correo electrónico o una huella digital.

NOTA: por defecto, virt-builder-repository busca la clave en el keyring GPG del usuario.

-i
--interactive
Solicita datos faltantes. Los valores predeterminados se calculan a partir de la imagen del disco.

Al solicitar datos, introducir "-" corresponde a dejar el valor vacío. Esto se puede usar para evitar establecer el valor calculado predeterminado.

--no-compression
No comprimir las imágenes de plantilla.
--machine-readable
--machine-readable=formato
Esta opción se utiliza para hacer que la salida sea más amigable para las máquinas, lo cual es útil cuando se llama a virt-builder-repository desde otros programas, GUI, etc. Consulta "SALIDA LEGIBLE POR MÁQUINA" a continuación.
--colors
--colours
Usar secuencias de escape ANSI para colorear los mensajes. Este es el valor predeterminado cuando la salida es una tty. Si la salida del programa se redirige a un archivo, las secuencias de escape ANSI se deshabilitan a menos que uses esta opción.
-q
--quiet
No imprimir mensajes de progreso ordinarios.
-v
--verbose
Habilita mensajes de depuración y/o produce una salida detallada.

Al informar de errores, utiliza esta opción y adjunta la salida completa a tu informe de error.

-V
--version
Muestra el número de versión y sale.
--wrap
Ajusta los mensajes de error, advertencia e informativos. Este es el valor predeterminado cuando la salida es una tty. Si la salida del programa se redirige a un archivo, el ajuste se deshabilita a menos que uses esta opción.
-x
Habilita el rastreo de las llamadas a la API de libguestfs.

SALIDA LEGIBLE POR MÁQUINA

La opción --machine-readable se puede utilizar para hacer que la salida sea más amigable para las máquinas, lo cual es útil cuando se llama a virt-builder-repository desde otros programas, GUI, etc.

Usa la opción por sí sola para consultar las capacidades del binario virt-builder-repository. La salida típica se ve así:

$ virt-builder-repository --machine-readable
virt-builder-repository

Se imprime una lista de características, una por línea, y el programa sale con el estado 0.

Es posible especificar una cadena de formato para controlar la salida; consulta "SALIDA AVANZADA LEGIBLE POR MÁQUINA" en guestfs(3).

CÓDIGO DE SALIDA

Este programa devuelve 0 si tiene éxito, o un valor distinto de cero si hubo un error.
