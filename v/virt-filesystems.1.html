NOMBRE

virt-filesystems - Listar sistemas de archivos, particiones, dispositivos de bloques, LVM en una máquina virtual o imagen de disco

SINOPSIS

virt-filesystems [--opciones] -d nombre_dominio
virt-filesystems [--opciones] -a disco.img [-a disco.img ...]

DESCRIPCIÓN

Esta herramienta te permite descubrir sistemas de archivos, particiones, volúmenes lógicos y sus tamaños en una imagen de disco o máquina virtual. Es un reemplazo para virt-list-filesystems(1) y virt-list-partitions(1).

Un uso para esta herramienta es desde scripts de shell para iterar sobre todos los sistemas de archivos de una imagen de disco:

for fs in $(virt-filesystems -a disco.img); do
  # ...
done

Otro uso es listar particiones antes de usar otra herramienta para modificar esas particiones (como virt-resize(1)). Si tienes curiosidad sobre lo que contiene una imagen de disco desconocida, usa esta herramienta junto con virt-inspector(1).

Varias opciones de línea de comandos controlan qué muestra este programa. Debes proporcionar las opciones -a o -d para especificar la imagen de disco o el invitado de libvirt, respectivamente. Si solo especificas eso, el programa mostrará los sistemas de archivos encontrados, uno por línea, así:

$ virt-filesystems -a disco.img
/dev/sda1
/dev/vg_guest/lv_root

Si agregas -l o --long, la salida incluye información adicional:

$ virt-filesystems -a disco.img -l
Nombre                   Tipo         VFS   Etiqueta  Tamaño
/dev/sda1              sistema de archivos ext4  boot   524288000
/dev/vg_guest/lv_root  sistema de archivos ext4  root   10212081664

Si agregas --extra, también se muestran los sistemas de archivos no montables (swap, desconocido):

$ virt-filesystems -a disco.img --extra
/dev/sda1
/dev/vg_guest/lv_root
/dev/vg_guest/lv_swap
/dev/vg_guest/lv_data

Si agregas --partitions, se muestran las particiones en lugar de los sistemas de archivos:

$ virt-filesystems -a disco.img --partitions
/dev/sda1
/dev/sda2

De manera similar, puedes usar --logical-volumes, --volume-groups, --physical-volumes, --block-devices para listar esos elementos.

También puedes usar estas opciones en combinación (si quieres una combinación que incluya sistemas de archivos, debes agregar --filesystems). Ten en cuenta que algunos elementos caen en varias categorías (por ejemplo, /dev/sda1 puede ser tanto una partición como un sistema de archivos). Estos elementos se listan varias veces. Para obtener una lista que incluya absolutamente todo lo que virt-filesystems conoce, usa la opción --all.

Las UUIDs (porque son bastante largas) no se muestran por defecto. Agrega la opción --uuid para mostrar las UUIDs de los dispositivos y sistemas de archivos en la salida larga.

--all --long --uuid es una combinación útil para mostrar toda la información posible sobre todo.

$ virt-filesystems -a win.img --all --long --uuid -h
Nombre      Tipo       VFS  Etiqueta        Tamaño Padre   UUID
/dev/sda1 filesystem ntfs System Reserved 100M -        F81C92571C92112C
/dev/sda2 filesystem ntfs -               20G  -        F2E8996AE8992E3B
/dev/sda1 partición  -    -               100M /dev/sda -
/dev/sda2 partición  -    -               20G  /dev/sda -
/dev/sda  dispositivo  -    -               20G  -        -

Para una salida legible por máquinas, usa --csv para obtener valores separados por comas (CSV).

OPCIONES

--help
Mostrar ayuda breve.
-a archivo
--add archivo
Agrega archivo, que debe ser una imagen de disco de una máquina virtual. Si la máquina virtual tiene múltiples dispositivos de bloques, debes proporcionar todos ellos con opciones -a separadas.

El formato de la imagen de disco se detecta automáticamente. Para anular esto y forzar un formato particular, usa la opción --format=..

-a URI
--add URI
Agrega un disco remoto. Ver "AGREGANDO ALMACENAMIENTO REMOTO" en guestfish(1).
--all
Mostrar todo. Actualmente es lo mismo que especificar estas opciones: --filesystems, --extra, --partitions, --block-devices, --logical-volumes, --volume-groups, --physical-volumes. (Puede que se agreguen más a esta lista en el futuro).

Ver también --long.

--blkdevs
--block-devices
Mostrar dispositivos de bloques.
--blocksize=512
--blocksize=4096
--blocksize
Este parámetro establece el tamaño del sector de la imagen de disco. Afecta a todos los discos subsiguientes añadidos explícitamente después de este parámetro. Usar --blocksize sin argumento cambia el tamaño del sector del disco al valor predeterminado, que suele ser de 512 bytes. Ver también "guestfs_add_drive_opts" en guestfs(3).
-c URI
--connect URI
Si se usa libvirt, conéctate a la URI dada. Si se omite, nos conectaremos al hipervisor libvirt por defecto.

Si especificas los dispositivos de bloque del invitado directamente (-a), entonces libvirt no se usa en absoluto.

--csv
Escribir los resultados en formato CSV (valores separados por comas). Este formato se puede importar fácilmente a bases de datos y hojas de cálculo, pero lee "NOTA SOBRE EL FORMATO CSV" a continuación.
-d invitado
--domain invitado
Agrega todos los discos del invitado libvirt nombrado. Se pueden usar UUIDs de dominio en lugar de nombres.
--echo-keys
Al solicitar claves y contraseñas, virt-filesystems normalmente desactiva el eco para que no veas lo que escribes. Si no te preocupan los ataques Tempest y no hay nadie más en la habitación, puedes especificar esta bandera para ver lo que escribes.
--extra
Esto hace que se muestren los sistemas de archivos que no son sistemas de archivos ordinarios y montables. Esta categoría incluye el espacio de intercambio (swap), y sistemas de archivos que están vacíos o contienen datos desconocidos.

Esta opción implica --filesystems.

--filesystems
Mostrar sistemas de archivos montables. Si no se seleccionó ninguna opción de visualización, esta opción se implica.

Con --extra, también se muestran los sistemas de archivos no montables.

--format=raw|qcow2|..
--format
El valor predeterminado para la opción -a es detectar automáticamente el formato de la imagen de disco. Usar esto fuerza el formato de disco para las opciones -a que siguen en la línea de comandos. Usar --format sin argumento revierte a la detección automática para las opciones -a subsiguientes.

Por ejemplo:

virt-filesystems --format=raw -a disco.img

fuerza el formato raw (sin detección automática) para disco.img.

virt-filesystems --format=raw -a disco.img --format -a otro.img

fuerza el formato raw (sin detección automática) para disco.img y revierte a la detección automática para otro.img.

Si tienes imágenes de disco de invitados no confiables en formato raw, deberías usar esta opción para especificar el formato del disco. Esto evita un posible problema de seguridad con invitados maliciosos (CVE-2010-3851).

-h
--human-readable
En modo --long, muestra los tamaños en formato legible por humanos.
--keys-from-stdin
Lee parámetros de clave o contraseña desde stdin
