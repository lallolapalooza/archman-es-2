VFS_SHADOW_COPY(8) Herramientas de administración del sistema VFS_SHADOW_COPY(8)

NOMBRE

vfs_shadow_copy - Exponer instantáneas a clientes de Windows como copias de sombra.

SINOPSIS

objetos vfs = shadow_copy

DESCRIPCIÓN

Este módulo VFS es parte de la suite de samba(7).

El módulo VFS vfs_shadow_copy proporciona funcionalidad similar a los servicios de Microsoft Shadow Copy. Cuando se configura correctamente, este módulo permite a los clientes de Microsoft Shadow Copy explorar "copias de sombra" en los recursos compartidos de Samba.

Este módulo es apilable.

CONFIGURACIÓN

vfs_shadow_copy se basa en una implementación de instantáneas del sistema de archivos. Muchos sistemas de archivos comunes tienen soporte nativo para esto.

Las instantáneas del sistema de archivos deben montarse en directorios con nombres especiales para ser reconocidas por vfs_shadow_copy. Los puntos de montaje de las instantáneas deben ser hijos inmediatos del directorio que se está compartiendo.

La convención de nomenclatura de las instantáneas es @GMT-AAAA.MM.DD-hh.mm.ss, donde:

•AAAA es el año de 4 dígitos
•MM es el mes de 2 dígitos
•DD es el día de 2 dígitos
•hh es la hora de 2 dígitos
•mm es el minuto de 2 dígitos
•ss es el segundo de 2 dígitos.

La convención de nomenclatura de instantáneas de vfs_shadow_copy se puede generar con el siguiente comando date(1):

TZ=GMT date +@GMT-%Y.%m.%d-%H.%M.%S

EJEMPLOS

Agregar soporte de copia de sombra a los directorios de inicio de usuario:

        [homes]
	vfs objects = shadow_copy

ADVERTENCIAS

Esto no es una solución de copia de seguridad, archivo o control de versiones.

Con servidores Samba o Windows, vfs_shadow_copy está diseñado para ser una herramienta solo para el usuario final. No reemplaza ni mejora sus soluciones de copia de seguridad y archivo, y de ninguna manera debe considerarse como tal. Además, si necesita control de versiones, implemente un sistema de control de versiones.
