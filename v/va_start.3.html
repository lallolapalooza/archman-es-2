stdarg(3) Manual de Funciones de Biblioteca stdarg(3)

NOMBRE

stdarg, va_start, va_arg, va_end, va_copy - listas de argumentos variables

BIBLIOTECA

Biblioteca estándar de C (libc, -lc)

SINOPSIS

#include <stdarg.h>
void va_start(va_list ap, last);
type va_arg(va_list ap, type);
void va_end(va_list ap);
void va_copy(va_list dest, va_list src);

DESCRIPCIÓN

Una función puede ser llamada con un número variable de argumentos de tipos variables. El archivo de inclusión <stdarg.h> declara un tipo va_list y define tres macros para recorrer una lista de argumentos cuyo número y tipos no son conocidos por la función llamada.

La función llamada debe declarar un objeto de tipo va_list que es utilizado por las macros va_start(), va_arg() y va_end().

va_start()

La macro va_start() inicializa ap para su uso posterior por va_arg() y va_end(), y debe ser llamada primero.

El argumento last es el nombre del último argumento antes de la lista de argumentos variables, es decir, el último argumento cuyo tipo conoce la función llamante.

Dado que la dirección de este argumento puede ser utilizada en la macro va_start(), no debe ser declarado como una variable de registro, o como una función o un tipo de matriz.

va_arg()

La macro va_arg() se expande a una expresión que tiene el tipo y valor del siguiente argumento en la llamada. El argumento ap es el va_list ap inicializado por va_start(). Cada llamada a va_arg() modifica ap para que la siguiente llamada devuelva el siguiente argumento. El argumento type es un nombre de tipo especificado para que el tipo de un puntero a un objeto que tiene el tipo especificado se pueda obtener simplemente añadiendo un * a type.

El primer uso de la macro va_arg() después del de la macro va_start() devuelve el argumento después de last. Las invocaciones sucesivas devuelven los valores de los argumentos restantes.

Si no hay un siguiente argumento, o si type no es compatible con el tipo del siguiente argumento real (promovido según las promociones de argumentos predeterminadas), ocurrirán errores aleatorios.

Si ap se pasa a una función que utiliza va_arg(ap,type), entonces el valor de ap no está definido después del retorno de esa función.

va_end()

Cada invocación de va_start() debe ser correspondida por una invocación de va_end() en la misma función. Después de la llamada va_end(ap), la variable ap no está definida. Son posibles múltiples recorridos de la lista, cada uno delimitado por va_start() y va_end(). va_end() puede ser una macro o una función.

va_copy()

La macro va_copy() copia la lista de argumentos variables (previamente inicializada) src a dest. El comportamiento es como si se hubiera aplicado va_start() a dest con el mismo argumento last, seguido por el mismo número de invocaciones de va_arg() que se usaron para alcanzar el estado actual de src.

Una implementación obvia tendría un va_list como puntero al marco de pila de la función variádica. En tal configuración (la más común con diferencia), no parece haber nada en contra de una asignación


va_list aq = ap;

Desafortunadamente, también hay sistemas que la hacen una matriz de punteros (de longitud 1), y allí se necesita


va_list aq;
*aq = *ap;

Finalmente, en sistemas donde los argumentos se pasan en registros, puede ser necesario que va_start() asigne memoria, almacene los argumentos allí, y también una indicación de cuál es el siguiente argumento, para que va_arg() pueda recorrer la lista. Ahora va_end() puede liberar la memoria asignada de nuevo. Para acomodar esta situación, C99 añade la macro va_copy(), de modo que la asignación anterior pueda ser reemplazada por


va_list aq;
va_copy(aq, ap);
...
va_end(aq);

Cada invocación de va_copy() debe ser correspondida por una invocación de va_end() en la misma función. Algunos sistemas que no suministran va_copy() tienen __va_copy en su lugar, ya que ese fue el nombre utilizado en la propuesta preliminar.

ADVERTENCIAS

A diferencia de las macros históricas varargs, las macros stdarg no permiten a los programadores codificar una función sin argumentos fijos. Este problema genera trabajo principalmente al convertir código varargs a código stdarg, pero también crea dificultades para las funciones variádicas que desean pasar todos sus argumentos a una función que toma un argumento va_list, como vfprintf(3).

EJEMPLOS

La función foo toma una cadena de caracteres de formato e imprime el argumento asociado con cada carácter de formato según el tipo.

#include <stdio.h>
#include <stdarg.h>
void
foo(char *fmt, ...)   /* '...' es sintaxis C para una función variádica */
{
    va_list ap;
    int d;
    char c;
    char *s;
    va_start(ap, fmt);
    while (*fmt)
        switch (*fmt++) {
        case 's':              /* cadena */
            s = va_arg(ap, char *);
            printf("cadena %s\n", s);
            break;
        case 'd':              /* entero */
            d = va_arg(ap, int);
            printf("entero %d\n", d);
            break;
        case 'c':              /* carácter */
            /* se necesita un casting aquí ya que va_arg
               solo toma tipos completamente promocionados */
            c = (char) va_arg(ap, int);
            printf("carácter %c\n", c);
            break;
        }
    va_end(ap);
}
