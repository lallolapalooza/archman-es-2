vendstat(8) Diagnósticos de InfiniBand vendstat(8)

Nombre

vendstat - consulta funciones específicas del proveedor InfiniBand

SINOPSIS

vendstat [opciones] <lid|guid>

DESCRIPCIÓN

vendstat usa MADs específicas del proveedor para acceder a funcionalidades específicas del proveedor más allá de la especificación IB. Actualmente, hay soporte para Mellanox InfiniSwitch-III (IS3) e InfiniSwitch-IV (IS4).

OPCIONES

-N
muestra información general de IS3 o IS4.
-w
muestra contadores de espera de transmisión de puerto de IS3.
-i
muestra información del grupo de contadores de IS4.
-c <num,num>
configura grupos de contadores de IS4.

Configura los grupos de contadores 0 y 1 de IS4. Dicha configuración no es persistente tras el reinicio de IS4. El primer número es para el grupo de contadores 0 y el segundo para el grupo de contadores 1.

Valores de configuración de contadores del grupo 0:

        0 - PortXmitDataSL0-7
        1 - PortXmitDataSL8-15
        2 - PortRcvDataSL0-7
Valores de configuración de contadores del grupo 1:
1 - PortXmitDataSL8-15
2 - PortRcvDataSL0-7
8 - PortRcvDataSL8-15
-R, --Read <dirección,máscara>
lee el registro del espacio de configuración en la dirección
-W, --Write <dirección,val,máscara>
escribe el registro del espacio de configuración en la dirección

Banderas de direccionamiento

-G, --Guid La dirección especificada es un GUID de puerto

-L, --Lid La dirección especificada es un LID

-s, --sm_port <lid_sm> usa 'lid_sm' como lid objetivo para consultas SA.

Banderas de selección de puerto

-C, --Ca <nombre_ca> usa el nombre_ca especificado.

-P, --Port <puerto_ca> usa el puerto_ca especificado.

Selección de puerto local

Soporte para múltiples puertos/múltiples CA: cuando no se especifica ningún dispositivo o puerto IB (ver los "parámetros umad locales" a continuación), la biblioteca libibumad selecciona el puerto a usar según los siguientes criterios:

1.
el primer puerto que esté ACTIVO.
2.
si no se encuentra, el primer puerto que esté ARRIBA (enlace físico activo).

Si se especifica un nombre de puerto y/o CA, la biblioteca libibumad intenta cumplir la solicitud del usuario y fallará si no es posible.

Por ejemplo:

ibaddr                 # usa el primer puerto (criterio #1 anterior)
ibaddr -C mthca1       # elige el mejor puerto solo de "mthca1".
ibaddr -P 2            # usa el segundo puerto (activo/arriba) del primer dispositivo IB disponible.
ibaddr -C mthca0 -P 2  # usa solo el puerto especificado.

Banderas de depuración

-d
aumenta el nivel de depuración de IB. Se puede usar varias veces (-ddd o -d -d -d).
-e
muestra errores de envío y recepción (tiempos de espera y otros)

-h, --help muestra el mensaje de uso

-v, --verbose
aumenta el nivel de verbosidad de la aplicación. Se puede usar varias veces (-vv o -v -v -v)

-V, --version muestra la información de la versión.

Banderas de configuración

-t, --timeout <timeout_ms> anula el tiempo de espera predeterminado para los MADs solicitados.

--config, -z <archivo_config> Especifica un archivo de configuración alternativo.

Predeterminado: /etc/infiniband-diags/ibdiag.conf

ARCHIVOS

ARCHIVO DE CONFIGURACIÓN

/etc/infiniband-diags/ibdiag.conf

Se proporciona un archivo de configuración global para establecer algunas de las opciones comunes para todas las herramientas. Consulte el archivo de configuración proporcionado para obtener más detalles.

EJEMPLOS

vendstat -N 6           # lee información general de IS3 o IS4
vendstat -w 6           # lee contadores de espera de transmisión de puerto de IS3
vendstat -i 6 12        # lee información del grupo de contadores del puerto 12 de IS4
vendstat -c 0,1 6 12    # configura los grupos de contadores del puerto 12 de IS4 para PortXmitDataSL
vendstat -c 2,8 6 12    # configura los grupos de contadores del puerto 12 de IS4 para PortRcvDataSL
