Nombre

virtstoraged - demonio de gestión de pools de almacenamiento de libvirt

SINOPSIS

virtstoraged [OPCIÓN]...

DESCRIPCIÓN

El programa virtstoraged es un componente demonio del lado del servidor del sistema de gestión de virtualización libvirt.

Es una de una colección de demonios modulares que reemplazan la funcionalidad previamente proporcionada por el demonio monolítico libvirtd.

Este demonio se ejecuta en hosts de virtualización para proporcionar gestión de pools de almacenamiento.

El demonio virtstoraged solo escucha solicitudes en un socket de dominio Unix local. El acceso remoto a través de TLS/TCP y la compatibilidad con versiones anteriores con clientes heredados que esperan libvirtd es proporcionado por el demonio virtproxyd.

Reiniciar virtstoraged no interrumpe las máquinas virtuales en ejecución. Las máquinas virtuales continúan operando y los cambios en su estado generalmente se capturarán automáticamente durante el inicio. Sin embargo, se recomienda evitar reiniciar con máquinas virtuales en ejecución siempre que sea práctico.

MODOS DE INICIO DEL DEMONIO

El demonio virtstoraged es capaz de iniciarse en dos modos.

Modo de activación por socket

En hosts con systemd, se inicia en modo de activación por socket y dependerá de systemd para crear y escuchar en los sockets UNIX y pasarlos como descriptores de archivo preabiertos. En este modo, la mayoría de las opciones de configuración relacionadas con sockets en /etc/libvirt/virtstoraged.conf ya no tendrán ningún efecto.

Modo de servicio tradicional

En hosts sin systemd, creará y escuchará en sockets UNIX por sí mismo.

OPCIONES

-h, --help

Muestra la ayuda de la línea de comandos y luego sale.

-d, --daemon

Ejecutar como demonio y escribir el archivo PID.

-f, --config *ARCHIVO*

Utiliza este archivo de configuración, anulando el valor predeterminado.

-p, --pid-file *ARCHIVO*

Utiliza este nombre para el archivo PID, anulando el valor predeterminado.

-t, --timeout *SEGUNDOS*

Sale después del período de tiempo de espera (en segundos), siempre que no haya conexiones de cliente.

-v, --verbose

Habilita la salida de mensajes detallados.

--version

Muestra la información de la versión y luego sale.

SEÑALES

Al recibir SIGHUP, virtstoraged recargará su configuración.

ARCHIVOS

Cuando se ejecuta como root

•
/etc/libvirt/virtstoraged.conf

El archivo de configuración predeterminado utilizado por virtstoraged, a menos que se anule en la línea de comandos usando la opción -f | --config.

  • /run/libvirt/virtstoraged-sock
  • /run/libvirt/virtstoraged-sock-ro
  • /run/libvirt/virtstoraged-admin-sock

Los sockets que utilizará virtstoraged.

La clave privada del servidor TLS que utilizará virtstoraged.

•
/run/virtstoraged.pid

El archivo PID a utilizar, a menos que se anule con la opción -p | --pid-file.

Cuando se ejecuta como no root

•
$XDG_CONFIG_HOME/libvirt/virtstoraged.conf

El archivo de configuración predeterminado utilizado por virtstoraged, a menos que se anule en la línea de comandos usando la opción -f``|--config``.

  • $XDG_RUNTIME_DIR/libvirt/virtstoraged-sock
  • $XDG_RUNTIME_DIR/libvirt/virtstoraged-admin-sock

Los sockets que utilizará virtstoraged.

•
$XDG_RUNTIME_DIR/libvirt/virtstoraged.pid

El archivo PID a utilizar, a menos que se anule con la opción -p``|--pid-file``.

Si $XDG_CONFIG_HOME no está configurado en su entorno, virtstoraged usará $HOME/.config

Si $XDG_RUNTIME_DIR no está configurado en su entorno, virtstoraged usará $HOME/.cache

EJEMPLOS

Para obtener la versión de virtstoraged:

# virtstoraged --version
virtstoraged (libvirt) 11.10.0

Para iniciar virtstoraged, indicándole que se ejecute como demonio y cree un archivo PID:

# virtstoraged -d
# ls -la /run/virtstoraged.pid
-rw-r--r-- 1 root root 6 Jul  9 02:40 /run/virtstoraged.pid

NAME

virtstoraged - daemon to provide virtual storage

SYNOPSIS

virtstoraged [-d|--daemon]

DESCRIPTION

The virtstoraged daemon is responsible for providing virtual storage devices to virtual machines. It listens for requests from virtual machines and manages the underlying storage resources. This includes creating, deleting, attaching, and detaching virtual disks.

OPTIONS

-d, --daemon
Run the daemon in the background.

EXAMPLES

Start virtstoraged in the background:

virtstoraged --daemon
