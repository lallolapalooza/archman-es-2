NOMBRE

vgs — Muestra información sobre grupos de volúmenes

SINOPSIS

vgs
[ argumentos_opcionales ]
[ argumentos_posicionales ]

DESCRIPCIÓN

vgs produce una salida formateada sobre los VGs.

USO

vgs

[ -a|--all ]
[ -o|--options Cadena ]
[ -O|--sort Cadena ]
[ -S|--select Cadena ]
[ --aligned ]
[ --binary ]

[ --foreign ]

[ --ignorelockingfailure ]

OPCIONES

--aligned
Usar con --separator para alinear las columnas de salida.
-a|--all
Listar todos los VGs. Equivalente a no especificar ningún VG.
--binary
Usar valores binarios "0" o "1" en lugar de valores literales descriptivos para columnas que tienen exactamente dos valores válidos para reportar (sin contar el valor "unknown" que denota que el valor no pudo ser determinado).
--commandprofile Cadena
El perfil de comando a usar para la configuración del comando. Ver lvm.conf(5) para más información sobre perfiles.
--config Cadena
Configuración de ajustes para el comando. Estos anulan los ajustes de lvm.conf(5). La cadena de argumento usa el mismo formato que lvm.conf(5), o puede usar sintaxis de sección/campo. Ver lvm.conf(5) para más información sobre la configuración.
--configreport log|vg|lv|pv|pvseg|seg
Ver lvmreport(7).
-d|--debug ...
Establecer el nivel de depuración. Repetir de 1 a 6 veces para aumentar el detalle de los mensajes enviados al archivo de registro y/o syslog (si está configurado).
--devices PV
Restringe los dispositivos que son visibles y accesibles para el comando. Los dispositivos no listados parecerán faltar. Esta opción se puede repetir o aceptar una lista separada por comas de dispositivos. Esto anula el archivo de dispositivos.
--devicesfile Cadena
Un archivo que lista los dispositivos que LVM debe usar. El archivo debe existir en /etc/lvm/devices/ y se gestiona con el comando lvmdevices(8). Esto anula la configuración devices/devicesfile y devices/use_devicesfile de lvm.conf(5).
--driverloaded y|n
Si se establece en no, el comando no intentará usar device-mapper. Para pruebas y depuración.
--foreign
Reportar/mostrar VGs extranjeros que de otro modo serían omitidos. Ver lvmsystemid(7) para más información sobre VGs extranjeros.
--headings none|abbrev|full|0|1|2
Tipo de encabezados a usar en la salida del informe. none o 0: Sin encabezados. abbrev o 1: Abreviaturas de nombres de columna. full o 2: Nombres completos de columna.
-h|--help
Muestra el texto de ayuda.
--ignorelockingfailure
Permite que un comando continúe con operaciones de metadatos de solo lectura después de fallos de bloqueo.
--journal Cadena
Registra información en el journal de systemd. Esta información se suma a la información habilitada por la configuración de registro/journal de lvm.conf. command: registra información sobre el comando. output: registra la salida predeterminada del comando. debug: registra la depuración completa del comando.
--lockopt Cadena
Se usa para pasar opciones para casos especiales a lvmlockd. Ver lvmlockd(8) para más información.
--logonly
Suprime el informe del comando y muestra solo el informe de registro.
--longhelp
Muestra el texto de ayuda largo.
--nameprefixes
Añade un prefijo "LVM2_" más el nombre del campo a la salida. Útil con --noheadings para producir una lista de pares campo=valor que se pueden usar para establecer variables de entorno (por ejemplo, en reglas udev).
--noheadings
Suprime la línea de encabezados que normalmente es la primera línea de salida. Útil si se filtra la salida.
--nohints
No usar el archivo de sugerencias para localizar dispositivos para PVs. Un comando puede leer más dispositivos para encontrar PVs cuando no se usan sugerencias. El comando aún realizará la invalidación estándar del archivo de sugerencias cuando sea apropiado.
--nolocking
Deshabilita el bloqueo. Usar con precaución, comandos concurrentes pueden producir resultados incorrectos.
--nosuffix
Suprime el sufijo en los tamaños de salida. Usar con --units (excepto h y H) si se procesa la salida.
-o|--options Cadena
Lista ordenada y separada por comas de campos a mostrar en columnas. La sintaxis de la cadena de argumento es: [+|-|#]Campo1[,Campo2 ...] El prefijo + añadirá los campos especificados a los campos predeterminados, - eliminará los campos especificados de los campos predeterminados, y # compactará los campos especificados (eliminándolos cuando estén vacíos para todas las filas). Usar -o help para ver la lista de todos los campos disponibles. Usar listas separadas de campos para añadir, eliminar o compactar repitiendo la opción -o: -o+campo1,campo2 -o-campo3,campo4 -o#campo5. Estas listas se evalúan de izquierda a derecha. Usar el nombre de campo lv_all para ver todos los campos de LV, vg_all todos los campos de VG, pv_all todos los campos de PV, seg_all todos los campos de segmento de LV, y pvseg_all todos los P

OPCIONES

-a|--all
Ver todas las áreas/archivos.
-A|--activate String
Cadena de activación separada por comas. El valor predeterminado es “a” (activar todos los volúmenes lógicos). Las opciones válidas son: a, m, r, s.
-B|--blockdevice
Incluir el nombre del dispositivo de bloque en la salida.
-c|--checks
Realizar comprobaciones de metadatos (solo lectura).
-d|--debug
Establecer nivel de depuración. Repetir de 1 a 4 veces para aumentar el detalle de los mensajes enviados a stdout y stderr.
-D|--deferred
Mostrar LVs con activación diferida.
-e|--exact
Encontrar el número exacto de dispositivos de destino.
-f|--force
Intentar continuar incluso si se detectan errores. No se debe utilizar, ya que los datos pueden dañarse.
-F|--fields String
Cadena de campos separados por comas para especificar qué campos se deben mostrar y en qué orden. Consulte el informe de lvm.conf(5) para ver más opciones de configuración. Consulte lvmreport(7) para obtener más información sobre la generación de informes.
-i|--ignorearch
Ignorar la comprobación de la arquitectura del sistema de archivos.
-I|--iterate
Iterar sobre todos los dispositivos y mostrar la salida.
-j|--jobs String
Paralelizar la operación en el número especificado de trabajos. El valor predeterminado es el número de CPUs.
-L|--logicalrank
Mostrar la clasificación lógica del dispositivo.
-l|--maxlogicalvolumes String
Número máximo de volúmenes lógicos en el grupo de volúmenes. Consulte vgcreate(8).
-m|--metadataprofile String
Especificar un perfil para la creación de metadatos. Consulte el informe de lvm.conf(5) para ver las opciones de perfiles. Consulte lvmreport(7) para obtener más información sobre la generación de informes.
-n|--nameprefixes
Mostrar nombres de campos con prefijos.
-o|--options String
Especificar opciones de salida. Consulte la sección de la línea de comandos para ver las opciones disponibles y el informe de lvmreport(7) para ver una descripción de los campos de salida. Use la ayuda de --options para ver una lista de todos los campos de salida válidos.
-p|--partial
Mostrar LVs parciales.
-P|--permission
Indicar permiso de acceso (r/w).
-q|--quiet ...
Suprimir la salida y los mensajes de registro. Anula --debug y --verbose. Repetir una vez para suprimir también cualquier indicación con respuesta 'no'.
-Q|--query
Mostrar la información del sistema de archivos.
-r|--readahead String
Establecer la relectura del volumen lógico. Consulte el informe de lvm.conf(5) para ver más opciones de configuración. Consulte lvmreport(7) para obtener más información sobre la generación de informes.
-R|--reported
Mostrar LVs informados.
-s|--short
Salida corta.
-S|--select String
Seleccionar objetos para procesar y generar informes basándose en criterios especificados. La sintaxis del criterio se describe con --select help y lvmreport(7). Para los comandos de generación de informes, se muestra una fila por cada objeto que coincide con el criterio. Consulte --options help para ver los campos de objetos seleccionables. Las filas se pueden mostrar con un campo adicional "selected" (-o selected) que muestra 1 si la fila coincide con la selección y 0 en caso contrario. Para los comandos no de generación de informes que procesan entidades LVM, la selección se utiliza para elegir los elementos a procesar.
-t|--test
Ejecutar en modo de prueba. Los comandos no actualizarán los metadatos. Esto se implementa deshabilitando toda la escritura de metadatos pero, no obstante, devolviendo éxito a la función de llamada. Esto puede generar mensajes de error inusuales en operaciones de varias etapas si una herramienta depende de leer metadatos que cree que han cambiado pero no lo han hecho.
-u|--uuid
Mostrar UUIDs para VG, LV y PV.
-v|--verbose ...
Establecer nivel detallado. Repetir de 1 a 4 veces para aumentar el detalle de los mensajes enviados a stdout y stderr.
-V|--version
Mostrar información de la versión.
-x|--external
Usar la configuración externa de metadatos.
-y|--yes
No solicitar confirmación interactivamente, sino asumir siempre la respuesta sí. Usar con extrema precaución. (Para un no automático, consulte -qq.)

-q|--quiet ...

Si hay más de un informe por comando, cada informe va precedido del nombre del informe para su identificación. json produce la salida del informe en formato JSON. json_std produce la salida del informe en formato JSON que es más compatible con el estándar JSON. Para los comandos de generación de informes, se muestra una fila por cada objeto que coincide con el criterio. Consulte --options help para ver los campos de objetos seleccionables. Las filas se pueden mostrar con un campo adicional "selected" (-o selected) que muestra 1 si la fila coincide con la selección y 0 en caso contrario. --separator String

--shared
Generar informe/mostrar VGs compartidos que de otro modo se omitirían cuando lvmlockd no se está utilizando en el host. Consulte lvmlockd(8) para obtener más información sobre VGs compartidos.
-O|--sort String
Lista ordenada separada por comas de columnas por las que ordenar. Reemplaza la selección predeterminada. Anteponga un '-' a cualquier columna para ordenar de forma inversa en esa columna.
-t|--test
Ejecutar en modo de prueba. Los comandos no actualizarán los metadatos. Esto se implementa deshabilitando toda la escritura de metadatos pero, no obstante, devolviendo éxito a la función de llamada. Esto puede generar mensajes de error inusuales en operaciones de varias etapas si una herramienta depende de leer metadatos que cree que han cambiado pero no lo han hecho.
--unbuffered
Producir salida inmediatamente sin ordenar ni alinear las columnas correctamente.
--units [Number]r|R|h|H|b|B|s|S|k|K|m|M|g|G|t|T|p|P|e|E
Todos los tamaños se muestran en estas unidades: legible por humanos (r) con indicador de redondeo '<', legible por (h)umanos, (b)ytes, (s)ectores, (k)ilobytes, (m)egabytes, (g)igabytes, (t)erabytes, (p)etabytes, (e)xabytes. Poner en mayúscula para usar múltiplos de 1000 (S.I.) en lugar de 1024. Se pueden especificar unidades personalizadas, por ejemplo, --units 3M.
--unquoted
Cuando se usa con --nameprefixes, los valores de salida en los pares campo=valor no se citan.
-v|--verbose ...
Establecer nivel detallado. Repetir de 1 a 4 veces para aumentar el detalle de los mensajes enviados a stdout y stderr.
--version
Mostrar información de la versión.
-y|--yes
No solicitar confirmación interactivamente, sino asumir siempre la respuesta sí. Usar con extrema precaución. (Para un no automático, consulte -qq.)

VARIABLES

VG
Nombre del Grupo de Volúmenes. Consulte lvm(8) para ver nombres válidos.
Tag
Nombre de la etiqueta. Consulte lvm(8) para obtener información sobre nombres de etiquetas y el uso de etiquetas en lugar de un VG, LV o PV.
String
Consulte la descripción de la opción para obtener información sobre el contenido de la cadena.
Size[UNIT]
Size es un número de entrada que acepta una unidad opcional. Las unidades de entrada siempre se tratan como valores en base dos, independientemente de la capitalización, por ejemplo, 'k' y 'K' se refieren a 1024. La unidad de entrada predeterminada se especifica por letra, seguida de |UNIT. UNIT representa otras unidades de entrada posibles: b|B es bytes, s|S es sectores de 512 bytes, k|K es KiB, m|M es MiB, g|G es GiB, t|T es TiB, p|P es PiB, e|E es EiB. (Esto no debe confundirse con el control de salida --units, donde las letras mayúsculas significan múltiplos de 1000).

VARIABLES DE ENTORNO

Consulte lvm(8) para obtener información sobre las variables de entorno utilizadas por lvm. Por ejemplo, LVM_VG_NAME generalmente puede sustituirse por un parámetro VG requerido.

NOTAS

Los bits de vg_attr son:

1
Permisos: (w)ritable, (r)ead-only
2
Redimensionable (z)
3
E(x)portado
4
(p)arcial: uno o más volúmenes físicos pertenecientes al grupo de volúmenes faltan en el sistema
5
Política de asignación: (c)ontigua, c(l)úster, (n)ormal, (a)cualquier lugar
6
(c)lustered, (s)hared
7
(P)la reserva persistente es requerida pero no está iniciada, (p)la reserva persistente es requerida y está iniciada.
