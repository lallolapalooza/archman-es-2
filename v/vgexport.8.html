vgexport(8)

VGEXPORT(8) System Manager's Manual VGEXPORT(8)

NOMBRE

vgexport — Anular el registro de grupos de volúmenes del sistema

SINOPSIS

vgexport argumentos_opcionales argumentos_posicionales
[ argumentos_opcionales ]

DESCRIPCIÓN

vgexport cambia un VG a un estado exportado, lo que asegura que el VG y sus discos no se estén utilizando, y no puedan utilizarse hasta que el VG sea importado por vgimport(8). Poner un VG en un estado inutilizable y fuera de línea puede ser útil al realizar acciones como mover los discos de un VG a otro sistema. Exportar un VG proporciona cierta protección contra el uso accidental de sus LV, o contra el uso por un sistema automatizado antes de que esté listo.

Un VG no puede ser exportado hasta que todos sus LV estén inactivos.

Los comandos LVM ignorarán un VG exportado o informarán de un error si un comando intenta utilizarlo.

Para un VG exportado, el comando vgs mostrará atributos, y el comando pvs mostrará atributos. Tanto vgs como pvs mostrarán el campo de informe.

vgexport borra el ID del sistema del VG, y vgimport establece el ID del sistema del VG para que coincida con el host que ejecuta vgimport (si el host tiene un ID de sistema).

USO

Exporta los VGs especificados.

vgexport VG|Etiqueta|Seleccionar ...

[ -S|--select Cadena ]
[ --persist stop ]
[ OPCIONES_COMUNES ]

—

Exporta todos los VGs.

vgexport -a|--all

[ OPCIONES_COMUNES ]

OPCIONES

-a|--all
--commandprofile Cadena
El perfil de comando a utilizar para la configuración del comando. Consulte lvm.conf(5) para obtener más información sobre los perfiles.
--config Cadena
Configuración de los ajustes para el comando. Estos anulan los ajustes de lvm.conf(5). La cadena de argumentos utiliza el mismo formato que lvm.conf(5), o puede utilizar la sintaxis de sección/campo. Consulte lvm.conf(5) para obtener más información sobre la configuración.
-d|--debug ...
Establece el nivel de depuración. Repita de 1 a 6 veces para aumentar el detalle de los mensajes enviados al archivo de registro y/o a syslog (si está configurado).
--devices PV
Restringe los dispositivos que son visibles y accesibles para el comando. Los dispositivos no listados parecerán faltar. Esta opción se puede repetir, o acepta una lista de dispositivos separada por comas. Esto anula el archivo de dispositivos.
--devicesfile Cadena
Un archivo que enumera los dispositivos que LVM debe utilizar. El archivo debe existir en /etc/lvm/devices/ y se gestiona con el comando lvmdevices(8). Esto anula la configuración devices/devicesfile y devices/use_devicesfile de lvm.conf(5).
--driverloaded s|n
Si se establece en no, el comando no intentará utilizar device-mapper. Para pruebas y depuración.
-h|--help
Muestra el texto de ayuda.
--journal Cadena
Registra información en el journal de systemd. Esta información es adicional a la información habilitada por la configuración de registro/journal de lvm.conf. comando: registra información sobre el comando. salida: registra la salida predeterminada del comando. depuración: registra la depuración completa del comando.
--lockopt Cadena
Se utiliza para pasar opciones para casos especiales a lvmlockd. Consulte lvmlockd(8) para obtener más información.
--longhelp
Muestra el texto de ayuda largo.
--nohints
No utilizar el archivo de pistas para localizar dispositivos para los PVs. Un comando puede leer más dispositivos para encontrar PVs cuando no se utilizan pistas. El comando seguirá realizando la invalidación estándar del archivo de pistas donde sea apropiado.
--nolocking
Deshabilita el bloqueo. Úselo con precaución, los comandos concurrentes pueden producir resultados incorrectos.
--persist Cadena
Operación de Reserva Persistente. start: registra la clave local y adquiere la reserva. stop: anula el registro de la clave local, liberando la reserva. remove: interrumpe y aborta otra clave. clear: borra la reserva y las claves. check: comprueba si se ha iniciado. autostart: inicia si la bandera de autoinicio del VG está establecida. lvmlocal.conf pr_key o host_id debe estar configurado para utilizar PR. Para VGs locales, se utiliza Write Exclusive (WE), y para VGs compartidos Write Exclusive, todos los registrantes (WEAR) se utilizan. Utilice --setpersist para automatizar y/o requerir PR.
--profile Cadena
Un alias para --commandprofile o --metadataprofile, dependiendo del comando.
-q|--quiet ...
Suprime la salida y los mensajes de registro. Anula --debug y --verbose. Repita una vez para suprimir también cualquier aviso con la respuesta 'no'.
--reportformat basic|json|json_std
Anula el formato de salida actual para los informes, que se define globalmente mediante la configuración report/output_format en lvm.conf(5). basic es el formato original con columnas y filas. Si hay más de un informe por comando, cada informe va precedido por el nombre del informe para identificación. json produce la salida del informe en formato JSON. json_std produce la salida del informe en formato JSON que cumple más con el estándar JSON. Consulte lvmreport(7) para obtener más información.
-S|--select Cadena
Selecciona objetos para procesar y reportar basándose en criterios especificados. La sintaxis de los criterios se describe en --select help y lvmreport(7). Para los comandos de informe, se muestra una fila por cada objeto que coincida con los criterios. Consulte --options help para los campos de objetos seleccionables. Las filas pueden mostrarse con un campo adicional "selected" (-o selected) que muestra 1 si la fila coincide con la selección y 0 en caso contrario. Para los comandos no de informe que procesan entidades LVM, la selección se utiliza para elegir los elementos a procesar.
-t|--test
Ejecutar en modo de prueba. Los comandos no actualizarán los metadatos. Esto se implementa deshabilitando toda escritura de metadatos pero devolviendo éxito a la función llamante. Esto puede generar mensajes de error inusuales en operaciones de múltiples etapas si una herramienta depende de leer metadatos que cree que han cambiado pero no lo han hecho.
-v|--verbose ...
Establece el nivel de verbosidad. Repita de 1 a 4 veces para aumentar el detalle de los mensajes enviados t

OPTIONS

-a | --all
Select all Volume Groups, Logical Volumes or Physical Volumes.
-d | --data
If the device is a logical volume, display the logical volume's data, not metadata. (This option is the default, for the reverse use -m.)
-h | --help
Display help information.
-m | --metadatas
If the device is a logical volume, display the logical volume's metadata, not data. (This option is the default, for the reverse use -d.)
-n | --noheadings
Suppress the header lines that are normally printed for the output data.
-o | --select [Select]
Selects fields from the output. Use -e to see all available fields, and -S to select fields. Note that the field names are case insensitive. Available fields: vguuid, vgname, pvname, seqno, status, allocatable, size, free, extent_size, max_extents, usage, vgcount, pvcount, lvcount, snap_count, write_cache_state, vg_attr.
-q | --quiet
Suppress output messages. Use -qq to suppress messages about errors also. Error messages are sent to stderr.
-s | --summarize
Provide a short summary of the selected items.
-t | --test
Perform a trial run with no changes made.
-u | --uuid
Display the UUIDs of the selected items.
-v | --verbose
Enables additional verbose output and debugging. The exact output depends on the command and its options. Multiple invocations lead to more verbosity.
-x | --separator [String]
Change the default Output Separator. Default is "|" (vertical bar). This option is used to create CSV or TSV format, or simply to delimit fields for easier parsing. The first use of -x indicates that the following argument is the separator. If no argument follows -x then the default separator will be a newline. So, -x alone selects newline as the separator.
-y|--yes
Do not prompt for confirmation interactively but always assume the answer yes. Use with extreme caution. (For automatic no, see -qq.)

VARIABLES

VG
Volume Group name. See lvm(8) for valid names.
Tag
Tag name. See lvm(8) for information about tag names and using tags in place of a VG, LV or PV.
Select
Select indicates that a required positional parameter can be omitted if the --select option is used. No arg appears in this position.
String
See the option description for information about the string content.
Size[UNIT]
Size is an input number that accepts an optional unit. Input units are always treated as base two values, regardless of capitalization, e.g. 'k' and 'K' both refer to 1024. The default input unit is specified by letter, followed by |UNIT. UNIT represents other possible input units: b|B is bytes, s|S is sectors of 512 bytes, k|K is KiB, m|M is MiB, g|G is GiB, t|T is TiB, p|P is PiB, e|E is EiB. (This should not be confused with the output control --units, where capital letters mean multiple of 1000.)

ENVIRONMENT VARIABLES

See lvm(8) for information about environment variables used by lvm. For example, LVM_VG_NAME can generally be substituted for a required VG parameter.
