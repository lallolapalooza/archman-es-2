VDE_TUNCTL(8) Manual del Administrador del Sistema VDE_TUNCTL(8)

NOMBRE

vde_tunctl — crear y gestionar interfaces TUN/TAP persistentes

SINOPSIS

vde_tunctl [-f dispositivo-clon] [-u propietario] [-g grupo] [-n] [-t nombre-disp]

vde_tunctl [-f dispositivo-clon] -d nombre-disp

DESCRIPCIÓN

vde_tunctl permite al administrador del sistema del host preconfigurar un dispositivo TUN/TAP para su uso por un usuario particular. Ese usuario puede abrir y usar el dispositivo, pero no puede modificar ningún aspecto del lado del host de la interfaz.

vde_tunctl es una extensión de tunctl.

vde_tunctl define interfaces tap a menos que nombre-disp comience con "tun" o la opción -n aparezca en la línea de comandos.

USO

Para crear una interfaz para uso por un usuario particular, invoca tunctl sin la opción -d:

# vde_tunctl -u someuser
Establecer 'tap0' persistente y propiedad del uid 500

Luego, configura la interfaz como de costumbre:

# ifconfig tap0 192.168.0.254 up
# route add -host 192.168.0.253 dev tap0
# bash -c 'echo 1 > /proc/sys/net/ipv4/conf/tap0/proxy_arp'
# arp -Ds 192.168.0.253 eth0 pub

Para eliminar la interfaz, usa la opción -d:

# vde_tunctl -d tap0
Establecer 'tap0' no persistente

Para crear o destruir una interfaz tun (en lugar de tap):

# vde_tunctl -n -u someuser
Establecer 'tun0' persistente y propiedad del uid 500
# vde_tunctl -d tun0
Establecer 'tun0' no persistente

VER TAMBIÉN

vde_switch(1) vde_plug2tap(1)
