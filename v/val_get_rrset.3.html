val_get_rrset(3) Manual del programador val_get_rrset(3)

NOMBRE

val_get_rrset() - obtener información de registro de recursos validada por DNSSEC

SINOPSIS

#include <validator/validator.h>
struct val_answer_chain {
    val_status_t   val_ans_status;
    char          *val_ans_name;
    int            val_ans_class;
    int            val_ans_type;
    struct rr_rec *val_ans;
    struct val_answer_chain *val_ans_next;
};
struct rr_rec {
    size_t         rr_length;
    unsigned char *rr_data;
    struct rr_rec *rr_next;
};
int val_get_rrset(val_context_t *ctx,
                  const char *name,
                  int class,
                  int type,
                  unsigned int flags,
                  struct val_answer_chain **answers);

void val_free_answer_chain(struct val_answer_chain *answers);

DESCRIPCIÓN

val_get_rrset() realiza la validación DNSSEC para el nombre, clase y tipo de DNS dados. Devuelve el estado de validación DNSSEC para el conjunto de registros de recursos, pero no devuelve detalles de la cadena de autenticación. Si se requieren los detalles de la cadena de autenticación, se debe usar la función val_resolve_and_check() en su lugar.

val_get_rrset() devuelve sus resultados en la estructura val_answer_chain. La memoria para esta estructura es asignada por val_get_rrset; el usuario debe liberar esta memoria después de su uso utilizando la función val_free_answer_chain().

Los RRsets en la respuesta se devuelven en la estructura val_answer_chain. El miembro val_ans_name contiene el nombre DNS del conjunto de registros de recursos actual devuelto. Este valor puede diferir del valor pasado como argumento name a val_get_rrset() si el registro de recursos se devolvió después de seguir un alias CNAME o DNAME. val_ans_name y val_ans_type contienen la clase y el tipo reales del registro de recursos devuelto. Estos valores pueden diferir de los valores pasados como argumentos a val_get_rrset() si el tipo o la clase de consulta tiene el valor 255 (ANY). El conjunto de registros de recursos se devuelve en val_ans como una lista enlazada de tuplas rr_length y rr_data, para los datos devueltos en cada registro de recursos del conjunto de registros de recursos. val_ans puede ser NULL si el nombre no existe.

val_ans_status proporciona el valor combinado del estado de validación para el RRset dado. val_istrusted() y val_isvalidated() se pueden usar para determinar la confiabilidad de los datos y p_val_status() se puede usar para mostrar el valor de estado al usuario en formato ASCII (ver libval(3) para más información).

El parámetro ctx especifica el contexto de validación, que puede establecerse en NULL para valores predeterminados (ver libval(3) y dnsval.conf para más detalles sobre contextos de validación y política de validación).

VALORES DE RETORNO

La función val_get_rrset() devuelve 0 si tiene éxito y uno de los códigos de error definidos en libval(3) en caso de fallo.
