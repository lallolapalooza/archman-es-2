VFS_TIME_AUDIT(8) Herramientas de administración del sistema VFS_TIME_AUDIT(8)

NOMBRE

vfs_time_audit - módulo VFS de samba para registrar operaciones VFS lentas

SINOPSIS

objetos vfs = time_audit

DESCRIPCIÓN

Este módulo VFS forma parte del conjunto de herramientas samba(7).

El módulo VFS time_audit registra las llamadas al sistema que tardan más que el número de milisegundos definido por la variable time_audit:timeout. Registrará las llamadas y el tiempo empleado en ellas.

Es comparable a strace -T y es útil para revelar problemas de rendimiento con los subsistemas de archivo y almacenamiento subyacentes.

Este módulo es apilable.

OPCIONES

time_audit:timeout = número de milisegundos

Llamadas VFS que tardan más que el número definido de milisegundos que se deben registrar. El valor predeterminado es 10000 (10s).

EJEMPLOS

Esto registraría las llamadas VFS que tardan más de 3 segundos:

        [muestra_compartida]
	ruta = /test/muestra_compartida
	objetos vfs = time_audit
	time_audit:timeout = 3000
