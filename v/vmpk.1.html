VMPK(1) Comandos de usuario VMPK(1)

NOMBRE

vmpk - Teclado de Piano MIDI Virtual

SINOPSIS

vmpk [opciones...]

DESCRIPCIÓN

Esta página del manual documenta brevemente el programa vmpk.

Este programa utiliza opciones estándar de Qt.

Virtual MIDI Piano Keyboard es un generador y receptor de eventos MIDI. No produce ningún sonido por sí mismo, pero puede ser utilizado para controlar un sintetizador MIDI (ya sea de hardware o de software, interno o externo). Puedes usar el teclado del ordenador para tocar notas MIDI, y también el ratón. Puedes usar el Teclado de Piano MIDI Virtual para mostrar las notas MIDI reproducidas desde otro instrumento o reproductor de archivos MIDI.

OPCIONES VMPK

Las siguientes opciones se aplican solo a vmpk:

-h|--help

Muestra un texto de ayuda.

-v|--version

Muestra información de la versión.

-p|--portable

Habilita el modo de configuración portátil utilizando un nombre de archivo de configuración predeterminado.

-f ruta/archivo.conf

Esta opción también implica --portable. Lee y escribe ruta/archivo.conf como el nombre del archivo de configuración de ajustes portátiles.

Este archivo de configuración es siempre un archivo de texto en formato INI, a pesar de las convenciones del sistema operativo en ejecución.

OPCIONES ESTÁNDAR

Las siguientes opciones se aplican a todas las aplicaciones Qt5/6:

-style= estilo / -style estilo

Establece el estilo de la GUI de la aplicación. Los valores posibles dependen de la configuración del sistema. Si Qt está compilado con estilos adicionales o tiene estilos adicionales como plugins, estarán disponibles para la opción de línea de comandos -style.

-stylesheet= hoja_estilo / -stylesheet hoja_estilo

Establece la hoja de estilo de la aplicación. El valor debe ser una ruta a un archivo que contenga la Hoja de Estilo.

-widgetcount

Imprime un mensaje de depuración al final sobre el número de widgets que quedan sin destruir y el número máximo de widgets que existieron al mismo tiempo.

-reverse

Establece la dirección de diseño de la aplicación a Qt::RightToLeft. Esta opción está destinada a ayudar a la depuración y no debe usarse en producción. El valor predeterminado se detecta automáticamente a partir de la configuración regional del usuario (ver también QLocale::textDirection()).

-platform nombre_plataforma[:opciones]

Especifica el plugin de Abstracción de Plataforma de Qt (QPA).

-platformpluginpath ruta

Especifica la ruta a los plugins de plataforma.

-platformtheme tema_plataforma

Especifica el tema de la plataforma.

-plugin plugin

Especifica plugins adicionales para cargar. El argumento puede aparecer varias veces.

-qwindowgeometry geometría

Especifica la geometría de la ventana para la ventana principal utilizando la sintaxis de X11. Por ejemplo: -qwindowgeometry 100x100+50+50

-qwindowicon icono

Establece el icono predeterminado de la ventana.

-qwindowtitle título

Establece el título de la primera ventana.

-session sesión

Restaura la aplicación de una sesión anterior.

-display nombre_host:numero_pantalla

Cambia las pantallas en X11. Anula la variable de entorno DISPLAY.

-geometry geometría

Especifica la geometría de la ventana para la ventana principal en X11. Por ejemplo: -geometry 100x100+50+50

-dialogs= [xp|none]

Solo disponible para la plataforma Windows. XP usa diálogos de estilo nativo y none los deshabilita.

-fontengine= freetype

Usa el motor de fuentes FreeType.
