VMMOUSE(4) Manual de Controladores de Dispositivos VMMOUSE(4)

NOMBRE

vmmouse — controlador de entrada de ratón de VMware

SINOPSIS

Section "InputDevice"
  Identifier "nombre_dispositivo"
  Driver "vmmouse"
  ...
EndSection

DESCRIPCIÓN

vmmouse es un controlador de entrada de ratón para XFree86. El controlador soporta la mayoría de los tipos e interfaces de ratón disponibles. Los ratones USB solo se soportan en algunos sistemas operativos, y el nivel de soporte para ratones PS/2 depende del sistema operativo.

El controlador vmmouse funciona como un dispositivo de entrada de puntero, y puede ser utilizado como el puntero principal del servidor X. Múltiples ratones son soportados por múltiples instancias de este controlador.

DETALLES DE CONFIGURACIÓN

Por favor, consulte xorg.conf(5) para detalles generales de configuración y para opciones que se pueden usar con todos los controladores de entrada. Esta sección solo cubre detalles de configuración específicos de este controlador.

El controlador detectará automáticamente si el dispositivo vmmouse está presente y, si no lo está, cargará el controlador mouse normal e intentará recurrir a él. No hay opciones específicas de vmmouse, pero si establece opciones de mouse(4), estas se pasarán.

Consulte la página del manual mouse(4) para obtener detalles sobre estas opciones.
