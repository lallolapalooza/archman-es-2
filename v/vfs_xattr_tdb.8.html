NOMBRE

vfs_xattr_tdb - Guarda atributos extendidos (EAs) en un archivo tdb

SINOPSIS

objetos vfs = xattr_tdb

DESCRIPCIÓN

Este módulo VFS es parte del conjunto de herramientas samba(7).

El módulo VFS vfs_xattr_tdb almacena Atributos Extendidos (EAs) en un archivo tdb. Esto permite el uso de Atributos Extendidos en sistemas operativos y sistemas de archivos que no los soportan por sí mismos.

Este módulo puede ser apilado.

OPCIONES

xattr_tdb:file = RUTA

Nombre del archivo tdb donde se almacenan los EAs. Si esta opción no está configurada, se usa el nombre de archivo predeterminado xattr.tdb.
