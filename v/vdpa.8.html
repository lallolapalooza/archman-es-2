NOMBRE

vdpa - herramienta de gestión de vdpa

SINOPSIS


vdpa [ OPCIONES ] { dev|mgmtdev } { COMANDO | help }

OPCIONES

-V, --Version
Imprime la versión de la utilidad vdpa y sale.
-j, --json
Genera salida JSON.
-p, --pretty
Cuando se combina con -j, genera una salida JSON bonita.

OBJETO

dev
- dispositivo vdpa.
mgmtdev
- dispositivo de gestión vdpa.

COMANDO

Especifica la acción a realizar sobre el objeto. El conjunto de acciones posibles depende del tipo de objeto. Es posible show (o list ) objetos. El comando help está disponible para todos los objetos. Imprime una lista de comandos disponibles y convenciones de sintaxis de argumentos.

Si no se proporciona ningún comando, se asume un comando por defecto. Normalmente es show o, si los objetos de esta clase no pueden listarse, help.

ESTADO DE SALIDA

El estado de salida es 0 si el comando fue exitoso o un entero positivo en caso de fallo.

VER TAMBIÉN

vdpa-dev(8), vdpa-mgmtdev(8),

REPORTE DE ERRORES

Reporta cualquier error a la lista de correo de desarrolladores de red <netdev@vger.kernel.org> donde se realiza principalmente el desarrollo y mantenimiento. No es necesario suscribirse a la lista para enviar un mensaje allí.
