NOMBRE

errc, verrc, warnc, vwarnc — mensajes de error formateados

BIBLIOTECA

biblioteca “libbsd”

SINOPSIS

#include <err.h> (Ver libbsd(7) para el uso de inclusiones.)
void
errc(int status, int code, const char *fmt, ...);

void
verrc(int status, int code, const char *fmt, va_list args);

void
warnc(int code, const char *fmt, ...);

void
vwarnc(int code, const char *fmt, va_list args);

DESCRIPCIÓN

Las funciones de la familia err() y warn() muestran un mensaje de error formateado en la salida de error estándar. En todos los casos, se imprime el último componente del nombre del programa, seguido de dos puntos (‘:’) y un espacio. El texto que sigue depende de la función que se esté llamando. La especificación fmt (y los argumentos asociados) puede ser cualquier formato permitido por printf(3) o NULL. Si el argumento fmt no es NULL, se imprime el mensaje de error formateado.

Todas las funciones imprimen una cadena de mensaje de error afiliada a un valor de error (ver strerror(3)), precedida por dos puntos y un espacio si fmt no es NULL. Es decir, la salida es la siguiente:

nombre_programa: fmt: cadena de mensaje de error

si fmt no es NULL, o:

nombre_programa: cadena de mensaje de error

si lo es.

El argumento code se utiliza como el valor de error en lugar del valor actual de la variable global errno.

En todos los casos, la salida va seguida de un carácter de nueva línea.

Las funciones errc() y verrc() no retornan, sino que salen con el valor del argumento status.

EJEMPLOS

Mostrar la cadena de información de errno actual y salir:

if ((p = malloc(size)) == NULL)
	err(1, NULL);
if ((fd = open(file_name, O_RDONLY, 0)) == -1)
	err(1, "%s", file_name);

Mostrar un mensaje de error y salir:

if (tm.tm_hour < START_TIME)
	errx(1, "demasiado temprano, espera hasta %s", start_time_string);

Advertir de un error:

if ((fd = open(raw_device, O_RDONLY, 0)) == -1)
	warnx("%s: %s: intentando el dispositivo de bloque",
	    raw_device, strerror(errno));
if ((fd = open(block_device, O_RDONLY, 0)) == -1)
	err(1, "%s", block_device);

VER TAMBIÉN

err(3) exit(3), perror(3), printf(3), strerror(3)

HISTORIA

Las funciones errc(), verrc(), warnc() y vwarnc() aparecieron por primera vez en FreeBSD 3.0, NetBSD 7.0 y OpenBSD 5.6.

ADVERTENCIAS

Es importante nunca pasar una cadena con datos proporcionados por el usuario como formato sin usar ‘%s’. Un atacante puede insertar especificadores de formato en la cadena para alterar la pila, lo que podría llevar a un posible agujero de seguridad. Esto es cierto incluso si la cadena se ha construido “a mano” usando una función como snprintf(), ya que la cadena resultante puede contener especificadores de conversión proporcionados por el usuario para su posterior interpolación por la familia de funciones err() y warn().

Asegúrate siempre de usar el modismo seguro adecuado:

errc(1, 0, "%s", cadena);
