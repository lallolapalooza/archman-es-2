NOMBRE

vnstati - soporte de salida de imagen para vnStat

SINOPSIS

vnstati [-5bcdDehiLmosStvy?] [--95th modo] [-5g [límite] [altura]] [--altdate] [--begin fecha] [--cache tiempo] [--config archivo] [--days [límite]] [--db archivo] [--dbdir directorio] [--dbiflist [modo]] [--debug] [--end fecha] [--fivegraph [límite] [altura]] [--fiveminutes [límite]] [--headertext texto] [--help] [-hg [modo]] [--hours [límite]] [--hoursgraph [modo]] [-hs [gráfico]] [--hsummary [gráfico]] [-i interfaz] [--iface interfaz] [-ic [modo]] [--invert-colors [modo]] [--large] [--limit límite] [--locale localización] [--months [límite]] [-ne] [-nh] [-nl] [--noedge] [--noheader] [--nolegend] [--output archivo] [-ru [modo]] [--rateunit [modo]] [--scale porcentaje] [--small] [--style número] [--summary] [--top [límite]] [--transparent [habilitado]] [--version] [-vs [gráfico]] [--vsummary [gráfico]] [--months [límite]] [interfaz]

DESCRIPCIÓN

El propósito de vnstati es proporcionar soporte de salida de imagen para las estadísticas recopiladas utilizando vnstat(1). Los formatos de archivo de imagen disponibles dependen de lo que sea compatible con la biblioteca GD utilizada. Se admiten todas las salidas básicas de vnStat, excepto las funciones de tráfico en vivo. La imagen se puede generar tanto en un archivo como en la salida estándar, esta última limitada al formato de imagen png.

OPCIONES

--95th modo
Muestra el gráfico de salida del percentil 95 para el mes en curso. Esta salida utiliza los datos de resolución de 5 minutos del mes en curso para calcular la tasa de tráfico del percentil 95 para el recibido, transmitido o total, según se seleccione utilizando el parámetro obligatorio modo. El percentil 95 se mostrará como una línea horizontal en el gráfico con la tasa de tráfico exacta del percentil 95 visible en la sección de leyenda de la imagen. Además, se presenta un gráfico de barras de tasa de tráfico de resolución de una hora promediado a partir de los datos de resolución de 5 minutos del modo seleccionado. Esta salida requiere que la opción de configuración 5MinuteHours tenga un valor de al menos 744 para almacenar todos los datos necesarios, de lo contrario, no es posible una cobertura del 100%. Modos disponibles: 0 = recibido, 1 = transmitido, 2 = total.
--altdate
Utiliza una ubicación de texto alternativa para la fecha y la hora. El texto de fecha y hora se moverá de la sección superior derecha de la cabecera a la esquina inferior izquierda. Esta opción no tendrá efecto si se ha seleccionado -nh, --noheader.
-b, --begin fecha
Comienza la salida de la lista con una fecha/hora específica definida por fecha en lugar de que el inicio se seleccione en función del número de entradas a mostrar. Si fecha no está disponible en la base de datos, se utilizará la fecha posterior más cercana. fecha admite los siguientes formatos: AAAA-MM-DD HH:MM, AAAA-MM-DD y "today". Esta opción solo se puede usar con salidas de lista.
-c, --cache tiempo
Actualiza el archivo de salida solo si han pasado al menos tiempo minutos desde la última actualización del archivo. Esta opción se ignora si se utiliza la salida estándar como salida.
--config archivo
Utiliza archivo como archivo de configuración en lugar de buscar automáticamente el archivo de configuración. Si se usa --config múltiples veces, la configuración de los archivos posteriores en la línea de comandos anulará la configuración cargada de los archivos anteriores si la configuración definida en los archivos se superpone.
-d, --days [límite]
Muestra estadísticas de tráfico diarias de los últimos días. La longitud de la lista se limitará a 30 entradas a menos que se configure lo contrario o a menos que se utilice el parámetro opcional límite. Se mostrarán todas las entradas almacenadas en la base de datos si límite se establece en 0.
--db archivo
Utiliza archivo como archivo de base de datos en lugar de buscar una base de datos en el directorio especificado en el archivo de configuración o el predeterminado codificado si no hay un archivo de configuración disponible. Esta opción anula --dbdir.
--dbdir directorio
Utiliza directorio como directorio de base de datos en lugar de utilizar el directorio especificado en el archivo de configuración o el predeterminado codificado si no hay un archivo de configuración disponible. Esta opción se ignora si también se define --db.
--dbiflist [modo]
Enumera las interfaces actualmente en la base de datos. Si modo no se define o se establece en 0, la salida utilizará un formato detallado de una línea. Si modo se establece en 1, la salida contendrá una interfaz por línea y si modo se establece en 2, solo se mostrará el recuento de interfaces como un solo número. Ver también --iflist.
-D, --debug
Muestra una salida de depuración adicional.
-e, --end fecha
Finaliza la salida de la lista con una fecha/hora específica definida por fecha en lugar de la última fecha/hora en la base de datos. Si fecha no está disponible en la base de datos, se utilizará la fecha anterior más cercana. fecha admite los siguientes formatos: AAAA-MM-DD HH:MM y AAAA-MM-DD. Esta opción solo se puede usar con salidas de lista. La lista superior también requiere que se use --begin al mismo tiempo que esta opción.
-5g, --fivegraph [límite] [altura]
Muestra estadísticas de tráfico con una resolución de 5 minutos durante las últimas 48 horas utilizando un gráfico de barras. El ancho del gráfico se puede modificar usando el parámetro opcional límite, que representa el número de entradas de 5 minutos con 12 entradas por hora. El valor más pequeño admitido es 288 (últimas 24 horas). Además, la altura del gráfico se puede modificar usando el parámetro opcional altura. La altura mínima admitida es de 150 píxeles.
-5, --fiveminutes [límite]
Muestra estadísticas de tráfico con una resolución de 5 minutos durante las últimas horas. La longitud de la lista se limitará a 24 entradas a menos que se configure lo contrario o a menos que se utilice el parámetro opcional límite. Se mostrarán todas las entradas almacenadas en la base de datos si límite se establece en 0.
--headertext texto
Muestra texto en la sección de cabecera de la imagen en lugar de la identificación de interfaz generada automáticamente. texto está limitado a 64 caracteres y es posible que no se muestre por completo si es más largo que el ancho de la imagen. Úselo con --altdate si necesita espacio máximo. Esta opción no tendrá efecto si se ha seleccionado -nh, --noheader.
-h, --hours [límite]
Muestra estadísticas de tráfico por hora. La longitud de la lista se limitará a 24 entradas a menos que se configure lo contrario o a menos que se utilice el parámetro opcional límite. Se mostrarán todas las entradas almacenadas en la base de datos si el límite se establece en 0.
-hg, --hoursgraph [modo]
Muestra estadísticas de tráfico por hora durante las últimas 24 horas utilizando un gráfico de barras. El parámetro opcional modo se puede utilizar para anular la configuración del archivo de configuración. Modos disponibles: 0 = ventana deslizante de 24 horas, 1 = el gráfico comienza desde la medianoche.
-hs, --hsummary [gráfico]
Muestra un resumen de tráfico junto con el gráfico seleccionado usando la configuración SummaryGraph en el archivo de configuración, usando un diseño horizontal. El parámetro opcional gráfico se puede usar para anular la configuración del archivo de configuración. Gráficos disponibles: 0 = horas, 1 = 5 minutos.

OPTIONS

-i, --iface interfaz
Utiliza interfaz en lugar de la interfaz predeterminada o configurada. También es posible fusionar la información de dos o más interfaces utilizando la sintaxis interfaz1+interfaz2+.... Todas las interfaces proporcionadas deben ser únicas y deben existir en la base de datos cuando se utiliza la sintaxis de fusión. Opcionalmente, dependiendo de la configuración del ajuste InterfaceMatchMethod, interfaz puede ser reemplazada por un alias establecido previamente utilizando vnstat --setalias. La sintaxis de fusión no es compatible cuando se utiliza alias. La opción -i, --iface es opcional y interfaz puede utilizarse como parámetro en la línea de comandos para seleccionar la interfaz utilizada incluso sin que la opción se utilice explícitamente.
-ic, --invert-colors [modo]
Invierte los colores de la imagen. El negro se convierte en blanco, los colores oscuros en claros, los colores claros en oscuros y el blanco en negro. El parámetro opcional modo puede utilizarse para cambiar el comportamiento de la inversión de color. Modos disponibles: 0 = sin inversión de color, 1 = invertir todos los colores excepto los utilizados para rx y tx, 2 = invertir todos los colores. Cuando no se especifica modo, se utilizará el modo 1.
-L, --large
Utiliza fuentes grandes en la salida.
--limit límite
Establece el número máximo de entradas mostradas en las salidas de lista a límite. El uso de --limit anula los valores predeterminados del límite de entradas de lista y el parámetro opcional límite dado directamente para una consulta de lista. Todas las entradas almacenadas en la base de datos se mostrarán si límite se establece en 0.
--locale localización
Utiliza localización en lugar de la configuración de localización especificada en el archivo de configuración o la predeterminada del sistema si no hay un archivo de configuración disponible.
-m, --months [límite]
Muestra estadísticas de tráfico mensuales correspondientes a los últimos meses. La longitud de la lista se limitará a 12 entradas a menos que se configure de otra manera o a menos que se utilice el parámetro opcional límite. Todas las entradas almacenadas en la base de datos se mostrarán si límite se establece en 0.
-ne, --noedge
Elimina los bordes más oscuros alrededor de la imagen.
-nh, --noheader
Elimina la cabecera que contiene el título y la hora de actualización. La hora de la actualización anterior seguirá siendo visible en la esquina inferior derecha utilizando un color menos visible.
-nl, --nolegend
Elimina la leyenda que contiene información de mapeo de colores rx y tx de la imagen.
-o, --output archivo
Escribe la imagen en archivo y sale. El formato de imagen utilizado se selecciona mediante la extensión del archivo dada a archivo. Por ejemplo, "imagen.png" da como resultado que el archivo se escriba utilizando el formato de imagen png debido a que se ha utilizado la extensión ".png". El uso del formato de imagen png generalmente resulta en el tamaño de archivo más pequeño sin pérdida de detalle o introducción de artefactos de compresión. Alternativamente, la salida puede dirigirse a stdout proporcionando "-" como archivo, en cuyo caso se utiliza el formato de imagen png.
-ru, --rateunit [modo]
Intercambia la unidad de tasa configurada. Si la tasa se ha configurado para mostrarse en bytes, se mostrará en bits si esta opción está presente. De la misma manera, si la tasa se ha configurado para mostrarse en bits, se mostrará en bytes cuando esta opción esté presente. Alternativamente, se puede utilizar modo con 0 o 1 como parámetro para esta opción con el fin de seleccionar entre bytes (0) y bits (1) independientemente de la configuración del archivo de configuración.
--scale porcentaje
Escala la salida al porcentaje dado, resultando en una imagen más pequeña o más grande que el tamaño predeterminado.
-S, --small
Utiliza fuentes pequeñas en la salida.
--style número
Modifica el contenido y el estilo de las salidas. Establecer número a 3 mostrará la tasa de tráfico promedio en todas las salidas donde sea compatible. Otros valores mostrarán gráficos de barras en su lugar.
-s, --summary
Muestra el resumen de estadísticas de tráfico.
-t, --top [límite]
Muestra los días de mayor tráfico de todos los tiempos. La longitud de la lista se limitará a 10 entradas a menos que se configure de otra manera o a menos que se utilice el parámetro opcional límite. Todas las entradas almacenadas en la base de datos se mostrarán si límite se establece en 0. Cuando se utiliza con --begin y opcionalmente con --end, la lista se generará utilizando los datos diarios en lugar de entradas superiores separadas. La disponibilidad de datos diarios define los límites a los que la consulta específica de fecha puede acceder.
--transparent [habilitado]
Activa/desactiva la transparencia del color de fondo según la configuración TransparentBg en el archivo de configuración. Alternativamente, se puede proporcionar 0 o 1 como parámetro habilitado para esta opción para deshabilitar (0) o habilitar (1) la transparencia independientemente de la configuración del archivo de configuración.
-v, --version
Muestra la versión actual.
-vs, --vsummary [gráfico]
Muestra el resumen de tráfico con el gráfico seleccionado utilizando la configuración SummaryGraph en el archivo de configuración debajo de él utilizando un diseño vertical. El parámetro opcional gráfico puede utilizarse para anular la configuración del archivo de configuración. Gráficos disponibles: 0 = horas, 1 = 5 minutos.
-y, --years [límite]
Muestra estadísticas de tráfico anuales correspondientes a los últimos años. La lista mostrará todas las entradas de forma predeterminada a menos que se configure de otra manera o a menos que se utilice el parámetro opcional límite. Todas las entradas almacenadas en la base de datos también se mostrarán si límite se establece en 0.
-?, --help
Muestra un resumen de las opciones del comando.

ARCHIVOS

/var/lib/vnstat/
Directorio de la base de datos predeterminado.
/etc/vnstat.conf
Archivo de configuración que se utilizará a menos que exista $HOME/.vnstatrc. Consulte vnstat.conf(5) para obtener más información.

EJEMPLOS

vnstati -s -i eth0 -o /tmp/vnstat.png
Muestra el resumen de tráfico para la interfaz eth0 al archivo /tmp/vnstat.png.
vnstati -vs -i eth0+eth1+eth2 -o /tmp/vnstat.png
Muestra el resumen de tráfico con datos horarios debajo del resumen normal para una fusión de las interfaces eth0, eth1 y eth2 al archivo /tmp/vnstat.png.
vnstati -h -c 15 -o /tmp/vnstat_h.png
Muestra estadísticas de tráfico horarias para la interfaz predeterminada al archivo /tmp/vnstat_h.png si el archivo no se ha actualizado en los últimos 15 minutos.
vnstati -d -ne -nh -o -
Muestra estadísticas de tráfico diarias sin mostrar la sección de cabecera ni los bordes para la interfaz predeterminada a la salida estándar (stdout).
vnstati -m --config /home/me/vnstat.cfg -i -o -
Muestra estadísticas de tráfico mensuales para la interfaz predeterminada especificada en el archivo de configuración /home/me/vnstat.cfg a la salida estándar (stdout).

RESTRICCIONES

Dependiendo de las fuentes integradas proporcionadas por la biblioteca GD, es posible que no todos los caracteres se muestren correctamente cuando se utiliza una localización UTF-8.

El uso de formatos de salida de fecha largos puede causar desalineación en las columnas mostradas si la longitud de la fecha excede la asignación de tamaño fijo.

Al escalar una imagen con la transparencia de fondo activada, es posible que la transparencia no se conserve.
