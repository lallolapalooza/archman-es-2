VFS_SYNCOPS(8) Herramientas de administración del sistema VFS_SYNCOPS(8)

NOMBRE

vfs_syncops - Asegura que las operaciones de metadatos se realicen sincrónicamente.

SINOPSIS

objetos vfs = syncops

DESCRIPCIÓN

Este módulo VFS forma parte del conjunto de herramientas samba(7).

Algunos sistemas de archivos (incluso algunos sistemas de archivos con registro por diario) requieren que se realice un fsync() en muchas operaciones de metadatos para garantizar que la operación permanezca en el sistema de archivos después de un corte de energía. Esto es particularmente importante para algunos sistemas de archivos en clúster que participan en un sistema de conmutación por error de nodos con Samba en clúster. En esos sistemas de archivos, el módulo VFS vfs_syncops proporciona una forma de realizar esas operaciones de forma segura.

Este módulo es apilable.

CONFIGURACIÓN

La mayor parte de la pérdida de rendimiento con el módulo VFS vfs_syncops se produce en el fsync al cerrar (). Puede deshabilitar esto con syncops:onclose = no, que se puede configurar globalmente o por recurso compartido.

En ciertos sistemas de archivos que solo requieren que los últimos datos escritos se sincronicen con fsync(), puede deshabilitar la sincronización de metadatos de este módulo con syncops:onmeta = no. Esta opción se puede configurar globalmente o por recurso compartido.

El módulo VFS vfs_syncops también se puede deshabilitar por completo para un recurso compartido con syncops:disable = true.

EJEMPLOS

Agregar funcionalidad de syncops para [recurso compartido]:

        [recurso_compartido]
	path = /data/recurso_compartido
	vfs objects = syncops
	syncops:onclose = no
