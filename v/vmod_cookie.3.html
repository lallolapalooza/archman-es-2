NOMBRE

vmod_cookie - Módulo de Cookies de Varnish

SINOPSIS

import cookie [as nombre] [from "ruta"]
VOID clean()
VOID delete(STRING nombre_cookie)
VOID filter(STRING cadena_filtro)
VOID filter_re(REGEX expresion)
VOID keep(STRING cadena_filtro)
VOID keep_re(REGEX expresion)
STRING format_date(TIME ahora, DURATION tiempo_delta)
STRING get(STRING nombre_cookie)
STRING get_re(REGEX expresion)
STRING get_string()
BOOL isset(STRING nombre_cookie)
VOID parse(STRING cabecera_cookie)
VOID set(STRING nombre_cookie, STRING valor)

DESCRIPCIÓN

Maneja las cookies HTTP más fácilmente en VCL de Varnish.

Analiza una cabecera de cookie en un almacén de datos interno, donde hay funciones get/set/delete por cookie disponibles. Una función keep() elimina todas las cookies excepto un conjunto de ellas, separadas por comas. Una función filter() elimina un conjunto de cookies separadas por comas.

Se pueden usar expresiones regulares para seleccionar cookies, eliminar cookies coincidentes y eliminar nombres de cookies no coincidentes.

También se incluye una función de conveniencia para formatear el campo de fecha Expires de Set-Cookie.

El estado cargado con cookie.parse() tiene una vida útil del contexto de la solicitud actual o de la solicitud al backend. Para pasar variables a la solicitud al backend, almacene los contenidos como cabeceras bereq falsas.

Ejemplo de filtrado:

import cookie;
sub vcl_recv {
    if (req.http.cookie) {
        cookie.parse(req.http.cookie);
        # Ya sea eliminar las que quieres deshacerte:
        cookie.delete("cookie2");
        # o eliminar todas excepto unas pocas:
        cookie.keep("SESSIONID,PHPSESSID");
        # Almacenarla de nuevo en req para que se pase al backend.
        set req.http.cookie = cookie.get_string();
        # Si está vacía, anularla para que el VCL incorporado pueda considerarla para el caché.
        if (req.http.cookie == "") {
            unset req.http.cookie;
        }
    }
}

VOID clean()

Limpia las cookies analizadas previamente. No es necesario ejecutar clean() en operaciones normales.

Ejemplo:

sub vcl_recv {
    cookie.clean();
}

VOID delete(STRING nombre_cookie)

Elimina nombre_cookie del almacenamiento interno de vmod si existe.

Ejemplo:

sub vcl_recv {
    cookie.parse("cookie1=valor1; cookie2=valor2");
    cookie.delete("cookie2");
    # get_string() ahora producirá "cookie1=valor1"
}

VOID filter(STRING cadena_filtro)

Elimina todas las cookies del almacenamiento interno de vmod que estén en los nombres de cookie del argumento separado por comas.

Ejemplo:

sub vcl_recv {
    cookie.parse("cookie1=valor1; cookie2=valor2; cookie3=valor3");
    cookie.filter("cookie1,cookie2");
    # get_string() ahora producirá "cookie3=valor3"
}

VOID filter_re(REGEX expresion)

Elimina todas las cookies del almacenamiento interno de vmod que coincidan con la expresión regular expresion.

Ejemplo:

sub vcl_recv {
    cookie.parse("cookie1=valor1; cookie2=valor2; cookie3=valor3");
    cookie.filter_re("^cookie[12]$");
    # get_string() ahora producirá "cookie3=valor3"
}

VOID keep(STRING cadena_filtro)

Elimina todas las cookies del almacenamiento interno de vmod que no estén en los nombres de cookie del argumento separado por comas.

Ejemplo:

sub vcl_recv {
    cookie.parse("cookie1=valor1; cookie2=valor2; cookie3=valor3");
    cookie.keep("cookie1,cookie2");
    # get_string() ahora producirá "cookie1=valor1; cookie2=valor2"
}

VOID keep_re(REGEX expresion)

Elimina todas las cookies del almacenamiento interno de vmod que no coincidan con la expresión expresion.

Ejemplo:

sub vcl_recv {
    cookie.parse("cookie1=valor1; cookie2=valor2; cookie3=valor3");
    cookie.keep_re("^cookie[12]$");
    # get_string() ahora producirá "cookie1=valor1; cookie2=valor2"
}

STRING format_date(TIME ahora, DURATION tiempo_delta)

Obtiene una cadena de fecha formateada según RFC1123 adecuada para incluirla en una cabecera de respuesta Set-Cookie.

Se debe tener cuidado si la respuesta tiene múltiples cabeceras Set-Cookie. En ese caso, se debe usar el vmod de cabeceras.

Ejemplo:

sub vcl_deliver {
    # Establece una cookie de usuario en el cliente que dura 5 minutos.
    set resp.http.Set-Cookie = "userid=" + req.http.userid +
        "; Expires=" + cookie.format_date(now, 5m) + "; httpOnly";
}

STRING get(STRING nombre_cookie)

Obtiene el valor de nombre_cookie, tal como está almacenado en el almacenamiento interno de vmod.

Ejemplo:

import std;
sub vcl_recv {
    cookie.parse("cookie1=valor1; cookie2=valor2");
    std.log("el valor de cookie1 es: " + cookie.get("cookie1"));
}

Si nombre_cookie no existe, se devuelve la cadena NULL. Tenga en cuenta que una cadena NULL se convierte en una cadena vacía cuando se asigna a una cabecera. Esto significa que lo siguiente es correcto:

if (req.http.Cookie) {
        cookie.parse(req.http.Cookie);
        set req.http.X-tmp = cookie.get("una_cookie");
} else {
        set req.http.X-tmp = "";
}
if (req.http.X-tmp != "") {
        # hacer algo con la cabecera X-tmp...
} else {
        # caso de fallback
}

Sin embargo, usar cookie.isset() suele ser una mejor manera de comprobar si una cookie particular está presente, así:

unset req.http.X-tmp; # innecesario si no se necesita fallback
if (req.http.Cookie) {
        cookie.parse(req.http.Cookie);
        if (cookie.isset("una_cookie")) {
                set req.http.X-tmp = cookie.get("una_cookie");
                # hacer algo con la cabecera X-tmp...
        }
}
# si es necesario, hacer algo cuando una_cookie no está ahí
if (!req.http.X-tmp) {
        # caso de fallback
}

STRING get_re(REGEX expresion)

Obtiene el valor de la primera cookie en el almacenamiento interno de vmod que coincide con la expresión regular expresion. Si nada coincide, se devuelve la cadena NULL.

Ejemplo:

import std;
sub vcl_recv {
    cookie.parse("cookie1=valor1; cookie2=valor2");
    std.log("el valor de cookie1 es: " + cookie.get_re("^cookie1$"));
}

STRING get_string()

Obtiene un valor de cadena de Cookie con todas las cookies en el almacenamiento interno de vmod. No modifica el almacenamiento interno.

Ejemplo:

sub vcl_recv {
    cookie.parse(req.http.cookie);
    cookie.keep("SESSIONID,PHPSESSID");
    set req.http.cookie = cookie.get_string();
}

BOOL isset(STRING nombre_cookie)

Comprueba si existe una cookie con el nombre nombre_cookie en el almacenamiento interno de vmod.

Ejemplo:

sub vcl_recv {
    cookie.parse("cookie1=valor1; cookie2=valor2");
    if (cookie.isset("cookie1")) {
        # cookie1 está presente
    }
}

VOID parse(STRING cabecera_cookie)

Analiza la cadena de cabecera de cookie especificada en el almacenamiento interno de vmod.

Ejemplo:

sub vcl_recv {
    cookie.parse(req.http.cookie);
}

El formato de la cabecera de cookie es el especificado en RFC 6265.

Ejemplo de cómo construir una cabecera de cookie modificada para ser enviada al backend:

sub vcl_recv {
    cookie.parse(req.http.cookie);
    cookie.delete("TrackingID");
    cookie.set("NewCookie", "NewValue");
    set req.http.cookie = cookie.get_string();
}

VOID set(STRING nombre_cookie, STRING valor)

Establece el valor de nombre_cookie en el almacenamiento interno de vmod. Si nombre_cookie ya existe, su valor se sobrescribe.

Ejemplo:

sub vcl_recv {
    cookie.parse("cookie1=valor1");
    cookie.set("cookie1", "new_value");
    # get_string() ahora producirá "cookie1=new_value"
}

Si nombre_cookie no existe, se añade al almacenamiento interno.

sub vcl_recv {
    cookie.parse("cookie1=valor1");
    cookie.set("cookie2", "valor2");
    # get_string() ahora producirá "cookie1=valor1; cookie2=valor2"
}

NAME

vmod_cookie — cookie handling Varnish module

SYNOPSIS

import cookie;

cookie.parse(STRING cookieheader);
cookie.clean();
cookie.get(STRING cookiename);
cookie.isset(STRING cookiename);
cookie.set(STRING cookiename, STRING value);
cookie.unset(STRING cookiename);
cookie.list();

DESCRIPTION

The cookie VMOD provides an API to parse and manage HTTP cookies.

clean()

Cleans the internal vmod storage.

Example:

import cookie;
sub vcl_recv {
    cookie.parse(req.http.Cookie);
    cookie.clean();
}

get(STRING cookiename)

Returns the value of cookiename from the internal vmod storage. Returns empty string if cookiename is not found.

Example:

import std;
import cookie;
sub vcl_recv {
    cookie.parse("cookie1=value1; cookie2=value2");
    local.mycookie = cookie.get("cookie1");
    std.log("cookie1 is: " + local.mycookie);
}

isset(STRING cookiename)

Check if cookiename is set in the internal vmod storage.

Example:

import std;
sub vcl_recv {
    cookie.parse("cookie1=value1; cookie2=value2");
    if (cookie.isset("cookie2")) {
        std.log("cookie2 is set.");
    }
}

VOID parse(STRING cookieheader)

Parse the cookie string in cookieheader. If state already exists, clean() will be run first.

Example:

sub vcl_recv {
    cookie.parse(req.http.Cookie);
}

VOID set(STRING cookiename, STRING value)

Set the internal vmod storage for cookiename to value.

Example:

sub vcl_recv {
    cookie.set("cookie1", "value1");
    std::log("cookie1 value is: " + cookie.get("cookie1"));
}

VOID unset(STRING cookiename)

Removes cookiename from the internal vmod storage.

Example:

sub vcl_recv {
    cookie.set("cookie1", "value1");
    cookie.unset("cookie1");
    if (!cookie.isset("cookie1")) {
        std::log("cookie1 was unset successfully.");
    }
}

list()

Returns a STRING containing all stored cookies as a semicolon separated string. Similar to the format of the HTTP Cookie header.

Example:

import std;
sub vcl_recv {
    cookie.set("cookie1", "value1");
    cookie.set("cookie2", "value2");
    std::log("Cookies are: " + cookie.list());
}
