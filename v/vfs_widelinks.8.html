VFS_WIDELINKS(8) Herramientas de administración del sistema VFS_WIDELINKS(8)

NOMBRE

vfs_widelinks - hace que un recurso compartido de Samba ignore los enlaces simbólicos del sistema de archivos dentro de un recurso compartido

SINOPSIS

objetos vfs = widelinks

DESCRIPCIÓN

Este módulo VFS forma parte del conjunto samba(7).

El módulo VFS vfs_widelinks oculta la existencia de enlaces simbólicos en el sistema de archivos dentro de un recurso compartido. Se utiliza en Samba versión 4.13 y posteriores para implementar la funcionalidad "wide links = yes" de smb.conf que solía estar dentro del código central de smbd. El módulo no debe cargarse explícitamente por smb.conf como parte del parámetro "vfs objects =", sino que se carga implícitamente cuando se habilita "wide links = yes". Esto es para evitar que los archivos smb.conf existentes tengan que modificarse para mantener la funcionalidad insegura existente de "wide links" en un recurso compartido.

Tenga en cuenta que la funcionalidad "wide links = yes" es una opción deliberadamente insegura y nunca debe utilizarse en instalaciones de Samba. En Linux, se pueden utilizar montajes bind en su lugar para implementar cualquier cosa que "wide links = yes" pueda habilitar. Este módulo se ha creado para proporcionar compatibilidad con versiones anteriores para los usuarios existentes de instalaciones con "wide links = yes", pero este uso no puede ser recomendado y no está respaldado por los desarrolladores de Samba.

Tenga en cuenta que esta carga implícita puede volverse explícita en una versión posterior de Samba, y los administradores que deseen mantener la funcionalidad insegura de "wide links" pueden tener que agregar este módulo a su lista de módulos "vfs objects =". Las notas de la versión del proyecto Samba y esta página del manual se actualizarán para reflejar esto cuando se realice este cambio.

Este módulo es apilable.

EJEMPLOS

No hay ejemplos listados. Este módulo se carga implícitamente por smbd según sea necesario.
