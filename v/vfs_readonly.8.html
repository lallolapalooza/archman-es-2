VFS_READONLY(8) Herramientas de administración del sistema VFS_READONLY(8)

NOMBRE

vfs_readonly - hace que un recurso compartido de Samba sea de solo lectura durante un período de tiempo especificado

SINOPSIS

objetos vfs = readonly

DESCRIPCIÓN

Este módulo VFS forma parte del conjunto de utilidades de samba(7).

El módulo VFS vfs_readonly marca un recurso compartido como de solo lectura para todos los clientes que se conectan dentro del período de tiempo configurado. Los clientes que se conecten durante este tiempo tendrán denegado el acceso de escritura a todos los archivos del recurso compartido, independientemente de sus privilegios de acceso reales.

Este módulo es apilable.

OPCIONES

readonly:period = INICIO, FIN

Solo marca el recurso compartido como de solo lectura si la conexión del cliente se realizó entre las horas marcadas por los especificadores de fecha INICIO y FIN. La sintaxis de estos especificadores de fecha es la misma que la aceptada por la opción -d de date(1) de GNU.

EJEMPLOS

Marca todos los recursos compartidos como de solo lectura:

        [global]
	vfs objects = readonly

Marca el recurso compartido [backup] como de solo lectura durante el horario comercial:

        [backup]
	path = /readonly
	vfs objects = readonly
	readonly:period = readonly:period = "hoy 9:00","hoy 17:00"
