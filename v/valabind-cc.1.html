NOMBRE

valabind-cc — Compilador de interfaz de Vala a swig

SINOPSIS

valabind-cc lenguaje nombre_mod [--version] [--vapidir dir] [--glib] [--test lang] [-n] [-x] [-X] [-I ruta] [-L ruta] [-l nombre_lib] [-D SIMBOLO] [-C] archivo_vapi

DESCRIPCIÓN

valabind-cc es un frontend para valabind, swig y el compilador C (gcc por defecto).

Su objetivo es simplificar el uso de todas las herramientas envueltas y compilar bindings utilizables para muchos lenguajes de programación.

EJEMPLO

valabind-cc python r_bp -I/usr/include/r_bp r_bp.vapi

ENTORNO

XDG_DATA_DIRS Variable de entorno estándar de freedesktop para apuntar al directorio de prefijo compartido donde vala busca archivos vapi.
