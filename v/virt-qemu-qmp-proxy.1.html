virt-qemu-qmp-proxy(1) Soporte de virtualización virt-qemu-qmp-proxy(1)

Nombre

virt-qemu-qmp-proxy - Exponer un servidor proxy QMP para una máquina virtual QEMU de libvirt

SINOPSIS

virt-qemu-qmp-proxy [OPCIÓN]... DOMINIO RUTA-SOCKET-QMP

DESCRIPCIÓN

Esta herramienta proporciona una forma de exponer un servidor proxy QMP que se comunica con una máquina virtual QEMU administrada por libvirt. Esto permite que las herramientas estándar del cliente QMP interactúen con las máquinas virtuales administradas por libvirt.

NOTA: el uso de esta herramienta hará que la máquina virtual QEMU en ejecución se marque como "tainted" (contaminada). Se recomienda encarecidamente que esta herramienta solo se utilice para enviar comandos que consulten información sobre la máquina virtual en ejecución. Si esta herramienta se utiliza para realizar cambios en el estado de la máquina virtual, esto puede tener interacciones negativas con el controlador QEMU, lo que resultará en la incapacidad de administrar la operación de la máquina virtual a partir de entonces, y en el peor de los casos, podría provocar pérdida o corrupción de datos.

El programa virt-qemu-qmp-proxy escuchará en un socket UNIX las conexiones entrantes de los clientes y ejecutará el protocolo QMP a través de la conexión. Cualquier comando recibido se enviará a la máquina virtual libvirt en ejecución y las respuestas se enviarán de vuelta.

El programa virt-qemu-qmp-proxy puede interrumpirse (por ejemplo, Ctrl-C) cuando ya no sea necesario. La máquina virtual QEMU de libvirt continuará ejecutándose.

OPCIONES

DOMINIO

El ID, UUID o Nombre de la máquina virtual QEMU de libvirt.

RUTA-SOCKET-QMP

La ruta del sistema de archivos en la que se ejecutará el servidor QMP, escuchando las conexiones entrantes.

-c URI-CONEXION --connect=URI-CONEXION

La URI para la conexión al controlador QEMU de libvirt. Si se omite, se detectará automáticamente una URI.

-v, --verbose

Ejecutar en modo detallado, imprimiendo todos los comandos y respuestas QMP que se manejan.

-h, --help

Mostrar la ayuda de la línea de comandos.

ESTADO DE SALIDA

Al apagarse con éxito, se establecerá un estado de salida de 0. En caso de fallo, se establecerá un estado distinto de cero.
