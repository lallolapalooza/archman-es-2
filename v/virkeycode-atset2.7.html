    virkeycode(7) - Arch Linux man pages

    Name

    virkeycode - map virtio key events to key names

    DESCRIPTION

    This document maps virtio key event codes to symbolic key names.

    The key codes are unsigned 32-bit integers. The upper 16 bits are used for flags, and the lower 16 bits are used for the key code.

    The flags currently defined are:

    0x0001
    The key event is a key repeat.

    The key codes are defined in the Linux kernel header ‘include/uapi/linux/input-event-codes.h’.
