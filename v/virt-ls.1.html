NAME

virt-ls - List files in a virtual machine

SYNOPSIS

virt-ls [--options] -d domname directory [directory ...]
virt-ls [--options] -a disk.img [-a disk.img ...] directory [directory ...]

Old style:

virt-ls [--options] domname directory
virt-ls [--options] disk.img [disk.img ...] directory

DESCRIPTION

"virt-ls" lists filenames, file sizes, checksums, extended attributes and more from a virtual machine or disk image.

Multiple directory names can be given, in which case the output from each is concatenated.

To list directories from a libvirt guest use the -d option to specify the name of the guest. For a disk image, use the -a option.

"virt-ls" can do many simple file listings. For more complicated cases you may need to use guestfish(1), or write a program directly to the guestfs(3) API.

EXAMPLES

Get a list of all files and directories in a virtual machine:

virt-ls -R -d guest /

List all setuid or setgid programs in a Linux virtual machine:

virt-ls -lR -d guest / | grep '^- [42]'

List all public-writable directories in a Linux virtual machine:

virt-ls -lR -d guest / | grep '^d ...7'

List all Unix domain sockets in a Linux virtual machine:

virt-ls -lR -d guest / | grep '^s'

List all regular files with filenames ending in ‘.png’:

virt-ls -lR -d guest / | grep -i '^-.*\.png$'

To display files larger than 10MB in home directories:

virt-ls -lR -d guest /home | awk '$3 > 10*1024*1024'

Find everything modified in the last 7 days:

virt-ls -lR -d guest --time-days / | awk '$6 <= 7'

Find regular files modified in the last 24 hours:

virt-ls -lR -d guest --time-days / | grep '^-' | awk '$6 < 1'

DIFFERENCES IN SNAPSHOTS AND BACKING FILES

Although it is possible to use virt-ls to look for differences, since libguestfs ≥ 1.26 a new tool is available called virt-diff(1).

OUTPUT MODES

"virt-ls" has four output modes, controlled by different combinations of the -l and -R options.

SIMPLE LISTING

A simple listing is like the ordinary ls(1) command:

$ virt-ls -d guest /
bin
boot
[etc.]

LONG LISTING

With the -l (--long) option, the output is like the "ls -l" command (more specifically, like the "guestfs_ll" function).

$ virt-ls -l -d guest /
total 204
dr-xr-xr-x.   2 root root   4096 2009-08-25 19:06 bin
dr-xr-xr-x.   5 root root   3072 2009-08-25 19:06 boot
[etc.]

Note that while this is useful for displaying a directory, do not try parsing this output in another program. Use "RECURSIVE LONG LISTING" instead.

RECURSIVE LISTING

With the -R (--recursive) option, "virt-ls" lists the names of files and directories recursively:

$ virt-ls -R -d guest /tmp
foo
foo/bar
[etc.]

To generate this output, "virt-ls" runs the "guestfs_find0" function and converts "\0" characters to "\n".

RECURSIVE LONG LISTING

Using -lR options together changes the output to display directories recursively, with file stats, and optionally other features such as checksums and extended attributes.

Most of the interesting features of "virt-ls" are only available when using -lR mode.

The fields are normally space-separated. Filenames are not quoted, so you cannot use the output in another program (because filenames can contain spaces and other unsafe characters). If the guest was untrusted and someone knew you were using "virt-ls" to analyze the guest, they could play tricks on you by creating filenames with embedded newline characters. To safely parse the output in another program, use the --csv (Comma-Separated Values) option.

Note that this output format is completely unrelated to the "ls -lR" command.

$ virt-ls -lR -d guest /bin
d 0555       4096 /bin
- 0755        123 /bin/alsaunmute
- 0755      28328 /bin/arch
l 0777          4 /bin/awk -> gawk
- 0755      27216 /bin/basename
- 0755     943360 /bin/bash
[etc.]

These basic fields are always shown:

type
The file type, one of: "-" (regular file), "d" (directory), "c" (character device), "b" (block device), "p" (named pipe), "l" (symbolic link), "s" (socket) or "u" (unknown).
permissions
The Unix permissions, displayed as a 4 digit octal number.
size
The size of the file. This is shown in bytes unless -h or --human-readable option is given, in which case this is shown as a human-readable number.
path
The full path of the file or directory.
link
For symbolic links only, the link target.

In -lR mode, additional command line options enable the display of more fields.

With the --uids flag, these additional fields are displayed before the path:

uid
gid
The UID and GID of the owner of the file (displayed numerically). Note these only make sense in the context of a Unix-like guest.

With the --times flag, these additional fields are displayed:

atime
The time of last access.
mtime
The time of last modification.
ctime
The time of last status change.

The time fields are displayed as string dates and times, unless one of the --time-t, --time-relative or --time-days flags is given.

With the --extra-stats flag, these additional fields are displayed:

device
The device containing the file (displayed as major:minor). This may not match devices as known to the guest.
inode
The inode number.
nlink
The number of hard links.
rdev
For block and char special files, the device (displayed as major:minor).
blocks
The number of 512 byte blocks allocated to the file.

With the --checksum flag, the checksum of the file contents is shown (only for regular files). Computing file checksums can take a considerable amount of time.

OPTIONS

--help
Muestra ayuda breve.
-a archivo
--add archivo
Añade archivo, que debe ser una imagen de disco de una máquina virtual. Si la máquina virtual tiene varios dispositivos de bloque, debes proporcionarlos todos con opciones -a separadas.

El formato de la imagen de disco se detecta automáticamente. Para anular esto y forzar un formato particular, usa la opción --format=...

-a URI
--add URI
Añade un disco remoto. Consulta "AÑADIR ALMACENAMIENTO REMOTO" en guestfish(1).
--blocksize=512
--blocksize=4096
--blocksize
Este parámetro establece el tamaño del sector de la imagen de disco. Afecta a todos los discos añadidos explícitamente después de este parámetro. Usar --blocksize sin argumento cambia el tamaño del sector del disco al valor predeterminado, que suele ser de 512 bytes. Consulta también "guestfs_add_drive_opts" en guestfs(3).
--checksum
--checksum=crc|md5|sha1|sha224|sha256|sha384|sha512
Muestra la suma de comprobación del contenido de los archivos regulares. Sin argumento, esto usa md5 por defecto. Usando un argumento, puedes seleccionar el tipo de suma de comprobación a usar.

Esta opción solo tiene efecto en el modo de salida -lR. Consulta "LISTADO LARGO RECURSIVO" arriba.

-c URI
--connect URI
Si usas libvirt, conéctate a la URI dada. Si se omite, nos conectaremos al hipervisor libvirt predeterminado.

Si especificas dispositivos de bloque de invitado directamente (-a), entonces libvirt no se usa en absoluto.

--csv
Escribe los resultados en formato CSV (valores separados por comas). Este formato se puede importar fácilmente a bases de datos y hojas de cálculo, pero lee "NOTA SOBRE EL FORMATO CSV" abajo.
-d invitado
--domain invitado
Añade todos los discos del invitado libvirt nombrado. Se pueden usar UUIDs de dominio en lugar de nombres.
--echo-keys
Al solicitar claves y frases de contraseña, virt-ls normalmente desactiva el eco para que no puedas ver lo que estás escribiendo. Si no te preocupan los ataques Tempest y no hay nadie más en la habitación, puedes especificar esta bandera para ver lo que escribes.
--extra-stats
Muestra estadísticas adicionales.

Esta opción solo tiene efecto en el modo de salida -lR. Consulta "LISTADO LARGO RECURSIVO" arriba.

--format=raw|qcow2|..
--format
El valor predeterminado para la opción -a es auto-detectar el formato de la imagen de disco. Usar esto fuerza el formato de disco para las opciones -a que sigan en la línea de comandos. Usar --format sin argumento vuelve a la auto-detección para las opciones -a subsiguientes.

Por ejemplo:

virt-ls --format=raw -a disco.img /dir

fuerza el formato raw (sin auto-detección) para disco.img.

virt-ls --format=raw -a disco.img --format -a otro.img /dir

fuerza el formato raw (sin auto-detección) para disco.img y revierte a auto-detección para otro.img.

Si tienes imágenes de disco de invitado en formato raw no confiables, deberías usar esta opción para especificar el formato del disco. Esto evita un posible problema de seguridad con invitados maliciosos (CVE-2010-3851).

-h
--human-readable
Muestra los tamaños de archivo en formato legible para humanos.

Esta opción solo tiene efecto en el modo de salida -lR. Consulta "LISTADO LARGO RECURSIVO" arriba.

--key SELECCIONADOR
Especifica una clave para LUKS, para abrir automáticamente un dispositivo LUKS al usar la inspección.
--key NOMBRE:key:CADENA_CLAVE
--key UUID:key:CADENA_CLAVE
--key all:key:CADENA_CLAVE
"NOMBRE" es el nombre del dispositivo libguestfs (ej. "/dev/sda1"). "UUID" es el UUID del dispositivo. "all" significa intentar la clave contra cualquier dispositivo cifrado.

Usa la "CADENA_CLAVE" especificada como frase de contraseña.

--key NOMBRE:file:NOMBRE_ARCHIVO
--key UUID:file:NOMBRE_ARCHIVO
--key all:file:NOMBRE_ARCHIVO
Lee la frase de contraseña de NOMBRE_ARCHIVO.
--key NOMBRE:clevis
--key UUID:clevis
--key all:clevis
Intenta desbloquear sin frase de contraseña el dispositivo con Clevis, a través de la red. Consulta "DISCOS CIFRADOS" en guestfs(3) para más información sobre el cifrado de disco enlazado a la red (NBDE).

Ten en cuenta que si alguna de estas opciones está presente en la línea de comandos, la red de usuario de QEMU se habilitará automáticamente para la aplicación libguestfs.

--keys-from-stdin
Lee parámetros de clave o frase de contraseña desde stdin. El valor predeterminado es intentar leer frases de contraseña del usuario abriendo /dev/tty.

Si hay varios dispositivos cifrados, es posible que necesites proporcionar varias claves en stdin, una por línea.

-m dev[:punto_montaje[:opciones[:tipofs]]]
--mount dev[:punto_montaje[:opciones[:tipofs]]]
Monta la partición o volumen lógico nombrado en el punto de montaje dado.

Si se omite el punto de montaje, se utiliza / por defecto.

Especificar cualquier punto de montaje desactiva la inspección del invitado y el montaje de su raíz y todos sus puntos de montaje, así que asegúrate de montar todos los puntos de montaje necesarios para trabajar con los nombres de archivo dados como argumentos.

Si no sabes qué sistemas de archivos contiene una imagen de disco, puedes ejecutar guestfish sin esta opción, luego listar las particiones, sistemas de archivos y LVs disponibles (ver los comandos "list-partitions", "list-filesystems" y "lvs"), o puedes usar el programa virt-filesystems(1).

La tercera (y raramente usada) parte del parámetro de montaje es la lista de opciones de montaje usadas para montar el sistema de archivos subyacente. Si no se proporciona, las opciones de montaje son la cadena vacía o "ro" (esta última si se usa la bandera --ro). Especificando las opciones de montaje, anulas esta elección predeterminada. Probablemente la única vez que usarías esto es para habilitar ACLs y/o atributos extendidos si el sistema de archivos puede soportarlos:

-m /dev/sda1:/:acl,user_xattr

Usar esta bandera es equivalente a usar el comando "mount-options".

La cuarta parte del parámetro es el controlador de sistema de archivos a usar, como "ext3" o "ntfs". Esto rara vez es necesario, pero puede ser útil si varios controladores son válidos para un sistema de archivos (ej: "ext2" y "ext3"), o si libguestfs identifica incorrectamente un sistema de archivos.

-l
--long
-R
--recursive
Selecciona el modo. Sin ninguna de estas opciones, "virt-ls" produce una lista simple y plana de los archivos en el directorio nombrado. Consulta "LISTADO SIMPLE".

"virt-ls -l" produce un "listado largo", que muestra más detalles. Consulta "LISTADO LARGO".

"virt-ls -R" produce una lista recursiva de archivos comenzando en el directorio nombrado. Consulta "LISTADO RECURSIVO".

"virt-ls -lR" produce un listado largo recursivo que puede ser analizado más fácilmente. Consulta "LISTADO LARGO RECURSIVO".

--times
Muestra campos de tiempo.

Esta opción solo tiene efecto en el modo de salida -lR. Consulta "LISTADO LARGO RECURSIVO" arriba.

--time-days
Muestra campos de tiempo como días anteriores a ahora (negativo si está en el futuro).

Ten en cuenta que 0 en la salida significa "hasta 1 día antes de ahora", o que la antigüedad del archivo está entre 0 y 86399 segundos.

Esta opción solo tiene efecto en el modo de salida -lR. Consulta "LISTADO LARGO RECURSIVO" arriba.

--time-relative
Mostrar campos de tiempo como segundos antes de ahora (negativo si está en el futuro).

Esta opción solo tiene efecto en el modo de salida -lR. Ver "LISTADO LARGO RECURSIVO" arriba.

--time-t
Mostrar campos de tiempo como segundos desde la época Unix.

Esta opción solo tiene efecto en el modo de salida -lR. Ver "LISTADO LARGO RECURSIVO" arriba.

--uids
Mostrar campos UID y GID.

Esta opción solo tiene efecto en el modo de salida -lR. Ver "LISTADO LARGO RECURSIVO" arriba.

-v
--verbose
Habilitar mensajes detallados para depuración.
-V
--version
Mostrar número de versión y salir.
-x
Habilitar el rastreo de llamadas a la API de libguestfs.

ARGUMENTOS DE LÍNEA DE COMANDOS ESTILO ANTIGUO

Versiones anteriores de virt-ls le permitían escribir:

virt-ls disk.img [disk.img ...] /dir

o

virt-ls guestname /dir

mientras que en esta versión debería usar -a o -d respectivamente para evitar el caso confuso en el que una imagen de disco podría tener el mismo nombre que un huésped.

Por compatibilidad, el estilo antiguo todavía es compatible.

NOTA SOBRE EL FORMATO CSV

Los valores separados por comas (CSV) son un formato engañoso. Parece que debería ser fácil de analizar, pero definitivamente no es fácil de analizar.

Mito: Simplemente divida los campos en comas. Realidad: Esto no funciona de manera fiable. Este ejemplo tiene dos columnas:

"foo,bar",baz

Mito: Lea el archivo línea por línea. Realidad: Esto no funciona de manera fiable. Este ejemplo tiene una fila:

"foo
bar",baz

Para scripts de shell, use "csvtool" (https://github.com/Chris00/ocaml-csv también empaquetado en las principales distribuciones de Linux).

Para otros idiomas, utilice una biblioteca de procesamiento de CSV (por ejemplo, "Text::CSV" para Perl o la biblioteca csv incorporada de Python).

La mayoría de las hojas de cálculo y bases de datos pueden importar CSV directamente.

ESTADO DE SALIDA

Este programa devuelve 0 si tiene éxito, o un valor distinto de cero si hubo un error.
