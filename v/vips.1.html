VIPS(1) Manual de Comandos Generales VIPS(1)

NOMBRE

vips - ejecuta operaciones de vips desde la línea de comandos

SINOPSIS

vips [opciones] [comando] [opciones-comando] [argumentos-comando]

DESCRIPCIÓN

vips(1) es el programa principal universal de VIPS. Puedes usarlo para ejecutar cualquier operación de VIPS desde la línea de comandos, para consultar la jerarquía de clases de VIPS y para mantener partes de la biblioteca VIPS.

Para ejecutar una operación de VIPS, el primer argumento debe ser el nombre de la operación y los argumentos siguientes deben ser los argumentos de la operación. Por ejemplo:


$ vips invert lena.v lena2.v

OPCIONES

-l NOMBRE-BASE, --list=NOMBRE-BASE
Lista operaciones debajo de NOMBRE-BASE. Esto imprime un resumen de una línea de cada operación en vips debajo de la clase NOMBRE-BASE, donde NOMBRE-BASE puede ser un nombre completo de clase vips o un apodo.

Si no se proporciona NOMBRE-BASE, se listarán todas las clases debajo de VipsOperation.

-p PLUGIN, --plugin=PLUGIN
Carga PLUGIN. Ten en cuenta que los plugins en $VIPSHOME/lib/vips-plugins-MAJOR.MINOR se cargan automáticamente.
-v, --version
Muestra la versión de VIPS.
-c NOMBRE, --completion NOMBRE
Imprime autocompletados para NOMBRE

COMANDOS

nombre-operacion argumentos-operacion
Ejecuta una operación con nombre, por ejemplo add.

EJEMPLOS

Ejecuta una operación de vips. Las opciones de operación deben seguir el nombre de la operación.


$ vips insert lena.v lena2.v out.v 0 0 --background "128 0 0"

Obtener un mensaje de "uso" para una operación.


$ vips insert
insert image @sub into @main at @x, @y
uso:
insert main sub out x y
donde:
main - Imagen de entrada principal, entrada VipsImage
sub - Subimagen para insertar en main, entrada VipsImage
out - Imagen de salida, salida VipsImage
x - Borde izquierdo de sub en main, entero gint por defecto: 0 min: -100000000, max: 100000000
y - Borde superior de sub en main, entero gint por defecto: 0 min: -100000000, max: 100000000
argumentos opcionales:
expand - Expande la salida para contener ambas entradas, booleano gboolean por defecto: falso
background - Color para los píxeles nuevos, arreglo doble VipsArrayDouble
flags de operación: secuencial

Lista todas las operaciones de dibujo.


$ vips -l draw
VipsDraw (draw), operaciones de dibujo
VipsDrawink (drawink), operaciones de dibujo con tinta
VipsDrawRect (draw_rect), pinta un rectángulo en una imagen
VipsDrawMask (draw_mask), dibuja una máscara en una imagen
VipsDrawLine (draw_line), dibuja una línea en una imagen
VipsDrawCircle (draw_circle), dibuja un círculo en una imagen
VipsDrawFlood (draw_flood), rellena un área con inundación
VipsDrawImage (draw_image), pinta una imagen dentro de otra imagen
VipsDrawSmudge (draw_smudge), difumina un rectángulo en una imagen

VALOR DE RETORNO

devuelve 0 en caso de éxito y un valor distinto de cero en caso de error.
