vmod_unix(3)

Paquete: varnish

Licencias: BSD-2-Clause

VMOD_UNIX(3) Manual de funciones de biblioteca VMOD_UNIX(3)

NOMBRE

vmod_unix - Utilidades para sockets de dominio Unix

SINOPSIS

import unix [as nombre] [from "ruta"]
STRING user()
STRING group()
INT uid()
INT gid()

DESCRIPCIÓN

Este VMOD proporciona información sobre las credenciales del proceso par (usuario y grupo del propietario del proceso) que está conectado a un escucha de Varnish a través de un socket de dominio Unix, si la plataforma lo soporta.

Ejemplos:

import unix;
sub vcl_recv {
      # Devuelve "403 Forbidden" si el par conectado
      # no se está ejecutando como el usuario "trusteduser".
      if (unix.user() != "trusteduser") {
              return( synth(403) );
      }
      # Requiere que el par conectado se ejecute en el grupo
      # "trustedgroup".
      if (unix.group() != "trustedgroup") {
              return( synth(403) );
      }
      # Requiere que el par conectado se ejecute bajo un ID numérico de
      # usuario específico.
      if (unix.uid() != 4711) {
              return( synth(403) );
      }
      # Requiere que el par conectado se ejecute bajo un ID numérico de
      # grupo.
      if (unix.gid() != 815) {
              return( synth(403) );
      }
}

La obtención de las credenciales del par es posible en una plataforma que soporte uno de los siguientes:

  • getpeereid(3) (como FreeBSD y otros sistemas derivados de BSD)
  • la opción de socket SO_PEERCRED para getsockopt(2) (Linux)
  • getpeerucred(3C) (SunOS y descendientes)

En SunOS y similares, el conjunto de privilegios PRIV_PROC_INFO se añade al proceso hijo de Varnish mientras se carga el VMOD, ver setppriv(2).

En la mayoría de las plataformas, el valor devuelto es el usuario efectivo o el grupo que era válido cuando el proceso par inició la conexión.

STRING user()

Devuelve el nombre de usuario del propietario del proceso par.

Restringido a: client, backend.

STRING group()

Devuelve el nombre del grupo del propietario del proceso par.

Restringido a: client, backend.

INT uid()

Devuelve el ID de usuario numérico del propietario del proceso par.

Restringido a: client, backend.

INT gid()

Devuelve el ID de grupo numérico del propietario del proceso par.

Restringido a: client, backend.

ERRORES

Todas las funciones de este VMOD están sujetas a las siguientes restricciones:

  • Ninguna de ellas puede ser llamada en vcl_init{} o vcl_fini{}. Si alguna es llamada en vcl_init{}, entonces el programa VCL fallará al cargarse, con un mensaje de error del VMOD.
  • Si se llama en una plataforma no soportada, entonces se invoca un fallo de VCL. Se escribe un mensaje de error en el registro (con la etiqueta VCL_Error) y, para todas las subrutinas VCL excepto vcl_synth{}, el control se dirige inmediatamente a vcl_synth{}, con el estado de la respuesta establecido a 503 y la cadena de razón establecida a "VCL failed".

    Si el fallo ocurre durante vcl_synth{}, entonces vcl_synth{} se aborta y se envía la línea de respuesta "503 VCL failed".

  • Si el oyente actual no es un socket de dominio Unix, o si el intento de leer las credenciales falla, entonces se escribe un mensaje de VCL_Error en el registro. Las funciones STRING (unix.user() y unix.group()) devuelven NULL, mientras que las funciones INT (unix.uid() y unix.gid()) devuelven -1.
