VIS(1) Manual de Comandos Generales VIS(1)

NOMBRE

vis — un editor de texto altamente eficiente

SINOPSIS

vis [-v] [+comando] [--] [archivos ...]

DESCRIPCIÓN

vis es un editor de texto orientado a pantalla altamente eficiente que combina las fortalezas de vi(m) y sam. Esta página del manual está destinada a usuarios que ya están familiarizados con vi/sam. Cualquier otra persona debería casi con seguridad leer un buen tutorial sobre uno de los editores antes de esta página del manual. Las siguientes opciones están disponibles:

-v
Imprime información de la versión y sale.
+comando
Ejecuta comando después de cargar el archivo.
--
Denota el final de las opciones. Los argumentos posteriores se manejarán como nombres de archivo.

El archivo especial - instruye a vis para leer desde la entrada estándar, en cuyo caso :wq escribirá en la salida estándar, permitiendo así su uso como filtro interactivo.

Si la entrada estándar se redirige y se consume toda la entrada, vis abrirá /dev/tty para recopilar comandos adicionales. El fallo al hacerlo resultará en la terminación del programa.

Selecciones

vis utiliza selecciones como primitivas de edición centrales. Una selección es un rango no vacío y dirigido con dos puntos finales llamados cursor y ancla. Una selección puede estar anclada, en cuyo caso el ancla permanece fija mientras solo se ajusta la posición del cursor. Para selecciones no ancladas, ambos puntos finales se actualizan. Una selección singleton abarca un carácter en el que residen tanto el cursor como el ancla. Siempre existe una selección primaria que permanece visible (es decir, los cambios en su posición ajustarán la vista).

Modos

vis emplea el mismo enfoque de edición modal que vi. Admite un modo ‘normal’, ‘pendiente de operador’, ‘inserción’, ‘reemplazo’ y ‘visual’ (en sus variantes de línea y carácter). Los modos visual de bloque y ex deliberadamente no se implementan; en su lugar, vis tiene soporte incorporado para múltiples selecciones y una variante interactiva del lenguaje de comandos basado en expresiones regulares estructurales de sam.

En el modo normal, todas las selecciones no están ancladas y se reducen a un solo carácter.

Deshacer/Rehacer

vis utiliza un árbol de deshacer para realizar un seguimiento de las revisiones de texto. Los comandos u (deshacer) y ⟨C-r⟩ (rehacer) se pueden usar para recorrer el árbol a lo largo de la rama principal. g+ y g- recorren el historial en orden cronológico. Los comandos :earlier y :later proporcionan medios para restaurar el texto a un estado arbitrario.

Marcas

Una marca asocia un nombre simbólico a un conjunto de selecciones. Una selección almacenada se vuelve inválida cuando sus límites delimitadores cambian en el búfer subyacente. Si dichos cambios se deshacen más tarde, la marca vuelve a ser válida. m establece una marca, M la restaura. Por ejemplo, 'am establece la marca a mientras que 'aM la restaura. El uso de m o M sin especificar una marca utiliza la marca predeterminada.

Las marcas disponibles son:

''
marca predeterminada
'^
selecciones activas al salir del modo visual
'a–'z
marcas de propósito general

No se admiten marcas entre archivos. Las marcas no se conservan entre sesiones de edición.

Lista de saltos

Existe una lista de saltos local por ventana, de tamaño fijo, que almacena marcas (es decir, conjuntos de selecciones).

g<
saltar hacia atrás
g>
saltar hacia adelante
gs
guardar las selecciones activas actuales

Registros

Los registros son listas de texto con nombre. Las ranuras de registro no inicializadas por defecto son la cadena vacía. Los registros disponibles son:

""
registro predeterminado
"a–"z
registros de propósito general
"A–"Z
añadir al registro de propósito general correspondiente
"*, "+
integración del portapapeles del sistema mediante el script de shell vis-clipboard(1)
"0
registro de copia, rango copiado más recientemente
"1–"9
 
"&
coincidencias de subexpresión del comando x o y más reciente
"/
registro de búsqueda, patrón de búsqueda utilizado más recientemente
":
registro de comando, comando ejecutado más recientemente
"_
registro del agujero negro (/dev/null), el contenido ignorado siempre está vacío
"#
número de selección (solo lectura)

Si no se especifica ningún registro explícito, se utiliza el registro predeterminado.

Macros

Los registros de propósito general "a–"z se pueden usar para grabar macros. Utilice uno de "A–"Z para añadir a una macro existente. q inicia una grabación, @ la reproduce. @@ se refiere a la macro grabada más recientemente. @: repite el último comando :. @/ es equivalente a n en modo normal. Estas operaciones siempre utilizan la primera ranura de registro.

Manejo de codificación, tabulaciones y saltos de línea

vis siempre asume que el archivo de entrada está codificado en UTF-8 con finales de línea \n. Si desea editar archivos con codificaciones heredadas o finales de línea no Unix, use iconv(1) y dos2unix(1) para convertirlos según sea necesario. ⟨Tab⟩ opcionalmente puede expandirse a un número configurable de espacios (ver OPCIONES DE CONFIGURACIÓN).

MOUSE SUPPORT

The mouse is currently not used at all.

SAM COMMANDS

vis supports an interactive variant of the structural regular expression based command language introduced by sam(1).

Regular expressions

vis currently defers regular expression matching to the underlying C library. It uses what POSIX refers to as "Extended Regular Expressions" as described in regex(7). The anchors ^ and $ match the beginning / end of the range they are applied to. Additionally \n and \t may be used to refer to newlines and tabs, respectively. The . atom matches any character except newline. The empty regular expression stands for the last complete expression encountered.

Addresses

An address identifies a substring (or range) in a file. In the following "character n" means the null string after the n-th character in the file, with 1 the first character in the file. "Line n" means the n-th match, starting at the beginning of the file, of the regular expression ".*\n?".

All windows always have at least one current substring which is the default address. In sam this is referred to as dot. In vis multiple "dots" (or selections) can exist at the same time.

Simple addresses

#n
The empty string after character n; #0 is the beginning of the file.
n
Line n.
/regexp/
 
?regexp?
The substring that matches the regular expression, found by looking towards the end (/) or beginning (?) of the file. The search does not wrap around when hitting the end (start) of the file.
0
The string before the first full line. This is not necessarily the null string; see + and - below.
$
The null string at the end of the file.
.
Dot, the current range.
'm
The mark m in the file.

Compound addresses

In the following, a1 and a2 are addresses.

a1+a2
The address a2 evaluated starting at the end of a1.
a1-a2
The address a2 evaluated looking the reverse direction starting at the beginning of a1.
a1,a2
The substring from the beginning of a1 to the end of a2. If a1 is missing, 0 is substituted. If a2 is missing, $ is substituted.
a1;a2
Like a1,a2 but with a2 evaluated at the end of, and range set to, a1.

The operators + and - are high precedence, while , and ; are low precedence.

In both + and - forms, if a2 is a line or character address with a missing number, the number defaults to 1. If a1 is missing, . is substituted. If both a1 and a2 are present and distinguishable, + may be elided. a2 may be a regular expression; if it is delimited by ? characters, the effect of the + or - is reversed. The % sign is an alias for , and hence 0,$. It is an error for a compound address to represent a malformed substring.

Commands

In the following, text demarcated by slashes represents text delimited by any printable ASCII character except alphanumerics. Any number of trailing delimiters may be elided, with multiple elisions then representing null strings, but the first delimiter must always be present. In any delimited text, newline may not appear literally; \n and \t may be typed for newline and tab; \/ quotes the delimiter, here /. An ampersand & and \n, where n is a digit (1–9) are replaced by the corresponding register. Backslash is otherwise interpreted literally.

Most commands may be prefixed with an address to indicate their range of operation. If a command takes an address and none is supplied, a default address is used. In normal mode this equates to the character the selection is currently over. If only one selection exists x and y default to the whole file 0,$. In normal mode the write commands w and wq always apply to the whole file. Commands are executed once for every selection. In visual mode the commands are applied to every selection as if an implicit x command, matching the existing selections, was present.

In the description, "range" is used to represent whatever address is supplied.

Many commands create new selections as a side effect when issued from a visual mode. If so, it is always to the "result" of the change: the new text for an insertion, the empty string for a deletion, the command output of a filter etc. If after a successful command execution no selections remain, the editor will switch to normal mode, otherwise it remains in visual mode. This allows interactive refinements of ranges.

Text commands

a[count]/text/
Insert the text count times into the file after the range.

May also be written as

a
lines
of
text
.
c or i
Same as a, but c replaces the text, while i inserts before the range.
d
Delete the text in range.

Display commands

p
Create a new selection for the range.

I/O commands

e[!] [file name]
Replace the file by the contents of the named external file. If no file name is given, reload file from disk.
r file name
Replace the text in the range by the contents of the named external file.
w[!] [file name]
Write the range (default 0,$) to the named external file.
wq[!] [file name]
Same as w, but close file afterwards.

If the file name argument is absent from any of these, the current file name is used. e always sets the file name, w will do so if the file has no name. Forcing the e command with ! will discard any unsaved changes. Forcing w will overwrite the file on disk even if it has been externally modified since loading it. Write commands with a non-default addresses and no file name are destructive and need always to be forced.

< shell command

> shell command
Sends the range to the standard input of shell command, and replaces the range by the standard output. For the purpose of this command the range is taken to be the whole file.

Mapeos de teclas en tiempo de ejecución

vis soporta mapeos de teclas globales y locales de ventana que siempre se evalúan recursivamente.

:map[!] modo lhs rhs
agrega un mapeo de teclas global
:map-window[!] modo lhs rhs
agrega un mapeo de teclas local de ventana
:unmap modo lhs
elimina un mapeo de teclas global
:unmap-window modo lhs
elimina un mapeo de teclas local de ventana

En lo anterior, modo se refiere a uno de ‘normal’, ‘insert’, ‘replace’, ‘visual’, ‘visual-line’ o ‘operator-pending’; lhs se refiere a la tecla a mapear y rhs es una acción de tecla o alias. Un mapeo existente puede ser sobrescrito forzando el comando de mapeo especificando !.

Debido a que los mapeos de teclas son siempre recursivos, hacer algo como:

:map! normal j 2j

no funcionará porque entraría en un bucle infinito. En su lugar, vis utiliza pseudo-teclas referidas como acciones de tecla que pueden ser usadas para invocar un conjunto de funciones disponibles del editor. :help lista todas las combinaciones de teclas activas actualmente, así como todas las teclas simbólicas disponibles.

Mapeos Específicos del Diseño del Teclado

Para facilitar el uso de diseños de teclado no latinos, vis permite mapear teclas específicas de la configuración regional a sus equivalentes latinos mediante el comando

:langmap teclas_locales teclas_latinas

Por ejemplo, lo siguiente mapea las teclas de movimiento en el diseño ruso:

:langmap ролд hjkl

Si las secuencias de teclas no tienen la misma longitud, se descartará el resto de la secuencia más larga.

Los mapeos definidos entran en vigor en todos los modos que no sean de entrada, es decir, en todas partes excepto en modo de inserción y reemplazo.

Deshacer/Rehacer

:earlier [contador]
revertir a un estado de texto anterior
:later [contador]
revertir a un estado de texto más reciente

Si se sufija al contador d (días), h (horas), m (minutos) o s (segundos) se interpreta como un desplazamiento desde la hora actual del sistema y se restaura el estado de texto disponible más cercano.

AJUSTAR OPCIONES

Hay un pequeño número de opciones que pueden ser establecidas (o desestablecidas) para cambiar el comportamiento del editor usando el comando :set. Esta sección describe las opciones, sus abreviaturas y sus valores por defecto. Las opciones booleanas pueden ser conmutadas añadiendo ! al nombre de la opción.

En cada entrada a continuación, la primera parte de la línea de etiqueta es el nombre completo de la opción, seguido de cualquier abreviatura equivalente. La parte entre corchetes es el valor por defecto de la opción.

shell [“/bin/sh”]
Shell de usuario a usar para comandos externos, anula SHELL y el campo shell de la base de datos de contraseñas /etc/passwd
escdelay [50]
Milisegundos a esperar antes de decidir si una secuencia de escape debe ser tratada como una tecla ⟨Escape⟩.
tabwidth, tw [8]
Ancho de visualización de una tabulación y número de espacios a usar si expandtab está habilitado.
autoindent, ai [off]
Indentación automática de nuevas líneas copiando el espacio en blanco de la línea anterior.
expandtab, et [off]
Si ⟨Tab⟩ debe ser expandido a tabwidth espacios.
number, nu [off]
Muestra números de línea absolutos.
relativenumbers, rnu [off]
Muestra números de línea relativos.
cursorline, cul [off]
Resalta la línea donde reside el cursor principal.
colorcolumn, cc [0]
Resalta una columna fija.
horizon [32768]
Cuántos bytes hacia atrás mirará el lexer para sincronizar el análisis.
theme [“default-16” o “default-256”]
Tema de color a usar, nombre sin extensión de archivo. Cargado desde un subdirectorio themes/ de las rutas listadas en la sección ARCHIVOS.
syntax [auto]
Léxico de resaltado de sintaxis a usar, nombre sin extensión de archivo.
showtabs [off]
Si mostrar un símbolo de reemplazo en lugar de tabulaciones.
shownewlines [off]
Si mostrar un símbolo de reemplazo en lugar de nuevas líneas.
showspaces [off]
Si mostrar un símbolo de reemplazo en lugar de celdas en blanco.
showeof [on]
Si mostrar un símbolo de reemplazo para líneas después del final del archivo.
savemethod [auto]
Cómo se debe guardar el archivo actual, atomic que usa rename(2) para reemplazar atómicamente el archivo, inplace que trunca el archivo y luego lo reescribe, o auto que intenta lo primero antes de recurrir a lo segundo. El método de renombrar falla para enlaces simbólicos, enlaces duros, en caso de permisos de directorio insuficientes o cuando el propietario del archivo, el grupo, el ACL POSIX o las etiquetas SELinux no pueden ser restaurados.
loadmethod [auto]
Cómo se deben cargar los archivos existentes, read que copia el contenido del archivo a un búfer independiente en memoria, mmap que mapea en memoria el archivo desde el disco y usa las capacidades del SO como capa de caché, o auto que intenta lo primero para archivos menores de 8Mb y lo segundo para los más grandes. ADVERTENCIA: modificar un archivo mapeado en memoria in situ causará pérdida de datos.
layout [“v” o “h”]
Si usar diseño vertical o horizontal.
ignorecase, ic [off]
Si ignorar mayúsculas y minúsculas al buscar.
wrapcolumn, wc [0]
Ajustar líneas al mínimo del ancho de ventana y wrapcolumn.
breakat, brk [“”]
Caracteres que pueden causar un salto de línea.

vis(1) — vis manual

NAME

vis — a vim-like text editor

SYNOPSIS

vis [− | −b | −c | −e | −l | −m | −p | −r | −s | −t | −w | −n | −v | −C file…] [−c cmd] [−d dir] [−f file] [−g file] [−l file] [−p file] [−r file] [−t file] [−w file] [−n file] [−v file] [file…]

DESCRIPTION

Vis is a modal text editor and a clone of sam(1) inspired by vi(1). It provides the standard vi key bindings and commands, and aims for small size and simplicity. Vis makes use of Lua for configuration and scripting.

The editor supports multiple windows, register, macro, completion, tag stack, diff mode, and plugins.

SAM COMMANDS

Vis implements a subset of the commands from the sam(1) text editor. These commands are primarily used for text manipulation and selection.

  • L: list all files in the current directory.
  • E: edit file.
  • F: finish editing the current file.
  • W: write file.
  • Q: quit editor.
  • d: delete selection.
  • w: write selection to file.
  • x: execute command.
  • i: insert text.
  • a: append text.
  • c: change text.
  • p: print selection.
  • r: read file.
  • t: copy selection.
  • m: move selection.
  • /: search.
  • ?: reverse search.
  • .: repeat last search.
  • n: next match.
  • N: previous match.
  • ^: go to start of file.
  • $: go to end of file.
  • 0: go to start of line.
  • %: matching parenthesis.
  • #: comment.
  • @: execute command in background.
  • &: execute command and replace selection.
  • ;: execute command.
  • |: pipe selection to command.

VI(M) KEY BINDINGS

Vis supports most of the standard vi(1) key bindings for navigation, editing, and command execution. These include:

  • hjkl: movement
  • wWhH: word movement
  • bB: word movement backwards
  • 0^: start of line
  • $: end of line
  • gg: start of file
  • G: end of file
  • f F t T: find character
  • ; ,: repeat find
  • dd: delete line
  • yy: yank line
  • p P: put line
  • u U: undo
  • i I a A o O: insert mode
  • v V: visual mode
  • C-n C-p: scroll up/down
  • C-f C-b: page up/down
  • C-a C-e: beginning/end of line

VI(M) COMMANDS

Vis supports the standard vi(1) Ex commands:

  • :w: write file
  • :q: quit
  • :wq: write and quit
  • :q!: quit without saving
  • :e: edit file
  • :d: delete line
  • :s: substitute
  • :g: global command
  • :/: search forward
  • :?: search backward
  • :@: execute macro

SET OPTIONS

Vis supports a subset of vi(1) set options:

  • number: display line numbers
  • relativenumber: display relative line numbers
  • tabstop: number of spaces for a tab
  • shiftwidth: number of spaces for indentation
  • expandtab: use spaces instead of tabs
  • autoindent: auto indent
  • smartindent: smart indent
  • wrap: enable/disable line wrapping
  • syntax: enable/disable syntax highlighting

COMMAND and SEARCH PROMPT

The command and search prompt as opened by :, /, or ? is implemented as a single line height window, displaying a regular file whose editing starts in insert mode. ⟨Escape⟩ switches to normal mode, a second ⟨Escape⟩ cancels the prompt. ⟨Up⟩ enlarges the window, giving access to the command history. ⟨C-v⟩ ⟨Enter⟩ inserts a literal new line thus enabling multiline commands. ⟨Enter⟩ executes the visual selection if present, or else everything in the region spawned by the selection position and the delimiting prompt symbols at the start of adjacent lines.

CONFIGURATION

vis uses Lua for configuration and scripting purposes. During startup visrc.lua (see the FILES section) is sourced which can be used to set personal configuration options. As an example the following will enable the display of line numbers:

vis:command('set number')

ENVIRONMENT

VIS_PATH
The default path to use to load Lua support files.
HOME
The home directory used for the cd command if no argument is given.
TERM
The terminal type to use to initialize the curses interface, defaults to xterm if unset.
SHELL
The command shell to use for I/O related commands like !, >, < and |.
XDG_CONFIG_HOME
The configuration directory to use, defaults to $HOME/.config if unset.

ASYNCHRONOUS EVENTS

SIGSTOP
Suspend editor.
SIGCONT
Resume editor.
SIGBUS
An mmap(2) ed file got truncated, unsaved file contents will be lost.
SIGHUP
 
SIGTERM
Restore initial terminal state. Unsaved file contents will be lost.
SIGINT
When an interrupt occurs while an external command is being run it is terminated.
SIGWINCH
The screen is resized.

FILES

Upon startup vis will source the first visrc.lua configuration file found from these locations. All actively used paths can be listed at runtime using the :help command.

  • $VIS_PATH
  • The location of the vis binary (on systems where /proc/self/exe is available).
  • $XDG_CONFIG_HOME/vis where XDG_CONFIG_HOME refers to $HOME/.config if unset.
  • /etc/vis for a system-wide configuration provided by administrator.
  • /usr/local/share/vis or /usr/share/vis depending on the build configuration.

    When creating a new visrc.lua be sure to copy the structure from here.

EXIT STATUS

The vis utility exits 0 on success, and >0 if an error occurs.

EXAMPLES

Use vis as an interactive filter.

$ { echo Pick your number; seq 1 10; } | vis - > choice

Use the vis-open(1) based file browser to list all C language source files:

:e *.c

Spawn background process and pipe range to its standard input:

:> { plumber <&3 3<&- & } 3<&0 1>&- 2>&-
