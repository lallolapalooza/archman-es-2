VDE_L3(1) Manual de Comandos Generales VDE_L3(1)

NOMBRE

vde_l3 - Conmutador de 'Capa 3' de Ethernet Distribuida Virtual.

SINOPSIS

vde_l3 -v enchufe_vde:direccion_ip/mascara_red [-v...] [-r red_destino/mascara_red:puerta_enlace] [-G gw_predeterminado] [-M socket_gestion]

DESCRIPCIÓN

Un vde_l3 se conecta a uno o más vde_switches, realizando reenvío de IP entre sus interfaces virtuales. Se crea una nueva interfaz al inicio por cada opción -v dada en la línea de comandos. Las rutas estáticas a redes de destino se pueden definir usando la opción -r.

vde_l3 -v /var/run/s1.ctl:192.168.0.1/24

se conecta al socket vde en /var/run/s1.ctl con su interfaz virtual ve0, con la dirección 192.168.0.1 y máscara 255.255.255.0.

vde_l3 \

-v /var/run/s1.ctl:192.168.0.1/24 \

-v /var/run/s2.ctl:10.0.0.254/255.255.0.0

se conecta a los dos sockets vde, con sus interfaces virtuales ve0 y ve1, teniendo direcciones 192.168.1.0 y 10.0.0.254 respectivamente. Los hosts en cada red pueden especificar el vde_l3 como su puerta de enlace para alcanzar la otra.

OPCIONES

-v enchufe_vde:direccion_ip/mascara_red
Crea una interfaz de red virtual en la caja vde_l3, con dirección direccion_ip y máscara mascara_red. Tenga en cuenta que la máscara de red puede especificarse tanto en el modo clásico A.B.C.D, como simplemente dando el número de bits iniciales (por ejemplo, /17 para 255.255.128.0). Se pueden definir tantas interfaces como se desee.
-r red_destino/mascara_red:puerta_enlace
Especifica una ruta estática a través de puerta_enlace para alcanzar hosts en red_destino con máscara de red mascara_red. Se pueden definir tantas rutas como se deseen.
-G gw_predeterminado
Especifica una puerta de enlace predeterminada, que se utilizará siempre que no se defina una ruta estática para un host de destino.
-M socket_gestion
El socket Unix donde se pueden consultar y cambiar los parámetros (direcciones de interfaz, rutas, etc.) en tiempo de ejecución. unixterm(1) puede ser utilizado como terminal remota para wirefilter.
