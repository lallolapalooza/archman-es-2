VAPIGEN(1) Comandos de usuario VAPIGEN(1)

NOMBRE

vapigen - generar una API de Vala

SINOPSIS

vapigen FUENTE PKGBASE [OPCIÓN]... [ARCHIVO]...

DESCRIPCIÓN

vapigen es una utilidad que genera archivos de API de Vala (VAPI) a partir de archivos GI, que pueden generarse utilizando la utilidad vala-gen-introspect(1).

Uso:

vapigen [OPCIÓN?] ARCHIVO... - Generador de API de Vala

Opciones de ayuda:

-h, --help
Mostrar opciones de ayuda

Opciones de aplicación:

--vapidir=DIRECTORIO...
Buscar bindings de paquetes en DIRECTORIO
--girdir=DIRECTORIO...
Buscar bindings de GIR en DIRECTORIO
--metadatadir=DIRECTORIO...
Buscar archivos .metadata de GIR en DIRECTORIO
--nostdpkg
No incluir paquetes estándar
--pkg=PAQUETE...
Incluir binding para PAQUETE
--library=NOMBRE
Nombre de la librería
-d, --directory=DIRECTORIO
Directorio de salida
--disable-warnings
Desactivar advertencias
--version
Mostrar número de versión
-q, --quiet
No imprimir mensajes en la consola

AUTORES

EJEMPLOS

Después de la compilación, el siguiente comando genera un GI para pango: vala-gen-introspect pango packages/pango

Esto se puede convertir a una API de Vala de la siguiente manera:
vapigen --pkg cairo --vapidir . --library pango packages/pango/pango.gi
