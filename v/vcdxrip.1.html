VCDXRIP(1) Comandos de usuario VCDXRIP(1)

NOMBRE

vcdxrip - página del manual para vcdxrip 2.0.0

SINOPSIS

vcdxrip [OPCIÓN...]

DESCRIPCIÓN

-o, --output-file=ARCHIVO
especificar archivo xml para la salida (por defecto: 'videocd.xml')
-b, --bin-file[=ARCHIVO]
establecer archivo de imagen como fuente (por defecto: 'videocd.bin')
-c, --cue-file[=ARCHIVO]
establecer archivo de imagen de CD-ROM "cue" como fuente
-N, --nrg-file[=ARCHIVO]
establecer archivo de imagen de CD-ROM Nero como fuente
--toc-file[=ARCHIVO]
establecer archivo de imagen de CD-ROM "toc" como fuente
-C, --cdrom-device[=DISPOSITIVO]
establecer dispositivo CDROM como fuente
--sector-2336
usar modo de sector de 2336 bytes para el archivo de imagen
-i, --input[=ARCHIVO]
establecer fuente y determinar si es imagen "bin" o dispositivo
--no-ext-psd
ignorar /EXT/PSD_X.VCD
--no-command-comment
No incluir el nombre del comando como comentario
--norip
solo extraer estructura XML
--nofiles
no extraer archivos
--nosequences
no extraer secuencias
--nosegments
no extraer elementos de reproducción de segmentos
-p, --progress
mostrar progreso
-t, --track=INT
extraer solo esta pista
-T, --notrack=INT
no extraer esta pista
--filename-encoding=CADENA
usar la codificación de conjunto de caracteres dada para los nombres de archivo en lugar de UTF8
-v, --verbose
ser detallado
-q, --quiet
mostrar solo mensajes críticos
--gui
habilitar modo GUI
-V, --version
mostrar información de versión y derechos de autor y salir

Opciones de ayuda:

-?, --help
Mostrar este mensaje de ayuda
--usage
Mostrar mensaje de uso breve
