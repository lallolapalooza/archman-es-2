VCD-INFO(1) Comandos de usuario VCD-INFO(1)

NOMBRE

vcd-info - página del manual para vcd-info 2.0.0

SINOPSIS

vcd-info [OPCIÓN...]

DESCRIPCIÓN

-a, --modo-acceso=ACCESO
establecer el modo de acceso del CD-ROM (IOCTL, READ_10, READ_CD)
-b, --archivo-bin[=ARCHIVO]
establecer el archivo de imagen de disco CD-ROM "bin" como fuente
-c, --archivo-cue[=ARCHIVO]
establecer el archivo de imagen de disco CD-ROM "cue" como fuente
-N, --archivo-nrg[=ARCHIVO]
establecer el archivo de imagen de disco CD-ROM de Nero como fuente
--archivo-toc[=ARCHIVO]
establecer el archivo de imagen de disco CD-ROM "toc" como fuente
-i, --entrada[=ARCHIVO]
establecer la fuente y determinar si es una imagen "bin" o un dispositivo
--sin-ext-psd
ignorar la información en /EXT/PSD_X.VCD
--sector-2336
usar el modo de sector de 2336 bytes para el archivo de imagen
-C, --dispositivo-cdrom[=DISPOSITIVO]
establecer el dispositivo CD-ROM como fuente
-d, --depuracion=INT
establecer la salida de depuración en NIVEL
-t, --conciso
igual que --sin-encabezado --sin-banner --sin-delimitador
-B, --sin-banner
no mostrar el encabezado del banner del programa ni la cadena de la versión RCS
-D, --sin-delimitador
no mostrar líneas delimitadoras alrededor de varias secciones de salida
-H, --sin-encabezado
no mostrar los títulos de las secciones
--mostrar-entradas=CADENA
mostrar una entrada específica de la sección ENTRIES
-E, --mostrar-todas-entradas
mostrar la sección ENTRIES
-F, --mostrar-sistema-archivos
mostrar información del sistema de archivos
--mostrar-info=CADENA
mostrar una entrada específica de la sección INFO
-I, --mostrar-toda-info
mostrar la sección INFO
-L, --mostrar-lot
mostrar la sección LOT
-p, --mostrar-psd
mostrar la(s) sección(es) PSD
-P, --mostrar-todos-pvd
mostrar la(s) sección(es) PVD
--mostrar-pvd=CADENA
mostrar una entrada específica de la sección Descriptor de Volumen Primario (PVD)
-s, --mostrar-datos-escaneo
mostrar datos de escaneo
-X, --mostrar-busqueda
mostrar datos de búsqueda
-S, --mostrar-fuente
mostrar el nombre del archivo de imagen de origen y el tamaño
-T, --mostrar-pistas
mostrar pistas
-f, --mostrar-formato
mostrar el formato VCD (VCD 1.1, VCD 2.0, SVCD, ...)
-q, --silencioso
mostrar solo mensajes críticos
-V, --version
mostrar información de versión y derechos de autor y salir

Opciones de ayuda:

-?, --help
Mostrar este mensaje de ayuda
--uso
Mostrar un breve mensaje de uso
