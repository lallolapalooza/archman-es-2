VFS_READAHEAD(8) Herramientas de administración del sistema VFS_READAHEAD(8)

NOMBRE

vfs_readahead - precargar la caché de búfer del kernel

SINOPSIS

objetos vfs = readahead

DESCRIPCIÓN

Este módulo VFS es parte del conjunto de herramientas samba(7).

Este módulo VFS vfs_readahead detecta solicitudes de lectura en múltiplos de un desplazamiento dado (0x80000 por defecto) y luego le indica al kernel, ya sea a través de la llamada al sistema readahead (en Linux) o la llamada al sistema posix_fadvise, que pre-cargue estos datos en la caché de búfer.

Este módulo es útil para clientes de Windows Vista que leen datos utilizando el programa Windows Explorer, el cual realiza asincrónicamente múltiples solicitudes de lectura de archivos en los límites de desplazamiento de 0x80000 bytes.

El múltiplo de desplazamiento utilizado se proporciona mediante la opción readahead:offset, que por defecto es 0x80000.

El tamaño de las operaciones de lectura de disco realizadas por vfs_readahead se determina mediante la opción readahead:length. Por defecto, esto se establece en el mismo valor que la opción readahead:offset y, si no se establece explícitamente, utilizará el valor actual de readahead:offset.

Este módulo se puede apilar.

OPCIONES

readahead:offset = BYTES

El múltiplo de desplazamiento que provoca que se solicite readahead a la caché de búfer del kernel.

readahead:length = BYTES

El número de bytes solicitados para leer en la caché de búfer del kernel en cada llamada de readahead.

Los siguientes sufijos pueden aplicarse a BYTES:

•K - BYTES es un número de kilobytes
•M - BYTES es un número de megabytes
•G - BYTES es un número de gigabytes

EJEMPLOS

[hipotético]
objetos vfs = readahead
