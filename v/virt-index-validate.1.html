NOMBRE

virt-index-validate - Valida el archivo de índice de virt-builder

SINOPSIS

virt-index-validate índice

DESCRIPCIÓN

virt-builder(1) utiliza un archivo de índice para almacenar metadatos sobre las plantillas que sabe cómo usar. Este archivo de índice tiene un formato específico que virt-index-validate sabe cómo validar.

Tenga en cuenta que virt-index-validate puede validar tanto el archivo de índice firmado como el no firmado (es decir, índice o índice.asc). Solo puede validar un archivo local, no una URL.

OPCIONES

--compat-1.24.0
Comprueba la compatibilidad con virt-builder 1.24.0. (Usar esta opción implica --compat-1.24.1, por lo que no es necesario usar ambas).

En particular:

  • Esta versión de virt-builder no podía manejar "[...]" (corchetes) en los nombres de campo (por ejemplo, "checksum[sha512]=...").
  • Requería firmas separadas ("sig=...").
--compat-1.24.1
Comprueba la compatibilidad con virt-builder ≥ 1.24.1.

En particular:

  • Esta versión de virt-builder no podía manejar "." (punto) en los nombres de campo o "," (coma) en los nombres de subcampo.
  • No podía manejar comentarios en el archivo.
--help
Muestra la ayuda.
-V
--version
Muestra el número de versión y sale.

ESTADO DE SALIDA

Este programa devuelve 0 si el archivo de índice se valida correctamente, o un valor distinto de cero si hubo un error.
