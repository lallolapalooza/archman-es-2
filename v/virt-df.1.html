NOMBRE

virt-df - Muestra el espacio libre en sistemas de archivos virtuales

SINOPSIS

Todos los invitados:

virt-df [--opciones]

Invitado único:

virt-df [--opciones] -d nombre_dominio
virt-df [--opciones] -a disco.img [-a disco.img ...]

Estilo antiguo:

virt-df [--opciones] nombre_dominio
virt-df [--opciones] disco.img [disco.img ...]

DESCRIPCIÓN

"virt-df" es una herramienta de línea de comandos para mostrar el espacio libre en los sistemas de archivos de máquinas virtuales. A diferencia de otras herramientas, no solo muestra el tamaño del disco asignado a una máquina virtual, sino que puede mirar dentro de las imágenes de disco para ver cuánto espacio se está utilizando realmente.

Si se usa sin argumentos -a o -d, "virt-df" consulta a libvirt para obtener una lista de todos los invitados activos e inactivos, y realiza una operación tipo "df" en cada uno por turno, imprimiendo los resultados.

Si se especifican argumentos -a o -d, "virt-df" realiza una operación tipo "df" en el dominio de libvirt con el nombre especificado, o en la(s) imagen(es) de disco listada(s) en la línea de comandos (que deben pertenecer a una sola VM). En este modo (con argumentos), "virt-df" solo funcionará para un solo invitado. Si desea ejecutar en varios invitados, debe invocar "virt-df" varias veces.

Utilice la opción --csv para obtener un formato que pueda ser fácilmente analizado por otros programas. Otras opciones son similares al comando estándar df(1).

EJEMPLOS

Mostrar el uso del disco para un invitado de libvirt llamado "F14x64". Hacer la salida legible para humanos:

# virt-df -d F14x64 -h
Filesystem                       Size     Used  Available  Use%
F14x64:/dev/sda1                 484M      66M       393M   14%
F14x64:/dev/vg_f13x64/lv_root    7.4G     3.4G       4.0G   46%

Mostrar el uso del disco para un archivo de imagen de disco llamado test.img:

$ virt-df -a test1.img
Filesystem                  1K-blocks     Used  Available  Use%
test1.img:/dev/sda1             99099     1551      92432    2%

Si un solo invitado tiene varios discos, use la opción -a repetidamente. Se muestra un signo más ("+") por cada disco adicional. Nota: No haga esto con discos de invitados no relacionados.

$ virt-df -a Win7x32TwoDisks-a -a Win7x32TwoDisks-b 
Filesystem                   1K-blocks    Used  Available  Use%
Win7x32TwoDisks-a+:/dev/sda1    102396   24712      77684   25%
Win7x32TwoDisks-a+:/dev/sda2  12478460 7403416    5075044   60%
Win7x32TwoDisks-a+:/dev/sdb1    521212   55728     465484   11%

OPCIONES

--help
Muestra ayuda breve.
-a ARCHIVO
--add ARCHIVO
Agrega "ARCHIVO" que debe ser una imagen de disco de una máquina virtual. Si la máquina virtual tiene múltiples dispositivos de bloque, debe proporcionar todos ellos con opciones -a separadas.

El formato de la imagen de disco se detecta automáticamente. Para anular esto y forzar un formato particular, use la opción --format=...

-a URI
--add URI
Agrega un almacenamiento remoto. Ver "AGREGANDO ALMACENAMIENTO REMOTO" en guestfish(1).
--blocksize=512
--blocksize=4096
--blocksize
Este parámetro establece el tamaño del sector de la imagen de disco. Afecta a todos los discos subsiguientes añadidos explícitamente después de este parámetro. Usar --blocksize sin argumento cambia el tamaño del sector del disco al valor predeterminado, que suele ser de 512 bytes. Ver también "guestfs_add_drive_opts" en guestfs(3).
-c URI
--connect URI
Si se utiliza libvirt, conéctese a la URI dada. Si se omite, nos conectaremos al hipervisor libvirt predeterminado.

Si especifica dispositivos de bloque de invitado directamente (-a), entonces no se usa libvirt en absoluto.

--csv
Escribe los resultados en formato CSV (valores separados por comas). Este formato se puede importar fácilmente a bases de datos y hojas de cálculo, pero lea "NOTA SOBRE EL FORMATO CSV" a continuación.
-d invitado
--domain invitado
Agrega todos los discos del invitado de libvirt con nombre. Se pueden usar UUIDs de dominio en lugar de nombres.
--format=raw|qcow2|..
--format
El valor predeterminado para la opción -a es la detección automática del formato de la imagen de disco. El uso de esto fuerza el formato del disco para las opciones -a que siguen en la línea de comandos. Usar --format sin argumento revierte a la detección automática para las opciones -a subsiguientes.

Por ejemplo:

virt-df --format=raw -a disk.img

fuerza el formato raw (sin detección automática) para disk.img.

virt-df --format=raw -a disk.img --format -a another.img

fuerza el formato raw (sin detección automática) para disk.img y revierte a la detección automática para another.img.

Si tiene imágenes de disco de invitado en formato raw no confiables, debe usar esta opción para especificar el formato del disco. Esto evita un posible problema de seguridad con invitados maliciosos (CVE-2010-3851).

-h
--human-readable
Imprime los tamaños en formato legible para humanos.

No se le permite usar -h y --csv al mismo tiempo.

-i
--inodes
Imprime inodos en lugar de bloques.
--one-per-guest
Desde libguestfs 1.22, este es el valor predeterminado. Esta opción no hace nada y se deja aquí para compatibilidad con scripts más antiguos.
-P nr_threads
Desde libguestfs 1.22, virt-df es multihilo y examina los invitados en paralelo. Por defecto, el número de hilos a utilizar se elige en función de la cantidad de memoria libre disponible en el momento en que se inicia virt-df. Puede forzar a virt-df a usar como máximo "nr_threads" utilizando la opción -P.

Tenga en cuenta que -P 0 significa autodetectar, y -P 1 significa usar un solo hilo.

--uuid
Imprime UUIDs en lugar de nombres. Esto es útil para seguir un invitado incluso cuando se migra o renombra, o cuando dos invitados tienen el mismo nombre.

Tenga en cuenta que solo los dominios que obtenemos de libvirt vienen con UUIDs. Para imágenes de disco, todavía imprimimos el nombre de la imagen de disco incluso cuando se especifica esta opción.

-v
--verbose
Habilita mensajes verbosos para depuración.
-V
--version
Muestra el número de versión y sale.
-x
Habilita el rastreo de llamadas a la API de libguestfs.

STATVFS NUMBERS

The virt-df command prints the same filesystem statistics as the statvfs(3) system call. You can get the same information directly, either from the host (using libguestfs) or inside the guest:

From the host
Run this command: 
guestfish --ro -d GuestName -i statvfs /

(change / to see stats for other filesystems).

From inside the guest
Run this command: 
python -c 'import os; s = os.statvfs ("/"); print s'

(change / to see stats for other filesystems).

NOTE ABOUT CSV FORMAT

Comma-separated values (CSV) is a deceptive format. It seems like it should be easy to parse, but it is definitely not easy to parse.

Myth: Just split fields at commas. Reality: This does not work reliably. This example has two columns:

"foo,bar",baz

Myth: Read the file one line at a time. Reality: This does not work reliably. This example has one row:

"foo
bar",baz

For shell scripts, use "csvtool" (https://github.com/Chris00/ocaml-csv also packaged in major Linux distributions).

For other languages, use a CSV processing library (eg. "Text::CSV" for Perl or Python’s built-in csv library).

Most spreadsheets and databases can import CSV directly.

EXIT STATUS
