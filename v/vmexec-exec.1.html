NOMBRE

vmexec-exec - Ejecuta un comando en una máquina virtual existente

SINOPSIS

vmexec exec [-e|--env] [-s|--ssh-timeout] [-i|--interactive] [-t|--tty] [-h|--help] <VMID> [ARGS]

DESCRIPCIÓN

Ejecuta un comando en una máquina virtual existente

OPCIONES

-e, --env=ENV
Establece variables de entorno para el proceso dentro de la máquina virtual

Se puede proporcionar varias veces.

Formato esperado: CLAVE=VALOR

-s, --ssh-timeout=SSH_TIMEOUT [por defecto: 20]
Tiempo de espera de la conexión SSH

Intenta conectar al servidor SSH de la máquina virtual durante este tiempo (en segundos).

-i, --interactive=INTERACTIVE [por defecto: auto]
Hace que STDIN esté disponible para el proceso de la máquina virtual

Si es 'auto', intentará leer desde stdin si está disponible, y no hará nada cuando stdin no esté disponible. Si es 'always', intentará leer desde stdin y abortará cuando stdin no esté disponible.

[posibles valores: always, never, auto]

-t, --tty=TTY [por defecto: auto]
Asigna un pseudo-TTY para la máquina virtual

Si es 'auto', se habilitará en caso de que vmexec se ejecute desde una terminal interactiva.

[posibles valores: always, never, auto]

-h, --help
Imprime la ayuda (ver un resumen con '-h')
<VMID>
Identificador de una máquina virtual en ejecución
[ARGS]
Argumentos para ejecutar en la máquina virtual
