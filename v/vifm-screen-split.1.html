VIFM-SCREEN-SPLIT(1) Manual de Comandos Generales VIFM-SCREEN-SPLIT(1)

NOMBRE

vifm-screen-split - un script auxiliar de vifm para ejecutar en divisiones de GNU screen

SINOPSIS

Solo se llama automáticamente desde dentro de vifm

vifm-screen-split

DESCRIPCIÓN

Un script auxiliar para vifm, no para uso independiente.

Imprime el mensaje "Presiona cualquier tecla para cerrar esta región..." y espera para cerrar la división.

VER TAMBIÉN

screen(1), vifm(1)
