NOMBRE

vnstat.conf - archivo de configuración de vnStat

SINOPSIS

/etc/vnstat.conf

DESCRIPCIÓN

vnstat(1), vnstati(1) y vnstatd(8) utilizan todos el mismo archivo de configuración para los ajustes relacionados con la configuración. Algunas de las configuraciones son comunes para los tres programas. El archivo consta de pares clave-argumento, uno por línea. Las líneas vacías y las líneas que comienzan con '#' o ';' se interpretan como comentarios y no se procesan. Los argumentos pueden ir opcionalmente entre comillas dobles (") para representar argumentos que contienen espacios. Los argumentos pueden rellenarse con espacios o tabuladores. Se utilizará un valor predeterminado codificado si una clave no se encuentra en el archivo de configuración o si el valor configurado no se puede analizar o está fuera del rango de valores admitidos.

El archivo de configuración se divide en tres secciones según el uso de cada palabra clave. La primera sección contiene palabras clave que se consideran comunes para todos los comandos, la segunda sección es para palabras clave relacionadas con el demonio y la última sección es para la salida de imágenes.

PALABRAS CLAVE COMUNES

DatabaseDir
Especifica el directorio donde se almacenará la base de datos. Se debe proporcionar una ruta completa y no se requiere una barra inclinada (/) al principio.
DayFormat, MonthFormat, TopFormat
Formato de la fecha en las salidas disponibles. Utiliza el mismo formato que date(1). (Solo vnstat y vnstati)
DefaultDecimals
Número de decimales a utilizar en las salidas. Rango de valores: 0..2 (Solo vnstat y vnstati)
EstimateBarVisible
Muestra una representación visual de la estimación de tráfico si OutputStyle se ha configurado con un valor de 1 o 2 para hacer visible la columna de la barra. 1 = habilitado, 0 = deshabilitado. (Solo vnstat, véase EstimateStyle para vnstati)
EstimateText
Reemplaza el texto predeterminado "estimated" en la línea de estimación con un texto personalizado. Limitado a 9 caracteres. (Solo vnstat y vnstati)
EstimateVisible
Muestra una línea con la estimación de tráfico para el período de tiempo seleccionado o una alerta como la última línea de la salida en los modos de salida que lo admiten. Deshabilitar la visibilidad de la estimación también deshabilita las condiciones de estimación en --alert. 1 = habilitado, 0 = deshabilitado. (Solo vnstat y vnstati)
HourlyDecimals
Número de decimales a utilizar en la salida del gráfico horario. Rango de valores: 0..2 (Solo vnstat)
HourlySectionStyle
Selecciona qué tipo de separador se utiliza para separar las secciones numéricas de la salida del gráfico horario. 0 = ninguno, 1 = '|', 2 = '][', 3 = '[ ]'. (Solo vnstat)
Interface
Interfaz predeterminada utilizada cuando no se especifica ninguna otra interfaz en la línea de comandos. Dejar vacío para selección automática. La selección automática priorizará la interfaz con más tráfico para las salidas que realizan consultas a la base de datos. Las consultas que no utilizan la base de datos primero comprobarán si la base de datos está disponible y seleccionarán la interfaz con más tráfico entre las que son visibles actualmente en el sistema. Si no se puede leer ninguna base de datos, se utilizará la primera interfaz disponible. (Solo vnstat y vnstati)
InterfaceMatchMethod
Método para hacer coincidir la interfaz dada para una consulta con una interfaz en la base de datos.

El método 0 requiere que el nombre de la interfaz sea una coincidencia exacta sensible a mayúsculas y minúsculas. El método 1 amplía el método anterior permitiendo una coincidencia exacta sensible a mayúsculas y minúsculas del alias de la interfaz. El método 2 amplía el método anterior permitiendo una coincidencia exacta insensible a mayúsculas y minúsculas del alias de la interfaz. El método 3 amplía el método anterior permitiendo una coincidencia insensible a mayúsculas y minúsculas del principio del alias de la interfaz.

Los métodos se evaluarán en el orden descrito anteriormente, lo que dará como resultado que las coincidencias exactas de la interfaz siempre tengan prioridad. Si algún método de coincidencia de alias de interfaz da como resultado múltiples coincidencias, se utilizará la interfaz con el mayor tráfico total. (Solo vnstat y vnstati)

InterfaceOrder
Orden de las interfaces en salidas con múltiples interfaces. 0 = alfabético por nombre, 1 = alfabético por alias. Si se selecciona 1 y múltiples interfaces no tienen alias, se utilizará el nombre de la interfaz para definir el orden. (Solo vnstat)
List5Mins, ListHours, ListDays, ListMonths, ListYears, ListTop
Número de entradas a mostrar en las salidas de lista a menos que se reemplace desde la línea de comandos. Establecer en 0 para mostrar todas las entradas disponibles en la base de datos. (vnstat y vnstati)
LiveSpinner
Muestra una animación giratoria al principio de la línea de salida -l / --live. 1 = habilitado, 0 = deshabilitado. (Solo vnstat)
Locale
Configuración regional a utilizar para las impresiones. Esto reemplaza la variable de entorno LC_ALL. Establecer en "-" o dejar vacío para utilizar el valor predeterminado del sistema. (Solo vnstat y vnstati)
OutputStyle
Modifica el contenido y el estilo de las salidas de texto. 0 = salida mínima y estrecha para terminales con ancho limitado, 1 = salida normal con columna de barra visible, 2 = igual que 1 excepto que la velocidad es visible en la salida resumen, 3 = la columna de velocidad es visible en todas las salidas donde sea compatible. (Solo vnstat y vnstati)
QueryMode
Modo de consulta predeterminado cuando no se proporcionan parámetros. 0 = resumen, 1 = días, 2 = meses, 3 = top, 4 = resumen individual, 5 = corto, 6 = años, 7 = gráfico de horas, 8 = xml, 9 = una línea, 10 = json, 11 = horas y 12 = 5 minutos. (Solo vnstat)
RateUnit
Selecciona qué unidad se utiliza cuando la velocidad de tráfico es visible. 0 = bytes, 1 = bits. (Solo vnstat y vnstati)
RateUnitMode
Selecciona el prefijo utilizado cuando la velocidad de tráfico se muestra en bits por segundo. Los prefijos binarios IEC se calculan con potencias de 1024. Los prefijos decimales SI se calculan con potencias de 1000. 0 = prefijos binarios IEC (Kibit/s...), 1 = prefijos decimales SI (kbit/s...). (Solo vnstat y vnstati)
RXCharacter, TXCharacter
Carácter utilizado para representar la parte porcentual del tráfico recibido y transmitido en las salidas del modo lista. (Solo vnstat)
RXHourCharacter, TXHourCharacter
Carácter utilizado para representar la parte porcentual del tráfico recibido y transmitido en la salida del gráfico horario. (Solo vnstat)
Sampletime
Define cuántos segundos muestreará tráfico la opción -tr. Rango de valores: 2..600 (Solo vnstat)
UnitMode
Selecciona cómo se prefijan las unidades. Los prefijos binarios IEC y JEDEC se calculan con potencias de 1024. Los prefijos decimales SI se calculan con potencias de 1000. 0 = prefijos estándar IEC (B/KiB/MiB/GiB...), 1 = prefijos binarios estilo antiguo (JEDEC) (B/KB/MB/GB...), 2 = prefijos decimales SI (B/kB/MB/GB...) (Solo vnstat y vnstati)

PALABRAS CLAVE RELACIONADAS CON EL DEMONIO

5MinuteHours
Duración de retención de datos para las entradas de resolución de 5 minutos. La configuración define cuántas horas pasadas se almacenarán las entradas. Establecer en -1 para entradas ilimitadas o en 0 para deshabilitar el demonio

64bitInterfaceCounters
Seleccione el manejo de los contadores de interfaz. Establezca en 1 para definir que todas las interfaces usan contadores de 64 bits en el lado del kernel y 0 para definir contadores de 32 bits. Establezca en -1 para usar la lógica de estilo antiguo utilizada en versiones anteriores donde los valores de los contadores dentro de 32 bits se asumen como de 32 bits y cualquier cosa más grande se asume como un contador de 64 bits. Esto puede producir resultados falsos si un contador de 64 bits se reinicia dentro de los 32 bits. Establezca en -2 para utilizar la detección automática basada en las estructuras de datos del kernel disponibles.
AlwaysAddNewInterfaces
Habilite o deshabilite la creación automática de nuevas entradas de base de datos para interfaces que no están actualmente en la base de datos, incluso si el archivo de base de datos ya existe cuando se inicia el demonio. Las nuevas entradas de base de datos también se crearán para nuevas interfaces vistas mientras el demonio está en ejecución. Las interfaces pseudo lo, lo0 y sit0 siempre se excluyen de ser agregadas. 1 = habilitado, 0 = deshabilitado.
BandwidthDetection
Intente detectar automáticamente el valor de MaxBandwidth para cada interfaz monitoreada. Principalmente solo las interfaces Ethernet admiten esta función. MaxBandwidth se utilizará como valor de respaldo si la detección falla. Cualquier configuración específica de interfaz MaxBW deshabilitará la detección para la interfaz especificada. En Linux, la detección está deshabilitada para interfaces tun debido a que el kernel de Linux siempre informa 10 Mbit independientemente de la interfaz real utilizada. 1 = habilitado, 0 = deshabilitado.
BandwidthDetectionInterval
Con qué frecuencia en minutos se realiza la detección específica de interfaz de MaxBandwidth para detectar posibles cambios cuando BandwidthDetection está habilitado. Se puede deshabilitar estableciéndolo en 0. Rango de valores: 0..30
BootVariation
Tiempo en segundos que puede variar el tiempo de arranque informado por el kernel del sistema entre actualizaciones. Rango de valores: 0..300
CheckDiskSpace
Habilite o deshabilite la verificación de disponibilidad de al menos algo de espacio libre en disco antes de escribir en la base de datos. 1 = habilitado, 0 = deshabilitado.
CreateDirs
Habilite o deshabilite la creación de directorios cuando una ruta configurada no existe. Esto incluye los directorios de DatabaseDir, LogFile y PidFile. El directorio de LogFile solo se creará cuando UseLogging se haya establecido en 1. El directorio de PidFile solo se creará si el demonio se inicia como un proceso en segundo plano. El proceso del demonio intentará crear el directorio utilizando los permisos del usuario con el que se inició el proceso.
DaemonGroup
Especifique el grupo al que debe cambiar el proceso del demonio durante el inicio. El grupo puede ser el nombre del grupo o un ID numérico de grupo. Deje vacío para deshabilitar el cambio de grupo. Esta opción solo se puede utilizar cuando el proceso se inicia como root.
DaemonUser
Especifique el usuario al que debe cambiar el proceso del demonio durante el inicio. El usuario puede ser el nombre de inicio de sesión del usuario o un ID de usuario numérico. Deje vacío para deshabilitar el cambio de usuario. Esta opción solo se puede utilizar cuando el proceso se inicia como root.
DailyDays
Duración de retención de datos para las entradas de resolución de un día. La configuración define cuántos días pasados se almacenarán las entradas. Establezca en -1 para entradas ilimitadas o en 0 para deshabilitar la recopilación de datos de esta resolución.
DatabaseSynchronous
Cambie la configuración del indicador "synchronous" de SQLite, que controla cuánta atención se presta para garantizar que las escrituras en disco se hayan completado completamente al escribir datos en la base de datos antes de continuar con otras acciones. Valores más altos toman medidas adicionales para garantizar la seguridad de los datos a costa de un rendimiento más lento. Un valor de 0 dará como resultado que todo el manejo sea dejado al propio sistema de archivos. Establezca en -1 para seleccionar el valor predeterminado según el modo de base de datos controlado por la configuración de DatabaseWriteAheadLogging. Consulte la documentación de SQLite para obtener más detalles sobre los valores de 1 a 3. Rango de valores: -1..3
DatabaseWriteAheadLogging
Habilite o deshabilite el modo de registro anticipado de escritura (Write-Ahead Logging) de SQLite para la base de datos. Consulte la documentación de SQLite para obtener más detalles y tenga en cuenta que el soporte para operaciones de solo lectura no está disponible en versiones anteriores de SQLite. 1 = habilitado, 0 = deshabilitado.
HourlyDays
Duración de retención de datos para las entradas de resolución de una hora. La configuración define cuántos días pasados se almacenarán las entradas. Establezca en -1 para entradas ilimitadas o en 0 para deshabilitar la recopilación de datos de esta resolución.
LogFile
Especifique la ruta y el nombre del archivo de registro que se utilizará si UseLogging se establece en 1.
MaxBandwidth
Ancho de banda máximo para todas las interfaces. Si el tráfico específico de la interfaz excede el valor dado, se asume que los datos no son válidos y se rechazan. Establezca en 0 para deshabilitar la función. Rango de valores: 0..50000
MaxBW
Igual que MaxBandwidth, pero se puede utilizar para establecer límites individuales para interfaces seleccionadas. El nombre de la interfaz se especifica directamente después de la palabra clave MaxBW sin espacios. Por ejemplo, MaxBWeth0 para eth0 y MaxBWppp0 para ppp0. BandwidthDetection está deshabilitado a nivel de interfaz específica para cada configuración de MaxBW. Rango de valores: 0..50000
MonthlyMonths
Duración de retención de datos para las entradas de resolución de un mes. La configuración define cuántos meses pasados se almacenarán las entradas. Establezca en -1 para entradas ilimitadas o en 0 para deshabilitar la recopilación de datos de esta resolución.
MonthRotate
Día del mes en el que se espera que cambien los meses. Generalmente se establece en 1, pero puede establecerse en valores alternativos, por ejemplo, para rastrear el tráfico facturado mensualmente donde el período de facturación no comienza el primer día. Por ejemplo, si se establece en 7, los días de febrero hasta el 6 inclusive contarán para enero. Cambiar esta opción no provocará que los datos existentes se recalculen. Rango de valores: 1..28
MonthRotateAffectsYears
Habilite o deshabilite que MonthRotate afecte también a los datos anuales. Aplicable solo cuando MonthRotate tiene un valor mayor que uno. 1 = habilitado, 0 = deshabilitado.
OfflineSaveInterval
Con qué frecuencia en minutos se guardan los datos de interfaz en caché en un archivo cuando todas las interfaces monitoreadas están desconectadas. Rango de valores: SaveInterval..60
PidFile
Especifique la ruta y el nombre del archivo PID que se utilizará. El archivo solo se crea si el demonio se inicia como un proceso en segundo plano.
PollInterval
Con qué frecuencia en segundos se comprueban las interfaces para detectar cambios de estado. Rango de valores: 2..60
RescanDatabaseOnSave
Descubra automáticamente las interfaces añadidas de la base de datos y comience a monitorear. El escaneo se realiza cada SaveInterval o OfflineSaveInterval minutos según el estado de actividad actual. 1 = habilitado, 0 = deshabilitado.
SaveInterval
Con qué frecuencia en minutos se guardan los datos de interfaz en caché en un archivo. Rango de valores: ( UpdateInterval / 60 )..60
SaveOnStatusChange
Habilite o deshabilite el guardado adicional en archivo de los datos de interfaz en caché cuando cambia la disponibilidad de una interfaz, es decir, cuando una interfaz se desconecta o se conecta. 1 = habilitado, 0 = deshabilitado.
TimeSyncWait
Cuántos minutos esperar durante el inicio del demonio para que el reloj del sistema se sincronice si la actualización más reciente de la base de datos parece estar en el futuro. Esto puede ser necesario en sistemas sin reloj en tiempo real (RTC) que requieren algo de tiempo después del arranque para consultar y establecer la hora correcta. 0 = espera deshabilitada. Rango de valores: 0..60
TopDayEntries
Duración de retención de datos para las entradas de los mejores días. La configuración define cuántas de las entradas de los mejores días pasados se almacenarán. Establezca en -1 para entradas ilimitadas o en 0 para deshabilitar la recopilación de datos de esta resolución.
TrafficlessEntries
Cree entradas de base de datos incluso cuando no hay tráfico durante el período de tiempo de la entrada. 1 = habilitado, 0 = deshabilitado.
UpdateFileOwner
Habilite o deshabilite la actualización de la propiedad del archivo durante el inicio del proceso del demonio. Durante el inicio del demonio, solo se modificarán los archivos de base de datos, registro y PID si la función de cambio de usuario o grupo ( DaemonUser o DaemonGroup ) está habilitada y los archivos no coinciden con el usuario o grupo solicitado. Durante la creación manual de la base de datos, esta opción hará que la propiedad del archivo se herede del directorio de la base de datos si el directorio ya existe. Esta opción solo tiene efecto cuando el proceso se inicia como root o a través de sudo.
UpdateInterval
Con qué frecuencia en segundos se actualizan los datos de la interfaz. Rango de valores: PollInterval..300
UseLogging
Habilite o deshabilite el registro. Esta opción se ignora cuando el demonio se inicia con -n, --nodaemon, lo que resulta en que toda la salida de registro se muestre en la terminal que utiliza el proceso del demonio. 0 = deshabilitado, 1 = archivo de registro y 2 = syslog.

PALABRAS CLAVE RELACIONADAS CON EL DEMONIO

UseUTC
Activar o desactivar el uso de UTC como zona horaria en la base de datos para todas las entradas. Cuando está activado, todas las entradas añadidas a la base de datos utilizarán UTC independientemente de la zona horaria del sistema configurada. Cuando está desactivado, se utilizará la zona horaria del sistema configurada. Cambiar esta configuración no modificará los datos ya existentes. 1 = activado, 0 = desactivado.
VacuumOnHUPSignal
Activar o desactivar la ejecución del comando SQLite VACUUM después de que el demonio haya recibido una señal HUP. Cuando está activado, el archivo de la base de datos se reconstruye y se empaqueta en una cantidad mínima de espacio en disco. La diferencia de tamaño puede ser notable, especialmente si los períodos de retención de datos se han reducido o si se han eliminado interfaces monitorizadas previamente de la base de datos. 1 = activado, 0 = desactivado.
VacuumOnStartup
Activar o desactivar la ejecución del comando SQLite VACUUM durante el inicio del demonio. Cuando está activado, el archivo de la base de datos se reconstruye y se empaqueta en una cantidad mínima de espacio en disco. La diferencia de tamaño puede ser notable especialmente si los períodos de retención de datos se han reducido o si se han eliminado interfaces monitorizadas previamente de la base de datos. 1 = activado, 0 = desactivado.
YearlyYears
Período de retención de datos para las entradas de resolución de un año. La configuración define durante cuántos años anteriores se almacenarán las entradas. Establécelo en -1 para entradas ilimitadas o en 0 para deshabilitar la recopilación de datos de esta resolución.

PALABRAS CLAVE RELACIONADAS CON LA SALIDA DE IMAGEN

5MinuteGraphResultCount
Número de períodos de 5 minutos que se incluirán en el gráfico de resolución de 5 minutos. El valor afecta al ancho del gráfico. Rango de valores: 288..2000
5MinuteGraphHeight
Altura del gráfico de resolución de 5 minutos en píxeles. Rango de valores: 150..2000
BarColumnShowsRate
La columna de barras representa la tasa de tráfico en las salidas de lista cuando está activada. Requiere también que OutputStyle se haya configurado para mostrar la columna de tasa de tráfico utilizando el valor 3. Habilitar esta opción provocará automáticamente que EstimateStyle tenga el valor 0. Visualmente, esta opción solo afecta al texto de la leyenda de colores y a la última línea de la lista si esa línea representa el período de tiempo en curso. 1 = activado, 0 = desactivado.
CBackground
Color de fondo.
CEdge
Color del borde, si es visible.
CHeader
Color de fondo del encabezado.
CHeaderTitle
Color del texto del título del encabezado.
CHeaderDate
Color del texto de la fecha del encabezado.
CLine
Color de la línea.
CLineL
Versión más clara del color de la línea. Establécelo en '-' para utilizar un valor calculado basado en CLine.
CPercentileLine
Color de la línea del percentil 95. Solo se utiliza en el gráfico del percentil 95.
CRx
Color para los datos recibidos.
CRxD
Versión más oscura del color de los datos recibidos. Establécelo en '-' para utilizar un valor calculado basado en CRx.
CText
Color del texto común.
CTotal
Color para los datos totales, suma de datos recibidos y transmitidos. Solo se utiliza en el gráfico del percentil 95.
CTx
Color para los datos transmitidos.
CTxD
Versión más oscura del color de los datos transmitidos. Establécelo en '-' para utilizar un valor calculado basado en CTx.
EstimateStyle
Mostrar una representación visual de la estimación del tráfico. 0 = no mostrado, 1 = continuación de la barra existente, 2 = barra separada.
HeaderFormat
Formato de la fecha en el encabezado. Utiliza el mismo formato que date(1).
HourlyGraphMode
Seleccionar el modo de salida del gráfico horario. 0 = ventana deslizante de 24 horas, 1 = el gráfico comienza desde la medianoche.
HourlyRate
Mostrar horas con tasa en lugar de cantidad transferida. 1 = activado, 0 = desactivado.
ImageScale
Escalar la salida al porcentaje dado. Rango de valores: 50..500
LargeFonts
Aumentar el tamaño de las fuentes utilizadas. 1 = activado, 0 = desactivado.
LineSpacingAdjustment
Ajustar el espaciado de las líneas en las salidas de formato de lista. Los valores positivos aumentan el espacio entre líneas, mientras que los valores negativos lo reducen. Rango de valores: -5..10
SummaryGraph
Seleccionar qué estilo de gráfico se muestra junto a los datos de resumen en las salidas de resumen horizontal y vertical. 0 = horas, 1 = 5 minutos.
SummaryRate
Mostrar la tasa en la salida de resumen si está disponible. 1 = activado, 0 = desactivado.
TransparentBg
Establecer el color de fondo como transparente. 1 = activado, 0 = desactivado.

ARCHIVOS

/etc/vnstat.conf
Archivo de configuración que se utilizará a menos que exista $HOME/.vnstatrc o se proporcione un valor alternativo como parámetro de línea de comandos.

RESTRICCIONES

El uso de formatos de fecha largos puede provocar desalineación en las columnas mostradas si la longitud de la fecha excede la asignación de tamaño fijo.
