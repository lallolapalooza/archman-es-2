NOMBRE

verdandi - Mezcla imágenes usando el algoritmo watershed.

USO

verdandi [opciones] imágenes

OPCIONES

--salida=ARCHIVO Establece el nombre del archivo para el archivo de salida.
--compresion=valor Compresión de los archivos de salida.
Para salida jpeg: 1-100

Para salida tiff: PACKBITS, DEFLATE, LZW

-w, --wrap Borde envolvente de 360 grados.
--costura=fusion_dura|fusion Selecciona el modo de fusión para la costura
-h, --help Muestra esta ayuda.
