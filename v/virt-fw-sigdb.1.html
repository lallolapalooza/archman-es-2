VIRT-FW-SIGDB(1) Comandos de usuario VIRT-FW-SIGDB(1)

NOMBRE

virt-fw-sigdb - página del manual para virt-fw-sigdb 25.10

DESCRIPCIÓN

La utilidad virt-fw-sigdb puede crear, modificar e imprimir bases de datos de firmas EFI. Este es el formato utilizado por el firmware UEFI para almacenar listas de certificados y hashes authenticode para binarios en variables EFI como 'PK', 'KEK', 'db' y 'dbx'.

Normalmente, las bases de datos de firmas están incrustadas en almacenes de variables EFI, por lo que para la mayoría de los casos de uso, probablemente debería consultar la utilidad virt-fw-vars(1) en su lugar.

La excepción a esta regla es la lista de certificados CA raíz para conexiones TLS que se pueden pasar desde el host a través de qemu a OVMF utilizando el archivo fw_cfg etc/edk2/https/cacerts.

uso: virt-fw-sigdb [-h] [-i ARCHIVO] [-o ARCHIVO] [--add-cert GUID ARCHIVO]

[--add-hash GUID HASH] [-p]

opciones:

-h, --help
mostrar este mensaje de ayuda y salir
-i, --input ARCHIVO
leer la base de datos de firmas EFI ARCHIVO
-o, --output ARCHIVO
escribir la base de datos de firmas EFI ARCHIVO.
--add-cert GUID ARCHIVO
añadir certificado x509 a la base de datos de firmas, cargado en formato pem desde ARCHIVO y con GUID de propietario, se puede especificar múltiples veces
--add-hash GUID HASH
añadir hash sha256 a la base de datos de firmas, con GUID de propietario, se puede especificar múltiples veces
-p, --print
imprimir la base de datos de firmas

EJEMPLOS

Imprimir la base de datos de CA raíz del sistema
virt-fw-sigdb --print \
--input /etc/pki/ca-trust/extracted/edk2/cacerts.bin
