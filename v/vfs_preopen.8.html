VFS_PREOPEN(8) Herramientas de administración del sistema VFS_PREOPEN(8)

NOMBRE

vfs_preopen - Oculta las latencias de lectura para aplicaciones que leen archivos numerados.

SINOPSIS

objetos vfs = preopen

DESCRIPCIÓN

Este módulo VFS forma parte del conjunto de utilidades de samba(7).

Este módulo ayuda a las aplicaciones que desean leer archivos numerados en secuencia con requisitos de latencia muy estrictos. Un área donde esto ocurre es en las aplicaciones de transmisión de video que desean leer un archivo por fotograma.

Cuando utiliza este módulo, se inician varios procesos auxiliares que abren especulativamente archivos y leen un número de bytes para preparar la caché del sistema de archivos, de modo que más tarde, cuando llegue la solicitud de la aplicación real, no sea necesario acceder al disco.

Este módulo se puede apilar.

OPCIONES

preopen:posix-basic-regex = BOOL (por defecto: no)

preopen:posix-basic-regex = sí cambia el significado de la opción preopen:names. Se describen más detalles allí.

preopen:names = /patrón1/patrón2/

preopen:names especifica el (los) patrón(es) de nombre de archivo que activarán a los auxiliares de preopen para realizar su trabajo. Suponemos que los archivos se numeran incrementalmente. Por lo tanto, si sus nombres de archivo están numerados FRAME00000.frm, FRAME00001.frm y así sucesivamente, los listaría como preopen:names=/FRAME*.frm/. El algoritmo predeterminado utiliza los primeros (al menos 3) dígitos que encuentra para calcular el nombre de los siguientes fotogramas.

preopen:posix-basic-regex = sí cambia el significado de la opción preopen:names. Significa que se utilizan cadenas de 'Expresión Regular Básica POSIX' como patrones. La clave es que cada patrón requiere exactamente una 'subexpresión' que comience con '\(' y termine con '\)' para especificar la posición de los dígitos que representan los números de fotograma incrementales. Dado un nombre de archivo como Movie7599Frame0v1234.txt, Movie7599Frame1v1234.txt, Movie7599Frame2v1234.txt hasta Movie7599Frame9v1234.txt puede usar preopen:names = /.*Frame\([0-9]\).*\.txt/ para coincidir con un solo dígito, esto podría no ser un ejemplo del mundo real, pero muestra la flexibilidad que es posible aquí.

preopen:num_bytes = BYTES

Especifica el número de bytes que los auxiliares deben leer especulativamente, por defecto es 1.

preopen:helpers = NUM-PROCS

Número de procesos auxiliares creados, por defecto es 1.

preopen:queuelen = NUM-FILES

Número de archivos que deben abrirse especulativamente. Por defecto son los 10 archivos subsiguientes.

preopen:nomatch_log_level = LOGLEVEL

Para depurar o auditar el uso de la lógica de preopen, puede usar esta opción para especificar a qué nivel de registro se registran los detalles sobre los nombres de archivo que no coinciden con ningún patrón de 'preopen:names'.

Por defecto es el nivel de registro 5. Consulte también smb.conf(5) en la sección 'nivel de registro' para el manejo especial de la clase de depuración 'preopen'.

preopen:match_log_level = LOGLEVEL

Para depurar o auditar el uso de la lógica de preopen, puede usar esta opción para especificar a qué nivel de registro se registran los detalles sobre los nombres de archivo que coinciden con un patrón de 'preopen:names'.

Consulte también 'preopen:founddigits_log_level' y 'preopen:push_log_level'.

Por defecto es el nivel de registro 5. Consulte también smb.conf(5) en la sección 'nivel de registro' para el manejo especial de la clase de depuración 'preopen'.

preopen:nodigits_log_level = LOGLEVEL

Para depurar o auditar problemas con la configuración de preopen, puede usar esta opción para especificar a qué nivel de registro se registran los detalles sobre los nombres de archivo que coinciden con un patrón de 'preopen:names', pero que al mismo tiempo no contienen los dígitos esperados. Esto es típicamente algo que el administrador quiere notar y ajustar la configuración para definir de manera más precisa dónde encontrar los dígitos en el nombre del archivo.

Por defecto es el nivel de registro 1. Consulte también smb.conf(5) en la sección 'nivel de registro' para el manejo especial de la clase de depuración 'preopen'.

preopen:founddigits_log_level = LOGLEVEL

Para depurar o auditar el uso de la lógica de preopen, puede usar esta opción para especificar a qué nivel de registro se registran los detalles sobre los nombres de archivo que coinciden con un patrón de 'preopen:names', y al mismo tiempo tienen dígitos esperados válidos. Esto significa que hay suficiente información disponible para poner en cola las preaperturas.

Por defecto es el nivel de registro 3. Consulte también smb.conf(5) en la sección 'nivel de registro' para el manejo especial de la clase de depuración 'preopen'.

preopen:reset_log_level = LOGLEVEL

Si un nombre de archivo coincidente pertenece a un patrón diferente de 'preopen:names', a un directorio padre diferente o difiere de manera significativa del último nombre de archivo que se encontró antes, el módulo necesita restablecer su estado interno de cola. Esto significa que no se enviarán más preaperturas a los procesos auxiliares que pertenezcan al estado de cola anterior. Para depurar o auditar tales reinicios de cola, puede usar esta opción para especificar a qué nivel de registro se registran los detalles.

Por defecto es el nivel de registro 5. Consulte también smb.conf(5) en la sección 'nivel de registro' para el manejo especial de la clase de depuración 'preopen'.

preopen:push_log_level = LOGLEVEL

Para depurar o auditar el uso de la lógica de preopen, puede usar esta opción para especificar a qué nivel de registro se registran los detalles sobre los nombres de archivo que se envían a los procesos auxiliares de preopen. Esto significa que pronto se preabrirán realmente.

Por defecto es el nivel de registro 3. Consulte también smb.conf(5) en la sección 'nivel de registro' para el manejo especial de la clase de depuración 'preopen'.

preopen:queue_log_level = LOGLEVEL

Para depurar detalles sobre el procesamiento de cola interno, puede usar esta opción para especificar a qué nivel de registro se registran los detalles.

Por defecto es el nivel de registro 10. Consulte también smb.conf(5) en la sección 'nivel de registro' para el manejo especial de la clase de depuración 'preopen'.
