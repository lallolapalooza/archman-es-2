VIRT-FW-DUMP(1) Comandos de usuario VIRT-FW-DUMP(1)

NOMBRE

virt-fw-dump - página del manual para virt-fw-dump 25.10

DESCRIPCIÓN

La utilidad virt-fw-dump imprime la estructura y el contenido de los volúmenes de firmware edk2 en la salida estándar.

uso: virt-fw-dump [-h] [-i ARCHIVO] [--all] [--volumes] [--modules]

[--ovmf-meta] [--volume-hashes]

Vuelca volúmenes de firmware EFI y almacenes de variables EFI.

opciones:

-h, --help
mostrar este mensaje de ayuda y salir
-i, --input ARCHIVO
volcar volumen de firmware ARCHIVO
--all
imprimir todo (por defecto)
--volumes
imprimir volúmenes de firmware
--modules
imprimir módulos incluidos
--ovmf-meta
decodificar metadatos de ovmf (en el vector de reinicio)
--volume-hashes
imprimir hashes de volúmenes

EJEMPLOS

virt-fw-dump --input /usr/share/edk2/ovmf/OVMF_CODE.fd
