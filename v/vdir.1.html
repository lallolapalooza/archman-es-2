VDIR(1) Comandos de Usuario VDIR(1)

NOMBRE

vdir - listar contenido del directorio

SINOPSIS

vdir [OPCIÓN]... [ARCHIVO]...

DESCRIPCIÓN

Lista información sobre los ARCHIVOS (el directorio actual por defecto). Ordena las entradas alfabéticamente si no se especifica ninguna de las opciones -cftuvSUX ni --sort.

Los argumentos obligatorios para las opciones largas también son obligatorios para las opciones cortas.

-a, --all
no ignorar las entradas que empiezan por .
-A, --almost-all
no listar las entradas implícitas . y ..
--author
con -l, imprime el autor de cada archivo
-b, --escape
imprime secuencias de escape estilo C para caracteres no imprimibles
--block-size=TAMAÑO
con -l, escala los tamaños por TAMAÑO al imprimirlos; por ejemplo, '--block-size=M'; ver formato TAMAÑO abajo
-B, --ignore-backups
no listar las entradas implícitas que terminan en ~
-c
con -lt: ordena por, y muestra, ctime (hora del último cambio de información de estado del archivo); con -l: muestra ctime y ordena por nombre; de lo contrario: ordena por ctime, los más recientes primero
-C
lista las entradas por columnas
--color[=CUÁNDO]
colorea la salida CUÁNDO; más información abajo
-d, --directory
lista los directorios en sí, no su contenido
-D, --dired
genera una salida diseñada para el modo dired de Emacs
-f
igual que -a -U
-F, --classify[=CUÁNDO]
añade un indicador (uno de */=>@|) a las entradas CUÁNDO
--file-type
igual, excepto que no se añade '* '
--format=PALABRA
across, horizontal (-x), comas (-m), largo (-l), una sola columna (-1), verboso (-l), vertical (-C)
--full-time
como -l --time-style=full-iso
-g
como -l, pero no lista el propietario
--group-directories-first
agrupa los directorios antes que los archivos
-G, --no-group
en un listado largo, no imprime los nombres de grupo
-h, --human-readable
con -l y -s, imprime tamaños como 1K 234M 2G etc.
--si
igual, pero usa potencias de 1000 en lugar de 1024
-H, --dereference-command-line
sigue los enlaces simbólicos listados en la línea de comandos
--dereference-command-line-symlink-to-dir
sigue cada enlace simbólico de la línea de comandos que apunta a un directorio
--hide=PATRÓN
no lista las entradas implícitas que coinciden con el PATRÓN de shell (anulado por -a o -A)
--hyperlink[=CUÁNDO]
enlaza los nombres de archivo CUÁNDO
--indicator-style=PALABRA
añade un indicador con el estilo PALABRA a los nombres de entrada: none (por defecto), slash (-p), file-type (--file-type), classify (-F)
-i, --inode
imprime el número de índice de cada archivo
-I, --ignore=PATRÓN
no lista las entradas implícitas que coinciden con el PATRÓN de shell
-k, --kibibytes
usa bloques de 1024 bytes por defecto para el uso del sistema de archivos; solo se usa con -s y totales por directorio
-l
usa un formato de listado largo
-L, --dereference
al mostrar información de archivo para un enlace simbólico, muestra información del archivo al que apunta el enlace en lugar del propio enlace
-m
rellena el ancho con una lista de entradas separadas por comas
-n, --numeric-uid-gid
como -l, pero lista los IDs numéricos de usuario y grupo
-N, --literal
imprime los nombres de entrada sin comillas
-o
como -l, pero no lista la información de grupo
-p, --indicator-style=slash
añade el indicador / a los directorios
-q, --hide-control-chars
imprime ? en lugar de caracteres no imprimibles
--show-control-chars
muestra los caracteres no imprimibles tal cual (por defecto, a menos que el programa sea 'ls' y la salida sea una terminal)
-Q, --quote-name
envuelve los nombres de entrada entre comillas dobles
--quoting-style=PALABRA
usa el estilo de comillas PALABRA para los nombres de entrada: literal, locale, shell, shell-always, shell-escape, shell-escape-always, c, escape (anula la variable de entorno QUOTING_STYLE)
-r, --reverse
invierte el orden al ordenar
-R, --recursive
lista los subdirectorios recursivamente
-s, --size
imprime el tamaño asignado de cada archivo, en bloques
-S
ordena por tamaño de archivo, el más grande primero
--sort=PALABRA
cambia el orden de 'nombre' por defecto a PALABRA: none (-U), size (-S), time (-t), version (-v), extension (-X), name, width
--time=PALABRA
selecciona qué marca de tiempo se usa para mostrar o ordenar; hora de acceso (-u): atime, access, use; hora de cambio de metadatos (-c): ctime, status; hora de modificación (por defecto): mtime, modification; hora de creación: birth, creation;
con -l, PALABRA determina qué hora se muestra; con --sort=time, ordena por PALABRA (los más recientes primero)
--time-style=ESTILO_HORA
formato de hora/fecha con -l; ver ESTILO_HORA abajo
-t
ordena por hora, los más recientes primero; ver --time
-T, --tabsize=COLUMNAS
>
establece las tabulaciones en cada COLS en lugar de 8
-u
con -lt: ordenar por, y mostrar, tiempo de acceso; con -l: mostrar tiempo de acceso y ordenar por nombre; de lo contrario: ordenar por tiempo de acceso, el más reciente primero
-U
no ordenar las entradas del directorio
-v
ordenación natural de números (de versión) dentro del texto
-w, --width=COLS
establece el ancho de salida a COLS. 0 significa sin límite
-x
lista las entradas por líneas en lugar de por columnas
-X
ordena alfabéticamente por la extensión de la entrada
-Z, --context
imprime cualquier contexto de seguridad de cada archivo
--zero
termina cada línea de salida con NUL, no con nueva línea
-1
lista un archivo por línea
--help
muestra esta ayuda y sale
--version
muestra información de la versión y sale

El argumento SIZE es un entero y una unidad opcional (ejemplo: 10K es 10*1024). Las unidades son K,M,G,T,P,E,Z,Y,R,Q (potencias de 1024) o KB,MB,... (potencias de 1000). También se pueden usar prefijos binarios: KiB=K, MiB=M, y así sucesivamente.

El argumento TIME_STYLE puede ser full-iso, long-iso, iso, locale, o +FORMAT. FORMAT se interpreta como en date(1). Si FORMAT es FORMAT1<nueva línea>FORMAT2, entonces FORMAT1 se aplica a archivos no recientes y FORMAT2 a archivos recientes. TIME_STYLE prefijado con 'posix-' solo tiene efecto fuera del locale POSIX. La variable de entorno TIME_STYLE también establece el estilo predeterminado a usar.

El argumento WHEN tiene por defecto 'always' y también puede ser 'auto' o 'never'.

El uso de color para distinguir tipos de archivo está deshabilitado tanto por defecto como con --color=never. Con --color=auto, ls emite códigos de color solo cuando la salida estándar está conectada a una terminal. La variable de entorno LS_COLORS puede cambiar la configuración. Usa el comando dircolors(1) para configurarla.

Estado de salida:

0
si OK,
1
si hay problemas menores (p. ej., no se puede acceder a un subdirectorio),
2
si hay problemas graves (p. ej., no se puede acceder al argumento de la línea de comandos).
