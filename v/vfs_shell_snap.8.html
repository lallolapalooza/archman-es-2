NOMBRE

vfs_shell_snap - Llamadas a scripts de shell para la creación y eliminación de instantáneas

SINOPSIS

objetos vfs = shell_snap

DESCRIPCIÓN

Este módulo VFS forma parte del conjunto de herramientas de samba(8).

El VFS vfs_shell_snap proporciona llamadas a scripts de shell para las operaciones de creación y eliminación de instantáneas emitidas por clientes remotos que utilizan el Protocolo Remoto VSS del Servidor de Archivos (FSRVP).

Las siguientes llamadas a shell pueden configurarse en smb.conf:

shell_snap:check path command

•Se llama cuando un cliente FSRVP desea verificar si un recurso compartido dado admite solicitudes de creación/eliminación de instantáneas.
•El comando se llama con un único argumento ruta_recurso_compartido.
•El comando debe devolver 0 si ruta_recurso_compartido es capaz de ser instantaneada.

shell_snap:create command

•Se llama cuando un cliente FSRVP desea crear una instantánea.
•El comando se llama con un único argumento ruta_recurso_compartido.
•El comando debe devolver un estado 0 si la instantánea se tomó correctamente.
•El comando debe mostrar la ruta de la instantánea recién creada en stdout.

shell_snap:delete command

•Se llama cuando un cliente FSRVP desea eliminar una instantánea.
•El comando se llama con los argumentos ruta_base_recurso_compartido y ruta_instantanea_recurso_compartido.
•El comando debe devolver un estado 0 si la instantánea se eliminó correctamente.
Todos los comandos se ejecutan como el usuario autenticado del cliente FSRVP.

Este módulo es apilable.

CONFIGURACIÓN

[recurso_compartido]
vfs objects = shell_snap
shell_snap:check path command = snap_check_path.sh
shell_snap:create command = snap_create.sh
shell_snap:delete command = snap_delete.sh

El servidor FSRVP de Samba debe configurarse en la sección [global]:

[global]
registry shares = yes
include = registry
