VERCMP(8) Manual de Pacman VERCMP(8)

NOMBRE

vercmp - utilidad de comparación de versiones

SINOPSIS

vercmp [-h] [--help] <version1> <version2>

DESCRIPCIÓN

vercmp se utiliza para determinar la relación entre dos números de versión dados. Produce valores como los siguientes:

•< 0 : si ver1 < ver2
•= 0 : si ver1 == ver2
•> 0 : si ver1 > ver2

La comparación de versiones funciona de la siguiente manera:

Alfanuméricos:
  1.0a < 1.0b < 1.0beta < 1.0p < 1.0pre < 1.0rc < 1.0 < 1.0.a < 1.0.1
Numéricos:
  1 < 1.0 < 1.1 < 1.1.1 < 1.2 < 2.0 < 3.0.0

Adicionalmente, las cadenas de versión pueden tener un valor de epoch definido que anulará cualquier comparación de versiones, a menos que los valores de epoch sean iguales. Esto se especifica en formato epoch:version-rel. Por ejemplo, 2:1.0-1 es siempre mayor que 1:3.6-1.

Tenga en cuenta que el pkgrel solo se compara si está disponible en ambas versiones dadas a esta herramienta. Por ejemplo, comparar 1.5-1 y 1.5 resultará en 0; comparar 1.5-1 y 1.5-2 resultará en < 0 como se espera. Esto es principalmente para soportar dependencias versionadas que no incluyen el pkgrel.

OPCIONES

-h, --help

Muestra un resumen de los códigos de retorno disponibles. Debe ser la primera opción especificada.

EJEMPLOS

$ vercmp 1 2
-1
$ vercmp 2 1
1
$ vercmp 2.0-1 1.7-6
1
$ vercmp 2.0 2.0-13
0
$ vercmp 4.34 1:001
-1
