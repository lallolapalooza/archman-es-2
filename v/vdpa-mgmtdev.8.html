NOMBRE

vdpa-mgmtdev - vista del dispositivo de gestión vdpa

SINOPSIS


vdpa mgmtdev { COMANDO| help }

OPCIONES := { -V[ersion] }

vdpa mgmtdev show [ MGMTDEV ]

vdpa mgmtdev help

DESCRIPCIÓN

vdpa mgmtdev show - mostrar atributos del dispositivo de gestión vdpa

MGMTDEV - especifica el dispositivo de gestión vdpa a mostrar. Si se omite este argumento, se listarán todos los dispositivos de gestión.

EJEMPLOS

vdpa mgmtdev show

Muestra todos los dispositivos de gestión vdpa del sistema.

vdpa mgmtdev show bar

Muestra el dispositivo de gestión vdpa especificado.

VER TAMBIÉN
