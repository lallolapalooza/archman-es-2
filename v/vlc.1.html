VLC(1) Manual de comandos generales VLC(1)

NOMBRE

vlc, qvlc, svlc, nvlc, rvlc, cvlc - el reproductor multimedia VLC

SINOPSIS

vlc [OPCIONES] [ELEMENTOS]...

DESCRIPCIÓN

Esta página del manual documenta brevemente el reproductor y servidor multimedia VLC.

OPCIONES

VLC sigue la sintaxis habitual de línea de comandos de GNU, con opciones largas que comienzan con dos guiones (`-'). Para una descripción precisa de las opciones, por favor use "vlc --help".

La lista completa de opciones de VLC depende de los plugins instalados, ya que añaden automáticamente sus propias opciones. Por favor, use "vlc --longhelp --advanced" para obtener una lista completa de las opciones disponibles.

ELEMENTOS

VLC reconoce varios elementos de estilo URL:

*.mpg, *.vob, *.avi, *.mp3, *.ogg, *.opus
Varios formatos de archivo multimedia
dvd://[<dispositivo>][@<dispositivo en bruto>][#[<título>][:[<capítulo>][:<ángulo>]]]
Dispositivo DVD (por ejemplo, dvd:///dev/dvd). El dispositivo en bruto es opcional y debe haber sido preparado de antemano.
vcd://[<dispositivo>][@{E|P|E|T|S}[<número>]]
Dispositivo VCD (por ejemplo, vcd:///dev/cdrom).
udp://[@[<dirección multicast>][:<puerto local>]]
Flujo UDP, como uno enviado por VLS u otro VLC. Normalmente "udp://" es suficiente.
http://<dirección del servidor>[:<puerto del servidor>]/[<archivo>]
Flujo HTTP
rtsp://<dirección del servidor>[:<puerto del servidor>]/<nombre del flujo>
Flujo RTSP Video On Demand
vlc://<comando>
Ejecutar un comando de lista de reproducción. Los comandos son: pause (pausar la ejecución de otros elementos) y quit (cerrar VLC).

VARIABLES DE ENTORNO

Las siguientes variables de entorno pueden afectar a VLC:

DISPLAY
La dirección del servidor de visualización X11.
http_proxy
La URL del servidor proxy HTTP.
OSSAUDIO_DEV
El dispositivo de salida de audio predeterminado, utilizado por el plugin de salida OSSv4.
VLC_DATA_PATH
El directorio que contiene los archivos de datos en tiempo de ejecución de VLC (por ejemplo, /usr/share/vlc).
VLC_PLUGIN_PATH
Un directorio adicional para cargar plugins de VLC.
VLC_VERBOSE
El nivel de verbosidad para los mensajes de registro (0: silencioso, 1: error/información, 2: advertencia, 3: depuración).
XDG_CACHE_DIR XDG_CONFIG_DIR XDG_DATA_DIR
Los directorios para almacenar datos de caché del usuario, archivos de configuración del usuario y archivos de datos del usuario, respectivamente.
XDG_DOCUMENTS_DIR XDG_DOWNLOAD_DIR XDG_MUSIC_DIR XDG_PICTURES_DIR XDG_VIDEO_DIR
Los directorios para obtener o almacenar archivos de texto del usuario, descargas, música, imágenes (es decir, capturas de pantalla) y video, respectivamente.
XDG_SESSION_COOKIE
El identificador único de la sesión de escritorio, utilizado por el plugin de salida PulseAudio.
