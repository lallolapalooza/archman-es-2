VFWSCANF(3P) Manual de Programador de POSIX VFWSCANF(3P)

PROLOG

Esta página del manual forma parte del Manual de Programador de POSIX. La implementación de esta interfaz en Linux puede diferir (consulte la página del manual correspondiente de Linux para obtener detalles sobre el comportamiento en Linux), o la interfaz puede no estar implementada en Linux.

NOMBRE

vfwscanf, vswscanf, vwscanf — entrada formateada de caracteres anchos de una lista de argumentos stdarg

SINOPSIS

#include <stdarg.h>
#include <stdio.h>
#include <wchar.h>
int vfwscanf(FILE *restrict stream, const wchar_t *restrict format,
    va_list arg);
int vswscanf(const wchar_t *restrict ws, const wchar_t *restrict format,
    va_list arg);
int vwscanf(const wchar_t *restrict format, va_list arg);

DESCRIPCIÓN

Las funciones vfwscanf(), vswscanf() y vwscanf() serán equivalentes a las funciones fwscanf(), swscanf() y wscanf(), respectivamente, excepto que en lugar de ser llamadas con un número variable de argumentos, son llamadas con una lista de argumentos tal como se define en la cabecera <stdarg.h>. Estas funciones no invocarán la macro va_end. Como estas funciones invocan la macro va_arg, el valor de ap después del retorno no está especificado.
