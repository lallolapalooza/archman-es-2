VIRT-MANAGER(1) Soporte de virtualización VIRT-MANAGER(1)

NOMBRE

virt-manager - Herramienta gráfica para gestionar VMs de libvirt

SINOPSIS

virt-manager [OPCIONES]

DESCRIPCIÓN

virt-manager es una herramienta de escritorio para gestionar máquinas virtuales. Proporciona la capacidad de controlar el ciclo de vida de máquinas existentes (arranque/apagado, pausa/reanudación, suspensión/restauración), aprovisionar nuevas máquinas virtuales y varios tipos de almacenamiento, gestionar redes virtuales, acceder a la consola gráfica de las máquinas virtuales y ver estadísticas de rendimiento, todo ello realizado localmente o de forma remota.

OPCIONES

Se aceptan opciones estándar de GTK como --g-fatal-warnings.

Se aceptan las siguientes opciones al ejecutar virt-manager

-h, --help
Mostrar resumen de ayuda de la línea de comandos
--version
Mostrar el número de versión de virt-manager y salir
-c, --connect
Especificar la URI de conexión del hipervisor
--debug
Listar salida de depuración en la consola (normalmente esto solo se registra en ~/.cache/virt-manager/virt-manager.log). Esta función implica --no-fork.
--no-fork
No separar virt-manager en segundo plano. Ver la sección VIRT-MANAGER, SSH Y FORKING para más información.
--fork
Forzar la separación de virt-manager en segundo plano. Este es el comportamiento predeterminado. Ver la sección VIRT-MANAGER, SSH Y FORKING para más información.

OPCIONES DE VENTANA DE DIÁLOGO

Para estas opciones, solo se mostrará la ventana solicitada, en cuyo caso no se ejecutará la ventana del gestor. El inicio automático de la conexión también se deshabilitará. Todas estas opciones requieren especificar una URI de --connect manual.

--show-domain-creator
Mostrar el asistente para crear nuevas máquinas virtuales
--show-domain-editor NOMBRE|ID|UUID
Mostrar el diálogo para editar las propiedades de la máquina virtual con el ID único que coincida con el nombre del dominio, ID o UUID
--show-domain-performance NOMBRE|ID|UUID
Mostrar el diálogo para monitorizar el rendimiento de la máquina virtual con el ID único que coincida con el nombre del dominio, ID o UUID
--show-domain-console NOMBRE|ID|UUID
Mostrar la consola virtual de la máquina virtual con el ID único que coincida con el nombre del dominio, ID o UUID
--show-host-summary
Mostrar la ventana de detalles del host/conexión.

OPCIÓN DE BANDEJA DEL SISTEMA

El inicio automático de la conexión no se deshabilitará y, por lo tanto, no requerirá la especificación de una URI de --connect manual. Sin embargo, también admite URI de --connect:

--show-systray
Iniciar virt-manager solo en la bandeja del sistema

VIRT-MANAGER, SSH Y FORKING

Históricamente, al iniciar, virt-manager se separaba de la terminal en ejecución y se ejecutaba en segundo plano. Esto se hacía para forzar cualquier uso de ssh a llamar a ssh-askpass cuando necesitaba una contraseña, en lugar de solicitarla silenciosamente en una terminal que el usuario probablemente no estaba vigilando.

openssh 8.4p1 lanzado en septiembre de 2020 añadió la variable de entorno SSH_ASKPASS_REQUIRE que nos ahorra tener que hacer el baile de fork.
https://man.openbsd.org/ssh.1#SSH_ASKPASS_REQUIRE

virt-manager ahora establece SSH_ASKPASS_REQUIRE=force. Sin embargo, para que esto funcione con conexiones ssh de libvirt, necesitará libvirt 10.8.0 lanzado el 1 de octubre de 2024.

virt-manager ya no se separa por defecto.

Puede obtener el comportamiento de forking anterior con la opción --fork, o configurando la variable de entorno VIRT_MANAGER_DEFAULT_FORK=yes.

Sin embargo, si encuentra que necesita forking para un caso de uso distinto de solucionar temporalmente problemas de versión de libvirt, por favor, informe a los desarrolladores de virt-manager presentando un informe de error.
