NOMBRE

vdpa-dev - configuración de dispositivos vdpa

SINOPSIS


vdpa dev [ OPCIONES ] { COMANDO| help }

OPCIONES := { -V[ersion] }

vdpa dev show [ DEV ]

vdpa dev help

vdpa dev add name NOMBRE mgmtdev MGMTDEV [ device_features DEVICE_FEATURES ] [ mac MACADDR ] [ mtu MTU ] [ max_vqp MAX_VQ_PAIRS ]

vdpa dev del DEV

vdpa dev config show [ DEV ]

vdpa dev vstats show DEV qidx QUEUE_INDEX

vdpa dev set name NOMBRE mac [ MACADDR ]

DESCRIPCIÓN

vdpa dev show - mostrar atributos del dispositivo vdpa

DEV - especifica el dispositivo vdpa a mostrar. Si este argumento se omite, se listan todos los dispositivos.


El formato es:
NOMBRE_DEL_DISPOSITIVO_VDPA

vdpa dev add - añadir un nuevo dispositivo vdpa.

name NOMBRE
Nombre del nuevo dispositivo vdpa a añadir.
mgmtdev MGMTDEV
Nombre del dispositivo de gestión a utilizar para la adición del dispositivo.

device_features DEVICE_FEATURES Especifica la máscara de bits de características del dispositivo virtio que se provisiona para el nuevo dispositivo vdpa.

Los bits se pueden encontrar en include/uapi/linux/virtio*h.

ver macros como VIRTIO_F_ y VIRTIO_XXX(por ejemplo, NET)_F_ para valores de bits específicos.

Esto es opcional.

mac MACADDR - especifica la dirección mac para el nuevo dispositivo vdpa. Esto solo es aplicable para el tipo de red del dispositivo vdpa. Es opcional.

mtu MTU - especifica el mtu para el nuevo dispositivo vdpa. Esto solo es aplicable para el tipo de red del dispositivo vdpa. Es opcional.

vdpa dev del - Eliminar el dispositivo vdpa.

DEV - especifica el dispositivo vdpa a eliminar.

vdpa dev config show - Mostrar la configuración de un dispositivo específico o de todos los dispositivos.

DEV - especifica el dispositivo vdpa cuya configuración se mostrará. Si se omite este argumento, se lista la configuración de todos los dispositivos.


El formato es:
NOMBRE_DEL_DISPOSITIVO_VDPA

vdpa dev vstats show - muestra estadísticas específicas del proveedor para el dispositivo y el índice de cola virtio dados. La información se presenta como pares nombre-valor donde nombre es el nombre del campo y valor es un valor numérico para él.

DEV
- especifica el dispositivo vdpa a consultar
qidx QUEUE_INDEX
- especifica el índice de cola virtio a consultar

vdpa dev set - establecer la configuración del dispositivo vdpa.

name NOMBRE - Nombre del dispositivo vdpa a configurar.

mac MACADDR - especifica la dirección mac para el dispositivo vdpa. Esto solo es aplicable para el tipo de red del dispositivo vdpa.

EJEMPLOS

vdpa dev show

Muestra todos los dispositivos vdpa en el sistema.

vdpa dev show foo

Muestra el dispositivo vdpa especificado.

vdpa dev add name foo mgmtdev vdpa_sim_net

Añade el dispositivo vdpa llamado foo en el dispositivo de gestión vdpa_sim_net.

vdpa dev add name foo mgmtdev vdpa_sim_net device_features 0x300020000

Añade el dispositivo vdpa llamado foo en el dispositivo de gestión vdpa_sim_net con device_features de 0x300020000

vdpa dev add name foo mgmtdev vdpa_sim_net mac 00:11:22:33:44:55

Añade el dispositivo vdpa llamado foo en el dispositivo de gestión vdpa_sim_net con dirección mac de 00:11:22:33:44:55.

vdpa dev add name foo mgmtdev vdpa_sim_net mac 00:11:22:33:44:55 mtu 9000

Añade el dispositivo vdpa llamado foo en el dispositivo de gestión vdpa_sim_net con dirección mac de 00:11:22:33:44:55 y mtu de 9000 bytes.

vdpa dev add name foo mgmtdev auxiliary/mlx5_core.sf.1 mac 00:11:22:33:44:55 max_vqp 8

Añade el dispositivo vdpa llamado foo en el dispositivo de gestión auxiliary/mlx5_core.sf.1 con dirección mac de 00:11:22:33:44:55 y un máximo de 8 pares de colas virtio

vdpa dev del foo

Elimina el dispositivo vdpa llamado foo que fue creado previamente.

vdpa dev config show foo

Muestra la configuración del dispositivo vdpa llamado foo.

vdpa dev vstats show vdpa0 qidx 1

Muestra información de estadísticas específicas del proveedor para el dispositivo vdpa vdpa0 y el índice de cola virtio 1

vdpa dev set name vdpa0 mac 00:11:22:33:44:55

Establece una dirección MAC específica para el dispositivo vdpa vdpa0
