NOMBRE

varnetload - Herramienta para crear tráfico de red sostenido reproducible.

SINOPSIS

varnetload [-d demora] [-t tiempo de ejecución] [-u url]

DESCRIPCIÓN

varnetload es un script simple de Python para crear tráfico de red sostenido reproducible.

Para usarlo de manera efectiva, necesitas tener un servidor HTTP presente en tu LAN local donde puedas colocar archivos. Sube un archivo HTML grande (o cualquier otro tipo de archivo) al servidor HTTP. Usa la opción -u del script para apuntar a esa URL. Experimenta con la opción de demora para variar la carga impuesta a tu red.

demora
Establece la demora entre descargas individuales en milisegundos. El valor predeterminado es 1000. Pero puedes encontrar valores en el rango de 0 a 500 más útiles.
tiempo de ejecución
Establece el tiempo total de ejecución en segundos. El valor predeterminado es 60.
url
Establece el recurso descargado. El valor predeterminado es http://myhost.mydomain/index.html.
