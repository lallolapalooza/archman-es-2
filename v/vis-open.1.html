VIS-OPEN(1) Manual de comandos generales VIS-OPEN(1)

NOMBRE

vis-open — Seleccionar interactivamente un archivo para abrir

SINOPSIS

vis-open [-p prompt] [-f] [--] [archivos]

vis-open -h

DESCRIPCIÓN

vis-open toma una lista de nombres de archivo y directorios en la línea de comandos y los muestra en un menú para que el usuario seleccione uno. Si el usuario selecciona un directorio (incluido ..), el contenido del directorio se muestra como un nuevo menú. Una vez que el usuario ha seleccionado un nombre de archivo, su ruta absoluta se imprime en la salida estándar.

vis-open utiliza vis-menu(1) como su interfaz de usuario, así que consulte esa página para obtener más detalles.

-p prompt
Muestra prompt antes de la lista de elementos. Esto se pasa directamente a vis-menu(1).
-f
Normalmente, si a vis-open se le proporciona un solo nombre de archivo o argumento de directorio, lo seleccionará automáticamente (imprimiendo el nombre de archivo en la salida estándar, o presentando un nuevo menú con el contenido del directorio). Si se proporciona -f, vis-open siempre presentará los argumentos que se le dan, incluso si solo hay uno.
--
Si se encuentra este token antes del primer argumento que no sea una opción, todos los argumentos siguientes se tratarán como elementos del menú, incluso si de otro modo serían opciones válidas de la línea de comandos.

Si se encuentra después del primer argumento que no es una opción, o después de una instancia anterior de --, se tratará como un elemento del menú.

archivos
Nombres de archivos y directorios que se presentarán al usuario. Si un nombre no existe en el sistema de archivos y el usuario lo selecciona, se tratará como un archivo.
-h
Si está presente, vis-open imprime un resumen de uso y sale, ignorando cualquier otra bandera y argumentos.

ESTADO DE SALIDA

La utilidad vis-open sale con 0 en caso de éxito, y >0 si ocurre un error.

En particular, al igual que vis-menu(1), vis-open no imprime nada y establece su estado de salida a 1 si el usuario se negó a seleccionar un archivo.

EJEMPLOS

CHOICE=$(vis-open -p "Seleccionar un archivo para stat")
if [ $? -gt 0 ]; then
	echo "No se hizo ninguna selección o ocurrió un error"
else
	stat "$CHOICE"
fi

VER TAMBIÉN

vis(1), vis-menu(1)

ERRORES

Dado que vis-open utiliza ls(1) para obtener el contenido de un directorio, pueden ocurrir cosas extrañas si tienes caracteres de control en tus nombres de archivo.
