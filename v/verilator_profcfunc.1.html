NOMBRE

verilator_profcfunc - Leer informe gprof creado con Verilator --prof-cfuncs

DESCRIPCIÓN

uso: verilator_profcfunc [-h] [--debug] nombre_archivo

Leer informe de perfil creado con Verilator --prof-cfuncs

Verilator_profcfunc lee un informe de perfil creado por gprof. Los nombres de las funciones se transforman, asumiendo que el usuario utilizó --prof-cfuncs de Verilator, y se imprime un informe que muestra el porcentaje de tiempo, etc., en cada bloque de Verilog.

Para documentación, ver https://verilator.org/guide/latest/exe_verilator_profcfunc.html

argumentos posicionales:

nombre_archivo
salida gprof de entrada a procesar

opciones:

-h, --help
mostrar este mensaje de ayuda y salir
--debug
habilitar depuración
