NOMBRE

voa-import - Importa un único verificador en una jerarquía VOA.

SINOPSIS

voa import [-c|--context] [-v|--verbose]... [-i|--input] [-q|--quiet]... [-b|--base-path] [-r|--runtime] [-h|--help] <SO> <PROPOSITO> <TECNOLOGIA>

DESCRIPCIÓN

Importa un único verificador en una jerarquía VOA.

Por defecto, se espera un único verificador en la entrada estándar. Usando la opción "-i"/"--input" se puede seleccionar un directorio o archivo específico para importar en su lugar.

El verificador se escribe en la ruta de carga VOA persistente y escribible del usuario, por ejemplo:

- "~/.config/voa/": para usuarios con uid >= 1000.
Tenga en cuenta que "voa import" respeta la Especificación de Directorios Base XDG y la variable de entorno "XDG_CONFIG_HOME".
Lo anterior sirve como ejemplo por defecto. - "/etc/voa/": para usuarios con uid < 1000

Al usar la opción "-r"/"--runtime", el verificador se escribe en la ruta de carga VOA efímera y escribible del usuario en su lugar, por ejemplo:

- "/run/user/$(id -u)/voa/": para usuarios con uid >= 1000.
Tenga en cuenta que "voa import" respeta la Especificación de Directorios Base XDG y la variable de entorno "XDG_RUNTIME_DIR".
Lo anterior sirve como ejemplo por defecto. - "/run/voa": para usuarios con uid < 1000

El verificador puede escribirse en otra ruta base VOA específica utilizando la opción "-b"/"--base-path".

OPCIONES

-c, --context <CONTEXTO>
El contexto para el que se importa.

Si no se especifica, el valor predeterminado es "default".

También se puede especificar con la variable de entorno VOA_IMPORT_CONTEXT.
-v, --verbose
Aumenta la verbosidad del registro
-i, --input <ENTRADA>
El directorio o archivo desde el que importar.

Si se proporciona un directorio y la tecnología seleccionada es "openpgp", debe contener:

- Archivos de paquetes OpenPGP, - o una estructura de directorios con archivos de paquetes OpenPGP, compatible con el formato "archlinux-keyring".

Si no se proporciona directorio ni archivo, se utiliza la entrada estándar en su lugar.

También se puede especificar con la variable de entorno VOA_IMPORT_INPUT.
-q, --quiet
Disminuye la verbosidad del registro
-b, --base-path <RUTA_BASE>
La ruta base VOA a la que escribir.

Si no se especifica, se elige la ruta de carga VOA persistente y escribible del usuario, por ejemplo:

- "~/.config/voa/": para usuarios con uid >= 1000 - "/etc/voa/": para usuarios con uid < 1000

Para utilizar la ruta de carga VOA efímera y escribible del usuario si no se proporciona un directorio, pase la opción "-r"/"--runtime" al comando. En este caso, se elige la ruta de carga VOA efímera y escribible, por ejemplo:

- "/run/user/$(id -u)/voa/": para usuarios con uid >= 1000 - "/run/voa": para usuarios con uid < 1000

Tenga en cuenta que esta opción no se puede seleccionar junto con "-b"/"--base-path".

También se puede especificar con la variable de entorno VOA_IMPORT_BASE_PATH.
-r, --runtime
Si se debe importar en el directorio de tiempo de ejecución.

Indica al mecanismo de importación que utilice la ruta de carga VOA efímera y escribible del usuario, por ejemplo:

- "/run/user/$(id -u)/voa/": para usuarios con uid >= 1000 - "/run/voa": para usuarios con uid < 1000

Por defecto, si no se proporcionan estas opciones ni las opciones "-b"/"--base-path", se importa un verificador en la ruta de carga VOA persistente y escribible del usuario, por ejemplo:

- "~/.config/voa/": para usuarios con uid >= 1000 - "/etc/voa/": para usuarios con uid < 1000

Tenga en cuenta que esta opción no se puede seleccionar junto con "-b"/"--base-path".

También se puede especificar con la variable de entorno VOA_IMPORT_RUNTIME.
-h, --help
Imprime la ayuda (ver un resumen con '-h')
<SO>
El sistema operativo para el que se importa.
También se puede especificar con la variable de entorno VOA_IMPORT_OS.
<PROPOSITO>
El propósito para el que se importa.
También se puede especificar con la variable de entorno VOA_IMPORT_PURPOSE.
<TECNOLOGIA>
La tecnología para la que se importa.

Actualmente solo se admite "openpgp".

También se puede especificar con la variable de entorno VOA_IMPORT_TECHNOLOGY.
