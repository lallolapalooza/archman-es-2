NOMBRE

vfs_streams_depot - módulo EXPERIMENTAL para almacenar flujos de datos alternativos en un directorio central.

SINOPSIS

objetos vfs = streams_depot

DESCRIPCIÓN

Este módulo VFS EXPERIMENTAL es parte de la suite samba(7).

El vfs_streams_depot permite almacenar flujos de datos NTFS alternativos en el sistema de archivos. Dado que un sistema de archivos posix normal no admite el concepto de múltiples flujos de datos por archivo, el módulo streams_depot almacena los datos en archivos en un directorio separado.

OPCIONES

streams_depot:directory = RUTA

Ruta del directorio donde se deben almacenar los flujos de datos alternativos. Por defecto es sharepath/.streams.

streams_depot:delete_lost = [ sí | no ]

En el caso de un directorio de flujos de datos ya existente para un archivo recién creado, el directorio de flujos se renombrará a "lost-%lu", random(). Con esta opción, los directorios de flujos perdidos se eliminarán en lugar de renombrarse.
•no (por defecto) - renombra los flujos perdidos a "lost-%lu", random().
•sí - elimina los flujos perdidos.

EJEMPLOS

        [share]
	vfs objects = streams_depot
