NOMBRE

varnishtop - Clasificación de entradas de registro de Varnish

SINOPSIS

varnishtop [-1] [-b] [-c] [-C] [-d] [-E] [-f] [-g <session|request|vxid|raw>] [-h] [-i <taglist>] [-I <[taglist:]regex>] [-L <limit>] [-n <workdir>] [-p <period>] [-Q <file>] [-q <query>] [-r <filename>] [-t <seconds|off>] [-T <seconds>] [-x <taglist>] [-X <[taglist:]regex>] [-V]

DESCRIPCIÓN

La utilidad varnishtop lee los registros de memoria compartida de varnishd(1) y presenta una lista actualizada continuamente de las entradas de registro que ocurren con mayor frecuencia. Con un filtrado adecuado utilizando las opciones -I, -i, -X y -x, se puede utilizar para mostrar una clasificación de documentos solicitados, clientes, agentes de usuario o cualquier otra información que se registre en el registro.

Las siguientes opciones están disponibles:

-1
En lugar de una pantalla actualizada continuamente, imprime las estadísticas una vez y sale. Implica -d.
-b
Solo muestra transacciones y registros que provienen de la comunicación del backend.
-c
Solo muestra transacciones y registros que provienen de la comunicación del cliente.
-C
Realiza todas las coincidencias de expresiones regulares y cadenas sin distinguir entre mayúsculas y minúsculas.
-d
Procesa los registros del registro desde el principio del registro.
-E
Muestra transacciones ESI y otros tipos de subsolicitudes. Esto implica la opción -c e incluye otras transacciones del cliente.
-f
Ordena y agrupa solo por el primer campo de cada entrada de registro. Para entradas de registro en el formato prefijo: valor, es el prefijo sin los dos puntos lo que se ordena y agrupa. Esto es útil al mostrar, por ejemplo, entradas ReqStart, donde el primer campo es la dirección IP del cliente.
-g <session|request|vxid|raw>
La agrupación de los registros. El valor predeterminado es agrupar por vxid.
-h
Imprime el uso del programa y sale
-i <taglist>
Incluye registros de estas etiquetas en la salida. Taglist es una lista separada por comas de globs de etiquetas. Se pueden dar múltiples opciones -i.

Si una opción de inclusión de etiqueta es la primera de cualquier opción de selección de etiqueta, todas las etiquetas se marcan inicialmente como excluidas.

-I <[taglist:]regex>
Incluir por coincidencia de regex. Salida solo registros que coincidan con la lista de etiquetas y la expresión regular. Se aplica a cualquier etiqueta si la lista de etiquetas está ausente. Se pueden dar múltiples opciones -I.

Si una opción de inclusión de etiqueta es la primera de cualquier opción de selección de etiqueta, todas las etiquetas se marcan inicialmente como excluidas.

-L <limit>
Establece el límite superior de transacciones incompletas mantenidas antes de que la transacción más antigua se complete forzosamente. Se sintetiza un registro de advertencia cuando esto sucede. Esta configuración mantiene un límite superior en el uso de memoria de las consultas en ejecución. El valor predeterminado es 1000 transacciones.
-n <workdir>
Especifica el directorio de trabajo de Varnish de la instancia a la que conectarse. Consulte la documentación de la opción -n de varnishd(1) para obtener información adicional y valores predeterminados.
-p <period>
Especifica el número de segundos para medir, el valor predeterminado es 60 segundos. El primer número de la lista es el número promedio de solicitudes vistas durante este período de tiempo. Esta opción no tiene ningún efecto si también se utiliza la opción -1.
-Q <file>
Especifica el archivo que contiene la consulta VSL a utilizar. Cuando se especifican múltiples opciones -Q o -q, todas las consultas se consideran como si se hubiera utilizado el operador 'or' para combinarlas.
-q <query>
Especifica la consulta VSL a utilizar. Cuando se especifican múltiples opciones -q o -Q, todas las consultas se consideran como si se hubiera utilizado el operador 'or' para combinarlas.
-r <filename>
Lee el registro en formato de archivo binario de este archivo. El archivo puede crearse con varnishlog -w filename. Si el nombre del archivo es -, los registros se leen desde la entrada estándar. y no puede funcionar como un demonio.
-t <seconds|off>
Tiempo de espera antes de devolver un error en la conexión VSM inicial. Si se establece, la conexión VSM se reintenta cada 0.5 segundos durante esta cantidad de segundos. Si es cero, la conexión se intenta solo una vez y fallará inmediatamente si no tiene éxito. Si se establece en "off", la conexión no fallará, lo que permitirá que la utilidad comience y espere indefinidamente a que aparezca la instancia de Varnish. El valor predeterminado es 5 segundos.
-T <seconds>
Establece el tiempo de espera de la transacción en segundos. Esto define el número máximo de segundos transcurridos entre una etiqueta Begin y la etiqueta End. Si expira el tiempo de espera, se sintetiza un registro de advertencia y la transacción se completa forzosamente. El valor predeterminado es 120 segundos.
-x <taglist>
Excluye registros de estas etiquetas en la salida. Taglist es una lista separada por comas de globs de etiquetas. Se pueden dar múltiples opciones -x.
-X <[taglist:]regex>
Excluir por coincidencia de regex. No genere registros que coincidan con la lista de etiquetas y la expresión regular. Se aplica a cualquier etiqueta si la lista de etiquetas está ausente. Se pueden dar múltiples opciones -X.
-V
Imprime la información de la versión y sale.
--optstring
Imprime el parámetro optstring para getopt(3) para ayudar a escribir scripts de envoltura.

EJEMPLOS

El siguiente ejemplo muestra una lista actualizada continuamente de las URLs solicitadas con mayor frecuencia:

varnishtop -i ReqURL

El siguiente ejemplo muestra una lista actualizada continuamente de los agentes de usuario utilizados con mayor frecuencia:

varnishtop -C -I ReqHeader:User-Agent
