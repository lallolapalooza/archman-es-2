VPNC(8) Utilidades de Administración del Sistema VPNC(8)

NOMBRE

vpnc - cliente para Cisco VPN3000 Concentrator, IOS y PIX

SINOPSIS

vpnc [--version] [--print-config] [--help] [--long-help] [opciones] [archivos de configuración]

DESCRIPCIÓN

Esta página del manual documenta brevemente los comandos vpnc y vpnc-disconnect.

vpnc es un cliente VPN para el Cisco 3000 VPN Concentrator, que crea una conexión similar a IPSec como un dispositivo de red de túnel para el sistema local. Utiliza el controlador TUN/TAP en el kernel de Linux 2.4 y superior, y el dispositivo tun(4) en BSD. La conexión creada se presenta como un dispositivo de red de túnel para el sistema local.

ADVERTENCIA OBLIGATORIA: la configuración más utilizada (autenticación XAUTH con claves precompartidas y autenticación por contraseña) es insegura por diseño, tenga en cuenta este hecho cuando utilice vpnc para intercambiar datos sensibles como contraseñas.

El demonio vpnc por sí solo no establece ninguna ruta, sino que llama a vpnc-script para realizar esta tarea. vpnc-script muestra un banner de conexión. Si el concentrador suministra una lista de redes para tunelización dividida, estas redes se añaden a la tabla de enrutamiento. De lo contrario, se modificará la ruta predeterminada para que apunte al túnel. Además, se añade una ruta de host al concentrador en este último caso. Si el host cliente necesita DHCP, se debe tener cuidado de añadir otra ruta de host al servidor DHCP rodeando el túnel.

El comando vpnc-disconnect se utiliza para terminar la conexión creada previamente por vpnc y restaurar la configuración de enrutamiento anterior.

CONFIGURACIÓN

El demonio lee los datos de configuración de los siguientes lugares:

  • opciones de línea de comandos
  • archivo(s) de configuración especificados en la línea de comandos
  • /etc/vpnc/default.conf
  • /etc/vpnc.conf
  • solicitando al usuario si no se encuentra en los anteriores

vpnc puede analizar opciones y archivos de configuración en cualquier orden. Sin embargo, el primer lugar donde se establece una opción es el que prevalece. los nombres de archivo de configuración que no contienen un / se buscarán en /etc/vpnc/<nombre de archivo> y /etc/vpnc/<nombre de archivo>.conf. De lo contrario, se usarán <nombre de archivo> y <nombre de archivo>.conf. Si no se especifica ningún archivo de configuración en la línea de comandos, se cargarán tanto /etc/vpnc/default.conf como /etc/vpnc.conf.

Adicionalmente, si el archivo de configuración "-" se especifica en la línea de comandos, vpnc leerá la configuración desde stdin. La configuración se analiza y la conexión procede cuando se cierra stdin o se lee el carácter especial CEOT (CTRL-D).

OPCIONES

Las opciones del programa se pueden proporcionar como argumentos (pero no todas por razones de seguridad) o almacenarse en un archivo de configuración.

--gateway <ip/nombre de host>
IP/nombre de su gateway IPSec

variable de configuración: gateway IPSec <ip/nombre de host>

--id <cadena ASCII>
su nombre de grupo

variable de configuración: ID IPSec <cadena ASCII>

--secret <cadena ASCII>
su contraseña de grupo (texto plano)

variable de configuración: secreto IPSec <cadena ASCII>

(solo opción de archivo de configuración)
su contraseña de grupo (ofuscada)

variable de configuración: secreto IPSec ofuscado <cadena hexadecimal>

--username <cadena ASCII>
su nombre de usuario

variable de configuración: nombre de usuario Xauth <cadena ASCII>

--password <cadena ASCII>
su contraseña (texto plano)

variable de configuración: contraseña Xauth <cadena ASCII>

(solo opción de archivo de configuración)
su contraseña (ofuscada)

variable de configuración: contraseña Xauth ofuscada <cadena hexadecimal>

--domain <cadena ASCII>
Nombre de dominio (NT) para la autenticación

variable de configuración: Dominio <cadena ASCII>

--xauth-inter
habilitar autenticación extendida interactiva (para autenticación de respuesta a desafío)

variable de configuración: Xauth interactivo

--vendor <cisco/netscreen/fortigate>
proveedor de su gateway IPSec
Predeterminado: cisco

variable de configuración: Proveedor <cisco/netscreen/fortigate>

--natt-mode <natt/none/force-natt/cisco-udp>
Qué método de NAT-Traversal usar:
  • natt -- NAT-T como se define en RFC3947
  • none -- deshabilitar el uso de cualquier método NAT-T
  • force-natt -- usar siempre encapsulación NAT-T incluso sin presencia de un dispositivo NAT (útil si el SO captura todo el tráfico ESP)
  • cisco-udp -- encapsulación UDP propietaria de Cisco, comúnmente sobre el puerto 10000
Nota: la encapsulación cisco-tcp aún no es compatible
Predeterminado: natt

variable de configuración: Modo de Traversal NAT <natt/none/force-natt/cisco-udp>

--script <comando>
el comando se ejecuta usando system() para configurar la interfaz, el enrutamiento, etc. El nombre del dispositivo, la IP, etc. se pasan a través de variables de entorno, consulte README. Este script se ejecuta justo después de que se completa ISAKMP, pero antes de que se habilite el tunelizado. También se llama cuando vpnc termina.
Predeterminado: /etc/vpnc/vpnc-script

variable de configuración: Script <comando>

--dh <dh1/dh2/dh5/dh14/dh15/dh16/dh17/dh18>
nombre del Grupo DH de IKE
Predeterminado: dh2

variable de configuración: Grupo DH de IKE <dh1/dh2/dh5/dh14/dh15/dh16/dh17/dh18>

--pfs <nopfs/dh1/dh2/dh5/dh14/dh15/dh16/dh17/dh18/server>
Grupo Diffie-Hellman a usar para PFS
Predeterminado: server

variable de configuración: Perfect Forward Secrecy <nopfs/dh1/dh2/dh5/dh14/dh15/dh16/dh17/dh18/server>

--enable-1des
Obsoleto: Utilice --enable-weak-encryption en su lugar.

variable de configuración: Habilitar Single DES

--enable-weak-encryption
habilita métodos de encriptación débiles (como DES, 3DES)

variable de configuración: Habilitar encriptación débil

--enable-no-encryption
habilita el uso de ninguna encriptación para el tráfico de datos (la clave intercambiada debe estar encriptada)

variable de configuración: Habilitar sin encriptación

--enable-weak-authentication
habilita métodos de autenticación débiles (como MD5)

variable de configuración: Habilitar autenticación débil

--application-version <cadena ASCII>
Versión de la aplicación a reportar. Nota: La cadena predeterminada se genera en tiempo de ejecución.
Predeterminado: Cisco Systems VPN Client 0.5.3:Linux

variable de configuración: Versión de la aplicación <cadena ASCII>

--ifname <cadena>
nombre de la interfaz a crear (ej. tun0)

variable de configuración: nombre de interfaz <cadena>

--daemon
ejecutar vpnc como un demonio

variable de configuración: Ejecutar como demonio

--debug
activar el registro detallado

variable de configuración: Debug

--foreground
No bifurcarse en segundo plano. Útil para la depuración.

variable de configuración: En primer plano

--log <nombre de archivo>
registrar en el archivo especificado

variable de configuración: Registro <nombre de archivo>

--remote-subnets <lista separada por comas de subredes IP/Máscara>
Lista de subredes que están accesibles a través del túnel.

variable de configuración: subredes remotas <lista separada por comas de subredes IP/Máscara>

--local-subnets <lista separada por comas de subredes IP/Máscara>
Lista de subredes a las que pertenece el cliente.

variable de configuración: subredes locales <lista separada por comas de subredes IP/Máscara>

--cisco-unity
Habilita la autenticación Cisco Unity.

variable de configuración: autenticación Cisco Unity

--disable-xauth-failure-notify
No notificar al servidor VPN que xauth ha fallado.

variable de configuración: no notificar fallo xauth

--rekey
Reinicia la conexión si se desconecta.

variable de configuración: Reconectar

--max-rekey <segundos>
Número máximo de reintentos antes de rendirse.

variable de configuración: máximo de reintentos <segundos>

--port <puerto>
Puerto UDP a usar para la conexión ISAKMP.

variable de configuración: puerto <puerto>

--version
Mostrar información de versión y salir.
--print-config
Imprime la configuración completa y sale.
--help
Mostrar mensaje de ayuda y salir.
--long-help
Mostrar mensaje de ayuda detallado y salir.

Las opciones se pueden especificar con guiones dobles (por ejemplo, --gateway) o guiones simples (por ejemplo, -g) si se define un alias.

EJEMPLOS

Ejecutar vpnc interactivamente sin archivo de configuración:

vpnc --gateway vpn.example.com --username alice

Leer la configuración del archivo /etc/vpnc/vpn.conf y conectar a un gateway:

vpnc /etc/vpnc/vpn.conf

Guardar la configuración completa en un archivo (incluyendo contraseñas ofuscadas):

vpnc --print-config > vpn.conf

ARCHIVOS

/etc/vpnc.conf /etc/vpnc/default.conf

El archivo de configuración predeterminado. Puedes especificar las mismas directivas de configuración que con las opciones de línea de comandos y, además, secreto IPSEC y contraseña Xauth, ambas proporcionando una contraseña en texto plano. Las contraseñas cifradas de los perfiles de configuración de Cisco se pueden usar con secreto ofuscado IPSEC y contraseña ofuscada Xauth.

Consulta EJEMPLOS para más detalles.

/etc/vpnc/*.conf

vpnc leerá archivos de configuración en este directorio cuando el nombre del archivo de configuración (con o sin .conf) se especifique en la línea de comandos.

EJEMPLOS

Este es un ejemplo de vpnc.conf con claves precompartidas:

IPSec gateway vpn.example.com

IPSec ID ExampleVpnPSK

IKE Authmode psk

IPSec secret PskS3cret!

Xauth username user@example.com

Xauth password USecr3t

Y otro con autenticación híbrida (requiere que vpnc se haya compilado con soporte openssl):

IPSec gateway vpn.example.com

IPSec ID ExampleVpnHybrid

IKE Authmode hybrid

CA-Dir /etc/vpnc

o

CA-File /etc/vpnc/vpn-example-com.pem

IPSec secret HybS3cret?

Xauth username user@example.com

Xauth password 123456

Las líneas comienzan con una palabra clave (sin espacios iniciales). Los valores comienzan exactamente un espacio después de las palabras clave y continúan hasta el final de la línea. Esto te permite poner cualquier tipo de caracter extraño (excepto CR, LF y NUL) en tus cadenas, pero significa que no puedes agregar comentarios después de una cadena, ni espacios antes de ellas.

En caso de que se use la opción CA-Dir, tu certificado debe llamarse algo así como 722d15bd.X, donde X es un número asignado manualmente para asegurar que los archivos con hashes que colisionan tengan nombres diferentes. El número se puede derivar del propio archivo de certificado:

openssl x509 -subject_hash -noout -in /etc/vpnc/vpn-example-com.pem

Consulta también la opción --print-config para generar un archivo de configuración, y el archivo de ejemplo en el directorio de documentación del paquete donde se demuestra un uso más avanzado.

Las características avanzadas como la configuración manual de múltiples rutas de destino y la deshabilitación de la reescritura de /etc/resolv.conf se documentan en el README del paquete vpnc.
