VIPSTHUMBNAIL(1) Manual de comandos generales VIPSTHUMBNAIL(1)

NOMBRE

vipsthumbnail - crear miniaturas de archivos de imagen

SINOPSIS

vipsthumbnail [indicadores] archivoimagen1 archivoimagen2 ...

DESCRIPCIÓN

vipsthumbnail(1) procesa cada archivoimagen por turno, reduciendo cada imagen para que quepa dentro de un cuadrado de 128 por 128 píxeles. La imagen reducida se escribe en un nuevo archivo llamado tn_archivoimagen.jpg. Este programa es típicamente más rápido y utiliza menos memoria que otros programas de miniaturas de imágenes.

Por ejemplo:


$ vipsthumbnail fred.png jim.tif

leerá los archivos de imagen fred.png y jim.tif y escribirá las miniaturas en los archivos tn_fred.jpg y tn_jim.jpg.


$ vipsthumbnail --size=64 -o thumbnails/%s.png fred.jpg

leerá el archivo de imagen fred.jpg y escribirá una miniatura de 64 x 64 píxeles en el archivo thumbnails/fred.png.

OPCIONES

-s N, --size=N
Establece el tamaño de la miniatura de salida a N x N píxeles.

Puede usar "MxN" para especificar un cuadro delimitador rectangular. La imagen se reduce para que quepa justo dentro de esta área; las imágenes más pequeñas que esto se expanden.

Use "xN" o "Mx" para redimensionar solo en un eje.

Añada "<" para redimensionar solo si la imagen de entrada es más pequeña que la de destino, añada ">" para redimensionar solo si la imagen de entrada es más grande que la de destino.

-o FORMATO, --output=FORMATO
Establece la cadena de formato de salida. Al nombre de archivo de entrada se le elimina el sufijo del tipo de archivo, y luego ese valor se sustituye en FORMATO reemplazando a %s. Si FORMATO es una ruta relativa, se antepone el nombre del directorio de entrada. En otras palabras, cualquier ruta en FORMATO es relativa al directorio del archivo de entrada actual.

El valor predeterminado es tn_%s.jpg, lo que significa salida JPEG, con tn_ antepuesto. También puede añadir opciones de formato, por ejemplo, tn_%s.jpg[Q=20] escribirá imágenes JPEG con Q establecido en 20.

-e PERFIL, --eprofile=PERFIL
Exporta miniaturas con este perfil ICC. Las imágenes solo se transforman de color si hay disponible tanto un perfil de salida como uno de entrada. El perfil de entrada puede estar incrustado en la imagen de entrada o proporcionarse con la opción --iprofile.
-i PERFIL, --iprofile=PERFIL
Importa imágenes con este perfil ICC, si no hay ningún perfil incrustado en la imagen. Las imágenes solo se transforman de color si hay disponible tanto un perfil de salida como uno de entrada. El perfil de salida debe proporcionarse con la opción --oprofile.
-c, --crop
Recorta la imagen de salida. La imagen se reduce para llenar completamente el cuadro delimitador en ambos ejes, y luego se recorta cualquier exceso.
-d, --delete
Elimina el perfil de salida de la imagen. Esto puede ahorrar un poco de espacio.
-t, --rotate
Rota automáticamente las imágenes utilizando las etiquetas de orientación EXIF.
-a, --linear
Reduce las imágenes en el espacio de color de luz lineal. Esto puede ser mucho más lento.

VALOR DE RETORNO

devuelve 0 en caso de éxito y un valor distinto de cero en caso de error. El error puede significar que una o más conversiones fallaron.
