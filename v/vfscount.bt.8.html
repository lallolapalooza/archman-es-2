vfscount.bt(8) Manual del Administrador del Sistema vfscount.bt(8)

NOMBRE

vfscount.bt - Cuenta llamadas VFS ("vfs_*"). Usa bpftrace/eBPF.

SINOPSIS

vfscount.bt

DESCRIPCIÓN

Este comando cuenta las llamadas VFS. Esto puede ser útil para la caracterización general de la carga de trabajo de estas operaciones.

Funciona rastreando todas las funciones del kernel que comienzan con "vfs_" usando rastreo dinámico. Esto puede coincidir con más funciones de las que te interesa medir: Edita el script para personalizar qué funciones rastrear.

Dado que esto usa BPF, solo el usuario root puede usar esta herramienta.

REQUISITOS

CONFIG_BPF y bpftrace.

EJEMPLOS

Cuenta todas las llamadas VFS hasta que se presiona Ctrl-C:
# vfscount.bt

CAMPOS

1º
Nombre de la función del kernel (en @[])
2º
Número de llamadas mientras se rastrea

SOBRECARGA

Esto rastrea las funciones vfs del kernel y mantiene recuentos en el kernel, que se copian de forma asíncrona al espacio de usuario. Si bien la tasa de operaciones VFS puede ser muy alta (>1M/segundo), esta es una forma relativamente eficiente de rastrear estos eventos, por lo que se espera que la sobrecarga sea pequeña para cargas de trabajo normales. Mide en un entorno de prueba y, si las sobrecargas son un problema, edita el script para reducir los tipos de funciones vfs rastreadas (actualmente todas las que comienzan con "vfs_").

FUENTE

Esto es de bpftrace.

https://github.com/bpftrace/bpftrace

Busca también en la distribución de bpftrace un archivo complementario _examples.txt que contiene ejemplos de uso, salida y comentarios para esta herramienta.

Esta es una versión de bpftrace de la herramienta bcc del mismo nombre. La herramienta bcc puede ofrecer más opciones y personalizaciones.
