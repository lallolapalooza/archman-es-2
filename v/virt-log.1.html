virt-log(1) Soporte de Virtualización virt-log(1)

NOMBRE

virt-log - Muestra archivos de registro de una máquina virtual

SINOPSIS

virt-log [--opciones] -d nombre_dominio
virt-log [--opciones] -a imagen_disco.img [-a imagen_disco.img ...]

DESCRIPCIÓN

"virt-log" es una herramienta de línea de comandos para mostrar los archivos de registro del nombre de la máquina virtual (o imagen de disco).

Esta herramienta comprende y muestra tanto archivos de registro de texto plano (p. ej., /var/log/messages) como formatos binarios como el journal de systemd.

Para mostrar otros tipos de archivos, usa virt-cat(1). Para seguir (tail) archivos de registro de texto, usa virt-tail(1). Para copiar archivos fuera de una máquina virtual, usa virt-copy-out(1). Para mostrar el contenido del Registro de Windows, usa virt-win-reg(1).

EJEMPLOS

Muestra los registros completos de un invitado:

virt-log -d mmi_dominio | less

Averigua qué dirección IP DHCP adquirió una VM:

virt-log -d mmi_dominio | grep 'dhclient.*bound to'

OPCIONES

--help
Muestra ayuda breve.
-a archivo
--add archivo
Añade archivo que debe ser una imagen de disco de una máquina virtual. Si la máquina virtual tiene múltiples dispositivos de bloque, debes proporcionar todos ellos con opciones -a separadas.

El formato de la imagen de disco se detecta automáticamente. Para anular esto y forzar un formato particular, usa la opción --format=...

-a URI
--add URI
Añade un disco remoto. Ver "AÑADIR ALMACENAMIENTO REMOTO" en guestfish(1).
--blocksize=512
--blocksize=4096
--blocksize
Este parámetro establece el tamaño del sector de la imagen de disco. Afecta a todos los discos añadidos explícitamente después de este parámetro. Usar --blocksize sin argumento cambia el tamaño del sector del disco al valor predeterminado, que suele ser de 512 bytes. Ver también "guestfs_add_drive_opts" en guestfs(3).
-c URI
--connect URI
Si usas libvirt, conéctate a la URI dada. Si se omite, nos conectamos al hipervisor libvirt predeterminado.

Si especificas los dispositivos de bloque del invitado directamente (-a), entonces libvirt no se utiliza en absoluto.

-d invitado
--domain invitado
Añade todos los discos del invitado libvirt nombrado. Los UUIDs de dominio pueden usarse en lugar de nombres.
--echo-keys
Al solicitar claves y contraseñas, virt-log normalmente desactiva el eco para que no veas lo que escribes. Si no te preocupas por los ataques Tempest y no hay nadie más en la habitación, puedes especificar esta bandera para ver lo que escribes.
--format=raw|qcow2|..
--format
El valor predeterminado para la opción -a es detectar automáticamente el formato de la imagen de disco. Usar esto fuerza el formato del disco para las opciones -a que siguen en la línea de comandos. Usar --format sin argumento vuelve a la detección automática para las opciones -a subsiguientes.

Por ejemplo:

virt-log --format=raw -a disco.img

fuerza el formato raw (sin detección automática) para disco.img.

virt-log --format=raw -a disco.img --format -a otro.img

fuerza el formato raw (sin detección automática) para disco.img y revierte a la detección automática para otro.img.

Si tienes imágenes de disco de invitados sin confiar en formato raw, deberías usar esta opción para especificar el formato del disco. Esto evita un posible problema de seguridad con invitados maliciosos (CVE-2010-3851).

--key SELECCIONADOR
Especifica una clave para LUKS, para abrir automáticamente un dispositivo LUKS al usar la inspección.
--key NOMBRE:key:CADENA_CLAVE
--key UUID:key:CADENA_CLAVE
--key all:key:CADENA_CLAVE
"NOMBRE" es el nombre del dispositivo libguestfs (p. ej., "/dev/sda1"). "UUID" es el UUID del dispositivo. "all" significa intentar la clave contra cualquier dispositivo cifrado.

Usa la "CADENA_CLAVE" especificada como contraseña.

--key NOMBRE:file:NOMBRE_ARCHIVO
--key UUID:file:NOMBRE_ARCHIVO
--key all:file:NOMBRE_ARCHIVO
Lee la contraseña desde el archivo NOMBRE_ARCHIVO.
--key NOMBRE:clevis
--key UUID:clevis
--key all:clevis
Intenta el desbloqueo sin contraseña para el dispositivo con Clevis, a través de la red. Por favor, consulta "DISCOS CIFRADOS" en guestfs(3) para más información sobre cifrado de disco enlazado a red (NBDE).

Ten en cuenta que si alguna de estas opciones está presente en la línea de comandos, la red de usuario QEMU se habilitará automáticamente para la aplicación libguestfs.

--keys-from-stdin
Lee parámetros de clave o contraseña desde la entrada estándar. El valor predeterminado es intentar leer contraseñas del usuario abriendo /dev/tty.

Si hay múltiples dispositivos cifrados, puede que necesites proporcionar múltiples claves en la entrada estándar, una por línea.

-v
--verbose
Habilita mensajes detallados para depuración.
-V
--version
Muestra el número de versión y sale.
-x
Habilita el rastreo de llamadas a la API de libguestfs.

ESTADO DE SALIDA

Este programa devuelve 0 si tiene éxito, o distinto de cero si hubo un error.
