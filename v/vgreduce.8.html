NOMBRE

vgreduce — Elimina volúmenes físicos de un grupo de volúmenes

SINOPSIS

vgreduce argumentos_opcionales argumentos_posicionales
[ argumentos_opcionales ]
-a|--all
-A|--autobackup y|n
   --commandprofile Cadena
   --config Cadena
-d|--debug ...
   --devices PV
   --devicesfile Cadena
   --driverloaded y|n
-f|--force ...
-h|--help
   --journal Cadena
   --lockopt Cadena
   --longhelp
   --mirrorsonly
   --nohints
   --nolocking
   --profile Cadena
-q|--quiet ...
   --removemissing
   --reportformat basic|json|json_std
-t|--test
-v|--verbose ...
   --version
-y|--yes

DESCRIPCIÓN

vgreduce elimina uno o más volúmenes físicos (PVs) no utilizados de un Grupo de Volúmenes (VG).

USO

Eliminar un PV de un VG.

vgreduce VG PV ...

[ OPCIONES_COMUNES ]

—

Eliminar todos los PVs no utilizados de un VG.

vgreduce -a|--all VG

[ OPCIONES_COMUNES ]

—

Eliminar todos los PVs faltantes de un VG.

vgreduce --removemissing VG

[ --mirrorsonly ]
[ OPCIONES_COMUNES ]

—

Opciones comunes para el comando:

[ -A|--autobackup y|n ]
[ -f|--force ... ]
[ --reportformat basic|json|json_std ]

OPCIONES

-a|--all
Elimina todos los PVs vacíos si no se nombran PVs en la línea de comandos.
-A|--autobackup y|n
Especifica si los metadatos deben ser respaldados automáticamente después de un cambio. ¡Se recomienda encarecidamente habilitar esto! Consulte vgcfgbackup(8) para más información.
--commandprofile Cadena
El perfil de comando a utilizar para la configuración del comando. Consulte lvm.conf(5) para más información sobre perfiles.
--config Cadena
Configuraciones del comando. Estas anulan los ajustes de lvm.conf(5). La cadena de argumentos usa el mismo formato que lvm.conf(5), o puede usar la sintaxis de sección/campo. Consulte lvm.conf(5) para más información sobre la configuración.
-d|--debug ...
Establece el nivel de depuración. Repetir de 1 a 6 veces para aumentar el detalle de los mensajes enviados al archivo de registro y/o a syslog (si está configurado).
--devices PV
Restringe los dispositivos que son visibles y accesibles para el comando. Los dispositivos no listados parecerán faltantes. Esta opción se puede repetir, o acepta una lista de dispositivos separada por comas. Esto anula el archivo de dispositivos.
--devicesfile Cadena
Un archivo que lista los dispositivos que LVM debe usar. El archivo debe existir en /etc/lvm/devices/ y se gestiona con el comando lvmdevices(8). Esto anula la configuración de devices/devicesfile y devices/use_devicesfile de lvm.conf(5).
--driverloaded y|n
Si se establece en no, el comando no intentará usar el mapeador de dispositivos. Para pruebas y depuración.
-f|--force ...
Anula varias comprobaciones, confirmaciones y protecciones. Úselo con extrema precaución.
-h|--help
Muestra el texto de ayuda.
--journal Cadena
Registra información en el journal de systemd. Esta información es adicional a la información habilitada por la configuración de log/journal de lvm.conf. command: registra información sobre el comando. output: registra la salida del comando por defecto. debug: registra la depuración completa del comando.
--lockopt Cadena
Se utiliza para pasar opciones para casos especiales a lvmlockd. Consulte lvmlockd(8) para más información.
--longhelp
Muestra el texto de ayuda extenso.
--mirrorsonly
Solo elimina PVs faltantes de LVs de espejo.
--nohints
No utiliza el archivo de sugerencias para localizar dispositivos para los PVs. Un comando puede leer más dispositivos para encontrar PVs cuando no se usan sugerencias. El comando aún realizará la invalidación estándar del archivo de sugerencias cuando sea apropiado.
--nolocking
Deshabilita el bloqueo. Úselo con precaución, los comandos concurrentes pueden producir resultados incorrectos.
--profile Cadena
Un alias para --commandprofile o --metadataprofile, dependiendo del comando.
-q|--quiet ...
Suprime la salida y los mensajes de registro. Anula --debug y --verbose. Repetir una vez para suprimir también cualquier solicitud con respuesta 'no'.
--removemissing
Elimina todos los PVs faltantes del VG, si no hay LVs asignados en ellos. Esto reanuda el funcionamiento normal del VG (nuevos LVs pueden crearse, cambiarse y así sucesivamente). Si esto no es posible porque los LVs hacen referencia a los PVs faltantes, esta opción puede combinarse con --force para que el comando elimine cualquier LV parcial. En este caso, todos los LVs y las instantáneas dependientes que estaban parcialmente en los discos faltantes se eliminan completamente, incluidas las partes en los discos que aún están presentes. Si los LVs abarcaron varios discos, incluidos los perdidos, puede ser posible salvar algunos datos primero activando los LVs en modo parcial.
--reportformat basic|json|json_std
Anula el formato de salida actual para informes, que se define globalmente mediante la configuración report/output_format en lvm.conf(5). basic es el formato original con columnas y filas. Si hay más de un informe por comando, cada informe se prefija con el nombre del informe para su identificación. json produce la salida del informe en formato JSON. json_std produce
