NOMBRE

VisiData — una utilidad de terminal para explorar y organizar datos tabulares

SINOPSIS

vd [opciones] [entrada ...]

visidata [opciones] [entrada ...]

vd [opciones] --play logcomandos [-w segundos_espera] [--batch] [-i] [-o salida] [campo=valor]

vd [opciones] [entrada ...] +toplevel:subhoja:fila:columna

DESCRIPCIÓN

VisiData es una herramienta multiusos fácil de usar para explorar, limpiar, editar y reestructurar datos. Las filas se pueden seleccionar, filtrar y agrupar; las columnas se pueden reorganizar, transformar y derivar mediante expresiones regulares o de Python; y los flujos de trabajo se pueden guardar, documentar y reproducir.

MODO DE REPRODUCCIÓN

-p, --play=logcomandos
reproduce un log de comandos guardado logcomandos dentro de la interfaz
-w, --replay-wait=segundos
espera segundos entre comandos
-b, --batch
reproducir en modo batch (sin interfaz)
-i, --interactive
iniciar VisiData en modo interactivo después del batch
-o, --output=archivo
guarda la hoja visible final en archivo como .tsv
campo=valor
reemplaza "{campo}" en el contenido del logcomandos con valor

Comandos Durante la Reproducción

Ctrl+K
cancelar la reproducción actual

COMANDOS GLOBALES

Todas las pulsaciones de teclas distinguen mayúsculas de minúsculas. El prefijo ^ es una abreviatura de Ctrl.

Pulsaciones de teclas para empezar

^Q
abortar el programa inmediatamente
^C
cancelar la entrada del usuario o abortar todos los hilos asíncronos en la hoja actual
g^C
abortar todos los hilos secundarios
q
salir de la hoja o menú actual
Q
salir de la hoja actual y liberar la memoria asociada
gq
salir de todas las hojas (salida limpia)
Alt+H
activar el menú de ayuda (Enter/ratón izquierdo para expandir submenú o ejecutar comando)
g^H
ver esta página de manual
z^H
ver hoja de nombres largos de comandos y atajos de teclado para la hoja actual
gb
abrir barra lateral en una nueva hoja
b
activar/desactivar barra lateral
U
deshacer la modificación más reciente (requiere options.undo habilitado)
R
rehacer el último deshacer (requiere options.undo habilitado
Espacio nombrelargo
abrir paleta de comandos; ejecutar comando superior por su nombrelargo

Paleta de Comandos

Tab
Mover a la paleta de comandos y ciclar entre comandos
0-9
Ejecutar comando numerado
Enter
Ejecutar comando resaltado

NOMBRE

visidata — interactivo de hoja de cálculo para la línea de comandos

SINOPSIS

vd [-C|-c|-s|-S|-P] [-H n] [-e expr] [-f source] [-p path] [-r rows] [-t threads] [-R reload] [source[...]]

DESCRIPCIÓN

VisiData es un visor interactivo de hojas de cálculo para la línea de comandos. Carga datos de varias fuentes (archivos, bases de datos, etc.) en una hoja de cálculo y permite al usuario navegar, filtrar, buscar, y realizar acciones sobre los datos de manera eficiente.

El programa permite al usuario cargar múltiples fuentes de datos en pestañas. Cada pestaña representa una hoja de datos, que puede ser un archivo, una tabla de base de datos, o incluso el resultado de un comando. El usuario puede moverse entre estas pestañas, y dentro de cada pestaña, navegar por filas y columnas.

Las operaciones comunes incluyen:

  • Navegación rápida (inicio/fin de línea, inicio/fin de archivo, ir a fila/columna).
  • Búsqueda y filtrado de datos.
  • Edición de celdas.
  • Ordenación de columnas.
  • Realización de cálculos y agregaciones.
  • Guardar datos en varios formatos.
  • Importación y exportación de datos.

VisiData es altamente configurable a través de un archivo de configuración y ofrece una amplia gama de atajos de teclado para la eficiencia.

Cargar archivos en modo de sólo lectura.

Separar archivos en pestañas.
-S
Separar archivos en pestañas en modo de sólo lectura.

Pre-cargar un plugin de la ruta especificada.
-H n
Omitir n líneas de encabezado al leer archivos.
-e expr
Evaluar una expresión de Python.
-f source
Especificar la fuente de datos (por ejemplo, postgresql).
-p path
Especificar la ruta del archivo de configuración.
-r rows
Especificar el número de filas a cargar.
-t threads
Especificar el número de hilos a utilizar.
-R reload
Recargar la fuente de datos cada reload segundos.

ARCHIVOS

Al inicio de cada sesión, VisiData busca $HOME/.visidatarc, y ejecuta exec() de Python en su contenido si existe. Por ejemplo:

options.min_memory_mb=100  # detener el procesamiento sin 100MB libres

bindkey('0', 'go-leftmost')   # alias '0' para ir a la primera columna, como vim

def median(values):
    L = sorted(values)
    return L[len(L)//2]

vd.aggregator('median', median)

Las funciones definidas en .visidatarc están disponibles en expresiones de python (por ejemplo, en columnas derivadas).

FUENTES SOPORTADAS

El núcleo de VisiData incluye estas fuentes:

tsv (valor separado por tabulaciones)
Simple y llano. VisiData escribe en formato tsv por defecto. Ver la opción --tsv-delimiter.
csv (valor separado por comas)
Los archivos .csv son una plaga sobre la tierra, y todavía lamentablemente comunes.
Ver las opciones --csv-dialect, --csv-delimiter, --csv-quotechar, y --csv-skipinitialspace.
Los dialectos aceptados son excel-tab, unix, y excel.
fixed (texto de ancho fijo)
Las columnas se detectan automáticamente a partir de las primeras 1000 filas (ajustable con --fixed-rows).
json (un solo objeto) y jsonl/ndjson/ldjson (un objeto por línea).
Las celdas que contienen listas (por ejemplo, [3]) o diccionarios ({3}) se pueden expandir en nuevas columnas con ( y contraer con ).
sqlite
Puede incluir múltiples tablas. La hoja inicial es el directorio de tablas;
Enter carga la tabla completa en memoria. z^S guarda las modificaciones en la fuente.

Los esquemas de URL también son compatibles:

http (requiere requests); se puede utilizar como transporte para otro tipo de archivo

Para una lista de todos los formatos restantes compatibles con VisiData, ver https://visidata.org/formats.

Además, .zip, .gz, .bz2, .xz, ,zstd, y .zst los archivos se descomprimen sobre la marcha.
