NOMBRE

virt-copy-out - Copia archivos y directorios desde una imagen de disco de máquina virtual.

SINOPSIS

virt-copy-out -a disk.img /archivo|dir [/archivo|dir ...] dir_local
virt-copy-out -d dominio /archivo|dir [/archivo|dir ...] dir_local

DESCRIPCIÓN

"virt-copy-out" copia archivos y directorios desde una imagen de disco de máquina virtual o un dominio libvirt con nombre.

Puede proporcionar uno o más nombres de archivo y directorios en la línea de comandos. Los directorios se copian recursivamente.

EJEMPLOS

Descargar los directorios de inicio desde una máquina virtual:

mkdir homes
virt-copy-out -d MiInvitado /home homes

SOLO UN ENVOLTORIO DE SCRIPT DE SHELL ALREDEDOR DE GUESTFISH

Este comando es solo un sencillo envoltorio de script de shell para el comando "copy-out" de guestfish(1). Para algo más complejo que una copia trivial, probablemente sea mejor usar directamente guestfish.

OPCIONES

Dado que el script de shell simplemente pasa las opciones directamente a guestfish, lea guestfish(1) para ver la lista completa de opciones.

VER TAMBIÉN

guestfish(1), virt-cat(1), virt-copy-in(1), virt-edit(1), virt-tar-in(1), virt-tar-out(1), http://libguestfs.org/.
