VGIMPORT(8) Manual del Administrador del Sistema VGIMPORT(8)

NOMBRE

vgimport — Registrar grupos de volúmenes exportados en el sistema

SINOPSIS

vgimport argumentos_opcionales argumentos_posicionales
[ argumentos_opcionales ]

DESCRIPCIÓN

vgimport hace que los VG exportados vuelvan a ser conocidos por el sistema, quizás después de mover los PV de otro sistema.

vgexport borra el ID del sistema del VG y vgimport establece el ID del sistema del VG para que coincida con el host que ejecuta vgimport (si el host tiene un ID de sistema).

USO

Importar VGs especificados.

vgimport VG|Etiqueta|Seleccionar ...

[ -S|--select Cadena ]
[ --persist start ]
[ ARGUMENTOS_COMUNES ]

—

Importar todos los VGs.

vgimport -a|--all

[ ARGUMENTOS_COMUNES ]

—

[ --reportformat basic|json|json_std ]

OPCIONES

-a|--all
Importar todos los VGs visibles.
--commandprofile Cadena
El perfil de comando a utilizar para la configuración del comando. Consulte lvm.conf(5) para obtener más información sobre los perfiles.
--config Cadena
Configuración de los ajustes para el comando. Estos anulan los ajustes de lvm.conf(5). La cadena de argumentos utiliza el mismo formato que lvm.conf(5), o puede utilizar la sintaxis de sección/campo. Consulte lvm.conf(5) para obtener más información sobre la configuración.
-d|--debug ...
Establecer el nivel de depuración. Repetir de 1 a 6 veces para aumentar el detalle de los mensajes enviados al archivo de registro y/o a syslog (si está configurado).
--devices PV
Restringe los dispositivos que son visibles y accesibles para el comando. Los dispositivos no listados parecerán faltar. Esta opción se puede repetir, o acepta una lista de dispositivos separada por comas. Esto anula el archivo de dispositivos.
--devicesfile Cadena
Un archivo que enumera los dispositivos que LVM debe utilizar. El archivo debe existir en /etc/lvm/devices/ y se gestiona con el comando lvmdevices(8). Esto anula la configuración de devices/devicesfile y devices/use_devicesfile de lvm.conf(5).
--driverloaded y|n
Si se establece en no, el comando no intentará utilizar el mapeo de dispositivos. Para pruebas y depuración.
-f|--force ...
Anular varias comprobaciones, confirmaciones y protecciones. Usar con extremo cuidado.
-h|--help
Mostrar texto de ayuda.
--journal Cadena
Registrar información en el diario de systemd. Esta información es adicional a la información habilitada por la configuración de registro/diario de lvm.conf. comando: registrar información sobre el comando. salida: registrar la salida predeterminada del comando. depuración: registrar la depuración completa del comando.
--lockopt Cadena
Se utiliza para pasar opciones para casos especiales a lvmlockd. Consulte lvmlockd(8) para obtener más información.
--longhelp
Mostrar texto de ayuda largo.
--nohints
No utilizar el archivo de pistas para localizar dispositivos para PVs. Un comando puede leer más dispositivos para encontrar PVs cuando no se utilizan pistas. El comando seguirá realizando una invalidación estándar del archivo de pistas cuando sea apropiado.
--nolocking
Desactivar el bloqueo. Usar con precaución, los comandos concurrentes pueden producir resultados incorrectos.
--persist Cadena
Operación de Reserva Persistente. start: registrar clave local y adquirir reserva. stop: anular el registro de la clave local, liberando la reserva. remove: anular y abortar otra clave. clear: eliminar la reserva y las claves. check: comprobar si se ha iniciado. autostart: iniciar si la bandera de inicio automático del VG está establecida. lvm.conf pr_key u host_id deben estar configurados para usar PR. Para VGs locales, se utiliza Write Exclusive (WE), y para VGs compartidos Write Exclusive, all registrants (WEAR) se utiliza. Usar --setpersist para automatizar y/o requerir PR.
--profile Cadena
Un alias para --commandprofile o --metadataprofile, dependiendo del comando.
-q|--quiet ...
Suprimir la salida y los mensajes de registro. Anula --debug y --verbose. Repetir una vez para suprimir también cualquier pregunta con respuesta 'no'.
--reportformat basic|json|json_std
Anula el formato de salida actual para los informes, que se define globalmente por la configuración report/output_format en lvm.conf(5). basic es el formato original con columnas y filas. Si hay más de un informe por comando, cada informe va precedido del nombre del informe para su identificación. json produce la salida del informe en formato JSON. json_std produce la salida del informe en formato JSON que cumple más con el estándar JSON. Consulte lvmreport(7) para obtener más información.
-S|--select Cadena
Selecciona objetos para su procesamiento e informe basándose en criterios especificados. La sintaxis de los criterios se describe en --select help y lvmreport(7). Para los comandos de informe, se muestra una fila por cada objeto que coincide con los criterios. Consulte --options help para ver los campos de objetos seleccionables. Las filas se pueden mostrar con un campo adicional "selected" (-o selected) que muestra 1 si la fila coincide con la selección y 0 en caso contrario. Para los comandos no informativos que procesan entidades LVM, la selección se utiliza para elegir los elementos a procesar.
-t|--test
Ejecutar en modo de prueba. Los comandos no actualizarán metadatos. Esto se implementa deshabilitando toda escritura de metadatos pero devolviendo éxito a la función que llama. Esto puede dar lugar a mensajes de error inusuales en operaciones de varias etapas si una herramienta depende de leer metadatos que cree que han cambiado pero no lo han hecho.
-v|--verbose ...
Establecer el nivel detallado. Repetir de 1 a 4 veces para aumentar el detalle de los mensajes enviados a stdout y stderr.
--version
Mostrar información de la versión.
-y|--yes
No solicitar confirmación interactivamente, sino asumir siempre la respuesta sí. Usar con extremo cuidado. (Para un no automático, ver -qq.)

VARIABLES

VG
Nombre del Grupo de Volúmenes. Ver lvm(8) para nombres válidos.
Tag
Nombre de la etiqueta. Ver lvm(8) para información sobre nombres de etiquetas y el uso de etiquetas en lugar de un VG, LV o PV.
Select
Select indica que un parámetro posicional requerido puede omitirse si se usa la opción --select. No se incluye ningún argumento en esta posición.
String
Ver la descripción de la opción para obtener información sobre el contenido de la cadena.
Size[UNIT]
Size es un número de entrada que acepta una unidad opcional. Las unidades de entrada siempre se tratan como valores de base dos, independientemente de mayúsculas/minúsculas, por ejemplo, 'k' y 'K' se refieren ambos a 1024. La unidad de entrada predeterminada se especifica mediante una letra, seguida de |UNIT. UNIT representa otras unidades de entrada posibles: b|B son bytes, s|S son sectores de 512 bytes, k|K son KiB, m|M son MiB, g|G son GiB, t|T son TiB, p|P son PiB, e|E son EiB. (Esto no debe confundirse con el control de salida --units, donde las letras mayúsculas significan múltiplos de 1000).

VARIABLES DE ENTORNO

Ver lvm(8) para obtener información sobre las variables de entorno utilizadas por lvm. Por ejemplo, LVM_VG_NAME generalmente puede sustituirse por un parámetro de VG requerido.
