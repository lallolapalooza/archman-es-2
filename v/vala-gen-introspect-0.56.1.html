VALA-GEN-INTROSPECT(1) Comandos de usuario VALA-GEN-INTROSPECT(1)

NOMBRE

vala-gen-introspect - genera un archivo GI para paquetes basados en GObject y glib

SINOPSIS

vala-gen-introspect NOMBRE_PAQUETE BASE_PAQUETE

DESCRIPCIÓN

vala-gen-introspect es una utilidad que genera archivos GI a partir de paquetes basados en GObject y glib. Puede ser utilizada en combinación con vapigen(1) para generar una API para Vala, y permitir su uso en Vala para compilar a código nativo. NOMBRE_PAQUETE es el nombre de pkg-config de la biblioteca y BASE_PAQUETE especifica el directorio base para ese paquete.

Uso:

gen-introspect [OPCIÓN?]

Opciones de ayuda:

-h, --help
Muestra las opciones de ayuda

Opciones de aplicación:

-v, --verbose
Ser verboso
-o, --output=ARCHIVO
escribir la salida aquí en lugar de stdout
-n, --namespace=ESPACIO_DE_NOMBRES
Espacio de nombres del módulo, como 'Gtk'
--shared-library=ARCHIVO
Biblioteca compartida que contiene los símbolos
--include-idl=IDL
Otras gidl a incluir

AUTORES

Jörg Billeter, Raffaele Sandrini.

EJEMPLOS

Después de la compilación, el siguiente comando genera un GI para pango: vala-gen-introspect pango paquetes/pango

Esto puede ser convertido luego a una API de Vala de la siguiente manera:
vapigen --pkg cairo --vapidir . --library pango paquetes/pango/pango.gi
