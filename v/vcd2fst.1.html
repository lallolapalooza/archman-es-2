VCD2FST(1) Conversión de tipo de archivo VCD2FST(1)

NOMBRE

vcd2fst - Convierte archivos VCD a archivos FST

SINTAXIS

vcd2fst [opción]... [ARCHIVO_VCD] [ARCHIVO_FST]

DESCRIPCIÓN

Convierte archivos VCD a archivos FST.

OPCIONES

-v,--nombrevcd <nombre_archivo>
Especifica el nombre del archivo de entrada VCD/FSDB/VPD/WLF. El procesamiento de otros tipos de archivo que no sean VCD requiere que el convertidor 2vcd apropiado se haya encontrado durante ./configure.
-f,--nombrefst <nombre_archivo>
Especifica el nombre del archivo de salida FST.
-4,--fourpack
Indica que LZ4 se usará para los datos de cambio de valor (por defecto).
-F,--fastpack
Indica que fastlz se usará en lugar de LZ4 para los datos de cambio de valor.
-Z,--zlibpack
Indica que zlib se usará en lugar de LZ4 para los datos de cambio de valor.
-c,--comprimir
Indica que el archivo completo se pasará por gzip al cerrarlo. Esto resulta en archivos mucho más pequeños a expensas de una penalización de descompresión única al abrir el archivo durante las lecturas.
-p,--paralelo
Indica que el modo paralelo debe habilitarse. Esto genera un hilo de trabajo para continuar con el procesamiento de bloques FST mientras la conversión continúa en el hilo principal para los nuevos datos de bloques FST.
-h,--ayuda
Muestra la pantalla de ayuda.

EJEMPLOS

Tenga en cuenta que debe especificar dumpfile.vcd directamente o usar "-" para la entrada estándar.

vcd2fst dumpfile.vcd dumpfile.fst --comprimir
Esto indica que el archivo FST se comprimirá después de cerrarlo.
