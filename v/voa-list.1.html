NOMBRE

voa-list - Lista todos los verificadores en VOA que coinciden con los identificadores proporcionados.

SINOPSIS

voa list [--context] [-v|--verbose]... [-q|--quiet]... [-t|--technology] [-o|--output-format] [-h|--help] <SO> <PROPÓSITO>

DESCRIPCIÓN

Lista todos los verificadores en VOA que coinciden con los identificadores proporcionados.

Por defecto, los identificadores "os" (sistema operativo) y "purpose" (propósito) deben proporcionarse para una búsqueda. Opcionalmente, el identificador "context" (contexto) y "technology" (tecnología) pueden proporcionarse para resultados de búsqueda más precisos.

OPCIONES

--contexto <CONTEXTO>
El contexto para buscar.

Si no se especifica, por defecto es "default".

También se puede especificar con la variable de entorno VOA_LIST_CONTEXT.
-v, --verbose
Aumenta la verbosidad del registro
-q, --quiet
Disminuye la verbosidad del registro
-t, --technology <TECNOLOGÍA>
La tecnología para buscar.

Actualmente solo se admite "openpgp". Si no se especifica, por defecto es "openpgp".

También se puede especificar con la variable de entorno VOA_LIST_TECHNOLOGY.
-o, --output-format <FORMATO_SALIDA> [predeterminado: text]
El formato de salida a utilizar.

Valores posibles:

  • json: El formato de salida JSON
  • text: El formato de salida de texto predeterminado
También se puede especificar con la variable de entorno VOA_LIST_OUTPUT_FORMAT.
-h, --help
Imprime la ayuda (ver un resumen con '-h')
<SO>
El sistema operativo para buscar.
También se puede especificar con la variable de entorno VOA_LIST_OS.
<PROPÓSITO>
El propósito para buscar.
También se puede especificar con la variable de entorno VOA_LIST_PURPOSE.
