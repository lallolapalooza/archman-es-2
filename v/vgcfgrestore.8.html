NOMBRE

vgcfgrestore — Restaura la configuración del grupo de volúmenes

SINOPSIS

DESCRIPCIÓN

vgcfgrestore restaura los metadatos de un VG desde un archivo de copia de seguridad de texto producido por vgcfgbackup(8). Esto escribe los metadatos del VG en los dispositivos especificados en el archivo de copia de seguridad.

Se puede especificar un archivo de copia de seguridad con --file. Si no se especifica ningún archivo de copia de seguridad, se utiliza el más reciente. Utilice --list para obtener una lista de los archivos de copia de seguridad y archivo disponibles de un VG.

ADVERTENCIA: Cuando un VG contiene pools delgados (thin pools), los cambios en los metadatos delgados no se pueden revertir y se puede producir pérdida de datos si los metadatos delgados han cambiado. Se requiere la opción force para restaurar en este caso.

USO

Restaurar metadatos del VG desde la última copia de seguridad.

vgcfgrestore VG

[ OPCIONES_COMUNES ]

—

Restaurar metadatos del VG desde un archivo específico.

vgcfgrestore -f|--file Cadena VG

[ OPCIONES_COMUNES ]

—

Listar todas las copias de seguridad de metadatos del VG.

vgcfgrestore -l|--list VG

[ OPCIONES_COMUNES ]

—

Listar un archivo de copia de seguridad de metadatos del VG.

vgcfgrestore -f|--file Cadena -l|--list

OPCIONES

--commandprofile Cadena
El perfil de comando a utilizar para la configuración del comando. Vea lvm.conf(5) para más información sobre perfiles.
--config Cadena
Configuración de ajustes para el comando. Estos anulan la configuración de lvm.conf(5). La cadena de argumento utiliza el mismo formato que lvm.conf(5), o puede usar la sintaxis de sección/campo. Vea lvm.conf(5) para más información sobre la configuración.
-d|--debug ...
Establece el nivel de depuración. Repita de 1 a 6 veces para aumentar el detalle de los mensajes enviados al archivo de registro y/o a syslog (si está configurado).
--devices PV
Restringe los dispositivos que son visibles y accesibles para el comando. Los dispositivos no listados parecerán faltar. Esta opción se puede repetir o acepta una lista de dispositivos separada por comas. Esto anula el archivo de dispositivos.
--devicesfile Cadena
Un archivo que lista los dispositivos que LVM debe utilizar. El archivo debe existir en /etc/lvm/devices/ y se gestiona con el comando lvmdevices(8). Esto anula la configuración devices/devicesfile y devices/use_devicesfile de lvm.conf(5).
--driverloaded y|n
Si se establece en no, el comando no intentará usar device-mapper. Para pruebas y depuración.
-f|--file Cadena
Lee la copia de seguridad de metadatos del archivo nombrado. Normalmente, este archivo fue creado por vgcfgbackup.
--force ...
Fuerza la restauración de metadatos incluso con LVs de thin pool. Úselo con extrema precaución. La mayoría de los cambios en los metadatos delgados no se pueden revertir. Puede perder datos si restaura metadatos que no coinciden con los metadatos del kernel del thin pool con precisión.
-h|--help
Muestra el texto de ayuda.
--journal Cadena
Registra información en el journal de systemd. Esta información se suma a la información habilitada por la configuración de registro/journal de lvm.conf. command: registra información sobre el comando. output: registra la salida predeterminada del comando. debug: registra la depuración completa del comando.
-l|--list
Lista los archivos de copia de seguridad y archivo de metadatos que pertenecen al VG. Puede usarse con --file. No restaura el VG.
--lockopt Cadena
Se utiliza para pasar opciones para casos especiales a lvmlockd. Vea lvmlockd(8) para más información.
--longhelp
Muestra el texto de ayuda largo.
-M|--metadatatype lvm2
Especifica el tipo de metadatos en disco a utilizar. lvm2 (o solo 2) es el formato actual y estándar. lvm1 (o solo 1) ya no se usa.
--nohints
No utiliza el archivo de pistas para localizar dispositivos para PVs. Un comando puede leer más dispositivos para encontrar PVs cuando no se usan las pistas. El comando aún realizará la invalidación estándar del archivo de pistas donde sea apropiado.
--nolocking
Deshabilita el bloqueo. Úselo con precaución, los comandos concurrentes pueden producir resultados incorrectos.
--profile Cadena
Un alias para --commandprofile o --metadataprofile, dependiendo del comando.
-q|--quiet ...
Suprime la salida y los mensajes de registro. Anula --debug y --verbose. Repita una vez para suprimir también cualquier solicitud con respuesta 'no'.
-t|--test
Ejecutar en modo de prueba. Los comandos no actualizarán los metadatos. Esto se implementa deshabilitando toda la escritura de metadatos pero devolviendo éxito a la función que llama. Esto puede llevar a mensajes de error inusuales en operaciones de múltiples etapas si una herramienta depende de leer metadatos que cree que han cambiado pero no lo han hecho.

OPCIONES

-v|--verbose ...
Establece el nivel de detalle. Repite de 1 a 4 veces para aumentar el nivel de detalle de los mensajes enviados a stdout y stderr.
--version
Muestra información de la versión.
-y|--yes
No pide confirmación de forma interactiva, sino que siempre asume la respuesta como sí. Usar con extrema precaución. (Para un "no" automático, ver -qq).

VARIABLES

VG
Nombre del Grupo de Volúmenes. Ver lvm(8) para nombres válidos.
String
Ver la descripción de la opción para obtener información sobre el contenido del string.
Size[UNIT]
Size es un número de entrada que acepta una unidad opcional. Las unidades de entrada siempre se tratan como valores de base dos, independientemente de la capitalización, por ejemplo, 'k' y 'K' se refieren a 1024. La unidad de entrada predeterminada se especifica con una letra, seguida de |UNIT. UNIT representa otras unidades de entrada posibles: b|B son bytes, s|S son sectores de 512 bytes, k|K son KiB, m|M son MiB, g|G son GiB, t|T son TiB, p|P son PiB, e|E son EiB. (Esto no debe confundirse con el control de salida --units, donde las letras mayúsculas significan múltiplos de 1000).

VARIABLES DE ENTORNO

Ver lvm(8) para información sobre las variables de entorno utilizadas por lvm. Por ejemplo, LVM_VG_NAME generalmente puede ser sustituido por un parámetro VG requerido.

NOTAS

Para reemplazar PVs, vgdisplay --partial --verbose mostrará los UUIDs y tamaños de cualquier PV que ya no esté presente. Si se pierde un PV en el VG y deseas sustituir otro del mismo tamaño, usa pvcreate --restorefile filename --uuid uuid (más argumentos adicionales según corresponda) para inicializarlo con el mismo UUID que el PV faltante. Repite para todos los demás PVs faltantes en el VG. Luego usa vgcfgrestore --file filename para restaurar la metadatos del VG.
