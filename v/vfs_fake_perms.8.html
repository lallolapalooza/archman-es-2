NOMBRE

vfs_fake_perms - habilita los perfiles itinerantes de solo lectura

SINOPSIS

objetos vfs = fake_perms

DESCRIPCIÓN

Este módulo VFS forma parte del conjunto de utilidades de samba(7).

El módulo VFS vfs_fake_perms fue creado para permitir que los archivos y directorios de Perfiles Itinerantes se establezcan (en el servidor Samba bajo UNIX) como solo lectura. Este módulo, si está instalado en el recurso compartido de Perfiles, informará al cliente que los archivos y directorios del Perfil son escribibles. Esto satisface al cliente a pesar de que los archivos nunca se sobrescribirán cuando el cliente cierre la sesión o se apague.

Este módulo es apilable.

EJEMPLOS

        [Perfiles]
	path = /perfiles
	objetos vfs = fake_perms
