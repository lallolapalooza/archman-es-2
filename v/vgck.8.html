VGCK(8) Manual del Administrador del Sistema VGCK(8)

NOMBRE

vgck — Comprueba la consistencia de los grupos de volúmenes

SINOPSIS

vgck argumentos_opcionales argumentos_posicionales
[ argumentos_opcionales ]
[ argumentos_posicionales ]

DESCRIPCIÓN

vgck comprueba la metadatos de LVM en busca de consistencia.

USO

Lee y muestra información sobre un VG.

vgck

[ --reportformat basic|json|json_std ]
[ OPCIONES_COMUNES ]
[ VG|Tag ... ]

—

Reescribe los metadatos del VG para corregir problemas.

vgck --updatemetadata VG

[ OPCIONES_COMUNES ]

—

Opciones comunes para lvm:

[ -d|--debug ... ]
[ -h|--help ]
[ -q|--quiet ... ]
[ -t|--test ]
[ -v|--verbose ... ]
[ -y|--yes ]
[ --commandprofile String ]
[ --config String ]
[ --devices PV ]
[ --devicesfile String ]
[ --driverloaded y|n ]
[ --journal String ]
[ --lockopt String ]
[ --longhelp ]
[ --nohints ]
[ --nolocking ]
[ --profile String ]
[ --version ]

OPCIONES

--commandprofile String
El perfil de comando a utilizar para la configuración del comando. Consulte lvm.conf(5) para obtener más información sobre los perfiles.
--config String
Configuración del comando. Estas anulan la configuración de lvm.conf(5). El argumento String utiliza el mismo formato que lvm.conf(5), o puede utilizar la sintaxis de sección/campo. Consulte lvm.conf(5) para obtener más información sobre la configuración.
-d|--debug ...
Establece el nivel de depuración. Repita de 1 a 6 veces para aumentar el detalle de los mensajes enviados al archivo de registro y/o a syslog (si está configurado).
--devices PV
Restringe los dispositivos que son visibles y accesibles para el comando. Los dispositivos no listados parecerán faltar. Esta opción se puede repetir, o acepta una lista de dispositivos separados por comas. Esto anula el archivo de dispositivos.
--devicesfile String
Un archivo que lista los dispositivos que LVM debe utilizar. El archivo debe existir en /etc/lvm/devices/ y se gestiona con el comando lvmdevices(8). Esto anula la configuración de devices/devicesfile y devices/use_devicesfile de lvm.conf(5).
--driverloaded y|n
Si se establece en no, el comando no intentará utilizar device-mapper. Para pruebas y depuración.
-h|--help
Muestra el texto de ayuda.
--journal String
Registra información en el journal de systemd. Esta información se suma a la información habilitada por la configuración lvm.conf log/journal. command: registra información sobre el comando. output: registra la salida predeterminada del comando. debug: registra la depuración completa del comando.
--lockopt String
Se utiliza para pasar opciones para casos especiales a lvmlockd. Consulte lvmlockd(8) para obtener más información.
--longhelp
Muestra el texto de ayuda largo.
--nohints
No utilice el archivo de sugerencias para localizar dispositivos para PV. Un comando puede leer más dispositivos para encontrar PV cuando no se utilizan sugerencias. El comando seguirá realizando la invalidación estándar del archivo de sugerencias cuando sea apropiado.
--nolocking
Desactiva el bloqueo. Úselo con precaución, los comandos concurrentes pueden producir resultados incorrectos.
--profile String
Un alias para --commandprofile o --metadataprofile, dependiendo del comando.
-q|--quiet ...
Suprime la salida y los mensajes de registro. Anula --debug y --verbose. Repita una vez para suprimir también cualquier pregunta con respuesta 'no'.
--reportformat basic|json|json_std
Anula el formato de salida actual para los informes, que se define globalmente mediante la configuración report/output_format en lvm.conf(5). basic es el formato original con columnas y filas. Si hay más de un informe por comando, cada informe se precede con el nombre del informe para su identificación. json produce la salida del informe en formato JSON. json_std produce la salida del informe en formato JSON que es más compatible con el estándar JSON. Consulte lvmreport(7) para obtener más información.
-t|--test
Ejecutar en modo de prueba. Los comandos no actualizarán los metadatos. Esto se implementa deshabilitando toda la escritura de metadatos pero, no obstante, devolviendo éxito a la función de llamada. Esto puede llevar a mensajes de error inusuales en operaciones de múltiples etapas si una herramienta depende de leer metadatos que cree que han cambiado pero no lo han hecho.
--updatemetadata
Actualiza los metadatos del VG para corregir problemas. Si los metadatos del VG se actualizaron mientras un PV faltaba, y el PV reaparece con una versión antigua de los metadatos, entonces esta opción (o cualquier otro comando que escriba metadatos) actualizará los metadatos en el PV que faltaba previamente. Si un PV fue eliminado de un VG mientras estaba ausente, y el PV reaparece, usar esta opción borrará los metadatos obsoletos del PV ausente previamente. Si el texto de metadatos está dañado en un PV, usar esta opción reemplazará el texto de metadatos dañado. Para daños más graves, por ejemplo con cabeceras, consulte pvck(8).
-v|--verbose ...
Establece el nivel de verbosidad. Repita de 1 a 4 veces para aumentar el detalle de los mensajes enviados a stdout y stderr.
--version
Muestra la información de la versión.
-y|--yes
No solicite confirmación interactivamente, sino que siempre asuma que la respuesta es sí. Úselo con extrema precaución. (Para un no automático, vea -qq).

VARIABLES

VG
Nombre del Grupo de Volúmenes. Consulte lvm(8) para ver nombres válidos.
Tag
Nombre de la etiqueta. Consulte lvm(8) para obtener información sobre los nombres de las etiquetas y el uso de etiquetas en lugar de un VG, LV o PV.
String
Consulte la descripción de la opción para obtener información sobre el contenido de la cadena.
Size[UNIDAD]
Size es un número de entrada que acepta una unidad opcional. Las unidades de entrada siempre se tratan como valores de base dos, independientemente de la capitalización, por ejemplo, 'k' y 'K' se refieren a 1024. La unidad de entrada predeterminada se especifica por letra, seguida de |UNIDAD. UNIDAD representa otras unidades de entrada posibles: b|B es bytes, s|S es sectores de 512 bytes, k|K es KiB, m|M es MiB, g|G es GiB, t|T es TiB, p|P es PiB, e|E es EiB. (Esto no debe confundirse con el control de salida --units, donde las letras mayúsculas significan múltiplos de 1

vgck(8) — LVM Tools 2.03.37

SYNOPSIS

vgck [VolumeGroupName...]

DESCRIPTION

vgck checks the consistency of the metadata of one or more volume groups.

The metadata of a volume group describes the physical volumes that compose it, the logical volumes it contains, and other configuration information. If the metadata becomes corrupted, LVM might not be able to access or manage the volume group and its logical volumes correctly.

vgck performs a series of checks to detect potential inconsistencies. If any issues are found, it reports them to standard output.

If no volume group names are specified on the command line, vgck will check all volume groups that are currently active on the system.

The primary purpose of vgck is to detect potential problems before they cause data loss or make the volume group unmanageable.

USAGE

To check a specific volume group:

vgck MyVolumeGroup

To check all active volume groups:

vgck

OPTIONS

This command does not support any options.

VARIABLES

See lvm(8) for information about environment variables used by lvm. For example, LVM_VG_NAME can generally be substituted for a required VG parameter.

ENVIRONMENT

See lvm(8) for information about environment variables used by lvm. For example, LVM_VG_NAME can generally be substituted for a required VG parameter.
