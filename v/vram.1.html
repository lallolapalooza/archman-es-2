vram(1) Comandos de usuario vram(1)

NOMBRE

vram - obtener la cantidad mínima de VRAM para todas las GPUs no integradas, o listar todas las GPUs

SINOPSIS

vram Muestra la cantidad mínima de VRAM disponible de todas las GPUs no integradas disponibles.

Si solo se encuentran GPUs no integradas, se utiliza la cantidad mínima de VRAM para estas en su lugar.

DESCRIPCIÓN

vram puede obtener información sobre todas las GPUs disponibles.

OPCIONES

-l o --list
Lista el ID del bus, una descripción y la VRAM disponible, para todas las GPUs.
-i o --integrated
Encuentra la cantidad mínima de VRAM para todas las GPUs, incluidas las integradas.
-V o --version
Muestra la versión actual.
