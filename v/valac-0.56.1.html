VALAC(1) Comandos de Usuario VALAC(1)

NOMBRE

valac - compilador que traduce código fuente de Vala a archivos de código fuente y cabecera C

SINOPSIS

valac [OPCIÓN]... [ARCHIVO]...

DESCRIPCIÓN

Vala es un lenguaje de programación que tiene como objetivo llevar características modernas de lenguaje de programación a los desarrolladores de GNOME sin imponer requisitos adicionales de tiempo de ejecución y sin utilizar una ABI diferente en comparación con las aplicaciones y bibliotecas escritas en C.

valac, el compilador de Vala, es un compilador autocontenido que traduce
código fuente de Vala a archivos de código fuente y cabecera C. Utiliza el sistema de tipos GObject para crear clases e interfaces declaradas en el código fuente de Vala.

Uso:

valac [OPCIÓN?] ARCHIVO... - Compilador Vala

--profile=PERFIL
Dependencia mínima de tiempo de ejecución: 'gobject' (por defecto) o 'posix' (libc mínima)
gobject habilita el sistema de tipos en tiempo de ejecución GType de GLib. El entorno de ejecución generalmente requerirá libgobject y su pequeño número de dependencias. posix elimina la dependencia de GLib y deshabilita el sistema de tipos en tiempo de ejecución. El perfil genera código alternativo o produce un error en tiempo de compilación si se utiliza una característica del lenguaje Vala que requiere el sistema de tipos en tiempo de ejecución. Esto es útil para escribir código, por ejemplo, que se dirige a microcontroladores o para utilidades de sistema o imágenes de contenedor extremadamente pequeñas. El entorno de ejecución generalmente requerirá un subconjunto pequeño de la biblioteca estándar ISO C.

--abi-stability
Habilitar soporte para la estabilidad de ABI
Esto cambia el comportamiento actual para que los miembros públicos de las clases e interfaces se muestren en el mismo orden en que aparecen en el código fuente de Vala. Para bibliotecas, se recomienda usar --abi-stability para garantizar la mantenibilidad de la Interfaz Binaria de Aplicación (ABI) resultante. Esta opción está deshabilitada por defecto por compatibilidad con versiones anteriores porque puede romper la ABI de proyectos existentes.
