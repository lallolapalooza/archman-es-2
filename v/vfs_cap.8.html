VFS_CAP(8) Herramientas de administración del sistema VFS_CAP(8)

NOMBRE

vfs_cap - Codifica nombres de archivo CAP

SINOPSIS

objetos vfs = cap

DESCRIPCIÓN

Este módulo VFS forma parte del conjunto samba(7).

La codificación CAP (Columbia Appletalk Protocol) es una técnica para representar nombres de archivo no ASCII en ASCII. El módulo VFS vfs_cap traduce nombres de archivo al formato CAP y viceversa, permitiendo a los usuarios nombrar archivos en su codificación nativa.

La codificación CAP se utiliza comúnmente en entornos de idioma japonés.

Este módulo puede apilarse.

EJEMPLOS

En un sistema que utiliza GNU libiconv, utilice la codificación CAP para dar soporte a usuarios en la configuración regional Shift_JIS:

        [global]
	dos charset = CP932
	vfs objects = cap
