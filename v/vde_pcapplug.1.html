VDE_PCAPPLUG(1) Manual de Comandos Generales VDE_PCAPPLUG(1)

NOMBRE

vde_pcapplug - Cable libpcap de conector VDE

SINOPSIS

vde_pcapplug [OPCIÓN]... interfaz

DESCRIPCIÓN

vde_pcapplug es un conector para ser conectado a un switch VDE. Todos los datos que son capturados por el conector se inyectan en la interfaz y todo lo que proviene de esa interfaz se envía al switch.

OPCIONES

-p, --puerto=num_puerto
Es posible decidir qué puerto del switch usar. Cuando esta opción no se especifica, el switch asigna el primer puerto libre disponible (si lo hay). Es posible conectar varios cables al mismo puerto del switch: de esta forma, todos estos cables trabajan concurrentemente. Significa que los paquetes pueden resultar duplicados, pero no se generan bucles en la tabla ARP. Es útil cuando vde se usa para movilidad. Se pueden usar varias interfaces físicas a la vez durante las transiciones para evitar cortes en la conectividad.
-g, --grupo=grupo
Propiedad del grupo del socket de comunicación. Por seguridad, cuando varios quieren compartir un switch, es mejor usar un grupo de Unix para poseer los sockets de comunicación, de modo que el tráfico de red no pueda ser interceptado.
-m, --modo=modo_octal
Permisos tipo chmod octal para los sockets de comunicación
-s, --socket=socket
especifica el socket UNIX a ser usado por programas locales para unirse al VDE. El valor predeterminado es "/tmp/vde.ctl".
-d, --demonio
inicia vde_plug2tap como un proceso en segundo plano
-P, --pidfile=archivo_pid
coloca el ID de proceso de vde_plug2tap en archivo_pid. Puede ser usado con --demonio para almacenar el PID para matarlo en el futuro.
-h, --ayuda
muestra una breve ayuda
