VCDXBUILD(1) Comandos de usuario VCDXBUILD(1)

NOMBRE

vcdxbuild - página del manual para vcdxbuild 2.0.0

SINOPSIS

vcdxbuild [OPCIÓN...] <archivo-de-control-xml>

DESCRIPCIÓN

-i, --tipo-imagen=TIPO
especificar el tipo de imagen para la salida (predeterminado: 'bincue')
-o, --opcion-imagen=CLAVE=VALOR
especificar opción de imagen
-c, --archivo-cue=ARCHIVO
especificar archivo cue para la salida (predeterminado: 'videocd.cue')
-b, --archivo-bin=ARCHIVO
especificar archivo bin para la salida (predeterminado: 'videocd.bin')
--archivo-cdrdao=ARCHIVO
especificar base del nombre de archivo de imagen estilo cdrdao
--sector-2336
usar sectores de 2336 bytes para la salida
-T, --fecha-creacion=CADENA
especificar la fecha de creación en los archivos de la imagen CD (predeterminado: fecha actual)
-p, --progreso
mostrar progreso
--volcar-dtd
volcar DTD interno a stdout
--codificacion-nombre-archivo=CADENA
usar la codificación de juego de caracteres dada para los nombres de archivo en lugar de UTF8
-v, --verbose
ser detallado
-q, --quieto
mostrar solo mensajes críticos
--gui
habilitar modo GUI
-V, --version
mostrar información de versión y derechos de autor y salir

Opciones de ayuda:

-?, --help
Mostrar este mensaje de ayuda
--uso
Mostrar mensaje de uso breve
