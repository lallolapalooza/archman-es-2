VMOD_PROXY(3) Manual de funciones de biblioteca VMOD_PROXY(3)

NOMBRE

vmod_proxy - Módulo de Varnish para extraer atributos TLV de PROXYv2

SINOPSIS

import proxy [as nombre] [from "ruta"]
STRING alpn()
STRING authority()
BOOL is_ssl()
BOOL client_has_cert_sess()
BOOL client_has_cert_conn()
INT ssl_verify_result()
STRING ssl_version()
STRING client_cert_cn()
STRING ssl_cipher()
STRING cert_sign()
STRING cert_key()

DESCRIPCIÓN

vmod_proxy contiene funciones para extraer atributos TLV de proxy-protocol-v2 tal como se describe en
https://www.haproxy.org/download/1.8/doc/proxy-protocol.txt .

STRING alpn()

Extrae el atributo ALPN.

Ejemplo:

set req.http.alpn = proxy.alpn();

Restringido a: client.

STRING authority()

Extrae el atributo de autoridad. Esto corresponde al SNI de una conexión TLS.

Ejemplo:

set req.http.authority = proxy.authority();

Restringido a: client.

BOOL is_ssl()

Informa si proxy-protocol-v2 tiene TLV SSL.

Ejemplo:

if (proxy.is_ssl()) {
        set req.http.ssl-version = proxy.ssl_version();
}

Restringido a: client.

BOOL client_has_cert_sess()

Informa si el cliente proporcionó un certificado al menos una vez durante la sesión TLS a la que pertenece esta conexión.

Restringido a: client.

BOOL client_has_cert_conn()

Informa si el cliente proporcionó un certificado durante la conexión actual.

Restringido a: client.

INT ssl_verify_result()

Informa el resultado de SSL_get_verify_result de una sesión TLS. Solo tiene importancia si client_has_cert_sess() es verdadero. Por defecto, el valor se establece en 0 (X509_V_OK).

Ejemplo:

if (proxy.client_has_cert_sess() && proxy.ssl_verify_result() == 0) {
        set req.http.ssl-verify = "ok";
}

Restringido a: client.

STRING ssl_version()

Extrae el atributo de versión SSL.

Ejemplo:

set req.http.ssl-version = proxy.ssl_version();

Restringido a: client.

STRING client_cert_cn()

Extrae el atributo del nombre común del certificado del cliente.

Ejemplo::
set req.http.cert-cn = proxy.client_cert_cn();

Restringido a: client.

STRING ssl_cipher()

Extrae el atributo del cifrado SSL.

Ejemplo:

set req.http.ssl-cipher = proxy.ssl_cipher();

Restringido a: client.

STRING cert_sign()

Extrae el atributo del algoritmo de firma del certificado.

Ejemplo:

set req.http.cert-sign = proxy.cert_sign();

Restringido a: client.

STRING cert_key()

Extrae el atributo del algoritmo de clave del certificado.

Ejemplo:

set req.http.cert-key = proxy.cert_key();

Restringido a: client.
