NOMBRE

vfs_linux_xfs_sgid - Solución alternativa para el bit sgid de XFS no heredado

SINOPSIS

objetos vfs = linux_xfs_sgid

DESCRIPCIÓN

Este módulo VFS es parte del conjunto de utilidades de samba(7).

vfs_linux_xfs_sgid es un módulo VFS para solucionar un antiguo error de XFS en Linux, corregido en la versión 3.11: el bit SGID no se hereda durante mkdir cuando se establece un ACL predeterminado (https://web.archive.org/web/20160320180937/http://oss.sgi.com/bugzilla/show_bug.cgi?id=280 corregido por https://git.kernel.org/pub/scm/linux/kernel/git/torvalds/linux.git/commit/?id=42c49d7f249c2487f36d3314753d5d8ebcee8249). El módulo VFS vfs_linux_xfs_sgid solucionará este error estableciendo manualmente el bit SGID después de un mkdir si el directorio padre tenía el bit SGID establecido.

Este módulo es apilable.

EJEMPLOS

Agregar la funcionalidad linux_xfs_sgid para [share]:

        [share]
	vfs objects = linux_xfs_sgid
