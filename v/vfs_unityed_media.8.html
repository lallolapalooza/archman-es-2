VFS_UNITYED_MEDIA(8) Herramientas de administración del sistema VFS_UNITYED_MEDIA(8)

NOMBRE

vfs_unityed_media - Permite que múltiples clientes Avid compartan una unidad de red.

SINOPSIS

objetos vfs = unityed_media

DESCRIPCIÓN

Este módulo VFS forma parte del conjunto samba(7).

Unityed Media está relacionado con Media Harmony VFS, la diferencia principal entre Unityed Media y Media Harmony es que Unityed Media no necesita refresco manual de los directorios de medios. Unityed Media maneja tus archivos multimedia de manera similar a como lo hacen Unity, ISIS, EditShare u otra solución dedicada. Sin aplicación del lado del cliente y en el hardware de tu elección.

Este módulo es apilable.

CONFIGURACIÓN

Si clientes Avid de Mac y Windows accederán a la misma carpeta, se les deben dar definiciones de compartición separadas, con los archivos ocultos de Mac vetados en la compartición de Windows. Ver EJEMPLOS.

OPCIONES

unityed_media:clientid = usuario | nombrehost | ip

Controla qué identificador relacionado con el cliente se añade a las rutas específicas del usuario:
•usuario (por defecto) - utiliza el nombre de usuario.
•nombrehost - utiliza el nombre del host. Nota: esto no funcionará con clientes OS X ya que estos siempre envían una cadena genérica ("workstation") al servidor.
•ip - utiliza la dirección IP del cliente. NOTA: esto no ha sido probado y puede que no funcione en absoluto.

EJEMPLOS

Habilitar unityed_media para clientes Mac y Windows:

        [avid_mac]
	ruta = /avid
	objetos vfs = unityed_media
        [avid_win]
	ruta = /avid
	objetos vfs = unityed_media
	vetar archivos = /.DS_Store/._@/.Trash@/.Spotlight@/.hidden/.hotfiles@/.vol/
	eliminar archivos vetados = sí
