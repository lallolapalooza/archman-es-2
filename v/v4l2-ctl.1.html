V4L2-CTL(1) Comandos de usuario V4L2-CTL(1)

NOMBRE

v4l2-ctl - Una aplicación para controlar los controladores de video4linux

SINOPSIS

v4l2-ctl [-h] [-d <dispositivo>] [muchas otras opciones]

DESCRIPCIÓN

La herramienta v4l2-ctl se utiliza para controlar dispositivos video4linux, ya sean de video, vbi, radio o swradio, tanto de entrada como de salida. Es capaz de controlar casi cualquier aspecto de dichos dispositivos, cubriendo la API completa de V4L2.

OPCIONES

-A, --list-devices
Lista todos los dispositivos v4l. Si se especificó -z, entonces lista solo los dispositivos del dispositivo multimedia con la cadena de información del bus especificada por la opción -z.
-d, --device <dispositivo>
Usa el dispositivo <dispositivo> como dispositivo V4L2. Si <dispositivo> comienza con un dígito, entonces se usa /dev/video<dispositivo>. De lo contrario, si se especificó -z anteriormente, entonces <dispositivo> es el nombre de la entidad o el ID de la interfaz (si está prefijado con 0x) tal como se encuentra en la topología del dispositivo multimedia con la cadena de información del bus especificada por la opción -z.
-v, --verbose
Activa la notificación detallada.
--version
Muestra la información de la versión.
-w, --wrapper
Utiliza la biblioteca de envoltura libv4l2 para todos los accesos al dispositivo V4L2. Por defecto, v4l2-ctl accederá directamente al dispositivo V4L2, pero con esta opción, todo el acceso pasará a través de esta biblioteca de envoltura.
-h, --help
Imprime el mensaje de ayuda.
--help-io
Imprime el mensaje de ayuda para todas las opciones que obtienen/establecen/listan entradas y salidas, tanto de video como de audio.
--help-meta
Imprime el mensaje de ayuda para todas las opciones que obtienen/establecen/listan formatos de metadatos.
--help-misc
Imprime el mensaje de ayuda para opciones misceláneas.
--help-overlay
Imprime el mensaje de ayuda para todas las opciones que obtienen/establecen/listan formatos de superposición y framebuffer.
--help-sdr
Imprime el mensaje de ayuda para todas las opciones que obtienen/establecen/listan formatos de radio definida por software.
--help-selection
Imprime el mensaje de ayuda para todas las opciones que manejan selecciones (recorte y composición).
--help-stds
Imprime el mensaje de ayuda para todas las opciones que manejan estándares SDTV y tiempos de video digital.
--help-streaming
Imprime el mensaje de ayuda para todas las opciones que manejan streaming.
--help-subdev
Imprime el mensaje de ayuda para todas las opciones que manejan dispositivos v4l-subdevX.
--help-tuner
Imprime el mensaje de ayuda para todas las opciones que manejan sintonizadores y moduladores.
--help-vbi
Imprime el mensaje de ayuda para todas las opciones que obtienen/establecen/listan formatos VBI.
--help-vidcap
Imprime el mensaje de ayuda para todas las opciones que obtienen/establecen/listan formatos de captura de video.
--help-vidout
Imprime el mensaje de ayuda para todas las opciones que obtienen/establecen/listan formatos de salida de video.
--help-edid
Imprime el mensaje de ayuda para todas las opciones que obtienen/establecen EDIDs.
--help-all
Imprime el mensaje de ayuda para todas las opciones.
--all
Muestra toda la información disponible.
-C, --get-ctrl <ctrl>[,<ctrl>...]
Obtiene el valor de los controles [VIDIOC_G_EXT_CTRLS].
-c, --set-ctrl <ctrl>=<val>[,<ctrl>=<val>...]
Establece el valor de los controles [VIDIOC_S_EXT_CTRLS].
-D, --info
Muestra información del controlador [VIDIOC_QUERYCAP].
-e, --out-device <dispositivo>
Usa el dispositivo <dispositivo> para flujos de salida en lugar del dispositivo predeterminado establecido con --device. Si <dispositivo> comienza con un dígito, entonces se usa /dev/video<dispositivo>. De lo contrario, si se especificó -z anteriormente, entonces <dispositivo> es el nombre de la entidad o el ID de la interfaz (si está prefijado con 0x) tal como se encuentra en la topología del dispositivo multimedia con la cadena de información del bus especificada por la opción -z.
-E, --export-device <dispositivo>
Usa el dispositivo <dispositivo> para exportar búferes DMA. Si <dispositivo> comienza con un dígito, entonces se usa /dev/video<dispositivo>. De lo contrario, si se especificó -z anteriormente, entonces <dispositivo> es el nombre de la entidad o el ID de la interfaz (si está prefijado con 0x) tal como se encuentra en la topología del dispositivo multimedia con la cadena de información del bus especificada por la opción -z.
-z, --media-bus-info <info-bus>
Busca el dispositivo multimedia con la cadena <info-bus> dada. Si se establece, entonces las opciones -d, -e y -E pueden usar el nombre de la entidad o el ID de la interfaz para referirse a los nodos del dispositivo. Ejemplo: v4l2-ctl -z platform:vivid-000 -d vivid-000-vid-cap
-k, --concise
Sé más conciso si es posible.
-l, --list-ctrls
Muestra todos los controles y sus valores [VIDIOC_QUERYCTRL].
-L, --list-ctrls-menus
Muestra todos los controles y sus menús [VIDIOC_QUERYMENU].
-r, --subset <ctrl>[,<offset>,<size>]+
El subconjunto del array N-dimensional para obtener/establecer para el control <ctrl>, para cada dimensión se da una tupla de (<offset>, <size>).
--list-devices-input <nombre>
Igual que --list-devices, pero solo muestra dispositivos con un nombre de entrada actual que coincida con <nombre>.
--list-devices-output <nombre>
Igual que --list-devices, pero solo muestra dispositivos con un nombre de salida actual que coincida con <nombre>.
--log-status
Registra el estado de la placa en el registro del kernel [VIDIOC_LOG_STATUS].
--get-priority
Consulta la prioridad de acceso actual [VIDIOC_G_PRIORITY].
--set-priority <prio>
Establece la nueva prioridad de acceso [VIDIOC_S_PRIORITY]. <prio> es 1 (fondo), 2 (interactivo) o 3 (grabación).
--silent
Solo establece el código de resultado, no imprime ningún mensaje.
--sleep <segundos>
Espera <segundos>, llama a QUERYCAP y cierra el manejador de archivo.

ESTADO DE SALIDA

En caso de éxito, devuelve 0. De lo contrario, devolverá el código de error.

EJEMPLOS

Consulta la información del dispositivo /dev/video1:

v4l2-ctl -d1 -D

Transmite video usando E/S de flujo MMAP desde /dev/video0:

v4l2-ctl -d0 --stream-mmap

Transmite un fotograma de v

v4l2-ctl(1) - Arch Linux

NAME

v4l2-ctl - videodev2 control utility

SYNOPSIS

v4l2-ctl [options]

DESCRIPTION

The v4l2-ctl utility can be used to query and control video capture devices that conform to the Video4Linux API.

This utility can be used to:

  • Query capabilities, controls, formats, etc.
  • Set controls (e.g. brightness, contrast, hue, etc.).
  • Set the video format.
  • Stream video.

OPTIONS

A full list of options can be found in the man page.

Commonly used options include:

-d, --device <device>
Use video device <device>.
-l, --list-controls
List available controls.
-L, --list-ctrls-range
List available controls with their ranges.
-g, --get-ctrl <name>
Get the value of control <name>.
-s, --set-ctrl <name>=<value>
Set control <name> to <value>.
-V, --get-fmt-video
Get the current video capture format.
-s, --set-fmt-video <fmt>
Set the video capture format.
--stream-mmap
Use memory mapping for streaming.
--stream-to <filename>
Stream video to <filename>.
--stream-count <count>
Number of frames to stream.
--stream-to-host <hostname>
Stream video to <hostname>.
--stream-dmabuf
Use DMABUFs for streaming.
--export-device <device>
Export DMABUFs from <device>.
--stream-out-mmap
Use memory mapping for output streaming.
--out-device <device>
Use output video device <device>.
--stream-out-dmabuf
Use DMABUFs for output streaming.

EXIT STATUS

Returns 0 on success, or a non-zero value if an error occurred.

EXAMPLES

Stream video from /dev/video0 and store it in a file:

v4l2-ctl --stream-mmap --stream-count=1 --stream-to=file.raw

Stream video from /dev/video0 and stream it over the network:

v4l2-ctl --stream-mmap --stream-to-host <hostname>

Use 'qvidcap -p' on the host to view the video.

Stream video from /dev/video0 using DMABUFs exported from /dev/video2:

v4l2-ctl --stream-dmabuf --export-device /dev/video2

Stream video from a memory-to-memory device:

v4l2-ctl --stream-mmap --stream-out-mmap

Stream video from a capture video device (/dev/video1) to an output video device (/dev/video2):

v4l2-ctl -d1 --stream-mmap --out-device /dev/video2 --stream-out-dmabuf
