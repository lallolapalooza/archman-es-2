VCDIMAGER(1) Comandos de Usuario VCDIMAGER(1)

NOMBRE

vcdimager - página del manual para vcdimager 2.0.0

SINOPSIS

vcdimager [OPCIÓN...] <archivos-mpeg...>

DESCRIPCIÓN

-t, --type=TIPO
seleccionar tipo de VideoCD ('vcd11', 'vcd2', 'svcd' o 'hqvcd') (por defecto: 'vcd2')
-c, --cue-file=ARCHIVO
especificar archivo cue para la salida (por defecto: 'videocd.cue')
-b, --bin-file=ARCHIVO
especificar archivo bin para la salida (por defecto: 'videocd.bin')
-l, --iso-volume-label=ETIQUETA
especificar etiqueta de volumen ISO para el video cd (por defecto: 'VIDEOCD')
--iso-application-id=ETIQUETA
especificar id de aplicación ISO para el video cd (por defecto: '')
--info-album-id=ETIQUETA
especificar id de álbum para el conjunto de video cd (por defecto: '')
--volume-count=NÚMERO
especificar número de volúmenes en el conjunto de álbumes
--volume-number=NÚMERO
especificar número de secuencia del conjunto de álbumes (< volume-count)
--broken-svcd-mode
habilitar modo de compatibilidad no conforme para dispositivos defectuosos
--update-scan-offsets
actualizar desplazamientos de datos de escaneo en el stream mpeg2 de video
--sector-2336
usar sectores de 2336 bytes para la salida
--add-dir=NOMBRE_DIR_ISO
añadir directorio vacío al sistema de archivos ISO
--add-file=ARCHIVO,NOMBRE_ARCHIVO_ISO
añadir archivo único al sistema de archivos ISO
--add-file-2336=ARCHIVO,NOMBRE_ARCHIVO_ISO
añadir archivo que contiene sectores completos de 2336 bytes al sistema de archivos ISO
-T, --create-time=CADENA
especificar fecha de creación en los archivos de la imagen del CD (por defecto: fecha actual)
-v, --verbose
ser detallado
-q, --quiet
mostrar solo mensajes críticos
-V, --version
mostrar información de versión y derechos de autor y salir

Opciones de ayuda:

-?, --help
Mostrar este mensaje de ayuda
--usage
Mostrar mensaje de uso breve
