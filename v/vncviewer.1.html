NOMBRE

vncviewer - Visor VNC para X

SINOPSIS

vncviewer [opciones] [host][:display#]
vncviewer [opciones] [host][::puerto]
vncviewer [opciones] [socket Unix]
vncviewer [opciones] -listen [puerto]
vncviewer [opciones] [archivo .tigervnc]

DESCRIPCIÓN

vncviewer es un visor (cliente) para Virtual Network Computing. Esta página del manual documenta la versión 4 para el sistema de ventanas X.

Si ejecuta el visor sin argumentos, le pedirá un servidor VNC al que conectarse. Alternativamente, especifique el servidor VNC como un argumento, por ejemplo:

vncviewer snoopy:2

donde 'snoopy' es el nombre de la máquina y '2' es el número de pantalla del servidor VNC en esa máquina. Se puede omitir tanto el nombre de la máquina como el número de pantalla. Por ejemplo, ":1" significa pantalla número 1 en la misma máquina, y "snoopy" significa "snoopy:0", es decir, pantalla 0 en la máquina "snoopy".

Otra forma rápida de iniciar una conexión a un servidor VNC es especificar un archivo de configuración .tigervnc como argumento para el visor, por ejemplo:

vncviewer ./alguno.tigervnc

donde './alguno.tigervnc' es un archivo de configuración de TigerVNC válido y existente. El nombre del archivo debe incluir un separador de ruta. También se pueden proporcionar opciones adicionales, pero el archivo de configuración dado sobrescribirá cualquier parámetro conflictivo.

Si se contacta con el servidor VNC con éxito, se le pedirá una contraseña para autenticarle. También puede añadir 'VNC_USERNAME' y 'VNC_PASSWORD' a las variables de entorno. Si la contraseña es correcta, aparecerá una ventana mostrando el escritorio del servidor VNC.

SELECCIÓN AUTOMÁTICA DE PROTOCOLO

El visor prueba la velocidad de la conexión con el servidor y elige la codificación y el formato de píxeles (nivel de color) apropiadamente. Esto lo hace mucho más fácil de usar que las versiones anteriores, donde el usuario tenía que especificar argumentos crípticos en la línea de comandos.

El visor normalmente empieza asumiendo que el enlace es lento, utilizando la codificación con la mejor compresión. Si resulta que el enlace es lo suficientemente rápido, cambia a una codificación que comprime menos pero es más rápida de generar, mejorando así la sensación interactiva.

El visor normalmente empieza en modo de color completo, pero cambia a modo de color bajo si el ancho de banda es insuficiente. Sin embargo, esto solo ocurre al comunicarse con servidores que soportan el protocolo 3.8 o más reciente, ya que muchos servidores antiguos no soportan cambios de modo de color de forma segura.

La selección automática se puede desactivar estableciendo el parámetro AutoSelect a falso, o desde el diálogo de opciones.

MENÚ DESPLEGABLE

El visor tiene un menú desplegable que contiene entradas que realizan varias acciones. Normalmente se invoca presionando F8, pero esto se puede configurar con el parámetro MenuKey. Las acciones que el menú desplegable puede realizar incluyen:

  • cambiar al modo de pantalla completa y salir de él
  • salir del visor
  • generar eventos de teclado, por ejemplo, enviar ctrl-alt-supr
  • acceder al diálogo de opciones y varios otros diálogos

Por defecto, las pulsaciones de teclas en el menú desplegable se envían al servidor VNC y cierran el menú. Por lo tanto, para que una F8 llegue al servidor VNC, simplemente presiónela dos veces.

MODO DE PANTALLA COMPLETA

Se soporta un modo de pantalla completa. Esto es particularmente útil al conectarse a una pantalla remota del mismo tamaño que la local. Si la pantalla remota es más grande, puede desplazarse chocando el ratón contra el borde de la pantalla.

OPCIONES (PARÁMETROS)

Puede obtener una lista de parámetros proporcionando -h como opción de línea de comandos a vncviewer. Los parámetros se pueden activar con -param o desactivar con -param=0. Los parámetros que toman un valor se pueden especificar como -param valor. Otras formas válidas son param=valor -param=valor --param=valor. Los nombres de los parámetros no distinguen mayúsculas de minúsculas.

Muchos de los parámetros también se pueden configurar gráficamente a través del cuadro de diálogo de opciones. Se puede acceder a él desde el menú desplegable o desde el cuadro de diálogo de "Detalles de la conexión".

-AcceptClipboard
Aceptar cambios del portapapeles del servidor. Por defecto está activado.
-AlertOnFatalError
Mostrar un diálogo con cualquier error fatal antes de salir. Por defecto está activado.
-AlwaysCursor
Mostrar un cursor local cuando el servidor envía un cursor invisible. Por defecto está desactivado.
-AutoSelect
Utilizar selección automática de codificación y formato de píxeles (por defecto está activado). Normalmente el visor prueba la velocidad de la conexión con el servidor y elige la codificación y el formato de píxeles apropiadamente. Desactívelo con -AutoSelect=0.
-CompressLevel nivel
Utilizar el nivel de compresión sin pérdidas especificado. 0 = Bajo, 9 = Alto. Por defecto es 2.
-CursorType tipo
Especificar qué tipo de cursor utilizar cuando se muestra un cursor local. Debe ser "Dot" o "System". Se ignora si AlwaysCursor está desactivado. El valor por defecto es "Dot".
-CustomCompressLevel
Utilizar nivel de compresión personalizado. Por defecto si se especifica CompressLevel.
-DesktopSize anchoxalto
En lugar de mantener el tamaño de pantalla remoto existente, el cliente intentará cambiar al tamaño especificado al conectarse. Si el servidor no soporta el mensaje SetDesktopSize, la pantalla conservará el tamaño original.
-display pantallaX
Especifica la pantalla X en la que debe aparecer la ventana del visor VNC.
-DotWhenNoCursor (OBSOLETO)
Mostrar el cursor de punto cuando el servidor envía un cursor invisible. Reemplazado por -AlwaysCursor y -CursorType=Dot
-EmulateMiddleButton
Emular el botón central del ratón presionando los botones izquierdo y derecho simultáneamente. Por defecto está desactivado.
-FullColor, -FullColour
Indica al servidor VNC que envíe píxeles a todo color en el mejor formato para esta pantalla. Esto es lo predeterminado.
-FullScreen
Iniciar en modo de pantalla completa.
-FullScreenAllMonitors (OBSOLETO)
Utilizar todos los monitores locales y no solo el actual al cambiar a modo de pantalla completa. Reemplazado por -FullScreenMode=all
-FullScreenMode modo
Especificar qué monitores utilizar en pantalla completa. Debe ser "Current", "Selected" (especificado por -FullScreenSelectedMonitors) o "All". El valor por defecto es "Current".
-FullScreenSelectedMonitors monitores
Esta opción especifica los monitores a utilizar con -FullScreenMode=selected. Los monitores se ordenan según la configuración del sistema de izquierda a derecha y, en caso de conflicto, de arriba a abajo. Por lo tanto, por ejemplo, "1,2,3" significa que se deben utilizar el primer, segundo y tercer monitor contando desde la izquierda. El valor por defecto es "1".
-FullscreenSystemKeys

OPTIONS

-AltGr
Pass AltGr key combinations directly to the server.
-AutoRepeat
Enable auto-repeat of keys. Default is on.
-AutoSelect
Automatically select the best encoding to use, by detecting whether the server supports the various encodings. Default is on.
-ColorDepth depth
Request the server to use a specific color depth (e.g. 8, 16, 24, 32). Note that the server may not be able to support the requested depth.
-connect host[:port]
Connect to a VNC server running on the specified host and port. If port is not specified, the default port 5900 is used. This option is a shortcut for specifying the host and port on the command line.
-debug
Enable debugging output. This is equivalent to -Log *:stderr:100.
-Dnd, -DropNotifications
Enable drag-and-drop support for text and files. This requires vncconfig to be running on the server side. Default is on.
-EnableFileStore
Enable file transfer via the clipboard. Default is on.
-Encoding encoding
This option specifies the encoding to use from one of "Tight", "Zlib", "ZRLE", "hextile" or "raw". The default is to try and auto-select the best encoding.
-EnableShare
Enable sharing of the remote desktop. This allows multiple clients to connect to the same desktop session. Default is on.
-FullColor, -FullColour
Use 24-bit color (16.7 million colors). This is the default.
-FullWindow
Make the viewer window fill the entire screen, without any window borders or decorations.
-fullscreen
Pass special keys (like Alt+Tab) directly to the server when in full-screen mode.
-geometry geometry
Initial position of the main VNC viewer window. The format is widthxheight+xoffset+yoffset , where `+' signs can be replaced with `-' signs to specify offsets from the right and/or from the bottom of the screen. Offsets are optional and the window will be placed by the window manager by default.
-GnuTLSPriority priority
GnuTLS priority string that controls the TLS session’s handshake algorithms. See the GnuTLS manual for possible values. Default is NORMAL.
-listen [port]
Causes vncviewer to listen on the given port (default 5500) for reverse connections from a VNC server. WinVNC supports reverse connections initiated using the 'Add new client' menu option or the '-connect' command-line option. Xvnc supports reverse connections with a helper program called vncconfig.
-Log logname:dest:level[, ...]
Configures the debug log settings. dest can currently be stderr or stdout, and level is between 0 and 100, 100 meaning most verbose output. logname is usually * meaning all, but you can target a specific source file if you know the name of its "LogWriter". Default is *:stderr:30.
-LowColorLevel, -LowColourLevel level
Selects the reduced color level to use on slow links. level can range from 0 to 2, 0 meaning 8 colors, 1 meaning 64 colors (the default), 2 meaning 256 colors. Note that decision if reduced color level is used is made by vncviewer. If you would like to force vncviewer to use reduced color level use -AutoSelect=0 parameter.
-MaxCutText bytes
The maximum size of a clipboard update that will be accepted from a server. Default is 262144.
-Maximize
Maximize viewer window.
-MenuKey keysym-name
This option specifies the key which brings up the popup menu. The currently supported list is: F1, F2, F3, F4, F5, F6, F7, F8, F9, F10, F11, F12, Pause, Scroll_Lock, Escape, Insert, Delete, Home, Page_Up, Page_Down). Default is F8.
-NoJpeg
Disable lossy JPEG compression in Tight encoding. Default is off.
-passwd, -PasswordFile password-file
If you are on a filesystem which gives you access to the password file used by the server, you can specify it here to avoid typing it in. It will usually be $XDG_CONFIG_HOME/tigervnc/passwd, or ~/.config/tigervnc/passwd if the former is unset.
-PointerEventInterval time
Time in milliseconds to rate-limit successive pointer events. Default is 17 ms (60 Hz).
-PreferredEncoding encoding
This option specifies the preferred encoding to use from one of "Tight", "ZRLE", "hextile" or "raw".
-QualityLevel level
JPEG quality level. 0 = Low, 9 = High. May be adjusted automatically if -AutoSelect is turned on. Default is 8.
-ReconnectOnError
Display a dialog with any error and offer the possibility to retry establishing the connection. In case this is off no dialog to re-connect will be offered. Default is on.
-RemoteResize
Dynamically resize the remote desktop size as the size of the local client window changes. Note that this may not work with all VNC servers.
-SecurityTypes sec-types
Specify which security schemes to attempt to use when authenticating with the server. Valid values are a comma separated list of None, VncAuth, Plain, TLSNone, TLSVnc, TLSPlain, X509None, X509Vnc, X509Plain, RA2, RA2ne, RA2_256 and RA2ne_256. Default is to attempt every supported scheme.
-SendClipboard
Send clipboard changes to the server. Default is on.
-SendPrimary
Send the primary selection to the server as well as the clipboard selection. Default is on.
-SetPrimary
Set the primary selection as well as the clipboard selection. Default is on.
-Shared
When you make a connection to a VNC server, all other existing connections are normally closed. This option requests that they be left open, allowing you to share the desktop with someone already using it.
-UseIPv4
Use IPv4 for incoming and outgoing connections. Default is on.
-UseIPv6
Use IPv6 for incoming and outgoing connections. Default is on.
-via gateway
Automatically create encrypted TCP tunnel to the gateway machine before connection, connect to the host through that tunnel (TigerVNC-specific). By default, this option invokes SSH local port forwarding, assuming that SSH client binary can be accessed as /usr/bin/ssh. Note that when using the -via option, the host machine name should be specified as known to the gateway machine, e.g. "localhost" denotes the gateway, not the machine where vncviewer was launched. The environment variable VNC_VIA_CMD can override the default tunnel command of /usr/bin/ssh -f -L "$L":"$H":"$R" "$G" sleep 20. The tunnel command is executed with the environment variables L, H, R, and G taking the values of the local port number, the remote host, the port number on the remote host, and the gateway machine respectively.
-ViewOnly
Specifies that no keyboard or mouse events should be sent to the server. Useful if you want to view a desktop without interfering; often needs to be combined with -Shared.
-X509CA path
Path to CA certificate to use when authenticating remote servers using any of the X509 security schemes (X509None, X509Vnc, etc.). Must be in PEM format. Default is $XDG_CONFIG_HOME/tigervnc/x509_ca.pem, or ~/.config/tigervnc/x509_ca.pem.
-X509CRL path
Path to certificate revocation list to use in conjunction with -X509CA. Must also be in PEM format. Default is $XDG_CONFIG_HOME/tigervnc/x509_crl.pem, or ~/.config/tigervnc/x509_crl.pem.
