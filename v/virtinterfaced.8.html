Nombre

virtinterfaced - demonio de gestión de interfaces de red de host libvirt

SINOPSIS

virtinterfaced [OPCIÓN]...

DESCRIPCIÓN

El programa virtinterfaced es un componente demonio del lado del servidor del sistema de gestión de virtualización libvirt.

Es una de las colecciones de demonios modulares que reemplazan la funcionalidad proporcionada anteriormente por el demonio monolítico libvirtd.

Este demonio se ejecuta en hosts de virtualización para proporcionar gestión de las interfaces de red del host.

El demonio virtinterfaced solo escucha solicitudes en un socket de dominio Unix local. El acceso remoto a través de TLS/TCP y la compatibilidad retroactiva con clientes heredados que esperan libvirtd son proporcionados por el demonio virtproxyd.

Reiniciar virtinterfaced no interrumpe las máquinas virtuales en ejecución. Las máquinas virtuales continúan operando y los cambios en su estado generalmente se capturarán automáticamente durante el inicio. No obstante, se recomienda evitar reiniciar con máquinas virtuales en ejecución siempre que sea práctico.

MODOS DE INICIO DEL DEMONIO

El demonio virtinterfaced es capaz de iniciarse en dos modos.

Modo de activación por socket

En hosts con systemd, se inicia en modo de activación por socket y confiará en systemd para crear y escuchar en los sockets UNIX y pasarlos como descriptores de archivo pre-abiertos. En este modo, la mayoría de las opciones de configuración relacionadas con el socket en /etc/libvirt/virtinterfaced.conf ya no tendrán ningún efecto.

Modo de servicio tradicional

En hosts sin systemd, creará y escuchará en los sockets UNIX por sí mismo.

OPCIONES

-h, --help

Muestra la ayuda de la línea de comandos y sale.

-d, --daemon

Ejecuta como demonio y escribe el archivo PID.

-f, --config *ARCHIVO*

Usa este archivo de configuración, anulando el valor predeterminado.

-p, --pid-file *ARCHIVO*

Usa este nombre para el archivo PID, anulando el valor predeterminado.

-t, --timeout *SEGUNDOS*

Sale después del período de tiempo de espera (en segundos), siempre que no haya conexiones de clientes.

-v, --verbose

Habilita la salida de mensajes detallados.

--version

Muestra la información de la versión y sale.

SEÑALES

Al recibir SIGHUP, virtinterfaced recargará su configuración.

ARCHIVOS

Cuando se ejecuta como root

•
/etc/libvirt/virtinterfaced.conf

El archivo de configuración predeterminado utilizado por virtinterfaced, a menos que se anule en la línea de comandos usando la opción -f | --config.

  • /run/libvirt/virtinterfaced-sock
  • /run/libvirt/virtinterfaced-sock-ro
  • /run/libvirt/virtinterfaced-admin-sock

Los sockets que utilizará virtinterfaced.

La clave privada Server TLS que utilizará virtinterfaced.

•
/run/virtinterfaced.pid

El archivo PID a utilizar, a menos que se anule con la opción -p | --pid-file.

Cuando se ejecuta como no root

•
$XDG_CONFIG_HOME/libvirt/virtinterfaced.conf

El archivo de configuración predeterminado utilizado por virtinterfaced, a menos que se anule en la línea de comandos usando la opción -f``|--config``.

  • $XDG_RUNTIME_DIR/libvirt/virtinterfaced-sock
  • $XDG_RUNTIME_DIR/libvirt/virtinterfaced-admin-sock

Los sockets que utilizará virtinterfaced.

•
$XDG_RUNTIME_DIR/libvirt/virtinterfaced.pid

El archivo PID a utilizar, a menos que se anule con la opción -p``|--pid-file``.

Si $XDG_CONFIG_HOME no está configurado en tu entorno, virtinterfaced usará $HOME/.config

Si $XDG_RUNTIME_DIR no está configurado en tu entorno, virtinterfaced usará $HOME/.cache

EJEMPLOS

Para obtener la versión de virtinterfaced:

# virtinterfaced --version
virtinterfaced (libvirt) 11.10.0

Para iniciar virtinterfaced, instruyéndole que se ejecute como demonio y cree un archivo PID:

# virtinterfaced -d
# ls -la /run/virtinterfaced.pid
-rw-r--r-- 1 root root 6 Jul  9 02:40 /run/virtinterfaced.pid

    NAME

    virtinterfaced - API for interfaces management

    SYNOPSIS

    virtinterfaced [OPTIONS] [INTERFACE...]

    DESCRIPTION

    The virtinterfaced utility provides a command line interface for managing network interfaces used by libvirt. It can be used to list, define, undefine, start, stop, and query network interfaces.

    OPTIONS

    The following options are available:

    --list
    List all available network interfaces.
    --define=FILE
    Define a new network interface from the specified XML file.
    --undefine=INTERFACE
    Undefine the specified network interface.
    --start=INTERFACE
    Start the specified network interface.
    --stop=INTERFACE
    Stop the specified network interface.
    --query=INTERFACE
    Query the status of the specified network interface.
    --help
    Display help information.
    --version
    Display version information.

    EXAMPLES

    List all network interfaces:

    virtinterfaced --list

    Define a new network interface from an XML file:

    virtinterfaced --define=my-interface.xml

    Start a network interface:

    virtinterfaced --start=my-interface
