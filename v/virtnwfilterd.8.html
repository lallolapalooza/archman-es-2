virtnwfilterd(8) Soporte de Virtualización virtnwfilterd(8)

Nombre

virtnwfilterd - demonio de gestión de filtros de red libvirt

SINÓPSIS

virtnwfilterd [OPCIÓN]...

DESCRIPCIÓN

El programa virtnwfilterd es un componente de demonio del lado del servidor del sistema de gestión de virtualización libvirt.

Es una de una colección de demonios modulares que reemplazan la funcionalidad previamente proporcionada por el demonio monolítico libvirtd.

Este demonio se ejecuta en hosts de virtualización para proporcionar gestión de filtros de red.

El demonio virtnwfilterd solo escucha las solicitudes en un socket de dominio Unix local. El acceso remoto a través de TLS/TCP y la compatibilidad con versiones anteriores con clientes heredados que esperan libvirtd es proporcionado por el demonio virtproxyd.

Reiniciar virtnwfilterd no interrumpe las máquinas virtuales en ejecución. Las máquinas virtuales continúan operando y los cambios en su estado generalmente se captarán automáticamente durante el inicio. Sin embargo, se recomienda evitar reiniciar con máquinas virtuales en ejecución siempre que sea práctico.

MODOS DE INICIO DEL DEMONIO

El demonio virtnwfilterd es capaz de iniciarse en dos modos.

Modo de activación de socket

En hosts con systemd, se inicia en modo de activación de socket y confiará en systemd para crear y escuchar en los sockets UNIX y pasarlos como descriptores de archivo preabiertos. En este modo, la mayoría de las opciones de configuración relacionadas con sockets en /etc/libvirt/virtnwfilterd.conf ya no tendrán ningún efecto.

Modo de servicio tradicional

En hosts sin systemd, creará y escuchará en los sockets UNIX por sí mismo.

OPCIONES

-h, --help

Muestra la ayuda de uso de la línea de comandos y luego sale.

-d, --daemon

Ejecutar como demonio y escribir archivo PID.

-f, --config *ARCHIVO*

Utilizar este archivo de configuración, anulando el valor predeterminado.

-p, --pid-file *ARCHIVO*

Utilizar este nombre para el archivo PID, anulando el valor predeterminado.

-t, --timeout *SEGUNDOS*

Salir después del período de tiempo de espera (en segundos), siempre que no haya conexiones de clientes.

-v, --verbose

Habilitar la salida de mensajes detallados.

--version

Muestra la información de la versión y luego sale.

SEÑALES

Al recibir SIGHUP, virtnwfilterd recargará su configuración.

ARCHIVOS

Cuando se ejecuta como root

•
/etc/libvirt/virtnwfilterd.conf

El archivo de configuración predeterminado utilizado por virtnwfilterd, a menos que se anule en la línea de comandos usando la opción -f | --config.

  • /run/libvirt/virtnwfilterd-sock
  • /run/libvirt/virtnwfilterd-sock-ro
  • /run/libvirt/virtnwfilterd-admin-sock

Los sockets que utilizará virtnwfilterd.

La clave privada del servidor TLS que utilizará virtnwfilterd.

•
/run/virtnwfilterd.pid

El archivo PID a usar, a menos que se anule con la opción -p | --pid-file.

Cuando se ejecuta como no-root

•
$XDG_CONFIG_HOME/libvirt/virtnwfilterd.conf

El archivo de configuración predeterminado utilizado por virtnwfilterd, a menos que se anule en la línea de comandos usando la opción -f``|--config``.

  • $XDG_RUNTIME_DIR/libvirt/virtnwfilterd-sock
  • $XDG_RUNTIME_DIR/libvirt/virtnwfilterd-admin-sock

Los sockets que utilizará virtnwfilterd.

•
$XDG_RUNTIME_DIR/libvirt/virtnwfilterd.pid

El archivo PID a usar, a menos que se anule con la opción -p``|--pid-file``.

Si $XDG_CONFIG_HOME no está configurado en tu entorno, virtnwfilterd usará $HOME/.config

Si $XDG_RUNTIME_DIR no está configurado en tu entorno, virtnwfilterd usará $HOME/.cache

EJEMPLOS

Para obtener la versión de virtnwfilterd:

# virtnwfilterd --version
virtnwfilterd (libvirt) 11.10.0

Para iniciar virtnwfilterd, instruyéndole a que se convierta en demonio y cree un archivo PID:

# virtnwfilterd -d
# ls -la /run/virtnwfilterd.pid
-rw-r--r-- 1 root root 6 Jul  9 02:40 /run/virtnwfilterd.pid

SINOPSIS

virtnwfilterd [OPCIONES]

DESCRIPCIÓN

virtnwfilterd es el demonio de libvirt responsable de gestionar y aplicar reglas de filtrado de red para máquinas virtuales. Este demonio trabaja en conjunto con el demonio principal libvirtd para proporcionar capacidades avanzadas de filtrado de tráfico de red, como la aplicación de políticas de seguridad, la configuración de VLANs y la inspección de paquetes.

virtnwfilterd implementa el backend de filtrado de red para libvirt. Maneja la creación, modificación y eliminación de filtros de red. Cuando se define un filtro de red para una máquina virtual, virtnwfilterd es el responsable de configurar las reglas de firewall y otras configuraciones de red necesarias para que ese filtro se aplique correctamente.

El demonio se comunica con libvirtd a través de un socket Unix o TCP y recibe comandos para gestionar los filtros de red. También interactúa con las herramientas de red del sistema operativo subyacente (como iptables, nftables, eBPF) para aplicar las reglas de filtrado. Es fundamental para implementar aislamiento de red, segmentación y políticas de seguridad personalizadas para las máquinas virtuales.

OPCIONES

virtnwfilterd no acepta argumentos de línea de comandos directos para su configuración. La configuración se gestiona a través de los archivos de configuración de libvirt (libvirtd.conf) y mediante la API de libvirt al definir filtros de red para las máquinas virtuales.

Sin embargo, virtnwfilterd puede ser controlado por systemd o init scripts, y puede responder a señales del sistema para reiniciarse o recargar configuraciones si el sistema de inicio lo soporta.

--daemon
Ejecuta el demonio en segundo plano.
--verbose
Aumenta la verbosidad del registro.
--help
Muestra un resumen de las opciones de ayuda.

Tenga en cuenta que el uso directo de estas opciones puede no ser compatible o necesario cuando se gestiona a través de un gestor de servicios como systemd.

CONFIGURACIÓN

La configuración principal de virtnwfilterd se realiza a través del archivo de configuración de libvirt, típicamente ubicado en /etc/libvirt/libvirtd.conf. Los parámetros relevantes incluyen:

nwfilter_commit_delay=N
Define el retardo en milisegundos antes de que se apliquen las reglas de filtrado de red. Un valor de 0 deshabilita el retardo.
nwfilter_commit_delay_log=1
Habilita el registro de los retrasos en la confirmación de las reglas de filtrado.

Además, las reglas de filtrado de red específicas para las máquinas virtuales se definen en archivos XML separados, generalmente en /etc/libvirt/nwfilter/ o dentro de los metadatos de la máquina virtual.

ARCHIVOS

/etc/libvirt/libvirtd.conf
Archivo de configuración principal para los demonios de libvirt, incluyendo virtnwfilterd.
/etc/libvirt/nwfilter/
Directorio donde se almacenan los archivos de definición de filtros de red.
/var/run/libvirt/nwfilter/
Directorio utilizado para sockets o archivos temporales relacionados con el filtrado de red.
