vm86(2) Manual de llamadas al sistema vm86(2)

NOMBRE

vm86old, vm86 - entrar en modo virtual 8086

BIBLIOTECA

Biblioteca C estándar (libc, -lc)

SINOPSIS

#include <sys/vm86.h>
int vm86old(struct vm86_struct *info);
int vm86(unsigned long fn, struct vm86plus_struct *v86);

DESCRIPCIÓN

La llamada al sistema vm86() se introdujo en Linux 0.97p2. En Linux 2.1.15 y 2.0.28, se cambió el nombre a vm86old(), y se introdujo un nuevo vm86(). La definición de struct vm86_struct cambió en 1.1.8 y 1.1.9.

Estas llamadas hacen que el proceso entre en modo VM86 (virtual-8086 en la literatura de Intel), y son utilizadas por dosemu.

El modo VM86 es una emulación del modo real dentro de una tarea en modo protegido.

VALOR DE RETORNO

Si la operación se realiza con éxito, se devuelve cero. En caso de error, se devuelve -1 y la variable errno se establece para indicar el error.

ERRORES

EFAULT
Este valor de retorno es específico de i386 e indica un problema al obtener datos del espacio de usuario.
ENOSYS
Este valor de retorno indica que la llamada no está implementada en la arquitectura actual.
EPERM
Existe una pila del kernel guardada. (Esta es una comprobación de cordura del kernel; la pila guardada solo debe existir dentro del propio modo vm86).

ESTÁNDARES

Linux en procesadores Intel de 32 bits.
