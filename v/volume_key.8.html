NOMBRE

volume_key - trabaja con secretos de cifrado de volúmenes y paquetes de resguardo

SINOPSIS

volume_key [OPCIÓN]... OPERANDO...

DESCRIPCIÓN

volume_key extrae "secretos" utilizados para el cifrado de volúmenes (por ejemplo, claves o contraseñas) y los almacena en "paquetes de resguardo" cifrados por separado, utiliza un paquete de resguardo creado previamente para restaurar el acceso a un volumen (por ejemplo, si el usuario olvida una contraseña), o manipula la información en los paquetes de resguardo.

El modo de operación y los operandos de volume_key se determinan especificando una de las opciones --save, --restore, --setup-volume, --reencrypt, --dump o --secrets. Consulte las secciones de OPCIONES para obtener más detalles.

OPCIONES

En todas las opciones descritas a continuación, VOLUMEN es un dispositivo LUKS, no el dispositivo de texto plano contenido dentro:

blkid -s TYPE VOLUMEN
debería informar TYPE="crypto_LUKS".

Las siguientes opciones determinan el modo de operación y los operandos esperados de volume_key:

--save
Espera los operandos VOLUMEN [PAQUETE]. Abre VOLUMEN. Si se proporciona PAQUETE, carga los secretos de él. De lo contrario, extrae los secretos de VOLUMEN, solicitando al usuario si es necesario. En cualquier caso, almacena los secretos en uno o más paquetes de salida.
--restore
Espera los operandos VOLUMEN PAQUETE. Abre VOLUMEN y utiliza los secretos de PAQUETE para que VOLUMEN sea accesible nuevamente, solicitando al usuario si es necesario (por ejemplo, permitiendo al usuario ingresar una nueva contraseña).
--setup-volume
Espera los operandos VOLUMEN PAQUETE NOMBRE. Abre VOLUMEN y utiliza los secretos de PAQUETE para configurar VOLUMEN para usar los datos descifrados como NOMBRE.

Actualmente NOMBRE es el nombre de un volumen dm-crypt, y esta operación hace que el volumen descifrado esté disponible como /dev/mapper/NOMBRE.

Esta operación no debería alterar permanentemente VOLUMEN (por ejemplo, agregando una nueva contraseña); el usuario puede, por supuesto, acceder y modificar el volumen descifrado, modificando VOLUMEN en el proceso.

--reencrypt
Espera el operando PAQUETE. Abre PAQUETE, descifrándolo si es necesario, y almacena la información en uno o más paquetes de salida nuevos.
--dump
Espera el operando PAQUETE. Abre PAQUETE, descifrándolo si es necesario, y muestra el contenido de PAQUETE. Los secretos no se muestran por defecto.
--secrets
Espera el operando PAQUETE. Abre PAQUETE, descifrándolo si es necesario, y muestra los secretos contenidos en PAQUETE.
--help
Muestra la información de uso.
--version
Muestra la versión de volume_key.

Las siguientes opciones alteran el comportamiento de la operación especificada:

-b, --batch
Ejecuta en modo batch. Lee contraseñas y frases de contraseña de la entrada estándar, cada una terminada por un carácter NUL. Si un paquete no coincide exactamente con un volumen, falla en lugar de solicitar al usuario.
-d, --nss-dir DIR
Utiliza claves privadas en la base de datos NSS en DIR para descifrar paquetes cifrados con clave pública.
-o, --output PAQUETE
Escribe el secreto predeterminado en PAQUETE.

Cuál secreto es el predeterminado depende del formato del volumen: no debería caducar fácilmente y debería permitir restaurar el acceso al volumen usando --restore.

--output-data-encryption-key PAQUETE
Escribe la clave de cifrado de datos (la clave utilizada directamente para cifrar los datos reales del volumen) en PAQUETE.
--output-passphrase PAQUETE
Escribe una frase de contraseña que se puede utilizar para acceder al volumen en PAQUETE.
--create-random-passphrase PAQUETE
Genera una frase de contraseña alfanumérica aleatoria, la agrega a VOLUMEN (sin afectar otras frases de contraseña) y almacena la frase de contraseña aleatoria en PAQUETE.
-c, --certificate CERT
Carga un certificado del archivo especificado por CERT y cifra todos los paquetes de salida utilizando la clave pública contenida en el certificado. Si esta opción no se especifica, todos los paquetes de salida se cifran utilizando una frase de contraseña.

Tenga en cuenta que CERT es el nombre de un archivo de certificado, no un alias de certificado NSS.

--output-format FORMATO
Utiliza FORMATO para todos los paquetes de salida. FORMATO actualmente puede ser uno de asymmetric (usa CMS para cifrar todo el paquete, requiere un certificado), asymmetric_wrap_secret_only (envuelve solo el secreto, requiere un certificado), passphrase (usa GPG para cifrar todo el paquete, requiere una frase de contraseña).
--unencrypted
Solo muestra las partes sin cifrar del paquete, si las hay, con --dump. No requiere ninguna frase de contraseña ni acceso a claves privadas.
--with-secrets
Incluye secretos en la salida de --dump

ESTADO DE SALIDA

volume_key regresa con el estado de salida 0 en caso de éxito, 1 en caso de error.

NOTAS

El único formato de volumen compatible actualmente es LUKS.

EJEMPLO

El uso típico de volume_key procede de la siguiente manera. Durante la instalación del sistema o poco después, haz una copia de seguridad del secreto predeterminado de un volumen y agrega una frase de contraseña aleatoria específica del sistema. Cifra ambos usando un certificado:

volume_key --save VOLUMEN -c CERT -o PAQUETE_POR_DEFECTO --create-random-passphrase PAQUETE_CONTRASEÑA
Almacena PAQUETE_POR_DEFECTO y PAQUETE_CONTRASEÑA fuera de la computadora.

Si el usuario olvida una contraseña y puedes acceder a la computadora, descifra PAQUETE_POR_DEFECTO usando la clave privada del certificado (que nunca debería abandonar una máquina segura):

volume_key --reencrypt -d NSS_DB PAQUETE_POR_DEFECTO -o PAQUETE_POR_DEFECTO_PW
Luego arranca la computadora (por ejemplo, usando un modo de rescate), copia PAQUETE_POR_DEFECTO_PW a ella y restaura el acceso al volumen:
volume_key --restore VOLUMEN PAQUETE_POR_DEFECTO_PW

Si el usuario olvida la frase de contraseña y no puedes acceder a la computadora, descifra la frase de contraseña de respaldo:

volume_key --secrets PAQUETE_CONTRASEÑA
y dile la frase de contraseña de respaldo al usuario. (Puedes generar una nueva frase de contraseña de respaldo más tarde).
