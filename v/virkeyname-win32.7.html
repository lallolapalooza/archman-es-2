Name

virkeyname-win32 - Windows virtual key codes

DESCRIPTION

The virkeyname-win32 utility converts Windows virtual key codes to names and vice versa. This is particularly useful for mapping keyboard input between host and guest systems when using virtual machines.

The utility can be invoked as:

virkeyname-win32 <code>

to convert a numeric key code to its symbolic name, or:

virkeyname-win32 <name>

to convert a symbolic name to its numeric key code.

If no argument is provided, virkeyname-win32 lists all known key codes and their names.

The following key codes are known:

  • None

    Key value 1 (0x1)

  • VK_LBUTTON

    Key value 2 (0x2)

  • VK_RBUTTON

    Key value 4 (0x4)

  • VK_CANCEL

    Key value 3 (0x3)

  • VK_MBUTTON

    Key value 8 (0x8)

  • None

    Key value 16 (0x10)

  • None
