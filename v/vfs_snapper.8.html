VFS_SNAPPER(8) Herramientas de administración del sistema VFS_SNAPPER(8)

NOMBRE

vfs_snapper - Expone instantáneas gestionadas por snapper como copias de sombra (shadow-copies)

SINOPSIS

objetos vfs = snapper

DESCRIPCIÓN

Este módulo VFS forma parte del conjunto de utilidades samba(8).

El módulo VFS vfs_snapper expone las instantáneas gestionadas por snapper para su uso por Samba. Esto proporciona la capacidad para que los clientes SMB remotos accedan a las copias de sombra a través del Explorador de Windows utilizando el diálogo de "versiones anteriores".

Las instantáneas también se pueden crear y eliminar de forma remota, utilizando el Protocolo Remoto VSS del Servidor de Archivos (FSRVP). Las solicitudes de creación y eliminación de instantáneas se reenvían a snapper a través de DBus.

Este módulo es apilable.

CONFIGURACIÓN

La ruta del recurso compartido subyacente debe tener un archivo de configuración de snapper correspondiente. El árbol de directorios de instantáneas debe permitir el acceso a los usuarios relevantes.

[recurso_compartido]
vfs objects = snapper

Para la creación y eliminación remota de instantáneas, el servidor FSRVP de Samba debe estar configurado en la sección [global]:

[global]
registry shares = yes
include = registry

PERMISOS

Snapper almacena las instantáneas en un subdirectorio .snapshots. Este directorio debe permitir la traversal (navegación) para cualquier usuario que desee acceder a las instantáneas a través del diálogo de versiones anteriores del Explorador de Windows. Por defecto, la traversal está prohibida para todos los usuarios que no sean root. Además, los usuarios deben tener permiso para listar las instantáneas gestionadas por snapper, a través de las opciones ALLOW_USERS o ALLOW_GROUPS de snapper. Snapper puede otorgar a estos usuarios y grupos acceso de traversal al directorio .snapshots automáticamente a través de la opción SYNC_ACL.

La creación y eliminación remota de instantáneas solo está permitida por Samba para administradores de Active Directory, operadores de copias de seguridad o usuarios a los que se les haya otorgado explícitamente SeBackupPrivilege. Snapper también debe permitir la creación y eliminación para el usuario apropiado, a través de las opciones ALLOW_USERS o ALLOW_GROUPS de snapper.

El cliente FSRVP DiskShadow.exe se autentica inicialmente como la cuenta del equipo de Active Directory. Por lo tanto, a esta cuenta se le deben otorgar los mismos permisos que a la cuenta de usuario que emite las solicitudes de creación y eliminación de instantáneas.
