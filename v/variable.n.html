variable(n) Comandos integrados de Tcl variable(n)

NOMBRE

variable - crea e inicializa una variable de espacio de nombres

SINOPSIS

variable nombre

variable ?nombre valor...?

DESCRIPCIÓN

Este comando se usa normalmente dentro de un comando namespace eval para crear una o más variables dentro de un espacio de nombres. Cada variable nombre se inicializa con valor. El valor para la última variable es opcional.

Si una variable nombre no existe, se crea. En este caso, si se especifica valor, se asigna a la variable recién creada. Si no se especifica ningún valor, la nueva variable se deja sin definir. Si la variable ya existe, se establece en valor si se especifica valor o se deja sin cambios si no se proporciona ningún valor. Normalmente, nombre no está calificado (no incluye los nombres de los espacios de nombres que la contienen), y la variable se crea en el espacio de nombres actual. Si nombre incluye calificadores de espacio de nombres, la variable se crea en el espacio de nombres especificado. Si la variable no está definida, será visible para el comando namespace which, pero no para el comando info exists.

Si el comando variable se ejecuta dentro de un procedimiento Tcl, crea variables locales vinculadas a las variables del espacio de nombres correspondientes (y, por lo tanto, estas variables son listadas por info vars). De esta manera, el comando variable se asemeja al comando global, aunque el comando global resuelve los nombres de las variables con respecto al espacio de nombres global en lugar del espacio de nombres actual del procedimiento. Si se proporcionan valores, se utilizan para modificar los valores de las variables del espacio de nombres asociadas. Si una variable de espacio de nombres no existe, se crea y se inicializa opcionalmente.

Un argumento nombre no puede hacer referencia a un elemento dentro de un array. En su lugar, nombre debe hacer referencia a todo el array, y el valor de inicialización debe omitirse. Después de declarar la variable, los elementos dentro del array se pueden establecer utilizando comandos set o array normales.

EJEMPLOS

Crear una variable en un espacio de nombres:

namespace eval foo {
    variable bar 12345
}

Crear un array en un espacio de nombres:

namespace eval someNS {
    variable someAry
    array set someAry {
        someName  someValue
        otherName otherValue
    }
}

Acceder a variables en espacios de nombres desde un procedimiento:

namespace eval foo {
    proc spong {} {
        # Variable en este espacio de nombres
        variable bar
        puts "bar is $bar"
        # Variable en otro espacio de nombres
        variable ::someNS::someAry
        parray someAry
    }
}
