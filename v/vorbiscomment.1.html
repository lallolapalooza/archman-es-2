VORBISCOMMENT(1) Herramientas Ogg Vorbis VORBISCOMMENT(1)

NOMBRE

vorbiscomment - Listar o editar comentarios en archivos Ogg Vorbis

SINOPSIS

vorbiscomment [-l] [-R] [-e] archivo.ogg
vorbiscomment -a [ -c archivo_comentarios | -t “nombre=valor” | -d “nombre=valor” ] [-q] [-R] [-e] in.ogg [out.ogg]
vorbiscomment -w [ -c archivo_comentarios | -t “nombre=valor” ] [-q] [-R] [-e] in.ogg [out.ogg]

DESCRIPCIÓN

vorbiscomment Lee, modifica y añade etiquetas de metadatos a archivos de audio Ogg Vorbis.

OPCIONES

-a, --append
Actualiza los comentarios.
-c archivo, --commentfile archivo
Toma los comentarios de un archivo. El archivo tiene el mismo formato que el salida de la opción -l o dado a la opción -t: un elemento por línea en formato 'etiqueta=valor'. Si el archivo es /dev/null y se pasó -w, los comentarios existentes se eliminarán.
-h, --help
Muestra la ayuda del comando.
-l, --list
Lista los comentarios en el archivo Ogg Vorbis.
-q, --quiet
Modo silencioso. No se muestran mensajes.
-t 'nombre=valor', --tag 'nombre=valor'
Especifica una nueva etiqueta en la línea de comandos. Cada etiqueta se da como una única cadena. La parte anterior al '=' se trata como el nombre de la etiqueta y la parte posterior como el valor.
-d 'nombre[=valor]', --rm 'nombre[=valor]'
Especifica una etiqueta en la línea de comandos para eliminar. Cada etiqueta se da como una única cadena. La parte anterior al '=' se trata como el nombre de la etiqueta y la parte posterior como el valor. Si no se da valor, se eliminan todas las etiquetas con el nombre dado. De lo contrario, solo se eliminan aquellas con valores coincidentes.
-w, --write
Reemplaza los comentarios con el nuevo conjunto dado en la línea de comandos con -t o desde un archivo con -c. Si no se dan ni -c ni -t, el nuevo conjunto se leerá de la entrada estándar.
-R, --raw
Lee y escribe comentarios en UTF-8, en lugar de convertir al conjunto de caracteres del usuario.
-e, --escapes
Comilla/descomprime saltos de línea y barras invertidas en los comentarios. Esto asegura que cada comentario sea exactamente una línea en la salida (o entrada), permitiendo filtrarlos y enviarlos en ciclo. Sin esto, solo puede escribir comentarios multilínea usando -t y no puede distinguirlos fiablemente de múltiples comentarios de una sola línea.

Los escapes soportados son de estilo c: "\n", "\r", "\\" y "\0". Una barra invertida seguida de cualquier otra cosa es un error.

Nota: actualmente, todo lo que esté después del primer "\0" se descarta al escribir. Esto es un error -- el formato Vorbis puede almacenar caracteres nulos de forma segura, pero la mayoría de las otras herramientas no los manejarían de todos modos.

-V, --version
Muestra la versión de vorbiscomment.

EJEMPLOS

Para simplemente ver qué etiquetas de comentarios hay en un archivo:


vorbiscomment -l archivo.ogg

Para editar esos comentarios:


vorbiscomment -l archivo.ogg > archivo.txt
[edita los comentarios en archivo.txt a tu satisfacción]
vorbiscomment -w -c archivo.txt archivo.ogg nuevofile.ogg

Para simplemente añadir un comentario:


vorbiscomment -a -t 'ARTIST=Nadie Que Conozcas' archivo.ogg nuevofile.ogg

Para añadir un conjunto de comentarios desde la entrada estándar:


vorbiscomment -a archivo.ogg
ARTIST=Nadie Que Conozcas
ALBUM=El Álbum Famoso
<ctrl-d>

FORMATO DE ETIQUETA

Consulta https://xiph.org/vorbis/doc/v-comment.html para ver la documentación sobre el formato de etiquetas Ogg Vorbis, incluida una lista sugerida de nombres de etiquetas canónicos.
