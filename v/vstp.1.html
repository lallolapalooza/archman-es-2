NOMBRE

vstpg, vstpp - Transferencia de archivos VisioBraille

SINOPSIS

vstpg [-ifbnd] [-s puerto_socket] [-k nombre_clave] [-o nombre_config] archivo ...

DESCRIPCIÓN

vstpg (resp. vstpp) recibe (resp. envía) archivos desde (resp. hacia) un terminal VisioBraille.

Para comunicarse con el terminal, debes lanzar brltty con el controlador BrÎlNet, y decirle a BrlNet que use el controlador VisioBraille.

Antes de enviar al terminal, los nombres de archivo se truncan a 8 caracteres sin ninguna extensión.

Antes de recibir desde el terminal, se eliminan la ruta inicial y las extensiones finales, pero se restauran para el nombre de archivo local.

OPCIONES DE LÍNEA DE COMANDOS

-i
solicitar confirmación de transferencia, para cada archivo (en el terminal)
-f
no solicitar dicha confirmación (por defecto)
-b
si existen, renombrar recursivamente los archivos antiguos con un sufijo .x añadido, al igual que hace logrotate
-n
no conservar dicho archivo de copia de seguridad (por defecto)
-s puerto_socket
usar puerto_socket como número de puerto en lugar del predeterminado para conectarse a BrlNet
-k nombre_archivo
usar nombre_archivo como ruta de clave en lugar del predeterminado para leer la clave de autenticación de BrlNet
-d
usar el directorio actual en lugar del directorio de descarga (ver vbs_dir más abajo)
-o nombre_archivo
leer también nombre_archivo como archivo de configuración

ARCHIVO DE CONFIGURACIÓN

vstpg y vstpp leen un archivo de configuración $HOME/.vstprc que contiene palabras clave o igualdades, una por línea (lo que sigue a un # se ignora).

Puedes pedirles que lean también cualquier otro archivo gracias a la opción -o.

Aquí están las palabras clave:

copia-de-seguridad
hacer la opción -b la predeterminada
sin-copia-de-seguridad
hacer la opción -f la predeterminada
y igualdades:
nombre-clave = nombre_archivo
usar este archivo en lugar del predeterminado, para encontrar la clave de autenticación de BrlNet
puerto-socket = puerto
usar este número de puerto, en lugar del predeterminado, para conectarse a BrlNet
vbs_ext = .ext
usar .ext como extensión para los archivos descargados (.vis por defecto) esto se anula en la línea de comandos si se proporciona una extensión en el nombre del archivo
vbs_dir = ruta
usar ruta en lugar del directorio actual para enviar archivos, excepto cuando se usa la opción -d, o si el nombre del archivo comienza con '.'

VALOR DE RETORNO

1 error de sintaxis en la línea de comandos
2 error de conexión con BrlNet
3 error de archivo Unix
4 error de protocolo
16 interrumpido por el usuario

EXPANSIONES DEL SHELL

Tenga cuidado con los caracteres especiales: * y . a menudo son expandidos por su shell, por lo tanto vstpp * probablemente hará lo que usted quiere, enviando todos los archivos existentes en el directorio actual al terminal, pero vstpg * puede que no haga lo que usted quiere: solo recibirá todos los archivos que ya existen en el directorio actual, ¡omitindo aquellos que acaba de crear en su terminal! Si quiere recibir todos los archivos que existen en el terminal, debería usar vstpg '*' o algo similar (por favor, lea el manual de su shell).

La misma advertencia se aplica a otros caracteres especiales, como $, ~, &, ..., que deberían protegerse rodeando los argumentos con comillas (') o usando barras invertidas simples (\) justo antes de ellos (por favor, lea el manual de su shell).

ERRORES

El que pudimos encontrar ha sido corregido :)
