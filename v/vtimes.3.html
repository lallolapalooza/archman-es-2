getrusage(2) Manual de llamadas al sistema getrusage(2)

NOMBRE

getrusage - obtener uso de recursos

BIBLIOTECA

Biblioteca C estándar (libc, -lc)

SINOPSIS

#include <sys/resource.h>
int getrusage(int who, struct rusage *usage);

DESCRIPCIÓN

getrusage() devuelve medidas de uso de recursos para who, que puede ser una de las siguientes:

RUSAGE_SELF
Devolver estadísticas de uso de recursos para el proceso que llama, que es la suma de los recursos utilizados por todos los hilos del proceso.
RUSAGE_CHILDREN
Devolver estadísticas de uso de recursos para todos los hijos del proceso que llama que han terminado y para los que se ha esperado. Estas estadísticas incluirán los recursos utilizados por los nietos, y descendientes más lejanos, si todos los descendientes intermedios esperaron por sus hijos terminados.
RUSAGE_THREAD (desde Linux 2.6.26)
Devolver estadísticas de uso de recursos para el hilo que llama. El macro de prueba de características _GNU_SOURCE debe definirse (antes de incluir *cualquier* archivo de cabecera) para obtener la definición de esta constante de <sys/resource.h>.

Los usos de recursos se devuelven en la estructura apuntada por usage, que tiene la siguiente forma:


struct rusage {
    struct timeval ru_utime; /* tiempo de CPU de usuario utilizado */
    struct timeval ru_stime; /* tiempo de CPU del sistema utilizado */
    long   ru_maxrss;        /* tamaño máximo del conjunto residente */
    long   ru_ixrss;         /* tamaño integral de memoria compartida */
    long   ru_idrss;         /* tamaño integral de datos no compartidos */
    long   ru_isrss;         /* tamaño integral de pila no compartida */
    long   ru_minflt;        /* recuperaciones de página (fallos de página suaves) */
    long   ru_majflt;        /* fallos de página (fallos de página duros) */
    long   ru_nswap;         /* intercambios */
    long   ru_inblock;       /* operaciones de entrada de bloque */
    long   ru_oublock;       /* operaciones de salida de bloque */
    long   ru_msgsnd;        /* mensajes IPC enviados */
    long   ru_msgrcv;        /* mensajes IPC recibidos */
    long   ru_nsignals;      /* señales recibidas */
    long   ru_nvcsw;         /* cambios de contexto voluntarios */
    long   ru_nivcsw;        /* cambios de contexto involuntarios */
};

No todos los campos se completan; los campos no mantenidos se establecen a cero por el kernel. (Los campos no mantenidos se proporcionan por compatibilidad con otros sistemas y porque algún día pueden ser compatibles en Linux.) Los campos se interpretan como sigue:

ru_utime
Este es el tiempo total empleado ejecutando en modo de usuario, expresado en una estructura timeval (segundos más microsegundos).
ru_stime
Este es el tiempo total empleado ejecutando en modo de kernel, expresado en una estructura timeval (segundos más microsegundos).
ru_maxrss (desde Linux 2.6.32)
Este es el tamaño máximo del conjunto residente utilizado (en KiB). Para RUSAGE_CHILDREN, este es el tamaño del conjunto residente del hijo más grande, no el tamaño máximo del conjunto residente del árbol de procesos.
ru_ixrss (no mantenido)
Este campo no se utiliza actualmente en Linux.
ru_idrss (no mantenido)
Este campo no se utiliza actualmente en Linux.
ru_isrss (no mantenido)
Este campo no se utiliza actualmente en Linux.
ru_minflt
El número de fallos de página atendidos sin actividad de E/S; aquí, la actividad de E/S se evita "recuperando" un marco de página de la lista de páginas que esperan la reasignación.
ru_majflt
El número de fallos de página atendidos que requirieron actividad de E/S.
ru_nswap (no mantenido)
Este campo no se utiliza actualmente en Linux.
ru_inblock (desde Linux 2.6.22)
El número de veces que el sistema de archivos tuvo que realizar una entrada.
ru_oublock (desde Linux 2.6.22)
El número de veces que el sistema de archivos tuvo que realizar una salida.
ru_msgsnd (no mantenido)
Este campo no se utiliza actualmente en Linux.
ru_msgrcv (no mantenido)
Este campo no se utiliza actualmente en Linux.
ru_nsignals (no mantenido)
Este campo no se utiliza actualmente en Linux.
ru_nvcsw (desde Linux 2.6)
El número de veces que un cambio de contexto resultó porque un proceso cedió voluntariamente el procesador antes de que su cuota de tiempo se completara (normalmente para esperar la disponibilidad de un recurso).
ru_nivcsw (desde Linux 2.6)
El número de veces que un cambio de contexto resultó porque un proceso de mayor prioridad se volvió ejecutable o porque el proceso actual excedió su cuota de tiempo.

VALOR DE RETORNO

En caso de éxito, se devuelve cero. En caso de error, se devuelve -1 y errno se establece para indicar el error.

ERRORES

EFAULT
usage apunta fuera del espacio de direcciones accesible.
EINVAL
who es inválido.

ATRIBUTOS

Para una explicación de los términos utilizados en esta sección, consulte attributes(7).

Interfaz Atributo Valor
getrusage () Seguridad de hilos MT-Safe

ESTÁNDARES

POSIX.1-2024.

POSIX.1 especifica getrusage(), pero solo especifica los campos ru_utime y ru_stime.

RUSAGE_THREAD es específico de Linux.

HISTORIA

POSIX.1-2001, SVr4, 4.3BSD.

Antes de Linux 2.6.9, si la disposición de SIGCHLD se establecía en SIG_IGN, los usos de recursos de los procesos hijos se incluían automáticamente en el valor devuelto por RUSAGE_CHILDREN, aunque POSIX.1-2001 lo prohíbe explícitamente. Esta falta de conformidad se rectifica en Linux 2.6.9 y posteriores.

La definición de estructura que se muestra al principio de esta página se tomó de 4.3BSD Reno.

Los sistemas antiguos proporcionaban una función vtimes() con un propósito similar a getrusage(). Para compatibilidad con versiones anteriores, glibc (hasta Linux 2.32) también proporciona vtimes(). Todas las aplicaciones nuevas deben escribirse utilizando getrusage(). (Desde Linux 2.33, glibc ya no proporciona una implementación de vtimes().)

NOTAS

Las métricas de uso de recursos se conservan a través de una llamada a execve(2).
