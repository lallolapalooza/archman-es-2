vcs(4) Manual de controladores de dispositivos vcs(4)

NOMBRE

vcs, vcsa - memoria de consola virtual

DESCRIPCIÓN

/dev/vcs0 es un dispositivo de caracteres con número mayor 7 y menor 0, usualmente con modo 0644 y propiedad root:tty. Se refiere a la memoria de la terminal de consola virtual actualmente mostrada.

/dev/vcs[1-63] son dispositivos de caracteres para terminales de consola virtuales, tienen número mayor 7 y menores del 1 al 63, usualmente modo 0644 y propiedad root:tty. /dev/vcsa[0-63] son lo mismo, pero usando unsigned shorts (en orden de bytes del host) que incluyen atributos, y prefijados por cuatro bytes que dan las dimensiones de la pantalla y la posición del cursor: líneas, columnas, x, y. (x = y = 0 en la esquina superior izquierda de la pantalla.)

Cuando se carga una fuente de 512 caracteres, la 9ª posición de bit puede ser obtenida aplicando la operación ioctl(2) VT_GETHIFONTMASK (disponible desde Linux 2.6.18) en /dev/tty[1-63]; el valor se devuelve en el unsigned short apuntado por el tercer argumento de ioctl(2).

Estos dispositivos reemplazan las operaciones ioctl(2) de volcado de pantalla de ioctl_console(2), por lo que el administrador del sistema puede controlar el acceso usando permisos del sistema de archivos.

Los dispositivos para las primeras ocho consolas virtuales pueden ser creados mediante:


for x in 0 1 2 3 4 5 6 7 8; do
    mknod -m 644 /dev/vcs$x c 7 $x;
    mknod -m 644 /dev/vcsa$x c 7 $[$x+128];
done
chown root:tty /dev/vcs*

No se soportan peticiones ioctl(2).

ARCHIVOS

/dev/vcs[0-63]
/dev/vcsa[0-63]

VERSIÓNES

Introducido con Linux 1.1.92.

EJEMPLOS

Puedes hacer un volcado de pantalla en vt3 cambiando a vt1 y escribiendo


cat /dev/vcs3 >foo

Ten en cuenta que la salida no contiene caracteres de nueva línea, por lo que puede ser necesario algún procesamiento, como en


fold -w 81 /dev/vcs3 | lpr

o (horror)


setterm -dump 3 -file /proc/self/fd/1

El dispositivo /dev/vcsa0 se usa para el soporte Braille.

Este programa muestra el carácter y los atributos de pantalla bajo el cursor de la segunda consola virtual, luego cambia el color de fondo allí:

#include <unistd.h>
#include <stdlib.h>
#include <stdio.h>
#include <fcntl.h>
#include <sys/ioctl.h>
#include <linux/vt.h>
int
main(void)
{
    int fd;
    char *device = "/dev/vcsa2";
    char *console = "/dev/tty2";
    struct {unsigned char lines, cols, x, y;} scrn;
    unsigned short s;
    unsigned short mask;
    unsigned char attrib;
    int ch;
    fd = open(console, O_RDWR);
    if (fd < 0) {
        perror(console);
        exit(EXIT_FAILURE);
    }
    if (ioctl(fd, VT_GETHIFONTMASK, &mask) < 0) {
        perror("VT_GETHIFONTMASK");
        exit(EXIT_FAILURE);
    }
    (void) close(fd);
    fd = open(device, O_RDWR);
    if (fd < 0) {
        perror(device);
        exit(EXIT_FAILURE);
    }
    (void) read(fd, &scrn, 4);
    (void) lseek(fd, 4 + 2*(scrn.y*scrn.cols + scrn.x), SEEK_SET);
    (void) read(fd, &s, 2);
    ch = s & 0xff;
    if (s & mask)
        ch |= 0x100;
    attrib = ((s & ~mask) >> 8);
    printf("ch=%#03x attrib=%#02x\n", ch, attrib);
    s ^= 0x1000;
    (void) lseek(fd, -2, SEEK_CUR);
    (void) write(fd, &s, 2);
    exit(EXIT_SUCCESS);
}

VER TAMBIÉN
