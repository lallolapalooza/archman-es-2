VIS-CLIPBOARD(1) Manual de comandos generales VIS-CLIPBOARD(1)

NOMBRE

vis-clipboard — Leer o escribir en el portapapeles del sistema

SINOPSIS

vis-clipboard --usable

vis-clipboard --copy [--selection selección]

vis-clipboard --paste [--selection selección]

DESCRIPCIÓN

vis-clipboard envuelve varias herramientas específicas del sistema para interactuar con el portapapeles del sistema, como xsel(1) para X11, pbcopy(1) para Mac OS X, y /dev/clipboard en Cygwin.

vis-clipboard puede ejecutarse de tres maneras diferentes, dependiendo de la bandera dada en la línea de comandos.

--usable
En este modo, vis-clipboard busca una forma de interactuar con el portapapeles del sistema. Si encuentra una, termina con código de salida 0. Si no hay ninguna interfaz disponible para el portapapeles del sistema, termina con código de salida 1.
--copy
En este modo, vis-clipboard lee el contenido de la entrada estándar y lo almacena en el portapapeles del sistema.
--paste
En este modo, vis-clipboard lee el contenido del portapapeles del sistema y lo escribe en la salida estándar.
--selection selección
especifica qué selección usar, las opciones son "primary" o "clipboard". Se ignora silenciosamente en plataformas con un solo portapapeles.

AMBIENTE

Las siguientes variables de entorno afectan la operación de vis-clipboard:

DISPLAY
Si no está vacío, vis-clipboard preferirá acceder al portapapeles de X11 incluso si hay otras opciones disponibles.

ESTADO DE SALIDA

La utilidad vis-clipboard termina con código 0 en caso de éxito, y >0 si ocurre un error. Cuando se ejecuta con la bandera --usable, un estado de salida de 0 significa que encontró una herramienta específica del sistema compatible, mientras que 1 significa que el acceso al portapapeles no está disponible.

EJEMPLOS

Probar si el acceso al portapapeles está disponible:

if vis-clipboard --usable; then
	echo "Acceso al portapapeles disponible"
else
	echo "Sin portapapeles"
fi

Copiar un saludo amistoso al portapapeles:

echo "Hola, Mundo" | vis-clipboard --copy

Enviar el contenido actual del portapapeles del sistema para que sea grabado y analizado:

vis-clipboard --paste | curl -d - https://www.nsa.gov/

VER TAMBIÉN

pbcopy(1), pbpaste(1), vis(1), xclip(1), xsel(1)
