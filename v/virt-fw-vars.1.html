VIRT-FW-VARS(1) Comandos de Usuario VIRT-FW-VARS(1)

NOMBRE

virt-fw-vars - página del manual para virt-fw-vars 25.10

DESCRIPCIÓN

La utilidad virt-fw-vars puede imprimir y modificar almacenes de variables UEFI. Los formatos compatibles son edk2 estándar (como se usa en ovmf y armvirt) y aws.

uso: virt-fw-vars [-h] [-l NIVEL] [-i ARCHIVO] [--inplace ARCHIVO]

[--extract-certs] [-d VAR] [--set-true VAR]
[--set-false VAR] [--set-json ARCHIVO] [--set-boot-uri ENLACE] [--append-boot-filepath ARCHIVO] [--set-shim-debug] [--set-shim-verbose] [--set-fallback-verbose] [--set-fallback-no-reboot] [--set-sbat-level ARCHIVO] [--set-pk GUID ARCHIVO] [--add-kek GUID ARCHIVO] [--add-db GUID ARCHIVO] [--add-db-hash GUID HASH] [--set-dbx ARCHIVO] [--add-dbx ARCHIVO] [--add-dbx-cert GUID ARCHIVO] [--add-dbx-hash GUID HASH] [--add-mok GUID ARCHIVO] [--add-mok-hash GUID HASH] [--enroll-redhat] [--enroll-cert CERT] [--enroll-generate CN] [--enroll-mgmt] [--no-microsoft] [--microsoft-db {none,win11,win23,win+rom23,uefi11,uefi23,uefi+rom23,all}] [--microsoft-kek {none,2011,2023,all}] [--distro-keys DISTRO] [--distro-list] [--sb] [-p] [-v] [--hashes] [-x] [-o ARCHIVO] [--output-aws ARCHIVO] [--output-json ARCHIVO] [--output-auth DIR]

Imprime y modifica almacenes de variables EFI.

opciones:

-h, --help
mostrar este mensaje de ayuda y salir
-l, --loglevel NIVEL
establecer el nivel de registro en NIVEL
-i, --input ARCHIVO
leer variables edk2 o aws de ARCHIVO
--inplace, --in-place ARCHIVO
modificar ARCHIVO in situ
--extract-certs
extraer todos los certificados

Opciones de variables:

-d, --delete VAR
eliminar la variable VAR, se puede especificar varias veces
--set-true VAR
establecer la variable VAR en verdadero, se puede especificar varias veces
--set-false VAR
establecer la variable VAR en falso, se puede especificar varias veces
--set-json ARCHIVO
establecer variables a partir del volcado json de ARCHIVO

Configuración de arranque:

--set-boot-uri ENLACE
establecer la URI de arranque de red en ENLACE (una vez, usando BootNext)
--append-boot-filepath ARCHIVO
añadir entrada de arranque para ARCHIVO (permanente, usando BootOrder)

Configuración de shim.efi:

--set-shim-debug
habilitar depuración de shim.efi (pausa para adjuntar depurador)
--set-shim-verbose
habilitar mensajes detallados de shim.efi
--set-fallback-verbose
habilitar mensajes detallados de fallback.efi
--set-fallback-no-reboot
deshabilitar el reinicio para fallback.efi
--set-sbat-level ARCHIVO
establecer la variable SbatLevel

Opciones de configuración de arranque seguro:

--set-pk, --set-pk-cert GUID ARCHIVO
establecer PK en certificado x509, cargado en formato pem o der desde ARCHIVO y con GUID de propietario
--add-kek, --add-kek-cert GUID ARCHIVO
añadir certificado x509 a KEK, cargado en formato pem o der desde ARCHIVO y con GUID de propietario, se puede especificar varias veces
--add-db, --add-db-cert GUID ARCHIVO
añadir certificado x509 a db, cargado en formato pem o der desde ARCHIVO y con GUID de propietario, se puede especificar varias veces
--add-db-hash GUID HASH
añadir HASH sha256 a db, con GUID de propietario, se puede especificar varias veces
--set-dbx ARCHIVO
inicializar dbx con la actualización de ARCHIVO
--add-dbx ARCHIVO
añadir actualización de dbx de ARCHIVO
--add-dbx-cert GUID ARCHIVO
añadir certificado x509 a dbx, cargado en formato pem o der desde ARCHIVO y con GUID de propietario, se puede especificar varias veces
--add-dbx-hash GUID HASH
añadir HASH sha256 a dbx, con GUID de propietario, se puede especificar varias veces
--add-mok, --add-mok-cert GUID ARCHIVO
añadir certificado x509 a MokList, cargado en formato pem o der desde ARCHIVO y con GUID de propietario, se puede especificar varias veces
--add-mok-hash GUID HASH
añadir HASH sha256 a MokList, con GUID de propietario, se puede especificar varias veces

Atajos de conveniencia de arranque seguro:

--enroll-redhat
inscribir certificados predeterminados para la plataforma redhat
--enroll-cert CERT
inscribir usando el certificado especificado
--enroll-generate CN
inscribir usando un certificado generado con el nombre común dado
--enroll-mgmt
inscribir usando guid de gestión externo
--no-microsoft
igual a "--microsoft-db none"
--microsoft-db, --profile {none,win11,win23,win+rom23,uefi11,uefi23,uefi+rom23,all}
elegir claves db de microsoft para inscribir
--microsoft-kek {none,2011,2023,all}
elegir claves KEK de microsoft para inscribir
--distro-keys DISTRO
añadir claves ca para DISTRO
--distro-list
listar distribuciones conocidas
--sb, --secure-boot
habilitar modo de arranque seguro

Opciones de impresión:

-p, --print
imprimir varstore
-v, --verbose
imprimir varstore detalladamente
--hashes
imprimir hashes sha256 de la base de datos de firmas
-x, --hexdump
imprimir volcado hexadecimal de variables

Opciones de salida:

-o, --output ARCHIVO
escribir variables edk2 o aws en ARCHIVO, usando el mismo formato que tiene ARCHIVO de --input.
--output-aws ARCHIVO
escribir variables aws en ARCHIVO
--output-json ARCHIVO
escribir volcado json en ARCHIVO
--output-auth DIR
escribir archivos *.auth en DIR

NAME

virt-fw-vars — manipulate UEFI firmware variables

SYNOPSIS

virt-fw-vars [OPTIONS] ...

DESCRIPTION

The virt-fw-vars utility can be used to manipulate UEFI firmware variables. It can print, enroll, or update variables in a firmware variable store file.

OPTIONS

--input FILE
Input variable store file (default: OVMF_VARS.fd).
--output FILE
Output variable store file (default: same as --input).
--print
Print variable store contents.
--enroll-redhat
Enroll default Red Hat secure boot certificates.
--secure-boot
Enable secure boot.
--verbose
Enable verbose output.

EXAMPLES

Print variable store.
virt-fw-vars --input ${guest}_VARS.fd \
--print --verbose
Enroll default (microsoft) secure boot certificates
virt-fw-vars --input OVMF_VARS.fd \
--output OVMF_VARS.secboot.fd \
--enroll-redhat \
--secure-boot
