VFWPRINTF(3P) Manual de Programador POSIX VFWPRINTF(3P)

PROLOG

Esta página del manual forma parte del Manual de Programador POSIX. La implementación de esta interfaz en Linux puede diferir (consulte la página del manual de Linux correspondiente para conocer los detalles del comportamiento en Linux), o la interfaz puede no estar implementada en Linux.

NOMBRE

vfwprintf, vswprintf, vwprintf — salida formateada de caracteres anchos de una lista de argumentos stdarg

SINOPIS

#include <stdarg.h>
#include <stdio.h>
#include <wchar.h>
int vfwprintf(FILE *restrict stream, const wchar_t *restrict format,
    va_list arg);
int vswprintf(wchar_t *restrict ws, size_t n,
    const wchar_t *restrict format, va_list arg);
int vwprintf(const wchar_t *restrict format, va_list arg);

DESCRIPCIÓN

La funcionalidad descrita en esta página de referencia está alineada con el estándar ISO C. Cualquier conflicto entre los requisitos descritos aquí y el estándar ISO C es no intencional. Este volumen de POSIX.1-2017 remite al estándar ISO C.

Las funciones vfwprintf(), vswprintf() y vwprintf() serán equivalentes a fwprintf(), swprintf() y wprintf() respectivamente, excepto que en lugar de ser llamadas con un número variable de argumentos, son llamadas con una lista de argumentos tal como se define en <stdarg.h>.

Estas funciones no invocarán la macro va_end. Sin embargo, dado que invocan la macro va_arg, el valor de ap después del retorno no está especificado.
