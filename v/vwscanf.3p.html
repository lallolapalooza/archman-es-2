VWSCANF(3P) Manual de Programador POSIX VWSCANF(3P)

PRÓLOGO

Esta página del manual forma parte del Manual del Programador POSIX. La implementación de esta interfaz en Linux puede diferir (consulte la página del manual de Linux correspondiente para obtener detalles sobre el comportamiento en Linux), o la interfaz puede no estar implementada en Linux.

NOMBRE

vwscanf — entrada con formato de caracteres anchos a partir de una lista de argumentos stdarg

SINOPSIS

#include <stdarg.h>
#include <stdio.h>
#include <wchar.h>
int vwscanf(const wchar_t *restrict format, va_list arg);

DESCRIPCIÓN

Consulte vfwscanf().
