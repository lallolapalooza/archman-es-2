VGCFGBACKUP(8) Manual del Administrador del Sistema VGCFGBACKUP(8)

NOMBRE

vgcfgbackup — Copia de seguridad de la configuración de grupos de volúmenes

SINOPSIS

vgcfgbackup
[ argumentos_opcionales ]
[ argumentos_posicionales ]

DESCRIPCIÓN

vgcfgbackup crea archivos de copia de seguridad que contienen metadatos de VGs. Si no se nombran VGs, se crean archivos de copia de seguridad para todos los VGs. Consulte vgcfgrestore(8) para obtener información sobre el uso de los archivos de copia de seguridad.

En una instalación predeterminada, cada VG se respalda en un archivo separado con el nombre del VG en el directorio /etc/lvm/backup.

Para usar un archivo de copia de seguridad alternativo, use -f. En este caso, al respaldar múltiples VGs, el nombre del archivo se trata como una plantilla, con %s reemplazado por el nombre del VG.

NB. Esto NO respalda el contenido de datos de los LVs.

También puede ser útil respaldar regularmente los archivos en /etc/lvm.

USO

vgcfgbackup

[ -f|--file Cadena ]
[ --foreign ]
[ --ignorelockingfailure ]
[ --readonly ]
[ --reportformat basic|json|json_std ]
[ OPCIONES_COMUNES ]
[ VG ... ]

OPCIONES

--commandprofile Cadena
El perfil de comando a utilizar para la configuración del comando. Consulte lvm.conf(5) para obtener más información sobre perfiles.
--config Cadena
Configuración para el comando. Estas anulan la configuración de lvm.conf(5). El argumento Cadena utiliza el mismo formato que lvm.conf(5), o puede utilizar la sintaxis de sección/campo. Consulte lvm.conf(5) para obtener más información sobre la configuración.
-d|--debug ...
Establece el nivel de depuración. Repítalo de 1 a 6 veces para aumentar el detalle de los mensajes enviados al archivo de registro y/o a syslog (si está configurado).
--devices PV
Restringe los dispositivos que son visibles y accesibles para el comando. Los dispositivos no listados parecerán faltar. Esta opción se puede repetir o acepta una lista de dispositivos separados por comas. Esto anula el archivo de dispositivos.
--devicesfile Cadena
Un archivo que lista los dispositivos que LVM debe usar. El archivo debe existir en /etc/lvm/devices/ y se gestiona con el comando lvmdevices(8). Esto anula la configuración devices/devicesfile y devices/use_devicesfile de lvm.conf(5).
--driverloaded s|n
Si se establece en no, el comando no intentará usar el mapeo de dispositivos. Para pruebas y depuración.
-f|--file Cadena
Escribe la copia de seguridad en el archivo con el nombre especificado. Al respaldar más de un VG, el nombre del archivo se trata como una plantilla y %s se reemplaza por el nombre del VG.
--foreign
Informa/muestra VGs extranjeros que de otro modo serían omitidos. Consulte lvmsystemid(7) para obtener más información sobre VGs extranjeros.
-h|--help
Muestra el texto de ayuda.
--ignorelockingfailure
Permite que un comando continúe con operaciones de metadatos de solo lectura después de fallos de bloqueo.
--journal Cadena
Registra información en el journal de systemd. Esta información se suma a la información habilitada por la configuración de registro/journal de lvm.conf. command: registra información sobre el comando. output: registra la salida predeterminada del comando. debug: registra la depuración completa del comando.
--lockopt Cadena
Se utiliza para pasar opciones para casos especiales a lvmlockd. Consulte lvmlockd(8) para obtener más información.
--longhelp
Muestra el texto de ayuda extenso.
--nohints
No utilizar el archivo de sugerencias para localizar dispositivos para PVs. Un comando puede leer más dispositivos para encontrar PVs cuando no se usan sugerencias. El comando aún realizará una invalidación estándar del archivo de sugerencias cuando sea apropiado.
--nolocking
Deshabilita el bloqueo. Úselo con precaución, los comandos concurrentes pueden producir resultados incorrectos.
--profile Cadena
Un alias para --commandprofile o --metadataprofile, dependiendo del comando.
-q|--quiet ...
Suprime la salida y los mensajes de registro. Anula --debug y --verbose. Repítalo una vez para también suprimir cualquier solicitud con respuesta 'no'.
--readonly
Evita que el comando realice cambios, incluida la activación y las actualizaciones de metadatos. (Ver --permission r para LVs de solo lectura).
--reportformat basic|json|json_std
Anula el formato de salida actual para informes, que se define globalmente mediante la configuración report/output_format en lvm.conf(5). basic es el formato original con columnas y filas. Si hay más de un informe por comando, cada informe se prefija con el nombre del informe para su identificación. json produce la salida del informe en formato JSON. json_std produce la salida del informe en formato JSON que es más compatible con el estándar JSON. Consulte lvmreport(7) para obtener más información.
-t|--test
Ejecutar en modo de prueba. Los comandos no actualizarán los metadatos. Esto se implementa deshabilitando toda escritura de metadatos, pero devolviendo éxito a la función de llamada. Esto puede generar mensajes de error inusuales en operaciones de múltiples etapas si una herramienta depende de leer metadatos que cree que han cambiado pero no lo han hecho.
-v|--verbose ...
Establece el nivel de verbosidad. Repita de 1 a 4 veces para aumentar el detalle de los mensajes enviados a stdout y stderr.
--version
Muestra la información de la versión.
-y|--yes
No solicite confirmación de forma interactiva, sino que siempre asuma la respuesta sí. Úselo con extrema precaución. (Para un no automático, consulte -qq).

NAME

vgcfgbackup — backup a Volume Group metadata configuration

SYNOPSIS

vgcfgbackup [options] [VolumeGroupName]

DESCRIPTION

This command backs up the metadata configuration of one or more Volume Groups. If VolumeGroupName is specified, only the metadata for that specific Volume Group is backed up. If not specified, all Volume Group metadata configurations are backed up.

The backup is written to a file in /etc/lvm/backup/. The file is named after the Volume Group and the current date and time.

This command is part of the LVM Tools.

USAGE

Back up the metadata configuration of the Volume Group named “myvg”:

vgcfgbackup myvg

Back up the metadata configuration of all Volume Groups:

vgcfgbackup

OPTIONS

-a, --all
Back up all Volume Group metadata configurations. This is the default behavior if no VolumeGroupName is specified.
-h, --help
Display help information and exit.
-m, --metadata
Back up the metadata configuration. This is the default behavior.
-t, --test
Perform a trial run with no changes made.
-u, --uuid
Back up the UUIDs of the Volume Groups. This is the default behavior.
-v, --verbose
Enable verbose mode.

VARIABLES

The following variables are used by this command:

UNITS

Units are always treated as base two values, regardless of capitalization, e.g. 'k' and 'K' both refer to 1024. The default input unit is specified by letter, followed by |UNIT. UNIT represents other possible input units: b|B is bytes, s|S is sectors of 512 bytes, k|K is KiB, m|M is MiB, g|G is GiB, t|T is TiB, p|P is PiB, e|E is EiB. (This should not be confused with the output control --units, where capital letters mean multiple of 1000.)

ENVIRONMENT VARIABLES

See lvm(8) for information about environment variables used by lvm. For example, LVM_VG_NAME can generally be substituted for a required VG parameter.
