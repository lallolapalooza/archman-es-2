VIMDIFF(1) Manual de Comandos Generales VIMDIFF(1)

NOMBRE

vimdiff - editar entre dos y ocho versiones de un archivo con Vim y mostrar las diferencias

SINOPSIS

vimdiff [opciones] archivo1 archivo2 [archivo3 [archivo4 [archivo5 [archivo6 [archivo7 [archivo8]]]]]]

gvimdiff

DESCRIPCIÓN

Vimdiff inicia Vim en dos hasta ocho archivos. Cada archivo tiene su propia ventana. Las diferencias entre los archivos se resaltan. Esta es una buena manera de inspeccionar cambios y mover cambios de una versión a otra versión del mismo archivo.

Consulte vim(1) para obtener detalles sobre Vim en sí.

Cuando se inicia como gvimdiff, se iniciará la GUI, si está disponible.

En cada ventana se establecerá la opción 'diff', que hace que las diferencias se resalten.
Las opciones 'wrap' y 'scrollbind' se establecen para que el texto se vea bien.
La opción 'foldmethod' se establece en "diff", que agrupa rangos de líneas sin cambios en un plegado. 'foldcolumn' se establece en dos para que sea fácil detectar los plegados y abrirlos o cerrarlos.

OPCIONES

Se utilizan divisiones verticales para alinear las líneas, como si se hubiera usado el argumento "-O". Para usar divisiones horizontales en su lugar, utilice el argumento "-o".

Para todos los demás argumentos, consulte vim(1).
