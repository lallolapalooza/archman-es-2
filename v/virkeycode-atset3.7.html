Name

virkeycode-atset3 - keyboard definition for AT Set 3 keyboard

DESCRIPTION

This is a keyboard definition for the AT Set 3 keyboard layout. This keyboard layout is the default layout for most modern PCs. It is a variant of the AT Set 1 and AT Set 2 layouts, which were used in older AT computers.

The AT Set 3 keyboard layout is a QWERTY layout, which means that the keys are arranged in the same order as the letters on a standard typewriter. The layout also includes a numeric keypad, function keys, and other special keys.
