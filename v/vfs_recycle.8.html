VFS_RECYCLE(8) Herramientas de administración del sistema VFS_RECYCLE(8)

NOMBRE

vfs_recycle - Papelera de reciclaje VFS de Samba

SINOPSIS

objetos vfs = recycle

DESCRIPCIÓN

Este módulo VFS forma parte de la suite samba(7).

Recycle intercepta las solicitudes de eliminación de archivos y mueve los archivos afectados a un repositorio temporal en lugar de eliminarlos inmediatamente. Esto produce el mismo efecto que la Papelera de Reciclaje en los ordenadores con Windows.

La Papelera de Reciclaje no aparecerá en las vistas del Explorador de Windows del sistema de archivos de red (recurso compartido) ni en ninguna unidad mapeada. En su lugar, se creará automáticamente un directorio llamado .recycle cuando se elimine el primer archivo y no se configure recycle:repository. Si se configura recycle:repository, el nombre del directorio creado dependerá de recycle:repository. Los usuarios pueden recuperar archivos de la papelera de reciclaje. Si se ha especificado la opción recycle:keeptree, los archivos eliminados se encontrarán en una ruta idéntica a aquella desde la que se eliminó el archivo.

Este módulo es apilable.

OPCIONES

recycle:repository = RUTA

Ruta del directorio donde se deben mover los archivos eliminados.

Si esta opción no está establecida, se utiliza la ruta predeterminada .recycle.

recycle:directory_mode = MODO

Establece MODO al modo octal con el que se debe crear el repositorio de reciclaje. El repositorio de reciclaje se creará cuando se elimine el primer archivo. Si no se establece recycle:subdir_mode, MODO también se aplica a los subdirectorios.

Si esta opción no está establecida, se utiliza el modo predeterminado 0700.

recycle:subdir_mode = MODO

Establece MODO al modo octal con el que se deben crear los subdirectorios del repositorio de reciclaje.

Si esta opción no está establecida, los subdirectorios se crearán con el modo de recycle:directory_mode.

recycle:keeptree = BOLEANO

Especifica si la estructura de directorios debe conservarse o si los archivos en un directorio que se está eliminando deben mantenerse separadamente en el repositorio.

recycle:versions = BOLEANO

Si esta opción es True, dos archivos con el mismo nombre que se eliminen se conservarán en el repositorio. Las versiones eliminadas más recientes de un archivo se llamarán "Copia #x de nombre de archivo".

recycle:touch = BOLEANO

Especifica si la fecha de acceso de un archivo debe actualizarse cuando el archivo se mueva al repositorio.

recycle:touch_mtime = BOLEANO

Especifica si la fecha de última modificación de un archivo debe actualizarse cuando el archivo se mueva al repositorio.

recycle:minsize = BYTES

Los archivos que sean más pequeños que el número de bytes especificado por este parámetro no se colocarán en el repositorio.

recycle:maxsize = BYTES

Los archivos que sean más grandes que el número de bytes especificado por este parámetro no se colocarán en el repositorio.

recycle:exclude = LISTA

Lista de archivos que no deben colocarse en el repositorio cuando se eliminen, sino que deben eliminarse de la forma habitual. Se admiten comodines como * y ?.

recycle:exclude_dir = LISTA

Lista de directorios cuyos archivos no deben colocarse en el repositorio cuando se eliminen, sino que deben eliminarse de la forma habitual. Se admiten comodines como * y ?.

recycle:noversions = LISTA

Especifica una lista de rutas (se admiten comodines como * y ?) para las cuales no se debe usar versionado. Solo útil cuando recycle:versions está habilitado.

EJEMPLOS

Mover los archivos "eliminados" en share a /data/share/.recycle en lugar de eliminarlos:

        [share]
	path = /data/share
	vfs objects = recycle
	recycle:repository = .recycle
	recycle:keeptree = yes
	recycle:versions = yes
