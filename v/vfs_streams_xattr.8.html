VFS_STREAMS_XATTR(8) Herramientas de administración del sistema VFS_STREAMS_XATTR(8)

NOMBRE

vfs_streams_xattr - Almacena flujos de datos alternativos en xattrs posix

SINOPSIS

vfs objects = streams_xattr

DESCRIPCIÓN

Este módulo VFS forma parte del conjunto de utilidades de samba(7).

vfs_streams_xattr permite almacenar flujos de datos alternativos de NTFS en el sistema de archivos. Como un sistema de archivos posix normal no soporta el concepto de múltiples flujos de datos por archivo, el módulo streams_xattr almacena los datos en atributos extendidos (xattrs) posix. El nombre de estos atributos por defecto es user.DosStream."ADS-NAME". El prefijo "user.DosStream." se puede cambiar con la opción del módulo streams_xattr:prefix, pero ten en cuenta que esto también expondrá esos ADS a través de la interfaz de atributos extendidos de SMB.

El sistema de archivos que se comparte con este módulo habilitado debe soportar xattrs.

Por favor, ten en cuenta que la mayoría de los sistemas de archivos tienen severas limitaciones en el tamaño de los xattrs. Por lo tanto, este módulo puede funcionar para aplicaciones como IE que almacenan pequeña información de zona en flujos, pero fallará para aplicaciones que almacenan grandes cantidades de datos en ADS.

OPCIONES

streams_xattr:prefix = STRING

Prefijo de nombre utilizado al almacenar un ADS en un xattr, por defecto es user.DosStream.. Cambiar esto también expondrá los ADS a través de la interfaz de atributos extendidos de SMB.

streams_xattr:store_stream_type = [yes|no]

Si los nombres de los xattr para los Flujos de Datos Alternativos de tipo "$DATA" se sufijan con la cadena de tipo de flujo ":$DATA". El valor por defecto es yes.

EJEMPLOS

        [share]
	vfs objects = streams_xattr
