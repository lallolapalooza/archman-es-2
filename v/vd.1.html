NOMBRE

VisiData — una utilidad de terminal para explorar y organizar datos tabulares

SINOPSIS

vd [opciones] [entrada ...]

visidata [opciones] [entrada ...]

vd [opciones] --play registro_comandos [-w segundos_espera] [--batch] [-i] [-o salida] [campo=valor]

vd [opciones] [entrada ...] +hoja_nivel_superior:subhoja:fila:columna

DESCRIPCIÓN

VisiData es una herramienta multifuncional fácil de usar para explorar, limpiar, editar y reestructurar datos. Las filas se pueden seleccionar, filtrar y agrupar; las columnas se pueden reorganizar, transformar y derivar mediante expresiones regulares o de Python; y los flujos de trabajo se pueden guardar, documentar y reproducir.

MODO REPRODUCCIÓN

-p, --play=registro_comandos
reproduce un registro_comandos guardado dentro de la interfaz
-w, --replay-wait=segundos
espera segundos entre comandos
-b, --batch
reproduce en modo batch (sin interfaz)
-i, --interactive
lanza VisiData en modo interactivo después del batch
-o, --output=archivo
guarda la hoja visible final en archivo como .tsv
campo=valor
reemplaza "{campo}" en el contenido de registro_comandos con valor

Comandos durante la reproducción

^K
cancela la reproducción actual

COMANDOS GLOBALES

Todas las pulsaciones de teclas distinguen entre mayúsculas y minúsculas. El prefijo ^ es una abreviatura de Ctrl.

Pulsaciones de teclas para empezar

^Q
abortar el programa inmediatamente
^C
cancelar la entrada del usuario o abortar todos los hilos asíncronos en la hoja actual
g^C
abortar todos los hilos secundarios
q
salir de la hoja o menú actual
Q
salir de la hoja actual y liberar la memoria asociada
gq
salir de todas las hojas (salida limpia)
Alt+H
activar el menú de ayuda (Intro/ratón-izquierdo para expandir submenú o ejecutar comando)
g^H
ver esta página del manual
z^H
ver la hoja de nombres largos y atajos de teclado para la hoja actual
gb
abrir barra lateral en una hoja nueva
b
alternar barra lateral
U
deshacer la modificación más reciente (requiere habilitar options.undo)
R
rehacer el último deshacer (requiere habilitar options.undo)
Espacio nombre_largo
abre la paleta de comandos; ejecuta el comando superior por su nombre_largo

Paleta de comandos

Tab
Mueve a la paleta de comandos y recorre los comandos
0-9
Ejecuta el comando numerado
Intro
Ejecuta el comando resaltado

C regex

c regex

navegar a la anterior celda con valor coincidente regex

navegar a la anterior columna cuyo nombre coincide con regex

navegar hacia adelante/atrás en la columna actual (con nombres de columna como expr de Python)

ir arriba/abajo en la columna actual al siguiente valor
z< z>

Manipulación de Columnas

_ (guion bajo)
alternar el ancho de la columna actual entre ancho completo y predeterminado
g_
alternar los anchos de todas las columnas visibles entre ancho completo y predeterminado
z_ número
ajustar el ancho de la columna actual a número
gz_ número
ajustar los anchos de todas las columnas visibles al número Ar
- (guion)
ocultar la columna actual
g- (guion)
ocultar cualquier columna que tenga múltiples filas pero solo un valor distinto
z-
reducir el ancho de la columna actual a la mitad
gv
mostrar todas las columnas
! z!
alternar/desactivar la columna actual como columna clave
~ # % $ @ z#
establecer el tipo de la columna actual a cadena/entero/flotante/moneda/fecha/longitud
Alt++ Alt+-
mostrar más/menos precisión en la columna numérica actual
^
renombrar la columna actual
g^
renombrar todas las columnas visibles sin nombre al contenido de las filas seleccionadas (o fila actual)
z^
renombrar la columna actual al contenido combinado de la celda actual en las filas seleccionadas (o fila actual)
gz^
renombrar todas las columnas visibles al contenido combinado de la columna actual para las filas seleccionadas (o fila actual)
= expr
crear nueva columna desde Python expr, con nombres de columna y atributos como variables
g= expr
establecer la columna actual para las filas seleccionadas al resultado de Python expr
gz= expr
establecer la columna actual para las filas seleccionadas a los elementos del resultado de la secuencia de Python expr
z= expr
evaluar la expresión de Python en la fila actual y establecer la celda actual con el resultado de Python expr
i
agregar columna con valores incrementales
gi
establecer la columna actual para las filas seleccionadas con valores incrementales
zi paso
agregar columna con valores a un incremento paso
gzi paso
establecer la columna actual para las filas seleccionadas a un incremento paso
' (apóstrofo)
agregar una copia congelada de la columna actual con todas las celdas evaluadas
g'
abrir una copia congelada de la hoja actual con todas las columnas visibles evaluadas
z' gz'
agregar/restablecer caché para la(s) columna(s) actual(es)/todas las visibles
Note que las operaciones de regex se aplican al valor mostrado en una celda.
 
: regex
agregar nuevas columnas desde regex dividido; el número de columnas determinado por la fila de ejemplo en el cursor
; regex
agregar nuevas columnas desde grupos de captura de regex (también requiere fila de ejemplo)
z; expr
crear nueva columna desde bash expr, con $los nombres de columna como variables
* búsqueda Tab reemplazo
agregar columna derivada de la columna actual, reemplazando búsqueda regex con reemplazo (puede incluir \1 referencias inversas)
g* gz* búsqueda Tab reemplazo
modificar filas seleccionadas en la(s) columna(s) actual(es)/todas las visibles, reemplazando búsqueda con reemplazo (puede incluir \1 referencias inversas)
( g(
expandir columna(s) actual(es)/todas las visibles de listas (p.ej. [3]) o diccionarios (p.ej. {3}) un nivel
z( gz( profundidad
expandir columna(s) actual(es)/todas las visibles de listas (p.ej. [3]) o diccionarios (p.ej. {3}) hasta la profundidad dada (0= completamente)
) g(
contraer columna(s) actual(es)/todas las visibles; restaurar columna original y eliminar otras columnas en este nivel
z) gz) profundidad
contraer columna(s) actual(es)/todas las visibles de listas anteriores (p.ej. [3]) o diccionarios (p.ej. {3}) hasta la profundidad dada (0= completamente)
zM
expandir por fila la columna actual de listas (p.ej. [3]) o diccionarios (p.ej. {3}) dentro de esa columna

METAHJAS

Hoja de Columnas (Shift+C)

Las propiedades de las columnas en la hoja de origen se pueden cambiar con comandos de edición estándar (e ge g= Del) en la Hoja de Columnas. Se pueden establecer múltiples agregadores listándolos (separados por espacios) en la columna de agregadores. Los comandos 'g' afectan a las filas seleccionadas, que son las columnas literales en la hoja de origen.
(comandos globales)
gC
abrir la Hoja de Columnas con todas las columnas visibles de todas las hojas
(comandos específicos de hoja)
&
añadir columna a partir de la unión de columnas de origen seleccionadas
g! gz!
alternar/desestablecer columnas seleccionadas como columnas clave en la hoja de origen
g+ agregador
añadir el Ar agregador No a las columnas de origen seleccionadas
g- (guion)
ocultar columnas seleccionadas en la hoja de origen
g~ g# g% g$ g@ gz# z%
establecer el tipo de las columnas seleccionadas en la hoja de origen a str/int/float/currency/date/len/floatsi
Enter
abrir una hoja de Tabla de Frecuencia agrupada por la columna referenciada en la fila actual

Hoja de Hojas (Shift+S)

abrir la Pila de Hojas, que contiene solo las hojas activas en la pila actual
(comandos globales)
gS
abrir la Hoja de Hojas, que contiene todas las hojas de la sesión actual, activas e inactivas
Alt número
saltar a la hoja número
(comandos específicos de hoja)
Enter
saltar a la hoja referenciada en la fila actual
gEnter
mover las hojas seleccionadas a la parte superior de la pila de hojas
a
añadir fila para referenciar una nueva hoja en blanco
gC gI
abrir la Hoja de Columnas / Hoja de Descripción con todas las columnas visibles de las hojas seleccionadas
g^R
recargar todas las hojas seleccionadas
z^C gz^C
abortar hilos asíncronos para la(s) hoja(s) actual(es)/seleccionada(s)
g^S
guardar hojas seleccionadas o todas
& tipo de unión
combinar las hojas seleccionadas con las columnas visibles de todas, manteniendo las filas según el tipo de unión:
.
interior mantener solo las filas que coinciden con las claves en todas las hojas
.
exterior mantener todas las filas de la primera hoja seleccionada
.
completo mantener todas las filas de todas las hojas (unión)
.
diferencia mantener solo las filas NO presentes en todas las hojas
.
añadir combinar todas las filas de todas las hojas
.
concatenar similar a 'añadir' pero manteniendo el tipo y las columnas de la primera hoja
.
extender copiar la primera hoja seleccionada, manteniendo todas las filas y el tipo de hoja, y extender con columnas de otras hojas
.
fusionar mantener todas las filas de la primera hoja, actualizando cualquier celda Falsa con valores no Falsos de la segunda hoja; añadir filas únicas de la segunda hoja

(comandos globales)
Shift+O
editar opciones globales (aplicar a todas las hojas)
zO

(comandos específicos de la hoja)

d
eliminar la anulación de opción para este contexto
^S

HOJAS DERIVADAS

Tabla de Frecuencia (Shift+F)

Una Tabla de Frecuencia agrupa filas por una o más columnas, e incluye columnas de resumen para aquellas con agregadores.
(comandos globales)
gF
abrir Tabla de Frecuencia, agrupada por todas las columnas clave de la hoja fuente
zF
abrir resumen de una línea para todas las filas y filas seleccionadas
(comandos específicos de la hoja)
s t u
seleccionar/deseleccionar/marcar estas entradas en la hoja fuente
Enter gEnter
abrir copia de la hoja fuente con filas agrupadas en la celda actual / filas seleccionadas

Hoja de Descripción (Shift+I)

Una Hoja de Descripción contiene estadísticas descriptivas para todas las columnas visibles.
(comandos globales)
gI
abrir Hoja de Descripción para todas las columnas visibles en todas las hojas
(comandos específicos de la hoja)
zs zu
seleccionar/deseleccionar filas en la hoja fuente que están siendo descritas en la celda actual
!
activar/desactivar la columna actual como columna clave en la hoja fuente
Enter
abrir una Tabla de Frecuencia agrupada por la columna referenciada en la fila actual
zEnter
abrir copia de la hoja fuente con filas descritas en la celda actual

Tabla Dinámica (Shift+W)

Establezca la(s) columna(s) clave y los agregadores en las columnas antes de presionar Shift+W en la columna a pivotar.
(comandos específicos de la hoja)
Enter
abrir hoja de filas fuente agregadas en la fila dinámica actual
zEnter
abrir hoja de filas fuente agregadas en la celda dinámica actual

Hoja Derretida (Shift+M)

Abrir Hoja Derretida (despivotar), conservando las columnas clave y reduciendo todas las columnas no clave a filas de Variable-Valor.
(comandos globales)
gM regex
abrir Hoja Derretida (despivotar), conservando las columnas clave y regex los grupos de captura determinarán cómo se reducirán las columnas no clave a filas de Variable-Valor.

NOMBRE

vd – hoja de cálculo interactiva para líneas de comandos

SINOPSIS

vd [options] [source] [sourceoptions]

DESCRIPCIÓN

VisiData es una herramienta de hoja de cálculo interactiva para la línea de comandos. Permite a los usuarios ver, modificar y analizar datos de forma rápida y eficiente. Soporta una amplia variedad de fuentes de datos, incluyendo archivos de texto delimitados, bases de datos SQL y formatos más exóticos.

VisiData combina la velocidad de las herramientas de línea de comandos con la potencia y la facilidad de uso de las hojas de cálculo gráficas.

El siguiente diagrama ilustra la arquitectura básica de VisiData:

vd --source :postgres/db
abre una conexión a la base de datos postgres dada
vd --play tests/pivot.vdj --replay-wait 1 --output tests/pivot.tsv
reproduce tests/pivot.vdj, esperando 1 segundo entre comandos, y emite la hoja final a test/pivot.tsv
ls -l | vd -f fixed --skip 1 --header 0
analiza la salida de ls -l en datos utilizables
ls | vd | lpr
selecciona interactivamente una lista de nombres de archivo para enviar a la impresora
vd newfile.tsv
abre una hoja en blanco llamada newfile si el archivo no existe
vd sample.xlsx +:sheet1:2:3
lanza con sheet1 en la cima de la pila, y el cursor en la columna 2 y la fila 3
vd -P open-plugins
pre-reproduce longname open-plugins antes de iniciar la sesión

ARCHIVOS

Al inicio de cada sesión, VisiData busca $HOME/.visidatarc, y llama a Python exec() sobre su contenido si existe. Por ejemplo:

options.min_memory_mb=100  # detener el procesamiento sin 100MB libres

bindkey('0', 'go-leftmost')   # alias '0' para ir a la primera columna, como vim

def median(values):
    L = sorted(values)
    return L[len(L)//2]

vd.aggregator('median', median)

Las funciones definidas en .visidatarc están disponibles en expresiones de python (por ejemplo, en columnas derivadas).

FUENTES SOPORTADAS

VisiData Core incluye estas fuentes:

tsv (valor separado por tabulaciones)
Simple y llano. VisiData escribe en formato tsv por defecto. Ver la opción --tsv-delimiter.
csv (valor separado por comas)
Los archivos .csv son una plaga sobre la tierra, y todavía lamentablemente comunes.
Ver las opciones --csv-dialect, --csv-delimiter, --csv-quotechar, y --csv-skipinitialspace.
Los dialectos aceptados son excel-tab, unix, y excel.
fixed (texto de ancho fijo)
Las columnas se detectan automáticamente de las primeras 1000 filas (ajustable con --fixed-rows).
json (objeto único) y jsonl/ndjson/ldjson (un objeto por línea).
Las celdas que contienen listas (por ejemplo, [3]) o diccionarios ({3}) se pueden expandir a nuevas columnas con ( y contraer con ).
sqlite
Puede incluir múltiples tablas. La hoja inicial es el directorio de tablas;
Enter carga la tabla completa en memoria. z^S guarda las modificaciones en la fuente.

Los esquemas de URL también son compatibles:

http (requiere requests); puede ser utilizado como transporte para con otro tipo de archivo

Para una lista de todos los formatos restantes soportados por VisiData, ver https://visidata.org/formats.

Además, los archivos .zip, .gz, .bz2, .xz, ,zstd, y .zst se descomprimen sobre la marcha.
