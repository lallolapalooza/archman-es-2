NOMBRE

virt-tar-out - Empaqueta un directorio de imagen de disco de máquina virtual en un tarball.

SINOPSIS

virt-tar-out -a disk.img /dir files.tar
virt-tar-out -d domain /dir files.tar
virt-tar-out -d domain /dir - | gzip --best > files.tar.gz

DESCRIPCIÓN

"virt-tar-out" empaqueta un directorio de imagen de disco de máquina virtual en un tarball.

El primer parámetro es la ruta absoluta del directorio de la máquina virtual. El segundo parámetro es el archivo tar a escribir. Use "-" para escribir en la salida estándar.

EJEMPLOS

Descargar los directorios de inicio de un invitado:

virt-tar-out -d MyGuest /home - | gzip --best > homes.tar.gz

SOLO UN SCRIPT DE ENVOLTURA SOBRE GUESTFISH

Este comando es solo un script simple de envoltura alrededor del comando "tar-out" de guestfish(1). Para algo más complejo que una copia trivial, probablemente sea mejor usar guestfish directamente.

OPCIONES

Dado que el script de shell simplemente pasa las opciones directamente a guestfish, lea guestfish(1) para ver la lista completa de opciones.

VER TAMBIÉN

guestfish(1), virt-cat(1), virt-copy-in(1), virt-copy-out(1), virt-edit(1), virt-tar-in(1), http://libguestfs.org/.
