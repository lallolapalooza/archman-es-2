vmsish(3perl) Guía de referencia del programador de Perl vmsish(3perl)

NOMBRE

vmsish - Pragma de Perl para controlar las características del lenguaje específicas de VMS

SINAPSIS

use vmsish;
use vmsish 'status';        # o '$?'
use vmsish 'exit';
use vmsish 'time';
use vmsish 'hushed';
no vmsish 'hushed';
vmsish::hushed($hush);
use vmsish;
no vmsish 'time';

DESCRIPCIÓN

Si no se proporciona una lista de importación, se asumen todas las características posibles específicas de VMS. Actualmente, hay cuatro características específicas de VMS disponibles: 'status' (también conocido como '$?'), 'exit', 'time' y 'hushed'.

Si no estás ejecutando VMS, este módulo no hace nada.

"vmsish status"
Esto hace que $? y "system" devuelvan el estado de salida nativo de VMS en lugar de emular el estado de salida POSIX.
"vmsish exit"
Esto hace que "exit 1" produzca una salida exitosa (con el estado SS$_NORMAL), en lugar de emular el exit() de UNIX, que considera "exit 1" como una indicación de error. Al igual que con la función exit() de CRTL, "exit 0" también se mapea a un estado de salida de SS$_NORMAL, y cualquier otro argumento a exit() se utiliza directamente como estado de salida de Perl.
"vmsish time"
Esto hace que todos los tiempos sean relativos a la zona horaria local, en lugar de la predeterminada Hora Universal (también conocida como Hora Media de Greenwich, o GMT).
"vmsish hushed"
Esto suprime la impresión de mensajes de estado de VMS en SYS$OUTPUT y SYS$ERROR si Perl termina con un estado de error, y permite que los programas que esperan un Perl de "estilo unix" eviten tener que analizar mensajes de error de VMS. No suprime ningún mensaje de Perl en sí, solo los mensajes generados por DCL después de que Perl sale. El símbolo DCL $STATUS seguirá teniendo el estado de terminación, pero con un bit de orden superior establecido:

EJEMPLO:
$ perl -e"exit 44;" Salida de error no silenciosa
%SYSTEM-F-ABORT, mensaje de abortar DCL
$ show sym $STATUS
$STATUS == "%X0000002C"

$ perl -e"use vmsish qw(hushed); exit 44;"   Salida de error silenciosa
$ show sym $STATUS
  $STATUS == "%X1000002C"

El indicador 'hushed' tiene un alcance global durante la compilación: los comandos exit() o die() que se compilan después de 'vmsish hushed' se silenciarán cuando se ejecuten. Hacer un "no vmsish 'hushed'" desactiva el indicador 'hushed'.

El estado del indicador 'hushed' también afecta la salida de mensajes de error de VMS por errores de compilación. De nuevo, sigues obteniendo el mensaje de error de Perl (y el código en $STATUS)

EJEMPLO:
use vmsish 'hushed'; # activa el indicador 'hushed'
use Carp; # Carp compilado en modo silencioso
exit 44; # se silenciará
croak('Me muero'); # se silenciará
no vmsish 'hushed'; # desactiva el indicador 'hushed'
exit 44; # no se silenciará
croak('Me muero2'): # SE silenciará, croak se compiló en modo silencioso

También puedes controlar el indicador 'hushed' en tiempo de ejecución, usando la rutina incorporada vmsish::hushed(). Sin argumentos, devuelve el estado 'hushed'. Dado que vmsish::hushed es incorporada, no necesitas "use vmsish" para llamarla.

EJEMPLO:
if ($quiet_exit) {
vmsish::hushed(1);
}
print "Sssshhhh... Estoy en silencio...\n" if vmsish::hushed();
exit 44;

Ten en cuenta que un exit() o die() que se compila 'hushed' debido a "use vmsish" no se desemudecen llamando a vmsish::hushed(0) en tiempo de ejecución.

Los mensajes de salidas de error desde el interior del núcleo de Perl son generalmente más serios y no se suprimen.

Ver "Módulos Perl" en perlmod.
