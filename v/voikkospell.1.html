VOIKKOSPELL(1) Manual de comandos generales VOIKKOSPELL(1)

NOMBRE

voikkospell - programa de prueba para el corrector ortográfico de Voikko

SINOPSIS

voikkospell [opciones]

DESCRIPCIÓN

voikkospell es un programa de prueba para la funcionalidad de corrección ortográfica de libvoikko, una biblioteca de herramientas de lenguaje. Lee palabras de la entrada estándar (una palabra por línea) y las imprime en la salida estándar, añadiendo "C: " delante de las palabras correctas y "W: " delante de las palabras incorrectas.

Las opciones comunes de los diferentes programas de prueba de Voikko se enumeran en OPCIONES COMUNES.

OPCIONES

-m
Además del resultado de la corrección ortográfica, imprime información de análisis morfológico (A:) para las palabras reconocidas.
-M
Imprime información de análisis morfológico (A:) para las palabras reconocidas sin mostrar el resultado de la corrección ortográfica.
-t
Imprime solo "C" o "W" en lugar de la salida completa típica.
-tt
Imprime solo las palabras mal escritas.
-s
Imprime sugerencias (S:) para palabras mal escritas.
-cn
Establece el parámetro de tamaño de caché a n. -1 deshabilita la caché y 0 es el valor predeterminado. Para comprobar grandes cantidades de texto no ordenado, es posible que desee establecer n en 5 para obtener un mejor rendimiento.
-j n
Utiliza n hilos para la corrección ortográfica. Cuando se utiliza más de un hilo, la comprobación se realiza utilizando grandes búferes internos, por lo que este modo solo debe utilizarse para procesamiento por lotes.
-xc
Similar a voikkospell -s pero la salida se imprime en una sola línea separada por el carácter c sin "C", "W" o "S" delante de las palabras. Si c no está definido, las palabras se separan por espacios y las sugerencias que contienen espacios no se imprimen.
-l
Imprime una lista de variantes de diccionario disponibles y sale. La primera variante es la predeterminada a utilizar cuando no se ha solicitado ninguna variante específica.
-L
Imprime una lista de capacidades e idiomas para los que estas capacidades están soportadas.
ignore_nonwords=n
accept_first_uppercase=n
accept_all_uppercase=n
accept_extra_hyphens=n
accept_missing_hyphens=n
ocr_suggestions=n

Establece el valor de la opción booleana especificada. n puede ser 0 (falso) o 1 (verdadero).

OPCIONES COMUNES

-p directorio
(voikkospell, voikkohyphenate, voikkogc) Busca en directorio antes de las ubicaciones estándar al buscar archivos de diccionario.
-d variante
(voikkospell, voikkohyphenate, voikkogc) Utiliza la variante de diccionario variante en lugar de la variante de diccionario predeterminada. La variante debe representarse como una etiqueta de idioma BCP 47.
ignore_dot=n
(voikkospell, voikkohyphenate)
ignore_numbers=n
(voikkospell, voikkohyphenate)
Establece el valor de la opción booleana especificada. n puede ser 0 (falso) o 1 (verdadero).
-h, --help
Imprime un mensaje de ayuda y sale.
--version
Imprime los números de versión de libvoikko y la herramienta de prueba.
