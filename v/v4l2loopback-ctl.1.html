v4l2loopback-ctl(1)

Paquete: v4l2loopback-utils

Licencias: GPL2

UNABLE(1) Comandos de Usuario UNABLE(1)

NOMBRE

v4l2loopback-ctl - controlar dispositivos v4l2 loopback

SINOPSIS

v4l2loopback-ctl [OPCIONES]
v4l2loopback-ctl add [OPCIONES] [<dispositivo_salida> [<dispositivo_captura>]]
v4l2loopback-ctl delete <dispositivo>
v4l2loopback-ctl list [OPCIONES]
v4l2loopback-ctl query [OPCIONES] <dispositivo>
v4l2loopback-ctl set-fps <dispositivo> <fps>
v4l2loopback-ctl get-fps <dispositivo>
v4l2loopback-ctl set-caps <dispositivo> <caps>
v4l2loopback-ctl get-caps <dispositivo>
v4l2loopback-ctl set-timeout-image [OPCIONES] <dispositivo> <imagen>

DESCRIPCIÓN

Gestiona dispositivos v4l2 loopback.

La invocación general usa un verbo (como 'add' o 'delete') que define una acción a ejecutar. Cada verbo tiene sus propias opciones y argumentos.

OPCIONES

-h, -?, --help: imprime esta ayuda y sale

-v, --version: imprime la versión y sale

VERBOS Y SUS ARGUMENTOS

v4l2loopback-ctl add [OPCIONES] [<dispositivo_salida> [<dispositivo_captura>]]:

crea/añade un nuevo dispositivo loopback
-b <num>, --buffers <num>
buffers a encolar
-a <a>, --max-height <a>
altura máxima de fotograma permitida
-n <nombre>, --name <nombre>
nombre descriptivo para el dispositivo

-o <num>, --max-openers <num> número máximo de aberturas concurrentes permitidas

-v, --verbose
modo detallado (imprime las propiedades del dispositivo después de crearlo exitosamente)
-a <a>, --max-width <a>
ancho máximo de fotograma permitido
-x <x>, --exclusive-caps <x>
si anunciar capacidades de SALIDA/CAPTURA exclusivamente
--min-width <w>
ancho mínimo de fotograma permitido
--min-height <w>
altura mínima de fotograma permitida
-?, --help
imprime esta ayuda y sale
<dispositivo_salida>
si se proporciona, crea un dispositivo específico (de lo contrario, solo crea uno libre).
especifica un nombre de dispositivo (p. ej., '/dev/video1') o un número de dispositivo ('1').
<dispositivo_captura>
si se proporciona, usa dispositivos de salida y captura separados (de lo contrario, son los mismos).

v4l2loopback-ctl delete <dispositivo>:

elimina/borra un dispositivo loopback no utilizado
<dispositivo>
puede darse una o más veces (para eliminar varios dispositivos a la vez). especifica un nombre de dispositivo (p. ej., '/dev/video1') o un número de dispositivo ('1').

v4l2loopback-ctl list [OPCIONES]:

lista todos los dispositivos loopback disponibles
-e, --escape
escapa caracteres de control en nombres (de dispositivo)
-a, --help
imprime esta ayuda y sale

v4l2loopback-ctl query [OPCIONES] <dispositivo>:

consulta información sobre un dispositivo loopback
-e, --escape
escapa caracteres de control en nombres (de dispositivo)
-a, --help
imprime esta ayuda y sale
<dispositivo>
puede darse una o más veces (para consultar varios dispositivos a la vez). especifica un nombre de dispositivo (p. ej., '/dev/video1') o un número de dispositivo ('1').

v4l2loopback-ctl set-fps <dispositivo> <fps>:

establece la velocidad de fotogramas predeterminada para un dispositivo loopback
<dispositivo>
especifica un nombre de dispositivo (p. ej., '/dev/video1') o un número de dispositivo ('1').
<fps>
fotogramas por segundo, ya sea como entero ('30') o fracción ('50/2').

v4l2loopback-ctl get-fps <dispositivo>:

consulta la velocidad de fotogramas de un dispositivo loopback

v4l2loopback-ctl set-caps <dispositivo> <caps>:

establece el formato/dimensión/velocidad de fotogramas de un dispositivo loopback
<dispositivo>
especifica un nombre de dispositivo (p. ej., '/dev/video1') o un número de dispositivo ('1').
<caps>
especificación de formato como '<fourcc>:<ancho>x<alto>@<fps>' (p. ej., 'UYVY:1024x768@60/1') anula las caps actuales con el valor especial 'any'

v4l2loopback-ctl get-caps <dispositivo>:

obtiene el formato/dimensión/velocidad de fotogramas actual de un dispositivo loopback

v4l2loopback-ctl set-timeout-image [OPCIONES] <dispositivo> <imagen>:

establece una imagen de reserva para usar si un productor de video no envía fotogramas nuevos a tiempo.
<flags>
pueden estar presentes cualquiera de las siguientes banderas
-a, --help
imprime esta ayuda y sale
-t <tiempo_espera>, --timeout <tiempo_espera>
tiempo de espera (en ms)
-v, --verbose
aumenta la verbosidad (imprime lo que se está haciendo)
<dispositivo>
especifica un nombre de dispositivo (p. ej., '/dev/video1') o un número de dispositivo ('1').
<imagen>
archivo de imagen
