virt-format(1) Virtualization Support virt-format(1)

NOMBRE

virt-format - Borra y crea un disco en blanco

SINOPSIS

virt-format [--opciones] -a disco.img [-a disco.img ...]

ADVERTENCIA

"virt-format" puede ser peligroso si se usa en máquinas virtuales en ejecución o concurrentemente con otras herramientas de edición de discos, pudiendo corromper el disco. La máquina virtual debe estar apagada antes de usar este comando, y las imágenes de disco no deben ser editadas concurrentemente.

DESCRIPCIÓN

Virt-format toma un archivo de disco existente (o puede ser una partición del host, LV, etc.), borra todos los datos en él y lo formatea como un disco en blanco. Opcionalmente, puede crear tablas de particiones, sistemas de archivos vacíos, volúmenes lógicos y más.

Para crear un disco que contenga datos, es mejor usar virt-make-fs(1). Si está creando un disco en blanco para usar en guestfish(1), debería usar la opción -N de guestfish en su lugar.

El uso normal sería algo como esto:

virt-format -a disco.qcow

o esto:

virt-format -a /dev/VG/LV

disco.qcow o /dev/VG/LV deben existir ya. Cualquier dato en estos discos será borrado por estos comandos. Estos comandos crearán una única partición vacía que cubre todo el disco, sin sistema de archivos dentro.

Se pueden usar parámetros adicionales para controlar la creación de particiones, sistemas de archivos, etc. Las opciones más comunes son:

--filesystem=[ext3|ntfs|vfat|...]
Crea un sistema de archivos vacío ("ext3", "ntfs", etc.) dentro de la partición.
--lvm[=/dev/VG/LV]
Crea un volumen lógico LVM2 de Linux en el disco. Cuando se usa con --filesystem, el sistema de archivos se crea dentro del LV.

Para más información sobre estas y otras opciones, consulte "OPCIONES" abajo.

El formato del disco normalmente se detecta automáticamente, pero también puede forzarlo usando la opción --format (ver). En situaciones en las que no confía en el contenido existente del disco, es aconsejable usar esta opción para evitar posibles exploits.

OPCIONES

--help
Muestra una breve ayuda.
-a archivo
--add archivo
Añade archivo, una imagen de disco, partición del host, LV, disco USB externo, etc.

El formato de la imagen de disco se detecta automáticamente. Para anular esto y forzar un formato particular, use la opción --format=...

Cualquier dato existente en el disco se borra.

-a URI
--add URI
Añade un disco remoto. Vea "AÑADIR ALMACENAMIENTO REMOTO" en guestfish(1).
--blocksize=512
--blocksize=4096
--blocksize
Este parámetro establece el tamaño del sector de la imagen de disco. Afecta a todos los discos añadidos explícitamente después de este parámetro. Usar --blocksize sin argumento cambia el tamaño del sector del disco al valor por defecto, que suele ser 512 bytes. Vea también "guestfs_add_drive_opts" en guestfs(3).
--filesystem=ext3|ntfs|vfat|...
Crea un sistema de archivos vacío del tipo especificado. libguestfs soporta muchos tipos de sistemas de archivos.
--filesystem=none
No crea ningún sistema de archivos. Este es el valor por defecto.
--format=raw|qcow2|..
--format
El valor por defecto para la opción -a es detectar automáticamente el formato de la imagen de disco. Usar esto fuerza el formato del disco para las opciones -a que sigan en la línea de comandos. Usar --format sin argumento revierte a la detección automática para las opciones -a subsiguientes.

Por ejemplo:

virt-format --format=raw -a disco.img

fuerza el formato raw (sin detección automática) para disco.img.

virt-format --format=raw -a disco.img --format -a another.img

fuerza el formato raw (sin detección automática) para disco.img y revierte a la detección automática para another.img.

Si tiene imágenes de disco en formato raw no confiables, debería usar esta opción para especificar el formato del disco. Esto evita un posible problema de seguridad con invitados maliciosos (CVE-2010-3851).

--label=ETIQUETA
Establece la etiqueta del sistema de archivos.
--lvm=/dev/VG/LV
Crea un volumen lógico LVM2 de Linux llamado /dev/VG/LV. Puede cambiar el nombre del grupo de volúmenes y del volumen lógico.
--lvm
Crea un volumen lógico LVM2 de Linux con el nombre por defecto (/dev/VG/LV).
--lvm=none
No crea ningún volumen lógico. Este es el valor por defecto.
--partition
Crea una partición MBR o GPT que cubre todo el disco. Se elige MBR si el tamaño del disco es < 2 TB, GPT si es ≥ 2 TB.

Este es el valor por defecto.

--partition=gpt
Crea una partición GPT.
--partition=mbr
Crea una partición MBR.
--partition=none
No crea tabla de particiones. Tenga en cuenta que Windows podría no ser capaz de ver estos discos.
-v
--verbose
Habilita mensajes detallados para depuración.
-V
--version
Muestra el número de versión y sale.
--wipe
Normalmente, virt-format no borra los datos del disco (porque eso lleva mucho tiempo). Por lo tanto, si hay datos en el disco, solo se ocultan y se sobrescriben parcialmente con virt-format, y podrían ser recuperados por herramientas de edición de discos.

Si usa esta opción, virt-format escribe ceros sobre todo el disco para que los datos anteriores no sean recuperables.

-x
Habilita el rastreo de llamadas a la API de libguestfs.

ESTADO DE SALIDA

Este programa devuelve 0 en caso de éxito, o 1 en caso de fallo.
