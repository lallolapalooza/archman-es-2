VLLM2PCP(1) Manual de Comandos Generales VLLM2PCP(1)

NOMBRE

vllmbench2pcp - importador de resultados de benchmark de vLLM

SINOPSIS

vllmbench2pcp [-hv] [-a archivo] [-H nombrehost] resultados [...]

DESCRIPCIÓN

vllmbench2pcp es una herramienta importadora de métricas de rendimiento que crea un archivo PCP a partir de los resultados JSON de un benchmark de vLLM.

Un archivo que abarca el tiempo durante el cual el benchmark y sus iteraciones de ejecución estuvieron activos. Se crean métricas discretas de PCP para cada aspecto registrado de una ejecución, y se registran una vez al inicio y una vez al final de cada iteración, seguidas de un registro de marca.

Esto permite que las herramientas de PCP informen sobre estas métricas de manera significativa junto con otras métricas del sistema (del kernel, hardware, vLLM, etc.) recopiladas durante el benchmark.

El único argumento obligatorio en la línea de comandos es el archivo resultados JSON de una invocación de vllm bench. Este JSON puede estar opcionalmente envuelto con metadatos adicionales de Model Furnace, y si se detecta, se extraerán y almacenarán etiquetas de PCP adicionales (como nombres de modelos y servidores de inferencia).

OPCIONES

Las opciones disponibles en la línea de comandos son:

-a archivo, --archive=archivo
Especifica el nombre del archivo de salida de PCP que se producirá. Por defecto, se utilizará un nombre de archivo que utiliza la marca de tiempo del inicio de la ejecución del benchmark.
-H nombrehost, --hostname=nombrehost
Establece el nombrehost que se estampará en la cabecera de la etiqueta del archivo PCP.
-h, --help
Muestra el mensaje de uso y sale.
-v, --verbose
Informa sobre el progreso a medida que se identifica cada ejecución y se guardan sus valores.

VER TAMBIÉN
