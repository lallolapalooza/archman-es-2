VDE_SWITCH(1) Manual de comandos generales VDE_SWITCH(1)

NOMBRE

vde_switch - Switch de red distribuida virtual

SINOPSIS

vde_switch [ -hub ] [ -sock ruta_directorio_comunicacion ] [ -mod modo_octal ] [ -group NOMBRE ] [ -tap interfaz ] [ -daemon ]

DESCRIPCIÓN

Un vde_switch es un switch virtual para la arquitectura vde.
Una red vde puede incluir varios vde_switches ejecutándose en diferentes ordenadores (reales). Los vde_switches se pueden conectar mediante cables vde (ver vde_plug (1)).
La arquitectura soportada para los nodos finales de VDE incluye: máquinas Linux reales (a través de la interfaz tuntap), máquinas virtuales Bochs, QEMU y MPS.
VDE es útil para crear redes de máquinas virtuales heterogéneas, así como una herramienta general de túnel — todos los protocolos basados en Ethernet funcionan mediante este tipo de túnel — y también como una herramienta para la movilidad. De hecho, VDE crea una red superpuesta donde los usuarios pueden mantener sus direcciones IP a pesar del cambio de direcciones IP en las interfaces.

vde_switch necesita privilegios de root para abrir una interfaz tap, puede ser ejecutado por usuarios cuando no se especifica la opción -tap.

vde-2 tiene varias características: VLAN, Protocolo de árbol de expansión rápido (Fast Spanning Tree Protocol), gestión por línea de comandos (en la consola para switches en primer plano, en una terminal para switches daemonizados). Si un vde_switch se ejecuta en modo primer plano, simplemente presione enter para obtener el prompt. Para los demonios, existe la opción -M para especificar el socket de gestión. Unixterm es la herramienta para iniciar una terminal para la gestión. Escriba "help" en el prompt para obtener una lista de opciones posibles.

OPCIONES

-hub
desactiva el motor del switch. Opera como un hub.
-sock ruta_directorio_comunicacion
especifica el directorio donde se crean los sockets de comunicación. El valor predeterminado es "/tmp/vde.ctl"
-mod modo_octal
especifica los permisos octales para los sockets de comunicación.
-group NOMBRE
especifica el propietario del grupo para el socket de comunicación. El valor predeterminado es el grupo principal del usuario actual.
-tap interfaz
conecta la interfaz tuntap especificada a este vde_switch (requiere privilegios de root). Es posible especificar varias interfaces tap, separadas por comas.
-daemon
Ejecutar como demonio. Utiliza syslog para el registro.
-f archivo_rc
archivo rc para establecer la configuración inicial del switch. Este archivo rc tiene la misma sintaxis que la interfaz de línea de comandos.
-nostdin
Permite cerrar stdin.
-h
ayuda. Por favor, úselo para obtener una lista más completa de opciones. vde_switch es un programa modular, las opciones varían según los módulos compilados.
