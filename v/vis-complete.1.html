VIS-COMPLETE(1) Manual de Comandos Generales VIS-COMPLETE(1)

NOMBRE

vis-complete — Completa interactivamente un archivo o una palabra

SINOPSIS

vis-complete [--archivo | --palabra] [--] patrón

vis-complete -h | --ayuda

DESCRIPCIÓN

vis-complete toma un patrón en la línea de comandos y completa archivos o palabras, mostrándolos en un menú para que el usuario seleccione uno. Una vez que el usuario ha seleccionado una completitud, la completitud (excluyendo el patrón) se imprime en la salida estándar.

vis-complete utiliza vis-menu(1) como su interfaz de usuario, así que consulta esa página para más detalles.

--archivo
Esto pasa patrón a find para obtener una lista de nombres de archivo coincidentes (este es el comportamiento por defecto).
--palabra
Esto lee la entrada estándar para obtener una lista de líneas que coinciden con patrón.
--
Un argumento que sigue a este token se tratará como patrón, incluso si de lo contrario fuera una opción de línea de comandos válida.

Si se encuentra después de una instancia previa de --, se trata como un patrón.

patrón
El patrón a completar por archivo o palabra.
-h | --ayuda
Si está presente, vis-complete imprime un resumen de uso y sale, ignorando cualquier otra bandera y argumento.

ESTADO DE SALIDA

La utilidad vis-complete sale con 0 en caso de éxito, y >0 si ocurre un error.

En particular, al igual que vis-menu(1), vis-complete no imprime nada y establece su estado de salida a 1 si el usuario se niega a seleccionar un archivo.

VER TAMBIÉN

vis(1), vis-menu(1)

ERRORES

Debido a que vis-complete usa find(1) para obtener la lista de archivos, pueden ocurrir cosas extrañas si tienes caracteres de control en los nombres de tus archivos.
