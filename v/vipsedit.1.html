NOMBRE

vipsedit - editar cabecera de un archivo de imagen vips

SINOPSIS

vipsedit [OPCIÓN...] archivo.vips

DESCRIPCIÓN

vipsedit modifica la cabecera de un archivo de imagen VIPS. Esto es útil para establecer la resolución, por ejemplo.

Las opciones son:


-x, --xsize=N establecer Xsize a N
-y, --ysize=N establecer Ysize a N
-b, --bands=N establecer Bands a N
-f, --format=F establecer BandFmt a F (ej. uchar)
-i, --interpretation=I
establecer Interpretation a I (ej. xyz)
-c, --coding=C establecer Coding a C (ej. labq)
-X, --xres=R establecer Xres a R píxeles/mm
-Y, --yres=R establecer Yres a R píxeles/mm
-u, --xoffset=N establecer Xoffset a N
-v, --yoffset=N establecer Yoffset a N
-e, --setext reemplazar bloque de extensión con stdin

Tenga mucho cuidado al cambiar Xsize, Ysize, BandFmt o Bands. ¡vipsedit no realiza ninguna comprobación!

EJEMPLOS

Para establecer Xsize a 512 y Bands a 6:


vipsedit --xsize=512 --bands=6 fred.v

o


vipsedit -x 512 -b 6 fred.v

Extraer los metadatos XML de una imagen con vipsheader(1), editarlos y volver a adjuntarlos con vipsedit(1).


vipsheader -f getext fred.v | sed s/banana/pinapple/ | vipsedit -e fred.v

VALOR DE RETORNO

devuelve 0 si tiene éxito y un valor distinto de cero si hay un error.
