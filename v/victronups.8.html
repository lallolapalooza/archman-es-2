NOMBRE

victronups - Controlador para unidades SAI IMV/Victron Match, Match Lite, NetUps

SINOPSIS

victronups -h

victronups -a NOMBRE_SAI [OPCIONES]


Nota

Esta página del manual solo documenta las características específicas del hardware del controlador victronups. Para obtener información sobre el controlador principal, consulte nutupsdrv(8).

HARDWARE SOPORTADO

El controlador victronups debería reconocer todos los modelos Victron que utilizan un protocolo serie a 1200 bps. Estos incluyen Match Lite, Match y la línea NetUps.

La línea Match Lite puede informar solo de un puñado de variables. Esto normalmente no es un error; simplemente no soportan nada más.

CABLEADO

Si su cable Victron está roto o falta, use este diagrama para construir un clon:

•https://github.com/networkupstools/nut/blob/master/docs/cables/ge-imv-victron.txt
•docs/cables/ge-imv-victron.txt

ARGUMENTOS ADICIONALES

Este controlador soporta la siguiente configuración opcional en el archivo ups.conf(5):

modelname=nombre

Establece el nombre del modelo

usd=retraso

Establece el retraso antes del apagado en la UPS

ERRORES

El protocolo para esta UPS no está documentado oficialmente.
