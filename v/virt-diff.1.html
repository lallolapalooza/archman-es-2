virt-diff(1) Soporte de Virtualización virt-diff(1)

NOMBRE

virt-diff - Diferencias entre archivos en dos máquinas virtuales

SINOPSIS

virt-diff [--opciones] -d dominio1 -D dominio2
virt-diff [--opciones] -a disco1.img [-a ...] -A disco2.img [-A ...]

DESCRIPCIÓN

"virt-diff" lista las diferencias entre archivos en dos máquinas virtuales o imágenes de disco. El uso habitual es mostrar los cambios en una VM después de que ha estado ejecutándose durante un tiempo, tomando una instantánea, ejecutando la VM y luego usando esta herramienta para mostrar lo que cambió entre el nuevo estado de la VM y la instantánea antigua.

Esta herramienta encontrará diferencias en nombres de archivos, tamaños de archivos, sumas de verificación, atributos extendidos, contenido de archivos y más de una máquina virtual o imagen de disco. Sin embargo, no revisa el cargador de arranque, el espacio no utilizado entre particiones o dentro de los sistemas de archivos, sectores "ocultos", etc. En otras palabras, no es una herramienta de seguridad o forense.

Para especificar dos invitados, debe usar las opciones -a o -d para el primer invitado, y las opciones -A o -D para el segundo invitado. El caso común es:

virt-diff -a old.img -A new.img

o usando nombres conocidos por libvirt:

virt-diff -d oldguest -D newguest

OPCIONES

--help
Muestra ayuda breve.
-a archivo
--add archivo
Añade archivo que debería ser una imagen de disco de la primera máquina virtual. Si la máquina virtual tiene múltiples dispositivos de bloque, debes proporcionar todos ellos con opciones -a separadas.

El formato de la imagen de disco se detecta automáticamente. Para anular esto y forzar un formato particular, usa la opción --format=...

-a URI
--add URI
Añade un disco remoto. Ver "AÑADIR ALMACENAMIENTO REMOTO" en guestfish(1).
--all
Igual que --extra-stats --times --uids --xattrs.
--atime
Por defecto, se ignoran los cambios en los tiempos de acceso de los archivos, ya que es poco probable que sean interesantes. Usar esta bandera muestra también las diferencias de atime.
-A archivo
-A URI
Añade una imagen de disco de la segunda máquina virtual.
--blocksize=512
--blocksize=4096
--blocksize
Este parámetro establece el tamaño del sector de la imagen de disco. Afecta a todos los discos subsiguientes añadidos explícitamente después de este parámetro. Usar --blocksize sin argumento cambia el tamaño del sector del disco al valor por defecto, que suele ser de 512 bytes. Ver también "guestfs_add_drive_opts" en guestfs(3).
--checksum
--checksum=crc|md5|sha1|sha224|sha256|sha384|sha512
Utiliza una suma de verificación sobre el contenido de los archivos para detectar cuándo los archivos regulares han cambiado de contenido.

Sin argumento, esto se establece por defecto en md5. Usando un argumento, puedes seleccionar el tipo de suma de verificación a utilizar. Si se omite la bandera, se utilizan los tiempos y el tamaño del archivo para determinar si un archivo ha cambiado.

-c URI
--connect URI
Si se usa libvirt, conéctate a la URI dada. Si se omite, nos conectaremos al hipervisor libvirt por defecto.

Si especificas los dispositivos de bloque del invitado directamente (-a), entonces libvirt no se utiliza en absoluto.

--csv
Escribe los resultados en formato CSV (valores separados por comas). Este formato se puede importar fácilmente en bases de datos y hojas de cálculo, pero lee "NOTA SOBRE EL FORMATO CSV" a continuación.
--dir-links
Por defecto, se ignoran los cambios en el número de enlaces en las entradas de directorio, ya que es poco probable que sean interesantes. Usar esta bandera muestra los cambios en el campo nlink de los directorios.
--dir-times
Por defecto, se ignoran los tiempos cambiados en las entradas de directorio, ya que es poco probable que sean interesantes. Usar esta bandera muestra los cambios en los campos de tiempo de los directorios.
-d invitado
--domain invitado
Añade todos los discos del invitado libvirt nombrado, como el primer invitado. Se pueden usar UUIDs de dominio en lugar de nombres.
-D invitado
Añade todos los discos del invitado libvirt nombrado, como el segundo invitado. Se pueden usar UUIDs de dominio en lugar de nombres.
--echo-keys
Al solicitar claves y contraseñas, virt-diff normalmente desactiva el eco para que no puedas ver lo que escribes. Si no te preocupan los ataques Tempest y no hay nadie más en la habitación, puedes especificar esta bandera para ver lo que escribes.
--extra-stats
Muestra estadísticas extra.
--format=raw|qcow2|..
--format
El valor por defecto para la opción -a/-A es detectar automáticamente el formato de la imagen de disco. Usar esto fuerza el formato del disco para las opciones -a/-A que siguen en la línea de comandos. Usar --format sin argumento vuelve a la detección automática para las opciones -a/-A subsiguientes.

Por ejemplo:

virt-diff --format=raw -a disk.img [...]

fuerza el formato raw (sin detección automática) para disk.img.

virt-diff --format=raw -a disk.img --format -a another.img [...]

fuerza el formato raw (sin detección automática) para disk.img y vuelve a la detección automática para another.img.

Si tienes imágenes de disco de invitado en formato raw no confiables, debes usar esta opción para especificar el formato del disco. Esto evita un posible problema de seguridad con invitados maliciosos (CVE-2010-3851).

-h
--human-readable
Muestra los tamaños de archivo en formato legible por humanos.
--key SELECCIONADOR
Especifica una clave para LUKS, para abrir automáticamente un dispositivo LUKS al usar la inspección.
--key NOMBRE:key:CADENA_CLAVE
--key UUID:key:CADENA_CLAVE
--key all:key:CADENA_CLAVE
"NOMBRE" es el nombre del dispositivo libguestfs (ej. "/dev/sda1"). "UUID" es el UUID del dispositivo. "all" significa intentar la clave contra cualquier dispositivo cifrado.

Usa la "CADENA_CLAVE" especificada como contraseña.

--key NOMBRE:file:NOMBRE_ARCHIVO
--key UUID:file:NOMBRE_ARCHIVO
--key all:file:NOMBRE_ARCHIVO
Lee la contraseña del "NOMBRE_ARCHIVO".
--key NOMBRE:clevis
--key UUID:clevis

OPCIONES

--key all:clevis
Intenta desbloquear el dispositivo sin contraseña con Clevis, a través de la red. Consulte "DISCOS CIFRADOS" en guestfs(3) para obtener más información sobre el cifrado de disco enlazado a la red (NBDE).

Tenga en cuenta que si alguna de estas opciones está presente en la línea de comandos, la red de usuarios de QEMU se habilitará automáticamente para el dispositivo de libguestfs.

--keys-from-stdin
Lee parámetros de clave o contraseña desde stdin. Por defecto, intenta leer las contraseñas del usuario abriendo /dev/tty.

Si hay varios dispositivos cifrados, es posible que necesite suministrar varias claves en stdin, una por línea.

--times
Muestra los campos de tiempo.
--time-days
Muestra los campos de tiempo como días transcurridos desde ahora (negativo si está en el futuro).

Tenga en cuenta que 0 en la salida significa "hasta 1 día antes de ahora", o que la antigüedad del archivo está entre 0 y 86399 segundos.

--time-relative
Muestra los campos de tiempo como segundos transcurridos desde ahora (negativo si está en el futuro).
--time-t
Muestra los campos de tiempo como segundos desde la época Unix.
--uids
Muestra los campos UID y GID.
-v
--verbose
Habilita mensajes detallados para depuración.
-V
--version
Muestra el número de versión y sale.
-x
Habilita el rastreo de llamadas a la API de libguestfs.
--xattrs
Muestra atributos extendidos.

NOTA SOBRE EL FORMATO CSV

Los valores separados por comas (CSV) es un formato engañoso. Parece que debería ser fácil de analizar, pero definitivamente no lo es.

Mito: Simplemente divide los campos en comas. Realidad: Esto no funciona de forma fiable. Este ejemplo tiene dos columnas:

"foo,bar",baz

Mito: Lee el archivo línea por línea. Realidad: Esto no funciona de forma fiable. Este ejemplo tiene una fila:

"foo
bar",baz

Para scripts de shell, use "csvtool" (https://github.com/Chris00/ocaml-csv, también empaquetado en las principales distribuciones de Linux).

Para otros lenguajes, utilice una biblioteca de procesamiento de CSV (por ejemplo, "Text::CSV" para Perl o la biblioteca csv integrada de Python).

La mayoría de las hojas de cálculo y bases de datos pueden importar CSV directamente.

ESTADO DE SALIDA

Este programa devuelve 0 si tiene éxito, o un valor distinto de cero si hubo un error.
