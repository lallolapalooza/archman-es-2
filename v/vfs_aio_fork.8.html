NOMBRE

vfs_aio_fork - implementa E/S asíncrona en VFS de Samba

SINOPSIS

vfs objects = aio_fork

DESCRIPCIÓN

Este módulo VFS es parte de la suite samba(7).

El módulo VFS aio_fork habilita la E/S asíncrona para Samba en plataformas donde la interfaz Posix AIO a nivel de sistema es insuficiente. Posix AIO puede sufrir severas limitaciones. Por ejemplo, en algunas versiones de Linux, las señales de tiempo real que utiliza están rotas bajo carga pesada. Otros sistemas solo permiten AIO cuando se cargan módulos especiales del kernel o solo permiten una cierta cantidad de solicitudes asíncronas programadas a nivel de sistema. Los sistemas basados en glibc (la mayoría de los sistemas Linux) solo permiten una solicitud pendiente por descriptor de archivo.

Para solucionar todas estas limitaciones, se escribió el módulo aio_fork. Utiliza procesos auxiliares bifurcados en lugar de la interfaz Posix AIO interna para crear asincronismo para las llamadas de lectura y escritura. No tiene parámetros, creará procesos auxiliares cuando lleguen solicitudes asíncronas según sea necesario. Los procesos auxiliares inactivos se eliminarán cada 30 segundos.

Este módulo es apilable.

EJEMPLOS

Uso directo:

        [datos_frescos]
	path = /data/ice
	vfs objects = aio_fork
