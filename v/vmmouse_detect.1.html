vmmouse_detect(1) Manual de comandos generales vmmouse_detect(1)

NOMBRE

vmmouse_detect - herramienta de autodetección del dispositivo del ratón de VMware

SINOPSIS

vmmouse_detect

OPCIONES

vmmouse_detect no tiene opciones

DESCRIPCIÓN

vmmouse_detect es una herramienta para detectar si se está ejecutando en un entorno VMware donde se utiliza vmmouse. Sale con un valor de retorno de 0 si el cliente vmmouse está habilitado, y 1 si no.

DIAGNÓSTICOS

El estado de salida de vmmouse_detect se utiliza para comunicar información.

0
vmmouse_detect encontró un ratón y salió normalmente.
1
O bien el cliente vmmouse no estaba habilitado, o bien no se está ejecutando dentro de una máquina virtual VMware.

ERRORES

Por favor, informe de los errores en vmmouse_detect https://bugs.launchpad.net/ubuntu/+source/mdetect/vmmouse_detect.
