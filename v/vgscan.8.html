NOMBRE

vgscan — Busca todos los grupos de volúmenes

SINOPSIS

vgscan
[ argumentos_opcionales ]

DESCRIPCIÓN

vgscan escanea todos los dispositivos de bloque LVM soportados en el sistema en busca de VGs.

USO

vgscan

[ --ignorelockingfailure ]
[ --mknodes ]
[ --notifydbus ]
[ --refresh ]
[ --reportformat basic|json|json_std ]
[ ARGUMENTOS_COMUNES ]

—

[ -d|--debug ... ]
[ -h|--help ]

[ -v|--verbose ... ]

OPCIONES

--commandprofile Cadena
El perfil de comando a usar para la configuración del comando. Consulte lvm.conf(5) para obtener más información sobre los perfiles.
--config Cadena
Configuraciones para el comando. Estas anulan los ajustes de lvm.conf(5). La cadena de argumento utiliza el mismo formato que lvm.conf(5), o puede utilizar la sintaxis de sección/campo. Consulte lvm.conf(5) para obtener más información sobre la configuración.
-d|--debug ...
Establece el nivel de depuración. Repetir de 1 a 6 veces para aumentar el detalle de los mensajes enviados al archivo de registro y/o a syslog (si está configurado).
--devices PV
Restringe los dispositivos visibles y accesibles para el comando. Los dispositivos no listados parecerán faltar. Esta opción se puede repetir o aceptar una lista separada por comas de dispositivos. Esto anula el archivo de dispositivos.
--devicesfile Cadena
Un archivo que lista los dispositivos que LVM debe usar. El archivo debe existir en /etc/lvm/devices/ y se gestiona con el comando lvmdevices(8). Esto anula la configuración devices/devicesfile y devices/use_devicesfile de lvm.conf(5).
--driverloaded y|n
Si se establece en no, el comando no intentará usar el device-mapper. Para pruebas y depuración.
-h|--help
Muestra el texto de ayuda.
--ignorelockingfailure
Permite que un comando continúe con operaciones de metadatos de solo lectura después de fallos de bloqueo.
--journal Cadena
Registra información en el journal de systemd. Esta información es adicional a la habilitada por la configuración de registro/journal de lvm.conf. comando: registra información sobre el comando. salida: registra la salida predeterminada del comando. depuración: registra la depuración completa del comando.
--lockopt Cadena
Se utiliza para pasar opciones para casos especiales a lvmlockd. Consulte lvmlockd(8) para obtener más información.
--longhelp
Muestra el texto de ayuda extendido.
--mknodes
También comprueba los archivos especiales de LVM en /dev que son necesarios para los LV activos y crea los que faltan y elimina los que no se usan. Véase también la opción adicional --refresh para su uso en entornos udev.
--nohints
No utiliza el archivo de pistas para localizar dispositivos para PVs. Un comando puede leer más dispositivos para encontrar PVs cuando no se usan pistas. El comando seguirá realizando la invalidación estándar del archivo de pistas cuando sea apropiado.
--nolocking
Deshabilita el bloqueo. Úselo con precaución, los comandos concurrentes pueden producir resultados incorrectos.
--notifydbus
Envía una notificación a D-Bus. El comando finalizará con un error si LVM no está compilado con soporte para notificación D-Bus, o si la configuración de notify_dbus está deshabilitada.
--profile Cadena
Un alias para --commandprofile o --metadataprofile, dependiendo del comando.
-q|--quiet ...
Suprime la salida y los mensajes de registro. Anula --debug y --verbose. Repetir una vez para suprimir también cualquier solicitud con respuesta 'no'.
--refresh
Si el LV está activo, recarga sus metadatos. En un entorno donde se utiliza udev para gestionar el contenido de /dev, se recomienda encarecidamente el uso de esta opción. Esto se debe a que refresh también regenera eventos udev para un LV basándose en qué reglas udev existentes se aplican para establecer el contenido y los permisos de /dev. Además, esta operación puede ser útil si algo ha ido mal, o si se está utilizando alguna forma de compartición manual de LV.
--reportformat basic|json|json_std
Anula el formato de salida actual para los informes, que se define globalmente por la configuración de report/output_format en lvm.conf(5). basic es el formato original con columnas y filas. Si hay más de un informe por comando, cada informe se prefija con el nombre del informe para su identificación. json produce la salida del informe en formato JSON. json_std produce la salida del informe en formato JSON que es más compatible con el estándar JSON. Consulte lvmreport(7) para obtener más información.
-t|--test
Ejecutar en modo de prueba. Los comandos no actualizarán los metadatos. Esto se implementa deshabilitando toda escritura de metadatos pero devolviendo éxito a la función de llamada. Esto puede llevar a mensajes de error inusuales en operaciones de múltiples etapas si una herramienta depende de leer metadatos que cree que han cambiado pero no lo han hecho.
-v|--verbose ...
Establece el nivel de verbosidad. Repetir de 1 a 4 veces para aumentar el detalle de los mensajes enviados a stdout y stderr.
--version
Muestra la información de la versión.
-y|--yes
No solicitar confirmación interactivamente, sino asumir siempre la respuesta sí. Usar con extrema precaución. (Para un 'no' automático, ver -qq).

vgscan
escanear los dispositivos para buscar volúmenes físicos y grupos de volúmenes

SYNOPSIS

vgscan [-a|--all] [-d|--debug] [-h|--help] [-H|--hash] [-M|--metadatacopy { select | last | all }] [-m|--monitor] [-p|--partial] [-v|--verbose] [-y|--yes]

DESCRIPTION

vgscan escanea el sistema en busca de volúmenes físicos (PV) y volúmenes de grupo (VG) y registra esta información en el directorio de metadatos de LVM. Si no se encuentra información de metadatos, la escanea desde los volúmenes físicos. Si se encuentran metadatos, se escanea un VG.

El escaneo se inicia buscando todos los dispositivos de bloque en el sistema. Cada dispositivo de bloque se examina para ver si contiene información de metadatos de LVM. Si la tiene, se lee la información de metadatos y se obtiene el nombre del VG y los PV que pertenecen al VG.

Si se encuentra un VG, se genera un archivo de configuración temporal para ese VG. Si la opción --all se usa, se escanearán todos los PVs y VGs. Si no se usa la opción --all, solo se escanearán los dispositivos con metadatos de LVM v1 o v2. Para escanear los dispositivos de LVM v1, se necesita la opción --metadatacopy.

Si se encuentra un PV, se lee su información y se actualiza el archivo de configuración de LVM. Si el PV pertenece a un VG que ya existe en la configuración, se añade el PV al VG.

La opción --monitor permite que vgscan se ejecute continuamente, monitorizando los dispositivos para detectar cambios y actualizando la configuración de LVM en consecuencia. Esto es útil para entornos dinámicos donde los dispositivos pueden ser añadidos o eliminados con frecuencia.

USAGE

vgscan se utiliza principalmente para descubrir y registrar los volúmenes de grupo y los volúmenes físicos en el sistema LVM. Se puede ejecutar manualmente o como parte de un script de inicialización del sistema.

Un uso común es ejecutar vgscan después de agregar nuevos dispositivos de almacenamiento o después de restaurar una copia de seguridad de metadatos de LVM. También se puede ejecutar para verificar la integridad de los metadatos de LVM en el sistema.

OPTIONS

-a, --all
Escanea todos los volúmenes físicos y grupos de volúmenes. Por defecto, solo se escanean los dispositivos que contienen metadatos LVM v2. Si se utiliza esta opción, se escanearán también los dispositivos con metadatos LVM v1.
-d, --debug
Activa la salida de depuración detallada.
-h, --help
Muestra un mensaje de ayuda y sale.
-H, --hash
Utiliza un algoritmo de hash para acelerar la búsqueda de volúmenes físicos.
-M, --metadatacopy { select | last | all }
Selecciona qué copia de los metadatos de volumen de grupo se utilizará. select: utiliza la copia seleccionada por el usuario. last: utiliza la última copia escrita. all: utiliza todas las copias disponibles. Por defecto, se utiliza la última copia escrita.
-m, --monitor
Ejecuta vgscan en modo monitor. En este modo, vgscan se ejecuta continuamente y monitoriza los dispositivos en busca de cambios. Cuando se detectan cambios, vgscan actualiza la configuración de LVM en consecuencia.
-p, --partial
Permite escanear volúmenes físicos que pertenecen a grupos de volúmenes parcialmente disponibles (es decir, grupos de volúmenes en los que no todos los volúmenes físicos son visibles).
-v, --verbose
Activa la salida detallada.
-y, --yes
No pide confirmación antes de realizar cambios. Esto puede ser útil en scripts, pero debe usarse con precaución.

VARIABLES

Algunas variables de entorno pueden afectar el comportamiento de vgscan. Consulte la página del manual de lvm(8) para obtener más detalles.

ENVIRONMENT VARIABLES

Consulte lvm(8) para obtener información sobre las variables de entorno utilizadas por lvm. Por ejemplo, LVM_VG_NAME puede sustituir generalmente a un parámetro VG requerido.
