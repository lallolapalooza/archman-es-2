VFS_AIO_PTHREAD(8) Herramientas de administración del sistema VFS_AIO_PTHREAD(8)

NOMBRE

vfs_aio_pthread - implementa la apertura asíncrona en VFS de Samba usando un pool de pthreads

SINOPSIS

objetos vfs = aio_pthread

DESCRIPCIÓN

Este módulo VFS es parte del conjunto samba(7).

El módulo VFS aio_pthread habilita aperturas asíncronas (para archivos nuevos) con aio_pthread:aio open = yes en plataformas que tienen disponible la API de pthreads, soportan la llamada al sistema openat() y soportan credenciales por hilo (kernels de Linux modernos).

El módulo utiliza el pool de hilos global que usa la opción aio max threads.

Este módulo DEBE listarse último en cualquier pila de módulos, ya que la interfaz de apertura VFS de Samba no es segura para hilos. Este módulo realiza llamadas directas al sistema openat() y NO llama a las interfaces de apertura VFS de Samba.

EJEMPLOS

Uso directo:

        [cooldata]
	path = /data/ice
	vfs objects = aio_pthread
	aio_pthread:aio open = yes

OPCIONES

aio_pthread:aio open = BOOL

Intenta aperturas asíncronas para crear nuevos archivos.

El valor predeterminado es 'no'.
