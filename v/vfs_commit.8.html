VFS_COMMIT(8) Herramientas de administración del sistema VFS_COMMIT(8)

NOMBRE

vfs_commit - vacía datos sucios en intervalos especificados

SINOPSIS

objetos vfs = commit

DESCRIPCIÓN

Este módulo VFS es parte del conjunto de utilidades de samba(7).

El módulo VFS vfs_commit realiza un seguimiento de la cantidad de datos escritos en un archivo y los sincroniza con el disco cuando se acumula una cantidad especificada.

vfs_commit es útil en dos circunstancias. Primero, si tiene datos muy preciosos, el impacto de una pérdida de energía inesperada puede minimizarse con un pequeño valor commit:dthresh. En segundo lugar, el rendimiento de escritura puede mejorarse en algunos sistemas vaciando los datos del archivo temprano y a intervalos regulares.

Este módulo se puede apilar.

OPCIONES

commit:dthresh = BYTES

Sincroniza los datos del archivo cada vez que se escriben el número especificado de bytes.

Los siguientes sufijos pueden aplicarse a BYTES:

•K - BYTES es un número de kilobytes
•M - BYTES es un número de megabytes
•G - BYTES es un número de gigabytes

EJEMPLOS

Sincroniza los datos del archivo en el recurso compartido [precious] después de cada 512 kilobytes (524288 bytes) de datos escritos:

        [precious]
	path = /data/precious
	vfs objects = commit
	commit:dthresh = 512K

ADVERTENCIAS

En algunos sistemas, la sincronización de datos realizada por commit puede reducir el rendimiento.
