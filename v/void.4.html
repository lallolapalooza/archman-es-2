VOID(4) Manual de Controladores de Dispositivos VOID(4)

NOMBRE

void - controlador de entrada nulo

SINOPSIS

Section "InputDevice"
  Identifier "nombre_dispositivo"
  Driver "void"
  ...
EndSection

DESCRIPCIÓN

void es un controlador de entrada dummy/nulo de Xorg. No se conecta a ningún dispositivo físico y nunca genera eventos. Funciona como un dispositivo de puntero y de teclado, y puede ser utilizado como el puntero principal y/o el teclado principal del servidor X. Su propósito es permitir que los servidores X anteriores a la versión 1.4 funcionen sin un puntero principal y/o un teclado principal.

DETALLES DE CONFIGURACIÓN

Por favor, consulte xorg.conf(5) para ver los detalles generales de configuración y las opciones que se pueden usar con todos los controladores de entrada. Este controlador no tiene ninguna opción de configuración adicional a las mencionadas.

VER TAMBIÉN

Xorg(1), xorg.conf(5), Xserver(1), X(7).
