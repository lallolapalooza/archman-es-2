VGRENAME(8) Manual del Administrador del Sistema VGRENAME(8)

NOMBRE

vgrename — Renombrar un grupo de volúmenes

SINOPSIS

vgrename args_posicionales
[ args_opcionales ]

DESCRIPCIÓN

vgrename renombra un VG.

Todos los VG visibles para un sistema necesitan tener nombres diferentes, de lo contrario, muchos comandos LVM se negarán a ejecutarse o mostrarán mensajes de advertencia. Pueden ocurrir VG con el mismo nombre cuando se mueven discos entre máquinas o se cambian los filtros. Si un disco conectado recientemente tiene un VG con el mismo nombre que el VG que contiene el sistema de archivos raíz, la máquina puede no arrancar correctamente. Cuando dos VG tienen el mismo nombre, el UUID del VG puede usarse en lugar del nombre del VG de origen.

USO

Renombrar un VG.

vgrename VG VG_nuevo

[ OPCIONES_COMUNES ]

—

Renombrar un VG especificando el UUID del VG.

vgrename Cadena VG_nuevo

OPCIONES

-A|--autobackup s|n
Especifica si los metadatos deben ser respaldados automáticamente después de un cambio. ¡Se recomienda encarecidamente habilitar esto! Consulte vgcfgbackup(8) para más información.
--commandprofile Cadena
El perfil de comando a utilizar para la configuración del comando. Consulte lvm.conf(5) para más información sobre perfiles.
--config Cadena
Configuraciones para el comando. Estas anulan la configuración de lvm.conf(5). La cadena de argumento utiliza el mismo formato que lvm.conf(5), o puede usar la sintaxis de sección/campo. Consulte lvm.conf(5) para más información sobre la configuración.
-d|--debug ...
Establece el nivel de depuración. Repetir de 1 a 6 veces para aumentar el detalle de los mensajes enviados al archivo de registro y/o syslog (si está configurado).
--devices PV
Restringe los dispositivos que son visibles y accesibles para el comando. Los dispositivos no listados parecerán faltar. Esta opción se puede repetir, o acepta una lista de dispositivos separada por comas. Esto anula el archivo de dispositivos.
--devicesfile Cadena
Un archivo que lista los dispositivos que LVM debe usar. El archivo debe existir en /etc/lvm/devices/ y se gestiona con el comando lvmdevices(8). Esto anula la configuración de devices/devicesfile y devices/use_devicesfile de lvm.conf(5).
--driverloaded s|n
Si se establece en no, el comando no intentará usar device-mapper. Para pruebas y depuración.
-f|--force ...
Anula varias comprobaciones, confirmaciones y protecciones. Úselo con extrema precaución.
-h|--help
Muestra el texto de ayuda.
--journal Cadena
Registra información en el journal de systemd. Esta información es adicional a la habilitada por la configuración de registro/journal de lvm.conf. comando: registra información sobre el comando. salida: registra la salida predeterminada del comando. depuración: registra la depuración completa del comando.
--lockopt Cadena
Se utiliza para pasar opciones para casos especiales a lvmlockd. Consulte lvmlockd(8) para más información.
--longhelp
Muestra el texto de ayuda extenso.
--nohints
No utiliza el archivo de sugerencias para localizar dispositivos para PVs. Un comando puede leer más dispositivos para encontrar PVs cuando no se usan sugerencias. El comando aún realizará la invalidación estándar del archivo de sugerencias donde sea apropiado.
--nolocking
Deshabilita el bloqueo. Úselo con precaución, los comandos concurrentes pueden producir resultados incorrectos.
--profile Cadena
Un alias para --commandprofile o --metadataprofile, dependiendo del comando.
-q|--quiet ...
Suprime la salida y los mensajes de registro. Anula --debug y --verbose. Repetir una vez para suprimir también cualquier pregunta con respuesta 'no'.
--reportformat basic|json|json_std
Anula el formato de salida actual para los informes, que se define globalmente por la configuración report/output_format en lvm.conf(5). basic es el formato original con columnas y filas. Si hay más de un informe por comando, cada informe se prefija con el nombre del informe para identificación. json produce la salida del informe en formato JSON. json_std produce la salida del informe en formato JSON que es más compatible con el estándar JSON. Consulte lvmreport(7) para más información.
-t|--test
Ejecuta en modo de prueba. Los comandos no actualizarán los metadatos. Esto se implementa deshabilitando toda la escritura de metadatos pero devolviendo éxito a la función que llama. Esto puede llevar a mensajes de error inusuales en operaciones de múltiples etapas si una herramienta depende de leer metadatos que cree que han cambiado pero no lo han hecho.
-v|--verbose ...
Establece el nivel de verbosidad. Repetir de 1 a 4 veces para aumentar el detalle de los mensajes enviados a stdout y stderr.
--version
Muestra la información de la versión.
-y|--yes
No solicita confirmación de forma interactiva, sino que siempre asume la respuesta sí. Úselo con extrema precaución. (Para un no automático, vea -qq.)

VARIABLES

VG
Nombre del Grupo de Volúmenes. Consulte lvm(8) para nombres válidos.
Cadena
Consulte la descripción de la opción para obtener información sobre el contenido de la cadena.
Tamaño[UNIDAD]
El tamaño es un número de entrada que acepta una unidad opcional. Las unidades de entrada siempre se tratan como valores de base dos, independientemente de la capitalización, por ejemplo, 'k' y 'K' se refieren a 1024. La unidad de entrada predeterminada se especifica con una letra, seguida de |UNIDAD. UNIDAD representa otras unidades de entrada posibles: b|B son bytes, s|S son sectores de 512 bytes, k|K son KiB, m|M son MiB, g|G son GiB, t|T son TiB, p|P son PiB, e|E son EiB.
