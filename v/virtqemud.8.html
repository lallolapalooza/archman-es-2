virtqemud(8) Soporte de Virtualización virtqemud(8)

Nombre

virtqemud - Demonio de gestión QEMU de libvirt

SINOPSIS

virtqemud [OPCIÓN]...

DESCRIPCIÓN

El programa virtqemud es un componente demonio del lado del servidor del sistema de gestión de virtualización libvirt.

Es una de una colección de demonios modulares que reemplazan la funcionalidad previamente proporcionada por el demonio monolítico libvirtd.

Este demonio se ejecuta en hosts de virtualización para proporcionar gestión para máquinas virtuales QEMU.

El demonio virtqemud solo escucha solicitudes en un socket de dominio Unix local. El acceso remoto a través de TLS/TCP y la compatibilidad con versiones anteriores con clientes heredados que esperan libvirtd es proporcionado por el demonio virtproxyd.

Reiniciar virtqemud no interrumpe las máquinas virtuales en ejecución. Las máquinas virtuales continúan operando y los cambios en su estado generalmente se capturarán automáticamente durante el inicio. No obstante, se recomienda evitar reiniciar con máquinas virtuales en ejecución siempre que sea práctico.

MODOS DE INICIO DEL DEMONIO

El demonio virtqemud es capaz de iniciarse en dos modos.

Modo de activación de socket

En hosts con systemd, se inicia en modo de activación de socket y dependerá de systemd para crear y escuchar en los sockets UNIX y pasarlos como descriptores de archivo preabiertos. En este modo, la mayoría de las opciones de configuración relacionadas con sockets en /etc/libvirt/virtqemud.conf ya no tendrán ningún efecto.

Modo de servicio tradicional

En hosts sin systemd, creará y escuchará en sockets UNIX por sí mismo.

OPCIONES

-h, --help

Muestra la ayuda de uso de la línea de comandos y luego sale.

-d, --daemon

Ejecutar como demonio y escribir archivo PID.

-f, --config *ARCHIVO*

Usar este archivo de configuración, reemplazando el valor predeterminado.

-p, --pid-file *ARCHIVO*

Usar este nombre para el archivo PID, reemplazando el valor predeterminado.

-t, --timeout *SEGUNDOS*

Salir después del período de tiempo de espera (en segundos), siempre que no haya conexiones de clientes ni dominios en ejecución.

-v, --verbose

Habilitar la salida de mensajes detallados.

--version

Muestra la información de la versión y luego sale.

SEÑALES

Al recibir SIGHUP, virtqemud recargará su configuración.

ARCHIVOS

Cuando se ejecuta como root

•
/etc/libvirt/virtqemud.conf

El archivo de configuración predeterminado utilizado por virtqemud, a menos que se anule en la línea de comandos utilizando la opción -f | --config.

Además del archivo de configuración predeterminado, virtqemud lee la configuración del controlador QEMU de:

•
/etc/libvirt/qemu.conf

Este archivo contiene varias opciones y valores predeterminados para las máquinas virtuales creadas dentro del controlador QEMU, y ofrece una forma de anular los valores predeterminados integrados, por ejemplo (pero no limitado a): rutas a varios binarios complementarios, ubicación de certificados TLS, configuración de consolas gráficas y otros. La ubicación de este archivo no se puede anular con ningún modificador de línea de comandos.

  • /run/libvirt/virtqemud-sock
  • /run/libvirt/virtqemud-sock-ro
  • /run/libvirt/virtqemud-admin-sock

Los sockets que utilizará virtqemud.

La clave privada del Servidor TLS que utilizará virtqemud.

•
/run/virtqemud.pid

El archivo PID a utilizar, a menos que se anule con la opción -p | --pid-file.

Cuando se ejecuta como no-root

•
$XDG_CONFIG_HOME/libvirt/virtqemud.conf

El archivo de configuración predeterminado utilizado por virtqemud, a menos que se anule en la línea de comandos utilizando la opción -f``|--config``.

Además del archivo de configuración predeterminado, virtqemud lee la configuración del controlador qemu de:

•
$XDG_CONFIG_HOME/libvirt/qemu.conf

Si el archivo existe, puede contener varias opciones y valores predeterminados para las máquinas virtuales creadas dentro del controlador QEMU, y ofrece una forma de anular los valores predeterminados integrados, por ejemplo (pero no limitado a): rutas a varios binarios complementarios, ubicación de certificados TLS, configuración de consolas gráficas y otros. La ubicación de este archivo no se puede anular con ningún modificador de línea de comandos.

  • $XDG_RUNTIME_DIR/libvirt/virtqemud-sock
  • $XDG_RUNTIME_DIR/libvirt/virtqemud-admin-sock

Los sockets que utilizará virtqemud.

•
$XDG_RUNTIME_DIR/libvirt/virtqemud.pid

El archivo PID a utilizar, a menos que se anule con la opción -p``|--pid-file``.

Si $XDG_CONFIG_HOME no está configurado en tu entorno, virtqemud usará $HOME/.config

Si $XDG_RUNTIME_DIR no está configurado en tu entorno, virtqemud usará $HOME/.cache

EJEMPLOS

Para obtener la versión de virtqemud:

# virtqemud --version
virtqemud (libvirt) 11.10.0

Para iniciar virtqemud, instruyéndolo para que se ejecute como demonio y cree un archivo PID:

# virtqemud -d
# ls -la /run/virtqemud.pid
-rw-r--r-- 1 root root 6 Jul  9 02:40 /run/virtqemud.pid
