virt-xml-validate(1) Soporte de Virtualización virt-xml-validate(1)

Nombre

virt-xml-validate - valida archivos XML de libvirt contra un esquema

SINÓPSIS

virt-xml-validate ARCHIVO-XML [NOMBRE-ESQUEMA]

virt-xml-validate OPCIÓN

DESCRIPCIÓN

Valida un XML de libvirt para cumplir con el esquema publicado. El primer argumento obligatorio es la ruta al archivo XML que se va a validar. El segundo argumento opcional es el nombre del esquema contra el cual validar. Si se omite, el nombre del esquema se inferirá del nombre del elemento raíz en el documento XML.

Los nombres de esquemas válidos actualmente incluyen

•
cpu

El esquema para el formato XML de cpu

•
domainsnapshot

El esquema para el formato XML utilizado por la configuración de instantáneas de dominio

•
domaincheckpoint

El esquema para el formato XML utilizado por la configuración de puntos de control de dominio

•
domainbackup

El esquema para el formato XML utilizado por la configuración de copias de seguridad de dominio

•
domaincaps

El esquema para el formato XML de capacidades de dominio

•
domain

El esquema para el formato XML utilizado por la configuración de dominios invitados

•
networkport

El esquema para el formato XML utilizado por la configuración de puertos de red

•
network

El esquema para el formato XML utilizado por la configuración de redes virtuales

•
storagepoolcaps

El esquema para el formato XML de capacidades de grupo de almacenamiento

•
storagepool

El esquema para el formato XML utilizado por la configuración de grupos de almacenamiento

•
storagevol

El esquema para el formato XML utilizado por las descripciones de volúmenes de almacenamiento

•
nodedev

El esquema para el formato XML utilizado por las descripciones de dispositivos de nodo

•
capability

El esquema para el formato XML utilizado para declarar capacidades del controlador

•
nwfilter

El esquema para el formato XML utilizado por los filtros de tráfico de red

•
nwfilterbinding

El esquema para el formato XML utilizado por los enlaces de filtro de red.

•
secret

El esquema para el formato XML utilizado por las descripciones de secretos

•
interface

El esquema para el formato XML utilizado por las interfaces de host físicas

OPCIONES

-h, --help

Muestra la ayuda de uso de la línea de comandos y luego sale.

-V, --version

Muestra la información de la versión y luego sale.

ESTADO DE SALIDA

Tras una validación exitosa, se establecerá un estado de salida de 0. En caso de fallo, se establecerá un estado de salida distinto de cero.
