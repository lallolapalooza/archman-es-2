NOMBRE

vfeedback - Simula el feedback de video.

SINOPSIS

vfeedback [--display host:display.screen] [--visual visual] [--window] [--root] [--window-id número] [--tv-color número] [--tv-tint número] [--noise número] [--tv-brightness número] [--tv-contrast número] [--fps]

DESCRIPCIÓN

Simula el feedback de video: apuntar una cámara de video a un televisor NTSC.

OPCIONES

--visual visual
Especifica qué visual usar. Los valores válidos son el nombre de una clase visual o el número de ID (decimal o hexadecimal) de un visual específico.
--window
Dibuja en una ventana recién creada. Esta es la opción predeterminada.
--root
Dibuja en la ventana raíz.
--window-id número
Dibuja en la ventana especificada.
--tv-color número
Perilla de Color. 0 - 1000. Predeterminado: 70.
--tv-tint número
Perilla de Tono. 0 - 100. Predeterminado: 5.
--noise número
Ruido analógico. 0.0 - 0.2. Predeterminado: 0.02.
--darken número
Oscurece la imagen en bucle. 0.0 - 1.0. Predeterminado: 0.7.
--tv-brightness número
Perilla de Brillo. 0.0 - 100.0. Predeterminado: 3.0.
--tv-contrast número
Perilla de Contraste. 0 - 1500. Predeterminado: 1000.
--fps | --no-fps
Si se muestra o no un contador de fotogramas por segundo en la parte inferior de la pantalla.

AMBIENTE

DISPLAY
para obtener el host y el número de pantalla predeterminados.
XENVIRONMENT
para obtener el nombre de un archivo de recursos que anula los recursos globales almacenados en la propiedad RESOURCE_MANAGER.
XSCREENSAVER_WINDOW
El ID de la ventana a usar con --root.

VER TAMBIÉN

X(1), xscreensaver(1)
