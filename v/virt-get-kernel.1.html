NOMBRE

virt-get-kernel - Extraer kernel e initramfs de invitados

SINOPSIS

virt-get-kernel [--opciones] -d nombre_dominio
virt-get-kernel [--opciones] -a imagen_disco.img

DESCRIPCIÓN

Este programa extrae el kernel y el initramfs de un invitado.

El formato de la imagen del disco se detecta automáticamente a menos que lo especifique utilizando la opción --format.

En el caso de que el invitado contenga múltiples kernels, se elige el que tenga el número de versión más alto. Para extraer kernels arbitrarios de la imagen del disco, consulte guestfish(1). Para extraer el directorio "/boot" completo de un invitado, consulte virt-copy-out(1).

OPCIONES

--help
Mostrar ayuda.
-a archivo
--add archivo
Añadir archivo, que debe ser una imagen de disco de una máquina virtual.

El formato de la imagen del disco se detecta automáticamente. Para anular esto y forzar un formato particular, use la opción --format.

-a URI
--add URI
Añadir un disco remoto. El formato de URI es compatible con guestfish. Consulte "AÑADIR ALMACENAMIENTO REMOTO" en guestfish(1).
--blocksize 512
--blocksize 4096
Este parámetro establece el tamaño del sector de la imagen de disco añadida con la opción -a y se ignora para invitados libvirt añadidos con la opción -d. Consulte también "guestfs_add_drive_opts" en guestfs(3).
--colors
--colours
Usar secuencias de colores ANSI para colorear los mensajes. Este es el predeterminado cuando la salida es una tty. Si la salida del programa se redirige a un archivo, las secuencias de colores ANSI se deshabilitan a menos que use esta opción.
-c URI
--connect URI
Si usa libvirt, conéctese a la URI dada. Si se omite, nos conectamos al hipervisor libvirt predeterminado.

Si especifica dispositivos de bloque de invitados directamente (-a), libvirt no se usa en absoluto.

-d invitado
--domain invitado
Añadir todos los discos del invitado libvirt nombrado. Se pueden usar UUIDs de dominio en lugar de nombres.
--echo-keys
Al solicitar claves y contraseñas, virt-get-kernel normalmente desactiva el eco para que no pueda ver lo que está escribiendo. Si no le preocupan los ataques Tempest y no hay nadie más en la habitación, puede especificar esta opción para ver lo que escribe.
--format raw|qcow2|..
--format auto
El valor predeterminado para la opción -a es detectar automáticamente el formato de la imagen del disco. Usar esto fuerza el formato del disco para la opción -a en la línea de comandos.

Si tiene imágenes de disco de invitados en formato raw no confiables, debe usar esta opción para especificar el formato del disco. Esto evita un posible problema de seguridad con invitados maliciosos (CVE-2010-3851).

--key SELECCIONADOR
Especificar una clave para LUKS, para abrir automáticamente un dispositivo LUKS al usar la inspección.
--key NOMBRE:clave:CADENA_CLAVE
--key UUID:clave:CADENA_CLAVE
--key all:clave:CADENA_CLAVE
"NOMBRE" es el nombre del dispositivo libguestfs (por ejemplo, "/dev/sda1"). "UUID" es el UUID del dispositivo. "all" significa intentar la clave contra cualquier dispositivo cifrado.

Use la "CADENA_CLAVE" especificada como contraseña.

--key NOMBRE:archivo:NOMBRE_ARCHIVO
--key UUID:archivo:NOMBRE_ARCHIVO
--key all:archivo:NOMBRE_ARCHIVO
Leer la contraseña del NOMBRE_ARCHIVO.
--key NOMBRE:clevis
--key UUID:clevis
--key all:clevis
Intentar desbloqueo sin contraseña para el dispositivo con Clevis, a través de la red. Por favor, consulte "DISCOS CIFRADOS" en guestfs(3) para más información sobre el cifrado de disco enlazado a la red (NBDE).

Tenga en cuenta que si alguna de estas opciones está presente en la línea de comandos, la red de usuario QEMU se habilitará automáticamente para el entorno libguestfs.

--keys-from-stdin
Leer parámetros de clave o contraseña desde stdin. El valor predeterminado es intentar leer contraseñas del usuario abriendo /dev/tty.

Si hay múltiples dispositivos cifrados, es posible que necesite suministrar múltiples claves en stdin, una por línea.

--machine-readable
--machine-readable=formato
Esta opción se utiliza para hacer la salida más amigable para las máquinas cuando es analizada por otros programas. Consulte "SALIDA LEGIBLE POR MÁQUINA" más abajo.
-o directorio
--output directorio
Esta opción especifica el directorio de salida donde se escriben el kernel y el initramfs del invitado.

Si no se especifica, la salida predeterminada es el directorio actual.

--prefix prefijo
Esta opción especifica un prefijo para los archivos extraídos.

Si se especifica un prefijo, habrá un guion ("-") después del prefijo y antes del resto del nombre del archivo; por ejemplo, un kernel en el invitado como "vmlinuz-3.19.0-20-generic" se guarda como "midistribucion-vmlinuz-3.19.0-20-generic" cuando el prefijo es "midistribucion".

Consulte también --unversioned-names.

-q
--quiet
No imprimir mensajes de progreso ordinarios.
--unversioned-names
Esta opción afecta al nombre del archivo de destino de los archivos extraídos.

Si está habilitado, los archivos se guardarán localmente solo con el nombre base; por ejemplo, el kernel y el initramfs en el invitado como "vmlinuz-3.19.0-20-generic" y "initrd.img-3.19.0-20-generic" se guardan respectivamente como "vmlinuz" y "initrd.img".

Consulte también --prefix.

-v
--verbose
Habilitar mensajes detallados para depuración.
-V
--version
Di

OPTIONS

--version
Print the virt-get-kernel version number and exit.
--wrap
Envuelve los mensajes de error, advertencia e informativos. Esta es la opción predeterminada cuando la salida es una tty. Si la salida del programa se redirige a un archivo, el ajuste se deshabilita a menos que uses esta opción.
-x
Habilita el rastreo de las llamadas a la API de libguestfs.

SALIDA LEGIBLE POR MÁQUINA

La opción --machine-readable se puede usar para hacer que la salida sea más amigable para las máquinas, lo cual es útil cuando se llama a virt-get-kernel desde otros programas, GUI, etc.

Usa la opción por sí sola para consultar las capacidades del binario virt-get-kernel. La salida típica se ve así:

$ virt-get-kernel --machine-readable
virt-get-kernel

Se imprime una lista de características, una por línea, y el programa sale con el estado 0.

Es posible especificar una cadena de formato para controlar la salida; consulta "SALIDA LEGIBLE POR MÁQUINA AVANZADA" en guestfs(3).

VARIABLES DE ENTORNO

Para otras variables de entorno que afectan a todos los programas de libguestfs, consulta "VARIABLES DE ENTORNO" en guestfs(3).

ESTADO DE SALIDA

Este programa devuelve 0 si tiene éxito o un valor distinto de cero si hubo un error.
