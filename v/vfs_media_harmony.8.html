NOMBRE

vfs_media_harmony - Permite que múltiples clientes de Avid compartan una unidad de red.

SINOPSIS

objetos vfs = media_harmony

DESCRIPCIÓN

Este módulo VFS forma parte del conjunto samba(7).

El módulo VFS vfs_media_harmony permite que las estaciones de trabajo de edición de Avid compartan una unidad de red. Lo hace mediante:

1.Proporcionando a cada cliente su propia copia de los archivos Avid msmMMOB.mdb y msmFMID.pmr y Creando directorios.
2.Permitiendo a cada cliente controlar explícitamente el tiempo de escritura que la aplicación Avid ve en los directorios de medios de Avid.

Este módulo es apilable.

CONFIGURACIÓN

vfs_media_harmony redirige automáticamente las solicitudes de los clientes para archivos de base de datos de Avid o un directorio de Creación de Avid a una versión específica del cliente del archivo. No se necesita ninguna configuración adicional más allá de habilitar el módulo para que esta parte de su funcionalidad funcione.

Si los clientes de Avid Mac y Windows accederán a la misma carpeta, se les deben dar definiciones de compartición separadas, con los archivos ocultos de Mac vetados en la compartición de Windows. Ver EJEMPLOS.

Para permitir que cada cliente controle cuándo la aplicación Avid actualiza sus bases de datos de Avid, cree archivos para cada cliente y cada directorio de medios de Avid con el nombre [nombre_dir_avid]_[direccion_ip_cliente]_[nombre_usuario_cliente]. Para activar las actualizaciones de la base de datos de Avid, actualice la hora de escritura en esos archivos. Ver EJEMPLOS.

También es necesario que la opción "cache locked write times = no" esté configurada para que los clientes puedan controlar las horas de escritura de su carpeta de medios de Avid.

EJEMPLOS

Habilitar media_harmony para clientes Mac y Windows:

        [avid_mac]
	path = /avid
	vfs objects = media_harmony
	cache locked write times = no
        [avid_win]
	path = /avid
	vfs objects = media_harmony
	cache locked write times = no
	veto files = /.DS_Store/._@/.Trash@/.Spotlight@/.hidden/.hotfiles@/.vol/
	delete veto files = yes

Crear los archivos que permitirán a los usuarios david y susan controlar sus propias actualizaciones de base de datos de Avid:

touch '/avid/OMFI MediaFiles_192.168.1.10_david' \
	'/avid/OMFI MediaFiles_192.168.1.11_susan' \
	'/avid/Avid MediaFiles/MXF/1_192.168.1.10_david' \
	'/avid/Avid MediaFiles/MXF/1_192.168.1.11_susan'

Activar una actualización de la base de datos de Avid para el usuario david:

touch '/avid/OMFI MediaFiles_192.168.1.10_david' \
	'/avid/Avid MediaFiles/MXF/1_192.168.1.10_david'

Si tiene un gran número de carpetas de medios de Avid para administrar, puede proporcionar a cada editor una versión convenientemente modificada de examples/scripts/vfs/media_harmony/trigger_avid_update.py para crear y actualizar estos archivos.

ADVERTENCIAS

vfs_media_harmony está diseñado para funcionar con aplicaciones de edición de Avid que buscan en los directorios Avid MediaFiles u OMFI MediaFiles para obtener medios. No está diseñado para funcionar según lo esperado en todas las circunstancias para uso general. Por ejemplo: Es posible abrir un archivo específico del cliente como msmMMOB.mdb_192.168.1.10_userx aunque no aparezca en una lista de directorios.
