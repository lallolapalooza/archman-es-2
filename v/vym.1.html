VYM(1) Herramienta de mapas mentales VYM(1)

NOMBRE

VYM - View Your Mind (Ver Tu Mente)

SINOPSIS

vym [ opciones ] [ archivo1 archivo2 ... ]

DESCRIPCIÓN

VYM (View Your Mind) es una herramienta para generar y manipular mapas que muestran tus pensamientos. Dichos mapas pueden ayudarte a mejorar tu creatividad y efectividad. Puedes usarlos para gestión del tiempo, para organizar tareas, para obtener una visión general de contextos complejos, para ordenar tus ideas, etc. Algunas personas incluso piensan que es divertido trabajar con estos mapas...

OPCIONES

-b, --batch
Modo por lotes: ocultar ventanas gráficas
-c, --commands
Mostrar todos los comandos disponibles
-d, --debug
Mostrar salida de depuración
-h, --help
Mostrar este texto de ayuda
-L, --load
Cargar script
-l, --local
Ejecutar con recursos del directorio actual. (Solo necesario para desarrollo)
--locale
Anular la configuración regional del sistema para seleccionar el idioma
-n, --name <CADENA>
Establecer el nombre de esta instancia de vym a CADENA. Esto se usa para identificar esta instancia en DBus.
-q, --quit
Salir inmediatamente después de iniciar para benchmarking
-r, --run <ARCHIVO>
Ejecutar el script ARCHIVO.
-R, --restore
Restaurar la última sesión
-s, --shortcuts
Mostrar atajos de teclado al inicio
-sl, --shortcutsLaTeX
Mostrar atajos de teclado en formato LaTeX al inicio
-t --test
Modo de prueba, por ejemplo, sin autoguardado ni cambio de configuración
-v, --version
Mostrar la versión de vym

ARCHIVOS

/usr/bin/vym
Ejecutable principal
$HOME/.config/InSilmaril/vym.conf
Archivo de configuración
/tmp/vym-XXXXXX
Datos en tiempo de ejecución para cada instancia de vym, incluyendo el historial de deshacer/rehacer y el portapapeles
