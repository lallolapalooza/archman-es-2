VIPE(1) VIPE(1)

NOMBRE

vipe - editar tubería

SINOPSIS

comando1 | vipe | comando2

DESCRIPCIÓN

vipe permite ejecutar tu editor en medio de una tubería de Unix y editar los datos que se están canalizando entre programas. Tu editor tendrá todos los datos que se canalizan desde command1 cargados en él, y cuando lo cierres, esos datos se canalizarán a command2.

ARGUMENTOS

vipe toma un argumento --suffix que se puede usar para proporcionar una extensión de archivo al archivo temporal generado. Esto permite que los editores proporcionen resaltado de sintaxis y activen modos. Por ejemplo, puedes llamar a vipe así:

vipe --suffix csv

para crear un archivo temporal con la extensión .csv, lo que hace que Emacs (o tu editor favorito) se inicie en modo principal CSV.

VARIABLES DE ENTORNO

EDITOR
Editor a usar.
VISUAL
También se admite para determinar qué editor usar.
