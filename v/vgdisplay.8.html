DESCRIPCIÓN

vgdisplay muestra los atributos de los VG, y los PV y LV asociados.

vgs(8) es una alternativa preferida que muestra la misma información y más, utilizando un formato de salida más compacto y configurable.

USO

vgdisplay

[ -A|--activevolumegroups ]
[ -s|--short ]
[ OPCIONES_COMUNES ]
[ VG|Etiqueta ... ]

—

Muestra la salida en columnas como vgs.

vgdisplay -C|--columns

[ -a|--all ]
[ -o|--options Cadena ]
[ -O|--sort Cadena ]
[ -S|--select Cadena ]
[ --aligned ]
[ --binary ]

OPCIONES

-A|--activevolumegroups
Selecciona solo VG activos. El VG se considera activo si al menos uno de sus LV está activo.
--aligned
Usar con --separator para alinear las columnas de salida.
-a|--all
Lista todos los VG. Equivalente a no especificar ningún VG.
--binary
Usa valores binarios "0" o "1" en lugar de valores literales descriptivos para las columnas que tienen exactamente dos valores válidos para reportar (sin contar el valor "unknown" que denota que el valor no pudo ser determinado).
-c|--colon
Genera salida separada por dos puntos para facilitar el análisis en scripts o programas. También consulta vgs(8), que proporciona considerablemente más control sobre la salida. Los valores son:
  • Nombre del grupo de volúmenes
  • Acceso al grupo de volúmenes
  • Estado del grupo de volúmenes
  • Número interno del grupo de volúmenes
  • Número máximo de volúmenes lógicos
  • Número actual de volúmenes lógicos
  • Recuento de apertura de todos los volúmenes lógicos en este grupo de volúmenes
  • Tamaño máximo del volumen lógico
  • Número máximo de volúmenes físicos
  • Número actual de volúmenes físicos
  • Número real de volúmenes físicos
  • Tamaño del grupo de volúmenes en kilobytes
  • Tamaño de extents físicos
  • Número total de extents físicos para este grupo de volúmenes
  • Número de extents físicos asignados para este grupo de volúmenes
  • Número de extents físicos libres para este grupo de volúmenes
  • UUID del grupo de volúmenes
-C|--columns
Muestra la salida en columnas. El equivalente de vgs(8). Las opciones listadas son las mismas que las opciones dadas en vgs(8).
--commandprofile Cadena
El perfil de comando a usar para la configuración del comando. Consulta lvm.conf(5) para más información sobre perfiles.
--config Cadena
Configuración del comando. Estas anulan los ajustes de lvm.conf(5). La cadena de argumento usa el mismo formato que lvm.conf(5), o puede usar la sintaxis de sección/campo. Consulta lvm.conf(5) para más información sobre la configuración.
--configreport log|vg|lv|pv|pvseg|seg
Consulta lvmreport(7).
-d|--debug ...
Establece el nivel de depuración. Repetir de 1 a 6 veces para aumentar el detalle de los mensajes enviados al archivo de registro y/o a syslog (si está configurado).
--devices PV
Restringe los dispositivos que son visibles y accesibles para el comando. Los dispositivos no listados parecerán faltar. Esta opción se puede repetir, o acepta una lista de dispositivos separados por comas. Esto anula el archivo de dispositivos.
--devicesfile String
Un archivo que lista los dispositivos que LVM debe usar. El archivo debe existir en /etc/lvm/devices/ y se gestiona con el comando lvmdevices(8). Esto anula los ajustes devices/devicesfile y devices/use_devicesfile de lvm.conf(5).
--driverloaded y|n
Si se establece en no, el comando no intentará usar device-mapper. Para pruebas y depuración.
--foreign
Informa/muestra VG externos que de lo contrario se omitirían. Consulte lvmsystemid(7) para obtener más información sobre VG externos.
--headings none|abbrev|full|0|1|2
Tipo de encabezados a usar en la salida del informe. none o 0: Sin encabezados. abbrev o 1: Abreviaturas de nombres de columna. full o 2: Nombres completos de columna.
-h|--help
Muestra el texto de ayuda.
--ignorelockingfailure
Permite que un comando continúe con operaciones de metadatos de solo lectura después de fallos de bloqueo.
--journal String
Registra información en el journal de systemd. Esta información es adicional a la información habilitada por la configuración de registro/journal de lvm.conf. command: registra información sobre el comando. output: registra la salida predeterminada del comando. debug: registra la depuración completa del comando.
--lockopt String
Se utiliza para pasar opciones para casos especiales a lvmlockd. Consulte lvmlockd(8) para obtener más información.
--logonly
Suprime el informe del comando y muestra solo el informe de registro.
--longhelp
Muestra el texto de ayuda largo.
--nameprefixes
Agrega un prefijo "LVM2_" más el nombre del campo a la salida. Útil con --noheadings para producir una lista de pares campo=valor que se pueden usar para establecer variables de entorno (por ejemplo, en reglas udev).
--noheadings
Suprime la línea de encabezados que normalmente es la primera línea de salida. Útil si se busca en la salida.
--nohints
No utiliza el archivo de pistas para localizar dispositivos para PVs. Un comando puede leer más dispositivos para encontrar PVs cuando no se utilizan pistas. El comando aún realizará la invalidación estándar del archivo de pistas donde sea apropiado.
--nolocking
Deshabilita el bloqueo. Úselo con precaución, los comandos concurrentes pueden producir resultados incorrectos.
--nosuffix
Suprime el sufijo en los tamaños de salida. Úselo con --units (excepto h y H) si se procesa la salida.
-o|--options String
Lista de campos separados por comas y ordenados para mostrar en columnas. La sintaxis del argumento String es: [+|-|#]Campo1[,Campo2 ...] El prefijo + añadirá los campos especificados a los campos predeterminados, - eliminará los campos especificados de los campos predeterminados, y # compactará los campos especificados (eliminándolos cuando estén vacíos para todas las filas). Use -o help para ver la lista de todos los campos disponibles. Use listas separadas de campos para agregar, eliminar o compactar repitiendo la opción -o: -o+campo1,campo2 -o-campo3,campo4 -o#campo5. Estas listas se evalúan de izquierda a derecha. Use el nombre de campo lv_all para ver todos los campos de LV, vg_all todos los campos de VG, pv_all todos los campos de PV, seg_all todos los campos de segmento de LV y pvseg_all todos los campos de segmento de PV. Consulte la sección de informes de lvm.conf(5) para ver más opciones de configuración. Consulte lvmreport(7) para obtener más información sobre los informes.
--profile String
Un alias para --commandprofile o --metadataprofile, dependiendo del comando.
-q|--quiet ...
Suprime la salida y los mensajes de registro. Anula --debug y --verbose. Repetir una vez para suprimir también cualquier solicitud con la respuesta 'no'.
--readonly
Evita que el comando realice cambios, incluida la activación y las actualizaciones de metadatos. (Consulte --permission r para LVs de solo lectura).
--reportformat basic|json|json_std
Anula el formato de salida actual para los informes, que se define globalmente mediante el ajuste report/output_format en lvm.conf(5). basic es el formato original con columnas y filas. Si hay más de un informe por comando, cada informe se antepone con el nombre del informe para su identificación. json produce la salida del informe en formato JSON. json_std produce la salida del informe en formato JSON que cumple más con el estándar JSON. Consulte lvmreport(7) para obtener más información.
--rows
Columnas de salida como filas.
-S|--select String
Selecciona objetos para procesar y reportar basándose en criterios especificados. La sintaxis de los criterios se describe en --select help y lvmreport(7). Para comandos de informe, se muestra una fila por cada objeto que cumpla los criterios. Consulte --options help para ver los campos de objetos seleccionables. Las filas se pueden mostrar con un campo adicional "selected" (-o selected) que muestra 1 si la fila cumple la selección y 0 en caso contrario. Para comandos que no son de informe y que procesan entidades LVM, la selección se utiliza para elegir los elementos a procesar.
--separator String
Cadena a usar para separar cada columna. Útil si se busca en la salida.
--shared
Informa/muestra VG compartidos que de lo contrario se omitirían cuando no se está utilizando lvmlockd en el host. Consulte lvmlockd(8) para obtener más información sobre VG compartidos.
-s|--short
Proporciona una lista corta que muestra la existencia de VG.
-O|--sort String
Lista ordenada de columnas separadas por comas para ordenar. Reemplaza la selección predeterminada. Anteponer cualquier columna con - para una ordenación inversa en esa columna.
-t|--test
Ejecutar en modo de prueba. Los comandos no actualizarán los metadatos. Esto se implementa deshabilitando toda escritura de metadatos pero devolviendo éxito a la función que llama. Esto puede generar mensajes de error inusuales en operaciones de varias etapas si una herramienta depende de leer metadatos que cree que han cambiado pero no lo han hecho.
--unbuffered
Produce la salida inmediatamente sin ordenar ni alinear correctamente las columnas.
--units [Number]r|R|h|H|b|B|s|S|k|K|m|M|g|G|t|T|p|P|e|E
Todos los tamaños se muestran en estas unidades: legible por humanos (r) con indicador de redondeo '<', legible por (h)umanos, (b)ytes, (s)ectores, (k)ilobytes, (m)egabytes, (g)igabytes, (t)erabytes, (p)etabytes, (e)xabytes. Poner en mayúscula para usar múltiplos de 1000 (S.I.) en lugar de 1024. Se pueden especificar unidades personalizadas, por ejemplo, --units 3M.
--unquoted
Cuando se utiliza con --nameprefixes, los valores de salida en los pares campo=valor no estarán entre comillas.
-v|--verbose ...
Establece el nivel de verbosidad. Repetir de 1 a 4 veces para aumentar el detalle de los mensajes enviados a stdout y stderr.
--version
Muestra la información de la versión.
-y|--yes
No pedir confirmación de forma interactiva, sino asumir siempre la respuesta sí. Usar con extrema precaución. (Para un no automático, ver -qq).

VARIABLES

VG
Nombre del Grupo de Volúmenes. Consulte lvm(8) para ver nombres válidos.
Tag
Nombre de la Etiqueta. Consulte lvm(8) para obtener información sobre nombres de etiquetas y el uso de etiquetas en lugar de un VG, LV o PV.
String
Consulte la descripción de la opción para obtener información sobre el contenido de la cadena.
Size[UNIT]
El tamaño es un número de entrada que acepta una unidad opcional. Las unidades de entrada siempre se tratan como valores base dos, independientemente de la capitalización, por ejemplo, 'k' y 'K' se refieren ambos a 1024. La unidad de entrada predeterminada se especifica por letra, seguida de |UNIT. UNIT representa otras posibles unidades de entrada: b|B son bytes, s|S son sectores de 512 bytes, k|K son KiB, m|M son MiB, g|G son GiB, t|T son TiB, p|P son PiB, e|E son EiB. (Esto no debe confundirse con el control de salida --units, donde las letras mayúsculas significan múltiplos de 1000.)
