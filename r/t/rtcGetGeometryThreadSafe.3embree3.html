rtcGetGeometryThreadSafe(3) Núcleos de trazado de rayos Embree 3 rtcGetGeometryThreadSafe(3)

NOMBRE

rtcGetGeometryThreadSafe - devuelve la geometría enlazada al
  ID de geometría especificado

SINOPSIS

#include <embree3/rtcore.h>
RTCGeometry rtcGetGeometryThreadSafe(RTCScene scene, unsigned int geomID);

DESCRIPCIÓN

La función rtcGetGeometryThreadSafe devuelve la geometría que está enlazada al ID de geometría especificado (argumento geomID) para la escena especificada (argumento scene). Esta función solo busca el manejador y NO incrementa el contador de referencias. Si desea obtener la propiedad del manejador, debe llamar adicionalmente a rtcRetainGeometry.

Esta función es segura para hilos y NO debe usarse durante el renderizado. Si necesita una versión rápida y no segura para hilos durante el renderizado, utilice la función [rtcGetGeometry].

ESTADO DE SALIDA

En caso de error, se devuelve NULL y se establece un código de error que puede consultarse con rtcGetDeviceError.

VER TAMBIÉN

[rtcAttachGeometry], [rtcAttachGeometryByID], [rtcGetGeometry]
