NOMBRE

rtcGetGeometryThreadSafe - devuelve la geometría enlazada a
  la ID de geometría especificada

SINOPSIS

#include <embree4/rtcore.h>
RTCGeometry rtcGetGeometryThreadSafe(RTCScene scene, unsigned int geomID);

DESCRIPCIÓN

La función rtcGetGeometryThreadSafe devuelve la geometría que está enlazada a la ID de geometría especificada (argumento geomID) para la escena especificada (argumento scene). Esta función solo busca el manejador y no incrementa el contador de referencias. Si desea obtener la propiedad del manejador, debe llamar adicionalmente a rtcRetainGeometry.

Esta función es segura para hilos y NO debe usarse durante el renderizado. Si necesita una versión rápida que no sea segura para hilos durante el renderizado, utilice la función [rtcGetGeometry].

ESTADO DE SALIDA

En caso de error, se devuelve NULL y se establece un código de error que se puede consultar con rtcGetDeviceError.

VER TAMBIÉN

[rtcAttachGeometry], [rtcAttachGeometryByID], [rtcGetGeometry]
