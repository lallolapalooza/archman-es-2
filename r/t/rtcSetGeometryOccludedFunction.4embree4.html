rtcSetGeometryOccludedFunction(3) Embree Ray Tracing Kernels 4 rtcSetGeometryOccludedFunction(3)

NOMBRE

rtcSetGeometryOccludedFunction - establece la función de retorno de llamada para
  probar una geometría de usuario en busca de oclusión

SINOPSIS

#include <embree4/rtcore.h>
struct RTCOccludedFunctionNArguments
{
  int* valid;
  void* geometryUserPtr;
  unsigned int primID;
  struct RTCRayQueryContext* context;
  struct RTCRayN* ray;
  unsigned int N;
  unsigned int geomID;
};
typedef void (*RTCOccludedFunctionN)(
  const struct RTCOccludedFunctionNArguments* args
);
void rtcSetGeometryOccludedFunction(
  RTCGeometry geometry,
  RTCOccludedFunctionN filter
);

DESCRIPCIÓN

La función rtcSetGeometryOccludedFunction registra una función de retorno de llamada de oclusión de rayos/primitivas (argumento de filtro) para la geometría de usuario especificada (argumento de geometría).

Solo se puede registrar una función de retorno de llamada por geometría, y las invocaciones posteriores sobrescribirán la función de retorno de llamada previamente establecida. Pasar NULL como puntero de función deshabilita la función de retorno de llamada registrada.

La función de retorno de llamada registrada es invocada por las consultas de rayos de tipo rtcOccluded para probar si los rayos de un paquete de tamaño variable son ocluidos por una primitiva definida por el usuario. La función de retorno de llamada de tipo RTCOccludedFunctionN recibe una serie de argumentos a través de la estructura RTCOccludedFunctionNArguments. El valor N especifica el tamaño del paquete de rayos, valid apunta a un arreglo de enteros que especifican si el rayo correspondiente es válido (-1) o inválido (0), el miembro geometryUserPtr apunta a los datos de usuario de la geometría establecidos previamente a través de rtcSetGeometryUserData, el miembro context apunta al contexto de consulta de rayos pasado a la consulta de rayos, el miembro ray apunta a un paquete de rayos de tamaño variable N, y los miembros geomID y primID identifican el ID de geometría y el ID de primitiva de la primitiva a intersectar.

La tarea de la función de retorno de llamada es intersectar cada rayo activo del paquete de rayos con la primitiva de usuario especificada. Si la primitiva definida por el usuario es omitida por un rayo del paquete de rayos, la función debe retornar sin modificar el rayo. Si se encontró una intersección de la primitiva definida por el usuario con el rayo en el rango válido (desde tnear hasta tfar), debe establecer el miembro tfar del rayo a -inf.

Como una primitiva puede tener múltiples intersecciones con un rayo, la función de filtro de oclusión debe ser invocada por la función de retorno de llamada de oclusión de geometría de usuario para cada intersección encontrada, si se desea filtrar intersecciones. Esto se puede lograr a través de la llamada rtcInvokeOccludedFilterFromGeometry.

Dentro de la función de oclusión de geometría de usuario, es seguro trazar nuevos rayos y crear nuevas escenas y geometrías.

ESTADO DE SALIDA

En caso de fallo, se establece un código de error que se puede consultar utilizando rtcGetDeviceError.

VER TAMBIÉN

[rtcSetGeometryIntersectFunction], [rtcSetGeometryUserData], [rtcInvokeOccludedFilterFromGeometry]
