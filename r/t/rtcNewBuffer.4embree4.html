NOMBRE

rtcNewBuffer - crea un nuevo búfer de datos

SINOPSIS

#include <embree4/rtcore.h>
RTCBuffer rtcNewBuffer(
  RTCDevice device,
  size_t byteSize
);

DESCRIPCIÓN

La función rtcNewBuffer crea un nuevo objeto de búfer de datos de tamaño especificado en bytes (argumento byteSize) que está vinculado al dispositivo especificado (argumento device). El objeto búfer tiene un contador de referencias con un valor inicial de 1. El objeto búfer devuelto puede ser liberado usando la llamada a la API rtcReleaseBuffer. Los bytes especificados se asignan en el momento de la construcción del búfer y se liberan cuando se destruye el búfer.

Si el dispositivo es un dispositivo SYCL de Embree, el búfer se asignará utilizando memoria compartida USM de SYCL, es decir, el búfer puede ser accedido en el host y en el dispositivo (GPU) y el tiempo de ejecución de SYCL manejará automáticamente las transferencias del búfer.

Para un control preciso sobre cuándo se copian los datos de memoria del host al dispositivo, también se puede crear un búfer utilizando rtcNewBufferHostDevice.

ESTADO DE SALIDA

En caso de fallo, se devuelve NULL y se establece un código de error que se puede consultar usando rtcGetDeviceError.

VER TAMBIÉN

[rtcNewBufferHostDevice], [rtcRetainBuffer], [rtcReleaseBuffer]
