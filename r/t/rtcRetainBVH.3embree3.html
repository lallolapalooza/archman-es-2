rtcRetainBVH(3) Embree Ray Tracing Kernels 3 rtcRetainBVH(3)

NOMBRE

rtcRetainBVH - incrementa el contador de referencias de BVH

SINOPSIS

#include <embree3/rtcore.h>
void rtcRetainBVH(RTCBVH bvh);

DESCRIPCIÓN

Los objetos BVH tienen un contador de referencias. La función rtcRetainBVH incrementa el contador de referencias del objeto BVH pasado (argumento bvh). Esta función, junto con rtcReleaseBVH, permite usar el conteo de referencias interno en una clase envoltorio C++ para manejar la propiedad del objeto.

ESTADO DE SALIDA

En caso de error, se establece un código de error que se puede consultar usando rtcGetDeviceError.

VER TAMBIÉN

[rtcNewBVH], [rtcReleaseBVH]
