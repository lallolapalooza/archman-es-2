rtcSetGeometryTimeStepCount(3) Núcleos de trazado de rayos Embree 3 rtcSetGeometryTimeStepCount(3)

NOMBRE

rtcSetGeometryTimeStepCount - establece el número de pasos de tiempo de la
  geometría

SINOPSIS

#include <embree3/rtcore.h>
void rtcSetGeometryTimeStepCount(
  RTCGeometry geometry,
  unsigned int timeStepCount
);

DESCRIPCIÓN

La función rtcSetGeometryTimeStepCount establece el número de pasos de tiempo para desenfoque de movimiento multi-segmento (parámetro timeStepCount) de la geometría especificada (parámetro geometry).

Para mallas de triángulos (RTC_GEOMETRY_TYPE_TRIANGLE), mallas de cuadriláteros (RTC_GEOMETRY_TYPE_QUAD), curvas (RTC_GEOMETRY_TYPE_CURVE), puntos (RTC_GEOMETRY_TYPE_POINT) y geometrías de subdivisión (RTC_GEOMETRY_TYPE_SUBDIVISION), el número de pasos de tiempo corresponde directamente al número de ranuras de búfer de vértices disponibles (tipo de búfer RTC_BUFFER_TYPE_VERTEX). Para estas geometrías, se debe especificar un búfer de vértices por paso de tiempo al crear geometrías de desenfoque de movimiento multi-segmento.

Para geometrías de instancia (RTC_GEOMETRY_TYPE_INSTANCE), se debe especificar una transformación para cada paso de tiempo (ver rtcSetGeometryTransform).

Para geometrías de usuario, la función de callback de delimitación registrada debe proporcionar una caja delimitadora por primitiva y paso de tiempo, y las funciones de callback de intersección y oclusión deben intersecar correctamente la geometría con desenfoque de movimiento en el tiempo del rayo.

ESTADO DE SALIDA

En caso de error, se establece un código de error que puede ser consultado usando rtcGetDeviceError.

VER TAMBIÉN

[rtcNewGeometry], [rtcSetGeometryTimeRange]
