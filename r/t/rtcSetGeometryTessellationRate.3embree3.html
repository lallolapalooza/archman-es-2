NOMBRE

rtcSetGeometryTessellationRate - establece la tasa de teselación de la
  geometría

SINOPSIS

#include <embree3/rtcore.h>
void rtcSetGeometryTessellationRate(
  RTCGeometry geometry,
  float tessellationRate
);

DESCRIPCIÓN

La función rtcSetGeometryTessellationRate establece la tasa de teselación (argumento tessellationRate) para la geometría especificada (argumento geometry). La tasa de teselación solo se puede establecer para curvas planas y geometrías de subdivisión. Para las curvas, la tasa de teselación especifica el número de cuádruples orientados al rayo por segmento de curva. Para las superficies de subdivisión, la tasa de teselación especifica el número de cuádruples a lo largo de cada borde.

ESTADO DE SALIDA

En caso de error, se establece un código de error que se puede consultar con rtcGetDeviceError.

VER TAMBIÉN

[RTC_GEOMETRY_TYPE_CURVE], [RTC_GEOMETRY_TYPE_SUBDIVISION]
