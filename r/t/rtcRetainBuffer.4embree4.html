NOMBRE

rtcRetainBuffer - incrementa el contador de referencias del buffer

SINOPSIS

#include <embree4/rtcore.h>
void rtcRetainBuffer(RTCBuffer buffer);

DESCRIPCIÓN

Los objetos buffer tienen un contador de referencias. La función rtcRetainBuffer incrementa el contador de referencias del objeto buffer pasado (argumento buffer). Esta función, junto con rtcReleaseBuffer, permite utilizar el contador de referencias interno en una clase wrapper de C++ para manejar la propiedad del objeto.

ESTADO DE SALIDA

En caso de error, se establece un código de error que puede ser consultado usando rtcGetDeviceError.

VER TAMBIÉN

[rtcNewBuffer], [rtcReleaseBuffer]
