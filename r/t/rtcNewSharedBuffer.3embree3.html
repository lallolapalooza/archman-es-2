NOMBRE

rtcNewSharedBuffer - crea un nuevo búfer de datos compartido

SINOPSIS

#include <embree3/rtcore.h>
RTCBuffer rtcNewSharedBuffer(
  RTCDevice device,
  void* ptr,
  size_t byteSize
);

DESCRIPCIÓN

La función rtcNewSharedBuffer crea un nuevo objeto de búfer de datos compartido vinculado al dispositivo especificado (argumento device). El objeto de búfer tiene un contador de referencias con un recuento inicial de 1. El búfer puede liberarse utilizando la función rtcReleaseBuffer.

En el momento de la construcción, se proporciona el puntero a los datos del búfer gestionado por el usuario (argumento ptr) junto con su tamaño en bytes (argumento byteSize) para crear el búfer. En el momento de la construcción del búfer no se asigna memoria para los datos del búfer, sino que se utilizan los datos proporcionados por la aplicación. Los datos del búfer deben permanecer válidos mientras el búfer pueda ser utilizado, y el usuario es responsable de liberar los datos del búfer cuando ya no sean necesarios.

El puntero a los datos (argumento ptr) debe estar alineado a 4 bytes; de lo contrario, la función rtcNewSharedBuffer fallará.

ESTADO DE SALIDA

En caso de fallo, se devuelve NULL y se establece un código de error que puede consultarse utilizando rtcGetDeviceError.

VER TAMBIÉN

[rtcRetainBuffer], [rtcReleaseBuffer]
