rtime(3) Manual de Funciones de Biblioteca rtime(3)

NOMBRE

rtime - obtener la hora de una máquina remota

BIBLIOTECA

Biblioteca C estándar (libc, -lc)

SINOPSIS

#include <rpc/auth_des.h>
int rtime(struct sockaddr_in *addrp, struct rpc_timeval *timep,
          struct rpc_timeval *timeout);

DESCRIPCIÓN

Esta función utiliza el Protocolo del Servidor de Hora descrito en RFC 868 para obtener la hora de una máquina remota.

El Protocolo del Servidor de Hora proporciona la hora en segundos desde las 00:00:00 UTC, 1 de enero de 1900, y esta función resta la constante apropiada para convertir el resultado en segundos desde la Época, 1970-01-01 00:00:00 +0000 (UTC).

Cuando timeout no es NULL, se utiliza el socket udp/time (puerto 37). De lo contrario, se utiliza el socket tcp/time (puerto 37).

VALOR DE RETORNO

En caso de éxito, se devuelve 0, y el valor de hora de 32 bits obtenido se almacena en timep->tv_sec. En caso de error, se devuelve -1 y se establece errno para indicar el error.

ERRORES

Todos los errores de las funciones subyacentes (sendto(2), poll(2), recvfrom(2), connect(2), read(2)) pueden ocurrir. Además:

EIO
El número de bytes devueltos no es 4.
ETIMEDOUT
Ha expirado el tiempo de espera definido en timeout.

ATRIBUTOS

Para una explicación de los términos utilizados en esta sección, consulte attributes(7).

Interfaz Atributo Valor
rtime () Seguridad de hilos MT-Safe

NOTAS

Solo se admite IPv4.

Algunas versiones de in.timed solo admiten TCP. Pruebe el programa de ejemplo con use_tcp establecido en 1.

ERRORES CONOCIDOS

rtime() en glibc 2.2.5 y anteriores no funciona correctamente en máquinas de 64 bits.

EJEMPLOS

Este ejemplo requiere que el puerto 37 esté activo y abierto. Puede comprobar que la entrada de tiempo en /etc/inetd.conf no está comentada.

El programa se conecta a un ordenador llamado "linux". Usar "localhost" no funciona. El resultado es la hora local del ordenador "linux".

#include <errno.h>
#include <netdb.h>
#include <stdio.h>
#include <stdlib.h>
#include <string.h>
#include <time.h>
#include <rpc/auth_des.h>
static int use_tcp = 0;
static const char servername[] = "linux";
int
main(void)
{
    int                 ret;
    time_t              t;
    struct hostent      *hent;
    struct rpc_timeval  time1 = {0, 0};
    struct rpc_timeval  timeout = {1, 0};
    struct sockaddr_in  name;
    memset(&name, 0, sizeof(name));
    sethostent(1);
    hent = gethostbyname(servername);
    memcpy(&name.sin_addr, hent->h_addr, hent->h_length);
    ret = rtime(&name, &time1, use_tcp ? NULL : &timeout);
    if (ret < 0)
        perror("rtime error");
    else {
        t = time1.tv_sec;
        printf("%s\n", ctime(&t));
    }
    exit(EXIT_SUCCESS);
}
