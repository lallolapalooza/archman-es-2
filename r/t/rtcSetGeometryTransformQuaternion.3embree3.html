rtcSetGeometryTransformQuaternion(3) Embree Ray Tracing Kernels 3 rtcSetGeometryTransformQuaternion(3)

NOMBRE

rtcSetGeometryTransformQuaternion - establece la transformación para un paso de
  tiempo particular de una geometría de instancia como una descomposición de la
  matriz de transformación usando cuaterniones para representar la rotación.

SINOPSIS

#include <embree3/rtcore.h>
void rtcSetGeometryTransformQuaternion(
  RTCGeometry geometry,
  unsigned int timeStep,
  const struct RTCQuaternionDecomposition* qd
);

DESCRIPCIÓN

La función rtcSetGeometryTransformQuaternion establece la transformación afín local-a-mundial (parámetro qd) de una geometría de instancia (parámetro geometry) para un paso de tiempo particular (parámetro timeStep). La transformación se especifica como una [RTCQuaternionDecomposition], que es una descomposición de una transformación afín que representa el componente rotacional de una transformación afín como un cuaternión. Esto permite interpolar transformaciones rotacionales exactamente usando interpolación lineal esférica (como una rueda giratoria).

Para obtener más información sobre la descomposición, consulte [RTCQuaternionDecomposition]. El cuaternión dado en la estructura RTCQuaternionDecomposition se normalizará internamente.

Para obtener resultados correctos, las matrices de transformación para todos los pasos de tiempo deben establecerse usando rtcSetGeometryTransform o rtcSetGeometryTransformQuaternion. No se permite mezclar ambas representaciones. Se utilizará la interpolación lineal esférica, si las matrices de transformación se establecen con rtcSetGeometryTransformQuaternion.

Para un ejemplo de esta funcionalidad, consulte el tutorial [Movimiento de Cuaterniones con Desenfoque].

ESTADO DE SALIDA

En caso de fallo, se establece un código de error que se puede consultar mediante rtcGetDeviceError.

VER TAMBIÉN

[rtcInitQuaternionDecomposition], [rtcSetGeometryTransform]
