NOMBRE

rtcNewBVH - crea un nuevo objeto BVH

SINOPSIS

#include <embree3/rtcore.h>
RTCBVH rtcNewBVH(RTCDevice device);

DESCRIPCIÓN

Esta función crea un nuevo objeto BVH y devuelve un manejador a este BVH. El objeto BVH tiene un contador de referencias con un recuento inicial de 1. El manejador se puede liberar usando la llamada a la API rtcReleaseBVH.

El objeto BVH se puede utilizar para construir un BVH en un formato especificado por el usuario sobre primitivas especificadas por el usuario. Consulte la documentación de la llamada rtcBuildBVH para obtener más detalles.

ESTADO DE SALIDA

En caso de fallo, se establece un código de error que se puede consultar usando rtcGetDeviceError.

VER TAMBIÉN

[rtcRetainBVH], [rtcReleaseBVH], [rtcBuildBVH]
