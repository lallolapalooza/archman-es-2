NOMBRE

rtcGetGeometryUserData - devuelve el puntero de datos de usuario
  de la geometría

SINOPSIS

#include <embree3/rtcore.h>
void* rtcGetGeometryUserData(RTCGeometry geometry);

DESCRIPCIÓN

La función rtcGetGeometryUserData consulta el puntero de datos de usuario establecido previamente con rtcSetGeometryUserData. Cuando rtcSetGeometryUserData aún no se ha llamado, se devuelve NULL.

ESTADO DE SALIDA

En caso de error, se establece un código de error que se puede consultar con rtcGetDeviceError.

VER TAMBIÉN

[rtcSetGeometryUserData]
