NOMBRE

rtcCollide - intersecta un BVH con otro

SINOPSIS

#include <embree4/rtcore.h>
struct RTCCollision {
  unsigned int geomID0, primID0;
  unsigned int geomID1, primID1;
};
typedef void (*RTCCollideFunc) (
  void* userPtr,
  RTCCollision* collisions,
  size_t num_collisions);
void rtcCollide (
    RTCScene hscene0, 
    RTCScene hscene1, 
    RTCCollideFunc callback, 
    void* userPtr
);

DESCRIPCIÓN

La función rtcCollide intersecta el BVH de hscene0 con el BVH de la escena hscene1 y llama a una función de callback definida por el usuario (por ejemplo, el argumento callback) para cada par de primitivas interesectadas entre las dos escenas. También se puede pasar un puntero de datos definido por el usuario (argumento userPtr).

Por cada par de primitivas que puedan intersectarse, se llama a la función de callback (callback). Al usuario se le proporcionarán los ID de primitiva (primID) y los ID de geometría (geomID) de múltiples pares de primitivas potencialmente intersectantes. Actualmente, solo se admiten escenas compuestas enteramente por geometrías de usuario, por lo que se espera que el usuario implemente una intersección primitiva/primitiva para filtrar falsos positivos en la función de callback. El argumento userPtr puede usarse para pasar datos de geometría de la escena o resultados de la consulta de intersección.

PRIMITIVAS SOPORTADAS

Actualmente, el único tipo soportado es el tipo de geometría de usuario (ver [RTC_GEOMETRY_TYPE_USER]).

ESTADO DE SALIDA

En caso de error, se establece un código de error que se puede consultar usando rtcGetDeviceError.
