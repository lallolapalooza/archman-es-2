rtcFilterIntersection(3) Kernels de Trazado de Rayos Embree 3 rtcFilterIntersection(3)

NOMBRE

rtcFilterIntersection - invoca la función de filtro de intersección

SINOPSIS

#include <embree3/rtcore.h>
void rtcFilterIntersection(
  const struct RTCIntersectFunctionNArguments* args,
  const struct RTCFilterFunctionNArguments* filterArgs
);

DESCRIPCIÓN

La función rtcFilterIntersection se puede llamar dentro de una función de callback RTCIntersectFunctionN para invocar la función de filtro de intersección registrada para la geometría y almacenada dentro del contexto. Para ello, se debe crear una estructura RTCFilterFunctionNArguments (ver rtcSetGeometryIntersectFilterFunction) que básicamente consiste en una máscara válida, un paquete de impacto a filtrar, el paquete de rayo correspondiente y el tamaño del paquete. Después de invocar rtcFilterIntersection, solo los rayos que aún sean válidos (máscara válida establecida a -1) deberían actualizar un impacto.

ESTADO DE SALIDA

Por razones de rendimiento, esta función no realiza comprobaciones de errores, por lo tanto, no establecerá ningún indicador de error en caso de fallo.

VER TAMBIÉN

[rtcFilterOcclusion], [rtcSetGeometryIntersectFunction]
