NOMBRE

rtcSetSceneFlags - establece las banderas de la escena

SINAPSIS

#include <embree4/rtcore.h>
enum RTCSceneFlags
{
  RTC_SCENE_FLAG_NONE                    = 0,
  RTC_SCENE_FLAG_DYNAMIC                 = (1 << 0),
  RTC_SCENE_FLAG_COMPACT                 = (1 << 1),
  RTC_SCENE_FLAG_ROBUST                  = (1 << 2),
  RTC_SCENE_FLAG_FILTER_FUNCTION_IN_ARGUMENTS = (1 << 3)
};
void rtcSetSceneFlags(RTCScene scene, enum RTCSceneFlags flags);

DESCRIPCIÓN

La función rtcSetSceneFlags establece las banderas de la escena (argumento flags) para la escena especificada (argumento scene). Las banderas de escena posibles son:

•
RTC_SCENE_FLAG_NONE: Ninguna bandera establecida.
•
RTC_SCENE_FLAG_DYNAMIC: Proporciona un mejor rendimiento de construcción para escenas dinámicas (pero también un mayor consumo de memoria).
•
RTC_SCENE_FLAG_COMPACT: Utiliza estructuras de aceleración compactas y evita algoritmos que consumen mucha memoria.
•
RTC_SCENE_FLAG_ROBUST: Utiliza estructuras de aceleración que permiten una traviesa robusta, y evita optimizaciones que reducen la precisión aritmética. Este modo se utiliza típicamente para evitar artefactos causados por rayos que atraviesan los bordes de primitivas vecinas.
•
RTC_SCENE_FLAG_FILTER_FUNCTION_IN_ARGUMENTS: Habilita el soporte de escena para funciones de filtro pasadas como argumento a las funciones de traversa. Véase la Sección [rtcInitIntersectArguments] y [rtcInitOccludedArguments] para más detalles.

Se pueden habilitar múltiples banderas utilizando una operación OR, por ejemplo, RTC_SCENE_FLAG_COMPACT | RTC_SCENE_FLAG_ROBUST.

ESTADO DE SALIDA

En caso de fallo, se establece un código de error que puede ser consultado utilizando rtcGetDeviceError.
