NOMBRE

rtcUpdateGeometryBuffer - marca un buffer vinculado a la geometría como modificado

SINOPSIS

#include <embree4/rtcore.h>
void rtcUpdateGeometryBuffer(
  RTCGeometry geometry,
  enum RTCBufferType type,
  unsigned int slot
);

DESCRIPCIÓN

La función `rtcUpdateGeometryBuffer` marca la vista del buffer vinculada al tipo y ranura de buffer especificados (argumentos `type` y `slot`) de una geometría (argumento `geometry`) como modificada.

Si una aplicación modifica un buffer de datos, se debe invocar la llamada `rtcUpdateGeometryBuffer` para ese buffer. Cada vista de buffer asignada a una ranura de buffer se marca inicialmente como modificada, por lo tanto, esta función solo necesita ser llamada cuando se realizan modificaciones de buffer después de la primera `rtcCommitScene`.

ESTADO DE SALIDA

En caso de error, se establece un código de error que se puede consultar usando `rtcGetDeviceError`.

VER TAMBIÉN

[rtcNewGeometry], [rtcCommitScene]
