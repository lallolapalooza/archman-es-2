rtnetlink(3) Manual de Funciones de Biblioteca rtnetlink(3)

NOMBRE

rtnetlink - macros para manipular mensajes rtnetlink

BIBLIOTECA

Biblioteca C estándar (libc, -lc)

SINOPSIS

#include <asm/types.h>
#include <linux/netlink.h>
#include <linux/rtnetlink.h>
#include <sys/socket.h>
rtnetlink_socket = socket(AF_NETLINK, int tipo_socket, NETLINK_ROUTE);
int RTA_OK(struct rtattr *rta, int tamano);
void *RTA_DATA(struct rtattr *rta);
unsigned int RTA_PAYLOAD(struct rtattr *rta);
struct rtattr *RTA_NEXT(struct rtattr *rta, unsigned int tamano);
unsigned int RTA_LENGTH(unsigned int tamano);
unsigned int RTA_SPACE(unsigned int tamano);

DESCRIPCIÓN

Todos los mensajes de rtnetlink(7) consisten en una cabecera de mensaje netlink(7) y atributos adjuntos. Los atributos solo deben manipularse utilizando las macros proporcionadas aquí.

RTA_OK(rta, tamano) devuelve verdadero si rta apunta a un atributo de enrutamiento válido; tamano es el tamaño actual del búfer de atributos. Cuando no es verdadero, debe asumir que no hay más atributos en el mensaje, incluso si tamano es distinto de cero.

RTA_DATA(rta) devuelve un puntero al inicio de los datos de este atributo.

RTA_PAYLOAD(rta) devuelve el tamaño de los datos de este atributo.

RTA_NEXT(rta, tamano) obtiene el siguiente atributo después de rta. La llamada a esta macro actualizará tamano. Debe usar RTA_OK para verificar la validez del puntero devuelto.

RTA_LENGTH(tamano) devuelve el tamaño que se requiere para tamano bytes de datos más la cabecera.

RTA_SPACE(tamano) devuelve la cantidad de espacio que se necesitará en un mensaje con tamano bytes de datos.

EJEMPLOS

Creación de un mensaje rtnetlink para establecer la MTU de un dispositivo:


#include <linux/rtnetlink.h>
...
struct {
    struct nlmsghdr  nh;
    struct ifinfomsg if;
    char             attrbuf[512];
} req;
struct rtattr *rta;
unsigned int mtu = 1000;
int rtnetlink_sk = socket(AF_NETLINK, SOCK_DGRAM, NETLINK_ROUTE);
memset(&req, 0, sizeof(req));
req.nh.nlmsg_len = NLMSG_LENGTH(sizeof(req.if));
req.nh.nlmsg_flags = NLM_F_REQUEST;
req.nh.nlmsg_type = RTM_NEWLINK;
req.if.ifi_family = AF_UNSPEC;
req.if.ifi_index = INTERFACE_INDEX;
req.if.ifi_change = 0xffffffff; /* ??? */
rta = (struct rtattr *) ((char *) &req +
                         NLMSG_ALIGN(req.nh.nlmsg_len));
rta->rta_type = IFLA_MTU;
rta->rta_len = RTA_LENGTH(sizeof(mtu));
req.nh.nlmsg_len = NLMSG_ALIGN(req.nh.nlmsg_len) +
                              RTA_LENGTH(sizeof(mtu));
memcpy(RTA_DATA(rta), &mtu, sizeof(mtu));
send(rtnetlink_sk, &req, req.nh.nlmsg_len, 0);
