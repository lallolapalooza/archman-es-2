NOMBRE

rtcGetGeometryTransformFromScene - devuelve la transformación de instancia
  interpolada para el tiempo especificado

SINOPSIS

#include <embree4/rtcore.h>
void rtcGetGeometryTransformFromScene(
  RTCScene scene,
  unsigned int geomID,
  float time,
  enum RTCFormat format,
  void* xfm
);

DESCRIPCIÓN

La función rtcGetGeometryTransformFromScene devuelve la transformación local a mundo interpolada (parámetro de salida xfm) de una geometría de instancia especificada por su ID de geometría (parámetro geomID) de una escena (parámetro scene) para un tiempo particular (parámetro time en el rango [0,1]) en el formato especificado (parámetro format).

Los formatos posibles para la matriz devuelta son:

•
RTC_FORMAT_FLOAT3X4_ROW_MAJOR: La matriz float de 3x4 se dispone en forma de fila principal.
•
RTC_FORMAT_FLOAT3X4_COLUMN_MAJOR: La matriz float de 3x4 se dispone en forma de columna principal.
•
RTC_FORMAT_FLOAT4X4_COLUMN_MAJOR: La matriz float de 3x4 se dispone en forma de columna principal como una matriz homogénea de 4x4 con la última fila igual a (0, 0, 0, 1).

A diferencia de la función rtcGetGeometryTransform, la función rtcGetGeometryTransformFromScene se puede usar durante el renderizado dentro de un kernel SYCL.

ESTADO DE SALIDA

En caso de error, se establece un código de error que se puede consultar usando rtcGetDeviceError.

VER TAMBIÉN
