rtl_power(1)

Paquete: rtl-sdr

rtl_power:(1) Comandos de Usuario rtl_power:(1)

NOMBRE

rtl_power: - utilidad de monitorización de espectro de banda ancha

DESCRIPCIÓN

Utiliza un receptor DVB-T reutilizado como radio definida por software para recibir señales en forma de datos I/Q. Escrito para e incorporado en el proyecto rtl-sdr de osmocom.

USO

rtl_power, un registrador FFT simple para receptores DVB-T basados en RTL2832

Esta herramienta recopila datos de señal sobre un área muy amplia del espectro de frecuencias, y luego esos datos se pueden usar para encontrar áreas activas del espectro.

Uso: rtl_power -f rango_freq [-opciones] [nombre_archivo]

-f inferior:superior:tamaño_bin [Hz]

(el tamaño del bin es un máximo, se usarán bins más pequeños y convenientes
y
rango válido de 1Hz - 2.8MHz)
[-i intervalo_integración (predeterminado: 10 segundos)]
(defectuoso si un barrido completo toma más tiempo que el intervalo)
[-1 habilita el modo de disparo único (predeterminado: desactivado)] [-e temporizador_salida (predeterminado: desactivado/0)] [-d índice_dispositivo (predeterminado: 0)] [-g ganancia_sintonizador (predeterminado: automático)] [-p error_ppm (predeterminado: 0)] nombre_archivo (un '-' vuelca las muestras a stdout)
(omitir el nombre_archivo también usa stdout)

Opciones experimentales:

[-w ventana (predeterminado: rectangular)]
(hamming, blackman, blackman-harris, hann-poisson, bartlett, youssef)
[-c porcentaje_recorte (predeterminado: 0%, recomendado: 20%-50%)]
(descarta datos en los bordes, 100% descarta todo) (no tiene efecto para bins mayores a 1MHz)
[-F tamaño_fir (predeterminado: desactivado)]
(habilita el filtro de submuestreo de baja fuga,
el tamaño_fir puede ser 0 o 9.
0 tiene una mala caída,
intenta con '-c 50%')
[-P habilita la retención de picos (predeterminado: desactivado)] [-D habilita el muestreo directo (predeterminado: desactivado)] [-O habilita la sintonización de offset (predeterminado: desactivado)]

Columnas de salida FFT CSV:

fecha, hora, Hz bajo, Hz alto, paso Hz, muestras, dbm, dbm, ...

EJEMPLOS

rtl_power -f 88M:108M:125k fm_stations.csv
(crea 160 bins en la banda FM,
las estaciones individuales deberían ser visibles)
rtl_power -f 100M:1G:1M -i 5m -1 survey.csv
(un escaneo de baja resolución de casi todo durante cinco minutos)
rtl_power -f ... -i 15m -1 log.csv
(integra durante 15 minutos y sale después)
rtl_power -f ... -e 1h | gzip > log.csv.gz
(recopila datos durante una hora y los comprime sobre la marcha)

Convertir CSV a una imagen de cascada con:

http://kmkeen.com/tmp/heatmap.py.txt

rtl_power(1)

rtl_power - Un programa de utilidad para registrar datos de radio definidos por el usuario.

SINOPSIS

rtl_power [-f <freqrange>] [-g <gain>] [-i <interval>] [-n <num_samples>] [-e <end_of_capture>] [-o <output_file>] [-d <device>]

DESCRIPCIÓN

rtl_power es una herramienta de línea de comandos diseñada para registrar datos de radio de dispositivos RTL2832U. Permite a los usuarios especificar rangos de frecuencia, ganancia, intervalos de muestreo y la cantidad de muestras a capturar. Los datos se pueden guardar en un archivo para su posterior análisis.

OPCIONES

-f <freqrange>
Especifica el rango de frecuencias a escanear. El formato es start_freq:end_freq[:step].
-g <gain>
Establece la ganancia del sintonizador en dB. Puede ser una ganancia automática o un valor específico.
-i <interval>
Establece el intervalo de muestreo en segundos. Por defecto es 1 segundo.
-n <num_samples>
Número de muestras a tomar por cada frecuencia o rango de frecuencia. Si no se especifica, se capturará hasta que se detenga el programa manualmente o se alcance el final de la captura.
-e <end_of_capture>
Establece el tiempo de finalización de la captura en segundos desde el inicio. Útil para capturas de duración fija.
-o <output_file>
Especifica el nombre del archivo de salida donde se guardarán los datos. Si no se especifica, los datos se imprimirán en la salida estándar.
-d <device>
Especifica el dispositivo RTL2832U a utilizar. Si hay varios dispositivos conectados, esto ayuda a seleccionar uno específico.

EJEMPLOS

Para escanear el rango de frecuencia de 100 MHz a 102 MHz con un paso de 0.1 MHz y guardar los datos en output.bin:

rtl_power -f 100M:102M:100k -o output.bin

Para capturar 60 segundos de datos de radio alrededor de 433.92 MHz con una ganancia de 30 dB:

rtl_power -f 433.92M -g 30 -e 60 -o radio_data.dat
