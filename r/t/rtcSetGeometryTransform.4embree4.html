rtcSetGeometryTransform(3) Kernels de Trazado de Rayos Embree 4 rtcSetGeometryTransform(3)

NOMBRE

rtcSetGeometryTransform - establece la transformación para un paso de
  tiempo particular de una geometría de instancia

SINOPSIS

#include <embree4/rtcore.h>
void rtcSetGeometryTransform(
  RTCGeometry geometry,
  unsigned int timeStep,
  enum RTCFormat format,
  const float* xfm
);

DESCRIPCIÓN

La función rtcSetGeometryTransform establece la transformación afín local-a-mundo (parámetro xfm) de una geometría de instancia (parámetro geometry) para un paso de tiempo particular (parámetro timeStep). La transformación se especifica como una matriz de 3×4 (transformación lineal de 3×3 más traslación), para la cual se soportan los siguientes formatos (parámetro format):

•
RTC_FORMAT_FLOAT3X4_ROW_MAJOR: La matriz flotante de 3×4 se organiza en orden de fila principal (row-major).
•
RTC_FORMAT_FLOAT3X4_COLUMN_MAJOR: La matriz flotante de 3×4 se organiza en orden de columna principal (column-major).
•
RTC_FORMAT_FLOAT4X4_COLUMN_MAJOR: La matriz flotante de 3×4 se organiza en orden de columna principal como una matriz homogénea de 4×4 con la última fila igual a (0, 0, 0, 1).

ESTADO DE SALIDA

En caso de fallo, se establece un código de error que se puede consultar mediante rtcGetDeviceError.

VER TAMBIÉN

[RTC_GEOMETRY_TYPE_INSTANCE]
