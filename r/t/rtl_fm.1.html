NOMBRE

rtl_fm - un simple demodulador FM para receptores DVB-T basados en RTL2832

DESCRIPCIÓN

Utiliza un receptor DVB-T reutilizado como radio definida por software para recibir señales FM de banda estrecha y demodularlas a audio. Escrito para y incorporado en el proyecto osmocom rtl-sdr.

La FM de banda estrecha es comúnmente utilizada por agencias de servicio público y operaciones comerciales de despacho en las bandas VHF y UHF. También puede demodular FM de banda ancha, como se encuentra en la banda de radiodifusión FM de 88-108 MHz. Las opciones experimentales incluyen demodulación AM, LSB, USB y DSB.

Hay mucho software disponible para el RTL2832. La mayoría de los paquetes a nivel de usuario dependen de la biblioteca librtlsdr, que viene como parte del código fuente de rtl-sdr. Este código fuente contiene tanto la biblioteca en sí como una serie de herramientas de línea de comandos, como rtl_test, rtl_sdr, rtl_tcp y rtl_fm. Estas herramientas de línea de comandos utilizan la biblioteca para probar la existencia de dispositivos RTL2832 y realizar funciones básicas de transferencia de datos hacia y desde el dispositivo.

Dado que la mayoría de los dispositivos RTL2832 se conectan mediante USB, la biblioteca librtlsdr depende de la biblioteca libusb para comunicarse con el dispositivo.

USO

Con una antena adecuada para recibir la señal conectada al dispositivo compatible con rtl-sdr, este programa emitirá los datos de audio digital decodificados de esa señal. Los datos se pueden escuchar canalizándolos a las aplicaciones Sox o aplay para reproducir la transmisión en la tarjeta de sonido del ordenador.

SINOPSIS

rtl_fm [-f freq] [-opciones] [nombre_archivo]

OPCIONES

-f frecuencia_a_sintonizar [Hz]

usa múltiples -f para escanear (requiere squelch)
se admiten rangos, -f 118M:137M:25k
[-M modulación (por defecto: fm)]

fm, wbfm, raw, am, usb, lsb
wbfm == -M fm -s 170k -o 4 -A fast -r 32k -l 0 -E deemp
el modo raw emite pares IQ de 2x16 bits
-s tasa_de_muestreo (por defecto: 24k)
-d índice_dispositivo (por defecto: 0)
-g ganancia_sintonizador (por defecto: automática)
-l nivel_squelch (por defecto: 0/apagado)
-o sobremuestreo (por defecto: 1, se recomienda 4)

para la fm, el squelch está invertido
[-o sobremuestreo (por defecto: 1, se recomienda 4)]
-p error_ppm (por defecto: 0)
[-E activar_opcion (por defecto: ninguna)]

usa múltiples -E para activar múltiples opciones
edge: activa la sintonización del borde inferior
dc: activa el filtro de bloqueo de CC
deemp: activa el filtro de desénfasis
direct: activa el muestreo directo
offset: activa la sintonización de desplazamiento
nombre_archivo ('-' significa stdout)

omitir el nombre del archivo también usa stdout

Opciones experimentales

[-r tasa_remuestreo (por defecto: ninguna / igual que -s)]
[-t retardo_squelch (por defecto: 10)]

los valores +silenciarán/escanearán, los valores -saldrán
[-F tamaño_fir (por defecto: apagado)]

activa el filtro de bajada de baja fuga
el tamaño puede ser 0 o 9. 0 tiene una caída deficiente
-A std/fast/lut elige la función atan (por defecto: std)
nombre_archivo

(un '-' vuelca las muestras a stdout)
(omitir el nombre del archivo también usa stdout)

EJEMPLOS

Produce enteros de 16 bits con signo, usa Sox o aplay para escucharlos.

rtl_fm ... - | play -t raw -r 24k -es -b 16 -c 1 -V1 -

| aplay -r 24k -f S16_LE -t raw -c 1
-M wbfm | play -r 32k ...
rtl_fm ... -s 22050 - | multimon -t raw /dev/stdin
