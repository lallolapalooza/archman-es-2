rtcSetGeometryVertexAttributeCount(3) Embree Ray Tracing Kernels 3 rtcSetGeometryVertexAttributeCount(3)

NOMBRE

rtcSetGeometryVertexAttributeCount - establece el número de atributos de
  vértice de la geometría

SINOPSIS

#include <embree3/rtcore.h>
void rtcSetGeometryVertexAttributeCount(
  RTCGeometry geometry,
  unsigned int vertexAttributeCount
);

DESCRIPCIÓN

La función rtcSetGeometryVertexAttributeCount establece el número de espacios (parámetro vertexAttributeCount) para los búferes de atributos de vértice (RTC_BUFFER_TYPE_VERTEX_ATTRIBUTE) que se pueden utilizar para la geometría especificada (parámetro geometry).

Esta función solo se admite para mallas triangulares (RTC_GEOMETRY_TYPE_TRIANGLE), mallas de cuadriláteros (RTC_GEOMETRY_TYPE_QUAD), curvas (RTC_GEOMETRY_TYPE_CURVE), puntos (RTC_GEOMETRY_TYPE_POINT) y geometrías de subdivisión (RTC_GEOMETRY_TYPE_SUBDIVISION).

ESTADO DE SALIDA

En caso de error, se establece un código de error que se puede consultar mediante rtcGetDeviceError.

VER TAMBIÉN

[rtcNewGeometry], [RTCBufferType]
