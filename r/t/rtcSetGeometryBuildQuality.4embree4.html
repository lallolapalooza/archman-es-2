NOMBRE

rtcSetGeometryBuildQuality - establece la calidad de construcción para la geometría

SINOPSIS

#include <embree4/rtcore.h>
void rtcSetGeometryBuildQuality(
  RTCGeometry geometry,
  enum RTCBuildQuality quality
);

DESCRIPCIÓN

La función rtcSetGeometryBuildQuality establece la calidad de construcción (argumento quality) para la geometría especificada (argumento geometry). La calidad de construcción por geometría es solo una pista y puede ser ignorada. Embree actualmente utiliza la calidad de construcción por geometría cuando la calidad de construcción de la escena se establece en RTC_BUILD_QUALITY_LOW. En este modo, se construye una estructura de aceleración de dos niveles, y las geometrías construyen una estructura de aceleración separada utilizando la calidad de construcción de la geometría. La calidad de construcción por geometría puede ser una de las siguientes:

•
RTC_BUILD_QUALITY_LOW: Crea estructuras de datos de menor calidad, p. ej., para escenas dinámicas.
•
RTC_BUILD_QUALITY_MEDIUM: Calidad de construcción predeterminada para la mayoría de los usos. Ofrece un buen compromiso entre el rendimiento de construcción y renderizado.
•
RTC_BUILD_QUALITY_HIGH: Crea estructuras de datos de mayor calidad para renderizado final. Habilita un constructor de división espacial para ciertos tipos de primitivas.
•
RTC_BUILD_QUALITY_REFIT: Utiliza un enfoque de ajuste de BVH al cambiar solo el búfer de vértices.

ESTADO DE SALIDA

En caso de error, se establece un código de error que se puede consultar usando rtcGetDeviceError.

VER TAMBIÉN

[rtcSetSceneBuildQuality]
