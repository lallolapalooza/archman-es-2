NOMBRE

rtcInterpolate - interpola atributos de vértices

SINOPSIS

#include <embree4/rtcore.h>
struct RTCInterpolateArguments
{
  RTCGeometry geometry;
  unsigned int primID;
  float u;
  float v;
  enum RTCBufferType bufferType;
  unsigned int bufferSlot;
  float* P;
  float* dPdu;
  float* dPdv;
  float* ddPdudu;
  float* ddPdvdv;
  float* ddPdudv;
  unsigned int valueCount;
};
void rtcInterpolate(
  const struct RTCInterpolateArguments* args
);

DESCRIPCIÓN

La función `rtcInterpolate` interpola suavemente datos por vértice sobre la geometría. Esta interpolación es compatible con mallas de triángulos, mallas de cuádruples, geometrías de curvas y geometrías de subdivisión. Además de interpolar el atributo de vértice en sí, también es posible obtener las derivadas de primer y segundo orden de dicho valor. Esta interpolación ignora los desplazamientos de las superficies de subdivisión y siempre interpola la superficie base subyacente.

La llamada a `rtcInterpolate` recibe un número de argumentos dentro de una estructura del tipo `RTCInterpolateArguments`. Para una geometría determinada (parámetro `geometry`), esta función interpola suavemente los datos por vértice almacenados dentro del búfer de geometría especificado (parámetros `bufferType` y `bufferSlot`) a la ubicación u/v (parámetros `u` y `v`) de la primitiva (parámetro `primID`). El número de valores de punto flotante a interpolar y almacenar en los arrays de destino se puede especificar usando el parámetro `valueCount`. Como búfer de interpolación, se pueden especificar búferes de vértices (`RTC_BUFFER_TYPE_VERTEX`) y búferes de atributos de vértices (`RTC_BUFFER_TYPE_VERTEX_ATTRIBUTE`).

La llamada a `rtcInterpolate` almacena `valueCount` número de valores de punto flotante interpolados en la ubicación de memoria a la que apunta `P`. Se puede evitar almacenar el valor interpolado estableciendo `P` a `NULL`.

Las derivadas de primer orden de la interpolación con respecto a `u` y `v` se almacenan en las ubicaciones de memoria `dPdu` y `dPdv`. Se pueden evitar almacenar las derivadas de primer orden estableciendo tanto `dPdu` como `dPdv` a `NULL`.

Las derivadas de segundo orden se almacenan en las ubicaciones de memoria `ddPdudu`, `ddPdvdv` y `ddPdudv`. Se pueden evitar almacenar las derivadas de segundo orden estableciendo estos tres punteros a `NULL`.

Para usar `rtcInterpolate` en una geometría, todos los cambios en esa geometría deben ser confirmados correctamente usando `rtcCommitGeometry`.

Todos los búferes de entrada y arrays de salida deben estar alineados a 16 bytes, ya que la implementación utiliza instrucciones SSE de 16 bytes para leer y escribir en estos búferes.

Ver el tutorial [Interpolación] para un ejemplo de uso de la función `rtcInterpolate`.

ESTADO DE SALIDA

Por razones de rendimiento, esta función no realiza ninguna comprobación de errores, por lo tanto, no establecerá ningún indicador de error en caso de fallo.
