rtcSetGeometryBuffer(3) Embree Ray Tracing Kernels 3 rtcSetGeometryBuffer(3)

NOMBRE

rtcSetGeometryBuffer - asigna una vista de un buffer a la geometría

SINOPSIS

#include <embree3/rtcore.h>
void rtcSetGeometryBuffer(
  RTCGeometry geometry,
  enum RTCBufferType type,
  unsigned int slot,
  enum RTCFormat format,
  RTCBuffer buffer,
  size_t byteOffset,
  size_t byteStride,
  size_t itemCount
);

DESCRIPCIÓN

La función rtcSetGeometryBuffer enlaza una vista de un objeto de buffer (argumento buffer) al tipo y slot de buffer de geometría (argumentos type y slot) de la geometría especificada (argumento geometry).

Se puede especificar la dirección de inicio del primer elemento del buffer en bytes (argumento byteOffset), el stride en bytes entre elementos individuales del buffer (argumento byteStride), el formato de los elementos del buffer (argumento format) y el número de elementos a enlazar (argumento itemCount).

La dirección de inicio (argumento byteOffset) y el stride (argumento byteStride) deben estar alineados a 4 bytes, de lo contrario la función rtcSetGeometryBuffer fallará.

Después de completar exitosamente esta función, la geometría mantendrá una referencia al objeto de buffer.

ESTADO DE SALIDA

En caso de fallo, se establece un código de error que puede ser consultado usando rtcGetDeviceError.

VER TAMBIÉN

[rtcSetSharedGeometryBuffer], [rtcSetNewGeometryBuffer]
