rtl_test(1) Comandos de usuario rtl_test(1)

NOMBRE

rtl_test - una herramienta de benchmark para receptores DVB-T basados en RTL2832

DESCRIPCIÓN

Prueba el rango de sintonización y las tasas de muestreo funcionales de tu dispositivo en tu sistema. Utiliza un receptor DVB-T reutilizado como radio definida por software. Escrito para e incorporado en el proyecto osmocom rtl-sdr.

Hay mucho software disponible para el RTL2832. La mayoría de los paquetes a nivel de usuario dependen de la biblioteca librtlsdr que viene como parte de la base de código de rtl-sdr. Esta base de código contiene tanto la biblioteca en sí como una serie de herramientas de línea de comandos como rtl_test, rtl_sdr, rtl_tcp y rtl_fm. Estas herramientas de línea de comandos utilizan la biblioteca para comprobar la existencia de dispositivos RTL2832 y realizar funciones básicas de transferencia de datos hacia y desde el dispositivo.

Dado que la mayoría de los dispositivos RTL2832 se conectan mediante USB, la biblioteca librtlsdr depende de la biblioteca libusb para comunicarse con el dispositivo.

SINOPSIS

rtl_test [OPCIONES]

OPCIONES

-s tasa_muestreo (predeterminado: 2048000 Hz)
-d índice_dispositivo (predeterminado: 0)
-t habilita el benchmark del sintonizador Elonics E4000]
-p habilita la medición del error PPM
-b tamaño_bloque_salida (predeterminado: 16 * 16384)
-S fuerza la salida de sincronización (predeterminado: asíncrono)

EJEMPLOS

Para comprobar el rango de sintonización posible (puede variar mucho en varios MHz dependiendo del dispositivo y la temperatura), llama a

rtl_test -t
Para comprobar la tasa de muestreo máxima posible en tu máquina, escribe (reduce la tasa hasta que no haya pérdida de muestras):

rtl_test -s 3.2e6

Una tasa de muestreo de 2.4e6 es conocida por funcionar incluso a través de conexiones tcp (ver rtl_tcp arriba). Una tasa de muestreo de 2.88e6 puede funcionar sin pérdida de muestras, pero esto puede depender de la interfaz host de tu PC/portátil.
