rtcSetSceneBuildQuality(3) Kernels de Ray Tracing Embree 3 rtcSetSceneBuildQuality(3)

NOMBRE

rtcSetSceneBuildQuality - establece la calidad de construcción para
  la escena

SINOPSIS

#include <embree3/rtcore.h>
void rtcSetSceneBuildQuality(
  RTCScene scene,
  enum RTCBuildQuality quality
);

DESCRIPCIÓN

La función rtcSetSceneBuildQuality establece la calidad de construcción (argumento quality) para la escena especificada (argumento scene). Los valores posibles para la calidad de construcción son:

•
RTC_BUILD_QUALITY_LOW: Crea estructuras de datos de menor calidad, por ejemplo, para escenas dinámicas. Se construye una estructura de índice espacial de dos niveles al habilitar este modo, que admite actualizaciones parciales rápidas de la escena y permite establecer una calidad de construcción por geometría a través de la función rtcSetGeometryBuildQuality.
•
RTC_BUILD_QUALITY_MEDIUM: Calidad de construcción predeterminada para la mayoría de los usos. Ofrece un buen compromiso entre el rendimiento de construcción y renderizado.
•
RTC_BUILD_QUALITY_HIGH: Crea estructuras de datos de mayor calidad para el renderizado de fotogramas finales. Para ciertos tipos de geometría, esto habilita un BVH de división espacial.

Seleccionar una calidad de construcción más alta da como resultado un mejor rendimiento de renderizado pero tiempos de confirmación de escena más lentos. La calidad de construcción predeterminada para una escena es RTC_BUILD_QUALITY_MEDIUM.

ESTADO DE SALIDA

En caso de error, se establece un código de error que se puede consultar utilizando rtcGetDeviceError.

VER TAMBIÉN

[rtcSetGeometryBuildQuality]
