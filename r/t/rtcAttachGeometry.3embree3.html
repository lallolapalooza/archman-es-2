rtcAttachGeometry(3) Kernels de Trazado de Rayos Embree 3 rtcAttachGeometry(3)

NOMBRE

rtcAttachGeometry - adjunta una geometría a la escena

SINOPSIS

#include <embree3/rtcore.h>
unsigned int rtcAttachGeometry(
  RTCScene scene,
  RTCGeometry geometry
);

DESCRIPCIÓN

La función rtcAttachGeometry adjunta una geometría (argumento geometry) a una escena (argumento scene) y asigna un ID de geometría a esa geometría. Todas las geometrías adjuntas a una escena se definen como incluidas dentro de la escena. Una geometría puede adjuntarse a múltiples escenas. El ID de geometría es único para la escena y se utiliza para identificar la geometría cuando es alcanzada por un rayo durante las consultas de rayos.

Esta función es segura para hilos, por lo que múltiples hilos pueden adjuntar geometrías a una escena en paralelo.

Los IDs de geometría se asignan secuencialmente, comenzando desde 0, siempre que ninguna geometría se haya desvinculado. Si se han desvinculado geometrías, la implementación reutilizará IDs de forma dependiente de la implementación. En consecuencia, la asignación secuencial ya no está garantizada, pero sí un rango compacto de IDs.

Estas reglas permiten a la aplicación administrar un array dinámico para mapear eficientemente los IDs de geometría a su propia representación de geometría. Alternativamente, la aplicación también puede usar datos de usuario por geometría para mapear a su representación de geometría. Consulte rtcSetGeometryUserData y rtcGetGeometryUserData para más información.

ESTADO DE SALIDA

En caso de error, se establece un código de error que se puede consultar utilizando rtcGetDeviceError.

VER TAMBIÉN

[rtcSetGeometryUserData], [rtcGetGeometryUserData]
