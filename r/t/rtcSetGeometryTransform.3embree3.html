rtcSetGeometryTransform(3) Kernels de Trazado de Rayos Embree 3 rtcSetGeometryTransform(3)

NOMBRE

rtcSetGeometryTransform - establece la transformación para un paso de
  tiempo particular de una geometría de instancia

SINOPSIS

#include <embree3/rtcore.h>
void rtcSetGeometryTransform(
  RTCGeometry geometry,
  unsigned int timeStep,
  enum RTCFormat format,
  const float* xfm
);

DESCRIPCIÓN

La función rtcSetGeometryTransform establece la transformación afín local-a-mundo (parámetro xfm) de una geometría de instancia (parámetro geometry) para un paso de tiempo particular (parámetro timeStep). La transformación se especifica como una matriz de 3×4 (transformación lineal de 3×3 más traslación), para la cual se admiten los siguientes formatos (parámetro format):

•
RTC_FORMAT_FLOAT3X4_ROW_MAJOR: La matriz flotante de 3×4 está dispuesta en formato de fila principal.
•
RTC_FORMAT_FLOAT3X4_COLUMN_MAJOR: La matriz flotante de 3×4 está dispuesta en formato de columna principal.
•
RTC_FORMAT_FLOAT4X4_COLUMN_MAJOR: La matriz flotante de 3×4 está dispuesta en formato de columna principal como una matriz homogénea de 4×4 con la última fila igual a (0, 0, 0, 1).

ESTADO DE SALIDA

En caso de error, se establece un código de error que se puede consultar usando rtcGetDeviceError.

VER TAMBIÉN

[RTC_GEOMETRY_TYPE_INSTANCE]
