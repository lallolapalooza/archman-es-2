rtcSetGeometryOccludedFilterFunction(3) Embree Ray Tracing Kernels 3 rtcSetGeometryOccludedFilterFunction(3)

NOMBRE

rtcSetGeometryOccludedFilterFunction - establece el filtro de oclusión
  para la geometría

SINOPSIS

#include <embree3/rtcore.h>
void rtcSetGeometryOccludedFilterFunction(
  RTCGeometry geometry,
  RTCFilterFunctionN filter
);

DESCRIPCIÓN

La función rtcSetGeometryOccludedFilterFunction registra una función de devolución de llamada de filtro de oclusión (argumento filter) para la geometría especificada (argumento geometry).

Solo se puede registrar una función de devolución de llamada por geometría, y las invocaciones posteriores sobrescriben la función de devolución de llamada previamente establecida. Pasar NULL como puntero de función deshabilita la función de devolución de llamada registrada.

La función de filtro de intersección registrada se invoca para cada impacto encontrado durante las consultas de rayos de tipo rtcOccluded y puede aceptar o rechazar ese impacto. La característica se puede utilizar para definir una silueta para una primitiva y rechazar los impactos que estén fuera de la silueta. Por ejemplo, la hoja de un árbol podría modelarse con una textura alfa que decide si los puntos de impacto se encuentran dentro o fuera de la hoja.

Por favor, consulte la descripción de rtcSetGeometryIntersectFilterFunction para una descripción de la función de devolución de llamada de filtro.

ESTADO DE SALIDA

En caso de error, se establece un código de error que se puede consultar mediante rtcGetDeviceError.

VER TAMBIÉN
