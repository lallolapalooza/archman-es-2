NOMBRE

rtcGetGeometryFace - devuelve la cara de un semiarco

SINOPSIS

#include <embree4/rtcore.h>
unsigned int rtcGetGeometryFace(
  RTCGeometry geometry,
  unsigned int edgeID
);

DESCRIPCIÓN

La función rtcGetGeometryFace devuelve el ID de la cara a la que pertenece el semiarco especificado (argumento edgeID). Por ejemplo, en el siguiente ejemplo se devuelve la cara f1 para los arcos e4, e5, e6 y e7.

Esta función solo se puede utilizar para geometrías de subdivisión. Dado que todas las topologías de una geometría de subdivisión comparten el mismo búfer de caras, la función no depende del ID de topología.

ESTADO DE SALIDA

En caso de error, se establece un código de error que se puede consultar mediante rtcGetDeviceError.
