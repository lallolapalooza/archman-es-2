rtcGetGeometryTransform(3) Núcleos de trazado de rayos Embree 4 rtcGetGeometryTransform(3)

NOMBRE

rtcGetGeometryTransform - devuelve la transformación de instancia interpolada
  para el tiempo especificado

SINOPSIS

#include <embree4/rtcore.h>
void rtcGetGeometryTransform(
  RTCGeometry geometry,
  float time,
  enum RTCFormat format,
  void* xfm
);

DESCRIPCIÓN

La función rtcGetGeometryTransform devuelve la transformación de local a mundo interpolada (parámetro xfm) de una geometría de instancia (parámetro geometry) para un tiempo particular (parámetro time en el rango [0,1]) en el formato especificado (parámetro format).

Los formatos posibles para la matriz devuelta son:

•
RTC_FORMAT_FLOAT3X4_ROW_MAJOR: La matriz float 3x4 se organiza en forma de fila principal.
•
RTC_FORMAT_FLOAT3X4_COLUMN_MAJOR: La matriz float 3x4 se organiza en forma de columna principal.
•
RTC_FORMAT_FLOAT4X4_COLUMN_MAJOR: La matriz float 3x4 se organiza en forma de columna principal como una matriz homogénea de 4x4 con la última fila igual a (0, 0, 0, 1).

Esta función está pensada para ser utilizada durante la renderización, pero solo es compatible con la CPU y no dentro de los kernels SYCL en la GPU. Dentro de un kernel SYCL, se debe usar la función rtcGetGeometryTransformFromScene.

ESTADO DE SALIDA

En caso de error, se establece un código de error que puede ser consultado con rtcGetDeviceError.

VER TAMBIÉN

[RTC_GEOMETRY_TYPE_INSTANCE], [rtcSetGeometryTransform], [rtcGetGeometryTransformFromScene]
