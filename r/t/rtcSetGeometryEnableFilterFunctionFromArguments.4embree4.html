NOMBRE

rtcSetGeometryEnableFilterFunctionFromArguments - habilita las funciones de filtro de argumentos para la geometría

SINOPSIS

#include <embree4/rtcore.h>
void rtcSetGeometryEnableFilterFunctionFromArguments(
   RTCGeometry geometry, bool enable);

DESCRIPCIÓN

Esta función habilita la invocación de la función de filtro pasada a través de RTCIntersectArguments o RTCOccludedArguments a las consultas de intersección y oclusión. Si `enable` es verdadero, la invocación de la función de filtro de argumentos se habilita para la geometría o se deshabilita en caso contrario. Por defecto, la invocación de la función de filtro de argumentos está deshabilitada para algunas geometrías.

La invocación de la función de filtro de argumentos también se puede forzar para cada geometría utilizando el indicador de consulta de rayos RTC_RAY_QUERY_FLAG_INVOKE_ARGUMENT_FILTER, que se puede pasar a las funciones rtcIntersect y rtcOccluded. Consulte la Sección [rtcInitIntersectArguments] y [rtcInitOccludedArguments] para obtener más detalles.

Para utilizar la función de filtro de argumentos para alguna escena, esta característica debe habilitarse adicionalmente utilizando el indicador de escena RTC_SCENE_FLAG_FILTER_FUNCTION_IN_ARGUMENTS. Consulte la Sección [rtcSetSceneFlags] para obtener más detalles.

VALOR DE RETORNO

En caso de error, se establece un código de error que se puede consultar mediante rtcGetDeviceError.

VER TAMBIÉN

[rtcInitIntersectArguments], [rtcInitOccludedArguments], [rtcSetSceneFlags]
