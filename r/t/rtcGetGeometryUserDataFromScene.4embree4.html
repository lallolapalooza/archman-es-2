NOMBRE

rtcGetGeometryUserDataFromScene - devuelve el puntero de datos de usuario
  del objeto de escena

SINOPSIS

#include <embree4/rtcore.h>
void* rtcGetGeometryUserDataFromScene(RTCScene scene, unsigned int geomID);

DESCRIPCIÓN

La función rtcGetGeometryUserDataFromScene consulta el puntero de datos de usuario establecido previamente con rtcSetGeometryUserData desde la geometría con el índice geomID de la escena especificada scene. Si rtcSetGeometryUserData aún no se ha llamado, se devuelve NULL.

A diferencia de la función rtcGetGeometryUserData, la función rtcGetGeometryUserDataFromScene se puede utilizar durante el renderizado dentro de un kernel SYCL.

ESTADO DE SALIDA

En caso de error, se establece un código de error que se puede consultar usando rtcGetDeviceError.

VER TAMBIÉN

rtcSetGeometryUserData, rtcGetGeometryUserData
