NOMBRE

rtcGetDeviceError - devuelve el código de error del dispositivo

SINOPSIS

#include <embree4/rtcore.h>
RTCError rtcGetDeviceError(RTCDevice device);

DESCRIPCIÓN

Cada hilo tiene su propio código de error por dispositivo. Si ocurre un error al llamar a una función de API, este código de error se establece al error ocurrido si no almacena un error previo. La función rtcGetDeviceError lee y devuelve el error almacenado actualmente y borra el código de error. Esto asegura que el código de error devuelto sea siempre el primer error ocurrido desde la última invocación de rtcGetDeviceError.

Los posibles códigos de error devueltos por rtcGetDeviceError son:

•
RTC_ERROR_NONE: No ocurrió ningún error.
•
RTC_ERROR_UNKNOWN: Ocurrió un error desconocido.
•
RTC_ERROR_INVALID_ARGUMENT: Se especificó un argumento no válido.
•
RTC_ERROR_INVALID_OPERATION: La operación no está permitida para el objeto especificado.
•
RTC_ERROR_OUT_OF_MEMORY: No queda suficiente memoria para completar la operación.
•
RTC_ERROR_UNSUPPORTED_CPU: La CPU no es compatible ya que no admite el ISA mínimo para el que está compilado Embree.
•
RTC_ERROR_CANCELLED: La operación fue cancelada por una función de devolución de llamada de monitor de memoria o de monitor de progreso.
•
RTC_ERROR_LEVEL_ZERO_RAYTRACING_SUPPORT_MISSING: Este error puede ocurrir al crear un dispositivo Embree con soporte SYCL usando rtcNewSYCLDevice y fallar. Este error probablemente significa que el controlador de la GPU es demasiado antiguo o no está instalado correctamente. Instale un controlador de GPU nuevo y en Linux asegúrese de que el paquete intel-level-zero-gpu-raytracing esté instalado. Para obtener información general sobre la instalación de controladores para Linux, consulte https://dgpu-docs.intel.com.

Cuando la construcción del dispositivo falla, rtcNewDevice devuelve NULL como dispositivo. Para detectar el código de error de una construcción de dispositivo fallida, pase NULL como dispositivo a la función rtcGetDeviceError. Para todas las demás invocaciones de rtcGetDeviceError, se debe especificar un puntero de dispositivo válido.

La función de API rtcGetDeviceLastErrorMessage se puede utilizar para obtener más detalles sobre el último RTCError que encontró un RTCDevice.

Para la notificación conveniente de un RTCError, se puede usar la función de API rtcGetErrorString, que devuelve una representación en cadena de un RTCError dado.

ESTADO DE SALIDA

Devuelve el código de error para el dispositivo.

VER TAMBIÉN

[rtcSetDeviceErrorFunction], [rtcGetDeviceLastErrorMessage], [rtcGetErrorString]
