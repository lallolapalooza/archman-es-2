rtcInitPointQueryContext(3) Kernels de Ray Tracing Embree 4 rtcInitPointQueryContext(3)

NOMBRE

rtcInitPointQueryContext - inicializa la información de contexto (ej.
  pila de transformaciones de instancia (multinivel)) para consultas de puntos

SINÓPSIS

#include <embree4/rtcore.h>
struct RTC_ALIGN(16) RTCPointQueryContext
{
  // Matrices acumuladas de columna mayor de 4x4 desde el mundo al espacio de instancia.
  float world2inst[RTC_MAX_INSTANCE_LEVEL_COUNT][16];
  // Matrices acumuladas de columna mayor de 4x4 desde la instancia al mundo.
  float inst2world[RTC_MAX_INSTANCE_LEVEL_COUNT][16];
  // IDs de instancia.
  unsigned int instID[RTC_MAX_INSTANCE_LEVEL_COUNT];
  // número de instancias actualmente en la pila.
  unsigned int instStackSize;
};
void rtcInitPointQueryContext(
  struct RTCPointQueryContext* context
);

DESCRIPCIÓN

Una pila (tipo RTCPointQueryContext) que almacena los IDs y transformaciones de instancia durante un recorrido BVH para una consulta de puntos. Se asume que las transformaciones son transformaciones afines (matriz de 3×3 más traslación) y, por lo tanto, se ignora la última columna (ver [RTC_GEOMETRY_TYPE_INSTANCE] para más detalles).

La función rtcInitPointContext inicializa el contexto con valores predeterminados y debe llamarse para la inicialización.

El contexto se pasará como argumento a la función de devolución de llamada de consulta de puntos (ver [rtcSetGeometryPointQueryFunction]) y debe usarse para pasar información de instancia hacia abajo en la cadena de instanciación para instanciación definida por el usuario (ver el tutorial [ClosestPoint] para una implementación de referencia de consultas de puntos con instanciación definida por el usuario).

El contexto es un argumento necesario para [rtcPointQuery] y Embree utiliza internamente la transformación de instancia superior de la pila para transformar la consulta de puntos al espacio de instancia.

ESTADO DE SALIDA

Esta función no establece ningún código de error.

VER TAMBIÉN

[rtcPointQuery], [rtcSetGeometryPointQueryFunction]
