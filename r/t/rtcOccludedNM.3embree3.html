rtcOccludedNM(3) Núcleos de trazado de rayos Embree 3 rtcOccludedNM(3)

NOMBRE

rtcOccludedNM - encuentra cualquier intersección para un flujo de M rayos
  paquetes de tamaño N

SINOPSIS

#include <embree3/rtcore.h>
void rtcOccludedNM(
  RTCScene scene,
  struct RTCIntersectContext* context,
  struct RTCRayN* ray,
  unsigned int N,
  unsigned int M,
  size_t byteStride
);

DESCRIPCIÓN

La función rtcOccludedNM comprueba si hay alguna intersección para un flujo de M paquetes de rayos (argumento ray) de tamaño N con la escena (argumento scene). El argumento ray apunta a una matriz de paquetes de rayos con una distancia entre bytes especificada (argumento byteStride) entre los paquetes de rayos. Ver Sección [rtcOccluded1] para una descripción de cómo configurar y trazar rayos de oclusión.

Un rayo en un flujo de rayos se considera inactivo si su valor tnear es mayor que su valor tfar.

El tamaño del paquete N debe ser mayor que 0, y el tamaño del flujo M puede ser un entero positivo arbitrario, incluido 0. Cada rayo debe estar alineado a 16 bytes.

ESTADO DE SALIDA

Por razones de rendimiento, esta función no realiza ninguna comprobación de errores, por lo que no establecerá ninguna bandera de error en caso de fallo.

VER TAMBIÉN

[rtcIntersectNM]
