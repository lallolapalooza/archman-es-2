rtcSetGeometryTransformQuaternion(3) Núcleos de Ray Tracing de Embree 4 rtcSetGeometryTransformQuaternion(3)

NOMBRE

rtcSetGeometryTransformQuaternion - establece la transformación para un
  paso de tiempo particular de una geometría de instancia como una descomposición de
  la matriz de transformación usando cuaterniones para representar la rotación.

SINOPSIS

#include <embree4/rtcore.h>
void rtcSetGeometryTransformQuaternion(
  RTCGeometry geometry,
  unsigned int timeStep,
  const struct RTCQuaternionDecomposition* qd
);

DESCRIPCIÓN

La función rtcSetGeometryTransformQuaternion establece la transformación afín local-a-mundo (parámetro qd) de una geometría de instancia (parámetro geometry) para un paso de tiempo particular (parámetro timeStep). La transformación se especifica como una [RTCQuaternionDecomposition], que es una descomposición de una transformación afín que representa el componente rotacional de una transformación afín como un cuaternión. Esto permite interpolar transformaciones rotacionales exactamente usando interpolación lineal esférica (como una rueda giratoria).

Para más información sobre la descomposición, consulte [RTCQuaternionDecomposition]. El cuaternión dado en la estructura RTCQuaternionDecomposition se normalizará internamente.

Para obtener resultados correctos, las matrices de transformación para todos los pasos de tiempo deben establecerse utilizando rtcSetGeometryTransform o rtcSetGeometryTransformQuaternion. No se permite mezclar ambas representaciones. Se utilizará la interpolación lineal esférica si las matrices de transformación se establecen con rtcSetGeometryTransformQuaternion.

Para un ejemplo de esta característica, consulte el tutorial [Movimiento con Cuaterniones y Desenfoque].

ESTADO DE SALIDA

En caso de error, se establece un código de error que puede ser consultado con rtcGetDeviceError.

VER TAMBIÉN

[rtcInitQuaternionDecomposition], [rtcSetGeometryTransform]
