NOMBRE

rtcGetDeviceLastErrorMessage - devuelve un mensaje que corresponde
  al último código de error

SINOPSIS

#include <embree4/rtcore.h>
const char* rtcGetDeviceLastErrorMessage(RTCDevice device);

DESCRIPCIÓN

Esta función se puede usar para obtener un mensaje que corresponde al último código de error (devuelto por rtcGetDeviceError), que a menudo proporciona detalles sobre el error ocurrido. El mensaje es el mismo que se escribirá en la consola cuando la verbosidad sea > 0 o que se pasa como argumento str de la RTCErrorFunction (ver [rtcSetDeviceErrorFunction]). Sin embargo, cuando la construcción del dispositivo falla, esta es la única forma de obtener información adicional sobre el error. En este caso, rtcNewDevice devuelve NULL como dispositivo. Para consultar el mensaje de error para una construcción de dispositivo fallida, pase NULL como dispositivo a la función rtcGetDeviceLastErrorMessage. Para todas las demás invocaciones de rtcGetDeviceLastErrorMessage, se debe especificar un puntero de dispositivo válido.

ESTADO DE SALIDA

Devuelve un mensaje que corresponde al último código de error.

VER TAMBIÉN

[rtcGetDeviceError], [rtcSetDeviceErrorFunction]
