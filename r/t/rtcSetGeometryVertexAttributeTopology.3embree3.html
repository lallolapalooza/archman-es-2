rtcSetGeometryVertexAttributeTopology(3) Embree Ray Tracing Kernels 3 rtcSetGeometryVertexAttributeTopology(3)

NOMBRE

rtcSetGeometryVertexAttributeTopology - vincula un atributo de vértice
  a una topología de la geometría

SINOPSIS

#include <embree3/rtcore.h>
void rtcSetGeometryVertexAttributeTopology(
  RTCGeometry geometry,
  unsigned int vertexAttributeID,
  unsigned int topologyID
);

DESCRIPCIÓN

La función `rtcSetGeometryVertexAttributeTopology` vincula un búfer de atributo de vértice (argumento `vertexAttributeID`) a una topología (argumento `topologyID`) para la geometría de subdivisión especificada (argumento `geometry`). Los búferes de vértices estándar siempre se vinculan a la topología predeterminada (topología 0) y no se pueden vincular de otra manera. Un búfer de atributo de vértice siempre utiliza la topología a la que está vinculado cuando se usa en las llamadas `rtcInterpolate` y `rtcInterpolateN`.

Una topología con el ID i consta de un modo de subdivisión establecido a través de `rtcSetGeometrySubdivisionMode` y el búfer de índices vinculado a la ranura de búfer de índices i. Este búfer de índices puede asignar índices para cada cara de la geometría de subdivisión que sean diferentes a los índices de la topología predeterminada. Estos nuevos índices pueden, por ejemplo, utilizarse para introducir bordes adicionales en la malla de subdivisión para mapear múltiples texturas en una sola geometría de subdivisión.

ESTADO DE SALIDA

En caso de error, se establece un código de error que se puede consultar usando `rtcGetDeviceError`.

VER TAMBIÉN

[rtcSetGeometrySubdivisionMode], [rtcInterpolate], [rtcInterpolateN]
