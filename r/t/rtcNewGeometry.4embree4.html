NOMBRE

rtcNewGeometry - crea un nuevo objeto de geometría

SINOPSIS

#include <embree4/rtcore.h>
enum RTCGeometryType
{
 RTC_GEOMETRY_TYPE_TRIANGLE,
 RTC_GEOMETRY_TYPE_QUAD,
 RTC_GEOMETRY_TYPE_SUBDIVISION,
 RTC_GEOMETRY_TYPE_FLAT_LINEAR_CURVE,
 RTC_GEOMETRY_TYPE_FLAT_BEZIER_CURVE,
 RTC_GEOMETRY_TYPE_FLAT_BSPLINE_CURVE,
 RTC_GEOMETRY_TYPE_FLAT_HERMITE_CURVE,
 RTC_GEOMETRY_TYPE_FLAT_CATMULL_ROM_CURVE,
 RTC_GEOMETRY_TYPE_NORMAL_ORIENTED_BEZIER_CURVE,
 RTC_GEOMETRY_TYPE_NORMAL_ORIENTED_BSPLINE_CURVE,
 RTC_GEOMETRY_TYPE_NORMAL_ORIENTED_HERMITE_CURVE,
 RTC_GEOMETRY_TYPE_NORMAL_ORIENTED_CATMULL_ROM_CURVE,
 RTC_GEOMETRY_TYPE_CONE_LINEAR_CURVE,
 RTC_GEOMETRY_TYPE_ROUND_LINEAR_CURVE,
 RTC_GEOMETRY_TYPE_ROUND_BEZIER_CURVE,
 RTC_GEOMETRY_TYPE_ROUND_BSPLINE_CURVE,
 RTC_GEOMETRY_TYPE_ROUND_HERMITE_CURVE,
 RTC_GEOMETRY_TYPE_ROUND_CATMULL_ROM_CURVE,
 RTC_GEOMETRY_TYPE_GRID,
 RTC_GEOMETRY_TYPE_SPHERE_POINT,
 RTC_GEOMETRY_TYPE_DISC_POINT,
 RTC_GEOMETRY_TYPE_ORIENTED_DISC_POINT,
 RTC_GEOMETRY_TYPE_USER,
 RTC_GEOMETRY_TYPE_INSTANCE,
 RTC_GEOMETRY_TYPE_INSTANCE_ARRAY,
};
RTCGeometry rtcNewGeometry(
  RTCDevice device,
  enum RTCGeometryType type
);

DESCRIPCIÓN

Las geometrías son objetos que representan un array de primitivas del mismo tipo. La función rtcNewGeometry crea una nueva geometría del tipo especificado (argumento type) enlazada al dispositivo especificado (argumento device) y devuelve un handle a esta geometría. El objeto de geometría tiene un contador de referencias con un valor inicial de 1. El handle de la geometría puede liberarse usando la llamada a la API rtcReleaseGeometry.

Los tipos de geometría soportados son mallas de triángulos (tipo RTC_GEOMETRY_TYPE_TRIANGLE), mallas de cuádruplas (pares de triángulos) (tipo RTC_GEOMETRY_TYPE_QUAD), superficies de subdivisión Catmull-Clark (tipo RTC_GEOMETRY_TYPE_SUBDIVISION), geometrías de curvas con diferentes bases (RTC_GEOMETRY_TYPE_FLAT_LINEAR_CURVE, RTC_GEOMETRY_TYPE_FLAT_BEZIER_CURVE,

RTC_GEOMETRY_TYPE_FLAT_BSPLINE_CURVE, RTC_GEOMETRY_TYPE_FLAT_HERMITE_CURVE,

RTC_GEOMETRY_TYPE_FLAT_CATMULL_ROM_CURVE, RTC_GEOMETRY_TYPE_NORMAL_ORIENTED_BEZIER_CURVE, RTC_GEOMETRY_TYPE_NORMAL_ORIENTED_BSPLINE_CURVE, RTC_GEOMETRY_TYPE_NORMAL_ORIENTED_HERMITE_CURVE, RTC_GEOMETRY_TYPE_NORMAL_ORIENTED_CATMULL_ROM_CURVE, RTC_GEOMETRY_TYPE_CONE_LINEAR_CURVE, RTC_GEOMETRY_TYPE_ROUND_LINEAR_CURVE, RTC_GEOMETRY_TYPE_ROUND_BEZIER_CURVE, RTC_GEOMETRY_TYPE_ROUND_BSPLINE_CURVE, RTC_GEOMETRY_TYPE_ROUND_HERMITE_CURVE, RTC_GEOMETRY_TYPE_ROUND_CATMULL_ROM_CURVE tipos) mallas de rejilla (RTC_GEOMETRY_TYPE_GRID), geometrías de puntos (RTC_GEOMETRY_TYPE_SPHERE_POINT, RTC_GEOMETRY_TYPE_DISC_POINT, RTC_TYPE_ORIENTED_DISC_POINT), geometrías definidas por el usuario (RTC_GEOMETRY_TYPE_USER), instancias (RTC_GEOMETRY_TYPE_INSTANCE), y arrays de instancias (RTC_GEOMETRY_TYPE_INSTANCE_ARRAY).

Los tipos RTC_GEOMETRY_TYPE_ROUND_BEZIER_CURVE, RTC_GEOMETRY_TYPE_ROUND_BSPLINE_CURVE, y RTC_GEOMETRY_TYPE_ROUND_CATMULL_ROM_CURVE tratarán la curva como una superficie de barrido de un círculo de radio variable barrido tangencialmente a lo largo de la curva. Los tipos RTC_GEOMETRY_TYPE_FLAT_BEZIER_CURVE, RTC_GEOMETRY_TYPE_FLAT_BSPLINE_CURVE, y RTC_GEOMETRY_TYPE_FLAT_CATMULL_ROM_CURVE utilizan cintas orientadas a los rayos como una aproximación más rápida de intersectar.

Después de la construcción, las geometrías están habilitadas por defecto y no están adjuntas a ninguna escena. Las geometrías pueden deshabilitarse (llamada a rtcDisableGeometry) y habilitarse de nuevo (llamada a rtcEnableGeometry). Una geometría puede adjuntarse a múltiples escenas usando la llamada a rtcAttachGeometry (o la llamada a rtcAttachGeometryByID) y desadjuntarse usando la llamada a rtcDetachGeometry. Durante la adjunción, se asigna un ID de geometría a la geometría (o lo asigna el usuario cuando se utiliza la llamada a rtcAttachGeometryByID), que identifica de forma única la geometría dentro de esa escena. Este identificador se devuelve cuando se golpean primitivas de la geometría en posteriores consultas de rayos para la escena.

Las geometrías también pueden modificarse, incluidos sus búferes de vértices e índices. Después de modificar un búfer, se debe llamar a rtcUpdateGeometryBuffer para notificar que el búfer ha sido modificado.

La aplicación puede usar la función rtcSetGeometryUserData para establecer un puntero de datos de usuario a su propia representación de geometría, y leer posteriormente este puntero usando la función rtcGetGeometryUserData.

Después de configurar la geometría o modificarla, se debe llamar a rtcCommitGeometry para finalizar la configuración de la geometría. Después de confirmar la geometría, la interpolación de datos de vértices se puede realizar utilizando las funciones rtcInterpolate y rtcInterpolateN.

Se puede especificar una calidad de construcción para una geometría usando la función rtcSetGeometryBuildQuality, para equilibrar el rendimiento de construcción de la estructura de aceleración y el rendimiento de la consulta de rayos. La calidad de construcción por geometría se utilizará si se construye internamente una estructura de aceleración de dos niveles, lo cual ocurre si se establece RTC_BUILD_QUALITY_LOW como calidad de construcción de la escena. Véase la Sección [rtcSetSceneBuildQuality] para más detalles.

ESTADO DE SALIDA

En caso de fallo se devuelve NULL y se establece un código de error que puede ser consultado usando rtcGetDeviceError.
