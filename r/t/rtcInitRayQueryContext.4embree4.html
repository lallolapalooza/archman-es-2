NOMBRE

rtcInitRayQueryContext - inicializa el contexto de consulta de rayos

SINOPSIS

#include <embree4/rtcore.h>
struct RTCRayQueryContext
{
  #if RTC_MAX_INSTANCE_LEVEL_COUNT > 1
    unsigned int instStackSize;
  #endif
  unsigned int instID[RTC_MAX_INSTANCE_LEVEL_COUNT];
};
void rtcInitRayQueryContext(
  struct RTCRayQueryContext* context
);

DESCRIPCIÓN

La función rtcInitRayQueryContext inicializa el contexto de intersección a valores predeterminados y debe ser llamada para inicializar cada contexto de consulta de rayos.

Se garantiza que el puntero al contexto de consulta de rayos (tipo RTCRayQueryContext) se pasa a las funciones de callback registradas. De esta manera es posible adjuntar datos arbitrarios al final del contexto de consulta de rayos, como una carga útil por rayo.

Dentro del callback de geometría de usuario, el contexto de consulta de rayos puede ser utilizado para acceder a la pila de instID y saber en qué instancia reside el objeto de geometría de usuario.

Si no se especifica ningún contexto de consulta de rayos al trazar un rayo, se utiliza un contexto predeterminado.

ESTADO DE SALIDA

Esta función no establece ningún código de error.
