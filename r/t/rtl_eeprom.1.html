NOMBRE

rtl-eeprom - Herramienta de programación EEPROM para receptores DVB-T basados en RTL2832

DESCRIPCIÓN

Descarga configuración y también escribe configuración de la EEPROM. Escrito por Steve Markgraf e incorporado en el proyecto osmocom rtl-sdr.

¡Úsalo bajo tu propio riesgo, especialmente -w!

Hay mucho software disponible para el RTL2832. La mayoría de los paquetes a nivel de usuario dependen de la biblioteca librtlsdr, que viene como parte de la base de código de rtl-sdr. Esta base de código contiene tanto la biblioteca en sí como una serie de herramientas de línea de comandos como rtl_test, rtl_sdr, rtl_tcp y rtl_fm. Estas herramientas de línea de comandos utilizan la biblioteca para probar la existencia de dispositivos RTL2832 y para realizar funciones básicas de transferencia de datos hacia y desde el dispositivo.

Dado que la mayoría de los dispositivos RTL2832 se conectan mediante USB, la biblioteca librtlsdr depende de la biblioteca libusb para comunicarse con el dispositivo.

USO

Escribir información incorrecta en la EEPROM hará que tu dispositivo sea inútil.

SINOPSIS

rtl_eeprom [OPCIONES]

OPCIONES

-d índice_dispositivo (predeterminado: 0)
-m <cadena> establecer cadena de fabricante
-p <cadena> establecer cadena de producto
-s <cadena> establecer cadena de número de serie
-i <0,1> deshabilitar/habilitar endpoint IR
-g <conf> generar configuración predeterminada y escribirla en el dispositivo

<conf> puede ser uno de:
realtek Predeterminado Realtek (como sin EEPROM)
realtek_oem OEM Realtek predeterminado con EEPROM
noxon Terratec NOXON DAB Stick
terratec_black Terratec T Stick Black
terratec_plus Terratec T Stick+ (DVB-T/DAB)
-w <nombre_archivo> escribir archivo descargado en el dispositivo
-r <nombre_archivo> descargar EEPROM a archivo
-h mostrar este texto de ayuda

¡Úsalo bajo tu propio riesgo, especialmente -w!
