RTMON(8) Manual del Administrador del Sistema RTMON(8)

NOMBRE

rtmon - escucha y monitoriza RTnetlink

SINOPSIS


rtmon [ OPCIONES ] archivo ARCHIVO [ todo | OBJETOS ]

OPCIONES := { f[amilia] { inet | inet6 | link | ayuda } | -4 | -6 | -0 | -V[ersión] }

OBJETOS := [ link ] [ direccion ] [ ruta ]

DESCRIPCIÓN

Esta página del manual documenta brevemente el comando rtmon.

rtmon escucha en el socket de netlink y monitoriza los cambios en la tabla de enrutamiento.

rtmon puede iniciarse antes de emitir el primer comando de configuración de red. Por ejemplo, si insertas:

rtmon archivo /var/log/rtmon.log

en un script de inicio, podrás ver el historial completo más tarde. Ciertamente, es posible iniciar rtmon en cualquier momento. Antepone al historial una instantánea del estado volcada en el momento de iniciarse.

OPCIONES

rtmon soporta las siguientes opciones:

-Versión
Imprime la versión y sale.
ayuda
Muestra un resumen de las opciones.
archivo ARCHIVO [ todo | OBJETOS ]
Registra la salida en ARCHIVO. OBJETOS es la lista de tipos de objetos que queremos monitorizar. Puede contener 'link', 'direccion', 'ruta' y 'todo'. 'link' especifica el dispositivo de red, 'direccion' la dirección del protocolo (IP o IPv6) en un dispositivo, 'ruta' la entrada de la tabla de enrutamiento y 'todo' hace lo que dice el nombre.
-familia [ inet | inet6 | link | ayuda ]
Especifica la familia de protocolos. 'inet' es IPv4, 'inet6' es IPv6, 'link' significa que no está involucrado ningún protocolo de red y 'ayuda' imprime información de uso.
-4
Usa IPv4. Atajo para -familia inet.
-6
Usa IPv6. Atajo para -familia inet6.
-0
Usa un identificador especial de familia que significa que no está involucrado ningún protocolo de red. Atajo para -familia link.

EJEMPLOS DE USO

# rtmon archivo /var/log/rtmon.log
Registra en el archivo /var/log/rtmon.log, luego ejecuta:
# ip monitor archivo /var/log/rtmon.log
para mostrar la salida registrada del archivo.
