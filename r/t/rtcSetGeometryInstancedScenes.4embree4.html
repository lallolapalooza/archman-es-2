rtcSetGeometryInstancedScenes(3) Embree Ray Tracing Kernels 4 rtcSetGeometryInstancedScenes(3)

NOMBRE

rtcSetGeometryInstancedScenes - establece un array de escenas que pueden
ser instanciadas por una geometría de array de instancias

SINOPSIS

#include <embree4/rtcore.h>
void rtcSetGeometryInstancedScenes(
  RTCGeometry geometry,
  RTCScene* scene,
  size_t numScenes
);

DESCRIPCIÓN

La función rtcSetGeometryInstancedScenes establece un array de tipo RTCScene con numScenes elementos que la geometría de instancia especificada (argumento geometry) puede instanciar. Esta llamada también requiere establecer un buffer de índices utilizando rtcSetSharedGeometryBuffer o rtcSetNewGeometryBuffer (similar a los buffers de índices para mallas de triángulos), que especifica qué instancia del array de instancias instancia qué escena en el array de escenas. Si solo se debe instanciar una escena, se debe preferir la llamada rtcSetGeometryInstancedScene.

ESTADO DE SALIDA

En caso de fallo, se establece un código de error que se puede consultar con rtcGetDeviceError.

VER TAMBIÉN

[RTC_GEOMETRY_TYPE_INSTANCE_ARRAY], [rtcSetNewGeometryBuffer], [rtcSetSharedGeometryBuffer], [rtcSetGeometryInstancedScene]
