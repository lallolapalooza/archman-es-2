sigpending(2) Manual de llamadas al sistema sigpending(2)

NOMBRE

sigpending, rt_sigpending - examinar señales pendientes

BIBLIOTECA

Biblioteca C estándar (libc, -lc)

SINOPSIS

#include <signal.h>
int sigpending(sigset_t *set);
Requisitos de Macro de Prueba de Funciones para glibc (ver feature_test_macros(7)):

sigpending():

    _POSIX_C_SOURCE

DESCRIPCIÓN

sigpending() devuelve el conjunto de señales que están pendientes de entrega al hilo que realiza la llamada (es decir, las señales que se han activado mientras estaban bloqueadas). La máscara de señales pendientes se devuelve en set.

VALOR DE RETORNO

sigpending() devuelve 0 si la operación tiene éxito. En caso de error, devuelve -1 y errno se establece para indicar el error.

ERRORES

EFAULT
set apunta a memoria que no es una parte válida del espacio de direcciones del proceso.

ESTÁNDARES

POSIX.1-2024.

HISTORIAL

POSIX.1-2001.

DIFERENCIAS C BIBLIOTECA/KERNEL

La llamada al sistema original de Linux se llamaba sigpending(). Sin embargo, con la adición de señales en tiempo real en Linux 2.2, el tipo sigset_t de tamaño fijo de 32 bits soportado por esa llamada al sistema ya no era adecuado. En consecuencia, se añadió una nueva llamada al sistema, rt_sigpending(), para soportar un tipo sigset_t ampliado. La nueva llamada al sistema toma un segundo argumento, size_t sigsetsize, que especifica el tamaño en bytes del conjunto de señales en set. La función envoltorio sigpending() de glibc oculta estos detalles, llamando de forma transparente a rt_sigpending() cuando el kernel lo proporciona.

NOTAS

Ver sigsetops(3) para más detalles sobre la manipulación de conjuntos de señales.

Si una señal está bloqueada y tiene una disposición de "ignorada", no se añade a la máscara de señales pendientes cuando se genera.

El conjunto de señales que está pendiente para un hilo es la unión del conjunto de señales que está pendiente para ese hilo y el conjunto de señales que está pendiente para el proceso en su conjunto; ver signal(7).

Un hijo creado a través de fork(2) inicialmente tiene un conjunto de señales pendientes vacío; el conjunto de señales pendientes se conserva a través de una execve(2).

ERRORES GRAVES

Hasta glibc 2.2.1, inclusive, hay un error en la función envoltorio para sigpending() que significa que la información sobre señales en tiempo real pendientes no se devuelve correctamente.

VER TAMBIÉN

kill(2), sigaction(2), signal(2), sigprocmask(2), sigsuspend(2), sigsetops(3), signal(7)
