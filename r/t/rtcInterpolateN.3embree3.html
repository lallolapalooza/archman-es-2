rtcInterpolateN(3) Kernels de Trazado de Rayos Embree 3 rtcInterpolateN(3)

NOMBRE

rtcInterpolateN - realiza N interpolaciones de datos de atributos de vértice

SINOPSIS

#include <embree3/rtcore.h>
struct RTCInterpolateNArguments
{
  RTCGeometry geometry;
  const void* valid;
  const unsigned int* primIDs;
  const float* u;
  const float* v;
  unsigned int N;
  enum RTCBufferType bufferType;
  unsigned int bufferSlot;
  float* P;
  float* dPdu;
  float* dPdv;
  float* ddPdudu;
  float* ddPdvdv;
  float* ddPdudv;
  unsigned int valueCount;
};
void rtcInterpolateN(
  const struct RTCInterpolateNArguments* args
);

DESCRIPCIÓN

rtcInterpolateN es similar a rtcInterpolate, pero realiza N interpolaciones a la vez. Adicionalmente recibe un array de coordenadas u/v y una máscara de validez (parámetro valid) que especifica cuáles de estas coordenadas son válidas. El puntero valid apunta a N enteros, y un valor de -1 denota válido y 0 inválido. Si el puntero valid es NULL, todos los elementos se consideran válidos. Los arrays de destino se rellenan en un diseño de estructura de arrays (SOA).

El valor N debe ser divisible por 4.

Para usar rtcInterpolateN para una geometría, todos los cambios en esa geometría deben ser confirmados correctamente usando rtcCommitGeometry.

ESTADO DE SALIDA

Por razones de rendimiento, esta función no realiza ninguna comprobación de errores, por lo tanto, no establecerá ningún indicador de error en caso de fallo.

VER TAMBIÉN

[rtcInterpolate]
