rtcSetGeometryUserPrimitiveCount(3) Kernels de Trazado de Rayos Embree 3 rtcSetGeometryUserPrimitiveCount(3)

NOMBRE

rtcSetGeometryUserPrimitiveCount - establece el número de primitivas
  de una geometría definida por el usuario

SINOPSIS

#include <embree3/rtcore.h>
void rtcSetGeometryUserPrimitiveCount(
  RTCGeometry geometry,
  unsigned int userPrimitiveCount
);

DESCRIPCIÓN

La función rtcSetGeometryUserPrimitiveCount establece el número de primitivas definidas por el usuario (parámetro userPrimitiveCount) de la geometría definida por el usuario especificada (parámetro geometry).

ESTADO DE SALIDA

En caso de error, se establece un código de error que se puede consultar usando rtcGetDeviceError.

VER TAMBIÉN

[RTC_GEOMETRY_TYPE_USER]
