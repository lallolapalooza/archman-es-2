RTLBROWSE(1) Visualización de archivos RTLBROWSE(1)

NOMBRE

rtlbrowse - Permite la navegación jerárquica del código fuente Verilog HDL y archivos de diseño de bibliotecas.

SINTAXIS

rtlbrowse <nombrearchivo_stems>

DESCRIPCIÓN

Permite la navegación jerárquica del código fuente Verilog HDL y archivos de diseño de bibliotecas. La navegación a través de la jerarquía se puede realizar haciendo clic en áreas abiertas del widget de árbol y haciendo clic en los niveles individuales de la jerarquía. Dentro del código fuente, seleccionar el nombre de la instanciación del módulo haciendo doble clic o seleccionando parte del nombre haciendo clic y arrastrando descenderá más profundamente en la jerarquía RTL. Tenga en cuenta que realiza la anotación opcional del código fuente cuando se llama como aplicación auxiliar por gtkwave(1) y cuando se establece el marcador principal. La anotación del código fuente no está disponible para todos los tipos de archivos de volcado soportados. Está disponible directamente para LXT2, VZT, FST y AET2. Para VCD, use la opción -o,--optimize de gtkwave(1) para optimizar el archivo VCD a FST. Todos los demás tipos de archivos de volcado (LXT, GHW) no son compatibles en este momento.

EJEMPLOS

Para ejecutar este programa de la forma estándar, escriba:

rtlbrowse archivo_stems
La RTL se mostrará en un visor de árbol GTK. Los stems deben haber sido generados previamente con xml2stems(1) o alguna otra herramienta capaz de generar archivos stems compatibles. Tenga en cuenta que gtkwave(1) iniciará este programa como una aplicación cliente para la anotación del código fuente. Lo hace iniciando el visor con el ID de memoria compartida de un segmento de memoria en el visor en lugar de usar un nombre de archivo stems.
