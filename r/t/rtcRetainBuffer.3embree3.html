rtcRetainBuffer(3) Embree Ray Tracing Kernels 3 rtcRetainBuffer(3)

NOMBRE

rtcRetainBuffer - incrementa el contador de referencias del buffer

SINOPSIS

#include <embree3/rtcore.h>
void rtcRetainBuffer(RTCBuffer buffer);

DESCRIPCIÓN

Los objetos de buffer tienen un contador de referencias. La función rtcRetainBuffer incrementa el contador de referencias del objeto buffer pasado (argumento buffer). Esta función, junto con rtcReleaseBuffer, permite utilizar el contador de referencias interno en una clase envolvente C++ para gestionar la propiedad del objeto.

ESTADO DE SALIDA

En caso de fallo, se establece un código de error que se puede consultar mediante rtcGetDeviceError.

VER TAMBIÉN

[rtcNewBuffer], [rtcReleaseBuffer]
