rtcIntersect4/8/16(3) Kernels de Trazado de Rayos Embree 3 rtcIntersect4/8/16(3)

NOMBRE

rtcIntersect4/8/16 - encuentra los impactos más cercanos para un paquete de rayos

SINOPSIS

#include <embree3/rtcore.h>
void rtcIntersect4(
  const int* valid,
  RTCScene scene,
  struct RTCIntersectContext* context,
  struct RTCRayHit4* rayhit
);
void rtcIntersect8(
  const int* valid,
  RTCScene scene,
  struct RTCIntersectContext* context,
  struct RTCRayHit8* rayhit
);
void rtcIntersect16(
  const int* valid,
  RTCScene scene,
  struct RTCIntersectContext* context,
  struct RTCRayHit16* rayhit
);

DESCRIPCIÓN

Las funciones rtcIntersect4/8/16 encuentran los impactos más cercanos para un paquete de rayos de tamaño 4, 8 o 16 (argumento rayhit) con la escena (argumento scene). La entrada de rayos/impactos contiene un paquete de rayos y un paquete de impactos. Consulte la Sección [rtcIntersect1] para obtener una descripción de cómo configurar y trazar rayos.

Se debe proporcionar una máscara de validez de rayos (argumento valid) que almacena un entero de 32 bits (-1 significa válido y 0 inválido) por rayo en el paquete. Solo se procesan los rayos activos y los datos de impacto de los rayos inactivos no se modifican.

Se garantiza que la implementación de estas funciones invoca funciones de devolución de llamada siempre con el mismo tamaño de paquete de rayos y orden de rayos que se especificaron inicialmente.

Para rtcIntersect4, el paquete de rayos debe estar alineado a 16 bytes, para rtcIntersect8 la alineación debe ser de 32 bytes y para rtcIntersect16 la alineación debe ser de 64 bytes.

Las funciones rtcIntersect4, rtcIntersect8 y rtcIntersect16 pueden cambiar el tamaño del paquete de rayos y el orden de los rayos al llamar a funciones de filtro de intersección o devoluciones de llamada de geometría de usuario. Bajo ciertas condiciones, la aplicación puede asumir que los paquetes permanecen intactos, lo cual se puede determinar consultando las propiedades RTC_DEVICE_PROPERTY_NATIVE_RAY4_SUPPORTED, RTC_DEVICE_PROPERTY_NATIVE_RAY8_SUPPORTED, RTC_DEVICE_PROPERTY_NATIVE_RAY16_SUPPORTED a través de la función rtcGetDeviceProperty. Consulte [rtcGetDeviceProperty] para obtener más información.

ESTADO DE SALIDA

Por razones de rendimiento, esta función no realiza ninguna comprobación de errores y, por lo tanto, no establecerá ningún indicador de error en caso de fallo.
