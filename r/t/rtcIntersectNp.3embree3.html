rtcIntersectNp(3) Embree Ray Tracing Kernels 3 rtcIntersectNp(3)

NOMBRE

rtcIntersectNp - encuentra los impactos más cercanos para un flujo de rayos SOA de
  tamaño N

SINOPSIS

#include <embree3/rtcore.h>
void rtcIntersectNp(
  RTCScene scene,
  struct RTCIntersectContext* context,
  struct RTCRayHitNp* rayhit,
  unsigned int N
);

DESCRIPCIÓN

La función rtcIntersectNp encuentra los impactos más cercanos para un flujo de rayos SOA (argumento rays) de tamaño N (básicamente un paquete de rayos grande) con la escena (argumento scene). El argumento rayhit apunta a dos estructuras de punteros con un puntero para cada componente de rayo e impacto. Cada uno de estos punteros apunta a una matriz con los datos del componente de rayo o impacto para cada rayo o impacto. De esta manera, los componentes individuales del flujo de rayos SOA no necesitan almacenarse secuencialmente en memoria, lo que hace posible tener paquetes de rayos de tamaño variable grandes en diseño SOA. Consulte la Sección [rtcIntersect1] para obtener una descripción de cómo configurar y rastrear rayos.

Un rayo en un flujo de rayos se considera inactivo si su valor tnear es mayor que su valor tfar.

El tamaño del flujo N puede ser un entero positivo arbitrario, incluido 0. Cada matriz de componentes de rayos debe estar alineada a 16 bytes.

ESTADO DE SALIDA

Por razones de rendimiento, esta función no realiza ninguna comprobación de errores, por lo que no establecerá ningún indicador de error en caso de fallo.

VER TAMBIÉN

[rtcOccludedNp]
