rtcSetGeometrySubdivisionMode(3) Kernels de trazado de rayos Embree 4 rtcSetGeometrySubdivisionMode(3)

NOMBRE

rtcSetGeometrySubdivisionMode - establece el modo de subdivisión
  de una geometría de subdivisión

SINOPSIS

#include <embree4/rtcore.h>
void rtcSetGeometrySubdivisionMode(
  RTCGeometry geometry,
  unsigned int topologyID,
  enum RTCSubdivisionMode mode
);

DESCRIPCIÓN

La función rtcSetGeometrySubdivisionMode establece el modo de subdivisión (parámetro mode) para la topología (parámetro topologyID) de la geometría de subdivisión especificada (parámetro geometry).

Los modos de subdivisión se pueden utilizar para forzar la interpolación lineal para ciertas partes de la malla de subdivisión:

•
RTC_SUBDIVISION_MODE_NO_BOUNDARY: Las parches de borde se ignoran. De esta manera, cada parche renderizado tiene un conjunto completo de vértices de control.
•
RTC_SUBDIVISION_MODE_SMOOTH_BOUNDARY: La secuencia de puntos de control de borde se utiliza para generar una curva de borde B-spline suave (modo predeterminado).
•
RTC_SUBDIVISION_MODE_PIN_CORNERS: Los vértices de las esquinas se fijan en su ubicación durante la subdivisión.
•
RTC_SUBDIVISION_MODE_PIN_BOUNDARY: Todos los vértices del borde se fijan en su ubicación durante la subdivisión. De esta manera, el borde se interpola linealmente. Este modo se utiliza típicamente para texturizado para mapear también texels en el borde de la textura a la malla.
•
RTC_SUBDIVISION_MODE_PIN_ALL: Todos los vértices del borde se fijan en su ubicación durante la subdivisión. De esta manera, todos los parches se interpola linealmente.

ESTADO DE SALIDA

En caso de error, se establece un código de error que se puede consultar con rtcGetDeviceError.

VER TAMBIÉN
