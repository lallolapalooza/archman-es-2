rtcForwardOccluded1/Ex(3) Núcleos de trazado de rayos Embree 4 rtcForwardOccluded1/Ex(3)

NOMBRE

rtcForwardOccluded1/Ex - reenvía un único rayo a una nueva escena
  desde una devolución de llamada de geometría de usuario

SINOPSIS

#include <embree4/rtcore.h>
void rtcForwardOccluded1(
  const struct RTCOccludedFunctionNArguments* args,
  RTCScene scene,
  struct RTCRay* ray,
  unsigned int instID
);
void rtcForwardOccluded1Ex(
  const struct RTCOccludedFunctionNArguments* args,
  RTCScene scene,
  struct RTCRay* ray,
  unsigned int instID,
  unsigned int instPrimID
);

DESCRIPCIÓN

Las funciones rtcForwardOccluded1 y rtcForwardOccluded1Ex reenvían la travesía de un rayo transformado (argumento ray) a una escena (argumento scene) desde una devolución de llamada de geometría de usuario. La función solo se puede invocar desde una devolución de llamada de geometría de usuario para una travesía de rayo iniciada con la función rtcOccluded1. La estructura de argumentos de la devolución de llamada de la invocación de la devolución de llamada debe pasarse al reenvío del rayo (argumento args). La devolución de llamada de geometría de usuario debe terminar inmediatamente después de invocar la función rtcForwardOccluded1/Ex.

Solo los miembros de origen del rayo y dirección del rayo del argumento ray se utilizan para el reenvío; todas las propiedades adicionales del rayo se heredan de la invocación de travesía del rayo inicial de rtcOccluded1.

La implementación de la función rtcForwardOccluded1 continúa recursivamente la travesía del rayo en la escena especificada y empuja el ID de instancia proporcionado (argumento instID) a la pila de IDs de instancia. La información de impacto se actualiza en la estructura del rayo pasada a la invocación original de rtcOccluded1.

Esta función se puede utilizar para implementar instanciación definida por el usuario utilizando geometrías de usuario, por ejemplo, transformando el rayo de una manera especial y/o seleccionando entre diferentes escenas para instanciar.

Para matrices de instancias definidas por el usuario, la variante rtcForwardIntersect1Ex tiene un argumento adicional instPrimID que se empuja a la pila de IDs de primitiva de instancia. Los IDs de primitiva de instancia identifican qué instancia de una matriz de instancias fue alcanzada.

Al usar Embree en la CPU, es posible invocar recursivamente rtcOccluded1 directamente desde una devolución de llamada de geometría de usuario. Sin embargo, cuando se usa SYCL, el trazado recursivo de rayos no es compatible directamente y se debe usar la función rtcForwardOccluded1/Ex.

La estructura del rayo debe estar alineada a 16 bytes.

ESTADO DE SALIDA

Por razones de rendimiento, esta función no realiza comprobaciones de errores y, por lo tanto, no establecerá ningún indicador de error en caso de fallo.

VER TAMBIÉN

[rtcOccluded1], [RTCRay]
