NOMBRE

rtcSetGeometryMask - establece la máscara de geometría

SINOPSIS

#include <embree3/rtcore.h>
void rtcSetGeometryMask(
  RTCGeometry geometry,
  unsigned int mask
);

DESCRIPCIÓN

La función rtcSetGeometryMask establece una máscara de geometría de 32 bits (argumento mask) para la geometría especificada (argumento geometry).

Esta máscara de geometría se utiliza junto con la máscara de rayo almacenada en el campo mask del rayo. Los primitivos de la geometría son alcanzados por el rayo solo si la operación AND bit a bit de la máscara de geometría con la máscara de rayo no es 0. Esta característica puede usarse para deshabilitar geometrías seleccionadas para rayos etiquetados específicamente, por ejemplo, para deshabilitar la generación de sombras para ciertas geometrías.

Las máscaras de rayo están deshabilitadas en Embree por defecto en tiempo de compilación y se pueden habilitar a través del parámetro EMBREE_RAY_MASK en CMake. Se puede consultar si las máscaras de rayo están habilitadas consultando la propiedad del dispositivo RTC_DEVICE_PROPERTY_RAY_MASK_SUPPORTED usando rtcGetDeviceProperty.

ESTADO DE SALIDA

En caso de error, se establece un código de error que se puede consultar usando rtcGetDeviceError.

VER TAMBIÉN

[RTCRay], [rtcGetDeviceProperty]
