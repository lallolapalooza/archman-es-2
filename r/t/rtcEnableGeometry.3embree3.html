rtcEnableGeometry(3) Núcleos de Ray Tracing Embree 3 rtcEnableGeometry(3)

NOMBRE

rtcEnableGeometry - habilita la geometría

SINOPSIS

#include <embree3/rtcore.h>
void rtcEnableGeometry(RTCGeometry geometry);

DESCRIPCIÓN

La función rtcEnableGeometry habilita la geometría especificada (argumento geometry). Solo las geometrías habilitadas se renderizan. Cada geometría se habilita por defecto en el momento de su construcción.

Después de habilitar una geometría, la escena que contiene esa geometría debe ser confirmada usando rtcCommitScene para que el cambio tenga efecto.

ESTADO DE SALIDA

En caso de error, se establece un código de error que se puede consultar usando rtcGetDeviceError.

VER TAMBIÉN

[rtcNewGeometry], [rtcDisableGeometry], [rtcCommitScene]
