NOMBRE

rtcSetGeometryBoundsFunction - establece una función de callback para consultar el
  cuadro delimitador de primitivas definidas por el usuario

SINOPSIS

#include <embree4/rtcore.h>
struct RTCBoundsFunctionArguments
{
  void* geometryUserPtr;
  unsigned int primID;
  unsigned int timeStep;
  struct RTCBounds* bounds_o;
};
typedef void (*RTCBoundsFunction)(
  const struct RTCBoundsFunctionArguments* args
);
void rtcSetGeometryBoundsFunction(
  RTCGeometry geometry,
  RTCBoundsFunction bounds,
  void* userPtr
);

DESCRIPCIÓN

La función rtcSetGeometryBoundsFunction registra una función de callback para el cuadro delimitador (argumento bounds) con datos (argumento userPtr) para la geometría de usuario especificada (argumento geometry).

Solo se puede registrar una función de callback por geometría, y las invocaciones posteriores sobrescriben la función de callback previamente establecida. Pasar NULL como puntero de función deshabilita la función de callback registrada.

En modo SYCL, la construcción de la BVH se realiza en el host y el puntero de función pasado debe ser un puntero de función del lado del host.

La función de callback del cuadro delimitador registrada se invoca para calcular los cuadros delimitadores alineados con los ejes de las primitivas de la geometría definida por el usuario durante la construcción de la estructura de aceleración espacial. La función de callback del cuadro delimitador de tipo RTCBoundsFunction se invoca con un puntero a una estructura de tipo RTCBoundsFunctionArguments que contiene varios argumentos, como: los datos del usuario de la geometría (miembro geometryUserPtr), el ID de la primitiva para la que se calculará el cuadro delimitador (miembro primID), el paso de tiempo en el que se calculará el cuadro delimitador (miembro timeStep) y una ubicación de memoria para escribir el cuadro delimitador calculado (miembro bounds_o).

En un escenario de uso típico, se almacenaría un puntero a la representación interna del objeto de geometría del usuario utilizando rtcSetGeometryUserData. La función de callback puede entonces leer ese puntero del campo geometryUserPtr y calcular el cuadro delimitador adecuado para la primitiva y el tiempo solicitados, y almacenar ese cuadro delimitador en la estructura de destino (miembro bounds_o).

ESTADO DE SALIDA

En caso de error, se establece un código de error que se puede consultar utilizando rtcGetDeviceError.
