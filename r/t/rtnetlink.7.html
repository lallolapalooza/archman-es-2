rtnetlink(7) Manual de Información Miscelánea rtnetlink(7)

NOMBRE

rtnetlink - socket de enrutamiento de Linux

SINOPSIS

#include <asm/types.h>
#include <linux/netlink.h>
#include <linux/rtnetlink.h>
#include <sys/socket.h>
rtnetlink_socket = socket(AF_NETLINK, int socket_type, NETLINK_ROUTE);

DESCRIPCIÓN

Rtnetlink permite leer y modificar las tablas de enrutamiento del kernel. Se utiliza dentro del kernel para la comunicación entre varios subsistemas, aunque este uso no se documenta aquí, y para la comunicación con programas de espacio de usuario. Rutas de red, direcciones IP, parámetros de enlace, configuraciones de vecinos, disciplinas de cola, clases de tráfico y clasificadores de paquetes pueden ser controlados a través de sockets NETLINK_ROUTE. Se basa en mensajes netlink; vea netlink(7) para más información.

Atributos de enrutamiento

Algunos mensajes rtnetlink tienen atributos opcionales después de la cabecera inicial:


struct rtattr {
    unsigned short rta_len;    /* Longitud de la opción */
    unsigned short rta_type;   /* Tipo de opción */
    /* Siguen los datos */
};

Estos atributos solo deben manipularse utilizando las macros RTA_* o libnetlink, vea rtnetlink(3).

Mensajes

Rtnetlink consiste en estos tipos de mensajes (además de los mensajes netlink estándar):

RTM_NEWLINK
RTM_DELLINK
RTM_GETLINK
Crear, eliminar u obtener información sobre una interfaz de red específica. Estos mensajes contienen una estructura ifinfomsg seguida de una serie de estructuras rtattr.

rtnetlink(7) — Linux manual pages

NAME

rtnetlink - Linux specific routing and network device configuration

SYNOPSIS

Standard sockets API, see rtnetlink(3).

DESCRIPTION

The rtnetlink family is used to manage network interfaces, routing, queuing disciplines, etc. in a way similar to the ip(7) utility.

All rtnetlink messages are composed of a header followed by a variable number of attributes. The header is a standard netlink message, see netlink(7). The attributes are structured as follows:

struct rtattr {
    unsigned short rtattr_len;
    unsigned short rtattr_type;
    unsigned char  rtattr_data[0];
};

rtattr_len is the length of the attribute including itself. rtattr_type is the attribute type. rtattr_data is the attribute payload. Attributes are aligned to (n)lseek(2) boundaries, i.e. 4 bytes.

The message payload follows a header structure that depends on the message type. It is followed by a variable number of attributes.

RTM_NEWLINK
RTM_DELLINK
RTM_GETLINK
Add, remove, or receive information about a network device (interface). The message contains a struct ifinfomsg.
struct ifinfomsg {
    unsigned char  ifi_family;
    unsigned short ifi_index;
    unsigned       ifi_flags;
    unsigned       ifi_change;
};
The attributes of the struct ifinfomsg are:
IFLA_UNSPEC Unused.
IFLA_ADDRESS MAC address.
IFLA_BROADCAST Broadcast address.
IFLA_IFNAME Interface name.
IFLA_MTU Interface MTU.
IFLA_LINK Set interface index for child devices.
IFLA_TXQLEN Transmit queue length.
IFLA_OPERATIONAL Operational state.
IFLA_GROUP Interface group.
IFLA_NET_PR_PRIO Network priority.
IFLA_PROTO_DOWN Protocol down.
The ifi_flags field contains the interface flags, like IFF_UP, IFF_BROADCAST, etc. See <linux/if.h>.
IFLA_OPERATIONAL is the operational state of the interface, which can be one of the following values:
IFLA_OPERATIONAL_UNKNOWN Unknown.
IFLA_OPERATIONAL_UP Interface is up.
IFLA_OPERATIONAL_DOWN Interface is down.
RTM_NEWADDR
RTM_DELADDR
RTM_GETADDR
Add, remove, or receive address information. The message contains a struct ifaddrmsg.
struct ifaddrmsg {
    unsigned char ifa_family;
    int           ifa_prefixlen;
    int           ifa_flags;
    int           ifa_scope;
    unsigned int  ifa_index;
};
The attributes of the struct ifaddrmsg are:
IFA_UNSPEC Unused.
IFA_ADDRESS Address.
IFA_LOCAL Local address.
IFA_LABEL Interface name.
IFA_BROADCAST Broadcast address.
IFA_ANY Any address.
ifa_flags is a bitmask, see <linux/if.h>.
ifa_scope is the address scope, see <linux/rtnetlink.h>.
RTM_NEWROUTE
RTM_DELROUTE
RTM_GETROUTE
Add, remove, or retrieve a route. The message contains a struct rtmsg.
struct rtmsg {
    unsigned char rtm_family;
    unsigned char rtm_dst_len;
    unsigned char rtm_src_len;
    unsigned char rtm_tos;

    int rtm_table;
    unsigned rtm_protocol;
    unsigned rtm_scope;
    unsigned rtm_type;
    unsigned rtm_flags;
};
Attributes of the struct rtmsg:
RTA_UNSPEC Unused.
RTA_DST Destination address.
RTA_SRC Source address.
RTA_IIF Incoming interface index.
RTA_OIF Outgoing interface index.
RTA_GATEWAY Gateway address.
RTA_PRIORITY Route priority.
RTA_METRICS Route metrics (see below).
RTA_NEWDST New destination for policy routing.
RTA_FLOW Flow identifier for policy routing.
RTA_LABEL Route label.
RTA_PROPS Route properties.
RTA_REMOTE Remote address for point-to-point routes.
RTA_TABLE Routing table identifier.
RTA_PROTOINFO Protocol specific information.
RTA_MPLS MPLS label stack.
RTA_MULTIPATH Multipath routing information.
RTA_ENCAP Encapsulation information.
RTA_ENCAP_TYPE Encapsulation type.
RTA_LOCAL Local address for multipath routes.
The rtm_metrics attribute contains a series of key/value pairs defining route metrics. See ip(7) for details.
The rtm_multipath attribute contains a list of route entries for multipath routing. Each entry consists of a header and attributes.
The rtm_encap attribute contains encapsulation information. The address family is specified by rtvia_family and the address by rtvia_addr.
struct rtvia {
    unsigned short rtvia_family;
    unsigned char  rtvia_addr[0];
};
rtvia_addr is the address, rtvia_family is its family type.
RTA_PREF may contain values ICMPV6_ROUTER_PREF_LOW, ICMPV6_ROUTER_PREF_MEDIUM, and ICMPV6_ROUTER_PREF_HIGH defined incw <linux/icmpv6.h>.
RTA_ENCAP_TYPE may contain values LWTUNNEL_ENCAP_MPLS, LWTUNNEL_ENCAP_IP, LWTUNNEL_ENCAP_ILA, or LWTUNNEL_ENCAP_IP6 defined in <linux/lwtunnel.h>.
Fill these values in!
RTM_NEWNEIGH
RTM_DELNEIGH
RTM_GETNEIGH
Add, remove, or receive information about a neighbor table entry (e.g., an ARP entry). The message contains an ndmsg structure.
struct ndmsg {
    unsigned char ndm_family;
    int           ndm_ifindex;  /* Interface index */
    __u16         ndm_state;    /* State */
    __u8          ndm_flags;    /* Flags */
    __u8          ndm_type;
};
struct nda_cacheinfo {
    __u32         ndm_confirmed;
    __u32         ndm_used;
    __u32         ndm_updated;
    __u32         ndm_refcnt;
};
ndm_state is a bit mask of the following states:
NUD_INCOMPLETE a currently resolving cache entry
NUD_REACHABLE a confirmed working cache entry
NUD_STALE an expired cache entry
NUD_DELAY an entry waiting for a timer
NUD_PROBE a cache entry that is currently reprobed
NUD_FAILED an invalid cache entry
NUD_NOARP a device with no destination cache
NUD_PERMANENT a static entry
Valid ndm_flags are:
NTF_PROXY a proxy arp entry
NTF_ROUTER an IPv6 router
The rtattr struct has the following meanings for the rta_type field:
NDA_UNSPEC unknown type
NDA_DST a neighbor cache n/w layer destination address
NDA_LLADDR a neighbor cache link layer address
NDA_CACHEINFO cache statistics
If the rta_type field is NDA_CACHEINFO, then a struct nda_cacheinfo header follows.
RTM_NEWRULE
RTM_DELRULE
RTM_GETRULE
Add, delete, or retrieve a routing rule. Carries a struct rtmsg
RTM_NEWQDISC
RTM_DELQDISC
RTM_GETQDISC
Add, remove, or get a queueing discipline. The message contains a struct tcmsg and may be followed by a series of attributes.
struct tcmsg {
    unsigned char    tcm_family;
    int              tcm_ifindex;   /* interface index */
    __u32            tcm_handle;    /* Qdisc handle */
    __u32            tcm_parent;    /* Parent qdisc */
    __u32            tcm_info;
};
Attributes
rta_type Value type Description
TCA_UNSPEC - unspecified
TCA_KIND asciiz string Name of queueing discipline
TCA_OPTIONS byte sequence Qdisc-specific options follow
TCA_STATS struct tc_stats Qdisc statistics
TCA_XSTATS qdisc-specific Module-specific statistics
TCA_RATE struct tc_estimator Rate limit
In addition, various other qdisc-module-specific attributes are allowed. For more information see the appropriate include files.
RTM_NEWTCLASS
RTM_DELTCLASS
RTM_GETTCLASS
Add, remove, or get a traffic class. These messages contain a struct tcmsg as described above.
RTM_NEWTFILTER
RTM_DELTFILTER
RTM_GETTFILTER
Add, remove, or receive information about a traffic filter. These messages contain a struct tcmsg as described above.
