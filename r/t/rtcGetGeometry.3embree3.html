rtcGetGeometry(3) Kernels de trazado de rayos Embree 3 rtcGetGeometry(3)

NOMBRE

rtcGetGeometry - devuelve la geometría enlazada al
  ID de geometría especificado

SINOPSIS

#include <embree3/rtcore.h>
RTCGeometry rtcGetGeometry(RTCScene scene, unsigned int geomID);

DESCRIPCIÓN

La función rtcGetGeometry devuelve la geometría que está enlazada al ID de geometría especificado (argumento geomID) para la escena especificada (argumento scene). Esta función simplemente busca el manejador y no incrementa el contador de referencias. Si desea obtener la propiedad del manejador, debe llamar adicionalmente a rtcRetainGeometry.

Esta función no es segura para subprocesos y, por lo tanto, se puede usar durante el renderizado. Sin embargo, generalmente se recomienda almacenar el manejador de geometría dentro de la representación de geometría de la aplicación y buscar el manejador de geometría directamente desde esa representación.

Si necesita una versión segura para subprocesos de esta función, use [rtcGetGeometryThreadSafe].

ESTADO DE SALIDA

En caso de fallo, se devuelve NULL y se establece un código de error que se puede consultar con rtcGetDeviceError.

VER TAMBIÉN

[rtcAttachGeometry], [rtcAttachGeometryByID], [rtcGetGeometryThreadSafe]
