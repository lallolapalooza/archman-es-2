NOMBRE

rtl_adsb - un decodificador ADS-B simple

DESCRIPCIÓN

Utiliza un receptor DVB-T reutilizado como radio definida por software para recibir y decodificar datos ADS-B. Escrito por Kyle Keen e incorporado en el proyecto rtl-sdr de osmocom.

Vigilancia dependiente automática por radiodifusión, ADS-B, consiste en datos de posición y otros datos de estado transmitidos por aeronaves en apoyo del control de tráfico aéreo para mejorar la seguridad del vuelo.

Existe mucho software disponible para el RTL2832. La mayoría de los paquetes de nivel de usuario dependen de la biblioteca librtlsdr, que viene como parte del código fuente de rtl-sdr. Este código fuente contiene tanto la biblioteca en sí como una serie de herramientas de línea de comandos como rtl_test, rtl_sdr, rtl_tcp y rtl_fm. Estas herramientas de línea de comandos utilizan la biblioteca para verificar la existencia de dispositivos RTL2832 y para realizar funciones básicas de transferencia de datos hacia y desde el dispositivo.

Dado que la mayoría de los dispositivos RTL2832 se conectan mediante USB, la biblioteca librtlsdr depende de la biblioteca libusb para comunicarse con el dispositivo.

USO

Con una antena adecuada para recibir la señal de 1090 MHz conectada al dispositivo compatible con rtl-sdr, este programa emitirá los datos decodificados de esa señal.

SINOPSIS

rtl_adsb [-R] [-g ganancia] [-p ppm] [archivo de salida]

OPCIONES

-d índice_dispositivo (por defecto: 0)
-V salida detallada (por defecto: desactivada)
-S mostrar tramas cortas (por defecto: desactivada)
-Q calidad (0: sin comprobaciones de integridad, 0.5: medio bit, 1: un bit (por defecto), 2: dos bits)
-e errores_permitidos (por defecto: 5)
-g ganancia_sintonizador (por defecto: automática)
-p error_ppm (por defecto: 0)
tarchivo

(un '-' envía muestras a stdout)
(omitir el nombre del archivo también usa stdout)

EJEMPLOS

Transmisión con netcat:

rtl_adsb | netcat -lp 8080


mientras true; hacer rtl_adsb | nc -lp 8080; hecho

Transmisión con socat:

rtl_adsb | socat -u - TCP4:sdrsharp.com:47806
