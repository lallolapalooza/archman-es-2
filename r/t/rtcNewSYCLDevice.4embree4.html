NOMBRE

rtcNewSYCLDevice - crea un nuevo dispositivo para usar con SYCL

SINOPSIS

#include <embree4/rtcore.h>
RTCDevice rtcNewSYCLDevice(sycl::context context, const char* config);

DESCRIPCIÓN

Esta función crea un nuevo dispositivo para usar con SYCL para renderizado con GPU y devuelve un manejador a este dispositivo. El objeto dispositivo tiene un recuento de referencias con un recuento inicial de 1. El manejador se puede liberar usando la llamada a la API rtcReleaseDevice.

El contexto SYCL pasado (argumento context) se usa para asignar memoria de GPU, por lo tanto, solo los dispositivos contenidos dentro de este contexto se pueden usar para el renderizado. Por defecto, la memoria de GPU se asigna en el primer dispositivo GPU del contexto, pero este comportamiento se puede cambiar con la función [rtcSetDeviceSYCLDevice].

El objeto dispositivo actúa como una fábrica de clases para todos los demás tipos de objetos. Todos los objetos creados a partir del dispositivo (como escenas, geometrías, etc.) mantienen una referencia al dispositivo, por lo tanto, el dispositivo no se destruirá a menos que estos objetos se destruyan primero.

Los objetos solo son compatibles si pertenecen al mismo dispositivo, por ejemplo, no se permite crear una geometría en un dispositivo y adjuntarla a una escena creada con un dispositivo diferente.

Para obtener una descripción general de las configuraciones que se pueden pasar (argumento config), consulte la descripción de la función [rtcNewDevice].

ESTADO DE SALIDA

En caso de éxito, devuelve un manejador del dispositivo creado. En caso de fallo, devuelve NULL como dispositivo y establece un código de error por hilo que se puede consultar usando rtcGetDeviceError(NULL).

VER TAMBIÉN

[rtcRetainDevice], [rtcReleaseDevice], [rtcNewDevice]
