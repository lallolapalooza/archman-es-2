NOMBRE

rt-migrate-test - programa de migración de tareas en tiempo real

SINOPSIS

rt-migrate-test [-c|--check] [-D|--duration TIME] [-e|--equal] [-h|--help] [--json FILENAME] [-l|--loops LOOPS] [-m|--maxerr TIME] [-p|--prio PRIO] [-r|--run-time TIME] [-s|--sleep-time TIME] [NR_TASKS]

DESCRIPCIÓN

Prueba la programación multiproceso en tiempo real de tareas para asegurar que las tareas de mayor prioridad se ejecuten en todas las CPUs disponibles.

OPCIONES

Este programa sigue la sintaxis habitual de línea de comandos de GNU, con opciones largas que comienzan con dos guiones ('--').

En el resumen de opciones, un valor entre corchetes (), indica un valor por defecto

-c, --check
Detener si una tarea de menor prioridad es más rápida que una de mayor prioridad (desactivado)
-D, --duration=TIME
Especifica una duración para la ejecución de la prueba.
Añada 'm', 'h', o 'd' para especificar minutos, horas o días.
-e, --equal
Usa la misma prioridad para #CPU-1 tareas (requiere > 2 CPUs)
-h, --help
Muestra la ayuda
--json=FILENAME
Escribe los resultados finales en FILENAME, con formato JSON.
-l --loops=LOOPS
Número de iteraciones a ejecutar (50)
-m, --maxerr=TIME
Error máximo permitido (microsegundos)
-p, --prio=PRIO
Prioridad base con la que se inician las tareas RT (2)
-r, --run-time=TIME
Tiempo de ejecución (ms) para el bucle ocupado de los hilos (20)
-s, --sleep-time=TIME
Tiempo de espera (ms) entre intervalos (100)
[NR_TASKS]
número de tareas a ejecutar (número de cpus + 1)
