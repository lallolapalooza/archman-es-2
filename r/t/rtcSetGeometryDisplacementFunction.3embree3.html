rtcSetGeometryDisplacementFunction(3) Kernels de Ray Tracing de Embree 3 rtcSetGeometryDisplacementFunction(3)

NOMBRE

rtcSetGeometryDisplacementFunction - establece la función de desplazamiento
  para una geometría de subdivisión

SINOPSIS

#include <embree3/rtcore.h>
struct RTCDisplacementFunctionNArguments
{
  void* geometryUserPtr;
  RTCGeometry geometry;
  unsigned int primID;
  unsigned int timeStep;
  const float* u;
  const float* v;
  const float* Ng_x;
  const float* Ng_y;
  const float* Ng_z;
  float* P_x;
  float* P_y;
  float* P_z;
  unsigned int N;
};
typedef void (*RTCDisplacementFunctionN)(
   const struct RTCDisplacementFunctionNArguments* args
);
void rtcSetGeometryDisplacementFunction(
  RTCGeometry geometry,
  RTCDisplacementFunctionN displacement
);

DESCRIPCIÓN

La función rtcSetGeometryDisplacementFunction registra una función de llamada de retorno de desplazamiento (argumento de desplazamiento) para la geometría de subdivisión especificada (argumento de geometría).

Solo se puede registrar una función de llamada de retorno por geometría, y las invocaciones posteriores sobrescribirán la función de llamada de retorno previamente establecida. Pasar NULL como puntero de función deshabilita la función de llamada de retorno registrada.

La función de llamada de retorno registrada se invoca para desplazar puntos en la geometría de subdivisión durante la construcción de la estructura de aceleración espacial, durante la llamada rtcCommitScene.

La función de llamada de retorno de tipo RTCDisplacementFunctionN se invoca con un número de argumentos almacenados dentro de la estructura RTCDisplacementFunctionNArguments. El puntero de datos de usuario proporcionado de la geometría (miembro geometryUserPtr) se puede usar para apuntar a la representación de la aplicación de la malla de subdivisión. Se proporciona un número N de puntos a desplazar en una estructura de diseño de array. Para cada punto a desplazar, se proporcionan las coordenadas UV del parche local (arrays u y v), la normal de geometría normalizada (arrays Ng_x, Ng_y y Ng_z), y la posición (arrays P_x, P_y y P_z). La tarea de la función de desplazamiento es utilizar esta información y cambiar los datos de posición.

El manejador de geometría (miembro geometry) y el ID de primitiva (miembro primID) del parche a desplazar se proporcionan adicionalmente, así como el paso de tiempo timeStep, que puede ser importante si el desplazamiento depende del tiempo y se utiliza desenfoque de movimiento.

Todos los arrays pasados deben estar alineados a 64 bytes y correctamente acolchados para facilitar el procesamiento de vectores anchos dentro de la función de desplazamiento.

Consulte también el tutorial [Geometría de Desplazamiento] para ver un ejemplo de cómo usar las funciones de mapeo de desplazamiento.

ESTADO DE SALIDA

En caso de fallo, se establece un código de error que se puede consultar usando rtcGetDeviceError.

VER TAMBIÉN

[RTC_GEOMETRY_TYPE_SUBDIVISION]
