RTF2RTF(1) Manual de comandos generales RTF2RTF(1)

NOMBRE

rtf2rtf - programas para posprocesar el RTF crudo generado por los archivos de mapeo

SINOPSIS

rtf2rtf [opciones] ..

DESCRIPCIÓN

Esta página del manual documenta brevemente los comandos de rtf2rtf. Esta página del manual fue escrita para la distribución Debian GNU/Linux porque el programa original no tiene una página del manual para rtf2rtf.

rtf2rtf es un programa para posprocesar el RTF crudo generado por los archivos de mapeo.

Es utilizado por otros programas en sgml-tools (v1), y normalmente el usuario normal no necesita usar este programa directamente.

Lo siguiente está citado del README en el árbol de fuentes.

No estoy orgulloso de este código. Es un parche añadido a otro parche, anidado dentro de otro o dos parches. Funciona más o menos bien para mis propósitos (generar archivos .RTF de WinHelp para mis documentos), pero definitivamente podría usar un rediseño/reescritura. Comenzó como una simple perturbación del filtro html2html, pero se volvió feo muy rápidamente...

Culpo descaradamente al formato RTF por la mayor parte de la hacendera aquí — RTF no es un _lenguaje_ como LaTeX o ROFF — es solo un formato de archivo. Por lo tanto, no podemos confiar en RTF para hacer incluso cosas simples como "insertar un salto de párrafo aquí solo si el token anterior tampoco fue un salto de párrafo". Dado que el frontend SGML no tiene capacidades de procesamiento condicional, múltiples líneas en blanco en SGML se traducen a múltiples saltos de párrafo en RTF. Es por eso que usamos un filtro "lex" (rtf2rtf) para posprocesar el RTF crudo generado por los archivos de mapeo.

De nuevo: ofrezco esto a la comunidad Linuxdoc con la esperanza de que sea útil para otros y que alguien más pueda ayudar a completar las partes faltantes. ¿Qué? ¿Partes faltantes? Sí, recuerde que digo que funciona "más o menos bien para mis propósitos". Los archivos de reemplazo (general, mapeo) comenzaron como los archivos de reemplazo de latex. Gran parte de ellos todavía *son* los archivos de reemplazo de latex. Solo convertí aquellas partes que son realmente utilizadas por mis documentos. Sus documentos pueden requerir que más archivos se traduzcan a RTF.

Dado que estoy usando estos mapeos para documentación real, planeo mantener este backend, así que por favor envíenme cualquier mejora — coordinaré con Greg para asegurarme de que se incluyan en la próxima versión oficial.

(Fin de Citas)
