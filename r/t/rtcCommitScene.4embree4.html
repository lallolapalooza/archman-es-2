rtcCommitScene(3) Embree Ray Tracing Kernels 4 rtcCommitScene(3)

NOMBRE

rtcCommitScene - confirma los cambios de la escena

SINOPSIS

#include <embree4/rtcore.h>
void rtcCommitScene(RTCScene scene);

DESCRIPCIÓN

La función rtcCommitScene confirma todos los cambios para la escena especificada (argumento scene). Esto activa internamente la construcción de una estructura de aceleración espacial para la escena utilizando todos los hilos trabajadores disponibles. Las consultas de rayos solo se pueden realizar después de confirmar todos los cambios de la escena.

Si la aplicación utiliza TBB 2019 Update 9 o posterior para la paralelización de renderizado, rtcCommitScene admite la construcción de escenas perezosa durante el renderizado. Por lo tanto, rtcCommitScene se puede llamar desde varios hilos trabajadores de TBB de forma concurrente para la misma escena. La función rtcCommitScene aislará internamente la construcción de la escena utilizando un grupo de tareas tbb::isolated_task_group. El enfoque alternativo de usar rtcJoinCommitScene, que utiliza un tbb:task_arena internamente, no se recomienda debido a su alta sobrecarga en tiempo de ejecución.

Si las geometrías de la escena se modifican o se adjuntan o desadjuntan, se debe invocar la llamada a rtcCommitScene antes de realizar cualquier consulta de rayos adicional para la escena; de lo contrario, el efecto de la consulta de rayos no está definido. La modificación de una geometría, la confirmación de la escena y el trazado de rayos siempre deben ocurrir secuencialmente, y nunca al mismo tiempo. Cualquier llamada a la API que establezca una propiedad de la escena o de las geometrías contenidas en la escena cuenta como modificación de la escena, por ejemplo, incluyendo la configuración de funciones de filtro de intersección.

El tipo de estructura de aceleración que se construye puede ser influenciado utilizando indicadores de escena (ver rtcSetSceneFlags), y la calidad se puede especificar usando la función rtcSetSceneBuildQuality.

Embree ignora silenciosamente las primitivas durante la construcción de la estructura de aceleración espacial que causarían problemas numéricos, por ejemplo, primitivas que contienen NaNs, INFs o valores mayores que 1.844E18f (ya que no se pueden realizar cálculos razonables con tales valores sin causar desbordamientos).

En caso de que el dispositivo RTCDevice asociado con la escena sea un dispositivo SYCL, rtcCommitScene creará internamente una cola SYCL temporal para emitir transferencias de memoria de la memoria del host a la memoria del dispositivo. En este caso, la llamada a rtcCommitScene será bloqueante y regresará solo después de que las transferencias de memoria se completen y los kernels SYCL puedan recorrer la escena de forma segura en el dispositivo. La función rtcCommitSceneWithQueue se puede usar para confirmar todos los cambios para la escena especificada de forma asíncrona. Los identificadores de objetos de recorrido (tipo RTCTraversable) que se hayan adquirido antes de una llamada a rtcCommitScene se invalidarán. Use rtcGetSceneTraversable para obtener un identificador válido de la escena después de cada confirmación de escena.

ESTADO DE SALIDA

En caso de fallo, se establece un código de error que se puede consultar con rtcGetDeviceError.

VER TAMBIÉN

[rtcCommitSceneWithQueue], [rtcJoinCommitScene]
