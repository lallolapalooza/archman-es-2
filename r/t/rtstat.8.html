LNSTAT(8) System Manager's Manual LNSTAT(8)

NOMBRE

lnstat - estadísticas de red unificadas de Linux

SINOPSIS

lnstat [opciones]

DESCRIPCIÓN

Esta página del manual documenta brevemente el comando lnstat.

lnstat es un reemplazo generalizado y más completo que el antiguo programa rtstat. Se usa comúnmente para imprimir periódicamente una selección de valores estadísticos exportados por el kernel. Además de las estadísticas de la caché de enrutamiento, soporta cualquier tipo de estadísticas que el kernel de Linux exporte a través de un archivo en /proc/net/stat/.

Cada archivo en /proc/net/stat/ contiene una línea de encabezado que lista los nombres de las columnas. Estos nombres son utilizados por lnstat como claves para seleccionar qué estadísticas imprimir. Por cada CPU presente en el sistema, sigue una línea que lista los valores reales para cada columna del archivo. lnstat suma estos valores (que de hecho son contadores) antes de imprimirlos. Después de cada intervalo, solo se imprime la diferencia con respecto al último valor.

Los archivos y columnas pueden seleccionarse usando los parámetros -f y -k. Por defecto, se imprimen todas las columnas de todos los archivos.

OPCIONES

lnstat soporta las siguientes opciones.

-h, --help
Muestra un resumen de las opciones.
-V, --version
Muestra la versión del programa.
-c, --count <conteo>
Imprime <conteo> número de intervalos.
-d, --dump
Vuelca la lista de archivos/claves disponibles.
-f, --file <archivo>
Archivo de estadísticas a usar, puede especificarse múltiples veces. Por defecto, se escanean todos los archivos en /proc/net/stat.
-i, --interval <intervalo>
Establece el intervalo a 'intervalo' segundos.
-j, --json
Muestra los resultados en formato JSON
-k, --keys k,k,k,...
Muestra solo las claves especificadas. Cada clave k tiene el formato [archivo:]clave. Si se proporciona <archivo>, la búsqueda de la clave dada se limita a ese archivo. De lo contrario, se utiliza el primer archivo que contiene la clave buscada.
-s, --subject [0-2]
Especifica la visualización del tema/encabezado. '0' significa sin encabezado, '1' imprime un encabezado solo al inicio del programa y '2' imprime un encabezado cada 20 líneas.
-w, --width n,n,n,...
Ancho para cada campo.

EJEMPLOS DE USO

# lnstat -d
Obtener una lista de los archivos de estadísticas compatibles.
# lnstat -k arp_cache:entries,rt_cache:in_hit,arp_cache:destroys
Seleccionar los archivos y claves especificados.
# lnstat -i 10
Usar un intervalo de 10 segundos.
# lnstat -f ip_conntrack
Usar solo el archivo especificado para estadísticas.
# lnstat -s 0
No imprimir ningún encabezado.
# lnstat -s 20
Imprimir un encabezado al inicio y cada 20 líneas.
# lnstat -c -1 -i 1 -f rt_cache -k entries,in_hit,in_slow_tot
Mostrar estadísticas para las claves entries, in_hit y in_slow_tot del campo rt_cache cada segundo.

ARCHIVOS

/proc/net/stat/arp_cache, /proc/net/stat/ndisc_cache
Estadísticas sobre la caché de vecinos y ARP. arp_cache es para IPv4, ndisc_cache es lo mismo para IPv6.

entries Número de entradas en la tabla de vecinos.

allocs Cuántas entradas de vecinos se han asignado.

destroys Cuántas entradas de vecinos se han eliminado.

hash_grows Cuántas veces ha crecido la tabla de vecinos (hash).

lookups Cuántas búsquedas se han realizado.

hits Cuántas lookups han sido exitosas.

res_failed Cuántas búsquedas de vecinos han fallado.

rcv_probes_mcast Cuántas soliciitudes multicast de vecinos se han recibido. (Solo IPv6.)

rcv_probes_ucast Cuántas soliciitudes unicast de vecinos se han recibido. (Solo IPv6.)

periodic_gc_runs Cuántas ejecuciones de recolección de basura se han ejecutado.

forced_gc_runs Cuántas ejecuciones forzadas de recolección de basura se han ejecutado. Ocurre al agregar una entrada y la tabla está demasiado llena.

unresolved_discards Cuántas entradas de la tabla de vecinos se han descartado debido a un fallo en la búsqueda.

table_fulls Número de desbordamientos de tabla. Ocurre si la tabla está llena y la ejecución forzada de GC (ver forced_gc_runs) ha fallado.

/proc/net/stat/ip_conntrack, /proc/net/stat/nf_conntrack
Contadores relacionados con conntrack. ip_conntrack es para compatibilidad con versiones anteriores de userspace y muestra los mismos datos que nf_conntrack.

entries Número de entradas en la tabla conntrack.

searched Número de búsquedas en la tabla conntrack realizadas.

found Número de entradas searched que fueron exitosas.

new Número de entradas conntrack añadidas que no se esperaban antes.

invalid Número de paquetes vistos que no pueden ser rastreados.

ignore Número de paquetes vistos que ya están conectados a una entrada conntrack.

delete Número de entradas conntrack que han sido eliminadas.

delete_list Número de entradas conntrack que han sido puestas en la lista de "muriendo".

insert Número de entradas insertadas en la lista.

insert_failed Número de entradas para las cuales se intentó insertar en la lista pero falló (ocurre si la misma entrada ya está presente).

drop Número de paquetes descartados debido a fallos de conntrack. Ya sea que la asignación de una nueva entrada conntrack falló, o el ayudante de protocolo descartó el paquete.

early_drop Número de entradas conntrack descartadas para hacer espacio para nuevas, si se alcanzó el tamaño máximo de la tabla.

icmp_error Número de paquetes que no pudieron ser rastreados debido a una situación de error. Esto es un subconjunto de invalid.

expect_new Número de entradas conntrack añadidas después de que ya existía una expectativa para ellas.

expect_create Número de expectativas añadidas.

expect_delete Número de expectativas eliminadas.

search_restart Número de búsquedas en la tabla conntrack que tuvieron que reiniciarse debido a redimensionamientos de la tabla hash.

/proc/net/stat/rt_cache
Estadísticas de la caché de enrutamiento.

entries Número de entradas en la caché de enrutamiento.

in_hit Número de aciertos de caché de ruta para paquetes entrantes. Obsoleto desde la eliminación de la caché de ruta IP, por lo tanto siempre es cero.

in_slow_tot Número de entradas de caché de ruta añadidas para tráfico de entrada.

in_slow_mc Número de entradas de caché de ruta multicast añadidas para tráfico de entrada.

in_no_route Número de paquetes de entrada para los cuales no se encontró una entrada en la tabla de enrutamiento.

in_brd Número de paquetes de entrada coincidentes de difusión (broadcast).

in_martian_dst Número de paquetes de destino marciano de entrada.

in_martian_src Número de paquetes de origen marciano de entrada.

out_hit Número de aciertos de caché de ruta para paquetes salientes. Obsoleto desde la eliminación de la caché de ruta IP, por lo tanto siempre es cero.

out_slow_tot Número de entradas de caché de ruta añadidas para tráfico de salida.

out_slow_mc Número de entradas de caché de ruta multicast añadidas para tráfico de salida.

NAME

rtstat - print routing table statistics

SYNOPSIS

rtstat [ OPTIONS ]

DESCRIPTION

rtstat displays routing table statistics.

OPTIONS

-h, --help
Display help text and exit.
-V, --version
Display version information and exit.

These statistics are part of the kernel's routing cache handling and might not be meaningful without kernel support. Since the introduction of the new generic route lookup code, many of these statistics are no longer relevant or are always zero.

The following statistics are available:

gc_median
Median garbage collector runs. Deprecated since IP route cache removal, therefore always zero.

Total garbage collector runs. Deprecated since IP route cache removal, therefore always zero.

Number of garbage collector runs eliminated. Deprecated since IP route cache removal, therefore always zero.

gc_memtr_avg

gc_memtr_limit
Garbage collector memtr limit. Deprecated since IP route cache removal, therefore always zero.
gc_memtr_gc_freq
Garbage collector memtr GC frequency. Deprecated since IP route cache removal, therefore always zero.
gc_memtr_gc_min
Garbage collector memtr GC minimum. Deprecated since IP route cache removal, therefore always zero.
