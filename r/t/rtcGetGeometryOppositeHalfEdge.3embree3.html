NOMBRE

rtcGetGeometryOppositeHalfEdge - devuelve la semiarista opuesta

SINAPSIS

#include <embree3/rtcore.h>
unsigned int rtcGetGeometryOppositeHalfEdge(
  RTCGeometry geometry,
  unsigned int topologyID,
  unsigned int edgeID
);

DESCRIPCIÓN

La función rtcGetGeometryOppositeHalfEdge devuelve el ID de la semiarista opuesta de la semiarista especificada (argumento edgeID) en la topología especificada (argumento topologyID). Por ejemplo, en el siguiente ejemplo, la semiarista opuesta de e6 es e16.

Una semiarista opuesta no existe si la semiarista especificada no tiene una cara vecina o tiene más de 2 caras vecinas. En estos casos, la función simplemente devuelve el mismo ID de semiarista edgeID.

Esta función solo se puede usar para geometrías de subdivisión. La función depende de la topología, ya que las topologías de una geometría de subdivisión tienen diferentes índices asignados.

ESTADO DE SALIDA

En caso de error, se establece un código de error que se puede consultar mediante rtcGetDeviceError.
