rtcNewBuffer(3) Embree Ray Tracing Kernels 3 rtcNewBuffer(3)

NOMBRE

rtcNewBuffer - crea un nuevo buffer de datos

SINOPSIS

#include <embree3/rtcore.h>
RTCBuffer rtcNewBuffer(
  RTCDevice device,
  size_t byteSize
);

DESCRIPCIÓN

La función rtcNewBuffer crea un nuevo objeto de buffer de datos del tamaño especificado en bytes (argumento byteSize) que está vinculado al dispositivo especificado (argumento device). El objeto buffer tiene un contador de referencias con un recuento inicial de 1. El objeto buffer devuelto puede liberarse utilizando la llamada a la API rtcReleaseBuffer. Los bytes especificados se asignan en el momento de la construcción del buffer y se desasignan cuando se destruye el buffer.

ESTADO DE SALIDA

En caso de fallo, se devuelve NULL y se establece un código de error que se puede consultar con rtcGetDeviceError.

VER TAMBIÉN

[rtcRetainBuffer], [rtcReleaseBuffer]
