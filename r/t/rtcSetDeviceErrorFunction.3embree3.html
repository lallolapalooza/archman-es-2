rtcSetDeviceErrorFunction(3) Embree Ray Tracing Kernels 3 rtcSetDeviceErrorFunction(3)

NOMBRE

rtcSetDeviceErrorFunction - establece una función de devolución de llamada de error para el dispositivo

SINOPSIS

#include <embree3/rtcore.h>
typedef void (*RTCErrorFunction)(
  void* userPtr,
  RTCError code,
  const char* str
);
void rtcSetDeviceErrorFunction(
  RTCDevice device,
  RTCErrorFunction error,
  void* userPtr
);

DESCRIPCIÓN

Utilizando la llamada rtcSetDeviceErrorFunction, es posible establecer una función de devolución de llamada (argumento error) con una carga útil (argumento userPtr), que se llama siempre que ocurre un error en el dispositivo especificado (argumento device).

Solo se puede registrar una función de devolución de llamada por dispositivo, y las invocaciones posteriores sobrescriben la función de devolución de llamada previamente establecida. Pasar NULL como puntero de función deshabilita la función de devolución de llamada registrada.

Cuando se invoca la función de devolución de llamada registrada, se le pasa la carga útil definida por el usuario (argumento userPtr tal como se especificó en el momento del registro), el código de error (argumento code) del error ocurrido, así como una cadena (argumento str) que describe más detalladamente el error.

El código de error también se establece si se registra una función de devolución de llamada de error.

ESTADO DE SALIDA

En caso de fallo, se establece un código de error que se puede consultar usando rtcGetDeviceError.

VER TAMBIÉN

[rtcGetDeviceError]
