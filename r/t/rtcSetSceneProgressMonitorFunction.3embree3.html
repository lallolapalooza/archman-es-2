rtcSetSceneProgressMonitorFunction(3) Kernels de Trazado de Rayos Embree 3 rtcSetSceneProgressMonitorFunction(3)

NOMBRE

rtcSetSceneProgressMonitorFunction - registra una función de callback
  para rastrear el progreso de la compilación

SINOPSIS

#include <embree3/rtcore.h>
typedef bool (*RTCProgressMonitorFunction)(
  void* ptr,
  double n
);
void rtcSetSceneProgressMonitorFunction(
  RTCScene scene,
  RTCProgressMonitorFunction progress,
  void* userPtr
);

DESCRIPCIÓN

Embree soporta un mecanismo de callback de monitor de progreso que puede ser usado para reportar el progreso de las operaciones de compilación de jerarquías y para cancelar operaciones de compilación.

rtcSetSceneProgressMonitorFunction registra una función de callback de monitor de progreso (argumento progress) con un payload (argumento userPtr) para la escena especificada (argumento scene).

Solo una función de callback puede ser registrada por escena, y las invocaciones posteriores sobrescribirán la función de callback previamente establecida. Pasar NULL como puntero de función deshabilita la función de callback registrada.

Una vez registrada, Embree invocará la función de callback múltiples veces durante las operaciones de compilación de jerarquías de la escena, pasando el payload tal como se estableció en el momento del registro (argumento userPtr), y un double en el rango [0, 1] que estima el progreso de la operación (argumento n). La función de callback podría ser llamada desde múltiples hilos concurrentemente.

Al retornar true desde la función de callback, Embree continuará la operación de compilación normalmente. Al retornar false, Embree cancelará la operación de compilación con el código de error RTC_ERROR_CANCELLED. Emitir múltiples solicitudes de cancelación para la misma operación de compilación está permitido.

ESTADO DE SALIDA

En caso de fallo, se establece un código de error que puede ser consultado usando rtcGetDeviceError.

VER TAMBIÉN

[rtcNewScene]
