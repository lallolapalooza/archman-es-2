rtcSetGeometryUserData(3) Kernels de trazado de rayos Embree 3 rtcSetGeometryUserData(3)

NOMBRE

rtcSetGeometryUserData - establece el puntero de datos definido por el usuario de la
  geometría

SINOPSIS

#include <embree3/rtcore.h>
void rtcSetGeometryUserData(RTCGeometry geometry, void* userPtr);

DESCRIPCIÓN

La función rtcSetGeometryUserData establece el puntero de datos definido por el usuario (argumento userPtr) para una geometría (argumento geometry). Este puntero de datos de usuario está destinado a apuntar a la representación de la geometría de la aplicación y se pasa a varias funciones de devolución de llamada. La aplicación puede usar este puntero dentro de las funciones de devolución de llamada para acceder a su representación de geometría.

La función rtcGetGeometryUserData se puede utilizar para consultar un puntero de datos de usuario ya establecido de una geometría.

ESTADO DE SALIDA

En caso de error, se establece un código de error que se puede consultar con rtcGetDeviceError.

VER TAMBIÉN

[rtcGetGeometryUserData]
