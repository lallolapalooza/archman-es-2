rtcIsSYCLDeviceSupported(3) Kernels de trazado de rayos Embree 4 rtcIsSYCLDeviceSupported(3)

NOMBRE

rtcIsSYCLDeviceSupported - comprueba si algún dispositivo SYCL es compatible con Embree

SINOPSIS

#include <embree4/rtcore.h>
bool rtcIsSYCLDeviceSupported(const sycl::device sycl_device);

DESCRIPCIÓN

Esta función se puede utilizar para comprobar si algún dispositivo SYCL (argumento sycl_device) es compatible con Embree.

ESTADO DE SALIDA

La función devuelve true si el dispositivo SYCL es compatible con Embree y false en caso contrario. En caso de error, se establece un código de error que se puede consultar usando rtcGetDeviceError.

VER TAMBIÉN

[rtcSYCLDeviceSelector]
