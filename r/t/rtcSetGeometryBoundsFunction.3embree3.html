rtcSetGeometryBoundsFunction(3) Embree Ray Tracing Kernels 3 rtcSetGeometryBoundsFunction(3)

NOMBRE

rtcSetGeometryBoundsFunction - establece una función de devolución de llamada para consultar el
  recuadro delimitador de primitivas definidas por el usuario

SINOPSIS

#include <embree3/rtcore.h>
struct RTCBoundsFunctionArguments
{
  void* geometryUserPtr;
  unsigned int primID;
  unsigned int timeStep;
  struct RTCBounds* bounds_o;
};
typedef void (*RTCBoundsFunction)(
  const struct RTCBoundsFunctionArguments* args
);
void rtcSetGeometryBoundsFunction(
  RTCGeometry geometry,
  RTCBoundsFunction bounds,
  void* userPtr
);

DESCRIPCIÓN

La función rtcSetGeometryBoundsFunction registra una función de devolución de llamada de recuadro delimitador (argumento bounds) con datos (argumento userPtr) para la geometría de usuario especificada (argumento geometry).

Solo se puede registrar una función de devolución de llamada por geometría, y las invocaciones posteriores sobrescriben la función de devolución de llamada previamente establecida. Pasar NULL como puntero de función deshabilita la función de devolución de llamada registrada.

La función de devolución de llamada de recuadro delimitador registrada se invoca para calcular recuadros delimitadores alineados con los ejes de las primitivas de la geometría definida por el usuario durante la construcción de la estructura de aceleración espacial. La devolución de llamada de recuadro delimitador del tipo RTCBoundsFunction se invoca con un puntero a una estructura de tipo RTCBoundsFunctionArguments que contiene varios argumentos, como: los datos del usuario de la geometría (miembro geometryUserPtr), el ID de la primitiva para calcular los límites (miembro primID), el paso de tiempo en el que calcular los límites (miembro timeStep) y una ubicación de memoria para escribir el límite calculado (miembro bounds_o).

En un escenario de uso típico, se almacenaría un puntero a la representación interna del objeto de geometría del usuario utilizando rtcSetGeometryUserData. La función de devolución de llamada puede entonces leer ese puntero del campo geometryUserPtr y calcular el recuadro delimitador adecuado para la primitiva y el tiempo solicitados, y almacenar ese recuadro delimitador en la estructura de destino (miembro bounds_o).

ESTADO DE SALIDA

En caso de error, se establece un código de error que se puede consultar utilizando rtcGetDeviceError.

VER TAMBIÉN
