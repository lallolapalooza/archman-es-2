NOMBRE

rtcSetGeometryMaxRadiusScale - asigna un factor de escala de radio máximo de curva para la característica de ancho mínimo

SINOPSIS

#include <embree3/rtcore.h>
void rtcSetGeometryMaxRadiusScale(RTCGeometry geometry, float maxRadiusScale);

DESCRIPCIÓN

La función rtcSetMaxGeometryScale especifica un factor de escala máximo para los radios de curva utilizados por la característica de ancho mínimo.

La característica de ancho mínimo puede aumentar el radio de las curvas y los puntos, para reducir el aliasing y mejorar los tiempos de renderizado. La característica está deshabilitada por defecto y debe ser habilitada usando la opción cmake EMBREE_MIN_WIDTH.

Para usar la característica, uno debe especificar un factor de escala de radio de curva máximo usando la función [rtcSetGeometryMaxRadiusScale]. Este factor debe ser un número pequeño (p. ej., 4) ya que los límites del BVH construido se incrementan para acotar la curva en el peor caso de radios máximos.

También se debe establecer el minWidthDistanceFactor en el RTCIntersectContext al trazar un rayo. Este factor controla el tamaño del radio objetivo de una curva o punto a cierta distancia del origen del rayo.

Para cada punto de control p con radio r de una curva o primitiva de punto, los interseccionadores de primitiva primero calculan un radio objetivo r’ como:

r' = length(p-ray_org) * minWidthDistanceFactor

Típicamente, la aplicación establece el minWidthDistanceFactor de manera que el radio objetivo proyecte el ancho de medio píxel (por lo tanto, el diámetro de la primitiva tiene el tamaño de un píxel).

Luego, el radio objetivo r’ se limita contra el límite mínimo r y el límite máximo maxRadiusScale*r para obtener el radio final r’’:

r'' = max(r, min(r', maxRadiusScale*r))

Por lo tanto, las curvas o puntos cercanos a la cámara se renderizan con radios normales r, y las curvas o puntos lejanos a la cámara no se agrandan demasiado, ya que sería muy costoso de renderizar.

Cuando la función rtcSetGeometryMaxRadiusScale no se invoca para una geometría de curva o punto (o si el factor de escala máximo se establece en 1.0), la geometría de curva o punto se renderiza normalmente, con radios no modificados por la característica de ancho mínimo.

ESTADO DE SALIDA

En caso de error, se establece un código de error que se puede consultar usando rtcGetDeviceError.

VER TAMBIÉN
