NOMBRE

rtcGetGeometryNextHalfEdge - devuelve la siguiente semiarista

SINOPSIS

#include <embree4/rtcore.h>
unsigned int rtcGetGeometryNextHalfEdge(
  RTCGeometry geometry,
  unsigned int edgeID
);

DESCRIPCIÓN

La función `rtcGetGeometryNextHalfEdge` devuelve el ID de la siguiente semiarista de la semiarista especificada (argumento `edgeID`). Por ejemplo, en el siguiente ejemplo, la siguiente semiarista de e10 es e11.

Esta función solo se puede utilizar para geometrías de subdivisión. Como todas las topologías de una geometría de subdivisión comparten el mismo búfer de caras, la función no depende del ID de la topología.

ESTADO DE SALIDA

En caso de error, se establece un código de error que se puede consultar con `rtcGetDeviceError`.
