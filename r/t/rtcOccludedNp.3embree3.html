rtcOccludedNp(3) Núcleos de trazado de rayos Embree 3 rtcOccludedNp(3)

NOMBRE

rtcOccludedNp - encuentra cualquier colisión para un flujo de rayos SOA de tamaño N

SINOPSIS

#include <embree3/rtcore.h>
void rtcOccludedNp(
  RTCScene scene,
  struct RTCIntersectContext* context,
  struct RTCRayNp* ray,
  unsigned int N
);

DESCRIPCIÓN

La función rtcOccludedNp comprueba si hay alguna colisión para un flujo de rayos SOA (argumento ray) de tamaño N (básicamente un paquete de rayos grande) con la escena (argumento scene). El argumento ray apunta a una estructura de punteros, con un puntero para cada componente del rayo. Cada uno de estos punteros apunta a una matriz con los datos del componente del rayo para cada rayo. De esta manera, los componentes individuales del flujo de rayos SOA no necesitan almacenarse secuencialmente en memoria, lo que permite tener paquetes de rayos de gran tamaño variable en diseño SOA. Véase la Sección [rtcOccluded1] para una descripción de cómo configurar y trazar rayos de oclusión.

Un rayo en un flujo de rayos se considera inactivo si su valor tnear es mayor que su valor tfar.

El tamaño del flujo N puede ser un entero positivo arbitrario, incluido 0. Cada matriz de componentes de rayo debe estar alineada a 16 bytes.

ESTADO DE SALIDA

Por razones de rendimiento, esta función no realiza ninguna comprobación de errores, por lo que no establecerá ninguna bandera de error en caso de fallo.

VER TAMBIÉN

[rtcIntersectNp]
