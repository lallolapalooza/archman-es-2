RTMPDUMP(1) Manual de comandos generales RTMPDUMP(1)

NOMBRE

rtmpdump - cliente de medios de streaming RTMP

SINOPSIS

rtmpdump -r url [-n hostname] [-c port] [-l protocol] [-S host:port] [-a app] [-t tcUrl] [-p pageUrl] [-s swfUrl] [-f flashVer] [-u auth] [-C conndata] [-y playpath] [-Y] [-v] [-d subscription] [-e] [-k skip] [-A start] [-B stop] [-b buffer] [-m timeout] [-T key] [-j JSON] [-w swfHash] [-x swfSize] [-W swfUrl] [-X swfAge] [-o output] [-#] [-q] [-V] [-z]
rtmpdump -h

DESCRIPCIÓN

rtmpdump es una herramienta para descargar contenido multimedia transmitido a través de RTMP.

rtmpdump establece una conexión con el servidor RTMP especificado y reproduce los medios especificados por la url dada. La url debe tener el formato

  rtmp[t][e]://hostname[:port][/app[/playpath]]

Se admiten rtmp plano, así como sesiones tunelizadas y cifradas.

OPCIONES

Parámetros de red

Estas opciones definen cómo conectarse al servidor multimedia.

--rtmp -r url
URL del servidor y contenido multimedia.
--host -n hostname
Anula el nombre de host en la URL RTMP.
--port -c port
Anula el número de puerto en la URL RTMP.
--protocol -l number
Anula el protocolo en la URL RTMP. 
  0 = rtmp
  1 = rtmpt
  2 = rtmpe
  3 = rtmpte
  4 = rtmps
  5 = rtmpts
--socks -S host:port
Utiliza el proxy SOCKS4 especificado.

Parámetros de conexión

Estas opciones definen el contenido del paquete RTMP Connect request. Si no se proporcionan los valores correctos, el servidor multimedia rechazará el intento de conexión.

--app -a app
Nombre de la aplicación a la que conectarse en el servidor RTMP. Anula la app en la URL RTMP. A veces, el analizador de URL de rtmpdump no puede determinar el nombre de la aplicación automáticamente, por lo que debe proporcionarse explícitamente con esta opción.
--tcUrl -t url
URL del stream de destino. Por defecto es rtmp[e]://host[:port]/app/playpath.
--pageUrl -p url
URL de la página web en la que se incrustó el medio. Por defecto no se enviará ningún valor.
--swfUrl -s url
URL del reproductor SWF para el medio. Por defecto no se enviará ningún valor.
--flashVer -f version
Versión del plugin Flash utilizada para ejecutar el reproductor SWF. Por defecto es "LNX 10,0,32,18".
--auth -u string
Una cadena de autenticación que se agregará al mensaje Connect. Usar esta opción agregará un booleano TRUE y luego la cadena especificada. Esta opción solo es utilizada por algunos servidores particulares y está obsoleta. Se debe usar la opción más general --conn en su lugar.
--conn -C type:data
Agrega datos AMF arbitrarios al mensaje Connect. El tipo debe ser B para Booleano, N para número, S para cadena, O para objeto o Z para nulo. Para Booleanos, los datos deben ser 0 o 1 para FALSO o VERDADERO, respectivamente. Igualmente, para los Objetos, los datos deben ser 0 o 1 para finalizar o iniciar un objeto, respectivamente. Los elementos de datos en subobjetos pueden tener nombre, anteponiendo el tipo con 'N' y especificando el nombre antes del valor, p. ej., NB:myFlag:1. Esta opción se puede usar varias veces para construir secuencias AMF arbitrarias. Por ejemplo: 
  -C B:1 -C S:authMe -C O:1 -C NN:code:1.23 -C NS:flag:ok -C O:0

Parámetros de sesión

Estas opciones entran en vigor después de que el Connect request haya sucedido.

--playpath -y path
Anula el playpath analizado de la URL RTMP. A veces, el analizador de URL de rtmpdump no puede determinar el playpath correcto automáticamente, por lo que debe proporcionarse explícitamente con esta opción.
--playlist -Y
Emite un comando set_playlist antes de enviar el comando play. La lista de reproducción solo contendrá el playpath actual.
--live -v
Especifica que el medio es una transmisión en vivo. No es posible reanudar ni buscar en transmisiones en vivo.
--subscribe -d stream
Nombre de la transmisión en vivo a la que suscribirse. Por defecto es playpath.
--realtime -R
Descarga aproximadamente en tiempo real, sin intentar acelerar mediante comandos Pause/Unpause ("el hack BUFX"). Útil para servidores que retroceden en el tiempo con el comando Unpause. La reanudación y la búsqueda en transmisiones en tiempo real todavía son posibles.
--resume -e
Reanuda una descarga RTMP incompleta.
--skip -k num
Omite num keyframes al buscar el último keyframe desde el cual reanudar. Esto puede ser útil si un intento normal de reanudar falla. El valor predeterminado es 0.
--start -A num
Comienza en el segundo num de la transmisión. No es válido para transmisiones en vivo.
--stop -B num
Detiene en el segundo num de la transmisión.
--buffer -b num
Establece el tiempo de búfer en num milisegundos. El valor predeterminado es 36000000.
--timeout -m num
Cierra la sesión después de num segundos sin recibir datos del servidor. El valor predeterminado es 120.

Parámetros de seguridad

Estas opciones manejan solicitudes de autenticación adicionales del servidor.

--token -T key
Clave para la respuesta SecureToken, utilizada si el servidor requiere autenticación SecureToken.
--jtv -j JSON
Token JSON utilizado por los servidores legacy de Justin.tv. Invoca NetStream.Authenticate.UsherToken
--swfhash -w hexstring
Hash SHA256 del archivo SWF descomprimido. Esta opción puede ser necesaria si el servidor utiliza Verificación de SWF, pero consulta la opción --swfVfy a continuación. El hash es de 32 bytes y debe proporcionarse en hexadecimal. La opción --swfsize siempre debe usarse con esta opción.
--swfsize -x num
Tamaño del archivo SWF descomprimido. Esta opción puede ser necesaria si el servidor utiliza Verificación de SWF, pero consulta la opción --swfVfy a continuación. La opción --swfhash siempre debe usarse con esta opción.
--swfVfy -W

OPTIONS

--swfUrl url
URL del reproductor SWF para este medio. Esta opción reemplaza las tres opciones --swfUrl, --swfhash y --swfsize. Cuando se utiliza esta opción, el reproductor SWF se obtiene de la URL especificada y el hash y el tamaño se calculan automáticamente. La información también se almacena en caché en un archivo .swfinfo en el directorio de inicio del usuario, para que no sea necesario recuperarla y recalcularla cada vez que se ejecuta rtmpdump. El archivo .swfinfo registra la URL, la hora en que se recuperó, la marca de tiempo de modificación del archivo SWF, su tamaño y su hash. Por defecto, la información en caché se utilizará durante 30 días antes de volver a comprobarla.
--swfAge days
Especifica cuántos días se utilizará la información SWF en caché antes de volver a comprobarla. Utilice 0 para comprobar siempre la URL SWF. Tenga en cuenta que si la comprobación muestra que el archivo SWF tiene la misma marca de tiempo de modificación que antes, no se volverá a descargar.

Misceláneo

--flv output
Especifica el nombre del archivo de salida. Si el nombre es - o se omite, la transmisión se escribe en la salida estándar (stdout).
--hashes
Muestra el progreso de la transmisión con una marca de hash por cada 1% de progreso, en lugar de un contador de bytes.
--quiet -q
Suprime toda la salida del comando.
--verbose -V
Salida detallada del comando.
--debug -z
Salida de nivel de depuración. Extremadamente detallada, incluyendo volcados hexadecimales de todos los datos de los paquetes.
--help -h
Imprime un resumen de las opciones del comando.

ESTADO DE SALIDA

0
Ejecución exitosa del programa.
1
Error irrecuperable.
2
Transferencia incompleta, la reanudación puede obtener más.

ENTORNO

HOME
El valor de $HOME se utiliza como ubicación para el archivo .swfinfo.

ARCHIVOS

$HOME/.swfinfo
Caché de información de verificación SWF
