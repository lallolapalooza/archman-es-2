NOMBRE

rtcGetGeometryFirstHalfEdge - devuelve la primera semiarista de una cara

SINOPSIS

#include <embree3/rtcore.h>
unsigned int rtcGetGeometryFirstHalfEdge(
  RTCGeometry geometry,
  unsigned int faceID
);

DESCRIPCIÓN

La función rtcGetGeometryFirstHalfEdge devuelve el ID de la primera semiarista perteneciente a la cara especificada (argumento faceID). Por ejemplo, en el siguiente ejemplo, la primera semiarista de la cara f1 es e4.

Esta función solo se puede utilizar para geometrías de subdivisión. Como todas las topologías de una geometría de subdivisión comparten el mismo búfer de caras, la función no depende del ID de la topología.

Aquí, f0 a f7 son 8 caras cuadriláteras con 4 vértices cada una. Las aristas e0 a e23 de estas caras se muestran con su orientación. Para cada cara, el ID de las aristas corresponde a las posiciones que ocupa la cara en el array de índices de la geometría. Por ejemplo, como los índices de la cara f1 comienzan en la ubicación 4 del array de índices, la primera arista es la arista e4, la siguiente arista e5, etc.

ESTADO DE SALIDA

En caso de fallo, se establece un código de error que se puede consultar usando rtcGetDeviceError.
