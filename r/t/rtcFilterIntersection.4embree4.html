NOMBRE

rtcFilterIntersection - invoca la función de filtro de intersección

SINOPSIS

#include <embree4/rtcore.h>
void rtcFilterIntersection(
  const struct RTCIntersectFunctionNArguments* args,
  const struct RTCFilterFunctionNArguments* filterArgs
);

DESCRIPCIÓN

La función rtcFilterIntersection se puede llamar dentro de una función de callback de RTCIntersectFunctionN para invocar el filtro de intersección registrado para la geometría y almacenado dentro del contexto. Para ello, se debe crear una estructura RTCFilterFunctionNArguments (ver rtcSetGeometryIntersectFilterFunction) que básicamente consiste en una máscara válida, un paquete de impacto a filtrar, el paquete de rayos correspondiente y el tamaño del paquete. Después de la invocación de rtcFilterIntersection, solo los rayos que sigan siendo válidos (máscara válida establecida a -1) deberían actualizar un impacto.

ESTADO DE SALIDA

Por razones de rendimiento, esta función no realiza ninguna comprobación de errores, por lo tanto, no establecerá ninguna bandera de error en caso de fallo.

VER TAMBIÉN

[rtcFilterOcclusion], [rtcSetGeometryIntersectFunction]
