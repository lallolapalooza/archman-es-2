NOMBRE

rtcAttachGeometryByID - adjunta una geometría a la escena
  usando un ID de geometría especificado

SINOPSIS

#include <embree3/rtcore.h>
void rtcAttachGeometryByID(
  RTCScene scene,
  RTCGeometry geometry,
  unsigned int geomID
);

DESCRIPCIÓN

La función rtcAttachGeometryByID adjunta una geometría (argumento geometry) a una escena (argumento scene) y asigna un ID de geometría proporcionado por el usuario (argumento geomID) a esa geometría. Todas las geometrías adjuntas a una escena se definen para ser incluidas dentro de la escena. Una geometría puede adjuntarse a múltiples escenas. El ID de geometría definido por el usuario se usa para identificar la geometría cuando es alcanzada por un rayo durante las consultas de rayos. Usando esta función, es posible compartir los mismos IDs para referirse a geometrías dentro de la aplicación y Embree.

Esta función es segura para hilos, por lo que múltiples hilos pueden adjuntar geometrías a una escena en paralelo.

El ID de geometría proporcionado por el usuario debe no estar utilizado en la escena, de lo contrario, la creación de la geometría fallará. Además, los IDs de geometría proporcionados por el usuario deben ser compactos, ya que Embree crea internamente un vector cuyo tamaño es igual al ID de geometría más grande utilizado. Por lo tanto, crear IDs de geometría muy grandes para escenas pequeñas causaría un consumo de memoria y una sobrecarga de rendimiento.

ESTADO DE SALIDA

En caso de fallo, se establece un código de error que puede ser consultado usando rtcGetDeviceError.

VER TAMBIÉN

[rtcAttachGeometry]
