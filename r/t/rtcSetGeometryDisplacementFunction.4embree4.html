rtcSetGeometryDisplacementFunction(3) Kernels de trazado de rayos Embree 4 rtcSetGeometryDisplacementFunction(3)

NOMBRE

rtcSetGeometryDisplacementFunction - establece la función de desplazamiento
  para una geometría de subdivisión

SINOPSIS

#include <embree4/rtcore.h>
struct RTCDisplacementFunctionNArguments
{
  void* geometryUserPtr;
  RTCGeometry geometry;
  unsigned int primID;
  unsigned int timeStep;
  const float* u;
  const float* v;
  const float* Ng_x;
  const float* Ng_y;
  const float* Ng_z;
  float* P_x;
  float* P_y;
  float* P_z;
  unsigned int N;
};
typedef void (*RTCDisplacementFunctionN)(
   const struct RTCDisplacementFunctionNArguments* args
);
void rtcSetGeometryDisplacementFunction(
  RTCGeometry geometry,
  RTCDisplacementFunctionN displacement
);

DESCRIPCIÓN

La función rtcSetGeometryDisplacementFunction registra una función de devolución de llamada de desplazamiento (argumento displacement) para la geometría de subdivisión especificada (argumento geometry).

Solo se puede registrar una función de devolución de llamada por geometría, y las invocaciones posteriores sobrescriben la función de devolución de llamada previamente establecida. Pasar NULL como puntero de función deshabilita la función de devolución de llamada registrada.

La función de devolución de llamada de desplazamiento registrada se invoca para desplazar puntos en la geometría de subdivisión durante la construcción de la estructura de aceleración espacial, durante la llamada rtcCommitScene.

La función de devolución de llamada de tipo RTCDisplacementFunctionN se invoca con varios argumentos almacenados dentro de la estructura RTCDisplacementFunctionNArguments. El puntero de datos de usuario proporcionado de la geometría (miembro geometryUserPtr) se puede utilizar para apuntar a la representación de la aplicación de la malla de subdivisión. Un número N de puntos a desplazar se especifica en una estructura de diseño de arreglos. Para cada punto a desplazar, se proporcionan las coordenadas UV locales del parche (arreglos u y v), la normal de geometría normalizada (arreglos Ng_x, Ng_y y Ng_z), y la posición (arreglos P_x, P_y y P_z). La tarea de la función de desplazamiento es utilizar esta información y cambiar los datos de posición.

El manejador de geometría (miembro geometry) y el ID de primitiva (miembro primID) del parche a desplazar se proporcionan adicionalmente, así como el paso de tiempo timeStep, que puede ser importante si el desplazamiento depende del tiempo y se utiliza desenfoque de movimiento.

Todos los arreglos pasados deben estar alineados a 64 bytes y rellenados adecuadamente para que el procesamiento de vectores amplios dentro de la función de desplazamiento sea fácilmente posible.

También consulte el tutorial [Geometría de desplazamiento] para ver un ejemplo de cómo usar las funciones de mapeo de desplazamiento.

ESTADO DE SALIDA

En caso de error, se establece un código de error que se puede consultar usando rtcGetDeviceError.

VER TAMBIÉN

[RTC_GEOMETRY_TYPE_SUBDIVISION]
