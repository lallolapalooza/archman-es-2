rtcGetDeviceProperty(3) Kernels de Ray Tracing Embree 4 rtcGetDeviceProperty(3)

NOMBRE

rtcGetDeviceProperty - consulta propiedades del dispositivo

SINOPSIS

#include <embree4/rtcore.h>
ssize_t rtcGetDeviceProperty(
  RTCDevice device,
  enum RTCDeviceProperty prop
);

DESCRIPCIÓN

La función rtcGetDeviceProperty se puede utilizar para consultar propiedades (argumento prop) de un objeto de dispositivo (argumento device). La propiedad devuelta es un entero de tipo ssize_t.

Las propiedades posibles a consultar son:

•
RTC_DEVICE_PROPERTY_VERSION: Consulta el número de versión combinado (MAJOR.MINOR.PATCH) con dos dígitos decimales por componente. Por ejemplo, para Embree 2.8.3 se devuelve el entero 208003.
•
RTC_DEVICE_PROPERTY_VERSION_MAJOR: Consulta el número de versión principal de Embree.
•
RTC_DEVICE_PROPERTY_VERSION_MINOR: Consulta el número de versión menor de Embree.
•
RTC_DEVICE_PROPERTY_VERSION_PATCH: Consulta el número de versión de parche de Embree.
•
RTC_DEVICE_PROPERTY_NATIVE_RAY4_SUPPORTED: Consulta si las funciones rtcIntersect4 y rtcOccluded4 preservan el tamaño del paquete y el orden de los rayos al invocar funciones de devolución de llamada. Esto solo ocurre si Embree se compila con EMBREE_RAY_PACKETS y SSE2 (o SSE4.2) habilitados, y si la máquina en la que se está ejecutando soporta SSE2 (o SSE4.2).
•
RTC_DEVICE_PROPERTY_NATIVE_RAY8_SUPPORTED: Consulta si las funciones rtcIntersect8 y rtcOccluded8 preservan el tamaño del paquete y el orden de los rayos al invocar funciones de devolución de llamada. Esto solo ocurre si Embree se compila con EMBREE_RAY_PACKETS y AVX (o AVX2) habilitados, y si la máquina en la que se está ejecutando soporta AVX (o AVX2).
•
RTC_DEVICE_PROPERTY_NATIVE_RAY16_SUPPORTED: Consulta si las funciones rtcIntersect16 y rtcOccluded16 preservan el tamaño del paquete y el orden de los rayos al invocar funciones de devolución de llamada. Esto solo ocurre si Embree se compila con EMBREE_RAY_PACKETS y AVX512 habilitados, y si la máquina en la que se está ejecutando soporta AVX512.
•
RTC_DEVICE_PROPERTY_RAY_MASK_SUPPORTED: Consulta si las máscaras de rayos están soportadas. Esto solo ocurre si Embree se compila con EMBREE_RAY_MASK habilitado.
•
RTC_DEVICE_PROPERTY_BACKFACE_CULLING_ENABLED: Consulta si el descarte de caras posteriores está habilitado. Esto solo ocurre si Embree se compila con EMBREE_BACKFACE_CULLING habilitado.
•
RTC_DEVICE_PROPERTY_BACKFACE_CULLING_CURVES_ENABLED: Consulta si el descarte de caras posteriores para curvas está habilitado. Esto solo ocurre si Embree se compila con EMBREE_BACKFACE_CULLING_CURVES habilitado.
•
RTC_DEVICE_PROPERTY_BACKFACE_CULLING_SPHERES_ENABLED: Consulta si el descarte de caras posteriores para esferas está habilitado. Esto solo ocurre si Embree se compila con EMBREE_BACKFACE_CULLING_SPHERES habilitado.
•
RTC_DEVICE_PROPERTY_COMPACT_POLYS_ENABLED: Consulta si los polígonos compactos están habilitados. Esto solo ocurre si Embree se compila con EMBREE_COMPACT_POLYS habilitado.
•
RTC_DEVICE_PROPERTY_FILTER_FUNCTION_SUPPORTED: Consulta si las funciones de filtro están soportadas, lo cual ocurre si Embree se compila con EMBREE_FILTER_FUNCTION habilitado.
•
RTC_DEVICE_PROPERTY_IGNORE_INVALID_RAYS_ENABLED: Consulta si los rayos inválidos son ignorados, lo cual ocurre si Embree se compila con EMBREE_IGNORE_INVALID_RAYS habilitado.
•
RTC_DEVICE_PROPERTY_TRIANGLE_GEOMETRY_SUPPORTED: Consulta si los triángulos están soportados, lo cual ocurre si Embree se compila con EMBREE_GEOMETRY_TRIANGLE habilitado.
•
RTC_DEVICE_PROPERTY_QUAD_GEOMETRY_SUPPORTED: Consulta si los cuadriláteros están soportados, lo cual ocurre si Embree se compila con EMBREE_GEOMETRY_QUAD habilitado.
•
RTC_DEVICE_PROPERTY_SUBDIVISION_GEOMETRY_SUPPORTED: Consulta si las mallas de subdivisión están soportadas, lo cual ocurre si Embree se compila con EMBREE_GEOMETRY_SUBDIVISION habilitado.
•
RTC_DEVICE_PROPERTY_CURVE_GEOMETRY_SUPPORTED: Consulta si las curvas están soportadas, lo cual ocurre si Embree se compila con EMBREE_GEOMETRY_CURVE habilitado.
•
RTC_DEVICE_PROPERTY_POINT_GEOMETRY_SUPPORTED: Consulta si los puntos están soportados, lo cual ocurre si Embree se compila con EMBREE_GEOMETRY_POINT habilitado.
•
RTC_DEVICE_PROPERTY_USER_GEOMETRY_SUPPORTED: Consulta si las geometrías de usuario están soportadas, lo cual ocurre si Embree se compila con EMBREE_GEOMETRY_USER habilitado.
•
RTC_DEVICE_PROPERTY_TASKING_SYSTEM: Consulta el sistema de tareas con el que está compilado Embree. Los valores de retorno posibles son:
0.
sistema de tareas interno
1.
Intel Threading Building Blocks (TBB)
2.
Parallel Patterns Library (PPL)
•
RTC_DEVICE_PROPERTY_JOIN_COMMIT_SUPPORTED: Consulta si rtcJoinCommitScene está soportado. Esto no ocurre cuando Embree se compila con PPL o versiones anteriores de TBB.
•
RTC_DEVICE_PROPERTY_PARALLEL_COMMIT_SUPPORTED: Consulta si rtcCommitScene puede ser invocado desde múltiples hilos de trabajo TBB concurrentemente. Esta característica solo se soporta a partir de TBB 2019 Update 9.

ESTADO DE SALIDA

En caso de éxito, devuelve el valor de la propiedad consultada. Para propiedades que devuelven un valor booleano, el valor de retorno 0 denota falso y 1 denota verdadero.

En caso de error, se devuelve cero y se establece un código de error que se puede consultar usando rtcGetDeviceError.
