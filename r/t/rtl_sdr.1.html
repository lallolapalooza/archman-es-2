NOMBRE

rtl-sdr - un grabador I/Q para receptores DVB-T basados en RTL2832

DESCRIPCIÓN

Utiliza un receptor DVB-T reutilizado como radio definida por software para recibir señales en forma de datos I/Q. Escrito para e incorporado en el proyecto osmocom rtl-sdr.

Los datos de Fase en Cuadratura y Fase en Continuo pueden representar fielmente toda la información en una banda de frecuencias centrada en la frecuencia portadora de la señal.

Existe mucho software disponible para el RTL2832. La mayoría de los paquetes de nivel de usuario dependen de la biblioteca librtlsdr, que viene como parte de la base de código de rtl-sdr. Esta base de código contiene tanto la biblioteca en sí como una serie de herramientas de línea de comandos como rtl_test, rtl_sdr, rtl_tcp y rtl_fm. Estas herramientas de línea de comandos utilizan la biblioteca para probar la existencia de dispositivos RTL2832 y para realizar funciones básicas de transferencia de datos hacia y desde el dispositivo.

Dado que la mayoría de los dispositivos RTL2832 se conectan mediante USB, la biblioteca librtlsdr depende de la biblioteca libusb para comunicarse con el dispositivo.

USO

Este programa captura información de una banda de frecuencias y produce los datos en un formato útil para otros programas de radio definida por software.

SINOPSIS

rtl_sdr [-f freq] [OPCIONES] [archivo de salida]

OPCIONES

-f frecuencia_a_sintonizar [Hz]
-s tasa_de_muestreo (predeterminado: 2048000 Hz)
-d índice_de_dispositivo (predeterminado: 0)
-g ganancia (predeterminado: 0 para automático)
-p error_ppm (predeterminado: 0)
-b tamaño_bloque_salida (predeterminado: 16 * 16384)
-n número de muestras a leer (predeterminado: 0, infinito)
-S forzar salida síncrona (predeterminado: asíncrono)
t_nombre_archivo

(un '-' envía muestras a stdout)

EJEMPLOS

Ejemplo: Para sintonizar a 392.0 MHz y establecer la tasa de muestreo a 1.8 MS/s, use:

./rtl_sdr /tmp/capture.bin -s 1.8e6 -f 392e6

para grabar muestras en un archivo o para reenviar los datos a una tubería FIFO (pipe).

Si no se puede abrir el dispositivo, asegúrese de tener los derechos apropiados para acceder al dispositivo (instale las reglas udev del repositorio, o ejecútelo como root).
