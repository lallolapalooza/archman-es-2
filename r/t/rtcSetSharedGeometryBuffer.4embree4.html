rtcSetSharedGeometryBuffer(3) Embree Ray Tracing Kernels 4 rtcSetSharedGeometryBuffer(3)

NOMBRE

rtcSetSharedGeometryBuffer - asigna una vista de un búfer de datos compartido
  a una geometría

SINOPSIS

#include <embree4/rtcore.h>
void rtcSetSharedGeometryBuffer(
  RTCGeometry geometry,
  enum RTCBufferType type,
  unsigned int slot,
  enum RTCFormat format,
  const void* ptr,
  size_t byteOffset,
  size_t byteStride,
  size_t itemCount
);

DESCRIPCIÓN

La función rtcSetSharedGeometryBuffer vincula una vista de un búfer de datos compartido y gestionado por el usuario (argumento ptr) a un tipo y ranura de búfer de geometría (argumentos type y slot) de la geometría especificada (argumento geometry).

Se puede especificar la dirección de inicio del primer elemento del búfer en bytes (argumento byteOffset), el paso en bytes entre elementos individuales del búfer (argumento byteStride), el formato de los elementos del búfer (argumento format) y el número de elementos a vincular (itemCount).

La dirección de inicio (argumento byteOffset) y el paso (argumento byteStride) deben estar alineados a 4 bytes; de lo contrario, la función rtcSetSharedGeometryBuffer fallará.

Los datos del búfer deben permanecer válidos mientras el búfer pueda ser utilizado, y el usuario es responsable de liberar los datos del búfer cuando ya no se necesiten.

Si se utiliza un dispositivo SYCL Embree, ptr debe estar asignado utilizando memoria compartida SYCL USM para ser accesible en el dispositivo. Alternativamente, se puede usar la función rtcSetSharedGeometryBufferHostDevice para pasar un par de búferes gestionados explícitamente de host/dispositivo.

Compartir búferes puede reducir significativamente la memoria requerida por la aplicación, por lo que recomendamos utilizar esta función. Al habilitar la bandera de escena RTC_SCENE_FLAG_COMPACT, las estructuras de índices espaciales indexan en el búfer de vértices, lo que resulta en un ahorro de memoria aún mayor.

ESTADO DE SALIDA

En caso de error, se establece un código de error que se puede consultar con rtcGetDeviceError.

VER TAMBIÉN
