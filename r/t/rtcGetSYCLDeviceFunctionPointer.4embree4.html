NOMBRE

rtcGetSYCLDeviceFunctionPointer - obtiene un puntero a función del lado del dispositivo para alguna función SYCL

SINAPSIS

#include <embree4/rtcore.h>
template<auto F>
inline decltype(F) rtcGetSYCLDeviceFunctionPointer(sycl::queue& queue);

DESCRIPCIÓN

Esta función devuelve un puntero a función del lado del dispositivo para alguna función F. Esta función F debe definirse usando el atributo RTC_SYCL_INDIRECTLY_CALLABLE, por ejemplo:

RTC_SYCL_INDIRECTLY_CALLABLE void filter(
  const RTCFilterFunctionNArguments* args) { ... }
RTCFilterFunctionN fptr = rtcGetSYCLDeviceFunctionPointer<filter>(queue);

Dichos punteros a funciones del lado del dispositivo de algunas callbacks de filtro pueden ser asignados a una geometría usando las funciones de API rtcSetGeometryIntersectFilterFunction y rtcSetGeometryOccludedFilterFunction.

Además, los punteros a funciones del lado del dispositivo para callbacks de geometría de usuario pueden ser asignados a geometrías usando las llamadas a API rtcSetGeometryIntersectFunction y rtcSetGeometryOccludedFunction.

Estas versiones de geometría de las funciones de callback están deshabilitadas en SYCL por defecto, y recomendamos no usarlas por razones de rendimiento.

ESTADO DE SALIDA

En caso de error, se establece un código de error que puede ser consultado usando rtcGetDeviceError.

VER TAMBIÉN

[rtcSetGeometryIntersectFunction], [rtcSetGeometryOccludedFunction], [rtcSetGeometryIntersectFilterFunction], [rtcSetGeometryOccludedFilterFunction]
