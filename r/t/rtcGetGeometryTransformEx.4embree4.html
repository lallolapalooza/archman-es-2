NOMBRE

rtcGetGeometryTransformEx - devuelve la transformación de instancia interpolada
para una instancia de un array de instancias para el tiempo especificado.

SINOPSIS

#include <embree4/rtcore.h>
void rtcGetGeometryTransformEx(
  RTCGeometry geometry,
  unsigned int instPrimID,
  float time,
  enum RTCFormat format,
  void* xfm
);

DESCRIPCIÓN

La función rtcGetGeometryTransformEx devuelve la transformación interpolada de local a mundo (parámetro xfm) de la instancia instPrimID de un array de instancias (parámetro geometry) para un tiempo particular (parámetro time en el rango [0,1]) en el formato especificado (parámetro format). La función también se puede usar cuando la geometría se refiere a una instancia regular, pero en ese caso instPrimID debe ser 0.

Los formatos posibles para la matriz devuelta son:

•
RTC_FORMAT_FLOAT3X4_ROW_MAJOR: La matriz flotante de 3x4 está dispuesta en forma de fila principal.
•
RTC_FORMAT_FLOAT3X4_COLUMN_MAJOR: La matriz flotante de 3x4 está dispuesta en forma de columna principal.
•
RTC_FORMAT_FLOAT4X4_COLUMN_MAJOR: La matriz flotante de 3x4 está dispuesta en forma de columna principal como una matriz homogénea de 4x4 con la última fila igual a (0, 0, 0, 1).

ESTADO DE SALIDA

En caso de fallo, se establece un código de error que puede ser consultado mediante rtcGetDeviceError.

VER TAMBIÉN

[RTC_GEOMETRY_TYPE_INSTANCE_ARRAY]
