rtcGetGeometryUserData(3) Núcleos de Trazado de Rayos de Embree 4 rtcGetGeometryUserData(3)

NOMBRE

rtcGetGeometryUserData - devuelve el puntero de datos de usuario
  de la geometría

SINOPSIS

#include <embree4/rtcore.h>
void* rtcGetGeometryUserData(RTCGeometry geometry);

DESCRIPCIÓN

La función rtcGetGeometryUserData consulta el puntero de datos de usuario establecido previamente con rtcSetGeometryUserData. Cuando aún no se ha llamado a rtcSetGeometryUserData, se devuelve NULL.

Se supone que esta función se utiliza durante el renderizado, pero solo está soportada en la CPU y no dentro de los kernels SYCL en la GPU. Dentro de un kernel SYCL, se debe utilizar la función rtcGetGeometryUserDataFromScene.

ESTADO DE SALIDA

En caso de error, se establece un código de error que se puede consultar mediante rtcGetDeviceError.

VER TAMBIÉN

[rtcSetGeometryUserData], [rtcGetGeometryUserDataFromScene]
