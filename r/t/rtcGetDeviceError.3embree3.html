rtcGetDeviceError(3) Kernels de Trazado de Rayos Embree 3 rtcGetDeviceError(3)

NOMBRE

rtcGetDeviceError - devuelve el código de error del dispositivo

SINOPSIS

#include <embree3/rtcore.h>
RTCError rtcGetDeviceError(RTCDevice device);

DESCRIPCIÓN

Cada hilo tiene su propio código de error por dispositivo. Si ocurre un error al llamar a una función de API, este código de error se establece al error ocurrido si no almacena un error previo. La función rtcGetDeviceError lee y devuelve el error almacenado actualmente y borra el código de error. Esto asegura que el código de error devuelto sea siempre el primer error ocurrido desde la última invocación de rtcGetDeviceError.

Los códigos de error posibles devueltos por rtcGetDeviceError son:

•
RTC_ERROR_NONE: No ocurrió ningún error.
•
RTC_ERROR_UNKNOWN: Ha ocurrido un error desconocido.
•
RTC_ERROR_INVALID_ARGUMENT: Se especificó un argumento inválido.
•
RTC_ERROR_INVALID_OPERATION: La operación no está permitida para el objeto especificado.
•
RTC_ERROR_OUT_OF_MEMORY: No queda suficiente memoria para completar la operación.
•
RTC_ERROR_UNSUPPORTED_CPU: La CPU no es compatible, ya que no admite el ISA más bajo para el que está compilado Embree.
•
RTC_ERROR_CANCELLED: La operación fue cancelada por una función de devolución de llamada de monitor de memoria o de monitor de progreso.

Cuando falla la construcción del dispositivo, rtcNewDevice devuelve NULL como dispositivo. Para detectar el código de error de una construcción de dispositivo fallida, pase NULL como dispositivo a la función rtcGetDeviceError. Para todas las demás invocaciones de rtcGetDeviceError, se debe especificar un puntero de dispositivo válido.

ESTADO DE SALIDA

Devuelve el código de error para el dispositivo.

VER TAMBIÉN
