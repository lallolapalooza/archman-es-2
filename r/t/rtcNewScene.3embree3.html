NOMBRE

rtcNewScene - crea una nueva escena

SINOPSIS

#include <embree3/rtcore.h>
RTCScene rtcNewScene(RTCDevice device);

DESCRIPCIÓN

Esta función crea una nueva escena vinculada al dispositivo especificado (argumento device) y devuelve un identificador para esta escena. El objeto de escena se cuenta por referencia con un recuento de referencias inicial de 1. El identificador de escena se puede liberar usando la llamada a la API rtcReleaseScene.

ESTADO DE SALIDA

En caso de éxito, se devuelve un identificador de escena. En caso de fallo, se devuelve NULL y se establece un código de error que se puede consultar con rtcGetDeviceError.

VER TAMBIÉN

[rtcRetainScene], [rtcReleaseScene]
