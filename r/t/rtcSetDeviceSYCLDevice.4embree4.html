NOMBRE

rtcSetDeviceSYCLDevice - establece el dispositivo SYCL a utilizar para las asignaciones de memoria

SINOPSIS

#include <embree4/rtcore.h>
void rtcSetDeviceSYCLDevice(RTCDevice device, const sycl::device sycl_device);

DESCRIPCIÓN

Esta función establece el dispositivo SYCL (argumento sycl_device) que se utilizará para asignar memoria de la GPU cuando se utilice el dispositivo Embree especificado (argumento device). Este dispositivo SYCL debe ser uno de los dispositivos SYCL contenidos dentro del contexto SYCL utilizado para crear el dispositivo Embree.

ESTADO DE SALIDA

En caso de error, se establece un código de error que se puede consultar usando rtcGetDeviceError.

VER TAMBIÉN

[rtcNewSYCLDevice]
