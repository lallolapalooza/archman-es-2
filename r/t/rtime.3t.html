RTIME(3t) Manual de funciones de biblioteca RTIME(3t)

NOMBRE

rtime — obtener la hora remota

SINOPSIS

#include <sys/types.h>
#include <sys/time.h>
#include <netinet/in.h>

int
rtime(struct sockaddr_in *addrp, struct timeval *timep, struct timeval *timeout);

DESCRIPCIÓN

La función rtime() consulta el Servidor de Hora de Internet en la dirección apuntada por addrp y devuelve la hora remota en la estructura timeval apuntada por timep. Normalmente, se utiliza el protocolo UDP al consultar el Servidor de Hora. El argumento timeout especifica cuánto tiempo debe esperar la rutina antes de darse por vencida mientras espera una respuesta. Si se especifica timeout como NULL, sin embargo, la rutina utilizará TCP y se bloqueará hasta que se reciba una respuesta del servidor de hora.

VALORES DE RETORNO

La función rtime() devuelve el valor 0 si tiene éxito; de lo contrario, se devuelve el valor -1 y la variable global errno se establece para indicar el error.

DISPONIBILIDAD

La función rtime() forma parte de libtirpc.
