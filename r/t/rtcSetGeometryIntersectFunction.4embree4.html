NOMBRE

rtcSetGeometryIntersectFunction - establece la función de callback para
  intersecar una geometría de usuario

SINOPSIS

#include <embree4/rtcore.h>
struct RTCIntersectFunctionNArguments
{
  int* valid;
  void* geometryUserPtr;
  unsigned int primID;
  struct RTCRayQueryContext* context;
  struct RTCRayHitN* rayhit;
  unsigned int N;
  unsigned int geomID;
};
typedef void (*RTCIntersectFunctionN)(
  const struct RTCIntersectFunctionNArguments* args
);
void rtcSetGeometryIntersectFunction(
  RTCGeometry geometry,
  RTCIntersectFunctionN intersect
);

DESCRIPCIÓN

La función rtcSetGeometryIntersectFunction registra una función de callback de intersección rayo/primitiva (argumento intersect) para la geometría de usuario especificada (argumento geometry).

Solo se puede registrar una función de callback por geometría y las invocaciones posteriores sobrescriben la función de callback previamente establecida. Pasar NULL como puntero de función deshabilita la función de callback registrada.

La función de callback registrada es invocada por consultas de rayos de tipo rtcIntersect para calcular la intersección de un paquete de rayos de tamaño variable con una primitiva definida por el usuario. La función de callback de tipo RTCIntersectFunctionN recibe varios argumentos a través de la estructura RTCIntersectFunctionNArguments. El valor N especifica el tamaño del paquete de rayos, valid apunta a un array de enteros que especifican si el rayo correspondiente es válido (-1) o inválido (0), el miembro geometryUserPtr apunta a los datos de usuario de la geometría establecidos previamente a través de rtcSetGeometryUserData, el miembro context apunta al contexto de consulta de rayos pasado a la consulta de rayos, el miembro rayhit apunta a un paquete de rayos y golpes de tamaño variable N, y los miembros geomID y primID identifican el ID de geometría y el ID de primitiva de la primitiva a intersecar.

El componente ray de la estructura rayhit contiene datos válidos, en particular, el valor tfar es la distancia de golpe más cercana encontrada actualmente. Todos los datos dentro del componente hit de la estructura rayhit no están definidos y no deben ser leídos por la función.

La tarea de la función de callback es intersecar cada rayo activo del paquete de rayos con la primitiva definida por el usuario especificada. Si la primitiva definida por el usuario es omitida por un rayo del paquete de rayos, la función debe retornar sin modificar el rayo o el golpe. Si se encontró una intersección de la primitiva definida por el usuario con el rayo en el rango válido (desde tnear hasta tfar), debe actualizar la distancia de golpe del rayo (miembro tfar) y el golpe (miembros u, v, Ng, instID, geomID, primID). En particular, la instancia actualmente interseccionada se almacena en el campo instID del contexto de consulta de rayos, que debe copiarse en profundidad en el miembro instID del golpe.

Como una primitiva puede tener múltiples intersecciones con un rayo, la función de filtro de intersección debe ser invocada por la función de intersección de geometría de usuario para cada intersección encontrada, si se desea filtrar las intersecciones. Esto se puede lograr a través de la llamada rtcInvokeIntersectFilterFromGeometry.

Dentro de la función de intersección de geometría de usuario, es seguro trazar nuevos rayos y crear nuevas escenas y geometrías.

ESTADO DE SALIDA

En caso de error, se establece un código de error que se puede consultar usando rtcGetDeviceError.

VER TAMBIÉN

[rtcSetGeometryOccludedFunction], [rtcSetGeometryUserData], [rtcInvokeIntersectFilterFromGeometry]
