sigsuspend(2) Manual de llamadas al sistema sigsuspend(2)

NOMBRE

sigsuspend, rt_sigsuspend - esperar una señal

LIBRERÍA

Biblioteca C estándar (libc, -lc)

SINOPSIS

#include <signal.h>
int sigsuspend(const sigset_t *mask);
Requisitos de Macro de Prueba de Funciones para glibc (ver feature_test_macros(7)):

sigsuspend():

    _POSIX_C_SOURCE

DESCRIPCIÓN

sigsuspend() reemplaza temporalmente la máscara de señales del hilo que llama con la máscara dada por mask y luego suspende el hilo hasta la entrega de una señal cuya acción sea invocar un manejador de señales o terminar un proceso.

Si la señal termina el proceso, entonces sigsuspend() no retorna. Si la señal es capturada, entonces sigsuspend() retorna después de que el manejador de señales retorne, y la máscara de señales se restaura al estado anterior a la llamada a sigsuspend().

No es posible bloquear SIGKILL o SIGSTOP; especificar estas señales en mask no tiene efecto en la máscara de señales del hilo.

VALOR DE RETORNO

sigsuspend() siempre retorna -1, con errno establecido para indicar el error (normalmente, EINTR).

ERRORES

EFAULT
mask apunta a memoria que no es una parte válida del espacio de direcciones del proceso.
EINTR
La llamada fue interrumpida por una señal; signal(7).

ESTÁNDARES

POSIX.1-2024.

HISTORIA

POSIX.1-2001.

Diferencias Librería C/Kernel

La llamada al sistema original de Linux se llamaba sigsuspend(). Sin embargo, con la adición de señales en tiempo real en Linux 2.2, el tipo sigset_t de tamaño fijo de 32 bits soportado por esa llamada al sistema ya no era adecuado. En consecuencia, se añadió una nueva llamada al sistema, rt_sigsuspend(), para soportar un tipo sigset_t ampliado. La nueva llamada al sistema toma un segundo argumento, size_t sigsetsize, que especifica el tamaño en bytes del conjunto de señales en mask. Este argumento debe tener actualmente el valor sizeof(sigset_t) (o el error EINVAL resulta). La función envoltorio sigsuspend() de glibc oculta estos detalles, llamando transparentemente a rt_sigsuspend() cuando el kernel la proporciona.

NOTAS

Normalmente, sigsuspend() se usa junto con sigprocmask(2) para evitar la entrega de una señal durante la ejecución de una sección de código crítica. El llamador primero bloquea las señales con sigprocmask(2). Cuando el código crítico ha completado, el llamador espera las señales llamando a sigsuspend() con la máscara de señales que fue devuelta por sigprocmask(2) (en el argumento oldset).

Ver sigsetops(3) para detalles sobre la manipulación de conjuntos de señales.
