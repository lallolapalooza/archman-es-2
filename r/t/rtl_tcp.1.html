NOMBRE

rtl_tcp - un servidor de espectro I/Q para receptores DVB-T basados en RTL2832

DESCRIPCIÓN

Utiliza un receptor DVB-T reutilizado como radio definida por software para recibir y enviar datos I/Q a través de la red TCP a otra aplicación de demodulación, decodificación o registro. Escrito para e incorporado al proyecto osmocom rtl-sdr.

Hay mucho software disponible para el RTL2832. La mayoría de los paquetes a nivel de usuario dependen de la biblioteca librtlsdr, que viene como parte de la base de código de rtl-sdr. Esta base de código contiene tanto la biblioteca en sí como una serie de herramientas de línea de comandos, como rtl_test, rtl_sdr, rtl_tcp y rtl_fm. Estas herramientas de línea de comandos utilizan la biblioteca para probar la existencia de dispositivos RTL2832 y realizar funciones básicas de transferencia de datos hacia y desde el dispositivo.

Debido a que la mayoría de los dispositivos RTL2832 están conectados mediante USB, la biblioteca librtlsdr depende de la biblioteca libusb para comunicarse con el dispositivo.

USO

Ejecuta este programa en una máquina con un dispositivo compatible con rtl-sdr conectado y proporcionará datos I/Q a otras aplicaciones a través de TCP/IP.

SINOPSIS

rtl_tcp [OPCIONES]

OPCIONES

-a dirección de escucha
-p puerto de escucha (por defecto: 1234)
-f frecuencia a sintonizar [Hz]
-g ganancia (por defecto: 0 para automático)
-s frecuencia de muestreo en Hz (por defecto: 2048000 Hz)
-b número de búferes (por defecto: 32, definido por la biblioteca)
-n número máximo de búferes de lista enlazada a mantener (por defecto: 500)
-d índice_dispositivo (por defecto: 0)
-P error_ppm (por defecto: 0)

Ejemplo:

rtl_tcp -a 10.0.0.2 [-p puerto de escucha (por defecto: 1234)]

Encontrados 1 dispositivos.
Sintonizador Elonics E4000 encontrado
Usando RTL2832U genérico (por ejemplo, hama nano)
Sintonizado a 100000000 Hz.
escuchando...

Utiliza el argumento de dispositivo 'rtl_tcp=10.0.0.2:1234' en la fuente OsmoSDR (gr-osmosdr) para recibir muestras en GRC y controlar los parámetros de rtl_tcp (frecuencia, ganancia, ...).

usa el argumento de dispositivo rtl_tcp=... en la fuente gr-osmosdr para recibir las muestras en GRC y controlar la configuración de rtl de forma remota.

Esta aplicación se ha compilado correctamente para dispositivos ARM y MIPS y proporciona datos IQ en una configuración ADS-B en red a una velocidad de 2.4MSps. La fuente gr-osmosdr se utiliza junto con una versión optimizada de gr-air-modes (ver Aplicaciones Conocidas a continuación). También está disponible como un paquete en OpenWRT.

Un caso de uso se describe ​https://sites.google.com/site/embrtlsdr/
