rtcGetDeviceProperty(3) Núcleos de trazado de rayos Embree 3 rtcGetDeviceProperty(3)

NOMBRE

rtcGetDeviceProperty - consulta propiedades del dispositivo

SINOPSIS

#include <embree3/rtcore.h>
ssize_t rtcGetDeviceProperty(
  RTCDevice device,
  enum RTCDeviceProperty prop
);

DESCRIPCIÓN

La función rtcGetDeviceProperty se puede usar para consultar propiedades (argumento prop) de un objeto de dispositivo (argumento device). La propiedad devuelta es un entero de tipo ssize_t.

Las propiedades posibles a consultar son:

•
RTC_DEVICE_PROPERTY_VERSION: Consulta el número de versión combinado (MAJOR.MINOR.PATCH) con dos dígitos decimales por componente. Por ejemplo, para Embree 2.8.3 se devuelve el entero 208003.
•
RTC_DEVICE_PROPERTY_VERSION_MAJOR: Consulta el número de versión principal de Embree.
•
RTC_DEVICE_PROPERTY_VERSION_MINOR: Consulta el número de versión menor de Embree.
•
RTC_DEVICE_PROPERTY_VERSION_PATCH: Consulta el número de versión de parche de Embree.
•
RTC_DEVICE_PROPERTY_NATIVE_RAY4_SUPPORTED: Consulta si las funciones rtcIntersect4 y rtcOccluded4 conservan el tamaño del paquete y el orden de los rayos al invocar funciones de devolución de llamada. Esto solo ocurre si Embree se compila con EMBREE_RAY_PACKETS y SSE2 (o SSE4.2) habilitados, y si la máquina en la que se ejecuta admite SSE2 (o SSE4.2).
•
RTC_DEVICE_PROPERTY_NATIVE_RAY8_SUPPORTED: Consulta si las funciones rtcIntersect8 y rtcOccluded8 conservan el tamaño del paquete y el orden de los rayos al invocar funciones de devolución de llamada. Esto solo ocurre si Embree se compila con EMBREE_RAY_PACKETS y AVX (o AVX2) habilitados, y si la máquina en la que se ejecuta admite AVX (o AVX2).
•
RTC_DEVICE_PROPERTY_NATIVE_RAY16_SUPPORTED: Consulta si las funciones rtcIntersect16 y rtcOccluded16 conservan el tamaño del paquete y el orden de los rayos al invocar funciones de devolución de llamada. Esto solo ocurre si Embree se compila con EMBREE_RAY_PACKETS y AVX512 habilitados, y si la máquina en la que se ejecuta admite AVX512.
•
RTC_DEVICE_PROPERTY_RAY_STREAM_SUPPORTED: Consulta si rtcIntersect1M, rtcIntersect1Mp, rtcIntersectNM, rtcIntersectNp, rtcOccluded1M, rtcOccluded1Mp, rtcOccludedNM y rtcOccludedNp son compatibles. Esto solo ocurre si Embree se compila con EMBREE_RAY_PACKETS habilitado.
•
RTC_DEVICE_PROPERTY_RAY_MASK_SUPPORTED: Consulta si las máscaras de rayos son compatibles. Esto solo ocurre si Embree se compila con EMBREE_RAY_MASK habilitado.
•
RTC_DEVICE_PROPERTY_BACKFACE_CULLING_ENABLED: Consulta si el descarte de caras posteriores está habilitado. Esto solo ocurre si Embree se compila con EMBREE_BACKFACE_CULLING habilitado.
•
RTC_DEVICE_PROPERTY_COMPACT_POLYS_ENABLED: Consulta si las polígonos compactos están habilitados. Esto solo ocurre si Embree se compila con EMBREE_COMPACT_POLYS habilitado.
•
RTC_DEVICE_PROPERTY_FILTER_FUNCTION_SUPPORTED: Consulta si las funciones de filtro son compatibles, lo que ocurre si Embree se compila con EMBREE_FILTER_FUNCTION habilitado.
•
RTC_DEVICE_PROPERTY_IGNORE_INVALID_RAYS_ENABLED: Consulta si los rayos inválidos se ignoran, lo que ocurre si Embree se compila con EMBREE_IGNORE_INVALID_RAYS habilitado.
•
RTC_DEVICE_PROPERTY_TRIANGLE_GEOMETRY_SUPPORTED: Consulta si los triángulos son compatibles, lo que ocurre si Embree se compila con EMBREE_GEOMETRY_TRIANGLE habilitado.
•
RTC_DEVICE_PROPERTY_QUAD_GEOMETRY_SUPPORTED: Consulta si los cuadriláteros son compatibles, lo que ocurre si Embree se compila con EMBREE_GEOMETRY_QUAD habilitado.
•
RTC_DEVICE_PROPERTY_SUBDIVISION_GEOMETRY_SUPPORTED: Consulta si las mallas de subdivisión son compatibles, lo que ocurre si Embree se compila con EMBREE_GEOMETRY_SUBDIVISION habilitado.
•
RTC_DEVICE_PROPERTY_CURVE_GEOMETRY_SUPPORTED: Consulta si las curvas son compatibles, lo que ocurre si Embree se compila con EMBREE_GEOMETRY_CURVE habilitado.
•
RTC_DEVICE_PROPERTY_POINT_GEOMETRY_SUPPORTED: Consulta si los puntos son compatibles, lo que ocurre si Embree se compila con EMBREE_GEOMETRY_POINT habilitado.
•
RTC_DEVICE_PROPERTY_USER_GEOMETRY_SUPPORTED: Consulta si las geometrías de usuario son compatibles, lo que ocurre si Embree se compila con EMBREE_GEOMETRY_USER habilitado.
•
RTC_DEVICE_PROPERTY_TASKING_SYSTEM: Consulta el sistema de tareas con el que se compila Embree. Los valores posibles de retorno son:
0.
sistema de tareas interno
1.
Intel Threading Building Blocks (TBB)
2.
Parallel Patterns Library (PPL)
•
RTC_DEVICE_PROPERTY_JOIN_COMMIT_SUPPORTED: Consulta si rtcJoinCommitScene es compatible. Esto no ocurre cuando Embree se compila con PPL o versiones anteriores de TBB.
•
RTC_DEVICE_PROPERTY_PARALLEL_COMMIT_SUPPORTED: Consulta si rtcCommitScene se puede invocar desde múltiples hilos de trabajo de TBB concurrentemente. Esta función solo es compatible a partir de TBB 2019 Update 9.

ESTADO DE SALIDA

En caso de éxito, devuelve el valor de la propiedad consultada. Para propiedades que devuelven un valor booleano, el valor de retorno 0 denota falso y 1 denota verdadero.

En caso de error, se devuelve cero y se establece un código de error que puede ser consultado usando rtcGetDeviceError.
