NOMBRE

rtcEnableGeometry - habilita la geometría

SINOPSIS

#include <embree4/rtcore.h>
void rtcEnableGeometry(RTCGeometry geometry);

DESCRIPCIÓN

La función rtcEnableGeometry habilita la geometría especificada (argumento geometry). Solo se renderizan las geometrías habilitadas. Cada geometría se habilita por defecto en el momento de su construcción.

Después de habilitar una geometría, la escena que contiene esa geometría debe ser confirmada usando rtcCommitScene para que el cambio tenga efecto.

ESTADO DE SALIDA

En caso de fallo, se establece un código de error que se puede consultar usando rtcGetDeviceError.

VER TAMBIÉN

[rtcNewGeometry], [rtcDisableGeometry], [rtcCommitScene]
