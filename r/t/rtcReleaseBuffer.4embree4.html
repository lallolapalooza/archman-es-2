NOMBRE

rtcReleaseBuffer - decrementa el contador de referencias del buffer

SINOPSIS

#include <embree4/rtcore.h>
void rtcReleaseBuffer(RTCBuffer buffer);

DESCRIPCIÓN

Los objetos buffer tienen un contador de referencias. La función rtcReleaseBuffer decrementa el contador de referencias del objeto buffer pasado (argumento buffer). Cuando el contador de referencias cae a 0, el buffer se destruye.

ESTADO DE SALIDA

En caso de error, se establece un código de error que se puede consultar usando rtcGetDeviceError.

VER TAMBIÉN

[rtcNewBuffer], [rtcRetainBuffer]
