rtcGetGeometryNextHalfEdge(3) Núcleos de trazado de rayos Embree 3 rtcGetGeometryNextHalfEdge(3)

NOMBRE

rtcGetGeometryNextHalfEdge - devuelve la semiarista siguiente

SINOPSIS

#include <embree3/rtcore.h>
unsigned int rtcGetGeometryNextHalfEdge(
  RTCGeometry geometry,
  unsigned int edgeID
);

DESCRIPCIÓN

La función rtcGetGeometryNextHalfEdge devuelve el ID de la siguiente semiarista de la semiarista especificada (argumento edgeID). Por ejemplo, en el siguiente ejemplo, la semiarista siguiente de e10 es e11.

Esta función solo se puede utilizar para geometrías de subdivisión. Como todas las topologías de una geometría de subdivisión comparten el mismo búfer de caras, la función no depende del ID de topología.

ESTADO DE SALIDA

En caso de error, se establece un código de error que se puede consultar utilizando rtcGetDeviceError.
