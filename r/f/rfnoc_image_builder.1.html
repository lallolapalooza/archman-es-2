UHD(1) Comandos de Usuario UHD(1)

NOMBRE

rfnoc_image_builder - Construye imágenes UHD usando bloques RFNoC.

USO

rfnoc_image_builder [-h] (-y CONFIG_YAML | -r CONFIG_GRC) [-C DIR_BASE] [-F DIR_FPGA] [-B DIR_CONSTRUCCION] [-O DIR_SALIDA_CONSTRUCCION] [-E DIR_IP_CONSTRUCCION] [-o SALIDA_CORE_IMAGEN] [-I DIR_INCLUIR] [-b BLOQUES_GRC] [-l NIVEL_LOG] [-R] [-G] [-W] [-S CORE_SEGURO] [-K CLAVE_SEGURO] [-d DISPOSITIVO] [-n NOMBRE_CORE_IMAGEN] [-t OBJETIVO] [-g] [-Y] [--VERIFICAR] [-s] [-P] [-j TRABAJOS] [-c] [-p RUTA_VIVADO] [-H] [-D] [--color {nunca,auto,siempre}]

argumentos opcionales:

-h, --help
muestra un mensaje de ayuda y sale
-y CONFIG_YAML, --yaml-config CONFIG_YAML
Ruta al archivo de configuración YAML (archivo del core de la imagen). Se requiere esta opción o --grc-config.
-r CONFIG_GRC, --grc-config CONFIG_GRC
Ruta al archivo .grc para generar la configuración
-C DIR_BASE, --base-dir DIR_BASE
Ruta al directorio base. Por defecto, el directorio actual.
-F DIR_FPGA, --fpga-dir DIR_FPGA
Ruta al directorio del árbol de fuentes FPGA. Por defecto, el árbol de fuentes FPGA del repositorio actual.
-B DIR_CONSTRUCCION, --build-dir DIR_CONSTRUCCION
Ruta al directorio donde se generarán el core de la imagen y los artefactos de construcción. Por defecto, "build-" en el directorio base.
-O DIR_SALIDA_CONSTRUCCION, --build-output-dir DIR_SALIDA_CONSTRUCCION
Ruta al directorio para los resultados finales de la construcción de FPGA. Por defecto, "build" en el directorio base.
-E DIR_IP_CONSTRUCCION, --build-ip-dir DIR_IP_CONSTRUCCION
Ruta al directorio para los artefactos de construcción de IP. Por defecto, "build-ip" en el directorio base.
-o SALIDA_CORE_IMAGEN, --image-core-output SALIDA_CORE_IMAGEN
¡OBSOLETO! Esto ha sido reemplazado por --build-dir.
-x SALIDA_HEX_ROUTER, --router-hex-output SALIDA_HEX_ROUTER
¡OBSOLETO! Esta opción será ignorada.
-I DIR_INCLUIR, --include-dir DIR_INCLUIR
Ruta al directorio del módulo RFNoC Fuera de Árbol (Out-of-Tree).
-b BLOQUES_GRC, --grc-blocks BLOQUES_GRC
Ruta al directorio de descripciones de bloques GRC (necesario solo para --grc-config)
-l NIVEL_LOG, --log-level NIVEL_LOG
Ajusta el nivel de registro.
-R, --reuse
Reutiliza archivos existentes (no regenera el core de la imagen).
-G, --generate-only
Solo genera archivos sin construir la FPGA.
-W, --ignore-warnings
Ejecuta la construcción incluso cuando hay advertencias en el proceso de construcción.
-S CORE_SEGURO, --secure-core CORE_SEGURO
Construye un core de imagen seguro en lugar de un bitfile. Este argumento proporciona el nombre del YAML generado.
-K CLAVE_SEGURO, --secure-key CLAVE_SEGURO
Ruta al archivo de clave de cifrado a utilizar para el core seguro.
-d DISPOSITIVO, --device DISPOSITIVO
Dispositivo a programar [x300, x310, e310, e320, n300, n310, n320, x410, x440]. Debe especificarse aquí o en el archivo de configuración.
-n NOMBRE_CORE_IMAGEN, --image-core-name NOMBRE_CORE_IMAGEN, --image_core_name NOMBRE_CORE_IMAGEN
Nombre a utilizar para el core de imagen RFNoC. Por defecto, el nombre del archivo YML del core de imagen, sin la extensión.
-t OBJETIVO, --target OBJETIVO
Objetivo de construcción (p. ej., X310_HG, N320_XG, ...). Debe especificarse aquí o en el archivo de configuración.
-g, --GUI
Abre la GUI de Vivado durante el proceso de construcción de la FPGA.
-Y, --SYNTH
Detiene el proceso de construcción de la FPGA después de la Síntesis.
-C, --CHECK
Ejecuta solo la elaboración para verificar la sintaxis HDL.
-s, --save-project
Guarda el proyecto Vivado en disco.
-P, --ip-only
Construye solo las IPs requeridas.
-j TRABAJOS, --jobs TRABAJOS
Número de trabajos paralelos a utilizar con make.
-c, --clean-all
Limpia la IP antes de una nueva construcción.
-p RUTA_VIVADO, --vivado-path RUTA_VIVADO
Ruta a la instalación base de Xilinx Vivado si no se encuentra en la ubicación predeterminada (p. ej., /tools/Xilinx/Vivado).
-H, --no-hash
No incluye el hash YAML de origen en el código fuente generado.
-D, --no-date
No incluye la fecha o hora en el código fuente generado.
--color {nunca,auto,siempre}
Habilita la salida con color. Cuando se establece en 'auto', solo se mostrará salida con color en entornos TTY (p. ej., shells interactivos).

DESCRIPCIÓN

Esta herramienta toma un archivo de configuración YAML y genera un bitfile FPGA que puede usarse con un dispositivo UHD compatible con RFNoC. El archivo de configuración YAML describe los bloques RFNoC que se incluirán en la imagen FPGA, junto con las conexiones entre los bloques y cualquier configuración adicional requerida para los bloques.
