RFKILL(8) Administración del Sistema RFKILL(8)

NOMBRE

rfkill - herramienta para habilitar y deshabilitar dispositivos inalámbricos

SINOPSIS

rfkill [opciones] [comando] [ID|tipo ...]

DESCRIPCIÓN

rfkill lista, habilita y deshabilita dispositivos inalámbricos.

El formato de salida del comando "list" está obsoleto y se mantiene solo por compatibilidad con versiones anteriores. El nuevo formato de salida es el predeterminado cuando no se especifica ningún comando o cuando se usa la opción --output.

La salida predeterminada está sujeta a cambios. Por lo tanto, siempre que sea posible, debe evitar usar salidas predeterminadas en sus scripts. Defina siempre explícitamente las columnas esperadas utilizando la opción --output junto con una lista de columnas en entornos donde se requiera una salida estable.

OPCIONES

-J, --json

Utilizar formato de salida JSON.

-n, --noheadings

No imprimir una línea de encabezado.

-o, --output

Especificar qué columnas de salida imprimir. Use --help para obtener una lista de columnas disponibles.

--output-all

Mostrar todas las columnas disponibles.

-r, --raw

Utilizar el formato de salida raw (crudo).

-h, --help

Mostrar texto de ayuda y salir.

-V, --version

Mostrar la versión y salir.

COMANDOS

help

Mostrar texto de ayuda y salir.

event

Escuchar eventos de rfkill y mostrarlos en la salida estándar.

list [id|tipo ...]

Listar el estado actual de todos los dispositivos disponibles. El formato de salida del comando está obsoleto, consulte la sección DESCRIPCIÓN. Es una buena idea verificar con el comando list si el ámbito de id o tipo es apropiado antes de configurar block o unblock. El string especial de tipo all coincidirá con todo. Se admite el uso de múltiples argumentos de ID o tipo. Los tipos posibles son all, {wlan | wifi}, bluetooth, {uwb | ultrawideband}, wimax, wwan, gps, fm, nfc.

block id|tipo [...]

Deshabilitar el dispositivo correspondiente.

unblock id|tipo [...]

Habilitar el dispositivo correspondiente. Si el dispositivo está bloqueado por hardware, por ejemplo, a través de un interruptor de hardware, permanecerá no disponible aunque ahora esté desbloqueado por software.

toggle id|tipo [...]

Habilitar o deshabilitar el dispositivo correspondiente.

EJEMPLO

  rfkill --output ID,TYPE
  rfkill block all
  rfkill unblock wlan
  rfkill block bluetooth uwb wimax wwan gps fm nfc
