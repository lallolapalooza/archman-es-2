rfnoc_modtool(1) Comandos de usuario rfnoc_modtool(1)

NOMBRE

rfnoc_modtool - Herramienta de gestión de módulos OOT de RFNoC

DESCRIPCIÓN

Crea y gestiona módulos OOT de RFNoC.

SINOPSIS

rfnoc_modtool [COMANDO] [OPCIONES]

COMANDOS

Ejecute rfnoc_modtool COMANDO --help para obtener más información sobre un comando específico.

create
Crea un nuevo módulo OOT de RFNoC.
add
Añade un nuevo bloque a un módulo OOT de RFNoC existente.
add-gr-oot
Añade un módulo OOT de GNU Radio.
add-gr-block
Añade un bloque de GNU Radio a un módulo OOT de GNU Radio existente.
add-grc
Añade enlaces GRC de GNU Radio para un bloque existente en este módulo OOT de RFNoC.
make-yaml
Asistente de Creación de YAML -- Genera un archivo descriptor YAML de bloque RFNoC basado en la entrada del usuario.

CREACIÓN DE NUEVOS MÓDULOS

Al ejecutar rfnoc_modtool create, se creará un nuevo directorio que contiene los archivos necesarios para un nuevo módulo OOT de RFNoC. Este directorio solo contendrá código de plantilla y el usuario deberá añadir sus propios bloques al módulo.

Al llamar a 'rfnoc_modtool add-gr-oot', el usuario puede añadir un módulo OOT de GNU Radio dentro del módulo OOT de RFNoC.

AÑADIR BLOQUES

Al ejecutar rfnoc_modtool add, se añadirá un nuevo bloque a un módulo OOT de RFNoC existente. Esto requiere haber ejecutado previamente rfnoc_modtool create para crear el módulo.

Tenga en cuenta que para que 'rfnoc_modtool add' tenga éxito, el usuario debe proporcionar un archivo descriptor de bloque en formato YAML. Este archivo describe el bloque y sus parámetros. El usuario puede crear este archivo manualmente o usar el Asistente de Creación de YAML ejecutando rfnoc_modtool make-yaml. El asistente solicitará al usuario la información necesaria para crear un archivo YAML válido.

Una vez creados los bloques, el usuario puede añadir bloques nativos de GNU Radio para permitir un control más preciso de los bloques RFNoC desde GNU Radio ejecutando 'rfnoc_modtool add-gr-block'.

Para añadir enlaces GRC de GNU Radio para los bloques, llame a 'rfnoc_modtool add-grc'.

EJEMPLOS

Crear un nuevo módulo OOT de RFNoC llamado filter

rfnoc_modtool create filter
cd rfnoc-filter

Usar el Asistente de Creación de YAML para crear un archivo descriptor de bloque

rfnoc_modtool make-yaml

Después de editar el archivo fir.yml para describir el bloque de filtro FIR, añadir un bloque llamado fir al módulo filter

rfnoc_modtool add fir

Ahora añadir un módulo OOT de GNU Radio

rfnoc_modtool add-gr-oot

Añadir un bloque de GNU Radio al módulo filter para controlar el bloque RFNoC FIR (por ejemplo, para una mejor integración en la herramienta de diseño de filtros de GNU Radio)

rfnoc_modtool add-gr-block --gr-blockname rfnoc_fir fir

Exponer este nuevo bloque en GRC

rfnoc_modtool add-grc --binding-type native fir
