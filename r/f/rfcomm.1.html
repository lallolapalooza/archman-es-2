rfcomm(1) Administración del sistema Linux rfcomm(1)

Nombre

rfcomm - utilidad de configuración RFCOMM

SINOPSIS

rfcomm [OPCIONES] <COMANDO> <dispositivo>

DESCRIPCIÓN

rfcomm(1) se utiliza para configurar, mantener e inspeccionar la configuración RFCOMM del subsistema Bluetooth en el kernel de Linux. Si no se proporciona ningún comando, o si se utiliza la opción -a, rfcomm muestra información sobre los dispositivos RFCOMM configurados.

OPCIONES

-h
Muestra una lista de comandos posibles.
-a
Muestra información sobre todos los dispositivos RFCOMM configurados.
-r
Cambia el TTY a modo crudo (no funciona con "bind").
-i <hciX> | <dirección_bluetooth>
El comando se aplica al dispositivo hciX, que debe ser el nombre o la dirección de un dispositivo Bluetooth instalado. Si no se especifica, el comando utilizará el primer dispositivo Bluetooth disponible.
-A
Habilita la autenticación
-E
Habilita el cifrado
-S
Conexión segura
-C
Conviértete en el central de una piconet
-L <segundos>
Establece el tiempo de espera de retención (linger)

COMANDOS

mostrar <dispositivo>
Muestra la información sobre el dispositivo especificado.
conectar <dispositivo> [dirección_bluetooth] [canal]
Conecta el dispositivo RFCOMM al dispositivo Bluetooth remoto en el canal especificado. Si no se especifica ningún canal, se utilizará el número de canal 1. Este comando se puede terminar con la secuencia de teclas CTRL-C.
escuchar <dispositivo> [canal] [comando]
Escucha en un canal RFCOMM especificado para conexiones entrantes. Si no se especifica ningún canal, se utilizará el número de canal 1, pero se debe especificar un canal antes del comando. Si se proporciona un comando, se ejecutará tan pronto como un cliente se conecte. Cuando el proceso hijo termine o el cliente se desconecte, el comando terminará. Las ocurrencias de {} en el comando se reemplazarán por el nombre del dispositivo utilizado por la conexión. Este comando se puede terminar con la secuencia de teclas CTRL-C.
vigilar <dispositivo> [canal] [comando]
Vigilar es idéntico a escuchar, excepto que cuando el proceso hijo termina o el cliente se desconecta, el comando reiniciará la escucha con los mismos parámetros.
enlazar <dispositivo> [dirección_bluetooth] [canal]
Esto enlaza el dispositivo RFCOMM a un dispositivo Bluetooth remoto. El comando no establece una conexión con el dispositivo remoto, solo crea el enlace. La conexión se establecerá justo después de que una aplicación intente abrir el dispositivo RFCOMM. Si no se especifica ningún número de canal, se utiliza el número de canal 1.
liberar <dispositivo>
Este comando libera un enlace RFCOMM definido.

Si se especifica todo para el dispositivo RFCOMM, se eliminarán todos los enlaces.
