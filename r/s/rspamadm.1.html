NOMBRE

rspamadm - utilidad de administración de rspamd

SINOPSIS

rspamadm [opciones_globales] [comando] [opciones_del_comando]...

DESCRIPCIÓN

rspamadm es una rutina para administrar el sistema de filtrado de spam de rspamd. Está destinado a realizar acciones como fusionar bases de datos, realizar pruebas de configuración, cifrar contraseñas, firmar configuraciones, etc. Puede obtener una lista de los comandos disponibles ejecutando

rspamadm -l

Además, para cada comando, puede verificar la lista de opciones_del_comando disponibles ejecutando

rspamadm help comando
rspamadm comando --help

OPCIONES

-h, --help
Mostrar mensaje de ayuda
-v, --verbose
Habilitar salida detallada
-l, --list-commands
Listar comandos disponibles
--version
Mostrar versión
--var=valor
Redefinir variable ucl en formato VARIABLE=VALOR

VALOR DE RETORNO

Al salir, rspamadm devuelve 0 si la operación fue exitosa y un código de error en caso contrario.

EJEMPLOS

Obtener ayuda para el comando pw:

rspamadm help pw
rspamadm pw --help

Cifrar la contraseña del controlador:

rspamadm pw encrypt

Fusionar bases de datos fuzzy:

rspamadm fuzzy_merge -s data1.sqlite -s data2.sqlite -t dest.sqlite

Realizar una prueba de configuración:

rspamadm configtest -c rspamd.conf

Probar la configuración estrictamente y redefinir algunas variables ucl:

rspamadm --var=DBDIR=/tmp configtest -c ./rspamd.conf -s

Volcar la configuración procesada:

rspamadm configdump

Volcar la configuración procesada como una cadena JSON:

rspamadm configdump -j

Generar un par de claves para usar en el cifrado HTTPCrypt:

rspamadm keypair

VER TAMBIÉN

La documentación de Rspamd y los códigos fuente pueden descargarse de https://rspamd.com/.
