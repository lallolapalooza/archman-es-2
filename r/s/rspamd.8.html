NOMBRE

rspamd - demonio principal para el sistema de filtrado rápido de spam

SINOPSIS

rspamd [opciones]...

rspamd –help

DESCRIPCIÓN

El sistema de filtrado Rspamd está diseñado para ser un sistema rápido, modular y fácilmente escalable. El núcleo de Rspamd está escrito en lenguaje C utilizando un modelo de procesamiento basado en eventos. Los plugins para rspamd se pueden escribir en lenguaje de programación Lua. Rspamd está diseñado para procesar conexiones de forma completamente asíncrona y no bloquearse en ningún punto del código.

OPCIONES

-f, --no-fork
No demonizar el proceso principal
-c ruta, --config=ruta
Especificar archivo(s) de configuración
-u nombreusuario, --user=nombreusuario
Usuario con el que ejecutar rspamd
-g nombregrupo, --group=nombregrupo
Grupo con el que ejecutar rspamd
-p ruta, --pid=ruta
Ruta al archivo PID
-i, --insecure
Ignorar procesos en ejecución como usuarios privilegiados (inseguro)

EJEMPLOS

Ejecutar el demonio rspamd con la configuración predeterminada:

rspamd

Ejecutar rspamd en primer plano con configuración personalizada:

rspamd -f -c ~/rspamd.conf

Ejecutar rspamd especificando usuario y grupo:

rspamd -u rspamd -g rspamd -c /etc/rspamd/rspamd.conf

VER TAMBIÉN

La documentación y el código fuente de Rspamd pueden descargarse de https://rspamd.com/.
