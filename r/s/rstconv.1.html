rstconv(1) Herramienta de conversión de cadenas de recursos de Free Pascal rstconv(1)

NOMBRE

rstconv - La herramienta de conversión de cadenas de recursos de Free Pascal.

SINOPSIS

rstconv [opciones] -o archivo_salida

DESCRIPCIÓN

rstconv lee un archivo de cadenas de recursos ( .rst ) que fue producido por el compilador Free Pascal y genera un archivo que puede ser utilizado por una herramienta de internacionalización (actualmente solo GNU gettext es compatible) para internacionalizar su aplicación.

USO

rstconv tiene una opción requerida: -o archivo_salida para especificar el nombre del archivo de salida. Si no se especifica ningún archivo de entrada, se asume la entrada estándar.

OPCIONES

-f formato
Especifica el formato del archivo de salida. Actualmente solo se admite el siguiente formato:
po
emite un archivo .po para usar con GNU gettext , que lo convierte en un archivo .mo, que se puede leer con la unidad gettext .
-h (o --help)
muestra un mensaje de ayuda corto.
-i archivo_entrada
Especifica el nombre del archivo de entrada. Si se omite, se asume la entrada estándar.
-o archivo_salida
(Requerido) especifica el nombre del archivo de salida.
