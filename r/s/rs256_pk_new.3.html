RS256_PK_NEW(3) Manual de Funciones de Biblioteca RS256_PK_NEW(3)

NOMBRE

rs256_pk_new, rs256_pk_free, rs256_pk_from_RSA, rs256_pk_from_EVP_PKEY, rs256_pk_from_ptr, rs256_pk_to_EVP_PKEY — API COSE RS256 FIDO

SINOPSIS

#include <openssl/rsa.h>
#include <fido/rs256.h>

rs256_pk_t *
rs256_pk_new(void);

void
rs256_pk_free(rs256_pk_t **pkp);

int
rs256_pk_from_EVP_PKEY(rs256_pk_t *pk, const EVP_PKEY *pkey);

int
rs256_pk_from_RSA(rs256_pk_t *pk, const RSA *rsa);

int
rs256_pk_from_ptr(rs256_pk_t *pk, const void *ptr, size_t len);

EVP_PKEY *
rs256_pk_to_EVP_PKEY(const rs256_pk_t *pk);

DESCRIPCIÓN

RS256 es el nombre dado en la RFC de CBOR Object Signing and Encryption (COSE) a PKCS#1.5 RSA de 2048 bits con SHA-256. La API COSE RS256 de libfido2 es una API auxiliar con rutinas para convertir entre los diferentes tipos de claves públicas RSA utilizados en libfido2 y OpenSSL.

En libfido2, las claves públicas RS256 se abstraen mediante el tipo rs256_pk_t.

La función rs256_pk_new() devuelve un puntero a un tipo rs256_pk_t vacío, recién asignado. Si no se puede asignar memoria, se devuelve NULL.

La función rs256_pk_free() libera la memoria que respalda *pkp, donde *pkp debe haber sido previamente asignado por rs256_pk_new(). Al regresar, *pkp se establece en NULL. O bien pkp o *pkp pueden ser NULL, en cuyo caso rs256_pk_free() no hace nada.

La función rs256_pk_from_EVP_PKEY() rellena pk con el contenido de pkey. No se conservan referencias a pkey.

La función rs256_pk_from_RSA() rellena pk con el contenido de rsa. No se conservan referencias a rsa.

La función rs256_pk_from_ptr() rellena pk con el contenido de ptr, donde ptr apunta a len bytes. No se conservan referencias a ptr.

La función rs256_pk_to_EVP_PKEY() convierte pk a un tipo EVP_PKEY recién asignado con un contador de referencias de 1. No se conservan referencias internas al puntero devuelto. Si ocurre un error, rs256_pk_to_EVP_PKEY() devuelve NULL.

VALORES DE RETORNO

Las funciones rs256_pk_from_EVP_PKEY(), rs256_pk_from_RSA() y rs256_pk_from_ptr() devuelven FIDO_OK si la operación es exitosa. En caso de error, se devuelve un código de error diferente definido en <fido/err.h>.
