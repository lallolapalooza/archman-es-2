subrutina csrscl (entero n, real sa, complejo, dimensión( * ) sx, entero incx)

CSRSCL multiplica un vector complejo de n elementos x por el escalar real 1/a. Se realiza esto sin desbordamiento ni subdesbordamiento, siempre que el resultado final x/a no se desborde ni subdesborde.

Propósito:

!>
!> CSRSCL multiplica un vector complejo de n elementos x por el escalar real
!> 1/a. Esto se hace sin desbordamiento ni subdesbordamiento, siempre que
!> el resultado final x/a no se desborde ni subdesborde.
!>

Parámetros

N 
!>          N es ENTERO
!>          El número de componentes del vector x.
!>

SA

!>          SA es REAL
!>          El escalar a que se utiliza para dividir cada componente de x.
!>          SA debe ser >= 0, o la subrutina dividirá por cero.
!>

SX

!>          SX es un array COMPLEJO, dimensión
!>                         (1+(N-1)*abs(INCX))
!>          El vector x de n elementos.
!>

INCX

!>          INCX es ENTERO
!>          El incremento entre valores sucesivos del vector SX.
!>          > 0:  SX(1) = X(1) y SX(1+(i-1)*INCX) = x(i),     1< i<= n
!>

NAME

rscl - Control display of virtual terminals

SYNOPSIS

rscl [-h] [-v] [-d] [-i] [-r] [-s] [-l] [-c] [--auto-login] [--tty tty] [--user user] [--shell shell] [--display display] [--geometry geometry] [--dpi dpi] [--font font] [--font-scale scale] [--locale locale] [--num-lock] [--caps-lock] [--scroll-lock] [--set-keymap keymap] [--suspend-then-hibernate] [--suspend-then-hybrid-sleep] [--suspend] [--hibernate] [--hybrid-sleep] [--sleep] [--power-off] [--reboot] [--shutdown]

Detailed Description

The rscl command is used to control the display of virtual terminals. It allows users to configure various aspects of the virtual terminal environment, including login behavior, session settings, and power management options.

Function Documentation

The following functions are available:

  • -h, --help: Display a help message and exit.
  • -v, --version: Display version information and exit.
  • -d, --debug: Enable debug output.
  • -i, --init-config: Initialize configuration files.
  • -r, --reload-config: Reload configuration files.
  • -s, --status: Display current status.
  • -l, --list: List available options.
  • -c, --clear: Clear screen.
  • --auto-login: Enable automatic login.
  • --tty tty: Specify the TTY to use.
  • --user user: Specify the user for automatic login.
  • --shell shell: Specify the default shell.
  • --display display: Specify the X display.
  • --geometry geometry: Specify the display geometry.
  • --dpi dpi: Specify the DPI.
  • --font font: Specify the font.
  • --font-scale scale: Specify the font scale factor.
  • --locale locale: Specify the locale.
  • --num-lock: Enable Num Lock.
  • --caps-lock: Enable Caps Lock.
  • --scroll-lock: Enable Scroll Lock.
  • --set-keymap keymap: Set the keymap.
  • --suspend-then-hibernate: Suspend and then hibernate after a timeout.
  • --suspend-then-hybrid-sleep: Suspend and then hybrid-sleep after a timeout.
  • --suspend: Suspend the system.
  • --hibernate: Hibernate the system.
  • --hybrid-sleep: Perform a hybrid sleep.
  • --sleep: Put the system to sleep (suspend).
  • --power-off: Power off the system.
  • --reboot: Reboot the system.
  • --shutdown: Shut down the system.
