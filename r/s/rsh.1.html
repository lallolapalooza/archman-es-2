RSH(1) Comandos de usuario RSH(1)

NOMBRE

rsh - Cliente de shell remoto

SINOPSIS

rsh [OPCIÓN...] [USUARIO@]HOST [COMANDO [ARG...]]

DESCRIPCIÓN

Shell remoto

-4, --ipv4
usar solo IPv4
-6, --ipv6
usar solo IPv6
-8, --8-bit
permite una ruta de datos de entrada de ocho bits en todo momento
-d, --debug
activa la depuración de sockets (ver setsockopt(2))
-e, --escape=CARACTER
permite al usuario especificar el carácter de escape (``~'' por defecto)
-l, --usuario=USUARIO
ejecutar como USUARIO en el sistema remoto
-n, --sin-entrada
usar /dev/null como entrada
-?, --ayuda
dar esta lista de ayuda
--uso
dar un mensaje de uso corto
-V, --version
imprimir la versión del programa

Los argumentos obligatorios u opcionales para las opciones largas también son obligatorios u opcionales para cualquier opción corta correspondiente.
