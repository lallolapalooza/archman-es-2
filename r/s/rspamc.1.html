NOMBRE

rspamc - cliente de línea de comandos de rspamd

SINOPSIS

rspamc [opciones] [comando] [archivo-entrada]...

rspamc –ayuda

DESCRIPCIÓN

rspamc es un cliente simple de rspamd, principalmente para clasificar o aprender mensajes. rspamc soporta los siguientes comandos:

•
Comandos de escaneo:
•
symbols: escanea el mensaje y muestra los símbolos (comando predeterminado)
•
Comandos de control
•
learn_spam: aprende el mensaje como spam
•
learn_ham: aprende el mensaje como ham (no spam)
•
fuzzy_add: añade el mensaje al almacenamiento fuzzy (comprueba las opciones -f y -w para este comando)
•
fuzzy_del: elimina el mensaje del almacenamiento fuzzy (comprueba la opción -f para este comando)
•
stat: muestra las estadísticas de rspamd
•
stat_reset: muestra y reinicia las estadísticas de rspamd (útil para gráficos)
•
counters: muestra las estadísticas de los símbolos de rspamd
•
uptime: muestra el tiempo de actividad de rspamd
•
add_symbol: añade o modifica la configuración de símbolos en rspamd
•
add_action: añade o modifica la configuración de acciones

Los comandos de control que modifican el estado de rspamd se consideran privilegiados y requieren que se especifique una contraseña con la opción -P (ver OPCIONES, a continuación, para más detalles).

Esto depende de la configuración de un controlador y se discute en la página de rspamd-workers (ver VER TAMBIÉN, a continuación, para más detalles).

Los archivos de entrada pueden ser uno o varios archivos regulares o un directorio para escanear. Si no se especifican archivos, rspamc lee de la entrada estándar. Los comandos del controlador normalmente no aceptan ninguna entrada, sin embargo, los comandos learn* y fuzzy* requieren entrada.

OPCIONES

-h host[:puerto], --connect=host[:puerto]
Especifica el host y el puerto
-P contraseña, --password=contraseña
Especifica la contraseña de control. Puede ser una ruta absoluta o relativa, en cuyo caso la contraseña se leerá de ese archivo.
-c nombre, --classifier=nombre
Clasificador para aprender spam o ham (bayes se usa por defecto)
-w peso, --weight=peso
Peso para operaciones fuzzy
-f número, --flag=número
Bandera para operaciones fuzzy
-p, --pass
Pasa todos los filtros
-v, --verbose
Salida más detallada
-i dirección IP, --ip=dirección IP
Emula que el mensaje fue recibido de la dirección IP especificada
-u nombre de usuario, --user=nombre de usuario
Emula que el mensaje fue recibido del usuario autenticado especificado
-d usuario@dominio, --deliver=usuario@dominio
Emula que el mensaje fue entregado al usuario especificado (para LDA/estadísticas)
-F usuario@dominio, --from=usuario@dominio
Emula que el mensaje tiene la dirección SMTP FROM especificada
-r usuario@dominio, --rcpt=usuario@dominio
Emula que el mensaje tiene la dirección SMTP RCPT especificada
--helo=cadena_helo
Imita el paso HELO de SMTP desde el MTA
--hostname=nombre de host
Imita el paso del nombre de host desde el MTA (rspamd asume que ha sido verificado por el MTA)
-t segundos, --timeout=segundos
Tiempo de espera para recibir una respuesta (puede ser un número de punto flotante, por ejemplo, 0.1)
-b host:puerto, --bind=host:puerto
Vincula a la dirección IP especificada
-R, --human
Salida de informe legible por humanos. La primera línea de la salida contiene la puntuación del mensaje y tres puntuaciones umbral, en este formato:
    puntuacion/lista_gris/agregar_encabezado/rechazar,accion=N:ACCION,spam=0|1,saltado=0|1
-j, --json
Salida JSON formateada
--ucl
Salida UCL
--raw
Salida de datos crudos recibidos de rspamd (JSON compactado)
--headers
Salida de los encabezados HTTP de una respuesta
--extended-urls
Salida de URLs en formato extendido, mostrando la URL completa, el host y la parte del host que fue utilizada por el módulo surbl (si está habilitado).
-n conteo_paralelo, --max-requests=conteo_paralelo
Número máximo de solicitudes a rspamd ejecutadas en paralelo (8 por defecto)
-e comando, --execute=comando
Ejecuta el comando especificado con salida mime (si la opción mime también está especificada) o salida formateada de rspamd
--mime
Salida del mensaje mime completo en lugar de solo los resultados del escaneo
--header=encabezado
Añade un encabezado HTTP personalizado para una solicitud. Puedes especificar el encabezado en formato nombre=valor o simplemente nombre para un encabezado vacío. Esta opción puede repetirse varias veces.
--sort=tipo
Ordena la salida según un campo específico. Para el comando counters, los valores permitidos para esta clave son name, weight, frequency y hits. Añadir :asc a cualquiera de estos tipos invierte el orden de clasificación.
--commands
Lista los comandos disponibles

VALOR DE RETORNO

Al salir, rspamc devuelve 0 si la operación fue exitosa y un código de error de lo contrario.

EJEMPLOS

Verificar stdin:

rspamc < archivo_alguno

Verificar archivos:

rspamc symbols archivo1 archivo2 archivo3

Aprender archivos:

rspamc -P contraseña aprender_spam archivo1 archivo2 archivo3

Añadir hash fuzzy al conjunto 2:

rspamc -P contraseña -f 2 -w 10 fuzzy_add archivo1 archivo2

Eliminar hash fuzzy de otro servidor:

rspamc -P contraseña -h nombre_host:11334 -f 2 fuzzy_del archivo1 archivo2

Obtener estadísticas:

rspamc stat

Obtener tiempo de actividad:

rspamc uptime

Añadir peso a una regla personalizada:

rspamc add_symbol prueba 1.5

Añadir peso a una acción personalizada:

rspamc

rspamc(1) - Manual de Usuario de Rspamd

NOMBRE

rspamc - cliente de línea de comandos de Rspamd

SINOPSIS

rspamc [-h host] [-p port] [-s socket] [-i timeout] [-d] [-v] [-f file] [-e expression] [-u user] [-a action] [-c connection_timeout] [--add-user user] [--remove-user user] [--expire-user user] [--add-action action] [--reject action]

DESCRIPCIÓN

El programa rspamc es un cliente de línea de comandos para el servidor Rspamd. Se utiliza para enviar correos electrónicos a Rspamd para su escaneo y para obtener el estado y la configuración de Rspamd. También se puede utilizar para administrar la lista de usuarios y acciones permitidas.

OPCIONES

•-h host
Especifica el host en el que se ejecuta el servidor Rspamd. El valor predeterminado es 127.0.0.1.
•-p port
Especifica el puerto en el que se ejecuta el servidor Rspamd. El valor predeterminado es 11334.
•-s socket
Especifica el socket de dominio Unix para conectarse al servidor Rspamd. Si se especifica, se ignora -h y -p.
•-i timeout
Establece el tiempo de espera de la solicitud en segundos. El valor predeterminado es 30.
•-d
Desactiva la validación de certificados TLS para conexiones seguras.
•-v
Imprime información detallada sobre la acción realizada.
•-f file
Lee el contenido del correo electrónico desde el archivo especificado.
•-e expression
Evalúa la expresión dada en el contexto del correo escaneado.
•-u user
Especifica el usuario para la operación de aprendizaje o descifrado.
•-a action
Realiza una acción específica en el correo electrónico.
•-c connection_timeout
Establece el tiempo de espera de la conexión en segundos. El valor predeterminado es 10.
•--add-user user
Agrega un usuario a la lista de usuarios permitidos.
•--remove-user user
Elimina un usuario de la lista de usuarios permitidos.
•--expire-user user
Expirar la lista de usuarios permitidos para el usuario especificado.
•--add-action action
Agrega una acción a la lista de acciones permitidas.
•--reject action
Establece la acción de rechazo para el correo electrónico.

VALOR DE RETORNO

El código de salida es 0 en caso de éxito, o un código de error distinto de cero en caso de fallo.

EJEMPLOS

 Escanear un correo electrónico y mostrar el resultado:
 $ rspamc -f email.txt

 Agregar un usuario a la lista de usuarios permitidos:
 $ rspamc --add-user john@example.com

 Establecer la acción de rechazo a "reject":
 $ rspamc --reject reject
