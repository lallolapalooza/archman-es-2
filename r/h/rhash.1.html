RHASH(1) Manuales de Usuario RHASH(1)

NOMBRE

rhash - calcular/verificar CRC32, MD5, SHA1, GOST, TTH, BTIH u otros resúmenes de mensajes.

SINOPSIS

rhash [ opción ]... [ archivo ]...

DESCRIPCIÓN

RHash (Recursive Hasher) calcula y verifica varios resúmenes de mensajes y sumas de verificación de archivos. Los algoritmos de hash soportados incluyen CRC32, CRC32C, MD4, MD5, SHA1, SHA256, SHA512, SHA3, Tiger, DC++ TTH, BTIH, AICH, ED2K, GOST R 34.11-*, RIPEMD-160, HAS-160, BLAKE2s/BLAKE2b, BLAKE3, EDON-R 256/512, Whirlpool, Snefru-128/256.

El programa puede crear y verificar enlaces Magnet y enlaces eDonkey ed2k://, ver las opciones --magnet y --ed2k-link.

Un parámetro de cadena guion `-' se interpreta como el flujo de entrada estándar (stdin).

Por defecto rhash imprime resúmenes en formato SFV con solo la suma de verificación CRC32. El formato puede ser cambiado por las opciones --bsd, --magnet, --simple, --printf, --template. Para emitir todos los resúmenes usa la opción `-a'.

OPCIONES DE MODO DEL PROGRAMA

El modo por defecto es imprimir las sumas de verificación para todos los archivos y árboles de directorios especificados en la línea de comandos. El modo puede ser cambiado por las siguientes opciones.

-c, --check
Verificar archivos de hash especificados en la línea de comandos. RHash puede verificar archivos de hash en formatos SFV y BSD, formatos de archivos MD5 y SHA1, y archivos de texto que contienen enlaces magnet o ed2k (un enlace por línea). Se ignoran las líneas vacías y las líneas que comienzan con `;' o `#' .

RHash puede verificar archivos de hash generados sin las opciones de formato --printf y --template.

Si el algoritmo de hash no se especifica mediante opciones de línea de comandos, entonces RHash intenta detectar el algoritmo por la extensión del archivo de hash. Si la detección falla, entonces se calculan todas las funciones de hash de la misma longitud de hash, lo que ralentiza significativamente la verificación de archivos. Para acelerar la verificación, en tal caso, especifica explícitamente el algoritmo de hash en la línea de comandos.

-u, --update=<archivo-hash>
Actualizar el archivo de hash especificado calculando resúmenes de mensajes para los archivos listados en los argumentos de la línea de comandos que no estén presentes en él. Los nuevos resúmenes se añaden en el formato especificado por las opciones de formato.

Con --recursive, actualiza el archivo de hash usando archivos de árboles de directorios completos. Con --check, verifica los resúmenes existentes antes de actualizar.

--missing=<archivo-hash>
Listar los archivos del archivo de hash que faltan o son inaccesibles en el sistema de archivos.
--unverified=<archivo-hash>
Listar los archivos de la línea de comandos que faltan en el archivo de hash dado (archivos no verificados). Con --recursive, comprueba árboles de directorios completos en busca de archivos no verificados.
-k, --check-embedded
Verificar archivos por la suma crc32 incrustada en sus nombres.
--torrent
Crear un archivo torrent para cada archivo procesado.
-h, --help
Ayuda: mostrar la pantalla de ayuda y salir.
-V, --version
Versión: mostrar la versión y salir.
-B, --benchmark
Ejecutar benchmark para el/los algoritmo(s) de hash seleccionado(s).

OPCIONES VARIAS

-r, --recursive
Procesar recursivamente los directorios especificados en la línea de comandos.
--follow
Seguir enlaces simbólicos al procesar archivos o directorios de forma recursiva.
-m, --message=<texto>
Calcular resúmenes de mensajes del texto dado.
--file-list=<archivo>
Procesar el archivo dado como una lista de archivos. Las líneas de este archivo se interpretan como rutas a los archivos a procesar. Se pueden especificar múltiples listas de archivos en la línea de comandos.
-v, --verbose
Ser verboso.
--brief
Imprimir forma abreviada del informe de verificación (sin encabezado ni pie de página), al verificar un archivo de hash.
-P, --percents
Mostrar porcentajes, al calcular o verificar sumas.
--skip-ok
No imprimir mensajes OK para archivos verificados exitosamente.
--ignore-missing
Ignorar archivos faltantes, al verificar un archivo de hash.
-i, --ignore-case
Ignorar mayúsculas/minúsculas de nombres de archivo al actualizar archivos crc.
--speed
Imprimir la velocidad de procesamiento por archivo y la total.
-e, --embed-crc
Renombrar archivos insertando la suma crc32 en el nombre.
--embed-crc-delimiter=<delimitador>
Insertar el <delimitador> especificado > antes de una suma crc en el modo --embed-crc, el valor predeterminado es un espacio en blanco. El puede ser un carácter o una cadena vacía.
--path-separator=<separador>
Utiliza el separador de rutas especificado para mostrar las rutas. Solo se aceptan los valores de barra inclinada (`/') y barra invertida (`\').
-q, --accept=<lista>
Establece una lista de extensiones de archivos a procesar, separada por comas.
--exclude=<lista>
Establece una lista de extensiones de archivos a excluir del procesamiento, separada por comas.
-t, --crc-accept=<lista>
Establece una lista de extensiones de archivos hash a verificar, separada por comas.
--max-depth=<niveles>
Desciende como máximo <niveles> (un entero no negativo) de directorios por debajo de los argumentos de la línea de comandos. `--max-depth 0' significa aplicar las pruebas y acciones solo a los argumentos de la línea de comandos.
-o, --output=<ruta-archivo>
Establece el archivo al que se enviarán los resúmenes de mensajes calculados o los resultados de la verificación.
-l, --log=<ruta-archivo>
Establece el archivo al que se registrarán los errores y la información detallada.
--openssl=<lista>
Especifica qué funciones hash deben calcularse utilizando la biblioteca OpenSSL. La <lista> es una lista de nombres de funciones hash separada por comas, pero solo se permiten las compatibles con openssl: md4, md5, sha1, sha2*, ripemd160 y whirlpool.
--gost-reverse
Invierte los bytes en la salida hexadecimal de las funciones hash GOST. El byte más significativo del resumen del mensaje se imprimirá primero. El orden predeterminado es el byte menos significativo primero.
--bt-batch=<ruta-archivo>
Activa el modo de lote de torrents (implica el modo torrent). Calcula el lote de torrents para los archivos especificados en la línea de comandos y guarda el archivo torrent en la ruta del archivo. La opción -r <directorio> puede ser útil en este modo.
--bt-private
Genera un archivo torrent o BTIH para un rastreador BitTorrent privado.
--bt-transmission
Genera un archivo torrent o BTIH compatible con el cliente torrent Transmission.
--bt-piece-length
Establece el valor de longitud de pieza para el archivo torrent.
--bt-announce=<url-anuncio>
Agrega una URL de anuncio de rastreador a los archivos torrent creados. Se pueden pasar varias URLs especificando la opción varias veces. Esta opción no cambia el resumen del mensaje BTIH.
--benchmark-raw
Cambia el formato de salida del benchmark a texto legible por máquina y delimitado por tabulaciones, con el nombre de la función hash, la velocidad y los ciclos de CPU por byte. Esta opción solo funciona si se especificó la opción --benchmark.
--no-detect-by-ext
No detectar la función hash por la extensión del archivo hash, en el modo --check.
--no-path-escaping
Desactiva los caracteres de escape en las rutas de archivo. La opción se puede especificar en los modos predeterminado, de verificación o de actualización.
-- (doble guion)
Marca el final de las opciones de la línea de comandos. Todos los parámetros que sigan al doble guion se interpretarán como archivos o directorios. Se utiliza típicamente para procesar nombres de archivo que comienzan con un guion `-'. Alternativamente, puedes especificar './' o una ruta completa antes de dichos archivos, para que ya no parezcan opciones.

--hex

--base32
Imprime los resúmenes de mensajes en formato Base32.
-b, --base64
Imprime los resúmenes de mensajes en formato Base64.
--uppercase
Imprime los resúmenes de mensajes en mayúsculas.

ARCHIVO DE CONFIGURACIÓN

RHash busca un archivo de configuración en $XDG_CONFIG_HOME/rhash/rhashrc, $HOME/.config/rhash/rhashrc, $XDG_CONFIG_DIRS/rhash/rhashrc, $HOME/.rhashrc y /etc.

El archivo de configuración consta de líneas formateadas como

variable = valor

donde la variable puede ser el nombre de cualquier opción de línea de comandos, como magnet, printf, percents, etc. Una variable booleana se puede establecer en verdadero con el valor `on', `yes' o `true', cualquier otro valor la establece en falso.

Las líneas vacías y las líneas que comienzan con `#` o `;` se ignoran.

Ejemplo de archivo de configuración:

# Esta es una línea de comentario
percents = on
crc-accept = .sfv,.md5,.sha1,.sha256,.sha512,.tth,.magnet

RHash - Calculadora de hash de archivos y cadenas

NOMBRE

rhash - Calculadora de hash de archivos y cadenas

SINOPSIS

rhash [OPTIONS]... [FILE]...

DESCRIPCIÓN

RHash es una utilidad para calcular y verificar resúmenes criptográficos (hashes) de archivos y cadenas. Soporta una amplia gama de algoritmos de hash, incluyendo MD5, SHA1, SHA256, SHA512, TIGER, CRC32, y más.

RHash se puede usar para varios propósitos:

  • Verificar la integridad de los archivos descargados:

    rhash --sha256 file.zip

    Compara la suma SHA256 calculada del archivo con una suma conocida proporcionada.

  • Generar sumas de verificación para compartir:

    rhash --md5 > file.md5

    Esto crea un archivo llamado file.md5 que contiene la suma MD5 del archivo.

  • Calcular hashes de cadenas:

    echo -n "hello world" | rhash --sha1

    Esto calcula la suma SHA1 de la cadena "hello world".

OPCIONES DE MODO DE PROGRAMA

-c, --check FILE
Lee las sumas de verificación y los nombres de archivo de FILE y verifica los archivos especificados.
--check-names
Verifica los nombres de archivo en la salida del modo de verificación.
-C, --check-first
Lee las sumas de verificación de la entrada estándar y verifica los archivos especificados.
-p, --process-list FILE
Lee una lista de archivos de FILE y calcula hashes para cada uno.
-e, --exclude PATTERN
Excluye archivos que coinciden con el PATTERN del procesamiento (se puede usar varias veces).
--list-options
Lista todas las opciones disponibles.

OPCIONES DE ALGORITMOS HASH

Se pueden seleccionar uno o más algoritmos de hash usando las siguientes opciones:

-m, --md5
Incluir el hash MD5.
-a, --sha1
Incluir el hash SHA1.
-H, --sha224
Incluir el hash SHA-224.
-h, --sha256
Incluir el hash SHA-256.
-g, --sha384
Incluir el hash SHA-384.
-G, --sha512
Incluir el hash SHA-512.
-t, --tiger
Incluir el hash Tiger.
-T, --tiger128
Incluir el hash Tiger-128.
-r, --ripemd160
Incluir el hash RIPEMD-160.
-l, --crc32
Incluir el hash CRC32.
--xxh32
Incluir el hash XXH32.
--xxh64
Incluir el hash XXH64.
--blake2b
Incluir el hash BLAKE2b.
--blake2s
Incluir el hash BLAKE2s.
-A, --all
Incluir todos los algoritmos de hash soportados.
-W, --wet-hash
Incluir el hash WET.
-s, --sum
Incluir el hash SUM.

OPCIONES VARIAS

-v, --verbose
Salida detallada.
-q, --quiet
Salida mínima.
-z, --zero
Leer desde la entrada estándar hasta que se encuentre un byte nulo.
--binary
Leer y escribir en modo binario.
-h, --help
Mostrar mensaje de ayuda y salir.
-V, --version
Mostrar información de versión y salir.

OPCIONES DE FORMATO DE SALIDA

-f, --format FORMAT
Especificar el formato de salida. Los formatos disponibles son: binary, hex, base64, crc32, aich, sfv, cksum, sha1sum, sha256sum, sha512sum.
-b, --brief
Formato de salida abreviado para el modo de verificación.
-l, --line-buffered
Salida con búfer de línea.

ARCHIVO DE CONFIGURACIÓN

RHash puede leer opciones de configuración de un archivo. El archivo de configuración por defecto es ~/.config/rhash/rhashrc.
