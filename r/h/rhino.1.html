RHINO(1) Manual de comandos generales RHINO(1)

NOMBRE

rhino - invoca el intérprete de JavaScript para ejecutar scripts en modo por lotes o interactivo

SINOPSIS

rhino [opciones] nombre_archivo_script_o_url [argumentos_script]

DESCRIPCIÓN

Esta página del manual documenta brevemente el comando rhino.

rhino es un script de inicio para el intérprete de JavaScript rhino que proporciona una forma sencilla de ejecutar scripts en modo por lotes o un entorno interactivo para la programación exploratoria.

OPCIONES

-debug
Genera información de depuración. Esto establecerá el nivel de optimización a cero.
-e fuente_script
Ejecuta fuente_script como un script de JavaScript.
-encoding codificación_caracteres
Establece la codificación de caracteres a aplicar en caso de que no se pudiera detectar.
-f nombre_archivo_script_o_url
Lee el contenido de nombre_archivo_script_o_url y lo ejecuta como un script de JavaScript.
-fatal-warnings
Establece las advertencias como errores.
-help, -?
Muestra la ayuda.
-modules módulo
Añade un módulo a la ruta.
-opt, -O nivel_opt
Optimiza en el nivel nivel_opt, que debe ser un entero entre 0 y 9.
-require
Usa require().
-sandbox
Las instancias de require() creadas estarán en un entorno aislado.
-sealedlib
Usa una biblioteca estándar sellada.
-strict
Establece el modo estricto.
-version número_versión
Especifica la versión del lenguaje con la que compilar. Debe ser una de las siguientes: 100, 110, 120, 130, 140, 150, 160, 170, 180 o 200.
-w
Informa de las advertencias.

PROPIEDADES PREDEFINIDAS

Los scripts que se ejecutan en el intérprete tienen acceso a algunas propiedades adicionales del objeto de nivel superior.

arguments
El objeto arguments es un array que contiene las cadenas de todos los argumentos proporcionados en la línea de comandos cuando se invocó el intérprete.
help()
Ejecutar la función help imprimirá mensajes de uso y ayuda.
defineClass(nombreClase)
Define una extensión utilizando la clase Java llamada con el argumento de cadena nombreClase. Utiliza ScriptableObject.defineClass() para definir la extensión.
deserialize(archivo)
Restaura desde el archivo especificado un objeto previamente escrito mediante una llamada a serialize.
load([archivo,...])
Carga archivos de origen de JavaScript nombrados por argumentos de cadena. Si se proporcionan varios argumentos, cada archivo se lee y se ejecuta en orden.
loadClass(nombreClase)
Carga y ejecuta la clase llamada por el argumento de cadena nombreClase. La clase debe ser una clase que implemente la interfaz Script, al igual que cualquier script compilado por jsc.
print([expresion...])
Evalúa e imprime expresiones. Evalúa cada expresión, convierte el resultado en una cadena y la imprime.
readFile(ruta[,codificación_caracteres])
Lee el archivo dado y convierte sus bytes en una cadena utilizando la codificación de caracteres especificada o la codificación de caracteres predeterminada si no se proporciona un argumento de codificación explícito.
readUrl(url[,codificación_caracteres])
Abre una conexión de entrada a la url de cadena dada, lee todos sus bytes y los convierte en una cadena utilizando la codificación de caracteres especificada o la codificación de caracteres predeterminada si no se proporciona un argumento de codificación explícito.
runCommand(nombreComando[,arg,...][opciones])
Ejecuta el comando especificado con el argumento y las opciones dadas como un proceso separado y devuelve el estado de salida del proceso. Para más detalles, consulte JavaDoc para org.mozilla.javascript.tools.shell.Global#runCommand.
setTimeout(función[,retraso,arg,...])
Ejecuta "función" después de "retraso" milisegundos. (Si "retraso" no está establecido, entonces se establece en 0). Pasa cualquier parámetro posterior como argumentos. Los tiempos de espera se ejecutan después de que la función actual termine de ejecutarse, y en el intérprete interactivo, solo después de que el intérprete se cierre. Devuelve un ID que puede pasarse a "clearTimeout".
clearTimeout(id)
Cancela un tiempo de espera establecido usando "setTimeout".
serialize(objeto,archivo)
Serializa el objeto dado al archivo especificado.
spawn(función_o_script)
Ejecuta la función o script dado en un hilo diferente.
sync(función)
Crea una función sincronizada (en el sentido de un método sincronizado de Java) a partir de una función existente. La nueva función se sincroniza en el objeto `this` de su invocación.
quit()
Cerrar el intérprete. El intérprete también se cerrará en modo interactivo si se escribe un carácter de fin de archivo en el prompt.
version([número])
Obtiene o establece el número de versión de JavaScript. Si no se proporciona ningún argumento, se devuelve el número de versión actual. Si se proporciona un argumento, se espera que sea uno de 100, 110, 120, 130, 150, 160, 170, 180 o 200 para indicar las versiones 1.0, 1.1, 1.2, 1.3, 1.4, 1.5, 1.6, 1.7, 1.8 o ECMAScript 6 de JavaScript, respectivamente.
write([expresion...])
Evalúa e imprime expresiones como en "print", pero sin el salto de línea final.
console
El objeto console proporciona una consola de depuración simple similar al objeto console proporcionado por los navegadores web.
console.log(formato[arg,...])
Para la salida general de información de registro. Se admite la sustitución de cadenas y argumentos adicionales. Imprime texto formateado según el formato y los argumentos proporcionados con el prefijo "INFO". Esta función es idéntica a console.info(formato[arg,...]).
console.trace(formato[arg,...])
Esta función es idéntica a console.log(formato[arg,...]) excepto que imprime el prefijo "TRACE" en lugar de "INFO".
console.debug(formato[arg,...])
Esta función es idéntica a console.log(formato[arg,...]) excepto que imprime el prefijo "DEBUG" en lugar de "INFO".
console.info(formato[arg,...])
Esta función es idéntica a console.log(formato[arg,...]).
console.warn(formato[arg,...])
Esta función es idéntica a console.log(formato[arg,...]) excepto que imprime el prefijo "WARN" en lugar de "INFO".
console.error(formato[arg,...])
Esta función es idéntica a console.log(formato[arg,...]) excepto que imprime el prefijo "ERROR" en lugar de "INFO".

console.assert(expresión[arg,...])
Imprime un error si la expresión es falsa. Si se proporcionan argumentos, se imprimirán también.
console.count([etiqueta])
Incrementa el contador de la etiqueta en uno, que comienza desde cero, e imprime la etiqueta y el valor después de incrementar. Si no se proporciona etiqueta, la etiqueta será "default".
console.countReset([etiqueta])
Reinicia el contador de la etiqueta a cero. Si no se proporciona etiqueta, la etiqueta será "default".
console.time([etiqueta])
Inicia un temporizador con la etiqueta especificada. Usa console.timeEnd([etiqueta]) para detener el temporizador e imprimir el tiempo transcurrido. Usa console.timeLog([etiqueta]) para imprimir el tiempo transcurrido sin detener el temporizador.
console.timeLog([etiqueta])
Ver console.time([etiqueta]).
console.timeEnd([etiqueta])
Ver console.time([etiqueta]).
