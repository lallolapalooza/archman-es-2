RHYTHMBOX(1) Manual de Comandos Generales RHYTHMBOX(1)

NOMBRE

rhythmbox - reproductor de música y biblioteca para archivos con etiquetas usando GStreamer

SINOPSIS

rhythmbox [opción...]

DESCRIPCIÓN

rhythmbox es un programa muy fácil de usar para reproducir y gestionar música que soporta una amplia gama de formatos de audio (incluyendo mp3 y ogg). Originalmente inspirado en iTunes de Apple, la versión actual también soporta Radio por Internet e integración con Last.fm, sincronización con iPod y soporte genérico para reproductores de audio portátiles. Reproducción de CD de audio, ripeo y codificación, intercambio de música y Podcasts.

Por razones de rendimiento, las capacidades de control remoto se han movido del binario de rhythmbox a un programa separado. Consulte rhythmbox-client y la página del manual correspondiente para obtener documentación.

OPCIONES

-d, --debug
Habilitar salida de depuración
-D, --debug-match=patrón
Habilitar salida de depuración que coincida con una cadena especificada
--no-update
No actualizar la biblioteca con cambios de archivos
-n, --no-registration
No registrar el shell
--dry-run
No guardar ningún dato permanentemente (implica --no-registration)
--rhythmdb-file=archivo
Ruta para el archivo de base de datos a usar
--playlists-file=archivo
Ruta para el archivo de listas de reproducción a usar
--display=PANTALLA
Pantalla X a usar
-?, --help
Mostrar opciones de ayuda
--help-all
Mostrar todas las opciones de ayuda
--help-gst
Mostrar Opciones de GStreamer
--help-gtk
Mostrar Opciones de GTK+
--help-sm-client
Mostrar opciones de gestión de sesiones
