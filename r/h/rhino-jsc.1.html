RHINO-JSC(1) Manual de comandos generales RHINO-JSC(1)

NOMBRE

rhino-jsc - invoca el compilador JavaScript de rhino

SINOPSIS

rhino-jsc [opciones] archivo1.js [archivo2.js...]

DESCRIPCIÓN

Esta página del manual documenta brevemente el comando rhino-jsc. Esta página del manual fue escrita para la distribución de Debian porque el programa original no tiene una página del manual. Está escrita de acuerdo con la documentación HTML.

rhino-jsc es un script de inicio para el compilador JavaScript de rhino. El compilador JavaScript traduce el código fuente JavaScript a archivos de clase Java. Los archivos de clase Java resultantes pueden luego ser cargados y ejecutados en otro momento, proporcionando un método conveniente para transferir JavaScript y evitar costos de traducción. Tenga en cuenta que las funciones de nivel superior disponibles para el shell (como print) no están disponibles para los scripts compilados cuando se ejecutan fuera del shell.

OPCIONES

-extends nombre_clase_java
Especifica que se debe generar una clase Java que extienda la clase Java java_class_name a partir del archivo de código fuente JavaScript de entrada. Cada función global en el archivo fuente se convierte en un método de la clase generada, reemplazando cualquier método en la clase base con el mismo nombre.
-implements nombre_intf_java
Especifica que se debe generar una clase Java que implemente la interfaz Java java_intf_name a partir del archivo de código fuente JavaScript de entrada. Cada función global en el archivo fuente se convierte en un método de la clase generada, implementando cualquier método en la interfaz con el mismo nombre.
-debug, -g
Especifica que se debe generar información de depuración. No se puede combinar con optimización en un nivel de optimización (optLevel) mayor que cero.
-nosource
No guarda el código fuente en el archivo de clase. Las funciones y scripts compilados de esta manera no pueden ser decompilados. Esta opción se puede utilizar para evitar la distribución de código fuente o simplemente para ahorrar espacio en el archivo de clase resultante.
-o archivoSalida
Escribe el archivo de clase en el archivo dado (que debe terminar en .class). La cadena archivoSalida debe ser un nombre de archivo escribible.
-opt, -O nivelOpt
Optimiza en el nivel nivelOpt, que debe ser un número entero entre 0 y 9.
-package nombrePaquete
Especifica el paquete en el que generar la clase. La cadena nombrePaquete debe estar compuesta por caracteres de identificador válidos, opcionalmente separados por puntos.
-version numeroVersion
Especifica la versión del lenguaje con la que compilar. La cadena numeroVersion debe ser una de las siguientes: 100, 110, 120, 130 o 140. Consulte Versiones del lenguaje JavaScript para obtener más información sobre las versiones del lenguaje.

EJEMPLO

Ejemplo de compilación del applet NervousText.js escrito en JavaScript. El ejemplo se proporciona en el paquete librhino-java-doc.

$ rhino-jsc -extends java.applet.Applet -implements java.lang.Runnable NervousText.js
