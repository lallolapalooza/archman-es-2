RHINO-DEBUGGER(1) Manual de comandos generales RHINO-DEBUGGER(1)

NOMBRE

rhino-debugger - invoca la GUI del depurador de JavaScript de rhino

SINOPSIS

rhino-debugger [opciones] nombre_archivo_script_o_url [argumentos_script]

DESCRIPCIÓN

Esta página del manual documenta brevemente el comando rhino-debugger. Esta página del manual fue escrita para la distribución Debian porque el programa original no tiene una página del manual. Está escrita de acuerdo con la documentación HTML.

rhino-debugger es un script de inicio para el depurador de JavaScript de rhino. El depurador de JavaScript de Rhino es una GUI que permite la depuración de scripts de JavaScript interpretados ejecutados en Rhino. Tenga en cuenta que este depurador no funcionará con scripts de JavaScript ejecutados en el navegador mozilla, ya que Rhino no es el motor utilizado en dichos entornos.

OPCIONES

-e fuente_script
Ejecuta fuente_script como un script de JavaScript.
-f nombre_archivo_script_o_url
Lee el contenido de nombre_archivo_script_o_url y lo ejecuta como un script de JavaScript.
-opt, -O nivel_optimizacion
Optimiza en el nivel nivel_optimizacion, que debe ser un entero entre 0 y 9.
-version numero_version
Especifica la versión del lenguaje a compilar. El número de versión debe ser uno de 100, 110, 120, 130 o 140. Consulte Versiones del lenguaje JavaScript para obtener más información sobre las versiones del lenguaje.
-strict
Habilita el modo estricto.

EJEMPLO

Ejemplo de depuración del applet NervousText.js escrito en JavaScript. El ejemplo se proporciona en el paquete librhino-java-doc.

$ rhino-debugger NervousText.js

VER TAMBIÉN

La documentación en línea en http://www.mozilla.org/rhino/debugger.html
