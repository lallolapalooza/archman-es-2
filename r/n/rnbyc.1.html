RNBYC(1) Comandos de usuario RNBYC(1)

NOMBRE

rnbyc - Analizador y generador de JWK y JWT

DESCRIPCIÓN

rnbyc - Analizador y generador de JWK/JWKS, analizador y serializador de JWT, soporta JWT firmados, cifrados y anidados.

Versión 1.1.8

Opciones de línea de comandos:

-j --jwks

Acción: JWKS, analiza o genera claves y produce JWKS.

-g --generate <tipo>

Genera un par de claves o una clave simétrica de <tipo> - valores disponibles: RSA[tamaño de clave] (tamaño de clave predeterminado: 4096), EC256, EC384, EC521, Ed25519, Ed448, X25519, X448, oct[tamaño de clave] (tamaño de clave predeterminado: 128 bits).

-i --stdin

Lee la clave a analizar desde la entrada estándar (stdin).

-f --in-file

Lee la clave a analizar desde un archivo.

-k --key-id

Especifica el key-id a añadir a la clave actual.

-a --alg

Acción: JWKS - Especifica el valor alg a añadir a la clave actual. Acción: Serializar - Especifica el valor alg para firmar el token.

-e --enc

Especifica el valor enc para cifrar el token (A128CBC por defecto).

-l --enc-alg

Especifica el algoritmo de cifrado para la gestión de claves del token.

-o --out-file

Especifica el archivo de salida para las claves privadas (o todas las claves si no se especifica un archivo público) en el JWKS.

-p --out-file-public

Especifica el archivo de salida para las claves públicas en el JWKS.

-n --indent

Indentación de espacios en la salida JWKS: 0 es modo compacto, el valor predeterminado es indentación de 2 espacios.

-F --format

Formato de salida, los valores disponibles son JWK (predeterminado), PEM o DER.

-x --split

Divide la salida JWKS en claves públicas y privadas.

-t --parse-token

Acción: Analizar token.

-s --serialize-token

Acción: Serializar las reclamaciones (claims) dadas en un token.

-H --header

Mostrar la cabecera de un token analizado.

-C --claims

Mostrar las reclamaciones (claims) de un token analizado, por defecto es verdadero.

-P --public-key

Especifica la clave pública para el cifrado de gestión de claves o la verificación de firma. La clave pública debe estar en formato JWKS y puede ser una cadena JWKS o una ruta a un archivo JWKS.

-K --private-key

Especifica la clave privada para el descifrado de gestión de claves o la generación de firma. La clave pública debe estar en formato JWKS y puede ser una cadena JWKS o una ruta a un archivo JWKS.

-S --self-signed

Verifica la firma del JWT si el JWT firmado incluye su clave pública en la cabecera como parámetro 'jwk', 'x5c' o 'x5u'.

-W --password

Especifica la contraseña para el cifrado/descifrado de gestión de claves usando el alg PBES2 o la generación/verificación de firma usando el alg HS.

-u --x5u-flags

Establece las banderas x5u para recuperar certificados en línea, los valores disponibles son:
cert: ignora errores de certificado del servidor (autofirmados, caducados, etc.). follow: sigue la redirección jwks_uri si existe. Los valores se pueden concatenar, por ejemplo: --x5u-flags cert,follow.

-v --version

Imprime la versión actual de rnbyc.

-h --help

Imprime este mensaje.

-d --debug

Muestra mensajes de depuración.

VER TAMBIÉN

La documentación completa de rnbyc se mantiene como un manual Texinfo. Si los programas info y rnbyc están correctamente instalados en su sitio, el comando

info rnbyc

debería darle acceso al manual completo.
