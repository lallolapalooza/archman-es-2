NOMBRE

rndc-confgen - herramienta de generación de claves rndc

SINOPSIS

rndc-confgen [-a] [-A algoritmo] [-b tamañoclave] [-c archivoclave] [-h] [-k nombreclave] [-p puerto] [-s dirección] [-t dirchroot] [-u usuario]

DESCRIPCIÓN

rndc-confgen genera archivos de configuración para rndc <#std-iscman-rndc>. Puede ser utilizado como una alternativa conveniente a la escritura manual del archivo rndc.conf <#std-iscman-rndc.conf> y las correspondientes sentencias controls y key en named.conf <#std-iscman-named.conf>. Alternativamente, puede ser ejecutado con la opción -a para configurar un archivo rndc.key y evitar la necesidad de un archivo rndc.conf <#std-iscman-rndc.conf> y una sentencia controls por completo.

OPCIONES

-a
Esta opción configura la configuración automática de rndc <#std-iscman-rndc>, que crea un archivo /etc/rndc.key que es leído por rndc <#std-iscman-rndc> y named <#std-iscman-named> al inicio. El archivo rndc.key define un canal de comandos y una clave de autenticación por defecto, permitiendo que rndc <#std-iscman-rndc> se comunique con named <#std-iscman-named> en el host local sin configuración adicional.

Si se requiere una configuración más elaborada que la generada por rndc-confgen -a, por ejemplo, si rndc va a ser utilizado de forma remota, ejecute rndc-confgen sin la opción -a y configure rndc.conf <#std-iscman-rndc.conf> y named.conf <#std-iscman-named.conf> como se indica.

-A algoritmo
Esta opción especifica el algoritmo a usar para la clave TSIG. Las opciones disponibles son: hmac-md5, hmac-sha1, hmac-sha224, hmac-sha256, hmac-sha384 y hmac-sha512. El valor por defecto es hmac-sha256.
-b tamañoclave
Esta opción especifica el tamaño de la clave de autenticación en bits. El tamaño debe estar entre 1 y 512 bits; el valor por defecto es el tamaño del hash.
-c archivoclave
Esta opción se usa con la opción -a para especificar una ubicación alternativa para rndc.key.
-h
Esta opción imprime un resumen corto de las opciones y argumentos de rndc-confgen.
-k nombreclave
Esta opción especifica el nombre de la clave de autenticación de rndc <#std-iscman-rndc>. Debe ser un nombre de dominio válido. El valor por defecto es rndc-key.
-p puerto
Esta opción especifica el puerto del canal de comandos donde named <#std-iscman-named> escucha las conexiones de rndc <#std-iscman-rndc>. El valor por defecto es 953.
-q
Esta opción evita imprimir la ruta escrita en modo de configuración automática.
-s dirección
Esta opción especifica la dirección IP en la que named <#std-iscman-named> escucha las conexiones del canal de comandos de rndc <#std-iscman-rndc>. El valor por defecto es la dirección de loopback 127.0.0.1.
-t dirchroot
Esta opción se usa con la opción -a para especificar un directorio donde named <#std-iscman-named> se ejecuta en modo chroot. Se escribe una copia adicional de rndc.key relativa a este directorio, para que sea encontrada por el named <#std-iscman-named> en modo chroot.
-u usuario
Esta opción se usa con la opción -a para establecer el propietario del archivo rndc.key generado. Si también se especifica -t, solo el archivo en el área chroot tendrá su propietario cambiado.

EJEMPLOS

Para permitir el uso de rndc <#std-iscman-rndc> sin configuración manual, ejecute:

rndc-confgen -a

Para imprimir un archivo de ejemplo rndc.conf <#std-iscman-rndc.conf> y las correspondientes sentencias controls y key para ser insertadas manualmente en named.conf <#std-iscman-named.conf>, ejecute:

rndc-confgen
