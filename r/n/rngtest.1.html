RNGTEST(1) Manual de comandos generales RNGTEST(1)

NOMBRE

rngtest - Comprueba la aleatoriedad de los datos utilizando las pruebas FIPS 140-2

SINOPSIS

rngtest [-c n | --blockcount=n] [-b n | --blockstats=n] [-t n | --timedstats=n] [-p | --pipe] [-?] [--help] [-V] [--version]

DESCRIPCIÓN

rngtest trabaja en bloques de 20000 bits a la vez, utilizando las pruebas FIPS 140-2 (erratas de 2001-10-10) para verificar la aleatoriedad del bloque de datos.

Toma la entrada de stdin y genera estadísticas en stderr, opcionalmente repitiendo en stdout los bloques que pasaron las pruebas FIPS (cuando opera en modo pipe). Los errores se envían a stderr.

Al inicio, rngtest desechará los primeros 32 bits de los datos cuando opera en modo pipe. Usará los siguientes 32 bits de datos para inicializar las pruebas FIPS (incluso cuando no opera en modo pipe). Estos bits no se prueban para determinar su aleatoriedad.

Las estadísticas se volcarán a stderr cuando el programa salga.

OPCIONES

-p, --pipe
Habilita el modo pipe. Todos los bloques de datos que pasan las pruebas FIPS se repiten en stdout, y rngtest opera en modo silencioso.
-c n, --blockcount=n (predeterminado: 0)
Sale después de procesar n bloques de entrada, si n no es cero.
-b n, --blockstats=n (predeterminado: 0)
Genera estadísticas cada n bloques, si n no es cero.
-t n, --timedstats=n (predeterminado: 0)
Genera estadísticas cada n segundos, si n no es cero.
-?, --help
Muestra un resumen breve de todas las opciones del programa.
-V, --version
Imprime la versión del programa

ESTADÍSTICAS

rngtest volcará estadísticas a stderr al salir, y cuando se le indique mediante blockstats o timedstats.

Éxitos FIPS 140-2 y fallos FIPS 140-2 cuentan el número de bloques de 20000 bits aceptados o rechazados por las pruebas FIPS 140-2. Las otras estadísticas muestran un desglose de los fallos FIPS 140-2 por prueba FIPS 140-2. Consulte el documento FIPS 140-2 para obtener más información (tenga en cuenta que estas pruebas se definen en las erratas FIPS 140-1 y FIPS 140-2 del 2001-10-10. Fueron eliminadas en las erratas FIPS 140-2 del 2002-12-03).

Las estadísticas de velocidad se toman para cada bloque de 20000 bits transferido o procesado.

CÓDIGO DE SALIDA

0 si no ocurren errores y ningún bloque falla las pruebas FIPS.
1 si no ocurren errores, pero al menos un bloque falla las pruebas FIPS.
10 si hay problemas con los parámetros.
11 si ocurre un error de entrada/salida.
12 si ocurre un error del sistema operativo o de falta de recursos.
