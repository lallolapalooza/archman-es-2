RABBITMQ-ECHOPID.BAT(8) Manual del Administrador del Sistema RABBITMQ-ECHOPID.BAT(8)

NOMBRE

rabbitmq-echopid.bat — devuelve el ID de proceso de Windows del runtime de Erlang que ejecuta RabbitMQ

SINOPSIS

rabbitmq-echopid.bat sname

DESCRIPCIÓN

RabbitMQ es un broker de mensajería multiplataforma de código abierto.

Ejecutar rabbitmq-echopid.bat intentará descubrir y mostrar el ID de proceso (PID) del proceso de runtime de Erlang (erl.exe) que aloja RabbitMQ. Para permitir que erl.exe tenga tiempo de iniciarse y cargar RabbitMQ, el script esperará diez segundos antes de agotar el tiempo de espera si no se encuentra un PID adecuado.

Si se descubre un PID, el script lo mostrará en stdout antes de salir con un ERRORLEVEL de 0. Si no se descubre ningún PID antes de que expire el tiempo de espera, no se escribe nada en stdout y el script sale estableciendo ERRORLEVEL en 1.

Tenga en cuenta que este script solo existe en Windows debido a la necesidad de esperar a erl.exe y posiblemente a agotar el tiempo de espera. Para obtener el PID en Unix, establezca RABBITMQ_PID_FILE antes de iniciar rabbitmq-server(8) y no utilice -detached.

OPCIONES

sname
La forma de nombre corto del nombre del nodo de RabbitMQ.
