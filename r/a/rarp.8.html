RARP(8) Manual de Administrador del Sistema de Linux RARP(8)

NOMBRE

rarp - manipula la tabla RARP del sistema

SINOPSIS

rarp [-V] [--version] [-h] [--help]
rarp -a
rarp [-v] -d nombre_host ...
rarp [-v] [-t tipo] -s nombre_host dir_hw

NOTA

Este programa está obsoleto. A partir de la versión 2.3, el kernel de Linux ya no contiene soporte RARP. Para un demonio RARP de reemplazo, consulte ftp://ftp.dementia.org/pub/net-tools

DESCRIPCIÓN

Rarp manipula la tabla RARP del kernel de diversas maneras. Las opciones principales son borrar una entrada de mapeo de direcciones y configurar manualmente una. Para fines de depuración, el programa rarp también permite una volcado completo de la tabla RARP.

OPCIONES

-V
Muestra la versión de RARP en uso.
-v
Informa al usuario de lo que está sucediendo siendo verboso.
-t tipo
Al configurar o leer la tabla RARP, este parámetro opcional indica a rarp qué clase de entradas debe comprobar. El valor predeterminado de este parámetro es ether (es decir, código de hardware 0x01 para IEEE 802.3 Ethernet de 10 Mbps. Otros valores podrían incluir tecnologías de red como AX.25 (ax25) y NET/ROM (netrom).
-a
--listar
Lista las entradas en la tabla RARP.
-d nombre_host
--borrar nombre_host
Elimina todas las entradas RARP para el host especificado.
-s nombre_host dir_hw
--configurar nombre_host dir_hw
Crea una entrada de mapeo de direcciones RARP para el host nombre_host con la dirección de hardware establecida en dir_hw. El formato de la dirección de hardware depende de la clase de hardware, pero para la mayoría de las clases se puede asumir que se puede utilizar la presentación habitual. Para la clase Ethernet, son 6 bytes en hexadecimal, separados por dos puntos.

ADVERTENCIA

Algunos sistemas (notablemente los Sun más antiguos) asumen que el host que responde a una consulta RARP también puede proporcionar otros servicios de arranque remoto. Por lo tanto, nunca agregue entradas RARP gratuitamente a menos que desee encontrarse con la ira del administrador de la red.
