RADWHO(1) Demonio FreeRADIUS RADWHO(1)

NOMBRE

radwho - mostrar usuarios en línea

SINOPSIS

radwho [-c] [-d directorio_raddb] [-F archivo_radutmp] [-i] [-n] [-N direccion_ip_nas] [-p] [-P puerto_nas] [-r] [-R] [-s] [-S] [-u usuario] [-U usuario] [-Z]

DESCRIPCIÓN

El servidor FreeRADIUS puede configurarse para mantener una base de datos de sesiones activas en un archivo llamado radutmp. Esta utilidad muestra el contenido de esa base de datos de sesiones.

OPCIONES

-c
Muestra el identificador de llamada (si está disponible) en lugar del nombre completo.
-d directorio_raddb
El directorio que contiene los archivos de configuración de RADIUS. El valor predeterminado es /etc/raddb.
-F archivo_radutmp
El archivo que contiene el archivo radutmp. Si se especifica, -d no es necesario.
-i
Muestra el ID de sesión en lugar del nombre completo.
-n
Normalmente, radwho busca el nombre de usuario en el archivo de contraseñas del sistema y muestra el nombre de usuario completo también. La opción -n evita esto.
-N direccion_ip_nas
Mostrar solo las entradas que coincidan con la dirección IP NAS dada.
-p
Añade una columna extra para el tipo de puerto - I para ISDN, A para Analógico.
-P puerto_nas
Mostrar solo las entradas que coincidan con el puerto NAS dado.
-r
Genera todos los datos en formato raw (crudo): sin encabezados, sin formato, los campos están separados por comas.
-R
Genera todos los datos en formato de atributo RADIUS. Se imprimen todos los campos.
-s
Muestra el nombre completo.
-S
Ocultar usuarios de shell. No muestra las entradas de usuarios que no tengan una sesión SLIP o PPP.
-u usuario
Mostrar solo las entradas que coincidan con el nombre de usuario dado (sin distinguir mayúsculas y minúsculas).
-U usuario
Mostrar solo las entradas que coincidan con el nombre de usuario dado (distinguiendo mayúsculas y minúsculas).
-Z
Cuando se combina con -R, imprime el contenido de un paquete Accounting-Request que puede pasarse a radclient, para eliminar la sesión de ese usuario de radutmp.

Por ejemplo,

$ radwho -ZRN 10.0.0.1 | radclient -f - radius.example.net acct testing123
resultará en el envío de un paquete Accounting-Request al servidor RADIUS, que le indica al servidor que el NAS se reinició. Es decir, elimina ("zaps") a todos los usuarios de ese NAS.

Para eliminar a un solo usuario, especifique NAS, nombre de usuario y puerto NAS:

$ radwho -ZRN 10.0.0.1 -u usuario -P 10 | radclient -f - radius.example.net acct testing123
También son posibles otras combinaciones.

VER TAMBIÉN

radiusd(8), radclient(1), radiusd.conf(5).
