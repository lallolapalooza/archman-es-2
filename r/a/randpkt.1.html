NOMBRE

randpkt - Generador de paquetes aleatorios

SINOPSIS

randpkt [ -b <maxbytes> ] [ -c <count> ] [ -F <formato_archivo> ] [ -r ] [ -t <tipo> ] <nombre_archivo>

randpkt -h|--help

randpkt -v|--version

DESCRIPCIÓN

randpkt es una pequeña utilidad que crea un archivo de traza lleno de paquetes aleatorios.

Al crear muchos paquetes aleatorizados de un cierto tipo, puedes probar los analizadores de paquetes (sniffers) para ver qué tan bien manejan paquetes mal formados. El analizador nunca puede confiar en los datos que ve en el paquete porque siempre puedes analizar un paquete muy malo que no cumple con ningún estándar. randpkt produce paquetes *muy malos*.

Al crear paquetes de un cierto tipo, randpkt utiliza un paquete de muestra que se almacena internamente en randpkt. Lo usa como punto de partida para tus paquetes aleatorios, y luego agrega bytes aleatorios adicionales al final de este paquete de muestra.

Por ejemplo, si eliges crear paquetes ARP aleatorios, randpkt creará un paquete que contenga una cabecera Ethernet II predeterminada, con el campo Tipo establecido en ARP. Después de la cabecera Ethernet II, pondrá un número aleatorio de bytes con valores aleatorios.

OPCIONES

-b <maxbytes>

Por defecto 5000.

Define el número máximo de bytes agregados al paquete de muestra. Si eliges un valor de maxbytes menor que el tamaño del paquete de muestra, tus paquetes contendrán solo el paquete de muestra... ¡no mucha varianza! randpkt saldrá en esa condición.

-c <count>

Por defecto 1000.

Define el número de paquetes a generar.

-F <formato_archivo>

Por defecto pcapng.

Establece el formato del archivo de captura de salida. randpkt puede escribir el archivo en varios formatos; randpkt -F proporciona una lista de los formatos de salida disponibles. Ten en cuenta que no todos los formatos de salida soportan todos los tipos de paquetes.

-h|--help

Imprime el número de versión y las opciones y sale.

-r

El tipo de paquete se determina aleatoriamente para cada paquete. Esto requiere un formato de salida que pueda admitir diferentes encapsulaciones por paquete, como pcapng.

-t <tipo>

Por defecto trama Ethernet II.

Define el tipo de paquete a generar:

arp             Protocolo de Resolución de Direcciones
bgp             Protocolo de Gateway de Borde
bvlc            BACnet Virtual Link Control
dns             Servicio de Nombres de Dominio
eth             Ethernet
fddi            Interfaz de Datos Distribuida por Fibra
giop            General Inter-ORB Protocol
icmp            Protocolo de Mensajes de Control de Internet
ip              Protocolo de Internet
ipv6            Protocolo de Internet Versión 6
llc             Control de Enlace Lógico
m2m             Protocolo de Encapsulación M2M de WiMAX
megaco          MEGACO
nbns            Servicio de Nombres NetBIOS sobre TCP
ncp2222         Protocolo Central NetWare
sctp            Protocolo de Control de Transmisión de Flujo
syslog          Mensaje Syslog
tds             TDS NetLib
tcp             Protocolo de Control de Transmisión
tr              Token-Ring
udp             Protocolo de Datagrama de Usuario
usb             Bus Universal en Serie
usb-linux       Bus Universal en Serie con cabecera específica de Linux

-v|--version

Imprime la información completa de la versión y sale.

OPCIONES DE DIAGNÓSTICO

--log-level <nivel>

Establece el nivel de registro activo. Los niveles admitidos en orden de menor a mayor son "noisy", "debug", "info", "message", "warning", "critical" y "error". Los mensajes en cada nivel y superiores se imprimirán, por ejemplo, "warning" imprime los mensajes "warning", "critical" y "error", y "noisy" imprime todos los mensajes. Los niveles no distinguen entre mayúsculas y minúsculas.

--log-fatal <nivel>

Aborta el programa si se registran mensajes en el nivel especificado o superior. Por ejemplo, "warning" aborta ante cualquier mensaje de "warning", "critical" o "error".

--log-domains <lista>

Solo imprime mensajes para los dominios de registro especificados, por ejemplo, "GUI,Epan,sshdump". La lista de dominios debe estar separada por comas. Puede ser negada con "!" como primer carácter (invierte la coincidencia).

--log-debug <lista>

Fuerza a los dominios especificados a registrarse en el nivel "debug". La lista de dominios debe estar separada por comas. Puede ser negada con "!" como primer carácter (invierte la coincidencia).

--log-noisy <lista>

Fuerza a los dominios especificados a registrarse en el nivel "noisy". La lista de dominios debe estar separada por comas. Puede ser negada con "!" como primer carácter (invierte la coincidencia).

--log-fatal-domains <lista>

Aborta el programa si se registran mensajes para los dominios de registro especificados. La lista de dominios debe estar separada por comas.

--log-file <ruta>

Escribe los mensajes de registro y la salida de stderr en el archivo especificado.

EJEMPLOS

Para ver una descripción de las opciones de randpkt usa:

randpkt

Para generar un archivo de captura con 1000 paquetes DNS usa:

randpkt -b 500 -t dns rand_dns.pcapng

Para generar un archivo de captura pequeño con solo una trama LLC usa:

randpkt -b 100 -c 1 -t llc single_llc.pcapng
