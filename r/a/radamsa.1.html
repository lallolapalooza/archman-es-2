radamsa(1) Manual de Comandos Generales radamsa(1)

NOMBRE

radamsa - un fuzzer de propósito general

SINOPSIS

radamsa [opciones] [ruta-muestra] ...

DESCRIPCIÓN

Radamsa es un fuzzer de datos de propósito general. Lee datos de archivos de muestra dados, o de la entrada estándar si no se proporcionan, y genera datos modificados. Generalmente se utiliza para generar datos malformados para probar programas.

OPCIONES

Este programa sigue la sintaxis habitual de línea de comandos de GNU, con opciones largas que comienzan con dos guiones (`-'). A continuación se incluye un resumen de las opciones.

-h, --help
Muestra un resumen más corto de las opciones.
-V, --version
Muestra la versión del programa.
-o, --output patrón
Especifica dónde escribir los datos modificados. Por defecto, los datos se escriben en la salida estándar. El patrón puede ser una ruta, en la que %n se rellena con el número de caso de prueba si está presente, :n para que los datos se envíen a los clientes TCP que se conecten al puerto local n, o a.b.c.d:n para que radamsa se conecte al puerto n de la dirección IPv4 a.b.c.d para enviar cada salida.
-n, --count n
Cuántas salidas generar basadas en la(s) muestra(s). Dar -1 o inf genera datos de forma continua. El valor predeterminado es 1.
-s, --seed n
Comienza desde el estado aleatorio n, que es un número decimal. Comenzar desde el mismo estado aleatorio con los mismos argumentos de línea de comandos y muestras genera las mismas salidas. Si no se especifica una semilla explícitamente, radamsa lee una semilla aleatoria de /dev/urandom o toma la hora actual en milisegundos.
-M, --meta ruta
Escribe metadatos sobre los datos generados en la ruta dada. Se puede usar - para escribir los metadatos en la salida estándar. Los metadatos contienen la semilla seguida de una línea por cada caso de prueba.
-l, --list
Muestra todas las mutaciones, patrones y generadores disponibles junto con sus descripciones.
-r, --recursive
Incluye muestras de directorios de forma recursiva.
-v, --verbose
Imprime lo que se está haciendo.
-m, --mutations cadena
Solicita las probabilidades de mutación iniciales manualmente. Generalmente no se recomienda y las opciones cambiarán en versiones futuras.
-p, --patterns cadena
Solicita los patrones de mutación manualmente. Generalmente no se recomienda y las opciones cambiarán en versiones futuras.
-g, --generators cadena
Solicita las probabilidades del generador de flujo de datos manualmente. Generalmente no se recomienda y las opciones cambiarán en versiones futuras.

EJEMPLOS


$ cat archivo | radamsa | programa -
$ radamsa muestras/*.foo | programa -
$ radamsa -o test-%n.foo -n 100 muestras/*.foo
$ radamsa -o :80 -n inf muestras/*.resp
$ radamsa -o 127.0.0.1:80 -n inf muestras/*.req
