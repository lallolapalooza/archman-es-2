RAX2(1) Manual de comandos generales RAX2(1)

NOMBRE

rax2 — convertidor base de radare

SINOPSIS

rax2 [-ebBsSvxkKh] [[expresión] ...]

DESCRIPCIÓN

Este comando es parte del proyecto radare.

Rax2 es una calculadora potente dentro de la suite Radare2, utilizada principalmente para conversiones de sistemas numéricos, codificación y decodificación de cadenas C, pares hexadecimales y base64, esencial para tareas de análisis binario e ingeniería inversa.

Las bases numéricas más comunes incluyen binario (base 2) para interacción directa con código máquina, hexadecimal (base 16) para direcciones de memoria y representación de datos compacta, y decimal (base 10) para cálculos e interpretaciones legibles por humanos.

OPCIONES

-a
Mostrar tabla ASCII
-b
Forzar modo de salida (base numérica)


f punto flotante
2 binario
3 ternario
8 octal
10 decimal
16 hexadecimal

-c
Mostrar cadena C hexadecimal a partir de un valor entero
-C
Volcar stdin a un array C en stdout (reemplazo de xxd)
-d
Imprimir el resultado en decimal (base 10)
-D
Decodificar los datos de entrada usando base64
-e
Intercambiar el orden de los bytes (endianness)
-E
Codificar los datos de entrada usando base64
-f
Interpretar el número de entrada como un dword de 32 bits y mostrarlo usando el estándar IEEE 754 para aritmética de punto flotante
-F
Leer cadenas C de stdin y mostrar en pares hexadecimales. Útil para cargar shellcodes
-h
Mostrar mensaje de ayuda de uso
-k
Mantener la misma base que los datos de entrada
-K
Mostrar arte ASCII de clave randomart para valores o pares hexadecimales
-H
Convertir una cadena a un hash
-i
Convertir LONG a/desde DIRECCIÓN IP
-j
Mostrar la salida en formato json, igual que el comando de r2 `?j 0x804`.
-n
Añadir nueva línea a la salida decodificada para que sea más amigable
-o
Convertir de cadena octal a carácter (rax2 -o 162 62)
-q
Silencioso. Mostrar menos información o eliminar los detalles superfluos en la salida. Por ejemplo: rax2 -qC
-r
Mostrar la misma salida que el comando `? 0x804` de r2. Cuando se combina con -S (-rS) imprimirá comandos r2 para escribir el binario actual en radare2
-s
Convertir de cadena de pares hexadecimales a carácter (rax2 -s 43 4a 50)
-S
Convertir de carácter a cadena hexadecimal (rax2 -S C J P)
-t
Convertir marca de tiempo epoch a formato de fecha legible por humanos
-u
Convertir el valor dado a formato de unidades legibles por humanos
-v
Mostrar la versión del programa
-w
Mostrar el resultado como un valor entero con signo de 16 bits
-x
Mostrar pares hexadecimales a partir de un valor entero
-X
Convertir un flujo de bits (una secuencia arbitraria de 0 y 1 de cualquier longitud) a hexadecimal. El resultado puede ser mayor que 64 bits
-z
Convertir de cadena de caracteres a binario (rax2 -z hola)
-Z
Convertir de cadena binaria a cadena (rax2 -l 01000101)

USO

Los tipos de variable disponibles son:


int -> hex rax2 10
hex -> int rax2 0xa
-int -> hex rax2 -77
-hex -> int rax2 0xffffffb3
int -> bin rax2 b30
bin -> int rax2 1010d
float -> hex rax2 3.33f
hex -> float rax2 Fx40551ed8
oct -> hex rax2 35o
hex -> oct rax2 Ox12 (O es una letra)
bin -> hex rax2 1100011b
hex -> bin rax2 Bx63

EJEMPLOS

Sin argumentos, rax2 lee valores de stdin. Puede pasar uno o más valores como argumentos.


$ rax2 33 0x41 0101b
0x21
65
0x5

Puede "desempaquetar" cadenas codificadas en pares hexadecimales fácilmente.


$ rax2 -s 41 42 43
ABC

Admite algunas operaciones matemáticas:


$ rax2 1+1 "0x5*101b+5"
2
30

Codificar y decodificar un archivo binario usando base64:


$ rax2 -E < /bin/ls > ls.b64
$ rax2 -D < ls.b64 > ls


$ cmp /bin/ls ls && echo $?
0

Use -z/-Z para convertir entre binario y cadena:


$ rax2 -z hola
01101000011011110110110001100001
$ rax2 -Z 0110100001100101011011000110110001101111
hello

Es una herramienta muy útil para scripting, por lo que puede leer valores de punto flotante, u obtener el desplazamiento entero de un salto o una delta de pila al analizar programas.
