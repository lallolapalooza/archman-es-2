NOMBRE

"razor-check" - Agente de Filtrado Razor

SINOPSIS

razor-check [opciones]  [ correo1 [ correo2 .. ] ]
$ cat mbox | razor-check
$ razor-check ./mbox
$ razor-check -d mbox correo.1 correo.2 correo.3

DESCRIPCIÓN

"razor-check" comprueba un correo contra el Catálogo Distribuido Razor comunicándose con un Servidor de Catálogo Razor. Debería invocarse antes de que el correo sea entregado o procesado por un humano. "razor-check" termina con valor de salida 0 si la firma del correo está catalogada en el servidor (spam) o 1 si el correo no está catalogado por el servidor (no es spam). "razor-check" debería ser invocado contra cada correo entrante por procesadores de correo (como procmail) o MTAs (como sendmail). Un método alternativo sería llamar a "razor-check" desde cron, a intervalos regulares, para identificar y marcar spam en buzones en cola.

Si a "razor-check" se le pasan más de un correo, comprobará cada uno contra la base de datos, imprimiendo el número de serie de cada correo considerado spam. "razor-check" soporta archivos con formato mbox con 1 o más correos en ellos, así como archivos que contienen un solo correo RFC 822 (no-mbox). Puede haber más de un archivo presente en la línea de comandos, que pueden ser no-mbox o mbox en cualquier orden. Sin embargo, no se pueden leer más de un correo no-mbox desde stdin.

USO

"razor-check" se ejecuta normalmente canalizando el contenido del correo hacia él, o proporcionando el nombre del archivo que contiene el mensaje de correo a comprobar como último argumento. "razor-check" toma los siguientes argumentos:

"-h"
Imprime un mensaje de uso y sale.
"-v"
Imprime el número de versión y sale.
"-d | --verbose"
Imprime información de depuración.
"-debuglevel=n | -dl=n"
Establece el nivel de depuración a 'n'. El valor por defecto es 3 sin la opción "-d", y 9 con ella.
"-whitelist=archivo"
Especifica el archivo a usar para la lista blanca. Sobrescribe la opción 'whitelist' en "razor-agent.conf".
"-s"
Simula una comprobación. Hace todo excepto hablar con el servidor.
"-conf=nombrearchivo"
Especifica un archivo de configuración alternativo. Si no se especifica, se calcula, consulta el manual de razor-agents(1) para más detalles. Consulta el manual de razor-agent.conf(5) para varias opciones de configuración. El valor por defecto es "<razorhome>/razor-agent.conf".
"-home=dir"
Especifica el directorio razorhome. Aquí es donde residen el archivo de configuración, los archivos de registro, las identidades y los archivos del servidor. Si no se especifica, se calcula, consulta el manual de razor-agents(1) para más detalles.
"-logfile=archivo"
Especifica el archivo al que registrar en lugar de lo que está en el archivo de configuración. El valor por defecto es "<razorhome>/razor-agent.log".
"-rs=razor.server.com"
Usa este Servidor de Catálogo Razor en lugar de leer "servers.catalogue.lst".
"-H"
Calcula e imprime la firma del contenido del correo y sale. Si no se especifica "-e=entero", se usarán todos los motores soportados.
"-S=cadena"
Acepta una lista de firmas precalculadas (con "-H") en la línea de comandos, en lugar de calcular una a partir del contenido del correo. Las firmas se pueden enviar en formato hexadecimal o base64, pero se prefiere base64. Requiere "-e=entero". Uso:

"razor-report -e 1 -S a8a3d545adb73f9733675571ffeaf10cba87745b"

"-e=entero"
Especifica el motor utilizado para crear firmas. Debe ser 1, 2, 3 o 4 en esta versión. El motor 1, o "-e=1", se utiliza para las firmas de Razor 1.x. Se usa solo con "-S=cadena" o "-H".
"-ep4=cadena"
Cadena utilizada por el motor 4 al calcular firmas. Publicada por los Servidores de Catálogo Razor y actualizada muy frecuentemente. Se usa solo cuando "-e=4".

RECETAS

"razor-check" se invoca normalmente desde procmail(1). Aquí hay algunas formas comunes de usarlo con procmail:

Para cambiar la cabecera "Subject" si el correo es spam:
:0 Wc
| razor-check
:0 Waf
| formail -i "Subject: Advertencia de Razor: SPAM/UBE/UCE"
Para añadir una cabecera "X-Razor2-Warning" al spam:
:0 Wc
| razor-check
:0 Waf
| formail -A "X-Razor2-Warning: SPAM."
Para archivar spam en un buzón
:0 Wc
| razor-check
:0 Wa
/home/foo/Mail/razor-caught
