RADDEBUG(8) Servidor de FreeRADIUS RADDEBUG(8)

NOMBRE

raddebug - Muestra la salida de depuración de un servidor en ejecución.

SINOPSIS

raddebug [-c condición] [-d directorio_de_configuración] [-D directorio_de_diccionarios] [-n nombre] [-i dirección_ipv4] [-I dirección_ipv6] [-f archivo_socket] [-t tiempo_de_espera] [-u nombre_de_usuario]

DESCRIPCIÓN

raddebug es un script de shell que envuelve a radmin y automatiza el proceso de obtención de salida de depuración de un servidor en ejecución. Lo hace sin afectar la disponibilidad del servicio, a diferencia de usar radiusd -X. Existen varios prerrequisitos necesarios para su correcto funcionamiento:


* radmin debe estar disponible en el PATH.
* El usuario que ejecuta raddebug debe tener permiso para conectarse al
socket de control del servidor.
* El socket de control debe estar configurado. Para obtener instrucciones, consulte
raddb/sites-available/control-socket
* El socket de control debe estar marcado como "mode = rw".
* El usuario que ejecuta raddebug debe tener permiso para leer y
escribir archivos en el directorio "logdir". Este es generalmente
/var/log/radiusd.

Por varias razones, la salida de depuración se coloca en un archivo intermedio, en lugar de enviarse directamente a la salida estándar. Para evitar que este archivo crezca demasiado, el programa raddebug se termina automáticamente después de 10 segundos. Este tiempo de espera se puede cambiar a través del parámetro "-t".

Cuando el script sale, el modo de depuración en el servidor se deshabilita y el archivo intermedio se elimina.

La salida de depuración de un servidor en vivo se puede redirigir a una sola ubicación. Si se inicia una segunda instancia de raddebug mientras la primera todavía se está ejecutando, la segunda anulará la primera, y la primera dejará de producir salida.

OPCIONES

-c condición
Establece una condición de depuración específica. El formato de la condición es como se especifica en la sección CONDITIONS de la página del manual de unlang.
-f archivo_socket
La ruta al socket de control. Consulte la página del manual de radmin para obtener más descripción de esta opción.
-i dirección_ipv4
Muestra la salida de depuración para el cliente con la dirección IPv4 dada. Esta opción es equivalente a usar:

-c '(Packet-Src-IP-Address == ipv4-address)'
-d directorio_de_configuración
El directorio de configuración de radius, generalmente /etc/raddb. Consulte la página del manual de radmin para obtener más descripción de esta opción.
-D directorio_de_diccionarios
Establece el directorio principal de diccionarios. Por defecto es /usr/share/freeradius.
-n nombre
Lee raddb/name.conf en lugar de raddb/radiusd.conf.
-I dirección_ipv6
Muestra la salida de depuración para el cliente con la dirección IPv6 dada. Esta opción es equivalente a usar:

-c '(Packet-Src-IPv6-Address == ipv6-address)'
-t tiempo_de_espera
Deja de imprimir la salida de depuración después de "tiempo_de_espera" segundos. El tiempo de espera predeterminado es de sesenta (60) segundos. Use "-t 0" para imprimir la salida de depuración indefinidamente, o hasta que el script salga.
-u nombre
Muestra la salida de depuración para los usuarios con el nombre dado. Esta opción es equivalente a usar:

-c '(User-Name == name)'

VER TAMBIÉN

radmin(8), raddb/sites-available/control-socket, unlang(5), radiusd.conf(5)
