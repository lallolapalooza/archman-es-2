NOMBRE

randpktdump - Proporciona una interfaz para generar capturas aleatorias utilizando randpkt

SINOPSIS

randpktdump [ --help ] [ --version ] [ --extcap-interfaces ] [ --extcap-dlts ] [ --extcap-interface=<interfaz> ] [ --extcap-config ] [ --capture ] [ --fifo=<ruta a archivo o tubería> ] [ --maxbytes=<bytes> ] [ --count=<número> ] [ --delay=<ms> ] [ --random-type=<true|false> ] [ --all-random=<true|false> ] [ --type=<tipo de paquete> ]

DESCRIPCIÓN

randpktdump es una herramienta extcap que proporciona acceso al generador de paquetes aleatorios (randpkt). Se utiliza principalmente para fines de prueba y educativos.

OPCIONES

--help

Imprime los argumentos del programa.

--version

Imprime la versión del programa.

--extcap-interfaces

Lista las interfaces disponibles.

--extcap-interface=<interfaz>

Utiliza la interfaz especificada.

--extcap-dlts

Lista los DLT de la interfaz especificada.

--extcap-config

Lista las opciones de configuración de la interfaz especificada.

--capture

Comienza a capturar desde la interfaz especificada y la guarda en la ubicación especificada por --fifo.

--fifo=<ruta a archivo o tubería>

Guarda el paquete capturado en un archivo o lo envía a través de una tubería.

--maxbytes=<bytes>

Establece el número máximo de bytes por paquete.

--count=<número>

Número de paquetes a generar (-1 para infinito).

--delay=<ms>

Espera un número de milisegundos después de escribir cada paquete.

--random-type

Elige un tipo de paquete aleatorio para todos los paquetes si se establece en true.

--all-random

Elige un tipo de paquete aleatorio diferente para cada paquete si se establece en true.

--type=<tipo de paquete>

Utiliza el tipo de paquete seleccionado. Para listar todos los tipos de paquete disponibles, ejecuta randpktdump --help.

EJEMPLOS

Para ver los argumentos del programa:

randpktdump --help

Para ver la versión del programa:

randpktdump --version

Para ver las interfaces:

randpktdump --extcap-interfaces

Salida de ejemplo

interface {value=randpkt}{display=Generador de paquetes aleatorios}

Para ver los DLTs de la interfaz:

randpktdump --extcap-interface=randpkt --extcap-dlts

Salida de ejemplo

dlt {number=1}{name=randpkt}{display=Ethernet}

Para ver las opciones de configuración de la interfaz:

randpktdump --extcap-interface=randpkt --extcap-config

Salida de ejemplo

arg {number=0}{call=--maxbytes}{display=Bytes máximos en un paquete}{type=unsigned}{range=1,5000}{default=5000}{tooltip=El número máximo de bytes en un paquete}
arg {number=1}{call=--count}{display=Número de paquetes}{type=long}{default=1000}{tooltip=Número de paquetes a generar (-1 para infinito)}
arg {number=2}{call=--delay}{display=Retraso de paquetes (ms)}{type=long}{default=0}{tooltip=Milisegundos de espera después de escribir cada paquete}
arg {number=3}{call=--random-type}{display=Tipo aleatorio}{type=boolflag}{default=false}{tooltip=El tipo de paquetes se elige aleatoriamente}
arg {number=4}{call=--all-random}{display=Todos los paquetes aleatorios}{type=boolflag}{default=false}{tooltip=El tipo de paquete para cada paquete se elige aleatoriamente}
arg {number=5}{call=--type}{display=Tipo de paquete}{type=selector}{tooltip=Tipo de paquete a generar}
value {arg=5}{value=arp}{display=Protocolo de resolución de direcciones}
[...]
value {arg=5}{value=usb-linux}{display=USB con encabezado específico de Linux}

Para capturar:

randpktdump --extcap-interface=randpkt --fifo=/tmp/randpkt.pcapng --capture

Nota

Para detener la captura, presiona CTRL+C o termina la aplicación con kill.
