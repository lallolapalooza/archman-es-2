RASIGN2(1) Manuales de usuario de Rasign2 RASIGN2(1)

NOMBRE

rasign2 - una herramienta para generar y gestionar firmas de archivos binarios

SINOPSIS

rasign2 [opciones] [archivo]

DESCRIPCIÓN

La herramienta rasign2 está diseñada para crear, volcar y gestionar archivos de firmas (bases de datos de firmas, SDB) para análisis binario. Facilita la generación de bases de datos de firmas a partir de archivos binarios, lo que facilita la identificación y catalogación de funciones y otros símbolos. La herramienta puede interpretar archivos FLIRT 'I.sig', ejecutar scripts personalizados de Radare2 y generar firmas en múltiples formatos.

OPCIONES

-a
Realiza un análisis más exhaustivo añadiendo 'a' adicionales al comando de análisis. Cuantas más 'A' haya, más profundo será el análisis.
-A[AAA]
Equivalente a r2 -A
-f
Interpreta el archivo de entrada como un archivo FLIRT 'I.sig' y vuelca sus firmas.
-h
Muestra el menú de ayuda.
-j
Genera las firmas en formato JSON.
-i script.r2
Ejecuta el script de Radare2 especificado en el archivo de entrada.
-o sigs.sdb
Añade las firmas generadas al archivo especificado. Crea el archivo si no existe.
-q
Activa el modo silencioso, suprimiendo la salida normal.
-r
Muestra la salida como comandos de Radare2.
-S
Opera sobre un archivo de firmas SDB. Usa '-o -' para guardar en el mismo archivo.
-s signspace
Guarda todas las firmas bajo el espacio de nombres de firmas especificado.
-c
Añade firmas de colisión antes de escribir en un archivo.
-v
Muestra la información de la versión.
-m
Fusiona o sobrescribe firmas con el mismo nombre.

EJEMPLOS DE USO

Generación básica de firmas:

rasign2 -o libc.sdb libc.so.6
Este comando genera firmas a partir de 'libc.so.6' y las guarda en 'libc.sdb'.

Análisis mejorado:

rasign2 -A -o enhanced_libc.sdb libc.so.6
Esto realiza un análisis más profundo antes de generar firmas, lo que puede descubrir más funciones.

Salida en comandos de Radare2:

rasign2 -r input_file | grep main
Imprime las firmas descubiertas para 'main' como comandos de Radare2.

Salida JSON:

rasign2 -j input_file
Genera las firmas en formato JSON.

Fusión de firmas:

rasign2 -m -o existing_sigs.sdb new_sigs.sdb
Fusiona o sobrescribe firmas en 'existing_sigs.sdb' con las de 'new_sigs.sdb'.

EL COMANDO Z EN RADARE2

El comando z en radare2 está dedicado a la gestión de firmas binarias, conocidas como zignatures. Las zignatures se utilizan para identificar y catalogar funciones en diferentes binarios por sus características únicas, como patrones de bytes, métricas de grafos y otros atributos.

OPCIONES DE CONFIGURACIÓN

El comportamiento del procesamiento de zignatures se puede ajustar a través de una variedad de opciones de configuración, accesibles mediante 'e??zign.' en radare2. Algunas opciones de configuración clave incluyen:

zign.autoload
Carga automáticamente todas las zignatures ubicadas en dir.zigns.
zign.bytes
Usa patrones de bytes para la coincidencia.
zign.graph
Usa métricas de grafos para la coincidencia.
zign.hash
Usa Hash para la coincidencia.
zign.threshold
Similitud mínima requerida para la inclusión en la salida de zb.
zign.types
Usa tipos para la coincidencia.

AÑADIENDO ZIGNATURES

Las zignatures se pueden añadir con el comando 'za', que soporta una variedad de tipos como patrones de bytes, métricas de grafos y más.

za foo b 558bec..e8........
Añade una zignature de patrón de bytes.
za foo g cc=2 nbbs=3 edges=3 ebbs=1
Añade una zignature de métricas de grafos.

COMANDOS DE ZIGNATURE

El comando z engloba varios subcomandos para gestionar las zignatures:

z
Muestra las zignatures.
z.
Busca zignatures coincidentes en el offset actual.
zb
Busca la mejor coincidencia.
zdzignature
Compara la función actual y la zignature.
z*
Muestra las zignatures en formato radare.
zo
Gestiona archivos de zignatures.
zf
Gestiona firmas FLIRT.
z/
Busca zignatures.
zc
Compara las zignatures del espacio de nombres de zignatures actual con otro.
zs
Gestiona espacios de nombres de zignatures.
zi
Muestra información de coincidencia de zignatures.

La gestión integral de zignatures a través de estos comandos facilita un flujo de trabajo robusto para el análisis binario, permitiendo la identificación de funciones conocidas y facilitando el análisis de similitudes y diferencias binarias.

MÉTRICAS DE ZIGNATURE SOPORTADAS

Las zignatures en radare2 se pueden crear con una variedad de métricas, cada una capturando diferentes aspectos de las funciones binarias. Estas métricas incluyen:

a: patrón de bytes
Radare2 crea una máscara a partir del análisis para hacer coincidir patrones de bytes.
b: patrón de bytes
Coincidencia directa de patrones de bytes.
c: comentario en base64
Asocia un comentario codificado en base64 con la zignature.
n: nombre real de la función
Utiliza el nombre real de la función para la coincidencia.
g: métricas de grafos
Utiliza métricas de grafos como complejidad ciclomática, número de aristas, bloques básicos y bloques finales.
o: offset original
Coincide basándose en el offset original de la función.
r: referencias
Utiliza referencias para la coincidencia.
x: referencias cruzadas
Incorpora referencias cruzadas en la zignature.
h: hash
Utiliza el hash del código de la función para la coincidencia.

ZIGNATURE COMMANDS

Radare2's `z` command is used for managing and manipulating zignatures. Zignatures are a powerful feature for identifying and classifying functions within a binary, enabling more efficient reverse engineering and analysis.

SUPPORTED ZIGNATURE METRICS

The following metrics are supported for generating and matching zignatures:

h: bbhash
Emplea el hash de los bloques básicos de la función para la coincidencia.
v: vars (and args)
Coincide basándose en variables y argumentos.

Cada métrica permite un enfoque matizado para identificar y comparar funciones entre binarios, permitiendo un análisis más preciso y completo.

EJEMPLOS DE USO PARA EL COMANDO Z

El comando z en radare2 es versátil, ofreciendo diversas funcionalidades a través de sus subcomandos. Aquí hay cinco ejemplos de uso:

Mostrar todas las zignaturas
z
Muestra todas las zignaturas cargadas actualmente en radare2.
Encontrar zignaturas coincidentes en la posición actual
z.
Busca y muestra las zignaturas que coinciden en la posición actual del binario.
Escanear todas las funciones para encontrar zignaturas coincidentes
z/
Busca y compara todas las firmas cargadas con todas las funciones analizadas para dar un nombre a cada una.
Cargar archivos de zignaturas
zo libc.sdb
Carga las zignaturas del archivo SDB especificado en la sesión actual.
Generar zignaturas para todas las funciones
zaF
Genera zignaturas para todas las funciones identificadas en el binario y las añade a la sesión actual.
Buscar las zignaturas coincidentes más cercanas
zb
Busca y muestra las zignaturas coincidentes más cercanas a la función en la posición actual, ayudando a identificar funciones similares entre binarios.

Estos ejemplos muestran la capacidad del comando `z` para gestionar eficientemente las zignaturas, ayudando en el proceso de análisis binario al aprovechar el poder de las zignaturas para la identificación y comparación de funciones.
