RABBITMQ-PLUGINS(8) Manual del Administrador del Sistema RABBITMQ-PLUGINS(8)

NOMBRE

rabbitmq-plugins — herramienta de línea de comandos para gestionar plugins de RabbitMQ

SINOPSIS

rabbitmq-plugins [-q] [-s] [-l] [-n nodo] [-t tiempo_espera] comando [opciones_comando]

DESCRIPCIÓN

rabbitmq-plugins es una herramienta de línea de comandos para gestionar plugins de RabbitMQ. Consulte la guía de Plugins de RabbitMQ para obtener una descripción general de los plugins de RabbitMQ y cómo se utilizan.

rabbitmq-plugins permite al operador habilitar, deshabilitar e inspeccionar plugins. Debe ser ejecutado por un usuario con permisos de escritura en el directorio de configuración de RabbitMQ.

Los plugins pueden depender de otros plugins. rabbitmq-plugins resuelve las dependencias y habilita o deshabilita todas las dependencias para que el usuario no tenga que gestionarlas explícitamente. Los plugins listados en la línea de comandos de rabbitmq-plugins se marcan como explícitamente habilitados; los plugins dependientes se marcan como implícitamente habilitados. Los plugins implícitamente habilitados se deshabilitan automáticamente de nuevo cuando ya no son necesarios.

Los comandos enable, disable y set actualizarán el archivo de plugins e intentarán conectarse al broker y asegurarse de que está ejecutando todos los plugins habilitados. Por defecto, si no es posible conectarse y autenticarse con el nodo de destino (por ejemplo, si está detenido), la operación fallará. Si rabbitmq-plugins se utiliza en el mismo host que el nodo de destino, se puede especificar --offline para que rabbitmq-plugins resuelva y actualice el estado de los plugins directamente (sin contactar al nodo). Dichos cambios solo tendrán efecto en el próximo inicio del nodo. Para obtener más información, consulte la guía de Plugins de RabbitMQ

OPCIONES

-n nodo
El nodo por defecto es "rabbit@hostname_destino", donde hostname_destino es el host local. En un host llamado "myserver.example.com", el nombre del nodo será normalmente "rabbit@myserver" (a menos que RABBITMQ_NODENAME se haya anulado). La salida de "hostname -s" suele ser el sufijo correcto para usar después del signo "@". Consulte rabbitmq-server(8) para obtener detalles sobre la configuración de un nodo RabbitMQ.
-q, --quiet
Se selecciona el modo de salida silenciosa. Los mensajes informativos se reducen cuando el modo silencioso está activo.
-s, --silent
Se selecciona el modo de salida ultra silenciosa. Los mensajes informativos se reducen y se suprimen las cabeceras de las tablas cuando el modo ultra silencioso está activo.
-t tiempo_espera, --timeout tiempo_espera
Tiempo de espera de la operación en segundos. No todos los comandos admiten tiempos de espera. El valor predeterminado es infinito.
-l, --longnames
Debe especificarse cuando el clúster está configurado para usar nombres de nodo largos (FQDN). Para obtener más información, consulte la guía de Clústeres de RabbitMQ
--erlang-cookie cookie
Secreto compartido para autenticarse en el nodo de destino. Prefiera usar un archivo local o la variable de entorno RABBITMQ_ERLANG_COOKIE en lugar de especificar esta opción en la línea de comandos. Para obtener más información, consulte la guía de Herramientas CLI de RabbitMQ

COMANDOS

list [-Eemv] [patrón]
-E
Mostrar solo plugins explícitamente habilitados.
-e
Mostrar solo plugins explícita o implícitamente habilitados.
-m
Mostrar solo nombres de plugins (mínimo).
-v
Mostrar todos los detalles de los plugins (verboso).
patrón
Patrón para filtrar los nombres de los plugins.

Lista todos los plugins, sus versiones, dependencias y descripciones. Cada plugin va precedido de dos caracteres indicadores de estado entre [ ]. El primer indicador puede ser:

<espacio>
para indicar que el plugin no está habilitado
E
para indicar que está explícitamente habilitado
e
para indicar que está implícitamente habilitado
para indicar que está habilitado pero falta y, por lo tanto, no es operativo

El segundo indicador puede ser:

<espacio>
para mostrar que el plugin no está en ejecución
*
para mostrar que lo está

Si se proporciona el patrón opcional, solo se mostrarán los plugins cuyo nombre coincida con patrón.

Por ejemplo, este comando lista todos los plugins, en una línea cada uno

rabbitmq-plugins list

Este comando lista todos los plugins:

rabbitmq-plugins list -v

Este comando lista todos los plugins cuyos nombres contienen "management".

rabbitmq-plugins list -v management

Este comando lista todos los plugins de RabbitMQ habilitados implícita o explícitamente.

rabbitmq-plugins list -e rabbit
enable [--offline] [--online] plugin ...
--offline
Modificar el estado de los plugins habilitados del nodo directamente sin contactar al nodo.
--online
Tratar un fallo al conectarse al broker en ejecución como fatal.
plugin
Uno o más plugins para habilitar.

Habilita los plugins especificados y todas sus dependencias.

Por ejemplo, este comando habilita los plugins "shovel" y "management" y todas sus dependencias:

rabbitmq-plugins enable rabbitmq_shovel rabbitmq_management
disable [--offline] [--online] plugin ...
--offline
Modificar el estado de los plugins habilitados del nodo directamente sin contactar al nodo.
--online
Tratar un fallo al conectarse al broker en ejecución como fatal.
plugin
Uno o más plugins para deshabilitar.

Deshabilita los plugins especificados. Si un plugin está siendo utilizado por otro plugin, este comando fallará y reportará el error. Si un plugin es explícitamente habilitado, seguirá estando habilitado de forma explícita tras la ejecución de este comando.

Por ejemplo, este comando deshabilita el plugin "rabbitmq_federation":

rabbitmq-plugins disable rabbitmq_federation
set [--offline] [--online] plugin ...
plugin
Uno o más plugins que deben estar habilitados.

Habilita los plugins especificados y deshabilita todos los demás plugins que no sean dependencias de los plugins habilitados. Esto establece un conjunto fijo de plugins para el nodo.

Por ejemplo, este comando habilita solo los plugins "rabbitmq_shovel" y "rabbitmq_management" y todas sus dependencias, y deshabilita todos los demás:

rabbitmq-plugins set rabbitmq_shovel rabbitmq_management

COMMANDS

disable [--offline] [--online] [plugin ...]
--offline
Modify node's enabled plugin state directly without contacting the node.
--online
Treat a failure to connect to the running broker as fatal.
plugin
One or more plugins to disable.

Disables the specified plugins and all their dependencies.

For example, this command disables "rabbitmq_management" and all plugins that depend on it:

rabbitmq-plugins disable rabbitmq_management
set [--offline] [--online] [plugin ...]
--offline
Modify node's enabled plugin state directly without contacting the node.
--online
Treat a failure to connect to the running broker as fatal.
plugin
Zero or more plugins to disable.

Enables the specified plugins and all their dependencies. Unlike enable, this command ignores and overwrites any existing enabled plugins. set with no plugin arguments is a legal command meaning "disable all plugins".

For example, this command enables the "management" plugin and its dependencies and disables everything else:

rabbitmq-plugins set rabbitmq_management
