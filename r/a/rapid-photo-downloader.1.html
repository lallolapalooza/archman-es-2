NOMBRE

rapid-photo-downloader - Descarga, renombra y realiza copias de seguridad de fotos y videos de cámaras, teléfonos, tarjetas de memoria y otros dispositivos

SINOPSIS

rapid-photo-downloader [opciones] [ruta]

Opciones:

-h, --help
--version
--detailed-version
-v, --verbose
--debug
-e, --extensions
--photo-renaming {on,off}
--video-renaming {on,off}
-a {on,off}, --auto-detect {on,off}
-t {on,off}, --this-computer {on,off}
--this-computer PATH
--photo-destination PATH
--video-destination PATH
-b {on,off}, --backup {on,off}
--backup-auto-detect {on,off}
--photo-backup-identifier FOLDER
--video-backup-identifier FOLDER
--photo-backup-location PATH
--video-backup-location PATH

--auto-download-device-insertion {on,off}
--thumbnail-cache {on,off}
--delete-thumbnail-cache
--forget-remembered-files
--import-old-version-preferences
--reset
--log-gphoto2
--camera-info

DESCRIPCIÓN

Rapid Photo Downloader importa fotos y videos de cámaras, teléfonos, tarjetas de memoria y otros dispositivos a alta velocidad. Puede ser configurado para renombrar fotos y videos con nombres de archivo significativos que usted especifique. También puede realizar copias de seguridad de fotos y videos mientras se descargan. Descarga y realiza copias de seguridad desde múltiples dispositivos simultáneamente.

Único en Rapid Photo Downloader es su Línea de Tiempo, que agrupa fotos y videos basándose en el tiempo transcurrido entre tomas consecutivas. Úsela para identificar fotos y videos tomados en diferentes momentos de un mismo día o durante días consecutivos.

Los archivos se descargan de dos tipos diferentes de fuentes: (1) uno o más dispositivos detectados automáticamente como cámaras, teléfonos, tarjetas de memoria y unidades externas; y (2) una única ruta especificada manualmente, mostrada en la interfaz de usuario como "Este Ordenador".

RUTA

Valor opcional que, cuando se especifica, se analiza para determinar si representa un dispositivo detectado automáticamente o una ruta en este ordenador.

Si la ruta representa un dispositivo detectado automáticamente, la detección automática de dispositivos se activa, como en la opción --auto-detect. Además, la descarga desde una ruta especificada manualmente, como en la opción --this-computer-location, se desactiva.

De lo contrario, se asume que la ruta es una ruta especificada manualmente, como en la opción --this-computer-location, en cuyo caso la descarga desde este ordenador se activa y la descarga desde dispositivos detectados automáticamente se desactiva.

OPCIONES

-h, --help
Muestra el mensaje de ayuda y sale.
--version
Muestra información sobre la versión instalada actualmente y sale.
--detailed-version
Muestra información sobre la versión instalada actualmente y sus librerías, y sale.
-v, --verbose
Muestra información del programa en la línea de comandos mientras el programa se ejecuta.
--debug
Muestra información de depuración en la línea de comandos mientras el programa se ejecuta.
-e, --extensions
Muestra las extensiones de archivos de imagen que el programa reconoce y sale.
--photo-renaming {on,off}
Activa o desactiva el cambio de nombre de las fotos durante la descarga, sobrescribiendo las preferencias actuales del programa. Si se activa, el esquema de nombres utilizado incorporará la fecha y hora de los metadatos de la foto, el número de descargas del día y la extensión del archivo en minúsculas: "AAAAMMDD-HHMM-<DescargasHoy>.<ExtensionMinusculas>", ej. 20160512-1309-23.jpg.
--video-renaming {on,off}
Activa o desactiva el cambio de nombre de los videos durante la descarga, sobrescribiendo las preferencias actuales del programa. Si se activa, el esquema de nombres utilizado incorporará la fecha y hora de los metadatos del video, el número de descargas del día y la extensión del archivo en minúsculas: "AAAAMMDD-HHMM-<DescargasHoy>.<ExtensionMinusculas>", ej. 20160512-1429-26.mp4.
-a {on,off}, --auto-detect {on,off}
Activa o desactiva la detección automática de dispositivos desde los que descargar, sobrescribiendo las preferencias actuales del programa.
-t {on,off}, --this-computer {on,off}
Activa o desactiva la descarga desde este ordenador (ver descripción arriba), sobrescribiendo las preferencias actuales del programa.
--this-computer-location PATH
La RUTA en este ordenador desde la que descargar, sobrescribiendo las preferencias actuales del programa.
--photo-destination PATH
Establece la RUTA donde se descargarán las fotos, sobrescribiendo las preferencias actuales del programa.
--video-destination PATH
Establece la RUTA donde se descargarán los videos, sobrescribiendo las preferencias actuales del programa.
-b {on,off}, --backup {on,off}
Activa o desactiva la copia de seguridad de fotos y videos durante la descarga, sobrescribiendo las preferencias actuales del programa.
--backup-auto-detect {on,off}
Activa o desactiva la detección automática de dispositivos de copia de seguridad, sobrescribiendo las preferencias actuales del programa.
--photo-backup-identifier FOLDER
Establece la CARPETA en la que se almacenan las copias de seguridad en el dispositivo de copia de seguridad de fotos detectado automáticamente, utilizando el nombre de la carpeta para identificar si el dispositivo se usa o no para copias de seguridad. Para cada dispositivo que desee usar para hacer copias de seguridad de fotos, cree una carpeta con este nombre. Sobrescribe las preferencias actuales del programa.
--video-backup-identifier FOLDER
Establece la CARPETA en la que se almacenan las copias de seguridad en el dispositivo de copia de seguridad de videos detectado automáticamente, utilizando el nombre de la carpeta para identificar si el dispositivo se usa o no para copias de seguridad. Para cada dispositivo que desee usar para hacer copias de seguridad de videos, cree una carpeta con este nombre. Sobrescribe las preferencias actuales del programa.
--photo-backup-location PATH
Establece la RUTA donde se realizarán las copias de seguridad de las fotos cuando la detección automática de dispositivos de copia de seguridad esté desactivada. Sobrescribe las preferencias actuales del programa.
--video-backup-location PATH
Establece la RUTA donde se realizarán las copias de seguridad de los videos cuando la detección automática de dispositivos de copia de seguridad esté desactivada. Sobrescribe las preferencias actuales del programa.
--ignore-other-photo-file-types
No descargar fotos con las siguientes extensiones: TIF, TIFF y MPO.
--auto-download-startup {on,off}
Activa o desactiva el inicio de descargas tan pronto como el programa arranca.
--auto-download-device-insertion {on,off}
Activa o desactiva el inicio de descargas tan pronto como se inserta un dispositivo.
--thumbnail-cache {on,off}
Activa o desactiva el uso de la Caché de Miniaturas de Rapid Photo Downloader. Desactivarla no elimina el contenido existente de la caché.
--delete-thumbnail-cache
Elimina todas las miniaturas en la Caché de Miniaturas de Rapid Photo Downloader y sale.
--forget-remembered-files
Olvida qué archivos se han descargado previamente y sale.
--import-old-version-preferences
Importa preferencias de una versión antigua del programa (0.4.11 o anterior) y sale. Requiere el programa de línea de comandos gconftool-2.

OPCIONES

--force-subdir
Fuerza la creación de subdirectorios basados en la fecha de la fotografía (para cámaras que no proporcionan información de fecha).
--skip-subdir
Omite la creación de subdirectorios. Las fotos se copian directamente al directorio de destino.
--recurse
Busca fotos en subdirectorios de la cámara (útil para algunas cámaras digitales).
--delete-after-copy
Borra las fotos de la cámara después de copiarlas correctamente.
--empty-folders-first
Crea directorios vacíos primero (útil para cámaras que no presentan directorios de forma consistente).
--process-subdirs
Procesa subdirectorios en el disco duro de la cámara (si la cámara los soporta).
--dry-run
Ejecuta el programa sin realizar cambios reales. Muestra lo que haría si se ejecutara normalmente.
--log-gphoto2
Incluye información de depuración de gphoto2 en los archivos de registro, lo que puede ser útil al analizar problemas que libgphoto2 pueda tener al acceder a una cámara.
--camera-info
Imprime información sobre las cámaras conectadas en la terminal y sale.

AMBIENTE

Si la variable de entorno RPD_SCAN_DEBUG se establece en cualquier valor, la operación de escaneo del programa generará voluminosa información de depuración en stdout.

Si la variable de entorno RPD_DEVEL_DEFAULTS se establece en cualquier valor, las preferencias predeterminadas del programa se establecerán en las de un entorno de desarrollo.
