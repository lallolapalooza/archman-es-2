RAND(3P) Manual de Programador POSIX RAND(3P)

PROLOGO

Esta página del manual forma parte del Manual del Programador POSIX. La implementación de Linux de esta interfaz puede diferir (consulte la página del manual de Linux correspondiente para obtener detalles sobre el comportamiento de Linux), o la interfaz puede no estar implementada en Linux.

NOMBRE

rand, rand_r, srand — generador de números pseudoaleatorios

SINOPSIS

#include <stdlib.h>
int rand(void);
int rand_r(unsigned *seed);
void srand(unsigned seed);

DESCRIPCIÓN

Para rand() y srand(): La funcionalidad descrita en esta página de referencia está alineada con el estándar ISO C. Cualquier conflicto entre los requisitos descritos aquí y el estándar ISO C es involuntario. Este volumen de POSIX.1‐2017 se remite al estándar ISO C.

La función rand() calculará una secuencia de enteros pseudoaleatorios en el rango [0,{RAND_MAX}] con un período de al menos 232.

La función rand() no necesita ser segura para hilos.

La función rand_r() calculará una secuencia de enteros pseudoaleatorios en el rango [0,{RAND_MAX}]. (El valor de la macro {RAND_MAX} será de al menos 32767.)

Si rand_r() se llama con el mismo valor inicial para el objeto al que apunta seed y ese objeto no se modifica entre retornos sucesivos y llamadas a rand_r(), se generará la misma secuencia.

La función srand() utiliza el argumento como semilla para una nueva secuencia de números pseudoaleatorios que serán devueltos por llamadas posteriores a rand(). Si luego se llama a srand() con el mismo valor de semilla, se repetirá la secuencia de números pseudoaleatorios. Si se llama a rand() antes de realizar cualquier llamada a srand(), se generará la misma secuencia que cuando se llama a srand() por primera vez con un valor de semilla de 1.

La implementación se comportará como si ninguna función definida en este volumen de POSIX.1‐2017 llamara a rand() o srand().

VALOR DE RETORNO

La función rand() devolverá el siguiente número pseudoaleatorio de la secuencia.

La función rand_r() devolverá un entero pseudoaleatorio.

La función srand() no devolverá ningún valor.

ERRORES

No se definen errores.

Las siguientes secciones son informativas.

EJEMPLOS

Generación de una secuencia de números pseudoaleatorios

El siguiente ejemplo demuestra cómo generar una secuencia de números pseudoaleatorios.

#include <stdio.h>
#include <stdlib.h>
...
    long count, i;
    char *keystr;
    int elementlen, len;
    char c;
...
/* Inicializar el generador de números aleatorios. */
    srand(1);
    /* Crear claves usando solo caracteres minúsculos */
    len = 0;
    for (i=0; i<count; i++) {
        while (len < elementlen) {
            c = (char) (rand() % 128);
            if (islower(c))
                keystr[len++] = c;
        }
        keystr[len] = '\0';
        printf("%s Element%0*ld\n", keystr, elementlen, i);
        len = 0;
    }

Generación de la misma secuencia en diferentes máquinas

El siguiente código define un par de funciones que podrían incorporarse en aplicaciones que deseen garantizar que se genere la misma secuencia de números en diferentes máquinas.

static unsigned long next = 1;
int myrand(void)  /* Se asume que RAND_MAX es 32767. */
{
    next = next * 1103515245 + 12345;
    return((unsigned)(next/65536) % 32768);
}
void mysrand(unsigned seed)
{
    next = seed;
}

USO POR LA APLICACIÓN

Las funciones drand48() y random() proporcionan generadores de números pseudoaleatorios mucho más elaborados.

Las limitaciones en la cantidad de estado que puede transportarse entre una llamada a función y otra significan que la función rand_r() nunca puede implementarse de una manera que satisfaga todos los requisitos de un generador de números pseudoaleatorios.

Se deben evitar estas funciones siempre que deban cumplirse requisitos no triviales (incluida la seguridad).

FUNDAMENTO

Las funciones rand() y srand() del estándar ISO C permiten flujos pseudoaleatorios por proceso compartidos por todos los hilos. Estas dos funciones no necesitan cambiar, pero debe haber exclusión mutua que impida la interferencia entre dos hilos que acceden concurrentemente al generador de números aleatorios.

Con respecto a rand(), existen dos comportamientos diferentes que pueden desearse en un programa multihilo:

1.
Una única secuencia de números pseudoaleatorios por proceso que es compartida por todos los hilos que llaman a rand()
2.
Una secuencia diferente de números pseudoaleatorios para cada hilo que llama a rand()

Esto se proporciona mediante la función modificada y segura para hilos, según si el valor de la semilla es global para todo el proceso o local para cada hilo.

Esto no aborda las deficiencias conocidas de las implementaciones de la función rand(), que se han abordado manteniendo más estado. En efecto, esto especifica nuevas formas seguras para hilos de una función defectuosa.

DIRECCIONES FUTURAS

La función rand_r() puede ser eliminada en una versión futura.
