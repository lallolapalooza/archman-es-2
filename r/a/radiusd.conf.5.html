radiusd.conf(5) Archivo de configuración de FreeRADIUS radiusd.conf(5)

NOMBRE

radiusd.conf - archivo de configuración para el servidor FreeRADIUS

DESCRIPCIÓN

El archivo radiusd.conf reside en el directorio de la base de datos de radius, por defecto /etc/raddb. Define la configuración global para el servidor RADIUS FreeRADIUS.

CONTENIDO

Hay un gran número de parámetros de configuración para el servidor. La mayoría están documentados en el propio archivo como comentarios. Esta página solo documenta el formato del archivo. Por favor, lea el archivo radiusd.conf para obtener más información.

El analizador del archivo de configuración es independiente de la configuración del servidor. Esto significa que puede poner casi cualquier cosa en el archivo de configuración. Siempre que esté correctamente formateado, el servidor se iniciará.

Cuando el servidor analiza el archivo de configuración, solo busca aquellas configuraciones que entiende. Las configuraciones adicionales se ignoran. Esta "característica" puede ser (ab)usada de formas interesantes.

FORMATO DEL ARCHIVO

El formato del archivo se basa en líneas, como muchos otros archivos de configuración de Unix. Cada entrada en el archivo debe colocarse en una línea separada, aunque se admiten continuaciones.

El archivo consta de elementos de configuración (pares variable = valor), secciones y comentarios.

Variables
Las variables se pueden establecer mediante: 
nombre = valor

Se permiten cadenas entre comillas simples y dobles:

	cadena1 = "hola mundo"
	cadena2 = 'hola mamá'
Secciones
Una sección comienza con un nombre de sección, seguido en la misma línea por un corchete de apertura '{'. Las secciones pueden contener otras secciones, comentarios o variables. Las secciones pueden anidarse a cualquier profundidad, limitada solo por la memoria disponible. Una sección termina con un corchete de cierre '}', en una línea separada. 
	seccion {
		...
	}

Las secciones a veces pueden tener un segundo nombre después del primero. Las situaciones en las que esto es legal dependen del contexto. Consulte los ejemplos y los comentarios en el archivo radiusd.conf para obtener más información.

	seccion foo {
		...
	}
Comentarios
Cualquier línea que comience con un (#) se considera un comentario y se ignora. Los comentarios pueden aparecer después de las definiciones de variables o secciones. 
	# comentario
	foo = bar # establece la variable 'foo' al valor 'bar'
	seccion {	# inicio de la sección
	...
	}		# fin de la sección
Continuaciones
Las líneas largas se pueden dividir mediante continuaciones, usando '\' como último carácter de la línea. Por ejemplo, la siguiente entrada: 
	foo = "blah \
	blah \
	blah"

establecerá el valor de la variable "foo" a "blah blah blah". Cualquier CR o LF no se convierte en un espacio, pero todo el demás espacio en blanco se conserva en el valor final.

REFERENCIAS

El valor de una variable puede hacer referencia a otra variable. Estas referencias se evalúan cuando se carga el archivo de configuración, lo que significa que no hay ningún coste en tiempo de ejecución asociado a ellas. Esta característica es más útil para convertir fragmentos de texto largos y repetidos en otros cortos.

Las variables se referencian mediante ${nombre_variable}, como en los siguientes ejemplos.

	foo = bar       # establece la variable 'foo' al valor 'bar'
	quien = ${foo}    # establece la variable 'quien' al valor de la variable 'foo'
	mi = "${foo} un" # establece la variable 'mi' a "bar un"

Si la variable existe en una sección o subsección, se puede referenciar como ${seccion.subseccion.variable}. Las referencias hacia adelante no están permitidas. Las referencias relativas están permitidas, precediendo el nombre con uno o más puntos.

blogs = ${.foo}

Establecerá la variable blogs al valor de la variable foo, de la sección actual.

blogs = ${..foo}

Establecerá la variable blogs al valor de la variable foo, de la sección que contiene la sección actual.

blogs = ${modulos.detalle.archivo}

Establecerá la variable blogs al valor de la variable archivo, del módulo detalle, que se encuentra en la sección modulos del archivo de configuración.

Las propiedades de las secciones padre anónimas también se pueden referenciar, actualmente se soportan nombre e instancia.

modulos {
	ejemplo foo {
		archivo = ${.:nombre}
	}
}

Establecerá la variable archivo al nombre de la sección contenedora (ejemplo).

modulos {
	ejemplo foo {
		archivo = ${.:instancia}
	}
}

Establecerá la variable archivo al nombre de instancia de la sección contenedora (foo).

modulos {
	ejemplo foo {
		archivo = ${..:nombre}
	}
}

Establecerá la variable archivo al nombre de la sección padre de la sección contenedora (modulos).
