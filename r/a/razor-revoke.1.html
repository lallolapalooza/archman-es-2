NOMBRE

"razor-revoke" - Agente de Revocación de Razor

SINOPSIS

razor-revoke [opciones] archivo_con_correo_en_formato_rfc822
$ cat correo | razor-revoke
$ razor-revoke ./correo 
$ razor-revoke -d ./correo

DESCRIPCIÓN

"razor-revoke" es el Agente de Revocación de Razor que se utiliza para reportar mensajes como NO spam a un Servidor de Nominación de Razor. Por ejemplo, puede ser invocado si una verificación marcó incorrectamente un mensaje como spam o después de que un mensaje fuera reportado incorrectamente como spam. "razor-revoke" generalmente debe ser llamado desde un MUA, aunque no hay restricciones para invocarlo desde la línea de comandos. "razor-revoke" es un filtro, lo que significa que los mensajes de spam deben ser pasados a través de él. Por defecto, "razor-revoke" se pone en segundo plano y se desvincula del terminal de control al iniciar.

Si a "razor-revoke" se le pasa más de un correo, revocará cada uno contra la base de datos. Por favor, use esto con precaución, no queremos que la base de datos tenga información inexacta. "razor-revoke" soporta archivos en formato mbox con 1 o más correos, así como archivos que contienen un único correo RFC 822 (no mbox). Se pueden presentar más de un archivo en la línea de comandos, pudiendo ser mbox o no mbox en cualquier orden. Sin embargo, no se pueden leer más de un correo no mbox desde la entrada estándar.

Tanto razor-report(1) como "razor-revoke" requieren autenticación de usuario para funcionar, ver razor-admin(1). Esto permite al Servidor de Nominación de Razor llevar un registro de cuántos mensajes reporta y revoca un usuario. Cuantos más mensajes reporte y/o revoque correctamente un usuario, más confianza ganará. Del mismo modo, cuando los mensajes se reportan o revocan incorrectamente, la confianza de ese usuario disminuye. Los usuarios con alta confianza tendrán el mayor impacto en la base de datos de Razor.

Tenga en cuenta que incluso después de una revocación exitosa, un correo podría seguir siendo considerado spam en el Catálogo de Razor. Por ejemplo, esto puede ocurrir si usuarios más confiables consideran que el correo es spam que no es spam.

USO

"razor-revoke" toma los siguientes argumentos:

"-h"
Imprime un mensaje de uso y sale.
"-v"
Imprime el número de versión y sale.
"-d | --verbose"
Imprime información de depuración.
"-debuglevel=n | -dl=n"
Establece el nivel de depuración a 'n'. Por defecto es 3 sin la opción "-d", 9 con ella.
"-whitelist=archivo"
Especifica el archivo a usar para la lista blanca. Sobrescribe la opción 'whitelist' en "razor-agent.conf".
"-s"
Simula una verificación. Hace todo excepto hablar con el servidor.
"-conf=nombre_archivo"
Especifica un archivo de configuración alternativo. Si no se especifica, se calcula, ver la página del manual de razor-agents(1) para más detalles. Ver la página del manual de razor-agent.conf(5) para varias opciones de configuración. El valor predeterminado es "<razorhome>/razor-agent.conf".
"-home=dir"
Especifica el directorio razorhome. Aquí es donde viven el archivo de configuración, los archivos de registro, las identidades y los archivos del servidor. Si no se especifica, se calcula, ver la página del manual de razor-agents(1) para más detalles.
"-logfile=archivo"
Especifica el archivo a registrar en lugar de lo que está en el archivo de configuración. El valor predeterminado es "<razorhome>/razor-agent.log".
"-ident=nombre_archivo"
Especifica un archivo de identidad a usar para la autenticación con los Servidores Razor. Si no se especifica, se usa "<razorhome>/identity-<usuario>".
"-rs=razor.server.com"
Usa este Servidor de Nominación Razor en lugar de leer "servers.nomination.lst".
"-M | --mbox"
Acepta un nombre de buzón en la línea de comandos y revoca cada correo en el buzón contra la base de datos. Si está en primer plano, "-f", "razor-revoke" imprimirá el número de correo de cada correo que fue aceptado por el servidor del Catálogo. 
C<razor-revoke -f -M ~/Mail/incorrectly-marked-spam>
"-i=nombre_archivo"
Usó la identidad del archivo de nombre en lugar de leer <razorhome>/identity.
"-a"
Solo autenticar. Si está autenticado, sale con 0; si no, sale con 1.
"-f"
Permanece en primer plano, no se separa y se ejecuta en segundo plano.

INTEGRACIÓN CON MUTT

Agrega la siguiente línea a "mutt.conf"

macro index R "|/usr/bin/razor-revoke"

Luego presiona R en el mensaje de spam en "mutt" para reportarlo con "razor-revoke". Como "razor-revoke" se bifurca, el control regresará inmediatamente.
