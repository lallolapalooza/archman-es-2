NOMBRE

radclient - enviar paquetes a un servidor RADIUS, mostrar respuesta

SINOPSIS

radclient [-4] [-6] [-b] [-c contador] [-d directorio_raddb] [-D directorio_diccionario] [-f archivo] [-F] [-h] [-i id] [-n num_solicitudes_por_segundo] [-p num_solicitudes_en_paralelo] [-q] [-r num_reintentos] [-s] [-S archivo_secreto_compartido] [-t tiempo_espera] [-v] [-x] servidor {acct|auth|status|coa|disconnect|auto} secreto

DESCRIPCION

radclient es un programa cliente de radius. Puede enviar paquetes radius arbitrarios a un servidor radius, y luego mostrar la respuesta. Puede ser utilizado para probar cambios realizados en la configuración del servidor radius, o para monitorear si un servidor radius está activo.

radclient lee pares atributo/valor de radius desde su entrada estándar, o desde un archivo especificado en la línea de comandos. Luego codifica estos pares atributo/valor usando el diccionario, y los envía al servidor remoto.

Los atributos User-Password y CHAP-Password se cifran automáticamente antes de que el paquete sea enviado al servidor.

OPCIONES

-4
Usar IPv4 (por defecto)
-6
Usar IPv6
-b
Forzar las comprobaciones de Blast RADIUS. Todas las respuestas a un paquete Access-Request deben contener un Message-Authenticator como primer atributo.

Para compatibilidad con servidores antiguos, esta bandera no está activada por defecto. Sin embargo, radclient aún comprueba la firma de Blast RADIUS y descarta los paquetes que coinciden con el ataque.

-c contador
Enviar cada paquete contador veces.
-d directorio_raddb
El directorio que contiene el archivo de diccionario de usuarios. Por defecto es /etc/raddb.
-D directorio_diccionario
El directorio que contiene el archivo de diccionario principal. Por defecto es /usr/share/freeradius.
-f archivo[:archivo]
Archivo del cual leer los pares atributo/valor. Si no se especifica, se leen desde stdin. Esta opción puede especificarse múltiples veces, en cuyo caso los paquetes se envían en orden por archivo, y dentro de cada archivo, del primer paquete al último. Una línea en blanco separa paquetes lógicos dentro de un archivo. Si se especifica un par de archivos separados por dos puntos, el segundo archivo se usará para filtrar las respuestas a las solicitudes del primero. El número de solicitudes y filtros debe ser el mismo. Se mostrará un resumen de los resultados del filtro si se pasa -s.
-F
Imprimir el nombre del archivo, el número del paquete y el código de respuesta.
-h
Imprimir información de ayuda de uso.
-i id
Usar id como el Id de solicitud RADIUS.
-n num_solicitudes_por_segundo
Intentar enviar num_solicitudes_por_segundo, espaciadas uniformemente. Esta opción permite reducir la velocidad a la que radclient envía solicitudes. Cuando no se usa -n, el valor por defecto es enviar paquetes tan rápido como sea posible, sin demoras entre paquetes.

Debido a limitaciones en radclient, esta opción no envía con precisión el número solicitado de paquetes por segundo.

-p num_solicitudes_en_paralelo
Enviar num_solicitudes_en_paralelo, sin esperar una respuesta por cada una. Por defecto, radclient envía la primera solicitud que ha leído, espera la respuesta, y una vez recibida la respuesta, envía la segunda solicitud de su lista. Esta opción permite enviar muchas solicitudes simultáneamente. Una vez que se envían num_solicitudes_en_paralelo, radclient espera a que lleguen todas las respuestas (o a que las solicitudes expiren), antes de enviar más paquetes.

Esta opción permite descubrir la carga máxima aceptada por un servidor RADIUS.

-P proto
Usar el protocolo de transporte proto ("tcp" o "udp"). Solo disponible si FreeRADIUS está compilado con soporte de transporte TCP.
-q
Entrar en modo silencioso, y no imprimir nada.
-r num_reintentos
Intentar enviar cada paquete num_reintentos veces, antes de rendirse. El valor por defecto es 10.
-s
Imprimir algunos resúmenes de paquetes enviados y recibidos.
-S archivo_secreto_compartido
En lugar de leer el secreto compartido de la línea de comandos (donde puede ser visto por otros en el sistema local), léalo en su lugar desde archivo_secreto_compartido.
-t tiempo_espera
Esperar tiempo_espera segundos antes de decidir que el NAS no ha respondido a una solicitud, y reenviar el paquete. El tiempo de espera por defecto es 3.
-v
Imprimir información de la versión.
-x
Imprimir información de depuración.
servidor[:puerto]
El nombre de host o dirección IP del servidor remoto. Opcionalmente se puede especificar un puerto UDP. Si no se especifica ningún puerto UDP, se busca en /etc/services. El nombre de servicio que se busca es radacct para paquetes de contabilidad, y radius para todas las demás solicitudes. Si no se encuentra un servicio en /etc/services, se usan 1813 y 1812 respectivamente. Para paquetes coa y disconnect, se usa el puerto 3799.

Si se especifica un nombre de host, entonces radclient realizará una consulta DNS y usará el registro A para encontrar la dirección IP del servidor RADIUS. Si no hay un registro A, entonces radclient buscará un registro AAAA. Si no hay un registro AAAA, se producirá un error.

Las direcciones IPv6 se pueden especificar rodeándolas entre corchetes. Por ejemplo, [2002:c000:0201:0:0:0:0:0], o con un puerto, [2002:c000:0201:0:0:0:0:0]:18120.

Los atributos RADIUS leídos por radclient pueden contener el atributo especial Packet-Dst-IP-Address. Si este atributo existe, entonces esa dirección IP es a donde se envía el paquete, y el servidor especificado en la línea de comandos se ignora.

Si la lista de atributos RADIUS siempre contiene el atributo Packet-Dst-IP-Address, entonces el parámetro servidor puede darse como -.

Los atributos RADIUS leídos por radclient pueden contener el atributo especial Packet-Dst-Port. Si este atributo existe, entonces ese puerto UDP es a donde se envía el paquete, y el :puerto especificado en la línea de comandos se ignora.

acct | auth | status | coa | disconnect | auto
Usar auth para enviar un paquete de autenticación (Access-Request), acct para enviar un paquete de contabilidad (Accounting-Request), status para enviar un paquete de estado (Status-Server), o coa para enviar una CoA-Request, o disconnect para enviar una solicitud de desconexión. En lugar de estos valores, también puede usar un código decimal aquí. Por ejemplo, el código 12 también es Status-Server.

Los atributos RADIUS leídos por radclient pueden contener el atributo especial Packet-Type. Si este atributo existe, entonces se envía ese tipo de paquete, y el tipo especificado en la línea de comandos se ignora.

Si la lista de atributos RADIUS siempre contiene el atributo Packet-Type, entonces el parámetro tipo puede darse como auto.

secreto
El secreto compartido para este cliente. Debe estar definido en el lado del servidor radius también, para la dirección IP desde la que se envían los paquetes radius.

EJEMPLO

Una sesión de ejemplo que consulta al servidor remoto por Status-Server (no todos los servidores lo soportan, pero FreeRADIUS tiene soporte configurable para ello).

radclient(1) — Arch Linux

NAME

radclient - Interrogue un serveur RADIUS

SYNOPSIS

radclient [ -d raddb ] [ -p port ] [ -q ] [ -x ] host command [ arg ... ]

DESCRIPTION

radclient est un utilitaire de ligne de commande pour interroger un serveur RADIUS. Il peut être utilisé pour effectuer diverses opérations, telles que la vérification de l'état du serveur, la transmission de messages ou la gestion des listes de contrôle d'accès.

OPTIONS

radclient comprend les options suivantes :

-d raddb
Spécifie le répertoire des fichiers de configuration RADIUS. La valeur par défaut est /etc/raddb.
-p port
Spécifie le port UDP à utiliser pour la communication avec le serveur RADIUS. La valeur par défaut est 1812.
-q
Supprime l'affichage des informations sur l'envoi et la réception des paquets.
-x
Active la journalisation de débogage détaillée.

EXAMPLE

La commande suivante vérifie l'état du serveur RADIUS à l'adresse 192.0.2.42 avec le secret partagé "s3cr3t" :

$ echo "Message-Authenticator = 0x00" | radclient 192.0.2.42 status s3cr3t
Sending request to server 192.0.2.42, port 1812.
radrecv: Packet from host 192.0.2.42 code=2, id=140, length=54
    Reply-Message = "FreeRADIUS up 21 days, 02:05"
