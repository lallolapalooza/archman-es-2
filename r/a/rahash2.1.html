RAHASH2(1) Manual de comandos generales RAHASH2(1)

NOMBRE

rahash2 — utilidad de hashing, codificación y cifrado basado en bloques

SINOPSIS

rahash2 [-BbdehjkLqrv] [-a algo] [-b tamaño] [-c hash] [-D deco] [-e] [-E enco] [-f desde] [-i num] [-I iv] [-j] [-J] [-L] [-S semilla] [-k] [-s cadena] [-t hasta] [-x cadhex] [-X] [-v] [[archivo] ...]

DESCRIPCIÓN

Este programa forma parte del proyecto radare.

Es particularmente útil para calcular hashes de archivos grandes e identificar modificaciones en análisis forenses de sistemas de archivos.

Este comando proporciona las mismas características que el comando 'ph' de radare.

-a algo
Lista de algoritmos separados por comas a usar al calcular hashes de archivos o cadenas. Consulte -L para listar los algoritmos de hashing soportados. Esta opción se puede pasar varias veces en lugar de separarlos por comas.
-b tamaño
Especifica el tamaño del bloque.
-c hash
Compara el hash calculado con el proporcionado. Esto solo está permitido cuando se calcula un solo hash.
-D deco
Descifra usando el algoritmo especificado. Usa -S para establecer la clave y -I para establecer el IV.
-e
Intercambia el orden de los bytes para mostrar resúmenes o ingerir claves en big o little endian.
-E enco
Cifra usando el algoritmo especificado. Usa -S para establecer la clave y -I para establecer el IV.
-f desde
Inicia el cálculo de hash en la dirección dada.
-i num
Repite el cálculo de hash `num` veces.
-I iv
Usa el vector de inicialización (IV) dado (hexadecimal o cadena).
-j
Muestra la salida en formato JSON.
-J
Nuevo formato de salida JSON simplificado (equivalente a -jj).
-k
Muestra el hash usando el algoritmo randomkey de OpenSSH.
-L
Lista los plugins de hash, checksum y criptografía disponibles. Esta opción se puede combinar con -j para leer los resultados en formato JSON.
-s cadena
Calcula el hash de la cadena proporcionada en lugar de usar los argumentos 'fuente' y 'archivo-hash'.
-S semilla
Usa la semilla dada (hexadecimal o cadena). Usa ^ para prefijar (clave para -E). '-' extraerá la clave desde stdin, y el prefijo '@' apunta a un archivo.
-t hasta
Detiene el cálculo de hash en la dirección dada.
-x cadhex
Calcula el hash de la cadena hexadecimal proporcionada en lugar de usar los argumentos 'fuente' y 'archivo-hash'.
-X
Salida del cifrado en pares hexadecimales en lugar de crudo (ver -j para salida json)
-v
Muestra información de la versión.

EJEMPLOS

Calcular el hash MD5 del binario 'ls':


$ rahash2 -qqa md5 /bin/ls

Calcular el hash SHA256 de una cadena desde stdin:


$ echo -n "Hola, Mundo" | rahash2 -a sha256 -
$ rahash2 -a sha256 -s "Hola, Mundo"

Comparar si el CRC32 del archivo dado no ha cambiado:


$ rahash2 -qqa crc32 /bin/ls
63212007
$ rahash2 -a crc32 -c 63212007 /bin/ls
INFO: El hash calculado coincide con el esperado
$ echo $?
0

Listar solo los plugins criptográficos cargados:


$ rahash2 -L | grep ^c


$ rahash2 -qqa crc32 /bin/ls

Codificar la cadena "Hola Mundo" con base64:


$ rahash2 -E base64 -s "Hola Mundo"

Calcular el hash SHA256 de una parte específica de un archivo:


$ rahash2 -qqa sha256 -f 0x1000 -t 0x2000 archivo_a_hashear

Cifrar y descifrar la cadena "hola" usando los plugins ror y rol:


$ rahash2 -S 12333 -E ror -s hola && echo
Cell{
$ rahash2 -S 12333 -E rol -s Cell{ && echo
hola

Cifrar y descifrar usando AES-CBC:


$ export AES_KEY="11111111111111111111111111113211"
$ rahash2 -E aes-ecb -S "$AES_KEY" -s "hola mundo maldito" > .archivo
$ cat .archivo | rahash2 -D aes-ecb -S "$AES_KEY" -s - && echo

Cifrar un archivo usando Blowfish y codificarlo en un JSON:


$ rahash2 -E blowfish -S "11111111111111111111111111113211" -j /bin/ls > ls.json

DIAGNÓSTICOS

La utilidad rahash2 sale con estado 0 en caso de éxito y >0 si ocurre un error.

Al usar la opción -c, un estado de salida de 0 indica una coincidencia entre los hashes esperado y calculado.

NAME

rahash2 - Una herramienta para calcular e intercambiar hashes de archivos.

SYNOPSIS

rahash2 [-a algo] [-b] [-c] [-C] [-d] [-e] [-f] [-h] [-H] [-i] [-l] [-m] [-n] [-N] [-p] [-P] [-q] [-r] [-R] [-s] [-S] [-t] [-T] [-u] [-v] [-w] [-z] [-Z] [-x] [-y] [file...]

DESCRIPTION

rahash2 es una herramienta para calcular e intercambiar hashes de archivos. Soporta MD5, SHA1, SHA256, SHA512, ssdeep, TTH, ED25519, ecc.

OPTIONS

-a algo
Especifica el algoritmo de hash a usar. Los algoritmos soportados son: md5, sha1, sha256, sha512, ssdeep, tth, ed25519, ecc. El valor predeterminado es sha256.
-b
Formato de salida binario.
-c
Compara hashes. Espera un archivo con hashes y nombres de archivo.
-C
Compara hashes. Espera un archivo con hashes y nombres de archivo en formato JSON.
-d
Decodifica hashes.
-e
Codifica hashes.
-f
Abre el archivo especificado y calcula hashes para cada línea en él.
-h
Muestra la ayuda.
-H
Muestra información detallada sobre los hashes.
-i
Lee la lista de nombres de archivo de la entrada estándar.
-l
Lista todos los algoritmos de hash soportados.
-m
Calcula el hash Merkle Tree.
-n
No imprime el nombre del archivo.
-N
No imprime el hash.
-p
Imprime el progreso.
-P
Calcula hashes para directorios recursivamente.
-q
Modo silencioso.
-r
Lee la lista de hashes y nombres de archivo de la entrada estándar.
-R
Formato de salida raw.
-s
Lee la lista de archivos de la entrada estándar.
-S
Formato de salida JSON.
-t
Imprime el tiempo de ejecución.
-T
Imprime el tiempo de ejecución en formato detallado.
-u
Formato de salida de texto sin procesar.
-v
Muestra información de la versión.
-w
Calcula el hash de la suma de verificación de 32 bits.
-z
El hash es para un archivo vacío.
-Z
El hash es para un archivo vacío con un tamaño específico.
-x
Modo de intercambio de hashes.
-y
Decodifica hashes de la entrada estándar.

EXAMPLES

Calcular el hash SHA256 de un archivo:

$ rahash2 -a sha256 archivo.txt

Calcular varios hashes de un archivo:

$ rahash2 -a md5,sha1,sha512 archivo.txt

Comparar hashes de un archivo contra una lista de hashes:

$ rahash2 -c hashes.txt archivo.txt

EXIT STATUS

Devuelve 0 si todas las operaciones se completaron con éxito, o 1 si ocurrió un error.

MODULES

rahash2 puede ser extendido con módulos. Los módulos se almacenan en /usr/lib/rahash2/.

ENVIRONMENT

RAHASH2_MODULE_PATH

Permite especificar una ruta alternativa para los módulos de rahash2.

FILES

/usr/lib/rahash2/*.so

Rutas de los módulos de rahash2.
