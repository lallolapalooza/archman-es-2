NOMBRE

rabin2 — Extractor de información de programas binarios

SINOPSIS

rabin2 [-AceghHiIsSMzlpRrLxvhqQTuUwV] [-a arch] [-b bits] [-B addr] [-C fmt:C:[D]] [-D lang sym|-] [-f subbin] [-k query] [-K algo] [-O binop] [-o str] [-m addr] [-@ addr] [-n str] [-X fmt file ...] file

DESCRIPCIÓN

Este programa permite obtener información sobre archivos ELF/PE/MZ y CLASS de una manera sencilla.

Todas estas opciones de línea de comandos también están disponibles bajo el comando i en radare2. Escribe i? para obtener ayuda.

-@ addr
Mostrar información (símbolo, sección, importación) de la dirección dada
-A
Listar sub-binarios y sus pares de arch-bits asociados
-a arch
Establecer arquitectura (x86, arm, .. acepta guiones bajos para bits x86_32)
-b bits
Establecer bits (32, 64, ...)
-B addr
Anular baddr
-c
Listar clases
-cc
Listar clases en formato de encabezado
-C [fmt:C[:D]]
Crear [elf,mach0,pe] para binarios pequeños de arm y x86-32/64 donde 'C' es una lista de pares de bytes del código y ':D' es una concatenación opcional para describir los bytes de la sección de datos.
-d
Mostrar información de depuración/dwarf
-D lang nombre_simbolo|-
Desmalezar el nombre del símbolo (o - para leer desde stdin) para el idioma (cxx, swift, java, cxx, ..)
-e
Mostrar puntos de entrada para disco y en memoria
-ee
Mostrar constructores/destructores (puntos de entrada extendidos)
-f subbin
Seleccionar arquitectura sub-binaria. Útil para binarios fat-mach0
-F binfmt
Forzar el uso de ese plugin binario (ignorar verificación de encabezado)
-g
Mostrar toda la información posible
-G addr
Dirección de carga . desplazamiento al encabezado
-h
Mostrar mensaje de ayuda.
-H
Mostrar campos del encabezado (ver comando ih en r2)
-I
Mostrar información binaria (ver comando iI en r2)
-i
Mostrar importaciones (símbolos importados de bibliotecas) (ver comando ii en r2)
-j
Salida en json
-k query
Realizar consulta SDB en el archivo cargado
-K algo
Seleccionar un algoritmo de checksum rahash2 para realizar en la lista de secciones (y posiblemente en otros en el futuro) por ejemplo 'rabin2 -K md5 -S /bin/ls'
-l
Listar bibliotecas enlazadas al binario
-L
Listar plugins binarios compatibles
-M
Mostrar dirección del símbolo 'main'
-m addr
Mostrar referencia de línea de código fuente desde una dirección dada
-N minlen:maxlen
Forzar un número mínimo y máximo de caracteres por cadena (ver -z y -zz). si (strlen>minlen && (!maxlen || strlen<=maxlen))
-n str
Mostrar información (símbolo, sección, importación) en el desplazamiento de la cadena
-o str
Archivo/carpeta de salida para operaciones de escritura (out por defecto)
-O binop
Realizar operación binaria en el binario de destino (volcar, redimensionar, cambiar secciones, ...) ver '-O help' para más información
-p
Desactivar VA. Mostrar siempre direcciones físicas (no es lo mismo que -B0)
-P
Mostrar información de depuración/pdb
-PP
Descargar archivo pdb para el binario
-q
Ser silencioso, mostrar menos datos
-qq
Mostrar menos información (sin desplazamiento/tamaño para -z, por ejemplo)
-Q
Mostrar dirección de carga utilizada por dlopen (libs sin aslr)
-r
Mostrar salida en formato radare
-R
Mostrar reubicaciones
-s
Mostrar símbolos exportados
-S
Mostrar secciones
-SS
Mostrar segmentos
-t
Mostrar hashes de archivos
-T
Mostrar certificados
-u
Sin filtrar (no renombrar símbolos/secciones duplicados)
-U
Mostrar recursos
-v
Mostrar información de versión
-V
Mostrar información de versión binaria
-w
Mostrar bloques try/catch
-x
Extraer todos los sub-binarios de un binario fat (por ejemplo: fatmach0)
-X formato archivo ...
Empaquetar un fat o zip que contenga todos los archivos pasados (fat, zip)
-z
Mostrar cadenas dentro de la sección .data (como hace el comando strings de gnu)
-Z
Adivinar el tamaño del programa binario
-zz
Muestra cadenas de binarios raw
-zzz
Volcar cadenas raw a stdout

NOMBRE

rabin2 - extractor de información de archivos binarios

SINOPSIS

rabin2 [-a] [-A] [-b] [-B] [-c] [-C] [-d] [-e] [-E] [-f file] [-F] [-h] [-i] [-I] [-k key] [-K] [-l] [-L] [-m] [-M] [-n] [-N] [-o] [-O] [-p] [-P] [-q] [-Q] [-r] [-R] [-s] [-S] [-t] [-T] [-u] [-U] [-v] [-w] [-x] [-X] [-z] [-Z] [file...]

DESCRIPCIÓN

rabin2 es una herramienta para extraer información de archivos binarios, como símbolos, cadenas, importaciones, exportaciones, etc.

-a
lista todas las arquitecturas
-A
lista todas las arquitecturas y sus características
-b
lista los bytes de un archivo binario
-B
lista las secciones de código
-c
lista los nombres de los compiladores
-C
descompila el código (solo para x86, ARM y MIPS)
-d
descodifica un archivo binario
-e
muestra el punto de entrada
-E
lista las exportaciones
-f file
lee la entrada desde el archivo especificado
-F
lista los formatos de archivo
-h
muestra la ayuda
-i
lista las importaciones
-I
lista los identificadores de UUID
-k key
especifica una clave para cifrar/descifrar
-K
muestra la tabla de claves
-l
lista las bibliotecas cargadas
-L
lista todas las bibliotecas disponibles
-m
muestra información del manifiesto
-M
muestra los metadatos
-n
muestra el nombre de la sección o símbolo
-N
lista los nombres de las secciones
-o
muestra la lista de seccionamiento
-O
muestra la lista de offset
-p
muestra la lista de cadenas de entrada
-P
muestra la lista de cadenas de salida
-q
modo silencioso
-Q
lista de consultas
-r
muestra el código ensamblador
-R
muestra la tabla de reubicación
-s
muestra la lista de símbolos
-S
muestra la lista de símbolos de la tabla de cadenas
-t
muestra la tabla de tipos
-T
muestra la tabla de tablas de hash
-u
muestra información de depuración
-U
muestra la tabla de nombres de las bibliotecas
-v
muestra la versión
-w
muestra la tabla de winsym
-x
muestra el contenido de la sección de texto
-X
muestra el contenido de la sección de datos
-z
muestra la lista de cadenas
-Z
muestra la lista de cadenas para archivos grandes

AMBIENTE

RABIN2_ARGS ignora la línea de comandos y usa estos argumentos en su lugar.

RABIN2_LANG igual que r2 -e bin.lang para rabin2.

RABIN2_DEMANGLE desmangling de símbolos.

RABIN2_MAXSTRBUF igual que r2 -e bin.maxstrbuf para rabin2.

RABIN2_DEBASE64 intenta decodificar todas las cadenas como base64 si es posible.

RABIN2_STRFILTER igual que r2 -e bin.str.filter para rabin2.

RABIN2_STRPURGE igual que r2 -e bin.str.purge para rabin2.

RABIN2_DEMANGLE_TRYLIB igual que r2 -e bin.demangle.trylib=<bool> - intenta cargar dinámicamente bibliotecas para desmangling.

RABIN2_VERBOSE igual que r2 -e bin.verbose=true.

EJEMPLOS

Listar símbolos de un programa


$ rabin2 -s a.out

Obtener el offset de un símbolo


$ rabin2 -n _main a.out

Obtener el punto de entrada


$ rabin2 -e a.out

Cargar símbolos e importaciones desde radare2


$ r2 -n /bin/ls
[0x00000000]> .!rabin2 -prsi $FILE
