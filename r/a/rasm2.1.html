RASM2(1) Manual de Comandos Generales RASM2(1)

NOMBRE

rasm2 — herramienta de ensamblaje y desensamblaje de radare2

SINOPSIS

rasm2 [-ABdDeEfCLvwrNqx] [-a arch] [-b bits] [-c cpu] [-F in:out] [-o offset] [-@ offset] [-O ofile] [-s syntax] [-i int] [-l int] [ARG]

DESCRIPCIÓN

Esta herramienta utiliza r_asm para ensamblar y desensamblar archivos o cadenas de pares hexadecimales. Soporta una gran lista de arquitecturas que pueden listarse usando la bandera -L.

-a arch
Establece el plugin de arquitectura
-A
Muestra la información de análisis de la cadena de pares hexadecimales dada
-b bits
Establece los bits de la arquitectura
-B
Entrada/salida binaria (-l es obligatorio para entrada binaria)
-c cpu
Selecciona una CPU específica (depende de -a arch)
-C
Salida en formato C
-d
Desensambla bytes de pares hexadecimales. rasm2 -d 9090
-D
Desensambla mostrando pares hexadecimales y opcode
-e
Usa big endian (o invierte el orden de los bytes si se usa más de una vez)
-E
Genera las instrucciones desensambladas en formato ESIL.
-f
Lee datos del archivo en lugar de ARG.
-F in:out
Especifica filtros de entrada y/o salida (att2intel, x86.pseudo, ...)
-h
Muestra el mensaje de ayuda de uso.
-hh
Muestra el mensaje de ayuda largo, incluyendo las directivas de ensamblador soportadas
-l int
Longitud de entrada/salida
-i int
Ignora/salta N bytes desde el principio del buffer de entrada
-L
Lista los plugins de asm cargados
-s offset
Offset del opcode a ensamblar (por defecto es 0)
-@ offset
Alias para -s
-N
No cargar ningún plugin, igual que R2_NOPLUGINS=1 o r2 -NN
-o ofile
salida a archivo, por ejemplo 'rasm2 -BF a a.asm'
-r
Muestra la salida en script de r2
-S syntax
Selecciona la sintaxis de salida (intel, att, masm, ...)
-w
Describe el opcode (qué es op)
-x
Usa dwords hexadecimales en lugar de pares hexadecimales en la salida del ensamblador
-q
Salida silenciosa (útil para -L, -v, ...)

DIRECTIVAS

Lista las directivas de ensamblador y preprocesador soportadas con:


$rasm2 -hh

EJEMPLOS

Ensamblar un opcode:


$ rasm2 -a x86 -b 32 'mov eax, 33'

Desensamblar un opcode:


$ rasm2 -d 90
