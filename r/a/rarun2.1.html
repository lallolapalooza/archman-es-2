RARUN2(1) Manual de Comandos Generales RARUN2(1)

NOMBRE

rarun2 — utilidad de radare2 para ejecutar programas en entornos exóticos

SINOPSIS

rarun2 [[directivas]] [[script.rr2]] [[--] [programa] [argumentos]]

DESCRIPCIÓN

Este programa se utiliza como lanzador para ejecutar programas con un entorno, argumentos, permisos, directorios y descriptores de archivo modificados diferentes.

rarun2 -t mostrará el nombre de la terminal y esperará una conexión de otro proceso. Intente rarun2 stdio=<ruta_ttypath> program=/bin/sh

El programa solo acepta un argumento que es el nombre del archivo de configuración para ejecutar el programa.

Es útil cuando se tiene que ejecutar un programa usando argumentos largos o pasar datos largos a stdin o cosas similares que suelen ser necesarias para explotar crackmes :)

DIRECTIVAS

El archivo de configuración rr2 (rarun2) acepta las siguientes directivas, descritas como entradas clave=valor y comentarios definidos como líneas que comienzan con '#'.

arg[0-N]
establecer el valor para el argumento N pasado al programa
aslr
habilitar o deshabilitar ASLR
bits
establecer 32 o 64 bits (si la arquitectura lo soporta)
chdir
cambiar de directorio antes de ejecutar el programa
chroot
ejecutar el programa en chroot. requiere alguna configuración previa
clearenv
desestablecer todo el entorno
core
establecer sin límite el tamaño del archivo core
times
valor booleano (true|false) para imprimir el tiempo de ejecución en milisegundos a stderr después de la ejecución del programa
connect
conectar stdin/stdout/stderr a un socket
pty
usar un pty para la conexión a través de socket (con connect/listen)
envfile
establecer un archivo con líneas como `var=valor` para ser utilizado como entorno
fork
utilizado con la opción listen, permite generar un proceso diferente para cada conexión. Ignorado durante la depuración.
input
establecer una cadena para ser pasada al programa a través de stdin
libpath
sobrescribir la ruta donde el cargador dinámico buscará bibliotecas compartidas
listen
enlazar stdin/stdout/stderr a un socket de escucha
maxstack
establecer el tamaño máximo de la pila
maxproc
establecer el número máximo de procesos
maxfd
establecer el número máximo de descriptores de archivo
nice
establecer el nivel de niceness del proceso
preload
pre-cargar una biblioteca (no soportado en Windows, solo linux, osx, bsd)
daemon
establecido a false por defecto, de lo contrario ejecutará el programa en segundo plano, separado de la terminal.
program
ruta al programa a ejecutar
execve
usar execve en lugar de posix_spawn (trucos de osx)
runlib
ruta a la biblioteca a ejecutar
runlib.fcn
nombre de la función a llamar desde la biblioteca runlib
r2preload
pre-cargar con libr2, enviar kill -USR1 para obtener un shell de r2 o -USR2 para generar un servidor web en un hilo
r2preweb
ejecutar el servidor web en un hilo justo al iniciar r2preload
setenv
establecer el valor para una variable de entorno dada
setegid
establecer el id de grupo del proceso efectivo
seteuid
establecer el uid del proceso efectivo
setgid
establecer el id de grupo del proceso
stderrout true|false
Redirigir el descriptor de archivo stderr a stdout
setuid
establecer el uid del proceso
sleep
dormir durante la cantidad de segundos dada
stdin
seleccionar archivo para leer datos desde stdin
stdout
seleccionar archivo para reemplazar el descriptor de archivo stdout
system
ejecutar el comando dado
timeout
establecer un tiempo de espera
timeoutsig
señal a usar al matar al hijo porque ocurre el tiempo de espera
unsetenv
desestablecer una variable de entorno

PREFIJOS DE VALOR

Cada valor en este archivo de configuración puede contener un especial

@nombrearchivo
Cargar el contenido del archivo y ponerlo dentro de la clave
texto
Escapar caracteres útiles para caracteres hexadecimales
'cadena'
Escapar caracteres útiles para caracteres hexadecimales
!comando
Ejecutar comando para almacenar la salida en la variable
:102030
Analizar cadena de pares hexadecimales y almacenarla en la variable
:!comando
Analizar cadena de pares hexadecimales desde la salida del comando y almacenarla en la variable
%1234
Analiza la cadena de entrada y la devuelve como entero

EJEMPLOS

Script de ejemplo de rarun2


$ cat foo.rr2
#!/usr/bin/rarun2
program=./pp400
arg0=10
stdin=foo.txt
chdir=/tmp
clearenv=true
setenv=EGG=eggsy
setenv=NOFUN=nogames
unsetenv=NOFUN
# EGG será la única variable de entorno
#chroot=.
./foo.rr2

Conectar un programa a un socket


$ nc -l 9999
$ rarun2 program=/bin/ls connect=localhost:9999

Depurar un programa redirigiendo IO a otra terminal


## abrir una nueva terminal y escribir 'tty' para obtener
$ tty ; clear ; sleep 999999
/dev/ttyS010
## en otra terminal ejecutar r2
$ r2 -r foo.rr2 -d ls
$ cat foo.rr2
#!/usr/bin/rarun2
stdio=/dev/ttys010
## O puedes usar -R para establecer un clave=valor
r2 -R stdio=/dev/ttys010 -d ls

También puedes usar el separador -- para especificar el programa y los argumentos de una manera más natural:


$ rarun2 timeout=2 -- sleep 4

Ejecutar una función de biblioteca


$ rarun2 runlib=/lib/libc-2.25.so runlib.fcn=system arg1="ls /"

ENTORNO


RARUN2_ARGS útil para simplemente ejecutar "rarun2" pero analizar argumentos desde la variable de entorno

rarun2(8)

rarun2 - ejecutar comandos en un entorno sandbox

SYNOPSIS

rarun2 [opciones] [programa] [argumentos...]

DESCRIPTION

rarun2 es un programa de seguridad que ejecuta programas en un entorno sandbox. El entorno sandbox puede ser configurado por el usuario usando directivas. Las directivas son opciones que especifican el comportamiento del sandbox. Algunas directivas comunes son:

  • chdir: cambia el directorio actual.
  • chroot: cambia la raíz del sistema de archivos.
  • exec: ejecuta un programa.
  • gid: establece el GID del proceso.
  • mount: monta un sistema de archivos.
  • net: habilita o deshabilita la red.
  • pid: establece el PID del proceso.
  • proc: configura el acceso al sistema de archivos /proc.
  • read_only_fs: monta el sistema de archivos como solo lectura.
  • rlimit_cpu: establece el límite de CPU.
  • rlimit_data: establece el límite de datos.
  • rlimit_fsize: establece el límite de tamaño de archivo.
  • rlimit_nofile: establece el límite de descriptores de archivo.
  • rlimit_stack: establece el límite de pila.
  • rlimit_nproc: establece el límite de procesos.
  • seccomp: habilita o deshabilita seccomp.
  • setgroups: establece el conjunto de grupos.
  • signal: envía una señal al proceso.
  • size: establece el tamaño de la memoria virtual.
  • uid: establece el UID del proceso.
  • unmount: desmonta un sistema de archivos.
  • usage: muestra información sobre el uso de recursos.
  • veth: crea una interfaz de red virtual.
  • write_barrier: habilita o deshabilita la barrera de escritura.

Las directivas se pueden especificar en la línea de comandos o en un archivo de configuración. El archivo de configuración por defecto es ~/.config/rarun2/default.conf.

VALUE PREFIXES

rarun2 utiliza prefijos para especificar el tipo de valor que se espera para una directiva. Los prefijos comunes son:

  • @: una ruta de archivo.
  • /: una ruta de directorio.
  • %: un número entero.
  • $: una variable de entorno.
  • <: una cadena.

EXAMPLES

Aquí hay algunos ejemplos de cómo usar rarun2:

# Ejecutar el comando `ls` en un entorno sandbox con el directorio actual como solo lectura.
rarun2 'read_only_fs=/, ls'

# Ejecutar el comando `cat` con un GID específico y sin acceso a la red.
rarun2 'gid=1000, net=0, cat /etc/passwd'

# Ejecutar un programa compilado con `gcc` en un directorio específico y con un límite de CPU.
rarun2 'chdir=/tmp, rlimit_cpu=10, gcc main.c -o main'

# Crear un entorno sandbox con un sistema de archivos solo lectura, un directorio montado y sin red.
rarun2 'read_only_fs=/, mount=/tmp, rw,tmpfs, none, net=0, /bin/bash'

ENVIRONMENT

rarun2 utiliza las siguientes variables de entorno:

  • RARUN2_CONF: especifica la ruta al archivo de configuración.
