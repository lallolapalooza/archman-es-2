RAVC2(1) Manual de comandos generales RAVC2(1)

NOMBRE

ravc2 — control de versiones de radare

SINOPSIS

ravc2 [-hv] [[expresión] ...]

DESCRIPCIÓN

Este comando es parte del proyecto radare.

Implementa un sistema de control de versiones simple que tiene como objetivo funcionar como frontend para git, así como su propia estructura para versionar los cambios del proyecto.

Este comando es bastante nuevo y experimental.

OPCIONES

-h
Mostrar mensaje de ayuda de uso
-v
Mostrar versión

USO

Los tipos de variables disponibles son:


ravc2 init
echo hola mundo > README.md
ravc2 add README.md
ravc2 branch
ravc2 commit

ENTORNO


RAVC2_USER anula cfg.user, que se basa en r_sys_whoami() que se utiliza para definir el autor de las confirmaciones de VC.
