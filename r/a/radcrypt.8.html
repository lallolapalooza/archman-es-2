RADCRYPT(8) Manual del Administrador del Sistema RADCRYPT(8)

NOMBRE

radcrypt - genera un hash de contraseña para usar con radius, o valida un hash de contraseña

SINOPSIS

radcrypt [-d|--des] [-m|--md5] [-c|--check] contraseña_texto_plano [hash_contraseña]

DESCRIPCIÓN

radcrypt genera un resumen cifrado de una contraseña en texto plano, o puede validar si un hash de contraseña coincide con una contraseña en texto plano. Actualmente se admiten hashes DES y MD5. Al generar un hash de contraseña, se genera y aplica una sal aleatoria.

Se puede validar un hash de contraseña especificando -c o --check y pasando hash_contraseña después de contraseña_texto_plano en la línea de comandos. En este caso, se comprobará hash_contraseña para ver si coincide con contraseña_texto_plano. Si es así, se imprimirá "Password OK" y el estado de salida será 1; de lo contrario, se imprimirá "Password BAD" y el estado de salida será 0 (tenga en cuenta que esto es lo opuesto a un estado normal de éxito en la shell).

OPCIONES

-d --des
Utiliza un hash DES (Data Encryption Standard) (predeterminado). Se ignora si se realiza una comprobación de contraseña.
-m --md5
Utiliza un hash MD5 (Message Digest 5). Se ignora si se realiza una comprobación de contraseña.
-c --check
Realiza una comprobación de validación en un hash de contraseña para verificar si coincide con la contraseña en texto plano.

EJEMPLOS

$ radcrypt foobar
HaX0xn7Qy650Q
$ radcrypt -c foobar HaX0xn7Qy650Q
Password OK

VER TAMBIÉN

radiusd(8), crypt(3)
