NOMBRE

rauc - actualización segura y protegida

SINOPSIS

rauc [OPCIONES...] bundle DIR_ENTRADA BUNDLE

rauc [OPCIONES...] resign BUNDLE_ENTRADA BUNDLE_SALIDA

rauc [OPCIONES...] extract BUNDLE DIR_SALIDA

rauc [OPCIONES...] extract-signature BUNDLE FIRMA_SALIDA

rauc [OPCIONES...] convert BUNDLE_ENTRADA BUNDLE_SALIDA

rauc [OPCIONES...] encrypt BUNDLE_ENTRADA BUNDLE_SALIDA

rauc [OPCIONES...] install BUNDLE

rauc [OPCIONES...] info BUNDLE

rauc [OPCIONES...] mount BUNDLE

rauc [OPCIONES...] status [NOMBRE_SLOT | mark-{good,bad,active} [booted|other|NOMBRE_SLOT]]

rauc [OPCIONES...] write-slot NOMBRE_SLOT ARCHIVO_IMAGEN

DESCRIPCIÓN

RAUC es un cliente de actualización ligero que se ejecuta en un dispositivo Linux Embebido y controla de manera confiable el procedimiento de actualización del dispositivo con un nuevo firmware.

RAUC es también la herramienta en el sistema host que se utiliza para crear, inspeccionar y modificar archivos de actualización ("bundles") para el dispositivo.

Esta página del manual documenta brevemente la utilidad de línea de comandos rauc.

Fue escrita para la distribución Debian GNU/Linux para cumplir con los requisitos de empaquetado. Por lo tanto, solo debe servir como un resumen; se recomienda leer el manual en línea completo (https://rauc.readthedocs.io/).

OPCIONES

Las siguientes opciones generales se pueden usar con la mayoría de los comandos, sin embargo, no todas las combinaciones tienen sentido.

-c NOMBRE_ARCHIVO, --conf=NOMBRE_ARCHIVO
usa el archivo de configuración dado en lugar del que se encuentra en la ruta predeterminada compilada.
-C SECCIÓN:CLAVE=VALOR, --confopt=SECCIÓN:CLAVE=VALOR
Anula los parámetros del archivo de configuración con los ajustes de configuración especificados. Si el parámetro especificado no está presente en el archivo de configuración, aún se establecerá con esta opción.
--keyring=ARCHIVO_PEM
usa un archivo de keyring específico.
--mount=RUTA
prefijo de montaje (/mnt/rauc por defecto).
-d, --debug
habilita la salida de depuración.
--version
muestra la versión.
-h, --help
imprime el uso.

COMANDOS

bundle DIR_ENTRADA BUNDLE

Crea un bundle a partir de un directorio de contenido.

Opciones:

--cert=ARCHIVO_PEM|URL_PKCS11
usa el archivo de certificado dado o el certificado referenciado por la URL PKCS#11 dada.
--key=ARCHIVO_PEM|URL_PKCS11
usa el archivo de clave privada dado o la clave referenciada por la URL PKCS#11 dada.
--intermediate=ARCHIVO_PEM|URL_PKCS11
archivo CA intermedio o el certificado referenciado por la URL PKCS#11 dada.
--signing-keyring=ARCHIVO_PEM
archivo de keyring de verificación.
--mksquashfs-args=ARGS
argumentos adicionales para mksquashfs.

resign BUNDLE_ENTRADA BUNDLE_SALIDA

Vuelve a firmar un bundle ya firmado.

Opciones:

--append
añade en lugar de reemplazar la firma.
--cert=ARCHIVO_PEM|URL_PKCS11
usa el archivo de certificado dado o el certificado referenciado por la URL PKCS#11 dada.
--key=ARCHIVO_PEM|URL_PKCS11
usa el archivo de clave privada dado o la clave referenciada por la URL PKCS#11 dada.
--intermediate=ARCHIVO_PEM|URL_PKCS11
archivo CA intermedio o el certificado referenciado por la URL PKCS#11 dada.
--no-verify
deshabilita la verificación del bundle.
--no-check-time
no comprueba el período de validez de los certificados con la hora actual.
--signing-keyring=ARCHIVO_PEM
archivo de keyring de verificación.

extract BUNDLE DIR_SALIDA

Extrae el contenido del bundle a un directorio.

Opciones:

--key=ARCHIVO_PEM|URL_PKCS11
usa el archivo de clave de descifrado dado o la clave de descifrado referenciada por la URL PKCS#11 dada.
--trust-environment
confía en el entorno y omite las comprobaciones de acceso al bundle.

extract-signature BUNDLE FIRMA_SALIDA

Extrae la firma del bundle.

Opciones:

--key=ARCHIVO_PEM|URL_PKCS11
usa el archivo de clave de descifrado dado o la clave de descifrado referenciada por la URL PKCS#11 dada.
--trust-environment
confía en el entorno y omite las comprobaciones de acceso al bundle.

convert BUNDLE_ENTRADA BUNDLE_SALIDA

Convierte un bundle existente en un bundle de índice casync y almacénalo.

Opciones:

--cert=ARCHIVO_PEM|URL_PKCS11
usa el archivo de certificado dado o el certificado referenciado por la URL PKCS#11 dada.
--key=ARCHIVO_PEM|URL_PKCS11
usa el archivo de clave privada dado o la clave referenciada por la URL PKCS#11 dada.
--intermediate=ARCHIVO_PEM|URL_PKCS11
archivo CA intermedio o el certificado referenciado por la URL PKCS#11 dada.
--trust-environment
confía en el entorno y omite las comprobaciones de acceso al bundle.
--no-verify
deshabilita la verificación del bundle.
--signing-keyring=ARCHIVO_PEM
archivo de keyring de verificación.
--mksquashfs-args=ARGS
argumentos adicionales para mksquashfs.
--casync-args=ARGS
argumentos adicionales para casync.
--ignore-image=CLASE_SLOT
ignora la imagen durante la conversión.

encrypt BUNDLE_ENTRADA BUNDLE_SALIDA

Cifra un bundle cifrado.

Opciones:

--key=ARCHIVO_PEM|URL_PKCS11
usa el archivo de clave privada dado o la clave referenciada por la URL PKCS#11 dada.
--cert=ARCHIVO_PEM|URL_PKCS11
usa el archivo de certificado dado o el certificado referenciado por la URL PKCS#11 dada.
--intermediate=ARCHIVO_PEM|URL_PKCS11
archivo CA intermedio o el certificado referenciado por la URL PKCS#11 dada.

install BUNDLE

Instala un bundle en el dispositivo.

Opciones:

--force
ignora las comprobaciones de estado y procede con la instalación.
--skip-verify
salta la verificación del bundle antes de la instalación.

info BUNDLE

Muestra información sobre el bundle.

Opciones:

--key=ARCHIVO_PEM|URL_PKCS11
usa el archivo de clave de descifrado dado o la clave de descifrado referenciada por la URL PKCS#11 dada.
--trust-environment
confía en el entorno y omite las comprobaciones de acceso al bundle.
--no-verify
deshabilita la verificación del bundle.

mount BUNDLE

Monta el contenido del bundle.

Opciones:

--key=ARCHIVO_PEM|URL_PKCS11
usa el archivo de clave de descifrado dado o la clave de descifrado referenciada por la URL PKCS#11 dada.
--trust-environment
confía en el entorno y omite las comprobaciones de acceso al bundle.
--no-verify
deshabilita la verificación del bundle.

status [NOMBRE_SLOT | mark-{good,bad,active} [booted|other|NOMBRE_SLOT]]

Obtiene o establece el estado de la actualización.

Opciones:

--args=STRING
argumentos para la operación de marcado.

write-slot NOMBRE_SLOT ARCHIVO_IMAGEN

Escribe una imagen en una ranura específica.

Opciones:

--force
fuerza la escritura, incluso si la ranura ya tiene contenido.

certificado(s) del destinatario

install BUNDLE

Instala un paquete.

Opciones:

--ignore-compatible
deshabilita la comprobación de compatibilidad
--ignore-version-limit=
deshabilita la comprobación de versión
--transaction-id=UUID
ID de transacción personalizado
--require-manifest-hash=HASH

--progress

--tls-cert=PEMFILE|PKCS11-URL
archivo de certificado de cliente TLS o URL PKCS#11
--tls-key=PEMFILE|PKCS11-URL

--tls-ca=PEMFILE
archivo CA de TLS
--tls-no-verify
no verifica el certificado del servidor TLS
-H, --http-header='HEADER: VALUE'
encabezado de solicitud HTTP (se admiten usos múltiples)
--handler-args=ARGS

--override-boot-slot=BOOTNAME

info BUNDLE

Muestra la información del paquete.

Opciones:

--no-verify
deshabilita la verificación del paquete
--no-check-time
no comprueba el período de validez de los certificados con la hora actual
--key=PEMFILE|PKCS11-URL

--output-format=[readable|shell|json|json-pretty|json-2]
selecciona el formato de salida

El formato de salida json-2 coincide con la estructura de la API D-Bus InspectBundle y debe usarse en lugar de json o json-pretty.

--dump-cert
muestra el certificado
--dump-recipients
muestra los destinatarios

mount BUNDLE

Monta un paquete para fines de desarrollo en el directorio de paquetes en el prefijo de montaje de RAUC. Debe ser desmontado manualmente por el usuario.

status [SLOTNAME | mark-{good,bad,active} [booted|other|SLOTNAME]]

Sin un subcomando adicional, simplemente muestra el estado del sistema o el estado de una ranura específica.

Los subcomandos mark-good y mark-bad se pueden usar para establecer explícitamente el estado de una ranura. Estos subcomandos normalmente operan en la ranura actualmente arrancada si no se especifica un parámetro adicional.

El subcomando mark-active permite cambiar manualmente a una ranura diferente. Aquí también, la ranura deseada se puede dar por parámetro, de lo contrario se usa la actualmente arrancada.

Opciones:

--detailed
muestra más detalles del estado
--output-format=[readable|shell|json|json-pretty]
selecciona el formato de salida
--override-boot-slot=BOOTNAME
anula la detección automática de la ranura arrancada

write-slot SLOTNAME IMAGEFILE

Escribe manualmente una imagen en la ranura (usando el controlador de actualización de ranura). ¡Esto omite toda la demás lógica de actualización y es solo para desarrollo o uso especial!

Opciones:

--image-type
Selecciona el tipo de imagen explícito a usar.

ENTORNO

RAUC_KEY_PASSPHRASE
Frase de contraseña para usar al acceder a los archivos clave (solo firma)
RAUC_PKCS11_MODULE
Nombre del archivo de biblioteca para el módulo PKCS#11 (solo firma)
RAUC_PKCS11_PIN
PIN a usar para acceder a las claves PKCS#11 (solo firma)

ARCHIVOS

/etc/rauc/system.conf, /run/rauc/system.conf, /usr/lib/rauc/system.conf

El archivo de configuración del sistema es la configuración central en RAUC que abstrae la configuración de almacenamiento de acoplamiento suelto, el particionamiento y la estrategia de arranque de su placa a una vista coherente del mundo de configuración de redundancia para RAUC.

Los archivos de configuración de RAUC se cargan desde uno de los directorios listados en orden de prioridad, solo se usa el primer archivo encontrado: /etc/rauc/, /run/rauc/, /usr/lib/rauc/.

Se espera que system.conf describa el sistema en el que se ejecuta RAUC de tal manera que se proporcione toda la información relevante para realizar actualizaciones y tomar decisiones.

Similar a otros archivos de configuración utilizados por RAUC, la configuración del sistema utiliza una sintaxis de clave-valor (similar a las conocidas de los archivos .ini).
