NOMBRE

radzap - eliminar entradas erróneas de la base de datos de sesiones activas

SINOPSIS

radzap [-d directorio_raddb] [-h] [-N direccion_ip_nas] [-P puerto_nas] [-u usuario] [-U usuario] [-x] servidor[:puerto] secreto

DESCRIPCIÓN

El servidor FreeRADIUS puede configurarse para mantener una base de datos de sesiones activas en un archivo llamado radutmp. Comandos como radwho(1) utilizan esta base de datos. A veces, esa base de datos puede desincronizarse y contener entradas erróneas. radzap puede limpiar esta base de datos.

A partir de FreeRADIUS 1.1.0, radzap es un simple script wrapper (envoltorio) para radwho(1) y radclient(1).

Las sesiones se "eliminan" enviando un paquete Accounting-Request que contiene la información necesaria para que el servidor elimine el registro de la sesión. radzap envía un paquete al servidor, en lugar de escribir directamente en radutmp, ya que los registros de sesiones también pueden mantenerse en SQL.

OPCIONES

-d directorio_raddb
El directorio que contiene los archivos de configuración de RADIUS. radzap lee radiusd.conf para determinar la ubicación del archivo radutmp.
-h
Imprime la información de ayuda de uso.
-N direccion_ip_nas
Elimina las entradas que coinciden con la dirección IP del NAS dada.
-P puerto_nas
Elimina las entradas que coinciden con el puerto NAS dado.
-u usuario
Elimina las entradas que coinciden con el nombre de usuario dado (sin distinguir mayúsculas y minúsculas).
-U usuario
Elimina las entradas que coinciden con el nombre de usuario dado (distinguiendo mayúsculas y minúsculas).
-x
Habilita la salida de depuración.
servidor[:puerto]
El nombre de host o la dirección IP del servidor remoto. Opcionalmente se puede especificar un puerto UDP. Si no se especifica ningún puerto UDP, se busca en /etc/services. El nombre del servicio buscado es radacct para paquetes de contabilidad y radius para todas las demás solicitudes. Si no se encuentra un servicio en /etc/services, se utilizan 1813 y 1812 respectivamente.
secreto
El secreto compartido para este cliente. Debe definirse también en el lado del servidor radius, para la dirección IP desde la que se envían los paquetes radius.

VER TAMBIÉN

radwho(1), radclient(1), radiusd(8), radiusd.conf(5).
