NOMBRE

rage-mount - Montar un sistema de archivos cifrado con age

SINOPSIS

rage-mount [-h|--help] [-V|--version] [--max-work-factor] <-t|--types> [-i|--identity] <FILENAME> <MOUNTPOINT>

DESCRIPCIÓN

rage-mount descifra el sistema de archivos cifrado con age en FILENAME al vuelo y lo monta como un directorio en el sistema de archivos local en MOUNTPOINT.

Los archivos cifrados con contraseña se detectan automáticamente y se solicita la contraseña de forma interactiva. De lo contrario, se utiliza una o más IDENTIDADES especificadas con -i/--identity para descifrar el archivo.

Los contenidos anteriores (si los hay), el propietario y el modo de MOUNTPOINT se vuelven invisibles, y mientras este sistema de archivos permanezca montado, la ruta MOUNTPOINT se referirá a la raíz del sistema de archivos en FILENAME.

OPCIONES

-h, --help
Imprime este mensaje de ayuda y sale.
-V, --version
Imprime información de la versión y sale.
--max-work-factor=WF
Factor de trabajo máximo permitido para el descifrado de contraseñas.
-t, --types=TYPES
Establece el tipo de sistema de archivos. Los siguientes tipos son compatibles actualmente: "tar", "zip".

Esta opción es obligatoria. rage-mount no intenta adivinar el formato del sistema de archivos.

En teoría, se puede admitir cualquier formato de sistema de archivos con búsqueda eficiente. Actualmente, rage-mount solo admite formatos de archivo con búsqueda.

-i, --identity=IDENTITY
Descifra usando las IDENTIDADES en IDENTITY.

IDENTITY puede ser una de las siguientes:

a. Un archivo que lista las IDENTIDADES una por línea. Las líneas vacías y las líneas que comienzan con "#" se ignoran como comentarios.

b. Un archivo age cifrado con contraseña, que contiene IDENTIDADES una por línea como las anteriores. Se solicita la contraseña de forma interactiva. Tenga en cuenta que los archivos de identidad protegidos con contraseña no son necesarios para la mayoría de los casos de uso, donde el acceso al archivo de identidad cifrado implica el acceso a todo el sistema.

c. Un archivo de clave privada SSH, en formato PKCS#1, PKCS#8 o OpenSSH. Si la clave privada está protegida con contraseña, se solicita la contraseña de forma interactiva solo si la identidad SSH coincide con el archivo. Consulte la sección de claves SSH para obtener más información, incluidos los tipos de claves admitidos.

d. "-", lo que hace que se lea una de las opciones anteriores desde la entrada estándar. En este caso, se debe especificar el argumento INPUT.

Esta opción puede repetirse. Las identidades se prueban en el orden en que se proporcionan, y se utiliza la primera que coincide con uno de los destinatarios del archivo. Las identidades no utilizadas se ignoran, pero es un error si el archivo INPUT está cifrado con contraseña y se especifica -i/--identity.

<FILENAME>
El sistema de archivos cifrado a montar.
<MOUNTPOINT>
El directorio donde montar el sistema de archivos.

EJEMPLOS

Montar un archivo cifrado para un destinatario:

$ rage-mount -t tar -i key.txt encrypted.tar.age ./tmp
Montar un archivo cifrado con una contraseña:

$ rage-mount -t zip encrypted.zip.age ./tmp
