RADRELAY(8) Servidor FreeRADIUS RADRELAY(8)

NOMBRE

radrelay -- Comando obsoleto.

DESCRIPCIÓN

Las funciones de radrelay se han añadido a radiusd. Un beneficio es que una instancia de radiusd puede leer múltiples archivos de detalle, entre otros.

El módulo rlm_sql_log hace algo similar, pero para consultas SQL. Ver su página del manual para más detalles.

REPLICACIÓN PARA COPIAS DE SEGURIDAD

Muchos sitios ejecutan múltiples servidores RADIUS; al menos un servidor principal y uno de respaldo. Cuando el principal falla, la mayoría de los NAS lo detectan y cambian al servidor de respaldo.

Eso hará que sus paquetes de contabilidad vayan al servidor de respaldo, y algunos NAS ni siquiera vuelven al servidor principal cuando este vuelve a estar en línea.

El resultado es que se pierden registros de contabilidad y/o el administrador debe hacer malabares para combinar los diferentes archivos de detalle de múltiples servidores. También significa que la base de datos de sesiones ("radutmp", utilizada para radwho y detección de uso simultáneo) se desincroniza.

Solucionamos este problema "retransmitiendo" paquetes de un servidor a otro, para que ambos tengan el mismo conjunto de datos de contabilidad.

Ver raddb/sites-available/buffered-sql para más información.

ALMACENAMIENTO TEMPORAL PARA SERVIDORES DE ALTA CARGA

Si el servidor RADIUS recibe repentinamente muchos paquetes de contabilidad, puede que no haya suficiente potencia de CPU para procesarlos todos a tiempo. Este problema es especialmente notable cuando los paquetes de contabilidad van a una base de datos de backend.

De manera similar, puede tener una base de datos que rastrea las sesiones "en vivo", y otra que rastrea los datos de contabilidad históricos. En ese caso, el acceso a la primera base de datos es rápido, ya que es pequeña. El acceso a la segunda base de datos puede ser más lento, ya que puede contener varios gigabytes de datos. Además, escribir en la primera base de datos a tiempo es importante, mientras que los datos pueden escribirse en la segunda base de datos con unos minutos de retraso, sin que ocurra ningún daño.

Ver raddb/sites-available/copy-to-home-server para más información.

VER TAMBIÉN

radiusd(8), rlm_sql_log(5)
