NOMBRE

razer.conf - archivo de configuración para el Demonio OpenRazer

DESCRIPCIÓN

El archivo ~/.config/openrazer/razer.conf (se respeta $XDG_CONFIG_HOME, si está establecido) configura algunas opciones de inicio y ejecución del openrazer-daemon(8). El openrazer-daemon(8) es capaz de utilizar archivos de configuración especificados en ubicaciones no estándar proporcionando el argumento --config.

El archivo de configuración tiene el formato de un archivo .INI y es analizado por ConfigParser de Python.

EJEMPLO

Un archivo de ejemplo debería estar instalado en /usr/share/openrazer/razer.conf.example.

SECCIONES

GENERAL

La primera sección del archivo de configuración es una sección [General]. Esta sección contiene opciones misceláneas.

verbose_logging bool

Esta bandera especifica si el demonio debe emitir información de registro detallada. Este valor actúa igual que si se pasara -v o --verbose en la línea de comandos.

ARRANQUE

La sección [Startup] en el archivo de configuración contiene valores a usar durante el arranque, por ejemplo, puede decidir si los efectos de sincronización estarán activos al iniciarse.

sync_effects_enabled bool

Esta bandera especifica si la lógica de sincronización de efectos está activa cuando se inicia el demonio, sin tener que esperar a que el usuario los active.

devices_off_on_screensaver bool

Esta bandera especifica si la funcionalidad para apagar los dispositivos Razer cuando se activa el salvapantallas está activa cuando se inicia el demonio.

battery_notifier bool

Esta bandera especifica que se mostrarán notificaciones regularmente con el nivel de batería restante.

battery_notifier_freq int

Esta bandera especifica con qué frecuencia se mostrará la notificación con el nivel de batería restante.

battery_notifier_percent int

Esta bandera especifica qué porcentaje de batería debe alcanzar el dispositivo antes de enviar notificaciones.

restore_persistence bool

Esta bandera especifica si los efectos guardados en persistence.conf se aplicarán cuando el demonio se inicie.

persistence_dual_boot_quirk bool

Esta bandera especifica si el efecto persistente se aplica dos veces para abordar una peculiaridad con dispositivos más nuevos que fueron modificados por última vez por Razer Synapse en Windows. Solo aplicable con restore_persistence = True.
