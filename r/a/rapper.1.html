rapper(1) General Commands Manual rapper(1)

NOMBRE

rapper - Utilidad de análisis y serialización Raptor RDF

SINOPSIS

rapper [OPCIONES] URI-ENTRADA [URI-BASE-ENTRADA]

EJEMPLO

rapper -o ntriples http://planetrdf.com/guide/rss.rdf
rapper -irss-tag-soup -orss-1.0 pile-of-rss.xml http://example.org/base/
rapper --count http://example.org/index.rdf

DESCRIPCIÓN

La utilidad rapper permite el análisis de contenido RDF por el kit de herramientas de análisis RDF Raptor emitiendo los resultados como tripletas RDF en una selección de sintaxis. La URI-ENTRADA puede ser un nombre de archivo, '-' para la entrada estándar o si Raptor está compilado con una biblioteca de recuperación WWW, una URI general. La opcional URI-BASE-ENTRADA se usa como la URI base del analizador del documento si está presente, de lo contrario, se utiliza la URI-ENTRADA por defecto. Un valor de '-' significa que no hay URI base.

OPCIONES

rapper utiliza la sintaxis habitual de línea de comandos de GNU, con opciones largas que comienzan con dos guiones (`-') si son compatibles con la función getopt_long. De lo contrario, solo están disponibles las opciones cortas.

-h, --help
Muestra un resumen de las opciones.
-i, --input FORMAT
Establece el FORMATO de entrada en uno de 'rdfxml' (RDF/XML, por defecto), 'ntriples' (N-Triples, véase abajo), 'turtle' (Turtle, véase abajo) o 'rss-tag-soup' (RSS Tag Soup). El analizador RSS Tag Soup puede convertir los muchos formatos XML RSS, Atom 0.3 y Atom 1.0 en tripletas RDF.
La lista de analizadores depende de cómo se compiló libraptor(3). La lista de analizadores compatibles se proporciona en el resumen de ayuda dado por -h.
-I, --input-uri URI
Establece la URI base de entrada/analizador o usa el valor '-' para no tener base. El valor por defecto es el valor del argumento URI-ENTRADA.
-o, --output FORMAT
Establece el FORMATO de salida en 'ntriples' (N-Triples, por defecto), 'rdfxml' (RDF/XML), 'rdfxml-abbrev' (RDF/XML con abreviaturas) o 'rss-1.0' (RSS 1.0, también una sintaxis RDF/XML).
La lista de serializadores depende de cómo se compiló libraptor(3). La lista de serializadores compatibles se proporciona en el resumen de ayuda dado por -h.
-O, --output-uri URI
Establece la URI base de salida/serializador o usa el valor '-' para no tener base. El valor por defecto es la URI base de entrada, ya sea establecida por el argumento URI-BASE-ENTRADA o mediante las opciones -I, --input-uri URI
-c, --count
Solo cuenta las tripletas y no produce ninguna otra salida.
-e, --ignore-errors
Ignora los errores, no emite los mensajes y trata de continuar el análisis.
-f, --feature CARACTERÍSTICA[=VALOR]
Establece una característica del analizador o serializador CARACTERÍSTICA a un valor, o a 1 si se omite VALOR. Usa -f help para obtener listas de características válidas del analizador y serializador.
Si se utiliza la forma -f 'xmlns:prefijo="uri"', el prefijo y la URI del espacio de nombres proporcionados se establecerán para la serialización. La sintaxis coincide con la de XML en que se puede omitir el prefijo o la URI, o ambos.
-g, --guess
Adivina el analizador a usar a partir de la URI de origen en lugar de usar el FORMATO -i.
-q, --quiet
Ningún mensaje de información adicional.
-r, --replace-newlines
Reemplaza los saltos de línea en literales multilínea con espacios.
--show-graphs
Imprime los nombres de los gráficos (URIs) tal como se ven en la entrada. Esto solo tiene significado para los analizadores que admiten nombres de gráfico, como el analizador TRiG.
--show-namespaces
Imprime los espacios de nombres tal como se ven en la entrada.
-t, --trace
Imprime las URIs recuperadas durante el análisis. Especialmente útil para monitorizar lo que hacen los analizadores guess y GRDDL.
-w, --ignore-warnings
Ignora las advertencias, no emite los mensajes.
-v, --version
Imprime la versión de raptor y sale.

EJEMPLOS

rapper -q -i ntriples -o rdfxml -f 'xmlns:rss="http://purl.org/rss/1.0/"' -f 'xmlns:ex="http://example.org/"' tests/test.nt
rapper -q -o rdfxml -f 'xmlns:rdfs="http://www.w3.org/2000/01/rdf-schema#"' tests/rdf-schema.rdf 'http://www.w3.org/2000/01/rdf-schema#'

rapper(1) — Páginas del manual de Arch Linux

NOMBRE

rapper - un analizador de RDF y generador de serialización

SINOPSIS

rapper [OPCIONES] [ARCHIVO ...]

EJEMPLO

rapper -i turtle -o ntriples example.ttl

DESCRIPCIÓN

rapper es una utilidad de línea de comandos para analizar y serializar datos RDF utilizando la biblioteca librdf. Permite convertir entre varios formatos RDF y realizar operaciones básicas con ellos.

OPCIONES

-i, --input-format <formato>
Especifica el formato de entrada (ej. turtle, rdfxml, ntriples). Si no se especifica, rapper intentará detectar el formato automáticamente.
-o, --output-format <formato>
Especifica el formato de salida (ej. turtle, rdfxml, ntriples). Si no se especifica, se usa el formato por defecto (generalmente ntriples).
--input-encoding <codificación>
Especifica la codificación de entrada (ej. utf-8).
--output-encoding <codificación>
Especifica la codificación de salida (ej. utf-8).
--pretty
Formatea la salida de manera legible.
-h, --help
Muestra la ayuda y sale.
-V, --version
Muestra la información de la versión y sale.

EJEMPLOS

Convertir un archivo RDF/XML a Turtle: 

rapper -i rdfxml -o turtle input.rdf > output.ttl

Analizar un archivo N-Triples y mostrarlo formateado: 

rapper -i ntriples --pretty input.nt

CONFORME A

rapper está diseñado para ser compatible con varias serializaciones y vocabularios RDF, incluyendo RDF/XML, Turtle, N-Triples, y más, según lo soportado por librdf.

VER TAMBIÉN
