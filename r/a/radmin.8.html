RADMIN(8) Herramienta de administración del servidor FreeRADIUS RADMIN(8)

NOMBRE

radmin - Herramienta de administración del servidor FreeRADIUS

SINOPSIS

radmin [-d directorio_config] [-D directorio_diccionarios] [-e comando] [-E] [-f archivo_socket] [-h] [-i archivo_entrada] [-n nombre] [-q]

DESCRIPCION

Herramienta de administración del servidor FreeRADIUS que se conecta al socket de control de un servidor en ejecución y proporciona una interfaz de línea de comandos.

En este momento, solo se admiten unos pocos comandos. Escriba "help" en el prompt de comandos para obtener información detallada sobre los comandos admitidos.

ADVERTENCIA

Las protecciones de seguridad que ofrece este comando se limitan a los permisos del socket de dominio Unix y la configuración del servidor. Si alguien puede conectarse al socket de dominio Unix, tiene una cantidad sustancial de control sobre el servidor.

OPCIONES

El programa acepta las siguientes opciones de línea de comandos.

-d directorio de configuración
Por defecto es /etc/raddb. radmin busca aquí los archivos de configuración del servidor para encontrar la sección "listen" que define el nombre del archivo del socket de control.
-D directorio de diccionarios
Establece el directorio principal de diccionarios. Por defecto es /usr/share/freeradius.
-e comando
Ejecuta el comando y sale.
-E
Muestra los comandos mientras se ejecutan.
-f archivo_socket
Especifica directamente el nombre del archivo del socket. No se lee el archivo radiusd.conf.
-h
Muestra la información de ayuda de uso.
-i archivo_entrada
Lee la entrada del archivo especificado. Si no se especifica, se usa la entrada estándar. Esto también establece "-q".
-n nombre
Lee raddb/nombre.conf en lugar de raddb/radiusd.conf.
-q
Modo silencioso.

COMANDOS

Los comandos implementados por la interfaz de línea de comandos están controlados casi por completo por el servidor. Hay algunos comandos interpretados localmente por radmin:

reconnect
Reconecta al servidor.
quit
Sale de radmin.
exit
Sale de radmin.

Los demás comandos son implementados por el servidor. Escriba "help" en el prompt para obtener más información.

EJEMPLOS

debug file /var/log/radius/bob.log
Establece los logs de depuración en /var/log/radius/bob.log. Hay muy poca comprobación de este nombre de archivo. Los administradores pícaros pueden utilizar este comando para sobrescribir casi cualquier archivo del sistema. Si esos administradores tienen acceso de escritura a "radius.conf", también pueden hacer lo mismo sin radmin.
debug condition '(User-Name == "bob")'
Habilita la salida de depuración para todas las solicitudes que coincidan con la condición. Cualquier condición "unlang" es válida aquí. La condición se analiza como una cadena, por lo que debe ir entre comillas simples o dobles. Las cadenas entre comillas dobles deben tener barras invertidas y las comillas escapadas dentro de la cadena.

Solo una condición de depuración puede estar activa a la vez.

debug condition '((User-Name == "bob") || (Packet-Src-IP-Address == 192.0.2.22))'
Una condición más compleja que habilita la salida de depuración para las solicitudes que contienen User-Name "bob", o solicitudes que se originan desde la dirección IP de origen 192.0.2.22.
debug condition
Deshabilita los condicionales de depuración.

radmin(8) - Arch manual pages

NAME

radmin - RADIUS administration client

SYNOPSIS

radmin [-n instance] [-C config-file] [-s socket] command [arguments ...]

DESCRIPTION

radmin is a command-line utility for administering a running FreeRADIUS server. It communicates with the server via a control socket.

By default, it connects to the control socket specified in radiusd.conf, or to /var/run/radiusd/radiusd.sock.

The radmin utility can only be used to administer a server which was started with the radiusd -l control option.

The default instance is "default". This can be overridden with the -n option. See radiusd.conf(5) for more details about instances.

WARNING

The control socket can be used to execute arbitrary commands on the server. It should be protected by file permissions, and should not be accessible by untrusted users.

OPTIONS

-n instance
Use the specified instance name. This defaults to "default".
-C config-file
Use the specified configuration file. This defaults to /etc/raddb/radiusd.conf.
-s socket
Use the specified control socket. This overrides the socket defined in the configuration file.

COMMANDS

The following commands are available:

exit
Exits the radmin client.
radmin
Prints usage information.
reload
Reloads the server configuration.
restarting
Requests the server to restart.
shutdown
Requests the server to shut down.
show command
do sub-command of show
stats command
do sub-command of stats
terminate connection
terminates the given connection
usersclear
Clear the users file cache.
usersrefresh
Reload the users file.

EXAMPLES

To reload the server configuration:

radmin reload

To show the status of the server:

radmin show status

To terminate connection ID 123:

radmin terminate 123
