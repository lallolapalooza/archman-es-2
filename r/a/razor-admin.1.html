RAZOR-ADMIN(1) Documentación de Perl aportada por el usuario RAZOR-ADMIN(1)

NOMBRE

"razor-admin" - Agente de Registro de Razor

SINOPSIS

razor-admin [opciones]  [ -register | -create | -discover ]

DESCRIPCIÓN

"razor-admin" es el Agente Razor que realiza funciones administrativas, destacando el registro (-register)

USO

"razor-admin" debe tener uno de los siguientes argumentos:

"-register"
Registra una nueva identidad, utilizada para autenticarse con los Servidores de Nominación de Razor. Las identidades son un par usuario + contraseña almacenado en "<razorhome>/identity-<usuario>". La primera vez que "razor-admin -register" finaliza con éxito, se crea un enlace simbólico "identity" para apuntar al archivo activo "identity-<usuario>". Después de eso, se pueden crear nuevas identidades, pero para usarlas, el enlace simbólico "identity" debe cambiarse para apuntar a ellas. En general, debe llamarse una vez desde la línea de comandos. Sale con 0 en caso de éxito, sale con 1 en caso de fallo con un mensaje de salida legible por humanos.

Tanto razor-report(1) como razor-revoke(1) requieren autenticación de usuario para funcionar, razor-check(1) no. Esto permite al Servidor de Nominación de Razor mantener un registro de cuántos mensajes reporta y revoca un usuario. Cuantos más mensajes reporte y/o revoque correctamente un usuario, más confianza ganará. De manera similar, cuando los mensajes se reportan o revoca incorrectamente, la confianza de ese usuario disminuye. Los usuarios con alta confianza tendrán el mayor impacto en la base de datos de Razor.

"-discover"
Forzar descubrimiento. Esto creará archivos "server.*.lst" en <razorhome>.
"-create"
Crea explícitamente el archivo "razor-agent.conf" en <razorhome>, así como <razorhome> si no existe. Normalmente carga "/etc/razor/razor-agent.conf" si existe, utilizando valores predeterminados para cualquier cosa que no se encuentre. No intenta registrarse con el servidor, pero realizará el descubrimiento, ver "-discover".

OPCIONES

"razor-admin" toma los siguientes argumentos opcionales:

"-h"
Imprime un mensaje de uso y sale.
"-v"
Imprime el número de versión y sale.
"-d | --verbose"
Imprime información de depuración.
"-debuglevel=n | -dl=n"
Establece el nivel de depuración en 'n'. El valor predeterminado es 3 sin la opción "-d", 9 con ella.
"-s"
Simula una comprobación. Hace todo excepto hablar con el servidor.
"-conf=archivo"
Especifica un archivo de configuración alternativo. Si no se especifica, se calcula; ver la página del manual razor-agents(1) para más detalles. Ver la página del manual razor-agent.conf(5) para varias opciones de configuración. El valor predeterminado es "<razorhome>/razor-agent.conf".
"-home=directorio"
Especifica el directorio razorhome. Aquí es donde viven el archivo de configuración, los archivos de registro, las identidades y los archivos del servidor. Si no se especifica, se calcula; ver la página del manual razor-agents(1) para más detalles.
"-logfile=archivo"
Especifica el archivo al que registrar en lugar del que está en el archivo de configuración. El valor predeterminado es "<razorhome>/razor-agent.log".
"-ident=archivo"
Especifica un archivo de identidad a usar para almacenar una identidad recién registrada. Si no se especifica, se usa "<razorhome>/identity-<usuario>".
"-rs=razor.servidor.com"
Usa este Servidor de Nominación de Razor en lugar de leer "servers.nomination.lst".
"-user=usuario@dominio.com"
Solicita ser conocido como este nombre de usuario. Debe tener menos de 64 caracteres y puede contener A-Z, a-z, 0-9, así como caracteres imprimibles [ej: - _ @ . + / ]. Si no se especifica, se asignará un nombre de usuario. Se anima a los usuarios de Razor a utilizar sus direcciones de correo electrónico como nombre de usuario.
"-pass=contraseña"
Solicita esta contraseña. Los caracteres válidos son los mismos que para -user. Si no se especifica, se asignará.
"-l"
La identidad creada durante esta "razor-admin" se convierte en la predeterminada. Normalmente, el primer archivo de identidad creado por "razor-admin" es el predeterminado utilizado.

EJEMPLOS

razor-admin -d -create
Sin razorhome global definido (predeterminado) en /etc/razor/razor-agents.conf, crea el directorio .razor en el directorio principal del usuario.

Con razorhome global definido en /etc/razor/razor-agents.conf, intentará usarlo, fallará si no tiene los permisos correctos.

razor-admin -register
Registra una nueva identidad, almacenándola en <razorhome>. El usuario y la contraseña serán generados por el servidor. Se requiere una identidad para razor-report(1) y razor-revoke(1).
razor-admin -register -user me@a.com
Intenta registrar una nueva identidad usando el nombre de usuario 'me\@a.com'. Fallará si el usuario ya está ocupado.
razor-admin -d -create -home=/home/me/.razor
Crea el directorio .razor en el directorio principal del usuario, que luego será el predeterminado a menos que se especifique desde la línea de comandos. Envía información de depuración a stdout y no habla con ningún Servidor Razor.
razor-admin -d -create -home=/etc/razor
Crea el razorhome global, /etc/razor. Este es el directorio mágico que se consultará si no se especifica ningún razorhome en la línea de comandos o no se encuentra en el directorio principal del usuario.

NAME

razor-admin - RAZOR administration tool

SYNOPSIS

razor-admin [ -d razorhome ] [ -h ] [ -v ] [ command ] [ command_args ... ]

DESCRIPTION

The razor-admin command is a utility for administering the RAZOR distributed configuration management system. It can be used to manage clients, monitor the system, and perform other administrative tasks.

USAGE

The general syntax for the razor-admin command is: 

razor-admin [options] [command] [command_args...]

Where:

  • options are global options for the tool.
  • command is the specific administrative task to perform.
  • command_args are arguments specific to the chosen command.

OPTIONS

Global options available for the razor-admin tool:

-d razorhome
Specifies the RAZOR home directory. Defaults to /var/razor.
-h
Displays a help message and exits.
-v
Displays the version of the RAZOR administration tool and exits.

Available commands and their arguments depend on the specific RAZOR installation. Common commands might include:

  • list-clients: Lists all registered RAZOR clients.
  • add-client: Adds a new RAZOR client.
  • remove-client: Removes an existing RAZOR client.
  • get-config: Retrieves the configuration for a specific client.
  • set-config: Sets the configuration for a specific client.
  • monitor: Starts the RAZOR monitoring daemon.
  • status: Shows the current status of the RAZOR system.

Consult the RAZOR documentation for a comprehensive list of commands and their specific syntax.

EXAMPLES

To list all registered RAZOR clients: 

razor-admin list-clients

To add a new client named 'webserver01' with IP address 192.168.1.100: 

razor-admin add-client webserver01 192.168.1.100

To retrieve the configuration for client 'dbserver': 

razor-admin get-config dbserver

To start the RAZOR monitoring daemon, specifying a custom RAZOR home directory: 

razor-admin -d /opt/razor/conf monitor
