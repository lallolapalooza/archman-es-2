RAID6CHECK(8) Manual del Administrador del Sistema RAID6CHECK(8)

NOMBRE

raid6check - comprueba errores en un dispositivo MD RAID6 alias RAID por software de Linux

SINOPSIS

raid6check <dispositivo raid6> <stripe de inicio> <número de stripes>

DESCRIPCIÓN

Los dispositivos RAID6 en los que un solo disco componente tiene errores pueden utilizar la doble paridad para averiguar cuál disco componente es el defectuoso. La herramienta "raid6check" comprueba, para cada stripe, la consistencia de la doble paridad, informa de las inconsistencias y, si es posible, de qué disco componente tiene la inconsistencia. Dado que funciona a nivel de stripe, puede informar de diferentes discos con inconsistencias en diferentes stripes.

"raid6check" requiere un dispositivo MD RAID6 no degradado como primer parámetro, un stripe de inicio (normalmente 0) y el número de stripes a comprobar. Si este tercer parámetro es también 0, comprobará el array hasta el final.

"raid6check" comenzará imprimiendo información sobre el RAID6, luego, para cada stripe, informará del estado de rotación de la paridad. En caso de inconsistencias de paridad, "raid6check" informa, si es posible, qué disco componente podría ser el responsable. De lo contrario, informa que no es posible encontrar el disco componente.

Si el dispositivo MD proporcionado no es un RAID6, "raid6check" no continuará, por supuesto.

Si el dispositivo MD RAID6 está degradado, "raid6check" informará de un error y no procederá más allá.

No se realizan operaciones de escritura en el array ni en los componentes. Además, el array comprobado puede estar en línea y en uso durante el funcionamiento de "raid6check".

EJEMPLOS

raid6check /dev/md0 0 0
Esto comprobará /dev/md0 de principio a fin.

raid6check /dev/md3 0 1
Esto comprobará el primer stripe de /dev/md3.

raid6check /dev/md1 1000 0
Esto comprobará /dev/md1 desde el stripe 1000 hasta el final.

raid6check /dev/m127 128 256
Esto comprobará 256 stripes de /dev/md127 comenzando desde el stripe 128.

raid6check /dev/md0 0 0 | grep -i error > md0_err.log
Esto comprobará /dev/md0 completamente y creará un archivo de registro solo con los errores, si los hubiera.

ARCHIVOS

"raid6check" utiliza directamente los discos componentes tal como se encuentran en /dev. Además, se necesita la interfaz sysfs para averiguar los parámetros RAID6.

ERRORES

Los parámetros negativos pueden dar lugar a resultados inesperados.

No está claro qué sucederá si el dispositivo MD RAID6 se degrada durante la comprobación.

https://www.kernel.org/pub/linux/utils/raid/mdadm/
