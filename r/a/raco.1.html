RACO(1) Manual de Comandos Generales RACO(1)

NOMBRE

raco - la herramienta de línea de comandos de RAcket COmpilation

SINOPSIS

raco [ opción ... ] [ argumento ... ]

DESCRIPCIÓN

raco realiza diversas tareas relacionadas con el lenguaje Racket, como encontrar documentación, compilar código fuente de Racket a bytecode, empaquetar ejecutables y empaquetar archivos instalables.

Ejecuta


raco help

para obtener una lista de subcomandos.

MÁS INFORMACIÓN

Para obtener más información, ejecuta


raco docs

para abrir la documentación instalada en tu navegador web.

Alternativamente, consulta la documentación en línea y otra información disponible en


http://racket-lang.org/


AUTOR

raco fue implementado por PLT.
