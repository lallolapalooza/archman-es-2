RADEAPCLIENT(1) Demoniode FreeRADIUS RADEAPCLIENT(1)

NOMBRE

radeapclient - envía paquetes EAP a un servidor RADIUS, calcula respuestas

SINOPSIS

radeapclient [-4] [-6] [-c contador] [-d directorio_raddb] [-f archivo] [-h] [-i ip_origen] [-q] [-s] [-r reintentos] [-S archivo] [-t tiempo_espera] [-v] [-x] servidor {acct|auth} secreto

DESCRIPCIÓN

radeapclient es un programa cliente de radius. Puede enviar paquetes de radius arbitrarios a un servidor de radius, y luego muestra la respuesta. Radeapclient se diferencia de radclient en que si hay un desafío EAP-MD5, se responderá a él.

radeapclient es, por lo demás, idéntico a radclient.

El atributo EAP-Identity, si está presente, se utiliza para construir un mensaje de Identidad EAP.

El atributo EAP-MD5-Password, si está presente, se utiliza para responder a un desafío MD5.

Actualmente no se admiten otros tipos de EAP.

OPCIONES

-4
Usar IPv4 (predeterminado)
-6
Usar IPv6
-c contador
Enviar cada paquete contador veces.
-d raddb
Establecer el directorio del diccionario.
-f archivo
Leer paquetes de archivo, no de stdin.
-r reintentos
Si hay tiempo de espera, reintentar enviar el paquete reintentos veces.
-t tiempo_espera
Esperar tiempo_espera segundos antes de reintentar (puede ser un número de punto flotante).
-h
Imprimir información de ayuda de uso.
-i id
Establecer el id de la solicitud a 'id'. Los valores pueden ser 0..255
-S archivo
Leer el secreto del archivo, no de la línea de comandos.
-q
Silencioso, no imprimir nada.
-s
Imprimir información de resumen de los resultados de autenticación.
-v
Mostrar información de la versión del programa.
-x
Habilitar el modo de depuración.

EJEMPLO

Una sesión de ejemplo que consulta al servidor remoto con un desafío EAP-MD5.

( echo 'User-Name = "bob"';
  echo 'EAP-MD5-Password = "hello"';
  echo 'NAS-IP-Address = marajade.sandelman.ottawa.on.c';
  echo 'EAP-Code = Response';
  echo 'EAP-Id = 210';
  echo 'EAP-Type-Identity = "bob";
  echo 'Message-Authenticator = 0x00';
  echo 'NAS-Port = 0' ) >req.txt
radeapclient -x localhost auth testing123 <req.txt
