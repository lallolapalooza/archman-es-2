random(3) Manual de funciones de biblioteca random(3)

NOMBRE

random, srandom, initstate, setstate - generador de números aleatorios

BIBLIOTECA

Biblioteca C estándar (libc, -lc)

SINOPSIS

#include <stdlib.h>
long random(void);
void srandom(unsigned int seed);
char *initstate(size_t n;
                unsigned int seed, char state[n], size_t n);
char *setstate(char *state);
Requisitos de la macro de prueba de características para glibc (ver feature_test_macros(7)):

random(), srandom(), initstate(), setstate():

    _XOPEN_SOURCE >= 500
        || /* glibc >= 2.19: */ _DEFAULT_SOURCE
        || /* glibc <= 2.19: */ _SVID_SOURCE || _BSD_SOURCE

DESCRIPCIÓN

La función random() utiliza un generador de números aleatorios de retroalimentación aditiva no lineal que emplea una tabla predeterminada de 31 enteros largos para devolver números pseudoaleatorios sucesivos en el rango de 0 a 2^31 - 1. El período de este generador de números aleatorios es muy grande, aproximadamente 16 * ((2^31) - 1).

La función srandom() establece su argumento como la semilla para una nueva secuencia de enteros pseudoaleatorios que serán devueltos por random(). Estas secuencias se pueden repetir llamando a srandom() con el mismo valor de semilla. Si no se proporciona ningún valor de semilla, la función random() se inicializa automáticamente con el valor 1.

La función initstate() permite inicializar una matriz de estado state para su uso por random(). El tamaño de la matriz de estado n es utilizado por initstate() para decidir qué tan sofisticado será el generador de números aleatorios que utilizará: cuanto mayor sea la matriz de estado, mejores serán los números aleatorios. Los valores actualmente "óptimos" para el tamaño de la matriz de estado n son 8, 32, 64, 128 y 256 bytes; otras cantidades se redondearán hacia abajo a la cantidad conocida más cercana. Usar menos de 8 bytes resulta en un error. seed es la semilla para la inicialización, que especifica un punto de partida para la secuencia de números aleatorios y permite reiniciar en el mismo punto.

La función setstate() cambia la matriz de estado utilizada por la función random(). La matriz de estado state se utiliza para la generación de números aleatorios hasta la próxima llamada a initstate() o setstate(). state debe haber sido previamente inicializado usando initstate() o ser el resultado de una llamada anterior de setstate().

VALOR DE RETORNO

La función random() devuelve un valor entre 0 y (2^31) - 1. La función srandom() no devuelve ningún valor.

La función initstate() devuelve un puntero a la matriz de estado anterior. En caso de error, devuelve NULL y se establece errno para indicar el error.

En caso de éxito, setstate() devuelve un puntero a la matriz de estado anterior. En caso de error, devuelve NULL y se establece errno para indicar el error.

ERRORES

EINVAL
El argumento state proporcionado a setstate() era NULL.
EINVAL
Se especificó una matriz de estado de menos de 8 bytes a initstate().

NOTAS

La generación de números aleatorios es un tema complejo. Numerical Recipes in C: The Art of Scientific Computing (William H. Press, Brian P. Flannery, Saul A. Teukolsky, William T. Vetterling; Nueva York: Cambridge University Press, 2007, 3ª ed.) proporciona una excelente discusión sobre cuestiones prácticas de generación de números aleatorios en el Capítulo 7 (Random Numbers).

Para una discusión más teórica que también cubre muchos problemas prácticos en profundidad, consulte el Capítulo 3 (Random Numbers) en The Art of Computer Programming de Donald E. Knuth, volumen 2 (Seminumerical Algorithms), 2ª ed.; Reading, Massachusetts: Addison-Wesley Publishing Company, 1981.

ADVERTENCIAS

La función random() no debe usarse en programas multihilo donde se requiera un comportamiento reproducible. Utilice random_r(3) para ese propósito.

ERRORES

Según POSIX, initstate() debería devolver NULL en caso de error. En la implementación de glibc, errno se establece (como se especifica) en caso de error, pero la función no devuelve NULL.

  • random(3)

    SYNOPSIS

    #include <stdlib.h>

    long int random(void);

    void srandom(unsigned int seed);

    void initstate(unsigned int seed, char *state, size_t nbytes);

    char *setstate(char *state);

    DESCRIPTION

    The function random() returns a non-negative pseudo-random long integer, which is uniformly distributed over the range of possible signed long integer values.

    The function srandom() is used to seed the random number generator. It is recommended that srandom() be called before the first call to random(). If random() is called without a prior call to srandom() or initstate(), random() will use srandom(1) as the seed value.

    The functions initstate() and setstate() allow the user to control the state of the random number generator. The state is stored in a buffer pointed to by the state argument to initstate(). This buffer must be at least nbytes bytes in size. The recommended size for nbytes is 32 bytes. The buffer will be filled with the appropriate state information. The seed argument to initstate() is used to initialize the state. After calling initstate(), the user must call setstate() with a pointer to the state buffer in order to make it the current state. setstate() returns a pointer to the previous state buffer.

    The state maintained by random() is 256 bytes in size. If the buffer provided to initstate() is less than 32 bytes, the behavior is undefined.

    The function random() generates a sequence of 32-bit (non-negative) integers. The sequence of values generated by random() is of period 2^32. The values are good pseudo-random values.

    The function random() is not thread-safe. If you need a thread-safe random number generator, use rand() (which is also not thread-safe, but has a smaller state) or the facilities provided by POSIX.1-2001 (see rand_r(3)).

    RETURN VALUE

    On success, random() returns a pseudo-random long integer.

    setstate() returns a pointer to the previous state buffer.

    ERRORS

    setstate() may fail if the pointer passed does not point to a valid state buffer previously initialized by initstate(). In this case, it returns NULL.

    STANDARDS

    The functions random(), srandom(), initstate(), and setstate() are specified by POSIX.1-2001 and XSI. They are part of the C standard library in most Unix-like systems.

    NOTES

    The algorithm used by random() is a linear congruential generator. It is a simple and fast algorithm, but it is not cryptographically secure. For applications requiring cryptographically secure random numbers, use /dev/urandom or similar facilities.
