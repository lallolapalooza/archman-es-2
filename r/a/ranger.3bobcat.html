Paquete: libbobcat

FBB::Ranger(3bobcat) iteradores de bucle for FBB::Ranger(3bobcat)

NOMBRE

FBB::Ranger - generaliza rangos para bucles for basados en rangos

SINOPSIS

#include <bobcat/ranger>

DESCRIPCIÓN

La plantilla de clase Ranger define rangos que se pueden usar con bucles for basados en rangos. El bucle for basado en rangos estándar requiere para su especificación de rango una matriz o un rango de iteradores, como los que ofrecen, por ejemplo, los contenedores (a través de sus miembros begin y end). Los rangos definidos por un par de punteros o por un subrango definido por expresiones de iteradores no se pueden utilizar actualmente en combinación con bucles for basados en rangos.

Ranger extiende la aplicabilidad de los bucles for basados en rangos al convertir pares de punteros, un puntero inicial y un recuento de punteros, o un par de iteradores en un rango que puede ser utilizado por bucles for basados en rangos.

Ranger es una plantilla de clase que requiere un parámetro de tipo de plantilla: Iterator, un tipo de iterador o puntero que accede a los datos al ser desreferenciado.

Los usuarios de Ranger no tienen que especificar el tipo de plantilla de Ranger. La plantilla de función ranger devuelve el objeto Ranger apropiado.

ESPACIO DE NOMBRES

FBB
Todos los constructores, miembros, operadores y manipuladores mencionados en esta página de manual están definidos en el espacio de nombres FBB.

FUNCIÓN LIBRE

Al usar las siguientes funciones libres, se pueden utilizar subrangos de iteradores o punteros. Con iteradores, también se pueden especificar subrangos de iteradores inversos. La sección EJEMPLO a continuación ilustra el uso de las plantillas de función ranger.

o
Ranger<Iterator> ranger(Iterator &&begin, Iterator &&end):
esta plantilla de función devuelve un objeto Ranger para el (sub)rango definido por dos (inversos) iteradores;
o
Ranger<Iterator> ranger(Iterator &&begin, size_t count):
esta plantilla de función devuelve un objeto Ranger para el (sub)rango definido por el rango de (inversos) iteradores begin y begin + count;
o
Ranger<Data *> ranger(Data *begin, Data *end):
esta plantilla de función devuelve un objeto Ranger para el (sub)rango definido por los dos punteros begin y end;
o
Ranger<Data *> ranger(Data *begin, size_t count):
esta plantilla de función devuelve un objeto Ranger para el (sub)rango definido por los dos punteros begin y begin + count.

CONSTRUCTORES

A continuación, Iterator se refiere al parámetro de tipo de la clase plantilla Ranger. Aunque se llama 'Iterator', también puede ser un puntero a algún tipo de dato (por ejemplo, std::string *).

o
Ranger(Iterator const &begin, Iterator const &end):
Se puede pasar un objeto Ranger como especificador de rango en un bucle for basado en rangos. Todos los elementos definidos por el rango serán posteriormente visitados por el bucle for basado en rangos.

Se encuentran disponibles constructores de copia y movimiento (y operadores de asignación).

FUNCIONES MIEMBRO

o
Iterator const &begin() const:
devuelve (una copia de) el iterador begin pasado al constructor de Ranger. Tenga en cuenta que si Iterator era un tipo de puntero (como int *) los datos a los que se puede acceder con el iterador devuelto por begin() se pueden modificar en realidad, ya que el tipo de retorno del miembro (usando int * para Iterator) se convierte en int * const &, es decir, una referencia a un puntero constante a un int. Esto está perfectamente bien: si los datos en sí mismos deben ser inmutables, entonces el tipo de dato debe definirse como int const, lo que ocurre automáticamente al pasar datos de tipo int const *. Vea la sección EJEMPLO para una ilustración.
o
Iterator const &end() const:
devuelve (una copia de) el iterador end pasado al constructor de Ranger. Si se pasan iteradores inversos al constructor de Ranger, entonces los miembros begin y end devuelven iteradores inversos. Dado que el uso previsto de los objetos Ranger es definir un rango para bucles for basados en rangos, miembros como rbegin y rend se pueden omitir de Ranger.

EJEMPLO

#include <vector>
#include <iostream>
#include <bobcat/ranger>
using namespace std;
using namespace FBB;
int main()
{
    vector<int> iv {1, 2, 3, 4, 5};
                                    // mostrar y modificar un subrango
    for(auto &el: ranger(iv.rbegin() + 1, iv.rend() - 1))
        cout << el++ << ’ ’;
    cout << ’\n’;
                                    // mostrar un rango inverso
    for(auto &el: ranger(iv.rbegin() + 1, iv.rend() - 1))
        cout << el << ’ ’;
    cout << ’\n’;
                                    // lo mismo: mostrar usando un recuento
    for(auto &el: ranger(iv.rbegin() + 1, 3))
        cout << el << ’ ’;
    cout << ’\n’;
    int intArray[] = {1, 2, 3, 4, 5};
                                    // mostrar y modificar elementos
                                    // en un rango basado en punteros
    for(auto &el: ranger(intArray + 1, intArray + 3))
        cout << el++ << ’ ’;
    cout << ’\n’;
                                    // datos ahora modificados
    for(auto &el: ranger(intArray + 1, intArray + 3))
        cout << el << ’ ’;
    cout << ’\n’;
                                    // usar un recuento en lugar de un
                                    // puntero de fin
    for(auto &el: ranger(intArray + 1, 3))
        cout << el << ’ ’;
    cout << ’\n’;
    int const constInts[] = {1, 2, 3, 4, 5};
                                    // los datos no se pueden modificar
    for(auto &el: ranger(constInts + 1, constInts + 3))
        cout << el << ’ ’;
    cout << ’\n’;
}
