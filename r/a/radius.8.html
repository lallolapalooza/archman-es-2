NOMBRE

radius - autenticador RADIUS de nnrpd

SINOPSIS

radius [-h] [-f config]

DESCRIPCIÓN

radius es un autenticador de nnrpd, que acepta un nombre de usuario y una contraseña de nnrpd (proporcionados a nnrpd por una conexión del lector) e intenta autenticar ese nombre de usuario y contraseña contra un servidor RADIUS. Consulte readers.conf(5) para obtener más información sobre cómo configurar un autenticador de nnrpd. Es útil para un sitio que ya realiza la autenticación de usuarios a través de RADIUS y desea autenticar también las conexiones de lectura de noticias.

Por defecto, radius lee pathetc/inn-radius.conf para obtener información de configuración, pero se puede especificar un archivo de configuración diferente con -f. Consulte inn-radius.conf(5) para obtener una descripción del archivo de configuración.

OPCIONES

-f config
Lee config en lugar de pathetc/inn-radius.conf para obtener información de configuración.
-h
Muestra un mensaje de uso y sale.

EJEMPLO

El siguiente fragmento de readers.conf(5) indica a nnrpd que autentique todas las conexiones utilizando este autenticador:

auth radius {
    auth: radius
    default: <FAIL>
    default-domain: example.com
}

"@example.com" se añadirá a la identidad proporcionada por el usuario, y si la autenticación RADIUS falla, al usuario se le asignará la identidad "<FAIL>@example.com".

ERRORES

Se ha informado de que este autenticador no funciona con servidores RADIUS Ascend, pero sí con servidores RADIUS Cistron. También se cree que funciona con el servidor RADIUS de Livingston. Se agradecerían contribuciones para que funcione mejor con diferentes tipos de servidores RADIUS.

Este código no ha sido auditado contra el protocolo RADIUS y es posible que no lo implemente correctamente.

HISTORIA

El autenticador RADIUS fue escrito originalmente por Aidan Cully. Esta documentación fue escrita por Russ Allbery <eagle@eyrie.org>.

VER TAMBIÉN

inn-radius.conf(5), nnrpd(8), readers.conf(5).
