RATBAGCTL(1) Manual de Comandos Generales RATBAGCTL(1)

NOMBRE

ratbagctl - inspeccionar y modificar ratones configurables

SINOPSIS

ratbagctl [<opciones>] list
ratbagctl [<opciones>] <dispositivo> <comando> ...

DESCRIPCIÓN

La herramienta ratbagctl consulta o cambia la configuración de un dispositivo.

Esta herramienta generalmente necesita que ratbagd esté en ejecución.

OPCIONES

--version, -V
Muestra el número de versión del programa y sale.
--verbose, -v
Imprime la salida de depuración. Múltiples opciones -v aumentan la verbosidad. Por ejemplo, -vvv mostrará la salida del protocolo.
--nocommit
No guarda inmediatamente la configuración en el ratón. Esto permite configurar múltiples parámetros en un script, y la última llamada a ratbagctl los guardará todos.
--help, -h
Imprime la ayuda.

Comandos Generales

list
Lista los dispositivos soportados (no toma un argumento de dispositivo)

Comandos de Dispositivo

info
Imprime información sobre un dispositivo
name
Imprime el nombre del dispositivo

Comandos de Perfil

profile active get
Imprime el perfil activo actualmente
profile active set N
Establece el perfil N como perfil activo
profile N {COMANDO}
Usa el perfil N para COMANDO

COMANDOS disponibles:

get
Imprime información del perfil seleccionado
name get
Imprime el nombre del perfil
name set blah
Establece el nombre del perfil
enable
Habilita un perfil
disable
Deshabilita un perfil
[resolution|dpi|rate|button|led] ...
Usa el perfil N para el comando especificado.

Comandos de Resolución

Los comandos de resolución operan sobre el perfil dado, o sobre el perfil activo si no se proporciona ninguno.

resolution active get
Imprime la resolución activa actualmente
resolution active set N
Establece la resolución N como la resolución activa
resolution default get
Imprime la resolución predeterminada actual
resolution default set N
Establece la resolución N como la resolución predeterminada
resolution N {COMANDO}
Usa la resolución N para COMANDO

COMANDOS disponibles:

get
Imprime la resolución seleccionada
[dpi|rate] ...
Usa la resolución N para el comando especificado.

Comandos DPI

Los comandos DPI operan sobre el perfil y resolución dados, o sobre la resolución activa del perfil activo si no se proporciona ninguno.

dpi get
Imprime el valor dpi
dpi get-all
Imprime los valores dpi soportados
dpi set N
Establece el valor dpi a N

Comandos de Tasa

Los comandos de tasa operan sobre el perfil y resolución dados, o sobre la resolución activa del perfil activo si no se proporciona ninguno.

rate get
Imprime la tasa de informe en ms
rate get-all
Imprime las tasas de informe soportadas en ms
rate set N
Establece la tasa de informe a N ms

Comandos de Botón

Los comandos de botón operan sobre el perfil dado, o sobre el perfil activo si no se proporciona ninguno.

button count
Imprime el número de botones
button N get
Imprime el botón seleccionado
button N action get
Imprime la acción del botón
button N action set button B
Establece la acción del botón a botón B
button N action set special S
Establece la acción del botón a la acción especial S
button N action set macro ...
Establece la acción del botón a la macro dada

Sintaxis de la macro:

Una macro es una serie de eventos de tecla o períodos de espera. Las teclas deben especificarse con los nombres de tecla de linux/input-event-codes.h.

KEY_A
Presiona y suelta 'a'
+KEY_A
Presiona 'a'
-KEY_A
Suelta 'a'
t300
Espera 300 ms

Comandos LED

Los comandos LED operan sobre el perfil dado, o sobre el perfil activo si no se proporciona ninguno.

led get
Imprime los valores LED actuales
led N get
Imprime el valor LED seleccionado
led N {COMANDO}
Usa el LED N para COMANDO

COMANDOS disponibles:

mode [on|off|cycle|breathing]
El modo a establecer como actual
color RRGGBB
El color a establecer como actual (el color debe estar en formato hexadecimal).
rate R
La tasa a establecer como actual
brightness B
El brillo a establecer como actual

Ejemplos

ratbagctl profile active get eventX
ratbagctl profile 0 resolution active set 4 eventX
ratbagctl profile 0 resolution 1 dpi get eventX
ratbagctl button 5 action set special VOLUMEDOWN eventX
ratbagctl button 4 action set macro KEY_A t100 KEY_B t100 KEY_C t100 eventX
ratbagctl led 0 color FF0000 eventX
ratbagctl led 0 mode breathing rate 10 brightness 80 eventX
