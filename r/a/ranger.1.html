RANGER(1) ranger manual RANGER(1)

ranger - gestor de archivos visual

SINOPSIS

ranger [--version] [--help] [--debug] [--clean] [--cachedir=directorio] [--confdir=directorio] [--datadir=directorio] [--copy-config=cual] [--choosefile=objetivo] [--choosefiles=objetivo] [--choosedir=objetivo] [--selectfile=rutaarchivo] [--show-only-dirs] [--list-unused-keys] [--list-tagged-files=etiqueta] [--profile] [--cmd=comando] [ruta ...]

DESCRIPCIÓN

ranger es un gestor de archivos de consola con atajos de teclado estilo VI.

RECURSOS

Este manual contiene instrucciones sobre cómo usar y configurar ranger.

Dentro de ranger, puedes presionar ? para obtener una lista de atajos de teclado, comandos o configuraciones.

El archivo README contiene instrucciones de instalación.

El archivo HACKING.md contiene directrices para la modificación del código.

El directorio doc/configs contiene archivos de configuración. Usualmente se instalan en /usr/share/doc/ranger/config y se pueden obtener con la opción --copy-config de ranger.

El directorio examples contiene implementaciones de referencia para plugins de ranger, archivos de configuración de ejemplo y algunos programas para integrar ranger con otro software. Usualmente se instalan en /usr/share/doc/ranger/examples.

La página del manual de rifle(1) describe las funciones del abridor de archivos.

La sección LINKS de esta página del manual contiene más recursos.

ARGUMENTOS POSICIONALES

ruta ...
Cada ruta se abrirá en una pestaña y si la ruta es un archivo, se seleccionará. Omitirlo es equivalente a proporcionar el directorio actual.

OPCIONES

-d, --debug
Activa el modo de depuración: Siempre que ocurra un error, ranger saldrá e imprimirá un traceback completo. El comportamiento por defecto es solo imprimir el nombre de la excepción en la barra de estado/registro e intentar seguir ejecutándose.
-c, --clean
Activa el modo limpio: ranger no accederá ni creará ningún archivo de configuración, ni dejará rastros en tu sistema. Esto es útil cuando tu configuración está rota, cuando quieres evitar desorden, etc.
--cachedir=dir
Cambia el directorio de caché de ranger desde $XDG_CACHE_HOME o ~/.cache/ranger a "dir".
-r dir, --confdir=dir
Cambia el directorio de configuración de ranger desde $XDG_CONFIG_HOME o ~/.config/ranger a "dir".
--datadir=dir
Cambia el directorio de datos de ranger desde $XDG_DATA_HOME o ~/.local/share/ranger a "dir".
--copy-config=archivo
Crea copias de los archivos de configuración predeterminados en tu directorio de configuración local. Los existentes no se sobrescribirán. Valores posibles: all, commands, commands_full, rc, rifle, scope.

Nota: Puede que desees deshabilitar la carga de los archivos de configuración globales exportando RANGER_LOAD_DEFAULT_RC=FALSE en tu entorno. Ver también: ARCHIVOS, ENTORNO

--copy-config=commands copiará solo un pequeño archivo de configuración de ejemplo con un ejemplo cuidadosamente comentado. Es recomendable mantener este archivo ordenado para evitar comandos defectuosos en las actualizaciones de ranger. El archivo completo de comandos predeterminados se puede copiar con --copy-config=commands_full, pero ese archivo será ignorado por ranger y servirá solo como referencia para crear tus propios comandos.

--choosefile=objetivoarchivo
Permite seleccionar un archivo con ranger. Esto cambia el comportamiento de modo que cuando abras un archivo, ranger saldrá y escribirá la ruta absoluta de ese archivo en objetivoarchivo.
--choosefiles=objetivoarchivo
Permite seleccionar múltiples archivos con ranger. Esto cambia el comportamiento de modo que cuando abras un archivo, ranger saldrá y escribirá las rutas absolutas de todos los archivos seleccionados en objetivoarchivo, añadiendo una nueva línea después de cada nombre de archivo.
--choosedir=objetivoarchivo
Permite seleccionar un directorio con ranger. Cuando salgas de ranger, escribirá el último directorio visitado en objetivoarchivo.
--selectfile=objetivoarchivo
Abre ranger con objetivoarchivo seleccionado. Esta es una opción obsoleta, superada por el comportamiento para los ARGUMENTOS POSICIONALES.
--show-only-dirs
Muestra solo los directorios. Puede usarse en conjunto con --choosedir=objetivoarchivo.
--list-unused-keys
Lista las teclas comunes que no están enlazadas a ninguna acción en el contexto "browser". Esta lista no es completa, puedes enlazar cualquier tecla que sea soportada por curses: usa el código de tecla devuelto por "getch()".
--list-tagged-files=etiqueta
Lista todos los archivos etiquetados con la etiqueta dada. Nota: Las etiquetas son caracteres individuales. La etiqueta predeterminada es "*"
--profile
Imprime estadísticas de uso de CPU al salir.
--cmd=comando
Ejecuta el comando después de que la configuración haya sido leída. Usa esta opción varias veces para ejecutar múltiples comandos.
--version
Imprime la versión y sale.
-h, --help
Imprime una lista de opciones y sale.

CONCEPTOS

Esta parte explica cómo funcionan ciertas partes de ranger y cómo pueden usarse eficientemente.

ETIQUETAS

Las etiquetas son caracteres individuales que se muestran a la izquierda de un nombre de archivo. Puedes usar las etiquetas como quieras. Presiona "t" para alternar etiquetas y "ut" para quitar cualquier etiqueta de la selección. La etiqueta predeterminada es un asterisco ("*"), pero puedes usar cualquier etiqueta escribiendo "<nombre_etiqueta>.

\n

Esto solo funciona en terminology. Puede renderizar graficos vectoriales, pero solo funciona localmente.

\n

\n

Esto solo funciona en urxvt compilado con soporte pixbuf. No funciona a traves de ssh.

SELECCION

\n

La seleccion se define como \"Todos los archivos marcados SI HAY ALGUNO, de lo contrario el archivo actual.\" Tenga en cuenta esto cuando utilice el comando :delete, que elimina todos los archivos de la seleccion.

\n

Puede marcar archivos presionando <Espacio>, v, etc. Un simbolo Mrk amarillo en la parte inferior derecha indica que hay archivos marcados en este directorio.

MACROS

\n

Los macros se pueden usar en comandos para abreviar cosas.

\n
%f   el archivo resaltado\n%d   la ruta del directorio actual\n%s   los archivos seleccionados en el directorio actual\n%t   todos los archivos etiquetados en el directorio actual\n%c   las rutas completas de los archivos actualmente copiados/cortados\n%p   las rutas completas de los archivos seleccionados
\n

Los macros %f, %d, %p, y %s tambien tienen variantes en mayusculas, %F, %D, %P, y %S, que se refieren a la siguiente pestaña. Para referirse a pestañas especificas, agregue un numero en medio. (%7s = seleccion de la septima pestaña.)

\n

%c es el unico macro que se extiende fuera del directorio actual. Por lo tanto, puede \"abusar\" de la funcion de copia para otros propositos, como comparar dos archivos que estan en directorios diferentes:

\n
Copie el archivo A (escriba yy), mueva al archivo B, luego escriba\n@diff %c %f
\n

Los macros para rutas de archivos generalmente estan escapados por el shell para que puedan usarse en el comando \"shell\".

\n

Al mapear teclas, puede usar el marcador de posicion <cualquiera>, la tecla ingresada en esa posicion se puede usar a traves de los macros %cualquiera y %cualquiera_ruta. (Al usar multiples marcadores de posicion <cualquiera> puede indexar los macros: %cualquiera0, %cualquiera_ruta0, %cualquiera1, %cualquiera_ruta1...) El macro %cualquiera sera reemplazado por la tecla presionada en la posicion del marcador de posicion <cualquiera>. El macro %cualquiera_ruta sera reemplazado por la ruta del marcador asociado a la tecla presionada en la posicion del marcador de posicion <cualquiera>. Por ejemplo, este macro se puede usar para mostrar la tecla que se presionó después de \"c\":

\n
map c<cualquiera> echo %cualquiera
\n

%cualquiera se usa en la configuracion de ranger para crear un atajo de teclado para agregar un marcador. c<set_bookmark> crea un marcador para el directorio actual y la tecla para el marcador es el primer argumento proporcionado. En este caso, la tecla presionada despues de \"m\":

\n
map m<cualquiera> set_bookmark %cualquiera
\n

El macro %cualquiera_ruta se puede usar para mostrar la ruta del marcador que se establece en la tecla presionada despues de \"c\":

\n
map c<cualquiera> echo %cualquiera_ruta
\n

Un ejemplo practico del uso de %cualquiera_ruta es pegar archivos cortados/copiados a un directorio marcado:

\n
map p'<cualquiera> paste dest=%cualquiera_ruta
\n

El macro %rangerdir se expande al directorio de la biblioteca python de ranger, puede usarlo para algo como este comando:\n
\n alias show_commands shell less\n%rangerdir/config/commands.py

\n

%confdir se expande al directorio dado por --confdir.

\n

%datadir se expande al directorio dado por --datadir.

\n

El macro %espacio se expande a un caracter de espacio. Puede usarlo para agregar espacios al final de un comando cuando sea necesario, mientras evita que los editores eliminen espacios del final de la linea automaticamente.

\n

Para escribir un % literal, necesita escaparlo escribiendo %%.

\n

Tenga en cuenta que los macros se expanden dos veces cuando se usa la cadena. Por ejemplo, para insertar un caracter de espacio en un comando encadenado, escribiria %%espacio:\n
\n chain command1; command2%%espacio

MARCADORES

\n

Escriba m<tecla> para marcar el directorio actual. Puede volver a ingresar a este directorio escribiendo `<tecla>. <tecla> puede ser cualquier letra o digito. A diferencia de vim, tanto los marcadores en minusculas como en mayusculas son persistentes.

\n

Cada vez que salta a un marcador, el marcador especial en la tecla ` se establecerá en el último directorio. Por lo tanto, escribir \"``\" lo devuelve a donde estaba antes.

\n

Los marcadores son seleccionables al presionar tab en el comando :cd.

\n

Nota: Los marcadores ' (Apostrofe) y ` (Acento grave) son los mismos.

RIFLE

\n

Rifle es el abridor de archivos de ranger. Se puede usar como un programa independiente o un módulo de python. Se encuentra en $repo/ranger/ext/rifle.py. A diferencia de otros abridores de archivos más simples, rifle puede encontrar programas instalados automáticamente, por lo que se puede usar de manera efectiva desde el primer momento en una variedad de sistemas.

\n

Se configura en rifle.conf a través de una lista de condiciones y comandos. Para cada línea, se verifican las condiciones y si se cumplen, se considera el comando respectivo. Por defecto, simplemente se utiliza la primera regla coincidente. En ranger, puede listar y elegir reglas escribiendo \"r\" o simplemente escribiendo \"<numeroderegla><enter>\". Si usa rifle de forma independiente, puede listar todas las reglas con el quo" } } t;-l" y elige una regla con "-p <número>".

Las reglas, junto con más documentación, se encuentran en $repo/ranger/config/rifle.conf.

FLAGS

Los flags te dan una forma de modificar el comportamiento del proceso iniciado. Se usan en los comandos ":open_with" (tecla "r") y ":shell" (tecla "!").

f   Inicia el proceso en segundo plano. Por favor, usa este flag
    en lugar de llamar a "disown" o "nohup", para evitar
    matar el comando en segundo plano al presionar Ctrl+C en ranger.
c   Ejecuta solo el archivo actual, en lugar de la selección.
r   Ejecuta la aplicación con privilegios de root (requiere sudo).
t   Ejecuta la aplicación en una nueva ventana de terminal.

Hay algunos flags adicionales que actualmente solo se pueden usar en el comando "shell": (por ejemplo ":shell -w df")

p   Redirige la salida al paginador.
s   Modo silencioso. La salida se descartará.
w   Espera a que se presione Enter cuando el proceso haya terminado.

Por defecto, todos los flags están desactivados a menos que se especifique lo contrario en los enlaces de teclas de rc.conf o en las reglas de rifle.conf. Puedes especificar tantos flags como quieras. Un flag en mayúsculas niega el efecto: "ffcccFsf" es equivalente a "cs".

El nombre del programa de terminal para el flag "t" se toma de la variable de entorno $TERMCMD. Si no existe, intenta extraerlo de $TERM, usa "x-terminal-emulator" como último recurso, y luego "xterm" si falla.

Ejemplos: ":open_with c" abrirá el archivo en el que te encuentras actualmente, incluso si has seleccionado otros archivos. ":shell -w df" ejecutará "df" y esperará a que presiones Enter antes de volver a ranger.

PLUGINS

El sistema de plugins de ranger consiste en archivos de python que se encuentran en ~/.config/ranger/plugins/ y se importan en orden alfabético al iniciar ranger. Un plugin cambia el comportamiento de ranger sobrescribiendo o extendiendo una función que ranger utiliza. Esto te permite cambiar casi todas las partes de ranger, pero no hay garantía de que las cosas sigan funcionando en futuras versiones a medida que el código fuente evoluciona.

Agregar nuevos comandos a través de un plugin es tan simple como especificarlos como lo harías en commands.py.

Hay algunos hooks que están hechos específicamente para su uso en plugins. Son funciones que comienzan con hook_ y se pueden encontrar en todo el código.

grep 'def hook_' -r /ruta/a/fuente/de/ranger

También prueba:

pydoc ranger.api

Ten en cuenta que NO debes sobrescribir una función simplemente a menos que sepas lo que estás haciendo. En su lugar, guarda la función existente y llámala desde tu nueva función. De esta manera, múltiples plugins pueden usar el mismo hook. Hay varios plugins de ejemplo en el directorio /usr/share/doc/ranger/examples/, incluido un plugin de hola-mundo que describe este procedimiento.

ENLACES DE TECLAS

Los enlaces de teclas se definen en el archivo %rangerdir/config/rc.conf. Consulta este archivo para obtener una lista de todos los enlaces de teclas. Puedes copiarlo a tu directorio de configuración local con la opción --copy-config=rc.

Muchos enlaces de teclas aceptan un argumento numérico adicional. Escribe 5j para moverte 5 líneas hacia abajo, 2l para abrir un archivo en el modo 2, 10<Espacio> para marcar 10 archivos.

Esta lista contiene los enlaces más útiles:

ENLACES PRINCIPALES

h, j, k, l
Moverse a la izquierda, abajo, arriba o derecha.
^D o J, ^U o K
Moverse media página hacia abajo, arriba.
H, L
Moverse hacia atrás y hacia adelante en el historial.
gg
Moverse al principio.
G
Moverse al final.
[, ]
Moverse arriba y abajo en el directorio padre.
^R
Recargar todo.
F
Alternar la configuración de freeze_files. Cuando está activa (indicado por un mensaje FROZEN en color cian en la barra de estado), los directorios y archivos no se cargarán, mejorando el rendimiento cuando todos los archivos que necesitas ya están cargados. Esto no afecta las previsualizaciones de archivos, que se pueden alternar con zI. También prueba a desactivar la previsualización de directorios con zP.
^L
Redibujar la pantalla.
i
Inspeccionar el archivo actual en una ventana más grande.
E
Editar el archivo actual en $VISUAL, de lo contrario $EDITOR, de lo contrario "vim".
S
Abrir un shell en el directorio actual.
?
Abre esta página de manual.
W
Abre la ventana de registro donde puedes revisar los mensajes que aparecen en la parte inferior.
w
Abre la ventana de tareas donde puedes ver y modificar los procesos en segundo plano que se están ejecutando actualmente en ranger. Allí, puedes escribir "dd" para abortar un proceso y "J" o "K" para cambiar la prioridad de un proceso. Solo se ejecuta un proceso a la vez.
^C
Detiene el proceso en segundo plano que ranger ha iniciado, como copiar archivos, cargar directorios o previsualizaciones de archivos.
<octal>=, +<quién><qué>, -<quién><qué>
Cambia los permisos de la selección. Por ejemplo, "777=" es equivalente a "chmod 777 %s", "+ar" hace "chmod a+r %s", "-ow" hace "chmod o-w %s", etc.
yy
Copiar (yank) la selección, como presionar Ctrl+C en programas gráficos modernos. (También puedes escribir "ya" para agregar archivos al búfer de copia, "yr" para eliminarlos de nuevo, o "yt" para alternar.)
dd
Cortar la selección, como presionar Ctrl+X en programas gráficos modernos. (También hay atajos "da", "dr" y "dt" equivalentes a "ya", "yr" y "yt".)
pp
Pegar los archivos que fueron copiados o cortados previamente, como presionar Ctrl+V en programas gráficos modernos.

Los conflictos se renombrarán agregando un '_' (y un contador si es necesario), resultando en "archivo.ext_", "archivo.ext_0", etc. Si prefieres "archivo_.ext" puedes usar el comando "paste_ext".

po
Pegar los archivos copiados/cortados, sobrescribiendo los archivos existentes.
pP, pO
Similar a pp y po, pero pone la operación en cola para que se ejecute después de cualquier otra operación. Recordatorio: escribe "w" para abrir la ventana de tareas.
pl, pL
Crear enlaces simbólicos (absolutos o relativos) a los archivos copiados.
phl
Crear enlaces duros a los archivos copiados.
pht
Duplicar el árbol de subdirectorios del directorio copiado, luego crear enlaces duros para cada archivo contenido en el nuevo árbol de directorios.
mX
Crear un marcador con el nombre X.
`X
Ir al marcador con el nombre X.
n
Encontrar el siguiente archivo. Por defecto, te lleva al archivo más nuevo en el directorio, pero si buscas algo usando las teclas /, cm, ct, ..., te llevará a la siguiente entrada encontrada.
N
Encontrar el archivo anterior.
oX
Cambiar el método de ordenación (como en mutt).
zX
Cambiar la configuración. Consulta la sección de configuración para ver una lista de configuraciones y sus atajos.
u?
Tecla de deshacer universal. Dependiendo de la tecla que presiones después de "u", restaura pestañas cerradas (uq), elimina etiquetas (ut), borra el búfer de copia/corte (ud), inicia el modo visual inverso (uV) o borra la selección (uv).
f
Navegar rápidamente ingresando una parte del nombre del archivo.
Espacio
Marcar un archivo.
v
Alternar el estado de marca de todos los archivos.
V
Inicia el modo visual, que selecciona todos los archivos entre el punto de inicio y el cursor hasta que presiones ESC. Para deseleccionar archivos de la misma manera, usa "uV".
/
Buscar archivos en el directorio actual.
:

alias [nuevo_comando] [comando_antiguo]
Copia el comando_antiguo como nuevo_comando.
bulkrename
Este comando abre una lista de archivos seleccionados en un editor externo. Después de editar y guardar el archivo, generará un script de shell que realiza el renombrado masivo según los cambios que hayas hecho en el archivo.

Este script de shell se abre en un editor para que lo revises. Después de cerrarlo, se ejecutará.

cd [ruta]
El comando cd cambia el directorio. Si la ruta es un archivo, selecciona ese archivo. El comando ":cd -" es equivalente a escribir ``.
chain comando1[; comando2[; comando3...]]
Combina múltiples comandos en uno, separados por puntos y comas.
chmod numero_octal
Establece los permisos de la selección al número octal.

El número octal está entre 000 y 777. Los dígitos especifican los permisos para el usuario, el grupo y los demás. Un 1 permite la ejecución, un 2 permite la escritura, un 4 permite la lectura. Suma esos números para combinarlos. Así, un 7 permite todo.

También existen enlaces de teclas en forma de [-+]<quién><qué> y <octal>=. Por ejemplo, +ar permite la lectura para todos, -ow prohíbe a otros escribir y 777= permite todo.

Ver también: man 1 chmod

Abre la consola con el comando ya escrito. El cursor se coloca en N.

Por ejemplo, copymap j down hará que la secuencia de teclas "down" mueva el cursor hacia abajo un elemento.

Para copiar enlaces de teclas de la consola, paginador o vista de tareas, usa "copycmap", "copypmap" o "copytmap" respectivamente.

filter [cadena]
Muestra solo los archivos que contienen la cadena en su nombre base. Ejecutar este comando sin ningún parámetro restablecerá el filtro.

Este comando se basa en el comando scout y soporta todas sus opciones.

Muestra solo los archivos del tipo de inodo especificado. Para mostrar solo directorios, usa el parámetro 'd'. Para mostrar solo archivos, usa el parámetro 'f'. Para mostrar solo enlaces, usa el parámetro 'l'. Los parámetros se pueden combinar. Para eliminar este filtro, no uses ningún parámetro.
filter_stack [comando [args]]
Gestiona la pila de filtros, añadiendo, eliminando y manipulando filtros. Por ejemplo, para mostrar solo archivos duplicados y enlaces simbólicos: 
:filter_stack add type f

:filter_stack add and
:filter_stack add type l

duplicate
Filtra archivos para que solo se muestren los archivos que tienen duplicados en el mismo directorio. Útil para limpiar canciones y memes idénticos que se guardaron usando nombres de archivo distintos.
filename NOMBRE

scout [-flags...] [--] patrón
Comando navaja suiza para buscar, viajar y filtrar archivos.

Flags:
-a Abre automáticamente un archivo en coincidencias no ambiguas
-e Abre el archivo seleccionado al presionar enter
-f Filtra archivos que coinciden con el patrón de búsqueda actual
-g Interpreta el patrón como un patrón glob
-i Ignora mayúsculas y minúsculas de los archivos
-k Mantiene la consola abierta al cambiar de directorio con el comando
-l Salto de letras; por ejemplo, permite que "rdme" coincida con el archivo "readme"
-m Marca los archivos coincidentes después de presionar enter
-M Desmarca los archivos coincidentes después de presionar enter
-p Filtro permanente: oculta los archivos no coincidentes después de presionar enter
-r Interpreta el patrón como un patrón de expresión regular
-s Caso inteligente; como -i a menos que el patrón contenga letras mayúsculas
-t Aplica el filtro y el patrón de búsqueda a medida que escribes
-v Invierte la coincidencia

Se pueden combinar varios flags. Por ejemplo, ":scout -gpt" crearía un comando similar a :filter usando globbing.

set opción valor
Asigna un nuevo valor a una opción. Las opciones válidas se enumeran en la sección de configuración. Usa la autocompletación con tabulación para obtener el valor actual de una opción, aunque esto no funciona para funciones y expresiones regulares. Los valores válidos son:

-------------------+----------------------------

Por ejemplo, para cambiar el orden de clasificación en tu directorio de descargas, márcalo con la etiqueta v escribiendo "v, luego usa este comando:

Asigna un nuevo valor a una opción, pero localmente para el directorio dado por ruta. Esto significa que esta opción solo tendrá efecto al visitar ese directorio. Si no se proporciona ruta, se usa el directorio actual.

ruta es una expresión regular. Esto significa que "path=~/dl" se aplica a todas las rutas que comienzan con ~/dl, por ejemplo, ~/dl2 y ~/dl/foo. Para evitar esto, usa "path=~/dl$".

ruta puede ser entrecomillada con comillas simples o dobles para evitar divisiones no deseadas. path='~/dl dl$' o path="~/dl dl$"

ARCHIVOS

ranger lee varios archivos de configuración ubicados en $HOME/.config/ranger o $XDG_CONFIG_HOME/ranger si $XDG_CONFIG_HOME está definido. Puedes usar la opción --copy-config para obtener los archivos de configuración predeterminados. Los archivos contienen documentación adicional.

rc.conf, commands.py y colorschemes no necesitan copiarse completamente, ya que solo añadirán a los archivos de configuración predeterminados, a menos que se anulen explícitamente. Esto puede llevar a situaciones confusas, por ejemplo, cuando una tecla está vinculada a pesar de que la línea correspondiente se ha eliminado de la copia del archivo de configuración del usuario. Este comportamiento se puede desactivar con una variable de entorno (ver también: ENTORNO). Nota: Todos los demás archivos de configuración solo leen de una fuente; es decir, predeterminado O usuario, no ambos. rc.conf y commands.py también se leen de /etc/ranger si existen para configuración a nivel de sistema, la configuración del usuario anula la configuración del sistema, que a su vez anula la configuración predeterminada.

Al iniciar ranger con la opción --clean, no accederá ni creará ninguno de estos archivos.

ALMACENAMIENTO

bookmarks
Este archivo contiene una lista de marcadores. La sintaxis es /^(.):(.*)$/. El primer carácter es la tecla del marcador y el resto después de los dos puntos es la ruta al archivo. En ranger, los marcadores se pueden establecer escribiendo m<tecla>, acceder escribiendo '<tecla>' y eliminar escribiendo um<tecla>.
copy_buffer
Al ejecutar el comando :save_copy_buffer, las rutas de todos los archivos copiados actualmente se guardan en este archivo. Posteriormente puedes ejecutar :load_copy_buffer para copiar los mismos archivos de nuevo, pasarlos a otra instancia de ranger o procesarlos en un script.
history
Contiene una lista de comandos que se han escrito previamente.
tagged
Contiene una lista de archivos etiquetados. La sintaxis es /^(.:)?(.*)$/, donde la primera letra es el nombre opcional de la etiqueta y el resto después de los dos puntos opcionales es la ruta al archivo. En ranger, las etiquetas se pueden establecer presionando t y eliminar con T. Para asignar una etiqueta con nombre, escribe "<nombre_etiqueta>.
