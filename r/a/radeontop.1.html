RADEONTOP(1)   RADEONTOP(1)

NOMBRE

radeontop - herramienta para mostrar la utilización de la GPU

SINOPSIS

radeontop [-chmv] [-b bus] [-d archivo] [-l límite] [-i secs] [-p dispositivo] [-t ticks]

DESCRIPCIÓN

RadeonTop muestra la utilización de tu GPU, tanto en general como por bloques.

Tarjetas compatibles son R600 y posteriores.

OPCIONES

-b, --bus bus

Si tienes varias tarjetas, usa este parámetro para seleccionar una específica. Para la salida de lspci 01:00.0 VGA compatible controller, el bus sería 1.

-c, --color

Habilita la salida en color.

-d, --dump archivo

En lugar de mostrar los datos, descárgalos al archivo. Usa - para stdout. El archivo se añade, por lo que es seguro especificar el mismo nombre de archivo para ejecuciones consecutivas.

Usa SIGTERM o SIGINT para una terminación ordenada.

-h, --help

Muestra la ayuda.

-i, --dump-interval segundos

Espera N segundos entre la salida de datos.

-l, --limit límite

Sale después de descargar límite líneas. Solo válido en modo de descarga. Por defecto, descarga hasta que se termina; usa SIGTERM o SIGINT para una terminación ordenada.

-m, --mem

Fuerza el uso de la ruta /dev/mem, en caso de que la autodetección falle. Útil para el controlador propietario.

-p, --path dispositivo

Abre el nodo del dispositivo DRM especificado por la ruta dispositivo. Normalmente se encuentra en /dev/dri/card0 o /dev/drm0. Si se usa esta opción, se ignoran --bus y --mem.

-t, --ticks ticks

Cuántas veces por segundo muestrear los datos. El valor predeterminado es 120. Valores más altos significan una salida más precisa y una mayor carga.

-v, --version

Muestra la versión del programa.

COMANDOS INTERACTIVOS

C, c

Cambia la salida en color.

Q, q

Salir.

RECURSOS

Ver http://github.com/clbr/radeontop
