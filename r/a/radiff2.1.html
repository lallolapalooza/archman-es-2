RADIFF2(1) Manual de Comandos Generales RADIFF2(1)

NOMBRE

radiff2 - utilidad de diff binario

SINOPSIS

radiff2 [-1abcCdeGhijnropqsSxuUvVzZ] [-A[A]] [-B #] [-g sim] [-m modo_grafo][-t %] archivo archivo

DESCRIPCIÓN

radiff2 es una herramienta del conjunto radare2 diseñada para comparar código y datos binarios.

Admite una amplia gama de formatos y características, incluida la especificación de arquitectura y bits, diff de delta, diff de grafos y más.

OPCIONES

-1
Salida en formato Generic binary DIFF (cabecera mágica 0xd1ffd1ff).
-a [arch]
Especifica el plugin de arquitectura a usar (x86, arm, etc.).
-A [-A]
Ejecuta aaa o aaaa después de cargar cada binario (ver -C).
-b [bits]
Especifica el tamaño del registro para la arquitectura (16 (thumb), 32, 64, etc.).
-B [baddr]
Define la dirección base para sumar los offsets al listar.
-c
Conteo de cambios.
-C
Graphdiff de código (columnas: off-A, ratio de coincidencia, off-B) (ver -A).
-d
Usa diff de delta.
-D
Muestra desensamblado en lugar de hexpairs.
-e [k=v]
Establece el valor de la variable de configuración eval para todas las instancias de RCore.
-g [arg]
Diff de grafo de [sim] o funciones en [off1,off2].
-G [cmd]
Ejecuta un comando de r2 en cada instancia de RCore creada.
-i [ifscm]
Compara importaciones | campos | símbolos | clases | métodos.
-j
Salida en formato JSON.
-m [modo]
Elige el modo de salida del grafo (aditsjJ).
-n
Imprime solo direcciones desnudas (diff.bare=1).
-O
Diff de código solo con bytes de opcode.
-p
Usa direccionamiento físico (io.va=false) (solo para radiff2 -AC).
-q
Modo silencioso (desactiva colores, reduce la salida).
-r
Salida en comandos de radare.
-s
Calcula la distancia de edición (sin sustitución, algoritmo de diff O(ND) de Eugene W. Myers).
-ss
Calcula la distancia de edición de Levenshtein (se permiten sustituciones, O(N^2)).
-S [nombre]
Ordena el diff de código (nombre, long_nombre, dir, tamaño, tipo, dist) (solo para -C o -g).
-t [0-100]
Establece el umbral para el diff de código (por defecto es 70%).
-T
Analiza archivos en hilos (EXPERIMENTAL, 30% más rápido y propenso a caídas).
-u
Salida unificada (---+++).
-U
Salida unificada usando 'diff' del sistema.
-v
Muestra información de la versión.
-V
Sea verboso (actualmente solo para -s).
-x
Muestra diff de hexdump en dos columnas.
-X
Muestra diff de hexII en dos columnas.
-z
Compara cadenas extraídas.
-Z
Compara código usando zigmas.

FORMATOS DE SALIDA DE GRAFO (-m [modo])

.
por defecto es arte ASCII.
s
comandos r2.
d
Graphviz dot.
g
Graph Modelling Language (gml).
j
JSON.
J
JSON con desensamblado.
k
clave-valor sdb.
t
arte ASCII diminuto.
i
arte ASCII interactivo.

EJEMPLOS DE USO

Comparando dos binarios
radiff2 binario1 binario2
Usando diff de grafo para comparar funciones por nombre
radiff2 -g main binario1 binario2
Contando el número de cambios entre dos binarios
radiff2 -c binario1 binario2
Generando la salida del diff en formato unificado
radiff2 -u binario1 binario2
Comparando los opcodes de dos funciones
radiff2 -O binario1 binario2

COMANDO 'C' EN R2

El comando 'c' en r2 se usa para varias operaciones de comparación dentro de los datos en el mismo archivo. Aquí hay algunos ejemplos de su uso:

Comparar una cadena normal con caracteres de escape
c "cadena a comparar"
Comparar un byte en una dirección específica con el offset actual
c1 0x100
Comparar bytes del tamaño de bloque desde el offset actual y el offset 0x100
cc 0x100
Diff unificado del desensamblado desde la búsqueda actual y la dirección dada
cud 0x200 @ 0x100
Comparar volcado de memoria hexadecimal en formato diff unificado
cu 0x100 @ 0x200

Para un uso más detallado del comando 'c', consulta la sección de ayuda `c[?dfx] [argumento]`.
