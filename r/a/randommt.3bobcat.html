FBB::RandomMT(3bobcat) Generador aleatorio usando std::mt19937 FBB::RandomMT(3bobcat)

NOMBRE

FBB::RandomMT - Plantilla de clase que genera números aleatorios

SINOPSIS

#include <bobcat/randommt>
Opción de enlazado: -lbobcat

DESCRIPCIÓN

La plantilla de clase RandomMT utiliza el Mersenne Twister std::mt19937 para producir números aleatorios. La plantilla de clase tiene un parámetro de tipo plantilla, que puede ser cualquier tipo integral o de punto flotante. Por defecto, se generan números aleatorios con valor size_t.

ESPACIO DE NOMBRES

FBB
Todos los constructores, miembros, operadores y manipuladores mencionados en esta página del manual están definidos en el espacio de nombres FBB.

HEREDA DE

-

CONSTRUCTORES

o
RandomMT<typename Type = size_t>::RandomMT(Type minimum, Type maximum, size_t mtSeed):
El parámetro de tipo plantilla Type puede ser cualquier tipo integral o de punto flotante. Si no se especifica, se usa size_t. Los parámetros minimum y maximum definen el rango de los valores aleatorios generados. minimum debe ser menor o igual a maximum, o se lanzará una excepción. El parámetro mtSeed se utiliza para inicializar (sembrar) el Mersenne Twister mt19937.

Los constructores de copia y movimiento por defecto, así como los operadores de asignación, están disponibles.

OPERADORES SOBRECARGADOS

o
Type operator()():
El operador de llamada de función devuelve el siguiente valor aleatorio.

EJEMPLO

#include <iostream>
#include <bobcat/randommt>
using namespace std;
using namespace FBB;
int main(int argc, char **argv)
try
{
    if (argc == 1)
    {
        cout << "arg[1]: valor mínimo, arg[2]: valor máximo,\n"
                "arg[3]: (opcional) semilla (o time(0))\n";
        return 0;
    }
    // especificar, por ejemplo, RandomMt<double> para generar valores dobles
    // aleatorios
    RandomMT<> rmt( stoull(argv[1]), stoull(argv[2]),
                  argc >= 4 ? stoull(argv[3]) : time(0) );
    while (true)
    {
        cout << rmt() << "\n"
                "Enter: siguiente";
        cin.ignore(1000, ’\n’);
    }
}
catch (exception const &exc)
{
    cerr << exc.what() << ’\n’;
}
