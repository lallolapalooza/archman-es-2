RAGG2(1) Manual de comandos generales RAGG2(1)

NOMBRE

ragg2 — Frontend de radare2 para r_egg, compila programas en binarios diminutos para x86-32/64 y arm.

SINOPSIS

ragg2 [-a arch] [-b bits] [-k kernel] [-f formato] [-o archivo] [-i shellcode] [-I ruta] [-e eggstr] [-E codificador] [-B pareshex] [-c k=v] [-C archivo] [-n num32] [-N num64] [-d off:dword] [-D off:qword] [-w off:pareshex] [-p relleno] [-P patron] [-q fragmento] [-FOLsrxvhz]

DESCRIPCIÓN

ragg2 es un frontend para r_egg, compila programas en binarios diminutos para x86-32/64 y arm.

Esta herramienta es experimental y es una reescritura de los programas antiguos rarc2 y rarc2-tool como una biblioteca e integrada con r_asm y r_bin.

Los programas generados por r_egg son reubicables y pueden ser inyectados en un proceso en ejecución o en un archivo binario en disco.

Dado que se fusionó ragg2-cc, ragg2 ahora puede generar shellcodes a partir de código C. El código final se puede enlazar con rabin2 y es reubicable, por lo que se puede utilizar para inyectarlo en cualquier proceso remoto. Esta característica se basa conceptualmente en shellforge4, pero solo se admiten las plataformas linux/osx x86-32/64.

DIRECTIVAS

El archivo de configuración de rr2 (ragg2) acepta las siguientes directivas, descritas como entradas clave=valor y comentarios definidos como líneas que comienzan con '#'.

-a arch
establecer arquitectura x86, arm
-b bits
32 o 64
-k kernel
windows, linux o osx
-f formato
formato de salida (raw, c, pe, elf, mach0, python, javascript)
-o archivo
archivo de salida para escribir el resultado de la compilación
-i shellcode
especificar el nombre del shellcode a utilizar (ver -L)
-e codificador
pasar el programa egg como argumento en lugar de en un archivo
-E codificador
especificar el nombre del codificador a utilizar (ver -L)
-B pareshex
especificar el shellcode como pares de hexadecimales
-c k=v
establecer la opción de configuración para el codificador de shellcode. El argumento debe ser clave=valor.
-C archivo
incluir el contenido del archivo
-d off:dword
Parchear el buffer final con el dword dado en el offset especificado
-D off:qword
Parchear el buffer final con el qword dado en el offset especificado
-w off:pareshex
Parchear el buffer final con los pares de hexadecimales dados en el offset especificado
-n num32
Añadir un número de 32 bits en little endian
-N num64
Añadir un número de 64 bits en little endian
-p relleno
Especificar rellenos genéricos con una cadena de formato. Usar letras minúsculas para prefijar y mayúsculas para sufijar, las claves son: 'n' para nop, 't' para trap, 'a' para secuencia y 's' para cero.
-P tamaño
Prefijar secuencia de debruijn de longitud dada.
-q fragmento
Offset de salida de un fragmento de secuencia de debruijn.
-F
autodetectar el formato de archivo nativo (osx=mach0, linux=elf, ..)
-O
usar archivo de salida predeterminado (nombre de archivo sin extensión o a.out)
-I ruta
añadir ruta de inclusión
-s
mostrar código ensamblador
-S
añadir una cadena
-r
mostrar bytes crudos en lugar de pares de hexadecimales
-x
ejecutar (just-in-time)
-X
ejecutar cadena de rop
-L
listar todos los plugins (shellcodes y codificadores)
-h
mostrar esta ayuda
-z
salida en sintaxis de cadena C
-v
mostrar versión

EJEMPLO


$ cat hi.r
/* hola mundo en r_egg */
write@syscall(4); //x64 write@syscall(1);
exit@syscall(1); //x64 exit@syscall(60);


main@global(128) {
.var0 = "hi!\n";
write(1,.var0, 4);
exit(0);
}
$ ragg2 -O -F hi.r
$ ./hi
hi!


# Con archivo C:
$ cat hi.c
main() {
write(1, "Hello\n", 6);
exit(0);
}
$ ragg2 -O -F hi.c


$ ./hi
Hello


# Enlazado en un binario diminuto. Esto tiene 165 bytes
$ wc -c < hi
165


# El shellcode compilado tiene ceros
$ ragg2 hi.c | tail -1

# Usar un codificador xor con clave 64 para eludir
$ ragg2 -e xor -c key=64 -B $(ragg2 hi.c | tail -1)
