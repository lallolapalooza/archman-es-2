ram(4) Manual de Controladores de Dispositivo ram(4)

NOMBRE

ram - dispositivo de disco RAM

DESCRIPCIÓN

El dispositivo ram es un dispositivo de bloques para acceder al disco RAM en modo crudo.

Normalmente se crea mediante:


mknod -m 660 /dev/ram b 1 1
chown root:disk /dev/ram

ARCHIVOS

/dev/ram

VER TAMBIÉN

chown(1), mknod(1), mount(8)
