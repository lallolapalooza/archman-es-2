NOMBRE

radvd - demonio de anuncios de enrutador para IPv6

SINOPSIS

radvd [ -hsvc ] [ -d nivel_depuracion ] [ -C archivo_configuracion ] [ -p archivo_pid ] [ -m metodo_log ] [ -l archivo_log ] [ -n nodemonio ] [ -f instalacion ] [ -t directorio_chroot ] [ -u nombre_usuario ]

DESCRIPCIÓN

radvd es el demonio de anuncios de enrutador para IPv6. Escucha las solicitudes de enrutador y envía anuncios de enrutador según se describe en "Neighbor Discovery for IP Version 6 (IPv6)" (RFC 4861). Con estos anuncios, los hosts pueden configurar automáticamente sus direcciones y algunos otros parámetros. También define "Neighbor Discovery Optimization for IPv6 over Low-Power Wireless Personal Area Networks (6LoWPANs)" (RFC6775). También pueden elegir un enrutador predeterminado basándose en estos anuncios.

El archivo de configuración no debe ser escribible por otros, y si se solicita operación sin ser root, ni siquiera por uno mismo/su propio grupo.

OPCIONES

Por cada opción de un solo carácter, también hay una opción larga, que se enumera justo al lado del nombre de la opción "corta":

-v, --version
Muestra la versión de radvd y luego aborta.
-h, --help
Muestra una breve descripción de uso y luego aborta.
-c, --configtest
Prueba la configuración y realiza pruebas de inicio, luego sale.
-n, --nodaemon
Evita la daemonización.
-d nivel_depuracion, --debug nivel_depuracion
Con esta opción se activa la información de depuración. El nivel de depuración es un entero en el rango de 1 a 5, de silencioso a muy detallado. Un nivel de depuración de 0 desactiva completamente la depuración. Si se utiliza un nivel de depuración mayor que 0, radvd no se ejecutará en segundo plano al iniciarse. El nivel de depuración predeterminado es 0.
-C archivo_configuracion, --config archivo_configuracion
Especifica un archivo de configuración alternativo. Normalmente se utiliza el valor predeterminado compilado /etc/radvd.conf.
-p archivo_pid, --pidfile archivo_pid
Especifica un archivo PID alternativo. Normalmente se utiliza el valor predeterminado compilado /run/radvd.pid.
-m metodo, --logmethod metodo
Especifica el método de registro a utilizar. Los valores posibles son:
none
Desactiva completamente cualquier registro.
logfile
Registra en el archivo de registro especificado por la opción -l. Si no se especifica un archivo de registro en la línea de comandos, se utiliza un valor predeterminado compilado (ver la siguiente opción).
stderr
Registra en la salida de error estándar.
stderr_syslog
Registra solo los mensajes de alta prioridad (de prioridad LOG_ERR o superior) en la salida de error estándar, y todo en syslog (método predeterminado).
syslog
Registra en syslog.
-l archivo_log, --logfile archivo_log
Especifica el archivo de registro a utilizar cuando se utiliza el método de registro logfile. El archivo de registro predeterminado es /var/log/radvd.log.
-f instalacion, --facility instalacion
Especifica la instalación (como un entero) al utilizar el registro de syslog. El valor predeterminado es LOG_DAEMON.
-t directorio_chroot, --chrootdir directorio_chroot
Si se especifica, cambia a directorio_chroot antes de hacer cualquier otra cosa. Este directorio y sus subdirectorios deben haber sido poblados previamente. Por razones de seguridad, -u siempre debe usarse cuando se utiliza directorio_chroot.

Tenga en cuenta que en Linux radvd requiere acceso al sistema de archivos /proc, por lo que configurar el entorno chroot es más desafiante.

-u nombre_usuario, --username nombre_usuario
Si se especifica, renuncia a los privilegios de root y cambia el ID de usuario a nombre_usuario y el ID de grupo al grupo primario de nombre_usuario. Esto se recomienda por razones de seguridad. Es posible que también necesite usar -p para apuntar a un archivo en un directorio escribible por nombre_usuario (por ejemplo, /var/run/radvd/radvd.pid).
