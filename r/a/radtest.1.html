RADTEST(1) Demonio FreeRADIUS RADTEST(1)

NOMBRE

radtest - enviar paquetes a un servidor RADIUS, mostrar respuesta

SINOPSIS

radtest [-d directorio_raddb] [-P tcp/udp] [-t pap/chap/mschap/eap-md5] [-x ] [-4 ] [-6 ] usuario contraseña servidor-radius número-puerto-nas secreto [ppphint] [nasname]

DESCRIPCIÓN

radtest es una interfaz para radclient(1). Genera una lista de pares atributo/valor basada en los argumentos de la línea de comandos, y los introduce en radclient. Es una forma rápida y conveniente de probar un servidor radius.

OPCIONES

-d directorio_raddb
El directorio que contiene los archivos de diccionario RADIUS. Por defecto es /etc/raddb.
-P proto
Usar el protocolo de transporte proto ("tcp" o "udp"). Solo disponible si FreeRADIUS está compilado con soporte de transporte TCP.
-t pap/chap/mschap/eap-md5
Elegir el método de autenticación a usar. Ej. "-t pap", "-t chap", "-t mschap", o "-t eap-md5",. Por defecto es "pap". Usar EAP-MD5 requiere que el programa "radeapclient" esté instalado.
-x
Habilita la salida de depuración para el cliente RADIUS.
-4
Usar NAS-IP-Address para la dirección del NAS (por defecto)
-6
Usar NAS-IPv6-Address para la dirección del NAS (por defecto)
usuario
Nombre de usuario a enviar.
contraseña
Contraseña del usuario.
servidor-radius
Nombre de host o dirección IP del servidor radius. Opcionalmente, puede especificar un puerto añadiendo :puerto
número-puerto-nas
El valor del atributo NAS-Port. Es un entero entre 0 y 2^31, y realmente no importa lo que ponga aquí. 10 servirá.
secreto
El secreto compartido para este cliente.
ppphint
Si pone un entero > 0 aquí, radtest (o en realidad radclient) añadirá el atributo Framed-Protocol = PPP al paquete de solicitud.
nasname
Si está presente, esto se resolverá a una dirección IP y se añadirá al paquete de solicitud como el atributo NAS-IP-Address. Si no lo especifica, se usará el nombre de host local del sistema.

VER TAMBIÉN

radiusd(8), radclient(1).
