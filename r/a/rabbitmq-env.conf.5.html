RABBITMQ-ENV.CONF(5) Manual de formatos de archivo RABBITMQ-ENV.CONF(5)

NOMBRE

rabbitmq-env.conf — variables de entorno utilizadas por el servidor RabbitMQ

DESCRIPCIÓN

rabbitmq-env.conf contiene variables de entorno que anulan los valores predeterminados incorporados en los scripts de RabbitMQ y las herramientas CLI.

El archivo es interpretado por el shell del sistema, y por lo tanto debe consistir en una secuencia de definiciones de variables de entorno del shell. Se permite la sintaxis normal del shell (ya que el archivo se carga utilizando el operador "." del shell), incluidos los comentarios de línea que comienzan con "#".

En orden de preferencia, los scripts de inicio obtienen sus valores del entorno, de rabbitmq-env.conf y, finalmente, de los valores predeterminados incorporados. Por ejemplo, para la configuración RABBITMQ_NODENAME, primero se verifica RABBITMQ_NODENAME del entorno. Si está ausente o es igual a la cadena vacía, entonces se verifica NODENAME de rabbitmq-env.conf. Si también está ausente o se establece igual a la cadena vacía, entonces se utiliza el valor predeterminado del script de inicio.

Los nombres de las variables en rabbitmq-env.conf siempre son iguales a los nombres de las variables de entorno, con el prefijo "RABBITMQ_" eliminado: RABBITMQ_NODE_PORT del entorno se convierte en NODE_PORT en rabbitmq-env.conf.

EJEMPLOS

A continuación se muestra un ejemplo de un archivo rabbitmq-env.conf minimalista que anula el prefijo predeterminado del nombre del nodo de "rabbit" a "hare".

# Soy un archivo rabbitmq-env.conf completo.
# Las líneas de comentarios comienzan con un carácter de almohadilla.
# Este es un archivo de script /bin/sh - use sintaxis ordinaria de variables de entorno
NODENAME=hare

En el siguiente archivo rabbitmq-env.conf, la ubicación del archivo de configuración de RabbitMQ se cambia a "/data/services/rabbitmq/rabbitmq.conf".

# Soy un archivo rabbitmq-env.conf completo.
# Las líneas de comentarios comienzan con un carácter de almohadilla.
# Este es un archivo de script /bin/sh - use sintaxis ordinaria de variables de entorno
CONFIG_FILE=/data/services/rabbitmq/rabbitmq.conf
