NOMBRE

rabbitmq-streams — Herramientas de gestión de flujos de RabbitMQ

SINOPSIS

rabbitmq-streams [-q] [-s] [-l] [-n nodo] [-t tiempo_espera] comando [opciones_comando]

DESCRIPCIÓN

rabbitmq-streams es una herramienta de línea de comandos que proporciona comandos utilizados para gestionar flujos, por ejemplo, añadir o eliminar réplicas de flujo. Consulte la visión general de los flujos de RabbitMQ.

OPCIONES

-n nodo
El nodo predeterminado es "rabbit@nombre_host_destino", donde nombre_host_destino es el host local. En un host llamado "myserver.example.com", el nombre del nodo suele ser "rabbit@myserver" (a menos que RABBITMQ_NODENAME se haya anulado). La salida de "hostname -s" suele ser el sufijo correcto para usar después del signo "@". Consulte rabbitmq-server(8) para obtener detalles sobre la configuración de un nodo RabbitMQ.
-q, --quiet
Se selecciona el modo de salida silencioso. Los mensajes informativos se reducen cuando el modo silencioso está activo.
-s, --silent
Se selecciona el modo de salida mudo. Los mensajes informativos se reducen y se suprimen las cabeceras de tabla cuando el modo mudo está activo.
-t tiempo_espera, --timeout tiempo_espera
Tiempo de espera de la operación en segundos. No todos los comandos admiten tiempos de espera. El valor predeterminado es infinity.
-l, --longnames
Debe especificarse cuando el clúster está configurado para usar nombres de nodo largos (FQDN). Para obtener más información, consulte la guía de clustering de RabbitMQ
--erlang-cookie cookie
Secreto compartido que se utilizará para autenticarse en el nodo de destino. Prefiera utilizar un archivo local o la variable de entorno RABBITMQ_ERLANG_COOKIE en lugar de especificar esta opción en la línea de comandos. Para obtener más información, consulte la guía de herramientas CLI de RabbitMQ

COMANDOS

help

Muestra la ayuda general y los comandos compatibles con rabbitmq-streams.

Replicación

add_replica cola nodo --vhost host_virtual

Añade una réplica de flujo en el nodo dado.

Ejemplo:

rabbitmq-streams add_replica --vhost "un-vhost" "una-cola" "rabbit@nuevo-nodo"
delete_replica cola nodo --vhost host_virtual

Elimina una réplica de flujo en el nodo dado.

Ejemplo:

rabbitmq-streams delete_replica --vhost "un-vhost" "una-cola" "rabbit@nodo-descomisionado"

Monitorización, observabilidad y comprobaciones de estado

stream_status flujo --vhost host_virtual

Muestra el estado de un flujo.

Ejemplo:

rabbitmq-streams stream_status --vhost "un-vhost" "un-flujo"
restart_stream flujo --vhost host_virtual ---preferred-leader-node nodo

Reinicia un flujo, incluidas todas sus réplicas. La bandera opcional de nodo preferido instruye al comando para que intente colocar el líder en un nodo específico durante el reinicio.

Ejemplo:

rabbitmq-streams restart_stream --vhost "un-vhost" "un-flujo" --preferred-leader-node "nodo"

Complemento de flujo

activate_stream_consumer --stream flujo --reference referencia [--vhost host_virtual]

Dispara un reequilibrio para activar un consumidor en un único grupo de consumidores activos.

Ejemplo:

rabbitmq-streams activate_stream_consumer --stream flujo --reference app-1
list_stream_connections [item_info_conexión ...]

Devuelve estadísticas de conexión del protocolo de flujo.

El parámetro item_info_conexión se utiliza para indicar qué elementos de información de conexión se deben incluir en los resultados. El orden de las columnas en los resultados coincidirá con el orden de los parámetros. item_info_conexión puede tomar cualquier valor de la siguiente lista:

auth_mechanism
Mecanismo de autenticación SASL utilizado, como "PLAIN".
client_properties
Propiedades informativas transmitidas por el cliente durante el establecimiento de la conexión.
conn_name
Nombre legible para la conexión.
connected_at
Fecha y hora en que se estableció esta conexión, como marca de tiempo.
connection_state
Estado de la conexión; uno de:
  • running
  • blocked
frame_max
Tamaño máximo de trama (bytes).
heartbeat
Intervalo de latido negociado, en segundos.
host
Nombre del host del servidor obtenido mediante DNS inverso, o su dirección IP si el DNS inverso falló o estaba deshabilitado.
peer_cert_issuer
El emisor del certificado SSL del par, en formato RFC4514.
peer_cert_subject
El sujeto del certificado SSL del par, en formato RFC4514.
peer_cert_validity
El período durante el cual el certificado SSL del par es válido.
peer_host
Nombre de host del par obtenido mediante DNS inverso, o su dirección IP si el DNS inverso falló o no estaba habilitado.
peer_port
Puerto del par.
port
Puerto del servidor.
ssl
Booleano que indica si la conexión está protegida con SSL.
ssl_cipher
Algoritmo de cifrado SSL (por ejemplo, "aes_256_cbc").
ssl_hash
Función hash SSL (por ejemplo, "sha").
ssl_key_exchange
Algoritmo de intercambio de claves SSL (por ejemplo, "rsa").
ssl_protocol
Protocolo SSL (por ejemplo, "tlsv1").
subscriptions
Número de suscripciones (consumidores) en la conexión.
user
Nombre de usuario asociado a la conexión.
vhost
Nombre del host virtual con caracteres no ASCII escapados como en C.

Si no se especifican connectioninfoitem, solo se muestra conn_name.

Por ejemplo, este comando muestra el nombre de la conexión y el usuario para cada conexión:

rabbitmq-streams list_stream_connections conn_name user
list_stream_consumers [-p vhost] [consumerinfoitem ...]

Devuelve los consumidores adjuntos a un stream.

El parámetro consumerinfoitem se utiliza para indicar qué elementos de información del consumidor incluir en los resultados. El orden de las columnas en los resultados coincidirá con el orden de los parámetros. consumerinfoitem puede tomar cualquier valor de la lista que sigue:

active
Booleano que indica si el consumidor está activo o no.
activity_status
Estado de actividad del consumidor; uno de:
  • up
  • single_active
  • waiting
connection_pid
ID del proceso Erlang asociado con la conexión del consumidor.
credits
Créditos disponibles para el consumidor.
messages_consumed
Número de mensajes consumidos por el consumidor.
offset
El desplazamiento (ubicación en el stream) en el que se encuentra el consumidor.
offset_lag
La diferencia entre el último desplazamiento almacenado y el último desplazamiento enviado para el consumidor.
properties
Las propiedades de la suscripción del consumidor.
stream
El stream al que está adjunto el consumidor.
subscription_id
El ID del consumidor dentro del ámbito de la conexión.

Si no se especifican consumerinfoitem, se mostrarán connection_pid, subscription_id, stream, messages_consumed, offset, offset_lag, credits, active, activity_status y properties.

Por ejemplo, este comando muestra el PID de la conexión, el ID de suscripción y el stream para cada consumidor:

rabbitmq-streams list_stream_consumers connection_pid subscription_id stream
list_stream_publishers [-p vhost] [publisherinfoitem ...]

Devuelve los publicadores registrados.

El parámetro publisherinfoitem se utiliza para indicar qué elementos de información del publicador incluir en los resultados. El orden de las columnas en los resultados coincidirá con el orden de los parámetros. publisherinfoitem puede tomar cualquier valor de la lista que sigue:

connection_pid
ID del proceso Erlang asociado con la conexión del consumidor.
messages_confirmed
El número de mensajes confirmados para el publicador.
messages_errored
El número de mensajes con error para el publicador.
messages_published
El número total de mensajes publicados por el publicador.
publisher_id
El ID del publicador dentro del ámbito de la conexión.
reference
La referencia de deduplicación del publicador.
stream
El stream al que publica el publicador.

Si no se especifican publisherinfoitem, se mostrarán connection_pid, publisher_id, stream, reference, messages_published, messages_confirmed y messages_errored.

Por ejemplo, este comando muestra el PID de la conexión, el ID del publicador y el stream para cada productor:

rabbitmq-streams list_stream_publishers connection_pid publisher_id stream
add_super_stream super-stream [--vhost vhost] [--partitions partitions] [--binding-keys binding-keys] [--max-length-bytes max-length-bytes] [--max-age max-age] [--stream-max-segment-size-bytes stream-max-segment-size-bytes] [--leader-locator leader-locator] [--initial-cluster-size initial-cluster-size]
super-stream
El nombre del super stream a crear.
vhost
El nombre del host virtual en el que se creará el super stream.
partitions
El número de particiones que tendrá el super stream.
binding-keys
Lista separada por comas de claves de enlace.
max-length-bytes
El tamaño máximo de los streams de partición, valores de ejemplo: 20gb, 500mb.
max-age
La edad máxima de los segmentos de stream de partición, utilizando el formato de duración ISO 8601, por ejemplo, PT10M30S para 10 minutos 30 segundos, P5DT8H para 5 días 8 horas.
stream-max-segment-size-bytes
El tamaño máximo de los segmentos de stream de partición, valores de ejemplo: 500mb, 1gb.
leader-locator
Estrategia de ubicación del líder para los streams de partición. Los valores posibles son:
  • client-local
  • balanced
El valor predeterminado es balanced
initial-cluster-size
El tamaño inicial del clúster de streams de partición.

Crea un super stream.

delete_super_stream super-stream [--vhost vhost]

Elimina un super stream.

super-stream
El nombre del super stream a eliminar.
vhost
El host virtual del super stream.
list_stream_consumer_groups [-p vhost] [groupinfoitem ...]

Lista los grupos de consumidores activos individuales de streams para un vhost.

El parámetro groupinfoitem se utiliza para indicar qué elementos de información del grupo incluir en los resultados. El orden de las columnas en los resultados coincidirá con el orden de los parámetros. groupinfoitem puede tomar cualquier valor de la lista que sigue:

consumers
Número de consumidores en el grupo.
partition_index
El índice de partición del stream si el stream es parte de un super stream, -1 si no lo es.
reference
La referencia (nombre) del grupo.
stream
El stream al que están adjuntos los consumidores.

Si no se especifican groupinfoitem, se mostrarán stream, reference, partition_index y consumers.

Por ejemplo, este comando muestra el stream, la referencia y el número de consumidores para cada grupo:

rabbitmq-streams list_stream_consumer_groups stream reference consumers
list_stream_group_consumers --stream stream

NAME

rabbitmq-streams - management of RabbitMQ Streams

SYNOPSIS

rabbitmq-streams [command] [options]

DESCRIPTION

The rabbitmq-streams utility is a command-line tool for managing RabbitMQ Streams. It allows you to perform various administrative tasks related to streams, such as listing streams, consumers, and tracking information, as well as resetting consumer offsets.

OPTIONS

The following options are available:

-h, --help
Display help message and exit.
-v, --version
Display program version and exit.

COMMANDS

list-streams [--vhost vhost]

Lists all streams in a virtual host.

vhost
The virtual host to list streams from. Defaults to the default vhost.
list_stream_consumers --stream stream --reference reference [--vhost vhost] [consumerinfoitem ...]

Lists consumers of a stream consumer group in a vhost.

stream
The stream the consumers are attached to.
reference
The group reference (name).
vhost
The virtual host of the stream.

The consumerinfoitem parameter is used to indicate which consumer information items to include in the results. The column order in the results will match the order of the parameters. consumerinfoitem can take any value from the list that follows:

connection_name
Readable name of the consumer connection.
state
Consumer state; one of:
  • active
  • inactive
subscription_id
The connection-scoped ID of the consumer.

If no consumerinfoitem are specified then subscription_id, connection_name, and state are displayed.

For example, this command displays the connection name and state for each consumer attached to the stream-1 stream and belonging to the stream-1 group:

rabbitmq-streams list_stream_group_consumers --stream stream-1 --reference stream-1 connection_name state
list_stream_tracking stream [--all | --offset | --writer] [--vhost vhost]

Lists tracking information for a stream.

stream
The name of the stream.

Tracking information can be filtered by their type using one of the following mutually exclusive options:

--all
List offset tracking and writer deduplication information.
--offset
List only offset tracking information.
--writer
List only writer deduplication tracking information.

Example:

rabbitmq-streams list_stream_tracking stream-1 --offset
reset_offset --stream stream --reference reference [--vhost vhost]

Reset the stored offset for a consumer name on a stream.

Example:

rabbitmq-streams reset_offset --stream stream --reference app-1
