RAFIND2(1) Manual de Comandos Generales RAFIND2(1)

NOMBRE

rafind2 — búsqueda avanzada de patrones de bytes en archivos desde línea de comandos

SINOPSIS

rafind2 [-a alineación] [-b tamaño] [-c] [-e regex] [-f desde] [-F archivo] [-h] [-i] [-j] [-L] [-m] [-M máscara] [-n] [-q] [-r] [-s cadena] [-S cadena] [-t hasta] [-v] [-V s:num | s:num1,num2] [-x hex] [-X] [-z] [-Z] archivo|directorio ..

DESCRIPCIÓN

rafind2 es un programa versátil diseñado para buscar patrones de bytes en archivos.

Las siguientes opciones están disponibles:

-a alineación
Aceptar solo resultados de búsqueda alineados.
-b tamaño
Define el tamaño del bloque para la búsqueda. Dependiendo de la caché de la CPU, la memoria y el almacenamiento, diferentes tamaños pueden afectar el rendimiento.
-c
Deshabilitar la salida de colores, útil principalmente para casos de uso no interactivos o por lotes.
-e regex
Buscar coincidencias usando expresiones regulares. Se pueden proporcionar múltiples expresiones.
-f desde
Especificar la dirección de inicio para la búsqueda. (Ver -t)
-F archivo
Leer palabras clave del archivo especificado para la búsqueda.
-h
Mostrar el mensaje de ayuda.
-i
Identificar el tipo de archivo usando técnicas similares al comando 'file'.
-j
Mostrar resultados en formato JSON.
-L
Listar todos los plugins de I/O disponibles.
-m
Realizar búsqueda mágica para identificar tipos de archivo basados en firmas.
-M máscara
Aplicar una máscara binaria a las palabras clave antes de la búsqueda.
-n
Continuar la búsqueda incluso si ocurren errores de lectura.
-q
Modo silencioso: suprimir encabezados o nombres de archivo en la salida.
-r
Imprimir resultados usando comandos de radare.
-s cadena
Buscar las cadenas especificadas en los archivos.
-S cadena
Buscar cadenas anchas (Unicode) en los archivos.
-t hasta
Especificar la dirección final para la búsqueda. (Ver -f)
-v
Mostrar la versión de rafind2 y salir.
-V s:num | s:num1,num2
Buscar el valor dado usando notación little-endian. Se puede especificar un valor único (p. ej., -V 4:123) o se puede buscar un rango de valores proporcionando dos valores separados por una coma (p. ej., -V 4:100,200).
-x hex
Buscar los patrones hexadecimales especificados en los archivos.
-X
Mostrar el volcado hexadecimal de los resultados de la búsqueda.
-z
Buscar cadenas terminadas en cero.
-Z
Mostrar las cadenas encontradas en cada coincidencia de búsqueda.

EJEMPLOS

Buscar una cadena específica en un archivo:

$ rafind2 -s "cadena_a_buscar" archivo.txt

Buscar un patrón hexadecimal en todos los archivos de un directorio:

$ rafind2 -x "909090" ruta_directorio

Identificar el tipo de archivo usando la base de datos mágica:

$ rafind2 -i archivo_binario

Buscar el valor 123 en formato little-endian almacenado en una palabra de 4 bytes dentro de un archivo:

$ rafind2 -V 4:123 archivo.bin
