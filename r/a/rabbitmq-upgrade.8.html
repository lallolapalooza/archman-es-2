NOMBRE

rabbitmq-upgrade — Herramientas de actualización de la instalación de RabbitMQ

SINOPSIS

rabbitmq-upgrade [-q] [-s] [-l] [-n nodo] [-t tiempo_espera] comando [opciones_comando]

DESCRIPCIÓN

rabbitmq-upgrade es una herramienta de línea de comandos que proporciona comandos utilizados durante la actualización de los nodos de RabbitMQ. Consulte la guía de actualización de RabbitMQ para obtener más información sobre las actualizaciones de la instalación de RabbitMQ.

OPCIONES

-n nodo
El nodo predeterminado es "rabbit@nombre_host_objetivo", donde nombre_host_objetivo es el host local. En un host llamado "myserver.example.com", el nombre del nodo suele ser "rabbit@myserver" (a menos que RABBITMQ_NODENAME se haya modificado). La salida de "hostname -s" suele ser el sufijo correcto para usar después del signo "@". Consulte rabbitmq-server(8) para obtener detalles sobre la configuración de un nodo RabbitMQ.
-q, --quieto
Se selecciona el modo de salida silencioso. Los mensajes informativos se reducen cuando el modo silencioso está activo.
-s, --silencioso
Se selecciona el modo de salida muy silencioso. Los mensajes informativos se reducen y los encabezados de tabla se suprimen cuando el modo muy silencioso está activo.
-t tiempo_espera, --tiempo-espera tiempo_espera
Tiempo de espera de la operación en segundos. No todos los comandos admiten tiempos de espera. El valor predeterminado es infinito.
-l, --nombres-largos
Debe especificarse cuando el clúster está configurado para usar nombres de nodo largos (FQDN). Para obtener más información, consulte la guía de clústeres de RabbitMQ
--erlang-cookie cookie
Secreto compartido para autenticarse en el nodo de destino. Prefiera usar un archivo local o la variable de entorno RABBITMQ_ERLANG_COOKIE en lugar de especificar esta opción en la línea de comandos. Para obtener más información, consulte la guía de herramientas CLI de RabbitMQ

COMANDOS

help

Muestra la ayuda general y los comandos compatibles con rabbitmq-upgrade.

post_upgrade

Ejecuta tareas posteriores a la actualización. En la versión actual, realiza el reequilibrio de colas replicadas y de quorum en todos los nodos del clúster.

await_online_quorum_plus_one

Espera a que todas las colas de quorum tengan un quorum en línea por encima del mínimo. Esto asegura que ninguna cola pierda su quorum si se apaga el nodo de destino.

drain

Pone el nodo en modo de mantenimiento. Dichos nodos no atenderán ningún tráfico de cliente ni se considerarán para alojar réplicas de líder de cola.

Para obtener más información, consulte la guía de actualización de RabbitMQ

revive

Saca el nodo del modo de mantenimiento y lo devuelve al modo de operación normal. Dichos nodos volverán a atender el tráfico de cliente y se considerarán para la colocación de réplicas de líder de cola.

Para obtener más información, consulte la guía de actualización de RabbitMQ
