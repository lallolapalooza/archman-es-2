FBB::RandBuffer(3bobcat) stream de números aleatorios FBB::RandBuffer(3bobcat)

NOMBRE

FBB::RandBuffer - std::streambuf que genera números aleatorios

SINOPSIS

#include <bobcat/randbuf>
Opción de enlace: -lbobcat

DESCRIPCIÓN

Los objetos FBB::RandBuffer se pueden usar como un std::streambuf de objetos std::istream para permitir la extracción de números aleatorios del stream.

ESPACIO DE NOMBRES

FBB
Todos los constructores, miembros, operadores y manipuladores mencionados en esta página del manual están definidos en el espacio de nombres FBB.

HEREDA DE

std::streambuf

CONSTRUCTOR

o
RandBuf(int min, int max, size_t seed = 1):
Este constructor RandBuf() inicializa el generador aleatorio. La semilla se utiliza para inicializar el generador de números aleatorios. Se devuelven valores aleatorios entre min y max (inclusive).

Los constructores de copia y movimiento (y los operadores de asignación) no están disponibles.`

MIEMBROS VIRTUALES

o
int underflow():
Esta función es llamada por los objetos std::istream que usan RandBuf. Produce el siguiente número aleatorio disponible, separando los números aleatorios por un espacio en blanco. Se devuelven valores aleatorios entre min y max (inclusive) (ver la descripción del constructor).

MIEMBROS HEREDADOS

Dado que la clase utiliza derivación pública de std::streambuf, todos los miembros de esta clase pueden ser utilizados.

EJEMPLO

#include <iostream>
#include <istream>
#include "../randbuf"
using namespace std;
using namespace FBB;
int main(int argc, char **argv)
{
    if (argc == 1)
    {
        cout << "esperado: nruns min max seed\n";
        return 1;
    }
    RandBuf rb(stoi(argv[2]), stoi(argv[3]), stoul(argv[4]));
    istream istr(&rb);
    for (unsigned idx = stoul(argv[1]); idx--; )
    {
        int c;
        if (!(istr >> c))
        {
            cout << "falló la extracción\n";
            break;
        }
        cout << "siguiente: " << c << endl;
    }
    int count = 0;
    while (istr.unget())
        count++;
    cout << "número de llamadas exitosas a unget(): " << count << endl;
    istr.clear();
    istr >> count;
    cout << "y leído: " << count << endl;
}
