NOMBRE

rasqal-config - script para obtener información sobre la versión instalada de la biblioteca de consultas RDF

SINOPSIS

rasqal-config [--prefix[=DIR]] [--libs] [--libtool-libs] [--cflags] [--version] [--version-decimal] [--help]

DESCRIPCIÓN

rasqal-config es una herramienta que se utiliza para determinar las opciones de compilación y enlazado que deben utilizarse para compilar y enlazar programas que utilicen la biblioteca de consultas Rasqal RDF.

OPCIONES

rasqal-config acepta las siguientes opciones:

--version
Imprime la versión actualmente instalada de rasqal en la salida estándar.
--version-decimal
Imprime la versión actualmente instalada de rasqal como un entero decimal.
--libs
Imprime las opciones de enlazado que son necesarias para enlazar un programa con Rasqal.
--libtool-libs
Imprime la ruta al archivo libtool para rasqal.
--cflags
Imprime las opciones del compilador que son necesarias para compilar un programa con el lenguaje de consulta RDF.
--prefix=PREFIX
Si se especifica, utiliza PREFIX en lugar del prefijo de instalación con el que se construyó Rasqal al calcular la salida para las opciones --cflags y --libs. Esta opción debe especificarse antes de cualquier opción --libs o --cflags.
