ratbagd(8) Manual del Administrador del Sistema ratbagd(8)

NOMBRE

ratbagd - demonio del sistema para introspeccionar y modificar ratones configurables

SINOPSIS

ratbagd [--verbose[=debug]|--quiet|--version|--help]

DESCRIPCIÓN

ratbagd inicia el demonio. No debe invocarse directamente; ratbagd normalmente se inicia mediante activación de DBus.

OPCIONES

--help
Imprime la ayuda y sale
--verbose, --verbose=debug
Habilita la salida detallada, incluyendo opcionalmente mensajes crudos enviados y recibidos del dispositivo. Esto debe usarse para depurar cualquier problema con el dispositivo.
--quiet
Deshabilita cualquier salida excepto los mensajes de error.
--version
Muestra el número de versión.

VER TAMBIÉN

ratbagctl(1)
