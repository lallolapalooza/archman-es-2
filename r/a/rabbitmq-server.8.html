RABBITMQ-SERVER(8) Manual del Administrador del Sistema RABBITMQ-SERVER(8)

NOMBRE

rabbitmq-server — inicia un nodo RabbitMQ

SINOPSIS

rabbitmq-server [-detached]

DESCRIPCIÓN

RabbitMQ es un broker de mensajería multi-protocolo de código abierto.

Ejecutar rabbitmq-server inicia un nodo RabbitMQ en primer plano. El nodo mostrará un banner de inicio e informará cuando el inicio se haya completado. Para apagar el servidor, utilice las herramientas de gestión de servicios o rabbitmqctl(8).

ENTORNO

RABBITMQ_CONFIG_FILE
Por defecto es /etc/rabbitmq/rabbitmq.conf. Ruta del archivo de configuración del nodo. Para más información, consulte la guía de configuración de RabbitMQ
RABBITMQ_MNESIA_BASE
Por defecto es /var/lib/rabbitmq/mnesia. El directorio de datos del nodo se ubicará (o creará) en este directorio. Para más información, consulte la guía de archivos y directorios de RabbitMQ
RABBITMQ_LOG_BASE
Por defecto es /var/log/rabbitmq. Los archivos de registro generados por el servidor se colocarán en este directorio. Para más información, consulte la guía de registro de RabbitMQ
RABBITMQ_NODENAME
Por defecto es "rabbit@". seguido del nombre de host calculado. Se puede utilizar para ejecutar varios nodos en el mismo host. Cada nodo en un clúster debe tener un RABBITMQ_NODENAME único. Para más información, consulte la guía de clústeres de RabbitMQ
RABBITMQ_NODE_IP_ADDRESS
Por defecto, RabbitMQ se enlazará a todas las interfaces IPv6 e IPv4 disponibles. Esta variable limita el nodo a una única interfaz de red o familia de direcciones. Para más información, consulte la guía de redes de RabbitMQ
RABBITMQ_NODE_PORT
Puerto AMQP 0-9-1 y AMQP 1.0. Por defecto es 5672. Para más información, consulte la guía de redes de RabbitMQ

OPCIONES

-detached
Inicia el proceso del servidor en segundo plano. Tenga en cuenta que esto provocará que el pid no se escriba en el archivo pid.

Por ejemplo, ejecuta el servidor AMQP de RabbitMQ en segundo plano:

rabbitmq-server -detached
