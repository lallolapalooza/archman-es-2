RADSQLRELAY(8) Programa auxiliar de FreeRADIUS RADSQLRELAY(8)

NOMBRE

radsqlrelay - retransmite consultas SQL a un servidor de base de datos central

SINOPSIS

radsqlrelay [-?] [-d controlador_sql] [-b base_de_datos] [-f archivo] [-h host] [-u usuario] [-P puerto] [-p contraseña] [-1] [-x] ruta_archivo

DESCRIPCIÓN

radsqlrelay sigue un archivo_log_sql y retransmite las consultas a un servidor de base de datos. Se utiliza para replicar registros de contabilidad a una base de datos (central), incluso si la base de datos tiene tiempos de inactividad prolongados.

El archivo de log SQL es creado por el módulo rlm_sql con el controlador rlm_sql_null registrando en disco. El módulo debe estar configurado en el servidor radiusd antes de que pueda usar radsqlrelay.

OPCIONES

-?
Imprime información de ayuda sobre el uso.
-d controlador_sql
Controlador a usar: mysql, pg, oracle.
-b base_de_datos
Nombre de la base de datos a usar.
-f archivo
Lee la contraseña desde un archivo, en lugar de la línea de comandos.
-h host
Conéctate al host.
-u usuario
Usuario para el inicio de sesión.
-P puerto
Número de puerto a usar para la conexión.
-p contraseña
Contraseña a usar al conectarse al servidor.
-1
Modo de ejecución única: empuja el archivo a la base de datos y sale.
-x
Activa la depuración.
ruta_archivo
La ruta del archivo de log SQL a usar.

NOTAS

Controlador Oracle

El comando "radsqlrelay -d oracle -b db.domain.tld sql-relay" lee la descripción de la base de datos almacenada en $TNS_ADMIN/tnsnames.ora:

db.domain.tld =
  (DESCRIPTION =
    (ADDRESS_LIST =
      (ADDRESS = (PROTOCOL = TCP)(HOST = db.domain.tld)(PORT = 1521))
    )
    (CONNECT_DATA =
      (SERVICE_NAME = <DB SID>)
    )
  )
