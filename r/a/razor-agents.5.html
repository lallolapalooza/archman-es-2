NOMBRE

Razor-Agents - Colección de archivos para comprobar, reportar y revocar spam

DESCRIPCIÓN

Vipul's Razor es una red distribuida y colaborativa de detección, reporte y filtrado de spam. El objetivo principal del sistema es identificar y eliminar todo el spam de correo electrónico de Internet. Visita la página web en http://razor.sourceforge.net/.

USO

Primero, se debe crear un directorio razorhome donde residirán los registros, la configuración y la información cacheada del servidor. Esto se hace con la opción "-create" de razor-admin(1). Consulta la página del manual para obtener detalles.

Puedes comprobar el spam inmediatamente usando razor-check(1). Consulta la página del manual para obtener detalles.

Para reportar spam, se debe registrar una identidad. Esto se hace con la opción "-register" de razor-admin(1). Después de eso, razor-report(1) y razor-revoke(1) funcionarán sin problemas.

CONFIGURACIÓN

Todos los Razor-Agents comparten un archivo de configuración. El contenido del archivo de configuración se detalla en la página del manual razor-agent.conf(5).

El archivo de configuración se determina antes que razorhome, en el siguiente orden:

-conf=/ruta/archivo.conf         se usa si es legible, si no
<home>/.razor/razor-agent.conf  se usa si es legible, si no
/etc/razor/razor-agent.conf     se usa si es legible, si no
se usan todos los valores por defecto.

Para ver los valores de configuración por defecto, haz
razor-admin -create -conf=/tmp/razor2-defaults.conf

RAZORHOME

Todos los Razor-Agents también comparten un directorio razorhome, donde se almacena la identidad, el registro y la información cacheada sobre los servidores. Razorhome se determina después del archivo de configuración, en el siguiente orden.

-home=/tmp/razor/                     se usa si es legible, si no
'razorhome' del archivo de configuración   se usa si es legible, si no
<home>/.razor/                        se usa si es legible, si no
<home>/.razor/                        se crea. si falla,
                                      no hay razorhome.
NOTA: Si no hay razorhome, razor-report y razor-revoke no
      funcionarán a menos que especifiques -ident=/ruta/identidad
      razor-check seguirá funcionando.

ARCHIVOS

Además de los listados al final con sus propias páginas del manual, Razor Agents también tiene los siguientes archivos.

razorhome/identity
Normalmente un enlace simbólico al archivo de identidad que contiene usuario+contraseña. Usado por razor-report(1) y razor-revoke(1).
razorhome/razor-agent.log
Archivo de registro por defecto. Para cambiarlo, edita razor-agent.conf(5).
razorhome/servers.*.lst
Lista cacheadada de Servidores Razor. Si hay más de uno, se ordenan por tiempo de ping más cercano.
razorhome/server.<nombre>.lst
Información cacheada para el servidor <nombre>. La clave "srl" en este archivo se compara con el saludo del servidor, y si el del servidor es mayor, se recupera la nueva información de caché del servidor.

EJEMPLOS

razor-check -d -debuglevel=9 mbox
Comprueba el spam en mbox. Imprime los números de los que se encuentran como spam. -d registra en stdout, -debuglevel=9 es registro detallado
razor-admin -create -home=/home/chad/.razor -d -s
Crea razorhome en /home/chad/.razor, registra en stdout, no se conecta al servidor (-s simula).
razor-report spam -debuglevel=0
envía spam al servidor, sin mensajes de registro.
