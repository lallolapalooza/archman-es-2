radiobutton(n) Comandos incorporados de Tk radiobutton(n)

NOMBRE

radiobutton - Crear y manipular widgets de selección única 'radiobutton'

SINOPSIS

radiobutton nombreRuta ?opciones?

OPCIONES ESTÁNDAR

-activebackground	-disabledforeground	-padx
-activeforeground	-font	-pady
-anchor	-foreground	-relief
-background	-highlightbackground	-takefocus
-bitmap	-highlightcolor	-text
-borderwidth	-highlightthickness	-textvariable
-compound	-image	-underline
-cursor	-justify	-wraplength

Ver la entrada del manual de options para más detalles sobre las opciones estándar.

OPCIONES ESPECÍFICAS DEL WIDGET

Nombre de línea de comandos:	-command
Nombre de base de datos:	command
Clase de base de datos:	Command
Especifica un comando Tcl para asociar con el botón. Este comando se invoca típicamente cuando se suelta el botón 1 del ratón sobre la ventana del botón. La variable global del botón (opción -variable) se actualizará antes de invocar el comando.
Nombre de línea de comandos:	-height
Nombre de base de datos:	height
Clase de base de datos:	Height
Especifica una altura deseada para el botón. Si se muestra una imagen o un mapa de bits en el botón, el valor está en unidades de pantalla (es decir, cualquiera de las formas aceptables para Tk_GetPixels); para texto, está en líneas de texto. Si no se especifica esta opción, la altura deseada del botón se calcula a partir del tamaño de la imagen o mapa de bits o texto que se muestra en él.
Nombre de línea de comandos:	-indicatoron
Nombre de base de datos:	indicatorOn
Clase de base de datos:	IndicatorOn
Especifica si el indicador debe dibujarse o no. Debe ser un valor booleano correcto. Si es falso, la opción -relief se ignora y el relieve del widget siempre es hundido si el widget está seleccionado y elevado de lo contrario.
Nombre de línea de comandos:	-offrelief
Nombre de base de datos:	offRelief
Clase de base de datos:	OffRelief
Especifica el relieve para el botón de selección cuando el indicador no está dibujado y el botón de selección está apagado. El valor predeterminado es "elevado". Al establecer esta opción en "plano" y establecer -indicatoron en falso y -overrelief en "elevado", se logra el efecto de tener un botón plano que se eleva al pasar el ratón por encima y que se deprime al activarse. Este es el comportamiento que exhiben típicamente los botones Alinear a la izquierda, Alinear a la derecha y Centrar en la barra de herramientas de un procesador de textos, por ejemplo.
Nombre de línea de comandos:	-overrelief
Nombre de base de datos:	overRelief
Clase de base de datos:	OverRelief
Especifica un relieve alternativo para el botón de selección, que se utilizará cuando el cursor del ratón esté sobre el widget. Esta opción se puede usar para crear botones de barra de herramientas, configurando -relief plano -overrelief elevado. Si el valor de esta opción es una cadena vacía, entonces no se utiliza ningún relieve alternativo cuando el cursor del ratón está sobre el botón de selección. La cadena vacía es el valor predeterminado.
Nombre de línea de comandos:	-selectcolor
Nombre de base de datos:	selectColor
Clase de base de datos:	Background
Especifica un color de fondo a usar cuando el botón está seleccionado. Si indicatorOn es verdadero, el color se utiliza como fondo para el indicador independientemente del estado de selección. Si -indicatoron es falso, este color se usa como fondo para todo el widget, en lugar de -background o -activeBackground, siempre que el widget esté seleccionado. Si se especifica como una cadena vacía, no se utiliza ningún color especial para la visualización cuando el widget está seleccionado.
Nombre de línea de comandos:	-selectimage
Nombre de base de datos:	selectImage
Clase de base de datos:	SelectImage
Especifica una imagen para mostrar (en lugar de la opción -image) cuando el botón de selección está seleccionado. Esta opción se ignora a menos que se haya especificado la opción -image.
Nombre de línea de comandos:	-state
Nombre de base de datos:	state
Clase de base de datos:	State
Especifica uno de los tres estados para el botón de selección: normal, active o disabled. En estado normal, el botón de selección se muestra utilizando las opciones -foreground y -background. El estado activo se usa típicamente cuando el puntero está sobre el botón de selección. En estado activo, el botón de selección se muestra utilizando las opciones -activeforeground y -activebackground. El estado deshabilitado significa que el botón de selección debe ser insensible: las vinculaciones predeterminadas se negarán a activar el widget e ignorarán las pulsaciones del botón del ratón. En este estado, las opciones -disabledforeground y -background determinan cómo se muestra el botón de selección.
Nombre de línea de comandos:	-tristateimage
Nombre de base de datos:	tristateImage
Clase de base de datos:	TristateImage
Especifica una imagen para mostrar (en lugar de la opción -image) cuando el botón de selección está seleccionado. Esta opción se ignora a menos que se haya especificado la opción -image.
Nombre de línea de comandos:	-tristatevalue
Nombre de base de datos:	tristateValue
Clase de base de datos:	Value
Especifica el valor que hace que el botón de selección muestre la selección de varios valores, también conocida como modo triestado. El valor predeterminado es "".
Nombre de línea de comandos:	-value
Nombre de base de datos:	value
Clase de base de datos:	Value
Especifica el valor que se almacenará en la variable asociada al botón cada vez que se seleccione este botón.
Nombre de línea de comandos:	-variable
Nombre de base de datos:	variable
Clase de base de datos:	Variable
Especifica el nombre de una variable global que se establecerá cada vez que se seleccione este botón. Los cambios en esta variable también hacen que el botón se seleccione o deseleccione a sí mismo. El valor predeterminado es selectedButton.
Nombre de línea de comandos:	-width
Nombre de base de datos:	width
Clase de base de datos:	Width
Especifica un ancho deseado para el botón. Si se muestra una imagen o un mapa de bits en el botón, el valor está en unidades de pantalla (es decir, cualquiera de las formas aceptables para Tk_GetPixels); para texto, está en caracteres. Si no se especifica esta opción, el ancho deseado del botón se calcula a partir del tamaño de la imagen o mapa de bits o texto que se muestra en él.

DESCRIPCIÓN

El comando radiobutton crea una nueva ventana (dada por el argumento nombreRuta) y la convierte en un widget de botón de selección. Opciones adicionales, descritas anteriormente, pueden especificarse en la línea de comandos o en la base de datos de opciones para configurar aspectos del botón de selección, como sus colores, fuente, texto y relieve inicial. El comando radiobutton devuelve su argumento nombreRuta. En el momento en que se invoca este comando, no debe existir ninguna ventana llamada nombreRuta, pero el padre de nombreRuta debe existir.

Un botón de selección es un widget que muestra una cadena textual, un mapa de bits o una imagen y un diamante o círculo llamado indicador. Si se muestra texto, todo debe estar en una sola fuente, pero puede ocupar varias líneas en la pantalla (si contiene saltos de línea o si se produce un ajuste de línea debido a la opción -wraplength) y uno de los caracteres puede estar opcionalmente subrayado usando la opción -underline. Un botón de selección tiene todo el comportamiento de un botón simple: puede mostrarse de tres maneras diferentes, según la opción -state; puede hacerse que parezca elevado, hundido o plano; puede hacerse que parpadee; e invoca un comando Tcl cada vez que se hace clic con el botón 1 del ratón sobre el botón de selección.

Además, los botones de selección pueden ser *seleccionados*. Si un botón de selección está seleccionado, el indicador normalmente se dibuja con una apariencia seleccionada, y una variable Tcl asociada con el botón de selección se establece en un valor particular (normalmente 1). En Unix, el indicador se dibuja con un relieve hundido y un color especial. En Windows, el indicador se dibuja con una marca redonda en su interior. Si el botón de selección no está seleccionado, entonces el indicador se dibuja con una apariencia deseleccionada, y la variable asociada se establece en un valor diferente (típicamente 0). El indicador se dibuja sin una marca redonda en su interior. Típicamente, varios botones de selección comparten una sola variable y el valor de la variable indica qué botón de selección debe ser seleccionado.

radiobutton(n)

NAME

radiobutton

create and manage radiobutton widgets

SYNOPSIS

package require Tk
radiobutton pathName ?options...?

STANDARD OPTIONS

See the options command for a full description of the standard options for the radiobutton command. The options available are -activebackground, -activeforeground, -anchor, -background, -bitmap, -borderwidth, -cursor, -disabledforeground, -font, -foreground, -height, -highlightbackground, -highlightcolor, -highlightthickness, -image, -justify, -labelwidget, -padx, -pady, -relief, -takefocus, -textvariable, -underline, -use, -width, and -wraplength.

WIDGET-SPECIFIC OPTIONS

-command script
Specifies a script to be executed whenever the radiobutton is selected. This is the same as the -command option for button widgets. If this option is specified, it overrides the -command specified in the application's option database or on the command line.
-selectcolor color
Specifies the color to use to draw the indicator for a selected radiobutton. The default is system dependent.
-selectimage image
Specifies an image to be displayed in the radiobutton when it is selected. If this option is specified, it overrides the value of the -image option. The -selectimage option is ignored if there is no -image option or if the -image option is set to the empty string.
-state state
Specifies one of the following values: normal, active, or disabled. The active state is normally used only internally to show the effect of the mouse pointer passing over the widget. If the state is disabled then mouse clicks and keyboard input directed to the radiobutton are ignored, and the radiobutton is grayed out. The default is normal.
-tristatevalue value
Specifies a value that is used to indicate a tri-state condition. If the associated variable contains this value, the radiobutton is displayed in a special tri-state mode. This option is intended for use in situations where a radiobutton is used to represent the state of multiple items, and those items may have different values. The default is empty string.
-value value
Specifies a value associated with this radiobutton. When the radiobutton is selected, the value of the variable specified by -textvariable is set to this value. The default is empty string.
-variable name
Specifies the name of the Tcl variable that is linked to the radiobutton. When the radiobutton is selected, the value of this variable is set to the value specified by the -value option. When the variable's value changes, the radiobutton automatically updates its selected state. If the variable's value matches the -tristatevalue, then the radiobutton is drawn using the tri-state mode. If the variable's value matches the -value for this radiobutton, then this radiobutton is selected. Otherwise, it is deselected. If the variable's value is neither the -value nor the -tristatevalue, and there is another radiobutton associated with the same variable that is selected, this radiobutton will be deselected. If no variable is specified, the radiobutton is not linked to any Tcl variable, and its state can only be changed using the select and deselect commands. The default is empty string.

DESCRIPTION

The radiobutton command creates a widget that is a small button containing an indicator. This indicator can be a diamond, a circle, or a bitmap. Radiobuttons are typically used in groups of two or more, where selecting one radiobutton causes any other previously selected radiobutton in the group to become deselected. They are useful for choosing one option from a set of mutually exclusive options.

When a radiobutton is selected it sets the value of the variable to indicate that fact; each radiobutton also monitors the value of the variable and automatically selects and deselects itself when the variable's value changes. If the variable's value matches the -tristatevalue, then the radiobutton is drawn using the tri-state mode. This mode is used to indicate mixed or multiple values. (This is used when the radiobutton represents the state of multiple items.) By default the variable selectedButton is used; its contents give the name of the button that is selected, or the empty string if no button associated with that variable is selected. The name of the variable for a radiobutton, plus the variable to be stored into it, may be modified with options on the command line or in the option database. Configuration options may also be used to modify the way the indicator is displayed (or whether it is displayed at all). By default a radiobutton is configured to select itself on button clicks.

WIDGET COMMAND

The radiobutton command creates a new Tcl command whose name is pathName. This command may be used to invoke various operations on the widget. It has the following general form:

pathName option ?arg arg ...?
Option and the args determine the exact behavior of the command. The following commands are possible for radiobutton widgets:
pathName cget option
Returns the current value of the configuration option given by option. Option may have any of the values accepted by the radiobutton command.
pathName configure ?option? ?value option value ...?
Query or modify the configuration options of the widget. If no option is specified, returns a list describing all of the available options for pathName (see Tk_ConfigureInfo for information on the format of this list). If option is specified with no value, the command returns a list describing the one named option (this list will be identical to the corresponding sublist of the value returned if no option is specified). If one or more option-value pairs are specified, the command modifies the given widget option(s) to have the given value(s); in this case the command returns an empty string. Option may have any of the values accepted by the radiobutton command.
pathName deselect
Deselects the radiobutton and sets the associated variable to an empty string. If this radiobutton was not currently selected, the command has no effect.
pathName flash
Flashes the radiobutton. This is accomplished by redisplaying the radiobutton several times, alternating between active and normal colors. At the end of the flash the radiobutton is left in the same normal/active state as when the command was invoked. This command is ignored if the radiobutton's state is disabled.
pathName invoke
Does just what would have happened if the user invoked the radiobutton with the mouse: selects the button and invokes its associated Tcl command, if there is one. The return value is the return value from the Tcl command, or an empty string if there is no command associated with the radiobutton. This command is ignored if the radiobutton's state is disabled.
pathName select
Selects the radiobutton and sets the associated variable to the value corresponding to this widget.

BINDINGS

Tk automatically creates class bindings for radiobuttons that give them the following default behavior:

[1]
On Unix systems, a radiobutton activates whenever the mouse passes over it and deactivates whenever the mouse leaves the radiobutton. On Mac and Windows systems, when mouse button 1 is pressed over a radiobutton, the button activates whenever the mouse pointer is inside the button, and deactivates whenever the mouse pointer leaves the button.
[2]
When mouse button 1 is pressed over a radiobutton it is invoked (it becomes selected and the command associated with the button is invoked, if there is one).
[3]
When a radiobutton has the input focus, the space key causes the radiobutton to be invoked.

If the radiobutton's state is disabled then none of the above actions occur: the radiobutton is completely non-responsive.

The behavior of radiobuttons can be changed by defining new bindings for individual widgets or by redefining the class bindings.
