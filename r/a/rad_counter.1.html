NOMBRE

rad_counter - Consultar y mantener el archivo de base de datos rlm_counter de FreeRADIUS.

Esta herramienta está obsoleta

SINOPSIS

rad_counter [--file nombre_archivo_contador] [--user nombre_usuario] [--match <expresión_regular>] [--reset número] [--help] [--hours|--minutes|--seconds]

DESCRIPCIÓN

rad_counter es una herramienta que puede consultar y mantener archivos de base de datos de rlm_counter de FreeRADIUS.

OPCIONES

--file=
Nombre del archivo de base de datos del contador.
--user= nombre_usuario
Información para un usuario específico.
--match= <expresión_regular>
Información para usuarios que coincidan.
--reset= número
Restablecer el contador a <número>. Si el divisor está establecido, úsalo, de lo contrario <número> significa segundos.
--help
Mostrar la pantalla de ayuda.
--(hours | minutes | seconds)
Especificar el divisor de información.

VER TAMBIÉN

radiusd(8)
