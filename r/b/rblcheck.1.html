rblckeck(1) Manual de Comandos Generales rblckeck(1)

NOMBRE

rblckeck - utilidad de consulta DNSBL

SINOPSIS

rblckeck [-s zona] [-S archivo-zona] [-c] [-tmvq] [-n dirección-ns] dirección...

DESCRIPCIÓN

rblckeck es una utilidad simple de línea de comandos para realizar consultas DNSBL (listas de bloqueo basadas en DNS). Para cada dirección IP (o nombre, en cuyo caso se resolverá primero a una dirección), la utilidad verifica si está incluida en una (lista de) listas de bloqueo de DNS especificadas con las opciones -s o -S, opcionalmente obtiene el texto asociado con la entrada (generalmente es una descripción del motivo de la inclusión o una URL que se refiere a dicha descripción) y muestra los resultados en la salida estándar.

El programa está implementado sobre la biblioteca udns(3).

OPCIONES

Las siguientes opciones son reconocidas por rblckeck:

-s zona
añade el nombre de la zona DNSBL dado a la lista de zonas activas.
-S archivo-zona
añade la lista de zonas del archivo-zona especificado a la lista de zonas activas (el archivo especifica una zona como la primera palabra en una línea, las líneas vacías y las líneas que comienzan con el carácter `#` se ignoran).
-c
restablece la lista de zonas activas.
-v
sea más verboso, produzca una salida más detallada.
-q
lo opuesto a -v: produzca menos detalles en la salida.
-t
obtenga el texto para las direcciones listadas.
-n dirección-ns
use el servidor de nombres dado (proporcionado como dirección IPv4 o IPv6) en lugar del predeterminado. El mismo efecto se puede lograr configurando la variable de entorno $NSCACHEIP.
-m
deténgase después del primer resultado positivo, es decir, después de la primera dirección que se encuentre listada.
-h
muestre una ayuda breve y salga.

Si no se proporcionan las opciones -s, -S y -c, rblckeck intentará obtener la lista de zonas utilizando la variable de entorno $RBLCHECK_ZONES, o los archivos ~/.rblcheckrc, o /etc/rblckechrc, en ese orden. Si no se encuentran zonas, saldrá sin éxito.

VALOR DE RETORNO

Cuando ninguna de las direcciones dadas esté listada y no ocurran errores, rblckeck saldrá con el código 0. Si al menos una dirección está listada, rblckeck devolverá 100. En caso de errores de DNS, rblckeck devolverá 2.

ENTORNO

$RBLCHECK_ZONES
si no se proporciona la opción -s, -S o -c, rblckeck intenta usar esta variable para obtener la lista de zonas DNSBL contra las cuales verificar.

FICHEROS

$HOME/.rblcheckrc y /etc/rblcheckrc
si no se proporciona la opción -s, -S o -c, y la variable de entorno $RBLCHECK_ZONES no está configurada, rblckeck intentará usar los dos archivos (el primero que exista) para obtener la lista de zonas DNSBL contra las cuales verificar. Cada línea especifica una zona (solo se usa la primera palabra de cada línea). Las líneas vacías y las líneas que comienzan con el carácter `#` se ignoran.

VER TAMBIÉN

dnsget(1) resolv.conf(5) udns(3).
