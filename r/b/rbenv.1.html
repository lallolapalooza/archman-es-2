RBENV(1) Manual de Rbenv RBENV(1)

NOMBRE

rbenv - gestiona el entorno Ruby de tu aplicación

SINOPSIS

rbenv <comando> [<argumentos>...]

DESCRIPCIÓN

rbenv respeta el archivo .ruby-version en el directorio de un proyecto asegurándose de que cualquier invocación de comandos como ruby, gem, bundle u otros comandos Ruby invoque automáticamente la versión de Ruby configurada para ese proyecto.

Lo hace generando "shims" para todos los ejecutables de Ruby. Mientras el directorio de shims de rbenv esté antepuesto a PATH, rbenv se asegura automáticamente de cambiar de forma transparente entre las versiones de Ruby.

rbenv busca versiones de Ruby disponibles en el directorio $RBENV_ROOT/versions.

COMANDOS

rbenv global [<versión>]

Ver o cambiar la versión global de Ruby

rbenv local [<versión>]

Ver o cambiar la versión local de Ruby

rbenv shell [<versión>]

Ver o cambiar la versión de Ruby para la sesión de shell actual

rbenv version

Ver la versión de Ruby actualmente activa y desde dónde se estableció

rbenv versions

Listar todas las versiones de Ruby instaladas localmente que rbenv conoce

rbenv install [<versión>]

(Proporcionado por el plugin ruby-build) Descargar e instalar una nueva versión de Ruby

rbenv rehash

Regenerar los shims para todos los ejecutables de Ruby conocidos

rbenv which [<comando>]

Ver la ruta del ejecutable al que se resuelve un comando

rbenv init

Ayuda a arrancar rbenv en el entorno de shell actual

rbenv help [<comando>]

Ver el texto de ayuda para cualquier comando de rbenv

VARIABLES DE ENTORNO

RBENV_VERSION (por defecto: leído del archivo .ruby-version)

El nombre de la versión de Ruby que se utilizará

RBENV_ROOT (por defecto: ~/.rbenv)

La ubicación donde rbenv descubre versiones de Ruby, plugins y otra configuración

RBENV_DEBUG

Activa la impresión de información de depuración sobre los internos de rbenv en la salida de error estándar

RBENV_HOOK_PATH

Lista separada por dos puntos de rutas buscadas para scripts de plugins de rbenv

RBENV_DIR (por defecto: $PWD)

Directorio que se recorrerá de abajo hacia arriba para localizar el archivo .ruby-version

PLUGINS

Como funcionalidad principal, rbenv solo cambia entre versiones de Ruby y no hace nada más, pero ofrece un mecanismo de plugins para engancharse y anular casi cualquier aspecto de su comportamiento predeterminado.

El plugin más común para rbenv es ruby-build, que facilita la instalación de nuevas versiones de Ruby en el directorio $RBENV_ROOT/versions.

Lee más en https://github.com/rbenv/rbenv/wiki/Plugins
