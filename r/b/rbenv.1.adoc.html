== Nombre

rbenv - gestiona el entorno Ruby de tu aplicación

== Sinopsis

*rbenv* _<comando>_ [_<argumentos>_...]

== Descripción

rbenv respeta el archivo _.ruby-version_ en un directorio de proyecto asegurándose de que cualquier invocación de comando *ruby*, *gem*, *bundle* u otro comando Ruby invoque automáticamente la versión de Ruby configurada para ese proyecto.

Lo hace generando shims para todos los ejecutables de Ruby. Siempre que el directorio de shims de rbenv esté antepuesto a PATH, rbenv asegura automáticamente el cambio transparente entre versiones de Ruby.

rbenv busca versiones de Ruby disponibles en el directorio _$RBENV_ROOT/versions_.

== Comandos

*rbenv global* [_<versión>_]::
Ver o cambiar la versión global de Ruby

*rbenv local* [_<versión>_]::
Ver o cambiar la versión local de Ruby

*rbenv shell* [_<versión>_]::
Ver o cambiar la versión de Ruby para la sesión de shell actual

*rbenv version*::
Ver la versión de Ruby actualmente activa y de dónde se establece

*rbenv versions*::
Listar todas las versiones de Ruby instaladas localmente conocidas por rbenv

*rbenv install* [_<versión>_]::
(Proporcionado por el plugin *ruby-build*) Descargar e instalar una nueva versión de Ruby

*rbenv rehash*::
Regenerar shims para todos los ejecutables de Ruby conocidos

*rbenv which* [_<comando>_]::
Ver la ruta del ejecutable a la que se resuelve un comando

*rbenv init*::
Ayuda a arrancar rbenv en el entorno de shell actual

*rbenv help* [_<comando>_]::
Ver el texto de ayuda para cualquier comando de rbenv

== Variables de Entorno

*RBENV_VERSION* (por defecto: leído del archivo _.ruby-version_)::
El nombre de la versión de Ruby a utilizar

*RBENV_ROOT* (por defecto: _~/.rbenv_)::
La ubicación donde rbenv descubre versiones de Ruby, plugins y otra configuración

*RBENV_DEBUG*::
Activa la impresión de información de depuración sobre los internos de rbenv en la salida estándar de error

*RBENV_HOOK_PATH*::
Lista separada por dos puntos de las rutas donde se buscan los scripts de plugins de rbenv

*RBENV_DIR* (por defecto: _$PWD_)::
Directorio a recorrer de abajo hacia arriba para localizar el archivo _.ruby-version_

== Plugins

Como funcionalidad principal, rbenv solo cambia entre versiones de Ruby y no hace nada más, pero ofrece un mecanismo de plugins para engancharse y sobrescribir casi cualquier aspecto de su comportamiento predeterminado.

El plugin más común para rbenv es *ruby-build*, que facilita la instalación de nuevas versiones de Ruby en el directorio _$RBENV_ROOT/versions_.

Lee más en https://github.com/rbenv/rbenv/wiki/Plugins
