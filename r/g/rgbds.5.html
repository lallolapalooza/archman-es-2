RGBDS(5) Manual de formatos de archivo RGBDS(5)

NOMBRE

rgbds — documentación del formato de archivo objeto

DESCRIPCIÓN

Esta es la descripción de los archivos objeto utilizados por rgbasm(1) y rgblink(1). ¡Por favor, ten en cuenta que la especificación aún no es estable! RGBDS todavía está en desarrollo activo, y algunas características nuevas requieren añadir más información al archivo objeto, o modificar algunos campos, ambos rompen la compatibilidad con versiones anteriores.

ESTRUCTURA DEL ARCHIVO

Se utilizan los siguientes tipos:

LONG es un entero de 32 bits almacenado en formato little-endian. BYTE es un entero de 8 bits. STRING es una cadena terminada en 0 de BYTE. Los corchetes después de un tipo (p. ej., LONG[n]) indican n elementos consecutivos (aquí, LONGs). Todos los elementos son contiguos, sin relleno en ningún lugar; ¡esto también significa que pueden no estar alineados en el archivo!

REPT n indica que los campos entre el REPT y el ENDR correspondiente se repiten n veces.

Todos los IDs se refieren a objetos dentro del archivo; por ejemplo, el ID de símbolo $0001 se refiere al segundo símbolo definido en este archivo objeto en el array de Símbolos. La única excepción son los nodos de información de archivo fuente (Información del archivo fuente), cuyos IDs son inversos, es decir, el ID del nodo fuente $0000 se refiere al último nodo de la lista, no al primero. Las referencias a otros archivos objeto se realizan mediante importaciones (símbolos), por nombre (secciones), etc.; ¡pero nunca por ID.

Expresiones RPN

Las expresiones en el archivo objeto se almacenan como RPN, o «Notación Polaca Inversa», que es una notación que permite calcular expresiones arbitrarias con una simple pila. Por ejemplo, la expresión «2 5 -» primero apilará el valor «2», luego «5». El operador «-» desapilará dos argumentos de la pila, los restará y luego volverá a apilar el resultado («3») en la pila. Una expresión RPN bien formada nunca intenta desapilar de una pila vacía y deja exactamente un valor en ella al final.

RGBDS codifica las expresiones RPN como una matriz de BYTEs. El primer byte codifica un operador o un literal, que consume más BYTEs después de él:

NAME

rgbasm - assembler for the Game Boy CPU

DESCRIPTION

rgbasm is an assembler that converts human-readable assembly code into machine code for the Game Boy CPU. It is part of the RGBDS package.

The assembler supports the original Z80 instruction set used by the Game Boy, as well as some extensions and directives specific to ROM hacking and development.

FILE STRUCTURE
