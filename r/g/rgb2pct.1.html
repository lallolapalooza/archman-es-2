rgb2pct(1)

Paquete: gdal

Licencias: custom

RGB2PCT(1) GDAL RGB2PCT(1)

NOMBRE

rgb2pct - Convierte una imagen RGB de 24 bits a una de 8 bits con paleta.

SINOPSIS

rgb2pct [--help] [--help-general] [--creation-option OPTION]
           [-n colores | -pct archivo_paleta] [-of formato] <archivo_origen> <archivo_destino>

DESCRIPCIÓN

Esta utilidad calculará una tabla de colores pseudocolor óptima para una imagen RGB dada utilizando un algoritmo de corte mediano sobre un histograma RGB submuestreado. Luego, convierte la imagen en una imagen pseudocolor utilizando la tabla de colores. Esta conversión utiliza el tramado de Floyd-Steinberg (difusión de errores) para maximizar la calidad visual de la imagen de salida.

NOTA:

rgb2pct es una utilidad de Python y solo está disponible si los enlaces de Python de GDAL están disponibles.
--help
Muestra este mensaje de ayuda y sale.
--help-general
Proporciona un breve mensaje de uso para las opciones generales de la línea de comandos de GDAL y sale.
-n <colores>
Selecciona el número de colores en la tabla de colores generada. Por defecto es 256. Debe estar entre 2 y 256.
--creation-option OPCION
Parámetros opcionales de creación para el controlador GeoTIFF, por ejemplo "COMPRESS=LZW". Se puede especificar varias veces.
-pct <archivo_paleta>
Extrae la tabla de colores de <archivo_paleta> en lugar de calcularla. Se puede usar para tener una tabla de colores consistente para múltiples archivos. El <archivo_paleta> debe ser un archivo ráster en un formato soportado por GDAL con una paleta o un archivo de color en un formato soportado (txt, qml, qlr).
-of <formato>
Selecciona el formato de salida. Si no se especifica, el formato se adivina a partir de la extensión. Usa el nombre corto del formato. Solo se deben usar formatos de salida que soporten tablas de pseudocolores.
<archivo_origen>
El archivo RGB de entrada.
<archivo_destino>
El archivo pseudocolorizado de salida que se creará.

EJEMPLO

Si se desea crear la paleta manualmente, el formato de texto más sencillo es probablemente el formato VRT de GDAL. En el siguiente ejemplo, se creó un VRT en un editor de texto con una pequeña paleta de 4 colores con los colores RGBA 238/238/238/255, 237/237/237/255, 236/236/236/255 y 229/229/229/255.

$ rgb2pct -pct palette.vrt rgb.tif pseudocolorizado.tif
$ more < palette.vrt
<VRTDataset rasterXSize="226" rasterYSize="271">
    <VRTRasterBand dataType="Byte" band="1">
        <ColorInterp>Palette</ColorInterp>
        <ColorTable>
        <Entry c1="238" c2="238" c3="238" c4="255"/>
        <Entry c1="237" c2="237" c3="237" c4="255"/>
        <Entry c1="236" c2="236" c3="236" c4="255"/>
        <Entry c1="229" c2="229" c3="229" c4="255"/>
        </ColorTable>
    </VRTRasterBand>
</VRTDataset>
