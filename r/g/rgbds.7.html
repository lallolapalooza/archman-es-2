RGBDS(7) Manual de Información Miscelánea RGBDS(7)

NOMBRE

rgbds — Sistema de Desarrollo Rednex Game Boy

EJEMPLOS

Para obtener una imagen ROM funcional a partir de un único archivo fuente de ensamblaje:

$ rgbasm -o game.o game.asm
$ rgblink -o game.gb game.o
$ rgbfix -v -p 0 game.gb

O en una sola línea de comandos, sin crear un archivo objeto intermedio:

$ (rgbasm -o - - | rgblink -o - - | rgbfix -v -p 0) < game.asm > game.gb

VER TAMBIÉN

rgbasm(1), rgbasm(5), rgblink(1), rgblink(5), rgbfix(1), rgbgfx(1), gbz80(7), rgbds(5)

HISTORIA

  • 1996-10-01: Carsten Sørensen (alias SurfSmurf) publica xAsm, xLink y RGBFix, un sistema de ensamblador/enlazador SM83 (GBZ80) para Game Boy para DOS/Win32.
  • 1997-07-03: Sørensen publica ASMotor, empaquetando los tres programas juntos y avanzando hacia la creación de un sistema genérico independiente del objetivo.
  • 1999-08-01: Justin Lloyd (alias Otaku no Zoku) adapta ASMotor para centrarse de nuevo en el ensamblaje/código máquina SM83 y publica esta versión como RGBDS.
  • 2009-06-11: Vegard Nossum adapta el código para que sea más parecido a UNIX y publica esta versión como rgbds-linux.
  • 2010-01-12: Anthony J. Bentley bifurca el repositorio de Nossum. La bifurcación se convierte en la implementación de referencia de RGBDS.
  • 2010-09-25: Sørensen continúa el desarrollo de ASMotor hasta el día de hoy.
  • 2015-01-18: stag019 comienza a implementar RGBGFX, un convertidor de gráficos PNG a Game Boy, para su integración futura en RGBDS.
  • 2016-09-05: RGBGFX se integra en el repositorio de Bentley.
  • 2017-02-23: El repositorio de Bentley se traslada a la organización rednex.
  • 2018-01-26: El código fuente se relicencia bajo la licencia MIT.
  • 2020-09-15: El repositorio se traslada a la organización gbdev.
  • 2022-05-17: Se publica el sitio web rgbds.gbdev.io para documentación y descargas de RGBDS.
