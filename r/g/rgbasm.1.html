RGBASM(1) Manual de comandos generales RGBASM(1)

NOMBRE

rgbasm — Ensamblador de Game Boy

SINOPSIS

rgbasm [-EhVvw] [-b caracteres] [-D nombre[=valor]] [-g caracteres] [-I ruta] [-M archivo_dependencias] [-MG] [-MC] [-MP] [-MT archivo_objetivo] [-MQ archivo_objetivo] [-o archivo_salida] [-P archivo_incluir] [-p valor_relleno] [-Q precision_fijo] [-r profundidad_recursion] [-s caracteristicas:archivo_estado] [-W advertencia] [-X max_errores] archivo_asm

DESCRIPCIÓN

El programa rgbasm crea un archivo objeto RGB a partir de un archivo fuente de ensamblaje. El formato del archivo objeto se documenta en rgbds(5).

El archivo fuente archivo_asm puede ser una ruta a un archivo, o - para leer desde la entrada estándar.

Tenga en cuenta que las opciones se pueden abreviar siempre que la abreviatura no sea ambigua: --verb es --verbose, pero --ver no es válido porque también podría ser --version. Los argumentos son los siguientes:

-b caracteres, --binary-digits caracteres
Permite usar dos caracteres adicionales para constantes binarias además de los predeterminados '0' y '1'. Los caracteres válidos son números distintos de '0' y '1', letras, '.', '#' o '@'.
-D nombre[=valor], --define nombre[=valor]
Añade un símbolo de cadena al código fuente compilado. Esto es equivalente a 'nombre EQUS "valor"' en código, o 'nombre EQUS "1"' si valor no se especifica.
-E, --export-all
Exporta todas las etiquetas, incluidas las no referenciadas y las locales.
-g caracteres, --gfx-chars caracteres
Permite usar cuatro caracteres adicionales para constantes gráficas además de los predeterminados '0', '1', '2' y '3'. Los caracteres válidos son números distintos de '0' a '3', letras, '.', '#' o '@'. Los valores predeterminados son 0123.
-h, --help
Imprime el texto de ayuda del programa y sale.
-I ruta, --include ruta
Añade una nueva "ruta de inclusión"; ruta debe apuntar a un directorio. Cuando se intenta un INCLUDE (incluido el implícito de -P), INCBIN o READFILE, rgbasm primero busca la ruta proporcionada desde su directorio de trabajo; si esto falla, lo intenta de nuevo desde cada uno de los directorios de "ruta de inclusión", en el orden en que se proporcionaron.
-M archivo_dependencias, --dependfile archivo_dependencias
Escribe las dependencias de make(1) en archivo_dependencias.
-MG
Para usar en conjunto con -M. Esto hace que rgbasm asuma que los archivos que faltan se generan automáticamente: cuando se intenta un INCLUDE (incluido el implícito de -P), INCBIN o READFILE en un archivo inexistente, se añade como dependencia, y luego rgbasm sale normalmente o continúa procesando (dependiendo de si se habilitó -MC) en lugar de dar un error. Esta característica se usa en la actualización automática de Makefiles.
-MC
Implica -MG. Esto hace que rgbasm continúe procesando después de un archivo de dependencia inexistente, en lugar de salir. Tenga en cuenta que esto no se recomienda si alguna dependencia inexistente hubiera influido en el procesamiento posterior, por ejemplo, al hacer que una condición IF tomara una rama diferente.
-MP
Cuando está habilitado, esto añade un objetivo ficticio a las reglas emitidas por -M para cada dependencia que no sea el archivo principal. Esto evita que make(1) muestre un error cuando se eliminan los archivos de dependencia.
-MT archivo_objetivo
Añade un objetivo a las reglas emitidas por -M. La cadena exacta proporcionada se escribirá, incluidos los espacios y caracteres especiales.
-MT archivoA -MT archivoB
es equivalente a
-MT 'archivoA archivoB'
. Si ni esto ni -MQ se especifican, se utiliza el nombre del archivo de salida.
-MQ archivo_objetivo
Igual que -MT, pero además escapa cualquier carácter especial de make(1), esencialmente '$'.
-o archivo_salida, --output archivo_salida
Escribe un archivo objeto en el nombre de archivo dado.
-P archivo_incluir, --preinclude archivo_incluir
Pre-incluye un archivo. Actúa como si se hubiera leído un 'INCLUDE "archivo_incluir"' antes del archivo fuente archivo_asm. Se pueden pre-incluir varios archivos en el orden en que se proporcionaron.
-p valor_relleno, --pad-value valor_relleno
Úselo como valor para las directivas DS en secciones ROM, a menos que se anule. El valor predeterminado es 0x00.
-Q precision_fijo, --q-precision precision_fijo
Úselo como la precisión de los números de punto fijo después del punto decimal, a menos que especifiquen su propia precisión. El valor predeterminado es 16, por lo que los números de punto fijo son Q16.16 (ya que son enteros de 32 bits). El argumento puede comenzar con un '.'
-r profundidad_recursion, --recursion-depth profundidad_recursion
Establece la profundidad máxima de recursión para las macros y las llamadas a funciones. Por defecto es 256.
-s caracteristicas:archivo_estado, --state-file caracteristicas:archivo_estado
Guarda o carga el estado del ensamblador. La cadena caracteristicas es una lista de características separadas por comas (por ejemplo, macros, defines, labels, sections). Si archivo_estado es -, el estado se guarda en la salida estándar.
-v, --verbose
Activa el modo detallado. Muestra información adicional sobre el proceso de ensamblaje.
-V, --version
Muestra la versión del programa y sale.
-W advertencia, --warning advertencia
Controla las advertencias. Puede usarse para habilitar, deshabilitar o tratar advertencias específicas como errores. Consulte la sección de advertencias en la documentación de rgbds para obtener una lista de las advertencias disponibles.
-X max_errores, --max-errors max_errores
Establece el número máximo de errores que se mostrarán antes de que el ensamblador se detenga. El valor predeterminado es 10.

ESTADO DE SALIDA

El código de salida es 0 si el ensamblaje fue exitoso. De lo contrario, es el número de errores encontrados.

DIAGNÓSTICOS

-Wno-truncation
Inhabilita esta advertencia.
-Wtruncation[=1|2]
Advierte cuando un valor de N bits es 2**N o mayor, o menor que -2**N. -Wtruncation=1 o solo -Wtruncation advierte cuando un valor de N bits es menor que -2**(N-1), lo cual no cabe en la codificación de complemento a dos.
-Wunmapped-char=
Advierte cuando un carácter pasa por la conversión de charmap pero no tiene un mapeo definido. -Wunmapped-char=0 o -Wno-unmapped-char inhabilita esta advertencia. -Wunmapped-char=1 o solo -Wunmapped-char solo advierte si el charmap activo no está vacío. -Wunmapped-char=2 advierte si el charmap activo está vacío y/o no es el charmap predeterminado ‘main’.
-Wunmatched-directive
Advierte cuando una directiva PUSHC, PUSHO o PUSHS no tiene una POPC, POPO o POPS correspondiente. Esta advertencia está habilitada por -Wextra.
-Wunterminated-load
Advierte cuando un bloque LOAD no está terminado por un ENDL. Esta advertencia está habilitada por -Wextra.
-Wno-user
Advierte cuando se ejecuta la instrucción incorporada WARN. (Ver “Aborting the assembly process” en rgbasm(5) para WARN).

EJEMPLOS

Puedes ensamblar un archivo fuente de dos maneras.

Manera directa:

$ rgbasm -o bar.o foo.asm

Manera con pipes:

$ cat foo.asm | rgbasm -o bar.o -
$ rgbasm -o bar.o - < foo.asm

El archivo objeto resultante aún no es una imagen ROM usable; primero debe ejecutarse a través de rgblink(1) y luego rgbfix(1).

Escribiendo el estado final del ensamblador a un archivo:

$ rgbasm -s all:state.dump.asm foo.asm

O a múltiples archivos:

$ rgbasm -s equ,var:numbers.dump.asm -s equs:strings.dump.asm foo.asm
