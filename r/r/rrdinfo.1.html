NOMBRE

rrdinfo - extraer información de cabecera de un RRD

SINOPSIS

rrdtool info nombre_archivo [--daemon|-d direccion [--noflush|-F]]

DESCRIPCIÓN

La función info imprime la información de cabecera de un RRD en un formato amigable para el análisis.

Comprueba rrdcreate si no estás seguro del significado de las claves individuales.

nombre_archivo
El nombre del RRD que quieres examinar.
--daemon|-d direccion
Dirección del demonio rrdcached. Si se especifica, se envía un comando "flush" al servidor antes de leer los archivos RRD. Esto permite a rrdtool devolver datos recientes incluso si el demonio está configurado para almacenar en caché los valores durante mucho tiempo. Para ver una lista de los formatos aceptados, consulta la opción -l en el manual de rrdcached. 
rrdtool info --daemon unix:/var/run/rrdcached.sock /var/lib/rrd/foo.rrd
--noflush|-F
Omite el comando "flush" que normalmente se envía al demonio antes de recuperar los datos. Si lo único que te interesa es la estructura del RRD y no la hora de la última actualización o los valores actuales, esto mejorará la eficiencia.

EJEMPLO

Esta es la salida generada al ejecutar info en un RRD sencillo que contiene dos fuentes de datos y un RRA. Ten en cuenta que el número después de la palabra clave last_update está en segundos desde 1970. La cadena NaN significa datos de *DESCONOCIDO* (Not a Number). En el ejemplo, significa que este RRD no tiene valores mínimos ni máximos definidos para ninguna de sus fuentes de datos.

filename = "random.rrd"
rrd_version = "0001"
step = 300
last_update = 955892996
header_size = 2872
ds[a].type = "GAUGE"
ds[a].minimal_heartbeat = 600
ds[a].min = NaN
ds[a].max = NaN
ds[a].last_ds = "UNKN"
ds[a].value = 2.1824421548e+04
ds[a].unknown_sec = 0
ds[b].type = "GAUGE"
ds[b].minimal_heartbeat = 600
ds[b].min = NaN
ds[b].max = NaN
ds[b].last_ds = "UNKN"
ds[b].value = 3.9620838224e+03
ds[b].unknown_sec = 0
rra[0].cf = "AVERAGE"
rra[0].pdp_per_row = 1
rra[0].cdp_prep[0].value = nan
rra[0].cdp_prep[0].unknown_datapoints = 0
rra[0].cdp_prep[1].value = nan
rra[0].cdp_prep[1].unknown_datapoints = 0

VARIABLES DE ENTORNO

Las siguientes variables de entorno pueden usarse para cambiar el comportamiento de "rrdtool info":

RRDCACHED_ADDRESS
Si esta variable de entorno está configurada, tendrá el mismo efecto que especificar la opción "--daemon" en la línea de comandos. Si ambas están presentes, el argumento de la línea de comandos tendrá precedencia.
