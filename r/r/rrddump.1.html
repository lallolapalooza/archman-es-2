NOMBRE

rrddump - volcar el contenido de un RRD a formato XML

SINOPSIS

rrdtool dump archivo.rrd [archivo.xml] [--header|-h {none,xsd,dtd}] [--no-header|-n] [--daemon|-d dirección] [> archivo.xml]

DESCRIPCIÓN

La función dump escribe el contenido de un RRD en formato XML legible por humanos (?) a un archivo o a la salida estándar. Este formato puede ser leído por rrdrestore. Juntos permiten transferir sus archivos de una arquitectura de computadora a otra, así como manipular el contenido de un archivo RRD de una manera un poco más conveniente.

archivo.rrd
El nombre del RRD que desea volcar.
archivo.xml
El nombre de archivo (opcional) al que desea escribir la salida XML. Si no se especifica, el XML se imprimirá en la salida estándar.
--header|-h {none,xsd,dtd}
Por defecto, RRDtool añadirá una cabecera dtd al archivo xml. Aquí puede personalizar esto a una cabecera xsd o a ninguna cabecera.
--no-header|-n
Un atajo para --header=none.

Si desea restaurar el volcado con RRDtool 1.2, debe usar la opción --no-header ya que la versión 1.2 no puede manejar cabeceras xml.

--daemon|-d dirección
Dirección del demonio rrdcached. Si se especifica, se envía un comando de "flush" al servidor antes de leer los archivos RRD. Esto permite a rrdtool devolver datos frescos incluso si el demonio está configurado para almacenar en caché valores durante mucho tiempo. Cuando se especifica, el nombre de archivo RRD significa un archivo del lado del servidor, pero el nombre de archivo de salida (XML) se refiere al lado local. Para una lista de formatos aceptados, consulte la opción -l en el manual de rrdcached. 
rrdtool dump --daemon unix:/var/run/rrdcached.sock /var/lib/rrd/foo.rrd

EJEMPLOS

Para transferir un RRD entre arquitecturas, siga estos pasos:

1.
En el mismo sistema donde se creó el RRD, use rrdtool dump para exportar los datos al formato XML.
2.
Transfiera el volcado XML al sistema de destino.
3.
Ejecute rrdtool restore para crear un nuevo RRD a partir del volcado XML. Consulte rrdrestore para obtener detalles.

VARIABLES DE ENTORNO

Las siguientes variables de entorno pueden ser utilizadas para cambiar el comportamiento de "rrdtool dump":

RRDCACHED_ADDRESS
Si esta variable de entorno está establecida, tendrá el mismo efecto que especificar la opción "--daemon" en la línea de comandos. Si ambas están presentes, el argumento de la línea de comandos tiene precedencia.
