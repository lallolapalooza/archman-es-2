NOMBRE

RRDLua - Binding de Lua para RRDtool

SINOPSIS

require 'rrd'
rrd.create(...)
rrd.dump(...)
rrd.fetch(...)
rrd.first(...)
rrd.graph(...)
rrd.graphv(...)
rrd.info(...)
rrd.last(...)
rrd.resize(...)
rrd.restore(...)
rrd.tune(...)
rrd.update(...)
rrd.updatev(...)

DESCRIPCIÓN

Secuencia de llamada

Este módulo accede a la funcionalidad de RRDtool directamente desde Lua. Los argumentos de las funciones listadas en la SINOPSIS se explican en la documentación regular de RRDtool. La llamada de línea de comandos

rrdtool update mydemo.rrd --template in:out N:12:13

se convierte en

rrd.update ("mydemo.rrd", "--template", "in:out", "N:12:13")

Tenga en cuenta que --template=in:out también es válido.

Usando con Lua 5.1

Inicie sus programas con:

---------------------------------------------------------------
package.cpath = '/usr/local/rrdtool-1.3.2/lib/lua/5.1/?.so;' ..
                package.cpath
require 'rrd'
---------------------------------------------------------------

OBSERVACIÓN: Si configuró con --enable-lua-site-install, no necesita configurar package.cpath como arriba.

Usando con Lua 5.0

El binding de Lua para RRDtool necesita el módulo Lua compat-5.1 para funcionar con Lua 5.0. Algunas distribuciones de Linux, como Ubuntu gutsy y hardy, ya lo tienen integrado en los paquetes -dev de Lua 5.0, por lo que solo tiene que requerirlo:

require 'compat-5.1'

Para otras plataformas, el módulo compat-5.1 que viene con este binding se instalará para usted en el mismo directorio donde se instaló RRDtool, bajo el subdirectorio .../lib/lua/5.0. En este caso, debe indicar a sus programas Lua dónde encontrarlo cambiando la variable Lua LUA_PATH:

-- compat-5.1.lua es necesario solo para Lua 5.0 ----------------
-- intente solo compat-5.1 instalado con el paquete RRDtool
local original_LUA_PATH = LUA_PATH
LUA_PATH = '/usr/local/rrdtool-1.3.2/lib/lua/5.0/?.lua'
require 'compat-5.1'
LUA_PATH = original_LUA_PATH
original_LUA_PATH = nil
--- fin del código para requerir compat-5.1 ---------------------------
Ahora podemos requerir el módulo rrd de la misma manera que lo hicimos para
    5.1 arriba:
---------------------------------------------------------------
package.cpath = '/usr/local/rrdtool-1.3.2/lib/lua/5.0/?.so;' ..
                package.cpath
require 'rrd'
---------------------------------------------------------------

Manejo de errores

Las funciones del módulo RRDtool de Lua abortarán su programa con un traceback de la pila cuando no puedan interpretar los argumentos que les ha proporcionado. Sin embargo, puede capturar y manejar los errores usted mismo, en lugar de simplemente dejar que el programa aborte, llamando a las funciones del módulo a través de llamadas protegidas de Lua - 'pcall' o 'xpcall'.

Ej: programa t.lua
--- compat-5.1.lua es necesario solo para Lua 5.0 ----------------
-- descomentar abajo si su distro no tiene compat-5.1
-- original_LUA_PATH = LUA_PATH
-- intente solo compat-5.1.lua instalado con el paquete RRDtool
-- LUA_PATH = '/usr/local/rrdtool-1.3.2/lib/lua/5.0/?.lua'
-- aquí usamos una llamada protegida para requerir compat-5.1
local r = pcall(require, 'compat-5.1')
if not r then
  print('** no se pudo cargar compat-5.1.lua')
  os.exit(1)
end
-- descomentar abajo si su distro no tiene compat-5.1
-- LUA_PATH = original_LUA_PATH
-- original_LUA_PATH = nil
--- fin del código para requerir compat-5.1 ---------------------------
-- Si el módulo Lua RRDtool se instaló junto con RRDtool,
-- en /usr/local/rrdtool-1.3.2/lib/lua/5.0, package.cpath debe
-- configurarse adecuadamente para que 'require' pueda encontrar el módulo:
package.cpath = '/usr/local/rrdtool-1.3.2/lib/lua/5.0/?.so;' ..
                package.cpath
local rrd = require 'rrd'
rrd.update ("mydemo.rrd","N:12:13")

Si ejecutamos el programa anterior obtendremos:

$ lua t.lua
lua: t.lua:27: abriendo 'mydemo.rrd': No existe el archivo o el directorio
stack traceback:
      [C]: en función `update'
      t.lua:27: en función principal
      [C]: ?

Valores de retorno

Las funciones rrd.first, rrd.last, rrd.graph, rrd.info y rrd.fetch devuelven sus hallazgos.

rrd.first devuelve un único ENTERO que representa la marca de tiempo de la primera muestra de datos en un RRA dentro de un archivo RRD. Ejemplo que devuelve la primera marca de tiempo del tercer RRA (índice 2):

local firstdate = rrd.first('example.rrd', '--rraindex', 2)

rrd.last devuelve un único ENTERO que representa la última hora de actualización.

local lastupdate = rrd.last('example.rrd')

rrd.graph devuelve el tamaño x e y de la imagen creada y una tabla con los resultados de los argumentos PRINT.

local xsize, ysize, averages = rrd.graph ...
print(string.format("Tamaño de imagen: %dx%d", xsize, ysize)
print("Promedios: ", table.concat(averages, ', '))

rrd.info devuelve una tabla donde las claves y los valores representan nombres de propiedades y valores de propiedades del RRD.

local info = rrd.info("test.rrd")
for key, value in pairs(info) do
  print(key, ' = ', value)
end

rrd.graphv toma los mismos parámetros que rrd.graph pero devuelve solo una tabla. La tabla devuelta contiene metainformación sobre el gráfico, como su tamaño y la posición del área del gráfico en la imagen. Cuando se llama con un nombre de archivo vacío, el contenido del gráfico también se devolverá en la tabla (clave 'image').

rrd.updatev también devuelve una tabla. Las claves de la tabla son cadenas formadas por la concatenación de la marca de tiempo, el índice del RRA y el nombre de la fuente de datos para cada punto de datos consolidados (CDP) escrito en disco como resultado de la llamada de actualización actual. Los valores clave son valores CDP.

rrd.fetch es el más complejo del paquete en cuanto a valores de retorno. Devuelve 5 valores: la marca de tiempo inicial, el paso, dos arrays paralelos que contienen los nombres de las fuentes de datos y sus puntos de datos respectivamente, y la marca de tiempo final.

--requerir compat-5.1 si es necesario
package.cpath = '/usr/local/rrdtool-1.3.2/lib/lua/5.0/?.so;' ..
                package.cpath
local rrd = require "rrd"
local first, last = rrd.first("test.rrd"), rrd.last("test.rrd")
local start, step, names, data =
  rrd.fetch("test.rrd", "--start", first, "--end", last, "AVERAGE")
io.write(string.format("Inicio:       %s (%d)\n",
                       os.date("%c", start),start))
io.write("Tamaño del paso:   ", step, " segundos\n")
io.write("Nombres DS:    ", table.concat(names, ', '), "\n")
io.write("Puntos de datos: ", #data[1], "\n")
io.write("Datos:\n")
for i,dp in ipairs(data) do
  io.write(os.date("%t", start), " (", start, "): ")
  start = start + step
  for j,v in ipairs(dp) do
    io.write(v, " ")
  end
io.write("\n")
end
