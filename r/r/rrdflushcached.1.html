NOMBRE

rrdflushcached - Vacía los valores de un archivo RRD específico de la memoria.

SINOPSIS

rrdtool flushcached [--daemon|-d dirección] nombre_archivo [nombre_archivo ...]

DESCRIPCIÓN

La función flushcached se conecta a rrdcached, el demonio de caché de RRD, y emite un comando "flush" para los archivos dados. El demonio pondrá los archivos al principio de la cola de actualización para que se escriban "pronto". El estado solo se devolverá después de que las actualizaciones pendientes de los archivos se hayan escrito en el disco.

nombre_archivo
El(los) nombre(s) del(los) archivo(s) RRD que deben escribirse en el disco.
--daemon|-d dirección
Dirección del demonio rrdcached. Si no se especifica, la variable de entorno RRDCACHED_ADDRESS debe estar establecida (ver más abajo). Para obtener una lista de formatos aceptados, consulta la opción -l en el manual de rrdcached. 
rrdtool flushcached --daemon unix:/var/run/rrdcached.sock /var/lib/rrd/foo.rrd

VARIABLES DE ENTORNO

Las siguientes variables de entorno pueden ser utilizadas para cambiar el comportamiento de "rrdtool flushcached":

RRDCACHED_ADDRESS
Si esta variable de entorno está establecida, tendrá el mismo efecto que especificar la opción "--daemon" en la línea de comandos. Si ambos están presentes, el argumento de la línea de comandos tendrá prioridad.
