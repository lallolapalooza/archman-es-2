RRDRUBY(1) rrdtool RRDRUBY(1)

NOMBRE

rrdruby - Sobre los enlaces de RRD para Ruby

SINOPSIS

require "RRD"
RRD.create(
   rrd,
   "--step", "300",
   "DS:a:GAUGE:600:U:U",
   "DS:b:GAUGE:600:U:U",
   "RRA:AVERAGE:0.5:1:300")

DESCRIPCIÓN

Las funciones de rrdtool son directamente invocables a través del lenguaje de programación Ruby. Esta implementación de envoltura se ha escrito desde cero (sin SWIG).

La API simplemente espera parámetros de cadena a las funciones. Por favor, consulte la otra documentación de rrdtool para conocer las funciones y los argumentos válidos.

EJEMPLO

$: << '/path/to/rrdtool/lib/ruby/1.8/i386-linux'
require "RRD"
name = "test"
rrd = "#{name}.rrd"
start = Time.now.to_i
RRD.create(
   rrd,
   "--start", "#{start - 1}",
   "--step", "300",
       "DS:a:GAUGE:600:U:U",
   "DS:b:GAUGE:600:U:U",
   "RRA:AVERAGE:0.5:1:300")
puts
puts "actualizando #{rrd}"
start.to_i.step(start.to_i + 300 * 300, 300) { |i|
   RRD.update(rrd, "#{i}:#{rand(100)}:#{Math.sin(i / 800) * 50 + 50}")
}
puts
puts "obteniendo datos de #{rrd}"
(fstart, fend, data, step) = RRD.fetch(rrd, "--start", start.to_s, "--end",
     (start + 300 * 300).to_s, "AVERAGE")
puts "se obtuvieron #{data.length} puntos de datos desde #{fstart} hasta #{fend}"
puts
puts "generando gráfico #{name}.png"
RRD.graph(
  "#{name}.png",
   "--title", " Demo de RubyRRD",
   "--start", "#{start+3600}",
   "--end", "start + 1000 min",
   "--interlaced",
   "--imgformat", "PNG",
   "--width=450",
   "DEF:a=#{rrd}:a:AVERAGE",
   "DEF:b=#{rrd}:b:AVERAGE",
   "CDEF:line=TIME,2400,%,300,LT,a,UNKN,IF",
   "AREA:b#00b6e4:beta",
   "AREA:line#0022e9:alpha",
   "LINE3:line#ff0000")
puts

Si utiliza la opción de configuración --ruby-site-install, puede omitir la línea $: ya que el módulo RRDtool se encontrará automáticamente.

Si RRDtool encuentra problemas, lanzará una excepción que quizás desee capturar.

VER TAMBIÉN

rrdcreate, rrdupdate, rrdgraph, rrddump, rrdfetch, rrdtune, rrdlast, rrdxport, rrdinfo
