NOMBRE

rrdlist - Listar directorios y bases de datos rrd.

SINOPSIS

rrdtool list [--daemon|-d dirección] [--noflush|-F] [--recursive|-r] ruta

DESCRIPCIÓN

La función list proporciona una interfaz similar a 'ls' para recorrer y listar el árbol de bases de datos rrd.

Al usar la opción --daemon, la función list se conecta a rrdcached, el demonio de caché de RRD, y emite un comando "list" para la ruta dada.

ruta
La ruta (empezando con '/') donde '/' es el base_dir de rrdcached.
--daemon|-d dirección
Dirección del demonio rrdcached. Si no se especifica, la variable de entorno RRDCACHED_ADDRESS debe estar establecida (ver abajo). Para una lista de formatos aceptados, ver la opción -l en el manual de rrdcached. 
rrdtool list --daemon 127.0.0.1:42218 /cluster/nodes/node1
--noflush|-F
Al usar un demonio, "rrdtool list" normalmente vaciará su caché al disco antes de realizar operaciones. Esta opción deshabilita el vaciado de la caché.
--recursive|-r
Hace que la lista de bases de datos rrd sea recursiva.

VARIABLES DE ENTORNO

Las siguientes variables de entorno pueden ser usadas para cambiar el comportamiento de "rrdtool list":

RRDCACHED_ADDRESS
Si esta variable de entorno está configurada, tendrá el mismo efecto que especificar la opción "--daemon" en la línea de comandos. Si ambos están presentes, el argumento de la línea de comandos tendrá precedencia.
