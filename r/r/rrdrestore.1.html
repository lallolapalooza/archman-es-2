NOMBRE

rrdrestore - Restaura el contenido de un RRD desde su formato de volcado XML

SINOPSIS

rrdtool restore archivo.xml archivo.rrd [--range-check|-r] [--force-overwrite|-f]

DESCRIPCIÓN

La función restore lee la representación XML de un RRD y la convierte al formato nativo RRD.

archivo.xml
El nombre del archivo XML que desea restaurar. El nombre especial de archivo "-" (un guion solo) se interpreta como entrada estándar.

Para soportar el comando restore en modo de tubería (especialmente al usar RRDtool a través de una conexión de red), al usar "-" como nombre de archivo, el final del archivo puede ser señalado cerrando el canal de datos después de transferir el archivo (como ocurriría al usar redirección de entrada dentro de un shell adecuado) o enviando una combinación de control-Z / nueva línea. Esto permite enviar más comandos al servidor RRDtool después de una restauración.

archivo.rrd
El nombre del RRD a restaurar.
--range-check|-r
Asegura que los valores en las RRAs no excedan los límites definidos para las diversas fuentes de datos.
--force-overwrite|-f
Permite a RRDtool sobrescribir el RRD de destino.
