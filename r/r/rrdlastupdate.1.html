NOMBRE

rrdlastupdate - Devuelve la actualización más reciente de una RRD

SINOPSIS

rrdtool lastupdate nombre_archivo [--daemon|-d direccion]

DESCRIPCIÓN

La función lastupdate devuelve la marca de tiempo UNIX y el valor almacenado para cada dato en la actualización más reciente de una RRD.

nombre_archivo
El nombre de la RRD que contiene los datos.
--daemon|-d direccion
Dirección del demonio rrdcached. Si se especifica, se envía un comando "flush" al servidor antes de leer los archivos RRD. Esto permite a rrdtool devolver datos frescos incluso si el demonio está configurado para almacenar en caché valores durante mucho tiempo. Para ver una lista de formatos aceptados, consulte la opción -l en el manual de rrdcached. 
rrdtool lastupdate --daemon unix:/var/run/rrdcached.sock /var/lib/rrd/foo.rrd

VARIABLES DE ENTORNO

Las siguientes variables de entorno pueden usarse para cambiar el comportamiento de "rrdtool lastupdate":

RRDCACHED_ADDRESS
Si esta variable de entorno está configurada, tendrá el mismo efecto que especificar la opción "--daemon" en la línea de comandos. Si ambos están presentes, el argumento de la línea de comandos tendrá precedencia.
