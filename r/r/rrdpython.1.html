Paquete: rrdtool

Licencias: GPL-2.0-or-later

RRDPYTHON(1) rrdtool RRDPYTHON(1)

NOMBRE

rrdpython - Sobre los enlaces de RRD para Python

SINOPSIS

import rrdtool
rrdtool.create('/tmp/test.rrd', 'DS:foo:GAUGE:20:0:U')

DESCRIPCIÓN

Las funciones de rrdtool son directamente invocables a través del lenguaje de programación Python. Esta implementación de envoltura se ha escrito desde cero (sin SWIG).

La API espera cadenas de texto y/o una lista de cadenas de texto como parámetros para las funciones. Consulte la otra documentación de rrdtool para conocer las funciones y los argumentos válidos.

EJEMPLOS

Ejemplo 1

import sys
sys.path.append('/ruta/a/rrdtool/lib/python2.6/site-packages/')
import rrdtool, tempfile
DIA = 86400
AÑO = 365 * DIA
fd,path = tempfile.mkstemp('.png')
rrdtool.graph(path,
             '--imgformat', 'PNG',
             '--width', '540',
             '--height', '100',
             '--start', "-%i" % AÑO,
             '--end', "-1",
             '--vertical-label', 'Descargas/Día',
             '--title', 'Descargas anuales',
             '--lower-limit', '0',
             'DEF:downloads=downloads.rrd:downloads:AVERAGE',
             'AREA:downloads#990033:Descargas')
info = rrdtool.info('downloads.rrd')
print info['last_update']
print info['ds[downloads].minimal_heartbeat']

Ejemplo 2

import sys
sys.path.append('/ruta/a/rrdtool/lib/python2.6/site-packages/')
import rrdtool
# en la vida real, data_sources se poblaría en un bucle o algo similar
data_sources=[ 'DS:speed1:COUNTER:600:U:U',
               'DS:speed2:COUNTER:600:U:U',
               'DS:speed3:COUNTER:600:U:U' ]
rrdtool.create( 'speed.rrd',
                '--start', '920804400',
                data_sources,
                'RRA:AVERAGE:0.5:1:24',
                'RRA:AVERAGE:0.5:6:10' )

Si utiliza el objetivo de compilación site-python-install, puede omitir la primera línea `sys.path.append` ya que el módulo RRDtool estará disponible en todas partes.

Si RRDtool encuentra problemas, lanzará una excepción que quizás desee capturar.
