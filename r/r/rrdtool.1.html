NOMBRE

rrdtool - Herramienta Round Robin Database

SINOPSIS

rrdtool - [directorio_trabajo]| función

DESCRIPCIÓN

VISIÓN GENERAL

Es bastante fácil recopilar información de estado de todo tipo de cosas, desde la temperatura en tu oficina hasta el número de octetos que han pasado por la interfaz FDDI de tu router. Pero no es tan trivial almacenar estos datos de manera eficiente y sistemática. Aquí es donde RRDtool resulta útil. Te permite registrar y analizar los datos que recopilas de todo tipo de fuentes de datos (DS). La parte de análisis de datos de RRDtool se basa en la capacidad de generar rápidamente representaciones gráficas de los valores de datos recopilados durante un período de tiempo definible.

En esta página del manual encontrarás información general sobre el diseño y la funcionalidad de la Herramienta Round Robin Database (RRDtool). Para una descripción más detallada de cómo usar las funciones individuales de RRDtool, consulta la página del manual correspondiente.

Para una introducción al uso de RRDtool, asegúrate de consultar el rrdtutorial.

FUNCIONES

Mientras que las páginas del manual hablan de interruptores de línea de comandos que debes configurar para que RRDtool funcione, es importante tener en cuenta que RRDtool puede ser controlado de forma remota a través de un conjunto de tuberías. Esto ahorra una cantidad considerable de tiempo de inicio cuando planeas que RRDtool haga muchas cosas rápidamente. Consulta la sección sobre "CONTROL REMOTO" más abajo. También hay una serie de enlaces de idioma para RRDtool que le permiten usarlo directamente desde Perl, python, Tcl, PHP, etc.

create
Configura una nueva base de datos Round Robin (RRD). Consulta rrdcreate.
update
Almacena nuevos valores de datos en una RRD. Consulta rrdupdate.
updatev
Operativamente equivalente a update excepto por la salida. Consulta rrdupdate.
graph
Crea un gráfico a partir de datos almacenados en una o varias RRD. Aparte de generar gráficos, los datos también se pueden extraer a la salida estándar. Consulta rrdgraph.
graphv
Crea un gráfico a partir de datos almacenados en una o varias RRD. Igual que graph, pero los metadatos se imprimen antes del gráfico. Consulta rrdgraph.
dump
Vuelca el contenido de una RRD en texto plano ASCII. En conexión con restore, puedes usar esto para mover una RRD de una arquitectura de computadora a otra. Consulta rrddump.
restore
Restaura una RRD en formato XML a una RRD binaria. Consulta rrdrestore
fetch
Obtiene datos para un período de tiempo específico de una RRD. La función graph utiliza fetch para recuperar sus datos de una RRD. Consulta rrdfetch.
tune
Modifica la configuración y la estructura de una RRD. Consulta rrdtune.
first
Encuentra la primera hora de actualización de una RRD. Consulta rrdfirst.
last
Encuentra la última hora de actualización de una RRD. Consulta rrdlast.
lastupdate
Encuentra la última hora de actualización de una RRD. También devuelve el valor almacenado para cada dato en la última actualización. Consulta rrdlastupdate.
info
Obtiene información sobre una RRD. Consulta rrdinfo.
resize
Cambia el tamaño de las RRA individuales. ¡Esto es peligroso! Consulta rrdresize.
xport
Exporta datos recuperados de una o varias RRD. Consulta rrdxport.
flushcached
Vacía los valores de un archivo RRD específico de la memoria. Consulta rrdflushcached.
list
Lista los directorios y las bases de datos rrd de forma remota. Consulta rrdlist.

¿CÓMO FUNCIONA RRDTOOL?

Adquisición de Datos
Al monitorear el estado de un sistema, es conveniente tener los datos disponibles a un intervalo de tiempo constante. Desafortunadamente, es posible que no siempre puedas obtener los datos exactamente en el momento en que deseas. Por lo tanto, RRDtool te permite actualizar el archivo de registro en cualquier momento. Interpolará automáticamente el valor de la fuente de datos (DS) en la última ranura de tiempo oficial (intervalo) y escribirá este valor interpolado en el registro. El valor original que proporcionaste también se almacena y se tiene en cuenta al interpolar la próxima entrada del registro.
Consolidación
Puedes registrar datos a intervalos de 1 minuto, pero también podrías estar interesado en conocer el desarrollo de los datos durante el último año. Podrías hacer esto simplemente almacenando los datos en intervalos de 1 minuto durante todo el año. Si bien esto requeriría un espacio en disco considerable, también llevaría mucho tiempo analizar los datos cuando quisieras crear un gráfico que cubriera todo el año. RRDtool ofrece una solución a este problema a través de su función de consolidación de datos. Al configurar una base de datos Round Robin (RRD), puedes definir a qué intervalo debe ocurrir esta consolidación y qué función de consolidación (CF) (promedio, mínimo, máximo, último) debe usarse para construir los valores consolidados (ver rrdcreate). Puedes definir cualquier número de configuraciones de consolidación diferentes dentro de una misma RRD. Todas se mantendrán sobre la marcha cuando se carguen nuevos datos en la RRD.
Archivos Round Robin
Los valores de datos de la misma configuración de consolidación se almacenan en Archivos Round Robin (RRA). Esta es una manera muy eficiente de almacenar datos durante un cierto período de tiempo, utilizando una cantidad de espacio de almacenamiento conocida y constante.

Funciona así: si quieres almacenar 1000 valores en intervalos de 5 minutos, RRDtool asignará espacio para 1000 valores de datos y un área de encabezado. En el encabezado, almacenará un puntero que indica qué ranuras (valor) en el área de almacenamiento se escribieron por última vez. Los nuevos valores se escriben en el Archivo Round Robin de manera, lo adivinaste, round robin. Esto limita automáticamente el historial a los últimos 1000 valores (en nuestro ejemplo). Debido a que puedes definir varios RRA dentro de una sola RRD, puedes configurar otro, por ejemplo, para almacenar 750 valores de datos en intervalos de 2 horas, y así mantener un registro durante los últimos dos meses a una resolución más baja.

El uso de RRA garantiza que la RRD no crezca con el tiempo y que los datos antiguos se eliminen automáticamente. Al usar la función de consolidación, aún puedes conservar datos durante mucho tiempo, al tiempo que reduces gradualmente la resolución de los datos a lo largo del eje del tiempo.

El uso de diferentes funciones de consolidación (CF) te permite almacenar exactamente el tipo de información que realmente te interesa: el tráfico máximo de un minuto en la LAN, la temperatura mínima de tu bodega, ... etc.

Datos Desconocidos
Como se mencionó anteriormente, la RRD almacena datos a un intervalo constante. A veces puede suceder que no haya nuevos datos disponibles cuando se debe escribir un valor en la RRD. La adquisición de datos puede no ser posible por una u otra razón. Con RRDtool puedes manejar estas situaciones almacenando un valor de *DESCONOCIDO* en la base de datos. El valor '*DESCONOCIDO*' es compatible con todas las funciones de la herramienta. Al consolidar un conjunto de datos, se cuenta la cantidad de valores de datos *DESCONOCIDO* y cuando un nuevo valor consolidado está listo para ser escrito en su Archivo Round Robin (RRA), se realiza una verificación de validez para asegurarse de que el porcentaje de valores desconocidos en el punto de datos no supere un nivel configurable. Si no es así, se escribirá un valor *DESCONOCIDO* en la RRA.

NOMBRE

rrdtool - una colección de utilidades para archivar y mostrar datos de series de tiempo

SINOPSIS

rrdtool ...

DESCRIPCIÓN

RRDtool es una colección de utilidades para archivar y mostrar datos de series de tiempo. RRD significa Round Robin Database. Los datos se almacenan en archivos de base de datos de tamaño fijo, por lo que la cantidad de espacio en disco utilizado no crece con el tiempo. Esto se logra mediante el uso de varias "Resoluciones Agregadas" (RRAs). El RRA más rápido solo almacena los datos más recientes, mientras que el RRA más lento almacena promedios a más largo plazo de los datos más antiguos. Consulte la documentación de rrdcreate para obtener una descripción detallada de las RRAs.

Trazado con datos RRDS
El comando rrdgraph genera gráficos a partir de los datos de la base de datos RRD. Admite la definición de líneas, áreas, acumulaciones, gráficos de pila, imágenes en segundo plano, leyendas y marcas de agua. Se pueden utilizar varios tipos de fuente de datos, como la consolidación, la promoción y el cálculo de proporciones, para generar los datos que se van a trazar. El tamaño, el color y el contenido del gráfico se pueden definir libremente. Consulte rrdgraph para obtener más información sobre esto.
Comportamiento Anómalo
de Jake Brutlag

RRDtool proporciona los componentes básicos para la detección de comportamiento anómalo en tiempo casi real. Estos componentes incluyen:

  • Un algoritmo para predecir el valor de una serie de tiempo un paso de tiempo en el futuro.
  • Una medida de la desviación entre los valores predichos y observados.
  • Un mecanismo para decidir si y cuándo un valor observado o una secuencia de valores observados es demasiado desviado del valor(es) predicho(s).

Aquí hay una breve explicación de estos componentes:

El algoritmo de pronóstico de series de tiempo Holt-Winters es un algoritmo en línea (o incremental) que predice adaptativamente las observaciones futuras en una serie de tiempo. Su pronóstico es la suma de tres componentes: una línea de base (o intercepto), una tendencia lineal en el tiempo (o pendiente) y un coeficiente estacional (un efecto periódico, como un ciclo diario). Hay un coeficiente estacional para cada punto de tiempo en el período (ciclo). Después de que se observa un valor, cada uno de estos componentes se actualiza mediante suavizado exponencial. Esto significa que el algoritmo "aprende" de los valores pasados y los utiliza para predecir el futuro. La tasa de adaptación está gobernada por 3 parámetros, alpha (intercepto), beta (pendiente) y gamma (estacional). La predicción también puede verse como un valor suavizado para la serie de tiempo.

La medida de la desviación es una desviación absoluta ponderada estacional. El término estacional significa que la desviación se mide por separado para cada punto de tiempo en el ciclo estacional. Al igual que con el pronóstico de Holt-Winters, la desviación se predice utilizando la medida calculada a partir de valores pasados (pero solo en ese punto del ciclo estacional). Después de que se observa el valor, el algoritmo aprende del valor observado mediante suavizado exponencial. Las bandas de confianza para la serie de tiempo observada se generan escalando la secuencia de valores de desviación predichos (generalmente pensamos en la secuencia como una línea continua en lugar de un conjunto de puntos discretos).

Se informa un comportamiento anómalo (un posible fallo) siempre que el número de veces que el valor observado viola las bandas de confianza alcanza o excede un umbral especificado dentro de una ventana temporal especificada (por ejemplo, 5 violaciones durante los últimos 45 minutos con un valor observado cada 5 minutos).

Esta funcionalidad está integrada en un conjunto de RRAS relacionados. En particular, un RRA FAILURES registra posibles fallos. Con estos datos, podría, por ejemplo, utilizar una aplicación de front-end para RRDtool para iniciar alertas en tiempo real.

Para una descripción detallada sobre cómo configurar esto, consulte rrdcreate.

CONTROL REMOTO

Cuando inicia RRDtool con la opción de línea de comandos '-' espera entrada a través de la entrada estándar (STDIN). Con esta función, puede mejorar el rendimiento conectando RRDtool a otro proceso (MRTG es un ejemplo) a través de un conjunto de tuberías. A través de estas tuberías RRDtool acepta los mismos argumentos que en la línea de comandos y algunos comandos especiales como cd, mkdir, pwd, ls y quit. Para obtener ayuda detallada sobre los comandos del servidor, escriba:

rrdtool help cd

Cuando se completa un comando, RRDtool imprimirá la cadena '"OK"', seguida de información de tiempo de la forma u:tiempousuario s:tiemposistemar:tiemporunning. Los valores tiempousuario y tiemposistema son los totales acumulados de segundos desde que se inició RRDtool. tiemporunning es la cantidad total de segundos que RRDtool ha estado ejecutándose. Si ocurre un error, se imprimirá una línea de la forma '"ERROR:" Descripción del error'. RRDtool no abortará, a menos que suceda algo realmente grave. Si se especifica un workdir y el UID es 0, RRDtool hará un chroot a ese workdir. Si el UID no es 0, RRDtool solo cambia el directorio actual a workdir.

Servidor RRD

Si desea crear un Servidor RRD, debe elegir un número de Servicio TCP/IP y agregarlo a /etc/services de esta manera:

rrdsrv      13900/tcp                       # Servidor RRD

Atención: el puerto TCP 13900 no está registrado oficialmente para rrdsrv. Puede usar cualquier puerto no utilizado en su archivo de servicios, pero el servidor y el sistema cliente deben usar el mismo puerto, por supuesto.

Con esta configuración, puede agregar RRDtool como metaserver a /etc/inetd.conf. Por ejemplo:

rrdsrv stream tcp nowait root /opt/rrd/bin/rrdtool rrdtool - /var/rrd

No olvide crear el directorio de bases de datos /var/rrd y reinicializar su inetd.

Si todo se configuró correctamente, puede acceder al servidor con sockets Perl, herramientas como netcat, o en una prueba interactiva rápida usando 'telnet localhost rrdsrv'.

NOTA: ¡no hay autenticación con esta función! No configure dicho puerto a menos que esté seguro de lo que está haciendo.

VARIABLES DE ENTORNO

Las siguientes variables de entorno pueden usarse para cambiar el comportamiento de la mayoría de las utilidades.

RRD_LOCKING
Si esta variable de entorno está configurada, el archivo RRD se bloquea en el modo dado:
  • try falla, cuando el archivo está bloqueado por otro proceso. Este es el comportamiento predeterminado.
  • block espera hasta que se libere el bloqueo.
  • none omite el bloqueo por completo. El llamador debe garantizar un bloqueo adecuado que sea compatible con "fcntl(fd, F_SETLK, ...)".

Algunas utilidades tienen opciones de línea de comandos (--locking) que anulan esta variable.

RRDCACHED, EL DEMONIO DE CACHÉ

Para configuraciones muy grandes, actualizar miles de archivos RRD a menudo se convierte en un problema serio de E/S. Si encuentra tales problemas, es posible que desee echar un vistazo a rrdcached, un demonio de caché para RRDtool que puede ayudarlo a reducir la carga en sus discos.
