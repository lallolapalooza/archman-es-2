rrsync(1) Comandos de usuario rrsync(1)

NOMBRE

rrsync - un script para configurar usuarios de rsync restringidos a través de inicios de sesión de ssh

SINOPSIS

rrsync [-ro|-wo] [-munge] [-no-del] [-no-lock] [-no-overwrite]  DIR

El único argumento que no es una opción especifica el DIR restringido a utilizar. Puede ser relativo al directorio de inicio del usuario o una ruta absoluta.

La versión en línea de esta página del manual (que incluye enlaces cruzados entre temas) está disponible en https://download.samba.org/pub/rsync/rrsync.1.

DESCRIPCIÓN

El inicio de sesión ssh de un usuario puede restringirse para permitir solo la ejecución de una transferencia rsync de dos maneras sencillas:

o
forzar la ejecución del script rrsync
o
forzar la ejecución de un comando rsync daemon-over-ssh.

Ambas configuraciones utilizan una característica de ssh que permite forzar la ejecución de un comando en lugar de un shell interactivo. Sin embargo, si el shell de inicio del usuario es bash, consulte PROBLEMA DE SEGURIDAD CON BASH para un problema potencial.

Para usar el script rrsync, edite el archivo ~/.ssh/authorized_keys del usuario y agregue un prefijo como uno de los siguientes (seguido de un espacio) delante de cada línea de clave ssh que deba restringirse:

command="rrsync DIR"
command="rrsync -ro DIR"
command="rrsync -munge -no-del DIR"

Luego, asegúrese de que el script rrsync tenga las restricciones de opción deseadas. Es posible que desee copiar el script a un directorio bin local con un nombre único si desea tener múltiples configuraciones. Se puede especificar una o más opciones de rrsync antes del DIR si desea restringir aún más la transferencia.

Para usar una configuración de rsync daemon, edite el archivo ~/.ssh/authorized_keys del usuario y agregue un prefijo como uno de los siguientes (seguido de un espacio) delante de cada línea de clave ssh que deba restringirse:

command="rsync --server --daemon ."
command="rsync --server --daemon --config=/PATH/TO/rsyncd.conf ."

Luego, asegúrese de que el archivo rsyncd.conf se cree con uno o más nombres de módulo con la ruta y las restricciones de opción apropiadas. Si se omite la opción --config de rsync, se utiliza ~/rsyncd.conf por defecto. Consulte la página del manual de rsyncd.conf(5) para obtener detalles sobre cómo configurar un rsync daemon.

Al usar rrsync, solo puede haber un directorio restringido por clave autorizada. Una configuración de daemon, por otro lado, permite varios nombres de módulo dentro del archivo de configuración, cada uno con su propia configuración de ruta.

El resto de esta página del manual se dedica a usar el script rrsync.

OPCIONES

-ro
Permite solo leer desde DIR. Implica -no-del y -no-lock.
-wo
Permite solo escribir en DIR.
-munge
Habilita --munge-links de rsync en el lado del servidor.
-no-del
Deshabilita las opciones --delete* y --remove* de rsync.
-no-lock
Evita la verificación de bloqueo de ejecución única (por usuario). Útil con -munge.
-no-overwrite
Impone --ignore-existing en el servidor. Evita sobrescribir archivos existentes cuando el servidor es el receptor.
-help, -h
Muestra este mensaje de ayuda y sale.

RESTRICCIONES DE SEGURIDAD

El script rrsync valida los argumentos de ruta que recibe para intentar restringirlos a permanecer dentro del DIR especificado.

El script rrsync rechaza la opción --copy-links de rsync (por defecto) para que una copia no pueda desreferenciar un enlace simbólico dentro del DIR para llegar a un archivo fuera del DIR.

El script rrsync rechaza la opción --protect-args (-s) de rsync porque permitiría enviar opciones al servidor que el script no puede verificar. Si desea admitir --protect-args, utilice una configuración de daemon-over-ssh.

El script rrsync acepta solo un subconjunto de las opciones de rsync que utiliza el rsync real al ejecutar el comando del servidor. También se incluyen algunas opciones de conveniencia adicionales para ayudarlo a interactuar con BackupPC y aceptar algunas anulaciones convenientes por parte del usuario.

El script (o una copia del mismo) se puede editar manualmente si desea personalizar el manejo de opciones.

PROBLEMA DE SEGURIDAD CON BASH

Si los usuarios tienen bash configurado como su shell de inicio, bash puede intentar ser demasiado útil y asegurarse de que los archivos bashrc de inicio del usuario se ejecuten antes de ejecutar el comando forzado. Esto puede ser un problema si el usuario puede actualizar de alguna manera sus archivos bashrc de inicio, quizás a través de la copia restringida, un directorio de inicio compartido o algo similar.

Una forma sencilla de evitar el problema es cambiar el shell del usuario a uno más simple, como dash. Al elegir el nuevo shell de inicio, asegúrese de no elegir bash disfrazado, ya que no está claro si evita el problema de seguridad.

Otra posible solución es asegurarse de que el directorio de inicio del usuario no sea un montaje compartido y que no tengan forma de copiar archivos fuera de sus directorios restringidos. Esto puede requerir que fuerce la habilitación de la manipulación de enlaces simbólicos en el lado del servidor.

Una futura versión de openssh puede tener un cambio en el manejo de comandos forzados que le permita evitar usar el shell de inicio del usuario.

EJEMPLOS

El archivo ~/.ssh/authorized_keys podría tener líneas como esta:

command="rrsync client/logs" ssh-rsa AAAAB3NzaC1yc2EAAAABIwAAAIEAzG...
command="rrsync -ro results" ssh-rsa AAAAB3NzaC1yc2EAAAABIwAAAIEAmk...

rrsync - un espejo de copia de seguridad para rsync

NOMBRE

rrsync - un espejo de copia de seguridad para rsync

SINOPSIS

rrsync [OPCIÓN...] ORIGEN DESTINO

DESCRIPCIÓN

rrsync es un script de shell que proporciona una interfaz sencilla para realizar copias de seguridad de directorios utilizando rsync.

Está diseñado para ser fácil de usar y seguro, ya que solo permite la sincronización unidireccional y evita la eliminación accidental de archivos.

OPCIONES

Este script no acepta opciones de línea de comandos específicas, ya que la configuración se realiza a través del archivo de configuración.

RESTRICCIONES DE SEGURIDAD

rrsync aplica varias restricciones de seguridad para proteger tus datos:

  • Solo permite la sincronización unidireccional (de origen a destino).
  • Evita la eliminación de archivos en el destino a menos que se especifique explícitamente en el archivo de configuración.
  • Utiliza el modo de solo lista de rsync para verificar los cambios antes de realizar la copia.

PROBLEMA DE SEGURIDAD DE BASH

Ten en cuenta que si utilizas un sistema con una versión vulnerable de Bash, podrías estar expuesto a problemas de seguridad. Asegúrate de que tu sistema Bash esté actualizado.

EJEMPLOS

Para realizar una copia de seguridad del directorio /home/usuario/documentos a un disco externo montado en /mnt/backup, asegúrate de que tu archivo de configuración (por ejemplo, ~/.rrsync.conf) esté configurado correctamente y luego ejecuta:

rrsync /home/usuario/documentos /mnt/backup/documentos_backup

ARCHIVOS

  • ~/.rrsync.conf: Archivo de configuración de rrsync.
