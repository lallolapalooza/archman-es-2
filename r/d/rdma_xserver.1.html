NOMBRE

rdma_xserver - Programa de prueba de comunicación RDMA CM

SINOPSIS

rdma_xserver [-p puerto] [-c tipo_comunicacion]

DESCRIPCIÓN

Utiliza librdmacm para establecer diversas formas de comunicación e intercambiar datos.

OPCIONES

-p puerto
Cambia el número de puerto en el que el servidor escucha. Por defecto, el servidor escucha en el puerto 7471.
-c tipo_comunicacion
Especifica el tipo de comunicación establecida con el programa cliente. 'r' resulta en el uso de una QP conectada fiable (el valor por defecto). 'x' utiliza QPs XRC conectadas fiables extendidas.

NOTAS

El uso básico es iniciar rdma_xserver y luego conectarse al servidor usando el programa rdma_xclient.

Dado que esta prueba mapea recursos RDMA al espacio de usuario, los usuarios deben asegurarse de que tienen recursos y permisos del sistema disponibles. Consulte el archivo README de libibverbs para obtener información adicional.

VER TAMBIÉN

rdma_cm(7), udaddy(1), mckey(1), rping(1), rdma_server(1), rdma_xclient(1)
