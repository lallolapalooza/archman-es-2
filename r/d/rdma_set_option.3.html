RDMA_SET_OPTION(3) Manual del programador de Librdmacm RDMA_SET_OPTION(3)

NOMBRE

rdma_set_option - Establece opciones de comunicación para un rdma_cm_id.

SINOPSIS

#include <rdma/rdma_cma.h>

int rdma_set_option (struct rdma_cm_id *id, int level, int optname, void *optval, size_t optlen);

ARGUMENTOS

id
Identificador RDMA.
level
Nivel de protocolo de la opción a establecer.
optname
Nombre de la opción, relativo al nivel, a establecer.
optval
Referencia a los datos de la opción. Los datos dependen del nivel y optname.
optlen
El tamaño del búfer de %optval.

DESCRIPCIÓN

Establece opciones de comunicación para un rdma_cm_id. Esta llamada se utiliza para anular la configuración predeterminada del sistema.

optname puede ser uno de
RDMA_OPTION_ID_TOS
Especifica la calidad del servicio proporcionada por una conexión. El optlen esperado es el tamaño de uint8_t.
RDMA_OPTION_ID_REUSEADDR
Vincula el rdma_cm_id a una dirección reutilizable. Esto permitirá que otros usuarios se vinculen a la misma dirección. El optlen esperado es el tamaño de int.
RDMA_OPTION_ID_AFONLY
Establece el socket IPV6_V6ONLY. El optlen esperado es el tamaño de int.
RDMA_OPTION_IB_PATH
Establece los datos del registro de ruta IB. El optlen esperado es el tamaño de struct ibv_path_data[].
RDMA_OPTION_ID_ACK_TIMEOUT
Establece el tiempo de espera de confirmación de QP. El valor se calcula según la fórmula 4.096 * 2^(ack_timeout) usec.

VALOR DE RETORNO

Devuelve 0 en caso de éxito, o -1 en caso de error. Si ocurre un error, errno se establecerá para indicar la razón del fallo.

NOTAS

Los detalles de las opciones se pueden encontrar en los archivos de cabecera relevantes.
