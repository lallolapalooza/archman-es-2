rdiff(1)

Paquete: librsync

Licencias: LGPL

rdiff(1) Manual de comandos generales rdiff(1)

NOMBRE

rdiff - calcula y aplica diferencias de archivos basadas en firmas

SINOPSIS

rdiff [opciones] signature archivo-antiguo archivo-firma
rdiff [opciones] delta archivo-firma archivo-nuevo archivo-delta
rdiff [opciones] patch archivo-antiguo archivo-delta archivo-nuevo

USO

Puedes usar rdiff para actualizar archivos, muy parecido a como lo hace rsync. Sin embargo, a diferencia de rsync, rdiff te da el control. Hay tres pasos para actualizar un archivo: signature, delta y patch. Usa el subcomando signature para generar un pequeño archivo-firma a partir del archivo-antiguo. Usa el subcomando delta para generar un pequeño archivo-delta a partir del archivo-firma y el archivo-nuevo. Usa el subcomando patch para aplicar el archivo-delta al archivo-antiguo para regenerar el archivo-nuevo.

DESCRIPCIÓN

En todos los casos en que se deba especificar un nombre de archivo, se puede usar - en su lugar para indicar la entrada estándar o la salida estándar, según corresponda. Ten en cuenta que si haces esto, necesitarás terminar tus opciones con -- o rdiff pensará que le estás pasando una opción vacía.

VALOR DE RETORNO

0 para una finalización exitosa, 1 para problemas ambientales (archivo no encontrado, opciones inválidas, error de E/S, etc.), 2 para un archivo corrupto y 3 para un error interno o una situación no manejada en librsync o rdiff.
