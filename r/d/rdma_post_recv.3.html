NOMBRE

rdma_post_recv - publicar una solicitud de trabajo para recibir un mensaje entrante.

SINOPSIS

#include <rdma/rdma_verbs.h>

int rdma_post_recv (struct rdma_cm_id *id, void *context, void *addr, size_t length, struct ibv_mr *mr);

ARGUMENTOS

id
Una referencia a un identificador de comunicación donde se publicará el buffer del mensaje.
context
Contexto definido por el usuario asociado con la solicitud.
addr
La dirección del buffer de memoria a publicar.
length
La longitud del buffer de memoria.
mr
Una región de memoria registrada asociada con el buffer publicado.

DESCRIPCIÓN

Publica una solicitud de trabajo en la cola de recepción del par de colas asociado con el rdma_cm_id. El buffer publicado se pondrá en cola para recibir un mensaje entrante enviado por el par remoto.

VALOR DEVUELTO

Devuelve 0 en caso de éxito, o -1 en caso de error. Si ocurre un error, errno se establecerá para indicar la razón de la falla.

NOTAS

El usuario es responsable de asegurar que se publique un buffer de recepción y que sea lo suficientemente grande como para contener todos los datos enviados antes de que el par publique el mensaje de envío correspondiente. El buffer del mensaje debe haber sido registrado antes de ser publicado, con el parámetro mr haciendo referencia al registro. El buffer debe permanecer registrado hasta que se complete la recepción.

Los mensajes pueden publicarse en un rdma_cm_id solo después de que se haya asociado un par de colas con él. Un par de colas se vincula a un rdma_cm_id después de llamar a rdma_create_ep o rdma_create_qp, si el rdma_cm_id se asigna utilizando rdma_create_id.

El contexto definido por el usuario asociado con la solicitud de recepción se devolverá al usuario a través del campo wr_id, identificador de la solicitud de trabajo, de la finalización del trabajo.
