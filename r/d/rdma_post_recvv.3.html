NOMBRE

rdma_post_recvv - publicar una solicitud de trabajo para recibir mensajes entrantes.

SINOPSIS

#include <rdma/rdma_verbs.h>

int rdma_post_recvv (struct rdma_cm_id *id, void *context, struct ibv_sge *sgl, int nsge);

ARGUMENTOS

id
Una referencia a un identificador de comunicación donde se publicarán los búferes de mensaje.
context
Contexto definido por el usuario asociado con la solicitud.
sgl
Una lista de dispersión-recolección de búferes de memoria publicados como una sola solicitud.
nsge
El número de entradas de dispersión-recolección en el array sgl.

DESCRIPCIÓN

Publica una única solicitud de trabajo en la cola de recepción del par de colas asociado con el rdma_cm_id. Los búferes publicados se pondrán en cola para recibir un mensaje entrante enviado por el par remoto.

VALOR DE RETORNO

Devuelve 0 en caso de éxito, o -1 en caso de error. Si ocurre un error, errno se establecerá para indicar la razón de la falla.

NOTAS

El usuario es responsable de garantizar que la recepción se publique y que el espacio total del búfer sea lo suficientemente grande para contener todos los datos enviados antes de que el par publique el mensaje de envío correspondiente. Los búferes de mensaje deben haberse registrado antes de publicarse, y los búferes deben permanecer registrados hasta que la recepción se complete.

Los mensajes se pueden publicar en un rdma_cm_id solo después de que se haya asociado un par de colas con él. Un par de colas está vinculado a un rdma_cm_id después de llamar a rdma_create_ep o rdma_create_qp, si el rdma_cm_id se asigna utilizando rdma_create_id.

El contexto definido por el usuario asociado con la solicitud de recepción se devolverá al usuario a través del campo wr_id, identificador de solicitud de trabajo, de la finalización del trabajo.
