RDMA_DESTROY_ID(3) Manual del programador de Librdmacm RDMA_DESTROY_ID(3)

NOMBRE

rdma_destroy_id - Libera un identificador de comunicación.

SINOPSIS

#include <rdma/rdma_cma.h>

int rdma_destroy_id (struct rdma_cm_id *id);

ARGUMENTOS

id
El identificador de comunicación a destruir.

DESCRIPCIÓN

Destruye el rdma_cm_id especificado y cancela cualquier operación asíncrona pendiente.

VALOR DE RETORNO

Devuelve 0 en caso de éxito, o -1 en caso de error. Si ocurre un error, errno se establecerá para indicar el motivo del fallo.

NOTAS

Los usuarios deben liberar cualquier QP asociado con el rdma_cm_id antes de llamar a esta rutina y confirmar todos los eventos relacionados.

VER TAMBIÉN

rdma_create_id(3), rdma_destroy_qp(3), rdma_ack_cm_event(3)
