RDMA_POST_WRITE(3) Manual del programador de Librdmacm RDMA_POST_WRITE(3)

NOMBRE

rdma_post_write - publicar una solicitud de trabajo de escritura RDMA.

SINOPSIS

#include <rdma/rdma_verbs.h>

int rdma_post_write (struct rdma_cm_id *id, void *context, void *addr, size_t length, struct *mr, int flags, uint64_t remote_addr, uint32_t rkey);

ARGUMENTOS

id
Una referencia a un identificador de comunicación donde se publicará la solicitud.
context
Contexto definido por el usuario asociado con la solicitud.
addr
La dirección local de la fuente de la solicitud de escritura.
length
La longitud de la operación de escritura.
mr
Región de memoria opcional asociada con el búfer local.
flags
Marcas opcionales utilizadas para controlar la operación de escritura.
remote_addr
La dirección de la memoria registrada remota en la que escribir.
rkey
La clave de memoria registrada asociada con la dirección remota.

DESCRIPCIÓN

Publica una solicitud de trabajo en la cola de envío del par de colas asociado con el rdma_cm_id. Los contenidos del búfer de datos local se escribirán en la región de memoria remota.

VALOR DE RETORNO

Devuelve 0 si tiene éxito, o -1 si ocurre un error. Si ocurre un error, se establecerá errno para indicar la razón de la falla.

NOTAS

Para obtener una lista de las marcas admitidas, consulte ibv_post_send. A menos que se especifiquen datos en línea, el búfer de datos local debe haber sido registrado antes de emitir la escritura, y el búfer debe permanecer registrado hasta que la escritura se complete. El búfer remoto siempre debe estar registrado.

Las operaciones de escritura no se pueden publicar en un rdma_cm_id o en el par de colas correspondiente hasta que se haya conectado.

El contexto definido por el usuario asociado con la solicitud de escritura se devolverá al usuario a través del campo wr_id, identificador de solicitud de trabajo, de la finalización del trabajo.

VER TAMBIÉN
