NOMBRE

rdma_ack_cm_event - Liberar un evento de comunicación.

SINOPSIS

#include <rdma/rdma_cma.h>

int rdma_ack_cm_event (struct rdma_cm_event *event);

ARGUMENTOS

event
Evento a liberar.

DESCRIPCIÓN

Todos los eventos que son asignados por rdma_get_cm_event deben ser liberados; debe haber una correspondencia uno a uno entre las llamadas exitosas a get y a ack. Esta llamada libera la estructura del evento y cualquier memoria a la que haga referencia.

VALOR DE RETORNO

Devuelve 0 si tiene éxito, o -1 si hay un error. Si ocurre un error, errno se establecerá para indicar el motivo del fallo.

VER TAMBIÉN

rdma_get_cm_event(3), rdma_destroy_id(3)
