RDMA_REG_WRITE(3) Manual del programador de Librdmacm RDMA_REG_WRITE(3)

NOMBRE

rdma_reg_write - registra(n) el(los) buffer(s) de datos para acceso de escritura RDMA remota.

SINOPSIS

#include <rdma/rdma_verbs.h>

struct ibv_mr * rdma_reg_write (struct rdma_cm_id *id, void *addr, size_t length);

ARGUMENTOS

id
Una referencia a un identificador de comunicación donde se utilizará(n) el(los) buffer(s) de mensaje.
addr
La dirección del(los) buffer(s) de memoria a registrar.
length
La longitud total de la memoria a registrar.

DESCRIPCIÓN

Registra un buffer de memoria que será accedido por una operación de escritura RDMA remota. Los buffers de memoria registrados usando rdma_reg_write pueden ser el objetivo en una solicitud de escritura RDMA, permitiendo que el buffer se especifique en el lado remoto de una conexión RDMA como el remote_addr de rdma_post_write, o una llamada similar.

VALOR DE RETORNO

Devuelve una referencia a la región de memoria registrada en caso de éxito, o NULL en caso de error. Si ocurre un error, errno se establecerá para indicar la razón de la falla.

NOTAS

rdma_reg_write se utiliza para registrar un buffer de datos que será el objetivo de una operación de escritura RDMA en un par de colas asociado con un rdma_cm_id. El buffer de memoria se registra con el dominio de protección asociado con el identificador. El inicio del buffer de datos se especifica a través del parámetro addr, y el tamaño total del buffer se da por length.

Todos los buffers de datos deben registrarse antes de ser publicados como una solicitud de trabajo. Los usuarios deben anular el registro de toda la memoria registrada llamando a rdma_dereg_mr.
