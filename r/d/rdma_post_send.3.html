RDMA_POST_SEND(3) Manual del programador de Librdmacm RDMA_POST_SEND(3)

NOMBRE

rdma_post_send - publicar una solicitud de trabajo para enviar un mensaje.

SINOPSIS

#include <rdma/rdma_verbs.h>

int rdma_post_send (struct rdma_cm_id *id, void *context, void *addr, size_t length, struct ibv_mr *mr, int flags);

ARGUMENTOS

id
Una referencia a un identificador de comunicación donde se publicará el buffer del mensaje.
context
Contexto definido por el usuario asociado a la solicitud.
addr
La dirección del buffer de memoria a publicar.
length
La longitud del buffer de memoria.
mr
Región de memoria registrada opcional asociada al buffer publicado.
flags
Flags opcionales utilizados para controlar la operación de envío.

DESCRIPCIÓN

Publica una solicitud de trabajo en la cola de envío del par de colas asociado con el rdma_cm_id. El contenido del buffer publicado se enviará al par remoto de una conexión.

VALOR DE RETORNO

Devuelve 0 en caso de éxito, o -1 en caso de error. Si ocurre un error, se establecerá errno para indicar la razón de la falla.

NOTAS

El usuario es responsable de asegurarse de que el par remoto ha enqueued una solicitud de recepción antes de emitir las operaciones de envío. Para una lista de flags compatibles, consulte ibv_post_send. A menos que la solicitud de envío esté utilizando datos en línea, el buffer del mensaje debe haber sido registrado antes de ser publicado, con el parámetro mr haciendo referencia al registro. El buffer debe permanecer registrado hasta que el envío se complete.

Las operaciones de envío no se pueden publicar en un rdma_cm_id o en el par de colas correspondiente hasta que se haya conectado.

El contexto definido por el usuario asociado a la solicitud de envío se devolverá al usuario a través del campo wr_id, identificador de la solicitud de trabajo, de la finalización del trabajo.

VER TAMBIÉN
