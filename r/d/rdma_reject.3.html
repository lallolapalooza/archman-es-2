RDMA_REJECT(3) Manual del programador de Librdmacm RDMA_REJECT(3)

NOMBRE

rdma_reject - Se llama para rechazar una solicitud de conexión.

SINOPSIS

#include <rdma/rdma_cma.h>

int rdma_reject (struct rdma_cm_id *id, const void *private_data, uint8_t private_data_len);

ARGUMENTOS

id
Identificador de conexión asociado con la solicitud.
private_data
Datos privados opcionales para enviar con el mensaje de rechazo.
private_data_len
Especifica el tamaño del búfer de datos controlado por el usuario. Tenga en cuenta que la cantidad real de datos transferidos al lado remoto depende del transporte y puede ser mayor que la solicitada.

DESCRIPCIÓN

Se llama desde el lado que escucha para rechazar una solicitud de conexión o de búsqueda de servicio de datagramas.

VALOR DE RETORNO

Devuelve 0 si tiene éxito, o -1 si ocurre un error. Si ocurre un error, la variable `errno` se establecerá para indicar el motivo de la falla.

NOTAS

Después de recibir un evento de solicitud de conexión, un usuario puede llamar a `rdma_reject` para rechazar la solicitud. Si el transporte RDMA subyacente admite datos privados en el mensaje de rechazo, los datos especificados se pasarán al lado remoto.

VER TAMBIÉN

rdma_listen(3), rdma_accept(3), rdma_get_cm_event(3)
