NOMBRE

rd-bomb - texturas de reacción/difusión

SINOPSIS

rd-bomb [--display host:display.screen] [--foreground color] [--background color] [--window] [--root] [--window-id número][--install] [--visual visual] [--width n] [--height n] [--reaction n] [--diffusion n] [--size f] [--speed f] [--delay millisegundos] [--fps]

DESCRIPCIÓN

El programa rd-bomb dibuja texturas de reacción/difusión.

OPCIONES

Si una de las opciones de reacción, difusión, radio y paleta se establece a un valor negativo, esa opción se establecerá a un valor adecuado aleatorio.

Asegúrate de probar "-speed 1 -size 0.1 -epoch 3000".

rd-bomb acepta las siguientes opciones:

--window
Dibuja en una ventana recién creada. Esta es la opción por defecto.
--root
Dibuja en la ventana raíz.
--window-id número
Dibuja en la ventana especificada.
--install
Instala un mapa de colores privado para la ventana.
--visual visual
Especifica qué visual usar. Los valores legales son el nombre de una clase visual, o el número de ID (decimal o hexadecimal) de un visual específico.
--width n
--height n
Especifica el tamaño de la baldosa, en píxeles.
--reaction n
--diffusion n
Estas son constantes en las ecuaciones que afectan su naturaleza visual. Cada una puede ser 0, 1 o 2. El valor por defecto es -1: estas constantes se eligen aleatoriamente.
--radius n
Tamaño de la semilla.
--size f
Qué fracción de la ventana se dibuja activamente, un número de punto flotante entre 0 (exclusivo) y 1 (inclusivo). El valor por defecto es 1.0.
--speed f
Cuando una fracción de la pantalla está activa, el área activa se mueve a esta velocidad (un número de punto flotante). El valor por defecto es cero. Valor sugerido: 1.0.
--delay millisegundos
Cuántos milisegundos esperar entre fotogramas; el valor por defecto es 1, o aproximadamente 1/1000 de segundo.
--fps
Muestra la velocidad de fotogramas actual y la carga de la CPU.

HISTORIA

El código se deriva del modo 'd' del instrumento musical visual "Bomb", también de Scott Draves. Las ecuaciones provienen de Xmorphia, que se basa en una versión del modelo Gray-Scott tomada de:

John E. Pearson "Complex Patterns in a Simple System"
Science, 261,189, 9 de julio de 1993.

ENTORNO

DISPLAY
para obtener el host y el número de pantalla por defecto.
XENVIRONMENT
para obtener el nombre de un archivo de recursos que anula los recursos globales almacenados en la propiedad RESOURCE_MANAGER.
XSCREENSAVER_WINDOW
El ID de la ventana a usar con --root.
