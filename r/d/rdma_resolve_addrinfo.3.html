RDMA_RESOLVE_ADDRINFO(3) Manual del programador de Librdmacm RDMA_RESOLVE_ADDRINFO(3)

Nombre

RDMA_RESOLVE_ADDRINFO - Resuelve direcciones RDMA que soportan tanto DNS como IB SA.

Sinopsis

#include <rdma/rdma_cma.h>

int rdma_resolve_addrinfo(struct rdma_cm_id *id, const char *node, const char *service, const struct rdma_addrinfo *hints);

Argumentos

id Identificador RDMA.

node Opcional, nombre, IPv4 de punto decimal, o dirección hexadecimal IPv6 a resolver.

service El nombre del servicio o número de puerto de la dirección.

hints Referencia a una estructura rdma_addrinfo que contiene indicaciones sobre el tipo de servicio que soporta el llamador.

Descripción

Esta llamada envía una solicitud de resolución de direcciones asíncrona. El comportamiento es similar a rdma_getaddrinfo(), excepto que la operación es asíncrona, generando un evento en el canal de eventos de RDMA CM que está asociado con el rdma_cm_id especificado cuando se completa. Los parámetros %node, %service y %hints se definen de manera similar a rdma_getaddrinfo().

Valor de retorno

Devuelve 0 si tiene éxito. El éxito indica que se inició la resolución de direcciones asíncrona. El resultado de la resolución, ya sea exitoso o fallido, se informará como un evento en el canal de eventos relacionado.

Devuelve -1 en caso de error, errno se establecerá para indicar la razón del fallo. La resolución de direcciones no se inició y no se generará ningún evento en el canal de eventos.

Notas

Esta llamada soporta tanto resolución DNS como IB SA, dependiendo de los hints.ai_flags:
  • RAI_DNS: Realiza la resolución de direcciones usando DNS.
  • RAI_SA: Realiza la resolución de direcciones usando el Infiniband SA. El rdma_cm_id asociado con la llamada debe estar enlazado a un puerto Infiniband, o ocurrirá un error. El parámetro %node debe ser nulo (no soportado). %Service debe ser un nombre o ID de servicio IB.

Estos 2 flags son mutuamente exclusivos; Si ninguno de ellos está establecido, entonces DNS es el predeterminado.

Se genera el evento cm RDMA_CM_EVENT_ADDRINFO_RESOLVED (en caso de éxito) o RDMA_CM_EVENT_ADDRINFO_ERROR (en caso de fallo).
