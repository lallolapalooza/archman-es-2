NOMBRE

rdma_post_ud_send - publicar una solicitud de trabajo para enviar un datagrama.

SINOPSIS

#include <rdma/rdma_verbs.h>

int rdma_post_ud_send (struct rdma_cm_id *id, void *context, void *addr, size_t length, struct ibv_mr *mr, int flags, struct ibv_ah *ah, uint32_t remote_qpn);

ARGUMENTOS

id
Una referencia a un identificador de comunicación donde se publicará el búfer del mensaje.
contexto
Contexto definido por el usuario asociado a la solicitud.
dir
La dirección del búfer de memoria a publicar.
longitud
La longitud del búfer de memoria.
mr
Región de memoria registrada opcional asociada con el búfer publicado.
banderas
Banderas opcionales utilizadas para controlar la operación de envío.
ah
Un identificador de dirección que describe la dirección del nodo remoto.
remote_qpn
El número del par de colas de destino.

DESCRIPCIÓN

Publica una solicitud de trabajo en la cola de envío del par de colas asociado con el rdma_cm_id. El contenido del búfer publicado se enviará al par de colas de destino especificado.

VALOR DEVUELTO

Devuelve 0 en caso de éxito, o -1 en caso de error. Si ocurre un error, errno se establecerá para indicar el motivo de la falla.

NOTAS

El usuario es responsable de asegurar que el par de colas de destino haya puesto en cola una solicitud de recepción antes de emitir las operaciones de envío. Para obtener una lista de banderas admitidas, consulte ibv_post_send. A menos que la solicitud de envío esté utilizando datos en línea, el búfer del mensaje debe haberse registrado antes de publicarse, con el parámetro mr haciendo referencia al registro. El búfer debe permanecer registrado hasta que se complete el envío.

El contexto definido por el usuario asociado con la solicitud de envío se devolverá al usuario a través del campo wr_id (identificador de solicitud de trabajo) de la finalización del trabajo.

VER TAMBIÉN

rdma_cm(7), rdma_connect(3), rdma_accept(3), rdma_reg_msgs(3) ibv_post_send(3), rdma_post_recv(3)
