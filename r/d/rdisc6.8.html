RDISC6(8) Manual del Administrador del Sistema RDISC6(8)

NOMBRE

rdisc - Herramienta de descubrimiento de routers ICMPv6

SINOPSIS

rdisc6 [-qv] [-r intentos] [-s ip_origen] [-w espera_ms] [dirección IPv6] <interfaz>

DESCRIPCIÓN

RDisc6 es un programa Unix que implementa el descubrimiento de routers ICMPv6 en el espacio de usuario (normalmente lo realiza el kernel). Se utiliza para buscar la lista de routers enlazados y prefijos IPv6.

También se puede usar para forzar al kernel a actualizar el estado de una interfaz de red autoconfigurada IPv6 dada.

Se debe especificar el nombre de la interfaz de red para la que se buscarán routers.

OPCIONES

-1 o --single
Salir tan pronto como se reciba el primer anuncio.
-h o --help
Mostrar ayuda y salir.
-m o --multiple
Esperar posibles anuncios múltiples e imprimir todos (por defecto).
-n o --numeric
Si el parámetro opcional no es una dirección IPv6 válida, no intentar resolverla como un nombre de host DNS.
-q o --quiet
Solo mostrar prefijos IPv6 anunciados. No mostrar nada en caso de fallo. Esto es útil principalmente cuando se llama al programa desde un script de shell.
-r intentos o --retry intentos
Enviar la solicitud de descubrimiento de routers ICMPv6 tantas veces hasta recibir una respuesta, o abortar. Por defecto, rdisc6 intentará 3 veces antes de abortar (MAX_RTR_SOLICITATIONS de RFC2461).
-s ip_origen o --source ip_origen
Especificar la dirección IPv6 que se utilizará como origen para los paquetes de solicitud de router.
-V o --version
Mostrar la versión del programa y la licencia, y salir.
-v o --verbose
Mostrar información detallada. Este es el comportamiento por defecto.
-w espera_ms o --wait espera_ms
Esperar espera_ms milisegundos para una respuesta antes de reintentar. Por defecto, rdisc6 espera 4 segundos entre cada intento (RTR_SOLICITATION_INTERVAL de RFC2461).

Si rdisc6 no recibe ninguna respuesta después del número especificado de intentos, esperando espera_ms milisegundos cada vez, saldrá con el código 2. En caso de error, saldrá con el código 1. En caso contrario, saldrá con el código 0.

SEGURIDAD

rdisc6 debe ser setuid root para permitir su uso por usuarios no privilegiados. Abandonará sus privilegios de root antes de intentar enviar o recibir datos de la red para reducir el impacto potencial de una vulnerabilidad de seguridad.
