NOMBRE

rdma_resolve_addr - Resuelve las direcciones de destino y, opcionalmente, de origen.

SINOPSIS

#include <rdma/rdma_cma.h>

int rdma_resolve_addr (struct rdma_cm_id *id, struct sockaddr *src_addr, struct sockaddr *dst_addr, int timeout_ms);

ARGUMENTOS

id
Identificador RDMA.
src_addr
Información de la dirección de origen. Este parámetro puede ser NULL.
dst_addr
Información de la dirección de destino.
timeout_ms
Tiempo de espera para que se complete la resolución.

DESCRIPCIÓN

Resuelve las direcciones de destino y, opcionalmente, de origen de direcciones IP a una dirección RDMA. Si tiene éxito, el `rdma_cm_id` especificado se vinculará a un dispositivo local.

VALOR DE RETORNO

Devuelve 0 en caso de éxito, o -1 en caso de error. Si ocurre un error, `errno` se establecerá para indicar el motivo de la falla.

NOTAS

Esta llamada se utiliza para mapear una dirección IP de destino dada a una dirección RDMA utilizable. El mapeo de IP a dirección RDMA se realiza utilizando las tablas de enrutamiento locales o mediante ARP. Si se proporciona una dirección de origen, el `rdma_cm_id` se vinculará a esa dirección, igual que si se hubiera llamado a `rdma_bind_addr`. Si no se proporciona una dirección de origen y el `rdma_cm_id` aún no se ha vinculado a un dispositivo, el `rdma_cm_id` se vinculará a una dirección de origen basada en las tablas de enrutamiento locales. Después de esta llamada, el `rdma_cm_id` se vinculará a un dispositivo RDMA. Esta llamada se realiza típicamente desde el lado activo de una conexión antes de llamar a `rdma_resolve_route` y `rdma_connect`.

ESPECÍFICO DE INFINIBAND

Esta llamada mapea las direcciones IP de destino y, si se proporcionan, de origen a GIDs. Para realizar el mapeo, IPoIB debe estar en ejecución tanto en el nodo local como en el remoto.
