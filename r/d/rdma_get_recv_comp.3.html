NOMBRE

rdma_get_recv_comp - recupera una solicitud de recepción completada.

SINOPSIS

#include <rdma/rdma_verbs.h>

int rdma_get_recv_comp (struct rdma_cm_id *id, struct ibv_wc *wc);

ARGUMENTOS

id
Una referencia a un identificador de comunicación para comprobar completados.
wc
Una referencia a una estructura de trabajo completado para rellenar.

DESCRIPCIÓN

Recupera una solicitud de trabajo completada para una operación de recepción. La información sobre la solicitud completada se devuelve a través del parámetro wc, con wr_id establecido al contexto de la solicitud. Para más detalles sobre la estructura de trabajo completado, ver ibv_poll_cq.

VALOR DE RETORNO

Devuelve el número de completados devueltos (0 o 1) en caso de éxito, o -1 en caso de error. Si ocurre un error, errno se establecerá para indicar la razón del fallo.

NOTAS

Esta llamada consulta la cola de completado de recepción asociada con un rdma_cm_id. Si no se encuentra un completado, la llamada se bloquea hasta que se complete una solicitud. Esta llamada solo debe usarse en rdma_cm_id's que no comparten CQs con otros rdma_cm_id's, y mantienen CQs separados para completados de envío y recepción.

VER TAMBIÉN

rdma_cm(7), ibv_poll_cq(3), rdma_get_send_comp(3), rdma_post_send(3), rdma_post_read(3), rdma_post_write(3)
