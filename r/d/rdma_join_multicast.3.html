RDMA_JOIN_MULTICAST(3) Manual del programador de Librdmacm RDMA_JOIN_MULTICAST(3)

NOMBRE

rdma_join_multicast - Se une a un grupo multicast.

SINOPSIS

#include <rdma/rdma_cma.h>

int rdma_join_multicast (struct rdma_cm_id *id, struct sockaddr *addr, void *context);

ARGUMENTOS

id
Identificador de comunicación asociado con la solicitud.
addr
Dirección multicast que identifica el grupo al que unirse.
context
Contexto definido por el usuario asociado con la solicitud de unión.

DESCRIPCIÓN

Se une a un grupo multicast y asocia una QP (Queue Pair) a ese grupo.

VALOR DE RETORNO

Devuelve 0 si tiene éxito, o -1 si ocurre un error. Si ocurre un error, errno se establecerá para indicar el motivo de la falla.

NOTAS

Antes de unirse a un grupo multicast, el rdma_cm_id debe estar vinculado a un dispositivo RDMA llamando a rdma_bind_addr o rdma_resolve_addr. El uso de rdma_resolve_addr requiere que las tablas de enrutamiento locales resuelvan la dirección multicast a un dispositivo RDMA, a menos que se proporcione una dirección de origen específica. El usuario debe llamar a rdma_leave_multicast para abandonar el grupo multicast y liberar cualquier recurso multicast. Después de que la operación de unión se complete, si una QP está asociada con el rdma_cm_id, se adjuntará automáticamente al grupo multicast cuando el usuario recupere el evento multicast. De lo contrario, el usuario es responsable de llamar a ibv_attach_mcast para vincular la QP al grupo multicast. El contexto de unión se devuelve al usuario a través del campo private_data en el rdma_cm_event.

VER TAMBIÉN

rdma_leave_multicast(3), rdma_bind_addr(3), rdma_resolve_addr(3), rdma_create_qp(3), rdma_get_cm_event(3)
