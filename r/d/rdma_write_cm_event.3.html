RDMA_WRITE_CM_EVENT(3) Manual del programador de Librdmacm RDMA_WRITE_CM_EVENT(3)

Nombre

RDMA_WRITE_CM_EVENT - Escribe un evento en un CM.

SINOPSIS

#include <rdma/rdma_cma.h>

int rdma_write_cm_event(struct rdma_cm_id *id, enum rdma_cm_event_type event, int status, uint64_t arg);

ARGUMENTOS

id El identificador RDMA asociado con el evento rdma_cm_event reportado.

event El valor del evento de comunicación a reportar. Debe establecerse en RDMA_CM_EVENT_USER.

status El valor de estado reportado en el rdma_cm_event.

arg Un valor especificado por el usuario reportado en el rdma_cm_event.

DESCRIPCIÓN

Escribe un evento en un CM, con un estado y un argumento.

VALOR DE RETORNO

En caso de éxito, se devuelve 0; en caso de error, se devuelve -1, y errno se establecerá para indicar la razón del fallo.

NOTAS

Esta llamada permite a una aplicación escribir un evento definido por el usuario en el canal de eventos asociado con el rdma_cm_id especificado. Los eventos de usuario válidos son: RDMA_CM_EVENT_USER. Las aplicaciones pueden utilizar esto para fines de señalización interna, como despertar a un hilo bloqueado en el canal de eventos.

VER TAMBIÉN
