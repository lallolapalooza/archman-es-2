RDMA_GET_LOCAL_ADDR(3) Manual del programador de Librdmacm RDMA_GET_LOCAL_ADDR(3)

NOMBRE

rdma_get_local_addr - Devuelve la dirección IP local de un rdma_cm_id enlazado.

SINOPSIS

#include <rdma/rdma_cma.h>

struct sockaddr * rdma_get_local_addr (struct rdma_cm_id *id);

ARGUMENTOS

id
Identificador RDMA.

DESCRIPCIÓN

Devuelve la dirección IP local para un rdma_cm_id que se ha enlazado a un dispositivo local.

VALOR DE RETORNO

Devuelve un puntero a la dirección sockaddr local del rdma_cm_id. Si el rdma_cm_id no está enlazado a una dirección, el contenido de la estructura sockaddr se establecerá a todos ceros.

VER TAMBIÉN

rdma_bind_addr(3), rdma_resolve_addr(3), rdma_get_src_port(3), rdma_get_dst_port(3), rdma_get_peer_addr(3)
