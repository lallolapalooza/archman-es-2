RDMA_CREATE_SRQ(3) Manual del programador de Librdmacm RDMA_CREATE_SRQ(3)

NOMBRE

rdma_create_srq - Asigna una cola de recepción compartida.

SINOPSIS

#include <rdma/rdma_verbs.h>

int rdma_create_srq (struct rdma_cm_id *id, struct ibv_pd *pd, struct ibv_srq_init_attr *attr);

ARGUMENTOS

id
Identificador RDMA.
pd
Dominio de protección opcional para la SRQ.
attr
Atributos de inicialización de SRQ.

DESCRIPCIÓN

Asigna una SRQ asociada con el rdma_cm_id especificado.

VALOR DE RETORNO

Devuelve 0 si tiene éxito, o -1 si hay un error. Si ocurre un error, errno se establecerá para indicar la razón de la falla.

NOTAS

El rdma_cm_id debe estar vinculado a un dispositivo RDMA local antes de llamar a esta función, y el dominio de protección, si se proporciona, debe ser para el mismo dispositivo. Después de ser asignada, la SRQ estará lista para manejar la publicación de recepciones.

Si no se proporciona un dominio de protección (el parámetro pd es NULL), entonces el rdma_cm_id se creará utilizando un dominio de protección predeterminado. Se asigna un dominio de protección predeterminado por dispositivo RDMA.

Los atributos iniciales de SRQ se especifican mediante el parámetro attr. Los campos ext.xrc.cq en ibv_srq_init_attr son opcionales. Si no se especifica una cola de finalización para una SRQ XRC, rdma_cm asignará una CQ para la SRQ, junto con los canales de finalización correspondientes. Los canales de finalización y la CQ creada por rdma_cm se exponen al usuario a través de la estructura rdma_cm_id.

Las capacidades y propiedades reales de la SRQ creada se devolverán al usuario a través del parámetro attr. Un rdma_cm_id solo puede estar asociado con una única SRQ.
