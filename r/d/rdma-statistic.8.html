NOMBRE

rdma-statistic - Configuración de contadores de estadísticas RDMA

SINOPSIS


rdma [ OPCIONES ] statistic { COMANDO | help }

rdma statistic { OBJETO } show

rdma statistic [ OBJETO ] show link [ DEV/PORT_INDX ] [ NOMBRE_FILTRO VALOR_FILTRO ]

rdma statistic OBJETO mode

rdma statistic OBJETO set AMBITO_CONTADOR [ INDX_DEV/PUERTO ] auto { CRITERIO | off } [ contadores-opcionales | on/off ]

rdma statistic OBJETO bind AMBITO_CONTADOR [ INDX_DEV/PUERTO ] [ ID-OBJETO ] [ ID-CONTADOR ]

rdma statistic OBJETO unbind AMBITO_CONTADOR [ INDX_DEV/PUERTO ] [ ID-CONTADOR ] [ ID-OBJETO ]

rdma statistic mode [ supported ] link [ INDX_DEV/PUERTO ]

rdma statistic set link [ INDX_DEV/PUERTO ] contadores-opcionales [ CONTADORES_OPCIONALES ]

rdma statistic unset link [ INDX_DEV/PUERTO ] contadores-opcionales

AMBITO_CONTADOR := { link | dev }

OBJETO := { qp | mr }

CRITERIO := { type | pid }

NOMBRE_FILTRO := { cntn | lqpn | pid | qp-type }

DESCRIPCIÓN

rdma statistic [objeto] show - Consulta el dispositivo RDMA especificado en busca de estadísticas RDMA y específicas del controlador. Muestra los contadores hw predeterminados si no se especifica el objeto

DEV - especifica los contadores en este dispositivo RDMA a mostrar.

PORT_INDEX - especifica los contadores en este puerto RDMA a mostrar.

NOMBRE_FILTRO - especifica un filtro para mostrar solo los resultados que coincidan con él.

rdma statistic <objeto> set - configura el modo automático de estadísticas de contador para un dispositivo/puerto específico

En modo automático, todos los objetos que pertenecen a una categoría se enlazan automáticamente a un conjunto de contadores. El "off" es global para todos los modos automáticos juntos. No aplicable para MRs.

rdma statistic <objeto> bind - enlaza manualmente un objeto (ej., un qp) con un contador

Cuando está enlazado, las estadísticas de este objeto están disponibles en este contador. No aplicable para MRs.

rdma statistic <objeto> unbind - desenlaza manualmente un objeto (ej., un qp) del contador previamente enlazado

Cuando se desenlaza, las estadísticas de este objeto ya no están disponibles en este contador; y si no se especifica el ID del objeto, todos los objetos en este contador se desenlazarán. No aplicable para MRs.

ID-CONTADOR - especifica el ID del contador a enlazar. Si se omite este argumento, se asignará un nuevo contador.

rdma statistic mode - Muestra los contadores opcionales habilitados para cada enlace.

rdma statistic mode supported - Muestra los contadores opcionales soportados para cada enlace.

rdma statistic set - Habilita un conjunto de contadores opcionales para un dispositivo/puerto específico.

CONTADORES_OPCIONALES - especifica el nombre de los contadores opcionales a habilitar. Los contadores opcionales que no se especifican se deshabilitarán. Tenga en cuenta que los contadores opcionales dependen del controlador.

rdma statistic unset - Deshabilita todos los contadores opcionales para un dispositivo/puerto específico.

EJEMPLOS

rdma statistic show

Muestra el estado del contador predeterminado de todos los dispositivos RDMA del sistema.

rdma statistic show link mlx5_2/1

Muestra el estado del contador predeterminado del puerto RDMA especificado

rdma statistic qp show

Muestra el estado de todos los contadores qp de todos los dispositivos RDMA del sistema.

rdma statistic qp show link mlx5_2/1

Muestra el estado de todos los contadores qp del puerto RDMA especificado.

rdma statistic qp show link mlx5_2 pid 30489

Muestra el estado de todos los contadores qp del puerto RDMA especificado y que pertenecen al pid 30489

rdma statistic qp show link mlx5_2 qp-type UD

Muestra el estado de todos los contadores qp del puerto RDMA especificado y con tipo de QP UD

rdma statistic qp mode

Lista el modo de contador actual en todos los dispositivos

rdma statistic qp mode link mlx5_2/1

Lista el modo de contador actual del puerto 1 del dispositivo mlx5_2

rdma statistic qp set link mlx5_2/1 auto type on

En el puerto 1 del dispositivo mlx5_2, para cada QP de usuario nuevo, enlázalo automáticamente con un contador. Por contador para QPs con el mismo tipo de qp.

rdma statistic qp set link mlx5_2/1 auto type on optional-counters on

En el puerto 1 del dispositivo mlx5_2, para cada QP de usuario nuevo, enlázalo automáticamente con un contador. Por contador para QPs con el mismo tipo de qp. Al mismo tiempo, enlaza los contadores opcionales actualmente habilitados.

rdma statistic qp set link mlx5_2/1 auto pid on

En el puerto 1 del dispositivo mlx5_2, para cada QP de usuario nuevo, enlázalo automáticamente con un contador. Por contador para QPs con el mismo pid.

rdma statistic qp set link mlx5_2/1 auto pid,type on

En el puerto 1 del dispositivo mlx5_2, para cada QP de usuario nuevo, enlázalo automáticamente con un contador. Por contador para QPs con el mismo pid y el mismo tipo.

rdma statistic qp set link mlx5_2/1 auto off

Desactiva el modo automático en el puerto 1 del dispositivo mlx5_2. Los contadores asignados se pueden acceder manualmente.

rdma statistic qp bind link mlx5_2/1 lqpn 178

En el puerto 1 del dispositivo mlx5_2, asigna un contador y enlaza el qp especificado en él

rdma statistic qp unbind link mlx5_2/1 cntn 4 lqpn 178

En el puerto 1 del dispositivo mlx5_2, enlaza el qp especificado en el contador especificado

rdma statistic qp unbind link mlx5_2/1 cntn 4

En el puerto 1 del dispositivo mlx5_2, desenlaza todos los QPs del contador especificado. Después de eso, el kernel liberará automáticamente este contador.

rdma statistic show mr

Lista todos los MRs asignados actualmente y sus contadores.

rdma statistic show mr mrn 6

Vuelca las estadísticas de un MR específico con mrn 6. No vuelca nada si no existe.

rdma statistic mode link mlx5_2/1

Muestra los contadores opcionales que se habilitaron en mlx5_2/1.

rdma statistic mode supported link mlx5_2/1

NAME

rdma-statistic - manage RDMA device statistics

SYNOPSIS

rdma statistic { COMMAND | -h | --help }

rdma statistic dev { COMMAND | -h | --help }

rdma statistic link { COMMAND | -h | --help }

DESCRIPTION

Manages RDMA device and link statistics. The statistics are divided into two categories: standard and optional. Standard statistics are always enabled and available. Optional statistics are disabled by default and must be explicitly enabled to be collected and reported.

COMMANDS

dev show [ DEV [ PORT ] ]
Show statistics for a specific RDMA device or port. If DEV and PORT are not specified, all devices and ports are shown.
link show [ DEV [ PORT ] ]
Show link statistics for a specific RDMA device or port. If DEV and PORT are not specified, all devices and ports are shown.
dev set DEV [ PORT ] { optional-counters LIST }
Enable specific optional counters for a given device or port. LIST is a comma-separated list of counter names.
dev unset DEV [ PORT ] { optional-counters }
Disable all optional counters for a given device or port.
link set DEV [ PORT ] { optional-counters LIST }
Enable specific optional counters for a given device or port's link. LIST is a comma-separated list of counter names.
link unset DEV [ PORT ] { optional-counters }
Disable all optional counters for a given device or port's link.

EXAMPLES

Show all standard statistics for device mlx5_2 port 1:

rdma statistic dev show mlx5_2 1

Show all link statistics for device mlx5_2 port 1:

rdma statistic link show mlx5_2 1

List all supported optional counters for device mlx5_2 port 1:

rdma statistic dev mlx5_2 1 optional-counters

Enable the cc_rx_ce_pkts,cc_rx_cnp_pkts optional counters on device mlx5_2 port 1:

rdma statistic dev mlx5_2 1 optional-counters cc_rx_ce_pkts,cc_rx_cnp_pkts

Disable all the optional counters on device mlx5_2 port 1.

rdma statistic dev mlx5_2 1 optional-counters

Enable the cc_rx_ce_pkts,cc_rx_cnp_pkts counters on device mlx5_2 port 1.

rdma statistic link mlx5_2/1 optional-counters cc_rx_ce_pkts,cc_rx_cnp_pkts

Disable all the optional counters on device mlx5_2 port 1.

rdma statistic link mlx5_2/1 optional-counters
