NOMBRE

rdma_listen - Escuchar las solicitudes de conexión entrantes.

SINOPSIS

#include <rdma/rdma_cma.h>

int rdma_listen (struct rdma_cm_id *id, int backlog);

ARGUMENTOS

id
Identificador RDMA.
backlog
cola de solicitudes de conexión entrantes.

DESCRIPCIÓN

Inicia una escucha para solicitudes de conexión entrantes o búsqueda de servicios de datagramas. La escucha se restringirá a la dirección de origen vinculada localmente.

VALOR DE RETORNO

Devuelve 0 en caso de éxito, o -1 en caso de error. Si ocurre un error, la variable `errno` se establecerá para indicar el motivo de la falla.

NOTAS

Los usuarios deben haber vinculado el `rdma_cm_id` a una dirección local llamando a `rdma_bind_addr` antes de llamar a esta rutina. Si el `rdma_cm_id` está vinculado a una dirección IP específica, la escucha se restringirá a esa dirección y al dispositivo RDMA asociado. Si el `rdma_cm_id` está vinculado solo a un número de puerto RDMA, la escucha se realizará en todos los dispositivos RDMA.

VER TAMBIÉN

rdma_cm(7), rdma_bind_addr(3), rdma_connect(3), rdma_accept(3), rdma_reject(3), rdma_get_cm_event(3)
