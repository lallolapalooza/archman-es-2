NOMBRE

rdma_reg_msgs - registra(n) el(los) buffer(s) de datos para enviar o recibir mensajes.

SINOPSIS

#include <rdma/rdma_verbs.h>

struct ibv_mr * rdma_reg_msgs (struct rdma_cm_id *id, void *addr, size_t length);

ARGUMENTOS

id
Una referencia a un identificador de comunicación donde se utilizará(n) el(los) buffer(s) de mensajes.
addr
La dirección del(los) buffer(s) de memoria a registrar.
length
La longitud total de la memoria a registrar.

DESCRIPCIÓN

Registra una matriz de buffers de memoria utilizados para enviar y recibir mensajes u operaciones RDMA. Los buffers de memoria registrados utilizando rdma_reg_msgs pueden ser publicados en un rdma_cm_id usando rdma_post_send o rdma_post_recv, o especificados como el objetivo de una operación de lectura RDMA o la fuente de una solicitud de escritura RDMA.

VALOR DE RETORNO

Devuelve una referencia a la región de memoria registrada en caso de éxito, o NULL en caso de error. Si ocurre un error, errno se establecerá para indicar el motivo de la falla.

NOTAS

rdma_reg_msgs se utiliza para registrar una matriz de buffers de datos que se utilizarán para enviar y/o recibir mensajes en un par de colas asociado con un rdma_cm_id. El buffer de memoria se registra con el dominio de protección asociado con el identificador. El inicio de la matriz de buffers de datos se especifica a través del parámetro addr, y el tamaño total de la matriz se proporciona mediante length.

Todos los buffers de datos deben registrarse antes de ser publicados como una solicitud de trabajo. Los usuarios deben anular el registro de toda la memoria registrada llamando a rdma_dereg_mr.
