NOMBRE

rdma_get_send_comp - recupera una solicitud de envío, lectura o escritura completada.

SINOPSIS

#include <rdma/rdma_verbs.h>

int rdma_get_send_comp (struct rdma_cm_id *id, struct ibv_wc *wc);

ARGUMENTOS

id
Una referencia a un identificador de comunicación para verificar finalizaciones.
wc
Una referencia a una estructura de finalización de trabajo para rellenar.

DESCRIPCIÓN

Recupera una solicitud de trabajo completada para una operación de envío, lectura RDMA o escritura RDMA. La información sobre la solicitud completada se devuelve a través del parámetro wc, con wr_id establecido en el contexto de la solicitud. Para obtener detalles sobre la estructura de finalización de trabajo, consulte ibv_poll_cq.

VALOR DE RETORNO

Devuelve el número de finalizaciones devueltas (0 o 1) en caso de éxito, o -1 en caso de error. Si se produce un error, errno se establecerá para indicar el motivo de la falla.

NOTAS

Esta llamada sondea la cola de finalización de envío asociada con un rdma_cm_id. Si no se encuentra una finalización, la llamada se bloquea hasta que se complete una solicitud. Esta llamada solo debe usarse en rdma_cm_id que no comparten CQs con otros rdma_cm_id, y que mantienen CQs separadas para finalizaciones de envío y recepción.

VER TAMBIÉN

rdma_cm(7), ibv_poll_cq(3), rdma_get_recv_comp(3), rdma_post_send(3), rdma_post_read(3), rdma_post_write(3)
