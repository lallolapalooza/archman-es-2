NOMBRE

rdma_server - Prueba simple de conexión y ping-pong de RDMA CM.

SINOPSIS

rdma_server [-p puerto]

DESCRIPCIÓN

Utiliza llamadas síncronas de librdmam para establecer conexiones RDMA entre dos nodos. Este ejemplo está destinado a proporcionar un ejemplo de código muy simple de cómo usar RDMA.

OPCIONES

-s dirección_servidor
Especifica la dirección en la que escucha rdma_server. Por defecto, el servidor escucha en cualquier dirección (0.0.0.0).
-p puerto
Cambia el número de puerto en el que escucha el servidor. Por defecto, el servidor escucha en el puerto 7471.

NOTAS

El uso básico es iniciar rdma_server, luego conectarse al servidor usando el programa rdma_client.

Dado que esta prueba mapea recursos RDMA al espacio de usuario, los usuarios deben asegurarse de tener recursos y permisos del sistema disponibles. Consulte el archivo README de libibverbs para obtener detalles adicionales.

VER TAMBIÉN

rdma_cm(7), udaddy(1), mckey(1), rping(1), rdma_client(1)
