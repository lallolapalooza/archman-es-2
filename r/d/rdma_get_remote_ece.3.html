RDMA_GET_REMOTE_ECE(3) Manual del programador de Librdmacm RDMA_GET_REMOTE_ECE(3)

NOMBRE

rdma_get_remote_ece - Obtener parámetros ECE tal como fueron recibidos del par.

SINOPSIS

#include <rdma/rdma_cma.h>
int rdma_get_remote_ece(struct rdma_cm_id *id, struct ibv_ece *ece);

DESCRIPCIÓN

rdma_get_remote_ece() obtiene los parámetros ECE tal como fueron recibidos del par de comunicación.

Esta función está pensada para ser utilizada por los usuarios de QPs externos. La llamada debe realizarse antes de responder al par y es necesaria para permitir que el lado pasivo conozca las opciones ECE del otro lado.

Al ser utilizado por un QP externo y como RDMA_CM no gestiona ese QP, el par necesita llamar a la API de libibverbs por sí mismo.

El flujo habitual para el lado pasivo será:

•
ibv_create_qp() <- crear QP de datos.
•
ece = rdma_get_remote_ece() <- obtener opciones ECE del par remoto
•
ibv_set_ece(ece) <- establecer opciones ECE locales con los datos recibidos del par.
•
ibv_modify_qp() <- habilitar QP de datos.
•
rdma_set_local_ece(ece) <- establecer opciones ECE deseadas después de que el proveedor de libibverbs correspondiente enmascare las opciones no soportadas.
•
rdma_accept()/rdma_establish()/rdma_reject_ece()

ARGUMENTOS

*id
Identificador de comunicación RDMA.
*ece
Estructura ECE a rellenar.

VALOR DE RETORNO

rdma_get_remote_ece() devuelve 0 en caso de éxito, o -1 en caso de error. Si ocurre un error, errno se establecerá para indicar la razón del fallo.

VER TAMBIÉN

rdma_cm(7), rdma_set_local_ece(3)
