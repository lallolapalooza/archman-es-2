RDMA_CONNECT(3) Manual del programador de Librdmacm RDMA_CONNECT(3)

NOMBRE

rdma_connect - Inicia una solicitud de conexión activa.

SINOPSIS

#include <rdma/rdma_cma.h>

int rdma_connect (struct rdma_cm_id *id, struct rdma_conn_param *conn_param);

ARGUMENTOS

id
Identificador RDMA.
conn_param
Parámetros de conexión. Ver PROPIEDADES DE CONEXIÓN abajo para más detalles.

DESCRIPCIÓN

Para un rdma_cm_id de tipo RDMA_PS_TCP, esta llamada inicia una solicitud de conexión a un destino remoto. Para un rdma_cm_id de tipo RDMA_PS_UDP, inicia una búsqueda del QP remoto que proporciona el servicio de datagramas.

VALOR DE RETORNO

Devuelve 0 en caso de éxito, o -1 en caso de error. Si ocurre un error, errno se establecerá para indicar el motivo de la falla.

NOTAS

Los usuarios deben haber resuelto una ruta a la dirección de destino habiendo llamado a rdma_resolve_route o rdma_create_ep antes de llamar a esta rutina.

PROPIEDADES DE CONEXIÓN

Las siguientes propiedades se utilizan para configurar la comunicación y se especifican mediante el parámetro conn_param al conectar o establecer comunicación de datagramas.

private_data
Hace referencia a un búfer de datos controlado por el usuario. El contenido del búfer se copia y se pasa transparentemente al lado remoto como parte de la solicitud de comunicación. Puede ser NULL si no se requiere private_data.
private_data_len
Especifica el tamaño del búfer de datos controlado por el usuario. Tenga en cuenta que la cantidad real de datos transferidos al lado remoto depende del transporte y puede ser mayor que la solicitada.
responder_resources
El número máximo de operaciones de lectura RDMA y atómicas pendientes que el lado local aceptará del lado remoto. Se aplica solo a RDMA_PS_TCP. Este valor debe ser menor o igual que los atributos del dispositivo RDMA local max_qp_rd_atom y los atributos del dispositivo RDMA remoto max_qp_init_rd_atom. El punto final remoto puede ajustar este valor al aceptar la conexión.
initiator_depth
El número máximo de operaciones de lectura RDMA y atómicas pendientes que el lado local tendrá hacia el lado remoto. Se aplica solo a RDMA_PS_TCP. Este valor debe ser menor o igual que los atributos del dispositivo RDMA local max_qp_init_rd_atom y los atributos del dispositivo RDMA remoto max_qp_rd_atom. El punto final remoto puede ajustar este valor al aceptar la conexión.
flow_control
Especifica si el control de flujo por hardware está disponible. Este valor se intercambia con el par remoto y no se utiliza para configurar el QP. Se aplica solo a RDMA_PS_TCP.
retry_count
El número máximo de veces que se debe reintentar una operación de transferencia de datos en la conexión cuando ocurre un error. Esta configuración controla el número de veces que se reintentan las operaciones de envío, RDMA y atómicas cuando ocurren tiempos de espera. Se aplica solo a RDMA_PS_TCP.
rnr_retry_count
El número máximo de veces que se debe reintentar una operación de envío desde el par remoto en una conexión después de recibir un error de receptor no listo (RNR). Los errores RNR se generan cuando llega una solicitud de envío antes de que se haya publicado un búfer para recibir los datos entrantes. Se aplica solo a RDMA_PS_TCP.
srq
Especifica si el QP asociado con la conexión está utilizando una cola de recepción compartida. La biblioteca ignora este campo si se ha creado un QP en el rdma_cm_id. Se aplica solo a RDMA_PS_TCP.
qp_num
Especifica el número de QP asociado con la conexión. La biblioteca ignora este campo si se ha creado un QP en el rdma_cm_id. Se aplica solo a RDMA_PS_TCP.

ESPECÍFICO INFINIBAND

Además de las propiedades de conexión definidas anteriormente, los QP de InfiniBand se configuran con un temporizador mínimo de NAK RNR y valores de tiempo de espera de ACK local. El valor mínimo del temporizador de NAK RNR se establece en 0, para un retraso de 655 ms. El tiempo de espera de ACK local se calcula en función de la vida útil del paquete y el retraso de ACK local de la HCA. La vida útil del paquete está determinada por el Administrador de Subred de InfiniBand y forma parte de la información de la ruta resuelta (registro de ruta). El retraso de ACK de la HCA es una propiedad de la HCA utilizada localmente.

Los valores de recuento de reintentos y recuento de reintentos RNR son valores de 3 bits.

La longitud de los datos privados proporcionados por el usuario se limita a 56 bytes para RDMA_PS_TCP, o 180 bytes para RDMA_PS_UDP.

ESPECÍFICO IWARP

Las conexiones establecidas a través de dispositivos RDMA iWarp actualmente requieren que el lado activo de la conexión envíe el primer mensaje.
