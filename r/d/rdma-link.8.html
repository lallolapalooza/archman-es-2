NOMBRE

rdma-link - configuración de enlaces RDMA

SINOPSIS


rdma [ OPCIONES ] link { COMANDO | help }

OPCIONES := { -V[ersion] | -d[etails] }

rdma link show [ DEV/PORT_INDEX ]

rdma link add NOMBRE type TIPO netdev NETDEV

rdma link delete NOMBRE

rdma link help

DESCRIPCIÓN

rdma link show - mostrar atributos del enlace rdma

DEV/PORT_INDEX - especifica el enlace RDMA a mostrar. Si se omite este argumento, se listarán todos los enlaces.

rdma link add NOMBRE type TIPO netdev NETDEV - añadir un enlace rdma para el tipo especificado al dispositivo de red

NOMBRE - especifica el nuevo nombre del enlace rdma a añadir

TIPO - especifica qué tipo de rdma usar. Tipos de enlace:


rxe - Controlador RoCE de software

siw - Controlador iWARP de software

NETDEV - especifica el dispositivo de red al que está enlazado el enlace

rdma link delete NOMBRE - eliminar un enlace rdma

NOMBRE - especifica el nombre del enlace rdma a eliminar

EJEMPLOS

rdma link show

Muestra el estado de todos los enlaces rdma en el sistema.

rdma link show mlx5_2/1

Muestra el estado del enlace rdma especificado.

rdma link add rxe_eth0 type rxe netdev eth0

Añade un enlace RXE llamado rxe_eth0 al dispositivo de red eth0

rdma link del rxe_eth0

Elimina el enlace RXE rxe_eth0
