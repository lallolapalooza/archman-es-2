RDNSSD(8) Manual del Administrador del Sistema RDNSSD(8)

NOMBRE

rdnssd - Demonio de descubrimiento de Servidores DNS Recursivos (RDNSS)

SINOPSIS

rdnssd [-f] [-H hook-de-fusion] [-r archivo-resolv] [-p archivo-pid] [-u nombre-usuario]

DESCRIPCIÓN

rdnssd es un programa demonio que proporciona soporte del lado del cliente para la configuración DNS utilizando la opción de Servidor DNS Recursivo (RDNSS), tal como se describe en la RFC 5006. Su propósito es suministrar resolutores DNS IPv6 a través de la autoconfiguración sin estado, transportada por Anuncios de Router.

rdnssd analiza las opciones RDNSS y realiza un seguimiento de los resolutores para escribir entradas de servidores de nombres en un archivo de configuración resolv.conf(5). Por defecto, escribe su propio archivo separado y puede llamar a un hook externo para fusionarlo con el /etc/resolv.conf principal. Esto tiene como objetivo facilitar la coexistencia con demonios concurrentes, especialmente los IPv4, que también actualizan /etc/resolv.conf.

En Linux, desde la versión 2.6.24, rdnssd aprovecha una nueva interfaz netlink, reenviando las opciones RDNSS validadas por el kernel al espacio de usuario. De lo contrario, simplemente escucha todo el tráfico ICMPv6 a través de un socket en bruto.

OPCIONES

-f o --foreground
No se desvincule de la consola. Ejecute el programa en primer plano.
-H hook-de-fusion o --merge-hook hook-de-fusion
Ejecute este hook cada vez que se actualice resolv.conf. Si esta opción no se especifica, no se llamará a ningún hook.
-h o --help
Muestre una ayuda y salga.
-p archivo-pid o --pidfile archivo-pid
Anule la ubicación del archivo pid.
-r archivo-resolv o --resolv-file archivo-resolv
Establezca la ruta al archivo resolv.conf generado.
-u nombre-usuario o --user nombre-usuario
Anule el usuario con el que se ejecutará el programa. Por defecto, se ejecuta como nobody.
-V o --version
Muestre la versión del programa y la licencia y salga.

ARCHIVOS

/etc/rdnssd/merge-hook
Un hook de fusión básico que se incluye con rdnssd, para ser llamado con la opción -H.
/var/run/rdnssd/resolv.conf
El archivo resolv.conf(5) por defecto al que rdnssd escribe su configuración.
/var/run/rdnssd.pid
El archivo de ID de proceso.

ERRORES

rdnssd no realiza un seguimiento de las vidas útiles de los routers asociados con algunos resolutores DNS, mientras que debería para cumplir estrictamente con la RFC 5006.

Cuando rdnssd utiliza un socket en bruto en lugar de la interfaz del kernel netlink, no valida de ninguna manera el tráfico de Descubrimiento de Vecinos recibido. Por ejemplo, siempre considerará los paquetes de Anuncio de Router, mientras que no debería si el host está configurado como router. Cuando se utiliza la interfaz netlink, el kernel realiza dicha validación.

resolv.conf(5), rdisc6(8), ipv6(7)
