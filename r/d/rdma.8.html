NOMBRE

rdma - Herramienta RDMA

SINOPSIS


rdma [ OPCIONES ] OBJETO { COMANDO | ayuda }

rdma [ -forzar ] -lote nombrearchivo

OBJETO := { dev | link | recurso | sistema | estadistica | monitor }

OPCIONES := { -V[ersion] | -d[etalles] | -j[son] | -o[unalinea] | -p[resentacion] }

OPCIONES

-V, -Version
Imprime la versión de la herramienta rdma y sale.
-b, -lote <NOMBREARCHIVO>
Lee comandos del archivo proporcionado o de la entrada estándar y los invoca. El primer fallo provocará la terminación de rdma.
-forzar
No terminar rdma ante errores en modo lote. Si hubo algún error durante la ejecución de los comandos, el código de retorno de la aplicación será no cero.
-d, --detalles
Muestra información detallada. Añadir un segundo -d incluye detalles específicos del controlador.
-r, --crudo
La salida incluye detalles específicos del controlador en formato crudo.
-p, --presentacion
Cuando se combina con -j genera una salida JSON formateada.
-j, --json
Genera salida JSON.
-o, -unalinea
muestra cada registro en una sola línea, reemplazando los saltos de línea con el carácter '\'.

OBJETO

dev
- Dispositivo RDMA.
link
- Puerto RDMA relacionado.
recurso
- Configuración de recursos RDMA.
sys
- Subsistema RDMA relacionado.
estadistica
- Contador de estadísticas RDMA relacionado.
monitor
- Monitor de eventos RDMA

Los nombres de todos los objetos se pueden escribir en forma completa o abreviada, por ejemplo, stats se puede abreviar como stat o simplemente s.

COMANDO

Especifica la acción a realizar sobre el objeto. El conjunto de acciones posibles depende del tipo de objeto. Por regla general, es posible mostrar (o listar ) objetos, pero algunos objetos no permiten todas estas operaciones o tienen algunos comandos adicionales. El comando ayuda está disponible para todos los objetos. Imprime una lista de comandos disponibles y convenciones de sintaxis de argumentos.

Si no se proporciona ningún comando, se asume un comando por defecto. Normalmente es listar o, si los objetos de esta clase no se pueden listar, ayuda.

ESTADO DE SALIDA

El estado de salida es 0 si el comando tuvo éxito o un entero positivo en caso de fallo.

VER TAMBIÉN

rdma-dev(8), rdma-link(8), rdma-resource(8), rdma-system(8), rdma-statistic(8), rdma-monitor(8),

REPORTAR ERRORES

Reportar cualquier error a la lista de correo de Linux RDMA <linux-rdma@vger.kernel.org> donde se realiza principalmente el desarrollo y el mantenimiento. No es necesario suscribirse a la lista para enviar un mensaje allí.
