RDMA_GET_REQUEST(3) Manual del programador de Librdmacm RDMA_GET_REQUEST(3)

NOMBRE

rdma_get_request - Recupera el próximo evento de solicitud de conexión pendiente.

SINOPSIS

#include <rdma/rdma_cma.h>

int rdma_get_request (struct rdma_cm_id *listen, struct rdma_cm_id **id);

ARGUMENTOS

listen
ID de rdma_cm_id de escucha.
id
ID de rdma_cm_id asociado con la nueva conexión.

DESCRIPCIÓN

Recupera un evento de solicitud de conexión. Si no hay solicitudes pendientes, la llamada se bloqueará hasta que se reciba un evento.

VALOR DE RETORNO

Devuelve 0 si tiene éxito, o -1 si ocurre un error. Si ocurre un error, se establecerá errno para indicar el motivo de la falla.

NOTAS

Esta llamada solo se puede usar en ID de rdma_cm_id de escucha que operan de forma síncrona. En caso de éxito, se devolverá al usuario un nuevo ID de rdma_cm_id que representa la solicitud de conexión. El nuevo ID de rdma_cm_id hará referencia a la información del evento asociada con la solicitud hasta que el usuario llame a rdma_reject, rdma_accept o rdma_destroy_id en el identificador recién creado. Para obtener una descripción de los datos del evento, consulte rdma_get_cm_event.

Si los atributos del QP están asociados con el punto final de escucha, el ID de rdma_cm_id devuelto también hará referencia a un QP asignado.

VER TAMBIÉN

rdma_get_cm_event(3), rdma_accept(3), rdma_reject(3), rdma_connect(3), rdma_listen(3), rdma_destroy_id(3)
