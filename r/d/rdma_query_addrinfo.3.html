RDMA_QUERY_ADDRINFO(3) Manual del programador de Librdmacm RDMA_QUERY_ADDRINFO(3)

Nombre

RDMA_QUERY_ADDRINFO - Consulta la información de dirección resuelta.

SINOPSIS

#include <rdma/rdma_cma.h>

int rdma_query_addrinfo(struct rdma_cm_id *id, struct rdma_addrinfo **info);

ARGUMENTOS

id Identificador RDMA.

info Un puntero a una lista enlazada de estructuras rdma_addrinfo que contienen información resuelta.

DESCRIPCIÓN

Esta función recupera las estructuras rdma_addrinfo resultantes de una operación rdma_resolve_addrinfo() exitosa.

VALOR DE RETORNO

En caso de éxito, se devuelve 0; info contiene información de dirección resuelta. En caso de error, se devuelve -1 y errno se establecerá para indicar el motivo del fallo.

NOTAS

La info debe liberarse con rdma_freeaddrinfo(3)

VER TAMBIÉN

rdma_getaddrinfo(3), rdma_freeaddrinfo(3), rdma_resolve_addrinfo(3)
