NOMBRE

rdma-resource - configuración de recursos rdma

SINOPSIS


rdma [ OPCIONES ] RECURSO { COMANDO | help }

RECURSO := { cm_id | cq | mr | pd | qp | ctx | srq }

OPCIONES := { -j[son] | -d[etails] }

rdma resource show [ DEV/PORT_INDEX ]

rdma resource help

DESCRIPCIÓN

rdma resource show - mostrar información de seguimiento de recursos rdma

DEV/PORT_INDEX - especifica el enlace RDMA a mostrar. Si este argument se omite, se listarán todos los enlaces.

EJEMPLOS

rdma resource show

Muestra un resumen de todos los dispositivos del sistema.

rdma resource show mlx5_2

Muestra el estado del dispositivo rdma especificado.

rdma res show qp link mlx5_4

Obtiene todos los QP para el dispositivo específico.

rdma res show qp link mlx5_4/1

Obtiene los QP del puerto específico.

rdma res show qp link mlx5_4/0

Proporciona un número de puerto ilegal (0 es ilegal).

rdma res show qp link mlx5_4/-

Obtiene los QP que aún no han asignado puerto.

rdma res show qp link mlx5_4/- -d

Vista detallada.

rdma res show qp link mlx5_4/- -dd

Vista detallada que incluye detalles específicos del controlador.

rdma res show qp link mlx5_4/1 lqpn 0-6

Limita a QPNs Locales específicos.

rdma res show qp link mlx5_4/1 lqpn 6 -r

Detalles específicos del controlador en formato crudo.

rdma resource show cm_id dst-port 7174

Muestra los CM_IDs con puerto IP de destino 7174.

rdma resource show cm_id src-addr 172.16.0.100

Muestra los CM_IDs enlazados a la dirección IP local 172.16.0.100

rdma resource show cq pid 30489

Muestra los CQ pertenecientes al pid 30489

rdma resource show ctx ctxn 1

Muestra los contextos que tienen un índice igual a 1.

rdma resource show srq lqpn 5-7

Muestra los SRQ a los que están asociados los QP con lqpn 5-7.
