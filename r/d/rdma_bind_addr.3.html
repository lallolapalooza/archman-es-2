RDMA_BIND_ADDR(3) Manual del programador de Librdmacm RDMA_BIND_ADDR(3)

NOMBRE

rdma_bind_addr - Vincula un identificador RDMA a una dirección de origen.

SINOPSIS

#include <rdma/rdma_cma.h>

int rdma_bind_addr (struct rdma_cm_id *id, struct sockaddr *addr);

ARGUMENTOS

id
Identificador RDMA.
addr
Información de la dirección local. Se permiten valores comodín.

DESCRIPCIÓN

Asocia una dirección de origen con un rdma_cm_id. La dirección puede ser comodín. Si se vincula a una dirección local específica, el rdma_cm_id también se vinculará a un dispositivo RDMA local.

VALOR DE RETORNO

Devuelve 0 si tiene éxito, o -1 si ocurre un error. Si ocurre un error, la variable errno se establecerá para indicar el motivo de la falla.

NOTAS

Normalmente, esta rutina se llama antes de llamar a rdma_listen para vincularse a un número de puerto específico, pero también puede llamarse en el lado activo de una conexión antes de llamar a rdma_resolve_addr para vincularse a una dirección específica.

Si se usa para vincularse al puerto 0, el rdma_cm seleccionará un puerto disponible, que puede recuperarse con rdma_get_src_port(3).

VER TAMBIÉN

rdma_create_id(3), rdma_listen(3), rdma_resolve_addr(3), rdma_create_qp(3), rdma_get_local_addr(3), rdma_get_src_port(3)
