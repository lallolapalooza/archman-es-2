rdfproc(1) Manual de Comandos Generales rdfproc(1)

NOMBRE

rdfproc - Utilidad de procesamiento RDF de Redland

SINOPSIS

rdfproc [opciones] nombre-almacen comando arg...

EJEMPLO

rdfproc test parse http://planetrdf.com/guide/rss.rdf
rdfproc test print
rdfproc test serialize ntriples

DESCRIPCIÓN

La utilidad rdfproc permite analizar, consultar, manipular y serializar contenido RDF utilizando la biblioteca RDF de Redland. El nombre-almacen es un nombre de almacén de Redland, típicamente un identificador corto. Los argumentos para comando varían y se explican en la sección COMANDOS más abajo.

OPCIONES

rdfproc utiliza la sintaxis habitual de línea de comandos de GNU, con opciones largas que comienzan con dos guiones (`-') si son compatibles con la función getopt_long. De lo contrario, solo están disponibles las opciones cortas.

-h, --help
Muestra un resumen de las opciones.
-c, --contexts
Utiliza un almacén con contextos de Redland.
-n, --new
Crea un nuevo almacén, sobrescribiendo cualquiera existente.
-o, --output FORMATO
Establece el FORMATO de salida para secuencias de triplas, como de una búsqueda (comando find) a un serializador de Redland. Usa -h o -o help para ver la lista completa de formatos compatibles.
-p, --password
Lee la opción de almacenamiento 'password' de la entrada estándar. Terminado por fin de línea ('\n') o fin de archivo. Esto es equivalente a establecerlo usando -t o --storage-options pero no requiere exponer la contraseña en la lista de argumentos.
-q, --quiet
Suprime mensajes informativos (que van a stderr)
-r, --results FORMATO
Establece el formato de sintaxis de los resultados de la consulta. Usa -h o -r help para ver la lista completa de formatos de resultados de consulta.
La lista exacta de formatos depende de con qué se compiló libraptor(3) pero se proporciona correctamente en el mensaje de uso con -h.
-s, --storage TIPO
Establece el tipo de almacenamiento de Redland (predeterminado 'hashes'). Si la variable de entorno RDFPROC_STORAGE_TYPE está establecida, el tipo de almacenamiento dado aquí la anulará. Usa -h o -s help para ver la lista completa de formatos de resultados de consulta.
-t, --storage-options OPCIONES
Establece las opciones para el almacenamiento de Redland, el valor predeterminado es "hash-type='bdb',dir='.'" para coincidir con el almacenamiento predeterminado "hashes". Para tipos de almacenamiento como 'mysql' que necesitan opciones adicionales, esto típicamente sería algo como "host='nombrehost',database='nombredb',user='abc',password='pass'". Si la variable de entorno RDFPROC_STORAGE_OPTIONS está establecida, las opciones de almacenamiento dadas aquí se aplicarán después.
-v, --version
Imprime la versión de Redland y sale.
-V, --verbose
Muestra mensajes informativos en stderr.

COMANDOS

Donde se permite un nodo, como NODO, SUJETO, PREDICADO u OBJETO a continuación, se utilizan heurísticas simples para adivinar cuáles son identificadores de nodo en blanco, URIs o literales (para agregar una declaración con un literal, use add-typed). Si el elemento comienza con _: entonces se asume que es un identificador de nodo en blanco, de lo contrario, si coincide con algo:// se asume que es una URI, de lo contrario es un literal. Los literales solo se permiten como objetos de declaraciones y los nodos en blanco no se permiten como predicados.

add SUJETO PREDICADO OBJETO [CONTEXTO]
Agrega la tripleta dada al grafo, en el contexto opcional de Redland si se proporciona el nodo CONTEXTO.
add-typed SUJETO PREDICADO OBJETO OBJETO-IDIOMA OBJETO-URI [CONTEXTO]
Agrega la tripleta con el objeto literal con tipo de datos al grafo, en el contexto opcional de Redland si se proporciona CONTEXTO.
arc SUJETO OBJETO
arcs SUJETO OBJETO
Muestra un nodo/todos los nodos que coinciden con triplas (SUJETO, ?, OBJETO)
arcs-in NODO
Muestra todas las propiedades de las triplas con NODO como sujeto.
arcs-out NODO
Muestra todas las propiedades de las triplas con NODO como objeto.
contains SUJETO PREDICADO OBJETO
Verifica si la tripleta dada está en el grafo.
contexts
Lista todos los contextos en el grafo (si los contextos están habilitados).
find SUJETO|- PREDICADO|- OBJETO|- [CONTEXTO]
Busca triplas coincidentes con la declaración dada donde - representa un comodín que coincide con cualquier nodo. Si se proporciona CONTEXTO, solo busca triplas en ese nodo de contexto.
has-arc-in NODO ARCO
Verifica que existe una tripleta con NODO como sujeto y ARCO como predicado.
has-arc-out NODO ARCO
Verifica que existe una tripleta con NODO como objeto y ARCO como predicado.
parse URI|NOMBREARCHIVO [SINTAXIS| [BASE URI]]
Analiza la sintaxis en URI en el grafo usando SINTAXIS, que puede ser una de rdfxml (RDF/XML, predeterminado), ntriples, turtle, rss-tag-soup (para todos los RSS y Atom), grddl y guess para usar pistas de contenido e información de protocolo para determinarla. (Esta lista cambia más rápido que esta página de manual) Si NOMBREARCHIVO es un archivo existente, se generará la URI apropiada para él. Si el análisis produce errores, el código de retorno será distinto de 0.
parse-stream URI|NOMBREARCHIVO [SINTAXIS [BASE URI [CONTEXTO]]
Análisis en streaming de la sintaxis en la URI al grafo usando SINTAXIS, que puede ser una de rdfxml (RDF/XML, predeterminado) o ntriples. Si NOMBREARCHIVO es un archivo existente, se generará la URI apropiada para él. Si se proporciona la URI de CONTEXTO opcional, se agregarán las triplas a ese contexto. Si el análisis produce errores, el código de retorno será distinto de 0.
print
Imprime las triplas del grafo en un formato simple que muestra nodos de contexto si están presentes.
query NOMBRE|- URI|- CADENA-CONSULTA
Ejecuta la consulta CADENA-CONSULTA en el idioma NOMBRE devolviendo enlaces de variables, un booleano o un grafo RDF dependiendo de la consulta. El idioma de consulta puede ser 'sparql' o 'rdql'.
remove SUJETO PREDICADO OBJETO [CONTEXTO]
Elimina el grafo de tripleta dado, en el contexto opcional de Redland si se proporciona CONTEXTO.
remove-context CONTEXTO
Elimina todas las triplas del grafo con el contexto de Redland CONTEXTO.
serialize

COMANDOS

about [URI]
Return information about the Redland library and the supported syntaxes, storage types, and URIs.
base URI
Set the base URI for resolving relative URIs in the input.
clear
Remove all statements from the current RDF store.
load [URI]
Load RDF triples from a file or URI. If no URI is given, read from standard input.
query [QUERY]
Execute an SPARQL query against the RDF graph. If no query is given, read from standard input. The query result is printed in a human-readable format.
read [SYNTAX [URI [MIME-TYPE]]]
Reads RDF triples from a file or URI and stores them in the current RDF store. The default syntax is RDF/XML (NAME "rdfxml", MIME Type "application/rdf/xml") if none of the above are given. Other alternatives are "ntriples" (no MIME Type).
serialize [SYNTAX [URI [MIME-TYPE]]]
Serializes the graph to a syntax with a particular ISYNTAX URI or Internet Media Type/MIME Type. The default is RDF/XML (NAME "rdfxml", MIME Type "application/rdf/xml") if none of the above are given. Other alternatives are "ntriples" (no MIME Type).
source PREDICATE OBJECT
sources PREDICATE OBJECT
Show one node/all nodes that match triples (?, PREDICATE, OBJECT)
target SUBJECT PREDICATE
targets SUBJECT PREDICATE
Show one node/all nodes that match triples (SUBJECT, PREDICATE, ?)

AMBIENTE

RDFPROC_STORAGE_OPTIONS puede ser establecido para proporcionar opciones de almacenamiento en lugar de usar la opción -t, --storage-options OPTIONS. Cuando ambos son dados, las opciones del comando se aplican al final.

RDFPROC_STORAGE_TYPE puede ser establecido para proporcionar un tipo de almacenamiento en lugar de usar la opción -s, --storage TYPE. Cuando ambos son dados, se usa el tipo de almacenamiento del comando.
