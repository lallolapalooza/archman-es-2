RDMA_SET_LOCAL_ECE(3) Manual del programador de Librdmacm RDMA_SET_LOCAL_ECE(3)

NOMBRE

rdma_set_local_ece - Establece los parámetros ECE locales que se utilizarán para la comunicación REQ/REP.

SINOPSIS

#include <rdma/rdma_cma.h>
int rdma_set_local_ece(struct rdma_cm_id *id, struct ibv_ece *ece);

DESCRIPCIÓN

rdma_set_local_ece() establece los parámetros ECE locales.

Esta función debe ser utilizada por los usuarios de QPs externos. La llamada debe realizarse antes de responder al par y es necesaria para configurar RDMA_CM con las opciones ECE deseadas.

Al ser utilizado por un QP externo y dado que RDMA_CM no gestiona ese QP, el par deberá llamar a la API de libibverbs por sí mismo.

El flujo habitual para el lado pasivo será:

•
ibv_create_qp() <- crea el QP de datos.
•
ece = ibv_query_ece() <- obtiene el ECE del proveedor de libibverbs.
•
rdma_set_local_ece(ece) <- establece las opciones ECE deseadas.
•
rdma_connect() <- envía la solicitud de conexión
•
ece = rdma_get_remote_ece() <- obtiene las opciones ECE del par remoto
•
ibv_set_ece(ece) <- establece las opciones ECE locales con los datos recibidos del par.
•
ibv_modify_qp() <- habilita el QP de datos.
•
rdma_accept()/rdma_establish()/rdma_reject_ece()

ARGUMENTOS

id
Identificador de comunicación RDMA.
*ece
Parámetros ECE.

VALOR DE RETORNO

rdma_set_local_ece() devuelve 0 si tiene éxito, o -1 si hay un error. Si ocurre un error, errno se establecerá para indicar el motivo de la falla.

VER TAMBIÉN

rdma_cm(7), rdma_get_remote_ece(3)
