NOMBRE

rdma_post_sendv - publicar una solicitud de trabajo para enviar un mensaje.

SINOPSIS

#include <rdma/rdma_verbs.h>

int rdma_post_sendv (struct rdma_cm_id *id, void *context, struct ibv_sge *slg, int nsge, int flags);

ARGUMENTOS

id
Una referencia a un identificador de comunicación donde se publicará el búfer del mensaje.
contexto
Contexto definido por el usuario asociado con la solicitud.
slg
Una lista de dispersión/recolección de búferes de memoria publicados como una única solicitud.
nsge
El número de entradas de dispersión/recolección en el array slg.
flags
Banderas opcionales utilizadas para controlar la operación de envío.

DESCRIPCIÓN

Publica una solicitud de trabajo en la cola de envío del par de colas asociado con el rdma_cm_id. El contenido de los búferes publicados se enviará al par remoto de una conexión.

VALOR DE RETORNO

Devuelve 0 si tiene éxito, o -1 si hay un error. Si ocurre un error, errno se establecerá para indicar el motivo de la falla.

NOTAS

El usuario es responsable de asegurarse de que el par remoto haya puesto en cola una solicitud de recepción antes de emitir las operaciones de envío. Para obtener una lista de las banderas admitidas, consulte ibv_post_send. A menos que la solicitud de envío utilice datos en línea, los búferes del mensaje deben haberse registrado antes de publicarse, y los búferes deben permanecer registrados hasta que se complete el envío.

Las operaciones de envío no se pueden publicar en un rdma_cm_id o en el par de colas correspondiente hasta que se haya conectado.

El contexto definido por el usuario asociado con la solicitud de envío se devolverá al usuario a través del campo wr_id, identificador de la solicitud de trabajo, de la finalización del trabajo.
