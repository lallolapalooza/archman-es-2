NOMBRE

rdma-dev - configuración de dispositivos RDMA

SINOPSIS


rdma [ OPCIONES ] dev { COMANDO | help }

OPCIONES := { -V[ersion] | -d[etails] }

rdma dev show [ DEV ]

rdma dev set [ DEV ] name NUEVONOMBRE

rdma dev set [ DEV ] netns NOMBREN

rdma dev set [ DEV ] adaptive-moderation [on/off]

rdma dev add [ NOMBRE ] type [ TIPO ] parent [ DEV_PADRE ]

rdma dev delete [ NOMBRE ]

rdma dev help

DESCRIPCIÓN

rdma dev set - renombrar dispositivo RDMA o establecer espacio de nombres de red o establecer moderación adaptativa del dispositivo RDMA

rdma dev show - mostrar atributos del dispositivo RDMA

DEV - especifica el dispositivo RDMA a mostrar. Si se omite este argumento, se listarán todos los dispositivos.

rdma dev add - Añadir un dispositivo RDMA con un tipo y dispositivo padre IB específicos; este nuevo dispositivo proporciona un subconjunto de funcionalidades definidas en la especificación IBTA.

rdma dev delete - Eliminar un dispositivo RDMA que fue creado con el comando add.

NOMBRE - El nombre del dispositivo que se está añadiendo/eliminando.

TIPO - El tipo de dispositivo que se está añadiendo; especifica qué funcionalidades proporciona. Tipo de dispositivo compatible:


SMI - Un dispositivo con este tipo proporciona la interfaz SMI (QP0). Este dispositivo y su padre se asocian con el mismo puerto HCA y comparten el enlace físico, por lo que cuando el padre no admite SMI, se puede crear este tipo de dispositivo para permitir que el administrador de la subred configure el enlace.

DEV_PADRE - El nombre de su dispositivo IB padre.

EJEMPLOS

rdma dev

Muestra el estado de todos los dispositivos RDMA en el sistema.

rdma dev show mlx5_3

Muestra el estado del dispositivo RDMA especificado.

rdma dev set mlx5_3 name rdma_0

Renombra el dispositivo mlx5_3 a rdma_0.

rdma dev set mlx5_3 netns foo

Cambia el espacio de nombres de red del dispositivo RDMA a foo, donde foo se creó previamente usando el comando ip de iproute2.

rdma dev set mlx5_3 adaptive-moderation [on/off]

Establece el estado de la moderación adaptativa de interrupciones para el dispositivo RDMA.
Esta es una configuración global para el dispositivo RDMA, pero el valor se imprime para cada CQ individualmente porque el estado es constante desde la asignación del CQ.

rdma dev add smi1 type SMI parent ibp8s0f1

Añade un nuevo dispositivo IB con el nombre "smi1", tipo "SMI" y "ibp8s0f1" como su dispositivo padre.

rdma dev delete smi1

Elimina el dispositivo IB "smi1".
