RDMA_DEREG_MR(3) Manual del programador de Librdmacm RDMA_DEREG_MR(3)

NOMBRE

rdma_dereg_mr - anula el registro de una región de memoria registrada.

SINOPSIS

#include <rdma/rdma_verbs.h>

int rdma_dereg_mr (struct ibv_mr *mr);

ARGUMENTOS

mr
Una referencia a un búfer de memoria registrado.

DESCRIPCIÓN

Anula el registro de un búfer de memoria que se había registrado para operaciones RDMA o de mensajes. Un usuario debe llamar a rdma_dereg_mr para toda la memoria registrada asociada con un rdma_cm_id antes de destruir el rdma_cm_id.

VALOR DE RETORNO

Devuelve 0 si tiene éxito, o -1 si ocurre un error. Si ocurre un error, errno se establecerá para indicar el motivo del fallo.

NOTAS

Toda la memoria registrada con un rdma_cm_id está asociada con el dominio de protección asociado con el id. Los usuarios deben anular el registro de toda la memoria registrada antes de que se pueda destruir el dominio de protección.

VER TAMBIÉN
