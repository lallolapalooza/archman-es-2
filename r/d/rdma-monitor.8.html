NOMBRE

rdma-monitor - Monitorización de eventos RDMA

SINOPSIS


rdma [ OPCIONES ] monitor { help }

OPCIONES := { -V[ersion] }

rdma monitor

rdma monitor help

DESCRIPCIÓN

rdma monitor - la utilidad puede monitorizar eventos de dispositivos RDMA en todos los dispositivos RDMA.

rdma abre un socket Netlink RDMA, escucha en él y vuelca la información del evento.

Los tipos de eventos soportados son el registro/anulación de registro de dispositivos RDMA y la conexión/desconexión de dispositivos de red.

EJEMPLOS

rdma monitor

Escuchar eventos de todos los dispositivos RDMA
