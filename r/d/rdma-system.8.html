NOMBRE

rdma-system - configuración del subsistema RDMA

SINOPSIS


rdma [ OPCIONES ] sys { COMANDO | help }

OPCIONES := { -V[ersion] | -d[etails] }

rdma system show

rdma system set netns NUEVOMODO

rdma system set privileged-qkey NUEVOESTADO

rdma system help

DESCRIPCIÓN

rdma system set - establecer el modo de espacio de nombres de red del subsistema RDMA o

modo de clave privilegiada (qkey)

rdma system show - mostrar el modo de espacio de nombres de red del subsistema RDMA,

estado de la clave privilegiada y si la monitorización RDMA es compatible.

NUEVOMODO - especifica el modo del subsistema RDMA. Exclusivo o compartido. Cuando el usuario desea asignar un dispositivo RDMA dedicado a un espacio de nombres de red particular, el modo exclusivo debe establecerse antes de crear cualquier espacio de nombres de red. Si existen espacios de nombres de red activos y si existen uno o más dispositivos RDMA, cambiar el modo de compartido a exclusivo devuelve el código de error EBUSY.

Cuando el subsistema RDMA está en modo compartido, el dispositivo RDMA es accesible en todos los espacios de nombres de red. Cuando no se necesita aislamiento de dispositivos RDMA entre múltiples espacios de nombres de red, se puede usar el modo compartido.

Se prefiere no cambiar el modo del subsistema cuando hay tráfico RDMA activo en curso, aunque sea compatible.

NUEVOESTADO - especifica el nuevo estado del parámetro privileged-qkey (clave privilegiada), ya sea activado (on) o desactivado (off). Este parámetro determina si a un usuario no privilegiado se le permite especificar una QKEY controlada o no.

EJEMPLOS

rdma system show

Muestra el estado del modo del espacio de nombres de red del subsistema RDMA en el sistema, el estado del parámetro de clave privilegiada y si el monitor RDMA es compatible.

rdma system set netns exclusive

Establece el subsistema RDMA en modo exclusivo de espacio de nombres de red. En este modo, los dispositivos RDMA solo son visibles en un único espacio de nombres de red.

rdma system set netns shared

Establece el subsistema RDMA en modo compartido de espacio de nombres de red. En este modo, los dispositivos RDMA se comparten entre los espacios de nombres de red.

rdma system set privileged-qkey on

Establece el parámetro privileged-qkey en activado. En este estado, se permite a un usuario no privilegiado especificar una QKEY controlada.

rdma system set privileged-qkey off

Establece el parámetro privileged-qkey en desactivado. En este estado, a un usuario no privilegiado *no* se le permite especificar una QKEY controlada.
