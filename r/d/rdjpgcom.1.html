NOMBRE

rdjpgcom - mostrar comentarios de texto de un archivo JPEG

SINOPSIS

rdjpgcom [ -raw ] [ -verbose ] [ nombre_archivo ]

DESCRIPCIÓN

rdjpgcom lee el archivo JPEG/JFIF especificado, o la entrada estándar si no se nombra ningún archivo, y muestra en la salida estándar cualquier comentario de texto encontrado en el archivo.

El estándar JPEG permite que los bloques de "comentario" (COM) aparezcan dentro de un archivo JPEG. Aunque el estándar no define realmente para qué sirven los bloques COM, se usan ampliamente para almacenar cadenas de texto proporcionadas por el usuario. Esto le permite agregar anotaciones, títulos, términos de índice, etc., a sus archivos JPEG y recuperarlos posteriormente como texto. Los bloques COM no interfieren con la imagen almacenada en el archivo JPEG. El tamaño máximo de un bloque COM es de 64 KB, pero puede tener tantos como desee en un solo archivo JPEG.

OPCIONES

-raw
Normalmente rdjpgcom escapa los caracteres no imprimibles en los comentarios, por razones de seguridad. Esta opción lo evita.

-verbose Hace que rdjpgcom también muestre las dimensiones de la imagen JPEG.

Los nombres de las opciones se pueden abreviar y no distinguen entre mayúsculas y minúsculas.

PISTAS

rdjpgcom no depende de la biblioteca JPEG de IJG. Su código fuente está destinado a ilustrar la cantidad mínima de código requerida para analizar correctamente la cabecera de un archivo JPEG.

En el modo -verbose, rdjpgcom también intentará mostrar el contenido de cualquier marcador "APP12" como texto. Algunas cámaras digitales producen marcadores APP12 que contienen información textual útil. Si lo desea, puede modificar el código fuente para mostrar otros tipos de marcadores APPn también.
