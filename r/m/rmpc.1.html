rmpc(1) Manual de Comandos Generales rmpc(1)

NOMBRE

rmpc

SINOPSIS

rmpc [-c|--config] [-t|--theme] [-a|--address] [-p|--password] [--partition] [--autocreate] [-h|--help] [subcomandos]

DESCRIPCIÓN

OPCIONES

-c, --config=ARCHIVO
-t, --theme=ARCHIVO
-a, --address=DIRECCIÓN
Sobrescribe la dirección a la que conectarse. Por defecto, utiliza el valor del archivo de configuración.
-p, --password=CONTRASEÑA
Sobrescribe la contraseña de MPD.
--partition=PARTICIÓN
Partición a la que conectarse al iniciar.
--autocreate
Crea automáticamente la partición si no existe. Requiere que la partición esté configurada.
-h, --help
Imprime la ayuda.

SUBCOMANDOS

rmpc-addrandom(1)
rmpc-config(1)
Imprime la configuración por defecto. Se puede usar para iniciar el archivo de configuración.
rmpc-theme(1)
Imprime el tema por defecto. Se puede usar para iniciar el archivo de tema.
rmpc-lyricsindex(1)
Indexa el directorio de letras y muestra el resultado, solo para fines de depuración.
rmpc-update(1)
Escanea el directorio de música de MPD en busca de actualizaciones.
rmpc-rescan(1)
Escanea el directorio de música de MPD en busca de actualizaciones. También escanea archivos no modificados.
rmpc-albumart(1)
Guarda la portada del álbum actual en un archivo. Códigos de salida: * 0: Éxito * 1: Error * 2: No se encontró portada del álbum * 3: No hay canción sonando.
rmpc-debuginfo(1)
Imprime información sobre dependencias opcionales en tiempo de ejecución.
rmpc-version(1)
Imprime la versión de rmpc.
rmpc-queue(1)
Imprime la lista de canciones en la cola actual.
rmpc-listall(1)
Lista los archivos de la base de datos de música. Si no se especifica ningún archivo, lista todas las canciones en la base de datos.
rmpc-play(1)
Reproduce la canción en la posición de la lista de reproducción actual. Por defecto, la canción actual pausada.
rmpc-pause(1)
Pausa la reproducción.
rmpc-unpause(1)
Reanuda la reproducción.
rmpc-togglepause(1)
Alterna entre reproducir y pausar.
rmpc-stop(1)
Detiene la reproducción.
rmpc-next(1)
Reproduce la siguiente canción en la lista de reproducción.
rmpc-prev(1)
Reproduce la canción anterior en la lista de reproducción.
rmpc-volume(1)
Establece el volumen, relativo si se antepone con + o -. Imprime el volumen actual si no se proporcionan argumentos.
rmpc-repeat(1)
Activado o desactivado.
rmpc-random(1)
Activado o desactivado.
rmpc-single(1)
Activado, desactivado o una vez.
rmpc-consume(1)
Activado, desactivado o una vez.
rmpc-togglerepeat(1)
Alterna el modo de repetición.
rmpc-togglerandom(1)
Alterna el modo aleatorio.
rmpc-togglesingle(1)
Alterna el modo individual.
rmpc-toggleconsume(1)
Alterna el modo de consumo.
rmpc-seek(1)
Busca en la canción actual (segundos), relativo si se antepone con + o -.
rmpc-clear(1)
Borra la cola actual.
rmpc-add(1)
Añade una canción a la cola actual. Relativo a la raíz de la base de datos de música. '/' para añadir todos los archivos a la cola.
rmpc-addyt(1)
Añade una canción de YouTube a la cola actual.
rmpc-searchyt(1)
Busca y añade la primera coincidencia a la cola actual (YouTube por defecto).
rmpc-outputs(1)
Lista las salidas de MPD.
rmpc-toggleoutput(1)
Alterna la salida de MPD activada o desactivada.
rmpc-enableoutput(1)
Habilita la salida de MPD.
rmpc-disableoutput(1)
Deshabilita la salida de MPD.
rmpc-decoders(1)
Lista los plugins decodificadores de MPD.
rmpc-status(1)
Imprime diversa información, como el estado de reproducción.
rmpc-song(1)
Imprime información sobre la canción actual. Si se especifica --path, imprime información sobre la canción en la ruta dada. Si se especifica --path varias veces, imprime una matriz que contiene todas las canciones.
rmpc-mount(1)
Monta el almacenamiento compatible en MPD.
rmpc-unmount(1)
Desmonta el almacenamiento con el nombre dado.
rmpc-listmounts(1)
Lista los almacenamientos montados actualmente.
rmpc-listpartitions(1)
Lista las particiones existentes actualmente.
rmpc-sticker(1)
Manipula y consulta las pegatinas de canciones.
rmpc-remote(1)
Envía un comando remoto a una instancia de rmpc en ejecución.
rmpc-sendmessage(1)
Envía un mensaje a un canal dado para la comunicación entre clientes.
rmpc-help(1)
Imprime este mensaje o la ayuda de los subcomandos especificados.
