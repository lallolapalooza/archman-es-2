RMCP(8) Manual del Administrador del Sistema RMCP(8)

NOMBRE

rmcp - eliminar puntos de control de NILFS2

SINOPSIS

rmcp [opciones] [dispositivo] rango-de-puntos-de-control ...

DESCRIPCIÓN

rmcp es una utilidad para eliminar puntos de control del sistema de archivos NILFS2 que se encuentra en dispositivo. Los puntos de control que el usuario desea eliminar se especifican con uno o más rangos-de-puntos-de-control. Cuando se omite dispositivo, rmcp intenta encontrar un sistema de archivos NILFS2 en /proc/mounts.

El rango-de-puntos-de-control debe proporcionarse con uno o dos enteros de una de las siguientes maneras:

cno
número de punto de control único
inicio..fin
cada número de punto de control entre inicio y fin
..fin
cada punto de control igual o más reciente que fin
inicio..
cada punto de control igual o más antiguo que inicio

Este comando solo es válido para sistemas de archivos NILFS2 montados y fallará si el dispositivo no tiene montajes activos.

OPCIONES

-f, --force
Ignorar instantáneas o puntos de control inexistentes.
-i, --interactive
Preguntar antes de cualquier eliminación.
-h, --help
Mostrar mensaje de ayuda y salir.
-V, --version
Mostrar versión y salir.

AUTOR

DISPONIBILIDAD

rmcp es parte del paquete nilfs-utils y está disponible en https://nilfs.sourceforge.io.

VER TAMBIÉN

nilfs(8), lscp(1), mkcp(8), chcp(8), nilfs-tune(8).
