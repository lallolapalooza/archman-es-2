RMMOD(8) rmmod RMMOD(8)

NOMBRE

rmmod - Programa simple para eliminar un módulo del Kernel de Linux

SINOPSIS

rmmod [OPCIONES] [lista de nombres de módulo]

DESCRIPCIÓN

rmmod es un programa trivial para eliminar un módulo o una lista de módulos del kernel (cuando se proporciona soporte para la descarga de módulos). La mayoría de los usuarios querrán usar modprobe(8) con la opción -r en su lugar, ya que también elimina los módulos dependientes no utilizados.

Cuando se proporciona una lista de módulos, el programa los procesará uno a uno. Si no se encuentra un módulo, rmmod saldrá inmediatamente con un código de error. Si la eliminación del módulo falla, el programa registrará un error Y continuará con el siguiente módulo. Este comportamiento NO está controlado por la opción --force.

OPCIONES

-f, --force

Esta opción puede ser extremadamente peligrosa: no tiene efecto a menos que CONFIG_MODULE_FORCE_UNLOAD se haya configurado al compilar el kernel. Con esta opción, puedes eliminar módulos que se estén utilizando, o que no estén diseñados para ser eliminados, o que se hayan marcado como inseguros (ver lsmod(8)).

-s, --syslog

Envía errores a syslog en lugar del error estándar.

-v, --verbose

Imprime mensajes sobre lo que está haciendo el programa. Normalmente rmmod solo imprime mensajes si algo va mal.

-V, --version

Muestra la versión del programa y sale.

-h, --help

Imprime el mensaje de ayuda y sale.
