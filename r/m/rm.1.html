RM(1) Comandos de usuario RM(1)

NOMBRE

rm - eliminar archivos o directorios

SINOPSIS

rm [OPCIÓN]... [ARCHIVO]...

DESCRIPCIÓN

Esta página del manual documenta la versión GNU de rm. rm elimina cada archivo especificado. Por defecto, no elimina directorios.

Si se da la opción -I o --interactive=once, y hay más de tres archivos o se dan las opciones -r, -R o --recursive, entonces rm pregunta al usuario si desea continuar con toda la operación. Si la respuesta no es afirmativa, se cancela todo el comando.

En caso contrario, si un archivo no es grabable, la entrada estándar es una terminal y la opción -f o --force no se da, o la opción -i o --interactive=always se da, rm pregunta al usuario si desea eliminar el archivo. Si la respuesta no es afirmativa, el archivo se omite.

OPCIONES

Elimina (desenlaza) los ARCHIVO(s).

-f, --force
ignora archivos y argumentos inexistentes, nunca pregunta
-i
pregunta antes de cada eliminación
-I
pregunta una vez antes de eliminar más de tres archivos, o al eliminar recursivamente; menos intrusivo que -i, mientras que aún proporciona protección contra la mayoría de los errores
--interactive[=CUÁNDO]
pregunta de acuerdo con CUÁNDO: never, once (-I), o always (-i); sin CUÁNDO, pregunta siempre
--one-file-system
al eliminar una jerarquía recursivamente, omite cualquier directorio que esté en un sistema de archivos diferente al del argumento de línea de comandos correspondiente
--no-preserve-root
no trata '/' especialmente
--preserve-root[=all]
no elimina '/' (por defecto); con 'all', rechaza cualquier argumento de línea de comandos en un dispositivo separado de su padre
-r, -R, --recursive
elimina directorios y su contenido recursivamente
-d, --dir
elimina directorios vacíos
-v, --verbose
explica lo que se está haciendo
--help
muestra esta ayuda y sale
--version
muestra información de versión y sale

Por defecto, rm no elimina directorios. Usa la opción --recursive (-r o -R) para eliminar también cada directorio listado, junto con todo su contenido.

Cualquier intento de eliminar un archivo cuyo último componente del nombre de archivo sea '.' o '..' se rechaza con un diagnóstico.

Para eliminar un archivo cuyo nombre comience con un '-', por ejemplo '-foo', usa uno de estos comandos:

rm -- -foo
rm ./-foo

Si usas rm para eliminar un archivo, es posible recuperar parte de su contenido, con la experiencia y/o el tiempo suficientes. Para mayor seguridad de que el contenido no es recuperable, considera usar shred(1).

    SINÓPSIS

    rm [OPCIÓN]... [ARCHIVO]...

    DESCRIPCIÓN

    Elimina archivos o directorios.

    OPCIONES

    -f, --force
    ignora los archivos y argumentos que no existen, y nunca se pedirá confirmación.
    -i, --interactive
    pide confirmación antes de cada eliminación.
    -I
    pide confirmación una vez antes de eliminar más de tres archivos, o cuando se elimina de forma recursiva.
    -r, -R, --recursive
    elimina directorios y su contenido de forma recursiva.
    -d, --dir
    elimina los directorios directorios especificados, sólo si están vacíos.
    -v, --verbose
    explica lo que se está haciendo.
    --help
    muestra este mensaje y sal.
    --version
    muestra información sobre la versión y sal.

    EJEMPLOS

    Eliminar un archivo:

    rm archivo.txt

    Eliminar varios archivos:

    rm archivo1.txt archivo2.txt

    Eliminar un archivo de forma interactiva:

    rm -i archivo.txt

    Eliminar un directorio y su contenido de forma recursiva:

    rm -r directorio
