RMCPING(8) Comandos del Administrador del Sistema RMCPING(8)

NOMBRE

rmcpping - envía un Ping RMCP a hosts de red

SINOPSIS

rmcpping [OPCIÓN...] destino

DESCRIPCIÓN

rmcpping utiliza el datagrama de solicitud RMCP Ping para obtener una respuesta RMCP Pong de un host remoto. La utilidad puede ser utilizada para verificar si un host remoto soporta RMCP o IPMI. El número de secuencia inicial se aleatorizará. rmcpping devolverá 0 al entorno si recibe al menos 1 respuesta del host remoto. De lo contrario, saldrá con un valor de 1.

OPCIONES

Las siguientes opciones están disponibles:

-h
Muestra el menú de ayuda.
-V
Muestra la versión.
-c cuenta
Detenerse después de enviar cuenta paquetes.
-i intervalo
Espera intervalo segundos entre el envío de cada paquete. El valor predeterminado es esperar un segundo entre cada paquete.
-I dirección_interfaz
Establece la dirección de origen a la dirección de la interfaz especificada. El argumento puede ser una dirección IP numérica o el nombre del dispositivo.
-t tiempo_de_espera
Tiempo de espera para una respuesta, en segundos. El valor predeterminado es cinco segundos.
-v
Salida detallada.
-s num
Especifica un número de secuencia inicial. El valor predeterminado es usar un número de secuencia inicial aleatorio.
-d
Activa la depuración.

PROBLEMAS CONOCIDOS

Se ha observado que algunos BMC remotos pueden "confundirse" y retrasar las respuestas de los paquetes si se envían paquetes duplicados (con números de secuencia duplicados) muy rápidamente en sucesión. No se conoce una forma limpia de tratar con un BMC "confundido" aparte de esperar un tiempo.

A diferencia de ping(8), los dispositivos de red locales (por ejemplo, 127.0.0.1) no pueden ser "pingueados".
