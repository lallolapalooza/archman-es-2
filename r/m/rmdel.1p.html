RMDEL(1P) Manual del programador de POSIX RMDEL(1P)

PROLOG

Esta página del manual forma parte del Manual del programador de POSIX. La implementación de Linux de esta interfaz puede diferir (consulte la página del manual de Linux correspondiente para conocer los detalles del comportamiento de Linux), o la interfaz puede no estar implementada en Linux.

NOMBRE

rmdel — eliminar un delta de un archivo SCCS (DESARROLLO)

SINOPSIS

rmdel -r SID archivo...

DESCRIPCIÓN

La utilidad rmdel eliminará el delta especificado por el SID del archivo SCCS especificado. El delta a eliminar será el delta más reciente de su rama en la cadena de deltas de cada archivo SCCS nombrado. Además, la aplicación deberá asegurarse de que el SID especificado no sea el de una versión que se esté editando con el propósito de crear un delta; es decir, si existe un p-file (ver get) para el archivo SCCS nombrado, el SID especificado no aparecerá en ninguna entrada del p-file.

La eliminación de un delta estará restringida a:

1.
El usuario que creó el delta
2.
El propietario del archivo SCCS
3.
El propietario del directorio que contiene el archivo SCCS

OPCIONES

La utilidad rmdel se ajustará a las Definiciones Base del volumen de POSIX.1‐2017, Sección 12.2, Guías de sintaxis de utilidades.

Se admitirá la siguiente opción:

-r SID
Especifica la cadena de identificación SCCS (SID) del delta a eliminar.

OPERANDOS

Se admitirá el siguiente operando:

archivo
Una ruta a un archivo SCCS existente o a un directorio. Si archivo es un directorio, la utilidad rmdel se comportará como si cada archivo en el directorio se especificara como un archivo nombrado, excepto que los archivos no SCCS (el último componente de la ruta no comienza con s.) y los archivos ilegibles serán ignorados silenciosamente.

Si aparece exactamente un operando archivo, y este es '-', se leerá la entrada estándar; cada línea de la entrada estándar se tomará como el nombre de un archivo SCCS que se procesará. Los archivos no SCCS y los archivos ilegibles serán ignorados silenciosamente.

STDIN

La entrada estándar será un archivo de texto utilizado solo cuando el operando archivo se especifica como '-'. Cada línea del archivo de texto se interpretará como una ruta SCCS.

ARCHIVOS DE ENTRADA

Los archivos SCCS serán archivos de formato no especificado.

VARIABLES DE ENTORNO

Las siguientes variables de entorno afectarán la ejecución de rmdel:

LANG
Proporciona un valor predeterminado para las variables de internacionalización que no están establecidas o están vacías. (Consulte el volumen de Definiciones Base de POSIX.1‐2017, Sección 8.2, Variables de internacionalización para conocer la precedencia de las variables de internacionalización utilizadas para determinar los valores de las categorías de localización).
LC_ALL
Si se establece en una cadena de valor no vacía, anula los valores de todas las demás variables de internacionalización.
LC_CTYPE
Determina la localización para la interpretación de secuencias de bytes de datos de texto como caracteres (por ejemplo, caracteres de un solo byte frente a caracteres multibyte en argumentos y archivos de entrada).
LC_MESSAGES

Determina la localización que debe utilizarse para afectar el formato y el contenido de los mensajes de diagnóstico escritos en el error estándar.
NLSPATH
Determina la ubicación de los catálogos de mensajes para el procesamiento de LC_MESSAGES.

EVENTOS ASÍNCRONOS

Predeterminado.

STDOUT

No se utiliza.

STDERR

La salida estándar se utilizará únicamente para mensajes de diagnóstico.

ARCHIVOS DE SALIDA

Los archivos SCCS serán archivos de formato no especificado. Durante el procesamiento de un archivo, se puede crear y eliminar un x-file temporal, como se describe en admin; se puede crear y eliminar un z-file de bloqueo, como se describe en get.

Ninguna.

ESTADO DE SALIDA

Se devolverán los siguientes valores de salida:

 0
Finalización exitosa.
>0
Ocurrió un error.
