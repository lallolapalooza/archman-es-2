RMIREGISTRY(1) Comandos de JDK RMIREGISTRY(1)

NOMBRE

rmiregistry - crea e inicia un registro de objetos remotos en el puerto especificado en el host actual

SINOPSIS

rmiregistry [opciones] [puerto]

opciones
Representa la opción para el comando rmiregistry. Ver OPCIONES
puerto
El número de un puerto en el host actual en el que iniciar el registro de objetos remotos.

DESCRIPCIÓN

El comando rmiregistry crea e inicia un registro de objetos remotos en el puerto especificado en el host actual. Si se omite el puerto, el registro se inicia en el puerto 1099. El comando rmiregistry no produce ninguna salida y normalmente se ejecuta en segundo plano, por ejemplo:

rmiregistry &

Un registro de objetos remotos es un servicio de nomenclatura de arranque que utilizan los servidores RMI en el mismo host para enlazar objetos remotos a nombres. Los clientes en hosts locales y remotos pueden buscar objetos remotos y realizar invocaciones de métodos remotos.

El registro se utiliza típicamente para localizar el primer objeto remoto sobre el que una aplicación necesita llamar a métodos. Ese objeto luego proporciona soporte específico de la aplicación para encontrar otros objetos.

Los métodos de la clase java.rmi.registry.LocateRegistry se utilizan para obtener un registro que opera en el host local o en el host y puerto locales.

Los métodos basados en URL de la clase java.rmi.Naming operan en un registro y se pueden utilizar para:

•
Enlazar el nombre especificado a un objeto remoto
•
Devolver una matriz de los nombres enlazados en el registro
•
Devolver una referencia, un stub, para el objeto remoto asociado con el nombre especificado
•
Reenlazar el nombre especificado a un nuevo objeto remoto
•
Destruir el enlace para el nombre especificado asociado con un objeto remoto

OPCIONES

-Jopción
Se utiliza con cualquier opción de Java para pasar la opción que sigue a -J (sin espacios entre -J y la opción) al intérprete de Java.
