rmdir(2) Manual de llamadas al sistema rmdir(2)

NOMBRE

rmdir - eliminar un directorio

BIBLIOTECA

Biblioteca C estándar (libc, -lc)

SINOPSIS

#include <unistd.h>
int rmdir(const char *path);

DESCRIPCIÓN

rmdir() elimina un directorio, el cual debe estar vacío.

VALOR DE RETORNO

En caso de éxito, se devuelve cero. En caso de error, se devuelve -1 y errno se establece para indicar el error.

ERRORES

EACCES
No se permitió el acceso de escritura al directorio que contiene path, o uno de los directorios en el prefijo de ruta de path no permitió permisos de búsqueda. (Ver también path_resolution(7)).
EBUSY
path está siendo utilizado actualmente por el sistema o algún proceso que impide su eliminación. En Linux, esto significa que path se utiliza actualmente como punto de montaje o es el directorio raíz del proceso que llama.
EFAULT
path apunta fuera de su espacio de direcciones accesible.
EINVAL
path tiene . como último componente.
ELOOP
Se encontraron demasiados enlaces simbólicos al resolver path.
ENAMETOOLONG
path era demasiado largo.
ENOENT
Un componente del directorio en path no existe o es un enlace simbólico colgante.
ENOMEM
No había suficiente memoria del kernel disponible.
ENOTDIR
path, o un componente utilizado como directorio en path, no es, de hecho, un directorio.
ENOTEMPTY
path contiene entradas distintas de . y ..; o, path tiene .. como su último componente. POSIX.1 también permite EEXIST para esta condición.
EPERM
El directorio que contiene path tiene el bit "sticky" (S_ISVTX) establecido y el ID de usuario efectivo del proceso no es ni el ID de usuario del archivo a eliminar ni el del directorio que lo contiene, y el proceso no tiene privilegios (Linux: no tiene la capacidad CAP_FOWNER).
EPERM
El sistema de archivos que contiene path no admite la eliminación de directorios.
EROFS
path se refiere a un directorio en un sistema de archivos de solo lectura.

ESTÁNDARES

POSIX.1-2024.

HISTORIA

POSIX.1-2001, SVr4, 4.3BSD.

ERRORES CONOCIDOS

Las infelicidades en el protocolo subyacente de NFS pueden causar la desaparición inesperada de directorios que todavía se están utilizando.

VER TAMBIÉN

rm(1), rmdir(1), chdir(2), chmod(2), mkdir(2), rename(2), unlink(2), unlinkat(2)
