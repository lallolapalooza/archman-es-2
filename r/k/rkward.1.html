RKWARD(1) Manual de usuario de RKWard RKWARD(1)

NOMBRE

rkward - Una interfaz gráfica de KDE para R

SINOPSIS

rkward [--evaluate código_R] [--debug-level nivel] [--debug-flags flags] [--debug-output dónde] [--backend-debugger comando_debugger] [--r-executable ruta_al_ejecutable] [--reuse] [--autoreuse] [--nowarn-external] [Opciones Generales de KDE] [Opciones Generales de Qt] [archivos_a_abrir]

DESCRIPCIÓN

RKWard es la GUI y IDE basada en KDE para el lenguaje de scripting R para computación estadística.

Para más información, por favor consulte el sitio web de RKWard[1], y la documentación proporcionada dentro de RKWard.

OPCIONES

--evaluate código_R

El código R dado se evaluará después de que RKWard haya arrancado, y después de que cualquier espacio de trabajo especificado sea cargado. Principalmente útil para pruebas automatizadas.

--debug-level nivel

Verbosidad de la salida de depuración. 0-5, donde 0 es sin salida, 5 es toda la salida incluyendo información de traza de funciones. El valor por defecto es 2.

--debug-output dónde

A dónde enviar la salida de depuración. El valor por defecto es almacenarla en un archivo en el directorio temporal. Especificar "terminal" escribirá la salida de depuración en stderr, en su lugar (útil para depurar problemas de inicio). Tenga en cuenta que la salida de depuración del proceso backend siempre se almacena en un archivo.

--debug-flags flags

Configura qué secciones de código depurar. Las flags se dan como un número binario. Consulte los archivos fuente para obtener documentación, ya que esta es realmente una opción interna.

--backend-debugger comando

Ejecuta el backend de RKWard a través del comando de depuración especificado. Para añadir opciones de línea de comandos al comando del depurador, enciérralas entre comillas simples (') junto con el comando. NOTA: Los argumentos del depurador se dividirán por espacios. Si esto no es apropiado, tendrá que escribir su propio script de envoltura para invocar al depurador. Además, asegúrese de redirigir toda la salida y/o entrada del depurador según corresponda. Consulte los ejemplos.

--r-executable comando

En caso de varias instalaciones de R, especifique la instalación a usar, por ejemplo, /usr/bin/R. También puede usar la cadena "auto", en cuyo caso RKWard intentará encontrar R en una de las rutas de instalación estándar conocidas. NOTA que aunque RKWard funcionará a menudo con versiones más recientes de R, a veces necesitará ser recompilado para esa versión, o puede ser incompatible por completo.

Esta opción cambia la instalación de R solo para la sesión actual, no de forma persistente.

--reuse

Si una instancia de RKWard ya se está ejecutando, llévela al frente y abra archivos_a_abrir. Tenga en cuenta que todas las demás opciones de línea de comandos serán ignoradas en caso de que se reutilice una instancia.

--autoreuse

Se comporta como --reuse, si también se proporcionan argumentos de archivo, inicia una nueva instancia, de lo contrario. Previsto para su uso en el archivo .desktop.

--nowarn-external

Normalmente, al invocar plugins de RKWard desde la línea de comandos (es decir, cuando archivos_a_abrir contiene URLs de la forma rkward://runplugin/...), RKWard mostrará una advertencia de que dichas URLs podrían usarse para desencadenar acciones maliciosas en su sistema. Esta advertencia se aplica específicamente a los enlaces que se encuentran en sitios web no confiables u otras fuentes externas no confiables. Si desea escribir scripts para RKWard localmente, puede evitar esta advertencia añadiendo --nowarn-external a la línea de comandos.

(Si se usa en combinación con --reuse, entonces *ambos* comandos en cuestión necesitarán ser invocados con --nowarn-external, para suprimir la advertencia.)

--setup

Actúa como si se hubiera instalado una nueva versión de RKWard, importando reinstalar el paquete de soporte de R, y mostrando el asistente de configuración. Esta característica está dirigida principalmente a desarrolladores y probadores.

--quirkmode

Desactiva parte del código de validación de inicio. Opción experimental, no destinada a un uso regular.

archivos_a_abrir

Puede especificar cualquier número de nombres de archivo o URLs para que RKWard los abra. Normalmente, serán archivos de espacio de trabajo, archivos de lugar de trabajo, archivos de script R o URLs rkward:// (por ejemplo, para iniciar con un diálogo de plugin). Especificar más de un archivo de espacio de trabajo llevará a que los espacios de trabajo se fusionen, y no se recomienda.

VER TAMBIÉN

R(1)

EJEMPLOS

# Iniciar con el diálogo de la prueba t
rkward --nowarn-external rkward://runplugin/rkward::t_test/
# Abrir dos archivos de script en una instancia en ejecución de RKWard (o en una instancia nueva, si RKWard no está en ejecución)
rkward --reuse file_a.R file_b.R
# Ejecutar el backend de rkward a través de valgrind
rkward --backend-debugger 'valgrind --log-file=valgrind.log'
