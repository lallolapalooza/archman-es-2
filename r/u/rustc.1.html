RUSTC(1) Comandos de usuario RUSTC(1)

NOMBRE

rustc - El compilador de Rust

SINOPSIS

rustc [OPCIONES] ENTRADA

DESCRIPCIÓN

Este programa es un compilador para el lenguaje Rust, disponible en https://www.rust-lang.org.

OPCIONES

-h, --help
Mostrar el mensaje de ayuda.
--cfg ESPEC
Configurar el entorno de compilación.
-L [TIPO=]RUTA
Añadir un directorio a la ruta de búsqueda de bibliotecas. El TIPO opcional puede ser uno de:
dependency
solo buscar dependencias transitivas aquí
crate
solo buscar directivas locales de `extern crate` aquí
native
solo buscar bibliotecas nativas aquí
framework
solo buscar frameworks de OSX aquí
all
buscar cualquier cosa aquí (por defecto)
-l [TIPO=]NOMBRE
Enlazar el (los) crate(s) generado(s) a la biblioteca especificada NOMBRE. El TIPO opcional puede ser static, dylib o framework. Si se omite, se asume dylib.
--crate-type [bin|lib|rlib|dylib|cdylib|staticlib|proc-macro]
Lista separada por comas de los tipos de crates que emitirá el compilador.
--crate-name NOMBRE
Especificar el nombre del crate que se está construyendo.
--emit [asm|llvm-bc|llvm-ir|obj|metadata|link|dep-info|mir][=RUTA]
Configurar la salida que rustc producirá. Cada emisión puede también tener una RUTA de salida explícita opcional especificada para ese tipo particular de emisión. Esta ruta tiene prioridad sobre la opción -o.
--print [crate-name|file-names|sysroot|target-libdir|cfg|target-list|target-cpus|target-features|relocation-models|code-models|tls-models|target-spec-json|native-static-libs|stack-protector-strategies|link-args]
Lista separada por comas de la información del compilador para imprimir en la salida estándar.
-g
Equivalente a -C debuginfo=2.
-O
Equivalente a -C opt-level=2.
-o NOMBRE_ARCHIVO
Escribir la salida en NOMBRE_ARCHIVO. Ignorado si se especifican múltiples salidas --emit que no tienen una ruta explícita de lo contrario.
--out-dir DIR
Escribir la salida en un nombre de archivo elegido por el compilador en DIR. Ignorado si se especifica -o. Por defecto, es el directorio actual.
--explain OPT
Proporcionar una explicación detallada de un mensaje de error.
--test
Construir un marco de pruebas.
--target TARGET
Triple de destino para la cual se compila el código. Esta opción tiene como valor predeterminado la triple de destino del host. La triple de destino tiene el formato general <arch><sub>-<vendor>-<sys>-<abi>, donde:
<arch>
x86, arm, thumb, mips, etc.
<sub>
por ejemplo en ARM: v5, v6m, v7a, v7m, etc.
<vendor>
pc, apple, nvidia, ibm, etc.
<sys>
none, linux, win32, darwin, cuda, etc.
<abi>
eabi, gnu, android, macho, elf, etc.
-W help
Imprimir opciones de 'lint' y configuraciones predeterminadas.
-W OPT, --warn OPT
Establecer advertencias de lint.
-A OPT, --allow OPT
Permitir lint.
-D OPT, --deny OPT
Denegar lint.
-F OPT, --forbid OPT
Prohibir lint.
-C FLAG[=VAL], --codegen FLAG[=VAL]
Establecer un flag relacionado con la generación de código al valor especificado. Usar -C help para imprimir los flags disponibles. Ver OPCIONES DE CODEGEN a continuación.
-V, --version
Imprimir información de la versión y salir.
-v, --verbose
Usar salida detallada.
--remap-path-prefix de=a
Remapear prefijos de ruta de origen en toda la salida, incluyendo diagnósticos del compilador, información de depuración, expansiones de macros, etc. El parámetro de=a se escanea de derecha a izquierda, por lo que de puede contener '=', pero a no puede.

Esto es útil para normalizar productos de construcción, por ejemplo, eliminando el directorio actual de los nombres de archivo emitidos en los archivos objeto. El reemplazo es puramente textual, sin tener en cuenta la sintaxis de nombres de archivo del sistema actual. Por ejemplo --remap-path-prefix foo=bar coincidirá con foo/lib.rs pero no con ./foo/lib.rs.

--extern NOMBRE=RUTA
Especificar la ubicación de una biblioteca de Rust externa. Estas deben coincidir con las declaraciones extern en el código fuente del crate.
--sysroot RUTA
Sobrescribir la raíz del sistema.
-Z FLAG
Establecer opciones inestables / permanentemente inestables. Usar -Z help para imprimir las opciones disponibles.
--color auto|always|never
Configurar el coloreado de la salida:
auto
colorear, si la salida va a un tty (por defecto);
always
colorear siempre la salida;
never
nunca colorear la salida.

OPCIONES DE CODEGEN

linker=/ruta/a/cc
Ruta a la utilidad de enlazador para usar al enlazar bibliotecas, ejecutables y objetos.
link-args='-flag1 -flag2'
Una lista separada por espacios de argumentos adicionales a pasar al enlazador cuando se invoca.
lto
Realizar optimizaciones de tiempo de enlazado LLVM.
target-cpu=help
Selecciona un procesador de destino. Si el valor es 'help', se imprimirá una lista de las CPUs disponibles.
target-feature='+feature1,-feature2'
Una lista separada por comas de características a habilitar o deshabilitar para el destino. Un '+' precedente habilita una característica mientras que un '-' precedente la deshabilita. Las características disponibles se pueden descubrir a través de llc -mcpu=help.
passes=val
Una lista separada por espacios de pases LLVM adicionales a ejecutar. Un valor de 'list' hará que rustc imprima todos los pases conocidos y salga. Los pases especificados se añaden al final del gestor de pases normal.
llvm-args='-arg1 -arg2'
Una lista separada por espacios de argumentos a pasar a LLVM.
save-temps
Guardar los archivos intermedios de compilación.

NAME

rustc — Rust compiler

SYNOPSIS

rustc [OPTIONS] [SRC...]

DESCRIPTION

The rustc command compiles Rust source files. It can produce executables, libraries, and object files. When invoked without any arguments, it prints usage information.

The compiler can be configured by passing arguments that resemble command-line flags. These flags are recognized by the compiler itself when it is run, and are not passed to the linker unless explicitly stated.

OPTIONS

-o output
Place the output into output.
--crate-name name
Specifies the name of the crate being compiled.
--crate-type type
Specifies the type of crate being compiled. Can be specified multiple times. Possible values include:
bin
Generate an executable (default).
lib
Generate a library.
rlib
Generate a static library, suitable for linking into other Rust binaries.
dylib
Generate a dynamic library.
cdylib
Generate a dynamic library suitable for use in other languages.
staticlib
Generate a static library suitable for use in other languages.
proc-macro
Generate a procedural macro library.
-Z flag
This flag enables experimental compiler features. These features are unstable and may change or be removed without warning. Some of the options available via -Z include:
codegen-units=n
Divide crate into n units to optimize in parallel.
debuginfo=val
Debug info emission level:
0
no debug info;
1
line‐tables only (for stacktraces and breakpoints);
2
full debug info with variable and type information.
extra-filename=val
Extra data to put in each output filename.
metadata=val
Metadata to mangle symbol names with.
no-prepopulate-passes
Suppresses pre‐population of the LLVM pass manager that is run over the module.
no-stack-check
Disable checks for stack exhaustion (a memory‐safety hazard!).
no-integrated-as
Force usage of an external assembler rather than LLVM's integrated one.
no-redzone
Disable the use of the redzone.
no-vectorize-loops
Suppresses running the loop vectorization LLVM pass, regardless of optimization level.
no-vectorize-slp
Suppresses running the LLVM SLP vectorization pass, regardless of optimization level.
opt-level=VAL
Optimize with possible levels 0–3, s (optimize for size), or z (for minimal size)
prefer-dynamic
Prefers dynamic linking to static linking.
relocation-model=[pic,static,dynamic-no-pic]
The relocation model to use. (Default: pic)
remark=val
Print remarks for these optimization passes (space separated, or "all").
rpath
If specified, then the rpath value for dynamic libraries will be set in either dynamic library or executable outputs.
save-temps
If specified, the compiler will save more files (.bc, .o, .no-opt.bc) generated throughout compilation in the output directory.
soft-float
Generates software floating point library calls instead of hardware instructions.
--code-model=[small,kernel,medium,large]
Choose the code model to use.
-g
Generate debug information. Equivalent to -Z debuginfo=2.
-h, --help
Print help information.
-L path
Add a directory to the library search path.
-passes=path
Add a directory to the pass search path.
--target target
Compile for the given target architecture. The default is the host architecture. For a list of supported targets, see rustc --print target-list.
-V, --version
Print compiler version information.

ENVIRONMENT

Some of these affect only test harness programs (generated via rustc --test); others affect all programs which link to the Rust standard library.

RUST_TEST_THREADS
The test framework Rust provides executes tests in parallel. This variable sets the maximum number of threads used for this purpose. This setting is overridden by the --test-threads option.
RUST_TEST_NOCAPTURE
If set to a value other than "0", a synonym for the --nocapture flag.
RUST_MIN_STACK
Sets the minimum stack size for new threads.
RUST_BACKTRACE
If set to a value different than "0", produces a backtrace in the output of a program which panics.

EXAMPLES

To build an executable from a source file with a main function:
$ rustc -o hello hello.rs

To build a library from a source file:
$ rustc --crate-type=lib hello-lib.rs

To build either with a crate (.rs) file:
$ rustc hello.rs

To build an executable with debug info:
$ rustc -g -o hello hello.rs
