DESCRIPCIÓN

rubikrotation es un script de Perl para procesar rotaciones del cubo de Rubik (3x3x3 y 2x2x2). Es parte del paquete LaTeX rubikrotation y normalmente es LLAMADO por rubikrotation.sty, en respuesta al comando RubikRotation{}: consulte el manual del paquete (rubikrotation.pdf) para obtener detalles. El paquete rubikrotation forma parte del conjunto `bundle' de LaTeX Rubik. La última versión se puede descargar desde

CTAN: mirror.ctan.org/macros/latex/contrib/rubik/

rubikrotation lee datos de estado de Rubik y comandos (secuencia de rotaciones) de un archivo de entrada, y escribe los nuevos datos de estado en un archivo de salida. Los nombres de archivo de entrada y salida se pueden especificar como argumentos de línea de comandos (ver: uso en línea de comandos).

Si existe un archivo de configuración (rubikrotation.cfg) entonces será leído automáticamente por rubikrotation.sty.

USO EN LÍNEA DE COMANDOS

rubikrotation [-h|--help|-v|--version] [-o <salida>] -i <entrada>

-h muestra la información de ayuda y sale.

-v muestra la información de versión y sale.

-i define el nombre del archivo de entrada. El nombre del archivo de entrada predeterminado establecido por el paquete rubikrotation es rubikstate.dat, y este es generado por el comando LaTeX RubikRotation{} (ver el manual del paquete LaTeX rubikrotation rubikrotation.pdf). Tenga en cuenta que el script de Perl rubikrotation espera que el archivo de entrada tenga una cierta estructura, como se describe en rubikrotation.pdf y rubikrotationPL.pdf).

-o define el nombre del archivo de salida. Si no se proporciona ningún nombre de archivo de salida, se utiliza el nombre de archivo predeterminado rubikOUT.txt.
