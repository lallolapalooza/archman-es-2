NOMBRE

run-with-aspell - script para ayudar a usar GNU Aspell como reemplazo de ispell

SINOPSIS

run-with-aspell <comando>

DESCRIPCIÓN

La forma recomendada de usar Aspell como reemplazo para Ispell es cambiar el comando Ispell desde el programa que se esté utilizando. Si eso no es posible, el script run-with-aspell puede ser utilizado en su lugar.

OPCIONES

<comando>
es el nombre del programa con cualquier argumento opcional.

El método antiguo de mapear ispell a Aspell está desaconsejado porque puede crear problemas de compatibilidad con programas que realmente requieren ispell, como los propios scripts de ispell.

VER TAMBIÉN

aspell(1), aspell-import(1), word-list-compress(1)

Aspell está completamente documentado en su manual Texinfo. Vea la entrada `aspell' en info para una documentación más completa.
