runc-exec(8) Manual del Administrador del Sistema runc-exec(8)

NOMBRE

runc-exec - ejecuta un nuevo proceso dentro del contenedor

SINOPSIS

runc exec [opción ...] id-contenedor [--] comando [arg ...]

runc exec [opción ...] -p proceso.json id-contenedor

OPCIONES

--console-socket ruta
Ruta a un socket AF_UNIX que recibirá un descriptor de archivo que hace referencia al extremo maestro de la pseudoterminal de la consola. Ver docs/terminals ⟨https://github.com/opencontainers/runc/blob/master/docs/terminals.md⟩>.
--cwd ruta
Cambiar a ruta dentro del contenedor antes de ejecutar el comando.
--env|-e nombre=valor
Establecer una variable de entorno nombre a valor. Se puede especificar varias veces.
--tty|-t
Asignar una pseudo-TTY.
--user|-u uid[:gid]
Ejecutar el comando como un usuario (y, opcionalmente, grupo) especificado por uid (y gid).
--additional-gids|-g gid
Añadir identificadores de grupo adicionales. Se puede especificar varias veces.
--process|-p proceso.json
En lugar de especificar todos los parámetros de ejecución directamente en la línea de comandos, obtenerlos de un archivo proceso.json, un archivo JSON que contiene la especificación del proceso tal como se define en la especificación del runtime OCI ⟨https://github.com/opencontainers/runtime-spec/blob/master/config.md#process⟩>.
--detach|-d
Desconectarse del proceso del contenedor.
--pid-file ruta
Especificar el archivo donde escribir el PID del proceso del contenedor.
--process-label etiqueta
Establecer la etiqueta de proceso asm para el proceso, comúnmente utilizada con selinux(7).
--apparmor perfil
Establecer el perfil de apparmor(7) para el proceso.
--no-new-privs
Establecer el valor de "no nuevos privilegios" para el proceso.
--cap cap
Añadir una capacidad al conjunto de límites para el proceso. Se puede especificar varias veces.
--preserve-fds N
Pasar N descriptores de archivo adicionales al contenedor (stdio + $LISTEN_FDS + N en total). El valor predeterminado es 0.
--ignore-paused
Permitir la ejecución en un contenedor pausado. Por defecto, si un contenedor está pausado, runc exec devuelve un error; esta opción se puede utilizar para anularlo. Un contenedor pausado necesita ser reanudado para que la ejecución se complete.
--cgroup ruta | controlador[,controlador...]:ruta
Ejecutar un proceso en un sub-cgroup. Si el cgroup especificado no existe, se devuelve un error. El valor predeterminado es ruta vacía, lo que significa usar el cgroup de nivel superior del contenedor.

Para cgroup v1 solamente, se puede especificar un controlador particular (o múltiples controladores separados por comas), y la opción se puede usar varias veces para establecer diferentes rutas para diferentes controladores.

Nota para cgroup v2, en caso de que el proceso no pueda unirse al cgroup de nivel superior, runc exec recurre a intentar unirse al cgroup del init del contenedor. Esta recursión se puede deshabilitar usando --cgroup /.

ESTADO DE SALIDA

Sale con un estado de comando (a menos que se use -d), o 255 si ocurrió un error.

EJEMPLOS

Si el contenedor puede ejecutar el comando ps(1), lo siguiente mostrará una lista de procesos que se ejecutan dentro del contenedor:

# runc exec <id-contenedor> ps
