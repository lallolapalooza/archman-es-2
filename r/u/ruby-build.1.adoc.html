== Nombre

ruby-build - Descarga, compila e instala una versión de Ruby

== Sinopsis

ruby-build [-dvpk] _<definición>_ _<prefijo>_ [-- _<argumentos-configuración>_...] + ruby-build {--list|--definitions} + ruby-build --version

== Descripción

ruby-build descarga, compila e instala una versión de Ruby nombrada por el argumento _definición_ en la ubicación especificada por _prefijo_.

El argumento _definición_ puede empezar opcionalmente con "ruby-", en cuyo caso se resuelve a un CRuby que coincide con el número de versión que sigue.

El argumento _definición_ puede ser una ruta a un archivo en disco, en cuyo caso se carga en ruby-build como un script de bash.

Opcionalmente, se pueden listar argumentos adicionales de Ruby _configure-args_ después de "--" y se reenviarán a la invocación de `./configure`.

Por defecto, toda la salida de compilación se redirige a un archivo de registro en `$TMPDIR/ruby-build.*.log`. Activa el modo detallado para omitir el archivo de registro e imprimir todo en los flujos estándar.

== Opciones

*-l, --list*::
Lista las últimas versiones estables para cada Ruby

*--definitions*::
Lista todas las definiciones locales, incluyendo las obsoletas

*--version*::
Muestra la versión de ruby-build

*-d, --dir*::
Instala el Ruby en el destino _prefijo/definición_ en lugar de directamente en _prefijo_

*-v, --verbose*::
Modo detallado: reenvía toda la salida de compilación a stdout/stderr

*-p, --patch*::
Aplica un parche desde stdin antes de compilar

*-k, --keep*::
No elimina el árbol de fuentes después de la instalación

*-4, --ipv4*::
Resuelve nombres a direcciones IPv4 solamente

*-6, --ipv6*::
Resuelve nombres a direcciones IPv6 solamente

== Ejemplos

Instala una versión de Ruby mientras ajustas algunas opciones de configuración: ---- $ ruby-build 3.2.2 /ruta/al/destino -- --disable-install-doc --with-openssl-dir=/opt/openssl ----

Instala una versión de Ruby en `~/.rubies/ruby-3.2.2`: ---- $ ruby-build --dir ruby-3.2.2 ~/.rubies ----

Instala una versión de Ruby en `~/.rbenv/versions/3.3.5`: ---- $ ruby-build --dir 3.3.5 ~/.rbenv/versions ----

Uso como plugin de rbenv, logra lo mismo que el ejemplo anterior: ---- $ rbenv install 3.3.5 ----

== Variables de Entorno

*TMPDIR*::
La ubicación para escribir archivos temporales en disco

*RUBY_BUILD_BUILD_PATH* (por defecto: un subdirectorio con marca de tiempo de _TMPDIR_)::
La ubicación de compilación para descargar archivos fuente y compilar

*RUBY_BUILD_CACHE_PATH* (por defecto: "~/.rbenv/cache" si se invoca como plugin de rbenv)::
Dónde almacenar en caché los archivos de paquetes descargados

*RUBY_BUILD_HTTP_CLIENT* (por defecto: la primera herramienta encontrada en PATH)::
Uno de "aria2c", "curl" o "wget" para usar en la descarga

*RUBY_BUILD_ARIA2_OPTS*::
Opciones adicionales para pasar a aria2c para la descarga

*RUBY_BUILD_CURL_OPTS*::
Opciones adicionales para pasar a curl para la descarga

*RUBY_BUILD_WGET_OPTS*::
Opciones adicionales para pasar a wget para la descarga

*RUBY_BUILD_MIRROR_URL* (por defecto: un espejo patrocinado de Amazon CloudFront)::
URL raíz de espejo personalizado para descargar paquetes

*RUBY_BUILD_MIRROR_PACKAGE_URL*::
URL de espejo completa personalizada

*RUBY_BUILD_SKIP_MIRROR*::
Evita el espejo de descarga y recupera todos los archivos de paquetes de sus URLs originales

*RUBY_BUILD_ROOT* (por defecto: "share/ruby-build" dentro de la ubicación de instalación de ruby-build)::
Directorio de definiciones de compilación personalizado

*RUBY_BUILD_TARBALL_OVERRIDE*::
Sobrescribe la URL para obtener el archivo tarball de Ruby, opcionalmente seguido de "#<checksum>"

*RUBY_BUILD_DEFINITIONS*::
Rutas a buscar definiciones de compilación además de _RUBY_BUILD_ROOT_

*CC*::
Ruta al compilador C

*RUBY_CFLAGS*::
Opciones `CFLAGS` adicionales para usar en la compilación de Ruby

*CONFIGURE_OPTS*::
Argumentos adicionales de "./configure"

*MAKE* (por defecto: "make")::
Comando make personalizado (p. ej., "gmake")

*MAKE_OPTS*, *MAKEOPTS*::
Argumentos adicionales para "make"

*MAKE_INSTALL_OPTS*::
Argumentos adicionales para "make install"

*RUBY_CONFIGURE_OPTS*::
Argumentos adicionales de "./configure" que se aplican solo al código fuente de Ruby

*RUBY_MAKE_OPTS*::
Argumentos de make adicionales que se aplican solo al código fuente de Ruby

*RUBY_MAKE_INSTALL_OPTS*::
Argumentos adicionales de "make install" que se aplican solo al código fuente de Ruby

*NO_COLOR* (por defecto: permite colores cuando está conectado a terminal)::
Desactiva los colores ANSI en la salida

*CLICOLOR_FORCE*::
Usa colores ANSI en la salida incluso cuando no está conectado a una terminal
