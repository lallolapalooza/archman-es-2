NOMBRE

runc-state - mostrar el estado de un contenedor

SINOPSIS

runc state id-del-contenedor

DESCRIPCIÓN

El comando state muestra información sobre el estado actual del id-del-contenedor especificado en formato JSON.

VER TAMBIÉN

runc(8).
