NOMBRE

ruby-build - Descarga, compila e instala una versión de Ruby

SINOPSIS

ruby-build [-dvpk] <definición> <prefijo> [-- <argumentos-configuración>...]
ruby-build {--list|--definitions}
ruby-build --version

DESCRIPCIÓN

ruby-build descarga, compila e instala una versión de Ruby nombrada por el argumento definición en la ubicación especificada por prefijo.

El argumento definición puede comenzar opcionalmente con "ruby-", en cuyo caso se resuelve a un CRuby que coincide con el número de versión que sigue.

El argumento definición puede ser una ruta a un archivo en disco, en cuyo caso se fuentea en ruby-build como un script bash.

Opcionalmente, se pueden listar argumentos adicionales de Ruby para la configuración ("configure-args") después de "--" y se reenviarán a la invocación de ./configure.

Por defecto, toda la salida de compilación se redirige a un archivo de registro en $TMPDIR/ruby-build.*.log. Activa el modo detallado para omitir el archivo de registro e imprimir todo en los flujos estándar.

OPCIONES

-l, --list

Lista las últimas versiones estables para cada Ruby

--definitions

Lista todas las definiciones locales, incluidas las obsoletas

--version

Muestra la versión de ruby-build

-d, --dir

Instala el Ruby en el destino prefijo/definición en lugar de directamente en prefijo

-v, --verbose

Modo detallado: reenvía toda la salida de compilación a stdout/stderr

-p, --patch

Aplica un parche desde stdin antes de compilar

-k, --keep

No elimina el árbol de fuentes después de la instalación

-4, --ipv4

Resuelve nombres a direcciones IPv4 solamente

-6, --ipv6

Resuelve nombres a direcciones IPv6 solamente

EJEMPLOS

Instala una versión de Ruby mientras modificas algunas opciones de configuración:

$ ruby-build 3.2.2 /ruta/de/destino -- --disable-install-doc --with-openssl-dir=/opt/openssl

Instala una versión de Ruby en ~/.rubies/ruby-3.2.2:

$ ruby-build --dir ruby-3.2.2 ~/.rubies

Instala una versión de Ruby en ~/.rbenv/versions/3.3.5:

$ ruby-build --dir 3.3.5 ~/.rbenv/versions

Uso como plugin de rbenv, logra lo mismo que el ejemplo anterior:

$ rbenv install 3.3.5

VARIABLES DE ENTORNO

TMPDIR

La ubicación donde escribir archivos temporales en disco

RUBY_BUILD_BUILD_PATH (por defecto: un subdirectorio con marca de tiempo de TMPDIR)

La ubicación de compilación para descargar archivos fuente y compilar

RUBY_BUILD_CACHE_PATH (por defecto: "~/.rbenv/cache" si se invoca como plugin de rbenv)

Dónde almacenar en caché los archivos de paquete descargados

RUBY_BUILD_HTTP_CLIENT (por defecto: primera herramienta encontrada en PATH)

Una de "aria2c", "curl" o "wget" para usar en la descarga

RUBY_BUILD_ARIA2_OPTS

Opciones adicionales para pasar a aria2c para la descarga

RUBY_BUILD_CURL_OPTS

Opciones adicionales para pasar a curl para la descarga

RUBY_BUILD_WGET_OPTS

Opciones adicionales para pasar a wget para la descarga

RUBY_BUILD_MIRROR_URL (por defecto: un mirror patrocinado de Amazon CloudFront)

URL raíz de mirror personalizado para descargar paquetes desde

RUBY_BUILD_MIRROR_PACKAGE_URL

URL completa de mirror personalizada

RUBY_BUILD_SKIP_MIRROR

Evita el mirror de descarga y recupera todos los archivos de paquete desde sus URLs originales

RUBY_BUILD_ROOT (por defecto: "share/ruby-build" dentro de la ubicación de instalación de ruby-build)

Directorio personalizado de definiciones de compilación

RUBY_BUILD_TARBALL_OVERRIDE

Reemplaza la URL desde donde se recupera el tarball de ruby, opcionalmente seguido de "#<checksum>"

RUBY_BUILD_DEFINITIONS

Rutas a buscar definiciones de compilación además de RUBY_BUILD_ROOT

CC

Ruta al compilador C

RUBY_CFLAGS

Opciones CFLAGS adicionales a usar para la compilación de Ruby

CONFIGURE_OPTS

Argumentos adicionales de "./configure"

MAKE (por defecto: "make")

Comando make personalizado (ej. "gmake")

MAKE_OPTS, MAKEOPTS

Argumentos adicionales para "make"

MAKE_INSTALL_OPTS

Argumentos adicionales para "make install"

RUBY_CONFIGURE_OPTS

Argumentos adicionales de "./configure" que se aplican solo al código fuente de Ruby

RUBY_MAKE_OPTS

Argumentos make adicionales que se aplican solo al código fuente de Ruby

RUBY_MAKE_INSTALL_OPTS

Argumentos adicionales de "make install" que se aplican solo al código fuente de Ruby

NO_COLOR (por defecto: permite colores cuando está conectado a una terminal)

Deshabilita los colores ANSI en la salida

CLICOLOR_FORCE

Usa colores ANSI en la salida incluso cuando no está conectado a una terminal
