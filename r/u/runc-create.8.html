NOMBRE

runc-create - crear un contenedor

SINOPSIS

runc create [opción ...] id-contenedor

DESCRIPCIÓN

El comando create crea una instancia de un contenedor a partir de un paquete (bundle). El paquete es un directorio con un archivo de especificación llamado config.json y un sistema de archivos raíz.

OPCIONES

--bundle|-b ruta
Ruta a la raíz del directorio del paquete. El valor predeterminado es el directorio actual.
--console-socket ruta
Ruta a un socket AF_UNIX que recibirá un descriptor de archivo que hace referencia al extremo maestro del pseudoterminal de la consola. Consulte docs/terminals ⟨https://github.com/opencontainers/runc/blob/master/docs/terminals.md⟩.
--pid-file ruta
Especifique el archivo donde escribir el PID del proceso inicial del contenedor.
--no-pivot
No utilizar pivot root para aislar el proceso dentro de rootfs. Esto no debe utilizarse excepto en circunstancias excepcionales y puede ser inseguro desde el punto de vista de la seguridad.
--no-new-keyring
No crear un nuevo keyring de sesión para el contenedor. Esto hará que el contenedor herede la clave de sesión del proceso que llama.
--preserve-fds N
Pasar N descriptores de archivo adicionales al contenedor (stdio + $LISTEN_FDS + N en total). El valor predeterminado es 0.

VER TAMBIÉN

runc-spec(8), runc-start(8), runc(8).
