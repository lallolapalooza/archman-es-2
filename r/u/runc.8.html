NOMBRE

runc - runtime de la Open Container Initiative

SINOPSIS

runc [opción-global ...] comando [opción-comando ...] [argumento ...]

DESCRIPCIÓN

runc es un cliente de línea de comandos para ejecutar aplicaciones empaquetadas de acuerdo con el formato de la Open Container Initiative (OCI) y es una implementación compatible de la especificación de la Open Container Initiative.

runc se integra bien con los supervisores de procesos existentes para proporcionar un entorno de tiempo de ejecución de contenedores de producción para aplicaciones. Puede usarse con sus herramientas de monitoreo de procesos existentes y el contenedor se creará como un hijo directo del supervisor de procesos.

Los contenedores se configuran usando bundles. Un bundle para un contenedor es un directorio que incluye un archivo de especificación llamado config.json y un sistema de archivos raíz. El sistema de archivos raíz contiene el contenido del contenedor.

Para ejecutar una nueva instancia de un contenedor:

# runc run [ -b bundle ] id-contenedor

Donde id-contenedor es el nombre que usted le da a la instancia del contenedor que está iniciando. El nombre que proporcione para la instancia del contenedor debe ser único en su host.

Proporcionar el directorio del bundle usando -b es opcional. El valor predeterminado para bundle es el directorio actual.

COMANDOS

checkpoint
Pone en pausa un contenedor en ejecución. Vea runc-checkpoint(8).
create
Crea un contenedor. Vea runc-create(8).
delete
Elimina todos los recursos que posee el contenedor; se usa a menudo con contenedores separados. Vea runc-delete(8).
events
Muestra eventos del contenedor, como notificaciones OOM, estadísticas de CPU, memoria, E/S y red. Vea runc-events(8).
exec
Ejecuta un nuevo proceso dentro del contenedor. Vea runc-exec(8).
kill
Envía una señal especificada al proceso init del contenedor. Vea runc-kill(8).
list
Lista los contenedores iniciados por runc con el --root dado. Vea runc-list(8).
pause
Suspende todos los procesos dentro del contenedor. Vea runc-pause(8).
ps
Muestra los procesos que se ejecutan dentro del contenedor. Vea runc-ps(8).
restore
Restaura un contenedor desde un checkpoint anterior. Vea runc-restore(8).
resume
Reanuda todos los procesos que han sido previamente pausados. Vea runc-resume(8).
run
Crea e inicia un contenedor. Vea runc-run(8).
spec
Crea un nuevo archivo de especificación (config.json). Vea runc-spec(8).
start
Inicia un contenedor creado previamente por runc create. Vea runc-start(8).
state
Muestra el estado del contenedor. Vea runc-state(8).
update
Actualiza las restricciones de recursos del contenedor. Vea runc-update(8).
help, h
Muestra una lista de comandos o ayuda para un comando particular.

OPCIONES GENERALES

Estas opciones pueden ser usadas con cualquier comando y deben preceder al comando.

--debug
Habilita el registro de depuración.
--log ruta
Establece el destino del registro a ruta. El valor predeterminado es registrar en stderr.
--log-format text|json
Establece el formato del registro (el predeterminado es text).
--root ruta
Establece el directorio raíz para almacenar el estado de los contenedores. La ruta debe estar ubicada en tmpfs. El valor predeterminado es /run/runc, o $XDG_RUNTIME_DIR/runc para contenedores sin privilegios.
--systemd-cgroup
Habilita el soporte de cgroups de systemd. Si esto está establecido, se espera que la especificación del contenedor (config.json) tenga el valor cgroupsPath en el formato slice:prefix:name (por ejemplo, system.slice:runc:434234).
--rootless true|false|auto
Habilita o deshabilita el modo sin privilegios. El valor predeterminado es auto, lo que significa que se detectará automáticamente si se debe habilitar el modo sin privilegios.
--help|-h
Muestra la ayuda.
--version|-v
Muestra la versión.
