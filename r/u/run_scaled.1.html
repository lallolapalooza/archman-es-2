RUN_SCALED(1) Manual de comandos generales RUN_SCALED(1)

NOMBRE

run_scaled - ejecuta una aplicación X11 escalada o reducida

SINOPSIS

run_scaled [--scale=VALOR] aplicación [argumentos-de-aplicacion]

run_scaled [--scale=VALOR] [argumentos-de-xpra] -- aplicación [argumentos-de-aplicacion]

DESCRIPCIÓN

run_scaled utiliza xpra(1) para mostrar cualquier aplicación X11 con escalado arbitrario aplicado.

EJEMPLOS

run_scaled xterm -ls
Inicia el comando "xterm -ls", con el escalado por defecto de 2.
La ventana de xterm será el doble de grande de lo que sería normalmente.
run_scaled --scale=250% firefox
Inicia firefox, escalado al 250%.
run_scaled --speaker=off --microphone=off -- wine notepad.exe
Inicia el comando "wine notepad.exe", con las entradas y salidas de audio deshabilitadas (mediante argumentos adicionales de Xpra) y el escalado por defecto de 2.

OPCIONES

--scale=VALOR
El factor de escalado a aplicar, especificado como:
número
ej: 2, 1.5
fracción
ej: 3/2
porcentaje
ej: 250%

Si no se especifica, el valor por defecto es 2.

LIMITACIONES

El valor de escalado está limitado al rango de 0.1 a 10, e incluso dentro de este rango, los valores inferiores a 1 pueden no funcionar correctamente con pantallas grandes.
