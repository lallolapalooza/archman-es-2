NOMBRE

rubik - salvapantallas que resuelve el Cubo de Rubik.

SINOPSIS

rubik [--display host:display.screen] [--visual visual] [--window] [--root] [--window-id número] [--count número] [--cycles número] [--delay número] [--size número] [--hideshuffling] [--fps]

DESCRIPCIÓN

Dibuja un Cubo de Rubik que rota en tres dimensiones y repetidamente se baraja y se resuelve.

OPCIONES

--visual visual
Especifica qué visual usar. Los valores legales son el nombre de una clase visual, o el número de ID (decimal o hexadecimal) de un visual específico.
--window
Dibuja en una ventana recién creada. Este es el valor predeterminado.
--root
Dibuja en la ventana raíz.
--window-id número
Dibuja en la ventana especificada.
--count número
Contador. -100 - 100. Valor predeterminado: -30.
--cycles número
Tiempo de espera. 0 - 60. Valor predeterminado: 5.
--delay número
Retraso por fotograma, en microsegundos. Valor predeterminado: 40000 (0.04 segundos).
--size número
Tamaño. -20 - 20. Valor predeterminado: -6.
--hideshuffling | --no-hideshuffling
Mostrar barajado. Booleano.
--fps
Muestra la tasa de fotogramas actual, la carga de la CPU y el número de polígonos.

AMBIENTE

DISPLAY
para obtener el host y el número de pantalla predeterminados.
XENVIRONMENT
para obtener el nombre de un archivo de recursos que anula los recursos globales almacenados en la propiedad RESOURCE_MANAGER.
XSCREENSAVER_WINDOW
El ID de ventana a usar con --root.

VER TAMBIÉN

X(1), xscreensaver(1)
