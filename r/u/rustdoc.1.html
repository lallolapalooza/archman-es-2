RUSTDOC(1) Comandos de usuario RUSTDOC(1)

NOMBRE

rustdoc - genera documentación a partir de código fuente de Rust

SINOPSIS

rustdoc [OPCIONES] ENTRADA

DESCRIPCIÓN

Esta herramienta genera documentación de referencia de API extrayendo comentarios del código fuente escrito en el lenguaje Rust, disponible en https://www.rust-lang.org. Acepta varios formatos de entrada y proporciona varios formatos de salida para la documentación generada.

OPCIONES

-r, --input-format FORMATO
rust
-w, --output-format FORMATO
html
-o, --output SALIDA,
dónde colocar la salida (por defecto: doc/ para html)
--passes LISTA
lista separada por espacios de pases a ejecutar (por defecto: '')
--no-defaults
no ejecutar los pases por defecto
--plugins LISTA
lista separada por espacios de plugins a ejecutar (por defecto: '')
--plugin-path DIR
directorio desde donde cargar plugins (por defecto: /tmp/rustdoc_ng/plugins)
--target TRIPLE
triple de destino para documentar
--crate-name NOMBRE
especificar el nombre de este crate
-L, --library-path DIR
directorio a añadir a la ruta de búsqueda de crates
--cfg ESPEC
pasar un --cfg a rustc
--extern VAL
pasar un --extern a rustc
--test
ejecutar ejemplos de código como pruebas
--test-args ARGUMENTOS
pasar argumentos al ejecutor de pruebas
--html-in-header ARCHIVO
archivo a añadir a <head>
--html-before-content ARCHIVOS
archivos a incluir en línea entre <body> y el contenido de un archivo Markdown renderizado o documentación generada
--markdown-before-content ARCHIVOS
archivos a incluir en línea entre <body> y el contenido de un archivo Markdown renderizado o documentación generada
--html-after-content ARCHIVOS
archivos a incluir en línea entre el contenido y </body> de un archivo Markdown renderizado o documentación generada
--markdown-after-content ARCHIVOS
archivos a incluir en línea entre el contenido y </body> de un archivo Markdown renderizado o documentación generada
--markdown-css ARCHIVOS
archivos CSS a incluir mediante <link> en un archivo Markdown renderizado o documentación generada
--markdown-playground-url URL
URL a la que enviar fragmentos de código
--markdown-no-toc
no incluir tabla de contenidos
-h, --extend-css
para redefinir algunas reglas css con un archivo dado para generar documentación con tu propio tema
-V, --version
Imprimir la versión de rustdoc

FORMATOS DE SALIDA

La herramienta rustdoc puede generar salida en formato HTML.

Si se utiliza un formato HTML, el destino de salida especificado será el directorio raíz de una estructura HTML para toda la documentación. Las páginas se colocarán en este directorio, y los archivos fuente también podrían ser renderizados en él.

EJEMPLOS

Para generar documentación para el código fuente en el directorio actual:
$ rustdoc hello.rs

Listar todos los pases disponibles que tiene rustdoc, junto con los pases por defecto:
$ rustdoc --passes list

La documentación HTML generada se puede ver con cualquier navegador web estándar.
