runtest(1) Manual de Comandos Generales runtest(1)

NOMBRE

runtest - controlador de pruebas de DejaGnu

SINOPSIS

runtest [OPCIÓN]...

DESCRIPCIÓN

DejaGnu es un framework para probar programas utilizando Expect. runtest es el programa controlador para DejaGnu. Controla qué pruebas ejecutar y cómo ejecutarlas.

OPCIONES

--all, -a
Muestra todos los resultados de las pruebas. Por defecto, solo se muestran los resultados inesperados.
--build TERNARIO
El TERNARIO de configuración para el sistema de compilación.
--debug
Activa la salida de depuración interna de Expect. La salida se guarda en un archivo llamado dbg.log.
--directory DIRECTORIO
Ejecuta solo las pruebas en el DIRECTORIO especificado.
--global_init NOMBRE
El NOMBRE a usar para el archivo de inicialización global en libdir. El valor predeterminado es site.exp si no se proporciona esta opción.
--help
Muestra un mensaje de uso y luego sale.
--host TERNARIO
El TERNARIO de configuración para el sistema host.
--host_board NOMBRE
La definición del tablero host a usar.
--ignore prueba1.exp prueba2.exp ...
No ejecutar las pruebas especificadas.
--local_init NOMBRE
El NOMBRE a usar para el archivo de inicialización local del conjunto de pruebas tanto en el directorio actual como en objdir. El valor predeterminado es site.exp si no se proporciona esta opción.
--log_dialog
Emitir la salida de Expect a la salida estándar.
--mail ´nombre1 nombre2 ...´
Direcciones de correo electrónico para recibir los resultados de las pruebas.
--objdir RUTA
RUTA es un directorio que contiene el código de prueba compilado.
--outdir DIRECTORIO
El nombre de un DIRECTORIO para la salida de los registros de pruebas.
--reboot
Reinicia el tablero de destino cuando runtest se inicializa (si es compatible).
--srcdir RUTA
RUTA es un directorio que contiene directorios de pruebas.
--strace N
Activa el rastreo interno de Expect hasta N niveles de profundidad. La salida se guarda en un archivo llamado dbg.log.
--target TERNARIO
El TERNARIO de configuración para el objetivo.
--target_board NOMBRE
Una lista de NOMBREs de tableros de destino en los que ejecutar las pruebas.
--tool NOMBREHERRAMIENTA
Especifica la herramienta a probar. NOMBREHERRAMIENTA controla el conjunto de pruebas aplicadas y el módulo de inicialización asociado.
--tool_exec RUTA
Especifica la RUTA al ejecutable a probar.
--tool_opts OPCIONES
OPCIONES adicionales para pasar a la herramienta.
-v, --verbose
Activa más salida de depuración de los casos de prueba y del código de utilidad de DejaGnu. Úselo varias veces para aumentar la salida.
-V, --version
Muestra las versiones de DejaGnu, Expect y Tcl.
-x, --xml
Genera salida XML. El archivo de salida se nombra según la herramienta con la extensión .xml.
-D[número]
Activa el depurador Tcl. número puede ser 1 o 0. Si es 1, el shell de Expect se detendrá cuando comience a ejecutarse. La tecla de interrupción hará que DejaGnu caiga al prompt del depurador. Si es 0, DejaGnu se inicia normalmente, pero Control-C lo lleva al prompt del depurador.
Cualquier nombre de archivo en la línea de comandos se asume que es un subconjunto de las
pruebas a ejecutar. Normalmente estos son los nombres de los scripts de prueba (ej. foo.exp).

Las variables al estilo Makefile se utilizan para especificar nombres de herramientas y sus flags; estos y otros valores dependientes de la configuración se guardan en el archivo site.exp, creado durante la configuración.

Estado de salida:

0
si todas las pruebas pasaron, incluyendo fallos esperados y pruebas no soportadas,
1
si alguna prueba falló, pasó inesperadamente o no se resolvió,
2
si Expect encontró algún error en los scripts de prueba.
