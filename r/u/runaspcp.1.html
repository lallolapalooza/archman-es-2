RUNASPCP(1) Manual de Comandos Generales RUNASPCP(1)

NOMBRE

runaspcp - ejecutar un comando de shell como el usuario ``pcp''

SINOPSIS

$PCP_BINADM_DIR/runaspcp [-D debug] [-s shell] comando

DESCRIPCIÓN

runaspcp ejecuta el único argumento comando como el usuario $PCP_USER y el grupo $PCP_GROUP (ambos de /etc/pcp.conf).

El comando se ejecuta con sh(1) por defecto, o con el shell del argumento de línea de comandos -s (o --shell).

Normalmente runaspcp se utiliza desde los scripts ``init'' de PCP que se lanzan como ``root'' pero necesitan degradar sus privilegios al ejecutar algunos demonios de PCP como el usuario ``pcp''.

La opción -?, --help muestra un mensaje de uso.

DIAGNÓSTICO

El estado de salida es 1 si runaspcp no puede cambiar de usuario o grupo, o no puede ejecutar el shell, de lo contrario es el estado de salida del comando.

ENTORNO PCP

Las variables de entorno con el prefijo PCP_ se utilizan para parametrizar los nombres de archivos y directorios utilizados por PCP. En cada instalación, el archivo /etc/pcp.conf contiene los valores locales para estas variables. La variable $PCP_CONF puede usarse para especificar un archivo de configuración alternativo, como se describe en pcp.conf(5).

OPCIONES DE DEPURACIÓN

La opción -D o --debug habilita la salida de diagnósticos adicionales en stderr para ayudar a solucionar problemas, aunque la información a veces es críptica y está destinada principalmente a guiar a los desarrolladores en lugar de a los usuarios finales. debug es una lista separada por comas de opciones de depuración; usa pmdbg(1) con la opción -l para obtener una lista de las opciones de depuración disponibles y su significado.

Las opciones de depuración específicas para runaspcp son las siguientes:

Opción Descripción
appl0 diagnósticos detallados
PCP Rendimiento Co-Pilot
