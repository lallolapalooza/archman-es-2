NOMBRE

runc-update - actualizar las restricciones de recursos de un contenedor en ejecución

SINOPSIS

runc update [opción ...] id-contenedor

runc update -r recursos.json|- id-contenedor

DESCRIPCIÓN

El comando update cambia las restricciones de recursos de una instancia de contenedor en ejecución.

Los recursos se pueden establecer usando opciones o, si se usa -r, se analizan desde JSON proporcionado como archivo o desde stdin.

En caso de usar -r, el formato JSON es el siguiente:

{
	"memory": {
		"limit": 0,
			"reservation": 0,
			"swap": 0,
			"kernel": 0,
			"kernelTCP": 0
	},
		"cpu": {
			"shares": 0,
			"quota": 0,
			"burst": 0,
			"period": 0,
			"realtimeRuntime": 0,
			"realtimePeriod": 0,
			"cpus": "",
			"mems": ""
		},
		"blockIO": {
			"blkioWeight": 0
		}
}

OPCIONES

--resources|-r recursos.json
Lee los nuevos límites de recursos de recursos.json. Usa - para leer desde stdin. Si se usa esta opción, todas las demás opciones se ignoran.
--blkio-weight peso
Establece un nuevo peso de E/S.
--cpu-period num
Establece el período CFS de la CPU a usar para el límite estricto (en microsegundos).
--cpu-quota num
Establece el límite de uso de CPU dentro de un período dado (en microsegundos).
--cpu-burst num
Establece el límite de ráfaga de CPU dentro de un período dado (en microsegundos).
--cpu-rt-period num
Establece el período de tiempo real de la CPU a usar para el límite estricto (en microsegundos).
--cpu-rt-runtime num
Establece el límite estricto de tiempo real de la CPU (en microsegundos). Tiempo de CPU permitido en un período dado.
--cpu-share num
Establece las cuotas de CPU (peso relativo frente a otros contenedores).
--cpuset-cpus lista
Establece la(s) CPU(s) a usar. La lista puede contener comas y rangos. Por ejemplo: 0-3,7.
--cpuset-mems lista
Establece el(los) nodo(s) de memoria a usar. El formato de la lista es el mismo que para --cpuset-cpus.
--memory num
Establece el límite de memoria a num bytes.
--memory-reservation num
Establece la reserva de memoria, o límite suave, a num bytes.
--memory-swap num
Establece el uso total de memoria + swap a num bytes. Usa -1 para desactivar el límite (es decir, usar swap ilimitado).
--pids-limit num
Establece el número máximo de procesos permitidos en el contenedor. Usa -1 para desactivar el límite.
--l3-cache-schema valor
Establece el valor para el esquema de caché L3 de Intel RDT/CAT.
--mem-bw-schema valor
Establece el esquema de ancho de banda de memoria de Intel RDT/MBA.
