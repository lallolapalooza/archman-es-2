R2PM(1) Manual de Comandos Generales R2PM(1)

NOMBRE

r2pm — gestor de paquetes de radare2

SINOPSIS

r2pm [[adhHIipuUglsv]] [[pkg ...]]

DESCRIPCIÓN

Permite instalar, actualizar, desinstalar y descubrir plugins y herramientas que se pueden usar con radare2.

-a, repo
Añade un repositorio externo de r2pm. Sin argumentos, -a listará todos los repositorios registrados. Usa '-a - repo' para eliminar/desregistrar esos repositorios.
-I
Muestra información sobre el repositorio y los paquetes instalados.
-i nombre_paquete
Instala un paquete.
-e nombre_paquete
Abre el script del paquete con tu editor favorito.
-d nombre_paquete
Muestra el código fuente del paquete r2pm.
-gi nombre_paquete
Instala un paquete en el directorio del sistema.
-u nombre_paquete
Desinstala un paquete.
-uu nombre_paquete
Fuerza la desinstalación de un paquete.
-U
Inicializa o actualiza la base de datos de paquetes.
-UU
Igual que -U, pero luego actualiza todos los paquetes instalados.
-gu nombre_paquete
Desinstala un paquete del directorio del sistema.
-l
Lista los paquetes instalados.
-s palabra_clave
Busca en la base de datos paquetes que coincidan con la palabra clave.
-t AAAA-MM-DD
Establece la variable de entorno R2PM_TIME para indicar la fecha desde la cual tomar el código fuente del paquete de git.
-r comando ...argumentos
Ejecuta el comando con R2PM_BINDIR en PATH.
-p
Requiere -c para limpiar la caché de R2PM_PLUGDIR.
-v
Muestra información de la versión.
-h
Muestra el mensaje de ayuda del uso.
-H
Lista todas las variables de entorno especiales definidas por r2pm internamente.
-H nombre_variable_entorno
Muestra el valor de la variable de entorno interna dada.
-c
Limpia la caché de fuentes.

EJEMPLOS

La base de datos se inicializa y descarga automáticamente. Todas las acciones con nombre han sido deprecadas; usa solo las opciones.

Instalar un paquete


$ r2pm -i yara3

Instalar un paquete de prueba (no hacer git pull en $R2PM_GITDIR/yara3)


$ R2PM_GITSKIP=1 r2pm -ci yara3

Evitar llamadas de inicialización/actualización (no hacer git pull en $R2PM_DBDIR)


$ R2PM_OFFLINE=1 r2pm -i yara

Desinstalar un paquete


$ r2pm -u yara3

Buscar un paquete


$ r2pm -s yara

Listar paquetes instalados


$ r2pm -l
