RCSDIFF(1) Manual de Comandos Generales RCSDIFF(1)

NOMBRE

rcsdiff - compara revisiones de RCS

SINOPSIS

rcsdiff [ -ksust ] [ -q ] [ -rrev1 [ -rrev2 ] ] [ -T ] [ -V[n] ] [ -xsufijos ] [ -zzona ] [ opciones de diff ] archivo ...

DESCRIPCIÓN

rcsdiff ejecuta diff(1) para comparar dos revisiones de cada archivo RCS dado.

Los nombres de archivo que coinciden con un sufijo de RCS denotan archivos RCS; todos los demás denotan archivos de trabajo. Los nombres se emparejan como se explica en ci(1).

La opción -q suprime la salida diagnóstica. Se pueden especificar cero, una o dos revisiones con -r. La opción -ksust afecta a la sustitución de palabras clave al extraer revisiones, como se describe en co(1); por ejemplo, -kk -r1.1 -r1.2 ignora las diferencias en los valores de las palabras clave al comparar las revisiones 1.1 y 1.2. Para evitar una salida excesiva de la sustitución del nombre del locker, se asume -kkvl si (1) se da como máximo una opción de revisión, (2) no se da ninguna opción -k, (3) -kkv es la sustitución de palabras clave por defecto, y (4) el modo del archivo de trabajo se produciría con co -l. Véase co(1) para más detalles sobre -T, -V, -x y -z. De lo contrario, se aceptan todas las opciones de diff(1) que se aplican a archivos regulares, con el mismo significado que para diff.

Si se omiten tanto rev1 como rev2, rcsdiff compara la última revisión en la rama por defecto (por defecto, el tronco) con el contenido del archivo de trabajo correspondiente. Esto es útil para determinar qué has cambiado desde la última confirmación.

Si se da rev1 pero se omite rev2, rcsdiff compara la revisión rev1 del archivo RCS con el contenido del archivo de trabajo correspondiente.

Si se dan tanto rev1 como rev2, rcsdiff compara las revisiones rev1 y rev2 del archivo RCS.

Tanto rev1 como rev2 pueden darse numéricamente o simbólicamente.

EJEMPLO

El comando

rcsdiff f.c

compara la última revisión en la rama por defecto del archivo RCS con el contenido del archivo de trabajo f.c.

ENTORNO

RCSINIT
Opciones antepuestas a la lista de argumentos, separadas por espacios. Una barra invertida escapa los espacios dentro de una opción. Las opciones de RCSINIT se anteponen a las listas de argumentos de la mayoría de los comandos RCS. Las opciones útiles de RCSINIT incluyen -q, -V, -x y -z.
RCS_MEM_LIMIT
Normalmente, por velocidad, los comandos mapean en memoria o copian a memoria el archivo RCS si su tamaño es inferior al límite de memoria, que actualmente por defecto es "ilimitado". De lo contrario (o si las formas rápidas intentadas inicialmente fallan), los comandos recurren a rutinas de E/S estándar. Puede ajustar el límite de memoria estableciendo RCS_MEM_LIMIT a un valor numérico lim (medido en kilobytes). Un valor vacío se ignora silenciosamente. Como efecto secundario, la especificación de RCS_MEM_LIMIT inhibe la recurrencia a rutinas más lentas.
TMPDIR
Nombre del directorio temporal. Si no está configurado, se inspeccionan las variables de entorno TMP y TEMP y se toma el primer valor encontrado; si ninguna de ellas está configurada, se utiliza un valor predeterminado dependiente del host, normalmente /tmp.

DIAGNÓSTICOS

El estado de salida es 0 si no hay diferencias durante ninguna comparación, 1 si hay algunas diferencias, 2 si hay problemas.
