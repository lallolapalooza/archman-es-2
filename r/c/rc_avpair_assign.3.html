rc_avpair_assign(3)

Paquete: radcli

Licencias: BSD

rc_avpair_assign(3) Biblioteca cliente de Radius rc_avpair_assign(3)

NOMBRE

rc_avpair_assign -

SINOPSIS

#include <radcli/radcli.h>

int rc_avpair_assign(
    VALUE_PAIR  *vp,
    void const  *pval,
    int          len
);

DESCRIPCIÓN

Asigna el valor dado a un par atributo-valor

Si el valor es de tipo PW_TYPE_STRING, debe ser una cadena terminada en nulo con len establecido en -1, o datos brutos con la longitud correctamente establecida. Para PW_TYPE_DATE, PW_TYPE_INTEGER y PW_TYPE_IPADDR, se debe establecer un número uint32_t en pval. Para direcciones IPv4, debe estar en orden de bytes del host.

Para el tipo PW_TYPE_IPV6ADDR, se espera una dirección de 16 bytes de longitud, y para PW_TYPE_IPV6PREFIX, se espera el formato de prefijo rfc3162. Simplemente, eso es un byte cero, un byte con el valor del prefijo (por ejemplo, 112), y los bytes restantes son la dirección IPv6.

PARÁMETROS

vp
un puntero a una estructura VALUE_PAIR.
pval
el valor (por ejemplo, el nombre de usuario real).
len
la longitud de pval, o -1 si se va a calcular (en el caso de cadenas).

ESTRUCTURAS

Evita usar esta estructura directamente. Usa las funciones rc_avpair_get.


struct rc_value_pair {
  char                   name[RC_NAME_LENGTH+1];      // nombre del atributo si se conoce. 
  uint64_t               attribute; // valor numérico del atributo de tipo rc_attr_id, incluido el proveedor; usa VENDOR() y ATTRID() para separar. 
  rc_attr_type           type;      // tipo de atributo. 
  uint32_t               lvalue;    // valor del atributo si el tipo es PW_TYPE_INTEGER, PW_TYPE_DATE o PW_TYPE_IPADDR. 
  char                   strvalue[AUTH_STRING_LEN+1];  // contiene el valor del atributo en otros casos. 
  struct rc_value_pair  *next;
  char                   pad[32];       // relleno no utilizado 
};

VALOR DE RETORNO

0 en caso de éxito o -1 en caso de fallo.
