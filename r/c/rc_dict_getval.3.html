Paquete: radcli

rc_dict_getval(3) Librería cliente de Radius rc_dict_getval(3)

NOMBRE

rc_dict_getval -

SINOPSIS

#include <radcli/radcli.h>

DICT_VALUE * rc_dict_getval(
    rc_handle const  *rh,
    uint32_t          value,
    char const       *attrname
);

DESCRIPCIÓN

Obtiene un DICT_VALUE basado en el nombre del atributo y el número de valor entero.

PARÁMETROS

rh
un manejador para la configuración analizada.
value
el valor del atributo.
attrname
el nombre del atributo.

VALOR DE RETORNO

La estructura de valor completa basada en el valor real y el nombre del atributo asociado.
