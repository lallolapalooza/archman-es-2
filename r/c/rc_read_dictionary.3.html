rc_read_dictionary(3)

Paquete: radcli

Licencias: BSD

rc_read_dictionary(3) Biblioteca cliente de Radius rc_read_dictionary(3)

NOMBRE

rc_read_dictionary -

SINOPSIS

#include <radcli/radcli.h>

int rc_read_dictionary(
    rc_handle   *rh,
    char const  *filename
);

DESCRIPCIÓN

Inicializa el diccionario.

Lee todos los ATRIBUTOS en la lista dictionary_attributes. Lee todos los VALORES en la lista dictionary_values.

PARÁMETROS

rh
un manejador de la configuración analizada.
filename
el nombre del archivo del diccionario.

VALOR DE RETORNO

0 si tiene éxito, -1 si falla.
