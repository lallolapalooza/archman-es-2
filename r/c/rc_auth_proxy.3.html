rc_auth_proxy(3) Biblioteca cliente de Radius rc_auth_proxy(3)

NOMBRE

rc_auth_proxy -

SINOPSIS

#include <radcli/radcli.h>

int rc_auth_proxy(
    rc_handle    *rh,
    VALUE_PAIR   *send,
    VALUE_PAIR  **received,
    char         *msg
);

DESCRIPCIÓN

Construye una solicitud de autenticación para proxy

Construye una solicitud de autenticación con los pares_valor a enviar y la envía a un servidor. Funciona para un proxy; no añade dirección IP y no depende del archivo de configuración.

PARÁMETROS

rh
un manejador para la configuración analizada.
send
un array VALUE_PAIR de valores (p. ej., PW_USER_NAME).
received
un array asignado de valores recibidos.
msg
debe ser un array de PW_MAX_MSG_SIZE o NULL; contendrá la concatenación de cualquier PW_REPLY_MESSAGE recibido.

VALOR DE RETORNO

pares_valor recibidos en received, mensajes del servidor en msg (si no es NULL) y OK_RC (0) en caso de éxito, CHALLENGE_RC (3) en caso de recibir un Access-Challenge, negativo en caso de fallo como valor de retorno.
