rc_avpair_insert(3) Biblioteca cliente de Radius rc_avpair_insert(3)

NOMBRE

rc_avpair_insert -

SINOPSIS

#include <radcli/radcli.h>

void rc_avpair_insert(
    VALUE_PAIR  **a,
    VALUE_PAIR   *p,
    VALUE_PAIR   *b
);

DESCRIPCIÓN

Insertar un VALUE_PAIR en una lista

Dada la dirección de una lista existente "a" y un puntero a una entrada "p" en esa lista, añadir el par de valores "b" a la lista "a" después de la entrada "p". Si "p" es NULL, añadir el par de valores "b" al final de "a".

PARÁMETROS

a
un array de VALUE_PAIR de valores.
p
un puntero a un VALUE_PAIR en a.
b
El puntero VALUE_PAIR a añadir en a.

rc_avpair_insert(3)

NOMBRE

rc_avpair_insert - Inserta un par clave-valor en un conjunto de pares clave-valor.

SINOPSIS

#include <rc_avpair.h>

int rc_avpair_insert(rc_avpair_t *avp, const char *key, const char *value);

DESCRIPCIÓN

La función rc_avpair_insert inserta un nuevo par clave-valor en el conjunto de pares clave-valor avp. Si ya existe una entrada con la misma key, su value se actualizará con el nuevo value proporcionado.

La función gestiona la asignación de memoria para la clave y el valor si es necesario y asegura que los datos se copien correctamente.

PARÁMETROS

  • avp: Un puntero al conjunto de pares clave-valor (rc_avpair_t) en el que se insertará el nuevo par.
  • key: La cadena que representa la clave del par.
  • value: La cadena que representa el valor asociado a la clave.

VALOR DE RETORNO

Devuelve 0 si la inserción o actualización fue exitosa. Devuelve un código de error negativo en caso de fallo (por ejemplo, error de asignación de memoria).

EJEMPLO


#include <rc_avpair.h>
#include <stdio.h>
#include <stdlib.h>

int main() {
    rc_avpair_t *av_list = NULL;
    int ret;

    // Inicializar la lista de pares clave-valor
    ret = rc_avpair_init(&av_list, NULL);
    if (ret != 0) {
        fprintf(stderr, "Error al inicializar la lista de pares clave-valor.\n");
        return 1;
    }

    // Insertar un par clave-valor
    ret = rc_avpair_insert(av_list, "nombre", "Ejemplo");
    if (ret != 0) {
        fprintf(stderr, "Error al insertar el par clave-valor.\n");
        rc_avpair_free(av_list);
        return 1;
    }

    // Actualizar un valor existente
    ret = rc_avpair_insert(av_list, "nombre", "Actualizado");
    if (ret != 0) {
        fprintf(stderr, "Error al actualizar el par clave-valor.\n");
        rc_avpair_free(av_list);
        return 1;
    }

    // Obtener e imprimir el valor
    const char *value = rc_avpair_get(av_list, "nombre");
    if (value) {
        printf("Valor de 'nombre': %s\n", value);
    }

    // Liberar la memoria
    rc_avpair_free(av_list);
    return 0;
}
