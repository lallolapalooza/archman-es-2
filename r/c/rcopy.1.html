NOMBRE

rcopy - copia simple de archivos sobre RDMA.

SINOPSIS

rcopy origen servidor[:destino] [-p puerto]
rcopy [-p puerto]

DESCRIPCIÓN

Utiliza sockets sobre la interfaz RDMA para copiar un archivo de origen al destino especificado.

OPCIONES

origen
El nombre y la ruta del archivo de origen a copiar.
servidor
El nombre o la dirección del servidor de destino.
:destino
Un nombre y ruta de archivo de destino opcional. Si no se proporciona, el nombre de archivo de destino coincidirá con el del origen.
-p puerto_servidor
El número de puerto del servidor.

NOTAS

El uso básico es iniciar rcopy en un sistema servidor, luego ejecutar rcopy archivo_origen nombre_servidor. La aplicación del servidor seguirá ejecutándose después de copiar el archivo, pero actualmente es de un solo hilo.

Dado que esta prueba mapea recursos RDMA al espacio de usuario, los usuarios deben asegurarse de tener recursos y permisos del sistema disponibles. Consulte el archivo README de libibverbs para obtener detalles adicionales.
