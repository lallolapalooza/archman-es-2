rc_auth(3)

Paquete: radcli

Licencias: BSD

rc_auth(3) Biblioteca cliente de Radius rc_auth(3)

NOMBRE

rc_auth -

SINOPSIS

#include <radcli/radcli.h>

int rc_auth(
    rc_handle    *rh,
    uint32_t      client_port,
    VALUE_PAIR   *send,
    VALUE_PAIR  **received,
    char         *msg
);

DESCRIPCIÓN

Construye una solicitud de autenticación para el puerto id nas_port con los pares de valores send y la envía a un servidor

PARÁMETROS

rh
un manejador para la configuración analizada.
client_port
send
un array VALUE_PAIR de valores (por ejemplo, PW_USER_NAME).
received
un array asignado de valores recibidos.
msg
debe ser un array de PW_MAX_MSG_SIZE o NULL; contendrá la concatenación de cualquier PW_REPLY_MESSAGE recibido.

VALOR DE RETORNO

pares de valores recibidos en received, mensajes del servidor en msg (si no es NULL), y OK_RC (0) en caso de éxito, CHALLENGE_RC (3) en caso de recibir un Access-Challenge, negativo en caso de fallo como valor de retorno.
