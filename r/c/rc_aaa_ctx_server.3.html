rc_aaa_ctx_server(3) Biblioteca cliente Radius rc_aaa_ctx_server(3)

NOMBRE

rc_aaa_ctx_server -

SINOPSIS

#include <radcli/radcli.h>

int rc_aaa_ctx_server(
    rc_handle        *rh,
    RC_AAA_CTX      **ctx,
    SERVER           *aaaserver,
    rc_type           type,
    uint32_t          client_port,
    VALUE_PAIR       *send,
    VALUE_PAIR      **received,
    char             *msg,
    int               add_nas_port,
    rc_standard_codes request_type
);

DESCRIPCIÓN

Construye una solicitud de autenticación/contabilidad para el ID de puerto nas_port con los pares de valores send y la envía a un servidor especificado. Esta función mantiene su estado en ctx después de una operación exitosa. Puede ser liberada usando rc_aaa_ctx_free().

PARÁMETROS

rh
un manejador para la configuración analizada.
ctx
si no es NULL, contendrá el contexto de la solicitud; su valor inicial debe ser NULL y debe liberarse usando rc_aaa_ctx_free().
aaaserver
un SERVIDOR no NULL al que enviar el mensaje.
type
client_port
send
un array VALUE_PAIR de valores (por ejemplo, PW_USER_NAME).
received
un array asignado de valores recibidos.
msg
debe ser un array de PW_MAX_MSG_SIZE o NULL; contendrá la concatenación de cualquier PW_REPLY_MESSAGE recibido.
add_nas_port
esto debe ser cero; si es distinto de cero, incluirá PW_NAS_PORT en los pares enviados.
request_type
uno de los códigos estándar RADIUS (por ejemplo, PW_ACCESS_REQUEST).

VALOR DE RETORNO

pares de valores recibidos en received, mensajes del servidor en msg y OK_RC (0) en caso de éxito, CHALLENGE_RC (3) si se recibe Access-Challenge, negativo en caso de fallo como valor de retorno.

DESCRIPTION

The rc_aaa_ctx_server structure is used to represent a RADIUS server in the FreeRADIUS client library.

It contains various configuration options for the RADIUS server, such as its name, secret, IP address, ports, timeouts, and more.

PARAMETERS

The following members are available in the rc_aaa_ctx_server structure:

  • name: The name of the RADIUS server.
  • secret: The shared secret for the RADIUS server.
  • nas_ip_address: The IP address of the Network Access Server (NAS).
  • nas_identifier: The identifier of the NAS.
  • require_message_authenticator: Whether to require the Message-Authenticator attribute.
  • omit_nas_ip_address: Whether to omit the NAS-IP-Address attribute.
  • auth_port: The port for RADIUS authentication.
  • acct_port: The port for RADIUS accounting.
  • timeout: The timeout for RADIUS requests.
  • retry: The number of retries for RADIUS requests.
  • virtual_server: The virtual server to use.
  • remote_requests: Whether to allow remote requests.
  • dns_retries: The number of DNS retries.
  • bind_addr: The local IP address to bind to.
  • bind_port: The local port to bind to.
  • debug: Whether to enable debug logging.
  • allow_empty_password: Whether to allow empty passwords.
  • use_challenge: Whether to use the challenge attribute.
  • password_type: The type of password to use.
  • strip_empty_from_request: Whether to strip empty attributes from the request.
  • realm: The realm to use.
  • auth_type: The authentication type.
  • auth_protocol: The authentication protocol.
  • fail_close: Whether to close the connection on failure.
  • accounting_on_stop: Whether to send accounting information on stop.
  • coa_port: The port for Change of Authorization (CoA) requests.
  • coa_secret: The shared secret for CoA requests.
  • coa_wait: The wait time for CoA requests.
  • coa_retry: The number of retries for CoA requests.
  • coa_timeout: The timeout for CoA requests.
  • coa_virtual_server: The virtual server to use for CoA requests.
  • coa_bind_addr: The local IP address to bind to for CoA requests.
  • coa_bind_port: The local port to bind to for CoA requests.
  • coa_dns_retries: The number of DNS retries for CoA requests.
  • coa_fail_close: Whether to close the connection on CoA failure.
  • coa_accounting_on_stop: Whether to send accounting information on stop for CoA requests.
  • coa_realm: The realm to use for CoA requests.
  • coa_auth_type: The authentication type for CoA requests.
  • coa_auth_protocol: The authentication protocol for CoA requests.
  • coa_strip_empty_from_request: Whether to strip empty attributes from CoA requests.
  • nas_port_type: The type of NAS port.
  • nas_port_id: The ID of the NAS port.
  • framed_protocol: The framed protocol.
  • state_send: Whether to send the state attribute.
  • state_get: Whether to get the state attribute.
  • state_wait: The wait time for the state attribute.
  • state_retry: The number of retries for the state attribute.
  • state_timeout: The timeout for the state attribute.
  • state_virtual_server: The virtual server to use for the state attribute.
  • state_bind_addr: The local IP address to bind to for the state attribute.
  • state_bind_port: The local port to bind to for the state attribute.
  • state_dns_retries: The number of DNS retries for the state attribute.
  • state_fail_close: Whether to close the connection on state attribute failure.
  • state_accounting_on_stop: Whether to send accounting information on stop for the state attribute.
  • state_realm: The realm to use for the state attribute.
  • state_auth_type: The authentication type for the state attribute.
  • state_auth_protocol: The authentication protocol for the state attribute.
  • state_strip_empty_from_request: Whether to strip empty attributes from requests for the state attribute.
  • state_coa_port: The port for CoA requests related to the state attribute.
  • state_coa_secret: The shared secret for CoA requests related to the state attribute.
  • state_coa_wait: The wait time for CoA requests related to the state attribute.
  • state_coa_retry: The number of retries for CoA requests related to the state attribute.
