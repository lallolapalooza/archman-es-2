NOMBRE

rc.news - Iniciar o detener demonios de INN

SINOPSIS

rc.news ["start" | "stop"]

DESCRIPCIÓN

rc.news se puede usar para iniciar o detener innd y programas de soporte. Comprueba que INN no se esté ejecutando ya, maneja casos de apagado inadecuado, finaliza tareas que podrían haber sido interrumpidas por el apagado anterior, envía por correo electrónico ciertas advertencias al arrancar a newsmaster (tal como se establece en inn.conf), y en general es más seguro y fácil que iniciar y detener todo directamente. Necesita ser ejecutado como el usuario de noticias para que los archivos en pathrun se creen con la propiedad correcta (aunque esto es menos importante para "rc.news stop").

Los programas ejecutados y detenidos por este script incluyen:

  • Siempre: se inicia o detiene innd.
  • Si doinnwatch es verdadero en inn.conf: se inicia y detiene innwatch.
  • Si docnfsstat es verdadero en inn.conf: se inicia y detiene cnfsstat.
  • Si ovmethod está configurado como "ovdb" en inn.conf: se ejecuta ovdb_init; se detienen ovdb_server y ovdb_monitor.
  • Si ovmethod está configurado como "ovsqlite" en inn.conf: se inicia y detiene ovsqlite-server.
  • Si rc.news.local existe en pathbin: se ejecuta rc.news.local con el argumento "start" o "stop" (para realizar tareas de inicio o apagado específicas del sitio).
  • Al iniciarse, si INN parece haber sido apagado previamente durante su proceso de expiración, ejecuta expirerm si hay artículos que desenlazar.
  • Al iniciarse, si los datos de vista previa parecen haber sido reconstruidos y active necesita ser renumerado, entonces lo renumerará.

OPCIONES

"start"
Si el primer argumento es "start", o si no se proporciona ningún primer argumento, rc.news inicia el arranque de INN.
"stop"
Si el primer argumento es "stop", rc.news inicia el apagado de INN.

EJEMPLOS

Para iniciar INN y dejar que ciertos mensajes de error se muestren en la terminal:

su news -s /bin/sh -c <pathbin en inn.conf>/rc.news

Para ejecutar INN al inicio desde los scripts de arranque del sistema apropiados:

su news -s /bin/sh -c '<pathbin>/rc.news' >> <pathlog>/rc.news 2>&1

Para detener INN:

su news -s /bin/sh -c '<pathbin>/rc.news stop'
