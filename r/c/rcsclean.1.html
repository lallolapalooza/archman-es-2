NOMBRE

rcsclean - limpia archivos de trabajo

SINOPSIS

rcsclean [opciones] [ archivo ... ]

DESCRIPCIÓN

rcsclean elimina archivos en los que no se está trabajando. rcsclean -u también desbloquea y elimina archivos en los que se está trabajando pero que no han cambiado.

Para cada archivo dado, rcsclean compara el archivo de trabajo y una revisión en el archivo RCS correspondiente. Si encuentra una diferencia, no hace nada. De lo contrario, primero desbloquea la revisión si se proporciona la opción -u, y luego elimina el archivo de trabajo a menos que el archivo de trabajo sea escribible y la revisión esté bloqueada. Registra sus acciones emitiendo los comandos correspondientes rcs -u y rm -f en la salida estándar.

Los archivos se emparejan como se explica en ci(1). Si no se proporciona ningún archivo, se limpian todos los archivos de trabajo en el directorio actual. Los nombres de archivo que coinciden con un sufijo RCS denotan archivos RCS; todos los demás denotan archivos de trabajo.

El número de la revisión con la que se compara el archivo de trabajo puede adjuntarse a cualquiera de las opciones -n, -q, -r o -u. Si no se especifica ningún número de revisión, entonces si se proporciona la opción -u y el llamante tiene una revisión bloqueada, rcsclean utiliza esa revisión; de lo contrario, rcsclean utiliza la última revisión en la rama predeterminada, normalmente la raíz.

rcsclean es útil para los objetivos clean en los makefiles. Consulte también rcsdiff(1), que imprime las diferencias, y ci(1), que normalmente revierte a la revisión anterior si un archivo no cambió.

OPCIONES

-ksust
Utiliza la sustitución de palabras clave estilo sust al recuperar la revisión para la comparación. Consulte co(1) para obtener detalles.
-n[rev]
No elimine realmente ningún archivo ni desbloquee ninguna revisión. Usar esta opción le dirá lo que rcsclean haría sin hacerlo realmente.
-q[rev]
No registre las acciones tomadas en la salida estándar.
-r[rev]
Esta opción no tiene ningún efecto aparte de especificar la revisión para la comparación.
-T
Conserva la hora de modificación en el archivo RCS incluso si el archivo RCS cambia porque se elimina un bloqueo. Esta opción puede suprimir recompilaciones extensas causadas por una dependencia de make(1) de alguna otra copia del archivo de trabajo en el archivo RCS. Use esta opción con cuidado; puede suprimir la recompilación incluso cuando sea necesaria, es decir, cuando la eliminación del bloqueo signifique un cambio en las cadenas de palabras clave en el otro archivo de trabajo.
-u[rev]
Desbloquea la revisión si está bloqueada y no se encuentra ninguna diferencia.
-V
Imprime el número de versión de RCS.
-Vn
Emula la versión n de RCS. Consulte co(1) para obtener detalles.
-xsufijos
Utiliza sufijos para caracterizar los archivos RCS. Consulte ci(1) para obtener detalles.
-zzona
Utiliza zona como zona horaria para la sustitución de palabras clave; consulte co(1) para obtener detalles.

EJEMPLOS

rcsclean *.c *.h

elimina todos los archivos de trabajo que terminan en .c o .h que no se modificaron desde su checkout.

rcsclean

elimina todos los archivos de trabajo en el directorio actual que no se modificaron desde su checkout.

ARCHIVOS

rcsclean accede a los archivos de manera similar a como lo hace ci(1).

ENTORNO

RCSINIT
Opciones antepuestas a la lista de argumentos, separadas por espacios. Una barra invertida escapa los espacios dentro de una opción. Las opciones RCSINIT se anteponen a las listas de argumentos de la mayoría de los comandos RCS. Las opciones útiles de RCSINIT incluyen -q, -V, -x y -z.
RCS_MEM_LIMIT
Normalmente, para mayor velocidad, los comandos mapean en memoria o copian en memoria el archivo RCS si su tamaño es inferior al límite de memoria, que actualmente tiene un valor predeterminado de "ilimitado". De lo contrario (o si las formas rápidas inicialmente intentadas fallan), los comandos recurren a rutinas de E/S estándar. Puede ajustar el límite de memoria estableciendo RCS_MEM_LIMIT a un valor numérico lim (medido en kilobytes). Un valor vacío se ignora silenciosamente. Como efecto secundario, especificar RCS_MEM_LIMIT inhibe la recurrencia a rutinas más lentas.
TMPDIR
Nombre del directorio temporal. Si no está establecido, se inspeccionan las variables de entorno TMP y TEMP y se toma el primer valor encontrado; si ninguna de ellas está establecida, se utiliza un valor predeterminado dependiente del host, normalmente /tmp.

DIAGNÓSTICOS

El estado de salida es cero si y solo si todas las operaciones fueron exitosas. Los archivos de trabajo y RCS faltantes se ignoran silenciosamente.
