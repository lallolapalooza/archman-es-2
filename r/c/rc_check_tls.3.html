rc_check_tls(3)

Paquete: radcli

Licencias: BSD

rc_check_tls(3) Biblioteca de cliente Radius rc_check_tls(3)

NOMBRE

rc_check_tls -

SINOPSIS

#include <radcli/radcli.h>

int rc_check_tls(
    rc_handle  *rh
);

DESCRIPCIÓN

Comprueba si los canales TLS/DTLS establecidos están operativos

Esta función comprobará si los canales establecidos para TLS o DTLS están operativos y los restablecerá si es necesario. Si esta función falla, el estado TLS o DTLS debe considerarse como desconectado. Debe llamarse en un momento en que las sesiones no estén en uso (por ejemplo, en un hilo diferente).

Nota: Se recomienda ejecutar esta función periódicamente si tienes un canal DTLS, ya que un reinicio del servidor no detectado puede provocar un comportamiento de agujero negro del servidor.

PARÁMETROS

rh
un manejador para la configuración analizada

VALOR DE RETORNO

0 si tiene éxito, -1 si hay un error
