rctest(1) Administración de sistemas Linux rctest(1)

Nombre

rctest - pruebas RFCOMM

SINOPSIS

rctest <MODO> [OPCIONES] [bdaddr]

DESCRIPCIÓN

rctest(1) se utiliza para probar las comunicaciones RFCOMM en la pila BlueZ.

MODOS

-r
escuchar y recibir
-w
escuchar y enviar
-d
escuchar y volcar datos entrantes
-s
conectar y enviar
-u
conectar y recibir
-n
conectar y permanecer en silencio
-c
conectar, desconectar, conectar, ...
-m
múltiples conexiones

OPCIONES

-b bytes
enviar/recibir bytes
-i dispositivo
seleccionar el dispositivo especificado
-P canal
seleccionar el canal especificado
-U uuid
seleccionar el uuid especificado
-L segundos
habilitar opciones SO_LINGER durante segundos
-W segundos
habilitar configuración diferida durante segundos
-B nombre_archivo
usar paquetes de datos del nombre_archivo
-N num
enviar num tramas
-C num
enviar num tramas antes del retraso (por defecto: 1)
-D milisegundos
retrasar milisegundos después de enviar num tramas (por defecto: 0)
-A
solicitar autenticación
-E
solicitar cifrado
-S
conexión segura
-M
convertirse en central
-T
habilitar marcas de tiempo
