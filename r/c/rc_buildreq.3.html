rc_buildreq(3) Biblioteca cliente de Radius rc_buildreq(3)

NOMBRE

rc_buildreq -

SINOPSIS

#include <radcli/radcli.h>

void rc_buildreq(
    rc_handle const  *rh,
    SEND_DATA        *data,
    int               code,
    char             *server,
    unsigned short    port,
    char             *secret,
    int               timeout,
    int               retries
);

DESCRIPCIÓN

Construye una solicitud RADIUS esqueleto utilizando información del archivo de configuración

PARÁMETROS

rh
un manejador para la configuración analizada.
data
un puntero a una estructura SEND_DATA.
code
uno de los códigos RADIUS estándar (por ejemplo, PW_ACCESS_REQUEST).
server
el nombre del servidor.
port
el número de puerto del servidor.
secret
el secreto utilizado por el servidor.
timeout
el tiempo de espera en segundos de un mensaje.
retries
el número de reintentos.

ESTRUCTURAS


struct send_data {
  uint8_t      code;          // Código del paquete RADIUS. 
  uint8_t      seq_nbr;       // Número de secuencia del paquete. 
  char        *server;        // Nombre/dirección del servidor RADIUS. 
  int          svc_port;      // Puerto de destino del protocolo RADIUS. 
  char        *secret;        // Secreto compartido del servidor RADIUS. 
  int          timeout;       // Tiempo de espera de sesión en segundos. 
  int          retries;
  VALUE_PAIR  *send_pairs;    // Más pares a/v para enviar. 
  VALUE_PAIR  *receive_pairs; // Dónde colocar los pares a/v recibidos. 
};
