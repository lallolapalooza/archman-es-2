rc_avpair_gen(3) Biblioteca cliente Radius rc_avpair_gen(3)

NOMBRE

rc_avpair_gen -

SINOPSIS

#include <radcli/radcli.h>

VALUE_PAIR * rc_avpair_gen(
    rc_handle const      *rh,
    VALUE_PAIR           *pair,
    unsigned char const  *ptr,
    int                   length,
    uint32_t              vendorspec
);

DESCRIPCIÓN

Toma pares de atributos/valor de un buffer y construye una lista de pares de valor utilizando memoria asignada.

PARÁMETROS

rh
un manejador para la configuración analizada.
pair
un puntero a una estructura VALUE_PAIR.
ptr
el valor (por ejemplo, el nombre de usuario real).
length
la longitud de ptr, o -1 si se calcula (en el caso de cadenas).
vendorspec
El ID del proveedor en caso de un valor específico del proveedor; de lo contrario, 0.

ESTRUCTURAS

Evite usar esta estructura directamente. Utilice las funciones rc_avpair_get_.


struct rc_value_pair {
  char                   name[RC_NAME_LENGTH+1];      // nombre del atributo si se conoce. 
  uint64_t               attribute; // valor numérico del atributo de tipo rc_attr_id, incluyendo el proveedor; use VENDOR() y ATTRID() para separar. 
  rc_attr_type           type;      // tipo de atributo. 
  uint32_t               lvalue;    // valor del atributo si el tipo es PW_TYPE_INTEGER, PW_TYPE_DATE o PW_TYPE_IPADDR. 
  char                   strvalue[AUTH_STRING_LEN+1];  // contiene el valor del atributo en otros casos. 
  struct rc_value_pair  *next;
  char                   pad[32];       // relleno no utilizado 
};

VALOR DE RETORNO

Lista value_pair o NULL en caso de fallo.
