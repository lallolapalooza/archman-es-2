rc_aaa(3) Biblioteca cliente de Radius rc_aaa(3)

NOMBRE

rc_aaa -

SINOPSIS

#include <radcli/radcli.h>

int rc_aaa(
    rc_handle        *rh,
    uint32_t          client_port,
    VALUE_PAIR       *send,
    VALUE_PAIR      **received,
    char             *msg,
    int               add_nas_port,
    rc_standard_codes request_type
);

DESCRIPCIÓN

Construye una solicitud de autenticación/contabilidad para el puerto id nas_port con los value_pairs send y la envía a un servidor.

PARÁMETROS

rh
un manejador para la configuración analizada.
client_port
send
un array VALUE_PAIR de valores (por ejemplo, PW_USER_NAME).
received
un array asignado de valores recibidos.
msg
debe ser un array de PW_MAX_MSG_SIZE o NULL; contendrá la concatenación de cualquier PW_REPLY_MESSAGE recibido.
add_nas_port
esto debe ser cero; si es distinto de cero, incluirá PW_NAS_PORT en los pares enviados.
request_type
uno de los códigos estándar de RADIUS (por ejemplo, PW_ACCESS_REQUEST).

ESTRUCTURAS

Evita usar esta estructura directamente. Usa las funciones rc_avpair_get_.


struct rc_value_pair {
  char                   name[RC_NAME_LENGTH+1];      // nombre del atributo si se conoce.

  rc_attr_type           type;      // tipo de atributo. 
  uint32_t               lvalue;    // valor del atributo si el tipo es PW_TYPE_INTEGER, PW_TYPE_DATE o PW_TYPE_IPADDR. 
  char                   strvalue[AUTH_STRING_LEN+1];  // contiene el valor del atributo en otros casos. 
  struct rc_value_pair  *next;
  char                   pad[32];       // pad no utilizado 
};

VALOR DE RETORNO

pares value_pairs recibidos en received, mensajes del servidor en msg y OK_RC (0) si tiene éxito, CHALLENGE_RC (3) si se recibe un Access-Challenge, negativo en caso de fallo como valor de retorno.
