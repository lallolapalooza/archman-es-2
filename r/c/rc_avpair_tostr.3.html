rc_avpair_tostr(3)

Paquete: radcli

Licencias: BSD

rc_avpair_tostr(3) Librería cliente de Radius rc_avpair_tostr(3)

NOMBRE

rc_avpair_tostr -

SINOPSIS

#include <radcli/radcli.h>

int rc_avpair_tostr(
    rc_handle const  *rh,
    VALUE_PAIR       *pair,
    char             *name,
    int               ln,
    char             *value,
    int               lv
);

DESCRIPCIÓN

Traduce un av_pair a cadenas imprimibles

PARÁMETROS

rh
un manejador de configuración parseada.
pair
un puntero a una estructura VALUE_PAIR.
name
el nombre del par.
ln
el tamaño de name.
value
el valor del par.
lv
el tamaño de value.

ESTRUCTURAS

Evite usar esta estructura directamente. Use las funciones rc_avpair_get_.


struct rc_value_pair {
  char                   name[RC_NAME_LENGTH+1];      // nombre del atributo si se conoce. 
  uint64_t               attribute; // valor numérico del atributo de tipo rc_attr_id incluyendo el vendedor; use VENDOR() y ATTRID() para separar. 
  rc_attr_type           type;      // tipo de atributo. 
  uint32_t               lvalue;    // valor del atributo si el tipo es PW_TYPE_INTEGER, PW_TYPE_DATE o PW_TYPE_IPADDR. 
  char                   strvalue[AUTH_STRING_LEN+1];  // contiene el valor del atributo en otros casos. 
  struct rc_value_pair  *next;
  char                   pad[32];       // pad no utilizado 
};

VALOR DE RETORNO

0 en éxito, -1 en fallo.
