rc_send_server(3)

Paquete: radcli

Licencias: BSD

rc_send_server(3) Biblioteca cliente de Radius rc_send_server(3)

NOMBRE

rc_send_server -

SINOPSIS

#include <radcli/radcli.h>

int rc_send_server(
    rc_handle  *rh,
    SEND_DATA  *data,
    char       *msg,
    rc_type     type
);

DESCRIPCIÓN

Envía una solicitud a un servidor RADIUS y espera la respuesta

PARÁMETROS

rh
un manejador para la configuración analizada
data
un puntero a una estructura SEND_DATA
msg
debe ser un array de PW_MAX_MSG_SIZE o NULL; contendrá la concatenación de cualquier PW_REPLY_MESSAGE recibido.
type
debe ser AUTH o ACCT

ESTRUCTURAS


struct send_data {
  uint8_t      code;          // Código del paquete RADIUS. 
  uint8_t      seq_nbr;       // Número de secuencia del paquete. 
  char        *server;        // Nombre/dirección del servidor RADIUS. 
  int          svc_port;      // Puerto de destino del protocolo RADIUS. 
  char        *secret;        // Secreto compartido del servidor RADIUS. 
  int          timeout;       // Tiempo de espera de la sesión en segundos. 
  int          retries;
  VALUE_PAIR  *send_pairs;    // Más pares a/v para enviar. 
  VALUE_PAIR  *receive_pairs; // Dónde colocar los pares a/v recibidos. 
};

VALOR DE RETORNO

OK_RC (0) en caso de éxito, TIMEOUT_RC en caso de tiempo de espera REJECT_RC en caso de rechazo de acceso, o negativo en caso de fallo como valor de retorno.
