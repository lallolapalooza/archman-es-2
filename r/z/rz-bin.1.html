RZ_BIN(1) Manual de Comandos Generales RZ_BIN(1)

NOMBRE

rz-bin — Extractor de información de programas binarios

SINOPSIS

rz-bin [-AcdeEghHiIjlLMqrRsSUvVxzZ] [-@ dir] [-a arquitectura] [-b bits] [-B dir] [-C F:C:D] [-f str] [-m dir] [-n str] [-N m:M] [-P pdb] [-o str] [-O str] [-k consulta] [-D lang nombre_simbolo] archivo

DESCRIPCIÓN

Este comando forma parte del proyecto Rizin.

rz-bin puede analizar y extraer información útil de archivos ejecutables binarios como ELF, PE, Mach-O, etc. Soporta múltiples arquitecturas como x86, ARM, MIPS, PowerPC, etc.

OPCIONES

-@ dir
Mostrar sección, símbolo o importación en la dirección dada
-A
Listar sub-binarios y sus pares arch-bits
-a arquitectura
Establecer arquitectura (x86, arm, .. o <arquitectura>_<bits>)
-b bits
Establecer bits (32, 64 ...)
-B dir
Anular la dirección base (binarios PIE)
-c
Listar clases
-cc
Listar clases en formato de encabezado
-C formato:C:D
Crear [elf, mach0, pe] con pares hexadecimales de Código y Datos (ver -a)
-d
Mostrar información de depuración/dwarf
-dd
Cargar información de depuración/dwarf desde el servidor debuginfod
-D lang nombre
Des-mangling del nombre del símbolo (-D all para bin.demangle=true)
-e
Punto de entrada
-E
Símbolos globalmente exportables
-f str
Seleccionar sub-bin llamado str
-F formato_bin
Forzar el uso de ese plugin de binario (ignorar verificación de encabezado)
-g
Igual a -SMZIHVResizcld -SS -SSS -ee (mostrar toda la información)
-G dir
Dirección de carga . desplazamiento al encabezado
-h
Mostrar mensaje de ayuda de uso
-H
Campos del encabezado
-i
Importaciones (símbolos importados de bibliotecas)
-I
Información del binario
-j
Salida en JSON
-k consulta-sdb
Ejecutar consulta sdb. por ejemplo: '*'
-K algoritmo
Calcular checksums (md5, sha1, ..)
-l
Bibliotecas enlazadas
-L plugin
Listar plugins de binario compatibles o detalles del plugin
-m dir
Mostrar línea de código fuente en dir
-M
Principal (mostrar dirección del símbolo principal)
-n str
Mostrar sección, símbolo o importación con el nombre str
-N min:max
Forzar número mínimo:máximo de caracteres por cadena (ver -z y -zz)
-o str
Archivo/carpeta de salida para operaciones de escritura (out por defecto)
-O str
Operaciones de escritura/extracción (-O ayuda)
-p
Mostrar direcciones físicas
-P
Mostrar información de depuración/pdb
-PP
Descargar archivo pdb para el binario
-q
Silencioso, solo mostrar menos datos
-qq
Mostrar menos información (sin desplazamiento/tamaño para -z, por ejemplo.)
-Q
Mostrar dirección de carga utilizada por dlopen (bibliotecas no-aslr)
-r
Mostrar salida en formato rizin
-R
Mostrar reubicaciones
-s
Símbolos
-S
Secciones
-SS
Segmentos
-SSS
Secciones mapeadas a segmentos
-T
Mostrar firma del archivo
-u
Sin filtrar (no renombrar símbolos/secciones duplicados)
-U
Recursos
-v
Mostrar información de versión
-V
Mostrar información de versión del binario
-w
Mostrar bloques try/catch
-x
Extraer binarios contenidos en el archivo
-X formato [f] ..
Empaquetar en fat o zip los archivos dados y los binarios contenidos en el archivo
-Y fw archivo
Calcular todas las posibles direcciones base candidatas de un firmware bin
-z
Mostrar cadenas de texto (de la sección de datos)
-zz
Mostrar cadenas de texto (de cadenas crudas del binario)
-zzz
Volcar cadenas de texto crudas a la salida estándar (para archivos muy grandes)
-Z
Adivinar el tamaño del programa binario

ENTORNO

RZ_BIN_BASE64: e bin.debase64 - intenta debase64 todas las cadenas

RZ_BIN_DEBUGINFOD_URLS: e bin.dbginfo.debuginfod_urls - usa un servidor debuginfod alternativo

RZ_BIN_DEMANGLE: e bin.demangle - no desmangles los símbolos

RZ_BIN_LANG: e bin.lang - asume el idioma para desmangling

RZ_BIN_MAXSTRBUF: e bin.maxstrbuf - especifica el tamaño máximo del buffer

RZ_BIN_PDBSERVER: e pdb.server - usa un servidor PDB alternativo

RZ_BIN_PREFIX: e bin.prefix - prefija los símbolos/secciones/relocaciones con una cadena específica

RZ_BIN_STRFILTER: e bin.str.filter - rizin -qc 'e bin.str.filter=??' -

RZ_BIN_STRPURGE: e bin.str.purge - intenta purgar falsos positivos

RZ_BIN_SYMSTORE: e pdb.symstore - ruta al almacén de símbolos downstream

RZ_CONFIG: archivo de configuración sdb

RZ_NOPLUGINS: no cargues plugins compartidos (acelera la carga)

EJEMPLOS

Listar símbolos de un programa:

rz-bin -s a.out

Obtener el desplazamiento de un símbolo:

rz-bin -n _main a.out

Obtener el punto de entrada:

rz-bin -e a.out

Cargar símbolos e importaciones desde rizin:

rizin -n /bin/ls
