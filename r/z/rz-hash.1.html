RZ_HASH(1) Manual de comandos generales RZ_HASH(1)

NOMBRE

rz-hash — utilidad de hashing basada en bloques

SINOPSIS

rz-hash [-vhBkjLq] [-a algoritmo] [-b tamaño] [-c hash] [-D algo] [-E algo] [-s cadena] [-x cadenahex] [-f desde] [-t hasta] [-c hash] [[archivo] ...]

DESCRIPCIÓN

Este programa es parte del proyecto Rizin.

rz-hash te permite calcular, verificar y mostrar los valores hash de cada bloque de un archivo objetivo. El tamaño del bloque es de 32768 bytes por defecto. Se permite hacer hashing desde stdin usando '-' como archivo objetivo. Puedes comparar contra un hash conocido y obtener el resultado en el estado de salida.

Puedes hacer hashing de archivos grandes calculando cada bloque y luego determinando qué parte ha sido modificada. Útil para el análisis del sistema de archivos.

Este comando puede usarse para calcular hashes de una parte específica de un archivo o de una cadena pasada por línea de comandos.

Este es el comando utilizado por el comando 'ph' de rizin.

-v
Mostrar información de la versión
-h
Mostrar mensaje de ayuda de uso
-
Leer entrada desde stdin en lugar de desde un archivo
-a algoritmo
Algoritmo de hash a utilizar; puedes especificar varios separándolos con una coma (ejemplo: sha1,md4,md5,sha256)
-B
Mostrar el valor calculado para cada bloque
-b tamaño
Establecer el tamaño del bloque
-c valor
Comparar el valor calculado con uno dado (hexadecimal)
-e endian
Establecer el orden de bytes (por defecto: 'big'; aceptados: 'big' o 'little')
-D algo
Descifrar la entrada dada; usar -S para establecer la clave y -I para establecer el IV (si es necesario)
-E algo
Cifrar la entrada dada; usar -S para establecer la clave y -I para establecer el IV (si es necesario)
-f desde
Iniciar el cálculo en el desplazamiento dado
-t hasta
Detener el cálculo en el desplazamiento dado
-I iv
Establecer el vector de inicialización (IV)
-i veces
Repetir el cálculo N veces
-j
Mostrar el resultado como una estructura JSON
-k
Mostrar el valor calculado usando el algoritmo randomkey de openssh
-L
Listar todos los algoritmos
-q
Establecer modo silencioso (usar -qq para obtener solo el valor calculado)
-S semilla
Establecer la semilla para -a; usar '^' para añadirla antes de la entrada. Usar el prefijo '@' para cargarla desde un archivo y '-' para leerla
-K clave
Establecer la clave HMAC para -a y la clave para -E/-D. Usar el prefijo '@' para cargarla desde un archivo y '-' para leerla desde stdin (puedes combinarlos)
-s cadena
Leer entrada desde una cadena terminada en nulo en lugar de desde un archivo
-x hex
Leer entrada desde un valor hexadecimal en lugar de desde un archivo

Todas las entradas (además de -s/-x/-c) pueden ser hexadecimales o cadenas si se especifica el prefijo 's:'.

DIAGNÓSTICOS

La utilidad rz-hash sale con estado 0 en caso de éxito, y >0 si ocurre un error.

Cuando se usa -c, el estado de salida 0 indica una coincidencia entre los hashes esperados y calculados.
