RZ_RUN(1) Manual de comandos generales RZ_RUN(1)

NOMBRE

rz-run — utilidad de rizin para ejecutar programas en entornos personalizados

SINOPSIS

rz-run [[directivas]] [[script.rz]] [[--] [programa] [args]]

DESCRIPCIÓN

Este comando forma parte del proyecto Rizin.

Este programa se utiliza como lanzador para ejecutar programas con diferentes entornos, argumentos, permisos, directorios y descriptores de archivo predeterminados anulados.

-l
Listar todas las opciones de perfil compatibles.
-t
Generar un perfil de plantilla base. Prueba `rz-run -d > profile.rz`
-w
Mostrar el nombre de la terminal y esperar una conexión de otro proceso. Prueba `rz-run stdio=<ttypath> program=/bin/sh`

El programa solo acepta un argumento que es el nombre del archivo de configuración para ejecutar el programa.

Es útil cuando tienes que ejecutar un programa con argumentos largos o pasar datos largos a la entrada estándar o cosas similares, generalmente requeridas para explotar crackmes :)

DIRECTIVAS

El archivo de configuración rrz (rz-run) acepta las siguientes directivas, descritas como entradas clave=valor y comentarios definidos como líneas que comienzan con '#'.

arg[0-511]
Establecer el valor para el argumento N pasado al programa
aslr
Habilitar o deshabilitar ASLR
bits
Establecer 32 o 64 bits (si la arquitectura lo soporta)
chdir
Cambiar de directorio antes de ejecutar el programa
chroot
Ejecutar el programa en chroot. Requiere alguna configuración previa
core
No limitar el tamaño del archivo core
connect
Conectar stdin/stdout/stderr a un socket
pty
Usar un pty para la conexión por socket (con connect/listen)
envfile
Establecer un archivo con líneas como `var=valor` para ser usado como entorno
fork
Usado con la opción listen, permite generar un proceso diferente para cada conexión. Ignorado durante la depuración.
input
Establecer la cadena a pasar al programa a través de stdin
libpath
Anular la ruta donde el cargador dinámico buscará bibliotecas compartidas
listen
Vincular stdin/stdout/stderr a un socket de escucha
maxstack
Establecer el tamaño máximo de la pila
maxproc
Establecer el número máximo de procesos
maxfd
Establecer el número máximo de descriptores de archivo
nice
Establecer el nivel de niceness del proceso
preload
Precargar una biblioteca (no compatible con Windows, solo linux, osx, bsd)
daemon
Establecido en falso por defecto, de lo contrario ejecutará el programa en segundo plano, separado de la terminal.
program
Ruta al programa a ejecutar
pid
Establecer en verdadero para imprimir el PID del proceso en stderr
pidfile
Imprimir el PID del proceso en el archivo especificado
runlib
Ruta a la biblioteca a ejecutar
runlib.fcn
Nombre de la función a llamar desde la biblioteca runlib
rzpreload
Precargar con librz, matar -USR1 para obtener un shell de rizin o -USRZ para generar un servidor web en un hilo
setenv
Establecer el valor para una variable de entorno dada
setegid
Establecer el ID de grupo de proceso efectivo
seteuid
Establecer el UID de proceso efectivo
setgid
Establecer el ID de grupo del proceso
setuid
Establecer el UID del proceso
sleep
Dormir durante la cantidad de segundos dada
stdio=value
Establecer los flujos de E/S (stdin, stdout, stderr) a un valor
stdio=!cmd
Redirigir entrada/salida al proceso creado por el comando especificado
stdin
Establecer los flujos stdin, stdout y stderr al valor especificado
stdout
Seleccionar archivo para reemplazar el descriptor de archivo stdout
stderr
Seleccionar archivo para reemplazar el descriptor de archivo stderr
system
Ejecutar el comando dado
timeout
Establecer un tiempo de espera
timeoutsig
Señal a usar al matar al hijo porque ocurre el tiempo de espera
unsetenv
Eliminar una variable de entorno

PREFIJOS DE VALOR

Cada valor en este archivo de configuración puede contener un especial

@filename
Cargar el contenido del archivo y colocarlo dentro de la clave
text
Escapar caracteres útiles para caracteres hexadecimales
'string'
Escapar caracteres útiles para caracteres hexadecimales
!cmd
Ejecutar comando para almacenar la salida en la variable
:102030
Analizar la cadena hexpair y almacenarla en la variable
:!cmd
Analizar la cadena hexpair de la salida del comando y almacenarla en la variable
%1234
Analiza la cadena de entrada y la devuelve como un entero

EJEMPLOS

Script de ejemplo rz-run


$ cat foo.rrz
#!/usr/bin/rz-run
program=./pp400
arg0=10
stdin=foo.txt
chdir=/tmp
clearenv=true
setenv=EGG=eggsy
setenv=NOFUN=nogames
unsetenv=NOFUN
# EGG será la única variable de entorno
#chroot=.
./foo.rrz

Conectar un programa a un socket

nc -l 9999

rz-run program=/bin/ls connect=localhost:9999

Depurar un programa redirigiendo E/S a otra terminal


## abre una nueva terminal y escribe 'tty' para obtener
$ tty ; clear ; sleep 999999
/dev/ttyS010
## en otra terminal ejecuta rizin
$ rizin -r foo.rrz -d ls
$ cat foo.rrz
#!/usr/bin/rz-run
stdio=/dev/ttys010
## O puedes usar -R para establecer una clave=valor
rizin -R stdio=/dev/ttys010 -d ls

También puedes usar el indicador -- para especificar el programa y los argumentos de una manera más natural:

rz-run timeout=2 -- sleep 4

Ejecutar una función de biblioteca

rz-run runlib=/lib/libc-2.25.so runlib.fcn=system arg1="ls /"

NOMBRE

rz-run - Ejecuta comandos de Rizin en scripts.

SINOPSIS

rz-run [--] [arch][://...]]

DESCRIPCIÓN

La utilidad rz-run se usa para ejecutar comandos de Rizin en scripts.

Por ejemplo, puedes usarlo para automatizar tareas como buscar cadenas en binarios o analizar información de depuración.

El argumento principal es una cadena de comando o una URL de Rizin que especifica el archivo a abrir y el comando a ejecutar.

DIRECTIVAS

Las directivas son comandos que se pasan a Rizin. Algunas directivas comunes incluyen:

  • e [var]=[val]: Establece una variable de configuración.
  • is [addr]: Salta a una dirección dada.
  • pi [n]: Imprime n instrucciones.
  • px [n]: Imprime n bytes en formato hexadecimal.
  • ?: Evalúa una expresión.

PREFIJOS DE VALOR

rz-run admite varios prefijos para especificar valores:

  • 0x: Prefijo hexadecimal.
  • 0b: Prefijo binario.
  • 0: Prefijo octal.
  • 'c': Carácter.
  • "s": Cadena.

EJEMPLOS

# Abrir un binario y mostrar las primeras 16 instrucciones
rz-run rz://path/to/binary 'pi 16'

# Establecer un valor de configuración y luego imprimir 8 bytes
rz-run rz://path/to/binary 'e scr.color=false; px 8'

# Buscar una cadena en un archivo
rz-run rz://path/to/binary '? rz_string_search("my_string")'
