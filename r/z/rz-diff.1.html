RZ_DIFF(1) Manual de Comandos Generales RZ_DIFF(1)

NOMBRE

RZ_DIFF — Compara archivos y encuentra diferencias binarias.

SINOPSIS

rz-diff [OPCIONES] archivo0 archivo1

DESCRIPCIÓN

rz-diff compara dos archivos o programas binarios y resalta las diferencias entre ellos. Soporta la comparación de diferentes aspectos como bytes crudos, líneas de texto, funciones, secciones, cadenas, etc., basándose en las opciones utilizadas.

-A
Compara direcciones virtuales del archivo0 con direcciones físicas en el archivo1
-a [arch]
Especifica el plugin de arquitectura a usar para el análisis (ej. x86, arm)
-b [bits]
Especifica el tamaño de registro para la arquitectura elegida (ej. 16, 32, 64)
-B
Ejecuta 'aaa' al cargar el binario
-C
Deshabilita el uso de colores en la salida
-d [algo]
Calcula la distancia de edición entre archivos usando el algoritmo elegido:
myers
Algoritmo O(ND) de Eugene W. Myers (sin sustitución)
leven
Algoritmo Levenshtein O(N^2) (con sustitución)
ssdeep
Comparación de hash de piezas activadas por contexto
-e [k=v]
Establece una variable de configuración evaluable
-H
Habilita el modo visual hexadecimal para comparar archivos en formato hexadecimal
-h
Muestra el mensaje de ayuda
-i
Usa argumentos de línea de comandos en lugar de archivos (solo para -d)
-j
Genera la salida de los resultados de la comparación en formato JSON
-q
Genera una salida silenciosa con información mínima
-0 [cmd]
Entrada para el archivo0 cuando se usa la opción -t 'commands'
-1 [cmd]
Entrada para el archivo1 cuando se usa la opción -t 'commands'
-S [AxA]
Establece el ancho y alto de la terminal para el modo visual
-t [tipo]
Calcula la diferencia entre dos archivos basándose en el tipo especificado:
bytes
Compara bytes crudos en los archivos (solo para archivos pequeños)
lines
Compara archivos de texto
functions
Compara funciones encontradas en los archivos
classes
Compara clases encontradas en los archivos
command
Compara la salida del comando devuelta al ejecutarse en ambos archivos. Requiere -0 <cmd>, -1 <cmd> es opcional.
entries
Compara entradas encontradas en los archivos
fields
Compara campos encontrados en los archivos
graphs
Compara 2 funciones y genera la salida en formato graphviz/dot. Requiere -0 <nombre_función|offset>, -1 <nombre_función|offset> es opcional.
imports
Compara importaciones encontradas en los archivos
libraries
Compara bibliotecas encontradas en los archivos
sections
Compara secciones encontradas en los archivos
strings
Compara cadenas encontradas en los archivos
symbols
Compara símbolos encontrados en los archivos
-T
Muestra información de marca de tiempo en la salida
-V
Muestra información de la versión de rz-diff
-v
ser más verboso (salida a stderr)

Los colores de la paleta se pueden cambiar añadiendo las siguientes líneas dentro del archivo $HOME/.rizinrc

ec diff.unknown blue
color de desplazamiento
ec diff.match green
color de coincidencia
ec diff.unmatch red
color de no coincidencia

EJEMPLO

Compara dos archivos binarios usando la configuración predeterminada:

rz-diff archivo1.bin archivo2.bin

Compara dos archivos de texto y muestra la salida en formato JSON:

rz-diff -j -t lines archivo1.txt archivo2.txt

Compara dos funciones de un plugin de arquitectura:

rz-diff -t graphs -0 funcion1 -1 funcion2 binario1 binario2
