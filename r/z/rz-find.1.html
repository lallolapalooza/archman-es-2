RZ_FIND(1) Manual de comandos generales RZ_FIND(1)

NOMBRE

rz-find — Busca patrones de bytes en archivos

SINOPSIS

rz-find [-hijmnrqvxzZ] [-a alineacion] [-b tamaño] [-f/t desde/hasta] [-[e|s|w|S|I] cadena] [-x hex] [-|archivo|directorio ..]

DESCRIPCIÓN

Este comando es parte del proyecto Rizin.

rz-find Busca patrones de bytes, cadenas o pares de bytes especificados en los archivos dados.

Las opciones son:

-a alineacion
Aceptar solo coincidencias alineadas
-b tamaño
Establecer tamaño de bloque
-e regex
Buscar coincidencias de regex (se puede usar varias veces)
-f desde
Empezar a buscar desde la dirección 'desde'
-F archivo
Leer el contenido del archivo y usarlo como palabra clave
-h
Mostrar mensaje de ayuda de uso
-i
Identificar tipo de archivo (rizin -nqcpm archivo)
-j
Salida en JSON
-m
Búsqueda mágica, excavador de tipos de archivo
-M cadena
Establecer una máscara binaria a aplicar en las palabras clave
-n
No detener la búsqueda cuando ocurra un error de lectura
-r
Imprimir usando comandos de rizin
-s cadena
Buscar una cadena específica (se puede usar varias veces)
-w cadena
Buscar una cadena ancha específica (se puede usar varias veces). Asume que la cadena es UTF-8
-I cadena
Buscar una entrada en la tabla de importaciones
-S cadena
Buscar un símbolo en la tabla de símbolos
-t hasta
Detener la búsqueda en la dirección 'hasta'
-q
Modo silencioso - no mostrar encabezados (nombres de archivo) encima del contenido coincidente (predeterminado para buscar un solo archivo)
-v
Mostrar información de la versión
-x hex
Buscar una cadena de pares de bytes hexadecimales (se puede usar varias veces)
-X
Mostrar volcado hexadecimal de los resultados de la búsqueda
-z
Buscar cadenas terminadas en cero
-Z
Mostrar la cadena encontrada en cada coincidencia de búsqueda
-E comando
Ejecutar <comando> para cada archivo encontrado.
