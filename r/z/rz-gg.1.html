RZ_GG(1) Manual de comandos generales RZ_GG(1)

NOMBRE

rz-gg — Frontend de Rizin para RzEgg, compila programas en binarios diminutos para diferentes arquitecturas.

SINOPSIS

rz-gg [-FOLsrxvhz] [-a arch] [-b bits] [-k os] [-f formato] [-o archivo] [-i shellcode] [-I ruta] [-e codificador] [-B pareshex] [-c k=v] [-C archivo] [-n dword] [-N dword] [-d off:dword] [-D off:qword] [-w off:pareshex] [-p relleno] [-P tamaño] [-q fragmento] archivo|f.asm|-

DESCRIPCIÓN

Este comando es parte del proyecto Rizin.

Los programas generados por RzEgg son reubicables y pueden ser inyectados en un proceso en ejecución o en un archivo binario en disco.

Desde la fusión de rz-gg-cc, rz-gg ahora puede generar shellcodes a partir de código C. El código final se puede enlazar con rz-bin, y es reubicable, lo que permite la inyección en cualquier proceso remoto. Esta característica se basa conceptualmente en shellforge4, pero solo admite plataformas Linux/OSX x86-32/64.

DIRECTIVAS

El archivo de configuración rrz (rz-gg) acepta las siguientes directivas, descritas como entradas clave=valor y comentarios definidos como líneas que comienzan con '#'.

-a arch
Selecciona arquitectura (x86, mips, arm)
-b bits
Establece el tamaño del registro (32, 64, ..)
-B pareshex
Agrega bytes de pares hexadecimales
-c k=v
Establece una opción de configuración para el codificador de shellcode. El argumento debe ser clave=valor
-C archivo
Agrega el contenido del archivo
-d off:dword
Parchea dword (4 bytes) en el desplazamiento dado
-D off:qword
Parchea qword (8 bytes) en el desplazamiento dado
-e codificador
Usa un codificador específico. Ver -L
-f formato
Formato de salida (raw, c, pe, elf, mach0, python, javascript)
-F
Salida en formato nativo (osx=mach0, linux=elf, ..)
-h
Muestra el mensaje de ayuda de uso
-i shellcode
Incluye un plugin de shellcode, usa opciones. Ver -L
-I ruta
Agrega una ruta de inclusión
-k kernel
Núcleo del sistema operativo (linux, bsd, osx, w32)
-L
Lista todos los plugins (shellcodes y codificadores)
-n num32
Agrega un número de 32 bits (4 bytes)
-N num64
Agrega un número de 64 bits (8 bytes)
-o archivo
Archivo de salida donde se escribirá el resultado de la compilación
-O
Usa el archivo de salida predeterminado (nombre de archivo sin extensión o a.out)
-p relleno
Agrega relleno después de la compilación (relleno=n10s32)
ntas : nop, trap, 'a', secuencia al inicio
NTAS : igual que lo anterior, pero al final
-P tamaño
Precede con una secuencia de De Bruijn de la longitud dada
-q fragmento
Desplazamiento del patrón de De Bruijn
-r
Muestra bytes en bruto en lugar de pares hexadecimales
-s
Muestra el ensamblador
-S cadena
Agrega una cadena
-v
Muestra información de la versión
-w off:hex
Parchea pares hexadecimales en el desplazamiento dado
-x
Ejecutar
-X pareshex
Ejecuta una cadena ROP, utilizando la pila proporcionada
-z
Salida en sintaxis de cadena C

EJEMPLO


$ cat hi.r
/* hola mundo en RzEgg */
write@syscall(4); //x64 write@syscall(1);
exit@syscall(1); //x64 exit@syscall(60);


main@global(128) {
.var0 = "hola!\n";
write(1,.var0, 4);
exit(0);
}
$ rz-gg -O -F hi.r
$ ./hi
hola!


# Con archivo C :
$ cat hi.c
main() {
write(1, "Hola\n", 6);
exit(0);
}
$ rz-gg -O -F hi.c


$ ./hi
Hola


# Enlazado en un binario diminuto. Esto tiene 165 bytes
$ wc -c < hi
165


# El shellcode compilado tiene ceros
$ rz-gg hi.c | tail -1
