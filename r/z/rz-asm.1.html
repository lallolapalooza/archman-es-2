NOMBRE

rz-asm — herramienta de ensamblador y desensamblador de Rizin

SINOPSIS

rz-asm [-ABCdDeIEhjLpqrvxw] [-a arch] [-b bits] [-m plugin] [-c CPU] [-O archivo] [-o dir] [-@ dir] [-f archivo] [-F entrada:salida] [-i longitud] [-k kernel] [-s sintaxis] [-l longitud]

DESCRIPCIÓN

Este comando es parte del proyecto Rizin.

Esta herramienta utiliza RzAsm para ensamblar y desensamblar archivos o cadenas de hex pares. Soporta una gran lista de arquitecturas que se pueden listar usando la opción -L.

-a arch
Establecer la arquitectura para ensamblar/desensamblar (ver -L)
-A
Mostrar información de análisis de los hex pares proporcionados
-b bits
Establecer el tamaño del registro de la CPU (8, 16, 32, 64) (RZ_ASM_BITS)
-B
Entrada/salida binaria (-l es obligatorio para entrada binaria)
-c CPU
Seleccionar una CPU específica (depende de la arquitectura)
-C
Salida en formato C
-d, -D
Desensamblar a partir de bytes de hex pares (-D mostrar hex pares)
-e
Usar big endian en lugar de little endian
-I
Mostrar código RzIL levantado (misma entrada que en -d, IL también se valida)
-E
Mostrar expresión ESIL (misma entrada que en -d)
-f archivo
Leer datos del archivo
-F entrada:salida
Especificar filtros de entrada y/o salida (att2intel, x86.pseudo, ...)
-h, -hh
Mostrar mensaje de ayuda, hh para la versión larga
-i longitud
Ignorar N bytes del búfer de entrada
-j
Salida en formato JSON
-k kernel
Seleccionar sistema operativo (linux, windows, darwin, ..)
-l longitud
Longitud de entrada/salida
-L
Listar plugins de asm: (a=asm, d=disasm, A=analizar, e=ESIL)
-m plugin
Listar CPUs compatibles para el plugin elegido
-o, -@ dir
Establecer la dirección inicial para el código (por defecto 0)
-O archivo
Nombre del archivo de salida (rz-asm -Bf a.asm -O a)
-p
Ejecutar SPP sobre la entrada para ensamblar
-q
Modo silencioso
-r
Salida en comandos de rizin
-s sintaxis
Seleccionar sintaxis (intel, att)
-v
Mostrar información de la versión
-x
Usar dwords hexadecimales en lugar de pares hexadecimales al ensamblar
-w
Describir opcode

Usar sintaxis Intel en lugar de AT&T
.att_syntax

.align numero
Establecer la alineación del código o los datos
.arch nombre
Establecer la arquitectura del código
.arm
Establecer el modo ARM (en contraposición a Thumb) para la arquitectura ARM
.ascii cadena
Definir la cadena ASCII
.asciz cadena
Definir la cadena ASCII terminada en cero
.bits numero
Definir los bits del código
.big_endian
Establecer el orden de bytes BE (big endian)
.cpu nombre
Establecer la CPU para la arquitectura elegida
.data
Marcar el inicio de la sección de datos
.endian 1|0
Establecer la endianidad (el orden de bytes) - 1 es BE, 0 es LE
.equ nombre valor
Definir la constante
.fill repeticion,tamaño,valor
Rellenar los datos con el patrón de valor repetido
.hex datos
Definir los datos en formato hexadecimal
.incbin nombre_archivo
Incluir archivo binario
.int16 numero
Definir entero de 16 bits
.int32 numero
Definir entero de 32 bits
.int64 numero
Definir entero de 64 bits
.kernel nombre
Establecer el kernel para llamadas al sistema
.little_endian
Establecer el orden de bytes LE (little endian)
.org valor
Establecer el valor del registro PC (Contador de Programa)
.os nombre
Establecer el sistema operativo para llamadas al sistema
