RZ_AX(1) Manual de Comandos Generales RZ_AX(1)

NOMBRE

rz-ax — convertidor de base de rizin

SINOPSIS

rz-ax [-ebBdDeEfFhiIklLosStuvwx] [[expresión] ...]

DESCRIPCIÓN

Este comando es parte del proyecto Rizin.

Este comando te permite convertir valores entre enteros positivos y negativos, flotantes, octales, binarios, ternarios y hexadecimales.

OPCIONES

-a
Mostrar tabla ASCII
-b
Convertir de binario a cadena (rz-ax -b 01000101 01110110)
-B
Convertir de cadena a binario (rz-ax -B hola)
-d
Forzar salida como entero (rz-ax -d 3 produce 3 en lugar de 0x3)
-D
Decodificar Base64
-e
Intercambiar el orden de los bytes (endianness) (rz-ax -e 0x33)
-E
Codificar Base64
-f
Aritmética de punto flotante (rz-ax -f 6.3+2.1)
-F
Leer cadenas C desde stdin y producirlas en pares hexadecimales. Útil para cargar shellcodes (rz-ax -F < shellcode.[c/py/js])
-h
Mostrar mensaje de ayuda de uso
-i
Volcar stdin a un array C en stdout (rz-ax -i < bytes)
-I
Convertir LONG a/desde DIRECCIÓN IP (rz-ax -I 3530468537)
-k
Mantener la misma base que los datos de entrada (rz-ax -k 33+3 -> 36)
-l
Añadir una nueva línea a la salida decodificada
-L
Convertir binario a hexadecimal (rz-ax -L 111111111 produce 0x1ff)
-n
Mostrar pares hexadecimales de un valor entero (rz-ax -n 0x1234 # 34120000)
-N
Mostrar cadena C hexadecimal de un valor entero (rz-ax -N 0x1234 # 4200)
-o
Convertir de cadena octal a carácter (rz-ax -o 162 172 # rz)
-r
Salida estilo Rz (rz-ax -r 0x1234)
-s
Convertir de cadena hexadecimal a carácter (rz-ax -s 43 4a 50)
-S
Convertir de carácter a cadena hexadecimal (rz-ax -S < /bin/ls > ls.hex)
-t
Convertir marca de tiempo Unix a cadena (rz-ax -t 1234567890)
-m
Convertir marca de tiempo MS-DOS a cadena (rz-ax -m 0x12345678)
-W
Convertir marca de tiempo Win32 a cadena (rz-ax -W 1234567890)
-u
Convertir valor dado a formato de unidades legibles por humanos (rz-ax -u 389289238 # 317.0M)
-v
Mostrar información de versión
-w
Convertir palabra con signo (rz-ax -w 16 0xffff)
-x
Convertir una cadena en un hash (rz-ax -x linux osx)
-p
Mostrar la posición de los bits establecidos en la representación binaria (rz-ax -p 0xb3)

USO

Forzar modo de salida (base numérica)


=f punto flotante
=2 binario
=3 ternario
=8 octal
=10 decimal
=16 hexadecimal

Los tipos de variables disponibles son:


int -> hex rz-ax 10
hex -> int rz-ax 0xa
-int -> hex rz-ax -77
-hex -> int rz-ax 0xffffffb3
int -> bin rz-ax 30
int -> ternario rz-ax t42
ternario -> int rz-ax 1010dt
bin -> int rz-ax 1010d
float -> hex rz-ax 3.33f
hex -> float rz-ax Fx40551ed8
oct -> hex rz-ax 35o
hex -> oct rz-ax Ox12 (O es una letra)
bin -> hex rz-ax 1100011b
hex -> bin rz-ax Bx63
ternario -> hex rz-ax 212t
hex -> ternario z-ax Tx23
raw -> hex rz-ax -S < /binfile
hex -> raw rz-ax -s 414141

Sin argumentos, rz-ax lee valores desde stdin. Puedes pasar uno o más valores como argumentos.


$ rz-ax 33 0x41 0101b
0x21
65
0x5

Puedes 'desempaquetar' cadenas codificadas en pares hexadecimales fácilmente.


$ rz-ax -s 41 42 43
ABC

Y soporta algunas operaciones matemáticas.


$ rz-ax
0x5*101b+5
30

Es una herramienta muy útil para scripting, por lo que puedes leer valores de punto flotante, u obtener el desplazamiento entero de un salto o un delta de pila al analizar programas.
