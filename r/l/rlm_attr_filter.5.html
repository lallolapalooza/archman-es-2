rlm_attr_filter(5) Módulo FreeRADIUS rlm_attr_filter(5)

NOMBRE

rlm_attr_filter - Módulo FreeRADIUS

DESCRIPCIÓN

El módulo rlm_attr_filter existe para filtrar ciertos atributos y valores en paquetes radius recibidos (o transmitidos). Proporciona al servidor un marco flexible para filtrar los atributos que enviamos a o recibimos de servidores de origen o NAS. Esto tiene sentido, por ejemplo, en una situación de acceso telefónico externalizado para diversas decisiones de política, como restringir a un cliente a ciertos rangos de Idle-Timeout o Session-Timeout.

Las reglas de filtrado normalmente se definen y aplican por reino, donde el reino es cualquier cosa definida y emparejada según la configuración del módulo rlm_realm. Las reglas de filtrado se pueden aplicar opcionalmente utilizando otro atributo, editando la configuración key para este módulo.

En las versiones 2.0.1 y anteriores, la sección "accounting" filtraba Accounting-Request, a pesar de que se documentaba como filtrado de la respuesta. Este problema se ha corregido en la versión 2.0.2 y posteriores. La sección "preacct" ahora puede usarse para filtrar paquetes Accounting-Request. La sección "accounting" ahora filtra paquetes Accounting-Response. Los administradores que usan "attr_filter" en la sección "accounting" DEBERÍAN mover la referencia a "attr_filter" de "accounting" a "preacct".

El archivo que define las reglas de filtrado de atributos sigue una sintaxis similar al archivo users. Sin embargo, hay algunas diferencias:

    No se permiten elementos de verificación (check-items) aparte del nombre de la clave.
    Solo puede haber una entrada DEFAULT.
Las reglas para cada entrada se analizan de arriba a abajo, y un
atributo debe pasar *todas* las reglas que le afectan para poder
superar el filtro. El orden de las reglas es importante.
Los operadores y su propósito en la definición de las reglas son
los siguientes:
=
ESTE OPERADOR NO ESTÁ PERMITIDO. Si se usa, se imprime un mensaje de advertencia y se trata como ==
:=
Establecer, este atributo y valor siempre se colocarán en los Pares A/V de salida. Si el atributo existe, se sobrescribe.
==
Igual, el valor debe coincidir exactamente.
=*
Siempre Igual, permite todos los valores para el atributo especificado.
!*
Nunca Igual, prohíbe todos los valores para el atributo especificado.
(Esto es redundante, ya que cualquier Par A/V no permitido explícitamente
será descartado).
!=
No Igual, el valor no debe coincidir.
>=
Mayor o Igual que
<=
Menor o Igual que
>
Mayor que
<
Menor que
Si las expresiones regulares están habilitadas, los siguientes operadores
también son posibles. (Las expresiones regulares se incluyen por defecto
a menos que su sistema no las soporte, lo cual debería ser raro).
El campo de valor utiliza la sintaxis estándar de expresiones
regulares.
=~
Igual Expresión Regular
!~
No Igual Expresión Regular
Consulte el archivo /etc/raddb/mods-config/attr_filter/ predeterminado para
ver ejemplos de orden de reglas y cómo usar los diferentes operadores.

Los elementos de configuración son:

archivo
Esto especifica la ubicación del archivo utilizado para cargar las reglas de filtro. Este archivo se utiliza para filtrar la respuesta de contabilidad, el paquete antes de ser reenviado, la respuesta de reenvío del servidor de origen o nuestra respuesta al NAS.
clave
Normalmente %{Realm} (el valor predeterminado). También puede ser %{User-Name}, u otro atributo que exista en la solicitud. Tenga en cuenta que el módulo siempre se basa en atributos de la solicitud, y NO en cualquier otro paquete.
relajado
Si se establece en 'yes', los atributos que no coinciden explícitamente con ninguna regla de filtro también se permitirán. Este comportamiento puede ser anulado para un bloque de filtro individual usando el elemento de verificación Relax-Filter. El valor predeterminado para este elemento de configuración es 'no'.

SECCIONES

preacct
Filtra paquetes Accounting-Request.
accounting
Filtra paquetes Accounting-Response.
pre-proxy
Filtra paquetes Accounting-Request o Access-Request antes de reenviarlos.
post-proxy
Filtra respuestas Accounting-Response, Access-Accept, Access-Reject o Access-Challenge de un servidor de origen.
authorize
Filtra paquetes Access-Request.
post-auth
Filtra paquetes Access-Accept o Access-Reject.

ARCHIVOS
