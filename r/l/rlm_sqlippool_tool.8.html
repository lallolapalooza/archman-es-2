RLM_SQLIPPOOL_TOOL(8) Manual del Administrador del Sistema RLM_SQLIPPOOL_TOOL(8)

NOMBRE

rlm_sqlippool_tool - gestionar pools de IPs SQL

SINOPSIS

rlm_sqlippool_tool -p nombre_pool -s inicio_rango -e fin_rango -t nombre_tabla -d -f directorio_raddb -i instancia [-c capacidad] [-x archivo_ips_existentes]

rlm_sqlippool_tool -y archivo_yaml_definiciones_pool -t nombre_tabla -d -f directorio_raddb -i instancia [-x archivo_ips_existentes]

DESCRIPCIÓN

rlm_sqlippool_tool es una herramienta para gestionar direcciones IP en pools de IP SQL tal como los utiliza FreeRADIUS. Generará SQL que puede ser utilizado para manipular la base de datos o interactuará directamente con una base de datos para poblar una tabla de pool de IPs.

El formato del SQL de salida o los comandos operados en la base de datos se basan en los esquemas por defecto de FreeRADIUS para ippool. Los campos que se rellenan son pool_name y framedipaddress. Todos los demás campos se dejan para ser rellenados con sus valores predeterminados de la base de datos.

OPCIONES

-c capacidad
Número de direcciones IP para poblar el pool. El valor predeterminado es 65536, o el número máximo de direcciones que pueden ser provisionadas entre el inicio y el fin del rango.
-d dialecto
Dialecto SQL a utilizar para generar la salida.
-e fin_rango
Dirección IP final en el rango del pool. Se permiten direcciones IPv4 o IPv6.
-f directorio_raddb
Directorio que contiene la configuración de FreeRADIUS. Si se especifica esta opción, rlm_sqlippool_tool analizará la configuración e intentará comunicarse directamente con el servidor de base de datos especificado en la configuración de FreeRADIUS.
-i instancia
Se usa en conjunción con -f. Especifica el nombre de la instancia del módulo SQL a analizar en la configuración de FreeRADIUS. El valor predeterminado es sql.
-p nombre_pool
El nombre del pool a poblar.
-s inicio_rango
Dirección IP de inicio en el rango del pool. Se permiten direcciones IPv4 o IPv6.
-t nombre_tabla
Nombre de la tabla en la base de datos a poblar.
-x archivo_ips_existentes
Un archivo que contiene las direcciones IP existentes en el pool. El uso de esto permite un crecimiento más controlado de un pool escasamente poblado.
-y archivo_yaml_definiciones_pool
Un archivo con formato YAML que contiene especificaciones para varios pools.

EJEMPLOS

Para generar SQL con formato MySQL para un pool llamado local poblado con direcciones de 10.0.0.1 a 10.0.0.199:

$ rlm_sqlippool_tool -p local -s 10.0.0.1 -e 10.0.0.199 \
    -t dhcpippool -d mysql

Para hacer lo mismo pero interactuando directamente con el módulo SQL configurado en la configuración de FreeRADIUS bajo /etc/raddb:

$ rlm_sqlippool_tool -p local -s 10.0.0.1 -e 10.0.0.199 \
    -t dhcpippool -f /etc/raddb

Para usar un archivo YAML para especificar los rangos de pools a ser poblados, generando SQL con formato PostgreSQL:

$ rlm_sqlippool_tool -y pools.yaml -t dhcpippool -d postgresql

FORMATO YAML

Un archivo YAML para poblar múltiples pools debe tener el siguiente formato:

pool_con_un_rango_continuo:
  - start:    192.0.2.3
    end:      192.0.2.250
pool_con_un_rango_disperso:
  - start:    10.10.10.0
    end:      10.10.20.255
    capacity: 200
pool_con_múltiples_rangos:
  - start:    10.10.10.1
    end:      10.10.10.253
  - start:    10.10.100.0
    end:      10.10.199.255
    capacity: 1000
pool_v6_con_rango_continuo:
  - start:    '2001:db8:1:2:3:4:5:10'
    end:      '2001:db8:1:2:3:4:5:7f'
pool_v6_con_rango_disperso:
  - start:    '2001:db8:1:2::'
    end:      '2001:db8:1:2:ffff:ffff:ffff:ffff'
    capacity: 200

PRERREQUISITOS

Para generar SQL formateado, se requiere el módulo Perl Template::Toolkit.

La conexión directa a bases de datos se realiza utilizando Perl DBI. Se debe instalar el controlador DBD de Perl apropiado para habilitar esta funcionalidad.

VER TAMBIÉN

radiusd.conf(5), raddb/mods-available/sql
