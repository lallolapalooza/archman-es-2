rlm_passwd(5) Módulo FreeRADIUS rlm_passwd(5)

NOMBRE

rlm_passwd - Módulo FreeRADIUS

DESCRIPCIÓN

El módulo rlm_passwd proporciona autorización a través de archivos similares en formato a /etc/passwd.

Este módulo permite recuperar cualquier información de cuenta de cualquier archivo con formato similar a passwd (/etc/passwd, /etc/group, smbpasswd, .htpasswd, etc.). Cada campo del archivo puede ser mapeado a un atributo RADIUS, con uno de los campos utilizado como clave.

El módulo lee el archivo al inicializarse y almacena los datos en memoria. Esto lo hace muy rápido, incluso para archivos con miles de líneas. Para volver a leer el archivo, el módulo deberá ser recargado con radmin(8), o el servidor deberá recibir una señal SIGHUP, ya que las actualizaciones dinámicas no están soportadas.

CONFIGURACIÓN

El/los ítem(s) de configuración:

allow_multiple_keys
Si se establece en 'yes', y más de un registro en el archivo coincide con la solicitud, se utilizarán los atributos de todos los registros. Si se establece en 'no' (por defecto), el módulo advertirá sobre registros duplicados.
delimiter = ":"
El carácter a utilizar como delimitador entre campos. El valor por defecto es ":"
filename
La ruta al archivo.
format
El formato de los campos en el archivo, dado como una línea de ejemplo del archivo, con el contenido de los campos como los atributos RADIUS a los que los campos se mapean. Los campos están separados por el carácter ':' en la configuración (sin importar lo que se configure para la opción 'delimiter').
hash_size
El tamaño de la tabla hash. Un valor mayor significa menor probabilidad de colisión, por lo que los registros se encontrarán más rápido, a costa de un mayor uso de memoria. Tener un hash_size en el rango del 30-100% del número de registros del archivo passwd es razonable.
ignore_empty
Cuando se establece en "yes", por defecto, los campos vacíos en la entrada se omitirán y el atributo RADIUS no se añadirá. Al establecer este valor a "no", todos los atributos de la lista de formato se añadirán siempre, incluso si no tienen valor.
ignore_nislike
Si se establece en 'yes', se omitirán todos los registros del archivo que comiencen con el signo '+'. El valor por defecto es 'no'.

FORMATO

La opción format controla cómo se leen las líneas del archivo y qué campos se mapean a qué atributos RADIUS.

El campo clave es el campo que se busca dentro del archivo. Normalmente se indica precedido por un carácter '*', que indica que el campo tiene una única clave, como el archivo /etc/passwd. El campo clave puede estar precedido por '*,', que indica que el campo tiene múltiples claves separadas por comas, como al buscar en el archivo /etc/group.

Los otros campos significan atributos RADIUS. Por defecto, se añadirán como una lista de atributos de control.

Para añadir un atributo a la solicitud RADIUS (como si hubiera sido enviada por el NAS), prefije el nombre del atributo en la cadena "format" con el carácter '~'.

Para añadir un atributo a la respuesta RADIUS (a enviar de vuelta al NAS), prefije el nombre del atributo en la cadena "format" con el carácter '='.

EJEMPLOS

format = "*User-Name:Crypt-Password:"
Para un archivo similar a /etc/passwd. El primer campo, User-Name, es la clave a buscar en el archivo. Cuando se encuentra el registro, se añadirá un atributo de control, 'Crypt-Password', con el contenido del segundo campo. (Nota: esto no funcionará con contraseñas shadow).
format = "My-Group:::*,User-Name"
Analizar un archivo similar al archivo /etc/group. Una entrada coincide con una solicitud cuando el nombre en un atributo User-Name existe en la lista separada por comas de una línea en el archivo. Cuando una entrada coincide, se creará un atributo "My-Group" y se añadirá a los elementos de control de la solicitud. El valor de ese atributo se tomará del primer campo de la línea coincidente en el archivo.
El ":::" en la cadena de formato significa que hay dos campos adicionales en la línea, entre el nombre del grupo y la lista de nombres de usuario. Esos campos no se mapean a ningún atributo RADIUS y, por lo tanto, se ignoran.
Para que este ejemplo funcione en la práctica, deberá añadir el atributo My-Group al archivo de diccionario. Consulte dictionary(5) para obtener detalles sobre cómo hacerlo.
format = "~My-Group:::*,User-Name"
Similar a la entrada anterior, excepto que el atributo My-Group se añade a la solicitud, como si hubiera sido enviada por el NAS.
