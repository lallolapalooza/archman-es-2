rlm_mschap(5) Módulo de FreeRADIUS rlm_mschap(5)

NOMBRE

rlm_mschap - Módulo de FreeRADIUS

DESCRIPCIÓN

El módulo rlm_mschap proporciona soporte de autenticación MS-CHAP y MS-CHAPv2.

Este módulo valida a un usuario con autenticación MS-CHAP o MS-CHAPv2. Si se llama en Autorizar, buscará atributos de Desafío/Respuesta MS-CHAP en la Solicitud de Acceso y agregará un atributo Auth-Type establecido en MS-CHAP en la lista de Elementos de Configuración, a menos que Auth-Type ya se haya establecido.

El módulo puede autenticar la sesión MS-CHAP a través de contraseñas de texto plano (atributo User-Password) o contraseñas NT (atributo NT-Password). El módulo no puede realizar autenticación contra un dominio NT.

El módulo también aplica el atributo SMB-Account-Ctrl. Consulte la documentación de Samba para conocer el significado del control de cuenta de Samba. El módulo no lee archivos de contraseñas de Samba. En su lugar, el módulo rlm_passwd puede usarse para leer un archivo de contraseñas de Samba y proporcionar un atributo NT-Password que este módulo puede usar.

Los principales elementos de configuración a tener en cuenta son:

authtype
Esta es la cadena utilizada para establecer el tipo de autenticación. Normalmente, debe dejarse con el valor predeterminado de MS-CHAP.
use_mppe
A menos que esto se establezca en 'no', FreeRADIUS agregará claves MS-CHAP-MPPE para MS-CHAPv1 y claves MS-MPPE-Recv-Key/MS-MPPE-Send-Key para MS-CHAPv2. El valor predeterminado es 'yes'.
require_encryption
Si MPPE está habilitado, establecer este atributo en 'yes' hará que el atributo MS-MPPE-Encryption-Policy se establezca para requerir cifrado. El valor predeterminado es 'no'.
require_strong
Si MPPE está habilitado, establecer este atributo en 'yes' hará que el atributo MS-MPPE-Encryption-Types se establezca para requerir una clave de 128 bits. El valor predeterminado es 'no'.
with_ntdomain_hack
Los clientes de Windows envían User-Name en el formato "DOMINIO\Usuario", pero envían el desafío/respuesta basándose únicamente en la parte del Usuario. Establecer este valor en yes habilita una solución alternativa para este error. El valor predeterminado es 'no'.

CONFIGURACIÓN

modules {
  ...
  mschap {
	authtype = MS-CHAP
	use_mppe = yes	
  }
  ...
}
 ...
authorize {
  ...
  mschap
  ...
}
 ...
authenticate {
  ...
  mschap
  ...
}

SECCIONES

authorization, authentication
