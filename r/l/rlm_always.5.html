rlm_always(5) Módulo de FreeRADIUS rlm_always(5)

NOMBRE

rlm_always - Módulo de FreeRADIUS

DESCRIPCIÓN

El módulo rlm_always proporciona una forma sencilla de devolver "siempre" un valor durante el procesamiento de una sección de configuración.

El elemento de configuración principal es rcode, que establece el código de retorno que devolverá esta instancia del módulo. El valor por defecto, si no se especifica ninguno, es 'fail'.

Las opciones válidas para rcode son las siguientes:

reject
rechazar al usuario;
fail
ha ocurrido un fallo;
ok
éxito;
handled
la solicitud ha sido procesada: se debe detener el procesamiento y enviar la respuesta;
invalid
la solicitud es inválida;
userlock
la cuenta de usuario ha sido bloqueada;
notfound
no se puede encontrar la cuenta de usuario;
noop
sin operación: no ha ocurrido nada;
updated
la solicitud ha sido actualizada.

CONFIGURACIÓN

rcode = <código>
Este módulo siempre devolverá el código especificado, como se indica en la tabla anterior. Si no se especifica, el valor por defecto es 'fail'.
simulcount = <n>
Si este módulo se utiliza en la sección session{}, la opción simulcount simula que el usuario tiene 'n' sesiones activas. El valor por defecto es no anular el número de sesiones.
mpp = <sí|no>
Si se establece en sí, y este módulo se utiliza en la sección session{}, simula que el usuario tiene sesiones multilink. El valor por defecto es 'no'.

EJEMPLO

modules {
  ...
  # instancia el módulo "always" con el nombre "ok"
  always ok {
	# código de retorno para esta instancia es "ok":
	rcode = ok
  }
  ...
}
authorize {
  ...
  redundant {
     sql1          # intentar encontrar el usuario en sql1
     sql2          # intentar encontrar el usuario en sql2
     # el valor por defecto aquí sería fallar, pero...
     ok            # si todavía no se encuentra, está OK.
  }
  ...
}

SECCIONES

authorization, authentication, postauthentication, preaccounting, accounting, preproxy, postproxy

ARCHIVOS

/etc/raddb/mods-available/always

VER TAMBIÉN

radiusd(8), radiusd.conf(5), unlang(5)

Se pueden encontrar más detalles sobre cómo funcionan los códigos de retorno de los módulos en http://wiki.freeradius.org/config/Fail-over.
