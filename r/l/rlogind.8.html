RLOGIND(8) Utilidades de Administración del Sistema RLOGIND(8)

NOMBRE

rlogind - Servidor de login remoto

SINOPSIS

rlogind [OPCIÓN...]

DESCRIPCIÓN

Servidor de login remoto, usando el servicio PAM 'rlogin'.

-4, --ipv4
el modo demonio solo acepta IPv4
-6, --ipv6
solo IPv6 en modo demonio
-a, --verify-hostname
solicitar nombre de host para verificación
-d, --daemon[=MAX]
modo demonio, con límite de instancias
-D, --debug[=NIVEL]
establecer nivel de depuración
-l, --no-rhosts
ignorar el archivo .rhosts
-L, --local-domain=NOMBRE
establecer el nombre de dominio local
-n, --no-keepalive
no establecer SO_KEEPALIVE
-o, --allow-root
permitir el login del uid 0, deshabilitado por defecto
-p, --port=PUERTO
escuchar en el puerto dado (válido solo en modo demonio)
-r, --reverse-required
requerir resolución inversa de la IP del host remoto
-?, --help
mostrar esta lista de ayuda
--usage
mostrar un mensaje de uso corto
-V, --version
imprimir la versión del programa

Los argumentos obligatorios u opcionales para las opciones largas también son obligatorios u opcionales para cualquier opción corta correspondiente.
