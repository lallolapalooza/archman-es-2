rlm_files(5) Módulo de FreeRADIUS rlm_files(5)

NOMBRE

rlm_files - Módulo de FreeRADIUS

DESCRIPCIÓN

El módulo rlm_files utiliza el archivo 'users' para acceder a la información de autorización de los usuarios. Adicionalmente, soporta una sintaxis de archivo 'users' que se aplicará a las secciones de contabilidad y pre-proxy.

Los principales elementos de configuración a tener en cuenta son:

usersfile
El nombre del archivo 'users', que se analiza durante la etapa de autorización de este módulo.
acctusersfile
El nombre del archivo 'users', que se analiza durante la etapa de contabilidad de este módulo.
preproxy_usersfile
El nombre del archivo 'users', que se analiza durante la etapa pre_proxy de este módulo.
compat
Esta opción permite a FreeRADIUS analizar una sintaxis Cistron de estilo antiguo. El valor por defecto es 'no'. Si necesitas analizar un archivo Cistron de estilo antiguo, establece esta opción a 'cistron'.
key
Esta opción te permite establecer el atributo que se utilizará como clave para encontrar entradas. El valor por defecto es "%{%{Stripped-User-Name}:-%{User-Name}}". Ten en cuenta que la clave DEBE proporcionar datos reales. Los atributos dinámicos como "Group" no funcionarán, ya que el atributo "Group" solo se puede usar como comparación, para ver si un usuario está en un grupo de Unix. No devolverá el nombre del grupo de Unix al que pertenece un usuario.

Si deseas usar grupos como clave, consulta rlm_passwd, que creará un atributo real que contiene el nombre del grupo.

Esta entrada de configuración te permite tener configuraciones que realicen comprobaciones por grupo y devuelvan atributos por grupo, donde la pertenencia al grupo se define dinámicamente mediante un módulo anterior. También te permite hacer cosas como basarse en atributos de la respuesta y expresar políticas como "cuando envíe respuestas que contengan el atributo FOO con valor BAR, realiza comprobaciones adicionales y quizás envía atributos adicionales".

CONFIGURACIÓN

modules {
  ... cosas aquí ...
  files {
    usersfile = %{confdir}/users
    acctusersfile = %{confdir}/acct_users
    preproxy_usersfile = %{confdir}/preproxy_users
    compat = no
    key = %{%{Stripped-User-Name}:-%{User-Name}}
  }
  ... cosas aquí ...
}

SECCIONES

autorización, contabilidad, pre_proxy

ARCHIVOS

/etc/raddb/radiusd.conf, /etc/raddb/users, /etc/raddb/acct_users, /etc/raddb/preproxy_users

VER TAMBIÉN
