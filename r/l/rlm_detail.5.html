rlm_detail(5) Módulo FreeRADIUS rlm_detail(5)

NOMBRE

rlm_detail - Módulo FreeRADIUS

DESCRIPCIÓN

El módulo rlm_detail escribe paquetes RADIUS en archivos 'detail'. Se utiliza principalmente para almacenar información de contabilidad, pero se puede usar en otras secciones para escribir detalles de paquetes también.

El formato del archivo es similar al de los antiguos servidores Livingston, y muchos analizadores de archivos 'detail' deberían funcionar con FreeRADIUS.

Los elementos de configuración principales a tener en cuenta son:

archivo
El nombre del archivo en el que almacenar los registros de paquetes RADIUS. NOTA: esta variable se procesa mediante expansión de cadenas dinámicas y puede incluir variables de FreeRADIUS para crear un nombre de archivo dinámico.


%{radacctdir}/%{Client-IP-Address}/detail-%Y%m


Esto creará un archivo por mes, para cada cliente.
Esto logra la 'rotación de archivos' automáticamente desde
dentro del servidor.

permisos
Los permisos del archivo. Si se omite, el valor predeterminado es 0600.
bloqueo
Esta opción se establece en 'yes' o 'no'. Por defecto es 'no'. Establezca esto en yes para habilitar el bloqueo de archivos, que se usa con el programa 'radrelay'.

CONFIGURACIÓN

modules {
  ...
  detail {
    filename = ${radacctdir}/%{Client-IP-Address}/detail-%Y%m
    permissions = 0600
    dir_permissions = 0755
    locking = no
  }
  ... 
}
  ...
accounting {
 ...
 detail
 ...
}

SECCIONES

authorization, accounting, pre_proxy, post_proxy, post_authentication

ARCHIVOS

/etc/raddb/radiusd.conf

VER TAMBIÉN

radiusd(8), radiusd.conf(5)
