rlm_realm(5) Módulo de FreeRADIUS rlm_realm(5)

NOMBRE

rlm_realm - Módulo de FreeRADIUS

DESCRIPCIÓN

El módulo rlm_realm analiza el atributo User-Name en una sección de Usuario y una sección de Dominio (Realm). Esto se utiliza principalmente en situaciones de proxy, sin embargo, los Dominios también pueden usarse localmente para proporcionar diferentes perfiles de servicio basados en el Dominio que se está utilizando.

Los principales elementos de configuración a tener en cuenta son:

formato
Esto puede ser 'prefijo' o 'sufijo'. Especifica si el Dominio está antes o después de la parte del Usuario en la cadena User-Name.
delimitador
Un solo carácter entre comillas, que se utiliza como el carácter delimitador que separa las secciones de Dominio y Usuario de la cadena.
ignorar_predeterminado
Esto se establece en 'sí' o 'no'. Si se establece en 'sí', evitará que la instancia del módulo haga coincidir un dominio con la entrada DEFAULT. Esto puede ser útil si tiene varias instancias de módulo de dominio. El valor predeterminado es 'no'.
ignorar_nulo
Esto se establece en 'sí' o 'no'. Si se establece en 'sí', evitará que la instancia del módulo haga coincidir un dominio con la entrada NULL. Esto puede ser útil si tiene varias instancias de módulo de dominio. El valor predeterminado es 'no'.

Este módulo analiza el dominio del atributo User-Name de acuerdo con la configuración de la instancia, y luego realiza una búsqueda para encontrar un dominio coincidente en el archivo '/etc/raddb/proxy.conf'. Dependiendo de la configuración del Dominio tal como se encuentra en el archivo, el nombre de usuario puede ser reescrito en un formato 'stripped' (despojado), o con la parte del Dominio eliminada. En cualquier caso, se crea un atributo de Dominio y se agrega al paquete en caso de coincidencia, el cual puede ser utilizado por otros módulos.

CONFIGURACIÓN

modules {
  ... cosas aquí ...
  # sintaxis nombreusuario@dominio
  realm suffix {
    format = suffix
    delimiter = "@"
  }
   # sintaxis dominio/nombreusuario
   realm prefix {
    format = prefix
    delimiter = "/"
  }
  ... cosas aquí ...
}

SECCIONES

autorización, pre-contabilidad

ARCHIVOS

/etc/raddb/radiusd.conf, /etc/raddb/proxy.conf
