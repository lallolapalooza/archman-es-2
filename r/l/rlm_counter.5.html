rlm_counter(5) Módulo de FreeRADIUS rlm_counter(5)

NOMBRE

rlm_counter - Módulo de FreeRADIUS

DESCRIPCIÓN

El módulo rlm_counter proporciona un marco general para permitir el acceso basado en el uso acumulado de un recurso, como el tiempo total en línea en un período determinado, la transferencia total de datos en un período determinado, etc. Esto es muy útil en una situación de 'Servicio Prepago', donde un usuario ha pagado por una cantidad finita de uso y no se le debería permitir usar más que ese servicio. La recopilación, el monitoreo y el reabastecimiento de los servicios prepagos están fuera del alcance de este módulo.

Los elementos de configuración principales a tener en cuenta son:

filename
El nombre del archivo donde se almacenan los datos de uso.
key
Un atributo que estará presente en la Solicitud de Acceso para ser utilizado como el valor de 'índice' para el contador. Se rastrea una entrada de contador por cada clave única. La clave más probable que querrá usar es User-Name.
count_attribute
Un atributo que se utilizará para incrementar el valor del contador. Si este atributo es Acct-Session-Time o un valor entero, los datos del contador se incrementan por el valor del Atributo. Para todos los demás tipos de atributos, el contador se incrementa en uno.
reset
Con qué frecuencia se deben restablecer los datos del contador a 0. Los valores válidos para esta variable son: hourly, daily, weekly, monthly, o never Alternativamente, puede ser definido por el usuario, en el formato: num[hdwm]. num es un valor numérico, seguido de una o ninguna de las siguientes letras. h: horas, d: días, w: semanas, m: meses.
check_name
Esto define un nombre de atributo que será registrado por el módulo contador y puede ser utilizado para establecer el valor máximo permitido para el contador, después del cual el usuario es rechazado. Si se establece Max-Daily-Session-Time, puede usar la siguiente sintaxis en el archivo Users para establecer un límite de 3600 segundos (8 horas):
DEFAULT Max-Daily-Session := 3600
reply_name
Este es el nombre del atributo que contendrá el valor restante para el contador en el paquete de respuesta cuando el usuario sea autorizado exitosamente. El nombre de atributo predeterminado es "Session-Timeout".
allowed_service_type
Esto se puede utilizar para aplicar las limitaciones solo a tipos de servicio específicos de las sesiones. Por ejemplo, establecer esto a Framed-User solo aplicará el módulo contador a sesiones Framed, excluyendo otros tipos como Telnet o Rlogin.
cache_size
El tamaño máximo de la caché que será utilizada por el módulo. El valor predeterminado es 1000.

NOTAS

Este módulo registra un atributo, por lo que debe agregarse a la sección de instanciación, para ser llamado al inicio del servidor. Cuando se usa en la sección de autorización, debe venir después de cualquier módulo que establezca el atributo 'check_name'.

SECCIONES

instantiate, authorize, accounting

ARCHIVOS

/etc/raddb/radiusd.conf
