NOMBRE

rlm_unbound - Módulo FreeRADIUS

DESCRIPCIÓN

Cada instancia de rlm_unbound proporciona un cliente DNS incrustado para realizar búsquedas DNS. Cada instancia puede configurarse por separado para consultar diferentes horizontes DNS, cambiar las opciones DNSSEC, etc.

El módulo está diseñado principalmente para ser utilizado por otros módulos a través de APIs internas, por lo que las instancias deben inicializarse antes que los módulos que las utilizan. Cada instancia también proporciona algunas funcionalidades xlat para uso general y para solución de problemas.

Cada instancia de rlm_unbound puede tomar los siguientes parámetros:

filename
Este archivo debe existir y apuntar a un archivo de configuración de libunbound válido. El valor predeterminado es ${raddbdir}/mods-config/unbound/default.conf.
timeout
Mientras que libunbound proporciona una API asíncrona para uso interno, el uso de cualquier xlat se realiza de forma síncrona desde la perspectiva de unlang. Este valor limita el tiempo que una solicitud esperará una respuesta DNS, después de lo cual el xlat fallará. El valor predeterminado es 3000 milisegundos. Esta configuración es independiente de cualquier valor de configuración de libunbound.
resolvconf
Ruta completa de un archivo resolv.conf del cual cargar los detalles del resolver. Si esto no está establecido, libunbound consultará los servidores DNS raíz.
hosts
Ruta completa de un archivo hosts para cargar. Esto proporciona un mecanismo para anulaciones locales de nombres que de otro modo no se resolverían o que necesitarían resultados diferentes a los que proporcionaría una resolución DNS.

Una instancia denominada, por ejemplo, "dns" proporcionará las siguientes funcionalidades xlat:

%{dns-a:<owner>}
Realiza una búsqueda A del nombre owner, devolviendo una dirección IPv4 en formato de cadena. Solo se devolverá el primer registro A del RRSET.
%{dns-aaaa:<owner>}
Realiza una búsqueda AAAA del nombre owner, devolviendo una dirección IPv6 en formato de cadena. Solo se devolverá el primer registro AAAA del RRSET.
%{dns-ptr:<owner>}
Realiza una búsqueda PTR del owner.

ADVERTENCIAS

El registro de rlm_unbound puede ser problemático, especialmente si se utiliza más de una instancia del módulo. Esto se debe a la necesidad de funciones adicionales en el libunbound subyacente, que se espera que mejoren con el tiempo.

Existe la posibilidad de que un servidor FreeRADIUS que utilice rlm_unbound falle al terminar limpiamente (dejando procesos zombis, fallando al limpiar otros módulos y colgado después de una SIGTERM hasta que se envíe una SIGKILL) o falle las comprobaciones de valgrind durante la terminación cuando se ejecuta con -m. Asimismo, este problema dependerá de mejoras posteriores antes de que pueda ser solucionado, y el comportamiento exacto puede cambiar en versiones intermedias hasta entonces.

El comportamiento de registro de rlm_unbound puede variar dependiendo de si FreeRADIUS está compilado con soporte para hilos.
