rlm_digest(5) Módulo de FreeRADIUS rlm_digest(5)

NOMBRE

rlm_digest - Módulo de FreeRADIUS

DESCRIPCIÓN

El módulo rlm_digest autentica los paquetes RADIUS Access-Request que contienen atributos de autenticación digest de Cisco SIP. El módulo debe incluirse en las secciones authorize y authenticate de radiusd.conf.

CONFIGURACIÓN

El módulo digest no requiere elementos de configuración adicionales. Sin embargo, cuando se utiliza para autenticar solicitudes, requiere acceso a la contraseña en texto plano del usuario. Las contraseñas cifradas no son aceptables y no funcionarán.

EJEMPLOS

Agregue las siguientes líneas al principio de su archivo 'raddb/users':

#---
test	Auth-Type := Digest, User-Password = "test"
	Reply-Message = "Hola, test con digest"
#---

Una vez que el servidor se haya iniciado (se recomienda el modo de depuración), use 'radclient para enviar el siguiente paquete al servidor:

$  radclient -f digest localhost auth testing123

Donde 'digest' es un archivo que contiene:

  User-Name = "test",
  Digest-Response = "631d6d73147add2f9e437f59bbc3aeb7",
  Digest-Realm = "testrealm",
  Digest-Nonce = "1234abcd",
  Digest-Method = "INVITE",
  Digest-URI = "sip:5555551212@example.com",
  Digest-Algorithm = "MD5",
  Digest-User-Name = "test",
  Message-Authenticator = ""

Debería ver que la autenticación tiene éxito.

SECCIONES

authorize, authenticate

ARCHIVOS

/etc/raddb/radiusd.conf, draft-sterman-aaa-sip-00.txt
