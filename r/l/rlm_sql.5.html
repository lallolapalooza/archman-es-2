rlm_sql(5) Módulo de FreeRADIUS rlm_sql(5)

NOMBRE

rlm_sql - Módulo de FreeRADIUS

DESCRIPCIÓN

El módulo rlm_sql proporciona una interfaz SQL para recuperar información de autorización y almacenar información de contabilidad. Se puede utilizar junto con, o en lugar de, los módulos de archivos y detalles. El módulo SQL tiene controladores para soportar las siguientes bases de datos SQL:

     db2
     iodbc
     mysql
     oracle
     postgresql
     sybase
     unixodbc

Debido al tamaño de las variables de configuración, el módulo sql se configura generalmente en un archivo separado, que se incluye en el radiusd.conf principal mediante una directiva de inclusión.

Los principales elementos de configuración a tener en cuenta son:

driver
Esta variable especifica el controlador que se cargará.
server
login
password
Estos especifican el nombre del servidor, el nombre de usuario y la contraseña que el módulo utilizará para conectarse a la base de datos.
radius_db
El nombre de la base de datos donde se almacenan las tablas de radius.
acct_table1
acct_table2
Estos especifican los nombres de las tablas para los registros de contabilidad. acct_table1 especifica la tabla donde se almacenan los registros de Inicio. acct_table2 especifica la tabla donde se almacenan los registros de Fin. En la mayoría de los casos, esta debería ser la misma tabla.
postauth_table
El nombre de la tabla para almacenar datos de post-autenticación.
authcheck_table
authreply_table
Las tablas donde se almacenan los elementos de comprobación y respuesta individuales de los usuarios.
groupcheck_table
groupreply_table
Las tablas donde se almacenan los elementos de comprobación y respuesta grupales.
usergroup_table
La tabla donde se almacenan las relaciones de nombre de usuario a grupo.
deletestalesessions
Esta opción se establece en 'yes' o 'no'. Si está haciendo la comprobación de Uso Simultáneo, y esto está establecido en yes, se eliminarán las sesiones obsoletas (definidas como sesiones para las que no se recibió un registro de Fin).
logfile
Esta opción es útil para depurar problemas de sql. Si logfile está establecido, entonces todas las consultas sql para la sección que lo contiene se escriben en el archivo especificado. Esto es útil para la depuración e inserciones masivas.
num_sql_socks
El número de conexiones sql a realizar a la base de datos.
connect_failure_retry_delay
El número de segundos a esperar antes de intentar reconectar a una conexión de base de datos fallida.
sql_user_name
Esta es la definición del atributo SQL-User-Name. Se establece una vez, para que pueda usar %{SQL-User-Name} en las consultas SQL, en lugar de la sustitución anidada de nombre de usuario. Esto asegura que el nombre de usuario se analiza de forma coherente para todas las consultas SQL ejecutadas.
default_user_profile
Este es el nombre de perfil predeterminado que se aplicará a todos los usuarios si se establece. No está configurado por defecto.
query_on_not_found
Esta opción se establece en 'yes' o 'no'. Si se establece en yes, entonces se devuelve el perfil de usuario predeterminado si no se encontró una coincidencia específica para el usuario.
authorize_check_query
authorize_reply_query
Estas consultas se ejecutan durante la etapa de autorización para extraer la información de autorización del usuario de las tablas ${authcheck_table} y ${authreply_table}.
authorize_group_check_query
authorize_group_reply_query
Estas consultas se ejecutan durante la etapa de autorización para extraer la información de autorización del grupo de las tablas ${groupcheck_table} y ${groupreply_table}.
accounting_onoff_query
La consulta que se ejecutará al recibir un paquete de Contabilidad Activada o Contabilidad Desactivada.
accounting_update_query
accounting_update_query_alt
La consulta que se ejecutará al recibir un paquete de Actualización de Contabilidad. Si la consulta principal falla, se ejecuta la consulta alternativa.
accounting_start_query
accounting_start_query_alt
La consulta que se ejecutará al recibir un paquete de Inicio de Contabilidad. Si la consulta principal falla, se ejecuta la consulta alternativa.
accounting_stop_query
accounting_stop_query_alt
La consulta que se ejecutará al recibir un paquete de Fin de Contabilidad. Si la consulta principal falla, se ejecuta la consulta alternativa.
simul_count_query
La consulta que se ejecutará para devolver el número de sesiones simultáneas para los propósitos de limitar el Uso Simultáneo.
simul_verify_query
La consulta para devolver la información detallada necesaria para confirmar que todas las sesiones sospechosas conectadas son válidas y no son sesiones obsoletas.
group_membership_query
La consulta que se ejecutará para comprobar la pertenencia de un usuario a un grupo.
postauth_query
La consulta que se ejecutará durante la etapa de post-autenticación.
