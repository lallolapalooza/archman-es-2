RLOGIN(1) Comandos de usuario RLOGIN(1)

NOMBRE

rlogin - Inicio de sesión remoto

SINOPSIS

rlogin [OPCIÓN...] HOST

DESCRIPCIÓN

Inicia una sesión de terminal en un host remoto.

-4, --ipv4
usar solo IPv4
-6, --ipv6
usar solo IPv6
-8, --8-bit
permite un canal de datos de entrada de ocho bits en todo momento
-d, --debug
establece la opción SO_DEBUG
-e, --escape=CARACTER
permite la especificación por el usuario del carácter de escape, que es ``~'' por defecto
-E, --no-escape
detiene que cualquier carácter sea reconocido como carácter de escape
-l, --user=USUARIO
ejecutar como USUARIO en el sistema remoto
-?, --help
mostrar esta lista de ayuda
--usage
mostrar un mensaje de uso corto
-V, --version
imprimir la versión del programa

Los argumentos obligatorios u opcionales para las opciones largas también son obligatorios u opcionales para cualquier opción corta correspondiente.
