RLM_IPPOOL_TOOL(8) Manual del Administrador del Sistema RLM_IPPOOL_TOOL(8)

NOMBRE

rlm_ippool_tool - volcar el contenido de los archivos de base de datos ippool de FreeRadius

SINOPSIS

Si se especifica una dirección IP, esta se utilizará para limitar las acciones o la salida.

rlm_ippool_tool [-a] [-c] [-o] [-v] sesion-db indice-db [direccion-ip]

Marcar la entrada nasIP/nasPort como que tiene la dirección IP

rlm_ippool_tool -n sesion-db indice-db direccion-ip nasIP nasPort

Actualizar la base de datos del formato antiguo al nuevo.

rlm_ippool_tool -u sesion-db nueva-sesion-db

DESCRIPCIÓN

rlm_ippool_tool vuelca el contenido de las bases de datos ippool de FreeRADIUS para análisis o para la eliminación de entradas activas (atascadas?).

O con el argumento -n añade una entrada de uso a las bases de datos ippool de FreeRADIUS.

OPCIONES

-a
Imprimir todas las entradas activas.
-c
Informar el número de entradas activas.
-r
Eliminar entradas activas.
-v
Informe detallado de todas las entradas.
-o
Asumir formato de base de datos antiguo (par nas/puerto, no salida md5).
-n
Marcar la entrada nasIP/nasPort como que tiene la dirección IP.
-u
Actualizar la base de datos del formato antiguo al nuevo.

EJEMPLOS

Dada la sintaxis en el radiusd.conf de FreeRadius:

 ippool myippool {
	range-start = 192.0.2.0
	range-stop = 192.0.2.255
	[...]
	session-db = ${raddbdir}/ip-pool.db
	ip-index = ${raddbdir}/ip-index.db
 }

Para ver el número de entradas activas en este pool, use:

 $ rlm_ippool_tool -c ip-pool.db ip-index.db
 13

Para ver todas las entradas activas en este pool, use:

 $ rlm_ippool_tool -a ip-pool.db ip-index.db
 192.0.2.5
 192.0.2.82
 192.0.2.244
 192.0.2.57
 192.0.2.120
 192.0.2.27
 [...]

Para ver toda la información sobre las entradas activas en el uso, use:

 $ rlm_ippool_tool -av ip-pool.db ip-index.db
 NAS:172.16.1.1 port:0x2e8 - ipaddr:192.0.2.5 active:1 cli:0 num:1
 NAS:172.16.1.1 port:0x17c - ipaddr:192.0.2.82 active:1 cli:0 num:1
 NAS:172.16.1.1 port:0x106 - ipaddr:192.0.2.244 active:1 cli:0 num:1
 NAS:172.16.1.1 port:0x157 - ipaddr:192.0.2.57 active:1 cli:0 num:1
 NAS:172.16.1.1 port:0x2d8 - ipaddr:192.0.2.120 active:1 cli:0 num:1
 NAS:172.16.1.1 port:0x162 - ipaddr:192.0.2.27 active:1 cli:0 num:1
 [...]

Para ver solo información de una entrada, use:

 $ rlm_ippool_tool -v ip-pool.db ip-index.db 192.0.2.1
 NAS:172.16.1.1 port:0x90 - ipaddr:192.0.2.1 active:0 cli:0 num:0

Para añadir una entrada de uso de dirección IP, use:

 $ rlm_ippool_tool -n ip-pool.db ip-index.db 192.0.0.1 172.16.1.1 0x90
 rlm_ippool_tool: Asignando ip a nas/puerto: 172.16.1.1/144
 rlm_ippool_tool: num: 1
 rlm_ippool_tool: IP asignada 192.0.2.1 al cliente en nas 172.16.1.1, puerto 144
