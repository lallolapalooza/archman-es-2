NOMBRE

gdb-add-index - Añadir archivos de índice para acelerar GDB

SINOPSIS

gdb-add-index nombre_archivo

DESCRIPCIÓN

Cuando GDB encuentra un archivo de símbolos, escanea los símbolos del archivo para construir una tabla de símbolos interna. Esto permite que la mayoría de las operaciones de GDB funcionen rápidamente, a costa de un retraso inicial. Para programas grandes, este retraso puede ser bastante largo, por lo que GDB ofrece una forma de construir un índice que acelera el arranque.

Para determinar si un archivo contiene dicho índice, use el comando "readelf -S nombre_archivo": el índice se almacena en una sección llamada ".gdb_index". El archivo de índice solo puede producirse en sistemas que usan binarios ELF e información de depuración DWARF (es decir, secciones llamadas ".debug_*").

gdb-add-index utiliza GDB y objdump encontrados en la variable de entorno PATH. Si desea utilizar diferentes versiones de estos programas, puede especificarlas a través de las variables de entorno GDB y OBJDUMP.

Vea más detalles en el manual de GDB en el nodo "Index Files" -- comando de shell "info -f gdb -n "Index Files"".
