RIGMEM(1) Utilidades Hamlib RIGMEM(1)

NOMBRE

rigmem - copia de seguridad y restauración de memoria de transceptores y receptores de radio

SINOPSIS

rigmem [-ahvVx] [-m id] [-r dispositivo] [-s velocidad] [-c id] [-C parm=val] [-p sep] comando [archivo]

DESCRIPCIÓN

Copia de seguridad y restauración de memoria de transceptores y receptores de radio. rigmem acepta comandos solo desde la línea de comandos.

Tenga en cuenta que Hamlib es software de nivel BETA. Aunque muchas bibliotecas de backend carecen de soporte completo para radio, las funciones básicas suelen estar bien soportadas.

Por favor, informe de errores y proporcione comentarios en la dirección de correo electrónico que se indica en la sección ERRORES a continuación. Los parches y las mejoras de código enviados a la misma dirección son bienvenidos.

OPCIONES

Este programa sigue la sintaxis habitual de línea de comandos de GNU. Las opciones cortas que toman un argumento pueden tener el valor inmediatamente después o separado por un espacio. Las opciones largas que comienzan con dos guiones (‘-’) requieren un ‘=’ entre la opción y cualquier argumento.

Aquí hay un resumen de las opciones compatibles:

-m, --modelo=id
Selecciona el número de modelo de la radio.
Ver lista de modelos (use “rigctl -l”).
-r, --archivo-radio=dispositivo
Usa dispositivo como nombre de archivo del puerto conectado a la radio.
A menudo es un puerto serie, pero podría ser un adaptador USB a serie. Típicamente /dev/ttyS0, /dev/ttyS1, /dev/ttyUSB0, etc. en Linux, COM1, COM2, etc. en MS Windows. Las variantes BSD y Mac OS/X tienen sus propias designaciones. Consulte la documentación de su sistema.
-s, --velocidad-serie=velocidad
Establece la velocidad serie de la radio a velocidad baudios.
Utiliza la velocidad serie máxima de las capacidades del backend de radio como predeterminada.
-c, --civaddr=id
Usa id como la dirección CI-V para comunicarse con la radio.
Solo útil para radios Icom y algunas Ten-Tec.
Nota: El id está en notación decimal, a menos que esté prefijado por 0x, en cuyo caso es hexadecimal.
-C, --set-conf=parm=val[,parm=val]
Establece parámetros de configuración de la radio, por ejemplo, stop_bits=2.
Use la opción -L de rigctl para obtener una lista de parámetros de configuración para un número de modelo dado.
-p, --set-separator=sep
Establece un carácter como separador de columnas en lugar de la coma CSV.
Algunas alternativas comunes son la barra vertical (pipe), ‘|’, el punto y coma, ‘;’, y los dos puntos, ‘:’.
-a, --all
Omite mem_caps, aplica a todos los campos de channel_t.
-x, --xml
Usa formato XML en lugar de CSV, si libxml2 está disponible.
-v, --verbose
Establece el modo detallado, acumulativo (ver DIAGNÓSTICOS abajo).
-h, --help
Muestra un resumen de estas opciones y sale.
-V, --version
Muestra la versión de rigmem y sale.

Nota: Es posible que algunas opciones no estén implementadas por un backend determinado y devuelvan un error. Esto es más probable que ocurra con la opción --set-conf.

COMANDOS

Se admiten copias de seguridad y restauración para archivos CSV básicos y formato XML cuando esté disponible.

Tenga en cuenta que el backend para la radio a controlar, o la propia radio, pueden no admitir algunos comandos. En ese caso, la operación fallará con un mensaje de error de Hamlib.

Aquí hay un resumen de los comandos compatibles:

save archivo
Guarda todo el contenido de la memoria en un archivo CSV (o XML) proporcionado como argumento al comando.
load archivo
Carga el contenido en toda la memoria desde un archivo CSV (o XML) proporcionado como argumento al comando.
save_parm archivo
Guarda todos los parámetros de la radio en un archivo CSV (o XML) proporcionado como argumento al comando.
load_parm archivo
Carga los parámetros de la radio desde un archivo CSV (o XML) proporcionado como argumento al comando.
clear
Este es un comando muy PELIGROSO, ya que borrará por completo todo lo que haya programado en la memoria de su radio. SE PERDERÁN TODOS LOS DATOS. ¡Úselo bajo su propio riesgo!

DIAGNÓSTICOS

La opción -v, --verbose permite diferentes niveles de diagnósticos para ser mostrados en stderr y corresponden a -v para BUG, -vv para ERR, -vvv para WARN, -vvvv para VERBOSE, o -vvvvv para TRACE.

Un nivel detallado determinado es útil para proporcionar la información de depuración necesaria a la dirección de correo electrónico a continuación. Por ejemplo, la salida TRACE muestra todos los valores enviados y recibidos de la radio, lo cual es muy útil para el desarrollo de bibliotecas de backend de radio y puede ser solicitado por los desarrolladores.

CÓDIGO DE SALIDA

rigmem sale con:

0
si todas las operaciones se completaron normalmente;
1
si hubo una opción o argumento de línea de comandos inválido;
2
si Hamlib devolvió un error.
3
el backend Hamlib no tiene soporte de memoria implementado y/o la radio no tiene acceso a memoria disponible.
