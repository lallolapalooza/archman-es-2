NOMBRE

gdb-add-index - Añade archivos de índice para acelerar GDB

SINOPSIS

gdb-add-index nombre_archivo

DESCRIPCIÓN

Cuando GDB encuentra un archivo de símbolos, escanea los símbolos en el archivo para construir una tabla de símbolos interna. Esto permite que la mayoría de las operaciones de GDB funcionen rápidamente, a costa de un retraso inicial. Para programas grandes, este retraso puede ser bastante largo, por lo que GDB proporciona una forma de construir un índice que acelera el inicio.

Para determinar si un archivo contiene dicho índice, usa el comando "readelf -S nombre_archivo": el índice se almacena en una sección llamada ".gdb_index". El archivo de índice solo se puede producir en sistemas que usan binarios ELF e información de depuración DWARF (es decir, secciones llamadas ".debug_*").

gdb-add-index utiliza GDB y objdump que se encuentran en la variable de entorno PATH. Si deseas usar diferentes versiones de estos programas, puedes especificarlas a través de las variables de entorno GDB y OBJDUMP.

Consulta más detalles en el manual de GDB en el nodo "Index Files" -- comando de shell "info -f gdb -n "Index Files"".
