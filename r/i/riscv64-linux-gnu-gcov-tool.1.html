NOMBRE

gcov-tool - herramienta de procesamiento de perfiles gcda sin conexión

SINOPSIS

gcov-tool [-v|--version] [-h|--help]

gcov-tool merge [merge-options] directorio1 directorio2
[-o|--output directorio]
[-v|--verbose]
[-w|--weight p1,p2]

gcov-tool merge-stream [merge-stream-options] [archivo]
[-v|--verbose]
[-w|--weight p1,p2]

gcov-tool rewrite [rewrite-options] directorio
[-n|--normalize valor_long_long]
[-o|--output directorio]
[-s|--scale valor_float_o_fraccion_simple]
[-v|--verbose]

gcov-tool overlap [overlap-options] directorio1 directorio2
[-f|--function]
[-F|--fullname]
[-h|--hotonly]
[-o|--object]
[-t|--hot_threshold] float
[-v|--verbose]

DESCRIPCIÓN

gcov-tool es una herramienta sin conexión para procesar los archivos de perfil gcda de gcc.

La versión actual de gcov-tool soporta las siguientes funcionalidades:

  • combinar dos conjuntos de perfiles con pesos.
  • leer un flujo de perfiles con nombres de archivo asociados y combinarlo con un conjunto de perfiles con pesos.
  • leer un conjunto de perfiles y reescribir el contenido del perfil. Se puede escalar o normalizar los valores de los contadores.

Ejemplos de casos de uso para esta herramienta son:

  • Recolectar los perfiles para diferentes conjuntos de entradas, y usar esta herramienta para combinarlos. Se puede especificar el peso para tener en cuenta la importancia relativa de cada entrada.
  • Recolectar perfiles de sistemas de destino sin sistema de archivos (entornos autónomos). Combinar los perfiles recolectados con los perfiles asociados presentes en el sistema anfitrión. Se puede especificar el peso para tener en cuenta la importancia relativa de cada entrada.
  • Reescribir el perfil después de eliminar un subconjunto de los archivos gcda, manteniendo la consistencia del resumen y el histograma.
  • También se puede usar para depurar el código de libgcov, ya que la herramienta comparte la mayor parte del código con la biblioteca en tiempo de ejecución.

Tenga en cuenta que para la operación de combinación, este perfil generado sin conexión puede contener valores ligeramente diferentes al perfil combinado en línea. Aquí hay una lista de diferencias típicas:

  • diferencia de histograma: Esta herramienta sin conexión recalcula el histograma después de combinar los contadores. El histograma resultante, por lo tanto, es preciso. La combinación en línea no tiene esta capacidad; el histograma se combina a partir de dos histogramas y el resultado es una aproximación.
  • diferencia de suma de verificación de resumen: La suma de verificación de resumen utiliza una operación CRC32. El valor depende del orden de la lista de enlaces de los objetos gcov-info. Este orden es diferente en gcov-tool que en la combinación en línea. Se espera que haya diferentes sumas de verificación de resumen. En realidad, no importa ya que el compilador no utiliza esta suma de verificación en ningún lugar.
  • diferencia de valores de contadores de perfil de valor: Algunos valores de contador para el perfil de valor dependen del tiempo de ejecución, como las direcciones del heap. Es normal ver algunas diferencias en este tipo de contadores.

Muestra la ayuda sobre el uso de gcov-tool (en la salida estándar) y sale sin realizar ningún procesamiento adicional.
-v

-o directorio

-v
--verbose
Activa el modo detallado.
-w p1,p2
--weight p1,p2
Establece los pesos de combinación de directorio1 y directorio2, respectivamente. Los pesos predeterminados son 1 para ambos.
merge-stream
Recopila perfiles con nombres de archivo asociados de un flujo de datos gcfn y gcda. Lee el flujo del archivo especificado por archivo o de la entrada estándar (stdin). Combina los perfiles con los perfiles asociados en el sistema de archivos anfitrión. Aplica los pesos opcionales al combinar los perfiles.

Para la generación de un flujo de datos gcfn y gcda en el sistema de destino, por favor, consulte las funciones "__gcov_filename_to_gcfn()" y "__gcov_info_to_gcda()" declaradas en "#include <gcov.h>".

-v
--verbose
Activa el modo detallado.
-w p1,p2
--weight p1,p2
Establece los pesos de combinación de los perfiles del flujo de datos gcfn y gcda y los perfiles asociados en el sistema de archivos anfitrión, respectivamente. Los pesos predeterminados son 1 para ambos.
rewrite
Lee el directorio de perfiles especificado y lo reescribe en un nuevo directorio.
-n valor_long_long
--normalize <valor_long_long>
Normaliza el perfil. El valor especificado es el valor máximo del contador en el nuevo perfil.
-o directorio
--output directorio
Establece el directorio de perfiles de salida. El nombre de salida predeterminado es rewrite_profile.
-s valor_float_o_fraccion_simple

Escala los contadores del perfil. El valor especificado puede ser en formato de punto flotante o en forma de fracción simple, como 1, 2, 2/3 y 5/3.

overlap
Calcula la puntuación de solapamiento entre los dos directorios de perfiles especificados. La puntuación de solapamiento se calcula basándose en los perfiles de arco. NAME

gcov-tool — tool for consolidating gcov data.

SYNOPSIS

gcov-tool [-a | --all] [-b | --branch]
    [-c | --capture] [-e | --erase]
    [-f | --force] [-j | --jobs num]
    [-l | --latency] [-o | --object] [-t | --hot_threshold float]
    [-v | --verbose] [--] [object-file]...

DESCRIPTION

The gcov-tool program is used to consolidate gcov data. It allows to obtain summary information about the coverage of objects and functions that are hot. The information is extracted from object files that contain gcov data. The object files must have been compiled with gcc option -fprofile-arcs -ftest-coverage.

The program consolidates the gcov data, obtains statistics and prints the results on standard output.

OPTIONS

-a, --all
Print all object level overlap score.
-b, --branch
Print branch probabilities.
-c, --capture
Capture gcov data into object files.
-e, --erase
Erase gcov data from object files.
-f, --force
Force overwrite of existing gcov data.
-j, --jobs
Set the number of parallel jobs.
-l, --latency
Print latency info for hot objects/functions.
-o
--object
Print object level overlap score.
-t float
--hot_threshold <float>
Set the threshold for hot counter value.
-v
--verbose
Set the verbose mode.
