RI(1) 1 (guía de referencia del programador de Ruby) RI(1)

NOMBRE

ri — Interfaz frontal de referencia de la API de Ruby

SINOPSIS

ri [-ahilTv] [-d DIRNAME] [-f FORMAT] [-w WIDTH] [--[no-]pager] [--server[=PORT]] [--[no-]list-doc-dirs] [--no-standard-docs] [--[no-]{system|site|gems|home}] [--[no-]profile] [--dump=CACHE] [nombre ...]

DESCRIPCIÓN

ri es una interfaz frontal de línea de comandos para la referencia de la API de Ruby. Puedes buscar y leer la referencia de la API para clases y métodos con ri.

ri es parte de Ruby.

nombre puede ser:

Clase | Módulo | Módulo::Clase
Clase::método | Clase#método | Clase.método | método
nombre_gema: | nombre_gema:README | nombre_gema:History
ruby: | ruby:NEWS | ruby:globals

Todos los nombres de clase pueden abreviarse a su forma mínima no ambigua. Si un nombre es ambiguo, se listarán todas las opciones válidas.

Un ‘.’ coincide con métodos de clase o de instancia, mientras que #método solo coincide con métodos de instancia y ::método solo coincide con métodos de clase.

Los archivos README y otros pueden mostrarse prefijándolos con el nombre de la gema en la que están contenidos. Si el nombre de la gema va seguido de dos puntos (‘:’) se mostrarán todos los archivos de la gema. La extensión del nombre del archivo puede omitirse cuando no sea ambigua.

Por ejemplo:

ri Fil
ri File
ri File.new
ri zip
ri rdoc:README

Ten en cuenta que puede ser necesario usar comillas o escape del shell para nombres de métodos que contengan puntuación:

ri 'Array.[]'
ri compact\!

Para ver los directorios predeterminados en los que ri buscará, ejecuta:

ri --list-doc-dirs

Especificar las opciones --system, --site, --home, --gems, o --doc-dir limitará ri a buscar solo en los directorios especificados.

Las opciones de ri se pueden establecer en la variable de entorno RI.

El paginador de ri se puede establecer con la variable de entorno RI_PAGER o la variable de entorno PAGER.

OPCIONES

-i
 
--[no-]interactive
En modo interactivo puedes buscar métodos repetidamente con autocompletado.
-a
 
--[no-]all
Mostrar toda la documentación para una clase o módulo.
-l
 
--[no-]list
Listar las clases que ri conoce.
--[no-]pager
Enviar la salida a un paginador, en lugar de directamente a stdout.
-T
Sinónimo de --no-pager.
-w WIDTH
 
--width=WIDTH
Establecer el ancho de la salida.
--server[=PORT]
Ejecutar el servidor RDoc en el puerto dado. El puerto predeterminado es 8214.
-f FORMAT
 
--format=FORMAT
Usar el formateador seleccionado. El formateador predeterminado es bs para salida paginada y ansi en caso contrario. Los formateadores válidos son: ansi, bs, markdown, rdoc.
-h
 
--help
Mostrar ayuda y salir.
-v
 
--version
Mostrar información de la versión y salir.

Opciones de fuente de datos:

--[no-]list-doc-dirs
Listar los directorios de los que ri obtendrá documentación en stdout y salir.
-d DIRNAME
 
--doc-dir=DIRNAME
Lista de directorios de los que obtener documentación además de los directorios estándar. Puede repetirse.
--no-standard-docs
No incluir documentación de la biblioteca estándar de Ruby, site_lib, gemas instaladas o ~/.rdoc. Usar con --doc-dir.
--[no-]system
Incluir documentación de la biblioteca estándar de Ruby. Por defecto es true.
--[no-]site
Incluir documentación de bibliotecas instaladas en site_lib. Por defecto es true.
--[no-]gems
Incluir documentación de RubyGems. Por defecto es true.
--[no-]home
Incluir documentación almacenada en ~/.rdoc. Por defecto es true.

Opciones de depuración:

--[no-]profile
Ejecutar con el perfilador de Ruby.
--dump=CACHE
Volcar datos de una caché o archivo de datos ri.

AMBIENTE

RI
Opciones para anteponer a las especificadas en la línea de comandos.
RI_PAGER
 
PAGER
Programa paginador a usar para mostrar.
HOME
 
USERPROFILE
El directorio de inicio del usuario. En Windows, puede ser USERPROFILE o HOME.

EJEMPLOS

Para mostrar la documentación de la clase String:

ri String

Para mostrar la documentación del método de instancia chomp de la clase String:

ri String#chomp

Para mostrar la documentación del método de clase parse de la clase JSON:

ri JSON.parse

Para buscar métodos que contengan la palabra parse en el módulo JSON:

ri JSON.parse

Para listar todas las clases y módulos que comienzan con Str:

ri Str

Para buscar la documentación de la gema pg:

ri pg:

Para buscar el archivo README de la gema pg:

ri pg:README

Para buscar en modo interactivo:

ri -i
