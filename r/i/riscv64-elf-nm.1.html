NOMBRE

nm - lista símbolos de archivos objeto

SINOPSIS

nm [-A|-o|--print-file-name]
[-a|--debug-syms]
[-B|--format=bsd]
[-C|--demangle[=estilo]]
[-D|--dynamic]
[-fformato|--format=formato]
[-g|--extern-only]
[-h|--help]
[--ifunc-chars=CARACTERES]
[-j|--format=just-symbols]
[-l|--line-numbers] [--inlines]
[-n|-v|--numeric-sort]
[-P|--portability]
[-p|--no-sort]
[-r|--reverse-sort]
[-S|--print-size]
[-s|--print-armap]
[-t base|--radix=base]
[-u|--undefined-only]
[-U|--defined-only]
[-V|--version]
[-W|--no-weak]
[-X 32_64]
[--no-demangle]
[--no-recurse-limit|--recurse-limit]]
[--plugin nombre]
[--size-sort]
[--special-syms]
[--synthetic]
[--target=bfdname]
[--unicode=método]
[--with-symbol-versions]
[--without-symbol-versions]
[archivo_objeto...]

DESCRIPCIÓN

GNU nm lista los símbolos de los archivos objeto archivo_objeto.... Si no se listan archivos objeto como argumentos, nm asume el archivo a.out.

Para cada símbolo, nm muestra:

  • El valor del símbolo, en la base seleccionada por las opciones (ver abajo), o hexadecimal por defecto.
  • El tipo del símbolo. Se utilizan al menos los siguientes tipos; otros también, dependiendo del formato del archivo objeto. Si está en minúsculas, el símbolo suele ser local; si está en mayúsculas, el símbolo es global (externo). Sin embargo, hay algunos símbolos en minúsculas que se muestran para símbolos globales especiales ("u", "v" y "w").
"A"
El valor del símbolo es absoluto y no será modificado por enlaces posteriores.
"B"
"b"
El símbolo está en la sección de datos BSS. Esta sección normalmente contiene datos inicializados a cero o no inicializados, aunque el comportamiento exacto depende del sistema.
"C"
"c"
El símbolo es común. Los símbolos comunes son datos no inicializados. Al enlazar, múltiples símbolos comunes pueden aparecer con el mismo nombre. Si el símbolo está definido en algún lugar, los símbolos comunes se tratan como referencias indefinidas. El carácter c en minúscula se usa cuando el símbolo está en una sección especial para comunes pequeños.
"D"
"d"
El símbolo está en la sección de datos inicializados.
"G"
"g"
El símbolo está en una sección de datos inicializados para objetos pequeños. Algunos formatos de archivos objeto permiten un acceso más eficiente a objetos de datos pequeños, como una variable entera global en lugar de un gran array global.
"i"
Para archivos con formato PE, esto indica que el símbolo está en una sección específica para la implementación de DLLs.

Para archivos con formato ELF, esto indica que el símbolo es una función indirecta. Esta es una extensión de GNU al conjunto estándar de tipos de símbolos ELF. Indica un símbolo que, si es referenciado por una relocalización, no se evalúa a su dirección, sino que debe ser invocado en tiempo de ejecución. La ejecución en tiempo de ejecución devolverá el valor a usar en la relocalización.

Nota: los símbolos reales que se muestran para símbolos indirectos de GNU están controlados por la opción de línea de comandos --ifunc-chars. Si se ha proporcionado esta opción, el primer carácter de la cadena se usará para símbolos de funciones indirectas globales. Si la cadena contiene un segundo carácter, este se usará para símbolos de funciones indirectas locales.

"I"
El símbolo es una referencia indirecta a otro símbolo.
"N"
El símbolo es un símbolo de depuración.
"n"
El símbolo está en una sección de solo lectura que no es de datos, ni código, ni depuración.
"p"
El símbolo está en una sección de desenrollo de pila (stack unwind).
"R"
"r"
El símbolo está en una sección de datos de solo lectura.
"S"
"s"
El símbolo está en una sección de datos no inicializados o inicializados a cero para objetos pequeños.
"T"
"t"
El símbolo está en la sección de texto (código).
"U"
El símbolo es indefinido.
"u"
El símbolo es un símbolo global único. Esta es una extensión de GNU al conjunto estándar de enlaces de símbolos ELF. Para un símbolo de este tipo, el enlazador dinámico se asegurará de que en todo el proceso solo se utilice un símbolo con este nombre y tipo.
"V"
"v"
El símbolo es un objeto débil. Cuando un símbolo definido débil se enlaza con un símbolo definido normal, se usa el símbolo definido normal sin error. Cuando se enlaza un símbolo indefinido débil y el símbolo no está definido, el valor del símbolo débil se convierte en cero sin error. En algunos sistemas, las mayúsculas indican que se ha especificado un valor predeterminado.
"W"
"w"
El símbolo es un símbolo débil que no ha sido marcado específicamente como un símbolo de objeto débil. Cuando un símbolo definido débil se enlaza con un símbolo definido normal, se usa el símbolo definido normal sin error. Cuando se enlaza un símbolo indefinido débil y el símbolo no está definido, el valor del símbolo se determina de manera específica del sistema sin error. En algunos sistemas, las mayúsculas indican que se ha especificado un valor predeterminado.
"-"
El símbolo es un símbolo stabs en un archivo objeto a.out. En este caso, los siguientes valores impresos son el campo 'other' de stabs, el campo 'desc' de stabs y el tipo de stab. Los símbolos stabs se usan para contener información de depuración.
"?"
El tipo de símbolo es desconocido o específico del formato del archivo objeto.
•
El nombre del símbolo. Si un símbolo tiene información de versión asociada, se mostrará la información de versión. Si el símbolo versionado está indefinido o oculto para el enlazador, la cadena de versión se mostrará como un sufijo al nombre del símbolo, precedido por un carácter @. Por ejemplo, foo@VER_1. Si la versión es la versión predeterminada a usar al resolver referencias no versionadas al símbolo, se mostrará como un sufijo precedido por dos caracteres @. Por ejemplo, foo@@VER_2.

OPCIONES

Las formas largas y cortas de las opciones, que se muestran aquí como alternativas, son equivalentes.

-A
-o
--print-file-name
Precede cada símbolo con el nombre del archivo de entrada (o miembro del archivo) en el que se encontró, en lugar de identificar el archivo de entrada una sola vez, antes de todos sus símbolos.
-a
--debug-syms
Muestra todos los símbolos, incluso los símbolos exclusivos del depurador; normalmente estos no se listan.
-B
Lo mismo que --format=bsd (para compatibilidad con el nm de MIPS).
-C
--demangle[=estilo]
Decodifica (demangle) los nombres de símbolos de bajo nivel en nombres de nivel de usuario. Además de eliminar el guion bajo inicial que añade el sistema, esto hace que los nombres de funciones de C++ sean legibles. Diferentes compiladores tienen diferentes estilos de mangling. El argumento opcional de estilo de demangling se puede usar para elegir un estilo de demangling adecuado para su compilador.
--no-demangle
No decodifica los nombres de símbolos de bajo nivel. Este es el valor predeterminado.
--recurse-limit
Establece el límite de recursividad para la lista de símbolos. Esto es útil cuando se trabaja con archivos muy grandes con estructuras de símbolos anidadas profundamente.
--no-recurse-limit
Desactiva el límite de recursividad. Esto puede ser útil si el programa tiene estructuras de símbolos muy profundas que exceden el límite predeterminado, pero también puede llevar a un consumo excesivo de memoria o a bucles infinitos en casos extremos.
-D
--dynamic
Muestra solo los símbolos dinámicos (útil para archivos compartidos).
-f formato
--format=formato
Usa el formato de salida especificado. Los formatos soportados son: default, bsd, sysv, posix, just-symbols, coredump, pe.
-g
--extern-only
Imprime solo los símbolos externos (globales).
-h
--help
Muestra un mensaje de ayuda y sale.
--ifunc-chars=CARACTERES
Define los caracteres que se usarán para mostrar los símbolos de función indirecta (IFUNC). El primer carácter se usa para los símbolos globales y el segundo (si existe) para los símbolos locales.
-j
--format=just-symbols
Imprime solo los nombres de los símbolos, sin sus valores ni tipos.
-l
--line-numbers
Para cada símbolo, muestra el número de línea donde se define en el archivo fuente. Esto requiere que la información de depuración esté disponible en el archivo objeto.
--inlines
Muestra los símbolos de funciones insertadas (inlined) junto con los símbolos normales. Esto proporciona una vista más detallada de las funciones y su uso en el código.
-n
-v
--numeric-sort
Ordena los símbolos numéricamente por su valor, en lugar de alfabéticamente por su nombre.
-P
--portability
Usa el formato de salida POSIX para garantizar la portabilidad entre diferentes sistemas.
-p
--no-sort
No ordena los símbolos. Los símbolos se muestran en el orden en que aparecen en el archivo objeto.
-r
--reverse-sort
Invierte el orden de clasificación de los símbolos (por ejemplo, de Z a A si se ordena alfabéticamente).
-S
--print-size
Muestra el tamaño de cada símbolo (en bytes).
-s
--print-armap
Muestra el mapa del archivo de archivo (archive map), que contiene información sobre los miembros del archivo y sus símbolos.
-t base
--radix=base
Usa la base especificada para mostrar los valores de los símbolos. Las bases soportadas son d (decimal), o (octal), x (hexadecimal), h (hexadecimal).
-u
--undefined-only
Imprime solo los símbolos indefinidos.
-U
--defined-only
Imprime solo los símbolos definidos.
-V
--version
Muestra la información de la versión de nm y sale.
-W
--no-weak
No muestra los símbolos débiles.
-X 32_64
Especifica el formato de salida para archivos que contienen múltiples arquitecturas (por ejemplo, archivos universales de macOS). Solo el formato especificado se mostrará.
--plugin nombre
Carga un plugin para extender la funcionalidad de nm. El nombre especifica el plugin a cargar.
--size-sort
Ordena los símbolos por tamaño, de mayor a menor.
--special-syms
Muestra símbolos especiales que normalmente no se incluyen en la salida.
--synthetic
Muestra símbolos sintéticos, que son generados por el compilador o el enlazador y no corresponden directamente a código o datos definidos por el usuario.
--target=bfdname
Especifica el formato del archivo objeto a procesar. Esto es útil cuando se trabaja con archivos objeto que no pueden ser detectados automáticamente por BFD.
--unicode=método
Especifica el método para manejar nombres de símbolos Unicode. Los métodos soportados son locale, fail, map, unknown.
--with-symbol-versions
Muestra información de versiones de símbolos si está disponible.
--without-symbol-versions
No muestra información de versiones de símbolos.
="permalink" href="#recurse">--recurse-limit
--no-recurse-limit
--recursion-limit
--no-recursion-limit
Habilita o deshabilita un límite en la cantidad de recursión realizada al desmangling de cadenas. Dado que los formatos de mangling de nombres permiten un nivel infinito de recursión, es posible crear cadenas cuya decodificación agote el espacio de pila disponible en la máquina host, desencadenando un fallo de memoria. El límite intenta evitar que esto ocurra restringiendo la recursión a 2048 niveles de anidamiento.

Por defecto, este límite está habilitado, pero puede ser necesario deshabilitarlo para desmangling nombres verdaderamente complicados. Tenga en cuenta, sin embargo, que si el límite de recursión está deshabilitado, es posible el agotamiento de la pila y se rechazarán los informes de errores sobre dicho evento.

-D
--dynamic
Muestra los símbolos dinámicos en lugar de los símbolos normales. Esto solo es significativo para objetos dinámicos, como ciertos tipos de bibliotecas compartidas.
-f formato
--format=formato
Usa el formato de salida formato, que puede ser "bsd", "sysv", "posix" o "just-symbols". El valor predeterminado es "bsd". Solo el primer carácter del formato es significativo; puede ser mayúscula o minúscula.
-g
--extern-only
Muestra solo símbolos externos.
-h
--help
Muestra un resumen de las opciones de nm y sale.
--ifunc-chars=CHARS
Al mostrar símbolos de funciones indirectas de GNU, nm usará por defecto el carácter "i" tanto para funciones indirectas locales como para funciones indirectas globales. La opción --ifunc-chars permite al usuario especificar una cadena que contenga uno o dos caracteres. El primer carácter se utilizará para los símbolos de funciones indirectas globales y el segundo carácter, si está presente, se utilizará para los símbolos de funciones indirectas locales.
j
Lo mismo que --format=just-symbols.
-l
--line-numbers
Para cada símbolo, utiliza la información de depuración para intentar encontrar un nombre de archivo y un número de línea. Para un símbolo definido, busca el número de línea de la dirección del símbolo. Para un símbolo indefinido, busca el número de línea de una entrada de reubicación que hace referencia al símbolo. Si se puede encontrar información del número de línea, imprímela después de la otra información del símbolo.
--inlines
Cuando la opción -l está activa, si la dirección pertenece a una función que fue inlinada, esta opción hace que también se imprima la información de origen de todos los ámbitos contenedores hasta la primera función no inlinada. Por ejemplo, si "main" inlina "callee1" que inlina "callee2", y la dirección es de "callee2", también se imprimirá la información de origen de "callee1" y "main".
-n
-v
--numeric-sort
Ordena los símbolos numéricamente por sus direcciones, en lugar de alfabéticamente por sus nombres.
-p
--no-sort
No te molestes en ordenar los símbolos en ningún orden; imprímelos en el orden en que se encuentran.
-P
--portability
Utiliza el formato de salida estándar POSIX.2 en lugar del formato predeterminado. Equivalente a -f posix.
-r
--reverse-sort
Invierte el orden de ordenación (ya sea numérico o alfabético); deja que el último venga primero.
-S
--print-size
Imprime tanto el valor como el tamaño de los símbolos definidos para el estilo de salida "bsd". Esta opción no tiene efecto para formatos de objeto que no registran los tamaños de los símbolos, a menos que también se use --size-sort, en cuyo caso se muestra un tamaño calculado.
-s
--print-armap
Al listar símbolos de miembros de archivos, incluye el índice: un mapa (almacenado en el archivo por ar o ranlib) de qué módulos contienen definiciones para qué nombres.
-t base
--radix=base
Utiliza base como la base para imprimir los valores de los símbolos. Debe ser d para decimal, o para octal, o x para hexadecimal.
-u
--undefined-only
Muestra solo símbolos indefinidos (aquellos externos a cada archivo objeto). Por defecto, se muestran tanto los símbolos definidos como los indefinidos.
-U
--defined-only
Muestra solo símbolos definidos para cada archivo objeto. Por defecto, se muestran tanto los símbolos definidos como los indefinidos.
-V
--version
Muestra el número de versión de nm y sale.
-X
Esta opción se ignora por compatibilidad con la versión AIX de nm. Toma un parámetro que debe ser la cadena 32_64. El modo predeterminado de AIX nm corresponde a -X 32, que no es compatible con GNU nm.
--plugin nombre
Carga el plugin llamado nombre para agregar soporte para tipos de destino adicionales. Esta opción solo está disponible si la cadena de herramientas se ha compilado con soporte de plugins habilitado.

Si no se proporciona --plugin, pero el soporte de plugins se ha habilitado, entonces nm itera sobre los archivos en ${libdir}/bfd-plugins en orden alfabético y se utiliza el primer plugin que reclama el objeto en cuestión.

Tenga en cuenta que este directorio de búsqueda de plugins *no* es el que utiliza la opción -plugin de ld. Para que nm utilice el plugin del enlazador, debe copiarse en el directorio ${libdir}/bfd-plugins. Para compilaciones basadas en GCC, el plugin del enlazador se llama liblto_plugin.so.0.0.0. Para compilaciones basadas en Clang, se llama LLVMgold.so. El plugin de GCC siempre es compatible con versiones anteriores, por lo que es suficiente copiar el más nuevo.

--size-sort
Ordena los símbolos por tamaño. Para objetos ELF, los tamaños de los símbolos se leen de ELF; para otros tipos de objetos, los tamaños de los símbolos se calculan como la diferencia entre el valor del símbolo y el valor del símbolo con el siguiente valor superior. Si el formato de salida "bsd" se utiliza, se imprime el tamaño del símbolo, en lugar del valor, y se debe usar -S para imprimir tanto el tamaño como el valor.

Nota: esta opción no funciona si se ha habilitado --undefined-only, ya que los símbolos indefinidos no tienen tamaño.

--special-syms
Muestra símbolos que tienen un significado especial específico del destino. Estos símbolos suelen ser utilizados por el destino para algún procesamiento especial y normalmente no son útiles cuando se incluyen en las listas de símbolos normales. Por ejemplo, para destinos ARM, esta opción omitiría los símbolos de mapeo utilizados para marcar transiciones entre código ARM, código THUMB y datos.
--synthetic
Incluye símbolos sintéticos en la salida. Estos son símbolos especiales creados por el enlazador para diversos fines. No se muestran por defecto ya que no forman parte del código fuente original del binario.
--unicode=[default|invalid|locale|escape|hex|highlight]
Controla la visualización de caracteres multibyte codificados en UTF-8 en cadenas. El valor predeterminado (--unicode=default) es no darles ningún tratamiento especial. La opción --unicode=locale muestra la secuencia en la configuración regional actual, que puede o no admitirlos. Las opciones --unicode=hex y --unicode=invalid los muestran como secuencias de bytes hexadecimales encerradas entre corchetes angulares o llaves.

La opción --unicode=escape los muestra como secuencias de escape (\uxxxx) y la opción --unicode=highlight los muestra como secuencias de escape resaltadas en rojo (si el dispositivo de salida lo admite). El coloreado está destinado a llamar la atención sobre la presencia de secuencias unicode donde no se esperan.

-W
--no-weak
No mostrar símbolos débiles.
--with-symbol-versions
--without-symbol-versions
Habilita o deshabilita la visualización de información de versiones de símbolos. La cadena de versión se muestra como un sufijo al nombre del símbolo, precedido por un carácter @. Por ejemplo riscv64-elf-nm(1) — Arch Linux

NOMBRE

nm — listar símbolos de archivos objeto

SINOPSIS

nm [OPTION...] [OBJECT...]

DESCRIPCIÓN

El programa nm lista los símbolos de los archivos objeto especificados. Si no se proporcionan archivos objeto, o si se especifica un guion, nm lee de la entrada estándar.

La salida de nm está ordenada alfabéticamente por el nombre del símbolo. Para cada símbolo, se imprime una línea que contiene su valor (si lo tiene) y su tipo (si se conoce) y su nombre.

Hay varias opciones disponibles para controlar la salida de nm. Consulte la página del manual de nm para obtener una lista completa de opciones.

Las siguientes opciones son especialmente útiles:

--just-symbols Muestra solo los símbolos que se han definido.
--defined-only Muestra solo los símbolos definidos.
--undefined-only Muestra solo los símbolos no definidos.
--no-unqualified-id No muestres los identificadores sin calificar.
--print-file-name Precede cada línea de salida con el nombre del archivo del que proviene el símbolo.
--format=bfdname Usa el formato de salida especificado por bfdname. Los formatos disponibles incluyen ecoﬀ, berkeley, sysv y posix.
--portability Usa el formato de salida POSIX. Esto es equivalente a --format=posix.
--demangle[=style] Decodifica los nombres de los símbolos C++. Si no se especifica style, se utiliza el estilo predeterminado.
--no-demangle No decodifiques los nombres de los símbolos C++.
--dynamic Lista los símbolos de la sección dinámica.
--all-headers Lista todos los encabezados de los símbolos, incluso si no son necesarios para la resolución de símbolos sin versión.
--version-script=filename Lista los símbolos de la versión del script de versión especificado en filename.
--hash-style=style Usa el estilo hash especificado por style. Los estilos disponibles son sysv, gnu, both y none.
--print-size Incluye el tamaño de cada símbolo.
--radix=radix Usa la base especificada por radix para imprimir los valores de los símbolos. Los valores disponibles son d (decimal), o (octal), x (hexadecimal) y a (octal por defecto).
--format=value Establece el formato de salida. Consulte la opción -o para más detalles.
--version Muestra la información de la versión de nm y sal.
--reverse-sort Invierte el orden de clasificación de los símbolos.
--no-sort No ordena la salida.
--with-symbol-versions Muestra información de versión de símbolos.
foo@VER_1 Si la versión es la versión predeterminada que se utilizará al resolver referencias sin versión al símbolo, se muestra como un sufijo precedido por dos caracteres @. Por ejemplo, foo@@VER_2. Por defecto, la información de versión del símbolo se muestra.
--target=bfdname Especifica un formato de código objeto distinto del formato predeterminado de su sistema.
@file Lee las opciones de línea de comandos de file. Las opciones leídas se insertan en lugar de la opción original @file. Si file no existe o no se puede leer, la opción se tratará literalmente y no se eliminará.

Las opciones en file están separadas por espacios en blanco. Se puede incluir un carácter de espacio en blanco en una opción rodeando la opción completa con comillas simples o dobles. Se puede incluir cualquier carácter (incluido una barra invertida) prefijando el carácter a incluir con una barra invertida. El file puede contener él mismo opciones adicionales @file; todas esas opciones se procesarán recursivamente.
