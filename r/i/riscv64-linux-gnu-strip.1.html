STRIP(1) Herramientas de desarrollo de GNU STRIP(1)

NOMBRE

strip - descarta símbolos y otros datos de archivos objeto

SINOPSIS

strip [-F nombrebfd |--target=nombrebfd]
[-I nombrebfd |--input-target=nombrebfd]
[-O nombrebfd |--output-target=nombrebfd]
[-s|--strip-all]
[-S|-g|-d|--strip-debug]
[--strip-dwo]
[-K nombredelsimbolo|--keep-symbol=nombredelsimbolo]
[-M|--merge-notes][--no-merge-notes]
[-N nombredelsimbolo |--strip-symbol=nombredelsimbolo]
[-w|--wildcard]
[-x|--discard-all] [-X |--discard-locals]
[-R nombreseccion |--remove-section=nombreseccion]
[--keep-section=patronseccion]
[--remove-relocations=patronseccion]
[--strip-section-headers]
[-o archivo] [-p|--preserve-dates]
[-D|--enable-deterministic-archives]
[-U|--disable-deterministic-archives]
[--keep-section-symbols]
[--keep-file-symbols]
[--only-keep-debug]
[-v |--verbose] [-V|--version]
[--help] [--info]
archivoobjeto...

DESCRIPCIÓN

GNU strip descarta todos los símbolos de los archivos objeto archivoobjeto. La lista de archivos objeto puede incluir archivos. Se debe proporcionar al menos un archivo objeto.

strip modifica los archivos nombrados en sus argumentos, en lugar de escribir copias modificadas con nombres diferentes.

OPCIONES

-F nombrebfd
--target=nombrebfd
Trata el archivoobjeto original como un archivo con el formato de código objeto nombrebfd, y lo reescribe en el mismo formato.
--help
Muestra un resumen de las opciones de strip y sale.
--info
Muestra una lista que indica todas las arquitecturas y formatos de objeto disponibles.
-I nombrebfd
--input-target=nombrebfd
Trata el archivoobjeto original como un archivo con el formato de código objeto nombrebfd.
-O nombrebfd
--output-target=nombrebfd
Reemplaza archivoobjeto con un archivo en el formato de salida nombrebfd.
-R nombreseccion
--remove-section=nombreseccion
Elimina cualquier sección llamada nombreseccion del archivo de salida, además de las secciones que de otro modo serían eliminadas. Esta opción se puede dar varias veces. Tenga en cuenta que el uso inapropiado de esta opción puede hacer que el archivo de salida sea inutilizable. El carácter comodín * se puede dar al final de nombreseccion. Si es así, se eliminarán todas las secciones que comiencen con nombreseccion.

Si el primer carácter de patronseccion es el signo de exclamación (!) entonces las secciones coincidentes no se eliminarán, incluso si un uso anterior de --remove-section en la misma línea de comando lo hiciera de otro modo. Por ejemplo:

--remove-section=.text.* --remove-section=!.text.foo

eliminará todas las secciones que coincidan con el patrón '.text.*', pero no eliminará la sección '.text.foo'.

--keep-section=patronseccion
Al eliminar secciones del archivo de salida, conserva las secciones que coinciden con patronseccion.
--remove-relocations=patronseccion
Elimina las reubicaciones del archivo de salida para cualquier sección que coincida con patronseccion. Esta opción se puede dar varias veces. Tenga en cuenta que el uso inapropiado de esta opción puede hacer que el archivo de salida sea inutilizable. Se aceptan caracteres comodín en patronseccion. Por ejemplo: 
--remove-relocations=.text.*

eliminará las reubicaciones de todas las secciones que coincidan con el patrón '.text.*'.

Si el primer carácter de patronseccion es el signo de exclamación (!) entonces a las secciones coincidentes no se les eliminarán sus reubicaciones, incluso si un uso anterior de --remove-relocations en la misma línea de comandos provocara anteriormente la eliminación de las reubicaciones. Por ejemplo:

--remove-relocations=.text.* --remove-relocations=!.text.foo

eliminará todas las reubicaciones para secciones que coincidan con el patrón '.text.*', pero no eliminará las reubicaciones para la sección '.text.foo'.

--strip-section-headers
Elimina las cabeceras de sección. Esta opción es específica de los archivos ELF. Implica --strip-all y --merge-notes.
-s
--strip-all
Elimina todos los símbolos.
-g
-S
-d
--strip-debug
Elimina solo los símbolos de depuración.
--strip-dwo
Elimina el contenido de todas las secciones DWARF .dwo, dejando intactas las secciones de depuración restantes y todos los símbolos. Consulte la descripción de esta opción en la sección objcopy para obtener más información.
--strip-unneeded
Elimina todos los símbolos que no son necesarios para el procesamiento de reubicación, además de los símbolos y secciones de depuración eliminados por --strip-debug.
-K nombredelsimbolo
--keep-symbol=nombredelsimbolo
Al eliminar símbolos, conserva el símbolo nombredelsimbolo aunque normalmente se eliminaría. Esta opción se puede dar varias veces.
-M
--merge-notes
--no-merge-notes
Para archivos ELF, intenta (o no intenta) reducir el tamaño de las secciones de tipo SHT_NOTE eliminando notas duplicadas. El valor predeterminado es intentar esta reducción a menos que se esté eliminando información de depuración o DWO.
-N nombredelsimbolo
--strip-symbol=nombredelsimbolo
Elimina el símbolo nombredelsimbolo del archivo de origen. Esta opción se puede dar varias veces y se puede combinar con otras opciones de strip que no sean -K.
-o archivo
Coloca la salida eliminada en archivo, en lugar de reemplazar el archivo existente. Cuando se usa este argumento, solo se puede especificar un argumento archivoobjeto.
-p
--preserve-dates
Conserva las fechas de acceso y modificación del archivo.
-D
--enable-deterministic-archives
Opera en modo determinista. Al copiar miembros de archivo y escribir el índice del archivo, usa cero para UID, GID, marcas de tiempo y usa modos de archivo consistentes para todos los archivos.

Si binutils se configuró con --enable-deterministic-archives, entonces este modo está activado por predeterminado. Se puede desactivar con la opción -U, a continuación.

-U
--disable-deterministic-archives
No opera en modo determinista.

Si se utiliza este argumento, el modo determinista se desactiva incluso si se configuró al compilar binutils.

--keep-section-symbols
No elimine los símbolos que son necesarios para el indexado de secciones de un archivo de biblioteca (o archivo).
--keep-file-symbols
No elimine los símbolos que son necesarios para el indexado de archivos de un archivo de biblioteca (o archivo).
--only-keep-debug
Conserva solo los símbolos de depuración. Elimina todos los demás símbolos y secciones de depuración de DWO.
-V
--version
Muestra información sobre la versión de strip y sale.
-v
--verbose
Muestra una lista de los archivos procesados.
-w
--wildcard
Permite que los caracteres comodín se utilicen en los nombres de símbolos que se pasan a las opciones -N y -K.
-x
--discard-all
Elimina todos los símbolos no utilizados en la reubicación.
-X
--discard-locals
Elimina todos los símbolos locales que no se utilizan en la reubicación.

DESCRIpción

-d
--strip-debug
Elimina la información de depuración de los archivos.
-g
--strip-unneeded
Elimina todos los símbolos que no son necesarios para la ejecución.
-K
--keep-symbol
No elimine el símbolo especificado. Esta opción puede especificarse varias veces.
-s
--strip-all
Elimina todos los símbolos del archivo.
-S
--strip-symbols
Elimina todos los símbolos del archivo, excepto aquellos especificados con la opción -K, --keep-symbol.
-t
--strip-time
Este es el inverso de la opción -D anterior: al copiar los miembros del archivo y escribir el índice del archivo, utilice sus valores reales de UID, GID, marca de tiempo y modo de archivo.
Esto es lo predeterminado a menos que
binutils se haya configurado con --enable-deterministic-archives.
-w
--wildcard
Permite expresiones regulares en los symbolnames utilizados en otras opciones de línea de comandos. Los operadores de signo de interrogación (?), asterisco (*), barra invertida (\) y corchetes ([]) se pueden usar en cualquier lugar del nombre del símbolo. Si el primer carácter del nombre del símbolo es el signo de exclamación (!), el sentido del interruptor se invierte para ese símbolo. Por ejemplo: 
-w -K !foo -K fo*

haría que strip solo conservara los símbolos que comienzan con las letras "fo", pero descartaría el símbolo "foo".

-x
--discard-all
Elimina los símbolos no globales.
-X
--discard-locals
Elimina los símbolos locales generados por el compilador. (Estos generalmente comienzan con L o ..)
--keep-section-symbols
Al eliminar un archivo, quizás con --strip-debug o --strip-unneeded, conserve cualquier símbolo que especifique nombres de sección, que de otro modo se eliminarían.
--keep-file-symbols
Al eliminar un archivo, quizás con --strip-debug o --strip-unneeded, conserve cualquier símbolo que especifique nombres de archivos fuente, que de otro modo se eliminarían.
--only-keep-debug
Elimina un archivo, vaciando el contenido de cualquier sección que no sería eliminada por --strip-debug y dejando intactas las secciones de depuración. En los archivos ELF, esto también preserva todas las secciones de notas en la salida.

Nota: las cabeceras de sección de las secciones eliminadas se preservan, incluidos sus tamaños, pero el contenido de la sección se descarta. Las cabeceras de sección se conservan para que otras herramientas puedan correlacionar el archivo de información de depuración con el ejecutable real, incluso si ese ejecutable se ha reubicado en un espacio de direcciones diferente.

La intención es que esta opción se utilice junto con --add-gnu-debuglink para crear un ejecutable de dos partes. Una es un binario eliminado que ocupará menos espacio en RAM y en una distribución, y la segunda es un archivo de información de depuración que solo se necesita si se requieren capacidades de depuración. El procedimiento sugerido para crear estos archivos es el siguiente:

1.<Enlace el ejecutable como de costumbre. Asumiendo que se llama>
"foo" entonces...
1.<Ejecute "objcopy --only-keep-debug foo foo.dbg" para>
crear un archivo que contenga la información de depuración.
1.<Ejecute "objcopy --strip-debug foo" para crear un>
ejecutable eliminado.
1.<Ejecute "objcopy --add-gnu-debuglink=foo.dbg foo">
para agregar un enlace a la información de depuración en el ejecutable eliminado.

Nota: la elección de ".dbg" como extensión para el archivo de información de depuración es arbitraria. Además, el paso "--only-keep-debug" es opcional. También puede hacer esto:

1.<Enlace el ejecutable como de costumbre.>
1.<Copie "foo" a "foo.full">
1.<Ejecute "strip --strip-debug foo">
1.<Ejecute "objcopy --add-gnu-debuglink=foo.full foo">

es decir, el archivo al que apunta --add-gnu-debuglink puede ser el ejecutable completo. No tiene por qué ser un archivo creado con el modificador --only-keep-debug.

Nota: este modificador solo está diseñado para usarse en archivos completamente enlazados. No tiene sentido usarlo en archivos objeto donde la información de depuración puede estar incompleta. Además, la función gnu_debuglink actualmente solo admite la presencia de un nombre de archivo que contenga información de depuración, no varios nombres de archivo en una base de un archivo por objeto.

-V
--version
Muestra el número de versión de strip.
-v
--verbose
Salida detallada: enumera todos los archivos objeto modificados. En el caso de archivos, strip -v enumera todos los miembros del archivo.
@file
Lee las opciones de línea de comandos de file. Las opciones leídas se insertan en lugar de la opción original @file. Si file no existe o no se puede leer, la opción se tratará literalmente y no se eliminará.

Las opciones en file están separadas por espacios en blanco. Se puede incluir un carácter de espacio en blanco en una opción rodeando la opción completa con comillas simples o dobles. Se puede incluir cualquier carácter (incluida una barra invertida) prefijando el carácter a incluir con una barra invertida. El file puede contener él mismo opciones adicionales @file; todas esas opciones se procesarán recursivamente.
