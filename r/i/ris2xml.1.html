bibutils - utilidades de conversión de bibliografía

SINOPSIS

formato2xml [OPCIONES] [archivo.formato]

xml2formato [OPCIONES] [archivo.xml]

DESCRIPCIÓN

El conjunto de programas bibutils realiza conversiones entre varios formatos de bibliografía utilizando el Metadata Object Description Schema (MODS)[2] versión 3.1 de la Library of Congress[1]. Por ejemplo, se pueden convertir archivos en formato RIS a Bibtex realizando dos transformaciones: RIS->MODS->Bibtex.

Opciones Comunes para la Conversión a MODS

Varias banderas disponibles para los programas end2xml, endx2xml, bib2xml, ris2xml, med2xml, y copac2xml. La mayoría de las opciones tienen tanto una versión corta como una larga.

-h --help muestra la ayuda
-v --version muestra la versión
-a --add-refcount agrega "_#", donde # es el número de referencias al id de referencia
-s --single-refperfile coloca una referencia por archivo con el número de referencia
-i --input-encoding interpreta el archivo de entrada como si usara el conjunto de caracteres solicitado (usar sin argumento para la lista actual derivada de los conjuntos de caracteres en www.kostis.net[4]) unicode es ahora una opción de conjunto de caracteres
-u --unicode-characters codifica caracteres unicode directamente en el archivo en lugar de como entidades XML
-un --unicode-no-bom igual que -u, pero no incluye una marca de orden de bytes
-x --xml-entities codifica caracteres unicode como entidades XML (lo opuesto a -u)
-nl --no-latex no convierte combinaciones de caracteres estilo latex
-s --single-refperfile una referencia por archivo de salida
-d --drop-key no coloca la clave de citación en el campo id de mods
-c --corporation-file con un argumento que especifica un archivo que contiene una lista de nombres de corporaciones para ser colocados en <name type="corporate"></name> en lugar de type="personal" y elimina la manipulación de nombres
-a --asis con un argumento que especifica un archivo que contiene una lista de nombres para ser tratados literalmente
-nt --nosplit-title no divide los títulos en pares TÍTULO/SUBTÍTULO
--verbose salida detallada
--debug salida muy detallada (principalmente para depuración)

bib2xml

bib2xml convierte un archivo de referencias en formato bibtex a un archivo bibliográfico intermedio XML. Especifique los archivos a convertir en la línea de comandos. Los archivos que contienen cadenas de sustitución de bibtex deben especificarse antes que los archivos donde se especifican las sustituciones (o en el mismo archivo antes de su uso). Si no se especifican archivos, la información de bibtex se leerá de la entrada estándar.

bib2xml archivo.bib > archivo_salida.xml

biblatex2xml

biblatex2xml convierte un archivo de referencias en formato biblatex (no confundir con bibtex) a un archivo bibliográfico intermedio XML MODS.

biblatex2xml archivo.bib > archivo_salida.xml

copac2xml

copac2xml convierte un archivo de referencias en formato COPAC a un archivo bibliográfico intermedio XML MODS.

end2xml

end2xml convierte un archivo de referencias en formato texto de endnote a un archivo bibliográfico intermedio XML. Este programa no funcionará en la biblioteca binaria; el archivo debe exportarse primero. Los formatos etiquetados de Endnote (exportación en formato "Refer") se parecen al Ejemplo 1, "Archivo de formato refer de ejemplo". Hay instrucciones muy buenas para asegurarse de que está exportando esto correctamente en http://www.sonnysoftware.com/endnoteimport.html[5]

El uso de end2xml es el mismo que el de bib2xml.

end2xml archivo.end > archivo_salida.xml

ebi2xml

ebi2xml convierte un archivo EBI XML a un archivo bibliográfico intermedio XML MODS.

endx2xml

endx2xml convierte un archivo de referencias exportado de EndNote-XML a un archivo bibliográfico intermedio XML MODS. Este programa no funcionará en la biblioteca binaria; el archivo debe exportarse primero.

isi2xml

isi2xml convierte un archivo de referencias en formato ISI-web-of-science a un archivo bibliográfico intermedio XML.

El uso de isi2xml es el mismo que el de bib2xml.

isi2xml archivo_entrada.isi > archivo_salida.xml

ris2xml

ris2xml convierte un archivo de referencias en formato RIS a un archivo bibliográfico intermedio XML. El uso de ris2xml es igual que el de end2xml y bib2xml.

ris2xml archivo.ris > archivo_salida.xml

wordbib2xml

wordbib2xml convierte un archivo de referencias en formato Word2007 a un archivo bibliográfico intermedio XML.

MODSCLEAN

modsclean es un programa que puede ser usado para actualizar archivos MODS existentes a un nuevo estándar MODS (es decir, para actualizar versiones de esquemas MODS). También se puede usar para eliminar elementos obsoletos de un archivo MODS. Consulte la página de manual de modsclean(1) para obtener más detalles.

ARCHIVOS

El programa utiliza ficheros XML que describen los metadatos bibliográficos en el formato MODS.

Opciones Comunes para Convertir desde MODS

Tenga en cuenta que --output-encoding se refiere al archivo de entrada

-h --help muestra la ayuda
-v --version muestra la versión
-o --output-encoding interpreta el archivo de entrada usando el conjunto de caracteres solicitado (usar sin argumento para la lista actual derivada de los conjuntos de caracteres en www.kostis.net[4]) unicode es ahora una opción de conjunto de caracteres
-s --single-refperfile coloca una referencia por nombre de archivo según el número de referencia
-nb --no-bom no escribe Marca de Orden de Byte si escribe UTF8

xml2bib

xml2bib convierte la bibliografía XML de MODS a un archivo de referencia con formato bibtex. El uso de xml2bib es como para otras herramientas

xml2bib xml_file.xml > output_file.bib

Dado que el formato de referencia BibTeX es bastante flexible y parece tener el mayor número de preferencias personales, también ha acumulado una serie de opciones específicas que no están disponibles para otros formatos.

A partir de la versión 3.24, la salida de xml2bib utiliza etiquetas en minúsculas y tipos de referencia de mayúsculas y minúsculas mixtas para una mejor interacción con otro software. El comportamiento anterior con etiquetas/tipos de referencia completamente en mayúsculas todavía se puede generar usando el interruptor de línea de comandos -U/--uppercase.

Opciones específicas de xml2bib:

-fc --finalcomma agrega una coma final en la salida bibtex para quienes la deseen
-sd --singledash usa un guion en lugar de dos (guion más largo en latex) entre números en la salida de páginas
-b --brackets usa corchetes en lugar de comillas alrededor de los datos del campo
-w --whitespace agrega espacios en blanco embellecedores a la salida
-U --uppercase usa mayúsculas para las etiquetas (nombres de campos) y tipos de referencia (comportamiento pre-3.24)
-sk --strictkey usa solo caracteres alfanuméricos para las claves de citación bibtex

xml2ads

xml2ads convierte la bibliografía XML de MODS al formato de referencia Astrophyics Data System (ADS) de Smithsonian Astrophysical Observatory (SAO)/National Aeronautics and Space Administration (NASA) [6] (que es muy similar al estilo Endnote etiquetado). El uso de xml2ads es como para otras herramientas

xml2ads xml_file.xml > output_file.ads

xml2ris

xml2ris convierte la bibliografía XML de MODS a un archivo de bibliografía con formato RIS. El uso de xml2ris es como para otras herramientas

xml2ris xml_file.xml > output_file.ris

xml2end

xml2end convierte la bibliografía XML de MODS a un archivo de bibliografía con formato Endnote etiquetado (refer-format). El uso de xml2end es como para otras herramientas

xml2end xml_file.xml > output_file.end

xml2wordbib

xml2wordbib convierte la bibliografía XML de MODS a un archivo de bibliografía XML con formato Word 2007. El uso de xml2wordbib es como para otras herramientas

xml2wordbib xml_file.xml > output_file.word.xml

xml2wordbib se llamaba xml2word en versiones de bibutils anteriores a la 3.40. Se le cambió el nombre para evitar confusiones con otras herramientas. Esperemos que esto no rompa demasiados scripts ya en uso.

ris2xml(1)

NAME

ris2xml - Convert RIS bibliographic data to XML

SYNOPSIS

ris2xml [OPTION]...

DESCRIPTION

Convert RIS bibliographic data to XML.

CONVERTING TO MODS

To convert RIS to MODS, you can use the following command:

ris2xml -f mods input.ris -o output.xml

CONVERTING FROM MODS

To convert MODS to RIS, you can use the following command:

ris2xml -f ris input.xml -o output.ris

EXAMPLES

Convert a RIS file to MODS XML:

ris2xml -f mods bibliography.ris -o bibliography.xml

Convert a MODS XML file to RIS:

ris2xml -f ris bibliography.xml -o bibliography.ris
