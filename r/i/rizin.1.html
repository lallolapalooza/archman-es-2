RIZIN(1) Manual de comandos generales RIZIN(1)

NOMBRE

rizin — Editor hexadecimal, desensamblador y depurador avanzado de línea de comandos

SINOPSIS

rizin [-ACdfLMnNqStuvwzX] [-P parche] [-p prj] [-a arch] [-b bits] [-i archivo] [-s dir] [-B bdir] [-m mdir] [-c cmd] [-e k=v] archivo|pid|-|--|=

DESCRIPCIÓN

Rizin es un framework de ingeniería inversa de línea de comandos diseñado para analizar y desensamblar archivos binarios. Proporciona diversas herramientas y características para analizar y comprender la estructura, el comportamiento y la lógica de los archivos ejecutables.

Las opciones son:

--
Ejecutar rizin sin abrir ningún archivo
=
Equivalente a 'rizin malloc://512'
-
Leer archivo desde stdin
-=
Ejecutar el comando R=! para ejecutar todos los comandos de forma remota
-0
Imprimir \x00 después de la inicialización y después de cada comando ejecutado
-1
Redirigir stderr a stdout
-2
Cerrar el descriptor de archivo stderr (mensajes de advertencia silenciosos)
-a [arch]
Establecer la arquitectura de ensamblaje. (x86, ppc, arm, mips, bf, java, ...)
-A
Ejecutar el comando 'aaa' antes del prompt o parche para analizar todo el código referenciado
-b [bits]
Establecer el número de bits del ensamblador. (16, 32, 64)
-B [bdir]
Establecer la dirección base para ejecutables independientes de la posición (PIE)
-c 'cmd..'
Ejecutar el comando Rizin especificado
-C
Especificar un archivo en el formato "host:puerto" para ejecutar Rizin de forma remota a través de HTTP
-d
Depurar el ejecutable 'archivo' o el proceso en ejecución 'pid'
-D [backend]
Habilitar el modo de depuración, estableciendo la variable de configuración 'cfg.debug=true'
-e k=v
Evaluar la variable de configuración especificada
-f
Establecer el tamaño del bloque igual al tamaño del archivo
-F [binplugin]
Forzar el uso de un plugin rbin específico
-h, -hh
Mostrar mensajes de ayuda, con -hh mostrando ayuda detallada
-H
Imprimir información sobre las rutas de instalación y la configuración de Rizin. Esta opción es útil para obtener detalles sobre la ubicación de instalación, directorios y varios componentes de Rizin
-i [archivo]
Ejecutar los comandos del archivo de script
-I [archivo]
Ejecutar archivo de script. Antes de que se cargue el archivo
-k [OS/kern]
Establecer el sistema operativo de ensamblaje
-l [lib]
Cargar el archivo de plugin especificado
-L
Listar plugins de IO compatibles
-m [dir]
Mapear archivo en la dirección dada
-M
Deshabilitar demangling
-n, -nn
Controlar la carga de información de RzBin, con -nn solo cargando estructuras binarias
-N
Deshabilitar configuraciones de usuario/proyectos de ~/.rizinrc, ~/.config/rizin/rizinrc y los scripts dentro del directorio .../rizinrc.d/
-NN
Deshabilitar la carga de cualquier script o plugin
-q
Modo silencioso, suprime el prompt y sale después de la ejecución del script
-qq
Salir antes de mostrar el prompt. Justo después de que se evalúen todos los argumentos -e -c y -i
-Q
Igual que q, pero saliendo sin liberar RzCore, esto produce fugas de memoria al salir, pero ahorra unos preciosos ms para ejecutar la suite de pruebas en modo rápido
-p [prj]
Establecer archivo de proyecto
-r [rz-run]
Especificar el perfil de rz-run de dbg.profile a usar al lanzar un programa para depuración
-R [rule]
Especificar directivas rz-run personalizadas sin tener que crear un perfil rz-run
-s [dir]
Comenzar a buscar en esta dirección
-T
Evitar calcular los hashes del archivo
-u
Establecer bin.filter=false para cargar información de rbin sin filtrar nombres
-v
Mostrar información de versión y salir (Usar -qv para obtener solo el número de versión)
-V
Mostrar versiones de las bibliotecas de rizin
-w
Abrir en modo de escritura
-x
Abrir el archivo sin el indicador de ejecución
-X
Igual que -e bin.usextr=false, no usar plugins de extracción, útil para dyldcache
-z, -zz
no cargar cadenas o cargarlas incluso en modo bruto

AMBIENTE

ANSICON: tamaño W y H del búfer de ansicon y w y h de la ventana en el formato: "WxH (wxh)"

DEBUGINFOD_URLS: e bin.dbginfo.debuginfod_urls - usar servidor debuginfod alternativo

COLUMNS: columnas del terminal a usar

RZ_ABORTLEVEL: nivel/severidad de registro de destino para abortar (0:DEBUG, 1:VERBOSE, 2:INFO, 3:WARN, 4:ERROR, 5:FATAL)

RZ_CURL: si usar curl (para soporte SSL)

RZ_DEBUG_ASSERT: establecer un punto de interrupción al golpear una aserción

RZ_DEBUG_TOOL herramienta de depuración a usar al mostrar mensajes de error y señal de bloqueo

RZ_DYLDCACHE_FILTER: filtro de caché dyld (ubicaciones de bibliotecas dinámicas de MacOS en tiempo de ejecución)

RZ_HTTP_AUTHFILE: archivo de usuario de autenticación HTTP

RZ_LOGCOLORS: ¿debe la salida de registro usar colores (TODO)?

RZ_LOGFILE: nombre de archivo/ruta de la salida de registro

RZ_LOGLEVEL: nivel/severidad de registro de destino (0:DEBUG, 1:VERBOSE, 2:INFO, 3:WARN, 4:ERROR, 5:FATAL)

RZ_LOGSHOWSOURCES: ¿debe la salida de registro contener información de origen (nombre de archivo:número de línea)?

NOMBRE

rizin – Rizin command-line interface

SINOPSIS

rizin [-hvdtfwsrS] [-c cmd] [-C file] [-n numb] [-N Numb] [-p plug] [-P patch] [-e k=v] [-o k=v] [-a arch] [-b bits] [-m mode] [-q qemu_bin] [-F fmt] [-f file] [-t file] [-l file] [-d file] [--] [file...]

DESCRIPCIÓN

Rizin is a free and open-source reverse engineering framework.

This command allows you to load binaries and interact with them using Rizin commands.

OPCIONES

The following options are available:

  • -A Perform analysis.
  • -a Specify the architecture.
  • -b Specify the number of bits.
  • -c Execute a Rizin command.
  • -C Load a C header file.
  • -d Start Rizin in debugger mode.
  • -D Debugger mode using QEMU.
  • -e Set environment variable.
  • -f Load a file.
  • -F Specify the file format.
  • -h Show help message.
  • -H Display Rizin commands.
  • -i Show info of Rizin.
  • -I Import symbols from a file.
  • -l Open the file in read-only mode.
  • -m Set the memory mapping mode.
  • -N Set the default number of bits.
  • -n Set the default number of bytes.
  • -o Set Rizin configuration.
  • -O Specify the output directory.
  • -p Load a plugin.
  • -P Apply a patch.
  • -q Specify QEMU binary.
  • -r Run script.
  • -R Reanalyze the file.
  • -s Load symbols from file.
  • -S Search for symbols.
  • -t Load a template file.
  • -v Show version information.
  • -w Open the file in write mode.
  • -- Separator for options and arguments.

ENTORNO

The following environment variables are used by Rizin:

RZ_API_PATH: Path for Rizin API libraries.

RZ_CONFIG_BP: Breakpoint configuration file.

RZ_CONFIG_DIR: Path for Rizin configuration files.

RZ_GDB_COLOR: Enable GDB color output.

RZ_HOME: User home directory.

RZ_INPUT_FILE: Input file for rzpipe.

RZ_LOCAL_PLUGINS: Path for local plugins.

RZ_MUSIC_DIR: Path for music files.

RZ_OUTPUT_FILE: Output file for rzpipe.

RZ_PLUGINS_DIR: Path for Rizin plugins.

RZ_PREFIX: Default prefix Rizin was compiled for.

RZ_RCFILE: User config file.

RZ_PIPE_CMD: rzpipe command input (file descriptor).

RZ_PIPE_IN: rzpipe command input (file descriptor).

RZ_PIPE_OUT: rzpipe command output (file descriptor).

RZ_PREFIX: Default prefix Rizin was compiled for.

RZ_RCFILE: User config file.

SFLIBPATH: SFLib syscall library path.

EJEMPLO

Start Rizin in analysis mode (-A) on the /bin/ls executable:

rizin -A /bin/ls

Open the file /bin/ls in write mode, allowing you to make changes to the binary:

rizin -w /bin/ls

Start Rizin's debugger (-d) on /bin/ls and passes arguments "-l" and "/tmp" to the program for debugging:

rizin -d /bin/ls -l /tmp
