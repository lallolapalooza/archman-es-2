RIVER(1) Manual de comandos generales RIVER(1)

NOMBRE

river - compositor dinámico de mosaicos para Wayland

SINOPSIS

river [opciones]

DESCRIPCIÓN

river es un compositor dinámico de mosaicos para Wayland. La gestión de ventanas se basa en una pila de vistas dispuestas dinámicamente por un generador de diseño externo. Las etiquetas se utilizan en lugar de los espacios de trabajo, lo que permite una mayor flexibilidad.

Toda la configuración y el control se realizan en tiempo de ejecución a través de protocolos de Wayland, incluidas varias extensiones de protocolo específicas de river. La utilidad riverctl(1) puede utilizarse para comunicarse con river a través de estos protocolos.

OPCIONES

-h

Muestra un mensaje de ayuda y sale.

-version

Muestra el número de versión y sale.

-c comando_shell

Anula las rutas de búsqueda predeterminadas para un ejecutable de inicio: en su lugar, se ejecutará comando_shell con /bin/sh -c. Consulte la sección CONFIGURACIÓN para obtener más detalles.

-log-level [error|warning|info|debug]

Establece el nivel de registro de river. En el nivel de registro error, solo se registran los errores. En el nivel de registro debug, se registra todo, incluidos los mensajes de depuración detallados.

-no-xwayland

Deshabilita xwayland en tiempo de ejecución, incluso si river se ha compilado con soporte para ello.

CONFIGURACIÓN

Al iniciarse, river ejecutará un archivo ejecutable en $XDG_CONFIG_HOME/river/init si dicho ejecutable existe. Si $XDG_CONFIG_HOME no está establecido, se utilizará ~/.config/river/init en su lugar.

El archivo ejecutable de inicio se ejecutará como líder de grupo de procesos después de que el servidor Wayland de river se inicialice, pero antes de entrar en el bucle principal. Al salir, river enviará SIGTERM a este grupo de procesos.

Normalmente, este ejecutable es un script de shell que invoca riverctl(1) para crear mapeos, iniciar programas como un generador de diseño o una barra de estado, y realizar otras configuraciones.

AUTORES
