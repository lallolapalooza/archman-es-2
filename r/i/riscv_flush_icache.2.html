__riscv_flush_icache(3) Manual de funciones de biblioteca __riscv_flush_icache(3)

NOMBRE

__riscv_flush_icache - Vacía las caché de instrucciones en RISC-V

BIBLIOTECA

Biblioteca C estándar (libc, -lc)

SINOPSIS

#include <sys/cachectl.h>
int __riscv_flush_icache(void *start, void *end, unsigned long flags);

DESCRIPCIÓN

__riscv_flush_icache() garantiza el orden entre las escrituras y las capturas de la caché de instrucciones.

El rango de direcciones sobre el cual se garantiza el orden se especifica mediante start y end.

El argumento flags controla la extensión de este orden, con el comportamiento predeterminado (un valor flags de 0) que consiste en garantizar la valla en todos los hilos del proceso actual. Establecer el bit SYS_RISCV_FLUSH_ICACHE_LOCAL permite a los usuarios indicar que solo es necesario garantizar el orden en el hilo actual. Todos los demás bits de bandera están reservados.

ESTÁNDARES

Linux en RISC-V.

HISTORIA

Linux 4.15. glibc 2.27.

VER TAMBIÉN
