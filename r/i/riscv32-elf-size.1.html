SIZE(1) GNU Development Tools SIZE(1)

NOMBRE

size - lista los tamaños de las secciones y el tamaño total de los archivos binarios

SINOPSIS

size [-A|-B|-G|--format=compatibilidad]
[--help]
[-d|-o|-x|--radix=número]
[--common]
[-t|--totals]
[--target=nombrebfd] [-V|--version]
[-f]
[ficheroobj...]

DESCRIPCIÓN

La utilidad size de GNU lista los tamaños de las secciones y el tamaño total para cada uno de los archivos binarios ficheroobj en su lista de argumentos. Por defecto, se genera una línea de salida para cada archivo o para cada módulo si el archivo es un archivo.

ficheroobj... son los archivos a examinar. Si no se especifica ninguno, se utilizará el archivo "a.out" en su lugar.

OPCIONES

Las opciones de la línea de comandos tienen los siguientes significados:

-A
-B
-G
--format=compatibilidad
Usando una de estas opciones, puedes elegir si la salida de size de GNU se parece a la salida de size de System V (usando -A, o --format=sysv), o a la de size de Berkeley (usando -B, o --format=berkeley). El valor por defecto es el formato de una línea similar al de Berkeley. Alternativamente, puedes elegir la salida en formato GNU (usando -G, o --format=gnu), que es similar al formato de salida de Berkeley, pero los tamaños se cuentan de forma diferente.

Aquí hay un ejemplo del formato de salida de Berkeley (por defecto) de size:

$ size --format=Berkeley ranlib size
   text    data     bss     dec     hex filename
 294880   81920   11592  388392   5ed28 ranlib
 294880   81920   11888  388688   5ee50 size

La salida estilo Berkeley cuenta los datos de solo lectura en la columna "text", no en la columna "data", las columnas "dec" y "hex" muestran la suma de las columnas "text", "data" y "bss" en decimal y hexadecimal respectivamente.

El formato GNU cuenta los datos de solo lectura en la columna "data", no en la columna "text", y solo muestra la suma de las columnas "text", "data" y "bss" una vez, en la columna "total". La opción --radix se puede usar para cambiar la base numérica de todas las columnas. Aquí se muestran los mismos datos con las convenciones GNU:

$ size --format=GNU ranlib size
      text       data        bss      total filename
    279880      96920      11592     388392 ranlib
    279880      96920      11888     388688 size

Estos son los mismos datos, pero mostrados más cerca de las convenciones de System V:

$ size --format=SysV ranlib size
ranlib  :
section         size         addr
.text         294880         8192
.data          81920       303104
.bss           11592       385024
Total         388392


size  :
section         size         addr
.text         294880         8192
.data          81920       303104
.bss           11888       385024
Total         388688
--help
-h
-H
-?
Muestra un resumen de los argumentos y opciones aceptables.
-d
-o
-x
--radix=número
Usando una de estas opciones, puedes controlar si el tamaño de cada sección se da en decimal (-d, o --radix=10); octal (-o, o --radix=8); o hexadecimal (-x, o --radix=16). En --radix=número, solo se admiten los tres valores (8, 10, 16). El tamaño total siempre se da en dos bases; decimal y hexadecimal para la salida -d o -x, u octal y hexadecimal si estás usando -o.
--common
Imprime el tamaño total de los símbolos comunes en cada archivo. Al usar el formato Berkeley o GNU, estos se incluyen en el tamaño bss.
-t
--totals
Muestra los totales de todos los objetos listados (solo en modo de formato Berkeley o GNU).
--target=nombrebfd
Especifica que el formato del código objeto para ficheroobj es nombrebfd. Es posible que esta opción no sea necesaria; size puede reconocer automáticamente muchos formatos.
-v
-V
--version
Muestra el número de versión de size.
-f
Ignorado. Esta opción es utilizada por otras versiones del programa size, pero no es compatible con la versión de GNU Binutils.
@archivo
Lee las opciones de la línea de comandos de archivo. Las opciones leídas se insertan en el lugar de la opción @archivo original. Si archivo no existe, o no se puede leer, la opción se tratará literalmente y no se eliminará.

Las opciones en archivo están separadas por espacios en blanco. Un carácter de espacio en blanco puede incluirse en una opción rodeando la opción completa con comillas simples o dobles. Cualquier carácter (incluyendo una barra invertida) puede incluirse prefijando el carácter a incluir con una barra invertida. El archivo puede contener opciones @archivo adicionales; dichas opciones se procesarán recursivamente.

RISCV32-ELF-SIZE(1) User Commands RISCV32-ELF-SIZE(1)

DESCRIPTION

The riscv32-elf-size utility is used to list the sizes of sections from each object file or archive member specified. The size of an executable or shared object is determined by the sum of the sizes of its sections.

By default, riscv32-elf-size displays the size of the .text, .data and .bss sections, followed by their sum.

OPTIONS

The following options are available:

  • -A, --print-target: Print the name of the target machine for each specified file.
  • -d, --radix=10: Print sizes in decimal. This is the default when symbols are not being processed.
  • -f, --format=FORMAT: Use the specified FORMAT when listing sizes. The following formats are recognized:
    • -f posix: Print sizes in a POSIX-compliant format.
    • -f human: Print sizes in human-readable format (e.g., 1K, 2M, 3G).
  • -h, --help: Print a summary of options and exit.
  • -o, --radix=8: Print sizes in octal.
  • -t, -t, --totals: Print a line of totals for each argument.
  • -x, --radix=16: Print sizes in hexadecimal.
  • -H, --size-only: Print only the total size.
  • --help: Display help information and exit.
  • --version: Output version information and exit.
