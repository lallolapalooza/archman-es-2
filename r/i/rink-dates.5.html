NOMBRE

rink-dates - Formato de archivo de Rink para patrones de fecha

SINOPSIS

Rink permite especificar fechas y horas utilizando la sintaxis #fecha# en las consultas. Este archivo define los patrones que se usan para intentar hacer coincidir la fecha especificada.

DESCRIPCIÓN

Las líneas en blanco se ignoran. Las líneas que comienzan con # se ignoran.

Un patrón de fecha es una secuencia de palabras clave que especifican un token para hacer coincidir. Parte de la secuencia puede ir entre corchetes [] para hacerla opcional.

Las palabras clave válidas son:

fullyear

El año completo de 4 dígitos, como 2024. Debe tener exactamente 4 dígitos.

shortyear

Año corto de 2 dígitos, como 24. Debe tener exactamente 2 dígitos.

century

El año con los últimos 2 dígitos truncados, como 20. No es lo mismo que el número de siglo real (que sería 21). Debe tener exactamente 2 dígitos.

monthnum

El número del mes actual, como 03. Debe tener exactamente 2 dígitos.

day

El día actual del mes, como 3. Puede tener cualquier número de dígitos.

fullday

El día actual del mes, como 03. Debe tener exactamente 2 dígitos.

min

El minuto actual de la hora, como 05. Debe tener exactamente 2 dígitos.

ordinal

El día actual del año, como 083. Debe tener exactamente 3 dígitos.

isoyear

El año ISO, como -0001. Debe tener exactamente 4 dígitos. El año ISO unifica EC y AEC tal que 1 a.C. es el año 0, y 2 a.C. es el año -1.

unix

Marca de tiempo Unix, es decir, el número de 1/86400 de día transcurrido desde el 1 de enero de 1970. Puede tener cualquier número de dígitos.

year

El año actual, como 2024. Puede tener cualquier número de dígitos.

adbc

Busca ad, ce, bc o bce (sin distinción de mayúsculas y minúsculas). Esto permite especificar fechas anteriores al año 1 EC.

hour12

La hora actual en un reloj de 12 horas. Debe tener exactamente 2 dígitos.

hour24

La hora actual en un reloj de 24 horas. Debe tener exactamente 2 dígitos.

meridiem

Busca am o pm (sin distinción de mayúsculas y minúsculas). Esto permite especificar la hora en formato de 12 horas.

sec

El segundo actual del minuto actual. Debe tener exactamente 2 dígitos. Opcionalmente, puede tener un punto decimal para especificar tiempo menor que un segundo.

offset

Coincide con un desplazamiento de zona horaria. Este puede ser el nombre de una zona horaria como US/Pacific o un desplazamiento fijo. El desplazamiento fijo puede tener el formato +07:00 o +0700.

monthname

Coincide con nombres de meses en inglés, sin distinción de mayúsculas y minúsculas. Reconoce nombres de 3 letras (como ene, feb, mar) y nombres completos.

weekday

Coincide con nombres de días de la semana en inglés, sin distinción de mayúsculas y minúsculas. Reconoce nombres de 3 letras (como lun, mar, mié) y nombres completos.

-

Coincide con un carácter literal -.

:

Coincide con un carácter literal :.

` `

Un solo espacio coincidirá con cualquier cantidad de espacio en blanco.

' <cualquier cosa> '

Envolver texto entre comillas simples coincidirá literalmente con ese texto.

ARCHIVOS

Rink busca en las siguientes ubicaciones:

•./rink/datepatterns.txt
•$XDG_CONFIG_DIR/rink/datepatterns.txt
•/usr/share/rink/datepatterns.txt
