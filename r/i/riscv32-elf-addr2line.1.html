NOMBRE

addr2line - convertir direcciones o símbolo+desplazamiento en nombres de archivo y números de línea

SINOPSIS

addr2line [-a|--addresses]
[-b nombrebfd|--target=nombrebfd]
[-C|--demangle[=estilo]]
[-r|--no-recurse-limit]
[-R|--recurse-limit]
[-e nombrearchivo|--exe=nombrearchivo]
[-f|--functions] [-s|--basename]
[-i|--inlines]
[-p|--pretty-print]
[-j|--section=nombre]
[-H|--help] [-V|--version]
[dir dir ...]

DESCRIPCIÓN

addr2line traduce direcciones o símbolo+desplazamiento a nombres de archivo y números de línea. Dada una dirección o símbolo+desplazamiento en un ejecutable o un desplazamiento en una sección de un objeto relocable, usa la información de depuración para determinar qué nombre de archivo y número de línea están asociados con él.

El ejecutable u objeto relocable a usar se especifica con la opción -e. El valor predeterminado es el archivo a.out. La sección en el objeto relocable a usar se especifica con la opción -j.

addr2line tiene dos modos de operación.

En el primero, se especifican direcciones hexadecimales o símbolo+desplazamiento en la línea de comandos, y addr2line muestra el nombre del archivo y el número de línea para cada dirección.

En el segundo, addr2line lee direcciones hexadecimales o símbolo+desplazamiento de la entrada estándar, e imprime el nombre del archivo y el número de línea para cada dirección en la salida estándar. En este modo, addr2line puede usarse en una tubería para convertir direcciones elegidas dinámicamente.

El formato de la salida es NOMBREARCHIVO:NUMEROLINEA. Por defecto, cada dirección de entrada genera una línea de salida.

Dos opciones pueden generar líneas adicionales antes de cada línea de NOMBREARCHIVO:NUMEROLINEA (en ese orden).

Si se usa la opción -a, se muestra una línea con la dirección de entrada.

Si se usa la opción -f, se muestra una línea con el NOMBREFUNCION. Este es el nombre de la función que contiene la dirección.

Una opción puede generar líneas adicionales después de la línea NOMBREARCHIVO:NUMEROLINEA.

Si se usa la opción -i y el código en la dirección dada está presente debido a la inlining por parte del compilador, entonces se mostrarán líneas adicionales después. Se muestran una o dos líneas adicionales (si se usa la opción -f) para cada función inlined.

Alternativamente, si se usa la opción -p, cada dirección de entrada genera una única línea de salida larga que contiene la dirección, el nombre de la función, el nombre del archivo y el número de línea. Si también se ha usado la opción -i, las funciones inlined se mostrarán de la misma manera, pero en líneas separadas y precedidas por el texto (inlined por).

Si el nombre del archivo o el nombre de la función no se pueden determinar, addr2line imprimirá dos signos de interrogación en su lugar. Si el número de línea no se puede determinar, addr2line imprimirá 0.

Cuando se usa símbolo+desplazamiento, +desplazamiento es opcional, excepto cuando el símbolo es ambiguo con un número hexadecimal. Los símbolos resueltos pueden estar mangled o demangled, excepto que no se permiten símbolos sin mangling con +.

OPCIONES

Las formas largas y cortas de las opciones, que se muestran aquí como alternativas, son equivalentes.

-a
--addresses
Muestra la dirección antes del nombre de la función, archivo y número de línea. La dirección se imprime con un prefijo 0x para identificarla fácilmente.
-b nombrebfd
--target=nombrebfd
Especifica que el formato del código objeto para los archivos objeto es nombrebfd.
-C
--demangle[=estilo]
Decodifica (demangle) nombres de símbolos de bajo nivel a nombres de nivel de usuario. Además de eliminar cualquier guion bajo inicial agregado por el sistema, esto hace que los nombres de funciones C++ sean legibles. Diferentes compiladores tienen diferentes estilos de mangling. El argumento opcional del estilo de demangling se puede usar para elegir un estilo de demangling apropiado para su compilador.
-e nombrearchivo
--exe=nombrearchivo
Especifica el nombre del ejecutable para el cual se traducirán las direcciones. El archivo predeterminado es a.out.
-f
--functions
Muestra los nombres de las funciones, así como la información del archivo y el número de línea.
-s
--basenames
Muestra solo la parte base de cada nombre de archivo.
-i
--inlines
Si la dirección pertenece a una función que fue inlined, también se imprimirá la información de origen de todos los ámbitos contenedores hasta la primera función no inlined. Por ejemplo, si "main" inlines "callee1" que inlines "callee2", y la dirección es de "callee2", también se imprimirá la información de origen de "callee1" y "main".
-j
--section
Lee los desplazamientos relativos a la sección especificada en lugar de las direcciones absolutas.
-p
--pretty-print
Hace que la salida sea más amigable para el humano: cada ubicación se imprime en una línea. Si se especifica la opción -i, las líneas de todos los ámbitos contenedores se prefijan con (inlined por).
-r
-R
--recurse-limit
--no-recurse-limit
--recursion-limit
--no-recursion-limit
Habilita o deshabilita un límite en la cantidad de recursión realizada al decodificar cadenas. Dado que los formatos de mangling de nombres permiten un nivel infinito de recursión, es posible crear cadenas cuya decodificación agote la cantidad de espacio de pila disponible en la máquina host, desencadenando un fallo de memoria. El límite intenta evitar que esto suceda restringiendo la recursión a 2048 niveles de anidamiento.

El valor predeterminado es que este límite esté habilitado, pero deshabilitarlo puede ser necesario para decodificar nombres verdaderamente complicados. Tenga en cuenta, sin embargo, que si el límite de recursión está deshabilitado, es posible agotar la pila y cualquier informe de error sobre tal evento será rechazado.

La opción -r es un sinónimo de la opción --no-recurse-limit. La opción -R es un sinónimo de la opción --recurse-limit.

Tenga en cuenta que esta opción solo es efectiva si se ha habilitado la opción -C o --demangle.

@archivo
Lee las opciones de la línea de comandos de archivo. Las opciones leídas se insertan en lugar de la opción original @archivo. Si archivo no existe o no se puede leer, la opción se tratará literalmente y no se eliminará.

Las opciones en archivo están separadas por espacios en blanco. Se puede incluir un carácter de espacio en blanco en una opción rodeando toda la opción con comillas simples o dobles. Se puede incluir cualquier carácter (incluido un contrabarra) anteponiendo el carácter a incluir con una contrabarra. El archivo puede contener opciones adicionales @archivo; cualquier opción de este tipo se procesará

NOMBRE

addr2line - convierte direcciones de memoria en nombres de ficheros, líneas de código y nombres de funciones.

SINOPSIS

addr2line [opciones...] [--] [dirección...]

DESCRIPCIÓN

addr2line toma direcciones de memoria como argumentos y, usando la información de depuración del ejecutable especificado (o si no se especifica, a.out), imprime el nombre del fichero y el número de línea de código correspondiente a cada dirección.

También puede imprimir el nombre de la función que contiene la dirección.

Si se proporciona más de una dirección, se procesan recursivamente.
