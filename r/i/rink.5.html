NOMBRE

rink - Formato de archivo de configuración TOML.

DESCRIPCIÓN

El archivo de configuración de Rink utiliza el formato TOML.

Los tipos de duración aceptan sufijos comunes como ms, s, h, d, y. Los tipos de tamaño aceptan sufijos como MB.

Las cadenas de color son un conjunto de palabras clave separadas por espacios. Las siguientes palabras clave son entendidas:

black, red, green, yellow, blue, purple, cyan, white

Establece el color a ese color ANSI.

dim/dimmed

Utiliza una variante atenuada del color en lugar de la variante brillante.

bold, italic, underline/under, strikethrough

Formato.

hidden/none

Hace que el texto sea invisible.

on

La palabra clave de color después de esto se aplicará al fondo en lugar del primer plano. Ejemplo: black on red.

default/plain

Resulta en texto sin estilo.

enteros 0 a 255

Códigos de paleta de colores extendida del terminal.

# <6 letras hexadecimales>

Se pueden usar códigos hexadecimales para especificar truecolor. Ejemplo: #000000

rgb( <rojo> , <verde> , <azul> )

Se pueden usar valores RGB para especificar truecolor. No se permiten espacios. Ejemplo: rgb(10,10,10)

Rink

La sección [rink].

prompt = <cadena>

El texto que se mostrará antes del cursor, para indicar interactividad. Debe incluir el carácter de espacio. Predeterminado: "> "

long_output = <booleano>

Divide las listas, como los resultados de búsqueda, en varias líneas. Requiere un terminal con capacidad Unicode. Predeterminado: false

Moneda

La sección [currency].

enabled = <booleano>

La obtención de divisas se puede deshabilitar para aquellos que no la deseen. Predeterminado: true

endpoint = <url>

Permite apuntar a instancias alternas de Rink-Web, o a cualquier otra API que ofrezca un formato compatible. Predeterminado: "https://rinkcalc.app/data/currency.json"

timeout = <duración>

Cuánto esperar para obtener la divisa antes de rendirse. Predeterminado: "2s"

cache_duration = <duración>

Cuánto esperar antes de considerar obsoletos los datos de divisas cacheados. Predeterminado: "1h"

Colores

La sección [colors].

enabled = <booleano>

Establecer a true para activar la salida en color. Predeterminado: true, o false si la variable de entorno NO_COLOR está establecida.

theme = <cadena>

Establece el tema activo. Ver la sección TEMAS. Predeterminado: "default"

Temas

La sección [themes]. Esta sección es un diccionario, cada tema debe crearse como [themes.mi_tema]. Estas opciones son específicas para cada uno.

plain = <color>

Texto genérico. Esto se usará a menudo. Predeterminado: "default"

error = <color>

Mensajes de error. Predeterminado: "red"

unit = <color>

Los nombres de las unidades, como kilogramo. Predeterminado: "cyan"

quantity = <color>

Los nombres de las cantidades físicas, como longitud y tiempo. Estos se muestran entre paréntesis en cada consulta. Predeterminado: "dimmed cyan"

number = <color>

Números que aparecen en las salidas. Predeterminado: "default"

user_input = <color>

Se utiliza cuando rink cita la entrada del usuario, como en errores de unidad no encontrada. Predeterminado: "bold"

doc_string = <color>

Se utiliza cuando rink muestra texto informativo que es parte de la definición de una unidad, como metro. Predeterminado: "italic"

pow = <color>

El ^2 en m/s^2. Predeterminado: "default"

prop_name = <color>

Nombres de propiedades en sustancias, como la velocidad en velocidad de la luz. Predeterminado: "cyan"

date_time = <color>

Objetos de fecha y hora, que se pueden obtener con la notación de hash o now. Predeterminado: "default"

ARCHIVOS

Linux

__$XDG_CONFIG_DIR__/rink/config.toml

Windows

__{FOLDERID_RoamingAppData}__\rink\config.toml

macOS

__$HOME__/Library/Application Support/rink/config.toml
