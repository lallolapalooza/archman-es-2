RIPASSO-CURSIVE(1) Manual de Comandos Generales RIPASSO-CURSIVE(1)

NOMBRE

ripasso-cursive - Un gestor de contraseñas que utiliza el formato de archivo del gestor de contraseñas estándar de Unix 'pass', implementado en rust.

SINOPSIS

ripasso-cursive [INDICADORES]

DESCRIPCIÓN

ripasso-cursive es una aplicación curses que te permite gestionar tus contraseñas o las de tu equipo. Las contraseñas se cifran con pgp y opcionalmente se almacenan en un repositorio git. La lista de miembros del equipo se almacena en el archivo .gpg-id, un id de clave pgp por línea.

INDICADORES

-h, --help
Imprime un texto de ayuda

ATAJOS DE TECLADO

Enter : Copia la contraseña seleccionada actualmente al búfer de copia durante 40 segundos

Delete : Elimina la contraseña marcada

Insert : Crea una nueva entrada de contraseña

Control + y : igual que Enter

Control + b : si la contraseña tiene una URL otpauth://, genera un código y lo almacena en el búfer de copia

Control + n : mueve el marcador hacia abajo

Control + p : mueve el marcador hacia arriba

Control + r : renombra la contraseña sin cambiar su contenido

Control + u : copia el nombre de archivo de la contraseña

Control + h : muestra el historial git de la contraseña

Control + v : muestra la lista de miembros del equipo

Control + o : abre un diálogo de edición de contraseñas

Control + f : extrae del repositorio git

Control + g : envía al repositorio git

Escape : salir

NOTA DE USO

ripasso-cursive lee por defecto $HOME/.password-store/, anula esto estableciendo la variable de entorno PASSWORD_STORE_DIR.

Si especificas la variable de entorno PASSWORD_STORE_SIGNING_KEY, entonces ripasso verificará que el archivo .gpg-id esté firmado correctamente. Los valores válidos son una o más huellas digitales pgp de 40 caracteres, separadas por comas.

ARCHIVO DE CONFIGURACIÓN

ripasso lee la configuración de $XDG_CONFIG_HOME/ripasso/settings.toml

Archivo de configuración de ejemplo

[stores]


[stores.default]


path = "/home/user/.password-store/"


valid_signing_keys = "AF77DAC5B3882EAD316B7312D5B659E1D2FDF0C3"


[stores.work]


path = "/home/user/.work_pass/"


style_path = "/home/user/.config/ripasso/work-style.toml"

La configuración válida para una tienda es:

path : Esta es la ruta raíz al directorio del almacén de contraseñas

valid_signing_keys : esta configuración corresponde a la variable de entorno PASSWORD_STORE_SIGNING_KEY

style_path : información de color y estilo para la tienda, las diferentes tiendas pueden tener estilos diferentes y cambiarán cuando cambies de tienda. La documentación sobre el formato se puede encontrar aquí https://docs.rs/cursive_core/0.1.1/cursive_core/theme/index.html

pgp : la implementación pgp a utilizar para la tienda, los valores válidos son gpg o sequoia

own_fingerprint : si la opción pgp está establecida en sequoia, ripasso necesita conocer la huella digital de tu propia clave para poder comunicarse con gpg-agent
