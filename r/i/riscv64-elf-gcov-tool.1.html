NOMBRE

gcov-tool - herramienta de procesamiento de perfiles gcda fuera de línea

SINOPSIS

gcov-tool [-v|--version] [-h|--help]

gcov-tool merge [opciones-de-fusión] directorio1 directorio2
[-o|--output directorio]
[-v|--verbose]
[-w|--weight p1,p2]

gcov-tool merge-stream [opciones-de-fusión-de-flujo] [archivo]
[-v|--verbose]
[-w|--weight p1,p2]

gcov-tool rewrite [opciones-de-reescritura] directorio
[-n|--normalize valor_long_long]
[-o|--output directorio]
[-s|--scale valor_float_o_fraccion_simple]
[-v|--verbose]

gcov-tool overlap [opciones-de-solapamiento] directorio1 directorio2
[-f|--function]
[-F|--fullname]
[-h|--hotonly]
[-o|--object]
[-t|--hot_threshold] float
[-v|--verbose]

DESCRIPCIÓN

gcov-tool es una herramienta fuera de línea para procesar los archivos de perfil gcda de gcc.

El gcov-tool actual soporta las siguientes funcionalidades:

  • fusionar dos conjuntos de perfiles con pesos.
  • leer un flujo de perfiles con nombres de archivo asociados y fusionarlo con un conjunto de perfiles con pesos.
  • leer un conjunto de perfiles y reescribir el contenido del perfil. Se pueden escalar o normalizar los valores de los contadores.

Ejemplos de los casos de uso para esta herramienta son:

  • Recopilar los perfiles para diferentes conjuntos de entradas y usar esta herramienta para fusionarlos. Se puede especificar el peso para tener en cuenta la importancia relativa de cada entrada.
  • Recopilar perfiles de sistemas de destino sin sistema de archivos (entornos autónomos). Fusionar los perfiles recopilados con los perfiles asociados presentes en el sistema host. Se puede especificar el peso para tener en cuenta la importancia relativa de cada entrada.
  • Reescribir el perfil después de eliminar un subconjunto de los archivos gcda, manteniendo la consistencia del resumen y el histograma.
  • También se puede usar para depurar el código de libgcov, ya que la herramienta comparte la mayoría del código con la biblioteca en tiempo de ejecución.

Tenga en cuenta que para la operación de fusión, este perfil generado fuera de línea puede contener valores ligeramente diferentes del perfil fusionado en línea. Aquí hay una lista de diferencias típicas:

  • diferencia de histograma: esta herramienta fuera de línea recalcula el histograma después de fusionar los contadores. El histograma resultante, por lo tanto, es preciso. La fusión en línea no tiene esta capacidad: el histograma se fusiona a partir de dos histogramas y el resultado es una aproximación.
  • diferencia de suma de verificación del resumen: la suma de verificación del resumen utiliza una operación CRC32. El valor depende del orden de la lista de enlaces de los objetos gcov-info. Este orden es diferente en gcov-tool que en la fusión en línea. Se espera que tenga diferentes sumas de verificación del resumen. En realidad, no importa ya que el compilador no utiliza esta suma de verificación en ninguna parte.
  • diferencia de valores de los contadores del perfil de valor: algunos valores de contadores para el perfil de valor dependen del tiempo de ejecución, como las direcciones del heap. Es normal ver alguna diferencia en este tipo de contadores.

OPCIONES

-h
--help
Muestra la ayuda sobre el uso de gcov-tool (en la salida estándar) y sale sin realizar ningún procesamiento adicional.
-v
--version
Muestra el número de versión de gcov-tool (en la salida estándar) y sale sin realizar ningún procesamiento adicional.
merge
Fusiona dos directorios de perfiles.
-o directorio
--output directorio
Establece el directorio de perfiles de salida. El nombre del directorio de salida predeterminado es merged_profile.
-v
--verbose
Establece el modo detallado.
-w p1,p2
--weight p1,p2
Establece los pesos de fusión de directorio1 y directorio2, respectivamente. Los pesos predeterminados son 1 para ambos.
merge-stream
Recopila perfiles con nombres de archivo asociados de un flujo de datos gcfn y gcda. Lee el flujo desde el archivo especificado por archivo o desde stdin. Fusiona los perfiles con los perfiles asociados en el sistema de archivos host. Aplica los pesos opcionales al fusionar perfiles.

Para la generación de un flujo de datos gcfn y gcda en el sistema de destino, consulte las funciones "__gcov_filename_to_gcfn()" y "__gcov_info_to_gcda()" declaradas en "#include <gcov.h>".

-v
--verbose
Establece el modo detallado.
-w p1,p2
--weight p1,p2
Establece los pesos de fusión de los perfiles del flujo de datos gcfn y gcda y los perfiles asociados en el sistema de archivos host, respectivamente. Los pesos predeterminados son 1 para ambos.
rewrite
Lee el directorio de perfiles especificado y reescribe a un nuevo directorio.
-n valor_long_long
--normalize <valor_long_long>
Normaliza el perfil. El valor especificado es el valor máximo del contador en el nuevo perfil.
-o directorio
--output directorio
Establece el directorio de perfiles de salida. El nombre de salida predeterminado es rewrite_profile.
-s valor_float_o_fraccion_simple
--scale valor_float_o_fraccion_simple
Escala los contadores del perfil. El valor especificado puede ser un valor de punto flotante o una forma de valor de fracción simple, como 1, 2, 2/3 y 5/3.
-v
--verbose
Establece el modo detallado.
overlap
Calcula la puntuación de solapamiento entre los dos directorios de perfiles especificados. La puntuación de solapamiento se calcula basándose en los perfiles de arco. Se define como la suma de min(contador_p1[i] / suma_total_p1, contador_p2[i] / suma_total_p2), para todos los contadores de arco i, donde contador_p1[i] y contador_p2[i] son dos contadores coincidentes y suma_total_p1 y suma_total_p2 son la suma de los valores de los contadores en el perfil 1 y el perfil 2, respectivamente.
-f
--function
Imprime la puntuación de solapamiento a nivel de función.
-F
--fullname
Imprime el nombre de archivo gcda completo.
-h
--hotonly
Solo imprime información

NAME

gcov-tool — dump and analyze GCC coverage data

SYNOPSIS

gcov-tool [OPTION]...

DESCRIPTION

The gcov-tool utility is used to dump and analyze GCC coverage data. It can be used to process and merge multiple coverage data files generated by different runs of a program. It also provides options to customize the output and filtering of coverage information.

OPTIONS

-a
Dump and analyze coverage data for hot objects/functions.
-o
--object
Print object level overlap score.
-t float
--hot_threshold <float>
Set the threshold for hot counter value.
-v
--verbose
Set the verbose mode.
