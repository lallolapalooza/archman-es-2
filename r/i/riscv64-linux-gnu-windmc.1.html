WINDMC(1) Herramientas de desarrollo de GNU WINDMC(1)

NOMBRE

windmc - genera recursos de mensajes de Windows

SINOPSIS

windmc [opciones] archivo-entrada

DESCRIPCIÓN

windmc lee las definiciones de mensajes de un archivo de entrada (.mc) y las traduce a un conjunto de archivos de salida. Los archivos de salida pueden ser de cuatro tipos:

"h"
Un archivo de cabecera C que contiene las definiciones de mensajes.
"rc"
Un archivo de recursos compilable por la herramienta windres.
"bin"
Uno o más archivos binarios que contienen los datos de recursos para un idioma de recursos específico.
"dbg"
Un archivo de inclusión C que mapea los IDs de mensajes a su nombre simbólico.

La descripción exacta de estos diferentes formatos está disponible en la documentación de Microsoft.

Cuando windmc convierte del formato "mc" al formato "bin", "rc", "h", y opcionalmente "dbg", actúa como el Compilador de Mensajes de Windows.

OPCIONES

-a
--ascii_in
Especifica que el archivo de entrada especificado está en ASCII. Este es el comportamiento por defecto.
-A
--ascii_out
Especifica que los mensajes en los archivos "bin" de salida deben estar en formato ASCII.
-b
--binprefix
Especifica que los nombres de archivo "bin" deben tener el prefijo del nombre base del archivo fuente.
-c
--customflag
Establece el bit de cliente en todos los IDs de mensajes.
-C página_de_códigos
--codepage_in página_de_códigos
Establece la página de códigos por defecto que se utilizará para convertir el archivo de entrada a UTF16. La página de códigos por defecto es 1252.
-d
--decimal_values
Muestra las constantes en el archivo de cabecera en decimal. La salida por defecto es en hexadecimal.
-e ext
--extension ext
La extensión para el archivo de cabecera. La extensión por defecto es .h.
-F objetivo
--target objetivo
Especifica el formato BFD a utilizar para un archivo binario como salida. Este es un nombre de objetivo BFD; puedes usar la opción --help para ver una lista de objetivos soportados. Normalmente windmc utilizará el formato por defecto, que es el primero listado por la opción --help.
-h ruta
--headerdir ruta
El directorio de destino del archivo de cabecera generado. El directorio por defecto es el directorio actual.
-H
--help
Muestra una lista de opciones de línea de comandos y luego sale.
-m caracteres
--maxlength caracteres
Indica a windmc que genere una advertencia si la longitud de cualquier mensaje excede el número especificado.
-n
--nullterminate
Termina el texto del mensaje en los archivos "bin" con un cero. Por defecto, se terminan con CR/LF.
-o
--hresult_use
Aún no implementado. Indica a "windmc" que genere un archivo de cabecera OLE2, utilizando definiciones HRESULT. Los códigos de estado se utilizan si la bandera no está especificada.
-O página_de_códigos
--codepage_out página_de_códigos
Establece la página de códigos por defecto que se utilizará para generar archivos de texto. La página de códigos por defecto es 1252.
-r ruta
--rcdir ruta
El directorio de destino del script "rc" generado y los archivos "bin" generados que incluye el script del compilador de recursos. El directorio por defecto es el directorio actual.
-u
--unicode_in
Especifica que el archivo de entrada es UTF16.
-U
--unicode_out
Especifica que los mensajes en el archivo "bin" de salida deben estar en formato UTF16. Este es el comportamiento por defecto.
-v
--verbose
Habilita el modo detallado.
-V
--version
Imprime el número de versión de windmc.
-x ruta
--xdgb ruta
La ruta del archivo de inclusión C "dbg" que mapea los IDs de mensajes al nombre simbólico. No se genera ningún archivo sin especificar esta opción.
@archivo
Lee las opciones de línea de comandos desde archivo. Las opciones leídas se insertan en lugar de la opción @archivo original. Si archivo no existe, o no se puede leer, la opción se tratará literalmente y no se eliminará.

Las opciones en archivo están separadas por espacios en blanco. Un carácter de espacio en blanco puede incluirse en una opción rodeando la opción completa con comillas simples o dobles. Cualquier carácter (incluido una barra invertida) puede incluirse prefijando el carácter a incluir con una barra invertida. El archivo puede contener opciones adicionales @archivo; cualquiera de estas opciones se procesará recursivamente.
