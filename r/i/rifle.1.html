RIFLE(1) Manual de rifle RIFLE(1)

NOMBRE

rifle - abridor de archivos de ranger

SINOPSIS

rifle [--ayuda] [-f FLAGS] [-l] [-p PALABRA_CLAVE] [-w PROGRAMA] [-c ARCHIVO_CONFIG] archivos

DESCRIPCIÓN

rifle es un ejecutor de archivos potente que permite una verificación compleja de tipos de archivo, escrito para satisfacer las necesidades del gestor de archivos ranger. La fortaleza de rifle radica en determinar automáticamente los tipos de archivo, dependiendo de los programas instalados en el sistema, incluso sin ninguna interacción del usuario.

OPCIONES

-f FLAGS
Especifica indicadores para abrir los archivos. Los indicadores son letras que cambian cómo se ejecuta el programa. Cualquier combinación de indicadores funcionará. Escribir indicadores en mayúsculas negará el efecto de todos los indicadores en minúsculas previamente utilizados de la misma letra.

Tabla de todos los indicadores:
f poner el programa en segundo plano (fork)
r ejecutar el programa como root, usando sudo
t ejecutar el programa en una terminal separada, según lo especificado por $TERMCMD

-l
Lista todas las formas posibles de abrir los archivos especificados. Cada línea contendrá información en el formato id:etiqueta:indicadores:comando. id es el número de identificación. etiqueta es una cadena de caracteres arbitraria que se especificó para este comando, indicadores son los indicadores que se usan por defecto, y comando es el comando que se va a ejecutar.
-p PALABRA_CLAVE
Selecciona un método para abrir los archivos.

PALABRA_CLAVE es el número de ID listado por "rifle -l" o una cadena que coincide con una etiqueta en el archivo de configuración.

-w PROGRAMA
Abre los archivos con el programa PROGRAMA
-c ARCHIVO_CONFIG
Lee la configuración desde ARCHIVO_CONFIG, en lugar de la predeterminada.
-h, --ayuda
Imprime una lista de opciones y sale.

ARCHIVOS

rifle comparte archivos de configuración con ranger, aunque ranger no es necesario para usar rifle. El archivo de configuración predeterminado rifle.conf se espera que esté en ~/.config/ranger/rifle.conf. Sin embargo, esto se puede anular con la opción -c.

Este archivo especifica patrones para determinar los comandos con los que abrir archivos. La sintaxis se describe en los comentarios del rifle.conf predeterminado que se incluye con ranger. Para obtenerlo, necesitas ejecutar: "ranger --copy-config=rifle"

ENTORNO

VISUAL
Determina qué editor se utilizará para editar archivos.
EDITOR
Determina qué editor se utilizará para editar archivos si VISUAL no está definido o está vacío (en el rifle.conf predeterminado). Si ambos no están definidos o están vacíos, se usará "vim" en su lugar.
PAGER
Determina qué paginador se utilizará para mostrar archivos (en el rifle.conf predeterminado).
TERMCMD
Determina el comando del emulador de terminal a utilizar con el indicador t. Se requiere que el valor sea la ruta a un archivo ejecutable que acepte el argumento "-e COMANDO".
XDG_CONFIG_HOME
Especifica el directorio para los archivos de configuración. Predetermina a $HOME/.config.

EJEMPLOS

Lista todos los métodos diferentes:

$ rifle -l helloworld.py
0:editor::"$EDITOR" -- "$@"
1:pager::"$PAGER" -- "$@"
2:::python -- "$1"

Muestra su contenido abriéndolo con "cat":

$ rifle -w cat helloworld.py
print("Hello World!")

Ejecútalo seleccionando el método 2, que llama a 'python -- "$1"':

$ rifle -p 2 helloworld.py
Hello World!

Muestra el archivo en un paginador dentro de una nueva terminal, ejecutado como root:

$ rifle -p 1 -f tr helloworld.py
rifle-1.9.4 2024-11-04
