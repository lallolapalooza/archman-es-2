RIOSTREAM(1) librdmacm RIOSTREAM(1)

NOMBRE

riostream - prueba de ping-pong de streaming de copia cero sobre RDMA.

SINOPSIS

riostream [-s dirección_servidor] [-b dirección_enlace] [-B tamaño_buffer]
			[-I iteraciones] [-C contador_transferencia]
			[-S tamaño_transferencia] [-p puerto_servidor] [-T opción_prueba]

DESCRIPCIÓN

Utiliza el protocolo de streaming sobre RDMA (rsocket) para conectar e intercambiar datos entre una aplicación cliente y servidor.

OPCIONES

-s dirección_servidor
El nombre de red o la dirección IP del sistema servidor que escucha las conexiones. El nombre o dirección utilizada debe enrutarse a través de un dispositivo RDMA. Esta opción debe ser especificada por el cliente.
-b dirección_enlace
La dirección de red local a la que enlazarse.
-B tamaño_buffer
Indica el tamaño de los búferes de red de envío y recepción.
-I iteraciones
El número de veces que se intercambiará el número especificado de mensajes entre el cliente y el servidor. (por defecto 1000)
-C contador_transferencia
El número de mensajes a transferir desde el cliente al servidor y viceversa en cada iteración. (por defecto 1)
-S tamaño_transferencia
El tamaño de cada transferencia de envío, en bytes. (por defecto 1000) Si se especifica 'all', rstream ejecutará una serie de pruebas de varios tamaños.
-p puerto_servidor
El número de puerto del servidor.
-T opción_prueba
Especifica los parámetros de la prueba. Las opciones disponibles son:

a | async - utiliza operación asíncrona (p. ej., select / poll)

b | blocking - utiliza llamadas bloqueantes

n | nonblocking - utiliza llamadas no bloqueantes

v | verify - verifica las transferencias de datos

NOTAS

El uso básico consiste en iniciar riostream en un sistema servidor, luego ejecutar riostream -s nombre_servidor en un sistema cliente. Por defecto, riostream ejecutará una serie de pruebas de rendimiento de latencia y ancho de banda. Especificar un número diferente de iteraciones, contador_transferencia o tamaño_transferencia ejecutará una prueba personalizada por el usuario utilizando los valores predeterminados donde no se haya especificado ninguno.

Dado que esta prueba mapea recursos RDMA al espacio de usuario, los usuarios deben asegurarse de que tienen recursos y permisos del sistema disponibles. Consulte el archivo README de libibverbs para obtener detalles adicionales.
