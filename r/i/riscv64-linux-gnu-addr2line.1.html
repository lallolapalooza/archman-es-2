ADDR2LINE(1) Herramientas de Desarrollo GNU ADDR2LINE(1)

NOMBRE

addr2line - convierte direcciones o símbolo+desplazamiento en nombres de archivo y números de línea

SINOPSIS

addr2line [-a|--addresses]
[-b nombre_bfd|--target=nombre_bfd]
[-C|--demangle[=estilo]]
[-r|--no-recurse-limit]
[-R|--recurse-limit]
[-e nombre_archivo|--exe=nombre_archivo]
[-f|--functions] [-s|--basename]
[-i|--inlines]
[-p|--pretty-print]
[-j|--section=nombre]
[-H|--help] [-V|--version]
[dir dir ...]

DESCRIPCIÓN

addr2line traduce direcciones o símbolo+desplazamiento a nombres de archivo y números de línea. Dada una dirección o símbolo+desplazamiento en un ejecutable o un desplazamiento en una sección de un objeto relocable, utiliza la información de depuración para determinar qué nombre de archivo y número de línea están asociados con él.

El ejecutable o objeto relocable a usar se especifica con la opción -e. El valor por defecto es el archivo a.out. La sección en el objeto relocable a usar se especifica con la opción -j.

addr2line tiene dos modos de operación.

En el primero, las direcciones hexadecimales o símbolo+desplazamiento se especifican en la línea de comandos, y addr2line muestra el nombre de archivo y el número de línea para cada dirección.

En el segundo, addr2line lee direcciones hexadecimales o símbolo+desplazamiento de la entrada estándar, y muestra el nombre de archivo y el número de línea para cada dirección en la salida estándar. En este modo, addr2line puede usarse en un pipe para convertir direcciones elegidas dinámicamente.

El formato de la salida es NOMBRE_ARCHIVO:NUMERO_LINEA. Por defecto, cada dirección de entrada genera una línea de salida.

Dos opciones pueden generar líneas adicionales antes de cada línea de NOMBRE_ARCHIVO:NUMERO_LINEA (en ese orden).

Si se usa la opción -a, entonces se muestra una línea con la dirección de entrada.

Si se usa la opción -f, entonces se muestra una línea con el NOMBRE_FUNCION. Este es el nombre de la función que contiene la dirección.

Una opción puede generar líneas adicionales después de la línea de NOMBRE_ARCHIVO:NUMERO_LINEA.

Si se usa la opción -i y el código en la dirección dada está presente allí debido a la inclusión por parte del compilador, entonces se mostrarán líneas adicionales después. Se muestran una o dos líneas adicionales (si se usa la opción -f) por cada función incluida.

Alternativamente, si se usa la opción -p, entonces cada dirección de entrada genera una única línea de salida larga que contiene la dirección, el nombre de la función, el nombre del archivo y el número de línea. Si también se ha usado la opción -i, entonces cualquier función incluida se mostrará de la misma manera, pero en líneas separadas y precedida por el texto (incluido por).

Si no se puede determinar el nombre del archivo o el nombre de la función, addr2line mostrará dos signos de interrogación en su lugar. Si no se puede determinar el número de línea, addr2line mostrará 0.

Cuando se usa símbolo+desplazamiento, +desplazamiento es opcional, excepto cuando el símbolo es ambiguo con un número hexadecimal. Los símbolos resueltos pueden estar ofuscados o sin ofuscar; sin embargo, los símbolos sin ofuscar con + no están permitidos.

OPCIONES

Las formas largas y cortas de las opciones, mostradas aquí como alternativas, son equivalentes.

-a
--addresses
Muestra la dirección antes del nombre de la función, el archivo y la información de número de línea. La dirección se imprime con un prefijo 0x para identificarla fácilmente.
-b nombre_bfd
--target=nombre_bfd
Especifica que el formato del código objeto para los archivos objeto es nombre_bfd.
-C
--demangle[=estilo]
Decodifica (demangle) los nombres de símbolos de bajo nivel a nombres de nivel de usuario. Además de eliminar cualquier guion bajo inicial añadido por el sistema, esto hace que los nombres de funciones C++ sean legibles. Diferentes compiladores tienen diferentes estilos de ofuscado. El argumento opcional de estilo de decodificación se puede usar para elegir un estilo de decodificación apropiado para su compilador.
-e nombre_archivo
--exe=nombre_archivo
Especifica el nombre del ejecutable para el cual se deben traducir las direcciones. El archivo por defecto es a.out.
-f
--functions
Muestra los nombres de las funciones, así como la información del archivo y el número de línea.
-s
--basenames
Muestra solo la parte base de cada nombre de archivo.
-i
--inlines
Si la dirección pertenece a una función que fue incluida, la información de origen de todos los ámbitos envolventes hasta la primera función no incluida también se imprimirá. Por ejemplo, si "main" incluye "callee1" que incluye "callee2", y la dirección es de "callee2", también se imprimirá la información de origen de "callee1" y "main".
-j
--section
Lee los desplazamientos relativos a la sección especificada en lugar de direcciones absolutas.
-p
--pretty-print
Hace que la salida sea más amigable para el humano: cada ubicación se imprime en una línea. Si se especifica la opción -i, las líneas de todos los ámbitos envolventes se prefijan con (incluido por).
-r
-R
--recurse-limit
--no-recurse-limit
--recursion-limit
--no-recursion-limit
Habilita o deshabilita un límite en la cantidad de recursión realizada al decodificar cadenas. Dado que los formatos de ofuscado de nombres permiten un nivel infinito de recursión, es posible crear cadenas cuya decodificación agote la cantidad de espacio de pila disponible en la máquina host, provocando un fallo de memoria. El límite intenta evitar que esto suceda restringiendo la recursión a 2048 niveles de anidamiento.

Por defecto, este límite está habilitado, pero puede ser necesario deshabilitarlo para decodificar nombres verdaderamente complicados. Tenga en cuenta, sin embargo, que si el límite de recursión está deshabilitado, es posible agotar la pila y cualquier informe de error sobre un evento de este tipo será rechazado.

La opción -r es un sinónimo de la opción --no-recurse-limit. La opción -R es un sinónimo de la opción --recurse-limit.

Tenga en cuenta que esta opción solo es efectiva si se ha habilitado la opción -C o --demangle.

@archivo
Lee las opciones de la línea de comandos de archivo. Las opciones leídas se insertan en lugar de la opción original @archivo. Si archivo no existe o no se puede leer, la opción se tratará literalmente y no se eliminará.

Las opciones en archivo están separadas por espacios en blanco. Un carácter de espacio en blanco puede incluirse en una opción rodeando toda la opción con comillas simples o dobles. Cualquier carácter (incluido una barra invertida) puede incluirse anteponiendo el carácter a incluir con una barra invertida. El archivo puede contener opciones adicionales @archivo; cualquiera de esas opciones se procesará de forma recursiva.

EJEMPLOS

Dado un programa llamado `hello.c`:

#include <stdio.h>

void func()
{
    printf("Hello, world!\n");
}

int main()
{
    func();
    return 0;
}

Compilando con información de depuración:

$ gcc -g hello.c -o hello

Si el programa falla y produce un volcado de memoria en la dirección 0x40051c, y la función `func` está en la dirección 0x40051c, puede obtener la ubicación del archivo de la siguiente manera:

$ addr2line -e hello 0x40051c
/home/user/hello.c:3

Para mostrar el nombre de la función:

$ addr2line -e -f hello 0x40051c
func
/home/user/hello.c:3

Para obtener la ubicación de la función `main`:

$ addr2line -e -f hello 0x400538
main
/home/user/hello.c:7

Para obtener la ubicación de la llamada a `printf` desde `func`:

$ addr2line -e -f -i hello 0x400521
printf
/usr/include/stdio.h:899

Para obtener la ubicación de `func` y la llamada a `printf` como una sola línea de salida:

$ addr2line -e -p hello 0x40051c
/home/user/hello.c:3 in func

Para obtener la ubicación de la llamada a `printf` como una sola línea de salida:

$ addr2line -e -p -i hello 0x400521
/usr/include/stdio.h:899 in printf (inlined by func)
