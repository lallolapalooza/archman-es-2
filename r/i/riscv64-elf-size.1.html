Paquete: riscv64-elf-binutils

Licencias: GPL

SIZE(1) Herramientas de desarrollo de GNU SIZE(1)

NOMBRE

size - lista los tamaños de las secciones y el tamaño total de los archivos binarios

SINOPSIS

size [-A|-B|-G|--formato=compatibilidad]
[--ayuda]
[-d|-o|-x|--base=número]
[--comunes]
[-t|--totales]
[--objetivo=nombrebfd] [-V|--version]
[-f]
[archivoobj...]

DESCRIPCIÓN

La utilidad GNU size lista los tamaños de las secciones y el tamaño total para cada uno de los archivos binarios archivoobj en su lista de argumentos. Por defecto, se genera una línea de salida para cada archivo o para cada módulo si el archivo es un archivo.

archivoobj... son los archivos a examinar. Si no se especifica ninguno, se utilizará el archivo "a.out" en su lugar.

OPCIONES

Las opciones de la línea de comandos tienen los siguientes significados:

-A
-B
-G
--formato=compatibilidad
Usando una de estas opciones, puede elegir si la salida de GNU size se asemeja a la salida de System V size (usando -A, o --formato=sysv), o a la de Berkeley size (usando -B, o --formato=berkeley). El valor por defecto es el formato de una línea similar al de Berkeley. Alternativamente, puede elegir la salida con formato GNU (usando -G, o --formato=gnu), que es similar al formato de salida de Berkeley, pero los tamaños se cuentan de manera diferente.

Aquí hay un ejemplo del formato de salida de Berkeley (por defecto) de size:

$ size --formato=Berkeley ranlib size
   text    data     bss     dec     hex filename
 294880   81920   11592  388392   5ed28 ranlib
 294880   81920   11888  388688   5ee50 size

La salida estilo Berkeley cuenta los datos de solo lectura en la columna "text", no en la columna "data"; las columnas "dec" y "hex" muestran la suma de las columnas "text", "data" y "bss" en decimal y hexadecimal respectivamente.

El formato GNU cuenta los datos de solo lectura en la columna "data", no en la columna "text", y solo muestra la suma de las columnas "text", "data" y "bss" una vez, en la columna "total". La opción --base se puede usar para cambiar la base numérica para todas las columnas. Aquí están los mismos datos mostrados con convenciones GNU:

$ size --formato=GNU ranlib size
      text       data        bss      total filename
    279880      96920      11592     388392 ranlib
    279880      96920      11888     388688 size

Estos son los mismos datos, pero mostrados más cerca de las convenciones de System V:

$ size --formato=SysV ranlib size
ranlib  :
section         size         addr
.text         294880         8192
.data          81920       303104
.bss           11592       385024
Total         388392


size  :
section         size         addr
.text         294880         8192
.data          81920       303104
.bss           11888       385024
Total         388688
--ayuda
-h
-H
-?
Muestra un resumen de los argumentos y opciones aceptables.
-d
-o
-x
--base=número
Usando una de estas opciones, puede controlar si el tamaño de cada sección se da en decimal (-d, o --base=10); octal (-o, o --base=8); o hexadecimal (-x, o --base=16). En --base=número, solo se admiten los tres valores (8, 10, 16). El tamaño total siempre se da en dos bases; decimal y hexadecimal para la salida -d o -x, u octal y hexadecimal si está usando -o.
--comunes
Imprime el tamaño total de los símbolos comunes en cada archivo. Al usar el formato Berkeley o GNU, estos se incluyen en el tamaño bss.
-t
--totales
Muestra los totales de todos los objetos listados (solo en modo de formato Berkeley o GNU).
--objetivo=nombrebfd
Especifica que el formato del código objeto para archivoobj es nombrebfd. Esta opción puede no ser necesaria; size puede reconocer automáticamente muchos formatos.
-v
-V
--version
Muestra el número de versión de size.
-f
Ignorada. Esta opción es utilizada por otras versiones del programa size, pero no es compatible con la versión de GNU Binutils.
@archivo
Lee las opciones de la línea de comandos desde archivo. Las opciones leídas se insertan en lugar de la opción @archivo original. Si archivo no existe, o no se puede leer, entonces la opción se tratará literalmente y no se eliminará.

Las opciones en archivo están separadas por espacios en blanco. Se puede incluir un carácter de espacio en blanco en una opción rodeando la opción completa con comillas simples o dobles. Se puede incluir cualquier carácter (incluyendo una barra invertida) prefijando el carácter a incluir con una barra invertida. El archivo puede contener opciones adicionales de @archivo; cualquier opción de este tipo se procesará recursivamente.

riscv64-elf-size(1)

DESCRIPCIÓN

size es una utilidad que se utiliza para listar las secciones de tamaño de los archivos objeto.

El comando size muestra el tamaño de cada sección del archivo objeto especificado y el tamaño total del archivo. Si el archivo objeto es un archivo de biblioteca, size muestra el tamaño de cada archivo objeto dentro de la biblioteca.

size es útil para determinar la cantidad de espacio que ocupa cada sección de un archivo objeto y para identificar posibles optimizaciones.

OPCIONES

size tiene las siguientes opciones:

  • -A, --format=any: Imprime el tamaño de todas las secciones en todos los formatos.
  • -B, --format=berkeley: Imprime el tamaño en formato Berkeley.
  • -d, --format=sysv: Imprime el tamaño en formato System V.
  • -o, --format=objective-c: Imprime el tamaño en formato Objective-C.
  • -x, --format=hex: Imprime el tamaño en formato hexadecimal.
  • --help: Muestra un mensaje de ayuda y sale.
  • --version: Muestra información sobre la versión y sale.

VER TAMBIÉN

objdump(1), readelf(1)
