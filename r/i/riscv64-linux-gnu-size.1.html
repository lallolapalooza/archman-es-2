SIZE(1) Herramientas de Desarrollo GNU SIZE(1)

NOMBRE

size - lista los tamaños de sección y el tamaño total de los archivos binarios

SINOPSIS

size [-A|-B|-G|--formato=compatibilidad]
[--ayuda]
[-d|-o|-x|--base=número]
[--comun]
[-t|--totales]
[--objetivo=nombrebfd] [-V|--version]
[-f]
[archivoobj...]

DESCRIPCIÓN

La utilidad GNU size lista los tamaños de sección y el tamaño total para cada uno de los archivos binarios archivoobj en su lista de argumentos. Por defecto, se genera una línea de salida por cada archivo o por cada módulo si el archivo es un archivo.

archivoobj... son los archivos a examinar. Si no se especifica ninguno, se utilizará el archivo "a.out" en su lugar.

OPCIONES

Las opciones de la línea de comandos tienen los siguientes significados:

-A
-B
-G
--formato=compatibilidad
Usando una de estas opciones, puedes elegir si la salida de GNU size se parece a la salida de System V size (usando -A, o --formato=sysv), o a la de Berkeley size (usando -B, o --formato=berkeley). El valor por defecto es el formato de una línea similar al de Berkeley. Alternativamente, puedes elegir la salida en formato GNU (usando -G, o --formato=gnu), esto es similar al formato de salida de Berkeley, pero los tamaños se cuentan de forma diferente.

Aquí hay un ejemplo del formato de salida de Berkeley (por defecto) de size:

$ size --formato=Berkeley ranlib size
   text    data     bss     dec     hex filename
 294880   81920   11592  388392   5ed28 ranlib
 294880   81920   11888  388688   5ee50 size

La salida estilo Berkeley cuenta los datos de solo lectura en la columna "text", no en la columna "data", las columnas "dec" y "hex" muestran la suma de las columnas "text", "data" y "bss" en decimal y hexadecimal respectivamente.

El formato GNU cuenta los datos de solo lectura en la columna "data", no en la columna "text", y solo muestra la suma de las columnas "text", "data" y "bss" una vez, en la columna "total". La opción --base puede ser utilizada para cambiar la base numérica de todas las columnas. Aquí están los mismos datos mostrados con convenciones GNU:

$ size --formato=GNU ranlib size
      text       data        bss      total filename
    279880      96920      11592     388392 ranlib
    279880      96920      11888     388688 size

Estos son los mismos datos, pero mostrados más cerca de las convenciones de System V:

$ size --formato=SysV ranlib size
ranlib  :
section         size         addr
.text         294880         8192
.data          81920       303104
.bss           11592       385024
Total         388392


size  :
section         size         addr
.text         294880         8192
.data          81920       303104
.bss           11888       385024
Total         388688
--ayuda
-h
-H
-?
Muestra un resumen de los argumentos y opciones aceptables.
-d
-o
-x
--base=número
Usando una de estas opciones, puedes controlar si el tamaño de cada sección se da en decimal (-d, o --base=10); octal (-o, o --base=8); o hexadecimal (-x, o --base=16). En --base=número, solo los tres valores (8, 10, 16) son soportados. El tamaño total siempre se da en dos bases; decimal y hexadecimal para la salida -d o -x, u octal y hexadecimal si estás usando -o.
--comun
Imprime el tamaño total de los símbolos comunes en cada archivo. Cuando se usa el formato Berkeley o GNU estos están incluidos en el tamaño bss.
-t
--totales
Muestra los totales de todos los objetos listados (solo en modo de formato Berkeley o GNU).
--objetivo=nombrebfd
Especifica que el formato del código objeto de archivoobj es nombrebfd. Esta opción puede no ser necesaria; size puede reconocer automáticamente muchos formatos.
-v
-V
--version
Muestra el número de versión de size.
-f
Ignorado. Esta opción es utilizada por otras versiones del programa size, pero no está soportada por la versión de GNU Binutils.
@archivo
Lee las opciones de la línea de comandos desde archivo. Las opciones leídas se insertan en el lugar de la opción @archivo original. Si archivo no existe, o no se puede leer, entonces la opción se tratará literalmente, y no se eliminará.

Las opciones en archivo están separadas por espacios en blanco. Un carácter de espacio en blanco puede incluirse en una opción rodeando la opción completa con comillas simples o dobles. Cualquier carácter (incluyendo una barra invertida) puede incluirse prefijando el carácter a incluir con una barra invertida. El archivo puede contener él mismo opciones adicionales @archivo; cualquier opción de este tipo se procesará recursivamente.

NAME

size - display size information of object files

SYNOPSIS

size [OPTION]... [FILE]...

DESCRIPTION

Print the size of each section, and the total size, of each argument which is a relocatable object file, or executable.

The default output format is:

name              total chand_start chand_end

size is a part of the GNU Binutils package.

The default output format is suitable for shell-script processing. For more human-readable output, use the --format= Berkeley option.

The sections are the segments in the object file that contain code and data. The most common sections are:

  • .text: This section contains the executable code of the program.
  • .data: This section contains initialized data.
  • .bss: This section contains uninitialized data.

The total size is the sum of the sizes of all sections.

OPTIONS

-A, --format=any
Print sizes in any format. This is the default.
-B, --format=berkeley
Print sizes in the Berkeley format. This format is more human-readable than the default format.
-d, --format=sysv
Print sizes in the System V format.
-f, --format=posix
Print sizes in the POSIX format.
-h, --help
Display help about all options.
-l, --format=long
Print sizes in the long format. This format includes the size of each section, as well as the total size.
-O, --format=tradition
Print sizes in the traditional format.
-t, --totals
Display the total size of all object files.
-V, --version
Display the version of size and exit.

EXIT STATUS

The exit status is 0 if the program executed successfully, and non-zero otherwise.

EXAMPLES

To display the size of the executable myprog in the default format:

$ size myprog

To display the size of the executable myprog in the Berkeley format:

$ size --format=berkeley myprog

To display the total size of all executables in the current directory:

$ size *.o --totals
