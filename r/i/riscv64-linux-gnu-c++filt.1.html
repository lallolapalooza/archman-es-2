NOMBRE

c++filt - decodifica símbolos de C++ y Java

SINOPSIS

c++filt [-_|--strip-underscore]
[-n|--no-strip-underscore]
[-p|--no-params]
[-t|--types]
[-i|--no-verbose]
[-r|--no-recurse-limit]
[-R|--recurse-limit]
[-s formato|--format=formato]
[--help] [--version] [simbolo...]

DESCRIPCIÓN

Los lenguajes C++ y Java proporcionan la sobrecarga de funciones, lo que significa que puedes escribir muchas funciones con el mismo nombre, siempre que cada función reciba parámetros de tipos diferentes. Para poder distinguir estas funciones de nombres similares, C++ y Java las codifican en un nombre de ensamblador de bajo nivel que identifica de forma única cada versión diferente. Este proceso se conoce como mangling (o codificación). El programa c++filt [1] realiza la operación inversa: decodifica (demangles) los nombres de bajo nivel a nombres de nivel de usuario para que puedan ser leídos.

Cada palabra alfanumérica (compuesta por letras, dígitos, guiones bajos, signos de dólar o puntos) vista en la entrada es un nombre potencialmente codificado. Si el nombre se decodifica a un nombre de C++, el nombre de C++ reemplaza al nombre de bajo nivel en la salida; de lo contrario, se genera la palabra original. De esta manera, puedes pasar un archivo fuente de ensamblador completo, que contenga nombres codificados, a través de c++filt y ver el mismo archivo fuente con nombres decodificados.

También puedes usar c++filt para descifrar símbolos individuales pasándolos en la línea de comandos:

c++filt <simbolo>

Si no se proporcionan argumentos de simbolo, c++filt lee los nombres de los símbolos de la entrada estándar en su lugar. Todos los resultados se imprimen en la salida estándar. La diferencia entre leer nombres de la línea de comandos y leerlos de la entrada estándar es que se espera que los argumentos de la línea de comandos sean solo nombres codificados y no se realiza ninguna comprobación para separarlos del texto circundante. Por lo tanto, por ejemplo:

c++filt -n _Z1fv

funcionará y decodificará el nombre a "f()", mientras que:

c++filt -n _Z1fv,

no funcionará. (Nota la coma adicional al final del nombre codificado que lo hace inválido). Sin embargo, este comando funcionará:

echo _Z1fv, | c++filt -n

y mostrará "f(),", es decir, el nombre decodificado seguido de una coma final. Este comportamiento se debe a que, cuando los nombres se leen de la entrada estándar, se espera que puedan formar parte de un archivo fuente de ensamblador donde pueda haber caracteres adicionales, extráneos, después de un nombre codificado. Por ejemplo:

.type   _Z1fv, @function

OPCIONES

-_
--strip-underscore
En algunos sistemas, tanto el compilador C como el C++ anteponen un guion bajo a cada nombre. Por ejemplo, el nombre C "foo" recibe el nombre de bajo nivel "_foo". Esta opción elimina el guion bajo inicial. Que c++filt elimine el guion bajo por defecto depende del destino.
-n
--no-strip-underscore
No elimine el guion bajo inicial.
-p
--no-params
Al decodificar el nombre de una función, no muestre los tipos de los parámetros de la función.
-t
--types
Intente decodificar tipos además de nombres de funciones. Esto está desactivado por defecto ya que los tipos codificados normalmente solo se usan internamente en el compilador, y pueden confundirse con nombres no codificados. Por ejemplo, una función llamada "a" tratada como un nombre de tipo codificado se decodificaría como "signed char".
-i
--no-verbose
No incluya detalles de implementación (si los hay) en la salida decodificada.
-r
-R
--recurse-limit
--no-recurse-limit
--recursion-limit
--no-recursion-limit
Habilita o deshabilita un límite en la cantidad de recursión realizada al decodificar cadenas. Dado que los formatos de codificación de nombres permiten un nivel infinito de recursión, es posible crear cadenas cuya decodificación agote el espacio de pila disponible en la máquina host, desencadenando una falla de memoria. El límite intenta evitar que esto suceda restringiendo la recursión a 2048 niveles de anidamiento.

Por defecto, este límite está habilitado, pero deshabilitarlo puede ser necesario para decodificar nombres verdaderamente complicados. Tenga en cuenta, sin embargo, que si el límite de recursión está deshabilitado, es posible agotar la pila y cualquier informe de error sobre tal evento será rechazado.

La opción -r es un sinónimo de la opción --no-recurse-limit. La opción -R es un sinónimo de la opción --recurse-limit.

-s formato
--format=formato
c++filt puede decodificar varios métodos de codificación, utilizados por diferentes compiladores. El argumento de esta opción selecciona qué método utiliza:
"auto"
Selección automática basada en el ejecutable (el método por defecto)
"gnu"
el utilizado por el compilador C++ de GNU (g++)
"lucid"
el utilizado por el compilador Lucid (lcc)
"arm"
el especificado por el C++ Annotated Reference Manual
"hp"
el utilizado por el compilador HP (aCC)
"edg"
el utilizado por el compilador EDG
"gnu-v3"
el utilizado por el compilador C++ de GNU (g++) con la ABI V3.
"java"
el utilizado por el compilador Java de GNU (gcj)
"gnat"
el utilizado por el compilador Ada de GNU (GNAT).
--help
Imprime un resumen de las opciones de c++filt y sale.
--version
Imprime el número de versión de c++filt y sale.
@archivo
Lee las opciones de la línea de comandos desde archivo. Las opciones leídas se insertan en lugar de la opción @archivo original. Si archivo no existe o no se puede leer, la opción se tratará literalmente y no se eliminará.

Las opciones en archivo están separadas por espacios en blanco. Se puede incluir un carácter de espacio en blanco en una opción rodeando la opción completa con comillas simples o dobles. Se puede incluir cualquier carácter (incluido una barra invertida) anteponiendo a ese carácter una barra invertida. El archivo puede contener opciones adicionales @archivo; dichas opciones se procesarán recursivamente.

NOTAS AL PIE

1.
MS-DOS no permite caracteres "+" en los nombres de archivo, por lo que en MS-DOS este programa se llama CXXFILT.

Manual de riscv64-linux-gnu-c++filt(1)

NAME

c++filt - Filtra nombres de símbolos de C++

SYNOPSIS

c++filt [opciones] [nombres]

DESCRIPTION

c++filt es un utilidad que des-manglea (decodifica) nombres de símbolos de C++. Los nombres de símbolos de C++ son generados por el compilador para permitir la sobrecarga de funciones y la especialización de plantillas. Estos nombres son difíciles de leer para los humanos. c++filt los traduce a un formato legible.

Si se proporcionan argumentos en la línea de comandos, se asume que son nombres de símbolos para decodificar. De lo contrario, c++filt leerá los nombres de los símbolos de la entrada estándar, uno por línea.

OPTIONS

Las opciones disponibles son:

-
Lee de la entrada estándar.
-i
Modo interactivo. Lee nombres de símbolos de la entrada estándar y escribe la versión des-mangled a la salida estándar hasta que se encuentre EOF.
--help
Muestra un mensaje de ayuda y sale.
--version
Muestra información sobre la versión y sale.
