NOMBRE

nm - listar símbolos de archivos objeto

SINOPSIS

nm [-A|-o|--print-file-name]
[-a|--debug-syms]
[-B|--format=bsd]
[-C|--demangle[=estilo]]
[-D|--dynamic]
[-fformato|--format=formato]
[-g|--extern-only]
[-h|--help]
[--ifunc-chars=CARACTERES]
[-j|--format=just-symbols]
[-l|--line-numbers] [--inlines]
[-n|-v|--numeric-sort]
[-P|--portability]
[-p|--no-sort]
[-r|--reverse-sort]
[-S|--print-size]
[-s|--print-armap]
[-t base|--radix=base]
[-u|--undefined-only]
[-U|--defined-only]
[-V|--version]
[-W|--no-weak]
[-X 32_64]
[--no-demangle]
[--no-recurse-limit|--recurse-limit]]
[--plugin nombre]
[--size-sort]
[--special-syms]
[--synthetic]
[--target=nombrebfd]
[--unicode=metodo]
[--with-symbol-versions]
[--without-symbol-versions]
[archivoobjeto...]

DESCRIPCIÓN

GNU nm lista los símbolos de los archivos objeto archivoobjeto.... Si no se listan archivos objeto como argumentos, nm asume el archivo a.out.

Para cada símbolo, nm muestra:

  • El valor del símbolo, en la base seleccionada por las opciones (ver abajo), o hexadecimal por defecto.
  • El tipo del símbolo. Al menos los siguientes tipos se utilizan; otros también, dependiendo del formato del archivo objeto. Si es minúscula, el símbolo es usualmente local; si es mayúscula, el símbolo es global (externo). Sin embargo, hay algunos símbolos en minúscula que se muestran para símbolos globales especiales ("u", "v" y "w").
"A"
El valor del símbolo es absoluto y no será cambiado por enlazados posteriores.
"B"
"b"
El símbolo está en la sección de datos BSS. Esta sección típicamente contiene datos inicializados a cero o no inicializados, aunque el comportamiento exacto depende del sistema.
"C"
"c"
El símbolo es común. Los símbolos comunes son datos no inicializados. Al enlazar, pueden aparecer múltiples símbolos comunes con el mismo nombre. Si el símbolo está definido en algún lugar, los símbolos comunes se tratan como referencias indefinidas. El carácter c minúscula se usa cuando el símbolo está en una sección especial para comunes pequeños.
"D"
"d"
El símbolo está en la sección de datos inicializados.
"G"
"g"
El símbolo está en una sección de datos inicializados para objetos pequeños. Algunos formatos de archivo objeto permiten un acceso más eficiente a objetos de datos pequeños, como una variable entera global en lugar de un array global grande.
"i"
Para archivos en formato PE, esto indica que el símbolo está en una sección específica de la implementación de DLLs.

Para archivos en formato ELF, esto indica que el símbolo es una función indirecta. Esta es una extensión de GNU al conjunto estándar de tipos de símbolos ELF. Indica un símbolo que si se referencia mediante una relocalización no se evalúa a su dirección, sino que debe invocarse en tiempo de ejecución. La ejecución en tiempo de ejecución devolverá el valor que se utilizará en la relocalización.

Nota: la visualización real de los símbolos para símbolos indirectos de GNU está controlada por la opción de línea de comandos --ifunc-chars. Si se ha proporcionado esta opción, el primer carácter de la cadena se usará para símbolos de función indirecta globales. Si la cadena contiene un segundo carácter, ese se usará para símbolos de función indirecta locales.

"I"
El símbolo es una referencia indirecta a otro símbolo.
"N"
El símbolo es un símbolo de depuración.
"n"
El símbolo está en una sección de solo lectura no de datos, no de código, no de depuración.
"p"
El símbolo está en una sección de desenrollado de pila.
"R"
"r"
El símbolo está en una sección de datos de solo lectura.
"S"
"s"
El símbolo está en una sección de datos no inicializados o inicializados a cero para objetos pequeños.
"T"
"t"
El símbolo está en la sección de texto (código).
"U"
El símbolo es indefinido.
"u"
El símbolo es un símbolo global único. Esta es una extensión de GNU al conjunto estándar de enlaces de símbolos ELF. Para un símbolo de este tipo, el enlazador dinámico se asegurará de que solo se utilice un símbolo con este nombre y tipo en todo el proceso.
"V"
"v"
El símbolo es un objeto débil. Cuando un símbolo definido débil se enlaza con un símbolo definido normal, se utiliza el símbolo definido normal sin errores. Cuando un símbolo indefinido débil se enlaza y el símbolo no está definido, el valor del símbolo débil se convierte en cero sin errores. En algunos sistemas, las mayúsculas indican que se ha especificado un valor por defecto.
"W"
"w"
El símbolo es un símbolo débil que no ha sido específicamente etiquetado como símbolo de objeto débil. Cuando un símbolo definido débil se enlaza con un símbolo definido normal, se utiliza el símbolo definido normal sin errores. Cuando un símbolo indefinido débil se enlaza y el símbolo no está definido, el valor del símbolo se determina de una manera específica del sistema sin errores. En algunos sistemas, las mayúsculas indican que se ha especificado un valor por defecto.
"-"
El símbolo es un símbolo stabs en un archivo objeto a.out. En este caso, los siguientes valores impresos son el campo 'other' de stabs, el campo 'desc' de stabs y el tipo de stab. Los símbolos stabs se utilizan para almacenar información de depuración.
"?"
El tipo del símbolo es desconocido, o específico del formato del archivo objeto.
•
El nombre del símbolo. Si un símbolo tiene información de versión asociada, entonces se muestra la información de versión. Si el símbolo versionado está indefinido o oculto para el enlazador, la cadena de versión se muestra como un sufijo del nombre del símbolo, precedido por un carácter @. Por ejemplo foo@VER_1. Si la versión es la versión por defecto a usar al resolver referencias no versionadas al símbolo, entonces se muestra como un sufijo precedido por dos caracteres @. Por ejemplo foo@@VER_2.

OPCIONES

Las formas largas y cortas de las opciones, que se muestran aquí como alternativas, son equivalentes.

-A
-o
--print-file-name
Precede cada símbolo con el nombre del archivo de entrada (o miembro del archivo) en el que se encontró, en lugar de identificar el archivo de entrada una sola vez, antes de todos sus símbolos.
-a
--debug-syms
Muestra todos los símbolos, incluso los símbolos solo para depuradores; normalmente estos no se listan.
-B
Lo mismo que --format=bsd (para compatibilidad con el nm de MIPS).
-C
--demangle[=estilo]
Decodifica (demangle) los nombres de símbolos de bajo nivel a nombres de nivel de usuario. Además de eliminar cualquier guion bajo inicial agregado por el sistema, esto hace que los nombres de funciones C++ sean legibles. Diferentes compiladores tienen diferentes estilos de mangling. El argumento opcional de estilo de decodificación puede usarse para elegir un estilo de decodificación apropiado para su compilador.
--no-demangle
No decodificar nombres de símbolos de bajo nivel. Esta es la opción predeterminada.
--no-recurse-limit—--recurse-limit
Permite deshabilitar el límite de recursión para símbolos. El comportamiento predeterminado es habilitar el límite.
-D
--dynamic
Muestra los símbolos de la tabla de símbolos dinámicos en lugar de los de la tabla de símbolos normal. Solo los archivos ELF tienen tablas de símbolos dinámicos.

<="permalink" href="#recurse">--recurse-limit
--no-recurse-limit
--recursion-limit
--no-recursion-limit
Habilita o deshabilita un límite en la cantidad de recursión realizada mientras se decodifican cadenas. Dado que los formatos de codificación de nombres permiten un nivel infinito de recursión, es posible crear cadenas cuya decodificación agote el espacio de pila disponible en la máquina host, provocando un fallo de memoria. El límite intenta evitar que esto suceda restringiendo la recursión a 2048 niveles de anidamiento.

Por defecto, este límite está habilitado, pero puede ser necesario deshabilitarlo para decodificar nombres verdaderamente complicados. Tenga en cuenta, sin embargo, que si el límite de recursión está deshabilitado, es posible el agotamiento de la pila y se rechazarán los informes de errores sobre tal evento.

-D
--dynamic
Muestra los símbolos dinámicos en lugar de los símbolos normales. Esto solo es significativo para objetos dinámicos, como ciertos tipos de bibliotecas compartidas.
-f formato
--format=formato
Utiliza el formato de salida formato, que puede ser "bsd", "sysv", "posix" o "just-symbols". El valor predeterminado es "bsd". Solo el primer carácter del formato es significativo; puede ser mayúscula o minúscula.
-g
--extern-only
Muestra solo símbolos externos.
-h
--help
Muestra un resumen de las opciones de nm y sale.
--ifunc-chars=CARACTERES
Al mostrar símbolos de función indirecta de GNU, nm utilizará por defecto el carácter "i" tanto para las funciones indirectas locales como para las funciones indirectas globales. La opción --ifunc-chars permite al usuario especificar una cadena que contenga uno o dos caracteres. El primer carácter se utilizará para los símbolos de función indirecta global y el segundo carácter, si está presente, se utilizará para los símbolos de función indirecta local.
j
Lo mismo que --format=just-symbols.
-l
--line-numbers
Para cada símbolo, utiliza la información de depuración para intentar encontrar un nombre de archivo y número de línea. Para un símbolo definido, busca el número de línea de la dirección del símbolo. Para un símbolo indefinido, busca el número de línea de una entrada de reubicación que hace referencia al símbolo. Si se puede encontrar información del número de línea, imprímela después de la otra información del símbolo.
--inlines
Cuando la opción -l está activa, si la dirección pertenece a una función que fue insertada, esta opción provoca que también se imprima la información de origen de todos los ámbitos contenedores hasta la primera función no insertada. Por ejemplo, si "main" inserta "callee1" que inserta "callee2", y la dirección es de "callee2", también se imprimirá la información de origen de "callee1" y "main".
-n
-v
--numeric-sort
Ordena los símbolos numéricamente por sus direcciones, en lugar de alfabéticamente por sus nombres.
-p
--no-sort
No se moleste en ordenar los símbolos en ningún orden; imprímalos en el orden en que se encuentran.
-P
--portability
Utiliza el formato de salida estándar POSIX.2 en lugar del formato predeterminado. Equivalente a -f posix.
-r
--reverse-sort
Invierte el orden de la ordenación (ya sea numérica o alfabética); deja que el último venga primero.
-S
--print-size
Imprime tanto el valor como el tamaño de los símbolos definidos para el estilo de salida "bsd". Esta opción no tiene efecto para formatos de objeto que no registran tamaños de símbolos, a menos que también se utilice --size-sort, en cuyo caso se mostrará un tamaño calculado.
-s
--print-armap
Al listar símbolos de miembros de archivos, incluye el índice: un mapa (almacenado en el archivo por ar o ranlib) de qué módulos contienen definiciones para qué nombres.
-t base
--radix=base
Utiliza base como la base para imprimir los valores de los símbolos. Debe ser d para decimal, o para octal, o x para hexadecimal.
-u
--undefined-only
Muestra solo símbolos indefinidos (aquellos externos a cada archivo objeto). Por defecto se muestran ambos símbolos, definidos e indefinidos.
-U
--defined-only
Muestra solo símbolos definidos para cada archivo objeto. Por defecto se muestran ambos símbolos, definidos e indefinidos.
-V
--version
Muestra el número de versión de nm y sale.
-X
Esta opción se ignora por compatibilidad con la versión AIX de nm. Toma un parámetro que debe ser la cadena 32_64. El modo predeterminado de nm de AIX corresponde a -X 32, que no es compatible con el nm de GNU.
--plugin nombre
Carga el plugin llamado nombre para agregar soporte para tipos de destino adicionales. Esta opción solo está disponible si la cadena de herramientas se compiló con soporte de plugins habilitado.

Si no se proporciona --plugin, pero el soporte de plugins ha sido habilitado, entonces nm itera sobre los archivos en ${libdir}/bfd-plugins en orden alfabético y se utiliza el primer plugin que reclama el objeto en cuestión.

Tenga en cuenta que este directorio de búsqueda de plugins no es el utilizado por la opción -plugin de ld. Para hacer que nm utilice el plugin del enlazador, debe copiarse en el directorio ${libdir}/bfd-plugins. Para compilaciones basadas en GCC, el plugin del enlazador se llama liblto_plugin.so.0.0.0. Para compilaciones basadas en Clang, se llama LLVMgold.so. El plugin de GCC siempre es compatible con versiones anteriores, por lo que es suficiente copiar el más reciente.

--size-sort
Ordena los símbolos por tamaño. Para objetos ELF, los tamaños de los símbolos se leen de ELF, para otros tipos de objetos, los tamaños de los símbolos se calculan como la diferencia entre el valor del símbolo y el valor del símbolo con el siguiente valor superior. Si se utiliza el formato de salida "bsd", se imprimirá el tamaño del símbolo, en lugar del valor, y se debe usar -S para poder imprimir tanto el tamaño como el valor.

Nota: esta opción no funciona si se ha habilitado --undefined-only, ya que los símbolos indefinidos no tienen tamaño.

--special-syms
Muestra símbolos que tienen un significado especial específico del destino. Estos símbolos suelen ser utilizados por el destino para algún procesamiento especial y normalmente no son útiles cuando se incluyen en las listas de símbolos normales. Por ejemplo, para los destinos ARM, esta opción omitiría los símbolos de mapeo utilizados para marcar las transiciones entre el código ARM, el código THUMB y los datos.
--synthetic
Incluye símbolos sintéticos en la salida. Estos son símbolos especiales creados por el enlazador para diversos fines. No se muestran por defecto ya que no forman parte del código fuente original del binario.
--unicode=[default|invalid|locale|escape|hex|highlight]
Controla la visualización de caracteres multibyte codificados en UTF-8 en cadenas. El valor predeterminado (--unicode=default) es no darles ningún tratamiento especial. La opción --unicode=locale muestra la secuencia en la configuración regional actual, que puede o no admitirlos. Las opciones --unicode=hex y --unicode=invalid las muestran como secuencias de bytes hexadecimales encerradas entre corchetes angulares o llaves.

La opción --unicode=escape las muestra como secuencias de escape (\uxxxx) y la opción --unicode=highlight las muestra como secuencias de escape resaltadas en rojo (si el dispositivo de salida lo admite). El coloreado está destinado a llamar la atención sobre la presencia de secuencias unicode donde podrían no esperarse.

-W
--no-weak
No muestra símbolos débiles.
--with-symbol-versions
--without-symbol-versions
Habilita o deshabilita la visualización de información de versiones de símbolos. La cadena de versión se muestra como un sufijo del nombre del símbolo, precedido por un carácter @. Por ejemplo

NOMBRE

nm – listar símbolos de archivos objeto

SINOPSIS

nm [OPTION]... [FILE]...

DESCRIPCIÓN

Listar los símbolos del archivo FILE, o de los archivos especificados en la línea de comandos. Los símbolos son las variables y funciones que se encuentran en los archivos objeto.

Por defecto, nm muestra la lista de símbolos ordenada alfabéticamente.

La salida estándar de nm para cada símbolo consiste en tres campos:

  1. El valor del símbolo en hexadecimal. Si el valor es desconocido, se imprime un guion (-).
  2. El tipo de símbolo. El tipo se imprime como un carácter. Las letras mayúsculas indican un símbolo del código o los datos del archivo objeto. Las letras minúsculas indican un símbolo de depuración. Si el tipo es desconocido, se imprime un signo de interrogación (?). Las letras que pueden aparecer como tipos de símbolo son:
    a
    Sección de datos asignada.
    b
    Sección bss.
    d
    Sección de datos.
    D
    Sección de datos de tamaño de archivo compartido.
    i
    Símbolo de importación.
    l
    Sección de texto enlazada.
    n
    Valor numérico.
    p
    Sección de sección de propósito especial.
    r
    Sección de sólo lectura de datos.
    t
    Sección de texto.
    T
    Sección de texto de tamaño de archivo compartido.
    u
    Símbolo no definido.
    w
    Símbolo débil.
    W
    Símbolo débil.
    s
    Símbolo privado de depuración.
    S
    Símbolo de depuración.
    v
    Símbolo de variable.
    0
    Símbolo de la sección .eh_frame.
  3. El nombre del símbolo.

Los símbolos con la versión predeterminada que se utilizará al resolver referencias sin versión al símbolo se muestran como un sufijo precedido de dos caracteres @. Por ejemplo, foo@VER_2. Por defecto, la información de versión del símbolo se muestra.

OPCIONES

-a, --all
Imprime todos los símbolos, incluidos los símbolos de depuración, que normalmente se omiten.
-g, --debugging
No imprima los símbolos de depuración que normalmente se imprimen.
-h, --help
Mostrar un mensaje de ayuda y salir.
-l, --dynamic
Listar los símbolos dinámicos en lugar de los símbolos normales.
-S
Imprimir sólo los símbolos que empiezan por el prefijo especificado.
-t, --format=fmt
Usar el formato especificado por fmt.
-u, --undefined-only
Imprimir sólo los símbolos indefinidos, que son aquellos que se referencian pero no se definen en los archivos dados.
-V, --version
Mostrar la información de la versión de nm y salir.
--target=bfdname
Especificar un formato de código objeto distinto del formato predeterminado de su sistema.
@file
Leer las opciones de la línea de comandos desde file. Las opciones leídas se insertan en lugar de la opción original @file. Si file no existe o no se puede leer, la opción se tratará literalmente y no se eliminará.
Las opciones en file están separadas por espacios en blanco. Un carácter de espacio en blanco puede incluirse en una opción rodeando la opción completa con comillas simples o dobles. Cualquier carácter (incluido una barra invertida) puede incluirse prefijando el carácter a incluir con una barra invertida. El file puede contener opciones adicionales de @file; dichas opciones se procesarán recursivamente.
