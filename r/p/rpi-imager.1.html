NOMBRE

rpi-imager - Escribe imágenes de disco en almacenamiento extraíble

SINOPSIS

rpi-imager [--debug] [--repo url] [--qm traducciones] [--disable-telemetry] [uri-imagen]
rpi-imager --cli [--debug] [--quiet] [--disable-verify] [--sha256 hash-esperado] uri-imagen dispositivo-destino
rpi-imager --version
rpi-imager --help

DESCRIPCIÓN

rpi-imager es una utilidad para escribir un archivo de imagen de disco, que opcionalmente puede estar comprimido, en un disco de destino extraíble, como una tarjeta micro-SD o una unidad SSD conectada por USB.

Cuando se ejecuta sin argumentos adicionales en la línea de comandos, la utilidad presenta una interfaz gráfica simple con controles para la selección del archivo de imagen, la selección de la unidad de destino y una para iniciar la escritura. En este modo, el servidor de Raspberry Pi (y potencialmente servidores de terceros) serán consultados para obtener las imágenes de SO disponibles. También puedes especificar una uri-imagen (que puede ser un archivo local o una URL HTTP o HTTPS) para escribir directamente desde la línea de comandos.

Cuando se ejecuta con el argumento --cli, la utilidad escribe directamente la uri-imagen dada en el dispositivo-destino especificado. En este caso, la opción --sha256 se puede usar para pasar la suma de verificación SHA256 esperada de la imagen.

OPCIONES

--cli
No iniciar la interfaz gráfica; solo escribir la imagen dada en la unidad especificada. En este modo, tanto uri-imagen como dispositivo-destino deben especificarse.
--debug
Salida de información de depuración adicional en la consola.
--disable-telemetry
No reportar escrituras de SO a http://rpi-imager-stats.raspberrypi.com/
--disable-verify
Después de escribir la imagen, no intentar verificar que la imagen se escribió correctamente. Solo válido cuando se ejecuta con --cli.
--help
Mostrar una sinopsis de la sintaxis de la línea de comandos y salir.
--quiet
Suprimir toda la salida de la consola. Solo válido cuando se ejecuta con --cli.
--qm traducciones
Especificar un archivo de traducciones de mensajes Qt alternativo para usar con la GUI.
--repo url
En lugar de consultar los servidores de Raspberry Pi para obtener la lista de imágenes de SO disponibles, consultar esta URL en su lugar. Se espera que la URL devuelva un archivo JSON que se ajuste al formato descrito en el json-schema asociado.
--sha256 hash-esperado
Verificar que la imagen coincide con el hash-esperado antes de escribirla en el destino especificado. Solo válido cuando se ejecuta con --cli.
--version
Reportar la versión de la utilidad y la URI predeterminada que intentará consultar para determinar las imágenes de SO disponibles.
uri-imagen
Si se especifica, la URI de la imagen a escribir en el destino. Puede ser un archivo local o una URL remota que admita los protocolos HTTP o HTTPS. Esto debe especificarse cuando se usa --cli.
dispositivo-destino
El dispositivo al que se escribirá la imagen especificada, por ejemplo, /dev/mmcblk0. Solo válido cuando se ejecuta con --cli.

EJEMPLOS

rpi-imager
Iniciar la interfaz gráfica.
rpi-imager --repo http://localhost:8080/os_list_utility.json
Probar una versión alojada localmente de la lista de SO con la interfaz gráfica.
rpi-imager --cli --disable-verify test.img /dev/mmcblk0
Escribir test.img en /dev/mmcblk0 sin ninguna verificación de la imagen en sí, y sin comprobar si la imagen se escribió correctamente. Esto también evita iniciar la interfaz gráfica.
