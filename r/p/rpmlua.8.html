NOMBRE

rpmlua - Intérprete Lua de RPM

SINOPSIS

rpmlua [{-e|--execute} “SENTENCIA”] [{-i|--interactive}] [ARCHIVO_SCRIPT] [arg1 ...]

DESCRIPCIÓN

Ejecuta el intérprete interno Lua de RPM.

Nota: los índices comienzan en 1 en Lua, por lo que el nombre del programa está en arg[1] en lugar del más habitual índice cero.

-i|--interactive
Ejecuta una sesión interactiva después de ejecutar un script o sentencia opcional.
–opts=CADENA_OPCIONES
Realiza el procesamiento de opciones de getopt(3) en los argumentos pasados de acuerdo con CADENA_OPCIONES.
-e|--execute
Ejecuta una sentencia Lua antes de ejecutar un script opcional.

EJEMPLOS

Ejecutar el archivo de script test.lua:

rpmlua test.lua

Ejecutar el archivo de script args.lua con procesamiento de opciones:

rpmlua –opts=ab:c args.lua – 1 2 3 -c -b5

Ejecutar una única sentencia para comparar versiones de rpm:

rpmlua -e “print(rpm.ver(`1.0') < rpm.ver(`2.0'))”

Ejecutar una sesión interactiva:

rpmlua -i

VER TAMBIÉN

lua(1), popt(3), getopt(3), rpm(8)
