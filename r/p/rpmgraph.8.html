NOMBRE

rpmgraph - Mostrar gráfico de dependencias de paquetes RPM

SINOPSIS

rpmgraph ARCHIVO_PAQUETE ...

DESCRIPCIÓN

rpmgraph utiliza los argumentos ARCHIVO_PAQUETE para generar un gráfico de dependencias de paquetes. Cada argumento ARCHIVO_PAQUETE se lee y se añade a un conjunto de transacciones de rpm(8). Los elementos del conjunto de transacciones se ordenan parcialmente utilizando un ordenamiento topológico. Los elementos ordenados parcialmente se imprimen en la salida estándar.

Los nodos del gráfico de dependencias son nombres de paquetes, y los bordes del gráfico dirigido apuntan al padre de cada nodo. El nodo padre se define como el último predecesor de un paquete cuando se ordena parcialmente utilizando las dependencias del paquete como una relación. Esto significa que el padre de un paquete dado es el último prerrequisito del paquete.

La salida está en formato de gráfico dirigido dot(1), y puede ser visualizada o impresa utilizando el editor de gráficos dotty del paquete graphviz. No hay opciones específicas de rpmgraph, solo opciones comunes de rpm. Consulte el mensaje de uso de rpmgraph para ver lo que está implementado actualmente.

VER TAMBIÉN

dot(1), dotty(1)
