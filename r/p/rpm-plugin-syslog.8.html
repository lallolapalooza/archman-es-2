NOMBRE

rpm-plugin-syslog - Plugin de Syslog para el Gestor de Paquetes RPM

DESCRIPCIÓN

El plugin escribe información básica sobre las transacciones de rpm(8) en el syslog, como las transacciones ejecutadas y los paquetes instalados o eliminados.

CONFIGURACIÓN

Actualmente no hay opciones específicas para este plugin. Consulte rpm-plugins(8) sobre cómo controlar los plugins en general.

VER TAMBIÉN

rpm(8), rpm-plugins(8)
