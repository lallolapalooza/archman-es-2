rpcctl(8) Manual del Administrador del Sistema rpcctl(8)

NOMBRE

rpcctl - Muestra información de conexión SunRPC

SINOPSIS

rpcctl [ -h | --help ] { client | switch | xprt }
rpcctl client [ -h | --help ] { show }
rpcctl client show [ -h  --help ] [ XPRT ]
rpcctl switch [ -h | --help ] { set | show }
rpcctl switch add-xprt [ -h | --help ] [ SWITCH ]
rpcctl switch set [ -h | --help ] SWITCH dstaddr NUEVA_DIRECCION
rpcctl switch show [ -h | --help ] [ SWITCH ]
rpcctl xprt [ -h | --help ] { remove | set | show }
rpcctl xprt remove [ -h | --help ] XPRT
rpcctl xprt set [ -h | --help ] XPRT { dstaddr NUEVA_DIRECCION | offline | online }
rpcctl xprt show [ -h | --help ] [ XPRT ]

DESCRIPCIÓN

El comando rpcctl muestra información recopilada en los archivos sysfs de SunRPC sobre los objetos SunRPC del sistema.

rpcctl cliente - Comandos que operan sobre clientes RPC

show [ CLIENTE ] (predeterminado)
Muestra información detallada sobre los clientes RPC en este sistema. Si se proporcionó CLIENTE, entonces solo muestra información sobre un único cliente RPC.

rpcctl switch - Comandos que operan sobre grupos de transportes

add-xprt SWITCH
Añade un transporte adicional al SWITCH. Ten en cuenta que el nuevo transporte tomará sus valores del transporte "principal".
set SWITCH dstaddr NUEVA_DIRECCION
Cambia la dirección de destino de todos los transportes en el SWITCH a NUEVA_DIRECCION. NUEVA_DIRECCION puede ser una dirección IP, un nombre DNS, o cualquier otra cosa resoluble por gethostbyname(3).
show [ SWITCH ] (predeterminado)
Muestra información detallada sobre los grupos de transportes en este sistema. Si se proporcionó SWITCH, entonces solo muestra información sobre un único grupo de transportes.

rpcctl xprt - Comandos que operan sobre transportes individuales

remove XPRT
Elimina el XPRT especificado del sistema. Ten en cuenta que los transportes "principales" no pueden ser eliminados.
set XPRT dstaddr NUEVA_DIRECCION
Cambia la dirección de destino del XPRT especificado a NUEVA_DIRECCION. NUEVA_DIRECCION puede ser una dirección IP, un nombre DNS, o cualquier otra cosa resoluble por gethostbyname(3).
set XPRT offline
Establece el estado del XPRT especificado a desconectado.
set XPRT online
Establece el estado del XPRT especificado a conectado.
show [ XPRT ] (predeterminado)
Muestra información detallada sobre los transportes de este sistema. Si se proporcionó XPRT, entonces solo muestra información sobre un único transporte.

EJEMPLOS

rpcctl switch show switch-2
Muestra detalles sobre el switch RPC llamado "switch-2".
rpcctl xprt remove xprt-4
Elimina el xprt llamado "xprt-4" del sistema.
rpcctl xprt set xprt-3 dstaddr https://linux-nfs.org
Cambia el dstaddr del xprt llamado "xprt-3" para que apunte a linux-nfs.org.
