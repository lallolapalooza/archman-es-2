NOMBRE

rpmdb2solv - convierte la base de datos de rpm en un archivo solv

SINOPSIS

rpmdb2solv [OPCIONES] [REFFILE.solv]

DESCRIPCIÓN

La herramienta rpmdb2solv lee la base de datos de paquetes instalados de rpm y la escribe en formato de archivo solv a la salida estándar. Puede hacer uso de una versión antigua de la base de datos especificando un archivo REFFILE.solv.

-o ARCHIVO_SALIDA

Escribe el solv generado en ARCHIVO_SALIDA en lugar de la salida estándar.

-P

Muestra porcentajes a medida que se leen los paquetes. El formato de salida es como la opción --percent de rpm.

-r DIRECTORIO_RAIZ

Usa DIRECTORIO_RAIZ como directorio raíz.

-D RUTA_DB

Usa la base de datos en el directorio RUTA_DB.

-k

Lee las claves públicas de la base de datos de rpm en lugar de los paquetes instalados. Tenga en cuenta que muchas distribuciones dejaron de almacenar claves públicas en la base de datos y utilizan un directorio como /var/lib/rpm/pubkeys en su lugar.

-A

También escanea /usr/share/appdata en busca de archivos de appdata instalados y crea pseudo-paquetes para cada archivo.

-p DIRECTORIO_PROD

También lee archivos de producto SUSE del directorio DIRECTORIO_PROD. El directorio estándar es /etc/products.d.

-n

No lee ningún paquete de la base de datos de rpm. Esto es útil junto con -p para convertir solo productos SUSE.

-C

Incluye el registro de cambios del paquete en el archivo solv generado.

-X

Expande automáticamente los patrones SUSE y los productos que proporcionan en paquetes.
