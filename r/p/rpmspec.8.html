NOMBRE

rpmspec - Herramienta de especificaciones RPM

SINOPSIS

CONSULTANDO ARCHIVOS SPEC

rpmspec {-q|--query} [select-options] [query-options] ARCHIVO_ESPEC ...

ANALIZANDO ARCHIVOS SPEC A SALIDA ESTÁNDAR

rpmspec {-P|--parse} ARCHIVO_ESPEC ...

INVOCANDO EL SHELL DE MACROS

rpmspec {–shell} [ARCHIVO_ESPEC ...]

DESCRIPCIÓN

rpmspec es una herramienta para consultar un archivo spec. Más específicamente, para consultar paquetes hipotéticos que se crearían a partir del archivo spec dado. Por lo tanto, consultar un archivo spec con rpmspec es similar a consultar un paquete construido a partir de ese archivo spec. Pero no es idéntico. Con rpmspec no se pueden consultar todos los campos que se pueden consultar de un paquete construido. Por ejemplo, no se puede consultar BUILDTIME con rpmspec por razones obvias. Tampoco se pueden consultar otros campos generados automáticamente durante la construcción de un paquete, como las dependencias generadas automáticamente.

select-options

[--rpms] [--srpm]

query-options

[--qf,--queryformat FORMATO_CONSULTA] [--target PLATAFORMA_DESTINO]

OPCIONES DE CONSULTA

La forma general de un comando de consulta de especificaciones rpm es

rpm {-q|--query} [select-options] [query-options]

Puede especificar el formato en el que se debe imprimir la información. Para ello, utilice la opción

--qf|--queryformat FORMATO_CONSULTA

seguida de la cadena de formato FORMATO_CONSULTA. Consulte rpm(8) para obtener más detalles.

OPCIONES SELECT

--rpms
Operar sobre todas las cabeceras de paquetes binarios generados a partir de la especificación.
--builtrpms
Operar solo sobre las cabeceras de paquetes binarios de los paquetes que se construirían a partir de la especificación. Esto significa ignorar las cabeceras de paquetes de paquetes que no se construirán a partir de la especificación, es decir, ignorar las cabeceras de paquetes sin sección de archivos.
--srpm
Operar sobre la(s) cabecera(s) del paquete fuente generado(s) a partir de la especificación.

EJEMPLOS

Obtener la lista de paquetes binarios que se generarían a partir del archivo spec de rpm:

 $ rpmspec -q rpm.spec
 rpm-4.11.3-3.fc20.x86_64
 rpm-libs-4.11.3-3.fc20.x86_64
 rpm-build-libs-4.11.3-3.fc20.x86_64
 ...

Obtener información resumida para paquetes binarios individuales generados a partir del archivo spec de rpm:

 $ rpmspec -q --qf "%{nombre}: %{resumen}\n" rpm.spec
 rpm: El sistema de gestión de paquetes RPM
 rpm-libs: Bibliotecas para manipular paquetes RPM
 rpm-build-libs: Bibliotecas para construir y firmar paquetes RPM
 ...

Obtener el paquete fuente que se generaría a partir del archivo spec de rpm:

 $ rpmspec -q --srpm rpm.spec
 rpm-4.11.3-3.fc20.x86_64

Analizar el archivo spec de rpm a la salida estándar:

 $ rpmspec -P rpm.spec
 Resumen: El sistema de gestión de paquetes RPM
 Nombre: rpm
 Versión: 4.14.0
 ...

Ejecutar un shell de macros interactivo para depurar macros:

 $ rpmspec --shell
 > %define foo bar
 > %foo
 bar
 > %(date)
 Mar 13 15:55:37 EEST 2021
 > %getncpus
 8

Ejecutar un shell de macros interactivo en contexto spec:

 $ rpmspec --shell popt.spec
 %name
 popt
 %version
 1.18
