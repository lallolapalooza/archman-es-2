NOMBRE

rpm-plugins - Plugins para el Gestor de Paquetes RPM

DESCRIPCIÓN

Los plugins de RPM proporcionan funcionalidad que no es adecuada para ser utilizada en todas partes. Es posible que no se compilen o envíen en algunas plataformas o que no se instalen o estén deshabilitados en algunos sistemas.

Esto permite que los plugins interactúen con sistemas que pueden no ser aceptables como dependencia para RPM y proporcionar funcionalidad que puede ser no deseada en algunas circunstancias.

Por ahora, la API de plugins es interna. Por lo tanto, hay un número limitado de plugins en las fuentes de RPM.

CONFIGURACIÓN

Algunos plugins pueden configurarse mediante macros específicas o influenciarse por parámetros de línea de comandos. Pero la mayoría solo se puede activar o desactivar. Consulte la página del manual del plugin para obtener detalles.

Los plugins se controlan mediante una macro %__transaction_NAME que se establece en la ubicación del archivo del plugin. Anular la definición de la macro o establecerla en %{nil} evitará que se ejecute el plugin.

Esto se puede hacer en la línea de comandos de RPM, por ejemplo, con --undefine=__transaction_syslog. Para deshabilitar un plugin permanentemente, elimine un archivo en /etc/rpm/ que contenga

__transaction_NAME %{nil}

Otra opción es eliminar el plugin del sistema si está empaquetado en su propio subpaquete.

Para algunas operaciones, puede ser deseable deshabilitar todos los plugins a la vez. Esto se puede hacer pasando --noplugins a rpm(8) en la línea de comandos.
