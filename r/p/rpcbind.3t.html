NOMBRE

rpcb_getmaps, rpcb_getaddr, rpcb_gettime, rpcb_rmtcall, rpcb_set, rpcb_unset — rutinas de biblioteca para el servicio de enlace RPC

SINOPSIS

#include <rpc/rpc.h>

rpcblist *
rpcb_getmaps(const struct netconfig *netconf, const char *host);

bool_t
rpcb_getaddr(const rpcprog_t prognum, const rpcvers_t versnum, const struct netconfig *netconf, struct netbuf *svcaddr, const char *host);

bool_t
rpcb_gettime(const char *host, time_t * timep);

enum clnt_stat
rpcb_rmtcall(const struct netconfig *netconf, const char *host, const rpcprog_t prognum, const rpcvers_t versnum, const rpcproc_t procnum, const xdrproc_t inproc, const caddr_t in, const xdrproc_t outproc, const caddr_t out, const struct timeval tout, const struct netbuf *svcaddr);

bool_t
rpcb_set(const rpcprog_t prognum, const rpcvers_t versnum, const struct netconfig *netconf, const struct netbuf *svcaddr);

bool_t
rpcb_unset(const rpcprog_t prognum, const rpcvers_t versnum, const struct netconfig *netconf);

DESCRIPCIÓN

Estas rutinas permiten a los programas C cliente realizar llamadas a procedimientos al servicio de enlace RPC. (ver rpcbind(8)) mantiene una lista de mapeos entre programas y sus direcciones universales.

RUTINAS

rpcb_getmaps()
Una interfaz al servicio rpcbind, que devuelve una lista de los mapeos actuales de programa-a-dirección RPC en host. Utiliza el transporte especificado a través de netconf para contactar al servicio rpcbind remoto en host. Esta rutina devolverá NULL si no se pudo contactar al rpcbind remoto.
rpcb_getaddr()
Una interfaz al servicio rpcbind, que encuentra la dirección del servicio en host que está registrado con el número de programa prognum, versión versnum, y habla el protocolo de transporte asociado con netconf. La dirección encontrada se devuelve en svcaddr. El argumento svcaddr debe estar preasignado. Esta rutina devuelve TRUE si tiene éxito. Un valor de retorno de FALSE significa que el mapeo no existe o que el sistema RPC no pudo contactar al servicio rpcbind remoto. En este último caso, la variable global rpc_createerr (ver rpc_clnt_create(3)) contiene el estado RPC.
rpcb_gettime()
Esta rutina devuelve la hora en host en timep. Si host es NULL, rpcb_gettime() devuelve la hora en su propia máquina. Esta rutina devuelve TRUE si tiene éxito, FALSE si falla. La función rpcb_gettime() puede usarse para sincronizar la hora entre el cliente y el servidor remoto.
rpcb_rmtcall()
Una interfaz al servicio rpcbind, que instruye a rpcbind en host para que realice una llamada RPC en tu nombre a un procedimiento en ese host. La estructura netconfig() debe corresponder a un transporte sin conexión. El argumento svcaddr se modificará a la dirección del servidor si el procedimiento tiene éxito (ver rpc_call() y clnt_call() en rpc_clnt_calls(3) para las definiciones de otros argumentos).

Este procedimiento normalmente debe usarse para un "ping" y nada más. Esta rutina permite a los programas hacer búsqueda y llamada, todo en un solo paso.

Nota: Incluso si el servidor no se está ejecutando, rpcb_rmtcall() no devuelve ningún mensaje de error al llamador. En tal caso, el llamador experimenta un timeout.

Nota: rpcb_rmtcall() solo está disponible para transportes sin conexión.

rpcb_set()
Una interfaz al servicio rpcbind, que establece un mapeo entre la tripleta [prognum, versnum, netconf->nc_netid] y svcaddr en el servicio rpcbind de la máquina. El valor de nc_netid debe corresponder a un identificador de red definido por la base de datos netconfig. Esta rutina devuelve TRUE si tiene éxito, FALSE en caso contrario. (Ver también svc_reg() en rpc_svc_calls(3).) Si ya existe una entrada similar en rpcbind, rpcb_set() fallará.
rpcb_unset()
Una interfaz al servicio rpcbind, que destruye el mapeo entre la tripleta [prognum, versnum, netconf->nc_netid] y la dirección en el servicio rpcbind de la máquina. Si netconf es NULL, rpcb_unset() destruye todos los mapeos entre la tripleta [prognum, versnum, todos-los-transportes] y las direcciones en el servicio rpcbind de la máquina. Esta rutina devuelve TRUE si tiene éxito, FALSE en caso contrario. Solo el propietario del servicio o el superusuario pueden destruir el mapeo. (Ver también svc_unreg() en rpc_svc_calls(3).)
