RPC_GSS_SET_CALLBACK(3) Manual de funciones de la biblioteca RPC_GSS_SET_CALLBACK(3)

NOMBRE

rpc_gss_set_callback — Registrar una función de devolución de llamada para la creación de contexto de seguridad

SINOPSIS

#include <rpc/rpcsec_gss.h>

bool_t
(*callback)(struct svc_req *req, gss_cred_id_t deleg, gss_ctx_id_t gss_context, rpc_gss_lock_t *lock, void **cookie);

bool_t
rpc_gss_set_callback(rpc_gss_callback_t *cb);

DESCRIPCIÓN

Registra una función que se llamará cuando se creen nuevos contextos de seguridad en un servidor. Esta función se llamará en la primera solicitud RPC que utilice ese contexto y tendrá la oportunidad de rechazar la solicitud (por ejemplo, después de hacer coincidir las credenciales de la solicitud con una lista de control de acceso). Para aceptar el nuevo contexto de seguridad, la función de devolución de llamada debe devolver TRUE, de lo contrario FALSE. Si la función de devolución de llamada acepta un contexto, se responsabiliza de la vida útil de las credenciales delegadas del cliente (si las hay).

También es posible 'bloquear' los valores de servicio y calidad de protección utilizados por el contexto. Si un contexto está bloqueado, cualquier solicitud posterior que utilice valores diferentes para el servicio y la calidad de protección será rechazada.

PARÁMETROS

cb
Una estructura que contiene el programa RPC y la versión para esta función de devolución de llamada y una función que se llamará cuando se creen nuevos contextos para el programa y la versión RPC dados.
req
La solicitud RPC que utiliza el nuevo contexto.
deleg
Credenciales delegadas GSS-API (si las hay).
gss_context
El contexto GSS-API.
lock
Una estructura utilizada para imponer una QOP y un servicio particulares. Establezca lock->locked a TRUE para bloquear los valores de servicio y QOP.
cookie
La función de devolución de llamada puede establecer *cookie a cualquier valor de tamaño de puntero. Este valor se puede acceder durante la vida útil del contexto a través de rpc_gss_getcred().

VALORES DE RETORNO

Devuelve TRUE si la función de devolución de llamada se registró correctamente o FALSE en caso contrario.

DISPONIBILIDAD

La función rpc_gss_set_callback() es parte de libtirpc.

VER TAMBIÉN

rpc(3), gssapi(3), rpc_gss_getcred(3) rpcsec_gss(3)

ERRORES

No existe un mecanismo para informar a un servidor cuando se ha eliminado un contexto de seguridad. Esto dificulta la asignación de recursos (por ejemplo, para devolverlos a través del argumento cookie de la función de devolución de llamada).
