NOMBRE

rpm-plugin-unshare - Plugin de unshare para el Gestor de Paquetes RPM

DESCRIPCIÓN

Este plugin permite usar varias tecnologías relacionadas con espacios de nombres específicas de Linux dentro de transacciones, como para endurecer y limitar el acceso de los scriptlets a los recursos.

CONFIGURACIÓN

Este plugin implementa las siguientes configurables:

%__transaction_unshare_paths
Una lista separada por dos puntos de rutas para montar privadamente durante la ejecución de scriptlets. Ejemplos típicos serían /tmp para proteger contra el uso inseguro de archivos temporales dentro de los scriptlets, y /home para evitar que los scriptlets accedan a los directorios personales de los usuarios. Cuando el unsharing de rutas está habilitado, cualquier montaje realizado desde scriptlets también es privado para el scriptlet (y viceversa, los cambios de montaje en el host no son visibles para el scriptlet).

Los montajes privados en operaciones chroot no están implementados.

%__transaction_unshare_nonet
Un valor distinto de cero deshabilita el acceso a la red durante la ejecución de scriptlets.

Consulte rpm-plugins(8) sobre cómo controlar plugins en general.

VER TAMBIÉN
