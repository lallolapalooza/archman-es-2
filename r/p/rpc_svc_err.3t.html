rpc_svc_err(3t)

Paquete: libtirpc

Licencias: SISSL, BSD-3-Clause

RPC_SVC_ERR(3) Manual de funciones de biblioteca RPC_SVC_ERR(3)

NOMBRE

rpc_svc_err, svcerr_auth, svcerr_decode, svcerr_noproc, svcerr_noprog, svcerr_progvers, svcerr_systemerr, svcerr_weakauth — rutinas de biblioteca para errores de llamadas a procedimientos remotos en el lado del servidor

SINOPSIS

#include <rpc/rpc.h>

void
svcerr_auth(SVCXPRT *xprt, enum auth_stat why);

void
svcerr_decode(SVCXPRT *xprt);

void
svcerr_noproc(SVCXPRT *xprt);

void
svcerr_noprog(SVCXPRT *xprt);

void
svcerr_progvers(SVCXPRT *xprt, rpcvers_t low_vers, rpcvers_t high_vers);

void
svcerr_systemerr(SVCXPRT *xprt);

void
svcerr_weakauth(SVCXPRT *xprt);

DESCRIPCIÓN

Estas rutinas forman parte de la biblioteca RPC, que permite a los programas del lenguaje C realizar llamadas a procedimientos en otras máquinas a través de la red.

Estas rutinas pueden ser llamadas por la función de distribución del lado del servidor si hay algún error en la transacción con el cliente.

Rutinas

Consulte rpc(3) para ver la definición de la estructura de datos SVCXPRT.

svcerr_auth()
Es llamada por una rutina de distribución de servicio que rechaza realizar una llamada a procedimiento remoto debido a un error de autenticación.
svcerr_decode()
Es llamada por una rutina de distribución de servicio que no puede decodificar con éxito los argumentos remotos (consulte svc_getargs() en rpc_svc_reg(3)).
svcerr_noproc()
Es llamada por una rutina de distribución de servicio que no implementa el número de procedimiento que el llamador solicita.
svcerr_noprog()
Se llama cuando el programa deseado no está registrado con el paquete RPC. Los implementadores de servicios normalmente no necesitan esta rutina.
svcerr_progvers()
Se llama cuando la versión deseada de un programa no está registrada con el paquete RPC. El argumento low_vers es el número de versión más bajo, y high_vers es el número de versión más alto. Los implementadores de servicios normalmente no necesitan esta rutina.
svcerr_systemerr()
Es llamada por una rutina de distribución de servicio cuando detecta un error del sistema no cubierto por ningún protocolo particular. Por ejemplo, si un servicio ya no puede asignar almacenamiento, puede llamar a esta rutina.
svcerr_weakauth()
Es llamada por una rutina de distribución de servicio que se niega a realizar una llamada a procedimiento remoto debido a argumentos de autenticación insuficientes (pero correctos). La rutina llama a svcerr_auth(xprt, AUTH_TOOWEAK).

DISPONIBILIDAD

Estas funciones forman parte de libtirpc.

VER TAMBIÉN
