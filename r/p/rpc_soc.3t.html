SINOPSIS

#include <rpc/rpc.h>

Ver DESCRIPCIÓN para las declaraciones de funciones.

DESCRIPCIÓN

Las funciones svc_*() y clnt_*() descritas en esta página son la interfaz antigua TS-RPC de la biblioteca XDR y RPC, y existen por compatibilidad hacia atrás. La nueva interfaz se describe en las páginas referenciadas desde rpc(3).

Estas rutinas permiten a los programas C realizar llamadas a procedimientos en otras máquinas a través de la red. Primero, el cliente llama a una rutina para enviar un paquete de datos al servidor. Al recibir el paquete, el servidor llama a una rutina de distribución para realizar el servicio solicitado y luego envía una respuesta. Finalmente, la llamada al procedimiento regresa al cliente.

Las rutinas que se utilizan para RPC Segura (autenticación DES) se describen en rpc_secure(3). RPC Segura solo se puede usar si la encriptación DES está disponible.

void
 
auth_destroy(AUTH *auth)

Una macro que destruye la información de autenticación asociada con auth. La destrucción generalmente implica la desasignación de estructuras de datos privadas. El uso de auth no está definido después de llamar a auth_destroy().

AUTH *
 
authnone_create()

Crea y devuelve un manejador de autenticación RPC que pasa información de autenticación no utilizable con cada llamada a procedimiento remoto. Esta es la autenticación por defecto utilizada por RPC.

AUTH *
 
authunix_create(char *host, int uid, int gid, int len, int *aup_gids)

Crea y devuelve un manejador de autenticación RPC que contiene información de autenticación de UNIX. El argumento host es el nombre de la máquina en la que se creó la información; uid es el ID de usuario del usuario; gid es el ID de grupo actual del usuario; len y aup_gids se refieren a un array contado de grupos a los que pertenece el usuario. Es fácil suplantar a un usuario.

AUTH *
 
authunix_create_default()

Llama a authunix_create() con los argumentos apropiados.

int callrpc(char *host, u_long prognum, u_long versnum, u_long procnum, xdrproc_t inproc, void *in, xdrproc_t outproc, void *out);

Llama al procedimiento remoto asociado con prognum, versnum y procnum en la máquina host. El argumento in es la dirección del(los) argumento(s) del procedimiento, y out es la dirección donde colocar el(los) resultado(s); inproc se utiliza para codificar los argumentos del procedimiento, y outproc se utiliza para decodificar los resultados del procedimiento. Esta rutina devuelve cero si tiene éxito, o el valor de enum clnt_stat convertido a un entero si falla. La rutina clnt_perrno() es útil para traducir los estados de falla a mensajes.

Advertencia: llamar a procedimientos remotos con esta rutina utiliza UDP/IP como transporte; ver clntudp_create() para restricciones. No tienes control de los tiempos de espera o la autenticación usando esta rutina.

enum clnt_stat
 
clnt_broadcast(u_long prognum, u_long versnum, u_long procnum, xdrproc_t inproc, char *in, xdrproc_t outproc, char *out, bool_t (*eachresult)(caddr_t, struct sockaddr_in *));

Similar a callrpc(), excepto que el mensaje de llamada se difunde a todas las redes de difusión conectadas localmente. Cada vez que recibe una respuesta, esta rutina llama a eachresult(), cuya forma es:

bool_t eachresult(caddr_t out, struct sockaddr_in *addr)

donde out es el mismo que out pasado a callrpc().

enum clnt_stat
 
clnt_call(CLIENT *clnt, u_long procnum, xdrproc_t inproc, char *in, xdrproc_t outproc, char *out);

Realiza una llamada RPC al cliente descrito por clnt. El procedimiento a llamar es procnum. Los argumentos se codifican usando inproc, y los resultados se decodifican usando outproc. El argumento in apunta a los argumentos y out apunta a los resultados. Esta rutina devuelve el estado de la llamada RPC.

bool_t
 
clnt_control(CLIENT *clnt, int request, char *arg);

Controla un cliente RPC. La solicitud request especifica la operación a realizar, y arg es un argumento para la operación. Las operaciones admitidas incluyen CLSET_TIMEOUT, CLGET_TIMEOUT, CLSET_RETRY_LIMIT, CLGET_RETRY_LIMIT, CLGET_SERVER_ADDR, CLGET_FD, CLSET_FD_CLOSE, CLSET_FD_NCLOSE, CLGET_FLAGS, CLSET_FLAGS.

CLIENT *
 
clnt_create(char *host, u_long prognum, u_long versnum, char *nettype);

Crea un manejador de cliente genérico para un programa RPC. host es el nombre del host del servidor, prognum es el número de programa RPC, versnum es el número de versión del programa, y nettype es el tipo de red a utilizar (por ejemplo, "tcp" o "udp").

clnt_destroy(CLIENT *clnt);

Destruye el manejador de cliente RPC clnt y libera todos los recursos asociados.

void
 
clnt_freeres(CLIENT *clnt, xdrproc_t xdr_res, char *res);

Libera la memoria utilizada para almacenar los resultados de una llamada RPC. xdr_res es el procedimiento XDR para decodificar los resultados, y res es un puntero a los resultados.

enum clnt_stat
 
clnt_geterr(CLIENT *clnt);

Devuelve el estado del último error que ocurrió en el cliente RPC clnt.

void
 
clnt_pcreateerror(char *sens);

Imprime un mensaje de error que describe la causa de la falla de creación del cliente RPC en stderr. Si sens no es NULL, se imprimirá antes del mensaje de error.

void
 
clnt_perrno(enum clnt_stat stat);

Imprime un mensaje de error que describe el estado RPC dado stat en stderr.

void
 
clnt_perror(CLIENT *clnt, char *s);

Imprime un mensaje de error que describe el error RPC actual para el cliente clnt en stderr. Si s no es NULL, se imprimirá antes del mensaje de error.

char *
 
clnt_spcreateerror(char *sens);

Similar a clnt_pcreateerror(), pero devuelve una cadena que describe la causa de la falla de creación del cliente RPC.

char *
 
clnt_sperrno(enum clnt_stat stat);

Similar a clnt_perrno(), pero devuelve una cadena que describe el estado RPC dado stat.

char *
 
clnt_sperror(CLIENT *clnt);

Similar a clnt_perror(), pero devuelve una cadena que describe el error RPC actual para el cliente clnt.

CLIENT *
 
clntraw_create(u_long prognum, u_long versnum);

Crea un cliente RPC genérico que utiliza un transporte de difusión de datos (raw).

CLIENT *
 
clnttcp_create(struct sockaddr_in *addr, u_long prognum, u_long versnum, u_int *sockp, u_int sendsz, u_int recvsz);

Crea un cliente RPC que utiliza TCP como transporte. addr es la dirección del servidor, prognum es el número de programa RPC, versnum es el número de versión del programa. Si sockp no es NULL, se asignará un nuevo socket y su descriptor se almacenará en sockp. sendsz y recvsz son los tamaños deseados para los buffers de envío y recepción.

CLIENT *
 
clntudp_bufcreate(struct sockaddr_in *addr, u_long prognum, u_long versnum, struct timeval waitfor, u_int *sockp, u_int sendsz, u_int recvsz);

Similar a clntudp_create(), pero permite especificar los tamaños de los búferes de envío y recepción.

CLIENT *
 
clntudp_create(struct sockaddr_in *addr, u_long prognum, u_long versnum, struct timeval waitfor);

Crea un cliente RPC que utiliza UDP como transporte. addr es la dirección del servidor, prognum es el número de programa RPC, versnum es el número de versión del programa, y waitfor es el tiempo de espera para las respuestas.

CLIENT *
 
clntunix_create(char *path, u_long prognum, u_long versnum, u_int *sockp, u_int sendsz, u_int recvsz);

Crea un cliente RPC que utiliza un socket de dominio UNIX como transporte. path es la ruta del socket, prognum es el número de programa RPC, versnum es el número de versión del programa. Si sockp no es NULL, se asignará un nuevo socket y su descriptor se almacenará en sockp. sendsz y recvsz son los tamaños deseados para los búferes de envío y recepción.

enum clnt_stat
 
clnt_broadcast(CLIENT *clnt, u_long procnum, xdrproc_t inproc, char *in, xdrproc_t outproc, char *out, resultproc_t eachresult, char *tsp);

This routine is similar to clnt_call(), except that the remote procedure's output is decoded there; addr points to the address of the machine that sent the results. If eachresult() returns zero, clnt_broadcast() waits for more replies; otherwise it returns with appropriate status.

Warning: broadcast sockets are limited in size to the maximum transfer unit of the data link. For ethernet, this value is 1500 bytes.

enum clnt_stat
 
clnt_call(CLIENT *clnt, u_long procnum, xdrproc_t inproc, char *in, xdrproc_t outproc, char *out, struct timeval tout);

A macro that calls the remote procedure procnum associated with the client handle, clnt, which is obtained with an RPC client creation routine such as clnt_create(). The in argument is the address of the procedure's argument(s), and out is the address of where to place the result(s); inproc is used to encode the procedure's arguments, and outproc is used to decode the procedure's results; tout is the time allowed for results to come back.

void clnt_destroy(CLIENT *clnt)

A macro that destroys the client's RPC handle. Destruction usually involves deallocation of private data structures, including clnt itself. Use of clnt is undefined after calling clnt_destroy(). If the RPC library opened the associated socket, it will close it also. Otherwise, the socket remains open.

CLIENT *
 
clnt_create(char *host, u_long prog, u_long vers, char *proto)

Generic client creation routine. The host argument identifies the name of the remote host where the server is located. The proto argument indicates which kind of transport protocol to use. The currently supported values for this field are "udp" and "tcp". Default timeouts are set, but can be modified using clnt_control().

Warning: Using UDP has its shortcomings. Since UDP-based RPC messages can only hold up to 8 Kbytes of encoded data, this transport cannot be used for procedures that take large arguments or return huge results.

bool_t
 
clnt_control(CLIENT *cl, u_int req, char *info)

A macro used to change or retrieve various information about a client object. The req argument indicates the type of operation, and info is a pointer to the information. For both UDP and TCP, the supported values of req and their argument types and what they do are:

CLSET_TIMEOUT struct timeval set total timeout
CLGET_TIMEOUT struct timeval get total timeout

Note: if you set the timeout using clnt_control(), the timeout argument passed to clnt_call() will be ignored in all future calls.

CLGET_SERVER_ADDR struct sockaddr_in get server's address

The following operations are valid for UDP only:

CLSET_RETRY_TIMEOUT struct timeval set the retry timeout
CLGET_RETRY_TIMEOUT struct timeval get the retry timeout

The retry timeout is the time that UDP RPC waits for the server to reply before retransmitting the request.

bool_t clnt_freeres(CLIENT *clnt, xdrproc_t outproc, char *out)

A macro that frees any data allocated by the RPC/XDR system when it decoded the results of an RPC call. The out argument is the address of the results, and outproc is the XDR routine describing the results. This routine returns one if the results were successfully freed, and zero otherwise.

void
 
clnt_geterr(CLIENT *clnt, struct rpc_err *errp)

A macro that copies the error structure out of the client handle to the structure at address errp.

void
 
clnt_pcreateerror(char *s)

prints a message to standard error indicating why a client RPC handle could not be created. The message is prepended with string s and a colon. A newline is appended at the end of the message. Used when a clnt_create(), clntraw_create(), clnttcp_create(), or clntudp_create() call fails.

void
 
clnt_perrno(enum clnt_stat stat)

Print a message to standard error corresponding to the condition indicated by stat. A newline is appended at the end of the message. Used after callrpc().

void clnt_perror(CLIENT *clnt, char *s)

Print a message to standard error indicating why an RPC call failed; clnt is the handle used to do the call. The message is prepended with string s and a colon. A newline is appended at the end of the message. Used after clnt_call().

char *
 
clnt_spcreateerror(char *s)

Like clnt_pcreateerror(), except that it returns a string instead of printing to the standard error.

Bugs: returns pointer to static data that is overwritten on each call.

char *
 
clnt_sperrno(enum clnt_stat stat)

Take the same arguments as clnt_perrno(), but instead of sending a message to the standard error indicating why an RPC call failed, return a pointer to a string which contains the message.

The clnt_sperrno() function is used instead of clnt_perrno() if the program does not have a standard error (as a program running as a server quite likely does not), or if the programmer does not want the message to be output with printf(), or if a message format different from that supported by clnt_perrno() is to be used.

Note: unlike clnt_sperror() and clnt_spcreateerror(), clnt_sperrno() returns pointer to static data, but the result will not get overwritten on each call.

char *
 
clnt_sperror(CLIENT *rpch, char *s)

Like clnt_perror(), except that it returns a pointer to a string instead of printing to the standard error.

Bugs: returns pointer to static data that is overwritten on each call.

bool_t registerrpc(u_long prognum, u_long versnum, u_long procnum, char *(*procname)(void), xdrproc_t inproc, xdrproc_t outproc);

Registra el procedimiento procname con el paquete de servicios RPC. Si llega una solicitud para el programa prognum, versión versnum y procedimiento procnum, se llama a procname con un puntero a sus argumentos; progname debe devolver un puntero a su(s) resultado(s) estático(s); inproc se usa para decodificar los argumentos mientras que outproc se usa para codificar los resultados. Una variable global que refleja la máscara de bits del descriptor de archivo de lectura del lado del servicio RPC; es adecuada como argumento de plantilla para la llamada al sistema select(2). bool_t svc_register(SVCXPRT *xprt, u_long prognum, u_long versnum, void (*dispatch)(struct svc_req *, SVCXPRT *), int protocol);

Asocia prognum y versnum con el procedimiento de despacho de servicio, dispatch(). Si protocolo es cero, el servicio no se registra con el servicio rpcbind(8). Si protocolo es distinto de cero, entonces se establece una correspondencia del triple (prognum, versnum, protocolo) con xprt->xp_port en el servicio local rpcbind(8) (generalmente protocolo es cero, IPPROTO_UDP o IPPROTO_TCP). La rutina svc_register() devuelve uno si tiene éxito y cero en caso contrario.

NAME

xdr_pmaplist, xdr_rejected_reply, xdr_replymsg, xprt_register, xprt_unregister — XDR routines for RPC

SYNOPSIS

bool_t xdr_pmaplist(XDR *xdrs, struct pmaplist **rp)
bool_t xdr_rejected_reply(XDR *xdrs, struct rejected_reply *rr)
bool_t xdr_replymsg(XDR *xdrs, struct rpc_msg *rmsg)
void
xprt_register(SVCXPRT *xprt)
void
xprt_unregister(SVCXPRT *xprt)

DESCRIPTION

The function xdr_pmaplist() is used to describe a list of port mappings, externally. This routine is useful for users who wish to generate these arguments without using the pmap_*() interface.

The function xdr_rejected_reply() is used to describe RPC reply messages. This routine is useful for users who wish to generate RPC-style messages without using the RPC package.

The function xdr_replymsg() is used to describe RPC reply messages. This routine is useful for users who wish to generate RPC style messages without using the RPC package.

The function xprt_register() registers RPC service transport handles with the RPC service package. After RPC service transport handles are created, they should register themselves with the RPC service package. This routine modifies the global variable svc_fds. Service implementors usually do not need this routine.

The function xprt_unregister() unregisters RPC service transport handles from the RPC service package. Before an RPC service transport handle is destroyed, it should unregister itself with the RPC service package. This routine modifies the global variable svc_fds. Service implementors usually do not need this routine.

AVAILABILITY

These functions are part of libtirpc.
