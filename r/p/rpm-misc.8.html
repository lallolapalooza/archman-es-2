NOMBRE rpm - opciones de menor necesidad para rpm(8)

OPCIONES

--predefinir='MACRO EXPR'
Define MACRO con el valor EXPR antes de cargar los archivos macro.

Desactivar funcionalidades

--color [nunca|auto|siempre]
Usa colores de terminal para resaltar mensajes de error y depuración. El valor predeterminado es activar los colores solo para ttys (auto).

--nocontexts Desactiva el plugin SELinux si está disponible. Esto evita que el plugin establezca contextos SELinux para archivos y scripts.

--noglob
No expande comodines en los argumentos al instalar archivos de paquetes.
--nocaps
No verifica las capacidades de los archivos.
--excluirconfiguraciones, --noconfigs
No instala archivos de configuración.
--nohdrchk
No verifica las cabeceras de la base de datos al ser recuperadas.

Depuración

-d, --debug
Imprime información de depuración.
--buclesdeservicio
Imprime bucles de dependencia como advertencia.
--fsmdebug
Imprime información de depuración del código de manejo de carga útil.
--rpmfcdebug
Imprime información de depuración sobre los archivos empaquetados.
--rpmiodebug
Imprime información de depuración sobre E/S de archivos.
--estadisticas
Imprime estadísticas de tiempo de ejecución de funciones usadas frecuentemente.

Opciones obsoletas

-K, --verificarsig
Ver y usar rpmkeys(8).
--nodocs
No instales documentación. Usa --excluirdocs en su lugar.
--promover-epoch
Habilita el manejo obsoleto de epoch utilizado en la época de rpm 3.x.
--prtpkts
¡OBSOLETO! Se usaba para imprimir los paquetes que contenían y representaban las claves pgp para fines de depuración.
