rpm - Gestor de Paquetes RPM

rpm {-q|--query} [opciones-de-selección] [opciones-de-consulta]

DESCRIPCIÓN

rpm es un potente Gestor de Paquetes, que puede ser utilizado para construir, instalar, consultar, verificar, actualizar y eliminar paquetes de software individuales. Un paquete consiste en un archivo de ficheros y metadatos utilizados para instalar y eliminar los archivos del archivo. Los metadatos incluyen scripts de ayuda, atributos de archivos e información descriptiva sobre el paquete. Los paquetes vienen en dos variedades: paquetes binarios, utilizados para encapsular software a instalar, y paquetes de origen, que contienen el código fuente y la receta necesaria para producir paquetes binarios.

Se debe seleccionar uno de los siguientes modos básicos: Consulta, Verificar, Instalar/Actualizar/Refrescar/Reinstalar, Desinstalar, Establecer Propietarios/Grupos, Mostrar Etiquetas de Consulta y Mostrar Configuración.

OPCIONES GENERALES

Estas opciones se pueden utilizar en todos los modos diferentes.

-?, --help
Imprime un mensaje de uso más largo de lo normal.
--version
Imprime una sola línea que contiene el número de versión de rpm que se está utilizando.
--quiet
Imprime lo menos posible; normalmente solo se mostrarán los mensajes de error.
-v, --verbose
Imprime información detallada; normalmente se mostrarán los mensajes de progreso rutinarios.
-vv
Imprime mucha información de depuración detallada.
--rcfile LISTA_ARCHIVOS
Reemplaza la lista predeterminada de archivos de configuración a leer con LISTA_ARCHIVOS. Ver Configuración rpmrc para detalles.
--load ARCHIVO
Carga un archivo de macros individual.
--macros LISTA_ARCHIVOS
Reemplaza la lista de archivos de macros a cargar con LISTA_ARCHIVOS. Ver Configuración de Macros para detalles.
--pipe COMANDO
Canaliza la salida de rpm al comando COMANDO.
--dbpath DIRECTORIO
Utiliza la base de datos en DIRECTORIO en lugar de la ruta predeterminada /var/lib/rpm.
--root DIRECTORIO
Utiliza el árbol de sistemas de archivos con raíz en DIRECTORIO para todas las operaciones. Tenga en cuenta que esto significa que la base de datos dentro de DIRECTORIO se utilizará para las comprobaciones de dependencias y cualquier scriptlet (por ejemplo, %post si se instala, o %prep si se construye un paquete) se ejecutará después de un chroot(2) a DIRECTORIO.

Tenga en cuenta que rpm asume que el entorno dentro de la raíz está configurado por el llamador, como cualquier montaje necesario para la operación dentro del directorio raíz.

-D, --define='MACRO EXPRESION'
Define MACRO con el valor EXPRESION.
--undefine='MACRO'
Anula la definición de MACRO.
-E, --eval='EXPRESION'
Imprime la expansión de macro de EXPRESION.

Más opciones (menos necesarias) se pueden encontrar en la página del manual rpm-misc(8).

OPCIONES DE INSTALACIÓN Y ACTUALIZACIÓN

En estas opciones, ARCHIVO_PAQUETE puede ser un archivo binario de rpm o un manifiesto de paquete ASCII (ver OPCIONES DE SELECCIÓN DE PAQUETES), y puede especificarse como una URL ftp o http, en cuyo caso el paquete

Este sitio no está asociado de ninguna forma con Arch Linux ni afiliado a este proyecto. El contenido es únicamente una traducción de las páginas del manual de Arch publicadas en man.archlinux.org.

será descargado antes de ser instalado. Consulte las opciones de **FTP/HTTP** para obtener información sobre el soporte del cliente **ftp** y **http** de **rpm**.

La forma general de un comando de instalación de **rpm** es

**rpm** {**-i|--install**} [opciones-de-instalacion] ARCHIVO_PAQUETE ...

Esto instala un nuevo paquete.

La forma general de un comando de actualización de **rpm** es

**rpm** {**-U|--upgrade**} [opciones-de-instalacion] ARCHIVO_PAQUETE ...

Esto actualiza o instala el paquete actualmente instalado a una versión más reciente. Es lo mismo que instalar, excepto que todas las demás versiones del paquete se eliminan después de instalar el nuevo paquete.

**rpm** {**-F|--freshen**} [opciones-de-instalacion] ARCHIVO_PAQUETE ...

Esto actualizará los paquetes, pero solo aquellos para los que haya instalada una versión anterior.

La forma general de un comando de reinstalación de **rpm** es

**rpm** {**--reinstall**} [opciones-de-instalacion] ARCHIVO_PAQUETE ...

Esto reinstala un paquete previamente instalado.

--allfiles
Instala o actualiza todos los archivos con `missingok` en el paquete, independientemente de si existen.
--badreloc
Usado con --relocate, permite reubicaciones en todas las rutas de archivos, no solo en aquellas RUTA_ANTIGUA incluidas en la(s) pista(s) de reubicación del paquete binario.
--excludepath RUTA_ANTIGUA
No instale archivos cuyo nombre comience con RUTA_ANTIGUA.
--excludeartifacts
No instale ningún archivo marcado como artefacto, como enlaces `build-id`.
--excludedocs
No instale ningún archivo marcado como documentación (que incluye páginas man y documentos texinfo).
--force
Igual que usar --replacepkgs, --replacefiles y --oldpackage.
-h, --hash
Imprime 50 signos de almohadilla mientras se desempaqueta el archivo del paquete. Úselo con -v|--verbose para una visualización más agradable.
--ignoresize
No verifique los sistemas de archivos montados para ver si hay suficiente espacio en disco antes de instalar este paquete.
--ignorearch
Permite la instalación o actualización incluso si las arquitecturas del paquete binario y del host no coinciden.
--ignoreos
Permite la instalación o actualización incluso si los sistemas operativos del paquete binario y del host no coinciden.
--includedocs
Instale archivos de documentación. Este es el comportamiento predeterminado.
--justdb
Actualice solo la base de datos, no el sistema de archivos.
--nodb
Actualice solo el sistema de archivos, no la base de datos.
--nodigest
No verifique los resúmenes del paquete o encabezado al leer.
--nomanifest
No procese archivos que no sean paquetes como manifiestos.
--nosignature
No verifique las firmas del paquete o encabezado al leer.
--nodeps
No realice una verificación de dependencias antes de instalar o actualizar un paquete.
--nocaps
No establezca las capacidades de archivo.
--noorder
No reordene los paquetes para una instalación. Normalmente, la lista de paquetes se reordenaría para satisfacer las dependencias.
--noverify
No realice la verificación de los archivos del paquete antes de la instalación.
--noplugins
No cargue ni ejecute plugins.
--noscripts, --nopre, --nopost, --nopreun, --nopostun, --nopretrans, --noposttrans, --nopreuntrans, --nopostuntrans
No ejecute el scriptlet del mismo nombre. La opción --noscripts es equivalente a

--nopre --nopost --nopreun --nopostun --nopretrans --noposttrans --nopreuntrans --nopostuntrans

y desactiva la ejecución del(los) scriptlet(s) correspondiente(s) %pre, %post, %preun, %postun %pretrans, %posttrans, %preuntrans y %postuntrans.

--notriggers, --notriggerin, --notriggerun, --notriggerprein, --notriggerpostun
No ejecute ningún scriptlet de disparador del tipo nombrado. La opción --notriggers es equivalente a

--notriggerprein --notriggerin --notriggerun --notriggerpostun

y desactiva la ejecución del(los) scriptlet(s) de disparador correspondiente(s) %triggerprein, %triggerin, %triggerun y %triggerpostun.

--nosysusers
No cree usuarios del sistema a partir de paquetes
--oldpackage
Permite que una actualización reemplace un paquete más nuevo por uno más antiguo.
--percent
Imprime porcentajes mientras se desempaquetan los archivos del archivo del paquete. Esto está destinado a hacer que **rpm** sea fácil de ejecutar desde otras herramientas.
--prefix NUEVA_RUTA
Para paquetes binarios reubicables, traduzca todas las rutas de archivos que comiencen con el prefijo de instalación en la(s) pista(s) de reubicación del paquete a NUEVA_RUTA.
--relocate RUTA_ANTIGUA=NUEVA_RUTA
Para paquetes binarios reubicables, traduzca todas las rutas de archivos que comiencen con RUTA_ANTIGUA en la(s) pista(s) de reubicación del paquete a NUEVA_RUTA. Esta opción se puede usar repetidamente si se deben reubicar varias RUTA_ANTIGUA en el paquete.
--replacefiles
Instale los paquetes incluso si reemplazan archivos de otros paquetes ya instalados.
--replacepkgs
Instale los paquetes incluso si algunos de ellos ya están instalados en este sistema.
--test
No instale el paquete, simplemente verifique e informe posibles conflictos.

OPCIONES DE BORRADO

La forma general de un comando de borrado de **rpm** es

**rpm** {**-e|--erase**} [--allmatches] [--justdb] [--nodeps] [--noscripts] [--notriggers] [--test] NOMBRE_PAQUETE ...

Las siguientes opciones también pueden usarse:

--allmatches
Elimine todas las versiones del paquete que coincidan con NOMBRE_PAQUETE. Normalmente, se emitirá un error si NOMBRE_PAQUETE coincide con varios paquetes.
--justdb
Actualice solo la base de datos, no el sistema de archivos.
--nodeps
No verifique las dependencias antes de desinstalar los paquetes.
--noscripts, --nopreun, --nopostun
No ejecute el scriptlet del mismo nombre. La opción --noscripts durante el borrado del paquete es equivalente a

--nopreun --nopostun

y desactiva la ejecución del(los) scriptlet(s) correspondiente(s) %preun y %postun.

--notriggers, --notriggerun, --notriggerpostun
No ejecute ningún scriptlet de disparador del tipo nombrado. La opción --notriggers es equivalente a

--notriggerun --notriggerpostun

y desactiva la ejecución del(los) scriptlet(s) de disparador correspondiente(s) %triggerun y %triggerpostun.

--test
No desinstale nada realmente, solo simule el proceso. Útil en conjunción con la opción -vv para depuración.

OPCIONES DE CONSULTA

La forma general de un comando de consulta de **rpm** es

**rpm** {**-q|--query**} [opciones-de-seleccion] [opciones-de-consulta]

Puede especificar el formato en el que se debe imprimir la información del paquete. Para hacer esto, use la opción

--qf|--queryformat FORMATO_CONSULTA

seguida de la cadena de formato FORMATO_CONSULTA. Los formatos de consulta son versiones modificadas del formato estándar de printf(3). El formato está compuesto por cadenas estáticas (que pueden incluir escapes de caracteres estándar de C para nuevas líneas, tabulaciones y otros caracteres especiales (no incluido \0)) y especificadores de formato de printf(3). Como **rpm** ya conoce el tipo a imprimir, el especificador de tipo debe omitirse y reemplazarse por el nombre de la etiqueta del encabezado que se imprimirá, encerrado entre caracteres de {}. Los nombres de etiqueta no distinguen entre mayúsculas y minúsculas, y la parte inicial RPMTAG_ del nombre de la etiqueta también se puede omitir.

Se pueden solicitar formatos de salida alternativos siguiendo la etiqueta con :etiquetadetipo. Actualmente, se admiten los siguientes tipos:

:armor
Envuelve una clave pública en armadura ASCII.
:arraysize
Muestra el número de elementos en las etiquetas de matriz.
:base64
Codifica datos binarios usando base64.
:date
Usa el formato de strftime(3) "%c".
:day
Use strftime(3) formato "%a %b %d %Y".
:depflags
Formato del operador de comparación de dependencias.
:deptype
Formato del tipo de dependencia.
:expand
Realizar expansión de macros.
:fflags
Formato de flags del archivo.
:fstate
Formato del estado del archivo.
:fstatus
Formato del estado de verificación del archivo.
:hex
Formato en hexadecimal.
:octal
Formato en octal.
:humaniec
Número legible por humanos (en IEC 80000). El sufijo K = 1024, M = 1048576, ...
:humansi
Número legible por humanos (en SI). El sufijo K = 1000, M = 1000000, ...
:json
Envolver datos en JSON.
:perms
Formato de permisos del archivo.
:pgpsig
Mostrar huella digital de firma y hora.
:shescape
Escapar comillas simples para uso en un script.
:string
Mostrar formato de cadena. (predeterminado)
:tagname
Mostrar nombre de etiqueta.
:tagnum
Mostrar número de etiqueta.
:triggertype
Mostrar sufijo de activación.
:vflags
Flags de verificación de archivo.
:xml
Envolver datos en marcado xml simple.

Por ejemplo, para imprimir solo los nombres de los paquetes consultados, puede usar %{NAME} como cadena de formato. Para imprimir el nombre de los paquetes y la información de distribución en dos columnas, puede usar %-30{NAME}%{DISTRIBUTION}. rpm imprimirá una lista de todas las etiquetas que conoce cuando se invoca con el argumento --querytags.

Hay tres subconjuntos de opciones para la consulta: selección de paquetes, selección de archivos y selección de información.

OPCIONES DE SELECCIÓN DE PAQUETES

NOMBRE_PAQUETE
Consulta el paquete instalado llamado NOMBRE_PAQUETE. Para especificar el paquete con mayor precisión, el nombre del paquete puede ir seguido de la versión o la versión y la versión, ambas separadas por un guión, o un nombre de arquitectura separado por un punto. Vea la salida de rpm -qa o rpm -qp ARCHIVO_PAQUETE como ejemplo.
-a, --all [SELECTOR]
Consulta todos los paquetes instalados.

Se puede proporcionar un SELECTOR opcional en forma de tag=patrón para acotar la selección, por ejemplo, name="b*" para consultar paquetes cuyo nombre comience con "b".

--dupes
Lista paquetes duplicados.
-f, --file ARCHIVO
Consulta el paquete que posee el ARCHIVO instalado.
--filecaps
Lista nombres de archivos con capacidades POSIX1.e.
--fileclass
Lista nombres de archivos con sus clases (clasificación libmagic).
--filecolor
Lista nombres de archivos con sus colores (0 para noarch, 1 para 32 bits, 2 para 64 bits).
--fileprovide
Lista nombres de archivos con sus proporcionados.
--filerequire
Lista nombres de archivos con sus requeridos.
-g, --group GRUPO
Consulta paquetes con el grupo de GRUPO.
--hdrid SHA1
Consulta el paquete que contiene un identificador de encabezado dado, es decir, el resumen SHA1 de la región de encabezado inmutable.
-p, --package ARCHIVO_PAQUETE
Consulta un ARCHIVO_PAQUETE de paquete (no instalado). El ARCHIVO_PAQUETE puede especificarse como una URL de estilo ftp o http, en cuyo caso el encabezado del paquete se descargará y consultará. Consulte las OPCIONES FTP/HTTP para obtener información sobre el soporte del cliente ftp y http de rpm. Los argumentos ARCHIVO_PAQUETE, si no son un paquete binario, se interpretarán como un manifiesto de paquete ASCII a menos que se utilice la opción --nomanifest. En los manifiestos, se permiten comentarios, que comienzan con un '#', y cada línea de un archivo de manifiesto de paquete puede incluir expresiones glob separadas por espacios en blanco, incluidas las URL, que se expandirán a rutas que se sustituirán en lugar del manifiesto del paquete como argumentos ARCHIVO_PAQUETE adicionales a la consulta.
--path RUTA
Consulta el(los) paquete(s) que poseen la RUTA, esté instalado o no el archivo. Múltiples paquetes pueden poseer una RUTA, pero el archivo solo es propiedad del paquete instalado más recientemente.
--pkgid MD5
Consulta el paquete que contiene un identificador de paquete dado, es decir, el resumen MD5 del contenido combinado del encabezado y la carga útil.
--querybynumber NUM_ENCAB
Consulta directamente la entrada de base de datos número NUM_ENCAB; esto es útil solo para depuración.
--specfile ARCHIVO_ESPEC
Analiza y consulta ARCHIVO_ESPEC como si fuera un paquete. Aunque no toda la información (por ejemplo, listas de archivos) está disponible, este tipo de consulta permite usar rpm para extraer información de los archivos spec sin tener que escribir un analizador de archivos spec.
--tid ID_TRANSACCION
Consulta el(los) paquete(s) que tienen un identificador de transacción ID_TRANSACCION dado. Actualmente se utiliza una marca de tiempo de UNIX como identificador de transacción. Todos los paquetes instalados o borrados dentro de una sola transacción tienen un identificador común.
--triggeredby NOMBRE_PAQUETE
Consulta los paquetes que son activados por el(los) paquete(s) NOMBRE_PAQUETE.
--whatobsoletes CAPACIDAD
Consulta todos los paquetes que obsoletan la CAPACIDAD para su correcto funcionamiento.
--whatprovides CAPACIDAD
Consulta todos los paquetes que proporcionan la capacidad CAPACIDAD.
--whatrequires CAPACIDAD
Consulta todos los paquetes que requieren la CAPACIDAD para su correcto funcionamiento.
--whatconflicts CAPACIDAD
Consulta todos los paquetes que entran en conflicto con la CAPACIDAD.
--whatrecommends CAPACIDAD
Consulta todos los paquetes que recomiendan la CAPACIDAD.
--whatsuggests CAPACIDAD
Consulta todos los paquetes que sugieren la CAPACIDAD.
--whatsupplements CAPACIDAD
Consulta todos los paquetes que complementan la CAPACIDAD.
--whatenhances CAPACIDAD
Consulta todos los paquetes que mejoran la CAPACIDAD.

OPCIONES

La forma general de un comando de consulta rpm es:

rpm {-q|--query} [select-options] [query-options]

Las select-options determinan qué paquetes se consultarán, y las query-options determinan qué información se extraerá de los paquetes seleccionados.

OPCIONES DE SELECCIÓN DE PAQUETE

-a, --all
Consulta todos los paquetes instalados.
-f, --file
Consulta el paquete que posee el archivo especificado.
-g, --grouplike
Consulta paquetes que coincidan con el patrón especificado de nombre, versión, lanzamiento y arquitectura.
-i, --info
Muestra información detallada sobre el paquete seleccionado (por ejemplo, nombre, versión, descripción, tamaño, etc.).
-l, --list
Lista los archivos que contiene el paquete seleccionado.
-N, --noconfirm
No consulta las dependencias del paquete.
-p, --package
Consulta el paquete sin instalarlo. Esto es útil para obtener información sobre un paquete antes de instalarlo.
-R, --requires
Lista las dependencias de software requeridas por el paquete.
--whatrequires
Lista los paquetes instalados que requieren la característica especificada (por ejemplo, un nombre de paquete o una biblioteca).
--whatconflicts
Lista los paquetes instalados que entran en conflicto con la característica especificada.
--whatobsoletes
Lista los paquetes instalados que quedan obsoletos por la característica especificada.
--whatsupplements
Lista los paquetes instalados que complementan la característica especificada.

OPCIONES DE FORMATO DE CONSULTA

-c
Lista solo los archivos de configuración contenidos en el paquete.
-d
Lista solo los archivos de documentación contenidos en el paquete.
-e
Formato de salida para la información de paquetes.
-E
Formato de salida para las dependencias de paquetes.
-f
Formato de salida para los archivos contenidos en el paquete.
-i
Formato de salida para la información de paquetes.
-l
Formato de salida para la lista de archivos del paquete.
-n
Formato de salida para el nombre del paquete.
-q
Formato de salida para la consulta de paquetes.
-R
Formato de salida para las dependencias de paquetes.
-s
Formato de salida para el estado de los archivos del paquete.
-t
Formato de salida para la lista de archivos del paquete (similar a -l).
-v

OPCIONES DE VERIFICACIÓN

La forma general de un comando de verificación rpm es

rpm {-V|--verify} [select-options] [verify-options]

La verificación de un paquete compara la información sobre los archivos instalados en el paquete con la información sobre los archivos tomada de los metadatos del paquete almacenados en la base de datos rpm. Entre otras cosas, la verificación compara el tamaño, el resumen (digest), los permisos, el tipo, el propietario y el grupo de cada archivo. Se muestran las discrepancias. Los archivos que no se instalaron desde el paquete, por ejemplo, los archivos de documentación excluidos durante la instalación usando la opción "--excludedocs", se ignorarán en silencio.

Las opciones de selección de paquetes y archivos son las mismas que para la consulta de paquetes (incluyendo archivos de manifiesto de paquetes como argumentos). Otras opciones únicas para el modo de verificación son:

--nodeps
No verificar las dependencias de los paquetes.
--nodigest
No verificar los resúmenes (digests) del paquete o del encabezado al leer.
--nofiles
No verificar ningún atributo de los archivos del paquete.
--noscripts
No ejecutar el scriptlet %verifyscript (si existe).
--nosignature
No verificar las firmas del paquete o del encabezado al leer.
--nolinkto
--nofiledigest (anteriormente --nomd5)
--nosize
--nomtime
--nomode
--nordev
No verificar el atributo de archivo correspondiente.
--nouser
--nogroup
No verificar la propiedad de usuario/grupo del archivo. Tenga en cuenta que solo se consultan las bases de datos locales de passwd(5) y group(5).
--nocaps
No verificar las capacidades del archivo.

El formato de la salida es una cadena de 9 caracteres, un posible marcador de atributo:

**a** %**a**rtifact archivo de efecto secundario de la compilación (como
      enlaces buildid).
**c** %**c**onfig archivo de configuración.
**d** %**d**oc archivo de documentación.
**g** %**g**host archivo (es decir, el contenido del archivo no se incluye en la
      carga útil del paquete).
**l** %**l**icense archivo de licencia.
**m** %**m**issingok la ausencia del archivo no es un fallo de verificación.
**n** %%config(**n**oreplace) (no reemplazar el archivo).
**r** %**r**eadme archivo readme.
**s** **s**pecfile en el paquete fuente.

del encabezado del paquete, seguido del nombre del archivo. Cada uno de los 9 caracteres denota el resultado de una comparación de uno o más atributos del archivo con el valor de esos atributos registrados en la base de datos. Un solo "." (punto) significa que la prueba pasó, mientras que un solo "?" (signo de interrogación) indica que la prueba no pudo realizarse (por ejemplo, los permisos del archivo impiden la lectura). De lo contrario, el carácter (mnemotécnicamente en negrita) denota el fallo de la prueba correspondiente de --verify:

**S** **S**ize (tamaño) del archivo diferente
**M** **M**ode (modo) diferente (incluye permisos y tipo de archivo)
**5** digest (anteriormente suma MD**5**) diferente
**D** **D**iscrepancia en el número mayor/menor del dispositivo
**L** **L**ink (enlace) path diferente
**U** **U**ser (propietario) diferente
**G** **G**roup (grupo) diferente
**T** **T**ime (tiempo de modificación) diferente
**P** ca**P**abilities (capacidades) diferentes

OPCIONES FTP/HTTP

rpm puede actuar como cliente FTP y/o HTTP para que los paquetes se puedan consultar o instalar desde Internet. Los archivos de paquetes para las operaciones de instalación, actualización y consulta pueden especificarse como una URL de estilo ftp o http:

http://HOST[:PORT]/path/to/package.rpm

ftp://[USUARIO:CONTRASEÑA]@HOST[:PORT]/path/to/package.rpm

Si se omiten tanto el usuario como la contraseña, se utiliza ftp anónimo.

rpm permite utilizar las siguientes opciones con URL ftp:

rpm permite utilizar las siguientes opciones con URL http y ftp:

--httpproxy HOST
El host HOST se utilizará como servidor proxy para todas las transferencias http y ftp. Esta opción también se puede especificar configurando la macro %_httpproxy.
--httpport PORT
El número de puerto TCP PORT a utilizar para la conexión http en el servidor proxy http en lugar del puerto predeterminado. Esta opción también se puede especificar configurando la macro %_httpport.

ASUNTOS LEGADOS

Ejecución de rpmbuild

Los modos de compilación de rpm ahora residen en el ejecutable /usr/bin/rpmbuild. Instale el paquete que contiene rpmbuild (normalmente rpm-build) y consulte rpmbuild(8) para obtener documentación sobre todos los modos de compilación de rpm.

ARCHIVOS

Configuración de rpmrc

Cada archivo en la ruta rpmrc separada por dos puntos es leída secuencialmente por rpm para obtener información de configuración. Solo el primer archivo de la lista debe existir, y las tildes se expandirán al valor de $HOME. La ruta rpmrc predeterminada es la siguiente:

/usr/lib/rpm/rpmrc:
/usr/lib/rpm/<vendor>/rpmrc:
/etc/rpmrc:
~/.config/rpm/rpmrc

Si la variable de entorno XDG_CONFIG_HOME está establecida, reemplaza ~/.config en la ruta.

En versiones anteriores de rpm, la ruta de rpmrc por usuario era ~/.rpmrc. Esto todavía se procesa si existe y el nuevo directorio de configuración no existe.

Configuración de macros

Cada archivo o patrón glob(7) en la ruta de macros separada por dos puntos es leída secuencialmente por rpm para obtener definiciones de macros. Las tildes se expandirán al valor de la variable de entorno HOME. La ruta de macros predeterminada es la siguiente:

/usr/lib/rpm/macros:
/usr/lib/rpm/macros.d/macros.*:
/usr/lib/rpm/platform/%{_target}/macros:
/usr/lib/rpm/fileattrs/*.attr:
/usr/lib/rpm/<vendor>/macros:
/etc/rpm/macros.*:
/etc/rpm/macros:
/etc/rpm/%{_target}/macros:
~/.config/rpm/macros

Si la variable de entorno XDG_CONFIG_HOME está establecida, reemplaza ~/.config en la ruta.

En versiones anteriores de rpm, la ruta de macros por usuario era ~/.rpmmacros. Esto todavía se procesa si existe y el nuevo directorio de configuración no existe.
