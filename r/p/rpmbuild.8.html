NOMBRE

rpmbuild - Construir Paquetes RPM

SINOPSIS

CONSTRUYENDO PAQUETES

rpmbuild {-ba|-bb|-bp|-bf|-bc|-bi|-bl|-bs|-br|-bd} [opciones-de-rpmbuild] ESPECIFICACIONES ...

rpmbuild {-ra|-rb|-rp|-rf|-rc|-ri|-rl|-rs|-rr|-rd} [opciones-de-rpmbuild] PAQUETES-FUENTE ...

rpmbuild {-ta|-tb|-tp|-tf|-tc|-ti|-tl|-ts|-tr|-td} [opciones-de-rpmbuild] TARBALL ...

rpmbuild {--rebuild|--recompile} PAQUETE-FUENTE ...

VARIOS

rpmbuild --showrc

opciones-de-rpmbuild

[--buildroot DIRECTORIO] [--clean] [--nobuild] [--rmsource] [--rmspec] [--short-circuit] [--build-in-place] [--noprep] [--noclean] [--nocheck] [--rpmfcdebug] [--target PLATAFORMA] [--with OPCION] [--without OPCION]

DESCRIPCIÓN

rpmbuild se utiliza para construir paquetes de software tanto binarios como fuente. Un paquete consiste en un archivo de ficheros y metadatos utilizados para instalar y borrar los ficheros del archivo. Los metadatos incluyen scripts de ayuda, atributos de archivo e información descriptiva sobre el paquete. Los paquetes vienen en dos variedades: paquetes binarios, utilizados para encapsular software a instalar, y paquetes fuente, que contienen el código fuente y la receta necesaria para producir paquetes binarios.

Se debe seleccionar uno de los siguientes modos básicos: Construir Paquete, Construir Paquete desde Tarball, Recompilar Paquete, Mostrar Configuración.

OPCIONES GENERALES

Estas opciones se pueden usar en todos los diferentes modos.

-?, --help
Imprime un mensaje de uso más largo de lo normal.
--version
Imprime una sola línea que contiene el número de versión de rpm que se está utilizando.
--quiet
Imprime lo menos posible; normalmente solo se mostrarán los mensajes de error.
-v
Imprime información detallada; normalmente se mostrarán los mensajes de progreso rutinarios.
-vv
Imprime mucha información de depuración detallada.
--rpmfcdebug
Permite depurar la generación de dependencias.
--rcfile LISTA-ARCHIVOS
Reemplaza la lista predeterminada de archivos de configuración a leer con LISTA-ARCHIVOS. Ver Configuración de rpmrc en rpm(8) para más detalles.
--load ARCHIVO
Carga un archivo de macros individual.
--macros LISTA-ARCHIVOS
Reemplaza la lista de archivos de macros a cargar con LISTA-ARCHIVOS. Ver Configuración de Macros en rpm(8) para más detalles.
--pipe CMD
Redirige la salida de rpm al comando CMD.
--dbpath DIRECTORIO
Usa la base de datos en DIRECTORIO en lugar de la ruta predeterminada /var/lib/rpm.
--root DIRECTORIO
Usa el árbol de sistemas de ficheros con raíz en DIRECTORIO para todas las operaciones. Tenga en cuenta que esto significa que la base de datos dentro de DIRECTORIO se usará para las comprobaciones de dependencias y cualquier scriptlet (p.ej. %post si se está instalando, o %prep si se está construyendo un paquete) se ejecutará después de un chroot(2) a DIRECTORIO.
-D, --define='MACRO EXPRESION'
Define MACRO con el valor EXPRESION.
--scm=SCM
Selecciona el SCM a usar con %autosetup, si no está configurado en el archivo spec. Tenga en cuenta que no todos los valores para SCM, p.ej., patch (el predeterminado) y gendiff, git, o quilt funcionan de forma intercambiable con otros parches y opciones indicadas en la línea %autosetup, especialmente la opción -pN.

OPCIONES DE CONSTRUCCIÓN

La forma general de un comando de construcción de rpm(8) es

rpmbuild {-bETAPA|-rETAPA|-tETAPA} [opciones-de-rpmbuild] ARCHIVO ...

El argumento utilizado es -b si se está utilizando un archivo spec para construir el paquete, -r si se va a reconstruir un paquete fuente y -t si rpmbuild debe buscar dentro de un archivo tar (posiblemente comprimido) el archivo spec a utilizar.

Los paquetes se construyen en una serie de etapas. Las seis primeras corresponden a las siguientes secciones en un archivo spec: %prep, %generate_buildrequires, %build, %install, %check y %clean. Finalmente, los paquetes binarios y fuente se crean en una etapa de ensamblaje.

El carácter ETAPA especifica la etapa final (después de realizar todas las etapas anteriores), y es uno de:

-ba
Realiza una construcción completa; ejecuta hasta e incluyendo la etapa de ensamblaje. En la mayoría de los casos, esta es la opción a elegir.
-bb
Construye solo los paquetes binarios; ejecuta hasta e incluyendo la etapa de ensamblaje, pero sin crear el paquete fuente. Si tiene éxito, el directorio de construcción se elimina (como en --clean).
-bp
Descomprime las fuentes y aplica los parches; ejecuta solo la etapa %prep.
-bf
Configura las fuentes; ejecuta hasta e incluyendo la etapa %conf. Esto generalmente implica el equivalente a un "./configure".
-bc
Compila las fuentes; ejecuta hasta e incluyendo la etapa %build. Esto generalmente implica el equivalente a "make".
-bi
Instala los binarios en la raíz de construcción; ejecuta hasta e incluyendo la etapa %check. Esto generalmente implica el equivalente a un "make install" y "make check".
-bl
Realiza una "comprobación de lista"; se expande el archivo %files del spec, y se realizan comprobaciones para verificar que cada archivo existe.
-bs
Construye solo el paquete fuente; salta directamente a la etapa de ensamblaje, sin ejecutar ninguna de las etapas anteriores ni crear paquetes binarios.
-br
Construye solo el paquete fuente, pero también analiza e incluye dependencias de construcción dinámicas; ejecuta hasta e incluyendo la etapa %generate_buildrequires y luego salta directamente a la etapa de ensamblaje, sin crear paquetes binarios. Este comando se puede usar para resolver completamente las dependencias de construcción dinámicas. Ver la sección DEPENDENCIAS DE CONSTRUCCIÓN DINÁMICAS para más detalles.
-bd
Comprueba las dependencias de construcción dinámicas y construye el paquete .buildreqs.nosrc.rpm si faltan algunas. No construye nada más.

NAME

rpmbuild - construir paquetes RPM a partir de especificaciones

SYNOPSIS

rpmbuild [opciones] SPECFILE ...

rpmbuild --rebuild | --recompile SOURCEPKG ...

DESCRIPTION

rpmbuild se utiliza para construir paquetes binarios y fuente RPM a partir de un archivo de especificaciones.

La creación de un paquete binario se puede invocar usando:

-bp SPECFILE
Ejecuta las etapas %prep y %build solamente.
-bc SPECFILE
Ejecuta las etapas %prep, %build y %install solamente.
-bi SPECFILE
Ejecuta las etapas %prep, %build, %install y %check solamente.
-ba SPECFILE
Ejecuta todas las etapas de compilación y construye tanto paquetes binarios como fuente.
-bb SPECFILE
Ejecuta todas las etapas de compilación y construye solo paquetes binarios.

Hay una serie de opciones de línea de comandos disponibles para controlar el proceso de compilación:

--clean
Elimina el árbol de compilación después de que se crean los paquetes.
--nobuild
No ejecuta ninguna etapa de compilación. Útil para probar archivos de especificaciones.
--noprep
No ejecuta la etapa de compilación %prep aunque esté presente en la especificación.
--noclean
No ejecuta la etapa de compilación %clean aunque esté presente en la especificación.
--nocheck
No ejecuta la etapa de compilación %check aunque esté presente en la especificación.
--nodebuginfo
No genera paquetes de información de depuración.
--nodeps
No verifica las dependencias de compilación.
--rmsource
Elimina las fuentes después de la compilación (también se puede usar de forma independiente, por ejemplo, "rpmbuild --rmsource foo.spec").
--rmspec
Elimina el archivo de especificación después de la compilación (también se puede usar de forma independiente, por ejemplo, "rpmbuild --rmspec foo.spec").
--short-circuit
Salta directamente a la etapa especificada (es decir, omite todas las etapas previas a la etapa especificada). Solo válido con -bc, -bi y -bb. Útil solo para pruebas locales. Los paquetes compilados de esta manera se marcarán con una dependencia insatisfecha para evitar su uso accidental.
--build-in-place
Compila a partir de fuentes extraídas localmente en el directorio de trabajo actual. El árbol de compilación se configura como si se hubiera usado %setup, pero %builddir/%buildsubdir apunta de nuevo al directorio de trabajo actual. %prep se omite por completo.
--target PLATFORM
Al compilar el paquete, interpreta PLATFORM como arch-vendor-os y establece los macros %_target, %_target_cpu y %_target_os en consecuencia.
--with OPTION
Habilita la opción de configuración OPTION para la compilación.
--without OPTION
Deshabilita la opción de configuración OPTION para la compilación.

OPCIONES DE RECOMPILACIÓN Y RECONSTRUCCIÓN

Hay dos formas más de invocar la compilación con rpm(8):

rpmbuild --rebuild|--recompile SOURCEPKG ...

Cuando se invoca de esta manera, rpmbuild instala el paquete fuente especificado y realiza las etapas de preparación, compilación e instalación. Además, --rebuild construye un nuevo paquete binario. Cuando la compilación ha finalizado, el directorio de compilación se elimina (como en --clean) y se eliminan las fuentes y el archivo de especificación del paquete.

Estas opciones ahora están reemplazadas por las opciones -r*, que permiten un control mucho más detallado sobre las etapas de compilación a ejecutar.

DEPENDENCIAS DE COMPILACIÓN DINÁMICAS

Cuando se ejecuta la etapa %generate_buildrequires y algunas de las dependencias de compilación recién generadas no están satisfechas, rpmbuild crea un paquete fuente intermedio que termina en buildreqs.nosrc.rpm, el cual tiene las nuevas dependencias de compilación, y sale con el código 11. Este paquete se puede usar en lugar del paquete fuente original para resolver e instalar las dependencias de compilación faltantes de la manera habitual, por ejemplo, con dnf-builddep(8).

Pueden existir múltiples capas de dependencias de compilación dinámicas en un archivo de especificación; la presencia de dependencias de compilación específicas en el sistema puede generar nuevas dependencias de compilación la próxima vez que se realice una compilación con el mismo paquete fuente. La forma más fácil de asegurar que todas las dependencias de compilación dinámicas estén satisfechas es ejecutar la opción -br, instalar las nuevas dependencias del paquete buildreqs.nosrc.rpm y repetir todo el procedimiento hasta que rpmbuild ya no salga con el código 11.

Si el comando -br se combina con --nodeps, siempre se devuelve el código de salida 11 y siempre se crea un paquete buildreqs.nosrc.rpm.

SHOWRC

El comando

rpmbuild --showrc

muestra los valores que rpmbuild utilizará para todas las opciones que estén configuradas actualmente en los archivos de configuración rpmrc y macros.
