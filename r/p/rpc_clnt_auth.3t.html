RPC_CLNT_AUTH(3) Manual de funciones de biblioteca RPC_CLNT_AUTH(3)

NOMBRE

auth_destroy, authnone_create, authsys_create, authsys_create_default — rutinas de biblioteca para autenticación de llamadas a procedimiento remoto del lado del cliente

SINOPSIS

#include <rpc/rpc.h>

void
auth_destroy(AUTH *auth);

AUTH *
authnone_create(void);

AUTH *
authsys_create(const char *host, const uid_t uid, const gid_t gid, const int len, const gid_t *aup_gids);

AUTH *
authsys_create_default(void);

DESCRIPCIÓN

Estas rutinas forman parte de la biblioteca RPC que permite a los programas del lenguaje C realizar llamadas a procedimientos en otras máquinas a través de la red, con la autenticación deseada.

Estas rutinas normalmente se llaman después de crear el manejador CLIENT. El campo cl_auth de la estructura CLIENT debe inicializarse con la estructura AUTH devuelta por alguna de las siguientes rutinas. La información de autenticación del cliente se pasa al servidor cuando se realiza la llamada RPC.

Solo se discuten aquí los estilos de autenticación NULL y SYS.

Rutinas

auth_destroy()
Una macro de función que destruye la información de autenticación asociada con auth. La destrucción generalmente implica la desasignación de estructuras de datos privadas. El uso de auth no está definido después de llamar a auth_destroy().
authnone_create()
Crea y devuelve un manejador de autenticación RPC que pasa información de autenticación no utilizable con cada llamada a procedimiento remoto. Esta es la autenticación predeterminada utilizada por RPC.
authsys_create()
Crea y devuelve un manejador de autenticación RPC que contiene información de autenticación AUTH_SYS. El argumento host es el nombre de la máquina en la que se creó la información; uid es el ID de usuario del usuario; gid es el ID de grupo actual del usuario; len y aup_gids se refieren a una matriz contada de grupos a los que pertenece el usuario.
authsys_create_default()
Llama a authsys_create() con los argumentos apropiados.

DISPONIBILIDAD

Estas funciones forman parte de libtirpc.

VER TAMBIÉN

rpc(3), rpc_clnt_calls(3), rpc_clnt_create(3)
