RPCINFO(8) Manual del Administrador del Sistema RPCINFO(8)

NOMBRE

rpcinfo — reportar información RPC

SINOPSIS

rpcinfo [-m | -s] [host]

rpcinfo -p [host]

rpcinfo -T transporte host prognum [versnum]

rpcinfo -l [-T transporte] host prognum versnum

rpcinfo [-n numeropuerto] -u host prognum [versnum]

rpcinfo [-n numeropuerto] [-t] host prognum [versnum]

rpcinfo -a direccion_serv -T transporte prognum [versnum]

rpcinfo -b [-T transporte] prognum versnum

rpcinfo -d [-T transporte] prognum versnum

DESCRIPCIÓN

rpcinfo realiza una llamada RPC a un servidor RPC y reporta lo que encuentra.

En la primera sinopsis, rpcinfo lista todos los servicios RPC registrados con rpcbind en host. Si no se especifica host, el host local es el predeterminado. Si se usa -s, la información se muestra en un formato conciso.

En la segunda sinopsis, rpcinfo lista todos los servicios RPC registrados con rpcbind, versión 2. Tenga en cuenta también que el formato de la información es diferente en la primera y la segunda sinopsis. Esto se debe a que la segunda sinopsis utiliza un protocolo más antiguo para recopilar la información mostrada (versión 2 del protocolo rpcbind).

La tercera sinopsis realiza una llamada RPC al procedimiento 0 de prognum y versnum en el host especificado y reporta si se recibió una respuesta. transporte es el transporte que se debe utilizar para contactar el servicio dado. La dirección remota del servicio se obtiene realizando una llamada al rpcbind remoto.

El argumento prognum es un número que representa un número de programa RPC. Si se especifica un versnum, rpcinfo intenta llamar a esa versión del prognum especificado. De lo contrario, rpcinfo intenta encontrar todos los números de versión registrados para el prognum especificado llamando a la versión 0, que se presume que no existe; si existe, rpcinfo intenta obtener esta información llamando a un número de versión extremadamente alto en su lugar, e intenta llamar a cada versión registrada. Nota: el número de versión es requerido para las opciones -b y -d.

OPCIONES

-T transporte
Especifica el transporte en el que se requiere el servicio. Si esta opción no se especifica, rpcinfo utiliza el transporte especificado en la variable de entorno NETPATH, o si esta no está definida o está vacía, se utiliza el transporte de la base de datos netconfig(5). Esta es una opción genérica y se puede usar en conjunción con otras opciones como se muestra en la SINOPSIS.
-a direccion_serv
Usa direccion_serv como la dirección (universal) para el servicio en transporte para hacer ping al procedimiento 0 del prognum especificado y reportar si se recibió una respuesta. La opción -T es requerida con la opción -a.

Si no se especifica versnum, rpcinfo intenta hacer ping a todos los números de versión disponibles para ese número de programa. Esta opción evita las llamadas a rpcbind remoto para encontrar la dirección del servicio. La direccion_serv se especifica en formato de dirección universal del transporte dado.

-b
Realiza una difusión RPC al procedimiento 0 del prognum y versnum especificados y reporta todos los hosts que responden. Si se especifica transporte, difunde su solicitud solo en el transporte especificado. Si algún transporte no soporta la difusión, se imprime un mensaje de error. El uso de la difusión debe limitarse debido al potencial efecto adverso en otros sistemas.
-d
Elimina el registro del servicio RPC del prognum y versnum especificados. Si se especifica transporte, anula el registro del servicio solo en ese transporte; de lo contrario, anula el registro del servicio en todos los transportes en los que estaba registrado. Solo el propietario de un servicio puede eliminar un registro, excepto el superusuario que puede eliminar cualquier servicio.
-l
Muestra una lista de entradas con un prognum y versnum dados en el host especificado. Se devuelven entradas para todos los transportes en la misma familia de protocolos que la utilizada para contactar al rpcbind remoto.
-m
Muestra una tabla de estadísticas de operaciones de rpcbind en el host dado. La tabla muestra estadísticas para cada versión de rpcbind (versiones 2, 3 y 4), indicando cuántas veces se solicitó y se atendió cada procedimiento, el número y tipo de solicitudes de llamada remota que se realizaron, e información sobre las búsquedas de direcciones RPC que se manejaron. Esto es útil para monitorear actividades RPC en host.
-n numeropuerto
Usa numeropuerto como el número de puerto para las opciones -t y -u en lugar del número de puerto proporcionado por rpcbind. El uso de esta opción evita una llamada al rpcbind remoto para averiguar la dirección del servicio. Esta opción se vuelve obsoleta por la opción -a.
-p
Sondea rpcbind en host usando la versión 2 del protocolo rpcbind, y muestra una lista de todos los programas RPC registrados. Si no se especifica host, se usa el host local por defecto. Nota: La versión 2 del protocolo rpcbind se conocía anteriormente como el protocolo portmapper.

OPTIONS

-s
Reproducir una lista concisa de todos los programas RPC registrados en host. Si no se especifica host, se utiliza el host local por defecto.
-t
Realizar una llamada RPC al procedimiento 0 de prognum en el host especificado usando TCP e informar si se recibió una respuesta. Esta opción está obsoleta por la opción -T, como se muestra en la tercera sinopsis.
-u
Realizar una llamada RPC al procedimiento 0 de prognum en el host especificado usando UDP e informar si se recibió una respuesta. Esta opción está obsoleta por la opción -T, como se muestra en la tercera sinopsis.

EJEMPLOS

Para mostrar todos los servicios RPC registrados en la máquina local, use:

ejemplo% rpcinfo

Para mostrar todos los servicios RPC registrados con rpcbind en la máquina llamada klaxon, use:

ejemplo% rpcinfo klaxon

La información mostrada por los comandos anteriores puede ser bastante extensa. Utilice la opción -s para mostrar una lista más concisa:

ejemplo$ rpcinfo -s klaxon
programa versión(es) id. red(es) servicio propietario
100000 2,3,4 local,tcp,udp,tcp6,udp6 rpcbind superusuario
100008 1 udp,tcp,udp6,tcp6 walld superusuario
100002 2,1 udp,udp6 rusersd superusuario
100001 2,3,4 udp,udp6 rstatd superusuario
100012 1 udp,tcp sprayd superusuario
100007 3 udp,tcp ypbind superusuario

Para mostrar si el servicio RPC con el número de programa prognum y versión versnum está registrado en la máquina llamada klaxon para el transporte TCP, use:

ejemplo% rpcinfo -T tcp klaxon prognum versnum

Para mostrar todos los servicios RPC registrados con la versión 2 del protocolo rpcbind en la máquina local, use:

ejemplo% rpcinfo -p

Para eliminar el registro de la versión 1 del servicio walld (número de programa 100008) para todos los transportes, use:

ejemplo# rpcinfo -d 100008 1

o

ejemplo# rpcinfo -d walld 1
