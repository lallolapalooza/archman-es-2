NOMBRE

rpmkeys - Anillo de claves RPM

SINOPSIS

rpmkeys {--list|--import|--delete|--checksig}

DESCRIPCIÓN

Las formas generales de los comandos de firma digital de rpm(8) son:

rpmkeys --list [HASH_DE_CLAVE ...]

rpmkeys --import CLAVE_PÚBLICA ...

rpmkeys --delete HASH_DE_CLAVE ...

rpmkeys {-K|--checksig} ARCHIVO_DE_PAQUETE ...

La opción --checksig verifica todos los resúmenes y firmas contenidos en ARCHIVO_DE_PAQUETE para garantizar la integridad y el origen del paquete. Tenga en cuenta que las firmas ahora se verifican cada vez que se lee un paquete, y --checksig es útil para verificar todos los resúmenes y firmas asociados con un paquete.

Las firmas digitales no se pueden verificar sin una clave pública. Una clave pública cifrada en ASCII se puede agregar a la base de datos de rpm usando --import. Una clave pública importada se lleva en una cabecera, y la gestión del anillo de claves se realiza exactamente como la gestión de paquetes. Por ejemplo, todas las claves públicas actualmente importadas se pueden mostrar mediante:

rpm -q gpg-pubkey

Una forma más conveniente de mostrarlas es:

rpmkeys --list

Se pueden mostrar más detalles sobre una clave pública específica, una vez importada, consultando. Aquí hay información sobre la clave GPG/DSA de Red Hat:

rpm -qi gpg-pubkey-db42a60e

Finalmente, las claves públicas se pueden borrar después de importarlas, al igual que los paquetes. Así es como se elimina la clave GPG/DSA de Red Hat:

rpmkeys --delete db42a60e

O alternativamente:

rpm -e gpg-pubkey-db42a60e
