NOMBRE

rpc_gss_set_defaults — establecer el servicio y la calidad de protección

SINOPSIS

#include <rpc/rpcsec_gss.h>

bool_t
rpc_gss_set_defaults(AUTH *auth, rpc_gss_service_t service, const char *qop);

DESCRIPCIÓN

Establece el tipo de servicio y la calidad de protección que se utilizarán para las solicitudes RPC. Los nuevos valores se aplican durante el resto de la vida del contexto (a menos que se cambien de nuevo con esta función).

PARÁMETROS

service
El tipo de servicio a utilizar para las solicitudes RPC subsiguientes.
qop
La calidad de protección a utilizar o NULL para la predeterminada.

VALORES DE RETORNO

Devuelve TRUE si los valores se establecieron correctamente.

DISPONIBILIDAD

La función rpc_gss_set_defaults() forma parte de libtirpc.

VER TAMBIÉN

rpc(3), gssapi(3), rpcsec_gss(3)
