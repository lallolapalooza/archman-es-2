RPASTE(1) Comandos de usuario RPASTE(1)

NOMBRE

rpaste - una herramienta CLI para rustypaste

SINOPSIS

rpaste [OPCIONES] <ARCHIVO(s)>

OPCIONES

-h, --help
muestra la información de ayuda
-v, --version
muestra la información de la versión
-V, --server-version
recupera la versión del servidor
-l, --list
lista los archivos en el servidor
-d, --delete
elimina archivos del servidor
-o, --oneshot
genera enlaces de un solo uso
-p, --pretty
embellece la salida

-c, --config CONFIG establece el archivo de configuración

-s, --server SERVER establece la dirección del servidor rustypaste

-a, --auth TOKEN
establece el token de autenticación
-u, --url URL
establece la URL a acortar
-r, --remote URL
establece la URL remota para subir
-e, --expire TIME
establece el tiempo de expiración del enlace
-n, --filename NAME
establece y sobrescribe el nombre de archivo

CONFIGURACIÓN

Se puede usar un archivo TOML para configurar los ajustes de rpaste.

[server]
  • address: dirección del servidor rustypaste
  • auth_token: token de autenticación
[paste]
  • oneshot: genera enlaces de un solo uso si se establece a true
  • expire: tiempo de expiración para los enlaces
[style]
•
prettify: embellece la salida si se establece a true
