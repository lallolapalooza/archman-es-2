RPC_GSS_IS_INSTALLED(3) Manual de funciones de la biblioteca RPC_GSS_IS_INSTALLED(3)

NOMBRE

rpc_gss_is_installed — Consulta la presencia de un mecanismo de seguridad

SINOPSIS

#include <rpc/rpcsec_gss.h>

bool_t
rpc_gss_is_installed(const char *mech);

DESCRIPCIÓN

Esta función indica si el mecanismo GSS_API llamado "mech" está instalado y habilitado.

PARÁMETROS

mech
El nombre de un mecanismo GSS_API. Actualmente, "kerberos_v5" es el único mecanismo soportado.

VALORES DE RETORNO

Devuelve TRUE si el mecanismo GSS_API nombrado está instalado y habilitado, FALSE en caso contrario.

DISPONIBILIDAD

La función rpc_gss_is_installed() forma parte de libtirpc.

VER TAMBIÉN

rpc(3), gssapi(3), rpcsec_gss(3)
