NOMBRE

rpc_gss_max_data_length — calcula el tamaño máximo de datos

SINOPSIS

#include <rpc/rpcsec_gss.h>

int
rpc_gss_max_data_length(AUTH *auth, int max_tp_unit_len);

DESCRIPCIÓN

Calcula el tamaño máximo de mensaje que cabrá en un paquete de tamaño max_tp_unit_len, dados el servicio actual y la configuración de QoP (Calidad de Protección).

PARÁMETROS

auth
Un manejador para el contexto de seguridad RPCSEC_GSS
max_tp_unit_len
Tamaño máximo del paquete del protocolo de transporte subyacente

VALORES DE RETORNO

El tamaño máximo del mensaje que se puede codificar.

DISPONIBILIDAD

La función rpc_gss_max_data_length() es parte de libtirpc.

VER TAMBIÉN

rpc(3), gssapi(3), rpcsec_gss(3)
