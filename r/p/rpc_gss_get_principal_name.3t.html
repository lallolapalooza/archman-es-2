RPC_GSS_GET_PRINCIPAL_NAME(3) Manual de funciones de biblioteca RPC_GSS_GET_PRINCIPAL_NAME(3)

NOMBRE

rpc_gss_get_principal_name — Obtener un nombre de principal

SINOPSIS

#include <rpc/rpcsec_gss.h>

bool_t
rpc_gss_get_principal_name(rpc_gss_principal_t *principal, const char *mech, const char *name, const char *node, const char *domain);

DESCRIPCIÓN

Esta función se puede utilizar para generar un nombre de principal de cliente a partir de varias cadenas.

PARÁMETROS

principal
Si el principal se crea con éxito, *principal se establecerá para apuntar al nuevo principal en el formato de nombre exportado de la API GSS.
mech
El nombre del mecanismo para este principal.
name
La parte del nombre del principal.
node
Si no es nulo, la parte del nombre de host o instancia del principal.
domain
Si no es nulo, la parte del dominio o reino del principal.

VALORES DE RETORNO

Devuelve TRUE si el principal se creó o FALSE en caso contrario.

DISPONIBILIDAD

La función rpc_gss_get_principal_name() es parte de libtirpc.

VER TAMBIÉN

rpc(3), gssapi(3), gss_export_name(3), rpcsec_gss(3)
