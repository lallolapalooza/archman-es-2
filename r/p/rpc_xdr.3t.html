RPC_XDR(3) Manual de funciones de biblioteca RPC_XDR(3)

NOMBRE

xdr_accepted_reply, xdr_authsys_parms, xdr_callhdr, xdr_callmsg, xdr_opaque_auth, xdr_rejected_reply, xdr_replymsg — Rutinas de la biblioteca XDR para llamadas a procedimientos remotos

SINOPSIS

#include <rpc/rpc.h>

bool_t
xdr_accepted_reply(XDR *xdrs, struct accepted_reply *ar);

bool_t
xdr_authsys_parms(XDR *xdrs, struct authsys_parms *aupp);

bool_t
xdr_callhdr(XDR *xdrs, struct rpc_msg *chdr);

bool_t
xdr_callmsg(XDR *xdrs, struct rpc_msg *cmsg);

bool_t
xdr_opaque_auth(XDR *xdrs, struct opaque_auth *ap);

bool_t
xdr_rejected_reply(XDR *xdrs, struct rejected_reply *rr);

bool_t
xdr_replymsg(XDR *xdrs, struct rpc_msg *rmsg);

DESCRIPCIÓN

Estas rutinas se utilizan para describir los mensajes RPC en el lenguaje XDR. Normalmente deberían ser utilizadas por aquellos que no desean utilizar el paquete RPC directamente. Estas rutinas devuelven TRUE si tienen éxito, FALSE en caso contrario.

Rutinas

Vea rpc(3) para la definición de la estructura de datos XDR.

xdr_accepted_reply()
Se utiliza para traducir entre mensajes de respuesta RPC y su representación externa. Incluye el estado de la llamada RPC en formato de lenguaje XDR. En caso de éxito, también incluye los resultados de la llamada.
xdr_authsys_parms()
Se utiliza para describir las credenciales del sistema operativo UNIX. Incluye el nombre de la máquina, uid, lista de gid, etc.
xdr_callhdr()
Se utiliza para describir los mensajes de cabecera de llamada RPC. Codifica la parte estática de la cabecera del mensaje de llamada en formato de lenguaje XDR. Incluye información como el ID de transacción, el número de versión RPC, el programa y el número de versión.
xdr_callmsg()
Se utiliza para describir los mensajes de llamada RPC. Esto incluye toda la información de la llamada RPC, como el ID de transacción, el número de versión RPC, el número de programa, el número de versión, la información de autenticación, etc. Esto lo suelen utilizar los servidores para determinar información sobre la llamada RPC del cliente.
xdr_opaque_auth()
Se utiliza para describir los mensajes de información de autenticación opaca RPC.
xdr_rejected_reply()
Se utiliza para describir los mensajes de respuesta RPC. Codifica el mensaje RPC rechazado en formato de lenguaje XDR. El mensaje puede ser rechazado debido a una discrepancia en el número de versión o debido a errores de autenticación.
xdr_replymsg()
Se utiliza para describir los mensajes de respuesta RPC. Traduce entre el mensaje de respuesta RPC y su representación externa. Esta respuesta puede ser una aceptación, un rechazo o NULL.

DISPONIBILIDAD

Estas funciones forman parte de libtirpc.
