RPC_GSS_SECCREATE(3) Manual de funciones de biblioteca RPC_GSS_SECCREATE(3)

NOMBRE

rpc_gss_seccreate — crea un contexto de seguridad utilizando el protocolo RPCSEC_GSS

SINOPSIS

#include <rpc/rpcsec_gss.h>

AUTH *
rpc_gss_seccreate(CLIENT *clnt, const char *principal, const char *mechanism, rpc_gss_service_t service, const char *qop, rpc_gss_options_req_t *options_req, rpc_gss_options_ret_t *options_ret);

DESCRIPCIÓN

Esta función se utiliza para establecer un contexto de seguridad entre una aplicación y un par remoto utilizando el protocolo RPSEC_GSS.

PARÁMETROS

clnt
Un manejador RPC que está conectado al par remoto.
principal
El nombre del principal de servicio en el par remoto. Por ejemplo, un principal como "nfs@server.example.com" podría ser utilizado por una aplicación que necesita contactar a un servidor NFS.
mechanism
El nombre del mecanismo GSS_API a utilizar para el nuevo contexto de seguridad. Actualmente, "kerberos_v5" es el único mecanismo soportado.
service
Tipo de servicio solicitado.
rpc_gss_svc_default
El predeterminado, típicamente el mismo que rpc_gss_svc_none.
rpc_gss_svc_none
Solo las cabeceras RPC están protegidas contra manipulación mediante una suma de verificación.
rpc_gss_svc_integrity
Las cabeceras y datos RPC están protegidos contra manipulación mediante una suma de verificación.
rpc_gss_svc_privacy
Las cabeceras RPC están protegidas contra manipulación mediante una suma de verificación y los datos están cifrados.
qop
El nombre de la Calidad de Protección (QOP) a utilizar para el nuevo contexto de seguridad, o NULL para usar el QOP predeterminado. Actualmente, "GSS_C_QOP_DEFAULT" es el único QOP soportado.
options_req
Opciones adicionales del contexto de seguridad a pasar al mecanismo GSS-API subyacente. Pase NULL para proporcionar valores predeterminados.
options_ret
Varios valores devueltos por el mecanismo GSS-API subyacente. Pase NULL si estos valores no son necesarios.

VALORES DE RETORNO

Si el contexto de seguridad se creó con éxito, se devuelve un puntero a una estructura AUTH que representa el contexto. Para utilizar este contexto de seguridad en llamadas RPC posteriores, establezca clnt->cl_auth a este valor.

DISPONIBILIDAD

La función rpc_gss_seccreate() forma parte de libtirpc.

VER TAMBIÉN

rpc(3), gssapi(3), mech(5), qop(5), rpcsec_gss(3)
