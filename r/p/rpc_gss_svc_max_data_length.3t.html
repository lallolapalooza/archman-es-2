NOMBRE

rpc_gss_svc_max_data_length — calcular el tamaño máximo de datos

SINOPSIS

#include <rpc/rpcsec_gss.h>

int
rpc_gss_svc_max_data_length(struct svc_req *req, int max_tp_unit_len);

DESCRIPCIÓN

Calcula el tamaño máximo del mensaje que cabe en un paquete de tamaño max_tp_unit_len, dados el servicio actual y la configuración de QoP (Calidad de Servicio).

PARÁMETROS

req
Una solicitud RPC
max_tp_unit_len
Tamaño máximo del paquete del protocolo de transporte subyacente

VALORES DEVUELTOS

El tamaño máximo del mensaje que se puede codificar.

DISPONIBILIDAD

La función rpc_gss_svc_max_data_length() es parte de libtirpc.

VER TAMBIÉN

rpc(3), gssapi(3), rpcsec_gss(3)
