rpcdebug(8) Manual del Administrador del Sistema rpcdebug(8)

NOMBRE

rpcdebug - establecer y borrar banderas de depuración del kernel de NFS y RPC

SINOPSIS

rpcdebug -vh
rpcdebug -m módulo
rpcdebug -m módulo -s banderas...
rpcdebug -m módulo -c banderas...

DESCRIPCIÓN

El comando rpcdebug permite a un administrador establecer y borrar las banderas de depuración del cliente y servidor NFS del kernel de Linux. Establecer estas banderas hace que el kernel emita mensajes al registro del sistema en respuesta a la actividad de NFS; esto es típicamente útil al depurar problemas de NFS.

La primera forma en la sinopsis se puede usar para listar todas las banderas de depuración disponibles. La segunda forma muestra las banderas de depuración actualmente establecidas para el módulo dado. La tercera forma establece una o más banderas, y la cuarta forma borra una o más banderas.

El valor all puede usarse para establecer o borrar todas las banderas para el módulo dado.

OPCIONES

-c
Borra las banderas de depuración dadas.
-h
Imprime un mensaje de ayuda y sale. Cuando se combina con la opción -v, también imprime las banderas de depuración disponibles.
-m módulo
Especifica qué banderas del módulo establecer o borrar. Los módulos disponibles son:
nfsd
El servidor NFS.
nfs
El cliente NFS.
nlm
El gestor de bloqueo de red, en un cliente o servidor NFS.
rpc
El módulo de llamada a procedimiento remoto, en un cliente o servidor NFS.
-s
Establece las banderas de depuración dadas.
-v
Aumenta la verbosidad de la salida de rpcdebug.

ARCHIVOS

/proc/sys/sunrpc/{rpc,nfs,nfsd,nlm}_debug
Interfaz basada en procfs para las banderas de depuración del kernel.

VER TAMBIÉN

rpc.nfsd(8), nfs(5), syslogd(8).

ERRORES

Los errores se pueden encontrar o reportar en http://nfs.sf.net/.
