NOMBRE

rping - Prueba de conexión RDMA CM y ping-pong RDMA.

SINOPSIS

rping -s [-v] [-V] [-d] [-P] [-a dirección] [-p puerto]
		[-C número_mensajes] [-S tamaño_mensaje]
rping -c [-v] [-V] [-d] [-I dirección] -a dirección [-p puerto]
		[-C número_mensajes] [-S tamaño_mensaje]

DESCRIPCIÓN

Establece una conexión RDMA fiable entre dos nodos utilizando librdmacm, realiza opcionalmente transferencias RDMA entre los nodos y luego se desconecta.

OPCIONES

-s
Ejecutar como servidor.
-c
Ejecutar como cliente.
-a dirección
En el servidor, especifica la dirección de red a la que vincular la conexión. Para vincular a cualquier dirección con IPv6, use -a ::0. En el cliente, especifica la dirección del servidor a la que conectarse.
-I dirección
La dirección a la que vincularse como dirección IP de origen a utilizar. Esto es útil si tiene varias direcciones en la misma red o enrutamientos complejos.
-p
Número de puerto para el servidor de escucha.
-v
Mostrar datos de ping.
-V
Validar datos de ping.
-d
Mostrar información de depuración.
-C número_mensajes
El número de mensajes a transferir por cada conexión. (predeterminado: infinito)
-S tamaño_mensaje
El tamaño de cada mensaje transferido, en bytes. (predeterminado: 100)
-P
Ejecutar el servidor en modo persistente. Esto permite que múltiples clientes rping se conecten a una única instancia de servidor. El servidor se ejecutará hasta que se mate.
-q
Controlar la creación/modificación de QP directamente desde la aplicación, en lugar de rdma_cm.

NOTAS

Dado que esta prueba mapea recursos RDMA al espacio de usuario, los usuarios deben asegurarse de que disponen de los recursos del sistema y los permisos necesarios. Consulte el archivo README de libibverbs para obtener más detalles.
