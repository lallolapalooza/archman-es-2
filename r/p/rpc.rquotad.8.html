RQUOTAD(8) Manual del Administrador del Sistema RQUOTAD(8)

NOMBRE

rpc.rquotad - servidor de cuotas remoto

SINOPSIS

/usr/sbin/rpc.rquotad [ -FI ] [ -p puerto ] [ -s | -S ] [ -x ruta ]

/usr/sbin/rpc.rquotad [ -h | -V ]

DESCRIPCIÓN

rpc.rquotad es un servidor rpc(3) que devuelve las cuotas de un usuario de un sistema de archivos local que está montado por una máquina remota a través de NFS. También permite establecer cuotas en sistemas de archivos montados por NFS (si se configuró durante la compilación y se permite mediante la opción de línea de comandos -S). Los resultados son utilizados por quota(1) para mostrar las cuotas de usuario para sistemas de archivos remotos y por edquota(8) para establecer cuotas en sistemas de archivos remotos. El demonio rquotad utiliza la biblioteca de tcp-wrappers (con el nombre de servicio rquotad) que le permite especificar qué hosts tienen permiso/no tienen permiso para usar el demonio (ver el manual de hosts.allow(5) para más información). El demonio rquotad normalmente se inicia al arrancar el sistema desde los scripts de inicio del sistema.

OPCIONES

-h, --ayuda
Muestra el uso del programa y sale. -V, --version Muestra la versión de las herramientas de cuotas.
-s, --no-setquota
No permite establecer cuotas (predeterminado). Esta opción solo está disponible si las utilidades fueron compiladas con la opción rpcsetquota.
-S, --setquota
Permite establecer cuotas. Esta opción solo está disponible si las utilidades fueron compiladas con la opción rpcsetquota.
-F, --foreground
Ejecuta el demonio en primer plano (puede ser útil para depuración).
-I, --autofs
No ignora los puntos de montaje de autofs.
-p puerto, --port puerto
Escucha en el puerto alternativo puerto.
-x ruta, --xtab ruta
Establece un archivo alternativo con la tabla de exportación de NFSD. Este archivo se utiliza para determinar la pseudoraíz de las exportaciones NFSv4. La pseudoraíz se antepondrá a cada ruta relativa (es decir, una ruta que no comience con '/') recibida en una solicitud RPC de cuota.

ARCHIVOS

aquota.user o aquota.group
archivo de cuota en la raíz del sistema de archivos (cuota versión 2, sistemas de archivos que no son XFS)
quota.user o quota.group
archivo de cuota en la raíz del sistema de archivos (cuota versión 1, sistemas de archivos que no son XFS)
/etc/mtab
sistemas de archivos predeterminados
