RYGEL.CONF(5) Rygel User Manual RYGEL.CONF(5)

NOMBRE

rygel.conf - Archivo de configuración de Rygel

SINOPSIS

$XDG_CONFIG_DIR/rygel.conf

/etc/rygel.conf

DESCRIPCIÓN

rygel lee sus valores de configuración del archivo $XDG_CONFIG_DIR/rygel.conf o de un archivo proporcionado en la línea de comandos con la opción --config. Si ese archivo no existe, utiliza el archivo /etc/rygel.conf.

La mayoría de las opciones pueden ser anuladas por argumentos de la línea de comandos o variables de entorno. Consulte rygel(1) para más detalles sobre ellas.

DIRECTIVAS GENERALES

Las listas en los archivos de configuración están separadas por punto y coma (;). Los valores booleanos pueden ser true o false.

ipv6

Establecer a false para deshabilitar la vinculación a direcciones IPv6

interface=INTERFACE

Lista separada por punto y coma de las interfaces de red en las que rygel debe escuchar. Puede ser una IP, un nombre de interfaz o, en Linux, incluso el ESSID de una red inalámbrica.

port=PORT

Establece el puerto de escucha.

enable-transcoding

Establecer a true para habilitar la transcodificación en general.

log-level=DOMAIN:LEVEL[,DOMAIN:LEVEL,...]

Lista separada por comas de pares DOMAIN:LEVEL, lo que permite establecer el nivel de registro individualmente para cada dominio, donde DOMAIN es "*", "rygel" o el nombre de un plugin. Los niveles de registro permitidos son 1=error, 2=crítico, 3=advertencia, 4=mensaje/información, 5=depuración. Tenga en cuenta que en las versiones recientes de GLib (>= 2.36) se requiere establecer la variable de entorno G_MESSAGES_DEBUG a all para obtener cualquier salida de depuración.

plugin-path=PATH

Establece la ruta de búsqueda de plugins.

engine-path=PATH

Establece la ruta de búsqueda del motor.

media-engine=ENGINE

Nombre del módulo cargable a utilizar como backend del motor multimedia.

allow-upload

Permitir la carga de archivos multimedia a través de UPnP.

allow-deletion

Permitir la eliminación remota de archivos multimedia a través de UPnP.

video-upload-folder

Si allow-upload es true, utilice esta carpeta para almacenar los vídeos cargados. Por defecto es @VIDEOS@, que se expande al directorio predeterminado para archivos de vídeo (normalmente $HOME/Videos).

music-upload-folder

Si allow-upload es true, utilice esta carpeta para almacenar los archivos de música cargados. Por defecto es @MUSIC@, que se expande al directorio predeterminado para archivos de música (normalmente $HOME/Music).

picture-upload-folder

Si allow-upload es true, utilice esta carpeta para almacenar las imágenes cargadas. Por defecto es @PICTURES@, que se expande al directorio predeterminado para archivos de imagen (normalmente $HOME/Pictures).

force-downgrade-for

Lista separada por punto y coma de user-agents de dispositivos (o partes de ellos) que necesitan una degradación forzada a MediaServer:1 y/o ContentDirectory:1.

Advertencia
Utilice este parámetro solo si sabe lo que está haciendo o se le indica que lo haga; anular el valor predeterminado puede causar incompatibilidades. Si descubre que añadir su dispositivo aquí permite su uso con Rygel, por favor presente un bug de IOP[1] para que podamos incluirlo en la configuración predeterminada.

acl-fallback-policy

Esta es la política predeterminada que se utiliza si no se encuentra ningún proveedor de control de acceso en D-Bus. Utilice true para permitir el acceso desde cualquier par, false para denegar todo el acceso. Si no se especifica, la política de fallback predeterminada es true.

strict-dlna

Deshabilitado por defecto. Utilice true para deshabilitar un conjunto de características que mejoran la compatibilidad con muchos clientes, pero rompen la conformidad con el estándar.

CONFIGURACIÓN DE LA BASE DE DATOS

Los ajustes en la sección [Database] son para la biblioteca de soporte de base de datos.

debug

Establecer a true para mostrar las sentencias SQL utilizadas.

CONFIGURACIÓN DEL MOTOR MULTIMEDIA GSTREAMER

Los ajustes en la sección [GstMediaEngine] son específicos del motor multimedia GStreamer, que es el motor multimedia predeterminado. Consulte el ajuste media-engine. Las siguientes opciones están disponibles para el motor multimedia GStreamer[2].

transcoders

Una lista separada por punto y coma de los transcodificadores activos. Este ajuste no tiene ningún efecto si enable-transcoding está establecido en false. Los valores posibles son: lpcm,mp3,mp2ts,aac,avc o wmv. Su valor predeterminado es lpcm;mp3;mp2ts;aac;wmv.

CONFIGURACIÓN ESPECÍFICA DE PLUGIN

Las secciones para plugins se denotan con [NombrePlugin] y pueden contener opciones específicas de un plugin (ver abajo) así como estas opciones comunes:

title=TÍTULO

Título del dispositivo implementado por este plugin. Hay algunas variables que serán reemplazadas por rygel. @REALNAME@ será sustituido por el nombre real del usuario, @USERNAME@ por el ID de inicio de sesión del usuario y @HOSTNAME@ por el nombre de la máquina en la que se ejecuta rygel.

enabled

Puede habilitar o deshabilitar plugins individualmente estableciéndolo en true o false.

energy-management

Establecer a true si desea que el dispositivo UPnP contenga un servicio de Gestión de Energía (EnergyManagement). Tenga en cuenta que se requiere configuración adicional, consulte la configuración de EnergyManagement.

diagnostics

Establecer a true si desea que el dispositivo UPnP contenga un servicio BasicManagement:2 que permita ejecutar herramientas como ping, nslookup y traceroute de forma remota.

server-name

Una cadena que se enviará como la cabecera "Server:" en una respuesta HTTP.

CONFIGURACIÓN DE GESTIÓN DE ENERGÍA

Los ajustes en las secciones [EnergyManagement-IFACENAME] especifican los ajustes relacionados con los servicios de Gestión de Energía en esta interfaz. Ejemplo: [EnergyManagement-eth0].

mode-on-suspend

El modo de interfaz de red (NetworkInterfaceMode) que debe utilizarse al suspender. El valor predeterminado es "Unimplemented", otros valores válidos son "IP-up-Periodic”, "IP-down-no-Wake", "IP-down-with-WakeOn", "IP-down-with-WakeAuto", "IP-down-with-WakeOnAuto".

supported-transport

Opcional WakeSupportedTransport que el servicio debe anunciar. Los valores válidos son "UDP-Broadcast", "UDP-Unicast", "TCP-Unicast", "Other".

password

Contraseña hexadecimal opcional que se utilizará para construir el WakeOnPattern.

PLUGIN TRACKER

El plugin tracker utiliza la base de datos centralizada de información meta del proyecto tracker. Consulte la página web del proyecto tracker[3] para más información sobre tracker.

share-pictures

Habilitar o deshabilitar el uso compartido de todas las imágenes en la base de datos de Tracker.

share-videos

Habilitar o deshabilitar el uso compartido de todos los vídeos en la base de datos de Tracker.

share-music

Habilitar o deshabilitar el uso compartido de toda la música en la base de datos de Tracker.

PLUGIN MEDIAEXPORT

El plugin MediaExport es una alternativa a la exportación multimedia basada en tracker. Extrae metadatos por sí mismo y los almacena en una base de datos SQLite[4] en $XDG_CACHE_DIR/rygel/media-export.db en plataformas UNIX.

Este sitio no está asociado de ninguna forma con Arch Linux ni afiliado a este proyecto. El contenido es únicamente una traducción de las páginas del manual de Arch publicadas en man.archlinux.org.

>

Nota

Si ambos plugins, Tracker y MediaExport, están habilitados, MediaExport se deshabilitará en favor del plugin Tracker.

Este plugin admite varias opciones:

uris

Una lista de URIs a exponer a través de UPnP. Pueden ser archivos, carpetas o cualquier cosa compatible con GVFS. Si se deja vacío, por defecto exportará las carpetas de música, video y fotos del usuario, según lo definido por la especificación de directorios especiales de usuario de XDG. Estas carpetas predeterminadas se pueden referenciar con @MUSIC@, @PICTURES@ y @VIDEOS@. Las ubicaciones se pueden introducir como URIs completamente escapadas o rutas normales.

Nota
Si introduces una ruta normal que contiene espacios en blanco, no es necesario escaparlos con una barra invertida ni poner la cadena entre comillas.

Nota
Se desaconseja encarecidamente utilizar una carpeta exportada como destino para descargas cuando extract-metadata está habilitado. Rygel probablemente ignorará los archivos porque no podrá extraer metadatos.

Ejemplo 1. Valores posibles para uris

uris=@MUSIC@;/home/user/My Pictures;file:///home/user/My%20Videos

extract-metadata

Establécelo en false si no te importan la duración ni ningún otro metadato, como el artista. Esto acelera mucho el rastreo inicial de los medios. Úsalo para compartir rápidamente algunos archivos a través de UPnP. Asegúrate de definir un include-filter, de lo contrario, terminarás con muchos archivos expuestos que el cliente no podrá mostrar de todos modos.

monitor-changes

Establécelo en false si no quieres que rygel recoja automáticamente los archivos nuevos.

monitor-grace-timeout

Tiempo en segundos a esperar después de detectar un nuevo archivo antes de intentar extraer metadatos de él. Útil si estás descargando a un directorio monitorizado por rygel. El valor predeterminado es 5 segundos.

virtual-folders

Establécelo en false si no necesitas la jerarquía de carpetas virtuales.

PLUGIN PLAYBIN

El plugin Playbin implementa un reproductor multimedia (Digital Media Renderer, DMR en términos de DLNA). Este plugin se conocía anteriormente como GstRenderer.

Se recomienda encarecidamente dejar la elección del sink a playbin. Si, sin embargo, las opciones predeterminadas no funcionan para ti, se pueden reconfigurar de la siguiente manera:

audio-sink

Definición del sink de audio a utilizar. Puede ser un único elemento o una definición de pipeline parcial en la sintaxis de gst-launch.

video-sink

Definición del sink de video a utilizar. Puede ser un único elemento o una definición de pipeline parcial en la sintaxis de gst-launch.

PLUGIN LIGHTMEDIASCANNER

El plugin LightMediaScanner exporta el contenido del demonio lightmediascanner[5].

Este plugin no tiene opciones especiales.

PLUGIN GSTLAUNCH

El plugin GstLaunch permite exponer pipelines de GStreamer utilizando la misma sintaxis que la utilidad gst-launch. Puedes configurar varios elementos en este plugin.

launch-items

Una lista de identificadores para los pipelines que se van a exponer.

identifier-title

Título del dispositivo representado por este pipeline. Identifier es el identificador tal como se establece en launch-items.

identifier-mime

Tipo MIME del pipeline.

identifier-launch

Definición del pipeline en sintaxis gst-launch. Para ver algunos ejemplos sobre cómo escribir pipelines, consulta gst-launch(1).

identifier-dlnaprofile

Perfil DLNA para la transmisión.

Un ejemplo de configuración está disponible en el archivo de configuración distribuido /etc/rygel.conf.

EXTERNAL

El plugin External es un consumidor de la especificación de la interfaz DBus MediaServer2[6]. Esto permite que programas externos compartan sus datos a través de UPnP implementando esta especificación DBus. El plugin detecta cualquier implementación de esta interfaz en el bus de sesión y expone los medios presentados a través de UPnP. Los implementadores conocidos de esta especificación son gnome-dvb-daemon[7], Rhythmbox[8] y Grilo[9] a través del proyecto grilo-ms2.

Puedes deshabilitar toda la funcionalidad estableciendo enabled=false en la sección [External] del archivo de configuración.

Los peers individuales se pueden habilitar o deshabilitar creando secciones correspondientes a los nombres de D-Bus del peer:

[org.gnome.UPnP.MediaServer2.Rhythmbox]
enabled=false

Este plugin no tiene opciones adicionales.

MPRIS

El plugin MPRIS es un consumidor de la especificación de la interfaz DBus MPRIS2[10]. La implementación cumple con la versión 2.0 del estándar.

rygel expone los reproductores multimedia que implementan el lado del proveedor de esta especificación DBus como DLNA Digital Media Renderers (DMR), de manera similar al plugin Playbin. Esto significa que puedes convertir fácilmente tu reproductor multimedia en un DMR implementando esta especificación DBus.

Los reproductores que implementan esta especificación y se sabe que funcionan con rygel son Banshee[11], Rhythmbox[8] y GNOME Videos (anteriormente conocido como Totem)[12].

Puedes deshabilitar toda la funcionalidad estableciendo enabled=false en la sección [MRPIS] del archivo de configuración.

La configuración de este plugin es especial. La configuración del plugin no se realiza en el plugin, sino por cada peer que se encuentra proporcionando la interfaz MPRIS2. Consulta el siguiente ejemplo para establecer el título de Banshee en MPRIS:

[org.mpris.MediaPlayer2.banshee]
title=@REALNAME@'s Banshee on @HOSTNAME@

Este plugin no tiene opciones adicionales.

    NOMBRE

    rygel.conf — Archivo de configuración de Rygel

    DESCRIPCIÓN

    El archivo rygel.conf contiene la configuración para Rygel. Rygel busca este archivo en las siguientes ubicaciones, en orden:

    • El directorio de configuración específico del usuario, que normalmente es ~/.config/rygel.conf.
    • El directorio de configuración del sistema, que normalmente es /etc/rygel.conf.

    Si no se encuentra ningún archivo, se utilizará un conjunto de valores predeterminados.

    El archivo de configuración utiliza el formato INI. Los valores permitidos para cada opción se describen en las secciones siguientes.

    SECCIONES

    El archivo de configuración se divide en varias secciones. Cada sección se inicia con una cabecera entre corchetes, por ejemplo, [MediaExport].

    [MediaExport]

    Esta sección controla la exportación de medios.

    paths
    Una lista separada por comas de directorios que se deben compartir con la red. Por ejemplo: paths=/home/user/Music,/home/user/Videos.
    monitor_changes
    Un valor booleano (true o false) que indica si se deben monitorizar los cambios en los directorios compartidos. El valor predeterminado es true.
    recursive
    Un valor booleano (true o false) que indica si se deben incluir los subdirectorios de forma recursiva. El valor predeterminado es true.

    [Tracker]

    Esta sección controla el uso del plugin Tracker para la indexación de medios.

    use_tracker
    Un valor booleano (true o false) que indica si se debe utilizar el plugin Tracker. El valor predeterminado es false.

    [Opensubtitles]

    Esta sección controla la configuración del plugin de subtítulos.

    username
    Tu nombre de usuario de Opensubtitles.org.
    password
    Tu contraseña de Opensubtitles.org.
    max_language
    Un código de idioma de dos letras (por ejemplo, es para español) que especifica el idioma preferido para los subtítulos. El valor predeterminado es en.

    [Upnp]

    Esta sección controla la configuración de la red UPnP.

    friendly_name
    El nombre que se mostrará para este dispositivo Rygel en la red. El valor predeterminado es Rygel DLNA Server.
    port_range
    El rango de puertos que utilizará Rygel para la comunicación UPnP. Por ejemplo: port_range=5000-6000. El valor predeterminado es 5000-6000.
    interface_auto
    Un valor booleano (true o false) que indica si se deben detectar automáticamente las interfaces de red. Si es false, deberás especificar las interfaces en la opción interfaces. El valor predeterminado es true.
    interfaces
    Una lista separada por comas de las interfaces de red que Rygel debe utilizar. Por ejemplo: interfaces=eth0,wlan0. Esta opción solo se tiene en cuenta si interface_auto es false.

    [CorePlugins]

    Esta sección habilita o deshabilita plugins específicos en Rygel.

    media_export
    Un valor booleano (true o false) para habilitar o deshabilitar el plugin MediaExport. El valor predeterminado es true.
    tracker
    Un valor booleano (true o false) para habilitar o deshabilitar el plugin Tracker. El valor predeterminado es false.
    opensubtitles
    Un valor booleano (true o false) para habilitar o deshabilitar el plugin Opensubtitles. El valor predeterminado es false.

    [LIGHTMEDIASCANNER_PLUGIN]

    Configuración del plugin LightMediaScanner.

    watch_dirs
    Una lista separada por comas de directorios que el plugin debe monitorizar en busca de cambios. Por ejemplo: watch_dirs=/home/user/Music,/home/user/Pictures.

    [GSTLAUNCH_PLUGIN]

    Configuración del plugin GstLaunch.

    launch_lines
    Una lista separada por saltos de línea de órdenes de gst-launch-1.0 que se ejecutarán al iniciar Rygel. Cada orden debe ir en una línea separada y puede incluir comentarios precedidos por #.

    [EXTERNAL]

    Esta sección está reservada para plugins externos.

    [MPRIS]

    Configuración relacionada con el soporte de MPRIS (Media Player Remote Interfacing Specification).

    can_play
    Un valor booleano (true o false) que indica si Rygel puede iniciar la reproducción de medios a través de MPRIS. El valor predeterminado es true.

    [SEE_ALSO]

    Esta sección no es configurable; se refiere a comandos y archivos relacionados.

    [AUTHOR]

    Esta sección no es configurable; se refiere al autor del software.

    [NOTES]

    Notas adicionales sobre el archivo de configuración.

    Plugins
    Los plugins que no se mencionan explícitamente en el archivo de configuración se habilitan o deshabilitan según sus valores predeterminados. Puedes habilitar o deshabilitar plugins explícitamente en la sección [CorePlugins].
