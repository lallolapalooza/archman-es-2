RYGEL(1) Manual de Usuario de Rygel RYGEL(1)

NOMBRE

rygel - una colección de servicios DLNA/UPnP AV

SINOPSIS

rygel [opciones]

DESCRIPCIÓN

rygel es una solución de medios domésticos que permite compartir fácilmente audio, video e imágenes, y controlar reproductores multimedia en su red doméstica. En términos técnicos, es tanto un servidor multimedia UPnP AV como un renderizador multimedia implementado a través de un mecanismo de complementos. La interoperabilidad con otros dispositivos del mercado se logra mediante la conformidad con los requisitos muy estrictos de DLNA y la conversión de medios sobre la marcha a formatos que los dispositivos cliente son capaces de manejar.

OPCIONES

El programa sigue la sintaxis habitual de línea de comandos de GNU, con opciones largas que comienzan con dos guiones (`-'). A continuación se incluye un resumen de las opciones.

-h, --help

Muestra un resumen de las opciones.

--version

Muestra la versión del programa.

-n, --network-interface=INTERFAZ

Establece las interfaces de red en las que escucha rygel. Se puede usar varias veces para configurar múltiples interfaces. INTERFAZ puede ser una IP, un nombre de dispositivo o un ESSID (solo Linux).

-p, --port=PUERTO

Establece el puerto de escucha.

-t, --disable-transcoding

Deshabilita cualquier transcodificación.

-U, --disallow-upload

No se permite la carga de archivos multimedia a través de UPnP.

-D, --disallow-deletion

Los clientes UPnP no tienen permitido eliminar archivos multimedia en el servidor.

-g, --log-level=NIVEL

Lista separada por comas de pares DOMINIO:NIVEL, que permite establecer el nivel de registro individualmente para cada dominio, donde DOMINIO es bien "*", "rygel" o el nombre de un complemento. Los niveles de registro permitidos son 1=crítico, 2=error, 3=advertencia, 4=mensaje/información, 5=depuración.

-u, --plugin-path=RUTA

Establece la ruta de búsqueda de complementos.

-e, --engine-path=RUTA_MOTOR

Establece la ruta de búsqueda del motor de transmisión y transcodificación de medios.

-d, --disable-plugin=NOMBRE_COMPLEMENTO

Deshabilita el complemento NOMBRE_COMPLEMENTO.

-i, --title=NOMBRE_COMPLEMENTO:TÍTULO

Establece el título del complemento NOMBRE_COMPLEMENTO a TÍTULO. Puede usar esta opción más de una vez por cada complemento cuyo nombre desee establecer.

-o, --plugin-option=NOMBRE_COMPLEMENTO: OPCIÓN:VALOR1[,VALOR2,...]

Establece opciones para un complemento.

-P, --disable-upnp

Deshabilita la publicidad a través de UPnP y pone rygel en modo de solo transmisión.

-c, --config=ARCHIVO_CONFIG

Usa ARCHIVO_CONFIG en lugar de ${XDG_CONFIG_DIR}/rygel.conf.

-s, --shutdown

Apaga una instancia de rygel en ejecución.

-r, --replace

Reemplaza la instancia de rygel en ejecución con esta instancia. Abreviatura de rygel -s && rygel

ARCHIVOS

/etc/rygel.conf

El archivo de configuración a nivel de sistema para controlar el comportamiento de rygel. Consulte rygel.conf(5) para más detalles.

${XDG_CONFIG_DIR}/rygel.conf

El archivo de configuración por usuario para controlar el comportamiento de rygel. Consulte rygel.conf(5) para más detalles.

${XDG_CONFIG_DIR}/Rygel/*.xml

Archivos de descripción de dispositivos UPnP en caché.

ENTORNO

RYGEL_DISABLE_UPNP

Deshabilita la publicidad a través de UPnP y pone rygel en modo de solo transmisión.

RYGEL_IFACE

Establece las interfaces de red a las que se conectará.

RYGEL_PORT

Define el puerto de red al que se conectará.

RYGEL_DISABLE_TRANSCODING

Deshabilita la transcodificación globalmente.

RYGEL_LOG

Establece el nivel de registro de rygel.

RYGEL_PLUGIN_PATH

Establece la ruta de búsqueda de complementos de rygel.

RYGEL_ENGINE_PATH

Establece la ruta de búsqueda del motor de transmisión y transcodificación de medios para rygel.

RYGEL_MEDIA_ENGINE

Establece un motor de transmisión de medios específico para seleccionar de la ruta de búsqueda del motor de medios.

RYGEL_DISABLE_UPLOAD

Deshabilita la carga de archivos multimedia a través de UPnP.

RYGEL_DISABLE_DELETION

Deshabilita la eliminación de archivos remotos a través de UPnP.

RYGEL_PLUGIN_TIMEOUT

Establece el tiempo de espera para encontrar los complementos. Útil para aumentar al ejecutar dentro de valgrind.

RYGEL_DATABASE_DEBUG

Si se establece en 1, la biblioteca de base de datos imprimirá las sentencias SQL utilizadas.

También, para cada complemento, puede establecer las siguientes variables de entorno:

RYGEL_NOMBRE_COMPLEMENTO_TÍTULO

Establece el título del complemento.

RYGEL_NOMBRE_COMPLEMENTO_ACTIVADO

Activa o desactiva el complemento.

ERRORES
