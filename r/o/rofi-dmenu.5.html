NOMBRE

modo rofi dmenu - Emulación de dmenu de Rofi

DESCRIPCIÓN

Para integrar rofi en scripts como simples diálogos de selección, rofi soporta la emulación de dmenu(1) (Un menú dinámico para X11).

El sitio web de dmenu se puede encontrar aquí.

rofi no pretende ser 100% compatible con dmenu. Simplemente hay demasiados sabores de dmenu. La idea es que las banderas de línea de comandos de uso básico se obedezcan, mientras que las relacionadas con el tema no. Además, rofi ofrece algunas características extendidas (como selección múltiple, resaltado, barra de mensajes, atajos de teclado adicionales).

CONCEPTO BÁSICO

En el modo dmenu, rofi lee datos de la entrada estándar, los divide en entradas separadas y las muestra. Si el usuario selecciona una fila, esta se imprime en la salida estándar, permitiendo que el script la procese más a fondo.

Por defecto, la separación de filas se realiza en nuevas líneas, lo que facilita pasar la salida de una aplicación a rofi y la salida de rofi a la siguiente.

USO

Al ejecutar rofi con la bandera -dmenu, entrará en modo de emulación de dmenu.

ls | rofi -dmenu

REEMPLAZO DIRECTO DE DMENU

Si argv[0] (comando de llamada) es dmenu, rofi se iniciará en modo dmenu. De esta manera, puede ser utilizado como un reemplazo directo para dmenu. Simplemente copie o cree un enlace simbólico de rofi a dmenu en $PATH.

ln -s /usr/bin/rofi /usr/bin/dmenu

DMENU VS MODO SCRIPT

El modo script se utiliza para extender rofi, el modo dmenu se utiliza para extender un script. Ambos comparten gran parte del mismo formato de entrada. Por favor, consulte la página del manual de rofi-script(5) para más información.

BANDERA ESPECÍFICA DE DMENU

Muchas de estas opciones también pueden ser modificadas por el script utilizando entrada especial. Consulte la página del manual de rofi-script(5) para obtener más información sobre esta sintaxis.

-sep separador
Separador para dmenu. Ejemplo: Para mostrar una lista de `a' a `e' con `|' como separador:
echo "a|b|c|d|e" | rofi -sep '|' -dmenu
-p prompt
Especifica el prompt a mostrar en el modo dmenu. Por ejemplo, seleccione `mono', a,b,c,d, o e.
echo "a|b|c|d|e" | rofi -sep '|' -dmenu -p "mono"

Por defecto: dmenu

-l número de líneas a mostrar
Número máximo de líneas que el menú puede mostrar antes de desplazarse.
rofi -dmenu -l 25

Por defecto: 15

-i
Hace que las búsquedas de dmenu no distingan entre mayúsculas y minúsculas.
-a X
Fila activa, marca X como activa. Donde X es una lista separada por comas de índices y rangos al estilo de python(1), por ejemplo, los índices comienzan en 0, -1 se refiere a la última fila con -2 precediéndola, los rangos están abiertos por la izquierda y cerrados por la derecha, y así sucesivamente. Puede especificar:
•
Una sola fila: `5'
•
Un rango de (últimas 3) filas: `-3:'
•
4 filas comenzando desde la fila 7: `7:11' (o en notación antigua: `7-10')
•
Un conjunto de filas: `2,0,-9'
•
O cualquier combinación: `5,-3:,7:11,2,0,-9'
-u X
Fila urgente, marca X como urgente. Véase la opción -a para más detalles.
-only-match
Solo devuelve un elemento seleccionado, no permite entrada personalizada. Este modo siempre devuelve un elemento. No devolverá nada si no se selecciona ningún elemento coincidente.
-no-custom
Solo devuelve un elemento seleccionado, no permite entrada personalizada. Este modo devuelve directamente si no se proporcionan elementos.
-format formato
Permite personalizar la salida de dmenu (N es el número total de entradas de entrada):
•
`s' cadena seleccionada
•
`i' índice (0 - (N-1))
•
`d' índice (1 - N)
•
`q' cadena entre comillas
•
`p' Cadena seleccionada sin el marcado Pango (Debe ser una cadena válida)
•
`f' cadena de filtro (entrada del usuario)
•
`F' cadena de filtro entre comillas (entrada del usuario)

Por defecto: `s'

-select cadena
Selecciona la primera línea que coincide con la cadena dada.
-mesg cadena
Añade una línea de mensaje debajo del cuadro de entrada de filtro. Soporta marcado Pango. Para más información sobre el marcado soportado, véase aquí
-dump
Vuelca la lista filtrada a stdout y sale. Esto se puede usar para obtener la lista tal como rofi la filtraría. Usar junto con la opción -filter.
-input archivo
Lee desde archivo en lugar de stdin.
-password
Oculta el texto de entrada. ¡Esto no debe considerarse seguro!
-markup-rows
Indica a rofi que la entrada de DMenu está codificada con marcado Pango y debe renderizarse. Véase aquí para detalles sobre el marcado Pango.
-multi-select
Permite seleccionar múltiples líneas. Añade un pequeño indicador de selección a la izquierda de cada entrada.
-sync
Fuerza al modo rofi a leer primero todos los datos de stdin antes de mostrar la ventana de selección. Este es el comportamiento original de dmenu.

Nota: el modo asíncrono por defecto también se deshabilitará automáticamente si se usa con opciones conflictivas, como -dump, -only-match o -auto-select.

-window-title título
Establece el nombre utilizado para el título de la ventana. Se mostrará como Rofi - título
-w id_ventana
Posiciona rofi sobre la ventana con el ID de ventana X11 dado.
-keep-right
Establece el modo de elipsis en inicio. Así, el final de la cadena es visible.
-display-columns
Una lista de columnas separadas por comas para mostrar.
-display-column-separator
El separador de columnas. Esto es una expresión regular.

por defecto: ’

-ballot-selected-str cadena
Cuando la selección múltiple está habilitada, prefija esta cadena cuando el elemento está seleccionado.

por defecto: “☑”

-ballot-unselected-str

string

-ellipsize-mode (start|middle|end)

ANÁLISIS DE OPCIONES DE FILA

También se pueden establecer opciones adicionales para filas individuales. Consulte la página man rofi-script(5) para obtener más detalles; la sintaxis y las características admitidas son idénticas.

VALOR DE RETORNO

•
0: La fila ha sido seleccionada y aceptada por el usuario.
•
1: El usuario canceló la selección.
•
10-28: Fila aceptada por una combinación de teclas personalizada.
