ros-init - Crea un script de roswell (opcionalmente basado en una plantilla)

Sinopsis

ros init [PLANTILLA] NOMBRE [ARGUMENTOS...]]

PLANTILLA
Especifica el nombre de una plantilla, por defecto la plantilla default. Sin embargo, si PLANTILLA no se especifica y NOMBRE_ARCHIVO coincide con una de las plantillas almacenadas, entonces automáticamente usa la plantilla. Para suprimir este comportamiento, deberías especificar explícitamente PLANTILLA como default.

Por lo tanto, se te advierte cuando usas este comando desde un script de shell. Para lograr un comportamiento consistente y deseado, se aconseja que siempre especifiquen explícitamente el nombre de la plantilla.

NOMBRE
Especifica el nombre del archivo de salida, o “-” para indicar salida estándar. Cuando PLANTILLA es default, automáticamente añade una extensión de archivo “.ros”.

Descripción

Inicializa un archivo de roswell basado en una plantilla. Las plantillas especificadas por el usuario pueden ser añadidas mediante ros-template(1).

La plantilla por defecto es algo como:

#!/bin/sh
#|-*- mode:lisp -*-|#
#| <Pon una descripción de una línea aquí>
exec ros -Q -- $0 "$@"
|#
(progn ;;formas de inicialización
  (ros:ensure-asdf)
  ;;#+quicklisp (ql:quickload '() :silent t)
  )
(defpackage :ros.script.test.3703600390
  (:use :cl))
(in-package :ros.script.test.3703600390)
(defun main (&rest argv)
  (declare (ignorable argv)))
;;; vim: set ft=lisp lisp:

Esto es básicamente un script de shell que invoca inmediatamente a Roswell mediante exec (ver sh(1)). Roswell carga el mismo script como entrada, salta los comentarios multilínea, lee el resto del archivo como un programa Common Lisp, y finalmente invoca una función main con los argumentos de la línea de comandos.
