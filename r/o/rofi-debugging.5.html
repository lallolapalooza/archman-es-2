NOMBRE

Depuración de rofi.

Al informar sobre un problema con rofi que se bloquea o se comporta mal. Ayuda realizar una pequeña prueba para identificar el problema.

Primero, intente deshabilitar su configuración personalizada: -no-config

Esto deshabilita el análisis de los archivos de configuración. Esto ejecuta rofi en modo predeterminado.

Si ejecuta complementos C personalizados, puede deshabilitar los complementos usando: -no-plugins

Obtener la información relevante para un problema

Por favor, pegue la salida de los siguientes comandos en un pastebin:

rofi -help
rofi -dump-config
rofi -dump-theme
rofi -help nos proporciona los archivos de configuración analizados, la versión exacta, la disposición del monitor y otra información útil.
La salida de rofi -dump-config y rofi -dump-theme nos da la interpretación de rofi de su configuración y tema.

Por favor, revise la salida en busca de información identificable y elimínela.

Trazas de tiempos

Para obtener una traza de tiempos, habilite el dominio de depuración Timings.

G_MESSAGES_DEBUG=Timings rofi -show drun

Mostrará una traza con información de tiempos (útil) en puntos relevantes durante la ejecución. Esto ayudará a depurar cuando rofi tarda en iniciarse.

Dominios de depuración

Para depurar más el complemento, puede obtener una traza con (mucha) información de depuración. Esta salida de depuración se puede habilitar para múltiples partes en rofi utilizando el marco de depuración de glib. Los dominios de depuración se pueden habilitar estableciendo la variable de entorno G_MESSAGES_DEBUG. En el momento de la creación de esta página, existen los siguientes dominios de depuración:

•
all: Muestra información de depuración de todos los dominios.
•
X11Helper: Las funciones auxiliares de X11.
•
View: Las funciones de la ventana principal.
•
Widgets.Box: El widget Box.
•
Modes.DMenu: El modo dmenu.
•
Modes.Run: El modo run.
•
Modes.DRun: El modo run de archivos de escritorio.
•
Modes.Window: El modo de ventana.
•
Modes.Script: El modo script.
•
Modes.Combi: El modo script.
•
Modes.Ssh: El modo ssh.
•
Rofi: La aplicación principal.
•
Timings: Obtiene la salida de tiempos.
•
Theme: Salida de depuración del motor de temas. (Advertencia: mucha salida).
•
Widgets.Icon: El widget Icon.
•
Widgets.Box: El widget box.
•
Widgets.Container: El widget contenedor.
•
Widgets.Window: El widget de ventana.
•
Helpers.IconFetcher: Información sobre la búsqueda de iconos.

Para la lista completa, consulte man rofi.

Ejemplo: G_MESSAGES_DEBUG=Dialogs.DRun rofi -show drun Para obtener una salida específica del diálogo de ejecución de archivos de escritorio.

Crear una traza de pila

Primero, asegúrate de compilar rofi con símbolos de depuración:

make CFLAGS="-O0 -g3" clean rofi

Obtener una traza de pila usando GDB no es muy práctico. Porque si rofi se atasca, captura el teclado y el ratón. Así que si falla en GDB, estás atascado. La mejor manera es habilitar el archivo core. (ulimit -c unlimited en bash) luego haz que rofi falle. Luego puedes cargar el core en GDB.

gdb rofi core

Luego escribe dentro de gdb:

thread apply all bt

El rastro de salida es útil al informar sobre fallos.

Algunas distribuciones tienen systemd-coredump, de esta manera puedes obtener fácilmente una traza de pila a través de coredumpctl.
