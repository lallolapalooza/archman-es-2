subrutina crot (entero n, complejo, dimensión( * ) cx, entero incx, complejo, dimensión( * ) cy, entero incy, real c, complejo s)

CROT aplica una rotación de plano con coseno real y seno complejo a un par de vectores complejos.

Propósito:

!>
!> CROT aplica una rotación de plano, donde el cos (C) es real y el
!> sin (S) es complejo, y los vectores CX y CY son complejos.
!>

Parámetros

N 
!>          N es ENTERO
!>          El número de elementos en los vectores CX y CY.
!>

CX

!>          CX es un array COMPLEJO, dimensión (N)
!>          En la entrada, el vector X.
!>          En la salida, CX se sobrescribe con C*X + S*Y.
!>

INCX

!>          INCX es ENTERO
!>          El incremento entre valores sucesivos de CX.  INCX <> 0.
!>

CY

!>          CY es un array COMPLEJO, dimensión (N)
!>          En la entrada, el vector Y.
!>          En la salida, CY se sobrescribe con -CONJG(S)*X + C*Y.
!>

INCY

!>          INCY es ENTERO
!>          El incremento entre valores sucesivos de CY.  INCX <> 0.
!>

C

!>          C es REAL
!>

S

!>          S es COMPLEJO
!>          C y S definen una rotación
!>             [  C          S  ]
!>             [ -conjg(S)   C  ]
!>          donde C*C + S*CONJG(S) = 1.0.
!>

!>

CY

!>           ( 1 + ( N - 1 )*abs( INCY ) ).
!>           Antes de la entrada, el array incrementado CY debe contener el
!>           vector de n elementos cy. En la salida, CY se sobrescribe con
!>           el vector cy actualizado.
!>

INCY

!>          INCY es ENTERO
!>           En la entrada, INCY especifica el incremento para los elementos de
!>           CY. INCY no debe ser cero.
!>

C

!>          C es REAL
!>           En la entrada, C especifica el coseno, cos.
!>

S

!>          S es REAL

NAME

rot, drot, zrot, srot, drotg, zrotg - rotar plane rotation

SYNOPSIS

subroutine drot(integer n, real, dimension( * ) dx, integer incx, real,
     dimension( * ) dy, integer incy, real c, real s)
subroutine zrot(integer n, complex*16, dimension( * ) cx, integer incx,
     complex*16, dimension( * ) cy, integer incy, real c, complex*16 s)
subroutine srot(integer n, real, dimension( * ) sx, integer incx, real,
     dimension( * ) sy, integer incy, real c, real s)
subroutine drotG(real da, real db, real, real c, real s)
subroutine zrotg(complex*16 za, complex*16 zb, complex*16 c, complex*16 s)

Detailed Description

The purpose of the routines SROT, DROT, ZROT, and CZROT is to apply a plane rotation:

    call srot(n, sx, incx, sy, incy, c, s)
    call drot(n, dx, incx, dy, incy, c, s)
    call zrot(n, cx, incx, cy, incy, c, s)
    call czrot(n, cx, incx, cy, incy, c, s)

The routines SROTG and ZROTG form the components of a plane rotation.

subroutine drot (integer n, real, dimension( * ) dx, integer incx, real, dimension( * ) dy, integer incy, real c, real s)

DROT applies a plane rotation.

Purpose:

!>
!> applies a plane rotation, where the cos and sin (c and s) are real
!> and the vectors dx and dy are real.
!> jack dongarra, linpack, 3/11/78.
!> modified 12/3/93, array(1) declarations changed to array(*)
!>

Parameters

N 
!>          N is INTEGER
!>           On entry, N specifies the order of the vectors dx and dy.
!>           N must be at least zero.
!>
DX 
!>          DX is REAL array, dimension at least
!>           ( 1 + ( N - 1 )*abs( INCX ) ).
!>           Before entry, the incremented array DX must contain the n
!>           element vector x. On exit, DX is overwritten by C*X + S*Y.
!>
INCX 
!>          INCX is INTEGER
!>           On entry, INCX specifies the increment for the elements of
!>           DX. INCX must not be zero.
!>
DY 
!>          DY is REAL array, dimension at least
!>           ( 1 + ( N - 1 )*abs( INCY ) ).
!>           Before entry, the incremented array DY must contain the n
!>           element vector y. On exit, DY is overwritten by -S*X + C*Y.
!>
INCY 
!>          INCY is INTEGER
!>           On entry, INCY specifies the increment for the elements of
!>           DY. INCY must not be zero.
!>
C 
!>          C is REAL
!>           On entry, C specifies the cosine, cos.
!>
S 
!>          S is REAL
!>           On entry, S specifies the sine, sin.
!>

subroutine zrot (integer n, complex*16, dimension( * ) cx, integer incx, complex*16, dimension( * ) cy, integer incy, double precision c, complex*16 s)

ZROT applies a plane rotation with real cosine and complex sine to a pair of complex vectors.

Purpose:

!>
!> ZROT applies a plane rotation, where the cos (C) is real and the
!> sin (S) is complex, and the vectors CX and CY are complex.
!>

Parameters

N 
!>          N is INTEGER
!>          The number of elements in the vectors CX and CY.
!>
CX 
!>          CX is COMPLEX*16 array, dimension (N)
!>          On input, the vector X.
!>          On output, CX is overwritten with C*X + S*Y.
!>
INCX 
!>          INCX is INTEGER
!>          The increment between successive values of CX.  INCX <> 0.
!>
CY 
!>          CY is COMPLEX*16 array, dimension (N)
!>          On input, the vector Y.
!>          On output, CY is overwritten with -CONJG(S)*X + C*Y.
!>
INCY 
!>          INCY is INTEGER
!>          The increment between successive values of CY.  INCX <> 0.
!>
C 
!>          C is DOUBLE PRECISION
!>
S 
!>          S is COMPLEX*16
!>          C and S define a rotation
!>             [  C          S  ]
!>             [ -conjg(S)   C  ]

!>
