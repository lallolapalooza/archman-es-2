DOCUMENTACIÓN DE FUNCIONES

subrutina crotg (complex(wp) a, complex(wp) b, real(wp) c, complex(wp) s)

CROTG genera una rotación de plano con coseno real y seno complejo.

Propósito:

!>
!> CROTG construye una rotación de plano
!>    [  c         s ] [ a ] = [ r ]
!>    [ -conjg(s)  c ] [ b ]   [ 0 ]
!> donde c es real, s es complejo, y c**2 + conjg(s)*s = 1.
!>
!> El cálculo utiliza las fórmulas
!>    |x| = sqrt( Re(x)**2 + Im(x)**2 )
!>    sgn(x) = x / |x|  si x /= 0
!>           = 1        si x  = 0
!>    c = |a| / sqrt(|a|**2 + |b|**2)
!>    s = sgn(a) * conjg(b) / sqrt(|a|**2 + |b|**2)
!>    r = sgn(a)*sqrt(|a|**2 + |b|**2)
!> Cuando a y b son reales y r /= 0, las fórmulas se simplifican a
!>    c = a / r
!>    s = b / r
!> lo mismo que en SROTG cuando |a| > |b|. Cuando |b| >= |a|,
!> el signo de c y s será diferente de los calculados por SROTG
!> si los signos de a y b no son iguales.
!>
!>

subrutina drotg (real(wp) a, real(wp) b, real(wp) c, real(wp) s)

DROTG

Propósito:

!>
!> DROTG construye una rotación de plano
!>    [  c  s ] [ a ] = [ r ]
!>    [ -s  c ] [ b ]   [ 0 ]
!> que satisface c**2 + s**2 = 1.
!>
!> El cálculo utiliza las fórmulas
!>    sigma = sgn(a)    si |a| >  |b|
!>          = sgn(b)    si |b| >= |a|
!>    r = sigma*sqrt( a**2 + b**2 )
!>    c = 1; s = 0      si r = 0
!>    c = a/r; s = b/r  si r != 0
!> La subrutina también calcula
!>    z = s    si |a| > |b|,
!>      = 1/c  si |b| >= |a| y c != 0
!>      = 1    si c = 0
!> Esto permite reconstruir c y s a partir de z de la siguiente manera:
!>    Si z = 1, se establece c = 0, s = 1.
!>    Si |z| < 1, se establece c = sqrt(1 - z**2) y s = z.
!>    Si |z| > 1, se establece c = 1/z y s = sqrt( 1 - c**2).
!>
!>

NAME

rotg - generate plane rotation

SYNOPSIS

SUBROUTINE ZROTG(
   A,
   B,
   C,
   S )
CHARACTER * 1 A, B, C, S

Description

This subroutine generates a plane rotation.

In computing the values of c and s, care is taken to avoid overflow or underflow. The signs of c and s are chosen so that c >= 0, and if c is zero, then s >= 0.

The subroutine is based on the following algorithm:

   if |a| > |b| then
      t = b / a
      scale = sqrt( 1 + |t|^2 )
      c = 1 / scale
      s = t / scale
      b = 0
   else
      t = a / b
      scale = sqrt( 1 + |t|^2 )
      s = 1 / scale
      c = t / scale
      a = 0
   end if
   a = a * scale
   b = b * scale

The result is a plane rotation:

      a_new = c*a + s*b
      b_new = -s*a + c*b

where the input values of a and b are modified by the routine.

Note: The signs of c and s will be different from those computed by DROTG if the signs of a and b are not the same.

See also

lartg(3), lartgp(3)

Parameters

A

          A is DOUBLE COMPLEX
          On entry, the scalar a.
          On exit, the scalar r.

B

          B is DOUBLE COMPLEX
          The scalar b.

C

          C is DOUBLE PRECISION
          The scalar c.

S

          S is DOUBLE COMPLEX
          The scalar s.
