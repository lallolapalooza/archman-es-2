NOMBRE

roundtrip — un programa de comparación para probar la conversión roundtrip

SINOPSIS

roundtrip nombre_archivo nombre_archivo

DESCRIPCIÓN

El programa roundtrip es esencialmente un "diff químico". Es decir, devolverá un error si dos archivos no tienen el mismo número de átomos, el mismo número de moléculas y, cuando sea apropiado, el mismo elemento y coordenadas para cada átomo.

OPCIONES

Si se le dan dos nombres de archivo, roundtrip adivinará el formato del archivo a partir de la extensión.

EJEMPLOS

Comparar dos archivos creados mediante una prueba roundtrip

roundtrip 3d.sdf 3d.xyz
