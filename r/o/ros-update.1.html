ros-update - Actualizar sistema instalado desde vcs

Sinopsis

•
ros update sistema [sistema ...]
•
ros update método [parámetros ...]

Descripción

sistema
un nombre que especifica un sistema.
método
el método soportado actualmente es git.

Actualizar sistema

Cuando los sistemas ya están instalados y el sistema tiene .git en el directorio del sistema, invoca git pull y ros instala el sistema.

VER TAMBIÉN

ros(1), ros-install(1)
