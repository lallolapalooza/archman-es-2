ROOT-CONFIG(1) Manual General de Comandos ROOT-CONFIG(1)

NOMBRE

root-config - Utilidad ROOT para tus Makefiles

SINOPSIS

root-config [opciones]

DESCRIPCIÓN

root-config es una herramienta que se utiliza para configurar y determinar las opciones del compilador y del enlazador que deben usarse para compilar y enlazar programas que utilizan ROOT.

CPPFLAGS  += $(shell root-config --cflags)
LDLIBS    += $(shell root-config --libs)
LDFLAGS   += $(shell root-config --ldflags)
%Cint.cxx:Include.h LinkDef.h
        rootcint -f $@ -c $^
en tu Makefile para usar las reglas integradas de GNU make. Para GUIs, reemplaza --libs por --glibs.

También puedes encontrar útil el archivo de macros automake(1), autoconf(1) y libtool(1) /usr/share/aclocal/root.m4. Si ese archivo de macros no está instalado donde aclocal lo encontrará, copia el contenido a tu archivo acinclude.m4 local. En los directorios donde uses bibliotecas de ROOT, ten en tu archivo Makefile.am:

lib_LTLIBRARIES         = libFoo.la
pkginclude_HEADERS      = Foo.h
noinst_HEADERS          = FooCint.h
libFoo_la_SOURCES       = Foo.cxx FooCint.cxx   
libFoo_la_LDFLAGS       = -version-info 1:0 -R @ROOTLIBDIR@
libFoo_la_LDADD         = -lCore -lCint @ROOTAUXLIBS@
BUILT_SOURCES           = FooCint.cxx FooCint.h 
AM_CPPFLAGS             = -I@ROOTINCDIR@
AM_LDFLAGS              = -L@ROOTLIBDIR@
CLEANFILES              = *Cint.cxx *Cint.h *~ core 
%Cint.cxx %Cint.h:Include.h LinkDef.h
        @ROOTCINT@ -f $*Cint.cxx -c $(INCLUDES) $(AM_CPPFLAGS) $^
donde debes sustituir Foo por lo que sea, y listar los archivos fuente apropiados en la variable _SOURCES. En tu archivo configure.in, pon: 
AC_PROG_CC
AC_PROG_CXX
ROOT_PATH
AM_PROG_LIBTOOL
junto con cualquier otra macro que puedas necesitar.

Nota que la macro ROOT_PATH toma tres argumentos opcionales: la versión mínima de ROOT a usar, la acción si se encuentra ROOT, y la acción si no se encuentra ROOT. Algunos ejemplos son

ROOT_PATH(3.03/05, , AC_MSG_ERROR(Tu versión de ROOT es demasiado antigua))
ROOT_PATH(, AC_DEFUN(HAVE_ROOT))
Por ejemplo, si quieres compilar alguna parte de tu árbol de fuentes condicionalmente a si ROOT está presente o no, puedes poner en tu archivo configure.in 
ROOT_PATH(,
[
  AC_DEFUN(HAVE_ROOT)
  have_root=yes  
])
AM_CONDITIONAL(GOT_ROOT, test "x$have_root" = "xyes")
Y luego en algún Makefile.am 
EXTRA_SOURCES		= root_dependent_source.cc
if GOT_ROOT
LIBFOOXTRA              = root_dependent_source.cc
else
LIBFOOXTRA              =
endif
lib_LTLIBRARIES         = libFoo.la
libFoo_la_SOURCES	= Foo.cc  $(LIBFOOXTRA)
La lista completa de variables de sustitución es:
ROOTCONF
ruta completa a root-config
ROOTEXEC
ruta completa a root
ROOTCINT
ruta completa a rootcint
ROOTLIBDIR
Dónde están las bibliotecas de ROOT
ROOTINCDIR
Dónde están las cabeceras de ROOT
ROOTCFLAGS
Opciones adicionales del compilador
ROOTLIBS
Bibliotecas básicas de ROOT
ROOTGLIBS
Bibliotecas básicas de ROOT + GUI
ROOTAUXLIBS
Bibliotecas auxiliares y opciones del enlazador para ROOT
ROOTAUXCFLAGS
Opciones auxiliares del compilador
ROOTRPATH
Igual que ROOTLIBDIR

OPCIONES

--help
Muestra una breve lista de las opciones disponibles y sale
--version
Informa del número de versión de ROOT instalado y sale.
--prefix=<prefijo>
Si no se dan argumentos, informa dónde está instalado ROOT. Con un argumento de =<prefijo>, establece la base de las opciones posteriores a <prefijo>. Si se pasa \--exec-prefix con un argumento, anula el argumento dado a \--prefix para la ruta de la biblioteca.
--exec-prefix=<prefijo>
Si no se da ningún argumento, informa dónde están instaladas las bibliotecas. Si se da un argumento, úsalo como directorio base de instalación para las bibliotecas. Esta opción no afecta la ruta de inclusión.
--libdir
Imprime el directorio donde están instaladas las bibliotecas de ROOT.
--incdir
Imprime el directorio donde están instaladas las cabeceras de ROOT.
--libs
Imprime una línea adecuada para enlazar un programa contra las bibliotecas de ROOT. No se incluyen bibliotecas gráficas.
--glibs
Igual que el anterior, pero también incluye las bibliotecas gráficas (GUI).
--evelibs
Igual que el anterior, pero también incluye las bibliotecas gráficas y de Eve.
--cflags
Imprime una línea adecuada para compilar un archivo fuente contra los archivos de cabecera (declaraciones de clase) de ROOT.
--new
Incluye la biblioteca libNew.so en las listas de bibliotecas. Esta opción debe darse antes que las opciones --libs y --glibs.
--nonew
Opción de compatibilidad, no hace nada.
--auxlibs
Imprime bibliotecas auxiliares y/o opciones del enlazador del sistema.
--noauxlibs
No imprime bibliotecas auxiliares y/o opciones del enlazador en la salida de --libs y --glibs. --auxcflags Imprime opciones auxiliares del compilador.
--noauxcflags
No imprime opciones auxiliares del compilador en la salida de --cflags.
--noldflags
No imprime la opción de enlace de la ruta de la biblioteca en la salida de --libs, --evelibs y --glibs.
--ldflags
Imprime opciones adicionales del enlazador (ej. -m64)
--arch
Imprime la arquitectura (compilador/SO)
--platform
Imprime la plataforma (SO)
--bindir
Imprime el directorio binario de la instalación de root (ubicación del ejecutable root)
--etcdir
Imprime el directorio de configuración (lugar de system.rootrc, tipo mime, archivos de supresión de valgrind y archivos .desktop)
--config
Imprime los argumentos utilizados para ./configure tal como se usaron al compilar root. Estos no se pueden usar para ./configure si root se compiló con CMake.
--git-revision
Imprime el número de revisión de git de ROOT con el que se compiló root.
--has-<característica>
Prueba si la <característica> se ha habilitado en el proceso de compilación.
--features
Imprime la lista de todas las características compatibles
--ncpu
Imprime el número de núcleos disponibles (con hyperthreading)

OPTIONS

--python-version
Imprime la versión de Python utilizada por ROOT
--cc
Imprime el compilador C alternativo especificado cuando se compiló ROOT
--cxx
Imprime el compilador C++ alternativo especificado cuando se compiló ROOT
--f77
Imprime el compilador Fortran alternativo especificado cuando se compiló ROOT
--ld
Imprime el enlazador alternativo especificado cuando se compiló ROOT
