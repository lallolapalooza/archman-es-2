NOMBRE

rofi keys - Atajos de teclado y ratón de Rofi

DESCRIPCIÓN

rofi soporta la sobreescritura de cualquiera de sus atajos de teclado y ratón.

Configurar atajos

Los atajos se pueden configurar en la línea de comandos (-{nombre-atajo}):

rofi -show run -kb-accept-entry 'Control+Shift+space'

o a través del archivo de configuración:

configuration {
  kb-accept-entry: "Control+Shift+space";
}

La tecla se puede definir por su nombre (ver arriba) o por su código de tecla:

configuration {
  kb-accept-entry: "Control+Shift+[65]";
}

Una forma fácil de buscar el código de tecla es usar xev(1).

Se pueden especificar múltiples teclas para una acción como una lista separada por comas:

configuration {
  kb-accept-entry: "Control+Shift+space,Return";
}

Por defecto, rofi reacciona al presionar la tecla. Para actuar al soltar todas las teclas, anteponga el atajo con !:

configuration {
  kb-accept-entry: "!Control+Shift+space,Return";
}

Desactivar un atajo

Para desactivar un atajo, pase una cadena vacía.

configuration {
  kb-clear-line: "";
}

Atajos de tecla de ratón

Los siguientes botones del ratón se pueden enlazar:

•
Primary: Clic del botón principal (izquierdo) del ratón.
•
Secondary: Clic del botón secundario (derecho) del ratón.
•
Middle: Clic del botón central del ratón.
•
Forward: El botón de avance del ratón.
•
Back: El botón de retroceso del ratón.
•
ExtraN: El N-ésimo botón del ratón. (Dependiendo del soporte del ratón).

El identificador se construye de la siguiente manera:

Mouse<D><Button>
•
D indica la pulsación doble opcional.
•
Button es el nombre del botón.

Así, MouseDPrimary es el doble clic del botón principal (izquierdo) del ratón.
