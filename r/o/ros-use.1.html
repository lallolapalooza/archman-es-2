ros-use - establece la implementación predeterminada utilizada por roswell # sinopsis

ros [opciones] use impl[/version]

impl : El nombre de una implementación que ya está instalada. Se pueden descargar nuevas implementaciones con ros-install(1). La lista de implementaciones instaladas está disponible en ros-list(1).

version: : El especificador de versión. La representación en cadena de la versión (por ejemplo, . ) depende de cada implementación y roswell generalmente sigue la representación utilizada por la implementación. Además, un nombre de versión especial “system” le indica a roswell que use la implementación que está instalada en su sistema, la cual debería estar en PATH.

ejemplo

ros use sbcl : usa la última versión de SBCL entre varias versiones de SBCL instaladas por ros-install. Esto se compila desde el código fuente, lo que puede llevar tiempo para instalar pero permite a SLIME saltar al código fuente de la implementación.

ros use sbcl-bin : usa el último binario estable de SBCL descargado del sitio web del proveedor. Roswell usa esto por defecto. sbcl-bin tiende a ser una versión más antigua en comparación con sbcl, ¡pero ciertamente más nueva que su contraparte instalada con apt-get!

ros use sbcl/1.3.1 : usa la versión compilada de SBCL 1.3.1.

ros use sbcl-bin/1.3.1 : usa la versión precompilada de SBCL 1.3.1.

ros use sbcl/system : usa la versión de SBCL disponible en el PATH.

ros use ccl : usa CCL compilado desde el código fuente. Se pueden aplicar los mismos especificadores de versión que para SBCL.

Roswell también soporta abcl, acl, clisp, cmu y ecl.
