rorschach(6) Manual de XScreenSaver rorschach(6)

NOMBRE

rorschach - simula patrones de manchas de tinta

SINOPSIS

rorschach [--display host:display.screen] [--foreground color] [--background color] [--window] [--root] [--window-id número][--mono] [--install] [--visual visual] [--iterations entero] [--offset entero] [--xsymmetry] [--ysymmetry] [--erase-speed usecs] [--delay secs] [--fps]

DESCRIPCIÓN

El programa rorschach dibuja patrones aleatorios que recuerdan al test psicológico del mismo nombre.

OPCIONES

rorschach acepta las siguientes opciones:

--window
Dibuja en una ventana recién creada. Esta es la opción predeterminada.
--root
Dibuja en la ventana raíz.
--window-id número
Dibuja en la ventana especificada.
--mono
Si está en una pantalla a color, finge estar en una pantalla monocromática.
--install
Instala un mapa de colores privado para la ventana.
--visual visual
Especifica qué visual usar. Los valores legales son el nombre de una clase visual o el número de ID (decimal o hexadecimal) de un visual específico.
--iterations entero
Cuántos puntos se dibujarán cada vez. Predeterminado: 4000.
--offset entero
Cuán separados deben estar los puntos. Predeterminado: 4 píxeles.
--xsymmetry
Si las imágenes deben ser horizontalmente simétricas. Predeterminado: verdadero.
--ysymmetry
Si las imágenes deben ser verticalmente simétricas. Predeterminado: falso.
--erase-speed usecs
Esto controla la velocidad a la que se borrará la pantalla. (Retraso entre el borrado de líneas individuales.)
--delay segundos
Esto establece el número de segundos que la figura permanecerá en la pantalla.
--fps
Muestra la tasa de fotogramas actual y la carga de la CPU.

AMBIENTE

DISPLAY
para obtener el host y el número de pantalla predeterminados.
XENVIRONMENT
para obtener el nombre de un archivo de recursos que anula los recursos globales almacenados en la propiedad RESOURCE_MANAGER.
XSCREENSAVER_WINDOW
El ID de ventana a usar con --root.

ERRORES

Puede poner en duda su cordura.

VER TAMBIÉN

X(1), xscreensaver(1)
