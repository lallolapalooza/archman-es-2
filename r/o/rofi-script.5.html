NOMBRE

modo script rofi - Formato de Rofi para modo scriptable.

DESCRIPCIÓN

rofi soporta modos que utilizan scripts simples en segundo plano para generar una lista y procesar el resultado de las acciones del usuario. Esto proporciona una interfaz sencilla para realizar extensiones simples a rofi.

USO

Para especificar un modo de script, configure un modo con la siguiente sintaxis: “{nombre}:{ejecutable}”

Por ejemplo:

rofi -show fb -modes "fb:file_browser.sh"

El nombre debe ser único.

API

Rofi llama al ejecutable sin argumentos al inicio. Este debería generar una lista de opciones, separadas por un salto de línea (\n) (esto puede ser cambiado por el script). Si el usuario selecciona una opción, rofi llama al ejecutable con el texto de esa opción como primer argumento. Si el script no devuelve ninguna entrada, rofi se cierra.

Un script simple sería:

#!/usr/bin/env bash
if [ x"$@" = x"quit" ]
then
    exit 0
fi
echo "reload"
echo "quit"

Esto muestra dos entradas, reload y quit. Cuando se selecciona la entrada quit, rofi se cierra.

Entorno

Rofi establece la siguiente variable de entorno al ejecutar el script:

ROFI_RETV

Un número entero con el estado actual:

•
0: Llamada inicial del script.
•
1: Se seleccionó una entrada.
•
2: Se seleccionó una entrada personalizada.
•
3: Se eliminó una entrada.
•
10-28: Combinaciones de teclas personalizadas 1-19 (deben ser activadas explícitamente por el script).

ROFI_INFO

La variable de entorno se establece cuando la entrada seleccionada se establece con el valor de la propiedad `info' de la opción de fila, si se establece.

ROFI_DATA

La variable de entorno se establece cuando el script establece la opción data en la cabecera.

Paso de opciones de modo

Se pueden establecer opciones adicionales, como la configuración del prompt, mediante el script. Las opciones adicionales son líneas que comienzan con un carácter NULL (\0) seguido de una clave, un separador (\x1f) y un valor.

Por ejemplo, para establecer el prompt:

    echo -en "\0prompt\x1fCambiar prompt\n"

Las siguientes opciones adicionales existen:

•
prompt: Actualiza el texto del prompt.
•
message: Actualiza el texto del mensaje.
•
markup-rows: Si es `true', renderiza el markup en la fila.
•
urgent: Marca filas como urgentes. (para la sintaxis ver la opción urgent en modo dmenu)
•
active: Marca filas como activas. (para la sintaxis ver la opción active en modo dmenu)
•
delim: Establece el delimitador para las siguientes filas. El predeterminado es `' y esta opción debe terminar con él. Solo llame a esto en la primera llamada del script, se recuerda para llamadas consecutivas.
•
no-custom: Si se establece en `true'; solo acepta entradas listadas, ignora la entrada personalizada.
•
use-hot-keys: Si se establece en true, habilita las combinaciones de teclas personalizadas para el script. Advertencia: esto rompe el flujo normal de rofi.
•
keep-selection: Si se establece, la selección no se mueve a la primera entrada, sino que se mantiene la posición actual. El filtro se borra.
•
keep-filter: Si se establece, el filtro no se borra.
•
new-selection: Si keep-selection está establecido, esto permite anular la entrada seleccionada (posición absoluta).
•
data: Pasa datos a la siguiente ejecución del script a través de ROFI_DATA.
•
theme: Un pequeño fragmento de tema para, por ejemplo, cambiar el color de fondo de un widget.

La propiedad theme no puede cambiar la interfaz mientras se ejecuta, solo es utilizable para pequeños cambios, por ejemplo, el color de fondo, de widgets que se actualizan durante la visualización, como el color de la fila de la lista.

Análisis de opciones de fila

Se pueden establecer opciones adicionales para filas individuales. La opción adicional se puede especificar siguiendo la misma sintaxis que la opción de modo, pero siguiendo la entrada.

Por ejemplo:

    echo -en "aap\0icon\x1ffolder\n"

Las siguientes opciones son compatibles:

•
icon: Establece el icono para esa fila.
•
display: Reemplaza la cadena mostrada. (La cadena original todavía se utilizará para el filtrado)
•
meta: Especifica términos de búsqueda invisibles utilizados para el filtrado.
•
nonselectable: Si es true, la fila no se puede activar.
•
permanent: Si es true, la fila siempre se muestra, independientemente del filtro.
•
info: Información que, al ser seleccionada, se coloca en la variable de entorno ROFI_INFO. Esta entrada no se busca para filtrar.
•
urgent: Establece la bandera urgente en la entrada (true/false)
•
active: Establece la bandera activa en la entrada (true/false)

Se pueden pasar múltiples entradas utilizando el separador \x1f.

    echo -en "aap\0icon\x1ffolder\x1finfo\x1ftest\n"

Ejecución de programa externo

Si desea lanzar un programa externo desde el script, debe asegurarse de que se lance en segundo plano. De lo contrario, rofi esperará su salida (para mostrarla).

En bash, la mejor manera de hacerlo es usando coproc.

 coproc ( myApp  > /dev/null  2>&1 )

Shell DASH

Si utiliza el shell dash para su script, preste especial atención a cómo dash maneja los valores escapados para los separadores. Ver el problema #1201 en github.

Ubicaciones de scripts

Para especificar un script, existen las siguientes opciones:

•
Especificar una ruta absoluta al script.
•
El script es ejecutable y se encuentra en su $PATH

Los scripts ubicados en la siguiente ubicación se cargan al inicio y se pueden ejecutar directamente basándose en el nombre del archivo (sin extensión):

•
El script está en $XDG_CONFIG_HOME/rofi/scripts/, que suele ser ~/.config/rofi/scripts/.

Si tiene un script `mymode.sh' en esta carpeta, puede abrirlo usando:

rofi -show mymode

Consulte la salida de rofi -h para ver una lista de scripts detectados.

SYNOPSIS

rofi -show script -modi script: /path/to/your/script.sh

DESCRIPTION

The script mode allows to script rofi, by using an external script as the source for the menu entries.

USAGE

The script is expected to print a list of valid menu entries to stdout. Each menu entry is a string, followed by a newline. If the menu entry is longer than one line, the additional lines are prepended with a tab character.

When the user selects an entry, rofi will print the selected entry to stdout and exit.

The script can be configured using the -u, -c, -a, and -l options, to set the default, selected, active, and urgent states of the entries, respectively.

The script can also be configured using the rofi configuration file.

API

The script can be passed the following arguments:

-dmenu

Use the dmenu compatibility mode. This will enable the dmenu mode and pass the arguments to rofi.

-display display

Specify the display to use. This is useful when running rofi in a script that might not have access to the default display.

-i

Case-insensitive matching.

-p prompt

Set the prompt to display.

-l lines

Set the number of lines to display.

-a active

Set the initially active entry.

-u urgent

Set the initially urgent entries.

-c selected

Set the initially selected entry.

Environment

The script can access the following environment variables:

ROFI_RETVM

The return value of the script. This is the index of the selected entry.

ROFI_INFO

The information string of the selected entry.

ROFI_DATA

The data string of the selected entry.

ROFI_ENTRY

The selected entry itself.

ROFI_QUERY

The current query string.

Passing mode options

The script can be passed options to configure the mode.

-theme theme

Use the specified theme.

-theme-str theme-string

Use the specified theme string.

-drun-highlights

Enable highlights for drun mode.

-drun-flat-dirs

Use flat directory structure for drun mode.

-drun-use-xdg-mime

Use xdg-mime for drun mode.

-normal-window

Show rofi as a normal window.

-fake-monitor wxhxy

Simulate a monitor with the given dimensions and position.

-bw border-width

Set the border width.

-bc border-color

Set the border color.

-l lines

Set the number of visible lines.

-tb text-background

Set the text background color.

-tf text-color

Set the text color.

-p prompt

Set the prompt text.

-m monitor

Select the monitor to display rofi on.

-location location

Set the location of rofi on the screen.

-r

Reverse the order of the entries.

-e error-message

Display an error message and exit.

-markup

Enable Pango markup for entries.

-normal-group

Group entries by mode.

-rofi-file file

Specify a rofi configuration file.

Parsing row options

Each row can have extra options. These options are comma-separated and placed at the end of the row string, after a closing parenthesis.

Example: 

My Entry (urgent) (active) (selected) (meta: some data)
urgent

Mark the entry as urgent.

active

Mark the entry as active.

selected

Mark the entry as selected.

meta: <data>

Add custom data to the entry. This data can be accessed by rofi using the ROFI_DATA environment variable.

Executing external program

The script mode can be used to execute external programs. The script should print a list of programs to stdout. When an entry is selected, rofi will execute the corresponding program.

Example script (scripts/programs.sh): 

#!/bin/sh
echo "Firefox"
echo "Terminal"
echo "Nautilus"

Command to run rofi: 

rofi -show drun -modi script:scripts/programs.sh

When "Firefox" is selected, rofi will execute `firefox`.

DASH shell

The script will be executed with the `/bin/sh` shell. If you need to use bash features, you should use a shebang line like `#!/bin/bash` or explicitly call bash in your script.

Script locations

The script can be located anywhere on your system. However, it's common to place scripts in a dedicated directory, such as ~/.config/rofi/scripts/ or /usr/local/bin/.
