NOMBRE

rofi-rbw - Un frontend de rofi para el cliente alternativo de Bitwarden rbw

SINOPSIS

rofi-rbw [-h] [--version] [--action {type,copy,print}] [--target {username,password,totp,OTHER}] [--prompt PROMPT] [--selector-args SELECTOR_ARGS] [--clipboarder CLIPBOARDER] [--typer TYPER] [--selector SELECTOR] [--clear-after NUMBER] [--typing-key-delay NUMBER] [--no-help] [--no-folder] [--keybindings KEYBINDINGS] [--menu-keybindings MENU_KEYBINDINGS] [--use-notify-send]

DESCRIPCIÓN

Escribe, copia o imprime tus credenciales de Bitwarden usando rofi.

OPCIONES

-h, --help
Imprime información breve de uso.
--version
muestra el número de versión del programa y sale
--action, -a
Valores posibles: type, copy, print

Elige qué hacer con los caracteres seleccionados: Escríbelos directamente con el 'Typer', cópialos al portapapeles usando el 'Clipboarder', o imprímelos en stdout.

--target, -t
Valores posibles: username, password, totp, notes, NOMBRE DE CAMPO PERSONALIZADO

Elige qué componente de la entrada seleccionada escribir/copiar/imprimir. Puede pasarse varias veces para usar múltiples destinos.

--prompt PROMPT, -r PROMPT
Establece el texto para el prompt.
--keybindings KEYBINDINGS
Formato: ::.

Define tus propios atajos de teclado. Se pueden concatenar múltiples atajos de teclado con ,; múltiples destinos para un mismo atajo se pueden concatenar con :. Esta función solo está disponible en 'selectores' compatibles.

--menu-keybindings KEYBINDINGS
Formato: :.

Define tus propios atajos de teclado para el menú de destinos. Se pueden concatenar múltiples atajos de teclado con ,. Esta función solo está disponible en 'selectores' compatibles.

--clear-after SEGUNDOS
Borra la contraseña del portapapeles después de SEGUNDOS segundos. Ponlo a 0 para deshabilitar.
--typing-key-delay MILISEGUNDOS
Establece un pequeño retraso entre pulsaciones de teclas al escribir. 0 por defecto.
--no-cache
Deshabilita la caché automática de frecuencia. Contiene hashes sha1 de las entradas seleccionadas y cuántas veces se usaron.
--no-help
No muestres el mensaje de ayuda sobre los atajos de teclado disponibles.
--no-folder
No muestres carpetas en la lista de entradas posibles.
--selector-args SELECTOR-ARGS
Una cadena de argumentos para darle al selector.
--selector SELECTOR
Valores posibles: rofi, wofi

Elige manualmente la aplicación selectora. Normalmente rofi, pero para Wayland, podrías querer wofi.

--clipboarder CLIPBOARDER
Valores posibles: xsel, xclip, wl-copy

Elige manualmente la aplicación para acceder al portapapeles.

--typer TYPER
Valores posibles: xdotool, wtype, ydotool, dotool

Elige manualmente la aplicación para escribir.

--use-notify-send
Envía una notificación de escritorio después de copiar el TOTP.

ATJOS DE TECLADO POR DEFECTO

enter para usar la acción por defecto

alt+c para copiar la contraseña

alt+u para copiar el nombre de usuario

alt+t para copiar el TOTP

alt+m para mostrar un menú de los componentes de la entrada

alt+s para sincronizar el contenido de la bóveda

alt+1 para escribir automáticamente el nombre de usuario y la contraseña, separados por un carácter de tab

alt+2 para escribir el nombre de usuario

alt+3 para escribir la contraseña

Por favor, ten en cuenta que wofi no soporta atajos de teclado distintos de enter.

CONFIGURACIÓN

Los argumentos que empiezan por "--" (ej. --version) también se pueden establecer en un archivo de configuración.

La sintaxis del archivo de configuración permite: clave=valor, flag=true, stuff=[a,b,c]. Si un argumento se especifica en más de un lugar, entonces los valores de la línea de comandos anulan los valores del archivo de configuración.

ARCHIVOS

~/.cache/rofi-rbw.runcache
Guarda el número de veces que se ha usado una entrada, para que puedan ordenarse primero. Las entradas se hashean con sha1 para no filtrar ningún secreto.
