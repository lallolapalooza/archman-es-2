ROUTEL(8) Linux ROUTEL(8)

NOMBRE

routel - lista rutas con formato de salida bonito

SINOPSIS

routel [ OPCIONES ] [ tablanr [ opciones de ruta ip... ] ]

OPCIONES := { -h | --help | [{-f | --family } {inet | inet6 } | -4 | -6 }

DESCRIPCIÓN

El script routel listará las rutas en un formato que algunos podrían considerar más fácil de interpretar que el equivalente de la lista de rutas de ip.
