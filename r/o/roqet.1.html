roqet(1) Manual de Comandos Generales roqet(1)

NOMBRE

roqet - Utilidad de consulta RDF de Rasqal

SINOPSIS

roqet [OPCIONES] <URI-de-consulta> [URI-base]
roqet [OPCIONES]-e cadena-de-consulta [URI-base]
roqet [OPCIONES]-p URI-del-servicio-protocolo-sparql URI-de-consulta [URI-base]
roqet [OPCIONES]-p URI-del-servicio-protocolo-sparql [-e cadena-de-consulta ] [URI-base]
roqet [OPCIONES]-t archivo-de-resultados-de-consulta [URI-base]

DESCRIPCIÓN

La utilidad roqet permite consultar contenido RDF utilizando la biblioteca de consultas RDF Rasqal, imprimiendo los resultados de las uniones de variables, el grafo RDF o los resultados booleanos en una variedad de formatos. La consulta se lee desde URI-de-consulta y la URI-base opcional se utiliza como URI base de la consulta si está presente.

OPCIONES PRINCIPALES

roqet utiliza la sintaxis habitual de línea de comandos de GNU, con opciones largas que comienzan con dos guiones (`-') si son compatibles con la función getopt_long. De lo contrario, solo están disponibles las opciones cortas.

-e, --exec CONSULTA
Ejecuta la cadena de consulta en el argumento CONSULTA en lugar de leer la consulta desde una URI (cuando -e / --exec no se proporciona).
-i, --input IDIOMA
Establece el IDIOMA de entrada de la consulta a uno de los idiomas soportados, que incluyen 'sparql' (SPARQL Query Language for RDF, por defecto), 'sparql11' y 'laqrs'. La lista completa de idiomas y subconjuntos soportados se proporciona en el resumen de ayuda con la opción -h / --help.
-p, --protocol URI-DEL-SERVICIO
Llama al URI-DEL-SERVICIO del protocolo HTTP SPARQL para ejecutar la consulta en lugar de ejecutarla localmente dentro del motor de consulta Rasqal (cuando se proporciona -e o una cadena de consulta).
-r, --results FORMATO
Establece el FORMATO de salida de los resultados de la consulta.
Para uniones de variables, los valores de FORMATO varían según lo que soporta Rasqal, pero incluyen 'simple' para un formato de texto simple (por defecto), 'xml' para el formato XML de resultados de consultas SPARQL, 'csv' para SPARQL CSV, 'tsv' para SPARQL TSV, 'rdfxml' y 'turtle' para formatos de sintaxis RDF, y 'json' para una versión JSON de los resultados.
Para resultados de grafos RDF, los valores de FORMATO son 'ntriples' (N-Triples, por defecto), 'rdfxml-abbrev' (RDF/XML Abreviado), 'rdfxml' (RDF/XML), 'turtle' (Turtle), 'json' (recurso central RDF/JSON), 'json-triples' (triples RDF/JSON) o 'rss-1.0' (RSS 1.0, también una sintaxis RDF/XML).
La lista exacta de formatos depende de con qué se compiló libraptor2(3), pero se proporciona correctamente en el mensaje de uso con -h.
-R, --results-input-format FORMATO
Establece el FORMATO de entrada de los resultados de la consulta.
Esto es para usar con -t y toma valores de 'xml' para el formato XML de resultados de consultas SPARQL, 'csv' para SPARQL CSV, 'tsv' para SPARQL TSV, 'turtle' y 'rdfxml' para formatos de sintaxis RDF.
-t, --results-input ARCHIVO
Lee los resultados de la consulta desde ARCHIVO.

OTRAS OPCIONES

-c, --count
Solo cuenta los triples y no produce ninguna otra salida.
-d, --dump-query FORMATO
Imprime la consulta analizada en un FORMATO dado, uno de 'none' (por defecto), 'debug', 'structure' o 'sparql'.
-D, --data URI
Añade una URI de fuente de datos RDF (no un grafo nombrado). Si no se proporcionan fuentes de datos, la consulta misma debe apuntar a los datos, por ejemplo, mediante sentencias SPARQL FROM uri.
-E, --ignore-errors
No imprime mensajes de error y no sale con un estado distinto de 0.
-f, --feature NOMBRE(=VALOR)
Establece la característica de consulta NOMBRE al VALOR o al entero 1 si se omite. Las características conocidas se pueden mostrar con -f help o --feature help.
-F, --format NOMBRE
Establece el NOMBRE del formato de la fuente de datos para los grafos de datos subsiguientes llamados con -D / --data o -G / --named. El valor por defecto si no se especifica es que el motor de consulta lo adivine. El NOMBRE es un nombre de parser de Raptor.
-G, --named URI
Añade una URI de fuente de datos RDF (grafo nombrado).
-h, --help
Muestra un resumen de las opciones.
-n, --dryrun
Prepara la consulta pero no la ejecuta.
-q, --quiet
Sin mensajes de información extra.
-s, --source URI
Añade la URI de fuente de datos RDF (grafo nombrado) URI agregándola a la lista de URIs de fuentes de datos de la consulta. FORMATO a 'simple' (por defecto) o 'xml' (un formato XML experimental).
-v, --version
Imprime la versión de la biblioteca rasqal y sale.
-W, --warnings NIVEL
Establece el NIVEL de advertencia en el rango de 0 (no advertir sobre nada) a 100 (mostrar todas las advertencias). El valor por defecto de Rasqal está en el medio (50).

EJEMPLOS

roqet archivo-de-consulta-sparql.rq

Ejecuta una consulta SPARQL contenida en el archivo local archivo-de-consulta-sparql.rq. Los datos utilizados se describirían en sentencias FROM en el archivo de consulta.

roqet -q -i sparql http://example.org/sparql-query.rq

Ejecuta una consulta SPARQL que se encuentra en la web en la URI http://example.org/sparql-query.rq sin mensajes extra (quiet, -q).

roqet -q archivo-de-consulta.rq http://example.org/base/

Ejecuta una consulta (idioma por defecto SPARQL) desde un archivo local archivo-de-consulta.rq pero utilizando la URI base http://example.org/base/ para resolver cualquier URI relativa.

roqet -q -i sparql -r xml http://example.org/sparql-query.rq

Ejecuta una consulta SPARQL que se encuentra en la web en la URI http://example.org/sparql-query.rq y formatea los resultados en el formato XML de resultados de consultas SPARQL sin mensajes extra.

roqet -i sparql -e 'SELECT * WHERE { ?s ?p ?o }' -D stuff.rdf

Ejecuta una consulta SPARQL dada en la línea de comandos contra datos en el archivo stuff.rdf. El tipo de archivo se adivinará y probablemente será del formato RDF/XML.

roqet -t resultado.srx -r html

Lee los resultados de una consulta SPARQL en formato XML de resultados de consultas SPARQL (por defecto) y los imprime en HTML.

roqet -t resultado.ttl -R turtle -r csv

Lee los resultados de una consulta SPARQL en formato RDF/Turtle y los imprime en CSV.
