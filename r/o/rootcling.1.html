rootcling(1) Manual de Comandos Generales rootcling(1)

SINOPSIS

uso: rootcling [-f F] [-v V] [-v0 V0] [-v1 V1] [-v2 V2] [-v3 V3] [-v4 V4]
[-m M] [-rmf RMF] [-rml RML] [-split SPLIT] [-s S]
[-multiDict MULTIDICT] [-inlineInputHeader INLINEINPUTHEADER]
[-interpreteronly INTERPRETERONLY]
[-noIncludePaths NOINCLUDEPATHS] [-excludePath EXCLUDEPATH]
[--lib-list-prefix LIB_LIST_PREFIX]

DESCRIPCIÓN

Este programa genera los diccionarios necesarios para realizar I/O de clases.

OPCIONES

-f
Sobrescribir un archivo de salida existente
El archivo de salida debe tener la extensión .cxx, .C, .cpp, .cc o .cp.
-v
Mostrar todos los mensajes
-v0
No mostrar ningún mensaje
-v1
Mostrar solo mensajes de error
-v2
Mostrar mensajes de error y advertencia (por defecto).
-v3
Mostrar mensajes de error, advertencia y nota
-v4
Mostrar todos los mensajes
-m
Especificar la ruta absoluta o relativa del archivo pcm de Clang a cargar
El archivo pcm (módulo) producido por esta invocación de rootcling
no incluirá ninguna de las declaraciones ya incluidas en los
archivos pcm cargados a través de -m. Puede haber más de un -m
-rmf
Nombre del archivo rootmap
Nombre del archivo rootmap. Para ser recogido por ROOT debe
tener la extensión .rootmap
-rml
Nombre de la biblioteca rootmap
Especificar el nombre de la biblioteca que contiene las claves de carga automática. Este
interruptor puede especificarse varias veces para cargar automáticamente varias bibliotecas en
presencia de una clave particular
-split
Dividir el diccionario
Dividir el diccionario en dos, colocando las funciones ClassDef en un archivo
separado
-s
Nombre de la biblioteca de destino
El flag -s debe ir seguido del nombre de la biblioteca que contendrá
el archivo objeto correspondiente al diccionario producido por
esta invocación de rootcling.
El nombre tiene prioridad sobre el especificado para el archivo rootmap.
El nombre influye en el nombre del pcm creado:

1) Si no se especifica, el pcm se llama libINPUTHEADER_rdict.pcm

2) Si se especifica, el pcm se llama libTARGETLIBRARY_rdict.pcm

Cualquier ocurrencia de "liblib" se transforma en "lib" según lo esperado

3) Si esto se especifica junto con --multiDict, la salida es

libTARGETLIBRARY_DICTIONARY_rdict.pcm
-multiDict
Habilitar soporte para múltiples pcms en una biblioteca
Necesita el flag -s. Ver su documentación.
-inlineInputHeader
Añadir la cabecera del argumento al código del diccionario
Esto permite que la cabecera se incluya directamente dentro del diccionario
-interpreteronly
Sin información de IO en el diccionario
-noIncludePaths
No almacenar los directorios de cabeceras en el diccionario
En su lugar, depender de la variable de entorno $ROOT_INCLUDE_PATH en tiempo de ejecución
-excludePath
Especificar una ruta a excluir de las rutas de inclusión
especificadas para construir este diccionario
--lib-list-prefix
Especificar las bibliotecas necesarias para los archivos de cabecera analizados
Esta característica es utilizada por ACliC (el generador automático de bibliotecas).
Rootcling leerá el contenido de xxx.in para obtener una lista de archivos rootmap (ver
rlibmap). Rootcling leerá estos archivos y los usará para deducir una lista de
bibliotecas que son necesarias para enlazar y cargar correctamente este diccionario. Esta
lista de bibliotecas se guarda en la primera línea del archivo xxx.out; las líneas
restantes contienen la lista de clases para las que esta ejecución de
rootcling produjo un diccionario
