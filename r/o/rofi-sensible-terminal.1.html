NOMBRE

rofi-sensible-terminal - lanza $TERMINAL con alternativas

SINOPSIS

rofi-sensible-terminal [argumentos]

DESCRIPCIÓN

rofi-sensible-terminal se invoca en la configuración predeterminada de rofi para iniciar un terminal. Este script envoltorio es necesario ya que no existe un lanzador de terminal independiente de la distribución (pero por ejemplo, Debian tiene x-terminal-emulator). Los empacadores de distribución son responsables de distribuir este script de una manera apropiada para la distribución.

Intenta iniciar uno de los siguientes (en ese orden):

•
$TERMINAL (esta es una variable no estándar)
•

•
