NOMBRE

rollchk - Comprueba un archivo rollrec de DNSSEC-Tools en busca de problemas e inconsistencias.

SINOPSIS

rollchk [-roll | -skip] [-count] [-quiet] [-verbose] [-help] archivo-rollrec

DESCRIPCIÓN

Este script comprueba el archivo rollrec especificado por archivo-rollrec en busca de problemas e inconsistencias.

TIPOS DE COMPROBACIONES

Hay cuatro tipos de comprobaciones realizadas por rollchk: comprobaciones de archivo, comprobaciones de archivo "raw", comprobaciones de info rollrec y comprobaciones de rollrec. Las comprobaciones se realizan en ese orden, y si falla alguna de las comprobaciones grupales, rollchk sale.

Comprobaciones de archivo

Estas comprobaciones determinan información básica sobre el propio archivo rollrec. Los problemas reconocidos son:

  • archivo rollrec inexistente

    El archivo rollrec especificado no existe.

  • archivo rollrec no regular

    El archivo rollrec especificado no es un archivo regular.

Comprobaciones de archivo raw

Estas comprobaciones se realizan directamente sobre el contenido del archivo, en lugar de utilizar las interfaces de rollrec.pm. Los problemas reconocidos son:

•
nombres de rollrec duplicados

Un nombre de rollrec no es único.

Comprobaciones de Info Rollrec

Estas comprobaciones se realizan para garantizar que el info rollrec sea válido. Los problemas reconocidos son:

  • versión negativa

    El número de versión en el info rollrec es menor que 0.

  • versión excesivamente grande

    El número de versión en el info rollrec es mayor que 2.

  • versión inválida

    El número de versión en el info rollrec no es 0, 1 o 2.

Comprobaciones de Rollrec

Estas comprobaciones se realizan después de referenciar el contenido del archivo a través de las interfaces de rollrec.pm. Los problemas reconocidos son:

  • no hay zonas definidas

    No hay zonas definidas en el archivo rollrec especificado.

  • fase de rollover de KSK inválida

    Una zona tiene una fase de rollover de KSK inválida. Estas fases pueden ser 0, 1, 2, 3, 4, 5, 6 o 7; cualquier otro valor es inválido.

  • desajuste en los datos de marca de tiempo KSK

    La marca de tiempo en segundos de rollover KSK de una zona no se traduce en la fecha almacenada en su cadena roll-date.

  • fase de rollover de ZSK inválida

    Una zona tiene una fase de rollover de ZSK inválida. Estas fases pueden ser 0, 1, 2, 3 o 4; cualquier otro valor es inválido.

  • desajuste en los datos de marca de tiempo ZSK

    La marca de tiempo en segundos de rollover ZSK de una zona no se traduce en la fecha almacenada en su cadena roll-date.

  • tiempos de rollover de KSK y ZSK contemporáneos

    Una zona tiene un rollover de KSK ocurriendo al mismo tiempo que un rollover de ZSK. Una zona solo puede tener una fase de rollover distinta de cero a la vez.

  • en rollover sin phasestart

    Una zona está actualmente en rollover, pero su registro rollrec no tiene un campo phasestart.

  • administrador vacío

    Una zona tiene un campo de administrador vacío. Este campo debe contener un valor de datos no vacío. El valor en sí no se analiza para verificar su precisión.

  • directorio inexistente

    Se realizan varias comprobaciones para el directorio de una zona. Si la zona tiene un directorio especificado, el directorio debe existir y debe ser un directorio real.

  • indicador de visualización inválido

    Una zona tiene un indicador de visualización inválido. Este indicador puede ser 0 o 1; cualquier otro valor es inválido.

  • ttl no positivo

    El valor máximo de TTL debe ser mayor que cero.

  • comprobaciones del archivo de zona

    Se realizan varias comprobaciones para el archivo de zona de una zona. El archivo de zona debe existir, debe ser un archivo regular y no debe tener longitud cero.

    Si el archivo no es una ruta absoluta y el archivo rollrec tiene una entrada de directory, se antepone el directorio al nombre del archivo antes de realizar cualquier comprobación.

  • comprobaciones del archivo keyrec

    Se realizan varias comprobaciones para el archivo keyrec de una zona. El archivo keyrec debe existir, debe ser un archivo regular y no debe tener longitud cero.

    Si el archivo no es una ruta absoluta y el archivo rollrec tiene una entrada de directory, se antepone el directorio al nombre del archivo antes de realizar cualquier comprobación.

  • comprobaciones de nombre de zona

    Se realizan varias comprobaciones para el nombre de zona. El nombre de zona debe coincidir con el nombre SOA en el archivo de zona, y el registro keyrec del nombre de zona en su archivo keyrec debe ser un registro de zona.

  • zsargs vacíos

    Una zona tiene un campo de argumentos de zonesigner vacío. Si este campo existe, debe contener un valor de datos no vacío. El valor en sí no se analiza para verificar su precisión.

OPCIONES

-roll
Mostrar solo los rollrec que son registros activos ("roll"). Esta opción es mutuamente excluyente de la opción -skip.
-skip
Mostrar solo los rollrec que son registros inactivos ("skip"). Esta opción es mutuamente excluyente de la opción -roll.
-count
Mostrar un recuento final de errores.
-quiet
No mostrar mensajes. Esta opción reemplaza la configuración de la opción -verbose.
-verbose
Mostrar muchos mensajes. Esta opción es subordinada a la opción -quiet.
-Version
Muestra la información de versión de rollchk y el paquete DNSSEC-Tools.
-help
Muestra un mensaje de uso.
