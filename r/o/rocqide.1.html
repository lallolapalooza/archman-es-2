ROCQIDE(1) Manual de Comandos Generales ROCQIDE(1)

NOMBRE

rocqide - interfaz gráfica para el Prover Rocq

SINOPSIS

rocqide [ opciones ]

DESCRIPCIÓN

rocqide es una interfaz gráfica gtk para el Prover Rocq.

Para el uso de Rocq orientado a línea de comandos o a lotes, véase rocq(1);

OPCIONES

-h
Muestra la lista completa de opciones aceptadas por rocqide.
-I dir, -include dir
Añade el directorio dir a la ruta de inclusión.
-R dir rocqdir
Mapea recursivamente el directorio físico dir al directorio lógico rocqdir.
-src
Añade directorios de origen a la ruta de inclusión.
-nois
Inicia con un estado vacío.
-load-ml-object f
Carga el archivo objeto ML f.
-load-ml-source f
Carga el archivo ML f.
-l f, -load-vernac-source f
Carga el archivo Rocq f.v (Carga f.).
-lv f, -load-vernac-source-verbose f
Carga el archivo Rocq f.v (Carga Verbosa f.).
-load-vernac-object path
Carga la biblioteca Rocq path (Requiere path.).
-require-import path
Carga la biblioteca Rocq path y la importa (Requiere Importar path.).
-compile f
Compila el archivo Rocq f.v (implica -batch).
-compile-verbose f
Compila de forma verbosa el archivo Rocq f.v (implica -batch).
-where
Imprime la ubicación de la biblioteca estándar de Rocq y sale.
-v
Imprime la versión de Rocq y sale.
-q
Omite la carga del archivo rcfile.
-init-file f
Establece el archivo rcfile a f.
-emacs
Indica a Rocq que está siendo ejecutado bajo Emacs.
-dump-glob f
Descarga las globalizaciones en el archivo f (para ser usado por rocq(1)doc).
-impredicative-set
Establece el conjunto de orden impredicativo.
-dont-load-proofs
No carga pruebas opacas en memoria.
