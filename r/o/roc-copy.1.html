ROC-COPY(1) Kit de herramientas Roc ROC-COPY(1)

NOMBRE

roc-copy - copia audio local

SINOPSIS

roc-copy OPCIONES

DESCRIPCIÓN

Lee un flujo de audio desde un archivo, lo transforma y lo escribe en otro archivo.

Opciones

-h, --help
Imprime la ayuda y sale
-V, --version
Imprime la versión y sale
-v, --verbose
Aumenta el nivel de verbosidad (puede usarse varias veces)
-L, --list-supported
Lista los esquemas y formatos compatibles
-i,--input=URI_ARCHIVO
URI del archivo de entrada
-o,--output=URI_ARCHIVO
URI del archivo de salida
--input-format=FORMATO_ARCHIVO
Forzar el formato del archivo de entrada
--output-format=FORMATO_ARCHIVO
Forzar el formato del archivo de salida
--frame-len=TIEMPO
Duración de los fotogramas internos, unidades de TIEMPO
-r,--rate=INT
Frecuencia de muestreo de salida, Hz
--resampler-backend=ENUM
Backend del remuestreador (valores posibles="default", "builtin", "speex", "speexdec" por defecto=`default')
--resampler-profile=ENUM
Perfil del remuestreador (valores posibles="low", "medium", "high" por defecto=`medium')
--profiling
Habilita la auto-perfilación (por defecto=desactivado)
--color=ENUM
Establece el modo de registro con color para la salida stderr (valores posibles="auto", "always", "never" por defecto=`auto')

URI de archivo

Las opciones --input y --output requieren una URI de archivo en una de las siguientes formas:

  • file:///RUTA/ABSOLUTA -- ruta de archivo absoluta
  • file://localhost/RUTA/ABSOLUTA -- ruta de archivo absoluta (forma alternativa; solo se admite el host "localhost")
  • file:/RUTA/ABSOLUTA -- ruta de archivo absoluta (forma alternativa)
  • file:RUTA/RELATIVA -- ruta de archivo relativa
  • file://- -- stdout
  • file:- -- stdout (forma alternativa)

Ejemplos:

  • file:///home/usuario/test.wav
  • file://localhost/home/usuario/test.wav
  • file:/home/usuario/test.wav
  • file:./test.wav
  • file:-

La lista de formatos de archivo compatibles se puede obtener usando la opción --list-supported.

Si se omite --output, los resultados de la conversión se descartan.

Las opciones --input-format y --output-format se pueden usar para forzar el formato del archivo. Si se omite la opción, el formato del archivo se detecta automáticamente. Esta opción siempre es requerida para stdin o stdout.

El componente de ruta de la URI proporcionada se *descodifica por porcentaje*. Para mayor comodidad, también se permiten caracteres sin codificar, excepto que % siempre debe codificarse como %25.

Por ejemplo, el archivo llamado /foo/bar%/[baz] se puede especificar usando cualquiera de las siguientes URIs: file:///foo%2Fbar%25%2F%5Bbaz%5D y file:///foo/bar%25/[baz].

Unidades de tiempo

TIEMPO debe tener una de las siguientes formas:
123ns; 1.23us; 1.23ms; 1.23s; 1.23m; 1.23h;

EJEMPLOS

Convertir la frecuencia de muestreo a 48k:

$ roc-copy -vv --rate=48000 -i file:input.wav -o file:output.wav

Descartar los resultados de salida (útil para benchmarking):

$ roc-copy -vv --rate=48000 -i file:input.wav

Entrada desde stdin, salida a stdout:

$ roc-copy -vv --input-format=wav -i file:- \
    --output-format=wav -o file:- >./output.wav <./input.wav

VARIABLES DE ENTORNO

Las siguientes variables de entorno son compatibles:

NO_COLOR
Por defecto, la coloración de la terminal se detecta automáticamente. Esta variable de entorno puede configurarse a una cadena no vacía para deshabilitar la coloración de la terminal. Tiene menor precedencia que la opción --color.
FORCE_COLOR
Por defecto, la coloración de la terminal se detecta automáticamente. Esta variable de entorno puede configurarse a un entero positivo para habilitar/forzar la coloración de la terminal. Tiene menor precedencia que la variable NO_COLOR y la opción --color.
