RONN(1) Manual de Ronn RONN(1)

NOMBRE

ronn - convierte archivos markdown a páginas de manual

SINOPSIS

ronn [formato...] archivo...
ronn -m|--man archivo...
ronn -S|--server archivo...
ronn --pipe archivo
ronn < archivo
ronn -E|--encoding codificación ...

DESCRIPCIÓN

Ronn convierte archivos de texto a páginas de manual Unix con formato roff estándar o HTML. ronn-format(7) se basa en markdown(7) pero incluye reglas y sintaxis adicionales orientadas a la autoría de manuales.

En su modo predeterminado, ronn convierte uno o más archivos de entrada a archivos de salida HTML o roff. Las opciones --roff, --html y --fragment dictan qué archivos de salida se generan. Se pueden especificar múltiples argumentos de formato para generar múltiples archivos de salida. Los archivos de salida se nombran y se escriben en el mismo directorio que los archivos de entrada.

Las opciones --server y --man cambian el comportamiento de salida de la generación de archivos a la visualización de páginas de manual HTML generadas dinámicamente o a la visualización del archivo como con man(1).

Sin argumentos de archivo, ronn actúa como un simple filtro. El texto fuente de Ronn se lee desde la entrada estándar y la salida roff se escribe en la salida estándar. Utilice las opciones --html, --roff y/o --fragment para seleccionar el formato de salida.

ARCHIVOS

El comando ronn espera que la entrada sea texto válido ronn-format(7). Los archivos fuente suelen nombrarse nombre.sección.ronn (por ejemplo, ejemplo.1.ronn). El nombre y la sección deben coincidir con el nombre y la sección definidos en el encabezado del archivo.

Los archivos fuente deben estar codificados en UTF-8, o en la codificación especificada por la opción -E/--encoding, independientemente de la configuración regional en la que se esté ejecutando ronn.

Al generar archivos de salida roff o HTML, los nombres de archivo de destino se determinan tomando el nombre base del archivo de entrada y agregando la extensión de archivo apropiada (o eliminando la extensión de archivo en el caso de la salida roff). Por ejemplo, ejecutar ronn ejemplo.1.ronn genera ejemplo.1 con salida roff y ejemplo.1.html con salida HTML.

OPCIONES

Estas opciones controlan si la salida se escribe en archivo(s), en la salida estándar o directamente en un visor de manuales.

-m, --man
No genere archivos, muestre los archivos como si se hubiera invocado man(1) en el archivo de salida roff. Esto simula el comportamiento predeterminado de man al canalizar la salida roff a través de groff(1) y el programa de paginación especificado por la variable de entorno MANPAGER.
-S, --server
No genere archivos, inicie un servidor HTTP en http://localhost:1207/ y sirva páginas de manual HTML generadas dinámicamente para el conjunto de archivos de entrada. Un archivo llamado ejemplo.2.ronn se sirve como /ejemplo.2.html. También hay una página de índice en la raíz con enlaces a cada archivo.
El servidor respeta las opciones --style y los atributos de documento (--manual, --date, etc.). Estas mismas opciones se pueden variar en el momento de la solicitud dándolas como parámetros de consulta: ?manual=FOO&style=dark,toc
NOTA: El servidor integrado está diseñado para ayudar en el proceso de escritura y estilo de manuales. No se recomienda en absoluto como servidor web de propósito general.
--port=puerto
Cuando se usa con -S/--server, ejecuta el servidor en el puerto especificado en lugar del puerto predeterminado 1207.
--pipe
No genere archivos, escriba la salida generada en la salida estándar. Este es el comportamiento predeterminado cuando el texto fuente de Ronn se canaliza desde la entrada estándar y no se proporcionan argumentos de archivo.
-o=directorio, --output-dir=directorio
Escriba los archivos generados en el directorio especificado en lugar de la ubicación predeterminada.
-E=codificación, --encoding=codificación
Especifique la codificación en la que se encuentran los archivos de entrada. El valor predeterminado es UTF-8, independientemente de la configuración regional del usuario. La entrada enviada a STDIN siempre se trata como UTF-8, independientemente de si se pasa -E.

Las opciones de formato controlan los archivos que ronn genera, o el formato de salida cuando se especifica el argumento --pipe. Cuando no se proporcionan opciones de formato, se asumen tanto --roff como --html.

-r, --roff
Generar salida roff. Este es el comportamiento predeterminado cuando no se proporcionan archivos y el texto fuente de ronn se lee desde la entrada estándar.
-5, --html
Generar salida en formato HTML.
-f, --fragment
Generar salida en formato HTML pero solo el fragmento del documento, no el encabezado, el título ni el pie de página.

Los atributos del documento que se muestran en las áreas de encabezado y pie de página del contenido generado se especifican con estas opciones. (Estos valores también se pueden establecer a través del ENTORNO).

--manual=manual
El nombre del manual al que pertenece esta página de manual; manual se muestra prominentemente en el centro superior del área del encabezado.
--organization=nombre
El nombre del grupo, organización o individuo responsable de publicar el documento; nombre se muestra en el área del pie de página inferior izquierda.
--date=fecha
La fecha de publicación del documento; fecha debe tener el formato AAAA-MM-DD y se muestra en el área del pie de página central inferior. Se utiliza el mtime del archivo cuando no se proporciona fecha, o la hora actual cuando no hay archivo disponible.

La salida HTML se puede personalizar mediante el uso de hojas de estilo CSS:

--style=módulo[,módulo]...
La lista de hojas de estilo CSS a aplicar al documento. Se pueden especificar múltiples argumentos de módulo, pero deben separarse por comas o espacios.
Cuando módulo es una palabra simple, busque archivos llamados módulo.css en todos los directorios listados en la variable de entorno RONN_STYLE, y luego busque estilos internos.
Cuando módulo incluye un carácter /, úselo como la ruta completa a un archivo de hoja de estilo.
Los estilos internos son man (incluido por defecto), toc y 80c. Consulte ESTILOS para ver descripciones de las características añadidas por cada módulo.

Opciones misceláneas:

-w, --warnings
Muestre las advertencias de troff en el error estándar al realizar la conversión roff. Las advertencias suelen ser el resultado de un error en la lógica de conversión de HTML a roff de ronn.
-W
Desactive las advertencias de troff. Las advertencias están desactivadas por defecto. Esta opción se puede utilizar para revertir el efecto de un argumento -w anterior.
-v, --version
Muestre la versión de ronn y salga.

ÍNDICES DE ENLACES

Al generar salida HTML, ronn crea hipervínculos a referencias de manual (como grep(1), ls(1), markdown(7)) en el texto fuente basados en asignaciones de nombre de referencia a URL definidas en un archivo index.txt. Cada línea del archivo de índice describe un solo enlace de referencia, con espacios en blanco separando el id de la referencia de su ubicación. Se permiten líneas en blanco; las líneas que comienzan con un carácter # se ignoran:

# manuales incluidos en este proyecto:
whisky(1)    whisky.1.ronn
tango(5)     tango.5.ronn
# manuales externos
grep(1)      https://man7.org/linux/man-pages/m

ronn(1) — Ronn-NG 0.10.1

NAME

ronn — compile markdown to man pages

SYNOPSIS

ronn [-c|--compile] [-d|--debug] [-e|--errors] [-f|--fragment] [-h|--help] [-i|--indent] [-l|--list] [-m|--man] [-o|--compile-only] [-p|--pipe] [-q|--quiet] [-r|--roff] [-s|--style styles] [-S|--server [port]] [-t|--html] [-w|--width width] [input...]

DESCRIPTION

The ronn utility translates markdown(7) documents into groff/troff(7) source suitable for inclusion in a manual page (man(1)). It can also generate HTML output for viewing man pages in a web browser.

By default, ronn generates both roff and HTML output files, named after the input file, for example: some-great-program.1.ronn produces some-great-program.1 and some-great-program.1.html.

Options that specify the output format (-t, -r, -m, -f) cause only that format to be generated. All other options that specify an output format cause both roff and HTML output files to be generated.

The --server option starts a web server that serves man pages generated from the specified input files.

FILES

index.txt
A directory may contain an index.txt file that defines a set of external references. This file is searched for automatically in the input file's directory and in all directories listed in the RONN_STYLE environment variable.

OPTIONS

The long and short options are equivalent.

-c, --compile
Compile the specified input file(s) to roff and HTML output files. This is the default action.
-d, --debug
Enable debug output to standard error.
-e, --errors
Report errors to standard error. Errors are reported by default when writing to a file; this option ensures they are reported when writing to standard output.
-f, --fragment
Generate only an HTML fragment without the standard man page header and footer.
-h, --help
Display a help message and exit.
-i, --indent
Indent the roff output. Useful for debugging the generated roff source.
-l, --list
List the names of the files that would be generated for the specified input, without actually creating them.
-m, --man
Generate output formatted for the man(1) pager. This is equivalent to running man(1) on the input file after processing.
-o, --compile-only
Compile the specified input file(s) to roff and HTML output files, but do not run the man(1) pager.
-p, --pipe
Pipe the input file through the man(1) pager. Useful for previewing changes without writing output files.
-q, --quiet
Suppress informational messages about generated files.
-r, --roff
Generate only roff output.
-s, --style styles
Select a comma-separated list of CSS stylesheets to be included in the generated HTML. See STYLES for details.
-S, --server [port]
Start a web server to serve man pages generated from the specified input files. The server listens on the given port, or port 1207 by default. This option implies --html.
-t, --html
Generate only HTML output.
-w, --width width
Set the display width for generated man pages. Default is 100 columns. Also affects the default width of the HTML output.
--
Option processing will terminate.

LINK INDEXES

Ronn can use external reference files, named index.txt, to provide links to man pages or other documents. These files are searched for in the input directory and in directories specified by the RONN_STYLE environment variable.

An index.txt file contains a list of references, one per line, in the format:

id: location [text]

Where:

id
A unique identifier for the reference. This is used in the Markdown link syntax [text][id].
location
An absolute or relative URL pointing to the referenced document. For man pages, this is typically a URL to an HTML version, e.g.: 
ls(1): https://man7.org/linux/man-pages/man1/ls.1.html
text (optional)
Alternative link text. If not provided, the id is used as the link text.

Example index.txt contents:

grep(1): https://man7.org/linux/man-pages/man1/grep.1.html
ls(1): https://man7.org/linux/man-pages/man1/ls.1.html
src: https://github.com/

The location is an absolute or relative URL that usually points at an HTML version of manpage. It's possible to define references for things that aren't manpages.

All manuals in an individual directory share the references defined in that directory's index.txt file. Index references may be used explicitly in Markdown reference style links using the syntax: [text][id], where text is the link text and id is a reference name defined in the index.

STYLES

The --style option selects a list of CSS stylesheets to include in the generated HTML. Styles are applied in the order defined, so each can use the cascade to override previously defined styles.

Builtin Stylesheets

These styles are included with the distribution:

man
Basic manpage styles: typography, definition lists, indentation. This is always included regardless of --style argument. It is however possible to replace the default man module with a custom one by placing a man.css file on the RONN_STYLE path.
print
Basic print stylesheet. The generated <style> tag includes a media=print attribute.
toc
Enables the Table of Contents navigation. The TOC markup is included in generated HTML by default but hidden with an inline display:none style rule; the toc module turns it on and applies basic TOC styles.
dark
Light text on a dark background.
80c
Changes the display width to mimic the display of a classic 80 character terminal. The default display width causes lines to wrap at a gratuitous 100 characters.

Custom Stylesheets

Writing custom stylesheets is straight-forward. The following core selectors allow targeting all generated elements:

.mp
The manual page container element. Present on full documents and document fragments.
body#manpage
Signifies that the page was fully-generated by Ronn and contains a single manual page (.mp element).
.man-decor
The three-item heading and footing elements both have this class.
.man-head, .man-foot
The heading and footing, respectively.
.man-title
The main <h1> element. Hidden by default unless the manual has no name or section attributes.

See the builtin style sources https://github.com/apjanke/ronn-ng/tree/main/lib/ronn/template for examples.

EXAMPLES

Build roff and HTML output files and view the roff manpage using man(1):

$ ronn some-great-program.1.ronn
roff: some-great-program.1
html: some-great-program.1.html
$ man ./some-great-program.1

Build only the roff manpage for all .ronn files in the current directory:

$ ronn --roff *.ronn
roff: mv.1
roff: ls.1
roff: cd.1
roff: sh.1

Build only the HTML manpage for a few files and apply the dark and toc stylesheets:

$ ronn --html --style=dark,toc mv.1.ronn ls.1.ronn
html: mv.1.html
html: ls.1.html

Generate roff output on standard output and write to file:

$ ronn <hello.1.ronn >hello.1

View a ronn file in the same way as man(1) without building a roff file:

$ ronn --man hello.1.ronn

Serve HTML manpages at http://localhost:1207/ for all *.ronn files under a man/ directory:

$ ronn --server man/*.ronn
$ open http://localhost:1207/

ENVIRONMENT

RONN_MANUAL
A default manual name to be displayed in the top-center header area. The --manual option takes precedence over this value.
RONN_ORGANIZATION
The default manual publishing group, organization, or individual to be displayed in the bottom-left footer area. The --organization option takes precedence over this value.
RONN_DATE
The default manual date in YYYY-MM-DD format. Displayed in the bottom-center footer area. The --date option takes precedence over this value.
RONN_STYLE
A PATH-style list of directories to check for stylesheets given to the --style option. Directories are separated by a :; blank entries are ignored. Use . to include the current working directory.
MANPAGER
The paging program used for man pages. This is typically set to something like 'less -is'.
PAGER
Used instead of MANPAGER when MANPAGER is not defined.
