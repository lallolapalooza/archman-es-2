subrutina drotm (entero n, doble precisión, dimensión(*) dx, entero incx, doble precisión, dimensión(*) dy, entero incy, doble precisión, dimensión(5) dparam)

DROTM

Propósito:

!>
!>    APLICAR LA TRANSFORMACIÓN DE GIVENS MODIFICADA, H, A LA MATRIZ DE 2 POR N
!>
!>    (DX**T) , DONDE **T INDICA TRANSPUESTA. LOS ELEMENTOS DE DX ESTÁN EN
!>    (DY**T)
!>
!>    DX(LX+I*INCX), I = 0 A N-1, DONDE LX = 1 SI INCX .GE. 0, DE LO CONTRARIO
!>    LX = (-INCX)*N, Y DE FORMA SIMILAR PARA SY USANDO LY E INCY.
!>    CON DPARAM(1)=DFLAG, H TIENE UNA DE LAS SIGUIENTES FORMAS..
!>
!>    DFLAG=-1.D0     DFLAG=0.D0        DFLAG=1.D0     DFLAG=-2.D0
!>
!>      (DH11  DH12)    (1.D0  DH12)    (DH11  1.D0)    (1.D0  0.D0)
!>    H=(          )    (          )    (          )    (          )
!>      (DH21  DH22),   (DH21  1.D0),   (-1.D0 DH22),   (0.D0  1.D0).
!>    VER DROTMG PARA UNA DESCRIPCIÓN DEL ALMACENAMIENTO DE DATOS EN DPARAM.
!>

Parámetros

N 
!>          N es ENTERO
!>         número de elementos en el vector(es) de entrada
!>

DX

!>          DX es un array de DOBLE PRECISIÓN, dimensión ( 1 + ( N - 1 )*abs( INCX ) )
!>

INCX

!>          INCX es ENTERO
!>         espaciado de almacenamiento entre elementos de DX
!>

DY

!>          DY es un array de DOBLE PRECISIÓN, dimensión ( 1 + ( N - 1 )*abs( INCY ) )
!>

INCY

!>          INCY es ENTERO
!>         espaciado de almacenamiento entre elementos de DY
!>

DPARAM

!>          DPARAM es un array de DOBLE PRECISIÓN, dimensión (5)
!>     DPARAM(1)=DFLAG
!>     DPARAM(2)=DH11
!>     DPARAM(3)=DH21
!>     DPARAM(4)=DH12
!>     DPARAM(5)=DH22
!>
