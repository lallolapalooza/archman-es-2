ROFIMOJI(1) Documentación del complemento de terceros de Rofi ROFIMOJI(1)

NOMBRE

rofimoji - Un selector de emojis y caracteres generales para rofi y similares a rofi

SINOPSIS

rofimoji [-h] [--version] [--action {type,copy,clipboard,type-numerical,unicode,copy-unicode,print,menu}] [--skin-tone {neutral,light,medium-light,moderate,dark brown,black,ask}] [--files {all,FILE [FILE ...]]} [--prompt PROMPT] [--selector-args SELECTOR_ARGS] [--max-recent MAX_RECENT] [--no-frecency] [--hidden-descriptions] [--clipboarder CLIPBOARDER] [--typer TYPER] [--selector SELECTOR]

DESCRIPCIÓN

Selecciona, inserta o copia caracteres Unicode como emojis usando rofi.

OPCIONES

-h, --help
Imprime información breve de uso.
--version
muestra el número de versión del programa y sale
--action, -a
Valores posibles: type, copy, clipboard, type-numerical, unicode, copy-unicode, print, menu

Elige qué hacer con los caracteres seleccionados: Escríbelos directamente con el "Typer", cópialos al portapapeles usando el "Clipboarder", o insértalos indirectamente usando el portapapeles. Para usar la funcionalidad de la tecla de composición, elige "type-numerical:.”unicode” escribirá los puntos de código unicode de los caracteres elegidos, “copy-unicode” lo copiará. “print” simplemente los muestra en stdout. Si quieres decidir espontáneamente, usa “menu”.

--files ARCHIVO [ARCHIVO ...], -f ARCHIVO [ARCHIVO ...]
Lee caracteres de este archivo (o estos archivos), una entrada por línea. Se admiten rutas absolutas y relativas, así como globbing (--files /home/tú/characters.csv ../other*.csv). Un nombre de archivo sin extensión es suficiente (--files musical_symbols supplemental_arrows) para los archivos de caracteres incluidos y todos los de ${XDG_DATA_HOME}/rofimoji/data. Aquí, también se admite el globbing y se hace por defecto. En el archivo de configuración, varios archivos deben listarse como files=[_ARCHIVO_, _ARCHIVO_].
--skin-tone=tono-piel, -s tono-piel
Valores posibles: neutral, light, medium-light, moderate, dark brown, black, ask

Decide un tono de piel para todos los emojis compatibles. Si no se establece (o se establece en "ask"), se te preguntará por cada uno.

--max-recent MAX-RECENT
Muestra como máximo este número de caracteres usados recientemente (no puede ser mayor que 10)
--no-frecency
No muestres caracteres usados frecuentemente al principio.
--hidden-descriptions
Solo lista los caracteres, pero no sus descripciones. Ten en cuenta que todavía puedes buscar a través de las descripciones. Solo se usa para rofi.
--use-icons
Muestra caracteres como iconos en rofi. No se usa con otros selectores.
--prompt PROMPT, -r PROMPT
Establece el prompt de rofimoji
--selector-args SELECTOR-ARGS
Una cadena de argumentos para pasar al selector.
--selector SELECTOR
Valores posibles: rofi, wofi, fuzzel, bemenu, tofi, dmenu, wmenu, choose

Elige la aplicación selectora manualmente. Normalmente rofi, pero es posible que quieras otra cosa.

--clipboarder CLIPBOARDER
Valores posibles: xsel, xclip, wl-copy, pbcopy

Elige la aplicación para acceder al portapapeles manualmente.

--typer TYPER
Valores posibles: xdotool, wtype, ydotool, cliclick

Elige la aplicación para escribir manualmente.

--keybinding-copy, --keybinding-type, --keybinding-clipboard, --keybinding-unicode, --keybinding-copy-unicode
Define diferentes atajos de teclado para estas acciones.

ATAJOS DE TECLADO

(opcional) Selecciona varios emojis con shift+enter

enter para insertar el emoji directamente

alt+c para copiarlo al portapapeles

alt+t para escribirlo directamente

alt+p para insertar usando el portapapeles

alt+1, alt+2 para insertar el carácter usado más recientemente (alt+2 para el segundo más reciente, etc.)

alt+u para insertar el punto de código Unicode

alt+i para copiar el punto de código Unicode al portapapeles

Ten en cuenta que wofi no admite atajos de teclado excepto enter.

ARCHIVOS

~/.config/rofimoji.rc
Archivo de configuración por usuario.
/etc/xdg/xdg-i3/rofimoji.rc
Archivo de configuración global.
~/.local/share/rofimoji/recent
Almacena los caracteres usados recientemente
~/.local/share/rofimoji/data/nombre-archivo.additional.csv
Contiene caracteres adicionales o descripciones adicionales para el conjunto de caracteres en nombre-archivo

CONFIGURACIÓN

Los argumentos que comienzan con "--" (por ejemplo, --version) también se pueden establecer en un archivo de configuración.

La sintaxis del archivo de configuración permite: clave=valor, flag=true, stuff=[a,b,c] (para más detalles, ver la sintaxis en https://github.com/fdw/rofimoji#example-config-file). Si un argumento se especifica en más de un lugar, los valores de la línea de comandos anulan los valores del archivo de configuración.
