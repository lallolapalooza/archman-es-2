subrutina drotmg (doble precisión dd1, doble precisión dd2, doble precisión dx1, doble precisión dy1, doble precisión, dimensión(5) dparam)

DROTMG

Propósito:

!>
!>    CONSTRUYE LA MATRIZ DE TRANSFORMACIÓN DE GIVENS MODIFICADA H QUE
!>    PONE A CERO EL SEGUNDO COMPONENTE DEL VECTOR 2 (DSQRT(DD1)*DX1,DSQRT(DD2)*>    DY2)**T.
!>    CON DPARAM(1)=DFLAG, H TIENE UNA DE LAS SIGUIENTES FORMAS..
!>
!>    DFLAG=-1.D0     DFLAG=0.D0        DFLAG=1.D0     DFLAG=-2.D0
!>
!>      (DH11  DH12)    (1.D0  DH12)    (DH11  1.D0)    (1.D0  0.D0)
!>    H=(          )    (          )    (          )    (          )
!>      (DH21  DH22),   (DH21  1.D0),   (-1.D0 DH22),   (0.D0  1.D0).
!>    LAS POSICIONES 2-4 DE DPARAM CONTIENEN DH11, DH21, DH12 Y DH22
!>    RESPECTIVAMENTE. (LOS VALORES DE 1.D0, -1.D0 O 0.D0 IMPLICADOS POR
!>    EL VALOR DE DPARAM(1) NO SE ALMACENAN EN DPARAM.)
!>
!>    LOS VALORES DE GAMSQ Y RGAMSQ ESTABLECIDOS EN LA DECLARACIÓN DE
!>    DATOS PUEDEN SER INEXACTOS. ESTO ESTÁ BIEN YA QUE SOLO SE USAN
!>    PARA PROBAR EL TAMAÑO DE DD1 Y DD2. TODO EL ESCALADO REAL DE
!>    LOS DATOS SE HACE USANDO GAM.
!>
!>

Parámetros

DD1 
!>          DD1 es DOBLE PRECISIÓN
!>

DD2

!>          DD2 es DOBLE PRECISIÓN
!>

DX1

!>          DX1 es DOBLE PRECISIÓN
!>

DY1

!>          DY1 es DOBLE PRECISIÓN
!>

DPARAM

!>          DPARAM es un array de DOBLE PRECISIÓN, dimensión (5)
!>     DPARAM(1)=DFLAG
!>     DPARAM(2)=DH11
!>     DPARAM(3)=DH21
!>     DPARAM(4)=DH12
!>     DPARAM(5)=DH22
!>
