NOMBRE

rofi-actions - Comandos personalizados tras la interacción con menús de rofi

DESCRIPCIÓN

rofi permite establecer comandos o scripts personalizados para que se ejecuten cuando se realizan acciones en el menú, como cambiar la selección, aceptar una entrada o cancelar.

Esto hace posible, por ejemplo, reproducir efectos de sonido o leer en voz alta las entradas del menú al seleccionarlas.

USO

A continuación se presenta la lista de indicadores de rofi para especificar comandos o scripts personalizados para ejecutar en acciones soportadas:

-on-selection-changed cmd
Comando o script para ejecutar cuando cambia la selección actual. El texto seleccionado se envía al comando reemplazando el patrón {entry}.
-on-entry-accepted cmd
Comando o script para ejecutar cuando se acepta una entrada del menú. El texto aceptado se envía al comando reemplazando el patrón {entry}.
-on-mode-changed cmd
Comando o script para ejecutar cuando se cambia el modo del menú (por ejemplo, drun, window, ssh...).
-on-menu-canceled cmd
Comando o script para ejecutar cuando se cancela el menú.
-on-menu-error cmd
Comando o script para ejecutar cuando se muestra un menú de error (por ejemplo, rofi -e "mensaje de error"). El texto del error se envía al comando reemplazando el patrón {error}.
-on-screenshot-taken cmd
Comando o script para ejecutar cuando se toma una captura de pantalla de rofi. La ruta de la captura de pantalla se envía al comando reemplazando el patrón {path}.

Ejemplo de uso

Línea de comandos de Rofi:

rofi -on-selection-changed "/ruta/a/select.sh {entry}" \
     -on-entry-accepted "/ruta/a/accept.sh {entry}" \
     -on-menu-canceled "/ruta/a/exit.sh" \
     -on-mode-changed "/ruta/a/change.sh" \
     -on-menu-error "/ruta/a/error.sh {error}" \
     -on-screenshot-taken "/ruta/a/camera.sh {path}" \
     -show drun

Archivo de configuración de Rofi:

configuration {
    on-selection-changed: "/ruta/a/select.sh {entry}";
    on-entry-accepted: "/ruta/a/accept.sh {entry}";
    on-menu-canceled: "/ruta/a/exit.sh";
    on-mode-changed: "/ruta/a/change.sh";
    on-menu-error: "/ruta/a/error.sh {error}";
    on-screenshot-taken: "/ruta/a/camera.sh {path}";
}

Reproducir efectos de sonido

Aquí hay un ejemplo de script bash que reproduce un efecto de sonido usando aplay cuando cambia la selección actual:

#!/bin/bash
coproc aplay -q $HOME/Musica/selecting_an_item.wav

Se sugiere el uso de coproc para reproducir sonidos, de lo contrario, el proceso de rofi esperará a que termine la reproducción del sonido antes de salir.

Leer en voz alta

Aquí hay un ejemplo de script bash que lee en voz alta las entradas actualmente seleccionadas usando espeak:

#!/bin/bash
killall espeak
echo "seleccionado: $@" | espeak
rofi
