ros-install - Instalar implementaciones de lisp o sistema quicklisp

Sinopsis

•
ros install sistema [sistema ...]
•
ros install impl[/versión] [param ...]

Descripción

sistema
un nombre que especifica un sistema.
impl
un nombre que especifica una implementación de lisp.

Instalando una Implementación de Lisp

Cuando el impl o sistema coincide con una de las implementaciones soportadas, descarga, baja e instala en uno de los directorios internos gestionados por roswell (~/.roswell, o ROSWELL_INSTALL_DIR). Para usar la implementación instalada, debes ejecutar ros-use(1).

Por ejemplo, el siguiente comando descarga el último binario sbcl de sbcl.org. Ten en cuenta que esto puede ser diferente del binario por defecto instalado por roswell, llamado sbcl-bin. sbcl-bin es una versión estable y bien probada del binario sbcl que se supone es un poco más antigua que la última versión de sbcl.

$ ros install sbcl

Cuando se invoca sin un nombre, imprime la lista de implementaciones instalables. (No confundir con ros list installed, que muestra las implementaciones ya instaladas.)

Usage: ros install impl [OPTIONS]
For more details on impl specific options, type:
ros help install impl
Candidates impls for installation are:
ecl
sbcl
clisp
ccl-bin
sbcl-bin

El nombre puede ir opcionalmente seguido por una barra / y una versión de la implementación.

$ ros install sbcl/1.2.14

Puede haber algunas implementaciones *ocultas* que no se listan aquí — están en calidad alfa, pero prueba la que quieras o consulta el sitio web (https://github.com/roswell/roswell).

$ ros install ccl
$ ros install abcl
$ ...

Instalando un sistema quicklisp y los scripts roswell incluidos

Si el nombre especificado no coincide con ninguna de las implementaciones, roswell intenta encontrar un sistema quicklisp con el nombre dado.

$ ros install alexandria

Después de compilar y cargar el sistema, llama a la variable especial ros:*build-hook* sin argumentos, si hay alguna función establecida durante la compilación/carga.

Cuando el sistema viene con un script roswell creado por ros-init(1) en el subdirectorio roswell, se instalan en ROSWELL_INSTALL_DIR/bin. Establecer la ruta a este directorio hace que estos scripts estén disponibles desde la línea de comandos de la shell.

$ ros install qlot
System 'qlot' found. Loading the system..
Processing build-hook..
Found 1 scripts: qlot
Attempting to install the scripts in roswell/ subdirectory of the system...
/home/user/.roswell/bin/qlot
$ qlot
Usage: qlot [install | update | bundle | exec shell-args..]
