NOMBRE

rofi-thumbnails - Sistema de miniaturas de Rofi

DESCRIPCIÓN

rofi ahora es capaz de mostrar miniaturas para todos los tipos de archivo para los que exista un generador de miniaturas compatible con XDG en el sistema.

Esto se hace por defecto en los modos filebrowser y recursivebrowser, si rofi se inicia con el argumento -show-icons.

En un script de usuario personalizado o en modo dmenu, es posible producir iconos de entrada utilizando generadores de miniaturas XDG añadiendo el prefijo thumbnail:// al nombre del archivo especificado después de \0icon\x1f, por ejemplo:

echo -en "NombreEntrada\0icon\x1fthumbnail://ruta/al/archivo\n" | rofi -dmenu -show-icons

Generadores de miniaturas XDG

Los generadores de miniaturas XDG son archivos con el sufijo “.thumbnailer” y una estructura similar a los archivos “.desktop” para lanzar aplicaciones. Se colocan en /usr/share/thumbnailers/ o $HOME/.local/share/thumbnailers/, y contienen una lista de tipos MIME, para los cuales es posible producir la imagen en miniatura, y una cadena con el comando para crear dicha imagen. El siguiente ejemplo muestra el contenido de librsvg.thumbnailer, un generador de miniaturas para archivos svg que utiliza librsvg:

[Thumbnailer Entry]
TryExec=/usr/bin/gdk-pixbuf-thumbnailer
Exec=/usr/bin/gdk-pixbuf-thumbnailer -s %s %u %o
MimeType=image/svg+xml;image/svg+xml-compressed;

Las imágenes producidas se nombran como el md5sum de los archivos de entrada y se colocan, dependiendo de su tamaño, en los directorios de miniaturas XDG: $HOME/.cache/thumbnails/{normal,large,x-large,xx-large}. Luego son cargadas por rofi como iconos de entrada y también pueden ser utilizadas por gestores de archivos como Thunar, Caja o KDE Dolphin para mostrar sus miniaturas. Adicionalmente, si se encuentra una miniatura para un archivo en los directorios de miniaturas (producida previamente por rofi o un gestor de archivos), rofi la cargará en lugar de llamar al generador de miniaturas.

Si no se encuentra un generador de miniaturas adecuado para un archivo dado, rofi intentará utilizar el icono del tipo MIME correspondiente del tema de iconos.

Comando personalizado para crear miniaturas

Es posible usar un comando personalizado para generar miniaturas para nombres de entrada genéricos, por ejemplo, un script que descargue un icono dada su URL o seleccione diferentes iconos dependiendo de la entrada. Esto se puede hacer proporcionando el argumento -preview-cmd seguido de una cadena con el comando a ejecutar, con la siguiente sintaxis:

rofi ... -preview-cmd 'ruta/al/script_o_comando "{input}" "{output}" "{size}"'

rofi llamará al script o comando sustituyendo {input} con el nombre del icono de entrada (la cadena después de \0icon\x1fthumbnail://), {output} con el nombre del archivo de salida de la miniatura y {size} con el tamaño de miniatura solicitado. El script o comando es responsable de producir una imagen en miniatura (si es posible respetando el tamaño solicitado) y guardarla en el nombre de archivo {output} proporcionado.

Problemas con AppArmor

En distribuciones de Linux que utilizan AppArmor (como Ubuntu y Debian), las reglas por defecto incluidas pueden causar problemas con la generación de miniaturas. Si este es el caso, AppArmor se puede deshabilitar emitiendo los siguientes comandos:

sudo systemctl stop apparmor
sudo systemctl disable apparmor

Alternativamente, el siguiente perfil de AppArmor se puede colocar en un archivo llamado /etc/apparmor.d/usr.bin.rofi

#vim:syntax=apparmor
# AppArmor policy for rofi
#include <tunables/global>
/usr/bin/rofi {
    #include <abstractions/base>
    # TCP/UDP network access for NFS
    network inet  stream,
    network inet6 stream,
    network inet  dgram,
    network inet6 dgram,
    /usr/bin/rofi mr,
    @{HOME}/ r,
    @{HOME}/** rw,
    owner @{HOME}/.cache/thumbnails/** rw,
}

luego ejecutar

apparmor_parser  -r /etc/apparmor.d/usr.bin.rofi

para recargar la regla. Esto asume que el binario rofi está en /usr/bin, que es el caso de una instalación de paquete estándar.

rofi
