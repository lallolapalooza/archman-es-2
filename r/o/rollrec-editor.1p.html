NOMBRE

rollrec-editor - Editor GUI de Rollrec de DNSSEC-Tools

SINOPSIS

rollrec-editor [opciones] <archivo-rollrec>

DESCRIPCIÓN

rollrec-editor proporciona la capacidad para una fácil gestión basada en GUI de archivos rollrec. Un archivo rollrec contiene uno o más registros rollrec. Estos registros son utilizados por las utilidades de rolado de DNSSEC-Tools (rollerd, etc.) para describir el estado de rolado de las zonas. Cada registro rollrec de una zona contiene información como el archivo de zona, la fase de rolado y el nivel de registro. Los archivos rollrec son archivos de texto y pueden ser editados por cualquier editor de texto. rollrec-editor permite editar solo aquellos registros que un usuario debe cambiar y realiza comprobaciones de errores en los datos.

Cuando rollrec-editor se inicia, se crea una ventana que tiene "botones" para cada registro rollrec en el archivo rollrec dado. (En esta documentación, esta ventana se llama Ventana de Botones.) Hacer clic en los botones selecciona (o deselecciona) esa zona. Después de que una o más zonas son seleccionadas, se puede ejecutar uno de varios comandos. Los comandos permiten la modificación y eliminación de registros rollrec existentes, la creación de nuevos registros rollrec, la fusión de archivos rollrec y la verificación de la validez del archivo.

Los comandos de rollrec-editor están disponibles a través de los menús y la mayoría tiene un acelerador de teclado. Los comandos se describen a continuación en la sección COMANDOS.

Cuando un registro rollrec es seleccionado para modificación, se crea una nueva ventana para contener los campos editables del registro. Los campos pueden ser modificados in situ. Cuando se completa la edición, el registro se "guarda". Esto no guarda el rollrec modificado en su archivo en disco; el archivo debe ser guardado explícitamente desde la Ventana de Botones.

Como se mencionó anteriormente, se realizan comprobaciones de verificación al guardar un registro rollrec editado. Un conjunto de comprobaciones asegura que los archivos y directorios asociados con una zona existen realmente. Esta comprobación puede desactivarse al iniciar el comando con la opción de línea de comandos -ignore-warns. Puede ser modificada durante la ejecución con el comando de menú "Ignorar Advertencias de Edición".

Diseño de la Ventana de Botones

La Ventana de Botones contiene un botón para cada registro rollrec en el archivo seleccionado. Los botones están dispuestos en una tabla con al menos tres columnas. El número de columnas puede establecerse al iniciar el comando con la opción de línea de comandos -columns. Puede ser modificado durante la ejecución con el comando de menú "Columnas en la Ventana de Botones".

Al establecer el número de columnas, rollrec-editor minimiza el espacio necesario para mostrar los botones rollrec del archivo seleccionado. Esto a veces causará que el número de columnas sea diferente al solicitado.

Por ejemplo, supongamos que un archivo rollrec tiene 12 registros rollrec. La siguiente tabla muestra cuántas filas y columnas se dan para cada una de las selecciones de columnas dadas.

número de columnas    filas    columnas
      1          12        1
      2          6         2
      3          4         3
      4          3         4
      5          3         4
      6          2         6
      7          2         6
      8          2         6
      9          2         6
      10         2         6
      11         2         6
      12         1         12

Las filas y columnas reales para un número de columnas solicitado variarán para permitir un "ajuste óptimo".

DESHACIENDO MODIFICACIONES

La capacidad de "deshacer" no está implementada actualmente.

rollrec-editor tiene la capacidad de revertir modificaciones que ha realizado en un archivo rollrec. Esta restauración histórica solo funcionará para las modificaciones realizadas durante una ejecución particular de rollrec-editor; las modificaciones realizadas durante una ejecución anterior no podrán deshacerse.

Después de una operación de "Guardar", los datos requeridos para revertir las modificaciones se eliminan. Este no es el caso de la operación "Guardar Como".

OPCIONES

rollrec-editor soporta las siguientes opciones.

-columns columnas
Esta opción permite al usuario especificar el número de columnas a usar en la Ventana de Botones.
-ignore-warns
Esta opción hace que rollrec-editor ignore las advertencias de edición al realizar comprobaciones de validación en el contenido de los registros rollrec.
-no-filter
Esta opción desactiva el filtrado de nombres cuando rollrec-editor presenta un diálogo de selección de archivos para elegir un nuevo archivo rollrec. Si esta opción no se proporciona, el diálogo de selección de archivos solo listará archivos regulares con la extensión .rrf.
-Version
Muestra la información de la versión de rollrec-editor y del paquete DNSSEC-Tools.

rollrec-editor

Perl/Tk script to edit rollrec files.

SYNOPSIS

rollrec-editor [-help] [-options] [rollrec_file]

DESCRIPTION

The rollrec-editor is a Perl/Tk application that allows users to create and edit rollrec files. rollrec files contain lists of DNSSEC key-signing keys (KSK) and zone-signing keys (ZSK) that are used by DNSSEC-Tools for key management.

The rollrec-editor presents the user with a window that displays a list of buttons, one for each rollrec record in the currently open rollrec file. The application is menu-driven, and the available commands are described below.

Button Window Layout

The Button Window displays a grid of buttons, each representing a rollrec record. The user can configure the number of columns in this window using the Options Menu. If there are too many rollrec records to fit in the available space, the Button Window will contain scrollbars.

Clicking a button will select or deselect the corresponding rollrec record. Multiple records may be selected at a time. The selected rollrec records are indicated by the buttons being depressed. The current state of the rollrec record (e.g., modified, new, etc.) is indicated by the color of the button.

Edit Window Layout

An Edit Window is opened for editing a rollrec record. The Edit Window contains fields for the various parameters of a rollrec record. These fields are described below.

When an Edit Window is opened, the corresponding button in the Button Window is selected. When the Edit Window is closed, the corresponding button is deselected.

Rollrec Record Fields

The following fields can be edited in an Edit Window:

Name
The name of the rollrec record. This is the name that will be used when referring to this record in other rollrec records or when generating DNSSEC keys. The name must be a valid DNS name.
Type
The type of the rollrec record. This can be either "roll" or "skip". A "roll" record indicates a key that should be rolled (i.e., generated and published). A "skip" record indicates a key that should be skipped (i.e., not generated or published).
Key File
The path to the key file for this rollrec record. This file contains the private key for the DNSSEC key.
Algorithm
The cryptographic algorithm used for this rollrec record. This can be one of the algorithms supported by BIND, such as RSASHA1, RSASHA256, ECDSAP256SHA256, etc.
Bits
The number of bits in the cryptographic key. This typically ranges from 1024 to 4096 for RSA keys.
Active
A flag indicating whether this rollrec record is currently active. An active record will be used for key generation and publication. An inactive record will be ignored.
Generated
A flag indicating whether the key for this rollrec record has been generated. If this is set, then the key file must exist.
Published
A flag indicating whether the key for this rollrec record has been published. If this is set, then the key has been added to the zone's DNS records.
Next Key File
The path to the next key file for this rollrec record. This is used when rolling keys to a new key.
Next Active
A flag indicating whether the next key for this rollrec record is active. This is used when rolling keys to a new key.
Next Generated
A flag indicating whether the next key for this rollrec record has been generated. This is used when rolling keys to a new key.
Next Published
A flag indicating whether the next key for this rollrec record has been published. This is used when rolling keys to a new key.

File Menu

The File Menu contains commands for managing rollrec files.

New
Create a new, empty rollrec file. If the current rollrec file has been modified, the user will be prompted to save the changes before creating the new file.
Open
Open an existing rollrec file for editing. If the current rollrec file has been modified, the user will be prompted to save the changes before opening the new file. A file-selection dialog box will appear, allowing the user to choose the rollrec file to open.
Save
Save the current rollrec file to disk. If the file has not been saved before, the user will be prompted for a filename. All modifications made since the last save will be written to the file.
Save As...
Save the current rollrec file to a new filename. The user will be prompted for the new filename. This command does not affect the currently open file.
Close
Close the current rollrec file. If the file has been modified, the user will be prompted to save the changes before closing.
Quit
Exit the rollrec-editor application. If the current rollrec file has been modified, the user will be prompted to save the changes before quitting.

Edit Menu

The Edit Menu contains commands for editing rollrec records.

New Rollrec
Create a new, empty rollrec record. A new Edit Window will be opened, and the corresponding button will be added to the Button Window. The new record will be initially marked as modified.
Edit Selected
Open an Edit Window for each selected rollrec record. If no rollrec records are selected, this command will open an Edit Window for the most recently selected record.
Delete Selected
Delete the selected rollrec records. The corresponding buttons will be removed from the Button Window. The user will be prompted to confirm the deletion.
Save Changes
Save the changes made in the currently open Edit Window. The Edit Window will close, and the corresponding button in the Button Window will be updated to reflect the new state. If there are any errors in the edited fields, the changes will not be saved, and an error message will be displayed. If the ignore-warnings flag is set, then warnings will not prevent the save. Errors will always prevent the save.
Cancel Changes
Discard the changes made in the currently open Edit Window. The Edit Window will close, and the corresponding button in the Button Window will remain unchanged. The user will be prompted to confirm the cancellation if any changes have been made.
Undo Changes
Undo the last change made to the current rollrec record. This command is not currently implemented.

When an edit window goes away (after a "Save" or "Cancel"), the rollrec record's button is deselected.

After editing is completed, the "Save" button will add the new rollrec record to the in-memory rollrec file. The file must be saved in order to have the new rollrec added to the file.

Potentially erroneous conditions will be reported to the user at save time. If the ignore-warnings flag has been turned on, then these warnings will not be reported. Errors (e.g., invalid log conditions) will always be reported.

Rename Selected Rollrec
Rename the selected rollrec record. The name in the rollrec's "roll" or "skip" line will be changed to the new name. Only one rollrec may be renamed at a time, and it may not be edited while the rename is taking place.

If the rollrec has been modified, the new contents must be written to disk prior to the rename happening. The user will be prompted to ensure that this the user wishes to continue.

Merge Rollrec Files
Merge a rollrec file with the currently open rollrec file. After a successful merge, the rollrec records in the second file will be added to the end of the currently open rollrec file.

If there are any rollrec name collisions in the files, then the user will be asked whether to continue with the merge or cancel it. If the merge continues, then the conflicting rollrec records from the "new" file will be discarded in favor of the currently open rollrec file.

Verify Rollrec File
Verify the validity of the rollrec file. The user-editable fields in the open rollrec file are checked for validity. An edit window is opened for each rollrec record that registers an error or warning.

If the ignore-warnings flag has been turned on, then potentially erroneous conditions will not be reported. Errors (e.g., invalid log conditions) will always be reported.

Summarize Problems
Summarize the warning and error counts of the rollrec file. Each rollrec record in the open rollrec file is checked for validity. If any warnings or errors are found, a window is displayed that lists the name of each rollrec record and its warning and error counts.

If the ignore-warnings flag has been turned on, then potentially erroneous conditions will not be reported. Errors (e.g., invalid log conditions) will always be reported.

View Menu

The View Menu contains miscellaneous commands for viewing edit windows.

Select All Rollrecs/Unselect All Rollrecs
Select or unselect all rollrec buttons. All the buttons in the Button Window will be selected or unselected. If any of the buttons are not selected, this command will cause all the buttons to become selected. If all of the buttons are selected, this command will cause all the buttons to be deselected.

This command is a toggle that switches between Select All Rollrecs and Unselect All Rollrecs.

Reveal Rollrec Edit Windows
Raise all rollrec edit windows. This command brings all rollrec edit windows to the front so that any that are hidden behind other windows will become visible.
Close Rollrec Edit Windows
Close all rollrec edit windows. This command closes and deselects all rollrec edit windows.

Options Menu

The Options Menu allows the user to set several options that control rollrec-editor behavior.

Ignore Edit Warnings/Don't Ignore Edit Warnings
Certain operations perform validation checks on the contents of rollrec records. Warnings and errors may be reported by these checks. This option controls whether or not warnings are flagged during validation. If they are flagged, then the operation will not continue until the warning condition is fixed or the operation canceled. If the warnings are ignored, then the operation will complete without the condition being fixed.

This command is a toggle that switches between Ignore Edit Warnings mode and Don't Ignore Edit Warnings mode.

Filter Name Selection/Don't Filter Name Selection
When opening rollrec files for editing or merging, a file-selection dialog box is displayed to allow the user to select a rollrec file. This option controls whether a filename filter is used by the dialog box. If Filter Names Selection mode is used, then only regular files with a suffix of .rrf will be displayed by the dialog box. If Don't Filter Name Selection mode is used, then all regular files will be displayed by the dialog box.

This command is a toggle that switches between Filter Name Selection display and Don't Filter Name Selection display.

Columns in Button Window
Set the number of columns used in the Button Window. See the Button Window Layout section for more information on columns in the Button Window.

Help Menu

The Help Menu contains commands for getting assistance.

Help
Display a help window.

REQUIREMENTS

rollrec-editor is implemented in Perl/Tk, so both Perl and Perl/Tk must be installed on your system.

KNOWN ISSUES

The following are known issues. These will be resolved in the fullness of time.

  • There is an issue with the column count and adding new rollrecs. It doesn't always work properly, thus occasionally leaving some rollrec buttons undisplayed.
  • There is no undo command.
