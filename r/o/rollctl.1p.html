NOMBRE

rollctl - Envía comandos al demonio de rotación de DNSSEC-Tools

SINOPSIS

rollctl [opciones]

DESCRIPCIÓN

El comando rollctl envía comandos al demonio de rotación de DNSSEC-Tools, rollerd. Solo se puede especificar una opción en una línea de comandos.

En la mayoría de los casos, rollerd enviará una respuesta a rollctl. rollctl mostrará un mensaje de éxito o fracaso, según corresponda.

Si rollctl se ejecuta como un comando empaquetado en PAR, utilizará su propia copia local del archivo dnssec-tools.conf. Este archivo se encontrará en el directorio del paquete.

OPCIONES

Las siguientes opciones son manejadas por rollctl.

-display
Inicia la GUI de estado de rotación.
-dspub zona
Indica que el padre de zona ha publicado un nuevo registro DS para zona.

Se pueden especificar múltiples zonas en la línea de comandos. Por ejemplo, este comando enviará el comando dspub a rollerd para tres zonas.

$ rollctl -dspub example1.com example2.com example3.com
-dspuball
Indica que se han publicado registros DS para todas las zonas en la fase 5 de la rotación KSK.
-group
Indica que el comando especificado debe aplicarse a un grupo de zonas en lugar de a una zona. En consecuencia, la zona especificada debe ser realmente un grupo de zonas. Esta opción debe usarse junto con otro comando.

Esta opción solo se aplica a los siguientes comandos: -dspub, -rollksk, -rollzone, -rollzsk y -skipzone. Este comando no tendrá ningún efecto si se da a otros comandos.

-halt [now]
Detiene limpiamente la ejecución de rollerd. Si se proporciona el parámetro opcional now, entonces rollerd se detendrá inmediatamente, en lugar de permitirle completar sus operaciones actualmente en cola.
-logfile logfile
Establece el archivo de registro de rollerd a logfile. Este debe ser un archivo de registro válido, lo que significa que si logfile ya existe, debe ser un archivo regular. Las únicas excepciones son si logfile es /dev/stdout o /dev/tty.
-loglevel loglevel
Establece el nivel de registro de rollerd a loglevel. Este debe ser uno de los niveles de registro válidos definidos en rollmgr.pm(3).

Si no se especifica un nivel de registro, se imprimirá la lista de niveles válidos y rollctl saldrá. La lista se proporciona en forma de texto y numérica.

-logtz logtz
Establece la zona horaria de registro de rollerd a loglevel. Debe ser gmt (para la hora media de Greenwich o local (para la hora local del host)).
-mergerrfs rollrec0 ... rollrecN
Indica a rollerd que fusione los archivos rollrec especificados con su archivo rollrec activo. Los nombres de los archivos rollrec no deben contener dos puntos.
-nodisplay
Detiene la GUI de estado de rotación.
-phasemsg longitud
longitud es la longitud por defecto de los mensajes relacionados con la fase utilizados por rollerd. Los niveles válidos son "long" y "short", siendo "long" el valor por defecto.

La longitud de mensaje larga significa que se incluirá una descripción de la fase con algunos mensajes de registro. Por ejemplo, la forma larga de un mensaje sobre la fase 3 de rotación ZSK será: "ZSK fase 3 (Esperando a que los datos de zona antiguos expiren de las cachés)".

La longitud de mensaje corta significa que no se incluirá una descripción de la fase con algunos mensajes de registro. Por ejemplo, la forma corta de un mensaje sobre la fase 3 de rotación ZSK será: "ZSK fase 3".

-rollall
Reanuda la rotación para todas las zonas en el archivo rollrec actual que han sido suspendidas. (Las zonas "skip" están suspendidas).
-rollallksks
Inicia la rotación KSK para todas las zonas definidas en el archivo rollrec actual que no estén actualmente en rotación.
-rollallzsks
Inicia la rotación ZSK para todas las zonas definidas en el archivo rollrec actual que no estén actualmente en rotación.
-rollksk zona
Inicia la rotación KSK para la zona nombrada por zona.

Se pueden especificar múltiples zonas en la línea de comandos. Por ejemplo, este comando enviará el comando rollksk a rollerd para tres zonas.

$ rollctl -rollksk example1.com example2.com example3.com
-rollrec archivo_rollrec
Establece el archivo rollrec a procesar por rollerd a archivo_rollrec.
-rollzone zona
Reanuda la rotación para la zona suspendida nombrada por zona.

Se pueden especificar múltiples zonas en la línea de comandos. Por ejemplo, este comando enviará el comando rollzone a rollerd para tres zonas.

$ rollctl -rollzone example1.com example2.com example3.com
-rollzsk zona
Inicia la rotación para la zona nombrada por zona.

Se pueden especificar múltiples zonas en la línea de comandos. Por ejemplo, este comando enviará el comando rollzsk a rollerd para tres zonas.

$ rollctl -rollzsk example1.com example2.com example3.com
-runqueue
Despierta a rollerd y hace que ejecute su cola de entradas de rollrec.
-shutdown
Sinónimo de -halt.
-signzone zona
Firma el archivo de zona de zona sin realizar ninguna acción de rotación. La zona se firma con las claves utilizadas más recientemente para firmar la zona. No se generarán nuevas claves.
-signzones [all | active]
Firma los archivos de zona de las zonas gestionadas por rollerd, sin realizar ninguna acción de rotación. Si se proporciona la opción all, se firmarán todas las zonas de rollerd. Si se proporciona la opción active, solo se firmarán las zonas que no estén en la etapa skip. Las zonas se firman con las claves utilizadas más recientemente para firmar cada zona. No se generarán nuevas claves.
-skipall
Suspende la rotación para todas las zonas en el archivo rollrec actual.
-skipzone zona
Suspende la rotación para la zona nombrada por zona.

Se pueden especificar múltiples zonas en la línea de comandos. Por ejemplo, este comando enviará el comando skipzone a rollerd para tres zonas.

$ rollctl -skipzone example1.com example2.com example3.com
-sleeptime segundos
Establece el tiempo de espera de rollerd a segundos segundos. sleeptime debe ser un entero al menos tan grande como el valor $MIN_SLEEP en rollerd.
-splitrrf nuevo-rrf zona0 ... zonaN
Indica a rollerd que mueva un conjunto de entradas de rollrec del archivo rollrec actual a un nuevo archivo. El nuevo archivo se nombra en el parámetro nuevo-rrf. Las entradas de rollrec cuyos nombres correspondan a zona0 a zonaN

rollctl(1p) — Arch Linux manual pages

NAME

rollctl — interface to the DNSSEC-Tools rollover daemon

SYNOPSIS

rollctl [ option ... ] [ command ] [ argument ...]

DESCRIPTION

The rollctl command is used to send control commands to the rollerd daemon. This program is part of the DNSSEC-Tools package, and is used to manage DNSSEC key rollovers.

The commands and their arguments are processed in the order in which they appear on the command line.

OPTIONS

-clear
Tells rollerd to clear all of its caches. This includes the rollover cache, the key cache, and the DNSKEY cache.
-config file
Specifies the configuration file to be used by rollerd. If this is not specified, then the default configuration file (usually located in /etc/dnssec-tools/rollerd.conf) will be used.
-debug level
Set the debugging level for rollerd. The debugging level is a numerical value. Higher values mean more debugging output. The new debugging level is only for the current execution of rollerd and is not saved to the active rollrec file.
-dump
Has rollerd dump its internal state to the log file. This is useful for debugging.
-execute file
Reads commands from the specified file and executes them. This is useful for running a sequence of commands.
-getlist
Requests a list of all the zones that rollerd is currently managing. The list is printed to the standard output.
-getlog
Requests the current log file from rollerd. The contents of the log file are printed to the standard output.
-getrollrec rollrec-file
Requests the contents of the specified rollrec-file from rollerd. The contents of the file are printed to the standard output. The name of the new rollrec file and the zone names must not contain colons.
-status
Has rollerd write several of its operational parameters to its log file. The parameters are also reported to rollctl, which prints them to the screen.
-zonegroup [zone-group]
Requests information about zone groups from rollerd. If the optional zone-group argument is not given, then rollerd will return a list of the defined zone groups and the number of zones in each. If a zone-group is specified, then rollerd will return a list of the zones in that group.

(While this is using the term "zone", it is actually referring to the name of the rollrec entries. For a particular rollrec entry, the rollrec name is usually the same as the zone name, but this is not a requirement.)

-zonelog
Set the logging level for the specified zone. The new logging level is only for the current execution of rollerd and is not saved to the active rollrec file.

The arguments for this command must be in the format "zone:loglevel". For example, this command will send the zonelog command to rollerd for three zones.

$ rollctl -zonelog example1.com:info example2.com:6 example3.com:err
-zonestatus
Has rollerd write the status of zones in the current rollrec file to the rollerd log file. The status is also reported to rollctl, which prints it to the screen. rollctl prints it in columnar fashion to enhance readability. The columns, in order, are: rollrec name, zone name, roll/skip state, and rollover phase.

Example:
anothersub anothersub.example.com skip KSK 1
example.com example.com roll KSK 1
site1.in.subzone.example.com subzone.example.com roll KSK 3
site1.subzone.example.com subzone.example.com roll KSK 3

-zsargs arglist zones
Provides additional zonesigner arguments for a given set of zones. These arguments will override the arguments in the DNSSEC-Tools defaults file, the DNSSEC-Tools configuration file, and the zones' keyrec files.

The zonesigner argument list is given in arglist. Given the rollctl argument processing, the new arguments for zonesigner cannot be specified as expected. Instead, the arguments should be given in the following manner. The leading dash should be replaced with an equals sign. If the option takes an argument, the space that would separate the option from the option's argument should also be replaced by an equals sign. rollerd translates these arguments to the appropriate format for zonesigner. These examples should clarify the modifications:

normal zonesigner option            -zsargs options
------------------------            ---------------
    -nokrfile                          =nokrfile
    -zskcount 5                        =zskcount=5

The zones list is a space-separated list of zones. All the new zonesigner arguments will be applied to all the listed zones.

The "=clear" argument is special. rollerd translates it to "-clear", which is not a normal zonesigner option. Instead, rollerd recognizes "-clear" as an indicator that it should remove the zsargs field from the rollrec records for the specified zones.

The following are valid uses of -zsargs:

# rollctl -zsargs =ksklength=2048 example.com
# rollctl -zsargs =ksklen=2048 =zsklen=2048 example.com test.com
-Version
Displays the version information for rollctl and the DNSSEC-Tools package.
-quiet
Prevents output from being given. Both error and non-error output is stopped.
-help
Displays a usage message.

EXIT CODES

rollctl may give the following exit codes:

0 - Successful execution
1 - Error sending the command to rollerd.
2 - Missing argument.
3 - Too many commands specified.
200 - Rollerd is not running.
201 - Configuration file checks failed.

FUTURE

The following modifications may be made in the future:

command execution order
The commands will be executed in the order given on the command line rather than in alphabetical order.
