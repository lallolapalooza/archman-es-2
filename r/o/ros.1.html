Roswell - Utilidad de configuración del entorno Common Lisp

Sinopsis

•
ros [opciones] [comando [argumentos...]]
•
ros [opciones] [--]script [argumentos...]
•
ros [opciones] < script.ros

Descripción

Roswell es una herramienta de línea de comandos para instalar y gestionar implementaciones de Common Lisp, así como una infraestructura de scripting para plantillas, escritura, ejecución, compilación, distribución, descarga e instalación de ROSWELL-SCRIPTS escritos en Common Lisp.

Actualmente, roswell soporta sbcl, ccl, clisp y ecl como implementaciones de lisp soportadas. Para más detalles, consulte ros-install(1).

Los scripts instalados por roswell estarán disponibles en todo el sistema si el directorio apropiado está incluido en PATH.

Subcomandos

En orden de utilidad/frecuencia.

install
Instala una implementación dada (p. ej., sbcl, ccl) o un sistema (p. ej., alexandria) para el entorno de roswell. Consulte ros-install(1).
init [nombre[.ros]]
Crea un nuevo script de ros. .ros es opcional y se añade automáticamente. Consulte ros-init.
dump [ejecutable|salida] [script]
Genera una imagen del script para un inicio más rápido o para crear un ejecutable. Consulte ros-dump.
build
Crea un ejecutable a partir del script. Consulte ros-build.
run
Inicia el REPL. Consulte ros-run.
use
Cambia la implementación predeterminada utilizada por roswell. Consulte ros-use.
list
Lista la información diversa. Consulte ros-list.
config
Obtiene y establece las opciones. Consulte ros-config.
setup
Ejecuta la configuración inicial. Consulte ros-setup.
emacs
Inicia emacs con slime. Consulte ros-emacs.
wait
Espera indefinidamente, se utiliza para demonizar el script. Consulte ros-wait.
delete
Elimina una implementación instalada. Consulte ros-delete.
version
Muestra la información de la versión de roswell. Consulte ros-version.
help
Muestra la ayuda del subcomando.

Opciones

Las opciones se procesan en orden de izquierda a derecha.

-w CODIGO –wrap CODIGO
Ejecuta el script con un envoltorio de shell CODIGO, p. ej., rlwrap
-m IMAGEN –image IMAGEN
Continúa desde la imagen Lisp IMAGEN
-L NOMBRE –lisp NOMBRE
Ejecuta el script con una implementación de lisp NOMBRE[/VERSIÓN] si está presente, p. ej., sbcl-bin, sbcl/1.2.16. Falla de lo contrario.
-l ARCHIVO –load ARCHIVO
Carga un archivo lisp ARCHIVO durante la compilación
-S X –source-registry X
Anula el registro de fuentes de los sistemas asdf.
-s SISTEMA –system SISTEMA
Carga el SISTEMA asdf durante la compilación.
–load-system SISTEMA
Igual que lo anterior (compatibilidad con buildapp)
-p PAQUETE –package PAQUETE
Cambia el paquete actual a PAQUETE
-sp SP –system-package SP
Combinación de -s SP y -p SP
-e FORMULARIO –eval FORMULARIO
Evalúa FORMULARIO durante la compilación
–require MODULO
requiere MODULO durante la compilación
-q –quit
sale de lisp aquí
-r FUNC –restart FUNC
la imagen de compilación reinicia desde la llamada a FUNC
-E FUNC –entry FUNC
la imagen de compilación reinicia desde la llamada a (FUNC argv).
-i FORMULARIO –init FORMULARIO
evalúa FORMULARIO después del reinicio.
-ip FORMULARIO –print FORMULARIO
evalúa y imprime FORMULARIO después del reinicio
-iw FORMULARIO –write FORMULARIO
evalúa y escribe FORMULARIO después del reinicio
-F FORMULARIO –final FORMULARIO
evalúa FORMULARIO antes de generar la IMAGEN
-R –rc
intenta leer /etc/rosrc, ~/.roswell/init.lisp
+R –no-rc
omite /etc/rosrc, ~/.roswell/init.lisp
-Q –quicklisp
carga quicklisp (predeterminado)
+Q –no-quicklisp
no carga quicklisp
-v –verbose
sea bastante verboso durante la compilación
–quiet
suprime la salida durante la compilación (predeterminado)
–test
para propósito de prueba
dynamic-space-size=[tamaño en MB]
específico de SBCL. El argumento se pasa a SBCL mediante --dynamic-space-size

Variables de Entorno

ROSWELL_HOME
Especifica el directorio de inicio de roswell, por defecto es $HOME en la plataforma Unix.

ROS

ROS - Arch Linux Package Manager

SYNOPSIS

ros [options] [package]

DESCRIPTION

ROS is a command-line tool for managing Arch Linux packages. It allows you to install, update, remove, and query packages.

OPTIONS

-S, --sync
Sync packages. This is the default operation when no other operation is specified. When a package name is given, ROS synchronizes the specified package and its dependencies. If no package name is given, ROS synchronizes all installed packages that are out-of-date.
-U, --upgrade
Upgrade packages. This operation is similar to --sync but only upgrades packages that are installed and already up-to-date.
-R, --remove
Remove packages. This operation removes the specified package and its dependencies if they are not required by other packages.
-Q, --query
Query installed packages. This operation can be used to list installed packages, search for packages, or display information about a specific package.
-h, --help
Display help information.

EXAMPLES

Install a package:

    ros -S package_name

Upgrade all installed packages:

    ros -Su

Remove a package:

    ros -R package_name

Query installed packages:

    ros -Q

The ROS tool itself is part of the Arch Linux package management system.
