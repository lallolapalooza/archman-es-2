root(1) Manual de Comandos Generales root(1)

SINÓPSIS

uso: root [-b B] [-x X] [-e E] [-n N] [-t T] [-q Q] [-l L] [-a A]
[-config CONFIG] [-h HELP] [--version VERSION]
[--notebook NOTEBOOK] [--web WEB] [--web=<type> WEB=<TYPE>]
[--web=off WEB=OFF]
[dir] [data1.root...dataN.root] [file1.C...fileN.C]
[file1_C.so...fileN_C.so] [anyfile1..anyfileN]

DESCRIPCIÓN

root es un intérprete interactivo de código C++ utilizando Cling y el framework ROOT. Para más información sobre ROOT, por favor consulte https://root.cern/ Una guía de usuario y una referencia de API extensas están disponibles en ese sitio web.

OPCIONES

-b
Ejecutar en modo batch sin gráficos
-x
Salir ante excepciones
-e
Ejecutar el comando pasado entre comillas simples
-n
No ejecutar macros de inicio y cierre de sesión según lo especificado en .rootrc
-t
Habilitar seguridad de hilos y multihilo implícito (IMT)
-q
Salir después de procesar los archivos de macros de la línea de comandos
-l
No mostrar el banner de ROOT
-a
Mostrar la pantalla de bienvenida de ROOT (solo Windows)
-config
imprimir opciones de ./configure
-h
Mostrar resumen de opciones
--version
Mostrar la versión de ROOT
--notebook
Ejecutar el cuaderno ROOT
--web
Usar visualización basada en web para gráficos, navegador, geometría
--web=<type>
Usar la visualización basada en web especificada, como chrome, firefox, qt6
Para más opciones consulte la documentación de TROOT::SetWebDisplay()
--web=off
Deshabilitar cualquier tipo de visualización basada en web
[dir]
si dir es un directorio válido, cambiar a él antes de ejecutar
[data1.root...dataN.root]
Abrir los archivos ROOT dados; se admiten protocolos remotos (como http://)
[file1.C...fileN.C]
Ejecutar el archivo de macro ROOT file1.C ... fileN.C
Se pueden pasar banderas de compilación así como argumentos de macro, ver el formato en https://root.cern/manual/root_macros_and_shared_libraries/
[file1_C.so...fileN_C.so]
Cargar y ejecutar file1_C.so ... fileN_C.so (o .dll si está en Windows)
Deben ser macros ROOT ya compiladas (bibliotecas compartidas) o:
bibliotecas compartidas de usuario regulares, por ejemplo, userlib.so con una función userlib(args)
[anyfile1..anyfileN]
Todos los demás argumentos que apunten a archivos existentes se comprobarán para ver si son Archivos ROOT (comprobando el tipo MIME dentro del archivo) y si no lo son se manejarán como un archivo de macro ROOT
