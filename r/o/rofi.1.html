rofi(1) Manual de Comandos Generales rofi(1)

NOMBRE

rofi - selector de ventanas, lanzador de aplicaciones, diálogo ssh, reemplazo de dmenu y más

SINOPSIS

rofi [ -show modo ]|[ -dmenu ]|[ -e mensaje ] CONFIGURACIÓN

DESCRIPCIÓN

rofi es un selector de ventanas emergente para X11, diálogo de ejecución, reemplazo de dmenu y más. Se enfoca en ser rápido de usar y tener mínima distracción. Soporta navegación por teclado y ratón, escritura para filtrar, búsqueda tokenizada y más.

USO

La funcionalidad principal de rofi es asistir en tu flujo de trabajo, permitiéndote cambiar rápidamente entre ventanas, iniciar aplicaciones o iniciar sesión en una máquina remota vía ssh. Hay diferentes modos para diferentes tipos de acciones. rofi es una aplicación independiente y no debe integrarse en scripts. Para la integración en scripts, tiene un modo especial que funciona como un reemplazo (directo) para dmenu(1). Ver emulando dmenu abajo.

Ejecutando rofi

Para lanzar rofi directamente en un modo específico, especifica un modo con rofi -show <modo>. Para mostrar el diálogo drun:

    rofi -show drun

Una configuración útil en gestores de ventanas minimalistas es combinar drun, run con el modo window:

  rofi -show combi -modes combi -combi-modes "window,drun,run"

En esta configuración, primero lista todas las aplicaciones abiertas, luego todas las aplicaciones instaladas. Así que si escribes firefox y presionas enter, cambiará a la instancia de firefox en ejecución o la lanzará si no está en ejecución.

Emulando dmenu

rofi puede emular dmenu(1) (un menú dinámico para X11) cuando se lanza con la bandera -dmenu.

Para más información, consulta rofi-dmenu(5).

Mostrando mensaje de error

El diálogo de error de rofi también puede ser llamado desde la línea de comandos.

    rofi -e "mi mensaje"

El soporte para marcado puede habilitarse, ver las opciones de CONFIGURACIÓN.

CONFIGURACIÓN

Actualmente existen tres métodos para establecer opciones de configuración (evaluados en orden a continuación):

•
Archivo de configuración del sistema (por ejemplo, /etc/rofi.rasi). Primero busca en XDG_CONFIG_DIRS, y luego en SYSCONFDIR (que se pasa en tiempo de compilación). Carga el primer archivo de configuración que encuentra, no fusiona múltiples archivos de configuración del sistema.
•
Archivo de tema Rasi: El nuevo formato de tema puede usarse para establecer valores de configuración.
•
Opciones de línea de comandos: Argumentos pasados a rofi.

Para obtener un archivo de configuración de plantilla, ejecuta: rofi -dump-config > config.rasi

Esto contendrá (comentadas) todas las opciones de configuración actuales, las opciones modificadas se descomentarán.

Para obtener un archivo de configuración de plantilla que establezca el tema de iconos, ejecuta: rofi -icon-theme hicolor -dump-config.

Se recomienda encarecidamente usar esto como punto de partida para tu configuración.

Una sección de configuración vacía en el archivo de configuración se ve así:

configuration {
 // establecer opciones de configuración aquí
}

La mayoría de las opciones de configuración mencionadas a continuación (aparte de opciones como -show, -dump-config que se aplican a una única ejecución) se pueden establecer aquí.

Por ejemplo, para establecer el valor de dpi a 72:

configuration {
 dpi: 72;
}

El sistema de configuración soporta los siguientes tipos:

•
cadena (string)
•
entero (con y sin signo)
•
caracter (char)
•
booleano
•
listas

Para la sintaxis de estas opciones, consulta la página del manual rofi-theme(5).

Para uso en la línea de comandos, las opciones booleanas tienen una sintaxis de línea de comandos no predeterminada. Ejemplo para habilitar la opción X:

    -X

Para deshabilitar la opción X:

    -no-X

A continuación, se muestra una lista de las opciones más importantes:

General

-help
La opción de ayuda muestra la lista completa de opciones de línea de comandos y los valores establecidos actualmente. Estos incluyen opciones dinámicas (generadas en tiempo de ejecución).
-info
La opción de información muestra información útil para incluir al reportar un problema. Esto incluye opciones de compilación, monitores detectados y más. Por favor, revisa la salida para cualquier información personal antes de publicarla en línea.
-version
Muestra la versión de rofi y sale.
-dump-config
Descarga la configuración activa actual, en formato rasi, a la salida estándar y sale. La información sobre el formato rasi se puede encontrar en la página del manual rofi-theme(5).
-dump-theme
Descarga el tema activo actual, en formato rasi, a la salida estándar y sale.
-rasi-validate nombre_archivo
Intenta analizar el archivo y devuelve 0 si tiene éxito, no cero si falla.
-list-keybindings
Lista todos los atajos de teclado conocidos sin intentar analizarlos. Esto se puede usar para buscar atajos duplicados.
-threads num
Especifica el número de hilos que rofi debe usar:
•
0: Autodetectar el número de hilos de hardware soportados.
•
1: Deshabilitar hilos
•
2..n: Especificar el número máximo de hilos a usar en el pool de hilos.

Por defecto: Autodetectar

-display pantalla
El servidor X a contactar. Por defecto es $DISPLAY.
-dmenu
Ejecuta rofi en modo dmenu. Esto permite scripts interactivos. En modo dmenu, rofi lee desde STDIN y escribe a STDOUT. Un ejemplo simple, mostrando tres opciones predefinidas:
    echo -e "Opción #1\nOpción #2\nOpción #3" | rofi -dmenu

O para obtener las opciones de un script:

    ~/mi_script.sh | rofi -dmenu

Consulta la página del manual rofi-dmenu(5) para más información.

-show modo
Abre rofi en un modo específico. Los modos disponibles son window, run, drun, ssh, combi. El argumento especial keys puede usarse para abrir una lista buscable de atajos de teclado soportados (ver la página del manual rofi-keys(5))

Para mostrar el diálogo de ejecución:

    rofi -show run

Si -show es la última opción pasada a rofi, se muestra el primer modo habilitado.

-modes modo1,modo2
Especifica una lista ordenada y separada por comas de modos a habilitar. Los modos habilitados se pueden cambiar en tiempo de ejecución. La tecla predeterminada es Ctrl+Tab. Si no se especifican modos ar
e especificado, todos los modos configurados se habilitarán. Para mostrar solo el lanzador run y ssh: 
    rofi -modes "run,ssh" -show run

Los modos personalizados se pueden agregar usando el modo interno script. Cada uno de estos modos tiene dos parámetros:

<nombre>:<script>

Ejemplo: Tener un modo llamado `Workspaces' usando el script i3_switch_workspaces.sh:

    rofi -modes "window,run,ssh,Workspaces:i3_switch_workspaces.sh" -show Workspaces

Notas: El administrador de ventanas i3 no tolera las comas en el comando al especificar un comando de ejecución. Para ese caso, # se puede usar como separador.

CONSEJO: Se permite que el nombre contenga espacios:

    rofi -modes "Mi Explorador de Archivos:fb.sh" -show "Mi Explorador de Archivos"
-case-sensitive
Iniciar en modo sensible a mayúsculas y minúsculas. Esta opción se puede cambiar en tiempo de ejecución usando la asignación de teclas -kb-toggle-case-sensitivity.
-case-smart
Iniciar en modo inteligente de mayúsculas y minúsculas, comportándose como el smartcase de vim, que determina la sensibilidad a mayúsculas y minúsculas según la entrada. Cuando está habilitado, esto suprimirá la configuración -case-sensitive.
-cycle
Recorrer la lista de resultados. Por defecto es `true'.
-filter filtro
Filtrar la lista estableciendo texto en la barra de entrada a filtro
-config nombre_archivo
Cargar un archivo de configuración alternativo.
-cache-dir nombre_directorio
Directorio que se utiliza para colocar archivos temporales, como el historial.
-scroll-method método
Seleccionar el método de desplazamiento. 0: Por página, 1: continuo.
-normalize-match
Normalizar la cadena antes de comparar, de modo que o coincida con ö, y é coincida con e. Esta no es una implementación perfecta, pero funciona. Por ahora, deshabilita el resaltado de la parte coincidente.
-no-lazy-grab
Deshabilita la captura perezosa (lazy grab), esto fuerza la captura del teclado antes de que se muestre la GUI.
-no-plugins
Deshabilitar la carga de plugins.
-plugin-path directorio
Especificar el directorio donde rofi debe buscar plugins.
-show-icons
Mostrar iconos de aplicaciones en los modos drun y window.
-icon-theme
Especificar el tema de iconos a utilizar. Si no se especifica, se utiliza el tema predeterminado del DE, los temas Adwaita y gnome actúan como temas de respaldo.
-markup
Usar marcado Pango para formatear la salida siempre que sea posible.
-normal-window
Hacer que rofi reaccione como una ventana de aplicación normal. Útil para scripts como Clerk que son básicamente una aplicación.
-transient-window
Hacer que rofi reaccione como un diálogo modal que es transitorio para la ventana actualmente enfocada. Útil cuando se usa un atajo de teclado para ejecutar y mostrar en la ventana con la que se está trabajando.
-[no-]steal-focus
Hacer que rofi robe el foco al iniciarse y restaure el foco a la ventana que lo tenía al iniciarse al cerrarse.
-refilter-timeout-limit
El límite de tiempo (en ms) que el filtro puede tardar antes de cambiar del modo de filtro instantáneo al retrasado.

Por defecto: 300

Se puede especificar un icono de respaldo para cada modo:

configuration {
    <modo>{
      fallback-icon: "<nombre_icono>";
    }
}

Ejemplo

configuration {
    run,drun {
      fallback-icon: "application-x-addon";
    }
}

Comparación

-matching método
Especificar el algoritmo de comparación utilizado. Actualmente, se admiten los siguientes métodos:
•
normal: comparar la cadena entera
•
regex: comparar una entrada regex
•
glob: comparar un patrón glob
•
fuzzy: hacer una comparación difusa (fuzzy)
•
prefix: comparar prefijo

Por defecto: normal

Se pueden especificar múltiples métodos de comparación en una lista separada por comas. La asignación de teclas de subir/bajar permite recorrerlos en tiempo de ejecución.

Nota: la comparación glob puede ser lenta para listas grandes

-tokenize
Tokenizar la entrada.
-drun-categories categoría1,categoría2
Mostrar solo archivos de escritorio que estén presentes en las categorías listadas.
-drun-exclude-categories categoría1,categoría2
Excluir archivos de escritorio que estén presentes en las categorías listadas.
-drun-match-fields campo1,campo2,...
Al usar drun, comparar solo con los campos especificados de la entrada de escritorio. Los diferentes campos son:
•
name: el nombre de la aplicación
•
generic: el nombre genérico de la aplicación
•
exec: el ejecutable de la aplicación
•
categories: las categorías de la aplicación
•
comment: el comentario de la aplicación
•
all: todos los anteriores

Por defecto: name,generic,exec,categories,keywords

-drun-display-format
La cadena de formato para el diálogo drun:
•
name: el nombre de la aplicación
•
generic: el nombre genérico de la aplicación
•
exec: el ejecutable de la aplicación
•
categories: las categorías de la aplicación
•
comment: el comentario de la aplicación
•
url: La URL en caso de un archivo de escritorio de tipo enlace

Se puede usar marcado Pango para formatear la salida.

Por defecto: {name} [<span weight='light' size='small'><i>({generic})</i></span>]

Nota: Solo se pueden usar campos habilitados en -drun-match-fields en la cadena de formato.

-[no-]drun-show-actions
Mostrar acciones presentes en los archivos de escritorio.

Por defecto: false

-window-match-fields campo1,campo2,...
Al usar el modo de ventana, comparar solo con los campos especificados. Los diferentes campos son:
•
title: el título de la ventana
•
class: la clase de la ventana
•
role: el rol de la ventana
•
name: el nombre de la ventana
•
desktop: el escritorio actual de la ventana
•
all: todos los anteriores

Para Wayland, la lista de campos aceptados es diferente:

•
title: el título de la ventana
•
app-id: ID de aplicación de Wayland o clase de ventana de XWayland
•
class: igual que app-id
•
all: todos los anteriores

Por defecto: all

-matching-negate-char cadena
Establecer el carácter utilizado para negar la consulta (es decir, si no coincide con la siguiente palabra clave). Establecer a `' para deshabilitar. Toma el primer carácter ASCII de la cadena.

Por defecto: `-'

Diseño y Tematización

IMPORTANTE: En las versiones más recientes de rofi, todas las opciones de tematización se han trasladado al nuevo formato de tema. Ya no son opciones normales de rofi que se puedan pasar directamente en la línea de comandos (son demasiadas). Se pueden pasar fragmentos pequeños en la línea de comandos: rofi -theme-str 'window {width: 50%;}' para anular una sola configuración. Se fusionan en el tema actual. También se pueden agregar al final del archivo de configuración de rofi para anular partes del tema.

La mayoría de las siguientes opciones están obsoletas y no deben usarse. Por favor, use el nuevo formato de tema para personalizar rofi. Puede encontrar más información sobre el nuevo formato en la página del manual rofi-theme(5).

configuration {
   filebrowser {

PATRÓN

Para lanzar comandos (por ejemplo, al usar el lanzador ssh), el usuario puede introducir la línea de comandos utilizada. Las siguientes claves se pueden usar y se reemplazarán en tiempo de ejecución:

•
{host}: el host al que conectarse
•
{terminal}: la terminal configurada (ver -terminal)
•
{ssh-client}: el cliente ssh configurado (ver -ssh-client)
•
{cmd}: el comando a ejecutar
•
{window}: el ID de la ventana seleccionada (en window-command)

Procesa la cadena de la siguiente manera: {clave} se reemplaza por su valor; si {clave} no está establecida, se elimina. Si la {clave} está entre corchetes [], todo el texto entre corchetes se elimina si {clave} no está establecida. De lo contrario, la clave se reemplaza y los corchetes [] se eliminan.

Por ejemplo: {ssh-client} [-p {port}] {host}

Modos disponibles

window

Muestra una lista de todas las ventanas y permite cambiar entre ellas. Pulsar la asignación delete-entry (shift-delete) cerrará la ventana. Pulsar la asignación accept-custom (control-enter o shift-enter) ejecutará un comando en la ventana. (Ver opción window-command);

Si no hay coincidencia, intentará lanzar la entrada.

windowcd

Muestra una lista de las ventanas en el escritorio actual y permite cambiar entre ellas. Pulsar la asignación delete-entry (shift-delete) matará la ventana. Pulsar la asignación accept-custom (control-enter o shift-enter) ejecutará un comando en la ventana. (Ver opción window-command);

Si no hay coincidencia, intentará lanzar la entrada.

run

Muestra una lista de ejecutables en $PATH y puede lanzarlos (opcionalmente en una terminal).

•
Pulsar la asignación delete-entry (shift-delete) eliminará esta entrada del historial de ejecución.
•
Pulsar la asignación accept-custom (control-enter) ejecutará el comando tal como se introdujo en el cuadro de entrada.
•
Pulsar la asignación accept-alt (shift-enter) ejecutará el comando en una terminal.

Al pulsar la asignación mode-complete (Control-l), puede usar el modo Explorador de Archivos para lanzar la aplicación con un archivo como primer argumento.

drun

Similar a los lanzamientos de run, pero la lista se crea a partir de los archivos de escritorio instalados. Los lanza automáticamente en una terminal si se especifica en el Archivo de Escritorio.

•
Pulsar la asignación delete-entry (shift-delete) eliminará esta entrada del historial de ejecución.
•
Pulsar la asignación accept-custom (control-enter) ejecutará el comando tal como se introdujo en el cuadro de entrada.
•
Pulsar la asignación accept-alt (shift-enter) ejecutará el comando en una terminal.

Al pulsar la asignación mode-complete (Control-l), puede usar el modo Explorador de Archivos para lanzar la aplicación pasando un archivo como argumento si se especifica en el archivo de escritorio.

El modo DRUN intenta seguir la Especificación de Entrada de Escritorio XDG y debería ser compatible con aplicaciones que utilicen este estándar. Algunas aplicaciones crean archivos de escritorio inválidos; rofi los descartará. Consulte la sección de depuración para más información sobre el modo DRUN, que imprimirá por qué se descartan los archivos de escritorio.

Hay algunas opciones avanzadas para ajustar el comportamiento:

configuration {
   drun {
      /** Escanea el escritorio del usuario actual en busca de archivos de escritorio. */
      scan-desktop: true;
      /** Analiza archivos de escritorio de usuario. */
      parse-user:   true;
      /** Analiza archivos de escritorio del sistema. */
      parse-system: false;
      /** Deshabilita DBusActivatable */
      DBusActivatable: false;
   }
}

ssh

Muestra una lista de destinos SSH basada en su archivo de configuración ssh y permite hacer ssh rápidamente a ellos.

keys

Muestra una lista de asignaciones de teclas que se puede buscar.

script

NAME

rofi

- A window switcher, application launcher and dmenu replacement

SYNOPSIS

rofi [-show mode] [options...]

rofi [-dump | -remote] [options...]

rofi [-e] [string] [options...]

DESCRIPTION

rofi is a window switcher, application launcher and dmenu replacement. It is designed to be highly customizable, flexible with support for custom themes and modes.

It can be used in several ways:

•
As a window switcher (default mode if no mode specified).
•
As an application launcher using the built-in run and drun modes.
•
As a dmenu replacement, accepting input from stdin and printing the selected line to stdout.
•
As a simple message displayer using the -e flag.

See the man pages for more details on the different modes and options.

USAGE

To launch rofi with a specific mode, use the -show option. For example:

    rofi -show run

To use rofi as a dmenu replacement, pipe input to it and capture the output:

    ls | rofi -dmenu -p "Select file:"

To display a message:

    rofi -e "Hello World"

CONFIGURATION

rofi can be configured using a configuration file, typically located at ~/.config/rofi/config.rasi. The configuration file uses the rasi syntax.

Key configuration options include:

modes
Specifies which modes to enable and their order.
drun-executable-brands
A list of executable names to search for icons when using drun mode.
hover-select
Enable selection on hover.
theme
Specifies the theme file to use.

For a complete list of configuration options, refer to the rofi-theme(5) man page.

PATTERN

rofi supports pattern matching for filtering results. By default, it uses a simple substring search. You can enable advanced matching modes using options like -case-sensitive, -matching-regex, and -tokenize-tokens.

A !bang can be used to filter results by mode. For example, if you have multiple modes enabled, typing !run will filter the results to only show those from the run mode.

THEMING

rofi is highly themeable. Themes can be specified using the -theme option or set in the configuration file. Theme files use the rasi syntax and allow customization of colors, fonts, layout, and more.

You can find example themes in the /usr/share/rofi/themes/ directory or online.

KEY BINDINGS

rofi has several built-in key bindings for navigation and selection. These can be customized using the -show keys option or configured in the configuration file.

Common key bindings include:

Ctrl+Shift+E / Alt+F4
Close rofi.
Return
Select the current entry.
Shift+Tab
Switch to the previous mode.
Tab
Switch to the next mode.

Refer to rofi-keys(5) for a complete list of key bindings and their customization options.

Available Modes

rofi supports several built-in modes, and custom modes can be created using scripts.

run
Launches applications from your PATH.
drun
Launches applications based on desktop entries (.desktop files).
window
Lists and switches between open windows.
windowcd
Same as window mode, but changes the current directory to the selected window's application directory.
ssh
Lists and connects to available SSH hosts.
keys
Displays key bindings.
calc
A simple calculator.
combi
Combines multiple modes in one list. Specify which modes are included with the -combi-modes option.

When using the combi mode, a !bang can be used to filter the results by modes. All modes that match the bang as a prefix are included. For example, say you have specified -combi-modes run,window,windowcd. If your query begins with the bang !w, only results from the window and windowcd modes are shown, even if the rest of the input text would match results from run.

If no match, the input is handled by the first combined modes.

FAQ

The text in the window switcher is not nicely aligned

Try using a mono-space font or tabs + the tab-stops setting..

The window is completely black

Check quotes used on the command-line: you might have used “ (“smart quotes”) instead of " (“machine quotes”).

What does the icon in the top right show?

The indicator shows:

•
`` Case insensitive and no sorting.
•
- Case sensitivity enabled, no sorting.
•
+ Case insensitive and Sorting enabled
•
± Sorting and Case sensitivity enabled”

Why do I see different icons for run,drun and window mode

Each of these modes uses different methods of resolving the icon:

•
Window: It first uses the icon that the application exposes via the X11 Server, if none is set it does a lookup of the window Class name in the icon theme.
•
drun: It uses the icon set in the desktop file.
•
run: It does a lookup using the executable name.

EXAMPLES

Some basic usage examples of rofi:

Show the run dialog:

    rofi -modes run -show run

Show the run dialog, and allow switching to Desktop File run dialog (drun):

    rofi -modes run,drun -show run

Combine the run and Desktop File run dialog (drun):

    rofi -modes combi -show combi -combi-modes run,drun

Combine the run and Desktop File run dialog (drun), and allow switching to window switcher:

    rofi -modes combi,window -show combi -combi-modes run,drun

Pop up a text message claiming that this is the end:

    rofi -e "This is the end"

Pop up a text message in red, bold font claiming that this is still the end:

    rofi -e "<span color='red'><b>This is still the end</b></span>" -markup

Show all key bindings:

    rofi -show keys

i3

In i3 you want to bind rofi to be launched on key release. Otherwise, it cannot grab the keyboard. See also the i3 manual:

Some tools (such as import or xdotool) might be unable to run upon a KeyPress event, because the keyboard/pointer is still grabbed. For these situations, the --release flag can be used, as it will execute the command after the keys have been released.

Hyprland

Hyprland’s animations make the launching of Rofi feel slower then needed. To avoid this, add the following rule to your hyprland.conf file:

layerrule = noanim,^(rofi)$

This disables the animations on the Rofi window.
