roundup(3) Manual de funciones de biblioteca roundup(3)

NOMBRE

roundup - redondear hacia arriba en pasos

BIBLIOTECA

Biblioteca C estándar (libc)

SINOPSIS

#include <sys/param.h>
roundup(x, step);

DESCRIPCIÓN

Esta macro redondea x al múltiplo más cercano de step que no sea menor que x.

Se usa típicamente para redondear un puntero para alinearlo o aumentar un búfer para su asignación.

Esta API no está diseñada para ser genérica y no funciona en algunos casos que no son importantes para los casos de uso típicos descritos anteriormente. Ver PRECAUCIONES.

VALOR DE RETORNO

Esta macro devuelve el valor redondeado.

ESTANDARES

Ninguno.

PRECAUCIONES

Los argumentos pueden ser evaluados más de una vez.

x debe ser no negativo, y step debe ser positivo.

Si x + step se desbordara o diera la vuelta, el comportamiento es indefinido.

VER TAMBIÉN

ceil(3), floor(3), lrint(3), rint(3), lround(3), round(3)
