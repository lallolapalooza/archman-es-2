NOMBRE

restic-self-update - Actualiza el binario de restic

SINOPSIS

restic self-update [flags]

DESCRIPCIÓN

El comando "self-update" descarga la última versión estable de restic desde GitHub y reemplaza el binario en ejecución. Después de la descarga, la autenticidad del binario se verifica utilizando la firma GPG en los archivos de lanzamiento.

ESTADO DE SALIDA

El estado de salida es 0 si el comando se ejecutó correctamente. El estado de salida es 1 si hubo algún error. El estado de salida es 10 si el repositorio no existe. El estado de salida es 11 si el repositorio ya está bloqueado. El estado de salida es 12 si la contraseña es incorrecta.

OPCIONES

-h, --help[=false] Ayuda para self-update

--output="" Guarda el archivo descargado como nombre_archivo (por defecto: el binario en ejecución mismo)

OPCIONES HEREDADAS DE COMANDOS PADRE

--cacert=[] archivo para cargar certificados raíz desde (por defecto: usar certificados del sistema o $RESTIC_CACERT)

--cache-dir="" establece el directorio de caché. (por defecto: usar el directorio de caché predeterminado del sistema)

--cleanup-cache[=false] elimina automáticamente los directorios de caché antiguos

--compression=auto modo de compresión (solo disponible para la versión 2 del formato de repositorio), uno de (auto|off|max) (por defecto: $RESTIC_COMPRESSION)

--http-user-agent="" establece un agente de usuario http para las solicitudes http salientes

--insecure-no-password[=false] usa una contraseña vacía para el repositorio, debe pasarse a cada comando restic (inseguro)

--insecure-tls[=false] omite la verificación del certificado TLS al conectarse al repositorio (inseguro)

--json[=false] establece el modo de salida a JSON para comandos que lo admiten

--key-hint="" ID de clave de la clave a intentar descifrar primero (por defecto: $RESTIC_KEY_HINT)

--limit-download=0 limita las descargas a una tasa máxima en KiB/s. (por defecto: ilimitado)

--limit-upload=0 limita las cargas a una tasa máxima en KiB/s. (por defecto: ilimitado)

--no-cache[=false] no usar caché local

--no-extra-verify[=false] omite la verificación adicional de datos antes de la carga (ver documentación)

--no-lock[=false] no bloquear el repositorio, esto permite algunas operaciones en repositorios de solo lectura

-o, --option=[] establece una opción extendida (clave=valor, se puede especificar varias veces)

--pack-size=0 establece el tamaño de paquete objetivo en MiB, los archivos de paquete creados pueden ser más grandes (por defecto: $RESTIC_PACK_SIZE)

--password-command="" comando shell para obtener la contraseña del repositorio desde (por defecto: $RESTIC_PASSWORD_COMMAND)

-p, --password-file="" archivo para leer la contraseña del repositorio desde (por defecto: $RESTIC_PASSWORD_FILE)

-q, --quiet[=false] no mostrar informe de progreso detallado

-r, --repo="" repositorio para hacer copias de seguridad o restaurar (por defecto: $RESTIC_REPOSITORY)

--repository-file="" archivo para leer la ubicación del repositorio desde (por defecto: $RESTIC_REPOSITORY_FILE)

--retry-lock=0s reintentar bloquear el repositorio si ya está bloqueado, toma un valor como 5m o 2h (por defecto: sin reintentos)

--stuck-request-timeout=5m0s duración después de la cual se reintentarán las solicitudes atascadas

--tls-client-cert="" ruta a un archivo que contiene el certificado de cliente TLS codificado en PEM y clave privada (por defecto: $RESTIC_TLS_CLIENT_CERT)

-v, --verbose[=0] ser detallado (especificar varias veces o un nivel usando --verbose=n, nivel/veces máximo es 2)
