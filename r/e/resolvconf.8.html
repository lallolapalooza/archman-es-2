RESOLVCONF(8) Manual del Administrador del Sistema RESOLVCONF(8)

NOMBRE

resolvconf — un framework para gestionar múltiples configuraciones de DNS

SINOPSIS

resolvconf -I

resolvconf [-m métrica] [-p] [-x] -a clave <archivo

resolvconf -C patrón

resolvconf -c patrón

resolvconf [-f] -d clave

resolvconf [-x] -iLlp patrón

resolvconf -u

resolvconf --version

DESCRIPCIÓN

resolvconf gestiona archivos resolv.conf(5) desde múltiples fuentes, como clientes DHCP y VPN. Tradicionalmente, el host ejecuta un solo cliente y este actualiza /etc/resolv.conf. Los sistemas más modernos frecuentemente tienen interfaces cableadas e inalámbricas y no hay garantía de que ambas estén en la misma red. Con la llegada de daemons de red VPN y otros tipos, muchas cosas compiten por el contenido de /etc/resolv.conf.

resolvconf resuelve esto permitiendo que los daemons envíen su archivo resolv.conf(5) a resolvconf a través de stdin(4) con el argumento -a clave en lugar del sistema de archivos. resolvconf entonces actualiza /etc/resolv.conf como mejor le parezca. Si /etc/resolv.conf ya existe y la línea superior no coincide con la firma esperada, entonces resolvconf se negará a actualizarlo a menos que se proporcione el comando de actualización -u. Cuando se instala un resolvedor local distinto de libc, como dnsmasq(8) o named(8), entonces resolvconf proporcionará archivos que el resolvedor debería estar configurado para incluir.

En su núcleo, resolvconf es un almacén de clave/valor para archivos de resolv.conf. Cada entrada debe tener una clave única y debe expresarse como interfaz.protocolo para que sea fácil saber de dónde provino el archivo resolv.conf. Esto también permite usar coincidencias de patrones como interfaz.* para coincidir con todos los protocolos que se ejecutan en la interfaz. Por ejemplo, un sistema moderno probablemente ejecutará DHCP, RA y DHCPv6, que podrían provenir de programas separados o de un programa que ejecute muchos protocolos. Sin embargo, esto no es un requisito fijo, resolvconf funcionará con cualquier nombre de clave y debe tratarse como un valor opaco fuera de resolvconf.

resolvconf puede marcar un resolv.conf como privado y opcionalmente no buscable. Esto significa que los servidores de nombres listados en ese resolv.conf solo se utilizan para consultas contra el dominio/búsqueda listados en el mismo archivo y, si no es buscable, los dominios/búsquedas listados se excluyen de la lista de búsqueda global definida en /etc/resolv.conf. Esto solo funciona cuando se instala un resolvedor local distinto de libc. Consulte resolvconf.conf(5) para saber cómo configurar resolvconf para usar un servidor de nombres local y cómo eliminar la marca de privado.

resolvconf puede marcar un resolv.conf como exclusivo. Solo se utiliza la última clave exclusiva para el procesamiento, de lo contrario, se utilizan todas.

Cuando una fuente de configuración desaparece, como una interfaz que se desconecta o una VPN que se detiene, debe llamar a resolvconf con argumentos -d clave para limpiar el resolv.conf que agregó previamente. Para los sistemas que admiten el concepto de persistencia de configuración cuando la fuente se suspende, como la desconexión del portador, deben llamar a resolvconf con argumentos -C clave para desaprobar la entrada -c clave para activar la entrada cuando vuelva. Esto solo afecta el orden en que se procesan las entradas de resolv.conf.

Aquí hay algunas opciones para los comandos anteriores:

-f
Ignora las entradas de resolv.conf inexistentes. Solo realmente útil para eliminar.
-m métrica
Establece la métrica de la entrada de resolv.conf al agregarla, por defecto 0. Las métricas más bajas tienen prioridad. Esto afecta el orden predeterminado de las entradas cuando se enumeran.
-p [patrón]
Marca el resolv.conf como privado si se da el comando -a, de lo contrario se enumeran las entradas de resolv.conf cuya clave coincide con patrón. Si se proporciona un -p adicional, entonces el resolv.conf también se marca como no buscable.
-x
Marca el resolv.conf como exclusivo al agregar, de lo contrario, solo se utiliza la última clave exclusiva.

resolvconf tiene más comandos para uso general:

-i [patrón]
Enumera las claves almacenadas, opcionalmente coincidiendo con patrón, para las cuales tenemos archivos de resolv.conf. Si se proporciona la opción -L primero, entonces las claves se enumerarán después de procesarlas.
-L [patrón]
Enumera los archivos de resolv.conf que tenemos, procesados posteriormente por la configuración de resolvconf.conf(5). Si se especifica patrón, entonces enumeramos los archivos para las claves que coinciden con él.
-l [patrón]
Enumera los archivos de resolv.conf que tenemos. Si se especifica patrón, entonces enumeramos los archivos para las claves que coinciden con él. que coinciden con él.
-u
Fuerza a resolvconf a actualizar a todos sus suscriptores. resolvconf no actualiza a los suscriptores al agregar un resolv.conf que coincide con lo que ya tiene para esa clave.
--version
Eco de la versión de resolvconf a stdout.
