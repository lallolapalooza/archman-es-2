REMOVE(3P) Manual de Programador de POSIX REMOVE(3P)

PRÓLOGO

Esta página del manual es parte del Manual de Programador de POSIX. La implementación de esta interfaz en Linux puede diferir (consulte la página del manual correspondiente de Linux para conocer los detalles del comportamiento en Linux), o la interfaz puede no estar implementada en Linux.

NOMBRE

remove — eliminar un archivo

SINOPSIS

#include <stdio.h>
int remove(const char *path);

DESCRIPCIÓN

La funcionalidad descrita en esta página de referencia está alineada con el estándar ISO C. Cualquier conflicto entre los requisitos descritos aquí y el estándar ISO C es no intencional. Este volumen de POSIX.1-2017 remite al estándar ISO C.

La función remove() hará que el archivo nombrado por la ruta apuntada por path ya no sea accesible por ese nombre. Un intento posterior de abrir ese archivo usando ese nombre fallará, a menos que se cree de nuevo.

Si path no nombra un directorio, remove(path) será equivalente a unlink(path).

Si path nombra un directorio, remove(path) será equivalente a rmdir(path).

VALOR DE RETORNO

Consulte rmdir() o unlink().

ERRORES

Consulte rmdir() o unlink().

Las siguientes secciones son informativas.

EJEMPLOS

Eliminar acceso a un archivo

El siguiente ejemplo muestra cómo eliminar el acceso a un archivo llamado /home/cnd/old_mods.

#include <stdio.h>
int status;
...
status = remove("/home/cnd/old_mods");
