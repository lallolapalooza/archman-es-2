REPO(1) Manual de Repo REPO(1)

NOMBRE

repo - herramienta de gestión de repositorios construida sobre git

SINOPSIS

repo [-p|--paginate|--no-pager] COMANDO [ARGUMENTOS]

OPCIONES

-h, --help
mostrar este mensaje de ayuda y salir
--help-all
mostrar este mensaje de ayuda con todos los subcomandos y salir
-p, --paginate
mostrar la salida del comando en el paginador
--no-pager
desactivar el paginador
--color=COLOR
controlar el uso del color: auto, siempre, nunca
--trace
rastrear la ejecución de comandos git (REPO_TRACE=1)
--trace-to-stderr
las salidas de rastreo van a stderr además de a .repo/TRACE_FILE
--trace-python
rastrear la ejecución de comandos python
--time
medir el tiempo de ejecución del comando repo
--version
mostrar esta versión de repo
--show-toplevel
mostrar la ruta del directorio de nivel superior del checkout del cliente de repo
--event-log=EVENT_LOG
nombre de archivo del registro de eventos para adjuntar la línea de tiempo
--git-trace2-event-log=GIT_TRACE2_EVENT_LOG
directorio para escribir el registro de eventos git trace2
--submanifest-path=RUTA_REL
ruta del submanifiesto

La lista completa de comandos repo reconocidos es:

abandon
Abandonar permanentemente una rama de desarrollo
branch
Ver ramas de temas actuales
branches
Ver ramas de temas actuales
checkout
Hacer checkout de una rama para desarrollo
cherry-pick
Seleccionar un cambio.
diff
Mostrar cambios entre un commit y el árbol de trabajo
diffmanifests
Utilidad de diferencia de manifiestos
download
Descargar y hacer checkout de un cambio
forall
Ejecutar un comando de shell en cada proyecto
gc
Limpieza del estado interno de repo y Git.
grep
Imprimir líneas que coinciden con un patrón
help
Mostrar ayuda detallada sobre un comando
info
Obtener información sobre la rama del manifiesto, la rama actual o las ramas no fusionadas
init
Inicializar un checkout de cliente de repo en el directorio actual
list
Listar proyectos y sus directorios asociados
manifest
Utilidad de inspección de manifiestos
overview
Mostrar resumen de ramas de proyectos no fusionadas
prune
Podar (eliminar) temas ya fusionados
rebase
Rebasar ramas locales sobre la rama remota
selfupdate
Actualizar repo a la última versión
smartsync
Actualizar el árbol de trabajo a la última revisión estable conocida
stage
Preparar archivos para commit
start
Iniciar una nueva rama para desarrollo
status
Mostrar el estado del árbol de trabajo
sync
Actualizar el árbol de trabajo a la última revisión
upload
Subir cambios para revisión de código
version
Mostrar la versión de repo

Ver 'repo help <comando>' para más información sobre un comando específico. Informes de errores: https://issues.gerritcodereview.com/issues/new?component=1370071
