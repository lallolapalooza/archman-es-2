Paquete: tcl

Licencias: TCL

regsub(n) Comandos integrados de Tcl regsub(n)

NOMBRE

regsub - Realiza sustituciones basadas en coincidencias de patrones de expresiones regulares

SINOPSIS

regsub ?switches? exp string subSpec ?varName?

DESCRIPCIÓN

Este comando compara la expresión regular exp con string, y ya sea copia string a la variable cuyo nombre se da en varName o devuelve string si varName no está presente. (La comparación de expresiones regulares se describe en la página de referencia re_syntax). Si hay una coincidencia, al copiar string a varName (o al resultado de este comando si varName no está presente) la porción de string que coincidió con exp se reemplaza con subSpec. Si subSpec contiene un “&” o “\0”, se reemplaza en la sustitución con la porción de string que coincidió con exp. Si subSpec contiene un “\n”, donde n es un dígito entre 1 y 9, se reemplaza en la sustitución con la porción de string que coincidió con la n-ésima subexpresión entre paréntesis de exp. Se pueden usar barras invertidas adicionales en subSpec para evitar la interpretación especial de “&”, “\0”, “\n” y barras invertidas. El uso de barras invertidas en subSpec tiende a interactuar mal con el uso de barras invertidas del analizador Tcl, por lo que generalmente es más seguro encerrar subSpec entre llaves si contiene barras invertidas.

Si los argumentos iniciales de regsub comienzan con -, se tratan como modificadores. Actualmente se soportan los siguientes modificadores:

-all
Se encuentran todos los rangos en string que coinciden con exp y se realiza la sustitución para cada uno de estos rangos. Sin este modificador, solo se encuentra y sustituye el primer rango coincidente. Si se especifica -all, las secuencias “&” y “\n” se manejan para cada sustitución utilizando la información de la coincidencia correspondiente.
-expanded
Permite el uso de la sintaxis expandida de expresiones regulares, donde se ignoran los espacios en blanco y los comentarios. Esto es lo mismo que especificar la opción incrustada (?x) (ver la página del manual re_syntax).
-line
Permite la comparación sensible a saltos de línea. Por defecto, el salto de línea es un carácter completamente ordinario sin significado especial. Con este indicador, las expresiones entre corchetes “[^” y el carácter “.” nunca coinciden con un salto de línea, “^” coincide con una cadena vacía después de cualquier salto de línea además de su función normal, y “$” coincide con una cadena vacía antes de cualquier salto de línea además de su función normal. Este indicador es equivalente a especificar tanto -linestop como -lineanchor, o la opción incrustada (?n) (ver la página del manual re_syntax).
-linestop
Cambia el comportamiento de las expresiones entre corchetes “[^” y “.” para que se detengan en los saltos de línea. Esto es lo mismo que especificar la opción incrustada (?p) (ver la página del manual re_syntax).
-lineanchor
Cambia el comportamiento de “^” y “$” (los “anclajes”) para que coincidan con el principio y el final de una línea respectivamente. Esto es lo mismo que especificar la opción incrustada (?w) (ver la página del manual re_syntax).
-nocase
Los caracteres en mayúsculas en string se convertirán a minúsculas antes de compararlos con exp; sin embargo, las sustituciones especificadas por subSpec utilizan la forma original no convertida de string.
-start índice
Especifica un desplazamiento de índice de carácter en la cadena para comenzar la comparación de la expresión regular. El valor de índice se interpreta de la misma manera que el argumento índice de string index. Al usar este modificador, “^” no coincidirá con el principio de la línea, y \A seguirá coincidiendo con el inicio de la cadena en índice. índice se ajustará a los límites de la cadena de entrada.
--
Marca el final de los modificadores. El argumento que sigue a este se tratará como exp, incluso si comienza con un -.

Si se proporciona varName, el comando devuelve un recuento del número de rangos coincidentes que se encontraron y reemplazaron; de lo contrario, se devuelve la cadena después del reemplazo. Consulte la entrada del manual para regexp para obtener detalles sobre la interpretación de las expresiones regulares.

EJEMPLOS

Reemplazar (en la cadena de la variable string) cada instancia de foo que sea una palabra completa por sí misma con bar:

regsub -all {\mfoo\M} $string bar string

o (usando la sintaxis de “expresión regular básica”):

regsub -all {(?b)\<foo\>} $string bar string

Insertar comillas dobles alrededor de la primera instancia de la palabra interesting, sin importar cómo esté capitalizada.

regsub -nocase {\yinteresting\y} $string {"&"} string

Convertir todos los caracteres no ASCII y significativos para Tcl en secuencias de escape \u utilizando regsub y subst en combinación:

# Este RE es solo una clase de caracteres para casi todo lo "malo"
set RE {[][{};#\\\$ \r\t\u0080-\uffff]}
# Sustituiremos con un fragmento de script Tcl entre corchetes
set substitution {[format \\\\u%04x [scan "\\&" %c]]}
# Ahora aplicamos la sustitución para obtener una subcadena
# que realizará las partes computacionales de la conversión. Tenga en
# cuenta que el salto de línea se maneja especialmente a través de
# string map ya que la secuencia barra invertida-salto de línea
# es especial.
set quoted [subst [string map {\n {\\u000a}} \
        [regsub -all $RE $string $substitution]]]
