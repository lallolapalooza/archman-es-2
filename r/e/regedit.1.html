NOMBRE

regedit - editor del registro de Wine

SINOPSIS

regedit [archivo de texto]

DESCRIPCIÓN

regedit es el editor del registro de Wine, diseñado para ser compatible con su contraparte de Microsoft Windows. Si se llama sin opciones, iniciará el editor gráfico completo.

Los modificadores no distinguen entre mayúsculas y minúsculas y pueden prefijarse con '-' o '/'.

OPCIONES

-E archivo [regpath]
Exporta el contenido de la clave de registro especificada al archivo especificado. Exporta todo el registro si no se especifica ninguna clave.
-D regpath
Elimina la clave de registro especificada.
-S
Ejecuta regedit silenciosamente (ignorado, el modo CLI siempre es silencioso). Esto existe para compatibilidad con el regedit de Windows.
-V
Ejecuta regedit en modo avanzado (ignorado). Esto existe para compatibilidad con el regedit de Windows.
-L ubicación
Especifica la ubicación del archivo de registro system.dat (ignorado). Esto existe para compatibilidad con el regedit de Windows.
-R ubicación
Especifica la ubicación del archivo de registro user.dat (ignorado). Esto existe para compatibilidad con el regedit de Windows.
-?
Imprime un mensaje de ayuda. Se ignoran otras opciones.
-C archivo.reg
Crea el registro a partir de archivo.reg (no implementado).

ERRORES

Los errores se pueden reportar en el rastreador de errores de Wine.

DISPONIBILIDAD

regedit forma parte de la distribución de Wine, que está disponible a través de WineHQ, el centro de desarrollo de Wine.
