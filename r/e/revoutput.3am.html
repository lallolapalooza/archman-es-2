REVOUTPUT(3am) Módulos de extensión de GNU Awk REVOUTPUT(3am)

NOMBRE

revoutput - Extensión de ejemplo para invertir cadenas de salida

SINOPSIS

@load "revoutput"

BEGIN { REVOUT = 1 } # Invierte todas las cadenas de salida

DESCRIPCIÓN

La extensión revoutput añade un envoltorio de salida simple que invierte los caracteres de cada línea de salida. Su propósito principal es mostrar cómo escribir un envoltorio de salida, aunque puede ser ligeramente divertido para el incauto.

EJEMPLO

@load "revoutput"
BEGIN {
    REVOUT = 1
    print "hola, mundo" > "/dev/stdout"
}

La salida de este programa es:

odnum ,aloh

ERRORES

Esta extensión no afecta a la salida estándar por defecto.
