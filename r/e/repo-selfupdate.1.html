REPO(1) Manual de Repo REPO(1)

NOMBRE

repo - repo selfupdate - página del manual para repo selfupdate

SINOPSIS

repo selfupdate

DESCRIPCIÓN

Resumen

Actualizar repo a la última versión

OPCIONES

-h, --help
mostrar esta ayuda y salir

Opciones de registro:

-v, --verbose
mostrar toda la salida
-q, --quiet
mostrar solo errores

Opciones multimanifesto:

--outer-manifest
operar comenzando desde el manifiesto más externo
--no-outer-manifest
no operar en manifiestos externos
--this-manifest-only
solo operar en este (sub)manifiesto
--no-this-manifest-only, --all-manifests
operar en este manifiesto y sus submanifiestos

Opciones de versión de repo:

--no-repo-verify
no verificar el código fuente de repo

Ejecute `repo help selfupdate` para ver el manual detallado.

DETALLES

El comando 'repo selfupdate' actualiza repo a la última versión, si hay una versión más reciente disponible.

Normalmente esto se hace automáticamente con 'repo sync' y no necesita ser realizado por un usuario final.
