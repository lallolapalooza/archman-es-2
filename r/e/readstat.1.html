READSTAT(1) Manual de Comandos Generales READSTAT(1)

NOMBRE

readstat - leer y escribir archivos de conjuntos de datos de SAS, SPSS y Stata

SINOPSIS

readstat archivo-entrada

readstat [-f] archivo-entrada archivo-salida

readstat [-f] archivo-entrada archivo-metadatos archivo-salida

DESCRIPCIÓN

readstat convierte archivos de conjuntos de datos de paquetes estadísticos populares almacenados en formatos de texto plano y binarios.

En el primer estilo de invocación, readstat muestra metadatos del archivo-entrada, incluyendo el número de filas, el número de columnas, la codificación de texto y la marca de tiempo. El archivo-entrada debe ser un archivo con una de las siguientes extensiones:

sas7bdat
Archivo binario SAS, creado con SAS versión 7 o posterior
xpt
Archivo portable SAS, versión 5 o versión 8, creado con el comando SAS XPORT
sav
Archivo binario sin comprimir de SPSS
zsav
Archivo binario comprimido de SPSS
por
Archivo portable de SPSS
dta
Archivo binario de Stata, versión 104 o posterior

Si el número de filas no se puede determinar a partir de la cabecera del archivo, lo que a veces ocurre con los archivos binarios de SPSS y siempre ocurre con los archivos portables de SPSS, readstat informará un valor de -1.

En el segundo estilo de invocación, readstat convierte archivo-entrada a archivo-salida, por ejemplo, un archivo portable SAS a un archivo binario Stata. Además de la lista de extensiones anterior, archivo-salida puede tener la extensión csv o xlsx, lo que crea un archivo CSV o Excel, respectivamente.

El tercer estilo de invocación se utiliza cuando metadatos adicionales sobre el archivo de entrada, como etiquetas de valor o anchos de columna, se almacenan en un archivo separado. Se admiten varios tipos de archivos de metadatos:

sas7bcat
Archivo "catálogo" binario SAS, creado con SAS versión 7 o posterior, que contiene etiquetas de valor
json
Archivo de Notación de Objetos JavaScript (JSON), que contiene metadatos de columna que no se pueden obtener del CSV de entrada. Para más detalles, consulte la página del manual del comando extract_metadata.
dct
Archivo de diccionario de Stata, que contiene la estructura de datos y los metadatos de columna para un archivo de entrada de texto plano.
sps
Archivo de comandos de SPSS, que describe la estructura de datos y los metadatos de columna para un archivo de entrada de texto plano.
sps
Archivo de comandos SAS, que describe la estructura de datos y los metadatos de columna para un archivo de entrada de texto plano.

Los últimos tres formatos se pueden utilizar tanto para archivos de entrada de ancho fijo como para archivos de entrada separados por delimitadores (por ejemplo, separados por tabulaciones). Estos se distribuyen comúnmente junto con conjuntos de datos ASCII de texto plano.

Los formatos de entrada y salida se infieren por la extensión del archivo.

OPCIONES

-f
Sobrescribir cualquier archivo-salida existente.

ERRORES

Los archivos binarios SAS creados por readstat no se abren con las versiones actuales de SAS.

Los detalles más finos de las cadenas de formato (por ejemplo, "%8.2g") no se convierten correctamente entre formatos de archivo.
