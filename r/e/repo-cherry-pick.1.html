repo-cherry-pick(1)

Paquete: repo

Licencias: Apache-2.0

REPO(1) Manual de Repo REPO(1)

NOMBRE

repo - repo cherry-pick - página del manual para repo cherry-pick

SINOPSIS

repo cherry-pick <sha1>

DESCRIPCIÓN

Resumen

Aplicar selectivamente un cambio.

OPCIONES

-h, --help
mostrar esta ayuda y salir

Opciones de registro:

-v, --verbose
mostrar toda la salida
-q, --quiet
mostrar solo errores

Opciones multi-manifiesto:

--outer-manifest
operar comenzando desde el manifiesto más externo
--no-outer-manifest
no operar en manifiestos externos
--this-manifest-only
solo operar en este manifiesto (sub)
--no-this-manifest-only, --all-manifests
operar en este manifiesto y sus submanifiestos

Ejecute `repo help cherry-pick` para ver el manual detallado.

DETALLES

'repo cherry-pick' aplica selectivamente un cambio de una rama a otra. El ID del cambio se actualizará y se agregará una referencia al ID del cambio anterior.
