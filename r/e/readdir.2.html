readdir(2) Manual de llamadas al sistema readdir(2)

NOMBRE

readdir - leer entrada de directorio

BIBLIOTECA

Biblioteca C estándar (libc, -lc)

SINOPSIS

#include <sys/syscall.h>      /* Definición de constantes SYS_* */
#include <unistd.h>
int syscall(SYS_readdir, unsigned int fd,
            struct old_linux_dirent *dirp, unsigned int count);

Nota: No existe definición de struct old_linux_dirent; ver VERSIONES.

DESCRIPCIÓN

Esta no es la función que te interesa. Mira readdir(3) para la interfaz de la biblioteca C que cumple con POSIX. Esta página documenta la interfaz de llamada al sistema sin procesar del kernel, que está obsoleta por getdents(2).

readdir() lee una estructura old_linux_dirent del directorio al que se refiere el descriptor de archivo fd y la introduce en el búfer al que apunta dirp. El argumento count se ignora; se lee como máximo una estructura old_linux_dirent.

La estructura old_linux_dirent se declara (privadamente en el archivo del kernel de Linux fs/readdir.c) de la siguiente manera:


struct old_linux_dirent {
    unsigned long d_ino;     /* número de inodo */
    unsigned long d_offset;  /* desplazamiento a esta old_linux_dirent */
    unsigned short d_namlen; /* longitud de este d_name */
    char  d_name[1];         /* nombre de archivo (terminado en nulo) */
}

d_ino es un número de inodo. d_offset es la distancia desde el inicio del directorio hasta esta old_linux_dirent. d_reclen es el tamaño de d_name, sin contar el byte nulo terminador ('\0'). d_name es un nombre de archivo terminado en nulo.

VALOR DE RETORNO

En caso de éxito, se devuelve 1. En el final del directorio, se devuelve 0. En caso de error, se devuelve -1 y errno se establece para indicar el error.

ERRORES

EBADF
Descriptor de archivo fd no válido.
EFAULT
El argumento apunta fuera del espacio de direcciones del proceso que llama.
EINVAL
El búfer de resultado es demasiado pequeño.
ENOENT
No existe tal directorio.
ENOTDIR
El descriptor de archivo no se refiere a un directorio.

VERSIONES

Tendrás que definir tú mismo la estructura old_linux_dirent. Sin embargo, probablemente deberías usar readdir(3) en su lugar.

Esta llamada al sistema no existe en x86-64.

ESTANDARES

Linux.

VER TAMBIÉN

getdents(2), readdir(3)
