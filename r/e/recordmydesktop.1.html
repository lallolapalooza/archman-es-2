recordMyDesktop(1) Manual de Comandos Generales recordMyDesktop(1)

Nombre

recordMyDesktop - graba sesiones de escritorio en un archivo de video Ogg Theora con audio Vorbis

Sinopsis

recordmydesktop

recordmydesktop nombre-archivo-salida

recordmydesktop --rescue ruta-a-datos

recordmydesktop {opciones-imagen|opciones-sonido|opciones-codificación|opciones-varias| ... }

recordmydesktop {-h|--help}

recordmydesktop --version

recordmydesktop --print-config

Descripción

recordMyDesktop produce un archivo (out.ogv por defecto) que contiene una grabación de video y audio de una sesión del sistema de ventanas X.

Para un escenario típico, grabar tu sesión es tan simple como

$ recordmydesktop
lo que producirá una grabación a pantalla completa llamada out.ogv en el directorio de trabajo actual, mientras que el comando
$ recordmydesktop ../foo
guardará la grabación en foo.ogv en el directorio padre del directorio de trabajo actual.

Para finalizar una grabación, presiona Control+C. (Esta acción envía una señal SIGINT a recordMyDesktop.)

Para designar una región de la pantalla para grabar puedes escribir esto:

$ recordmydesktop -x pos-x -y pos-y --width ancho --height alto -o foo.ogv
donde pos-x y pos-y especifican el desplazamiento en píxeles desde la esquina superior izquierda de tu pantalla y ancho y alto el tamaño de la región a grabar, también en píxeles. Si el área se extiende más allá de tu resolución actual, serás notificado apropiadamente y no sucederá nada.

Nota: Si se utiliza cualquier opción y deseas usar un nombre de archivo de salida diferente al predeterminado, debes especificarlo con la opción -o.

Desde la versión 0.3 de recordMyDesktop, la codificación se realiza inmediatamente después de que finaliza la grabación. Si bien este comportamiento ahorra mucha CPU, puedes volver al anterior especificando la opción --on-the-fly-encoding.

El comportamiento predeterminado de grabación es marcar las áreas que han cambiado (según lo determinado por la extensión X Damage) y actualizar el fotograma. Este comportamiento se puede cambiar mediante la opción --full-shots para producir un resultado más preciso o capturar ventanas que no generan eventos X al cambiar, como ventanas con contexto 3D acelerado, pero esto aumentará notablemente la carga de trabajo.

recordMyDesktop no tiene una interfaz de usuario en el sentido convencional. Después de iniciarse, solo se puede controlar mediante las siguientes señales:

SIGUSR1
hace que el programa se pause si está grabando actualmente, y viceversa.
SIGTERM
SIGINT
provoca la terminación normal de la grabación.
SIGABRT
termina el programa y elimina el archivo de salida.

Estas señales también se pueden enviar a la aplicación a través de la configuración de atajos de teclado. Consulta --pause-shortcut y --stop-shortcut en la subsección Misceláneo de la sección Opciones a continuación.

Para una manipulación adicional del resultado final, consulta las secciones Opciones y Notas a continuación.

Opciones

Si y solo si no se especifican opciones, recordMyDesktop acepta un único operando que interpreta como un nombre de archivo de salida.

recordMyDesktop acepta muchas opciones de línea de comandos. La discusión siguiente las agrupa en familias.

General

-h o --help
Imprime un resumen del uso y sale.
--version
Imprime la versión del programa y sale.
--print-config
Imprime información sobre las opciones seleccionadas durante la compilación y sale. Actualmente indica si la captura Jack está habilitada y si se usa ALSA u OSS; puede informar más información en el futuro.

Imagen

--windowid wid
Graba la región de la pantalla correspondiente a la ventana X wid en el momento en que se inicia recordMyDesktop. Grabar una ventana no rastrea la ventana en sí, sino la región que cubre; si la ventana se mueve, recordMyDesktop no la sigue. Si la ventana está oscurecida por otra, se captura el contenido de la ventana oscurecedora dentro de la región de grabación. El ID de la ventana de un cliente X se puede obtener con el programa xwininfo(1); consulta la sección Notas a continuación.
--display x-display
Conéctate a la pantalla del sistema de ventanas X en x-display. Por defecto, se utiliza el valor de la variable de entorno DISPLAY para determinar la pantalla.
-x desplazamiento-x
Restringe la región de grabación para que comience a desplazamiento-x píxeles desde el borde izquierdo de la pantalla o de la ID de ventana X designada con --windowid. El valor predeterminado es 0.
-y desplazamiento-y
Restringe la región de grabación para que comience a desplazamiento-y píxeles desde el borde superior de la pantalla o de la ID de ventana X designada con --windowid. El valor predeterminado es 0.
--width ancho
Restringe la región de grabación a ancho píxeles de ancho. El valor predeterminado es el ancho completo de la pantalla o de la ID de ventana X designada con --windowid.
--height alto
Restringe la región de grabación a alto píxeles de alto. El valor predeterminado es el alto completo de la pantalla o de la ID de ventana X designada con --windowid.
--dummy-cursor color
Dibuja un cursor ficticio en lugar del normal. El color dado debe ser una cadena, ya sea "black" (negro) o "white" (blanco).
--no-cursor
Deshabilita el dibujo del cursor.
--no-shared
No uses la extensión de memoria compartida MIT (MIT-SHM). No se recomienda el uso de esta opción.
--full-shots
Toma una captura de pantalla completa en cada fotograma. No se recomienda el uso de esta opción.
--follow-mouse
Cuando esta opción está habilitada, el área de captura sigue al cursor del ratón. Esto solo tiene sentido cuando el área seleccionada es un subconjunto de la pantalla completa. Esta opción implica --full-shots.
--quick-subsampling
Submuestrea los planos de croma descartando píxeles adicionales.
--fps n
Intenta capturar n fotogramas por segundo, donde n es positivo y puede ser un número entero o decimal. La velocidad de fotogramas alcanzable está limitada por el hardware y la carga de trabajo de tu sistema. El valor predeterminado es 15.

Sonido

--channels n
Graba hasta n canales, donde n es un entero positivo. El valor predeterminado es 2 (estéreo).
--freq n
Graba a una frecuencia de muestreo de n hercios, donde n es un entero positivo. El valor predeterminado es 22050 (22.05 kHz).
--buffer-size n
Almacena en búfer n bytes de datos de sonido al usar los sistemas de sonido ALSA u OSS, donde n es un entero positi

Options

The options are grouped below by category.

Audio

--buffer-size n
Set the size of the sound card buffer in bytes, where n is a positive integer. The default is 4096 (4 kiB).
--ring-buffer-size n
Set the size of the JACK ring buffer in seconds, where n is a positive floating-point number. The default is 3.0.
The total size of the buffer in bytes can be expressed as a C language expression: 
ring_buffer_size * sample_rate * number_of_ports
        * sizeof(jack_default_audio_sample_t),
where sizeof(jack_default_audio_sample_t) is normally 4.
--device sound-device
Capture audio from sound-device. The default is default or /dev/dsp, depending on whether ALSA or OSS is used, respectively.
--use-jack port ...
Record audio from the specified list of space-separated JACK ports. When using this option, all other audio-related options (except --no-sound) are ignored.
--no-sound
Do not record sound.

Encoding

--on-the-fly-encoding
Encode the audio/video data while recording. The default is to defer encoding until after recording is complete.
--v_quality n
Set the desired video quality to n, an integer between 0 and 63 inclusive; higher is better. The default is 63. See the Notes section below.
--v_bitrate n
Set the desired bit rate of the encoded video to n bits per second. The accepted range of n is between 0 and 200,000,000 inclusive; the default is 0. (The thousands separator is shown here for clarity; do not use it in the option argument.)
--s_quality n
Set the desired audio quality to n, an integer between -1 and 10 inclusive; higher is better. The default is 10.

Miscellaneous

--rescue path-to-data
Encode cache data from a previous session into an Ogg Theora file. The filename will be the one that was chosen initially. Any other option specified with this one will be implicitly ignored and recordMyDesktop will exit after the end of the encoding. This option was added in recordMyDesktop 0.3.7 and it will not work with cache files produced from earlier versions. When using this option, note that recordMyDesktop's cache is not safe with respect to data type sizes and endianness. To locate the cached data, see the --workdir option below.
--no-wm-check
When a 3D compositing window manager is detected, the program will function as if the --full-shots option had been specified. This option disables the check.
--no-frame
Normally, a frame is drawn around the recording region to assist the user to identify what does and doesn't get captured. When the --follow-mouse is given, this frame will also follow the pointer around. However, the frame might cause problems for drag-and-drop operations. If you do not wish this frame to appear, use this option.
--pause-shortcut mod+key
Designate a key combination to toggle the pause state of the recording. mod can be any combination of the following modifier keys: Control, Shift, and Mod1 to Mod5. The modifiers can be separated by any character (except a space) or none at all. key can be any key defined in /usr/include/X11/keysymdef.h. Omit the XK_ prefixes to the key names found in that file. The list of modifiers must be separated from the key with a plus sign “+”. The default is Control+Mod1+p. (Mod1 usually corresponds to the left Alt key).
--stop-shortcut mod+key
Designate a key combination to stop the recording. For details, see --pause-shortcut above. The default is Control+Mod1+s.
--compress-cache
Image data are cached with a light compression.
--workdir dir
recordMyDesktop creates a temporary directiory in dir to cache intermediate files. The default is read from the environment variable TMPDIR if set, otherwise /tmp is used.
--delay n[H|h|M|m]
Wait n units of time (seconds, if not specified) before starting the recording, where n is a non-negative integral or floating-point value. An optional suffix of H or h, M or m; indicates time units of hours or minutes, respectively. The default is no delay.
--overwrite
If the output filename already exists, delete it. The default is to refuse to overwrite, interpolating a numeric discriminator into the filename instead (see the Files section below).
-o filename
Write the encoded video to filename. The default is out.ogv.

Exit Status

An exit status of 0 means success per the usual Unix conventions.

A non-zero exit status means that an error occurred; these are accompanied by diagnostic messages to the standard error. Furthermore, several exceptional conditions are distinguished by exit status.

1
Argument parsing failed or argument input was nonsensical.
2
Encoder initialization failed (Vorbis or Theora).
3
Could not open or configure sound device.
4
XDamage extension is not present.
5
MIT-SHM extension is not present.
6
XFixes extension is not present.
7
XInitThreads(3) failed.
8
The DISPLAY environment variable is not set and no --display option was specified.
9
Could not connect to the X server.
10
The color depth of the root window is not 32, 24, or 16 bits per pixel.
11
The recording window specification was invalid.
12
Could not attach shared memory to process.
13
Could not open file for writing.

Environment

DISPLAY
specifies the X server to connect to. For typical use cases, this variable is already set correctly in the environment and corresponds to the X display the user is already interacting with (in other words, recordMyDesktop “does the right thing”). See section Display Names in X(7) for more information.

Files

recordMyDesktop adds the suffix .ogv to any output filename that does not already possess one (in any letter case).

If you try to save to a filename that already exists, a numeric discriminator of the form -n is interpolated into the filename before the .ogv suffix. The number n starts at 1 and is incremented if the filename with that discriminator exists already.

For example, when not specifying a name, if out.ogv exists, the new file will be out-1.ogv, and if that exists too, out-2.ogv is used, and so on ad infinitum (not really, more like ad unsigned short).

Notes

Recoding using an X window ID

When using the --windowid option, read carefully its description in the Options section above, as well as those of the -x, -y, --width, and --height options.

An easy way to find out the ID of a window is by using the xwininfo(1) program. Running a command like

$ xwininfo | awk '/Window id:/ {print $4}'
will report only the window ID, which will be a hexadecimal integer in C literal format, like “0x4800005”. More conveniently, you can put all that in the command that launches recordMyDesktop like this:
$ recordmydesktop --windowid $(xwininfo | awk '/Window id:/ {print $4}')

Tuning the video quality

The lower the quality you select on a video recording (by using the --v_quality option), the more CPU performance you will require. So if you are also using the --on-the-fly-encoding option, it's better to start with default values and manipulate the end result with another program. An excellent converter is the vlc(1) media player, which can perform a variety of transcoding operations, using either a graphical interface or the command line. vlc is a complex piece of software; you should consult its documentation before using it. An example follows which will resize a recording named out.ogv to 512×384.

$ vlc -I dummy out.ogv vlc:quit --sout "#transcode{ vcodec = theo, width = 512, height = 384 }:duplicate{ dst = std{ access = file, mux=ogg, dst = \"out_512x384.ogv\" }}"

If you wish to change the video quality you can append the option --sout-theora-quality=n, with n in the range [1,10]; for example,

$ vlc -I dummy out.ogv vlc:quit --sout "#transcode{ vcodec = theo, width = 512, height = 38

Notas

Otra opción es ffmpeg2theora(1), que, a pesar de su nombre, también es un conversor de Theora a Theora. Cambiar la calidad de una grabación con él puede ser tan simple como:

$ ffmpeg2theora infile.ogv -v 3 -a 4 -o outfile.ogv

Incluso puede realizar un redimensionamiento en la geometría de la grabación o cambiar la duración general.

Errores

  • No graba ventanas 3D si no se especifica --full-shots.
  • Guardar 65536 archivos con el mismo nombre dará como resultado un comportamiento impredecible, que podría manifestarse como un bucle infinito o una falla de segmentación.
