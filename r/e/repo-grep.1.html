NOMBRE

repo grep - página de manual para repo grep

SINOPSIS

repo grep {patrón | -e patrón} [proyecto...]

DESCRIPCIÓN

Resumen

Imprimir líneas que coincidan con un patrón

OPCIONES

-h, --help
mostrar este mensaje de ayuda y salir
-j TRABAJOS, --jobs=TRABAJOS
número de trabajos a ejecutar en paralelo (predeterminado: basado en el número de núcleos de CPU)

Opciones de registro:

--verbose
mostrar toda la salida
-q, --quiet
mostrar solo errores

Opciones de múltiples manifiestos:

--outer-manifest
operar comenzando desde el manifiesto más externo
--no-outer-manifest
no operar en manifiestos externos
--this-manifest-only
operar solo en este (sub)manifiesto
--no-this-manifest-only, --all-manifests
operar en este manifiesto y sus submanifiestos

Fuentes:

--cached
Buscar en el índice, en lugar del árbol de trabajo
-r TREEish, --revision=TREEish
Buscar en TREEish, en lugar del árbol de trabajo

Patrón:

-e PATRÓN
Patrón a buscar
-i, --ignore-case
Ignorar diferencias de mayúsculas/minúsculas
-a, --text
Procesar archivos binarios como si fueran de texto
-I
No buscar el patrón en archivos binarios
-w, --word-regexp
Coincidir el patrón solo en los límites de las palabras
-v, --invert-match
Seleccionar líneas no coincidentes
-G, --basic-regexp
Usar expresiones regulares básicas POSIX para patrones (predeterminado)
-E, --extended-regexp
Usar expresiones regulares extendidas POSIX para patrones
-F, --fixed-strings
Usar cadenas fijas (no expresiones regulares) para el patrón

Agrupación de patrones:

--all-match
Limitar la coincidencia a líneas que tengan todos los patrones
--and, --or, --not
Operadores booleanos para combinar patrones
-(, -)
Agrupación de operadores booleanos

Salida:

-n
Prefijar el número de línea a las líneas coincidentes
-C CONTEXTO
Mostrar líneas de CONTEXTO alrededor de la coincidencia
-B CONTEXTO
Mostrar líneas de CONTEXTO antes de la coincidencia
-A CONTEXTO
Mostrar líneas de CONTEXTO después de la coincidencia
-l, --name-only, --files-with-matches
Mostrar solo los nombres de archivo que contienen líneas coincidentes
-L, --files-without-match
Mostrar solo los nombres de archivo que no contienen líneas coincidentes

Ejecuta `repo help grep` para ver el manual detallado.

DETALLES

Buscar los patrones especificados en todos los archivos del proyecto.

Opciones booleanas

Las siguientes opciones pueden aparecer tantas veces como sea necesario para expresar el patrón a localizar:

-e PATRÓN

--and, --or, --not, -(, -)

Además, la opción -r/--revision puede especificarse varias veces para escanear varios árboles. Si el mismo archivo coincide en más de un árbol, solo se informa el primer resultado, prefijado por el nombre de la revisión bajo el cual se encontró.

Ejemplos

Buscar una línea que contenga '#define' y ya sea 'MAX_PATH o 'PATH_MAX':

repo grep -e '#define' --and -\( -e MAX_PATH -e PATH_MAX \)

Buscar una línea que contenga 'NODE' o 'Unexpected' en archivos que contengan una línea que coincida con ambas expresiones:

repo grep --all-match -e NODE -e Unexpected
