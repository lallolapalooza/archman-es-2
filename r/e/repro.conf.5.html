NOMBRE

repro.conf - archivo de configuración de repro

SINOPSIS

/etc/archlinux-repro/repro.conf, $XDG_CONFIG_HOME/archlinux-repro/repro.conf, ~/.repro.conf

DESCRIPCIÓN

Las opciones de configuración para repro se almacenan en repro.conf. Este archivo es invocado por repro al iniciarse. Todas las variables, independientemente de si se describen a continuación, se exportan al entorno de compilación.

El archivo de configuración a nivel de sistema se encuentra en /etc/archlinux-repro/repro.conf. Las opciones individuales pueden ser anuladas por usuario en $XDG_CONFIG_HOME/devtools-repro/repro.conf o ~/.repro.conf, con la primera teniendo prioridad.

OPCIONES

BOOTSTRAPMIRROR="https://mirror.archlinux.no/iso/latest"

Ubicación de descarga de la imagen de arranque utilizada para crear el contenedor.

BUILDDIRECTORY="/var/lib/repro"

Ubicación donde se deben almacenar los contenedores.

DIFFOSCOPE="diffoscope"

Establece el comando diffoscope(1) que se ejecutará cuando se encuentren paquetes no reproducibles.

HOSTMIRROR="http://mirror.neuf.no/archlinux/\$repo/os/\$arch"

El espejo utilizado dentro del contenedor por pacman.

IMGDIRECTORY="/tmp/arch_img"

Ubicación donde se debe descargar la imagen de arranque de Arch Linux.

MAKEFLAGS="-j$(nproc)"

Configura MAKEFLAGS en el nodo. El valor predeterminado se establece para fines de optimización.

ARCH_ARCHIVE_CACHE="https://archive.archlinux.org/packages"

Configura el espejo de archivo a utilizar al descargar paquetes archivados.

NOCHECK=0

Decide si makepkg debe ejecutarse con o sin --nocheck dentro del contenedor. Nota: Esto podría afectar el proceso de compilación.

CACHEDIR=cache

Elige la ubicación del directorio de caché. El valor predeterminado crea una caché en el directorio de trabajo.

OUTDIR=./build

Elige el directorio de salida de la compilación. El valor predeterminado crea ./build en el directorio de trabajo.
