remainder(3) Manual de Funciones de Biblioteca remainder(3)

NOMBRE

drem, dremf, dreml, remainder, remainderf, remainderl - función de resto de punto flotante

BIBLIOTECA

Biblioteca matemática (libm, -lm)

SINOPSIS

#include <math.h>
double remainder(double x, double y);
float remainderf(float x, float y);
long double remainderl(long double x, long double y);
/* Sinónimos obsoletos */
[[deprecated]] double drem(double x, double y);
[[deprecated]] float dremf(float x, float y);
[[deprecated]] long double dreml(long double x, long double y);
Requisitos de Macro de Prueba de Funciones para glibc (ver feature_test_macros(7)):

remainder():

    _ISOC99_SOURCE || _POSIX_C_SOURCE >= 200112L
        || _XOPEN_SOURCE >= 500
        || /* Desde glibc 2.19: */ _DEFAULT_SOURCE
        || /* glibc <= 2.19: */ _BSD_SOURCE || _SVID_SOURCE

remainderf(), remainderl():

    _ISOC99_SOURCE || _POSIX_C_SOURCE >= 200112L
        || /* Desde glibc 2.19: */ _DEFAULT_SOURCE
        || /* glibc <= 2.19: */ _BSD_SOURCE || _SVID_SOURCE

drem(), dremf(), dreml():

    /* Desde glibc 2.19: */ _DEFAULT_SOURCE
        || /* glibc <= 2.19: */ _BSD_SOURCE || _SVID_SOURCE

DESCRIPCIÓN

Estas funciones calculan el resto de la división de x por y. El valor de retorno es x-n*y, donde n es el valor x / y, redondeado al entero más cercano. Si el valor absoluto de x-n*y es 0.5, n se elige para ser par.

Estas funciones no se ven afectadas por el modo de redondeo actual (ver fenv(3)).

La función drem() hace exactamente lo mismo.

VALOR DE RETORNO

En caso de éxito, estas funciones devuelven el resto en punto flotante, x-n*y. Si el valor de retorno es 0, tiene el signo de x.

Si x o y es un NaN, se devuelve un NaN.

Si x es un infinito y y no es un NaN, se produce un error de dominio y se devuelve un NaN.

Si y es cero y x no es un NaN, se produce un error de dominio y se devuelve un NaN.

ERRORES

Consulte math_error(7) para obtener información sobre cómo determinar si se ha producido un error al llamar a estas funciones.

Los siguientes errores pueden ocurrir:

Error de dominio: x es un infinito y y no es un NaN
errno se establece en EDOM (pero consulte BUGS). Se genera una excepción de punto flotante inválida (FE_INVALID).
Estas funciones no establecen errno para este caso.
Error de dominio: y es cero
errno se establece en EDOM. Se genera una excepción de punto flotante inválida (FE_INVALID).

ERRORES CONOCIDOS

Antes de glibc 2.15, la llamada


remainder(nan(""), 0);

devolvía un NaN, como se esperaba, pero erróneamente causaba un error de dominio. Desde glibc 2.15, se devuelve un NaN silencioso (es decir, sin error de dominio).

Antes de glibc 2.15, errno no se establecía en EDOM para el error de dominio que ocurre cuando x es un infinito y y no es un NaN.

EJEMPLOS

La llamada "remainder(29.0, 3.0)" devuelve -1.
