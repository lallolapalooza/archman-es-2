NOMBRE

regulatory.bin, regulatory.db - La base de datos regulatoria inalámbrica de Linux


DESCRIPCIÓN

regulatory.bin y regulatory.db son los archivos utilizados por el subsistema inalámbrico de Linux para mantener su información de la base de datos regulatoria.

regulatory.bin es leído por crda a solicitud del kernel de Linux para obtener información regulatoria para un código de país alfa2 ISO / IEC 3166 específico.

regulatory.db es un formato de base de datos más nuevo y extensible que (desde Linux 4.15) es leído directamente por el kernel como un archivo de firmware.

La base de datos regulatoria se mantiene en un formato binario pequeño para eficiencia de tamaño y código. El archivo regulatory.bin puede ser analizado y leído en formato legible para humanos utilizando el comando regdbdump. Los archivos de la base de datos regulatoria deben actualizarse ante cambios o correcciones regulatorias.

MANTENIMIENTO

La base de datos regulatoria es mantenida por la comunidad, por lo que se le anima a enviar cualquier corrección o actualización a las listas de correo linux-wireless y wireless-regdb: linux-wireless@vger.kernel.org y wireless-regdb@lists.infradead.org
