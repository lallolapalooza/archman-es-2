regex(3) Manual de Funciones de Biblioteca regex(3)

NOMBRE

regcomp, regexec, regerror, regfree - Funciones POSIX de regex

BIBLIOTECA

Biblioteca C estándar (libc, -lc)

SINOPSIS

#include <regex.h>
int regcomp(regex_t *restrict preg, const char *restrict regex,
            int cflags);
int regexec(const regex_t *restrict preg,
            const char *restrict string,
            size_t n, regmatch_t pmatch[_Nullable restrict n],
            int eflags);
size_t regerror(size_t errbuf_size;
            int errcode, const regex_t *_Nullable restrict preg,
            char errbuf[_Nullable restrict errbuf_size],
            size_t errbuf_size);
void regfree(regex_t *preg);
typedef struct {
    size_t    re_nsub;
} regex_t;
typedef struct {
    regoff_t  rm_so;
    regoff_t  rm_eo;
} regmatch_t;
typedef /* ... */  regoff_t;

DESCRIPCION

Compilacion

regcomp() se usa para compilar una expresión regular en un formato adecuado para búsquedas posteriores con regexec().

En caso de éxito, el búfer de patrones en *preg se inicializa. regex es una cadena terminada en nulo. La configuración regional debe ser la misma al ejecutar regexec().

Después de que regcomp() tenga éxito, preg->re_nsub contiene el número de subexpresiones en regex. Por lo tanto, un valor de preg->re_nsub + 1 pasado como n a regexec() es suficiente para capturar todas las coincidencias.

cflags es el OR a nivel de bits de cero o más de las siguientes opciones:

REG_EXTENDED
Utiliza la sintaxis de Expresiones Regulares Extendidas POSIX al interpretar regex. Si no se establece, se utiliza la sintaxis de Expresiones Regulares Básicas POSIX.
REG_ICASE
No diferencia entre mayúsculas y minúsculas. Las búsquedas posteriores con regexec() que utilicen este búfer de patrones no distinguirán mayúsculas de minúsculas.
REG_NOSUB
Solo informa del éxito general. regexec() solo utilizará pmatch para REG_STARTEND, ignorando n.
REG_NEWLINE
Los operadores de carácter comodín no coinciden con un salto de línea.
Una lista de no coincidencia ([^...]) que no contiene un salto de línea no coincide con un salto de línea.
El operador de principio de línea (^) coincide con la cadena vacía inmediatamente después de un salto de línea, independientemente de si eflags, las banderas de ejecución de regexec(), contiene REG_NOTBOL.
El operador de fin de línea ($) coincide con la cadena vacía inmediatamente antes de un salto de línea, independientemente de si eflags contiene REG_NOTEOL.

Coincidencia

regexec() se utiliza para hacer coincidir una cadena terminada en nulo con el búfer de patrón compilado en *preg, el cual debe haber sido inicializado con regcomp(). eflags es el OR a nivel de bits de cero o más de las siguientes banderas:

REG_NOTBOL
El operador de principio de línea siempre falla al coincidir (pero ver la bandera de compilación REG_NEWLINE anterior). Esta bandera puede usarse cuando diferentes porciones de una cadena se pasan a regexec() y el principio de la cadena no debe interpretarse como el principio de la línea.
REG_NOTEOL
El operador de fin de línea siempre falla al coincidir (pero ver la bandera de compilación REG_NEWLINE anterior).
REG_STARTEND
Coincide [string + pmatch[0].rm_so, string + pmatch[0].rm_eo) en lugar de [string, string + strlen(string)). Esto permite hacer coincidir bytes NUL incrustados y evita una llamada a strlen(3) en cadenas de longitud conocida. Si se devuelven coincidencias (no se pasó REG_NOSUB a regcomp(), la coincidencia tuvo éxito y n > 0), estas sobrescriben pmatch como de costumbre, y los desplazamientos de la coincidencia permanecen relativos a string (no a string + pmatch[0].rm_so). Esta bandera es una extensión de BSD, no presente en POSIX.

Desplazamientos de coincidencia

A menos que se haya pasado REG_NOSUB a regcomp(), es posible obtener las ubicaciones de las coincidencias dentro de string: regexec() rellena n elementos de pmatch con resultados: pmatch[0] corresponde a la coincidencia completa, pmatch[1] al primer subexpresión, etc. Si hubo más coincidencias que n, estas se descartan; si fueron menos, los elementos no utilizados de pmatch se rellenan con -1.

Cada coincidencia válida devuelta (distinta de -1) corresponde al rango [string + rm_so, string + rm_eo).

regoff_t es un tipo de entero con signo capaz de almacenar el valor más grande que puede almacenarse en un tipo ptrdiff_t o un tipo ssize_t.

Notificación de errores

regerror() se utiliza para convertir los códigos de error que pueden ser devueltos tanto por regcomp() como por regexec() en cadenas de mensajes de error.

Si preg no es un puntero nulo, errcode debe ser el último error devuelto por una operación en preg.

Si errbuf_size no es 0, se copian hasta errbuf_size bytes a errbuf; la cadena de error siempre se termina con nulo y se trunca para que quepa.

Liberacion

regfree() desinicializa el búfer de patrones en *preg, liberando cualquier memoria asociada; *preg debe haber sido inicializado mediante regcomp().

VALOR DE RETORNO

regcomp() devuelve cero para una compilación exitosa o un código de error en caso de fallo.

regexec() devuelve cero para una coincidencia exitosa o REG_NOMATCH en caso de fallo.

regerror() devuelve el tamaño del búfer necesario para alojar la cadena.

ERRORES

Los siguientes errores pueden ser devueltos por regcomp():

REG_BADBR
Uso inválido del operador de retroreferencia.
REG_BADPAT
Uso inválido de operadores de patrones como grupos o listas.
REG_BADRPT
Uso inválido de operadores de repetición como usar '*' como primer carácter.
REG_EBRACE
Operadores de intervalo de llaves no emparejados.
REG_EBRACK
Operadores de lista de corchetes no emparejados.
REG_ECOLLATE
Elemento de ordenación inválido.
REG_ECTYPE
Nombre de clase de caracteres desconocido.
REG_EEND
Error no específico. Esto no está definido por POSIX.
REG_EESCAPE
Barra invertida final.
REG_EPAREN
Operadores de grupo de paréntesis no emparejados.
REG_ERANGE
Uso inválido del intervalo de caracteres dentro de una expresión.

El siguiente error puede ser devuelto por regexec():

REG_NOMATCH
La expresión regular no coincidió con la cadena.

Los siguientes errores pueden ser devueltos por ambas funciones:

REG_BADOPT
Una opción no reconocida fue pasada en cflags o eflags.
REG_ENOSYS
La funcionalidad de expresiones regulares no está implementada.
REG_ESPACE
No hay suficiente memoria disponible para procesar la expresión regular.

CONFORMIDAD

Las funciones regcomp, regexec, regerror y regfree cumplen con la norma POSIX.1-2017.

VEASE TAMBIÉN

grep(1), regcomp(3), regex(7)

regex(3) — Páginas del manual de Linux

NAME

regex - Expresiones regulares - POSIX.2, BRE, ERE

LIBRARY

libc, -lc

SYNOPSIS

#include <regex.h>
int regcomp(regex_t *regex, const char *restrict pattern, int cflags);
int regexec(const regex_t *restrict regex, const char *restrict string,
    size_t nmatch, regmatch_t pmatch[restrict static nmatch], int eflags);
void regfree(regex_t *regex);
size_t regerror(int errcode, const regex_t *restrict regex,
    char *restrict errbuf, size_t errbuf_size);

DESCRIPTION

Las funciones regcomp, regexec, regfree y regerror implementan la interfaz estándar POSIX para el manejo de expresiones regulares.

La función regcomp compila la expresión regular especificada por pattern en un formato que puede ser interpretado por regexec. La estructura devuelta en regex contiene la representación compilada de la expresión regular. El argumento cflags es un OR bit a bit de los siguientes indicadores:

REG_BASIC
Utiliza expresiones regulares básicas (BRE).
REG_NOSUB
No almacena la información de las subexpresiones coincidentes. Si se especifica este indicador, el argumento pmatch en regexec se ignora y el miembro re_nsub de la estructura regex_t no se inicializa.
REG_EXTENDED
Utiliza expresiones regulares extendidas (ERE).
REG_ICASE
Ignora las diferencias entre mayúsculas y minúsculas en la coincidencia.
REG_NEWLINE
El carácter de nueva línea (newline) coincide con el carácter especial de inicio y fin de la línea.
REG_NOSUB
No se debe informar de las subcoincidencias.

La función regexec ejecuta la expresión regular compilada en regex contra el string especificado. Si se encuentra una coincidencia, devuelve 0. Si no se encuentra ninguna coincidencia, devuelve REG_NOMATCH. El argumento eflags es un OR bit a bit de los siguientes indicadores:

REG_NOTBOL
El primer carácter de la cadena de entrada no debe considerarse como el inicio de una línea.
REG_NOTEOL
El carácter de nueva línea no debe considerarse como el fin de una línea.

El argumento pmatch apunta a una matriz de estructuras regmatch_t. Cada estructura regmatch_t almacena los índices de inicio y fin de una subexpresión coincidente. pmatch[0] corresponde a la coincidencia completa, mientras que pmatch[i] (para i > 0) corresponde a la i-ésima subexpresión capturada entre paréntesis en el patrón.

El argumento nmatch especifica el tamaño de la matriz pmatch. Debe ser al menos 1 si se desea obtener la coincidencia completa. Si nmatch es 0, pmatch se ignora, pero esto es una representación mal utilizada, en lugar de eso se debería utilizar REG_NOSUB.

La función regfree libera la memoria asignada por regcomp para la expresión regular compilada.

La función regerror devuelve una cadena de caracteres que describe un código de error específico devuelto por regcomp o regexec. El argumento errbuf es un puntero a un búfer donde se almacenará la cadena de error, y errbuf_size es el tamaño de dicho búfer. Si el búfer es demasiado pequeño, se truncará la cadena de error.

RETURN VALUE

Las funciones regcomp y regexec devuelven 0 en caso de éxito, o un código de error distinto de cero en caso de fallo.

La función regerror devuelve el número de caracteres escritos en el búfer de error, sin incluir el carácter nulo terminador.

ERRORS

Los siguientes códigos de error pueden ser devueltos por regcomp:

REG_EACCES
Permiso denegado al leer un archivo de cola de entrada.
REG_BADATFMT
El formato de archivo es incorrecto.
REG_BADPAT
La expresión regular es mal formada.
REG_BADRPT
Un operador de repetición (? o *) se utiliza incorrectamente (por ejemplo, al principio de la expresión o después de otro operador de repetición).
REG_BREC
Número de subexpresiones posteriores excesivo.
REG_CANTOPEN
No se pudo abrir el archivo de entrada.
REG_DOWN
La cola de entrada descendió.
REG_EEND
Fin de archivo inesperado.
REG_EESC
Secuencia de escape ilegal.
REG_EFLAGS
Indicadores de compilación ilegales.
REG_EMAGIC
Demasiados caracteres mágicos.
REG_ENOSYS
La función no está implementada.
REG_EPARSE
Error de análisis de la expresión regular.
REG_ERE
La expresión regular extendida es mal formada.
REG_ESIZE
El búfer del patrón compilado es demasiado grande (más de 64k).
REG_ETRAN
Error en la traducción.
REG_ESUBREG
Referencia posterior inválida a una subexpresión.
REG_INVARG
Argumento inválido.
REG_NOMATCH
No se encontró ninguna coincidencia.
REG_NOSUB
No se solicitaron subcoincidencias.
REG_POSIX
Se requiere compatibilidad con POSIX.1-2001.
REG_STARTEND
El punto final de un rango ocurre antes del punto inicial.

Los siguientes códigos de error pueden ser devueltos por regexec:

REG_NOMATCH
No se encontró ninguna coincidencia.
REG_ESPACE
Se agotó la memoria de las rutinas de regex.

Otros posibles códigos de error de regcomp incluyen:

REG_ESIZE
La expresión regular compilada requiere un búfer de patrón mayor que 64 kB. Esto no está definido por POSIX.
REG_ESPACE
Las rutinas de regex se quedaron sin memoria.
REG_ESUBREG
Referencia posterior inválida a una subexpresión.

STANDARDS

POSIX.1-2008.

HISTORY

POSIX.1-2001.

Antes de POSIX.1-2008, se requería que regoff_t fuera capaz de almacenar el valor más grande que se puede almacenar en un tipo off_t o en un tipo ssize_t.

CAVEATS

Solo se requiere que re_nsub se inicialice si no se especificó REG_NOSUB, pero todas las implementaciones conocidas lo inicializan independientemente.

Tanto regex_t como regmatch_t pueden tener (y tienen) más miembros, en cualquier orden. Siempre refiérase a ellos por nombre.

EXAMPLES

#include <stdint.h>
#include <stdio.h>
#include <stdlib.h>
#include <regex.h>
#define NITEMS(arr)  (sizeof((arr)) / sizeof((arr)[0]))
static const char *const str =
        "1) John Driverhacker;\n2) John Doe;\n3) John Foo;\n";
static const char *const re = "John.*o";
int main(void)
{
    static const char *s = str;
    regex_t     regex;
    regmatch_t  pmatch[1];
    regoff_t    off, len;
    if (regcomp(&regex, re, REG_NEWLINE))
        exit(EXIT_FAILURE);
    printf("String = \"%s\"\n", str);
    printf("Matches:\n");
    for (unsigned int i = 0; ; i++) {
        if (regexec(&regex, s, NITEMS(pmatch), pmatch, 0))
            break;
        off = pmatch[0].rm_so + (s - str);
        len = pmatch[0].rm_eo - pmatch[0].rm_so;
        printf("#%u:\n", i);
        printf("offset = %jd; length = %jd\n", (intmax_t) off,
                (intmax_t) len);
        printf("substring = \"%.*s\"\n", len, s + pmatch[0].rm_so);
        s += pmatch[0].rm_eo;
    }
    exit(EXIT_SUCCESS);
}
