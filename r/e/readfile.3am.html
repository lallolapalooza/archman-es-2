readfile(3am)

Paquete: gawk

Licencias: GPL-3.0-or-later

READFILE(3am) Módulos de extensión de GNU Awk READFILE(3am)

NOMBRE

readfile - devuelve el contenido completo de un archivo como una cadena

SINOPSIS

@load "readfile"

resultado = readfile("/alguna/ruta")

Para hacer que archivos completos sean registros únicos:

@load "readfile"
BEGIN { PROCINFO["readfile"] = 1 }

DESCRIPCIÓN

La extensión readfile añade una única función llamada readfile(). El argumento es el nombre del archivo a leer. El valor de retorno es una cadena que contiene el contenido completo del archivo solicitado.

En caso de error, la función devuelve una cadena vacía y establece ERRNO.

Además, añade un analizador de entrada que se activa si PROCINFO["readfile"] existe. Cuando se activa, cada archivo de entrada se devuelve en su totalidad como $0. RT se establece en la cadena nula.

EJEMPLO

@load "readfile"
...
contenido = readfile("/ruta/al/archivo");
if (contenido == "" && ERRNO != "") {
    print("problema al leer el archivo", ERRNO) > "/dev/stderr"
    ...
}
