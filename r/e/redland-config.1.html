NOMBRE

redland-config - script para obtener información sobre la versión instalada de Redland

SINOPSIS

redland-config [--cflags] [--help] [--libs] [--libtool-libs] [--prefix[=DIR]] [--private-libs] [--version-decimal] [--version]

DESCRIPCIÓN

redland-config es una herramienta que se utiliza para determinar las banderas de compilación y enlazado que deben utilizarse para compilar y enlazar programas que utilizan la biblioteca RDF de Redland.

OPCIONES

redland-config acepta las siguientes opciones:

--version
Imprime la versión actualmente instalada de redland en la salida estándar.
--version-decimal
Imprime la versión actualmente instalada de redland como un entero decimal.
--libs
Imprime las banderas del enlazador que son necesarias para enlazar un programa de redland. Esto excluye los argumentos del enlazador utilizados para construir la biblioteca compartida librdf.
--libtool-libs
Imprime las banderas que son necesarias para enlazar un programa de redland con libtool.
--private-libs
Imprime las banderas del enlazador que son necesarias para construir la biblioteca compartida librdf. Esta opción generalmente no es necesaria porque la biblioteca compartida librdf ya ha sido enlazada dinámicamente contra estas bibliotecas.
--cflags
Imprime las banderas del compilador que son necesarias para compilar un programa de redland.
--prefix=PREFIX
Si se especifica, utiliza PREFIX en lugar del prefijo de instalación con el que se construyó redland al calcular la salida para las opciones --cflags y --libs. Esta opción debe especificarse antes de cualquier opción --libs o --cflags.
