NOMBRE

repomdxml2solv - convierte un archivo repomd.xml en un archivo solv

SINOPSIS

repomdxml2solv [OPCIONES]

DESCRIPCIÓN

El archivo repomd.xml es el archivo índice de un repositorio rpm-md, que contiene referencias a todos los archivos de datos con sus sumas de verificación. La herramienta repomdxml2solv lee el archivo repomd.xml de la entrada estándar y escribe los datos analizados como un archivo solv en la salida estándar. Los datos se almacenan como metadatos en el resultado.

-q QUÉ

Modo de consulta de datos: en lugar de escribir un archivo solv, selecciona el elemento QUÉ en los datos de entrada y escríbelo en la salida estándar. Ejemplos de QUÉ son type para obtener una lista de todos los tipos, y primary:location para obtener la ubicación del elemento con el tipo primary.

VéASE TAMBIÉN

rpmmd2solv(1), mergesolv(1), createrepo(8)
