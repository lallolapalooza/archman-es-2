recursive_key_scan(3)

Paquete: keyutils

Licencias: GPL2, LGPL2.1

RECURSIVE_KEY_SCAN(3) Llamadas de la utilidad de claves de Linux RECURSIVE_KEY_SCAN(3)

NOMBRE

recursive_key_scan, recursive_session_key_scan - aplicar una función a todas las claves en un árbol de clave de acceso

SINOPSIS

#include <keyutils.h>

typedef int (*recursive_key_scanner_t)(key_serial_t parent,
    key_serial_t key, char *desc, int desc_len, void *data);

long recursive_key_scan(key_serial_t keyring,
    recursive_key_scanner_t func, void *data);
long recursive_session_key_scan(recursive_key_scanner_t func,
    void *data);

DESCRIPCIÓN

recursive_key_scan() realiza un escaneo recursivo de profundidad en el árbol de keyring especificado y aplica func a cada enlace encontrado en las claves de acceso accesibles en ese árbol. data se pasa a cada invocación de func.

Los valores de retorno de func se suman y se devuelven como el valor de retorno general. Los errores se ignoran. Las claves de acceso inaccesibles no se escanean, pero los enlaces a ellas todavía se pasan a func.

recursive_session_key_scan() funciona exactamente como recursive_key_scan() con la clave de acceso de sesión del llamador especificada como la clave de inicio.

La función de devolución de llamada se llama para cada enlace encontrado en todas las claves de acceso en el árbol nominado y, por lo tanto, puede ser llamada múltiples veces para una clave particular si esa clave tiene múltiples enlaces a ella.

A la función de devolución de llamada se le pasan los siguientes parámetros:

parent
La clave de acceso que contiene el enlace o 0 para la clave inicial.
key
La clave a la que apunta el enlace.
desc y desc_len
Un puntero a la descripción sin procesar y su longitud tal como se obtuvieron con keyctl_describe_alloc(). Estos serán NULL y -1 respectivamente si la descripción no se pudo recuperar y errno conservará el error de keyctl_describe_alloc().
data
Los datos pasados a la función de escaneo.

VALOR DE RETORNO

Estas funciones devuelven la suma de los resultados de las funciones de devolución de llamada que invocan.

ERRORES

Ignorados.

ENLAZANDO

Al enlazar, se debe especificar -lkeyutils al enlazador.

VER TAMBIÉN

keyctl(3), keyctl_describe_alloc(3), keyrings(7)
