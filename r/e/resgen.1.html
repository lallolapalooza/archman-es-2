Paquete: mono

Licencias: GPL, LGPL2.1, MPL

Mono(resgen) Mono(resgen)

NOMBRE

resgen, resgen2 - Generador de Recursos de Mono/CLI

SINOPSIS

resgen archivo_fuente.ext [archivo_destino.ext]

resgen /compile archivo_fuente.ext[,recursos_destino.ext] [...]

resgen2

DESCRIPCIÓN

Convierte un archivo de recursos de un formato a otro.

Los formatos actualmente soportados son texto, recursos, resx y po.

.txt, .text

Se utiliza para procesar archivos de texto, el formato del archivo de texto es el siguiente:

clave=valor
El argumento valor puede contener caracteres especiales siempre que estén escapados. Las secuencias de escape soportadas actualmente son \n, \r, \t, \\ (para obtener la propia secuencia de escape) y con resgen2 se soportan secuencias de escape unicode con la secuencia de escape \uXXXX, donde XXXX es un número de cuatro dígitos.

Las líneas que comienzan con el carácter # o ; se consideran comentarios y se ignoran.

'.resources'

Este es el formato de archivo binario implementado por la clase System.Resources.ResourceReader, parte de mscorlib.dll

'.resx'

Este es el formato de archivo binario implementado por la clase System.Resources.ResXResourceReader. Esta clase no forma parte de mscorlib.dll, sino de System.Windows.Forms.

'.po'.

Los archivos PO son los archivos fuente utilizados por la infraestructura gettext de Unix que se utiliza típicamente para internacionalizar aplicaciones.

Las líneas que comienzan con el carácter '#' son líneas de comentario.

El archivo contiene muchas instancias de cadenas como esta:

     msgid CLAVE
     msgstr VALOR
La CLAVE es típicamente la cadena a traducir y el VALOR es la traducción. En los archivos PO, en lugar de usar códigos como CLAVE (como es habitual con los archivos de recursos), la CLAVE es típicamente un mensaje completo en inglés que las aplicaciones incrustan en su código fuente y se utilizará como último recurso si no se utilizan recursos de traducción.

Dado que los recursos son pares clave-valor, no se soportan las características extendidas de los archivos PO (plurales y soporte para N-casos).

Para obtener más información sobre el formato de archivo PO, use su navegador de información y apúntelo al nodo "(gettext)PO Files".

Si no se especifica el archivo de destino, se utilizará source.resources.

La opción /compile toma una lista de archivos .resX o .txt para convertir al nombre del archivo de salida.

OPCIONES

-compile

Este modificador indica a resgen que compile múltiples archivos. Debe aparecer antes de que se especifiquen los recursos en la línea de comandos.

-usesourcepath

Esta opción solo está disponible para resgen2 e indica a resgen que resuelva las rutas relativas utilizando el directorio del archivo resx como directorio actual.

ARCHIVOS

Este programa cargará los ensamblados referenciados desde la caché de ensamblados de Mono.
