READER.CONF(5) PC/SC Lite READER.CONF(5)

NOMBRE

reader.conf - archivo de configuración para los drivers de lectores de pcscd

DESCRIPCIÓN

Los archivos /etc/reader.conf.d/* contienen información de configuración para lectores de tarjetas inteligentes seriales y (algunos) PCMCIA.

Los lectores USB NO DEBEN configurarse usando estos archivos. pcscd utiliza otro mecanismo para cargar automáticamente los drivers USB.

SINTAXIS

Los archivos /etc/reader.conf.d/* son archivos de texto normales. Cada lector debe definirse mediante cuatro campos:


FRIENDLYNAME CADENA_TEXTO
DEVICENAME NOMBRE_ARCHIVO
LIBPATH NOMBRE_ARCHIVO
CHANNELID NÚMERO

El campo "FRIENDLYNAME" es un texto arbitrario utilizado para identificar el lector. Este texto es mostrado por comandos como pcsc_scan(1), que imprime los nombres de todos los lectores conectados y detectados.

El campo "DEVICENAME" no se utilizaba para drivers antiguos (que usan la versión 2.0 o anterior del manejador IFD). Ahora (versión 3.0 del manejador IFD) se utiliza para identificar el puerto físico en el que está conectado el lector. Este es el nombre del dispositivo de este puerto. Depende del kernel del sistema operativo. El primer dispositivo de puerto serial se llama /dev/ttyS0 en Linux y /dev/cuaa0 en FreeBSD.

El campo "LIBPATH" es el nombre del archivo del código del driver. El driver es un fragmento de código cargado dinámicamente (generalmente un archivo nombre_driver.so.*).

El "CHANNELID" ya no se utiliza para drivers recientes (manejador IFD 3.0) y ha sido reemplazado por "DEVICENAME". Si tienes un driver antiguo, este campo se utiliza para indicar el puerto a usar. Debes leer la documentación de tu driver para saber qué información se necesita aquí. Debería ser el número de puerto serial para un lector serial.

EJEMPLO


# Lector Gemplus GemPCTwin con comunicación serial
# conectado al primer puerto serial
FRIENDLYNAME "GemPCTwin serial"
DEVICENAME /dev/ttyS0
LIBPATH /usr/lib/pcsc/drivers/serial/libccidtwin.so.0.4.1
CHANNELID 1

DEPURACIÓN

Para configurar correctamente tu archivo /etc/reader.conf.d/my_reader.conf, es posible que desees tener mensajes de depuración de pcscd. Recomiendo iniciar pscsd en primer plano y en modo de depuración usando:

# pcscd --foreground --debug

Si todo parece correcto, puedes usar el comando pcsc_scan para imprimir la lista de lectores detectados correctamente y tratar de obtener el ATR de tus tarjetas inteligentes.
