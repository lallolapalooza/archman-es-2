NOMBRE

restic-repair-packs - Recuperar archivos de pack dañados

SINOPSIS

restic repair packs [IDs_de_pack...] [flags]

DESCRIPCIÓN

El comando "repair packs" extrae blobs intactos de los archivos de pack especificados, reconstruye el índice para eliminar los archivos de pack dañados y los elimina del repositorio.

ESTADO DE SALIDA

El estado de salida es 0 si el comando se ejecutó correctamente. El estado de salida es 1 si hubo algún error. El estado de salida es 10 si el repositorio no existe. El estado de salida es 11 si el repositorio ya está bloqueado. El estado de salida es 12 si la contraseña es incorrecta.

OPCIONES

-h, --help[=false] Ayuda para packs

OPCIONES HEREDADAS DE COMANDOS PADRE

--cacert=[] Archivo para cargar certificados raíz desde (por defecto: usar certificados del sistema o $RESTIC_CACERT)

--cache-dir="" establece el directorio de caché. (por defecto: usar el directorio de caché predeterminado del sistema)

--cleanup-cache[=false] eliminar automáticamente directorios de caché antiguos

--compression=auto modo de compresión (solo disponible para la versión 2 del formato de repositorio), uno de (auto|off|max) (por defecto: $RESTIC_COMPRESSION)

--http-user-agent="" establece un agente de usuario http para las solicitudes http salientes

--insecure-no-password[=false] usa una contraseña vacía para el repositorio, debe pasarse a cada comando de restic (inseguro)

--insecure-tls[=false] omite la verificación del certificado TLS al conectarse al repositorio (inseguro)

--json[=false] establece el modo de salida a JSON para los comandos que lo admiten

--key-hint="" ID de clave de la clave para intentar descifrar primero (por defecto: $RESTIC_KEY_HINT)

--limit-download=0 limita las descargas a una tasa máxima en KiB/s. (por defecto: sin límites)

--limit-upload=0 limita las cargas a una tasa máxima en KiB/s. (por defecto: sin límites)

--no-cache[=false] no usar caché local

--no-extra-verify[=false] omitir verificación adicional de datos antes de la carga (ver documentación)

--no-lock[=false] no bloquear el repositorio, esto permite algunas operaciones en repositorios de solo lectura

-o, --option=[] establecer opción extendida (clave=valor, se puede especificar varias veces)

--pack-size=0 establece el tamaño del pack objetivo en MiB, los archivos de pack creados pueden ser más grandes (por defecto: $RESTIC_PACK_SIZE)

--password-command="" comando de shell para obtener la contraseña del repositorio desde (por defecto: $RESTIC_PASSWORD_COMMAND)

-p, --password-file="" archivo para leer la contraseña del repositorio desde (por defecto: $RESTIC_PASSWORD_FILE)

-q, --quiet[=false] no mostrar informe de progreso exhaustivo

-r, --repo="" repositorio para hacer copia de seguridad o restaurar desde (por defecto: $RESTIC_REPOSITORY)

--repository-file="" archivo para leer la ubicación del repositorio desde (por defecto: $RESTIC_REPOSITORY_FILE)

--retry-lock=0s volver a intentar bloquear el repositorio si ya está bloqueado, toma un valor como 5m o 2h (por defecto: sin reintentos)

--stuck-request-timeout=5m0s duración después de la cual se reintentarán las solicitudes bloqueadas

--tls-client-cert="" ruta a un archivo que contiene el certificado de cliente TLS codificado en PEM y la clave privada (por defecto: $RESTIC_TLS_CLIENT_CERT)

-v, --verbose[=0] ser verboso (especificar varias veces o un nivel usando --verbose=n, nivel/veces máximo es 2)
