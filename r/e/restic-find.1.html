NOMBRE

restic-find - Buscar un archivo, un directorio o IDs de restic

SINOPSIS

restic find [flags] PATRON...

DESCRIPCIÓN

El comando "find" busca archivos o directorios en los snapshots almacenados en el repositorio. También puede usarse para buscar blobs o árboles de restic para la resolución de problemas. La opción de ordenación por defecto para los snapshots es del más reciente al más antiguo. Para ordenar la salida del más antiguo al más reciente, especifique --reverse.

OPCIONES

--blob[=false] el patrón es un ID de blob

-h, --help[=false] ayuda para find

-H, --host=[] considerar solo snapshots para este host (se puede especificar varias veces) (por defecto: $RESTIC_HOST)

--human-readable[=false] mostrar tamaños en formato legible para humanos

-i, --ignore-case[=false] ignorar mayúsculas/minúsculas para el patrón

-l, --long[=false] usar un formato de listado largo que muestre tamaño y modo

-N, --newest="" fecha/hora de modificación más reciente

-O, --oldest="" fecha/hora de modificación más antigua

--pack[=false] el patrón es un ID de paquete

--path=[] considerar solo snapshots que incluyan esta ruta (absoluta) ruta (se puede especificar varias veces, los snapshots deben incluir todas las rutas especificadas)

-R, --reverse[=false] ordenar en orden inverso, del más antiguo al más nuevo

--show-pack-id[=false] mostrar el ID de paquete al que pertenecen los blobs (con --blob o --tree)

-s, --snapshot=[] ID del snapshot en el que buscar (se puede especificar varias veces)

--tag=[] considerar solo snapshots que incluyan tag[,tag,...] (se puede especificar varias veces)

--tree[=false] el patrón es un ID de árbol

OPCIONES HEREDADAS DE COMANDOS PADRE

--cacert=[] archivo desde el que cargar certificados raíz (por defecto: usar certificados del sistema o $RESTIC_CACERT)

--cache-dir="" establecer el directorio de caché. (por defecto: usar el directorio de caché predeterminado del sistema)

--cleanup-cache[=false] eliminar automáticamente directorios de caché antiguos

--compression=auto modo de compresión (solo disponible para la versión 2 del formato de repositorio), uno de (auto|off|max) (por defecto: $RESTIC_COMPRESSION)

--http-user-agent="" establecer un agente de usuario http para las solicitudes http salientes

--insecure-no-password[=false] usar una contraseña vacía para el repositorio, debe pasarse a cada comando de restic (inseguro)

--insecure-tls[=false] omitir la verificación del certificado TLS al conectarse al repositorio (inseguro)

--json[=false] establecer el modo de salida a JSON para los comandos que lo soporten

--key-hint="" ID de la clave que se intentará descifrar primero (por defecto: $RESTIC_KEY_HINT)

--limit-download=0 limita las descargas a una tasa máxima en KiB/s. (por defecto: ilimitado)

--limit-upload=0 limita las cargas a una tasa máxima en KiB/s. (por defecto: ilimitado)

--no-cache[=false] no usar caché local

--no-extra-verify[=false] omitir la verificación adicional de datos antes de la carga (ver documentación)

--no-lock[=false] no bloquear el repositorio, esto permite algunas operaciones en repositorios de solo lectura

-o, --option=[] establecer opción extendida (clave=valor, se puede especificar varias veces)

--pack-size=0 establecer el tamaño del paquete de destino en MiB, los archivos de paquete creados pueden ser más grandes (por defecto: $RESTIC_PACK_SIZE)

--password-command="" comando de shell para obtener la contraseña del repositorio (por defecto: $RESTIC_PASSWORD_COMMAND)

-p, --password-file="" archivo desde el que leer la contraseña del repositorio (por defecto: $RESTIC_PASSWORD_FILE)

-q, --quiet[=false] no mostrar informe de progreso detallado

-r, --repo="" repositorio en el que guardar la copia de seguridad o del que restaurar (por defecto: $RESTIC_REPOSITORY)

--repository-file="" archivo desde el que leer la ubicación del repositorio (por defecto: $RESTIC_REPOSITORY_FILE)

--retry-lock=0s reintentar el bloqueo del repositorio si ya está bloqueado, toma un valor como 5m o 2h (por defecto: sin reintentos)

--stuck-request-timeout=5m0s duración después de la cual se reintentarán las solicitudes atascadas

--tls-client-cert="" ruta a un archivo que contenga el certificado de cliente TLS y la clave privada codificados en PEM (por defecto: $RESTIC_TLS_CLIENT_CERT)

-v, --verbose[=0] ser detallado (especificar varias veces o un nivel usando --verbose=n, nivel/veces máximo es 2)

EJEMPLO

restic find config.json
restic find --json "*.yml" "*.json"
restic find --json --blob 420f620f b46ebe8a ddd38656
restic find --show-pack-id --blob 420f620f
restic find --tree 577c2bc9 f81f2e22 a62827a9
restic find --pack 025c1d06
ESTADO DE SALIDA
==============
El estado de salida es 0 si el comando se ejecutó correctamente.
El estado de salida es 1 si hubo algún error.
El estado de salida es 10 si el repositorio no existe.
El estado de salida es 11 si el repositorio ya está bloqueado.
El estado de salida es 12 si la contraseña es incorrecta.
