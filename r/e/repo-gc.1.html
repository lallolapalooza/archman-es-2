REPO(1) Manual de Repo REPO(1)

NOMBRE

repo - repo gc - página del manual para repo gc

SINOPSIS

repo gc

DESCRIPCIÓN

Resumen

Limpieza del estado interno de repo y Git.

OPCIONES

-h, --help
mostrar esta ayuda y salir
-n, --dry-run
hacer todo excepto eliminar realmente
-y, --yes
responder sí a todas las indicaciones seguras
--repack
reempaquetar todos los proyectos que usan clonación parcial con filter=blob:none

Opciones de registro:

-v, --verbose
mostrar toda la salida
-q, --quiet
mostrar solo errores

Opciones de múltiples manifiestos:

--outer-manifest
operar comenzando desde el manifiesto más externo
--no-outer-manifest
no operar en manifiestos externos
--this-manifest-only
operar solo en este manifiesto (sub)
--no-this-manifest-only, --all-manifests
operar en este manifiesto y sus submanifiestos

Ejecuta `repo help gc` para ver el manual detallado.
