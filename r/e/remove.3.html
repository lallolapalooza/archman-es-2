remove(3) Manual de funciones de biblioteca remove(3)

NOMBRE

remove - eliminar un archivo o directorio

BIBLIOTECA

Biblioteca C estándar (libc, -lc)

SINOPSIS

#include <stdio.h>
int remove(const char *path);

DESCRIPCIÓN

remove() elimina un nombre del sistema de archivos. Llama a unlink(2) para archivos, y a rmdir(2) para directorios.

Si el nombre eliminado era el último enlace a un archivo y ningún proceso tiene el archivo abierto, el archivo se elimina y el espacio que utilizaba queda disponible para su reutilización.

Si el nombre era el último enlace a un archivo, pero todavía hay procesos que tienen el archivo abierto, el archivo permanecerá existente hasta que se cierre el último descriptor de archivo que lo referencia.

Si el nombre hacía referencia a un enlace simbólico, se elimina el enlace.

Si el nombre hacía referencia a un socket, FIFO o dispositivo, se elimina el nombre, pero los procesos que tengan el objeto abierto pueden continuar utilizándolo.

VALOR DE RETORNO

En caso de éxito, se devuelve cero. En caso de error, se devuelve -1 y se establece la variable errno para indicar el error.

ERRORES

Los errores que ocurren son los de unlink(2) y rmdir(2).

ATRIBUTOS

Para una explicación de los términos utilizados en esta sección, consulte attributes(7).

Interfaz Atributo Valor
remove () Seguridad de hilos MT-Safe

ESTÁNDARES

C11, POSIX.1-2008.

HISTORIA

POSIX.1-2001, C89, 4.3BSD.

ERRORES CONOCIDOS

Las deficiencias en el protocolo subyacente de NFS pueden causar la desaparición inesperada de archivos que todavía se están utilizando.

VER TAMBIÉN

rm(1), unlink(1), link(2), mknod(2), open(2), rename(2), rmdir(2), unlink(2), mkfifo(3), symlink(7)
