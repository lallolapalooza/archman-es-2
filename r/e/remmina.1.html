REMMINA(1) Manual de comandos generales REMMINA(1)

NOMBRE

remmina -- Cliente de escritorio remoto Remmina GTK+

SINOPSIS

remmina [-a|i|n|q|v] [-c ARCHIVO] [-e ARCHIVO] [-p ÍNDICE_PESTAÑA] [-s SERVIDOR] [-t PROTOCOLO] [-x PLUGIN] [--actualizar-perfil] [--establecer-opción OPCIÓN[=VALOR]] [--pantalla PANTALLA]

DESCRIPCIÓN

Remmina es un cliente de escritorio remoto escrito en GTK+, cuyo objetivo es ser útil para administradores de sistemas y viajeros, que necesitan trabajar con muchos ordenadores remotos frente a monitores grandes o netbooks diminutos. Remmina soporta múltiples protocolos de red en una interfaz de usuario integrada y consistente.

Actualmente se soportan RDP, VNC, SSH, SPICE y WWW.

Remmina se distribuye en paquetes fuente separados:

  • "remmina", la aplicación GTK+ principal
  • "remmina-plugins", un conjunto de plugins

Remmina es software libre y de código abierto, publicado bajo la licencia GNU GPL.

ARCHIVOS

${XDG_CONFIG_DIRS}/remmina.pref o ${XDG_CONFIG_HOME}/remmina/remmina.pref :

Archivos de configuración de Remmina.

En la primera ejecución de Remmina, los archivos de configuración de Remmina a nivel de sistema se copiarán a ${XDG_CONFIG_HOME}

${XDG_DATA_DIRS}/ARCHIVO.remmina o ${XDG_DATA_HOME}/remmina/ARCHIVO.remmina :

Perfiles de Remmina, el nombre del archivo se genera automáticamente, pero puedes crear tus propios archivos manualmente con el nombre de archivo que prefieras. Es posible especificar un nombre de perfil y una ubicación personalizados.

OPCIONES

-h, --help

Muestra las opciones de ayuda

-a

Muestra el diálogo "Acerca de"

-c, --connect=ARCHIVO

Conéctate directamente a un escritorio usando las opciones descritas en un archivo, o una URI soportada (RDP, VNC, SSH o SPICE).
El tipo de archivo puede ser ".remmina" o uno soportado por un plugin capaz de importar archivos.

-e, --edit=ARCHIVO

Abre y edita la conexión de escritorio usando las opciones descritas por el archivo; el tipo de archivo puede ser .remmina o uno soportado por un plugin capaz de importar archivos.

-k, --kiosk

Inicia Remmina en modo quiosco (thin client)

-n, --new

Crea un nuevo perfil de conexión

-p, --pref=ÍNDICE_PESTAÑA

Muestra la página del diálogo de preferencias

-x, --plugin=PLUGIN

Ejecuta el plugin

-q, --quit

Sale de la aplicación

-s, --server=SERVIDOR

Usa el nombre de servidor por defecto (para --new)

-t, --protocol=PROTOCOLO

Usa el protocolo por defecto (para --new)

-i, --icon

Inicia como icono de bandeja

-v, --version

Muestra la versión de la aplicación

--update-profile

Modifica el perfil de conexión, requiere también --set-option

--set-option OPCIÓN[=VALOR]

Establece una o más configuraciones del perfil, para ser usadas con --update-pro-file

--encrypt-password

Cifra una contraseña

--display=PANTALLA

Pantalla X a utilizar

--disable-toolbar

Deshabilita la barra de herramientas

--enable-fullscreen

Habilita pantalla completa

--enable-extra-hardening

Habilita endurecimiento adicional (deshabilita confirmación de cierre, deshabilita teclas de acceso directo inseguras, oculta pestañas, oculta barra de búsqueda)
Lista de teclas de acceso directo deshabilitadas:
pantalla completa, ajuste automático, pestaña anterior y siguiente, escalar, capturar, minimizar, solo ver, captura de pantalla, desconectar, barra de herramientas

--no-tray-icon

Deshabilita el icono de bandeja

EJEMPLOS

Para conectarte usando un perfil de conexión existente, usa: remmina -c ARCHIVO.remmina

Para conectarte rápidamente usando una URI:

remmina -c rdp://usuario@servidor
remmina -c rdp://dominio\\usuario@servidor
remmina -c vnc://usuario@servidor
remmina -c vnc://servidor?VncUsername=usuario
remmina -c ssh://usuario@servidor
remmina -c spice://servidor

Para conectarte rápidamente usando una URI junto con una contraseña cifrada:

remmina -c rdp://usuario:contraseña-cifrada@servidor
remmina -c vnc://usuario:contraseña-cifrada@servidor
remmina -c vnc://servidor?VncUsername=usuario\&VncPassword=contraseña-cifrada

Para cifrar una contraseña para usarla con una URI:

remmina --encrypt-password

Para actualizar el nombre de usuario y la contraseña y establecer un modo de resolución diferente de un perfil de conexión de remmina, usa:

echo "usuario:contraseña" | remmina --update-profile /RUTA/A/FOO.remmina --set-option username --set-option resolution_mode=2 --set-option password
