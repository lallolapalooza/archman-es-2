NOMBRE

restic-repair-index - Construir un nuevo índice

SINOPSIS

restic repair index [flags]

DESCRIPCIÓN

El comando "repair index" crea un nuevo índice basado en los archivos pack del repositorio.

ESTADO DE SALIDA

El estado de salida es 0 si el comando fue exitoso. El estado de salida es 1 si hubo algún error. El estado de salida es 10 si el repositorio no existe. El estado de salida es 11 si el repositorio ya está bloqueado. El estado de salida es 12 si la contraseña es incorrecta.

OPCIONES

-h, --help[=false] ayuda para index

--read-all-packs[=false] lee todos los archivos pack para generar un nuevo índice desde cero

OPCIONES HEREDADAS DE COMANDOS PADRE

--cacert=[] archivo desde el cual cargar los certificados raíz (predeterminado: usar certificados del sistema o $RESTIC_CACERT)

--cache-dir="" establece el directorio de caché. (predeterminado: usar el directorio de caché predeterminado del sistema)

--cleanup-cache[=false] elimina automáticamente los directorios de caché antiguos

--compression=auto modo de compresión (solo disponible para el formato de repositorio versión 2), uno de (auto|off|max) (predeterminado: $RESTIC_COMPRESSION)

--http-user-agent="" establece un agente de usuario http para las solicitudes http salientes

--insecure-no-password[=false] usa una contraseña vacía para el repositorio, debe pasarse a cada comando restic (inseguro)

--insecure-tls[=false] omite la verificación del certificado TLS al conectarse al repositorio (inseguro)

--json[=false] establece el modo de salida a JSON para los comandos que lo admitan

--key-hint="" ID de clave de la clave a intentar descifrar primero (predeterminado: $RESTIC_KEY_HINT)

--limit-download=0 limita las descargas a una velocidad máxima en KiB/s. (predeterminado: ilimitado)

--limit-upload=0 limita las cargas a una velocidad máxima en KiB/s. (predeterminado: ilimitado)

--no-cache[=false] no usar caché local

--no-extra-verify[=false] omite la verificación adicional de datos antes de la carga (ver documentación)

--no-lock[=false] no bloquear el repositorio, esto permite algunas operaciones en repositorios de solo lectura

-o, --option=[] establecer opción extendida (clave=valor, se puede especificar varias veces)

--pack-size=0 establecer el tamaño del pack de destino en MiB, los archivos pack creados pueden ser más grandes (predeterminado: $RESTIC_PACK_SIZE)

--password-command="" comando de shell para obtener la contraseña del repositorio desde (predeterminado: $RESTIC_PASSWORD_COMMAND)

-p, --password-file="" archivo para leer la contraseña del repositorio desde (predeterminado: $RESTIC_PASSWORD_FILE)

-q, --quiet[=false] no mostrar un informe de progreso exhaustivo

-r, --repo="" repositorio al que realizar copia de seguridad o del cual restaurar (predeterminado: $RESTIC_REPOSITORY)

--repository-file="" archivo desde el cual leer la ubicación del repositorio (predeterminado: $RESTIC_REPOSITORY_FILE)

--retry-lock=0s reintentar bloquear el repositorio si ya está bloqueado, toma un valor como 5m o 2h (predeterminado: sin reintentos)

--stuck-request-timeout=5m0s duración después de la cual se reintentarán las solicitudes atascadas

--tls-client-cert="" ruta a un archivo que contiene el certificado de cliente TLS codificado en PEM y la clave privada (predeterminado: $RESTIC_TLS_CLIENT_CERT)

-v, --verbose[=0] ser detallado (especificar varias veces o un nivel usando --verbose=n, nivel/veces máximo es 2)
