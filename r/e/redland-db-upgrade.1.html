redland-db-upgrade(1) Manual de comandos generales redland-db-upgrade(1)

NOMBRE

redland-db-upgrade - actualiza bases de datos antiguas de Redland al formato 0.9.12

SINOPSIS

redland-db-upgrade NombreBD Antiguo NombreBD Nuevo

DESCRIPCIÓN

redland-db-upgrade convierte bases de datos de Redland del formato de 0.9.11 y anteriores al nuevo formato. Debe ejecutarse en cada base de datos de Redland. Por ejemplo, si la base de datos a creó los archivos a-sp2o.db, a-so2p.db y a-po2s.db, podría convertirse a una nueva base de datos b con:

redland-db-upgrade a b
