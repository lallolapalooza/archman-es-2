DESCRIPCIÓN

Estas funciones sirven para extender y/o modificar el comportamiento de las funciones de la familia printf(3).

register_printf_specifier()

Esta función registra un especificador de conversión personalizado para las funciones de la familia printf(3).

spec
El carácter que se utilizará como especificador de conversión en la cadena de formato.
func
Función de callback que será ejecutada por las funciones de la familia printf(3) para formatear los argumentos de entrada en el flujo de salida (stream).
stream
Flujo de salida donde se debe imprimir la salida formateada. Este flujo representa transparentemente la salida, incluso en el caso de funciones que escriben en una cadena.
info
Estructura que contiene información de contexto, incluyendo los modificadores especificados en la cadena de formato. Contiene el mismo contenido que en arginfo.
args
Arreglo de punteros a los argumentos de la función tipo printf(3).
arginfo
Función de callback que será ejecutada por las funciones de la familia printf(3) para saber cuántos argumentos deben ser analizados para el especificador personalizado y también sus tipos.
info
Estructura que contiene información de contexto, incluyendo los modificadores especificados en la cadena de formato. Contiene el mismo contenido que en func.
n
Número de argumentos restantes por analizar.
argtypes
Este arreglo debe configurarse para definir el tipo de cada uno de los argumentos que se analizarán. Cada elemento del arreglo representa uno de los argumentos a analizar, en el mismo orden en que se pasan a la función tipo printf(3). Cada elemento debe configurarse a un tipo base (PA_*) de la enumeración anterior, o uno personalizado, y opcionalmente combinarse con OR bit a bit con un modificador de longitud apropiado (PA_FLAG_*).

El tipo se determina utilizando una de las siguientes constantes:

PA_INT
int.
PA_CHAR
int, casteado a char.
PA_WCHAR
wchar_t.
PA_STRING
const char *, una cadena terminada en '\0'.
PA_WSTRING
const wchar_t *, una cadena de caracteres anchos terminada en L'\0'.
PA_POINTER
void *.
PA_FLOAT
float.
PA_DOUBLE
double.
PA_LAST
PENDIENTE.
size
Para tipos definidos por el usuario, el tamaño del tipo (en bytes) también debe especificarse a través de este arreglo. De lo contrario, déjelo sin usar.

arginfo se llama antes que func, y prepara alguna información necesaria para llamar a func.

VALOR DE RETORNO

register_printf_specifier(), register_printf_modifier(), y register_printf_type() devuelven cero si tienen éxito, o -1 en caso de error.

Callbacks

El callback de tipo printf_function debe devolver el número de caracteres escritos, o -1 en caso de error.

El callback de tipo printf_arginfo_size_function debe devolver el número de argumentos a analizar por este especificador. También pasa información sobre el tipo de esos argumentos al llamador a través de argtypes. En caso de error, debe devolver -1.

ERRORES

EINVAL
El especificador no era un carácter válido.

ESTANDARES

GNU.

HISTORIA

register_printf_function(3) es una función más antigua similar a register_printf_specifier(), y ahora está obsoleta. Esa función no puede manejar tipos definidos por el usuario.

register_printf_specifier() reemplaza a register_printf_function(3).

EJEMPLOS

El siguiente programa de ejemplo registra los especificadores 'b' y 'B' para imprimir enteros en formato binario, reflejando las reglas para otros especificadores de conversión sin signo como 'x' y 'u'. Esto se puede usar para imprimir en binario antes de C23.

#include <stdio.h>
#include <stdlib.h>
#include <string.h>
#include <sys/param.h>
#include <printf.h>
#define GROUP_SEP  '\''
struct Printf_Pad {
    char    ch;
    size_t  len;
};

                    ptrdiff_t bin_len);

static int
b_printf(FILE *stream, const struct printf_info *info,
         const void *const args[])
{
    char               bin[UINTMAX_WIDTH];
    size_t             min_len, bin_len;
    ssize_t            len, tmp;
    struct Printf_Pad  pad = {0};
    len = 0;
    min_len = b_bin_repr(bin, info, args[0]);
    bin_len = b_bin_len(info, min_len);
    pad.ch = pad_ch(info);
    if (pad.ch == ' ')
        pad.len = b_pad_len(info, bin_len);
    /* Relleno con ' ' (alineado a la derecha) */
    if ((pad.ch == ' ') && !info->left) {
        tmp = pad_spaces(stream, pad.len);
        if (tmp == EOF)
            return EOF;
        len += tmp;
    }
    /* Prefijo "0b"/"0B" */
    if (info->alt) {
        tmp = b_print_prefix(stream, info);
        if (tmp == EOF)
            return EOF;
        len += tmp;
    }
    /* Relleno con '0' */
    if (pad.ch == '0') {
        tmp = b_pad_zeros(stream, info, min_len);
        if (tmp == EOF)
            return EOF;
        len += tmp;
    }
    /* Imprimir número (incluyendo ceros iniciales para completar la precisión) */
    tmp = b_print_number(stream, info, bin, min_len, bin_len);
    if (tmp == EOF)
        return EOF;
    len += tmp;
    /* Relleno con ' ' (alineado a la izquierda) */
    if (info->left) {
        tmp = pad_spaces(stream, pad.len);
        if (tmp == EOF)
            return EOF;
        len += tmp;
    }
    return len;
}
static int
b_arginf_sz(const struct printf_info *info, size_t n, int argtypes[n],
            [[maybe_unused]] int size[n])
{
    if (n < 1)
        return -1;
    if (info->is_long_double)
        argtypes[0] = PA_INT | PA_FLAG_LONG_LONG;
    else if (info->is_long)
        argtypes[0] = PA_INT | PA_FLAG_LONG;
    else
        argtypes[0] = PA_INT;
    return 1;
}
static uintmax_t
b_value(const struct printf_info *info, const void *arg)
{
    if (info->is_long_double)
        return *(const unsigned long long *)arg;
    if (info->is_long)
        return *(const unsigned long *)arg;
    /* short y char se promocionan a int */
    return *(const unsigned int *)arg;
}
static size_t
b_bin_repr(char bin[UINTMAX_WIDTH],
           const struct printf_info *info, const void *arg)
{
    size_t     min_len;
    uintmax_t  val;
    val = b_value(info, arg);
    bin[0] = '0';
    for (min_len = 0; val; min_len++) {
        bin[min_len] = '0' + (val % 2);
        val >>= 1;
    }
    return MAX(min_len, 1);
}
static size_t
b_bin_len(const struct printf_info *info, ptrdiff_t min_len)
{
    return MAX(info->prec, min_len);
}
static size_t
b_pad_len(const struct printf_info *info, ptrdiff_t bin_len)
{
    ptrdiff_t  pad_len;
    pad_len = info->width - bin_len;
    if (info->alt)
        pad_len -= 2;
    if (info->group)
        pad_len -= (bin_len - 1) / 4;
    return MAX(pad_len, 0);
}
static ssize_t
b_print_prefix(FILE *stream, const struct printf_info *info)
{
    ssize_t len;
    len = 0;
    if (fputc('0', stream) == EOF)
        return EOF;
    len++;
    if (fputc(info->spec, stream) == EOF)
        return EOF;
    len++;
    return len;
}
static ssize_t
b_pad_zeros(FILE *stream, const struct printf_info *info,
            ptrdiff_t min_len)
{
    ssize_t    len;
    ptrdiff_t  tmp;
    len = 0;
    tmp = info->width - (info->alt * 2);
    if (info->group)
        tmp -= tmp / 5 - !(tmp % 5);
    for (ptrdiff_t i = tmp - 1; i > min_len - 1; i--) {
        if (fputc('0', stream) == EOF)
            return EOF;
        len++;
        if (!info->group || (i % 4))
            continue;
        if (fputc(GROUP_SEP, stream) == EOF)
            return EOF;
        len++;
    }
    return len;
}
static ssize_t
b_print_number(FILE *stream, const struct printf_info *info,
               const char bin[UINTMAX_WIDTH],
               size_t min_len, size_t bin_len)
{
    ssize_t  len;
    len = 0;
    /* Imprimir ceros iniciales para completar la precisión */
    for (size_t i = bin_len - 1; i > min_len - 1; i--) {
        if (fputc('0', stream) == EOF)
            return EOF;
        len++;
        if (!info->group || (i % 4))
            continue;
        if (fputc(GROUP_SEP, stream) == EOF)
            return EOF;
        len++;
    }
    /* Imprimir número */
    for (size_t i = min_len - 1; i < min_len; i--) {
        if (fputc(bin[i], stream) == EOF)
            return EOF;
        len++;
        if (!info->group || (i % 4) || !i)
            continue;
        if (fputc(GROUP_SEP, stream) == EOF)
            return EOF;
        len++;
    }
    return len;
}
static char
pad_ch(const struct printf_info *info)
{
    if ((info->prec != -1) || (info->pad == ' ') || info->left)
        return ' ';
    return '0';
}
static ssize_t
pad_spaces(FILE *stream, size_t pad_len)
{
    ssize_t  len;
    len = 0;
    for (size_t i = pad_len - 1; i < pad_len; i--) {
        if (fputc(' ', stream) == EOF)
            return EOF;
        len++;
    }
    return len;
}

    register_printf_modifier(3)

    Linux Programmer's Manual

    BIBLIOTECA

    Library C Standard Libraries (libc, -lc)

    SINOPSIS

    
#define _GNU_SOURCE
#include <stdio.h>

int register_printf_modifier(char **modifiers, const char *modifier_name,
                             void (*handler)(FILE *, char, void *), void *data);
int unregister_printf_modifier(const char *modifier_name);

    DESCRIPCIÓN

    The register_printf_modifier function registers a new printf(3) modifier named modifier_name. The handler function will be called when this modifier is encountered in a format string. The handler function receives a pointer to the FILE stream, the character immediately following the modifier name, and the data pointer passed to register_printf_modifier. The modifiers argument should be a pointer to a NULL-terminated array of strings representing the currently registered modifiers. This array will be updated by the function to include the new modifier.

    The unregister_printf_modifier function removes the registration for the specified modifier_name.

    VALOR DE RETORNO

    On success, register_printf_modifier returns 0. On failure, it returns -1 and sets errno appropriately.

    unregister_printf_modifier returns 0 on success, and -1 on failure.

    ERRORES

    ENOMEM
    Not enough memory to register the new modifier.
    EINVAL
    Invalid arguments were provided.
    EEXIST
    A modifier with the same name already exists.

    ESTÁNDARES

    These functions are GNU extensions.

    HISTORIA

    These functions were introduced in glibc 2.35.

    EJEMPLOS

    
// Example demonstrating register_printf_modifier and unregister_printf_modifier

#define _GNU_SOURCE
#include <stdio.h>
#include <stdlib.h>
#include <string.h>

static char **registered_modifiers = NULL;

void hex_modifier_handler(FILE *stream, char c, void *data) {
    int value = *(int *)data;
    fprintf(stream, "0x%X", value);
}

int main() {
    int ret;
    int my_value = 42;
    char **modifiers_copy = NULL;

    // Initialize the modifiers array if it's the first registration
    if (registered_modifiers == NULL) {
        registered_modifiers = malloc(sizeof(char *));
        if (registered_modifiers == NULL) {
            perror("malloc");
            return 1;
        }
        registered_modifiers[0] = NULL;
    }

    // Register a new modifier
    ret = register_printf_modifier(®istered_modifiers, "H", hex_modifier_handler, &my_value);
    if (ret == -1) {
        perror("register_printf_modifier");
        // Clean up if registration failed after initialization
        if (registered_modifiers != NULL && registered_modifiers[0] == NULL) {
             free(registered_modifiers);
             registered_modifiers = NULL;
        }
        return 1;
    }

    printf("Registered 'H' modifier.\n");

    // Use the registered modifier
    printf("My value in hex: %H\n", my_value); // Note: %H is not a standard printf specifier, this is for demonstration

    // Attempt to register a modifier with the same name (should fail)
    ret = register_printf_modifier(®istered_modifiers, "H", hex_modifier_handler, &my_value);
    if (ret == -1) {
        printf("Attempt to re-register 'H' failed as expected: %d\n", errno);
    }

    // Unregister the modifier
    ret = unregister_printf_modifier("H");
    if (ret == -1) {
        perror("unregister_printf_modifier");
        // Clean up the modifiers array
        free(registered_modifiers);
        registered_modifiers = NULL;
        return 1;
    }

    printf("Unregistered 'H' modifier.\n");

    // Clean up the modifiers array
    free(registered_modifiers);
    registered_modifiers = NULL;

    return 0;
}

/*
 * Note: The example above uses %H as a placeholder for the custom modifier.
 * In a real scenario, you would need to ensure that your custom modifier
 * name is not conflicting with existing ones and that your handler correctly
 * parses and uses the character following the modifier.
 *
 * Also, the way printf handles custom modifiers might vary, and this example
 * assumes a mechanism where the handler is directly invoked. Standard printf
 * does not directly support custom modifiers this way without specific library
 * implementations or extensions.
 *
 * For the example to compile and potentially run with glibc, you might need
 * to link with the appropriate library that provides these functions.
 * The actual usage within printf might require specific library support
 * that is not standard C.
 *
 * The way %H is used in printf("My value in hex: %H\n", my_value);
 * is illustrative. Standard printf doesn't recognize %H. You would typically
 * use a format like "%<modifier_name>d" or similar, depending on the library's
 * specification for using custom modifiers.
 *
 * A more realistic usage might involve a custom format specifier like "%{H}d"
 * where 'H' is the modifier. The handler would then need to parse the
 * surrounding format specifier.
 *
 * The `modifiers` argument in `register_printf_modifier` is meant to be a
 * pointer to the array of registered modifier names. The function modifies
 * this array in place.
 */
