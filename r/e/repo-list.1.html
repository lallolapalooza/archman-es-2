REPO(1) Manual de Repo REPO(1)

NOMBRE

repo - repo list - página del manual para repo list

SINOPSIS

repo list [-f] [<proyecto>...]

DESCRIPCIÓN

Resumen

Lista proyectos y sus directorios asociados

repo list [-f] -r str1 [str2]...

OPCIONES

-h, --help
muestra este mensaje de ayuda y sale
-r, --regex
filtra la lista de proyectos basándose en coincidencias de expresiones regulares o comodines de cadenas
-g GRUPOS, --groups=GRUPOS
filtra la lista de proyectos basándose en los grupos a los que pertenece el proyecto
-a, --all
muestra proyectos independientemente de su estado de checkout
-n, --name-only
muestra solo el nombre del repositorio
-p, --path-only
muestra solo la ruta del repositorio
-f, --fullpath
muestra la ruta completa del árbol de trabajo en lugar de la ruta relativa
--relative-to=RUTA
muestra rutas relativas a esta (por defecto: la parte superior del checkout del cliente repo)

Opciones de registro:

-v, --verbose
muestra toda la salida
-q, --quiet
muestra solo errores

Opciones multimanifesto:

--outer-manifest
opera comenzando desde el manifiesto más externo
--no-outer-manifest
no opera en manifiestos externos
--this-manifest-only
opera solo en este (sub)manifiesto
--no-this-manifest-only, --all-manifests
opera en este manifiesto y sus submanifiestos

Ejecuta `repo help list` para ver el manual detallado.

DETALLES

Lista todos los proyectos; pasa '.' para listar el proyecto del directorio actual.

Por defecto, solo se muestran los proyectos que existen actualmente en el checkout. Si deseas listar todos los proyectos (usando la configuración de filtro especificada), usa la opción --all. Si deseas mostrar todos los proyectos independientemente de los grupos del manifiesto, pasa también --groups all.

Esto es similar a ejecutar: repo forall -c 'echo "$REPO_PATH : $REPO_PROJECT"'.
