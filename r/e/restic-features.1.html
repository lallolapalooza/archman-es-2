NOMBRE

restic-features - Imprime la lista de indicadores de función

SINOPSIS

restic features [flags]

DESCRIPCIÓN

El comando "features" imprime una lista de los indicadores de función admitidos.

Para pasar indicadores de función a restic, establezca la variable de entorno RESTIC_FEATURES a "featureA=true,featureB=false". Especificar un indicador de función desconocido es un error.

Una función puede estar en estado alfa, beta, estable o obsoleta. Una función alfa está deshabilitada por defecto y puede cambiar de manera arbitraria entre versiones de restic o ser eliminada. Una función beta está habilitada por defecto, pero aún puede cambiar de manera menor o ser eliminada. Una función estable siempre está habilitada y no puede ser deshabilitada. El indicador se eliminará en una futura versión de restic. Una función obsoleta siempre está deshabilitada y no puede ser habilitada. El indicador se eliminará en una futura versión de restic.

ESTADO DE SALIDA

El estado de salida es 0 si el comando se ejecutó correctamente. El estado de salida es 1 si hubo algún error.

OPCIONES

-h, --help[=false] ayuda para features

OPCIONES HEREDADAS DE COMANDOS PADRE

--cacert=[] archivo desde el cual cargar certificados raíz (por defecto: usar certificados del sistema o $RESTIC_CACERT)

--cache-dir="" establecer el directorio de caché. (por defecto: usar el directorio de caché predeterminado del sistema)

--cleanup-cache[=false] eliminar automáticamente directorios de caché antiguos

--compression=auto modo de compresión (solo disponible para la versión 2 del formato de repositorio), uno de (auto|off|max) (por defecto: $RESTIC_COMPRESSION)

--http-user-agent="" establecer un agente de usuario http para las solicitudes http salientes

--insecure-no-password[=false] usar una contraseña vacía para el repositorio, debe pasarse a cada comando restic (inseguro)

--insecure-tls[=false] omitir la verificación del certificado TLS al conectarse al repositorio (inseguro)

--json[=false] establecer el modo de salida a JSON para los comandos que lo admitan

--key-hint="" ID de clave de la clave a intentar descifrar primero (por defecto: $RESTIC_KEY_HINT)

--limit-download=0 limita las descargas a una tasa máxima en KiB/s. (por defecto: sin límites)

--limit-upload=0 limita las cargas a una tasa máxima en KiB/s. (por defecto: sin límites)

--no-cache[=false] no usar caché local

--no-extra-verify[=false] omitir la verificación adicional de datos antes de la carga (ver documentación)

--no-lock[=false] no bloquear el repositorio, esto permite algunas operaciones en repositorios de solo lectura

-o, --option=[] establecer opción extendida (clave=valor, se puede especificar varias veces)

--pack-size=0 establecer el tamaño del paquete objetivo en MiB, los archivos de paquete creados pueden ser más grandes (por defecto: $RESTIC_PACK_SIZE)

--password-command="" comando de shell para obtener la contraseña del repositorio de (por defecto: $RESTIC_PASSWORD_COMMAND)

-p, --password-file="" archivo desde el cual leer la contraseña del repositorio (por defecto: $RESTIC_PASSWORD_FILE)

-q, --quiet[=false] no mostrar informe de progreso completo

-r, --repo="" repositorio para hacer copia de seguridad o restaurar desde (por defecto: $RESTIC_REPOSITORY)

--repository-file="" archivo desde el cual leer la ubicación del repositorio (por defecto: $RESTIC_REPOSITORY_FILE)

--retry-lock=0s reintentar bloquear el repositorio si ya está bloqueado, toma un valor como 5m o 2h (por defecto: sin reintentos)

--stuck-request-timeout=5m0s duración después de la cual se reintentarán las solicitudes atascadas

--tls-client-cert="" ruta a un archivo que contiene el certificado de cliente TLS codificado en PEM y la clave privada (por defecto: $RESTIC_TLS_CLIENT_CERT)

-v, --verbose[=0] ser detallado (especificar varias veces o un nivel usando --verbose=n, nivel/veces máximo es 2)
