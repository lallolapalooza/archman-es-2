repose(1) Comandos de usuario repose(1)

NOMBRE

repose - compilador de repositorios de Archlinux

SINOPSIS

repose [opciones] <base de datos> [pkgs|deltas ...]

DESCRIPCIÓN

repose crea y manipula repositorios de Archlinux, automatizando su generación a partir de un directorio de paquetes. Escanea el sistema de archivos en busca de paquetes y cambios en esos paquetes y los compila en bases de datos que pacman entiende.

OPCIONES

-h, --help
Muestra el mensaje de ayuda.
-V, --version
Muestra la información de la versión.
-v, --verbose
Produce una salida detallada. Al escanear en busca de cambios, repose listará cada paquete que se agregará, eliminará o actualizará, y también listará cada base de datos que se serializa en disco.
-f, --files
Además de construir la base de datos del repositorio, construye una base de datos de archivos utilizable por pkgfile y la mantiene sincronizada con la base de datos principal. Si esta bandera no se proporciona y se encuentra una base de datos de archivos, esta bandera se asume.
-l, --list
Lista todos los paquetes y sus versiones actuales.
-d, --drop
En lugar de agregar el conjunto especificado de paquetes, elimínelos de la base de datos.
-s, --sign
Crea una firma PGP separada para la base de datos.
-r RUTA, --root=RUTA
Establece la raíz del repositorio donde residirán los archivos de la base de datos. Si el directorio de agrupación es diferente del directorio raíz, mantiene enlaces simbólicos entre ambos para que el directorio raíz también contenga un enlace a todos los paquetes referenciados por el repositorio. El valor predeterminado si no se anula es el directorio de trabajo actual.
-p RUTA, --pool=RUTA
Establece el grupo (pool) del repositorio. El grupo es donde repose escaneará en busca de paquetes nuevos, cambiados o faltantes para actualizar la base de datos del repositorio. El valor predeterminado si no se anula es el directorio de trabajo actual.
-m ARQUITECTURA, --arch=ARQUITECTURA
Establece la arquitectura principal de la base de datos. La base de datos solo contendrá los paquetes encontrados para la arquitectura establecida en ARQUITECTURA o marcados como 'any'. Si no se proporciona este argumento, se asume la arquitectura de la máquina.
-j, --bzip2
Comprime la base de datos resultante con bzip2(1).
-J, --xz
Comprime la base de datos resultante con xz(1).
-z, --gzip
Comprime la base de datos resultante con gzip(1).
-Z, --compress
Comprime la base de datos resultante con compress(1).
--reflink
Hace que repose cree reflinks en lugar de symlinks al compilar un repositorio.
--rebuild
En lugar de intentar actualizar la base de datos existente, reconstruirla.
