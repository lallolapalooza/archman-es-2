NOMBRE

rediff, editdiff - corrige los desplazamientos y recuentos de un diff editado a mano

SINOPSIS

rediff ORIGINAL EDITADO

rediff EDITADO

rediff {[--ayuda] | [--versión]}

editdiff ARCHIVO

editdiff {[--ayuda] | [--versión]}

DESCRIPCIÓN

Puede usar rediff para corregir un diff unificado editado a mano. Tome una copia del diff que desea editar y edítelo sin cambiar ningún desplazamiento o recuento (las líneas que comienzan con “@@”). Luego, ejecute rediff, indicándole el nombre del archivo diff original y el nombre del que ha editado, y generará el archivo diff editado pero con los desplazamientos y recuentos corregidos.

Se proporciona un pequeño script, editdiff, para editar un archivo diff en el lugar.

Los tipos de cambios que se manejan actualmente son:

•Modificar el texto de cualquier línea de contenido de archivo (por supuesto).
•Añadir nuevas inserciones o eliminaciones de línea.
•Añadir, cambiar o eliminar líneas de contexto. Las líneas en el horizonte de contexto se manejan ajustando el desplazamiento y/o el recuento.
•Añadir una sola sección (sección prefijada con @@).
•Eliminar múltiples secciones (secciones prefijadas con @@).

Alternativamente, si solo se proporciona un argumento, se toma como el archivo editado y se ajustan los recuentos y desplazamientos según corresponda. Se hacen algunas suposiciones cuando se usa en este modo. Consulte recountdiff(1) para obtener más información.

OPCIONES

--ayuda

Muestra un breve mensaje de uso.

--versión

Muestra el número de versión de rediff.

VER TAMBIÉN

interdiff(1), recountdiff(1)
