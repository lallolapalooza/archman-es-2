rename(n) Comandos integrados de Tcl rename(n)

NOMBRE

rename - Renombrar o eliminar un comando

SINOPSIS

rename nombreAntiguo nombreNuevo

DESCRIPCIÓN

Renombra el comando que antes se llamaba nombreAntiguo para que ahora se llame nombreNuevo. Si nombreNuevo es una cadena vacía, se elimina nombreAntiguo. nombreAntiguo y nombreNuevo pueden incluir calificadores de espacio de nombres (nombres de los espacios de nombres contenedores). Si un comando se renombra a un espacio de nombres diferente, las invocaciones futuras se ejecutarán en el nuevo espacio de nombres. El comando rename devuelve una cadena vacía como resultado.

EJEMPLO

El comando rename se puede utilizar para envolver los comandos estándar de Tcl con su propia maquinaria de monitorización. Por ejemplo, es posible que desee contar cuántas veces se llama al comando source:

rename ::source ::fuenteReal
set contadorFuente 0
proc ::source args {
    global contadorFuente
    puts "se llamó a source por [incr contadorFuente]ª vez"
    uplevel 1 ::fuenteReal $args
}
