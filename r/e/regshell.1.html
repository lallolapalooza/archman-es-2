REGSHELL(1) Herramientas de administración del sistema REGSHELL(1)

NOMBRE

regshell - explorador de archivos del registro de Windows usando readline

SINOPSIS

regshell [--ayuda] [--backend=BACKEND] [--credenciales=CREDENCIALES] [ubicacion]

DESCRIPCIÓN

regshell es una utilidad que le permite explorar un archivo del registro de Windows como si estuviera utilizando un shell de Unix normal para explorar un sistema de archivos.

OPCIONES

--ayuda

Muestra la lista de opciones disponibles.

--backend BACKEND

Nombre del backend a cargar. Los valores posibles son: creg, regf, dir y rpc. El valor predeterminado es dir.

--credenciales=CREDENCIALES

Credenciales a utilizar, si las hay. La contraseña debe estar separada del nombre de usuario por un signo de porcentaje.

COMANDOS

ck|cd <nombreclave>

Ir a la subclave especificada.

ch|predef [nombre-clave-predefinida]

Ir a la clave predefinida especificada.

list|ls

Lista las subclaves y valores de la clave actual.

mkkey|mkdir <nombreclave>

Crea una clave con el nombreclave especificado como subclave de la clave actual.

rmval|rm <nombrevalor>

Elimina el valor especificado.

rmkey|rmdir <nombreclave>

Elimina la subclave especificada recursivamente.

pwd|pwk

Imprime el nombre completo de la clave actual.

set|update

Actualiza el valor de una clave de valor. No implementado en este momento.

help|?

Imprime una lista de comandos disponibles.

exit|quit

Salir de regshell.

EJEMPLOS

Explorando un archivo de registro de nt4

regshell -b nt4 NTUSER.DAT
$$$PROTO.HIV> ls
K AppEvents
K Console
K Control Panel
K Environment
K Identities
K Keyboard Layout
K Network
K Printers
K Software
K UNICODE Program Groups
K Windows 3.1 Migration Status
$$$PROTO.HIV> exit

Listando las subclaves de HKEY_CURRENT_USER\AppEvents en una máquina remota:

regshell --remote=ncacn_np:aurelia -c "jelmer%secret"
HKEY_CURRENT_MACHINE> predef HKEY_CURRENT_USER
HKEY_CURRENT_USER> cd AppEvents
Ruta actual: HKEY_CURRENT_USER\AppEvents
HKEY_CURRENT_USER\AppEvents> ls
K EventLabels
K Schemes
HKEY_CURRENT_USER\AppEvents> exit
