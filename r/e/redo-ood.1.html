REDO-OOD(1) Manual de comandos generales REDO-OOD(1)

NOMBRE

redo-ood - imprime la lista de objetivos de redo que están obsoletos

SINOPSIS

redo-ood

DESCRIPCIÓN

redo(1) es una herramienta para construir archivos y para reconstruirlos si alguna de sus dependencias ha cambiado. redo-ood imprime la lista de objetivos de redo en el directorio actual y sus subdirectorios que existen y están obsoletos, es decir, archivos que se reconstruirían si se les diera como argumento a redo-ifchange(1).

Los archivos que no existen no se listan porque es posible que ya no sean objetivos. Por ejemplo, si construyes un archivo y luego lo eliminas y cambias la construcción para que ya no lo genere, no se listará.

ERRORES

redo-ood puede fallar si el nombre del archivo objetivo contiene una tabulación o una nueva línea.
