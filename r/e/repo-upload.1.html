DETALLES

El comando 'repo upload' se usa para enviar cambios al sistema de revisión de código Gerrit. Busca ramas temáticas en proyectos locales que aún no se han publicado para su revisión. Si se encuentran múltiples ramas temáticas, 'repo upload' abre un editor para permitir al usuario seleccionar qué ramas subir.

'repo upload' busca cambios subibles en todos los proyectos listados en la línea de comandos. Los proyectos se pueden especificar por nombre o por una ruta relativa o absoluta al directorio local del proyecto. Si no se especifican proyectos, 'repo upload' buscará cambios subibles en todos los proyectos listados en el manifiesto.

Si se pasan las opciones --reviewers o --cc, esos correos electrónicos se agregan a la lista respectiva de usuarios y se envían correos a los nuevos usuarios. Los usuarios pasados como --reviewers deben estar ya registrados en el sistema de revisión de código, o la carga fallará.

Aunque la mayoría de las opciones normales de Gerrit tienen opciones dedicadas en la línea de comandos, el acceso directo a las opciones de Gerrit está disponible a través de --push-options. Esto es útil cuando Gerrit tiene funcionalidades más nuevas que repo upload aún no soporta, o no planea soportar. Consulte la documentación de Opciones de Push para más detalles: https://gerrit-review.googlesource.com/Documentation/user-upload.html#push_options

Configuración

review.URL.autoupload:

Para deshabilitar la pregunta "¿Subir ... (s/N)?", puede establecer una opción de configuración de Git por proyecto o global. Si review.URL.autoupload se establece en "true", repo asumirá que siempre responde "s" a la pregunta y no le preguntará más. Si se establece en "false", repo asumirá que siempre responde "n" y abortará.

review.URL.autoreviewer:

Para agregar automáticamente un usuario o lista de correo a las revisiones, puede establecer una opción de Git por proyecto o global para hacerlo.

review.URL.autocopy:

Para copiar automáticamente un usuario o lista de correo a todas las revisiones subidas, puede establecer una opción de Git por proyecto o global para hacerlo. Específicamente, review.URL.autocopy puede establecerse como una lista separada por comas de revisores que siempre desea que se copien en todas las cargas con un argumento --re no vacío.

review.URL.username:

Anular el nombre de usuario utilizado para conectarse a Gerrit Code Review. Por defecto, se utiliza la parte local de la dirección de correo electrónico.

La URL debe coincidir con la URL de revisión listada en el archivo XML del manifiesto, o en el .git/config dentro del proyecto. Por ejemplo:

[remote "origin"]
url = git://git.example.com/project.git review = http://review.example.com/
[review "http://review.example.com/"]
autoupload = true autocopy = johndoe@company.com,my-team-alias@company.com

review.URL.uploadtopic:

Para agregar una rama temática cada vez que se sube un commit, puede establecer una opción de Git por proyecto o global para hacerlo. Si review.URL.uploadtopic se establece en "true", repo asumirá que siempre desea el equivalente a la opción -t del comando repo. Si no está establecido o se establece en "false", repo solo utilizará la línea de comandos o

NAME

repo-upload - Upload commits to Gerrit Code Review

SYNOPSIS

repo upload [options] [project...]

DESCRIPTION

This command uploads commits from the current branch to Gerrit Code Review.

If no project is specified, the command uploads commits from all projects listed in the manifest.

If --all is specified, the command uploads commits from all branches in the current project.

If --current-branch or --current-only is specified, the command uploads commits from the current branch only.

If --cproj is specified, the command uploads commits from the specified project only.

OPTIONS

--all
Upload all branches.
--cproj project
Upload commits from the specified project only.
--current-branch
Upload commits from the current branch only.
--current-only
Upload commits from the current branch only. This is an alias for --current-branch.
--days number
Upload commits newer than number days.
--exclude project
Exclude specified projects.
--force-broken
Continue upload even if some commits are broken.
--hashtag hashtags
Add comma separated hashtags to the upload.
--lazy-fetch
Fetch only the necessary commits during upload.
--label labels
Add comma separated labels to the upload.
--no-current-branch
Upload all branches except the current branch.
--no-tags
Do not upload tags.
-o key=value
Set Gerrit option. The option name is case insensitive. https://gerrit-review.googlesource.com/Documentation/user-upload.html#_options
--preserve-tags
Preserve tags during upload.
-p project
Upload commits from the specified project only. This is an alias for --cproj.
-s file
Set Gerrit topic. The topic is applied to all commits in the upload.
--stealth
Do not notify reviewers.
--topic topic
Set Gerrit topic. The topic is applied to all commits in the upload.
--track branch
Set tracking branch for the upload.
--verify-commits
Verify commits before uploading.
-v
Increase verbosity.

DETAILS

The following Git options can be set per-project or globally:

review.URL.uploadhashtags:

To add hashtags whenever uploading a commit, you can set a per-project or global Git option to do so. The value of review.URL.uploadhashtags will be used as comma delimited hashtags like the --hashtag option.

review.URL.uploadlabels:

To add labels whenever uploading a commit, you can set a per-project or global Git option to do so. The value of review.URL.uploadlabels will be used as comma delimited labels like the --label option.

review.URL.uploadnotify:

Control e-mail notifications when uploading. https://gerrit-review.googlesource.com/Documentation/user-upload.html#notify

review.URL.uploadwarningthreshold:

Repo will warn you if you are attempting to upload a large number of commits in one or more branches. By default, the threshold is five commits. This option allows you to override the warning threshold to a different value.
