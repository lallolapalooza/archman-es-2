NOMBRE

repo - repo diffmanifests - página del manual para repo diffmanifests

SINOPSIS

repo diffmanifests manifest1.xml [manifest2.xml] [opciones]

DESCRIPCIÓN

Resumen

Utilidad de diferencias de manifiesto

OPCIONES

-h, --help
mostrar esta ayuda y salir
--raw
mostrar la diferencia cruda
--no-color
no mostrar la diferencia en color
--pretty-format=<FORMATO>
imprimir el registro usando una cadena de formato bonito de git personalizada

Opciones de registro:

-v, --verbose
mostrar toda la salida
-q, --quiet
mostrar solo errores

Opciones multi-manifiesto:

--outer-manifest
operar comenzando desde el manifiesto más externo
--no-outer-manifest
no operar en manifiestos externos
--this-manifest-only
operar solo en este (sub)manifiesto
--no-this-manifest-only, --all-manifests
operar en este manifiesto y sus submanifiestos

Ejecuta `repo help diffmanifests` para ver el manual detallado.

DETALLES

El comando repo diffmanifests muestra las diferencias entre las revisiones de proyectos de manifest1 y manifest2. si manifest2 no se especifica, se usará el manifest.xml actual en su lugar. Se pueden usar rutas absolutas y relativas para los manifiestos. Las rutas relativas comienzan desde la carpeta ".repo/manifests" del proyecto.

La opción --raw muestra la diferencia de una manera que facilita el análisis, el patrón del proyecto será <estado> <ruta> <revisión desde> [<revisión hasta>] y el patrón del commit será <estado> <registro en una línea> con los valores de estado respectivamente:

A = Proyecto añadido R = Proyecto eliminado C = Proyecto cambiado U = Proyecto con revisiones inalcanzables (revisiones no encontradas)

para el proyecto, y

A = Commit añadido R = Commit eliminado

para un commit. Solo los proyectos cambiados pueden contener commits, y el estado del commit siempre comienza con un espacio, y son parte del último proyecto impreso. Las revisiones inalcanzables pueden ocurrir si el proyecto no está actualizado o si repo no se ha inicializado con todos los grupos, en cuyo caso algunos proyectos no se sincronizarán y sus revisiones no se encontrarán.
