Paquete: libbobcat

Licencias: GPL

FBB::ReadLineHistory(3bobcat) Edición de líneas de entrada FBB::ReadLineHistory(3bobcat)

NOMBRE

FBB::ReadLineHistory - std::streambuf que ofrece edición de línea e historial

SINOPSIS

#include <bobcat/readlinebuf>
Opción de enlace: -lbobcat -lreadline

DESCRIPCIÓN

El objeto FBB::ReadLineHistory ofrece acceso al historial mantenido por los objetos FBB::ReadLineBuf y ReadLineStream.

Estas dos últimas clases utilizan la biblioteca readline de Gnu para permitir la edición de líneas de entrada. El historial acumulado de estos objetos se puede acceder desde el objeto ReadLineHistory.

Dado que la biblioteca readline de Gnu mantiene datos globales, solo puede haber un historial. Por lo tanto, la clase ReadLineHistory es, como ReadLineBuf, un singleton. (Sin embargo, la biblioteca readline de Gnu ofrece funciones que permiten a los programas usar múltiples historiales. Por lo tanto, en principio, sería posible diseñar una clase ReadLineHistory que no sea singleton. Dado que los programas normalmente solo interactúan con una sola terminal, probablemente haya poco uso para una clase ReadLineHistory no singleton).

La clase ReadLineHistory encapsula el acceso al historial. Ofrece instalaciones limitadas: se ofrecen iteraciones hacia adelante o hacia atrás sobre el historial, así como la lectura y escritura del historial desde/hacia flujos. Al leer el historial de un flujo, reemplaza las líneas actualmente disponibles en el historial de readline de Gnu. El contenido de las líneas del historial y, si se definen, las marcas de tiempo de las líneas en el historial se pueden obtener utilizando iteradores definidos por ReadLineHistory.

TIPOS ANIDADOS

La clase ReadLineHistory define los siguientes tipos anidados:

HistoryElement

Los iteradores disponibles a través del objeto ReadLineHistory proporcionan acceso a un objeto HistoryElement. Estos objetos pueden copiarse y asignarse entre sí, pero los programas de usuario no pueden construir objetos HistoryElement de otra manera.

La clase HistoryElement tiene solo dos miembros:

o
char const *line() const devuelve el contenido de la línea del historial a la que se refiere un iterador de ReadLineHistory;
o
char const *timestamp() const devuelve la marca de tiempo (si se define) de la línea del historial a la que se refiere un iterador de ReadLineHistory;

const_iterator y const_reverse_iterator

Los iteradores devueltos por los miembros de la clase ReadLineHistory son iteradores de entrada, que apuntan a objetos HistoryElement. Como son iteradores de entrada, no se permite la modificación de los elementos del historial a los que se refieren.

La clase const_iterator permite iteraciones desde el primer hasta el último elemento del historial, la clase const_reverse_iterator permite iteraciones desde el último hasta el primer elemento del historial.

Los iteradores se pueden incrementar, comparar por (in)igualdad y ofrecen miembros operator* y operator->, que ofrecen acceso a objetos HistoryElement y sus direcciones, respectivamente.

CONSTRUCTORES

Dado que la clase ReadLineHistory es una clase singleton, no hay constructores disponibles públicamente, ni operadores de asignación disponibles.

FUNCIONES MIEMBRO ESTÁTICAS

o
ReadLineHistory &instance():
Se devuelve una referencia al objeto ReadLineHistory. Si se ha acumulado algún historial, se puede recuperar inmediatamente. El uso de este miembro estático no afectará la forma en que el objeto ReadLineHistory maneja las marcas de tiempo al guardar o recuperar líneas del historial. Al construirse inicialmente, el objeto ReadLineHistory asume que no se utilizan marcas de tiempo.
o
ReadLineHistory &instance(bool useTimestamps):
Se devuelve una referencia al objeto ReadLineHistory. Si se ha acumulado algún historial, se puede recuperar inmediatamente. El parámetro useTimestamps define la forma en que se leen o escriben las líneas del historial desde/hacia un flujo. Al especificar true, el historial insertado en un flujo incluirá marcas de tiempo (que pueden estar vacías si no se registraron marcas de tiempo). De manera similar, al extraer el historial, también se extraen las marcas de tiempo (que también pueden estar vacías). Al especificar false, no se leen ni se escriben marcas de tiempo. Una discrepancia entre el contenido real del flujo desde el que se extrae el historial y el parámetro useTimestamps resultará en un comportamiento inesperado.

FUNCIONES MIEMBRO

o
ReadLineHistory::const_iterator begin() const:
Se devuelve un iterador de entrada que apunta a la primera línea del historial.
o
ReadLineHistory::const_iterator end() const:
Se devuelve un iterador de entrada que apunta más allá de la última línea del historial.
o
size_t maxSize() const:
Se devuelve el número máximo de líneas que se pueden almacenar en el historial. Después de recopilar un historial de maxSize líneas, la siguiente línea introducida provocará que la línea inicial del historial se elimine del historial, dejando espacio para que se agregue la siguiente línea al final del historial.
o
ReadLineHistory::const_reverse_iterator rbegin() const:
Se devuelve un iterador de entrada que apunta a la última línea del historial. Incrementar este iterador accederá a la línea anterior en el historial.
o
ReadLineHistory::const_reverse_iterator rend() const:
Se devuelve un iterador de entrada que apunta antes de la primera línea del historial.
o
ReadLineHistory &setTimestamps(bool useTimestamps):
El estado actual del uso de marcas de tiempo se establece de acuerdo con el valor de su parámetro. Cuando es true, la inserción y extracción del historial incluirán las marcas de tiempo. No se insertan ni extraen marcas de tiempo cuando es false. Devuelve una referencia al objeto actualizado ReadLineHistory, lo que permite construcciones como (suponiendo la disponibilidad de ReadLineHistory &history): 
    cout << history.setTimestamps(true);
o
size_t size() const:
Se devuelve el número de líneas almacenadas actualmente en el historial.
o
bool timestamps() const:
Se devuelve el estado actual del uso de marcas de tiempo. Cuando devuelve true, la inserción y extracción del historial incluirán las marcas de tiempo. No se insertan ni extraen marcas de tiempo cuando este miembro devuelve false

OPERADORES SOBRECARGADOS

o
std::istream &operator>>(std::istream &in, ReadLineHistory &his):
El historial disponible en el flujo in se extrae para convertirse en el historial actual, reemplazando el historial existente (Gnu readline) por el historial leído de in. El estado useTimestamp determina si se extraen marcas de tiempo (si es true) o no (si es false). Si la extracción del historial desde in falla, se lanza una excepción.
o
std::ostream &operator<<(std::ostream &out, ReadLineHistory &his):
El historial disponible en el objeto his se inserta en el flujo de salida out. Si el estado useTimestamp está activado, cada línea del historial se precederá por su marca de tiempo (si se conoce) y un carácter de tabulación. Si las marcas de tiempo no se utilizan, se insertarán solo las líneas del historial. La operación se realiza al revés: desde la última entrada del historial hasta la más antigua.

El historial actual se escribe en el flujo *out*. El estado *useTimestamp* determina si se insertan las marcas de tiempo (si es *true*) o no (si es *false*).

EJEMPLO

#include <iostream>
#include <algorithm>
#include <fstream>
#include <bobcat/datetime>
#include <bobcat/readlinestream>
//#include <bobcat/readlinehistory>
#include "../readlinehistory"
using namespace std;
using namespace FBB;
void showHis(ReadLineHistory::HistoryElement const &element)
{
    cout << element.timestamp() << " " << element.line() << ’\n’;
}
string timestamp()
{
    return DateTime().rfc2822();
};
int main(int argc, char **argv)
{
    ReadLineStream in("? ", ReadLineBuf::EXPAND_HISTORY);
    in.useTimestamps(&timestamp);
    cout << "Enter some lines, end the input using ctrl-d\n";
    string line;
    while (getline(in, line))
        ;
                                            // argument means: write/read
                                            // history timestamps
    ReadLineHistory &history = ReadLineHistory::instance(argc > 1);
    cout << "All lines, from the first to the last:\n";
    for_each(history.begin(), history.end(), showHis);
    cout << "\n"
            "Again: all lines, from the first to the last:\n";
    for_each(history.begin(), history.end(), showHis);
    cout << "\n"
            "All lines, from the last to the first:\n";
    for_each(history.rbegin(), history.rend(), showHis);
    cout << "\n"
            "History out and in:\n"
            "\n";
    ofstream hisout("history.out");
    hisout << history;
    hisout.close();
    ifstream hisin("history.out");
    hisin >> history;
    cout << "All lines, from the first to the last:\n";
    for_each(history.begin(), history.end(), showHis);
    cout << "\n"
            "All lines, from the last to the first:\n";
    for_each(history.rbegin(), history.rend(), showHis);
}
