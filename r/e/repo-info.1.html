NOMBRE

repo - información de repo - página del manual para información de repo

SINOPSIS

repo info [-dl] [-o [-c]] [<proyecto>...]

DESCRIPCIÓN

Resumen

Obtener información sobre la rama de manifiesto, la rama actual o las ramas no fusionadas

OPCIONES

-h, --help
mostrar esta ayuda y salir
-d, --diff
mostrar información completa y diferencia de commits, incluyendo ramas remotas
-o, --overview
mostrar un resumen de todos los commits locales
-c, --current-branch
considerar solo las ramas seleccionadas
--no-current-branch
considerar todas las ramas locales
-l, --local-only
deshabilitar todas las operaciones remotas

Opciones de registro:

-v, --verbose
mostrar toda la salida
-q, --quiet
mostrar solo errores

Opciones multi-manifiesto:

--outer-manifest
operar comenzando desde el manifiesto más externo
--no-outer-manifest
no operar en manifiestos externos
--this-manifest-only
operar solo en este manifiesto (sub)
--no-this-manifest-only, --all-manifests
operar en este manifiesto y sus submanifiestos

Ejecuta `repo help info` para ver el manual detallado.
