repeat(3bobcat) llamadas a funciones repetidas repeat(3bobcat)

NOMBRE

FBB::repeat - llamar a una (función miembro) un número fijo de veces

SINOPSIS

#include <bobcat/repeat>

DESCRIPCIÓN

La plantilla de función FBB::repeat permite que una función o función miembro sea llamada un cierto número de veces. Las funciones o funciones miembro pueden definir argumentos. Los argumentos para estas funciones se especifican cuando se llama a repeat, y son perfectamente reenviados por la plantilla de función repeat a la función (miembro) llamada por repeat.

El primer argumento de la plantilla de función repeat define el número de veces que la función (miembro) debe ser llamada.

La plantilla de función FBB::repeat está definida como inline, permitiendo al compilador `optimizar’ la propia llamada a la función repeat.

PLANTILLA DE FUNCIÓN REPEAT

La plantilla de función repeat se declara como:

template <typename Counter, typename First, typename ...Params>
void repeat(Counter counter, First &&first, Params &&...params);

En esta declaración,

o
Counter representa el tipo del contador. Normalmente un int o size_t. Al llamar a repeat, counter debe ser inicializado con el número de veces que repeat debe llamar a la función (miembro) (ver abajo);
o
First representa el prototipo de una función o el nombre de una clase. De manera similar, first es o bien la dirección (nombre) de la función a llamar o el nombre de un objeto de tipo de clase First. En este último caso, el objeto puede ser o no un objeto const.
o
...Params representa el conjunto de tipos de parámetros de los argumentos que deben ser reenviados perfectamente a la función llamada. Si first representa un objeto de tipo de clase, el primer argumento *debe* ser la dirección de una función miembro de la clase First.

EJEMPLOS

#include <iostream>
#include <iterator>
#include <algorithm>
#include "../repeat"
using namespace std;
using namespace FBB;
class Object
{
    public:
        void member(int argc, char **argv) const;
        void member2(size_t &rept, int argc, char **argv);
};
void Object::member(int argc, char **argv) const
{
    cout << "member llamado\n";
    copy(argv, argv + argc, ostream_iterator<char const *>(cout, "\n"));
}
void Object::member2(size_t &rept, int argc, char **argv)
{
    cout << "member2 llamado, iteración " << rept++ << "\n";
    copy(argv, argv + argc, ostream_iterator<char const *>(cout, "\n"));
}
void fun()
{
    cout << "Fun llamado\n";
}
int main(int argc, char **argv)
{
    Object object;
    cout << "\n"
            "*** El número de argumentos determina el número de repeticiones ***\n\n";
    cout << "Fun sin argumentos:\n";
    repeat(argc, fun);
    cout << "Objeto recibiendo argc y argv:\n";
    repeat(argc, object, &Object::member, argc, argv);
    cout << "Objeto recibiendo argc y argv, mostrando el contador de iteraciones:\n";
    size_t count = 0;
    repeat(argc, object, &Object::member2, count, argc, argv);
    Object const obj;
    cout << "Objeto Const recibiendo argc y argv:\n";
    repeat(argc, obj, &Object::member, argc, argv);
}

ERRORES

Tenga cuidado al usar funciones sobrecargadas, ya que el mecanismo de resolución de argumentos de plantilla puede no ser capaz de determinar qué función llamar. Si se deben usar funciones sobrecargadas, es probable que se requiera un static_cast para desambiguar sus intenciones.
