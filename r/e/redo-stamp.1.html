REDO-STAMP(1) Manual de comandos generales REDO-STAMP(1)

NOMBRE

redo-stamp - reconstruye archivos objetivo que dependen de datos dados por entrada estándar

SINOPSIS

[comando] | redo-stamp

DESCRIPCIÓN

redo(1) es una herramienta para construir archivos y reconstruirlos si alguna de sus dependencias ha cambiado. redo-stamp, cuando se invoca desde un dofile, añade una dependencia del objetivo de redo(1) actual en los datos dados por entrada estándar. Si los datos dados por entrada estándar a redo-stamp no han cambiado desde la última compilación, el objetivo de redo(1) actual no se reconstruye y se marca como actualizado. Para asegurar que redo-stamp compruebe la validez del objetivo actual, se puede usar redo-always(1) para marcar el objetivo actual como siempre obsoleto.

EJEMPLOS

Consideremos los siguientes dos archivos all.do y b.do:

all.do

#!/bin/sh
redo-ifchange b
b.do

#!/bin/sh
redo-always
echo 'introduce una línea de texto:' >&2
line | redo-stamp
date +%s

Invocar redo(1) en un directorio con estos archivos construirá un archivo llamado b que contiene una marca de tiempo. La próxima vez que se invoque redo(1), solo reconstruirá b si la salida de line(1) cambió desde la última compilación. Esto se puede verificar invocando redo(1) repetidamente y examinando la marca de tiempo b después de cada invocación, luego cambiando la entrada a line(1), invocando redo(1) nuevamente y examinando la marca de tiempo nuevamente.
