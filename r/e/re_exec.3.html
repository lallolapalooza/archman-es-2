re_comp(3) Manual de Funciones de Biblioteca re_comp(3)

NOMBRE

re_comp, re_exec - Funciones de expresiones regulares BSD

BIBLIOTECA

Biblioteca C estándar (libc, -lc)

SINOPSIS

#define _REGEX_RE_COMP
#include <sys/types.h>
#include <regex.h>
[[deprecated]] char *re_comp(const char *regex);
[[deprecated]] int re_exec(const char *string);

DESCRIPCIÓN

re_comp() se utiliza para compilar la expresión regular terminada en nulo apuntada por regex. El patrón compilado ocupa un área estática, el búfer de patrón, que se sobrescribe con el uso posterior de re_comp(). Si regex es NULL, no se realiza ninguna operación y el contenido del búfer de patrón no se modifica.

re_exec() se utiliza para evaluar si la cadena terminada en nulo apuntada por string coincide con la regex compilada previamente.

VALOR DE RETORNO

re_comp() devuelve NULL si la compilación de regex es exitosa; de lo contrario, devuelve un puntero a un mensaje de error apropiado.

re_exec() devuelve 1 si hay una coincidencia exitosa, cero si falla.

ATRIBUTOS

Para obtener una explicación de los términos utilizados en esta sección, consulte attributes(7).

Interfaz Atributo Valor
re_comp (), re_exec () Seguridad de hilos No seguro para MT

ESTÁNDARES

Ninguno.

HISTORIA

4.3BSD.

Estas funciones están obsoletas; se deben utilizar en su lugar las funciones documentadas en regcomp(3).

VÉASE TAMBIÉN

regcomp(3), regex(7), Manual de expresiones regulares de GNU
