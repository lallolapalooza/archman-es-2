RESIZE.F2FS(8) Manual del Administrador del Sistema RESIZE.F2FS(8)

NOMBRE

resize.f2fs - redimensionar el tamaño del sistema de archivos

SINOPSIS

resize.f2fs [ -t sectores objetivo ] [ -d nivel de depuración ] [ -o porcentaje de ratio de sobreaprovisionamiento ] [ -i ] [ -s ] [ -V ] dispositivo

DESCRIPCIÓN

resize.f2fs se utiliza para redimensionar un sistema de archivos f2fs (normalmente en una partición de disco). dispositivo es el archivo especial correspondiente al dispositivo (por ejemplo, /dev/sdXX).

La versión actual solo admite la expansión del sistema de archivos preconstruido.

El código de salida devuelto por resize.f2fs es 0 en caso de éxito y -1 en caso de error.

OPCIONES

-t sectores objetivo
Especifica el tamaño en sectores.
-d nivel de depuración
Especifica el nivel de las opciones de depuración. El número por defecto es 0, que muestra mensajes de depuración básicos.
-o porcentaje de ratio de sobreaprovisionamiento
Especifica el porcentaje del volumen que se utilizará como área de sobreaprovisionamiento. Esta área está oculta a los usuarios y es utilizada por el limpiador de F2FS. Si no se especifica, se asignará automáticamente el mejor número según el tamaño de la partición.
-i
Habilita el mapa de bits de nodos extendido.
-s
Habilita el redimensionamiento seguro.
-V
Imprime el número de versión y sale.

AUTOR

DISPONIBILIDAD
