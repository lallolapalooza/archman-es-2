NOMBRE

referer2dlf - convierte el archivo de registro del servidor web referer a www DLF

SINOPSIS

referer2dlf archivo

DESCRIPCIÓN

referer2dlf convierte los archivos de registro del servidor web Referer al formato www DLF. El formato de registro Referer fue implementado por primera vez en el servidor httpd de NSCA. Apache puede configurarse para registrar en ese formato.

Tenga en cuenta que si desea registrar información de referer, el formato de registro combinado es un formato mejor.

FORMATO DE REGISTRO REFERER

El formato de registro Referer registra la información del referer en el siguiente formato:

I<uri> -> I<documento>

donde los campos tienen el siguiente significado:

uri
La URI de referencia. Este es el contenido de la cabecera de la solicitud Referer, que generalmente refleja la página donde estaba el usuario antes de esa solicitud.
documento
El documento local al que hacía referencia esa URI. Este es el archivo solicitado sin ninguna cadena de consulta.

EJEMPLOS

Para procesar un registro como el producido en el formato de registro referer:

$ referer2dlf < referer.log

referer2dlf rara vez se usará por sí solo, sino que es más probable que sea llamado por lr_log2report:

$ lr_log2report referer < /var/log/httpd/referer.log
