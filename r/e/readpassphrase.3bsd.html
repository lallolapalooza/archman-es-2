readpassphrase(3bsd)

Paquete: libbsd

Licencias: custom

readpassphrase(3bsd) 3bsd readpassphrase(3bsd)

NOMBRE

readpassphrase — obtener una contraseña del usuario

BIBLIOTECA

biblioteca “libbsd”

SINOPSIS

#include <readpassphrase.h> (Ver libbsd(7) para el uso de la inclusión.)
char *
readpassphrase(const char *prompt, char *buf, size_t bufsiz, int flags);

DESCRIPCIÓN

La función readpassphrase() muestra un mensaje y lee una contraseña desde /dev/tty. Si este archivo es inaccesible y la bandera (flag) RPP_REQUIRE_TTY no está establecida, readpassphrase() muestra el mensaje en la salida de error estándar y lee desde la entrada estándar. En este caso, generalmente no es posible desactivar el eco.

Se leen hasta bufsiz - 1 caracteres (uno es para el NUL) en el buffer proporcionado buf. Cualquier caracter adicional y el carácter de nueva línea (o retorno) final se descartan.

El argumento flags es el OR a nivel de bits de cero o más de los siguientes valores:

RPP_ECHO_OFF		desactivar eco (comportamiento por defecto)
RPP_ECHO_ON		dejar eco activado
RPP_REQUIRE_TTY		fallar si no hay tty
RPP_FORCELOWER		forzar entrada a minúsculas
RPP_FORCEUPPER		forzar entrada a mayúsculas
RPP_SEVENBIT		eliminar el bit alto de la entrada
RPP_STDIN		leer contraseña desde stdin; ignorar prompt

El proceso que llama debe poner a cero la contraseña lo antes posible para evitar dejar la contraseña en texto claro visible en el espacio de direcciones del proceso.

VALORES DE RETORNO

Al completarse con éxito, readpassphrase() devuelve un puntero a la contraseña terminada en NUL. Si se encuentra un error, se restaura el estado de la terminal y se devuelve un puntero nulo.

ARCHIVOS

/dev/tty
 

EJEMPLOS

El siguiente fragmento de código leerá una contraseña desde /dev/tty en el buffer passbuf.

char passbuf[1024];

...

if (readpassphrase("Respuesta: ", passbuf, sizeof(passbuf),
    RPP_REQUIRE_TTY) == NULL)
	errx(1, "no se pudo leer la contraseña");

if (compare(transform(passbuf), epass) != 0)
	errx(1, "contraseña incorrecta");

...

explicit_bzero(passbuf, sizeof(passbuf));

ERRORES

[EINTR]
La función readpassphrase() fue interrumpida por una señal.
[EINVAL]
El argumento bufsiz era cero.
[EIO]
El proceso es miembro de un proceso en segundo plano que intenta leer desde su terminal de control, el proceso está ignorando o bloqueando la señal SIGTTIN, o el grupo de procesos está huérfano.
[EMFILE]
El proceso ya ha alcanzado su límite de descriptores de archivo abiertos.
[ENFILE]
La tabla de archivos del sistema está llena.
[ENOTTY]
No hay una terminal de control y se especificó la bandera RPP_REQUIRE_TTY.

SEÑALES

readpassphrase() capturará las siguientes señales:

SIGALRM		SIGHUP		SIGINT
SIGPIPE		SIGQUIT		SIGTERM
SIGTSTP		SIGTTIN		SIGTTOU

Cuando se intercepta una de las señales anteriores, se restaurará el eco de la terminal si previamente se había desactivado. Si se había instalado un manejador de señales para la señal cuando se llamó a readpassphrase(), entonces se ejecutará ese manejador. Si no se había instalado previamente un manejador para la señal, se tomará la acción predeterminada según sigaction(2).

Las señales SIGTSTP, SIGTTIN y SIGTTOU (señales de parada generadas desde el teclado o debido a E/S de terminal de un proceso en segundo plano) se tratan de manera especial. Cuando el proceso se reanuda después de haberse detenido, readpassphrase() volverá a mostrar el mensaje y el usuario podrá entonces introducir una contraseña.

VER TAMBIÉN

sigaction(2), getpass(3)

ESTÁNDARES

La función readpassphrase() es una extensión de BSD y no debe usarse si se desea portabilidad.

HISTORIA

La función readpassphrase() apareció por primera vez en OpenBSD 2.9 y FreeBSD 4.6.
