RESIZECONS(8) Manual del Administrador del Sistema RESIZECONS(8)

NOMBRE

resizecons - cambia la idea del kernel sobre el tamaño de la consola

SINOPSIS

resizecons COLSxFILAS
resizecons -filas FILAS

DESCRIPCIÓN

El comando resizecons intenta cambiar el modo de video de la consola. Hay varios aspectos en esto: (a) el kernel debe saberlo, (b) el hardware debe saberlo, (c) los programas de usuario deben saberlo, (d) la fuente de la consola puede tener que ser adaptada.

(a) Se le informa al kernel del cambio usando el ioctl VT_RESIZE. Esto hace que el kernel reasigne memoria de pantalla de consola para todas las consolas virtuales, y puede fallar si no hay suficiente memoria. (En ese caso, intente primero desasignar algunas consolas virtuales.) Si este ioctl tiene éxito, pero un paso posterior falla (por ejemplo, porque no tiene permisos de root), puede quedarse con una pantalla muy desordenada.

La parte más difícil de esto es (b), ya que requiere conocimiento detallado del hardware de la tarjeta de video, y la configuración de numerosos registros. Solo cambiar el número de filas es un poco más sencillo, y resizecons intentará hacerlo él mismo, cuando se le dé la opción -filas. (Probablemente, se requerirán permisos de root.) El comando resizecons COLSxFILAS ejecutará restoretextmode -r COLSxFILAS (y por lo tanto requiere que tenga svgalib instalado). Aquí COLSxFILAS es un archivo que fue creado anteriormente por restoretextmode -w COLSxFILAS. Nuevamente, se requieren permisos de root, o restoretextmode tiene que ser suid root.

Para tratar con (c), resizecons hace un `stty filas FILAS columnas COLS' para cada consola activa (en el rango tty0..tty15), y envía una señal SIGWINCH a selection si encuentra el archivo /tmp/selection.pid.

Finalmente, (d) se maneja ejecutando un comando setfont. Lo más probable es que se cargue la fuente incorrecta, y es posible que desee ejecutar otro setfont usted mismo después.

ERRORES

resizecons no funciona en todo el hardware. Este comando solía llamarse resize, pero se renombró para evitar conflictos con otro comando del mismo nombre.

VER TAMBIÉN

setfont(8), stty(1), selection(1), restoretextmode(8), disalloc(8)
