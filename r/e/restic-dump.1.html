NOMBRE

restic dump - Imprimir un archivo respaldado en stdout

SINOPSIS

restic dump [flags] snapshotID archivo

DESCRIPCIÓN

El comando "dump" extrae archivos de un snapshot del repositorio. Si se selecciona un solo archivo, imprime su contenido en stdout. Las carpetas se emiten como un archivo tar (predeterminado) o zip que contiene el contenido de la carpeta especificada. Pase "/" como nombre de archivo para extraer todo el snapshot como un archivo.

El snapshotID especial "latest" se puede usar para usar el último snapshot en el repositorio.

Para incluir el contenido de la carpeta en la raíz del archivo, puede usar la sintaxis "snapshotID:subcarpeta", donde "subcarpeta" es una ruta dentro del snapshot.

ESTADO DE SALIDA

El estado de salida es 0 si el comando se completó con éxito. El estado de salida es 1 si hubo algún error. El estado de salida es 10 si el repositorio no existe. El estado de salida es 11 si el repositorio ya está bloqueado. El estado de salida es 12 si la contraseña es incorrecta.

OPCIONES

-a, --archive="tar" establece el formato del archivo como "tar" o "zip"

-h, --help[=false] ayuda para dump

-H, --host=[] considerar solo snapshots para este host, cuando se da el snapshotID "latest" (se puede especificar múltiples veces) (predeterminado: $RESTIC_HOST)

--path=[] considerar solo snapshots que incluyan esta ruta (absoluta), cuando se da el snapshotID "latest" (se puede especificar múltiples veces, los snapshots deben incluir todas las rutas especificadas)

--tag=[] considerar solo snapshots que incluyan tag[,tag,...], cuando se da el snapshotID "latest" (se puede especificar múltiples veces)

-t, --target="" escribe la salida en la ruta de destino

OPCIONES HEREDADAS DE COMANDOS PADRE

--cacert=[] archivo para cargar certificados raíz desde (predeterminado: usar certificados del sistema o $RESTIC_CACERT)

--cache-dir="" establece el directorio de caché. (predeterminado: usar el directorio de caché predeterminado del sistema)

--cleanup-cache[=false] eliminar automáticamente directorios de caché antiguos

--compression=auto modo de compresión (solo disponible para la versión 2 del formato del repositorio), uno de (auto|off|max) (predeterminado: $RESTIC_COMPRESSION)

--http-user-agent="" establece un agente de usuario http para las solicitudes http salientes

--insecure-no-password[=false] usa una contraseña vacía para el repositorio, debe pasarse a cada comando restic (inseguro)

--insecure-tls[=false] omite la verificación del certificado TLS al conectarse al repositorio (inseguro)

--json[=false] establece el modo de salida en JSON para comandos que lo admiten

--key-hint="" ID de clave de clave para intentar descifrar primero (predeterminado: $RESTIC_KEY_HINT)

--limit-download=0 limita las descargas a una tasa máxima en KiB/s. (predeterminado: ilimitado)

--limit-upload=0 limita las subidas a una tasa máxima en KiB/s. (predeterminado: ilimitado)

--no-cache[=false] no usar caché local

--no-extra-verify[=false] omitir verificación adicional de datos antes de la subida (ver documentación)

--no-lock[=false] no bloquear el repositorio, esto permite algunas operaciones en repositorios de solo lectura

-o, --option=[] establece una opción extendida (clave=valor, se puede especificar múltiples veces)

--pack-size=0 establece el tamaño del paquete de destino en MiB, los archivos de paquete creados pueden ser más grandes (predeterminado: $RESTIC_PACK_SIZE)

--password-command="" comando de shell para obtener la contraseña del repositorio de (predeterminado: $RESTIC_PASSWORD_COMMAND)

-p, --password-file="" archivo para leer la contraseña del repositorio desde (predeterminado: $RESTIC_PASSWORD_FILE)

-q, --quiet[=false] no mostrar un informe de progreso exhaustivo

-r, --repo="" repositorio para hacer copias de seguridad o restaurar desde (predeterminado: $RESTIC_REPOSITORY)

--repository-file="" archivo para leer la ubicación del repositorio desde (predeterminado: $RESTIC_REPOSITORY_FILE)

--retry-lock=0s reintentar bloquear el repositorio si ya está bloqueado, toma un valor como 5m o 2h (predeterminado: sin reintentos)

--stuck-request-timeout=5m0s duración después de la cual se reintentarán las solicitudes atascadas

--tls-client-cert="" ruta a un archivo que contiene el certificado de cliente TLS codificado en PEM y la clave privada (predeterminado: $RESTIC_TLS_CLIENT_CERT)

-v, --verbose[=0] ser verboso (especificar múltiples veces o un nivel usando --verbose=n, nivel/veces máximo es 2)
