DESCRIPCIÓN

Las funciones son un sistema bastante extensible para analizar varios archivos de configuración en tiempo de ejecución de una aplicación. El flujo del archivo de configuración se divide en las siguientes fases:

1.
Registro de manejadores.
2.
Lectura de los archivos de configuración para requisitos de análisis previo a MIB.
3.
Lectura y análisis de los archivos MIB textuales.
4.
Lectura de los archivos de configuración para directivas de configuración.
5.
Opcionalmente, volver a leer los archivos de configuración en una fecha posterior.

La idea es que la aplicación que llama pueda registrar manejadores para ciertos tokens especificados en ciertos archivos de configuración nombrados. Luego, se puede llamar a la función read_configs() para buscar todos los archivos de configuración relevantes, comparar la primera palabra de cada línea con la lista de tokens registrados y pasar el resto de la línea al manejador registrado apropiado.

REGISTRO DE UN MANEJADOR

register_config_handler()
Registra una rutina de manejo de configuración, que debe ser llamada para procesar directivas de configuración que comiencen con el token especificado. Por ejemplo:
register_config_handler("snmp", "exampleToken", example_handler, NULL, "ARG1 [ARG2]");
registraría la función example_handler() para que se llame cada vez que la primera palabra de una línea en el archivo(s) de configuración snmp.conf coincida con "exampleToken".
Llamar a los manejadores apropiados para procesar las directivas del archivo de configuración es responsabilidad de read_configs() (ver abajo).
register_const_config_handler()
Similar a la función register_config_handler(), pero la rutina del analizador se restringe explícitamente a no modificar la cadena que se está analizando.
register_prenetsnmp_mib_handler()
Similar a la función register_config_handler(), pero la rutina del manejador registrado se llamará *antes* de que se lean los MIB textuales. Esto se usa típicamente para tokens que afectarán la configuración del analizador MIB y normalmente solo se usará dentro de la propia biblioteca SNMP.
register_mib_handlers()
Rutina de inicialización para registrar los manejadores de configuración internos de la biblioteca SNMP.
unregister_config_handler()
Elimina el manejador de configuración registrado para el filePrefix y token especificados.
unregister_all_config_handlers()
Elimina todos los manejadores de configuración registrados.

Manejadores de Tokens

Las funciones manejadoras deben tener la siguiente firma:

void handler(const char *token, char *line);
o
void handler(const char *token, const char *line); br (si se registró usando register_const_config_handler)

La función se llamará con dos argumentos, el primero es el token que desencadenó la llamada a esta función (es decir, el token utilizado al registrar el manejador), y el segundo es el resto de la línea del archivo de configuración (es decir, todo lo que sigue al espacio en blanco después del token coincidente).

Manejadores de Liberación

Si la función manejadora de tokens asigna dinámicamente recursos al procesar una entrada de configuración, estos pueden necesitar ser liberados antes de volver a leer los archivos de configuración. Si el cuarto parámetro ( releaser ) pasado a register_config_handler no es NULL, entonces especifica una función que se llamará antes de volver a leer los archivos de configuración. Esta función debe liberar cualquier recurso asignado por la función manejadora de tokens y restablecer su noción de configuración a su valor predeterminado. La función manejadora de tokens entonces se puede llamar de nuevo de forma segura. No se pasan argumentos a la función manejadora de liberación de recursos.
Tenga en cuenta que esta función no se llama cuando el manejador se desregistra individualmente (pero *sí* se llama como parte de unregister_all_config_handlers() ).
