realpath(3) Manual de funciones de biblioteca realpath(3)

NOMBRE

realpath - devuelve la ruta canónica absoluta

BIBLIOTECA

Biblioteca C estándar (libc, -lc)

SINOPSIS

#include <limits.h>
#include <stdlib.h>
char *realpath(const char *restrict path,
               char *restrict resolved_path);
Requisitos de la macro de prueba de características para glibc (véase feature_test_macros(7)):

realpath():

    _XOPEN_SOURCE >= 500
        || /* glibc >= 2.19: */ _DEFAULT_SOURCE
        || /* glibc <= 2.19: */ _BSD_SOURCE

DESCRIPCIÓN

realpath() expande todos los enlaces simbólicos y resuelve las referencias a /./, /../ y caracteres '/' adicionales en la cadena terminada en nulo denominada por path para producir una ruta absoluta canónica. La ruta resultante se almacena como una cadena terminada en nulo, con un máximo de PATH_MAX bytes, en el búfer apuntado por resolved_path. La ruta resultante no tendrá componentes de enlace simbólico, /./ o /../.

Si resolved_path se especifica como NULL, entonces realpath() usa malloc(3) para asignar un búfer de hasta PATH_MAX bytes para almacenar la ruta resuelta, y devuelve un puntero a este búfer. El llamador debe liberar este búfer usando free(3).

VALOR DE RETORNO

Si no hay error, realpath() devuelve un puntero a resolved_path.

De lo contrario, devuelve NULL, el contenido del array resolved_path no está definido y errno se establece para indicar el error.

ERRORES

EACCES
Se denegó el permiso de lectura o búsqueda para un componente del prefijo de ruta.
EINVAL
path es NULL. (Antes de glibc 2.3, este error también se devuelve si resolved_path es NULL.)
EIO
Ocurrió un error de E/S al leer del sistema de archivos.
ELOOP
Se encontraron demasiados enlaces simbólicos al traducir la ruta.
ENAMETOOLONG
Un componente de una ruta excedió los caracteres NAME_MAX, o una ruta completa excedió los caracteres PATH_MAX.
ENOENT
El archivo nombrado no existe.
ENOMEM
Memoria agotada.
ENOTDIR
Un componente del prefijo de ruta no es un directorio.

ATRIBUTOS

Para obtener una explicación de los términos utilizados en esta sección, véase attributes(7).

Interfaz Atributo Valor
realpath () Seguridad de hilos MT-Safe

VERSIONES

Extensiones GNU

Si la llamada falla con EACCES o ENOENT y resolved_path no es NULL, entonces el prefijo de path que no es legible o no existe se devuelve en resolved_path.

ESTÁNDARES

POSIX.1-2008.

HISTORIAL

4.4BSD, POSIX.1-2001, Solaris.

POSIX.1-2001 dice que el comportamiento si resolved_path es NULL depende de la implementación. POSIX.1-2008 especifica el comportamiento descrito en esta página.

En 4.4BSD y Solaris, el límite de la longitud de la ruta es MAXPATHLEN (encontrado en <sys/param.h>). SUSv2 prescribe PATH_MAX y NAME_MAX, como se encuentra en <limits.h> o proporcionado por la función pathconf(3). Un fragmento de código típico sería


#ifdef PATH_MAX
  path_max = PATH_MAX;
#else
  path_max = pathconf(path, _PC_PATH_MAX);
  if (path_max <= 0)
    path_max = 4096;
#endif

(Pero véase la sección de BUGS.)

BUGS

La versión de la norma POSIX.1-2001 de esta función está rota por diseño, ya que es imposible determinar un tamaño adecuado para el búfer de salida, resolved_path. Según POSIX.1-2001, un búfer de tamaño PATH_MAX es suficiente, pero PATH_MAX no tiene por qué ser una constante definida, y puede tener que obtenerse utilizando pathconf(3). Y preguntar a pathconf(3) no ayuda realmente, ya que, por un lado, POSIX advierte que el resultado de pathconf(3) puede ser enorme y no apto para asignar memoria, y por otro lado, pathconf(3) puede devolver -1 para indicar que PATH_MAX no está limitado. La característica de resolved_path == NULL, no estandarizada en POSIX.1-2001, pero sí en POSIX.1-2008, permite evitar este problema de diseño.

VEASE TAMBIÉN

realpath(1), readlink(2), canonicalize_file_name(3), getcwd(3), pathconf(3), sysconf(3)

realpath(3)

NAME

realpath - devuelve la ruta canónica de un nombre de archivo

SYNOPSIS

#include <stdlib.h>

char *realpath(const char *<var>file</var>, char *<var>resolved_path</var>);

DESCRIPTION

La función realpath() devuelve la ruta canónica del archivo especificado por <var>file</var>. La ruta canónica es una ruta absoluta que no contiene componentes de directorio "." o "..", ni enlaces simbólicos. Los componentes de directorio redundantes se eliminan de la ruta y los enlaces simbólicos se resuelven.

Si <var>resolved_path</var> no es NULL, se asume que apunta a un buffer de al menos PATH_MAX bytes (definido en <limits.h>). La ruta canónica resultante se copia en este buffer.

Si <var>resolved_path</var> es NULL, realpath() asigna un buffer de memoria utilizando malloc(3). El programador es responsable de liberar este buffer con free(3) cuando ya no sea necesario.

La ruta canónica devuelta por realpath() siempre es una ruta absoluta, incluso si <var>file</var> es una ruta relativa. Si <var>file</var> es un nombre de archivo relativo, se resolverá con respecto al directorio de trabajo actual.

RETURN_VALUE

En caso de éxito, realpath() devuelve un puntero a la ruta canónica resuelta. Si se proporcionó un puntero <var>resolved_path</var>, se devuelve ese puntero. Si <var>resolved_path</var> era NULL, se devuelve un puntero al buffer asignado por malloc(3).

En caso de error, realpath() devuelve NULL y la variable global <var>errno</var> se establece para indicar el error.

ERRORS

EACCES: Se denegó el acceso de lectura o ejecución a un componente del prefijo de la ruta.

EBADF: Un descriptor de archivo utilizado internamente es inválido.

EFAULT: <var>file</var> o <var>resolved_path</var> apunta fuera de la copia de memoria accesible.

EINVAL: <var>file</var> es NULL.

EIO: Se produjo un error de entrada/salida.

ELOOP: Se encontraron demasiados enlaces simbólicos al resolver la ruta.

ENAMETOOLONG: La longitud de un nombre de archivo o de un componente de ruta excede PATH_MAX o NAME_MAX respectivamente.

ENOENT: Un componente de la ruta no existe o es un enlace simbólico roto.

ENOMEM: No hay suficiente memoria disponible para asignar un buffer para la ruta resuelta (si <var>resolved_path</var> era NULL).

ENOTDIR: Un componente de la ruta no es un directorio.

ERANGE: La ruta resultante es demasiado larga para ser almacenada en el buffer proporcionado.

ATTRIBUTES

Para obtener una explicación de los siguientes atributos, consulta attributes(7).

Se utiliza en el contexto de glibc, iconv, libidn, readline, threads. No aplica

POSIX.1-2001, POSIX.1-2008, C99.
