NOMBRE

restic-repair-snapshots - Reparar instantáneas

SINOPSIS

restic repair snapshots [flags] [ID de instantánea] [...]

DESCRIPCIÓN

El comando "repair snapshots" repara instantáneas rotas. Escanea las instantáneas dadas y genera nuevas con los directorios y contenidos de archivos dañados eliminados. Si las instantáneas rotas se eliminan, una ejecución de prune podrá limpiar el repositorio.

El comando depende de un índice correcto, ¡así que asegúrate de ejecutar "repair index" primero!

ADVERTENCIA

¡Reparar y eliminar instantáneas rotas causa pérdida de datos! Eliminará directorios rotos y modificará archivos rotos en las instantáneas modificadas.

Si los contenidos de los directorios y archivos aún están disponibles, la mejor opción es ejecutar "backup", que en ese caso es capaz de recuperar instantáneas existentes. ¡Solo usa el comando "repair snapshots" si necesitas recuperar una instantánea antigua y rota!

ESTADO DE SALIDA

El estado de salida es 0 si el comando se ejecutó correctamente. El estado de salida es 1 si hubo algún error. El estado de salida es 10 si el repositorio no existe. El estado de salida es 11 si el repositorio ya está bloqueado. El estado de salida es 12 si la contraseña es incorrecta.

OPCIONES

-n, --dry-run[=false] no hacer nada, solo imprimir lo que se haría

--forget[=false] eliminar las instantáneas originales después de crear las nuevas

-h, --help[=false] ayuda para snapshots

-H, --host=[] considerar solo instantáneas para este host (se puede especificar varias veces) (por defecto: $RESTIC_HOST)

--path=[] considerar solo instantáneas que incluyan esta ruta (absoluta) (se puede especificar varias veces, las instantáneas deben incluir todas las rutas especificadas)

--tag=[] considerar solo instantáneas que incluyan tag[,tag,...] (se puede especificar varias veces)

OPCIONES HEREDADAS DE COMANDOS PADRE

--cacert=[] archivo del que cargar certificados raíz (por defecto: usar certificados del sistema o $RESTIC_CACERT)

--cache-dir="" establecer el directorio de caché. (por defecto: usar el directorio de caché predeterminado del sistema)

--cleanup-cache[=false] eliminar automáticamente directorios de caché antiguos

--compression=auto modo de compresión (solo disponible para la versión 2 del formato de repositorio), uno de (auto|off|max) (por defecto: $RESTIC_COMPRESSION)

--http-user-agent="" establecer un agente de usuario http para las solicitudes http salientes

--insecure-no-password[=false] usar una contraseña vacía para el repositorio, se debe pasar a cada comando restic (inseguro)

--insecure-tls[=false] omitir la verificación del certificado TLS al conectarse al repositorio (inseguro)

--json[=false] establecer el modo de salida a JSON para comandos que lo soporten

--key-hint="" ID de clave de la clave a intentar descifrar primero (por defecto: $RESTIC_KEY_HINT)

--limit-download=0 limita las descargas a una tasa máxima en KiB/s. (por defecto: ilimitado)

--limit-upload=0 limita las subidas a una tasa máxima en KiB/s. (por defecto: ilimitado)

--no-cache[=false] no usar caché local

--no-extra-verify[=false] omitir verificación adicional de datos antes de la subida (ver documentación)

--no-lock[=false] no bloquear el repositorio, esto permite algunas operaciones en repositorios de solo lectura

-o, --option=[] establecer opción extendida (clave=valor, se puede especificar varias veces)

--pack-size=0 establecer el tamaño de paquete objetivo en MiB, los archivos de paquete creados pueden ser más grandes (por defecto: $RESTIC_PACK_SIZE)

--password-command="" comando de shell para obtener la contraseña del repositorio de (por defecto: $RESTIC_PASSWORD_COMMAND)

-p, --password-file="" archivo del que leer la contraseña del repositorio (por defecto: $RESTIC_PASSWORD_FILE)

-q, --quiet[=false] no mostrar informe de progreso detallado

-r, --repo="" repositorio al que hacer copia de seguridad o del que restaurar (por defecto: $RESTIC_REPOSITORY)

--repository-file="" archivo del que leer la ubicación del repositorio (por defecto: $RESTIC_REPOSITORY_FILE)

--retry-lock=0s reintentar bloquear el repositorio si ya está bloqueado, toma un valor como 5m o 2h (por defecto: sin reintentos)

--stuck-request-timeout=5m0s duración después de la cual se reintentarán las solicitudes bloqueadas

--tls-client-cert="" ruta a un archivo que contiene el certificado de cliente TLS y la clave privada codificados en PEM (por defecto: $RESTIC_TLS_CLIENT_CERT)

-v, --verbose[=0] ser verboso (especificar varias veces o un nivel usando --verbose=n, nivel/veces máximas es 2)
