RESIZE2FS(8) Manual del Administrador del Sistema RESIZE2FS(8)

NOMBRE

resize2fs - redimensionador de sistemas de archivos ext2/ext3/ext4

SINOPSIS

resize2fs [ -fFpPMbs ] [ -d flags-de-depuracion ] [ -S pasada-RAID ] [ -z archivo-deshacer ] dispositivo [ tamaño ]

DESCRIPCIÓN

El programa resize2fs redimensiona los sistemas de archivos ext2, ext3 o ext4. Puede ser utilizado para agrandar o encoger un sistema de archivos desmontado ubicado en dispositivo. Si el sistema de archivos está montado, puede ser utilizado para expandir el tamaño del sistema de archivos montado, asumiendo que el kernel y el sistema de archivos soportan el redimensionamiento en línea. (Los kernels Linux 2.6 modernos soportarán el redimensionamiento en línea para sistemas de archivos montados usando ext3 y ext4; los sistemas de archivos ext3 requerirán el uso de sistemas de archivos con la característica resize_inode habilitada.)

El parámetro tamaño especifica el nuevo tamaño solicitado del sistema de archivos. Si no se especifican unidades, las unidades del parámetro tamaño serán el tamaño de bloque del sistema de archivos. Opcionalmente, el parámetro tamaño puede ir seguido por uno de los siguientes designadores de unidades: 'K', 'M', 'G', 'T' (ya sea en mayúsculas o minúsculas) o 's' para kilobytes, megabytes, gigabytes, terabytes o sectores de 512 bytes en potencia de dos, respectivamente. El tamaño del sistema de archivos nunca puede ser mayor que el tamaño de la partición. Si no se especifica el parámetro tamaño, se usará por defecto el tamaño de la partición.

El programa resize2fs no manipula el tamaño de las particiones. Si desea agrandar un sistema de archivos, debe asegurarse de poder expandir primero el tamaño de la partición subyacente. Esto se puede hacer usando fdisk(8) eliminando la partición y recreándola con un tamaño mayor o usando lvextend(8), si está utilizando el gestor de volúmenes lógicos lvm(8). Al recrear la partición, asegúrese de crearla con el mismo cilindro de inicio del disco que antes. De lo contrario, la operación de redimensionamiento ciertamente no funcionará y podría perder todo su sistema de archivos. Después de ejecutar fdisk(8), ejecute resize2fs para redimensionar el sistema de archivos ext2 y usar todo el espacio en la partición recién ampliada.

Si desea encoger una partición ext2, primero use resize2fs para encoger el tamaño del sistema de archivos. Luego puede usar fdisk(8) para encoger el tamaño de la partición. Al encoger el tamaño de la partición, ¡asegúrese de no hacerla más pequeña que el nuevo tamaño del sistema de archivos ext2!

Las opciones -b y -s habilitan y deshabilitan la característica 64 bits, respectivamente. El programa resize2fs, por supuesto, se encargará de redimensionar los descriptores de grupo de bloques y mover otros bloques de datos fuera del camino, según sea necesario. No es posible redimensionar el sistema de archivos concurrentemente con el cambio del estado de 64 bits.

OPCIONES

-b
Activa la característica 64 bits, redimensiona los descriptores de grupo según sea necesario y mueve otros metadatos fuera del camino.
-d flags-de-depuracion
Activa varias características de depuración de resize2fs, si han sido compiladas en el binario. flags-de-depuracion debe ser calculado sumando los números de las características deseadas de la siguiente lista:
2 - Depurar reubicaciones de bloques
4 - Depurar reubicaciones de inodos
8 - Depurar movimiento de la tabla de inodos
16 - Imprimir información de tiempos
32 - Depurar el cálculo del tamaño mínimo del sistema de archivos (-M)
-f
Fuerza a resize2fs a proceder con la operación de redimensionamiento del sistema de archivos, anulando algunas comprobaciones de seguridad que resize2fs normalmente aplica.
-F
Vacía las cachés de búfer del dispositivo del sistema de archivos antes de comenzar. Solo es realmente útil para realizar pruebas de tiempo de resize2fs.
-M
Encoge el sistema de archivos para minimizar su tamaño tanto como sea posible, dados los archivos almacenados en el sistema de archivos.
-p
Imprime barras de progreso de porcentaje para cada fase de resize2fs durante una operación de redimensionamiento fuera de línea (no trivial), para que el usuario pueda seguir el progreso del programa. (Para operaciones de redimensionamiento muy rápidas, es posible que no se muestren barras de progreso.)
-P
Imprime una estimación del número de bloques del sistema de archivos si el sistema de archivos se encoge usando la opción -M de resize2fs y luego sale.
-s
Desactiva la característica 64 bits y libera los bloques que ya no están en uso.
-S pasada-RAID
El programa resize2fs determinará heurísticamente la pasada RAID que se especificó cuando se creó el sistema de archivos. Esta opción permite al usuario especificar explícitamente una configuración de pasada RAID para ser utilizada por resize2fs en su lugar.
-z archivo-deshacer
Antes de sobrescribir un bloque del sistema de archivos, escribe el contenido anterior del bloque en un archivo de deshacer. Este archivo de deshacer puede ser utilizado con e2undo(8) para restaurar el contenido anterior del sistema de archivos en caso de que algo salga mal. Si se pasa una cadena vacía como argumento de archivo-deshacer, el archivo de deshacer se escribirá en un archivo llamado resize2fs-dispositivo.e2undo en el directorio especificado a través de la variable de entorno E2FSPROGS_UNDO_DIR.

ADVERTENCIA: El archivo de deshacer no se puede utilizar para recuperarse de un corte de energía o un fallo del sistema.

ERRORES CONOCIDOS

El tamaño mínimo del sistema de archivos estimado por resize2fs puede ser incorrecto, especialmente para sistemas de archivos con tamaños de bloque de 1k y 2k.
