READLINK(1) Comandos de usuario READLINK(1)

NOMBRE

readlink - muestra el valor de los enlaces simbólicos o nombres canónicos de archivos

SINOPSIS

readlink [OPCIÓN]... ARCHIVO...

DESCRIPCIÓN

realpath(1) es un mejor comando para la funcionalidad de canonización.

Muestra el valor de un enlace simbólico o el nombre canónico de un archivo.

-f, --canonicalizar
canoniza siguiendo cada enlace simbólico en cada componente del nombre dado recursivamente; todos los componentes excepto el último deben existir.
-e, --canonicalizar-existente
canoniza siguiendo cada enlace simbólico en cada componente del nombre dado recursivamente, todos los componentes deben existir.
-m, --canonicalizar-faltante
canoniza siguiendo cada enlace simbólico en cada componente del nombre dado recursivamente, sin requisitos de existencia de componentes.
-n, --sin-nueva-linea
no mostrar el delimitador final.

-q, --silencioso

-s, --callado
suprime la mayoría de los mensajes de error (activado por defecto si POSIXLY_CORRECT no está establecido).
-v, --verboso
muestra mensajes de error (activado por defecto si POSIXLY_CORRECT está establecido).
-z, --cero
termina cada línea de salida con NULO, no con una nueva línea.
--ayuda
muestra esta ayuda y sale.
--version
muestra información de la versión y sale.
