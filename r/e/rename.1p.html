rename(1p)

Paquete: perl-rename

Licencias: GPL-1.0-or-later, Artistic-1.0-Perl

RENAME(1) Documentación de Perl contribuida por el usuario RENAME(1)

NOMBRE

rename - renombra múltiples archivos usando expresiones de perl

SINOPSIS

rename [-bcfgilnv] [-B prefijo] [-C comando] [-S sufijo] [-V método] [-Y prefijo] [-z sufijo] [--backup] [--command=comando] [--copy] [--basename-prefix=prefijo] [--dry-run] [--force] [--help] [--no-stdin] [--interactive] [--just-print] [--link-only] [--prefix=prefijo] [--suffix=sufijo] [--verbose] [--version-control=método] [--version] expresion_perl [archivos]...

DESCRIPCIÓN

rename renombra los nombres de archivo proporcionados de acuerdo con la regla especificada como el primer argumento. El argumento es una expresión de Perl que se espera que modifique la cadena $_ para al menos algunos de los nombres de archivo especificados. Si un nombre de archivo dado no es modificado por la expresión, no será renombrado. Si no se proporcionan nombres de archivo en la línea de comandos, los nombres de archivo se leerán a través de la entrada estándar (a menos que se proporcione --no-stdin en la línea de comandos).

Si un archivo de destino no es escribible, la entrada estándar es una tty, y la opción -f o --force no se proporciona, rename pregunta al usuario si desea sobrescribir el archivo. Si la respuesta no comienza con `y' o `Y', el archivo se omite.

OPCIONES

-b, --backup
Crear archivos de copia de seguridad. Es decir, al estar a punto de sobrescribir un archivo, renombrar el original en lugar de eliminarlo. Consulte la opción -V o --version-control para obtener detalles sobre cómo se determinan los nombres de los archivos de copia de seguridad.
-B prefijo, --prefix=prefijo
Usar el método simple para determinar los nombres de los archivos de copia de seguridad (consulte la opción -V método o --version-control=método), y anteponer prefijo al nombre de un archivo al generar su nombre de archivo de copia de seguridad.
-c, --copy
Copiar archivos a los nuevos nombres en lugar de renombrarlos. Esto conservará los archivos originales.
-f, --force
Eliminar los archivos de destino existentes y nunca preguntar al usuario.
-h, --help
Imprimir un resumen de las opciones y salir.
--no-stdin
Deshabilitar la lectura de nombres de archivo desde STDIN. Úselo cuando su shell tenga nullglob habilitado para asegurarse de que rename no espere entrada.
-i, --interactive
Preguntar si sobrescribir cada archivo de destino que ya existe. Si la respuesta no comienza con `y' o `Y', el archivo se omite.
-l, --link-only
Enlazar archivos a los nuevos nombres en lugar de renombrarlos. Esto conservará los archivos originales.
-n, --just-print, --dry-run
Hacer todo excepto el renombrado real, en su lugar solo imprimir el nombre de cada archivo que sería renombrado. Cuando se usa junto con --verbose, también imprimir los nombres de las copias de seguridad (que pueden ser correctos o no dependiendo del renombrado anterior).
-v, --verbose
Imprimir el nombre de cada archivo antes de renombrarlo.
-V método, --version-control=método
Usar método para determinar los nombres de los archivos de copia de seguridad. El método también puede especificarse mediante la variable de entorno RENAME_VERSION_CONTROL (o si no está establecida, VERSION_CONTROL), que es anulada por esta opción. Esta opción no afecta si se crean archivos de copia de seguridad; solo afecta el nombre de cualquier archivo de copia de seguridad que se cree.

El valor de método es como la variable `version-control' de GNU Emacs; rename también reconoce sinónimos que son más descriptivos. Los valores válidos son (se aceptan abreviaturas únicas):

existing o nil
Crear copias de seguridad numeradas de archivos que ya las tienen, de lo contrario, copias de seguridad simples. Este es el valor predeterminado.
numbered o t
Crear copias de seguridad numeradas. El nombre del archivo de copia de seguridad numerada para F es F.~N~ donde N es el número de versión.
simple o never
Crear copias de seguridad simples. Las opciones -B o --prefix, -Y o --basename-prefix, y -z o --suffix especifican el nombre del archivo de copia de seguridad simple. Si ninguna de estas opciones se proporciona, se utiliza un sufijo de copia de seguridad simple, ya sea el valor de la variable de entorno SIMPLE_BACKUP_SUFFIX si está establecida, o ~ en caso contrario.
--version
Imprimir información de la versión en la salida estándar y luego salir con éxito.
-Y prefijo, --basename-prefix=prefijo
Usar el método simple para determinar los nombres de los archivos de copia de seguridad (consulte la opción -V método o --version-control=método), y anteponer prefijo al nombre base de un nombre de archivo al generar su nombre de archivo de copia de seguridad. Por ejemplo, con -Y .del/ el nombre del archivo de copia de seguridad simple para a/b/foo es a/b/.del/foo.
-z sufijo, -S sufijo, --suffix=sufijo
Usar el método simple para determinar los nombres de los archivos de copia de seguridad (consulte la opción -V método o --version-control=método), y añadir sufijo al nombre de un archivo al generar su nombre de archivo de copia de seguridad.
--shell-completion=shell, --shellcompletion=shell
Generar código de shell para la finalización de parámetros para bash o zsh.

EJEMPLOS

Para renombrar todos los archivos que coincidan con *.bak para eliminar la extensión, puede escribir

rename 's/\e.bak$//' *.bak

Para traducir nombres en mayúsculas a minúsculas, usaría

rename 'y/A-Z/a-z/' *

Más ejemplos:

    rename 's/\.flip$/.flop/' *     # renombrar *.flip a *.flop
    rename s/flip/flop/ *           # renombrar *flip* a *flop*
    rename 's/^s\.(.*)/$1.X/' *     # cambiar los nombres de archivo sccs
    rename 's/\$/.orig/' */*.[ch]    # añadir .orig a los archivos fuente en */
    rename 'y/A-Z/a-z/' *           # convertir a minúsculas todos los nombres de archivo en .
    rename 'y/A-Z/a-z/ if -B' *     # lo mismo, ¡pero solo binarios!
o incluso
    rename chop *~                  # restaurar todos los archivos de copia de seguridad ~

ENTORNO

Se utilizan dos variables de entorno, SIMPLE_BACKUP_SUFFIX y VERSION_CONTROL. Consulte "OPCIONES".

VER TAMBIÉN

mv(1) y perl(1)

DIAGNÓSTICOS

Si proporciona una expresión Perl inválida, obtendrá un error de sintaxis.

AUTOR

Peder Stray <pederst@cpan.org>, script original de Larry Wall.

ERRORES

rename

perldoc rename(1p)

Usage

rename [options] expression replacement file...

This script renames the specified files by renaming them according to the regular expression and replacement string given, or by the substitution given by the perl expression. The perl expression must be a valid expression that, when evaluated, returns a string that will be the new name of the file.

The most common cause of failure is if the expression or replacement string are not correctly quoted, so that the shell interprets them, instead of passing them through to rename.

The expression is a Perl expression, which can be a regular expression with substitution. The file name is passed to the expression as the variable $f.

For example, to change all files from .htm to .html, you could use:

rename 's/\.htm$/.html/' *.htm

This is equivalent to the command:

rename '$_ = 's/\.htm$/.html/'' *

Which is the same as:

rename 's/\.htm$/.html/' *

If the expression starts with a - or a / then it is assumed to be a perl expression. Otherwise, it is assumed to be a regular expression to be used in a substitution.

If the expression does not contain any of the characters x, a, i, n, c, p, t, e, s, m, g, etc., then the expression is assumed to be a replacement string.

If no files are given, the files are read from standard input.

Options

-v
verbose. Print what is being done.
-n
dry run. Print what would be done, but don't change anything.
-0
null-terminated filenames. Useful for filenames containing spaces or other special characters.
-e
expression. The expression to be evaluated. This is useful when the expression starts with a dash.
-f
force. Overwrite existing files without prompting.

Examples

Rename all files in the current directory from .htm to .html: 

rename 's/\.htm$/.html/' *.htm

Remove all trailing spaces from filenames in the current directory: 

rename 's/\s+$//' *

Prepend 'backup_' to all filenames in the current directory: 

rename 's/^/backup_/' *

Change all filenames in the current directory to lowercase: 

rename 'y/A-Z/a-z/' *

Remove the first 3 characters from all filenames in the current directory: 

rename 's/^.{3}//' *

Environment

No special environment variables are used.

See also

mv(1), sed(1), perl(1)

Diagnostics

Prints an error message and exits with a non-zero status if the expression is invalid or if any file cannot be renamed.
