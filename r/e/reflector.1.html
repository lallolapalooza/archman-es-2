NOMBRE

reflector - recuperar y filtrar la lista de espejos más reciente de Pacman

SINOPSIS

reflector [argumentos]

DESCRIPCIÓN

reflector es un script de Python y un módulo de Python asociado que puede recuperar datos actualizados de espejos de Arch Linux de la interfaz web del Estado de Espejos (https://www.archlinux.org/mirrors/status/).

ARGUMENTOS

Ver reflector --help.

EJEMPLOS

Imprimir la lista de espejos más reciente en STDOUT:

reflector

Ordenar los cinco espejos sincronizados más recientemente por velocidad de descarga y sobrescribir la lista de espejos local:

reflector --latest 5 --sort rate --save /etc/pacman.d/mirrorlist

Seleccionar los 200 espejos HTTP o HTTPS sincronizados más recientemente, ordenarlos por velocidad de descarga y sobrescribir el archivo /etc/pacman.d/mirrorlist:

reflector --latest 200 --protocol http,https --sort rate --save /etc/pacman.d/mirrorlist

Seleccionar los espejos HTTPS sincronizados en las últimas 12 horas y ubicados en Francia o Alemania, ordenarlos por velocidad de descarga y sobrescribir el archivo /etc/pacman.d/mirrorlist con los resultados:

reflector --country France,Germany --age 12 --protocol https --sort rate --save /etc/pacman.d/mirrorlist

INTEGRACIÓN CON SYSTEMD

Reflector incluye unidades de servicio y temporizador de systemd que pueden usarse para actualizar automáticamente la lista de espejos de Pacman. Para usar el temporizador, edite el archivo de configuración en /etc/xdg/reflector/reflector.conf y luego habilite el temporizador con

systemctl enable reflector.timer
systemctl start reflector.timer

Verifique el estado con systemctl list-timers. Para actualizar la lista de espejos inmediatamente en lugar de esperar la operación programada, ejecute systemctl start reflector.service.
