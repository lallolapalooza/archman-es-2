NOMBRE

realminit - Crea nuevos registros de dominio para un archivo de dominios de DNSSEC-Tools.

SINOPSIS

realminit [opciones] <dominio1> ... <dominioN>

DESCRIPCIÓN

realminit crea nuevas entradas de dominio para un archivo realms. dtrealms administra múltiples entornos de cambio de DNSSEC activos simultáneamente. Cada entorno de cambio, llamado dominio, se define en un archivo realms. dtrealms utiliza este archivo para determinar cómo ejecutar el entorno de cambio. Esto es útil para cosas como administrar colecciones muy grandes de zonas, segregar zonas de clientes y realizar pruebas de software.

Las entradas de dominio recién generadas se escriben en la salida estándar, a menos que se especifique la opción -out.

Un archivo realms contiene varias entradas, una para cada dominio administrado. Una entrada de dominio tiene este formato:

dominio "ejemplo"
    estado          "activo"
    directorioconfig  "/usr/realms/configs/ejemplo"
    directoríostado     "/usr/realms/states/ejemplo"
    directoríodominios      "/usr/realms/realms-files/ejemplo"
    archivorollrec       "ejemplo.rrf"
    administrador  "bob@cat.ejemplo.com"
    mostrar         "1"
    gestor         "rollerd"
    argumentos         "-mostrar -nivel-log fase"

Se pueden crear múltiples entradas de dominio con una sola ejecución de realminit. Excepto por el campo de nombre de la entrada, las entradas serán exactamente las mismas a menos que se utilice el metacaracter '=' en las opciones de línea de comandos. Si los valores de las opciones configdir, statedir, realmdir, rollrec, administrator, args, o user contienen un '=', este será reemplazado por el nombre del dominio al construir la entrada. Consulte la sección EJEMPLOS para ver ejemplos de cómo realminit utiliza las opciones.

OPCIONES

A realminit se le pueden dar las siguientes opciones:

-activo
Esto indica que dtrealms debe iniciar el dominio cuando se inicie dtrealms. Los dominios están activos por defecto.
-administrador
Esta es la dirección de correo electrónico del administrador del dominio.
-argumentos
Este es un conjunto de argumentos de línea de comandos que se pasan al gestor de cambios del dominio cuando se inicia el dominio.
-directorioconfig
Este es el directorio de configuración del dominio. Contendrá archivos como el archivo de configuración de DNSSEC-Tools para ese dominio.
-mostrar
Esto indica si el dominio debe incluirse en la salida de grandvizier.
-inactivo
Esto indica que dtrealms no debe iniciar el dominio cuando se inicie dtrealms.
-gestor
Este es el gestor de cambios para el dominio. rollerd es el gestor de cambios por defecto, pero se pueden utilizar otros gestores.
-out archivo-salida
Las nuevas entradas de dominio se añadirán a archivo-salida. El archivo se creará si no existe.

Si no se proporciona esta opción, las nuevas entradas de archivorollrec se escribirán en la salida estándar.

-directoriodominios
Este es el directorio de datos del dominio. Se espera que este directorio contenga el archivo rollrec, archivos de zona, archivos keyrec y archivos de clave para las zonas de ese dominio.
-archivorollrec
Esta es la ruta al archivo rollrec del dominio. Se utiliza para controlar las acciones de cambio para el dominio. Si no es una ruta absoluta, se asumirá que es relativa al campo realmdir.
-directoríostado
Este es el directorio de estado del dominio. Contendrá archivos como el archivo de bloqueo rollrec de ese dominio y el socket de comunicaciones de rollerd. Si el statedir no está definido para un dominio, se utilizará el configdir del dominio para ese valor.
-usuario
Este es el usuario con el que se ejecuta el dominio. (Esto aún no está implementado en dtrealms.)
-ayuda
Mostrar un mensaje de uso.
-Versión
Mostrar información de la versión de realminit y DNSSEC-Tools.

EJEMPLOS

Las siguientes opciones deberían dejar claro cómo realminit maneja las opciones y los nuevos dominios. El Ejemplo 1 mostrará el registro de dominio completo. Por brevedad, los ejemplos restantes solo mostrarán los campos relevantes para ese ejemplo. Ejemplos adicionales también utilizarán formas abreviadas de los nombres de las opciones.

Ejemplo 1. Un dominio, con -directoríostado

Este ejemplo muestra el dominio generado al proporcionar a realminit un solo dominio.

$ realminit -activo -directorioconfig /realms/confs/ejemplo -directoríostado /realms/states/ejemplo -directoriodominios /realms/realms/ejemplo -archivorollrec ejemplo.rrf -admin bob@cat.ejemplo.com -argumentos ""-nivel-log fase -archivolog logger"" ejemplo
dominio       "ejemplo"
    estado           "activo"
    directorioconfig       "/realms/confs/ejemplo"
    directoríostado        "/realms/states/ejemplo"
    directoriodominios        "/realms/realms/ejemplo"
    archivorollrec         "ejemplo.rrf"
    administrador   "bob@cat.ejemplo.com"
    mostrar         "1"
    gestor         "rollerd"
    argumentos            "-nivel-log fase -archivolog logger"

Ejemplo 2. Un dominio, sin -directoríostado

Este ejemplo muestra el dominio generado al proporcionar a realminit un solo dominio.

$ realminit -activo -directorioconfig /realms/confs/ejemplo -directoriodominios /realms/realms/ejemplo -archivorollrec ejemplo.rrf -admin bob@cat.ejemplo.com -argumentos ""-nivel-log fase -archivolog logger"" ejemplo
dominio       "ejemplo"
    estado           "activo"
    directorioconfig       "/realms/confs/ejemplo"
    directoríostado        "/realms/confs/ejemplo"
    ...
