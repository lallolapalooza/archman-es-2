REPO(1) Manual de Repo REPO(1)

NOMBRE

repo - descripción general de repo - página del manual de descripción general de repo

SINOPSIS

repo overview [--current-branch] [<proyecto>...]

DESCRIPCIÓN

Resumen

Muestra un resumen de las ramas de proyectos no fusionadas

OPCIONES

-h, --help
muestra este mensaje de ayuda y sale
-c, --current-branch
considera solo las ramas en las que se está trabajando actualmente
--no-current-branch
considera todas las ramas locales

Opciones de registro:

-v, --verbose
muestra toda la salida
-q, --quiet
solo muestra errores

Opciones multi-manifiesto:

--outer-manifest
opera comenzando desde el manifiesto más externo
--no-outer-manifest
no opera en manifiestos externos
--this-manifest-only
opera solo en este manifiesto (sub)manifiesto
--no-this-manifest-only, --all-manifests
opera en este manifiesto y sus submanifiestos

Ejecuta `repo help overview` para ver el manual detallado.

DETALLES

El comando 'repo overview' se utiliza para mostrar un resumen de las ramas de los proyectos y listar cualquier commit local que aún no se haya fusionado en el proyecto.

La opción -c/--current-branch se puede usar para restringir la salida a solo las ramas que están actualmente en uso en cada proyecto. Por defecto, se muestran todas las ramas.
