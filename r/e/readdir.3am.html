READDIR(3am) Módulos de extensión de GNU Awk READDIR(3am)

NOMBRE

readdir - analizador de entrada de directorios para gawk

SINOPSIS

@load "readdir"

BEGIN { PROCINFO["readdir_override"] = cualquier_valor } # opcional

DESCRIPCIÓN

La extensión readdir agrega un analizador de entrada para directorios.

Cuando esta extensión está en uso, en lugar de omitir los directorios nombrados en la línea de comandos (o con getline), se leen, y cada entrada se devuelve como un registro.

El registro consta de tres campos separados por barras. Los dos primeros son el número de inodo y el nombre del archivo, y el tercer campo es una sola letra que indica el tipo de archivo: f para archivo, d para directorio, b para un dispositivo de bloques, c para un dispositivo de caracteres, p para una FIFO, l para un enlace simbólico o s para un socket.

En sistemas donde la entrada del directorio contiene el tipo de archivo, el tercer campo se completa con esa información. En sistemas sin la información del tipo de archivo, la extensión recurre a llamar a stat(2), para proporcionar la información. Por lo tanto, el tercer campo nunca debe ser u (desconocido).

Normalmente, al leer directorios, deberías establecer FS igual a "/". Sin embargo, puedes optar por crear PROCINFO["readdir_override"] (con cualquier valor). Si este elemento existe cuando se abre el directorio, la extensión establece automáticamente los campos de cada registro por ti.

Por defecto, si un directorio no se puede abrir (debido a problemas de permisos, por ejemplo), gawk saldrá. Al igual que con los archivos regulares, esta situación se puede manejar usando una regla BEGINFILE que verifique ERRNO e imprima un error o maneje el problema de otra manera.

EJEMPLO

@load "readdir"
...
BEGIN { FS = "/" }
{ print "nombre de archivo es", $2 }
