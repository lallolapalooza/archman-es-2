REBAR3(1) Manual de comandos generales REBAR3(1)

NOMBRE

rebar3 - herramienta para trabajar con proyectos Erlang

SINOPSIS

rebar3 --version

rebar3 help

rebar3 comando [opciones] ...

DESCRIPCIÓN

Rebar3 es una herramienta Erlang que facilita la creación, desarrollo y lanzamiento de librerías, aplicaciones y sistemas Erlang de forma repetible.

Documentación completa en http://www.rebar3.org/

COMANDOS ESENCIALES

Para la lista completa de comandos, consulte la sección COMANDOS.

Con rebar3 help <tarea>, los comandos y plugins mostrarán su propia información de ayuda.

compile
Compila el proyecto actual
new (help [plantilla])|plantilla
Muestra información sobre plantillas o usa una
update
Obtiene la versión más reciente del índice Hex
do comando[,comando,...]
Ejecuta uno o más comandos en una secuencia
shell
Inicia el proyecto actual en un REPL. Luego puede usar r3:do(tarea) para llamarlo en el proyecto sin perder el estado actual.

COMANDOS

as
Proveedor de orden superior para ejecutar múltiples tareas en una secuencia como ciertos perfiles.
clean [-a|--all] [-p|--profile]
Elimina los archivos compilados de beam de las aplicaciones.
--all: Limpia todas las aplicaciones, incluidas las dependencias
--profile: Limpia bajo un perfil. Equivalente a `rebar3 as <perfil> clean`
compile [-d|--deps_only]
Compila archivos .app.src y .erl de las aplicaciones.
--deps_only: Solo compila dependencias, no se compilarán las aplicaciones del proyecto.
cover [-r|--reset] [-v|--verbose] [-m|--min_coverage]
Realiza un análisis de cobertura.
--reset: Restablece todos los datos de cobertura.
--verbose: Imprime el análisis de cobertura.
--min_coverage: Exige un porcentaje de cobertura requerido para tener éxito (0..100)
ct [--dir] [--suite] [--group] [--case] [--label] [--config] [--spec] [--join_specs] [--allow_user_terms] [--logdir] [--logopts] [--verbosity] [-c|--cover] [--cover_export_name] [--repeat] [--duration] [--until] [--force_stop] [--basic_html] [--stylesheet] [--decrypt_key] [--decrypt_file] [--abort_if_missing_suites] [--multiply_timetraps] [--scale_timetraps] [--create_priv_dir] [--include] [--readable] [-v|--verbose] [--name] [--sname] [--setcookie] [--sys_config] [--compile_only] [--retry]
Ejecuta Pruebas Comunes (Common Tests).
--dir: Lista de directorios adicionales que contienen suites de pruebas
--suite: Lista de suites de pruebas a ejecutar
--group: Lista de grupos de pruebas a ejecutar
--case: Lista de casos de prueba a ejecutar
--label: Etiqueta de prueba
--config: Lista de archivos de configuración
--spec: Lista de especificaciones de prueba
--join_specs: Fusiona todas las especificaciones de prueba y realiza una única ejecución de prueba
--allow_user_terms: Permite valores de configuración definidos por el usuario en los archivos de configuración
--logdir: Carpeta de registro
--logopts: Opciones para el registro de pruebas comunes
--verbosity: Verbosidad
--cover: Genera datos de cobertura
--cover_export_name: Nombre base del archivo de datos de cobertura a escribir
--repeat: Cuántas veces repetir las pruebas
--duration: Duración máxima (formato: HHMMSS)
--until: Ejecutar hasta (formato: HHMMSS)
--force_stop: Detener forzosamente en caso de tiempo de espera de prueba (true | false | skip_rest)
--basic_html: Muestra HTML básico
--stylesheet: Hoja de estilos CSS a aplicar a la salida HTML
--decrypt_key: Ruta a la clave para descifrar la configuración
--decrypt_file: Ruta al archivo que contiene la clave para descifrar la configuración
--abort_if_missing_suites: Aborta si faltan suites
--multiply_timetraps:
--scale_timetraps: Escala los timetraps
--create_priv_dir: Crea el directorio priv (auto_per_run | auto_per_tc | manual_per_tc)
--include: Directorios que contienen archivos de inclusión adicionales
--readable: Muestra los nombres de los casos de prueba y solo muestra los registros en la consola en caso de fallos (true | compact | false)
--verbose: Salida detallada
--name: Da un nombre largo al nodo
--sname: Da un nombre corto al nodo
--setcookie: Establece la cookie si el nodo está distribuido
--sys_config: Lista de archivos de configuración de aplicaciones
--compile_only: Compila módulos en el proyecto con la configuración de prueba pero no ejecuta las pruebas
--retry: Característica experimental. Si se encuentra alguna especificación para pruebas fallidas anteriormente, las ejecuta.

ENTORNO

Las variables de entorno permiten el control general de rebar3 entre los límites de los comandos.

REBAR_PROFILE
Elegir un perfil predeterminado. Por defecto es default
HEX_CDN
Elegir un espejo de hex alternativo.
REBAR_CACHE_DIR
Ubicación del directorio para la caché local. Por defecto es hex.pm.
QUIET
Mostrar solo errores.
DEBUG
Mostrar información de depuración.
REBAR_COLOR=high|low
Cuánta color mostrar en la terminal. Por defecto es high.
REBAR_CONFIG
Nombre de los archivos de configuración de rebar. Por defecto es rebar.config
REBAR_GIT_CLONE_OPTIONS
Argumentos para añadir después de cada operación de git clone. Por ejemplo, el valor --reference ~/.cache/repos.reference permite crear una caché de todos los repositorios obtenidos en las compilaciones
