NOMBRE

revtwoway - Extensión de procesador bidireccional de ejemplo para invertir cadenas

SINOPSIS

@load "revtwoway"

BEGIN {
    cmd = "/magic/mirror"
    print "hello, world" |& cmd
    cmd |& getline result
    print result
    close(cmd)
}

DESCRIPCIÓN

La extensión revtwoway añade un procesador bidireccional simple que invierte los caracteres de cada línea que se le envía para ser leída de nuevo por el programa AWK. Su propósito principal es mostrar cómo escribir una extensión bidireccional, aunque también puede ser ligeramente entretenido.
