REPQUOTA(8) Manual del Administrador del Sistema REPQUOTA(8)

NOMBRE

repquota - resumir cuotas para un sistema de archivos

SINOPSIS

/usr/sbin/repquota [ -vspiugP ] [ -c | -C ] [ -t | -n ] [ -F nombre-formato ] sistema-de-archivos...

/usr/sbin/repquota [ -avtpsiugP ] [ -c | -C ] [ -t | -n ] [ -F nombre-formato ]

DESCRIPCIÓN

repquota imprime un resumen del uso del disco y las cuotas para los sistemas de archivos especificados. Para cada usuario, se imprime el número actual de archivos y la cantidad de espacio (en kilobytes), junto con los límites de cuota establecidos con edquota(8) o setquota(8). En la segunda columna, repquota imprime dos caracteres que marcan qué límites se han excedido. Si el usuario ha superado su límite blando de espacio o ha alcanzado su límite duro de espacio en caso de que el límite blando no esté establecido, el primer carácter será '+'. De lo contrario, el carácter impreso será '-'. El segundo carácter denota el estado del uso de inodos de forma análoga.

repquota debe traducir los IDs de todos los usuarios/grupos/proyectos a nombres (a menos que se haya especificado la opción -n), por lo que puede tardar un tiempo en imprimir toda la información. Para que la traducción sea lo más rápida posible, repquota intenta detectar (leyendo /etc/nsswitch.conf) si las entradas se almacenan en un archivo de texto plano estándar o en una base de datos, y traduce lotes de 1024 nombres o cada nombre individualmente. Puede anular esta autodetección con las opciones -c o -C.

OPCIONES

-a, --all
Informar sobre todos los sistemas de archivos indicados en /etc/mtab como de lectura/escritura con cuotas.
-v, --verbose
Informar de todas las cuotas, incluso si no hay uso. También ser más detallado sobre la información del archivo de cuotas.
-c, --cache
Almacenar en caché las entradas para informar y traducir uids/gids a nombres en lotes grandes escaneando todos los usuarios (predeterminado). Este es un comportamiento bueno (rápido) cuando se utiliza el archivo /etc/passwd.
-C, --no-cache
Traducir entradas individuales. Esto es más rápido cuando los usuarios están almacenados en una base de datos.
-t, --truncate-names
Truncar nombres de usuario/grupo de más de 9 caracteres. Esto da como resultado una salida más limpia cuando existen dichos nombres.
-n, --no-names
No resolver UIDs/GIDs a nombres. Esto puede acelerar mucho la impresión.
-s, --human-readable[=unidades]
Intentar informar del espacio utilizado, el número de inodos utilizados y los límites en unidades más apropiadas que las predeterminadas. Las unidades también se pueden especificar explícitamente mediante un argumento opcional en formato [ kgt ],[ kgt ] donde el primer carácter especifica las unidades de espacio y el segundo carácter especifica las unidades de inodos.
-p, --raw-grace
Cuando un usuario está en período de gracia, informar del tiempo en segundos desde la época en que vence (o ha vencido) su tiempo de gracia. El campo es '0' cuando no hay tiempo de gracia activo. Esto es especialmente útil al analizar la salida por un script.
-i, --no-autofs
Ignorar puntos de montaje montados por el automontador.
-F, --format=nombre-formato
Informar de la cuota para el formato especificado (es decir, no realizar autodetención del formato). Los nombres de formato posibles son: vfsold Formato de cuota original con UIDs / GIDs de 16 bits, vfsv0 Formato de cuota con UIDs / GIDs de 32 bits, uso de espacio de 64 bits, uso y límites de inodos de 32 bits, vfsv1 Formato de cuota con límites y uso de cuotas de 64 bits, xfs (cuota en sistema de archivos XFS)
-g, --group
Informar de cuotas para grupos.
-P, --project
Informar de cuotas para proyectos.
-u, --user
Informar de cuotas para usuarios. Este es el valor predeterminado.
-O, --output=nombre-formato
Generar el informe de cuotas en el formato especificado. Los nombres de formato posibles son: default El formato predeterminado, optimizado para visualización en consola csv Valores separados por comas, un archivo de texto con las columnas delimitadas por comas xml La salida está codificada en XML, útil para procesar con XSLT

Solo el superusuario puede ver cuotas que no son las suyas.

ARCHIVOS

aquota.user o aquota.group
Archivo de cuota en la raíz del sistema de archivos (cuota versión 2, sistemas de archivos no XFS)
quota.user o quota.group
Archivo de cuota en la raíz del sistema de archivos (cuota versión 1, sistemas de archivos no XFS)
/etc/mtab
sistemas de archivos predeterminados
/etc/passwd
conjunto predeterminado de usuarios
/etc/group
conjunto predeterminado de grupos
