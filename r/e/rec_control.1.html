REC_CONTROL(1) PowerDNS Recursor REC_CONTROL(1)

NOMBRE

rec_control - Herramienta de línea de comandos para controlar un Recursor en ejecución

SINOPSIS

rec_control [OPCIÓN]... COMANDO [OPCIÓN-DE-COMANDO]...

DESCRIPCIÓN

rec_control permite al operador consultar y controlar una instancia en ejecución del PowerDNS Recursor.

rec_control se comunica con el recursor a través de un 'controlsocket'. Que generalmente se encuentra en /var/run . Los interruptores --socket-dir o --config-dir y --config-name controlan a qué proceso se conecta rec_control.

EJEMPLOS

Para ver si el Recursor está activo, ejecute:

# rec_control ping

Para detener el recursor manualmente, ejecute:

# rec_control quit

Para volcar las cachés al disco, ejecute:

# rec_control dump-cache /tmp/the-cache

NOTA:

Antes de la versión 4.5.0, para cada comando que escribe en un archivo, pdns_recursor abría el archivo para escribir. A partir de la 4.5.0, los archivos son abiertos por el comando rec_control usando las credenciales y el directorio de trabajo actual del usuario que ejecuta rec_control. Un guion simple - puede ser usado como nombre de archivo para escribir los datos en el flujo de salida estándar.

OPCIONES

--help
proporciona este mensaje útil.
--config-dir=<ruta>
Directorio donde se encuentra recursor.conf.
--config-name=<nombre>
Nombre de la configuración virtual.
--socket-dir=<ruta>
Donde vivirá el controlsocket, por favor use --config-dir en su lugar.
--socket-pid=<pid>
Cuando se ejecuta en modo SMP, pid de pdns_recursor a controlar.
--timeout=<num>
Número de segundos a esperar para que el PowerDNS Recursor remoto responda.
--version
Muestra el número de versión de este programa. Tenga en cuenta que el comando version muestra la versión del recursor en ejecución.

COMANDOS

add-dont-throttle-names NOMBRE [NOMBRE...]
Agrega nombres para dominios de servidores de nombres que no pueden ser estrangulados.
add-dont-throttle-netmasks MASCARARED [MASCARARED...]
Agrega máscaras de red para servidores de nombres que no pueden ser estrangulados.
add-nta DOMINIO [RAZÓN]
Agrega un Ancla de Confianza Negativa para DOMINIO, opcionalmente sufijada con RAZÓN.
add-ta DOMINIO REGISTRODS
Agrega un Ancla de Confianza para DOMINIO con datos del registro DS REGISTRODS. Esto agrega el nuevo Ancla de Confianza al conjunto existente de Anclas de Confianza para DOMINIO.
current-queries
Muestra las consultas actualmente activas.
clear-dont-throttle-names NOMBRE [NOMBRE...]
Elimina nombres que no tienen permitido ser estrangulados. Si NOMBRE es *, elimina todos.
clear-dont-throttle-netmasks MASCARARED [MASCARARED...]
Elimina máscaras de red que no tienen permitido ser estranguladas. Si MASCARARED es *, elimina todas.
clear-nta DOMINIO...
Elimina el Ancla de Confianza Negativa para uno o más DOMINIOs. Establezca el dominio a * para eliminar todas las NTA.
clear-ta [DOMINIO]...
Elimina el Ancla de Confianza para uno o más DOMINIOs. Tenga en cuenta que no es posible eliminar el ancla de confianza raíz.
dump-cache NOMBREARCHIVO [TIPO...]
Vuelca las cachés a NOMBREARCHIVO. Este archivo no debe existir previamente, PowerDNS se negará a sobrescribirlo. Mientras se vuelca, el recursor podría no responder a las preguntas.

Si no se especifica ningún TIPO, se vuelcan la caché de registros, la caché negativa, la caché de paquetes y la caché NSEC agresiva. Para seleccionar cachés específicas, especifique uno o más TIPOs, separados por espacios. El valor de *TIPO* puede ser r, n, p o a.

dump-dot-probe-map NOMBREARCHIVO
Vuelca el contenido del mapa de sondas DoT al NOMBREARCHIVO mencionado.
dump-edns NOMBREARCHIVO
Vuelca el estado EDNS al nombre de archivo mencionado. Este archivo no debe existir previamente, PowerDNS se negará a sobrescribirlo. Mientras se vuelca, el recursor no responderá a las preguntas.
dump-failedservers NOMBREARCHIVO
Vuelca el contenido del mapa de servidores fallidos al NOMBREARCHIVO mencionado. Este archivo no debe existir previamente, de lo contrario PowerDNS se negará a sobrescribirlo. Mientras se vuelca, el recursor no responderá a las preguntas.
dump-non-resolving NOMBREARCHIVO
Vuelca el contenido del mapa de nombres de servidores de nombres que no se resolvieron a una dirección. Este archivo no debe existir previamente, de lo contrario PowerDNS se negará a sobrescribirlo. Mientras se vuelca, el recursor no responderá a las preguntas.
dump-nsspeeds NOMBREARCHIVO
Vuelca las estadísticas de velocidad de los servidores de nombres al NOMBREARCHIVO mencionado. Este archivo no debe existir previamente, PowerDNS se negará a sobrescribirlo. Mientras se vuelca, el recursor no responderá a las preguntas. Las estadísticas se mantienen por hilo y los volcados terminan en el mismo archivo.
dump-rpz ZONA NOMBRE NOMBREARCHIVO
Vuelca el contenido de la zona RPZ llamada ZONA NOMBRE al NOMBREARCHIVO mencionado. Este archivo no debe existir previamente, de lo contrario PowerDNS se negará a sobrescribirlo. Mientras se vuelca, el recursor no responderá a las preguntas. Para obtener detalles sobre cómo se nombran las RPZ, consulte https://docs.powerdns.com/recursor/lua-config/rpz.html#policyname.
dump-saved-parent-ns-sets NOMBREARCHIVO
Vuelca las entradas del mapa que contienen conjuntos de NS padre guardados que se usaron con éxito en la resolución. El número total de entradas también se imprime en la cabecera. Una entrada se guarda si el recursor detecta que el conjunto padre incluye nombres que no están en el conjunto hijo. Esto es una indicación de un dominio mal configurado.
dump-throttlemap NOMBREARCHIVO
Vuelca el contenido del mapa de estrangulamiento al NOMBREARCHIVO mencionado. Este archivo no debe existir previamente, de lo contrario PowerDNS se negará a sobrescribirlo. Mientras se vuelca, el recursor no responderá a las preguntas.
get ESTADÍSTICA [ESTADÍSTICA]...
Recupera una estadística. Para elementos que se pueden consultar, consulte https://docs.powerdns.com/recursor/metrics.html.
get-all
Recupera todas las estadísticas conocidas.
get-dont-throttle-names
Obtiene la lista de nombres que no tienen permitido ser estrangulados.
get-dont-throttle-netmasks
Obtiene la lista de máscaras de red que no tienen
