REQUEST-KEY(8) Utilidades de gestión de claves de Linux REQUEST-KEY(8)

NOMBRE

request-key - maneja las solicitudes de devolución de llamada de instanciación de claves del kernel

SINOPSIS

/sbin/request-key <op> <clave> <uid> <gid> <threadring> <processring> <sessionring> [<info>]

DESCRIPCIÓN

Este programa es invocado por el kernel cuando se solicita una clave que no está disponible de inmediato. El kernel crea una clave parcialmente configurada y luego llama a este programa para instanciarla. No está diseñado para ser llamado directamente.

Sin embargo, para fines de depuración, se le pueden dar algunas opciones en la línea de comandos:

-d
Activa el modo de depuración. En este modo, no se realizan intentos de acceder a ninguna clave y, si se selecciona un programa manejador, no se ejecutará; en cambio, este programa imprimirá un mensaje y saldrá con 0.
-D
En modo de depuración, usa la descripción de clave propuesta especificada con esto en lugar de la muestra ("user;0;0;1f0000;debug:1234") integrada en el programa.
-l
Usa la configuración del directorio actual. El programa utilizará request-key.d/* y request-key.conf del directorio actual en lugar de los de /etc.
-n
No registrar en el registro del sistema. Normalmente, los mensajes de error y los mensajes de depuración se copiarán en el registro del sistema; esto lo impedirá.
-v
Activa la salida de depuración. Puede especificarse varias veces para producir niveles crecientes de verbosidad.
--version
Imprime la versión del programa y sale.

ERRORES

Todos los errores se registrarán en syslog.

ARCHIVOS

/etc/request-key.d/*.conf Archivos de configuración individuales.

/etc/request-key.conf Archivo de configuración de reserva.

VER TAMBIÉN

keyctl(1), request-key.conf(5), keyrings(7)
