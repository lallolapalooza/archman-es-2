EPSTOPDF(1) Manual de Comandos Generales EPSTOPDF(1)

NOMBRE

epstopdf, repstopdf - convertir un archivo EPS a PDF

SINOPSIS

epstopdf [opciones] [archivo.eps [archivo.pdf.pdf]]

DESCRIPCIÓN

epstopdf convierte el archivo PostScript de entrada a PDF, utilizando Ghostscript por defecto.

En más detalle: epstopdf transforma el archivo Encapsulated PostScript archivo.eps (o la entrada estándar) de tal manera que se garantiza que comienza en la coordenada 0,0, y establece un tamaño de página que corresponde exactamente al BoundingBox. Por lo tanto, el resultado no necesita recorte y el MediaBox de PDF es correcto.

Por defecto, el nombre de salida es el nombre de entrada con cualquier extensión reemplazada por .pdf. Un nombre de salida que termine en .pdf también se puede proporcionar como segundo argumento en la línea de comandos, o se puede usar la opción --outfile (-o) con cualquier nombre.

El resultado es PDF 1.5 por defecto. Para cambiar esto, use, por ejemplo

--gsopt=-dCompatibilityLevel=1.7
(Hasta epstopdf 2.28 (publicado en septiembre de 2018), la versión de PDF era la que Ghostscript u otro intérprete subyacente producía por defecto.)

Los comandos PJL al inicio de un archivo se eliminan. Se admiten archivos binarios EPS de DOS (TN 5002). La búsqueda desde una tubería no está soportada.

Si el cuadro delimitador en la entrada es incorrecto, inevitablemente habrá problemas resultantes.

OPCIONES

Las opciones pueden comenzar con "-" o "--", y pueden abreviarse de forma no ambigua. Es mejor usar el nombre completo de la opción en scripts para evitar posibles colisiones con nuevas opciones en el futuro.

Opciones generales del script:

--help
mostrar mensaje de ayuda y salir
--version
mostrar información de versión y salir
--outfile=archivo
escribir el resultado en archivo. Si esta opción no se da, y se especifica --nogs o --filter, escribir a la salida estándar; de lo contrario, el valor por defecto es construir el nombre del archivo de salida reemplazando cualquier extensión en el archivo de entrada con `.pdf'.
--[no]debug
escribir información de depuración (por defecto: falso). Para una salida máxima, use --debug como la primera opción.
--[no]exact
analizar ExactBoundingBox (por defecto: falso).
--[no]filter
leer entrada estándar y (a menos que se dé --outfile) escribir salida estándar (por defecto: falso).
--[no]gs
ejecutar Ghostscript (por defecto: verdadero). Con --nogs, escribir (a la salida estándar por defecto) el PostScript que normalmente se convertiría; es decir, el PostScript de entrada modificado por epstopdf.
--[no]hires
analizar HiresBoundingBox (por defecto: falso).
--restricted=val
activar el modo restringido (por defecto: [verdadero para repstopdf, de lo contrario falso]); esto prohíbe el uso de --gscmd, entre otras opciones, e impone restricciones en los nombres de los archivos de entrada y salida según los valores de openin_any y openout_any (ver el manual de Web2c, https://tug.org/web2c). En Windows, el comando Ghostscript se fuerza a ser el gs incorporado de TeX Live, instalado bajo .../tlpkg/tlgs/bin/.

Opciones para Ghostscript (más información abajo):

--gscmd=val
enviar la salida a val (por defecto: [gswin64c.exe en Windows de 64 bits, gswin32c.exe en Windows de 32 bits, de lo contrario gs])
--gsopt=val
incluir val como un argumento en el comando gs (se puede repetir).
--gsopts=val
dividir val por espacios en blanco e incluir cada palabra resultante como un argumento en el comando gs (se puede repetir).
--autorotate=val
establecer AutoRotatePages (por defecto: None); opciones de val reconocidas: None, All, PageByPage. Para archivos EPS, PageByPage es equivalente a All.
--[no]compress
usar compresión en la salida (por defecto: verdadero); si se desactiva, pasa -dUseFlateCompression=false.
--device=dev
usar -sDEVICE=dev (por defecto: pdfwrite); no permitido en modo restringido.
--[no]embed
incrustar fuentes (por defecto: verdadero); pasa -dMaxSubsetPct=100 -dSubsetFonts=true -dEmbedAllFonts=true.
--[no]gray
salida en escala de grises (por defecto: falso); pasa -sColorConversionStrategy=Gray -dProcessColorModel=/DeviceGray.
--pdfsettings=val
usar -dPDFSETTINGS=/val (el valor por defecto es `prepress' si --embed, de lo contrario vacío); opciones de val reconocidas: screen, ebook, printer, prepress, default.
--[no]quiet
usar -q, también conocido como -dQUIET (por defecto: falso).
--res=dpi, dpixdpi
establecer la resolución de imagen (por defecto: [usar el valor por defecto de gs]).
--[no]safer
usar -d(NO)SAFER (por defecto: verdadero).

Además de las opciones específicas anteriores, se pueden especificar opciones adicionales para usar con gs con las dos opciones acumulativas --gsopts y --gsopt.

--gsopts toma una sola cadena de opciones, que se divide por espacios en blanco; cada palabra resultante se agrega a la línea de comandos de gs individualmente.

--gsopt agrega su argumento como una opción única al comando gs. Se puede usar varias veces para especificar opciones por separado. Esta forma debe usarse si una opción de gs o su valor contiene espacios en blanco.

En modo restringido, las opciones se limitan a aquellas cuyos nombres y valores se sabe que son seguros. Se permiten algunas opciones que toman booleanos, enteros o nombres fijos, pero no aquellas que toman cadenas generales.

Para proporcionar un mensaje de error comprensible, epstopdf verifica si kpsewhich y gs (el especificado) se encuentran en el PATH actual, o si son ejecutables si se especifican como nombres absolutos.

EJEMPLOS

Estos ejemplos convierten de manera equivalente `test.eps' a `test.pdf':

epstopdf test.eps
epstopdf test.eps test.pdf
cat test.eps | epstopdf --filter >test.pdf
cat test.eps | epstopdf -f -o=test.pdf

Ejemplo para usar HiResBoundingBox en lugar de BoundingBox:

epstopdf --hires test.eps

Ejemplo del intento de epstopdf de corregir PostScript:

epstopdf --nogs test.ps >testcorr.ps

En todos los casos, puede agregar --debug para ver más sobre lo que está haciendo epstopdf. Use --debug como la primera opción para una salida máxima.

ERRORES

El caso de "%%BoundingBox: (atend)" cuando la entrada no es buscable (por ejemplo, desde una tubería) no está soportado.

Reporte errores en el programa o en esta página de manual a tex-k@tug.org (https://lists.tug.org/tex-k). Al reportar errores, incluya un archivo de entrada y las opciones de línea de comandos especificadas, para que el problema pueda ser reproducido.

NAME

epstopdf

convert EPS graphics to PDF using Ghostscript

SYNOPSIS

epstopdf

[ options ] file.eps [ file.eps ... ]

epstopdf --help | --version

DESCRIPTION

The epstopdf script is a front-end to the Ghostscript command. It converts Encapsulated PostScript (EPS) files to PDF (Portable Document Format) files.

EPS is a page description language based on PostScript. PDF is also based on PostScript, but it is a more modern and widely supported format. Many graphics programs and typesetting systems (like LaTeX) can generate EPS files. However, PDF is often preferred for inclusion in documents, especially when using modern PDF-based workflows.

epstopdf attempts to convert the specified EPS file(s) into PDF files, overwriting the original EPS file if the conversion is successful and the output filename is the same as the input filename.

By default, epstopdf writes the PDF file to standard output, leaving the original EPS file unchanged. If an output filename is specified using the -o option, the PDF file will be written to that name.

The script uses Ghostscript to perform the conversion. Ghostscript must be installed and in the system's PATH for epstopdf to function.

OPTIONS

--help
Display a help message and exit.

--version
Display version information and exit.

-o output.pdf
Write the PDF output to the specified file. If this option is not used, the PDF output will be written to standard output.

--output-file=output.pdf
Same as -o.

--outfile=output.pdf
Same as -o.

-i
Identify the bounding box of the input EPS file and adjust the PDF media box accordingly. This is useful to prevent unnecessary whitespace around the graphic.

--imposition
Apply imposition processing to the PDF output. This option is primarily for advanced use cases and may not be necessary for most conversions.

--gscommand=path/to/gs
Specify the path to the Ghostscript executable if it is not in the system's PATH.

--gsargs="gs arguments"
Pass additional arguments to the Ghostscript command. Use with caution.

--exact-bounding-box
Calculate the exact bounding box of the content in the EPS file. This can be more accurate than the bounding box information stored in the EPS header.

--parse-bounding-box
Attempt to parse the bounding box directly from the EPS file. This is often used in conjunction with other options to refine the output.

--nopserror
Do not exit on PostScript errors. Ghostscript will attempt to continue processing even if errors occur.

--quiet
Suppress output messages from Ghostscript.

EXAMPLES

Convert an EPS file to PDF and print to standard output:

epstopdf input.eps

Convert an EPS file to PDF and save it as output.pdf:

epstopdf input.eps -o output.pdf

Convert an EPS file, adjust the bounding box, and overwrite the original file (use with caution):

epstopdf -i input.eps && mv input.pdf input.eps

Convert multiple EPS files to PDF:

epstopdf file1.eps file2.eps file3.eps -o

(This will write all converted PDFs to standard output, one after another. It's often better to specify output files individually or use a script for batch conversion.)

BUGS

The quality of the conversion depends heavily on the capabilities of Ghostscript and the specific features used in the input EPS file. Complex PostScript code or unsupported features may lead to conversion errors or imperfect output.

Ensure that Ghostscript is correctly installed and configured.
