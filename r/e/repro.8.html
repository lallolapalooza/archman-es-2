NOMBRE

repro - utilidad para la compilación reproducible

SINOPSIS

repro [opciones] <paquete-local>

DESCRIPCIÓN

repro es un script para ayudar a verificar y comprobar la reproducibilidad de los paquetes. Construye un contenedor systemd-nspawn(1) con la imagen de arranque de Arch Linux para compilar paquetes en un chroot limpio.

Toma un paquete como argumento e intenta recrear el paquete con la información proporcionada en BUILDINFO(5). Utilizará el archivo de Arch Linux para obtener paquetes con la versión correcta (`pkgver`).

OPCIONES

-h

Muestra la ayuda.

-d

Cuando está habilitado, diffoscope(1) se ejecuta en los paquetes producidos. DIFFOSCOPE se puede configurar en repro.conf(5) para cambiar el comando diffoscope.

-f

Cuando está habilitado, repro busca un archivo PKGBUILD en el directorio de trabajo actual. Este se utiliza para compilar el paquete en lugar de obtener un PKGBUILD de asp.

-n

Cuando está habilitado, makepkg se ejecuta con --nocheck.

-o

Establece el directorio de salida para los paquetes recompilados. Por defecto es ./build.

VER TAMBIÉN

makepkg(8) repro.conf(5)
