FBB::Reverse(3bobcat) iteradores inversos de bucle for FBB::Reverse(3bobcat)

NOMBRE

FBB::Reverse - Una plantilla de clase que ofrece iteradores inversos

SINOPSIS

#include <bobcat/reverse>

DESCRIPCIÓN

No todos los tipos de datos que ofrecen (o proporcionan implícitamente) iteradores también ofrecen iteradores inversos. Los arrays no, y tampoco las listas de inicialización. Se pueden usar punteros a elementos de arrays en lugar de iteradores, pero los arrays no se pueden usar en bucles for basados en rangos. La clase Ranger (consulte ranger(3bobcat)) se puede usar para definir miembros begin y end que permiten el uso de arrays en bucles for basados en rangos. Usando objetos Reverse y estructuras de datos, se pueden usar en bucles for basados en rangos y/o para obtener iteradores inversos que recorran los elementos de datos en orden inverso.

Las plantillas de clase Reverse, ReverseArray, y ReverseSize normalmente no se usan directamente, sino que son devueltas por las diversas funciones de soporte reverse. Estas tres clases ofrecen dos miembros begin, que devuelve un iterador inverso al final del rango de datos del objeto pasado a reverse, y end, que devuelve un iterador inverso al principio del rango de datos del objeto pasado a reverse.

FUNCIONES REVERSE

o
reverse(Type &object):
devuelve un objeto Reverse que ofrece iteradores inversos al rango de datos de object, que debe soportar los miembros begin y end. Si Type es un tipo constante, entonces los miembros begin y end de Reverse devuelven iteradores inversos constantes, de lo contrario se devuelven iteradores inversos;
o
reverse(Type (&array)[size]):
devuelve un objeto Reverse que ofrece iteradores inversos al rango inverso de elementos de array. Si Type es un tipo constante, entonces los miembros begin y end de Reverse devuelven iteradores inversos constantes, de lo contrario se devuelven iteradores inversos;
o
reverse(Type *array, size_t size):
devuelve un objeto Reverse que ofrece iteradores inversos al rango inverso de elementos de array hasta array + size. Si Type es un tipo constante, entonces los miembros begin y end de Reverse devuelven iteradores inversos constantes, de lo contrario se devuelven iteradores inversos.

EJEMPLO

#include <iostream>
#include <vector>
#include <bobcat/reverse>
using namespace std;
using namespace FBB;
int main()
{
    int intArr[] = { 1, 2, 3, 4, 5};        // arrays de tamaños conocidos
    for (int value: reverse(intArr))
        cout << value << ’ ’;
    cout << ’\n’;
    for (int value: reverse(intArr, 5))     // usando tamaños especificados
        cout << value << ’ ’;
    cout << ’\n’;
    int const constArr[] = { 1, 2, 3, 4, 5};// arrays con elementos const
    for (int value: reverse(constArr))
        cout << value << ’ ’;
    cout << ’\n’;
    for (int value: reverse(constArr, 5))   // usando tamaños especificados
        cout << value << ’ ’;
    cout << ’\n’;
    for (int value: reverse(intArr, 5))     // arrays de tamaños especificados
        cout << value << ’ ’;
    cout << ’\n’;
    vector<int> vi{ 1, 2, 3, 4, 5 };        // manejo de objetos no-const
    for (int value: reverse(vi))
        cout << value << ’ ’;
    cout << ’\n’;
    vector<int> const cvi{ 1, 2, 3, 4, 5 }; // manejo de objetos const
    for (int value: reverse(cvi))
        cout << value << ’ ’;
    cout << ’\n’;
                                            // manejo de lvalues
    for (int value: reverse(initializer_list<int>{ 1, 2, 4, 8 }))
        cout << value << ’ ’;
    cout.put(’\n’);
                                            // manejo de objetos const nombrados
    auto ilist = initializer_list<int>{ 1, 2, 4, 8 };
    for (int value: reverse(ilist))
        cout << value << ’ ’;
    cout.put(’\n’);
}

NAME

reverse - returns a reversed string

SYNOPSIS

const char *reverse(const char *s);

DESCRIPTION

The reverse() function takes a null-terminated string `s` and returns a pointer to a new string that is the reverse of `s`. The returned string is allocated using malloc(3) and must be freed by the caller using free(3).

RETURN VALUE

On success, reverse() returns a pointer to the reversed string. On failure (e.g., insufficient memory), it returns NULL.

EXAMPLES

#include <stdio.h>
#include <stdlib.h>
#include "bobcat.h"

int main() {
    const char *original = "hello world";
    char *reversed = reverse(original);
    if (reversed) {
        printf("Original: %s\n", original);
        printf("Reversed: %s\n", reversed);
        free(reversed);
    } else {
        perror("reverse");
    }
    return 0;
}
