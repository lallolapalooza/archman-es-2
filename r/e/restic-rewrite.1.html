NOMBRE

restic rewrite - Reescribe snapshots para excluir archivos no deseados

SINOPSIS

restic rewrite [flags] [ID_snapshot ...]

DESCRIPCIÓN

El comando "rewrite" excluye archivos de snapshots existentes. Crea nuevos snapshots que contienen los mismos datos que los originales, pero sin los archivos que especificas para excluir. Se conservarán todos los metadatos (hora, host, etiquetas).

Los snapshots a reescribir se especifican usando las opciones --host, --tag y --path, o proporcionando una lista de IDs de snapshots. Ten en cuenta que si no se especifica ninguna de estas opciones ni un ID de snapshot, el comando reescribirá todos los snapshots.

La etiqueta especial 'rewrite' se añadirá a los nuevos snapshots para distinguirlos de los originales, a menos que se utilice --forget. Si se utiliza la opción --forget, los snapshots originales se eliminarán directamente del repositorio.

Ten en cuenta que la opción --forget solo elimina los snapshots y no los datos reales almacenados en el repositorio. Para eliminar los datos ya no referenciados, usa el comando "prune".

Cuando rewrite se utiliza con la opción --snapshot-summary, se crea un nuevo snapshot que contiene datos de resumen estadísticos. Solo dos campos en el resumen serán distintos de cero: TotalFilesProcessed y TotalBytesProcessed.

Cuando rewrite se llama con una de las opciones --exclude, se actualizarán TotalFilesProcessed y TotalBytesProcessed en el resumen del snapshot.

ESTADO DE SALIDA

El estado de salida es 0 si el comando se ejecutó correctamente. El estado de salida es 1 si hubo algún error. El estado de salida es 10 si el repositorio no existe. El estado de salida es 11 si el repositorio ya está bloqueado. El estado de salida es 12 si la contraseña es incorrecta.

OPCIONES

-n, --dry-run[=false] no hagas nada, solo imprime lo que se haría

-e, --exclude=[] excluye un patrón (se puede especificar varias veces)

--exclude-file=[] lee patrones de exclusión de un archivo (se puede especificar varias veces)

--forget[=false] elimina los snapshots originales después de crear los nuevos

-h, --help[=false] ayuda para rewrite

-H, --host=[] considera solo snapshots para este host (se puede especificar varias veces) (predeterminado: $RESTIC_HOST)

--iexclude=[] igual que --exclude patrón pero ignora la distinción entre mayúsculas y minúsculas en los nombres de archivo

--iexclude-file=[] igual que --exclude-file pero ignora la distinción entre mayúsculas y minúsculas en los nombres de archivo en los patrones

--new-host="" reemplaza el nombre del host

--new-time="" reemplaza la hora de la copia de seguridad

--path=[] considera solo snapshots que incluyan esta ruta (absoluta) (se puede especificar varias veces, los snapshots deben incluir todas las rutas especificadas)

-s, --snapshot-summary[=false] crea un registro de resumen de snapshot si no existe

--tag=[] considera solo snapshots que incluyan etiqueta[,etiqueta,...] (se puede especificar varias veces)

OPCIONES HEREDADAS DE COMANDOS PADRE

--cacert=[] archivo desde el cual cargar certificados raíz (predeterminado: usa certificados del sistema o $RESTIC_CACERT)

--cache-dir="" establece el directorio de caché. (predeterminado: usa el directorio de caché predeterminado del sistema)

--cleanup-cache[=false] elimina automáticamente directorios de caché antiguos

--compression=auto modo de compresión (solo disponible para la versión 2 del formato del repositorio), uno de (auto|off|max) (predeterminado: $RESTIC_COMPRESSION)

--http-user-agent="" establece un agente de usuario http para las solicitudes http salientes

--insecure-no-password[=false] usa una contraseña vacía para el repositorio, debe pasarse a cada comando restic (inseguro)

--insecure-tls[=false] omite la verificación del certificado TLS al conectarse al repositorio (inseguro)

--json[=false] establece el modo de salida a JSON para los comandos que lo soportan

--key-hint="" ID de clave de la clave que intentará descifrar primero (predeterminado: $RESTIC_KEY_HINT)

--limit-download=0 limita las descargas a una tasa máxima en KiB/s. (predeterminado: ilimitado)

--limit-upload=0 limita las cargas a una tasa máxima en KiB/s. (predeterminado: ilimitado)

--no-cache[=false] no usar caché local

--no-extra-verify[=false] omitir verificación adicional de datos antes de la carga (ver documentación)

--no-lock[=false] no bloquear el repositorio, esto permite algunas operaciones en repositorios de solo lectura

-o, --option=[] establece una opción extendida (clave=valor, se puede especificar varias veces)

--pack-size=0 establece el tamaño de paquete objetivo en MiB, los archivos de paquete creados pueden ser más grandes (predeterminado: $RESTIC_PACK_SIZE)

--password-command="" comando de shell para obtener la contraseña del repositorio (predeterminado: $RESTIC_PASSWORD_COMMAND)

-p, --password-file="" archivo para leer la contraseña del repositorio (predeterminado: $RESTIC_PASSWORD_FILE)

-q, --quiet[=false] no mostrar informe de progreso detallado

-r, --repo="" repositorio para copiar o restaurar (predeterminado: $RESTIC_REPOSITORY)

--repository-file="" archivo para leer la ubicación del repositorio (predeterminado: $RESTIC_REPOSITORY_FILE)

--retry-lock=0s intentar bloquear el repositorio de nuevo si ya está bloqueado, toma un valor como 5m o 2h (predeterminado: sin reintentos)

--stuck-request-timeout=5m0s duración después de la cual se reintentarán las solicitudes bloqueadas

--tls-client-cert="" ruta a un archivo que contiene el certificado de cliente TLS codificado en PEM y la clave privada (predeterminado: $RESTIC_TLS_CLIENT_CERT)

-v, --verbose[=0] ser verboso (especificar varias veces o un nivel usando --verbose=n, nivel/veces máximo es 2)
