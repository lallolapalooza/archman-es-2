re_comp(3) Manual de funciones de biblioteca re_comp(3)

NOMBRE

re_comp, re_exec - Funciones de expresiones regulares BSD

BIBLIOTECA

Biblioteca C estándar (libc, -lc)

SINOPSIS

#define _REGEX_RE_COMP
#include <sys/types.h>
#include <regex.h>
[[deprecated]] char *re_comp(const char *regex);
[[deprecated]] int re_exec(const char *string);

DESCRIPCIÓN

re_comp() se utiliza para compilar la expresión regular terminada en nulo apuntada por regex. El patrón compilado ocupa un área estática, el búfer de patrón, que se sobrescribe por el uso posterior de re_comp(). Si regex es NULL, no se realiza ninguna operación y el contenido del búfer de patrón no se altera.

re_exec() se utiliza para evaluar si la cadena terminada en nulo apuntada por string coincide con el regex previamente compilado.

VALOR DE RETORNO

re_comp() devuelve NULL en la compilación exitosa de regex; de lo contrario, devuelve un puntero a un mensaje de error apropiado.

re_exec() devuelve 1 en caso de coincidencia exitosa, cero en caso de fallo.

ATRIBUTOS

Para obtener una explicación de los términos utilizados en esta sección, consulte attributes(7).

Interfaz Atributo Valor
re_comp (), re_exec () Seguridad de hilos No segura para MT

ESTÁNDARES

Ninguno.

HISTORIA

4.3BSD.

Estas funciones están obsoletas; en su lugar, se deben utilizar las funciones documentadas en regcomp(3).

VÉASE TAMBIÉN

regcomp(3), regex(7), manual de expresiones regulares de GNU
