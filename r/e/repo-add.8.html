REPO-ADD(8) Manual de Pacman REPO-ADD(8)

NOMBRE

repo-add - utilidad de mantenimiento de la base de datos de paquetes

SINOPSIS

repo-add [opciones] <ruta-a-la-bd> <paquete> [<paquete> ...]

repo-remove [opciones] <ruta-a-la-bd> <nombre-paquete> [<nombre-paquete> ...]

DESCRIPCIÓN

repo-add y repo-remove son dos scripts para ayudar a construir una base de datos de paquetes para paquetes construidos con makepkg(8) e instalados con pacman(8).

repo-add actualizará una base de datos de paquetes leyendo un archivo de paquete construido. Se pueden especificar múltiples paquetes a añadir en la línea de comandos.

Si se encuentra un archivo “.sig” coincidente junto al archivo del paquete, la firma se incrustará automáticamente en la base de datos.

repo-remove actualizará una base de datos de paquetes eliminando el nombre del paquete especificado en la línea de comandos. Se pueden especificar múltiples paquetes a eliminar en la línea de comandos.

Una base de datos de paquetes es un archivo tar, opcionalmente comprimido. Las extensiones válidas son “.db” seguida de una extensión de archivo de “.tar”, “.tar.gz”, “.tar.bz2”, “.tar.xz”, o “.tar.Z”. El archivo no necesita existir, pero todos los directorios padres deben existir.

OPCIONES COMUNES

-q, --quiet

Obliga a este programa a mantenerse en silencio y ejecutarse sin mostrar mensajes, excepto por advertencias y errores.

-s, --sign

Genera un archivo de firma PGP usando GnuPG. Esto ejecutará gpg --detach-sign en la base de datos generada para crear un archivo de firma separada, usando el agente GPG si está disponible. El archivo de firma será el nombre completo de la base de datos con una extensión “.sig”.

-k, --key <clave>

Especifica una clave a utilizar al firmar paquetes. También se puede especificar usando la variable de entorno GPGKEY. Si no se especifica en ninguna de las ubicaciones, se utilizará la clave predeterminada del llavero.

-v, --verify

Verifica la firma PGP de la base de datos antes de actualizar la base de datos. Si la firma no es válida, se produce un error y la actualización no procede.

--nocolor

Elimina el color de la salida de repo-add y repo-remove.

OPCIONES DE REPO-ADD

-n, --new

Solo añade paquetes que aún no están en la base de datos. Se imprimirán advertencias al detectar paquetes existentes, pero no se volverán a añadir.

-R, --remove

Elimina archivos de paquetes antiguos del disco al actualizar su entrada en la base de datos.

--include-sigs

Incluye las firmas PGP de los paquetes en la base de datos del repositorio (si están disponibles).

EJEMPLO

repo-add foo.db.tar.xz <paq1> [<paq2> ...]

Esto crea dos bases de datos separadas; una base de datos más pequeña “foo.db.tar.xz” utilizada por pacman y una base de datos grande que contiene listas de archivos de paquetes “foo.files.tar.xz” para su uso por otras utilidades. Aunque pacman puede usar la base de datos grande (si se renombra con una extensión db.tar*), actualmente no hay un beneficio adicional para la descarga más grande.
