RESOLVEIP(1) Sistema de Base de Datos MariaDB RESOLVEIP(1)

NOMBRE

resolveip - resuelve el nombre de host a dirección IP o viceversa

SINOPSIS

resolveip [opciones] {nombre_host|direccion-ip} ...

DESCRIPCIÓN

La utilidad resolveip resuelve nombres de host a direcciones IP y viceversa.

Ejecuta resolveip de la siguiente manera:

shell> resolveip [opciones] {nombre_host|direccion-ip} ...

resolveip soporta las siguientes opciones.

•--help, --info, -?, -I

Muestra un mensaje de ayuda y sale.

•--silent, -s

Modo silencioso. Produce menos salida.

•--version, -V

Muestra información de la versión y sale.
