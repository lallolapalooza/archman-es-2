NOMBRE

readpst - convertir archivos PST (Carpetas personales de MS Outlook) a mbox y otros formatos

SINOPSIS

readpst [-C conjunto-de-caracteres-predeterminado] [-D] [-M] [-S] [-V] [-a lista-extensiones-adjuntos] [-b] [-c formato] [-d archivo-depuración] [-e] [-h] [-j trabajos] [-k] [-m] [-o directorio-salida] [-q] [-r] [-t códigos-tipo-salida] [-u] [-w] [-8] archivo-pst

DESCRIPCIÓN

readpst es un programa que puede leer un archivo PST (Carpetas Personales) de Outlook y convertirlo a un archivo mbox, un formato adecuado para KMail, una estructura de mbox recursiva o correos electrónicos separados.

OPCIONES

-C conjunto-de-caracteres-predeterminado

Establece el conjunto de caracteres que se utilizará para los elementos con un conjunto de caracteres no especificado.

-D

Incluir elementos eliminados en la salida.

-M

Genera mensajes en formato MH (rfc822) como archivos separados. Esto creará carpetas con los nombres del archivo PST y colocará cada correo electrónico junto con sus adjuntos en su propio archivo. Estos archivos se numerarán de 1 a n sin ceros iniciales. Este formato no utiliza comillas de remite.

-S

Genera mensajes en archivos separados. Esto creará carpetas con los nombres del archivo PST y colocará cada correo electrónico en su propio archivo. Estos archivos se numerarán de 1 a n sin ceros iniciales. Los adjuntos también se guardarán en la misma carpeta que el mensaje de correo electrónico. Los adjuntos del mensaje $m se guardan como $m-$nombre, donde $nombre es (el nombre original del adjunto, o 'adjunto$n' si el adjunto no tenía nombre), donde $n es un índice secuencial adicional sin ceros iniciales. Este formato no utiliza comillas de remite.

-V

Muestra la versión del programa y sale.

-a lista-extensiones-adjuntos

Establece la lista de extensiones de adjuntos aceptables. Cualquier adjunto que no tenga una extensión en esta lista será descartado. Todos los adjuntos son aceptables si la lista está vacía o si esta opción no se especifica.

-b

No guardar los adjuntos para el formato RTF del cuerpo del correo electrónico.

-c formato

Establece el modo de salida de Contactos. Usa -cv para formato vcard o -cl para una lista de correos electrónicos.

-d archivo-depuración

Especifica el nombre del archivo de registro de depuración. El archivo de registro es ahora un archivo ASCII, en lugar del archivo binario utilizado en versiones anteriores.

-e

Igual que la opción M, pero cada archivo de salida incluirá una extensión de (.eml, .ics, .vcf). Este formato no utiliza comillas de remite.

-h

Muestra un resumen de las opciones y sale.

-j trabajos

Especifica el número máximo de trabajos paralelos. Especifica 0 para suprimir la ejecución de trabajos paralelos. Las carpetas pueden procesarse en paralelo. Los formatos de salida que colocan cada mensaje de correo en un archivo separado (-M, -S, -e) pueden procesar el contenido de carpetas individuales en paralelo.

-k

Cambia el formato de salida a KMail. Este formato utiliza comillas de remite mboxrd.

-m

Igual que la opción e, pero también escribe archivos .msg

-o directorio-salida

Especifica el directorio de salida. El directorio debe existir y se ingresa después de abrir el archivo PST, pero antes de que comience cualquier procesamiento de archivos.

-q

Cambia al modo silencioso. No se imprime información en la pantalla, excepto los mensajes de error.

-r

Cambia el formato de salida a Recursivo. Esto creará carpetas con los nombres del archivo PST y colocará todos los correos electrónicos en un archivo llamado "mbox" dentro de cada carpeta. Las citas van a un archivo llamado "calendar", las entradas de la libreta de direcciones van a un archivo llamado "contacts" y las entradas del diario van a un archivo llamado "journal". Estos archivos son entonces compatibles con todos los clientes de correo electrónico compatibles con mbox. Este formato utiliza comillas de remite mboxrd.

-t códigos-tipo-salida

Especifica los tipos de elementos que se procesan. El argumento es una secuencia de letras individuales de (e,a,j,c) para los tipos (correo electrónico, cita, diario, contacto). El valor predeterminado es procesar todos los tipos de elementos.

-u

Establece el modo Thunderbird, un submodo del modo recursivo. Esto provoca la creación de dos archivos meta adicionales .type y .size. Este formato utiliza comillas de remite mboxrd.

-w

Sobrescribe cualquier archivo de salida anterior. Advertencia: Cuando se usa con el interruptor -S, esto eliminará todos los archivos de la carpeta de destino antes de escribir. Esto es para mantener el recuento de correos electrónicos y adjuntos correcto.

-8

Genera cuerpos en UTF-8, en lugar de la codificación original, si hay disponible una versión UTF-8.

COMILLAS DE REMITENTE

Los formatos de salida que colocan cada mensaje de correo en un archivo separado (-M, -S, -e, -m) no realizan ninguna comilla de remite. Los formatos de salida que colocan varios mensajes de correo en un solo archivo (-k, -r, -u) ahora utilizan las reglas de comillas de remite mboxrd. Si no se especifican ninguno de esos interruptores, el formato de salida predeterminado utiliza las reglas de comillas de remite mboxrd, ya que produce varios mensajes de correo en un solo archivo. Las versiones anteriores utilizaban las reglas de comillas de remite mboxo para todos los formatos de salida.
