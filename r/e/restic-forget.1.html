NOMBRE

restic-forget - Elimina instantáneas del repositorio

SINOPSIS

restic forget [flags] [ID de instantánea] [...]

DESCRIPCIÓN

El comando "forget" elimina instantáneas de acuerdo con una política. Todas las instantáneas se dividen primero en grupos según "--group-by", y después de eso se aplica la política especificada por las opciones "--keep-" a cada grupo individualmente. Si no hay suficientes instantáneas para conservar una para cada duración relacionada con la opción "--keep-{within-,}", se conservará adicionalmente la instantánea más antigua del grupo.

Tenga en cuenta que este comando realmente solo elimina el objeto de instantánea en el repositorio, que es una referencia a los datos almacenados allí. Para eliminar los datos no referenciados después de que "forget" se haya ejecutado correctamente, consulte el comando "prune".

Por favor, lea también la documentación de "forget" para conocer algunas consideraciones de seguridad importantes.

ESTADO DE SALIDA

El estado de salida es 0 si el comando se ejecutó correctamente. El estado de salida es 1 si hubo algún error. El estado de salida es 10 si el repositorio no existe. El estado de salida es 11 si el repositorio ya está bloqueado. El estado de salida es 12 si la contraseña es incorrecta.

OPCIONES

-l, --keep-last=0 conserva las últimas n instantáneas (usa 'unlimited' para conservar todas las instantáneas)

-H, --keep-hourly=0 conserva las últimas n instantáneas horarias (usa 'unlimited' para conservar todas las instantáneas horarias)

-d, --keep-daily=0 conserva las últimas n instantáneas diarias (usa 'unlimited' para conservar todas las instantáneas diarias)

-w, --keep-weekly=0 conserva las últimas n instantáneas semanales (usa 'unlimited' para conservar todas las instantáneas semanales)

-m, --keep-monthly=0 conserva las últimas n instantáneas mensuales (usa 'unlimited' para conservar todas las instantáneas mensuales)

-y, --keep-yearly=0 conserva las últimas n instantáneas anuales (usa 'unlimited' para conservar todas las instantáneas anuales)

--keep-within= conserva instantáneas que son más recientes que duración (ej. 1a5m7d2h) en relación con la instantánea más reciente

--keep-within-hourly= conserva instantáneas horarias que son más recientes que duración (ej. 1a5m7d2h) en relación con la instantánea más reciente

--keep-within-daily= conserva instantáneas diarias que son más recientes que duración (ej. 1a5m7d2h) en relación con la instantánea más reciente

--keep-within-weekly= conserva instantáneas semanales que son más recientes que duración (ej. 1a5m7d2h) en relación con la instantánea más reciente

--keep-within-monthly= conserva instantáneas mensuales que son más recientes que duración (ej. 1a5m7d2h) en relación con la instantánea más reciente

--keep-within-yearly= conserva instantáneas anuales que son más recientes que duración (ej. 1a5m7d2h) en relación con la instantánea más reciente

--keep-tag=[] conserva instantáneas con esta lista de etiquetas (se puede especificar varias veces)

--unsafe-allow-remove-all[=false] permite eliminar todas las instantáneas de un grupo de instantáneas

--host=[] considera solo instantáneas para este host (se puede especificar varias veces) (predeterminado: $RESTIC_HOST)

--tag=[] considera solo instantáneas que incluyan etiqueta[,etiqueta,...] (se puede especificar varias veces)

--path=[] considera solo instantáneas que incluyan esta ruta (absoluta) (se puede especificar varias veces, las instantáneas deben incluir todas las rutas especificadas)

-c, --compact[=false] usa formato de salida compacto

-g, --group-by=host,paths agrupa las instantáneas por host, rutas y/o etiquetas, separadas por comas (desactiva la agrupación con '')

-n, --dry-run[=false] no elimines nada, solo imprime lo que se haría

--prune[=false] ejecuta automáticamente el comando 'prune' si se han eliminado instantáneas

--max-unused="5%" tolera el límite dado de datos no utilizados (valor absoluto en bytes con sufijos k/K, m/M, g/G, t/T, un valor en % o la palabra 'unlimited')

--max-repack-size="" detente después de reempaquetar esta cantidad de datos en total (sufijos permitidos para size: k/K, m/M, g/G, t/T)

--repack-cacheable-only[=false] solo reempaqueta los paquetes que son cacheados

--repack-small[=false] reempaqueta los archivos de paquetes por debajo del 80% del tamaño de paquete objetivo

--repack-uncompressed[=false] reempaqueta todos los datos sin comprimir

--repack-smaller-than="" empaqueta los archivos de paquetes por debajo del límite (sufijos permitidos: k/K, m/M)

-h, --help[=false] ayuda para forget

OPCIONES HEREDADAS DE COMANDOS PADRE

--cacert=[] archivo desde el cual cargar los certificados raíz (predeterminado: usa certificados del sistema o $RESTIC_CACERT)

--cache-dir="" establece el directorio de caché. (predeterminado: usa el directorio de caché predeterminado del sistema)

--cleanup-cache[=false] elimina automáticamente los directorios de caché antiguos

--compression=auto modo de compresión (solo disponible para la versión 2 del formato del repositorio), uno de (auto|off|max) (predeterminado: $RESTIC_COMPRESSION)

--http-user-agent="" establece un agente de usuario http para las solicitudes http salientes

--insecure-no-password[=false] usa una contraseña vacía para el repositorio, debe pasarse a cada comando restic (inseguro)

--insecure-tls[=false] omite la verificación del certificado TLS al conectarse al repositorio (inseguro)

--json[=false] establece el modo de salida a JSON para los comandos que lo soporten

--key-hint="" ID de la clave para intentar desencriptar primero (predeterminado: $RESTIC_KEY_HINT)

--limit-download=0 limita las descargas a una tasa máxima en KiB/s. (predeterminado: ilimitado)

--limit-upload=0 limita las cargas a una tasa máxima en KiB/s. (predeterminado: ilimitado)

--no-cache[=false] no uses una caché local

--no-extra-verify[=false] omite la verificación adicional de datos antes de la carga (ver documentación)

--no-lock[=false] no bloquees el repositorio, esto permite algunas operaciones en repositorios de solo lectura

-o, --option=[] establece una opción extendida (clave=valor, se puede especificar varias veces)

--pack-size=0 establece el tamaño del paquete objetivo en MiB, los archivos de paquete creados pueden ser más grandes (predeterminado: $RESTIC_PACK_SIZE)

--password-command="" comando shell para obtener la contraseña del repositorio desde (predeterminado: $RESTIC_PASSWORD_COMMAND)

-p, --password-file="" archivo desde el cual leer la contraseña del repositorio (predeterminado: $RESTIC_PASSWORD_FILE)

-q, --quiet[=false] no muestres un informe de progreso completo

-r, --repo="" repositorio al cual hacer la copia de seguridad o restaurar desde (predeterminado: $RESTIC_REPOSITORY)

--repository-file="" archivo desde el cual leer la ubicación del repositorio (predeterminado: $RESTIC_REPOSITORY_FILE)

--retry-lock=0s reintenta bloquear el repositorio si ya está bloqueado, toma un valor como 5m o 2h (predeterminado: sin reintentos)

--stuck-request-timeout=5m0s duración después de la cual se reintentarán las solicitudes atascadas

--tls-client-cert="" ruta a un archivo que contiene el certificado de cliente TLS PEM codificado y la clave privada (predeterminado: $RESTIC_TLS_CLIENT_CERT)

-v, --verbose[=0] sé verboso (especifica múltiples veces o un nivel usando --verbose=n``, nivel/veces máximas es 2)
