NOMBRE

repro-env - Archivos de bloqueo de dependencias para entornos de compilación reproducibles

SINOPSIS

repro-env update

repro-env build -- [COMANDO]

DESCRIPCIÓN

Rastrea una descripción de un estado deseado en repro-env.toml, por ejemplo, la última versión de alguna imagen de contenedor oficial, con el último nivel de parche y la última versión de algunos paquetes adicionales. También rastrea una variante resuelta en repro-env.lock que rastrea las versiones y sumas de verificación específicas de los paquetes necesarios para configurar el entorno descrito (al nivel de parche disponible en el momento de escribir esto).

El propósito de repro-env.toml es hacer trivial la resolución posterior de la especificación si hay nuevos parches disponibles. Este archivo es leído por repro-env update.

El propósito de repro-env.lock es documentar qué versiones del compilador se han utilizado para el binario de lanzamiento asociado con un lanzamiento determinado. Registrar esta información es esencial para las compilaciones reproducibles y permite la investigación forense futura del entorno de compilación. Puede ser incluido en el repositorio del código fuente o adjuntado a un lanzamiento como artefacto, junto con el binario compilado. Este archivo es leído por repro-env build.

OPCIONES GENERALES

-v, --verbose

Aumenta la salida del registro (se puede usar varias veces)

-C ruta, --context ruta

Cambia el directorio actual a esta ruta antes de ejecutar el subcomando

UPDATE

Este comando resuelve el entorno descrito en repro-env.toml con las últimas actualizaciones disponibles y escribe un repro-env.lock. Usarías este comando de manera similar a como usarías cargo update.

--no-pull

No intentes descargar la etiqueta del contenedor del registro antes de resolverla

-k, --keep

No elimines el contenedor de compilación, espera a Ctrl+C

BUILD

Este comando carga un repro-env.lock, configura el entorno que describe en un contenedor y monta el directorio actual en /build dentro del contenedor. Luego ejecuta el COMANDO dado dentro de este contenedor.

-f ruta, --file ruta

El archivo de bloqueo de dependencias a usar

-k, --keep

No elimines el contenedor de compilación, espera a Ctrl+C

-e env, --env env

Pasa variables de entorno al contenedor de compilación (FOO=bar o simplemente FOO para buscar el valor)

PAQUETES: ARCH LINUX

Arch Linux alberga una colección completa de compiladores recientes en https://archive.archlinux.org. Puedes crear una sección [packages] en tu repro-env.toml con system = "archlinux" para instalar paquetes adicionales con pacman.

# repro-env.toml
[container]
image = "docker.io/library/archlinux"
[packages]
system = "archlinux"
dependencies = ["rust-musl", "lua"]

PAQUETES: DEBIAN

Debian es una opción ampliamente aceptada y alberga un archivo de todos sus paquetes en https://snapshot.debian.org/. Puedes crear una sección [packages] en tu repro-env.toml con system = "debian" para instalar paquetes adicionales con apt-get.

# repro-env.toml
[container]
image = "debian:bookworm"
[packages]
system = "debian"
dependencies = ["gcc", "libc6-dev"]
