CREATEPYMB(1) Manual de comandos generales CREATEPYMB(1)

NOMBRE

createPYMB, readPYBase, readPYMB, mb2org, scel2org - herramientas relacionadas con Pinyin de fcitx

SINOPSIS

createPYMB <ArchivoPinyin> <ArchivoFrase>

readPYBase [-b <ArchivoPinyinMB>] [-h]

readPYMB [-f <ArchivoFraseMB>] [-s] [-h]

mb2org [-b <ArchivoPinyinMB>] [-f <ArchivoFraseMB>] [-s] [-h]

scel2org [-o <ArchivoFrase>] [-h]

DESCRIPCIÓN

-b <ArchivoPinyinMB>
Si no se especifica, leerá el pybase.mb predeterminado del sistema.
-f <ArchivoFraseMB>
Si no se especifica, leerá el PhraseMBFile predeterminado del usuario, que es ~/.config/fcitx/pyusrphrase.mb.
-s
Si se especifica, leerá PhraseMBFile como formato del sistema, de lo contrario lo leerá como formato de usuario.
-h
muestra la ayuda y sale
Archivo Pinyin
El Archivo Pinyin es un archivo con pinyin y un carácter por línea, separados por espacios. Un archivo disponible está en el código fuente de fcitx, llamado gbkpy.org.
Archivo Frase
El Archivo Frase es un archivo con pinyin completo separado por ' y la frase correspondiente. El archivo de frase predeterminado de fcitx se puede descargar en http://fcitx.googlecode.com/files/pinyin.tar.gz.
Archivo Pinyin MB
El Archivo Pinyin MB es el formato binario del Archivo Pinyin.
Archivo Frase MB
El Archivo Frase MB es el formato binario del Archivo Pinyin, el archivo de frases históricas del usuario es ~/.config/fcitx/pyuserphrase.mb. Existen dos formatos diferentes, uno es el formato del sistema que solo puede ser generado por createPYMB, y el otro es el formato de usuario que solo puede ser generado al introducir con el IM Pinyin de fcitx.
La salida de createPYMB será pybase.mb, que es el Archivo Pinyin MB, y pyphrase.mb, que es el Archivo Frase MB.
La salida de mb2org, readPYBase y readPYMB será stdout. readPYBase y readPYMB están diseñados para emitir más mensajes de depuración del Archivo Pinyin MB y del Archivo Frase MB. mb2org emitirá en el formato del Archivo Frase.
scel2org se utiliza para transformar el Archivo Scel de Sogou en el Archivo Frase de fcitx. La salida de scel2org será stdout si no se usa -o.
