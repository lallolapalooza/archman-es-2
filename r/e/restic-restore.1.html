NOMBRE

restic-restore - Extrae los datos de una instantánea

SINOPSIS

restic restore [flags] snapshotID

DESCRIPCIÓN

El comando "restore" extrae los datos de una instantánea del repositorio a un directorio.

Se puede usar el snapshotID especial "latest" para restaurar la última instantánea en el repositorio.

Para restaurar solo una subcarpeta específica, puede usar la sintaxis "snapshotID:subcarpeta", donde "subcarpeta" es una ruta dentro de la instantánea.

ESTADO DE SALIDA

El estado de salida es 0 si el comando fue exitoso. El estado de salida es 1 si hubo algún error. El estado de salida es 10 si el repositorio no existe. El estado de salida es 11 si el repositorio ya está bloqueado. El estado de salida es 12 si la contraseña es incorrecta.

OPCIONES

--delete[=false] elimina archivos del directorio de destino si no existen en la instantánea. Usa '--dry-run -vv' para comprobar qué se eliminaría.

--dry-run[=false] no escribe ningún dato, solo muestra lo que se haría.

-e, --exclude=[] excluye un patrón (se puede especificar varias veces).

--exclude-file=[] lee patrones de exclusión de un archivo (se puede especificar varias veces).

--exclude-xattr=[] excluye xattr por patrón (se puede especificar varias veces).

-h, --help[=false] ayuda para restore.

-H, --host=[] considera solo instantáneas para este host, cuando se proporciona el ID de instantánea "latest" (se puede especificar varias veces) (predeterminado: $RESTIC_HOST).

--iexclude=[] igual que --exclude pattern pero ignora la capitalización de los nombres de archivo.

--iexclude-file=[] igual que --exclude-file pero ignora la capitalización de los nombres de archivo en los patrones.

--iinclude=[] igual que --include pattern pero ignora la capitalización de los nombres de archivo.

--iinclude-file=[] igual que --include-file pero ignora la capitalización de los nombres de archivo en los patrones.

-i, --include=[] incluye un patrón (se puede especificar varias veces).

--include-file=[] lee patrones de inclusión de un archivo (se puede especificar varias veces).

--include-xattr=[] incluye xattr por patrón (se puede especificar varias veces).

--overwrite=always comportamiento de sobrescritura, uno de (always|if-changed|if-newer|never).

--path=[] considera solo instantáneas que incluyan esta ruta (absoluta), cuando se proporciona el ID de instantánea "latest" (se puede especificar varias veces, las instantáneas deben incluir todas las rutas especificadas).

--sparse[=false] restaura archivos como dispersos.

--tag=[] considera solo instantáneas que incluyan tag[,tag,...], cuando se proporciona el ID de instantánea "latest" (se puede especificar varias veces).

-t, --target="" directorio al que extraer los datos.

--verify[=false] verifica el contenido de los archivos restaurados.

OPCIONES HEREDADAS DE COMANDOS PADRE

--cacert=[] archivo para cargar certificados raíz (predeterminado: usar certificados del sistema o $RESTIC_CACERT).

--cache-dir="" establece el directorio de caché. (predeterminado: usar el directorio de caché predeterminado del sistema).

--cleanup-cache[=false] elimina automáticamente directorios de caché antiguos.

--compression=auto modo de compresión (solo disponible para la versión 2 del formato de repositorio), uno de (auto|off|max) (predeterminado: $RESTIC_COMPRESSION).

--http-user-agent="" establece un agente de usuario http para las solicitudes http salientes.

--insecure-no-password[=false] usa una contraseña vacía para el repositorio, debe pasarse a cada comando de restic (inseguro).

--insecure-tls[=false] omite la verificación del certificado TLS al conectarse al repositorio (inseguro).

--json[=false] establece el modo de salida a JSON para comandos que lo admitan.

--key-hint="" ID de clave de la clave a intentar descifrar primero (predeterminado: $RESTIC_KEY_HINT).

--limit-download=0 limita las descargas a una tasa máxima en KiB/s. (predeterminado: ilimitado).

--limit-upload=0 limita las cargas a una tasa máxima en KiB/s. (predeterminado: ilimitado).

--no-cache[=false] no usa caché local.

--no-extra-verify[=false] omite la verificación adicional de datos antes de la carga (ver documentación).

--no-lock[=false] no bloquea el repositorio, esto permite algunas operaciones en repositorios de solo lectura.

-o, --option=[] establece una opción extendida (key=value, se puede especificar varias veces).

--pack-size=0 establece el tamaño del paquete de destino en MiB, los archivos de paquete creados pueden ser más grandes (predeterminado: $RESTIC_PACK_SIZE).

--password-command="" comando de shell para obtener la contraseña del repositorio (predeterminado: $RESTIC_PASSWORD_COMMAND).

-p, --password-file="" archivo para leer la contraseña del repositorio (predeterminado: $RESTIC_PASSWORD_FILE).

-q, --quiet[=false] no muestra un informe de progreso completo.

-r, --repo="" repositorio del que hacer copia de seguridad o del que restaurar (predeterminado: $RESTIC_REPOSITORY).

--repository-file="" archivo del que leer la ubicación del repositorio (predeterminado: $RESTIC_REPOSITORY_FILE).

--retry-lock=0s reintenta bloquear el repositorio si ya está bloqueado, toma un valor como 5m o 2h (predeterminado: sin reintentos).

--stuck-request-timeout=5m0s duración después de la cual se reintentarán las solicitudes atascadas.

--tls-client-cert="" ruta a un archivo que contiene el certificado de cliente TLS codificado en PEM y la clave privada (predeterminado: $RESTIC_TLS_CLIENT_CERT).

-v, --verbose[=0] sea detallado (especifique varias veces o un nivel usando --verbose=n, nivel/veces máximo es 2).
