recallocarray(3bsd)

Paquete: libbsd

Licencias: custom

reallocarray(3bsd) 3bsd reallocarray(3bsd)

NOMBRE

reallocarray, recallocarray, freezero — asignación y desasignación de memoria

BIBLIOTECA

biblioteca «libbsd»

SINOPSIS

#include <stdlib.h> (Véase libbsd(7) para el uso de la inclusión.)
void *
reallocarray(void *ptr, size_t nmemb, size_t size);

void *
recallocarray(void *ptr, size_t oldnmemb, size_t nmemb, size_t size);

void
freezero(void *ptr, size_t size);

DESCRIPCIÓN

Diseñada para la asignación segura de arreglos, la función reallocarray() es similar a realloc() excepto que opera sobre nmemb miembros de tamaño size y verifica desbordamientos enteros en el cálculo nmemb * size.

Usada para la asignación de memoria que contiene datos sensibles, la función recallocarray() garantiza que la memoria que deja de estar asignada es explícitamente descartada, lo que significa que los objetos gratuitos cacheados se limpian con explicit_bzero(3).

La función recallocarray() es similar a reallocarray() excepto que asegura que la memoria recién asignada se limpie de manera similar a calloc(). Si ptr es NULL, oldnmemb se ignora y la llamada es equivalente a calloc(). Si ptr no es NULL, oldnmemb debe ser un valor tal que oldnmemb * size sea el tamaño de la asignación anterior que devolvió ptr, de lo contrario el comportamiento es indefinido. La función freezero() es similar a la función free() excepto que asegura que la memoria se descarta explícitamente. Si ptr es NULL, no ocurre ninguna acción. Si ptr no es NULL, el argumento size debe ser igual o menor que el tamaño de la asignación anterior que devolvió ptr. freezero() garantiza que el rango de memoria que comienza en ptr con longitud size se descarta mientras se desasigna el objeto completo asignado originalmente.

VALORES DE RETORNO

Las funciones reallocarray() y recallocarray() devuelven un puntero al espacio asignado si tiene éxito; de lo contrario, se devuelve un puntero nulo y errno se establece en ENOMEM.

Si la multiplicación de nmemb y size resulta en desbordamiento entero, reallocarray() y recallocarray() devuelven NULL y establecen errno en ENOMEM.

Si ptr no es NULL y la multiplicación de oldnmemb y size resulta en desbordamiento entero, recallocarray() devuelve NULL y establece errno en EINVAL.

IDIOMAS

Considere calloc() o las extensiones reallocarray() y recallocarray() cuando haya una multiplicación en el argumento size de malloc() o realloc(). Por ejemplo, evite este idioma común ya que puede conducir a desbordamiento entero:

if ((p = malloc(num * size)) == NULL)
	err(1, NULL);

Un reemplazo directo es reallocarray():

if ((p = reallocarray(NULL, num, size)) == NULL)
	err(1, NULL);

Alternativamente, se puede usar calloc() con el costo de la sobrecarga de inicialización.

Al usar realloc(), tenga cuidado de evitar el siguiente idioma:

size += 50;
if ((p = realloc(p, size)) == NULL)
	return (NULL);

No ajuste la variable que describe cuánta memoria se ha asignado hasta que la asignación haya sido exitosa. Esto puede causar un comportamiento aberrante del programa si se utiliza un valor de tamaño incorrecto. En la mayoría de los casos, el ejemplo anterior también resultará en una fuga de memoria. Como se indicó anteriormente, un valor de retorno de NULL indica que el objeto antiguo todavía permanece asignado. Un código mejor se ve así:

newsize = size + 50;
if ((newp = realloc(p, newsize)) == NULL) {
	free(p);
	p = NULL;
	size = 0;
	return (NULL);
}
p = newp;
size = newsize;

Al igual que con malloc(), es importante asegurarse de que el nuevo valor de tamaño no se desborde; es decir, evite asignaciones como la siguiente:

if ((newp = realloc(p, num * size)) == NULL) {
	...

En su lugar, use reallocarray():

if ((newp = reallocarray(p, num, size)) == NULL) {
	...

Llamar a realloc() con un ptr NULL es equivalente a llamar a malloc(). En lugar de este idioma:

if (p == NULL)
	newp = malloc(newsize);
else
	newp = realloc(p, newsize);

Use lo siguiente:

newp = realloc(p, newsize);

La función recallocarray() debe usarse para redimensionar objetos que contienen datos sensibles como claves. Para evitar fugas de información, garantiza que la memoria se limpie antes de colocarla en la lista interna de objetos libres. La desasignación de dicho objeto debe hacerse llamando a freezero().

malloc(3), calloc(3), alloca(3)

recallocarray(3bsd)

Allocate memory with resizing and zeroing.

NAME

recallocarray — allocate memory with resizing and zeroing

LIBRARY

libbsd

SYNOPSIS

#include <stdlib.h>

void *recallocarray(void *ptr, size_t nmemb, size_t size);

DESCRIPTION

The recallocarray() function reallocates the given block of memory ptr to be nmemb elements, each of which is size bytes.

The newly allocated memory is initialized to zero. If ptr is NULL, then the call is equivalent to calloc() with the same arguments. If nmemb or size is equal to zero, then the call is equivalent to free() and returns NULL.

The memory is allocated from the heap.

The recallocarray() function returns a pointer, whose type is correctly cast to pointer to the type of the elements. The value of the pointer is guaranteed to be such that it may be passed to free(). If the allocation is not possible, the function returns NULL. If the resulting memory block is larger than the previous one, the contents of the block are unchanged up to the smaller of the two block sizes. If the new block is smaller than the old one, then the contents of the block are reduced up to the new size.

RETURN VALUES

The recallocarray() function returns a pointer to the newly allocated memory block. If the allocation fails, it returns NULL.

IDIOMS

A common idiom for allocating dynamic arrays is (type *)recallocarray(ptr, nmemb, sizeof(type)).

SEE ALSO

calloc(3bsd), free(3bsd), realloc(3bsd), reallocf(3bsd)

HISTORY

The recallocarray function first appeared in DragonFly 5.5.
