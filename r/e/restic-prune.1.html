NOMBRE

restic-prune - Eliminar datos innecesarios del repositorio

SINOPSIS

restic prune [flags]

DESCRIPCIÓN

El comando "prune" comprueba el repositorio y elimina los datos que no están referenciados y, por lo tanto, ya no son necesarios.

ESTADO DE SALIDA

El estado de salida es 0 si el comando se ejecutó correctamente. El estado de salida es 1 si hubo algún error. El estado de salida es 10 si el repositorio no existe. El estado de salida es 11 si el repositorio ya está bloqueado. El estado de salida es 12 si la contraseña es incorrecta.

OPCIONES

-n, --dry-run[=false] no modificar el repositorio, solo mostrar lo que se haría

-h, --help[=false] ayuda para prune

--max-repack-size="" detenerse después de reempaquetar esta cantidad de datos en total (sufijos permitidos para size: k/K, m/M, g/G, t/T)

--max-unused="5%" tolerar el límite dado de datos no utilizados (valor absoluto en bytes con sufijos k/K, m/M, g/G, t/T, un valor en % o la palabra 'unlimited')

--repack-cacheable-only[=false] solo reempaquetar los packs que son cacheados

--repack-small[=false] reempaquetar archivos de pack por debajo del 80% del tamaño de pack objetivo

--repack-smaller-than="" empaquetar archivos de pack por debajo del límite (sufijos permitidos: k/K, m/M)

--repack-uncompressed[=false] reempaquetar todos los datos sin comprimir

--unsafe-recover-no-free-space="" INSEGURO, ¡LEA LA DOCUMENTACIÓN ANTES DE USAR! Intentar recuperar un repositorio atascado sin espacio libre. No usar sin probar primero 'prune --max-repack-size 0'.

OPCIONES HEREDADAS DE COMANDOS PADRE

--cacert=[] archivo para cargar certificados raíz desde (predeterminado: usar certificados del sistema o $RESTIC_CACERT)

--cache-dir="" establecer el directorio de caché. (predeterminado: usar el directorio de caché predeterminado del sistema)

--cleanup-cache[=false] eliminar automáticamente directorios de caché antiguos

--compression=auto modo de compresión (solo disponible para el formato de repositorio versión 2), uno de (auto|off|max) (predeterminado: $RESTIC_COMPRESSION)

--http-user-agent="" establecer un agente de usuario http para las solicitudes http salientes

--insecure-no-password[=false] usar una contraseña vacía para el repositorio, debe pasarse a cada comando restic (inseguro)

--insecure-tls[=false] omitir la verificación del certificado TLS al conectarse al repositorio (inseguro)

--json[=false] establecer el modo de salida a JSON para comandos que lo soporten

--key-hint="" ID de clave de la clave para intentar descifrar primero (predeterminado: $RESTIC_KEY_HINT)

--limit-download=0 limita las descargas a una tasa máxima en KiB/s. (predeterminado: ilimitado)

--limit-upload=0 limita las cargas a una tasa máxima en KiB/s. (predeterminado: ilimitado)

--no-cache[=false] no usar una caché local

--no-extra-verify[=false] omitir la verificación adicional de datos antes de la carga (ver documentación)

--no-lock[=false] no bloquear el repositorio, esto permite algunas operaciones en repositorios de solo lectura

-o, --option=[] establecer opción extendida (clave=valor, se puede especificar varias veces)

--pack-size=0 establecer el tamaño de pack objetivo en MiB, los archivos de pack creados pueden ser más grandes (predeterminado: $RESTIC_PACK_SIZE)

--password-command="" comando de shell para obtener la contraseña del repositorio de (predeterminado: $RESTIC_PASSWORD_COMMAND)

-p, --password-file="" archivo para leer la contraseña del repositorio desde (predeterminado: $RESTIC_PASSWORD_FILE)

-q, --quiet[=false] no mostrar informe de progreso detallado

-r, --repo="" repositorio para hacer copias de seguridad o restaurar (predeterminado: $RESTIC_REPOSITORY)

--repository-file="" archivo para leer la ubicación del repositorio desde (predeterminado: $RESTIC_REPOSITORY_FILE)

--retry-lock=0s reintentar bloquear el repositorio si ya está bloqueado, toma un valor como 5m o 2h (predeterminado: sin reintentos)

--stuck-request-timeout=5m0s duración después de la cual se reintentarán las solicitudes atascadas

--tls-client-cert="" ruta a un archivo que contiene el certificado de cliente TLS y la clave privada codificados en PEM (predeterminado: $RESTIC_TLS_CLIENT_CERT)

-v, --verbose[=0] ser verboso (especificar varias veces o un nivel usando --verbose=n, nivel/veces máximo es 2)
