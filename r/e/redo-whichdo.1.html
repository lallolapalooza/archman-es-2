REDO-WHICHDO(1) Manual de comandos generales REDO-WHICHDO(1)

NOMBRE

redo-whichdo - imprime las rutas de búsqueda para los dofiles para construir un objetivo de redo

SINOPSIS

redo-whichdo objetivo

DESCRIPCIÓN

redo(1) es una herramienta para construir archivos y para reconstruirlos si alguna de sus dependencias ha cambiado. redo-whichdo imprime todos los dofiles que redo(1) buscará para construir el objetivo. Si el código de salida de redo-whichdo indica éxito, el último nombre de archivo es el nombre del dofile que redo(1) usará realmente para construir el objetivo.

redo-whichdo imprime el nombre del dofile que redo(1) podría usar para construir el objetivo. Si el dofile existe, redo-whichdo sale con un código de estado que indica éxito. Si el dofile no existe, redo-whichdo repite la acción anterior con un nombre de archivo de respaldo o sale con un código de estado que indica error si redo-whichdo no puede encontrar un dofile para construir el objetivo.

Si la salida estándar es una terminal, redo-whichdo separa los nombres de archivo por caracteres de nueva línea. De lo contrario, redo-whichdo separa los nombres de archivo por caracteres nulos. Los scripts de shell que actúan sobre la salida de redo-whichdo pueden enviarla a xargs(1) invocado con la opción -0 para manejar los nombres de archivo.

EJEMPLOS

Considera un directorio raíz que contiene solo los tres dofiles a.do, default.b.do, default.c.do, y una carpeta d. Para los objetivos, a, a.b, y a.b.c, d/a.b.c, la salida de redo-whichdo(1) sería la siguiente:

a

/a.do
a.b

/a.b.do
/default.b.do
a.b.c

/a.b.c.do
/default.b.c.do
/default.c.do
d/a.b.c

/d/a.b.c.do
/d/default.b.c.do
/d/default.c.do
/d/default.do
/default.b.c.do
/default.c.do

NOTAS

Un dofile utilizado para construir un objetivo es una dependencia de ese objetivo: si redo(1) determina que el dofile utilizado para construir un objetivo ha cambiado, el objetivo se reconstruirá.

Todos los dofiles inexistentes buscados mientras se construye un objetivo son dependencias de no existencia de ese objetivo: si redo(1) encuentra que un dofile buscado previamente y inexistente ahora existe, el objetivo se reconstruirá.
