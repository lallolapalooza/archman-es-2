NOMBRE

restic-key-add - Añadir una nueva clave (contraseña) al repositorio; devuelve el ID de la nueva clave

SINOPSIS

restic key add [flags]

DESCRIPCIÓN

El subcomando "add" crea una nueva clave y valida la clave. Devuelve el ID de la nueva clave.

ESTADO DE SALIDA

El estado de salida es 0 si el comando se completó con éxito. El estado de salida es 1 si hubo algún error. El estado de salida es 10 si el repositorio no existe. El estado de salida es 11 si el repositorio ya está bloqueado. El estado de salida es 12 si la contraseña es incorrecta.

OPCIONES

-h, --help[=false] ayuda para add

--host="" el nombre del host para la nueva clave

--new-insecure-no-password[=false] añade una contraseña vacía para el repositorio (inseguro)

--new-password-file="" archivo desde el cual leer la nueva contraseña

--user="" el nombre de usuario para la nueva clave

OPCIONES HEREDADAS DE COMANDOS PADRE

--cacert=[] archivo para cargar certificados raíz desde (predeterminado: usar certificados del sistema o $RESTIC_CACERT)

--cache-dir="" establece el directorio de caché. (predeterminado: usar el directorio de caché predeterminado del sistema)

--cleanup-cache[=false] elimina automáticamente los directorios de caché antiguos

--compression=auto modo de compresión (solo disponible para la versión 2 del formato del repositorio), uno de (auto|off|max) (predeterminado: $RESTIC_COMPRESSION)

--http-user-agent="" establece un agente de usuario http para las solicitudes http salientes

--insecure-no-password[=false] usa una contraseña vacía para el repositorio, debe pasarse a cada comando restic (inseguro)

--insecure-tls[=false] ignora la verificación del certificado TLS al conectarse al repositorio (inseguro)

--json[=false] establece el modo de salida a JSON para los comandos que lo soporten

--key-hint="" ID de clave de la clave a intentar descifrar primero (predeterminado: $RESTIC_KEY_HINT)

--limit-download=0 limita las descargas a una tasa máxima en KiB/s. (predeterminado: ilimitado)

--limit-upload=0 limita las subidas a una tasa máxima en KiB/s. (predeterminado: ilimitado)

--no-cache[=false] no usar una caché local

--no-extra-verify[=false] omitir la verificación adicional de datos antes de la subida (ver documentación)

--no-lock[=false] no bloquear el repositorio, esto permite algunas operaciones en repositorios de solo lectura

-o, --option=[] establecer opción extendida (clave=valor, se puede especificar varias veces)

--pack-size=0 establecer el tamaño del paquete objetivo en MiB, los archivos de paquete creados pueden ser más grandes (predeterminado: $RESTIC_PACK_SIZE)

--password-command="" comando de shell para obtener la contraseña del repositorio de (predeterminado: $RESTIC_PASSWORD_COMMAND)

-p, --password-file="" archivo desde el cual leer la contraseña del repositorio (predeterminado: $RESTIC_PASSWORD_FILE)

-q, --quiet[=false] no mostrar informe de progreso completo

-r, --repo="" repositorio al cual realizar la copia de seguridad o desde el cual restaurar (predeterminado: $RESTIC_REPOSITORY)

--repository-file="" archivo desde el cual leer la ubicación del repositorio (predeterminado: $RESTIC_REPOSITORY_FILE)

--retry-lock=0s volver a intentar bloquear el repositorio si ya está bloqueado, toma un valor como 5m o 2h (predeterminado: sin reintentos)

--stuck-request-timeout=5m0s duración después de la cual se reintentarán las solicitudes atascadas

--tls-client-cert="" ruta a un archivo que contiene el certificado de cliente TLS codificado en PEM y la clave privada (predeterminado: $RESTIC_TLS_CLIENT_CERT)

-v, --verbose[=0] ser verboso (especificar varias veces o un nivel usando --verbose=n, nivel/veces máximo es 2)
