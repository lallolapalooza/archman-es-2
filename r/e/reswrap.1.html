reswrap(1) Manual del programador de FOX reswrap(1)

NOMBRE

reswrap - empaqueta recursos de iconos en código C

SINOPSIS

reswrap [opciones] [-o[a] archivo_salida] archivos...

DESCRIPCIÓN

Reswrap es una herramienta para convertir imágenes, texto y otros archivos de recursos en matrices de datos C++. Esto permite que varios recursos binarios se incorporen en el código fuente y se compilen en una aplicación.

En el desarrollo de aplicaciones gráficas con FOX, se utiliza para incrustar iconos e imágenes para la interfaz de usuario en el ejecutable y eliminar la necesidad de distribuir archivos de iconos e imágenes separados.

Reswrap se invoca típicamente como parte del proceso de compilación para generar archivos fuente C++ a partir de una colección de iconos, imágenes y otros recursos binarios.

Por defecto, reswrap interpretará los archivos listados como un flujo de bytes crudos y los generará como una matriz de datos inicializada a la salida estándar.

OPCIONES

-o[a] archivo_salida
Escribe el resultado en el archivo archivo_salida en lugar de en la salida estándar. Con -o, el archivo_salida será sobrescrito con los datos de la entrada. Con la opción -oa, el código resultante se añadirá al archivo de salida, permitiendo que múltiples archivos de entrada se coloquen en un único archivo fuente.
-h
Imprime un breve mensaje de uso.
-v
Solo imprime el número de versión e información de licencia.
-d
Escribe los datos como números decimales en lugar de usar los números hexadecimales predeterminados.
-m
Lee archivos con modo MS-DOS (por defecto es binario). Esto reemplaza "\r\n" con "\n" al leer el archivo de recurso.
-x
Escribe los datos como números hexadecimales (predeterminado).
-t[a]
Escribe los datos como una cadena de texto, con cada byte representado como una secuencia de escape hexadecimal, como en "\x33".

Tenga en cuenta que el compilador C añade un carácter nulo al final de la cadena de texto, haciendo que la matriz de datos sea un carácter más larga que el archivo.

Con la opción a, los caracteres ASCII imprimibles se mantienen sin escapar, mientras que los caracteres especiales como tabulaciones y saltos de línea reciben los códigos de escape habituales.

-e
Coloca el modificador de almacenamiento extern delante de la matriz de datos, asegurando que la matriz de datos pueda enlazarse con otras unidades de compilación. Normalmente, las declaraciones de constantes no son visibles en otras unidades de compilación.
-i
En lugar de generar solo una definición de matriz, escribe una declaración, que puede incluirse como un archivo de cabecera.
-k
Esta opción hace que reswrap conserve la extensión del archivo, reemplazando el punto "." por un guion bajo "_". Se recomienda el uso de esta opción, ya que reduce los errores al usar las matrices de datos.
-s
Esta opción suprime los comentarios insertados por reswrap para indicar el nombre del archivo original del cual se generó la declaración de datos.
-p prefijo
Antepone el prefijo dado al nombre del recurso; esto se puede usar para generar nombres de clase o nombres de espacio de nombres delante de los símbolos.
-n espacio_de_nombres
Genera todas las declaraciones dentro de la declaración de espacio_de_nombres C++ dada. El uso de un espacio_de_nombres puede servir para garantizar que las declaraciones solo sean accesibles dentro del ámbito dado y, por lo tanto, no choquen con otros símbolos.
-c columnas
Escribe columnas columnas en lugar del número predeterminado de columnas en las declaraciones de datos generadas por reswrap. El número predeterminado de columnas para la impresión decimal y hexadecimal es de 16 caracteres; el predeterminado para la impresión de cadenas de texto es de 80 caracteres.
-u
Fuerza la salida como caracteres sin signo en modo texto.
-z
Imprime el tamaño del recurso en la declaración de una matriz de recursos. Esto permite que el operador C++ sizeof() devuelva el tamaño correcto del recurso incluso para declaraciones externas. Tenga en cuenta que en modo texto (opción -t), se añade un byte adicional al tamaño para el carácter de fin de cadena.
-r nombre
En lugar de usar un nombre de recurso basado en el nombre del archivo, reswrap sustituye nombre por el nombre del recurso utilizado en la declaración o definición para el siguiente archivo de recurso. Esto es útil si el nombre del archivo no se puede usar como identificador, por ejemplo, si el nombre del archivo es una palabra reservada en C o C++, como "while".

ADVERTENCIAS

Al usar el modo de cadena de texto, recuerde que el compilador C añade un carácter nulo después de la cadena, lo que hace que la matriz de datos sea un elemento más larga que el archivo de recurso.
