RESIZE(1) Sistema X Window RESIZE(1)

NOMBRE

resize - establece variables de entorno y de terminal al tamaño actual de la ventana xterm

SINOPSIS

resize [ -v | -u | -c ] [ -s [ filas columnas ] ]

DESCRIPCIÓN

resize imprime un comando de shell para establecer las variables de entorno apropiadas que indiquen el tamaño actual de la ventana xterm desde la que se ejecuta el comando.

resize determina el comando a través de varios pasos:

  • primero, encuentra el nombre del programa shell del usuario. Utiliza la variable SHELL si está establecida, de lo contrario, utiliza los datos del usuario de /etc/passwd.
  • luego decide si usar sintaxis de Bourne shell o de C-Shell. Utiliza una tabla interna de shells conocidos, que puede ser anulada por las opciones -u y -c.
  • luego resize solicita al sistema operativo la configuración de la terminal. Esta es la misma información que se puede manipular con stty.
  • luego resize pregunta a la terminal por su tamaño en caracteres. Dependiendo de si se proporciona la opción "-s", resize utiliza una secuencia de escape diferente para solicitar esta información.
  • en este punto, resize intenta actualizar la configuración de la terminal para reflejar el tamaño de la ventana de la terminal en píxeles:
  • si se utiliza la opción -s, resize solicita entonces a la terminal su tamaño en píxeles.
  • de lo contrario, resize solicita al sistema operativo la información y la actualiza después de asegurarse de que las dimensiones de la ventana sean múltiplos de la altura y anchura de los caracteres.
  • en cualquier caso, la configuración actualizada de la terminal se realiza mediante una llamada al sistema diferente a la utilizada para stty.
  • luego resize actualiza la configuración de la terminal para reflejar cualquier valor alterado, como su tamaño en filas o columnas. Esto afecta a los valores mostrados por stty.
  • finalmente, resize genera comandos de shell para establecer las variables de entorno y los escribe en la salida estándar.

OPCIONES

Las siguientes opciones pueden ser utilizadas con resize:

-c
Esta opción indica que se deben generar comandos de C shell incluso si el shell actual del usuario no parece usar sintaxis de C shell.
-s [filas columnas]
Esta opción indica que se utilizarán secuencias de escape de consola Sun en lugar de los códigos de escape de xterm estilo VT100. Si se proporcionan filas y columnas, resize le pedirá a xterm que cambie su tamaño utilizando esos valores.
Ambas secuencias de escape utilizadas para esta opción (primero para obtener el tamaño de la ventana y segundo para modificarlo) están sujetas a la configuración del recurso allowWindowOps de xterm. El gestor de ventanas también puede optar por no permitir el cambio.
La secuencia de escape estilo VT100 utilizada para determinar el tamaño de la pantalla siempre funciona para terminales compatibles con VT100. Los VT100 no tienen una forma correspondiente de modificar el tamaño de la pantalla.
-u
Esta opción indica que se deben generar comandos de Bourne shell incluso si el shell actual del usuario no parece usar sintaxis de Bourne shell.
-v
Esto hace que resize imprima el número de versión en la salida estándar y luego salga.

Tenga en cuenta que las secuencias de escape de consola Sun son reconocidas por xterm de XFree86 y por dtterm. El programa resize puede ser instalado como sunsize, lo que hace que asuma la opción -s.

Los argumentos filas y columnas deben aparecer al final; aunque normalmente están asociados con la opción -s, se analizan por separado.

ENTORNO

SHELL
A menos que se anule con la opción -c, resize determina el shell actual del usuario mediante
  • primero verificando si $SHELL está establecido y utilizándolo,
  • de lo contrario, resize busca en el archivo de contraseñas (/etc/passwd).
Generalmente, las variantes de Bourne shell (incluido ksh) no modifican $SHELL, por lo que es posible que resize se confunda si uno ejecuta resize desde un Bourne shell iniciado desde un C shell.
Después de determinar el shell del usuario, resize compara el nombre del shell con una tabla de nombres de shells conocidos. Si no encuentra el nombre en su tabla, resize utilizará la sintaxis de C shell para los comandos generados que establecen variables de entorno.
TERM
El comando de shell generado por resize lo establece en "xterm" si no está ya establecido.
TERMCAP
El comando de shell generado por resize establece esta variable en sistemas que usan termcap, p. ej., cuando resize está enlazado con la biblioteca termcap en lugar de una biblioteca terminfo. Esta última no proporciona el texto completo para una entrada termcap.
COLUMNS, LINES
El comando de shell generado por resize establece estas variables en sistemas que usan terminfo. Muchas aplicaciones (incluida la biblioteca curses) utilizan esas variables cuando están establecidas para anular el tamaño de su pantalla.

ARCHIVOS

/etc/termcap
para la entrada termcap base a modificar.
~/.cshrc
alias de usuario para el comando.

EJEMPLOS

Para que la salida de resize tenga efecto, resize debe ser evaluado como parte de la línea de comandos (generalmente hecho con un alias o función de shell) o redirigido a un archivo que luego pueda ser leído. Desde el C shell (generalmente conocido como /bin/csh), el siguiente alias podría definirse en el .cshrc del usuario:


% alias rs 'set noglob; eval `resize`'

Después de cambiar el tamaño de la ventana, el usuario escribiría:


% rs

Los usuarios de versiones de Bourne shell (generalmente conocidas como /bin/sh) que no tienen funciones de comando necesitarán enviar la salida a un archivo temporal y luego leerla de nuevo con el comando “.”:


$ resize > /tmp/out
$ . /tmp/out

  • NAME

    resize - Resizes the terminal.

    SYNOPSIS

    resize [-u] [-s lines columns]

    DESCRIPTION

    The resize utility determines the current size of the terminal and prints an initialization string to the terminal's environment that can be used to set the LINES and COLUMNS environment variables.

    If the -s option is given, resize will attempt to resize the terminal to the specified number of lines and columns.

    If the -u option is given, resize will use the user's current terminal settings instead of querying the kernel.

    OPTIONS

    -u

    Use the user's current terminal settings instead of querying the kernel.

    -s lines columns

    Attempt to resize the terminal to the specified number of lines and columns.

    ENVIRONMENT

    The following environment variables are used by resize:

    LINES

    The number of lines in the terminal.

    COLUMNS

    The number of columns in the terminal.

    FILES

    /etc/termcap

    Terminal capability database.

    /etc/terminfo

    Terminal information database.

    EXAMPLES

    To set the LINES and COLUMNS environment variables to the current terminal size:

    eval $(resize)

    To resize the terminal to 25 lines and 80 columns:

    resize -s 25 80
