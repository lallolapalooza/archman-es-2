rebuilderd-sync.conf(5) Manual de formatos de archivo rebuilderd-sync.conf(5)

NOMBRE

rebuilderd-sync.conf - Archivos de configuración de rebuildctl pkgs sync-profile

SINOPSIS

/etc/rebuilderd-sync.conf

DESCRIPCIÓN

Este archivo permite configurar perfiles que pueden iniciarse con un temporizador de systemd o un cronjob. De esta manera, no necesita proporcionar estas opciones en la línea de comandos todo el tiempo.

OPCIONES

distro=

El nombre de la distribución, actualmente archlinux o debian.

suite=

Esto es para paquetes que tienen múltiples suites/repositorios, como main, contrib, non-free o core, extra y community.

architectures=

Las arquitecturas de la lista de paquetes que queremos importar.

releases=

Importar lanzamientos específicos. Esta opción no tiene efecto en distribuciones de lanzamiento continuo como Arch Linux, pero es importante para, por ejemplo, Debian. Si la misma versión está presente en múltiples lanzamientos, el paquete solo se importa una vez.

source=

Esta es la URL de la que queremos importar. Para Arch Linux, podría verse así: 
source = "https://ftp.halifax.rwth-aachen.de/archlinux/$repo/os/$arch"

maintainers= (opcional)

Seleccionar paquetes de mantenedores específicos. Se supone que las cadenas coinciden con el principio del campo del empaquetador de los paquetes. 
maintainers = ["kpcyrd", "Levente Polyak"]

pkgs= (opcional)

Seleccionar paquetes por nombre: 
pkgs = ["rebuilderd", "python-*"]

excludes= (opcional)

Si un paquete coincide con uno de estos patrones, siempre se ignorará. 
excludes = ["tensorflow*"]

Tanto pkgs= como excludes= admiten patrones glob. Si maintainers= y pkgs= no están configurados, se seleccionan todos los paquetes.

EJEMPLO

## reconstruir todo el core
[profile."archlinux-core"]
distro = "archlinux"
suite = "core"
architecture = "x86_64"
source = "https://ftp.halifax.rwth-aachen.de/archlinux/$repo/os/$arch"
## reconstruir paquetes de la comunidad de mantenedores específicos, o permitir
## la lista de paquetes por nombre.
## Si no se establece ningún filtro, se importan todos los paquetes, si se
## establecen ambos filtros, el paquete solo tiene que coincidir con uno de
## ellos para ser incluido.
#[profile."archlinux-community"]
#distro = "archlinux"
#suite = "community"
#architecture = "x86_64"
#source = "https://ftp.halifax.rwth-aachen.de/archlinux/$repo/os/$arch"
#maintainers = ["somebody"]
#pkgs = ["some-pkg", "python-*"]
#excludes = ["tensorflow*"]

SINCRONIZACIÓN AUTOMÁTICA

Habilite el temporizador de systemd para sincronizar automáticamente perfiles específicos:

systemctl enable --now rebuilderd-sync@archlinux-core.timer

El argumento detrás del @ hace referencia a la sección del archivo de configuración.
