remainder(3) Manual de Funciones de Librería remainder(3)

NOMBRE

drem, dremf, dreml, remainder, remainderf, remainderl - función de resto de punto flotante

LIBRERÍA

Librería matemática (libm, -lm)

SINOPSIS

#include <math.h>
double remainder(double x, double y);
float remainderf(float x, float y);
long double remainderl(long double x, long double y);
/* Sinónimos obsoletos */
[[deprecated]] double drem(double x, double y);
[[deprecated]] float dremf(float x, float y);
[[deprecated]] long double dreml(long double x, long double y);
Requisitos de Macro de Prueba de Funciones para glibc (ver feature_test_macros(7)):

remainder():

    _ISOC99_SOURCE || _POSIX_C_SOURCE >= 200112L
        || _XOPEN_SOURCE >= 500
        || /* Desde glibc 2.19: */ _DEFAULT_SOURCE
        || /* glibc <= 2.19: */ _BSD_SOURCE || _SVID_SOURCE

remainderf(), remainderl():

    _ISOC99_SOURCE || _POSIX_C_SOURCE >= 200112L
        || /* Desde glibc 2.19: */ _DEFAULT_SOURCE
        || /* glibc <= 2.19: */ _BSD_SOURCE || _SVID_SOURCE

drem(), dremf(), dreml():

    /* Desde glibc 2.19: */ _DEFAULT_SOURCE
        || /* glibc <= 2.19: */ _BSD_SOURCE || _SVID_SOURCE

DESCRIPCIÓN

Estas funciones calculan el resto de la división de x entre y. El valor de retorno es x-n*y, donde n es el valor x / y, redondeado al entero más cercano. Si el valor absoluto de x-n*y es 0.5, n se elige para que sea par.

Estas funciones no se ven afectadas por el modo de redondeo actual (ver fenv(3)).

La función drem() hace precisamente lo mismo.

VALOR DE RETORNO

En caso de éxito, estas funciones devuelven el resto de punto flotante, x-n*y. Si el valor de retorno es 0, tiene el signo de x.

Si x o y es un NaN, se devuelve un NaN.

Si x es un infinito y y no es un NaN, ocurre un error de dominio y se devuelve un NaN.

Si y es cero y x no es un NaN, ocurre un error de dominio y se devuelve un NaN.

ERRORES

Ver math_error(7) para información sobre cómo determinar si ha ocurrido un error al llamar a estas funciones.

Los siguientes errores pueden ocurrir:

Error de dominio: x es un infinito y y no es un NaN
errno se establece en EDOM (pero ver BUGS). Se genera una excepción de punto flotante inválida (FE_INVALID).
Estas funciones no establecen errno para este caso.
Error de dominio: y es cero
errno se establece en EDOM. Se genera una excepción de punto flotante inválida (FE_INVALID).

BUGS

Antes de glibc 2.15, la llamada


remainder(nan(""), 0);

devuelve un NaN, como se esperaba, pero erróneamente causó un error de dominio. Desde glibc 2.15, se devuelve un NaN silencioso (es decir, sin error de dominio).

Antes de glibc 2.15, errno no se establecía en EDOM para el error de dominio que ocurre cuando x es un infinito y y no es un NaN.

EJEMPLOS

La llamada "remainder(29.0, 3.0)" devuelve -1.

remainder(3)

remainder - resto de la división de punto flotante

NOMBRE

remainder - resto de la división de punto flotante

SINOPSIS

#define _GNU_SOURCE
#include <math.h>

double remainder(double x, double y);
float remainderf(float x, float y);
long double remainderl(long double x, long double y);

DESCRIPCIÓN

La función remainder() calcula el resto de la división de x entre y. El resultado es el valor de x - n * y, donde n es el entero más cercano al valor exacto de x / y. Si x / y está exactamente a medio camino entre dos enteros, se elige el entero par.

El resultado tiene el mismo signo que x y su magnitud es menor que la magnitud de y.

El comportamiento de remainder() es diferente al de fmod(), que calcula el resto truncando el cociente hacia cero. remainder() busca redondear el cociente al entero más cercano.

La función también establece la variable global errno si ocurre algún error, aunque esto es poco común para esta función.

VALOR DE RETORNO

En caso de éxito, remainder() devuelve el resto de la división de punto flotante de x entre y.

Si el divisor y es cero, el comportamiento está definido por la implementación. Algunas implementaciones pueden devolver NaN y establecer errno a EDOM o ERANGE, mientras que otras pueden generar una excepción de punto flotante.

ERRORES

  • EDOM: El divisor y es cero.
