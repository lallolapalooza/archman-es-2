REDO-IFCREATE(1) Manual de Comandos Generales REDO-IFCREATE(1)

NOMBRE

redo-ifcreate - reconstruye archivos objetivo cuando se crean archivos fuente

SINOPSIS

redo-ifcreate objetivo [objetivo]...

DESCRIPCIÓN

redo(1) es una herramienta para construir archivos y para reconstruirlos si alguna de sus dependencias ha cambiado. redo-ifcreate, cuando se invoca desde un dofile, agrega dependencias de no existencia del redo(1) objetivo actual en todos los archivos dados como argumentos. Esto significa que el objetivo actual se reconstruirá en la invocación de redo(1) si alguno de los archivos dados como argumentos a redo-ifcreate existe. Si un argumento para redo-ifcreate existe, saldrá con un código de estado que indica fallo.

EJEMPLOS

Considera los siguientes dos archivos all.do y b.do:

all.do

#!/bin/sh
redo-ifchange b
b.do

#!/bin/sh
if [ ! -e c ]; then
redo-ifcreate c
fi
date +%s

Invocar redo(1) en un directorio con estos archivos que no contiene un archivo llamado c creará un archivo llamado b que contiene una marca de tiempo. La próxima vez que se invoque redo(1), solo reconstruirá b si se creó un archivo llamado c desde la última construcción. Esto se puede verificar invocando redo(1) repetidamente y examinando la marca de tiempo de b después de cada invocación, luego creando un archivo llamado c, invocando redo(1) nuevamente y examinando la marca de tiempo nuevamente.
