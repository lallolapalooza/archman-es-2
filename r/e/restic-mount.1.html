NOMBRE

restic-mount - Montar el repositorio

SINOPSIS

restic mount [flags] punto_de_montaje

DESCRIPCIÓN

El comando "mount" monta el repositorio a través de fuse en un directorio. Este es un montaje de solo lectura.

Directorios de Snapshots

Si necesitas una plantilla diferente para los directorios que contienen snapshots, puedes pasar una plantilla de tiempo a través de --time-template y plantillas de ruta a través de --path-template.

Ejemplo de plantilla de tiempo sin dos puntos:

--time-template "2006-01-02_15-04-05"

Debes especificar un formato de muestra para la marca de tiempo exacta siguiente:

Lun Ene 2 15:04:05 -0700 MST 2006

Para más detalles, por favor, consulta la documentación de time.Format() en:
https://godoc.org/time#Time.Format

Para las plantillas de ruta, puedes usar los siguientes patrones que serán reemplazados:
%i por el ID corto del snapshot
%I por el ID largo del snapshot
%u por el nombre de usuario
%h por el nombre del host
%t por las etiquetas
%T por la marca de tiempo según lo especificado por --time-template

Las plantillas de ruta predeterminadas son:
"ids/%i"
"snapshots/%T"
"hosts/%h/%T"
"tags/%t/%T"

ESTADO DE SALIDA

El estado de salida es 0 si el comando se completó con éxito. El estado de salida es 1 si hubo algún error. El estado de salida es 10 si el repositorio no existe. El estado de salida es 11 si el repositorio ya está bloqueado. El estado de salida es 12 si la contraseña es incorrecta.

OPCIONES

--allow-other[=false] permite a otros usuarios acceder a los datos en el directorio montado

-h, --help[=false] ayuda para mount

-H, --host=[] considerar solo snapshots para este host (se puede especificar varias veces) (predeterminado: $RESTIC_HOST)

--no-default-permissions[=false] para 'allow-other', ignora los permisos de Unix y permite a los usuarios leer todos los archivos de snapshot

--owner-root[=false] usa 'root' como el propietario de archivos y directorios

--path=[] considerar solo snapshots que incluyan esta (ruta absoluta) ruta (se puede especificar varias veces, los snapshots deben incluir todas las rutas especificadas)

--path-template=[] establece la plantilla para los nombres de ruta (se puede especificar varias veces)

--tag=[] considerar solo snapshots que incluyan tag[,tag,...] (se puede especificar varias veces)

--time-template="2006-01-02T15:04:05Z07:00" establece la plantilla a usar para las horas

OPCIONES HEREDADAS DE COMANDOS PADRE

--cacert=[] archivo desde el cual cargar certificados raíz (predeterminado: usar certificados del sistema o $RESTIC_CACERT)

--cache-dir="" establece el directorio de caché. (predeterminado: usar el directorio de caché predeterminado del sistema)

--cleanup-cache[=false] elimina automáticamente directorios de caché antiguos

--compression=auto modo de compresión (solo disponible para la versión 2 del formato del repositorio), uno de (auto|off|max) (predeterminado: $RESTIC_COMPRESSION)

--http-user-agent="" establece un agente de usuario http para las solicitudes http salientes

--insecure-no-password[=false] usa una contraseña vacía para el repositorio, debe pasarse a cada comando restic (inseguro)

--insecure-tls[=false] omite la verificación del certificado TLS al conectarse al repositorio (inseguro)

--json[=false] establece el modo de salida a JSON para comandos que lo admitan

--key-hint="" ID de clave de la clave a intentar descifrar primero (predeterminado: $RESTIC_KEY_HINT)

--limit-download=0 limita las descargas a una tasa máxima en KiB/s. (predeterminado: ilimitado)

--limit-upload=0 limita las subidas a una tasa máxima en KiB/s. (predeterminado: ilimitado)

--no-cache[=false] no usar caché local

--no-extra-verify[=false] omite la verificación adicional de datos antes de la subida (ver documentación)

--no-lock[=false] no bloquear el repositorio, esto permite algunas operaciones en repositorios de solo lectura

-o, --option=[] establece una opción extendida (clave=valor, se puede especificar varias veces)

--pack-size=0 establece el tamaño del paquete objetivo en MiB, los archivos de paquete creados pueden ser más grandes (predeterminado: $RESTIC_PACK_SIZE)

--password-command="" comando de shell para obtener la contraseña del repositorio de (predeterminado: $RESTIC_PASSWORD_COMMAND)

-p, --password-file="" archivo desde el cual leer la contraseña del repositorio (predeterminado: $RESTIC_PASSWORD_FILE)

-q, --quiet[=false] no mostrar informe de progreso completo

-r, --repo="" repositorio donde hacer copias de seguridad o restaurar (predeterminado: $RESTIC_REPOSITORY)

--repository-file="" archivo desde el cual leer la ubicación del repositorio (predeterminado: $RESTIC_REPOSITORY_FILE)

--retry-lock=0s reintentar bloquear el repositorio si ya está bloqueado, toma un valor como 5m o 2h (predeterminado: sin reintentos)

--stuck-request-timeout=5m0s duración después de la cual se reintentarán las solicitudes bloqueadas

--tls-client-cert="" ruta a un archivo que contiene el certificado de cliente TLS y la clave privada codificados en PEM (predeterminado: $RESTIC_TLS_CLIENT_CERT)

-v, --verbose[=0] ser verboso (especificar varias veces o un nivel usando --verbose=n, nivel/veces máximo es 2)
