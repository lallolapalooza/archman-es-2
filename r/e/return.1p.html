RETURN(1P) Manual del programador POSIX RETURN(1P)

PRÓLOGO

Esta página del manual forma parte del Manual del Programador POSIX. La implementación de Linux de esta interfaz puede diferir (consulte la página del manual de Linux correspondiente para obtener detalles del comportamiento de Linux), o la interfaz puede no estar implementada en Linux.

NOMBRE

return — regresar de una función o script dot

SINOPSIS

return [n]

DESCRIPCIÓN

La utilidad return hará que el shell deje de ejecutar la función o el script dot actual. Si el shell no está ejecutando actualmente una función o un script dot, los resultados no están definidos.

ESTADO DE SALIDA

El valor del parámetro especial '?' se establecerá en n, un entero decimal sin signo, o en el estado de salida del último comando ejecutado si n no se especifica. Si n no es un entero decimal sin signo, o es mayor que 255, los resultados no están definidos. Cuando se ejecuta return en una acción trap, el último comando se considera el comando ejecutado inmediatamente antes de la acción trap.

USO DE LA APLICACIÓN

Ninguno.

EJEMPLOS

Ninguno.

FUNDAMENTO

El comportamiento de return cuando no está en una función o en un script dot difiere entre el shell System V y el KornShell. En el shell System V esto es un error, mientras que en el KornShell, el efecto es el mismo que exit.

Los resultados de devolver un número mayor que 255 no están definidos debido a las diferentes prácticas en las diversas implementaciones históricas. Algunos shells realizan una operación AND bit a bit con los 8 bits menos significativos; otros permiten valores mayores, pero no de tamaño ilimitado.

Vea la discusión sobre los valores apropiados de estado de salida bajo exit.
