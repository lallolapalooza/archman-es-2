NOMBRE

registry - Manipular el registro de Windows

SINOPSIS

package require registry 1.3

registry ?-mode? option keyName ?arg arg ...?

DESCRIPCIÓN

El paquete registry proporciona un conjunto general de operaciones para manipular el registro de Windows. El paquete implementa el comando Tcl registry. Este comando solo se admite en la plataforma Windows. Advertencia: este comando debe usarse con precaución, ya que un registro corrupto puede dejar su sistema en un estado inutilizable.

keyName es el nombre de una clave de registro. Las claves de registro deben tener una de las siguientes formas:

\\hostname\rootname\keypath

rootname\keypath

rootname

Hostname especifica el nombre de cualquier host de Windows válido que exporte su registro. El componente rootname debe ser uno de HKEY_LOCAL_MACHINE, HKEY_USERS, HKEY_CLASSES_ROOT, HKEY_CURRENT_USER, HKEY_CURRENT_CONFIG, HKEY_PERFORMANCE_DATA, o HKEY_DYN_DATA. El keypath puede ser uno o más nombres de claves de registro separados por caracteres de barra invertida (\).

El argumento opcional -mode indica con qué registro trabajar; cuando es -32bit se usará el registro de 32 bits y cuando es -64bit se usará el registro de 64 bits. Si se omite este argumento, el registro predeterminado del sistema será el sujeto de la operación solicitada.

Option indica qué hacer con el nombre de la clave de registro. Se acepta cualquier abreviatura única de option. Las opciones válidas son:

registry broadcast keyName ?-timeout milliseconds?
Envía un mensaje de difusión al sistema y a los programas en ejecución para notificarles sobre ciertas actualizaciones. Esto es necesario para propagar cambios en claves de registro importantes como Environment. El tiempo de espera especifica la cantidad de tiempo, en milisegundos, para esperar a que las aplicaciones respondan al mensaje de difusión. El valor predeterminado es 3000. El siguiente ejemplo demuestra cómo agregar una ruta al entorno global y notificar a las aplicaciones sobre el cambio sin requerir un cierre de sesión/inicio de sesión (asume privilegios de administrador):
set regPath [join {
    HKEY_LOCAL_MACHINE
    SYSTEM
    CurrentControlSet
    Control
    {Session Manager}
    Environment
} "\\"]
set curPath [registry get $regPath "Path"]
registry set $regPath "Path" "$curPath;$addPath"
registry broadcast "Environment"
registry delete keyName ?valueName?
Si está presente el argumento opcional valueName, se eliminará del registro el valor especificado bajo keyName. Si se omite el valueName opcional, se eliminará la clave especificada y todas las subclaves o valores debajo de ella en la jerarquía del registro. Si la clave no pudo ser eliminada, se genera un error. Si la clave no existía, el comando no tiene efecto.
registry get keyName valueName
Devuelve los datos asociados con el valor valueName bajo la clave keyName. Si la clave o el valor no existen, se genera un error. Para más detalles sobre el formato de los datos devueltos, consulte TIPOS ADMITIDOS, más abajo.
registry keys keyName ?pattern?
Si no se especifica pattern, devuelve una lista de nombres de todas las subclaves de keyName. Si se especifica pattern, solo se devuelven aquellos nombres que coincidan con pattern. La coincidencia se determina utilizando las mismas reglas que para string match. Si la keyName especificada no existe, se genera un error.
registry set keyName ?valueName data ?type??
Si no se especifica valueName, crea la clave keyName si aún no existe. Si se especifica valueName, crea la clave keyName y el valor valueName si es necesario. El contenido de valueName se establece en data con el tipo indicado por type. Si no se especifica type, se asume el tipo sz. Para más detalles sobre los argumentos de datos y tipo, consulte TIPOS ADMITIDOS más abajo.
registry type keyName valueName
Devuelve el tipo del valor valueName en la clave keyName. Para más información sobre los posibles tipos, consulte TIPOS ADMITIDOS más abajo.
registry values keyName ?pattern?
Si no se especifica pattern, devuelve una lista de nombres de todos los valores de keyName. Si se especifica pattern, solo se devuelven aquellos nombres que coincidan con pattern. La coincidencia se determina utilizando las mismas reglas que para string match.

TIPOS ADMITIDOS

Cada valor bajo una clave en el registro contiene algunos datos de un tipo particular en una representación específica del tipo. El comando registry convierte entre esta representación interna y una que puede ser manipulada por scripts Tcl. En la mayoría de los casos, los datos se devuelven simplemente como una cadena Tcl. El tipo indica el uso previsto para los datos, pero en realidad no cambia la representación. Para algunos tipos, el comando registry devuelve los datos en un formato diferente para facilitar su manipulación. Los siguientes tipos son reconocidos por el comando registry:

binary
El valor del registro contiene datos binarios arbitrarios. Los datos se representan exactamente en Tcl, incluyendo cualquier nulo incrustado.
none
El valor del registro contiene datos binarios arbitrarios sin tipo definido. Los datos se representan exactamente en Tcl, incluyendo cualquier nulo incrustado.
sz
El valor del registro contiene una cadena terminada en nulo. Los datos se representan en Tcl como una cadena.
expand_sz
El valor del registro contiene una cadena terminada en nulo que contiene referencias no expandidas a variables de entorno en el estilo normal de Windows (por ejemplo, “%PATH%”). Los datos se representan en Tcl como una cadena.
dword
El valor del registro contiene un número de 32 bits little-endian. Los datos se representan en Tcl como una cadena decimal.
dword_big_endian
El valor del registro contiene un número de 32 bits big-endian. Los datos se representan en Tcl como una cadena decimal.
link
El valor del registro contiene un enlace simbólico. Los datos se representan exactamente en Tcl, incluyendo cualquier nulo incrustado.
multi_sz
El valor del registro contiene una matriz de cadenas terminadas en nulo. Los datos se representan en Tcl como una lista de cadenas.
resource_list
El valor del registro contiene una lista de recursos del controlador de dispositivo. Los datos se representan exactamente en Tcl, incluyendo cualquier nulo incrustado.

Además de los tipos nombrados simbólicamente enumerados anteriormente, los tipos desconocidos se identifican mediante un entero de 32 bits que corresponde al código de tipo devuelto por las interfaces del sistema. En este caso, los datos se representan exactamente en Tcl, incluyendo cualquier nulo incrustado.

PROBLEMAS DE PORTABILIDAD

El comando registry solo está disponible en Windows.

EJEMPLO

Imprime cómo hacer doble clic en un archivo de script Tcl invocará un intérprete Tcl:

package require registry
set ext .tcl
# Leer el nombre del tipo
set type [registry get HKEY_CLASSES_ROOT\\$ext {}]

registry

NAME

registry - acceder al registro de Windows

SYNOPSIS

registry ?subcommand?

DESCRIPTION

El comando registry proporciona una interfaz Tcl para el registro de Windows. Permite leer y escribir en el registro, así como obtener una lista de las claves y valores de una clave dada.

El comando registry admite los siguientes subcomandos:

registry delete keyName ?valueName?
Elimina la clave o el valor especificado del registro. Si se omite valueName, se elimina la clave keyName. Si keyName es una clave vacía, no se eliminará.
registry get keyName ?valueName?
Devuelve el valor de la entrada de valor especificada en la clave especificada. Si se omite valueName, devuelve una lista de los nombres de valor de la clave especificada.
registry keys keyName
Devuelve una lista de los nombres de las subclaves de la clave especificada.
registry set keyName ?valueName? value
Establece el valor de la entrada de valor especificada en la clave especificada. Si se omite valueName, el valor se establece en la entrada de valor predeterminada de la clave. El tipo de value se determina automáticamente (cadena, entero, binario).
registry values keyName
Devuelve una lista de las entradas de valor de la clave especificada. Cada entrada de valor se devuelve como un par de lista: {nombre_valor datos_valor}.

SUPPORTED TYPES

El comando registry admite los siguientes tipos de datos del registro:

REG_SZ
Cadena de caracteres.
REG_EXPAND_SZ
Cadena expandible.
REG_MULTI_SZ
Múltiples cadenas de caracteres.
REG_DWORD
Entero de 32 bits.
REG_QWORD
Entero de 64 bits.
REG_BINARY
Datos binarios.

PORTABILITY ISSUES

Este comando solo está disponible en Windows.

EXAMPLE

# Define la extensión de archivo
set ext .txt
# Construye la ruta a la clave del registro para la extensión
set path HKEY_CLASSES_ROOT\\$ext\\Shell\\Open\\command
# Lee el comando!
set command [registry get $path {}]
puts "$ext abre con $command"
