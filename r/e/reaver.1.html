Reaver(1) Manual de comandos generales Reaver(1)

NOMBRE

Reaver - Cracker de WPS

SINOPSIS

reaver -i <interfaz> -b <bssid_objetivo> -vv

DESCRIPCIÓN

Reaver implementa un ataque de fuerza bruta contra WiFi Protected Setup que puede descifrar el PIN de WPS de un punto de acceso en cuestión de horas y, posteriormente, recuperar la contraseña WPA/WPA2.

Específicamente, Reaver se dirige a la funcionalidad de registro de WPS, que es defectuosa en el sentido de que solo se necesitan 11.000 intentos para adivinar el PIN de WPS correcto para convertirse en un registrador de WPS. Una vez registrado como registrador con el punto de acceso, el punto de acceso te proporcionará la contraseña WPA.

OPCIONES

-m, --mac=<mac>
MAC del sistema host (debería resolverse automáticamente)
-e, --essid=<ssid>
ESSID del AP objetivo. A menos que esté oculto, esto se resolverá automáticamente.
-c, --channel=<canal>
Establecer el canal 802.11 para la interfaz (implica -f)
-o, --out-file=<archivo>
Enviar salida a un archivo de registro [predeterminado: stdout]
-f, --fixed
Desactivar el salto de canal
-5, --5ghz
Usar canales 802.11 de 5 GHz
-v, --verbose
Mostrar advertencias no críticas (-vv para más)
-q, --quiet
Mostrar solo mensajes críticos
-i, --interface=<wlan>
Nombre de la interfaz en modo monitor a usar
-b, --bssid=<mac>
BSSID del AP objetivo
-p, --pin=<wps pin>
Usar el PIN de WPS especificado
-h, --help
Mostrar ayuda
