RECOLL(1) Manual de comandos generales RECOLL(1)

NOMBRE

recoll - interfaz de usuario para el sistema de búsqueda de texto completo Recoll

SINOPSIS

recoll [ -h ] [ -c <directorio_config> ] [ -L <idioma> ] [ -w ] [ -W ] [ -o | -l | -f | -a ] [ -q <consulta> ]

recoll -t [ -h ] [ -c <directorio_config> ] [ -o | -l | -f | -a ] [ -q <consulta> ]

recoll [ -c <directorio_config> ] <url>

DESCRIPCIÓN

En la primera forma, el comando recoll iniciará la interfaz gráfica de usuario para la consulta del índice. En la primera ejecución, esto creará la configuración del usuario, que puede personalizarse antes de iniciar la creación del índice.

En la segunda forma (con la opción -t), recoll se comportará como el comando recollq. No iniciará una GUI, sino que ejecutará la consulta y mostrará los resultados en la terminal (salida estándar). Este también será el caso si recoll se llama como recollq a través de un enlace. En este caso, se pueden especificar opciones adicionales entendidas por el comando recollq. Estas pueden controlar el formato de salida y el número máximo de resultados a imprimir. Consulte la ayuda del comando obtenida a través de las opciones -t -h, o la página del manual de recollq para una descripción completa.

La opción -c especifica el nombre del directorio de configuración, reemplazando el predeterminado o $RECOLL_CONFDIR.

Con la opción -w, la GUI se inicia minimizada, lo que puede ser útil para iniciarla automáticamente con el escritorio. -W es similar, pero solo mostrará un icono en la bandeja del sistema. Solo se puede usar si la opción de bandeja del sistema está configurada en las preferencias.

La opción -q se puede usar para especificar una consulta inicial en la línea de comandos. Por defecto, esta consulta se interpretará como una cadena de lenguaje de consulta. Si se especifica -a, la cadena de consulta se interpretará como una consulta simple de búsqueda de *todas las palabras*. Si se especifica -o, la cadena de consulta se interpretarará como una consulta simple de búsqueda de *cualquier palabra*. Si se especifica -f, la cadena de consulta se interpretará como una consulta simple de búsqueda de *nombre de archivo*. Si se especifica -l (o, por defecto, sin ninguna opción), la cadena de consulta se interpretará como una consulta simple de búsqueda en *lenguaje de consulta*.

En la tercera forma, el comando recoll se puede usar para iniciar un visor nativo para un documento indexado por Recoll. Entenderá un fragmento de URL final (separado por un carácter '#') para indicar un *ipath*, el especificador de la parte de la ruta de acceso del documento Recoll que es interna a un contenedor como una carpeta mbox o un archivo zip, y, si es necesario, creará un archivo temporal para permitir que una utilidad del sistema normal muestre el documento. Esta forma se utiliza principalmente para abrir documentos incrustados desde una interfaz de búsqueda de escritorio externa.
