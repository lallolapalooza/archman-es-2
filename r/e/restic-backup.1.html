NOMBRE

restic-backup - Crear una nueva copia de seguridad de archivos y/o directorios

SINOPSIS

restic backup [opciones] [ARCHIVO/DIR] ...

DESCRIPCIÓN

El comando "backup" crea una nueva instantánea y guarda los archivos y directorios dados como argumentos.

ESTADO DE SALIDA

El estado de salida es 0 si el comando se ejecutó correctamente. El estado de salida es 1 si hubo un error fatal (no se creó ninguna instantánea). El estado de salida es 3 si no se pudo leer algunos datos de origen (se creó una instantánea incompleta). El estado de salida es 10 si el repositorio no existe. El estado de salida es 11 si el repositorio ya está bloqueado. El estado de salida es 12 si la contraseña es incorrecta.

OPCIONES

-n, --dry-run[=false] no subir ni escribir ningún dato, solo mostrar lo que se haría

-e, --exclude=[] excluir un patrón (se puede especificar varias veces)

--exclude-caches[=false] excluye directorios de caché marcados con un archivo CACHEDIR.TAG. Véase https://bford.info/cachedir/ para el Estándar de Etiquetado de Directorios de Caché

--exclude-file=[] leer patrones de exclusión de un archivo (se puede especificar varias veces)

--exclude-if-present=[] toma nombre_archivo[:encabezado], excluye el contenido de los directorios que contienen nombre_archivo (excepto el propio nombre_archivo) si el encabezado de ese archivo es el proporcionado (se puede especificar varias veces)

--exclude-larger-than="" tamaño máximo de los archivos a respaldar (sufijos permitidos: k/K, m/M, g/G, t/T)

--files-from=[] leer los archivos a respaldar de archivo (se puede combinar con argumentos de archivo; se puede especificar varias veces)

--files-from-raw=[] leer los archivos a respaldar de archivo (se puede combinar con argumentos de archivo; se puede especificar varias veces)

--files-from-verbatim=[] leer los archivos a respaldar de archivo (se puede combinar con argumentos de archivo; se puede especificar varias veces)

-f, --force[=false] forzar la relectura de los archivos/directorios de origen (anula la bandera "parent")

-g, --group-by=host,paths agrupar instantáneas por host, rutas y/o etiquetas, separadas por coma (desactivar agrupación con '')

-h, --help[=false] ayuda para backup

-H, --host="" establecer el nombre del host para la instantánea manualmente (predeterminado: $RESTIC_HOST). Para evitar un reescaneo costoso, use la bandera "parent"

--iexclude=[] igual que --exclude patrón pero ignora la capitalización de los nombres de archivo

--iexclude-file=[] igual que --exclude-file pero ignora la capitalización de los nombres de archivo en los patrones

--ignore-ctime[=false] ignorar cambios en ctime al verificar archivos modificados

--ignore-inode[=false] ignorar cambios en el número de inodo y ctime al verificar archivos modificados

--no-scan[=false] no ejecutar el escáner para estimar el tamaño de la copia de seguridad

-x, --one-file-system[=false] excluir otros sistemas de archivos, no cruzar límites de sistemas de archivos y subvolúmenes

--parent="" usar esta instantánea padre (predeterminado: la última instantánea del grupo determinado por --group-by y no más reciente que la marca de tiempo determinada por --time)

--read-concurrency=0 leer n archivos concurrentemente (predeterminado: $RESTIC_READ_CONCURRENCY o 2)

--skip-if-unchanged[=false] omitir la creación de la instantánea si es idéntica a la instantánea padre

--stdin[=false] leer copia de seguridad desde stdin

--stdin-filename="stdin" nombre de archivo a usar al leer desde stdin

--stdin-from-command[=false] interpretar los argumentos como un comando a ejecutar y almacenar su salida estándar

--tag=[] añadir etiquetas para la nueva instantánea en formato etiqueta[,etiqueta,...] (se puede especificar varias veces)

--time="" hora de la copia de seguridad (ej. '2012-11-01 22:08:41') (predeterminado: ahora)

--with-atime[=false] almacenar el atime para todos los archivos y directorios

OPCIONES HEREDADAS DE COMANDOS PADRE

--cacert=[] archivo para cargar certificados raíz (predeterminado: usar certificados del sistema o $RESTIC_CACERT)

--cache-dir="" establecer el directorio de caché. (predeterminado: usar el directorio de caché predeterminado del sistema)

--cleanup-cache[=false] eliminar automáticamente directorios antiguos de caché

--compression=auto modo de compresión (solo disponible para la versión 2 del formato de repositorio), uno de (auto|off|max) (predeterminado: $RESTIC_COMPRESSION)

--http-user-agent="" establecer un agente de usuario http para las solicitudes http salientes

--insecure-no-password[=false] usar una contraseña vacía para el repositorio, debe pasarse a cada comando restic (inseguro)

--insecure-tls[=false] omitir la verificación del certificado TLS al conectarse al repositorio (inseguro)

--json[=false] establecer el modo de salida a JSON para los comandos que lo admitan

--key-hint="" ID de clave de la clave a intentar descifrar primero (predeterminado: $RESTIC_KEY_HINT)

--limit-download=0 limita las descargas a una tasa máxima en KiB/s. (predeterminado: ilimitado)

--limit-upload=0 limita las subidas a una tasa máxima en KiB/s. (predeterminado: ilimitado)

--no-cache[=false] no usar caché local

--no-extra-verify[=false] omitir la verificación adicional de datos antes de la carga (ver documentación)

--no-lock[=false] no bloquear el repositorio, esto permite algunas operaciones en repositorios de solo lectura

-o, --option=[] establecer opción extendida (clave=valor, se puede especificar varias veces)

--pack-size=0 establecer el tamaño objetivo del paquete en MiB, los archivos de paquete creados pueden ser más grandes (predeterminado: $RESTIC_PACK_SIZE)

--password-command="" comando de shell para obtener la contraseña del repositorio (predeterminado: $RESTIC_PASSWORD_COMMAND)

-p, --password-file="" archivo para leer la contraseña del repositorio (predeterminado: $RESTIC_PASSWORD_FILE)

-q, --quiet[=false] no mostrar informe de progreso detallado

-r, --repo="" repositorio al que hacer la copia de seguridad o del que restaurar (predeterminado: $RESTIC_REPOSITORY)

--repository-file="" archivo para leer la ubicación del repositorio (predeterminado: $RESTIC_REPOSITORY_FILE)

--retry-lock=0s reintentar bloquear el repositorio si ya está bloqueado, toma un valor como 5m o 2h (predeterminado: sin reintentos)

--stuck-request-timeout=5m0s duración después de la cual se reintentarán las solicitudes atascadas

--tls-client-cert="" ruta a un archivo que contenga un certificado de cliente TLS codificado en PEM y clave privada (predeterminado: $RESTIC_TLS_CLIENT_CERT)

-v, --verbose[=0] ser detallado (especificar varias veces o un nivel usando --verbose=n``, nivel/veces máximo es 2)

restic-backup(1) -- create a backup repository

NAME

restic-backup(1) - create a backup repository

SYNOPSIS

restic backup [--help] [--version] [--verbose=N] [--quiet] [ [--no-cache] [--options-file=PATH] [--json] [ [--comprepo=URI] [--repo-file=PATH] [--no-lock] [ [--password-file=PATH] [--password=PASSWORD] [--key-file=PATH] [ [--insecure-encryption] [--forget OPTIONS] [--keep-hourly=N] [--keep-daily=N] [--keep-weekly=N] [--keep-monthly=N] [--keep-yearly=N] [--keep-tag=TAG] [--keep-within=DURATION] [--keep-last=N] [--prune] [--max-unused=PERCENT] [--list-unreferenced] [--ren TAG] [--ren-tag=OLDTAG[=NEWTAG]] [--tag=TAG] [--host=HOSTNAME] [--time=DATETIME] [--ignore-empty] [--exclude=PATTERN] [--exclude-from=FILE] [--exclude-repo=PATTERN] [--exclude-caches] [--include=PATTERN] [--include-from=FILE] [--files-from=FILE] [--read-sparse-files] [--disable-full-backup] [--threshold=PERCENT] [--cache-dir=PATH] [--no-subdirs] [--glob] [--path=PATH] [--repo-path=PATH] [PATH]...

DESCRIPTION

The backup command creates a backup of the specified files and directories. It is also possible to save the backup to a repository located in a directory (not necessarily a git repository).

The backup command uses the repository located in the directory pointed to by the environment variable RESTIC_REPOSITORY or --repo.

If the repository does not exist, it will be created.

All files and directories specified on the command line are backed up. This command backs up the files and directories specified on the command line. The files and directories are stored in the repository.

The command creates a snapshot of the specified files and directories. A snapshot is a read-only copy of the files and directories at a specific point in time.

The backup command supports the following options:

--help: Print help information.

--version: Print version information.

--verbose=N: Increase verbosity level.

--quiet: Suppress output.

--no-cache: Do not use the cache.

--options-file=PATH: Read options from a file.

--json: Output in JSON format.

--comprepo=URI: Use a compressed repository.

--repo-file=PATH: Use a repository file.

--no-lock: Do not lock the repository.

--password-file=PATH: Read password from a file.

--password=PASSWORD: Password for the repository.

--key-file=PATH: Key file for the repository.

--insecure-encryption: Do not encrypt the repository.

--forget OPTIONS: Forget old snapshots.

--keep-hourly=N: Keep N hourly snapshots.

--keep-daily=N: Keep N daily snapshots.

--keep-weekly=N: Keep N weekly snapshots.

--keep-monthly=N: Keep N monthly snapshots.

--keep-yearly=N: Keep N yearly snapshots.

--keep-tag=TAG: Keep snapshots with the given tag.

--keep-within=DURATION: Keep snapshots within the given duration.

--keep-last=N: Keep the last N snapshots.

--prune: Remove unused data from the repository.

--max-unused=PERCENT: Maximum percentage of unused data to keep.

--list-unreferenced: List unreferenced data.

--ren TAG: Rename snapshots.

--ren-tag=OLDTAG[=NEWTAG]: Rename tags.

--tag=TAG: Add a tag to the snapshot.

--host=HOSTNAME: Set the host name for the snapshot.

--time=DATETIME: Set the time for the snapshot.

--ignore-empty: Ignore empty files.

--exclude=PATTERN: Exclude files matching the pattern.

--exclude-from=FILE: Read exclude patterns from a file.

--exclude-repo=PATTERN: Exclude repository files.

--exclude-caches: Exclude cache directories.

--include=PATTERN: Include files matching the pattern.

--include-from=FILE: Read include patterns from a file.

--files-from=FILE: Read file paths from a file.

--read-sparse-files: Read sparse files.

--disable-full-backup: Disable full backup.

--threshold=PERCENT: Percentage of disk usage to trigger a full backup.

--cache-dir=PATH: Directory for the cache.

--no-subdirs: Do not back up subdirectories.

--glob: Use glob patterns for file paths.

--path=PATH: Path to back up.

--repo-path=PATH: Path to the repository.

EXIT STATUS

The backup command exits with a non-zero status if any error occurs.

OPTIONS

See restic-backup(1) for a list of all options.

See restic(1) for a list of options inherited from parent commands.
