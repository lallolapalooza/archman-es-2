CREATEPYMB(1) Manual de comandos generales CREATEPYMB(1)

NOMBRE

createPYMB, readPYBase, readPYMB, mb2org, scel2org - herramientas relacionadas con Pinyin de fcitx

SINOPSIS

createPYMB <ArchivoPinyin> <ArchivoFrase>

readPYBase [-b <ArchivoMBPinyin>] [-h]

readPYMB [-f <ArchivoMBFrase>] [-s] [-h]

mb2org [-b <ArchivoMBPinyin>] [-f <ArchivoMBFrase>] [-s] [-h]

scel2org [-o <ArchivoFrase>] [-h]

DESCRIPCIÓN

-b <ArchivoMBPinyin>
Si no se especifica, leerá el pybase.mb predeterminado del sistema.
-f <ArchivoMBFrase>
Si no se especifica, leerá el archivo PhraseMB predeterminado del usuario, que es ~/.config/fcitx/pyusrphrase.mb.
-s
Si se especifica, leerá PhraseMBFile como formato de sistema, de lo contrario lo leerá como formato de usuario.
-h
Muestra la ayuda y sale
Archivo Pinyin
El Archivo Pinyin es un archivo con pinyin y un carácter por línea, separados por espacios. Un archivo disponible está en la fuente de fcitx, llamado gbkpy.org.
Archivo Frase
El Archivo Frase es un archivo con pinyin completo separado por ' y la frase correspondiente. El archivo de frase predeterminado de fcitx se puede descargar en http://fcitx.googlecode.com/files/pinyin.tar.gz.
Archivo MB Pinyin
El Archivo MB Pinyin es el formato binario del Archivo Pinyin.
Archivo MB Frase
El Archivo MB Frase es el formato binario del Archivo Pinyin, el archivo mb de frases del historial del usuario es ~/.config/fcitx/pyuserphrase.mb. Hay dos formatos diferentes, uno es el formato de sistema que solo puede ser generado por createPYMB, y el otro es el formato de usuario que solo puede ser generado mientras se introduce con el IM Pinyin de fcitx.
La salida de createPYMB será pybase.mb, que es el Archivo MB Pinyin, y pyphrase.mb, que es el Archivo MB Frase.
La salida de mb2org, readPYBase y readPYMB será stdout. readPYBase y readPYMB están diseñados para mostrar más mensajes de depuración del Archivo MB Pinyin y el Archivo MB Frase. mb2org se mostrará en el formato del Archivo Frase.
scel2org se usa para transformar el Archivo Scel de Sogou al Archivo Frase de fcitx. La salida de scel2org será stdout si no se usa -o.
