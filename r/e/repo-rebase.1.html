repo-rebase(1)

Paquete: repo

Licencias: Apache-2.0

REPO(1) Manual de Repo REPO(1)

NOMBRE

repo - repo rebase - página del manual para repo rebase

SINOPSIS

repo rebase {[<proyecto>...] | -i <proyecto>...}

DESCRIPCIÓN

Resumen

Reorganiza las ramas locales sobre la rama upstream

OPCIONES

-h, --help
muestra este mensaje de ayuda y sale
--fail-fast
detiene la reorganización después del primer error
-f, --force-rebase
pasa --force-rebase a git rebase
--no-ff
pasa --no-ff a git rebase
--autosquash
pasa --autosquash a git rebase
--whitespace=WS
pasa --whitespace a git rebase
--auto-stash
guarda las modificaciones locales antes de comenzar
-m, --onto-manifest
reorganiza sobre la versión del manifiesto en lugar de HEAD upstream (esto ayuda a asegurar que el árbol local se mantenga consistente si previamente te sincronizaste con un manifiesto)

Opciones de registro:

-v, --verbose
muestra toda la salida
-q, --quiet
solo muestra errores
-i, --interactive
reorganización interactiva (solo un proyecto)

Opciones multi-manifiesto:

--outer-manifest
opera comenzando desde el manifiesto más externo
--no-outer-manifest
no opera en manifiestos externos
--this-manifest-only
opera solo en este (sub)manifiesto
--no-this-manifest-only, --all-manifests
opera en este manifiesto y sus submanifiestos

Ejecuta `repo help rebase` para ver el manual detallado.

DETALLES

'repo rebase' utiliza git rebase para mover los cambios locales en la rama de tema actual a la HEAD del historial upstream, útil cuando has hecho commits en una rama de tema pero necesitas incorporar nuevos cambios upstream "debajo" de ellos.
