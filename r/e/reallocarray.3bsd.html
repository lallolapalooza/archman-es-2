reallocarray(3bsd)

Paquete: libbsd

Licencias: custom

reallocarray(3bsd) 3bsd reallocarray(3bsd)

NOMBRE

reallocarray, recallocarray, freezero — asignación y desasignación de memoria

BIBLIOTECA

biblioteca “libbsd”

SINOPSIS

#include <stdlib.h> (Véase libbsd(7) para el uso de la inclusión.)
void *
reallocarray(void *ptr, size_t nmemb, size_t size);

void *
recallocarray(void *ptr, size_t oldnmemb, size_t nmemb, size_t size);

void
freezero(void *ptr, size_t size);

DESCRIPCIÓN

Diseñada para la asignación segura de arreglos, la función reallocarray() es similar a realloc() excepto que opera sobre nmemb miembros de tamaño size y verifica desbordamientos enteros en el cálculo nmemb * size.

Utilizada para la asignación de memoria que contiene datos sensibles, la función recallocarray() garantiza que la memoria que deja de estar asignada sea explícitamente descartada, lo que significa que los objetos libres cacheados se limpian con explicit_bzero(3).

La función recallocarray() es similar a reallocarray() excepto que asegura que la memoria recién asignada se limpie de manera similar a calloc(). Si ptr es NULL, oldnmemb se ignora y la llamada es equivalente a calloc(). Si ptr no es NULL, oldnmemb debe ser un valor tal que oldnmemb * size sea el tamaño de la asignación anterior que devolvió ptr, de lo contrario el comportamiento es indefinido. La función freezero() es similar a la función free() excepto que asegura que la memoria sea explícitamente descartada. Si ptr es NULL, no ocurre ninguna acción. Si ptr no es NULL, el argumento size debe ser igual o menor que el tamaño de la asignación anterior que devolvió ptr. freezero() garantiza que el rango de memoria que comienza en ptr con longitud size sea descartado mientras se desasigna todo el objeto originalmente asignado.

VALORES DE RETORNO

Las funciones reallocarray() y recallocarray() devuelven un puntero al espacio asignado si tienen éxito; de lo contrario, se devuelve un puntero nulo y errno se establece en ENOMEM.

Si la multiplicación de nmemb y size resulta en un desbordamiento entero, reallocarray() y recallocarray() devuelven NULL y establecen errno en ENOMEM.

Si ptr no es NULL y la multiplicación de oldnmemb y size resulta en un desbordamiento entero, recallocarray() devuelve NULL y establece errno en EINVAL.

IDIOMAs

Considere calloc() o las extensiones reallocarray() y recallocarray() cuando haya una multiplicación en el argumento size de malloc() o realloc(). Por ejemplo, evite este modismo común, ya que puede llevar a desbordamientos enteros:

if ((p = malloc(num * size)) == NULL)
	err(1, NULL);

Un reemplazo directo es reallocarray():

if ((p = reallocarray(NULL, num, size)) == NULL)
	err(1, NULL);

Alternativamente, se puede usar calloc() con el costo de la sobrecarga de inicialización.

Al usar realloc(), tenga cuidado de evitar el siguiente modismo:

size += 50;
if ((p = realloc(p, size)) == NULL)
	return (NULL);

No ajuste la variable que describe cuánta memoria se ha asignado hasta que la asignación sea exitosa. Esto puede causar un comportamiento aberrante del programa si se usa el valor de tamaño incorrecto. En la mayoría de los casos, el ejemplo anterior también resultará en una fuga de memoria. Como se indicó anteriormente, un valor de retorno de NULL indica que el objeto antiguo todavía permanece asignado. Un mejor código se ve así:

newsize = size + 50;
if ((newp = realloc(p, newsize)) == NULL) {
	free(p);
	p = NULL;
	size = 0;
	return (NULL);
}
p = newp;
size = newsize;

Al igual que con malloc(), es importante asegurarse de que el nuevo valor de tamaño no se desborde; es decir, evite asignaciones como la siguiente:

if ((newp = realloc(p, num * size)) == NULL) {
	...

En su lugar, use reallocarray():

if ((newp = reallocarray(p, num, size)) == NULL) {
	...

Llamar a realloc() con un ptr NULL es equivalente a llamar a malloc(). En lugar de este modismo:

if (p == NULL)
	newp = malloc(newsize);
else
	newp = realloc(p, newsize);

Use lo siguiente:

newp = realloc(p, newsize);

La función recallocarray() debe usarse para redimensionar objetos que contienen datos sensibles como claves. Para evitar fugas de información, garantiza que la memoria se limpie antes de colocarla en la lista interna de libres. La desasignación de dicho objeto debe hacerse llamando a freezero().

reallocarray

libbsd utility library

NAME

reallocarray ― allocate and reallocate memory arrays

LIBRARY

libbsd utility library

SYNOPSIS

void *reallocarray(void *ptr, size_t num, size_t size);

DESCRIPTION

The reallocarray() function allocates memory for an array of num elements, each of which is size bytes in size. The total size of the allocation is thus num * size bytes. If ptr is not NULL, the contents of the old memory block referred to by ptr are copied to the new memory block. The size of the new memory block is num * size bytes. If ptr is NULL, then the allocated memory is initialized to zero. If num or size is zero, reallocarray() behaves like free(). In this case, ptr must be NULL, or a pointer returned earlier by a call to reallocarray().

The reallocarray() function is a wrapper around malloc() and memcpy(). It checks for integer overflow when calculating the size of the memory block to be allocated. If an overflow occurs, reallocarray() returns NULL and sets errno to ENOMEM.

RETURN VALUES

On success, reallocarray() returns a pointer to the newly allocated memory block. On failure, reallocarray() returns NULL and sets errno to indicate the error.

IDIOMS

This function is useful for allocating memory for arrays of structures or other data types, where the size of each element is known. It can also be used to reallocate existing memory blocks, for example, to increase or decrease the size of an array.

HISTORY
