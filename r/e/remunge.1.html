REMUNGE(1) MUNGE Uid 'N' Gid Emporium REMUNGE(1)

NOMBRE

remunge - Punto de referencia de credenciales MUNGE

SINOPSIS

remunge [OPCIÓN]...

DESCRIPCIÓN

El programa remunge mide el rendimiento de MUNGE. Una prueba de rendimiento se ejecuta durante la duración especificada o hasta que se procesa el número especificado de credenciales, lo que ocurra primero. Al concluir, el número de credenciales procesadas por segundo se escribe en la salida estándar.

Por defecto, las credenciales se codifican durante un segundo usando un único hilo.

OPCIONES

-h, --help
Muestra un resumen de las opciones de la línea de comandos.
-L, --license
Muestra información de la licencia.
-V, --version
Muestra información de la versión.
-q, --quiet
Muestra solo el resultado numérico de credenciales/segundo. Esto es útil para producir archivos de entrada para ministat.
-c, --cipher cadena
Especifica el tipo de cifrado, ya sea por nombre o número.
-C, --list-ciphers
Muestra una lista de tipos de cifrado compatibles.
-m, --mac cadena
Especifica el tipo de MAC, ya sea por nombre o número.
-M, --list-macs
Muestra una lista de tipos de MAC compatibles.
-z, --zip cadena
Especifica el tipo de compresión, ya sea por nombre o número.
-Z, --list-zips
Muestra una lista de tipos de compresión compatibles.
-e, --encode
Codifica (pero no decodifica) cada credencial. Al omitir la operación de decodificación, la credencial no se almacena en la caché de repetición.
-d, --decode
Codifica y decodifica cada credencial.
-l, --length bytes
Especifica una longitud de carga útil arbitraria (en bytes). El entero puede ir seguido de un modificador de un solo carácter: k=kilobytes, m=megabytes, g=gigabytes; K=kibibytes, M=mebibytes, G=gibibytes.
-u, --restrict-uid uid
Especifica el nombre de usuario o UID permitido para decodificar la credencial. Esto se comparará con el ID de usuario efectivo del proceso que solicita la decodificación de la credencial.
-g, --restrict-gid gid
Especifica el nombre de grupo o GID permitido para decodificar la credencial. Esto se comparará con el ID de grupo efectivo del proceso que solicita la decodificación de la credencial, así como con cada grupo suplementario del que el ID de usuario efectivo de ese proceso sea miembro.
-t, --ttl segundos
Especifica el tiempo de vida (en segundos). Esto controla cuánto tiempo es válida la credencial una vez que ha sido codificada. Un valor de 0 selecciona el TTL predeterminado. Un valor de -1 selecciona el TTL máximo permitido.
-S, --socket ruta
Especifica el socket local para conectarse con munged.
-D, --duration segundos
Especifica la duración de la prueba (en segundos). La duración predeterminada es un segundo. Un valor de -1 selecciona la duración máxima. El entero puede ir seguido de un modificador de un solo carácter: s=segundos, m=minutos, h=horas, d=días.
-N, --num-creds entero
Especifica el número de credenciales a generar. El entero puede ir seguido de un modificador de un solo carácter: k=kilobytes, m=megabytes, g=gigabytes; K=kibibytes, M=mebibytes, G=gibibytes.
-T, --num-threads entero
Especifica el número de hilos a generar para procesar credenciales.
-W, --warn-time segundos
Especifica el número máximo de segundos permitido para una operación munge_encode() o munge_decode() dada antes de emitir una advertencia.

ESTADO DE SALIDA

El programa remunge devuelve un código de salida cero si la prueba de rendimiento se completa. En caso de error, imprime un mensaje de error en stderr y devuelve un código de salida distinto de cero.
