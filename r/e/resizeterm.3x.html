Paquete: ncurses

resizeterm(3X) Llamadas a biblioteca resizeterm(3X)

NOMBRE

is_term_resized, resize_term, resizeterm - gestionar las dimensiones del terminal entendidas por curses

SINOPSIS

#include <curses.h>
bool is_term_resized(int lines, int columns);
int resize_term(int lines, int columns);
int resizeterm(int lines, int columns);

DESCRIPCIÓN

Esta es una extensión de la biblioteca curses. Proporciona a los llamadores un punto de conexión en los datos de ncurses para redimensionar ventanas, principalmente para ser utilizada por programas que se ejecutan en un terminal X Window (por ejemplo, xterm) cuando el usuario cambia el tamaño de la pantalla del terminal:

  • Las ventanas de curses no pueden extenderse fuera de la pantalla. Si el terminal se encoge, las ventanas de curses deben encogerse para caber.
  • Si el terminal se estira, se pueden añadir filas y/o columnas a las ventanas existentes. Las celdas añadidas deben coincidir con los atributos actuales de las ventanas.

Si el programa llamante no ha configurado un manejador para SIGWINCH al inicializar ncurses (por ejemplo, usando initscr(3X) o newterm(3X)), entonces ncurses configura un manejador para SIGWINCH que notifica a la biblioteca cuando ha ocurrido un evento de cambio de tamaño de la ventana. La biblioteca comprueba esta notificación

  • al leer datos de entrada,
  • al reanudar implícitamente el modo programa (por ejemplo, entre endwin(3X) y wrefresh(3X)), y
  • al reanudar explícitamente el modo programa en restartterm(3X).

Cuando la biblioteca detecta que el tamaño de la ventana del terminal ha cambiado, llama a resizeterm para actualizar sus estructuras de datos.

Una aplicación que establece su propio manejador de SIGWINCH puede llamar a resizeterm, pero en ese caso, la biblioteca no verá SIGWINCH y el diseño correcto dependerá de la aplicación.

FUNCIONES

resizeterm

La función resizeterm redimensiona las ventanas estándar y actual (es decir, stdscr y curscr) a las dimensiones especificadas, y ajusta otros datos de contabilidad utilizados por la biblioteca ncurses que registran las dimensiones de la ventana, como las variables LINES y COLS.

resize_term

La mayor parte del trabajo para resizeterm lo realiza la función interna resize_term. La función externa resizeterm añade contabilidad para el manejador de SIGWINCH, así como repintado del área de teclas blandas (ver slk_touch(3X)).

La función resize_term intenta redimensionar todas las ventanas. Esto ayuda con aplicaciones sencillas. Sin embargo:

  • No es posible redimensionar automáticamente los pads.
  • Las aplicaciones con diseños complicados deben comprobar KEY_RESIZE devuelto por wgetch, y ajustar su diseño, por ejemplo, usando wresize y mvwin, o recreando las ventanas.

Al redimensionar ventanas, resize_term ajusta recursivamente las subventanas, manteniéndolas dentro de los límites de la ventana padre actualizada. Si una ventana de nivel superior se extiende hasta los límites de la pantalla, entonces al redimensionar la ventana, resize_term mantendrá la ventana extendiéndose hasta el límite correspondiente, independientemente de si la pantalla se ha encogido o agrandado.

is_term_resized

Se proporciona una función de soporte is_term_resized para que las aplicaciones puedan comprobar si la función resize_term modificaría las estructuras de ventanas. Devuelve TRUE si las ventanas se modificarían, y FALSE en caso contrario.

VALOR DE RETORNO

Excepto donde se indique lo contrario, estas funciones devuelven el entero ERR en caso de fallo y OK en caso de éxito. Fallarán si alguna de las dimensiones es menor o igual a cero, o si ocurre un error al (re)asignar memoria para las ventanas.

NOTAS

Aunque estas funciones están destinadas a ser utilizadas para soportar un manejador de señales (es decir, para SIGWINCH), se debe tener cuidado de evitar invocarlas en un contexto donde malloc o realloc puedan haber sido interrumpidos, ya que las utiliza.

Si ncurses está configurado para proporcionar su propio manejador de SIGWINCH,

  • al recibir una SIGWINCH, el manejador establece una bandera
  • que se comprueba en wgetch(3X), doupdate(3X) y restartterm(3X),
  • lo que a su vez llama a la función resizeterm,
  • que hace un ungetch de un KEY_RESIZE que se leerá en la próxima llamada a wgetch.
El KEY_RESIZE alerta a una aplicación de que el tamaño de la pantalla ha cambiado y que debe repintar características especiales como los pads que no se pueden hacer automáticamente.
Llamar directamente a resizeterm o resize_term desde un manejador de señales no es seguro. Este método indirecto se utiliza para proporcionar una forma segura de redimensionar las estructuras de datos de ncurses.

Si las variables de entorno LINES o COLUMNS están establecidas, esto anula el uso por parte de la biblioteca del tamaño de ventana obtenido del sistema operativo. Por lo tanto, incluso si se recibe una SIGWINCH, es posible que no se registre ningún cambio de tamaño de pantalla.

PORTABILIDAD

Es posible redimensionar la pantalla con curses de SVr4, mediante

  • salir de curses con endwin(3X) y
  • reanudar usando refresh(3X).

Hacer eso borra la pantalla y es visualmente molesto.

Esta extensión de ncurses se introdujo a mediados de 1995. Fue adoptada en curses de NetBSD (2001) y PDCurses (2003).
