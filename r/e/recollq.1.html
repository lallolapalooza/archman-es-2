NOMBRE

recollq - comando de consulta de Recoll para línea de comandos / salida estándar.

SINOPSIS

recollq [ -c <dir_config> ] [ -o | -f | -a ] [ -b ] [ -d ] [ -A ] [ -p | -q ] [ -e ] [ -m ] [ -n <[primero-]cnt> ] [ -Q ] [ -s <idioma de stemming> ] [ -S <nombre_campo> ] [ -D ] [ -i <directorio de índice adicional> ] [ -F <lista de nombres de campo entre comillas y separadas por espacios> ] [ --extract-to <ruta de archivo> ] <cadena_consulta>

recollq -P

DESCRIPCIÓN

El comando recollq ejecutará la consulta Recoll especificada en la línea de comandos e imprimirá los resultados en la salida estándar. Está diseñado principalmente para diagnóstico, o para canalizar los datos a algún otro programa. El formato básico y sus variaciones pueden ser útiles para consultar desde la línea de comandos. La opción -F debe usarse exclusivamente para usar los datos de salida en otro programa, ya que es la única para la que se garantiza que la salida sea completamente analizable.

La opción -c especifica el nombre del directorio de configuración, reemplazando el predeterminado o $RECOLL_CONFDIR.

La cadena de consulta se construye concatenando todos los argumentos que se encuentran al final de la línea de comandos (después de las opciones). Se interpretará por defecto como una cadena de lenguaje de consulta. Se deben usar comillas según sea necesario para escapar los caracteres que el shell podría interpretar (por ejemplo, comodines). Si se especifica -a, la cadena de consulta se interpretará como una consulta de búsqueda simple de *todas las palabras*. Si se especifica -o, la cadena de consulta se interpretará como una consulta de búsqueda simple de *cualquier palabra*. Si se especifica -f, la cadena de consulta se interpretaré como una consulta de búsqueda simple de *nombre de archivo*.

Se puede especificar -b (básico) para imprimir solo las URL de los resultados en el flujo de salida.

Si se establece -d, el texto del contenido de los archivos resultantes se volcará a stdout.

Si se establece -m, se volcará todo el array de metadatos para cada documento.

Si se establece -A, se imprimirán los resúmenes del documento. Con una opción adicional -p (o -q), se mostrarán fragmentos con números de página (o números de línea), si están disponibles.

-S <nombre_campo> ordena los resultados según el campo especificado. Use -D para orden descendente.

-n <[primero-]cnt> se puede usar para establecer el número máximo de resultados que se deben imprimir. El valor predeterminado es 2000. Use un valor de 0 para no tener límite. Si el argumento tiene el formato primero-cnt, también define el primer resultado a mostrar (a partir de 0).

-s <idioma> selecciona el idioma de stemming de palabras. El valor debe coincidir con una base de datos de stemming existente (configurada o agregada con recollindex -s).

-i <db_extra> agrega el índice Xapian especificado al conjunto utilizado para la consulta. Se puede especificar varias veces.

-F <lista de campos separados por espacios> (un argumento, por ejemplo, "autor título") debe usarse para canalizar los datos a otro programa. Después de 2 líneas iniciales que muestran la consulta real y los recuentos de resultados estimados, imprimirá una línea por cada documento de resultado. Cada línea tendrá exactamente los campos solicitados en la línea de comandos. Los campos están codificados en base64 y separados por un carácter de espacio. Los campos vacíos se indican con caracteres de espacio consecutivos. Hay un carácter de espacio adicional al final de cada línea.

--extract-to <ruta de archivo> Extraerá el primer documento de resultado de la consulta a la ruta del argumento, que no debe existir. Use -n primero-cnt para seleccionar el documento.

recollq -P (Punto) imprimirá los años de modificación mínimo y máximo de los documentos en el índice.
