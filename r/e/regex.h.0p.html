NOMBRE

regex.h — tipos de coincidencia de expresiones regulares

SINOPSIS

#include <regex.h>

DESCRIPCIÓN

La cabecera <regex.h> definirá las estructuras y constantes simbólicas utilizadas por las funciones regcomp(), regexec(), regerror() y regfree().

La cabecera <regex.h> definirá el tipo de estructura regex_t, que incluirá al menos el siguiente miembro:

size_t    re_nsub    Número de subexpresiones entre paréntesis.

La cabecera <regex.h> definirá el tipo size_t según se describe en <sys/types.h>.

La cabecera <regex.h> definirá el tipo regoff_t como un tipo entero con signo que puede contener el valor más grande que se puede almacenar en un tipo ptrdiff_t o un tipo ssize_t.

La cabecera <regex.h> definirá el tipo de estructura regmatch_t, que incluirá al menos los siguientes miembros:

regoff_t    rm_so    Desplazamiento en bytes desde el inicio de la cadena
                     hasta el inicio de la subcadena.
regoff_t    rm_eo    Desplazamiento en bytes desde el inicio de la cadena
                     hasta el primer carácter después del final de la subcadena.

La cabecera <regex.h> definirá las siguientes constantes simbólicas para el parámetro cflags de la función regcomp():

REG_EXTENDED
Utilizar Expresiones Regulares Extendidas.
REG_ICASE
Ignorar mayúsculas/minúsculas en la coincidencia.
REG_NOSUB
Informar solo éxito o fracaso en regexec().
REG_NEWLINE
Cambiar el manejo de <nueva línea>.

La cabecera <regex.h> definirá las siguientes constantes simbólicas para el parámetro eflags de la función regexec():

REG_NOTBOL
El carácter circunflejo ('^'), cuando se toma como un carácter especial, no coincide con el principio de string.
REG_NOTEOL
El signo de dólar ('$'), cuando se toma como un carácter especial, no coincide con el final de string.

La cabecera <regex.h> definirá las siguientes constantes simbólicas como valores de retorno de error:

REG_NOMATCH
regexec() no encontró coincidencia.
REG_BADPAT
Expresión regular inválida.
REG_ECOLLATE
Se hizo referencia a un elemento de ordenación inválido.
REG_ECTYPE
Se hizo referencia a un tipo de clase de caracteres inválido.
REG_EESCAPE
Barra invertida al final del patrón.
REG_ESUBREG
Número en \dígito inválido o en error.
REG_EBRACK
Desequilibrio de "[]".
REG_EPAREN
Desequilibrio de "\(\)" o "()".
REG_EBRACE
Desequilibrio de "\{\}".
REG_BADBR
Contenido de "\{\}" inválido: no es un número, número demasiado grande, más de dos números, el primero mayor que el segundo.
REG_ERANGE
Extremo inválido en la expresión de rango.
REG_ESPACE
Sin memoria.
REG_BADRPT
'?', '*' o '+' no precedidos por una expresión regular válida.

Las siguientes se declararán como funciones y también pueden definirse como macros. Se proporcionarán prototipos de función.

int    regcomp(regex_t *restrict, const char *restrict, int);
size_t regerror(int, const regex_t *restrict, char *restrict, size_t);
int    regexec(const regex_t *restrict, const char *restrict, size_t,
           regmatch_t [restrict], int);
void   regfree(regex_t *);

La implementación puede definir macros o constantes adicionales con nombres que comiencen con REG_.

    • NAME

    regex.h - Regular expression matching

    SYNOPSIS

    #include <regex.h>

    DESCRIPTION

    The regex.h header defines the interface for POSIX extended regular expression matching.

    The functions available are:

    • regcomp(): Compile a regular expression.
    • regexec(): Execute a compiled regular expression.
    • regerror(): Retrieve error messages.
    • regfree(): Free memory allocated by regcomp().

    These functions are used for pattern matching and manipulation of text based on regular expressions.

    EXAMPLE

    #include <stdio.h>
#include <regex.h>

int main() {
    regex_t regex;
    int reti;
    char msgbuf[100];

    /* Compile regular expression */
    reti = regcomp(&regex, "^a-z]+$", 0);
    if (reti) {
        fprintf(stderr, "Could not compile regex\n");
        exit(1);
    }

    /* Execute regular expression */
    reti = regexec(&regex, "abc", 0, NULL, 0);
    if (!reti) {
        puts("Match found!");
    } else if (reti == REG_NOMATCH) {
        puts("No match");
    } else {
        regerror(reti, &regex, msgbuf, sizeof(msgbuf));
        fprintf(stderr, "Regex match failed: %s\n", msgbuf);
    }

    /* Free memory allocated by regcomp() */
    regfree(&regex);

    return 0;
}

    RATIONALE

    The POSIX standard for regular expressions provides a consistent and portable way to perform pattern matching in C programs. This header file is essential for any application that needs to parse or validate text based on complex patterns.

    FUTURE DIRECTIONS

    Future developments might include support for PCRE (Perl Compatible Regular Expressions) or other more advanced regex flavors, offering more features and potentially better performance for specific use cases. However, the POSIX standard remains the baseline for compatibility.
