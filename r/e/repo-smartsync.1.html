repo-smartsync(1)

Paquete: repo

Licencias: Apache-2.0

REPO(1) Manual de Repo REPO(1)

NOMBRE

repo - repo smartsync - página del manual de repo smartsync

SINOPSIS

repo smartsync [<proyecto>...]

DESCRIPCIÓN

Resumen

Actualiza el árbol de trabajo a la última revisión conocida y correcta.

OPCIONES

-h, --help
mostrar este mensaje de ayuda y salir
-j TRABAJOS, --jobs=TRABAJOS
número de trabajos a ejecutar en paralelo (por defecto: basado en el número de núcleos de CPU)
--jobs-network=TRABAJOS
número de trabajos de red a ejecutar en paralelo (por defecto --jobs o 1). Se ignora cuando se establece --interleaved
--jobs-checkout=TRABAJOS
número de trabajos de checkout locales a ejecutar en paralelo (por defecto --jobs o 8). Se ignora cuando se establece --interleaved
-f, --force-broken
opción obsoleta (se eliminará en el futuro)
--fail-fast
detener la sincronización después del primer error
--force-sync
sobrescribir un directorio git existente si necesita apuntar a un directorio de objetos diferente. ADVERTENCIA: esto puede causar pérdida de datos
--force-checkout
forzar el checkout incluso si resulta en descartar modificaciones no confirmadas. ADVERTENCIA: esto puede causar pérdida de datos
--force-remove-dirty
forzar la eliminación de proyectos con modificaciones no confirmadas si los proyectos ya no existen en el manifiesto. ADVERTENCIA: esto puede causar pérdida de datos
--rebase
reorganizar commits locales independientemente de si están publicados
-l, --local-only
solo actualizar el árbol de trabajo, no descargar
--no-manifest-update, --nmu
usar el checkout del manifiesto existente tal cual. (no actualizar a la última revisión)
--interleaved
descargar y hacer checkout de proyectos en paralelo (experimental)
-n, --network-only
solo descargar, no actualizar el árbol de trabajo
-d, --detach
separar proyectos de vuelta a la revisión del manifiesto
-c, --current-branch
descargar solo la rama actual del servidor
--no-current-branch
descargar todas las ramas del servidor
-m NOMBRE.xml, --manifest-name=NOMBRE.xml
manifiesto temporal a usar para esta sincronización
--clone-bundle
habilitar el uso de /clone.bundle en HTTP/HTTPS
--no-clone-bundle
deshabilitar el uso de /clone.bundle en HTTP/HTTPS
-u USUARIO_SERVIDOR_MANIFIESTO, --manifest-server-username=USUARIO_SERVIDOR_MANIFIESTO
nombre de usuario para autenticarse con el servidor de manifiestos
-p CONTRASEÑA_SERVIDOR_MANIFIESTO, --manifest-server-password=CONTRASEÑA_SERVIDOR_MANIFIESTO
contraseña para autenticarse con el servidor de manifiestos
--fetch-submodules
descargar submodules del servidor
--use-superproject
usar el superproyecto del manifiesto para sincronizar proyectos; implica -c
--no-use-superproject
deshabilitar el uso de superproyectos de manifiesto
--tags
descargar etiquetas
--no-tags
no descargar etiquetas (por defecto)
--optimized-fetch
descargar solo proyectos fijados a sha1 si la revisión no existe localmente
--retry-fetches=REINTENTOS_DESCARGAS
número de veces que se reintentan las descargas en errores transitorios
--prune
eliminar referencias que ya no existen en el remoto (por defecto)
--no-prune
no eliminar referencias que ya no existen en el remoto
--auto-gc
ejecutar recolección de basura en todos los proyectos sincronizados
--no-auto-gc
no ejecutar recolección de basura en ningún proyecto (por defecto)

Opciones de registro:

-v, --verbose
mostrar toda la salida
-q, --quiet
mostrar solo errores

Opciones multi-manifiesto:

--outer-manifest
operar comenzando desde el manifiesto más externo
--no-outer-manifest
no operar en manifiestos externos
--this-manifest-only
operar solo en este manifiesto (sub)
--no-this-manifest-only, --all-manifests
operar en este manifiesto y sus sub-manifiestos

Opciones de versión de repo:

--no-repo-verify
no verificar el código fuente de repo

Ejecute `repo help smartsync` para ver el manual detallado.

DETALLES

El comando 'repo smartsync' es un atajo para sync -s.

junio de 2025 repo smartsync
