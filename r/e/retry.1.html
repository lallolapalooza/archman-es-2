retry(1) Manual de comandos generales retry(1)

NOMBRE

retry - Repite un comando hasta que se cumpla un criterio, normalmente el éxito.

SINOPSIS

retry [-v] [-h] [-u hasta] [-w mientras] comando ...

DESCRIPCIÓN

La herramienta repite el comando dado hasta que el comando tenga éxito, retrocediendo con un retardo configurable entre cada intento.

Retry captura la entrada estándar en memoria mientras los datos se pasan al comando repetido, y esta entrada estándar capturada se reproduce si el comando se repite. Esto hace posible incrustar la herramienta retry en canalizaciones de shell.

Retry captura la salida estándar en memoria, y si el comando tuvo éxito, la salida estándar se pasa a la salida estándar normalmente, mientras que si el comando se repitió, la salida estándar se pasa a la salida de error en su lugar. Esto asegura que la salida se pase a la salida estándar una y solo una vez.

OPCIONES

-d segundos, --delay=segundos
El número de segundos para retroceder después de cada intento. Múltiples retardos separados por comas permiten que los retardos subsiguientes sean diferentes, con el último retardo repetido.
-j segundos, --jitter=segundos
El número de segundos de jitter para añadir a cada intento de retardo. Se añadirá un número aleatorio de nanosegundos entre cero y este número al retardo.
-m mensaje, --message=mensaje
Un mensaje para incluir en la notificación cuando retry haya retrocedido. Por defecto es el nombre del comando.
-t veces, --times=veces
Número total de veces para intentar el comando. Por defecto, lo intentamos para siempre.
-u criterio, --until=criterio
Sigue repitiendo el comando hasta que se cumpla cualquiera de los criterios separados por comas. Las opciones incluyen 'success', 'true', 'fail', 'false', un entero o un rango de enteros. El valor por defecto es 'success'.
-w criterio, --while=criterio
Sigue repitiendo el comando mientras se cumpla cualquiera de los criterios separados por comas. Las opciones incluyen 'success', 'true', 'fail', 'false', un entero o un rango de enteros.
-h, --help
Muestra este mensaje de ayuda.
-v, --version
Muestra el número de versión.

VALOR DE RETORNO

La herramienta retry devuelve el código de retorno del comando que se está ejecutando, una vez que se alcanza el criterio.

Si el comando fue interrumpido por una señal, el código de retorno es el número de señal más 128.

Si el comando no pudo ser ejecutado, o si las opciones son inválidas, se devuelve el estado 1.

EJEMPLOS

En este ejemplo básico, repetimos el comando para siempre.

        ~$ retry --until=success -- false
        retry: 'false' returned 1, backing off for 10 seconds and trying again...
        retry: 'false' returned 1, backing off for 10 seconds and trying again...
        retry: 'false' returned 1, backing off for 10 seconds and trying again...

^C

En este ejemplo más complejo, cada invocación de curl se reintenta hasta que curl tiene éxito, momento en el cual la salida estándar se pasa una y solo una vez al siguiente elemento de la canalización.

        ~$ retry -- curl --fail http://localhost/entities | \ 
        jq ... | \ 
        retry -- curl --fail -X POST http://localhost/resource | \ 
        logger -t resource-init
En este ejemplo, escalonamos cada retardo exponencialmente hasta 64 segundos, que luego se repite hasta ser interrumpido. 
        ~$ retry --until=success --delay "1,2,4,8,16,32,64" -- false
        retry: false returned 1, backing off for 1 second and trying again...
        retry: false returned 1, backing off for 2 seconds and trying again...
        retry: false returned 1, backing off for 4 seconds and trying again...
        retry: false returned 1, backing off for 8 seconds and trying again...
        retry: false returned 1, backing off for 16 seconds and trying again...
        retry: false returned 1, backing off for 32 seconds and trying again...
        retry: false returned 1, backing off for 64 seconds and trying again...
        retry: false returned 1, backing off for 64 seconds and trying again...
        retry: false returned 1, backing off for 64 seconds and trying again...

^C

En este ejemplo, intentamos tres veces antes de rendirnos.

        ~$ retry --times=3 -- false
        retry: false returned 1, backing off for 10 seconds and trying again...
        retry: false returned 1, backing off for 10 seconds and trying again...
        retry: false returned 1, giving up.
