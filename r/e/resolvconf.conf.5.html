RESOLVCONF.CONF(5) Manual de Formatos de Archivo RESOLVCONF.CONF(5)

NOMBRE

resolvconf.conf — archivo de configuración de resolvconf

DESCRIPCIÓN

resolvconf.conf es el archivo de configuración para resolvconf(8). El archivo resolvconf.conf es un script de shell que es cargado por resolvconf(8), lo que significa que resolvconf.conf debe contener comandos válidos de shell. A continuación se enumeran las variables estándar de resolvconf.conf que pueden establecerse. Si los valores contienen espacios en blanco, comodines u otros caracteres especiales de shell, asegúrese de que estén entre comillas y escapados correctamente. Vea la variable replace para un ejemplo de cómo usar comillas.

Después de actualizar este archivo, puede que desee ejecutar resolvconf -u para aplicar la nueva configuración.

Cuando una lista generada dinámicamente se añade o se antepone, el conjunto completo se hace único, prevaleciendo el que aparece más a la izquierda.

RESOLVCONF OPCIONES

resolvconf
Establecido en NO para evitar que resolvconf ejecute cualquier suscriptor. Por defecto es YES.
allow_keys
Si se establece, solo se procesarán estas claves.
deny_keys
Si se establece, estas claves no se procesarán.
exclude
Es una lista separada por espacios de pares clave/valor para coincidir. Si todos los pares clave/valor en un elemento se encuentran en el archivo, entonces todo el archivo se excluirá del procesamiento. La sintaxis es: $keyword/$match[/$keyword/$match]

Por ejemplo, dada esta configuración:

exclude="search/foo*/nameserver/1.2.3.4 search/bar.org"

Entonces cualquier resolv.conf con una opción de búsqueda que comience con foo y un servidor de nombres de 1.2.3.4 O una opción de búsqueda de bar.org sería excluido.

key_order
Estas claves se procesarán siempre primero. Si no se establece, por defecto es la siguiente: 
lo lo[0-9]*
dynamic_order
Estas claves se procesarán a continuación, a menos que tengan una métrica. Si no se establece, por defecto es la siguiente: 
tap[0-9]* tun[0-9]* vpn vpn[0-9]* wg[0-9]* ppp[0-9]* ippp[0-9]*
inclusive_keys
Ignora cualquier marca exclusiva para estas claves. Esto es útil cuando las integraciones de terceros fuerzan la opción resolvconf -x y desea deshabilitarla fácilmente.
local_nameservers
Si no se establece, por defecto es la siguiente: 
127.* 0.0.0.0 255.255.255.255 ::1
search_domains
Antepone dominios de búsqueda a la lista generada dinámicamente.
search_domains_append
Añade dominios de búsqueda a la lista generada dinámicamente.
domain_blacklist
Una lista de dominios que se eliminarán de la consideración. Para eliminar un dominio, puede usar foo.* Para eliminar un subdominio, puede usar *.bar
name_servers
Antepone servidores de nombres a la lista generada dinámicamente. Debe establecer esto en 127.0.0.1 si usa un servidor de nombres local distinto de libc.
name_servers_append
Añade servidores de nombres a la lista generada dinámicamente.
name_server_blacklist
Una lista de servidores de nombres que se eliminarán de la consideración. Por defecto es 0.0.0.0 ya que algunos routers defectuosos lo envían a través de DHCP. Para eliminar un bloque, puede usar 192.168.*
private_keys
Los servidores de nombres de estas claves solo se consultarán para los dominios listados en su resolv.conf. Útil para dominios VPN. Establecer private_keys="*" detendrá el reenvío de la zona raíz y permitirá al resolvedor local consultar recursivamente los servidores raíz directamente. Requiere un servidor de nombres local distinto de libc. Esto es equivalente a la opción resolvconf -p.
nosearch_keys
Los dominios/búsquedas de estas claves no se añadirán a la lista global de búsqueda en /etc/resolv.conf.
public_keys
Fuerza que estas claves sean públicas, anulando las marcas privadas y nosearch. Esto es útil cuando las integraciones de terceros fuerzan la opción resolvconf -p y desea deshabilitarla fácilmente.
replace
Es una lista separada por espacios de palabras clave de reemplazo. La sintaxis es: $keyword/$match/$replacement

Ejemplo, dada esta resolv.conf:

domain foo.org
search foo.org dead.beef
nameserver 1.2.3.4
nameserver 2.3.4.5

y esta configuración:

replace="search/foo*/bar.com"
replace="$replace nameserver/1.2.3.4/5.6.7.8"
replace="$replace nameserver/2.3.4.5/"

obtendría esta resolv.conf en su lugar:

domain foo.org
search bar.com
nameserver 5.6.7.8
replace_sub
Funciona de la misma manera que replace, excepto que opera en cada valor separado por espacios en lugar de en toda la línea, por lo que es útil para reemplazar un solo dominio dentro de la directiva de búsqueda. Usando el mismo ejemplo de resolv.conf y cambiando replace a replace_sub, obtendría esta resolv.conf en su lugar: 
domain foo.org
search bar.com dead.beef
nameserver 5.6.7.8
state_dir
Anula el directorio de estado por defecto de /run/resolvconf. Esto no debe cambiarse una vez que resolvconf esté en uso, a menos que el directorio antiguo se copie al nuevo.

LIBC OPCIONES

Las siguientes variables afectan directamente a resolv.conf(5):

resolv_conf
Por defecto es /etc/resolv.conf si no se establece. Establecer en /dev/null para evitar que resolvconf(8) lo modifique.
resolv_conf_options
Una lista de opciones del resolvedor libc, como se especifica en resolv.conf(5).
resolv_conf_passthrough
Cuando se establece en YES, el último resolv.conf se escribe en resolv_conf sin ninguna alteración. Cuando se establece en /dev/null o NULL, resolv_conf_local_only se establece por defecto en NO, local_nameservers no se establece a menos que se anule y solo la información establecida en resolvconf.conf se escribe en resolv_conf.

VÉASE TAMBIÉN

resolvconf(8), resolv.conf(5)

ERRORES

Cada distribución es un copo de nieve especial y le gusta nombrar la misma cosa de manera diferente, concretamente el script del servicio llamado.

El cambio entre suscriptores de resolvectl y systemd-resolved en tiempo de ejecución no es compatible. Los archivos referenciados por systemd_resolved_conf y systemd_delegate_dir deben eliminarse manualmente. Se recomienda un reinicio para eliminar los datos obsoletos. Si bien podría ejecutar ambos al mismo tiempo, se recomienda usar solo uno.

Por favor, repórtelos a https://roy.marples.name/projects/openresolv
