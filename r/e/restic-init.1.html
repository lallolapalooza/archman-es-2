NOMBRE

restic-init - Inicializa un nuevo repositorio

SINOPSIS

restic init [flags]

DESCRIPCIÓN

El comando "init" inicializa un nuevo repositorio.

ESTADO DE SALIDA

El estado de salida es 0 si el comando se ejecutó correctamente. El estado de salida es 1 si hubo algún error.

OPCIONES

--copy-chunker-params[=false] copia los parámetros del divisor del repositorio secundario (útil con el comando copy)

--from-insecure-no-password[=false] usa una contraseña vacía para el repositorio de origen (inseguro)

--from-key-hint="" ID de clave de la clave a intentar para descifrar primero el repositorio de origen (predeterminado: $RESTIC_FROM_KEY_HINT)

--from-password-command="" comando de shell para obtener la contraseña del repositorio de origen (predeterminado: $RESTIC_FROM_PASSWORD_COMMAND)

--from-password-file="" archivo para leer la contraseña del repositorio de origen (predeterminado: $RESTIC_FROM_PASSWORD_FILE)

--from-repo="" repositorio de origen para copiar los parámetros del divisor desde (predeterminado: $RESTIC_FROM_REPOSITORY)

--from-repository-file="" archivo desde el cual leer la ubicación del repositorio de origen para copiar los parámetros del divisor (predeterminado: $RESTIC_FROM_REPOSITORY_FILE)

-h, --help[=false] ayuda para init

--repository-version="stable" versión del formato del repositorio a usar, los valores permitidos son una versión de formato, 'latest' y 'stable'

OPCIONES HEREDADAS DE COMANDOS PADRE

--cacert=[] archivo para cargar certificados raíz desde (predeterminado: usar certificados del sistema o $RESTIC_CACERT)

--cache-dir="" establece el directorio de caché. (predeterminado: usar el directorio de caché predeterminado del sistema)

--cleanup-cache[=false] elimina automáticamente los directorios de caché antiguos

--compression=auto modo de compresión (solo disponible para la versión 2 del formato del repositorio), uno de (auto|off|max) (predeterminado: $RESTIC_COMPRESSION)

--http-user-agent="" establece un agente de usuario http para las solicitudes http salientes

--insecure-no-password[=false] usa una contraseña vacía para el repositorio, debe pasarse a cada comando restic (inseguro)

--insecure-tls[=false] omite la verificación del certificado TLS al conectarse al repositorio (inseguro)

--json[=false] establece el modo de salida a JSON para comandos que lo soporten

--key-hint="" ID de clave de la clave a intentar descifrar primero (predeterminado: $RESTIC_KEY_HINT)

--limit-download=0 limita las descargas a una tasa máxima en KiB/s. (predeterminado: ilimitado)

--limit-upload=0 limita las subidas a una tasa máxima en KiB/s. (predeterminado: ilimitado)

--no-cache[=false] no usar caché local

--no-extra-verify[=false] omite la verificación adicional de datos antes de la subida (ver documentación)

--no-lock[=false] no bloquear el repositorio, esto permite algunas operaciones en repositorios de solo lectura

-o, --option=[] establece una opción extendida (key=value, se puede especificar varias veces)

--pack-size=0 establece el tamaño del paquete de destino en MiB, los archivos de paquete creados pueden ser más grandes (predeterminado: $RESTIC_PACK_SIZE)

--password-command="" comando de shell para obtener la contraseña del repositorio (predeterminado: $RESTIC_PASSWORD_COMMAND)

-p, --password-file="" archivo para leer la contraseña del repositorio desde (predeterminado: $RESTIC_PASSWORD_FILE)

-q, --quiet[=false] no mostrar un informe de progreso completo

-r, --repo="" repositorio para hacer copia de seguridad o restaurar desde (predeterminado: $RESTIC_REPOSITORY)

--repository-file="" archivo desde el cual leer la ubicación del repositorio (predeterminado: $RESTIC_REPOSITORY_FILE)

--retry-lock=0s intenta bloquear el repositorio si ya está bloqueado, toma un valor como 5m o 2h (predeterminado: sin reintentos)

--stuck-request-timeout=5m0s duración después de la cual se reintentarán las solicitudes atascadas

--tls-client-cert="" ruta a un archivo que contiene el certificado de cliente TLS y la clave privada codificados en PEM (predeterminado: $RESTIC_TLS_CLIENT_CERT)

-v, --verbose[=0] ser verboso (especificar varias veces o un nivel usando --verbose=n, nivel/veces máximo es 2)
