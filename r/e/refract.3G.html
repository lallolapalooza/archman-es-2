REFRACT(3G) [FIXME: manual] REFRACT(3G)

NOMBRE

refract - calcula la dirección de refracción para un vector incidente

DECLARACIÓN

genType refract(genType I, genType N, float eta);

genDType refract(genDType I, genDType N, float eta);

PARÁMETROS

I

Especifica el vector incidente.

N

Especifica el vector normal.

eta

Especifica la relación de los índices de refracción.

DESCRIPCIÓN

Para un vector incidente dado I, normal de superficie N y relación de índices de refracción eta, refract devuelve el vector de refracción R.

R se calcula como:

    k = 1.0 - eta * eta * (1.0 - dot(N, I) * dot(N, I));
    if (k < 0.0)
        R = genType(0.0);       // o genDType(0.0)
    else
        R = eta * I - (eta * dot(N, I) + sqrt(k)) * N;

Los parámetros de entrada I y N deben estar normalizados para lograr el resultado deseado.
