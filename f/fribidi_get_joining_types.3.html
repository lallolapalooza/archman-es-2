NOMBRE

fribidi_get_joining_types - obtener tipos de unión para una cadena de caracteres

SINOPSIS

#include <../fribidi/lib/fribidi.h>

void fribidi_get_joining_types
(
const FriBidiChar *str,
const FriBidiStrIndex len,
FriBidiJoiningType *jtypes
);

PARÁMETROS

const FriBidiChar *str
Cadena de entrada.
const FriBidiStrIndex len
Longitud de la cadena de entrada.
FriBidiJoiningType *jtypes
Tipos de unión de salida.

Los valores posibles para un FriBidiJoiningType son los siguientes:

FRIBIDI_JOINING_TYPE_U
No unión, p.ej. Punto final.
FRIBIDI_JOINING_TYPE_R
Unión a la derecha, p.ej. Letra árabe Dal.
FRIBIDI_JOINING_TYPE_D
Unión dual, p.ej. Letra árabe Ain.
FRIBIDI_JOINING_TYPE_C
Causa de unión, p.ej. Tatweel, ZWJ.
FRIBIDI_JOINING_TYPE_T
Transparente, p.ej. Fatha árabe.
FRIBIDI_JOINING_TYPE_L
Unión a la izquierda, es decir, Ficticio.
FRIBIDI_JOINING_TYPE_G
Ignorado, p.ej. LRE, RLE, ZWNBSP.

DESCRIPCIÓN

Esta función encuentra los tipos de unión de una cadena de caracteres. Consulte fribidi_get_joining_type para obtener más información sobre los tipos de unión devueltos por esta función.
