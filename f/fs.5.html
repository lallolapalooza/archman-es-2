filesystems(5) Manual de formatos de archivo filesystems(5)

NOMBRE

filesystems - tipos de sistemas de archivos de Linux: ext, ext2, ext3, ext4, hpfs, iso9660, JFS, minix, msdos, ncpfs nfs, ntfs, proc, Reiserfs, smb, sysv, umsdos, vfat, XFS, xiafs

DESCRIPCIÓN

Cuando, como es costumbre, el sistema de archivos proc está montado en /proc, puedes encontrar en el archivo /proc/filesystems qué sistemas de archivos soporta actualmente tu kernel; consulta proc(5) para más detalles. También hay una llamada al sistema sysfs(2) heredada (cuya disponibilidad está controlada por la opción de configuración de compilación del kernel CONFIG_SYSFS_SYSCALL desde Linux 3.15) que permite la enumeración de los tipos de sistemas de archivos disponibles actualmente independientemente de la disponibilidad y/o sanidad de /proc.

Si necesitas un sistema de archivos no soportado actualmente, inserta el módulo del kernel correspondiente o recompila el kernel.

Para poder usar un sistema de archivos, debes montarlo; consulta mount(2) y mount(8).

La siguiente lista proporciona una breve descripción de los sistemas de archivos disponibles o históricamente disponibles en el kernel de Linux. Consulta la documentación del kernel para una descripción completa de todas las opciones y limitaciones.

erofs
es el Sistema de Archivos de Solo Lectura Mejorado (Enhanced Read-Only File System), estable desde Linux 5.4. Consulta erofs(5).
ext
es una extensión elaborada del sistema de archivos minix. Ha sido completamente reemplazada por la segunda versión del sistema de archivos extendido (ext2) y ha sido eliminada del kernel (en Linux 2.1.21).
ext2
es un sistema de archivos de disco que fue utilizado por Linux tanto para discos fijos como para medios extraíbles. El segundo sistema de archivos extendido fue diseñado como una extensión del sistema de archivos extendido (ext). Consulta ext2(5).
ext3
es una versión con registro (journaling) del sistema de archivos ext2. Es fácil cambiar entre ext2 y ext3. Consulta ext3(5).
ext4
es un conjunto de mejoras para ext3 que incluye mejoras sustanciales de rendimiento y fiabilidad, además de grandes aumentos en los límites de tamaño de volumen, archivo y directorio. Consulta ext4(5).
hpfs
es el Sistema de Archivos de Alto Rendimiento (High Performance Filesystem), utilizado en OS/2. Este sistema de archivos es de solo lectura bajo Linux debido a la falta de documentación disponible.
iso9660
es un tipo de sistema de archivos de CD-ROM que cumple con el estándar ISO/IEC 9660.
High Sierra
Linux soporta High Sierra, el precursor del estándar ISO/IEC 9660 para sistemas de archivos de CD-ROM. Se reconoce automáticamente dentro del soporte del sistema de archivos iso9660 bajo Linux.
Rock Ridge
Linux también soporta los registros del Protocolo de Compartición de Uso del Sistema especificados por el Protocolo de Intercambio Rock Ridge. Se utilizan para describir más detalladamente los archivos en el sistema de archivos iso9660 a un host UNIX, y proporcionan información como nombres de archivo largos, UID/GID, permisos POSIX y dispositivos. Se reconoce automáticamente dentro del soporte del sistema de archivos iso9660 bajo Linux.
JFS
es un sistema de archivos con registro (journaling), desarrollado por IBM, que se integró en Linux 2.4.24.
minix
es el sistema de archivos utilizado en el sistema operativo Minix, el primero en ejecutarse bajo Linux. Tiene una serie de deficiencias, incluyendo un límite de tamaño de partición de 64 MB, nombres de archivo cortos y una única marca de tiempo. Sigue siendo útil para disquetes y discos en RAM.
msdos
es el sistema de archivos utilizado por DOS, Windows y algunas computadoras OS/2. Los nombres de archivo msdos no pueden tener más de 8 caracteres, seguidos opcionalmente por un punto y una extensión de 3 caracteres.
ncpfs
es un sistema de archivos de red que soporta el protocolo NCP, utilizado por Novell NetWare. Fue eliminado del kernel en Linux 4.17.
Para usar ncpfs, necesitas programas especiales, que se pueden encontrar en ftp://ftp.gwdg.de/pub/linux/misc/ncpfs.
nfs
es el sistema de archivos de red utilizado para acceder a discos ubicados en computadoras remotas.
ntfs
es el sistema de archivos nativo de Microsoft Windows NT, que soporta características como ACLs, registro (journaling), cifrado, etc.
proc
es un sistema de archivos pseudo que se utiliza como interfaz a las estructuras de datos del kernel en lugar de leer e interpretar /dev/kmem. En particular, sus archivos no ocupan espacio en disco. Consulta proc(5).
Reiserfs
es un sistema de archivos con registro (journaling), diseñado por Hans Reiser, que se integró en Linux 2.4.1.
smb
es un sistema de archivos de red que soporta el protocolo SMB, utilizado por Windows. Consulta https://www.samba.org/samba/smbfs/.
sysv
es una implementación del sistema de archivos System V/Coherent para Linux. Implementa todo el FS de Xenix, FS de System V/386 y FS de Coherent.
umsdos
es un sistema de archivos DOS extendido utilizado por Linux. Añade capacidad para nombres de archivo largos, UID/GID, permisos POSIX y archivos especiales (dispositivos, tuberías con nombre, etc.) bajo el sistema de archivos DOS, sin sacrificar la compatibilidad con DOS.
tmpfs
es un sistema de archivos cuyos contenidos residen en memoria virtual. Dado que los archivos en dichos sistemas de archivos residen típicamente en RAM, el acceso a los archivos es extremadamente rápido. Consulta tmpfs(5).
vfat
es un sistema de archivos FAT extendido utilizado por Microsoft Windows95 y Windows NT. vfat añade la capacidad de usar nombres de archivo largos bajo el sistema de archivos MSDOS.
XFS
es un sistema de archivos con registro (journaling), desarrollado por SGI, que se integró en Linux 2.4.20.
xiafs
fue diseñado e implementado para ser un sistema de archivos estable y seguro mediante la extensión del código del sistema de archivos Minix. Proporciona las características básicas más solicitadas sin complejidad excesiva. El sistema de archivos xiafs ya no se desarrolla ni se mantiene activamente. Fue eliminado del kernel en Linux 2.1.21.
