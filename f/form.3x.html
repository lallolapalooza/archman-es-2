form(3X) Llamadas de biblioteca form(3X)

NOMBRE

form - extensión de curses para programar formularios

SINOPSIS

#include <form.h>

DESCRIPCIÓN

La biblioteca form proporciona facilidades independientes del terminal para componer pantallas de formularios en terminales de celda de caracteres. La biblioteca incluye: rutinas de campo, que crean y modifican campos de formulario; y rutinas de formulario, que agrupan campos en formularios, muestran formularios en la pantalla y manejan la interacción con el usuario.

La biblioteca form utiliza las bibliotecas curses. Para usar la biblioteca form, enlaza con las opciones -lform -lcurses.

Tu programa debería configurar la localización, por ejemplo,


setlocale(LC_ALL, "");

para que el procesamiento de entrada/salida funcione.

Una rutina de inicialización de curses como initscr debe ser llamada antes de usar cualquiera de estas funciones.

Valores Predeterminados Actuales para Atributos de Campo

La biblioteca form mantiene un valor predeterminado para los atributos de campo. Puedes obtener o establecer este valor predeterminado llamando a la rutina set_ apropiada o de recuperación con un puntero de campo NULL. Cambiar este valor predeterminado con una función set_ afecta a las futuras creaciones de campos, pero no cambia la representación de los campos ya creados.
