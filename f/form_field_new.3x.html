Paquete: ncurses

Licencias: MIT-open-group

form_field_new(3X) Llamadas a biblioteca form_field_new(3X)

NOMBRE

new_field, dup_field, link_field, free_field - crear y destruir campos de formulario

SINOPSIS

#include <form.h>
FIELD *new_field(int height, int width,
                 int toprow, int leftcol,
                 int offscreen, int nbuffers);
FIELD *dup_field(FIELD *field, int toprow, int leftcol);
FIELD *link_field(FIELD *field, int toprow, int leftcol);
int free_field(FIELD *field);

DESCRIPCIÓN

La función new_field asigna memoria para un nuevo campo y lo inicializa con los parámetros dados: altura, anchura, fila de la esquina superior izquierda, columna de la esquina superior izquierda, número de filas fuera de pantalla y número de búferes de trabajo adicionales.

La función dup_field duplica un campo en una nueva ubicación. Se copian la mayoría de los atributos (incluyendo el contenido actual, tamaño, tipo de validación, recuento de búferes, umbral de crecimiento, justificación, color de primer plano, color de fondo, carácter de relleno, opciones y puntero de usuario). El estado del campo y el bit de página del campo no se copian.

La función link_field actúa como dup_field, pero el nuevo campo comparte los búferes con su padre. Los datos de atributos son separados.

La función free_field libera el almacenamiento asociado con un campo.

VALOR DE RETORNO

Las funciones new_field, dup_field, link_field devuelven NULL en caso de error. Establecen errno de acuerdo con su éxito:

E_OK
La rutina tuvo éxito.
E_BAD_ARGUMENT
La rutina detectó un argumento incorrecto o fuera de rango.
E_SYSTEM_ERROR
Ocurrió un error del sistema, por ejemplo, fallo de malloc.

La función free_field devuelve uno de los siguientes:

E_OK
La rutina tuvo éxito.
E_BAD_ARGUMENT
La rutina detectó un argumento incorrecto o fuera de rango.
E_CONNECTED
El campo está conectado.

PORTABILIDAD

Estas rutinas emulan la biblioteca de formularios de System V. No fueron compatibles con las versiones 7 o BSD.

Puede ser desaconsejable depender del conjunto de atributos que copia dup_field; la documentación de la biblioteca de formularios de System V no es muy explícita sobre lo que se copia y lo que no.
