scanf(3) Manual de funciones de la biblioteca scanf(3)

NOMBRE

scanf, fscanf, vscanf, vfscanf - conversión de formato de entrada FILE

BIBLIOTECA

Biblioteca estándar C (libc, -lc)

SINOPSIS

#include <stdio.h>
int scanf(const char *restrict format, ...);
int fscanf(FILE *restrict stream,
           const char *restrict format, ...);
#include <stdarg.h>
int vscanf(const char *restrict format, va_list ap);
int vfscanf(FILE *restrict stream,
           const char *restrict format, va_list ap);
Requisitos de Feature Test Macro para glibc (ver feature_test_macros(7)):

vscanf(), vfscanf():

    _ISOC99_SOURCE o _POSIX_C_SOURCE >= 200112L

DESCRIPCIÓN

Las funciones scanf() y familia escanean la entrada formateada como sscanf(3), pero leen de un FILE. Es muy difícil usar estas funciones correctamente, y es preferible leer líneas completas con fgets(3) o getline(3) y analizarlas más tarde con sscanf(3) o funciones más especializadas como strtol(3).

La función scanf() lee la entrada del flujo de entrada estándar stdin y fscanf() lee la entrada del puntero de flujo stream.

La función vfscanf() es análoga a vfprintf(3) y lee la entrada del puntero de flujo stream usando una lista de argumentos variables de punteros (ver stdarg(3). La función vscanf() es análoga a vprintf(3) y lee de la entrada estándar.

VALOR DE RETORNO

En caso de éxito, estas funciones devuelven el número de elementos de entrada que se emparejaron y asignaron correctamente; esto puede ser menor que lo proporcionado, o incluso cero, en caso de un fallo temprano de emparejamiento.

Se devuelve el valor EOF si se alcanza el final de la entrada antes de que ocurra la primera conversión exitosa o un fallo de emparejamiento. EOF también se devuelve si ocurre un error de lectura, en cuyo caso el indicador de error para el flujo (ver ferror(3)) se establece y errno se establece para indicar el error.

ERRORES

EAGAIN
El descriptor de archivo subyacente a stream está marcado como no bloqueante, y la operación de lectura bloquearía.
EBADF
El descriptor de archivo subyacente a stream es inválido o no está abierto para lectura.
EILSEQ
La secuencia de bytes de entrada no forma un carácter válido.
EINTR
La operación de lectura fue interrumpida por una señal; ver signal(7).
EINVAL
Argumentos insuficientes; o format es NULL.
ENOMEM
Sin memoria.

ATRIBUTOS

Para una explicación de los términos utilizados en esta sección, ver attributes(7).

Interfaz Atributo Valor

ESTÁNDARES

C11, POSIX.1-2008.

HISTORIA

C99, POSIX.1-2001.

ADVERTENCIAS

Estas funciones hacen que sea difícil distinguir las nuevas líneas de otros espacios en blanco. Esto es especialmente problemático con la entrada con búfer de línea, como el flujo de entrada estándar.

Estas funciones no pueden reportar errores después de la última especificación de conversión no suprimida.

ERRORES

Es imposible saber con precisión cuántos caracteres han consumido estas funciones del flujo de entrada, ya que solo informan el número de conversiones exitosas. Por ejemplo, si la entrada es "123\n a", scanf("%d %d", &a, &b) consumirá los dígitos, la nueva línea y el espacio, pero no la letra a. Esto hace que sea difícil recuperarse de entradas inválidas.

VER TAMBIÉN

fgets(3), getline(3), sscanf(3)
