NOMBRE

fpcjres - página del manual para fpcjres: un conversor de archivos de recursos

DESCRIPCIÓN

fpcjres Este programa es llamado por el compilador Free Pascal y se utiliza para traducir directivas {$R xxx} a recursos java que pueden ser incluidos en una clase java.

Sintaxis: fpcjres [opciones] <archivo de entrada> [<archivo de entrada>...] [-o <archivo de salida>]

OPCIONES

--help, -h -?
Mostrar una pantalla de mensaje de ayuda.
--version, -V
Mostrar la versión del programa.
--verbose, -v
Ser verboso.
--input, -i <x>
Ignorado por compatibilidad con otras herramientas.
--output, -o <x>
Establecer el nombre del archivo de salida.
@<archivo>
Leer más opciones del archivo <archivo>
