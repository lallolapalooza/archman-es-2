NOMBRE

foomatic-compiledb - Compila la base de datos de impresoras/controladores de Foomatic

SINOPSIS

foomatic-compiledb [ -t tipo ] [ -f ] [ -j n ] [  controlador ...  ]

DESCRIPCIÓN

foomatic-compiledb genera todos los archivos PPD o los archivos XML combinados de Foomatic para todas las combinaciones posibles de impresora/controlador, o solo para un rango seleccionado de controladores. Generalmente no debería ser necesario excepto para quienes deseen generar un conjunto de archivos de datos de Foomatic para su distribución. Para configurar impresoras individuales, foomatic-ppdfile(1) y especialmente foomatic-configure(1) calcularán automáticamente solo lo que necesitan.

Opciones

-t tipo
Tipo de archivo de salida, ya sea ppd o xml.
-f
Forzar: Escribir en el directorio de destino incluso si ya existe.
-j n
n = número de procesos de trabajo a ejecutar
controlador ...
generar solo archivos de datos para estos controladores

VER TAMBIÉN

foomatic-ppdfile(1),foomatic-configure(1)

ESTADO DE SALIDA

foomatic-compiledb devuelve 0 a menos que ocurra algo inesperado.

AUTORES

Manfred Wassmann <manolo@NCC-1701.B.Shuttle.de> y Till Kamppeter <till.kamppeter@gmail.com> para el proyecto foomatic utilizando la salida del binario asociado.

ERRORES

Los archivos existentes siempre se conservan en lugar de sobrescribir archivos más antiguos. Por lo tanto, se recomienda eliminar el directorio de destino (rm -rf dir) y llamar a foomatic-compiledb sin la opción -f.
