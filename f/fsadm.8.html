FSADM(8) Manual del Administrador del Sistema FSADM(8)

NOMBRE

fsadm — utilidad para redimensionar o verificar el sistema de archivos en un dispositivo

SINOPSIS

fsadm
[opciones] check dispositivo
fsadm
[opciones] resize dispositivo [nuevo_tamaño]

DESCRIPCIÓN

La utilidad fsadm comprueba o redimensiona el sistema de archivos en un dispositivo (que también puede ser un dispositivo encriptado dm-crypt). Intenta usar la misma API para los sistemas de archivos ext2, ext3, ext4, ReiserFS y XFS.

OPCIONES

-e|--ext-offline
Desmonta el sistema de archivos ext2/ext3/ext4 antes de realizar el redimensionamiento.
-f|--force
Omite algunas comprobaciones de seguridad.
-h|--help
Muestra el texto de ayuda.
-l|--lvresize
También redimensiona el volumen lógico lvm2 dado. Hay más funcionalidad de gestión de volúmenes proporcionada por lvresize(8) y la opción -r|--resizefs.
-n|--dry-run
Imprime los comandos sin ejecutarlos.
-v|--verbose
Sea más verboso.
-y|--yes
Responde "sí" a cualquier pregunta.
-c|--cryptresize
Redimensiona el mapeo dm-crypt junto con el sistema de archivos detectado en el dispositivo. El dispositivo dm-crypt debe ser reconocible por cryptsetup(8).
nuevo_tamaño[B|K|M|G|T|P|E]
Número absoluto de bloques del sistema de archivos que habrá en el sistema de archivos, o un tamaño absoluto usando un sufijo (en potencias de 1024). Si no se proporciona new_size, se utiliza todo el dispositivo.

DIAGNÓSTICOS

Al completarse con éxito, el código de estado es 0. Un código de estado de 2 indica que la operación fue interrumpida por el usuario. Un código de estado de 3 indica que la operación de verificación solicitada no pudo realizarse porque el sistema de archivos está montado y no admite una verificación fsck(8) en línea. Se utiliza un código de estado 1 para otros fallos.

EJEMPLOS

Redimensiona el sistema de archivos en el volumen lógico /dev/vg/test a 1000 MiB. Si /dev/vg/test contiene un sistema de archivos ext2/ext3/ext4, se desmontará antes del redimensionamiento. Se responderá 'y' a todas las preguntas [y/n].

fsadm -e -y resize /dev/vg/test 1000M

VARIABLES DE ENTORNO

TMPDIR
El nombre del directorio temporal para los puntos de montaje. Por defecto es "/tmp".
DM_DEV_DIR
El nombre del directorio de dispositivos. Por defecto es "/dev" y debe ser una ruta absoluta.
