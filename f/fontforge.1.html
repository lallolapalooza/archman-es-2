DESCRIPCIÓ

N

FontForge leerá archivos de fuentes PostScript (pfa, pfb, ps, cid), OpenType (otf), TrueType (ttf, ttc), fuentes de recursos de Macintosh (dfont, bin, hqx), Gráficos Vectoriales Escalables (svg), mapas de bits de TeX (pk), Formato de Distribución de Mapas de Bits de Glifos (bdf), y mapas de bits de X11 (pcf). Los archivos de fuentes pueden estar comprimidos con gzip (por ejemplo, myfont.pcf.gz). FontForge también leerá su propio formato: archivos de Base de Datos de Fuentes Spline (sfd)

.

Si la lista de argumentos contiene un nombre de archivo de fuente (o varios), fontforge abre una ventana de visualización de fuentes para cada fuente mostrando los caracteres de esa fuente. En ausencia de opciones o argumentos, el programa abre una ventana de selección de archivos, permitiéndole explorar su disco para encontrar un archivo de fuente o crear uno

nuevo.

Esta página de manual está destinada solo como una descripción general básica; consulte el Manual de Usuario HTML para información más

completa.

Si no se especifican archivos de fuentes, y tampoco se especifica -new, y no hay nada que recuperar, entonces FontForge producirá un cuadro de diálogo de apertura de

fuentes.

Si se especifica un archivo de script, entonces FontForge no abrirá la pantalla X, ni procesará ningún argumento adicional. Ejecutará el archivo de script y le pasará cualquier argumento

restante.

Si el primer argumento es un nombre de archivo ejecutable, y la primera línea de ese archivo contiene "fontforge", entonces se tratará como un archivo d

e scr

NAME

fontforge ― a font editor

SYNOPSIS

fontforge [ options ] [ files... ]

DESCRIPTION

FontForge is a font editor. It supports many font formats, including TrueType, OpenType, PostScript, Bézier, CID, Multiple Master, and SVG.

FontForge can be run in two modes:

Interactive Mode
This is the default mode. FontForge opens a GUI window from which you can edit fonts. You can open fonts for editing, create new fonts, and save them.
Batch Mode
In batch mode, FontForge executes a Python script (or a set of scripts) without opening a GUI window. This is useful for automating font conversions and other font manipulations. The script may be given on the command line using the -script option.

OPTIONS

Most of the options are used to control the behaviour of FontForge when run in batch mode. For a list of all options see the sfddiff(1) man page.

EXAMPLE

To open a font file Myfont.sfd for editing:

fontforge Myfont.sfd

To convert a TrueType font input.ttf to OpenType output.otf using a Python script:

fontforge -script conv_script.py input.ttf output.otf

ENVIRONMENT

The behaviour of FontForge can be influenced by several environment variables:

FONTFORGE_CONFIGDIR
Specifies the directory for configuration files.
FONTFORGE_VERBOSE
If set, FontForge will print more verbose output in batch mode.

FILES

~/.config/fontforge/
~/.fontforge/
Default directories for user configuration files and scripts.
/usr/share/fontforge/
System-wide configuration files, scripts, and plugins.
