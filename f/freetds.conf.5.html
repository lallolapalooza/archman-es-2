NOMBRE

freetds.conf — archivo de configuración para FreeTDS

SINOPSIS

El archivo freetds.conf describe los servidores de bases de datos Sybase y Microsoft a la biblioteca FreeTDS. Comprende secciones encabezadas por un nombre de servidor, seguido de una lista de propiedades de conexión denotadas como pares nombre-valor. Los valores predeterminados se definen mediante una sección [global]. Este archivo reemplaza al archivo interfaces que Sybase define para el mismo propósito, aunque el último todavía es compatible.

DESCRIPCIÓN

Una sección comienza con un nombre de servidor — el nombre del servidor — entre corchetes. El nombre de servidor es elegido a discreción del cliente. (Una excepción: con Sybase ASA el nombre de servidor debe coincidir con el nombre de la base de datos a utilizar.)

Las secciones contienen propiedades, una por línea, en la forma

nombre = valor

donde nombre es la propiedad de conexión a describir. Los nombres de servidor y las propiedades no distinguen mayúsculas de minúsculas. Los valores conservan las mayúsculas y minúsculas, es decir, se copian literalmente. Los comentarios comienzan con un punto y coma (‘;’) o un signo de número (‘#’) y continúan hasta el final de la línea. Las líneas en blanco se ignoran. El espacio en blanco alrededor del ‘=’ se ignora.

NOMBRES Y UBICACIONES

El archivo se llama normalmente /etc/freetds.conf o ${HOME}/.freetds.conf. Ese nombre se puede anular con la variable de entorno FREETDSCONF.

FreeTDS buscará archivos de configuración para un nombre de servidor en el siguiente orden:

  1. un nombre de archivo establecido programáticamente mediante dbsetifile() que esté en formato .conf
  2. un nombre de archivo en la variable de entorno FREETDSCONF que esté en formato .conf
  3. ${HOME}/.freetds.conf si existe
  4. /etc/freetds/freetds.conf

La búsqueda se detiene con el primer archivo que contenga el nombre de servidor.

Si no se encuentra ningún archivo de configuración, FreeTDS busca un archivo interfaces en el siguiente orden:

  1. un nombre de archivo establecido programáticamente mediante dbsetifile() que esté en formato interfaces formato
  2. ${HOME}/.interfaces
  3. $SYBASE/interfaces (donde $SYBASE es una variable de entorno)

Si el nombre de servidor solicitado no se encuentra en ningún archivo de configuración, el mecanismo de reserva es:

  1. intentar convertir el nombre a una dirección IP con inet_addr(3), si no,
  2. intentar convertir el nombre a una dirección IP con gethostbyname(3), si no,
  3. intentar buscar el nombre literal “SYBASE”

ENTORNO

FREETDSCON

ENVIRONMENT

FREETDSCONF
anula el nombre y la ubicación del archivo de configuración global del sistema
TDSDUMP
anula el nombre y la ubicación del archivo de registro de FreeTDS
TDSDUMPCONFIG
especifica un nombre y una ubicación para un archivo que registra la búsqueda de archivos de configuración
TDSHOST
anula la propiedad host
TDSPORT
anula la propiedad port
TDSQUERY
sinónimo de DSQUERY, el nombre del servidor predeterminado
TDSVER
anula la versión especificada en freetds.conf

Las variables de entorno TDSVER, TDSDUMP, TDSPORT, TDSQUERY, y TDSHOST anulan los valores establecidos por un archivo .conf o interfaces.
