frexp(3) Manual de Funciones de Biblioteca frexp(3)

NOMBRE

frexp, frexpf, frexpl - convierte un número de punto flotante en componentes fraccionales e integrales

BIBLIOTECA

Biblioteca matemática (libm, -lm)

SINOPSIS

#include <math.h>
double frexp(double x, int *e);
float frexpf(float x, int *e);
long double frexpl(long double x, int *e);
Requisitos de Macros de Prueba de Funciones para glibc (ver feature_test_macros(7)):

frexpf(), frexpl():

    _ISOC99_SOURCE || _POSIX_C_SOURCE >= 200112L
        || /* Desde glibc 2.19: */ _DEFAULT_SOURCE
        || /* glibc <= 2.19: */ _BSD_SOURCE || _SVID_SOURCE

DESCRIPCIÓN

Estas funciones se utilizan para dividir el número x en una fracción normalizada y un exponente que se almacena en e.

VALOR DE RETORNO

Estas funciones devuelven la fracción normalizada. Si el argumento x no es cero, la fracción normalizada es x por una potencia de dos, y su valor absoluto siempre está en el rango [0.5, 1) (incluyendo 0.5, excluyendo 1).

Si x es cero, la fracción normalizada es cero y se almacena cero en e.

Si x es un NaN, se devuelve un NaN y el valor de *e no está especificado.

Si x es infinito positivo (infinito negativo), se devuelve infinito positivo (infinito negativo) y el valor de *e no está especificado.

ERRORES

No ocurren errores.

ATRIBUTOS

Para una explicación de los términos utilizados en esta sección, consulte attributes(7).

Interfaz Atributo Valor
frexp (), frexpf (), frexpl () Seguridad en hilos MT-Safe

ESTÁNDARES

C11, POSIX.1-2008.

HISTORIA

C99, POSIX.1-2001.

La variante que devuelve double también cumple con SVr4, 4.3BSD, C89.

EJEMPLOS

El programa a continuación produce resultados como los siguientes:


$ ./a.out 2560
frexp(2560, &e) = 0.625: 0.625 * 2^12 = 2560
$ ./a.out -4
frexp(-4, &e) = -0.5: -0.5 * 2^3 = -4

Código fuente del programa

#include <float.h>
#include <math.h>
#include <stdio.h>
#include <stdlib.h>
int
main(int argc, char *argv[])
{
    double x, r;
    int e;
    x = strtod(argv[1], NULL);
    r = frexp(x, &e);
    printf("frexp(%g, &e) = %g: %g * %d^%d = %g\n", x, r, r, 2, e, x);
    exit(EXIT_SUCCESS);
}

VER TAMBIÉN

ldexp(3), modf(3)
