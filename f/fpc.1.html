DESCRIPCIÓ

N

Este binario es el binario principal del Compilador Free Pascal (FPC), que es un compilador Pascal multitarget independiente (no frontend de GCC) compatible con Turbo Pascal y Delphi (7.0)

.

El compilador usa LD(1) y puede usar AS(1) (ver el parámetro -Aas), pero también tiene su propio escritor de objetos

binarios.

Los objetivos principales actuales son Go32V2 (extensor DJGPP de Dos), Freebsd, Linux, MacOS, MacOSX, MorphOS, Netware, OS/2 y Win32. Los otros objetivos (compiladores M68K para Atari y Amiga) se basan en versiones anteriores del compilador o aún están en

desarrollo.

Esta página man está destinada solo para referencia rápida. FPC viene c

on un gran manual (de más de 2000 páginas), que se actualiza const
antemente, mientras que esta página man puede estar desactualizada.

Número de

versión

A partir de la versión 1.0, se ha implementado un nuevo sistema de versionado. Si el último número es par (1.0, 1.0.2), es estable, y si el último número es impar, es una versión de desarrollo que cambia diariamente (1.0.5, 1.1), al igual que el kernel de

Linux.

La versión 0.99.5, sin embargo, es una versión

estable. Se creó antes de que se introduje
ra el sistema de nombres de versión par/impar.

Us

o

El proceso de compilación se iniciando escribiendo fpc seguido de un nombre de archivo fuente (normalmente con extensión .pas o .pp). Antes de procesar el procesamiento real del archivo fuente, fpc.cfg(5), el archivo de configuración del compilador, se lee, el cual contiene la ubicación de la RTL, otros paquetes (FCL, FreeVision) y, opcionalmente, valores predeterminados para algunos interruptores. Ver la página man separada de fpc.cfg(5) para má

s inf
ormación.
