fmod(3) Manual de Funciones de Biblioteca fmod(3)

NOMBRE

fmod, fmodf, fmodl - función de resto de punto flotante

BIBLIOTECA

Biblioteca matemática (libm, -lm)

SINOPSIS

#include <math.h>
double fmod(double x, double y);
float fmodf(float x, float y);
long double fmodl(long double x, long double y);
Requisitos de macros de prueba de características para glibc (ver feature_test_macros(7)):

fmodf(), fmodl():

    _ISOC99_SOURCE || _POSIX_C_SOURCE >= 200112L
        || /* Desde glibc 2.19: */ _DEFAULT_SOURCE
        || /* glibc <= 2.19: */ _BSD_SOURCE || _SVID_SOURCE

DESCRIPCIÓN

Estas funciones calculan el resto de punto flotante de la división de x entre y. El valor de retorno es x - n * y, donde n es el cociente de x / y, redondeado hacia cero a un entero.

Para obtener el módulo, más específicamente, el Residuo Mínimo Positivo, necesitará ajustar el resultado de fmod() de la siguiente manera:


z = fmod(x, y);
if (z < 0)
	z += fabs(y);

Una forma alternativa de expresar esto es con fmod(fmod(x, y) + y, y), pero el segundo fmod() suele costar mucho más que una sola rama.

VALOR DE RETORNO

En caso de éxito, estas funciones devuelven el valor x - n*y, para algún entero n, tal que el valor devuelto tenga el mismo signo que x y una magnitud menor que la magnitud de y.

Si x o y es un NaN, se devuelve un NaN.

Si x es un infinito, ocurre un error de dominio y se devuelve un NaN.

Si y es cero, ocurre un error de dominio y se devuelve un NaN.

Si x es +0 (-0), y y no es cero, se devuelve +0 (-0).

ERRORES

Ver math_error(7) para obtener información sobre cómo determinar si ha ocurrido un error al llamar a estas funciones.

Los siguientes errores pueden ocurrir:

Error de dominio: x es un infinito
errno se establece en EDOM (pero ver BUGS). Se genera una excepción de punto flotante inválida (FE_INVALID).
Error de dominio: y es cero
errno se establece en EDOM. Se genera una excepción de punto flotante inválida (FE_INVALID).

ATRIBUTOS

Para una explicación de los términos utilizados en esta sección, ver attributes(7).

Interfaz Atributo Valor
fmod (), fmodf (), fmodl () Seguridad de hilos MT-Safe

ESTÁNDARES

C11, POSIX.1-2008.

HISTORIA

C99, POSIX.1-2001.

La variante que devuelve double también se ajusta a SVr4, 4.3BSD, C89.

ERRORES CONOCIDOS

Antes de glibc 2.10, la implementación de glibc no establecía errno a EDOM cuando ocurría un error de dominio para un x infinito.

EJEMPLOS

La llamada fmod(372, 360) devuelve 12.

La llamada fmod(-372, 360) devuelve -12.

La llamada fmod(-372, -360) también devuelve -12.
