NOMBRE

freeciv-gtk3.22, freeciv-gtk2, freeciv-curses, freeciv-sdl2, freeciv-sdl3 - clientes para el juego de estrategia Freeciv.

SINOPSIS

freeciv-gtk3.22 [opciones...] [freeciv-server [opciones...]]

freeciv-gtk2 [opciones...] [freeciv-server [opciones...]]

freeciv-curses [opciones...] [freeciv-server [opciones...]]

freeciv-sdl2 [opciones...] [freeciv-server [opciones...]]

freeciv-sdl3 [opciones...] [freeciv-server [opciones...]]

DESCRIPCIÓN

Estos son los programas cliente para el juego de estrategia de código abierto Freeciv. Freeciv es un juego de estrategia por turnos de conquista, diplomacia y gestión económica. Los jugadores comienzan en la antigüedad con una sola tribu y deben guiarla a través de las edades hasta la era espacial. Los jugadores compiten contra otros jugadores o contra el ordenador para ser el poder dominante en la Tierra. Los jugadores pueden ganar declarándose superpotencia mundial, explorando el espacio exterior o destruyendo a todos sus oponentes.

Todos los clientes comparten el mismo código principal y la misma interfaz de protocolo de red. Los clientes difieren principalmente en su interfaz gráfica de usuario (GUI). Los clientes GTK (gtk2 y gtk3) y SDL (sdl2 y sdl3) proporcionan una interfaz gráfica, mientras que el cliente curses proporciona una interfaz basada en texto en una terminal.

Si se proporciona un argumento de línea de comandos que no es una opción reconocida, se supone que es el nombre de un servidor Freeciv ejecutable. Si ese servidor se puede iniciar localmente, se iniciará automáticamente y se conectará a él.

OPCIONES

Las opciones comunes a todos los clientes incluyen:

-a, --autoconnect
Conectar automáticamente al servidor local.
-c, --connect host[ port]
Conectar al servidor en host. Si se omite el puerto, se usará el puerto predeterminado de Freeciv (5557).
-d level, --debug level
Establece el nivel de depuración. Los niveles más altos imprimen más información de depuración. El nivel 0 significa ninguna depuración.
-g file, --load file
Cargar una partida guardada desde file.
-h, --help
Mostrar un mensaje de ayuda y salir.
-i, --interface name
Especificar una interfaz gráfica de usuario diferente a la predeterminada.
-k file, --scenario file
Usar el escenario especificado en file. Si se usa un escenario personalizado, debe estar en uno de los directorios de escenarios o debe proporcionarse una ruta completa.
-l file, --log file
Registrar la salida en file en lugar de la pantalla.
-n, --newgame
Iniciar una nueva partida. Requiere que también se inicie un servidor (ya sea mediante la opción -s o ejecutando freeciv-server por separado).
-N name, --name name
Especifica el nombre del jugador que se utilizará. Si el nombre contiene espacios, debe ir entre comillas.
-p port, --port port
Intentar conectar al puerto especificado. Si también se usa la opción -c, este puerto se usará en lugar del puerto predeterminado.
-q, --quit
Salir del cliente.
-r file, --rcfile file
Cargar la configuración desde el archivo especificado en file en lugar del predeterminado.
-s [options], --server [options]
Iniciar un servidor Freeciv. Las opciones pasadas al servidor deben ir precedidas de -s. Vea freeciv-server(6) para ver las opciones disponibles del servidor.
-t tilespec, --tileset tilespec
Usar el conjunto de teselas especificado.
-T theme, --theme theme
Usar un tema de GUI en particular. Solo implementado en los clientes freeciv-sdl2 y freeciv-sdl3.

EJEMPLOS

freeciv-gtk3.22 --name "King Richard" --server io.daimi.aau.dk
Inicia el cliente GTK3.22 usando el nombre King Richard y conectándose al servidor en io.daimi.aau.dk.
freeciv-sdl3 -a -t trident
Inicia el cliente SDL3 con las teselas trident y se conecta automáticamente a localhost.

ENTORNO

El cliente Freeciv acepta estas variables de entorno:

FREECIV_CAPS
Una cadena que contiene una lista de "capacidades" proporcionadas por el servidor. El valor predeterminado compilado debería ser correcto para la mayoría de los propósitos, pero si está familiarizado con el sistema de capacidades en el código fuente, puede usarlo para imponer algunas restricciones entre clientes y servidor.
FREECIV_COMPRESSION_LEVEL
Establece el nivel de compresión para el tráfico de red.
FREECIV_DATA_ENCODING
Establece la codificación de caracteres utilizada para los archivos de datos, partidas guardadas y cadenas de red. Normalmente, esto no debería cambiarse del valor predeterminado UTF-8, ya que ese es el formato de los conjuntos de reglas proporcionados y el protocolo de red estándar.
FREECIV_INTERNAL_ENCODING
Establece la codificación de caracteres utilizada internamente por el cliente freeciv. Esto generalmente debe coincidir con el toolkit de la GUI, por lo que su valor predeterminado depende del cliente específico; la mayoría de los clientes usan UTF-8 de forma predeterminada.
FREECIV_LOCAL_ENCODING
Establece la codificación de caracteres local (utilizada para la línea de comandos y la salida de la terminal). El valor predeterminado se infiere de otros aspectos del entorno.
FREECIV_MULTICAST_GROUP
Establece el grupo de multidifusión (para la pestaña LAN).
FREECIV_DATA_PATH
Una lista de directorios separados por dos puntos que apuntan a los directorios de datos de freeciv. Por defecto, Freeciv busca en los siguientes directorios, en orden, cualquier archivo de datos: el directorio actual; el subdirectorio "data" del directorio actual; el subdirectorio ".freeciv/3.2" en el directorio de inicio del usuario; y el directorio donde se colocan los archivos al ejecutar "make install". Si no se establece, se buscan los datos en los directorios predeterminados del sistema.
FREECIV_SAVE_PATH
Una lista de directorios separados por dos puntos que apuntan a los directorios de guardado de freeciv. Por defecto, Freeciv busca en los siguientes directorios, en orden, archivos guardados: el directorio actual; y el subdirectorio ".freeciv/saves" en el directorio de inicio del usuario.

(Esto no afecta dónde el servidor iniciado por el cliente crea los archivos de partida guardada; estos siempre se crean en ".freeciv/saves" en el directorio de inicio del usuario.)

FREECIV_SCENARIO_PATH
Una lista de directorios separados por dos puntos que apuntan a los directorios de escenarios de freeciv. Por defecto, Freeciv busca en los siguientes directorios, en orden, archivos de escenario: el directorio actual; el subdirectorio "data/scenarios" del directorio actual; los subdirectorios ".freeciv/3.2/scenarios" y luego ".freeciv/scenarios" en el directorio de inicio del usuario; y el directorio donde se colocan los archivos al ejecutar "make install".

(Esto no afecta dónde el servidor iniciado por el cliente crea los archivos de escenario; estos siempre se crean en ".freeciv/scenarios" en el directorio de inicio del usuario.)

FREECIV_OPT
Especifica un archivo que contenga configuraciones locales, en lugar de ~/.freeciv/freeciv-client-rc-[version-number].
HOME
Especifica el directorio de inicio del usuario.
http_proxy
Establezca esta variable en consecuencia cuando use un proxy.
LANG o LANGUAGE
Establece el idioma y la configuración regional en algunas plataformas.
LC_ALL o LC_CTYPE
Similar a LANG (consulte la documentación de su sistema).
USER
Especifica el nombre de usuario del usuario actual.
