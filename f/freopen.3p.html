APLICACIONES

La función freopen () se utiliza típicamente para asociar los flujos preabiertos flujos asociados con stdin , stdou

t

y stderr a otros archivos. Dado que no se exige a las implementaciones que soporten ningún cambio en el modo del flujo cuando el argumento pathname es NULL, las aplicaciones portables no pueden confiar en el uso de freopen () para cambiar el modo del flujo, y se desaconseja el uso de esta característica. Esta característica se añadió originalmente al estándar ISO C para facilitar el cambio de stdin y stdout a modo binario. Dado que un carácter 'b'en el modo no tiene efecto en sistemas POSIX, este uso de la característica es innecesario en aplicaciones POSIX. Sin embargo, aunque el 'b' se ignora, una llamada exitosa afreopen (NULL, " wb ", stdout ) sí tiene un efecto. En particular, para archivos regulares, trunca el archivo y establece el indicador de posición del archivo del flujo al inicio del archivo. Es posible que estos efectos secundarios sean una consecuencia no intencionada de la forma en que la característica está especificada en el estándar ISO/IEC 9899:1999, pero a menos que o hasta que el estándar ISO C se modifique, las aplicaciones que llamen exitosamente
