NOMBRE

fwb_ipt - Compilador de políticas para iptables

SINOPSIS

fwb_ipt -farchivo_datos.xml [-4] [-6] [-V] [-ddirectorio_trabajo] [-i] [-osalida.fw] [-Oid_fw1,salida_fw1.fw[,id_fw2,salida_fw2.fw]] [-v] [-xc] [-xnN] [-xpN] [-xt] nombre_objeto

DESCRIPCIÓN

fwb_ipt es un componente del compilador de políticas de cortafuegos de Firewall Builder (ver fwbuilder(1)). El compilador lee las definiciones de objetos y la descripción del cortafuegos del archivo de datos especificado con la opción "-f" y genera el script de iptables resultante. El script se escribe en un archivo con el mismo nombre que el objeto del cortafuegos, más la extensión ".fw".

El archivo de datos y el nombre de los objetos del cortafuegos deben especificarse en la línea de comandos. Los demás parámetros de la línea de comandos son opcionales.

OPCIONES

-4
Genera el script de iptables para la parte IPv4 de la política. Si alguna regla del cortafuegos se refiere a direcciones IPv6, el compilador omitirá dichas reglas. Las opciones "-4" y "-6" son excluyentes. Si no se usa ninguna de las opciones, el compilador intenta generar ambas partes del script, aunque la generación de la parte IPv6 está controlada por la opción "Habilitar soporte IPv6" en la pestaña "IPv6" del diálogo de configuración avanzada del objeto del cortafuegos. Esta opción está desactivada por defecto.
-6
Genera el script de iptables para la parte IPv6 de la política. Si alguna regla del cortafuegos se refiere a direcciones IPv6, el compilador omitirá dichas reglas.
-f ARCHIVO
Especifica el nombre del archivo de datos que se procesará.
-o salida.fw
Especifica el nombre del archivo de salida.
-O id_fw1,salida_fw1.fw[,id_fw2,salida_fw2.fw]
El argumento es una lista separada por comas de IDs de objetos de cortafuegos y sus nombres de archivo de salida correspondientes. Esta opción es utilizada por la GUI de fwbuilder al compilar clústeres de cortafuegos.
-d dir_trabajo
Especifica el directorio de trabajo. El compilador crea el archivo con el script de iptables en este directorio. Si falta este parámetro, el script de iptables se colocará en el directorio de trabajo actual.
-v
Sea verboso: el compilador imprime mensajes de diagnóstico mientras trabaja.
-V
Imprime el número de versión y sale.
-i
Cuando esta opción está presente, el último argumento de la línea de comandos se supone que es el ID del objeto del cortafuegos en lugar de su nombre.
-xc
Cuando el nombre del archivo de salida se determina automáticamente (es decir, las opciones -o u -O no están presentes), el nombre del archivo se compone del nombre del clúster y el nombre del cortafuegos miembro en lugar de solo el nombre del cortafuegos miembro. Esto se utiliza principalmente para pruebas cuando el mismo objeto de cortafuegos miembro puede ser parte de diferentes clústeres con diferentes configuraciones.
-xt
Esta bandera hace que el compilador trate todos los errores fatales como advertencias y continúe procesando las reglas. El script de configuración generado probablemente será incorrecto, pero incluirá el mensaje de error como un comentario; esta bandera se utiliza para pruebas y depuración.
-xp N
Bandera de depuración: esto hace que el compilador imprima una descripción detallada de la regla de política número "N" a medida que la procesa, paso a paso.
-xn N
Bandera de depuración: esto hace que el compilador imprima una descripción detallada de la regla NAT número "N" a medida que la procesa, paso a paso.
