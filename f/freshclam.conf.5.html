NOMBRE

freshclam.conf - Archivo de configuración para la herramienta de actualización de bases de datos de Clam AntiVirus

DESCRIPCIÓN

El archivo freshclam.conf configura la herramienta de actualización de bases de datos de Clam AntiVirus, freshclam(1).

FORMATO DEL ARCHIVO

El archivo consiste en comentarios y opciones con argumentos. Cada línea que comienza con un símbolo de almohadilla (#) es ignorada por el analizador. Las opciones y los argumentos distinguen entre mayúsculas y minúsculas y tienen el formato Opción Argumento. Los argumentos son de los siguientes tipos:

BOOL
Valor booleano (sí/no o verdadero/falso o 1/0).
STRING
Cadena de caracteres sin espacios en blanco.
SIZE
Tamaño en bytes. Puede usar los modificadores 'M' o 'm' para megabytes y 'K' o 'k' para kilobytes.
NUMBER
Entero sin signo.

DIRECTIVAS

Cuando una opción no se usa (está comentada o no existe en el archivo de configuración) freshclam toma una acción predeterminada.

Ejemplo
Si esta opción está establecida, freshclam no se ejecutará.
LogFileMaxSize SIZE
Limita el tamaño del archivo de registro. El registrador se deshabilitará automáticamente si el archivo es mayor que SIZE. Un valor de 0 deshabilita el límite.
Por defecto: 1M
LogTime BOOL
Registra la hora con cada mensaje.
Por defecto: no
LogSyslog BOOL
Habilita el registro en Syslog. Puede usarse en combinación con UpdateLogFile.
Por defecto: deshabilitado.
LogFacility STRING
Especifica el tipo de mensajes de syslog; consulte 'man syslog' para ver los nombres de las instalaciones.
Por defecto: LOG_LOCAL6
LogVerbose BOOL
Habilita el registro detallado.
Por defecto: deshabilitado
LogRotate BOOL
Rota el archivo de registro. Requiere que la opción LogFileMaxSize se establezca antes que esta opción.
Por defecto: no
PidFile STRING
Escribe el PID del demonio en el archivo especificado.
Por defecto: deshabilitado
DatabaseDirectory STRING
Ruta a un directorio que contiene los archivos de base de datos. Este directorio ya debe existir, ser una ruta absoluta, ser escribible por freshclam y legible por clamd/clamscan.
Por defecto: /var/lib/clamav
CVDCertsDirectory STRING
Ruta a un directorio que contiene los archivos de certificados CA de ClamAV utilizados para verificar archivos de bases de datos firmadas (por ejemplo, archivos CVD). Este directorio ya debe existir, ser una ruta absoluta, ser legible por freshclam, clamd, clamscan y sigtool.
Por defecto: /etc/clamav/certs
FIPSCryptoHashLimits BOOL
Impone límites similares a FIPS en el uso de algoritmos hash con fines criptográficos. Deshabilitará las firmas FP MD5 y SHA1 y requerirá archivos '.sign' para verificar la autenticidad de CVD.
Por defecto: no
Foreground BOOL
No se bifurque en segundo plano.
Por defecto: no
Debug BOOL
Habilita mensajes de depuración en libclamav.
Por defecto: no
UpdateLogFile STRING
Habilita el registro en un archivo especificado. Altamente recomendado.
Por defecto: deshabilitado.
DatabaseOwner STRING
Cuando se inicia como root, renuncia a privilegios a un usuario especificado.
Por defecto: clamav
Checks NUMBER
Número de verificaciones de bases de datos por día.
Por defecto: 12
DNSDatabaseInfo STRING
Usa DNS para verificar la versión de la base de datos de virus. FreshClam utiliza registros TXT de DNS para verificar las versiones de la base de datos y del propio software. Con esta directiva puede cambiar el dominio de verificación de la base de datos.
ADVERTENCIA: No lo cambie a menos que esté configurando freshclam para usar su propio dominio de verificación de bases de datos.
Por defecto: habilitado, apunta a current.cvd.clamav.net
DatabaseMirror STRING
DatabaseMirror especifica a qué espejo(s) debe conectarse freshclam. Debe tener al menos una entrada: database.clamav.net. Ahora que CloudFlare se utiliza como nuestra Red de Entrega de Contenido (CDN), este único nombre de dominio funciona en todo el mundo para dirigir freshclam al punto final geográfico más cercano.
Por defecto: database.clamav.net
PrivateMirror STR
Esta opción le permite dirigir fácilmente freshclam a espejos privados. Si se establece PrivateMirror, freshclam no intenta usar DNS para determinar si sus bases de datos están desactualizadas, sino que usará la solicitud If-Modified-Since o verificará directamente las cabeceras de los archivos de base de datos remotos. Para cada base de datos, freshclam primero intenta descargar el archivo CLD. Si falla, intenta descargar el archivo CVD. Esta opción anula DatabaseMirror, DNSDatabaseInfo y ScriptedUpdates. Se puede usar varias veces para proporcionar espejos de respaldo.
Por defecto: deshabilitado
MaxAttempts NUMBER
Cuántos intentos (por espejo) se realizarán antes de darse por vencido.
Por defecto: 3 (por espejo)
ScriptedUpdates BOOL
Con esta opción puede controlar las actualizaciones de scripts. Se recomienda encarecidamente mantenerla habilitada.
Por defecto: sí
TestDatabases BOOL
Con esta opción habilitada, freshclam intentará cargar las nuevas bases de datos en memoria para asegurarse de que son manejadas correctamente por libclamav antes de reemplazar las antiguas.
Por defecto: habilitado
CompressLocalDatabase BOOL
Por defecto, freshclam mantendrá las bases de datos locales (.cld) sin comprimir para acelerar su manejo. Con esta opción puede habilitar la compresión; el cambio tendrá efecto con la próxima actualización de la base de datos.
Por defecto: no
ExtraDatabase STRING
Descarga una base de datos de firmas adicional de terceros distribuida a través de los espejos de ClamAV. Esta opción se puede usar varias veces.
Por defecto: deshabilitado
ExcludeDatabase STRING
Excluye una base de datos de firmas estándar (exclusión voluntaria). Esta opción se puede usar varias veces.
Por defecto: deshabilitado
DatabaseCustomURL STRING
Con esta opción puede proporcionar fuentes personalizadas para archivos de bases de datos. Esta opción se puede usar varias veces. Soporte para:
http(s)://, ftp(s)://, o file:// Ejemplo de uso:
DatabaseCustomURL https://myserver.com:4567/allow_list.wdb
Por defecto: deshabilitado
HTTPProxyServer STR, HTTPProxyPort NUMBER
Utiliza el servidor proxy y el puerto TCP dados para las descargas de bases de datos. El HTTPProxyServer puede ir precedido de [scheme]:// para especificar qué tipo de proxy se utiliza.
http:// Proxy HTTP. Por defecto cuando no se especifica esquema ni tipo de proxy.
https:// Proxy HTTPS. (Añadido en la versión 7.52.0 para OpenSSL, GnuTLS y NSS)
socks4:// Proxy SOCKS4.
socks4a:// Proxy SOCKS4a. El proxy resuelve el nombre de host de la URL.

freshclam.conf(5)

NAME

freshclam.conf — configuration file for freshclam(1)

DESCRIPTION

The freshclam.conf file is used to configure the freshclam utility. This utility is used to update the ClamAV virus database. The configuration options are described below. Blank lines and lines starting with ; or # are ignored.

All options are case sensitive.

FILE FORMAT

The configuration file is a text file. Each line contains one configuration directive, consisting of a keyword and an argument. Keywords and arguments are separated by whitespace.

The keywords are case sensitive.

DIRECTIVES

DatabaseMirror STRING
This option specifies the host from which to download the virus databases. It can be specified multiple times. freshclam will try to connect to them in the specified order.

The following protocols are supported:

http://
Use HTTP protocol.
https://
Use HTTPS protocol. The supported cipher suites are those enabled in your OpenSSL library.
ftp://
Use FTP protocol.
ftps://
Use FTP protocol over SSL/TLS.
rsync://
Use rsync protocol. Make sure that freshclam has access to rsync binary and that the rsync daemon is configured to serve the databases.
file://
Use local file system directory. Useful for testing or for mirroring databases locally.
socks4://
Use SOCKS4 Proxy.
socks4a://
Use SOCKS4a Proxy. Proxy resolves URL hostname.
socks5://
Use SOCKS5 Proxy.
socks5h://
Use SOCKS5 Proxy. Proxy resolves URL hostname.

When specifying an HTTPS URL, you may also specify the path to a specific certificate authority (CA) bundle file using the HTTPProxyCAFile option.

Default: database.clamav.net

PrivateMirror STRING
This option specifies a private mirror. It has the same functionality as DatabaseMirror, but it is used only if the UseDatabaseMirror option is set to false. This is useful if you want to use your own mirror server and do not want to use the official ClamAV mirrors.
Repository STRING
This option specifies the repository to use. It can be specified multiple times. The format is [protocol://]host[:port]/path.

Currently supported protocols are:

http://
Use HTTP protocol.
https://
Use HTTPS protocol.
ftp://
Use FTP protocol.
ftps://
Use FTP protocol over SSL/TLS.
rsync://
Use rsync protocol.
file://
Use local file system directory.
socks4://
Use SOCKS4 Proxy.
socks4a://
Use SOCKS4a Proxy. Proxy resolves URL hostname.
socks5://
Use SOCKS5 Proxy.
socks5h://
Use SOCKS5 Proxy. Proxy resolves URL hostname.

The Repository option may be specified multiple times. freshclam will try to connect to them in the specified order.

Default: http://database.clamav.net/

UseDatabaseMirror BOOL
Specifies whether to use the DatabaseMirror directive. If set to true, freshclam will use the mirrors specified in DatabaseMirror. If set to false, freshclam will use the private mirror specified in PrivateMirror.

Default: true

HTTPProxyServer STRING
Use this option to specify your HTTP proxy server. The format is host:port.

Default: disabled

HTTPProxyPort NUMBER
This option specifies the port number for your HTTP proxy server.

Default: 8080

HTTPProxyUsername STRING,
HTTPProxyPassword STRING
Proxy usage is authenticated through given username and password.

Default: disabled

HTTPProxySocks STRING
Use this option to specify your SOCKS proxy server. The format is host:port.

Default: disabled

HTTPProxySocks4 STRING
Use this option to specify your SOCKS4 proxy server. The format is host:port.

Default: disabled

HTTPProxySocks5 STRING
Use this option to specify your SOCKS5 proxy server. The format is host:port.

Default: disabled

HTTPProxySocks5Password STRING
Use this option to specify the password for your SOCKS5 proxy server.

Default: disabled

HTTPProxySocks5Username STRING
Use this option to specify the username for your SOCKS5 proxy server.

Default: disabled

HTTPProxyCAFile STRING
Path to a CA certificate bundle file to use for SSL/TLS connections to the proxy server or the database mirror.

Default: disabled

HTTPProxySSLCert STRING
Path to a client certificate file to use for SSL/TLS connections to the proxy server or the database mirror.

Default: disabled

HTTPProxySSLKey STRING
Path to a client key file to use for SSL/TLS connections to the proxy server or the database mirror.

Default: disabled

HTTPProxySSLPassword STRING
Password for the client key file.

Default: disabled

HTTPUserAgent STRING
If your servers are behind a firewall/proxy which applies User-Agent filtering, you can use this option to force the use of a different User-Agent header. As of ClamAV 0.103.3, this setting may not be used when updating from the clamav.net CDN and can only be used when updating from a private mirror.

Default: clamav/version_number

NotifyClamd STRING
Notify a running clamd(8) to reload its database after a download has occurred. The path for clamd.conf file must be provided.

Default: The default is to not notify clamd. See clamd.conf(5)'s option SelfCheck for how clamd(8) handles database updates in this case.

OnUpdateExecute STRING
Execute this command after the database has been successfully updated.

Default: disabled

OnErrorExecute STRING
Execute this command after a database update has failed.

Default: disabled

OnOutdatedExecute STRING
Execute this command when freshclam reports outdated version. In the command string %v will be replaced by the new version number.

Default: disabled

LocalIPAddress IP
Use IP as client address for downloading databases. Useful for multi homed systems.

Default: Use OS'es default outgoing IP address.

ConnectTimeout NUMBER
Timeout in seconds when connecting to database server.

Default: 10

ReceiveTimeout NUMBER
Maximum time in seconds for each download operation. 0 means no timeout.

Default: 0

Bytecode BOOL
This option enables downloading of bytecode.cvd, which includes additional detection mechanisms and improvements to the ClamAV engine.

Default: yes

FILES

/etc/clamav/freshclam.conf
