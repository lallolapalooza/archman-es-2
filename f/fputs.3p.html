FPUTS(3P) Manual del programador POSIX FPUTS(3P)

PROLOGO

Esta página del manual es parte del Manual del programador POSIX. La implementación de esta interfaz en Linux puede diferir (consulte la página del manual de Linux correspondiente para conocer los detalles del comportamiento en Linux), o la interfaz puede no estar implementada en Linux.

NOMBRE

fputs — escribir una cadena en un flujo

SINOPSIS

#include <stdio.h>
int fputs(const char *restrict s, FILE *restrict stream);

DESCRIPCIÓN

La funcionalidad descrita en esta página de referencia está alineada con el estándar ISO C. Cualquier conflicto entre los requisitos descritos aquí y el estándar ISO C es involuntario. Este volumen de POSIX.1‐2017 se remite al estándar ISO C.

La función fputs() escribirá la cadena terminada en nulo apuntada por s en el flujo apuntado por stream. El byte nulo terminador no se escribirá.

Las marcas de tiempo de la última modificación de datos y del último cambio de estado del archivo se marcarán para actualización entre la ejecución exitosa de fputs() y la próxima finalización exitosa de una llamada a fflush() o fclose() en el mismo flujo o una llamada a exit() o abort().

VALOR DE RETORNO

Al completarse con éxito, fputs() devolverá un número no negativo. De lo contrario, devolverá EOF, establecerá un indicador de error para el flujo y establecerá errno para indicar el error.

ERRORES

Consulte fputc().

EJEMPLOS

Imprimir en la salida estándar

El siguiente ejemplo obtiene la hora actual, la convierte en una cadena usando localtime() y asctime(), y la imprime en la salida estándar usando fputs(). Luego imprime el número de minutos para un evento al que está esperando.

#include <time.h>
#include <stdio.h>
...
time_t now;
int minutes_to_event;
...
time(&now);
printf("La hora es ");
fputs(asctime(localtime(&now)), stdout);
printf("Todavía quedan %d minutos para el evento.\n",
    minutes_to_event);
...

USO DE LA APLICACIÓN

La función puts() añade un <salto de línea> mientras que fputs() no lo hace.

Este volumen de POSIX.1‐2017 requiere que la finalización exitosa simplemente devuelva un entero no negativo. Existen al menos tres convenciones de implementación diferentes conocidas para este requisito:

*
Devolver un valor constante.
*
Devolver el último carácter escrito.
*
Devolver el número de bytes escritos. Tenga en cuenta que esta convención de implementación no se puede cumplir para cadenas más largas que {INT_MAX} bytes, ya que el valor no sería representable en el tipo de retorno de la función. Para compatibilidad con versiones anteriores, las implementaciones pueden devolver el número de bytes para cadenas de hasta {INT_MAX} bytes, y devolver {INT_MAX} para todas las cadenas más largas.

FUNDAMENTO

fputs() es una función cuyo código fuente se especificó en el libro The C Programming Language de referencia. En la edición original, la función no tenía un valor de retorno definido, pero muchas implementaciones prácticas, como efecto secundario, devolvían el valor del último carácter escrito, ya que era el valor que quedaba en el acumulador utilizado como valor de retorno. En la segunda edición del libro, se devolvería 0 o EOF según el valor de retorno de ferror(); sin embargo, por compatibilidad con las implementaciones existentes, varias implementaciones devolverían, tras el éxito, un valor positivo que representa el último byte escrito.
