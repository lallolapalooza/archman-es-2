NOMBRE

fulla - Corregir distorsión de lente, viñeteado y aberración cromática

SINOPSIS

fulla [opciones] archivo(s) de entrada

DESCRIPCIÓN

Aplicar corrección de viñeteado radial o de campo plano, así como corrección de distorsión radial geométrica y aberración cromática transversal.

fulla puede usarse para corregir por lotes un gran número de archivos. Los coeficientes de distorsión radial se pueden leer de una base de datos de lentes.

La corrección de viñeteado se realiza de la misma manera que se describe en la documentación del archivo de script de nona, o desde la base de datos de lentes. La corrección de viñeteado se puede hacer basándose en un campo plano o en un escalado radial.

Corrección de viñeteado por división de campo plano:
I = I / c, c = campo_plano / media(campo_plano)

Corrección de viñeteado radial:
I = I / c, c = a + b*r^2 + c*r^4 + d*r^6

La corrección de distorsión radial es idéntica a la implementada por PanoTools:

r_nuevo = a*r^4 + b*r^3 + c*r^2 + d*r [1]

Dado que las aberraciones cromáticas transversales (TCA) conducen a objetos escalados de forma diferente en los canales rojo, verde y azul, se pueden corregir escalando los canales rojo y azul para que coincidan con el canal verde. La mayoría de las aplicaciones, como Photoshop o Picture Window Pro, ofrecen corrección de TCA mediante escalado lineal. Esto es igual a variar el parámetro d en la ecuación [1].

Ver http://hugin.sf.net/tutorials/tca para un método de determinación de estos parámetros.

OPCIONES

--green=bd|a:b:c:d
Coeficiente de corrección de distorsión radial para todos los canales, (a, b, c, d). Especificar 'bd' para búsqueda en base de datos o los 4 coeficientes a:b:c:d
--blue=bd|a:b:c:d
Coeficientes de corrección de distorsión radial para el canal azul, (a, b, c, d). Esto se aplica sobre los coeficientes de distorsión de --green, usar para corrección TCA. Especificar 'bd' para búsqueda en base de datos o los 4 coeficientes a:b:c:d
--red=bd|a:b:c:d
Coeficientes de corrección de distorsión radial para el canal rojo, (a, b, c, d). Esto se aplica sobre los coeficientes de distorsión de --green, usar para corrección TCA. Especificar 'bd' para búsqueda en base de datos o los 4 coeficientes a:b:c:d
--camera-maker=Fabricante
Fabricante de la cámara, para consulta en base de datos
--camera-model=Camara
Nombre de la cámara, para consulta en base de datos
--lensname=Lente
Nombre de la lente, para consulta en base de datos
Especificar --camera-maker y --camera-model para cámaras con lente fijo o --lensname para lentes intercambiables.
--focallength=50
Especificar longitud focal en mm, para consulta en base de datos
--aperature=3.5
Especificar apertura para consulta en base de datos de viñeteado
--dont-rescale
No escalar la imagen para evitar bordes negros.
--flatfield=nombrearchivo
Corrección de viñeteado por división de campo plano I = I / c, c = campo_plano / media(campo_plano)
--vignetting=bd|a:b:c:d
Corregir viñeteado (por división). Especificar bd para búsqueda en base de datos o los 4 coeficientes a:b:c:d I = I / ( a + b*r^2 + c*r^4 + d*r^6)
--linear
Realizar corrección de viñeteado en espacio de color lineal
--gamma=valor
Gamma de los datos de entrada. Usado para corrección gamma antes y después de la corrección de campo plano
threads=n
Número de hilos que deben usarse
-h|--help
Mostrar ayuda
--output=nombre
Establecer nombre de archivo de salida. Si se dan varios archivos, el nombre se usará como sufijo. (sufijo por defecto: _corr)
--compression=valor
Compresión de los archivos de salida. Para salida jpeg: 0-100. Para salida tiff: PACKBITS, DEFLATE, LZW
--offset=X:Y
Desplazamiento horizontal y vertical
--verbose
Detallado
