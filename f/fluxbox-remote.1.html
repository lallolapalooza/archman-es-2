FLUXBOX-REMOTE(1) Manual de Fluxbox FLUXBOX-REMOTE(1)

NOMBRE

fluxbox-remote - acceso desde línea de comandos a comandos clave de fluxbox(1)

SINOPSIS

fluxbox-remote comando

DESCRIPCIÓN

fluxbox-remote(1) está diseñado para permitir a los scripts ejecutar la mayoría de los comandos clave de fluxbox(1). fluxbox-remote(1) solo funcionará con fluxbox(1): sus comunicaciones con fluxbox(1) no están estandarizadas de ninguna manera. Se recomienda que se utilice una herramienta basada en estándares como wmctrl(1) siempre que sea posible, para que los scripts funcionen con otros gestores de ventanas.

ADVERTENCIAS

fluxbox-remote(1) utiliza el protocolo X11 para comunicarse con fluxbox(1). Por lo tanto, es posible que cualquier usuario con acceso al servidor X(7) utilice fluxbox-remote(1). Por esta razón, varios comandos clave han sido deshabilitados. Los usuarios deben ser conscientes de las implicaciones de seguridad al habilitar fluxbox-remote(1), especialmente al utilizar una conexión X(7) reenviada.

RECURSOS

session.screen0.allowRemoteActions: <booleano>

Este recurso en ~/.fluxbox/init debe establecerse en «true» para que fluxbox-remote(1) funcione. Por favor, lea las ADVERTENCIAS primero.

ENTORNO

Para comunicarse con fluxbox(1), la variable de entorno DISPLAY debe estar configurada correctamente. Normalmente, el valor debe ser «:0.0».
