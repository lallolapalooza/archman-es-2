fma(3) Manual de funciones de biblioteca fma(3)

NOMBRE

fma, fmaf, fmal - multiplicar y sumar punto flotante

BIBLIOTECA

Biblioteca matemática (libm, -lm)

SINOPSIS

#include <math.h>
double fma(double x, double y, double z);
float fmaf(float x, float y, float z);
long double fmal(long double x, long double y, long double z);
Requisitos de macro de prueba de características para glibc (ver feature_test_macros(7)):

fma(), fmaf(), fmal():

    _ISOC99_SOURCE || _POSIX_C_SOURCE >= 200112L

DESCRIPCIÓN

Estas funciones calculan x * y + z. El resultado se redondea como una única operación ternaria según el modo de redondeo actual (ver fenv(3)).

VALOR DE RETORNO

Estas funciones devuelven el valor de x * y + z, redondeado como una única operación ternaria.

Si x o y es un NaN, se devuelve un NaN.

Si x por y es un infinito exacto, y z es un infinito con el signo opuesto, ocurre un error de dominio y se devuelve un NaN.

Si uno de x o y es un infinito, y el otro es 0, y z no es un NaN, ocurre un error de dominio y se devuelve un NaN.

Si uno de x o y es un infinito, y el otro es 0, y z es un NaN, ocurre un error de dominio y se devuelve un NaN.

Si x por y no es un infinito por cero (o viceversa), y z es un NaN, se devuelve un NaN.

Si el resultado desborda, ocurre un error de rango y se devuelve un infinito con el signo correcto.

Si el resultado subdesborda, ocurre un error de rango y se devuelve un 0 con signo.

ERRORES

Ver math_error(7) para obtener información sobre cómo determinar si ha ocurrido un error al llamar a estas funciones.

Los siguientes errores pueden ocurrir:

Error de dominio: x * y + z o x * y es inválido.
Se genera una excepción de punto flotante inválida (FE_INVALID).
Error de rango: desbordamiento del resultado
Se genera una excepción de punto flotante por desbordamiento (FE_OVERFLOW).
Error de rango: subdesbordamiento del resultado
Se genera una excepción de punto flotante por subdesbordamiento (FE_UNDERFLOW).

Estas funciones no establecen errno.

ATRIBUTOS

Para una explicación de los términos utilizados en esta sección, ver attributes(7).

Interfaz Atributo Valor
fma (), fmaf (), fmal () Seguridad en hilos MT-Safe

ESTANDARES

C11, POSIX.1-2008.

HISTORIA

glibc 2.1. C99, POSIX.1-2001.
