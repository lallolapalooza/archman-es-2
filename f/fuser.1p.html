FUSER(1P) Manual de Programador de POSIX FUSER(1P)

PROLOGO

Esta página del manual forma parte del Manual de Programador de POSIX. La implementación de esta interfaz en Linux puede diferir (consulte la página del manual de Linux correspondiente para obtener detalles del comportamiento de Linux), o la interfaz puede no estar implementada en Linux.

NOMBRE

fuser — lista los IDs de proceso de todos los procesos que tienen uno o más archivos abiertos

SINOPSIS

fuser [-cfu] archivo...

DESCRIPCION

La utilidad fuser escribirá en la salida estándar los IDs de proceso de los procesos que se ejecutan en el sistema local y que tienen uno o más archivos nombrados abiertos. Para dispositivos especiales de bloques, se listarán todos los procesos que utilizan cualquier archivo en ese dispositivo.

La utilidad fuser escribirá en la salida de error estándar información adicional sobre los archivos nombrados, indicando cómo se está utilizando el archivo.

Cualquier salida para procesos que se ejecutan en sistemas remotos que tienen un archivo nombrado abierto no está especificada.

Un usuario puede necesitar privilegios apropiados para invocar la utilidad fuser.

OPCIONES

La utilidad fuser se ajustará al volumen de Definiciones Base de POSIX.1‐2017, Sección 12.2, Guías de Sintaxis de Utilidad.

Las siguientes opciones serán compatibles:

-c
El archivo se tratará como un punto de montaje y la utilidad informará sobre cualquier archivo abierto en el sistema de archivos.
-f
El informe será solo para los archivos nombrados.
-u
El nombre de usuario, entre paréntesis, asociado a cada ID de proceso escrito en la salida estándar se escribirá en la salida de error estándar.

OPERANDOS

El siguiente operando será compatible:

archivo
Una ruta de acceso en la que se informará sobre el archivo o sistema de archivos.

ENTRADA ESTÁNDAR

No se utiliza.

ARCHIVOS DE ENTRADA

La base de datos de usuarios.

VARIABLES DE ENTORNO

Las siguientes variables de entorno afectarán la ejecución de fuser:

LANG
Proporciona un valor predeterminado para las variables de internacionalización que no están establecidas o están vacías. (Consulte el volumen de Definiciones Base de POSIX.1‐2017, Sección 8.2, Variables de Internacionalización para la precedencia de las variables de internacionalización utilizadas para determinar los valores de las categorías de localización.)
LC_ALL
Si se establece en una cadena de caracteres no vacía, anulará los valores de todas las demás variables de internacionalización.
LC_CTYPE
Determina la localización para la interpretación de secuencias de bytes de datos de texto como caracteres (por ejemplo, caracteres de un solo byte frente a caracteres multibyte en los argumentos).
LC_MENSAJES

Determina la localización que debe utilizarse para afectar el formato y el contenido de los mensajes de diagnóstico escritos en la salida de error estándar.
NLSPATH
Determina la ubicación de los catálogos de mensajes para el procesamiento de LC_MENSAJES.

EVENTOS ASINCRONOS

Predeterminado.

SALIDA ESTÁNDAR

La utilidad fuser escribirá el ID de proceso de cada proceso que utilice cada archivo proporcionado como operando en la salida estándar en el siguiente formato:

"%d", <id_de_proceso>

SALIDA DE ERROR ESTÁNDAR

La utilidad fuser escribirá mensajes de diagnóstico en la salida de error estándar.

La utilidad fuser también escribirá lo siguiente en la salida de error estándar:

*
Se escribe la ruta de acceso de cada archivo nombrado seguida inmediatamente por dos puntos (<colon>).
*
Para cada ID de proceso escrito en la salida estándar, se escribirá el carácter 'c' en la salida de error estándar si el proceso está utilizando el archivo como su directorio actual y el carácter 'r' se escribirá en la salida de error estándar si el proceso está utilizando el archivo como su directorio raíz. Las implementaciones pueden escribir otros caracteres alfabéticos para indicar otros usos de archivos.
*
Cuando se especifica la opción -u, los caracteres que indican el uso del archivo irán seguidos inmediatamente por el nombre de usuario, entre paréntesis, correspondiente al ID de usuario real del proceso. Si el nombre de usuario no se puede resolver a partir del ID de usuario real del proceso, se escribirá el ID de usuario real del proceso en lugar del nombre de usuario.

Cuando la salida estándar y la salida de error estándar se dirigen al mismo archivo, la salida se intercalará de modo que el nombre del archivo aparezca al principio de cada línea, seguido por el ID del proceso y los caracteres que indican el uso del archivo. Luego, si se especifica la opción -u, se escribirá el nombre de usuario o el ID de usuario de cada proceso que utilice ese archivo.

Se escribirá un salto de línea (<newline>) en la salida de error estándar después de la última salida descrita anteriormente para cada operando archivo.

USO DE APLICACIONES

Ninguno.

EJEMPLOS

El comando:

fuser -fu .

escribe en la salida estándar los IDs de proceso de los procesos que están utilizando el directorio actual y escribe en la salida de error estándar una indicación de cómo esos procesos están utilizando el directorio y los nombres de usuario asociados con los procesos que están utilizando el directorio actual.

fuser -c <punto_de_montaje>

escribe en la salida estándar los IDs de proceso de los procesos que están utilizando cualquier archivo en el sistema de archivos que está montado en <punto_de_montaje> y escribe en la salida de error estándar una indicación de cómo esos procesos están utilizando los archivos.

fuser <punto_de_montaje>

escribe en la salida estándar los IDs de proceso de los procesos que están utilizando el archivo nombrado por <punto_de_montaje> y escribe en la salida de error estándar una indicación de cómo esos procesos están utilizando el archivo.

fuser <dispositivo_de_bloque>

escribe en la salida estándar los IDs de proceso de los procesos que están utilizando cualquier archivo que se encuentre en el dispositivo nombrado por <dispositivo_de_bloque> y escribe en la salida de error estándar una indicación de cómo esos procesos están utilizando el archivo.

fuser -f <dispositivo_de_bloque>

escribe en la salida estándar los IDs de proceso de los procesos que están utilizando el propio archivo <dispositivo_de_bloque> y escribe en la salida de error estándar una indicación de cómo esos procesos están utilizando el archivo.

fuser -v <archivo>

Escribe en la salida estándar los IDs de proceso de los procesos que utilizan el archivo especificado. Escribe en la salida de error estándar una lista de los procesos que utilizan el archivo, el usuario asociado a cada proceso y el tipo de acceso que tiene cada proceso al archivo.
