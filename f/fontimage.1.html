FONTIMAGE(1) Manual de Comandos Generales FONTIMAGE(1)

NOMBRE

fontimage - produce una imagen en miniatura de fuente

SINOPSIS

fontimage [--help] [--width num] [--height num] [--pixelsize num] [--text cadena] [--o archivo_salida] [--usage] [--version] archivo_fuente

DESCRIPCIÓN

El programa fontimage carga una fuente, que puede estar en cualquier formato que fontforge(1) pueda leer, y luego produce una imagen que muestra glifos representativos de la fuente.

OPCIONES

--help
Proporciona una descripción con una lista de las opciones disponibles.
--width num
Especifica el ancho de la imagen de salida. Si se omite, la imagen será tan ancha como sea necesario para mostrar el texto.
--height num
Especifica la altura de la imagen de salida. Si se omite, la imagen será tan alta como sea necesario para mostrar el texto.
--pixelsize num
Especifica el tamaño en píxeles utilizado para mostrar el texto. Este argumento puede especificarse varias veces y cada uno se refiere a cualquier línea --text que le siga.
--text cadena
Especifica una línea de texto para ser mostrada. La cadena debe estar en UTF-8. Este argumento puede especificarse varias veces para proporcionar varias líneas de texto. Si no se proporcionan argumentos --text, fontimage examinará la fuente, buscando varios scripts que conozca, e intentará mostrar algo apropiado para cada uno.
-o archivo_salida
Especifica el nombre del archivo de salida para la imagen. El tipo de imagen se determinará por la extensión del archivo. Actualmente, solo se reconocen ".bmp" y ".png". Si se omite, fontimage elegirá un nombre de salida basado en el campo fontname de la fuente.
--usage
Muestra la descripción de uso.
--version
Muestra la versión actual.
