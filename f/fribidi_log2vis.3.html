NOMBRE

fribidi_log2vis - obtener cadena visual

SINOPSIS

#include <../fribidi/lib/fribidi.h>

FriBidiLevel fribidi_log2vis
(
const FriBidiChar *str,
const FriBidiStrIndex len,
FriBidiParType *pbase_dir,
FriBidiChar *visual_str,
FriBidiStrIndex *positions_L_to_V,
FriBidiStrIndex *positions_V_to_L,
FriBidiLevel *embedding_levels
);

PARÁMETROS

const FriBidiChar *str
Cadena lógica de entrada.
const FriBidiStrIndex len
Longitud de la cadena de entrada.
FriBidiParType *pbase_dir
Dirección base del párrafo solicitada y resuelta.

Los valores posibles para un FriBidiParType son los siguientes:

FRIBIDI_PAR_LTR
Párrafo de Izquierda a Derecha.
FRIBIDI_PAR_RTL
Párrafo de Derecha a Izquierda.
FRIBIDI_PAR_ON
Párrafo Neutro en cuanto a Dirección.
FRIBIDI_PAR_WLTR
Párrafo Débil de Izquierda a Derecha.
FRIBIDI_PAR_WRTL
Párrafo Débil de Derecha a Izquierda.
FriBidiChar *visual_str
Cadena visual de salida.
FriBidiStrIndex *positions_L_to_V
Mapeo de salida de las posiciones de la cadena lógica a la visual.
FriBidiStrIndex *positions_V_to_L
Mapeo de salida de la cadena visual de vuelta a las posiciones de la cadena lógica.
FriBidiLevel *embedding_levels
Lista de salida de los niveles de incrustación.

DESCRIPCIÓN

Esta función convierte la cadena lógica de entrada a las cadenas visuales de salida según lo especificado por el Algoritmo Bidireccional Unicode. Como efecto secundario, también genera listas de mapeo entre las dos cadenas y la lista de niveles de incrustación según lo definido por el algoritmo.

Si se pasa NULL como cualquiera de las listas, la lista se ignora y no se rellena.

Tenga en cuenta que esta función maneja párrafos de una sola línea. Para textos de múltiples párrafos, es necesario primero dividir el texto en párrafos separados y luego transferir el pbase_dir resuelto entre las invocaciones subsiguientes.

RETORNA

El nivel máximo encontrado más uno, o cero si ocurrió algún error (probablemente un fallo en la asignación de memoria).
