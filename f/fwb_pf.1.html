NOMBRE

fwb_pf - Compilador de políticas para el filtro de paquetes de OpenBSD "pf"

SINOPSIS

fwb_pf [-vVx] [-d directorio_trabajo] [-o salida.fw] [-i] -f archivo_datos.xml nombre_objeto

DESCRIPCIÓN

fwb_pf es un componente del compilador de políticas de firewall de Firewall Builder (ver fwbuilder(1)). Este compilador genera código para el Filtro de Paquetes de OpenBSD (pf). El compilador lee las definiciones de objetos y la descripción del firewall desde el archivo de datos especificado con la opción "-f" y genera archivos de configuración de pf y un script de activación del firewall.

Todos los archivos generados tienen nombres que comienzan con el nombre del objeto del firewall. El script de activación del firewall tiene la extensión ".fw" y es un script de shell simple que purga la política actual, carga las nuevas reglas de filtro y nat y luego activa pf. El nombre del archivo de configuración de PF comienza con el nombre del objeto del firewall, más "-pf.conf". El nombre del archivo de configuración de NAT también comienza con el nombre del objeto del firewall, más "-nat.conf". Por ejemplo, si el objeto del firewall se llama "mi_firewall", el compilador creará tres archivos: "mi_firewall.fw", "mi_firewall-pf.conf", "mi_firewall-nat.conf".

El archivo de datos y el nombre de los objetos del firewall deben especificarse en la línea de comandos. Otros parámetros de la línea de comandos son opcionales.

OPCIONES

-f ARCHIVO
Especifica el nombre del archivo de datos a procesar.
-o salida.fw
Especifica el nombre del archivo de salida
-d directorio_trabajo
Especifica el directorio de trabajo. El compilador crea el script de activación del firewall y los archivos de configuración de PF en este directorio. Si este parámetro falta, todos los archivos se colocarán en el directorio de trabajo actual.
-v
Sea verboso: el compilador imprime mensajes de diagnóstico mientras trabaja.
-V
Imprime el número de versión y sale.
-i
Cuando esta opción está presente, el último argumento en la línea de comandos se supone que es el ID del objeto del firewall en lugar de su nombre.
-x
Genera información de depuración mientras trabaja. Esta opción está destinada solo a la depuración y puede producir muchos mensajes crípticos.

NOTAS

El soporte para PF se introdujo en la versión 1.0.1 de Firewall Builder.

Características admitidas:

o
se generan tanto los archivos pf.conf como nat.conf
o
negación en las reglas de política y NAT
o
agrupación en "from", "to" y puertos usando la sintaxis '{' '}'
o
si la casilla "Scrub" está marcada en el cuadro de diálogo de opciones de regla, y la acción de la regla es Aceptar, el compilador genera dos reglas (casi) idénticas: la primera con acción 'scrub' y la segunda con acción 'pass quick'
o
la inspección con estado en reglas individuales se puede desactivar en el cuadro de diálogo de opciones de reglas. Por defecto, el compilador agrega "keep state" o "modulate state" a cada regla con acción 'pass'
o
el cuadro de diálogo de opciones de reglas proporciona una opción de respuestas icmp o tcp rst para reglas con acción "Reject"
o
el compilador agrega la bandera "allow-opts" si se necesita una coincidencia en opciones de IP
o
el compilador puede generar reglas que coincidan con banderas TCP
o
el compilador puede generar un script que agregue alias de IP para reglas NAT usando direcciones que no pertenecen a ninguna interfaz del firewall
o
el compilador siempre agrega la regla "block quick all" al final del script para garantizar la política "bloquear todo por defecto" incluso si la política está vacía.
o
rangos de direcciones tanto en política como en NAT

Características que no son compatibles (todavía)

o
servicios personalizados

Lo que no será compatible (al menos no en el corto plazo)

o
enrutamiento de políticas
