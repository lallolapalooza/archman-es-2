NAME

fpathconf, pathconf - get configurable pathname variables

LIBRARY

Standard C library (libc, -lc)

SYNOPSIS

#include <unistd.h>

long fpathconf(int fd, int name);
long pathconf(const char *path, int name);

DESCRIPTION

The function fpathconf() returns the value of a configurable variable associated with the file descriptor fd. The function pathconf() returns the value of a configurable variable associated with the file specified by the pathname path.

The name argument specifies which variable to query. The following values are defined for name (defined in <unistd.h>):

_PC_CHOWN_RESTRICTED
Indicates whether chown(2) is restricted to disallowing changes to a file's owner or group ID. On success, returns a nonnegative value if chown(2) is restricted, and 0 otherwise.
_PC_MAX_CANON
The value of st_size of a file. This is the maximum length of a canonicalized input line.
_PC_MAX_INPUT
The maximum number of bytes for which the system will accept input in a buffer.
_PC_NAME_MAX
The maximum number of characters in a filename component (excluding the terminating null byte).
_PC_NO_TRUNC
Indicates whether filenames longer than _PC_NAME_MAX are truncated. On success, returns a nonnegative value if filenames longer than _PC_NAME_MAX are truncated, and 0 otherwise.
_PC_PATH_MAX
The maximum length of a pathname.
_PC_PIPE_BUF
The maximum number of bytes that can be written atomically to a pipe.
_PC_SYNC_IO
Indicates whether synchronous I/O is supported. On success, returns a nonnegative value if synchronous I/O is supported, and 0 otherwise.
_PC_VDISABLE
The value that can be assigned to the c_cc[VMIN] and c_cc[VTIME] members of a termios structure to disable the corresponding special character.

See also fcntl(2), termios(3), confstr(3).

RETURN VALUE

On success, fpathconf() and pathconf() return the value of the requested system limit. If an error occurs, they return -1 and set errno to indicate the error.

If the system limit is not defined for the specified name, or if the limit is not defined for the file descriptor or path, the return value is -1 and errno is set to EINVAL.

ERRORS

EBADF
fpathconf() was called with an invalid file descriptor fd.
EINVAL
name is not a valid value, or the limit corresponding to name is not defined for the file descriptor or path.
ENAMETOOLONG
A pathname resolution process resulted in a too-long name. This occurs pathconf() is called with a name other than _PC_NAME_MAX or _PC_PATH_MAX and the pathname specified by path is too long.
ENOENT
The file specified by path does not exist.
ENOTDIR
A component of the path prefix is not a directory, or path is a relative path and the current directory does not exist.
ENOMEM
Insufficient kernel memory was available to satisfy the request.
ENOSYS
The underlying system does not support this function.
EROFS
path refers to a read-only filesystem, and the operation would have modified the filesystem.
ETXTBSY
The file named by path is a regular file that is being executed.

STANDARDS

POSIX.1-2001, POSIX.1-2008.

HISTORY

POSIX.1-2001.

NOTES

The behavior of fpathconf() and pathconf() depends on the underlying system. Some values may not be defined or may be fixed constants.

The constants for name (e.g., _PC_PATH_MAX) are defined in <unistd.h>.
