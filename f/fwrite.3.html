fread(3) Manual de funciones de la biblioteca fread(3)

NOMBRE

fread, fwrite - entrada/salida binaria de flujo

BIBLIOTECA

Biblioteca estándar C (libc, -lc)

SINOPSIS

#include <stdio.h>
size_t fread(size_t size, size_t n;
             void ptr[restrict size * n],
             size_t size, size_t n,
             FILE *restrict stream);
size_t fwrite(size_t size, size_t n;
             const void ptr[restrict size * n],
             size_t size, size_t n,
             FILE *restrict stream);

DESCRIPCIÓN

La función fread() lee n elementos de datos, cada uno de size bytes de longitud, del flujo apuntado por stream, almacenándolos en la ubicación dada por ptr.

La función fwrite() escribe n elementos de datos, cada uno de size bytes de longitud, en el flujo apuntado por stream, obteniéndolos de la ubicación dada por ptr.

Para contrapartes no bloqueantes, vea unlocked_stdio(3).

VALOR DE RETORNO

En caso de éxito, fread() y fwrite() devuelven el número de elementos leídos o escritos. Este número es igual al número de bytes transferidos solo cuando size es 1. Si ocurre un error, o se alcanza el final del archivo, el valor de retorno es un recuento de elementos parcial (o cero).

El indicador de posición del archivo para el flujo se avanza por el número de bytes leídos o escritos correctamente.

fread() no distingue entre el final del archivo y el error, y los llamadores deben usar feof(3) y ferror(3) para determinar cuál ocurrió.

ATRIBUTOS

Para una explicación de los términos utilizados en esta sección, vea attributes(7).

Interfaz Atributo Valor
fread (), fwrite () Seguridad de hilos MT-Safe

ESTANDARES

C11, POSIX.1-2008.

HISTORIAL

POSIX.1-2001, C89.

EJEMPLOS

El programa siguiente demuestra el uso de fread() analizando el ejecutable ELF /bin/sh en modo binario e imprimiendo su magia y clase:


$ ./a.out;
ELF magic: 0x7f454c46
Class: 0x02

Fuente del programa

#include <stdio.h>
#include <stdlib.h>
#define NITEMS(arr)  (sizeof(arr) / sizeof((arr)[0]))
int
main(void)
{
    FILE           *fp;
    size_t         ret;
    unsigned char  buffer[4];
    fp = fopen("/bin/sh", "rb");
    if (!fp) {
        perror("fopen");
        return EXIT_FAILURE;
    }
    ret = fread(buffer, sizeof(*buffer), NITEMS(buffer), fp);
    if (ret != NITEMS(buffer)) {
        fprintf(stderr, "fread() failed: %zu\n", ret);
        exit(EXIT_FAILURE);
    }
    printf("ELF magic: %#04x%02x%02x%02x\n", buffer[0], buffer[1],
           buffer[2], buffer[3]);
    ret = fread(buffer, 1, 1, fp);
    if (ret != 1) {
        fprintf(stderr, "fread() failed: %zu\n", ret);
        exit(EXIT_FAILURE);
    }
    printf("Class: %#04x\n", buffer[0]);
    fclose(fp);
    exit(EXIT_SUCCESS);
}
