FreeHDL-CONFIG(1) Comandos de usuario FreeHDL-CONFIG(1)

NOMBRE

FreeHDL-CONFIG - El script de configuración de FreeHDL.

SINOPSIS

freehdl-config [OPCIÓN] ...

DESCRIPCIÓN

FreeHDL es un conjunto de analizador/compilador/simulador para el lenguaje de descripción de hardware VHDL. Se admiten archivos VHDL'93 y VHDL'87.

FreeHDL-CONFIG se puede utilizar para obtener la configuración de instalación (ruta) del paquete FreeHDL.

OPCIONES

-v, --version
mostrar la versión instalada de FreeHDL
-h, --help
mostrar información de uso
-l, --ldflags
imprimir las bibliotecas con las que enlazar
-libs, --libtool
imprimir las bibliotecas de libtool con las que enlazar
-ieee, --ieee
imprimir las bibliotecas de libtool IEEE con las que enlazar
-c, --cxxflags
imprimir las banderas del compilador C++ con las que compilar
-cxx, --cxx
imprimir el compilador C++ -linker, --linker imprimir el enlazador de libtool

VER TAMBIÉN

gvhdl(1), freehdl-v2cc(1), v2cc.libs(5)

DISPONIBILIDAD

La última versión de FreeHDL siempre se puede obtener en www.freehdl.seul.org

REPORTE DE ERRORES

Los errores conocidos se documentan en el archivo BUGS. Si su informe aborda un tema relacionado con el analizador, póngase en contacto con Marius Vollmer <mvo@zagadka.ping.de>. Si está relacionado con el generador de código o el compilador, envíe un correo electrónico a Edwin Naroska <edwin@ds.e-technik.uni-dortmund.de>. Si no está seguro, envíelo a Edwin. Él se encargará de reenviar su informe al destinatario adecuado.
