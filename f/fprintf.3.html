DESCRIPCIÓN

Las funciones de la familia printf() producen salida de acuerdo con un formato descrito a continuación. Las funciones printf() y vprintf() escriben la salida en stdout, el flujo de salida estándar; fprintf() y vfprintf() escriben la salida en el flujo de salida streamdado; sprintf(), snprintf(), vsprintf(), y vsnprintf() escriben en la cadena de caracteres str.

La función dprintf() es igual a fprintf() excepto que escribe en un descriptor de archivo, fd, en lugar de en un flujo stdio(3) .

Las funciones snprintf() y vsnprintf() escriben como máximo size bytes (incluyendo el byte nulo final ('\0')) en str.

Las funciones vprintf(), vfprintf(), vdprintf(), vsprintf(), vsnprintf() son equivalentes a las funciones printf(), fprintf(), dprintf(), sprintf(), snprintf(), respectivamente, excepto que se llaman con un va_list en lugar de un número variable de argumentos. Estas funciones no llaman a la macro va_end . Debido a que invocan la macro va_arg , el valor de ap es indefinido después de la llamada. Ver stdarg(3).

Todas estas funciones escriben la salida bajo el control de una cadena formato que especifica cómo se convierten para la salida los argumentos subsiguientes (o los argumentos accedidos a través de las instalaciones de argumentos de longitud variable de stdarg(3)) .

C99 y POSIX.1-2001 especifican que los resultados son indefinidos si una llamada a sprintf(), snprintf(), vsprintf(), o vsnprintf() causaría que se produjera una copia entre objetos que se superponen (por ejemplo, si la cadena de destino y uno de los argumentos de entrada proporcionados se refieren al mismo búfer). Ver ADVERTENCIAS.

Formato de la cadena de formato

La cadena de formato es una cadena de caracteres, que comienza y termina en su estado de cambio inicial, si lo hay. La cadena de formato está compuesta por cero o más directivas: caracteres ordinarios (no %), que se copian sin cambios al flujo de salida; y especificaciones de conversión, cada una de las cuales resulta en la obtención de cero o más argumentos subsiguientes. Cada especificación de conversión es introducida por el carácter %, y termina con un especificador de conversión. Entre ellos puede haber (en este orden) cero o más banderas, un ancho de campomínimo opcional, una precisión opcional y un modificador de longitudopcional.

La sintaxis general de una especificación de conversión es:


%[argument$][flags][width][.precision][length modifier]conversion

Los argumentos deben corresponder adecuadamente (después de la promoción de tipo) con el especificador de conversión. Por defecto, los argumentos se utilizan en el orden dado, donde cada '*' (ver Ancho de campo y Precisión más abajo) y cada especificador de conversión solicita el siguiente argumento (y es un error si se proporcionan argumentos insuficientes). También se puede especificar explícitamente qué argumento se toma, en cada lugar donde se requiere un argumento, escribiendo "%m$" en lugar de '%' y "*m$" en lugar de '*', donde el entero decimal m denota la posición en la lista de argumentos del argumento deseado, indexada a partir de 1. Así,


printf("%*d", width, num);

y


printf("%2$*1$d", width, num);

son equivalentes. El segundo estilo permite referencias repetidas al mismo argumento. El estándar C99 no incluye el estilo que usa '$', que proviene de la Especificación UNIX Única. Si se usa el estilo que usa '$', debe usarse en todas las conversiones que tomen un argumento y en todos los argumentos de ancho y precisión, pero puede mezclarse con formatos "%%", que no consumen un argumento. No puede haber huecos en los números de argumentos especificados usando '$'; por ejemplo, si se especifican los argumentos 1 y 3, el argumento 2 también debe especificarse en algún lugar de la cadena de formato.

Para algunas conversiones numéricas se usa un carácter de radix ("punto decimal") o un carácter de agrupación de miles. El carácter real utilizado depende de la parte LC_NUMERIC de la configuración regional (locale). (Ver setlocale(3).) La configuración regional POSIX usa '.' como carácter de radix, y no tiene un carácter de agrupación. Así,


printf("%'.2f", 1234567.89);

resulta en "1234567.89" en la configuración regional POSIX, en "1234567,89" en la configuración regional nl_NL, y en "1.234.567,89" en la configuración regional da_DK.

Caracteres de bandera

El carácter % va seguido de cero o más de las siguientes banderas:

#
El valor debe convertirse a una "forma alternativa". Para o conversiones, el primer carácter de la cadena de salida se hace cero (anteponiendo un 0 si no era cero ya). Para x y X conversiones, un resultado distinto de cero tiene la cadena "0x" (o "0X" para X conversiones) anteponida. Para a, A, e, E, f, F, g, y G conversiones, el resultado siempre contendrá un punto decimal, incluso si no siguen dígitos (normalmente, un punto decimal aparece en los resultados de esas conversiones solo si sigue un dígito). Para g y G conversiones, los ceros finales no se eliminan del resultado como de lo contrario se haría. Para m, si errno contiene un código de error válido, se imprime la salida de strerrorname_np(errno) ; de lo contrario, se imprime el valor almacenado en errno como un número decimal. Para otras conversiones, el resultado es indefinido.
0
El valor debe rellenarse con ceros. Para d, i, o, u, x, X, a, A, e, E, f, F, g, y G conversiones, el valor convertido se rellena a la izquierda con ceros en lugar de espacios en blanco. Si aparecen las banderas 0 y - , la bandera 0 se ignora. Si se da una precisión con una conversión entera (d, i, o, u, x, y X), la bandera 0 se ignora. Para imprimir Pi con cinco decimales:


#include <math.h>
#include <stdio.h>
fprintf(stdout, "pi = %.5f\n", 4 * atan(1.0));

Para imprimir una fecha y hora en el formato "domingo, 3 de julio, 10:02", donde weekday y month son punteros a cadenas:


#include <stdio.h>
fprintf(stdout, "%s, %s %d, %.2d:%.2d\n",
        weekday, month, day, hour, min);

Muchos países utilizan el orden día-mes-año. Por lo tanto, una versión internacionalizada debe ser capaz de imprimir los argumentos en un orden especificado por el formato:


#include <stdio.h>
fprintf(stdout, format,
        weekday, month, day, hour, min);

donde format depende de la configuración regional (locale), y puede permutar los argumentos. Con el valor:


"%1$s, %3$d. %2$s, %4$d:%5$.2d\n"

se podría obtener "Sonntag, 3. Juli, 10:02".

Para asignar una cadena de tamaño suficiente e imprimir en ella (código correcto tanto para glibc 2.0 como para glibc 2.1):

#include <stdio.h>
#include <stdlib.h>
#include <stdarg.h>
char *
make_message(const char *fmt, ...)
{
    int n = 0;
    size_t size = 0;
    char *p = NULL;
    va_list ap;
    /* Determine required size.  */
    va_start(ap, fmt);
    n = vsnprintf(p, size, fmt, ap);
    va_end(ap);
    if (n < 0)
        return NULL;
    size = (size_t) n + 1;      /* One extra byte for '\0' */
    p = malloc(size);
    if (p == NULL)
        return NULL;
    va_start(ap, fmt);
    n = vsnprintf(p, size, fmt, ap);
    va_end(ap);
    if (n < 0) {
        free(p);
        return NULL;
    }
    return p;
}

Si ocurre una truncación en versiones de glibc anteriores a glibc 2.0.6, esto se trata como un error en lugar de manejarse de manera elegante.
