VALOR DE

RETORNO

Un valor de retorno cero para getaddrinfo() indica una finalización exitosa; un valor de retorno distinto de cero indica un fallo. Los valores posibles para los fallos se enumeran en la sección

ERRORES.

Tras el retorno exitoso de getaddrinfo(), la ubicación a la que res apunta hará referencia a una lista enlazada de estructuras addrinfo, cada una de las cuales especificará una dirección de socket y la información para usar al crear un socket con el cual usar esa dirección de socket. La lista incluirá al menos una estructura addrinfo. El campo ai_next de cada estructura contiene un puntero a la siguiente estructura de la lista, o un puntero nulo si es la última estructura de la lista. Cada estructura de la lista incluirá valores para usar con una llamada a la función socket(), y una dirección de socket para usar con la función connect() o, si se especificó la bandera AI_PASSIVE, para usar con la función bind(). Los campos ai_family, ai_socktype y ai_protocol deberán ser utilizables como los argumentos para la función socket() para crear un socket adecuado para usar con la dirección devuelta. Los campos ai_addr y ai_addrlen son utilizables como los argumentos para las funciones connect() o bind() con dicho socket, según la bandera

AI_PASSIVE.

Si nodename no es nulo, y si lo solicita la bandera AI_CANONNAME, el campo ai_canonname de la primera estructura addrinfo devuelta apuntará a una cadena terminada por nulo que contiene el nombre canónico correspondiente al nodename de entrada; si el nombre canónico no está disponible, entonces ai_canonname hará referencia al argumento nodename o a una cadena con el mismo contenido. El contenido del campo ai_flags de las estructuras devueltas es

indefinido.

Todos los campos en las estructuras de dirección de socket devueltas por getaddrinfo() que no se rellenan a través de un argumento explícito (por ejemplo, sin6_flowinfo) se establecerán en

cero.
