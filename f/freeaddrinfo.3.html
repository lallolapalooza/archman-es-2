Extensiones a getaddrinfo() para Nombres de Dominio Internacionalizados

A partir de glibc 2.3.4, getaddrinfo() se ha ampliado para permitir de forma selectiva que los nombres de host entrantes y salientes se conviertan y conviertan transparentemente al y del formato de Nombres de Dominio Internacionalizados (IDN) (ver RFC 3490, Internationalizing Domain Names in Applications (IDNA)). Se definen cuatro nuevas banderas:

AI_IDN
Si se especifica esta bandera, entonces el nombre de nodo dado en node se convierte al formato IDN si es necesario. La codificación de origen es la de la configuración regional actual.
Si el nombre de entrada contiene caracteres no ASCII, entonces se utiliza la codificación IDN. Esas partes del nombre de nodo (delimitadas por puntos) que contienen caracteres no ASCII se codifican utilizando Codificación Compatible con ASCII (ACE) antes de pasarlas a las funciones de resolución de nombres.
AI_CANONIDN
Después de una búsqueda de nombre exitosa, y si se especificó la bandera AI_CANONNAME, getaddrinfo() devolverá el nombre canónico del nodo correspondiente al valor de la estructura addrinfo devuelto. El valor de retorno es una copia exacta del valor devuelto por la función de resolución de nombres.
Si el nombre está codificado usando ACE, entonces contendrá el prefijo xn-- para uno o más componentes del nombre. Para convertir estos componentes a un formato legible, la bandera AI_CANONIDN se puede pasar además de AI_CANONNAME. La cadena resultante se codifica utilizando la codificación de la configuración regional actual.
AI_IDN_ALLOW_UNASSIGNED
AI_IDN_USE_STD3_ASCII_RULES
Establecer estas banderas habilitará las banderas IDNA_ALLOW_UNASSIGNED (permitir puntos de código Unicode no asignados) e IDNA_USE_STD3_ASCII_RULES (verificar la salida para asegurarse de que sea un nombre de host conforme a STD3) respectivamente para ser utilizadas en el manejo de IDNA.

VALOR DE RETORNO

getaddrinfo() devuelve 0 si tiene éxito, o uno de los siguientes códigos de error distintos de cero:

EAI_ADDRFAMILY
El host de red especificado no tiene ninguna dirección de red en la familia de direcciones solicitada.
EAI_AGAIN
El servidor de nombres devolvió una indicación de fallo temporal. Inténtelo de nuevo más tarde.
EAI_BADFLAGS
hints.ai_flags contiene banderas inválidas; o, hints.ai_flags incluyó AI_CANONNAME y node era NULL.
EAI_FAIL
El servidor de nombres devolvió una indicación de fallo permanente.
EAI_FAMILY
La familia de direcciones solicitada no es compatible.
EAI_MEMORY
Sin memoria.
EAI_NODATA
El host de red especificado existe, pero no tiene ninguna dirección de red definida.
EAI_NONAME
El node o service no se conoce; o ambos node y service son NULL; o se especificó AI_NUMERICSERV en hints.ai_flags y service no era una cadena de número de puerto numérico.
EAI_SERVICE
El servicio solicitado no está disponible para el tipo de socket solicitado. Puede estar disponible a través de otro tipo de socket. Por ejemplo, este error podría ocurrir si service era "shell" (un servicio disponible solo en sockets de flujo), y ya sea hints.ai_protocol era IPPROTO_UDP, o hints.ai_socktype era SOCK_DGRAM; o el error podría ocurrir si service no era NULL, y hints.ai_socktype era SOCK_RAW (un tipo de socket que no soporta el concepto de servicios).
EAI_SOCKTYPE
El tipo de socket solicitado no es compatible. Esto podría ocurrir, por ejemplo, si hints.ai_socktype y hints.ai_protocol son inconsistentes (por ejemplo, SOCK_DGRAM y IPPROTO_TCP, respectivamente).
EAI_SYSTEM
Otro error del sistema; errno se establece para indicar el error.

La función gai_strerror() traduce estos códigos de error a una cadena legible por humanos, adecuada para la notificación de errores.

freeaddrinfo(3) — Arch Linux

NAME

freeaddrinfo — free address structure

LIBRARY

libc, -lc

SYNOPSIS

#include <sys/types.h>
#include <sys/socket.h>
#include <netdb.h>
void freeaddrinfo(struct addrinfo *ai);

DESCRIPTION

The freeaddrinfo() function frees a dynamic list of address structures allocated by a prior call to getaddrinfo(3).

The ai argument is a pointer to the first structure in the linked list of structures. This pointer must have been returned by a successful call to getaddrinfo(3).

RETURN VALUE

None.

FILES

/etc/gai.conf

ATTRIBUTES

For an explanation of the terms used in this section, see attributes(7).

                                   | Attribute
    -----------------------------------|---------------------------
    interface, freeaddrinfo()          | Availability

VERSIONS

The freeaddrinfo() function first appeared in glibc in version 2.3.2.

STANDARDS

POSIX.1-2001, POSIX.1-2008.

HISTORY

The freeaddrinfo() function was introduced in RFC 3493.

NOTES

This function frees the linked list of addrinfo structures that was allocated by getaddrinfo(3). It is crucial to call this function after using the results of getaddrinfo(3) to avoid memory leaks.

The freeaddrinfo() function recursively frees all structures in the linked list starting from the one pointed to by ai.

EXAMPLES

A simple example showing the usage of getaddrinfo(3) and freeaddrinfo():

#include <sys/types.h>
#include <sys/socket.h>
#include <netdb.h>
#include <stdio.h>
#include <stdlib.h>
int
main(void)
{
    struct addrinfo hints;
    struct addrinfo *result, *rp;
    int s;
    const char *hostname = "www.example.com";
    const char *port = "80";
    memset(&hints, 0, sizeof(hints));
    hints.ai_family = AF_UNSPEC;     /* Allow IPv4 or IPv6 */
    hints.ai_socktype = SOCK_STREAM; /* Stream socket */
    hints.ai_flags = 0;
    hints.ai_protocol = 0;           /* Any protocol */
    s = getaddrinfo(hostname, port, &hints, &result);
    if (s != 0) {
        fprintf(stderr, "getaddrinfo: %s\n", gai_strerror(s));
        exit(EXIT_FAILURE);
    }
    for (rp = result; rp != NULL; rp = rp->ai_next) {
        char addrstr[NI_MAXHOST];
        char portstr[NI_MAXSERV];
        s = getnameinfo(rp->ai_addr, rp->ai_addrlen,
                        addrstr, sizeof(addrstr),
                        portstr, sizeof(portstr),
                        NI_NUMERICHOST | NI_NUMERICSERV);
        if (s == 0) {
            printf("Address: %s:%s\n", addrstr, portstr);
            // Here you would typically create a socket and connect
        } else {
            fprintf(stderr, "getnameinfo: %s\n", gai_strerror(s));
        }
    }
    /* Free the memory allocated by getaddrinfo() */
    freeaddrinfo(result);
    exit(EXIT_SUCCESS);
}

The following example demonstrates a simple UDP server that echoes received datagrams back to the sender.

Server program

#include <arpa/inet.h>
#include <netdb.h>
#include <stdio.h>
#include <stdlib.h>
#include <string.h>
#include <sys/socket.h>
#include <sys/types.h>
#include <unistd.h>
#define BUF_SIZE 500
#define BACKLOG 5
int
main(int argc, char *argv[])
{
    int              sfd, s;
    struct addrinfo  hints;
    struct addrinfo  *result, *rp;
    char             buf[BUF_SIZE];
    char             host[NI_MAXHOST], service[NI_MAXSERV];
    struct sockaddr_storage peer_addr;
    socklen_t        peer_addrlen;
    ssize_t          nread;
    if (argc < 2) {
        fprintf(stderr, "Usage: %s port\n", argv[0]);
        exit(EXIT_FAILURE);
    }
    memset(&hints, 0, sizeof(hints));
    hints.ai_family = AF_UNSPEC;        /* Allow IPv4 or IPv6 */
    hints.ai_socktype = SOCK_DGRAM;     /* Datagram socket */
    hints.ai_flags = AI_PASSIVE;        /* Use my IP address */
    hints.ai_protocol = 0;              /* Any protocol */
    s = getaddrinfo(NULL, argv[1], &hints, &result);
    if (s != 0) {
        fprintf(stderr, "getaddrinfo: %s\n", gai_strerror(s));
        exit(EXIT_FAILURE);
    }
    for (rp = result; rp != NULL; rp = rp->ai_next) {
        sfd = socket(rp->ai_family, rp->ai_socktype,
                     rp->ai_protocol);
        if (sfd == -1)
            continue;
        if (bind(sfd, rp->ai_addr, rp->ai_addrlen) == 0)
            break; /* Success */
        close(sfd);
    }
    if (rp == NULL) {
        fprintf(stderr, "Could not bind\n");
        exit(EXIT_FAILURE);
    }
    freeaddrinfo(result); /* No longer needed */
    printf("Server listening on port %s\n", argv[1]);
    for (;;) {        /* Read datagrams and echo them back */
        peer_addrlen = sizeof(peer_addr);
        nread = recvfrom(sfd, buf, BUF_SIZE, 0,
                         (struct sockaddr *) &peer_addr, &peer_addrlen);
        if (nread == -1) {
            perror("recvfrom");
            continue;
        }
        s = getnameinfo((struct sockaddr *) &peer_addr,
                        peer_addrlen, host, NI_MAXHOST,
                        service, NI_MAXSERV, NI_NUMERICSERV);
        if (s == 0)
            printf("Received %zd bytes from %s:%s\n",
                   nread, host, service);
        else
            fprintf(stderr, "getnameinfo: %s\n", gai_strerror(s));
        if (sendto(sfd, buf, nread, 0, (struct sockaddr *) &peer_addr,
                   peer_addrlen) != nread)
        {
            fprintf(stderr, "Error sending response\n");
        }
    }
}

Client program

#include <netdb.h>
#include <stdio.h>
#include <stdlib.h>
#include <string.h>
#include <sys/socket.h>
#include <sys/types.h>
#include <unistd.h>
#define BUF_SIZE 500
int
main(int argc, char *argv[])
{
    int              sfd, s;
    char             buf[BUF_SIZE];
    size_t           size;
    ssize_t          nread;
    struct addrinfo  hints;
    struct addrinfo  *result, *rp;
    if (argc < 3) {
        fprintf(stderr, "Usage: %s host port msg...\n", argv[0]);
        exit(EXIT_FAILURE);
    }
    /* Obtain address(es) matching host/port.  */
    memset(&hints, 0, sizeof(hints));
    hints.ai_family = AF_UNSPEC;    /* Allow IPv4 or IPv6 */
    hints.ai_socktype = SOCK_DGRAM; /* Datagram socket */
    hints.ai_flags = 0;
    hints.ai_protocol = 0;          /* Any protocol */
    s = getaddrinfo(argv[1], argv[2], &hints, &result);
    if (s != 0) {
        fprintf(stderr, "getaddrinfo: %s\n", gai_strerror(s));
        exit(EXIT_FAILURE);
    }
    /* getaddrinfo() returns a list of address structures.
       Try each address until we successfully connect(2).
       If socket(2) (or connect(2)) fails, we (close the socket
       and) try the next address.  */
    for (rp = result; rp != NULL; rp = rp->ai_next) {
        sfd = socket(rp->ai_family, rp->ai_socktype,
                     rp->ai_protocol);
        if (sfd == -1)
            continue;
        /* Use connect() for datagram sockets to simplify sending/receiving.
           It associates the default destination address with the socket. */
        if (connect(sfd, rp->ai_addr, rp->ai_addrlen) != -1)
            break;                  /* Success */
        close(sfd);
    }
    freeaddrinfo(result);           /* No longer needed */
    if (rp == NULL) {               /* No address succeeded */
        fprintf(stderr, "Could not connect\n");
        exit(EXIT_FAILURE);
    }
    /* Send remaining command-line arguments as separate
       datagrams, and read responses from server.  */
    for (size_t j = 3; j < argc; j++) {
        size = strlen(argv[j]) + 1;
                /* +1 for terminating null byte */
        if (size > BUF_SIZE) {
            fprintf(stderr,
                    "Ignoring long message in argument %zu\n", j);
            continue;
        }
        /* write() with a connected datagram socket sends to the default destination */
        if (write(sfd, argv[j], size) != size) {
            perror("write"); /* Use perror for better error reporting */
            exit(EXIT_FAILURE);
        }
        nread = read(sfd, buf, BUF_SIZE); /* read() receives from the default source */
        if (nread == -1) {
            perror("read");
            exit(EXIT_FAILURE);
        }
        printf("Received %zd bytes: %s\n", nread, buf);
    }
    exit(EXIT_SUCCESS);
}
