NOMBRE

fprcp - Programa preprocesador de Free Pascal para windres.

SINOPSIS

fprcp -i nombre_archivo [-n] [-C] [-l PASCAL|C] [-p <ruta_inclusión>]

DESCRIPCIÓN

fprcp lee un archivo .rc y lo preprocesa, escribiendo el resultado en la salida estándar a medida que avanza. Reemplaza las constantes definidas con sus valores, para que windres pueda procesar el archivo resultante y crear un recurso.

USO

fprcp necesita como mínimo la opción -i nombre_archivo, que es el archivo a procesar.

OPCIONES

fprcp tiene un pequeño número de opciones para controlar su comportamiento:

-C
Define el símbolo símbolo antes de que comience el procesamiento.
-i archivo
Especifica el nombre del archivo de entrada. Este argumento es obligatorio.
-l lenguaje
Establece el lenguaje de programación para los archivos de inclusión. La constante lenguaje puede ser una de las siguientes:
C
El lenguaje de programación C.
PASCAL
el lenguaje de programación Pascal
-n
No admite comentarios anidados. Por defecto, los comentarios anidados de pascal están habilitados.
-p ruta
Establece la ruta de inclusión. Puede contener varios archivos, separados por punto y coma.
