DESCRIPCIÓ

N

La función getifaddrs() crea una lista enlazada de estructuras que describen las interfaces de red del sistema local, y almacena la dirección del primer elemento de la lista en *ifap. La lista consta de estructuras ifaddrs, definidas de la siguiente

manera: 


struct ifaddrs {
    struct ifaddrs  *ifa_next;    /* Siguiente elemento en la lista */
    char            *ifa_name;    /* Nombre de la interfaz */
    unsigned int     ifa_flags;   /* Banderas de SIOCGIFFLAGS */
    struct sockaddr *ifa_addr;    /* Dirección de la interfaz */
    struct sockaddr *ifa_netmask; /* Máscara de red de la interfaz */
    union {
        struct sockaddr *ifu_broadaddr;
                         /* Dirección de difusión de la interfaz */
        struct sockaddr *ifu_dstaddr;
                         /* Dirección de destino punto a punto */
    } ifa_ifu;
#define              ifa_broadaddr ifa_ifu.ifu_broadaddr
#define              ifa_dstaddr   ifa_ifu.ifu_dstaddr
    void            *ifa_data;    /* Datos específicos de la dirección */
}
;

El campo ifa_next contiene un puntero a la siguiente estructura de la lista, o NULL si este es el último elemento de la

lista.

El ifa_name apunta al nombre de la interfaz terminado en

nulo.

El campo ifa_flags contiene las banderas de la interfaz, tal como son devueltas por la operación ioctl(2) SIOCGIFFLAGS (véase netdevice(7) para una lista de estas banderas)

.

El campo ifa_addr apunta a una estructura que contiene la dirección de la interfaz. (Debería consultarse el subcampo sa_family para determinar el formato de la estructura de dirección). Este campo puede contener un puntero

nulo.

El campo ifa_netmask apunta a una estructura que contiene la máscara de red asociada a ifa_addr, si es aplicable para la familia de direcciones. Este campo puede contener un puntero

nulo.

Dependiendo de si el bit IFF_BROADCAST o IFF_POINTOPOINT está establecido en ifa_flags (solo uno puede estar establecido a la vez), ya sea ifa_broadaddr contendrá la dirección de difusión asociada a ifa_addr (si es aplicable para la familia de direcciones) o ifa_dstaddr contendrá la dirección de destino de la interfaz punto a

punto.

El campo ifa_data apunta a un búfer que contiene datos específicos de la familia de direcciones; este campo puede ser NULL si no hay tales datos para esta

interfaz.

Los datos devueltos por getifaddrs() se asignan dinámicamente y deberían liberarse usando freeifaddrs() cuando y

a no sean
necesarios.

HISTORI

A

Esta función apareció por primera vez en BSDi y está presente en los sistemas BSD, pero con semántica ligeramente diferente documentada—devolviendo una entrada por interfaz, no por dirección. Esto significa que ifa_addr y otros campos pueden ser realmente NULL si la interfaz no tiene dirección, y no se devuelve una dirección de nivel de enlace si la interfaz tiene una dirección IP asignada. Además, la forma de elegir ya sea ifa_broadaddr o ifa_dstaddr difiere en varios

sistemas.

getifaddrs() apareció por primera vez en glibc 2.3, pero antes de glibc 2.3.3, la implementación solo soportaba direcciones IPv4; el soporte I

Pv6 se añadió en glibc 2.3.3. El soporte de familias de direcciones di
stintas de IPv4 está disponible solo en kernels que soportan netlink.

NOTA

S

Las direcciones devueltas en Linux serán usualmente las direcciones IPv4 e IPv6 asignadas a la interfaz, pero también una dirección AF_PACKET por interfaz que contiene detalles de nivel inferior sobre la interfaz y su capa física. En este caso, el campo ifa_data puede contener un puntero a un struct rtnl_link_stats, definido en <linux/if_link.h> (en Linux 2.4 y anteriores, struct net_device_stats, definido en <linux/netdevice.h>), que contiene vari

os atributos y estadí
sticas de la interfaz.

#define _GNU_SOURCE     /* Para obtener las definiciones de NI_MAXSERV y NI_MAXHOST */
#include <arpa/inet.h>
#include <sys/socket.h>
#include <netdb.h>
#include <ifaddrs.h>
#include <stdio.h>
#include <stdlib.h>
#include <unistd.h>
#include <linux/if_link.h>
int main(int argc, char *argv[])
{
    struct ifaddrs *ifaddr;
    int family, s;
    char host[NI_MAXHOST];
    if (getifaddrs(&ifaddr) == -1) {
        perror("getifaddrs");
        exit(EXIT_FAILURE);
    }
    /* Recorrer la lista enlazada, manteniendo el puntero a la cabeza para poder
       liberar la lista más tarde.  */
    for (struct ifaddrs *ifa = ifaddr; ifa != NULL;
             ifa = ifa->ifa_next) {
        if (ifa->ifa_addr == NULL)
            continue;
        family = ifa->ifa_addr->sa_family;
        /* Mostrar el nombre de la interfaz y la familia (incluyendo la forma
           simbólica de esta última para las familias comunes).  */
        printf("%-8s %s (%d)\n",
               ifa->ifa_name,
               (family == AF_PACKET) ? "AF_PACKET" :
               (family == AF_INET) ? "AF_INET" :
               (family == AF_INET6) ? "AF_INET6" : "???",
               family);
        /* Para una dirección de interfaz AF_INET*, mostrar la dirección.  */
        if (family == AF_INET || family == AF_INET6) {
            s = getnameinfo(ifa->ifa_addr,
                    (family == AF_INET) ? sizeof(struct sockaddr_in) :
                                          sizeof(struct sockaddr_in6),
                    host, NI_MAXHOST,
                    NULL, 0, NI_NUMERICHOST);
            if (s != 0) {
                printf("getnameinfo() falló: %s\n", gai_strerror(s));
                exit(EXIT_FAILURE);
            }
            printf("\t\tdirección: <%s>\n", host);
        } else if (family == AF_PACKET && ifa->ifa_data != NULL) {
            struct rtnl_link_stats *stats = ifa->ifa_data;
            printf("\t\ttx_packets = %10u; rx_packets = %10u\n"
                   "\t\ttx_bytes   = %10u; rx_bytes   = %10u\n",
                   stats->tx_packets, stats->rx_packets,
                   stats->tx_bytes, stats->rx_bytes);
        }
    }
    freeifaddrs(ifaddr);
    exit(EXIT_SUCCESS)
;
}
