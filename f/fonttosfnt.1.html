FONTTOSFNT(1) Manual de comandos generales FONTTOSFNT(1)

NOMBRE

fonttosfnt - Envuelve una fuente de mapa de bits en un envoltorio sfnt (OpenType)

SINOPSIS

fonttosfnt [ opciones ] -o archivo.otb [ -- ] [ fuente ] ...

DESCRIPCIÓN

Envuelve una fuente de mapa de bits o un conjunto de fuentes de mapa de bits en un envoltorio sfnt (TrueType u OpenType). Si no se especifica ninguna fuente, se lee una fuente BDF de la entrada estándar (stdin).

OPCIONES

-v
Ser verboso.
-c
No recortar glifos. Esto generalmente aumenta el tamaño del archivo, pero a veces puede producir una modesta disminución en el tamaño del archivo para fuentes de celda de caracteres pequeñas (fuentes de terminal).
-b
Escribir datos de glifos alineados por bytes. Por defecto, se escriben datos no alineados, lo que produce un tamaño de archivo menor.
-r
No volver a codificar fuentes. Por defecto, las fuentes se vuelven a codificar a Unicode siempre que sea posible.
-g n
Establecer el tipo de glifos escalables que escribimos. Si n es 0, no se escriben glifos escalables; esto es legal pero confunde la mayoría del software actual. Si n es 1, se escribe un solo glifo escalable (el glifo no definido); esto es recomendable, pero activa un error en las versiones actuales de FreeType. Si n es 2 (el valor predeterminado), se escriben un número suficientemente alto de glifos en blanco, lo que funciona con FreeType pero aumenta el tamaño del archivo.
-m n
Establecer el tipo de métricas escalables que escribimos. Si n es 0, no se escriben métricas escalables, lo que puede ser legal o no. Si n es 1, se escriben métricas completas para un solo glifo, y solo se escriben los valores de desvío lateral izquierdo para los otros glifos. Si n es 2, se escriben métricas escalables para todos los glifos, lo que aumenta el tamaño del archivo y no se recomienda. El valor predeterminado es 1.
--
Fin de las opciones.

ERRORES

Algunos de los valores a nivel de fuente, en particular las posiciones de sub- y superíndice, son valores ficticios.

VER TAMBIÉN

X(7), Xserver(1), Xft(3). Fuentes en X11.
