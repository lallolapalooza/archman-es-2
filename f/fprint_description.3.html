MIB read_objid prend une chaîne contenant une version textuelle d'un identifiant d'objet (sous forme numérique ou descriptive), et la transforme en la liste de sous-identifiants correspondante. Celle-ci est renvoyée dans le paramètre [[177]] output, avec le nombre de sous-identifiants renvoyés via out_len. Lors de l'appel, out_len doit contenir la longueur maximale du tableau [[180]] output. Si plusieurs identifiants d'objets sont traités, cette longueur doit être réinitialisée avant chaque appel. Cette fonction renvoie une valeur de 1 si elle parvient

à

analyser la chaîne et 0 sinon. snmp_parse_oid est similaire, mais renvoie un pointeur vers

le

tampon OID analysé (ou NULL). get_module_node prend un descripteur et le nom d'un module, et renvoie la liste oid correspondante, de la même
manière que read_objid ci-dessus. Si le nom du module est spécifié comme "ANY", cette routine supposera que le descripteur donné est unique dans l'arbre, et renverra l'entrée correspondante. Si cette hypothèse est invalide, le comportement concernant la variable renvoyée dépend de l'implémentation.

VARIABLES DE ENTORNO

El uso principal de las variables de entorno con respecto a estas llamadas a la API es configurar qué módulos MIB deben cargarse y dónde se encuentran.

MIBDIRS
Una lista de directorios separada por dos puntos para buscar módulos MIB.
Por defecto: /usr/share/snmp/mibs
Usado por init_mib, netsnmp_read_module, read_all_mibs y (implícitamente) por read_mib.
MIBS
Una lista de módulos MIB separada por dos puntos para cargar.
La lista de módulos por defecto dependerá de cómo se compiló originalmente el software Net-SNMP, pero típicamente es:
IP-MIB:IF-MIB:TCP-MIB:UDP-MIB:SNMPv2-MIB:RFC1213-MIB:UCD-SNMP-MIB:HOST-RESOURCES-MIB
Si el valor de la variable de entorno MIBS comienza con el carácter '+', entonces estos módulos MIB se añadirán a la lista por defecto. De lo contrario, estos módulos (más cualquiera de los que IMPORTEN de ellos) se cargarán en lugar de la lista por defecto.
Si la variable de entorno MIBS tiene el valor ALL entonces read_all_mibs será llamada para cargar la colección completa de todos los módulos MIB disponibles.
Usado por init_mib únicamente.
MIBFILES
Una lista de archivos separada por dos puntos para cargar.
Por defecto: (ninguno)
Usado por init_mib únicamente.
