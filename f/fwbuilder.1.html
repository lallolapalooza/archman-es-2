fwbuilder(1) Firewall Builder fwbuilder(1)

NOMBRE

fwbuilder - Herramienta de configuración de firewall multiplataforma

SINOPSIS

/usr/bin/fwbuilder [-farchivo.fwb] [-d] [-h] [-oarchivo] [-Pnombre_objeto] [-r] [-v]

DESCRIPCIÓN

fwbuilder es el componente de Interfaz Gráfica de Usuario (GUI) de Firewall Builder.

Firewall Builder consiste en una GUI y un conjunto de compiladores de políticas para diversas plataformas de firewall. Ayuda a los usuarios a mantener una base de datos de objetos y permite la edición de políticas mediante operaciones sencillas de arrastrar y soltar. La GUI genera la descripción del firewall en forma de archivo XML, que los compiladores interpretan y generan código específico de la plataforma. Se proporcionan varios algoritmos para el descubrimiento automatizado de objetos de red y la importación masiva de datos. La GUI y los compiladores de políticas son completamente independientes, esto proporciona un modelo abstracto consistente y la misma GUI para diferentes plataformas de firewall.

Firewall Builder soporta firewalls basados en iptables (kernel de Linux 2.4.x y 2.6.x, véase fwb_ipt(1)), ipfilter (variedad de plataformas incluyendo *BSD, Solaris y otros, véase fwb_ipf(1)), pf (OpenBSD y FreeBSD, véase fwb_pf(1)), ipfw (FreeBSD y otros), Cisco PIX (v6.x y 7.x) y listas de control de acceso extendidas de Cisco IOS.

OPCIONES

-f ARCHIVO
Especifica el nombre del archivo que se cargará al iniciar el programa.
-r
Cuando esta opción de línea de comandos se da en combinación con -f archivo, el programa abre automáticamente la revisión principal de RCS del archivo si el archivo está en RCS. Si el archivo no está en RCS, esta opción no hace nada y el archivo se abre como de costumbre.
-d
Activa el modo de depuración. Tenga en cuenta que en este modo el programa genera mucha salida en la salida estándar de error. Esto se utiliza para la depuración.
-h
Imprime un breve mensaje de ayuda.
-o archivo
Especifica el nombre del archivo para la salida impresa, véase la opción "-P".
-P nombre_objeto
Imprime las reglas y objetos para el objeto de firewall "nombre_objeto" y sale inmediatamente. El programa no entra en modo interactivo. La salida impresa se colocará en el archivo especificado con la opción "-o". Si no se proporciona un nombre de archivo con la opción "-o", la salida impresa se almacenará en el archivo "print.pdf" en el directorio actual.
