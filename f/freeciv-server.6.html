NOMBRE

freeciv-server - El servidor para el juego Freeciv

SINOPSIS

freeciv-server [ -A|--Announce protocolo ] [ -b|--bind dirección ] [ -B|--Bind-meta dirección ] [ -d|--debug nivel ] [ -e|--exit-on-end ] [ -F|--Fatal [ número_señal ] ] [ -f|--file nombre_archivo ] [ -h|--help ] [ -i|--identity dirección ] [ -k|--keep ] [ -l|--log nombre_archivo ] [ -M|--Metaserver dirección ] [ -m|--meta ] [ -p|--port puerto ] [ -q|--quitidle tiempo ] [ -R|--Ranklog nombre_archivo ] [ -r|--read nombre_archivo ] [ -S|--Serverid id ] [ -s|--saves directorio ] [ --scenarios directorio ] [ -v|--version ]

Los servidores con soporte de autenticación tienen parámetros adicionales: [ -a|--auth ] [ -D|--Database archivo ] [ -G|--Guests ] [ -N|--Newusers ]

Los servidores con soporte de módulo IA tienen un parámetro adicional: [ -L|--LoadAI módulo ]

DESCRIPCIÓN

Freeciv es un juego de estrategia multijugador por turnos gratuito, en el que cada jugador se convierte en el líder de una civilización, luchando para obtener el objetivo final: ser la civilización más grande.

Los jugadores de Civilization II® de Microprose® se sentirán como en casa, ya que uno de los objetivos de Freeciv es tener reglas compatibles.

Freeciv es mantenido por un equipo internacional de programadores y entusiastas, ¡y es fácilmente uno de los juegos de red más divertidos y adictivos que existen!

Este es el programa del servidor utilizado para establecer un servidor de Freeciv; consulte también freeciv-client(6).

Esta página del manual solo enumera los argumentos de la línea de comandos. Para obtener detalles sobre las directivas necesarias para configurar freeciv-server, consulte el Manual del Servidor que se puede encontrar en el sitio web de Freeciv, así como la documentación que forma parte de la distribución de Freeciv.

OPCIONES

Las siguientes opciones se aceptan en la línea de comandos del servidor. No se pueden combinar; es decir, "freeciv-server -fp savegame.sav 5557" no funcionará, sino que necesitaría introducir "freeciv-server -f savegame.sav -p 5557". La mayoría de las opciones tienen una forma corta (un solo guion y una sola letra) y una forma larga (doble guion y una palabra completa); sus efectos son idénticos.

-A protocolo, --Announce protocolo
Utiliza protocolo al anunciar el juego en LAN. Valores posibles para protocolo son:

IPv4

IPv6

none

-a, --auth
Habilita la autenticación del servidor y permite el acceso solo a jugadores registrados. Requiere que se especifique la opción --Database.
-b dirección, --bind dirección
Establece la dirección en la que el servidor escuchará a los clientes.
-B dirección, --Bind-meta dirección
Establece la dirección desde la que se envían las solicitudes al metaserver. Por defecto, es la dirección dada por la opción -b.
-d nivel, --debug nivel
Establece la cantidad de información de depuración que se registrará en el archivo nombrado por la opción -l. Los valores aceptables para el nivel son:

fatal solo para mensajes fatales.

error para mensajes fatales y de error.

warning para mensajes fatales, de error y de advertencia

normal para mensajes fatales, de error, de advertencia y normales (predeterminado).

verbose para mensajes fatales, de error, de advertencia, normales y detallados.

-D nombre_archivo, --Database nombre_archivo
Especifica un archivo de configuración de base de datos para la autenticación. Este archivo especifica los detalles de la base de datos. Consulte README.fcdb en la distribución de Freeciv para obtener detalles sobre su formato.
-e, --exit-on-end
Cuando un juego termina, sale en lugar de reiniciarse.
-F [ número_señal ], --Fatal [ número_señal ]
Genera una señal personalizada en una aserción fallida. Si no se especifica número_señal, se utilizará la señal ABRT.
-f nombre_archivo, --file nombre_archivo
Carga una partida guardada (nombre_archivo) en el servidor antes de la inicialización, en lugar de iniciar una nueva partida. Esto es para recargar partidas guardadas, o para cargar escenarios. Consulte ENTORNO para saber dónde busca el servidor estos archivos.

La distribución viene con varios escenarios, típicamente almacenados en /usr/local/share/freeciv/scenarios, por ejemplo:

• british-isles-85x80-v2.80.sav

• earth-160x90-v2.sav

• earth-80x50-v3.sav

• europe-200x100-v2.sav

• hagworld-120x60-v1.2.sav

• iberian-peninsula-136x100-v1.0.sav

-G, --Guests
Permite que los invitados inicien sesión como 'guest' cuando la autenticación está habilitada.
-h, --help
Imprime una descripción de las opciones de la línea de comandos y sale.
-i dirección, --identity dirección
Informa la dirección al metaserver. Luego, el metaserver usará esta dirección para redirigir a los usuarios.
-L módulo, --LoadAI módulo
Carga el módulo de IA. Esta opción puede aparecer varias veces para cargar diferentes módulos.
-l nombre_archivo, --log nombre_archivo
Define un archivo de registro, nombre_archivo, que se producirá durante el procesamiento. Utilice la opción -d para establecer la cantidad de registro. Por defecto, los mensajes fatales, de error, de advertencia y normales se imprimen en la salida estándar. Con un archivo de registro, dichos mensajes van al registro en su lugar. Si nombre_archivo ya existe, se añade al final.
-M dirección, --Metaserver dirección
Especifica la dirección del metaserver al que se enviará la información de su servidor. Por defecto, se utilizará el metaserver estándar gestionado por los mantenedores de Freeciv.
-m, --meta
Dirige al servidor para que se comunique con un metaserver, un lugar donde los servidores de Freeciv pueden publicar su presencia. Los clientes de Freeciv consultan al metaserver para ofrecer a los usuarios una selección de juegos a los que unirse. Por defecto, se utiliza el metaserver estándar de Freeciv. Puede especificar un metaserver alternativo con la opción -M.
-k, --keep
Normalmente, el servidor de freeciv deja de enviar actualizaciones al metaserver cuando hay problemas de conexión. Con esta opción, sigue intentando enviar actualizaciones incluso después de haber fallado una vez en enviar el estado actualizado. Esta opción implica la opción -m.
-N, --Newusers
Permite que los nuevos usuarios inicien sesión y se registren en la base de datos de jugadores si la autenticación está habilitada.
-p puerto, --port puerto
Especifica el número de puerto TCP al que se conectarán los clientes; los jugadores deben conocer este número para poder conectarse si no van a utilizar el valor predeterminado de 5556 decimal. Puede que necesite usar esto si 5556 no está disponible para su uso en su sistema, o si desea ejecutar múltiples servidores en el mismo sistema.
-q tiempo, --quitidle tiempo
Sale si no hay jugadores presentes durante el tiempo especificado, en segundos, y reinicia un nuevo servidor.
-R nombre_archivo, --Ranklog nombre_archivo
Define un archivo de registro, nombre_archivo, que se producirá durante el procesamiento. Este registro contiene información para la clasificación de jugadores.
-r nombre_archivo, --read nombre_archivo
Especifica un archivo, nombre_archivo, de comandos del servidor que el servidor leerá y procesará automáticamente, como si los hubiera escrito usted mismo en la línea de comandos.
-S id, --Serverid id
Establece el identificador único del servidor a id. Por defecto, el servidor genera un ID aleatorio si no se especifica esta opción.
-s directorio, --saves directorio
Especifica un directorio donde guardar las partidas. Si no se especifica, se utiliza el directorio predeterminado (normalmente ~/.freeciv/saves).
--scenarios directorio
Especifica un directorio donde buscar escenarios. Si no se especifica, se utiliza el directorio predeterminado (normalmente /usr/local/share/freeciv/scenarios).
-v, --version
Imprime la versión del programa y sale.

AMBIENTE

El servidor busca los siguientes archivos y directorios:

$FREECIV_CONFIGDIR/freeciv-server.conf
Archivo de configuración del servidor. Si este archivo existe, se leerán las directivas de configuración desde él.
$XDG_CONFIG_HOME/freeciv/freeciv-server.conf
$HOME/.freeciv/freeciv-server.conf
SYSCONFDIR/freeciv/freeciv-server.conf
SYSCONFDIR es típicamente /etc o /etc/freeciv. Las directivas más importantes son:
auto_save
Intervalo de guardado automático en segundos.
autosave_dir
Directorio donde guardar partidas guardadas automáticamente.
default_ai_module
Módulo IA predeterminado a cargar.
default_difficulty
Nivel de dificultad predeterminado para jugadores IA.
default_scenario
Nombre del escenario predeterminado a cargar.
max_players
Número máximo de jugadores permitidos en el servidor.
players
Configuración de jugadores predeterminados (utilizado si no se carga ningún escenario).
port
Puerto TCP predeterminado.
ranklog
Archivo de registro de clasificación.
save_dir
Directorio donde guardar partidas guardadas.
scenario_dir
Directorio donde buscar escenarios.
server_identity
Identidad del servidor (nombre que aparece en la lista de servidores).
shout_command
Comando de difusión para anunciar el servidor en la red local.
shout_protocol
Protocolo de difusión (IPv4, IPv6, none).
use_meta
Habilita la comunicación con el metaserver.
verbose
Nivel de detalle de los registros.

Consulte el Manual del Servidor de Freeciv para obtener una lista completa de directivas.

S

2244
Inicia un servidor en el puerto 2244, cargando el archivo de partida guardada oldgame.
sav.

2244
Inicia un servidor en el puerto 2244, cargando el archivo de partida guardada oldgame.sav.gz. Los eventos relacionados con la clasificación se escriben en ranklog, otra información de registro se escribe en logfile. Cuando el servidor inicia, ejecuta inmediatamente los comandos contenidos en scrip
t.
freeciv-server -m -a -D fc_auth.conf -q 60 -p 2244 -d normal -l logfile -r script -s
~/saves
Inicia un servidor en el puerto 2244 con autenticación habilitada y comunica su existencia al metaservidor estándar de Freeciv. Los mensajes fatales, de error, de advertencia y normales se escriben en logfile. Cuando el servidor inicia, ejecuta inmediatamente los comandos contenidos en script. Los archivos de partidas guardadas se almacenan en el directorio ~/saves. Cuando no hay usuarios en el servidor durante 60 segundos, el se
