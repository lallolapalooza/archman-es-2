fpclassify(3) Manual de funciones de biblioteca fpclassify(3)

NOMBRE

fpclassify, isfinite, isnormal, isnan, isinf - macros de clasificación de punto flotante

BIBLIOTECA

Biblioteca matemática (libm, -lm)

SINOPSIS

#include <math.h>
int fpclassify(x);
int isfinite(x);
int isnormal(x);
int isnan(x);
int isinf(x);
Requisitos de macro de prueba de características para glibc (ver feature_test_macros(7)):

fpclassify(), isfinite(), isnormal():

    _ISOC99_SOURCE || _POSIX_C_SOURCE >= 200112L

isnan():

    _ISOC99_SOURCE || _POSIX_C_SOURCE >= 200112L
        || _XOPEN_SOURCE
        || /* Desde glibc 2.19: */ _DEFAULT_SOURCE
        || /* glibc <= 2.19: */ _BSD_SOURCE || _SVID_SOURCE

isinf():

    _ISOC99_SOURCE || _POSIX_C_SOURCE >= 200112L
        || /* Desde glibc 2.19: */ _DEFAULT_SOURCE
        || /* glibc <= 2.19: */ _BSD_SOURCE || _SVID_SOURCE

DESCRIPCIÓN

Los números de punto flotante pueden tener valores especiales, como infinito o NaN. Con la macro fpclassify(x) puede averiguar qué tipo es x. La macro toma cualquier expresión de punto flotante como argumento. El resultado es uno de los siguientes valores:

FP_NAN
x es "No es un número" (Not a Number).
FP_INFINITE
x es infinito positivo o infinito negativo.
FP_ZERO
x es cero.
FP_SUBNORMAL
x es demasiado pequeño para ser representado en formato normalizado.
FP_NORMAL
si nada de lo anterior es correcto, entonces debe ser un número de punto flotante normal.

Las otras macros proporcionan una respuesta corta a algunas preguntas estándar.

(isfinite(x)
devuelve un valor distinto de cero si
(fpclassify(x) != FP_NAN && fpclassify(x) != FP_INFINITE)
(isnormal(x)
devuelve un valor distinto de cero si (fpclassify(x) == FP_NORMAL)
(isnan(x)
devuelve un valor distinto de cero si (fpclassify(x) == FP_NAN)
(isinf(x)
devuelve 1 si x es infinito positivo y -1 si x es infinito negativo.

ATRIBUTOS

Para una explicación de los términos utilizados en esta sección, ver attributes(7).

Interfaz Atributo Valor
fpclassify (), isfinite (), isnormal (), isnan (), isinf () Seguridad de hilos MT-Safe

ESTÁNDARES

C11, POSIX.1-2008.

HISTORIA

POSIX.1-2001, C99.

En glibc 2.01 y anteriores, isinf() devuelve un valor distinto de cero (de hecho: 1) si x es infinito positivo o infinito negativo. (Esto es todo lo que C99 requiere).

NOTAS

Para isinf(), los estándares simplemente dicen que el valor de retorno es distinto de cero si y solo si el argumento tiene un valor infinito.

VER TAMBIÉN

finite(3), INFINITY(3), isgreater(3), signbit(3)
