FOOMATIC-PERL-DATA(1) Manual de Comandos Generales FOOMATIC-PERL-DATA(1)

NOMBRE

foomatic-perl-data - genera estructuras de datos Perl a partir de XML

SINOPSIS

foomatic-perl-data [ -O ] [ -C ] [ -P ] [ -D ] [ -o option=setting ] [ -o ... ] [ -v ] [ nombre_archivo ]

Opciones

-O Analiza datos XML de resumen

-C Analiza datos XML de combinación impresora/controlador (por defecto)

-P Analiza datos de entrada de impresora

-D Analiza datos de entrada de controlador

-o option=setting Configuraciones de opción por defecto para los datos Perl generados (solo combinación)

-v Modo detallado (depuración)

nombre_archivo Lee la entrada de un archivo y no de la entrada estándar

ESTADO DE SALIDA

foomatic-perl-data retorna ...
