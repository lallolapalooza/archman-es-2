DESCRIPCIÓ

N

El comando tk fontchooser controla el diálogo de selección de fuentes de Tk. Utiliza el diálogo de selección de fuentes nativo de la plataforma cuando está disponible, o un diálogo implementado en Tcl en caso

contrario.

A diferencia de la mayoría de los otros comandos de diálogo de Tk, tk fontchooser no devuelve un resultado inmediato, ya que en algunas plataformas (macOS) el diálogo de fuentes estándar es no modal, mientras que en otras (Windows) es modal. Para acomodar esta diferencia, toda la interacción del usuario con el diálogo se comunicará al llamador mediante callbacks o eventos

virtuales.

El comando tk fontchooser puede tener una de las siguientes

formas:
tk fontchooser configure ?-option valu

Tk).

NOTAS Los llamadores no deben esperar un resultado de tk fontchooser show y no pueden asumir que el diálogo ha sido retirado o cerrado cuando el comando retorna. Toda la interacción del usuario con el diálogo se comunica al llamador mediante el callback -command y los eventos virtuales <<TkFontchooser*>>. Es dependiente de la implementación qué acciones exactas del usuario resultan en la invocación del callback o el envío de los eventos virtuales. Donde hay un botón Aplicar o OK presente en el diálogo, ese botón desencadenará el callback -command y

el

evento virtual <<TkFontchooserFontChanged>>. En algunas implementaciones otras acciones del usuario también pueden tener ese efecto; en macOS, por ejemplo, el diálogo de selección de fuentes estándar refleja inmediatamente todas las elecciones del usuario al llamador. En presencia de múltiples widgets destinados a ser influenciados por el diálogo de selección de fuentes, se debe tener cuidado para manejar correctamente los cambios de foco: la fuente seleccionada en el diálogo siempre debe coincidir con la fuente actual del widget con el foco, y el callback -command solo debe actuar sobre el widget con el foco. La práctica recomendada es establecer las opciones de configuración -font y -command del diálogo de fuentes en manejadores <FocusIn> por widget (y si es necesario desestablecerlas - es decir, establecerlas a la cadena vacía - en los correspondiente

s

manejadores <FocusOut>). Esto es particularmente importante para los implementadores de código de biblioteca que usan el diálogo de selección de fuentes, para evitar conflictos con código de aplicación que también pueda querer usar el diálogo. Debido a que el diálogo de selección de fuentes es global a la aplicación, en presencia de múltiples intérpretes llamando a tk fontchooser, solo el callback -command establecido por el intérprete que llamó más recientemente a tk fontchooser configure o tk fontchooser show será invocado en respuesta a la acción del usuario y solo el -parent establecido por ese intérprete

recibirá

eventos virtuales <<TkFontchooser*>>. La implementación del diálogo de fuentes puede solo almacenar (y devolver) datos de fuente actual como el valor de la opción de configuración -font. Esto puede ser un problema cuando -font es establecido a una fuente con nombre, si esa fuente es posteriormente cambiada, la opción -font del diálogo de fuentes necesita ser establecida de nuevo para asegurar q

ue su fuente seleccionada coincida con
el nuevo valor de la fuente con nombre.

EJEMPL

O 
proc fontchooserDemo {} {
    wm title . "Font Chooser Demo"
    tk fontchooser configure -parent .
    button .b -command fontchooserToggle -takefocus 0
    fontchooserVisibility .b
    bind . <<TkFontchooserVisibility>> \
            [list fontchooserVisibility .b]
    foreach w {.t1 .t2} {
        text $w -width 20 -height 4 -borderwidth 1 -relief solid
        bind $w <FocusIn> [list fontchooserFocus $w]
        $w insert end "Text Widget $w"
    }
    .t1 configure -font {Courier 14}
    .t2 configure -font {Times 16}
    pack .b .t1 .t2; focus .t1
}
proc fontchooserToggle {} {
    tk fontchooser [expr {
            [tk fontchooser configure -visible] ?
            "hide" : "show"}]
}
proc fontchooserVisibility {w} {
    $w configure -text [expr {
            [tk fontchooser configure -visible] ?
            "Hide Font Dialog" : "Show Font Dialog"}]
}
