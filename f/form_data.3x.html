NOMBRE

data_ahead, data_behind - probar datos fuera de pantalla en formularios dados

SINOPSIS

#include <form.h>
bool data_ahead(const FORM *form);
bool data_behind(const FORM *form);

DESCRIPCIÓN

La función data_ahead prueba si hay datos fuera de pantalla adelante en el formulario dado. Devuelve TRUE (1) o FALSE (0).

La función data_behind prueba si hay datos fuera de pantalla detrás en el formulario dado. Devuelve TRUE (1) o FALSE (0).

PORTABILIDAD

Estas rutinas emulan la biblioteca de formularios System V. No eran compatibles con las versiones 7 o BSD.
