NOMBRE

form_field_buffer - control de búfer de campo

SINOPSIS

#include <form.h>
int set_field_buffer(FIELD *field, int buf, const char *value);
char *field_buffer(const FIELD *field, int buffer);
int set_field_status(FIELD *field, bool status);
bool field_status(const FIELD *field);
int set_max_field(FIELD *field, int max);

DESCRIPCIÓN

La función set_field_buffer establece el búfer numerado del campo dado para que contenga una cadena dada:

  • El búfer 0 es el valor mostrado del campo.
  • Otros búferes numerados pueden ser asignados por las aplicaciones a través del argumento nbuf de (ver form_field_new(3X)) pero no son manipulados por la biblioteca de formularios.

La función field_buffer devuelve un puntero al contenido del búfer numerado dado:

  • El contenido del búfer siempre tiene la misma longitud y se rellena con espacios finales según sea necesario para asegurar que esta longitud sea la misma.
  • El búfer puede contener espacios iniciales, dependiendo de cómo se estableció.
  • El contenido del búfer se establece con set_field_buffer, o como efecto secundario de cualquier operación de edición en el campo correspondiente.
  • Las operaciones de edición se basan en la ventana que muestra el campo, en lugar de una cadena. La ventana solo contiene caracteres imprimibles y se rellena con espacios en blanco. Si desea los datos sin procesar, debe escribir su propia rutina que copie el valor del búfer y elimine los espacios iniciales y finales.
  • Debido a que las operaciones de edición cambian el contenido del búfer para que corresponda a la ventana, no debe confiar en el uso de búferes para el almacenamiento a largo plazo de los datos del formulario.

La función set_field_status establece la bandera de estado asociada del campo; field_status obtiene el valor actual. La bandera de estado se establece a un valor distinto de cero cada vez que el campo cambia.

La función set_max_field establece el tamaño máximo para un campo dinámico. Un argumento de 0 desactiva cualquier umbral de tamaño máximo para ese campo.

VALOR DE RETORNO

La función field_buffer devuelve NULL en caso de error. Establece errno según su éxito:

E_OK
La rutina tuvo éxito.
E_BAD_ARGUMENT
La rutina detectó un argumento incorrecto o fuera de rango.

La función field_status devuelve TRUE o FALSE.

Las rutinas restantes devuelven uno de los siguientes:

E_OK
La rutina tuvo éxito.
E_SYSTEM_ERROR
Ocurrió un error del sistema (ver errno(3)).
E_BAD_ARGUMENT
La rutina detectó un argumento incorrecto o fuera de rango.

NOTAS

Cuando se configura para caracteres anchos, field_buffer devuelve un puntero a almacenamiento temporal (asignado y liberado por la biblioteca). La aplicación no debe intentar modificar los datos. Se liberará en la próxima llamada a field_buffer para devolver el mismo búfer.

PORTABILIDAD

Estas rutinas emulan la biblioteca de formularios de System V. No fueron compatibles con las versiones 7 o BSD.

La función set_max_field verifica una extensión de ncurses O_INPUT_FIELD que permite que un campo dinámico se reduzca si el nuevo límite es menor que el tamaño actual del campo.
