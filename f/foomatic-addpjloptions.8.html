FOOMATIC-ADDPJLOPTIONS(8) Manual del Administrador del Sistema FOOMATIC-ADDPJLOPTIONS(8)

NOMBRE

foomatic-addpjloptions - Formatea la información de opciones PJL para la base de datos de Foomatic

SINOPSIS

foomatic-addpjloptions [-dafis][-o dir] -p printer_ID [archivo_info_pjl]

foomatic-addpjloptions [-dafq] [archivo_info_pjl]

foomatic-addpjloptions -h

DESCRIPCIÓN

foomatic-addpjloptions formatea el archivo de información PJL (o STDIN) en un formato utilizable por la base de datos de Foomatic.

Opciones

-a
Convierte todas las opciones PJL en el archivo de información.
-d
Habilita la información de depuración.
-f
No pida permiso, fuerce la conversión.
-h
Imprime un mensaje de ayuda y sale.
-q
Imprime un resumen de la información PJL. Esta salida no es compatible con la base de datos de foomatic y es útil para depuración.
-s
Produce un único archivo de opciones que contiene todos los valores de las opciones.
-o dir
El directorio donde se escriben los archivos de información de opciones.
-p printer_ID
Nombre de la impresora en la base de datos de foomatic. Se utiliza para extraer información del fabricante y modelo de la impresora.
archivo_info_pjl
Archivo con información PJL devuelta por la impresora. Si no se proporciona este nombre de archivo, las opciones PJL se toman de la entrada estándar.

ARCHIVOS

/usr/share/foomatic/templates/pjl*.xml
Archivos de plantilla para la información de opciones.
./foomatic-db/opts
Información de opciones almacenada en este directorio.

ESTADO DE SALIDA

foomatic-addpjloptions devuelve 0 en caso de éxito y un valor distinto de cero en caso de fallo.
