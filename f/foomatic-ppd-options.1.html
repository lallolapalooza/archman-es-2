NOMBRE

foomatic-ppd-options - mostrar las opciones de PPD

SINOPSIS

foomatic-ppd-options [-d=nivel_depuracion] [ archivos_ppd ]

DESCRIPCIÓN

El programa foomatic-ppd-options lee los archivos PPD especificados o la entrada estándar y decodifica el archivo PPD para producir una lista de opciones. Esto es realmente solo una versión basada en texto de otras herramientas de configuración de impresión.

El formato de salida consiste en un conjunto de líneas, cada una comenzando con una palabra clave, seguida de un conjunto de opciones y el valor predeterminado. Por ejemplo:

makemodel = Tektronix Phaser 350 Foomatic/Postscript (recomendado)
name=PageSize; default=Letter; options=Letter (US Letter), \
    A4 (A4), 11x17 (11x17), A3 (A3), A5 (A5), B5 (B5 \(JIS\)),...
name=PageRegion; default=Letter; options=Letter (US Letter), A4 (A4), ...

Cada opción comienza con la etiqueta name, seguida de un valor predeterminado (si lo hay), seguido del conjunto de opciones y un comentario que las describe. La puntuación en el comentario se escapa.

Opciones

-dnivel_depuracion
Establece el nivel de depuración. 0 deshabilita los mensajes de depuración.
[ archivos ]
La lista de archivos PPD para leer las opciones. Un '-' hace que se lea STDIN.

ESTADO DE SALIDA

foomatic-ppd-options sale con un estado 0 si tiene éxito, y un valor distinto de cero si hay un error. También se imprime un mensaje de error en el error estándar (STDERR).
