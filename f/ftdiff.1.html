NOMBRE

ftdiff - compara modos de insinuación de fuentes

SINOPSIS

ftdiff [opciones] fuente ...

DESCRIPCIÓN

ftdiff muestra texto en tres columnas, utilizando la(s) fuente(s) proporcionada(s) en la línea de comandos, y aplica diferentes modos de insinuación de FreeType a cada columna.

fuente
Los archivos de fuente a mostrar. Para los archivos de fuente Type 1, ftdiff también intenta adjuntar el archivo de métricas correspondiente (con extensión `.afm' o `.pfm').

Este programa forma parte del paquete de demostración de FreeType.

OPCIONES

-d WxH
Establece el ancho de la ventana a W px, la altura a H px (predeterminado: 640 x 480).
-r r
Utiliza una resolución de r dpi (predeterminado: 72 dpi).
-s s
Establece el tamaño del carácter a s puntos (predeterminado: 16pt).
-f archivo_texto
Cambia el texto mostrado, utilizando el texto en archivo_texto (en codificación UTF-8).
-v
Muestra la versión.
