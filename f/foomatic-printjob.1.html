FOOMATIC-PRINTJOB(1) Manual de Comandos Generales FOOMATIC-PRINTJOB(1)

NOMBRE

foomatic-printjob - gestiona trabajos de impresión de forma independiente del spooler

SINOPSIS

foomatic-printjob [ -s spooler ] [ -P nombrecola ] [ -o opcion1=valor1 -o opcion2 ... ] [ -i ] [ archivo1 archivo2 ... ]

foomatic-printjob -Q [ -s spooler ] [ -P nombrecola ] [ -i ] [ -a ] [ usuario1 usuario2 ... ]

foomatic-printjob -R [ -s spooler ] [ -P nombrecola ] [ -i ] [ - | jobid1 jobid2 ... ]

foomatic-printjob -C [ -s spooler ] [ -i ] comando [ argumentos ]

foomatic-printjob -S [ -s spooler ] [ -i ]

foomatic-printjob -h [ -s spooler ] [ -P nombrecola ] [ -i ]

DESCRIPCIÓN

foomatic-printjob proporciona una interfaz independiente del spooler para crear y gestionar trabajos de impresión y colas de impresión. Tenga en cuenta que el primer argumento cambia el modo del comando, ya que combina la funcionalidad de varios comandos de impresión al estilo System V.

OPCIONES

-sspooler
Tipo de spooler explícito.
-Pnombrecola
Cualquier comando especificado se aplicará a esta cola en lugar de la predeterminada.
-oopcion=valor
Establece la opción a valor.
-oopcion
Establece la opción de interruptor.
-#n
Imprime n copias.
archivo1  archivo2  ...
Archivos a imprimir. Cuando no se proporciona ningún archivo, se imprimirá la entrada estándar.
-Q
Consulta los trabajos en una cola. Si se especifica una lista de usuarios, solo se consultarán los trabajos de esos usuarios.
-Q -a
Consulta los trabajos en todas las colas. Si se especifica una lista de usuarios, solo se consultarán los trabajos de esos usuarios.
-R [ - | jobid1 jobid2 ... ]
Elimina un trabajo de una cola. Usar - eliminará todos los trabajos.
-C comando [ argumentos ]
Ejecuta comandos de control para la manipulación de colas/trabajos. Los comandos son los de la utilidad "lpc" de BSD. Utilice el comando de control "help" para obtener una lista de comandos compatibles. Nota: la cantidad de comandos varía según el spooler, pero los mismos comandos dados bajo diferentes spoolers hacen lo mismo.
-i
Modo interactivo: se le preguntará si foomatic-printjob tiene alguna duda sobre algo. De lo contrario, foomatic-printjob utiliza la autodetección o sale con un error.
-S
Guarda el spooler elegido como spooler predeterminado.
-h
Muestra este mensaje o muestra una lista de opciones disponibles si se especifica una cola.

VER TAMBIÉN

foomatic-configure(1) y la documentación de su spooler de impresión.
