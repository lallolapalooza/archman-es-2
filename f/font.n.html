N

El comando font proporciona varias utilidades para tratar con fuentes, como definir fuentes con nombre e inspeccionar los atributos reales de una fuente. El comando tiene varias formas diferentes, determinadas por el primer argumento. Actualmente se admiten las siguientes

formas:
font actual font ?-displayof ventana? ?opción? ?--? ?caráct
er?
Devuelve información sobre los atributos reales que se obtienen cuando font se usa en la pantalla de la ventana; los atributos reales obtenidos pueden diferir de los atributos solicitados debido a limitaciones dependientes de la plataforma, como la disponibilidad de familias de fuentes y tamaños en puntos. font es una descripción de fuente; véase DESCRIPCIONES DE FUENTES más abajo. Si el argumento ventana se omite, por defecto es la ventana principal. Si se especifica opción, devuelve el valor de ese atributo; si se omite, el valor de retorno es una lista de todos los atributos y sus valores. Véase OPCIONES DE FUENTES más abajo para una lista de los posibles atributos. Si se proporciona el argumento carácter, debe ser un solo carácter. Los atributos de fuente devueltos serán los de la fuente específica utilizada para renderizar ese carácter, que será diferente de la fuente base si la fuente base no contiene el carácter dado. Si carácter puede ser un guion, debe ir precedido por -- para distinguirlo de una opción mal escrita .
font configure nombredefuente ?opción? ?valor opción valor .
..?
Consulta o modifica los atributos deseados para la fuente con nombre llamada nombredefuente. Si no se especifica ninguna opción, devuelve una lista que describe todas las opciones y sus valores para nombredefuente. Si se especifica una sola opción sin valor, entonces devuelve el valor actual de ese atributo. Si se especifican uno o más paresopción-valor , entonces el comando modifica la fuente con nombre dada para que tenga los valores dados; en este caso, todos los widgets que usen esa fuente se redibujarán a sí mismos usando los nuevos atributos de la fuente. Puede haber cualquier número de paresopción-valor , que proporcionan los atributos deseados para la nueva fuente con nombre. Véase OPCIONES DE FUENTES más abajo para una lista de los posibles

DESCRIPCIONES DE

FUENTES

Se aceptan los siguientes formatos como descripción de fuente en cualquier lugar donde font se especifique como argumento más arriba; estas mismas formas también se permiten al especificar la opción -font para

widgets.
[1] nombredefu
ente
El nombre de una fuente con nombre, creada usando el comando font create. Cuando un widget usa una fuente con nombre, se garantiza que esto nunca causará un error, siempre que la fuente con nombre exista, sin importar qué conjunto potencialmente inválido o sin sentido de atributos tenga la fuente con nombre. Si la fuente con nombre no se puede mostrar con exactamente los atributos especificados, se sustituirá automáticamente por alguna otra fuente
cercana.
[2] fuente del
sistema
El nombre específico de la plataforma de una fuente, interpretado por el servidor gráfico. Esto también incluye, bajo X, un XLFD (véase [4]) para el que se usó un solo carácter “*” para omitir más de un campo en medio del nombre. Véase FUENTES ESPECÍFICAS DE LA PLATAFORMA para una lista de las fuentes del
sistema.
[3] familia ?tamaño? ?estilo? ?estilo
...?
Una lista correctamente formada cuyo primer elemento es la familia de fuente deseada y cuyo segundo elemento opcional es el tamaño deseado. La interpretación del atributo tamaño sigue las mismas reglas descritas para -size en OPCIONES DE FUENTES más abajo. Cualquier argumento opcional adicional que siga al tamaño son estilos de fuente. Los posibles valores para los argumentos estilo son los
sig
uientes: 
normal	negrita	romana	cursiva
subrayado	ta
ch
a
do
[4] Nombres de fuentes X
(XLFD)
Un nombre de fuente centrado en Unix de la forma -fundición-familia-peso-inclinación-anchura-estilo-píxel-punto-resx-resy-espaciado-ancho-juego de caracteres-codificación. El carácter “*” puede usarse para omitir campos individuales que al usuario no le interesen. Debe haber exactamente un “*” por cada campo omitido, excepto que un “*” al final del XLFD omite cualquier campo restante; el XLFD válido más corto es simplemente “*”, que significa todos los campos como valores por defecto. Cualquier campo que se haya omitido recibe valores por defecto. Por compatibilidad, un XLFD siempre elige una fuente del tamaño de píxel especificado (no el tamaño en puntos); aunque esta interpretación no es estrictamente correcta, todas las aplicaciones existentes que usan XLFD asumían que un “punto” era de hecho un píxel y se mostrarían incorrectamente (generalmente más grandes) si se usara realmente la fuente del tamaño
correcto.
[5] opción valor ?opción valo
r ...?
Una lista correctamente formada de paresopción-valor que especifican los atributos deseados de la fuente, en el mismo formato usado al definir una fuente con nombre; véase OPCIONES DE FUE
NTES má
s abajo.

Cuando se usa la descripción de fuente font, el sistema intenta analizar la descripción según cada una de las cinco reglas anteriores, en el ordenespecificado. Los casos [1] y [2] deben coincidir con el nombre de una fuente con nombre existente o de una fuente del sistema. Los casos [3], [4] y [5] se aceptan en todas las platafo

rmas y se utilizará la fuente disponible más cercana. En algunas situaciones puede no ser posible encontrar ninguna fuente cercana (por ejemplo, si la familia de fuentes era un valor
basura); en ese caso, se elige una fuente predeterminada dependiente del sistema. Si la descripción de la fuente no coincide con ninguno de los patrones anteriores, se genera un error.

MÉTRICAS DE

FUENTES

Las siguientes opciones son utilizadas por el comando font metrics para consultar datos específicos de la fuente determinados cuando se creó la fuente. Estas propiedades son para la fuente en sí misma y no para los caracteres individuales dibujados en esa fuente. En las siguientes definiciones, la “línea base” de una fuente es la línea horizontal donde la parte inferior de la mayoría de las letras se alinean; ciertas letras, como la “g” minúscula, sobresalen por debajo de la línea

base.
-asce
nt
La cantidad en píxeles que la letra más alta sobresale por encima de la línea base de la fuente, más cualquier espacio en blanco extra añadido por el diseñador de la
fuente.
-desce
nt
La mayor cantidad en píxeles que cualquier letra sobresale por debajo de la línea base de la fuente, más cualquier espacio en blanco extra añadido por el diseñador de la
fuente.
-linespa
ce
Devuelve qué tan separadas verticalmente en píxeles deben colocarse dos líneas de texto que usan la misma fuente para que ninguno de los caracteres de una línea se superponga a ninguno de los caracteres de la otra línea. Generalmente, esto es la suma de la altura sobre la línea base más la profundidad por debajo de la línea
base.
-fix
ed
Devuelve un indicador booleano que es “1” si esta es una fuente de ancho fijo, donde cada carácter normal tiene el mismo ancho que todos los demás caracteres, o es “0” si esta es una fuente de espaciado proporcional, donde los caracteres individuales tienen diferente
s anchos. Los anchos de los caracteres de control,
los caracteres de tabulación y otros caracteres no
imprimibles no se incluyen al calcular este valor.

OPCIONES DE

FUENTES

Las siguientes opciones se admiten en todas las plataformas y se utilizan al construir una fuente con nombre o al especificar una fuente usando el estilo [5] como se indicó

anteriormente:
-family nom
bre
El nombre de la familia de fuentes, sin distinguir mayúsculas de minúsculas. Tk garantiza admitir las familias de fuentes llamadas Courier (una fuente de “máquina de escribir” monoespaciada), Times (una fuente de “periódico” con serifa), y Helvetica (una fuente “europea” sin serifa). La familia de fuentes nativa que más se acople se sustituirá automáticamente cuando se use una de las familias de fuentes anteriores. El nombre también puede ser el nombre de una familia de fuentes nativa específica de la plataforma; en ese caso, funcionará como se desea en una plataforma pero puede no mostrarse correctamente en otras plataformas. Si la familia no está especificada o no se reconoce, se elegirá una fuente predeterminada específica de la
plataforma.
-size tam
año
El tamaño deseado de la fuente. Si el argumento tamaño es un número positivo, se interpreta como un tamaño en puntos. Si tamaño es un número negativo, su valor absoluto se interpreta como un tamaño en píxeles. Si una fuente no se puede mostrar en el tamaño especificado, se elegirá un tamaño cercano. Si tamaño no está especificado o es cero, se elegirá un
tamaño predeterminado dep
endiente de la plataforma.

Los tamaños normalmente deben especificarse en puntos para que la aplicación mantenga el mismo tamaño en la pantalla, incluso al cambiar las resoluciones de pantalla o al mover scripts entre plataformas. Sin embargo, especificar en píxeles es útil en ciertas circunstancias, como cuando un texto debe alinearse con respecto a un mapa de bits de tamaño fijo. La correspondencia entre puntos y píxeles se establece cuando la aplicación se inicia, basándose en las propiedades del monitor instalado, pero se puede anular llamando al comando tk

sca
ling.
-weight pes
o
El grosor nominal de los caracteres en la fuente. El valor normal especifica una fuente de peso normal, mientras que bold especifica una fuente en negrita. Se elegirá el peso disponible más cercano al especificado. El peso predeterminado es norma
l.
-slant inclina
ción
La cantidad que los caracteres en la fuente están inclinados desde la vertical. Los valores válidos para la inclinación son roman y italic. Una fuente roman es la apariencia normal y vertical de una fuente, mientras que una fuente italic está inclinada un cierto número de grados desde la vertical. Se elegirá la inclinación disponible más cercana a la especificada. La inclinación predeterminada es roma
n.
-underline boolea
no
El valor es un indicador booleano que especifica si los caracteres en esta fuente deben subrayarse. El valor predeterminado para subrayado es fals
e.
-overstrike boolea
no
El valor es un indicador booleano que especifica si debe dibujarse una línea horizontal a través del medio de los caracteres en esta fuente. El valor predeterminado para el tachado es fa
ls
e
.

EJEMPL

O

Llene un widget de texto con muchos demostradores de fuentes, uno para cada familia de fuentes instalada en su

sistema: 
pack [text .t -wrap none] -fill both -expand 1
set count 0
set tabwidth 0
foreach family [lsort -dictionary [font families]] {
    .t tag configure f[incr count] -font [list $family 10]
    .t insert end ${family}:\t {} \
            "This is a simple sampler\n" f$count
    set w [font measure [.t cget -font] ${family}:]
    if {$w + 5 > $tabwidth} {
        set tabwidth [expr {$w + 5}]
        .t configure -tabs $tabwidth
}
}
