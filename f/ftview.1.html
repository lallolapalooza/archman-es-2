FTVIEW(1) Manual de comandos generales FTVIEW(1)

NOMBRE

ftview - visor simple de glifos

SINOPSIS

ftview [opciones] [pt] fuente ...

DESCRIPCIÓN

ftview muestra todos los glifos de una fuente, permitiendo cambios interactivos de varios parámetros de renderizado y hinting.

pt
El tamaño en puntos para la resolución dada. Si la resolución es 72dpi, esto da directamente el valor ppem (píxeles por EM).
fuente
Los archivos de fuente a mostrar. Para archivos de fuentes Tipo 1, ftview también intenta adjuntar el archivo de métricas correspondiente (con extensión `.afm' o `.pfm').

Este programa forma parte del paquete de demostraciones de FreeType.

OPCIONES

-d AxAL[xP]
Establece el ancho de la ventana a A px, la altura a AL px, y opcionalmente la profundidad a P bpp (por defecto: 640x480x24).
-r r
Usa una resolución de r dpi (por defecto: 72dpi).
-f índice
Especifica el índice inicial a mostrar (por defecto: 0).
-e codificación
Especifica la etiqueta de codificación (por defecto: sin codificación). Valores comunes: unic (Unicode), symb (símbolo), ADOB (estándar de Adobe), ADBC (personalizado de Adobe), o un índice numérico de mapa de caracteres.
-m texto
Usa texto para el renderizado.
-l modo
Establece el modo de renderizado de inicio (0 <= modo <= 6). Esto corresponde a las pulsaciones de teclas 'A' a 'G' dentro del programa.
-L A1,A2,V1,V2,V3,V4
-L Rx,Ry,Gx,Gy,Bx,By
Dependiendo del método de renderizado subpíxel implementado y el número de argumentos proporcionados, establece ya sea cinco pesos de filtro LCD o seis coordenadas subpíxel (como se especifica en las funciones FT_Library_SetLcdFilterWeights o FT_Library_SetLcdGeometry respectivamente).
-k teclas
Emula una secuencia de pulsaciones de teclas al inicio. Si las pulsaciones de teclas contienen 'q', el programa opera en modo batch. Las teclas de función Fx se mapean a códigos de caracteres 0xFx; como ejemplo, -k $'\xF3q' es la tecla de función 'F3' seguida del carácter 'q'.
-p
Precarga el archivo en memoria para simular el mapeo de memoria.
-v
Muestra la versión.
