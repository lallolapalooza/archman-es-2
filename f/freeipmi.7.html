Sin embargo, la mayoría de las veces, el BMC debe configurarse en banda antes de que se pueda permitir el acceso fuera de banda (por ejemplo, se deben configurar la dirección IP y la dirección MAC

Para conectarse de forma remota a una máquina, normalmente debe especificar el host, el nombre de usuario y la contraseña para la herramienta a fin de conectarse. Dependiendo de la configuración, puede ser necesario especificar una clave K_g, un nivel de privilegio, un tipo de autenticación, un identificador de suite de cifrado o una versión de protocolo. Algunos proveedores pueden no haber implementado IPMI correctamente y debe especificarse una solución alternativa en FreeIPMI para garantizar que la herramienta pueda ejecutarse correctamente. Por ejemplo, una cantidad considerable de proveedores han poblado sus registros FRU con sumas de verificación no válidas. Para ignorar correctamente este conjunto de sumas de verificación, se ha añadido una solución alternativa skipchecks a ipmi-fru(8). Por favor, consulte la página del manual de cada herramienta para ver una lista de las soluciones alternativas disponibles. Herramientas del

Las siguientes herramientas son distribuidas y soportadas por

FreeIPMI.

bmc-inf

o

Una herramienta para leer información sobre un BMC, como números de versión del dispositivo, soporte del dispositivo e identificadores únicos globales (guids)

.

bmc-watchdo

g

Una herramienta/demonio para gestionar un watchdog de BMC. Esta herramienta se utiliza normalmente para la gestión de tiempos de espera del sistema y reinicios automáticos del sistema en caso de un fallo del

ipmi-chassi

Una herramienta para gestionar/monitorear un chasis, como la energía del chasis, la identificación (es decir, control de LED) y el

ipmi-fr

ipmi-se

Una herramienta para leer y gestionar los registros del Registro de Eventos del Sistema (SEL) de IPMI. Los registros SEL almacenan información de eventos del sistema y pueden ser útiles para depurar

problemas.

ipmi-sensor

s

Una herramienta para leer las lecturas de los sensores IPMI y la información del repositorio de datos de sensores (SDR)

.

ipmipowe

r

energía.

ipmiconsol

e

Una herramienta para el acceso a la consola Serial-over-Lan (SOL)

.

ipmi-confi

g

Una herramienta para configurar la información del BMC e IPMI. Se puede usar para configurar nombres de usuario, contraseñas, información de red, seguridad, Serial-over-LAN (SOL), filtrado de eventos de plataforma (PEF), dispositivos de arranque, política de restauración de energía, umbrales de sensores, eventos de sensores y muchas más opciones de

configuración.

ipmi-ra

w

Una herramienta que proporciona entrada/salida hexadecimal de comandos

ipmi-locat

Una herramienta para ejecutar comandos de extensión IPMI de la Interfaz de Administrabilidad del Centro de Datos (DCMI). Admite extensiones para la gestión de activos y la gestión del uso de

Bibliotecas del proyecto

Las siguientes bibliotecas son distribuidas y mantenidas por FreeIPMI.

libfreeipmi

Una biblioteca C que incluye controladores KCS, SSIF y OpenIPMI para Linux y Solaris, interfaces de comunicación IPMI 1.5 e IPMI 2.0 LAN, utilidades de construcción de paquetes IPMI, utilidades de comandos IPMI y utilidades para leer/interpretar/gestionar IPMI. Esta biblioteca está destinada a programadores íntimamente familiarizados con el protocolo IPMI y la especificación IPMI. La mayoría de los usuarios pueden preferir usar las bibliotecas listadas a continuación.

libipmiconsole

Una biblioteca para el acceso a la consola Serial-over-Lan (SOL). El acceso a la consola SOL está abstraído en una interfaz de descriptor de archivo, de modo que los usuarios pueden leer y escribir datos de la consola a través de un descriptor de archivo.

libipmimonitoring

Una biblioteca para el monitoreo de sensores y del registro de eventos del sistema (SEL) que abstrae la mayoría de los detalles de IPMI. La interpretación de esos sensores y eventos está abstraída en una API con una interfaz de iterador.

libipmidetect

Una biblioteca para la detección de nodos IPMI.
