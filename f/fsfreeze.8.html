FSFREEZE(8) Administración del Sistema FSFREEZE(8)

NOMBRE

fsfreeze - suspende el acceso a un sistema de archivos (Ext3/4, ReiserFS, JFS, XFS)

SINOPSIS

fsfreeze --freeze|--unfreeze punto_de_montaje

DESCRIPCIÓN

fsfreeze suspende o reanuda el acceso a un sistema de archivos.

fsfreeze detiene cualquier acceso nuevo al sistema de archivos y crea una imagen estable en disco. fsfreeze está pensado para ser utilizado con dispositivos RAID de hardware que soportan la creación de instantáneas.

fsfreeze es innecesario para dispositivos device-mapper. El device-mapper (y LVM) congela automáticamente un sistema de archivos en el dispositivo cuando se solicita la creación de una instantánea. Para más detalles, consulte la página del manual dmsetup(8).

El argumento punto_de_montaje es la ruta del directorio donde está montado el sistema de archivos. El sistema de archivos debe estar montado para poder ser congelado (ver mount(8)).

Tenga en cuenta que las actualizaciones del tiempo de acceso también se suspenden si el sistema de archivos está montado con el comportamiento tradicional de atime (opción de montaje strictatime, para más detalles ver mount(8)).

OPCIONES

-f, --freeze

Esta opción solicita que el sistema de archivos especificado sea congelado para nuevas modificaciones. Cuando se selecciona esto, todas las transacciones en curso en el sistema de archivos se permiten completar, las nuevas llamadas de sistema write(2) se detienen, otras llamadas que modifican el sistema de archivos se detienen, y todos los datos sucios, metadatos e información de registro se escriben en disco. Cualquier proceso que intente escribir en el sistema de archivos congelado se bloqueará esperando a que el sistema de archivos se descongele.

Tenga en cuenta que incluso después de congelar, el sistema de archivos en disco puede contener información sobre archivos que todavía están en proceso de desvinculación. Estos archivos no se desvincularán hasta que el sistema de archivos se descongele o se complete un montaje limpio de la instantánea.

-u, --unfreeze

Esta opción se utiliza para descongelar el sistema de archivos y permitir que las operaciones continúen. Todas las modificaciones del sistema de archivos que fueron bloqueadas por la congelación se desbloquean y se permite que se completen.

-h, --help

Muestra el texto de ayuda y sale.

-V, --version

Muestra la versión y sale.

SOPORTE DE SISTEMAS DE ARCHIVOS

Este comando solo funcionará si el sistema de archivos soporta la congelación. La lista de estos sistemas de archivos incluye (a fecha 2016-12-18) btrfs, ext2/3/4, f2fs, jfs, nilfs2, reiserfs y xfs. La lista anterior puede ser incompleta, ya que más sistemas de archivos obtienen soporte. En caso de duda, la forma más fácil de saber si un sistema de archivos tiene soporte es crear un pequeño montaje de bucle y probar a congelarlo.
