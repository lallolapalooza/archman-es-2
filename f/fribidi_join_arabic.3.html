NOMBRE

fribidi_join_arabic - realizar la unión árabe

SINOPSIS

#include <../fribidi/lib/fribidi.h>

void fribidi_join_arabic
(
const FriBidiCharType *bidi_types,
const FriBidiStrIndex len,
const FriBidiLevel *embedding_levels,
FriBidiArabicProp *ar_props
);

PARÁMETROS

const FriBidiCharType *bidi_types
Lista de entrada de tipos bidi tal como se devuelve por fribidi_get_bidi_types().

Dado que hay 23 valores posibles para un const FriBidiCharType, no todos se enumeran aquí.

const FriBidiStrIndex len
Longitud de la cadena de entrada.
const FriBidiLevel *embedding_levels
Lista de entrada de niveles de incrustación, tal como se devuelve por fribidi_get_par_embedding_levels.
FriBidiArabicProp *ar_props
Propiedades árabes a analizar, inicializadas por los tipos de unión, tal como se devuelve por fribidi_get_joining_types.

DESCRIPCIÓN

Esta función realiza el algoritmo de unión árabe. Significa que, dadas las tipos de unión árabes de los caracteres en ar_props (no te preocupes, FriBidiJoiningType se puede convertir a FriBidiArabicProp automáticamente), esta función modifica estas propiedades para captar el efecto de los caracteres vecinos. Probablemente necesites esta información más tarde para dar forma árabe.

Esta función implementa las reglas R1 a R7 inclusive (todas las reglas) del algoritmo de unión cursiva árabe del estándar Unicode disponible en http://www.unicode.org/versions/Unicode4.0.0/ch08.pdf#G7462. También interactúa correctamente con el algoritmo bidireccional tal como se define en la Sección
3.5 Forma del Algoritmo Bidireccional Unicode disponible en http://www.unicode.org/reports/tr9/#Shaping.

Hay algunas macros definidas en fribidi-joining-types.h para consultar las propiedades árabes calculadas por esta función.
