DESCRIPCIÓ

N

foomatic-configure es un programa para establecer y configurar colas de impresión para cada despachador conocido (CUPS, LPRng, LPD, GNUlpr, PPR, PDQ, CPS, sin despachador) y cada combinación válida de impresora/controlador en la base de datos de Foomatic o cada archivo PPD que viene con impresoras PostScript. Como filtro RIP (Procesador de Imágenes de Mapa de Bits, traducción de PostScript al lenguaje nativo de la impresora) siempre se usará foomatic-rip(1), excepto para los archivos PPD de impresoras PostScript bajo CUPS o PPR, que se usarán sin filtro RIP.

También

comprende la mitad de una API programática para herramientas de usuario: aquí puedes aprender y controlar todo sobre las propiedades estáticas de las colas de impresión. Con el programa hermano foomatic-printjob(1), puedes hacer todo lo relacionado con el estado dinámico de la cola de impresión: enviar trabajos, y consultar, cancelar, reordenar

y

redirigirlo

Como lprng puede usar printcaps en estilo BSD, esto no es mucho problema, siempre que no se use el gestor de impresión basado en GUI lprngtool. La diferencia entre esos formatos es que el estilo BSD requiere que las líneas de continuación en las definiciones de impresora terminen con dos puntos y que el carácter de nueva línea se escape con una barra invertida.
