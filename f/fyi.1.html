DESCRIPCIÓ

N

fyi es una utilidad de línea de comandos para enviar notificaciones de escritorio al usuario a través de un demonio de notificaciones que implementa las notificaciones de escritorio

XDG.

Es similar a la conocida utilidad notify-send(1). De hecho, la mayoría de las opciones son

idénticas.

Cuando se usa sin ninguna opción, fyi envía la notificación y sale inmediatamente, sin imprimir nada en

stdout.

Usa --print-id para que fyi imprima el ID de notificación asignado por el demonio en stdout, en el

formato:
id=I
D

Para ver por qué se cerró la notificación, usa --print-reason. La razón se imprime en stdout, en el

formato:
reason=REASO
N

fyi también puede bloquearse hasta que la notificación haya sido cerrada, usando la opción --wait. Enviar SIGINT al proceso fyi forzará el cierre de la

notificación.

fyi también se bloqueará si la notificación tiene alguna acción. Cuando se activa una acción, fyi imprime el nombre de la acción en stdout, en el

formato:
action=NAM
E

Algunos demonios de notificaciones pueden enviar un "token de activación". Esto se hace típicamente cuando el usuario hace clic en la notificación, o activa la acción predeterminada. El token se puede usar para enfocar (activar) una ventana. Para ver el token, usa --print-token. El token se imprime en stdout, en el

formato:
xdgtoken=TO
K

-T,--print-toke

Imprimir el token de activación, si existe, en el formato:

Algunos demonios de notificaciones envían un token de activación cuando la notificación es descartada; ya sea cuando se hace clic en la notificación, o se invoca la acción predeterminada. Otros lo enviarán independientemente de qué acción se haya invocado. Algunos solo lo enviarán cuando se invoca una acción, mientras que otros lo enviarán cuando la notificación es descartada, independientemente de

cómo.

El token se puede usar para enfocar (activar, elevar) una ventana. No es directamente utilizable por fyi, pero los programas que usan fyi como ayudante para mostrar notificaciones pueden
