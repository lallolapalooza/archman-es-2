fmtutil.cnf(5) Manual de formatos de archivo fmtutil.cnf(5)

NOMBRE

fmtutil.cnf - archivo de configuración para fmtutil

DESCRIPCIÓN

El archivo fmtutil.cnf contiene la información de configuración para fmtutil(8). Cada línea contiene el nombre del formato (ej. ``tex'', ``latex'', ``omega''), el nombre del motor que se utiliza por ese formato (ej. ``tex'', ``etex'', ``omega''), el archivo de patrones (ej. language.dat, language.def), y cualquier argumento (nombre de un archivo .ini).

Los campos están separados por espacios en blanco y las líneas completas pueden ser comentadas con ``#'. El campo ``archivo de patrones'' no se puede usar para definir un archivo que se usa durante la creación del formato. Le dice a fmtutil qué archivos (separados por comas) lee el procedimiento de creación del formato y tiene un efecto en las opciones --showhyphen y --byhyphen. Si el formato no tiene forma de personalizar la separación silábica, se puede usar un ``-'' para indicar esto.

NOTAS

Los formatos tex(1) y amstex(1) siempre cargan hyphen.tex. No hay personalización disponible para estos formatos mediante un archivo de patrones. Por lo tanto, el campo del archivo de patrones para tex y amstex se suele indicar como vacío (``-'').

Sin embargo, puede crear formatos personalizados sobre el tex(1) o amstex(1) básicos usando bplain.tex en lugar de plain.tex (b de sistema Babel). Consulte, por ejemplo, el archivo bplain.ini para el formato bplain).

etex(1) carga language.def, no language.dat.

Los enlaces simbólicos a los motores correctos (ej. bplain -> tex) son generados por el script texlinks(8). Recuerde ejecutar texlinks(8) si ejecuta usted mismo fmtutil(8), en lugar de usar la opción FORMATS en texconfig(8).
