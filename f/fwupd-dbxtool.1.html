NOMBRE

dbxtool - modificar la lista de revocación de dbx

SINOPSIS

dbxtool [COMANDO]

DESCRIPCIÓN

Esta página del manual documenta brevemente el comando dbxtool.

dbxtool permite a un usuario operar en la lista de revocación dbx de UEFI. Esta herramienta puede usarse para listar el contenido actual de dbx o actualizarlo a una versión más reciente.

OPCIONES

La herramienta dbxtool toma varias opciones dependiendo de la acción. Ejecute dbxtool --help para la lista completa.
