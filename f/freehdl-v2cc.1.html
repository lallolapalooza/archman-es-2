FreeHDL-V2CC(1) Comandos de usuario FreeHDL-V2CC(1)

NOMBRE

FreeHDL-V2CC - Un conversor de VHDL a C++.

SINOPSIS

freehdl-v2cc [OPCIÓN] ... [ARCHIVO] ...

DESCRIPCIÓN

FreeHDL es un conjunto de analizador/compilador/simulador para el lenguaje de descripción de hardware VHDL. Se admiten archivos VHDL'93 y VHDL'87.

FreeHDL-V2CC traduce los archivos fuente originales de VHDL a C++.

OPCIONES

-o ARCHIVO
Escribe el código C++ generado en ARCHIVO.
-n
Ejecución de prueba (dry run).
-R
Emite código de registro.
-v
Habilita la verbosidad.
-g
Emite código de depuración.
-D
Emite código CDFG.
-l NOMBRE_BIBLIOTECA
Usa NOMBRE_BIBLIOTECA como la biblioteca WORK, por defecto es el directorio de la biblioteca ".".
--relaxed-component-visibility
Permite enlaces predeterminados invisibles desde WORK.
--depend ARCHIVO
Escribe la información de dependencia en ARCHIVO.
-m ARCHIVO
Emite el código C++ del archivo principal (main()) en ARCHIVO.
-L VHDLLIB
Ruta al directorio raíz de la biblioteca VHDL. Dentro de este directorio, el compilador busca un archivo llamado v2cc.libs. El archivo de mapeo v2cc.libs traduce los nombres de las unidades de biblioteca a directorios. Tenga en cuenta que se puede proporcionar más de un VHDLLIB.

VARIABLES DE ENTORNO

V2CC_LIBRARY_PATH
La variable V2CC_LIBRARY_PATH consta de nombres de archivo separados por ":". Además de la variable de entorno, puede usar la opción de línea de comandos "-L libdir" con v2cc. Los directorios especificados con "-L" se añaden delante de los especificados por V2CC_LIBRARY_PATH. En la ruta final de la biblioteca, aparecen en el mismo orden que en la línea de comandos.

VER TAMBIÉN

gvhdl(1), freehdl-config(1), v2cc.libs(5)

DISPONIBILIDAD

La última versión de FreeHDL siempre se puede obtener en www.freehdl.seul.org
