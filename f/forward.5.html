FORWARD(5) Manual de Formatos de Archivo FORWARD(5)

NOMBRE

forward — archivo de información de reenvío de correo electrónico

DESCRIPCIÓN

Los usuarios pueden colocar un archivo .forward en su directorio de inicio. Si este archivo existe, smtpd(8) reenvía el correo electrónico a los destinos especificados en él.

Un archivo .forward contiene una lista de valores de expansión, tal como se describe en aliases(5). Cada valor de expansión debe estar en una línea separada. La expansión se realiza bajo el ID de usuario del propietario del archivo .forward.

Los permisos del archivo .forward son muy estrictos y la expansión se rechaza si el archivo es escribible por el grupo o por todos; si el directorio de inicio es escribible por el grupo; o si el archivo no pertenece al usuario.

Los usuarios deben evitar editar el archivo .forward directamente, para evitar fallos de entrega si llega un mensaje mientras el archivo no está completamente escrito. La mejor opción es utilizar un archivo temporal y el comando mv(1) para sobrescribir atómicamente el archivo .forward anterior. Alternativamente, establecer el bit sticky(8) en el directorio de inicio hará que la búsqueda de .forward devuelva un fallo temporal, provocando el aplazamiento de los correos.

ARCHIVOS

~/.forward
Información de reenvío de correo electrónico.

EJEMPLOS

El siguiente archivo reenvía el correo a “user@example.com”, y canaliza el mismo correo a “examplemda”.

# las líneas vacías se ignoran

user@example.com	# todo lo que esté después de # se ignora
"|/path/to/examplemda"

VER TAMBIÉN

aliases(5), smtpd(8)

ADVERTENCIAS

Los mecanismos de canalización ‘|’ y :include: no están permitidos para el usuario root.
