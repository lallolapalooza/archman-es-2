FOOMATIC-KITLOAD(8) Manual del Administrador del Sistema FOOMATIC-KITLOAD(8)

NOMBRE

foomatic-kitload - instala un kit de datos en la base de datos de foomatic.

SINOPSIS

foomatic-kitload [ -k kit-dir] [ -d dest-dir]...

DESCRIPCIÓN

foomatic-kitload instala un kit de datos de foomatic en la biblioteca de datos local. Toma una opción -k dirname, donde dirname es el directorio raíz de un "kit" de controladores de foomatic. Un "kit" es una selección de archivos fuente XML organizados exactamente como en la sección source/ de la base de datos maestra (es decir, subdirectorios opt/driver/printer/).

El generador foomatic de Gimp-Print produce exactamente tal kit.

Foomatic-kitload es moderadamente paranoico con los kits: el kit debe contener al menos uno de printer, driver u opt; el kit solo debe contener archivos que terminen en .xml, el kit no puede ser la biblioteca local misma, etc. Pero no inspecciona el contenido de los archivos del kit de ninguna manera.

Opciones

-k dirname
dirname es el directorio raíz de un "kit" de controladores de foomatic.
-d destdir
destdir es un prefijo para anteponer a la ruta de instalación. Normalmente no será necesario, pero es útil si se instala en un área de 'staging' temporal antes de instalar en la ubicación final.

ESTADO DE SALIDA

foomatic-kitload devuelve 0 en caso de éxito, 255 o algo más cuando ocurre un error.
