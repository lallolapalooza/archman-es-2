form_field_info(3x)

Paquete: ncurses

Licencias: MIT-open-group

form_field_info(3X) Llamadas a biblioteca form_field_info(3X)

NOMBRE

dynamic_field_info, field_info - recuperar características de campo

SINOPSIS

#include <form.h>
int field_info(const FIELD *campo,
               int *filas, int *columnas,
               int *fila_superior_izq, int *col_superior_izq,
               int *filas_fuera_pantalla, int *buffers_trabajo);
int dynamic_field_info(const FIELD *campo,
                       int *filas, int *columnas, int *max);

DESCRIPCIÓN

La función field_info devuelve los tamaños y otros atributos pasados a la hora de crear el campo. Los atributos son: altura, anchura, fila de la esquina superior izquierda, columna de la esquina superior izquierda, número de filas fuera de pantalla y número de buffers de trabajo.

La función dynamic_field_info devuelve el tamaño real del campo y su tamaño máximo posible. Si el campo no tiene límite de tamaño, la ubicación a la que apunta el tercer argumento se establecerá en 0. Un campo puede hacerse dinámico desactivando la opción O_STATIC con field_opts_off.

VALOR DE RETORNO

Estas rutinas devuelven uno de los siguientes:

E_OK
La rutina tuvo éxito.
E_SYSTEM_ERROR
Ocurrió un error del sistema (ver errno(3)).
E_BAD_ARGUMENT
La rutina detectó un argumento incorrecto o fuera de rango.

PORTABILIDAD

Estas rutinas emulan la biblioteca forms de System V. No eran soportadas en las versiones Version 7 o BSD.

Se acepta un puntero nulo (cero) para cualquiera de los valores de retorno, para ignorar ese valor. No todas las implementaciones permiten esto, por ejemplo, Solaris 2.7 no lo hace.

AUTORES
