DESCRIPCIÓ

N

fsverity es una utilidad de espacio de usuario para fs-verity. fs-verity es una característica del sistema de archivos del núcleo de Linux que realiza una verificación transparente bajo demanda del contenido de archivos de solo lectura mediante árboles de

Merkle.

fsverity puede activar fs-verity en archivos, recuperar los resúmenes (digests) de archivos con fs-verity y firmar archivos para su uso con fs-verity (entre otras cosas). La funcionalidad de fsverity está dividida entre varios

subcomandos.

Esta página de manual se centra en documentar todos los subcomandos y opciones de fsverity. Para ejemplos y más información sobre la c

aracterística del núcleo fs-verity, consul
te las referencias al final de esta página.

fsverity dump_metadata [OPCIÓN...] TIPO ARCHIV

O

Vuelca los metadatos de fs-verity del archivo dado. El archivo debe tener fs-verity activado, y el sistema de archivos debe soportar el FS_IOC_READ_VERITY_METADATA ioctl (se añadió en Linux v5.12). Este subcomando normalmente no es útil, pero puede serlo en casos donde un programa servidor de espacio de usuario esté sirviendo un archivo verity a un cliente que implementa una verificación compatible con

fs-verity.

TIPO puede ser “merkle_tree”, “descriptor” o “signature”, indicando el tipo de metadatos a volcar. “signature” se refiere a la firma incorporada, si está presente; las firmas gestionadas por el espacio de usuario no se

incluirán.

fsverity sign [OPCIÓN...] ARCHIVO ARCHIVO_SIG_SALI

DA

Firma el archivo dado para fs-verity, de una manera compatible con la implementación de verificación de firmas incorporadas de fs-verity del núcleo de Linux. La firma se escribirá en ARCHIVO_SIG_SALIDA en formato PKCS#7

DER.

La clave privada puede especificarse mediante un archivo de clave o mediante un token PKCS#11. Para usar un archivo de clave, proporcione --key y opcionalmente --cert. Para usar un token PKCS#11, proporcione --pkcs11-engine, --pkcs11-module, --cert y opcionalmente --pkcs11-keyid. El soporte para tokens PKCS#11 no está disponible cuando fsverity-utils se compiló con BoringSSL raque

OpenSSL.

fsverity sign solo debe usarse si necesitas compatibilidad con las firmas integradas de fs-verity. No es la única forma de hacer firmas con fs-verity. Para más información, consulta el README de

fsverity-utils.
