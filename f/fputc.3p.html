FPUTC(3P) Manual del Programador POSIX FPUTC(3P)

PRÓLOGO

Esta página del manual forma parte del Manual del Programador POSIX. La implementación de esta interfaz en Linux puede diferir (consulte la página de manual de Linux correspondiente para detalles del comportamiento en Linux), o la interfaz puede no estar implementada en Linux.

NOMBRE

fputc — escribe un byte en un flujo

SINOPSIS

#include <stdio.h>
int fputc(int c, FILE *stream);

DESCRIPCIÓN

La funcionalidad descrita en esta página de referencia está alineada con el estándar ISO C. Cualquier conflicto entre los requisitos descritos aquí y el estándar ISO C no es intencional. Este volumen de POSIX.1‐2017 se subordina al estándar ISO C.

La función fputc() escribirá el byte especificado por c (convertido a un unsigned char) en el flujo de salida apuntado por stream, en la posición indicada por el indicador de posición de archivo asociado al flujo (si está definido), y avanzará el indicador apropiadamente. Si el archivo no puede soportar solicitudes de posicionamiento, o si el flujo se abrió en modo de anexión, el byte se añadirá al flujo de salida.

Las marcas de tiempo de la última modificación de datos y del último cambio de estado del archivo se marcarán para su actualización entre la ejecución exitosa de fputc() y la siguiente finalización exitosa de una llamada a fflush() o fclose() en el mismo flujo, o una llamada a exit() o abort().

VALOR DE RETORNO

Tras la finalización exitosa, fputc() devolverá el valor que ha escrito. De lo contrario, devolverá EOF, el indicador de error del flujo se establecerá, y errno se establecerá para indicar el error.

ERRORES

La función fputc() fallará si stream no tiene búfer o si el búfer de streamnecesita ser vaciado, y:

EAGAIN
La bandera O_NONBLOCK está establecida para el descriptor de archivo subyacente a stream y el hilo se retrasaría en la operación de escritura.
EBADF
El descriptor de archivo subyacente a stream no es un descriptor de archivo válido abierto para escritura.
EFBIG
Se intentó escribir en un archivo que excede el tamaño máximo de archivo.
EFBIG
Se intentó escribir en un archivo que excede el límite de tamaño de archivo del proceso.
EFBIG
El archivo es un archivo regular y se intentó escribir en o más allá del máximo desplazamiento.
EINTR
La operación de escritura fue terminada debido a la recepción de una señal, y no se transfirieron datos.
EIO
Ha ocurrido un error físico de E/S, o el proceso es miembro de un grupo de procesos en segundo plano que intenta escribir en su terminal de control, TOSTOP está establecido, el hilo que llama no está bloqueando SIGTTOU, el proceso no está ignorando SIGTTOU, y el grupo de procesos del proceso está huérfano. Este error también puede devolverse bajo condiciones definidas por la implementación.
ENOSPC
No quedaba espacio libre en el dispositivo que contiene el archivo.
EPIPE
Se intenta escribir en una tubería o FIFO que no está abierta para lectura por ningún proceso. También se enviará una señal SIGPIPE al hilo.

La función fputc() puede fallar si:

ENOMEM
No hay suficiente espacio de almacenamiento disponible.
ENXIO
Se hizo una solicitud a un dispositivo inexistente, o la solicitud estaba fuera de las capacidades del dispositivo.
