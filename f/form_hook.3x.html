form_hook(3x)

Paquete: ncurses

Licencias: MIT-open-group

form_hook(3X) Llamadas de librería form_hook(3X)

NOMBRE

form_hook - establecer ganchos para invocación automática por aplicaciones

SINOPSIS

#include <form.h>
int set_field_init(FORM *form, Form_Hook func);
Form_Hook field_init(const FORM *form);
int set_field_term(FORM *form, Form_Hook func);
Form_Hook field_term(const FORM *form);
int set_form_init(FORM *form, Form_Hook func);
Form_Hook form_init(const FORM *form);
int set_form_term(FORM *form, Form_Hook func);
Form_Hook form_term(const FORM *form);

DESCRIPCIÓN

Estas funciones permiten establecer funciones de gancho para ser llamadas en varios puntos del procesamiento automático de códigos de entrada por parte de form_driver.

set_field_init

establece un gancho para ser llamado en el momento de publicar el formulario y cada vez que el campo seleccionado cambia (después del cambio).

field_init

devuelve el gancho de inicialización de campo actual, si lo hay (NULL si no hay tal gancho).

set_field_term

establece un gancho para ser llamado en el momento de despublicar el formulario y cada vez que el campo seleccionado cambia (antes del cambio).

field_term

devuelve el gancho de terminación de campo actual, si lo hay (NULL si no hay tal gancho).

set_form_init

establece un gancho para ser llamado en el momento de publicar el formulario y justo después de un cambio de página una vez que se publica.

form_init

devuelve el gancho de inicialización de formulario actual, si lo hay (NULL si no hay tal gancho).

set_form_term

establece un gancho para ser llamado en el momento de despublicar el formulario y justo antes de un cambio de página una vez que se publica.

form_term

devuelve el gancho de terminación de formulario actual, si lo hay (NULL si no hay tal gancho).

VALOR DE RETORNO

Las rutinas que devuelven punteros devuelven NULL en caso de error. Otras rutinas devuelven uno de los siguientes:

E_OK
La rutina tuvo éxito.
E_SYSTEM_ERROR
Ocurrió un error del sistema (ver errno(3)).

PORTABILIDAD

Estas rutinas emulan la biblioteca de formularios de System V. No eran compatibles con las versiones 7 o BSD.

AUTORES
