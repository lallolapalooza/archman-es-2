fontinst(1) Manual de comandos generales fontinst(1)

NOMBRE

fontinst - utilidad para ejecutar TeX como fontinst

SINOPSIS

fontinst paquete

DESCRIPCIÓN

fontinst ejecuta tex(1) con la bandera --progname establecida para simular ser el programa fontinst (afectando las rutas de Karl Berry).

Escribir

fontinst fontinst.sty

iniciará tex(1) y le dará al usuario un prompt interactivo (*) donde se pueden escribir comandos de fontinst (como \latinfamily{ptm}{}\bye).

VER TAMBIÉN

tex(1)

El manual de fontinst, fontinst.tex.

Página web: https://tug.org/applications/fontinst/
