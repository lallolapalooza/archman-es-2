foreach(n) Comandos integrados de Tcl foreach(n)

NOMBRE

foreach - Itera sobre todos los elementos de una o más listas

SINOPSIS

foreach nombre_variable lista cuerpo
foreach lista_vars1 lista1 ?lista_vars2 lista2 ...? cuerpo

DESCRIPCIÓN

El comando foreach implementa un bucle donde la(s) variable(s) del bucle toman valores de una o más listas. En el caso más simple hay una variable de bucle, nombre_variable, y una lista, lista, que es una lista de valores para asignar a nombre_variable. El argumento cuerpo es un script Tcl. Para cada elemento de lista (en orden de primero a último), foreach asigna el contenido del elemento a nombre_variable como si se hubiera utilizado el comando lindex para extraer el elemento, y luego llama al intérprete Tcl para ejecutar cuerpo.

En el caso general puede haber más de una lista de valores (por ejemplo, lista1 y lista2), y cada lista de valores puede estar asociada con una lista de variables de bucle (por ejemplo, lista_vars1 y lista_vars2). Durante cada iteración del bucle las variables de cada lista_vars se asignan valores consecutivos de la lista correspondiente. Los valores en cada lista se usan en orden de primero a último, y cada valor se usa exactamente una vez. El número total de iteraciones del bucle es suficiente para usar todos los valores de todas las listas de valores. Si una lista de valores no contiene suficientes elementos para cada una de sus variables de bucle en cada iteración, se usan valores vacíos para los elementos que faltan.

Los comandos break y continue pueden invocarse dentro de cuerpo, con el mismo efecto que en el comando for. Foreach devuelve una cadena vacía.

EJEMPLOS

Este bucle imprime cada valor de una lista junto con el cuadrado y el cubo del valor:

set valores {1 3 5 7 2 4 6 8}	;# ¡Números impares primero, por diversión!
puts "Valor\tCuadrado\tCubo"	;# Encabezado con formato ordenado
foreach x $valores {	;# Ahora bucle e impresión...
    puts " $x\t [expr {$x**2}]\t [expr {$x**3}]"
}

El siguiente bucle utiliza i y j como variables de bucle para iterar sobre pares de elementos de una única lista.

set x {}
foreach {i j} {a b c d e f} {
    lappend x $j $i
}
# El valor de x es "b a d c f e"
# Hay 3 iteraciones del bucle.

El siguiente bucle utiliza i y j para iterar sobre dos listas en paralelo.

set x {}
foreach i {a b c} j {d e f g} {
    lappend x $i $j
}
# El valor de x es "a d b e c f {} g"
# Hay 4 iteraciones del bucle.

Las dos formas se combinan en el siguiente ejemplo.

set x {}
foreach i {a b c} {j k} {d e f g} {
    lappend x $i $j $k
}
# El valor de x es "a d e b f g c {} {}"
# Hay 3 iteraciones del bucle.
