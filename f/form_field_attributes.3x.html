NOMBRE

form_field_attributes - control de color y atributos para campos de formulario

SINOPSIS

#include <form.h>
int set_field_fore(FIELD *campo, chtype attr);
chtype field_fore(const FIELD *campo);
int set_field_back(FIELD *campo, chtype attr);
chtype field_back(const FIELD *campo);
int set_field_pad(FIELD *campo, int relleno);
int field_pad(const FIELD *campo);

DESCRIPCIÓN

La función set_field_fore establece el atributo de primer plano de campo. Este es el resaltado utilizado para mostrar el contenido del campo. La función field_fore devuelve el atributo de primer plano. El valor predeterminado es A_STANDOUT.

La función set_field_back establece el atributo de fondo de formulario. Este es el resaltado utilizado para mostrar los campos de extensión en el formulario. La función field_back devuelve el atributo de fondo. El valor predeterminado es A_NORMAL.

La función set_field_pad establece el carácter utilizado para rellenar el campo. La función field_pad devuelve el carácter de relleno del formulario dado. El valor predeterminado es un espacio en blanco.

VALOR DE RETORNO

Estas rutinas devuelven uno de los siguientes:

E_OK
La rutina tuvo éxito.
E_BAD_ARGUMENT
La rutina detectó un argumento incorrecto o fuera de rango.
E_SYSTEM_ERROR
Ocurrió un error del sistema (ver errno(3)).

PORTABILIDAD

Estas rutinas emulan la biblioteca de formularios de System V. No eran compatibles con las versiones 7 o BSD.
