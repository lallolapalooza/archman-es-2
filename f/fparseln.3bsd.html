fparseln(3bsd)

Paquete: libbsd

Licencias: custom

fparseln(3bsd) 3bsd fparseln(3bsd)

NOMBRE

fparseln — devolver la siguiente línea lógica de un flujo

BIBLIOTECA

biblioteca “libbsd”

SINOPSIS

#include <stdio.h> (Ver libbsd(7) para el uso de la inclusión.)
char *
fparseln(FILE *stream, size_t *len, size_t *lineno, const char delim[3], int flags);

DESCRIPCIÓN

La función fparseln() devuelve un puntero a la siguiente línea lógica del flujo al que se hace referencia con stream. Esta cadena está terminada en NUL y se asigna dinámicamente en cada invocación. Es responsabilidad del llamador liberar el puntero.

Por defecto, si un carácter se escapa, tanto él como el carácter de escape precedente estarán presentes en la cadena devuelta. Varias flags alteran este comportamiento.

El significado de los argumentos es el siguiente:

stream
El flujo del que leer.
len
Si no es NULL, la longitud de la cadena se almacena en la ubicación de memoria a la que apunta.
lineno
Si no es NULL, el valor de la ubicación de memoria a la que se apunta se incrementa por el número de líneas realmente leídas del archivo.
delim
Contiene los caracteres de escape, continuación y comentario. Si un carácter es NUL, el procesamiento de ese carácter se deshabilita. Si es NULL, todos los caracteres usan por defecto los valores especificados a continuación. El contenido de delim es el siguiente:
delim[0]
El carácter de escape, que por defecto es \, se utiliza para eliminar cualquier significado especial del siguiente carácter.
delim[1]
El carácter de continuación, que por defecto es \, se utiliza para indicar que la siguiente línea debe concatenarse con la actual si este carácter es el último de la línea actual y no está escapado.
delim[2]
El carácter de comentario, que por defecto es #, si no está escapado, indica el inicio de un comentario que se extiende hasta el final de la línea actual.
flags
Si es distinto de cero, altera el funcionamiento de fparseln(). Las diversas flags, que pueden ser or-ed juntas, son:
FPARSELN_UNESCCOMM
Eliminar el escape que precede a un comentario escapado.
FPARSELN_UNESCCONT
Eliminar el escape que precede a una continuación escapada.
FPARSELN_UNESCESC
Eliminar el escape que precede a un escape escapado.
FPARSELN_UNESCREST
Eliminar el escape que precede a cualquier otro carácter.
FPARSELN_UNESCALL
Todas las anteriores.

VALORES DE RETORNO

Al completarse con éxito, se devuelve un puntero a la línea analizada; de lo contrario, se devuelve NULL.

La función fparseln() utiliza internamente getline(3), por lo que todas las condiciones de error que se aplican a getline(3), se aplican a fparseln(). Además, fparseln() puede establecer errno a [ENOMEM] y devolver NULL si se queda sin memoria.

VER TAMBIÉN

getline(3)

HISTORIA

La función fparseln() apareció por primera vez en NetBSD 1.4 y FreeBSD 4.0.
