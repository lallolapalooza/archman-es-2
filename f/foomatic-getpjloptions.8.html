FOOMATIC-GETPJLOPTIONS(8) Manual del Administrador del Sistema FOOMATIC-GETPJLOPTIONS(8)

NOMBRE

foomatic-getpjloptions - <ponga una breve descripción aquí>

SINOPSIS

foomatic-getpjloptions dispositivo

foomatic-getpjloptions nombrehost puerto

DESCRIPCIÓN

foomatic-getpjloptions envía un conjunto de comandos PJL y lee las opciones y el estado PJL de una impresora a través de una conexión de red o una interfaz bidireccional del dispositivo como paralelo, USB, serie. Las impresoras a la salida estándar. La salida se puede canalizar a foomatic-addpjloptions para agregar opciones a la base de datos.

Opciones

dispositivo
La interfaz a la que está conectada una impresora local, p. ej., /dev/lp0, /dev/usb/lp0, /dev/tty00, etc. Para un puerto paralelo, debe tener soporte bidireccional habilitado a nivel de BIOS y el controlador del puerto paralelo debe soportar el modo bidireccional. Verifique la configuración de la BIOS de su puerto paralelo para el modo EPP/bidireccional.
nombrehost
Nombre de host o dirección IP de una impresora de red (HP JetDirect, DLINK, etc.).
puerto
Puerto en el que su impresora de red escucha las conexiones de socket (Appsocket). Los puertos más comunes son 9100 (JetDirect), 10000 (DLINK). Normalmente puede configurar el puerto a través de una interfaz de configuración.

AUTOR

Manfred Wassmann <manolo@NCC-1701.B.Shuttle.de> para el proyecto foomatic usando la salida del binario asociado. Modificado por Patrick Powell <papowell at lprng.com> para proporcionar un mejor soporte para impresoras de red, mensajes de error y eliminar CR y FF de la salida.

ADVERTENCIAS

Los protocolos unidireccionales como LPD remoto no son compatibles, ya que no se devuelve ningún estado. Algunos servidores de impresión de red que se conectan al puerto paralelo de una impresora no soportan el modo bidireccional.
