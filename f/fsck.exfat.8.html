fsck.exfat(8) Manual del Administrador del Sistema fsck.exfat(8)

NOMBRE

fsck.exfat - comprobar un sistema de archivos exFAT

SINOPSIS

fsck.exfat [ -a ] [ -n ] [ -r ] [ -v ] [ -y ] [ -b ] [ -v ] dispositivo
fsck.exfat -V

DESCRIPCIÓN

fsck.exfat comprueba un sistema de archivos exFAT y repara el sistema de archivos según las opciones pasadas. Las siguientes corrupciones pueden ser reparadas, y ver la opción, '-s'.

-
El sector de arranque tiene parámetros inválidos. Si el sector de arranque de respaldo es válido, reemplaza el sector de arranque con él.
-
El clúster está marcado como libre pero pertenecía a un archivo, o viceversa. El mapa de bits del clúster está marcado correctamente.
-
El tamaño del archivo es anormalmente grande considerando la cantidad de clústeres. El tamaño se modifica.
-
El tamaño del archivo es anormalmente pequeño considerando la cantidad de clústeres. Los clústeres restantes se eliminan.
-
La cadena de clústeres de un archivo tiene un número de clúster inválido. El número se cambia a EOF, y el tamaño del archivo también se modifica.
-
La cadena de clústeres de un archivo contiene un bucle. El bucle se rompe.
-
Los archivos comparten el mismo clúster. Las cadenas de clústeres para los archivos, excepto uno, se rompen.
-
El número de clúster de inicio es inválido. El número de clúster y el tamaño del archivo se cambian a 0.
-
El valor de suma de comprobación del conjunto de entradas de directorio es inválido. El conjunto de entradas de directorio se elimina.
-
Mala suma de comprobación de un nombre de archivo. El valor de suma de comprobación se modifica correctamente.
-
Los campos del conjunto de entradas de directorio tienen valores inválidos. El conjunto de entradas de directorio se elimina.

OPCIONES

-a
Esta opción hace lo mismo que la opción -p. Se proporciona solo por compatibilidad con versiones anteriores; se sugiere que las personas usen la opción -p siempre que sea posible.
-n
Comprueba el sistema de archivos pero no intenta repararlo.
-p
Repara el sistema de archivos sin interacción del usuario si se puede hacer de forma segura.
-r
Repara el sistema de archivos interactivamente.
-s
Crea archivos en /LOST+FOUND para clústeres huérfanos. Estos archivos tienen clústeres asignados pero no pertenecen a ningún archivo al reparar el sistema de archivos. Los clústeres no utilizados y contiguos en el mapa de bits se asignan al mismo archivo.
-v
Imprime información de depuración detallada mientras se comprueba el sistema de archivos exFAT.
-V
Imprime el número de versión y sale.
-y
Repara el sistema de archivos respondiendo sí a todas las preguntas.
-b
Intenta reparar el sistema de archivos incluso si no se encuentra el sistema de archivos exFAT.

EJEMPLOS

Reparar un dispositivo corrupto y crear archivos en /LOST+FOUND, que tienen clústeres asignados pero no pertenecen a ningún archivo al reparar el dispositivo.

$ fsck.exfat -p -s /dev/sda1
