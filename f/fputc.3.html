puts(3) Manual de Funciones de Biblioteca puts(3)

NOMBRE

fputc, fputs, putc, putchar, puts - salida de caracteres y cadenas

BIBLIOTECA

Biblioteca C estándar (libc, -lc)

SINOPSIS

#include <stdio.h>
int fputc(int c, FILE *stream);
int putc(int c, FILE *stream);
int putchar(int c);
int fputs(const char *restrict s, FILE *restrict stream);
int puts(const char *s);

DESCRIPCIÓN

fputc() escribe el carácter c, convertido a unsigned char, en stream.

putc() es equivalente a fputc() excepto que puede implementarse como una macro que evalúa stream más de una vez.

putchar(c) es equivalente a putc(c, stdout).

fputs() escribe la cadena s en stream, sin su byte nulo de terminación ('\0').

puts() escribe la cadena s y una nueva línea al final en stdout.

Las llamadas a las funciones descritas aquí pueden mezclarse entre sí y con otras funciones de salida de la biblioteca stdio para el mismo flujo de salida.

Para las contrapartes no bloqueantes, véase unlocked_stdio(3).

VALOR DE RETORNO

fputc(), putc() y putchar() devuelven el carácter escrito como un unsigned char convertido a int o EOF en caso de error.

puts() y fputs() devuelven un número no negativo en caso de éxito, o EOF en caso de error.

ATRIBUTOS

Para una explicación de los términos utilizados en esta sección, véase attributes(7).

Interfaz Atributo Valor
fputc (), fputs (), putc (), putchar (), puts () Seguridad en hilos MT-Safe

ESTÁNDARES

C11, POSIX.1-2008.

HISTORIA

POSIX.1-2001, C89, C99.

ERRORES

No es recomendable mezclar llamadas a funciones de salida de la biblioteca stdio con llamadas de bajo nivel a write(2) para el descriptor de archivo asociado al mismo flujo de salida; los resultados serán indefinidos y muy probablemente no los que desea.
