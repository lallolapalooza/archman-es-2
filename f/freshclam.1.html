DESCRIPCIÓ

N

freshclam es una herramienta

de actualización de bases de
datos de virus para ClamAV.

OPCIONE

S

FreshClam lee su configuración de freshclam.conf. La configuración puede ser sobrescrita con opciones de línea de

comandos.
-h,
--help
Muestra información de ayuda y
sale.
-V,
--version
Imprime el número de versión y
sale.
-v,
--verbose
Ser detallado. Esta opción hace que freshclam imprima mucha información
adicional.
--deb
ug
Habilita mensajes de depuración de
LibClamAV.
--qui
et
Ser silencioso - imprimir solo mensajes de
error.
--no-warnin
gs
No imprimir ni registrar
advertencias.
--stdo
ut
Escribir todos los mensajes a
stdout.
--show-progr
ess
Mostrar el porcentaje de progreso de la
descarga.
--config-file=ARCH
IVO
Leer la configuración de
ARCHIVO.
-l ARCHIVO,
--log=ARCHIVO
Registrar el informe en
ARCHIVO.
-d,
--daemon
Ejecutar en modo demonio. Por defecto realiza 12 comprobaciones al día a menos que se especifique de otra forma con --checks o freshclam.
conf.
-p ARCHIVO,
--pid=ARCHIVO
Escribir el pid del demonio en
ARCHIVO.
-F,
--foreground
No hacer fork a segundo plano (para usar en modo demonio)
.
-u USUARIO, --user
USUARIO
Ejecutar como USUARIO. Por defecto (cuando es iniciado por root) freshclam cede privilegios y opera como el usuario
'clamav'.
--no-d
ns
Esta opción fuerza el método de verificación antiguo sin DNS (sin un retraso
TTL).
-c #n,
--checks=#n
Comprobar #n veces al día si hay una nueva base de datos. #n debe estar entre 1 y
50.
--datadir=DIRECTO
RIO
Instalar la nueva base de datos en DIRECTORIO. El directorio debe ser escribible para el usuario 'clamav' o el usuario sin privilegios que ejecute freshclam, debe existir ya, y debe ser una ruta
absoluta.
--daemon-notify=/ruta/a/clamd.
conf
Notificar al demonio sobre la nueva base de datos. Por defecto lee un archivo de configuración predefinido pero puedes usar uno diferente. Se soportan tanto sockets locales como
TCP.
-a IP, --local-address
=IP
Usar IP (local) para descargas HTTP. Útil para sistemas multi-homed. Si el enlace falla por cualquier razón, se emite una advertencia y freshclam se comporta como sin esta
opción.
--on-update-execute=COMA
NDO
Ejecutar COMANDO después de una actualización
exitosa.
--on-error-execute=COMA
NDO
Ejecutar COMANDO si ocurrió un error. Recuerda, la frescura de la base de datos de virus es lo más importante en un sistema antivirus. Con esta opción freshclam puede alertarte (ej. enviar un SMS) cuando algo va
mal.
--on-outdated-execute=COMA
NDO
Ejecutar COMANDO cuando freshclam reporte una versión obsoleta. En la cadena de comando %v será reemplazado por el número de la nueva
versión.
--update-db=NOMBR
EDB
Con esta opción puedes limitar las actualizaciones a un subconjunto de archivos de base de datos. El NOMBREDB debe ser "ma
in", "daily", "bytecode", "safebrowsing" o uno de los nombres de las bases de datos de terceros. Esta opción puede usarse
múltiples veces y solo funciona con las bases de datos oficiales y de terceros distribuidas a través de los mirror
s de ClamAV, tus bases de datos personalizadas (especificadas con DatabaseCustomURL en freshclam.conf) no serán ignoradas.

VARIABLES DE

ENTORNO

freshclam usa las siguientes variables de

entorno:
CURL_CA_BUND
LE
(Solo Linux/Unix, excluyendo macOS) Puede ser establecida a la ruta de un archivo (bundle) que contenga uno o más certificados CA. Esto sobrescribirá la ruta de certificado openssl por
defecto.
FRESHCLAM_CLIENT_C
ERT
Puede ser establecida a la ruta de un archivo (PEM) que contenga el certificado del cliente. Esto puede usarse para autenticación del
cliente.
FRESHCLAM_CLIENT_
KEY
Puede ser establecida a la ruta de un archivo (PEM) que contenga la clave privada del cliente. Esto es requerido si FRESHCLAM_CLIENT_CERT está
establecida.
FRESHCLAM_CLIENT_KEY_PAS
SWD
Puede ser establecida a una contraseña para el archivo PEM de la clave del cliente. Esto es requerido si FRESHCLAM_CLIENT_KEY está establecida y el archivo PEM está protegido por
contraseña.
CVD_CERTS_D
IR
Especifica un directorio que contenga el certificado raíz CA necesario para verificar las firmas digitales CVD separadas. Si no se proporciona, freshclam buscará en el directorio por
defecto.
Ten en cuenta que la variable de entorno CURL_CA_BUNDLE también es usada por la herramienta de línea de comandos curl para el mismo
propósito.

CÓDIGOS DE

RETORNO

Algunos códigos de retorno de freshclam pueden ser sobrescritos con un comando integrado EXIT_n que puede pasarse a --on-*-execute, ej. --on-update-execute=EXIT_1 forzará a freshclam a siempre retornar 1 después de una actualización exitosa de la base de

datos.
0 : La base de datos está actualizada o fue actualizada
exitosamente.
40: Opción desconocida
pasada.
50: No se puede cambiar de
directorio.
51: No se puede comprobar la suma
MD5.
52: Problema de conexión (de
red).
53: No se puede eliminar el
archivo.
54: Error de verificación de MD5 o firma
digital.
55: Error al leer el
archivo.
56: Error en el archivo de
configuración.
57: No se puede crear un nuevo
archivo.
58: No se puede leer la base de datos del servidor
remoto.
59: Los mirrors no están completamente sincronizados (intenta de nuevo más
tarde).
60: No se puede obtener información del usuario 'clamav' de
/etc/passwd.
61: No se pueden ceder
privilegios.
62: No se puede inicializar el
registrador.
