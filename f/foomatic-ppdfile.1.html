FOOMATIC-PPDFILE(1) Manual de comandos generales FOOMATIC-PPDFILE(1)

NOMBRE

foomatic-ppdfile - Genera un archivo PPD para una combinación dada de impresora/controlador

SINOPSIS

foomatic-ppdfile [-w] [-d <controlador>] -p <id_impresora>
foomatic-ppdfile [-A] [-P patrón]
foomatic-ppdfile -h

DESCRIPCIÓN

La primera forma de foomatic-ppdfile calcula el archivo PPD de Foomatic independiente del spooler para cualquier combinación válida de impresora/controlador disponible en la base de datos de Foomatic, tanto para imprimir con foomatic-rip(1) como para que las aplicaciones/clientes puedan acceder a las opciones de la impresora. El archivo PPD se devuelve en la salida estándar. Si no se especifica el controlador, se utiliza el controlador predeterminado.

La segunda forma del programa foomatic-ppdfile buscará en la base de datos de impresoras y devolverá todas las entradas de impresoras o aquellas cuyos nombres y/o información de modelo coincidan con una expresión regular.

La última forma imprime un mensaje de ayuda y sale.

Opciones

-dnombre_controlador
El nombre (opcional) del controlador a usar. Si no se proporciona el nombre del controlador, se utiliza el controlador predeterminado o el primer controlador de la lista de controladores compatibles de la impresora.
-p
id_impresora El id de la impresora.
-w
Devuelve un archivo PPD que se ajusta a las limitaciones del formato de Microsoft Windows.
-A
Devuelve todas las entradas de impresoras en la base de datos.
-Ppatrón
Devuelve todas las entradas de impresoras en la base de datos que coinciden con la expresión regular.

VER TAMBIÉN

foomatic-rip(1)

ESTADO DE SALIDA

foomatic-ppdfile devuelve 0 en caso de éxito, 1 en caso contrario.
