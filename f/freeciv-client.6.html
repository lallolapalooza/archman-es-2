NOMBRE

freeciv-gtk3.22, freeciv-gtk4, freeciv-sdl2, freeciv-sdl3, freeciv-qt - Los clientes para el juego Freeciv

SINOPSIS

freeciv-gtk3.22|freeciv-gtk4|freeciv-sdl2|freeciv-sdl3|freeciv-qt [ -A|--Announce protocolo ] [ -a|--autoconnect ] [ -d|--debug nivel ] [ -F|--Fatal [ número_de_señal ] ] [ -f|--file nombre_archivo ] [ -h|--help ] [ -l|--log nombre_archivo ] [ -M|--Meta URL ] [ -n|--name nombre ] [ -p|--port puerto ] [ -P|--Plugin cadena ] [ -r|--read nombre_archivo ] [ -s|--server dirección ] [ -S|--Sound nombre ] [ -t|--tiles nombre ] [ -v|--version ] [ -- parámetros_específicos_del_cliente ]

freeciv-gtk3.22 acepta los parámetros estándar de Gtk después de --; ver la documentación de Gtk. También acepta [ -h|--help ] [ -r|--resolution ANCHOxALTO ]

freeciv-gtk4 acepta los siguientes parámetros después de --: [ -h|--help ] [ -r|--resolution ANCHOxALTO ]

freeciv-qt acepta los parámetros estándar de Qt después de --; ver la documentación de Qt. También acepta [ -h|--help ] [ -f|--flags ]

freeciv-sdl3 acepta los siguientes parámetros después de --: [ -f|--fullscreen ] [ -F|--Font ize ] [ -h|--help ] [ -t|--theme cadena ]

DESCRIPCIÓN

Freeciv es un juego de estrategia multijugador por turnos gratuito, en el que cada jugador se convierte en el líder de una civilización, luchando para alcanzar el objetivo final: ser la civilización más grande.

Los jugadores de Civilization II® de Microprose® se sentirán como en casa, ya que uno de los objetivos de Freeciv es tener reglas compatibles.

Freeciv es mantenido por un equipo internacional de programadores y entusiastas, ¡y es sin duda uno de los juegos de red más divertidos y adictivos que existen!

Este es el programa cliente utilizado para conectarse a un servidor Freeciv; vea también freeciv-server(6). freeciv-gtk3.22, freeciv-gtk4, freeciv-qt, freeciv-sdl2 y freeciv-sdl3 también pueden iniciar su propio servidor local para partidas de un solo jugador.

Esta página del manual solo enumera los argumentos de la línea de comandos. Para más detalles sobre el uso de freeciv-gtk3.22, freeciv-gtk4, freeciv-sdl2, freeciv-sdl3 o freeciv-qt, consulte el Manual del Cliente que se puede encontrar en el sitio web de Freeciv, así como la documentación que forma parte de la distribución de Freeciv.

OPCIONES

Todos los clientes aceptan las siguientes opciones. No se pueden combinar; es decir, "-np caesar 5557" no funcionará, en su lugar debería introducir "-n caesar -p 5557". Todas las opciones tienen una forma corta (guion simple y una letra) y una forma larga (doble guion y una palabra completa); sus efectos son idénticos.

-A protocolo, --Announce protocolo
Utiliza protocolo al buscar partidas en una LAN. Los valores posibles para protocolo son:

IPv4

IPv6

none

-a, --autoconnect
Omite el diálogo de conexión, insertando automáticamente los valores predeterminados. Esto es bastante conveniente cuando todo está configurado correctamente.
-d nivel, --debug nivel
Establece la cantidad de información de depuración que se registrará en el archivo especificado por la opción -l. Los valores aceptables para el nivel son:

fatal solo para mensajes fatales.

error para mensajes fatales y de error.

warning para mensajes fatales, de error y de advertencia

normal para mensajes fatales, de error, de advertencia y normales (predeterminado).

verbose para mensajes fatales, de error, de advertencia, normales y detallados.

-F [ número_de_señal ], --Fatal [ número_de_señal ]
Genera una señal personalizada en una aserción fallida. Si no se especifica número_de_señal, se utilizará la señal ABRT.
-f nombre_archivo, --file nombre_archivo
Carga un archivo de partida guardada (nombre_archivo). Esto es para recargar partidas guardadas previamente, o para iniciar escenarios desde la línea de comandos.
-h, --help
Imprime un resumen corto de las opciones estándar de la línea de comandos.
-l nombre_archivo, --log nombre_archivo
Define un archivo de registro, nombre_archivo, que se producirá durante el procesamiento. Utilice la opción -d para establecer cuánto se registrará. Por defecto, los mensajes fatales, de error, de advertencia y normales se imprimen en la salida estándar. Con un archivo de registro, dichos mensajes van al registro en su lugar. Si nombre_archivo ya existe, se anexa.
-M URL, --Meta URL
Especifica la URL del metaserver al que conectarse. Un metaserver es un lugar donde los servidores Freeciv pueden publicar su presencia. Los clientes Freeciv consultan el metaserver para ofrecer a los usuarios una selección de partidas a las que unirse. Por defecto, se utilizará el metaserver estándar gestionado por los mantenedores de Freeciv.
-n nombre, --name nombre
Especifica el nombre de usuario (nombre) a utilizar para conectarse al servidor. Esta opción es crítica al reconectarse a una partida. Tenga en cuenta que es posible que necesite entrecomillar su nombre de usuario.
-p puerto, --port puerto
Especifica el puerto del servidor al que conectarse. Por defecto es 5556; en caso de duda, pregunte al administrador del servidor.
-P cadena, --Plugin cadena
Especifica el plugin a utilizar para la salida de sonido. Las opciones disponibles para cadena son:

none

sdl

-r nombre_archivo, --read nombre_archivo
Especifica un archivo, nombre_archivo, de comandos del servidor que un servidor iniciado por el cliente leerá y procesará automáticamente, como si los hubieras escrito en el prompt del servidor.
-s dirección, --server dirección
Especifica la dirección del servidor de juego al que conectarse. Este servidor puede ejecutarse fácilmente en la misma máquina que el cliente.
-S nombre, --Sound nombre
Especifica el conjunto de sonidos a utilizar. Se buscará un archivo llamado nombre.soundspec en los lugares habituales (ver la sección ARCHIVOS).
-t nombre, --tiles nombre
Especifica los gráficos del mapa ("tiles") que se utilizarán dentro del juego. Se buscará un archivo llamado nombre.tilespec en los lugares habituales (ver la sección ARCHIVOS). Actualmente, los siguientes tilespecs se distribuyen con Freeciv:

• amplio2.tilespec

• cimpletoon.tilespec

• hex2t.tilespec

• isophex.tilespec

• isotrident.tilespec

• trident.tilespec

-v, --version
Imprime el número de versión y sale.
--
Todos los parámetros que sigan a este -- se considerarán como parámetros específicos del cliente.
-- -f, -- --fullscreen
Inicia el cliente en modo de pantalla completa. Solo implementado en los clientes freeciv-sdl2 y freeciv-sdl3.
-- -h, -- --help
Imprime la ayuda de los parámetros específicos del cliente.
-- -r ANCHOxALTO, -- --resolution ANCHOxALTO
Actúa como si la resolución de pantalla fuera ANCHOxALTO. Solo implementado en los clientes freeciv-gtk3.22 y freeiv-gtk4.
-- -t tema, -- --theme

NOMBRE

freeciv-client - cliente de Freeciv

SINOPSIS

freeciv-client [ -a | --autoconnect ] [ -c | --connect HOST ] [ -d | --debuglevel NUM ] [ -f | --file FILE ] [ -h | --help ] [ -i | --interface INTERFACE ] [ -l | --language LANG ] [ -n | --name NAME ] [ -p | --port PORT ] [ -r | --rule RULESET ] [ -s | --scenario SCENARIO ] [ -t | --tiles TILESET ] [ --theme THEME ] [ --verbose ] [ -v | --version ] [ -x | --execute COMMAND ]

DESCRIPCIÓN

El programa freeciv-client es el cliente gráfico para el juego de estrategia multijugador Freeciv.

Freeciv es un juego de estrategia por turnos en el que cada jugador intenta desarrollar una civilización desde la prehistoria hasta la era espacial, compitiendo contra otros jugadores para ver quién puede fundar la mejor civilización. Puedes jugar contra otros jugadores en la misma máquina o a través de la red. Si juegas a través de la red, el servidor se ejecuta normalmente en una máquina y los clientes en otras. Este programa es el cliente.

Hay varios tipos de clientes disponibles. Este manual se refiere al cliente genérico, pero también puede haber manuales específicos para clientes como freeciv-gtk3(6) o freeciv-sdl(6).

El cliente se puede usar para conectarse a un servidor existente, o para iniciar su propio servidor y conectarse a él.

Para iniciar un servidor y conectarse a él, use -c o --connect y omita -n o --name. El servidor se iniciará automáticamente.

Los clientes disponibles incluyen:

  • freeciv-gnome2 - El cliente GNOME2.
  • freeciv-gnome-canvas - El cliente GNOME Canvas.
  • freeciv-gtk2 - El cliente GTK2.
  • freeciv-gtk3 - El cliente GTK3.
  • freeciv-kde - El cliente KDE.
  • freeciv-motif - El cliente Motif.
  • freeciv-sdl - El cliente SDL1.
  • freeciv-sdl2 - El cliente SDL2.
  • freeciv-sdl3 - El cliente SDL3.
  • freeciv-xaw - El cliente Xaw.

OPCIONES

-a, --autoconnect
Autoconecta al servidor en localhost.
-c, --connect HOST
Conecta al servidor en HOST. Si HOST es omitido, se usa localhost. Si el servidor no se está ejecutando, se iniciará uno.
-d, --debuglevel NUM
Establece el nivel de depuración a NUM.
-f, --file FILE
Carga los comandos desde el archivo FILE al inicio.
-h, --help
Muestra un mensaje de ayuda y sale.
-i, --interface INTERFACE
Usa la interfaz especificada. Las interfaces válidas son gtk2, gtk3, gnome2, gnome-canvas, kde, motif, sdl, sdl2, sdl3 y xaw.
-l, --language LANG
Establece el idioma a LANG.
-n, --name NAME
Establece el nombre del jugador a NAME.
-p, --port PORT
Conecta al servidor en el puerto especificado PORT.
-r, --rule RULESET
Usa el conjunto de reglas especificado RULESET.
-s, --scenario SCENARIO
Usa el escenario especificado SCENARIO.
-t, --tiles TILESET
Usa el conjunto de teselas especificado TILESET.
--theme THEME
Utiliza un tema gráfico específico. Solo implementado en los clientes freeciv-sdl2 y freeciv-sdl3.
--verbose
Habilita la salida detallada.
-v, --version
Muestra la información de la versión y sale.
-x, --execute COMMAND
Ejecuta el comando especificado.

EJEMPLOS

freeciv-gtk3.22 --name "Rey Ricardo" --server io.daimi.aau.dk
Inicia el cliente GTK3 usando el nombre Rey Ricardo y conectándose al servidor en io.daimi.aau.dk.
freeciv-sdl3 -a -t trident
Inicia el cliente SDL3 con las teselas trident y se autoconecta a localhost.

ARCHIVOS

~/.freeciv/freeciv-client-rc-[número-versión]
Aquí es donde se almacenarán tus configuraciones locales.
tilespecs
Estos se buscan en la ruta de datos; véase ENTORNO.
soundspecs
Estos se buscan en la ruta de datos; véase ENTORNO.

La utilidad freeciv-modpack(6) puede usarse para localizar y descargar contenido adicional como conjuntos de teselas y conjuntos de sonidos y (solo para servidores iniciados por el cliente) escenarios y conjuntos de reglas; guarda archivos en ~/.freeciv .

ENTORNO

El cliente Freeciv acepta las siguientes variables de entorno:

FREECIV_CAPS
Una cadena que contiene una lista de "capacidades" proporcionadas por el servidor. El valor predeterminado compilado debería ser correcto para la mayoría de los propósitos, pero si está familiarizado con el sistema de capacidades en el código fuente, puede usarlo para imponer algunas restricciones entre clientes y servidor.
FREECIV_COMPRESSION_LEVEL
Establece el nivel de compresión para el tráfico de red.
FREECIV_DATA_ENCODING
Establece la codificación de caracteres utilizada para los archivos de datos, partidas guardadas y cadenas de red). Normalmente no se debería cambiar de UTF-8, ya que ese es el formato de los conjuntos de reglas proporcionados y el protocolo de red estándar.
FREECIV_INTERNAL_ENCODING
Establece la codificación de caracteres utilizada internamente por el cliente freeciv. Generalmente, debe coincidir con el kit de herramientas GUI, por lo que su valor predeterminado depende del cliente específico; la mayoría de los clientes usan UTF-8 por defecto.
FREECIV_LOCAL_ENCODING
Establece la codificación de caracteres local (utilizada para la línea de comandos y la salida de terminal). El valor predeterminado se infiere de otros aspectos del entorno.
FREECIV_MULTICAST_GROUP
Establece el grupo de multidifusión (para la pestaña LAN).
FREECIV_DATA_PATH
Una lista de directorios separados por dos puntos que apuntan a los directorios de datos de freeciv. Por defecto, Freeciv busca en los siguientes directorios, en orden, cualquier archivo de datos: el directorio actual; el subdirectorio "data" del directorio actual; el subdirectorio ".freeciv/"3.2"" en el directorio principal del usuario; y el directorio donde se colocan los archivos al ejecutar "make install". Si no está configurado, los directorios de datos del sistema serán usados.

FREECIV_SAVE_PATH Una lista de directorios separados por dos puntos que apuntan a los directorios de guardado de freeciv. Por defecto, Freeciv busca en los siguientes directorios, en orden, archivos guardados: el directorio actual; y el subdirectorio ".freeciv/saves" en el directorio principal del usuario.

(Esto no afecta a dónde crea el servidor iniciado por el cliente los archivos de partida guardada; estos siempre se crean en ".freeciv/saves" en el directorio principal del usuario.)

FREECIV_SCENARIO_PATH
Una lista de directorios separados por dos puntos que apuntan a los directorios de escenarios de freeciv. Por defecto, Freeciv busca en los siguientes directorios, en orden, archivos de escenario: el directorio actual; el subdirectorio "data/scenarios" del directorio actual; los subdirectorios ".freeciv/"3.2"/scenarios" y luego ".freeciv/scenarios" en el directorio principal del usuario; y el directorio donde se colocan los archivos al ejecutar "make install".

(Esto no afecta a dónde crea el servidor iniciado por el cliente los archivos de escenario; estos siempre se crean en ".freeciv/scenarios" en el directorio principal del usuario.)

FREECIV_OPT
Especifica un archivo para contener configuraciones locales, en lugar de ~/.freeciv/freeciv-client-rc-[número-versión].
HOME
Especifica el directorio principal del usuario.
http_proxy
Establece esta variable apropiadamente cuando se usa un proxy.
LANG o LANGUAGE
Establece el idioma y la configuración regional en algunas plataformas.
LC_ALL o LC_CTYPE
Similar a LANG (ver la documentación de tu sistema).
USER
Especifica el nombre de usuario del usuario actual.
