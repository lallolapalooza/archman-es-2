form_win(3x)

Paquete: ncurses

Licencias: MIT-open-group

form_win(3X) Llamadas a la biblioteca form_win(3X)

NOMBRE

form_win - establecer y romper asociaciones de ventana y subventana de formulario

SINOPSIS

#include <form.h>
int set_form_win(FORM *form, WINDOW *win);
WINDOW *form_win(const FORM *form);
int set_form_sub(FORM *form, WINDOW *sub);
WINDOW *form_sub(const FORM *form);
int scale_form(const FORM *form, int *rows, int *columns);

DESCRIPCIÓN

Cada formulario tiene un par asociado de ventanas de curses. La ventana del formulario muestra cualquier título y borde asociado con la ventana; la subventana del formulario muestra los elementos del formulario que están actualmente disponibles para su selección.

Las primeras cuatro funciones obtienen y establecen esas ventanas. No es necesario establecer ninguna de las ventanas; por defecto, el código del controlador utiliza stdscr para ambas.

En las funciones set_, el argumento de ventana NULL se trata como si fuera stsdcr. Un argumento de formulario NULL se trata como una solicitud para cambiar la ventana o subventana del formulario predeterminada del sistema.

La función scale_form devuelve el tamaño mínimo requerido para la subventana del form.

VALOR DE RETORNO

Las rutinas que devuelven punteros devuelven NULL en caso de error. Las rutinas que devuelven un entero devuelven uno de los siguientes códigos de error:

E_OK
La rutina tuvo éxito.
E_SYSTEM_ERROR
Ocurrió un error del sistema (ver errno(3)).
E_BAD_ARGUMENT
La rutina detectó un argumento incorrecto o fuera de rango.
E_POSTED
El formulario ya ha sido mostrado.
E_NOT_CONNECTED
No hay elementos conectados al formulario.

PORTABILIDAD

Estas rutinas emulan la biblioteca de formularios de System V. No eran compatibles con las versiones 7 o BSD.

AUTORES

Juergen Pfeifer. Páginas del manual y adaptación para new curses por Eric S. Raymond.

VER TAMBIÉN
