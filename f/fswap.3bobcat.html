fswap.3bobcat

FBB::fswap(3bobcat) Función de intercambio rápida FBB::fswap(3bobcat)

NAME

FBB::fswap - función de intercambio rápida genérica

SYNOPSIS

#include <bobcat/fswap>

DESCRIPTION

La información almacenada en los objetos necesita frecuentemente ser intercambiada. Un ejemplo bien conocido es la operación de intercambio necesaria al implementar un operador de asignación sobrecargado. Por ejemplo, la forma genérica del operador de asignación es:

    Class &operator=(Class const &other)
    {
        Class tmp(other);
        swap(tmp);
        return *this;
    }

La funcionalidad de intercambio simplemente intercambia el contenido del objeto actual y otro objeto. La función estándar std::swap llama a la función operator= de la clase para intercambiar objetos. Las implementaciones más recientes podrían usar operaciones de movimiento para aumentar la velocidad del intercambio, pero en ambos casos debe estar disponible alguna forma del operador de asignación. Sin embargo, el intercambio podría ser posible incluso cuando la asignación no lo es. Las clases que tienen miembros de datos de referencia suelen no ofrecer operadores de asignación, pero el intercambio podría ser una operación bien definida.

Es bien conocido que los objetos pueden instalarse en un bloque de memoria usando placement new, utilizando un bloque de memoria del tamaño del objeto para construirlo. Este es el fundamento de la función de plantilla FBB::fswap (intercambio rápido). Esta función de intercambio simplemente usa la memoria ocupada por los objetos para implementar la operación de intercambio y por lo tanto puede usarse con clases que tienen miembros de datos const, miembros de referencia, punteros a memoria asignada, etc. La función simplemente usa un bloque de memoria libre del tamaño del objeto a intercambiar. Luego usa memcpy(3) para intercambiar la información contenida en los dos objetos, usando el bloque de memoria libre como marcador de posición.

Las clases pueden definir miembros de datos que no soportan intercambio rápido. Si tales miembros de datos pueden intercambiarse usando std::swap o su propio miembro swap, entonces se pueden usar versiones sobrecargadas de fswap para intercambiar rápidamente objetos de tales clases. Además, las clases pueden heredar de clases base que no soportan intercambio rápido, pero que ofrecen sus propios miembros swap o pueden intercambiarse usando std::swap. Para estos casos también están disponibles versiones sobrecargadas de fswap. Las clases std::string y std::unordered_map son ejemplos de clases cuyos objetos podrían no poder intercambiarse usando un método de intercambio rápido. Por lo tanto, en la práctica, las clases que definen miembros de tales clases deberían usar una de las funciones sobrecargadas fswap para intercambiar sus objetos.

ENUMERATION

La enumeración SwapMode se usa para especificar un método de intercambio específico:

o
SWAPMEMBER se selecciona por defecto, pero también puede especificarse explícitamente. Indica que los miembros seleccionados se intercambian usando su propio miembro de función swap con la prototipografía void Type::swap(Type &rhs).
o
STDSWAP puede especificarse para indicar que los miembros seleccionados deben intercambiarse usando std::swap. Los miembros específicos que no soportan intercambio rápido siempre pueden intercambiarse usando un método de intercambio específico. Por ejemplo, cuando se selecciona SWAPMEMBER, pero un miembro de datos específico no ofrece un miembro swap, entonces se puede especificar std::swap solo para ese miembro.

SWAP FUNCTIONS

o
fswap(Type &lhs, Type &rhs):
Esta función de plantilla intercambia el contenido de dos objetos. Puede usarse con clases que tienen miembros de datos const, miembros de referencia, miembros de puntero o miembros de datos de tipo de valor estándar;
o
fswap(Type &lhs, Type &rhs, member, ...):
Esta función se proporciona con una lista de nombres de miembros (es decir, miembros de la clase Type) que no soportan intercambio rápido. Esos miembros se intercambian usando su miembro swap, mientras que todos los otros miembros se intercambian rápidamente. Al usar listas de miembros, los miembros seleccionados deben estar listados en el orden de su declaración o se generará una excepción std::runtime_error cuando se usa la función.
o
fswap<SwapMode::SWAPMEMBER>(Type &lhs, Type &rhs, member, ...):
Esta función actúa idénticamente a la función anterior, pero especifica explícitamente su método de intercambio por defecto.
Cada uno de los miembros especificados en la lista de miembros puede especificarse por su nombre, en cuyo caso se usa el método de intercambio especificado. Alternativamente se puede usar stdswap(member), en cuyo caso se usa std::swap para intercambiar member; o swapmember(member) se puede usar, en cuyo caso se usa la función miembro swap de member para intercambiar member;
o
fswap<SwapMode::STDSWAP>(Type &lhs, Type &rhs, member, ...):
Esta función también se proporciona con una lista de nombres de miembros que no soportan intercambio rápido. Esos miembros se intercambian usando std::swap. Al igual que con la función anterior, los miembros pueden especificarse por su nombre, o se puede usar stdswap(member) o swapmember(member);
o
fswap[swapMode](&firstMember, Type &lhs, Type &rhs [, member, ...]):
El primer argumento de esta función es la dirección del primer miembro de datos de Type (generalmente especificado como &d_first dentro del propio miembro swap de Type). Se usa cuando Type hereda de una clase base que en sí misma no soporta intercambio rápido. Esta función puede opcionalmente proporcionarse con un argumento no tipo de plantilla SwapMode (por defecto se usa SWAPMEMBER) y también puede proporcionarse con una lista de miembros (opcionalmente usando stdswap y swapmember).
