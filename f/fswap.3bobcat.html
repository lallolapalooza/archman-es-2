NAME

                        
fswap - bobcat fast-swap

                    

                    

                        
SYNOPSIS

                        
#include <bobcat/fswap>


                    

                    

                        
DESCRIPTION

                        
The fswap functions are
                            designed for fast-swapping the members of classes. It is
                            assumed that the class members are primitive types or
                            classes that themselves implement a swap
                            member, or that they implement a swapmember
                            member which the user may enable.

                        
The function:

                        
template<typename T, typename Object, typename Member>
void fswap(T *member, Object& obj, Object& rhs, Member&& ... members);
                        

                        
swaps the members pointed to by member
                            with the corresponding members of rhs.
                            All other members of obj and rhs
                            are swapped using stdswap by default.
                            This default can be overridden by using template
                            arguments.

                        
The SwapMode enum supports the
                            following modes:

                        

                            
SWAPMEMBER

                            
For each member member(x) swap
                                x.swapmember().

                            
STDSWAP

                            
For each member stdswap(x) swap
                                std::swap(x).

                        

                        
A member swapmember(x) forces the
                            use of a swapmember() member function
                            of x.

                    

                    

                        
NAMESPACE

                        
bobcat

                    

                    

                        
INHERITS FROM

                        
none

                    

                    

                        
ENUMERATION

                        
The SwapMode enumeration:

                        

                            
SwapMode::SWAPMEMBER

                            
used when swapmember() member
                                functions are available.

                            
SwapMode::STDSWAP

                            
used when std::swap() is
                                available.

                        

                    

                    

                        
SWAP FUNCTIONS

                        
The fswap functions:

                        

                            
fswap<SwapMode::SWAPMEMBER>(&d_v1, *this, rhs, d_v3, d_v4);

                            
explicitly requesting the swap
                                method, swapping all members.

                            
fswap<SwapMode::STDSWAP>(&d_v1, *this, rhs, d_v3, d_v4);

                            
explicitly requesting another swap-mode.

                            
fswap(&d_v1, *this, rhs, d_v3, swapmember(d_v4));

                            
use stdswap by default, but not
                                for d_v4, for which .swap()
                                is used.

                            
fswap<SwapMode::STDSWAP>(&d_v1, *this, rhs, d_v3, swapmember(d_v4));

                            
same.

                            
fswap(&d_v1, *this, rhs, swapmember(d_v3), stdswap(d_v4));

                            
explicitly requesting the already default
                                swap method is OK.

                        

                        
void Demo::show(char const *msg)

BUGS

                        
The fswap functions should
                            not be applied mechanically to swap objects of classes
                            having pointer data members defining, e.g., a linked
                            list. Consider a list of four objects like:

                        
    A -> B -> C -> D
                        

                        
fast-swapping B and C would result in the
                            following corrupted list:

                        
               +------+
               |      |
    A -> C -+  +-> B -+   +-> D
            |             |
            +-------------+
                        

                        
However, classes implementing a data structure
                            like a linked-list might still benefit from fast swapping
                            operations: by implementing their own swap member they
                            could first use fast swapping to swap the objects,
                            followed by another fast swap to unswap their
                            `next’ pointers.

                        
The fswap function should also
                            not be used for objects defining (back-)pointers to their
                            own data. Consider the following objects using pointers to
                            data and (back-)pointers to the original objects:

                        
    Before fswapping:
        A                                  B
       +--------+   +-----------+         +--------+   +-----------+
       |        |   |           |         |        |   |           |
     +--> *Aimp------> *A (back)--+     +--> *Bimp------> *B (back)--+
     | |        |   |           | |     | |        |   |           | |
     +--**Aimp  |   +-----------+ |     +--**Bimp  |   +-----------+ |
       +--------+ <---------------+       +--------+ <---------------+
    After fswapping:
                     +-------------------------------+
                  +--|-------------------------------|-+
    +-------------|--|-----------------+             | |
    |   A         |  v                 |   B         | v
    |  +--------+ | +-----------+      |  +--------+ | +-----------+
    |  |        | | |           |      |  |        | | |           |
  +-----> *Bimp---+ |  *A (back)--+    +---> *Aimp---+ |  *B (back)--+
  | |  |        |   |           | |       |        |   |           | |
  | +---**Bimp  |   +-----------+ |    +---**Aimp  |   +-----------+ |
  |    +--------+ <---------------+    |  +--------+ <---------------+
  +------------------------------------+
                        

                        
After the swap **Bimp should
                            point to Bimp’s address (now at
                            A), but in fact it points to Aimp’s
                            address (now at B). Likewise, the back pointers still
                            point at their original objects rather than at their
                            swapped objects.

                        
All stream classes define such
                            pointers and can therefore not be swapped using
                            fswap.

                        
The bottom line being that fswap
                            should only be used for self-defined classes for which it
                            can be proven that fast-swapping does not corrupt the
                            values of its pointer data.
