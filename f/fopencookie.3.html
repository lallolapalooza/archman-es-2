La función fopencookie() permite al programador crear una implementación personalizada para un flujo de E/S estándar. Esta implementación puede almacenar los datos del flujo en una ubicación de su propia elección; por ejemplo, fopencookie() se utiliza para implementar fmemopen(3), que proporciona una interfaz de flujo para datos almacenados en un búfer en

memoria.

NAME

fopencookie - create a stream associated with a cookie-described memory location

LIBRARY

Standard C Library (libc, -lc)

SYNOPSIS

#include <stdio.h>
FILE *fopencookie(void *cookie, const char *mode, cookie_io_functions_t io_funcs);

DESCRIPTION

The fopencookie() function creates a dynamic stream object associated with a user-defined data structure (the "cookie"). The argument cookie is a pointer to this data structure. The argument mode is a string that specifies the access mode for the stream. The argument io_funcs is a pointer to a structure containing pointers to user-defined read, write, seek, and close functions.

The mode argument is used similarly to the argument of the same name for fopen(3). It must begin with "r", "w", or "a" to indicate the desired access mode. Additional characters may follow to specify other attributes. Permitted modes are "r+", "w+", and "a+", each optionally followed by "b" (for binary mode, though this is ignored on Linux).

The io_funcs argument is a pointer to a cookie_io_functions_t structure:

typedef struct {
    ssize_t (*read)(void *cookie, char *buf, size_t size);
    ssize_t (*write)(void *cookie, const char *buf, size_t size);
    int (*seek)(void *cookie, off_t *offset, int whence);
    int (*close)(void *cookie);
} cookie_io_functions_t;

The argument cookie is passed as the first argument to each of the functions pointed to by the members of the io_funcs structure.

The read function should read at most size bytes from the stream associated with cookie and store them in buf. It should return the number of bytes read, or 0 if the end of the stream is reached. On error, it should return -1 and set errno appropriately.

The write function should write size bytes from buf to the stream associated with cookie. It should return the number of bytes written. On error, it should return -1 and set errno appropriately.

The seek function should update the stream's position according to whence and offset, similarly to lseek(2). whence is one of the values SEEK_SET, SEEK_CUR, or SEEK_END. The new stream position should be written to *offset. If the seek operation fails, seek should return -1 and set errno appropriately. Otherwise, it should return 0.

The close function should release any resources associated with the stream (e.g., dynamically allocated memory). It should return 0 on success, and -1 on error.

The fopencookie() function returns a pointer to a stream object that can be used with other standard I/O functions. On error, it returns NULL and sets errno.

Once a stream created by fopencookie() is closed using fclose(3), the stream object is invalidated, and the close function specified in io_funcs is called.

If the stream is created with mode "w+" or "a+", the initial size of the dynamically sized buffer for the cookie should be set up before calling fopencookie().

RETURN VALUE

On success, fopencookie() returns a pointer to the newly created stream. On failure, it returns NULL and sets errno.

EXAMPLES

The following program demonstrates the use of fopencookie(). It creates a stream that writes to a dynamically allocated buffer in memory. It then writes the command-line arguments to this stream. Finally, it reads two bytes out of every five, printing them, until the end of the stream is reached.

The example uses a struct memfile_cookie to hold the buffer, its allocated size, the current end position, and the current file offset. The read, write, seek, and close functions operate on this structure.

The memfile_write function grows the buffer as needed by doubling its size. The memfile_read function reads data from the buffer up to the current offset. The memfile_seek function updates the offset based on the whence parameter. The memfile_close function frees the dynamically allocated buffer.

The main function initializes the cookie, creates the stream using fopencookie(), writes the arguments, and then reads from the stream in chunks of two bytes every five bytes, printing the read data until EOF is reached. Finally, it frees the memory allocated for the buffer (note: the memfile_close function already does this when fclose is called, but the example shows it explicitly freeing it after the stream has been used and implicitly closed by the end of the program). It's important to note that the provided example code seems to be freeing the buffer manually after the stream is potentially still open or implicitly closed, which might lead to double-free issues if not handled carefully. A cleaner approach would rely solely on the memfile_close function being called via fclose to manage the memory.

Note: The example code below demonstrates the functionality but might require careful handling of memory management in a production environment, especially regarding when the cookie's buffer is freed. The `free(mycookie.buf);` call at the end might be redundant or problematic if `fclose(stream)` was intended to be called explicitly before exiting, as `memfile_close` handles the freeing.

#define _GNU_SOURCE
#include <stdio.h>
#include <stdlib.h>
#include <string.h>
#include <sys/types.h>
#include <unistd.h>
#define INIT_BUF_SIZE 4
struct memfile_cookie {
    char   *buf;        /* Dynamically sized buffer for data */
    size_t  allocated;  /* Size of buf */
    size_t  endpos;     /* Number of characters in buf */
    off_t   offset;     /* Current file offset in buf */
};
static ssize_t
memfile_write(void *c, const char *buf, size_t size)
{
    char *new_buff;
    struct memfile_cookie *cookie = c;
    /* Buffer too small? Keep doubling size until big enough.  */
    while (size + cookie->offset > cookie->allocated) {
        new_buff = realloc(cookie->buf, cookie->allocated * 2);
        if (new_buff == NULL)
            return -1;
        cookie->allocated *= 2;
        cookie->buf = new_buff;
    }
    memcpy(cookie->buf + cookie->offset, buf, size);
    cookie->offset += size;
    if (cookie->offset > cookie->endpos)
        cookie->endpos = cookie->offset;
    return size;
}
static ssize_t
memfile_read(void *c, char *buf, size_t size)
{
    ssize_t xbytes;
    struct memfile_cookie *cookie = c;
    /* Fetch minimum of bytes requested and bytes available.  */
    xbytes = size;
    if (cookie->offset + size > cookie->endpos)
        xbytes = cookie->endpos - cookie->offset;
    if (xbytes < 0)     /* offset may be past endpos */
        xbytes = 0;
    memcpy(buf, cookie->buf + cookie->offset, xbytes);
    cookie->offset += xbytes;
    return xbytes;
}
static int
memfile_seek(void *c, off_t *offset, int whence)
{
    off_t new_offset;
    struct memfile_cookie *cookie = c;
    if (whence == SEEK_SET)
        new_offset = *offset;
    else if (whence == SEEK_END)
        new_offset = cookie->endpos + *offset;
    else if (whence == SEEK_CUR)
        new_offset = cookie->offset + *offset;
    else
        return -1;
    if (new_offset < 0)
        return -1;
    cookie->offset = new_offset;
    *offset = new_offset;
    return 0;
}
static int
memfile_close(void *c)
{
    struct memfile_cookie *cookie = c;
    free(cookie->buf);
    cookie->allocated = 0;
    cookie->buf = NULL;
    return 0;
}
int
main(int argc, char *argv[])
{
    cookie_io_functions_t  memfile_func = {
        .read  = memfile_read,
        .write = memfile_write,
        .seek  = memfile_seek,
        .close = memfile_close
    };
    FILE *stream;
    struct memfile_cookie mycookie;
    size_t nread;
    char buf[1000];
    /* Set up the cookie before calling fopencookie().  */
    mycookie.buf = malloc(INIT_BUF_SIZE);
    if (mycookie.buf == NULL) {
        perror("malloc");
        exit(EXIT_FAILURE);
    }
    mycookie.allocated = INIT_BUF_SIZE;
    mycookie.offset = 0;
    mycookie.endpos = 0;
    stream = fopencookie(&mycookie, "w+", memfile_func);
    if (stream == NULL) {
        perror("fopencookie");
        exit(EXIT_FAILURE);
    }
    /* Write command-line arguments to our file.  */
    for (size_t j = 1; j < argc; j++)
        if (fputs(argv[j], stream) == EOF) {
            perror("fputs");
            exit(EXIT_FAILURE);
        }
    /* Read two bytes out of every five, until EOF.  */
    for (long p = 0; ; p += 5) {
        if (fseek(stream, p, SEEK_SET) == -1) {
            perror("fseek");
            exit(EXIT_FAILURE);
        }
        nread = fread(buf, 1, 2, stream);
        if (nread == 0) {
            if (ferror(stream) != 0) {
                fprintf(stderr, "fread failed\n");
                exit(EXIT_FAILURE);
            }
            printf("Reached end of file\n");
            break;
        }
        printf("/%.*s/\n", (int) nread, buf);
    }
    /*
     * The stream is implicitly closed when the program exits.
     * The memfile_close function will be called, freeing the buffer.
     * The explicit free() below is redundant and could cause a double-free
     * if fclose() were called explicitly before exiting.
     */
    // free(mycookie.buf);
    fclose(stream); /* Explicitly close the stream to ensure memfile_close is called */
    exit(EXIT_SUCCESS);
}

NOTES

_FILE_OFFSET_BITS should be defined to be 64 in code that uses non-null seek or that takes the address of fopencookie, if the code is intended to be portable to traditional 32-bit x86 and ARM platforms where off_t's width defaults to 32 bits.
