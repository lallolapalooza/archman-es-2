fputws(3) Manual de funciones de biblioteca fputws(3)

NOMBRE

fputws - escribe una cadena de caracteres anchos en un flujo FILE

BIBLIOTECA

Biblioteca C estándar (libc, -lc)

SINOPSIS

#include <wchar.h>
int fputws(const wchar_t *restrict ws, FILE *restrict stream);

DESCRIPCIÓN

La función fputws() es el equivalente de caracteres anchos de la función fputs(3). Escribe la cadena de caracteres anchos que comienza en ws, hasta pero sin incluir el carácter nulo ancho terminador (L'\0'), en stream.

Para una contraparte sin bloqueo, consulte unlocked_stdio(3).

VALOR DE RETORNO

La función fputws() devuelve un entero no negativo si la operación fue exitosa, o -1 para indicar un error.

ATRIBUTOS

Para una explicación de los términos utilizados en esta sección, consulte attributes(7).

Interfaz Atributo Valor
fputws () Seguridad de hilos MT-Safe

ESTÁNDARES

C11, POSIX.1-2008.

HISTORIAL

POSIX.1-2001, C99.

NOTAS

El comportamiento de fputws() depende de la categoría LC_CTYPE de la configuración regional actual.

En ausencia de información adicional pasada a la llamada fopen(3), es razonable esperar que fputws() escriba realmente la cadena multibyte correspondiente a la cadena de caracteres anchos ws.

VER TAMBIÉN

fputwc(3), unlocked_stdio(3)
