DESCRIPCIÓ

N

El comando frame crea una nueva ventana (dada por el argumento pathName) y la convierte en un widget frame. Opciones adicionales, descritas arriba, pueden especificarse en la línea de comandos o en la base de datos de opciones para configurar aspectos del frame como su color de fondo y su relieve. El comando frame devuelve el nombre de ruta de la nueva

ventana.

Un frame es un widget simple. Su propósito principal es actuar como un espaciador o conte

nedor para diseños de ventanas complejos. Las únicas características de un frame son su
color de fondo y un borde 3-D opcional para hacer que el frame parezca elevado o hundido.

Consulta o modifica las opciones de configuración del widget. Si no se especifica ninguna opción, devuelve una lista describiendo todas las opciones disponibles para pathName (consulte Tk_ConfigureInfo para información sobre el formato de esta lista). Si se especifica opción sin valor, entonces el comando devuelve una lista describiendo la opción nombrada (esta lista será idéntica a la sublista correspondiente del valor devuelto si no se especifica opción). Si se especifica uno o más pares opción-valor, entonces el comando modifica la(s) opción(es) del widget dado para que tengan el(los) valor(es) dado(s); en este caso el comando devuelve una cadena vacía.
