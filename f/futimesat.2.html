futimesat(2) Manual de llamadas al sistema futimesat(2)

NOMBRE

futimesat - cambiar marcas de tiempo de un archivo relativas a un descriptor de archivo de directorio

BIBLIOTECA

Biblioteca C estándar (libc, -lc)

SINOPSIS

#include <fcntl.h>            /* Definición de constantes AT_* */
#include <sys/time.h>
[[deprecated]] int futimesat(int dirfd, const char *path,
                             const struct timeval times[2]);
Requisitos de macro de prueba de características para glibc (ver feature_test_macros(7)):

futimesat():

    _GNU_SOURCE

DESCRIPCIÓN

Esta llamada al sistema está obsoleta. Use utimensat(2) en su lugar.

La llamada al sistema futimesat() opera exactamente de la misma manera que utimes(2), excepto por las diferencias descritas en esta página del manual.

Si path es relativo, entonces se interpreta relativo al directorio al que se refiere el descriptor de archivo dirfd (en lugar de relativo al directorio de trabajo actual del proceso llamante, como hace utimes(2) para un nombre de ruta relativo).

Si path es relativo y dirfd es el valor especial AT_FDCWD, entonces path se interpreta relativo al directorio de trabajo actual del proceso llamante (como utimes(2)).

Si path es absoluto, entonces se ignora dirfd. (Ver openat(2) para una explicación de por qué el argumento dirfd es útil).

VALOR DE RETORNO

En caso de éxito, futimesat() devuelve 0. En caso de error, se devuelve -1 y se establece errno para indicar el error.

ERRORES

Los mismos errores que ocurren para utimes(2) también pueden ocurrir para futimesat(). Los siguientes errores adicionales pueden ocurrir para futimesat():

EBADF
path es relativo pero dirfd no es AT_FDCWD ni un descriptor de archivo válido.
ENOTDIR
path es relativo y dirfd es un descriptor de archivo que se refiere a un archivo que no es un directorio.

VERSIONES

glibc

Si path es NULL, entonces la función envoltorio futimesat() de glibc actualiza las marcas de tiempo para el archivo al que se refiere dirfd.

ESTANDARES

Ninguno.

HISTORIA

Linux 2.6.16, glibc 2.4.

Se implementó a partir de una especificación que se propuso para POSIX.1, pero esa especificación fue reemplazada por la de utimensat(2).

Una llamada al sistema similar existe en Solaris.

VER TAMBIÉN
