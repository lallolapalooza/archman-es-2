FSTMINER(1) Minería de datos de volcados FSTMINER(1)

NOMBRE

fst2miner - Minería de datos de archivos FST

SINTAXIS

fstminer [opción]... [ARCHIVO_FST]

DESCRIPCIÓN

Extrae datos de archivos FST para valores específicos y genera archivos de guardado de gtkwave en la salida estándar para recargas futuras.

OPCIONES

-d,--volcado <nombre_archivo>
Especifica el archivo de volcado de entrada FST.
-m,--coincidir <valor>
Especifica datos de coincidencia "bitwise" (binario, real, cadena)
-x,--hex <valor>
Especifica datos de coincidencia hexadecimales que se convertirán automáticamente a binario para las búsquedas
-n,--nombres
Indica que solo se deben imprimir los nombres de las facilidades en un formato compatible con el archivo de guardado de gtkwave. Al hacer esto, el archivo se puede utilizar para especificar qué trazas se importarán en gtkwave.
-c,--completo
Indica que los resultados no deben detenerse después de la primera coincidencia. Esto se puede utilizar para extraer todos los valores coincidentes en la traza.
-h,--ayuda
Muestra la pantalla de ayuda.

EJEMPLOS

fstminer dumpfile.fst --hex 20470000 -n

Este intenta que coincida el valor hexadecimal 20470000 en todas las facilidades y, cuando se encuentra el valor, solo se imprime el nombre de la facilidad en la salida estándar para generar un archivo de guardado compatible con gtkwave.

LIMITACIONES

fstminer solo imprime la primera vez que se encuentra un valor para una red específica. Esto se hace para reducir el tamaño de los archivos de salida y para ayudar a seguir datos como direcciones a través de un modelo de simulación.
