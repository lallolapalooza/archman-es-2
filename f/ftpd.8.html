FTPD(8) Utilidades de Administración del Sistema FTPD(8)

NOMBRE

ftpd - Servidor del Protocolo de Transferencia de Archivos.

SINOPSIS

ftpd [OPCIÓN...]

DESCRIPCIÓN

Demonio del Protocolo de Transferencia de Archivos, que ofrece el servicio PAM 'ftp'.

-4, --ipv4
restringir el demonio a IPv4
-6, --ipv6
restringir el demonio a IPv6
-a, --auth=AUTH
usar AUTH para la autenticación
-A, --anonymous-only
el servidor está configurado solo para servicio anónimo
-d, --debug
modo de depuración
-D, --daemon
iniciar el ftpd de forma independiente
-l, --logging
aumentar la verbosidad de los mensajes de syslog
--non-rfc2577
ignorar RFC 2577 proporcionando información sobre usuarios ausentes
-p, --pidfile[=PIDFILE]
cambiar la ubicación predeterminada del archivo pid
-q, --no-version
no mostrar la versión en el banner
-t, --timeout=TIMEOUT
establecer el tiempo de inactividad predeterminado
-T, --max-timeout=MAX_TIMEOUT
establecer el valor máximo de tiempo de inactividad permitido
-u, --umask=VAL
establecer el umask predeterminado
AUTH puede ser uno de los siguientes:
default
autenticación de contraseñas
pam
usando el servicio PAM 'ftp'
-?, --help
mostrar esta lista de ayuda
--usage
mostrar un breve mensaje de uso
-V, --version
imprimir la versión del programa

Los argumentos obligatorios u opcionales para las opciones largas también son obligatorios u opcionales para las opciones cortas correspondientes.
