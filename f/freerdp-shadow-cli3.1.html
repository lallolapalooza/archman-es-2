NOMBRE

freerdp-shadow-cli - Una utilidad para compartir una pantalla X vía RDP.

SINOPSIS

freerdp-shadow-cli [/puerto:< número de puerto>] [/ipc-socket:<ipc-socket>] [/monitores:<0,1,2,...>] [/rect:<x,y,w,h>] [+auth] [-may-view] [-may-interact] [/sec:<rdp|tls|nla|ext>] [-sec-rdp] [-sec-tls] [-sec-nla] [-sec-ext] [/sam-file:<archivo>] [/version] [/help]

DESCRIPCIÓN

freerdp-shadow-cli se puede usar para compartir una pantalla X en ejecución como con VNC, pero utilizando RDP en su lugar. También es posible compartir solo partes (rect) de la pantalla.

OPCIONES

/ipc-socket:<ipc-socket>
Si se establece esta opción, se utiliza un socket ipc con la ruta ipc-socket en lugar de un socket TCP.
/puerto:<puerto>
Establece el puerto a utilizar. El valor predeterminado es 3389. Esta opción se ignora si se utiliza ipc-socket.
/monitores:<1,2,3,...>
Selecciona el(los) monitor(es) a compartir.
/rect:<x,y,w,h>
Selecciona un rectángulo dentro del monitor para compartir.
-auth
Deshabilita la autenticación. Si la autenticación está habilitada, se usa PAM con el subsistema X11. No es necesario ejecutar como root, sin embargo, si se ejecuta como usuario, solo el mismo usuario que inició freerdp-shadow-cli puede autenticarse.
Advertencia: Si la autenticación está deshabilitada, *cualquiera* puede conectarse.
-may-view
Los clientes pueden ver sin solicitar confirmación.
-may-interact
Los clientes pueden interactuar sin solicitar confirmación.
/sec:<rdp|tls|nla|ext>
Fuerza una seguridad de protocolo específica
-sec-rdp
Deshabilita la seguridad RDP (predeterminado: activado)
-sec-tls
Deshabilita la seguridad del protocolo TLS (predeterminado: activado)
-sec-nla
Deshabilita la seguridad del protocolo NLA (predeterminado: activado)
+sec-ext
Utiliza la seguridad de protocolo extendida NLA (predeterminado: desactivado)
/sam-file:<archivo>
Archivo SAM de NTLM para la autenticación NLA
/version
Imprime la versión y sale.
/help
Imprime la ayuda y sale.

USO

#NOMBRE_DE_PÁGINA_DE_MANUAL@ - inicia el servidor shadow en el puerto 3389 con seguridad NLA, base de datos SAM en /etc/winpr/SAM
freerdp-shadow-cli /sam-file:SAM.db - lo mismo que lo anterior, pero una base de datos SAM personalizada proporcionada como argumento
freerdp-shadow-cli -sec-nla - inicia el servidor shadow en el puerto 3380 con seguridad TLS/NLA. Esto permite autenticarse contra PAM con usuarios de unix. Tenga en cuenta que la contraseña se transmite en texto plano, como con la autenticación HTTP básica

EJEMPLOS

freerdp-shadow-cli /puerto:12345

Cuando se ejecuta como usuario dentro de una sesión X (por ejemplo, desde un xterm), se abre un socket en el puerto 12345 y la pantalla actual se comparte vía RDP.

ESTADO DE SALIDA

0
Ejecución exitosa del programa.
1
En caso contrario.
