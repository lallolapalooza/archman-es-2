fmax(3) Manual de funciones de biblioteca fmax(3)

NOMBRE

fmax, fmaxf, fmaxl - determinar el máximo de dos números de punto flotante

BIBLIOTECA

Biblioteca matemática (libm, -lm)

SINOPSIS

#include <math.h>
double fmax(double x, double y);
float fmaxf(float x, float y);
long double fmaxl(long double x, long double y);
Requisitos de Macro de Prueba de Funciones para glibc (ver feature_test_macros(7)):

fmax(), fmaxf(), fmaxl():

    _ISOC99_SOURCE || _POSIX_C_SOURCE >= 200112L

DESCRIPCIÓN

Estas funciones devuelven el valor mayor entre x e y.

VALOR DEVUELTO

Estas funciones devuelven el máximo entre x e y.

Si un argumento es NaN, se devuelve el otro argumento.

Si ambos argumentos son NaN, se devuelve un NaN.

ERRORES

No se producen errores.

ATRIBUTOS

Para una explicación de los términos utilizados en esta sección, consulte attributes(7).

Interfaz Atributo Valor
fmax (), fmaxf (), fmaxl () Seguridad de hilos MT-Safe

ESTÁNDARES

C11, POSIX.1-2008.

HISTORIAL

glibc 2.1. C99, POSIX.1-2001.

VER TAMBIÉN

fdim(3), fmin(3)
