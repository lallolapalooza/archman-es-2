ftok(3) Manual de Funciones de Biblioteca ftok(3)

NOMBRE

ftok - convierte una ruta de archivo y un identificador de proyecto en una clave IPC de System V

BIBLIOTECA

Biblioteca C estándar (libc, -lc)

SINOPSIS

#include <sys/ipc.h>

key_t ftok(const char *path, int proj_id);

DESCRIPCIÓN

ftok() utiliza la identidad del archivo nombrado por la ruta dada path (que debe referirse a un archivo existente y accesible) y los 8 bits menos significativos de proj_id (que debe ser distinto de cero) para generar una clave IPC de System V de tipo key_t, adecuada para su uso con msgget(2), semget(2), o shmget(2).

El valor resultante es el mismo para todas las rutas de archivo que nombran el mismo archivo, cuando se usa el mismo valor de proj_id. El valor devuelto debe ser diferente cuando los archivos (existentes simultáneamente) o los identificadores de proyecto difieren.

VALOR DE RETORNO

En caso de éxito, se devuelve el valor key_t generado. En caso de error, se devuelve -1, y errno indica el error como en la llamada al sistema stat(2).

ATRIBUTOS

Para una explicación de los términos utilizados en esta sección, consulte attributes(7).

Interfaz Atributo Valor
ftok () Seguridad de hilos MT-Safe

ESTÁNDARES

POSIX.1-2008.

HISTORIA

POSIX.1-2001.

NOTAS

En algunos sistemas antiguos, el prototipo era:


key_t ftok(char *path, char proj_id);

Hoy en día, proj_id es un int, pero todavía solo se utilizan 8 bits. El uso típico tiene un proj_id de carácter ASCII, por eso se dice que el comportamiento no está definido cuando proj_id es cero.

Por supuesto, no se puede garantizar que el key_t resultante sea único. Típicamente, un intento de "lo mejor posible" combina el byte proj_id dado, los 16 bits inferiores del número de inodo y los 8 bits inferiores del número de dispositivo en un resultado de 32 bits. Las colisiones pueden ocurrir fácilmente, por ejemplo, entre archivos en /dev/hda1 y archivos en /dev/sda1.

EJEMPLOS

Consulte semget(2).

VER TAMBIÉN

msgget(2), semget(2), shmget(2), stat(2), sysvipc(7)
