NOMBRE

fribidi_get_par_direction - obtener la dirección base del párrafo

SINOPSIS

#include <../fribidi/lib/fribidi.h>

FriBidiParType fribidi_get_par_direction
(
const FriBidiCharType *bidi_types,
const FriBidiStrIndex len
);

PARÁMETROS

const FriBidiCharType *bidi_types
Lista de entrada de tipos bidi tal como se devuelve por fribidi_get_bidi_types().

Dado que hay 23 valores posibles para un const FriBidiCharType, no todos se enumeran aquí.

const FriBidiStrIndex len
Longitud de la cadena de entrada.

DESCRIPCIÓN

Esta función encuentra la dirección base de un párrafo individual, tal como se define en la regla P2 del Algoritmo Bidireccional Unicode disponible en http://www.unicode.org/reports/tr9/#P2.

Normalmente no necesita esta función, ya que fribidi_get_par_embedding_levels() sabe cómo calcular la dirección base por sí misma, pero es posible que la necesite para implementar un manejo más sofisticado de la dirección de los párrafos. Tenga en cuenta que puede pasar más de un párrafo a esta función y se devuelve la dirección del primer párrafo no neutral, lo que es una muy buena heurística para establecer la dirección de los párrafos neutrales al principio del texto. Para otros párrafos neutrales, es mejor usar la dirección del párrafo anterior.

VALORES

Dirección base del párrafo. No se devuelve una dirección de párrafo débil, solo LTR, RTL o ON.

Los valores posibles para un FriBidiParType son los siguientes:

FRIBIDI_PAR_LTR
Párrafo de Izquierda a Derecha.
FRIBIDI_PAR_RTL
Párrafo de Derecha a Izquierda.
FRIBIDI_PAR_ON
Párrafo Neutro en Dirección.
FRIBIDI_PAR_WLTR
Párrafo Débil de Izquierda a Derecha.
FRIBIDI_PAR_WRTL
Párrafo Débil de Derecha a Izquierda.
