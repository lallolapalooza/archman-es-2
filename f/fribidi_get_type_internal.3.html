NOMBRE

fribidi_get_type_internal - obtener el tipo bidi del carácter

SINOPSIS

#include <../fribidi/lib/fribidi.h>

FriBidiCharType fribidi_get_type_internal(FriBidiChar ch);

PARÁMETROS

FriBidiChar ch
Carácter de entrada.

DESCRIPCIÓN

Obsoleto. Reemplazado por fribidi_get_bidi_type.

RETORNA

Dado que hay 23 valores posibles para un FriBidiCharType, no se enumeran todos aquí.
