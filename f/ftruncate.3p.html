DESCRIPCIÓ

N

Si fildes no es un descriptor de archivo válido abierto para escritura, la función ftruncate()

fallará.

Si fildes se refiere a un archivo regular, la función ftruncate() hará que el tamaño del archivo se trunque a length. Si el tamaño del archivo excedía previamente a length, los datos extra ya no estarán disponibles para lecturas en el archivo. Si el archivo era previamente más pequeño que este tamaño, ftruncate() aumentará el tamaño del archivo. Si el tamaño del archivo se aumenta, el área extendida aparecerá como si estuviera rellena de ceros. El valor del puntero de búsqueda no será modificado por una llamada a ftruncat

e().

Tras una finalización exitosa, si fildes se refiere a un archivo regular, ftruncate() marcará para actualización las marcas de tiempo de última modificación de datos y de último cambio de estado del archivo, y los bits S_ISUID y S_ISGID del modo del archivo pueden ser borrados. Si la función ftruncate() no tiene éxito, el archivo no se ve

afectado.

Si la solicitud causaría que el tamaño del archivo excediera el límite de tamaño de archivo suave del proceso, la solicitud fallará y la implementación generará la señal SIGXFSZ para el

hilo.

Si fildes se refiere a un directorio, ftruncate()

fallará.

Si fildes se refiere a cualquier otro tipo de archivo, excepto un objeto de memoria compartida, el resultado es

indeterminado.

Si fildes se refiere a un objeto de memoria compartida, ftruncate() establecerá el tamaño del objeto de memoria compartida a length

.

Si el efecto de ftruncate() es disminuir el tamaño de un archivo con memoria mapeada o un objeto de memoria compartida, y páginas enteras más allá del nuevo final fueron previamente mapeadas, entonces las páginas enteras más allá del nuevo final serán

descartadas.

Las referencias a páginas descartadas resultarán en la generación de una señal

SIGBUS.

Si el efecto de ftruncate() es aumentar el tamaño de un objeto de memoria, es indeterminado si el contenido de cua

lquier página mapeada entre el antiguo final de
archivo y el nuevo se vuelca al objeto subyacente.
