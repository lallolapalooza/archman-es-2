ftw.h(0p) Manual del programador POSIX ftw.h(0p)

PROLOG

Esta página del manual forma parte del Manual del programador POSIX. La implementación de Linux de esta interfaz puede diferir (consulte la página del manual de Linux correspondiente para obtener detalles sobre el comportamiento de Linux), o la interfaz puede no estar implementada en Linux.

NOMBRE

ftw.h — recorrido de árboles de archivos

SINOPSIS

#include <ftw.h>

DESCRIPCIÓN

El archivo de cabecera <ftw.h> definirá la estructura FTW, que incluirá al menos los siguientes miembros:

int  base
int  level

El archivo de cabecera <ftw.h> definirá las siguientes constantes simbólicas para usarlas como valores del tercer argumento de la función suministrada por la aplicación que se pasa como segundo argumento a ftw() y nftw():

FTW_F
Archivo que no es un directorio.
FTW_D
Directorio.
FTW_DNR
Directorio sin permiso de lectura.
FTW_DP
Directorio con subdirectorios visitados.
FTW_NS
Tipo desconocido; stat() falló.
FTW_SL
Enlace simbólico.
FTW_SLN
Enlace simbólico que apunta a un archivo inexistente.

El archivo de cabecera <ftw.h> definirá las siguientes constantes simbólicas para usarlas como valores del cuarto argumento de nftw():

FTW_PHYS
Recorrido físico, no sigue enlaces simbólicos. De lo contrario, nftw() sigue los enlaces pero no recorre ningún camino que se cruce a sí mismo.
FTW_MOUNT
El recorrido no cruza un punto de montaje.
FTW_DEPTH
Se visitan todos los subdirectorios antes que el propio directorio.
FTW_CHDIR
El recorrido cambia a cada directorio antes de leerlo.

Se declararán las siguientes funciones y también podrán definirse como macros. Se proporcionarán prototipos de función.

int ftw(const char *, int (*)(const char *, const struct stat *,
    int), int);
int nftw(const char *, int (*)(const char *, const struct stat *,
    int, struct FTW *), int, int);

El archivo de cabecera <ftw.h> definirá la estructura stat y los nombres simbólicos para st_mode y las macros de prueba de tipo de archivo como se describe en <sys/stat.h>.

La inclusión del archivo de cabecera <ftw.h> también puede hacer visibles todos los símbolos de <sys/stat.h>.
