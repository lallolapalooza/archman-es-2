NOMBRE

form_fieldtype - definir tipos de campo de validación

SINOPSIS

#include <form.h>
FIELDTYPE *new_fieldtype(
    bool (* const field_check)(FIELD *, const void *),
    bool (* const char_check)(int, const void *));
int free_fieldtype(FIELDTYPE *fieldtype);
int set_fieldtype_arg(
    FIELDTYPE *fieldtype,
    void *(* const make_arg)(va_list *),
    void *(* const copy_arg)(const void *),
    void  (* const free_arg)(void *));
int set_fieldtype_choice(
    FIELDTYPE *fieldtype,
    bool (* const next_choice)(FIELD *, const void *),
    bool (* const prev_choice)(FIELD *, const void *));
FIELDTYPE *link_fieldtype(FIELDTYPE *type1,
                          FIELDTYPE *type2);

DESCRIPCIÓN

new_fieldtype

La función new_fieldtype crea un nuevo tipo de campo utilizable para la validación de datos. Sus parámetros son punteros a funciones:

field_check
Esta función verifica la validez de una cadena de datos introducida cada vez que el usuario intenta salir de un campo. Tiene dos argumentos:
  • El argumento (FIELD *) se pasa para que el predicado de validación pueda ver el búfer del campo, los tamaños y otros atributos.
  • El segundo argumento es una estructura de bloque de argumentos, sobre la cual se detallará más adelante.
char_check
Esta función valida los caracteres de entrada a medida que se introducen. La biblioteca de formularios se la pasa el carácter a verificar y un puntero a una estructura de bloque de argumentos.

free_fieldtype

La función free_fieldtype libera el espacio asignado para un tipo de validación dado por new_fieldtype.

set_fieldtype_arg

La función set_fieldtype_arg asocia tres funciones de gestión de almacenamiento con un tipo de campo:

make_arg
Esta función se aplica automáticamente a la lista de argumentos que proporciona a set_field_type al adjuntar validación a un campo. Almacena los argumentos en un objeto de bloque de argumentos asignado que se utiliza al validar la entrada.
copy_arg
Las aplicaciones pueden utilizar esta función para copiar bloques de argumentos.
free_arg
Libera una estructura de bloque de argumentos.

Debe proporcionar la función make_arg. Las otras dos son opcionales: puede proporcionar NULL para ellas. En este caso, la biblioteca de formularios asume que make_arg no asigna memoria, sino que simplemente carga el argumento en un único valor escalar.

set_fieldtype_choice

El controlador de formularios solicita REQ_NEXT_CHOICE y REQ_PREV_CHOICE asume que los valores posibles de un campo forman un conjunto ordenado y proporciona al usuario del formulario una forma de moverse por el conjunto.

La función set_fieldtype_choice permite a los programadores de formularios definir funciones sucesoras y predecesoras para el tipo de campo. Estas funciones toman el puntero al campo y una estructura de bloque de argumentos como argumentos.

link_fieldtype

La función link_fieldtype crea un nuevo tipo de campo a partir de los dos tipos dados. Están conectados por una 'O' lógica.

VALOR DE RETORNO

Las rutinas con valor de puntero devuelven NULL en caso de error. Establecen errno según su éxito:

E_OK
La rutina tuvo éxito.
E_BAD_ARGUMENT
La rutina detectó un argumento incorrecto o fuera de rango.
E_SYSTEM_ERROR
Ocurrió un error del sistema, por ejemplo, fallo de malloc.

Las rutinas con valor entero devuelven uno de los siguientes códigos en caso de error:

E_OK
La rutina tuvo éxito.
E_BAD_ARGUMENT
La rutina detectó un argumento incorrecto o fuera de rango.
E_CONNECTED
El campo ya está conectado a un formulario.
E_CURRENT
El campo es el campo actual.
E_SYSTEM_ERROR
Ocurrió un error del sistema (ver errno(3)).

PORTABILIDAD

Estas rutinas emulan la biblioteca de formularios de System V. No se soportaban en las versiones 7 o BSD.
