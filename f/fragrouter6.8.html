fragrouter6(8) IPv6 fragrouter6(8)

NOMBRE

fragrouter6

SINOPSIS

fragrouter6 [-dv -f len -e count -t count] INTERFAZ METODO_EVASION

OPCIONES

  -f len    tamaño de mini fragmentos (opción 64, por defecto 8)
  -e count  contador de saltos a la IDS para evadir (opciones 256 y 512)
  -t count  contador de saltos al destino que lo alcanza
  -v        modo detallado, imprime todos los paquetes procesados para la evasión

Métodos de Evasión


0 sin manipulación
1-31 el número de cabeceras de fragmentación atómica a insertar
32 usa cabeceras de destino para 1-31 en lugar de cabeceras de fragmentación
64 fragmenta cada paquete en piezas de 8 bytes (o cambia con -f)
128 una cabecera de destino grande que fragmenta el paquete
256 inserta datos TCP falsos con un contador de saltos solo para la IDS (-e)
512 inserta un paquete de reinicio de conexión TCP con un contador de saltos solo para la IDS (-e)
1024 inserta datos de fragmentación falsos con un contador de saltos solo para la IDS (-e)
2048 inserta un paquete TCP con datos seq/ack falsos

Realiza evasión de NIDS/NIPS a todos los paquetes definidos que se originan en tu sistema o pasan a través de él. Todos los métodos de evasión se pueden combinar (sumar) con la excepción de que solo se puede usar uno de 64 o 128 a la vez. La opción 1024 se puede usar con 1..31 y 64. Los métodos de evasión se procesan en el siguiente orden: 256, 512, 2048, 1..31/33..63 y luego 64 o 128 y luego 1024. Requiere configurar reglas de ip6tables que salten a NFQUEUE, usa fragrouter6.sh, ¡que es un script de envoltura para ip6tables y fragrouter6!
