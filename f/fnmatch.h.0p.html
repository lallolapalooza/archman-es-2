PROLOG

Esta página del manual forma parte del Manual del programador POSIX. La implementación de Linux de esta interfaz puede diferir (consulte la página del manual de Linux correspondiente para conocer los detalles del comportamiento de Linux) o la interfaz puede no estar implementada en Linux.

NOMBRE

fnmatch.h — tipos de coincidencia de nombres de archivo

SINOPSIS

#include <fnmatch.h>

DESCRIPCIÓN

El archivo de cabecera <fnmatch.h> definirá las siguientes constantes simbólicas:

FNM_NOMATCH
La cadena no coincide con el patrón especificado.
FNM_PATHNAME
<barra> en cadena solo coincide con <barra> en patrón.
FNM_PERIOD
El <punto> inicial en cadena debe coincidir exactamente con <punto> en patrón.
FNM_NOESCAPE
Deshabilita el escape con barra invertida.

Se declarará lo siguiente como una función y también puede definirse como una macro. Se proporcionará un prototipo de función.

int fnmatch(const char *, const char *, int);
