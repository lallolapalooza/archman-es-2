fpurge(3) Manual de Funciones de Biblioteca fpurge(3)

NOMBRE

fpurge, __fpurge - purgar un flujo

BIBLIOTECA

Biblioteca C estándar (libc, -lc)

SINOPSIS

/* No soportado */
#include <stdio.h>
int fpurge(FILE *stream);
/* Soportado */
#include <stdio.h>
#include <stdio_ext.h>
void  __fpurge(FILE *stream);

DESCRIPCIÓN

La función fpurge() limpia los búferes del flujo dado. Para flujos de salida, esto descarta cualquier salida no escrita. Para flujos de entrada, esto descarta cualquier entrada leída del objeto subyacente pero aún no obtenida a través de getc(3); esto incluye cualquier texto devuelto mediante ungetc(3). Ver también fflush(3).

La función __fpurge() hace exactamente lo mismo, pero sin devolver un valor.

VALOR DE RETORNO

Al completarse con éxito, fpurge() devuelve 0. En caso de error, devuelve -1 y establece errno para indicar el error.

ERRORES

EBADF
stream no es un flujo abierto.

ATRIBUTOS

Para una explicación de los términos utilizados en esta sección, consulte attributes(7).

Interfaz Atributo Valor
__fpurge () Seguridad de hilos MT-Safe race:stream

ESTANDARES

Ninguno.

HISTORIA

fpurge()
4.4BSD. No disponible en Linux.
__fpurge()
Solaris, glibc 2.1.95.

NOTAS

Normalmente es un error querer descartar búferes de entrada.

VER TAMBIÉN

fflush(3), setbuf(3), stdio_ext(3)
