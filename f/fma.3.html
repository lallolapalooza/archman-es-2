fma(3) Manual de funciones de biblioteca fma(3)

NOMBRE

fma, fmaf, fmal - multiplicar y sumar en punto flotante

BIBLIOTECA

Biblioteca de matemáticas (libm, -lm)

SINÓPSIS

#include <math.h>
double fma(double x, double y, double z);
float fmaf(float x, float y, float z);
long double fmal(long double x, long double y, long double z);
Requisitos de Macro de Prueba de Funciones para glibc (ver feature_test_macros(7)):

fma(), fmaf(), fmal():

    _ISOC99_SOURCE || _POSIX_C_SOURCE >= 200112L

DESCRIPCIÓN

Estas funciones calculan x * y + z. El resultado se redondea como una operación ternaria única de acuerdo con el modo de redondeo actual (ver fenv(3)).

VALOR DE RETORNO

Estas funciones devuelven el valor de x * y + z, redondeado como una operación ternaria única.

Si x o y es un NaN, se devuelve un NaN.

Si x multiplicado por y es un infinito exacto, y z es un infinito con el signo opuesto, ocurre un error de dominio y se devuelve un NaN.

Si uno de x o y es un infinito, el otro es 0, y z no es un NaN, ocurre un error de dominio y se devuelve un NaN.

Si uno de x o y es un infinito, y el otro es 0, y z es un NaN, ocurre un error de dominio y se devuelve un NaN.

Si x multiplicado por y no es un infinito por cero (o viceversa), y z es un NaN, se devuelve un NaN.

Si el resultado se desborda, ocurre un error de rango y se devuelve un infinito con el signo correcto.

Si el resultado se desborda (underflow), ocurre un error de rango y se devuelve un 0 con signo.

ERRORES

Consulte math_error(7) para obtener información sobre cómo determinar si ha ocurrido un error al llamar a estas funciones.

Los siguientes errores pueden ocurrir:

Error de dominio: x * y + z o x * y es inválido.
Se genera una excepción de punto flotante inválida (FE_INVALID).
Error de rango: desbordamiento del resultado
Se genera una excepción de punto flotante de desbordamiento (FE_OVERFLOW).
Error de rango: desbordamiento (underflow) del resultado
Se genera una excepción de punto flotante de desbordamiento (underflow) (FE_UNDERFLOW).

Estas funciones no establecen errno.

ATRIBUTOS

Para obtener una explicación de los términos utilizados en esta sección, consulte attributes(7).

Interfaz Atributo Valor
fma (), fmaf (), fmal () Seguridad en hilos MT-Safe
