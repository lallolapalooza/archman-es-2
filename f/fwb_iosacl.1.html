NOMBRE

fwb_ipt - Compilador de políticas para ACL de Cisco IOS

SINOPSIS

fwb_iosacl [-vV] [-d wdir] [-4] [-6] [-i] -f archivo_datos.xml nombre_objeto

DESCRIPCIÓN

fwb_iosacl es un componente del compilador de políticas de firewall de Firewall Builder (ver fwbuilder(1)). El compilador lee las definiciones de objetos y la descripción del firewall del archivo de datos especificado con la opción "-f" y genera el archivo de configuración resultante de la ACL de Cisco IOS. La configuración se escribe en el archivo con el mismo nombre que el objeto del firewall, más la extensión ".fw". El compilador genera listas de acceso extendidas para routers Cisco que ejecutan IOS v12.x utilizando la sintaxis "ip access-list <nombre>". El compilador también genera comandos "ip access-group" para asignar listas de acceso a las interfaces. La configuración de ACL generada se puede cargar en el router manualmente o utilizando el instalador integrado en la GUI de fwbuilder(1).

El archivo de datos y el nombre de los objetos del firewall deben especificarse en la línea de comandos. Otros parámetros de la línea de comandos son opcionales.

OPCIONES

-4
Genera el script iptables para la parte IPv4 de la política. Si alguna regla del firewall se refiere a direcciones IPv6, el compilador omitirá estas reglas. Las opciones "-4" y "-6" son excluyentes. Si no se utiliza ninguna de las opciones, el compilador intenta generar ambas partes del script, aunque la generación de la parte IPv6 está controlada por la opción "Habilitar soporte IPv6" en la pestaña "IPv6" del diálogo de configuración avanzada del objeto del firewall. Esta opción está desactivada por defecto.
-6
Genera el script iptables para la parte IPv6 de la política. Si alguna regla del firewall se refiere a direcciones IPv6, el compilador omitirá estas reglas.
-f ARCHIVO
Especifica el nombre del archivo de datos a procesar.
-d wdir
Especifica el directorio de trabajo. El compilador crea el archivo de configuración de ACL en este directorio. Si este parámetro falta, la ACL generada se colocará en el directorio de trabajo actual.
-v
Sé verboso: el compilador imprime mensajes de diagnóstico cuando trabaja.
-V
Imprime el número de versión y sale.
-i
Cuando esta opción está presente, el último argumento en la línea de comandos se supone que es el ID del objeto del firewall en lugar de su nombre.
