NOMBRE

fuzzyflakes - copos de nieve/formas de flores que caen

SINOPSIS

fuzzyflakes [--display host:display.screen] [--foreground color] [--background color] [--window] [--root] [--window-id número][--mono] [--install] [--visual visual] [--delay usecs] [--speed int] [--arms int] [--thickness int] [--bthickness int] [--radius int] [--layers int] [--density int] [--no-db] (-color cadena) (-random-colors) [--fps]

DESCRIPCIÓN

El programa fuzzyflakes dibuja formas de copos de nieve/flores de colores pastel que caen. Inspirado en los créditos del anime "Azumanga Daioh".

OPCIONES

fuzzyflakes acepta las siguientes opciones:

--window
Dibuja en una ventana recién creada. Esta es la opción predeterminada.
--root
Dibuja en la ventana raíz.
--window-id número
Dibuja en la ventana especificada.
--mono
Si está en una pantalla en color, simula estar en una pantalla monocromática.
--install
Instala un mapa de colores privado para la ventana.
--visual visual
Especifica qué visual usar. Los valores legales son el nombre de una clase visual o el número de id (decimal o hexadecimal) de un visual específico.
--delay usecs
El retraso entre los pasos de la animación, en microsegundos. Predeterminado: 250000.
--speed int
Qué tan rápido, 1-50. Predeterminado 10.
--arms int
Cuántos brazos tienen los copos de nieve; predeterminado 5.
--thickness int
Qué tan gruesas hacer las líneas; predeterminado 10 píxeles.
--bthickness int
Qué tan gruesos hacer los bordes; predeterminado 3 píxeles.
--radius int
Radio de los objetos; predeterminado 20 píxeles.
--layers int
Cuántas capas de objetos; predeterminado 3.
--density int
Predeterminado 5.
--no-db
Deshabilita el doble búfer.
--color cadena
El color base para el esquema de color. Se escribe como un triplete hexadecimal con o sin el prefijo #. por ejemplo, fa4563 y #43cd12 son aceptables. Si la saturación de tu color es demasiado baja (<0.03), el generador de colores aleatorios se activará. El color predeterminado es #efbea5
--random-colors
Esto habilita la generación de colores aleatorios. Está deshabilitado por defecto. Anula cualquier cosa de -color
--fps
Muestra la tasa de fotogramas actual y la carga de la CPU.

AMBIENTE

DISPLAY
para obtener el host y el número de pantalla predeterminados.
XENVIRONMENT
para obtener el nombre de un archivo de recursos que anula los recursos globales almacenados en la propiedad RESOURCE_MANAGER.
XSCREENSAVER_WINDOW
El ID de ventana a usar con --root.
