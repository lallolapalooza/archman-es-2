NAME

foomatic-rip - convert document formats to the printer language

SYNOPSIS

foomatic-rip [-v] [-q] [-p] [-P printer] [-d device] [-m mimetypes] [-n job-name] [-N job-id] [-o options] [-j job-sheets] [-L locale] [-D document-format] [-F filter-format] [-r driver-format] [-T driver-options] [-- postscript-file]

DESCRIPTION

The foomatic-rip filter is a universal filter which can take a document in any supported format and convert it into the printer language which is understood by the printer driver.

It is intended to be called by a print spooler like CUPS, LPR, or GTP.

DIRECT, SPOOLER-LESS PRINTING

If you want to use foomatic-rip directly, you can do so by running:

    foomatic-rip -P printer -d device -m mime/type < documentfile

This would send the content of documentfile, which is of the MIME type mime/type, to the printer named printer, using the device device.

If the device is a serial port like /dev/ttyS0 or a parallel port like /dev/lp0, then the print job is sent directly to the printer.

If you want to use the PostScript output of Ghostscript, you can also use foomatic-rip:

    gs -q -dNOPAUSE -dBATCH -sDEVICE=ps2pdfwr -sOutputFile=- - < documentfile | foomatic-rip -P printer -d device -m application/postscript

Also the special command line option -- followed by a PostScript file name is supported.

PRINTING WITH SPOOLER

If you use CUPS, you would configure the printer with the CUPS web interface, e.g. http://localhost:631/ or with the command line tool lpadmin. In this case, you usually select the driver for your printer, and CUPS will automatically configure foomatic-rip to be used as the filter.

The configuration file /etc/cups/printers.conf will contain lines like:

    PrintingAlgorithm=foomatic

In this case, CUPS will pipe the data file to foomatic-rip, and foomatic-rip will automatically find the correct filter chain for the given printer.

CONFIGURATION FILE

The configuration file /etc/foomatic/filter.conf can be used to set default values for the command line options.
