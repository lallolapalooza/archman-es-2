FSCK.F2FS(8) Manual del Administrador del Sistema FSCK.F2FS(8)

NOMBRE

fsck.f2fs - verificar un sistema de archivos F2FS de Linux

SINOPSIS

fsck.f2fs [ -a habilitar corrección automática ] [ -f habilitar corrección forzada ] [ -M mostrar mapa de archivos ] [ -p habilitar modo preen ] [ -t mostrar árbol de directorios almacenado ] [ -d nivel de depuración ] dispositivo

DESCRIPCIÓN

fsck.f2fs se utiliza para verificar un sistema de archivos f2fs (generalmente en una partición de disco). dispositivo es el archivo especial que corresponde al dispositivo (por ejemplo, /dev/sdXX).

El código de salida devuelto por fsck.f2fs es 0 en caso de éxito y -1 en caso de error.

OPCIONES

-a habilitar corrección automática
Habilita la ejecución de la verificación del sistema de archivos solo si el módulo del kernel F2FS ha reportado un error. Está deshabilitado por defecto.
-f habilitar corrección forzada
Habilita la corrección de todas las inconsistencias en la partición.
-M mostrar mapa de archivos
Habilita la visualización de todos los nombres de archivo y números de inodo almacenados en la imagen.
-p habilitar modo preen
Igual que "-a" para soportar la convención general de fsck.
-t mostrar árbol de directorios almacenado
Habilita la visualización de cada entrada de directorio en la partición.
-d nivel de depuración
Especifica el nivel de opciones de depuración. El número por defecto es 0, que muestra mensajes de depuración básicos.

AUTOR

El código de verificación inicial fue escrito por Byoung Geun Kim <bgbg.kim@samsung.com>. Jaegeuk Kim <jaegeuk@kernel.org> revisó la mayoría de las partes del código para permitir la corrección de imágenes corruptas.
