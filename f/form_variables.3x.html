form_variables(3X) Llamadas a biblioteca form_variables(3X)

NOMBRE

TYPE_ALNUM, TYPE_ALPHA, TYPE_ENUM, TYPE_INTEGER, TYPE_IPV4, TYPE_NUMERIC, TYPE_REGEXP - variables globales del sistema de formularios

SINOPSIS

#include <form.h>
FIELDTYPE * TYPE_ALNUM;
FIELDTYPE * TYPE_ALPHA;
FIELDTYPE * TYPE_ENUM;
FIELDTYPE * TYPE_INTEGER;
FIELDTYPE * TYPE_IPV4;
FIELDTYPE * TYPE_NUMERIC;
FIELDTYPE * TYPE_REGEXP;

DESCRIPCIÓN

Estos son los bloques de construcción para la biblioteca de formularios, que definen campos que pueden crearse utilizando las funciones de form_fieldtype(3X). Cada uno proporciona funciones para la validación de campos y caracteres, según el tipo de dato dado.

TYPE_ALNUM

Contiene datos alfanuméricos.

TYPE_ALPHA

Contiene datos alfabéticos.

TYPE_ENUM

Contiene un tipo enumerado.

TYPE_INTEGER

Contiene un entero decimal.

TYPE_IPV4

Contiene una dirección de internet IPv4, por ejemplo, "127.0.0.1".

TYPE_NUMERIC

Contiene un número decimal, con signo y punto decimal opcionales.

TYPE_REGEXP

Contiene una expresión regular.

PORTABILIDAD

La variable TYPE_IPV4 es una extensión no proporcionada por implementaciones anteriores de la biblioteca de formularios.
