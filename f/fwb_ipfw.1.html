NOMBRE

fwb_ipfw - Compilador de políticas para ipfw

SINOPSIS

fwb_ipfw [-vVx] [-d wdir] [-o salida.fw] [-i] -f archivo_datos.xml nombre_objeto

DESCRIPCIÓN

fwb_ipfw es un componente del compilador de políticas de cortafuegos de Firewall Builder (ver fwbuilder(1)). Este compilador genera código para ipfw, un cortafuegos y modelador de tráfico en FreeBSD (ver ipfw(8)). El compilador lee las definiciones de objetos y la descripción del cortafuegos desde el archivo de datos especificado con la opción "-f" y genera la configuración del cortafuegos y un script de activación.

El archivo generado tiene un nombre que comienza con el nombre del objeto del cortafuegos, con la extensión ".fw". Es un script de shell que vacía la política actual y luego carga las nuevas reglas de filtro y NAT.

El archivo de datos y el nombre de los objetos del cortafuegos deben especificarse en la línea de comandos. Otros parámetros de la línea de comandos son opcionales.

OPCIONES

-f ARCHIVO
Especifica el nombre del archivo de datos a procesar.
-o salida.fw
Especifica el nombre del archivo de salida.
-d wdir
Especifica el directorio de trabajo. El compilador crea el script de activación del cortafuegos en este directorio. Si este parámetro falta, todos los archivos se colocarán en el directorio de trabajo actual.
-v
Sea verboso: el compilador imprime mensajes de diagnóstico mientras trabaja.
-V
Imprime el número de versión y sale.
-i
Cuando esta opción está presente, se supone que el último argumento en la línea de comandos es el ID del objeto del cortafuegos en lugar de su nombre.
-x
Genera información de depuración mientras trabaja. Esta opción está destinada únicamente a la depuración y puede producir muchos mensajes crípticos.

NOTAS

El soporte para ipfw se añadió en la versión 1.0.10 de Firewall Builder.
