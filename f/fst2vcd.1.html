FST2VCD(1) Conversión de tipo de archivo FST2VCD(1)

NOMBRE

fst2vcd - Convierte archivos FST a VCD

SINTAXIS

fst2vcd [opción]... [ARCHIVO_FST]

DESCRIPCIÓN

Convierte archivos FST a archivos VCD. Si no se especifica un nombre de archivo de salida, el VCD se emite a la salida estándar.

OPCIONES

-f,--nombre-fst <nombre_archivo>
Especifica el nombre del archivo de entrada FST.
-o,--salida <nombre_archivo>
Especifica un nombre de archivo de salida VCD opcional.
-e,--extensiones
Emite extensiones FST a VCD. Habilitar esto puede crear archivos VCD que no sean legibles por otras herramientas. Generalmente, está destinado a ser utilizado como una herramienta de depuración al desarrollar interfaces de escritura FST para simuladores.
-h,--ayuda
Muestra la ayuda y sale.

EJEMPLOS

Para ejecutar este programa de la forma estándar, escriba:

fst2vcd archivo.fst
La conversión VCD se emite a la salida estándar.
