NOMBRE

fwupd-remotes.d - remotos utilizados para el demonio fwupd.

SINOPSIS

Los directorios /etc/fwupd/remotes.d y /var/fwupd/remotes.d se utilizan para leer información sobre fuentes de metadatos remotos. La descripción completa del formato de archivo y los parámetros posibles se documentan aquí como referencia.

FORMATO DEL ARCHIVO

El archivo consiste en múltiples secciones con parámetros opcionales. Los parámetros son de la forma:

[sección]
clave = valor

El archivo está basado en líneas, cada línea terminada con nueva línea representa un comentario, un nombre de sección o un parámetro.

Los nombres de sección y parámetro distinguen entre mayúsculas y minúsculas.

Solo el primer signo igual en un parámetro es significativo. El espacio en blanco antes o después del primer signo igual se descarta, al igual que el espacio en blanco al principio y al final en un valor de parámetro. El espacio en blanco interno dentro de un valor de parámetro se conserva.

Cualquier línea que comience con un carácter de almohadilla (#) se ignora, al igual que las líneas que solo contienen espacio en blanco.

Los valores que siguen al signo igual en los parámetros son todos cadenas (no se necesitan comillas), enteros sin signo o booleanos, que pueden darse como true o false. Las mayúsculas y minúsculas no son significativas en los valores booleanos, pero se conservan en los valores de cadena.

PARÁMETROS REMOTO

La sección [fwupd Remote] puede contener los siguientes parámetros:

Enabled=false


Si el remoto debe ser considerado al encontrar lanzamientos para dispositivos. Solo los remotos habilitados se actualizan al usar fwupdmgr refresh y al considerar qué actualizaciones están disponibles para cada dispositivo. Este valor se puede modificar usando fwupdmgr enable-remote.

Title=


La descripción de una sola línea para mostrar en cualquier herramienta de interfaz de usuario.

MetadataURI=


La URL de los metadatos de AppStream para descargar y usar. Esto debe tener un sufijo de .xml.gz para metadatos heredados y .xml.xz para el formato más moderno. Solo se admiten los prefijos http://, https:// y file:// aquí.

FirmwareBaseURI=


La URL base opcional de los archivos de gabinete para descargar. Si no se especifica, se utiliza la URL base de MetadataURI. Solo se admiten los prefijos http://, https:// y file:// aquí.

ApprovalRequired=false


Si se establece en true, solo los lanzamientos permitidos explícitamente con fwupdmgr set-approved-firmware se mostrarán en las herramientas de línea de comandos y GUI.

ReportURI=


El punto final a usar para enviar informes de éxito para el firmware obtenido de este remoto, o vacío para deshabilitar esta función.

AutomaticReports=false


Si es true, se envían automáticamente informes de éxito para el firmware obtenido de este remoto después de que se haya completado la actualización del firmware.

AutomaticSecurityReports=false


Si es true, se envían automáticamente informes de seguridad de plataforma HSI al ejecutar fwupdmgr security.

NoPhasedUpdates=false


Si es true, se ignora el control de elegibilidad para la implementación aleatoria por fases del cliente.


La elegibilidad de un sistema para una actualización por fases se determina sembrando el generador de números aleatorios con /etc/machine-id, el nombre del archivo del archivo, y la hora de modificación de la caché remota. Si la semilla se divide por el valor de phased_update proporcionado por los metadatos sin resto, entonces se considera el lanzamiento. Esto también implica que la semilla será diferente en una máquina diferente, para una actualización diferente o si se actualizan los metadatos.

OrderBefore=


Este remoto se ordenará antes que cualquier remoto listado aquí, usando comas como delimitador.


NOTA: Cuando el mismo lanzamiento de firmware está disponible en múltiples remotos, se utilizará el de mayor prioridad.

OrderAfter=


Este remoto se ordenará después de cualquier remoto listado aquí, usando comas como delimitador.

Username=


El nombre de usuario a utilizar para la autenticación BÁSICA al descargar metadatos y firmware de este remoto, y para cargar informes de éxito.

Password=


La contraseña (aunque, en la práctica, será un *token* de usuario) a utilizar para la autenticación BÁSICA al descargar tanto metadatos como firmware de este remoto, y para cargar informes de éxito.

RefreshInterval=


El tiempo en segundos después del cual las herramientas frontales deben volver a descargar la firma de los metadatos, o 0 para volver a descargar cada vez.

NOTAS

El nombre base de la ruta sin la extensión se utiliza para el ID del remoto. Por ejemplo, el archivo remoto /etc/fwupd/remotes.d/lvfs.conf tendrá el ID de lvfs.
