FSTATVFS(3P) Manual del Programador POSIX FSTATVFS(3P)

PRÓLOGO

Esta página manual forma parte del Manual del Programador POSIX. La implementación de Linux de esta interfaz puede diferir (consulte la página manual de Linux correspondiente para detalles del comportamiento de Linux), o la interfaz puede no estar implementada en Linux.

NOMBRE

fstatvfs, statvfs — obtener información del sistema de archivos

SINOPSIS

#include <sys/statvfs.h>
int fstatvfs(int fildes, struct statvfs *buf);
int statvfs(const char *restrict path, struct statvfs *restrict buf);

DESCRIPCIÓN

La función fstatvfs() debe obtener información sobre el sistema de archivos que contiene el archivo referenciado por fildes.

La función statvfs() debe obtener información sobre el sistema de archivos que contiene el archivo nombrado por path.

Para ambas funciones, el argumento buf es un puntero a una estructura statvfs que debe ser rellenada. No se requiere permiso de lectura, escritura o ejecución del archivo nombrado.

Los siguientes indicadores pueden ser devueltos en el miembro f_flag :

ST_RDONLY
Sistema de archivos de solo lectura.
ST_NOSUID
Bits setuid/setgid ignorados por exec.

No está especificado si todos los miembros de la estructura statvfs tienen valores significativos en todos los sistemas de archivos.

VALOR DE RETORNO

Tras la finalización exitosa, statvfs() debe devolver 0. De lo contrario, debe devolver -1 y establecer errno para indicar el error.

ERRORES

Las funciones fstatvfs() y statvfs() deben fallar si:

EIO
Ocurrió un error de E/S mientras se leía el sistema de archivos.
EINTR
Se capturó una señal durante la ejecución de la función.
EOVERFLOW
Uno de los valores a devolver no puede ser representado correctamente en la estructura apuntada por buf.

La función fstatvfs() debe fallar si:

EBADF
El argumento fildes no es un descriptor de archivo abierto.

La función statvfs() debe fallar si:

EACCES
Se denegó el permiso de búsqueda en un componente del prefijo de la ruta.
ELOOP
Existe un bucle en los enlaces simbólicos encontrados durante la resolución del argumento path .
ENAMETOOLONG

La longitud de un componente de una ruta de acceso es mayor que {NAME_MAX}.
ENOENT
Un componente de path no nombra un archivo existente o path es una cadena vacía.
ENOTDIR
Un componente del prefijo de la ruta nombra un archivo existente que no es ni un directorio ni un enlace simbólico a un directorio, o el argumento path contiene al menos un carácter que no es <barra invertida> y termina con uno o más caracteres de <barra invertida> finales, y el último componente de la ruta de acceso nombra un archivo existente que no es ni un directorio ni un enlace simbólico a un directorio.

La función statvfs() puede fallar si:

ELOOP
Se encontraron más de {SYMLOOP_MAX} enlaces simbólicos durante la resolución del argumento path .
ENAMETOOLONG

La longitud de una ruta de acceso excede {PATH_MAX}, o la resolución de la ruta de acceso de un enlace simbólico produjo un resultado intermedio con una longitud que excede {PATH_MAX}.

EJEMPLOS

Obtener Información del Sistema de Archivos Usando fstatvfs()

El siguiente ejemplo muestra cómo obtener información del sistema de archivos para el sistema de archivos en el que reside el archivo nombrado /home/cnd/mod1 , usando la función fstatvfs() . El archivo /home/cnd/mod1 se abre con privilegios de lectura/escritura y el descriptor de archivo abierto se pasa a la función fstatvfs() .

#include <sys/statvfs.h>
#include <fcntl.h>
struct statvfs buffer;
int            status;
...
fildes = open("/home/cnd/mod1", O_RDWR);
status  = fstatvfs(fildes, &buffer);

Obtener Información del Sistema de Archivos Usando statvfs()

El siguiente ejemplo muestra cómo obtener información del sistema de archivos para el sistema de archivos en el que reside el archivo nombrado /home/cnd/mod1 , usando la función statvfs() .

#include <sys/statvfs.h>
struct statvfs buffer;
int            status;
...
status = statvfs("/home/cnd/mod1", &buffer);
