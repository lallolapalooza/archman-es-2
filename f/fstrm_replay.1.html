NOMBRE

fstrm_replay - Reproduce datos guardados de Frame Streams a una conexión de socket.

SINOPSIS

fstrm_replay -t tipo-contenido -r archivo [ -r archivo ... ]
[ -u ruta-socket ] [ -a IP -p puerto ]

fstrm_replay --tipo tipo-contenido
--leer archivo [ --leer archivo ... ]
[ --unix ruta-socket ] [ --tcp IP --puerto puerto ]

DESCRIPCIÓN

fstrm_replay se conecta a un receptor de Frame Streams en el ruta-socket de dominio UNIX o en la dirección y puerto TCP especificados, luego lee y envía datos del tipo-contenido suministrado desde el(los) archivo(s) dado(s).

OPCIONES

-t tipo-contenido | --tipo tipo-contenido
Especifica el tipo-contenido a leer de los archivos y enviar al socket de Frame Streams. Se omiten los archivos cuyo tipo de contenido sea diferente. Si el servidor del socket no acepta el tipo-contenido, fstrm_replay fallará.
-r archivo | --leer archivo
Lee datos del archivo. Se pueden proporcionar varios archivos con múltiples opciones -r. Los archivos que no se puedan abrir, o que no contengan datos válidos de Frame Streams, serán omitidos.
-u ruta-socket | --unix ruta-socket
Se conecta a la ruta-socket de dominio UNIX para escribir datos de Frame Streams. Solo se puede dar una de las opciones -u o -a.
-a IP | --tcp IP
Se conecta a la dirección TCP IP para escribir datos de Frame Streams. Solo se puede dar una de las opciones -u o -a. El uso de -a requiere un puerto proporcionado con -p.
-p puerto | --puerto puerto
Si se proporciona -a, usa el puerto TCP puerto para escribir datos de Frame Streams.

EJEMPLOS

Reproducir datos dnstap a través del socket de dominio UNIX:

fstrm_replay -t protobuf:dnstap.Dnstap \
	-u /var/run/named/dnstap.sock -r dnstap-log.fstrm
