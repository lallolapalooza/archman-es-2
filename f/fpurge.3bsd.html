fpurge(3bsd)

Paquete: libbsd

Licencias: custom

fpurge(3bsd) 3bsd fpurge(3bsd)

NOMBRE

fpurge — vaciar un flujo

BIBLIOTECA

biblioteca “libbsd”

SINOPSIS

#include <stdio.h> (Ver libbsd(7) para el uso de la inclusión.)
int
fpurge(FILE *stream);

DESCRIPCIÓN

La función fpurge() borra cualquier entrada o salida almacenada en búfer en el stream dado. Para flujos de salida, esto descarta cualquier salida no escrita. Para flujos de entrada, esto descarta cualquier entrada leída del objeto subyacente pero aún no obtenida a través de getc(3); esto incluye cualquier texto devuelto mediante ungetc(3).

VALORES DE RETORNO

Al completarse con éxito, se devuelve 0. De lo contrario, se devuelve EOF y la variable global errno se establece para indicar el error.

ERRORES

[EBADF]
stream no es un flujo abierto.

VER TAMBIÉN

fclose(3), fopen(3), setvbuf(3)

HISTORIA

La función fpurge() apareció por primera vez en 4.4BSD-Lite.
