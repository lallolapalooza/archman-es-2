DESCRIPCIÓ

N

La funcionalidad descrita en esta página de referencia está alineada con el estándar ISO C. Cualquier conflicto entre los requisitos descritos aquí y el estándar ISO C no es intencional. Este volumen de POSIX.1‐2017 se subordina al estándar ISO

C.

La función fseek() establecerá el indicador de posición de archivo para el flujo apuntado por stream. Si ocurre un error de lectura o escritura, el indicador de error del flujo será establecido y fseek()

fallará.

La nueva posición, medida en bytes desde el comienzo del archivo, se obtendrá sumando offset a la posición especificada por whence. El punto especificado es el comienzo del archivo para SEEK_SET, el valor actual del indicador de posición de archivo para SEEK_CUR, o el fin del archivo para

SEEK_END.

Si el flujo se va a usar con funciones de entrada/salida de caracteres anchos, la aplicación deberá asegurar que offset sea 0 o un valor devuelto por una llamada anterior a ftell() en el mismo flujo y whence sea

SEEK_SET.

Una llamada exitosa a fseek() borrará el indicador de fin de archivo del flujo y deshará cualquier efecto de ungetc() y ungetwc() en el mismo flujo. Después de una llamada a fseek(), la siguiente operación en un flujo de actualización puede ser de entrada o de

salida.

Si la operación más reciente, distinta de ftell(), en un flujo dado es fflush(), el desplazamiento de archivo en la descripción de archivo abierto subyacente será ajustado para reflejar la ubicación especificada por fseek

().

La función fseek() permitirá que el indicador de posición de archivo sea establecido más allá del final de los datos existentes en el archivo. Si se escriben datos posteriormente en este punto, las lecturas subsiguientes de datos en el hueco devolverán bytes con el valor 0 hasta que se escriban datos realmente en el

hueco.

El comportamiento de fseek() en dispositivos que son incapaces de buscar es definido por la implementación. El valor del desplazamiento de archivo asociado con un tal dispositivo es

indefinido.

Si el flujo es escribible y los datos en búfer no habían sido escritos al archivo subyacente, fseek() causará que los datos no escritos sean escritos al archivo y marcará las marcas de tiempo de última modificación de datos y último cambio de estado del archivo para su

actualización.

En una localización con codificación dependiente del estado, si fseek() restaura el estado de cambio del flujo es definido por la

implementación.

La función fseeko() será equivalente a la función fseek() excepto que el argumento offset es de tipo off

_
t.
