Paquete: ncurses

form_page(3X) Llamadas de biblioteca form_page(3X)

NOMBRE

form_page - establecer y obtener el número de página del formulario

SINOPSIS

#include <form.h>
int set_current_field(FORM *form, FIELD *field);
FIELD *current_field(const FORM *form);
int unfocus_current_field(FORM *form);
int set_form_page(FORM *form, int n);
int form_page(const FORM *form);
int field_index(const FIELD *field);

DESCRIPCIÓN

La función set_current_field establece el campo actual del formulario dado; current_field devuelve el campo actual del formulario dado.

La función unfocus_current_field elimina el foco del campo actual del formulario. En tal estado, las consultas a través de current_field devolverán un puntero nulo.

La función set_form_page establece el número de página del formulario (va a la página n del formulario).

La función form_page devuelve el número de página actual del formulario.

La función field_index devuelve el índice del campo en el array de campos del formulario al que está conectado. Devuelve ERR si el argumento es un puntero nulo o si el campo no está conectado.

VALOR DE RETORNO

Excepto form_page, cada rutina devuelve uno de los siguientes:

E_OK
La rutina se ejecutó correctamente.
E_BAD_ARGUMENT
La rutina detectó un argumento incorrecto o fuera de rango.
E_BAD_STATE
La rutina se llamó desde una función de inicialización o terminación.
E_INVALID_FIELD
El contenido de un campo no es válido.
E_REQUEST_DENIED
El controlador del formulario no pudo procesar la solicitud.
E_SYSTEM_ERROR
Ocurrió un error del sistema (consulte errno(3)).

PORTABILIDAD

Estas rutinas emulan la biblioteca de formularios de System V. No eran compatibles con las versiones 7 o BSD.

La función unfocus_current_field es una extensión de ncurses.

AUTORES
