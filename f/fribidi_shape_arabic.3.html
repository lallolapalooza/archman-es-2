NOMBRE

fribidi_shape_arabic - dar forma a caracteres árabes

SINOPSIS

void fribidi_shape_arabic
(
FriBidiFlags flags,
const FriBidiLevel *embedding_levels,
const FriBidiStrIndex len,
FriBidiArabicProp *ar_props,
FriBidiChar *str
);

PARÁMETROS

FriBidiFlags flags
Indicadores de modelado.
const FriBidiLevel *embedding_levels
No documentado.
const FriBidiStrIndex len
Longitud de la cadena de entrada.
FriBidiArabicProp *ar_props
Propiedades árabes de entrada/salida calculadas por fribidi_join_arabic.

Cadena a modelar.

DESCRIPCIÓN

El modelado real que se realiza depende de los indicadores establecidos. Solo los indicadores que comienzan con FRIBIDI_FLAG_SHAPE_ARAB_ afectan a esta función. Actualmente, estos son:

* FRIBIDI_FLAG_SHAPE_MIRRORING: Realiza el espejado.
* FRIBIDI_FLAG_SHAPE_ARAB_PRES: Modela caracteres árabes a sus glifos de forma de presentación.
* FRIBIDI_FLAG_SHAPE_ARAB_LIGA: Forma ligaduras árabes obligatorias.
* FRIBIDI_FLAG_SHAPE_ARAB_CONSOLE: Realiza un modelado árabe adicional adecuado para texto renderizado en terminales de cuadrícula sin capacidades de renderizado de marcas.

De los anteriores, FRIBIDI_FLAG_SHAPE_ARAB_CONSOLE solo se usa en casos especiales, pero los demás se recomiendan en cualquier entorno que no tenga otros medios para realizar el modelado árabe. El conjunto de indicadores adicionales que habilitan este nivel de soporte árabe tiene un atajo llamado FRIBIDI_FLAGS_ARABIC.
