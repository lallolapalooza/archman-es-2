NOMBRE

fsck.btrfs - no hace nada, con éxito

SINOPSIS

fsck.btrfs [-aApy] [<dispositivo>...]

DESCRIPCIÓN

fsck.btrfs es un tipo de utilidad que debería existir para cualquier sistema de archivos y que se llama durante la configuración del sistema cuando las entradas correspondientes de /etc/fstab contienen un valor distinto de cero para fs_passno, véase fstab(5) https://man7.org/linux/man-pages/man5/fstab.5.html para más información.

Los sistemas de archivos tradicionales necesitan ejecutar su utilidad fsck respectiva en caso de que el sistema de archivos no se desmontara limpiamente y el registro necesite ser reproducido antes del montaje. Esto no es necesario para BTRFS. Debería establecer fs_passno en 0.

Si desea comprobar la consistencia de un sistema de archivos BTRFS o reparar un sistema de archivos dañado, consulte btrfs-check(8) <>. Por defecto, se comprueba la consistencia del sistema de archivos, el modo de reparación se habilita mediante la opción --repair (¡úsela con precaución!).

OPCIONES

Todas las opciones son las mismas y detectan si fsck.btrfs se ejecuta en modo no interactivo y sale con éxito, de lo contrario, muestra un mensaje sobre la comprobación de btrfs.

ESTADO DE SALIDA

Hay dos códigos de salida posibles que se devuelven:

0
Sin error
8
Error operativo, por ejemplo, el dispositivo no existe

FICHEROS

/etc/fstab
