ftpusers(5) Manual de Formatos de Archivo ftpusers(5)

NOMBRE

ftpusers - lista de usuarios que no pueden iniciar sesión a través del demonio FTP

DESCRIPCIÓN

El archivo de texto ftpusers contiene una lista de usuarios que no pueden iniciar sesión utilizando el demonio del servidor (FTP) de Protocolo de Transferencia de Archivos. Este archivo se utiliza no solo con fines de administración del sistema, sino también para mejorar la seguridad dentro de un entorno de red TCP/IP.

El archivo ftpusers típicamente contendrá una lista de usuarios que o bien no tienen necesidad de usar ftp o tienen demasiados privilegios como para permitirles iniciar sesión a través del demonio del servidor FTP. Dichos usuarios usualmente incluyen root, daemon, bin, uucp y news.

Si su demonio de servidor FTP no usa ftpusers, se sugiere que lea su documentación para averiguar cómo bloquear el acceso a ciertos usuarios. El demonio FTP de Washington University (wuftpd) y el demonio FTP Profesional (proftpd) son conocidos por hacer uso de ftpusers.

Formato

El formato de ftpusers es muy simple. Hay un nombre de cuenta (o nombre de usuario) por línea. Las líneas que comienzan con un # se ignoran.

ARCHIVOS

/etc/ftpusers

VER TAMBIÉN

passwd(5), proftpd(8), wuftpd(8)
