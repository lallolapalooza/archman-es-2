NOMBRE

fribidi_get_bracket_types - obtener caracteres entre corchetes

SINOPSIS

#include <../fribidi/lib/fribidi.h>

void fribidi_get_bracket_types
(
const FriBidiChar *str,
const FriBidiStrIndex len,
const FriBidiCharType *types,
FriBidiBracketType *btypes
);

PARÁMETROS

const FriBidiChar *str
Cadena de entrada.
const FriBidiStrIndex len
Longitud de la cadena de entrada.
const FriBidiCharType *types
Tipos bidi de entrada.

Dado que hay 23 valores posibles para un const FriBidiCharType, no se enumeran todos aquí.

FriBidiBracketType *btypes
Caracteres entre corchetes de salida.

DESCRIPCIÓN

Esta función encuentra los caracteres entre corchetes de una cadena de caracteres. Consulte fribidi_get_bracket() para obtener más información sobre los caracteres entre corchetes devueltos por esta función.
