fuzz_dhcpc6(8) IPv6 fuzz_dhcpc6(8)

NOMBRE

fuzz_dhcpc6 Parcialmente basado en código de Brandon Hutcheson y Graeme Neilson

SINOPSIS

fuzz_dhcpc6 [-1|-2|-3|-4|-5|-6|-7|-8|-9|-A|-B|-C|-D|-m] -f mac -l link -v ipv6 -x xid -c client -o options interface

OPCIONES

  -1         fuzz DHCPv6 Solicit
  -2         fuzz DHCPv6 Advertise (predeterminado)
  -3         fuzz DHCPv6 Request
  -4         fuzz DHCPv6 Confirm
  -5         fuzz DHCPv6 Renew
  -6         fuzz DHCPv6 Rebind
  -7         fuzz DHCPv6 Reply
  -8         fuzz DHCPv6 Release
  -9         fuzz DHCPv6 Decline
  -A         fuzz DHCPv6 Reconfigure
  -B         fuzz DHCPv6 Information Request
  -C         fuzz DHCPv6 Relay-Forward
  -D         fuzz DHCPv6 Relay-reply
  -m         también hacer fuzz al tipo de mensaje
  -v ipv6    dirección IPv6 de la víctima (si no se especifica, se ataca a los clientes DHCP que envían mensajes)
  -x xid     ID de transacción de la víctima - cero para aleatorio (ignorado si no se especifica -v) 
  -c client  ID de cliente de la víctima - cero para aleatorio (ignorado si no se especifica -v) 
  -f mac     suplantar la dirección mac
  -l link    suplantar la dirección de enlace
  -o options opciones del mensaje DHCPv6 a enviar (predeterminado: abcdefghijklmonpqr)
       a  OPTION_SERVERID
       b  OPTION_IA_NA
       c  OPTION_IA_TA
       d  OPTION_IAADR
       e  OPTION_ORO
       f  OPTION_PREFERENCE
       g  OPTION_ELAPSED_TIME
       h  OPTION_RELAY_MSG
       i  OPTION_AUTH
       j  OPTION_UNICAST
       k  OPTION_STATUS_CODE
       l  OPTION_RAPID_COMMIT
       m  OPTION_USER_CLASS
       n  OPTION_VENDOR_CLASS
       o  OPTION_VENDOR_OPTS
       p  OPTION_INTERFACE_ID
       q  OPTION_RECONF_MSG
       r  OPTION_RECONF_ACCEPT
Mensajes Fuzz enviados a un cliente DHCPv6
