fpdoc - El generador

de documentación de un
idades Pascal de FPC.

SINOPSI

S

fpdoc --input=inputcommand [--output=output] [--format=fmt]

[--descr=descriptionfile] [-
-package=packagename] [options]

Descripció

n

fpdoc analiza un archivo fuente de unidad de Free Pascal y genera documentación para él. La documentación puede estar en varios formatos (actualmente

HTML y LaTeX). Puede leer varios archivos de descripción que contienen la
descripción de los varios símbolos encontrados en el archivo de la unidad.

Us

o

Puede invocar fpdoc con como únicos argumentos requeridos los argumentos 'input' y 'package'. Debe contener al menos el nombre del

archivo de la unidad para la cual se debe generar la document
ación y el nombre del paquete al cual pertenece la unidad.

Opcione

s

fpdoc tiene varias opciones, la mayoría opcionales, se usarán los valores predeterminados en la mayoría de los

casos.
--conte
nt
Esta opción le indica a fpdoc que genere un archivo de contenido. Un archivo de contenido contiene una lista de todos los anclajes (etiquetas) posibles en el archivo de documentación generado, y puede usarse para crear enlaces cruzados en la documentación de diferentes unidades, usando la opción --im
port.
--cputarget=va
lue
Esta opción le indica a fpdoc para qué CPU generar la documentación. Esto simplemente define las macros de CPU
apropiadas.
--descr=descf
ile
Esta opción especifica el nombre de un archivo de descripción descfile que contiene la documentación real de la unidad. Esta opción puede darse varias veces, para varios archivos de
descripción.
--descr-dir=
dir
Esta opción especifica el nombre de un directorio con archivos de descripción XML, nombrado dir Esta opción puede darse varias veces, para varios directorios de descripción. Esta opción es equivalente a especificar todos los archivos en el directorio con la opción
--descr.
--dont-tr
im
Esta opción le indica a fpdoc que no recorte los espacios en blanco en los archivos XML. Por defecto, los espacios en blanco se recortan de la entrada, lo que puede tener efectos secundarios indeseables en, por ejemplo, etiquetas
PRE.
--dry-r
un
Esta opción le indica a fpdoc que no genere ninguna salida, sino que solo analice toda la entrada. Esto puede usarse con la opción verbose para verificar qué errores quedan en la documentación, o qué es lo que aún
falta.
--format=f
mt
Especifica el formato fmt en el cual se generará la documentación.

--hide-protec
ted
Por defecto, la documentación incluirá descripciones y listados de campos y métodos protegidos en clases u objetos. Esta opción cambia este comportamiento; si se especifica, no se generará documentación para estos métodos. Tenga en cuenta que los métodos o propiedades públicos que se refieran a estos métodos protegidos tendrán entonces un enlace colgante (es decir, no disponible)
.
--html-search=l
ink
Agrega una entrada para una página de búsqueda HTML en la ubicación link en los encabezados de las páginas HTML generadas. No se proporciona ninguna página de búsqueda, esta debe ser creada y proporcionada por el
usuario.
--import=impf
ile
importa un archivo de contenido impfile de otro conjunto de documentación. Esto puede usarse para resolver referencias a elementos dentro de este otro archivo de
documentación;
--input=c
md
Esta opción le indica a fpdoc qué archivo de entrada debe usarse. El argumento cmd puede ser solo un nombre de archivo, pero también puede ser un comando de compilador completo con opciones que conciernen al análisis del código fuente pascal: definiciones, archivos de inclusión, opciones de sintaxis, como se especificarían al compilador de Free Pascal al compilar el archivo. Si se usa un comando completo, entonces debe estar encerrado en comillas simples o dobles, para que el shell no lo divida en partes. Es posible especificar múltiples comandos de entrada; se tratarán uno por uno, y se generará documentación para cada uno de
ellos.
--input-dir=
dir
Esta opción le indica a fpdoc que agregue todos los archivos .pas y .pp en el directorio nombrado cmd como archivos de entrada para el documentador. Esto es equivalente a especificar todos los archivos en el directorio con el comando --i
nput.
--lang=langu
age
Establece el idioma del archivo de salida. Esto principalmente establecerá las cad
enas usadas para los encabezados en varias partes de los archivos de docume
ntación (por defecto están en inglés). Actualmente, las opciones válidas son

--latex-extension=
ext
Establece la extensión a usar para el archivo LaTeX a ext el valor predeterminado es .tex (con el . (punto) incluido)
.
--latex-highli
ght
Activa un resaltador de sintaxis latex interno. Esto aún no está implementado. Por defecto, el resaltado de sintaxis lo proporciona el paquete syntax que viene con
fpc.
--mo-dir=d
ir
Esta opción le indica a fpdoc dónde buscar los archivos de traducción que pueden usarse para internacionalizar la salida de
fpdoc.
--ostarget=va
lue
Esta opción le indica a fpdoc para qué sistema operativo generar la documentación. Esto simplemente define las macros de sistema operativo
apropiadas.
--output=na
me
Esta opción le indica a fpdoc dónde debe generarse el archivo de salida. Cómo se interpreta esta opción depende del formato que se use. Para latex, name se interpreta como el nombre de archivo para el archivo tex. Para todos los demás formatos, name se interpreta como el directorio donde se escribirán todos los archivos de documentación. El directorio se creará si aún no existe. Por defecto, esto equivale al nombre del
paquete.
--package=packagen
ame
Especifica el nombre del paquete. Todas las unidades se documentarán como parte de packagename , que también es el nombre de archivo de salida o directorio predeterminado. Solo se considerarán los nodos de documentación dentro de un nodo de paquete con este nombre al
documentar.
--parse-im
pl
(Experimental) intenta analizar también la implementación de una unidad, esto puede usarse para verificación de
sintaxis.
--project=arch
ivo
Esta opción le indica a fpdoc que lea todas las opciones de un archivo de proyecto. Este es un archivo XML; consulte la documentación para obtener más información sobre el formato de este
archivo.
--show-priva
te
De forma predeterminada, no se genera documentación para métodos o campos privados. Esta opción hace que fpdoc genere documentación también para estos
métodos.
--verbo
se
De forma predeterminada, fpdoc es escaso con la salida. Esto le indica a fpdoc que genere algo más de información sobre lo que está
haciendo.
--warn-no-no
de
Si se especifica esta opción, fpdoc emitirá una advertencia si no encuentra un nodo de descripción para un identificador del que está generando
documentación.
--write-project=arch
ivo
Si se especifica esta opción, fpdoc escribirá un archivo de proyecto fpdoc (en el nombre d
e archivo especificado) que corres
ponda a las opciones de la línea
de comandos proporcionadas.
