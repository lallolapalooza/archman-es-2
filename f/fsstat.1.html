FSSTAT(1) Manual de Comandos Generales FSSTAT(1)

NOMBRE

fsstat - Muestra detalles generales de un sistema de archivos

SINOPSIS

fsstat [-f tipo_fs ] [-i tipo_img] [-o offset_img] [-b tam_sector_dev] [-tvV] imagen [imágenes]

DESCRIPCIÓN

fsstat muestra los detalles asociados con un sistema de archivos. La salida de este comando es específica del sistema de archivos. Como mínimo, se proporcionan los rangos de valores de metadatos (números de inodo) y unidades de contenido (bloques o clústeres). También se proporcionan detalles del Superbloque, como tiempos de montaje y características. Para sistemas de archivos que usan grupos (FFS y EXT2FS), se lista la disposición de cada grupo.

Para un sistema de archivos FAT, la tabla FAT se muestra en un formato condensado. Tenga en cuenta que los datos están en sectores y no en clústeres.

ARGUMENTOS

-t tipo
Imprime solo el tipo de sistema de archivos.
-f tipo_fs
Especifica el tipo de sistema de archivos. Usa '-f list' para listar los tipos de sistemas de archivos compatibles. Si no se proporciona, se usan métodos de autodetección.
-i tipo_img
Identifica el tipo de archivo de imagen, como 'raw'. Usa '-i list' para listar los tipos compatibles. Si no se proporciona, se usan métodos de autodetección.
-o offset_img
El desplazamiento del sector donde comienza el sistema de archivos en la imagen.
-b tam_sector_dev
El tamaño, en bytes, de los sectores del dispositivo subyacente. Si no se proporciona, se usa el valor en el formato de imagen (si existe) o se asumen 512 bytes.
-v
Salida detallada de sentencias de depuración a stderr
-V
Mostrar versión
imagen [imágenes]
La imagen del disco o partición a leer, cuyo formato se proporciona con '-i'. Se pueden dar múltiples nombres de archivo de imagen si la imagen está dividida en varios segmentos. Si solo se da un archivo de imagen y su nombre es el primero de una secuencia (por ejemplo, indicado por terminar en '.001'), los segmentos de imagen subsiguientes se incluirán automáticamente.
