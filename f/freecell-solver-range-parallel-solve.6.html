NOMBRE

freecell-solver-range-parallel-solve - Utilidad de Freecell Solver para resolver un rango de tableros de Microsoft Freecell/Freecell Pro

SINOPSIS

freecell-solver-range-parallel-solve inicio fin paso_impresion [--binary-output-to nombre_archivo] [Argumentos de fc-solve...]

DESCRIPCIÓN

freecell-solver-range-parallel-solve es una aplicación de línea de comandos que resuelve un rango de acuerdos de Freecell de Microsoft Freecell y Freecell Pro.

inicio es el primer tablero a resolver; fin es el último (inclusive) y paso_impresion es la división de los números de tablero en los que se imprimirá un mensaje de estado.

Después de estos tres parámetros obligatorios, se pueden dar varias opciones específicas para la resolución de rangos. (consulte la sección OPCIONES para más información)

Posteriormente, se le puede pasar una línea de comandos de fc-solve que utilizará para resolver cada tablero. Consulte la página del manual de fc-solve(6) para obtener información sobre sus opciones.

OPCIONES

--binary-output-to establece el nombre del archivo en el que se volcará el número de iteraciones necesarias para resolver cada tablero. Este archivo puede ser utilizado posteriormente con optimizadores predeterminados estadísticos, como los que se encuentran en el repositorio de control de versiones de Freecell Solver.
