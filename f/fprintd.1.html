NOMBRE

fprintd - Demonio de gestión de huellas dactilares, y aplicaciones de prueba

SINOPSIS

fprintd-enroll [-f dedo] [nombredeusuario]

fprintd-list nombredeusuario [nombredeusuario...]

fprintd-verify [-f dedo] [nombredeusuario]

fprintd-delete nombredeusuario [nombredeusuario...]

DESCRIPCIÓN

Esta página del manual documenta brevemente las utilidades de línea de comandos de fprintd.

El demonio fprintd se accede a través de D-Bus por esas utilidades de línea de comandos.

ARGUMENTOS

nombredeusuario
El nombre de usuario para el que desea consultar o modificar la base de datos de huellas dactilares.

Tenga en cuenta que fprintd-list y fprintd-delete requieren que se pase al menos un nombre de usuario y admiten varios nombres de usuario.

fprintd-enroll y fprintd-verify usarán el nombre de usuario actual si no se pasa ninguno en la línea de comandos.

-f dedo
Para fprintd-enroll, el dedo a inscribir. Los valores posibles son:

pulgar-izquierdo, índice-izquierdo, medio-izquierdo, anular-izquierdo, meñique-izquierdo, pulgar-derecho, índice-derecho, medio-derecho, anular-derecho, meñique-derecho.

El valor predeterminado es elegir automáticamente, seleccionando el primer dedo disponible para dispositivos deslizantes, o todos los dedos inscritos, para dispositivos de presión.

APLICACIONES DE PRUEBA

fprintd-enroll

Inscribirá el dedo índice derecho del usuario en la base de datos.

fprintd-list

Listará las huellas dactilares inscritas del usuario.

fprintd-verify

Verificará las huellas dactilares del usuario contra la base de datos.

fprintd-delete

Eliminará el dedo índice derecho del usuario de la base de datos.

AUTOR

fprintd fue escrito por Bastien Nocera y Daniel Drake.

DIRECTORIOS

Por defecto, fprintd almacena las huellas dactilares en /var/lib/fprint/
