NOMBRE

freerdp-proxy - Un binario de servidor que permite el proxy MITM de conexiones RDP

SINOPSIS

freerdp-proxy [-h] [--help] [--buildconfig] [--dump-config <archivo de configuración>] [-v] [--version] [<archivo de configuración>]

DESCRIPCIÓN

freerdp-proxy se puede usar para hacer proxy de una conexión RDP entre un servidor de destino y los clientes que se conectan. Los escenarios de uso posibles son:

Proxy
Conectar servidores RDP obsoletos/inseguros desde detrás de un proxy (más seguro)
Análisis
Permitir el análisis detallado del protocolo de características de protocolo (canales) desconocidas (muchas)
Inspección
Proxy MITM para inspección y grabación de sesiones

OPCIONES

-h,--help
Mostrar un texto de ayuda que explique el uso.
--buildconfig
Imprimir la configuración de compilación del proxy y salir.
-v,--version
Imprimir la versión del proxy y salir.
--dump-config
Volcar una plantilla de configuración en <archivo-ini-configuración>
<archivo-ini-configuración>
Iniciar el proxy con la configuración leída de <archivo-ini-configuración>

ADVERTENCIA

El proxy no admite autenticación de forma nativa, sino que actúa simplemente como intermediario. Solo se admiten los modos de seguridad RDP y TLS; NLA fallará en las conexiones al proxy. Para implementar la autenticación, se puede implementar un módulo-proxy que pueda autenticarse contra un backend y mapear usuarios y credenciales conectadas a usuarios y credenciales del servidor de destino.

EJEMPLOS

freerdp-proxy /algun/archivo/de/configuracion

freerdp-proxy --dump-config /algun/archivo/de/configuracion

PREPARACIÓN

1. generar certificados para el proxy

winpr-makecert -rdp -path . proxy

2. generar configuración del proxy

freerdp-proxy --dump-config proxy.ini

3. editar configuración y:


* proporcionar rutas (preferiblemente absolutas) para CertificateFile y PrivateKeyFile generados previamente
* eliminar CertificateContents y PrivateKeyContents
* ajustar la configuración [Server] Host y Port para enlazar un puerto específico en una interfaz de red
* ajustar la configuración [Target] Host y Port al servidor de destino RDP
* ajustar (o eliminar si no se usa) la configuración Plugins

3. iniciar el servidor proxy


freerdp-proxy proxy.ini
