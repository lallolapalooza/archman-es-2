newlocale(3) Manual de Funciones de Biblioteca newlocale(3)

NOMBRE

newlocale, freelocale - crear, modificar y liberar un objeto de configuración regional

BIBLIOTECA

Biblioteca C estándar (libc,-lc)

SINOPSIS

#include <locale.h>
locale_t newlocale(int category_mask, const char *locale,
                   locale_t base);
void freelocale(locale_t locobj);
Requisitos de la macro de prueba de características para glibc (ver feature_test_macros(7)):

newlocale(), freelocale():

    Desde glibc 2.10:
        _XOPEN_SOURCE >= 700
    Antes de glibc 2.10:
        _GNU_SOURCE

DESCRIPCIÓN

La función newlocale() crea un nuevo objeto de configuración regional, o modifica un objeto existente, devolviendo una referencia al objeto nuevo o modificado como resultado de la función. Si la llamada crea un nuevo objeto o modifica uno existente se determina por el valor de base:

•
Si base es (locale_t) 0, se crea un nuevo objeto.
•
Si base se refiere a un objeto de configuración regional existente válido (es decir, un objeto devuelto por una llamada previa a newlocale() o duplocale(3)), entonces ese objeto es modificado por la llamada. Si la llamada es exitosa, el contenido de base queda sin especificar (en particular, el objeto al que se refiere base puede ser liberado, y un nuevo objeto creado). Por lo tanto, el llamador debe asegurarse de dejar de usar base antes de la llamada a newlocale(), y debe referirse posteriormente al objeto modificado a través de la referencia devuelta como resultado de la función. Si la llamada falla, el contenido de base permanece válido y sin cambios.

Si base es el objeto de configuración regional especial LC_GLOBAL_LOCALE (ver duplocale(3)), o no es (locale_t) 0 y no es un identificador de objeto de configuración regional válido, el comportamiento es indefinido.

El argumento category_mask es una máscara de bits que especifica las categorías de configuración regional que deben establecerse en un objeto de configuración regional recién creado o modificadas en un objeto existente. La máscara se construye mediante una operación OR bit a bit de las constantes LC_ADDRESS_MASK, LC_CTYPE_MASK, LC_COLLATE_MASK, LC_IDENTIFICATION_MASK, LC_MEASUREMENT_MASK, LC_MESSAGES_MASK, LC_MONETARY_MASK, LC_NUMERIC_MASK, LC_NAME_MASK, LC_PAPER_MASK, LC_TELEPHONE_MASK, y LC_TIME_MASK. Alternativamente, la máscara puede especificarse como LC_ALL_MASK, que es equivalente a hacer OR de todas las constantes anteriores.

Para cada categoría especificada en category_mask, los datos de configuración regional de locale se usarán en el objeto devuelto por newlocale(). Si se está creando un nuevo objeto de configuración regional, los datos para todas las categorías no especificadas en category_mask se toman de la configuración regional predeterminada ("POSIX").

Los siguientes valores preestablecidos de locale están definidos para todas las categorías que pueden especificarse en category_mask:

"POSIX"
Un entorno de configuración regional mínimo para programas en lenguaje C.
"C"
Equivalente a "POSIX".
""
Un entorno nativo definido por la implementación que corresponde a los valores de las variables de entorno LC_* y LANG (ver locale(7)).

freelocale()

La función freelocale() desasigna los recursos asociados con locobj, un objeto de configuración regional devuelto previamente por una llamada a newlocale() o duplocale(3). Si locobj es LC_GLOBAL_LOCALE o no es un identificador de objeto de configuración regional válido, los resultados son indefinidos.

Una vez que un objeto de configuración regional ha sido liberado, el programa no debe hacer más uso de él.

VALOR DE RETORNO

En caso de éxito, newlocale() devuelve un identificador que puede usarse en llamadas a duplocale(3), freelocale(), y otras funciones que toman un argumento locale_t . En caso de error, newlocale() devuelve (locale_t) 0, y establece errno para indicar el error.

ERRORES

EINVAL
Uno o más bits en category_mask no corresponden a una categoría de configuración regional válida.
EINVAL
locale es NULL.
ENOENT
locale no es un puntero de cadena que se refiera a una configuración regional válida.
ENOMEM
Memoria insuficiente para crear un objeto de configuración regional.

ESTÁNDARES

POSIX.1-2008.

HISTORIA

glibc 2.3.

NOTAS

Cada objeto de configuración regional creado por newlocale() debe ser desasignado usando freelocale().

EJEMPLOS

El programa de abajo toma hasta dos argumentos de línea de comandos, que identifican configuraciones regionales. El primer argumento es requerido, y se usa para establecer la categoría LC_NUMERIC en un objeto de configuración regional creado usando newlocale(). El segundo argumento de línea de comandos es opcional; si está presente, se usa para establecer la categoría LC_TIME del objeto de configuración regional.

Después de crear e inicializar el objeto de configuración regional, el programa lo aplica usando uselocale(3), y luego prueba el efecto de los cambios de configuración regional mediante:

(1)
Mostrar un número de punto flotante con una parte fraccionaria. Esta salida se verá afectada por la configuración de LC_NUMERIC . En muchas configuraciones regionales de idiomas europeos, la parte fraccionaria del número se separa de la parte entera usando una coma, en lugar de un punto.
(2)
Mostrar la fecha. El formato y el idioma de la salida se verán afectados por la configuración de LC_TIME .

Las siguientes sesiones de shell muestran algunos ejemplos de ejecución de este programa.

Establecer la categoría LC_NUMERIC en fr_FR (francés):


$ ./a.out fr_FR;
123456,789
Fri Mar  7 00:25:08 2014

Establecer la categoría LC_NUMERIC en fr_FR (francés), y la categoría LC_TIME en it_IT (italiano):


$ ./a.out fr_FR it_IT;

ven 07 mar 2014 00:26:01 CET

Especificar la configuración de LC_TIME como una cadena vacía, lo que hace que el valor se tome de la configuración de las variables de entorno (que, en este caso, especifican mi_NZ, maorí de Nueva Zelanda):


$ LC_ALL=mi_NZ ./a.out fr_FR ""
123456,789
Te Paraire, te 07 o Poutū-te-rangi, 2014 00:38:44 CET

NAME


freelocale - free a locale object






LIBRARY


Realtime library (libc, -lrt)






SYNOPSIS


#include <locale.h>
void freelocale(locale_t loc);







DESCRIPTION


The freelocale function frees the memory
    associated with the locale object referenced by loc.
    The locale object must have been previously created by a call to
    newlocale() or duplocale().


If loc refers to the current locale for
    the calling thread (as returned by uselocale with a
    category like LC_GLOBAL_LOCALE), then calling
    freelocale is a subclass violation.


The behavior is undefined if loc was not
    obtained from newlocale() or duplocale().






RETURN VALUE


None.






ERRORS


None. The function does not set errno.






STANDARDS


POSIX.1-2008.






HISTORY


POSIX.1-2001.






NOTES


The locale object loc must not be in use by
    the calling thread when freelocale is called. If the
    locale object is the current locale for the thread, the thread's locale
    should be reset to LC_GLOBAL_LOCALE using
    uselocale before calling
    freelocale.






EXAMPLES


The following program creates a new locale based on the existing
    "de_DE.UTF-8" locale, applies it to the current thread, performs some
    locale-dependent operations, and then frees the locale object.


#include <locale.h>
#include <stdio.h>
#include <stdlib.h>
#include <time.h>
#include <err.h>

int
main(void)
{
    locale_t loc;
    locale_t nloc;
    time_t t;
    struct tm *tm;
    char buf[256];
    size_t s;

    /* Create a new locale object for "de_DE.UTF-8". */
    nloc = newlocale(LC_ALL, "de_DE.UTF-8", NULL);
    if (nloc == (locale_t) NULL)
        err(EXIT_FAILURE, "newlocale");

    /* Apply the new locale to this thread. */
    loc = uselocale(nloc);
    if (loc == (locale_t) NULL)
        err(EXIT_FAILURE, "uselocale");

    /* Test effect of LC_NUMERIC. */
    printf("%8.3f\n", 123456.789);

    /* Test effect of LC_TIME. */
    t = time(NULL);
    tm = localtime(&t);
    if (tm == NULL)
        err(EXIT_FAILURE, "time");
    s = strftime(buf, sizeof(buf), "%c", tm);
    if (s == 0)
        err(EXIT_FAILURE, "strftime");
    printf("%s\n", buf);

    /* Free the locale object. */
    /* Restore the previous locale for this thread so 'loc' is no longer in use */
    if (uselocale(loc) == (locale_t) NULL)
        err(EXIT_FAILURE, "uselocale");
    freelocale(loc); /* Free the old locale object */

    loc = uselocale(nloc); /* Use the new locale again */
    freelocale(nloc); /* Free the new locale object */
    
    /* Restore the global locale */
    uselocale(LC_GLOBAL_LOCALE);

    exit(EXIT_SUCCESS);
}
