uint32_t LIBMTP_Create_Folder (LIBMTP_mtpdevice_t * device, char * name, uint32_t parent_id, uint32_t storage_id)

Esta función crea una carpeta en el dispositivo MTP actual. El nombre PTP para una carpeta es 'association'. Los dispositivos PTP/MTP no tienen realmente un concepto interno de 'carpeta'; contienen una lista plana de todos los archivos y algunos archivos son 'associations' a los que otros archivos y carpetas pueden referirse como su 'padre'.

Parámetros

device un puntero al dispositivo en el que crear la carpeta.
name el nombre de la nueva carpeta. Tenga en cuenta que esto puede ser modificado si el dispositivo no soporta todos los caracteres del nombre.
parent_id id de la carpeta padre a la que añadir la nueva carpeta, o 0xFFFFFFFF para ponerla en el directorio raíz.
storage_id id del almacenamiento al que añadir esta nueva carpeta. Tenga en cuenta que no puede emparejar mal el id de almacenamiento y el id del padre: ¡ambos deben estar en el mismo almacenamiento! Pase 0 si desea crear esta carpeta en el almacenamiento predeterminado.

Devuelve

id de la nueva carpeta o 0 si ocurrió un error

void LIBMTP_destroy_folder_t (LIBMTP_folder_t * folder)

Esta función borra recursivamente la memoria de una estructura de carpeta. Esto normalmente se debe llamar en una lista de carpetas de nivel superior para destruir el árbol completo de carpetas.

Parámetros

folder estructura de carpeta a destruir

int LIBMTP_Set_Folder_Name (LIBMTP_mtpdevice_t * device, LIBMTP_folder_t * folder, const char * newname)

Esta función renombra una sola carpeta. Esto simplemente significa que la propiedad PTP_OPC_ObjectFileName se actualiza, si esto es soportado por el dispositivo.

Parámetros

device un puntero al dispositivo que contiene el archivo.
folder los metadatos de la carpeta a renombrar. En caso de éxito, el miembro name se actualiza. Tenga en cuenta que este nombre puede ser diferente a newname dependiendo de las restricciones del dispositivo.
newname el nuevo nombre para este objeto.

Devuelve

0 en caso de éxito, cualquier otro valor significa fallo.

Referencias LIBMTP_folder_struct::folder_id, y LIBMTP_folder_struct::name.
