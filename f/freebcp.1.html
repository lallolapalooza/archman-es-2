FREEBCP(1) Manual de Comandos Generales FREEBCP(1)

NOMBRE

freebcp — utilidad de carga masiva para bases de datos Sybase y Microsoft

SINOPSIS

freebcp [[⟨base_de_datos⟩.]⟨esquema⟩.]⟨nombre_objeto⟩ {in | [query]out} archivo_datos {-c | -n | -f archivo_formato} [-S nombre_servidor] [-D nombre_db] [-U nombre_usuario] [-P contraseña] [-b tamaño_lote] [-F fila_inicial] [-L fila_final] [-e archivo_errores] [-I interfaces] [-m max_errores] [-t terminador_campo] [-r terminador_fila] [-h pistas] [-T tamaño_texto] [-A tamaño_paquete] [-O opciones] [-i archivo_entrada] [-o archivo_salida] [-C conjunto_caracteres] [-EdVv]

DESCRIPCIÓN

freebcp es un programa de utilidad distribuido con FreeTDS. freebcp replica (al menos en parte) la funcionalidad de los programas de utilidad bcp distribuidos por Sybase y Microsoft. freebcp utiliza la API bcp de DB-Library proporcionada por FreeTDS. Esta API también está disponible para los desarrolladores de aplicaciones.

Se puede consultar las páginas del manual o la ayuda en línea de Sybase o SQL Server para obtener información más detallada sobre la funcionalidad de bcp.

TABLAS Y ARCHIVOS

base_de_datos
El nombre de la base de datos que contiene el objeto a copiar. Opcional si la tabla/vista está en la base de datos predeterminada para nombre_usuario.
esquema
El esquema del objeto que se está copiando. Si no se proporciona, se utiliza el esquema predeterminado para nombre_usuario.
objeto
El nombre del objeto de base de datos al que desea acceder, normalmente una tabla. También puede ser una vista. Todas las vistas se pueden leer; algunas se pueden escribir, sujetas a restricciones. Con queryout, objeto también puede ser una consulta SQL.
in
Copiar datos de un archivo del host a una tabla de base de datos.
out
Copiar datos de una tabla de base de datos a un archivo del host.
queryout
indica que nombre_tabla es en realidad SQL, en lugar de un objeto de base de datos. freebcp ejecutará la consulta y escribirá los resultados en un archivo. (Es una buena idea que la consulta devuelva uno y solo un conjunto de resultados).
archivo_datos
El nombre de un archivo del sistema operativo.

OPCIONES

-A tamaño_paquete
Establece el tamaño de un paquete TDS en tamaño_paquete. No está claro por qué querrías hacer esto, excepto como experimento.
-D nombre_db
El nombre de la base de datos predeterminada a usar. Anula la base de datos predeterminada asociada con la cuenta de inicio de sesión. Hace que freebcp emita un comando USE nombre_db inmediatamente después de iniciar sesión, antes de comenzar las operaciones de BCP.
-E
Escribe los datos en archivo_datos en la columna IDENTITY de la tabla. Sin esta bandera, los datos de identidad presentes en archivo_datos se ignorarán, y se generarán nuevos valores IDENTITY para las filas importadas.
-F fila_inicial
La primera fila a copiar del archivo de entrada o tabla de base de datos. El valor predeterminado es la primera fila, fila 1.
-I interfaces
El nombre y la ubicación del archivo de interfaces a buscar al conectarse a nombre_servidor. Anula freetds.conf.
-L fila_final
La última fila a copiar de un archivo de entrada o tabla de base de datos. El valor predeterminado es la última fila.
-O opciones
Texto SQL para establecer opciones de conexión antes de la operación bcp. Si opciones es un nombre de archivo válido, el SQL se lee del archivo en su lugar. A veces es necesario para queryout. Ejemplo: -O `SET QUOTED_IDENTIFIER ON'.
-P contraseña
La contraseña asociada con nombre_usuario.
-S nombre_servidor
El nombre del Servidor de Base de Datos al que conectarse.
-T tamaño_texto
Para columnas de texto o imagen, establece el número máximo de caracteres a solicitar del servidor. Predeterminado a la configuración en freetds.conf. Si no se especifica en ningún lugar, se utiliza el tamaño completo de los datos.
-U nombre_usuario
Un nombre de inicio de sesión de base de datos. Para conexiones TDS 7+, se intenta un inicio de sesión de dominio si no se proporciona nombre_usuario.
-b tamaño_lote
El número de filas por lote de datos copiados. La agrupación en lotes solo se aplica cuando se copian datos masivamente en la base de datos. Cada lote de datos se “confirma” efectivamente en la base de datos. El valor predeterminado para tamaño_lote es 1000.
-c
El archivo de datos del host está (o estará) en formato de "carácter", es decir, un archivo de texto. La codificación se determina por el atributo charset del cliente en freetds.conf.
-d
Desactiva cualquier registro. (Poco intuitivo, quizás).
-e archivo_errores
Escribe errores en archivo_errores. Para cargas. Incluye información de línea y columna, y los datos de la fila.
-f archivo_formato
El formato del archivo de datos del host se describe mediante archivo_formato. La disposición de archivo_formato es idéntica a la que entienden las utilidades bcp de Sybase y Microsoft, pero es demasiado complicada para describirla aquí.
-h pistas
Establece pistas de bcp. Para valores válidos, véase bcp_options() en el Manual de Referencia de FreeTDS.
-m max_errores
Detener después de encontrar max_errores errores. Predeterminado 10.
-n
El archivo de datos del host está en formato "nativo". Este es un formato que freebcp podrá procesar, pero no es portable ni legible.
