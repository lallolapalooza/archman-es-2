NOMBRE

form_field - establecer y romper conexiones entre campos y formularios

SINOPSIS

#include <form.h>
int set_form_fields(FORM *form, FIELD **fields);
FIELD **form_fields(const FORM *form);
int field_count(const FORM *form);
int move_field(FIELD *field, int frow, int fcol);

DESCRIPCIÓN

La función set_form_fields cambia el array de punteros de campo del form dado. El array debe estar terminado con NULL.

La función form_fields devuelve el array de campos del formulario dado.

La función field_count devuelve el recuento de campos en form.

La función move_field mueve el campo dado (que debe estar desconectado) a una ubicación especificada en la pantalla.

VALOR DE RETORNO

La función form_fields devuelve un puntero (que puede ser NULL). No establece errno.

La función field_count devuelve ERR si el parámetro form es NULL.

Las funciones set_form_fields y move_field devuelven uno de los siguientes códigos en caso de error:

E_OK
La rutina tuvo éxito.
E_BAD_ARGUMENT
La rutina detectó un argumento incorrecto o fuera de rango.
E_CONNECTED
El campo ya está conectado a un formulario.
E_POSTED
El formulario ya está publicado.
E_SYSTEM_ERROR
Ocurrió un error del sistema (ver errno(3)).

PORTABILIDAD

Estas rutinas emulan la biblioteca de formularios de System V. No eran compatibles con las versiones 7 o BSD.

La documentación de la biblioteca de formularios SVr4 especifica que el valor de error de field_count es -1 (que es el valor de ERR).
