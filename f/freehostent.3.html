getipnodebyname(3) Manual de Funciones de Biblioteca getipnodebyname(3)

NOMBRE

getipnodebyname, getipnodebyaddr, freehostent - obtener nombres y direcciones de hosts de red

BIBLIOTECA

Biblioteca C estándar (libc, -lc)

SINOPSIS

#include <sys/types.h>
#include <sys/socket.h>
#include <netdb.h>
[[deprecated]] struct hostent *getipnodebyname(const char *name, int af,
                                            int flags, int *error_num);
[[deprecated]] struct hostent *getipnodebyaddr(size_t size;
                                            const void addr[size],
                                            size_t size, int af,
                                            int *error_num);
[[deprecated]] void freehostent(struct hostent *ip);

DESCRIPCIÓN

Estas funciones están obsoletas (y no están disponibles en glibc). Utilice getaddrinfo(3) y getnameinfo(3) en su lugar.

Las funciones getipnodebyname() y getipnodebyaddr() devuelven los nombres y direcciones de un host de red. Estas funciones devuelven un puntero a la siguiente estructura:


struct hostent {
    char  *h_name;
    char **h_aliases;
    int    h_addrtype;
    int    h_length;
    char **h_addr_list;
};

Estas funciones reemplazan a las funciones gethostbyname(3) y gethostbyaddr(3), que solo podían acceder a la familia de direcciones de red IPv4. Las funciones getipnodebyname() y getipnodebyaddr() pueden acceder a múltiples familias de direcciones de red.

A diferencia de las funciones gethostby, estas funciones devuelven punteros a memoria asignada dinámicamente. La función freehostent() se utiliza para liberar la memoria asignada dinámicamente después de que el llamador ya no necesite la estructura hostent.

getipnodebyname() argumentos

La función getipnodebyname() busca direcciones de red para el host especificado por el argumento name. El argumento af especifica uno de los siguientes valores:

AF_INET
El argumento name apunta a una dirección IPv4 de puntos cuádruples o al nombre de un host de red IPv4.
AF_INET6
El argumento name apunta a una dirección IPv6 hexadecimal o al nombre de un host de red IPv6.

El argumento flags especifica opciones adicionales. Se pueden especificar varias opciones combinándolas mediante OR bit a bit. El valor de flags debe establecerse en 0 si no se desean opciones.

AI_V4MAPPED
Esta bandera se utiliza con AF_INET6 para solicitar una consulta de direcciones IPv4 en lugar de direcciones IPv6; las direcciones IPv4 se mapearían a direcciones IPv6.
AI_ALL
Esta bandera se utiliza con AI_V4MAPPED para solicitar una consulta tanto de direcciones IPv4 como IPv6. Cualquier dirección IPv4 encontrada se mapeará a una dirección IPv6.
AI_ADDRCONFIG
Esta bandera se utiliza con AF_INET6 para solicitar además que no se realicen consultas de direcciones IPv6 a menos que el sistema tenga al menos una dirección IPv6 asignada a una interfaz de red, y que no se realicen consultas de direcciones IPv4 a menos que el sistema tenga al menos una dirección IPv4 asignada a una interfaz de red. Esta bandera puede ser utilizada sola o con la bandera AI_V4MAPPED.
AI_DEFAULT
Esta bandera es equivalente a (AI_ADDRCONFIG | AI_V4MAPPED).

getipnodebyaddr() argumentos

La función getipnodebyaddr() busca el nombre del host cuya dirección de red está especificada por el argumento addr. El argumento af especifica uno de los siguientes valores:

AF_INET
El argumento addr apunta a una struct in_addr y size debe establecerse en sizeof(struct in_addr).
AF_INET6
El argumento addr apunta a una struct in6_addr y size debe establecerse en sizeof(struct in6_addr).

VALOR DE RETORNO

Se devuelve NULL si se produjo un error y error_num contendrá un código de error de la siguiente lista:

HOST_NOT_FOUND
No se encontró el nombre de host o la dirección de red.
NO_ADDRESS
El servidor de nombres de dominio reconoció la dirección o el nombre de red, pero no se devolvió ninguna respuesta. Esto puede ocurrir si el host de red solo tiene direcciones IPv4 y se ha realizado una solicitud solo de información IPv6, o viceversa.
NO_RECOVERY
El servidor de nombres de dominio devolvió una respuesta de error permanente.
TRY_AGAIN
El servidor de nombres de dominio devolvió una respuesta de error temporal. Puede que tenga más suerte la próxima vez.

Una consulta exitosa devuelve un puntero a una estructura hostent que contiene los siguientes campos:

h_name
Este es el nombre oficial de este host de red.
h_aliases
Este es un array de punteros a alias no oficiales para el mismo host. El array está terminado por un puntero nulo.
h_addrtype
Esta es una copia del argumento af de getipnodebyname() o getipnodebyaddr(). h_addrtype siempre será AF_INET si el argumento af fue AF_INET. h_addrtype siempre será AF_INET6 si el argumento af fue AF_INET6.
h_length
Este campo se establecerá en sizeof(struct in_addr) si h_addrtype es AF_INET, y en sizeof(struct in6_addr) si h_addrtype es AF_INET6.
h_addr_list
Este es un array de uno o más punteros a estructuras de direcciones de red para el host de red. El array está terminado por un puntero nulo.

ESTANDARES

Ninguno.

HISTORIA

RFC 2553.

Presente en glibc 2.1.91-95, pero eliminado de nuevo. Varios sistemas tipo UNIX los soportan, pero todos los consideran obsoletos.
