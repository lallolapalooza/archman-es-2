form_userptr(3X) Llamadas a biblioteca form_userptr(3X)

NOMBRE

set_form_userptr, form_userptr - asociar datos de aplicación con un elemento de formulario

SINOPSIS

#include <form.h>
int set_form_userptr(FORM *form, void *userptr);
void* form_userptr(const FORM *form);

DESCRIPCIÓN

Cada formulario y cada elemento de formulario tiene un campo que puede ser utilizado para almacenar datos específicos de la aplicación (es decir, el código del controlador de formulario lo deja en paz). Estas funciones obtienen y establecen el campo del puntero de usuario del formulario.

VALOR DE RETORNO

La función form_userptr devuelve un puntero (que puede ser NULL). No establece errno.

La función set_form_userptr devuelve E_OK (éxito).

PORTABILIDAD

Estas rutinas emulan la biblioteca de formularios de System V. No eran compatibles con las versiones 7 o BSD.

El puntero de usuario es un puntero void. Elegimos no dejarlo como un puntero char por compatibilidad con SVr4.

AUTORES

Juergen Pfeifer. Páginas de manual y adaptación para curses nuevas por Eric S. Raymond.
