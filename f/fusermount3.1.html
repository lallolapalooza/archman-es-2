FUSERMOUNT3(1) Filesystem in Userspace (FUSE) FUSERMOUNT3(1)

NOMBRE

fusermount3 - montar y desmontar sistemas de archivos FUSE

SINOPSIS

fusermount3 [OPCIONES] PUNTO_DE_MONTAJE

DESCRIPCIÓN

Filesystem in Userspace (FUSE) es una interfaz simple para que los programas en el espacio de usuario exporten un sistema de archivos virtual al kernel de Linux. También tiene como objetivo proporcionar un método seguro para que los usuarios no privilegiados creen y monten sus propias implementaciones de sistemas de archivos.

fusermount3 es un programa para montar y desmontar sistemas de archivos FUSE. Solo debe llamarse directamente para desmontar sistemas de archivos FUSE. Para permitir el montaje y desmontaje por parte de usuarios no privilegiados, fusermount3 debe estar instalado con el bit SUID root activado.

OPCIONES

-h
imprimir ayuda.
-V
imprimir versión.
-o OPCIÓN[,OPCIÓN...]
opciones de montaje.
-u
desmontar.
-q
silencioso.
-z
desmontaje perezoso.

VER TAMBIÉN

mount(8), mount.fuse3(8), fuse(4),

PÁGINA PRINCIPAL

Puede encontrar más información sobre fusermount3 y el proyecto FUSE en http://fuse.sourceforge.net/.
