FSCK.CRAMFS(8) Administración del Sistema FSCK.CRAMFS(8)

NOMBRE

fsck.cramfs - fsck sistema de archivos de ROM comprimido

SINOPSIS

fsck.cramfs [opciones] archivo

DESCRIPCIÓN

fsck.cramfs se utiliza para comprobar el sistema de archivos cramfs.

OPCIONES

-v, --verbose

Habilita mensajes detallados.

-b, --blocksize tamaño_bloque

Usa este tamaño de bloque, por defecto el tamaño de página. Debe ser igual al establecido en el momento de la creación. Solo se usa para --extract.

--extract[=directorio]

Intenta descomprimir todo el sistema de archivos. Opcionalmente extrae el contenido del archivo al directorio.

-a

Esta opción se ignora silenciosamente.

-y

Esta opción se ignora silenciosamente.

-h, --help

Muestra el texto de ayuda y sale.

-V, --version

Muestra la versión y sale.

ESTADO DE SALIDA

0

éxito

4

el sistema de archivos quedó sin corregir

8

error de operación, como la incapacidad de asignar memoria

16

se mostró información de uso

VER TAMBIÉN

mount(8), mkfs.cramfs(8)

REPORTE DE ERRORES

Para reportes de errores, use el rastreador de incidencias https://github.com/util-linux/util-linux/issues.

DISPONIBILIDAD

El comando fsck.cramfs es parte del paquete util-linux que se puede descargar del Archivo del Kernel de Linux https://www.kernel.org/pub/linux/utils/util-linux/.
