NOMBRE

ftbench - evalúa el rendimiento de algunas rutas comunes de FreeType

SINOPSIS

ftbench [opciones] nombre_fuente

DESCRIPCIÓN

La herramienta ftbench mide el rendimiento de algunas operaciones comunes de FreeType.

Este programa forma parte del paquete de demostraciones de FreeType.

OPCIONES

-a eje1,eje2,...
Para fuentes Multiple Master, GX u OpenType de variación, especifique las coordenadas de diseño para cada eje al iniciar. Se ignora para todos los demás formatos de fuente.
-b pruebas
Realizar las pruebas elegidas:
a cargar glifos (FT_Load_Glyph)
b cargar anchos de avance (FT_Get_Advances)
c renderizar glifos (FT_Render_Glyph)
d cargar glifos (FT_Get_Glyph)
e obtener índices de glifo (FT_Get_Char_Index)
f iterar CMap (FT_Get_{First,Next}_Char)
g abrir una nueva cara (FT_New_Face o FT_New_Memory_Face)
h negrita de glifos (FT_GlyphSlot_Embolden)
i contornear glifos (FT_Glyph_Stroke)
j obtener recuadros de glifos (FT_Outline_Get_BBox)
k obtener cajas de glifos (FT_Glyph_Get_CBox)
l abrir una nueva cara y cargar glifos
(por defecto es abcdefghijkl, es decir, todas las pruebas).
El número de glifos usados por prueba (dentro de una sola iteración) se da con la opción -i.
-C
Comparar con la versión en caché si está disponible.
-c N
Usar como máximo N iteraciones por prueba (0 significa tiempo limitado).
-e E
Usar el mapa de caracteres con índice E en lugar del unicode por defecto.
-f L
Usar el número L en base hexadecimal (no decimal) como banderas de carga (ver las macros `FT_LOAD_XXX' en la referencia de FreeType).
-H nombre
Usar el motor de indicaciones CFF nombre. Las versiones disponibles dependen de las opciones de compilación de FreeType; llame a ftbench sin argumentos para obtener la lista real.
-I ver
Usar la versión del intérprete TT ver. Las versiones disponibles dependen de las opciones de compilación de FreeType; llame a ftbench sin argumentos para obtener la lista real.
-i I-J
Rango de índices de glifo hacia adelante o hacia atrás a usar (por defecto es de 0 al número de glifos menos uno).
-m M
Establecer el tamaño máximo de caché a M KiByte (por defecto es 1024).
-p
Precargar el archivo de fuente en memoria (es decir, probar FT_New_Memory_Face en lugar de FT_New_Face).
-r R
Establecer el modo de renderizado a R:
0 normal
1 claro
2 mono
3 LCD horizontal
4 LCD vertical
(por defecto es 0). Esto corresponde a los valores de las banderas `FT_RENDER_MODE_XXX'.
-s S
Usar S ppem como tamaño de cara (por defecto es 10ppem). Si se establece en cero, no llame a FT_Set_Pixel_Sizes. Use el valor 0 con la opción `-f 1' o algo similar para cargar los glifos sin escalar, de lo contrario se mostrarán errores.
-t T
Usar como máximo T segundos por prueba (por defecto es 2).
-v
Mostrar versión.
