fpcmake(1) Constructor de makefiles de Free Pascal fpcmake(1)

NOMBRE

fpcmake - El programa constructor de makefiles de Free Pascal.

SINOPSIS

fpcmake [-Ttarget] [-pwhrqvV] [nombrearchivo [nombrearchivo [nombrearchivo]]]

DESCRIPCIÓN

fpcmake lee un Makefile.fpc y lo convierte en un Makefile adecuado para ser leído por GNU make para compilar tus proyectos. Es similar en funcionalidad a GNU autoconf o Imake para la creación de proyectos X.

USO

fpcmake acepta nombres de archivo de archivos de descripción de makefile como argumentos de línea de comandos. Para cada uno de estos archivos, creará un Makefile en el mismo directorio donde se encuentra el archivo, sobrescribiendo cualquier archivo existente con el mismo nombre.

Si no se proporcionan opciones, simplemente intenta leer el archivo Makefile.fpc en el directorio actual e intenta construir un Makefile a partir de él. Cualquier Makefile existente previamente será borrado. Consulte fpcmake(5) para una descripción del formato del archivo Makefile.fpc.

OPCIONES

fpcmake tiene un pequeño número de opciones para controlar su comportamiento:

-h
Emite un texto de ayuda corto que describe el uso de fpcmake
-p
Si se proporciona esta opción, se generará un archivo de descripción del paquete así como un makefile.
-q
Indica a fpcmake que sea más silencioso, es decir, que emita menos mensajes.
-r
Si se proporciona esta opción, fpcmake escaneará recursivamente los subdirectorios en busca de archivos makefile.fpc y generará makefiles para ellos.
-T
Especifica los objetivos para los cuales fpcmake debe generar makefiles. Esto puede ser una lista separada por comas de sistemas objetivo, o el identificador especial all que indica que se debe generar un makefile para todas las plataformas compatibles.
-v
Esta opción instruye a fpcmake a ser más detallado.
-V
Imprime la versión de fpcmake y sale.
-w
Esta es la opción estándar e indica a fpcmake que genere un makefile.
