NOMBRE

set_field_opts, field_opts_on, field_opts_off, field_opts - establecer y obtener opciones de campo

SINOPSIS

#include <form.h>
int set_field_opts(FIELD *field, Field_Options opts);
Field_Options field_opts(const FIELD *field);
int field_opts_on(FIELD *field, Field_Options opts);
int field_opts_off(FIELD *field, Field_Options opts);

DESCRIPCIÓN

La función set_field_opts establece todos los bits de opción del campo dado (los bits de opción de campo pueden combinarse lógicamente con un OR).

La función field_opts_on activa los bits de opción dados y deja los demás sin cambios.

La función field_opts_off desactiva los bits de opción dados y deja los demás sin cambios.

La función field_opts devuelve los bits de opción actuales del campo.

Las siguientes opciones estándar están definidas (todas están activadas por defecto):

O_ACTIVE
El campo se visita durante el procesamiento. Si esta opción está desactivada, el campo no será alcanzable mediante teclas de navegación. Tenga en cuenta que un campo invisible también parece inactivo.
O_AUTOSKIP
Saltar al siguiente campo cuando este se llena.
O_BLANK
El campo se borra cada vez que se introduce un carácter en la primera posición.
O_EDIT
El campo se puede editar.
O_NULLOK
Permitir un campo en blanco.
O_PASSOK
Validar el campo solo si es modificado por el usuario.
O_PUBLIC
El contenido del campo se muestra a medida que se introducen los datos.
O_STATIC
Los búferes de campo están fijos al tamaño original del campo. Desactive esta opción para crear un campo dinámico.
O_VISIBLE
El campo se muestra. Si esta opción está desactivada, se suprime la visualización del campo.
O_WRAP
Las palabras que no caben en una línea se pasan a la siguiente. Las palabras están separadas por espacios.

Estas opciones de extensión están definidas (las extensiones están desactivadas por defecto):

O_DYNAMIC_JUSTIFY
Permitir que los campos dinámicos se justifiquen, como los campos estáticos.
O_NO_LEFT_STRIP
Preservar los espacios en blanco iniciales en el búfer de campo, que normalmente se descartan.
O_EDGE_INSERT_STAY
Al insertar en un campo hasta la posición límite, opcionalmente retrasar el desplazamiento, de modo que el último carácter insertado permanezca visible, pero avanzar el cursor para reflejar la inserción. Esto permite que la biblioteca de formularios muestre el carácter insertado en campos de un solo carácter, así como que la biblioteca mantenga un estado consistente.
O_INPUT_FIELD
La función set_max_field comprueba esta extensión, que permite que un campo dinámico se encoja si el nuevo límite es menor que el tamaño actual del campo.

VALOR DE RETORNO

Excepto para field_opts, cada rutina devuelve uno de los siguientes:

E_OK
La rutina tuvo éxito.
E_BAD_ARGUMENT
La rutina detectó un argumento incorrecto o fuera de rango.
E_CURRENT
El campo es el campo actual.
E_SYSTEM_ERROR
Ocurrió un error del sistema (ver errno(3)).

PORTABILIDAD

Estas rutinas emulan la biblioteca de formularios de System V. No fueron compatibles con las versiones 7 o BSD.
