fpclasschart(1) Generador de árbol de clases de Free Pascal fpclasschart(1)

NOMBRE

fpclasschart - El generador de árbol de clases de Free Pascal.

SINOPSIS

fpclasschart --input=cmdline --output=nombre_archivo [--merge=nombre_archivo] [--kind=tipoclase] [--lang=idioma] [--help]

DESCRIPCIÓN

fpclasschart Crea un árbol de clases a partir de código fuente Pascal.

USO

Puede invocar fpclasschart con una o más opciones.

OPCIONES

fpclasschart tiene varias opciones, la mayoría opcionales, se usarán valores predeterminados en la mayoría de los casos.

--input=cmdline
Esta opción le dice a fpclasschart que genere un archivo de árbol. La línea de comandos es la misma que la del compilador utilizada para compilar el archivo fuente.
--output=nombre_archivo
Esta opción especifica el nombre del archivo generado descfile que contiene el gráfico real para el árbol de objetos.
--merge=nombre_archivo
Proporciona la ruta a un archivo que ya contiene un árbol de objetos para fusionar.
--kind=tipoclase
Especifica el tipo de objeto. Uno de object, class, interface.
--lang=idioma
Establece el idioma para el archivo de salida. Esto principalmente establecerá las cadenas utilizadas para los encabezados en varias partes de los archivos de documentación (por defecto están en inglés). Actualmente, las opciones válidas son:
de
Alemán.
fr
Francés.
nl
Holandés.
--help
Escribe un mensaje de ayuda.
