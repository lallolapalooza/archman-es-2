FORK(3am) Módulos de extensión de GNU Awk FORK(3am)

NOMBRE

fork, wait, waitpid - gestión básica de procesos

SINOPSIS

@load "fork"

pid = fork()

ret = waitpid(pid)

ret = wait();

DESCRIPCIÓN

La extensión fork añade tres funciones, como sigue.

fork()
Esta función crea un nuevo proceso. El valor de retorno es cero en el hijo y el número del identificador de proceso del hijo en el padre, o -1 en caso de error. En este último caso, ERRNO indica el problema. En el hijo, PROCINFO["pid"] y PROCINFO["ppid"] se actualizan para reflejar los valores correctos.
waitpid()
Esta función toma un argumento numérico, que es el identificador de proceso al que esperar. El valor de retorno es el de la llamada al sistema waitpid(2).
wait()
Esta función espera a que muera el primer hijo. El valor de retorno es el de la llamada al sistema wait(2).

ERRORES

No existe una función exec() correspondiente.

Las interfaces podrían mejorarse para proporcionar más facilidades, incluyendo la extracción de los diversos bits del estado de retorno.

EJEMPLO

@load "fork"
...
if ((pid = fork()) == 0)
    print "hola desde el hijo"
else
    print "hola desde el padre"
