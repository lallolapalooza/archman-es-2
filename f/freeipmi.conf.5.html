NOMBRE

freeipmi.conf - especificar valores predeterminados para FreeIPMI

DESCRIPCIÓN

El archivo de configuración FreeIPMI se puede usar para establecer valores predeterminados alternativos para muchas herramientas de FreeIPMI, de modo que los valores no tengan que configurarse en la línea de comandos. Esto permite a los usuarios evitar escribir una larga lista de opciones de línea de comandos cada vez que se ejecuta un comando. También se puede utilizar para ocultar nombres de usuario, contraseñas y otra información sensible del comando ps(1).

Actualmente, las herramientas que se pueden configurar con el archivo de configuración son: bmc-device(8), bmc-info(8), bmc-watchdog(8), ipmi-chassis(8), ipmi-config(8), ipmi-fru(8), ipmi-oem(8), ipmi-pet(8), ipmi-raw(8), ipmi-sel(8), ipmi-sensors(8), ipmiconsole(8), y ipmipower(8).

Por defecto, el archivo de configuración se almacena en /etc/freeipmi//freeipmi.conf. Pero los usuarios pueden seleccionar un archivo de configuración diferente en la línea de comandos con la opción --config-file.

Los valores especificados en la línea de comandos anulan los valores de configuración especificados en el archivo de configuración.

FORMATO

Las opciones de configuración que se pueden especificar en el archivo de configuración se enumeran a continuación. Cada opción de configuración debe aparecer en una línea separada. Los argumentos de una opción se separan por cualquier cantidad de espacio en blanco. Múltiples argumentos también se separan por espacio en blanco. Los comentarios se pueden marcar usando el carácter de signo de almohadilla ("#"), y las líneas se pueden continuar en la siguiente usando la barra invertida ("\").

Tenga en cuenta que es posible enumerar el nombre de usuario, la contraseña y otra información potencialmente sensible en el archivo de configuración. Si estos datos se almacenan en un archivo de configuración, los administradores del sistema deben limitar el acceso a este archivo.

OPCIONES GENERALES

Las siguientes son opciones generalmente disponibles para todas las herramientas, aunque algunas pueden ignorar opciones específicas. (Por ejemplo, ipmiconsole(8) e ipmipower(8) no realizan comunicación en banda, por lo tanto, ignorarían las opciones de comunicación en banda. De manera similar, bmc-watchdog(8) no realiza comunicación fuera de banda, por lo tanto, ignoraría todas las opciones fuera de banda).

tipo-driver IPMIDRIVER
Especificar el tipo de driver predeterminado a usar.
desactivar-sondaje-automatico ACTIVAR|DESACTIVAR
Especificar si los dispositivos IPMI deben sondearse para obtener configuraciones predeterminadas.
direccion-driver DIRECCION-DRIVER
Especificar la dirección predeterminada del driver en banda a usar.
dispositivo-driver DISPOSITIVO
Especificar la ruta predeterminada del dispositivo driver en banda a usar.
espaciado-registro ESPACIADO-REGISTRO
Especificar el espaciado predeterminado del registro del driver en banda a usar.
numero-canal-objetivo NUMERO-CANAL
Especificar el número de canal predeterminado del driver en banda objetivo.
direccion-esclavo-objetivo DIRECCION-ESCLAVO
Especificar la dirección predeterminada del driver en banda esclavo objetivo.
nombre-usuario NOMBRE-USUARIO
Especificar el nombre de usuario predeterminado a usar.
contraseña CONTRASEÑA
Especificar la contraseña predeterminada a usar.
k_g cadena
Especificar la clave BMC predeterminada (K_g) a usar. Prefijar con '0x' para introducir la clave en hexadecimal.
tiempo-limite-sesion MILISEGUNDOS
Especificar la duración predeterminada del tiempo límite de sesión a usar en milisegundos.
tiempo-limite-retransmision MILISEGUNDOS
Especificar la duración predeterminada del tiempo límite de retransmisión a usar en milisegundos.
tipo-autenticacion TIPO-AUTENTICACION
Especificar el tipo de autenticación predeterminado a usar. Los siguientes tipos de autenticación son compatibles: NONE, STRAIGHT_PASSWORD_KEY, MD2, y MD5.
id-conjunto-cifrado ID-CONJUNTO-CIFRADO
Especificar el id del conjunto de cifrado predeterminado a usar. Los siguientes ids de conjuntos de cifrado son compatibles: 0, 1, 2, 3, 6, 7, 8, 11, 12.
nivel-privilegio NIVEL-PRIVILEGIO
Especificar el tipo de privilegio predeterminado a usar. Los siguientes niveles de privilegio son compatibles: USER, OPERATOR, ADMIN.
flags-solucion SOLUCIONES
Especificar las flags de solución predeterminadas a usar. Se pueden especificar varias soluciones separadas por espacios. Consulte las páginas del manual de las herramientas para obtener detalles sobre las soluciones disponibles para cada herramienta. Las siguientes soluciones son compatibles: assumeio, spinpoll, idzero, forcepermsg, unexpectedauth, endianseq, noauthcodecheck, authcap, nochecksumcheck, intel20, supermicro20, sun20, opensesspriv, integritycheckvalue, assumemaxsdrrecordcount, solpayloadsize, solport, solstatus, solchannelsupport, serialalertsdeferred, solpacketseq, skipchecks, assumesystemevent, discretereading, ignorescanningdisabled, assumebmcowner, ignoreauthcode, slowcommit, veryslowcommit, solchannelassumelanchannel, ignorestateflag, malformedack, guidformat, ipmiping.
