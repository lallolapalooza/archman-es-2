NOMBRE

freeciv-mp-gtk4, freeciv-mp-gtk3, freeciv-mp-qt, freeciv-cli - Instaladores de contenido personalizado para el juego Freeciv

SINOPSIS

freeciv-mp-XXX [ -d|--debug nivel ] [ -h|--help ] [ -i|--install URL ] [ -L|--List URL ] [ -p|--prefix directorio ] [ -v|--version ]

DESCRIPCIÓN

Freeciv es un juego de estrategia multijugador por turnos, de código abierto, en el que cada jugador se convierte en el líder de una civilización, luchando para obtener el objetivo final: ser la civilización más grande.

Los jugadores de Civilization II® de Microprose® deberían sentirse como en casa, ya que uno de los objetivos de Freeciv es tener reglas compatibles.

Freeciv es mantenido por un equipo internacional de programadores y entusiastas, ¡y es fácilmente uno de los juegos de red más divertidos y adictivos que existen!

Este es el programa instalador de contenido personalizado; consulta también freeciv-server(6) freeciv-client(6).

Este programa permite a los usuarios seleccionar y descargar contenido adicional ("modpacks") para Freeciv desde Internet, ya sea desde una lista mantenida por el equipo de Freeciv, o utilizando una URL obtenida por otros medios. Se encarga de instalar los archivos en el lugar correcto bajo el directorio de inicio del usuario para esta versión de Freeciv; no instala nada para uso a nivel de sistema.

freeciv-mp-cli es una versión del instalador de modpack utilizable desde la línea de comandos. Por defecto, lista los modpacks de la lista predeterminada o de la lista especificada con --List. Luego se puede volver a ejecutar proporcionando la URL apropiada de la lista para el parámetro --install.

Esta página del manual solo enumera los argumentos de la línea de comandos. Para obtener detalles sobre el funcionamiento de freeciv-mp-XXX, consulta README.modpack_installer en la distribución de Freeciv y la documentación en el sitio web de Freeciv.

OPCIONES

Todas las opciones tienen una forma corta (un solo guion y una sola letra) y una forma larga (doble guion y una palabra completa); sus efectos son idénticos.

-d nivel, --debug nivel
Establece la cantidad de información de depuración que se registrará. Los valores aceptables para el nivel son:

fatal solo para mensajes fatales.

error para mensajes fatales y de error.

warning para mensajes fatales, de error y de advertencia.

normal para mensajes fatales, de error, de advertencia y normales (predeterminado).

verbose para mensajes fatales, de error, de advertencia, normales y detallados.

-h, --help
Imprime un breve resumen de las opciones de la línea de comandos.
-i URL, --install URL
Instala automáticamente el modpack desde una URL dada.
-L URL, --List URL
Obtiene la lista de modpacks de una URL dada, en lugar de la ubicación estándar en los servidores del equipo de Freeciv.
-p directorio, --prefix directorio
Instala los modpacks bajo la jerarquía de directorios dada.
-v, --version
Imprime el número de versión y sale.

ARCHIVOS

El instalador de modpacks de freeciv instala archivos en los siguientes subdirectorios del directorio de inicio del usuario (o en otro directorio especificado con --prefix), según corresponda:

• .freeciv/scenarios/

• .freeciv/"3.2"/

El instalador de modpacks mantiene un registro de los nombres y versiones de los modpacks instalados en estos archivos:

• .freeciv/scenarios/.control/mp.db

• .freeciv/"3.2"/.control/mp.db

Esta información se utiliza para mostrar y para decidir si las dependencias de los nuevos modpacks ya están satisfechas. No es utilizada por los otros programas de Freeciv, y puede eliminarse con bastante seguridad si se desincroniza con el estado real de los modpacks instalados. Estos son archivos sqlite cuyo formato está sujeto a cambios.

ENTORNO

El instalador de modpacks de freeciv acepta estas variables de entorno:

HOME
Especifica el directorio de inicio del usuario.
http_proxy
Establezca esta variable en consecuencia cuando utilice un proxy.
LANG o LANGUAGE
Establece el idioma y la configuración regional en algunas plataformas.
LC_ALL o LC_CTYPE
Similar a LANG (consulte la documentación de su sistema).
USER
Especifica el nombre de usuario del usuario actual.

ERRORES
