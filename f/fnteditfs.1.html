FNTEDITFS(1) Manual de comandos generales FNTEDITFS(1)

NOMBRE

fnteditfs — un editor de fuentes de consola a pantalla completa

SINOPSIS

fnteditfs [archivo de fuente]

DESCRIPCIÓN

La utilidad fnteditfs permite editar fácilmente fuentes de consola.

OPCIONES

Se admiten las siguientes opciones de línea de comandos:

[archivo de fuente]
Especifica qué archivo de fuente cargar al iniciar el programa. Si no se proporciona ningún archivo de fuente, fnteditfs intentará cargar la fuente activa actualmente en la consola (si es compatible con el sistema operativo y tiene los permisos correctos para hacerlo), y si falla, comenzará con una fuente vacía.

VER TAMBIÉN

vidcontrol(1), vidfont(1)

DISPONIBILIDAD

La última versión y algo de documentación en línea están disponibles en la Página de fnteditfs, URL http://fonteditfs.sourceforge.net/
