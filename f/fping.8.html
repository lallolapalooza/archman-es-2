NOMBRE

fping - envía paquetes ICMP ECHO_REQUEST a hosts de red

SINOPSIS

fping [ opciones ] [ sistemas... ]

DESCRIPCIÓN

fping es un programa similar a ping que utiliza el Protocolo de Mensajes de Control de Internet (ICMP) de solicitud de eco para determinar si un host de destino está respondiendo. fping difiere de ping en que puedes especificar cualquier número de destinos en la línea de comandos, o especificar un archivo que contenga la lista de destinos a los que hacer ping. En lugar de enviar a un destino hasta que se agota el tiempo de espera o responde, fping enviará un paquete de ping y pasará al siguiente destino en modo de ronda. En el modo predeterminado, si un destino responde, se anota y se elimina de la lista de destinos a verificar; si un destino no responde dentro de un límite de tiempo y/o un límite de reintentos determinado, se designa como inalcanzable. fping también admite el envío de un número específico de pings a un destino, o el bucle indefinido (como en ping). A diferencia de ping, fping está diseñado para usarse en scripts, por lo que su salida está diseñada para ser fácil de analizar. Se pueden obtener estadísticas actuales sin terminar el proceso con la señal SIGQUIT (^\ desde el teclado en la mayoría de los sistemas).

OPCIONES

-4, --ipv4
Restringe la resolución de nombres y las IP a direcciones IPv4.
-6, --ipv6
Restringe la resolución de nombres y las IP a direcciones IPv6.
-a, --alive
Muestra los sistemas que están activos. (Las opciones -c y -C anulan -a).
-A, --addr
Muestra los destinos por dirección en lugar de por nombre DNS. Combinado con -d, la salida será tanto la IP como (si está disponible) el nombre del host.
-b, --size=BYTES
Número de bytes de datos de ping a enviar. El tamaño mínimo (normalmente 12) permite espacio para los datos que fping necesita para hacer su trabajo (número de secuencia, marca de tiempo). El tamaño de los datos recibidos reportados incluye la cabecera IP (normalmente 20 bytes) y la cabecera ICMP (8 bytes), por lo que el tamaño total mínimo es de 40 bytes. El valor predeterminado es 56, como en ping. El máximo es el tamaño máximo teórico del datagrama IP (64K), aunque la mayoría de los sistemas lo limitan a un número menor y dependiente del sistema. No se puede usar junto con --icmp-timestamp.
-B, --backoff=N
Factor de retroceso. En el modo predeterminado, fping envía varias solicitudes a un destino antes de rendirse, esperando más tiempo por una respuesta en cada solicitud sucesiva. Este parámetro es el valor por el cual el tiempo de espera (-t) se multiplica en cada solicitud sucesiva; debe ingresarse como un número de punto flotante (x.y). El valor predeterminado es 1.5.
-c, --count=N
Número de paquetes de solicitud a enviar a cada destino. En este modo, se muestra una línea por cada respuesta recibida (esto se puede suprimir con -q o -Q). Además, se muestran estadísticas sobre las respuestas de cada destino cuando se han enviado todas las solicitudes (o cuando se interrumpe). Esta opción anula -a o -u.
-C, --vcount=N
Similar a -c, pero las estadísticas por destino se muestran en un formato diseñado para la recopilación automatizada de estadísticas de tiempo de respuesta. Por ejemplo: 
$ fping -C 5 -q somehost
somehost : 91.7 37.0 29.2 - 36.8

muestra el tiempo de respuesta en milisegundos para cada una de las cinco solicitudes, con el "-" indicando que no se recibió respuesta a la cuarta solicitud. Esta opción anula -a o -u.

--check-source
Descarta las respuestas de Eco que provienen de una dirección diferente a la dirección de destino. Esto evita resultados de alcanzabilidad espurios en sistemas de monitoreo ocupados donde pueden ejecutarse simultáneamente dos instancias de fping con los mismos 16 bits inferiores del ID de proceso.
-d, --rdns
Utiliza DNS para buscar la dirección del destino del ping. Esto te permite darle a fping una lista de direcciones IP como entrada e imprimir nombres de host en la salida. Esto es similar a la opción -n/--name, pero forzará una búsqueda inversa de DNS incluso si proporcionas nombres de host como destino (NOMBRE->IP->NOMBRE).
-D, --timestamp
Agrega marcas de tiempo Unix al principio de las líneas de salida generadas en modo de bucle o de conteo (-l, -c, o -C).

Subcomando: --timestamp-format=ctime|iso|rfc3339

Permite cambiar el formato de marca de tiempo de la opción -D a los siguientes tipos de formato.

ctime = "%c" (Ejemplo: Mon Jun 10 07:50:00 2024)

iso = "%Y-%m-%dT%T%z" (Ejemplo: 2024-06-10T07:50:00+0200)

rfc3339 = "%Y-%m-%d %H:%M:%S" (Ejemplo: 2024-06-10 07:50:00)

-e, --elapsed
Muestra el tiempo transcurrido (ida y vuelta) de los paquetes.
-f, --file
Lee la lista de destinos de un archivo.
-g, --generate direccion/mascara
Genera una lista de destinos a partir de una máscara de red IP proporcionada, o una IP de inicio y fin. Especifica la máscara de red o el inicio/fin en la porción de destinos de la línea de comandos. Si se proporciona una red con máscara de red, se excluirán las direcciones de red y de difusión. Ej: Para hacer ping a la red 192.168.1.0/24, la línea de comandos especificada podría ser: 
$ fping -g 192.168.1.0/24

o

$ fping -g 192.168.1.1 192.168.1.254
-h, --help
Imprime el mensaje de uso.
-H, --ttl=N
Establece el campo TTL (tiempo de vida de saltos) de IP.
--print-ttl
Muestra el valor TTL de IPv4 de la cabecera IP en la salida. Si fping no puede leer el valor TTL, se devuelve "(TTL desconocido)". Solo IPv4, requiere privilegios de root o cap_net_raw.
-i, --interval=MSEC
La cantidad mínima de tiempo (en milisegundos) entre el envío de un paquete de ping a cualquier destino (predeterminado es 10, mínimo es 1).
-I, --iface=IFACE
Establece la interfaz (requiere soporte SO_BINDTODEVICE).
--icmp-timestamp
Envía solicitudes de marca de tiempo ICMP (ICMP tipo 13) en lugar de solicitudes de eco ICMP. Imprime marcas de tiempo ICMP de origen, recepción y transmisión, junto con la hora de recepción local en el mismo formato, además de la salida normal. No se puede usar junto con -b porque los mensajes de marca de tiempo ICMP tienen un tamaño fijo. Solo IPv4, requiere privilegios de root o cap_net_raw.
-k, --fwmark=FWMARK
Establece FWMARK en los paquetes de ping para enrutamiento basado en políticas. Requiere kernel de Linux 2.6.25 y superior, y privilegios de root o cap_net_admin.
-l, --loop
Bucle enviando paquetes a cada destino indefinidamente. Puede interrumpirse con Ctrl-C; luego se muestran estadísticas sobre las respuestas de cada destino.
-m, --all
Envía pings a cada una de las múltiples direcciones IP de un host de destino (se recomienda el uso de la opción '-A').
-M, --dontfrag
Establece el bit "No fragmentar" en la cabecera IP (utilizado para determinar/probar la MTU).
-n, --name
Si los destinos se especifican como direcciones IP, realiza una búsqueda inversa de DNS en ellos para imprimir nombres de host en la salida.
-N, --netdata
Formatea la salida para netdata (se requieren -l -Q). Ver: https://netdata.cloud/
-o, --outage
Calcula el "tiempo de inactividad" basándose en el número de pings perdidos y el intervalo utilizado (útil para pruebas de convergencia de red).
-O, --tos=
N
Establece el indicador de tipo de servicio (TOS). N puede ser tanto en formato decimal como hexadecimal (0xh)
.
--print-t
os
Muestra el valor TOS en la salida. Si fping no puede leer el valor TOS, se devuelve "(TOS unknown)". Solo IPv4, requiere privilegios de root o
cap_net_raw.
-p, --period=MS
EC
En los modos de bucle o conteo (-l, -c, o -C), este parámetro establece el tiempo en milisegundos que fping espera entre paquetes sucesivos a un objetivo individual. El valor predeterminado es 1000 y el mínimo es
10.

Silencioso. No mostrar resultados por sonda, sino solo el resumen final. Tampoco mostrar mensajes de error
ICMP.
-Q, --squiet=SECS[,
cumulative]

.

N
Límite de reintentos (predeterminado 3). Este es el número de veces que se intentará hacer ping a un objetivo, sin incluir el primer
intento.
-R, --rand
om
En lugar de usar todos ceros como datos del paquete, genera bytes aleatorios. Úsese para evitar, por ejemplo, la compresión de datos del
enlace.
-s, --sta
ts
Imprime estadísticas acumuladas al
salir.

dr
Establece la dirección de
origen.
-t, --timeout=MS
EC
Tiempo de espera inicial del objetivo en milisegundos. En el modo predeterminado, no de bucle, el tiempo de espera predeterminado es 500ms, y representa la cantidad de tiempo que fping espera una respuesta a su primera solicitud. Los tiempos de espera sucesivos se multiplican por el factor de retroceso especificado con -B.

En modo bucle/conteo, el tiempo de espera predeterminado se ajusta automáticamente para coincidir con el valor de "period" (pero no más de 2000ms). Aún puede ajustar el valor del tiempo de espera con esta opción, si lo desea, pero tenga en cuenta que establecer un valor mayor que "period" produce resultados inconsistentes, porque el valor del tiempo de espera solo puede respetarse para el último

ping.

S

El estado de salida es 0 si todos los hosts (o el número de hosts especificado con -x o -X) son alcanzables, 1 si algunos (o demasiados con -x o -X) hosts eran inalcanzables, 2 si no se encontraron algunas direcciones IP, 3 para a

rgumentos de línea de comando inválidos, y 4
para un fallo en una llamada al sistema.
