NOMBRE

fzy - Un selector de texto difuso para la terminal.

SINOPSIS

fzy [OPCIÓN]...

DESCRIPCIÓN

fzy es un selector de texto difuso/buscador de archivos para la terminal que utiliza una búsqueda similar a la de TextMate o CmdT.

fzy lee una lista de elementos separados por saltos de línea desde stdin para mostrarlos como un menú en la terminal. Al presionar ENTER, el elemento seleccionado actualmente se imprime en stdout.

Escribir texto filtra los elementos utilizando coincidencia difusa. Los resultados se ordenan utilizando heurísticas para obtener la mejor coincidencia.

OPCIONES

-l, --lineas=LINEAS
Cuántas líneas de elementos mostrar. Si no se especifica, por defecto son 10 líneas.
-p, --prompt=PROMPT
Indicador de entrada (por defecto: '> ')
-s, --mostrar-puntuaciones
Mostrar las puntuaciones de cada elemento.
-t, --tty=TTY
Usar TTY en lugar del dispositivo tty predeterminado (/dev/tty).
-q, --consulta=CONSULTA
Usar CONSULTA como la consulta de búsqueda inicial.
-e, --mostrar-coincidencias=CONSULTA
Modo no interactivo. Imprime las coincidencias en orden para CONSULTA a stdout.
-0, --leer-nulo
Leer entrada delimitada por caracteres NUL ASCII.
-i, --mostrar-info
Mostrar la línea de información de selección.
-h, --ayuda
Ayuda de uso.
-v, --version
Ayuda de uso.

TECLAS

ENTER
Imprimir el elemento seleccionado en stdout y salir
Ctrl+c, Ctrl+g, Esc
Salir con estado 1, sin realizar una selección.
Flecha Arriba, Ctrl+p, Ctrl+k
Seleccionar el elemento anterior
Flecha Abajo, Ctrl+n, Ctrl+j
Seleccionar el siguiente elemento
Tab
Reemplazar la cadena de búsqueda actual con el elemento seleccionado
Retroceso, Ctrl+h
Eliminar el carácter anterior al cursor
Ctrl+w
Eliminar la palabra anterior al cursor
Ctrl+u
Eliminar toda la línea

EJEMPLOS DE USO

ls | fzy
Presentar un menú de elementos en el directorio actual
ls | fzy -l 25
Igual que el anterior, pero mostrar 25 líneas de elementos
vi $(find -type f | fzy)
Listar archivos en el directorio actual y abrir el seleccionado en vi.
cd $(find -type d | fzy)
Presentar todos los directorios bajo la ruta actual y cambiar al seleccionado.
ps aux | fzy | awk '{ print $2 }' | xargs kill
Listar procesos en ejecución, matar el proceso seleccionado
git checkout $(git branch | cut -c 3- | fzy)
Igual que el anterior, pero cambiando ramas de git.
