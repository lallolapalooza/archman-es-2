NOMBRE

freeciv-ruledit - Editor de conjuntos de reglas de Freeciv

SINOPSIS

freeciv-ruledit [ -d|--debug nivel ] [ -F|--Fatal [ número_de_señal ] ] [ -h|--help ] [ -r|--ruleset conjunto_de_reglas ] [ -v|--version ]

DESCRIPCIÓN

Esta herramienta se puede utilizar para editar conjuntos de reglas de freeciv.

OPCIONES

Todas las opciones tienen una forma corta (guion simple y una sola letra) y una forma larga (doble guion y una palabra completa); sus efectos son idénticos.

-d nivel, --debug nivel
Establece la cantidad de información de depuración que se registrará. Los valores aceptables para el nivel son:

fatal solo para mensajes fatales.

error para mensajes fatales y de error.

warning para mensajes fatales, de error y de advertencia.

normal para mensajes fatales, de error, de advertencia y normales (por defecto).

verbose para mensajes fatales, de error, de advertencia, normales y detallados.

-F [ número_de_señal ], --Fatal [ número_de_señal ]
Genera una señal personalizada en una aserción fallida. Si no se especifica número_de_señal, se utilizará la señal ABRT.
-h, --help
Imprime un breve resumen de las opciones estándar de la línea de comandos.
-r conjunto_de_reglas, --ruleset conjunto_de_reglas
Carga el conjunto de reglas especificado como punto de partida para editar.
-v, --version
Imprime el número de versión y sale.

INFORMAR ERRORES

Reporta errores en "https://redmine.freeciv.org/projects/freeciv"

VER TAMBIÉN

freeciv-server(6) y el Manual del Cliente en la página principal de Freeciv.
