Paquete: gawk

FNMATCH(3am) Módulos de extensión de GNU Awk FNMATCH(3am)

NOMBRE

fnmatch - compara una cadena con un comodín de nombre de archivo

SINOPSIS

@load "fnmatch"

resultado = fnmatch(patrón, cadena, indicadores)

DESCRIPCIÓN

La extensión fnmatch proporciona una interfaz AWK a la rutina fnmatch(3). Añade una única función llamada fnmatch(), una variable predefinida (FNM_NOMATCH) y una matriz de valores de indicadores llamada FNM.

El primer argumento es el comodín de nombre de archivo que coincidirá, el segundo es la cadena del nombre de archivo y el tercero es cero o el OR bit a bit de uno o más de los indicadores de la matriz FNM.

El valor de retorno es cero en caso de éxito, FNM_NOMATCH si la cadena no coincidió con el patrón, o un valor distinto de cero diferente si ocurrió un error.

Los indicadores son los siguientes:

FNM["CASEFOLD"]
Corresponde al indicador FNM_CASEFOLD tal como se define en fnmatch(3).
FNM["FILE_NAME"]
Corresponde al indicador FNM_FILE_NAME tal como se define en fnmatch(3).
FNM["LEADING_DIR"]
Corresponde al indicador FNM_LEADING_DIR tal como se define en fnmatch(3).
FNM["NOESCAPE"]
Corresponde al indicador FNM_NOESCAPE tal como se define en fnmatch(3).
FNM["PATHNAME"]
Corresponde al indicador FNM_PATHNAME tal como se define en fnmatch(3).
FNM["PERIOD"]
Corresponde al indicador FNM_PERIOD tal como se define en fnmatch(3).

NOTAS

Nada impide que el código AWK cambie la variable predefinida FNM_NOMATCH, pero hacerlo puede causar resultados extraños.

EJEMPLO

@load "fnmatch"
...
flags = or(FNM["PERIOD"], FNM["NOESCAPE"])
if (fnmatch("*.a", "foo.c", flags) == FNM_NOMATCH)
	print "no coincide"
