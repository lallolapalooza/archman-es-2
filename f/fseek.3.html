fseek(3) Manual de Funciones de Biblioteca fseek(3)

NOMBRE

fgetpos, fseek, fsetpos, ftell, rewind - reposicionar un flujo

BIBLIOTECA

Biblioteca C estándar (libc, -lc)

SINOPSIS

#include <stdio.h>
int fseek(FILE *stream, long offset, int whence);
long ftell(FILE *stream);
void rewind(FILE *stream);
int fgetpos(FILE *restrict stream, fpos_t *restrict pos);
int fsetpos(FILE *stream, const fpos_t *pos);

DESCRIPCIÓN

La función fseek() establece el indicador de posición del archivo para el flujo apuntado por stream. La nueva posición, medida en bytes, se obtiene añadiendo offset bytes a la posición especificada por whence. Si whence se establece en SEEK_SET, SEEK_CUR o SEEK_END, el desplazamiento es relativo al inicio del archivo, al indicador de posición actual o al final del archivo, respectivamente. Una llamada exitosa a la función fseek() borra el indicador de fin de archivo para el flujo y deshace cualquier efecto de la función ungetc(3) en el mismo flujo.

La función ftell() obtiene el valor actual del indicador de posición del archivo para el flujo apuntado por stream.

La función rewind() establece el indicador de posición del archivo para el flujo apuntado por stream al principio del archivo. Es equivalente a:

(void) fseek(stream, 0L, SEEK_SET)

excepto que el indicador de error para el flujo también se borra (ver clearerr(3)).

Las funciones fgetpos() y fsetpos() son interfaces alternativas equivalentes a ftell() y fseek() (con whence establecido en SEEK_SET), estableciendo y almacenando el valor actual del desplazamiento del archivo en o desde el objeto referenciado por pos. En algunos sistemas que no son UNIX, un objeto fpos_t puede ser un objeto complejo y estas rutinas pueden ser la única forma de reposicionar portablemente un flujo de texto.

Si el flujo se refiere a un archivo regular y el desplazamiento de flujo resultante está más allá del tamaño del archivo, las escrituras subsiguientes ampliarán el archivo con un hueco, hasta el desplazamiento, antes de confirmar cualquier dato. Ver lseek(2) para detalles sobre la semántica de búsqueda de archivos.

VALOR DE RETORNO

La función rewind() no devuelve ningún valor. Tras la finalización exitosa, fgetpos(), fseek(), fsetpos() devuelven 0, y ftell() devuelve el desplazamiento actual. De lo contrario, se devuelve -1 y se establece errno para indicar el error.

ERRORES

EINVAL
El argumento whence de fseek() no fue SEEK_SET, SEEK_END o SEEK_CUR. O: el desplazamiento resultante del archivo sería negativo.
ESPIPE
El descriptor de archivo subyacente a stream no es buscable (por ejemplo, se refiere a una tubería, FIFO o socket).

Las funciones fgetpos(), fseek(), fsetpos() y ftell() también pueden fallar y establecer errno para cualquiera de los errores especificados para las rutinas fflush(3), fstat(2), lseek(2) y malloc(3).
