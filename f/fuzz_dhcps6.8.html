NOMBRE

fuzz_dhcps6

SINOPSIS

fuzz_dhcps6 [-t número | -T número] [-e número | -T número] [-p número] [-md] [-1|-2|-3|-4|-5|-6|-7|-8] interface [nombre-dominio]

OPCIONES

 -1         fuzz DHCPv6 Solicit (por defecto)
 -2         fuzz DHCPv6 Request
 -3         fuzz DHCPv6 Confirm
 -4         fuzz DHCPv6 Renew
 -5         fuzz DHCPv6 Rebind
 -6         fuzz DHCPv6 Release
 -7         fuzz DHCPv6 Decline
 -8         fuzz DHCPv6 Information Request
 -m         fuzz también el tipo de mensaje
 -t número  continuar desde la prueba n.º número
 -e número  continuar hasta la prueba n.º número
 -T número  solo realiza la prueba n.º número
 -n número  cuántas veces enviar cada paquete (por defecto: 1)
 -f         falsear mac
 -F         falsear dirección de enlace
 -w seg     esperar un número de segundos entre paquetes (por defecto: 0)
 -p número  realizar una comprobación de actividad cada número de pruebas (por defecto: ninguna)
 -d         Usar -d para forzar actualizaciones de DNS, puedes especificar un nombre de dominio en la línea de comandos.
Realiza fuzzing de paquetes DHCPv6 a un servidor
Solo puedes definir uno de los tipos -0 ... -4, por defecto es -1.
Devuelve -1 en caso de error, 0 si las pruebas se completaron y el objetivo está activo, o 1 si el objetivo se bloqueó.
