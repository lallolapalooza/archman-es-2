NOMBRE

fribidi_reorder_line - reordena una línea de cadena lógica a visual

SINOPSIS

#include <../fribidi/lib/fribidi.h>

FriBidiLevel fribidi_reorder_line
(
FriBidiFlags flags,
const FriBidiCharType *bidi_types,
const FriBidiStrIndex len,
const FriBidiStrIndex off,
const FriBidiParType base_dir,
FriBidiLevel *embedding_levels,
FriBidiChar *visual_str,
FriBidiStrIndex *map
);

PARÁMETROS

FriBidiFlags flags
Banderas de reordenación.
const FriBidiCharType *bidi_types
Lista de entrada de tipos bidi como se devuelve por fribidi_get_bidi_types().

Dado que hay 23 valores posibles para un const FriBidiCharType, no se enumeran aquí todos.

const FriBidiStrIndex len
Longitud de entrada de la línea.
const FriBidiStrIndex off
Desplazamiento de entrada del principio de la línea en el párrafo.
const FriBidiParType base_dir
Dirección base del párrafo resuelta.

Los valores posibles para un const FriBidiParType son los siguientes:

FRIBIDI_PAR_LTR
Párrafo de Izquierda a Derecha.
FRIBIDI_PAR_RTL
Párrafo de Derecha a Izquierda.
FRIBIDI_PAR_ON
Párrafo de Dirección Neutra.
FRIBIDI_PAR_WLTR
Párrafo Débil de Izquierda a Derecha.
FRIBIDI_PAR_WRTL
Párrafo Débil de Derecha a Izquierda.
FriBidiLevel *embedding_levels
Lista de entrada de niveles de incrustación, tal como se devuelve por fribidi_get_par_embedding_levels.
FriBidiChar *visual_str
Cadena visual a reordenar.
FriBidiStrIndex *map
Un mapa de índices de cadena que se reordena para reflejar dónde termina cada glifo.

DESCRIPCIÓN

Esta función reordena los caracteres de una línea de texto de orden lógico a orden visual final. Esta función implementa parte 4 de la regla L1, y las reglas L2 y L3 del Algoritmo Bidireccional Unicode disponible en http://www.unicode.org/reports/tr9/#Reordering_Resolved_Levels.

Como efecto secundario, también establece mapas de posición si no son NULL.

Debe proporcionar la dirección del párrafo resuelta y los niveles de incrustación tal como se establecen por fribidi_get_par_embedding_levels(). Tenga en cuenta también que los niveles de incrustación pueden cambiar un poco. Para ser exactos, el nivel de incrustación de cualquier secuencia de espacios en blanco al final de la línea se restablece al nivel de incrustación del párrafo (Eso es parte 4 de la regla L1).

Tenga en cuenta que los tipos bidi y los niveles de incrustación no se reordenan. Puede reordenar estos (o cualquier otro) arrays usando el mapa más tarde. El usuario es responsable de inicializar el mapa con algo sensato, como un mapeo de identidad, o pasar NULL si no se necesita ningún mapa.

Hay una parte opcional en esta función, que es si las marcas no espaciadas para partes de derecha a izquierda del texto deben reordenarse para que queden después de sus caracteres base en la cadena visual o no. La mayoría de los motores de renderizado esperan este comportamiento, pero los sistemas basados en consola, por ejemplo, no lo prefieren. Esto está controlado por el flag FRIBIDI_FLAG_REORDER_NSM. El flag está activado en FRIBIDI_FLAGS_DEFAULT.

DEVUELVE

El nivel máximo encontrado en esta línea más uno, o cero si ocurrió algún error (probablemente un fallo de asignación de memoria).
