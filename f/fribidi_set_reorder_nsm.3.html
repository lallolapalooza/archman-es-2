NOMBRE

fribidi_set_reorder_nsm - activar o desactivar la reorganización de marcas

SINOPSIS

#include <../fribidi/lib/fribidi.h>

fribidi_boolean fribidi_set_reorder_nsm(fribidi_boolean state);

PARÁMETROS

fribidi_boolean state
Nuevo estado a establecer.

DESCRIPCIÓN

Esta función se utiliza para activar o desactivar la reorganización de marcas no espaciadoras. La reorganización de marcas no espaciadoras es el acto de colocar marcas no espaciadoras (clase bidi NSM) después de su carácter base en un contexto resuelto de derecha a izquierda. Si su motor de renderizado espera que las marcas no espaciadoras estén siempre después del carácter base en la representación en memoria de la cadena visual, necesita esta opción activada. Un ejemplo de dónde la gente puede necesitarla desactivada es al renderizar en la consola cuando las marcas no espaciadoras no se pueden aplicar encima del carácter base.

Este indicador está activado por defecto. Esta función está obsoleta y solo se utiliza con otras funciones obsoletas.

RETORNA

El nuevo estado de reorganización de marcas.
