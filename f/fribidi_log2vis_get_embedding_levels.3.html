NOMBRE

fribidi_log2vis_get_embedding_levels - obtener niveles de incrustación

SINOPSIS

#include <../fribidi/lib/fribidi.h>

FriBidiLevel fribidi_log2vis_get_embedding_levels
(
const FriBidiCharType *bidi_types,
const FriBidiStrIndex len,
FriBidiParType *pbase_dir,
FriBidiLevel *embedding_levels
);

PARÁMETROS

const FriBidiCharType *bidi_types
Lista de entrada de tipos bidi como se devuelve en fribidi_get_bidi_types().

Dado que hay 23 valores posibles para un const FriBidiCharType, no todos están listados aquí.

const FriBidiStrIndex len
Longitud de la cadena de entrada del párrafo.
FriBidiParType *pbase_dir
Dirección base del párrafo solicitada y resuelta.

Los valores posibles para un FriBidiParType son los siguientes:

FRIBIDI_PAR_LTR
Párrafo de Izquierda a Derecha.
FRIBIDI_PAR_RTL
Párrafo de Derecha a Izquierda.
FRIBIDI_PAR_ON
Párrafo de Dirección Neutral.
FRIBIDI_PAR_WLTR
Párrafo Débil de Izquierda a Derecha.
FRIBIDI_PAR_WRTL
Párrafo Débil de Derecha a Izquierda.
FriBidiLevel *embedding_levels
Lista de salida de niveles de incrustación.

DESCRIPCIÓN

Obsoleto. Reemplazado por fribidi_get_par_embedding_levels_ex.
