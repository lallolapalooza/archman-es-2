for(n) Comandos integrados de Tcl for(n)

NOMBRE

for - Bucle 'for'

SINOPSIS

for inicio prueba siguiente cuerpo

DESCRIPCIÓN

For es un comando de bucle, similar en estructura a la sentencia for de C. Los argumentos inicio, siguiente y cuerpo deben ser cadenas de comandos Tcl, y prueba es una cadena de expresión. El comando for primero invoca al intérprete Tcl para ejecutar inicio. Luego evalúa repetidamente prueba como una expresión; si el resultado no es cero, invoca al intérprete Tcl sobre cuerpo, luego invoca al intérprete Tcl sobre siguiente, y repite el bucle. El comando termina cuando prueba se evalúa como 0. Si se invoca un comando continue dentro de cuerpo, se omiten los comandos restantes en la ejecución actual de cuerpo; el procesamiento continúa invocando al intérprete Tcl sobre siguiente, luego evaluando prueba, y así sucesivamente. Si se invoca un comando break dentro de cuerpo o siguiente, el comando for retornará inmediatamente. La operación de break y continue es similar a las sentencias correspondientes en C. For retorna una cadena vacía.

Nota: prueba casi siempre debe estar entre llaves. Si no, se harán sustituciones de variables antes de que el comando for comience a ejecutarse, lo que significa que los cambios de variables realizados por el cuerpo del bucle no se considerarán en la expresión. Es probable que esto resulte en un bucle infinito. Si prueba está entre llaves, las sustituciones de variables se retrasan hasta que la expresión sea evaluada (antes de cada iteración del bucle), por lo que los cambios en las variables serán visibles. Ver abajo para un ejemplo:

EJEMPLOS

Imprime una línea por cada entero de 0 a 9:

for {set x 0} {$x<10} {incr x} {
    puts "x es $x"
}

Ya sea que el bucle sea infinito o no, porque la expresión que se evalúa es en realidad una constante, ¡o incluso genera un error! El comportamiento real dependerá de si la variable x existe antes de que se ejecute el comando for y si su valor es un valor menor o mayor o igual a diez, y esto se debe a que la expresión se sustituirá antes de que se ejecute el comando for.

for {set x 0} $x<10 {incr x} {
    puts "x es $x"
}

Imprime las potencias de dos de 1 a 1024:

for {set x 1} {$x<=1024} {set x [expr {$x * 2}]} {
    puts "x es $x"
}
