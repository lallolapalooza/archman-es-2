freezero(3bsd)

Paquete: libbsd

Licencias: custom

reallocarray(3bsd) 3bsd reallocarray(3bsd)

NOMBRE

reallocarray, recallocarray, freezero — asignación y desasignación de memoria

BIBLIOTECA

biblioteca “libbsd”

SINOPSIS

#include <stdlib.h> (Ver libbsd(7) para el uso de include.)
void *
reallocarray(void *ptr, size_t nmemb, size_t size);

void *
recallocarray(void *ptr, size_t oldnmemb, size_t nmemb, size_t size);

void
freezero(void *ptr, size_t size);

DESCRIPCIÓN

Diseñada para la asignación segura de arreglos, la función reallocarray() es similar a realloc() excepto que opera sobre nmemb miembros de tamaño size y verifica desbordamientos de enteros en el cálculo nmemb * size.

Utilizada para la asignación de memoria que contiene datos sensibles, la función recallocarray() garantiza que la memoria que se vuelve no asignada se descarta explícitamente, lo que significa que los objetos liberados en caché se borran con explicit_bzero(3).

La función recallocarray() es similar a reallocarray() excepto que asegura que la memoria recién asignada se borra de manera similar a calloc(). Si ptr es NULL, oldnmemb se ignora y la llamada es equivalente a calloc(). Si ptr no es NULL, oldnmemb debe ser un valor tal que oldnmemb * size sea el tamaño de la asignación anterior que devolvió ptr, de lo contrario el comportamiento es indefinido. La función freezero() es similar a la función free() excepto que asegura que la memoria se descarta explícitamente. Si ptr es NULL, no ocurre ninguna acción. Si ptr no es NULL, el argumento size debe ser igual o menor que el tamaño de la asignación anterior que devolvió ptr. freezero() garantiza que el rango de memoria que comienza en ptr con longitud size se descarta mientras se desasigna el objeto completo asignado originalmente.

VALORES DE RETORNO

Las funciones reallocarray() y recallocarray() devuelven un puntero al espacio asignado si tienen éxito; de lo contrario, devuelven un puntero nulo y establecen errno a ENOMEM.

Si la multiplicación de nmemb y size resulta en desbordamiento de enteros, reallocarray() y recallocarray() devuelven NULL y establecen errno a ENOMEM.

Si ptr no es NULL y la multiplicación de oldnmemb y size resulta en desbordamiento de enteros, recallocarray() devuelve NULL y establece errno a EINVAL.

IDIOMAS

Considere calloc() o las extensiones reallocarray() y recallocarray() cuando haya multiplicación en el argumento size de malloc() o realloc(). Por ejemplo, evite este modismo común ya que puede provocar desbordamiento de enteros:

if ((p = malloc(num * size)) == NULL)
	err(1, NULL);

Un reemplazo directo es reallocarray():

if ((p = reallocarray(NULL, num, size)) == NULL)
	err(1, NULL);

Alternativamente, calloc() puede usarse a costa de la sobrecarga de inicialización.

Al usar realloc(), tenga cuidado de evitar el siguiente modismo:

size += 50;
if ((p = realloc(p, size)) == NULL)
	return (NULL);

No ajuste la variable que describe cuánta memoria se ha asignado hasta que la asignación haya sido exitosa. Esto puede causar un comportamiento aberrante del programa si se usa un valor de tamaño incorrecto. En la mayoría de los casos, el ejemplo anterior también provocará una fuga de memoria. Como se indicó anteriormente, un valor de retorno de NULL indica que el objeto antiguo permanece asignado. Un código mejor se ve así:

newsize = size + 50;
if ((newp = realloc(p, newsize)) == NULL) {
	free(p);
	p = NULL;
	size = 0;
	return (NULL);
}

Al igual que con malloc(), es importante asegurarse de que el nuevo valor de tamaño no se desborde; es decir, evite asignaciones como la siguiente:

if ((newp = realloc(p, num * size)) == NULL) {
	...

En su lugar, use reallocarray():

if ((newp = reallocarray(p, num, size)) == NULL) {
	...

Llamar a realloc() con un ptr NULL es equivalente a llamar a malloc(). En lugar de este modismo:

if (p == NULL)
	newp = malloc(newsize);
else
	newp = realloc(p, newsize);

Use lo siguiente:

newp = realloc(p, newsize);

La función recallocarray() debe usarse para redimensionar objetos que contienen datos sensibles como claves. Para evitar fugas de información, garantiza que la memoria se borra antes de colocarla en la lista interna de objetos liberados. La desasignación de un objeto de este tipo debe realizarse llamando a freezero().

VER TAMBIÉN

malloc(3), calloc(3), alloca(3)

HISTORIA

La función reallocarray() apareció en OpenBSD 5.6, DragonFly 5.5 y glibc 2.26.

La función recallocarray() apareció en OpenBSD 6.1 y DragonFly 5.5. La función freezero() apareció en OpenBSD 6.2 y DragonFly 5.5.
