fwbedit(1) Firewall Builder fwbedit(1)

NOMBRE

fwbedit - Herramienta de edición de árboles de objetos de propósito general

SINOPSIS

fwbedit comando [opciones]

DESCRIPCIÓN

fwbedit es una herramienta de edición de árboles de objetos de propósito general para Firewall Builder (ver fwbuilder(1)). Esta herramienta puede usarse en scripts de shell escritos para el procesamiento por lotes de los archivos de datos de Firewall Builder. Fwbedit puede realizar las siguientes operaciones sobre los objetos y el árbol: crear un objeto nuevo, eliminar un objeto existente, modificar los atributos de un objeto, añadir una referencia al objeto dado a un grupo, eliminar una referencia a un objeto de un grupo, actualizar el archivo de datos y comprobar el árbol de objetos en el archivo y repararlo si es necesario. Tanto un objeto como un grupo pueden definirse por su ID o por su nombre y una ruta completa en el árbol (ver la sección EJEMPLOS más abajo).

COMANDOS Y OPCIONES:

new -f archivo.fwb -t tipoobj -n nombre -p padre [-c comentario] [-a atributos]

Crea un objeto nuevo.


-f archivo.fwb archivo de datos
-t tipoobj crea un nuevo objeto de este tipo
-p padre crea el nuevo objeto como hijo de este objeto.
Este parámetro es obligatorio. Si está añadiendo una dirección
a una interfaz, la interfaz correspondiente debe
especificarse como el padre. De manera similar, si necesita añadir una
interfaz a un host o a un firewall, el objeto host o
firewall correspondiente es el padre. Si está añadiendo un
objeto a una de las carpetas estándar, el padre es la
biblioteca a la que desea añadir el objeto o la ruta
completa correcta a la carpeta en el árbol.
-n nombre el nombre del nuevo objeto
-c txt especifica el comentario para el nuevo objeto
-a atributo1[,atributo2...] : especifica los atributos que
definen los parámetros del nuevo objeto (ver más abajo)

delete -f archivo.fwb -o objeto

Elimina el objeto especificado por su ruta completa en el árbol o por su ID de objeto.


-f archivo.fwb archivo de datos
-o objeto objeto a eliminar, ruta completa o ID

modify -f archivo.fwb -o objeto -c comentario [-a atributos]

Modifica el objeto especificado por su ruta completa en el árbol o por su ID de objeto. El objeto no puede ser renombrado usando esta operación.


-f archivo.fwb archivo de datos
-o objeto objeto a eliminar, ruta completa o ID
-c txt especifica el comentario para el nuevo objeto
-a atributo1[,atributo2...] : especifica los atributos que
definen los parámetros del nuevo objeto (ver más abajo)

list -f archivo.fwb -o objeto [-r|-c] [-d|-Fformato]

Imprime el nombre y el ID de un objeto.


-f archivo.fwb archivo de datos
-o objeto objeto a imprimir, ruta completa o ID
-r imprime el objeto especificado y todos los objetos bajo él en el árbol
-c imprime solo los objetos hijos del objeto dado pero no
imprime el objeto en sí.
-d imprime un volcado completo de todos los atributos del objeto, incluyendo la información
interna de depuración si está disponible; esto puede ser muy
extenso.
-Fcadena_formato El programa reconoce macros en la cadena de formato
y las reemplaza con los valores de los atributos correspondientes del
objeto. Una macro es el nombre del atributo rodeado
por '%', como '%name%' o '%address%'. Aquí está la
lista de algunos nombres de atributos: "id", "name", "path",
"comment", "type", "address", "netmask", "dnsname". Los objetos de servicio TCP
y UDP proporcionan los atributos
"src_range_start", "src_range_end", "dst_range_start",
"dst_range_end" para los rangos de puertos de origen y destino.
Los objetos de servicio ICMP e ICMP6 tienen los atributos
"icmp_type" y "icmp_code".

add -f archivo.fwb -g grupo -o objeto

Añade el objeto especificado por ruta o ID a un grupo, también especificado por su ruta o ID.


-f archivo.fwb archivo de datos
-g grupo grupo al que se debe añadir el objeto,
ruta completa o ID
-o objeto objeto a eliminar, ruta completa o ID

remove -f archivo.fwb -g grupo -o objeto

Elimina un objeto de un grupo.


-f archivo.fwb archivo de datos
-g grupo grupo del que se debe eliminar el objeto,
ruta completa o ID
-o objeto objeto a eliminar, ruta completa o ID

upgrade -f archivo.fwb

Actualiza el archivo de datos a la última versión de formato de datos.


-f archivo.fwb archivo de datos

checktree -f archivo.fwb

Comprueba la consistencia y corrección del árbol de objetos en el archivo de datos dado y lo repara si es necesario.


-f archivo.fwb archivo de datos

merge -f archivo1.fwb -i archivo2.fwb

Los objetos del archivo2.fwb se fusionan con los objetos en archivo1 y el árbol de objetos combinado se guarda en archivo1.fwb


-f archivo.fwb archivo de datos #1
-i archivo.fwb archivo de datos #2

import -f archivo1.fwb -i firewall_config.txt -o ruta_al_objeto_firewall [-d]

La configuración del firewall del archivo firewall_config.txt se analiza y se importa en el archivo de datos archivo1.fwb. El programa crea un nuevo objeto firewall ubicado en la biblioteca y con el nombre definido por su ruta ruta_al_objeto_firewall.


-f archivo.fwb archivo de datos #1
-i config.txt archivo de configuración del firewall
-o ruta_objeto ruta completa al objeto firewall que será
creado. Esta debe ser una ruta completa, que comience
con el nombre de la biblioteca, como
"/User/Firewalls/my_new_firewall"
-d evita la creación de objetos duplicados durante la importación

actualmente (a partir de la v4.2.0) fwbuilder soporta la importación de configuraciones de iptables guardadas con el comando iptables-save, así como la importación de configuraciones de routers Cisco IOS, y de los firewalls Cisco PIX, ASA y FWSM guardados con el comando "show run".

ATRIBUTOS PARA LOS NUEVOS OBJETOS, POR TIPO

-t Firewall -a plataforma, sistema operativo del host

-t IPv4 -a dirección IP [,máscara]

-t IPv6 -a dirección IPv6 [,longitud_máscara]

-t DNSName -a registro DNS, tiempo de ejecución

-t AddressRange -a dirección de inicio, dirección de fin

-t ObjectGroup

-t Network -a dirección,máscara

-t NetworkIPv6 -a ipv6_address,netmask_length

-t Interval -a hora de inicio,fecha de inicio,día de inicio,hora de fin, fecha de fin, día de fin

-t Interface -a nivel de seguridad,tipo de dirección (dinámica o sin numerar),gestión

-t Host

-t TCPService -a inicio,fin del rango de puertos de origen,inicio,fin del rango de puertos de destino, UAPRSF,UAPRSF

-t UDPService -a inicio,fin del rango de puertos de origen,Inicio,fin del rango de puertos de destino

-t ICMPService -a tipo ICMP,código ICMP

-t IPService -a número de protocolo, lsrr/ssrr/rr/ts/fragm/short_fragm

EJEMPLOS

Imprime el contenido del objeto /User/Firewalls/firewall/eth0 según el formato proporcionado. Nótese que el objeto de tipo "Interface" no tiene un atributo que defina su dirección; la dirección IP está definida por su objeto hijo de tipo IPv4 o IPv6.

fwbedit list -f x.fwb -o /User/Firewalls/firewall/eth0 -F "type=%type% name=%name% id=%id% %comment%"

Imprime el contenido del objeto /User/Firewalls/firewall/eth0 y todos sus objetos hijos. Esta es la forma de ver las direcciones y las máscaras de red. El objeto de interfaz no tiene el atributo "address" por lo que el programa ignora la macro "%address%" cuando imprime la interfaz.

fwbedit list -f x.fwb -o /User/Firewalls/firewall/eth0 -F "type=%type% name=%name% id=%id% %comment% %address%" -r

Imprime el objeto de grupo /User/Objects/Addresses

fwbedit list -f x.fwb -o /User/Objects/Addresses -F "type=%type% name=%name% id=%id% %comment%"

Imprime el objeto de grupo /User/Objects/Addresses y todos los objetos de dirección dentro de él:

fwbedit list -f x.fwb -o /User/Objects/Addresses -F "type=%type% name=%name% id=%id% %comment%" -r

Imprime los objetos de dirección dentro del grupo /User/Objects/Addresses pero no imprime el objeto de grupo en sí:

fwbedit list -f x.fwb -o /User/Objects/Addresses -F "type=%type% name=%name% id=%id% %comment%" -c

Imprime las direcciones y las máscaras de redks de todas las interfaces de todos los firewalls en la forma de su ruta completa del árbol de objetos, seguida del tipo, id, dirección y máscara de red:

fwbedit list -f x.fwb -o /User/Firewalls -F "%path% %type% %id% %address% %netmask%" -r | grep IP

Imprimir nombres, plataforma e información de versión para todos los objetos de firewall definidos en el archivo de datos:

fwbedit list -f x.fwb -o /User/Firewalls -F "%name% platform: %platform% version: %version%" -c

Imprimir nombre, rango de puertos de origen y destino para todos los servicios TCP en la carpeta TCP del grupo definido por el usuario User:

fwbedit list -f x.fwb -o /User/Services/TCP -c -F "name='%name%' est=%established% %src_range_start%-%src_range_end% : %dst_range_start%-%dst_range_end%"

Imprimir tipo y código icmp para todos los servicios ICMP en la carpeta ICMP del grupo definido por el usuario User:

fwbedit list -f x.fwb -o /User/Services/ICMP -c -F "name='%name%' icmp_type=%icmp_type% icmp_code=%icmp_code%"

Añadir dirección IPv6 a una de las interfaces del objeto de firewall "firewall":

fwbedit new -f x.fwb -p /User/Firewalls/firewall/eth3 -t IPv6 -n eth3-v6-addr -a 2001:470:1f05:590::2,64

Añadir referencia al objeto Host 'A' al grupo 'B':

fwbedit add -f x.fwb -g /User/Objects/Groups/B -o /User/Objects/Hosts/A

Añadir referencia al objeto con ID id3D71A1BA al grupo con ID id3D151943. Si los objetos con los IDs dados no existen, fwbedit imprime un mensaje de error y no hace ningún cambio en el archivo de datos.

fwbedit add -f x.fwb -o id3D71A1BA -g id3D151943

Añadir referencia al objeto con ID id3D71A1BA al grupo 'testgroup':

fwbedit add -f x.fwb -o id3D71A1BA -g /User/Objects/Groups/testgroup

El siguiente script usa el comando "list" de fwbedit para imprimir los IDs de todos los objetos Address en la carpeta /User/Objects/Addresses , luego recorre la lista obtenida y usa fwbedit para añadirlos al grupo "group1".


fwbedit list -f x.fwb -o /User/Objects/Addresses -F "%id%" -c | \
while read id; do \
fwbedit add -f x.fwb -g /User/Objects/Groups/group1 -o $id; \
done

Aquí hay un ejemplo ligeramente más complejo. El siguiente script usa el comando "list" de fwbedit para imprimir los tipos y IDs de todos los objetos Address en la carpeta /User/Objects/Addresses , luego los filtra usando grep para obtener solo los objetos IPv6 y finalmente recorre la lista obtenida y usa fwbedit para añadirlos al grupo "group1".


fwbedit list -f x.fwb -o /User/Objects/Addresses -F "%type% %id%" -c | \
grep IPv6 | \
while read type id; do \
fwbedit add -f x.fwb -g /User/Objects/Groups/group1 -o $id; \
done
