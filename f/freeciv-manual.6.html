FREECIV(6) Comandos de usuario FREECIV(6)

NOMBRE

freeciv-manual - Generar manual en formato HTML o wiki para freeciv-server(6)

SINOPSIS

freeciv-manual [opción ...]

-d, --debug NIVEL
Establecer el nivel de registro de depuración (uno de f,e,w,n,v)
-h, --help
Imprimir un resumen de las opciones
-l, --log ARCHIVO
Usar ARCHIVO como archivo de registro

-r, --ruleset REGLAS Generar manual para REGLAS

-v, --version
Imprimir el número de versión
-w, --wiki
Escribir el manual en formato wiki

DESCRIPCIÓN

freeciv-manual genera un subconjunto de la documentación para freeciv-server(6) y las reglas del juego de un conjunto de reglas seleccionado que ejecuta. Actualmente genera 8 archivos:

manual1.html
Opciones del servidor
manual2.html
Comandos del servidor
manual3.html
Terreno
manual4.html
Edificios
manual5.html
Maravillas
manual6.html
Gobiernos
manual7.html
Tipos de unidades
manual8.html
Tecnologías

ERRORES

Esta herramienta es actualmente de poca utilidad para los usuarios finales de Freeciv, y su principal uso es para los mantenedores de Freeciv como punto de partida para las páginas en el wiki principal de Freeciv.

Las deficiencias conocidas incluyen que faltan muchas características del conjunto de reglas.

REPORTE DE ERRORES

Reporte errores en "https://redmine.freeciv.org/projects/freeciv" (pero vea las advertencias anteriores).

VER TAMBIÉN

freeciv-server(6) y el Manual del Cliente en la página de inicio de Freeciv.
