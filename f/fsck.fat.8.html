FSCK.FAT(8) Manual del Administrador del Sistema FSCK.FAT(8)

NOMBRE

fsck.fat - verificar y reparar sistemas de archivos FAT de MS-DOS

SINOPSIS

fsck.fat [OPCIONES] DISPOSITIVO

DESCRIPCIÓN

fsck.fat verifica la consistencia de los sistemas de archivos MS-DOS y opcionalmente intenta repararlos.

Los siguientes problemas del sistema de archivos pueden corregirse (en este orden):

  • La FAT contiene números de clúster inválidos. El clúster se cambia a EOF.
  • La cadena de clústers del archivo contiene un bucle. El bucle se rompe.
  • Clústeres defectuosos (errores de lectura). Los clústeres se marcan como defectuosos y se eliminan de los archivos que los poseen. Esta comprobación es opcional.
  • Directorios con un gran número de entradas defectuosas (probablemente corruptos). El directorio puede eliminarse.
  • Los archivos . y .. no son directorios. Pueden eliminarse o renombrarse.
  • Directorios . y .. en el directorio raíz. Se eliminan.
  • Nombres de archivo defectuosos. Pueden renombrarse.
  • Entradas de directorio duplicadas. Pueden eliminarse o renombrarse.
  • Directorios con un campo de tamaño distinto de cero. El tamaño se establece en cero.
  • El directorio . no apunta al directorio padre. Se ajusta el puntero de inicio.
  • El directorio .. no apunta al padre del directorio padre. Se ajusta el puntero de inicio.
  • . y .. no son las dos primeras entradas en un directorio que no es la raíz. Las entradas se crean, moviendo las ranuras ocupadas si es necesario.
  • El número de clúster inicial de un archivo es inválido. El archivo se trunca.
  • El archivo contiene clústeres defectuosos o libres. El archivo se trunca.
  • La cadena de clústers del archivo es más larga de lo indicado por los campos de tamaño. El archivo se trunca.
  • Dos o más archivos comparten el mismo clúster o clústeres. Todos los archivos excepto uno se truncan. Si el archivo que se está truncando es un archivo de directorio que ya se ha leído, la comprobación del sistema de archivos se reinicia después de la truncación.
  • La cadena de clústers del archivo es más corta de lo indicado por los campos de tamaño. El archivo se trunca.
  • La etiqueta de volumen en el directorio raíz o la etiqueta en el sector de arranque es inválida. Las etiquetas inválidas se eliminan.
  • La etiqueta de volumen en el directorio raíz y la etiqueta en el sector de arranque son diferentes. La etiqueta de volumen del directorio raíz se copia al sector de arranque.
  • Los clústeres están marcados como usados pero no pertenecen a ningún archivo. Se marcan como libres.

•
Parámetros inválidos en el sector de arranque

Cuando fsck.fat verifica un sistema de archivos, acumula todos los cambios en memoria y los realiza solo después de que todas las comprobaciones se hayan completado. Esto puede deshabilitarse con la opción -w .

Se admiten dos variantes diferentes del sistema de archivos FAT. El estándar son los sistemas de archivos FAT12, FAT16 y FAT32 tal como los define Microsoft y que se utilizan ampliamente en discos duros y medios extraíbles como llaves USB y tarjetas SD. La otra es la variante heredada de Atari utilizada en Atari ST.

Hay algunas diferencias menores en el formato de Atari: algunos campos del sector de arranque se interpretan ligeramente diferente, y las entradas especiales de la FAT para fin de archivo y clúster defectuoso pueden ser diferentes. En MS-DOS se usa 0xfff8 para EOF y Atari emplea 0xffff de forma predeterminada, pero ambos sistemas reconocen todos los valores de 0xfff8–0xffff como fin de archivo. MS-DOS usa solo 0xfff7 para clústeres defectuosos, mientras que en Atari los valores 0xfff0–0xfff7 se usan para este propósito (pero el valor estándar sigue siendo 0xfff7).

OPCIONES

-a
Reparar automáticamente el sistema de archivos. No se necesita intervención del usuario. Siempre que haya más de un método para resolver un problema, se utiliza el enfoque menos destructivo.
-A
Seleccionar la variación de Atari del sistema de archivos FAT si no está activa ya, de lo contrario seleccionar el sistema de archivos FAT estándar. Esto se selecciona de forma predeterminada si mkfs.fat se ejecuta en un Atari Linux de 68k.
-b
Realizar una comprobación de solo lectura del sector de arranque.
-c PÁGINA
Usar la página de códigos de DOS PÁGINA para decodificar los nombres de archivo cortos. De forma predeterminada se usa la página de códigos 850.
-d RUTA
Eliminar el archivo especificado. Si existe más de un archivo con ese nombre, se elimina el primero. Esta opción puede darse más de una vez.
-f
Recuperar cadenas de clústeres no utilizadas en archivos. De forma predeterminada, los clústeres no utilizados se añaden al espacio libre del disco excepto en modo automático (-a).
-F NÚM
Especificar la tabla FAT NÚM para el acceso al sistema de archivos. De forma predeterminada se asume el valor 0 y luego se elige la primera tabla FAT no corrupta. No corrupta significa que la tabla FAT tiene un primer clúster válido. Si se usa el valor predeterminado 0 y todas las tablas FAT están corruptas, entonces fsck.fat se rinde e intenta reparar el sistema de archivos FAT. Si se especifica un valor de NÚM distinto de cero, entonces fsck.fat usa la tabla FAT NÚM para reparar el sistema de archivos FAT. Si la tabla FAT NÚM tiene el primer clúster corrupto, entonces fsck.fat lo reparará. En cualquier caso, si el sistema de archivos FAT tiene más de una tabla FAT, el contenido reparado de la tabla FAT elegida se copia a las otras tablas FAT. Para reparar el primer clúster corrupto se requiere llamar a fsck.fat con un valor de NÚM distinto de cero.
-l
Listar los nombres de ruta de los archivos que se están procesando.
-n
Modo de no operación: comprobar errores de forma no interactiva, pero no escribir nada en el sistema de archivos.
-p
Igual que -a, por compatibilidad con otros *fsck.
-r
Reparar el sistema de archivos de forma interactiva. Se le pide consejo al usuario siempre que haya más de un enfoque para corregir una inconsistencia. Este es el modo predeterminado y la opción se mantiene solo por compatibilidad con versiones anteriores.
-S
Considerar que los nombres de archivo cortos (8.3) con espacios en medio son inválidos, como hacían las versiones anteriores de este programa. Aunque la especificación FAT no prohíbe tales nombres de archivo, y las herramientas de comprobación de sistemas de archivos de Microsoft nunca los trataron como errores, muchos programas de DOS son incapaces de manejar archivos con tales nombres. Usar esta opción puede hacerlos accesibles para estos programas.
Los nombres de archivo cortos que comienzan con un espacio se consideran inválidos independientemente de la configuración de esta opción.
Las versiones anteriores de este programa trataban excepcionalmente EA DATA. SF y WP ROOT. SF como nombres cortos válidos; usar esta opción no conserva esa excepción.
-t
Marcar los clústeres ilegibles como defectuosos.
-u RUTA
Intentar deshacer la eliminación del archivo especificado. fsck.fat intenta asignar una cadena de clústeres no asignados contiguos que comienza con el clúster inicial del archivo deseliminado. Esta opción puede darse más de una vez.
-U
Considerar que las etiquetas de volumen y de arranque en minúsculas son inválidas y permitir solo caracteres en mayúsculas. Tales etiquetas están prohibidas por la especificación FAT, pero son ampliamente utilizadas por las herramientas de Linux. Además, los sistemas MS-DOS y Windows no tienen problemas para leerlas. Por lo tanto, las etiquetas de volumen y de arranque con caracteres en minúsculas se permiten de forma predeterminada.
-v
Modo detallado. Genera un poco más de salida.
-V
Realizar un pase de verificación. La comprobación del sistema de archivos se repite después de la primera ejecución. El segundo pase nunca debería informar de ningún error corregible. Puede tardar considerablemente más que el primer pase, porque el primer pase puede haber generado una lista larga de modificaciones que tienen que escanearse para cada lectura de disco.
--variante TIPO
Crear un sistema de archivos de la variante TIPO. Los valores aceptables son standard y atari (en cualquier combinación de mayúsculas/minúsculas). Vea arriba la secciónDESCRIPCIÓN de las diferencias.
-w
Escribe los cambios en el disco inmediatamente.
-y
Igual que -a (reparar el sistema de archivos automáticamente) para compatibilidad con otras herramientas fsck.
--help
Muestra un mensaje de ayuda describiendo el uso y las opciones y luego sale.

ESTADO DE SALIDA

0
No se han detectado errores recuperables.
1
Se han detectado errores recuperables o fsck.fat ha descubierto una inconsistencia interna.
2
Error de uso. fsck.fat no accedió al sistema de archivos.

ARCHIVOS

fsck0000.rec, fsck0001.rec, ...
Al recuperarse de un sistema de archivos dañado, fsck.fat vuelca los datos recuperados en archivos llamados fsckNNNN.rec en el directorio de nivel superior del sistema de archivos.

ERRORES

  • No elimina directorios completamente vacíos.
  • Debería dar más mensajes de diagnóstico.
  • La recuperación de archivos eliminados debería usar un algoritmo más sofisticado.

VÉASE TAMBIÉN

fatlabel(8), mkfs.fat(8)
