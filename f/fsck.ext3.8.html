DESCRIPCIÓ

N

e2fsck se usa para comprobar la familia de sistemas de archivos ext2/ext3/ext4. Para sistemas de archivos ext3 y ext4 que usan un diario, si el sistema se ha apagado de forma no limpia sin ningún error, normalmente, después de reproducir las transacciones confirmadas en el diario, el sistema de archivos debería marcarse como limpio. Por lo tanto, para sistemas de archivos que usan diario, e2fsck normalmente reproducirá el diario y saldrá, a menos que su superbloque indique que se requiere una comprobación

adicional.

device es un dispositivo de bloque (por ejemplo, /dev/sdc1) o un archivo que contiene el sistema de

archivos.

Tenga en cuenta que, en general, no es seguro ejecutar e2fsck en sistemas de archivos montados. La única excepción es si se especifica la opción -n, y no se especifican las opciones -c, -l o -L. Sin embargo, incluso si es seguro hacerlo, los resultados impresos por e2fsck no son válidos si el sistema de archivos está montado. Si e2fsck pregunta si debe o no comprobar un sistema de archivos que está montado, la única respuesta correcta es ``no''. Solo los expertos que realmente saben lo que están haciendo deberían considerar responder a esta pregunta de otra

manera.

Si e2fsck se ejecuta en modo interactivo (lo que significa que no se especifica ninguna de las opciones -y, -n o -p), el programa le pedirá al usuario que corrija cada problema encontrado en el sistema de archivos. Una respuesta de 'y' corregirá el error; 'n' dejará el error sin corregir; y 'a' corregirá el p

roblema y todos los problemas posteriores; presionar Intro procederá con la respuesta predeterminada,
que se imprime antes del signo de interrogación. Presionar Control-C termina e2fsck inmediatamente.

r

Si se especifica un superbloque alternativo y el sistema de archivos no está a
bierto en modo solo lectura, e2fsck se asegurará de que el superbloque principal se
actualice adecuadamente al finalizar la comprobación del sistema de archivos.
-B blocksi
ze
Normalmente, e2fsck buscará el superbloque en varios tamaños de bloque diferentes en un intento de encontrar el tamaño de bloque apropiado. Esta búsqueda puede engañarse en algunos casos. Esta opción fuerza a e2fsck a intentar localizar el superbloque solo en un tamaño de bloque particular. Si el superbloque no se encuentra, e2fsck terminará con un error
fatal.
-
c
Esta opción hace que e2fsck use el programa badblocks(8) para hacer un escaneo de solo lectura del dispositivo para encontrar cualquier bloque defectuoso. Si se encuentran bloques defectuosos, se añaden al inode de bloques defectuosos para evitar que se asignen a un archivo o directorio. Si se especifica esta opción dos veces, entonces el escaneo de bloques defectuosos se hará usando una prueba de lectura-escritura no
destructiva.
-C f
d
Esta opción hace que e2fsck escriba información de finalización en el descriptor de archivo especificado para que se pueda monitorear el progreso de la comprobación del sistema de archivos. Esta opción se usa típicamente por programas que están ejecutando e2fsck. Si el número del descriptor de archivo es negativo, entonces se usará el valor absoluto del descriptor de archivo, y la información de progreso se suprimirá inicialmente. Puede habilitarse más tarde enviando una señal SIGUSR1 al proceso e2fsck. Si el descriptor de archivo especificado es 0, e2fsck imprimirá una barra de finalización mientras va haciendo su trabajo. Esto requiere que e2fsck se esté ejecutando en una consola de video o
terminal.
-
d
Imprime la salida de depuración (inútil a menos que esté depurando e2fsc
k).
-
D
Optimiza los directorios en el sistema de archivos. Esta opción hace que e2fsck intente optimizar todos los directorio
s, ya sea re-indexándolos si el sistema de archivos soporta indexación de directorios, o ordenando y comprimiendo dir
ectorios para directorios más pequeños, o para sistemas de archivos que usan directorios lineales tradicionales.
Incluso sin la opción -D, e2fsck a veces puede optimizar algunos directorios --- por ejemplo, si la indexación de directorios está habilitada y un directorio no está indexado y se beneficiaría de ser indexado, o si las estructuras de índice están corrompidas y necesitan ser reconstruidas. La opción -D fuerza a que todos los directorios del sistema de archivos sean optimizados. Esto a veces puede hacerlos un poco más pequeños y ligeramente más rápidos de buscar, pero en la práctica, rara vez debería necesitar usar esta
opción.
La opción -D detectará entradas de directorio con nombres duplicados en un solo direct
orio, lo que e2fsck normalmente no hace
cumplir por razones de rendimiento.
