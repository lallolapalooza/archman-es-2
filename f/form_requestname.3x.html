form_requestname(3x)

Paquete: ncurses

Licencias: MIT-open-group

form_requestname(3X) Llamadas de biblioteca form_requestname(3X)

NOMBRE

form_request_by_name, form_request_name - manejar nombres imprimibles de solicitud de formulario

SINOPSIS

#include <form.h>
const char *form_request_name(int request);
int form_request_by_name(const char *name);

DESCRIPCIÓN

La función form_request_name devuelve el nombre imprimible de un código de solicitud de formulario. La función form_request_by_name busca en la tabla de nombres una solicitud con el nombre dado y devuelve su código de solicitud. De lo contrario, se devuelve E_NO_MATCH.

VALOR DEVUELTO

form_request_name devuelve NULL en caso de error y establece errno a E_BAD_ARGUMENT.

form_request_by_name devuelve E_NO_MATCH en caso de error. No establece errno.

PORTABILIDAD

Estas rutinas son específicas de ncurses. No eran compatibles en las implementaciones de la Versión 7, BSD o System V. Se recomienda que cualquier código que dependa de ellas se condicione usando NCURSES_VERSION.

AUTORES

Juergen Pfeifer. Páginas de manual y adaptación para new curses por Eric S. Raymond.
