fwide(3) Manual de Funciones de Biblioteca fwide(3)

NOMBRE

fwide - establecer y determinar la orientación de un stream FILE

BIBLIOTECA

Biblioteca C estándar (libc, -lc)

SINOPSIS

#include <wchar.h>
int fwide(FILE *stream, int mode);
Requisitos de Macro de Prueba de Funciones para glibc (ver feature_test_macros(7)):

fwide():

    _XOPEN_SOURCE >= 500 || _ISOC99_SOURCE
        || _POSIX_C_SOURCE >= 200112L

DESCRIPCIÓN

Cuando mode es cero, la función fwide() determina la orientación actual de stream. Devuelve un valor positivo si stream está orientado a caracteres anchos, es decir, si se permiten operaciones de E/S de caracteres anchos pero no se permiten operaciones de E/S de caracteres. Devuelve un valor negativo si stream está orientado a bytes — es decir, si se permiten operaciones de E/S de caracteres pero no se permiten operaciones de E/S de caracteres anchos. Devuelve cero si stream aún no tiene orientación; en este caso, la próxima operación de E/S podría cambiar la orientación (a orientada a bytes si es una operación de E/S de caracteres, o a orientada a caracteres anchos si es una operación de E/S de caracteres anchos).

Una vez que un stream tiene una orientación, no se puede cambiar y persiste hasta que el stream se cierre.

Cuando mode no es cero, la función fwide() intenta primero establecer la orientación de stream (a orientada a caracteres anchos si mode es mayor que 0, o a orientada a bytes si mode es menor que 0). Luego, devuelve un valor que denota la orientación actual, como se describe anteriormente.

VALOR DE RETORNO

La función fwide() devuelve la orientación del stream, después de posiblemente cambiarla. Un valor de retorno positivo significa orientado a caracteres anchos. Un valor de retorno negativo significa orientado a bytes. Un valor de retorno de cero significa indeciso.

ESTANDARES

C11, POSIX.1-2008.

HISTORIA

POSIX.1-2001, C99.

NOTAS

La salida de caracteres anchos a un stream orientado a bytes se puede realizar a través de la función fprintf(3) con las directivas %lc y %ls.

La salida de caracteres a un stream orientado a caracteres anchos se puede realizar a través de la función fwprintf(3) con las directivas %c y %s.

VER TAMBIÉN

fprintf(3), fwprintf(3)
