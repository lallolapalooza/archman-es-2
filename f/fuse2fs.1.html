FUSE2FS(1) Manual de Comandos Generales FUSE2FS(1)

NOMBRE

fuse2fs - Cliente de sistema de archivos FUSE para sistemas de archivos ext2/ext3/ext4

SINOPSIS

fuse2fs [ dispositivo/imagen ] [ punto de montaje ] [ opciones ]

DESCRIPCIÓN

fuse2fs es un cliente de sistema de archivos FUSE que soporta la lectura y escritura desde dispositivos o archivos de imagen que contienen sistemas de archivos ext2, ext3 y ext4.

OPCIONES

opciones generales:

-o opción,[opción...]
opciones de montaje
-h --help
imprimir ayuda
-V --version
imprimir versión

opciones fuse2fs:

-o ro
montaje de solo lectura
-o errors=panic
volcar el núcleo en caso de error
-o minixdf
df estilo minix
-o fakeroot
pretender ser root para comprobaciones de permisos
-o no_default_opts
no incluir opciones de fuse por defecto
-o norecovery
no reproducir el journal y montar el sistema de archivos en modo de solo lectura
-o fuse2fs_debug
habilitar depuración de fuse2fs
-o kernel
Comportarse más como el controlador ext4 del kernel de las siguientes maneras: Permite que procesos propiedad de otros usuarios accedan al sistema de archivos. Utiliza la lógica de comprobación de permisos del kernel en lugar de la de fuse2fs. Habilita los archivos setuid y de dispositivo. Tenga en cuenta que estas opciones aún pueden ser anuladas (por ejemplo, nosuid) posteriormente.
-o direct
Usar O_DIRECT para acceder al dispositivo de bloques.
-o cache_size
Establecer el tamaño de la caché del disco a esta cantidad. La cantidad puede contener los sufijos k, m o g. Por defecto, el tamaño es de 32 MB. El tamaño no puede ser superior a 2 GB.

opciones FUSE:

-d -o debug
habilitar salida de depuración (implica -f)
-f
operación en primer plano
-s
deshabilitar operación multihilo

Para otras opciones de FUSE, consulte mount.fuse(8) o vea la salida de fuse2fs --helpfull

DISPONIBILIDAD

fuse2fs es parte del paquete e2fsprogs y está disponible en http://e2fsprogs.sourceforge.net.

VER TAMBIÉN

ext4(5) e2fsck(8), mount.fuse(8)
