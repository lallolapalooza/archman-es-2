DESCRIPCIÓ

N

Esta función muestra un mensaje descrito por sus argumentos en el dispositivo(s) especificado en el argumento classification. Para los mensajes escritos en stderr, el formato depende de la variable de entorno MSGVERB

.

El argumento label identifica la fuente del mensaje. La cadena debe constar de dos partes separadas por dos puntos, donde la primera parte tiene no más de 10 y la segunda no más de 14

caracteres.

El argumento text describe la condición del

error.

El argumento action describe los posibles pasos para recuperarse del error. Si se imprime, se le antepone "PARA CORREGIR:

".

El argumento tag es una referencia a la documentación en línea donde se puede encontrar más información. Debe contener el valor de label y un número de identificación

único.

Argumentos

ficticios

El valor ficticio de severidad NO_SEV (0) indica que no se proporciona ninguna severidad. ENTORN

O

La variable de entorno MSGVERB ("verbosidad del mensaje") puede usarse para suprimir partes de la salida a stderr. (No influye en la salida a la consola.) Cuando esta variable está definida, no es NULL y es una lista de palabras clave válidas separadas por dos puntos, entonces solo se imprime la parte del mensaje correspondiente a estas palabras clave. Las palabras clave válidas son "label", "severity", "text", "action" y

"tag".

La variable de entorno SEV_LEVEL puede usarse para introducir nuevos niveles de severidad. Por defecto, solo están disponibles los cinco niveles de severidad descritos arriba. Cualquier otro valor numérico haría que fmtmsg() no imprimiera nada. Si el usuario pone SEV_LEVEL con un formato

como
SEV_LEVEL=[descripción[:descripción[:...]]
]

en el entorno del proceso antes de la primera llamada a fmtmsg(), donde cada descripción es de la

forma
palabra-clave-de-severidad,nivel,cadena-de-impresió
n

entonces fmtmsg() también aceptará los valores indicados para el nivel (además de los niveles estándar 0–4), y usará la cadena de impresión indicada cuando ocurra dicho

nivel.

La parte de palabra-clave-de-severidad no es usada por fmtmsg() pero debe estar presente. La parte de nivel es una representación en cadena de un número. El valor numérico debe ser un número mayor que 4. Este valor debe usarse en el argumento severity de fmtmsg() para seleccionar esta clase. No es posible sobrescribir ninguna de las clases predefinidas. La cadena de impresión es la cadena que se imprime cuando un mensaje de esta clase es procesado por fmtm

EJEMPLO

S 
#include <fmtmsg.h>
#include <stdio.h>
#include <stdlib.h>
int
main(void)
{
    long class = MM_PRINT | MM_SOFT | MM_OPSYS | MM_RECOVER;
    int err;
    err = fmtmsg(class, "util-linux:mount", MM_ERROR,
                 "unknown mount option", "See mount(8).",
                 "util-linux:mount:017");
    switch (err) {
    case MM_OK:
        break;
    case MM_NOTOK:
        printf("Nothing printed\n");
        break;
    case MM_NOMSG:
        printf("Nothing printed to stderr\n");
        break;
    case MM_NOCON:
        printf("No console output\n");
        break;
    default:
        printf("Unknown error from fmtmsg()\n");
    }
    exit(EXIT_SUCCESS);
}
