fstrm_capture(1) Manual de Comandos Generales fstrm_capture(1)

NOMBRE

fstrm_capture - Recibe y guarda datos de Frame Streams desde un socket.

SINOPSIS

fstrm_capture -t tipo-de-contenido -w nombre-archivo
[ -u ruta-socket ] [ -a IP -p puerto ]
[ -c max-conexiones ] [ -b tamaño-buffer ]
[ -s segundos ] [ --gmtime ] [ --localtime ]
[ -d [-d ...] ]

fstrm_capture --tipo tipo-de-contenido --escribir nombre-archivo
[ --unix ruta-socket ] [ --tcp IP --puerto puerto ]
[ --maxconns max-conexiones ] [ --buffersize tamaño-buffer ]
[ --split segundos ] [ --gmtime ] [ --localtime ]
[ --debug [--debug ...] ]

DESCRIPCIÓN

fstrm_capture escucha en un socket de dominio UNIX o TCP, recibe datos de Frame Streams y escribe los datos en un archivo.

OPCIONES

-w nombre-archivo | --escribir nombre-archivo
Escribe los datos en el archivo nombre-archivo.

Si se proporciona la opción --gmtime o --localtime, nombre-archivo se procesa con strftime(). Esto permitirá especificar una cadena de formato que incluya la fecha y hora, por ejemplo, para el nombre de archivo creado.

Si nombre-archivo es "-" y la salida estándar no está conectada a una terminal, fstrm_capture escribirá en la salida estándar. La división de salida (-s) no puede usarse con un nombre-archivo de "-".

Enviar SIGHUP a fstrm_capture vaciará cualquier salida en búfer al archivo. Enviar SIGUSR1 cerrará y reabrirá el archivo.

-t tipo-de-contenido | --tipo tipo-de-contenido
Especifica el tipo-de-contenido a recibir del socket y escribir en el nombre-archivo de salida.
-u ruta-socket | --unix ruta-socket
Escucha en el socket de dominio Unix ruta-socket para recibir datos de Frame Streams. Solo se puede dar una de las opciones -u o -a.
-a IP | --tcp IP
Escucha conexiones TCP en la dirección IP para recibir datos de Frame Streams. Solo se puede dar una de las opciones -u o -a. El uso de -a requiere un puerto especificado con -p.
-p puerto | --puerto puerto
Si se proporciona -a, escucha en el puerto TCP puerto para recibir datos de Frame Streams.
-c max-conexiones | --maxconns max-conexiones
Permite un máximo de max-conexiones conexiones simultáneas. Si no se especifica, las conexiones simultáneas no tienen límite.
-b tamaño-buffer | --buffersize tamaño-buffer
Establece el tamaño del búfer de lectura a tamaño-buffer bytes. Combinado con -c, esto se puede usar para limitar el uso total de memoria de fstrm_capture. El tamaño-buffer también afecta al tamaño máximo de fotograma que fstrm_capture aceptará. Los fotogramas más grandes que tamaño-buffer, incluido el encabezado de formato de 4 bytes, se descartarán.

El tamaño-buffer predeterminado es 262144 (256KiB).

-s intervalo | --split intervalo
Reabre el archivo de salida cada intervalo segundos. Requiere el uso de las opciones --gmtime o --localtime.

Tenga en cuenta que esta rotación de archivos se activa por los datos entrantes, por lo que puede retrasarse después del intervalo.

--gmtime
Procesa el nombre de archivo de --escribir a través de strftime() con la hora actual en GMT. Esta opción --gmtime puede usarse para proporcionar un archivo de salida con marca de tiempo al iniciar fstrm_capture o al reabrir un archivo de salida usando la opción --split o al recibir una señal SIGUSR1.
--localtime
Procesa el nombre de archivo de --escribir a través de strftime() con la hora actual en la zona horaria local del sistema. Esta opción --localtime puede usarse para proporcionar un archivo de salida con marca de tiempo al iniciar fstrm_capture o al reabrir un archivo de salida usando la opción --split o al recibir una señal SIGUSR1.
-d [ -d ... ] | --debug [ --debug ]
Aumenta el nivel de depuración. Sin -d, fstrm_capture solo imprime mensajes de error críticos. Se pueden especificar hasta cinco opciones -d, después de las cuales repeticiones adicionales no tendrán efecto.

EJEMPLOS

Recibe datos dnstap y los guarda en archivos que rotan cada hora (con un nombre de archivo convertido como /var/log/dnstap/dnstap-2018-05-04-12:58:48.fstrm).

fstrm_capture -t protobuf:dnstap.Dnstap \
	-u /var/run/named/dnstap.sock \
	-w /var/log/dnstap/dnstap-%F-%T.fstrm \
	-s 3600 --gmtime
