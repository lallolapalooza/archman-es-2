NOMBRE

fribidi_get_bracket - obtener carácter entre corchetes

SINOPSIS

#include <../fribidi/lib/fribidi.h>

FriBidiBracketType fribidi_get_bracket(FriBidiChar ch);

PARÁMETROS

FriBidiChar ch
Carácter de entrada.

DESCRIPCIÓN

Esta función encuentra el equivalente entre corchetes de un carácter tal como se define en el archivo BidiBrackets.txt de la Base de Datos de Caracteres Unicode disponible en http://www.unicode.org/Public/UNIDATA/BidiBrackets.txt.

Si el carácter de entrada se declara como un carácter entre corchetes en el estándar Unicode y tiene un equivalente entre corchetes. El carácter entre corchetes correspondiente se coloca en la salida, de lo contrario se coloca el carácter de entrada mismo.

RETORNA

El tipo de corchete del carácter. Utilice FRIBIDI_IS_BRACKET(FriBidiBracketType) para comprobar si es una propiedad válida.
