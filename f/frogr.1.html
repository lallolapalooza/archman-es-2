NOMBRE

frogr - un Organizador Remoto de Flickr para GNOME

SINOPSIS

frogr [URI-proyecto|URI-medios]

DESCRIPCIÓN

Esta página del manual documenta brevemente el comando frogr.

frogr es una pequeña aplicación para el escritorio GNOME que permite a los usuarios gestionar sus cuentas en el sitio web de alojamiento de imágenes Flickr. Soporta todas las tareas básicas, incluyendo la subida de imágenes y vídeos, la adición de descripciones, la configuración de etiquetas y la gestión de álbumes.

OPCIONES

URI-proyecto
URI completo para un archivo de proyecto que contiene una sesión guardada previamente.
URI-medios
URI completos para imágenes y vídeos que se cargarán junto con la aplicación.

ARCHIVOS

~/.config/frogr/accounts.xml
Archivo de cuentas de frogr.
~/.config/frogr/settings.xml
Archivo de configuración de frogr.
