    fputwc(3p)

    Programmer's Manual

    NOMBRE

    fputwc - escribe un carácter ancho en un flujo (función de biblioteca de C)

    SINOPSIS

    #include <wchar.h>

wint_t fputwc(wchar_t wc, FILE *stream);

    DESCRIPCIÓN

    La función fputwc escribe el carácter ancho dado wc en el flujo indicado por stream.

    Si elstream está abierto en modo binario, el carácter ancho wc se escribe tal como está. Si elstream está abierto en modo de texto, wc se convierte a un carácter multibyte de acuerdo con la configuración regional actual y el carácter multibyte resultante se escribe en elstream.

    Si ocurre un error de escritura, se devuelve WEOF y se establece la variable global errno para indicar el error.

    VALOR DE RETORNO

    En caso de éxito, fputwc devuelve el carácter ancho que se escribió. En caso de error, devuelve WEOF.

    ERRORES

    EAGAIN
    Elstream es un descriptor de archivo asociado con un socket no bloqueante y la escritura requeriría bloqueo.
    EBADF
    El descriptor de archivo asociado constream es inválido.
    EFBIG
    El archivo es demasiado grande.
    EINTR
    Se capturó una señal mientras se intentaba escribir en elstream.
    EIO
    Ocurrió un error de entrada/salida mientras se escribía en elstream.
    ENOSPC
    No hay espacio en el dispositivo para escribir los datos.
    EPIPE
    Se escribió en una tubería rota.
    ENXIO
    El dispositivo especificado porstream no existe.
