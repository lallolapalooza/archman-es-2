flockfile(3) Manual de Funciones de Biblioteca flockfile(3)

NOMBRE

flockfile, ftrylockfile, funlockfile - bloquear FILE para stdio

BIBLIOTECA

Biblioteca C estándar (libc, -lc)

SINOPSIS

#include <stdio.h>
void flockfile(FILE *filehandle);
int ftrylockfile(FILE *filehandle);
void funlockfile(FILE *filehandle);
Requisitos de Macro de Prueba de Funciones para glibc (ver feature_test_macros(7)):

Todas las funciones mostradas arriba:

    /* Desde glibc 2.24: */ _POSIX_C_SOURCE >= 199309L
        || /* glibc <= 2.23: */ _POSIX_C_SOURCE
        || /* glibc <= 2.19: */ _BSD_SOURCE || _SVID_SOURCE

DESCRIPCIÓN

Las funciones stdio son seguras para hilos. Esto se logra asignando a cada objeto FILE un contador de bloqueos y (si el contador de bloqueos es distinto de cero) un hilo propietario. Para cada llamada a la biblioteca, estas funciones esperan hasta que el objeto FILE ya no esté bloqueado por otro hilo, luego lo bloquean, realizan la E/S solicitada y vuelven a desbloquear el objeto.

(Nota: este bloqueo no tiene nada que ver con el bloqueo de archivos realizado por funciones como flock(2) y lockf(3).)

Todo esto es invisible para el programador C, pero puede haber dos razones para desear un control más detallado. Por un lado, tal vez una serie de acciones de E/S de un hilo pertenecen juntas y no deben ser interrumpidas por la E/S de algún otro hilo. Por otro lado, tal vez se deba evitar la sobrecarga de bloqueo para una mayor eficiencia.

Con este fin, un hilo puede bloquear explícitamente el objeto FILE, luego realizar su serie de acciones de E/S, y luego desbloquearlo. Esto evita que otros hilos se interpongan. Si la razón para hacer esto fue lograr una mayor eficiencia, se realiza la E/S con las versiones sin bloqueo de las funciones stdio: con getc_unlocked(3) y putc_unlocked(3) en lugar de getc(3) y putc(3).

La función flockfile() espera a que *filehandle ya no esté bloqueado por otro hilo, luego hace que el hilo actual sea el propietario de *filehandle e incrementa el contador de bloqueos.

La función funlockfile() decrementa el contador de bloqueos.

La función ftrylockfile() es una versión no bloqueante de flockfile(). No hace nada en caso de que otro hilo sea propietario de *filehandle, y obtiene la propiedad e incrementa el contador de bloqueos en caso contrario.

VALOR DE RETORNO

La función ftrylockfile() devuelve cero si tiene éxito (se obtuvo el bloqueo), y un valor distinto de cero en caso de fallo.

ERRORES

Ninguno.

ATRIBUTOS

Para una explicación de los términos utilizados en esta sección, ver attributes(7).

Interfaz Atributo Valor
flockfile (), ftrylockfile (), funlockfile () Seguridad de hilos MT-Safe

ESTÁNDARES

POSIX.1-2008.

HISTORIA

POSIX.1-2001.

Estas funciones están disponibles cuando _POSIX_THREAD_SAFE_FUNCTIONS está definido.
