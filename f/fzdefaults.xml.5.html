NOMBRE

fzdefaults.xml - Opciones predeterminadas para FileZilla

SINOPSIS

/etc/filezilla/fzdefaults.xml
~/.filezilla/fzdefaults.xml

DESCRIPCIÓN

Este archivo de configuración se puede utilizar para especificar algunas opciones predeterminadas a nivel de sistema para FileZilla:

  • Ubicación del directorio de configuración del usuario
  • Lista predefinida de entradas del Gestor de Sitios
  • Modo quiosco para evitar que FileZilla guarde contraseñas
  • Desactivación de la capacidad de comprobación de actualizaciones

Por favor, busque el archivo fzdefaults.xml.example para más información. A menudo se encuentra en el directorio /usr/share/filezilla/docs.

SOPORTE

Por favor, visite https://filezilla-project.org/ para más información. Reporte errores solo si está utilizando la última versión disponible en el sitio web de FileZilla.
