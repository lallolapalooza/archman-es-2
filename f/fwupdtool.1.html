NOMBRE

fwupdtool - utilidad de actualización de firmware independiente

SINOPSIS

fwupdtool [CMD]

DESCRIPCIÓN

Esta herramienta permite a un administrador utilizar los complementos de fwupd directamente sin usar el proceso del demonio, lo que puede ser más rápido o más fácil de usar al crear o depurar complementos específicos. Para la mayoría de los usuarios finales, fwupdmgr es un programa más adecuado para usar en casi todos los casos.

Además, fwupdtool se puede utilizar para convertir firmware de varios formatos diferentes, o para modificar las imágenes contenidas dentro del archivo de firmware del contenedor. Por ejemplo, puede convertir firmware DFU o Intel HEX al formato específico del proveedor.

OPCIONES

El comando fwupdtool toma varias opciones dependiendo de la acción. Ejecute fwupdtool --help para ver la lista completa. Tenga en cuenta que algunos fallos de tiempo de ejecución se pueden ignorar usando --force.

ESTADO DE SALIDA

Los comandos que se ejecutan correctamente devolverán “0”, con un fallo genérico como “1”.

También hay varios otros códigos de salida utilizados: Un código de retorno de “2” se usa para comandos que no tienen acciones pero se ejecutaron correctamente, y “3” se usa cuando no se encontró un recurso.
