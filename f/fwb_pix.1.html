NOMBRE

fwb_ipt - Compilador de políticas para Cisco PIX

SINOPSIS

fwb_pix -farchivo_datos.xml [-V] [-ddirectorio_trabajo] [-i] [-v] [-xc] [-xt] nombre_objeto

DESCRIPCIÓN

fwb_pix es un componente del compilador de políticas de firewall de Firewall Builder (ver fwbuilder(1)). El compilador lee las definiciones de objetos y la descripción del firewall del archivo de datos especificado con la opción "-f" y genera el archivo de configuración de Cisco PIX resultante. La configuración se escribe en un archivo con el mismo nombre que el objeto del firewall, más la extensión ".fw".

El archivo de datos y el nombre del objeto del firewall deben especificarse en la línea de comandos. Otros parámetros de la línea de comandos son opcionales.

OPCIONES

-f ARCHIVO
Especifica el nombre del archivo de datos a procesar.
-d directorio_trabajo
Especifica el directorio de trabajo. El compilador crea el archivo de configuración de PIX en este directorio. Si este parámetro falta, la configuración de PIX se colocará en el directorio de trabajo actual.
-v
Sea detallado: el compilador imprime mensajes de diagnóstico cuando funciona.
-V
Imprime el número de versión y sale.
-i
Cuando esta opción está presente, el último argumento en la línea de comandos se supone que es el ID del objeto del firewall en lugar de su nombre.
-xc
Cuando el nombre del archivo de salida se determina automáticamente (es decir, no están presentes las banderas -o ni -O), el nombre del archivo se compone del nombre del clúster y el nombre del firewall miembro en lugar de solo el nombre del firewall miembro. Esto se utiliza principalmente para pruebas, cuando el mismo objeto de firewall miembro puede ser parte de diferentes clústeres con diferentes configuraciones.
-xt
Esta bandera hace que el compilador trate todos los errores fatales como advertencias y continúe procesando las reglas. Es muy probable que el script de configuración generado sea incorrecto, pero incluirá el mensaje de error como un comentario; esta bandera se utiliza para pruebas y depuración.
