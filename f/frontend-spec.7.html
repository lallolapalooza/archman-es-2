NOMBRE

frontend-spec - interfaz entre jw y sus frontends

DESCRIPCIÓN

jw(1) llama a frontends como frontends/docbook para obtener la información específica de un formato de entrada dado. El frontend sabe qué información devolver a partir del primer parámetro de la línea de comandos. Recibe todos los datos necesarios a través de variables de entorno listos para usar.

Este documento describe ese parámetro de la línea de comandos y esas variables de entorno.

El frontend debe devolver 0 si no hubo ningún problema, y devolver un valor positivo en caso contrario.

VARIABLES

$1
El parámetro de la línea de comandos, especificando qué información devolver. Puede tomar los siguientes valores:
catálogo-centralizado
El frontend debe devolver el nombre del catálogo centralizado específico de la DTD. Los catálogos centralizados normalmente residen en /etc/sgml y proporcionan la ubicación de todos los archivos de catálogo útiles para manejar este tipo de entrada (el catálogo de la DTD, el catálogo de las hojas de estilo, el catálogo de las entidades,
hoja-de-estilo
El frontend debe devolver el nombre del archivo de la hoja de estilo que se utilizará para este tipo de documento y con el backend elegido.
SGML_CATALOGS_DIR
El directorio donde residen los catálogos centralizados. Normalmente es /etc/sgml.

(Esta variable solo es válida mientras se determina el catálogo centralizado a usar.)

SGML_BASE_DIR
El directorio base del sistema SGML. Normalmente es /usr/share/sgml.

(Esta variable solo es válida mientras se determina la hoja de estilo a usar.)

SGML_FILE
El nombre del archivo a convertir.

(Esta variable solo es válida mientras se determina el catálogo centralizado a usar.)

SGML_TYPE
El tipo de backend a utilizar, ya sea que produzca archivos de salida para ser mostrados en línea o para ser impresos. Puede tomar el valor html o print.

(Esta variable solo es válida mientras se determina la hoja de estilo a usar).

SGML_STYLESHEETS
El tipo de hoja de estilo personalizada deseada, ya sea none o default. Si es none, el frontend debe devolver el nombre del archivo de la hoja de estilo proporcionado por el sistema debajo de docbook-utils. Si es default, el frontend debe devolver la hoja de estilo personalizada proporcionada por docbook-utils.

(Esta variable solo es válida mientras se determina la hoja de estilo a usar).

SGML_XML
El metalenguaje del archivo a convertir, ya sea sgml o xml.

(Esta variable solo es válida mientras se determina el catálogo centralizado a usar).
