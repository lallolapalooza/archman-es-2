XHOST(1) Manual de Comandos Generales XHOST(1)

NOMBRE

xhost - programa de control de acceso al servidor para X

SINOPSIS

xhost [[+-]nombre ...]

DESCRIPCIÓN

El programa xhost se utiliza para añadir y eliminar nombres de host o nombres de usuario de la lista permitida para realizar conexiones al servidor X. En el caso de los hosts, esto proporciona una forma rudimentaria de control de privacidad y seguridad. Sólo es suficiente para un entorno de estación de trabajo (un solo usuario), aunque limita los peores abusos. Los entornos que requieren medidas más sofisticadas deberían implementar el mecanismo basado en usuarios o utilizar los ganchos del protocolo para pasar otros datos de autenticación al servidor.

OPCIONES

xhost acepta las siguientes opciones de línea de comandos descritas a continuación. Por seguridad, las opciones que afectan al control de acceso sólo pueden ejecutarse desde el "host de control". Para las estaciones de trabajo, esta es la misma máquina que el servidor. Para las terminales X, es el host de inicio de sesión.

-ayuda
Imprime un mensaje de uso.
[+]nombre
El nombre dado (el signo más es opcional) se añade a la lista de permitidos para conectarse al servidor X. El nombre puede ser un nombre de host o un nombre completo (Ver NOMBRES para más detalles).
-nombre
El nombre dado se elimina de la lista de permitidos para conectarse al servidor. El nombre puede ser un nombre de host o un nombre completo (Ver NOMBRES para más detalles). Las conexiones existentes no se rompen, pero los nuevos intentos de conexión serán denegados. Tenga en cuenta que la máquina actual puede ser eliminada; sin embargo, no se permitirán más conexiones (incluidos los intentos de volver a añadirla). Reiniciar el servidor (rompiendo así todas las conexiones) es la única forma de permitir de nuevo las conexiones locales.
+
Se concede acceso a todo el mundo, incluso si no están en la lista (es decir, se desactiva el control de acceso).
-
El acceso se restringe sólo a los que están en la lista (es decir, se activa el control de acceso).
nada
Si no se proporcionan argumentos en la línea de comandos, se imprime un mensaje indicando si el control de acceso está actualmente habilitado o no, seguido de la lista de los permitidos para conectarse. Esta es la única opción que se puede usar desde máquinas distintas al host de control.

NOMBRES

Un nombre completo tiene la sintaxis ``familia:nombre'' donde las familias son las siguientes:

inet	Host de Internet (IPv4)
inet6	Host de Internet (IPv6)
dnet	Host DECnet
nis	Nombre de red RPC segura
krb	Principal de Kerberos V5
local	contiene solo un nombre, la cadena vacía
si	Interpretado por el servidor

La familia no distingue entre mayúsculas y minúsculas. El formato del nombre varía según la familia.

Cuando se utiliza RPC segura, se puede especificar el nombre de red independiente (por ejemplo, "nis:unix.uid@nombre_dominio"), o se puede especificar un usuario local sólo con el nombre de usuario y un signo arroba al final (por ejemplo, "nis:pat@").

Para compatibilidad con versiones anteriores a xhost R6, los nombres que contienen un signo arroba (@) se suponen de la familia nis. De lo contrario, se suponen direcciones de Internet. Si está compilado para soportar IPv6, todas las direcciones IPv4 e IPv6 devueltas por getaddrinfo(3) se añaden a la lista de acceso en la familia inet o inet6 apropiada.

La familia local especifica todas las conexiones locales a la vez. Sin embargo, la dirección interpretada por el servidor "si:localuser:nombre_usuario" puede usarse para especificar un usuario local individual. (Ver la página del manual de Xsecurity(7) para más detalles).

Las direcciones interpretadas por el servidor consisten en una etiqueta de tipo sensible a mayúsculas y minúsculas y una cadena que representa un valor dado, separadas por dos puntos. Por ejemplo, "si:hostname:almas" es una dirección interpretada por el servidor de tipo hostname, con un valor de almas. Para más información sobre las formas disponibles de direcciones interpretadas por el servidor, ver la página del manual de Xsecurity(7).

La lista inicial de control de acceso para el display número n puede ser establecida por el archivo /etc/Xn.hosts, donde n es el número de display del servidor. Ver Xserver(1) para más detalles.

DIAGNÓSTICOS

Para cada nombre añadido a la lista de control de acceso, se imprime una línea del tipo "nombre se está añadiendo a la lista de control de acceso". Para cada nombre eliminado de la lista de control de acceso, se imprime una línea del tipo "nombre se está eliminando de la lista de control de acceso".

VER TAMBIÉN

X(7), Xsecurity(7), Xserver(1), xdm(1), xauth(1), getaddrinfo(3)

AMBIENTE

DISPLAY
para obtener el host y display por defecto a usar.

ERRORES

No se puede especificar un display en la línea de comandos porque -display es un argumento de línea de comandos válido (indicando que quiere eliminar la máquina llamada ``display'' de la lista de acceso).

El servidor X almacena direcciones de red, no nombres de host, a menos que utilice la dirección de tipo nombre de host interpretada por el servidor. Si de alguna manera cambia la dirección de red de un host mientras el servidor todavía está en ejecución, y está utilizando una forma de autenticación basada en direcciones de red, se debe usar xhost para añadir la nueva dirección y/o eliminar la dirección antigua.
