XINE-CHECK(1) Manual de Comandos Generales XINE-CHECK(1)

NOMBRE

xine-check - un verificador para el reproductor de video xine

SINOPSIS

xine-check [-q] [-v] [-B] [-b]
xine-bugreport [-q] [-v] [-B]

DESCRIPCIÓN

Esta página del manual explica el programa xine-checker. xine-check es un programa que prueba la instalación del reproductor de video xine en busca de problemas comunes.

Si experimenta algún problema con o al ejecutar xine, ejecutar xine-check podría proporcionar pistas útiles para el seguimiento de problemas.

xine-check prueba la configuración del sistema operativo, la instalación de plugins, la configuración de la unidad de CD/DVD y los parámetros de soporte de video.

Si se ejecuta como xine-bugreport, producirá una descripción concisa del sistema y le guiará a través del proceso de reporte de un error. Esta es la forma preferida de reportar errores de xine, ya que es más sencilla para usted y proporciona a los desarrolladores un informe de error más completo.

OPCIONES

El programa sigue la sintaxis habitual de línea de comandos de GNU, con opciones largas que comienzan con dos guiones (`-'). A continuación se incluye un resumen de las opciones. Para una descripción completa, consulte README y FAQ en /usr/share/doc/xine-ui o en la página principal de xine.

-h, --help
Muestra un resumen de las opciones y el número de versión.

Las opciones restantes, etiquetadas como Opciones de XINE-CHECK: cuando se enumeran con "xine-check --help", se explican aquí.

-q, --quiet
Solo proporciona mensajes de una sola línea, incluso si se encuentran problemas. Normalmente xine-check proporciona pistas para cada problema encontrado para ayudar a resolverlo.
-v, --verbose
Habilita la salida extendida que describe cada verificación en detalle, lo que produce una especie de lista de preguntas frecuentes (FAQ).
-B, --batch
Desactiva la pausa después de mensajes largos. Normalmente xine-check espera confirmación después de encontrar un problema o imprimir un mensaje largo.
-b, --bug
Produce un informe de error. Esto es lo mismo que llamar a xine-bugreport directamente.

ERRORES
