XINE(1) Manual de comandos generales XINE(1)

NOMBRE

xine - un reproductor de vídeo gratuito

SINOPSIS

xine [opciones] [MRL] ...

DESCRIPCIÓN

Esta página del manual documenta brevemente el reproductor de audio/vídeo xine.

xine reproduce flujos de sistema MPEG (audio y vídeo), flujos elementales mpeg (por ejemplo, archivos .mp3 o .mpv), flujos de transporte mpeg, archivos ogg, archivos avi, archivos asf, archivos quicktime, (S)VCDs y DVDs y muchos más.

OPCIONES

Los programas siguen la sintaxis habitual de línea de comandos de GNU, con opciones largas que comienzan con dos guiones (`--'). A continuación se incluye un resumen de las opciones. Para una descripción completa, consulte README y FAQ en /usr/share/doc/xine-ui o en la página principal de xine.

-h, --help
Muestra un resumen de las opciones y los controladores de salida (plugins) disponibles.
--verbose[=nivel]
Establece el nivel de verbosidad.
-c, --config <archivo>
Utiliza el archivo de configuración en lugar del predeterminado.
-a, --audio-channel <num>
Selecciona el canal de audio dado. <num> es el número del canal de audio, el valor predeterminado es 0.
xine 0.5 y versiones posteriores hacen todo lo posible para recopilar todos los canales de audio válidos (ac3, mpeg audio, avi audio, ...) del flujo y los mapea a canales "virtuales" con números de canal que comienzan en 0.
-V, --video-driver <drv>
Selecciona el controlador de vídeo. Consulta xine --help para ver una lista de los plugins de salida de vídeo disponibles en tu sistema. Esta selección se almacena automáticamente en tu ~/.xine/config, por lo que solo tendrás que especificar el controlador de vídeo una vez.
-A, --audio-driver <drv>
Selecciona el controlador de audio. Consulta xine --help para ver una lista de los plugins de salida de audio disponibles en tu sistema. Esta selección se almacena automáticamente en tu ~/.xine/config, por lo que solo tendrás que especificar el controlador de audio una vez.
-u, --spu-channel <num>
Selecciona el canal de subpictures (subtítulos). <num> es el ID del canal de subpictures, el valor predeterminado es sin subtítulos (-1).
-p, --auto-play=[f][F][h][w][q][d][v]
Comienza a reproducir inmediatamente después del inicio. Puede ir seguido de:
`f' en modo de pantalla completa,
`F' en modo de pantalla completa xinerama,
`h' oculta la GUI (panel principal, etc.),
`w' oculta la ventana de salida de vídeo,
`q' para salir después de la reproducción,
También es posible solicitar la lista de reproducción de DVD `d', o VCD `v'. Ahora hay una opción más genérica, --auto-scan, para ello (ver más abajo).
-s, --auto-scan <plugin>
Escanea automáticamente la lista de reproducción del plugin de entrada indicado. Muchos plugins permiten leer una lista de reproducción predeterminada, para reproducir todo. Esto funciona bien para DVDs o VCDs, por ejemplo. Dar esta opción tiene el mismo efecto que presionar el botón correspondiente en el panel principal de xine.

Esta opción es especialmente útil en combinación con la reproducción automática. Podrías iniciar xine --auto-play --auto-scan dvd para reproducir un DVD completo sin tener que presionar ningún botón adicional. Esto también funciona para plugins que no se suministran con xine, ¡simplemente indica el nombre del botón que el plugin deseado añade al panel de xine!

-f, --fullscreen
Cambia xine a modo de pantalla completa al inicio (igual que al presionar `f')
-F, --xineramafull
Cambia xine a modo de pantalla completa xinerama al inicio (igual que al presionar `F'). Es decir, intenta expandir la visualización en varias pantallas. Las pantallas a utilizar se definen en el archivo de configuración.
-g, --hide-gui
Oculta todas las ventanas de la GUI (excepto la ventana de vídeo) al inicio. Esto es lo mismo que presionar `G' dentro de xine.
-H, --hide-video
Oculta la ventana de salida de vídeo.
-L, --no-lirc
Desactiva el soporte LIRC. Esta opción solo está disponible si xine se ha compilado con soporte LIRC.
--visual <clase-o-id-visual-de-x11>
Intenta utilizar un visual de servidor X11 específico para las ventanas de xine. El parámetro <clase-o-id-visual-de-x11> es el nombre de una clase visual de X11 (StaticGray, GrayScale, StaticColor, PseudoColor, TrueColor o DirectColor) o el valor hexadecimal de un visual X11 específico.

Cuando se utiliza con un nombre de clase visual, xine intenta encontrar un visual de este tipo con profundidad 15 o 16, 24, 32 u 8 (en ese orden). La clase visual predeterminada utilizada por xine en ausencia de una opción --visual es TrueColor.

Si no se encuentra ningún visual utilizable, xine recurre al visual predeterminado utilizado en la ventana raíz del servidor X11.

--install
Al utilizar un visual X11 con colores modificables (mapas de colores), instala un mapa de colores privado para xine. Con un mapa de colores privado, xine puede asignar más colores para que la salida de vídeo se vea mejor.
--keymap [=opción]
Muestra el mapa de teclas. Las opciones son:
`default' muestra la tabla de mapa de teclas predeterminada,
`lirc' muestra un borrador de un archivo de configuración ~/.lircrc,
`remapped' tabla de mapa de teclas reasignada por el usuario,
`file:<archivo>' utiliza archivo como tabla de mapa de teclas,
Si no se proporciona ninguna opción, se selecciona `default'.
-n, --network
Habilita el servidor de control remoto por red. Para utilizar el servidor de control remoto por red, se requiere un archivo de contraseñas. Si xine no lo encuentra, el servidor se detiene. La sintaxis del archivo de contraseñas sigue el esquema (familiar) de <identificación>:<contraseña>. Dado que la criptografía está sujeta a problemas legales en algunos países, la contraseña no está cifrada y se transmite sin cifrar, así que tenga cuidado con las conexiones remotas. También hay disponibles dos reglas genéricas (opcionales) (una a la vez): 
ALL:ALLOW o ALL:DENY
En el primer caso, se permite a todos los clientes ejecutar todos los comandos disponibles, sin restricciones. En el segundo caso, a nadie se le permite ejecutar ningún comando, excepto a los usuarios identificados (utilizando el comando 'identify').

Si una entrada de contraseña comienza con un asterisco `*', el usuario está bloqueado. Si una entrada de contraseña está vacía, la entrada completa se ignora. Aquí hay un ejemplo de un pequeño archivo ~/.xine/passwd:

ALL:DENY
daniel:mypasswd
foo:*
Esto solo permitirá a 'daniel' ejecutar comandos, después de una etapa de identificación exitosa.

El puerto predeterminado del servidor es 6789, este número es totalmente arbitrario. Puedes conectarte al servidor usando un simple comando telnet:

telnet localhost 6789
Para cambiar el puerto predeterminado, puedes (como root) editar tu /etc/services, y añadir una entrada como esta: 
xinectl    7890/tcp        # control de xine
Esto cambiará el puerto predeterminado de 6789 a 7890, y creará un servicio "humano" llamado xinectl.

El servidor en sí ofrece ayuda/sintaxis de comandos:
help [comando]
Sin especificar comando, se mostrarán todos los comandos disponibles. Si se especifica un comando, se dará un texto breve sobre la funcionalidad del comando.
syntax <comando>
Muestra la sintaxis del comando.

OPTIONS

-R, --root
Usar la ventana raíz como ventana de vídeo.
-G, --geometry <AnxAl[+X+Y]>
Puedes definir el tamaño y la posición de la salida de vídeo usando la geometría de X (ver X(7)). Los desplazamientos X e Y son opcionales.
-B, --borderless
Eliminar los bordes de la ventana de salida de vídeo, en modo ventana.
-N, --animation <mrl>
Especificar uno o más mrl para reproducir con flujos solo de audio.
-P, --playlist <nombre_archivo>
Usar el archivo como lista de reproducción. Los formatos conocidos son: asx, toxine, m3u, pls, sfv y archivo de texto plano.
-l, --loop [=modo]
Establecer el modo de bucle de la lista de reproducción. Si no se especifica el modo, se usa el modo loop. Los modos posibles son:
loop: buclar toda la lista de reproducción.
repeat: repetir la entrada actual de la lista de reproducción.
shuffle: seleccionar aleatoriamente una entrada de la lista de reproducción de las que aún no se han reproducido.
shuffle+: igual que shuffle, pero reproducir la lista de reproducción indefinidamente.
--skin-server-url <url>
Definir la url del servidor de skins.
--enqueue <mrl>...

Añadir uno o más mrl a una sesión en curso (sesión 0).
Si quieres especificar otra sesión, usa la opción -S session=x.
-S, --session <opcion1,opcion2,...>

Gestión de sesiones. Todas las opciones se pueden usar más de una vez, excepto session.
Las opciones son:
session=n especifica el número de sesión <n>,
mrl=m añade el mrl <m> a la lista de reproducción,
audio=c selecciona el canal de audio (<c>: next o prev),
spu=c selecciona el canal spu (<c>: next o prev),
volume=v establece el volumen de audio (<v>: de 0 a 100),
amp=v establece la amplificación de audio de la instancia (<v>: de 0 a 200),
loop=m establece el modo de bucle (<m>: none loop repeat shuffle o shuffle+),
get_speed obtiene el estado de velocidad actual. Los valores de retorno son:
- 1: error
- 2: stop
- 3: play
- 4: pause
- 5: slow4
- 6: slow2
- 7: fast2
- 8: fast4
get_time[=p|pos] obtiene la posición actual en segundos, o en posición en el flujo (0..65535).
(playlist|pl)=p
<p> puede ser:
clear: limpiar la lista de reproducción,
first: reproducir la primera entrada de la lista de reproducción,
prev: reproducir la entrada anterior de la lista de reproducción,
next: reproducir la siguiente entrada de la lista de reproducción,
last: reproducir la última entrada de la lista de reproducción,
load:s: cargar el archivo de lista de reproducción <s>,
stop: detener la reproducción al final de la reproducción actual,
cont: continuar la reproducción al final de la reproducción actual.
También hay algunas opciones autoexplicativas.
play, slow2, slow4, pause, fast2, fast4, stop, quit, fullscreen, eject.
-Z
No iniciar la reproducción automáticamente, solo afecta al inicio automático cuando se utiliza el modo inteligente.
-D, --deinterlace [post[:..][;]]
Reducir el entrelazado de la salida de vídeo. Puedes anular la opción de configuración de los posts utilizados para reducir el entrelazado de la imagen de salida. Ver --post para la sintaxis.
-r, --aspect-ratio <modo>
Establecer la relación de aspecto de la salida de vídeo. <modo> puede ser: auto, square, 4:3, anamorphic, dvb.
--broadcast-port <puerto>
Establecer el puerto del emisor de xine (lado maestro), el esclavo se inicia con 'xine slave://direccion:puerto'
--no-logo
No mostrar el logo.
-E, --no-reload
No recargar la lista de reproducción antigua. La lista de reproducción se guarda al salir de xine, luego se recarga y se reproduce la próxima vez que inicies xine. Esta función se puede deshabilitar a través de la ventana de configuración.
--post <plugin>[:parametro=valor][,...][;...]
Cargar uno o más plugins post. Los parámetros se separan por comas. Esta opción se puede usar más de una vez para encadenar dos o más plugins de postprocesado de vídeo. Puedes especificar dos o más plugins, que pueden estar separados por un punto y coma ';'.
--disable-post
No habilitar los plugins post. De esta forma, puedes especificar uno o más plugins para usar, usando la opción de línea de comandos --post, pero sin habilitar esos efectos.
--no-splash
No mostrar la pantalla de presentación.
--stdctl
Activar el control de xine a través de STDIN.
-T, --tvout<backend>
Activar el soporte de TVout. <backend> puede ser: nvtv, ati.
--list-plugins[=tipo]
Mostrar la lista de plugins disponibles. El <tipo> opcional puede ser: audio_out, video_out, demux, input, sub, post, audio_decoder, video_decoder
--bug-report[=mrl]
Habilitar el modo de reporte de errores. Esto activa la verbosidad, recopila todos los mensajes de salida y los escribe en un archivo llamado BUG-REPORT.TXT. Si se proporciona <mrl>, xine reproducirá ese mrl y luego saldrá (como lo hace -pq).

Si no especificas ningún MRL, tendrás que seleccionar un archivo arrastrando y soltando. Se sabe que arrastrar archivos desde el GNOME Midnight Commander (gmc), Nautilus o Konqueror funciona.

MRL (localizador de recursos multimedia)

Los MRL son similares a las URL en tu navegador web. Describen el medio a leer. xine(5) los describe con cierto detalle. xine extiende la sintaxis de la siguiente manera:

<mrl>::<archivo_subtitulos>
Esta es la forma específica de xine-ui para definir el archivo de subtítulos a usar. El nombre del archivo será extraído por el frontend, lo que permite cambiarlo, guardarlo en una lista de reproducción, etc...

OPCIONES DE TRANSMISIÓN

Después de un delimitador # puedes añadir varios parámetros de transmisión:

novideo
se ignorará el vídeo
noaudio
se ignorará el audio
nospu
se ignorarán los subpictures
demux:<nombre_demuxer>
especificar el plugin demuxer a usar
volume:<nivel>
establecer el volumen de audio
compression:<nivel>
establecer la compresión del rango dinámico de audio
<entrada_configuracion>:<valor_configuracion>
asignar un nuevo valor a cualquier entrada de configuración
cambiar la opción de configuración 'sobre la marcha':

Puedes cambiar una opción de configuración en cualquier momento, usando el estilo especial cfg:/ mrl. La sintaxis es:
cfg:/<entrada_configuracion> : <valor_configuracion>
A diferencia de las opciones de configuración de transmisión, puedes cambiar cualquier cosa *antes* de reproducir la transmisión.

MRL (media resource locator)

En xine, una MRL es una cadena que describe la ubicación de un recurso multimedia. La sintaxis de las MRLs se describe en la página del manual xine(5). Las MRLs pueden ser pasadas a xine como argumentos de línea de comandos, o pueden ser especificadas a través de la GUI.

Se puede solicitar la reproducción de la siguiente MRL: file:///usr/share/doc/xine/README.html como se describe en la descripción.

Las MRLs pueden ser guardadas en la opción de menú "File->Save MRL as..." o pueden ser introducidas en la línea de comando: xine dvd://<device>.

STREAM OPTIONS

Se pueden pasar algunas opciones adicionales directamente a la MRL. Estas opciones se añaden al final de la MRL, separadas por |. Por ejemplo, la siguiente MRL puede reproducir un archivo MPG, pero si la reproducción se detiene, buscará la siguiente MRL en su lugar.

file:///path/to/file.mpg|dvd://
<device>

Otras opciones son: loop, realtime, nograb, pause, title, chapter, seek, frames, start, stop, speed, display, port, remote, port y remote.

Por ejemplo:

  • file:///path/to/file.mpg|seek=100 busca 100 segundos en el archivo.
  • file:///path/to/file.mpg|start=100|stop=200 reproduce sólo la porción del archivo entre 100 y 200 segundos.
  • dvd://|title=3|chapter=5 reproduce el título 3, capítulo 5 de un DVD.
  • vcd://|track=5 reproduce la pista 5 de un VCD.

La opción % o / se puede usar para indicar un porcentaje del stream. El porcentaje especificado se aplica como un factor de desplazamiento. Así, "50%" o "50/" le lleva a la mitad del stream.

El nuevo plugin VCD/SVCD permite alguna entrada numérica. Introduciendo un número seguido de la tecla "Seleccionar evento" (por defecto, la tecla Enter del teclado numérico), se puede ir a un "Capítulo" (pista o entrada) o número de selección específico. Como se trata de una característica relativamente nueva, quizás con el tiempo más plugins harán uso de la selección numérica.

Otros comandos que pueden ser prefijados numéricamente por un argumento numérico son la siguiente/anterior MRL (MRL_NEXT, MRL_PRIOR), el siguiente/anterior subtítulo (SPU_NEXT, SPU_PRIOR), y el siguiente/anterior canal de audio (AUDIOCHAN_NEXT, AUDIOCHAN_PRIOR). Con un prefijo numérico, es como si se hubiera introducido ese comando el número de veces. Aquí, el argumento 0, ya que de lo contrario sería insignificante, se interpreta aquí como 1.

Hay que admitir que el uso de la entrada numérica aquí es de valor limitado. Con el tiempo, quizás se implementen comandos más útiles como especificar un número de MRL, subtítulo o canal de audio específico o absoluto.
