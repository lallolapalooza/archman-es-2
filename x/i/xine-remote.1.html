XINE-REMOTE(1) Manual de Comandos Generales XINE-REMOTE(1)

NOMBRE

xine-remote - una pequeña herramienta para conectar el servidor de control remoto de xine.

SINOPSIS

xine-remote [opciones]

DESCRIPCIÓN

Esta página del manual documenta brevemente la herramienta xine-remote.

xine-remote puede reemplazar una conexión telnet cruda a un servidor de control remoto de xine. Utiliza las facilidades de readline (autocompletado, atajos vi/emacs, historial de comandos, etc...). Por defecto, intenta conectarse al localhost, usando el puerto predeterminado (ver xine(1)).

OPCIONES

El programa sigue la sintaxis habitual de línea de comandos de GNU, con opciones largas que comienzan con dos guiones (`-´). A continuación se incluye un resumen de las opciones.

-H, --host <nombre-host>
Intenta conectarse a <nombre-host>.
-P, --port <puerto>
Intenta conectarse al host usando el <puerto>.
-c, --command <comando>
Envía <comando> al servidor y luego sale. El comando debe ir entre comillas simples si contiene espacios o caracteres especiales.
-n, --noconnect
No inicia la conexión al arrancar.
-v, --version
Muestra la versión.
-h, --help
Muestra el resumen de opciones.

COMANDOS

Hay pocos comandos disponibles, que se utilizan para abrir o cerrar una conexión:

?
Muestra los comandos disponibles (los de xine-remote más los del servidor cuando la conexión se establece).
ayuda <comando>
Muestra el propósito de <comando>. Si este se omite, muestra los comandos disponibles.
sintaxis <comando>
Muestra el uso de <comando>.
version
Muestra la versión.
abrir <servidor[:puerto]>
Abre la conexión al servidor. Opcionalmente se puede especificar un puerto, usando dos puntos (:) como separador.
cerrar
Cierra la conexión.
salir
Abandona xine-remote.

VER TAMBIÉN

xine(1).
