NOMBRE

xine-config - script para obtener información sobre la versión instalada de libxine

SINOPSIS

xine-config [--prefix[=DIR]] [--exec-prefix[=DIR]] [--version] [--libs] [--cflags] [--objcflags] [--plugindir] [--datadir] [--scriptdir] [--localedir]

DESCRIPCIÓN

xine-config está MARCADO PARA SER ELIMINADO. Usa pkg-config en su lugar.

xine-config es una herramienta que se utiliza para determinar las banderas del compilador y del enlazador que deben utilizarse para compilar y enlazar programas que usan libxine. También se puede utilizar para determinar los directorios donde libxine espera los plugins.

OPCIONES

xine-config acepta las siguientes opciones, pasándolas (posiblemente modificadas) a pkg-config libxine:

--version
--modversion
Imprime la versión actualmente instalada de libxine en la salida estándar.
--libs
--cflags
--objcflags
Pasadas sin modificar.
Imprime las banderas del compilador (para C y Objective C, respectivamente) que son necesarias para compilar un programa que usa libxine.
--bindir
--plugindir
--datadir
--scriptdir
--localedir
--variable=...
Imprime el directorio donde, respectivamente, se almacenan/esperan los binarios, plugins, archivos de datos, scripts y datos de localización de libxine.
--prefix=PREFIX
--define-variable=prefix=PREFIX
Si se especifica, utiliza PREFIX en lugar del prefijo de instalación con el que se construyó xine-lib. Esta opción también se usa para el prefijo de ejecución si no se especificó --exec-prefix.
--exec-prefix=PREFIX
--define-variable=exec_prefix=PREFIX
Si se especifica, utiliza PREFIX en lugar del prefijo de ejecución de instalación con el que se construyó xine-lib.
