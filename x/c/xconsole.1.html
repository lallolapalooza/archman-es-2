XCONSOLE(1) Manual de comandos generales XCONSOLE(1)

NOMBRE

xconsole - supervisa los mensajes de la consola del sistema con X

SINOPSIS

xconsole [-opción-toolkit ...] [-file nombre-archivo]
         [-notify|-nonotify] [-daemon] [-verbose]
         [-exitOnFail] [-stripNonprint] [-saveLines cuenta]
xconsole -help
xconsole -version

DESCRIPCIÓN

El programa xconsole muestra los mensajes que normalmente se envían a /dev/console.

OPCIONES

Xconsole acepta todas las opciones de línea de comandos estándar de X Toolkit junto con las opciones adicionales que se enumeran a continuación:

-file nombre-archivo
Para supervisar algún otro dispositivo, use esta opción para especificar el nombre del dispositivo. Esto no funciona en archivos regulares ya que siempre están listos para ser leídos.
-notify -nonotify
Cuando se reciben nuevos datos de la consola y se activa la opción notify, el nombre del icono de la aplicación tendrá " *" añadido, para que sea evidente incluso cuando la aplicación está minimizada. -notify es el valor predeterminado.
-daemon
Esta opción hace que xconsole se ejecute en segundo plano, utilizando fork/exit.
-verbose
Cuando está activada, esta opción dirige xconsole a mostrar un mensaje informativo en la primera línea del búfer de texto.
-exitOnFail
Cuando está activada, esta opción dirige xconsole a salir cuando no pueda redirigir la salida de la consola.
-stripNonprint
Cuando está activada, esta opción dirige xconsole a no incluir ningún carácter no imprimible en la configuración regional actual en la salida mostrada.
-saveLines cuenta
Cuando está activada, xconsole solo conserva cuenta líneas del historial de mensajes en lugar de aumentar el búfer de texto sin límite (un valor de cuenta de cero - el valor predeterminado - se trata como si no hubiera límite en el historial).
-help
Esta opción indica que xconsole debe mostrar un mensaje de uso y salir.
-version
Esta opción indica que xconsole debe mostrar su versión y salir.

X DEFAULTS

Este programa utiliza el widget Athena Text, consulte la documentación de Athena Widget Set para controlarlo.

Xconsole de lo contrario, acepta recursos de los mismos nombres que las opciones de línea de comandos (sin el guión inicial). "file" es de tipo cadena, "saveLines" es un entero, y las opciones restantes son booleanas.

WIDGETS

Para especificar recursos, es útil conocer la jerarquía de los widgets que componen xconsole. En la siguiente notación, la indentación indica la estructura jerárquica. El nombre de la clase del widget se indica primero, seguido del nombre de la instancia del widget.

XConsole  xconsole
     XConsole  text

ENTORNO

DISPLAY
para obtener el host y el número de pantalla predeterminados.
XENVIRONMENT
para obtener el nombre de un archivo de recursos que anula los recursos globales almacenados en la propiedad RESOURCE_MANAGER.

ARCHIVOS

/usr/share/X11/app-defaults/XConsole
especifica los recursos requeridos
