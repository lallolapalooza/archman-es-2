Estructura del evento

typedef struct xcb_xkb_compat_map_notify_event_t {
    uint8_t         response_type;
    uint8_t         xkbType;
    uint16_t        sequence;
    xcb_timestamp_t time;
    uint8_t         deviceID;
    uint8_t         changedGroups;
    uint16_t        firstSI;
    uint16_t        nSI;
    uint16_t        nTotalSI;

} xcb_xkb_compat_map_notify_event_t;

CAMPOS DEL EVENTO

response_type
El tipo de este evento, en este caso XCB_XKB_COMPAT_MAP_NOTIFY. Este campo también está presente en xcb_generic_event_t y se puede utilizar para diferenciar los eventos entre sí.
sequence
El número de secuencia de la última solicitud procesada por el servidor X11.
