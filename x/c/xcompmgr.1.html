xcompmgr(1) Manual de comandos generales xcompmgr(1)

NOMBRE

xcompmgr - gestor de composición de muestra para X

SINOPSIS

xcompmgr [-d pantalla] [-r radio] [-o opacidad] [-l desplazamiento-izquierdo] [-t desplazamiento-superior] [-acCfFnsS]

DESCRIPCIÓN

xcompmgr es un gestor de composición de muestra para servidores X que soportan las extensiones XFIXES, DAMAGE y COMPOSITE. Permite efectos visuales básicos.

OPCIONES

-d pantalla
Especifica la pantalla a gestionar.
-r radio
Especifica el radio de desenfoque para las sombras del lado del cliente.
-o opacidad
Especifica la opacidad para las sombras del lado del cliente.
-l desplazamiento-izquierdo
Especifica el desplazamiento izquierdo para las sombras del lado del cliente.
-t desplazamiento-superior
Especifica el desplazamiento superior para las sombras del lado del cliente.
-I paso-fundido-entrada
Especifica el cambio de opacidad entre pasos al fundir la entrada.
-O paso-fundido-salida
Especifica el cambio de opacidad entre pasos al fundir la salida.
-D delta-fundido
Especifica el tiempo (en milisegundos) entre pasos en un fundido.
-a
Composición automática del lado del servidor. Esto indica al servidor que use las reglas de composición estándar. Útil para depuración.
-c
Composición del lado del cliente con sombras suaves y soporte de translucidez.
-f
Cuando se especifica -c, activa un efecto de fundido suave para ventanas transitorias como menús, y para todas las ventanas en eventos de ocultar y restaurar.
-n
Composición simple del lado del cliente. Este es el modo predeterminado.
-s
Composición del lado del servidor con sombras de bordes duros.
-C
Cuando se especifica -c, intenta evitar pintar sombras en paneles y barras de tareas.
-F
Cuando se especifica -f, también activa el efecto de fundido cuando las ventanas cambian su opacidad, como con transset(1).
-S
Activa la operación síncrona. Útil para depuración.

ERRORES

Probablemente. Por favor, informe de cualquier error que encuentre en https://gitlab.freedesktop.org/xorg/app/xcompmgr/.
