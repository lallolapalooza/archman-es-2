NOMBRE

xcb_enter_notify_event_t - el puntero está en una ventana diferente

SINOPSIS

#include <xcb/xproto.h>

Estructura de evento

typedef struct xcb_enter_notify_event_t {
    uint8_t         response_type;
    uint8_t         detail;
    uint16_t        sequence;
    xcb_timestamp_t time;
    xcb_window_t    root;
    xcb_window_t    event;
    xcb_window_t    child;
    int16_t         root_x;
    int16_t         root_y;
    int16_t         event_x;
    int16_t         event_y;
    uint16_t        state;
    uint8_t         mode;
    uint8_t         same_screen_focus;
} xcb_enter_notify_event_t;

CAMPOS DEL EVENTO

response_type
El tipo de este evento, en este caso XCB_LEAVE_NOTIFY. Este campo también está presente en el xcb_generic_event_t y puede usarse para distinguir eventos entre sí.
sequence
El número de secuencia de la última solicitud procesada por el servidor X11.
detail
AÚN NO DOCUMENTADO.
time
AÚN NO DOCUMENTADO.
root
La ventana raíz para la posición final del cursor.
event
La ventana en la que se generó el evento.
child
Si la ventana event tiene subventanas y la posición final del puntero está en una de ellas, entonces child se establece en esa subventana, XCB_WINDOW_NONE en caso contrario.
root_x
La coordenada X del puntero relativa al origen de root en el momento del evento.
root_y
La coordenada Y del puntero relativa al origen de root en el momento del evento.
event_x
Si event está en la misma pantalla que root, esta es la coordenada X del puntero relativa al origen de la ventana del evento.
event_y
Si event está en la misma pantalla que root, esta es la coordenada Y del puntero relativa al origen de la ventana del evento.
state
AÚN NO DOCUMENTADO.
mode
same_screen_focus
AÚN NO DOCUMENTADO.
