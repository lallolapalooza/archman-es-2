NOMBRE

xcmsdb - Utilidad de caracterización de color del dispositivo para el Sistema de Gestión de Color de X

SINOPSIS

xcmsdb [ -query ] [ -remove ] [ -format 32|16|8 ] [ -help ] [ -version ] [ archivo ]

DESCRIPCIÓN

xcmsdb se utiliza para cargar, consultar o eliminar datos de Caracterización de Color del Dispositivo almacenados en propiedades de la ventana raíz de la pantalla, según se especifica en la sección 7, Caracterización de Color del Dispositivo, del ICCCM. Los datos de Caracterización de Color del Dispositivo (también llamados Perfil del Dispositivo) son una parte integral del Sistema de Gestión de Color de X (Xcms) de Xlib, necesarios para la conversión adecuada de la especificación de color entre formas independientes y dependientes del dispositivo. Xcms utiliza matrices de 3x3 almacenadas en la propiedad XDCCC_LINEAR_RGB_MATRICES para convertir especificaciones de color entre CIEXYZ e Intensidad RGB (XcmsRGBi, también referidas como RGB lineal). Xcms luego utiliza la información de gamma de pantalla almacenada en la propiedad XDCCC_LINEAR_RGB_CORRECTION para convertir especificaciones de color entre RGBi y RGB de dispositivo (XcmsRGB, también referidas como RGB de dispositivo).

Tenga en cuenta que Xcms permite a los clientes registrar conjuntos de funciones además de su conjunto de funciones incorporado para monitores de color CRT. Conjuntos de funciones adicionales pueden almacenar su información de perfil de dispositivo en otras propiedades en un formato específico del conjunto de funciones. Esta utilidad no tiene conocimiento de estas propiedades no estándar.

El contenido legible en ASCII de archivo (o la entrada estándar si no se proporciona ningún archivo de entrada) se transforma adecuadamente para su almacenamiento en propiedades, siempre que no se especifiquen las opciones -query o -remove.

OPCIONES

El programa xcmsdb acepta las siguientes opciones:

-query
Esta opción intenta leer las propiedades XDCCC de la ventana raíz de la pantalla. Si tiene éxito, transforma los datos a un formato más legible y luego envía los datos a la salida estándar.
-remove
Esta opción intenta eliminar las propiedades XDCCC de la ventana raíz de la pantalla.
-format 32|16|8
Especifica el formato de la propiedad (32, 16 u 8 bits por entrada) para la propiedad XDCCC_LINEAR_RGB_CORRECTION. La precisión de los valores de punto flotante codificados aumenta con el aumento de bits por entrada. El valor predeterminado es 32 bits por entrada.
-help
Esta opción imprime un resumen de las opciones disponibles y sale.
-version
Esta opción imprime la versión del programa y sale.
