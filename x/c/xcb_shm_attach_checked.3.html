NOMBRE

xcb_shm_attach - Adjuntar un segmento de memoria compartida System V.

SINOPSIS

#include <xcb/shm.h>

Función de solicitud

xcb_void_cookie_t xcb_shm_attach(xcb_connection_t *conn, xcb_shm_seg_t shmseg, uint32_t shmid, uint8_t read_only);

ARGUMENTOS DE LA SOLICITUD

conn
La conexión XCB a X11.
shmseg
Un ID de segmento de memoria compartida creado con xcb_generate_id().
shmid
El segmento de memoria compartida System V que el servidor debe mapear.
read_only
Verdadero si el segmento se mapeará en modo de solo lectura por el servidor X11, en caso contrario, falso.

DESCRIPCIÓN

Adjunta un segmento de memoria compartida System V al servidor. Esto fallará a menos que el servidor tenga permiso para mapear el segmento. El cliente puede destruir el segmento tan pronto como reciba un evento XCB_SHM_COMPLETION con el valor shmseg de esta solicitud y con el número de serie apropiado.

VALOR DE RETORNO

Devuelve una xcb_void_cookie_t. Los errores (si los hay) deben ser manejados en el bucle de eventos.

Si desea manejar los errores directamente con xcb_request_check en su lugar, use xcb_shm_attach_checked. Consulte xcb-requests(3) para obtener detalles.

ERRORES

Esta solicitud nunca genera ningún error.

VER TAMBIÉN

xcb-requests(3)

AUTOR

Generado a partir de shm.xml. Póngase en contacto con xcb@lists.freedesktop.org para correcciones y mejoras.
