XCB_GC_PLANE_MASK
En las operaciones gráficas, dada una fuente y un píxel de destino, el resultado se calcula bit a bit en los bits correspondientes de los píxeles; es decir, se realiza una operación booleana en cada plano de bits. XCB_GC_TILE
El mosaico/patrón de puntos representa un plano bidimensional infinito con el mosaico/patrón de puntos replicado en todas las dimensiones. Cuando ese plano se superpone en el drawable para su uso en una operación gráfica, la esquina superior izquierda de alguna instancia del mosaico/patrón de puntos se encuentra en las coordenadas dentro del drawable especificadas por el origen del mosaico/patrón de puntos. Los orígenes del mosaico/patrón de puntos y del clip se interpretan en relación con el origen del drawable de destino especificado en una solicitud gráfica. El pixmap del mosaico debe tener la misma raíz y profundidad que el gcontext (o se produce un error de coincidencia). El pixmap del patrón de puntos debe tener profundidad uno y la misma raíz que el gcontext (o se produce un error de coincidencia). Para el estilo de relleno En puntos (pero no OpaqueStippled), el patrón de puntos se mosaica en un solo plano y actúa como una máscara de clip adicional que se combinará con la máscara de clip. Se puede usar cualquier tamaño de pixmap para mosaicar o para patrones de puntos, aunque algunos tamaños pueden ser más rápidos de usar que otros.

XCB_GC_SUBWINDOW_MODE
Para ClipByChildren, tanto la ventana de origen como la de destino se recortan adicionalmente por todos los hijos visibles de tipo InputOutput. Para IncludeInferiors, ni la ventana de origen ni la de destino se recortan por los inferiores. El uso de IncludeInferiors con una ventana de origen o destino de una profundidad con inferiores visibles de profundidad diferente no es ilegal, pero la semántica no está definida por el protocolo central.

NAME

xcb_change_gc - Change the components specified by value_mask for the specified graphics context.

SYNOPSIS

#include <xcb/xproto.h>

    xcb_void_cookie_t
    xcb_change_gc(xcb_connection_t *conn,
                  xcb_gcontext_t      gc,
                  uint32_t            value_mask,
                  const uint32_t     *value_list);
    xcb_void_cookie_t
    xcb_change_gc_checked(xcb_connection_t *conn,
                          xcb_gcontext_t      gc,
                          uint32_t            value_mask,
                          const uint32_t     *value_list);

REQUEST ARGUMENTS

conn
The XCB connection to the X server.
gc
The graphics context to change.
value_mask
Specifies which components of the graphics context to change. Can be the bitwise OR of:
XCB_GC_FOREGROUND
Changes the foreground color.
XCB_GC_BACKGROUND
Changes the background color.
XCB_GC_LINE_WIDTH
Changes the line width.
XCB_GC_LINE_STYLE
Changes the line style.
XCB_GC_CAP_STYLE
Changes the cap style.
XCB_GC_JOIN_STYLE
Changes the join style.
XCB_GC_FILL_STYLE
Changes the fill style.
XCB_GC_FILL_RULE
Changes the fill rule.
XCB_GC_STIPPLE
Changes the stipple pattern.
XCB_GC_STIPPLE_X_ORIGIN
Changes the X origin of the stipple pattern.
XCB_GC_STIPPLE_Y_ORIGIN
Changes the Y origin of the stipple pattern.
XCB_GC_TILE
Changes the tile pattern.
XCB_GC_TILE_X_ORIGIN
Changes the X origin of the tile pattern.
XCB_GC_TILE_Y_ORIGIN
Changes the Y origin of the tile pattern.
XCB_GC_FONT
Changes the font.
XCB_GC_SUBWINDOW_MODE
Changes the subwindow mode.
XCB_GC_CLIP_ORIGIN
Changes the clip origin.
XCB_GC_CLIP_MASK
Changes the clip mask. Pixels are not drawn outside the area covered by the clip-mask or where the clip-mask has bits set to 0. The clip-mask affects all graphics requests, but it does not clip sources. The clip-mask origin is interpreted relative to the origin of whatever destination drawable is specified in a graphics request. If a pixmap is specified as the clip-mask, it must have depth 1 and have the same root as the gcontext (or a Match error results). If clip-mask is None, then pixels are always drawn, regardless of the clip origin. The clip-mask can also be set with the SetClipRectangles request.

EXAMPLE

/*
 * Changes the foreground color component of the specified graphics context.
 *
 */
void my_example(xcb_connection_t *conn, xcb_gcontext_t gc, uint32_t fg, uint32_t bg) {
    /* C99 allows us to use a compact way of changing a single component: */
    xcb_change_gc(conn, gc, XCB_GC_FOREGROUND, (uint32_t[]){ fg });
    /* The more explicit way. Beware that the order of values is important! */
    uint32_t mask = 0;
    mask |= XCB_GC_FOREGROUND;
    mask |= XCB_GC_BACKGROUND;
    uint32_t values[] = {
        fg,
        bg
    };
    xcb_change_gc(conn, gc, mask, values);
    xcb_flush(conn);
}
