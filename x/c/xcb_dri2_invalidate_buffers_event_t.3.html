CAMPOS DEL EVENTO

response_type
El tipo de este evento, en este caso XCB_DRI2_INVALIDATE_BUFFERS. Este campo también está presente en el xcb_generic_event_t y puede utilizarse para diferenciar eventos entre sí.
sequence
El número de secuencia de la última solicitud procesada por el servidor X11.
