xcb_get_property_reply(3)

Paquete: libxcb

Licencias: X11

xcb_get_property(3) Solicitudes XCB xcb_get_property(3)

NOMBRE

xcb_get_property - Obtiene una propiedad de ventana

SINOPSIS

#include <xcb/xproto.h>

Función de solicitud

xcb_get_property_cookie_t xcb_get_property(xcb_connection_t *conn, uint8_t _delete, xcb_window_t window, xcb_atom_t property, xcb_atom_t type, uint32_t long_offset, uint32_t long_length);

Estructura de datos de respuesta

typedef struct xcb_get_property_reply_t {
    uint8_t    response_type;
    uint8_t    format;
    uint16_t   sequence;
    uint32_t   length;
    xcb_atom_t type;
    uint32_t   bytes_after;
    uint32_t   value_len;
    uint8_t    pad0[12];
} xcb_get_property_reply_t;

Función de respuesta

xcb_get_property_reply_t *xcb_get_property_reply(xcb_connection_t *conn, xcb_get_property_cookie_t cookie, xcb_generic_error_t **e);

Acceso a la respuesta

void *xcb_get_property_value(const xcb_get_property_request_t *reply);

int xcb_get_property_value_length(const xcb_get_property_reply_t *reply);

xcb_generic_iterator_t xcb_get_property_value_end(const xcb_get_property_reply_t *reply);

ARGUMENTOS DE LA SOLICITUD

conn
La conexión XCB a X11.
_delete
Si la propiedad debe eliminarse realmente. Para eliminar una propiedad, el type especificado debe coincidir con el tipo real de la propiedad.
window
La ventana de la que se desea obtener la propiedad.
property
La propiedad que se desea obtener (un átomo).
type
El tipo de la propiedad que se desea obtener (un átomo).
long_offset
Especifica el desplazamiento (en múltiplos de 32 bits) en la propiedad especificada donde se deben recuperar los datos.
long_length
Especifica cuántos múltiplos de 32 bits de datos se deben recuperar (por ejemplo, si se establece long_length en 4, recibirá 16 bytes de datos).

CAMPOS DE LA RESPUESTA

response_type
El tipo de esta respuesta, en este caso XCB_GET_PROPERTY. Este campo también está presente en xcb_generic_reply_t y se puede utilizar para distinguir las respuestas entre sí.
sequence
El número de secuencia de la última solicitud procesada por el servidor X11.
length
La longitud de la respuesta, en palabras (una palabra son 4 bytes).
format
Especifica si los datos deben verse como una lista de cantidades de 8, 16 o 32 bits. Los valores posibles son 8, 16 y 32. Esta información permite que el servidor X realice correctamente las operaciones de intercambio de bytes según sea necesario.
type
El tipo real de la propiedad (un átomo).
bytes_after
El número de bytes restantes por leer en la propiedad si se realizó una lectura parcial.
value_len
La longitud del valor. Se debe utilizar el acceso correspondiente en lugar de este campo.

DESCRIPCIÓN

Obtiene la property especificada de la window especificada. Las propiedades son, por ejemplo, el título de la ventana (WM_NAME) o su tamaño mínimo (WM_NORMAL_HINTS). Los protocolos como EWMH también usan propiedades; por ejemplo, EWMH define el título de la ventana, codificado como una cadena UTF-8, en la propiedad _NET_WM_NAME.

VALOR DE RETORNO

Devuelve una xcb_get_property_cookie_t. Los errores deben gestionarse al llamar a la función de respuesta xcb_get_property_reply.

Si desea gestionar los errores en el bucle de eventos en su lugar, use xcb_get_property_unchecked. Consulte xcb-requests(3) para obtener más detalles.

ERRORES

xcb_atom_error_t
property o type no hacen referencia a un átomo válido.
xcb_value_error_t
El long_offset especificado está más allá de la longitud real de la propiedad (por ejemplo, la propiedad tiene una longitud de 3 bytes y se establece long_offset en 1, lo que resulta en un desplazamiento de byte de 4).
xcb_window_error_t
La window especificada no existe.

EJEMPLO

/*
 * Imprime la propiedad WM_NAME de la ventana.
 *
 */
void my_example(xcb_connection_t *c, xcb_window_t window) {
    xcb_get_property_cookie_t cookie;
    xcb_get_property_reply_t *reply;
    /* Estos átomos están predefinidos en el protocolo X11. */
    xcb_atom_t property = XCB_ATOM_WM_NAME;
    xcb_atom_t type = XCB_ATOM_STRING;
    // TODO: ¿un long_length razonable para WM_NAME?
    cookie = xcb_get_property(c, 0, window, property, type, 0, 0);
    if ((reply = xcb_get_property_reply(c, cookie, NULL))) {
        int len = xcb_get_property_value_length(reply);
        if (len == 0) {
            printf("TODO\n");
            free(reply);
            return;
        }
        printf("WM_NAME es %.*s\n", len,
               (char*)xcb_get_property_value(reply));
    }
    free(reply);
}

    xcb_get_property_reply(3)

    NAME

    xcb_get_property_reply -

    DESCRIPCIÓN

    Devuelve el valor de una propiedad.

    ARGUMENTOS DE LA PETICIÓN

    xcb_get_property_cookie_t xcb_get_property ( xcb_connection_t *connection, uint8_t what_to_return, xcb_window_t window, xcb_atom_t property, xcb_atom_t type, uint32_t offset, uint32_t length );

    Lee una propiedad de la ventana especificada. La propiedad solicitada es identificada por property. Si el nombre de la propiedad esNone (oXCB_ATOM_NONE), entonces el valor de la propiedad esNone y no se devuelve ningún dato.

    SitypeesAny(oXCB_ATOM_ANY), entonces se devolverá cualquier propiedad cuyo tipo coincida con el nombre de la propiedad solicitado.

    La solicitud se especifica el número de bytes de la propiedad que se desea leer. El desplazamiento se especifica en unidades de la unidad de tamaño de tipo de datos. El número de bytes es el número de bytes que se deben devolver.

    La unidad de tamaño de tipo de datos es el tamaño en bytes del elemento más pequeño que puede componer el tipo de datos. Por ejemplo, si se solicita una propiedad de tipoSTRING, la unidad de tamaño de tipo de datos es 1. Si se solicita una propiedad de tipoINT16, la unidad de tamaño de tipo de datos es 2. Si se solicita una propiedad de tipoINT32, la unidad de tamaño de tipo de datos es 4.

    CAMPOS DE LA RESPUESTA

    Si la petición tiene éxito, se devuelve una estructura xcb_get_property_reply_t. Los campos de esta estructura son los siguientes:

    • response_type: El tipo de respuesta.
    • sequence: La secuencia de la petición.
    • length: La longitud de la respuesta en bytes.
    • type: El tipo de la propiedad.
    • format: El formato de la propiedad. Este puede ser 8, 16 o 32.
    • bytes_after: El número de bytes restantes en la propiedad.
    • value_len: La longitud del valor de la propiedad en bytes.
    • value: Un puntero al valor de la propiedad.

    VALOR DE RETORNO

    Devuelve un puntero a una estructura xcb_get_property_reply_t si la petición tiene éxito. Si la petición falla, devuelveNULL.

    ERRORES

    xcb_get_property_error: Se genera si elwindowo elpropertyno son válidos.

    EJEMPLO

    Este ejemplo muestra cómo obtener el nombre de la ventana: 

    
    xcb_connection_t *connection = xcb_connect(NULL, NULL);
    if (connection == NULL) {
        fprintf(stderr, "Could not connect to X server\n");
        return 1;
    }

    xcb_window_t root = xcb_setup_roots_iterator(xcb_get_setup(connection)).data->root;
    xcb_atom_t property = xcb_intern_atom_reply(connection, xcb_intern_atom(connection, 0, strlen("WM_NAME"), "WM_NAME"), NULL)->atom;

    xcb_get_property_cookie_t cookie = xcb_get_property(connection, 0, root, property, XCB_ATOM_STRING, 0, 1024);
    xcb_get_property_reply_t *reply = xcb_get_property_reply(connection, cookie, NULL);

    if (reply != NULL && reply->type == XCB_ATOM_STRING) {
        char *name = (char *)xcb_get_property_value(reply);
        printf("Window name: %.*s\n", xcb_get_property_value_length(reply), name);
    } else {
        printf("Could not get window name\n");
    }

    free(reply);
    xcb_disconnect(connection);
    return 0;
