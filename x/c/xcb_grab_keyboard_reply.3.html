Si es 1, la grab_window seguirá recibiendo los eventos del puntero. Si es 0, los eventos no se reportan a la grab_window.

Marca de tiempo para evitar condiciones de carrera al ejecutar X sobre la red.

El valor especial XCB_CURRENT_TIME será reemplazado por la hora actual del servidor.

XCB_GRAB_MODE_SYNC

DESCRIPCIÓN

Captura activamente el control del teclado y genera eventos FocusIn y FocusOut. Los eventos de teclas posteriores solo se informan al cliente que captura.

Cualquier captura de teclado activa por parte de este cliente se anula. Si el teclado está activamente capturado por algún otro cliente, se devuelve AlreadyGrabbed. Si grab_window no es visible, se devuelve GrabNotViewable. Si el teclado está congelado por una captura activa de otro cliente, se devuelve GrabFrozen. Si la marca de tiempo especificada es anterior a la última marca de tiempo de captura del teclado o posterior a la hora actual del servidor X, se devuelve GrabInvalidTime. De lo contrario, la última marca de tiempo de captura del teclado se establece en la marca de tiempo especificada.

VALOR DE RETORNO

Devuelve una xcb_grab_keyboard_cookie_t. Los errores deben gestionarse al llamar a la función de respuesta xcb_grab_keyboard_reply.

Si desea gestionar los errores en el bucle de eventos en su lugar, use xcb_grab_keyboard_unchecked. Consulte xcb-requests(3) para obtener detalles.

EJEMPLO

/*
 * Captura el teclado activamente
 *
 */
void my_example(xcb_connection_t *conn, xcb_screen_t *screen) {
    xcb_grab_keyboard_cookie_t cookie;
    xcb_grab_keyboard_reply_t *reply;
    cookie = xcb_grab_keyboard(
        conn,
        true,                /* reportar eventos */
        screen->root,        /* capturar la ventana raíz */
        XCB_CURRENT_TIME,
        XCB_GRAB_MODE_ASYNC, /* procesar eventos normalmente, no requerir sync */
        XCB_GRAB_MODE_ASYNC
    );
    if ((reply = xcb_grab_keyboard_reply(conn, cookie, NULL))) {
        if (reply->status == XCB_GRAB_STATUS_SUCCESS)
            printf("teclado capturado con éxito\n");
        free(reply);
    }
}

xcb_grab_keyboard_reply -

SINOPSIS

Inclusión

#include <xcb/xcb.h>

Función

int xcb_grab_keyboard_reply (xcb_connection_t *connection,
                                     xcb_grab_keyboard_cookie_t cookie,
                                     xcb_grab_keyboard_reply_t **reply);

Argumentos

connection

El objeto de conexión XCB.

cookie

La cookie devuelta por xcb_grab_keyboard.

reply

Puntero a un puntero a la estructura xcb_grab_keyboard_reply_t. Después de que la función se ejecute correctamente, el puntero apuntará a la estructura de respuesta.

ARGUMENTOS DE SOLICITUD

Este comando se utiliza para atrapar el teclado y así recibir todos los eventos de teclado. El propietario del teclado se convierte en el cliente que envía la solicitud.

Un cliente puede atrapar el teclado solo si el teclado no está siendo actualmente atrapo por otro cliente.

El cliente que atrapa el teclado recibe todos los eventos de teclado, incluyendo los que no están dirigidos a él. El cliente puede, sin embargo, pasar el teclado a otro cliente usando xcb_allow_events.

Los clientes también pueden desatrapar el teclado y permitir que otros clientes reciban eventos de teclado otra vez usando xcb_ungrab_keyboard.

CAMPOS DE RESPUESTA

Como xcb_grab_keyboard_reply_t es una estructura de respuesta, solo contiene los siguientes campos:

int status

El estado de la solicitud. Posibles valores: XCB_GRAB_STATUS_SUCCESSFUL, XCB_GRAB_STATUS_ALREADY_GRABBED, XCB_GRAB_STATUS_INVALID_TIME, XCB_GRAB_STATUS_NOT_VIEWABLE, XCB_GRAB_STATUS_FROZEN.

xcb_timestamp_t owner_events

Determina si los eventos del propietario deben ser pasados al cliente o si deben ser enviados al propietario de la ventana.

xcb_timestamp_t grab_window

La ventana que fue atrapada.

xcb_timestamp_t time

La marca de tiempo cuando el teclado fue atrapado.

xcb_timestamp_t server_grab

Determina si el servidor tiene el teclado atrapado.

DESCRIPCIÓN

Lee la respuesta de una solicitud xcb_grab_keyboard.

VALOR DE RETORNO

Retorna 0 si la solicitud fue enviada con éxito. De lo contrario, retorna un código de error.

ERRORES

xcb_grab_keyboard_error_t

XCB_GRAB_STATUS_ALREADY_GRABBED

El teclado ya está atrapado por otro cliente.

XCB_GRAB_STATUS_INVALID_TIME

La marca de tiempo proporcionada no es válida.

XCB_GRAB_STATUS_NOT_VIEWABLE

La ventana especificada no es visible.

XCB_GRAB_STATUS_FROZEN

El propietario de la ventana está congelado.

EJEMPLO

// Grab the keyboard
xcb_grab_keyboard_cookie_t cookie = xcb_grab_keyboard(connection, 0, XCB_CURRENT_TIME, XCB_WINDOW_ANY, XCB_GRAB_MODE_ASYNC, XCB_GRAB_MODE_ASYNC);

// Get the reply
xcb_grab_keyboard_reply_t *reply = NULL;
int status = xcb_grab_keyboard_reply(connection, cookie, (void **)&reply);

if (status == 0 && reply->status == XCB_GRAB_STATUS_SUCCESSFUL) {
    // Keyboard grabbed successfully
} else {
    // Failed to grab keyboard
}

// Free the reply
free(reply);
