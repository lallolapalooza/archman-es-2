XCLOCK(1) Manual de comandos generales XCLOCK(1)

NOMBRE

xclock - reloj analógico / digital para X

SINOPSIS

xclock [ -help ] [ -analog | -digital ] [ -brief ] [ -chime ] [ -hd color ] [ -hl color ] [ -update segundos ] [ -strftime formato ] [ -twelve | -twentyfour | -utime ] [ -padding número ] [ -norender ] [ -render ] [ -sharp ] [ -face patrón ]

DESCRIPCIÓN

El programa xclock muestra la hora en formato analógico o digital. La hora se actualiza continuamente a una frecuencia que puede ser especificada por el usuario.

OPCIONES

Xclock acepta todas las opciones de línea de comandos del kit de herramientas X estándar junto con las opciones adicionales que se enumeran a continuación:

-help
Esta opción indica que se debe imprimir un resumen breve de las opciones permitidas en el error estándar.
-analog
Esta opción indica que se debe utilizar una cara de reloj convencional de 12 horas con marcas y manecillas. Esta es la opción predeterminada.
-digital o -d
Esta opción indica que se debe utilizar un reloj digital de 24 horas.
-brief
Esta opción indica que el reloj digital solo debe mostrar los campos de horas y minutos. La opción predeterminada es mostrar toda la información de hora y fecha.
-utime
Esta opción indica que un reloj digital debe mostrar los segundos desde la Época (en formato '970012340 segundos desde la Época' en lugar de la hora estándar de 24 horas.
-strftime formato
Esta opción permite especificar una cadena de formato strftime(3) para la pantalla del reloj digital.
-twelve
Esta opción indica que un reloj digital debe mostrar la hora en formato de doce horas. Esto solo es efectivo para la pantalla breve.
-twentyfour
Esta opción indica que un reloj digital debe mostrar la hora en formato de veinticuatro horas. Esto solo es efectivo para la pantalla breve. Esta es la opción predeterminada cuando se utiliza un reloj digital.
-chime
Esta opción indica que el reloj debe sonar una vez a la media hora y dos veces en punto.
-hands color (o -hd color)
Esta opción especifica el color de las manecillas de un reloj analógico. La opción predeterminada es negro. Esta opción se ignora efectivamente cuando se utiliza Xrender.
-highlight color (o -hl color)
Esta opción especifica el color de los bordes de las manecillas de un reloj analógico, y solo es útil en pantallas a color. La opción predeterminada es negro. Esta opción se ignora efectivamente cuando se utiliza Xrender.
-update segundos
Esta opción especifica la frecuencia en segundos a la que xclock debe actualizar su pantalla. Si el reloj está oscurecido y luego se expone, se actualizará inmediatamente. Un valor de 30 segundos o menos activará un segundero en un reloj analógico. La opción predeterminada es 60 segundos.
-padding número
Esta opción especifica el ancho en píxeles del relleno entre el borde de la ventana y el texto o la imagen del reloj. La opción predeterminada es 10 en un reloj digital y 8 en un reloj analógico.
-render
Esta opción indica a xclock que utilice la extensión Xrender para dibujar una cara antialiased. Esta es la opción predeterminada si xclock se ha compilado con soporte Xrender. Tenga en cuenta que las opciones de selección de color y los recursos utilizados cuando Xrender está activo difieren de las opciones estándar.
-norender
Esta opción desactiva el uso de Xrender para dibujar el reloj.
-sharp
Esta opción indica a xclock que utilice bordes más nítidos cuando se dibuje utilizando la extensión Xrender.
-face patrón
Esta opción especifica la fuente a utilizar en modo digital cuando se utiliza la extensión Xrender. Los patrones se especifican utilizando el formato de cara fontconfig descrito en la sección Nombres de fuentes de fonts.conf(5).

PREDETERMINADOS DE X

Este programa utiliza el widget Clock. Entiende todos los nombres y clases de recursos principales, así como:

width (class Width)
Especifica el ancho del reloj. El valor predeterminado para los relojes analógicos es de 164 píxeles; el valor predeterminado para los relojes digitales es el necesario para contener el reloj cuando se muestra en la fuente elegida.
height (class Height)
Especifica la altura del reloj. El valor predeterminado para los relojes analógicos es de 164 píxeles; el valor predeterminado para los relojes digitales es el necesario para contener el reloj cuando se muestra en la fuente elegida.
update (class Interval)
Especifica la frecuencia en segundos con la que se debe redibujar la hora.
foreground (class Foreground)
Especifica el color de las marcas. El valor predeterminado depende de si se especifica reverseVideo. Si se especifica reverseVideo, el valor predeterminado es lwhite, de lo contrario, el valor predeterminado es black.
hands (class Foreground)
Especifica el color del interior de las manecillas del reloj. El valor predeterminado depende de si se especifica reverseVideo. Si se especifica reverseVideo, el valor predeterminado es lwhite, de lo contrario, el valor predeterminado es black. Tenga en cuenta que este recurso no se utiliza cuando Xrender está activo.
highlight (class Foreground)
Especifica el color utilizado para resaltar las manecillas del reloj. El valor predeterminado depende de si se especifica reverseVideo. Si reverseVideo se especifica, el valor predeterminado es
lwhite, de lo contrario, el valor predeterminado es black. Tenga en cuenta que este recurso no se utiliza cuando Xrender está activo.
analog (class Boolean)
Especifica si se debe usar un reloj analógico en lugar de uno digital. El valor predeterminado es True.
twentyfour (class Boolean)
Especifica si un reloj digital debe mostrar la hora en formato de veinticuatro horas. El valor predeterminado es True.
chime (class Boolean)
Especifica si se debe sonar una campana en punto y media hora.
padding (class Margin)
Especifica la cantidad de relleno interno en píxeles a utilizar. El valor predeterminado es 8.
font (class Font)
Especifica la fuente a utilizar para el reloj digital. Tenga en cuenta que las fuentes de ancho variable actualmente no siempre se mostrarán correctamente. Esta fuente solo se utiliza cuando Xrender no está activo.
render (class Boolean)
Especifica si se debe utilizar la extensión Xrender para la visualización. El valor predeterminado es True si xclock se ha compilado con soporte Xrender.

Cuando Xrender está activo, se entienden los siguientes recursos adicionales:

face (class FaceName)
Especifica el patrón para la fuente a utilizar para el reloj digital cuando se utiliza Xrender. Los patrones se especifican utilizando el formato de cara fontconfig descrito en la sección Nombres de fuentes de OPTIONS

The following options are available for the xclock utility:

-analog
Display an analog clock.
-digital
Display a digital clock.
-chime
Chime every hour.
-d
Same as -digital.
-help
Display a usage message and exit.
-nbeauty
Same as -sharp.
-padding number
Sets the padding around the clock face.
-pango-markup
Use Pango markup for rendering the digital clock string. This is only supported in digital mode.
-render renderer
Use the specified renderer. Possible values are cairo and pango. Default is cairo.
-revert
Same as -reverse.
-reverse
Reverse the default foreground and background colors.
-seconds
Display seconds.
-sharp
Use sharp edges for rendering the clock.
-update seconds
The rate at which to update the clock.
-version
Display program version and exit.
-w seconds
Same as -update.
background (class Background)
The color to use for the background of the clock. Defaults to White.
borderColor (class BorderColor)
The color to use for the border of the clock window. Defaults to Black.
borderWidth (class BorderWidth)
The width of the border of the clock window, in pixels. Defaults to 1.
faceColor (class FaceColor)
The color to use for the face of the analog clock. Defaults to Black.
font (class Font)
The font to use for the digital clock. Defaults to the font returned by the fixed font family. See also fonts.conf(5).
foreground (class Foreground)
The color to use for the foreground elements of the clock. Defaults to Black.
geometry (class Geometry)
Standard X11 geometry specification.
internalBorder (class InternalBorder)
The width of the internal border of the clock, in pixels. Defaults to 10.
leftSide (class Side)
The color of the left side of the 3D analog clock face. Defaults to gray50.
lowerRightSide (class Side)
The color of the lower right side of the 3D analog clock face. Defaults to gray30.
rightSide (class Side)
The color of the right side of the 3D analog clock face. Defaults to gray70.
shColor (class Shadow)
The color of the shadow around the clock. Defaults to Black.
shadow (class Boolean)
Specifies if a shadow should be drawn around the clock. The default is False.
sharp (class Boolean)
Specifies if sharp edges should be used when rendering the clock. The default is False.
buffer (class Boolean)
Specifies that the updates of the image are drawn to a pixmap before copied into the window instead drawing them into the window directly.

The defaults of the following color resources depend on whether reverseVideo is specified. If reverseVideo is specified the default is lwhite, otherwise the default is black.

hourColor (class Foreground)
The color of the hour hand.
minuteColor (class Foreground)
The color of the minute hand.
secondColor (class Foreground)
The color of the second hand.
majorColor (class Foreground)
The color of the major scale ticks (i. e. each five minutes).
minorColor (class Foreground)
The color of the minor scale ticks (between major ticks).

WIDGETS

In order to specify resources, it is useful to know the hierarchy of the widgets which compose xclock. In the notation below, indentation indicates hierarchical structure. The widget class name is given first, followed by the widget instance name.

XClock  xclock
        Clock  clock

ENVIRONMENT

DISPLAY
to get the default host and display number.
XENVIRONMENT
to get the name of a resource file that overrides the global resources stored in the RESOURCE_MANAGER property.

FILES

/usr/share/X11/app-defaults/XClock
specifies required resources

SEE ALSO

X(7), xrdb(1), time(3), fonts.conf (5).

BUGS

Xclock believes the system clock.

When in digital mode, the string should be centered automatically.
