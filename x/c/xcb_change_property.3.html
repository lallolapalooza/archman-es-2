xcb_change_property(3) Solicitudes XCB xcb_change_property(3)

NOMBRE

xcb_change_property - Cambia una propiedad de ventana

SINOPSIS

#include <xcb/xproto.h>

Función de solicitud

xcb_void_cookie_t xcb_change_property(xcb_connection_t *conn, uint8_t mode, xcb_window_t window, xcb_atom_t property, xcb_atom_t type, uint8_t format, uint32_t data_len, const void *data);

ARGUMENTOS DE LA SOLICITUD

conn
La conexión XCB a X11.
mode
Uno de los siguientes valores:
XCB_PROP_MODE_REPLACE
Descarta el valor de propiedad anterior y almacena los nuevos datos.
XCB_PROP_MODE_PREPEND
Inserta los nuevos datos antes del inicio de los datos existentes. El formato debe coincidir con el valor de propiedad existente. Si la propiedad no está definida, se trata como definida con el tipo y formato correctos con datos de longitud cero.
XCB_PROP_MODE_APPEND
Inserta los nuevos datos después del inicio de los datos existentes. El formato debe coincidir con el valor de propiedad existente. Si la propiedad no está definida, se trata como definida con el tipo y formato correctos con datos de longitud cero.
window
La ventana cuya propiedad deseas cambiar.
property
La propiedad que deseas cambiar (un átomo).
type
El tipo de la propiedad que deseas cambiar (un átomo).
format
Especifica si los datos deben verse como una lista de cantidades de 8, 16 o 32 bits. Los valores posibles son 8, 16 y 32. Esta información permite al servidor X realizar correctamente operaciones de intercambio de bytes según sea necesario.
data_len
Especifica el número de elementos (ver formato).
data
Los datos de la propiedad.

DESCRIPCIÓN

Establece o actualiza una propiedad en la ventana especificada. Las propiedades son, por ejemplo, el título de la ventana (WM_NAME) o su tamaño mínimo (WM_NORMAL_HINTS). Protocolos como EWMH también utilizan propiedades; por ejemplo, EWMH define el título de la ventana, codificado como una cadena UTF-8, en la propiedad _NET_WM_NAME.

VALOR DE RETORNO

Devuelve una xcb_void_cookie_t. Los errores (si los hay) deben manejarse en el bucle de eventos.

Si desea manejar errores directamente con xcb_request_check en su lugar, use xcb_change_property_checked. Consulte xcb-requests(3) para obtener detalles.

ERRORES

xcb_alloc_error_t
El servidor X no pudo almacenar la propiedad (¿sin memoria?).
xcb_atom_error_t
property o type no hacen referencia a un átomo válido.
xcb_match_error_t
TODO: ¿razones?
xcb_value_error_t
TODO: ¿razones?
xcb_window_error_t
La ventana especificada no existe.

EJEMPLO

/*
 * Establece la propiedad WM_NAME de la ventana a "XCB Example".
 *
 */
void my_example(xcb_connection_t *conn, xcb_window_t window) {
    xcb_change_property(conn,
        XCB_PROP_MODE_REPLACE,
        window,
        XCB_ATOM_WM_NAME,
        XCB_ATOM_STRING,
        8,
        strlen("XCB Example"),
        "XCB Example");
    xcb_flush(conn);
}
