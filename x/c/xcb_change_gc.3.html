XCB_GC_PLANE_MASK
En operaciones gráficas, dada una fuente y un píxel de destino, el resultado se calcula bit a bit sobre los bits correspondientes de los píxeles; es decir, se realiza una operación booleana en cada plano de bits. XCB_GC_TILE
El mosaico/stipple representa un plano bidimensional infinito con el mosaico/stipple replicado en todas las dimensiones. Cuando ese plano se superpone al drawable para su uso en una operación gráfica, la esquina superior izquierda de alguna instancia del mosaico/stipple se encuentra en las coordenadas dentro del drawable especificadas por el origen del mosaico/stipple. Los orígenes del mosaico/stipple y del clip se interpretan en relación con el origen de cualquier drawable de destino que se especifique en una solicitud gráfica. El pixmap del mosaico debe tener la misma raíz y profundidad que el gcontext (o se producirá un error de coincidencia). El pixmap del stipple debe tener profundidad uno y debe tener la misma raíz que el gcontext (o se producirá un error de coincidencia). Para el estilo de relleno Patrón de stipple (pero no Relleno opaco), el patrón de stipple se empaqueta en un solo plano y actúa como una máscara de clip adicional que se unirá con la máscara de clip. Se puede usar cualquier tamaño de pixmap para mosaicos o stippling, aunque algunos tamaños pueden ser más rápidos de usar que otros.

NAME

xcb_change_gc - change graphics context

SYNOPSIS

#include <xcb/xcb.h> 

xcb_void_cookie_t xcb_change_gc (xcb_connection_t *conn,
                               xcb_gcontext_t      gc,
                               uint32_t            value_mask,
                               const uint32_t     *value_list);
xcb_void_cookie_t xcb_change_gc_checked (xcb_connection_t *conn,
                                        xcb_gcontext_t      gc,
                                        uint32_t            value_mask,
                                        const uint32_t     *value_list);

DESCRIPTION

Changes the components specified by value_mask for the specified graphics context.

REQUEST ARGUMENTS

gc
The graphics context to change.
value_mask
Which components of the GC to change.
XCB_GC_FOREGROUND
Changes the foreground color component.
XCB_GC_BACKGROUND
Changes the background color component.
XCB_GC_LINE_WIDTH
Changes the line width component.
XCB_GC_LINE_STYLE
Changes the line style component.
XCB_GC_CAP_STYLE
Changes the cap style component.
XCB_GC_JOIN_STYLE
Changes the join style component.
XCB_GC_FILL_STYLE
Changes the fill style component.
XCB_GC_FILL_RULE
Changes the fill rule component.
XCB_GC_STIPPLE
Changes the stipple component.
XCB_GC_STIPPLE_X_ORIGIN
Changes the stipple x origin component.
XCB_GC_STIPPLE_Y_ORIGIN
Changes the stipple y origin component.
XCB_GC_TILE
Changes the tile component.
XCB_GC_TILE_X_ORIGIN
Changes the tile x origin component.
XCB_GC_TILE_Y_ORIGIN
Changes the tile y origin component.
XCB_GC_FONT
Changes the font component.
XCB_GC_SUBWINDOW_MODE
Changes the subwindow mode component.
XCB_GC_CLIP_X_ORIGIN
Changes the clip x origin component.
XCB_GC_CLIP_Y_ORIGIN
Changes the clip y origin component.
XCB_GC_CLIP_MASK

Changes the clip-mask component. Pixels are not drawn outside the area covered by the clip-mask or where the clip-mask has bits set to 0. The clip-mask affects all graphics requests, but it does not clip sources. The clip-mask origin is interpreted relative to the origin of whatever destination drawable is specified in a graphics request. If a pixmap is specified as the clip-mask, it must have depth 1 and have the same root as the gcontext (or a Match error results). If clip-mask is None, then pixels are always drawn, regardless of the clip origin. The clip-mask can also be set with the SetClipRectangles request.

EXAMPLE

/*
 * Changes the foreground color component of the specified graphics context.
 *
 */
void my_example(xcb_connection_t *conn, xcb_gcontext_t gc, uint32_t fg, uint32_t bg) {
    /* C99 allows us to use a compact way of changing a single component: */
    xcb_change_gc(conn, gc, XCB_GC_FOREGROUND, (uint32_t[]){ fg });
    /* The more explicit way. Beware that the order of values is important! */
    uint32_t mask = 0;
    mask |= XCB_GC_FOREGROUND;
    mask |= XCB_GC_BACKGROUND;
    uint32_t values[] = {
        fg,
        bg
    };
    xcb_change_gc(conn, gc, mask, values);
    xcb_flush(conn);
}
