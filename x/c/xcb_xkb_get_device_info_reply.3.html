VALOR DE RETORNO

Devuelve una xcb_xkb_get_device_info_cookie_t. Los errores deben manejarse al llamar a la función de respuesta xcb_xkb_get_device_info_reply.

Si desea manejar los errores en el bucle de eventos en su lugar, use xcb_xkb_get_device_info_unchecked. Consulte xcb-requests(3) para obtener detalles.

DESCRIPTION

Get the reply for the XkbGetDeviceInfo request. The reply contains information about the specified keyboard device, including its type, name, supported groups, LEDs, and keycode range.

REPLY FIELDS

  • device_spec: The device specification.
  • device_type: The type of the device.
  • name_len: The length of the device name.
  • num_groups: The number of groups supported by the device.
  • num_codiles: The number of LEDs on the device.
  • dge_len: The length of the device group events.
  • nglis: The number of group list entries.
  • min_keycode: The minimum keycode supported by the device.
  • max_keycode: The maximum keycode supported by the device.
  • numb_devices: The number of devices.
  • map_feedback_state: The mapping of feedback states.
  • map_type_state: The mapping of type states.
  • map_group_state: The mapping of group states.
  • map_pointer_state: The mapping of pointer states.
  • map_indicator_state: The mapping of indicator states.
  • mk_device_group_state: The device group state for each device.
  • mk_device_led_state: The device LED state for each device.
  • mk_device_button_state: The device button state for each device.
  • name: The name of the device.
  • dges: The device group events.
  • nglis: The group list entries.
  • leds: Information about the LEDs on the device.
  • buttons: Information about the buttons on the device.

RETURN VALUE

Returns the reply structure if the request was successful, or NULL if an error occurred.

ERRORS

This function can return the following errors:

  • XCB_XKB_ID_ERROR: The specified device ID is invalid.
  • XCB_XKB_CODE_ERROR: An invalid keycode was specified.
  • XCB_XKB_DEVICE_SPEC_ERROR: An invalid device specification was provided.
  • XCB_XKB_GROUP_ERROR: An invalid group number was specified.
  • XCB_XKB_INSTALLATION_ERROR: An invalid installation number was specified.
  • XCB_XKB_LIMITS_ERROR: A value exceeded the specified limits.
