NOMBRE

xcb_list_fonts_with_info - obtener nombres e información de fuentes coincidentes

SINOPSIS

#include <xcb/xproto.h>

ARGUMENTOS DE LA SOLICITUD

conn
La conexión XCB a X11.
max_names
El número máximo de fuentes a devolver.
pattern_len
La longitud (en bytes) de pattern.
pattern
Un patrón de fuente, por ejemplo, "-misc-fixed-*".

El asterisco (*) es un comodín para cualquier número de caracteres. El signo de interrogación (?) es un comodín para un solo carácter. El uso de mayúsculas o minúsculas no importa.

CAMPOS DE LA RESPUESTA

response_type
El tipo de esta respuesta, en este caso XCB_LIST_FONTS_WITH_INFO. Este campo también está presente en xcb_generic_reply_t y se puede usar para distinguir las respuestas entre sí.
sequence
El número de secuencia de la última solicitud procesada por el servidor X11.
length
La longitud de la respuesta, en palabras (una palabra son 4 bytes).
name_len
El número de nombres de fuentes coincidentes.
min_bounds
límites mínimos sobre todos los caracteres existentes
max_bounds
límites máximos sobre todos los caracteres existentes
min_char_or_byte2
primer carácter
max_char_or_byte2
último carácter
default_char
carácter a imprimir para caracteres indefinidos
properties_len
cuántas propiedades hay
draw_direction

all_chars_exist
indicador si todos los caracteres tienen tamaño distinto de cero
font_ascent
línea base hasta el borde superior del raster
font_descent
línea base hasta el borde inferior del raster
replies_hint
Una indicación de cuántas fuentes más se devolverán. Esto es solo una pista y puede ser mayor o menor que el número de fuentes realmente devueltas. Un valor cero no garantiza que no se devolverán más fuentes.

DESCRIPCIÓN

Obtiene una lista de nombres de fuentes disponibles que coinciden con el pattern dado.

VALOR DE RETORNO

Devuelve una xcb_list_fonts_with_info_cookie_t. Los errores deben manejarse al llamar a la función de respuesta xcb_list_fonts_with_info_reply.

Si desea manejar los errores en el bucle de eventos en su lugar, use xcb_list_fonts_with_info_unchecked. Consulte xcb-requests(3) para obtener detalles.

ERRORES

Esta solicitud nunca genera errores.

NAME

xcb_list_fonts_with_info_properties - ListFontsWithInfoReply structure and functions

SYNOPSIS

#include <xcb/render.h>

xcb_list_fonts_with_info_cookie_t
xcb_list_fonts_with_info(xcb_connection_t *conn, uint16_t max_names, uint16_t max_font_name_len, const
                         char *pattern);

xcb_list_fonts_with_info_reply_t *
xcb_list_fonts_with_info_reply(xcb_list_fonts_with_info_cookie_t cookie,
                               xcb_generic_error_t **e);

int
xcb_list_fonts_with_info_reply_wipe(xcb_list_fonts_with_info_reply_t *reply);

xcb_font_t
xcb_list_fonts_with_info_reply_font(const xcb_list_fonts_with_info_reply_t *reply, int i);

int
xcb_list_fonts_with_info_reply_name_len(const xcb_list_fonts_with_info_reply_t *reply, int i);

char *
xcb_list_fonts_with_info_reply_name(const xcb_list_fonts_with_info_reply_t *reply, int i);

xcb_charinfo_t *
xcb_list_fonts_with_info_reply_font_info(const xcb_list_fonts_with_info_reply_t *reply, int i);

REQUEST ARGUMENTS

conn:
The XCB connection to the X server.
max_names:
A value for the maximum number of names to return.
max_font_name_len:
A value for the maximum length of the font name.
pattern:
A pattern to match the font names against.

REPLY FIELDS

response:
The generic XCB response structure.
nranges:
Number of font ranges.
min_bounds:
Minimum bounds for the listed fonts.
max_bounds:
Maximum bounds for the listed fonts.
min_lsb:
Minimum left-side-bearing for the listed fonts.
max_lsb:
Maximum left-side-bearing for the listed fonts.
min_rsb:
Minimum right-side-bearing for the listed fonts.
max_rsb:
Maximum right-side-bearing for the listed fonts.
min_width:
Minimum width for the listed fonts.
max_width:
Maximum width for the listed fonts.
default_char:
The default character for the listed fonts.
properties:
A list of font properties.

DESCRIPTION

The function xcb_list_fonts_with_info lists fonts with information about them. The pattern argument specifies a pattern to match font names against. The max_names and max_font_name_len arguments limit the number of names and the length of each name, respectively.

The xcb_list_fonts_with_info_reply function retrieves the reply from the server. The reply contains information about the listed fonts, including their minimum and maximum bounds, minimum and maximum left-side-bearing, minimum and maximum right-side-bearing, minimum and maximum width, default character, and a list of font properties.

The xcb_list_fonts_with_info_reply_wipe function frees the memory allocated for the reply. The xcb_list_fonts_with_info_reply_font function returns the font ID for the i-th font. The xcb_list_fonts_with_info_reply_name_len function returns the length of the font name for the i-th font. The xcb_list_fonts_with_info_reply_name function returns the font name for the i-th font. The xcb_list_fonts_with_info_reply_font_info function returns the font information for the i-th font.

RETURN VALUE

On success, xcb_list_fonts_with_info_reply returns a pointer to the xcb_list_fonts_with_info_reply_t structure. On failure, it returns NULL and sets the error structure pointed to by e.

ERRORS

The function may return XCB errors.
