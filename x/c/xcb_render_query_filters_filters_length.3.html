NOMBRE

xcb_render_query_filters -

SINOPSIS

#include <xcb/render.h>

Función solicitud

xcb_render_query_filters_cookie_t xcb_render_query_filters(xcb_connection_t *conn, xcb_drawable_t drawable);

Estructura de datos respuesta

typedef struct xcb_render_query_filters_reply_t {
    uint8_t  response_type;
    uint8_t  pad0;
    uint16_t sequence;
    uint32_t length;
    uint32_t num_aliases;
    uint32_t num_filters;
    uint8_t  pad1[16];
} xcb_render_query_filters_reply_t;

ARGUMENTOS DE LA SOLICITUD

conn
La conexión XCB a X11.
drawable
PENDIENTE DE DOCUMENTACIÓN.

CAMPOS DE LA RESPUESTA

response_type
El tipo de esta respuesta, en este caso XCB_RENDER_QUERY_FILTERS. Este campo también está presente en xcb_generic_reply_t y se puede usar para distinguir las respuestas entre sí.
sequence
El número de secuencia de la última solicitud procesada por el servidor X11.
length
La longitud de la respuesta, en palabras (una palabra son 4 bytes).
num_aliases
PENDIENTE DE DOCUMENTACIÓN.
num_filters
PENDIENTE DE DOCUMENTACIÓN.

DESCRIPCIÓN

VALOR DE RETORNO

Devuelve una xcb_render_query_filters_cookie_t. Los errores deben manejarse al llamar a la función de respuesta xcb_render_query_filters_reply.

Si desea manejar los errores en el bucle de eventos en su lugar, use xcb_render_query_filters_unchecked. Consulte xcb-requests(3) para obtener detalles.

ERRORES

Esta solicitud nunca genera errores.

VER TAMBIÉN

AUTOR

Generado a partir de render.xml. Contacte a xcb@lists.freedesktop.org para correcciones y mejoras.
