xcb_copy_area(3) Solicitudes XCB xcb_copy_area(3)

NOMBRE

xcb_copy_area - copiar áreas

SINOPSIS

#include <xcb/xproto.h>

Función de solicitud

xcb_void_cookie_t xcb_copy_area(xcb_connection_t *conn, xcb_drawable_t src_drawable, xcb_drawable_t dst_drawable, xcb_gcontext_t gc, int16_t src_x, int16_t src_y, int16_t dst_x, int16_t dst_y, uint16_t width, uint16_t height);

ARGUMENTOS DE SOLICITUD

conn
La conexión XCB a X11.
src_drawable
El drawable de origen (Ventana o Pixmap).
dst_drawable
El drawable de destino (Ventana o Pixmap).
gc
El contexto gráfico a utilizar.
src_x
La coordenada X de origen.
src_y
La coordenada Y de origen.
dst_x
La coordenada X de destino.
dst_y
La coordenada Y de destino.
width
El ancho del área a copiar (en píxeles).
height
La altura del área a copiar (en píxeles).

DESCRIPCIÓN

Copia el rectángulo especificado de src_drawable a dst_drawable.

VALOR DE RETORNO

Devuelve una xcb_void_cookie_t. Los errores (si los hay) deben manejarse en el bucle de eventos.

Si desea manejar los errores directamente con xcb_request_check, utilice xcb_copy_area_checked. Consulte xcb-requests(3) para obtener detalles.

ERRORES

xcb_drawable_error_t
El drawable especificado (Ventana o Pixmap) no existe.
xcb_g_context_error_t
El contexto gráfico especificado no existe.
xcb_match_error_t
src_drawable tiene una raíz o profundidad diferente a dst_drawable.

VER TAMBIÉN

xcb-requests(3)

AUTOR

Generado a partir de xproto.xml. Póngase en contacto con xcb@lists.freedesktop.org para correcciones y mejoras.
