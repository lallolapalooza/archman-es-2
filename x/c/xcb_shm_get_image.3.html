xcb_shm_get_image(3)

Paquete: libxcb

Licencias: X11

xcb_shm_get_image(3) Solicitudes XCB xcb_shm_get_image(3)

NOMBRE

xcb_shm_get_image - Copia datos del drawable especificado al segmento de memoria compartida.

SINOPSIS

#include <xcb/shm.h>

Función de solicitud

xcb_shm_get_image_cookie_t xcb_shm_get_image(xcb_connection_t *conn, xcb_drawable_t drawable, int16_t x, int16_t y, uint16_t width, uint16_t height, uint32_t plane_mask, uint8_t format, xcb_shm_seg_t shmseg, uint32_t offset);

Estructura de respuesta

typedef struct xcb_shm_get_image_reply_t {
    uint8_t        response_type;
    uint8_t        depth;
    uint16_t       sequence;
    uint32_t       length;
    xcb_visualid_t visual;
    uint32_t       size;
} xcb_shm_get_image_reply_t;

Función de respuesta

xcb_shm_get_image_reply_t *xcb_shm_get_image_reply(xcb_connection_t *conn, xcb_shm_get_image_cookie_t cookie, xcb_generic_error_t **e);

ARGUMENTOS DE SOLICITUD

conn
La conexión XCB a X11.
drawable
El drawable del cual copiar la imagen.
x
La coordenada X en el drawable donde comenzar la copia.
y
La coordenada Y en el drawable donde comenzar la copia.
width
El ancho de la imagen a copiar.
height
La altura de la imagen a copiar.
plane_mask
Una máscara que determina qué planos se utilizan.
format
El formato a usar para la copia (???).
shmseg
El segmento de memoria compartida de destino.
offset
El desplazamiento en el segmento de memoria compartida donde copiar los datos.

CAMPOS DE RESPUESTA

response_type
El tipo de esta respuesta, en este caso XCB_SHM_GET_IMAGE. Este campo también está presente en el xcb_generic_reply_t y se puede usar para distinguir las respuestas entre sí.
sequence
El número de secuencia de la última solicitud procesada por el servidor X11.
length
La longitud de la respuesta, en palabras (una palabra son 4 bytes).
depth
La profundidad del drawable de origen.
visual
El ID visual del drawable de origen.
size
El número de bytes copiados.

DESCRIPCIÓN

Copia datos del drawable especificado al segmento de memoria compartida. La cantidad de bytes escritos en la imagen de destino es siempre igual a la cantidad de bytes leídos del segmento de memoria compartida.

VALOR DE RETORNO

Devuelve una xcb_shm_get_image_cookie_t. Los errores deben manejarse al llamar a la función de respuesta xcb_shm_get_image_reply.

Si desea manejar los errores en el bucle de eventos en su lugar, use xcb_shm_get_image_unchecked. Consulte xcb-requests(3) para obtener detalles.

ERRORES

Esta solicitud nunca genera errores.

VER TAMBIÉN

xcb-requests(3)

AUTOR

Generado a partir de shm.xml. Póngase en contacto con xcb@lists.freedesktop.org para correcciones y mejoras.
