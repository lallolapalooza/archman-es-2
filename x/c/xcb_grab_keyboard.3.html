NOMBRE

xcb_grab_keyboard - Capturar el teclado

SINOPSIS

#include <xcb/xproto.h>

Función de solicitud

xcb_grab_keyboard_cookie_t xcb_grab_keyboard(xcb_connection_t *conn, uint8_t owner_events, xcb_window_t grab_window, xcb_timestamp_t time, uint8_t pointer_mode, uint8_t keyboard_mode);

Estructura de respuesta

typedef struct xcb_grab_keyboard_reply_t {
    uint8_t  response_type;
    uint8_t  status;
    uint16_t sequence;
    uint32_t length;
} xcb_grab_keyboard_reply_t;

Función de respuesta

xcb_grab_keyboard_reply_t *xcb_grab_keyboard_reply(xcb_connection_t *conn, xcb_grab_keyboard_cookie_t cookie, xcb_generic_error_t **e);

ARGUMENTOS DE SOLICITUD

conn
La conexión XCB a X11.
owner_events
Si es 1, la grab_window seguirá recibiendo eventos del puntero. Si es 0, los eventos no se informan a la grab_window.
grab_window
Especifica la ventana en la que se capturará el puntero.
time
Marca de tiempo para evitar condiciones de carrera al ejecutar X sobre la red.

El valor especial XCB_CURRENT_TIME se reemplazará con la hora actual del servidor.

pointer_mode
Uno de los siguientes valores:
XCB_GRAB_MODE_SYNC
El estado del teclado parece congelarse: el servidor no genera más eventos de teclado hasta que el cliente que captura emita una solicitud AllowEvents de liberación o hasta que se libere la captura del teclado.
XCB_GRAB_MODE_ASYNC
El procesamiento de eventos del teclado continúa normalmente.
keyboard_mode
Uno de los siguientes valores:
XCB_GRAB_MODE_SYNC
El estado del teclado parece congelarse: el servidor no genera más eventos de teclado hasta que el cliente que captura emita una solicitud AllowEvents de liberación o hasta que se libere la captura del teclado.
XCB_GRAB_MODE_ASYNC
El procesamiento de eventos del teclado continúa normalmente.

length

DESCRIPCIÓN

Captura activamente el control del teclado y genera eventos FocusIn y FocusOut. Los eventos de teclado posteriores se informan solo al cliente que captura.

Cualquier captura de teclado activa por parte de este cliente se anula. Si el teclado está capturado activamente por algún otro cliente, se devuelve AlreadyGrabbed. Si grab_window no es visible, se devuelve GrabNotViewable. Si el teclado está congelado por una captura activa de otro cliente, se devuelve GrabFrozen. Si la marca de tiempo especificada es anterior a la hora de la última captura de teclado o posterior a la hora actual del servidor X, se devuelve GrabInvalidTime. De lo contrario, la hora de la última captura de teclado se establece en la marca de tiempo especificada.

VALOR DE RETORNO

Devuelve una xcb_grab_keyboard_cookie_t. Los errores deben manejarse al llamar a la función de respuesta xcb_grab_keyboard_reply.

Si desea manejar los errores en el bucle de eventos en su lugar, use xcb_grab_keyboard_unchecked. Consulte xcb-requests(3) para obtener más detalles.

EJEMPLO

/*
 * Captura el teclado activamente
 *
 */
void my_example(xcb_connection_t *conn, xcb_screen_t *screen) {
    xcb_grab_keyboard_cookie_t cookie;
    xcb_grab_keyboard_reply_t *reply;
    cookie = xcb_grab_keyboard(
        conn,
        true,                /* informar eventos */
        screen->root,        /* capturar la ventana raíz */
        XCB_CURRENT_TIME,
        XCB_GRAB_MODE_ASYNC, /* procesar eventos normalmente, no requerir sync */
        XCB_GRAB_MODE_ASYNC
    );
    if ((reply = xcb_grab_keyboard_reply(conn, cookie, NULL))) {
        if (reply->status == XCB_GRAB_STATUS_SUCCESS)
            printf("teclado capturado con éxito\n");
        free(reply);
    }
}
