ARGUMENTOS DE LA SOLICITUD

conn
La conexión XCB a X11.
max_names
El número máximo de fuentes a devolver.
pattern_len
La longitud (en bytes) de pattern.
pattern
Un patrón de fuente, por ejemplo "-misc-fixed-*".

El asterisco (*) es un comodín para cualquier número de caracteres. El signo de interrogación (?) es un comodín para un solo carácter. El uso de mayúsculas o minúsculas no importa.

DESCRIPCIÓN

Obtiene una lista de nombres de fuentes disponibles que coinciden con el pattern dado.

VALOR DE RETORNO

Devuelve una xcb_list_fonts_with_info_cookie_t. Los errores deben ser manejados al llamar a la función de respuesta xcb_list_fonts_with_info_reply.

Si desea manejar los errores en el bucle de eventos en su lugar, utilice xcb_list_fonts_with_info_unchecked. Consulte xcb-requests(3) para obtener detalles.

ERRORES

Esta solicitud nunca genera errores.

NAME

xcb_list_fonts_with_info - list available fonts with information

SYNOPSIS

REQUEST_ARGUMENTS

The xcb_list_fonts_with_info request takes the following arguments:

  • connection: The XCB connection to use.
  • max_names: The maximum number of font names to return. If 0, all matching font names are returned.
  • pattern: A string specifying the font pattern to match. This can be an empty string to match all fonts.
REPLY_FIELDS

The xcb_list_fonts_with_info_reply_t structure contains the following fields:

  • names_len: The number of font names returned in the names array.
  • names: An array of xcb_font_struct_t structures, each containing information about a font.
  • min_bounds: The minimum bounds of the returned fonts.
  • max_bounds: The maximum bounds of the returned fonts.
  • draw: A boolean indicating whether the fonts can be drawn.
  • is_gc_font: A boolean indicating whether the fonts are GC fonts.
  • left_ நி: The minimum left offset of the returned fonts.
  • right_ நி: The minimum right offset of the returned fonts.
  • avg_ நி: The average offset of the returned fonts.
  • min_ நி: The minimum offset of the returned fonts.
  • max_ நி: The maximum offset of the returned fonts.
  • all_ நி: A boolean indicating whether all returned fonts have the same offset.
DESCRIPTION

The xcb_list_fonts_with_info function returns a list of available fonts that match the given pattern, along with their associated information. The information includes font properties such as bounding boxes, offsets, and whether the font can be drawn.

The pattern argument can be used to filter the fonts. For example, a pattern like "*-*-*-*-*-*-*-*-*-*-*-*-*" will match all fonts, while a pattern like "-*-helvetica-bold-r-normal-*-12-*-*-*-*-*-*-*" will match a specific font.

The max_names argument limits the number of font names returned. If max_names is 0, all matching font names are returned.

RETURN VALUE

If the request is successful, the function returns a pointer to an xcb_list_fonts_with_info_reply_t structure, which contains the list of fonts and their information. If an error occurs, the function returns NULL.

ERRORS

This function can generate the following errors:

  • XCB_CORE_ERROR_ACCESS: If the server denies access to the font.
  • XCB_CORE_ERROR_ALLOCATION: If the server runs out of memory.
