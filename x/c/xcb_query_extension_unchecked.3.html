xcb_query_extension(3) Solicitudes XCB xcb_query_extension(3)

NOMBRE

xcb_query_extension - verificar si una extensión está presente

SINOPSIS

#include <xcb/xproto.h>

Función de solicitud

xcb_query_extension_cookie_t xcb_query_extension(xcb_connection_t *conn, uint16_t name_len, const char *name);

Estructura de respuesta

typedef struct xcb_query_extension_reply_t {
    uint8_t  response_type;
    uint8_t  pad0;
    uint16_t sequence;
    uint32_t length;
    uint8_t  present;
    uint8_t  major_opcode;
    uint8_t  first_event;
    uint8_t  first_error;
} xcb_query_extension_reply_t;

Función de respuesta

xcb_query_extension_reply_t *xcb_query_extension_reply(xcb_connection_t *conn, xcb_query_extension_cookie_t cookie, xcb_generic_error_t **e);

ARGUMENTOS DE LA SOLICITUD

conn
La conexión XCB a X11.
name_len
La longitud de name en bytes.
name
El nombre de la extensión a consultar, por ejemplo "RANDR". ¡Esto distingue entre mayúsculas y minúsculas!

CAMPOS DE RESPUESTA

response_type
El tipo de esta respuesta, en este caso XCB_QUERY_EXTENSION. Este campo también está presente en xcb_generic_reply_t y se puede usar para distinguir entre respuestas.
sequence
El número de secuencia de la última solicitud procesada por el servidor X11.
length
La longitud de la respuesta, en palabras (una palabra son 4 bytes).
present
Si la extensión está presente en este servidor X11.
major_opcode
El opcode principal para las solicitudes.
first_event
El primer código de evento, si lo hay.
first_error
El primer código de error, si lo hay.

DESCRIPCIÓN

Determina si la extensión especificada está presente en este servidor X11.

Cada extensión tiene un major_opcode único para identificar las solicitudes; los opcodes menores y los formatos de solicitud son específicos de la extensión. Si la extensión proporciona eventos y errores, los campos first_event y first_error en la respuesta se establecen en consecuencia.

Rara vez debería haber necesidad de usar esta solicitud directamente; XCB proporciona la función xcb_get_extension_data en su lugar.

VALOR DE RETORNO

Devuelve una xcb_query_extension_cookie_t. Los errores deben manejarse al llamar a la función de respuesta xcb_query_extension_reply.

Si desea manejar los errores en el bucle de eventos en su lugar, use xcb_query_extension_unchecked. Vea xcb-requests(3) para más detalles.

ERRORES

Esta solicitud nunca genera errores.

VER TAMBIÉN

xcb-requests(3), xcb_get_extension_data(3), xdpyinfo(1)

AUTOR

Generado a partir de xproto.xml. Contacte xcb@lists.freedesktop.org para correcciones y mejoras.
