xcb_query_tree(3) Solicitudes XCB xcb_query_tree(3)

NOMBRE

xcb_query_tree - consultar el árbol de ventanas

SINOPSIS

#include <xcb/xproto.h>

Función de solicitud

xcb_query_tree_cookie_t xcb_query_tree(xcb_connection_t *conn, xcb_window_t window);

Estructura de datos de respuesta

typedef struct xcb_query_tree_reply_t {
    uint8_t      response_type;
    uint8_t      pad0;
    uint16_t     sequence;
    uint32_t     length;
    xcb_window_t root;
    xcb_window_t parent;
    uint16_t     children_len;
    uint8_t      pad1[14];
} xcb_query_tree_reply_t;

Función de respuesta

xcb_query_tree_reply_t *xcb_query_tree_reply(xcb_connection_t *conn, xcb_query_tree_cookie_t cookie, xcb_generic_error_t **e);

Accesores de respuesta

xcb_window_t *xcb_query_tree_children(const xcb_query_tree_request_t *reply);

int xcb_query_tree_children_length(const xcb_query_tree_reply_t *reply);

xcb_generic_iterator_t xcb_query_tree_children_end(const xcb_query_tree_reply_t *reply);

ARGUMENTOS DE LA SOLICITUD

conn
La conexión XCB a X11.
window
La window (ventana) a consultar.

CAMPOS DE LA RESPUESTA

response_type
El tipo de esta respuesta, en este caso XCB_QUERY_TREE. Este campo también está presente en el xcb_generic_reply_t y se puede usar para distinguir las respuestas entre sí.
sequence
El número de secuencia de la última solicitud procesada por el servidor X11.
length
La longitud de la respuesta, en palabras (una palabra son 4 bytes).
root
La ventana raíz de window.
parent
La ventana padre de window.
children_len
El número de ventanas hijas.

DESCRIPCIÓN

Obtiene el ID de la ventana raíz, el ID de la ventana padre y la lista de ventanas hijas para la window especificada. Las hijas se listan en orden de apilamiento de abajo hacia arriba.

VALOR DE RETORNO

Devuelve un xcb_query_tree_cookie_t. Los errores deben ser manejados al llamar a la función de respuesta xcb_query_tree_reply.

Si desea manejar los errores en el bucle de eventos en su lugar, use xcb_query_tree_unchecked. Consulte xcb-requests(3) para obtener detalles.

ERRORES

Esta solicitud nunca genera errores.

EJEMPLO

/*
 * Muestra la raíz, el padre y las hijas de la ventana especificada.
 *
 */
void my_example(xcb_connection_t *conn, xcb_window_t window) {
    xcb_query_tree_cookie_t cookie;
    xcb_query_tree_reply_t *reply;
    cookie = xcb_query_tree(conn, window);
    if ((reply = xcb_query_tree_reply(conn, cookie, NULL))) {
        printf("root = 0x%08x\n", reply->root);
        printf("parent = 0x%08x\n", reply->parent);
        xcb_window_t *children = xcb_query_tree_children(reply);
        for (int i = 0; i < xcb_query_tree_children_length(reply); i++)
            printf("child window = 0x%08x\n", children[i]);
        free(reply);
    }
}
