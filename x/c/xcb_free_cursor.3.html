xcb_free_cursor(3) Solicitudes XCB xcb_free_cursor(3)

NOMBRE

xcb_free_cursor - Elimina un cursor

SINOPSIS

#include <xcb/xproto.h>

Función de solicitud

xcb_void_cookie_t xcb_free_cursor(xcb_connection_t *conn, xcb_cursor_t cursor);

ARGUMENTOS DE LA SOLICITUD

conn
La conexión XCB a X11.
cursor
El cursor a destruir.

DESCRIPCIÓN

Elimina la asociación entre el ID del recurso del cursor y el cursor especificado. El cursor se libera cuando ningún otro recurso lo referencia.

VALOR DE RETORNO

Devuelve una xcb_void_cookie_t. Los errores (si los hay) deben manejarse en el bucle de eventos.

Si desea manejar los errores directamente con xcb_request_check en su lugar, use xcb_free_cursor_checked. Consulte xcb-requests(3) para obtener detalles.

ERRORES

xcb_cursor_error_t
El cursor especificado no existe.

VER TAMBIÉN

xcb-requests(3)

AUTOR

Generado a partir de xproto.xml. Póngase en contacto con xcb@lists.freedesktop.org para correcciones y mejoras.
