XCLIP(1) Manual de Comandos Generales XCLIP(1)

NOMBRE

xclip - interfaz de línea de comandos para selecciones de X (portapapeles)

SINOPSIS

xclip [OPCIÓN] [ARCHIVO]...

DESCRIPCIÓN

Lee desde la entrada estándar, o desde uno o más archivos, y pone los datos a disposición como una selección de X para pegar en aplicaciones X. Imprime la selección X actual a la salida estándar.

-i, -in
lee texto en la selección X desde la entrada estándar o archivos (por defecto)
-o, -out
imprime la selección a la salida estándar (generalmente para canalizar a un archivo o programa)
-f, -filter
cuando xclip se invoca en modo de entrada con el nivel de salida en silencioso (los valores por defecto), la opción filter hará que xclip imprima el texto canalizado a la entrada estándar de vuelta a la salida estándar sin modificar
-r, -rmlastnl
cuando el último carácter de la selección es un carácter de nueva línea, lo elimina. Los caracteres de nueva línea que no son el último carácter de la selección no se ven afectados. Si la selección no termina con un carácter de nueva línea, esta opción no tiene efecto. Esta opción es útil para copiar la salida de una sola línea de programas como pwd al portapapeles para pegarla de nuevo en la línea de comandos sin ejecutar la línea inmediatamente debido al carácter de nueva línea que pwd añade.
-l, -loops
número de solicitudes de selección de X (pegados en aplicaciones X) a esperar antes de salir, con un valor de 0 (por defecto) que hace que xclip espere un número ilimitado de solicitudes hasta que otra aplicación (posiblemente otra invocación de xclip) tome posesión de la selección
-t, -target
especifica un formato de datos particular usando el átomo de destino dado. Con -o, el átomo de destino especial "TARGETS" puede ser usado para obtener una lista de átomos de destino válidos para esta selección. Para más información sobre átomos de destino, consulta la sección 2.6.2 del ICCCM.
-d, -display
pantalla X a usar (por ejemplo, "localhost:0"), xclip usa por defecto el valor en $DISPLAY si se omite esta opción
-h, -help
muestra un resumen rápido de las opciones
-selection
especifica qué selección de X usar, las opciones son "primary" para usar XA_PRIMARY (por defecto), "secondary" para XA_SECONDARY o "clipboard" para XA_CLIPBOARD
-version
muestra información de la versión
-silent
se bifurca en segundo plano para esperar solicitudes, sin salida informativa, solo errores (por defecto)
-quiet
muestra mensajes informativos en la terminal y se ejecuta en primer plano
-verbose
proporciona un comentario detallado de lo que está haciendo xclip
-noutf8
opera en modo legado (es decir, no UTF-8) para compatibilidad retroactiva (Usa esta opción solo cuando sea realmente necesario, ya que el comportamiento anterior estaba roto)

xclip lee texto desde la entrada estándar o archivos y lo pone a disposición de otras aplicaciones X para pegarlo como una selección de X (tradicionalmente con el botón del medio del ratón). Lee de todos los archivos especificados, o de la entrada estándar si no se especifican archivos. xclip también puede imprimir el contenido de una selección a la salida estándar con la opción -o.

xclip fue diseñado para permitir una integración más estrecha de las aplicaciones X y los programas de línea de comandos. La acción por defecto es esperar silenciosamente en segundo plano las solicitudes de selección de X (pegados) hasta que otra aplicación X coloque datos en el portapapeles, momento en el cual xclip sale silenciosamente. Puedes usar la opción -verbose para ver si y cuándo xclip recibe realmente solicitudes de selección de otras aplicaciones X.

Las opciones se pueden abreviar siempre que sigan siendo inequívocas. Por ejemplo, es posible usar -d o -disp en lugar de -display. Sin embargo, -v no se podría usar porque es ambigua (podría ser una abreviatura de -verbose o -version), por lo que se interpretaría como un nombre de archivo.

Ten en cuenta que solo el primer carácter de la selección especificada con la opción -selection es importante. Esto significa que "p", "sec" y "clip" tendrían el mismo efecto que usar "primary", "secondary" o "clipboard" respectivamente.

EJEMPLOS

¡Odio las páginas del manual sin ejemplos!

uptime | xclip

Pon tu tiempo de actividad en la selección de X. Luego haz clic con el botón central en una aplicación X para pegarlo.

xclip -loops 10 -verbose /etc/motd

Sal después de que /etc/motd (mensaje del día) se haya pegado 10 veces. Muestra cuántas solicitudes de selección (pegados) se han procesado.

xclip -o > helloworld.c

Pon el contenido de la selección en un archivo.

xclip -t text/html index.html

Haz clic con el botón central en una aplicación X que soporte HTML para pegar el contenido del archivo dado como HTML.

ENTORNO

DISPLAY
Pantalla X a usar si no se especifica ninguna con la opción -display.
