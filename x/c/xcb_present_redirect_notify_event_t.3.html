CAMPOS DEL EVENTO

response_type
El tipo de este evento, en este caso XCB_PRESENT_REDIRECT_NOTIFY. Este campo también está presente en xcb_generic_event_t y se puede utilizar para diferenciar eventos entre sí.
sequence
El número de secuencia de la última solicitud procesada por el servidor X11.
