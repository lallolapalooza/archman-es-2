CAMPOS DE LA RESPUESTA

response_type
El tipo de esta respuesta, en este caso XCB_SELINUX_GET_SELECTION_DATA_CONTEXT. Este campo también está presente en xcb_generic_reply_t y se puede utilizar para distinguir las respuestas entre sí.

El número de secuencia de la última solicitud procesada por el servidor X11.

TODO: AÚN NO DOCUMENTADO.

DESCRIPCIÓN

VALOR DE RETORNO

Devuelve una xcb_selinux_get_selection_data_context_cookie_t. Los errores deben manejarse al llamar a la función de respuesta xcb_selinux_get_selection_data_context_reply.

Si desea manejar los errores en el bucle de eventos, utilice xcb_selinux_get_selection_data_context_unchecked. Consulte xcb-requests(3) para obtener más detalles.

ERRORES

Esta solicitud nunca genera ningún error.

VER TAMBIÉN

AUTOR

Generado a partir de xselinux.xml. Póngase en contacto con xcb@lists.freedesktop.org para correcciones y mejoras.
