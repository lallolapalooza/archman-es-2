xcb_poly_segment(3) Solicitudes de XCB xcb_poly_segment(3)

NOMBRE

xcb_poly_segment - dibuja líneas

SINAPSIS

#include <xcb/xproto.h>

Función de solicitud

xcb_void_cookie_t xcb_poly_segment(xcb_connection_t *conn, xcb_drawable_t drawable, xcb_gcontext_t gc, uint32_t segments_len, const xcb_segment_t *segments);

ARGUMENTOS DE SOLICITUD

conn
La conexión XCB a X11.
drawable
Un drawable (Ventana o Pixmap) sobre el cual dibujar.
gc
El contexto gráfico a utilizar.

TODO: documentar qué atributos de un gc se utilizan

segments_len
El número de estructuras xcb_segment_t en segments.
segments
Un array de estructuras xcb_segment_t.

DESCRIPCIÓN

Dibuja múltiples líneas no conectadas. Para cada segmento, se dibuja una línea entre (x1, y1) y (x2, y2). Las líneas se dibujan en el orden listado en el array de estructuras xcb_segment_t y no realiza uniones en puntos finales coincidentes. Para cualquier línea dada, un píxel no se dibuja más de una vez. Si las líneas se cruzan, los píxeles de intersección se dibujan varias veces.

VALOR DE RETORNO

Devuelve una xcb_void_cookie_t. Los errores (si los hay) deben manejarse en el bucle de eventos.

Si desea manejar los errores directamente con xcb_request_check en su lugar, use xcb_poly_segment_checked. Consulte xcb-requests(3) para obtener detalles.

ERRORES

El gc especificado no existe.
