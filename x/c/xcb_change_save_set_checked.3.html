NOMBRE

xcb_change_save_set - Cambia el conjunto de guardado de un cliente

SINOPSIS

#include <xcb/xproto.h>

Función de solicitud

xcb_void_cookie_t xcb_change_save_set(xcb_connection_t *conn, uint8_t mode, xcb_window_t window);

ARGUMENTOS DE LA SOLICITUD

conn
La conexión XCB a X11.
mode
Uno de los siguientes valores:
XCB_SET_MODE_INSERT
TODO: AÚN NO DOCUMENTADO.
XCB_SET_MODE_DELETE
TODO: AÚN NO DOCUMENTADO.

Insertar para añadir la ventana especificada al conjunto de guardado o Eliminar para eliminarla del conjunto de guardado.

window
La ventana a añadir o eliminar de tu conjunto de guardado.

DESCRIPCIÓN

TODO: explicar para qué sirve el conjunto de guardado.

Esta función añade o elimina la ventana especificada al conjunto de guardado del cliente (tu aplicación).

VALOR DE RETORNO

Devuelve una xcb_void_cookie_t. Los errores (si los hay) deben manejarse en el bucle de eventos.

Si desea manejar los errores directamente con xcb_request_check en su lugar, use xcb_change_save_set_checked. Consulte xcb-requests(3) para obtener detalles.

ERRORES

xcb_match_error_t
Usted creó la ventana especificada. Esto no tiene sentido, solo puede añadir ventanas creadas por otros clientes a su conjunto de guardado.
xcb_value_error_t
Especificó un modo inválido.
xcb_window_error_t
La ventana especificada no existe.

VER TAMBIÉN

xcb-requests(3), xcb_reparent_window(3)
