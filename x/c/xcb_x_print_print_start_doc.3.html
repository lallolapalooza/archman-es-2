VALOR DE RETORNO

Devuelve una xcb_void_cookie_t. Los errores (si los hay) deben manejarse en el bucle de eventos.

Si desea manejar los errores directamente con xcb_request_check en su lugar, use xcb_x_print_print_start_doc_checked. Consulte xcb-requests(3) para obtener más detalles.
