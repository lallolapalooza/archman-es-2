CAMPOS DEL EVENTO

response_type
El tipo de este evento, en este caso XCB_INPUT_DEVICE_BUTTON_STATE_NOTIFY. Este campo también está presente en el xcb_generic_event_t y se puede usar para distinguir los eventos entre sí.
