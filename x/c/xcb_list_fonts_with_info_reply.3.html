NOMBRE

xcb_list_fonts_with_info - obtener nombres de fuentes coincidentes e información

SINÓPSIS

#include <xcb/xproto.h>

Función de solicitud

xcb_list_fonts_with_info_cookie_t xcb_list_fonts_with_info(xcb_connection_t *conn, uint16_t max_names, uint16_t pattern_len, const char *pattern);

Estructura de datos de respuesta

typedef struct xcb_list_fonts_with_info_reply_t {
    uint8_t        response_type;
    uint8_t        name_len;
    uint16_t       sequence;
    uint32_t       length;
    xcb_charinfo_t min_bounds;
    uint8_t        pad0[4];

    uint8_t        max_byte1;

    int16_t        font_descent;
    uint32_t       replies_hint;
} xcb_list_fonts_with_info_reply_t;

ARGUMENTOS DE LA SOLICITUD

conn
La conexión XCB a X11.
max_names
El número máximo de fuentes a devolver.
pattern_len
La longitud (en bytes) de pattern.
pattern
Un patrón de fuente, por ejemplo "-misc-fixed-*".

El asterisco (*) es un comodín para cualquier número de caracteres. El signo de interrogación (?) es un comodín para un solo carácter. El uso de mayúsculas o minúsculas no importa.

CAMPOS DE LA RESPUESTA

response_type
El tipo de esta respuesta, en este caso XCB_LIST_FONTS_WITH_INFO. Este campo también está presente en xcb_generic_reply_t y se puede utilizar para distinguir las respuestas entre sí.
sequence
El número de secuencia de la última solicitud procesada por el servidor X11.
length
La longitud de la respuesta, en palabras (una palabra son 4 bytes).
name_len
El número de nombres de fuentes coincidentes.
min_bounds
límites mínimos sobre el carácter existente
max_bounds
límites máximos sobre el carácter existente
min_char_or_byte2
primer carácter
max_char_or_byte2
último carácter
default_char
carácter para imprimir si el carácter no está definido
properties_len
cuántas propiedades hay
draw_direction
Uno de los siguientes valores:
XCB_FONT_DRAW_LEFT_TO_RIGHT
TODO: AÚN NO DOCUMENTADO.
XCB_FONT_DRAW_RIGHT_TO_LEFT
TODO: AÚN NO DOCUMENTADO.
min_byte1
TODO: AÚN NO DOCUMENTADO.
max_byte1
TODO: AÚN NO DOCUMENTADO.
all_chars_exist
indicador si todos los caracteres tienen tamaño distinto de cero
font_ascent
línea base hasta el borde superior de la trama
font_descent
línea base hasta el borde inferior de la trama
replies_hint
Una indicación de cuántas fuentes más se devolverán. Esto es solo una pista y puede ser mayor o menor que el número de fuentes realmente devueltas. Un valor cero no garantiza que no se devolverán más fuentes.

DESCRIPCIÓN

Obtiene una lista de nombres de fuentes disponibles que coinciden con el pattern dado.

VALOR DE RETORNO

Devuelve una xcb_list_fonts_with_info_cookie_t. Los errores deben manejarse al llamar a la función de respuesta xcb_list_fonts_with_info_reply.

Si desea manejar los errores en el bucle de eventos en su lugar, use xcb_list_fonts_with_info_unchecked. Consulte xcb-requests(3) para obtener detalles.

ERRORES

Esta solicitud nunca genera ningún error.

VER TAMBIÉN
