xcb_motion_notify_event_t(3) Eventos de XCB xcb_motion_notify_event_t(3)

NOMBRE

xcb_motion_notify_event_t - se pulsó una tecla

SINOPSIS

#include <xcb/xproto.h>

Estructura de datos del evento

typedef struct xcb_motion_notify_event_t {
    uint8_t         response_type;
    uint8_t         detail;
    uint16_t        sequence;
    xcb_timestamp_t time;
    xcb_window_t    root;
    xcb_window_t    event;
    xcb_window_t    child;
    int16_t         root_x;
    int16_t         root_y;
    int16_t         event_x;
    int16_t         event_y;
    uint16_t        state;
    uint8_t         same_screen;
    uint8_t         pad0;
} xcb_motion_notify_event_t;

CAMPOS DEL EVENTO

response_type
El tipo de este evento, en este caso XCB_MOTION_NOTIFY. Este campo también está presente en el xcb_generic_event_t y se puede usar para distinguir los eventos entre sí.
sequence
El número de secuencia de la última solicitud procesada por el servidor X11.
detail
El código de tecla (un número que representa una tecla física en el teclado) de la tecla que se pulsó.
time
Hora en que se generó el evento (en milisegundos).
root
La ventana raíz de child.
event
AÚN NO DOCUMENTADO.
child
AÚN NO DOCUMENTADO.
root_x
La coordenada X del puntero relativa a la ventana root en el momento del evento.
root_y
La coordenada Y del puntero relativa a la ventana root en el momento del evento.
event_x
Si same_screen es verdadero, esta es la coordenada X relativa al origen de la ventana event. De lo contrario, event_x se establecerá a cero.
event_y
Si same_screen es verdadero, esta es la coordenada Y relativa al origen de la ventana event. De lo contrario, event_y se establecerá a cero.
state
El estado lógico de los botones del puntero y las teclas modificadoras justo antes del evento.
same_screen
Si la ventana event está en la misma pantalla que la ventana root.
