NOMBRE

xcb_change_window_attributes - cambiar atributos de ventana

SINOPSIS

#include <xcb/xproto.h>

Función de solicitud

xcb_void_cookie_t xcb_change_window_attributes(xcb_connection_t *conn, xcb_window_t window, uint32_t value_mask, const void *value_list);

ARGUMENTOS DE SOLICITUD

conn
La conexión XCB a X11.
window
La ventana a cambiar.
value_mask
Uno de los siguientes valores:
XCB_CW_BACK_PIXMAP
Anula el pixmap de fondo predeterminado. El pixmap de fondo y la ventana deben tener la misma raíz y la misma profundidad. Se puede usar un pixmap de cualquier tamaño, aunque algunos tamaños pueden ser más rápidos que otros.

Si se especifica XCB_BACK_PIXMAP_NONE, la ventana no tiene fondo definido. El servidor puede rellenar el contenido con el contenido anterior de la pantalla o con el contenido de su elección.

Si se especifica XCB_BACK_PIXMAP_PARENT_RELATIVE, se utiliza el fondo del padre, pero la ventana debe tener la misma profundidad que el padre (o se producirá un error de coincidencia). El fondo del padre se rastrea, y se utiliza la versión actual cada vez que se requiere el fondo de la ventana.

XCB_CW_BACK_PIXEL
Anula BackPixmap. Se utiliza un pixmap de tamaño indefinido rellenado con el píxel de fondo especificado para el fondo. No se realiza ninguna comprobación de rango, el píxel de fondo se trunca al número apropiado de bits.
XCB_CW_BORDER_PIXMAP
Anula el pixmap del borde predeterminado. El pixmap del borde y la ventana deben tener la misma raíz y la misma profundidad. Se puede usar un pixmap de cualquier tamaño, aunque algunos tamaños pueden ser más rápidos que otros.

El valor especial XCB_COPY_FROM_PARENT significa que se copia el pixmap del borde del padre (los cambios posteriores en el atributo del borde del padre no afectan al hijo), pero la ventana debe tener la misma profundidad que el padre.

XCB_CW_BORDER_PIXEL
Anula BorderPixmap. Se utiliza un pixmap de tamaño indefinido rellenado con el píxel de borde especificado para el borde. No se realiza ninguna comprobación de rango en el valor del píxel de borde, se trunca al número apropiado de bits.
XCB_CW_BIT_GRAVITY
Define qué región de la ventana debe conservarse si se redimensiona la ventana.
XCB_CW_WIN_GRAVITY
Define cómo se debe reposicionar la ventana si se redimensiona el padre (ver ConfigureWindow).
XCB_CW_BACKING_STORE
Un backing-store de WhenMapped aconseja al servidor que mantener el contenido de las regiones oscurecidas cuando la ventana está mapeada sería beneficioso. Un backing-store de Always aconseja al servidor que mantener el contenido incluso cuando la ventana no está mapeada sería beneficioso. En este caso, el servidor puede generar un evento de exposición cuando se crea la ventana. Un valor de NotUseful aconseja al servidor que mantener el contenido es innecesario, aunque un servidor aún puede optar por mantener el contenido mientras la ventana está mapeada. Tenga en cuenta que si el servidor mantiene el contenido, entonces el servidor debe mantener el contenido completo, no solo la región dentro de los límites del padre, incluso si la ventana es más grande que su padre. Mientras el servidor mantiene el contenido, normalmente no se generarán eventos de exposición, pero el servidor puede dejar de mantener el contenido en cualquier momento.
XCB_CW_BACKING_PLANES
Los planos de respaldo indican (con bits establecidos en 1) qué planos de bits de la ventana contienen datos dinámicos que deben conservarse en los respaldos y durante los save-unders.
XCB_CW_BACKING_PIXEL
El píxel de respaldo especifica qué valor usar en los planos no cubiertos por los planos de respaldo. El servidor es libre de guardar solo los planos de bits especificados en el respaldo o save-under y regenerar los planos restantes con el valor de píxel especificado. Cualquier bit más allá de la profundidad especificada de la ventana en estos valores simplemente se ignora.
XCB_CW_OVERRIDE_REDIRECT
El override-redirect especifica si las solicitudes de mapeo y configuración en esta ventana anulan un SubstructureRedirect en el padre, típicamente para informar a un gestor de ventanas que no manipule la ventana.
XCB_CW_SAVE_UNDER
Si es 1, se aconseja al servidor que, cuando esta ventana esté mapeada, guardar el contenido de las ventanas que oscurece sería beneficioso.
XCB_CW_EVENT_MASK
La máscara de eventos define de qué eventos está interesado el cliente para esta ventana (o para algunos tipos de eventos, para los inferiores de la ventana).
XCB_CW_DONT_PROPAGATE
La máscara do-not-propagate define qué eventos no deben propagarse a las ventanas ancestro cuando ningún cliente tiene el tipo de evento seleccionado en esta ventana.
XCB_CW_COLORMAP
El mapa de colores especifica el mapa de colores que mejor refleja los colores verdaderos de la ventana. Los servidores capaces de soportar múltiples mapas de hardware pueden usar esta información, y los gestores de ventanas pueden usarla para solicitudes de InstallColormap. El mapa de colores debe tener el mismo tipo visual y raíz que la ventana (o se producirá un error de coincidencia). Si se especifica CopyFromParent, se copia el mapa de colores del padre (los cambios posteriores en el atributo del mapa de colores del padre no afectan al hijo). Sin embargo, la ventana debe tener el mismo tipo visual que el padre (o se producirá un error de coincidencia), y el padre no debe tener un mapa de colores de None (o se producirá un error de coincidencia). Para una explicación de None, ver la solicitud FreeColormap. El mapa de colores se copia compartiendo el objeto del mapa de colores entre el hijo y el padre, no haciendo una copia completa del contenido del mapa de colores.
XCB_CW_CURSOR
Si se especifica un cursor, se utilizará siempre que el puntero esté en la ventana. Si se especifica None, se utilizará el cursor del padre cuando el puntero esté en la ventana, y cualquier cambio en el cursor del padre provocará un cambio inmediato en el cursor mostrado.
value_list
Valores para cada uno de los atributos especificados en la máscara de bits value_mask. El orden debe corresponder al orden de los bits posibles de value_mask. Ver el ejemplo.

DESCRIPCIÓN

Cambia los atributos especificados por value_mask para la window especificada.

VALOR DE RETORNO

Devuelve una xcb_void_cookie_t. Los errores (si los hay) deben manejarse en el bucle de eventos.

Si desea manejar los errores directamente con xcb_request_check en su lugar, utilice xcb_change_window_attributes_checked. Ver xcb-requests(3) para más detalles.
