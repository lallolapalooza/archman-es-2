xcb_query_font(3) Solicitudes XCB xcb_query_font(3)

NOMBRE

xcb_query_font - consultar métricas de fuentes

SINOPSIS

#include <xcb/xproto.h>

Función de solicitud

xcb_query_font_cookie_t xcb_query_font(xcb_connection_t *conn, xcb_fontable_t font);

Estructura de datos de respuesta

typedef struct xcb_query_font_reply_t {
    uint8_t        response_type;
    uint8_t        pad0;
    uint16_t       sequence;
    uint32_t       length;
    xcb_charinfo_t min_bounds;
    uint8_t        pad1[4];
    xcb_charinfo_t max_bounds;
    uint8_t        pad2[4];
    uint16_t       min_char_or_byte2;
    uint16_t       max_char_or_byte2;
    uint16_t       default_char;
    uint16_t       properties_len;
    uint8_t        draw_direction;
    uint8_t        min_byte1;
    uint8_t        max_byte1;
    uint8_t        all_chars_exist;
    int16_t        font_ascent;
    int16_t        font_descent;
    uint32_t       char_infos_len;
} xcb_query_font_reply_t;

Función de respuesta

xcb_query_font_reply_t *xcb_query_font_reply(xcb_connection_t *conn, xcb_query_font_cookie_t cookie, xcb_generic_error_t **e);

Accesorios de respuesta

xcb_fontprop_t *xcb_query_font_properties(const xcb_query_font_request_t *reply);

int xcb_query_font_properties_length(const xcb_query_font_reply_t *reply);

xcb_fontprop_iterator_t xcb_query_font_properties_iterator(const xcb_query_font_reply_t *reply);

xcb_charinfo_t *xcb_query_font_char_infos(const xcb_query_font_request_t *reply);

int xcb_query_font_char_infos_length(const xcb_query_font_reply_t *reply);

xcb_charinfo_iterator_t xcb_query_font_char_infos_iterator(const xcb_query_font_reply_t *reply);

ARGUMENTOS DE LA SOLICITUD

conn
La conexión XCB a X11.
font
La fuente gráfica (Font o Graphics Context) a consultar.

CAMPOS DE RESPUESTA

response_type
El tipo de esta respuesta, en este caso XCB_QUERY_FONT. Este campo también está presente en xcb_generic_reply_t y puede usarse para distinguir las respuestas entre sí.
sequence
El número de secuencia de la última solicitud procesada por el servidor X11.
length
La longitud de la respuesta, en palabras (una palabra son 4 bytes).
min_bounds
límites mínimos de todos los caracteres existentes
max_bounds
límites máximos de todos los caracteres existentes
min_char_or_byte2
primer carácter
max_char_or_byte2
último carácter
default_char
carácter a imprimir para caracteres indefinidos
properties_len
cuántas propiedades hay
draw_direction
Uno de los siguientes valores:
XCB_FONT_DRAW_LEFT_TO_RIGHT

XCB_FONT_DRAW_RIGHT_TO_LEFT
TODO: AÚN NO DOCUMENTADO.

TODO: AÚN NO DOCUMENTADO.
all_chars_exist
indicador si todos los caracteres tienen un tamaño distinto de cero
font_ascent
línea base hasta el borde superior del raster
font_descent
línea base hasta el borde inferior del raster

DESCRIPCIÓN

Consulta la información asociada a la fuente.

VALOR DE RETORNO

Devuelve un xcb_query_font_cookie_t. Los errores deben manejarse al llamar a la función de respuesta xcb_query_font_reply.

Si desea manejar los errores en el bucle de eventos, utilice xcb_query_font_unchecked. Consulte xcb-requests(3) para obtener más detalles.

ERRORES

Esta solicitud nunca genera errores.

VER TAMBIÉN
