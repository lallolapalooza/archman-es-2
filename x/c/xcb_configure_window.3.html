NOMBRE

xcb_configure_window - Configura los atributos de la ventana

SINOPSIS

#include <xcb/xproto.h>

Función de solicitud

xcb_void_cookie_t xcb_configure_window(xcb_connection_t *conn, xcb_window_t window, uint16_t value_mask, const void *value_list);

ARGUMENTOS DE LA SOLICITUD

conn
La conexión XCB a X11.
window
La ventana a configurar.
value_mask
Máscara de bits de los atributos a cambiar.
value_list
Nuevos valores, correspondientes a los atributos en value_mask. El orden debe corresponder al orden de los bits posibles de value_mask. Ver el ejemplo.

DESCRIPCIÓN

Configura el tamaño, posición, ancho del borde y orden de apilamiento de una ventana.

VALOR DE RETORNO

Devuelve una xcb_void_cookie_t. Los errores (si los hay) deben manejarse en el bucle de eventos.

Si desea manejar los errores directamente con xcb_request_check en su lugar, use xcb_configure_window_checked. Ver xcb-requests(3) para más detalles.

ERRORES

xcb_match_error_t
Especificaste un Hermano sin especificar también el Modo de Apilamiento o la ventana no es realmente un Hermano.
xcb_value_error_t
TODO: ¿razones?
xcb_window_error_t
La ventana especificada no existe. TODO: ¿alguna otra razón?

EJEMPLO

/*
 * Configura la ventana dada en la esquina superior izquierda
 * con un tamaño de 1024x768 píxeles.
 *
 */
void my_example(xcb_connection_t *c, xcb_window_t window) {
    uint16_t mask = 0;
    mask |= XCB_CONFIG_WINDOW_X;
    mask |= XCB_CONFIG_WINDOW_Y;
    mask |= XCB_CONFIG_WINDOW_WIDTH;
    mask |= XCB_CONFIG_WINDOW_HEIGHT;
    const uint32_t values[] = {
        0,    /* x */
        0,    /* y */
        1024, /* width */
        768   /* height */
    };
    xcb_configure_window(c, window, mask, values);
    xcb_flush(c);
}
