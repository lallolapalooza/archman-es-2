CAMPOS DEL EVENTO

response_type
El tipo de este evento, en este caso XCB_RANDR_SCREEN_CHANGE_NOTIFY. Este campo también está presente en xcb_generic_event_t y se puede utilizar para distinguir los eventos entre sí.
