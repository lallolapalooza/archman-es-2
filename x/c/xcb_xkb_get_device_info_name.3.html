DESCRIPCIÓN

VALOR DE RETORNO

Devuelve una xcb_xkb_get_device_info_cookie_t. Los errores deben manejarse al llamar a la función de respuesta xcb_xkb_get_device_info_reply.

Si desea manejar los errores en el bucle de eventos en su lugar, use xcb_xkb_get_device_info_unchecked. Consulte xcb-requests(3) para obtener detalles.

ERRORES

Esta solicitud nunca genera errores.

NAME

xcb_xkb_get_device_info_name -

SYNOPSIS

#include <xcb_xkb.h>


xcb_xkb_get_device_info_reply_t *
xcb_xkb_get_device_info_name (xcb_connection_t *c,
                              uint8_t           device_id);

REPLY FIELDS

See DESCRIPTION.

DESCRIPTION

Get the name of a specific XKB device.

RETURN VALUE

Returns a pointer to the xcb_xkb_get_device_info_reply_t structure containing the device name. The memory for this structure should be freed using xcb_xkb_get_device_info_reply_t_free().
