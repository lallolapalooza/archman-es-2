XCUTSEL(1) Manual de comandos generales XCUTSEL(1)

NOMBRE

xcutsel - intercambiar entre el búfer de corte y la selección

SINOPSIS

xcutsel [ -opcióntoolkit ...] [-selection selección] [-cutbuffer número]

DESCRIPCIÓN

El programa xcutsel se utiliza para copiar la selección actual a un búfer de corte y para crear una selección que contenga el contenido actual del búfer de corte. Actúa como un puente entre aplicaciones que no admiten selecciones y aquellas que sí lo hacen.

Por defecto, xcutsel utilizará la selección llamada PRIMARY y el búfer de corte CUT_BUFFER0. Cualquiera de estas opciones o ambas pueden ser anuladas por argumentos de línea de comandos o por recursos.

Una ventana de xcutsel tiene los siguientes botones:

salir
Cuando se presiona este botón, xcutsel sale. Cualquier selección mantenida por xcutsel se libera automáticamente.
copiar PRIMARY a 0
Cuando se presiona este botón, xcutsel copia la selección actual al búfer de corte.
copiar 0 a PRIMARY
Cuando se presiona este botón, xcutsel convierte el contenido actual del búfer de corte en la selección.

Las etiquetas de los botones reflejan la selección y el búfer de corte seleccionados por las opciones de línea de comandos o a través de la base de datos de recursos.

Cuando se activa el botón "copiar 0 a PRIMARY", este permanecerá invertido mientras xcutsel sea el propietario de la selección. Esto sirve para recordarle qué cliente posee la selección actual. Tenga en cuenta que el valor de la selección permanece constante; si el búfer de corte cambia, debe volver a activar el botón de copia para recuperar el nuevo valor cuando lo desee.

OPCIONES

Xcutsel acepta todas las opciones de línea de comandos estándar del Kit de Herramientas X, así como las siguientes:

-selection nombre
Esta opción especifica el nombre de la selección a utilizar. El valor por defecto es PRIMARY. Las únicas abreviaturas admitidas para esta opción son ``-select'', ``-sel'' y ``-s'', ya que la opción estándar del kit de herramientas ``-selectionTimeout'' tiene un nombre similar.
-cutbuffer número
Esta opción especifica el número del búfer de corte a utilizar. El valor por defecto es el búfer de corte 0.

VALORES PREDETERMINADOS X

Este programa acepta todos los nombres y clases de recursos estándar del Kit de Herramientas X, así como:

selection (clase Selection)
Este recurso especifica el nombre de la selección a utilizar. El valor por defecto es PRIMARY.
cutBuffer (clase CutBuffer)
Este recurso especifica el número del búfer de corte a utilizar. El valor por defecto es 0.

NOMBRES DE WIDGET

Los siguientes nombres de instancia pueden ser utilizados cuando se desea la configuración por parte del usuario de las etiquetas en ellos:

sel-cut (clase Command)
Este es el botón "copiar SELECTION a BUFFER".
cut-sel (clase Command)
Este es el botón "copiar BUFFER a SELECTION".
quit (clase Command)
Este es el botón "salir".

VER TAMBIÉN

X(7), xclipboard(1), xterm(1), documentación del widget de texto, documentación individual del cliente sobre cómo realizar una selección.

ERRORES

No hay forma de cambiar el nombre de la selección o el número del búfer de corte mientras el programa se está ejecutando.
