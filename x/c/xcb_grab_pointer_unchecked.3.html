xcb_grab_pointer - Agarra el puntero

ARGUMENTOS DE LA SOLICITUD

conn
La conexión XCB a X11.
owner_events
Si es 1, la grab_window seguirá recibiendo los eventos del puntero. Si es 0, los eventos no se informarán a la grab_window.
grab_window
Especifica la ventana en la que se debe agarrar el puntero.
event_mask
Especifica qué eventos del puntero se informan al cliente.

pointer_mode
Uno de los siguientes valores:
XCB_GRAB_MODE_SYNC
El estado del teclado parece congelarse: el servidor no genera más eventos de teclado hasta que el cliente que agarra emita una solicitud de AllowEvents liberadora o hasta que se libere el agarre del teclado.

keyboard_mode
Uno de los siguientes valores:
XCB_GRAB_MODE_SYNC
El estado del teclado parece congelarse: el servidor no genera más eventos de teclado hasta que el cliente que agarra emita una solicitud de AllowEvents liberadora o hasta que se libere el agarre del teclado.
XCB_GRAB_MODE_ASYNC
El procesamiento de eventos del teclado continúa normalmente.
confine_to
Especifica la ventana en la que confinar el puntero (el usuario no podrá mover el puntero fuera de esa ventana).

El valor especial XCB_NONE significa no confinar el puntero.

cursor
Especifica el cursor que se debe mostrar o XCB_NONE para no cambiar el cursor.
time
El argumento time permite evitar ciertas circunstancias que surgen si las aplicaciones tardan mucho en responder o si hay retrasos de red largos. Considere una situación en la que tiene dos aplicaciones, ambas suelen agarrar el puntero al hacer clic en ellas. Si ambas aplicaciones especifican la marca de tiempo del evento, la segunda aplicación puede activarse más rápido y agarrar el puntero con éxito antes que la primera aplicación. La primera aplicación luego recibirá una indicación de que la otra aplicación agarró el puntero antes de que se procesara su solicitud.

El valor especial XCB_CURRENT_TIME se reemplazará con la hora actual del servidor.

DESCRIPCIÓN

Agarra activamente el control del puntero. Los eventos posteriores del puntero solo se informan al cliente que agarra. Anula cualquier agarre de puntero activo por parte de este cliente.

VALOR DE RETORNO

Devuelve una xcb_grab_pointer_cookie_t. Los errores deben manejarse al llamar a la función de respuesta xcb_grab_pointer_reply.

Si desea manejar los errores en el bucle de eventos en su lugar, use xcb_grab_pointer_unchecked. Consulte xcb-requests(3) para obtener detalles.

EJEMPLO

/*
 * Agarra el puntero activamente
 *
 */
void my_example(xcb_connection_t *conn, xcb_screen_t *screen, xcb_cursor_t cursor) {
    xcb_grab_pointer_cookie_t cookie;
    xcb_grab_pointer_reply_t *reply;
    cookie = xcb_grab_pointer(
        conn,
        false,               /* obtener todos los eventos del puntero especificados por la siguiente máscara */
        screen->root,        /* agarrar la ventana raíz */
        XCB_NONE,            /* qué eventos permitir pasar */
        XCB_GRAB_MODE_ASYNC, /* los eventos del puntero deben continuar con normalidad */
        XCB_GRAB_MODE_ASYNC, /* modo del teclado */
        XCB_NONE,            /* confine_to = en qué ventana debe permanecer el cursor */
        cursor,              /* cambiamos el cursor a lo que el usuario deseaba */
        XCB_CURRENT_TIME
    );
    if ((reply = xcb_grab_pointer_reply(conn, cookie, NULL))) {
        if (reply->status == XCB_GRAB_STATUS_SUCCESS)
            printf("puntero agarrado con éxito\n");
        free(reply);
    }
}

SYNOPSIS

                        #include <xcb/grab.h>
                    
                        xcb_grab_keyboard_cookie_t
                        xcb_grab_keyboard(
                            xcb_connection_t *conn,
                            xcb_window_t grab_window,
                            uint32_t time,
                            uint8_t pointer_mode,
                            uint8_t keyboard_mode,
                            uint16_t owner_events,
                            xcb_cursor_t confine_to
                        );

REQUEST ARGUMENTS

conn
The XCB connection to the X server.
grab_window
The window on which to grab the keyboard.
time
The time at which the grab should occur. Use XCB_CURRENT_TIME for the current time.
pointer_mode
Specifies whether pointer events should be sent to the client grabbing the keyboard. Possible values are XCB_GRAB_MODE_SYNC and XCB_GRAB_MODE_ASYNC.
keyboard_mode
Specifies whether keyboard events should be sent to the client grabbing the keyboard. Possible values are XCB_GRAB_MODE_SYNC and XCB_GRAB_MODE_ASYNC.
owner_events
Specifies whether the grabbed window should receive events. Possible values are 1 (True) and 0 (False).
confine_to
The window to which the pointer should be confined. Use XCB_NONE if the pointer should not be confined.

REPLY FIELDS

If the request is successful, the following fields are available in the reply:

status
The status of the grab. Possible values are XCB_GRAB_STATUS_SUCCESS, XCB_GRAB_STATUS_ALREADY_GRABBED, XCB_GRAB_STATUS_INVALID_TIME, XCB_GRAB_STATUS_NOT_VIEWABLE, and XCB_GRAB_STATUS_PERMISSIONS.

DESCRIPTION

Grabs the keyboard, causing all keyboard events to be reported to the grabbing client. The grab continues until the time specified by time or until the grab is released.

The pointer_mode and keyboard_mode arguments control whether pointer and keyboard events are actively delivered to clients, respectively. If set to XCB_GRAB_MODE_SYNC, events are reported only when the grabbing client calls `xcb_allow_events`.

The owner_events argument determines whether the grabbed window itself receives events. If set to 1 (True), the window receives events normally. If set to 0 (False), the window does not receive events, and they are instead reported to the grabbing client.

The confine_to argument specifies a window to which the pointer should be confined. If set to XCB_NONE, the pointer is not confined.

RETURN VALUE

Returns a xcb_grab_keyboard_cookie_t which can be used to retrieve the reply to the request.

ERRORS

xcb_grab_keyboard_error_t

XCB_GRAB_STATUS_ALREADY_GRABBED
Another client has already grabbed the keyboard.
XCB_GRAB_STATUS_INVALID_TIME
The time specified is in the future or too far in the past.
XCB_GRAB_STATUS_NOT_VIEWABLE
The grabbed window is not viewable.
XCB_GRAB_STATUS_PERMISSIONS
The client does not have permission to grab the keyboard.

EXAMPLE

                        // Grab the keyboard in the root window
                        xcb_grab_keyboard_cookie_t cookie =
                            xcb_grab_keyboard(conn,
                                                    xcb_setup_root_window(xcb_get_setup(conn), 0),
                                                    XCB_CURRENT_TIME,
                                                    XCB_GRAB_MODE_ASYNC,
                                                    XCB_GRAB_MODE_ASYNC,
                                                    XCB_NONE,
                                                    XCB_NONE);

                        xcb_grab_keyboard_reply_t *reply =
                            xcb_grab_keyboard_reply(conn, cookie, NULL);

                        if (reply->status == XCB_GRAB_STATUS_SUCCESS) {
                            /* Keyboard grabbed successfully */
                        }

                        free(reply);
