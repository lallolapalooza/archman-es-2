NOMBRE

xcur2png - toma imágenes PNG de Xcursor y genera un archivo de configuración para xcursorgen

SINOPSIS

xcur2png [ -V ] [ --version ]

xcur2png [ -h ] [ --help ]

xcur2png [ -c ruta-conf ] [ --conf=ruta-conf ] [ -d ruta-dir ] [ --directory=ruta-dir ] [ -i sufijo ] [ --initial-suffix=sufijo ] [ -q ] [ --quiet ] [ -n ] [ --dry-run ] archivo-Xcursor

DESCRIPCIÓN

Xcur2png toma imágenes PNG de archivo-Xcursor y genera un archivo de configuración reutilizable por xcursorgen(1). En pocas palabras, es un convertidor de cursores X a imágenes PNG.

archivo-Xcursor es la ruta a un archivo Xcursor existente. No se admite el uso de múltiples archivo-Xcursor. Las imágenes PNG generadas se guardan en el directorio actual.

OPCIONES

-V, --version
Muestra el número de versión y sale con estado 0.
-h, --help
Muestra el mensaje de uso y sale con estado 0.
-c ruta-conf, --conf=ruta-conf
Establece la ruta de salida del archivo de configuración. Si se especifica "-", se usa stdout(3). Si no se especifica, se usa [nombre del archivo de archivo-Xcursor].conf. Si "ruta-conf" es un directorio, el archivo de configuración se guarda en el directorio especificado como [nombre del archivo de archivo-Xcursor].conf.
-d ruta-dir, --directory=ruta-dir
Establece la ruta del directorio donde se guardan las imágenes PNG. Si no se especifica, se usa el directorio actual.
-i sufijo, --initial-suffix=sufijo
Establece el sufijo inicial de las imágenes PNG a sufijo. sufijo debe ser un entero positivo y no mayor que 999. Cuando el sufijo supera 999, xcur2png sale con un estado negativo.
-q, --quiet
Suprime el mensaje de progreso.
-n, --dry-run
No genera imágenes PNG ni datos de configuración en archivos. Los datos de configuración se envían a stdout y el mensaje de progreso se suprime.

ESTADO DE SALIDA

xcur2png devuelve el número de imágenes PNG de salida si la conversión se completó con éxito y se generó el archivo-configuración. Si ocurre un error, xcur2png devuelve un valor negativo.
