XCURSORGEN(1) Manual de Comandos Generales XCURSORGEN(1)

NOMBRE

xcursorgen - crea un archivo de cursor de X a partir de una colección de imágenes PNG

SINOPSIS

xcursorgen [ -p dir ] [ --prefix dir ] [ archivo-config [ archivo-salida ] ]
xcursorgen -V | --version | -? | --help

DESCRIPCIÓN

Xcursorgen lee el archivo-config para encontrar la lista de imágenes de cursor junto con su punto activo e información de tamaño nominal. Xcursorgen convierte todas las imágenes al formato Xcursor y las escribe en el archivo-salida.

Cada línea en el archivo de configuración tiene el formato:
<tamaño> <xhot> <yhot> <nombre-archivo> <retraso-ms>

Múltiples imágenes con el mismo <tamaño> se utilizan para crear cursores animados, el valor <retraso-ms> en cada línea indica cuánto tiempo se debe mostrar cada imagen antes de cambiar a la siguiente. <retraso-ms> puede omitirse para cursores estáticos.

Si no se especifica archivo-config, o se especifica como "-", se utiliza la entrada estándar para el archivo de configuración. Si no se especifica archivo-salida, o se especifica como "-", se utiliza la salida estándar para el archivo de salida.

OPCIONES

-V, --version
Muestra el número de versión y sale.
-?, --help
Muestra el mensaje de uso y sale.
-p dir, --prefix dir
Busca imágenes de cursor en el directorio especificado por dir. Si no se especifica, se utiliza el directorio actual.
