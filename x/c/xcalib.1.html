NOMBRE

xcalib - Cargador diminuto de calibración de monitor para Xorg y Windows.

SINOPSIS

xcalib [-opciones] PERFIL_ICC

DESCRIPCIÓN

xcalib carga la etiqueta 'vcgt' de los perfiles ICC al servidor usando la extensión XRandR/XVidMode/GDI para cargar las curvas de calibración en tu pantalla.

OPCIONES

-d, -display <host:dpy>
-s, -screen <pantalla-#>
-c, -clear
-n, -noaction
-v, -verbose
-p, -printramps
-l, -loss
-i, -invert
-gc, -gammacor <gamma>
-b, -brightness <porcentaje>
-co, -contrast <porcentaje>
-red <gamma> <porcentaje-brillo> <porcentaje-contraste>
-green <gamma> <porcentaje-brillo> <porcentaje-contraste>
-blue <gamma> <porcentaje-brillo> <porcentaje-contraste>
-a, -alter
-h, -help
-version

El último parámetro DEBE ser un perfil ICC que contenga una etiqueta vcgt o mLUT, o vacío si se usa el parámetro "-a" o "-alter", o si la LUT se va a limpiar con el parámetro "-c".

EJEMPLOS

Asignar las curvas VCGT de un perfil ICC a una pantalla:
xcalib -d :0 -s 0 -v perfil_con_etiqueta_vcgt.icc
Restablecer la LUT de hardware de una pantalla para realizar una calibración:
xcalib -d :0 -s 0 -c
