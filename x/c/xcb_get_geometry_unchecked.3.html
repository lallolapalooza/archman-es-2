NOMBRE

xcb_get_geometry - Obtiene la geometría actual de la ventana

SINOPSIS

#include <xcb/xproto.h>

Función Solicitud

xcb_get_geometry_cookie_t xcb_get_geometry(xcb_connection_t *conn, xcb_drawable_t drawable);

Estructura Respuesta

typedef struct xcb_get_geometry_reply_t {
    uint8_t      response_type;
    uint8_t      depth;
    uint16_t     sequence;
    uint32_t     length;
    xcb_window_t root;
    int16_t      x;
    int16_t      y;
    uint16_t     width;
    uint16_t     height;
    uint16_t     border_width;
    uint8_t      pad0[2];
} xcb_get_geometry_reply_t;

Función Respuesta

xcb_get_geometry_reply_t *xcb_get_geometry_reply(xcb_connection_t *conn, xcb_get_geometry_cookie_t cookie, xcb_generic_error_t **e);

ARGUMENTOS DE LA SOLICITUD

conn
La conexión XCB a X11.
drawable
El drawable (Ventana o Pixmap) cuya geometría se recibirá.

CAMPOS DE LA RESPUESTA

response_type
El tipo de esta respuesta, en este caso XCB_GET_GEOMETRY. Este campo también está presente en xcb_generic_reply_t y se puede usar para distinguir respuestas entre sí.
sequence
El número de secuencia de la última solicitud procesada por el servidor X11.
length
La longitud de la respuesta, en palabras (una palabra son 4 bytes).
depth
La profundidad del drawable (bits por píxel para el objeto).
root
La ventana raíz de la pantalla que contiene el drawable.
x
La coordenada X del drawable. Si el drawable es una ventana, la coordenada especifica la esquina exterior superior izquierda en relación con el origen de su padre. Si el drawable es un pixmap, la coordenada X es siempre 0.
y
La coordenada Y del drawable. Si el drawable es una ventana, la coordenada especifica la esquina exterior superior izquierda en relación con el origen de su padre. Si el drawable es un pixmap, la coordenada Y es siempre 0.
width
El ancho del drawable.
height
La altura del drawable.
border_width
El ancho del borde (en píxeles).

DESCRIPCIÓN

Obtiene la geometría actual del drawable especificado (ya sea Window o Pixmap).

VALOR DE RETORNO

Devuelve una xcb_get_geometry_cookie_t. Los errores deben gestionarse al llamar a la función de respuesta xcb_get_geometry_reply.

Si desea gestionar los errores en el bucle de eventos en su lugar, utilice xcb_get_geometry_unchecked. Consulte xcb-requests(3) para obtener más detalles.

EJEMPLO

/*
 * Muestra la posición x e y de la ventana dada.
 *
 */
void my_example(xcb_connection_t *c, xcb_window_t window) {
    xcb_get_geometry_cookie_t cookie;
    xcb_get_geometry_reply_t *reply;
    cookie = xcb_get_geometry(c, window);
    /* ... haz otro trabajo aquí si es posible ... */
    if ((reply = xcb_get_geometry_reply(c, cookie, NULL))) {
        printf("Esta ventana está en %d, %d\n", reply->x, reply->y);
    }
    free(reply);
}
