grab_window

Marca de tiempo para evitar condiciones de carrera al ejecutar X a través de la red.

El valor especial XCB_CURRENT_TIME será reemplazado por la hora actual del servidor.

pointer_mode
Uno de los siguientes valores:
XCB_GRAB_MODE_SYNC

El procesamiento de eventos del teclado continúa normalmente.

DESCRIPCIÓN

Captura activamente el control del teclado y genera eventos FocusIn y FocusOut. Los eventos de teclado posteriores solo se informan al cliente que realiza la captura.

Cualquier captura activa del teclado por parte de este cliente se anula. Si el teclado está activamente capturado por algún otro cliente, se devuelve AlreadyGrabbed. Si grab_window no es visible, se devuelve GrabNotViewable. Si el teclado está congelado por una captura activa de otro cliente, se devuelve GrabFrozen. Si la marca de tiempo especificada es anterior a la marca de tiempo de la última captura de teclado o posterior a la hora actual del servidor X, se devuelve GrabInvalidTime. De lo contrario, la marca de tiempo de la última captura de teclado se establece en la marca de tiempo especificada.

VALOR DE RETORNO

Devuelve una xcb_grab_keyboard_cookie_t. Los errores deben gestionarse al llamar a la función de respuesta xcb_grab_keyboard_reply.

Si desea gestionar los errores en el bucle de eventos, utilice xcb_grab_keyboard_unchecked. Consulte xcb-requests(3) para obtener detalles.

EJEMPLO

/*
 * Captura activamente el teclado
 *
 */
void my_example(xcb_connection_t *conn, xcb_screen_t *screen) {
    xcb_grab_keyboard_cookie_t cookie;
    xcb_grab_keyboard_reply_t *reply;
    cookie = xcb_grab_keyboard(
        conn,
        true,                /* reportar eventos */
        screen->root,        /* capturar la ventana raíz */
        XCB_CURRENT_TIME,
        XCB_GRAB_MODE_ASYNC, /* procesar eventos como normal, no requerir sincronización */
        XCB_GRAB_MODE_ASYNC
    );
    if ((reply = xcb_grab_keyboard_reply(conn, cookie, NULL))) {
        if (reply->status == XCB_GRAB_STATUS_SUCCESS)
            printf("teclado capturado con éxito\n");
        free(reply);
    }
}

xcb_grab_keyboard_unchecked

NAME

xcb_grab_keyboard_unchecked - grab the keyboard

SYNOPSIS

#include <xcb/xproto.h>

 
 xcb_grab_keyboard_reply_t *xcb_grab_keyboard_unchecked(xcb_connection_t * c,
                                                         uint32_t  grab_window,
                                                         uint32_t  event_mask,
                                                         uint8_t  pointer_mode,
                                                         uint8_t  keyboard_mode,
                                                         uint32_t  owner_events,
                                                         uint32_t  time);

REQUEST ARGUMENTS

c
The XCB connection, as returned by xcb_connect().
grab_window
The window to grab.
event_mask
Specifies which events the client is interested in.
pointer_mode
Specifies whether the pointer should be grabbed.
keyboard_mode
Specifies whether the keyboard should be grabbed.
owner_events
Specifies whether the grab should be treated as active.
time
Specifies the time of the grab.

REPLY FIELDS

same_screen
Whether the grab window is on the same screen as the pointer.
status
The status of the grab.

DESCRIPTION

Grabs control of the keyboard. Any keyboard events that would normally be reported to clients are reported to the grabbing client.

The grab continues until the time specified by time or until the grab is released.

The pointer_mode and keyboard_mode arguments specify whether the pointer and keyboard, respectively, should be allowed to continue processing events.

The owner_events argument specifies whether events should be reported to the grabbing client or to the clients that normally would receive them.

The event_mask argument specifies which events the grabbing client is interested in.

RETURN VALUE

Returns a reply structure that contains the following fields:

  • same_screen: A boolean indicating whether the grab window is on the same screen as the pointer.
  • status: The status of the grab. Possible values are:
    • XCB_GRAB_STATUS_SUCCESSFUL
    • XCB_GRAB_STATUS_ALREADY_GRABBED
    • XCB_GRAB_STATUS_INVALID_TIME
    • XCB_GRAB_STATUS_NOT_VIEWABLE
    • XCB_GRAB_STATUS_FROZEN

ERRORS

xcb_grab_keyboard_error_t.

EXAMPLE

Grab the keyboard for the client: 

xcb_grab_keyboard_reply_t *reply;
reply = xcb_grab_keyboard_unchecked(c,
                                    XCB_GRAB_ANY,
                                    XCB_EVENT_MASK_ANY,
                                    XCB_GRAB_MODE_ASYNC,
                                    XCB_GRAB_MODE_ASYNC,
                                    XCB_CURRENT_TIME);
if (reply->status == XCB_GRAB_STATUS_SUCCESSFUL) {
    // Keyboard grabbed successfully
}
free(reply);
