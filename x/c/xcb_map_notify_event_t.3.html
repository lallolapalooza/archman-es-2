xcb_map_notify_event_t(3)

Paquete: libxcb

Licencias: X11

xcb_map_notify_event_t(3) Eventos XCB xcb_map_notify_event_t(3)

NOMBRE

xcb_map_notify_event_t - una ventana fue mapeada

SINOPSIS

#include <xcb/xproto.h>

Estructura de datos del evento

typedef struct xcb_map_notify_event_t {
    uint8_t      response_type;
    uint8_t      pad0;
    uint16_t     sequence;
    xcb_window_t event;
    xcb_window_t window;
    uint8_t      override_redirect;
    uint8_t      pad1[3];
} xcb_map_notify_event_t;

CAMPOS DEL EVENTO

response_type
El tipo de este evento, en este caso XCB_MAP_NOTIFY. Este campo también está presente en xcb_generic_event_t y se puede usar para distinguir entre eventos.
sequence
El número de secuencia de la última solicitud procesada por el servidor X11.
event
La ventana que fue mapeada o su padre, dependiendo de si se seleccionó StructureNotify o SubstructureNotify.
window
La ventana que fue mapeada.
override_redirect
Los gestores de ventanas deben ignorar esta ventana si override_redirect es 1.
