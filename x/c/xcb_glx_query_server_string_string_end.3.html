El tipo de esta respuesta, en este caso XCB_GLX_QUERY_SERVER_STRING. Este campo también está presente en el xcb_generic_reply_t y se puede utilizar para diferenciar las respuestas entre sí.

DESCRIPCIÓN

VALOR DE RETORNO

Devuelve una xcb_glx_query_server_string_cookie_t. Los errores deben manejarse al llamar a la función de respuesta xcb_glx_query_server_string_reply.

Si desea manejar los errores en el bucle de eventos en su lugar, utilice xcb_glx_query_server_string_unchecked. Consulte xcb-requests(3) para obtener más detalles.

ERRORES

Esta solicitud nunca genera ningún error.
