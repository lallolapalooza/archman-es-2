NOMBRE

xcb_shm_attach_fd - Crear un segmento de memoria compartida

SINOPSIS

#include <xcb/shm.h>

Función de solicitud

xcb_void_cookie_t xcb_shm_attach_fd(xcb_connection_t *conn, xcb_shm_seg_t shmseg, int32_t shm_fd, uint8_t read_only);

ARGUMENTOS DE LA SOLICITUD

conn
La conexión XCB a X11.
shmseg
Un ID de segmento de memoria compartida creado con xcb_generate_id().
shm_fd
El descriptor de archivo que el servidor debe mapear (mmap()).
read_only
Verdadero si el segmento debe ser mapeado de solo lectura por el servidor X11, de lo contrario falso.

DESCRIPCIÓN

Crea un segmento de memoria compartida. El descriptor de archivo se mapeará en la posición cero, y el tamaño se obtendrá usando fstat(). Un tamaño cero resultará en un error de valor.

VALOR DE RETORNO

Devuelve un xcb_void_cookie_t. Los errores (si los hay) deben manejarse en el bucle de eventos.

Si desea manejar los errores directamente con xcb_request_check en su lugar, use xcb_shm_attach_fd_checked. Consulte xcb-requests(3) para obtener detalles.

ERRORES

Esta solicitud nunca genera errores.

VER TAMBIÉN

xcb-requests(3)

AUTOR

Generado a partir de shm.xml. Póngase en contacto con xcb@lists.freedesktop.org para correcciones y mejoras.
