NOMBRE

xcolor - selector de color ligero para X11

SINOPSIS

xcolor [-f NOMBRE | -c FORMATO] [-s [SELECCIÓN]] [-S ESCALA] [-P TAMAÑO_VISTA_PREVIA] [-v] [-h]

DESCRIPCIÓN

xcolor es un selector de color ligero para X11. Utilice el ratón para seleccionar colores visibles en cualquier lugar de la pantalla para obtener su representación RGB.

Por defecto, el color seleccionado se imprime en la salida estándar.

OPCIONES

-f NOMBRE, --format NOMBRE
Especificar el formato de salida. Los valores posibles para NOMBRE son hex, HEX, hex!, HEX!, rgb, y plain. Consulte FORMATO para una explicación de las diferentes opciones de formato. Entra en conflicto con --custom.
-c FORMATO, --custom FORMATO
Especificar una plantilla para el formato de salida personalizado. Consulte FORMATO PERSONALIZADO para una explicación de la sintaxis de la plantilla. Entra en conflicto con --format.
-s [SELECCIÓN], --selection [SELECCIÓN]
Guardar la salida en la selección de X11. Los valores posibles para SELECCIÓN son clipboard, primary y secondary. Si no se proporciona SELECCIÓN, se utiliza clipboard.
-S, --scale
Escala de magnificación del selector, por defecto es 8
-P, --preview-size
Tamaño en píxeles del selector, por defecto es 255
-v, --version
Imprimir información de la versión y salir.
-h, --help
Imprimir mensaje de ayuda y salir.

FORMATO

Por defecto, los valores de color se imprimen en formato hexadecimal en minúsculas. El formato de salida se puede cambiar usando el interruptor --format NOMBRE. Los valores posibles de NOMBRE son:

hex
Hexadecimal en minúsculas (por defecto)
HEX
Hexadecimal en mayúsculas
hex!
Hexadecimal compacto en minúsculas
HEX!
Hexadecimal compacto en mayúsculas
rgb
RGB decimal
plain
Decimal con separadores de punto y coma

La forma compacta se refiere a los códigos de color CSS de tres letras especificados por el Módulo de Color CSS Nivel 3. Si el color no es expresable en forma de tres letras, se utilizará la forma regular de seis letras.

FORMATO PERSONALIZADO

El interruptor --format proporciona acceso rápido a algunas opciones de formato comúnmente utilizadas. Sin embargo, si se desea un formato de salida personalizado, esto se puede lograr usando el interruptor --custom FORMATO. El parámetro FORMATO especifica una plantilla para la salida y admite un lenguaje de plantillas simple. Las plantillas de FORMATO pueden contener expansiones especiales que se escriben dentro de bloques %{...}. Estos bloques se expandirán a valores de color según los especificadores definidos dentro del bloque. Aquí hay ejemplos de cadenas de formato válidas y lo que podrían traducir a:

Cadena de Formato Salida de Ejemplo
%{r}, %{g}, %{b} 255, 0, 100
Green: %{-4g} Green: ---7
#%{02hr}%{02hg}%{02hb} #00ff00
%{016Br} 0000000000000011

Los bloques de expansión en las cadenas de formato siempre contienen un especificador de canal (r para rojo, g para verde y b para azul). Además, pueden contener un especificador de formato numérico opcional (h para hexadecimal en minúsculas, H para hexadecimal en mayúsculas, o para octal, B para binario y d para decimal) y un especificador de relleno opcional que consiste en un carácter para usar para el relleno y la longitud que debe tener la cadena rellena. El siguiente diagrama ilustra cómo podemos usar estas reglas para decodificar una plantilla de formato:

%{016Br}
  | |||
  | ||`- Canal (rojo)
  | |`-- Especificador de formato numérico (binario)
  | `--- Longitud de relleno (16)
  `----- Carácter a usar para relleno (0)

La salida es el contenido del canal de color rojo formateado en binario y rellenado con ceros para que tenga dieciséis caracteres de longitud.

AMBIENTE

XCOLOR_FOREGROUND
Deshabilita el modo demonio. Debido a la forma en que funcionan las selecciones en X11, xcolor se bifurca en segundo plano cuando se usa el modo --selection. Este comportamiento se puede deshabilitar definiendo la variable de entorno XCOLOR_FOREGROUND.
