NOMBRE

xchm - Visor de archivos Compiled HTML Help (CHM) para X.

SINOPSIS

xchm [OPCIONES] [ARCHIVO]

DESCRIPCIÓN

xchm es un visor de archivos Compiled HTML Help (CHM). Puede mostrar el árbol de contenidos si está disponible, imprimir la página actual y realizar las típicas acciones de historial. Permite cambiar fuentes y buscar texto en todas las páginas del archivo, o en los títulos de las páginas.

xchm no maneja Javascript en el libro.

OPCIONES

-c, --contextid=<num>
ID de contexto para abrir en el archivo, requiere que se especifique un archivo.
-h, --help
Muestra el mensaje de ayuda y sale.
