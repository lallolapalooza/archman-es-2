XCAPE(1) Manual de xcape XCAPE(1)

NOMBRE

xcape - usar una tecla modificadora como otra tecla

SINOPSIS

xcape [-d] [-t tiempo_espera] [-e expresion_mapeo]

DESCRIPCIÓN

xcape permite que una tecla modificadora se utilice como otra tecla cuando se presiona y se suelta por sí sola. El comportamiento predeterminado es generar la tecla Escape en lugar de Control_L (Control izquierdo).

OPCIONES

-d
Modo de depuración. Se ejecutará como un proceso en primer plano.
-t tiempo_espera
Establece un tiempo_espera en milisegundos. Si mantienes una tecla presionada durante más tiempo que tiempo_espera, no se generará un evento de tecla.
-e expresion_mapeo
Utiliza expresion_mapeo como la(s) expresión(es).

SINTAXIS DE EXPRESIÓN

La sintaxis de la expresión es ´ModKey=Key[|OtherKey]´. Se pueden pasar múltiples expresiones, delimitadas por punto y coma (;).

Una lista de claves (keysyms) se puede encontrar en el archivo de cabecera <X11/keysymdef.h> (sin el prefijo XK_).

Ten en cuenta que las teclas con mayúsculas deben especificarse como una tecla de mayúsculas seguida de la tecla que se va a presionar, en lugar del nombre real del carácter. Por ejemplo, para generar "{" se podría usar la expresión ´ModKey=Shift_L|bracketleft´ (suponiendo que tienes una tecla con ´{´ encima de ´[´).

También puedes especificar ModKey en decimal (prefijo #), octal (#0) o hexadecimal (#0x). Se interpretará como un código de tecla (keycode) a menos que no se encuentre ningún nombre de tecla correspondiente.

EJEMPLOS

Hacer que la tecla Shift izquierda genere Escape cuando se presiona y suelta por sí sola, y que la tecla Control izquierda genere la combinación Ctrl-O cuando se presiona y suelta por sí sola:

xcape -e 'Shift_L=Escape;Control_L=Control_L|O'

En conjugación con xmodmap, es posible hacer que una tecla ordinaria actúe como un modificador adicional. Primero, mapea la tecla al modificador con xmodmap y luego el modificador de vuelta a la tecla con xcape. Como ejemplo, podemos hacer que la barra espaciadora funcione como una tecla de control adicional cuando se mantiene presionada con la siguiente secuencia de comandos:

Primero, mapea un keysym de modificador no utilizado al código de tecla de la barra espaciadora y haz que sea un modificador de control. Debe ser una tecla existente para que emacs no se vuelva loco cuando la presiones. Hyper_L es un buen candidato.

spare_modifier="Hyper_L"
xmodmap -e "keycode 65 = $spare_modifier"
xmodmap -e "remove mod4 = $spare_modifier"
# hyper_l es mod4 por defecto
xmodmap -e "add Control = $spare_modifier"

A continuación, mapea el espacio a un código de tecla no utilizado (para mantenerlo disponible para que xcape lo use).

xmodmap -e "keycode any = space"

Finalmente, usa xcape para hacer que la barra espaciadora genere un espacio cuando se pulsa.

xcape -e "$spare_modifier=space"
