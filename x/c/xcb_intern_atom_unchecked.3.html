NOMBRE

xcb_intern_atom - Obtener identificador de átomo por nombre

SINOPSIS

#include <xcb/xproto.h>

Función de solicitud

xcb_intern_atom_cookie_t xcb_intern_atom(xcb_connection_t *conn, uint8_t only_if_exists, uint16_t name_len, const char *name);

Estructura de respuesta

typedef struct xcb_intern_atom_reply_t {
    uint8_t    response_type;
    uint8_t    pad0;
    uint16_t   sequence;
    uint32_t   length;
    xcb_atom_t atom;
} xcb_intern_atom_reply_t;

Función de respuesta

xcb_intern_atom_reply_t *xcb_intern_atom_reply(xcb_connection_t *conn, xcb_intern_atom_cookie_t cookie, xcb_generic_error_t **e);

ARGUMENTOS DE SOLICITUD

conn
La conexión XCB a X11.
only_if_exists
Devuelve un ID de átomo válido solo si el átomo ya existe.
name_len
La longitud del siguiente name.
name
El nombre del átomo.

CAMPOS DE RESPUESTA

response_type
El tipo de esta respuesta, en este caso XCB_INTERN_ATOM. Este campo también está presente en xcb_generic_reply_t y se puede usar para distinguir respuestas entre sí.
sequence
El número de secuencia de la última solicitud procesada por el servidor X11.
length
La longitud de la respuesta, en palabras (una palabra es de 4 bytes).
atom

DESCRIPCIÓN

Recupera el identificador (xcb_atom_t TODO) para el átomo con el nombre especificado. Los átomos se utilizan en protocolos como EWMH, por ejemplo, para almacenar títulos de ventanas (átomo _NET_WM_NAME) como propiedad de una ventana.

Si only_if_exists es 0, el átomo se creará si no existe ya. Si only_if_exists es 1, se devolverá XCB_ATOM_NONE si el átomo aún no existe.

VALOR DE RETORNO

Devuelve una xcb_intern_atom_cookie_t. Los errores deben manejarse al llamar a la función de respuesta xcb_intern_atom_reply.

Si desea manejar los errores en el bucle de eventos en su lugar, use xcb_intern_atom_unchecked. Consulte xcb-requests(3) para obtener más detalles.

EJEMPLO

/*
 * Resuelve el átomo _NET_WM_NAME.
 *
 */
void my_example(xcb_connection_t *c) {
    xcb_intern_atom_cookie_t cookie;
    xcb_intern_atom_reply_t *reply;
    cookie = xcb_intern_atom(c, 0, strlen("_NET_WM_NAME"), "_NET_WM_NAME");
    /* ... haz otro trabajo aquí si es posible ... */
    if ((reply = xcb_intern_atom_reply(c, cookie, NULL))) {
        printf("El átomo _NET_WM_NAME tiene el ID %u0, reply->atom);
        free(reply);
    }
}
