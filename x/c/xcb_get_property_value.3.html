NOMBRE

xcb_get_property - Obtiene una propiedad de ventana

SINOPSIS

#include <xcb/xproto.h>

Función de solicitud

xcb_get_property_cookie_t xcb_get_property(xcb_connection_t *conn, uint8_t _delete, xcb_window_t window, xcb_atom_t property, xcb_atom_t type, uint32_t long_offset, uint32_t long_length);

Estructura de respuesta

typedef struct xcb_get_property_reply_t {
    uint8_t    response_type;
    uint8_t    format;
    uint16_t   sequence;
    uint32_t   length;
    xcb_atom_t type;
    uint32_t   bytes_after;
    uint32_t   value_len;
    uint8_t    pad0[12];
} xcb_get_property_reply_t;

Función de respuesta

xcb_get_property_reply_t *xcb_get_property_reply(xcb_connection_t *conn, xcb_get_property_cookie_t cookie, xcb_generic_error_t **e);

Accesorios de respuesta

void *xcb_get_property_value(const xcb_get_property_request_t *reply);

int xcb_get_property_value_length(const xcb_get_property_reply_t *reply);

xcb_generic_iterator_t xcb_get_property_value_end(const xcb_get_property_reply_t *reply);

ARGUMENTOS DE SOLICITUD

conn
La conexión XCB a X11.
_delete
Si la propiedad debe eliminarse realmente. Para eliminar una propiedad, el type especificado debe coincidir con el tipo de propiedad real.
window
La ventana cuya propiedad quieres obtener.
property
La propiedad que quieres obtener (un átomo).
type
El tipo de la propiedad que quieres obtener (un átomo).
long_offset
Especifica el desplazamiento (en múltiplos de 32 bits) en la propiedad especificada desde donde se deben recuperar los datos.
long_length
Especifica cuántos múltiplos de 32 bits de datos se deben recuperar (por ejemplo, si estableces long_length en 4, recibirás 16 bytes de datos).

CAMPOS DE RESPUESTA

response_type
El tipo de esta respuesta, en este caso XCB_GET_PROPERTY. Este campo también está presente en xcb_generic_reply_t y se puede usar para distinguir las respuestas entre sí.
sequence
El número de secuencia de la última solicitud procesada por el servidor X11.
length
La longitud de la respuesta, en palabras (una palabra son 4 bytes).
format
Especifica si los datos deben verse como una lista de cantidades de 8, 16 o 32 bits. Los valores posibles son 8, 16 y 32. Esta información permite al servidor X realizar correctamente las operaciones de intercambio de bytes según sea necesario.
type
El tipo real de la propiedad (un átomo).
bytes_after
El número de bytes restantes para leer en la propiedad si se realizó una lectura parcial.
value_len
La longitud del valor. Debes usar el accesorio correspondiente en lugar de este campo.

DESCRIPCIÓN

Obtiene la property especificada de la window especificada. Las propiedades son, por ejemplo, el título de la ventana (WM_NAME) o su tamaño mínimo (WM_NORMAL_HINTS). Protocolos como EWMH también usan propiedades; por ejemplo, EWMH define el título de la ventana, codificado como una cadena UTF-8, en la propiedad _NET_WM_NAME.

VALOR DE RETORNO

Devuelve una xcb_get_property_cookie_t. Los errores deben manejarse al llamar a la función de respuesta xcb_get_property_reply.

Si prefieres manejar los errores en el bucle de eventos, usa xcb_get_property_unchecked. Consulta xcb-requests(3) para obtener más detalles.

ERRORES

xcb_atom_error_t
property o type no se refieren a un átomo válido.
xcb_value_error_t
El long_offset especificado está más allá de la longitud real de la propiedad (por ejemplo, la propiedad tiene una longitud de 3 bytes y estableces long_offset en 1, lo que resulta en un desplazamiento de byte de 4).
xcb_window_error_t
La window especificada no existe.

EJEMPLO

/*
 * Imprime la propiedad WM_NAME de la ventana.
 *
 */
void my_example(xcb_connection_t *c, xcb_window_t window) {
    xcb_get_property_cookie_t cookie;
    xcb_get_property_reply_t *reply;
    /* Estos átomos están predefinidos en el protocolo X11. */
    xcb_atom_t property = XCB_ATOM_WM_NAME;
    xcb_atom_t type = XCB_ATOM_STRING;
    // TODO: ¿un long_length razonable para WM_NAME?
    cookie = xcb_get_property(c, 0, window, property, type, 0, 0);
    if ((reply = xcb_get_property_reply(c, cookie, NULL))) {
        int len = xcb_get_property_value_length(reply);
        if (len == 0) {
            printf("TODO\n");
            free(reply);
            return;
        }
        printf("WM_NAME es %.*s\n", len,
               (char*)xcb_get_property_value(reply));
    }
    free(reply);
}

    GET PROPERTY VALUE

    DESCRIPTION

    Retrieves the property value of a window.

    REQUEST ARGUMENTS

    This request does not take any arguments.

    REPLY FIELDS

    The following fields are available in the reply:

    • format: The format of the property.
    • type: The atom specifying the type of the property.
    • length: The length of the property in items.
    • value: The value of the property.

    RETURN VALUE

    Returns a pointer to a xcb_get_property_value_reply_t structure on success, or NULL on failure.

    ERRORS

    Possible errors:

    • xcb_generic_error_t: If the property does not exist or the request is invalid.

    EXAMPLE

    
int
main (void)
{
    xcb_connection_t    *c;
    xcb_get_property_reply_t *reply;
    int                  screen;

    c = xcb_connect (NULL, &screen);
    if (xcb_connection_has_error (c)) {
        fprintf (stderr, "Cannot open display\n");
        return 1;
    }

    /* Get the root window */
    xcb_window_t root = xcb_setup_roots_iterator (xcb_get_setup (c)).data->root;

    /* Get the _NET_WM_NAME property */
    xcb_intern_atom_cookie_t cookie;
    cookie = xcb_intern_atom (c, 1, 11, "_NET_WM_NAME");
    xcb_intern_atom_reply_t *reply_atom = xcb_intern_atom_reply (c, cookie, NULL);

    if (!reply_atom) {
        fprintf (stderr, "Cannot get atom for _NET_WM_NAME\n");
        xcb_disconnect (c);
        return 1;
    }

    xcb_get_property_cookie_t prop_cookie;
    prop_cookie = xcb_get_property (c, 0, root, reply_atom->atom, XCB_ATOM_STRING, 0, ~0);

    reply = xcb_get_property_reply (c, prop_cookie, NULL);

    if (!reply) {
        fprintf (stderr, "Cannot get property\n");
        free (reply_atom);
        xcb_disconnect (c);
        return 1;
    }

    if (reply->type == XCB_ATOM_STRING) {
        printf ("Window name: %.*s\n", xcb_get_property_value_length (reply), (char *) xcb_get_property_value (reply));
    } else {
        printf ("Window name is not a string\n");
    }

    free (reply);
    free (reply_atom);
    xcb_disconnect (c);
    return 0;
}
