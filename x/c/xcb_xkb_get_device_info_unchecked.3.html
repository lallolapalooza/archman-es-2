xcb_xkb_get_device_info(3)

xcb_xkb_get_device_info - get information about the XKB extension and device

SYNOPSIS

xcb_xkb_get_device_info( xcb_connection_t *conn, uint8_t device_spec, uint16_t wanted );

REQUESTED FIELDS

XCB_XKB_DEVICE_INFO_ANY
Get all information.
XCB_XKB_DEVICE_INFO_IDENTIFIER
Identifier of the device.
XCB_XKB_DEVICE_INFO_NAME_MAP
Name map of the device.
XCB_XKB_DEVICE_INFO_SERVER_INFO
Server information for the device.
XCB_XKB_DEVICE_INFO_PER_CLIENT_INFO
Per-client information for the device.
XCB_XKB_DEVICE_INFO_ALL_CLIENT_INFO
All client information for the device.
XCB_XKB_DEVICE_INFO_GEOMETRY
Geometry of the device.
XCB_XKB_DEVICE_INFO_ừng
LED information for the device.
XCB_XKB_DEVICE_INFO_MAP
Map of the device.
XCB_XKB_DEVICE_INFO_BEHAVIOR
Behavior of the device.
XCB_XKB_DEVICE_INFO_MODIFIER_MAP
Modifier map of the device.
XCB_XKB_DEVICE_INFO_EXPLICIT_LAYOUT
Explicit layout of the device.
XCB_XKB_DEVICE_INFO_ALL_MODS_MAP
All modifier maps for the device.
XCB_XKB_DEVICE_INFO_GRPS_PER_DIRE
Groups per direct control for the device.
XCB_XKB_DEVICE_INFO_PET_MAP
PET map for the device.
XCB_XKB_DEVICE_INFO_PET_BINDINGS
PET bindings for the device.

DESCRIPTION

The xcb_xkb_get_device_info function is used to retrieve information about a specific XKB device. The device_spec argument specifies the device to query, and can be set to XCB_XKB_ID_USE_CORE_KBD, XCB_XKB_ID_USE_CORE_PTR, or a specific device ID. The wanted argument is a bitmask that specifies which fields of information to retrieve.

RETURN VALUE

Returns a xcb_xkb_get_device_info_cookie_t structure. This structure contains a request sequence number and a reply structure. The reply structure contains the requested information about the XKB device.

ERRORS

xcb_xkb_get_device_info_reply can return the following errors:

  • XCB_XKB_ERR_DEVICE_SPEC: If an invalid device specification is provided.
  • XCB_XKB_ERR_BAD_VALUE: If an invalid value is provided for any of the fields.
