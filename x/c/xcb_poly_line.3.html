xcb_poly_line(3) Solicitudes de XCB xcb_poly_line(3)

NOMBRE

xcb_poly_line - dibujar líneas

SINOPSIS

#include <xcb/xproto.h>

Función de solicitud

xcb_void_cookie_t xcb_poly_line(xcb_connection_t *conn, uint8_t coordinate_mode, xcb_drawable_t drawable, xcb_gcontext_t gc, uint32_t points_len, const xcb_point_t *points);

ARGUMENTOS DE LA SOLICITUD

conn
La conexión XCB a X11.
coordinate_mode
Uno de los siguientes valores:
XCB_COORD_MODE_ORIGIN
Trata todas las coordenadas como relativas al origen.
XCB_COORD_MODE_PREVIOUS
Trata todas las coordenadas después de la primera como relativas a la coordenada anterior.
drawable
El drawable donde dibujar la(s) línea(s).
gc
El contexto gráfico a utilizar.
points_len
El número de estructuras xcb_point_t en points.
points
Un array de puntos.

DESCRIPCIÓN

Dibuja points_len-1 líneas entre cada par de puntos (punto[i], punto[i+1]) en el array points. Las líneas se dibujan en el orden listado en el array. Se unen correctamente en todos los puntos intermedios, y si el primer y último puntos coinciden, las líneas primera y última también se unen correctamente. Para cualquier línea dada, un píxel no se dibuja más de una vez. Si las líneas delgadas (ancho de línea cero) se cruzan, los píxeles que se cruzan se dibujan varias veces. Si las líneas anchas se cruzan, los píxeles que se cruzan se dibujan solo una vez, como si toda la solicitud fuera una única forma rellena.

VALOR DE RETORNO

Devuelve una xcb_void_cookie_t. Los errores (si los hay) deben manejarse en el bucle de eventos.

Si desea manejar los errores directamente con xcb_request_check, use xcb_poly_line_checked. Consulte xcb-requests(3) para más detalles.

EJEMPLO

/*
 * Dibuja una línea recta.
 *
 */
void my_example(xcb_connection_t *conn, xcb_drawable_t drawable, xcb_gcontext_t gc) {
    xcb_poly_line(conn, XCB_COORD_MODE_ORIGIN, drawable, gc, 2,
                  (xcb_point_t[]) { {10, 10}, {100, 10} });
    xcb_flush(conn);
}
