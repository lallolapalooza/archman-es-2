Estructura de evento

typedef struct xcb_input_change_device_notify_event_t {
    uint8_t         response_type;
    uint8_t         device_id;
    uint16_t        sequence;
    xcb_timestamp_t time;
    uint8_t         request;
    uint8_t         pad0[23];
} xcb_input_change_device_notify_event_t;

CAMPOS DEL EVENTO

response_type
El tipo de este evento, en este caso XCB_INPUT_CHANGE_DEVICE_NOTIFY. Este campo también está presente en el xcb_generic_event_t y se puede usar para distinguir entre eventos.
sequence
El número de secuencia de la última solicitud procesada por el servidor X11.
