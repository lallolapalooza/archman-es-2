XCLIPBOARD(1) Manual de comandos generales XCLIPBOARD(1)

NOMBRE

xclipboard - Cliente de portapapeles X

SINOPSIS

xclipboard [ -opciondel toolkit ... ] [ -w ] [ -nw ]

DESCRIPCIÓN

El programa xclipboard se utiliza para recopilar y mostrar las selecciones de texto que se envían al CLIPBOARD por otros clientes. Se suele utilizar para guardar selecciones del CLIPBOARD para su uso posterior. Almacena cada selección del CLIPBOARD como una cadena separada, cada una de las cuales puede ser seleccionada. Cada vez que otra aplicación declara el CLIPBOARD, xclipboard transfiere el contenido de esa selección a un nuevo búfer y lo muestra en la ventana de texto. Los búferes nunca se eliminan automáticamente, por lo que querrá usar el botón de eliminar para deshacerse de elementos inútiles.

Dado que xclipboard utiliza un Widget de Texto para mostrar el contenido del portapapeles, el texto enviado al CLIPBOARD puede ser re-seleccionado para su uso en otras aplicaciones. xclipboard también responde a las solicitudes de la selección del CLIPBOARD de otros clientes enviando el contenido completo del búfer actualmente mostrado. Por lo tanto, puede usar xclipboard para mover texto de una aplicación a otra.

Una ventana de xclipboard tiene los siguientes botones en la parte superior:

quit
Cuando se pulsa este botón, xclipboard sale.
delete
Cuando se pulsa este botón, se elimina el búfer actual y se muestra el siguiente.
new
Crea un nuevo búfer sin contenido. Útil para construir manualmente una nueva selección del CLIPBOARD.
save
Muestra un cuadro de diálogo para guardar archivos. Al pulsar el botón Aceptar, se guarda el búfer actualmente mostrado en el archivo especificado en el campo de texto.
next
Muestra el siguiente búfer de la lista.
previous
Muestra el búfer anterior.

OPCIONES

El programa xclipboard acepta todas las opciones de línea de comandos estándar del X Toolkit, así como las siguientes:

-w
Esta opción indica que las líneas de texto que son demasiado largas para ser mostradas en una sola línea en el portapapeles se envolverán en las líneas siguientes.
-nw
Esta opción indica que las líneas de texto largas no se envolverán. Este es el comportamiento predeterminado.

ENVÍO/RECUPERACIÓN DE CONTENIDOS DEL PORTAPAPELES

El texto se copia al portapapeles cada vez que un cliente declara la propiedad de la selección CLIPBOARD. El texto se copia desde el portapapeles cada vez que un cliente solicita el contenido de la selección CLIPBOARD. Los ejemplos de enlaces de eventos que un usuario podría desear incluir en un archivo de configuración de recursos para usar el portapapeles son:

*VT100.Translations: #override \
        <Btn3Up>:       select-end(CLIPBOARD) \n\
        <Btn2Up>:       insert-selection(PRIMARY,CLIPBOARD) \n\
        <Btn2Down>:     ignore ()

VER TAMBIÉN

X(7), xcutsel(1), xterm(1), documentación individual del cliente para saber cómo hacer una selección y enviarla al CLIPBOARD.
