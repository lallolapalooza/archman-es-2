xcb_send_event(3) Solicitudes XCB xcb_send_event(3)

NOMBRE

xcb_send_event - enviar un evento

SINOPSIS

#include <xcb/xproto.h>

Función de solicitud

xcb_void_cookie_t xcb_send_event(xcb_connection_t *conn, uint8_t propagate, xcb_window_t destination, uint32_t event_mask, const char *event);

ARGUMENTOS DE SOLICITUD

conn
La conexión XCB a X11.
propagate
Si propagate es verdadero y ningún cliente ha seleccionado ningún evento en destination, el destino se reemplaza por el ancestro más cercano de destination para el cual algún cliente ha seleccionado un tipo en event_mask y para el cual ninguna ventana intermedia tiene ese tipo en su máscara de no propagación. Si no existe tal ventana o si la ventana es un ancestro de la ventana de foco y InputFocus fue originalmente especificado como destino, el evento no se envía a ningún cliente. De lo contrario, el evento se informa a cada cliente que selecciona en el destino final cualquiera de los tipos especificados en event_mask.
destination
La ventana a la que se enviará este evento. Cada cliente que selecciona cualquier evento dentro de event_mask en destination recibirá el evento.

El valor especial XCB_SEND_EVENT_DEST_POINTER_WINDOW se refiere a la ventana que contiene el puntero del ratón.

El valor especial XCB_SEND_EVENT_DEST_ITEM_FOCUS se refiere a la ventana que tiene el foco del teclado.

event_mask
Máscara de eventos para determinar qué clientes deben recibir el evento especificado. Ver destination y propagate.
event
El evento a enviar al destination especificado.

DESCRIPCIÓN

Identifica la ventana de destination, determina qué clientes deben recibir el evento especificado e ignora cualquier captura activa.

El event debe ser uno de los eventos principales o un evento definido por una extensión, para que el servidor X pueda intercambiar los bytes correctamente según sea necesario. El contenido de event se mantiene sin cambios y sin verificar, excepto por el campo send_event que se fuerza a 'true'.

VALOR DE RETORNO

Devuelve una xcb_void_cookie_t. Los errores (si los hay) deben gestionarse en el bucle de eventos.

Si desea gestionar los errores directamente con xcb_request_check en su lugar, utilice xcb_send_event_checked. Consulte xcb-requests(3) para obtener detalles.

ERRORES

xcb_value_error_t
El event proporcionado no es un evento principal ni un evento definido por una extensión.
xcb_window_error_t
La ventana de destination especificada no existe.

EJEMPLO

/*
 * Informar a la ventana dada que fue configurada a un tamaño de 800x600 píxeles.
 *
 */
void my_example(xcb_connection_t *conn, xcb_window_t window) {
    /* Cada evento de X11 tiene 32 bytes de longitud. Por lo tanto, XCB copiará 32
     * bytes. Para inicializar correctamente estos bytes, asignamos 32 bytes
     * aunque solo necesitemos menos para un xcb_configure_notify_event_t */
    xcb_configure_notify_event_t *event = calloc(32, 1);
    event->event = window;
    event->window = window;
    event->response_type = XCB_CONFIGURE_NOTIFY;
    event->x = 0;
    event->y = 0;
    event->width = 800;
    event->height = 600;
    event->border_width = 0;
    event->above_sibling = XCB_NONE;
    event->override_redirect = false;
    xcb_send_event(conn, false, window, XCB_EVENT_MASK_STRUCTURE_NOTIFY,
                   (char*)event);
    xcb_flush(conn);
    free(event);
}
