typedef struct xcb_selection_request_event_t {
    uint8_t         response_type;
    uint8_t         pad0;
    uint16_t        sequence;
    xcb_timestamp_t time;
    xcb_window_t    owner;

CAMPOS DEL EVENTO

response_type
El tipo de este evento, en este caso XCB_SELECTION_REQUEST. Este campo también está presente en xcb_generic_event_t y se puede utilizar para diferenciar eventos entre sí.
sequence
El número de secuencia de la última solicitud procesada por el servidor X11.
