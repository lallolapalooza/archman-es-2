NOMBRE

xcb_list_fonts_with_info - obtener nombres e información de fuentes coincidentes

SINOPSIS

#include <xcb/xproto.h>

ARGUMENTOS DE LA SOLICITUD

conn
La conexión XCB a X11.
max_names
El número máximo de fuentes a devolver.
pattern_len
La longitud (en bytes) de pattern.
pattern
Un patrón de fuente, por ejemplo "-misc-fixed-*".

El asterisco (*) es un comodín para cualquier número de caracteres. El signo de interrogación (?) es un comodín para un solo carácter. El uso de mayúsculas o minúsculas no importa.

sequence
El número de secuencia de la última solicitud procesada por el servidor X11.
length
La longitud de la respuesta, en palabras (una palabra son 4 bytes).
name_len

replies_hint
Una indicación de cuántas fuentes más se devolverán. Esto es solo una pista y puede ser mayor o menor que el número de fuentes realmente devueltas. Un valor cero no garantiza que no se devolverán más fuentes.

DESCRIPCIÓN

Obtiene una lista de nombres de fuentes disponibles que coinciden con el pattern dado.

VALOR DE RETORNO

Devuelve una xcb_list_fonts_with_info_cookie_t. Los errores deben gestionarse al llamar a la función de respuesta xcb_list_fonts_with_info_reply.

Si desea gestionar los errores en el bucle de eventos en su lugar, utilice xcb_list_fonts_with_info_unchecked. Consulte xcb-requests(3) para obtener detalles.

ERRORES

Esta solicitud nunca genera errores.

xcb_list_fonts_with_info_properties_iterator - iterate over Reply

NAME

xcb_list_fonts_with_info_properties_iterator - iterate over Reply

SYNOPSIS

#include <xcb/render.h>

xcb_list_fonts_with_info_properties_iterator_t
xcb_list_fonts_with_info_properties_iterator (xcb_list_fonts_with_info_reply_t *reply);

REQUEST ARGUMENTS

reply The Reply structure whose contents will be iterated.

REPLY FIELDS

DESCRIPTION

This function is used to iterate over the Reply data structure for the xcb_list_fonts_with_info request. The structure of the Reply is as follows: 

typedef struct {
    uint8_t                             response_type;
    uint8_t                             nfonts;
    uint16_t                            sequence;
    uint32_t                            length;
    xcb_font_properties_iterator_t      properties_iterator;
    xcb_glyphset_t                      glyphset;
    uint8_t                             drawas;
    uint8_t                             num_properties;
    uint8_t                             min_bounds[2];
    uint8_t                             max_bounds[2];
    uint8_t                             avg_bounds[2];
    uint8_t                             properties_n_bytes;
    uint8_t                             pad0[2];
} xcb_list_fonts_with_info_reply_t;

The xcb_list_fonts_with_info_properties_iterator function returns an iterator structure that can be used to traverse the list of font properties. The iterator has the following fields: 

typedef struct {
    xcb_font_properties_t           *data;
    int                              rem;
    int                              index;
} xcb_list_fonts_with_info_properties_iterator_t;

- data: A pointer to the start of the font properties data. - rem: The number of font properties remaining to be iterated. - index: The current index of the font property being iterated.

To use the iterator, you would typically do the following: 

xcb_list_fonts_with_info_reply_t *reply = xcb_list_fonts_with_info_reply(c, cookie);
xcb_list_fonts_with_info_properties_iterator_t iter = xcb_list_fonts_with_info_properties_iterator(reply);
while (iter.rem) {
    // Access the current font property using iter.data
    // Increment the iterator to move to the next font property
    xcb_list_fonts_with_info_properties_next(&iter);
}

RETURN VALUE

Returns an xcb_list_fonts_with_info_properties_iterator_t structure that can be used to iterate over the font properties.
