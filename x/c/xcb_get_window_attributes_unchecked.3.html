NAME

xcb_get_window_attributes, xcb_get_window_attributes_unchecked, xcb_get_window_attributes_reply - get the attributes for the specified window

DESCRIPTION

Obtiene los atributos actuales para la window especificada.

RETURN VALUE

Devuelve una xcb_get_window_attributes_cookie_t. Los errores deben manejarse al llamar a la función de respuesta xcb_get_window_attributes_reply.

Si desea manejar los errores en el bucle de eventos en su lugar, use xcb_get_window_attributes_unchecked. Consulte xcb-requests(3) para más detalles.
