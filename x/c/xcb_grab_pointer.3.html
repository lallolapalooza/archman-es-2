NOMBRE

xcb_grab_pointer - Capturar el puntero

SINÓPSIS

#include <xcb/xproto.h>

Función de solicitud

xcb_grab_pointer_cookie_t xcb_grab_pointer(xcb_connection_t *conn, uint8_t owner_events, xcb_window_t grab_window, uint16_t event_mask, uint8_t pointer_mode, uint8_t keyboard_mode, xcb_window_t confine_to, xcb_cursor_t cursor, xcb_timestamp_t time);

Estructura de datos de respuesta

typedef struct xcb_grab_pointer_reply_t {
    uint8_t  response_type;
    uint8_t  status;
    uint16_t sequence;
    uint32_t length;
} xcb_grab_pointer_reply_t;

Función de respuesta

xcb_grab_pointer_reply_t *xcb_grab_pointer_reply(xcb_connection_t *conn, xcb_grab_pointer_cookie_t cookie, xcb_generic_error_t **e);

ARGUMENTOS DE SOLICITUD

conn
La conexión XCB a X11.
owner_events
Si es 1, la grab_window aún recibirá los eventos del puntero. Si es 0, los eventos no se informan a la grab_window.
grab_window
Especifica la ventana en la que se debe capturar el puntero.
event_mask
Especifica qué eventos del puntero se informan al cliente.

pointer_mode
Uno de los siguientes valores:
XCB_GRAB_MODE_SYNC
El estado del teclado parece congelarse: el servidor no genera más eventos de teclado hasta que el cliente que captura emite una solicitud AllowEvents de liberación o hasta que se libera la captura del teclado.
XCB_GRAB_MODE_ASYNC
El procesamiento de eventos del teclado continúa normalmente.
keyboard_mode
Uno de los siguientes valores:
XCB_GRAB_MODE_SYNC
El estado del teclado parece congelarse: el servidor no genera más eventos de teclado hasta que el cliente que captura emite una solicitud AllowEvents de liberación o hasta que se libera la captura del teclado.
XCB_GRAB_MODE_ASYNC
El procesamiento de eventos del teclado continúa normalmente.
confine_to
Especifica la ventana en la que confinar el puntero (el usuario no podrá mover el puntero fuera de esa ventana).

El valor especial XCB_NONE significa no confinar el puntero.

cursor
Especifica el cursor que se debe mostrar o XCB_NONE para no cambiar el cursor.
time
El argumento de tiempo permite evitar ciertas circunstancias que surgen si las aplicaciones tardan mucho en responder o si hay retrasos de red prolongados. Considere una situación en la que tiene dos aplicaciones, ambas de las cuales normalmente capturan el puntero al hacer clic. Si ambas aplicaciones especifican la marca de tiempo del evento, la segunda aplicación puede activarse más rápido y capturar el puntero con éxito antes de que la primera aplicación lo haga. La primera aplicación, entonces, recibirá una indicación de que la otra aplicación capturó el puntero antes de que se procesara su solicitud.

El valor especial XCB_CURRENT_TIME será reemplazado por la hora actual del servidor.

El tipo de esta respuesta, en este caso XCB_GRAB_POINTER. Este campo también está presente en el xcb_generic_reply_t y puede usarse para distinguir las respuestas entre sí.
sequence
El número de secuencia de la última solicitud procesada por el servidor X11.
length
La longitud de la respuesta, en palabras (una palabra son 4 bytes).

DESCRIPCIÓN

Captura activamente el control del puntero. Los eventos posteriores del puntero solo se informan al cliente que captura. Anula cualquier captura activa del puntero realizada por este cliente.

VALOR DE RETORNO

Devuelve una xcb_grab_pointer_cookie_t. Los errores deben manejarse al llamar a la función de respuesta xcb_grab_pointer_reply.

Si desea manejar los errores en el bucle de eventos en su lugar, use xcb_grab_pointer_unchecked. Consulte xcb-requests(3) para obtener detalles.

EJEMPLO

/*
 * Captura el puntero activamente
 *
 */
void my_example(xcb_connection_t *conn, xcb_screen_t *screen, xcb_cursor_t cursor) {
    xcb_grab_pointer_cookie_t cookie;
    xcb_grab_pointer_reply_t *reply;
    cookie = xcb_grab_pointer(
        conn,
        false,               /* obtener todos los eventos del puntero especificados por la siguiente máscara */
        screen->root,        /* capturar la ventana raíz */
        XCB_NONE,            /* qué eventos dejar pasar */
        XCB_GRAB_MODE_ASYNC, /* los eventos del puntero deben continuar como normal */
        XCB_GRAB_MODE_ASYNC, /* modo del teclado */
        XCB_NONE,            /* confine_to = en qué ventana debe permanecer el cursor */
        cursor,              /* cambiamos el cursor a lo que el usuario deseaba */
        XCB_CURRENT_TIME
    );
    if ((reply = xcb_grab_pointer_reply(conn, cookie, NULL))) {
        if (reply->status == XCB_GRAB_STATUS_SUCCESS)
            printf("puntero capturado exitosamente\n");
        free(reply);
    }
}
