X11PERFCOMP(1) Manual de comandos generales X11PERFCOMP(1)

NOMBRE

x11perfcomp - programa de comparación de rendimiento del servidor X11

SINTAXIS

x11perfcomp [ -r | -ro ] [ -l archivo_etiquetas ] archivos

DESCRIPCIÓN

El programa x11perfcomp combina la salida de varias ejecuciones de x11perf(1) en un formato tabular agradable. Toma los resultados de cada archivo, rellena los resultados de pruebas faltantes si es necesario, y para cada prueba muestra la tasa de objetos/segundo de cada servidor. Si se invoca con las opciones -r o -ro, muestra el rendimiento relativo de cada servidor con respecto al primer servidor.

Normalmente, x11perfcomp utiliza el primer archivo especificado para determinar qué pruebas específicas debe informar. Algunos servidores (no los de DEC :) pueden fallar al realizar todas las pruebas. En este caso, x11perfcomp sustituye automáticamente una tasa de 0.0 objetos/segundo. Dado que el primer archivo determina qué pruebas se informan, este archivo debe contener un superconjunto de las pruebas que se informan en los otros archivos, de lo contrario, x11perfcomp fallará.

Puede proporcionar una lista explícita de pruebas para informar utilizando la opción -l para especificar un archivo de etiquetas. Puede crear un archivo de etiquetas utilizando la opción -label en x11perf.

OPCIONES

x11perfcomp acepta las opciones que se enumeran a continuación:

-r
Especifica que la salida también debe incluir el rendimiento relativo del servidor.
-ro
Especifica que la salida solo debe incluir el rendimiento relativo del servidor.
-l archivo_etiquetas
Especifica un archivo de etiquetas a utilizar.

VALORES PREDETERMINADOS X

Este programa no utiliza valores predeterminados de X.

VER TAMBIÉN

X(7), x11perf(1)
