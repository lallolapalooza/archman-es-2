NOMBRE

x11-ssh-askpass — un diálogo de frase de contraseña basado en X11 para usar con OpenSSH

SINOPSIS

x11-ssh-askpass [opciones] [etiqueta]

DESCRIPCIÓN

x11-ssh-askpass es un diálogo de frase de contraseña basado en X11 para usar con OpenSSH. Está destinado a ser llamado desde el programa ssh-add(1) y no invocado directamente.

x11-ssh-askpass soporta la mayoría de los argumentos de línea de comandos estándar del Toolkit, con la excepción de -geometry, -borderwidth, -iconic, -rv, y -title. Ver X(1).

Si se proporciona exactamente un argumento no opcional en la línea de comandos, se muestra en el diálogo en lugar de la etiqueta predeterminada. Si el argumento contiene caracteres de nueva línea ('\n'), cada línea de texto se muestra en una línea separada en el diálogo.

Las características de x11-ssh-askpass son las siguientes:

  • Configurable a través de los mecanismos de recursos X estándar /usr/X11R6/lib/X11/app-defaults, ~/.Xdefaults, xrdb(1), etc.
  • Requiere solo bibliotecas X11 estándar (libXt, libX11, libSM, libICE).
  • Puede configurarse para capturar el teclado y/o el puntero (captura el teclado por defecto, no el puntero).

La interfaz de usuario es algo diferente a la mayoría de los diálogos de contraseña/frase de contraseña y más similar al diálogo de frase de contraseña basado en X11 que acompaña a la distribución SSH regular. En lugar de un campo de texto que se llena con asteriscos o algún otro carácter a medida que el usuario ingresa la frase de contraseña, una serie de áreas similares a LED se iluminan una por una con cada carácter de la frase de contraseña ingresado, comenzando desde el borde izquierdo del diálogo. Cuando llegan al borde derecho, se apagan una por una nuevamente, y así sucesivamente. Esto le da al usuario retroalimentación de que se han ingresado caracteres de la frase de contraseña, pero no proporciona a los observadores una pista sobre la longitud de la frase de contraseña.

Al presionar el botón ‘OK’ se acepta la frase de contraseña (incluso si está vacía), que se imprime en la salida estándar, y el diálogo se cierra con un estado de cero (éxito). Al presionar el botón ‘Cancelar’ se descarta la frase de contraseña y el diálogo se cierra con un estado distinto de cero.

Las siguientes pulsaciones de teclas funcionan como se espera:

[Suprimir]
Borrar carácter anterior
[Control+U]

[Intro]

Aceptar frase de contraseña (OK)

Descartar frase de contraseña (Cancelar)

NAME

x11-ssh-askpass - Ask for SSH passphrase

SYNOPSIS

x11-ssh-askpass

DESCRIPTION

The x11-ssh-askpass program is a graphical dialog box which asks the user for a passphrase. It is typically invoked by ssh(1) when it needs a passphrase to unlock a private key and the SSH_ASKPASS environment variable is set to /usr/bin/x11-ssh-askpass.

WIDGETS

The following widgets are used in the dialog:

Dialog
The main dialog box that contains the other widgets.
Title
The title of the dialog box, which is normally the application name (e.g. ssh).
Label
A text label that prompts the user for the passphrase.
TextField
The text entry field where the user types the passphrase. This field is usually set to obscure the input.
active_leds
A set of three small ssh-askpass(1x) leds that indicate the status of the input. They are all lit when the passphrase is entered. Only the left led is lit when the passphrase is empty.
inactive_leds
A set of three small ssh-askpass(1x) leds that indicate the status of the input. They are normally not lit.
Button
The button widget that the user presses to confirm the passphrase entry.

RESOURCES

The following resources are recognized by the Dialog widget:

width
The width of the dialog in pixels. Default is 300 pixels.
height
The height of the dialog in pixels. Default is 100 pixels.
title (class Title)
The title of the application as specified to the window manager.
label (class Label)
The label displayed above the led indicators.
font (class Font)
The font to be used to display the label.

The following Resources are recognized by the dialog, button, and indicator widgets and the main widget to customize the 3D appearance (all measurements are in pixels):

foreground (class Foreground)
The foreground color of the widget. This is the text color of the label for buttons and dialog and the color of the active led for the indicator.
background (class Background)
The background color of the widget. In the case of the indicator this is the color of the inactive led.
topShadowColor (class TopShadowColor)
The color used by the sides of the widget exposed to the light (top and left).
bottomShadowColor (class BottomShadowColor)
The color used by the sides of the widget in the shadow (right and bottom).
shadowThickness (class ShadowTickness)
The thickness of the 3D border of the widget.
borderColor (class BorderColor)
The color of the border around the widget.
borderWidth (class BorderWidth)
The width of the border around the widget.
horizontalSpacing (class HorizontalSpacing)
The space to leave on left and right sides of the widget.
verticalSpacing (class VerticalSpacing)
The space to leave on top and bottom sides of the widget.

The following resources are recognized by the indicator widgets:

minimumCount (class MinimumCount)
The minimum number of indicators to display in the dialog.
maximumCount (class MaximumCount)
The maximum number of indicators to display in the dialog.

Each button uses the following resources to customize its label:

label (class Label)
the string to display on the button.
font (class Font)
the font to use for this button label.
