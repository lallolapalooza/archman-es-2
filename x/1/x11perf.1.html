NOMBRE

x11perf - programa de prueba de rendimiento de X11

SINTAXIS

x11perf [ -opcion ... ]

DESCRIPCIÓN

El programa x11perf ejecuta una o más pruebas de rendimiento e informa de la rapidez con la que un servidor X puede ejecutar las pruebas.

Muchos puntos de referencia gráficos asumen que el dispositivo gráfico se utiliza para mostrar la salida de una única aplicación gráfica sofisticada, y que el usuario realiza su trabajo en otro dispositivo, como una terminal. Dichos puntos de referencia suelen medir la velocidad de dibujo de líneas, polígonos, texto, etc.

Dado que las estaciones de trabajo no se utilizan como motores gráficos independientes, sino como superterminales, x11perf mide el rendimiento de la gestión de ventanas, así como el rendimiento gráfico tradicional. x11perf incluye pruebas de referencia para el tiempo que se tarda en crear y mapear ventanas (como cuando se inicia una aplicación); para mapear un conjunto preexistente de ventanas en la pantalla (como cuando se desiconiza una aplicación o se muestra un menú); y para reorganizar ventanas (como cuando se mueven ventanas de un lado a otro tratando de encontrar la que se desea).

x11perf también mide el rendimiento gráfico para operaciones que normalmente no se utilizan en pantallas gráficas independientes, pero que sin embargo son utilizadas frecuentemente por aplicaciones X. Dichas operaciones incluyen CopyPlane (utilizada para mapear mapas de bits en píxeles), desplazamiento (utilizado en ventanas de texto) y varios patrones y teselas (utilizados para CAD y semitonos de color, respectivamente).

x11perf debe utilizarse para analizar los puntos fuertes y débiles particulares de los servidores, y es más útil para un escritor de servidores que desea analizar y mejorar un servidor. x11perf está destinado a ejercitar de forma exhaustiva casi todas las operaciones de X11 que se pueden realizar; no pretende ser una muestra representativa de las operaciones que las aplicaciones X11 utilizan realmente. Aunque se puede utilizar como punto de referencia, fue escrito y está destinado a ser una herramienta de prueba de rendimiento.

Como tal, x11perf NO reduce las mediciones a un solo número de ``HeXStones'' o ``MeXops''. Consideramos que tales números son, en el mejor de los casos, poco informativos y, en el peor, engañosos. Algunos servidores que son muy rápidos para ciertas aplicaciones pueden ser muy lentos para otras. Ningún número único o un pequeño conjunto de números es suficiente para caracterizar cómo funcionará una implementación X en todas las aplicaciones. Sin embargo, conociendo su aplicación favorita, puede utilizar los números que x11perf informa para predecir su rendimiento en una implementación X determinada.

Dicho esto, es posible que también desee consultar x11perfcomp(1), un programa para comparar los resultados de diferentes ejecuciones de x11perf. Usted proporciona una lista de archivos que contienen resultados de x11perf, y lo presenta en un formato tabular agradable.

Para obtener resultados repetibles, x11perf debe ejecutarse utilizando una conexión local en un servidor recién iniciado. La configuración predeterminada ejecuta cada prueba 5 veces, para ver si cada ensayo lleva aproximadamente la misma cantidad de tiempo. Deben examinarse los fallos extraños; si no son repetibles, uno podría atribuirlos a demonios y tráfico de red. Cada ensayo se ejecuta durante 5 segundos, para reducir las diferencias aleatorias de tiempo. El número de objetos procesados por segundo se muestra con 3 dígitos significativos, pero tendrá suerte en la mayoría de los sistemas UNIX si los números son realmente consistentes a 2 dígitos. x11perf mueve el cursor fuera de la ventana de prueba; debe tener cuidado de no golpear el ratón y moverlo de nuevo a la ventana. (¡¡Un premio para las personas que expliquen correctamente por qué!!).

Antes de ejecutar una prueba, x11perf determina cuál es el tiempo de ida y vuelta al servidor y lo elimina del tiempo final informado. Asegura que el servidor realmente ha realizado el trabajo solicitado al recuperar un píxel de la ventana de prueba, lo que significa que los servidores que se comunican con aceleradores gráficos no pueden afirmar que han terminado, mientras que en el ínterin el acelerador está pintando frenéticamente.

Por defecto, x11perf calibra automáticamente el número de repeticiones de cada prueba, de modo que cada una debería tardar aproximadamente la misma cantidad de tiempo en ejecutarse en servidores de velocidades muy diferentes. Sin embargo, dado que cada prueba debe ejecutarse hasta su finalización al menos una vez, algunos servidores lentos pueden tardar mucho tiempo, particularmente en las pruebas de movimiento y redimensionamiento de ventanas, y en las pruebas de dibujo de arcos.

Todos los informes de tiempo corresponden al objeto más pequeño involucrado. Por ejemplo, las pruebas de línea utilizan una solicitud PolyLine para pintar varias líneas a la vez, pero informan cuántas líneas por segundo puede pintar el servidor, no cuántas solicitudes PolyLine por segundo. Las pruebas de texto pintan una línea de caracteres, pero informan sobre el número de caracteres por segundo. Algunas pruebas de ventanas mapean, desmapean o mueven una única ventana padre, pero informan sobre cuántas ventanas secundarias por segundo puede mapear, desmapear o mover el servidor.

El programa actual es en gran parte responsabilidad de Joel McCormack. Se basa en el x11perf desarrollado por Phil Karlton, Susan Angebranndt, Chris Kent, Mary Walker y Todd Newman, que querían evaluar las diferencias de rendimiento entre varios servidores. Se añadieron varias pruebas para escribir y ajustar los servidores PMAX (DECstation 3100). Para un lanzamiento general al mundo, x11perf fue reescrito para facilitar las comparaciones entre máquinas muy diversas, para cubrir la mayoría de las funcionalidades X importantes (e irrelevantes) y para ejercitar las operaciones gráficas en tantas orientaciones y alineaciones como sea posible.

OPCIONES

x11perf se basa exclusivamente en Xlib y acepta las opciones que se enumeran a continuación:

-display host:dpy
Especifica qué pantalla usar.
-sync
Ejecuta las pruebas en modo síncrono. Normalmente solo es útil para depurar x11perf .
-pack
Ejecuta las pruebas de rectángulos de forma que los rectángulos queden justo uno al lado del otro. Esto facilita la depuración del código del servidor para patrones y teselas... si el patrón se ve feo, tienes problemas de alineación.
-repeat <n>
Repite cada prueba n veces (por defecto, cada prueba se ejecuta 5 veces).
-time <s>
Especifica cuánto tiempo en segundos se debe ejecutar cada prueba (por defecto 5 segundos).
-pause <s>
Especifica cuánto tiempo, en segundos, hacer una pausa entre cada ejecución.
-all
Ejecuta todas las pruebas. Esto puede llevar un tiempo.
-range <prueba1>[,<prueba2>]
Ejecuta todas las pruebas comenzando desde el nombre especificado prueba1 hasta el nombre prueba2, incluyendo ambas pruebas especificadas. Los nombres de prueba deben ser una de las opciones que comienzan con -dot. (ej.) -range line100 realizará las pruebas desde la prueba de línea de 100 píxeles, y continuará hasta la última prueba, -range line100,dline10 hará las pruebas de line100 a dline10.
-labels
Genera solo las etiquetas descriptivas para cada prueba especificada. Ver x11perfcomp para más detalles.
-fg color-o-píxel
Especifica el color de primer plano o valor de píxel a utilizar.
-bg color-o-píxel
Especifica el color de fondo o valor de píxel a utilizar.
-clips predeterminado
Número predeterminado de ventanas de recorte.
-ddbg color-o-píxel
Especifica el color o valor de píxel a utilizar para dibujar los segmentos impares de una línea o arco de doble guion. Esto será predeterminado al color de fondo.
-rop <rop0 rop1 ...>
Utiliza las operaciones raster especificadas (el predeterminado es GXcopy). Esta opción solo afecta a las pruebas de gráficos en las que se utiliza la función gráfica.
-pm <pm0 pm1 ...>
Utiliza las máscaras de plano especificadas (el predeterminado es ~0). Esta opción solo afecta a las pruebas de gráficos en las que se utiliza la máscara de plano.
-depth <profundidad>
Utiliza una visualización con <profundidad> planos por píxel (el predeterminado es la visualización predeterminada).
-vclass <vclass>
Utiliza una visualización con la clase especificada.

NAME

x11perf - benchmark X Window System protocol and Xlib performance

SYNOPSIS

x11perf [ options ] [ tests ]

DESCRIPTION

The x11perf utility measures the performance of X Window System protocol operations and Xlib routines. It is designed to be run against a variety of X servers, including those running locally and remotely. By default, it runs a selection of tests and prints the results to standard output.

The tests can be selected either on the command line or by using the -all option. If no tests are specified, x11perf runs a default set of tests.

General Options

-a
Run all tests. This option can be combined with the -vversion option to limit the tests to a specific version.
-c
Run all tests with the same semantics as the version specified by the -vversion option. This option can be combined with the -vversion option to limit the tests to a specific version.
-display display
Use the specified display to connect to the X server.
-vclass <vclass>
Use the specified visual class for the windows created by x11perf. <vclass> can be StaticGray, GrayScale, StaticColor, PseudoColor, TrueColor, or DirectColor. (default is the default visual).
-reps <n>
Specify the repetition count (Default is number that takes approx. 5 seconds)
-subs <s0 s1 ...>
Specify the number of sub windows to use in the Window tests. Default is 4, 16, 25, 50, 75, 100 and 200.
-v1.2
Perform only x11perf Version 1.2 tests using Version 1.2 semantics.
-v1.3
Perform only x11perf Version 1.3 tests using Version 1.3 semantics.
-v1.4
Perform only x11perf Version 1.4 tests using Version 1.4 semantics.
-v1.5
Perform only x11perf Version 1.5 tests using Version 1.5 semantics.
-v1.6
Perform only x11perf Version 1.6 tests using Version 1.6 semantics.
-v1.7
Perform only x11perf Version 1.7 tests using Version 1.7 semantics.
-version
Print program version and exit.
-su
Set the save_under window attribute to True on all windows created by x11perf. Default is False.
-bs <backing_store_hint>
Set the backing_store window attribute to the given value on all windows created by x11perf. <backing_store_hint> can be WhenMapped or Always. Default is NotUseful.
-help [ options|tests|all ]
Print information about available options and exit. If no argument is specified, or options is specified, just prints information about general options, but does not include the long list of options for running specific tests. If tests is specified, just prints the long list of options for running specific tests. If all is specified, prints information about both sets of options. If -vversion is also specified, the list of options for running specific tests will be limited to the tests for that version.
