XWUD(1) Manual de comandos generales XWUD(1)

NOMBRE

xwud - visor de imágenes para X

SINOPSIS

xwud [-in archivo] [-noclick] [-geometry geom] [-display display] [-new] [-std <tipomapa>] [-raw] [-vis <tipo-o-id-vis>] [-scale] [-help] [-rv] [-plane numero] [-fg color] [-bg color] [-dumpheader] [-version]

DESCRIPCIÓN

Xwud es una utilidad de volcados de imágenes del sistema de ventanas X. Xwud permite a los usuarios de X mostrar en una ventana una imagen guardada en un archivo de volcado formateado especialmente, como el producido por xwd(1).

OPCIONES

-bg color
Si se muestra una imagen de mapa de bits (o un solo plano de una imagen), esta opción se puede usar para especificar el color con el que se mostrarán los bits "0" de la imagen.
-display display
Esta opción le permite especificar el servidor al que conectarse; véase X(7).
-dumpheader
Esta opción imprime solo la información de la cabecera XWD. No se muestra nada.
-fg color
Si se muestra una imagen de mapa de bits (o un solo plano de una imagen), esta opción se puede usar para especificar el color con el que se mostrarán los bits "1" de la imagen.
-geometry geom
Esta opción le permite especificar el tamaño y la posición de la ventana. Normalmente, solo querrá especificar la posición y dejar que el tamaño sea el tamaño real de la imagen por defecto.
-help
Imprime una breve descripción de las opciones permitidas.
-in archivo
Esta opción permite al usuario especificar explícitamente el archivo de entrada en la línea de comandos. Si no se proporciona ningún archivo de entrada, se asume la entrada estándar.
-new
Esta opción fuerza la creación de un nuevo mapa de colores para mostrar la imagen. Si las características de la imagen coinciden con las de la pantalla, esto puede poner la imagen en pantalla más rápido, pero a costa de usar un nuevo mapa de colores (que en la mayoría de las pantallas hará que otras ventanas se vuelvan multicolores).
-noclick
Hacer clic en cualquier botón de la ventana terminará la aplicación, a menos que se especifique esta opción. La terminación siempre se puede lograr escribiendo 'q', 'Q' o Ctrl+c.
-plane numero
Puede seleccionar un único plano de bits de la imagen para mostrar con esta opción. Los planos se numeran con cero siendo el bit menos significativo.
-raw
Esta opción fuerza la visualización de la imagen con los valores de color que existan actualmente en la pantalla. Esta opción es útil principalmente cuando se descarga una imagen de vuelta a la misma pantalla de la que provino originalmente, mientras las ventanas originales todavía están en pantalla, y resulta en que la imagen se ponga en pantalla más rápido.
-rv
Si se muestra una imagen de mapa de bits (o un solo plano de una imagen), esta opción fuerza el intercambio de los colores de primer plano y fondo. Esto puede ser necesario al mostrar una imagen de mapa de bits cuyos valores de píxel "0" y "1" tienen el sentido de color invertido respecto a los de su pantalla.
-scale
Permite redimensionar la ventana y escala la imagen al tamaño de la ventana.
-std tipomapa
Esta opción hace que la imagen se muestre utilizando el Mapa de Colores Estándar especificado. El nombre de la propiedad se obtiene convirtiendo el tipo a mayúsculas, anteponiendo "RGB_" y añadiendo "_MAP". Los tipos típicos son "best", "default" y "gray". Consulte xstdcmap(1) para ver una forma de crear Mapas de Colores Estándar.
-version
Esta opción hace que xwd imprima su información de versión y salga.
-vis tipo-o-id-vis
Esta opción le permite especificar una visual o clase visual particular. El valor por defecto es elegir el "mejor". Se puede especificar una clase particular: "StaticGray", "GrayScale", "StaticColor", "PseudoColor", "DirectColor" o "TrueColor". O se puede especificar "Match", lo que significa usar la misma clase que la imagen de origen. Alternativamente, se puede especificar un id. visual exacto (específico del servidor), ya sea como número hexadecimal (precedido por "0x") o como número decimal. Finalmente, se puede especificar "default", lo que significa usar la misma clase que el mapa de colores de la ventana raíz. Las mayúsculas/minúsculas no son significativas en ninguna de estas cadenas.

AMBIENTE

DISPLAY
Para obtener la pantalla predeterminada.

ARCHIVOS

XWDFile.h
Archivo de definición del formato de archivo de volcado de X Window.

ERRORES

xwud no maneja imágenes grandes/profundas muy bien en servidores que no tienen la extensión BIG-REQUESTS.

VER TAMBIÉN

xwd(1), xstdcmap(1), X(7)
