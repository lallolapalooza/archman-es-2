XWD(1) Manual de Comandos Generales XWD(1)

NOMBRE

xwd - volcar una imagen de una ventana X

SINOPSIS

xwd [-debug] [-help] [-nobdrs] [-out archivo] [-xy] [-frame] [-add valor] [-root | -id wdid | -name wdname ] [-icmap] [-screen] [-silent] [-display host:dpy] [-version]

DESCRIPCIÓN

Xwd es una utilidad para volcar ventanas del sistema de ventanas X. Xwd permite a los usuarios de X almacenar imágenes de ventanas en un archivo de volcado con formato especial. Este archivo puede ser leído por diversas utilidades X para redibujarlo, imprimirlo, editarlo, formatearlo, archivarlo, procesar imágenes, etc. La ventana objetivo se selecciona haciendo clic con el puntero en la ventana deseada. La campana del teclado suena una vez al principio del volcado y dos veces cuando se completa el volcado.

OPCIONES

-debug
Habilita el modo de depuración.
-d, -display host:dpy
Este argumento permite especificar el servidor al que conectarse; véase X(7).
-help
Imprime el resumen de la sintaxis del comando `Usage:'
-nobdrs
Este argumento especifica que el volcado de la ventana no debe incluir los píxeles que componen el borde de la ventana X. Esto es útil en situaciones donde se puede desear incluir el contenido de la ventana en un documento como ilustración.
-out archivo
Este argumento permite al usuario especificar explícitamente el archivo de salida en la línea de comandos. Por defecto, se envía a la salida estándar.
-xy
Esta opción se aplica solo a pantallas en color. Selecciona el volcado en formato `XY' en lugar del formato `Z' por defecto.
-add valor
Esta opción especifica un valor con signo que se añadirá a cada píxel.
-frame
Esta opción indica que el marco del gestor de ventanas debe incluirse al seleccionar manualmente una ventana.
-root
Esta opción indica que se debe seleccionar la ventana raíz para el volcado de la ventana, sin requerir que el usuario seleccione una ventana con el puntero.
-id wdid
Esta opción indica que se debe seleccionar la ventana con el identificador de recurso especificado para el volcado de la ventana, sin requerir que el usuario seleccione una ventana con el puntero.
-name wdname
Esta opción indica que se debe seleccionar la ventana con la propiedad WM_NAME especificada para el volcado de la ventana, sin requerir que el usuario seleccione una ventana con el puntero.
-icmap
Normalmente se utiliza el mapa de colores de la ventana elegida para obtener valores RGB. Esta opción fuerza el uso del primer mapa de colores instalado de la pantalla en su lugar.
-screen
Esta opción indica que la solicitud GetImage utilizada para obtener la imagen debe hacerse en la ventana raíz, en lugar de directamente en la ventana especificada. De esta manera, se pueden obtener partes de otras ventanas que se superponen a la ventana especificada y, lo que es más importante, se pueden capturar menús u otros popups que son ventanas independientes pero aparecen sobre la ventana especificada.
-silent
Operar en silencio, es decir, no hacer sonar ninguna campana antes y después de volcar la ventana.
-version
Esta opción indica que xwd debe imprimir su información de versión y salir.

AMBIENTE

DISPLAY
Para obtener el host y el número de pantalla por defecto.

ARCHIVOS

XWDFile.h
Archivo de definición del formato de archivo de volcado de ventanas X.

VER TAMBIÉN

xwud(1), X(7)
