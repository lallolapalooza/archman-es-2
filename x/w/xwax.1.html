XWAX(1) Manual de Comandos Generales XWAX(1)

NOMBRE

xwax - Vinilo digital en Linux

SINOPSIS

xwax [opciones]

DESCRIPCIÓN

xwax es un software de emulación de vinilo para Linux. Permite a DJs y turntablists reproducir archivos de audio digital (MP3, Ogg Vorbis, FLAC, AAC y más), controlados mediante un par normal de tocadiscos a través de vinilos con código de tiempo.

OPCIONES

El orden de las opciones es importante. La mayoría de las opciones se aplican a las siguientes bibliotecas de música o decks, que pueden especificarse varias veces. Consulte los EJEMPLOS a continuación.

-l ruta
Escanear la biblioteca de música o la lista de reproducción en la ruta dada.
-t nombre
Utilizar el código de tiempo con nombre para los decks posteriores. Consulte -h para obtener una lista de códigos de tiempo válidos. Necesitará la señal de código de tiempo correspondiente en vinilo para controlar la reproducción.
-33
Establecer la velocidad de reproducción de referencia para los decks posteriores a 33 y un tercio de revoluciones por minuto. Este es el valor predeterminado.
-45
Establecer la velocidad de reproducción de referencia para los decks posteriores a 45 revoluciones por minuto.
-c
Proteger los decks posteriores contra ciertas operaciones durante la reproducción.
-u
Permitir todas las operaciones en un deck durante la reproducción. Esta es la inversa de la opción -c, y es el valor predeterminado.
--phono
Ajustar los umbrales de ruido de los decks posteriores para tolerar una señal a nivel de cartucho conectada a una interfaz de audio a nivel de línea. Este es un 'preamplificador de software'. A menos que su ruta de audio tenga bajo ruido, esto dará peores resultados o puede que no funcione en absoluto; siempre se prefiere un preamplificador de fono real.
--line
Establecer los umbrales de ruido de los decks posteriores a niveles de audio estándar. Esto revierte el efecto de la opción --phono, y es el valor predeterminado.
-i ruta
Utilizar el ejecutable importador dado para los decks posteriores.
-s ruta
Utilizar el ejecutable escáner dado para escanear las bibliotecas de música posteriores.
--dummy
Crear un deck que no esté conectado a ningún dispositivo de audio, utilizado para pruebas.
-k
Bloquear en RAM cualquier memoria necesaria para uso en tiempo real. Esto incluye pistas de audio mantenidas en memoria, que pueden ser grandes. Utilice ulimit -l para aumentar el límite de memoria del kernel para permitir esto.
-q n
Cambiar la prioridad en tiempo real del proceso. Una prioridad de 0 no da ninguna prioridad al proceso y se utiliza solo para pruebas.
-g [nxn][+n+n][/f]
Cambiar la geometría de la pantalla en tamaño, posición y escala (zoom) respectivamente. El tamaño y la posición se pasan a SDL, que puede utilizarlos para establecer el modo de visualización o el tamaño de una ventana X. Consulte los EJEMPLOS.
--no-decor
Solicitar al gestor de ventanas que cree una ventana 'sin bordes' que no tenga los controles habituales como barras de título y botones. Esto puede ser útil en conjunción con la opción -g para instalaciones de xwax dedicadas.
-h
Mostrar el mensaje de ayuda y los valores predeterminados.

OPCIONES DEL DISPOSITIVO ALSA

Las siguientes opciones solo están disponibles cuando xwax está compilado con soporte ALSA.

-a dispositivo
Crear un deck que utilice el dispositivo ALSA dado (por ejemplo, plughw:0).
--rate hz
Establecer la frecuencia de muestreo para los decks posteriores. El valor predeterminado es preferir 48000Hz, pero utilizar 44100Hz si no está disponible. Para mantener el mejor rendimiento, solo están disponibles las frecuencias de muestreo implementadas por el hardware.
--buffer muestras
Establecer el tamaño del búfer ALSA para los decks posteriores. Cuanto menor sea, mejor para latencias más bajas y mayor capacidad de respuesta. Si se establece demasiado bajo, se producirán fallos audibles y se informarán de subdesbordamientos en la consola.

OPCIONES DEL DISPOSITIVO JACK

Las siguientes opciones solo están disponibles cuando xwax está compilado con soporte JACK.

-j nombre
Crear un deck que se conecte a JACK y se registre bajo el nombre dado.

xwax no establece la frecuencia de muestreo para los dispositivos JACK; utiliza la frecuencia de muestreo especificada en la configuración global de JACK.

OPCIONES DEL DISPOSITIVO OSS

Las siguientes opciones solo están disponibles cuando xwax está compilado con soporte OSS.

-d ruta_archivo
Crear un deck que utilice el dispositivo OSS dado (por ejemplo, /dev/dsp).
--rate hz
Establecer la frecuencia de muestreo para los decks posteriores. El valor predeterminado para los dispositivos OSS es 48000Hz.
-b n
Establecer el número de búferes OSS para los decks posteriores.
-f n
Establecer el tamaño del búfer OSS (2^n bytes).

OPCIONES DE CONTROLADOR DE HARDWARE

Las siguientes opciones solo están disponibles cuando xwax está compilado con soporte ALSA.

--dicer dispositivo
Utilizar uno o dos controladores Dicer conectados como el dispositivo ALSA dado (por ejemplo, hw:Dicer). Consulte la sección CONTROLES NOVATION DICER para más información.

Añadir un controlador de hardware resulta en el control de los decks posteriores, hasta el límite del hardware.

CONTROLES DE TECLADO

La reproducción de cada deck (dirección, velocidad y posición) se controla a través de la señal entrante de código de tiempo de los tocadiscos. El teclado proporciona controles adicionales.

"C-" y "S-" significan que una pulsación de tecla se combina con la tecla 'Control' o 'Shift', respectivamente.

Controles de selección de discos:

flecha arriba, flecha abajo
Mover el disco resaltado hacia arriba/abajo una posición.
re Pág, Av Pág
Desplazar la lista de discos hacia arriba/abajo una página.
flecha izquierda, flecha derecha
Cambiar a la crate de discos anterior/siguiente.
tab
Alternar entre la crate actual y la crate 'Todos los discos'.
C-tab
Alternar el modo de ordenación entre: artista/nombre de la pista, BPM y orden de 'lista de reproducción'. El orden de la lista de reproducción es el orden en el que los discos fueron devueltos por el escáner.
C-S-tab
Volver a escanear la crate seleccionada actualmente.

Para filtrar la lista actual de discos, escriba una porción del nombre de un disco. Separe varias búsquedas con un espacio y use retroceso para borrar.

Controles específicos del deck:

Deck 0 Deck 1 Deck 2
F1 F5 F9 Cargar la pista actualmente seleccionada a este deck
F2 F6 F10 Restablecer el inicio de la pista a la posición actual
F3 F7 F11 Alternar el control de código de tiempo activado/desactivado
C-F3 C-F7 C-F11 Recorrer los códigos de tiempo disponibles

ALSA DEVICE OPTIONS

These options are used to select ALSA sound devices. These options are mutually exclusive.

-a device
Select an ALSA device. Examples are hw:0, hw:0,1, or plughw:1,0. See asound.conf(5) for details.
-A device
Select an ALSA device for the auxiliary input. This can be used for scratching with vinyl or CDJ. Use this if your soundcard has multiple stereo inputs.
-45
Set the specified ALSA device to 45 RPM. Only affects devices that support changing RPMs.
-S
Set the specified ALSA device to 33 RPM. Only affects devices that support changing RPMs.
-s rate
Set the sample rate for the specified ALSA device. Defaults to 44100 Hz.
--rate=rate
Set the sample rate for all subsequent ALSA devices. Defaults to 44100 Hz.
-m mixer
Select a mixer device for the specified ALSA device. See amixer(1) for details.
-c card
Select an ALSA card number.
-d device
Select an ALSA device number.

JACK DEVICE OPTIONS

-j name
Select a JACK client name. Examples are jack0, midi2jack, etc. See jackd(8) for details.

OSS DEVICE OPTIONS

-d device
Select an OSS device. Examples are /dev/dsp, /dev/dsp1, etc.

HARDWARE CONTROLLER OPTIONS

--dicer device
Select a Novation Dicer controller. The device is typically a midi device like hw:Dicer.

KEYBOARD CONTROLS

The following keys are bound to functions:

Space
Play/Pause.
Enter
Play.
Shift+Enter
Stop.
c
Cue.
z
Set Cue point.
x
Clear Cue point.
v
Jump to position.
b
Set position.
Arrow Left
Seek backwards.
Arrow Right
Seek forwards.
Ctrl+Arrow Left
Seek backwards slowly.
Ctrl+Arrow Right
Seek forwards slowly.
Bracket Left
Pitch bend down.
Bracket Right
Pitch bend up.
Shift+Bracket Left
Decrease tempo.
Shift+Bracket Right
Increase tempo.
Tab
Switch deck.
Escape
Quit.

The "available timecodes" are those which have been the subject of any -t flag on the command line.

Audio display controls:

+, -
Zoom in/out the close-up audio meters for all decks.

NOVATION DICER CONTROLS

The Novation Dicer provides hardware control of cue points. The controls are:

cue mode: dice button (1-5)
Jump to the specified cue point, or set it if unset.
loop-roll mode: dicer button (1-5)
"Punch" to the specified cue point, or set it if unset. Returns playback to normal when the button is released.
mode button + dice button (1-5)
Clear the specified cue point.

The dice buttons are lit to show that the corresponding cue point is set.

EXAMPLES

2-deck setup using one directory of music and OSS devices:

xwax -l ~/music -d /dev/dsp -d /dev/dsp1

As above, but using ALSA devices:

xwax -l ~/music -a hw:0 -a hw:1

2-deck setup using a different timecode on each deck:

xwax -l ~/music -t serato_2a -a hw:0 -t mixvibes_v2 -a hw:1

As above, but with the second deck at 45 RPM:

xwax -l ~/music -t serato_2a -a hw:0 -t mixvibes_v2 -45 -a hw:1

Default to the same timecode, but allow switching at runtime:

xwax -l ~/music -t serato_2a -t mixvibes_v2 -a hw:0 -a hw:1

3-deck setup with the third deck at a higher sample rate:

xwax -l ~/music --rate 48000 -a hw:0 -a hw:1 --rate 96000 -a hw:2

Using all three device types simultaneously, one deck on each:

xwax -l ~/music -a hw:0 -d /dev/dsp1 -j jack0

Scan multiple music libraries:

xwax -l ~/music -l ~/sounds -l ~/mixes -a hw:0

Scan a second music library using a custom script:

xwax -l ~/music -i ./custom-scan -l ~/sounds -a hw:0

Control two decks with Dicer hardware:

xwax --dicer hw:Dicer -a hw:0 -a hw:1

Use a high resolution and enlarge the user interface:

xwax -g 1920x1200/1.8 -a hw:0
