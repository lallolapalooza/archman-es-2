XWALLPAPER(1) Manual de comandos generales XWALLPAPER(1)

NOMBRE

xwallpaper — utilidad para establecer fondos de pantalla para X

SINOPSIS

xwallpaper [--screen pantalla] [--clear] [--daemon] [--debug] [--no-atoms] [--no-randr] [--no-root] [--trim ancho x alto[+x+y]] [--output salida] [--center archivo] [--focus archivo] [--maximize archivo] [--stretch archivo] [--tile archivo] [--zoom archivo] [--version]

DESCRIPCIÓN

El programa xwallpaper te permite establecer archivos de imagen como fondo de pantalla de tu X. El formato de archivo PNG es compatible por defecto y preferido, pero también existe soporte opcional para JPEG.

El fondo de pantalla también se anuncia a programas que soportan fondos semitransparentes.

OPCIONES

Las diversas opciones son las siguientes:

--center archivo
Centra el archivo de entrada en la salida. Si las dimensiones del archivo de entrada son menores que las dimensiones de salida, el área restante se rellena de negro. Si las dimensiones del archivo de entrada son demasiado grandes, partes de la imagen se recortarán.
--clear
Inicializa la pantalla con un fondo negro. Sin esta opción, se recupera el contenido actual de los átomos de pseudo transparencia y se utiliza como base. Si los contenidos de los átomos no existen o no pueden reutilizarse, por ejemplo, debido a un cambio de resolución de una de las salidas, entonces también se utiliza un fondo negro inicial.
--daemon
Mantiene xwallpaper ejecutándose en segundo plano, escuchando eventos de RandR. En este modo, los fondos de pantalla se redibujan cuando cambian los tamaños de salida. Esta opción solo se puede utilizar cuando el soporte de RandR está disponible y activado.
--debug
Muestra mensajes de depuración en la salida estándar de error mientras xwallpaper se está ejecutando. Si se usa junto con --daemon, el proceso no modificará las entradas y salidas estándar.
--focus archivo
En conjunción con --trim, se garantiza que el cuadro de recorte especificado sea visible en la salida, ampliando si es necesario. Si los píxeles negros aparecieran alrededor de la selección, la imagen de entrada se amplía y se mueve para cubrirla lo mejor posible bajo la restricción de mantener el cuadro de recorte especificado (o toda la imagen si no se ha especificado ningún cuadro de recorte) en la salida.
--maximize archivo
Maximiza el archivo de entrada para que encaje en la salida sin recortar. Esto puede significar ampliar o reducir, dependiendo de las dimensiones del archivo de entrada y la salida. Esta opción garantiza que se vea toda la imagen. Si la relación no se ajusta a la salida, el área restante se rellena de negro. La imagen en sí se centrará en la salida.
--no-atoms
Los átomos que se utilizan para la pseudo transparencia no se actualizan. Mutuamente excluyente con la opción --no-root. Habilita automáticamente la opción --clear.
--no-randr
Ignora las salidas individuales y utiliza la salida completa en su lugar. Esta es el área que abarca todas las diferentes salidas (monitores).
--no-root
El fondo de la ventana raíz no se actualiza. Utilice esta opción si solo desea actualizar los átomos utilizados para la pseudo transparencia. Por lo tanto, es mutuamente excluyente con la opción --no-atoms.
--trim ancho x alto+x+y
Especifica el área de interés en el archivo fuente. Si el modo de salida intenta generar más píxeles de los especificados con el cuadro de recorte, se añadirán a la salida los píxeles adyacentes alrededor del cuadro. Los píxeles negros solo se añaden si no quedan más píxeles fuente.
--output salida
Especifica la salida en la que se establecerá un archivo suministrado posteriormente como fondo de pantalla. Puede obtener una lista de las salidas en su sistema ejecutando xrandr(1). Si no se especifica ninguna salida, todas las salidas se modificarán individualmente. La palabra clave especial all repetirá las acciones posteriores en todas las pantallas. Si la salida no se encuentra, sus acciones asociadas se ignoran.
--screen pantalla
Especifica una pantalla por su número de pantalla. Normalmente se procesan todas las pantallas de una pantalla X. Tenga en cuenta que una pantalla no es un monitor individual. Consulte --output para este tipo de caso de uso.
--stretch archivo
Estira el archivo de entrada para cubrir completamente la salida. Si la relación de aspecto del archivo de entrada no coincide con la de la salida, se ajustará la relación del archivo de entrada.
--tile archivo
Utiliza el modo de mosaico. Dibuja el archivo de entrada en la esquina superior izquierda de la salida y repite la imagen hasta que el área restante de la salida esté cubierta.
--version
Imprime la versión y sale.
--zoom archivo
Amplía el archivo de entrada para que encaje en la salida con recorte. Esto puede significar ampliar o reducir, dependiendo de las dimensiones del archivo de entrada y la salida. Si la relación no se ajusta a la salida, partes del archivo de entrada no se mostrarán. La imagen en sí se centrará en la salida. Comportamiento predeterminado si no se seleccionó ninguna opción.

Si se dieron múltiples opciones contradictorias, la última opción suministrada prevalece. También es posible repetir argumentos de salida sin archivos subsiguientes. En ese caso, se reutilizarán el último modo y archivo.

EJEMPLOS

Centra un archivo PNG como fondo de pantalla en LVDS-1:

$ xwallpaper --output LVDS-1 --center archivo.png

Se enfoca en la esquina superior izquierda de un archivo JPEG como fondo de pantalla en Virtual-1:

$ xwallpaper --output Virtual-1 --trim 1x1+0+0 --focus archivo.jpg

Crea un mosaico de un archivo PNG como fondo de pantalla en todas las salidas:

$ xwallpaper --no-randr --tile archivo.png

Amplía un archivo JPEG como fondo de pantalla en cada salida individualmente:

$ xwallpaper --zoom archivo.jpg

Centra y recentra un archivo JPEG después de actualizaciones de salida en todas las salidas:

$ xwallpaper --daemon --center archivo.jpg

Crea un mosaico de un archivo JPEG como fondo de pantalla en VGA-1 y amplía un archivo PNG en LVDS-1:

$ xwallpaper --output VGA-1 --tile archivo.jpg --output LVDS-1 --zoom archivo.png

NAME

xwallpaper - Wallpaper setter for X11

SYNOPSIS

xwallpaper [OPTIONS] [imagefile]

DESCRIPTION

The xwallpaper program allows you to set a background image for your X11 session. It supports common image formats like PNG, JPEG, and GIF.

It can be used to set a static wallpaper, or to cycle through a list of images.

OPTIONS

-h, --help
Show help message and exit.
-v, --version
Show program version and exit.
-o, --output OUTPUT
Specifies the output window or root window. Defaults to the root window.
-z, --zoom
Zoom the image to fit the screen without cropping.
-c, --center
Center the image on the screen.
-s, --scale
Scale the image to fit the screen, cropping if necessary.
-t, --tile
Tile the image.
-r, --random DIR
Set a random wallpaper from the specified directory.
-i, --interval SECONDS
Change wallpaper at regular intervals (used with -r).
-f, --config FILE
Use a configuration file.

EXAMPLES

Set a wallpaper:

xwallpaper -s ~/Pictures/wallpaper.jpg

Center a wallpaper:

xwallpaper -c ~/Pictures/wallpaper.png

Set a random wallpaper from a directory and change it every 5 minutes:

xwallpaper -r ~/Pictures/Wallpapers -i 300
