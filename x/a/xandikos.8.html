XANDIKOS(8) Utilidades de Administración del Sistema XANDIKOS(8)

NOMBRE

xandikos - servidor CalDAV/CardDAV basado en git

DESCRIPCIÓN

uso: ./bin/xandikos -d DIRECTORIO_RAIZ [OPCIONES]

argumentos opcionales:

-h, --help
mostrar este mensaje de ayuda y salir
--version
mostrar número de versión del programa y salir
-d DIRECTORIO, --directory DIRECTORIO
Directorio desde el cual servir.
--current-user-principal PRINCIPAL_USUARIO_ACTUAL
Ruta al principal del usuario actual. [/user/]
--autocreate
Crear automáticamente directorios necesarios.
--defaults
Crear calendario y agenda de direcciones iniciales. Implica --autocreate.
--dump-dav-xml
Imprimir peticiones/respuestas DAV XML.
--avahi
Anunciar servicios con avahi.
--no-strict
Habilitar soluciones alternativas para implementaciones de clientes CalDAV/CardDAV con errores.

Opciones de Acceso:

-l DIRECCION_ESCUCHA, --listen-address DIRECCION_ESCUCHA
Vincular a esta dirección. Pasar la ruta para el socket de dominio unix. [localhost]
-p PUERTO, --port PUERTO
Puerto en el que escuchar. [8080]
--route-prefix PREFIJO_RUTA
Ruta a Xandikos. (útil cuando Xandikos está detrás de un proxy inverso) [/]
