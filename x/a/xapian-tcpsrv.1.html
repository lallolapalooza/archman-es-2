NOMBRE

xapian-tcpsrv - demonio TCP para usar con el backend remoto de Xapian

SINOPSIS

xapian-tcpsrv [OPCIONES] RUTA_BASE_DATOS...

DESCRIPCIÓN

xapian-tcpsrv - demonio TCP para usar con el backend remoto de Xapian

OPCIONES

--port NUMPUERTO
escuchar en el puerto NUMPUERTO para conexiones (sin valor por defecto)
--interface DIRECCION
escuchar en la interfaz asociada con el nombre o dirección DIRECCION (por defecto son todas las interfaces)
--idle-timeout MSECS
establecer el tiempo de espera para conexiones inactivas (por defecto: 60000ms)
--active-timeout MSECS
establecer el tiempo de espera para conexiones activas (por defecto: 15000ms)
--timeout MSECS
establecer ambos valores de tiempo de espera
--one-shot
servir una única conexión y salir
--quiet
deshabilitar mensajes de información a stdout
--writable
permitir actualizaciones
--help
mostrar esta ayuda y salir
--version
mostrar información de la versión y salir
