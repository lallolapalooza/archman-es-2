XAPIAN-CONFIG(1) Comandos de usuario XAPIAN-CONFIG(1)

NOMBRE

xapian-config - informa sobre la versión instalada de xapian

SINOPSIS

xapian-config OPCIÓN...

DESCRIPCIÓN

xapian-config - informa sobre la versión instalada de xapian

OPCIONES

--cxxflags
muestra todas las banderas del preprocesador y compilador C++
--libs
muestra todas las banderas del enlazador
--ltlibs
muestra las banderas del enlazador para enlazar usando GNU libtool
--static
hace que otras opciones muestren valores para el enlazado estático
--swigflags
muestra las banderas del preprocesador para usar con SWIG
--help
muestra esta ayuda y sale
--version
muestra información de la versión y sale

REPORTAR ERRORES

Reporta errores a https://xapian.org/bugs.
