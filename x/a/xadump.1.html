XADUMP(1) Manual de comandos generales XADUMP(1)

NOMBRE

xadump - acceso de bajo nivel a un índice Xapian de Recoll.

SINOPSIS

xadump [ -d <directorio_bd> ] [ -e <codificación_salida> ] -i <id_documento> -D
xadump [ -d <directorio_bd> ] [ -e <codificación_salida> ] -i <id_documento> -X
xadump [ -d <directorio_bd> ] [ -e <codificación_salida> ] -i <id_documento> [ -x ] -T
xadump [ -d <directorio_bd> ] [ -e <codificación_salida> ] -i <id_documento> [ -x ] -r

xadump [ -d <directorio_bd> ] [ -e <codificación_salida> ] -t <término> -E
xadump [ -d <directorio_bd> ] [ -e <codificación_salida> ] -t <término> -F
xadump [ -d <directorio_bd> ] [ -e <codificación_salida> ] -t <término> -P

xadump -T [ -f ] [ -n ] [ -l ]

xadump -q término [término ...]

DESCRIPCIÓN

El comando xadump es una herramienta de diagnóstico y acceso de bajo nivel para un índice Xapian tal como está organizado por el indexador de Recoll. El directorio del índice a utilizar se especifica con la opción -d.

Las opciones -D, -X, -T y -r toman un único argumento id_documento especificado con la opción -i. -D muestra el registro de datos del documento. -X elimina todos los datos del índice para el documento. -T imprime la lista de términos para el documento. Sin argumento de id_documento, esta opción listará toda la lista de términos del índice. -f se puede establecer para preceder cada término con su recuento de ocurrencias (solo si no se especifica id_documento). -n se puede establecer para omitir los corchetes de cierre. -l se puede establecer para omitir los términos prefijados. -r imprime el texto del documento tal como se reconstruye a partir de los datos del índice.

Cuando se establece la opción -x, los términos se imprimen con cada carácter separado por un espacio, lo que puede ser útil para verificar algunos problemas de codificación.

Las opciones -E, -F y -P necesitan un argumento de término, especificado con -t <término>. -E realiza una prueba de existencia del término. -F recupera la frecuencia del término para el término dado. -P muestra las publicaciones para el término dado.

Con la opción -q, xadump realiza una consulta AND simple en el índice, utilizando los argumentos de término dados.
