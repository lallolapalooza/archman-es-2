NOMBRE

xapian-compact - Compactar una base de datos, o fusionar y compactar varias

SINOPSIS

xapian-compact [OPCIONES] BASE_DE_DATOS_ORIGEN... BASE_DE_DATOS_DESTINO

DESCRIPCIÓN

xapian-compact - Compactar una base de datos, o fusionar y compactar varias

OPCIONES

-b, --blocksize=T
Establecer el tamaño del bloque en bytes (por ejemplo, 4096) o K (por ejemplo, 4K) (debe estar entre 2K y 64K y ser una potencia de 2, por defecto 8K)
-n, --no-full
Desactivar la compactación completa
-F, --fuller
Activar la compactación más completa (no recomendado si planeas actualizar la base de datos compactada)
-m, --multipass
Si se fusionan más de 3 bases de datos, fusionar las listas posteriores en múltiples pasadas (lo cual es generalmente más rápido pero requiere más espacio en disco para archivos temporales)
--no-renumber
Preservar la numeración de los IDs de documentos (útil si tienes referencias externas a ellos, o si los has configurado para que coincidan con IDs únicos de una fuente externa). Actualmente, esta opción solo se admite al fusionar bases de datos si tienen rangos disjuntos de IDs de documentos utilizados.
-s, --single-file
Producir una base de datos de un solo archivo (no compatible con chert)
--help
mostrar esta ayuda y salir
--version
mostrar información de versión y salir
