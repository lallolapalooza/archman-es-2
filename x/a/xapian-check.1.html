XAPIAN-CHECK(1) Comandos de usuario XAPIAN-CHECK(1)

NOMBRE

xapian-check - Comprueba la consistencia de una base de datos o tabla

SINOPSIS

xapian-check DIRECTORIO_BASE_DE_DATOS|RUTA_A_BTREE [[F][t][f][b][v][+]]

DESCRIPCIÓN

xapian-check - Comprueba la consistencia de una base de datos o tabla

Si se comprueba una base de datos completa, se realizan comprobaciones cruzadas adicionales entre las tablas.

El/Los árbol(es) B-tree siempre se comprueban. Controle la verbosidad de la salida con:

F = intenta arreglar una base de datos rota (implementado para chert actualmente) t = impresión corta del árbol f = impresión completa del árbol b = mostrar bloques libres v = mostrar estadísticas del árbol B (por defecto) + = lo mismo que tbv por ejemplo, xapian-check /var/lib/xapian/data/default
xapian-check /var/lib/xapian/data/default/postlist fbv
