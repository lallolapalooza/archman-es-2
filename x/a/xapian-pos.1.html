XAPIAN-POS(1) Comandos de usuario XAPIAN-POS(1)

NOMBRE

xapian-pos - Depurar datos posicionales en una base de datos Xapian

SINOPSIS

xapian-pos [OPCIONES] BASE_DE_DATOS

DESCRIPCIÓN

xapian-pos - Depurar datos posicionales en una base de datos Xapian

OPCIONES

-d, --doc=ID_DOCUMENTO
mostrar posiciones para el documento ID_DOCUMENTO
-s, --start=POSICIÓN
especifica la primera posición a mostrar
-e, --end=POSICIÓN
especifica la última posición a mostrar
--help
mostrar esta ayuda y salir
--version
mostrar información de la versión y salir
abril 2025 xapian-core 1.4.29
