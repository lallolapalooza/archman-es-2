DELVE(1) Comandos de usuario DELVE(1)

NOMBRE

delve - Inspecciona el contenido de una base de datos Xapian

SINOPSIS

delve [OPCIONES] BASE_DE_DATOS...

DESCRIPCIÓN

delve - Inspecciona el contenido de una base de datos Xapian

OPCIONES

-a
muestra todos los términos de la base de datos
-A <prefijo>
muestra todos los términos de la base de datos con el prefijo dado
-r <nº_registro>
para lista(s) de términos
-t <término>
para lista(s) de posteo
-t <término> -r <nº_registro>
para lista(s) de posiciones
-s, --stemmer=IDIOMA
establece el idioma de stemming, el valor predeterminado es 'none'
-1
muestra una entrada de lista por línea
-V[<tipo>]<nº_valor>
muestra el valor nº_valor para cada documento al que se hace referencia (o para cada documento de la base de datos si no hay opciones -r). <tipo> puede ser: E: escapar de forma similar a C (predeterminado) I: decodificar como entero empaquetado R: mostrar el valor crudo (que puede contener datos binarios,
saltos de línea, UTF-8 no válido, etc.)
S: decodificar usando Xapian::sortable_unserialise()
-V[<tipo>]
muestra todos los valores para cada documento al que se hace referencia. <tipo> es como se indica arriba.
-d
muestra los datos del documento para cada documento al que se hace referencia
-z
para db, cuenta documentos con longitud 0
-v
información extra (wdf y len para postlist; wdf y termfreq para termlist; número de términos para db; termfreq al mostrar todos los términos; límites de valor y frecuencia al mostrar todos los valores en una ranura)
-vv
información aún más detallada (también muestra la frecuencia de colección y el límite superior de wdf para los términos)
--help
muestra esta ayuda y sale
--version
muestra información de la versión y sale
