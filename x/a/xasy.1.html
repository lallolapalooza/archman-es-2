NOMBRE

asy - lenguaje de gráficos vectoriales basado en scripts

SINOPSIS

xasy [-x magnificación] [nombre_archivo]

DESCRIPCIÓN

Asymptote es un potente lenguaje descriptivo de gráficos vectoriales para dibujo técnico, inspirado en MetaPost pero con una sintaxis mejorada similar a C++. Asymptote proporciona para las figuras el mismo nivel de alta calidad de tipografía que LaTeX hace para el texto científico.

xasy es una GUI para Asymptote que permite ajustes finales de figuras.

OPCIONES

-x magnificación
Zoom inicial.

VER TAMBIÉN

Asymptote y xasy están documentados completamente en la página de información de Asymptote.
