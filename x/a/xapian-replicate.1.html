NOMBRE

xapian-replicate - Replicar una base de datos desde un servidor maestro a una copia local

SINOPSIS

xapian-replicate [OPCIONES] BASE_DE_DATOS

DESCRIPCIÓN

xapian-replicate - Replicar una base de datos desde un servidor maestro a una copia local

OPCIONES

-h, --host=HOST
host al que conectarse (requerido)
-p, --port=PUERTO
puerto al que conectarse (requerido)
-m, --master=DB
replicar la base de datos DB del maestro (por defecto: BASE_DE_DATOS)
-i, --interval=N
esperar N segundos entre cada conexión al maestro (por defecto: 60)
-r, --reader-time=N esperar N segundos para dar tiempo a los lectores a cerrar antes de
aplicar cambiosets repetidos (por defecto: 30)
-t, --timeout=N
establecer tiempos de espera del socket (si es compatible) en N segundos; N=0 para sin tiempo de espera (por defecto: 0)
-f, --force-copy
forzar una copia completa de la base de datos para ser enviada (y luego replicar como normal)
-o, --one-shot
replicar solo una vez y luego salir
-q, --quiet
solo reportar errores
-v, --verbose
ser más verboso
--help
mostrar esta ayuda y salir
--version
mostrar información de la versión y salir
