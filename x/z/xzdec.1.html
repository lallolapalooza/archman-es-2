XZDEC(1) Utilidades XZ XZDEC(1)

NOMBRE

xzdec, lzmadec - Descompresores pequeños de .xz y .lzma

SINOPSIS

xzdec [opción...] [archivo...]
lzmadec [opción...] [archivo...]

DESCRIPCIÓN

xzdec es una herramienta de solo descompresión basada en liblzma para archivos .xz (y solo .xz). xzdec está diseñado para funcionar como un reemplazo directo para xz(1) en las situaciones más comunes donde un script ha sido escrito para usar xz --decompress --stdout (y posiblemente algunas otras opciones usadas comúnmente) para descomprimir archivos .xz. lzmadec es idéntico a xzdec excepto que lzmadec soporta archivos .lzma en lugar de archivos .xz.

Para reducir el tamaño del ejecutable, xzdec no soporta multihilo ni localización, y no lee opciones de las variables de entorno XZ_DEFAULTS y XZ_OPT. xzdec no soporta mostrar información de progreso intermedio: enviar SIGINFO a xzdec no hace nada, pero enviar SIGUSR1 termina el proceso en lugar de mostrar información de progreso.

OPCIONES

-d, --decompress, --uncompress
Ignorado para compatibilidad con xz(1). xzdec solo soporta descompresión.
-k, --keep
Ignorado para compatibilidad con xz(1). xzdec nunca crea ni elimina archivos.
-c, --stdout, --to-stdout
Ignorado para compatibilidad con xz(1). xzdec siempre escribe los datos descomprimidos a la salida estándar.
-q, --quiet
Especificar esto una vez no hace nada ya que xzdec nunca muestra advertencias ni notificaciones. Especificar esto dos veces suprime los errores.
-Q, --no-warn
Ignorado para compatibilidad con xz(1). xzdec nunca usa el código de salida 2.
-h, --help
Muestra un mensaje de ayuda y sale exitosamente.
-V, --version
Muestra el número de versión de xzdec y liblzma.

ESTADO DE SALIDA

0
Todo salió bien.
1
Ocurrió un error.

xzdec no tiene mensajes de advertencia como los de xz(1), por lo tanto, el estado de salida 2 no es utilizado por xzdec.

NOTAS

Usa xz(1) en lugar de xzdec o lzmadec para el uso diario normal. xzdec o lzmadec están pensados solo para situaciones donde es importante tener un descompresor más pequeño que el xz(1) completo.

xzdec y lzmadec en realidad no son tan pequeños. El tamaño se puede reducir aún más eliminando características de liblzma en tiempo de compilación, pero eso generalmente no debería hacerse para ejecutables distribuidos en distribuciones típicas de sistemas operativos no embebidos. Si necesitas un descompresor .xz verdaderamente pequeño, considera usar XZ Embedded.
