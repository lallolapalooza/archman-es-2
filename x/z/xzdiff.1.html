XZDIFF(1) Utilidades XZ XZDIFF(1)

NOMBRE

xzcmp, xzdiff, lzcmp, lzdiff - compara archivos comprimidos

SINOPSIS

xzcmp [opción...] archivo1 [archivo2]
xzdiff ...
lzcmp ... (OBSOLETO)
lzdiff ... (OBSOLETO)

DESCRIPCIÓN

xzcmp y xzdiff comparan el contenido descomprimido de dos archivos. Los datos descomprimidos y las opciones se pasan a cmp(1) o diff(1) a menos que se especifiquen --help o --version.

Si se especifican tanto archivo1 como archivo2, pueden ser archivos sin comprimir o archivos en formatos que xz(1), gzip(1), bzip2(1), lzop(1), zstd(1), o lz4(1) pueden descomprimir. Los comandos de descompresión necesarios se determinan a partir de los sufijos de nombre de archivo de archivo1 y archivo2. Un archivo con un sufijo desconocido se asume que está sin comprimir o en un formato que xz(1) puede descomprimir.

Si solo se proporciona un nombre de archivo, archivo1 debe tener un sufijo de un formato de compresión compatible y el nombre para archivo2 se asume que es archivo1 con el sufijo del formato de compresión eliminado.

Los comandos lzcmp y lzdiff se proporcionan para compatibilidad con versiones anteriores con LZMA Utils. Están obsoletos y se eliminarán en una versión futura.

ESTADO DE SALIDA

Si ocurre un error de descompresión, el estado de salida es 2. De lo contrario, se utiliza el estado de salida de cmp(1) o diff(1).

VER TAMBIÉN

cmp(1), diff(1), xz(1), gzip(1), bzip2(1), lzop(1), zstd(1), lz4(1)
