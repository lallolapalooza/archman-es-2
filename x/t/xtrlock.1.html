NOMBRE

xtrlock - Bloquea la pantalla X hasta que se proporcione la contraseña, dejando las ventanas visibles

SINOPSIS

xtrlock [-b] [-f] [-F]

DESCRIPCIÓN

xtrlock bloquea el servidor X hasta que el usuario introduce su contraseña en el teclado.

Mientras xtrlock se está ejecutando, el ratón y el teclado son capturados y el cursor del ratón se convierte en un candado. La salida mostrada por los programas X, y las ventanas abiertas por nuevos clientes X, continúan siendo visibles, y cualquier nueva salida se muestra normalmente.

El ratón y el teclado se devuelven cuando el usuario escribe su contraseña, seguida de Enter o Nueva Línea. Si se introduce una contraseña incorrecta, se suena la campana. Pulsar Retroceso o Suprimir borra un carácter de una contraseña parcialmente escrita; pulsar Escape o Borrar limpia todo lo que se ha introducido.

Si se realizan demasiados intentos en muy poco tiempo, las pulsaciones de teclas posteriores generan campanas y se ignoran de lo contrario hasta que expire un tiempo de espera.

El salvapantallas del servidor X continúa funcionando normalmente; si entra en funcionamiento, la pantalla puede restaurarse de las maneras habituales tocando una tecla (Mayúsculas, por ejemplo) o el ratón.

ADVERTENCIA

Debido a las limitaciones del protocolo X11, xtrlock no puede interceptar todos los eventos del teclado y del ratón si se ejecuta bajo un entorno de escritorio basado en Wayland. En esta situación, las aplicaciones que utilizan el protocolo X11 "heredado" se bloquearán, mientras que las que soportan Wayland aún se podrán utilizar, incluso cuando xtrlock esté en funcionamiento. Algunos atajos de teclado también pueden seguir funcionando mientras la pantalla está bloqueada.

Se imprime una advertencia si se detecta dicho entorno. Para una solución alternativa, consulte swaylock(1) o similar.

OPCIONES

-b
borra la pantalla además de mostrar el candado
-f
se bifurca después de que el bloqueo se complete, y devuelve el éxito del proceso padre -F fuerza el bloqueo, por ejemplo si no hay contraseña establecida. proceso

RECURSOS X, CONFIGURACIÓN

Ninguno.

ERRORES

Dispositivos de entrada adicionales aparte del teclado y el ratón no se deshabilitan.

Los tiempos de espera, mapas de bits y el color del cursor del ratón no se pueden modificar.
