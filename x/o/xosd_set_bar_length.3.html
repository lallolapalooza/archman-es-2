xosd_set_bar_length(3)

Paquete: xosd

Licencias: GPL2

XOSD_SET_BAR_LENGTH(3) XOSD_SET_BAR_LENGTH(3)

NOMBRE

xosd_set_bar_length - Cambiar la longitud de la barra de porcentaje o el control deslizante

SINOPSIS

#include <xosd.h>

int xosd_set_bar_length (xosd *osd, int displayPercentage);

DESCRIPCIÓN

xosd_set_bar_length cambia el porcentaje de la pantalla utilizado por un control deslizante o una barra de porcentaje. Normalmente XOSD elige una longitud sensata para la barra, pero puede que desees cambiar el comportamiento por defecto si solo hay un número pequeño de valores posibles para mostrar.

ARGUMENTOS

osd
La ventana XOSD a modificar.
displayPercentage
El porcentaje de la pantalla a utilizar por el control deslizante o la barra de porcentaje, como un entero entre 0 y 100. Establecer displayPercentage a -1 revierte al comportamiento por defecto.

VALOR DE RETORNO

En caso de éxito, se devuelve cero. En caso de error, se devuelve -1 y se establece xosd_error para indicar la razón del error.

ENTORNO

char *xosd_error
Una cadena que describe el error, si ocurrió alguno.

ERRORES CONOCIDOS

No se conocen errores con xosd_set_bar_length. Los informes de errores se pueden enviar a <xosd@ignavus.net>.
