NOMBRE

xosd-config - script para obtener información sobre la versión instalada de libxosd

SINOPSIS

xosd-config [--prefix[=DIR]] [--exec-prefix[=DIR]] [--version] [--libs] [--cflags]

DESCRIPCIÓN

xosd-config es una herramienta que se utiliza para determinar las opciones del compilador y del enlazador que deben utilizarse para compilar y enlazar programas que usan libxosd. También se utiliza internamente en las macros .m4 para GNU autoconf que se incluyen con libxosd.

OPCIONES

xosd-config acepta las siguientes opciones:

--version
Imprime la versión actualmente instalada de libxosd en la salida estándar.
--libs
Imprime las opciones del enlazador que son necesarias para enlazar un programa libxosd.
--cflags
Imprime las opciones del compilador que son necesarias para compilar un programa libxosd.
--prefix=PREFIX
Si se especifica, utiliza PREFIX en lugar del prefijo de instalación con el que se compiló libxosd al calcular la salida para las opciones --cflags y --libs. Esta opción también se utiliza para el prefijo de ejecución si no se especificó --exec-prefix. Esta opción debe especificarse antes de cualquier opción --libs o --cflags.
--exec-prefix=PREFIX
Si se especifica, utiliza PREFIX en lugar del prefijo de ejecución de instalación con el que se compiló libxosd al calcular la salida para las opciones --cflags y --libs. Esta opción debe especificarse antes de cualquier opción --libs o --cflags.
