NOMBRE

xosd_get_number_lines - Recuperar el número de líneas para las que se inicializó el objeto xosd para mostrar.

SINOPSIS

#include <xosd.h>

int xosd_get_number_lines(xosd* osd);

DESCRIPCIÓN

xosd_get_number_lines obtendrá el número de líneas para las que se inicializó el objeto xosd para mostrar.

ARGUMENTOS

osd
El objeto de visualización en pantalla sobre el que actuar.

VER TAMBIÉN

xosd_init(3).
