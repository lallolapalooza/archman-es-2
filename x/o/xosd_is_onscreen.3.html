NOMBRE

xosd_is_onscreen - Devuelve si la ventana XOSD está mostrada

SINOPSIS

#include <xosd.h>

xosd *xosd_is_onscreen (xosd *osd);

DESCRIPCIÓN

osd_is_onscreen determina si una ventana XOSD está siendo mostrada actualmente (está mapeada en la pantalla X). Como XOSD muestra datos asíncronamente (ver xosd_display(3) para más detalles) puede ser difícil saber si se están mostrando datos, xosd_is_onscreen soluciona este problema.

Llama a xosd_show(3) o xosd_hide(3) para alterar la visibilidad de la ventana XOSD.

ARGUMENTOS

osd
La ventana XOSD a consultar.

VALOR DE RETORNO

Se devuelve un 1 si la ventana está en pantalla (mapeada), o 0 si está oculta (desmapeada). En caso de error, se devuelve -1 y se establece xosd_error para indicar el motivo del error.

ENTORNO

char *xosd_error
Una cadena de texto que describe el error, si ocurrió alguno.

HISTORIA

La función xosd_is_onscreen apareció por primera vez en la versión 2.1 de la biblioteca XOSD.

AUTORES

La biblioteca XOSD fue escrita originalmente por André Renaud y actualmente es mantenida por Tim Wright, quien también escribió la función xosd_is_onscreen. Michael JasonSmith cree que escribió este documento, pero no está seguro; envíale un correo a Michael (<mike@ldots.org>) si crees que él no escribió este documento.

ERRORES

No se conocen errores con xosd_is_onscreen. Los informes de errores pueden enviarse a <xosd@ignavus.net>.

VER TAMBIÉN


xosd_display(3), xosd_show(3), xosd_hide(3).
