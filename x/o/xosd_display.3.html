Paquete: xosd

XOSD_DISPLAY(3) XOSD_DISPLAY(3)

NOMBRE

xosd_display - Muestra datos en una ventana XOSD

SINOPSIS

#include <xosd.h>

int xosd_display (xosd *osd, int line, xosd_command command, ...);

DESCRIPCIÓN

xosd_display muestra una cadena de texto, una barra de porcentaje (como una barra de progreso) o un deslizador en una pantalla X. Los datos se muestran en una ventana sin bordes y con forma, por lo que parece flotar sobre las otras ventanas, como las pantallas en pantalla que se encuentran en muchos televisores. Los usuarios no pueden interactuar con la pantalla de ninguna manera.

Los datos se muestran hasta que se alcanza el límite de tiempo, establecido al llamar a xosd_set_timeout(3), pero xosd_display regresa inmediatamente. Si se requiere bloqueo, se debe llamar a xosd_wait_until_no_display(3) después de xosd_display. Una ventana que muestra datos puede ocultarse llamando a xosd_hide(3).

El tipo de datos que se muestran está determinado por el argumento command. Hay dos tipos de datos que se pueden mostrar: texto o enteros.

Mostrar datos textuales

El texto normalmente se muestra pasando XOSD_string como argumento a command, seguido de una cadena en formato UTF-8. Si se desea texto formateado, pase XOSD_printf como argumento a command, seguido de una cadena que tenga el mismo formato que printf(3), y tantos argumentos adicionales como sea necesario por la cadena de formato.

Mostrar valores enteros

Los valores enteros (que deben estar en el rango de 0 a 100) se pueden mostrar de dos maneras: una barra de porcentaje o un deslizador. Una barra de porcentaje se parece a una pantalla de volumen en un televisor y se crea pasando XOSD_percentage como argumento a command. Un deslizador (ver el plugin XOSD para xmms(1) como ejemplo) se crea pasando XOSD_slider como argumento a command. Se espera un int entre 0 y 100 como argumento final cuando se pasa XOSD_percentage o XOSD_slider como argumento a command.

ARGUMENTOS

osd
La ventana XOSD a usar como pantalla.
line
La línea de la pantalla a cambiar. El valor de line debe ser menor que number_lines, establecido en la llamada a xosd_create(3).
command
Uno de XOSD_percentage, XOSD_slider o XOSD_string. Si el valor de command es XOSD_string, el siguiente argumento debe ser una cadena en formato UTF-8. Si se da XOSD_percentage o XOSD_slider, se espera un int entre 1 y 100 como siguiente argumento.

VALOR DE RETORNO

Si el command es XOSD_percentage o XOSD_slider, se devuelve el valor entero de la barra o deslizador (entre 1 y 100). Para XOSD_string y XOSD_printf se devuelve el número de caracteres escritos en la pantalla.

En caso de error, se devuelve -1 y xosd_error se establece para indicar el motivo del error.

ENTORNO

char *xosd_error
Una cadena que describe el error, si ocurrió alguno.
enum xosd_command
El tipo de información que se puede mostrar, definido como un tipo enumerado. Hay cuatro valores definidos: XOSD_percentage, XOSD_string, XOSD_printf y XOSD_slider.

AUTORES

ERRORES

No hay errores conocidos con xosd_display. Los informes de errores se pueden enviar a <xosd@ignavus.net>.

VER TAMBIÉN
