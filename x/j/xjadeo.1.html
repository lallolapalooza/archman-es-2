XJADEO(1) Comandos de usuario XJADEO(1)

NOMBRE

xjadeo - Monitor de Video X Jack

SINOPSIS

xjadeo [ OPCIONES ] [ archivo-de-video ]

DESCRIPCIÓN

xjadeo - el Monitor de Video X Jack

Xjadeo es un reproductor de software que muestra un clip de video sincronizado con una fuente de tiempo externa (MTC, LTC, transporte JACK).

Xjadeo está pensado para la composición de bandas sonoras, monitorización de video y es útil para cualquier tarea que requiera sincronizar fotogramas de película con eventos de audio.

OPCIONES

-A, --avverbose
Muestra mensajes detallados del decodificador de video.
-a, --ontop
Mantiene la ventana de xjadeo encima de otras aplicaciones.
-b, --no-letterbox
Escala la película para que quepa en la ventana. Sin esta opción se utiliza un letterbox para mantener la relación de aspecto.
-D, --debug
Imprime información relacionada con el desarrollo.
-d <nombre>, --midi-driver <nombre>
Especifica el controlador midi a usar. Ejecuta 'xjadeo -V' para listar los controladores compatibles. <nombre> no distingue entre mayúsculas y minúsculas y se puede acortar al primer nombre único. ej. '-d j' para jack, '-d alsa-r' para alsa-raw
-f <val>, --screen-fps <val>
Tasa de refresco deseada de la pantalla de video en fotogramas. Si este valor es igual o inferior a cero, xjadeo utilizará los FPS del archivo de video como frecuencia de actualización (que es el valor por defecto). Nota: Esto no afecta la sincronización de pantalla/vblank. La sincronización con el refresco vertical de la pantalla depende del hardware (y siempre se usa si está disponible).
-h, --help
Muestra esta ayuda y sale.
-I, --ignore-file-offset
Esta opción solo es útil para archivos de video con un desplazamiento de inicio, como archivos vob divididos. Por defecto, xjadeo respeta los desplazamientos especificados en la cabecera del archivo de video. Esta opción permite anular (y restar) este desplazamiento para alinear el inicio del archivo con el código de tiempo 00:00:00:00.
-i <int>, --info <int>
Muestra información de tiempo usando el OSD (visualización en pantalla). 0:Apagado, 1: Número de fotograma, 2: Código de tiempo, 3: ambos.
-J, --no-initial-sync
No se conecta a JACK ni utiliza ninguna otra fuente de sincronización al inicio de la aplicación.
-K <int>, --keyframe-limit <int>
Especifica un límite máximo de intervalo de fotogramas clave. Con la mayoría de los códecs de video, un fotograma de video es la suma de un fotograma clave más las diferencias del fotograma clave más cercano. Para una reproducción no continua y búsquedas aleatorias, xjadeo tendrá que retroceder a un fotograma clave y decodificar secuencialmente hasta el fotograma objetivo. Esto puede ser bastante intensivo en CPU y, por lo tanto, la secuencia máxima de decodificación secuencial está limitada. Por defecto, a 100 fotogramas. Para búsquedas rápidas y precisas de fotogramas, se recomienda encarecidamente transcodificar el archivo de video usando un códec donde cada fotograma sea un fotograma clave (ej. mjpeg), y el video consista solo en fotogramas "intra". (el intervalo de fotogramas clave a veces también se llama "grupo de imágenes" o GOP).
-l, --ltc
Sincroniza con Código de Tiempo Lineal (audio jack).
-M <int>, --midifps <int>
Especifica el modo de conversión MTC:
0:
usa la tasa de fotogramas del reloj MTC (por defecto)
1:
usa los FPS del archivo de video
2:
"remuestre" los FPS del archivo / MTC
-m <puerto>, --midi <puerto>
Usa MTC como fuente de sincronización. El argumento <puerto> es específico del controlador midi:
jack-midi:
especifica un nombre de puerto midi al que conectarse,
o "" para no conectar automáticamente.
alsa-seq: especifica el ID al que conectarse (-1: ninguno)
ej. -m ardour o -m 80
alsa-raw: especifica el dispositivo de hardware
ej. -m hw:1,0 o -m 1
portmidi: ID numérico; -1: autodetección
un valor > -1 especifica el número de puerto a utilizar.
usa '-v -m -1' para listar los puertos midi.
-O <puerto>, --osc <puerto>
Escucha mensajes OSC en el puerto dado. Xjadeo puede ser controlado remotamente usando Open Sound Control. Para una lista de comandos disponibles, por favor consulte el código fuente o la documentación en línea.
-o <val>, --offset <val>
Desplaza el video en el tiempo respecto a la fuente de código de tiempo. Esto permite desplazar la reproducción del video un cierto número de fotogramas (de video) en relación con la fuente de tiempo. Se permiten valores positivos y negativos. El desplazamiento se puede especificar como un número de fotograma entero o como código de tiempo separado por dos puntos.
--osc-doc
Imprime los comandos OSC disponibles y sale.
-Q, --mq
Habilita colas de mensajes en tiempo real POSIX. Esto configura un canal de comunicación para control remoto, destinado a ser utilizado con `xjremote`.
-q, --quiet, --silent
Inhibe la salida habitual.
-R, --remote
Habilita el modo de control remoto interactivo usando E/S estándar. Esta opción implica no verbose y quiet, ya que la terminal se utiliza para la interacción.
-r <archivo>, --rc <archivo>
Especifica un archivo de configuración personalizado para cargar.
-S, --no-splash
Omite la secuencia de inicio de la visualización en pantalla.
-s, --fullscreen
Inicia xjadeo en modo de pantalla completa.
-T <archivo>, --ttf-file <archivo>
ruta al archivo .ttf para la visualización en pantalla
-U, --uuid
especifica el UUID de la sesión JACK.
-V, --version
Imprime información de la versión y sale.
-W <rpc-id>, --ipc <rpc-id>
Configura colas de mensajes IPC para el control remoto. La Comunicación entre Procesos es utilizada por `xjremote` en OSX y otras plataformas que no soportan colas de mensajes en tiempo real.
-v, --verbose
Imprime más información.
-x <int>, --vo <int>, --videomode <int>
Selecciona un modo de salida de video (por defecto: 0: autodetectar). Un valor de -1 lista los modos disponibles y sale.

Fuentes de sincronización:

JACK:
Transporte JACK
LTC:
Código de Tiempo Lineal/Longitudinal - a través de audio JACK
MTC:
MIDI Time Code a través de MIDI JACK
MTC:
MIDI Time Code a través del secuenciador ALSA (solo Linux)
MTC:
MIDI Time Code a través de dispositivos ALSA raw (solo Linux)
MTC:
MIDI Time Code a través de portmidi (OSX, Windows)
Manual:
Búsquedas manuales controladas remotamente.

Si no se proporcionan las opciones -m ni -l, xjadeo se sincroniza con el transporte jack por defecto.

Códecs y formatos de vídeo:

Xjadeo

A simple video player for JACK/ALSA/OSS and ALSA-MIDI/OSS-MIDI.

SYNOPSIS

xjadeo [-h] [-v] [-c configfile] [-l loglevel] [-p port] [-S sync] [-M mtrack] [-a alsa_device] [-F alsa_capture] [-j jack_server] [-A audio_out] [-r rate] [-n n_voices] [-s capture_channels] [-f frame] [-t time] [-O offset] [-i input_port] [-u output_port] [-o output_port] [-k input_port] [-K output_port] [-d display_port] [-e display_port] [-w width] [-h height] [-g group] [-R group] [-d device] [-D device] [-G device] [-W device] [-L device] [-N device] [-P device] [-C device] [-I device] [-E device] [-X device] [-Y device] [-Z device] [-V device] [-U device] [-T device] [-B device] [-Q device] [-H device] [-J device] [-K device] [-m midi_device] [input-file] ...

DESCRIPTION

xjadeo is a realtime video-display plugin for the JACK Audio Connection Kit. It is intended to be used for synchronized video playback in live shows and studio work, e.g. when scoring film or video content.

xjadeo utilizes the ffmpeg libraries to decode video files, thus supporting a wide range of formats and codecs. It syncs to the JACK transport as either master or slave. Additionally it can sync to incoming MIDI timecode (MIDI TC) or incoming audio timecode (ATC).

The video display itself is managed using SDL or Xvideo. Additionally xjadeo can be controlled via OSC (Open Sound Control) and accepts commands to seek, play, pause, and load new files.

Synchronization Sources:

xjadeo can sync to one of the following sources:

JACK
Synchronize to the JACK transport.
MTC
Synchronize to MIDI timecode.
ATC
Synchronize to audio timecode.
NONE
No synchronization.

If JACK is selected, xjadeo will act as a slave to the JACK transport. If MTC or ATC is selected, xjadeo will sync to the incoming timecode stream. In case of MTC, the track number can be specified with -M.

The timecode offset can be adjusted using the -O option or via key-commands.

Video Codecs and Formats:

xjadeo uses ffmpeg to decode video files, so a wide range of formats and codecs are supported. Note however that not all the codecs support reliable seeking. It is highly recommended to transcode the video file into a suitable format/codec. The recommend combination is avi/mjpeg. e.g. ffmpeg -i input-file.xxx -an -vcodec mjpeg output-file.avi This creates from your input-file.xxx an AVI mjpeg encoded video file without sound, and no compression between frames (motion jpeg - every frame is a key-frame). You may want also to shrink the size of the file by scaling down its geometry. This uses fewer system resources for decoding and display and leaves more space on the screen for your audio software. see ffmpeg -s <width>x<height> option and read up on the ffmpeg man page for further options. e.g. -qscale 0 to retain image quality.

Configuration Files:

At startup xjadeo reads the following resource configuration files in the following order:

system wide:
/etc/xjadeorc or /usr/local/etc/xjadeorc
old user config:
$HOME/.xjadeorc
user config:
$XDM_CONFIG_HOME/xjadeo/xjadeorc (usually $HOME/.config/)
on OSX:
$HOME/Library/Preferences/xjadeorc
on Windows:
$HOMEDRIVE$HOMEPATH\xjadeorc
and $HOMEDRIVE$HOMEPATH\Local Settings\xjadeorc
(usually C:\Documents and Settings\<Username>\)
project specific:
$PWD/xjadeorc

Every line in the configuration file is a KEY=VALUE pair. If the first character on a line is either is a literal '#' or ';', the line is ignored. KEYS are case insensitive. Boolean values are specified as 'yes' or 'no'. As for a list of available keys, please see the example configuration file, which is available in the documentation folder of the source code.

If xjadeo is compiled with jack session support, it will save its current state as config file and pass it as handle to the jack session manager.

User Interaction:

The xjadeo window offers a right-click context menu (except on OSX where the application has a main menu bar) which provides easy access to common functionality. On OSX and Windows this menu offers a file open dialog to change the video file that is being monitored. On Linux new files can be loaded by dragging the file onto the window itself. In addition xjadeo reacts to key presses. The following shortcuts are defined:

'Esc'
Close window and quit
'a'
Toggle always-on-top mode
'b'
Toggle On Screen Display black border
'Shift+C'
Clear all OSD display messages.
'f'
Toggle full screen mode
'g'
Toggle On Screen file geometry display
'i'
Toggle On Screen file time info display
'l'
Toggle letterbox scaling
'm'
Toggle mouse-cursor visibility
'o'
Cycle though offset display modes.
'p'
Swap OSD timecode/frame number position.
's'
Toggle On Screen sync source timecode display
'v'
Cycle On Screen VTS/frame number display
'x'
Toggle seek-bar (experimental)
'\'
Reset timecode offset to zero

Decrease timecode offset by one frame

Note that it is possible to disable certain features using the remote control. A Host can take control of certain aspects e.g. offset or disallow closing the video monitor, except by host-provided means.
