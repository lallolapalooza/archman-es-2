NOMBRE

xml_spellcheck - corrector ortográfico para archivos XML

SINOPSIS

xml_spellcheck [opciones] <archivos>

DESCRIPCIÓN

xml_spellcheck permite corregir la ortografía del contenido de un archivo XML. Extrae el texto (el contenido de elementos y opcionalmente de atributos), llama a un corrector ortográfico y luego recrea el documento XML.

OPCIONES

Tenga en cuenta que todas las opciones se pueden abreviar a la primera letra

--conf <archivo_de_configuracion>
Obtiene las opciones de un archivo de configuración. (AÚN NO IMPLEMENTADO).
--spellchecker <corrector_ortografico>
El comando a usar para la corrección ortográfica, incluyendo cualquier opción.

Por defecto se usa "aspell -c"

--backup-extension <extension>
Por defecto, el archivo original se guarda con la extensión ".bak". Esta opción cambia la extensión.
--attributes
Corrige la ortografía del contenido de los atributos. Por defecto, los valores de los atributos NO se corrigen. (AÚN NO IMPLEMENTADO).
--exclude_elements <lista_de_elementos_excluidos>
Una lista de elementos que no deben ser corregidos ortográficamente.
--include_elements <lista_de_elementos_incluidos>
Una lista de elementos que deben ser corregidos ortográficamente (por defecto, todos los elementos se corrigen).

"--exclude_elements" y "--include_elements" son mutuamente excluyentes.

--pretty_print <estilo_de_formato_opcional>
Un estilo de formato para el documento, tal como se define en XML::Twig. Si la opción se proporciona sin un valor, se utiliza el estilo "indented".
--version
Muestra la versión de la herramienta y sale.
--help
Muestra el mensaje de ayuda y sale.
--man
Muestra un mensaje de ayuda más extenso y sale.
