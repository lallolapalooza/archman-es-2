bibutils - utilidades de conversión de bibliografías

SINOPSIS

formato2xml [OPCIONES] [archivo.formato]

xml2formato [OPCIONES] [archivo.xml]

DESCRIPCIÓN

El conjunto de programas bibutils interconvierte entre varios formatos de bibliografía usando el esquema Metadata Object Description Schema (MODS)[2] versión 3.1 de la Library of Congress[1]. Por ejemplo, se pueden convertir archivos en formato RIS a Bibtex haciendo dos transformaciones: RIS->MODS->Bibtex.

CONVERSIÓN A MODS

Resumen

Comando Descripción
bib2xml convertir bibtex a MODS
biblatex2xml convertir biblatex a MODS
copac2xml convertir referencias en formato COPAC[3] a MODS
ebi2xml convertir EBI XML a MODS
end2xml convertir EndNote (formato Refer) a MODS
endx2xml convertir EndNote XML a MODS
isi2xml convertir ISI web of science a MODS
med2xml convertir referencias XML de Pubmed a MODS
nbib2xml convertir referencias en formato nbib de Pubmed a MODS
modsclean un conversor de MODS a MODS
ris2xml convertir formato RIS a MODS
wordbib2xml convertir bibliografía XML de Word2007 a MODS

Opciones Comunes de Conversión a MODS

Varias banderas disponibles para los programas end2xml, endx2xml, bib2xml, ris2xml, med2xml e isi2xml. La mayoría de las opciones tienen una versión corta y una larga.

-h --help mostrar ayuda
-v --version mostrar versión
-a --add-refcount añadir "_#", donde # es el número de referencia, al ID de la referencia
-s --single-refperfile poner una referencia por archivo llamado por el número de referencia
-i --input-encoding interpretar el archivo de entrada usando el conjunto de caracteres solicitado (usar sin argumento para la lista actual derivada de los conjuntos de caracteres en www.kostis.net[4]) unicode es ahora una opción de conjunto de caracteres
-u --unicode-characters codificar caracteres unicode directamente en el archivo en lugar de como entidades XML
-un --unicode-no-bom igual que -u, pero no incluir una marca de orden de bytes
-x --xml-entities codificar caracteres unicode como entidades XML (opuesto a -u)
-nl --no-latex no convertir combinaciones de caracteres estilo latex
-s --single-refperfile una referencia por archivo de salida
-d --drop-key no poner la clave de citación en el campo id de mods
-c --corporation-file con un argumento que especifica un archivo que contiene una lista de nombres de corporaciones para colocarlos en <name type="corporate"></name> en lugar de type="personal" y eliminar la manipulación de nombres
-a --asis con un argumento que especifica un archivo que contiene una lista de nombres para ser tratados literalmente
-nt --nosplit-title no dividir títulos en pares TÍTULO/SUBTÍTULO
--verbose salida detallada
--debug salida muy detallada (principalmente para depuración)

bib2xml

bib2xml convierte un archivo de referencias en formato bibtex a un archivo intermedio de bibliografía XML. Especifique los archivos a convertir en la línea de comandos. Los archivos que contengan cadenas de sustitución de bibtex deben especificarse antes que los archivos donde se especifican las sustituciones (o en el mismo archivo antes de su uso). Si no se especifican archivos, la información de bibtex se leerá de la entrada estándar.

bib2xml archivo.bib > archivo_salida.xml

biblatex2xml

biblatex2xml convierte un archivo de referencias en formato biblatex (que no debe confundirse con bibtex) a un archivo intermedio de bibliografía XML MODS.

biblatex2xml archivo.bib > archivo_salida.xml

copac2xml

copac2xml convierte un archivo de referencias en formato COPAC a un archivo intermedio de bibliografía XML MODS.

end2xml

end2xml convierte un archivo de referencias en formato de texto endnote a un archivo intermedio de bibliografía XML. Este programa no funcionará con la biblioteca binaria; el archivo debe ser exportado primero. Los formatos etiquetados de Endnote (exportación en formato "Refer") se parecen al Ejemplo 1, “Archivo de ejemplo en formato refer”. Hay instrucciones muy buenas para asegurarse de que está exportando esto correctamente en http://www.sonnysoftware.com/endnoteimport.html[5]

El uso de end2xml es el mismo que el de bib2xml.

end2xml archivo.end > archivo_salida.xml

ebi2xml

ebi2xml convierte un archivo XML de EBI a un archivo intermedio de bibliografía XML MODS.

endx2xml

endx2xml convierte un archivo de referencias exportado en formato EndNote-XML a un archivo intermedio de bibliografía XML MODS. Este programa no funcionará con la biblioteca binaria; el archivo debe ser exportado primero.

isi2xml

isi2xml convierte un archivo de referencias en formato ISI-web-of-science a un archivo intermedio de bibliografía XML.

El uso de isi2xml es el mismo que el de bib2xml.

isi2xml archivo_entrada.isi > archivo_salida.xml

ris2xml

ris2xml convierte un archivo de referencias en formato RIS a un archivo intermedio de bibliografía XML. El uso de ris2xml es como el de end2xml y bib2xml

ris2xml archivo.ris >	archivo_salida.xml

wordbib2xml

wordbib2xml convierte un archivo de referencias en formato Word2007 a un archivo intermedio de bibliografía XML.

MODSCLEAN

modsclean toma un archivo MODS y genera un archivo MODS limpio y consistente. Es particularmente útil después de la conversión automática de varios formatos a MODS.

modsclean input_file.xml > output_file.xml

Las opciones disponibles son las mismas que las de las utilidades xml2*.

Nota que --output-encoding se refiere al archivo de entrada

-h --help mostrar ayuda

-o --output-encoding interpretar el archivo de entrada como usando el conjunto de caracteres solicitado (usar s/argumento para la lista actual derivada de los conjuntos de caracteres en www.kostis.net[4]) unicode es ahora una opción de conjunto de caracteres

-nb --no-bom no escribir Byte Order Mark si se escribe UTF8

xml2bib

xml2bib convierte la bibliografía XML de MODS en un archivo de referencias con formato bibtex. El uso de xml2bib es como para otras herramientas

xml2bib xml_file.xml > output_file.bib

Dado que el formato de referencia BibTeX es bastante flexible y parece tener el mayor número de preferencias personales, también ha acumulado una serie de opciones específicas que no están disponibles para otros formatos.

A partir de la versión 3.24, la salida de xml2bib utiliza etiquetas en minúsculas y tipos de referencia en mayúsculas y minúsculas para una mejor interacción con otro software. El comportamiento anterior con etiquetas/tipos de referencia completamente en mayúsculas todavía se puede generar usando el modificador de línea de comandos -U/--uppercase.

Opciones específicas de xml2bib:

-fc --finalcomma añadir coma final en la salida bibtex para aquellos que la deseen
-sd --singledash usar un guión en lugar de dos (guión más largo en latex) entre números en la salida de páginas
-b --brackets usar corchetes en lugar de comillas alrededor de los datos del campo
-w --whitespace añadir espacios en blanco para embellecer la salida
-U --uppercase usar todas las mayúsculas para etiquetas (nombres de campo) y tipos de referencia (comportamiento anterior a la v3.24)
-sk --strictkey usar solo caracteres alfanuméricos para las claves de citación bibtex

xml2ads

xml2ads convierte la bibliografía XML de MODS al formato de referencia del Smithsonian Astrophysical Observatory (SAO)/National Aeronautics and Space Administration (NASA) Astrophyics Data System o ADS[6] (que es muy similar al estilo Endnote etiquetado). El uso de xml2ads es como para otras herramientas

xml2ads xml_file.xml > output_file.ads

xml2ris

xml2ris convierte la bibliografía XML de MODS a un archivo bibliográfico con formato RIS. El uso de xml2ris es como para otras herramientas

xml2ris xml_file.xml > output_file.ris

xml2end

xml2end convierte la bibliografía XML de MODS a un archivo bibliográfico con formato Endnote etiquetado (refer-format). El uso de xml2end es como para otras herramientas

xml2end xml_file.xml > output_file.end

xml2wordbib

xml2wordbib convierte la bibliografía XML de MODS a un archivo bibliográfico XML con formato Word 2007. El uso de xml2wordbib es como para otras herramientas

xml2wordbib xml_file.xml > output_file.word.xml

xml2wordbib se llamaba xml2word en versiones de bibutils anteriores a la 3.40. Se cambió el nombre para evitar confusiones con otras herramientas. Esperamos que esto no rompa demasiados scripts en uso.
