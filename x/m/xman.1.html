XMAN(1) Manual de Comandos Generales XMAN(1)

NOMBRE

xman - programa de visualización de páginas del manual para el Sistema de Ventanas X

SINOPSIS

xman [ -opciones ... ]

DESCRIPCIÓN

Xman es un navegador de páginas del manual. El tamaño por defecto de la ventana inicial de xman es pequeño para que pueda dejarlo en ejecución durante toda su sesión de inicio de sesión. En la ventana inicial hay tres opciones: Help (Ayuda) mostrará una ventana con ayuda en línea, Quit (Salir) terminará la ejecución, y Manual Page (Página del Manual) mostrará una ventana con un navegador de páginas del manual. Escribir Control-S mostrará una ventana solicitando una página del manual específica para mostrar. Puede mostrar más de una ventana de navegador de páginas del manual a la vez con una sola ejecución de xman.

Para más información sobre el uso de xman, por favor lea la información de ayuda en línea. La mayor parte de este manual discutirá la personalización de xman.

OPCIONES

Xman soporta todos los argumentos de línea de comandos estándar del Toolkit (ver X(7)). Los siguientes argumentos adicionales son soportados.

-archivo-ayuda nombre_archivo
Especifica un archivo de ayuda a usar en lugar del predeterminado.
-ambos-mostrados
Permite que tanto la página del manual como el directorio del manual estén en la pantalla al mismo tiempo.
-sin-caja-superior
Inicia sin el Menú Superior con los tres botones.
-geometria AxA+X+Y
Establece el tamaño y la ubicación del Menú Superior con los tres botones.
-tamano-pagina AxA+X+Y
Establece el tamaño y la ubicación de todas las Páginas del Manual.
-ayuda
Imprime un mensaje de uso y sale.
-version
Imprime la versión del programa y sale.

PERSONALIZANDO XMAN

Xman permite la personalización tanto de los directorios que se buscarán para las páginas del manual, como del nombre al que se mapeará cada directorio en el menú de Secciones. Xman determina qué directorios buscará leyendo la variable de entorno MANPATH. Si no se encuentra MANPATH, entonces se busca el directorio /usr/man en sistemas POSIX. Se espera que esta variable sea una lista de directorios separados por dos puntos para que xman busque.

setenv MANPATH /mit/kit/man:/usr/man

Por defecto, xman buscará en cada uno de los siguientes directorios (dentro de cada uno de los directorios especificados en el MANPATH del usuario) páginas del manual. Si existen páginas del manual en ese directorio, se añaden a la lista de páginas del manual para el elemento de menú correspondiente. Solo se muestra un elemento de menú para aquellas secciones que contienen páginas del manual.

Directorio Nombre de Sección
- -
man1 (1) Comandos de Usuario
man2 (2) Llamadas al Sistema
man3 (3) Subrutinas
man4 (4) Dispositivos
man5 (5) Formatos de Archivo
man6 (6) Juegos
man7 (7) Varios
man8 (8) Administración del Sistema
manl (l) Local
mann (n) Nuevo
mano (o) Antiguo

Por ejemplo, un usuario tiene tres directorios en su ruta manual y cada uno contiene un directorio llamado man3. Todas estas páginas del manual aparecerán ordenadas alfabéticamente cuando el usuario seleccione el elemento de menú llamado (3) Subrutinas. Si no hay un directorio llamado mano en ninguno de los directorios de su MANPATH, o si no hay páginas del manual en ninguno de los directorios llamados mano, entonces no se mostrará ningún elemento de menú para la sección llamada (o) Antiguo.

SISTEMAS BSD Y LINUX

En sistemas BSD y Linux más recientes, Xman buscará un archivo llamado /etc/man.conf que contendrá la lista de directorios que contienen páginas del manual. Ver man.conf(5) para una descripción completa del formato del archivo.

EL ARCHIVO MANDESC

Mediante el uso del archivo mandesc, un usuario o administrador del sistema puede controlar de forma más precisa qué páginas del manual aparecerán en cada una de las secciones representadas por los elementos del menú en el menú Secciones. Esta funcionalidad solo está disponible por sección, y las páginas individuales del manual no pueden ser manejadas de esta manera. (Aunque el uso generoso de enlaces simbólicos — ver ln(1) — permitirá casi cualquier configuración que pueda imaginar.)

El formato del archivo mandesc es un carácter seguido de una etiqueta. El carácter determina qué secciones se añadirán bajo esta etiqueta. Por ejemplo, supongamos que desea crear un elemento de menú adicional que contenga todas las subrutinas del programador. Esta etiqueta debe contener todas las páginas del manual tanto de las secciones dos como tres. El archivo mandesc se vería así:

2Subrutinas del Programador
3Subrutinas del Programador
Esto añadirá un elemento de menú al menú Secciones que mostrará una lista de todas las páginas del manual en las secciones dos y tres del Manual del Programador. Dado que los nombres de las etiquetas son exactamente los mismos, se añadirán a la misma sección. Sin embargo, tenga en cuenta que las secciones originales todavía existen.

Si desea ignorar completamente las secciones predeterminadas en un directorio de manuales, añada la línea:

no secciones predeterminadas
en cualquier lugar de su archivo mandesc. Esto evita que xman busque las secciones de manual predeterminadas solo en ese directorio. Como ejemplo, supongamos que desea hacer lo mismo que arriba, pero no cree que sea útil tener las secciones de Llamadas al Sistema o Subrutinas. Necesitaría duplicar las entradas predeterminadas, además de añadir la suya nueva. 
no secciones predeterminadas
1(1) Comandos de Usuario
2Subrutinas del Programador
3Subrutinas del Programador
4(4) Dispositivos
5(5) Formatos de Archivo
6(6) Juegos
7(7) Varios
8(8) Administración del Sistema
l(l) Local
n(n) Nuevo
o(o) Antiguo
Xman leerá cualquier sección que tenga la forma man<caracter>, donde <caracter> es una letra mayúscula o minúscula (se tratan de forma distinta) o un número (0-9). Sin embargo, tenga en cuenta que man(1) y catman(8) no buscarán directorios que no sean estándar.

RECURSOS DE LA APLICACIÓN

xman tiene los siguientes recursos específicos de la aplicación que permiten personalizaciones únicas para xman.

manualFontNormal (Clase Font)
La fuente a utilizar para texto normal en las páginas del manual.
manualFontBold (Clase Font)
La fuente a utilizar para texto en negrita en las páginas del manual.
manualFontItalic (Clase Font)
La fuente a utilizar para texto en cursiva en las páginas del manual.
directoryFontNormal (Clase Font)
La fuente a utilizar para el texto del directorio.
bothShown (Clase Boolean)
Ya sea 'true' o 'false', especifica si desea que tanto el directorio como la página del manual se muestren al inicio.
directoryHeight (Clase DirectoryHeight)
La altura en píxeles del directorio, cuando el directorio y la página del manual se muestran simultáneamente.
topCursor (Clase Cursor)
El cursor a utilizar en el cuadro superior.
helpCursor (Clase Cursor)
El cursor a utilizar en la ventana de ayuda.
manpageCursor (Clase Cursor)
El cursor a utilizar en la ventana de la página del manual.
searchEntryCursor (Clase Cursor)
El cursor a utilizar en el widget de texto de entrada de búsqueda.
pointerColor (Clase Foreground)
Este es el color de todos los cursores (punteros) especificados anteriormente. El nombre fue elegido para ser compatible con xterm.
helpFile (Clase File)
Usar este archivo en lugar del archivo de ayuda predeterminado del sistema.
topBox (Clase Boolean)
Ya sea 'true' o 'false', determina si el cuadro superior (que contiene los botones de ayuda, salir y página del manual) o una página del manual se muestra en la pantalla al inicio. El valor predeterminado es true.
verticalList (Clase Boolean)
Ya sea 'true' o 'false', determina si la lista del directorio está organizada vertical u horizontalmente. El valor predeterminado es horizontal (false).

ACCIONES GLOBALES

Xman define toda la interacción del usuario a través de acciones globales. Esto permite al usuario modificar la tabla de traducción de cualquier widget y vincular cualquier evento a la nueva acción del usuario. La lista de acciones soportadas por xman son:

GotoPage(página)
Cuando se usa en una ventana de visualización de página del manual, esto permitirá al usuario moverse entre un directorio y una pantalla de página del manual. El argumento página puede ser Directory o ManualPage.
Quit()
Esta acción puede usarse en cualquier lugar y saldrá de xman.
Search(tipo, acción)
Solo es útil cuando se usa en una ventana emergente de búsqueda, esta acción hará que el widget de búsqueda realice el tipo de búsqueda nombrado en la cadena del widget de valor de la ventana emergente de búsqueda. Esta acción también cerrará la ventana emergente de búsqueda. El argumento tipo puede ser Apropos, Manpage o Cancel. Si se especifica una acción de Open, entonces xman abrirá una nueva página del manual para mostrar los resultados de la búsqueda, de lo contrario, xman intentará mostrar los resultados en el padre de la ventana emergente de búsqueda.
PopupHelp()
Esta acción puede usarse en cualquier lugar y mostrará la ventana emergente de ayuda.
PopupSearch()
Esta acción puede usarse en cualquier lugar excepto en una ventana de ayuda. Provocará que la ventana emergente de búsqueda se active y sea visible en la pantalla, permitiendo al usuario buscar una página del manual.
CreateNewManpage()
Esta acción puede usarse en cualquier lugar y creará una nueva ventana de visualización de página del manual.
RemoveThisManpage()
Esta acción puede usarse en cualquier ventana de visualización de página del manual o de ayuda. Cuando se llama, eliminará la ventana y limpiará todos los recursos asociados a ella.
SaveFormattedPage(acción)
Esta acción solo puede usarse en el widget emergente likeToSave, y le dice a xman si debe Guardar o Cancelar el guardado de la página del manual que acaba de ser formateada.
ShowVersion()
Esta acción puede llamarse desde cualquier ventana de visualización de página del manual o de ayuda, y hará que la línea de visualización de información muestre la versión actual de xman.

APPLICATION RESOURCES

These resources are used to customize the look and feel of xman. The default values are set by the application. For a full list of resources, refer to the XMAN RESOURCES file.

XtNdisplay
The X display to use. This is typically set in the .Xdefaults file or via the command-line argument -display.
XtNfont
The font to use for displaying text. This can be a
XtNgeometry
The initial geometry for the xman window. This can be set using the -geometry command-line argument.
XtNiconPixmap
The pixmap to use for the icon. This can be set using the -iconPixmap command-line argument.
XtNtitle
The title for the xman window. This can be set using the -title command-line argument.

GLOBAL ACTIONS

These actions are available globally and can be bound to key or mouse events. They are defined in the .Xdefaults file.

Find
Searches for a man page. This action takes one argument: the name of the man page to search for.
Help
Displays the help message.
Quit
Exits xman.
View
Displays a man page. This action takes one argument: the name of the man page to display.

FILES

/
.Xdefaults: User-specific application resources.
/
.xman: User-specific xman configuration file.
/
/etc/X11/app-defaults/Xman: System-wide application resources.
/
/usr/share/man: Standard location for man pages.

The app-defaults file is read first, followed by the user's .Xdefaults file. This allows users to override system-wide defaults.

The .xman file is an optional file that can be used to specify custom configurations for xman, such as preferred man page directories or default search paths.

The system app-defaults file should be merged into the resource database after the user's app-defaults file, and before the resources that are attached to the display.
