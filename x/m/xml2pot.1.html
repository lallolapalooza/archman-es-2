NOMBRE

xml2pot - Crea un archivo de plantilla PO desde un archivo XML DocBook.

SINOPSIS

xml2pot [original-XML]

DESCRIPCIÓN

xml2pot es una herramienta de línea de comandos que produce un archivo de plantilla de mensajes gettext a partir del archivo XML DocBook original-XML. El archivo de plantilla se envía a la salida estándar.

El archivo de plantilla resultante se puede utilizar para crear archivos de mensajes gettext (archivos PO) para una variedad de idiomas. Estos se pueden usar junto con po2xml(1) para traducir el archivo XML original a estos otros idiomas.

Esta utilidad forma parte del Kit de Desarrollo de Software de KDE.

VER TAMBIÉN

po2xml(1), split2po(1), swappo(1)
