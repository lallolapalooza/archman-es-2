XMMS2(1) Manual de Comandos Generales XMMS2(1)

NOMBRE

xmms2 - La interfaz de línea de comandos oficial de XMMS2

SINOPSIS

xmms2 [comando] [argumentos]
xmms2 ayuda [comando]

DESCRIPCIÓN

XMMS2 es un rediseño del reproductor de música XMMS (https://en.wikipedia.org/wiki/XMMS). Presenta un modelo cliente-servidor, que permite múltiples interfaces de usuario (incluso simultáneas), tanto textuales como gráficas. Todos los formatos de audio comunes son compatibles mediante plugins. Además de esto, hay una biblioteca multimedia flexible para organizar tu música.

xmms2 es el cliente CLI oficial de XMMS2.

INVOCACIÓN

Modo en línea

Si a xmms2 se le pasa un comando como argumento, ese comando se interpretará y xmms2 saldrá después de que haya terminado.

Modo interactivo

xmms2 presenta un potente entorno similar a un shell a través de readline que permite al usuario ingresar comandos en un prompt y tener las características geniales habituales como la expansión de nombres de ruta y la edición de línea.

COMANDOS

Todos los comandos aceptan la opción -h/--help que muestra la ayuda del comando.

patrón se refiere a una definición de colección. (Ver PATRÓN abajo).

posición es un patrón para coincidir con posiciones en la lista de reproducción. Cuando está ausente en un comando, el valor predeterminado es el final de la lista de reproducción. (Ver PATRÓN DE POSICIÓN abajo).

Comandos generales

add [ -f [-N] [-P] [-A clave=valor]... ] [-p lista_reproduccion] [-n | -a posición] [-o prop[,...]] [-j] argumentos...
add [-p lista_reproduccion] [-n | -a posición] [-o prop[,...]] [-j] patrón...

Agrega medios a una lista de reproducción. Intentará adivinar si argumentos constituyen un patrón o representan rutas de archivo. Este comportamiento se puede anular forzando el tipo con -f y -t. Si las rutas de archivo contienen caracteres * o ?, intentará expandirlos. Si no se encuentra una coincidencia, se intentará agregar los caracteres * y ? como parte de la URL.
-f, --file
Forzar el tratamiento de argumentos como rutas de archivo.
-P, --pls
Forzar el tratamiento de argumentos como archivos de lista de reproducción. Esta opción implica -f.
-t, --pattern
Forzar el tratamiento de argumentos como un patrón.
-N, --non-recursive
No agregar directorios recursivamente.
-p, --playlist lista_reproduccion
Agregar medios a lista_reproduccion en lugar de la lista de reproducción activa.
-n, --next
Agregar medios después de la pista actual.
-a, --at posición
Agregar medios en la posición dada.
-A, --attribute clave=valor
Agregar medios con el atributo clave=valor dado. Puede ocurrir varias veces. Solo válido al agregar nuevos archivos a la biblioteca multimedia.
-o, --order prop[,...]
Agregar medios ordenados por la lista separada por comas de propiedades dadas. Si una propiedad está prefijada con -, los medios se ordenan en orden inverso según esa propiedad.
-j, --jump
Saltar y comenzar a reproducir los medios recién agregados.
salir
Salir de la interfaz similar a un shell.
ayuda [-a] comando
Mostrar la ayuda sobre comando. Esto es equivalente a comando -h. Si comando es un alias, mostrar la definición del alias. Si no se proporciona ningún comando, listar todos los comandos disponibles.
-a, --alias
Listar alias disponibles si comando no se proporciona. De lo contrario, no tiene efecto.
info [patrón | posiciones...]
Mostrar las propiedades de todos los medios que coinciden con patrón o en las posiciones dadas. Sin argumento, mostrar las propiedades de la pista actual.
saltar [-b] patrón|posición
Saltar a los primeros medios que coinciden con patrón o a la posición dada.
-b, --backward
Saltar hacia atrás a los primeros medios que coinciden con el patrón.
listar [-p nombre] [patrón | posiciones...]
Listar el contenido de una lista de reproducción (la activa por defecto). Si se proporciona patrón, el contenido se filtra aún más y solo se muestran los medios coincidentes.
-p, --playlist
Listar lista_reproduccion, en lugar de la lista de reproducción activa.
mover [-p lista_reproduccion] [-n | -a posición] patrón | posiciones...
Mover entradas dentro de una lista de reproducción (la activa por defecto).
-p, --playlist lista_reproduccion
La lista_reproduccion sobre la que actuar.
-n, --next
Mover las pistas coincidentes después de la pista actual.
-a, --at posición
Mover las pistas coincidentes por un desplazamiento o a una posición.
siguiente [desplazamiento]
Saltar a la siguiente canción. Si se proporciona desplazamiento, actúa como saltar +desplazamiento.
pausar
Pausar la reproducción.
tocar
Iniciar la reproducción.
anterior [desplazamiento]
Saltar a la canción anterior. Si se proporciona desplazamiento, actúa como saltar -desplazamiento.
eliminar [-p lista_reproduccion] patrón | posiciones...
Eliminar los medios coincidentes de una lista de reproducción (la activa por defecto).
-p, --playlist lista_reproduccion
Eliminar de lista_reproduccion, en lugar de la lista de reproducción activa.
actual [-r segundos] [-f formato]
Mostrar el estado de la reproducción, ya sea de forma continua o única.
-r, --refresh segundos
Establecer el retraso, en segundos, entre cada actualización de los metadatos de reproducción actuales. Si es 0, los metadatos solo se imprimen una vez (por defecto) y el comando sale inmediatamente. Cuando está en modo de actualización, se proporciona control básico sobre la lista de reproducción activa.
-f, --format formato
Establecer la cadena de formato utilizada para mostrar la información de estado, en lugar de la del archivo de configuración (ver CADENA DE FORMATO abajo).
buscar [-o prop1[,prop2...]] [-l prop1[,prop2...] ] patrón
Buscar y
Imprime todos los medios que coincidan con patrón.
-o, --order prop1[,prop2...]
Muestra los resultados de la búsqueda ordenados por la lista dada de propiedades. Si una propiedad va precedida por '-', los resultados se ordenarán en orden inverso para esa propiedad.
-l, --columns prop1[,prop2...]
Lista de propiedades a usar como columnas.
seek tiempo | offset
Salta a un tiempo relativo o absoluto en la pista actual.
stop
Detiene la reproducción.
toggle
Alterna la reproducción (iniciar/detener).

Comandos de Lista de Reproducción

playlist clear [lista_de_reproduccion]
Borra una lista de reproducción. Por defecto, borra la lista de reproducción activa.
playlist config [-t tipo] [-s historial] [-u proximos] [-i coleccion] [-j lista_de_reproduccion] [lista_de_reproduccion]
Configura una lista de reproducción cambiando su tipo, atributos, etc. Por defecto, configura la lista de reproducción activa.
-t, --type tipo
Cambia el tipo de la lista de reproducción: list (lista), queue (cola), pshuffle (reproducción aleatoria con reproducción prioritaria).
-s, --history tamaño
El tamaño del historial de pistas reproducidas (para cola, reproducción aleatoria con reproducción prioritaria).
-u, --upcoming proximos
Número de pistas próximas a mantener (para reproducción aleatoria con reproducción prioritaria).
-i, --input coleccion
Colección de entrada para la lista de reproducción (para reproducción aleatoria con reproducción prioritaria). Por defecto es 'All Media' (Todos los Medios).
-j, --jumplist lista_de_reproduccion
Salta a otra lista de reproducción al llegar al final de la lista actual.
playlist create [-s] [-p lista_de_reproduccion] nombre
Crea una nueva lista de reproducción.
-s, --switch
Cambia a la lista de reproducción recién creada.
-p, --playlist lista_de_reproduccion
Copia el contenido de la lista de reproducción especificada en la nueva lista de reproducción.
playlist list [-a]
Lista todas las listas de reproducción.
-a, --all
Incluye listas de reproducción ocultas.
playlist remove lista_de_reproduccion
Elimina la lista de reproducción especificada.
playlist rename [-f] [-p lista_de_reproduccion] nuevonombre
Renombra una lista de reproducción. Por defecto, renombra la lista de reproducción activa.
-f, --force
Fuerza el renombrado de la lista de reproducción, sobrescribiendo una lista existente si es necesario.
-p, --playlist
Renombra la lista de reproducción especificada.
playlist shuffle [lista_de_reproduccion]
Mezcla una lista de reproducción. Por defecto, mezcla la lista de reproducción activa.
playlist sort [-p lista_de_reproduccion] [prop] ...
Ordena una lista de reproducción. Por defecto, ordena la lista de reproducción activa. Anteponer '-' a las propiedades para ordenar en orden inverso. Si no se especifican propiedades, la lista de reproducción se ordena por artista, álbum y número de pista.
-p, --playlist
Renombra la lista de reproducción especificada.
playlist switch lista_de_reproduccion
Cambia la lista de reproducción activa.

Comandos de Colección

collection config coleccion [nombre_atributo [valor_atributo]]
Obtiene o establece atributos para la colección dada. Si no se proporciona un nombre de atributo, lista todos los atributos. Si solo se proporciona un nombre de atributo, muestra el valor del atributo. Si se proporcionan tanto el nombre del atributo como el valor, establece el nuevo valor del atributo.
collection create [-f] [-e] [-c coleccion] nombre [patron]
Crea una nueva colección. Si se proporciona un patrón, se utiliza para definir la colección. De lo contrario, la nueva colección contendrá toda la biblioteca de medios.
-f, --force
Fuerza la creación de la colección, sobrescribiendo una colección existente si es necesario.
-c, --collection coleccion
Copia una colección existente a la nueva colección.
-e, --empty
Inicializa una colección vacía.
collection list
Lista todas las colecciones.
collection show coleccion
Muestra una descripción legible por humanos de una colección.
collection remove coleccion
Elimina una colección.
collection rename [-f] nombreantiguo nombrenuevo
Renombra una colección.
-f, --force
Fuerza el renombrado de la colección, sobrescribiendo una colección existente si es necesario.

Comandos del Servidor

server browse URL
Navega por una URL a través de los plugins xform disponibles en el demonio.
server config [nombre [valor]]
Obtiene o establece valores de configuración. Si no se proporcionan nombre ni valor, lista todos los valores de configuración. Si solo se proporciona un nombre, muestra el contenido del valor de configuración correspondiente. Si se proporcionan tanto el nombre como un valor, establece el nuevo contenido del valor de configuración.

El nombre del valor de configuración está sujeto a la expansión de comodines del shell para que se puedan consultar (pero no establecer) varios valores a la vez.

server import [-N] ruta
Importa nuevos archivos a la biblioteca de medios. Por defecto, los directorios se importan recursivamente.
-N, --non-recursive
No importar directorios recursivamente.
server plugins
Lista los plugins cargados en el servidor.
server property [-i | -s | -D] [-S] mid [nombre [valor]]
Obtiene o establece propiedades para un medio dado. Si no se proporcionan nombre ni valor, lista todas las propiedades. Si solo se proporciona un nombre, muestra el valor de la propiedad. Si se proporcionan tanto un nombre como un valor, establece el nuevo valor de la propiedad.

Por defecto, las operaciones de establecimiento utilizan la fuente "client/xmms2-cli", mientras que las operaciones de listado y visualización utilizan la preferencia de fuente. Usa la opción --source para anular este comportamiento.

Por defecto, el valor se utilizará para determinar si debe guardarse como cadena o entero. Usa el indicador --int o --string para anular este comportamiento.

-i, --int
Fuerza a que el valor se trate como un entero.
-s, --string
Fuerza a que el valor se trate como una cadena.
-D, --delete
Elimina la propiedad seleccionada.
-S, --source
Fuente de la propiedad.
server rehash [patron]
Vuelve a procesar los medios que coincidan con el patrón, o toda la biblioteca de medios si no se proporciona ningún patrón.
server remove [patron]
Elimina los medios coincidentes de la biblioteca de medios.
server shutdown
Apaga el servidor.
server stats
Muestra estadísticas sobre el servidor: tiempo de actividad, versión, tamaño de la biblioteca de medios, etc.
server sync
Guarda inmediatamente las colecciones en disco. (De lo contrario, solo se realiza al apagar o 10 segundos después del último cambio en las colecciones.)
servidor volumen [-c nombre] [valor]
Obtiene o establece el volumen de audio (en un rango de 0-100). Si se proporciona un valor, establece el volumen a valor. De lo contrario, muestra el volumen actual. Por defecto, el comando se aplica a todos los canales de audio. Utilice la opción --canal para anular este comportamiento. Son posibles cambios relativos en el volumen anteponiendo valor con + o -.
-c, --canal
Obtiene o establece el volumen solo para el canal nombrado.

PATRÓN

Los patrones se utilizan para buscar canciones en la biblioteca de medios; algunos de estos patrones pueden requerir escape (con '\') dependiendo de la shell utilizada. Las propiedades se pueden encontrar en la salida de xmms2 info.

<propiedad>:<cadena>
Coincide con canciones cuya propiedad coincide con la cadena. Un ? en la cadena indica un único carácter comodín, y un * indica múltiples caracteres comodín.
<propiedad>~<cadena>
Coincide con canciones cuya propiedad coincide de forma aproximada con la cadena. Equivalente a coincidir con <propiedad>:*<cadena>*.
<propiedad><operación><número>
La operación puede ser <, <=, > o >=; el patrón coincidirá con canciones cuya propiedad sea un valor numérico menor, menor o igual, mayor, mayor o igual en comparación con el número.
+<propiedad>
Coincide con canciones que tienen la propiedad.
en:<espacio de nombres>/<colección>
Coincide con canciones de la colección dada. El espacio de nombres puede ser Listas de reproducción o Colecciones.
NO <patrón>
Coincide con el complemento del patrón.

<patrón> <patrón>
<patrón> Y <patrón>

Coincide con canciones que coinciden con ambos patrones.
<patrón> O <patrón>
Coincide con canciones que coinciden con al menos uno de los dos patrones.
( <patrón> )
Coincide con canciones que coinciden con el patrón, utilizado para agrupar coincidencias Y y O.
<cadena>
Coincide con canciones cuyos artista, título o álbum coinciden con la cadena.
~<cadena>
Coincide con canciones cuyos artista, título o álbum coinciden de forma aproximada con la cadena.
#<número>
Coincide con un ID específico de la biblioteca de medios.

PATRÓN DE POSICIÓN

Los patrones de posición se utilizan junto con comandos que operan sobre el contenido de las listas de reproducción.

M_N
Selecciona entradas de la lista de reproducción que van desde M posiciones antes de la canción actual hasta N posiciones después. Tanto M como N pueden omitirse y, en ese caso, por defecto serán 0.
-N
Selecciona la canción N posiciones antes de la canción actual.
+N
Selecciona la canción N posiciones después de la canción actual.
pos0,pos1,...,posN
Selecciona una o más posiciones de la lista de reproducción.

CADENA DE FORMATO

Los comandos que generan metadatos formateados se pueden personalizar con la ayuda de cadenas de formato definidas por el usuario, como las siguientes:

´${artista} - ${título}´

Cuando se pasan metadatos, el nombre del artista y el título se insertarán en la cadena resultante. Además de los metadatos proporcionados por la biblioteca de medios, también están disponibles las siguientes propiedades:

posición
La posición actual de la lista de reproducción.
estado_reproduccion
El estado de reproducción como una cadena (Detenido, Reproduciendo, Pausado, Desconocido).
tiempo_reproduccion
El tiempo de reproducción de la canción que se está reproduciendo actualmente.
duración
La duración de la canción actual, en formato minutos:segundos con ceros iniciales
minutos
La parte de minutos, con ceros iniciales, de la duración de la canción actual.
segundos
La parte de segundos, con ceros iniciales, de la duración de la canción actual.

ALIAS

Una lista de alias de comandos se lee del archivo de configuración en la sección [alias] en tiempo de ejecución. La sintaxis de los alias de xmms2 es algo similar a la de bash y otras shells. Un alias se define mediante una lista de comandos y argumentos separados por punto y coma. La expansión de parámetros es compatible (consulte Expansión más abajo).

La configuración predeterminada incluye los siguientes alias:
addpls
add -f -P $@
clear
playlist clear
status
current -f $1
ls
list
mute
servidor volumen 0
quit
servidor shutdown
repeat
seek 0
scap
stop ; playlist clear ; add $@ ; play

Expansión

Parámetros Posicionales

Un alias puede usar parámetros posicionales, por ejemplo:

foo = add -f $1 $3

foo ctkoz.ogg and slre.ogg

Resultará en:

add -f ctkoz.ogg slre.ogg

Parámetros Especiales

$@
Esto se expande a todos los parámetros pasados al alias.

CONFIGURACIÓN

Todos los caracteres de control se interpretan según lo esperado, incluidas las secuencias de escape ANSI.

AUTO_UNIQUE_COMPLETE

Booleano, completa una abreviatura de un comando y sus argumentos. Por ejemplo: `serv vol 42' se completará a `servidor volumen 42'. (Nota: las abreviaturas deben ser inequívocas)

CLASSIC_LIST

Booleano, formatea la salida de list de manera similar a la CLI clásica.

CLASSIC_LIST_FORMAT

Cadena para formatear la salida de list clásica.

GUESS_PLS

Booleano, intenta adivinar si la URL es una lista de reproducción y la agrega en consecuencia. (No fiable)

HISTORY_FILE

Archivo donde guardar el historial de comandos.

PLAYLIST_MARKER

Cadena a utilizar para marcar la entrada activa actual en la lista de reproducción.

PROMPT

Cadena a utilizar como prompt en el MODO INTERACTIVO.

SERVER_AUTOSTART

Booleano, si es verdadero, xmms2 intentará iniciar xmms2d(1) si aún no se está ejecutando.

SHELL_START_MESSAGE

Booleano, si es verdadero, xmms2 mostrará un mensaje de bienvenida y ayuda básica al iniciarse en MODO INTERACTIVO.

STATUS_FORMAT

Cadena para formatear la salida de status.

ARCHIVOS

$XDG_CACHE_HOME/xmms2/nyxmms2_history

Archivo de historial de comandos predeterminado si HISTORY_FILE está sin definir.

$XDG_CONFIG_HOME/xmms2/clients/nycli.conf

El archivo de configuración para xmms2.
