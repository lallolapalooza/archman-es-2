xml_grep(1p)

Paquete: perl-xml-twig

Licencias: GPL, PerlArtistic

XML_GREP(1) Documentación de Perl de Contribución de Usuarios XML_GREP(1)

NOMBRE

xml_grep - busca en archivos XML buscando elementos específicos

SINOPSIS

xml_grep [opciones] <lista de archivos>

o

xml_grep <expresión xpath> <lista de archivos>

Por defecto, puedes simplemente darle a "xml_grep" una expresión XPath y una lista de archivos, y obtener un archivo XML con el resultado.

Esto es equivalente a escribir

xml_grep --group_by_file file --pretty_print indented --cond <lista de archivos>

OPCIONES

--help
mensaje de ayuda breve
--man
documentación completa
--Version
muestra la versión de la herramienta
--root <cond>
busca y devuelve fragmentos de XML que coincidan con <cond>

si no se utilizan ni "--root" ni "--file", se utilizan los elementos que activan la opción "--cond". Si "--cond" no se utiliza, se devuelven todos los elementos que coinciden con el <cond>.

se pueden proporcionar varios "--root".

--cond <cond>
devuelve los fragmentos (o nombres de archivo) solo si contienen elementos que coinciden con <cond>

se pueden proporcionar varios "--cond" (en cuyo caso se combinan con OR).

--files
devuelve solo nombres de archivo (no genera salida XML)

el uso de esta opción excluye el uso de cualquiera de las opciones que definen la salida XML: "--roots", "--encoding", "--wrap", "--group_by_file" o "--pretty_print".

--count
devuelve solo el número de coincidencias en cada archivo

el uso de esta opción excluye el uso de cualquiera de las opciones que definen la salida XML: "--roots", "--encoding", "--wrap", "--group_by_file" o "--pretty_print".

--strict
sin esta opción, los errores de análisis se informan en STDOUT y el archivo se omite
--date
cuando está activada (por defecto), el elemento envolvente recibe un atributo "date" que indica la fecha en que se ejecutó la herramienta.

con "--nodate" este atributo no se añade, lo que puede ser útil si necesitas comparar 2 ejecuciones.

--encoding <enc>
codificación de la salida xml (utf-8 por defecto)
--nb_results <nb>
salida de solo <nb> resultados
--by_file
salida de solo <nb> resultados por archivo
--wrap <tag>
envuelve el resultado XML en la etiqueta proporcionada (por defecto es 'xml_grep')

Si wrap se establece en una cadena vacía ("--wrap ''"), entonces el resultado XML no se envuelve en absoluto.

--nowrap
igual que usar "--wrap ''": el resultado XML no se envuelve.
--descr <string>
atributos de la etiqueta de envoltura (por defecto es "version="<VERSION>" date="<date>"")
--group_by_file <etiqueta_opcional>
envuelve los resultados para cada archivo en un elemento separado. Por defecto, ese elemento se llama "file". Tiene un atributo llamado "filename" que indica el nombre del archivo.

la versión corta de esta opción es -g

--exclude <condición>
igual que usar "-v" en grep: los elementos que coinciden con la condición se excluyen del resultado, el(los) archivo(s) de entrada no se ven afectados

la forma corta de esta opción es -v

--pretty_print <estilo_opcional>
imprime bonito la salida utilizando los estilos de XML::Twig ('"indented"', '"record"' o '"record_c"' son probablemente lo que estás buscando)

si se utiliza la opción pero no se proporciona ningún estilo, se utiliza '"indented"'

la forma corta para este argumento es -s

--text_only
Muestra el texto de los resultados, uno por línea.
--html
Permite entrada HTML, los archivos se convierten usando HTML::TreeBuilder
--Tidy
Permite entrada HTML, los archivos se convierten usando HTML::Tidy

Sintaxis de Condición

<cond> es una expresión similar a XPath que permite XML::Twig para activar manejadores.

ejemplos:
'para'
'para[@compact="compact"]'
'*[@urgent]'
'*[@urgent="1"]'
'para[string()="WARNING"]'

consulta XML::Twig para una descripción más completa de la sintaxis de <cond>

las opciones son procesadas por Getopt::Long, por lo que pueden comenzar con '-' o '--' y pueden abreviarse ("-r" en lugar de "--root", por ejemplo)

DESCRIPCIÓN

xml_grep realiza una búsqueda en archivos XML. En lugar de usar expresiones regulares, usa expresiones XPath (de hecho, el subconjunto de XPath soportado por XML::Twig).

los resultados pueden ser los nombres de los archivos o elementos XML que contienen elementos coincidentes.

VER TAMBIÉN

XML::Twig Getopt::Long
