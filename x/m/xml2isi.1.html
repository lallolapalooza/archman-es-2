bibutils, bib2xml, biblatex2xml, copac2xml, ebi2xml, end2xml, endx2xml, isi2xml, med2xml, modsclean, nbib2xml, ris2xml, wordbib2xml, xml2ads, xml2bib, xml2biblatex, xml2end, xml2isi, xml2nbib, xml2ris, xml2wordbib - utilidades de conversión de bibliografía
bibutils - utilidades de conversión de bibliografía

SINOPSIS

formato2xml [OPCIONES] [archivo.formato]

xml2formato [OPCIONES] [archivo.xml]

DESCRIPCIÓN

El conjunto de programas bibutils interconecta varios formatos de bibliografía utilizando el Metadata Object Description Schema (MODS)[2]versión 3.1 de la Library of Congress[1]. Por ejemplo, se puede convertir archivos en formato RIS a Bibtex realizando dos transformaciones: RIS->MODS->Bibtex.

CONVERSIÓN A MODS

Descripción general

Comando Descripción
bib2xml convierte bibtex a MODS
biblatex2xml convierte biblatex a MODS
copac2xml convierte referencias en formato COPAC[3] a MODS
ebi2xml convierte EBI XML a MODS
end2xml convierte EndNote (formato Refer) a MODS
endx2xml convierte EndNote XML a MODS
isi2xml convierte ISI web of science a MODS
med2xml convierte referencias XML de Pubmed a MODS
nbib2xml convierte referencias en formato nbib de Pubmed a MODS
modsclean un conversor de MODS a MODS
ris2xml convierte formato RIS a MODS
wordbib2xml convierte bibliografía XML de Word2007 a MODS

Opciones comunes para la conversión a MODS

Varios indicadores disponibles para los programas end2xml, endx2xml, bib2xml, ris2xml, med2xml y copac2xml. La mayoría de las opciones tienen una versión corta y una larga.

-h --help muestra la ayuda
-v --version muestra la versión
-a --add-refcount añade "_#", donde # es el número de referencias, al ID de referencia
-s --single-refperfile pon una referencia por archivo con el número de referencia
-i --input-encoding interpreta el archivo de entrada usando el conjunto de caracteres solicitado (úsalo sin argumento para la lista actual derivada de los conjuntos de caracteres en www.kostis.net[4]) unicode es ahora una opción de conjunto de caracteres
-u --unicode-characters codifica caracteres unicode directamente en el archivo en lugar de como entidades XML
-un --unicode-no-bom igual que -u, pero sin incluir una marca de orden de bytes
-x --xml-entities codifica caracteres unicode como entidades XML (lo opuesto a -u)
-nl --no-latex no convierte combinaciones de caracteres estilo latex
-s --single-refperfile una referencia por archivo de salida
-d --drop-key no pongas la clave de citación en el campo ID de mods
-c --corporation-file con argumento que especifica un archivo que contiene una lista de nombres de corporaciones a colocar en <name type="corporate"></name> en lugar de type="personal" y elimina la manipulación de nombres
-a --asis con argumento que especifica un archivo que contiene una lista de nombres a tratar literalmente
-nt --nosplit-title no dividas los títulos en pares TÍTULO/SUBTÍTULO
--verbose salida detallada
--debug salida muy detallada (principalmente para depuración)

bib2xml

bib2xml convierte un archivo de referencias en formato bibtex a un archivo de bibliografía intermedio en XML. Especifica los archivos a convertir en la línea de comandos. Los archivos que contienen cadenas de sustitución de bibtex deben especificarse antes que los archivos donde se especifican las sustituciones (o en el mismo archivo antes de su uso). Si no se especifican archivos, la información de bibtex se leerá de la entrada estándar.

bib2xml archivo.bib > archivo_salida.xml

biblatex2xml

biblatex2xml convierte un archivo de referencias en formato biblatex (no confundir con bibtex) a un archivo de bibliografía intermedio en MODS XML.

biblatex2xml archivo.bib > archivo_salida.xml

copac2xml

copac2xmlconvierte un archivo de referencias en formato COPAC a un archivo de bibliografía intermedio en MODS XML.

end2xml

end2xml convierte un archivo de referencias en formato endnote de texto a un archivo de bibliografía intermedio en XML. Este programa no funcionará en la biblioteca binaria; el archivo debe ser exportado primero. Los formatos etiquetados de Endnote (exportación en formato "Refer") se parecen al Ejemplo 1, “Archivo de ejemplo en formato refer”. Hay instrucciones muy buenas para asegurarse de que se está exportando correctamente en http://www.sonnysoftware.com/endnoteimport.html[5]

El uso de end2xml es el mismo que el de bib2xml.

end2xml archivo.end > archivo_salida.xml

ebi2xml

ebi2xml convierte un archivo EBI XML a un archivo de bibliografía intermedio en MODS XML.

endx2xml

endx2xml convierte un archivo exportado de EndNote-XML de referencias a un archivo de bibliografía intermedio en MODS XML. Este programa no funcionará en la biblioteca binaria; el archivo debe ser exportado primero.

isi2xml

isi2xml convierte un archivo de referencias en formato ISI-web-of-science a un archivo de bibliografía intermedio en XML.

El uso de isi2xml es el mismo que el de bib2xml.

isi2xml archivo_entrada.isi > archivo_salida.xml

ris2xml

ris2xml convierte un archivo de referencias en formato RIS a un archivo de bibliografía intermedio en XML. El uso de ris2xml es como el de end2xml y bib2xml

ris2xml archivo.ris >	archivo_salida.xml

wordbib2xml

wordbib2xml convierte un archivo de referencias en formato Word2007 a un archivo de bibliografía intermedio en XML.

CONVERSIÓN DESDE MODS

Descripción general

Comando Descripción
xml2ads convierte MODS al formato SAO/NASA ADS
xml2bib convierte MODS a bibtex
xml2end convierte MODS al formato para EndNote
xml2isi convierte MODS a formato ISI
xml2ris convierte MODS a formato RIS
xml2wordbib convierte MODS a formato de bibliografía de Word 2007

Opciones comunes al convertir desde MODS

Tenga en cuenta que --output-encoding se refiere al archivo de entrada

-h --help mostrar ayuda
-v --version mostrar versión
-o --output-encoding interpretar el archivo de entrada como si usara el conjunto de caracteres solicitado (usar sin argumento para la lista actual derivada de los conjuntos de caracteres en www.kostis.net[4]) unicode es ahora una opción de conjunto de caracteres
-s --single-refperfile poner una referencia por nombre de archivo según el número de referencia
-nb --no-bom no escribir Byte Order Mark si se escribe UTF8

xml2bib

xml2bib convierte la bibliografía XML MODS en un archivo de referencias con formato bibtex. El uso de xml2bib es como para otras herramientas

xml2bib archivo_xml.xml > archivo_salida.bib

Dado que el formato de referencia BibTeX es bastante flexible y parece tener la mayor cantidad de preferencias personales, también ha acumulado una serie de opciones específicas que no están disponibles para otros formatos.

A partir de la versión 3.24, la salida de xml2bib utiliza etiquetas en minúsculas y tipos de referencia en mayúsculas y minúsculas para una mejor interacción con otro software. El comportamiento anterior con etiquetas/tipos de referencia completamente en mayúsculas todavía se puede generar utilizando el modificador de línea de comandos -U/--uppercase.

Opciones específicas de xml2bib:

-fc --finalcomma agregar coma final en la salida bibtex para aquellos que la deseen
-sd --singledash usar un guión en lugar de dos (guión más largo en latex) entre números en la salida de páginas
-b --brackets usar corchetes en lugar de comillas alrededor de los datos del campo
-w --whitespace agregar espacio en blanco para embellecer la salida
-U --uppercase usar todas las mayúsculas para las etiquetas (nombres de campo) y tipos de referencia (comportamiento anterior a la versión 3.24)
-sk --strictkey usar solo caracteres alfanuméricos para las claves de citación bibtex

xml2ads

xml2ads convierte la bibliografía XML MODS al formato de referencia del Smithsonian Astrophysical Observatory (SAO)/National Aeronautics and Space Administration (NASA) Astrophyics Data System o ADS[6] (que es muy similar al estilo Endnote etiquetado). El uso de xml2ads es como para otras herramientas

xml2ads archivo_xml.xml > archivo_salida.ads

xml2ris

xml2ris convierte la bibliografía XML MODS a un archivo bibliográfico con formato RIS. El uso de xml2ris es como para otras herramientas

xml2ris archivo_xml.xml > archivo_salida.ris

xml2end

xml2end convierte la bibliografía XML MODS a un archivo bibliográfico con formato Endnote etiquetado (refer-format). El uso de xml2end es como para otras herramientas

xml2end archivo_xml.xml > archivo_salida.end

xml2wordbib

xml2wordbib convierte la bibliografía XML MODS a un archivo bibliográfico XML con formato Word 2007. El uso de xml2wordbib es como para otras herramientas

xml2wordbib archivo_xml.xml > archivo_salida.word.xml

xml2wordbib se llamaba xml2word en versiones de bibutils anteriores a la 3.40. Se cambió de nombre para evitar confusiones con otras herramientas. Esperemos que esto no rompa demasiados scripts ya en uso.

Ejemplo 1. Ejemplo de archivo de formato de referencia

%0 Artículo de revista
%A C. D. Putnam
%A C. S. Pikaard
%D 1992
%T Cooperative binding of the Xenopus RNA polymerase I
   transcription factor xUBF to repetitive ribosomal gene enhancers
%J Mol Cell Biol
%V 12
%P 4970-4980
%F Putnam1992
