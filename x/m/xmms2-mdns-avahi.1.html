NOMBRE

xmms2-mdns-avahi - anuncia XMMS2 a través de mDNS

SINOPSIS

xmms2-mdns-avahi

DESCRIPCIÓN

XMMS2 es un rediseño del reproductor de música XMMS (https://github.com/xmms2). Presenta un modelo cliente-servidor, que permite múltiples interfaces de usuario (incluso simultáneas), tanto textuales como gráficas. Todos los formatos de audio comunes son compatibles mediante plugins. Además de esto, hay una biblioteca de medios flexible para organizar tu música.

xmms2-mdns-avahi es el cliente de anuncio mDNS de Avahi para XMMS2. xmms2-mdns-avahi está diseñado para anunciar la presencia de un socket TCP XMMS2 accesible si hay uno disponible.

xmms2-mdns-avahi ofrece un servicio _xmms2._tcp si, y solo si, la variable de entorno XMMS_PATH_FULL contiene un socket TCP. Esto permite que los clientes que soportan el descubrimiento mDNS localicen y se conecten fácilmente a esta instancia de xmms2d(1).

VARIABLES DE ENTORNO

XMMS_PATH_FULL
Una lista completa de rutas de URL separadas por ';' apuntando al xmms2d(1). Consulte **IPC SOCKET** en xmms2d(1) para obtener detalles sobre los posibles valores de esta variable.
