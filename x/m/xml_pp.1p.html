NOMBRE

xml_pp - formateador de XML elegante

SINOPSIS

xml_pp [opciones] [<archivos>]

DESCRIPCIÓN

Formateador de XML elegante que utiliza XML::Twig

OPCIONES

-i[<extensión>]
edita los archivos en el lugar, si se proporciona una extensión (sin espacio entre "-i" y la extensión), el archivo original se respalda con esa extensión.

Las reglas para la extensión son las mismas que las de Perl (ver perldoc perlrun): si la extensión no contiene ningún "*", se añade al nombre del archivo original. Si la extensión contiene uno o más caracteres "*", cada "*" se reemplaza por el nombre del archivo actual.

-s <estilo>
el estilo a utilizar para el formateo elegante: none, nsgmls, nice, indented, record o record_c (ver la documentación de XML::Twig para la descripción exacta de esos estilos), 'indented' por defecto.
-p <etiqueta(s)>
conserva los espacios en blanco en las etiquetas. Puedes usar varias opciones "-p" o entrecomillar las etiquetas si necesitas más de una.
-e <codificación>
usa la codificación de salida de XML::Twig (basada en Text::Iconv o Unicode::Map8 y Unicode::String) para establecer la codificación de salida. Por defecto, se conserva la codificación original.

Si se usa esta opción, la declaración XML se actualiza (y se crea si no había ninguna).

Asegúrate de que la codificación sea compatible con el analizador que utilices si deseas poder procesar el archivo formateado (por ejemplo, XML::Parser no admite 'latin1', tienes que usar 'iso-8859-1').

-l
carga los documentos en memoria en lugar de sacarlos a medida que se analizan.

Esto evita un error (ver BUGS) pero consume más memoria.

-f <archivo>
lee la lista de archivos a procesar desde <archivo>, uno por línea.
-v
verboso (lista el archivo que se está procesando actualmente).
--
detiene el procesamiento de argumentos (para procesar archivos que empiezan por -).
-h
muestra la ayuda.

EJEMPLOS

xml_pp foo.xml > foo_pp.xml           # formatear elegantemente foo.xml 
xml_pp < foo.xml > foo_pp.xml         # formatear elegantemente desde la entrada estándar
xml_pp -v -i.bak *.xml                # formatear elegantemente archivos .xml, con copias de seguridad
xml_pp -v -i'orig_*' *.xml            # las copias de seguridad se llaman orig_<nombre_archivo>
xml_pp -i -p pre foo.xhtml            # conservar espacios en las etiquetas pre

xml_pp -i.bak -p 'pre code' foo.xml   # conservar espacios en las etiquetas pre y code
xml_pp -i.bak -p pre -p code foo.xml  # lo mismo
xml_pp -i -s record mydb_export.xml   # formatear elegantemente usando el estilo record
xml_pp -e utf8 -i foo.xml             # la salida estará en utf8
xml_pp -e iso-8859-1 -i foo.xml       # la salida estará en iso-8859-1
xml_pp -v -i.bak -f lof               # formatear elegantemente en el lugar los archivos de lof

xml_pp -- -i.xml                      # formatear elegantemente el archivo -i.xml
xml_pp -l foo.xml                     # carga todo el archivo en memoria 
                                      # antes de formatearlo elegantemente
xml_pp -h                             # muestra la ayuda

ERRORES

Los elementos con contenido mixto que empiezan con un elemento incrustado obtienen un \n adicional.

<elt><b>b</b>toto<b>bold</b></elt>

se sacará como

<elt>
  <b>b</b>toto<b>bold</b></elt>

Usar la opción "-l" soluciona este error (pero consume más memoria).
