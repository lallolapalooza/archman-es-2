XMLCATALOG(1) Manual de xmlcatalog XMLCATALOG(1)

NOMBRE

xmlcatalog - Herramienta de línea de comandos para analizar y manipular archivos de catálogo XML o SGML.

SINOPSIS

xmlcatalog [--sgml | --shell | --convert | --create | --del VALOR(ES) | [ --add TIPO ORIG REEMPLAZO  | --add NOMBREARCHIVO] | --noout | --no-super-update | [-v | --verbose]] {ARCHIVO_CATALOGO} {ENTIDADES...}

DESCRIPCIÓN

xmlcatalog es una aplicación de línea de comandos que permite a los usuarios monitorear y manipular catálogos XML y SGML. Está incluido en libxml(3).

Sus funciones se pueden invocar desde un solo comando en la línea de comandos, o puede realizar múltiples funciones en modo interactivo. Puede operar tanto en archivos XML como SGML.

OPCIONES

xmlcatalog acepta las siguientes opciones (en orden alfabético):

--add TIPO ORIG REEMPLAZO

Agrega una entrada a ARCHIVO_CATALOGO. TIPO indica el tipo de entrada. Los tipos posibles son: public, system, uri, rewriteSystem, rewriteURI, delegatePublic, delegateSystem, delegateURI, nextCatalog. ORIG es la referencia original a reemplazar, y REEMPLAZO es la URI de la entidad de reemplazo a utilizar. La opción --add no sobrescribirá ARCHIVO_CATALOGO, enviando la salida a stdout, a menos que se use --noout. La opción --add siempre tomará tres parámetros, incluso si algunas de las construcciones del catálogo XML solo tienen un argumento.

--add NOMBRE_ARCHIVO

Si se usa la opción --add después de la opción --sgml, solo se utiliza un argumento, un NOMBRE_ARCHIVO. Esto se usa para agregar el nombre de un archivo de catálogo a un supercatálogo SGML, un archivo que contiene referencias a otros archivos de catálogo SGML incluidos.

--convert

Convierte el catálogo SGML a XML.

--create

Crea un nuevo catálogo XML. Salida a stdout, ignorando nombre_archivo a menos que se use --noout, en cuyo caso crea un nuevo archivo de catálogo nombre_archivo.

--del VALOR(ES)

Elimina entradas de ARCHIVO_CATALOGO que coincidan con VALOR(ES). La opción --del no sobrescribirá ARCHIVO_CATALOGO, enviando la salida a stdout, a menos que se use --noout.

--noout

Guarda la salida en el archivo especificado en lugar de enviarla a stdout.

--no-super-update

No actualiza el supercatálogo SGML.

--shell

Ejecuta un shell que permite consultas interactivas en el archivo de catálogo ARCHIVO_CATALOGO. Para el conjunto de comandos disponibles, consulte la sección "COMANDOS DEL SHELL".

--sgml

Utiliza supercatálogos SGML para las opciones --add y --del.

-v, --verbose

Muestra información de depuración.

Invocar xmlcatalog de forma no interactiva sin una acción designada (impuesta con opciones como --add) resultará en una búsqueda de la entrada del catálogo para ENTIDADES en el catálogo denotado con ARCHIVO_CATALOGO. Las entradas correspondientes se enviarán a la línea de comandos. Este modo de operación, junto con el modo --shell y las acciones directas no modificadoras (es decir, sin --noout), permite un acceso directo especial a la especificación de ARCHIVO_CATALOGO vacía (posiblemente expresada como "" en el entorno del shell) que designa el catálogo del sistema predeterminado. Esto simplifica el manejo cuando su ubicación exacta es irrelevante, pero aún se necesita consultar el correspondiente incorporado.

COMANDOS DEL SHELL

Invocar xmlcatalog con la opción --shell ARCHIVO_CATALOGO abre un shell de línea de comandos que permite el acceso interactivo al archivo de catálogo identificado por ARCHIVO_CATALOGO. Invocar el shell proporciona un prompt de línea de comandos después del cual se pueden ingresar los siguientes comandos (descritos en orden alfabético).

add TIPO ORIG REEMPLAZO

Agrega una entrada al archivo de catálogo. TIPO indica el tipo de entrada. Los tipos posibles son: public, system, uri, rewriteSystem, rewriteURI, delegatePublic, delegateSystem, delegateURI, nextCatalog. ORIG es la referencia original a reemplazar, y REEMPLAZO es la URI de la entidad de reemplazo a utilizar. La opción --add no sobrescribirá ARCHIVO_CATALOGO, enviando la salida a stdout, a menos que se use --noout. La opción --add siempre tomará tres parámetros, incluso si algunas de las construcciones del catálogo XML solo tienen un argumento.

debug

Muestra declaraciones de depuración que indican los pasos que está ejecutando xmlcatalog.

del VALOR(ES)

Elimina la entrada del catálogo correspondiente a VALOR(ES).

dump

Muestra el catálogo actual.

exit

Sale del shell.

public ID_PÚBLICO

Ejecuta una búsqueda de Identificador Público Formal de la entrada del catálogo para ID_PÚBLICO. La entrada correspondiente se enviará a la línea de comandos.

quiet

Deja de mostrar declaraciones de depuración.

system ID_SISTEMA

Ejecuta una búsqueda de Identificador Público Formal de la entrada del catálogo para ID_SISTEMA. La entrada correspondiente se enviará a la línea de comandos.

AMBIENTE

XML_CATALOG_FILES

El comportamiento del catálogo XML se puede cambiar redirigiendo las consultas al propio conjunto de catálogos del usuario. Esto se puede hacer estableciendo la variable de entorno XML_CATALOG_FILES a una lista de catálogos separada por espacios. Use la codificación de porcentaje para escapar espacios u otros caracteres. Una variable vacía debería desactivar la carga del catálogo predeterminado desde /etc/xml/catalog o, más específicamente, ${sysconfdir}/xml/catalog.

DIAGNÓSTICOS

Los códigos de retorno de xmlcatalog proporcionan información que se puede utilizar al llamarlo desde scripts.

0

Sin error

1

Error al eliminar una entrada del catálogo

2

Error al guardar en el catálogo, compruebe los permisos del archivo

3

Error al agregar una entrada al catálogo

4

Error al buscar una entrada en el catálogo
