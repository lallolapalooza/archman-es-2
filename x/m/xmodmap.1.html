XMODMAP(1) Manual de comandos generales XMODMAP(1)

NOMBRE

xmodmap - utilidad para modificar mapas de teclas y asignaciones de botones del puntero en X

SINOPSIS

xmodmap [-opciones ...] [archivo]

DESCRIPCIÓN

El programa xmodmap se utiliza para editar y mostrar el mapa de modificadores y la tabla de mapa de teclas del teclado que utilizan las aplicaciones cliente para convertir los códigos de evento de tecla en keysyms. Normalmente se ejecuta desde el script de inicio de sesión del usuario para configurar el teclado según los gustos personales.

OPCIONES

Las siguientes opciones pueden ser utilizadas con xmodmap:

-display pantalla
Esta opción especifica el host y la pantalla a utilizar.
-help
Esta opción indica que se debe imprimir una breve descripción de los argumentos de la línea de comandos en el canal de error estándar. Esto se hará cada vez que se proporcione un argumento no manejado a xmodmap.
-grammar
Esta opción indica que se debe imprimir un mensaje de ayuda que describa la gramática de expresiones utilizada en archivos y con expresiones -e en el canal de error estándar.
-version
Esta opción indica que xmodmap debe imprimir su información de versión y salir.
-verbose
Esta opción indica que xmodmap debe imprimir información de registro mientras analiza su entrada.
-quiet
Esta opción desactiva el registro detallado. Este es el valor predeterminado.
-n
Esta opción indica que xmodmap no debe cambiar los mapeos, sino mostrar lo que haría, de manera similar a como lo hace make(1) cuando se le da esta opción.
-e expresión
Esta opción especifica una expresión a ejecutar. Se pueden especificar cualquier número de expresiones desde la línea de comandos.
-pm
Esta opción indica que el mapa de modificadores actual debe imprimirse en la salida estándar. Este es el modo de operación predeterminado si no se especifican otras opciones de modo.
-pk
Esta opción indica que la tabla de mapa de teclas actual debe imprimirse en la salida estándar.
-pke
Esta opción indica que la tabla de mapa de teclas actual debe imprimirse en la salida estándar en forma de expresiones que puedan ser retroalimentadas a xmodmap.
-pp
Esta opción indica que el mapa del puntero actual debe imprimirse en la salida estándar.
-
Un guion solo significa que la entrada estándar se utilizará como archivo de entrada.

El archivo especifica un archivo que contiene expresiones de xmodmap a ejecutar. Este archivo generalmente se mantiene en el directorio principal del usuario con un nombre como .xmodmaprc.

GRAMÁTICA DE EXPRESIONES

El programa xmodmap lee una lista de expresiones y las analiza todas antes de intentar ejecutar alguna. Esto hace posible referirse a keysyms que están siendo redefinidos de una manera natural sin tener que preocuparse tanto por los conflictos de nombres.

La lista de nombres de keysym se puede encontrar en el archivo de encabezado <X11/keysymdef.h> (sin el prefijo XK_). Los keysyms que coinciden con caracteres Unicode se pueden especificar como "U0020" a "U007E" y "U00A0" a "U10FFFF" para todos los caracteres Unicode posibles.

keycode NÚMERO = NOMBREKEYSOM ...
La lista de keysyms se asigna al keycode indicado (que puede especificarse en decimal, hexadecimal u octal y se puede determinar ejecutando el programa xev). Se pueden adjuntar hasta ocho keysyms a una tecla, sin embargo, los últimos cuatro no se utilizan en ninguna implementación importante del servidor X. El primer keysym se utiliza cuando no se presiona ninguna tecla modificadora junto con esta tecla, el segundo con Shift, el tercero cuando se utiliza la tecla Mode_switch con esta tecla y el cuarto cuando se utilizan tanto las teclas Mode_switch como Shift.
keycode any = NOMBREKEYSOM ...
Si ninguna tecla existente tiene la lista especificada de keysyms asignada a ella, se selecciona una tecla de repuesto en el teclado y se le asignan los keysyms. La lista de keysyms se puede especificar en decimal, hexadecimal u octal.
keysym NOMBREKEYSOM = NOMBREKEYSOM ...
El NOMBREKEYSOM del lado izquierdo se traduce en los keycodes correspondientes utilizados para realizar el conjunto de expresiones keycode. Tenga en cuenta que si el mismo keysym está enlazado a múltiples teclas, la expresión se ejecuta para cada keycode coincidente.
clear NOMBREMODIFICADOR
Esto elimina todas las entradas del mapa de modificadores para el modificador dado, donde los nombres válidos son: Shift, Lock, Control, Mod1, Mod2, Mod3, Mod4 y Mod5 (la capitalización no importa en los nombres de los modificadores, aunque sí importa para todos los demás nombres). Por ejemplo, ``clear Lock'' eliminará cualquier tecla que estuviera asociada al modificador de bloqueo de mayúsculas.
add NOMBREMODIFICADOR = NOMBREKEYSOM ...
Esto agrega todas las teclas que contienen los keysyms dados al mapa de modificadores indicado. Los nombres de keysym se evalúan después de leer todas las expresiones de entrada para facilitar la escritura de expresiones para intercambiar teclas (ver la sección EJEMPLOS).
remove NOMBREMODIFICADOR = NOMBREKEYSOM ...
Esto elimina todas las teclas que contienen los keysyms dados del mapa de modificadores indicado. A diferencia de add, los nombres de keysym se evalúan a medida que se lee la línea. Esto le permite eliminar teclas de un modificador sin tener que preocuparse de si han sido reasignadas o no.
pointer = default
Esto restablece el mapa del puntero a su configuración predeterminada (el botón 1 genera un código 1, el botón 2 genera un 2, etc.).
pointer = NÚMERO ...
Esto establece el mapa del puntero para que contenga los códigos de botón indicados. La lista siempre comienza con el primer botón físico. Establecer un código de botón en 0 deshabilita los eventos de ese botón.

Las líneas que comienzan con un signo de exclamación (!) se toman como comentarios.

Si desea cambiar la asignación de una tecla modificadora, también debe eliminarla del mapa de modificadores apropiado.

EJEMPLOS

Muchos punteros están diseñados de tal manera que el primer botón se presiona usando el dedo índice de la mano derecha. Las personas zurdas a menudo encuentran más cómodo invertir los códigos de botón que se generan para que el botón principal se presione con el dedo índice de la mano izquierda. Esto se podría hacer en un puntero de 3 botones de la siguiente manera:

%  xmodmap -e "pointer = 3 2 1"

Muchas aplicaciones admiten la noción de teclas Meta (similares a las teclas Control, excepto que Meta se mantiene presionada en lugar de Control). Sin embargo, algunos servidores no tienen un keysym Meta en la tabla de mapa de teclas predeterminada, por lo que es necesario agregar uno manualmente. El siguiente comando adjuntará Meta a la tecla Multi-idioma (a veces etiquetada como Carácter de Composición). También aprovecha el hecho de que las aplicaciones que necesitan una tecla Meta simplemente necesitan obtener el keycode y no requieren que el keysym esté en la primera columna de la tabla de mapa de teclas. Esto significa que las aplicaciones que buscan una Multi_key (incluido el mapa de modificadores predeterminado) no notarán ningún cambio.

%  xmodmap -e "

EJEMPLOS

A continuación se presentan algunos ejemplos que ilustran el uso de xmodmap.

  % xmodmap -e "keysym Multi_key = Multi_key Meta_L"

De manera similar, algunos teclados tienen una tecla Alt pero no una tecla Meta. En ese caso, lo siguiente puede ser útil:

%  xmodmap -e "keysym Alt_L = Meta_L Alt_L"

Uno de los usos más sencillos, pero convenientes, de xmodmap es establecer la tecla "rubout" (borrar) del teclado para que genere un keysym alternativo. Esto frecuentemente implica intercambiar Retroceso con Suprimir para que sea más cómodo para el usuario. Si el recurso ttyModes en xterm también está configurado, todas las ventanas del emulador de terminal usarán la misma tecla para borrar caracteres:

%  xmodmap -e "keysym BackSpace = Delete"
%  echo "XTerm*ttyModes:  erase ^?" | xrdb -merge

Algunos teclados no generan automáticamente los caracteres de menor que y mayor que cuando las teclas de coma y punto se presionan con Mayús. Esto se puede remediar con xmodmap restableciendo las asignaciones para la coma y el punto con los siguientes scripts:

!
! hacer que shift-, sea < y shift-. sea >
!
keysym comma = comma less
keysym period = period greater

Una de las diferencias más irritantes entre teclados es la ubicación de las teclas Control y Bloq Mayús. Un uso común de xmodmap es intercambiar estas dos teclas de la siguiente manera:

!
! Intercambiar Bloq Mayús y Control Izquierdo
!
remove Lock = Caps_Lock
remove Control = Control_L
keysym Control_L = Caps_Lock
keysym Caps_Lock = Control_L
add Lock = Caps_Lock
add Control = Control_L

Este ejemplo se puede ejecutar de nuevo para intercambiar las teclas y devolverlas a sus asignaciones anteriores.

El comando keycode es útil para asignar el mismo keysym a múltiples keycodes. Aunque no es portable, también hace posible escribir scripts que puedan restablecer el teclado a un estado conocido. El siguiente script establece la tecla retroceso para que genere Suprimir (como se mostró anteriormente), limpia todas las asignaciones existentes de bloq mayús, hace que la tecla Bloq Mayús sea una tecla de control, hace que F5 genere Escape, y hace que Pausa/Reinicio sea un bloq mayús.

!
! En el HP, los siguientes keycodes tienen las siguientes teclas:
!
!     101  Backspace
!      55  Caps
!      14  Ctrl
!      15  Break/Reset
!      86  Stop
!      89  F5
!
keycode 101 = Delete
keycode 55 = Control_R
clear Lock
add Control = Control_R
keycode 89 = Escape
keycode 15 = Caps_Lock
add Lock = Caps_Lock

ERRORES

Cada vez que se evalúa una expresión keycode, el servidor genera un evento MappingNotify en cada cliente. Esto puede causar cierta degradación del rendimiento. Todos los cambios deben agruparse y realizarse de una vez. Los clientes que reciben entrada del teclado e ignoran los eventos MappingNotify no notarán ningún cambio realizado en los mapeos del teclado.

Xmodmap debería generar expresiones de "add" y "remove" automáticamente cada vez que se cambia un keycode que ya está enlazado a un modificador.

Debería haber una forma de que la expresión remove acepte keycodes además de keysyms para aquellos casos en los que realmente arruinas tus mapeos.
