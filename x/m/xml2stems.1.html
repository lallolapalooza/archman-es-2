NOMBRE

xml2stems - Conversión de XML de Verilator a stems.

SINTAXIS

xml2stems [opción]... ARCHIVO_ENTRADA [ARCHIVO_SALIDA]

DESCRIPCIÓN

Convierte la representación AST XML de Verilator a un archivo stems para usarlo con rtlbrowse. Diseñado para reemplazar al obsoleto vermin, y en el futuro, las características avanzadas de la herramienta podrían usar datos adicionales proporcionados por el AST de Verilator. Usar "-" como nombre de archivo de entrada lee desde stdin. Omitir el nombre de archivo de salida genera la salida en stdout.

OPCIONES

-V,--vl_sim
Añade la jerarquía TOP para la simulación de Verilator. No es necesario para otros simuladores.
-h,--help
Muestra la ayuda y sale.

EJEMPLOS

La siguiente es una cadena de comandos para compilar código fuente Verilog y luego iniciar gtkwave y rtlbrowse juntos para la anotación del código fuente. Esto asume que el archivo des.fst ya fue generado a partir de una simulación previa.

verilator -Wno-fatal des.v -xml-only --bbox-sys
xml2stems obj_dir/Vdes.xml des.stems
gtkwave -t des.stems des.fst
