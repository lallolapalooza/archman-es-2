XMMS2-ET(1) Manual de Comandos Generales XMMS2-ET(1)

NOMBRE

xmms2-et - transmite un paquete informativo anónimo al equipo de XMMS2 en cada cambio de canción

SINOPSIS

xmms2-et

DESCRIPCIÓN

XMMS2 es un rediseño del reproductor de música XMMS (https://github.com/xmms2). Presenta un modelo cliente-servidor, lo que permite múltiples interfaces de usuario (¡incluso simultáneas!), tanto textuales como gráficas. Todos los formatos de audio comunes se soportan mediante plugins. Además, hay una biblioteca multimedia flexible para organizar tu música.

xmms2-et es el Cliente de Envío de Informes para XMMS2. xmms2-et está diseñado para transmitir un paquete de información al equipo de XMMS2 cada vez que se reproduce una nueva canción. El paquete es anónimo y no contiene metadatos sobre la canción que se está reproduciendo. Los detalles de qué datos se transmiten al equipo de XMMS2 se pueden encontrar en la sección PAQUETE ET de esta página del manual.

xmms2-et es utilizado para la ingeniería de lanzamientos por el equipo de XMMS2. Durante un ciclo de lanzamiento, el uso de varios plugins, sistemas operativos y componentes de XMMS2 se recopila a partir de los datos transmitidos por el cliente xmms2-et. Se realiza un lanzamiento cuando se ha realizado suficiente prueba, según lo determinado por el número de paquetes xmms2-et relacionados que ha recibido el equipo de XMMS2.

PAQUETE ET

Los siguientes datos se transmiten con cada paquete enviado por xmms2-et:

Estado XMMS2-ET
Inicia los paquetes de XMMS2-ET; estado proporciona un mensaje descriptivo que denota de qué trata este paquete. (Ej. Cierre limpio, Cierre sin limpiar, Nuevo medio)
version=versión
contiene la versión del demonio de XMMS2
system=so
contiene el nombre y la versión del sistema operativo en el que se está ejecutando xmms2d
output=plugin_salida
contiene el plugin de salida que se está utilizando para la reproducción de audio por xmms2d
starttime=hora_inicio
contiene la hora en la que se inició el cliente xmms2-et
uptime=tiempo_activo_xmms2d
contiene el tiempo de actividad del cliente xmms2-et
playlistloads=veces
contiene el número de veces que se ha cargado una lista de reproducción desde la Biblioteca Multimedia
mlibresolves=veces
contiene el número de veces que se han resuelto metadatos para medios en la Biblioteca Multimedia

Los siguientes datos son diferentes para cada canción que se reproduce:

decoder=plugin
contiene el plugin decodificador utilizado para reproducir la última canción reproducida
transport=plugin
contiene el plugin de transporte utilizado para leer la última canción reproducida
samplefmt:in=fmt_entrada
contiene el formato de muestra del archivo de audio original de la última canción reproducida
samplefmt:out=fmt_salida
contiene el formato de muestra que se envió al plugin de salida para la última canción reproducida
samplerate:in=tasa_entrada
contiene la tasa de muestreo del archivo de audio original de la última canción reproducida
samplerate:out=tasa_salida
contiene la tasa de muestreo que se envió al plugin de salida para la última canción reproducida
channels:in=número_entrada
contiene el número de canales del archivo de audio original de la última canción reproducida
channels:out=número_salida
contiene el número de canales que se enviaron al plugin de salida para la última canción reproducida

VARIABLES DE ENTORNO

XMMS_PATH
La ruta URL a xmms2d. Consulte SOCKET IPC en xmms2d(8) para obtener detalles sobre los posibles valores para esta variable
