XMAG(1) Manual de Comandos Generales XMAG(1)

NOMBRE

xmag - magnifica partes de la pantalla

SINOPSIS

xmag [ -mag factor_magnificacion ] [ -source geometria ] [ -opcion_toolkit ... ]
xmag [ -help | -version ]

DESCRIPCIÓN

El programa xmag te permite magnificar porciones de una pantalla X. Si no se especifica una región explícita, se muestra un cuadrado con el puntero en la esquina superior izquierda que indica el área a agrandar. El área se puede arrastrar hasta el tamaño deseado presionando el Botón 2. Una vez seleccionada una región, aparece una ventana que muestra una versión ampliada de la región en la que cada píxel de la imagen fuente se representa por un pequeño cuadrado del mismo color. Presionar el Botón 1 en la ventana de ampliación muestra la posición y el valor RGB del píxel bajo el puntero hasta que se suelte el botón. Escribir "Q" o "^C" en la ventana de ampliación sale del programa. La aplicación tiene 5 botones en la parte superior. Close (Cerrar) elimina esta instancia de magnificación en particular. Replace (Reemplazar) vuelve a mostrar el selector de banda elástica para seleccionar otra región para esta instancia de magnificación. New (Nuevo) muestra el selector de banda elástica para crear una nueva instancia de magnificación. Select (Seleccionar) pone la imagen de magnificación en la selección primaria. Paste (Pegar) copia el búfer de selección primaria en xmag. Ten en cuenta que puedes cortar y pegar entre xmag y el programa bitmap. Redimensionar xmag redimensiona el área de magnificación. xmag conserva el mapa de colores, la representación visual y la profundidad de la ventana de la fuente.

WIDGETS

xmag utiliza el Kit de Herramientas X y el Conjunto de Widgets de Athena. La imagen magnificada se muestra en el widget Scale. Para más información, consulta la documentación del Conjunto de Widgets de Athena. A continuación se muestra la estructura de widgets de la aplicación xmag. La indentación indica la estructura jerárquica. Primero se da el nombre de la clase del widget, seguido del nombre de la instancia del widget.

OPCIONES

-source geometria
Esta opción especifica el tamaño y/o la ubicación de la región fuente en la pantalla. Por defecto, se proporciona un cuadrado de 64x64 para que el usuario seleccione un área de la pantalla.
-mag entero
Esta opción indica la magnificación a utilizar. 5 es el valor por defecto.
-help
Esta opción indica que xmag debe imprimir un mensaje de uso y salir.
-version
Esta opción indica que xmag debe imprimir información de la versión y salir.
