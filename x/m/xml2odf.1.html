NOMBRE
xml2odf - Crear paquete ODF a partir de OpenDocument en forma XML



SINOPSIS

xml2odf [-o archivo_salida] [-s] [archivo_entrada]



DESCRIPCIÓN

OpenDocument puede ser un documento de oficina completo en un solo archivo XML. El script tomará dicho documento y creará un paquete. Esto es principalmente útil como postprocesador de un programa que produce XML, como una hoja de estilos.

Se asume que "archivo_entrada" es un archivo OpenDocument en formato XML. Si no hay archivo_entrada, el programa leerá desde la entrada estándar. La opción -s añade el sufijo correcto al nombre del archivo según el tipo MIME que se encuentre en el archivo XML, en caso de que no sepas ya qué tipo de documento estás empaquetando.

Si no se especifica el archivo de salida, la salida será a la salida estándar.

La sección 2.1.1 del Formato Open Document para Aplicaciones de Oficina dice que el archivo [content.xml] contiene el contenido del documento, junto con los estilos automáticos necesarios para el contenido del documento. El archivo [styles.xml] contiene todos los estilos nombrados de un documento, junto con los estilos automáticos necesarios para los estilos nombrados. La aplicación no sabe qué estilo automático se necesita para qué, por lo que pone el mismo conjunto de estilos automáticos en ambos archivos.

Se podría suponer que la operación inversa sería más fácil, pero OpenOffice.org está muy contento de usar los mismos nombres para dos estilos automáticos diferentes. Por ejemplo, un estilo utilizado dentro de <style:footer> puede tener el mismo nombre que uno utilizado dentro de <office:text> pero ser un estilo de párrafo diferente. Esto se informa como el error n.º 90494 (http://www.openoffice.org/issues/show_bug.cgi?id=90494)



EJEMPLO

xml2odf -o documentodetest -s archivo-xml



VER TAMBIÉN

odftools(1), odf2xml(1)



ERRORES

No maneja datos externos — imágenes y similares.

La biblioteca utilizada para el análisis de XML expande elementos vacíos de <elemento/> a <elemento></elemento>. Esto no debería tener ningún efecto en el análisis del documento.
