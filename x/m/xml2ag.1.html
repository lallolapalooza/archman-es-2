xml2ag(1) Comandos de usuario xml2ag(1)

NOMBRE

xml2ag - Convertidor de XML a Definiciones de AutoGen

SINOPSIS

xml2ag [-banderas] [-bandera [valor]] [--nombre-de-opcion[[=| ]valor]] [ <archivo-def> ]

Este programa convertirá cualquier archivo XML arbitrario en definiciones equivalentes de AutoGen e invocará a AutoGen.

DESCRIPCIÓN

La plantilla se derivará de:
* la opción de línea de comandos --override-tpl
* un atributo XML de nivel superior llamado "template"
Una de las dos opciones debe proporcionarse, o el programa saldrá con un mensaje de error.

El "nombre base" para la salida será, de manera similar:
* la opción de línea de comandos --base-name
* el nombre base del archivo .xml

OPCIONES

Todas las demás opciones se derivan de autogen

-O archivo, --output=archivo

Archivo de salida en lugar del procesamiento de AutoGen.

Por defecto, la salida se entrega a AutoGen para su procesamiento. Sin embargo, puedes guardar las definiciones en un archivo en su lugar.

Todas las demás opciones

Estas opciones se pasan principalmente a autogen. La única excepción es --override-tpl, que reemplaza la plantilla predeterminada en las definiciones de salida. No se pasa a través de la línea de comandos.

-L dir, --templ-dirs=dir

Busca plantillas en DIR. Esta opción puede aparecer un número ilimitado de veces.

Pasa el argumento de AutoGen

-T archivo-tpl, --override-tpl=archivo-tpl

Usa ARCHIVO-TPL para la plantilla.

Pasa el argumento de AutoGen

--definitions=archivo

Lee definiciones de ARCHIVO.

Pasa el argumento de AutoGen

--shell=shell

nombre o ruta del shell a usar.

Pasa el argumento de AutoGen

-m, --no-fmemopen

No uses flujos en memoria.

Pasa el argumento de AutoGen

--equate=lista-caracteres

caracteres considerados equivalentes.

Pasa el argumento de AutoGen

-b nombre, --base-name=nombre

Especifica NOMBRE como nombre base para la salida.

Pasa el argumento de AutoGen

--source-time

establece los tiempos de modificación a la última fuente.

Pasa el argumento de AutoGen

--writable, --not-writable

Permite que los archivos de salida sean escribibles. La forma not-writable desactivará la opción.

Pasa el argumento de AutoGen

--loop-limit=lim

Límite en bucles de incremento. Esta opción toma un número entero como argumento. El valor de lim se restringe a: 
exactamente -1, o
en el rango  1 hasta 0x1000000

El lim por defecto para esta opción es:
256

Pasa el argumento de AutoGen

-t segundos, --timeout=segundos

Limita las operaciones del shell del servidor a SEGUNDOS. Esta opción toma un número entero como argumento. El valor de segundos se restringe a: 
en el rango  0 hasta 3600

Pasa el argumento de AutoGen

--trace=nivel

nivel de detalle de rastreo. Esta opción toma una palabra clave como argumento. El argumento establece un valor de enumeración que puede ser probado comparándolos con la macro de valor de opción. Las palabras clave disponibles son: 
nothing       debug-message server-shell
templates     block-macros  expressions
everything
o su equivalente numérico.

El nivel por defecto para esta opción es:
nothing

Pasa el argumento de AutoGen

--trace-out=archivo

archivo o filtro de salida de rastreo.

Pasa el argumento de AutoGen

--show-defs

Muestra el árbol de definiciones.

Pasa el argumento de AutoGen

--used-defines

Muestra las definiciones usadas.

Pasa el argumento de AutoGen

-C, --core

Deja un volcado del núcleo en una salida por fallo.

Muchos sistemas tienen por defecto un límite de núcleo de tamaño cero. Si el sistema tiene la cabecera sys/resource.h y si se proporciona esta opción, entonces en la ruta de salida por fallo, autogen intentará establecer el límite suave del núcleo al límite duro del núcleo. Si eso no funciona, un administrador deberá aumentar el tamaño del límite duro del núcleo.

-s sufijo, --skip-suffix=sufijo

Omite el archivo con este SUFIJO. Esta opción puede aparecer un número ilimitado de veces. Esta opción no debe aparecer en combinación con ninguna de las siguientes opciones: select-suffix.

Pasa el argumento de AutoGen

-o sufijo, --select-suffix=sufijo

especifica este sufijo de salida. Esta opción puede aparecer un número ilimitado de veces.

Pasa el argumento de AutoGen

-D valor, --define=valor

nombre a añadir a la lista de definiciones. Esta opción puede aparecer un número ilimitado de veces.

Pasa el argumento de AutoGen

-U pat-nombre, --undefine=pat-nombre

patrón de eliminación de la lista de definiciones. Esta opción puede aparecer un número ilimitado de veces.

Pasa el argumento de AutoGen

-M tipo, --make-dep [tipo]

emite el archivo de dependencia de make. Esta opción puede aparecer un número ilimitado de veces.

Pasa el argumento de AutoGen

-?, --help

Muestra la información de uso y sale.
-!, --more-help

Pasa la información de uso extendida a un paginador.
-v [{v|c|n --version [{v|c|n}]}]

Muestra la versión del programa y sale. El modo por defecto es `v', una versión simple. El modo `c' mostrará información de copyright y `n' mostrará el aviso de copyright completo.

ESTADO DE SALIDA

Se devolverá uno de los siguientes valores de salida:

0 (EXIT_SUCCESS)

Ejecución exitosa del programa.
1 (EXIT_FAILURE)

La operación falló o la sintaxis del comando no era válida.
70 (EX_SOFTWARE)

libopts tuvo un error operativo interno. Por favor, repórtelo a autogen-users@lists.sourceforge.net. Gracias.
