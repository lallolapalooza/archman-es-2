NOMBRE

xml2-config - script para obtener información sobre la versión instalada de libxml2

SINOPSIS

xml2-config [--prefijo[=DIR]] [--libs] [--cflags] [--version] [--help]

DESCRIPCIÓN

xml2-config es una herramienta que se utiliza para determinar las opciones de compilación y enlazado que deben utilizarse para compilar y enlazar programas que utilizan libxml2.

OPCIONES

xml2-config acepta las siguientes opciones:

--version
Imprime la versión actualmente instalada de libxml2 en la salida estándar.
--libs
Imprime las opciones del enlazador que son necesarias para enlazar un programa de libxml2. Añada --dynamic después de --libs para imprimir solo información de enlace de bibliotecas compartidas.
--cflags
Imprime las opciones del compilador que son necesarias para compilar un programa de libxml2.
--prefijo=PREFIJO
Si se especifica, utiliza PREFIJO en lugar del prefijo de instalación con el que se construyó libxml2 al calcular la salida para las opciones --cflags y --libs. Esta opción debe especificarse antes de cualquier opción --libs o --cflags.
