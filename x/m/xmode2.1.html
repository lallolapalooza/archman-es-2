MODE2(1) Comandos de usuario MODE2(1)

NOMBRE

xmode2 - Muestra la longitud de pulso/espacio de señales infrarrojas

SINOPSIS

xmode2 [opciones]

DESCRIPCIÓN

El propósito principal de xmode2 es comprobar el funcionamiento de tu hardware receptor de LIRC casero y ver la forma de onda IR del mando a distancia sin un osciloscopio caro. Muy útil para depuración. Por supuesto, este programa no funcionará con hardware que decodifica las señales automáticamente como, por ejemplo, tarjetas de TV o el Irman, es decir, solo funciona con drivers de tipo LIRC_MODE_MODE2.

xmode2 imprime una gráfica sencilla de las longitudes de pulso/espacio. Acepta algunos comandos, incluyendo cambios de base de tiempo; consulta la salida de xmode2 -h.

lirc-lsplugins(1) permite comprobar si un driver es de tipo LIRC_MODE2.

OPCIONES

-h --help
muestra el resumen de uso
-v --version
muestra la versión
-d --device=dispositivo
lee del dispositivo indicado
-H --driver=driver
usa el driver indicado
-m --mode
habilita el modo de visualización alternativo
-r --raw
accede al dispositivo directamente

EJECUCIÓN COMO ROOT

En muchos casos, xmode2 necesita ejecutarse como root para acceder a dispositivos no disponibles para usuarios normales. Por otro lado, ejecutarse como root crea problemas como archivos de registro propiedad de root, preocupaciones de seguridad, etc.

Para solucionar esto, xmode2, por defecto, renuncia a los privilegios de root después de abrir el dispositivo de entrada. Esta funcionalidad se basa en que los permisos de root se adquieren utilizando sudo(1), por ejemplo, usando

        $ sudo xmode2 --driver default --device /dev/lirc0
Si no se usa sudo, el mismo comportamiento se podría lograr usando la variable de entorno SUDO_USER, por ejemplo, 
        # SUDO_USER=$LOGNAME xmode2 --raw /dev/lirc0
La opción --keep-root hará que xmode2 mantenga sus privilegios de root durante toda la ejecución.

CARGA DE DRIVERS

Los drivers se cargan dinámicamente. La ruta de búsqueda utilizada para esto está determinada por (prioridad decreciente):

  • La opción --plugindir.
  • La entrada 'plugindir' en la sección [lircd] del archivo lirc_options.conf.
  • La variable de entorno LIRC_PLUGINDIR.
  • Un valor predeterminado codificado (generalmente /usr/lib[64]/lirc/plugins).

ARCHIVOS

~/.cache/xmode2.log
Salida de depuración. Establecer la variable de entorno XDG_CACHE_HOME reubica este archivo a $XDG_CACHE_HOME/mode2.log.
