NOMBRE

xmessage - muestra un mensaje o consulta en una ventana (basado en X /bin/echo)

SINOPSIS

xmessage [ -botones etiqueta1[:valor1],etiqueta2[:valor2], ... ] [ opciones ] -archivo nombrearchivo
xmessage [ -botones etiqueta1[:valor1],etiqueta2[:valor2], ... ] [ opciones ] mensaje ...
xmessage [ -ayuda | -versión ]

DESCRIPCIÓN

El programa xmessage muestra una ventana que contiene un mensaje de la línea de comandos, un archivo o la entrada estándar. A lo largo del borde inferior del mensaje hay una fila de botones; hacer clic con el botón izquierdo del ratón en cualquiera de estos botones hará que xmessage salga. Qué botón se presionó se devuelve en el estado de salida y, opcionalmente, escribiendo la etiqueta del botón en la salida estándar.

El programa se utiliza típicamente en scripts de shell para mostrar información al usuario o para pedirle al usuario que tome una decisión.

A menos que se especifique un tamaño, xmessage se ajusta para adaptarse al mensaje, hasta un tamaño máximo. Si el mensaje es demasiado grande para la ventana, xmessage mostrará barras de desplazamiento.

OPCIONES

Estas son las opciones de línea de comandos que xmessage entiende, además de las estándar enumeradas en X(7).

-botones botón,botón,...
Esta opción hará que xmessage cree un botón por cada argumento botón separado por comas. El recurso correspondiente es botones. Cada botón consiste en una etiqueta seguida opcionalmente por dos puntos y un valor de salida. La etiqueta es el nombre del widget de botón de Comando creado y será el texto predeterminado que se muestra al usuario. Como este es el nombre del widget, se puede usar para cambiar cualquiera de los recursos asociados con ese botón. El valor de salida será devuelto por xmessage si se selecciona ese botón. El valor de salida predeterminado es 100 más el número del botón. Los botones se numeran de izquierda a derecha comenzando desde uno. La cadena predeterminada si no se proporciona la opción -botones es okay:0.
-predeterminado etiqueta
Define el botón con una etiqueta coincidente como predeterminado. Si no se especifica, no hay predeterminado. El recurso correspondiente es botónPredeterminado. Presionar Intro en cualquier lugar de la ventana de xmessage activará el botón predeterminado. El botón predeterminado tiene un borde más ancho que los otros.
-archivo nombrearchivo
Archivo a mostrar. El recurso correspondiente es archivo. Un nombrearchivo de `-' lee desde la entrada estándar. Si esta opción no se proporciona, xmessage mostrará todos los argumentos que no sean opciones al estilo de echo. Se debe proporcionar -archivo o un mensaje en la línea de comandos, pero no ambos.
-imprimir
Esto hará que el programa escriba la etiqueta del botón presionado en la salida estándar. Equivalente a establecer el recurso imprimirValor a TRUE. Esta es una forma de obtener retroalimentación sobre qué botón se presionó.
-centrar
Mostrar la ventana en el centro de la pantalla. Equivalente a establecer el recurso centrar a TRUE.
-cercadearaton
Mostrar la ventana cerca del cursor del ratón. Equivalente a establecer el recurso cercaDelRaton a TRUE.
-tiempoespera seg
Salir con estado 0 después de seg segundos si el usuario aún no ha hecho clic en un botón. El recurso correspondiente es tiempoEspera.
-ayuda
Imprimir un mensaje de uso y salir.
-versión
Imprimir información de versión y salir.

RECURSOS

El programa tiene algunos recursos de aplicación de nivel superior que permiten personalizaciones específicas de xmessage.

archivo
Una Cadena que especifica el archivo a mostrar.
botones
Una Cadena que especifica los botones a mostrar. Consulte la opción de línea de comandos -botones.
botónPredeterminado
Una Cadena que especifica un botón predeterminado por etiqueta.
imprimirValor
Un valor Booleano que especifica si la etiqueta del botón presionado para salir del programa se escribe en la salida estándar. El valor predeterminado es FALSE.
centrar
Un valor Booleano que especifica si se muestra la ventana en el centro de la pantalla. El valor predeterminado es FALSE.
cercaDelRaton
Un valor Booleano que especifica si se muestra la ventana cerca del cursor del ratón. El valor predeterminado es FALSE.
tiempoEspera
El número de segundos después del cual salir con estado 0. El valor predeterminado es 0, lo que significa que nunca se agota el tiempo de espera.
alturaMaxima (Clase Máxima)
La altura máxima de la parte de texto de la ventana en píxeles, utilizada si no se especificó ningún tamaño en la geometría. El valor predeterminado es 0, lo que significa que se usa el 70% de la altura de la pantalla.
anchuraMaxima (Clase Máxima)
El ancho máximo de la parte de texto de la ventana en píxeles, utilizado si no se especificó ningún tamaño en la geometría. El valor predeterminado es 0, lo que significa que se usa el 70% del ancho de la pantalla.

ACCIONES

salir(valor)
Salir inmediatamente con un estado de salida de valor (predeterminado 0). Esta acción se puede usar con traducciones para proporcionar formas alternativas de salir de xmessage.
salir-predeterminado()
Salir inmediatamente con el estado de salida especificado por el botón predeterminado. Si no hay un botón predeterminado, esta acción no tiene efecto.

ESTADO DE SALIDA

Si detecta un error, xmessage devuelve 1, por lo que este valor no debe usarse con un botón.
