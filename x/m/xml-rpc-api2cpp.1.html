XML-RPC-API2CPP(1) Manual de comandos generales XML-RPC-API2CPP(1)

NOMBRE

xml-rpc-api2cpp - Crea una clase envoltorio de C++ para una API XML-RPC

SINOPSIS

xml-rpc-api2cpp url-servidor prefijo-método-remoto nombre-clase-c++

DESCRIPCIÓN

xml-rpc-api2cpp consulta un servidor XML-RPC utilizando la API de introspección XML-RPC diseñada por Edd Dumbill. Luego, imprime una clase envoltorio de C++ en la salida estándar. Esta clase puede usarse con la API de C++ de xmlrpc-c.

Puede encontrar una lista de bibliotecas de servidores XML-RPC compatibles (y parches para muchas otras) en http://xmlrpc-c.sourceforge.net/hacks.php.

OPCIONES

url-servidor
El nombre del servidor a consultar. Pruebe http://xmlrpc-c.sourceforge.net/cgi-bin/interop.cgi.
prefijo-método-remoto
El prefijo de los métodos a envolver. Por ejemplo, para envolver todas las llamadas system.*, puede especificar "system".
nombre-clase-c++
El nombre de la clase C++ a generar. Pruebe "SystemProxy".

ERRORES

xml-rpc-api2cpp no puede comunicarse con ciertos servidores PHP basados en la biblioteca PHP de Edd Dumbill, porque los bytes finales del mensaje XML-RPC se truncan en modo de canalización HTTP. No está claro si esto es un error de PHP, Apache o w3c-libwww.

xml-rpc-api2cpp asume que las descripciones de los métodos son texto ASCII, no HTML como se especifica en el estándar. (En la práctica, ambas convenciones se ven a menudo). También puede tener problemas si las descripciones de los métodos contienen ""*/"".

En general, los mensajes de error y los diagnósticos siguen siendo bastante pobres.

VER TAMBIÉN

xmlrpc-c(7), xml-rpc-api2txt(1).

Este programa es parte de xmlrpc-c.
