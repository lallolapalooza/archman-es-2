XMMS2D(1) Manual de Comandos Generales XMMS2D(1)

NOMBRE

xmms2d - Demonio de XMMS2 que maneja la reproducción de música y el almacenamiento de metadatos musicales

SINOPSIS

xmms2d [-v|-q] [-p dir] [-o plugin] [-i url] [-c archivo] [-s fd] [--yes-run-as-root]
xmms2d -?
xmms2d -V

DESCRIPCIÓN

XMMS2 es un rediseño del reproductor de música XMMS (https://en.wikipedia.org/wiki/XMMS). Presenta un modelo cliente-servidor, que permite múltiples interfaces de usuario (incluso simultáneas), tanto textuales como gráficas. Todos los formatos de audio comunes son compatibles mediante plugins. Además de esto, hay una biblioteca multimedia flexible para organizar tu música.

xmms2d es el demonio a través del cual los clientes de XMMS2 reproducen y gestionan música. Una biblioteca cliente proporcionada permite a terceros escribir fácilmente clientes de XMMS2, especialmente utilizando los enlaces para Python y Ruby.

xmms2d utiliza un método de tres partes para reproducir música. La música se accede desde el disco o la red utilizando un plugin de transporte, los datos se pasan luego a un plugin decodificador que decodifica el audio a un formato que puede ser reproducido por un plugin de salida.

OPCIONES

Opciones generales

-v, --verbose
Aumenta la verbosidad.
-q, --quiet
Disminuye la verbosidad.
-p dir, --plugindir=dir
Usa el directorio de plugins dir.
-o plugin, --output=plugin
Usa el plugin de salida plugin.
-i url, --ipc-socket=url
Escucha en el socket en url. Se pueden especificar múltiples sockets separados por caracteres ;. Ver la sección SOCKET_IPC.
-c archivo, --conf=archivo
Usa el archivo de configuración archivo.
-s fd, --status-fd=fd
Escribe en el descriptor de archivo fd cuando se inicia. Esto puede usarse para esperar hasta que la comunicación entre procesos (IPC) esté activa, como lo hace por ejemplo xmms2-launcher(1).
--yes-run-as-root
Permite ejecutar xmms2d como root.

Obtener ayuda

-h, -?, --help
Muestra información básica de ayuda y sale.
-V, --version
Muestra información de la versión.

SOCKET IPC

Los clientes de XMMS2 utilizan sockets IPC para comunicarse con xmms2d. Estos sockets IPC se especifican en un formato basado en URL con tres métodos de transporte posibles: unix, tcp y tcp6.

Los métodos TCP permiten a los clientes conectarse a través de IPv4 e IPv6 a xmms2d y, por lo tanto, permiten el control remoto de XMMS2. Una URL de socket IPC típica que usa TCP es tcp://127.0.0.1:9667.

El método de transporte UNIX es solo para clientes locales y crea un archivo a través del cual los clientes de XMMS2 pueden acceder a xmms2d. Una ruta de socket IPC típica que utiliza el transporte UNIX es unix:///tmp/xmms-ipc-foobar.

ARCHIVOS

Abajo, CONFDIR es $XDG_CONFIG_HOME/xmms2 en UNIX si la variable de entorno XDG_CONFIG_HOME está configurada. De lo contrario, es $HOME/.config/xmms2 (UNIX excepto Darwin), o $HOME/Library/xmms2 (Darwin). En Win32 es %APPDATA%/xmms2.

CONFDIR/xmms2.conf
Un archivo de configuración con formato XML que permite cambiar la configuración de xmms2d.
CONFDIR/startup.d/
Un directorio poblado con programas que se ejecutan cuando se ejecuta xmms2d. Se puede especificar una ubicación alternativa en el archivo de configuración.
CONFDIR/shutdown.d/
Un directorio poblado con programas que se ejecutan cuando xmms2d se apaga correctamente. Se puede especificar una ubicación alternativa en el archivo de configuración.
CONFDIR/medialib.db
Una base de datos sqlite3(1) que incluye información sobre cada canción que se ha añadido a la biblioteca multimedia de XMMS2. Se puede especificar una ubicación alternativa en el archivo de configuración.
CONFDIR/bindata/
Un directorio que contiene archivos con datos binarios confiados a la biblioteca multimedia de XMMS2, como carátulas de álbumes. Se puede especificar una ubicación alternativa en el archivo de configuración.
/tmp/xmms-ipc-USER
La ubicación típica para el socket IPC de UNIX. Aquí USER es el nombre del usuario que ejecutó xmms2d.

ENTORNO

XDG_CONFIG_HOME
La ruta donde se encuentran los archivos de configuración y recursos de XMMS2.
XMMS_PATH
La URL del primer socket que xmms2d escucha. Esta variable de entorno se establece para programas en los directorios de inicio y apagado.
XMMS_PATH_FULL
Una lista separada por ; de rutas a las que xmms2d escucha. Esta variable de entorno se establece para programas en los directorios de inicio y apagado.

xmms2d(1)

xmms2d - demonio del reproductor de medios XMMS2

SINopsis

xmms2d [OPCIONES]

DESCRIPCIÓN

xmms2d es el demonio de fondo para el reproductor de medios XMMS2. Sirve como el núcleo del motor de reproducción, gestionando la lista de reproducción, la decodificación de audio y la salida de audio.

OPCIONES

-h, --help
Muestra un mensaje de ayuda y sal.
-v, --version
Muestra información de la versión y sal.
-q, --quiet
Suprime la mayoría de los mensajes informativos.
-d, --debug
Activa la depuración para el demonio.
--config-dir DIR
Especifica el directorio de configuración.
--log-file ARCHIVO
Especifica el archivo de registro para la salida del demonio.

Archivos

~/.config/xmms2/
Directorio de configuración por defecto para XMMS2.
/etc/xmms2/
Directorio de configuración del sistema para XMMS2.

ENTORNO

XMMS_CONFIG_DIR
Si se establece, se utilizará como directorio de configuración en lugar de ~/.config/xmms2/.
XMMS_DATADIR
Si se establece, se utilizará como directorio de datos para los complementos.

VER TAMBIÉN

xmms2(1), control-xmms2(1)
