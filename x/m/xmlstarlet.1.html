XMLSTARLET(1) Manual de XMLStarlet XMLSTARLET(1)

NOMBRE

xmlstarlet - kit de herramientas XML/XSLT de línea de comandos

SINOPSIS

xml [opciones...] {comando} [opciones-comando...]

INTRODUCCIÓN

XMLStarlet es un conjunto de utilidades de línea de comandos (herramientas) que se pueden utilizar para transformar, consultar, validar y editar documentos y archivos XML utilizando un conjunto simple de comandos de shell de manera similar a como se hace para archivos de texto plano con comandos UNIX como grep, sed, awk, diff, patch, join, etc. Este conjunto de utilidades de línea de comandos puede ser utilizado por aquellos que trabajan con muchos documentos XML en el prompt de comandos de shell de UNIX, así como para el procesamiento automatizado de XML con scripts de shell.

OPCIONES

--version

Muestra la versión de xmlstarlet.

--help

Muestra la ayuda.

COMANDOS

xml comando --help para obtener ayuda específica del comando

Los comandos disponibles incluyen:

ed (o edit)

Edita/actualiza documentos XML.

sel (o select)

Selecciona datos o consulta documentos XML (XPATH, etc.).

tr (o transform)

Transforma documentos XML usando XSLT.

val (o validate)

Valida documentos XML (bien formados/DTD/XSD/RelaxNG).

fo (o format)

Formatea documentos XML.

el (o elements)

Muestra la estructura de elementos de un documento XML.

c14n (o canonic)

Canonización XML.

ls (o list)

Lista el directorio como XML.

esc (o escape)

Escapa caracteres XML especiales.

unesc (o unescape)

Deshace el escape de caracteres XML especiales.

pyx (o xmln)

Convierte XML a formato PYX (basado en ESIS - ISO 8879).

p2x (o depyx)

Convierte PYX a XML.

REFERENCIAS

XMLStarlet es un kit de herramientas de línea de comandos para consultar/editar/verificar/transformar documentos XML (para más información, consulta http://xmlstar.sourceforge.net/).
