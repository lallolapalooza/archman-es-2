NOMBRE

xpad - Una aplicación de notas adhesivas para GTK+ 3.0

SINOPSIS

xpad [OPCIONES]

DESCRIPCIÓN

Una aplicación de notas adhesivas para GTK+ 3.0.

OPCIONES

-v, --version
Muestra la información de la versión.
-?, --help
Muestra la información de uso.
-h, --hide
Oculta las notas existentes al iniciar. Todas las notas se ocultarán, así que a menos que el icono de la bandeja esté presente o también especifique --new, xpad saldrá inmediatamente.
-s, --show
Muestra las notas existentes al iniciar.
-t, --toggle
Alterna entre mostrar y ocultar cada una de las notas existentes al iniciar.
-n, --new
Abre una nueva nota.
-N, --no-new
Evita que xpad cree una nueva nota al iniciar. Se crearía una nueva nota si xpad ya está en ejecución y se vuelve a ejecutar, o si no hay notas antiguas que cargar.
-f, --new-from-file=ARCHIVO
Crea una nueva nota con el contenido de un archivo
-q, --quit
Cierra todas las notas abiertas y termina los procesos de xpad.
