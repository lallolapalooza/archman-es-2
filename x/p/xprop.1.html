XPROP(1) Manual de Comandos Generales XPROP(1)

NOMBRE

xprop - visualizador de propiedades para X

SINOPSIS

xprop [-ayuda] [-gramática] [-id id] [-root] [-nombre nombre] [-frame] [-fuente fuente] [-display display] [-len n] [-notype] [-fs archivo] [-remove nombre-propiedad] [-set nombre-propiedad valor] [-spy] [-version] [-f átomo formato [dformato]]* [formato [dformato] átomo]*

RESUMEN

La utilidad xprop sirve para mostrar propiedades de ventanas y fuentes en un servidor X. Se selecciona una ventana o fuente usando los argumentos de la línea de comandos o, en el caso de una ventana, haciendo clic en la ventana deseada. A continuación, se proporciona una lista de propiedades, posiblemente con información de formato.

OPCIONES

-ayuda
Imprime un resumen de las opciones de la línea de comandos.
-gramática
Imprime una gramática detallada para todas las opciones de la línea de comandos.
-id id
Este argumento permite al usuario seleccionar la ventana id en la línea de comandos en lugar de usar el puntero para seleccionar la ventana de destino. Esto es muy útil para depurar aplicaciones X donde la ventana de destino no está mapeada en la pantalla o donde el uso del puntero podría ser imposible o interferir con la aplicación.
-nombre nombre
Este argumento permite al usuario especificar que la ventana llamada nombre es la ventana de destino en la línea de comandos en lugar de usar el puntero para seleccionar la ventana de destino.
-fuente fuente
Este argumento permite al usuario especificar que se deben mostrar las propiedades de la fuente fuente.
-root
Este argumento especifica que la ventana raíz de X es la ventana de destino. Esto es útil en situaciones donde la ventana raíz está completamente oculta.
-display display
Este argumento le permite especificar el servidor al que conectarse; consulte X(7).
-len n
Especifica que como máximo n bytes de cualquier propiedad deben ser leídos o mostrados.
-notype
Especifica que el tipo de cada propiedad no debe ser mostrado.
-fs archivo
Especifica que el archivo archivo debe usarse como fuente de más formatos para propiedades.
-frame
Especifica que al seleccionar una ventana manualmente (es decir, si no se especifican -nombre, -root o -id), se mire el marco del gestor de ventanas (si existe) en lugar de buscar la ventana del cliente.
-remove nombre-propiedad
Especifica el nombre de una propiedad que debe eliminarse de la ventana indicada.
-set nombre-propiedad valor
Especifica el nombre de una propiedad y un valor de propiedad, que se establecerán en la ventana indicada.
-spy
Examina las propiedades de las ventanas de forma continua, buscando eventos de cambio de propiedad.
-version
Imprime la información de la versión del programa y sale.
-f nombre formato [dformato]
Especifica que el formato para nombre debe ser formato y que el dformato para nombre debe ser dformato. Si falta dformato, se asume " = $0+\n".

DESCRIPCIÓN

Para cada una de estas propiedades, su valor en la ventana o fuente seleccionada se imprime utilizando la información de formato proporcionada, si la hay. Si no se proporciona información de formato, se utilizan los valores predeterminados internos. Si una propiedad no está definida en la ventana o fuente seleccionada, se imprime "no definida" como valor para esa propiedad. Si no se proporciona una lista de propiedades, se imprimen todas las propiedades que posee la ventana o fuente seleccionada.

Se puede seleccionar una ventana de cuatro maneras. Primero, si la ventana deseada es la ventana raíz, se puede usar el argumento -root. Si la ventana deseada no es la ventana raíz, se puede seleccionar de dos maneras en la línea de comandos, ya sea por su número de id, como podría obtenerse de xwininfo, o por su nombre si la ventana tiene un nombre. El argumento -id selecciona una ventana por su número de id, ya sea decimal o hexadecimal (debe comenzar con 0x), mientras que el argumento -name selecciona una ventana por su nombre.

La última forma de seleccionar una ventana no involucra la línea de comandos en absoluto. Si no se especifican -fuente, -id, -nombre ni -root, se muestra un cursor de mira y se permite al usuario elegir cualquier ventana visible presionando cualquier botón del puntero en la ventana deseada. Si se desea mostrar las propiedades de una fuente en lugar de una ventana, se debe usar el argumento -fuente.

Aparte de los cuatro argumentos anteriores y el argumento -ayuda para obtener ayuda, y el argumento -gramática para listar la gramática completa de la línea de comandos, todos los demás argumentos de la línea de comandos se utilizan para especificar tanto el formato de las propiedades a mostrar como cómo mostrarlas. El argumento -len n especifica que como máximo n bytes de cualquier propiedad dada se leerán y mostrarán. Esto es útil, por ejemplo, al mostrar el buffer de corte en la ventana raíz, que podría ocupar varias páginas si se mostrara completo.

Normalmente, cada nombre de propiedad se muestra imprimiendo primero el nombre de la propiedad, luego su tipo (si lo tiene) entre paréntesis, seguido de su valor. El argumento -notype especifica que los tipos de propiedad no deben mostrarse. El argumento -fs se utiliza para especificar un archivo que contiene una lista de formatos para propiedades, mientras que el argumento -f se utiliza para especificar el formato para una propiedad.

La información de formato para una propiedad consta en realidad de dos partes, un formato y un dformato. El formato especifica el formato real de la propiedad (es decir, ¿está compuesto por palabras, bytes o longitudes?, etc.) mientras que el dformato especifica cómo se debe mostrar la propiedad.

Los siguientes párrafos describen cómo construir formatos y dformatos. Sin embargo, para la gran mayoría de los usuarios y usos, esto no debería ser necesario, ya que los valores predeterminados incorporados contienen los formatos y dformatos necesarios para mostrar todas las propiedades estándar. Solo debería ser necesario especificar formatos y dformatos si se está tratando una nueva propiedad o si al usuario no le gusta el formato de visualización estándar. Se anima especialmente a los nuevos usuarios a omitir esta parte.

Un formato consiste en 0, 8, 16 o 32, seguido de una secuencia de uno o más caracteres de formato. El 0, 8, 16 o 32 especifica cuántos bits por campo hay en la propiedad. Cero es un caso especial que significa usar la información del tamaño del campo asociada con la propiedad misma. (Esto solo es necesario para casos especiales como el tipo INTEGER, que en realidad son tres tipos diferentes dependiendo del tamaño de los campos de la propiedad).

Un valor de 8 significa que la propiedad es una secuencia de bytes, mientras que un valor de 16 significaría que la propiedad es una secuencia de palabras. La diferencia entre estos dos radica en el hecho de que la secuencia de palabras se intercambiará por bytes, mientras que la secuencia de bytes no se intercambiará cuando sea leída por una máquina con orden de bytes opuesto al de la máquina que originalmente escribió la propiedad. Para obtener más información sobre cómo se formatean y almacenan las propiedades, consulte el manual de Xlib.

Una vez especificado el tamaño de los campos, es necesario especificar el tipo de cada campo (es decir, ¿es un entero, una cadena, un átomo, o qué?). Esto se hace usando un carácter de formato por campo. Si hay más campos en la propiedad que caracteres de formato proporcionados, el último carácter se repetirá tantas veces como sea necesario para los campos adicionales. Los caracteres de formato y su significado son los siguientes:

a
El campo contiene un número de átomo. Un campo de este tipo debe tener un tamaño de 32.
b
El campo es un booleano. Un 0 significa falso, mientras que cualquier otro valor significa verdadero.

xprop(1) — Arch Linux Manual Pages

NAME

xprop - property displayer for X windows

SYNOPSIS

xprop [-options ...] [-f format-file ...] [-fs format-file] [-remove property] [-set property] [-spy] [window]

SUMMARY

The xprop utility is a simple client for the X Window System that allows you to interactively display and modify properties on the X server.

When invoked without a window argument, xprop will select a window interactively using the mouse. Clicking the desired window will select it. If you click the root window, xprop will select the root window. If you click on a child window, xprop will select that child window.

When invoked with a window argument, xprop will select that window. The window can be specified either as a name or as a number. If it is a name, it is assumed to be the name of a child of the root window. If it is a number, it is assumed to be the hexadecimal id of the window.

Once a window has been selected, xprop will query the X server for the properties of that window. The properties will be displayed on the standard output, one property per line. The display format is determined by the type of the property and potentially by the property name. The display format can be specified with the -f and -fs command line options, or via the XPROPFORMATS environment variable.

If the -spy option is used, xprop will enter a loop and will print out the name of any properties added or deleted for the selected window, or any properties changed for the selected window.

If the -remove option is used, xprop will remove the specified property from the selected window and exit.

If the -set option is used, xprop will set the specified property on the selected window to the given value and exit.

OPTIONS

-id id
Select the specified window. This is an alternative to providing the window as a command line argument.
-root
Select the root window.
-name name
Select the specified window by name. This is an alternative to providing the window name as a command line argument.
-f format-file
Use the specified file as a source of formats. Multiple -f options may be specified. The formats are searched in the order the options are given.
-fs format-file
Use the specified file as a source of formats. This file is searched after any files specified with the -f option.
-remove property
Remove the specified property from the selected window and exit.
-set property [value]
Set the specified property on the selected window. If a value is given, the property is set to that value. If no value is given, the property is set to the value of the property specified on the command line. This option is intended for use with simple properties.
-spy
Monitor the selected window for changes to its properties. When a property is added, deleted, or changed, xprop will print the name of the property and its new value.
-len number
Print only the first number characters of a property value.

DESCRIPTION

The xprop utility is used to display window properties. Properties are the primary mechanism by which applications communicate with the X server and with each other. They are essentially arbitrary data stored on the X server, associated with a window.

When xprop is run, it prompts you to select a window. You can do this by clicking on the window with the mouse. Once a window is selected, xprop displays its properties. Each property is displayed with its name, type, and value. The format of the value depends on the property's type and potentially its name.

The display format of a property is controlled by a pair of strings: a format and a dformat.

The format string is a sequence of characters, each character describing one field of the property. The fields are processed from left to right. The size of each field is determined by the format character.

c
El campo es un número sin signo, un cardinal.
i
El campo es un entero con signo.
m
El campo es un conjunto de banderas de bits, donde 1 significa activado.
o
El campo es una matriz de iconos, empaquetada como una secuencia de números de 32 bits que consisten en el ancho, la altura y los valores de píxeles ARGB, según se define para la propiedad _NET_WM_ICON en la especificación Extended Window Manager Hints. Un campo de este tipo debe tener un tamaño de 32 bits.
s
Este campo y los siguientes hasta que se encuentre un 0 o el final de la propiedad representan una secuencia de bytes. Este carácter de formato solo es usable con un tamaño de campo de 8 bits y se usa con mayor frecuencia para representar una cadena de texto.
t
Este campo y los siguientes hasta que se encuentre un 0 o el final de la propiedad representan una cadena de texto internacionalizada. Este carácter de formato solo es usable con un tamaño de campo de 8 bits. Se asume que la cadena está en una codificación compatible con ICCCM y se convierte a la codificación de localización actual antes de ser emitida.
u
Este campo y los siguientes hasta que se encuentre un 0 o el final de la propiedad representan una cadena Unicode codificada en UTF-8. Este carácter de formato solo es usable con un tamaño de campo de 8 bits. Si la cadena resulta ser un carácter inválido, se imprime el tipo de violación de codificación en su lugar, seguido de la cadena formateada usando 's'. Cuando se está en un entorno que no puede mostrar cadenas codificadas en UTF-8, el comportamiento es idéntico a 's'.
x
El campo es un número hexadecimal (como 'c' pero mostrado en hexadecimal, lo más útil para mostrar IDs de ventana y similares).

Un ejemplo de formato es 32ica, que es el formato para una propiedad de tres campos de 32 bits cada uno, el primero contiene un entero con signo, el segundo un entero sin signo y el tercero un átomo.

El formato de un dformat, a diferencia del de un format, no es tan rígido. Las únicas limitaciones para un dformat son que no se puede empezar con una letra o un guion. Esto es para que pueda distinguirse de un nombre de propiedad o un argumento. Un dformat es una cadena de texto que contiene caracteres especiales que instruyen que varios campos se impriman en varios puntos de una manera similar a la cadena de formato utilizada por printf. Por ejemplo, el dformat " es ( $0, $1 \)\n" representaría el POINT 3, -4 que tiene un format de 32ii como " es ( 3, -4 )\n".

Cualquier carácter que no sea $, ?, \, o ( en un dformat se imprime como tal. Para imprimir uno de $, ?, \, o (, precedalo con un \. Por ejemplo, para imprimir un $, use \$. Se proporcionan varias secuencias especiales de barra invertida como atajos. \n causará que se muestre una nueva línea, mientras que \t causará que se muestre una tabulación. \o donde o es un número octal mostrará el carácter número o.

Un $ seguido de un número n hace que se muestre el campo número n. El formato del campo mostrado depende del carácter de formato utilizado para describirlo en el format correspondiente. Es decir, si un cardinal se describe con 'c', se imprimirá en decimal, mientras que si se describe con un 'x', se mostrará en hexadecimal.

Si el campo no está presente en la propiedad (esto es posible con algunas propiedades), se muestra <campo no disponible> en su lugar. $n+ mostrará el campo número n, luego una coma, luego el campo número n+1, luego otra coma, ... hasta el último campo definido. Si el campo n no está definido, no se muestra nada. Esto es útil para una propiedad que es una lista de valores.

Un ? se utiliza para iniciar una expresión condicional, una especie de declaración if-then. ?exp(texto) mostrará texto si y solo si exp se evalúa como distinto de cero. Esto es útil para dos cosas. Primero, permite que los campos se muestren si y solo si una bandera está activada. Y segundo, permite que un valor, como un número de estado, se muestre como un nombre en lugar de solo un número. La sintaxis de exp es la siguiente:

exp
::= término | término=exp | !exp
término
::= n | $n | mn

El operador ! es un "no" lógico, que cambia 0 a 1 y cualquier valor distinto de cero a 0. = es un operador de igualdad. Tenga en cuenta que internamente todas las expresiones se evalúan como números de 32 bits, por lo que -1 no es igual a 65535. = devuelve 1 si los dos valores son iguales y 0 si no lo son. n representa el valor constante n, mientras que $n representa el valor del campo número n. mn es 1 si la bandera número n en el primer campo con el carácter de formato 'm' en el format correspondiente está activada, 0 en caso contrario.

Ejemplos: ?m3(count: $3\n) muestra el campo 3 con la etiqueta count si y solo si la bandera número 3 (¡el conteo comienza en 0!) está activada. ?$2=0(True)?!$2=0(False) muestra el valor invertido del campo 2 como un booleano.

Para mostrar una propiedad, xprop necesita tanto un format como un dformat. Antes de que xprop use sus valores predeterminados de un format de 32x y un dformat de " = $0+\n", busca varios lugares en un intento de encontrar formatos más específicos. Primero, se realiza una búsqueda utilizando el nombre de la propiedad. Si esto falla, se realiza una búsqueda utilizando el tipo de la propiedad. Esto permite definir el tipo STRING con un conjunto de formatos, mientras se permite que la propiedad WM_NAME, que es de tipo STRING, se defina con un formato diferente. De esta manera, los formatos de visualización para un tipo dado pueden ser anulados para propiedades específicas.

Las ubicaciones buscadas son, en orden: el formato si alguno se especifica con el nombre de la propiedad (como en 8x WM_NAME), los formatos definidos por las opciones -f de último a primero, el contenido del archivo especificado por la opción -fs si existe, el contenido del archivo especificado por la variable de entorno XPROPFORMATS si existe, y finalmente el archivo de formatos incorporado de xprop.

El formato de los archivos a los que se refieren los argumentos -fs y la variable XPROPFORMATS es una o más líneas de la siguiente forma:

nombre formato [dformato]

Donde nombre es el nombre de una propiedad o el nombre de un tipo, formato es el formato que se usará con nombre y dformato es el dformato que se usará con nombre. Si dformato no está presente, se asume " = $0+\n".

EJEMPLOS

Para mostrar el nombre de la ventana raíz: xprop -root WM_NAME

Para mostrar las sugerencias del gestor de ventanas para el reloj: xprop -name xclock WM_HINTS

Para mostrar el inicio del búfer de corte: xprop -root -len 100 CUT_BUFFER0

Para mostrar el tamaño del punto de la fuente fija: xprop -font fixed POINT_SIZE

Para mostrar todas las propiedades de la ventana # 0x200007: xprop -id 0x200007

Para establecer una propiedad de cadena simple: xprop -root -format MY_ATOM_NAME 8s -set MY_ATOM_NAME "mi_valor"

ENTORNO

DISPLAY
Para obtener la pantalla predeterminada.
XPROPFORMATS
Especifica el nombre de un archivo del cual se obtendrán formatos adicionales.
