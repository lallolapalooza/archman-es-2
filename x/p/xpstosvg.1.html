NOMBRE

xpstosvg - convertidor de XPS a SVG

SINOPSIS

xpstosvg [OPCIÓN...] ARCHIVO [ARCHIVO DE SALIDA]

DESCRIPCIÓN

xpstosvg convierte documentos XPS a formato SVG. xpstosvg lee el archivo XPS, ARCHIVO, y escribe un archivo SVG, ARCHIVO DE SALIDA. Si ARCHIVO DE SALIDA no se especifica, el nombre del archivo de salida se derivará del nombre del archivo ARCHIVO.

OPCIONES

-?, --help

Muestra las opciones de ayuda.

-d DOCUMENTO, --documento=DOCUMENTO

El documento dentro del archivo XPS a convertir. Por defecto, se utiliza el primer documento del archivo XPS.

-f PÁGINA, --primera=PÁGINA

La primera página a convertir.

-l PÁGINA, --última=PÁGINA

La última página a convertir.

-o, --impar

Convierte solo páginas impares.

-e, --par

Convierte solo páginas pares.

-r RESOLUCIÓN, --resolución=RESOLUCIÓN

Resolución horizontal y vertical en PPI (Píxeles Por Pulgada). El valor predeterminado es 150 PPI.

--rx=RESOLUCIÓN

Resolución horizontal en PPI (Píxeles Por Pulgada). El valor predeterminado es 150 PPI.

--ry=RESOLUCIÓN

Resolución vertical en PPI (Píxeles Por Pulgada). El valor predeterminado es 150 PPI.

-x X, --recortar-x=X

La coordenada x de la esquina superior izquierda del área de recorte.

-y Y, --recortar-y=Y

La coordenada y de la esquina superior izquierda del área de recorte.

-w ANCHO, --recortar-ancho=ANCHO

El ancho del área de recorte.

-h ALTURA, --recortar-altura=ALTURA

La altura del área de recorte.

--ancho-papel=ANCHO

El ancho del papel.

--alto-papel=ALTURA

La altura del papel.

--expandir

Expande las páginas más pequeñas que el papel para llenar el papel. Por defecto, las páginas no se escalan.

--no-reducir

No escala las páginas más grandes que el papel. Por defecto, las páginas más grandes que el papel se reducen para que quepan.

--no-centrar

No centra en el papel las páginas más pequeñas que el papel (después de cualquier escalado). Por defecto, las páginas más pequeñas que el papel se alinean a la esquina inferior izquierda.

ERRORES

Por favor, envíe informes de errores a https://bugzilla.gnome.org/enter_bug.cgi?product=libgxps.
