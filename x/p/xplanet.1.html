XPLANET(1) Manual de comandos generales XPLANET(1)

NOMBRE

xplanet - renderiza una imagen de un planeta en una ventana X o archivo

SINOPSIS

xplanet [opciones]

DESCRIPCIÓN

Xplanet es similar a Xearth, donde se renderiza una imagen de la tierra en una ventana X. Se pueden dibujar todos los planetas principales y la mayoría de los satélites. También se admiten varias proyecciones de mapa diferentes, incluyendo azimutales, de Mercator, de Mollweide, ortográficas y rectangulares. La última versión siempre se puede encontrar en http://xplanet.sourceforge.net.

OPCIONES

Las opciones solo necesitan especificarse con suficientes caracteres para ser inequívocas. Las opciones válidas para Xplanet son:

-archivo_arco
Especifica un archivo de arco para ser trazado contra las estrellas de fondo. Cada línea en el archivo debe tener la siguiente sintaxis: 
dec1 ra1 dec2 ra2
donde la declinación está en grados y el ascensión recta está en horas. Esta opción no tiene efecto si se especifica -proyeccion.
-espaciado_arco espaciado
Al dibujar un arco, dibuja segmentos de línea que estén separados por espaciado grados. El valor predeterminado es 0.1 grados. Los segmentos de línea más cortos que espaciado no se dibujarán.
-grosor_arco grosor
Especifica el grosor de los arcos. El valor predeterminado es 1 píxel. Al dibujar arcos en un planeta usando la opción archivo_arco en el archivo de configuración, use también la opción grosor_arco allí.
-fondo archivo_fondo
Usa archivo_fondo como imagen de fondo, con el planeta a superponer sobre él. También se puede proporcionar un color (por ejemplo, -fondo "azul marino" o -fondo 0xff00ff).
-magnitud_base magnitud
Una estrella de la magnitud especificada tendrá un brillo de 1 píxel. El valor predeterminado es 10. Las estrellas se dibujarán más brillantes si este número es mayor.
-cuerpo cuerpo
Renderiza una imagen del planeta o satélite especificado. Los valores válidos para cuerpo son sol, mercurio, venus, tierra, luna, marte, fobos, deimos, júpiter, io, europa, ganímedes, calisto, saturno, mimas, encélado, tetis, dione, rea, titán, hiperión, iapetus, febe, urano, miranda, ariel, umbriel, titania, oberón, neptuno, tritón, nereida, plutón, caronte, aleatorio y principal.

El campo de visión también se puede centrar en la ubicación de un satélite usando "naif" o "norad", junto con el ID del satélite. Por ejemplo, "-cuerpo naif-82" centrará el campo de visión en el ID NAIF -82, que es el orbitador Cassini. Xplanet debe compilarse con soporte SPICE y los kernels requeridos deben estar presentes. Ver el README en el subdirectorio spice para más detalles. Usando "-cuerpo norad20580" centrará el campo de visión en el ID NORAD 20580, que es el Telescopio Espacial Hubble. Los archivos TLE apropiados deben estar presentes en este caso. Ver el README en el subdirectorio satellites para más información.

Usar "ruta" centrará el campo de visión en la dirección de movimiento del origen. Esta dirección es relativa a la dirección de movimiento del cuerpo especificado con -relativo_a_ruta.

La Tierra es el cuerpo predeterminado. Esta opción es la misma que -objetivo.

-centro +x+y
Coloca el centro del cuerpo renderizado en las coordenadas de píxel (x, y). La esquina superior izquierda de la pantalla está en (0,0). Cualquiera de x o y puede ser negativo. El valor predeterminado es el centro de la pantalla.
-color color
Establece el color de la etiqueta. El valor predeterminado es "rojo". Cualquier color en el archivo rgb.txt puede ser usado. Los colores también pueden especificarse por valores hexadecimales RGB; por ejemplo, -color 0xff y -color azul significan lo mismo, al igual que -color 0xff0000 y -color rojo.
-config archivo_config
Usa el archivo de configuración archivo_config. El formato de archivo_config se describe en README.config. Ver la descripción de -subdir para ver dónde busca xplanet para encontrar el archivo de configuración.
-crear_tablas_dispersión archivo_dispersión
Crea tablas de búsqueda para la dispersión de Rayleigh. Ver el README en el directorio scattering para más información.
-fecha AAAAmmdd.HHMMSS
Usa la fecha especificada en lugar de la hora local actual. Se asume que la fecha es GMT.
-formato_fecha cadena
Especifica el formato para la etiqueta de fecha/hora. Esta cadena de formato se pasa a strftime(3). El valor predeterminado es "%c %Z", que muestra la fecha, la hora y la zona horaria en la representación de fecha y hora apropiada de la configuración regional.
-origen_dinamico archivo
Especifica una ubicación de observador. La ubicación es relativa al cuerpo especificado con -origen (por defecto, este es el Sol). La última línea del archivo debe tener la forma 
AAAAmmdd.HHMMSS rango lat lon horalocal
Por ejemplo, 
19951207.120000     10.328   -3.018   97.709    9.595
La hora especificada se ignora y se usa la hora actual. El rango está en radios planetarios, y lat y lon están en grados. Horalocal (en horas) es opcional, pero si está presente, se usará en lugar de la longitud. Solo se usa la última línea del archivo. Este archivo puede actualizarse entre renderizaciones usando un script ejecutado con las opciones -comando_previo o -comando_posterior.
-archivo_efemerides nombre_archivo
Especifica un archivo de efemérides digital de JPL (DE200, DE405 o DE406) para usar en el cálculo de posiciones planetarias. Xplanet utiliza el código de Bill Gray (http://www.projectpluto.com/jpl_eph.htm), que lee archivos binarios tanto de endianness big como little. Los archivos de efemérides que se encuentran en ftp://ssd.jpl.nasa.gov/pub/eph/export/unix son archivos de endianness big, pero no necesita realizar ningún cambio de bytes adicional para usarlos. Ver la descripción de -subdir para ver dónde busca xplanet para encontrar el archivo de efemérides.
-fuente nombre_fuente
Establece la fuente para la etiqueta. Solo se admiten fuentes TrueType. Si se usa la opción -pango, nombre_fuente se toma como el nombre de la familia de fuentes (por ejemplo, "Arial").
-tamanio_fuente tamaño
Especifica el tamaño en puntos. El valor predeterminado es 12.
-fork
Desconecta del terminal de control. Esto es útil en MS Windows para ejecutar xplanet desde un archivo batch sin tener que mantener una ventana DOS abierta. Tenga cuidado al usar esta opción; es fácil tener varios procesos ejecutándose al mismo tiempo sin saberlo: revise el Administrador de Tareas. En sistemas unix, esto es prácticamente lo mismo que ejecutar xplanet en segundo plano.
-fov
Especifica el campo de visión, en grados. Esta opción y la opción -radio son mutuamente excluyentes. Esta opción no tiene efecto si se usa la opción -proyeccion.
-geometria cadena
Especifica la geometría de la imagen usando la sintaxis de geometría estándar de ventanas X, [<ancho>{xX}<alto>][{+-}<desplazamiento_x>{+-}<desplazamiento_y>] (por ejemplo, 256x256-10+10 coloca una ventana de 256x256 píxeles de tamaño a 10 píxeles de distancia del borde derecho y 10 píxeles debajo de la parte superior de la ventana raíz). La ventana raíz fuera de la imagen será negra. Esta opción se puede usar con -ventana o -salida.
-resplandor radio
Dibuja un resplandor alrededor del sol con un radio del valor especificado mayor que el sol. El valor predeterminado es 28.
-etiqueta_gmt
Lo mismo que la opción -etiqueta, pero muestra GMT en lugar de la hora local.
-grs_longitude lon
La longitud de la Gran Mancha Roja (GRS) de Júpiter. Un valor típico es 94 grados. Si se especifica esta opción, las longitudes en Júpiter se calcularán en coordenadas del Sistema II. Por defecto, las longitudes se calculan en coordenadas del Sistema III. Al usar esta opción, utilice un mapa de imagen para Júpiter donde el centro de la GRS se encuentre en la columna de píxeles 0, o en el lado izquierdo de la imagen.
-hibernate segundos
Después de que la pantalla haya estado inactiva durante el número de segundos especificado, xplanet se suspenderá. Esta opción requiere que xplanet se haya compilado con la extensión X Screensaver.
-idlewait segundos
No ejecute Xplanet a menos que la pantalla haya estado inactiva durante el número de segundos especificado. Esta opción requiere que xplanet se haya compilado con la extensión X Screensaver.
-interpolate_origin_file
Esta opción solo es útil junto con -origin_file. Calcula la posición del observador en el momento actual interpolando entre los valores especificados en el archivo de origen. Esto es útil si tiene posiciones de naves espaciales tabuladas en un archivo de origen, pero desea una vista en tiempo real.
-jdate Julian fecha
Utilice la fecha juliana especificada en lugar de la hora local actual.
-label
Muestra una etiqueta en la esquina superior derecha.
-labelpos
Especifique la ubicación de la etiqueta utilizando la sintaxis estándar de geometría de ventanas X. La posición predeterminada es "-15+15", o 15 píxeles a la izquierda y debajo de la esquina superior derecha de la pantalla. Esta opción implica -label.
-label_altitude
Muestra la altitud sobre la superficie en lugar de la distancia desde el centro del cuerpo en la etiqueta.
-label_body cuerpo
Utilice el cuerpo especificado para calcular los valores sub-observador, sub-solar e de iluminación en la etiqueta. Esto es útil con la opción -separation.
-label_string
Especifique el texto de la primera línea de la etiqueta. Por defecto, dice algo como "Mirando a la Tierra". Cualquier instancia de %t se reemplazará por el nombre del objetivo y cualquier instancia de %o se reemplazará por el nombre del origen.
-latitude latitud
Representa el cuerpo objetivo visto desde encima de la latitud especificada (en grados). El valor predeterminado es 0.
-light_time
Tiene en cuenta el tiempo que tarda la luz en viajar desde el cuerpo objetivo hasta el observador. Por defecto, se ignoran los efectos del tiempo de luz.
-localtime horalocal
Coloca al observador por encima de la longitud donde la hora local es el valor especificado. 0 es medianoche y 12 es mediodía.
-log_magstep paso
Aumenta el brillo de una estrella en 10^paso por cada disminución entera de magnitud. El valor predeterminado es 0.4. Esto significa que una estrella de magnitud 2 es 10^0.4 (aproximadamente 2.5) veces más brillante que una estrella de magnitud 3. Un número mayor hace que las estrellas sean más brillantes.
-longitude longitud
Coloca al observador por encima de la longitud especificada (en grados). La longitud es positiva hacia el este, negativa hacia el oeste (para la Tierra y la Luna), por lo que, por ejemplo, Los Ángeles está en -118 o 242. El valor predeterminado es 0.
-make_cloud_maps
Si hay una entrada en el archivo de configuración para cloud_map, xplanet generará una imagen diurna y nocturna con nubes superpuestas y luego saldrá. Las imágenes se crearán en el directorio especificado por -tmpdir, o en el directorio actual si no se utiliza -tmpdir. Los nombres de las imágenes de salida son por defecto day_clouds.jpg y night_clouds.jpg, pero pueden ser cambiados por la opción -output. Si se especifica "-output filename.extension", las imágenes de salida se llamarán "day_filename.extension" y "night_filename.extension". Las dimensiones de las imágenes de salida son las mismas que las de la imagen diurna.
-marker_file
Especifique un archivo que contenga datos de marcadores definidos por el usuario para mostrar contra las estrellas de fondo. El formato de cada línea generalmente es declinación, ascensión recta, cadena, como en el ejemplo a continuación: 
-16.7161 6.7525 "Sirius"
Para opciones adicionales que se pueden especificar, consulte la entrada marker_file en README.config. Esta opción no tiene efecto si se especifica -projection. Esta opción no está pensada para marcadores de ciudades; para eso, use la opción marker_file en el archivo de configuración.
-markerbounds archivo
Escriba las coordenadas del cuadro delimitador para cada marcador en archivo. Esto podría ser útil si está utilizando xplanet para crear mapas de imágenes para páginas web. Cada línea se ve así: 
204,312 277,324 Los Angeles
donde las coordenadas son para las esquinas superior izquierda e inferior derecha del cuadro. Este archivo se sobrescribe cada vez que xplanet representa su imagen.
-north tiponorte
Esta opción rota la imagen para que la parte superior apunte a tiponorte. Los valores válidos para tiponorte son: 
body:        polo norte del cuerpo
galactic:    polo norte galáctico
orbit:       polo norte orbital del cuerpo (perpendicular al plano orbital)
path:        vector de velocidad del origen  (ver también la opción -path_relative_to)
separation:  perpendicular a la línea de visión y a la
             línea de separación objetivo-objetivo (ver opción -separation)
El valor predeterminado es "body".
-num_times num_veces
Ejecutar num_veces antes de salir. El valor predeterminado es ejecutar indefinidamente.
-origin cuerpo
Coloca al observador en el centro del cuerpo especificado. Los valores válidos son los mismos que para -target. Además, se pueden especificar "above", "below" o "system". Usar "above" o "below" centra la vista en el primario del cuerpo y el campo de visión es lo suficientemente grande como para mostrar la órbita del cuerpo. Usar "system" coloca al observador en el centro de un cuerpo aleatorio en el mismo sistema que el cuerpo objetivo. Dos cuerpos están en el mismo sistema si se cumple una de las siguientes condiciones: 
 1) objetivo y origen tienen el mismo primario
 2) objetivo es el primario del origen
 3) origen es el primario del objetivo
Si el nombre del cuerpo va precedido por un guion, el observador se coloca en el lado opuesto del objetivo desde el cuerpo especificado a una distancia igual a la distancia entre el objetivo y el cuerpo. Por ejemplo, -target earth -origin sun coloca al observador en el centro del sol. Si se usa -target earth -origin -sun, el observador se coloca en una línea que une los centros de la Tierra y el Sol a una distancia de 1 AU más allá del Sol que la Tierra.
-origin_file archivo_origen
Especifique una lista de posiciones de observador en archivo_origen. Las posiciones son relativas al cuerpo especificado con -origin (por defecto, este es el Sol). Cada línea debe tener el formato 
AAAA MM DD.HHMMSS rango lat lon horalocal
Por ejemplo, 
19951207.120000     10.328   -3.018   97.709    9.595
El rango está en radios planetarios, y latitud y longitud en grados. La fecha es el único valor requerido. Si se proporciona la hora local (en horas), se utilizará en lugar de la longitud. Para cada línea en el archivo de origen, el observador se coloca en la posición especificada, relativa al cuerpo especificado con -origin. Esta opción es útil para mostrar sobrevuelos de naves espaciales o para orbitar alrededor de un planeta. Cualquier línea que tenga un # en la primera columna se ignora.
-output archivo
Salida a un archivo en lugar de representar en una ventana. El formato del archivo se toma de la extensión. Actualmente se pueden crear imágenes .gif, .jpg, .ppm, .png y .tiff, si xplanet se ha compilado con las bibliotecas apropiadas. El tamaño de la imagen por defecto es de 512 por 512 píxeles, pero esto puede cambiarse con la bandera -geometry. Si se usa con la opción -num_times, cada archivo de salida se numerará secuencialmente.
-output_map archivo
Genera el mapa rectangular intermedio que se crea en el proceso de renderizar la imagen final. Tendrá las mismas dimensiones que el mapa diurno por defecto.
-output_start_index índice
Inicia la numeración de los archivos de salida en índice. El valor predeterminado es 0.
-pango
Utiliza la biblioteca Pango (http://www.pango.org) para representar texto internacionalizado. Pango utiliza Unicode para toda su codificación y eventualmente admitirá la salida en todos los principales idiomas del mundo. Si xplanet no se ha compilado con esta biblioteca, esta opción se ignorará. Parece haber fugas de memoria en la biblioteca pango, por lo que no recomiendo dejar que xplanet se ejecute indefinidamente con esta opción.
-path_relative_to cuerpo
Solo se usa con -north path o -target path. El vector de velocidad del origen se calcula en relación con el cuerpo especificado. Por defecto, este es el Sol.
-post_command comando
-prev_command comando
Ejecuta un comando antes o después de que xplanet represente una imagen. En MS Windows, es posible que necesite usar rutas de estilo Unix. Por ejemplo: 
xplanet.exe -prev_command ./prev.bat
-print_ephemeris
Imprime las coordenadas rectangulares ecuatoriales heliocéntricas (J2000) para cada cuerpo que xplanet conoce, y luego sale.

NAME

xplanet - dibuja un globo terráqueo en una ventana o como fondo de escritorio

SYNOPSIS

xplanet [OPTIONS] [BODY...]

DESCRIPTION

xplanet dibuja un globo terráqueo en una ventana o como fondo de escritorio. Puede mostrar múltiples planetas, sus lunas, el sol, nubes, marcadores, satélites, estrellas y la Vía Láctea. Las imágenes pueden crearse para ser utilizadas como fondos de escritorio en los sistemas operativos Microsoft Windows y Mac OS X.

OPTIONS

-projection tipo_proyeccion
El tipo de proyección puede ser uno de los siguientes: antiguo, azimutal, bonne, área_equivalente, gnomónico, hemisferio, lambert, mercator, mollweide, ortográfico, peters, policónico, rectangular o tsc. El valor predeterminado es sin proyección. No se mostrarán múltiples cuerpos si se especifica esta opción, aunque las sombras aún se dibujarán.
-proj_param valor
Pasa parámetros adicionales para algunas proyecciones. Las únicas proyecciones que utilizan esta opción actualmente son las proyecciones de Bonne, Gnomónica y Mercator. La proyección de Bonne es conforme en la latitud especificada. Valores más altos conducen a una forma de corazón más delgada. El valor predeterminado es 50 grados. Las proyecciones Gnomónica y Mercator utilizan la latitud especificada como límites de la proyección. Los valores predeterminados son 45 y 80 grados, respectivamente. Esta opción puede usarse más de una vez para futuras proyecciones que requieran parámetros adicionales. Actualmente solo se utiliza el primer valor.
-quality calidad
Esta opción solo se usa al crear imágenes JPEG. La calidad puede variar de 0 a 100. El valor predeterminado es 80.
-radius radio
Especifica el radio del globo como un porcentaje de la altura de la pantalla. El valor predeterminado es el 45% de la altura de la pantalla. Al dibujar Saturno, el valor del radio se aplica al radio del anillo exterior.
-random
Coloca al observador en una latitud y longitud aleatorias.
-range rango
Renderiza el globo visto desde una distancia de `rango` desde el centro del planeta, en unidades del radio planetario. El valor predeterminado es 1000. Ten en cuenta que si usas rangos muy cercanos, ¡el campo de visión de la pantalla puede ser mayor de 180 grados! Si quieres una imagen "cercana", usa la opción -radius.
-rotate angulo
Rota el globo `angulo` grados en sentido antihorario para que el norte (definido por el argumento -north) no esté en la parte superior. El valor predeterminado es 0. ¡Mis amigos del hemisferio sur pueden usar -rotate 180 para que la Tierra se vea como debería! Para proyecciones no ortográficas, el globo se rota y luego se proyecta, si eso te ayuda a visualizar qué esperar.
-save_desktop_file
En Microsoft Windows y Mac OS X, xplanet crea un archivo de imagen intermedio que se utiliza para establecer el escritorio. Este archivo se creará en el directorio -tmpdir. Por defecto, esta imagen se elimina después de que se ha configurado el escritorio. Especificar esta opción dejará el archivo en su lugar.
-searchdir directorio
Cualquier archivo utilizado por xplanet debe colocarse en uno de los siguientes directorios según su tipo: "arcs", "config", "ephemeris", "fonts", "images", "markers", "origin", "satellites" o "stars". Por defecto, xplanet buscará un archivo en el siguiente orden: 
El directorio actual
searchdir
subdirectorios de searchdir
subdirectorios de xplanet (si existe en el directorio actual)
subdirectorios de ${HOME}/.xplanet en X11
subdirectorios de ${HOME}/Library/Xplanet en Mac OS X
subdirectorios de DATADIR/xplanet
DATADIR se establece en el momento de la compilación y por defecto es /usr/local/share.
-separation cuerpo:dist
Coloca al observador en una ubicación donde el cuerpo objetivo y el cuerpo de separación estén separados `dist` grados. Por ejemplo, "-target earth -separation moon:-3" significa colocar al observador en una ubicación donde la luna aparezca 3 grados a la izquierda de la Tierra.
-spice_ephemeris indice
Usa kernels SPICE para calcular la posición del cuerpo nombrado. El índice es el código de identificación naif (por ejemplo, 599 para Júpiter). La opción -spice_file debe usarse para proporcionar los nombres de los archivos kernel. Esta opción puede usarse más de una vez para diferentes cuerpos.
-spice_file archivo_spice
Especifica un archivo que contiene una lista de objetos a mostrar. Debe existir un archivo que contenga una lista de kernels SPICE a leer llamado spice_file.krn junto con spice_file. Vea el README en el subdirectorio "spice" para más información.
-starfreq frecuencia
Fracción de píxeles de fondo que se colorearán de blanco. El valor predeterminado es 0.001. Esta opción solo tiene sentido con las proyecciones azimutal, mollweide, ortográfica y de peters.
-starmap mapa_estrellas
Usa `mapa_estrellas` para dibujar las estrellas de fondo. Este archivo debe ser un archivo de texto donde cada línea tenga el siguiente formato: 
Declinación, Ascensión Recta, Magnitud
donde la Declinación está en grados decimales y la Ascensión Recta está en horas decimales. Por ejemplo, la entrada para Sirio es 
-16.7161  6.7525 -1.46
Consulta la descripción de -searchdir para ver dónde busca xplanet para encontrar el mapa estelar.
-target objetivo
Igual que -body.
-tt
Usa tiempo terrestre en lugar de tiempo universal. Los dos difieren ligeramente debido a la rotación no uniforme de la Tierra. El valor predeterminado es usar tiempo universal.
-timewarp
Al igual que en xearth, escala la tasa aparente a la que progresa el tiempo por el factor. El valor predeterminado es 1.
-tmpdir dir_temporal
Especifica un directorio que xplanet utilizará para colocar las imágenes creadas con -make_cloud_maps. En Microsoft Windows, xplanet escribirá un archivo de mapa de bits llamado xplanet.bmp en el directorio especificado. El valor predeterminado es el resultado de la llamada GetWindowsDirectory (C:WINDOWS en Win95). En Mac OS X, xplanet creará un archivo PNG intermedio para establecer el fondo. El valor predeterminado es /tmp. En Windows y Mac OS X, el archivo intermedio se eliminará a menos que se especifique la opción -save_desktop_file.
-transparency
Actualiza el pixmap de fondo para Eterms y aterms transparentes. Esta opción solo funciona en X11.
-transpng nombre_archivo
Igual que la opción -output, excepto que establece el fondo en transparente al escribir un archivo PNG.
-utclabel
Igual que -gmtlabel.
-verbosity nivel
nivel      salida
< 0        solo mensajes de error fatales
0          mensajes de advertencia no fatales
1          información básica
2          diagnósticos básicos
3          diagnósticos más detallados
4          diagnósticos muy detallados
El valor predeterminado es 0.
-version
Muestra la información de la versión actual, junto con una lista de opciones de compilación que xplanet admite.
-vroot
Renderiza la imagen en la ventana raíz virtual. Algunos gestores de ventanas usan una ventana grande que se superpone a la ventana raíz real como su ventana de fondo. Xscreensaver usa una ventana raíz virtual para cubrir la pantalla también.
-wait espera
Actualiza cada `espera` segundos.
-window
Renderiza la imagen en su propia ventana X. El tamaño por defecto es 512 por 512 píxeles, pero esto puede establecerse con la opción -geometry.
-window-id ID
Al usar el sistema de ventanas X11, dibuja en la ventana con el ID especificado.
-window_title titulo
Establece el título de la ventana a `titulo`. Esta opción implica -window.
-XID ID
Igual que -window-id.
-xscreensaver
Igual que -vroot.
