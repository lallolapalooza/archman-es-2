FBB::Xpointer(3bobcat) Establece el puntero X FBB::Xpointer(3bobcat)

NOMBRE

FBB::Xpointer - Establece la ubicación del puntero X-windows

SINOPSIS

#include <bobcat/xpointer>

Opción de enlazado: -lbobcat -lX11

DESCRIPCIÓN

Esta clase permite a los programas que se ejecutan dentro del entorno gráfico X establecer y recuperar la ubicación del puntero de X-windows.

ESPACIO DE NOMBRES

FBB
Todos los constructores, miembros, operadores y manipuladores mencionados en esta página de manual están definidos en el espacio de nombres FBB.

HEREDA DE

-

CONSTRUCTORES

o
Xpointer():
El constructor por defecto. Se conecta a la pantalla. Lanza una excepción Exception si no se puede abrir la pantalla. Con múltiples objetos Xpointer, la conexión a la pantalla solo se abre una vez.
Este constructor lanza una excepción Exception si no pudo conectarse a la Pantalla.

Los constructores y operadores de copia y movimiento están disponibles.

FUNCIONES MIEMBRO

o
bool get(int *x, int *y) const:
Devuelve en sus argumentos las coordenadas actuales del puntero relativas a la ventana raíz. Devuelve true si tiene éxito; devuelve false si el puntero no se pudo mover.
o
bool set(int x, int y) const:
Establece el puntero a una ubicación cuyas coordenadas de píxeles se proporcionan con respecto a la ventana raíz. Una coordenada x negativa se mide desde el margen derecho de la pantalla de la ventana raíz (yendo hacia la izquierda), una coordenada y negativa se mide desde el margen inferior de la pantalla de la ventana raíz (yendo hacia arriba). Devuelve true si tiene éxito; devuelve false si el puntero no se pudo mover.

EJEMPLO

#include <iostream>
#include <string>
#include <bobcat/xpointer>
using namespace FBB;
int main()
try
{
    Xpointer xpointer;
    xpointer.verify();
    if (!xpointer.set(100, 200))
        throw string("Set pointer failed");
    int x;
    int y;
    if (!xpointer.get(&x, &y))
        throw string("Get pointer failed");
    cout << "Pointer now at " << x << ", " << y << ’\n’;
}
catch (string msg)
{
    cout << msg << ’\n’;
    return 1;
}
