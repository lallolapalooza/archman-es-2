xpdf(1) Manual de Comandos Generales xpdf(1)

NOMBRE

xpdf - visor de archivos en formato PDF (Portable Document Format) (versión 4.05)

SINOPSIS

xpdf [opciones] [archivo-PDF [:página | +destino]] ...

xpdf [opciones] -remote nombre-remoto [comando ...]

xpdf [opciones] -open [archivo-PDF]

DESCRIPCIÓN

Xpdf es un visor de archivos en formato PDF (Portable Document Format). (Estos también se conocen a veces como archivos 'Acrobat', por el nombre del software PDF de Adobe). Xpdf utiliza el conjunto de herramientas GUI Qt y se ejecuta en Unix, OS X y Windows.

Para ejecutar xpdf, escribe:

xpdf archivo.pdf

donde archivo.pdf es tu archivo PDF. El nombre del archivo puede ir seguido de un número de página a mostrar, precedido por dos puntos:

xpdf archivo.pdf :18

o por un destino con nombre, precedido por un signo de aposento (esto solo es útil con archivos PDF que proporcionan destinos con nombre):

xpdf archivo.pdf +destinoA

Si especificas varios archivos, cada uno se abrirá en una pestaña separada:

xpdf archivo1.pdf archivo2.pdf :18 archivo3.pdf

También puedes iniciar xpdf sin abrir ningún archivo:

xpdf

ARCHIVO DE CONFIGURACIÓN

Xpdf lee un archivo de configuración al inicio. Primero intenta encontrar el archivo de configuración privado del usuario, ~/.xpdfrc. Si este no existe, busca un archivo de configuración a nivel de sistema, típicamente /etc/xpdfrc (pero esta ubicación puede cambiarse cuando se compila xpdf). Consulta la página del manual xpdfrc(5) para obtener detalles.

OPCIONES

Las siguientes opciones de línea de comandos están disponibles. Todas las opciones de línea de comandos deben aparecer antes que cualquier archivo PDF a abrir.

Muchas de las opciones se pueden configurar con comandos en el archivo de configuración. Estos se enumeran entre corchetes con la descripción de la opción de línea de comandos correspondiente.

-geometry geometría
Establece la geometría inicial de la ventana.
-title título
Establece el título de la ventana. Por defecto, el título será "xpdf: foo.pdf".
-open [archivo-PDF]
Esta opción configura un servidor remoto por defecto. Si Xpdf ya se está ejecutando (con el modificador "-open"), el archivo PDF (si existe) se abre en una nueva pestaña. Si Xpdf (con el modificador "-open") aún no se está ejecutando, inicia Xpdf y abre el archivo PDF (si existe). Esto es útil para entornos de escritorio GUI, por ejemplo, el caso típico de doble clic en un archivo PDF.
-rv
Establece el modo de video inverso. Esto invierte los colores de todo excepto las imágenes. Puede que no siempre produzca buenos resultados para archivos PDF que hacen cosas extrañas con el color. Esto también hace que el color del papel sea negro por defecto.
-papercolor color
Establece el color del "papel", es decir, el fondo de la visualización de la página. El color puede ser #RRGGBB (hexadecimal) o un color con nombre. Esta opción no funcionará bien con archivos PDF que ponen blanco detrás del texto. [archivo de config: paperColor]
-mattecolor color
Establece el color mate, es decir, el color utilizado para el fondo fuera del área real de la página. El color puede ser #RRGGBB (hexadecimal) o un color con nombre. [archivo de config: matteColor]
-fsmattecolor color
Establece el color mate para el modo de pantalla completa. El color puede ser #RRGGBB (hexadecimal) o un color con nombre. [archivo de config: fullScreenMatteColor]
-z zoom
Establece el factor de zoom inicial. Un número especifica un porcentaje de zoom, donde 100 significa 72 ppp. También puede especificar 'página' para ajustar la página al tamaño de la ventana, o 'ancho' para ajustar el ancho de la página al ancho de la ventana. [archivo de config: initialZoom]
-rot ángulo
Rota las páginas 0 (por defecto), 90, 180 o 270 grados.
-aa sí | no
Habilita o deshabilita el suavizado de fuentes (anti-aliasing). Por defecto es "sí". [archivo de config: antialias]
-aaVector sí | no
Habilita o deshabilita el suavizado de vectores (anti-aliasing). Por defecto es "sí". [archivo de config: vectorAntialias]
-enc nombre-codificación
Establece la codificación a utilizar para la salida de texto. El nombre-codificación debe definirse con el comando unicodeMap (ver xpdfrc(5)). Por defecto es "Latin1" (que es una codificación incorporada). [archivo de config: textEncoding]
-pw contraseña
Especifica la contraseña para el archivo PDF. Puede ser la contraseña del propietario (que omitirá todas las restricciones de seguridad) o la contraseña del usuario.
-fullscreen
Abre xpdf en modo de pantalla completa, útil para presentaciones.
-remote nombre-remoto
Inicia Xpdf en modo de servidor remoto. Ver la sección MODO DE SERVIDOR REMOTO.
-display pantalla
Establece la pantalla X (solo disponible con X11).
-cmd
Imprime los comandos a medida que se ejecutan (útil para depuración). [archivo de config: printCommands]
-tabstate archivo-estado-pestañas
Establece el archivo utilizado por los comandos loadTabState y saveTabState. [archivo de config: tabStateFile]
-cfg archivo-configuración
Lee archivo-configuración en lugar de ~/.xpdfrc o el archivo de configuración a nivel de sistema.
-v
Imprime información de copyright y versión.
-h
Imprime información de uso. (-help y --help son equivalentes).

Barra de menús

La barra de menús está encima de la barra de herramientas. Los elementos del menú deberían ser autoexplicativos.

Lista de pestañas

La lista de pestañas está a la izquierda, justo debajo de la barra de herramientas. Lista todas las pestañas abiertas.

Panel de esquema/capas/adjuntos

Este panel está a la izquierda, debajo de la lista de pestañas. El menú emergente le permite seleccionar entre esquema, capas o adjuntos.

El esquema es una estructura similar a un árbol de marcadores que permite moverse dentro del archivo PDF. No todos los archivos PDF tienen esquemas.

Las capas (también conocidas como contenido opcional) permiten mostrar u ocultar partes del contenido del PDF. No todos los archivos PDF tienen capas.

Los adjuntos son otros archivos incrustados dentro del archivo PDF. Hay un botón 'guardar' para cada archivo adjunto. No todos los archivos PDF tienen adjuntos.

Selección de texto

En el modo de selección de bloque, arrastrar el ratón con el botón izquierdo presionado resaltará un rectángulo arbitrario. Hacer clic con Mayús extenderá la selección.

En el modo de selección lineal, arrastrar con el botón izquierdo resaltará el texto en orden de lectura. Hacer doble clic o triple clic seleccionará una palabra o una línea, respectivamente. Hacer clic con Mayús extenderá la selección.

El texto seleccionado se puede copiar al portapapeles (con el elemento de menú editar/copiar). En X11, el texto seleccionado estará disponible en el búfer de selección X.

Enlaces

Cuando el ratón está sobre un hipervínculo, el destino del enlace se mostrará en una ventana emergente cerca de la parte inferior de la ventana.

Hacer clic en un hipervínculo saltará al destino del enlace. Un enlace a otro documento PDF hará que xpdf cargue ese documento. Un enlace de 'lanzamiento' a un programa ejecutable mostrará un diálogo y, si hace clic en 'aceptar', ejecutará el programa. Los enlaces de URL se abren de forma dependiente del sistema. (En UNIX, Qt usa la variable de entorno $BROWSER).

Asociaciones de ratón

El botón izquierdo del ratón se utiliza para seleccionar texto (ver arriba).

Hacer clic en un enlace con el botón central abre el enlace en una nueva pestaña.

Arrastrar el ratón con el botón central presionado desplaza la ventana.

El botón derecho del ratón abre un menú emergente (ver popupMenuCmd en xpdfrc(5)).

Modo de pantalla completa

Xpdf se puede colocar en modo de pantalla completa mediante la opción de línea de comandos -fullscreen, el elemento de menú 'pantalla completa' o una asociación al comando fullScreenMode o toggleFullScreenMode.

Entrar en modo de pantalla completa cambia automáticamente al modo de vista de una sola página y al factor de zoom de ajuste de página.

Se puede salir del modo de pantalla completa mediante la asociación de teclas <esc> predeterminada, o mediante una asociación al comando windowMode o toggleFullScreenMode.

COMANDOS

Las asociaciones de teclas y ratón de Xpdf son configurables por el usuario, utilizando los comandos bind y unbind en el archivo de configuración (ver xpdfrc(5)). El comando bind le permite asociar una tecla o un botón del ratón a una secuencia de uno o más comandos.

En los comandos que toman argumentos (entre paréntesis), los caracteres especiales (a saber, '(', ')', ',' y '\x01') se pueden escapar precediéndolos con un carácter '\x01'. Esto es útil principalmente en cosas como scripts que necesitan poder abrir archivos PDF arbitrarios, utilizando el comando 'openFile'.

Ejecuta un comando externo. El comando puede incluir las siguientes variables de sustitución:
    %f => nombre del archivo actual (sin extensión)
    %u => URL del enlace (o cadena vacía si no está sobre un enlace URL)
    %p => número de página actual (o cadena vacía si no hay archivo abierto)
    %x => coordenada x superior izquierda de la selección (o 0 si no hay selección)
    %y => coordenada y superior izquierda de la selección (o 0 si no hay selección)
    %X => coordenada x inferior derecha de la selección (o 0 si no hay selección)
    %Y => coordenada y inferior derecha de la selección (o 0 si no hay selección)
    %i => página que contiene el puntero del ratón
    %j => coordenada x del puntero del ratón
    %k => coordenada y del puntero del ratón
    %% => %
La cadena de comando externa a menudo contendrá espacios, por lo que el comando completo debe ser citado en el archivo xpdfrc: 
    bind x "run(ls -l)"

MODO SERVIDOR REMOTO

Iniciar xpdf con el modificador "-remote" lo pone en modo servidor remoto. Todas las opciones restantes de la línea de comandos son comandos (ver la sección COMMANDS). Las invocaciones subsiguientes de "xpdf -remote" con el mismo nombre de servidor remoto enviarán comandos a la instancia de xpdf ya en ejecución. Los comandos "checkOpenFile" son útiles aquí para cosas como cambiar de página. Por ejemplo:


# Inicia xpdf y abre algo.pdf.
xpdf -remote foo 'openFile(algo.pdf)'


# Cambia a la página 7 en el algo.pdf ya abierto. Si el usuario
# ha cerrado xpdf en el ínterin, esto lo reiniciará y reabrirá
# el archivo.
xpdf -remote foo 'checkOpenFileAtPage(algo.pdf, 7)'
