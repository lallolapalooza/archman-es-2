XPATH(1) Documentación de Perl aportada por el usuario XPATH(1)

NOMBRE

xpath - un script para consultar sentencias XPath en documentos XML.

SINOPSIS

xpath [-s sufijo] [-p prefijo] [-n] [-q] -e consulta [-e consulta] ... [archivo] ...

DESCRIPCIÓN

xpath utiliza el módulo perl XML::XPath para realizar consultas XPath a cualquier documento XML. El módulo XML::XPath pretende cumplir exactamente con la especificación XPath en "http://www.w3.org/TR/xpath" y aun así permite añadir extensiones en forma de funciones.

El script toma cualquier número de punteros XPath y trata de aplicarlos a cada documento XML proporcionado en la línea de comandos. Si no se proporcionan argumentos de archivo, la consulta se realiza utilizando "STDIN" como documento XML.

Cuando existen múltiples consultas, el resultado de la última consulta se utiliza como contexto para la siguiente consulta y solo se emite el resultado de la última. El contexto de la primera consulta es siempre la raíz del documento actual.

OPCIONES

-q

Silencioso. Emitir solo errores (y ningún separador) en stderr.

-n

Nunca usar una DTD externa, es decir, instanciar el módulo XML::Parser con 'ParseParamEnt => 0'.

-s sufijo

Colocar "sufijo" al final de cada entrada. Por defecto es un salto de línea.

-p prefijo

Colocar "prefijo" antes de cada entrada. Por defecto es nada.
