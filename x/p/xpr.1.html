NOMBRE

xpr - imprimir un volcado de ventana X

SINOPSIS

xpr [ -device tipodispositivo ] [ -scale escala ] [ -height pulgadas ] [ -width pulgadas ] [ -left pulgadas ] [ -top pulgadas ] [ -header cadena ] [ -trailer cadena ] [ -landscape ] [ -portrait ] [ -plane número ] [ -gray ] [ -rv ] [ -compact ] [ -output nombrearchivo ] [ -append nombrearchivo ] [ -noff ] [ -split n ] [ -papertype formato ] [ -pheight pulgadas [ unidades ]] [ -pwidth pulgadas [ unidades ]] [ -psfig ] [ -density dpi ] [ -cutoff nivel ] [ -noposition ] [ -gamma correccion ] [ -render algoritmo ] [ -slide ] [ -version ] [ nombrearchivo ]

DESCRIPCIÓN

xpr toma como entrada un archivo de volcado de ventana producido por xwd(1) y lo formatea para su salida en impresoras PostScript, la impresora de páginas IBM PP3812, la HP LaserJet (u otras impresoras PCL), o la HP PaintJet. Si no se proporciona ningún argumento de archivo, se utiliza la entrada estándar. Por defecto, xpr imprime la representación más grande posible de la ventana en la página de salida. Las opciones permiten al usuario añadir encabezados y pies de página, especificar márgenes, ajustar la escala y la orientación, y añadir varios volcados de ventana a un único archivo de salida. La salida se dirige a la salida estándar a menos que se especifique -output.

Opciones de Comando

-device tipodispositivo
Especifica el dispositivo en el que se imprimirá el archivo. Actualmente soportados:
ljet
Serie HP LaserJet y otros dispositivos monocromáticos PCL como ThinkJet, QuietJet, RuggedWriter, impresoras de la serie HP2560 y HP2930
pjet
HP PaintJet (modo color)
pjetxl
Impresora HP PaintJet XL Color Graphics Printer (modo color)
pp
IBM PP3812
ps
Impresora PostScript
El valor predeterminado es PostScript. -device lw (LaserWriter) es equivalente a -device ps y se proporciona solo por compatibilidad anterior.
-scale escala
Afecta al tamaño de la ventana en la página. Las impresoras PostScript y HP son capaces de traducir cada bit en un mapa de bits de ventana a una cuadrícula de un tamaño especificado. Por ejemplo, cada bit podría traducirse en una cuadrícula de 3x3. Esto se especificaría con -scale 3. Por defecto, una ventana se imprime con la escala más grande que quepa en la página para la orientación especificada.
-height pulgadas
Especifica la altura máxima de la página.
-width pulgadas
Especifica el ancho máximo de la página.
-left pulgadas
Especifica el margen izquierdo en pulgadas. Se permiten fracciones. Por defecto, la ventana se centra en la página.
-top pulgadas
Especifica el margen superior para la imagen en pulgadas. Se permiten fracciones.
-header cadena
Especifica una cadena de encabezado que se imprimirá encima de la ventana.
-trailer cadena
Especifica una cadena de pie de página que se imprimirá debajo de la ventana.
-landscape
Fuerza a imprimir la ventana en modo horizontal. Por defecto, una ventana se imprime de tal manera que su lado más largo sigue al lado largo del papel.
-plane número
Especifica qué plano de bits usar en una imagen. Por defecto, se utiliza la imagen completa y los valores se mapean a blanco y negro según las intensidades de color.
-gray 2 | 3 | 4
Utiliza una conversión simple de escala de grises de 2x2, 3x3 o 4x4 en una imagen en color, en lugar de mapear estrictamente a blanco y negro. Esto duplica, triplica o cuadruplica el ancho y alto efectivos de la imagen.
-portrait
Fuerza a imprimir la ventana en modo vertical. Por defecto, una ventana se imprime de tal manera que su lado más largo sigue al lado largo del papel.
-rv
Fuerza a imprimir la ventana en video inverso.
-compact
Utiliza codificación simple de longitud de ejecución para una representación compacta de ventanas con muchos píxeles blancos.
-output nombrearchivo
Especifica un nombre de archivo de salida. Si no se especifica esta opción, se utiliza la salida estándar.
-append nombrearchivo
Especifica un nombre de archivo producido previamente por xpr al cual se va a añadir la ventana.
-noff
Cuando se especifica junto con -append, la ventana aparecerá en la misma página que la ventana anterior.
-split n
Esta opción permite al usuario dividir una ventana en varias páginas. Esto podría ser necesario para ventanas muy grandes que de lo contrario harían que la impresora se sobrecargara e imprimiera la página de manera oscura.
-papertype formato
Especifica el formato del papel de salida. Actualmente soportados:

tamaño carta 8.5x11 pulgadas

NAME

xpr - convert X11 window dump to various output formats

SYNOPSIS

xpr [ options ] [ filename ]

DESCRIPTION

The xpr command is used to convert an X11 window dump, created with the xwd program, into a variety of output formats suitable for printing on various printers.

The default output format is PostScript. Other output formats can be selected with the -device option.

The following paper sizes are supported by the PostScript device:

B10
B10 tamaño 31x44 mm o 1.22x 1.73 pulgadas
C0
C0 tamaño 917x1297 mm o 36.10x51.06 pulgadas
C1
C1 tamaño 648x917 mm o 25.51x36.10 pulgadas
C2
C2 tamaño 458x648 mm o 18.03x25.51 pulgadas
C3
C3 tamaño 324x458 mm o 12.76x18.03 pulgadas
C4
C4 tamaño 229x324 mm o 9.02x12.76 pulgadas
C5
C5 tamaño 162x229 mm o 6.38x 9.02 pulgadas
C6
C6 tamaño 114x162 mm o 4.49x 6.38 pulgadas
C7
C7 tamaño 81x114 mm o 3.19x 4.49 pulgadas
C8
C8 tamaño 57x81 mm o 2.24x 3.19 pulgadas
C9
C9 tamaño 40x57 mm o 1.57x 2.24 pulgadas
C10
C10 tamaño 28x40 mm o 1.10x 1.57 pulgadas
-pheight pulgadas [ unidades ]
Esta opción permite al usuario especificar una altura de papel específica. Las unidades por defecto son en pulgadas (in), pero pueden ser anuladas con cm o mm para centímetros o milímetros respectivamente.
-pwidth pulgadas [ unidades ]
Esta opción permite al usuario especificar un ancho de papel específico. Las unidades por defecto son en pulgadas (in), pero pueden ser anuladas con cm o mm para centímetros o milímetros respectivamente.
-psfig
Suprimir la traducción de la imagen PostScript al centro de la página.
-density dpi
Indica qué densidad de puntos por pulgada debe ser utilizada por la impresora HP.
-cutoff nivel
Cambia el nivel de intensidad donde los colores se mapean a blanco o negro para salida monocromática en una impresora LaserJet. El nivel se expresa como porcentaje de brillo completo. Se permiten fracciones.
-noposition
Esta opción provoca que la generación de comandos de posicionamiento de encabezado, pie de página e imagen sea omitida para las impresoras LaserJet, PaintJet y PaintJet XL.
-gamma corrección
Esto cambia la intensidad de los colores impresos por la impresora PaintJet XL. La corrección es un valor de punto flotante en el rango de 0.00 a 3.00. Consulte el manual del operador para determinar el valor correcto para la impresora específica.
-render algoritmo
Esto permite a la impresora PaintJet XL renderizar la imagen con el mejor equilibrio entre calidad y rendimiento. Consulte el manual del operador para determinar qué algoritmos están disponibles.
-slide
Esta opción permite imprimir transparencias para proyector utilizando las impresoras PaintJet y PaintJet XL.
-version
Esta opción imprime la información de la versión del programa y sale.

VER TAMBIÉN

xwd(1), xwud(1), X(7)

LIMITACIONES

El soporte para salida PostScript actualmente no puede manejar las opciones -append, -noff o -split.

La opción -compact *solo* se soporta para salida PostScript. Comprime los espacios en blanco pero no los espacios negros, por lo que no es útil para ventanas de video inverso.

Para imágenes en color, debería mapearse directamente al soporte de imágenes PostScript.

IMPRESORAS HP

Si no se especifica ningún -density en la línea de comandos, se asumirán 300 puntos por pulgada para ljet y 90 puntos por pulgada para pjet. Los valores de density permitidos para una impresora LaserJet son 300, 150, 100 y 75 puntos por pulgada. Consulte el manual del operador para determinar las densidades soportadas por otras impresoras.

Si no se especifica ningún -scale, la imagen se ampliará para ajustarse al área imprimible de la página.

El área imprimible por defecto es de 8x10.5 pulgadas. Se pueden acomodar otros tamaños de papel utilizando las opciones -height y -width.

Tenga en cuenta que una imagen de 1024x768 se ajusta al área imprimible por defecto cuando se procesa a 100 dpi con scale=1, la misma imagen también se puede imprimir utilizando 300 dpi con scale=3 pero requerirá una cantidad considerablemente mayor de datos que se transferirán a la impresora.

xpr puede adaptarse para su uso con impresoras PCL monocromáticas distintas de la LaserJet. Para imprimir en una ThinkJet (HP2225A) xpr podría invocarse como:

xpr -density 96 -width 6.667 nombre_archivo

o para salida en blanco y negro a una PaintJet:

xpr -density 180 nombre_archivo

La intensidad monocromática de un píxel se calcula como 0.30*R + 0.59*G + 0.11*B. Si la intensidad calculada de un píxel es menor que el nivel de -cutoff, se imprimirá como blanco. Esto mapea imágenes de pantalla de claro en oscuro a copias impresas de blanco sobre negro. La intensidad de corte por defecto es el 50% del brillo completo. Ejemplo: especificar -cutoff 87.5 mueve el punto de intensidad blanco/negro al 87.5% del brillo completo.

Una impresora LaserJet debe estar configurada con suficiente memoria para manejar la imagen. Para una página completa a 300 puntos por pulgada se requieren aproximadamente 2 MB de memoria de impresora.

Las imágenes en color se producen en la PaintJet a 90 puntos por pulgada. La PaintJet está limitada a dieciséis colores de su paleta de 330 colores en cada línea de impresión horizontal. xpr emitirá un mensaje de advertencia si se encuentran más de dieciséis colores en una línea. xpr programará la PaintJet para los primeros dieciséis colores encontrados en cada línea y usará el valor programado más cercano para otros colores presentes en la línea.

Especificar la opción -rv, video inverso, para la PaintJet intercambiará el blanco y el negro en la imagen de salida. Ningún otro color se cambia.

Las imágenes de múltiples planos deben ser grabadas por xwd en formato ZPixmap. Las imágenes de un solo plano (monocromáticas) pueden estar en formato XYPixmap o ZPixmap.

Algunas impresoras PCL no reconocen los comandos de posicionamiento de imagen. La salida para estas impresoras no se centrará en la página y es posible que las cadenas de encabezado y pie de página no aparezcan donde se espera.

Las opciones -gamma y -render solo se admiten en las impresoras PaintJet XL.

La opción -slide no se admite para impresoras LaserJet.

La opción -split no se admite para impresoras HP.

La opción -gray no se admite para impresoras HP o IBM.
