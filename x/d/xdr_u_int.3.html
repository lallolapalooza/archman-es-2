xdr(3) Manual de funciones de biblioteca xdr(3)

NOMBRE

xdr - rutinas de biblioteca para la representación externa de datos

BIBLIOTECA

Biblioteca C estándar (libc, -lc)

SINOPSIS Y DESCRIPCIÓN

Estas rutinas permiten a los programadores de C describir estructuras de datos arbitrarias de forma independiente de la máquina. Los datos para las llamadas a procedimientos remotos se transmiten utilizando estas rutinas.

Los prototipos a continuación se declaran en <rpc/xdr.h> y utilizan los siguientes tipos:

typedef int bool_t;
typedef typeof(bool_t (XDR *, void *, ...))  *xdrproc_t;

Para la declaración del tipo XDR, consulte <rpc/xdr.h>.

bool_t xdr_array(XDR *xdrs, char **arrp, unsigned int *sizep,
                 unsigned int maxsize, unsigned int elsize,
                 xdrproc_t elproc);
Un filtro primitivo que traduce entre matrices de longitud variable y sus representaciones externas correspondientes. El argumento arrp es la dirección del puntero a la matriz, mientras que sizep es la dirección del contador de elementos de la matriz; este contador de elementos no puede exceder maxsize. El argumento elsize es el sizeof de cada uno de los elementos de la matriz, y elproc es un filtro XDR que traduce entre la forma C de los elementos de la matriz y su representación externa. Esta rutina devuelve uno si tiene éxito, cero en caso contrario.
bool_t xdr_bool(XDR *xdrs, bool_t *bp);
Un filtro primitivo que traduce entre booleanos (enteros C) y sus representaciones externas. Al codificar datos, este filtro produce valores de uno o cero. Esta rutina devuelve uno si tiene éxito, cero en caso contrario.
bool_t xdr_bytes(XDR *xdrs, char **sp, unsigned int *sizep,
                 unsigned int maxsize);
Un filtro primitivo que traduce entre cadenas de bytes contadas y sus representaciones externas. El argumento sp es la dirección del puntero a la cadena. La longitud de la cadena se encuentra en la dirección sizep; las cadenas no pueden tener una longitud superior a maxsize. Esta rutina devuelve uno si tiene éxito, cero en caso contrario.
bool_t xdr_char(XDR *xdrs, char *cp);
Un filtro primitivo que traduce entre caracteres C y sus representaciones externas. Esta rutina devuelve uno si tiene éxito, cero en caso contrario. Nota: los caracteres codificados no están empaquetados y ocupan 4 bytes cada uno. Para matrices de caracteres, vale la pena considerar xdr_bytes(), xdr_opaque() o xdr_string().
void xdr_destroy(XDR *xdrs);
Una macro que invoca la rutina de destrucción asociada al flujo XDR, xdrs. La destrucción generalmente implica la liberación de estructuras de datos privadas asociadas con el flujo. Usar xdrs después de invocar xdr_destroy() no está definido.
bool_t xdr_double(XDR *xdrs, double *dp);
Un filtro primitivo que traduce entre números de precisión double de C y sus representaciones externas. Esta rutina devuelve uno si tiene éxito, cero en caso contrario.
bool_t xdr_enum(XDR *xdrs, enum_t *ep);
Un filtro primitivo que traduce entre enumeraciones C (en realidad, enteros) y sus representaciones externas. Esta rutina devuelve uno si tiene éxito, cero en caso contrario.
bool_t xdr_float(XDR *xdrs, float *fp);
Un filtro primitivo que traduce entre floats de C y sus representaciones externas. Esta rutina devuelve uno si tiene éxito, cero en caso contrario.
void xdr_free(xdrproc_t proc, char *objp);
Rutina de liberación genérica. El primer argumento es la rutina XDR para el objeto que se está liberando. El segundo argumento es un puntero al objeto en sí. Nota: el puntero pasado a esta rutina no se libera, pero lo que apunta sí se libera (recursivamente).
unsigned int xdr_getpos(XDR *xdrs);
Una macro que invoca la rutina de obtención de posición asociada al flujo XDR, xdrs. La rutina devuelve un entero sin signo, que indica la posición del flujo de bytes XDR. Una característica deseable de los flujos XDR es que la aritmética simple funciona con este número, aunque las instancias de flujo XDR no necesitan garantizar esto.
long *xdr_inline(XDR *xdrs, int len);
Una macro que invoca la rutina en línea asociada al flujo XDR, xdrs. La rutina devuelve un puntero a una pieza contigua del búfer del flujo; len es la longitud en bytes del búfer deseado. Nota: el puntero se convierte a long *.
Advertencia: xdr_inline() puede devolver NULL (0) si no puede asignar una pieza contigua de un búfer. Por lo tanto, el comportamiento puede variar entre las instancias de flujo; existe por motivos de eficiencia.
bool_t xdr_int(XDR *xdrs, int *ip);
Un filtro primitivo que traduce entre enteros C y sus representaciones externas. Esta rutina devuelve uno si tiene éxito, cero en caso contrario.
bool_t xdr_long(XDR *xdrs, long *lp);
Un filtro primitivo que traduce entre enteros long de C y sus representaciones externas. Esta rutina devuelve uno si tiene éxito, cero en caso contrario.
void xdrmem_create(XDR *xdrs, char *addr, unsigned int size,
                   enum xdr_op op);
Esta rutina inicializa el objeto de flujo XDR apuntado por xdrs. Los datos del flujo se escriben o se leen de un bloque de memoria en la ubicación addr cuya longitud no supera los size bytes. El op determina la dirección del flujo XDR (ya sea XDR_ENCODE, XDR_DECODE o XDR_FREE).
bool_t xdr_opaque(XDR *xdrs, char *cp, unsigned int cnt);
Un filtro primitivo que traduce entre datos opacos de tamaño fijo y su representación externa. El argumento cp es la dirección del objeto opaco y cnt es su tamaño en bytes. Esta rutina devuelve uno si tiene éxito, cero en caso contrario.
bool_t xdr_pointer(XDR *xdrs, char **objpp,
                   unsigned int objsize, xdrproc_t xdrobj);
Similar a xdr_reference() excepto que serializa punteros nulos, mientras que xdr_reference() no lo hace. Por lo tanto, xdr_pointer() puede representar estructuras de datos recursivas, como árboles binarios o listas enlazadas.
void xdrrec_create(XDR *xdrs, unsigned int sendsize,
                   unsigned int recvsize, char *handle,
                   typeof(int (char *, char *, int)) *readit,
                   typeof(int (char *, char *, int)) *writeit);
Esta rutina inicializa el objeto de flujo XDR apuntado por xdrs. Los datos del flujo se escriben en un búfer de tamaño sendsize; un valor de cero indica que el sistema debe usar un valor predeterminado adecuado. Los datos del flujo se leen de un búfer de tamaño recvsize; este también se puede establecer en un valor predeterminado adecuado pasando un valor cero. Cuando el búfer de salida de un flujo está lleno, se llama a writeit. De manera similar, cuando el búfer de entrada de un flujo está vacío, se llama a readit. El comportamiento de estas dos rutinas es similar a las llamadas al sistema read(2) y write(2), excepto que handle se pasa a las rutinas anteriores como primer argumento. Nota: el campo op del flujo XDR debe ser establecido por el llamador.
Advertencia: para leer desde un flujo XDR creado por esta API, necesitará llamar primero a xdrrec_skiprecord() antes de llamar a cualquier otra API XDR. Esto inserta bytes adicionales en el flujo para proporcionar límites de registro.
bool_t xdrrec_endofrecord(XDR *xdrs, bool_t sendr);
Esta rutina se usa para marcar el final de un registro. Si sendr es verdadero, el flujo XDR se prepara para enviar un registro; si es falso, el flujo XDR está listo para recibir un registro. Esta rutina devuelve uno si tiene éxito, cero en caso contrario.
bool_t xdrrec_skiprecord(XDR *xdrs);
Esta rutina se usa para omitir el registro actual. Esto es útil cuando se reciben datos en un flujo XDR que pueden contener información que no es necesaria. Esta rutina devuelve uno si tiene éxito, cero en caso contrario.
bool_t xdr_reference(XDR *xdrs, char **pp, unsigned int size,
                     xdrproc_t proc);
Un filtro primitivo que traduce entre referencias a datos y su representación externa. El argumento pp es la dirección del puntero al dato. El argumento size es el tamaño en bytes del dato. El argumento proc es una rutina XDR que traduce entre la forma C del dato y su representación externa. Esta rutina devuelve uno si tiene éxito, cero en caso contrario.
bool_t xdr_setpos(XDR *xdrs, unsigned int pos);
Una macro que invoca la rutina de establecimiento de posición asociada al flujo XDR, xdrs. La rutina establece la posición del flujo de bytes XDR en el valor pos. Esta rutina devuelve uno si tiene éxito, cero en caso contrario.
bool_t xdr_short(XDR *xdrs, short *sp);
Un filtro primitivo que traduce entre enteros cortos de C y sus representaciones externas. Esta rutina devuelve uno si tiene éxito, cero en caso contrario.
bool_t xdr_string(XDR *xdrs, char **sp, unsigned int maxsize);
Un filtro primitivo que traduce entre cadenas de caracteres terminadas en nulo y sus representaciones externas. El argumento sp es la dirección del puntero a la cadena. La longitud máxima de la cadena está dada por maxsize. Esta rutina devuelve uno si tiene éxito, cero en caso contrario.
bool_t xdr_u_char(XDR *xdrs, unsigned char *ucp);
Un filtro primitivo que traduce entre caracteres sin signo de C y sus representaciones externas. Esta rutina devuelve uno si tiene éxito, cero en caso contrario.
bool_t xdr_u_int(XDR *xdrs, unsigned int *uip);
Un filtro primitivo que traduce entre enteros sin signo de C y sus representaciones externas. Esta rutina devuelve uno si tiene éxito, cero en caso contrario.
bool_t xdr_u_long(XDR *xdrs, unsigned long *ulp);
Un filtro primitivo que traduce entre enteros largos sin signo de C y sus representaciones externas. Esta rutina devuelve uno si tiene éxito, cero en caso contrario.
bool_t xdr_union(XDR *xdrs, enum_t *switchp, char *data,
                 struct xdr_discrim *choices,
                 typeof(bool_t (XDR *, void *, enum_t *)) *defaultgo);
Un filtro primitivo que traduce entre uniones discriminadas C y sus representaciones externas. El argumento switchp es un puntero al selector de la unión. El argumento data es un puntero a los datos de la unión. El argumento choices es un puntero a una matriz de discriminantes que especifica los descriptores XDR para cada valor posible del selector. El argumento defaultgo es un puntero a una rutina que se llama si el selector no coincide con ningún valor en choices. Esta rutina devuelve uno si tiene éxito, cero en caso contrario.
bool_t xdr_vector(XDR *xdrs, char *arrp, unsigned int size,
                  unsigned int maxsize, xdrproc_t elproc);
Un filtro primitivo que traduce entre matrices de longitud fija y sus representaciones externas correspondientes. El argumento arrp es la dirección de la matriz, mientras que size es el número de elementos en la matriz. Este número no puede exceder maxsize. El argumento elproc es un filtro XDR que traduce entre los elementos de la matriz y su representación externa. Esta rutina devuelve uno si tiene éxito, cero en caso contrario.
bool_t xdr_void(void);
Un filtro primitivo que no hace nada. Se utiliza para indicar que no hay datos que serializar o deserializar. Esta rutina siempre devuelve uno.
bool_t xdr_wrapstring(XDR *xdrs, char **sp);
Una rutina de envoltura para xdr_string que se usa para serializar cadenas de caracteres de longitud arbitraria. El argumento sp es la dirección del puntero a la cadena. Esta rutina devuelve uno si tiene éxito, cero en caso contrario.

NOMBRE

xdr_u_int, xdr_u_long, xdr_u_short, xdr_void - filtro de primitivas XDR para enteros sin signo, cadenas y métodos de validación de datos

BIBLIOTECA

Librería de RPC de librería C (libtirpc, o librpc)

SINOPSIS Y DESCRIPCIÓN

#include <rpc/rpc.h>
bool_t xdr_u_char(XDR *xdrs, unsigned char *ucp);
Una primitiva de filtro que traduce entre caracteres C unsigned y sus representaciones externas. Esta rutina devuelve uno si tiene éxito, cero en caso contrario.
bool_t xdr_u_int(XDR *xdrs, unsigned int *up);
Una primitiva de filtro que traduce entre enteros C unsigned y sus representaciones externas. Esta rutina devuelve uno si tiene éxito, cero en caso contrario.
bool_t xdr_u_long(XDR *xdrs, unsigned long *ulp);
Una primitiva de filtro que traduce entre enteros C unsigned long y sus representaciones externas. Esta rutina devuelve uno si tiene éxito, cero en caso contrario.
bool_t xdr_u_short(XDR *xdrs, unsigned short *usp);
Una primitiva de filtro que traduce entre enteros C unsigned short y sus representaciones externas. Esta rutina devuelve uno si tiene éxito, cero en caso contrario.
bool_t xdr_union(XDR *xdrs, enum_t *dscmp, char *unp,
                 const struct xdr_discrim *choices,
                 xdrproc_t defaultarm); /* puede ser NULL */
Una primitiva de filtro que traduce entre una union C discriminada y su representación externa correspondiente. Primero traduce el discriminador de la unión ubicada en dscmp. Este discriminador es siempre un enum_t. Luego se traduce la unión ubicada en unp. El argumento choices es un puntero a una matriz de estructuras xdr_discrim(). Cada estructura contiene un par ordenado de [valor,proc]. Si el discriminador de la unión es igual al valor asociado, se llama a proc para traducir la unión. El final de la matriz de estructuras xdr_discrim() está denotado por una rutina con valor NULL. Si el discriminador no se encuentra en la matriz choices, se llama al procedimiento defaultarm (si no es NULL). Devuelve uno si tiene éxito, cero en caso contrario.
bool_t xdr_vector(XDR *xdrs, char *arrp, unsigned int size,
                  unsigned int elsize, xdrproc_t elproc);
Una primitiva de filtro que traduce entre matrices de longitud fija y sus representaciones externas correspondientes. El argumento arrp es la dirección del puntero a la matriz, mientras que size es el recuento de elementos de la matriz. El argumento elsize es el sizeof de cada uno de los elementos de la matriz, y elproc es un filtro XDR que traduce entre la forma C de los elementos de la matriz y su representación externa. Esta rutina devuelve uno si tiene éxito, cero en caso contrario.
bool_t xdr_void(void);
Esta rutina siempre devuelve uno. Puede pasarse a rutinas RPC que requieren un argumento de función, donde no se debe hacer nada.
bool_t xdr_wrapstring(XDR *xdrs, char **sp);
Una primitiva que llama a xdr_string(xdrs, sp, MAXUN.UNSIGNED); donde MAXUN.UNSIGNED es el valor máximo de un entero sin signo. xdr_wrapstring() es útil porque el paquete RPC pasa como máximo dos rutinas XDR como argumentos, y xdr_string(), una de las primitivas más utilizadas, requiere tres. Devuelve uno si tiene éxito, cero en caso contrario.
bool_t xdrrec_endofrecord(XDR *xdrs, int sendnow);
Esta rutina solo se puede invocar en flujos creados por xdrrec_create(). Los datos en el búfer de salida se marcan como un registro completado, y el búfer de salida se escribe opcionalmente si sendnow es distinto de cero. Esta rutina devuelve uno si tiene éxito, cero en caso contrario.
bool_t xdrrec_eof(XDR *xdrs);
Esta rutina solo se puede invocar en flujos creados por xdrrec_create(). Después de consumir el resto del registro actual en el flujo, esta rutina devuelve uno si el flujo no tiene más entrada, cero en caso contrario.
bool_t xdrrec_skiprecord(XDR *xdrs);
Esta rutina solo se puede invocar en flujos creados por xdrrec_create(). Indica a la implementación XDR que se debe descartar el resto del registro actual en el búfer de entrada del flujo. Esta rutina devuelve uno si tiene éxito, cero en caso contrario.
bool_t xdr_reference(XDR *xdrs, char **pp, unsigned int size,
                     xdrproc_t proc);
Una primitiva que proporciona seguimiento de punteros dentro de estructuras. El argumento pp es la dirección del puntero; size es el sizeof de la estructura a la que apunta *pp; y proc es un procedimiento XDR que filtra la estructura entre su forma C y su representación externa. Esta rutina devuelve uno si tiene éxito, cero en caso contrario.
Advertencia: esta rutina no comprende punteros nulos. Utilice xdr_pointer() en su lugar.
xdr_setpos(XDR *xdrs, unsigned int pos);
Una macro que invoca la rutina de establecer posición asociada con el flujo XDR xdrs. El argumento pos es un valor de posición obtenido de xdr_getpos(). Esta rutina devuelve uno si el flujo XDR pudo ser reposicionado y cero en caso contrario.
Advertencia: es difícil reposicionar algunos tipos de flujos XDR, por lo que esta rutina puede fallar con un tipo de flujo y tener éxito con otro.
bool_t xdr_short(XDR *xdrs, short *sp);
Una primitiva de filtro que traduce entre enteros C short y sus representaciones externas. Esta rutina devuelve uno si tiene éxito, cero en caso contrario.
void xdrstdio_create(XDR *xdrs, FILE *file, enum xdr_op op);
Esta rutina inicializa el objeto de flujo XDR apuntado por xdrs. Los datos del flujo XDR se escriben o leen del flujo stdio file. El argumento op determina la dirección del flujo XDR (ya sea XDR_ENCODE, XDR_DECODE, o XDR_FREE).
Advertencia: la rutina de destrucción asociada con dichos flujos XDR llama a fflush(3) en el flujo file, pero nunca a fclose(3).
bool_t xdr_string(XDR *xdrs, char **sp, unsigned int maxsize);
Una primitiva de filtro que traduce entre cadenas C y sus representaciones externas correspondientes. Las cadenas no pueden ser más largas que maxsize. Nota: sp es la dirección del puntero de la cadena. Esta rutina devuelve uno si tiene éxito, cero en caso contrario.
