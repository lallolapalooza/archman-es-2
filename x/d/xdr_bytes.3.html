xdr(3) Manual de funciones de biblioteca xdr(3)

NOMBRE

xdr — rutinas de biblioteca para la representación externa de datos

BIBLIOTECA

Biblioteca C estándar (libc, -lc)

SINAPSIS Y DESCRIPCIÓN

Estas rutinas permiten a los programadores de C describir estructuras de datos arbitrarias de forma independiente de la máquina. Los datos para las llamadas a procedimientos remotos se transmiten utilizando estas rutinas.

Los prototipos a continuación se declaran en <rpc/xdr.h> y utilizan los siguientes tipos:

typedef int bool_t;
typedef typeof(bool_t (XDR *, void *, ...))  *xdrproc_t;

Para la declaración del tipo XDR, consulte <rpc/xdr.h>.

bool_t xdr_array(XDR *xdrs, char **arrp, unsigned int *sizep,
                 unsigned int maxsize, unsigned int elsize,
                 xdrproc_t elproc);
Una primitiva de filtro que traduce entre arrays de longitud variable y sus representaciones externas correspondientes. El argumento arrp es la dirección del puntero al array, mientras que sizep es la dirección del contador de elementos del array; este contador de elementos no puede exceder maxsize. El argumento elsize es el sizeof de cada uno de los elementos del array, y elproc es un filtro XDR que traduce entre la forma C de los elementos del array y su representación externa. Esta rutina devuelve uno si tiene éxito, cero en caso contrario.
bool_t xdr_bool(XDR *xdrs, bool_t *bp);
Una primitiva de filtro que traduce entre booleanos (enteros C) y sus representaciones externas. Al codificar datos, este filtro produce valores de uno o cero. Esta rutina devuelve uno si tiene éxito, cero en caso contrario.
bool_t xdr_bytes(XDR *xdrs, char **sp, unsigned int *sizep,
                 unsigned int maxsize);
Una primitiva de filtro que traduce entre cadenas de bytes contadas y sus representaciones externas. El argumento sp es la dirección del puntero de la cadena. La longitud de la cadena se encuentra en la dirección sizep; las cadenas no pueden tener más de maxsize. Esta rutina devuelve uno si tiene éxito, cero en caso contrario.
bool_t xdr_char(XDR *xdrs, char *cp);
Una primitiva de filtro que traduce entre caracteres C y sus representaciones externas. Esta rutina devuelve uno si tiene éxito, cero en caso contrario. Nota: los caracteres codificados no se empaquetan y ocupan 4 bytes cada uno. Para arrays de caracteres, vale la pena considerar xdr_bytes(), xdr_opaque() o xdr_string().
void xdr_destroy(XDR *xdrs);
Una macro que invoca la rutina de destrucción asociada al flujo XDR, xdrs. La destrucción generalmente implica la liberación de estructuras de datos privadas asociadas con el flujo. Usar xdrs después de invocar xdr_destroy() no está definido.
bool_t xdr_double(XDR *xdrs, double *dp);
Una primitiva de filtro que traduce entre números C de doble precisión (double) y sus representaciones externas. Esta rutina devuelve uno si tiene éxito, cero en caso contrario.
bool_t xdr_enum(XDR *xdrs, enum_t *ep);
Una primitiva de filtro que traduce entre enumeraciones C (enums) (en realidad, enteros) y sus representaciones externas. Esta rutina devuelve uno si tiene éxito, cero en caso contrario.
bool_t xdr_float(XDR *xdrs, float *fp);
Una primitiva de filtro que traduce entre números C de punto flotante (float) y sus representaciones externas. Esta rutina devuelve uno si tiene éxito, cero en caso contrario.
void xdr_free(xdrproc_t proc, char *objp);
Rutina genérica de liberación. El primer argumento es la rutina XDR para el objeto que se está liberando. El segundo argumento es un puntero al objeto en sí. Nota: el puntero pasado a esta rutina no se libera, pero lo que apunta sí se libera (recursivamente).
unsigned int xdr_getpos(XDR *xdrs);
Una macro que invoca la rutina de obtención de posición asociada al flujo XDR, xdrs. La rutina devuelve un entero sin signo, que indica la posición del flujo de bytes XDR. Una característica deseable de los flujos XDR es que la aritmética simple funciona con este número, aunque las instancias de flujo XDR no tienen por qué garantizarlo.
long *xdr_inline(XDR *xdrs, int len);
Una macro que invoca la rutina en línea asociada al flujo XDR, xdrs. La rutina devuelve un puntero a una pieza contigua del búfer del flujo; len es la longitud en bytes del búfer deseado. Nota: el puntero se convierte a long *.
Advertencia: xdr_inline() puede devolver NULL (0) si no puede asignar una pieza contigua de un búfer. Por lo tanto, el comportamiento puede variar entre las instancias del flujo; existe por motivos de eficiencia.
bool_t xdr_int(XDR *xdrs, int *ip);
Una primitiva de filtro que traduce entre enteros C y sus representaciones externas. Esta rutina devuelve uno si tiene éxito, cero en caso contrario.
bool_t xdr_long(XDR *xdrs, long *lp);
Una primitiva de filtro que traduce entre enteros C largos (long) y sus representaciones externas. Esta rutina devuelve uno si tiene éxito, cero en caso contrario.
void xdrmem_create(XDR *xdrs, char *addr, unsigned int size,
                   enum xdr_op op);
Esta rutina inicializa el objeto de flujo XDR apuntado por xdrs. Los datos del flujo se escriben o leen de un bloque de memoria en la ubicación addr cuya longitud no exceda los size bytes. El op determina la dirección del flujo XDR (ya sea XDR_ENCODE, XDR_DECODE o XDR_FREE).
bool_t xdr_opaque(XDR *xdrs, char *cp, unsigned int cnt);
Una primitiva de filtro que traduce entre datos opacos de tamaño fijo y su representación externa. El argumento cp es la dirección del objeto opaco, y cnt es su tamaño en bytes. Esta rutina devuelve uno si tiene éxito, cero en caso contrario.
bool_t xdr_pointer(XDR *xdrs, char **objpp,
                   unsigned int objsize, xdrproc_t xdrobj);
Similar a xdr_reference() excepto en que serializa punteros nulos, mientras que xdr_reference() no lo hace. Por lo tanto, xdr_pointer() puede representar estructuras de datos recursivas, como árboles binarios o listas enlazadas.
void xdrrec_create(XDR *xdrs, unsigned int sendsize,
                   unsigned int recvsize, char *handle,
                   typeof(int (char *, char *, int)) *readit,
                   typeof(int (char *, char *, int)) *writeit);
Esta rutina inicializa el objeto de flujo XDR apuntado por xdrs. Los datos del flujo se escriben en un búfer de tamaño sendsize; un valor de cero indica que el sistema debe usar uno adecuado por defecto. Los datos del flujo se leen de un búfer de tamaño recvsize; este también puede establecerse a un valor adecuado por defecto pasando un valor cero. Cuando el búfer de salida de un flujo está lleno, se llama a writeit. De manera similar, cuando el búfer de entrada de un flujo está vacío, se llama a readit. El comportamiento de estas dos rutinas es similar a las llamadas al sistema read(2) y write(2), excepto en que handle se pasa a las rutinas anteriores como primer argumento. Nota: el campo op del flujo XDR debe ser establecido por el llamador.
Advertencia: para leer de un flujo XDR creado por esta API, necesitará llamar primero a xdrrec_skiprecord() antes de llamar a cualquier otra API XDR. Esto inserta bytes adicionales en el flujo para proporcionar límites de registro.
bool_t xdrrec_endofrecord(XDR *xdrs, bool_t sendf);
Esta rutina se utiliza para señalar el final de un registro. Si sendf es verdadero, indica que se está codificando un registro. El búfer de salida se vacía y se escribe un marcador de fin de registro. Si sendf es falso, indica que se está decodificando un registro. Si hay datos restantes en el búfer de entrada, se ignoran y se devuelve el valor que indica el final del registro. Esta rutina devuelve uno si tiene éxito, cero en caso contrario.
bool_t xdrrec_skiprecord(XDR *xdrs);
Esta rutina se utiliza para omitir el resto del registro actual. Es útil cuando se está decodificando y se detecta un error o se desea pasar por alto la información restante. Si hay datos restantes en el búfer de entrada, se consumen hasta el final del registro. Esta rutina devuelve uno si tiene éxito, cero en caso contrario.
bool_t xdr_reference(XDR *xdrs, char **pp, unsigned int size,
                     xdrproc_t proc);
Esta es una primitiva de filtro general para serializar y deserializar referencias. El argumento pp es la dirección del puntero que apunta al objeto que se va a serializar o deserializar. El argumento size es el tamaño del objeto que se va a serializar o deserializar. El argumento proc es el procedimiento XDR que se va a utilizar para serializar o deserializar el objeto. Esta rutina devuelve uno si tiene éxito, cero en caso contrario.
bool_t xdr_setpos(XDR *xdrs, unsigned int pos);
Una macro que invoca la rutina de establecimiento de posición asociada al flujo XDR, xdrs. La rutina establece la posición del flujo de bytes XDR a pos. Esta rutina devuelve uno si tiene éxito, cero en caso contrario.
bool_t xdr_short(XDR *xdrs, short *sp);
Una primitiva de filtro que traduce entre enteros cortos C (short) y sus representaciones externas. Esta rutina devuelve uno si tiene éxito, cero en caso contrario.
bool_t xdr_string(XDR *xdrs, char **sp, unsigned int maxsize);
Una primitiva de filtro que traduce entre cadenas terminadas en nulo y sus representaciones externas. El argumento sp es la dirección del puntero de la cadena. Las cadenas no pueden tener más de maxsize bytes, sin incluir el terminador nulo. Esta rutina devuelve uno si tiene éxito, cero en caso contrario.
bool_t xdr_u_char(XDR *xdrs, unsigned char *cp);
Una primitiva de filtro que traduce entre caracteres sin signo C y sus representaciones externas. Esta rutina devuelve uno si tiene éxito, cero en caso contrario. Nota: los caracteres codificados no se empaquetan y ocupan 4 bytes cada uno. Para arrays de caracteres, vale la pena considerar xdr_bytes(), xdr_opaque(), o xdr_string().
bool_t xdr_u_int(XDR *xdrs, unsigned int *up);
Una primitiva de filtro que traduce entre enteros sin signo C y sus representaciones externas. Esta rutina devuelve uno si tiene éxito, cero en caso contrario.
bool_t xdr_u_long(XDR *xdrs, unsigned long *ulp);
Una primitiva de filtro que traduce entre enteros largos sin signo C (unsigned long) y sus representaciones externas. Esta rutina devuelve uno si tiene éxito, cero en caso contrario.
bool_t xdr_void(void);
Una primitiva de filtro que no hace nada. Se utiliza para la serialización y deserialización de tipos que no tienen representación externa.
bool_t xdr_union(XDR *xdrs, enum_t *dest, char *ans,
                 const struct xdr_discriminate *choices,
                 typeof(bool_t (XDR *, char *, enum_t *)) *switch_XDR);
Una primitiva de filtro que traduce entre uniones discriminadas. El argumento xdrs es el flujo XDR. El argumento dest es un puntero al discriminador de la unión. El argumento ans es un puntero a la unión. El argumento choices es una matriz de estructuras que especifican los diferentes casos de la unión. El argumento switch_XDR es un puntero a la rutina XDR que se utilizará para serializar o deserializar el cuerpo de la unión. Esta rutina devuelve uno si tiene éxito, cero en caso contrario.
bool_t xdr_vector(XDR *xdrs, char *arr, unsigned int len,
                  unsigned int maxsize, xdrproc_t elementproc);
Similar a xdr_array(), pero para arrays de tamaño fijo. El argumento arr es el puntero al array, len es el número de elementos en el array, maxsize es el tamaño máximo permitido para el array, y elementproc es la rutina XDR para serializar o deserializar cada elemento.
bool_t xdr_longlong_array(XDR *xdrs, long long **arrp,

bool_t xdr_int32_array(XDR *xdrs, int32_t **arrp,

bool_t xdr_hyper_array(XDR *xdrs, hyper **arrp,

PRIMITIVAS DE FILTRO XDR

bool_t xdr_array(XDR *xdrs, char **pp, unsigned int *lenp, unsigned int maxsize, xdrproc_t xdr_element, xdrproc_t xdr_ ƯCLN);
Una primitiva que se utiliza para realizar la serialización y deserialización de matrices. La matriz está ubicada en el puntero dado por pp, y la longitud de la matriz se da en lenp. La longitud máxima de la matriz permitida es maxsize. La primitiva xdr_element se utiliza para serializar o deserializar cada elemento individual de la matriz. La primitiva xdr_ ƯCLN se utiliza para serializar o deserializar los elementos opcionales de la matriz que pueden no estar presentes. Esta rutina devuelve uno si tiene éxito, cero en caso contrario.
Las matrices no compatibles de diferentes implementaciones de XDR no se pueden codificar ni decodificar utilizando esta rutina. La rutina devolverá cero si la matriz no es compatible. Por lo tanto, no se admiten las matrices anidadas, ya que la rutina de codificación del elemento de matriz debe ser la misma que la rutina de codificación de la matriz general.
bool_t xdr_bool(XDR *xdrs, bool_t *bp);
Una primitiva de filtro que traduce entre enteros booleanos de C y sus representaciones externas. Esta rutina devuelve uno si tiene éxito, cero en caso contrario.
bool_t xdr_bytes(XDR *xdrs, char **pp, unsigned int *lenp, unsigned int maxsize);
Una primitiva de filtro que traduce entre secuencias de bytes (un puntero a un entero con signo de 32 bits que apunta a una matriz de caracteres) y su representación externa. La longitud de la secuencia de bytes está contenida en la variable con signo de 32 bits lenp. La longitud máxima de la secuencia de bytes que se puede serializar o deserializar está limitada por maxsize. Esta rutina devuelve uno si tiene éxito, cero en caso contrario.
Las secuencias de bytes creadas con diferentes APIs de xdr_*_create no son compatibles por la misma razón.
bool_t xdr_char(XDR *xdrs, char *cp);
Una primitiva de filtro que traduce entre caracteres char de C y sus representaciones externas. Esta rutina devuelve uno si tiene éxito, cero en caso contrario.
void xdr_destroy(XDR *xdrs);
Libera todos los recursos asociados con el objeto de flujo XDR especificado por xdrs.
bool_t xdr_double(XDR *xdrs, double *dp);
Una primitiva de filtro que traduce entre enteros de punto flotante de doble precisión double de C y sus representaciones externas. Esta rutina devuelve uno si tiene éxito, cero en caso contrario.
bool_t xdr_enum(XDR *xdrs, enum_t *ep);
Una primitiva de filtro que traduce entre enumeraciones enum de C y sus representaciones externas. Esta rutina devuelve uno si tiene éxito, cero en caso contrario.
bool_t xdr_float(XDR *xdrs, float *fp);
Una primitiva de filtro que traduce entre enteros de punto flotante de precisión simple float de C y sus representaciones externas. Esta rutina devuelve uno si tiene éxito, cero en caso contrario.
void xdr_free(xdrproc_t proc, char *objp);
Esta rutina llama a la rutina de serialización/deserialización proc para liberar la memoria de los datos de tipo C en objp. El uso de esta rutina es necesario para liberar memoria asignada por las rutinas de deserialización XDR.
unsigned int xdr_getpos(XDR *xdrs);
Una macro que invoca la rutina de obtención de posición asociada con el flujo XDR xdrs. Esta posición se puede usar posteriormente para reposicionar el flujo utilizando la rutina xdr_setpos(). Devuelve la posición actual en el flujo XDR.
Advertencia: No todos los tipos de flujos XDR admiten la obtención de posición.
int xdr_inline(XDR *xdrs, unsigned int len);
Una primitiva que intenta devolver un puntero a una len de bytes de datos en el búfer de serialización/deserialización. Si no hay suficientes bytes contiguos disponibles en el búfer, devuelve NULL. Esta rutina se utiliza principalmente para optimizar la serialización/deserialización de tipos de datos grandes.
bool_t xdr_int(XDR *xdrs, int *ip);
Una primitiva de filtro que traduce entre enteros con signo int de C y sus representaciones externas. Esta rutina devuelve uno si tiene éxito, cero en caso contrario.
bool_t xdr_long(XDR *xdrs, long *lp);
Una primitiva de filtro que traduce entre enteros con signo long de C y sus representaciones externas. Esta rutina devuelve uno si tiene éxito, cero en caso contrario.
void xdrmem_create(XDR *xdrs, const char *addr, unsigned int len, enum xdr_op op);
Inicializa el objeto de flujo XDR xdrs para operar en una matriz de memoria. Los datos se leen o escriben en la matriz que comienza en addr y tiene una longitud de len bytes. El argumento op determina la dirección del flujo XDR (XDR_ENCODE, XDR_DECODE o XDR_FREE).
bool_t xdr_opaque(XDR *xdrs, const char *cp, unsigned int size);
Una primitiva de filtro que traduce entre datos opacos (una matriz de bytes) y su representación externa. El argumento cp es un puntero a los datos, y size es el número de bytes que se van a traducir. Esta rutina devuelve uno si tiene éxito, cero en caso contrario.
bool_t xdr_pointer(XDR *xdrs, char **pp, unsigned int size, xdrproc_t proc);
Una primitiva que proporciona seguimiento de punteros dentro de estructuras. El argumento pp es la dirección del puntero; size es el sizeof de la estructura a la que apunta *pp; y proc es un procedimiento XDR que filtra la estructura entre su forma C y su representación externa. Esta rutina devuelve uno si tiene éxito, cero en caso contrario.
Esta rutina admite punteros nulos. Si *pp es NULL, se codifica o decodifica un valor especial para representar el puntero nulo.
bool_t xdrrec_create(XDR *xdrs, unsigned int bufsiz, xdr_ops *ops, const char *realstock, unsigned int realstocksize);
Esta rutina inicializa el objeto de flujo XDR xdrs para la serialización/deserialización de registros de longitud variable. Los argumentos bufsiz, ops, realstock y realstocksize se utilizan para configurar el búfer de registro. Esta rutina devuelve uno si tiene éxito, cero en caso contrario.
Advertencia: Las operaciones de flujo XDR creadas con esta rutina son compatibles entre sí.
Advertencia: Las operaciones de flujo XDR creadas con diferentes APIs de xdr_*_create no son compatibles por la misma razón.
bool_t xdrrec_endofrecord(XDR *xdrs, int sendnow);
Esta rutina solo se puede invocar en flujos creados por xdrrec_create(). Los datos en el búfer de salida se marcan como un registro completado y el búfer de salida se escribe opcionalmente si sendnow es distinto de cero. Esta rutina devuelve uno si tiene éxito, cero en caso contrario.
bool_t xdrrec_eof(XDR *xdrs);
Esta rutina solo se puede invocar en flujos creados por xdrrec_create(). Después de consumir el resto del registro actual en el flujo, esta rutina devuelve uno si el flujo no tiene más entrada, cero en caso contrario.
bool_t xdrrec_skiprecord(XDR *xdrs);
Esta rutina solo se puede invocar en flujos creados por xdrrec_create(). Indica a la implementación XDR que se debe descartar el resto del registro actual en el búfer de entrada del flujo. Esta rutina devuelve uno si tiene éxito, cero en caso contrario.
bool_t xdr_reference(XDR *xdrs, char **pp, unsigned int size,
                     xdrproc_t proc);
Una primitiva que proporciona seguimiento de punteros dentro de estructuras. El argumento pp es la dirección del puntero; size es el sizeof de la estructura a la que apunta *pp; y proc es un procedimiento XDR que filtra la estructura entre su forma C y su representación externa. Esta rutina devuelve uno si tiene éxito, cero en caso contrario.
Advertencia: esta rutina no entiende los punteros nulos. Use xdr_pointer() en su lugar.
xdr_setpos(XDR *xdrs, unsigned int pos);
Una macro que invoca la rutina de establecimiento de posición asociada con el flujo XDR xdrs. El argumento pos es un valor de posición obtenido de xdr_getpos(). Esta rutina devuelve uno si el flujo XDR pudo ser reposicionado, y cero en caso contrario.
Advertencia: es difícil reposicionar algunos tipos de flujos XDR, por lo que esta rutina puede fallar con un tipo de flujo y tener éxito con otro.
bool_t xdr_short(XDR *xdrs, short *sp);
Una primitiva de filtro que traduce entre enteros short de C y sus representaciones externas. Esta rutina devuelve uno si tiene éxito, cero en caso contrario.
void xdrstdio_create(XDR *xdrs, FILE *file, enum xdr_op op);
Esta rutina inicializa el objeto de flujo XDR apuntado por xdrs. Los datos del flujo XDR se escriben o leen del flujo stdio file. El argumento op determina la dirección del flujo XDR (XDR_ENCODE, XDR_DECODE o XDR_FREE).
Advertencia: la rutina de destrucción asociada con dichos flujos XDR llama a fflush(3) en el flujo file, pero nunca a fclose(3).
bool_t xdr_string(XDR *xdrs, char **sp, unsigned int maxsize);
Una primitiva de filtro que traduce entre cadenas de C y sus representaciones externas correspondientes. Las cadenas no pueden tener una longitud superior a maxsize. Nota: sp es la dirección del puntero de la cadena. Esta rutina devuelve uno si tiene éxito, cero en caso contrario.
bool_t xdr_u_char(XDR *xdrs, unsigned char *ucp);
Una primitiva de filtro que traduce entre caracteres unsigned C y sus representaciones externas. Esta rutina devuelve uno si tiene éxito, cero en caso contrario.
bool_t xdr_u_int(XDR *xdrs, unsigned int *up);
Una primitiva de filtro que traduce entre enteros unsigned C y sus representaciones externas. Esta rutina devuelve uno si tiene éxito, cero en caso contrario.
bool_t xdr_u_long(XDR *xdrs, unsigned long *ulp);
Una primitiva de filtro que traduce entre enteros unsigned long de C y sus representaciones externas. Esta rutina devuelve uno si tiene éxito, cero en caso contrario.
bool_t xdr_u_short(XDR *xdrs, unsigned short *usp);
Una primitiva de filtro que traduce entre enteros unsigned short de C y sus representaciones externas. Esta rutina devuelve uno si tiene éxito, cero en caso contrario.
bool_t xdr_union(XDR *xdrs, enum_t *dscmp, char *unp,
                 const struct xdr_discrim *choices,
                 xdrproc_t defaultarm);     /* puede ser NULL */
Una primitiva de filtro que traduce entre una unión C discriminada y su representación externa correspondiente. Primero traduce el discriminante de la unión ubicado en dscmp. Este discriminante es siempre un enum_t. Luego se traduce la unión ubicada en unp. El argumento choices es un puntero a una matriz de estructuras xdr_discrim(). Cada estructura contiene un par ordenado de [valor,proc]. Si el discriminante de la unión es igual al valor asociado, entonces se llama a proc para traducir la unión. El final de la matriz de estructuras xdr_discrim() se indica mediante un procedimiento de valor NULL. Si el discriminante no se encuentra en la matriz choices, entonces se llama al procedimiento defaultarm (si no es NULL). Devuelve uno si tiene éxito, cero en caso contrario.
bool_t xdr_vector(XDR *xdrs, char *arrp, unsigned int size,
                  unsigned int elsize, xdrproc_t elproc);
Una primitiva de filtro que traduce entre matrices de longitud fija y sus representaciones externas correspondientes. El argumento arrp es la dirección del puntero a la matriz, mientras que size es el recuento de elementos de la matriz. El argumento elsize es el sizeof de cada uno de los elementos de la matriz, y elproc es un filtro XDR que traduce entre la forma C de los elementos de la matriz y su representación externa. Esta rutina devuelve uno si tiene éxito, cero en caso contrario.
bool_t xdr_void(void);
Esta rutina siempre devuelve uno. Se puede pasar a las rutinas RPC que requieren un argumento de función, donde no se debe hacer nada.
bool_t xdr_wrapstring(XDR *xdrs, char **sp);
Una primitiva que llama a xdr_string(xdrs, sp, MAXUN.UNSIGNED); donde MAXUN.UNSIGNED es el valor máximo de un entero sin signo. xdr_wrapstring() es útil porque el paquete RPC pasa un máximo de dos rutinas XDR como argumentos, y xdr_string(), una de las primitivas más utilizadas, requiere tres. Devuelve uno si tiene éxito, cero en caso contrario.
