XDG-DESKTOP-ICON(1) Manual de xdg-desktop-icon XDG-DESKTOP-ICON(1)

NOMBRE

xdg-desktop-icon - herramienta de línea de comandos para (des)instalar iconos en el escritorio

SINOPSIS

xdg-desktop-icon install [--novendor] ARCHIVO

xdg-desktop-icon uninstall ARCHIVO

xdg-desktop-icon {--help | --manual | --version}

DESCRIPCIÓN

El programa xdg-desktop-icon se puede utilizar para instalar un lanzador de aplicaciones u otro archivo en el escritorio del usuario actual.

Un lanzador de aplicaciones se representa mediante un archivo *.desktop. Los archivos de escritorio se definen por la Especificación de Entrada de Escritorio de freedesktop.org. Los aspectos más importantes de los archivos *.desktop se resumen a continuación.

COMANDOS

install

Instala ARCHIVO en el escritorio del usuario actual. ARCHIVO puede ser un archivo *.desktop o cualquier otro tipo de archivo.

uninstall

Elimina ARCHIVO del escritorio del usuario actual.

OPCIONES

--novendor

Normalmente, xdg-desktop-icon comprueba que un archivo *.desktop a instalar tenga un prefijo de proveedor. Esta opción se puede utilizar para deshabilitar esa comprobación.

Un prefijo de proveedor consta de caracteres alfabéticos ([a-zA-Z]) y termina con un guion ("-"). Se anima a las empresas y organizaciones a utilizar una palabra o frase, preferiblemente el nombre de la organización, para la cual tengan una marca comercial como su prefijo de proveedor. El propósito del prefijo de proveedor es evitar conflictos de nombres.

--help

Muestra la sinopsis del comando.

--manual

Muestra esta página del manual.

--version

Muestra la información de la versión de xdg-utils.

ARCHIVOS DE ESCRITORIO

Se puede agregar un lanzador de aplicaciones al escritorio instalando un archivo *.desktop. Un archivo *.desktop consta de un encabezado [Desktop Entry] seguido de varias líneas Clave=Valor.

Un archivo *.desktop puede proporcionar un nombre y una descripción para una aplicación en varios idiomas diferentes. Esto se hace agregando un código de idioma como el utilizado por LC_MESSAGES entre corchetes detrás de la Clave. De esta manera, se pueden especificar diferentes valores para la misma Clave dependiendo del idioma seleccionado actualmente.

Las siguientes claves se utilizan a menudo:

Type=Application

Este es un campo obligatorio que indica que el archivo *.desktop describe un lanzador de aplicaciones.

Name=Nombre de la aplicación

El nombre de la aplicación. Por ejemplo, Mozilla.

GenericName=Nombre genérico

Una descripción genérica de la aplicación. Por ejemplo, Navegador web.

Comment=Comentario

Campo opcional para especificar una descripción emergente para la aplicación. Por ejemplo, Visita sitios web en Internet.

Icon=Archivo de icono

El icono a utilizar para la aplicación. Puede ser una ruta absoluta a un archivo de imagen o un nombre de icono. Si se proporciona un nombre de icono, se realiza una búsqueda de imagen por nombre en el tema de iconos actual del usuario. El comando xdg-icon-resource se puede utilizar para instalar archivos de imagen en temas de iconos. La ventaja de usar un nombre de icono en lugar de una ruta absoluta es que con un nombre de icono, el icono de la aplicación se puede proporcionar en varios tamaños diferentes, así como en varios estilos temáticos.

Exec=Línea de comandos

La línea de comandos para iniciar la aplicación. Si la aplicación puede abrir archivos, se debe especificar el marcador %f. Cuando se suelta un archivo en el lanzador de aplicaciones, %f se reemplaza con la ruta del archivo del archivo soltado. Si se pueden especificar varios archivos en la línea de comandos, se debe usar el marcador %F en lugar de %f. Si la aplicación puede abrir URL además de archivos locales, se pueden usar %u o %U en lugar de %f o %F.

Para una descripción completa del formato de archivo *.desktop, visite http://www.freedesktop.org/wiki/Specifications/desktop-entry-spec

VARIABLES DE ENTORNO

xdg-desktop-icon respeta las siguientes variables de entorno:

XDG_UTILS_DEBUG_LEVEL

Establecer esta variable de entorno a un valor numérico distinto de cero hace que xdg-desktop-icon proporcione informes más detallados en stderr. Establecer un valor más alto aumenta la verbosidad.

CÓDIGOS DE SALIDA

Un código de salida de 0 indica éxito, mientras que un código de salida distinto de cero indica fallo. Los siguientes códigos de fallo se pueden devolver:

1

Error en la sintaxis de la línea de comandos.

2

Uno de los archivos pasados en la línea de comandos no existía.

3

No se pudo encontrar una herramienta requerida.

4

La acción falló.

5

No hay permiso para leer uno de los archivos pasados en la línea de comandos.

VER TAMBIÉN

xdg-icon-resource(1)

EJEMPLOS

La empresa ShinyThings Inc. ha desarrollado una aplicación llamada "WebMirror" y desea agregar un lanzador para ella en el escritorio. La empresa usará "shinythings" como su ID de proveedor. Para agregar la aplicación al escritorio, debe haber un archivo .desktop para la aplicación:

shinythings-webmirror.desktop:
  [Desktop Entry]
  Encoding=UTF-8
  Type=Application
  Exec=webmirror
  Icon=shinythings-webmirror
  Name=WebMirror
  Name[nl]=WebSpiegel

Ahora, la herramienta xdg-desktop-icon se puede utilizar para agregar el archivo webmirror.desktop al escritorio:

xdg-desktop-icon install ./shinythings-webmirror.desktop

Para agregar también un archivo README al escritorio, se puede usar el siguiente comando:

xdg-desktop-icon install ./shinythings-README

NAME xdg-desktop-icon - gestión de iconos de escritorio

SYNOPSIS
xdg-desktop-icon [OPCIÓN...] [FICHERO...]

DESCRIPTION
xdg-desktop-icon es una utilidad de línea de comandos para gestionar iconos de escritorio. Permite añadir, eliminar y listar iconos para aplicaciones.

OPTIONS

--add FICHERO
Añade un nuevo icono de escritorio para la aplicación especificada por FICHERO.
--remove FICHERO
Elimina el icono de escritorio para la aplicación especificada por FICHERO.
--list
Lista todos los iconos de escritorio instalados.
--help
Muestra un mensaje de ayuda y sale.
--version
Muestra información sobre la versión y sale.

EXIT CODES

0
Éxito.
1
Error.

SEE ALSO
xdg-open(1)

EXAMPLES 

Añadir un icono para la aplicación Firefox:
$ xdg-desktop-icon --add /usr/share/applications/firefox.desktop

Eliminar el icono de escritorio para la aplicación Firefox:
$ xdg-desktop-icon --remove /usr/share/applications/firefox.desktop

Listar todos los iconos de escritorio:
$ xdg-desktop-icon --list
