xdr(3) Manual de funciones de biblioteca xdr(3)

NOMBRE

xdr - rutinas de biblioteca para la representación externa de datos

BIBLIOTECA

Biblioteca C estándar (libc, -lc)

SINOPSIS Y DESCRIPCIÓN

Estas rutinas permiten a los programadores de C describir estructuras de datos arbitrarias de forma independiente de la máquina. Los datos para las llamadas a procedimientos remotos se transmiten utilizando estas rutinas.

Los prototipos a continuación se declaran en <rpc/xdr.h> y utilizan los siguientes tipos:

typedef int bool_t;
typedef typeof(bool_t (XDR *, void *, ...))  *xdrproc_t;

Para la declaración del tipo XDR, consulte <rpc/xdr.h>.

bool_t xdr_array(XDR *xdrs, char **arrp, unsigned int *sizep,
                 unsigned int maxsize, unsigned int elsize,
                 xdrproc_t elproc);
Un primitivo de filtro que traduce entre arreglos de longitud variable y sus representaciones externas correspondientes. El argumento arrp es la dirección del puntero al arreglo, mientras que sizep es la dirección del contador de elementos del arreglo; este contador de elementos no puede exceder maxsize. El argumento elsize es el sizeof de cada uno de los elementos del arreglo, y elproc es un filtro XDR que traduce entre la forma C de los elementos del arreglo y su representación externa. Esta rutina devuelve uno si tiene éxito, cero en caso contrario.
bool_t xdr_bool(XDR *xdrs, bool_t *bp);
Un primitivo de filtro que traduce entre booleanos (enteros C) y sus representaciones externas. Al codificar datos, este filtro produce valores de uno o cero. Esta rutina devuelve uno si tiene éxito, cero en caso contrario.
bool_t xdr_bytes(XDR *xdrs, char **sp, unsigned int *sizep,
                 unsigned int maxsize);
Un primitivo de filtro que traduce entre cadenas de bytes contadas y sus representaciones externas. El argumento sp es la dirección del puntero a la cadena. La longitud de la cadena se encuentra en la dirección sizep; las cadenas no pueden ser más largas que maxsize. Esta rutina devuelve uno si tiene éxito, cero en caso contrario.
bool_t xdr_char(XDR *xdrs, char *cp);
Un primitivo de filtro que traduce entre caracteres C y sus representaciones externas. Esta rutina devuelve uno si tiene éxito, cero en caso contrario. Nota: los caracteres codificados no se empaquetan y ocupan 4 bytes cada uno. Para arreglos de caracteres, vale la pena considerar xdr_bytes(), xdr_opaque() o xdr_string().
void xdr_destroy(XDR *xdrs);
Una macro que invoca la rutina de destrucción asociada con el flujo XDR, xdrs. La destrucción generalmente implica la liberación de estructuras de datos privadas asociadas con el flujo. Usar xdrs después de invocar xdr_destroy() no está definido.
bool_t xdr_double(XDR *xdrs, double *dp);
Un primitivo de filtro que traduce entre números C de doble precisión double y sus representaciones externas. Esta rutina devuelve uno si tiene éxito, cero en caso contrario.
bool_t xdr_enum(XDR *xdrs, enum_t *ep);
Un primitivo de filtro que traduce entre enums C (en realidad enteros) y sus representaciones externas. Esta rutina devuelve uno si tiene éxito, cero en caso contrario.
bool_t xdr_float(XDR *xdrs, float *fp);
Un primitivo de filtro que traduce entre floats C y sus representaciones externas. Esta rutina devuelve uno si tiene éxito, cero en caso contrario.
void xdr_free(xdrproc_t proc, char *objp);
Rutina de liberación genérica. El primer argumento es la rutina XDR para el objeto que se está liberando. El segundo argumento es un puntero al objeto mismo. Nota: el puntero pasado a esta rutina no se libera, pero lo que apunta sí se libera (recursivamente).
unsigned int xdr_getpos(XDR *xdrs);
Una macro que invoca la rutina de obtención de posición asociada con el flujo XDR, xdrs. La rutina devuelve un entero sin signo, que indica la posición del flujo de bytes XDR. Una característica deseable de los flujos XDR es que la aritmética simple funciona con este número, aunque las instancias del flujo XDR no garantizan esto.
long *xdr_inline(XDR *xdrs, int len);
Una macro que invoca la rutina en línea asociada con el flujo XDR, xdrs. La rutina devuelve un puntero a una pieza contigua del búfer del flujo; len es la longitud en bytes del búfer deseado. Nota: el puntero se convierte a long *.
Advertencia: xdr_inline() puede devolver NULL (0) si no puede asignar una pieza contigua de un búfer. Por lo tanto, el comportamiento puede variar entre las instancias del flujo; existe por eficiencia.
bool_t xdr_int(XDR *xdrs, int *ip);
Un primitivo de filtro que traduce entre enteros C y sus representaciones externas. Esta rutina devuelve uno si tiene éxito, cero en caso contrario.
bool_t xdr_long(XDR *xdrs, long *lp);
Un primitivo de filtro que traduce entre enteros long C y sus representaciones externas. Esta rutina devuelve uno si tiene éxito, cero en caso contrario.
void xdrmem_create(XDR *xdrs, char *addr, unsigned int size,
                   enum xdr_op op);
Esta rutina inicializa el objeto de flujo XDR apuntado por xdrs. Los datos del flujo se escriben, o se leen, de un bloque de memoria en la ubicación addr cuya longitud no es superior a size bytes. El op determina la dirección del flujo XDR (ya sea XDR_ENCODE, XDR_DECODE o XDR_FREE).
bool_t xdr_opaque(XDR *xdrs, char *cp, unsigned int cnt);
Un primitivo de filtro que traduce entre datos opacos de tamaño fijo y su representación externa. El argumento cp es la dirección del objeto opaco, y cnt es su tamaño en bytes. Esta rutina devuelve uno si tiene éxito, cero en caso contrario.
bool_t xdr_pointer(XDR *xdrs, char **objpp,
                   unsigned int objsize, xdrproc_t xdrobj);
Similar a xdr_reference() excepto que serializa punteros nulos, mientras que xdr_reference() no lo hace. Por lo tanto, xdr_pointer() puede representar estructuras de datos recursivas, como árboles binarios o listas enlazadas.
void xdrrec_create(XDR *xdrs, unsigned int sendsize,
                   unsigned int recvsize, char *handle,
                   typeof(int (char *, char *, int)) *readit,
                   typeof(int (char *, char *, int)) *writeit);
Esta rutina inicializa el objeto de flujo XDR apuntado por xdrs. Los datos del flujo se escriben en un búfer de tamaño sendsize; un valor de cero indica que el sistema debe usar un valor predeterminado adecuado. Los datos del flujo se leen de un búfer de tamaño recvsize; este también puede establecerse en un valor predeterminado adecuado pasando un valor cero. Cuando el búfer de salida de un flujo está lleno, se llama a writeit. De manera similar, cuando el búfer de entrada de un flujo está vacío, se llama a readit. El comportamiento de estas dos rutinas es similar a las llamadas al sistema read(2) y write(2), excepto que handle se pasa a las rutinas anteriores como primer argumento. Nota: el campo op del flujo XDR debe ser establecido por el llamador.
Advertencia: para leer de un flujo XDR creado por esta API, necesitará llamar a xdrrec_skiprecord() primero antes de llamar a cualquier otra API XDR. Esto inserta bytes adicionales en el flujo para proporcionar límites de registro.
bool_t xdrrec_skiprecord(XDR *xdrs);
Esta rutina ignora el resto del registro actual y se posiciona al principio del siguiente registro. Devuelve 1 si tiene éxito, 0 en caso contrario.
bool_t xdr_reference(XDR *xdrs, char **pp,
                     unsigned int size, xdrproc_t proc);
Una rutina de filtro genérica que se utiliza para serializar estructuras de datos no nulas. El argumento pp es la dirección de un puntero al objeto que se va a serializar. El argumento size es el tamaño del objeto en bytes. El argumento proc es la rutina XDR utilizada para serializar el objeto. Esta rutina devuelve uno si tiene éxito, cero en caso contrario.
bool_t xdr_setpos(XDR *xdrs, unsigned int pos);
Una macro que invoca la rutina de establecimiento de posición asociada con el flujo XDR, xdrs. La rutina intenta establecer la posición del flujo de bytes XDR en pos. Devuelve 1 si tiene éxito, 0 en caso contrario.
bool_t xdr_short(XDR *xdrs, short *sp);
Un primitivo de filtro que traduce entre enteros cortos C y sus representaciones externas. Esta rutina devuelve uno si tiene éxito, cero en caso contrario.
bool_t xdr_string(XDR *xdrs, char **sp, unsigned int maxsize);
Un primitivo de filtro que traduce entre cadenas terminadas en nulo y sus representaciones externas. El argumento sp es la dirección del puntero a la cadena. La cadena no puede ser más larga que maxsize. Esta rutina devuelve uno si tiene éxito, cero en caso contrario.
bool_t xdr_u_long(XDR *xdrs, unsigned long *ulp);
Un primitivo de filtro que traduce entre enteros largos sin signo C y sus representaciones externas. Esta rutina devuelve uno si tiene éxito, cero en caso contrario.
bool_t xdr_u_longlong(XDR *xdrs, unsigned long long *ullp);
Un primitivo de filtro que traduce entre enteros largos sin signo de C (C's unsigned long long) y sus representaciones externas. Esta rutina devuelve uno si tiene éxito, cero en caso contrario.
bool_t xdr_u_int32_t(XDR *xdrs, uint32_t *uip);
Un primitivo de filtro que traduce entre enteros de 32 bits sin signo C y sus representaciones externas. Esta rutina devuelve uno si tiene éxito, cero en caso contrario.
bool_t xdr_u_int16_t(XDR *xdrs, uint16_t *usp);
Un primitivo de filtro que traduce entre enteros de 16 bits sin signo C y sus representaciones externas. Esta rutina devuelve uno si tiene éxito, cero en caso contrario.
bool_t xdr_u_int8_t(XDR *xdrs, uint8_t *ucp);
Un primitivo de filtro que traduce entre enteros de 8 bits sin signo C y sus representaciones externas. Esta rutina devuelve uno si tiene éxito, cero en caso contrario.
bool_t xdr_uint(XDR *xdrs, unsigned int *uip);
Un primitivo de filtro que traduce entre enteros sin signo C y sus representaciones externas. Esta rutina devuelve uno si tiene éxito, cero en caso contrario.
bool_t xdr_vector(XDR *xdrs, char *cp, unsigned int size,
                  unsigned int maxsize, xdrproc_t xdrelem);
Un primitivo de filtro que traduce entre arreglos de tamaño fijo y sus representaciones externas. El argumento cp es la dirección del arreglo, size es el número de elementos en el arreglo, y maxsize es el tamaño máximo permitido para el arreglo. El argumento xdrelem es la rutina XDR utilizada para traducir cada elemento del arreglo. Esta rutina devuelve uno si tiene éxito, cero en caso contrario.
bool_t xdr_void(void);
Esta rutina no hace nada y siempre devuelve 1. Se utiliza para representar la ausencia de argumentos en llamadas a procedimientos remotos.
bool_t xdr_longlong(XDR *xdrs, long long *llp);
Un primitivo de filtro que traduce entre enteros largos de C (C's long long) y sus representaciones externas. Esta rutina devuelve uno si tiene éxito, cero en caso contrario.
bool_t xdr_int32_t(XDR *xdrs, int32_t *ip);
Un primitivo de filtro que traduce entre enteros de 32 bits con signo C y sus representaciones externas. Esta rutina devuelve uno si tiene éxito, cero en caso contrario.
bool_t xdr_int16_t(XDR *xdrs, int16_t *isp);
Un primitivo de filtro que traduce entre enteros de 16 bits con signo C y sus representaciones externas. Esta rutina devuelve uno si tiene éxito, cero en caso contrario.
bool_t xdr_int8_t(XDR *xdrs, int8_t *icp);
Un primitivo de filtro que traduce entre enteros de 8 bits con signo C y sus representaciones externas. Esta rutina devuelve uno si tiene éxito, cero en caso contrario.
