XDG-ICON-RESOURCE(1) Manual de xdg-icon-resource XDG-ICON-RESOURCE(1)

NOMBRE

xdg-icon-resource - herramienta de línea de comandos para (des)instalar recursos de iconos

SINOPSIS

xdg-icon-resource install [--noupdate] [--novendor] [--theme tema] [--context contexto] [--mode modo] --size tamaño archivo-icono [nombre-icono]

xdg-icon-resource uninstall [--noupdate] [--theme tema] [--context contexto] [--mode modo] --size tamaño nombre-icono

xdg-icon-resource forceupdate [--theme tema] [--mode modo]

xdg-icon-resource {--help | --manual | --version}

DESCRIPCIÓN

El programa xdg-icon-resource puede ser utilizado para instalar recursos de iconos en el sistema de iconos de escritorio con el fin de ilustrar entradas de menú, representar iconos de escritorio o representar gráficamente tipos de archivo.

El sistema de iconos de escritorio identifica los iconos por nombre. Dependiendo del tamaño requerido, la elección del tema de iconos y el contexto en el que se utiliza el icono, el sistema de iconos de escritorio localiza un recurso de icono apropiado para representar un icono. Los recursos de iconos pueden ser archivos XPM o PNG.

El sistema de iconos de escritorio funciona de acuerdo con la Especificación de Temas de Iconos XDG en http://www.freedesktop.org/wiki/Specifications/icon-theme-spec

COMANDOS

install

Instala el archivo de icono indicado por archivo-icono en el sistema de iconos de escritorio bajo el nombre nombre-icono. Los nombres de iconos no tienen extensión. Si nombre-icono no se proporciona, el nombre se deriva de archivo-icono. El archivo de icono debe tener la extensión .png o .xpm. Si existe un archivo .icon correspondiente en la misma ubicación que archivo-icono, también se instalará.

uninstall

Elimina el icono indicado por nombre-icono del sistema de iconos de escritorio. Tenga en cuenta que los nombres de iconos no tienen extensión.

forceupdate

Fuerza una actualización del sistema de iconos de escritorio. Esto solo es útil si la última llamada a xdg-icon-resource incluyó la opción --noupdate.

OPCIONES

--noupdate

Pospone la actualización del sistema de iconos de escritorio. Si se añaden varios iconos en secuencia, esta bandera puede usarse para indicar que seguirán cambios adicionales y que no es necesario actualizar el sistema de iconos de escritorio de inmediato.

--novendor

Normalmente, xdg-icon-resource comprueba que un archivo de icono a instalar en el contexto apps tenga un prefijo de proveedor adecuado. Esta opción se puede utilizar para desactivar esa comprobación.

Un prefijo de proveedor consta de caracteres alfabéticos ([a-zA-Z]) y se termina con un guion ("-"). Se anima a las empresas y organizaciones a utilizar una palabra o frase, preferiblemente el nombre de la organización, para la que tengan una marca registrada como prefijo de proveedor. El propósito del prefijo de proveedor es evitar conflictos de nombres.

--theme tema

Instala o elimina el archivo de icono como parte del tema. Si no se especifica ningún tema, los iconos se instalarán como parte del tema predeterminado hicolor. Las aplicaciones pueden instalar iconos bajo múltiples temas, pero al menos deben instalar iconos para el tema predeterminado hicolor.

--context contexto

Especifica el contexto para el icono. Los iconos a utilizar en el menú de aplicaciones y como iconos de escritorio deben usar apps como contexto, que es el contexto predeterminado. Los iconos a utilizar como iconos de archivo deben usar mimetypes como contexto. Otros contextos comunes son actions, devices, emblems, filesystems y stock.

--size tamaño

Especifica el tamaño del icono. Todos los iconos deben ser cuadrados. Los tamaños comunes para iconos en el contexto apps son: 16, 22, 32, 48, 64 y 128. Los tamaños comunes para iconos en el contexto mimetypes son: 16, 22, 32, 48, 64 y 128

--mode modo

modo puede ser user o system. En modo usuario, el archivo se (des)instala solo para el usuario actual. En modo sistema, el archivo se (des)instala para todos los usuarios del sistema. Normalmente, solo la raíz tiene permitido instalar en modo sistema.

El valor predeterminado es usar el modo sistema cuando lo llama root y el modo usuario cuando lo llama un usuario no root.

--help

Muestra el resumen del comando.

--manual

Muestra esta página del manual.

--version

Muestra la información de la versión de xdg-utils.

VARIABLES DE ENTORNO

xdg-icon-resource respeta las siguientes variables de entorno:

XDG_UTILS_DEBUG_LEVEL

Establecer esta variable de entorno a un valor numérico no nulo hace que xdg-icon-resource proporcione informes más detallados en stderr. Establecer un valor más alto aumenta la verbosidad.

XDG_UTILS_INSTALL_MODE

Esta variable de entorno puede ser utilizada por el usuario o administrador para anular el modo de instalación. Los valores válidos son user y system.

CÓDIGOS DE SALIDA

Un código de salida de 0 indica éxito, mientras que un código de salida distinto de cero indica fallo. Los siguientes códigos de fallo pueden ser devueltos:

1

Error en la sintaxis de la línea de comandos.

2

Uno de los archivos pasados en la línea de comandos no existía.

3

No se pudo encontrar una herramienta requerida.

4

La acción falló.

5

No hay permiso para leer uno de los archivos pasados en la línea de comandos.

VER TAMBIÉN

xdg-desktop-icon(1), xdg-desktop-menu(1), xdg-mime(1), Especificación de temas de iconos[1]

EJEMPLOS

Para instalar un recurso de icono para representar un lanzador de la aplicación myfoobar, la empresa ShinyThings Inc. puede usar:

xdg-icon-resource install --size 64 shinythings-myfoobar.png

Para instalar un icono para un nuevo tipo de archivo application/x-foobar, se puede usar:

xdg-icon-resource install --context mimetypes --size 48 ./mime-foobar-48.png application-x-foobar
xdg-icon-resource install --context mimetypes --size 64 ./mime-foobar-64.png application-x-foobar

Esto instalará dos iconos con el nombre application-x-foobar pero con diferentes tamaños.
