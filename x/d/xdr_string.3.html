xdr(3) Manual de funciones de biblioteca xdr(3)

NOMBRE

xdr - rutinas de biblioteca para la representación externa de datos

BIBLIOTECA

Biblioteca C estándar (libc, -lc)

SINOPSIS Y DESCRIPCIÓN

Estas rutinas permiten a los programadores de C describir estructuras de datos arbitrarias de una manera independiente de la máquina. Los datos para las llamadas a procedimientos remotos se transmiten utilizando estas rutinas.

Los prototipos a continuación se declaran en <rpc/xdr.h> y utilizan los siguientes tipos:

typedef int bool_t;
typedef typeof(bool_t (XDR *, void *, ...))  *xdrproc_t;

Para la declaración del tipo XDR, consulte <rpc/xdr.h>.

bool_t xdr_array(XDR *xdrs, char **arrp, unsigned int *sizep,
                 unsigned int maxsize, unsigned int elsize,
                 xdrproc_t elproc);
Una primitiva de filtro que traduce entre matrices de longitud variable y sus representaciones externas correspondientes. El argumento arrp es la dirección del puntero a la matriz, mientras que sizep es la dirección del contador de elementos de la matriz; este contador de elementos no puede exceder maxsize. El argumento elsize es el sizeof de cada uno de los elementos de la matriz, y elproc es un filtro XDR que traduce entre la forma C de los elementos de la matriz y su representación externa. Esta rutina devuelve uno si tiene éxito, cero en caso contrario.
bool_t xdr_bool(XDR *xdrs, bool_t *bp);
Una primitiva de filtro que traduce entre booleanos (enteros C) y sus representaciones externas. Al codificar datos, este filtro produce valores de uno o cero. Esta rutina devuelve uno si tiene éxito, cero en caso contrario.
bool_t xdr_bytes(XDR *xdrs, char **sp, unsigned int *sizep,
                 unsigned int maxsize);
Una primitiva de filtro que traduce entre cadenas de bytes contadas y sus representaciones externas. El argumento sp es la dirección del puntero a la cadena. La longitud de la cadena se encuentra en la dirección sizep; las cadenas no pueden tener una longitud superior a maxsize. Esta rutina devuelve uno si tiene éxito, cero en caso contrario.
bool_t xdr_char(XDR *xdrs, char *cp);
Una primitiva de filtro que traduce entre caracteres C y sus representaciones externas. Esta rutina devuelve uno si tiene éxito, cero en caso contrario. Nota: los caracteres codificados no están empaquetados y ocupan 4 bytes cada uno. Para matrices de caracteres, vale la pena considerar xdr_bytes(), xdr_opaque() o xdr_string().
void xdr_destroy(XDR *xdrs);
Una macro que invoca la rutina de destrucción asociada con el flujo XDR, xdrs. La destrucción generalmente implica la liberación de estructuras de datos privadas asociadas con el flujo. Usar xdrs después de invocar xdr_destroy() no está definido.
bool_t xdr_double(XDR *xdrs, double *dp);
Una primitiva de filtro que traduce entre números de doble precisión de C y sus representaciones externas. Esta rutina devuelve uno si tiene éxito, cero en caso contrario.
bool_t xdr_enum(XDR *xdrs, enum_t *ep);
Una primitiva de filtro que traduce entre enumeraciones C (en realidad enteros) y sus representaciones externas. Esta rutina devuelve uno si tiene éxito, cero en caso contrario.
bool_t xdr_float(XDR *xdrs, float *fp);
Una primitiva de filtro que traduce entre flotantes de C y sus representaciones externas. Esta rutina devuelve uno si tiene éxito, cero en caso contrario.
void xdr_free(xdrproc_t proc, char *objp);
Rutina genérica de liberación. El primer argumento es la rutina XDR para el objeto que se está liberando. El segundo argumento es un puntero al objeto en sí. Nota: el puntero pasado a esta rutina no se libera, pero lo que apunta sí se libera (recursivamente).
unsigned int xdr_getpos(XDR *xdrs);
Una macro que invoca la rutina de obtención de posición asociada con el flujo XDR, xdrs. La rutina devuelve un entero sin signo, que indica la posición del flujo de bytes XDR. Una característica deseable de los flujos XDR es que la aritmética simple funciona con este número, aunque las instancias del flujo XDR no necesiten garantizarlo.
long *xdr_inline(XDR *xdrs, int len);
Una macro que invoca la rutina en línea asociada con el flujo XDR, xdrs. La rutina devuelve un puntero a una pieza contigua del búfer del flujo; len es la longitud en bytes del búfer deseado. Nota: el puntero se convierte a long *.
Advertencia: xdr_inline() puede devolver NULL (0) si no puede asignar una pieza contigua de un búfer. Por lo tanto, el comportamiento puede variar entre las instancias de flujo; existe por motivos de eficiencia.
bool_t xdr_int(XDR *xdrs, int *ip);
Una primitiva de filtro que traduce entre enteros C y sus representaciones externas. Esta rutina devuelve uno si tiene éxito, cero en caso contrario.
bool_t xdr_long(XDR *xdrs, long *lp);
Una primitiva de filtro que traduce entre enteros long de C y sus representaciones externas. Esta rutina devuelve uno si tiene éxito, cero en caso contrario.
void xdrmem_create(XDR *xdrs, char *addr, unsigned int size,
                   enum xdr_op op);
Esta rutina inicializa el objeto de flujo XDR apuntado por xdrs. Los datos del flujo se escriben, o se leen, de un bloque de memoria en la ubicación addr cuya longitud no supera los size bytes. El op determina la dirección del flujo XDR (ya sea XDR_ENCODE, XDR_DECODE o XDR_FREE).
bool_t xdr_opaque(XDR *xdrs, char *cp, unsigned int cnt);
Una primitiva de filtro que traduce entre datos opacos de tamaño fijo y su representación externa. El argumento cp es la dirección del objeto opaco, y cnt es su tamaño en bytes. Esta rutina devuelve uno si tiene éxito, cero en caso contrario.
bool_t xdr_pointer(XDR *xdrs, char **objpp,
                   unsigned int objsize, xdrproc_t xdrobj);
Similar a xdr_reference() excepto que serializa punteros nulos, mientras que xdr_reference() no lo hace. Por lo tanto, xdr_pointer() puede representar estructuras de datos recursivas, como árboles binarios o listas enlazadas.
void xdrrec_create(XDR *xdrs, unsigned int sendsize,
                   unsigned int recvsize, char *handle,
                   typeof(int (char *, char *, int)) *readit,
                   typeof(int (char *, char *, int)) *writeit);
Esta rutina inicializa el objeto de flujo XDR apuntado por xdrs. Los datos del flujo se escriben en un búfer de tamaño sendsize; un valor de cero indica que el sistema debe usar uno adecuado por defecto. Los datos del flujo se leen de un búfer de tamaño recvsize; este también puede establecerse en un valor por defecto adecuado pasando un valor cero. Cuando el búfer de salida de un flujo está lleno, se llama a writeit. De manera similar, cuando el búfer de entrada de un flujo está vacío, se llama a readit. El comportamiento de estas dos rutinas es similar a las llamadas del sistema read(2) y write(2), excepto que handle se pasa a las rutinas anteriores como primer argumento. Nota: el campo op del flujo XDR debe ser establecido por el llamador.
Advertencia: para leer de un flujo XDR creado por esta API, necesitará llamar a xdrrec_skiprecord() antes de llamar a cualquier otra API XDR. Esto inserta bytes adicionales en el flujo para proporcionar límites de registro.
bool_t xdrrec_skiprecord(XDR *xdrs);
Esta rutina es utilizada para obtener el siguiente registro en un flujo XDR. Si el flujo XDR no se ha posicionado, esta rutina avanza hasta el principio del registro actual. Si el flujo XDR ya ha leído todos los registros, esta rutina devuelve cero. Si la operación tiene éxito, devuelve uno.
bool_t xdr_reference(XDR *xdrs, char **pp,
                   unsigned int size, xdrproc_t proc);
Una primitiva de filtro que se utiliza para traducir entre punteros a objetos y sus representaciones externas. El argumento pp es la dirección del puntero al objeto, mientras que size es el tamaño del objeto al que apunta el puntero. El argumento proc es la rutina XDR que se utilizará para traducir el objeto. Esta rutina devuelve uno si tiene éxito, cero en caso contrario.
bool_t xdr_setpos(XDR *xdrs, unsigned int pos);
Una macro que invoca la rutina de establecimiento de posición asociada con el flujo XDR, xdrs. La rutina establece la posición del flujo de bytes XDR a la que se indica en pos. Devuelve uno si tiene éxito, cero en caso contrario.
bool_t xdr_short(XDR *xdrs, short *sp);
Una primitiva de filtro que traduce entre enteros cortos de C y sus representaciones externas. Esta rutina devuelve uno si tiene éxito, cero en caso contrario.
bool_t xdr_string(XDR *xdrs, char **sp, unsigned int maxsize);
Una primitiva de filtro que traduce entre cadenas de C terminadas en nulo y sus representaciones externas. El argumento sp es la dirección del puntero a la cadena. La longitud de la cadena no puede exceder maxsize. Esta rutina devuelve uno si tiene éxito, cero en caso contrario.
bool_t xdr_u_int32_t(XDR *xdrs, u_int32_t *uip);
Una primitiva de filtro que traduce entre enteros de 32 bits sin signo de C y sus representaciones externas. Esta rutina devuelve uno si tiene éxito, cero en caso contrario.
bool_t xdr_u_int64_t(XDR *xdrs, u_int64_t *ullp);
Una primitiva de filtro que traduce entre enteros de 64 bits sin signo de C y sus representaciones externas. Esta rutina devuelve uno si tiene éxito, cero en caso contrario.
bool_t xdr_u_long(XDR *xdrs, unsigned long *ulp);
Una primitiva de filtro que traduce entre enteros largos sin signo de C y sus representaciones externas. Esta rutina devuelve uno si tiene éxito, cero en caso contrario.
bool_t xdr_u_longlong_t(XDR *xdrs, unsigned long long *ullp);
Una primitiva de filtro que traduce entre enteros largos largos sin signo de C y sus representaciones externas. Esta rutina devuelve uno si tiene éxito, cero en caso contrario.
bool_t xdr_uint(XDR *xdrs, unsigned int *uip);
Una primitiva de filtro que traduce entre enteros sin signo de C y sus representaciones externas. Esta rutina devuelve uno si tiene éxito, cero en caso contrario.
bool_t xdr_union(XDR *xdrs, enum_t *discr, char *`union`,
                 struct xdr_discmu *choices,
                 xdrproc_t xxx);
Una primitiva de filtro que traduce entre uniones discriminadas y sus representaciones externas. El argumento discr es la dirección del discriminante de la unión, mientras que `union es la dirección de la unión. El argumento choices es un puntero a una estructura que contiene la lista de posibles casos para la unión. El argumento xxx es la rutina XDR que se utilizará para traducir el cuerpo de la unión. Esta rutina devuelve uno si tiene éxito, cero en caso contrario.
bool_t xdr_vector(XDR *xdrs, char *arr, unsigned int len,
                  unsigned int maxsize, xdrproc_t arrproc);
Similar a xdr_array() pero para matrices de tamaño fijo. El argumento arr es la dirección de la matriz, mientras que len es la longitud de la matriz. El argumento maxsize es el tamaño máximo de la matriz, y arrproc es la rutina XDR para serializar los elementos de la matriz. Esta rutina devuelve uno si tiene éxito, cero en caso contrario.
bool_t xdr_void(void);
Una primitiva de filtro trivial que no hace nada. Se utiliza para las llamadas a procedimientos remotos que no tienen argumentos ni resultados. Esta rutina devuelve uno.
bool_t xdr_wrapstring(XDR *xdrs, char **sp);
Una primitiva de filtro que traduce entre cadenas de C terminadas en nulo y sus representaciones externas. Esta rutina es similar a xdr_string(), pero no toma un argumento maxsize. Esta rutina devuelve uno si tiene éxito, cero en caso contrario.

El tipo XDR se utiliza para mantener el estado del dispositivo de representación de datos externo. Las rutinas de filtro XDR toman un puntero a una estructura XDR como su primer argumento.

Las rutinas xdr_create() inicializan un objeto de flujo XDR. Las rutinas xdr_destroy() liberan un objeto de flujo XDR. Las rutinas xdr_getpos() y xdr_setpos() obtienen y establecen la posición actual en el flujo XDR, respectivamente. La rutina xdr_inline() intenta obtener un puntero a una porción contigua del flujo XDR. Las rutinas de filtro XDR (como xdr_int(), xdr_string(), etc.) se utilizan para traducir tipos de datos específicos entre sus representaciones C y sus representaciones externas.

La rutina xdr_free() se utiliza para liberar memoria que fue asignada por una rutina de filtro XDR. Toma la rutina de filtro XDR como primer argumento y un puntero al objeto que se va a liberar como segundo argumento.

Las rutinas xdrmem_create() y xdrrec_create() se utilizan para crear flujos XDR. xdrmem_create() crea un flujo XDR que opera en un bloque de memoria. xdrrec_create() crea un flujo XDR que opera en un búfer de entrada/salida y utiliza rutinas de lectura y escritura proporcionadas por el usuario para transferir datos.

La rutina xdrrec_skiprecord() se utiliza para avanzar hasta el siguiente registro en un flujo XDR. Esto es útil cuando se lee de un flujo XDR que contiene varios registros.

Para obtener más información sobre la representación externa de datos, consulte RFC 1014 de la IETF.
