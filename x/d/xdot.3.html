NOMBRE

libxdot - análisis y desanálisis de operaciones xdot

SINOPSIS

#include <graphviz/xdot.h>
typedef enum {
    xd_none,
    xd_linear,
    xd_radial
} xdot_grad_type;
typedef struct {
    float frac;
    char* color;
} xdot_color_stop;
typedef struct {
    double x0, y0;
    double x1, y1;
    int n_stops;
    xdot_color_stop* stops;
} xdot_linear_grad;
typedef struct {
    double x0, y0, r0;
    double x1, y1, r1;
    int n_stops;
    xdot_color_stop* stops;
} xdot_radial_grad;
typedef struct {
    xdot_grad_type type;
    union {
	char* clr;
	xdot_linear_grad ling;
	xdot_radial_grad ring;
    } u;
} xdot_color;
typedef enum {
    xd_left, xd_center, xd_right
} xdot_align;
typedef struct {
    double x, y, z;
} xdot_point;
typedef struct {
    double x, y, w, h;
} xdot_rect;
typedef struct {
    int cnt;
    xdot_point* pts;
} xdot_polyline;
typedef struct {
  double x, y;
  xdot_align align;
  double width;
  char* text;
} xdot_text;
typedef struct {
    xdot_rect pos;
    char* name;
} xdot_image;
typedef struct {
    double size;
    char* name;
} xdot_font;
typedef enum {
    xd_filled_ellipse, xd_unfilled_ellipse,
    xd_filled_polygon, xd_unfilled_polygon,
    xd_filled_bezier,  xd_unfilled_bezier,
    xd_polyline,       xd_text,
    xd_fill_color,     xd_pen_color, xd_font, xd_style, xd_image,
    xd_grad_fill_color,     xd_grad_pen_color,
    xd_fontchar
} xdot_kind; 
typedef enum {
    xop_ellipse,
    xop_polygon,
    xop_bezier,
    xop_polyline,       xop_text,
    xop_fill_color,     xop_pen_color, xop_font, xop_style, xop_image,
    xop_grad_color,
    xop_fontchar
} xop_kind; 
typedef struct _xdot_op xdot_op;
typedef void (*drawfunc_t)(xdot_op*, int);
typedef void (*freefunc_t)(xdot_op*);
struct _xdot_op {
    xdot_kind kind;
    union {
      xdot_rect ellipse;       /* xd_filled_ellipse, xd_unfilled_ellipse */
      xdot_polyline polygon;   /* xd_filled_polygon, xd_unfilled_polygon */
      xdot_polyline polyline;  /* xd_polyline */
      xdot_polyline bezier;    /* xd_filled_bezier,  xd_unfilled_bezier */
      xdot_text text;          /* xd_text */
      xdot_image image;        /* xd_image */
      char* color;             /* xd_fill_color, xd_pen_color */
      xdot_color grad_color;   /* xd_grad_fill_color, xd_grad_pen_color */
      xdot_font font;          /* xd_font */
      char* style;             /* xd_style */
      unsigned int fontchar;   /* xd_fontchar */
    } u;
    drawfunc_t drawfunc;
};
#define XDOT_PARSE_ERROR 1
typedef struct {
    int cnt;
    int sz;
    xdot_op* ops;
    freefunc_t freefunc;
    int flags;
} xdot;
typedef struct {
    int cnt;  /* no. of xdot ops */
    int n_ellipse;
    int n_polygon;
    int n_polygon_pts;
    int n_polyline;
    int n_polyline_pts;
    int n_bezier;
    int n_bezier_pts;
    int n_text;
    int n_font;
    int n_style;
    int n_color;
    int n_image;
    int n_gradcolor;
    int n_fontchar;
} xdot_stats;
xdot* parseXDotF (char*, drawfunc_t opfns[], int sz);
xdot* parseXDotFOn (char*, drawfunc_t opfns[], int sz, xdot*);
xdot* parseXDot (char*);
char* sprintXDot (xdot*);
void fprintXDot (FILE*, xdot*);
void jsonXDot (FILE*, xdot*);
void freeXDot (xdot*);
int statXDot (xdot*, xdot_stats*);
xdot_grad_type colorType (char*);
xdot_color* parseXDotColor (char*);
void freeXDotColor (xdot_color*);

DESCRIPCIÓN

libxdot proporciona soporte para el análisis y desanálisis de operaciones gráficas especificadas por el lenguaje xdot.

Tipos

xdot

Esto encapsula una serie de operaciones xdot, almacenadas en el array apuntado por ops. El campo sz indica el tamaño de cada elemento almacenado en ops. Si el usuario establece el campo freefunc, esta función se llamará en cada elemento de ops durante freeXDot antes de que la biblioteca realice su propia limpieza del elemento. Esto permite al usuario liberar cualquier recurso almacenado en el elemento utilizando una expansión de la estructura xdot_op.

xdot_op

Un valor de este tipo representa una operación xdot. La operación se especifica por el campo kind. Los datos correspondientes se almacenan en la unión u, con el subcampo asociado a un determinado kind indicado por los comentarios.

El campo drawfunc permite al usuario adjuntar una función específica de dibujo a la operación, proporcionando una interfaz basada en objetos. Estas funciones pueden adjuntarse automáticamente durante el análisis proporcionando un segundo argumento no NULL a parseXDotF.

xop_kind

Este tipo proporciona una enumeración de las operaciones xdot permitidas. Consulte
https://graphviz.org/docs/outputs/canon/#xdot
para ver la semántica específica asociada a cada operación.

xdot_rect

Esto representa un rectángulo. Para elipses, los campos x e y representan el centro del rectángulo, y w y h dan la mitad del ancho y la mitad de la altura, respectivamente. Para imágenes, (x,y) da la esquina inferior izquierda del rectángulo, y w y h dan el ancho y la altura, respectivamente.

xdot_polyline

Este tipo encapsula una serie de cnt puntos.

xdot_text

Un valor de este tipo corresponde a la impresión de la cadena text usando el punto base (x,y). El campo width da una aproximación de cuán ancha será la cadena impresa usando la fuente y el tamaño de fuente actuales. El campo align indica cómo se debe alinear horizontalmente el texto con el punto (x,y).

xdot_image

Esto denota la inserción de una imagen. La fuente de la imagen se proporciona por name. La imagen debe colocarse en el rectángulo pos.

xdot_font

Los campos dan el nombre y el tamaño, en puntos, de una fuente.

xdot_align

Este tipo de enumeración corresponde a los valores de alineación xdot -1, 0 y 1 usados con el operador de texto, o '\l', '\n' y '\r' usados en texto de punto.

Funciones

xdot* parseXDotF (char *str, drawfunc_t* opfns, int sz)

Analiza la cadena str como una secuencia de operaciones xdot y devuelve un puntero a la estructura xdot resultante. La función analiza tantas operaciones xdot como pueda. Si se encontró alguna entrada desconocida o incorrecta en str, los campos ops y cnt reflejarán las operaciones analizadas antes del error, y el bit XDOT_PARSE_ERROR se establecerá en el campo flags. La función devuelve NULL si no puede analizar nada.

Si sz no es cero, se asume que es el tamaño de algún tipo de estructura que contiene xdot_op como prefijo. En este caso, los elementos del array apuntado por ops tendrán cada uno un tamaño de sz.

Si opfns no es cero, se toma como un array de funciones indexado por xop_kind. Durante el análisis, el miembro drawfunc de xop_op se establecerá en la función correspondiente en opfns.

xdot* parseXDotFOn (char *str, drawfunc_t* opfns, int sz, xdot* x)

Lo mismo que parseXDotF, pero se añade al objeto xdot dado x.

xdot* parseXDot (char *str)

Esto es equivalente a parseXDotF(str, 0, 0) .

void freeXDot (xdot* xp)

Libera la estructura xdot apuntada por xp. Si el campo freefunc de la estructura xdot se estableció en parseXDotF, esta función se llama para cada operación antes de que la biblioteca libxdot libere la operación.

void fprintXDot (FILE* fp, xdot* xp)

Imprime la representación textual de la estructura xdot apuntada por xp en el flujo de archivo fp.

void jsonXDot (FILE* fp, xdot* xp)

Imprime una representación JSON de la estructura xdot apuntada por xp en el flujo de archivo fp.

char* sprintXDot (xdot* xp)

Devuelve una cadena que contiene la representación textual de la estructura xdot apuntada por xp. El llamador es responsable de liberar la memoria de la cadena devuelta.

int statXDot (xdot* xp, xdot_stats* stats)

Rellena la estructura stats con estadísticas sobre las operaciones xdot contenidas en xp. Devuelve 0 si tiene éxito, y XDOT_PARSE_ERROR si ocurre un error.

xdot_grad_type colorType (char* color)

Devuelve el tipo de gradiente de color para la cadena de color dada. Los tipos posibles son xd_none, xd_linear y xd_radial.

xdot_color* parseXDotColor (char* color)

Analiza la cadena de color dada y devuelve un puntero a una estructura xdot_color. El llamador es responsable de liberar la memoria devuelta usando freeXDotColor.

void freeXDotColor (xdot_color* xc)

Libera la estructura xdot_color apuntada por xc.

NOMBRE

xdot - formato de archivo para describir gráficos

SINOPSIS

#include <graphviz/xdot.h>

void freeXDot (xdot* xp);
char* sprintXDot (xdot* xp);
void fprintXDot (FILE* fp, xdot* xp);
void jsonXDot(FILE * fp, xdot * x);
xdot_grad_type colorTypeXDot (char *str);
char* parseXDotColor (char *str, xdot_color* clr);
void freeXDotColor (xdot_color* cp);
int statXDot (xdot *x, xdot_stats *sp);

DESCRIPCIÓN

El formato de archivo xdot es una representación textual de un gráfico, diseñada para ser una forma de describir el resultado de un dibujo, y no para ser un formato de entrada general.

El paquete xdot proporciona soporte para la serialización y deserialización de este formato.

void freeXDot (xdot * xp)

Libera los recursos asociados con el argumento. Si xp es NULL, no hace nada.

extern char* sprintXDot (xdot* xp)

extern void fprintXDot (FILE* fp, xdot* xp)

Estas dos funciones deparsifican la estructura xdot del argumento, produciendo una representación de cadena. fprintXDot escribe la salida en el flujo abierto fp; sprintXDot devuelve una cadena asignada en el heap.

La cadena de color con operaciones de relleno y dibujo puede codificar gradientes lineales y radiales. Estos valores son analizados automáticamente por parseXDotF o parseXDot, con xdot_op teniendo el tipo xd_grad_pen_color o xd_grad_fill_color y el valor se almacena en grad_color.

Para una aplicación que maneja su propio análisis de xdot, la biblioteca proporciona tres funciones auxiliares.

void jsonXDot(FILE * fp, xdot * x)

Traduce un objeto xdot dado a una representación JSON. Esta funcionalidad se considera actualmente experimental y el formato de la salida JSON puede no ser estable en las versiones de Graphviz.

xdot_grad_type colorTypeXDot (char *str)

Devuelve el tipo de color descrito por la cadena de entrada.

char* parseXDotColor (char *str, xdot_color* clr)

Intenta analizar la cadena str como un valor de color, almacenando el resultado en clr. Devuelve NULL en caso de fallo.

void freeXDotColor (xdot_color* cp)

Esto libera los recursos asociados con un valor de tipo xdot_color.

int statXDot (xdot *x, xdot_stats *sp)

Esta función se proporciona para recuperar diversas estadísticas sobre un objeto xdot. Devuelve 0 en caso de éxito y rellena el parámetro de salida sp con recuentos de varias entidades en el objeto xdot.

ERRORES

Aunque se realiza una pequeña comprobación en el argumento sz de parseXDotF, se asume que es un valor válido de sizeof aplicado a algún tipo de estructura que contiene xdot_op como su primer campo. No se puede validar el argumento opfns.
