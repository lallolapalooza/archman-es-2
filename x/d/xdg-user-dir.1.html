XDG-USER-DIR(1) Comandos de usuario XDG-USER-DIR(1)

NOMBRE

xdg-user-dir - Buscar un directorio de usuario XDG

SINOPSIS

xdg-user-dir [NOMBRE]

DESCRIPCIÓN

xdg-user-dir busca la ruta actual de uno de los directorios especiales de usuario XDG.

Este comando espera el nombre de un directorio de usuario XDG como argumento. Los nombres posibles son:

DESKTOP
DOWNLOAD
TEMPLATES
PUBLICSHARE
DOCUMENTS
MUSIC
PICTURES
VIDEOS

FICHEROS

Los valores se buscan en el archivo user-dirs.dirs. Este archivo es creado por la utilidad xdg-user-dirs-update.

ENTORNO

La variable de entorno XDG_CONFIG_HOME determina dónde se encuentra el archivo user-dirs.dirs.

VER TAMBIÉN

xdg-user-dirs-update(1)
