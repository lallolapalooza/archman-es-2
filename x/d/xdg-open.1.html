NOMBRE

xdg-open - abre un archivo o URL en la aplicación preferida del usuario

SINOPSIS

xdg-open {archivo | URL}

xdg-open {--help | --manual | --version}

DESCRIPCIÓN

xdg-open abre un archivo o URL en la aplicación preferida del usuario. Si se proporciona una URL, se abrirá en el navegador web preferido del usuario. Si se proporciona un archivo, se abrirá en la aplicación preferida para archivos de ese tipo. xdg-open soporta URLs de tipo file, ftp, http e https.

xdg-open es solo para uso dentro de una sesión de escritorio. No se recomienda usar xdg-open como root.

Como xdg-open no puede manejar argumentos que comiencen con un carácter “-”, se recomienda pasar las rutas de archivo de una de las siguientes maneras:

• Pasar rutas absolutas, es decir, usando realpath como preprocesador.
• Anteponer `./` a rutas de archivo relativas conocidas. Por ejemplo, usando sed -E 's|^[^/]|./\0|'.
• Pasar una URL de archivo.

OPCIONES

--help

Muestra el resumen del comando.

--manual

Muestra esta página del manual.

--version

Muestra la información de la versión de xdg-utils.

CÓDIGOS DE SALIDA

Un código de salida de 0 indica éxito, mientras que un código de salida distinto de cero indica fallo. Los siguientes códigos de fallo pueden ser devueltos:

1

Error en la sintaxis de la línea de comandos.

2

Uno de los archivos pasados en la línea de comandos no existía.

3

No se pudo encontrar una herramienta requerida.

4

La acción falló.

En caso de éxito, el proceso iniciado desde el archivo .desktop no se bifurcará y, por lo tanto, xdg-open podría ejecutarse durante mucho tiempo. Este comportamiento difiere intencionalmente de la mayoría de los abrelatas específicos del escritorio para permitir que las aplicaciones basadas en terminal se ejecuten utilizando la misma terminal desde la que se llamó a xdg-open.

REPORTE DE PROBLEMAS

Por favor, ten en cuenta que xdg-open hereda la mayoría de los defectos de su configuración y del abrelatas subyacente.

En caso de que el comando xdg-mime query default "$(xdg-mime query filetype path/to/troublesome_file)" nombre el programa responsable de cualquier comportamiento inesperado, puedes solucionarlo configurando un manejador diferente. (Si el programa está roto, informa a los desarrolladores)

También consulta la nota de seguridad en xdg-mime(1) para el subcomando predeterminado.

Si un defecto es reproducible usando el abrelatas específico del escritorio (y no es un problema de configuración): Por favor, informa primero a quien sea responsable de ello (informar a xdg-utils es mejor que no informar en absoluto, pero como los xdg-utils se mantienen con muy poco tiempo libre, una solución tardará mucho más)

En caso de un problema específico de xdg-open, por favor repórtalo en https://gitlab.freedesktop.org/xdg/xdg-utils/-/issues .

VER TAMBIÉN

xdg-mime(1), xdg-settings(1), Especificación de asociaciones de aplicaciones MIME[1]

EJEMPLOS

xdg-open 'http://www.freedesktop.org/'

Abre el sitio web de freedesktop.org en el navegador predeterminado del usuario.

xdg-open /tmp/foobar.png

Abre el archivo de imagen PNG /tmp/foobar.png en la aplicación de visualización de imágenes predeterminada del usuario.
