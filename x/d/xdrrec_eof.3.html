xdrrec_eof(3) Manual de funciones de biblioteca xdrrec_eof(3)

NOMBRE

xdrrec_eof - probar el final de un flujo XDR de registro

BIBLIOTECA

Biblioteca C estándar (libc, -lc)

SINOPSIS Y DESCRIPCIÓN

#include <rpc/xdr.h>

bool_t
xdrrec_eof(XDR *xdrs);

La función xdrrec_eof toma como argumento un puntero a un flujo XDR, xdrs. Devuelve uno si el flujo se encuentra al final de un registro, cero en caso contrario.

Normalmente, se utiliza para probar el final de un flujo XDR después de haber leído todos los registros que componen un mensaje.

Para obtener una descripción más detallada de los tipos y funciones XDR, véase xdr(3).

Notas:

  • La función devuelve uno si se alcanza el final de un registro (es decir, si no quedan más bytes para leer en el registro actual).
  • Devuelve cero si el final del flujo XDR se alcanza antes de que se haya terminado de leer el registro actual.

EJEMPLO

Aquí tienes un ejemplo de cómo usar xdrrec_eof:

#include <rpc/xdr.h>
#include <stdio.h>

int main() {
    XDR xdrs;
    char buffer[100];
    // Suponiendo que el buffer está inicializado con algunos datos XDR
    // y que xdrs se ha inicializado con xdrmem_create o xdrrec_create.

    // Inicializar xdrs (esto es solo un ejemplo, la inicialización real
    // dependerá de cómo se creen los datos XDR)
    xdrmem_create(&xdrs, buffer, sizeof(buffer), XDR_DECODE);

    // Leer algunos registros
    // ... código para leer registros usando xdrrec_readrecord o similar ...

    // Comprobar si se ha llegado al final del registro
    if (xdrrec_eof(&xdrs)) {
        printf("Se ha llegado al final del registro.\n");
    } else {
        printf("Todavía hay datos en el registro actual.\n");
    }

    // Limpiar el flujo XDR
    xdr_destroy(&xdrs);

    return 0;
}

Este ejemplo ilustra el uso básico de xdrrec_eof. En un escenario real, el flujo XDR normalmente se asociaría a una conexión de red o a un archivo, y los datos se leerían utilizando las funciones apropiadas como xdrrec_readrecord.

bool_t xdrrec_endofrecord(XDR *xdrs, int sendnow);
Esta rutina solo puede invocarse en flujos creados por xdrrec_create(). Los datos en el búfer de salida se marcan como un registro completado, y el búfer de salida se escribe opcionalmente si sendnow no es cero. Esta rutina devuelve uno si tiene éxito, cero en caso contrario.
bool_t xdrrec_eof(XDR *xdrs);
Esta rutina solo puede invocarse en flujos creados por xdrrec_create(). Después de consumir el resto del registro actual en el flujo, esta rutina devuelve uno si el flujo no tiene más entrada, cero en caso contrario.
bool_t xdrrec_skiprecord(XDR *xdrs);
Esta rutina solo puede invocarse en flujos creados por xdrrec_create(). Indica a la implementación XDR que el resto del registro actual en el búfer de entrada del flujo debe ser descartado. Esta rutina devuelve uno si tiene éxito, cero en caso contrario.
bool_t xdr_reference(XDR *xdrs, char **pp, unsigned int size,
                     xdrproc_t proc);
Una primitiva que proporciona seguimiento de punteros dentro de estructuras. El argumento pp es la dirección del puntero; size es el sizeof de la estructura a la que apunta *pp; y proc es un procedimiento XDR que filtra la estructura entre su forma C y su representación externa. Esta rutina devuelve uno si tiene éxito, cero en caso contrario.
Advertencia: esta rutina no entiende los punteros nulos. Utilice xdr_pointer() en su lugar.
xdr_setpos(XDR *xdrs, unsigned int pos);
Una macro que invoca la rutina de establecer la posición asociada con el flujo XDR xdrs. El argumento pos es un valor de posición obtenido de xdr_getpos(). Esta rutina devuelve uno si el flujo XDR pudo ser reposicionado, y cero en caso contrario.
Advertencia: es difícil reposicionar algunos tipos de flujos XDR, por lo que esta rutina puede fallar con un tipo de flujo y tener éxito con otro.
bool_t xdr_short(XDR *xdrs, short *sp);
Una primitiva de filtro que traduce entre enteros short de C y sus representaciones externas. Esta rutina devuelve uno si tiene éxito, cero en caso contrario.
void xdrstdio_create(XDR *xdrs, FILE *file, enum xdr_op op);
Esta rutina inicializa el objeto de flujo XDR apuntado por xdrs. Los datos del flujo XDR se escriben, o se leen, del flujo stdio file. El argumento op determina la dirección del flujo XDR (ya sea XDR_ENCODE, XDR_DECODE o XDR_FREE).
Advertencia: la rutina de destrucción asociada con dichos flujos XDR llama a fflush(3) en el flujo file, pero nunca a fclose(3).
bool_t xdr_string(XDR *xdrs, char **sp, unsigned int maxsize);
Una primitiva de filtro que traduce entre cadenas de C y sus representaciones externas correspondientes. Las cadenas no pueden ser más largas que maxsize. Nota: sp es la dirección del puntero de la cadena. Esta rutina devuelve uno si tiene éxito, cero en caso contrario.
bool_t xdr_u_char(XDR *xdrs, unsigned char *ucp);
Una primitiva de filtro que traduce entre caracteres unsigned de C y sus representaciones externas. Esta rutina devuelve uno si tiene éxito, cero en caso contrario.
bool_t xdr_u_int(XDR *xdrs, unsigned int *up);
Una primitiva de filtro que traduce entre enteros unsigned de C y sus representaciones externas. Esta rutina devuelve uno si tiene éxito, cero en caso contrario.
bool_t xdr_u_long(XDR *xdrs, unsigned long *ulp);
Una primitiva de filtro que traduce entre enteros unsigned long de C y sus representaciones externas. Esta rutina devuelve uno si tiene éxito, cero en caso contrario.
bool_t xdr_u_short(XDR *xdrs, unsigned short *usp);
Una primitiva de filtro que traduce entre enteros unsigned short de C y sus representaciones externas. Esta rutina devuelve uno si tiene éxito, cero en caso contrario.
bool_t xdr_union(XDR *xdrs, enum_t *dscmp, char *unp,
                 const struct xdr_discrim *choices,
                 xdrproc_t defaultarm);     /* puede ser NULL */
Una primitiva de filtro que traduce entre una union discriminada de C y su representación externa correspondiente. Primero traduce el discriminante de la unión ubicada en dscmp. Este discriminante es siempre un enum_t. Luego se traduce la unión ubicada en unp. El argumento choices es un puntero a una matriz de estructuras xdr_discrim(). Cada estructura contiene un par ordenado de [valor,proc]. Si el discriminante de la unión es igual al valor asociado, entonces se llama a proc para traducir la unión. El final de la matriz de estructuras xdr_discrim() se denota por un procedimiento de valor NULL. Si el discriminante no se encuentra en la matriz choices, entonces se llama al procedimiento defaultarm (si no es NULL). Devuelve uno si tiene éxito, cero en caso contrario.
bool_t xdr_vector(XDR *xdrs, char *arrp, unsigned int size,
                  unsigned int elsize, xdrproc_t elproc);
Una primitiva de filtro que traduce entre matrices de longitud fija y sus representaciones externas correspondientes. El argumento arrp es la dirección del puntero a la matriz, mientras que size es el recuento de elementos de la matriz. El argumento elsize es el sizeof de cada uno de los elementos de la matriz, y elproc es un filtro XDR que traduce entre la forma C de los elementos de la matriz y su representación externa. Esta rutina devuelve uno si tiene éxito, cero en caso contrario.
bool_t xdr_void(void);
Esta rutina siempre devuelve uno. Puede pasarse a rutinas RPC que requieran un argumento de función, donde no se debe hacer nada.
bool_t xdr_wrapstring(XDR *xdrs, char **sp);
Una primitiva que llama a xdr_string(xdrs, sp,MAXUN.UNSIGNED ); donde MAXUN.UNSIGNED es el valor máximo de un entero sin signo. xdr_wrapstring() es útil porque el paquete RPC pasa un máximo de dos rutinas XDR como argumentos, y xdr_string(), una de las primitivas más utilizadas, requiere tres. Devuelve uno si tiene éxito, cero en caso contrario.
