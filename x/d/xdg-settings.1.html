XDG-SETTINGS(1) Manual de xdg-settings XDG-SETTINGS(1)

NOMBRE

xdg-settings - obtener varias configuraciones del entorno de escritorio

SINOPSIS

xdg-settings {get | check | set} {propiedad} [subpropiedad] [valor]

xdg-settings {--help | --list | --manual | --version}

DESCRIPCIÓN

xdg-settings obtiene varias configuraciones del entorno de escritorio. Por ejemplo, los entornos de escritorio a menudo proporcionan configuración de proxy y configuración del navegador web predeterminado. Usando xdg-settings estos parámetros pueden ser extraídos para su uso por aplicaciones que no usan las bibliotecas del entorno de escritorio (que usarían las configuraciones de forma nativa).

xdg-settings es solo para uso dentro de una sesión de escritorio. No se recomienda usar xdg-settings como root.

OPCIONES

--help

Muestra el resumen del comando.

--list

Lista todas las propiedades que xdg-settings conoce.

--manual

Muestra esta página del manual.

--version

Muestra la información de la versión de xdg-utils.

PROPIEDADES

Al usar xdg-settings para obtener, verificar o establecer una configuración de escritorio, se utilizan propiedades y, posiblemente, subpropiedades para especificar la configuración que se va a cambiar.

Algunas propiedades (como default-web-browser) describen completamente la configuración que se va a cambiar. Otras propiedades (como default-url-scheme-handler) requieren más información (en este caso, el esquema real para el que se debe establecer el manejador predeterminado) que debe proporcionarse en una subpropiedad.

CÓDIGOS DE SALIDA

Un código de salida de 0 indica éxito, mientras que un código de salida distinto de cero indica fallo. Los siguientes códigos de fallo pueden ser devueltos:

1

Error en la sintaxis de la línea de comandos.

2

Uno de los archivos pasados en la línea de comandos no existía.

3

No se pudo encontrar una herramienta requerida.

4

La acción falló.

VER TAMBIÉN

xdg-mime(1), xdg-open(1), Especificación de asociaciones de aplicaciones MIME[1]

EJEMPLOS

Obtener el nombre del archivo de escritorio del navegador web predeterminado actual

        xdg-settings get default-web-browser

Comprobar si el navegador web predeterminado es firefox.desktop, lo cual puede ser falso incluso si "get default-web-browser" dice que es el valor actual (si solo algunas de las configuraciones subyacentes reflejan ese valor)

        xdg-settings check default-web-browser firefox.desktop

Establecer el navegador web predeterminado en google-chrome.desktop

        xdg-settings set default-web-browser google-chrome.desktop

Establecer el manejador de URL predeterminado para el esquema mailto en evolution.desktop

        xdg-settings set default-url-scheme-handler mailto evolution.desktop
