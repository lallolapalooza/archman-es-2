NOMBRE

xdpyinfo - utilidad para mostrar información sobre X

SINOPSIS

xdpyinfo [-display nombre-pantalla] [-queryExtensions] [-ext nombre-extension]
         [-help | -version]

DESCRIPCIÓN

Xdpyinfo es una utilidad para mostrar información sobre un servidor X. Se utiliza para examinar las capacidades de un servidor, los valores predefinidos para varios parámetros utilizados en la comunicación entre clientes y el servidor, y los diferentes tipos de pantallas y visualizaciones disponibles.

Por defecto, la información numérica (código de operación, evento base, error base) sobre las extensiones del protocolo no se muestra. Esta información se puede obtener con la opción -queryExtensions. El uso de esta opción en servidores que cargan extensiones dinámicamente probablemente provocará la carga de todas las extensiones posibles, lo que puede ser lento y consumir recursos significativos del servidor.

La información detallada sobre una extensión particular se muestra con la opción -ext nombre-extension. Si nombre-extension es all, se muestra información sobre todas las extensiones compatibles tanto con xdpyinfo como con el servidor.

Si se especifica -help, xdpyinfo imprime su mensaje de uso y sale, sin contactar al servidor X.

Si se especifica -version, xdpyinfo imprime su versión y sale, sin contactar al servidor X.

AMBIENTE

DISPLAY
Para obtener el host, número de pantalla y pantalla predeterminados.

VER TAMBIÉN

X(7), xprop(1), xrdb(1), xwininfo(1), xrandr(1), xdriinfo(1), xvinfo(1), glxinfo(1)
