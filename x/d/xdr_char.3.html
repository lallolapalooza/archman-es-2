xdr(3) Manual de Funciones de Biblioteca xdr(3)

NOMBRE

xdr - rutinas de biblioteca para la representación de datos externa

BIBLIOTECA

Biblioteca estándar de C (libc, -lc)

SINOPSIS Y DESCRIPCION

Estas rutinas permiten a los programadores de C describir estructuras de datos arbitrarias de una manera independiente de la máquina. Los datos para las llamadas a procedimientos remotos se transmiten utilizando estas rutinas.

Los prototipos a continuación se declaran en <rpc/xdr.h> y utilizan los siguientes tipos:

typedef int bool_t;
typedef typeof(bool_t (XDR *, void *, ...))  *xdrproc_t;

Para la declaración del tipo XDR, consulte <rpc/xdr.h>.

bool_t xdr_array(XDR *xdrs, char **arrp, unsigned int *sizep,
                 unsigned int maxsize, unsigned int elsize,
                 xdrproc_t elproc);
Un primitivo de filtro que traduce entre arrays de longitud variable y sus representaciones externas correspondientes. El argumento arrp es la dirección del puntero al array, mientras que sizep es la dirección del contador de elementos del array; este contador de elementos no puede exceder maxsize. El argumento elsize es el tamaño en bytes de cada uno de los elementos del array, y elproc es un filtro XDR que traduce entre la forma C de los elementos del array y su representación externa. Esta rutina devuelve uno si tiene éxito, cero en caso contrario.
bool_t xdr_bool(XDR *xdrs, bool_t *bp);
Un primitivo de filtro que traduce entre booleanos (enteros C) y sus representaciones externas. Al codificar datos, este filtro produce valores de uno o cero. Esta rutina devuelve uno si tiene éxito, cero en caso contrario.
bool_t xdr_bytes(XDR *xdrs, char **sp, unsigned int *sizep,
                 unsigned int maxsize);
Un primitivo de filtro que traduce entre cadenas de bytes contadas y sus representaciones externas. El argumento sp es la dirección del puntero a la cadena. La longitud de la cadena se encuentra en la dirección sizep; las cadenas no pueden ser más largas que maxsize. Esta rutina devuelve uno si tiene éxito, cero en caso contrario.
bool_t xdr_char(XDR *xdrs, char *cp);
Un primitivo de filtro que traduce entre caracteres C y sus representaciones externas. Esta rutina devuelve uno si tiene éxito, cero en caso contrario. Nota: los caracteres codificados no se empaquetan y ocupan 4 bytes cada uno. Para arrays de caracteres, merece la pena considerar xdr_bytes(), xdr_opaque() o xdr_string().
void xdr_destroy(XDR *xdrs);
Una macro que invoca la rutina de destrucción asociada con el flujo XDR, xdrs. La destrucción generalmente implica la liberación de estructuras de datos privadas asociadas con el flujo. El uso de xdrs después de invocar xdr_destroy() no está definido.
bool_t xdr_double(XDR *xdrs, double *dp);
Un primitivo de filtro que traduce entre números de punto flotante de doble precisión C y sus representaciones externas. Esta rutina devuelve uno si tiene éxito, cero en caso contrario.
bool_t xdr_enum(XDR *xdrs, enum_t *ep);
Un primitivo de filtro que traduce entre enumeraciones C (en realidad, enteros) y sus representaciones externas. Esta rutina devuelve uno si tiene éxito, cero en caso contrario.
bool_t xdr_float(XDR *xdrs, float *fp);
Un primitivo de filtro que traduce entre números de punto flotante C y sus representaciones externas. Esta rutina devuelve uno si tiene éxito, cero en caso contrario.
void xdr_free(xdrproc_t proc, char *objp);
Rutina de liberación genérica. El primer argumento es la rutina XDR para el objeto que se está liberando. El segundo argumento es un puntero al objeto mismo. Nota: el puntero pasado a esta rutina no se libera, pero lo que apunta sí se libera (recursivamente).
unsigned int xdr_getpos(XDR *xdrs);
Una macro que invoca la rutina de obtención de posición asociada con el flujo XDR, xdrs. La rutina devuelve un entero sin signo, que indica la posición del flujo de bytes XDR. Una característica deseable de los flujos XDR es que la aritmética simple funciona con este número, aunque las instancias de flujos XDR no garantizan esto.
long *xdr_inline(XDR *xdrs, int len);
Una macro que invoca la rutina en línea asociada con el flujo XDR, xdrs. La rutina devuelve un puntero a una pieza contigua del buffer del flujo; len es la longitud en bytes del buffer deseado. Nota: el puntero se convierte a long *.
Advertencia: xdr_inline() puede devolver NULL (0) si no puede asignar una pieza contigua de un buffer. Por lo tanto, el comportamiento puede variar entre instancias de flujo; existe por eficiencia.
bool_t xdr_int(XDR *xdrs, int *ip);
Un primitivo de filtro que traduce entre enteros C y sus representaciones externas. Esta rutina devuelve uno si tiene éxito, cero en caso contrario.
bool_t xdr_long(XDR *xdrs, long *lp);
Un primitivo de filtro que traduce entre enteros long C y sus representaciones externas. Esta rutina devuelve uno si tiene éxito, cero en caso contrario.
void xdrmem_create(XDR *xdrs, char *addr, unsigned int size,
                   enum xdr_op op);
Esta rutina inicializa el objeto de flujo XDR apuntado por xdrs. Los datos del flujo se escriben o leen de un bloque de memoria en la ubicación addr cuya longitud no supera los size bytes. El argumento op determina la dirección del flujo XDR (ya sea XDR_ENCODE, XDR_DECODE o XDR_FREE).
bool_t xdr_opaque(XDR *xdrs, char *cp, unsigned int cnt);
Un primitivo de filtro que traduce entre datos opacos de tamaño fijo y su representación externa. El argumento cp es la dirección del objeto opaco y cnt es su tamaño en bytes. Esta rutina devuelve uno si tiene éxito, cero en caso contrario.
bool_t xdr_pointer(XDR *xdrs, char **objpp,
                   unsigned int objsize, xdrproc_t xdrobj);
Similar a xdr_reference() excepto en que serializa punteros nulos, mientras que xdr_reference() no lo hace. Por lo tanto, xdr_pointer() puede representar estructuras de datos recursivas, como árboles binarios o listas enlazadas.
void xdrrec_create(XDR *xdrs, unsigned int sendsize,
                   unsigned int recvsize, char *handle,
                   typeof(int (char *, char *, int)) *readit,
                   typeof(int (char *, char *, int)) *writeit);
Esta rutina inicializa el objeto de flujo XDR apuntado por xdrs. Los datos del flujo se escriben en un buffer de tamaño sendsize; un valor de cero indica que el sistema debe usar un valor predeterminado adecuado. Los datos del flujo se leen de un buffer de tamaño recvsize; este también se puede configurar con un valor predeterminado adecuado pasando un valor cero. Cuando el buffer de salida de un flujo está lleno, se llama a writeit. De manera similar, cuando el buffer de entrada de un flujo está vacío, se llama a readit. El comportamiento de estas dos rutinas es similar a las llamadas del sistema read(2) y write(2), excepto que handle se pasa a las rutinas anteriores como primer argumento. Nota: el campo op del flujo XDR debe ser establecido por el llamador.
Advertencia: para leer de un flujo XDR creado por esta API, deberá llamar a xdrrec_skiprecord() antes de llamar a cualquier otra API XDR. Esto inserta bytes adicionales en el flujo para proporcionar límites de registro
bool_t xdr_reference(XDR *xdrs, char **pp, unsigned int size,
                     xdrproc_t proc);
Esta es una rutina de filtro genérica que traduce entre un puntero a un objeto y la representación externa de ese objeto. El argumento pp es la dirección del puntero al objeto, size es el tamaño del objeto en bytes, y proc es la rutina XDR que se utiliza para traducir el objeto. Esta rutina devuelve uno si tiene éxito, cero en caso contrario.
bool_t xdr_setpos(XDR *xdrs, unsigned int pos);
Una macro que invoca la rutina de establecimiento de posición asociada con el flujo XDR, xdrs. La rutina establece la posición del flujo de bytes XDR a pos. Esta rutina devuelve uno si tiene éxito, cero en caso contrario.
bool_t xdr_short(XDR *xdrs, short *sp);
Un primitivo de filtro que traduce entre enteros cortos C y sus representaciones externas. Esta rutina devuelve uno si tiene éxito, cero en caso contrario.
bool_t xdr_skiprecord(XDR *xdrs);
Esta rutina omite el registro actual en un flujo XDR registrado. Se utiliza principalmente para avanzar en un flujo XDR cuando no se necesita procesar el registro actual. Devuelve uno si tiene éxito, cero en caso contrario.
bool_t xdr_string(XDR *xdrs, char **sp, unsigned int maxsize);
Un primitivo de filtro que traduce entre cadenas de caracteres C (terminadas en nulo) y su representación externa. El argumento sp es la dirección del puntero a la cadena. La cadena no puede ser más larga que maxsize. Esta rutina devuelve uno si tiene éxito, cero en caso contrario.
bool_t xdr_u_char(XDR *xdrs, unsigned char *ucp);
Un primitivo de filtro que traduce entre caracteres sin signo C y sus representaciones externas. Esta rutina devuelve uno si tiene éxito, cero en caso contrario.
bool_t xdr_u_long(XDR *xdrs, unsigned long *ulp);
Un primitivo de filtro que traduce entre enteros long sin signo C y sus representaciones externas. Esta rutina devuelve uno si tiene éxito, cero en caso contrario.
bool_t xdr_uint(XDR *xdrs, unsigned int *uip);
Un primitivo de filtro que traduce entre enteros sin signo C y sus representaciones externas. Esta rutina devuelve uno si tiene éxito, cero en caso contrario.
bool_t xdr_union(XDR *xdrs, enum_t *discr, char *fmt,
                 xdrproc_t *dispatch, xdrproc_t fdispatch);
Un primitivo de filtro que traduce entre uniones C y sus representaciones externas. El argumento discr es un puntero al discriminante de la unión. El argumento fmt es una dirección de una lista de argumentos que describe los tipos de las ramas de la unión. El argumento dispatch es una tabla de búsqueda de rutinas XDR para las ramas de la unión. El argumento fdispatch es una rutina XDR que se llama para serializar o deserializar el discriminante. Esta rutina devuelve uno si tiene éxito, cero en caso contrario.
bool_t xdr_vector(XDR *xdrs, char *arrp, unsigned int size,
                  unsigned int elsize, xdrproc_t elproc);
Un primitivo de filtro que traduce entre arrays de longitud fija y sus representaciones externas correspondientes. El argumento arrp es la dirección del puntero al array, size es el número de elementos en el array, elsize es el tamaño en bytes de cada elemento, y elproc es un filtro XDR que traduce entre la forma C de los elementos del array y su representación externa. Esta rutina devuelve uno si tiene éxito, cero en caso contrario.
bool_t xdr_void(XDR *xdrs);
Un primitivo de filtro que no traduce nada. Se utiliza para representar llamadas a procedimientos que no tienen argumentos ni resultados.
bool_t xdr_longlong(XDR *xdrs, long long *llp);
Un primitivo de filtro que traduce entre enteros de 64 bits C (long long) y sus representaciones externas. Esta rutina devuelve uno si tiene éxito, cero en caso contrario.
bool_t xdr_u_longlong(XDR *xdrs, unsigned long long *ullp);
Un primitivo de filtro que traduce entre enteros de 64 bits sin signo C (unsigned long long) y sus representaciones externas. Esta rutina devuelve uno si tiene éxito, cero en caso contrario.
bool_t xdr_hyper(XDR *xdrs, long long *hiep);
Alias para xdr_longlong().
bool_t xdr_u_hyper(XDR *xdrs, unsigned long long *uhiep);
Alias para xdr_u_longlong().

SYNOPSIS AND DESCRIPTION

bool_t xdr_array(XDR *xdrs, char **cpp, unsigned int *size,
                 unsigned int maxsize, xdrproc_t element_proc,
                 xdrproc_t fix_proc);
A filter primitive that translates between C arrays and their external representations. The argument cpp is the address of the pointer to the array; size is the address of the number of elements in the array. The argument maxsize is the maximum number of elements the array can hold. The argument element_proc is an XDR filter that translates between the array elements' C form, and their external representation. The argument fix_proc is an XDR filter that translates between the array's C form and its external form. This routine returns one if it succeeds, zero otherwise.
Warning: the XDR package does not support variable-length arrays. Use xdr_vector() instead.
bool_t xdr_bool(XDR *xdrs, bool_t *bp);
A filter primitive that translates between C bool_t types and their external representations. This routine returns one if it succeeds, zero otherwise.
bool_t xdr_bytes(XDR *xdrs, char **sp, unsigned int *size,
                 unsigned int maxsize);
A filter primitive that translates between C byte strings and their external representations. The argument sp is the address of the string's pointer; size is the address of the number of bytes in the string. The argument maxsize is the maximum number of bytes allowed in the string. This routine returns one if it succeeds, zero otherwise.
bool_t xdr_char(XDR *xdrs, char *cp);
A filter primitive that translates between C characters and their external representations. This routine returns one if it succeeds, zero otherwise.
void xdr_destroy(XDR *xdrs);
This routine deallocates the private state associated with the XDR stream xdrs. If the XDR stream was created using xdrstdio_create(), it also calls fflush(3) on the associated FILE* stream, but never fclose(3).
bool_t xdr_double(XDR *xdrs, double *dp);
A filter primitive that translates between C double precision floating-point numbers and their external representations. This routine returns one if it succeeds, zero otherwise.
bool_t xdr_enum(XDR *xdrs, enum_t *ep);
A filter primitive that translates between C enum types and their external representations. This routine returns one if it succeeds, zero otherwise.
bool_t xdr_float(XDR *xdrs, float *fp);
A filter primitive that translates between C float precision floating-point numbers and their external representations. This routine returns one if it succeeds, zero otherwise.
void xdr_free(xdrproc_t proc, char *ptr);
This routine frees the memory pointed to by ptr. The argument proc is the XDR filter used to encode or decode the structure pointed to by ptr. It is the responsibility of the caller to ensure that proc is the correct XDR filter. It is also the caller's responsibility to ensure that ptr was dynamically allocated. This routine is typically used to free memory that was allocated by the XDR package during decoding.
unsigned int xdr_getpos(XDR *xdrs);
A macro that invokes the get position routine associated with the XDR stream xdrs. The return value is a position, which may be used later with xdr_setpos(). Not all XDR streams support this operation.
char *(*xdr_inline(XDR *xdrs, unsigned int len));
A primitive that returns a pointer to a buffer of length len. The buffer is associated with the XDR stream xdrs. This routine should only be called when the XDR filter is expecting data of exactly length len. This routine returns NULL if it is not possible to get an in-line buffer. This routine returns a pointer to the buffer if it succeeds.
Warning: the buffer returned by this routine may be overwritten by subsequent calls to XDR routines on the same stream.
bool_t xdr_int(XDR *xdrs, int *ip);
A filter primitive that translates between C int types and their external representations. This routine returns one if it succeeds, zero otherwise.
bool_t xdr_long(XDR *xdrs, long *lp);
A filter primitive that translates between C long integers and their external representations. This routine returns one if it succeeds, zero otherwise.
void xdrmem_create(XDR *xdrs, const char *addr, unsigned int len,
                   enum xdr_op op);
This routine initializes the XDR stream object pointed to by xdrs. The XDR stream data is read from, or written to, the memory buffer starting at address addr, for len bytes. The argument op determines the direction of the XDR stream (either XDR_ENCODE, XDR_DECODE, or XDR_FREE).
bool_t xdr_opaque(XDR *xdrs, char *cp, unsigned int len);
A filter primitive that translates between C opaque data and their external representations. The argument cp is the buffer containing the data; len is the number of bytes to translate. This routine returns one if it succeeds, zero otherwise.
bool_t xdr_pointer(XDR *xdrs, char **pp, unsigned int size,
                   xdrproc_t proc);
A primitive that provides pointer chasing within structures. The argument pp is the address of the pointer; size is the sizeof the structure that *pp points to; and proc is an XDR procedure that filters the structure between its C form and its external representation. This routine returns one if it succeeds, zero otherwise.
Warning: this routine understands NULL pointers. Use xdr_reference() if you do not need NULL pointer support.
XDR * xdrrec_create(XDR *xdrs, unsigned int buflen,
                   unsigned int oversize, FILE *infile,
                   FILE *outfile, xdr_op_t op);
This routine initializes the XDR stream object pointed to by xdrs. It enables record-oriented XDR transfer. The argument buflen is the size of the buffer to be used for XDR operations. The argument oversize is the size of the buffer that can be used for XDR operations. The arguments infile and outfile are the corresponding stdio streams to be used for reading and writing. The argument op determines the direction of the XDR stream (either XDR_ENCODE, XDR_DECODE, or XDR_FREE).
Note: the infile and outfile arguments are optional, and may be specified as NULL. If both are NULL, then the XDR stream will operate entirely in memory. If only one is specified, it will be used for both reading and writing.
Note: XDR streams created with xdrrec_create() are not compatible with XDR streams created with other xdr_*_create routines. This is because xdrrec_create() uses buffered I/O, while other routines may use unbuffered I/O. Also, XDR streams created with different xdr_*_create APIs are not compatible for the same reason.
bool_t xdrrec_endofrecord(XDR *xdrs, int sendnow);
This routine can be invoked only on streams created by xdrrec_create(). The data in the output buffer is marked as a completed record, and the output buffer is optionally written out if sendnow is nonzero. This routine returns one if it succeeds, zero otherwise.
bool_t xdrrec_eof(XDR *xdrs);
This routine can be invoked only on streams created by xdrrec_create(). After consuming the rest of the current record in the stream, this routine returns one if the stream has no more input, zero otherwise.
bool_t xdrrec_skiprecord(XDR *xdrs);
This routine can be invoked only on streams created by xdrrec_create(). It tells the XDR implementation that the rest of the current record in the stream's input buffer should be discarded. This routine returns one if it succeeds, zero otherwise.
bool_t xdr_reference(XDR *xdrs, char **pp, unsigned int size,
                     xdrproc_t proc);
A primitive that provides pointer chasing within structures. The argument pp is the address of the pointer; size is the sizeof the structure that *pp points to; and proc is an XDR procedure that filters the structure between its C form and its external representation. This routine returns one if it succeeds, zero otherwise.
Warning: this routine does not understand null pointers. Use xdr_pointer() instead.
xdr_setpos(XDR *xdrs, unsigned int pos);
A macro that invokes the set position routine associated with the XDR stream xdrs. The argument pos is a position value obtained from xdr_getpos(). This routine returns one if the XDR stream could be repositioned, and zero otherwise.
Warning: it is difficult to reposition some types of XDR streams, so this routine may fail with one type of stream and succeed with another.
bool_t xdr_short(XDR *xdrs, short *sp);
A filter primitive that translates between C short integers and their external representations. This routine returns one if it succeeds, zero otherwise.
void xdrstdio_create(XDR *xdrs, FILE *file, enum xdr_op op);
This routine initializes the XDR stream object pointed to by xdrs. The XDR stream data is written to, or read from, the stdio stream file. The argument op determines the direction of the XDR stream (either XDR_ENCODE, XDR_DECODE, or XDR_FREE).
Warning: the destroy routine associated with such XDR streams calls fflush(3) on the file stream, but never fclose(3).
bool_t xdr_string(XDR *xdrs, char **sp, unsigned int maxsize);
A filter primitive that translates between C strings and their corresponding external representations. Strings cannot be longer than maxsize. Note: sp is the address of the string's pointer. This routine returns one if it succeeds, zero otherwise.
bool_t xdr_u_char(XDR *xdrs, unsigned char *ucp);
A filter primitive that translates between unsigned C characters and their external representations. This routine returns one if it succeeds, zero otherwise.
bool_t xdr_u_int(XDR *xdrs, unsigned int *up);
A filter primitive that translates between C unsigned integers and their external representations. This routine returns one if it succeeds, zero otherwise.
bool_t xdr_u_long(XDR *xdrs, unsigned long *ulp);
A filter primitive that translates between C unsigned long integers and their external representations. This routine returns one if it succeeds, zero otherwise.
bool_t xdr_u_short(XDR *xdrs, unsigned short *usp);
A filter primitive that translates between C unsigned short integers and their external representations. This routine returns one if it succeeds, zero otherwise.
bool_t xdr_union(XDR *xdrs, enum_t *dscmp, char *unp,
                 const struct xdr_discrim *choices,
                 xdrproc_t defaultarm);     /* may equal NULL */
A filter primitive that translates between a discriminated C union and its corresponding external representation. It first translates the discriminant of the union located at dscmp. This discriminant is always an enum_t. Next the union located at unp is translated. The argument choices is a pointer to an array of xdr_discrim() structures. Each structure contains an ordered pair of [value,proc]. If the union's discriminant is equal to the associated value, then the proc is called to translate the union. The end of the xdr_discrim() structure array is denoted by a routine of value NULL. If the discriminant is not found in the choices array, then the defaultarm procedure is called (if it is not NULL). Returns one if it succeeds, zero otherwise.
bool_t xdr_vector(XDR *xdrs, char *arrp, unsigned int size,
                  unsigned int elsize, xdrproc_t elproc);
A filter primitive that translates between fixed-length arrays and their corresponding external representations. The argument arrp is the address of the pointer to the array, while size is the element count of the array. The argument elsize is the sizeof each of the array's elements, and elproc is an XDR filter that translates between the array elements' C form, and their external representation. This routine returns one if it succeeds, zero otherwise.
bool_t xdr_void(void);
This routine always returns one. It may be passed to RPC routines that require a function argument, where nothing is to be done.
bool_t xdr_wrapstring(XDR *xdrs, char **sp);
A primitive that calls xdr_string(xdrs, sp,MAXUN.UNSIGNED ); where MAXUN.UNSIGNED is the maximum value of an unsigned integer. xdr_wrapstring() is handy because the RPC package passes a maximum of two XDR routines as arguments, and xdr_string(), one of the most frequently used primitives, requires three. Returns one if it succeeds, zero otherwise.
