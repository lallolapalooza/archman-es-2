NOMBRE

xdo - Realizar acciones en ventanas

SINOPSIS

xdo ACCIÓN [OPCIONES] [WID ...]

DESCRIPCIÓN

Aplica la acción dada a las ventanas dadas.

Si no se proporcionan IDs de ventana ni opciones, la acción se aplica a la ventana enfocada.

ACCIONES

close

Cierra la ventana.

kill

Mata al cliente.

hide

Desmonta la ventana.

show

Monta la ventana.

raise

Eleva la ventana.

lower

Baja la ventana.

below

Coloca la ventana debajo del objetivo (ver -t).

above

Coloca la ventana encima del objetivo (ver -t).

move

Mueve la ventana.

resize

Redimensiona la ventana.

activate

Activa la ventana.

id

Imprime el ID de la ventana.

pid

Imprime el PID de la ventana.

key_press, key_release

Simula un evento de pulsación/liberación de tecla.

button_press, button_release

Simula un evento de pulsación/liberación de botón.

pointer_motion

Simula un evento de movimiento del puntero.

-h

Imprime la sinopsis y sale.

-v

Imprime la versión y sale.

OPCIONES

Cuando se proporcionan opciones, la acción se aplica a todos los hijos de la ventana raíz que coinciden con las comparaciones implícitas por las opciones en relación con la ventana enfocada.

-r

ID distinto.

-c

Misma clase.

-C

Clase distinta.

-d

Mismo escritorio.

-D

Escritorio distinto.

-n NOMBRE_INSTANCIA

La ventana tiene el nombre de instancia dado.

-N NOMBRE_CLASE

La ventana tiene el nombre de clase dado.

-a NOMBRE_WM

La ventana tiene el nombre WM dado.

-t WID

La ventana objetivo para las acciones below y above.

-p PID

La ventana tiene el PID dado.

-k CÓDIGO

Usa el código dado para las acciones key_press, key_release, button_press y button_release.

-x [±]PÍXELES

Coordenada X de la ventana (o delta) para la acción move y pointer_motion.

-y [±]PÍXELES

Coordenada Y de la ventana (o delta) para la acción move y pointer_motion.

-w [±]PÍXELES

Ancho de la ventana (o delta) para la acción resize.

-h [±]PÍXELES

Altura de la ventana (o delta) para la acción resize.

-m

Espera la existencia de una ventana coincidente.

-s

Maneja números de escritorio simbólicos.

EJEMPLOS

Cerrar la ventana enfocada:

xdo close

Cerrar todas las ventanas que tengan la misma clase que la ventana enfocada:

xdo close -c

Ocultar todas las ventanas del escritorio actual excepto la ventana enfocada:

xdo hide -dr

Activar la ventana con ID 0x00800109:

xdo activate 0x00800109

Enviar eventos falsos de pulsación/liberación de tecla con el código de tecla 46 a la ventana enfocada:

xdo key_press -k 46; sleep 0.2; xdo key_release -k 46
