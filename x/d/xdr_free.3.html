xdr(3) Manual de Funciones de Librería xdr(3)

NOMBRE

xdr - rutinas de librería para la representación de datos externa

LIBRERÍA

Librería C estándar (libc, -lc)

SINOPSIS Y DESCRIPCIÓN

Estas rutinas permiten a los programadores C describir estructuras de datos arbitrarias de forma independiente de la máquina. Los datos para las llamadas a procedimientos remotos se transmiten utilizando estas rutinas.

Los prototipos a continuación se declaran en <rpc/xdr.h> y hacen uso de los siguientes tipos:

typedef int bool_t;
typedef typeof(bool_t (XDR *, void *, ...))  *xdrproc_t;

Para la declaración del tipo XDR, véase <rpc/xdr.h>.

bool_t xdr_array(XDR *xdrs, char **arrp, unsigned int *sizep,
                 unsigned int maxsize, unsigned int elsize,
                 xdrproc_t elproc);
Un filtro primitivo que traduce entre arrays de longitud variable y sus representaciones externas correspondientes. El argumento arrp es la dirección del puntero al array, mientras que sizep es la dirección del contador de elementos del array; este contador de elementos no puede exceder maxsize. El argumento elsize es el sizeof de cada uno de los elementos del array, y elproc es un filtro XDR que traduce entre la forma C de los elementos del array y su representación externa. Esta rutina devuelve uno si tiene éxito, cero en caso contrario.
bool_t xdr_bool(XDR *xdrs, bool_t *bp);
Un filtro primitivo que traduce entre booleanos (enteros C) y sus representaciones externas. Al codificar datos, este filtro produce valores de uno o cero. Esta rutina devuelve uno si tiene éxito, cero en caso contrario.
bool_t xdr_bytes(XDR *xdrs, char **sp, unsigned int *sizep,
                 unsigned int maxsize);
Un filtro primitivo que traduce entre cadenas de bytes contadas y sus representaciones externas. El argumento sp es la dirección del puntero de la cadena. La longitud de la cadena se encuentra en la dirección sizep; las cadenas no pueden ser más largas que maxsize. Esta rutina devuelve uno si tiene éxito, cero en caso contrario.
bool_t xdr_char(XDR *xdrs, char *cp);
Un filtro primitivo que traduce entre caracteres C y sus representaciones externas. Esta rutina devuelve uno si tiene éxito, cero en caso contrario. Nota: los caracteres codificados no se empaquetan y ocupan 4 bytes cada uno. Para arrays de caracteres, vale la pena considerar xdr_bytes(), xdr_opaque(), o xdr_string().
void xdr_destroy(XDR *xdrs);
Una macro que invoca la rutina de destrucción asociada con el flujo XDR, xdrs. La destrucción generalmente implica liberar estructuras de datos privadas asociadas con el flujo. Usar xdrs después de invocar xdr_destroy() no está definido.
bool_t xdr_double(XDR *xdrs, double *dp);
Un filtro primitivo que traduce entre números de precisión double de C y sus representaciones externas. Esta rutina devuelve uno si tiene éxito, cero en caso contrario.
bool_t xdr_enum(XDR *xdrs, enum_t *ep);
Un filtro primitivo que traduce entre enums de C (en realidad enteros) y sus representaciones externas. Esta rutina devuelve uno si tiene éxito, cero en caso contrario.
bool_t xdr_float(XDR *xdrs, float *fp);
Un filtro primitivo que traduce entre floats de C y sus representaciones externas. Esta rutina devuelve uno si tiene éxito, cero en caso contrario.
void xdr_free(xdrproc_t proc, char *objp);
Rutina genérica de liberación. El primer argumento es la rutina XDR para el objeto que se está liberando. El segundo argumento es un puntero al objeto en sí. Nota: el puntero pasado a esta rutina no se libera, pero lo que apunta sí se libera (recursivamente).
unsigned int xdr_getpos(XDR *xdrs);
Una macro que invoca la rutina de obtención de posición asociada con el flujo XDR, xdrs. La rutina devuelve un entero sin signo, que indica la posición del flujo de bytes XDR. Una característica deseable de los flujos XDR es que la aritmética simple funciona con este número, aunque las instancias de flujo XDR no necesitan garantizar esto.
long *xdr_inline(XDR *xdrs, int len);
Una macro que invoca la rutina en línea asociada con el flujo XDR, xdrs. La rutina devuelve un puntero a una pieza contigua del búfer del flujo; len es la longitud en bytes del búfer deseado. Nota: el puntero se convierte a long *.
Advertencia: xdr_inline() puede devolver NULL (0) si no puede asignar una pieza contigua de un búfer. Por lo tanto, el comportamiento puede variar entre las instancias de flujo; existe por eficiencia.
bool_t xdr_int(XDR *xdrs, int *ip);
Un filtro primitivo que traduce entre enteros C y sus representaciones externas. Esta rutina devuelve uno si tiene éxito, cero en caso contrario.
bool_t xdr_long(XDR *xdrs, long *lp);
Un filtro primitivo que traduce entre enteros long de C y sus representaciones externas. Esta rutina devuelve uno si tiene éxito, cero en caso contrario.
void xdrmem_create(XDR *xdrs, char *addr, unsigned int size,
                   enum xdr_op op);
Esta rutina inicializa el objeto de flujo XDR apuntado por xdrs. Los datos del flujo se escriben o leen de un bloque de memoria en la ubicación addr cuya longitud no excede los size bytes. El op determina la dirección del flujo XDR (ya sea XDR_ENCODE, XDR_DECODE, o XDR_FREE).
bool_t xdr_opaque(XDR *xdrs, char *cp, unsigned int cnt);
Un filtro primitivo que traduce entre datos opacos de tamaño fijo y su representación externa. El argumento cp es la dirección del objeto opaco, y cnt es su tamaño en bytes. Esta rutina devuelve uno si tiene éxito, cero en caso contrario.
bool_t xdr_pointer(XDR *xdrs, char **objpp,
                   unsigned int objsize, xdrproc_t xdrobj);
Similar a xdr_reference() excepto que serializa punteros nulos, mientras que xdr_reference() no lo hace. Por lo tanto, xdr_pointer() puede representar estructuras de datos recursivas, como árboles binarios o listas enlazadas.
void xdrrec_create(XDR *xdrs, unsigned int sendsize,
                   unsigned int recvsize, char *handle,
                   typeof(int (char *, char *, int)) *readit,
                   typeof(int (char *, char *, int)) *writeit);
Esta rutina inicializa el objeto de flujo XDR apuntado por xdrs. Los datos del flujo se escriben en un búfer de tamaño sendsize; un valor de cero indica que el sistema debe usar un valor predeterminado adecuado. Los datos del flujo se leen de un búfer de tamaño recvsize; este también se puede establecer a un valor predeterminado adecuado pasando un valor cero. Cuando el búfer de salida de un flujo está lleno, se llama a writeit. De manera similar, cuando el búfer de entrada de un flujo está vacío, se llama a readit. El comportamiento de estas dos rutinas es similar a las llamadas al sistema read(2) y write(2), excepto que handle se pasa a las rutinas anteriores como primer argumento. Nota: el campo op del flujo XDR debe ser establecido por el llamador.
Advertencia: para leer de un flujo XDR creado por esta API, necesitará llamar a xdrrec_skiprecord() primero antes de llamar a cualquier otra API XDR. Esto inserta bytes adicionales en el flujo para proporcionar límites de registro.
bool_t xdrrec_skiprecord(XDR *xdrs);
Esta rutina está pensada para ser llamada al principio de una secuencia de deserialización XDR cuando se utiliza la API de registro XDR. Omite cualquier byte que quede de un registro anterior y se posiciona al principio del próximo registro. Devuelve uno si tiene éxito, cero en caso contrario.
bool_t xdr_reference(XDR *xdrs, char **pp,
                     unsigned int size, xdrproc_t proc);
Un filtro primitivo que traduce entre referencias a objetos y sus representaciones externas. El argumento pp es la dirección del puntero del objeto, size es el tamaño del objeto en bytes y proc es el filtro XDR para serializar/deserializar el objeto. Esta rutina devuelve uno si tiene éxito, cero en caso contrario. Nota: xdr_reference() no soporta punteros nulos. Para la serialización de punteros que pueden ser nulos, véase xdr_pointer().
bool_t xdr_setpos(XDR *xdrs, unsigned int pos);
Una macro que invoca la rutina de establecimiento de posición asociada con el flujo XDR, xdrs. La rutina establece la posición del flujo de bytes XDR a pos. Un valor de retorno de uno indica que tuvo éxito, cero en caso contrario.
bool_t xdr_short(XDR *xdrs, short *sp);
Un filtro primitivo que traduce entre enteros short de C y sus representaciones externas. Esta rutina devuelve uno si tiene éxito, cero en caso contrario.
bool_t xdr_string(XDR *xdrs, char **sp, unsigned int maxsize);
Un filtro primitivo que traduce entre cadenas de caracteres terminadas en NULL y sus representaciones externas. El argumento sp es la dirección del puntero de la cadena. La cadena no puede tener más de maxsize caracteres, sin incluir el carácter nulo terminador. Esta rutina devuelve uno si tiene éxito, cero en caso contrario.
bool_t xdr_u_int32_t(XDR *xdrs, u_int32_t *ip);
Un filtro primitivo que traduce entre enteros de 32 bits sin signo de C y sus representaciones externas. Esta rutina devuelve uno si tiene éxito, cero en caso contrario.
bool_t xdr_u_long(XDR *xdrs, unsigned long *ulp);
Un filtro primitivo que traduce entre enteros long sin signo de C y sus representaciones externas. Esta rutina devuelve uno si tiene éxito, cero en caso contrario.
bool_t xdr_u_longlong_t(XDR *xdrs, unsigned long long *ullp);
Un filtro primitivo que traduce entre enteros long long sin signo de C y sus representaciones externas. Esta rutina devuelve uno si tiene éxito, cero en caso contrario.
bool_t xdr_uint64_t(XDR *xdrs, uint64_t *ullp);
Un filtro primitivo que traduce entre enteros de 64 bits sin signo de C y sus representaciones externas. Esta rutina devuelve uno si tiene éxito, cero en caso contrario.
bool_t xdr_union(XDR *xdrs, enum_t *discr, char * P,
                 const struct xdr_disc_byname *choices,
                 xdrproc_t defaultix);
Un filtro primitivo que traduce entre uniones discriminadas de C y sus representaciones externas. El argumento discr es un puntero al discriminante de la unión. El argumento P es un puntero al cuerpo de la unión. El argumento choices es una tabla que mapea los valores del discriminante a los filtros XDR apropiados para los cuerpos de la unión. El argumento defaultix es el filtro XDR para el caso predeterminado (si existe).
bool_t xdr_vector(XDR *xdrs, char *arr, unsigned int size,
                  unsigned int maxsize, xdrproc_t proc);
Similar a xdr_array() pero para arrays de tamaño fijo. El argumento arr es un puntero al array, y size es el tamaño del array. El tamaño no puede exceder maxsize. El argumento proc es el filtro XDR para los elementos del array. Esta rutina devuelve uno si tiene éxito, cero en caso contrario.
bool_t xdr_void(XDR *xdrs);
Un filtro primitivo que no hace nada. Se utiliza para representar valores nulos en las estructuras de datos RPC.
bool_t xdr_wrapstring(XDR *xdrs, char **sp);
Similar a xdr_string() pero no requiere que el tamaño máximo sea especificado explícitamente. Utiliza un tamaño máximo predeterminado de infraestructura XDR. Esta rutina devuelve uno si tiene éxito, cero en caso contrario.
