xdrrec_skiprecord(3) Manual de funciones de biblioteca xdrrec_skiprecord(3)

NOMBRE

xdrrec_skiprecord - salta un registro XDR en un flujo de registro XDR.

BIBLIOTECA

Biblioteca C estándar (libc, -lc)

SINOPSIS

#include <rpc/xdr.h>
bool_t
xdrrec_skiprecord(XDR *xdrs);

DESCRIPCIÓN

El procedimiento xdrrec_skiprecord() se utiliza para saltar el resto del registro actual y posicionarse al principio del siguiente registro en el flujo XDR especificado por xdrs.

Esta función es parte de la biblioteca XDR (External Data Representation) utilizada en RPC (Remote Procedure Call). Los flujos XDR de tipo registro (XDR_ENCODE y XDR_DECODE) manejan los datos en bloques de registros. Cada registro está delimitado por un encabezado especial. xdrrec_skiprecord() lee y descarta este encabezado y cualquier dato restante en el registro actual.

Cuando se utiliza un flujo XDR de tipo registro para decodificar datos, es necesario llamar a xdrrec_skiprecord() antes de leer cualquier registro de datos. Esto asegura que el flujo se posicione correctamente para la lectura del primer registro.

La función devuelve TRUE si la operación tiene éxito, y FALSE si ocurre un error (por ejemplo, si no se puede leer el encabezado del registro).

ADVERTENCIA

Para leer desde un flujo XDR creado con la API xdrrec_create(), primero debe llamar a xdrrec_skiprecord() antes de llamar a cualquier otra API XDR. Esto inserta bytes adicionales en el flujo para proporcionar límites de registro, y omitir el registro actual es la forma correcta de avanzar en el flujo.

EJEMPLO

A continuación se muestra un ejemplo conceptual de cómo se podría usar xdrrec_skiprecord() al decodificar datos en un flujo XDR de registro:

XDR xdrs;
char recv_buf[BUFFER_SIZE];
int result;
my_data_t data;

// Inicializar el flujo XDR de registro (ej. para decodificar)
xdrrec_create(&xdrs, 0, 0, NULL, NULL, NULL);
// ... (rellenar recv_buf con datos codificados) ...

// Es necesario llamar a xdrrec_skiprecord() para posicionarse
// correctamente antes de leer el primer registro.
if (!xdrrec_skiprecord(&xdrs)) {
    // Error al saltar el registro
    fprintf(stderr, "Error skipping record\n");
    exit(1);
}

// Ahora se puede leer el primer registro de datos
if (!xdr_my_data_t(&xdrs, &data)) {
    // Error al decodificar los datos
    fprintf(stderr, "Error decoding data\n");
    exit(1);
}

// ... (procesar los datos) ...

// Para leer el siguiente registro, se necesitaría llamar nuevamente
// a xdrrec_skiprecord() antes de xdr_my_data_t().

VER TAMBIÉN

xdr(3), xdrrec_create(3)

Nombres de macros y funciones XDR adicionales

Estas son las funciones y macros XDR que no se incluyeron en la sección anterior:

bool_t xdr_array(XDR *xdrs, char **arrpp, unsigned int *size, unsigned int maxsize, xdrproc_t xdr_element, char *size_of_element);
Un filtro primitivo que traduce entre arreglos C y su representación externa. El argumento arrpp es la dirección del puntero al arreglo, mientras que size es el tamaño del arreglo. El argumento maxsize es el tamaño máximo permitido para el arreglo. El argumento xdr_element es un filtro XDR que traduce los elementos del arreglo, y size_of_element es el tamaño de cada elemento. Esta función devuelve uno si tiene éxito, cero en caso contrario.
bool_t xdr_bool(XDR *xdrs, bool_t *bp);
Un filtro primitivo que traduce entre valores booleanos C y su representación externa. Esta función devuelve uno si tiene éxito, cero en caso contrario.
bool_t xdr_bytes(XDR *xdrs, char **pp, unsigned int *lp, unsigned int maxsize);
Un filtro primitivo que traduce entre cadenas de bytes C y su representación externa. El argumento pp es la dirección del puntero a la cadena de bytes, lp es la dirección del tamaño de la cadena de bytes, y maxsize es el tamaño máximo permitido para la cadena de bytes. Esta función devuelve uno si tiene éxito, cero en caso contrario.
bool_t xdr_char(XDR *xdrs, char *cp);
Un filtro primitivo que traduce entre caracteres C y su representación externa. Esta función devuelve uno si tiene éxito, cero en caso contrario.
void xdr_destroy(XDR *xdrs);
Libera cualquier recurso asociado con el objeto XDR xdrs. Esta función se llama automáticamente cuando un programa cliente o servidor termina, pero también se puede llamar explícitamente.
bool_t xdr_double(XDR *xdrs, double *dp);
Un filtro primitivo que traduce entre números de punto flotante de doble precisión C y su representación externa. Esta función devuelve uno si tiene éxito, cero en caso contrario.
bool_t xdr_enum(XDR *xdrs, enum_t *ep);
Un filtro primitivo que traduce entre enumeraciones C y su representación externa. El argumento ep es la dirección de la enumeración. Esta función devuelve uno si tiene éxito, cero en caso contrario.
bool_t xdr_float(XDR *xdrs, float *fp);
Un filtro primitivo que traduce entre números de punto flotante de simple precisión C y su representación externa. Esta función devuelve uno si tiene éxito, cero en caso contrario.
void xdr_free(xdrproc_t proc, char *ptr);
Llama a la rutina de liberación de memoria (pasada como proc) para la estructura XDR en ptr. Esto se usa para liberar memoria que fue asignada por XDR durante la decodificación.
unsigned int xdr_getpos(XDR *xdrs);
Una macro que invoca la rutina de obtención de posición asociada con el flujo XDR xdrs. Devuelve la posición actual en el flujo XDR.
Advertencia: algunos tipos de flujos XDR no pueden reposicionarse, por lo que esta rutina puede fallar con un tipo de flujo y tener éxito con otro.
caddr_t xdr_inline(XDR *xdrs, unsigned int len);
Devuelve un puntero a un búfer de longitud len en el flujo XDR xdrs. Este búfer puede usarse para copiar datos directamente en el flujo XDR. Esto solo funciona para flujos XDR que admiten acceso en línea, como los flujos de memoria. Devuelve NULL si el acceso en línea no es posible.
bool_t xdr_int(XDR *xdrs, int *ip);
Un filtro primitivo que traduce entre enteros con signo C y su representación externa. Esta función devuelve uno si tiene éxito, cero en caso contrario.
bool_t xdr_long(XDR *xdrs, long *lp);
Un filtro primitivo que traduce entre enteros largos con signo C y su representación externa. Esta función devuelve uno si tiene éxito, cero en caso contrario.
void xdrmem_create(XDR *xdrs, const char *addr, unsigned int size, enum xdr_op op);
Inicializa el objeto de flujo XDR apuntado por xdrs para operar en un búfer de memoria. El búfer se especifica por addr y size. El argumento op determina la dirección del flujo XDR (ya sea XDR_ENCODE, XDR_DECODE o XDR_FREE).
bool_t xdr_opaque(XDR *xdrs, const char *cp, unsigned int size);
Un filtro primitivo que traduce entre bloques de datos opacos C y su representación externa. El argumento cp es la dirección de los datos, y size es el tamaño de los datos en bytes. Esta función devuelve uno si tiene éxito, cero en caso contrario.
bool_t xdr_pointer(XDR *xdrs, char **pp, unsigned int size, xdrproc_t proc);
Un filtro primitivo que maneja punteros. El argumento pp es la dirección del puntero, size es el tamaño de la estructura a la que apunta *pp y proc es un procedimiento XDR que filtra la estructura entre su forma C y su representación externa. Esta función devuelve uno si tiene éxito, cero en caso contrario. Es similar a xdr_reference pero maneja punteros nulos correctamente.
bool_t xdrrec_create(XDR *xdrs, unsigned int sendsize, unsigned int recsize, char *rdbuf,
                     char *wrbuf, int (*readfn)(char *, int), int (*writefn)(char *, int));
Inicializa el flujo XDR xdrs para la transmisión de registros basada en búferes. Los argumentos sendsize y recsize especifican los tamaños de los búferes de envío y recepción, respectivamente. Los argumentos rdbuf y wrbuf son punteros a los búferes de lectura y escritura. Los argumentos readfn y writefn son punteros a funciones personalizadas para leer y escribir datos desde/hacia los búferes. Si rdbuf es NULL, se asigna un búfer de lectura del tamaño recsize. Si wrbuf es NULL, se asigna un búfer de escritura del tamaño sendsize. Si readfn es NULL, se utiliza la función de lectura predeterminada para los flujos de memoria. Si writefn es NULL, se utiliza la función de escritura predeterminada para los flujos de memoria. Nota: Los flujos XDR creados con xdrrec_create() no son compatibles con los creados con xdrstdio_create() u otras funciones de creación de XDR, ya que utilizan un mecanismo de serialización diferente. Del mismo modo, los flujos XDR creados con diferentes APIs de xdr_*_create() no son compatibles por la misma razón.
bool_t xdrrec_endofrecord(XDR *xdrs, int sendnow);
Esta función solo se puede invocar en flujos creados con xdrrec_create(). Los datos en el búfer de salida se marcan como un registro completado, y el búfer de salida se escribe opcionalmente si sendnow es distinto de cero. Esta función devuelve uno si tiene éxito, cero en caso contrario.
bool_t xdrrec_eof(XDR *xdrs);
Esta función solo se puede invocar en flujos creados con xdrrec_create(). Después de consumir el resto del registro actual en el flujo, esta función devuelve uno si el flujo no tiene más entrada, cero en caso contrario.
bool_t xdrrec_skiprecord(XDR *xdrs);
Esta función solo se puede invocar en flujos creados con xdrrec_create(). Indica a la implementación XDR que el resto del registro actual en el búfer de entrada del flujo debe ser descartado. Esta función devuelve uno si tiene éxito, cero en caso contrario.
bool_t xdr_reference(XDR *xdrs, char **pp, unsigned int size,
                     xdrproc_t proc);
Un filtro primitivo que proporciona seguimiento de punteros dentro de estructuras. El argumento pp es la dirección del puntero; size es el sizeof de la estructura a la que apunta *pp; y proc es un procedimiento XDR que filtra la estructura entre su forma C y su representación externa. Esta función devuelve uno si tiene éxito, cero en caso contrario.
Advertencia: esta función no comprende los punteros nulos. Use xdr_pointer() en su lugar.
xdr_setpos(XDR *xdrs, unsigned int pos);
Una macro que invoca la rutina de establecimiento de posición asociada con el flujo XDR xdrs. El argumento pos es un valor de posición obtenido de xdr_getpos(). Esta rutina devuelve uno si el flujo XDR pudo ser reposicionado, y cero en caso contrario.
Advertencia: es difícil reposicionar algunos tipos de flujos XDR, por lo que esta rutina puede fallar con un tipo de flujo y tener éxito con otro.
bool_t xdr_short(XDR *xdrs, short *sp);
Un filtro primitivo que traduce entre enteros short de C y su representación externa. Esta función devuelve uno si tiene éxito, cero en caso contrario.
void xdrstdio_create(XDR *xdrs, FILE *file, enum xdr_op op);
Esta función inicializa el objeto de flujo XDR apuntado por xdrs. Los datos del flujo XDR se escriben o leen del flujo stdio file. El argumento op determina la dirección del flujo XDR (ya sea XDR_ENCODE, XDR_DECODE o XDR_FREE).
Advertencia: la rutina de destrucción asociada con dichos flujos XDR llama a fflush(3) en el flujo file, pero nunca a fclose(3).
bool_t xdr_string(XDR *xdrs, char **sp, unsigned int maxsize);
Un filtro primitivo que traduce entre cadenas C y sus correspondientes representaciones externas. Las cadenas no pueden tener una longitud mayor que maxsize. Nota: sp es la dirección del puntero de la cadena. Esta función devuelve uno si tiene éxito, cero en caso contrario.
bool_t xdr_u_char(XDR *xdrs, unsigned char *ucp);
Un filtro primitivo que traduce entre caracteres C unsigned y su representación externa. Esta función devuelve uno si tiene éxito, cero en caso contrario.
bool_t xdr_u_int(XDR *xdrs, unsigned int *up);
Un filtro primitivo que traduce entre enteros unsigned C y su representación externa. Esta función devuelve uno si tiene éxito, cero en caso contrario.
bool_t xdr_u_long(XDR *xdrs, unsigned long *ulp);
Un filtro primitivo que traduce entre enteros largos unsigned C y su representación externa. Esta función devuelve uno si tiene éxito, cero en caso contrario.
bool_t xdr_u_short(XDR *xdrs, unsigned short *usp);
Un filtro primitivo que traduce entre enteros unsigned short C y su representación externa. Esta función devuelve uno si tiene éxito, cero en caso contrario.
bool_t xdr_union(XDR *xdrs, enum_t *dscmp, char *unp,
                 const struct xdr_discrim *choices,
                 xdrproc_t defaultarm);     /* puede ser NULL */
Un filtro primitivo que traduce entre una union C discriminada y su representación externa correspondiente. Primero traduce el discriminante de la unión ubicado en dscmp. Este discriminante es siempre un enum_t. Luego se traduce la unión ubicada en unp. El argumento choices es un puntero a una matriz de estructuras xdr_discrim(). Cada estructura contiene un par ordenado de [valor,proc]. Si el discriminante de la unión es igual al valor asociado, entonces se llama a proc para traducir la unión. El final de la matriz de estructuras xdr_discrim() se indica con una rutina de valor NULL. Si el discriminante no se encuentra en la matriz choices, entonces se llama al procedimiento defaultarm (si no es NULL). Devuelve uno si tiene éxito, cero en caso contrario.
bool_t xdr_vector(XDR *xdrs, char *arrp, unsigned int size,
                  unsigned int elsize, xdrproc_t elproc);
Un filtro primitivo que traduce entre arreglos de longitud fija y su representación externa correspondiente. El argumento arrp es la dirección del puntero al arreglo, mientras que size es el conteo de elementos del arreglo. El argumento elsize es el sizeof de cada uno de los elementos del arreglo, y elproc es un filtro XDR que traduce entre la forma C de los elementos del arreglo y su representación externa. Esta función devuelve uno si tiene éxito, cero en caso contrario.
bool_t xdr_void(void);
Esta función siempre devuelve uno. Puede pasarse a rutinas RPC que requieran un argumento de función, donde no se debe hacer nada.
bool_t xdr_wrapstring(XDR *xdrs, char **sp);
Un primitivo que llama a xdr_string(xdrs, sp, MAXUN.UNSIGNED); donde MAXUN.UNSIGNED es el valor máximo de un entero sin signo. xdr_wrapstring() es útil porque el paquete RPC pasa un máximo de dos rutinas XDR como argumentos, y xdr_string(), uno de los primitivos más utilizados, requiere tres. Devuelve uno si tiene éxito, cero en caso contrario.
