XDELTA3(1) Manual de Comandos Generales XDELTA3(1)

NOMBRE

xdelta3 - Herramienta de diferencias binarias VCDIFF (RFC 3284)

SINOPSIS

xdelta3 [comando] [opciones] [entrada [salida]]

DESCRIPCIÓN

xdelta3 es una herramienta de diferencias binarias que utiliza el formato VCDIFF (RFC 3284) y compresión.

COMANDOS

config
imprime la configuración de xdelta3
decode
descomprime la entrada, también establecida por -d
encode
comprime la entrada, también establecida por -e (por defecto)
test
ejecuta las pruebas integradas
printdelta
imprime información sobre toda la diferencia
printhdr
imprime información sobre la primera ventana
printhdrs
imprime información sobre todas las ventanas
recode
codifica con nueva configuración de aplicación/secundaria

OPCIONES

opciones estándar:

-0 .. -9
nivel de compresión
-c
usa stdout
-d
descomprimir
-e
comprimir
-f
forzar sobrescritura
-h
mostrar ayuda
-q
silencioso
-v
verboso (máx 2)
-V
mostrar versión
opciones de memoria:
-B
tamaño de ventana de origen en bytes
-W
tamaño de ventana de entrada en bytes
-P
tamaño de duplicados de compresión de ventana
-I
tamaño del búfer de instrucciones (0 = ilimitado)
opciones de compresión:
-s
archivo fuente de origen para copiar (si lo hay)
-S [djw|fgk]
habilitar/deshabilitar compresión secundaria
-N
deshabilitar compresión de coincidencias de cadenas pequeñas
-D
deshabilitar descompresión externa (codificar/decodificar)
-R
deshabilitar recompresión externa (decodificar)
-n
deshabilitar checksum (codificar/decodificar)
-C
configuración suave (codificar, no documentado)
-A [cabecera_app]
deshabilitar/proporcionar cabecera de aplicación (codificar)
-J
deshabilitar salida (solo comprobar/calcular)
-T
usar tabla de códigos alternativa (prueba)

NOTAS

La variable de entorno XDELTA puede contener argumentos adicionales:

XDELTA="-s source-x.y.tar.gz" \
tar --use-compress-program=xdelta3 -cf \
target-x.z.tar.gz.vcdiff target-x.y/

EJEMPLOS

Comprime las diferencias entre SOURCE y TARGET, produciendo OUT, usando compresión secundaria "djw":

xdelta3 -S djw -s SOURCE TARGET OUT

Haz lo mismo, usando entrada y salida estándar:

xdelta3 -S djw -s SOURCE < TARGET > OUT

Para descomprimir OUT, usando SOURCE, produciendo TARGET:

xdelta3 -d -s SOURCE OUT TARGET
