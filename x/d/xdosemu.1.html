DOSEMU(1) Emulación de DOS DOSEMU(1)

NOMBRE

dosemu, xdosemu - ejecutar DOS y programas DOS bajo Linux

SINOPSIS

dosemu [ -dumb ] [ -quiet ] [ -input cadena-de-pulsaciones-de-tecla ] [ -s ] [ -install [ directorio-arranque ] ] [ argumentos ]

xdosemu [ -dumb ] [ -quiet ] [ -input cadena-de-pulsaciones-de-tecla ] [ -s ] [ -install [ directorio-arranque ] ] [ argumentos ]

DESCRIPCIÓN

dosemu es el script envoltorio para dosemu.bin (1) que invoca el emulador de DOS de Linux, también conocido como DOSEMU. El envoltorio también se encarga de (eventualmente) instalar la instancia privada de DOSEMU en el $HOME del usuario, si esta no existe.

OPCIONES

argumentos
cualquier número de opciones descritas en dosemu.bin (1), por favor consulte esta página del manual para más detalles. Sin embargo, tenga cuidado de citar y escapar correctamente para que bash no interfiera con los argumentos que contienen espacios y barras invertidas.
-dumb
usa el modo de terminal `dumb'. Esto solo funcionará para aplicaciones DOS que produzcan salida de texto plano a stdout, pero tiene la ventaja de que (A) la salida de la aplicación DOS se acumula en el búfer de desplazamiento de su xterm y (B) puede redirigirla a un archivo como
$ dosemu -dumb dir > listado

Tenga en cuenta que el editor/historial de línea de comandos de command.com de DOSEMU también funcionará aquí, sin embargo, la edición se restringe a retroceder con BACKSPACE.

-quiet
no imprima el comentario de inicio ni espere para preguntar
-input
Realiza pulsaciones de teclas simuladas según lo indicado por cadena-de-pulsaciones-de-tecla justo después de que DOS se inicie. Esto se puede usar para lanzar aplicaciones automáticamente, omitir menús de inicio necesarios o algo similar. Para detalles sobre el formato de la cadena, consulte README.txt.
-s
Invoca dosemu a través de sudo. Esto es necesario para acceder a ciertos puertos de E/S y para obtener gráficos en la consola de Linux. Por favor, consulte la documentación (INSTALL y README.txt) para ver qué archivos necesitan ser ajustados antes de intentar esto.
-install [ directorio-arranque ]
lanzado como parte de una instalación a nivel de sistema, esta opción (re)instala un DOS que se utiliza en DOSEMU (este puede ser el FreeDOS distribuido por DOSEMU o cualquier DOS propietario que se pueda arrancar a través de fatfs). directorio-arranque es el nombre base de un directorio. El enlace simbólico ~/.dosemu/drives/c se cambiará para que apunte a este directorio. La reinstalación rara vez es necesaria, ya que en la práctica los enlaces simbólicos apuntarán automáticamente a archivos actualizados.
--version
imprime la versión de dosemu y la lista de opciones disponibles.

AUTOR

DOSEMU (compuesto por los archivos dosemu.bin y dosemu) se basa en la versión 0.4 del programa original escrito por Matthias Lautner (ninguna dirección actual que yo sepa).

Robert Sanders <gt8134b@prism.gatech.edu> mantenía y mejoraba la encarnación de DOSEMU con la que se distribuyó originalmente esta página del manual. Durante aproximadamente 4 años, James B. MacLean <macleajb@ednet.ns.ca> fue el líder incansable del equipo de dosemu, la implementación de DPMI (que hizo funcionar Windows-3.1, dos4gw, djgpp, etc.) sucedió durante su 'gobierno' y llevó el proyecto cerca del estado Beta. Hans Lermen <lermen@fgan.de> se hizo cargo y lanzó la primera versión 1.0. Ahora Bart Oldeman <bart@dosemu.org> mantiene este divertido software.
