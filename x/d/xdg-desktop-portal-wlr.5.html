NOMBRE

xdg-desktop-portal-wlr - un backend de xdg-desktop-portal para compositores wlroots

DESCRIPCIÓN

xdg-desktop-portal-wlr (o xdpw para abreviar) permite a las aplicaciones solicitar capturas de pantalla y grabaciones de pantalla a través de xdg-desktop-portal en compositores Wayland basados en wlroots.

xdpw intentará cargar el archivo de configuración desde estas ubicaciones:

  • $XDG_CONFIG_HOME/xdg-desktop-portal-wlr/$XDG_CURRENT_DESKTOP
  • $XDG_CONFIG_HOME/xdg-desktop-portal-wlr/config
  • /etc/xdg/xdg-desktop-portal-wlr/$XDG_CURRENT_DESKTOP
  • /etc/xdg/xdg-desktop-portal-wlr/config

$XDG_CONFIG_HOME tiene como valor predeterminado ~/.config. $XDG_CURRENT_DESKTOP puede ser una lista separada por dos puntos. Se intentará cada elemento de esa lista.

Los archivos de configuración utilizan el formato de archivo INI. Ejemplo:

[screencast]
output_name=HDMI-A-1
max_fps=30
exec_before=disable_notifications.sh
exec_after=enable_notifications.sh
chooser_type=simple
chooser_cmd=slurp -f %o -or

OPCIONES DE GRABACIÓN DE PANTALLA

Estas opciones deben colocarse bajo la sección [screencast].

output_name = nombre

Selecciona qué salida se grabará en pantalla.

Esta opción se utiliza con chooser_type = none. La lista de salidas disponibles se puede obtener a través de wayland-info(1) (bajo la sección wl_output).

max_fps = límite

Limita el número de fotogramas por segundo a la tasa proporcionada.

Esto es útil para reducir el uso de CPU cuando la captura de fotogramas a la tasa de refresco de la salida no es necesaria.

exec_before = comando

Ejecuta comando antes de iniciar una grabación de pantalla. El comando se ejecutará dentro de sh.

exec_after = comando

Ejecuta comando después de finalizar todas las grabaciones de pantalla. El comando se ejecutará dentro de sh.

chooser_cmd = comando

Ejecuta este comando para seleccionar una salida.

Para más detalles, consulta SELECTOR_DE_SALIDA.

chooser_type = tipo

Especifica la entrada enviada al selector.

Los tipos compatibles son:

  • default: xdpw intentará usar el primer selector encontrado en la lista de selectores codificados (slurp, wmenu, wofi, rofi, bemenu) y recurrirá a una salida arbitraria si ninguno de estos se encontró.
  • none: xdpw permitirá la grabación de pantalla ya sea en la salida dada por output_name, o si está vacía, en una salida arbitraria sin más interacción.
  • simple, dmenu: xdpw ejecutará el selector dado por chooser_cmd. Para más detalles, consulta SELECTOR_DE_SALIDA.

force_mod_linear = bool

Forzar búferes con modificadores implícitos a ser lineales (experimental)

Establecer esta opción a 1 forzará a xdpw a asignar dma-bufs con modificador implícito como lineales. Esta opción no debería ser necesaria en configuraciones de GPU única, pero puede aumentar la compatibilidad, especialmente en configuraciones con múltiples GPUs.

Esta opción es experimental y puede ser eliminada o reemplazada en versiones futuras.

SELECTOR DE SALIDA

El selector puede ser cualquier programa o script con el siguiente comportamiento:

  • Devuelve cualquier código de error excepto 127. El código de error 127 se usa internamente para indicar que no se encontró ningún comando y toda la salida de él será ignorada.
  • Devuelve el nombre de una salida válida en stdout, tal como lo proporciona wayland-info(1). Cualquier otra cosa se manejará como un rechazo por parte del usuario.
  • Para indicar que el usuario ha rechazado la grabación de pantalla, el selector debe salir sin nada en stdout.

Tipos de selectores compatibles a través de la opción chooser_type:

  • simple: el selector simplemente se llama sin nada más en stdin.
  • dmenu: el selector recibe una lista de salidas separada por saltos de línea (estilo dmenu) en stdin.
