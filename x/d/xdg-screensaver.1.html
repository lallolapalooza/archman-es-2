XDG-SCREENSAVER(1) Manual de xdg-screensaver XDG-SCREENSAVER(1)

NOMBRE

xdg-screensaver - herramienta de línea de comandos para controlar el salvapantallas

SINOPSIS

xdg-screensaver suspend IDVentana

xdg-screensaver resume IDVentana

xdg-screensaver {activate | lock | reset | status}

xdg-screensaver {--help | --manual | --version}

DESCRIPCIÓN

xdg-screensaver proporciona comandos para controlar el salvapantallas.

xdg-screensaver es solo para uso dentro de una sesión de escritorio. No se recomienda usar xdg-screensaver como root.

COMANDOS

suspend IDVentana

Suspende el salvapantallas y la gestión de energía del monitor. IDVentana debe ser el ID de la Ventana X de una ventana existente de la aplicación que llama. La ventana debe permanecer en existencia durante la suspensión.

IDVentana puede representarse como un número decimal o como un número hexadecimal que consiste en el prefijo 0x seguido de uno o más dígitos hexadecimales.

El salvapantallas puede suspenderse en relación con múltiples ventanas al mismo tiempo. En ese caso, la operación del salvapantallas solo se restaura una vez que el salvapantallas se ha reanudado en relación con cada una de las ventanas.

resume IDVentana

Reanuda el salvapantallas y la gestión de energía del monitor después de haber sido suspendido. IDVentana debe ser el mismo ID de Ventana X que se pasó a una llamada anterior de xdg-screensaver suspend

activate

Enciende el salvapantallas inmediatamente. Esto puede resultar en el bloqueo de la pantalla, dependiendo de las políticas del sistema existentes.

lock

Bloquea la pantalla inmediatamente.

reset

Apaga el salvapantallas inmediatamente. Si la pantalla estaba bloqueada, es posible que se solicite al usuario que se autentique primero.

status

Imprime enabled en stdout si el salvapantallas está habilitado para activarse después de un período de inactividad, e imprime disabled si el salvapantallas no está habilitado.

OPCIONES

--help

Muestra el resumen de comandos.

--manual

Muestra esta página del manual.

--version

Muestra la información de la versión de xdg-utils.

CÓDIGOS DE SALIDA

Un código de salida de 0 indica éxito, mientras que un código de salida distinto de cero indica fallo. Los siguientes códigos de fallo pueden ser devueltos:

1

Error en la sintaxis de la línea de comandos.

3

No se pudo encontrar una herramienta requerida.

4

La acción falló.

EJEMPLOS

xdg-screensaver suspend 0x1c00007

Hace que el salvapantallas se desactive hasta que se llame a xdg-screensaver resume 0x1c00007. 0x1c00007 debe ser el ID de Ventana X de una ventana existente.
