xdr_wrapstring(3) Library Functions Manual xdr_wrapstring(3)

NAME

xdr_wrapstring - general-purpose string serialization routine

LIBRARY

Network RPC library (librpc, -lrpc)

SYNOPSIS AND DESCRIPTION

The XDR (external data representation) library provides routines for serializing C data structures into a machine-independent format, suitable for network transmission. The routines described here deal with strings.

The prototypes are declared in <rpc/xdr.h>.

bool_t xdr_wrapstring(XDR *xdrs, char **cpp);
This routine serializes a null-terminated C string. The argument cpp is the address of the pointer to the string. If the string is being encoded, the length of the string is first encoded as an unsigned integer, followed by the string's data. If the string is being decoded, the length is first decoded, then memory is allocated for the string, and finally the string's data is decoded into the allocated buffer. The caller is responsible for freeing the allocated memory for the decoded string. This routine returns one if it succeeds, zero otherwise.

The following routines are often used in conjunction with xdr_wrapstring():

bool_t xdr_string(XDR *xdrs, char **sp, unsigned int maxsize);
This routine is similar to xdr_wrapstring() but takes an additional argument, maxsize, which specifies the maximum allowed length of the string. If the string's length exceeds maxsize during encoding, or if the decoded string's length exceeds maxsize during decoding, the operation fails and returns zero. This provides a basic level of buffer overflow protection.
void xdr_free(xdrproc_t proc, char *objp);
This generic routine is used to free memory previously allocated by XDR decoding routines, such as xdr_wrapstring() or xdr_string(). The first argument, proc, is the XDR routine used for serialization (e.g., xdr_wrapstring), and the second argument, objp, is a pointer to the data structure (the string pointer in this case) to be freed. Note that the pointer itself is not freed, but the memory it points to is recursively freed.

RETURN VALUE

All XDR filter routines return 1 on success and 0 on failure.

bool_t xdrrec_endofrecord(XDR *xdrs, int sendnow);
Esta rutina solo se puede invocar en flujos creados por xdrrec_create(). Los datos en el búfer de salida se marcan como un registro completado, y el búfer de salida se escribe opcionalmente si sendnow es distinto de cero. Esta rutina devuelve uno si tiene éxito, cero en caso contrario.
bool_t xdrrec_eof(XDR *xdrs);
Esta rutina solo se puede invocar en flujos creados por xdrrec_create(). Después de consumir el resto del registro actual en el flujo, esta rutina devuelve uno si el flujo no tiene más entrada, cero en caso contrario.
bool_t xdrrec_skiprecord(XDR *xdrs);
Esta rutina solo se puede invocar en flujos creados por xdrrec_create(). Indica a la implementación XDR que el resto del registro actual en el búfer de entrada del flujo debe ser descartado. Esta rutina devuelve uno si tiene éxito, cero en caso contrario.
bool_t xdr_reference(XDR *xdrs, char **pp, unsigned int size,
                     xdrproc_t proc);
Un primitivo que proporciona seguimiento de punteros dentro de estructuras. El argumento pp es la dirección del puntero; size es el sizeof de la estructura a la que apunta *pp; y proc es un procedimiento XDR que filtra la estructura entre su forma C y su representación externa. Esta rutina devuelve uno si tiene éxito, cero en caso contrario.
Advertencia: esta rutina no entiende punteros nulos. Utilice xdr_pointer() en su lugar.
xdr_setpos(XDR *xdrs, unsigned int pos);
Una macro que invoca la rutina de establecer posición asociada con el flujo XDR xdrs. El argumento pos es un valor de posición obtenido de xdr_getpos(). Esta rutina devuelve uno si el flujo XDR pudo ser reposicionado, y cero en caso contrario.
Advertencia: es difícil reposicionar algunos tipos de flujos XDR, por lo que esta rutina puede fallar con un tipo de flujo y tener éxito con otro.
bool_t xdr_short(XDR *xdrs, short *sp);
Un primitivo de filtro que traduce entre enteros C short y sus representaciones externas. Esta rutina devuelve uno si tiene éxito, cero en caso contrario.
void xdrstdio_create(XDR *xdrs, FILE *file, enum xdr_op op);
Esta rutina inicializa el objeto de flujo XDR apuntado por xdrs. Los datos del flujo XDR se escriben o leen del flujo stdio file. El argumento op determina la dirección del flujo XDR (ya sea XDR_ENCODE, XDR_DECODE o XDR_FREE).
Advertencia: la rutina de destrucción asociada con dichos flujos XDR llama a fflush(3) en el flujo file, pero nunca a fclose(3).
bool_t xdr_string(XDR *xdrs, char **sp, unsigned int maxsize);
Un primitivo de filtro que traduce entre cadenas C y sus correspondientes representaciones externas. Las cadenas no pueden tener una longitud mayor que maxsize. Nota: sp es la dirección del puntero de la cadena. Esta rutina devuelve uno si tiene éxito, cero en caso contrario.
bool_t xdr_u_char(XDR *xdrs, unsigned char *ucp);
Un primitivo de filtro que traduce entre caracteres C unsigned y sus representaciones externas. Esta rutina devuelve uno si tiene éxito, cero en caso contrario.
bool_t xdr_u_int(XDR *xdrs, unsigned int *up);
Un primitivo de filtro que traduce entre enteros C unsigned y sus representaciones externas. Esta rutina devuelve uno si tiene éxito, cero en caso contrario.
bool_t xdr_u_long(XDR *xdrs, unsigned long *ulp);
Un primitivo de filtro que traduce entre enteros C unsigned long y sus representaciones externas. Esta rutina devuelve uno si tiene éxito, cero en caso contrario.
bool_t xdr_u_short(XDR *xdrs, unsigned short *usp);
Un primitivo de filtro que traduce entre enteros C unsigned short y sus representaciones externas. Esta rutina devuelve uno si tiene éxito, cero en caso contrario.
bool_t xdr_union(XDR *xdrs, enum_t *dscmp, char *unp,
                 const struct xdr_discrim *choices,
                 xdrproc_t defaultarm);     /* may equal NULL */
Un primitivo de filtro que traduce entre una union C discriminada y su representación externa correspondiente. Primero traduce el discriminante de la unión ubicado en dscmp. Este discriminante es siempre un enum_t. A continuación, se traduce la unión ubicada en unp. El argumento choices es un puntero a una matriz de estructuras xdr_discrim(). Cada estructura contiene un par ordenado de [valor,proc]. Si el discriminante de la unión es igual al valor asociado, se llama a proc para traducir la unión. El final de la matriz de estructuras xdr_discrim() se denota por un valor de procedimiento NULL. Si el discriminante no se encuentra en la matriz choices, se llama al procedimiento defaultarm (si no es NULL). Devuelve uno si tiene éxito, cero en caso contrario.
bool_t xdr_vector(XDR *xdrs, char *arrp, unsigned int size,
                  unsigned int elsize, xdrproc_t elproc);
Un primitivo de filtro que traduce entre matrices de longitud fija y sus representaciones externas correspondientes. El argumento arrp es la dirección del puntero a la matriz, mientras que size es el recuento de elementos de la matriz. El argumento elsize es el sizeof de cada uno de los elementos de la matriz, y elproc es un filtro XDR que traduce entre la forma C de los elementos de la matriz y su representación externa. Esta rutina devuelve uno si tiene éxito, cero en caso contrario.
bool_t xdr_void(void);
Esta rutina siempre devuelve uno. Se puede pasar a rutinas RPC que requieren un argumento de función, donde no se debe hacer nada.
bool_t xdr_wrapstring(XDR *xdrs, char **sp);
Un primitivo que llama a xdr_string(xdrs, sp,MAXUN.UNSIGNED ); donde MAXUN.UNSIGNED es el valor máximo de un entero sin signo. xdr_wrapstring() es útil porque el paquete RPC pasa un máximo de dos rutinas XDR como argumentos, y xdr_string(), uno de los primitivos más utilizados, requiere tres. Devuelve uno si tiene éxito, cero en caso contrario.
