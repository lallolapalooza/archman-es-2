NOMBRE

xdt-csource - utilidad de generación de código C para datos arbitrarios

SINOPSIS

xdt-csource [opciones] [archivo]

xdt-csource [opciones] --build-list [[nombre] [archivo]...]

DESCRIPCIÓN

xdt-csource es una pequeña utilidad que genera código C que contiene datos arbitrarios, útil para compilar textos u otros datos directamente en programas. Reemplaza a exo-csource.

INVOCACIÓN

xdt-csource toma como entrada el nombre de un archivo para generar código, o, usando la opción --build-list, una lista de pares (nombre, archivo) para generar código para una lista de imágenes en variables con nombre.

Opciones

-h, --help

Muestra ayuda breve y sale.

-V, --version

Muestra información de la versión y sale.

--extern

Genera símbolos externos.

--static

Genera símbolos estáticos (por defecto).

--name=identificador

Especifica el nombre del identificador (prefijo) para las variables generadas (solo se usa si no se especificó --build-list).

--build-list

Habilita el modo de análisis de pares (nombre, archivo).

--strip-comments

Elimina comentarios de archivos XML

--strip-content

Elimina el contenido de los nodos de archivos XML

--output=identificador

Imprime la salida en identificador en lugar de stdout (solo se usa si no se especificó --build-list).

VER TAMBIÉN

La utilidad gdk-pixbuf-csource que viene con la distribución Gtk+, disponible en www.gtk.org[1].

AUTOR

El programa original exo-csource fue escrito por Benedikt Meurer <benny@xfce.org>. xdt-csource lo reemplaza.
