xdp-monitor(8) Una herramienta simple de monitoreo XDP xdp-monitor(8)

NOMBRE

XDP-monitor - una herramienta simple de monitoreo XDP impulsada por BPF

SINOPSIS

XDP-monitor es una herramienta que monitorea varias estadísticas y eventos relacionados con XDP utilizando la infraestructura de puntos de rastreo de BPF, tratando de ser lo más liviana posible en cuanto a sobrecarga.

Tenga en cuenta que, por defecto, las estadísticas para eventos XDP de redirección exitosa están deshabilitadas, ya que esto genera una sobrecarga de rastreo de BPF por paquete, que si bien tiene baja sobrecarga, puede degradar el procesamiento de paquetes.

Esta herramienta se basa en la infraestructura de puntos de rastreo crudos de BPF en el kernel.

Hay más información sobre el significado de la salida tanto en el modo de salida predeterminado (conciso) como en el detallado, en la sección Descripción del Formato de Salida.

Ejecutar xdp-monitor

La sintaxis para ejecutar xdp-monitor es:

xdp-monitor [opciones]

Las opciones soportadas son:

-i, --intervalo <SEGUNDOS>

Establece el intervalo de sondeo para recopilar todas las estadísticas y mostrarlas en la salida. La unidad del intervalo está en segundos.

-s, --estadisticas

Habilita las estadísticas para la redirección exitosa. Esta opción conlleva una sobrecarga de rastreo por paquete, para registrar todas las redirecciones exitosas.

-e, --extendido

Inicia xdp-bench en modo de salida "extendido". Si no está establecido, xdp-bench iniciará en modo "conciso". El modo de salida se puede cambiar presionando C-$ mientras el programa se está ejecutando. Consulte también la sección Descripción del Formato de Salida a continuación.

-v, --detallado

Habilita el registro detallado. Suministre dos veces para habilitar el registro detallado de las bibliotecas subyacentes libxdp y libbpf.

--version

Muestra la versión de la aplicación y sale.

-h, --ayuda

Muestra un resumen de las opciones disponibles

Descripción del Formato de Salida

Por defecto, las estadísticas de éxito de redirección están deshabilitadas; use --estadisticas para habilitarlas. El modo de salida conciso es el predeterminado; el modo de salida extendido se puede activar usando la opción de línea de comandos --extendido.

SIGQUIT (Ctrl + \) se puede usar para cambiar el modo dinámicamente en tiempo de ejecución.

El modo conciso muestra como máximo los siguientes campos:

rx/s		Número de paquetes recibidos por segundo
redir/s	Número de paquetes redirigidos exitosamente por segundo
err,drop/s	Conteo agregado de errores por segundo (incluyendo paquetes descartados)
xmit/s	Número de paquetes transmitidos en el dispositivo de salida por segundo

El modo de salida detallado muestra como máximo los siguientes campos:

CAMPO		  DESCRIPCIÓN
receive	       Muestra el número de paquetes recibidos y los errores encontrados
                        Cada vez que ocurre un error o descarte de paquete, los detalles de los errores por CPU
                        y las estadísticas de descarte se expandirán en línea en modo conciso.
                                        pkt/s		- Paquetes recibidos por segundo
                                        drop/s		- Paquetes descartados por segundo
                                        error/s		- Errores encontrados por segundo
                                        redirect	- Muestra el número de paquetes redirigidos exitosamente
                       Los errores encontrados se expanden en el campo redirect_err
                       Tenga en cuenta que pasar -s para habilitarlo tiene una sobrecarga por paquete
                                        redir/s		- Paquetes redirigidos exitosamente por segundo
redirect_err	  Muestra el número de paquetes que fallaron la redirección
                        El errno se expande en este campo con el conteo por CPU
                       Los errores reconocidos son:
                                        EINVAL:		Redirección inválida
                                        ENETDOWN:	Dispositivo al que se redirige está caído
                                        EMSGSIZE:	Tamaño de paquete demasiado grande para el dispositivo
                                        EOPNOTSUPP:	Operación no soportada
                                        ENOSPC:		No hay espacio en el ptr_ring del hilo kthread cpumap
                                        error/s		- Paquetes que fallaron la redirección por segundo
enqueue to cpu N Muestra el número de paquetes encolados en la cola masiva de la CPU N
                       Se expande a cpu:FROM->N para mostrar estadísticas de encolamiento para cada CPU que encola a la CPU N
                       Los paquetes recibidos se pueden asociar con la CPU a la que el programa XDP está encolando
                       paquetes.
                                        pkt/s		- Paquetes encolados por segundo desde otra CPU a la CPU N
                                        drop/s		- Paquetes descartados al intentar encolar a la CPU N
                                        bulk-avg	- Número promedio de paquetes procesados para cada evento
kthread	       Muestra el número de paquetes procesados en el hilo kthread CPUMAP para cada CPU
                       Los paquetes consumidos del ptr_ring en el hilo kthread, y sus xdp_stats (después de llamar
                       al programa bpf CPUMAP) se expanden debajo de esto. Los xdp_stats se expanden como un total y
                       luego por CPU para asociarlo con el hilo kthread CPUMAP de cada CPU.
                                        pkt/s		- Paquetes consumidos por segundo del ptr_ring
                                        drop/s		- Paquetes descartados por segundo en el hilo kthread
                                        sched		- Número de veces que el hilo kthread llamó a schedule()
                       xdp_stats (también se expande a conteos por CPU)
                                        pass/s		- Conteo XDP_PASS para la ejecución del programa CPUMAP
                                        drop/s		- Conteo XDP_DROP para la ejecución del programa CPUMAP
                                        redir/s		- Conteo XDP_REDIRECT para la ejecución del programa CPUMAP
xdp_exception	  Muestra eventos de puntos de rastreo xdp_exception
                        Esto puede ocurrir debido a errores internos del controlador,
                       acciones XDP no reconocidas y debido a la activación explícita por el usuario mediante el uso de XDP_ABORTED
                       Cada acción se expande debajo de este campo con su conteo
                                        hit/s		- Número de veces que se activó el punto de rastreo por segundo
devmap_xmit      Muestra eventos de puntos de rastreo devmap_xmit
                        Este punto de rastreo se invoca para transmisiones exitosas en el dispositivo de salida
                       pero estas estadísticas no están disponibles para el modo XDP genérico,
                       por lo tanto, se omitirán de la salida cuando se utilice el modo SKB
                                        xmit/s		- Número de paquetes que se transmitieron por segundo
                                        drop/s		- Número de paquetes que fallaron la transmisión por segundo
                                        drv_err/s	- Número de errores internos del controlador por segundo
                                        bulk-avg	- Número promedio de paquetes procesados para cada evento
