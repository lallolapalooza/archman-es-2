xdr(3) Manual de funciones de biblioteca xdr(3)

NOMBRE

xdr — rutinas de biblioteca para la representación externa de datos

BIBLIOTECA

Biblioteca C estándar (libc, -lc)

SINOPSIS Y DESCRIPCIÓN

Estas rutinas permiten a los programadores C describir estructuras de datos arbitrarias de forma independiente de la máquina. Los datos para las llamadas a procedimientos remotos se transmiten utilizando estas rutinas.

Los prototipos a continuación se declaran en <rpc/xdr.h> y hacen uso de los siguientes tipos:

typedef int bool_t;
typedef typeof(bool_t (XDR *, void *, ...))  *xdrproc_t;

Para la declaración del tipo XDR, véase <rpc/xdr.h>.

bool_t xdr_array(XDR *xdrs, char **arrp, unsigned int *sizep,
                 unsigned int maxsize, unsigned int elsize,
                 xdrproc_t elproc);
Un filtro primitivo que traduce entre arrays de longitud variable y sus representaciones externas correspondientes. El argumento arrp es la dirección del puntero al array, mientras que sizep es la dirección del contador de elementos del array; este contador de elementos no puede superar maxsize. El argumento elsize es el sizeof de cada uno de los elementos del array, y elproc es un filtro XDR que traduce entre la forma C de los elementos del array y su representación externa. Esta rutina devuelve uno si tiene éxito, cero en caso contrario.
bool_t xdr_bool(XDR *xdrs, bool_t *bp);
Un filtro primitivo que traduce entre booleanos (enteros C) y sus representaciones externas. Al codificar datos, este filtro produce valores de uno o cero. Esta rutina devuelve uno si tiene éxito, cero en caso contrario.
bool_t xdr_bytes(XDR *xdrs, char **sp, unsigned int *sizep,
                 unsigned int maxsize);
Un filtro primitivo que traduce entre cadenas de bytes contadas y sus representaciones externas. El argumento sp es la dirección del puntero a la cadena. La longitud de la cadena se encuentra en la dirección sizep; las cadenas no pueden tener más de maxsize. Esta rutina devuelve uno si tiene éxito, cero en caso contrario.
bool_t xdr_char(XDR *xdrs, char *cp);
Un filtro primitivo que traduce entre caracteres C y sus representaciones externas. Esta rutina devuelve uno si tiene éxito, cero en caso contrario. Nota: los caracteres codificados no están empaquetados y ocupan 4 bytes cada uno. Para arrays de caracteres, merece la pena considerar xdr_bytes(), xdr_opaque() o xdr_string().
void xdr_destroy(XDR *xdrs);
Una macro que invoca la rutina de destrucción asociada al stream XDR, xdrs. La destrucción generalmente implica liberar estructuras de datos privadas asociadas al stream. El uso de xdrs después de invocar xdr_destroy() no está definido.
bool_t xdr_double(XDR *xdrs, double *dp);
Un filtro primitivo que traduce entre números C de precisión double y sus representaciones externas. Esta rutina devuelve uno si tiene éxito, cero en caso contrario.
bool_t xdr_enum(XDR *xdrs, enum_t *ep);
Un filtro primitivo que traduce entre enums C (en realidad, enteros) y sus representaciones externas. Esta rutina devuelve uno si tiene éxito, cero en caso contrario.
bool_t xdr_float(XDR *xdrs, float *fp);
Un filtro primitivo que traduce entre floats C y sus representaciones externas. Esta rutina devuelve uno si tiene éxito, cero en caso contrario.
void xdr_free(xdrproc_t proc, char *objp);
Rutina genérica de liberación. El primer argumento es la rutina XDR para el objeto que se está liberando. El segundo argumento es un puntero al objeto mismo. Nota: el puntero pasado a esta rutina *no* se libera, pero lo que apunta *sí* se libera (recursivamente).
unsigned int xdr_getpos(XDR *xdrs);
Una macro que invoca la rutina de obtención de posición asociada al stream XDR, xdrs. La rutina devuelve un entero sin signo, que indica la posición del stream de bytes XDR. Una característica deseable de los streams XDR es que la aritmética simple funciona con este número, aunque las instancias de stream XDR no necesiten garantizar esto.
long *xdr_inline(XDR *xdrs, int len);
Una macro que invoca la rutina inline asociada al stream XDR, xdrs. La rutina devuelve un puntero a un trozo contiguo del buffer del stream; len es la longitud en bytes del buffer deseado. Nota: el puntero se convierte a long *.
Advertencia: xdr_inline() puede devolver NULL (0) si no puede asignar un trozo contiguo de un buffer. Por lo tanto, el comportamiento puede variar entre las instancias de stream; existe por razones de eficiencia.
bool_t xdr_int(XDR *xdrs, int *ip);
Un filtro primitivo que traduce entre enteros C y sus representaciones externas. Esta rutina devuelve uno si tiene éxito, cero en caso contrario.
bool_t xdr_long(XDR *xdrs, long *lp);
Un filtro primitivo que traduce entre enteros C long y sus representaciones externas. Esta rutina devuelve uno si tiene éxito, cero en caso contrario.
void xdrmem_create(XDR *xdrs, char *addr, unsigned int size,
                   enum xdr_op op);
Esta rutina inicializa el objeto de stream XDR apuntado por xdrs. Los datos del stream se escriben o leen de un bloque de memoria en la ubicación addr cuya longitud no supera los size bytes. El op determina la dirección del stream XDR (ya sea XDR_ENCODE, XDR_DECODE o XDR_FREE).
bool_t xdr_opaque(XDR *xdrs, char *cp, unsigned int cnt);
Un filtro primitivo que traduce entre datos opacos de tamaño fijo y su representación externa. El argumento cp es la dirección del objeto opaco, y cnt es su tamaño en bytes. Esta rutina devuelve uno si tiene éxito, cero en caso contrario.
bool_t xdr_pointer(XDR *xdrs, char **objpp,
                   unsigned int objsize, xdrproc_t xdrobj);
Similar a xdr_reference() excepto en que serializa punteros nulos, mientras que xdr_reference() no lo hace. Por lo tanto, xdr_pointer() puede representar estructuras de datos recursivas, como árboles binarios o listas enlazadas.
void xdrrec_create(XDR *xdrs, unsigned int sendsize,
                   unsigned int recvsize, char *handle,
                   typeof(int (char *, char *, int)) *readit,
                   typeof(int (char *, char *, int)) *writeit);
Esta rutina inicializa el objeto de stream XDR apuntado por xdrs. Los datos del stream se escriben en un buffer de tamaño sendsize; un valor de cero indica que el sistema debe usar un valor predeterminado adecuado. Los datos del stream se leen de un buffer de tamaño recvsize; este también se puede establecer a un valor predeterminado adecuado pasando un valor cero. Cuando el buffer de salida de un stream está lleno, se llama a writeit. De manera similar, cuando el buffer de entrada de un stream está vacío, se llama a readit. El comportamiento de estas dos rutinas es similar a las llamadas al sistema read(2) y write(2), excepto en que handle se pasa a las rutinas anteriores como primer argumento. Nota: el campo op del stream XDR debe ser establecido por el llamador.
Advertencia: para leer de un stream XDR creado por esta API, necesitará llamar a xdrrec_skiprecord() primero antes de llamar a cualquier otra API XDR. Esto inserta bytes adicionales en el stream para proporcionar límites de registro
bool_t xdrrec_endofrecord(XDR *xdrs, bool_t send إ);
Esta rutina se utiliza para indicar el final de un registro. Si send es verdadero, se escribirán bytes de relleno y un byte nulo al final del registro. Si send es falso, solo se leerán bytes de relleno.
bool_t xdrrec_skiprecord(XDR *xdrs);
Esta rutina se utiliza para saltarse el resto del registro actual y posicionarse al principio del siguiente registro. Esto es útil cuando se lee del stream y el tamaño del registro no se conoce de antemano.
bool_t xdr_reference(XDR *xdrs, char **pp, unsigned int size,
                     xdrproc_t proc);
Este es un filtro primitivo que opera sobre punteros. El argumento pp es la dirección de un puntero al objeto que se va a serializar o deserializar. El argumento size es el tamaño del objeto, y el argumento proc es la rutina XDR para serializar o deserializar el objeto. Esta rutina funciona de forma similar a xdr_pointer() pero no serializa punteros nulos.
bool_t xdr_rejected_reply(XDR *xdrs, struct rpc_err *error_recv);
Esta rutina deserializa una respuesta rechazada de RPC. El argumento error_recv es un puntero a una estructura rpc_err donde se almacenará la información del error.
bool_t xdr_replymsg(XDR *xdrs, struct reply_msg *rmsg);
Esta rutina serializa o deserializa un mensaje de respuesta de RPC. El argumento rmsg es un puntero a una estructura reply_msg que contiene el mensaje de respuesta.
bool_t xdr_setpos(XDR *xdrs, unsigned int pos);
Una macro que invoca la rutina de establecimiento de posición asociada al stream XDR, xdrs. La rutina establece la posición del stream de bytes XDR a pos. La posición debe ser una obtenida previamente mediante una llamada a xdr_getpos().
bool_t xdr_string(XDR *xdrs, char **sp, unsigned int maxsize);
Un filtro primitivo que traduce entre cadenas de caracteres terminadas en nulo y su representación externa. El argumento sp es la dirección del puntero a la cadena. La longitud de la cadena no puede superar maxsize. Esta rutina devuelve uno si tiene éxito, cero en caso contrario.
bool_t xdr_u_int32_t(XDR *xdrs, uint32_t *uip);
Un filtro primitivo que traduce entre enteros C de 32 bits sin signo (uint32_t) y sus representaciones externas. Esta rutina devuelve uno si tiene éxito, cero en caso contrario.
bool_t xdr_u_long(XDR *xdrs, unsigned long *ulp);
Un filtro primitivo que traduce entre enteros C sin signo long y sus representaciones externas. Esta rutina devuelve uno si tiene éxito, cero en caso contrario.
bool_t xdr_u_longlong_t(XDR *xdrs, ulonglong_t *ullp);
Un filtro primitivo que traduce entre enteros C sin signo de 64 bits (ulonglong_t) y sus representaciones externas. Esta rutina devuelve uno si tiene éxito, cero en caso contrario.
bool_t xdr_uint(XDR *xdrs, unsigned int *up);
Un filtro primitivo que traduce entre enteros C sin signo y sus representaciones externas. Esta rutina devuelve uno si tiene éxito, cero en caso contrario.
bool_t xdr_union(XDR *xdrs, enum_t *dest, char * ,
                 const struct xdr_discrim *choices,
                 typeof(bool_t (XDR *, void *, enum_t)) *defaultgo);
Un filtro primitivo que traduce entre uniones C y sus representaciones externas. El argumento dest es la dirección del discriminador de la unión. El tercer argumento es un puntero al espacio de unión. El argumento choices es una tabla de discriminadores y las rutinas XDR correspondientes. El argumento defaultgo es una rutina opcional que se llama si el discriminador no se encuentra en la tabla de elecciones.
bool_t xdr_vector(XDR *xdrs, char *arr, unsigned int length,
                  unsigned int elsize, xdrproc_t elproc);
Un filtro primitivo que traduce entre arrays de longitud fija y sus representaciones externas correspondientes. El argumento arr es la dirección del array, mientras que length es el número de elementos en el array. El argumento elsize es el sizeof de cada uno de los elementos del array, y elproc es un filtro XDR que traduce entre los elementos del array en forma C y su representación externa. Esta rutina devuelve uno si tiene éxito, cero en caso contrario.
bool_t xdr_wrapstring(XDR *xdrs, char **sp);
Similar a xdr_string() pero asume que la cadena está delimitada por un marcador de fin de registro XDR. Esto es útil para transmitir cadenas largas que pueden abarcar varios registros.
bool_t xdr_sizeof(xdrproc_t proc, void *data);
Devuelve el tamaño de la representación externa de los datos especificados por proc y data. Esto es útil para preasignar búferes para operaciones XDR.
bool_t xdr_int16_t(XDR *xdrs, int16_t *ip);
Un filtro primitivo que traduce entre enteros C de 16 bits (int16_t) y sus representaciones externas. Esta rutina devuelve uno si tiene éxito, cero en caso contrario.
bool_t xdr_u_int16_t(XDR *xdrs, uint16_t *uip);
Un filtro primitivo que traduce entre enteros C de 16 bits sin signo (uint16_t) y sus representaciones externas. Esta rutina devuelve uno si tiene éxito, cero en caso contrario.
bool_t xdr_int32_t(XDR *xdrs, int32_t *ip);
Un filtro primitivo que traduce entre enteros C de 32 bits (int32_t) y sus representaciones externas. Esta rutina devuelve uno si tiene éxito, cero en caso contrario.
bool_t xdr_int64_t(XDR *xdrs, int64_t *ip);
Un filtro primitivo que traduce entre enteros C de 64 bits (int64_t) y sus representaciones externas. Esta rutina devuelve uno si tiene éxito, cero en caso contrario.
bool_t xdr_uint64_t(XDR *xdrs, uint64_t *uip);
Un filtro primitivo que traduce entre enteros C de 64 bits sin signo (uint64_t) y sus representaciones externas. Esta rutina devuelve uno si tiene éxito, cero en caso contrario.
bool_t xdr_hyper(XDR *xdrs, long long *llp);
Un filtro primitivo que traduce entre enteros C long long y sus representaciones externas. Esta rutina devuelve uno si tiene éxito, cero en caso contrario.
bool_t xdr_longlong_t(XDR *xdrs, long long *llp);
Alias para xdr_hyper().
bool_t xdr_quadruple(XDR *xdrs, long double *ldp);
Un filtro primitivo que traduce entre números C de precisión long double y sus representaciones externas. Esta rutina devuelve uno si tiene éxito, cero en caso contrario.

La rutina xdr_opaque_auth() se utiliza para serializar o deserializar la información de autenticación de RPC.

bool_t xdr_opaque_auth(XDR *xdrs, struct opaque_auth *ap);
La rutina xdr_opaque_auth() se utiliza para serializar o deserializar la información de autenticación de RPC. El argumento ap es un puntero a una estructura opaque_auth que contiene la información de autenticación.
bool_t xdr_authsys_parms(XDR *xdrs, struct authsys_parms *p);
Esta rutina serializa o deserializa parámetros de autenticación del sistema. El argumento p es un puntero a una estructura authsys_parms que contiene los parámetros.
bool_t xdr_authdes_parms(XDR *xdrs, struct authdes_parms *p);
Esta rutina serializa o deserializa parámetros de autenticación de DES. El argumento p es un puntero a una estructura authdes_parms que contiene los parámetros.
bool_t xdr_callmsg(XDR *xdrs, struct call_msg *cmsg);
Esta rutina serializa o deserializa un mensaje de llamada de RPC. El argumento cmsg es un puntero a una estructura call_msg que contiene el mensaje de llamada.
bool_t xdr_callhdr(XDR *xdrs, struct call_header *chdr);
Esta rutina serializa o deserializa la cabecera de un mensaje de llamada de RPC. El argumento chdr es un puntero a una estructura call_header que contiene la cabecera.
bool_t xdr_rm_xid(XDR *xdrs);
Esta rutina lee un ID de transacción (xid) de un stream XDR.
