NOMBRE

xdg-user-dirs-update - Actualiza la configuración de directorios de usuario XDG

SINOPSIS

xdg-user-dirs-update [OPCIÓN...] [--set NOMBRE RUTA...]

DESCRIPCIÓN

xdg-user-dirs-update actualiza el estado actual de los directorios de usuario de los usuarios. Si no existían previamente, se creará uno basado en los valores predeterminados del sistema, o se recurrirá a los nombres de archivo antiguos no traducidos si existen dichos directorios. La lista de directorios antiguos utilizados es: ~/Escritorio, ~/Plantillas y ~/Público.

Si existe una configuración antigua, se actualiza con cualquier directorio predeterminado nuevo. Además, cualquier directorio configurado que apunte a ubicaciones inexistentes se restablece, apuntándolos al directorio de inicio del usuario. Esto suele ocurrir cuando el usuario elimina el directorio, por lo que es probable que ya no quiera usarlo.

En la primera ejecución, se crea un archivo user-dirs.locale que contiene la configuración regional que se utilizó para la traducción. Esto lo utilizan posteriormente herramientas gráficas como xdg-user-dirs-gtk-update para detectar si la configuración regional ha cambiado, lo que le permite migrar de los nombres antiguos.

xdg-user-dirs-update se ejecuta normalmente de forma automática al inicio de una sesión de usuario para actualizar los directorios de usuario XDG de acuerdo con la configuración regional del usuario.

OPCIONES

Se entienden las siguientes opciones:

--help

Muestra la ayuda y sale.

--force

Actualiza el archivo user-dirs.dirs existente, pero fuerza un reinicio completo. Esto significa: no restablecer los directorios inexistentes a HOME, sino recrear el directorio. Nunca usar nombres antiguos compatibles con versiones anteriores no traducidas. Siempre recrear user-dirs.locale.

--dummy-output RUTA

Escribe la configuración en RUTA en lugar del archivo de configuración predeterminado. Además, no se crean directorios.

--set NOMBRE RUTA

Establece el directorio de usuario XDG con el nombre dado.

NOMBRE debe ser uno de los siguientes:

ESCRITORIO
DESCARGAS
PLANTILLAS
COMPARTIRPÚBLICO
DOCUMENTOS
MÚSICA
IMÁGENES
VIDEOS

RUTA debe ser una ruta absoluta, por ejemplo, $HOME/Algún/Directorio.

ARCHIVOS

La configuración de directorios de usuario XDG se almacena en el archivo user-dirs.dirs en la ubicación indicada por la variable de entorno XDG_CONFIG_HOME.

ENTORNO

La variable de entorno XDG_CONFIG_HOME determina dónde se encuentra el archivo user-dirs.dirs.

VER TAMBIÉN

xdg-user-dir(1), user-dirs.dirs(5), user-dirs.defaults(5), user-dirs.conf(5).
