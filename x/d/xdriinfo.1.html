NOMBRE

xdriinfo - consultar información de configuración de los controladores DRI

SINOPSIS

xdriinfo [-display nombredisplay] [-help|-version] [comando]

DESCRIPCIÓN

xdriinfo se puede usar para consultar información de configuración de los controladores de renderizado directo (DRI). Si no se especifica ningún argumento de comando, lista los nombres de los controladores de renderizado directo para todas las pantallas.

Las opciones válidas son:

-display
Especifica el servidor X al que conectarse.
-help
Imprime el uso del programa y sale.
-version
Imprime la versión del programa y sale.

Los comandos válidos son:

nscreens
Imprime el número de pantallas.
driver pantalla
Imprime el nombre del controlador de renderizado directo para pantalla.
options pantalla|driver
Imprime el documento XML que describe las opciones de configuración de un controlador. El controlador se puede especificar directamente por su nombre de driver o indirectamente por el número de pantalla. Si el nombre del controlador se especifica directamente, no se necesita conexión X.

AMBIENTE

DISPLAY
La pantalla predeterminada.

VER TAMBIÉN

X(7), xdpyinfo(1), xwininfo(1), xvinfo(1), glxinfo(1), xprop(1)
