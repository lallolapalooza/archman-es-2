xdr(3) Manual de funciones de biblioteca xdr(3)

NOMBRE

xdr — rutinas de biblioteca para la representación externa de datos

BIBLIOTECA

Biblioteca C estándar (libc, -lc)

SINOPSIS Y DESCRIPCIÓN

Estas rutinas permiten a los programadores de C describir estructuras de datos arbitrarias de forma independiente de la máquina. Los datos para las llamadas a procedimientos remotos se transmiten utilizando estas rutinas.

Los prototipos a continuación se declaran en <rpc/xdr.h> y hacen uso de los siguientes tipos:

typedef int bool_t;
typedef typeof(bool_t (XDR *, void *, ...))  *xdrproc_t;

Para la declaración del tipo XDR, consulte <rpc/xdr.h>.

bool_t xdr_array(XDR *xdrs, char **arrp, unsigned int *sizep,
                 unsigned int maxsize, unsigned int elsize,
                 xdrproc_t elproc);
Una primitiva de filtro que traduce entre arreglos de longitud variable y sus representaciones externas correspondientes. El argumento arrp es la dirección del puntero al arreglo, mientras que sizep es la dirección del contador de elementos del arreglo; este contador de elementos no puede exceder maxsize. El argumento elsize es el tamaño (sizeof) de cada uno de los elementos del arreglo, y elproc es un filtro XDR que traduce entre la forma C de los elementos del arreglo y su representación externa. Esta rutina devuelve uno si tiene éxito, cero en caso contrario.
bool_t xdr_bool(XDR *xdrs, bool_t *bp);
Una primitiva de filtro que traduce entre booleanos (enteros C) y sus representaciones externas. Al codificar datos, este filtro produce valores de uno o cero. Esta rutina devuelve uno si tiene éxito, cero en caso contrario.
bool_t xdr_bytes(XDR *xdrs, char **sp, unsigned int *sizep,
                 unsigned int maxsize);
Una primitiva de filtro que traduce entre cadenas de bytes contadas y sus representaciones externas. El argumento sp es la dirección del puntero de la cadena. La longitud de la cadena se encuentra en la dirección sizep; las cadenas no pueden ser más largas que maxsize. Esta rutina devuelve uno si tiene éxito, cero en caso contrario.
bool_t xdr_char(XDR *xdrs, char *cp);
Una primitiva de filtro que traduce entre caracteres C y sus representaciones externas. Esta rutina devuelve uno si tiene éxito, cero en caso contrario. Nota: los caracteres codificados no se empaquetan y ocupan 4 bytes cada uno. Para arreglos de caracteres, vale la pena considerar xdr_bytes(), xdr_opaque() o xdr_string().
void xdr_destroy(XDR *xdrs);
Una macro que invoca la rutina de destrucción asociada con el flujo XDR, xdrs. La destrucción generalmente implica la liberación de estructuras de datos privadas asociadas con el flujo. Usar xdrs después de invocar xdr_destroy() no está definido.
bool_t xdr_double(XDR *xdrs, double *dp);
Una primitiva de filtro que traduce entre números de doble precisión C y sus representaciones externas. Esta rutina devuelve uno si tiene éxito, cero en caso contrario.
bool_t xdr_enum(XDR *xdrs, enum_t *ep);
Una primitiva de filtro que traduce entre enumeraciones C (en realidad, enteros) y sus representaciones externas. Esta rutina devuelve uno si tiene éxito, cero en caso contrario.
bool_t xdr_float(XDR *xdrs, float *fp);
Una primitiva de filtro que traduce entre flotantes C y sus representaciones externas. Esta rutina devuelve uno si tiene éxito, cero en caso contrario.
void xdr_free(xdrproc_t proc, char *objp);
Rutina genérica de liberación. El primer argumento es la rutina XDR para el objeto que se está liberando. El segundo argumento es un puntero al objeto en sí. Nota: el puntero pasado a esta rutina no se libera, pero lo que apunta sí se libera (recursivamente).
unsigned int xdr_getpos(XDR *xdrs);
Una macro que invoca la rutina de obtención de posición asociada con el flujo XDR, xdrs. La rutina devuelve un entero sin signo, que indica la posición del flujo de bytes XDR. Una característica deseable de los flujos XDR es que la aritmética simple funciona con este número, aunque las instancias de flujo XDR no necesitan garantizar esto.
long *xdr_inline(XDR *xdrs, int len);
Una macro que invoca la rutina en línea asociada con el flujo XDR, xdrs. La rutina devuelve un puntero a una pieza contigua del búfer del flujo; len es la longitud en bytes del búfer deseado. Nota: el puntero se convierte a long *.
Advertencia: xdr_inline() puede devolver NULL (0) si no puede asignar una pieza contigua de un búfer. Por lo tanto, el comportamiento puede variar entre instancias de flujo; existe por motivos de eficiencia.
bool_t xdr_int(XDR *xdrs, int *ip);
Una primitiva de filtro que traduce entre enteros C y sus representaciones externas. Esta rutina devuelve uno si tiene éxito, cero en caso contrario.
bool_t xdr_long(XDR *xdrs, long *lp);
Una primitiva de filtro que traduce entre enteros largos C y sus representaciones externas. Esta rutina devuelve uno si tiene éxito, cero en caso contrario.
void xdrmem_create(XDR *xdrs, char *addr, unsigned int size,
                   enum xdr_op op);
Esta rutina inicializa el objeto de flujo XDR apuntado por xdrs. Los datos del flujo se escriben o se leen de un bloque de memoria en la ubicación addr cuya longitud no supera los size bytes. El parámetro op determina la dirección del flujo XDR (ya sea XDR_ENCODE, XDR_DECODE o XDR_FREE).
bool_t xdr_opaque(XDR *xdrs, char *cp, unsigned int cnt);
Una primitiva de filtro que traduce entre datos opacos de tamaño fijo y su representación externa. El argumento cp es la dirección del objeto opaco y cnt es su tamaño en bytes. Esta rutina devuelve uno si tiene éxito, cero en caso contrario.
bool_t xdr_pointer(XDR *xdrs, char **objpp,
                   unsigned int objsize, xdrproc_t xdrobj);
Similar a xdr_reference() excepto que serializa punteros nulos, mientras que xdr_reference() no lo hace. Por lo tanto, xdr_pointer() puede representar estructuras de datos recursivas, como árboles binarios o listas enlazadas.
void xdrrec_create(XDR *xdrs, unsigned int sendsize,
                   unsigned int recvsize, char *handle,
                   typeof(int (char *, char *, int)) *readit,
                   typeof(int (char *, char *, int)) *writeit);
Esta rutina inicializa el objeto de flujo XDR apuntado por xdrs. Los datos del flujo se escriben en un búfer de tamaño sendsize; un valor de cero indica que el sistema debe usar un valor predeterminado adecuado. Los datos del flujo se leen de un búfer de tamaño recvsize; este también se puede establecer en un valor predeterminado adecuado pasando un valor cero. Cuando el búfer de salida de un flujo está lleno, se llama a writeit. De manera similar, cuando el búfer de entrada de un flujo está vacío, se llama a readit. El comportamiento de estas dos rutinas es similar a las llamadas al sistema read(2) y write(2), excepto que handle se pasa a las rutinas anteriores como primer argumento. Nota: el campo op del flujo XDR debe ser establecido por el llamador.
Advertencia: para leer de un flujo XDR creado por esta API, deberá llamar a xdrrec_skiprecord() primero antes de llamar a cualquier otra API XDR. Esto inserta bytes adicionales en el flujo para proporcionar límites de registro
bool_t xdrrec_skiprecord(XDR *xdrs);
Ignora el resto del registro actual y se posiciona al comienzo del siguiente. Esto es útil para ignorar los bytes de relleno que se insertan al final de un registro.
bool_t xdr_reference(XDR *xdrs, char **pp, unsigned int size,
                     xdrproc_t proc);
Una primitiva de filtro que serializa o deserializa un dato indirecto. El primer argumento es la dirección de un puntero al dato, el segundo es el tamaño del dato, y el tercero es la rutina XDR que traduce el dato en sí. Esta primitiva es útil para la serialización recursiva de estructuras de datos. A diferencia de xdr_pointer(), esta rutina no maneja punteros nulos.
void xdr_setpos(XDR *xdrs, unsigned int pos);
Una macro que invoca la rutina de establecimiento de posición asociada con el flujo XDR, xdrs. La rutina establece la posición del flujo de bytes XDR a pos. El valor de pos debe haber sido devuelto previamente por una llamada a xdr_getpos().
bool_t xdr_string(XDR *xdrs, char **sp, unsigned int maxsize);
Una primitiva de filtro que traduce entre cadenas terminadas en nulo y su representación externa. El argumento sp es la dirección del puntero de la cadena, y maxsize es la longitud máxima permitida para la cadena, incluido el carácter nulo terminador. Esta rutina devuelve uno si tiene éxito, cero en caso contrario.
bool_t xdr_u_char(XDR *xdrs, unsigned char *ucp);
Una primitiva de filtro que traduce entre caracteres sin signo C y sus representaciones externas. Esta rutina devuelve uno si tiene éxito, cero en caso contrario.
bool_t xdr_u_int(XDR *xdrs, unsigned int *up);
Una primitiva de filtro que traduce entre enteros sin signo C y sus representaciones externas. Esta rutina devuelve uno si tiene éxito, cero en caso contrario.
bool_t xdr_u_long(XDR *xdrs, unsigned long *ulp);
Una primitiva de filtro que traduce entre enteros largos sin signo C y sus representaciones externas. Esta rutina devuelve uno si tiene éxito, cero en caso contrario.
bool_t xdr_void(XDR *xdrs);
No hace nada. Se utiliza como marcador de posición para procedimientos que no tienen argumentos ni resultados.
bool_t xdr_vector(XDR *xdrs, char *cp, unsigned int size,
                  unsigned int maxsize, xdrproc_t xdrroutine);
Similar a xdr_bytes(), pero se utiliza para traducir un número fijo de elementos de tamaño size. El argumento maxsize es el tamaño máximo permitido para el vector. xdrroutine es la rutina XDR utilizada para serializar/deserializar cada elemento del vector.
bool_t xdr_wrapstring(XDR *xdrs, char **sp);
Similar a xdr_string(), pero asume que la cadena ya está codificada en la representación XDR. Se utiliza para deserializar cadenas.

Estas rutinas se utilizan para serializar y deserializar estructuras de datos complejas. Permiten la transferencia de datos entre procesos que pueden estar ejecutándose en diferentes máquinas con diferentes arquitecturas.

bool_t xdrrec_endofrecord(XDR *xdrs, int sendnow);
Esta rutina solo se puede invocar en flujos creados por xdrrec_create(). Los datos en el búfer de salida se marcan como un registro completado y el búfer de salida se escribe opcionalmente si sendnow no es cero. Esta rutina devuelve uno si tiene éxito, cero en caso contrario.
bool_t xdrrec_eof(XDR *xdrs);
Esta rutina solo se puede invocar en flujos creados por xdrrec_create(). Después de consumir el resto del registro actual en el flujo, esta rutina devuelve uno si el flujo no tiene más entrada, cero en caso contrario.
bool_t xdrrec_skiprecord(XDR *xdrs);
Esta rutina solo se puede invocar en flujos creados por xdrrec_create(). Indica a la implementación XDR que el resto del registro actual en el búfer de entrada del flujo debe ser descartado. Esta rutina devuelve uno si tiene éxito, cero en caso contrario.
bool_t xdr_reference(XDR *xdrs, char **pp, unsigned int size,
                     xdrproc_t proc);
Un primitivo que proporciona seguimiento de punteros dentro de estructuras. El argumento pp es la dirección del puntero; size es el resultado de sizeof de la estructura a la que apunta *pp; y proc es un procedimiento XDR que filtra la estructura entre su forma C y su representación externa. Esta rutina devuelve uno si tiene éxito, cero en caso contrario.
Advertencia: esta rutina no comprende los punteros nulos. Utilice xdr_pointer() en su lugar.
xdr_setpos(XDR *xdrs, unsigned int pos);
Una macro que invoca la rutina de establecer posición asociada con el flujo XDR xdrs. El argumento pos es un valor de posición obtenido de xdr_getpos(). Esta rutina devuelve uno si el flujo XDR pudo ser reposicionado y cero en caso contrario.
Advertencia: es difícil reposicionar algunos tipos de flujos XDR, por lo que esta rutina puede fallar con un tipo de flujo y tener éxito con otro.
bool_t xdr_short(XDR *xdrs, short *sp);
Un primitivo de filtro que traduce entre enteros short de C y sus representaciones externas. Esta rutina devuelve uno si tiene éxito, cero en caso contrario.
void xdrstdio_create(XDR *xdrs, FILE *file, enum xdr_op op);
Esta rutina inicializa el objeto de flujo XDR apuntado por xdrs. Los datos del flujo XDR se escriben o se leen del flujo stdio file. El argumento op determina la dirección del flujo XDR (ya sea XDR_ENCODE, XDR_DECODE o XDR_FREE).
Advertencia: la rutina de destrucción asociada con dichos flujos XDR llama a fflush(3) en el flujo file, pero nunca a fclose(3).
bool_t xdr_string(XDR *xdrs, char **sp, unsigned int maxsize);
Un primitivo de filtro que traduce entre cadenas de caracteres C y sus representaciones externas correspondientes. Las cadenas no pueden ser más largas que maxsize. Nota: sp es la dirección del puntero de la cadena. Esta rutina devuelve uno si tiene éxito, cero en caso contrario.
bool_t xdr_u_char(XDR *xdrs, unsigned char *ucp);
Un primitivo de filtro que traduce entre caracteres C sin signo y sus representaciones externas. Esta rutina devuelve uno si tiene éxito, cero en caso contrario.
bool_t xdr_u_int(XDR *xdrs, unsigned int *up);
Un primitivo de filtro que traduce entre enteros sin signo de C y sus representaciones externas. Esta rutina devuelve uno si tiene éxito, cero en caso contrario.
bool_t xdr_u_long(XDR *xdrs, unsigned long *ulp);
Un primitivo de filtro que traduce entre enteros long sin signo de C y sus representaciones externas. Esta rutina devuelve uno si tiene éxito, cero en caso contrario.
bool_t xdr_u_short(XDR *xdrs, unsigned short *usp);
Un primitivo de filtro que traduce entre enteros short sin signo de C y sus representaciones externas. Esta rutina devuelve uno si tiene éxito, cero en caso contrario.
bool_t xdr_union(XDR *xdrs, enum_t *dscmp, char *unp,
                 const struct xdr_discrim *choices,
                 xdrproc_t defaultarm);     /* puede ser NULL */
Un primitivo de filtro que traduce entre una unión discriminada de C y su representación externa correspondiente. Primero traduce el discriminante de la unión ubicado en dscmp. Este discriminante siempre es un enum_t. Luego, se traduce la unión ubicada en unp. El argumento choices es un puntero a una matriz de estructuras xdr_discrim(). Cada estructura contiene un par ordenado de [valor,proc]. Si el discriminante de la unión es igual al valor asociado, entonces se llama a proc para traducir la unión. El final de la matriz de estructuras xdr_discrim() se denota mediante un procedimiento de valor NULL. Si el discriminante no se encuentra en la matriz choices, entonces se llama al procedimiento defaultarm (si no es NULL). Devuelve uno si tiene éxito, cero en caso contrario.
bool_t xdr_vector(XDR *xdrs, char *arrp, unsigned int size,
                  unsigned int elsize, xdrproc_t elproc);
Un primitivo de filtro que traduce entre matrices de longitud fija y sus representaciones externas correspondientes. El argumento arrp es la dirección del puntero a la matriz, mientras que size es el recuento de elementos de la matriz. El argumento elsize es el resultado de sizeof de cada uno de los elementos de la matriz, y elproc es un filtro XDR que traduce entre la forma C de los elementos de la matriz y su representación externa. Esta rutina devuelve uno si tiene éxito, cero en caso contrario.
bool_t xdr_void(void);
Esta rutina siempre devuelve uno. Se puede pasar a rutinas RPC que requieren un argumento de función, donde no se debe hacer nada.
bool_t xdr_wrapstring(XDR *xdrs, char **sp);
Un primitivo que llama a xdr_string(xdrs, sp,MAXUN.UNSIGNED ); donde MAXUN.UNSIGNED es el valor máximo de un entero sin signo. xdr_wrapstring() es útil porque el paquete RPC pasa un máximo de dos rutinas XDR como argumentos, y xdr_string(), uno de los primitivos más utilizados, requiere tres. Devuelve uno si tiene éxito, cero en caso contrario.
