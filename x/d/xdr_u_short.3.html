xdr(3) Manual de funciones de biblioteca xdr(3)

NOMBRE

xdr — rutinas de biblioteca para la representación externa de datos

BIBLIOTECA

Biblioteca C estándar (libc, -lc)

SINOPSIS Y DESCRIPCIÓN

Estas rutinas permiten a los programadores C describir estructuras de datos arbitrarias de forma independiente de la máquina. Los datos para las llamadas a procedimientos remotos se transmiten utilizando estas rutinas.

Los prototipos a continuación se declaran en <rpc/xdr.h> y utilizan los siguientes tipos:

typedef int bool_t;
typedef typeof(bool_t (XDR *, void *, ...)) *xdrproc_t;

Para la declaración del tipo XDR, consulte <rpc/xdr.h>.

bool_t xdr_array(XDR *xdrs, char **arrp, unsigned int *sizep,
                 unsigned int maxsize, unsigned int elsize,
                 xdrproc_t elproc);
Un filtro primitivo que traduce entre arreglos de longitud variable y sus representaciones externas correspondientes. El argumento arrp es la dirección del puntero al arreglo, mientras que sizep es la dirección del contador de elementos del arreglo; este contador de elementos no puede exceder maxsize. El argumento elsize es el sizeof de cada uno de los elementos del arreglo, y elproc es un filtro XDR que traduce entre la forma C de los elementos del arreglo y su representación externa. Esta rutina devuelve uno si tiene éxito, cero en caso contrario.
bool_t xdr_bool(XDR *xdrs, bool_t *bp);
Un filtro primitivo que traduce entre booleanos (enteros C) y sus representaciones externas. Al codificar datos, este filtro produce valores de uno o cero. Esta rutina devuelve uno si tiene éxito, cero en caso contrario.
bool_t xdr_bytes(XDR *xdrs, char **sp, unsigned int *sizep,
                 unsigned int maxsize);
Un filtro primitivo que traduce entre cadenas de bytes contadas y sus representaciones externas. El argumento sp es la dirección del puntero a la cadena. La longitud de la cadena se encuentra en la dirección sizep; las cadenas no pueden tener más de maxsize. Esta rutina devuelve uno si tiene éxito, cero en caso contrario.
bool_t xdr_char(XDR *xdrs, char *cp);
Un filtro primitivo que traduce entre caracteres C y sus representaciones externas. Esta rutina devuelve uno si tiene éxito, cero en caso contrario. Nota: los caracteres codificados no se empaquetan y ocupan 4 bytes cada uno. Para arreglos de caracteres, vale la pena considerar xdr_bytes(), xdr_opaque() o xdr_string().
void xdr_destroy(XDR *xdrs);
Una macro que invoca la rutina de destrucción asociada con el flujo XDR, xdrs. La destrucción generalmente implica liberar estructuras de datos privadas asociadas con el flujo. Usar xdrs después de invocar xdr_destroy() no está definido.
bool_t xdr_double(XDR *xdrs, double *dp);
Un filtro primitivo que traduce entre números C de doble precisión y sus representaciones externas. Esta rutina devuelve uno si tiene éxito, cero en caso contrario.
bool_t xdr_enum(XDR *xdrs, enum_t *ep);
Un filtro primitivo que traduce entre enum C (en realidad, enteros) y sus representaciones externas. Esta rutina devuelve uno si tiene éxito, cero en caso contrario.
bool_t xdr_float(XDR *xdrs, float *fp);
Un filtro primitivo que traduce entre floats C y sus representaciones externas. Esta rutina devuelve uno si tiene éxito, cero en caso contrario.
void xdr_free(xdrproc_t proc, char *objp);
Rutina de liberación genérica. El primer argumento es la rutina XDR para el objeto que se está liberando. El segundo argumento es un puntero al objeto en sí. Nota: el puntero pasado a esta rutina no se libera, pero lo que apunta sí se libera (recursivamente).
unsigned int xdr_getpos(XDR *xdrs);
Una macro que invoca la rutina de obtención de posición asociada con el flujo XDR, xdrs. La rutina devuelve un entero sin signo, que indica la posición del flujo de bytes XDR. Una característica deseable de los flujos XDR es que la aritmética simple funciona con este número, aunque las instancias de flujo XDR no necesitan garantizar esto.
long *xdr_inline(XDR *xdrs, int len);
Una macro que invoca la rutina en línea asociada con el flujo XDR, xdrs. La rutina devuelve un puntero a una pieza contigua del búfer del flujo; len es la longitud en bytes del búfer deseado. Nota: el puntero se convierte a long *.
Advertencia: xdr_inline() puede devolver NULL (0) si no puede asignar una pieza contigua de un búfer. Por lo tanto, el comportamiento puede variar entre las instancias de flujo; existe por eficiencia.
bool_t xdr_int(XDR *xdrs, int *ip);
Un filtro primitivo que traduce entre enteros C y sus representaciones externas. Esta rutina devuelve uno si tiene éxito, cero en caso contrario.
bool_t xdr_long(XDR *xdrs, long *lp);
Un filtro primitivo que traduce entre enteros long C y sus representaciones externas. Esta rutina devuelve uno si tiene éxito, cero en caso contrario.
void xdrmem_create(XDR *xdrs, char *addr, unsigned int size,
                   enum xdr_op op);
Esta rutina inicializa el objeto de flujo XDR apuntado por xdrs. Los datos del flujo se escriben o leen de un bloque de memoria en la ubicación addr cuya longitud no sea mayor que size bytes. El op determina la dirección del flujo XDR (ya sea XDR_ENCODE, XDR_DECODE o XDR_FREE).
bool_t xdr_opaque(XDR *xdrs, char *cp, unsigned int cnt);
Un filtro primitivo que traduce entre datos opacos de tamaño fijo y su representación externa. El argumento cp es la dirección del objeto opaco y cnt es su tamaño en bytes. Esta rutina devuelve uno si tiene éxito, cero en caso contrario.
bool_t xdr_pointer(XDR *xdrs, char **objpp,
                   unsigned int objsize, xdrproc_t xdrobj);
Similar a xdr_reference() excepto que serializa punteros nulos, mientras que xdr_reference() no lo hace. Por lo tanto, xdr_pointer() puede representar estructuras de datos recursivas, como árboles binarios o listas enlazadas.
void xdrrec_create(XDR *xdrs, unsigned int sendsize,
                   unsigned int recvsize, char *handle,
                   typeof(int (char *, char *, int)) *readit,
                   typeof(int (char *, char *, int)) *writeit);
Esta rutina inicializa el objeto de flujo XDR apuntado por xdrs. Los datos del flujo se escriben en un búfer de tamaño sendsize; un valor de cero indica que el sistema debe usar un valor predeterminado adecuado. Los datos del flujo se leen de un búfer de tamaño recvsize; también se puede establecer en un valor predeterminado adecuado pasando un valor cero. Cuando el búfer de salida de un flujo está lleno, se llama a writeit. De manera similar, cuando el búfer de entrada de un flujo está vacío, se llama a readit. El comportamiento de estas dos rutinas es similar a las llamadas al sistema read(2) y write(2), excepto que handle se pasa a las rutinas anteriores como el primer argumento. Nota: el campo op del flujo XDR debe ser establecido por el llamador.
Advertencia: para leer desde un flujo XDR creado por esta API, necesitará llamar a xdrrec_skiprecord() primero antes de llamar a cualquier otra API XDR. Esto inserta bytes adicionales en el flujo para proporcionar límites de registro.
bool_t xdrrec_endofrecord(XDR *xdrs, bool_t sendf);
Si sendf es verdadero, esta rutina prepara el flujo para enviar el registro actual. Si sendf es falso, esta rutina busca el final del registro actual y devuelve uno si tiene éxito o cero si el registro está truncado.
bool_t xdrrec_skiprecord(XDR *xdrs);
Esta rutina omite el registro actual y busca el inicio del siguiente registro. Es útil cuando se lee un flujo en modo de decodificación, ya que se llama implícitamente al inicio de cada llamada de decodificación XDR después de la primera.
bool_t xdr_reference(XDR *xdrs, char **pp, unsigned int size,
                     xdrproc_t proc);
Una rutina de filtro de nivel inferior. El argumento pp es la dirección del puntero al objeto que se está codificando o decodificando. El argumento size es el tamaño del objeto, y proc es el procedimiento XDR que traduce entre la forma C del objeto y su representación externa. A diferencia de xdr_pointer(), esta rutina no serializa punteros nulos.
bool_t xdr_register(XDR *xdrs, u_int val);
Se utiliza para serializar enteros sin signo de 16 bits (cortos sin signo) al vuelo.
bool_t xdr_replymsg(XDR *xdrs, struct rpc_msg *rmsg);
Serializa o deserializa un mensaje de respuesta RPC. El argumento rmsg es un puntero a la estructura rpc_msg que contiene el mensaje de respuesta.
bool_t xdr_setpos(XDR *xdrs, unsigned int pos);
Una macro que invoca la rutina de establecer posición asociada con el flujo XDR, xdrs. La rutina establece la posición actual del flujo de bytes XDR a pos. El valor de pos se obtiene típicamente de una llamada anterior a xdr_getpos().
bool_t xdr_short(XDR *xdrs, short *sp);
Un filtro primitivo que traduce entre enteros cortos C y sus representaciones externas. Esta rutina devuelve uno si tiene éxito, cero en caso contrario.
bool_t xdr_string(XDR *xdrs, char **sp, unsigned int maxsize);
Un filtro primitivo que traduce entre cadenas terminadas en nulo y sus representaciones externas. El argumento sp es la dirección de la cadena. La cadena no puede tener más de maxsize caracteres, sin incluir el terminador nulo. Esta rutina devuelve uno si tiene éxito, cero en caso contrario.
bool_t xdr_u_int(XDR *xdrs, u_int *up);
Un filtro primitivo que traduce entre enteros sin signo C y sus representaciones externas. Esta rutina devuelve uno si tiene éxito, cero en caso contrario.
bool_t xdr_u_long(XDR *xdrs, u_long *ulp);
Un filtro primitivo que traduce entre enteros largos sin signo C y sus representaciones externas. Esta rutina devuelve uno si tiene éxito, cero en caso contrario.
bool_t xdr_uint16_t(XDR *xdrs, uint16_t *val);
Un filtro primitivo que traduce entre enteros sin signo de 16 bits C y sus representaciones externas.
bool_t xdr_uint32_t(XDR *xdrs, uint32_t *val);
Un filtro primitivo que traduce entre enteros sin signo de 32 bits C y sus representaciones externas.
bool_t xdr_uint64_t(XDR *xdrs, uint64_t *val);
Un filtro primitivo que traduce entre enteros sin signo de 64 bits C y sus representaciones externas.
bool_t xdr_u_short(XDR *xdrs, u_short *usp);
Un filtro primitivo que traduce entre enteros cortos sin signo C y sus representaciones externas. Esta rutina devuelve uno si tiene éxito, cero en caso contrario.
bool_t xdr_void(void);
No hace nada y devuelve uno. Se utiliza para representar la ausencia de datos en una estructura de datos.
bool_t xdr_wrapstring(XDR *xdrs, char **sp);
Similar a xdr_string(), pero utiliza una longitud predeterminada de 1024 bytes.

NAME

xdr_u_short, xdr_u_int, xdr_u_long, xdr_string, xdr_union, xdr_vector, xdr_void, xdr_wrapstring - library routines for XDR (eXternal Data Representation)

LIBRARY

XDR library (libtirpc, -ltirpc)

SYNOPSIS AND DESCRIPTION

bool_t xdr_u_short(XDR *xdrs, unsigned short *usp);
A filter primitive that translates between C unsigned short integers and their external representations. This routine returns one if it succeeds, zero otherwise.
bool_t xdr_u_int(XDR *xdrs, unsigned int *up);
A filter primitive that translates between C unsigned integers and their external representations. This routine returns one if it succeeds, zero otherwise.
bool_t xdr_u_long(XDR *xdrs, unsigned long *ulp);
A filter primitive that translates between C unsigned long integers and their external representations. This routine returns one if it succeeds, zero otherwise.
bool_t xdr_string(XDR *xdrs, char **sp, unsigned int maxsize);
A filter primitive that translates between C strings and their corresponding external representations. Strings cannot be longer than maxsize. Note: sp is the address of the string's pointer. This routine returns one if it succeeds, zero otherwise.
bool_t xdr_union(XDR *xdrs, enum_t *dscmp, char *unp,
                 const struct xdr_discrim *choices,
                 xdrproc_t defaultarm);     /* may equal NULL */
A filter primitive that translates between a discriminated C union and its corresponding external representation. It first translates the discriminant of the union located at dscmp. This discriminant is always an enum_t. Next the union located at unp is translated. The argument choices is a pointer to an array of xdr_discrim() structures. Each structure contains an ordered pair of [value,proc]. If the union's discriminant is equal to the associated value, then the proc is called to translate the union. The end of the xdr_discrim() structure array is denoted by a routine of value NULL. If the discriminant is not found in the choices array, then the defaultarm procedure is called (if it is not NULL). Returns one if it succeeds, zero otherwise.
bool_t xdr_vector(XDR *xdrs, char *arrp, unsigned int size,
                  unsigned int elsize, xdrproc_t elproc);
A filter primitive that translates between fixed-length arrays and their corresponding external representations. The argument arrp is the address of the pointer to the array, while size is the element count of the array. The argument elsize is the sizeof each of the array's elements, and elproc is an XDR filter that translates between the array elements' C form, and their external representation. This routine returns one if it succeeds, zero otherwise.
bool_t xdr_void(void);
This routine always returns one. It may be passed to RPC routines that require a function argument, where nothing is to be done.
bool_t xdr_wrapstring(XDR *xdrs, char **sp);
A primitive that calls xdr_string(xdrs, sp,MAXUN.UNSIGNED ); where MAXUN.UNSIGNED is the maximum value of an unsigned integer. xdr_wrapstring() is handy because the RPC package passes a maximum of two XDR routines as arguments, and xdr_string(), one of the most frequently used primitives, requires three. Returns one if it succeeds, zero otherwise.
