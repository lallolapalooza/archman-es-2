xdr(3) Manual de funciones de biblioteca xdr(3)

NOMBRE

xdr — rutinas de biblioteca para la representación externa de datos

BIBLIOTECA

Biblioteca C estándar (libc, -lc)

SINOPSIS Y DESCRIPCIÓN

Estas rutinas permiten a los programadores C describir estructuras de datos arbitrarias de forma independiente de la máquina. Los datos para las llamadas a procedimientos remotos se transmiten utilizando estas rutinas.

Los prototipos a continuación se declaran en <rpc/xdr.h> y utilizan los siguientes tipos:

typedef int bool_t;
typedef typeof(bool_t (XDR *, void *, ...))  *xdrproc_t;

Para la declaración del tipo XDR, véase <rpc/xdr.h>.

bool_t xdr_array(XDR *xdrs, char **arrp, unsigned int *sizep,
                 unsigned int maxsize, unsigned int elsize,
                 xdrproc_t elproc);
Un filtro primitivo que traduce entre matrices de longitud variable y sus representaciones externas correspondientes. El argumento arrp es la dirección del puntero a la matriz, mientras que sizep es la dirección del contador de elementos de la matriz; este contador de elementos no puede exceder maxsize. El argumento elsize es el sizeof de cada uno de los elementos de la matriz, y elproc es un filtro XDR que traduce entre la forma C de los elementos de la matriz y su representación externa. Esta rutina devuelve uno si tiene éxito, cero en caso contrario.
bool_t xdr_bool(XDR *xdrs, bool_t *bp);
Un filtro primitivo que traduce entre booleanos (enteros C) y sus representaciones externas. Al codificar datos, este filtro produce valores de uno o cero. Esta rutina devuelve uno si tiene éxito, cero en caso contrario.
bool_t xdr_bytes(XDR *xdrs, char **sp, unsigned int *sizep,
                 unsigned int maxsize);
Un filtro primitivo que traduce entre cadenas de bytes contadas y sus representaciones externas. El argumento sp es la dirección del puntero de la cadena. La longitud de la cadena se encuentra en la dirección sizep; las cadenas no pueden tener más de maxsize. Esta rutina devuelve uno si tiene éxito, cero en caso contrario.
bool_t xdr_char(XDR *xdrs, char *cp);
Un filtro primitivo que traduce entre caracteres C y sus representaciones externas. Esta rutina devuelve uno si tiene éxito, cero en caso contrario. Nota: los caracteres codificados no se empaquetan y ocupan 4 bytes cada uno. Para matrices de caracteres, vale la pena considerar xdr_bytes(), xdr_opaque() o xdr_string().
void xdr_destroy(XDR *xdrs);
Una macro que invoca la rutina de destrucción asociada con el flujo XDR, xdrs. La destrucción generalmente implica la liberación de estructuras de datos privadas asociadas con el flujo. Usar xdrs después de invocar xdr_destroy() no está definido.
bool_t xdr_double(XDR *xdrs, double *dp);
Un filtro primitivo que traduce entre números de precisión double de C y sus representaciones externas. Esta rutina devuelve uno si tiene éxito, cero en caso contrario.
bool_t xdr_enum(XDR *xdrs, enum_t *ep);
Un filtro primitivo que traduce entre enums de C (en realidad enteros) y sus representaciones externas. Esta rutina devuelve uno si tiene éxito, cero en caso contrario.
bool_t xdr_float(XDR *xdrs, float *fp);
Un filtro primitivo que traduce entre floats de C y sus representaciones externas. Esta rutina devuelve uno si tiene éxito, cero en caso contrario.
void xdr_free(xdrproc_t proc, char *objp);
Rutina genérica de liberación. El primer argumento es la rutina XDR para el objeto que se está liberando. El segundo argumento es un puntero al objeto en sí. Nota: el puntero pasado a esta rutina no se libera, pero lo que apunta sí se libera (recursivamente).
unsigned int xdr_getpos(XDR *xdrs);
Una macro que invoca la rutina de obtención de posición asociada con el flujo XDR, xdrs. La rutina devuelve un entero sin signo, que indica la posición del flujo de bytes XDR. Una característica deseable de los flujos XDR es que la aritmética simple funciona con este número, aunque las instancias de flujo XDR no necesiten garantizar esto.
long *xdr_inline(XDR *xdrs, int len);
Una macro que invoca la rutina en línea asociada con el flujo XDR, xdrs. La rutina devuelve un puntero a una pieza contigua del búfer del flujo; len es la longitud en bytes del búfer deseado. Nota: el puntero se convierte a long *.
Advertencia: xdr_inline() puede devolver NULL (0) si no puede asignar una pieza contigua de un búfer. Por lo tanto, el comportamiento puede variar entre instancias de flujo; existe por eficiencia.
bool_t xdr_int(XDR *xdrs, int *ip);
Un filtro primitivo que traduce entre enteros C y sus representaciones externas. Esta rutina devuelve uno si tiene éxito, cero en caso contrario.
bool_t xdr_long(XDR *xdrs, long *lp);
Un filtro primitivo que traduce entre enteros long de C y sus representaciones externas. Esta rutina devuelve uno si tiene éxito, cero en caso contrario.
void xdrmem_create(XDR *xdrs, char *addr, unsigned int size,
                   enum xdr_op op);
Esta rutina inicializa el objeto de flujo XDR al que apunta xdrs. Los datos del flujo se escriben o leen de un bloque de memoria en la ubicación addr cuya longitud no supera los size bytes. El op determina la dirección del flujo XDR (ya sea XDR_ENCODE, XDR_DECODE o XDR_FREE).
bool_t xdr_opaque(XDR *xdrs, char *cp, unsigned int cnt);
Un filtro primitivo que traduce entre datos opacos de tamaño fijo y su representación externa. El argumento cp es la dirección del objeto opaco y cnt es su tamaño en bytes. Esta rutina devuelve uno si tiene éxito, cero en caso contrario.
bool_t xdr_pointer(XDR *xdrs, char **objpp,
                   unsigned int objsize, xdrproc_t xdrobj);
Similar a xdr_reference() excepto que serializa punteros nulos, mientras que xdr_reference() no lo hace. Por lo tanto, xdr_pointer() puede representar estructuras de datos recursivas, como árboles binarios o listas enlazadas.
void xdrrec_create(XDR *xdrs, unsigned int sendsize,
                   unsigned int recvsize, char *handle,
                   typeof(int (char *, char *, int)) *readit,
                   typeof(int (char *, char *, int)) *writeit);
Esta rutina inicializa el objeto de flujo XDR al que apunta xdrs. Los datos del flujo se escriben en un búfer de tamaño sendsize; un valor de cero indica que el sistema debe usar un valor predeterminado adecuado. Los datos del flujo se leen de un búfer de tamaño recvsize; este también puede establecerse en un valor predeterminado adecuado pasando un valor cero. Cuando el búfer de salida de un flujo está lleno, se llama a writeit. De manera similar, cuando el búfer de entrada de un flujo está vacío, se llama a readit. El comportamiento de estas dos rutinas es similar a las llamadas al sistema read(2) y write(2), excepto que handle se pasa a las rutinas anteriores como el primer argumento. Nota: el campo op del flujo XDR debe ser establecido por el llamador.
Advertencia: para leer de un flujo XDR creado por esta API, necesitará llamar a xdrrec_skiprecord() antes de llamar a cualquier otra API XDR. Esto inserta bytes adicionales en el flujo para proporcionar límites de registro

BIBLIOTECA

Funciones de la biblioteca C (libc)

DESCRIPCIÓN Y SINOPSIS

Las rutinas XDR son un conjunto de rutinas de procesamiento de macros que ayudan a los programadores a construir software cliente-servidor basado en el Protocolo de llamada a procedimiento remoto (RPC) de Sun Microsystems. El propósito del sistema XDR es definir un protocolo estándar para la representación de estructuras de datos en una máquina de forma que puedan ser transmitidas a otra máquina que pueda tener una representación de datos diferente. La biblioteca XDR proporciona macros y rutinas que permiten a los desarrolladores codificar y decodificar estructuras de datos en el formato XDR estándar. Consulte rpc(3) para obtener más información.

bool_t xdr_short(XDR *xdrs, short *sp);
Un primitivo de filtro que traduce entre enteros short de C y sus representaciones externas. Esta rutina devuelve uno si tiene éxito, cero en caso contrario.
bool_t xdr_u_short(XDR *xdrs, unsigned short *usp);
Un primitivo de filtro que traduce entre enteros unsigned short de C y sus representaciones externas. Esta rutina devuelve uno si tiene éxito, cero en caso contrario.
bool_t xdr_int(XDR *xdrs, int *ip);
Un primitivo de filtro que traduce entre enteros int de C y sus representaciones externas. Esta rutina devuelve uno si tiene éxito, cero en caso contrario.
bool_t xdr_u_int(XDR *xdrs, unsigned int *up);
Un primitivo de filtro que traduce entre enteros unsigned int de C y sus representaciones externas. Esta rutina devuelve uno si tiene éxito, cero en caso contrario.
bool_t xdr_long(XDR *xdrs, long *lp);
Un primitivo de filtro que traduce entre enteros long de C y sus representaciones externas. Esta rutina devuelve uno si tiene éxito, cero en caso contrario.
bool_t xdr_u_long(XDR *xdrs, unsigned long *ulp);
Un primitivo de filtro que traduce entre enteros unsigned long de C y sus representaciones externas. Esta rutina devuelve uno si tiene éxito, cero en caso contrario.
bool_t xdr_float(XDR *xdrs, float *fp);
Un primitivo de filtro que traduce entre números de punto flotante de precisión simple de C y sus representaciones externas. Esta rutina devuelve uno si tiene éxito, cero en caso contrario.
bool_t xdr_double(XDR *xdrs, double *dp);
Un primitivo de filtro que traduce entre números de punto flotante de doble precisión de C y sus representaciones externas. Esta rutina devuelve uno si tiene éxito, cero en caso contrario.
bool_t xdr_enum(XDR *xdrs, enum_t *ep);
Un primitivo de filtro que traduce entre un enum de C y su representación externa. Esta rutina devuelve uno si tiene éxito, cero en caso contrario.
bool_t xdr_inline(XDR *xdrs, unsigned int len);
Un primitivo que devuelve un puntero a los datos de len bytes en el búfer XDR. Esto se usa para la serialización rápida de estructuras compuestas de tipos primitivos XDR. El valor de retorno es un puntero a los datos, o NULL si no se pudo satisfacer la solicitud (por ejemplo, si los datos no están disponibles en línea). Tenga en cuenta que esta función solo se puede usar con flujos que admitan la obtención de acceso en línea, como los creados con xdrmem_create(3) o xdrrec_create(3).
unsigned int xdr_getpos(XDR *xdrs);
Una macro que invoca la rutina de obtención de posición asociada con el flujo XDR xdrs. La rutina devuelve la posición actual dentro del flujo XDR. Para algunos tipos de flujos XDR, la posición podría no ser significativa.
bool_t xdr_descriptor(XDR *xdrs, struct \{ unsigned int max_len; char *buf;
                      \} *dsc);
Un primitivo que traduce entre un descriptor (un puntero a datos y su longitud) y su representación externa. El argumento dsc es el descripto-r para los datos que se codifican o decodifican. Esta rutina devuelve uno si tiene éxito, cero en caso contrario.
bool_t xdr_bytes(XDR *xdrs, char **bp, unsigned int *fl,
                 unsigned int maxsize);
Un primitivo que es similar a xdr_string(3) pero también maneja los bytes nulos. Los bytes se transmiten como una cadena de longitud seguida de los bytes. El argumento maxsize es el tamaño máximo de los bytes que se pueden transmitir. El argumento fl es la longitud de los bytes. El argumento bp es el puntero a los bytes. Esta rutina devuelve uno si tiene éxito, cero en caso contrario.
bool_t xdr_opaque(XDR *xdrs, char *cp, unsigned int cnt);
Un primitivo que traduce entre datos opacos (un bloque de bytes) y su representación externa. El argumento cp es el puntero a los datos, y cnt es el número de bytes que se van a traducir. Esta rutina devuelve uno si tiene éxito, cero en caso contrario.
bool_t xdr_string(XDR *xdrs, char **sp, unsigned int maxsize);
Un primitivo de filtro que traduce entre cadenas de caracteres C y sus correspondientes representaciones externas. Las cadenas no pueden ser más largas que maxsize. Nota: sp es la dirección del puntero de la cadena. Esta rutina devuelve uno si tiene éxito, cero en caso contrario.
bool_t xdr_wrapstring(XDR *xdrs, char **sp);
Un primitivo que llama a xdr_string(xdrs, sp,MAXUN.UNSIGNED ); donde MAXUN.UNSIGNED es el valor máximo de un entero sin signo. xdr_wrapstring() es útil porque el paquete RPC pasa un máximo de dos rutinas XDR como argumentos, y xdr_string(), uno de los primitivos más utilizados, requiere tres. Devuelve uno si tiene éxito, cero en caso contrario.
bool_t xdr_reference(XDR *xdrs, char **pp, unsigned int size,
                     xdrproc_t proc);
Un primitivo que proporciona seguimiento de punteros dentro de estructuras. El argumento pp es la dirección del puntero; size es el sizeof de la estructura a la que apunta *pp; y proc es un procedimiento XDR que filtra la estructura entre su forma C y su representación externa. Esta rutina devuelve uno si tiene éxito, cero en caso contrario.
Advertencia: esta rutina no comprende los punteros nulos. Utilice xdr_pointer() en su lugar.
bool_t xdr_pointer(XDR *xdrs, char **pp, unsigned int size,
                   xdrproc_t proc);
Similar a xdr_reference(3), pero esta rutina maneja correctamente los punteros nulos. Si el puntero es nulo, se serializa un valor especial para indicar la nulidad.
bool_t xdr_array(XDR *xdrs, char **arrp, unsigned int *size,
                 unsigned int maxsize, xdrproc_t proc);
Un primitivo de filtro que traduce entre arreglos de longitud variable y sus representaciones externas correspondientes. El argumento arrp es la dirección del puntero al arreglo; size es el número de elementos en el arreglo y también se actualiza con el tamaño real después de la deserialización; maxsize es el tamaño máximo permitido para el arreglo; y proc es un filtro XDR que se utiliza para traducir entre los elementos del arreglo. Esta rutina devuelve uno si tiene éxito, cero en caso contrario.
bool_t xdr_vector(XDR *xdrs, char *arrp, unsigned int size,
                  unsigned int elsize, xdrproc_t elproc);
Un primitivo de filtro que traduce entre arreglos de longitud fija y sus representaciones externas correspondientes. El argumento arrp es la dirección del puntero al arreglo, mientras que size es el recuento de elementos del arreglo. El argumento elsize es el sizeof de cada uno de los elementos del arreglo, y elproc es un filtro XDR que traduce entre la forma C de los elementos del arreglo y su representación externa. Esta rutina devuelve uno si tiene éxito, cero en caso contrario.
bool_t xdr_union(XDR *xdrs, enum_t *dscmp, char *unp,
                 const struct xdr_discrim *choices,
                 xdrproc_t defaultarm);     /* puede ser NULL */
Un primitivo de filtro que traduce entre una unión discriminada de C y su representación externa correspondiente. Primero traduce el discriminante de la unión ubicado en dscmp. Este discriminante siempre es un enum_t. Luego se traduce la unión ubicada en unp. El argumento choices es un puntero a un arreglo de estructuras xdr_discrim(). Cada estructura contiene un par ordenado de [valor,proc]. Si el discriminante de la unión es igual al valor asociado, entonces se llama a proc para traducir la unión. El final del arreglo de estructuras xdr_discrim() se denota por un procedimiento de valor NULL. Si el discriminante no se encuentra en el arreglo choices, entonces se llama al procedimiento defaultarm (si no es NULL). Devuelve uno si tiene éxito, cero en caso contrario.
bool_t xdr_char(XDR *xdrs, char *cp);
Un primitivo de filtro que traduce entre caracteres C y sus representaciones externas. Esta rutina devuelve uno si tiene éxito, cero en caso contrario.
bool_t xdr_u_char(XDR *xdrs, unsigned char *ucp);
Un primitivo de filtro que traduce entre caracteres C sin signo y sus representaciones externas. Esta rutina devuelve uno si tiene éxito, cero en caso contrario.
bool_t xdr_bool(XDR *xdrs, bool_t *bp);
Un primitivo de filtro que traduce entre booleanos de C (0 o 1) y su representación externa (0 o 1). Esta rutina devuelve uno si tiene éxito, cero en caso contrario.
bool_t xdr_void(void);
Esta rutina siempre devuelve uno. Se puede pasar a rutinas RPC que requieren un argumento de función, donde no se debe hacer nada.
void xdrrec_create(XDR *xdrs, unsigned int chunk_size, void *handle,
                   int (*readit)(), int (*writeit)());
Esta rutina inicializa el objeto de flujo XDR apuntado por xdrs. Los datos del flujo XDR se escriben o leen desde un búfer de memoria. El argumento chunk_size especifica el tamaño de los fragmentos de memoria que se utilizan para el búfer. Los argumentos readit y writeit son punteros a funciones que se utilizan para leer y escribir datos desde y hacia el flujo subyacente, respectivamente. El argumento handle es un puntero a datos definidos por el usuario que se pasan a las funciones readit y writeit. Esta rutina devuelve uno si tiene éxito, cero en caso contrario.
Las rutinas XDR con acceso a memoria no alineada no son compatibles. Por lo tanto, los flujos XDR creados con diferentes xdrmem_create(3) o xdrrec_create(3) no son compatibles por la misma razón.
bool_t xdrrec_endofrecord(XDR *xdrs, int sendnow);
Esta rutina solo se puede invocar en flujos creados por xdrrec_create(). Los datos en el búfer de salida se marcan como un registro completado, y el búfer de salida se escribe opcionalmente si sendnow es distinto de cero. Esta rutina devuelve uno si tiene éxito, cero en caso contrario.
bool_t xdrrec_eof(XDR *xdrs);
Esta rutina solo se puede invocar en flujos creados por xdrrec_create(). Después de consumir el resto del registro actual en el flujo, esta rutina devuelve uno si el flujo no tiene más entrada, cero en caso contrario.
bool_t xdrrec_skiprecord(XDR *xdrs);
Esta rutina solo se puede invocar en flujos creados por xdrrec_create(). Indica a la implementación XDR que el resto del registro actual en el búfer de entrada del flujo debe descartarse. Esta rutina devuelve uno si tiene éxito, cero en caso contrario.
xdr_setpos(XDR *xdrs, unsigned int pos);
Una macro que invoca la rutina de establecer posición asociada con el flujo XDR xdrs. El argumento pos es un valor de posición obtenido de xdr_getpos(). Esta rutina devuelve uno si el flujo XDR pudo ser reposicionado, y cero en caso contrario.
Advertencia: es difícil reposicionar algunos tipos de flujos XDR, por lo que esta rutina puede fallar con un tipo de flujo y tener éxito con otro.
void xdrstdio_create(XDR *xdrs, FILE *file, enum xdr_op op);
Esta rutina inicializa el objeto de flujo XDR apuntado por xdrs. Los datos del flujo XDR se escriben o leen desde el flujo stdio file. El argumento op determina la dirección del flujo XDR (ya sea XDR_ENCODE, XDR_DECODE o XDR_FREE).
Advertencia: la rutina de destrucción asociada con dichos flujos XDR llama a fflush(3) en el flujo file, pero nunca a fclose(3).
bool_t xdr_free(xdrproc_t proc, char *ptr);
Esta rutina libera la memoria asignada por una rutina XDR de decodificación. El argumento proc es el procedimiento XDR que se utilizó para decodificar los datos, y ptr es un puntero a los datos que se van a liberar. Esta rutina devuelve uno si tiene éxito, cero en caso contrario.
