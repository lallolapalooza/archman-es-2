xdr(3) Manual de funciones de biblioteca xdr(3)

NOMBRE

xdr — rutinas de biblioteca para la representación externa de datos

BIBLIOTECA

Biblioteca C estándar (libc, -lc)

SINOPSIS Y DESCRIPCIÓN

Estas rutinas permiten a los programadores C describir estructuras de datos arbitrarias de forma independiente de la máquina. Los datos para las llamadas a procedimientos remotos se transmiten utilizando estas rutinas.

Los prototipos a continuación se declaran en <rpc/xdr.h> y utilizan los siguientes tipos:

typedef int bool_t;
typedef typeof(bool_t (XDR *, void *, ...)) *xdrproc_t;

Para la declaración del tipo XDR, véase <rpc/xdr.h>.

bool_t xdr_array(XDR *xdrs, char **arrp, unsigned int *sizep,
                 unsigned int maxsize, unsigned int elsize,
                 xdrproc_t elproc);
Una primitiva de filtro que traduce entre arreglos de longitud variable y sus representaciones externas correspondientes. El argumento arrp es la dirección del puntero al arreglo, mientras que sizep es la dirección del contador de elementos del arreglo; este contador de elementos no puede exceder maxsize. El argumento elsize es el sizeof de cada uno de los elementos del arreglo, y elproc es un filtro XDR que traduce entre la forma C de los elementos del arreglo y su representación externa. Esta rutina devuelve uno si tiene éxito, cero en caso contrario.
bool_t xdr_bool(XDR *xdrs, bool_t *bp);
Una primitiva de filtro que traduce entre booleanos (enteros C) y sus representaciones externas. Al codificar datos, este filtro produce valores de uno o cero. Esta rutina devuelve uno si tiene éxito, cero en caso contrario.
bool_t xdr_bytes(XDR *xdrs, char **sp, unsigned int *sizep,
                 unsigned int maxsize);
Una primitiva de filtro que traduce entre cadenas de bytes contadas y sus representaciones externas. El argumento sp es la dirección del puntero a la cadena. La longitud de la cadena se encuentra en la dirección sizep; las cadenas no pueden tener una longitud mayor a maxsize. Esta rutina devuelve uno si tiene éxito, cero en caso contrario.
bool_t xdr_char(XDR *xdrs, char *cp);
Una primitiva de filtro que traduce entre caracteres C y sus representaciones externas. Esta rutina devuelve uno si tiene éxito, cero en caso contrario. Nota: los caracteres codificados no están empaquetados y ocupan 4 bytes cada uno. Para arreglos de caracteres, vale la pena considerar xdr_bytes(), xdr_opaque() o xdr_string().
void xdr_destroy(XDR *xdrs);
Una macro que invoca la rutina de destrucción asociada con el flujo XDR, xdrs. La destrucción generalmente implica liberar estructuras de datos privadas asociadas con el flujo. Usar xdrs después de invocar xdr_destroy() no está definido.
bool_t xdr_double(XDR *xdrs, double *dp);
Una primitiva de filtro que traduce entre números de precisión double de C y sus representaciones externas. Esta rutina devuelve uno si tiene éxito, cero en caso contrario.
bool_t xdr_enum(XDR *xdrs, enum_t *ep);
Una primitiva de filtro que traduce entre enums de C (en realidad enteros) y sus representaciones externas. Esta rutina devuelve uno si tiene éxito, cero en caso contrario.
bool_t xdr_float(XDR *xdrs, float *fp);
Una primitiva de filtro que traduce entre floats de C y sus representaciones externas. Esta rutina devuelve uno si tiene éxito, cero en caso contrario.
void xdr_free(xdrproc_t proc, char *objp);
Rutina genérica de liberación. El primer argumento es la rutina XDR para el objeto que se está liberando. El segundo argumento es un puntero al objeto en sí. Nota: el puntero pasado a esta rutina no se libera, pero lo que apunta sí se libera (recursivamente).
unsigned int xdr_getpos(XDR *xdrs);
Una macro que invoca la rutina de obtener posición asociada con el flujo XDR, xdrs. La rutina devuelve un entero sin signo, que indica la posición del flujo de bytes XDR. Una característica deseable de los flujos XDR es que la aritmética simple funciona con este número, aunque las instancias de flujo XDR no garantizan esto.
long *xdr_inline(XDR *xdrs, int len);
Una macro que invoca la rutina en línea asociada con el flujo XDR, xdrs. La rutina devuelve un puntero a una pieza contigua del búfer del flujo; len es la longitud en bytes del búfer deseado. Nota: el puntero se convierte a long *.
Advertencia: xdr_inline() puede devolver NULL (0) si no puede asignar una pieza contigua de un búfer. Por lo tanto, el comportamiento puede variar entre las instancias de flujo; existe por motivos de eficiencia.
bool_t xdr_int(XDR *xdrs, int *ip);
Una primitiva de filtro que traduce entre enteros C y sus representaciones externas. Esta rutina devuelve uno si tiene éxito, cero en caso contrario.
bool_t xdr_long(XDR *xdrs, long *lp);
Una primitiva de filtro que traduce entre enteros long de C y sus representaciones externas. Esta rutina devuelve uno si tiene éxito, cero en caso contrario.
void xdrmem_create(XDR *xdrs, char *addr, unsigned int size,
                   enum xdr_op op);
Esta rutina inicializa el objeto de flujo XDR apuntado por xdrs. Los datos del flujo se escriben o leen de un bloque de memoria en la ubicación addr cuya longitud no supera los size bytes. El op determina la dirección del flujo XDR (ya sea XDR_ENCODE, XDR_DECODE o XDR_FREE).
bool_t xdr_opaque(XDR *xdrs, char *cp, unsigned int cnt);
Una primitiva de filtro que traduce entre datos opacos de tamaño fijo y su representación externa. El argumento cp es la dirección del objeto opaco, y cnt es su tamaño en bytes. Esta rutina devuelve uno si tiene éxito, cero en caso contrario.
bool_t xdr_pointer(XDR *xdrs, char **objpp,
                   unsigned int objsize, xdrproc_t xdrobj);
Similar a xdr_reference() excepto que serializa punteros nulos, mientras que xdr_reference() no lo hace. Por lo tanto, xdr_pointer() puede representar estructuras de datos recursivas, como árboles binarios o listas enlazadas.
void xdrrec_create(XDR *xdrs, unsigned int sendsize,
                   unsigned int recvsize, char *handle,
                   typeof(int (char *, char *, int)) *readit,
                   typeof(int (char *, char *, int)) *writeit);
Esta rutina inicializa el objeto de flujo XDR apuntado por xdrs. Los datos del flujo se escriben en un búfer de tamaño sendsize; un valor de cero indica que el sistema debe usar uno predeterminado adecuado. Los datos del flujo se leen de un búfer de tamaño recvsize; este también puede establecerse en un valor predeterminado adecuado pasando un valor cero. Cuando el búfer de salida de un flujo está lleno, se llama a writeit. De manera similar, cuando el búfer de entrada de un flujo está vacío, se llama a readit. El comportamiento de estas dos rutinas es similar a las llamadas al sistema read(2) y write(2), excepto que handle se pasa a las rutinas anteriores como primer argumento. Nota: el campo op del flujo XDR debe ser establecido por el llamador.
Advertencia: para leer desde un flujo XDR creado por esta API, necesitará llamar a xdrrec_skiprecord() antes de llamar a cualquier otra API de XDR. Esto inserta bytes adicionales en el flujo para proporcionar límites de registro.
bool_t xdrrec_skiprecord(XDR *xdrs);
Esta rutina omite el registro actual en el flujo XDR. Esto es útil al leer datos de un flujo XDR que utiliza la codificación por registro (ver xdrrec_create()). Devuelve 1 si tiene éxito, 0 si falla.
bool_t xdr_reference(XDR *xdrs, char **pp, unsigned int len,
                     xdrproc_t proc);
Una rutina de serialización genérica. El argumento pp es la dirección de un puntero al objeto a serializar. El argumento len es el tamaño del objeto a serializar, y proc es la rutina XDR para serializar el objeto. Esta rutina se utiliza para serializar estructuras de datos anidadas. Nota: esta rutina no serializa punteros nulos.
bool_t xdr_setpos(XDR *xdrs, unsigned int pos);
Una macro que invoca la rutina de establecer posición asociada con el flujo XDR, xdrs. La rutina establece la posición del flujo de bytes XDR a pos. El valor pos se obtuvo previamente de xdr_getpos(). Esta rutina devuelve uno si tiene éxito, cero en caso contrario.
bool_t xdr_short(XDR *xdrs, short *sp);
Una primitiva de filtro que traduce entre enteros short de C y sus representaciones externas. Esta rutina devuelve uno si tiene éxito, cero en caso contrario.
char *xdr_sizeof(xdrproc_t proc, char *objp);
Rutina para calcular el tamaño de un objeto XDR. El primer argumento es la rutina XDR para el objeto. El segundo argumento es un puntero al objeto. Devuelve el tamaño del objeto en bytes. Nota: esta rutina solo funciona si la rutina XDR dada soporta la operación XDR_FREE.
bool_t xdr_string(XDR *xdrs, char **sp, unsigned int maxsize);
Una primitiva de filtro que traduce entre cadenas terminadas en nulo y sus representaciones externas. El argumento sp es la dirección de la cadena. La longitud máxima permitida para la cadena es maxsize. Esta rutina devuelve uno si tiene éxito, cero en caso contrario.
bool_t xdr_u_char(XDR *xdrs, unsigned char *ucp);
Una primitiva de filtro que traduce entre caracteres sin signo C y sus representaciones externas. Esta rutina devuelve uno si tiene éxito, cero en caso contrario.
bool_t xdr_u_long(XDR *xdrs, unsigned long *ulp);
Una primitiva de filtro que traduce entre enteros unsigned long de C y sus representaciones externas. Esta rutina devuelve uno si tiene éxito, cero en caso contrario.
bool_t xdr_u_short(XDR *xdrs, unsigned short *usp);
Una primitiva de filtro que traduce entre enteros unsigned short de C y sus representaciones externas. Esta rutina devuelve uno si tiene éxito, cero en caso contrario.
bool_t xdr_union(XDR *xdrs, enum_t *dest, char *obj,
                 const struct xdr_discrim *choices,
                 typeof(bool_t (XDR *, char *, enum_t *)) *defaultix);
Una primitiva de filtro que traduce entre uniones discriminadas de C y sus representaciones externas. El primer argumento es el flujo XDR. El segundo argumento es un puntero al discriminante de la unión. El tercer argumento es un puntero a la unión. El cuarto argumento es un puntero a una matriz de estructuras xdr_discrim que describe los casos de la unión. El quinto argumento es un puntero a una rutina XDR que se llama si el discriminante no coincide con ninguno de los casos de la unión.
bool_t xdr_vector(XDR *xdrs, char *basep, unsigned int size,
                  unsigned int elsize, xdrproc_t elproc);
Una primitiva de filtro que traduce entre arreglos de longitud fija y sus representaciones externas. El argumento basep es la dirección del arreglo, size es el número de elementos en el arreglo, elsize es el tamaño de cada elemento, y elproc es la rutina XDR para serializar un solo elemento. Esta rutina devuelve uno si tiene éxito, cero en caso contrario.
bool_t xdr_void(void);
Este filtro se utiliza para representar el tipo void. No hace nada y siempre devuelve uno.
bool_t xdr_wrapstring(XDR *xdrs, char **sp);
Una primitiva de filtro que traduce entre cadenas terminadas en nulo y sus representaciones externas. Es similar a xdr_string() pero no toma un argumento maxsize. Utiliza un tamaño predeterminado para las cadenas.

Ver también: xdr_bytes(3), xdr_getpos(3), xdr_long(3), xdr_opaque(3), xdr_register(3), xdr_setpos(3), xdr_string(3), xdr_union(3), xdr_vector(3), xdr_wrapstring(3)

LIBRARY

SYNOPSIS AND DESCRIPTION

bool_t xdr_double(XDR *xdrs, double *dp);
A filter primitive that translates between C double types and their external representations. This routine returns one if it succeeds, zero otherwise.
bool_t xdr_float(XDR *xdrs, float *fp);
A filter primitive that translates between C float types and their external representations. This routine returns one if it succeeds, zero otherwise.
void * xdr_inline(XDR *xdrs, unsigned int len);
A macro that provides access to a buffer of len bytes within the XDR stream xdrs. This buffer is guaranteed to be aligned. If the XDR stream does not support inline data, this routine returns NULL. Otherwise, it returns a pointer to the buffer.
Warning: if the XDR stream supports inline data, the data in the buffer may be overwritten if the caller does not consume it all. The caller should use xdr_in_cksum() to checksum the data.
bool_t xdr_int(XDR *xdrs, int *ip);
A filter primitive that translates between C int types and their external representations. This routine returns one if it succeeds, zero otherwise.
bool_t xdr_long(XDR *xdrs, long *lp);
A filter primitive that translates between C long types and their external representations. This routine returns one if it succeeds, zero otherwise.
bool_t xdr_longlong(XDR *xdrs, long long *llp);
A filter primitive that translates between C long long types and their external representations. This routine returns one if it succeeds, zero otherwise.
bool_t xdr_longlong_bytes(XDR *xdrs, char *cp, unsigned int len);
A filter primitive that translates between a block of long long bytes and their external representations. This routine returns one if it succeeds, zero otherwise.
bool_t xdr_long_bytes(XDR *xdrs, char *cp, unsigned int len);
A filter primitive that translates between a block of long bytes and their external representations. This routine returns one if it succeeds, zero otherwise.
bool_t xdr_quadruple(XDR *xdrs, long double *qp);
A filter primitive that translates between C long double types and their external representations. This routine returns one if it succeeds, zero otherwise.
bool_t xdr_array(XDR *xdrs, char **arrpp, unsigned int *lenp,
                 unsigned int maxsize, xdrproc_t element_proc,
                 xdrproc_t destructor_proc);
A filter primitive that translates between fixed-size arrays and their corresponding external representations. The argument arrpp is the address of the pointer to the array. The argument lenp is the address of the number of elements in the array. The argument maxsize is the maximum number of elements the array may contain. The argument element_proc is an XDR filter that translates between the array elements' C form, and their external representation. The argument destructor_proc is an XDR filter that deallocates memory that was allocated by element_proc. This routine returns one if it succeeds, zero otherwise.
Note: The destructor_proc argument is deprecated and should be NULL.
bool_t xdr_bytes(XDR *xdrs, char **sp, unsigned int *lenp,
                 unsigned int maxsize);
A filter primitive that translates between arbitrary sequences of bytes and their external representations. The argument sp is the address of the pointer to the byte sequence, and lenp is the address of the size of the byte sequence. The argument maxsize is the maximum number of bytes that may be transferred. This routine returns one if it succeeds, zero otherwise.
bool_t xdr_char(XDR *xdrs, char *cp);
A filter primitive that translates between C characters and their external representations. This routine returns one if it succeeds, zero otherwise.
void xdr_destroy(XDR *xdrs);
This routine destroys the specified XDR stream. It frees any buffers associated with the stream and destroys the stream linkage.
bool_t xdr_enum(XDR *xdrs, enum_t *ep);
A filter primitive that translates between C enum types and their external representations. This routine returns one if it succeeds, zero otherwise.
bool_t xdr_free(const char *obj_dr, char *obj_ptr);
This routine frees the memory associated with the specified XDR object. The argument obj_dr is the XDR routine used to encode or decode the object, and obj_ptr is the pointer to the object to be freed. This routine returns one if it succeeds, zero otherwise.
unsigned int xdr_getpos(XDR *xdrs);
A macro that returns the current position in the XDR stream xdrs. The position is a cookie that is passed to xdr_setpos(). Some XDR streams may not support this operation; in such cases, zero is returned.
bool_t xdrrec_create(XDR *xdrs, unsigned int ahiresz,
                     unsigned int alowsxz, char *raddr,
                     int (*fgetc())(char *, int),
                     int (*fsendit())(char *, int));
This routine initializes the XDR stream object pointed to by xdrs to use record marking. The stream is created with an input buffer size of ahiresz and an output buffer size of alowsxz. The argument raddr is a pointer to the buffer used for reading and writing. The arguments fgetc and fsendit are pointers to routines that handle reading and writing data. This routine returns one if it succeeds, zero otherwise.
The arguments ahiresz and alowsxz represent the maximum sizes of the input and output buffers, respectively. These sizes are used to optimize data transfer. The default values for these parameters depend on the specific XDR implementation.
The arguments fgetc and fsendit are function pointers to routines that handle reading and writing data to the underlying transport. The fgetc routine should read data from the transport and place it into the buffer provided. The fsendit routine should write data from the buffer to the transport. These routines should return the number of bytes read or written, or -1 in case of an error.
Warning: XDR streams created with different xdrrec_create() arguments may not be compatible. XDR streams created with different xdr*_create() APIs are not compatible for the same reason.
bool_t xdrrec_endofrecord(XDR *xdrs, int sendnow);
This routine can be invoked only on streams created by xdrrec_create(). The data in the output buffer is marked as a completed record, and the output buffer is optionally written out if sendnow is nonzero. This routine returns one if it succeeds, zero otherwise.
bool_t xdrrec_eof(XDR *xdrs);
This routine can be invoked only on streams created by xdrrec_create(). After consuming the rest of the current record in the stream, this routine returns one if the stream has no more input, zero otherwise.
bool_t xdrrec_skiprecord(XDR *xdrs);
This routine can be invoked only on streams created by xdrrec_create(). It tells the XDR implementation that the rest of the current record in the stream's input buffer should be discarded. This routine returns one if it succeeds, zero otherwise.
bool_t xdr_reference(XDR *xdrs, char **pp, unsigned int size,
                     xdrproc_t proc);
A primitive that provides pointer chasing within structures. The argument pp is the address of the pointer; size is the sizeof the structure that *pp points to; and proc is an XDR procedure that filters the structure between its C form and its external representation. This routine returns one if it succeeds, zero otherwise.
Warning: this routine does not understand null pointers. Use xdr_pointer() instead.
xdr_setpos(XDR *xdrs, unsigned int pos);
A macro that invokes the set position routine associated with the XDR stream xdrs. The argument pos is a position value obtained from xdr_getpos(). This routine returns one if the XDR stream could be repositioned, and zero otherwise.
Warning: it is difficult to reposition some types of XDR streams, so this routine may fail with one type of stream and succeed with another.
bool_t xdr_short(XDR *xdrs, short *sp);
A filter primitive that translates between C short integers and their external representations. This routine returns one if it succeeds, zero otherwise.
void xdrstdio_create(XDR *xdrs, FILE *file, enum xdr_op op);
This routine initializes the XDR stream object pointed to by xdrs. The XDR stream data is written to, or read from, the stdio stream file. The argument op determines the direction of the XDR stream (either XDR_ENCODE, XDR_DECODE, or XDR_FREE).
Warning: the destroy routine associated with such XDR streams calls fflush(3) on the file stream, but never fclose(3).
bool_t xdr_string(XDR *xdrs, char **sp, unsigned int maxsize);
A filter primitive that translates between C strings and their corresponding external representations. Strings cannot be longer than maxsize. Note: sp is the address of the string's pointer. This routine returns one if it succeeds, zero otherwise.
bool_t xdr_u_char(XDR *xdrs, unsigned char *ucp);
A filter primitive that translates between unsigned C characters and their external representations. This routine returns one if it succeeds, zero otherwise.
bool_t xdr_u_int(XDR *xdrs, unsigned int *up);
A filter primitive that translates between C unsigned integers and their external representations. This routine returns one if it succeeds, zero otherwise.
bool_t xdr_u_long(XDR *xdrs, unsigned long *ulp);
A filter primitive that translates between C unsigned long integers and their external representations. This routine returns one if it succeeds, zero otherwise.
bool_t xdr_u_longlong(XDR *xdrs, unsigned long long *ullp);
A filter primitive that translates between C unsigned long long integers and their external representations. This routine returns one if it succeeds, zero otherwise.
bool_t xdr_u_short(XDR *xdrs, unsigned short *usp);
A filter primitive that translates between C unsigned short integers and their external representations. This routine returns one if it succeeds, zero otherwise.
bool_t xdr_union(XDR *xdrs, enum_t *dscmp, char *unp,
                 const struct xdr_discrim *choices,
                 xdrproc_t defaultarm);     /* may equal NULL */
A filter primitive that translates between a discriminated C union and its corresponding external representation. It first translates the discriminant of the union located at dscmp. This discriminant is always an enum_t. Next the union located at unp is translated. The argument choices is a pointer to an array of xdr_discrim() structures. Each structure contains an ordered pair of [value,proc]. If the union's discriminant is equal to the associated value, then the proc is called to translate the union. The end of the xdr_discrim() structure array is denoted by a routine of value NULL. If the discriminant is not found in the choices array, then the defaultarm procedure is called (if it is not NULL). Returns one if it succeeds, zero otherwise.
bool_t xdr_vector(XDR *xdrs, char *arrp, unsigned int size,
                  unsigned int elsize, xdrproc_t elproc);
A filter primitive that translates between fixed-length arrays and their corresponding external representations. The argument arrp is the address of the pointer to the array, while size is the element count of the array. The argument elsize is the sizeof each of the array's elements, and elproc is an XDR filter that translates between the array elements' C form, and their external representation. This routine returns one if it succeeds, zero otherwise.
bool_t xdr_void(void);
This routine always returns one. It may be passed to RPC routines that require a function argument, where nothing is to be done.
bool_t xdr_wrapstring(XDR *xdrs, char **sp);
A primitive that calls xdr_string(xdrs, sp,MAXUN.UNSIGNED ); where MAXUN.UNSIGNED is the maximum value of an unsigned integer. xdr_wrapstring() is handy because the RPC package passes a maximum of two XDR routines as arguments, and xdr_string(), one of the most frequently used primitives, requires three. Returns one if it succeeds, zero otherwise.

Arch Linux es una distribución Linux independiente, creada para usuarios experimentados que les gusta tener el control de su sistema operativo.

El objetivo de Arch Linux es la simplicidad, la modernidad, el pragmatismo, el centralismo del usuario y la versatilidad.

Arch Linux utiliza un modelo de lanzamiento de rolling release, lo que significa que el sistema está constantemente actualizado, sin necesidad de reinstalarlo cada vez que se lanza una nueva versión.

El sistema de paquetes de Arch Linux, llamado Pacman, es conocido por su velocidad y simplicidad.

El proyecto también mantiene un Arch User Repository (AUR), una gran colección de descripciones de paquetes que permite a los usuarios compilar software adicional fácilmente.

El sitio web utiliza mandoc para la conversión de las páginas del manual.

El sitio web está disponible bajo los términos de la licencia GPL-3.0, excepto por el contenido de las páginas del manual, que tienen su propia licencia especificada en el paquete correspondiente de Arch Linux.
