XDG-MIME(1) Manual de xdg-mime XDG-MIME(1)

NOMBRE

xdg-mime - herramienta de línea de comandos para consultar información sobre el manejo de tipos de archivo y agregar descripciones para nuevos tipos de archivo

SINOPSIS

xdg-mime query {filetype ARCHIVO | default tipodemime}

xdg-mime default aplicación tipodemime(s)

xdg-mime install [--modo modo] [--novendor] archivo-tiposdemime

xdg-mime uninstall [--modo modo] archivo-tiposdemime

xdg-mime {--ayuda | --manual | --versión}

DESCRIPCIÓN

El programa xdg-mime se puede utilizar para consultar información sobre tipos de archivo y para agregar descripciones para nuevos tipos de archivo.

COMANDOS

query filetype

Devuelve el tipo de archivo de ARCHIVO en forma de un tipo MIME.

Tenga en cuenta que los nombres de archivo que comienzan con un - serán rechazados; esto se puede mitigar:

•Pase rutas absolutas, es decir, usando realpath como preprocesador.
•Prefije los nombres de archivo relativos conocidos con un “./”. Por ejemplo, usando sed -E 's|^[^/]|./\0|' como preprocesador.

La opción query filetype es solo para uso dentro de una sesión de escritorio. No se recomienda usar xdg-mime query filetype como root.

query default

Devuelve la aplicación predeterminada que el entorno de escritorio utiliza para abrir archivos del tipo tipodemime. La aplicación predeterminada se identifica por su archivo *.desktop.

El valor devuelto por este comando puede o no coincidir con la aplicación iniciada por xdg-open, ya que xdg-open a menudo delega a los abridores específicos del escritorio, los cuales pueden implementar su propia lógica.

La opción query default es solo para uso dentro de una sesión de escritorio. No se recomienda usar xdg-mime query default como root.

default

Solicita al entorno de escritorio que haga de aplicación la aplicación predeterminada para abrir archivos del tipo tipodemime. Una aplicación puede convertirse en la predeterminada para varios tipos de archivo especificando varios tipos MIME.

aplicación es el ID del archivo .desktop de la aplicación y tiene el formato vendor-name.desktop. aplicación ya debe estar instalada en el menú de aplicaciones antes de poder convertirla en la predeterminada. El archivo .desktop de la aplicación debe enumerar la compatibilidad con todos los tipos MIME para los que desea ser el manejador predeterminado.

Las solicitudes para hacer de una aplicación un manejador predeterminado pueden estar sujetas a la política del sistema o a la aprobación del usuario final. xdg-mime query se puede usar para verificar si una aplicación es el manejador predeterminado real para un tipo de archivo específico.

Nota de seguridad: Nunca establezca un manejador que ejecute ciegamente código o comandos del archivo que se está manejando. Dicho comportamiento tarde o temprano conducirá a la ejecución de código no deseada, por ejemplo, a través de un usuario curioso que intente inspeccionar un archivo recién descargado pero que lo ejecute por accidente.

Mantener la apertura y la ejecución como acciones separadas ayuda a las personas a protegerse contra malware; el manejador predeterminado es un abridor, no un ejecutor.

La opción default es solo para uso dentro de una sesión de escritorio. No se recomienda usar xdg-mime default como root.

install

Agrega las descripciones de tipos de archivo proporcionadas en archivo-tiposdemime al entorno de escritorio. archivo-tiposdemime debe ser un archivo XML que siga la especificación de la base de datos Shared MIME-info de freedesktop.org y que tenga un elemento mime-info como su raíz de documento. Para cada nuevo tipo de archivo, se deben instalar uno o más iconos con el nombre type-subtype usando el comando xdg-icon-resource en el contexto de mimetypes. Por ejemplo, el tipo de archivo application/vnd.oasis.opendocument.text requiere un icono llamado application-vnd.oasis.opendocument.text instalado (a menos que el tipo de archivo recomiende otro nombre de icono).

uninstall

Elimina las descripciones de tipos de archivo proporcionadas en archivo-tiposdemime y previamente agregadas con xdg-mime install del entorno de escritorio. archivo-tiposdemime debe ser un archivo XML que siga la especificación de la base de datos Shared MIME-info de freedesktop.org y que tenga un elemento mime-info como su raíz de documento.

OPCIONES

--modo modo

modo puede ser user o system. En modo usuario, el archivo se instala/desinstala solo para el usuario actual. En modo sistema, el archivo se instala/desinstala para todos los usuarios del sistema. Normalmente, solo root tiene permiso para instalar en modo sistema.

El valor predeterminado es usar el modo sistema cuando lo llama root y el modo usuario cuando lo llama un usuario no root.

--novendor

Normalmente, xdg-mime verifica que el archivo-tiposdemime a instalar tenga un prefijo de proveedor adecuado. Esta opción se puede usar para deshabilitar esa verificación.

Un prefijo de proveedor consiste en caracteres alfabéticos ([a-zA-Z]) y termina con un guion ("-"). Se anima a las empresas y organizaciones a usar una palabra o frase, preferiblemente el nombre de la organización, para la cual tienen una marca registrada como su prefijo de proveedor. El propósito del prefijo del proveedor es evitar conflictos de nombres.

--ayuda

Muestra la sinopsis del comando.

--manual

Muestra esta página del manual.

--versión

Muestra la información de la versión de xdg-utils.

VARIABLES DE ENTORNO

xdg-mime respeta las siguientes variables de entorno:

XDG_UTILS_DEBUG_LEVEL

Establecer esta variable de entorno a un valor numérico distinto de cero hace que xdg-mime genere informes más detallados en stderr. Establecer un valor más alto aumenta la verbosidad.

XDG_UTILS_INSTALL_MODE

Esta variable de entorno puede ser utilizada por el usuario o administrador para anular el modo de instalación. Los valores válidos son user y system.

CÓDIGOS DE SALIDA

Un código de salida de 0 indica éxito, mientras que un código de salida distinto de cero indica fallo. Los siguientes códigos de fallo pueden ser devueltos:

1

Error en la sintaxis de la línea de comandos.

2

Uno de los archivos pasados en la línea de comandos no existía.

3

No se pudo encontrar una herramienta requerida.

4

La acción falló.

5

No hay permiso para leer uno de los archivos pasados en la línea de comandos.

VER TAMBIÉN

xdg-icon-resource(1), xdg-desktop-menu(1), Especificación de la base de datos Shared MIME[1], Especificación de asociaciones de aplicaciones MIME[2]

EJEMPLOS

xdg-mime query filetype /tmp/foobar.png

Imprime el tipo MIME del archivo /tmp/foobar.png, en este caso image/png

xdg-mime query default image/png

Imprime el nombre del archivo .desktop de la aplicación que está registrada para abrir archivos PNG.

xdg-mime install shinythings-shiny.xml

Agrega una descripción de tipo de archivo para archivos "shiny". "shinythings-" se usa como prefijo de proveedor. La descripción del tipo de archivo podría verse así.

shinythings-shiny.xml:
<?xml version="1.0"?>
<mime-info xmlns='http://www.freedesktop.org/standards/shared-mime-info'>
  <mime-type type="text/x-shiny">
    <comment>Shiny new file type</comment>
    <glob pattern="*.shiny"/>
    <glob pattern="*.shi"/>
  </mime-type>
</mime-info>

También se debe instalar un icono para este nuevo tipo de archivo, por ejemplo, con:

xdg-icon-resource install --context mimetypes --size 64 shiny-file-icon.png text-x-shiny
