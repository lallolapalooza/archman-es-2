xdr(3) Manual de funciones de biblioteca xdr(3)

NOMBRE

xdr — rutinas de biblioteca para la representación externa de datos

BIBLIOTECA

Biblioteca C estándar (libc, -lc)

SINOPSIS Y DESCRIPCIÓN

Estas rutinas permiten a los programadores C describir estructuras de datos arbitrarias de forma independiente de la máquina. Los datos para las llamadas a procedimientos remotos se transmiten utilizando estas rutinas.

Los prototipos a continuación se declaran en <rpc/xdr.h> y utilizan los siguientes tipos:

typedef int bool_t;
typedef typeof(bool_t (XDR *, void *, ...)) *xdrproc_t;

Para la declaración del tipo XDR, consulte <rpc/xdr.h>.

bool_t xdr_array(XDR *xdrs, char **arrp, unsigned int *sizep,
                 unsigned int maxsize, unsigned int elsize,
                 xdrproc_t elproc);
Un filtro primitivo que traduce entre arreglos de longitud variable y sus representaciones externas correspondientes. El argumento arrp es la dirección del puntero al arreglo, mientras que sizep es la dirección del contador de elementos del arreglo; este contador de elementos no puede exceder maxsize. El argumento elsize es el sizeof de cada uno de los elementos del arreglo, y elproc es un filtro XDR que traduce entre la forma C de los elementos del arreglo y su representación externa. Esta rutina devuelve uno si tiene éxito, cero en caso contrario.
bool_t xdr_bool(XDR *xdrs, bool_t *bp);
Un filtro primitivo que traduce entre booleanos (enteros C) y sus representaciones externas. Al codificar datos, este filtro produce valores de uno o cero. Esta rutina devuelve uno si tiene éxito, cero en caso contrario.
bool_t xdr_bytes(XDR *xdrs, char **sp, unsigned int *sizep,
                 unsigned int maxsize);
Un filtro primitivo que traduce entre cadenas de bytes contadas y sus representaciones externas. El argumento sp es la dirección del puntero de la cadena. La longitud de la cadena se encuentra en la dirección sizep; las cadenas no pueden tener más de maxsize. Esta rutina devuelve uno si tiene éxito, cero en caso contrario.
bool_t xdr_char(XDR *xdrs, char *cp);
Un filtro primitivo que traduce entre caracteres C y sus representaciones externas. Esta rutina devuelve uno si tiene éxito, cero en caso contrario. Nota: los caracteres codificados no están empaquetados y ocupan 4 bytes cada uno. Para arreglos de caracteres, vale la pena considerar xdr_bytes(), xdr_opaque() o xdr_string().
void xdr_destroy(XDR *xdrs);
Una macro que invoca la rutina de destrucción asociada con el flujo XDR, xdrs. La destrucción generalmente implica liberar estructuras de datos privadas asociadas con el flujo. Usar xdrs después de invocar xdr_destroy() no está definido.
bool_t xdr_double(XDR *xdrs, double *dp);
Un filtro primitivo que traduce entre números de doble precisión C y sus representaciones externas. Esta rutina devuelve uno si tiene éxito, cero en caso contrario.
bool_t xdr_enum(XDR *xdrs, enum_t *ep);
Un filtro primitivo que traduce entre enums C (en realidad, enteros) y sus representaciones externas. Esta rutina devuelve uno si tiene éxito, cero en caso contrario.
bool_t xdr_float(XDR *xdrs, float *fp);
Un filtro primitivo que traduce entre floats C y sus representaciones externas. Esta rutina devuelve uno si tiene éxito, cero en caso contrario.
void xdr_free(xdrproc_t proc, char *objp);
Rutina de liberación genérica. El primer argumento es la rutina XDR para el objeto que se está liberando. El segundo argumento es un puntero al objeto en sí. Nota: el puntero pasado a esta rutina no se libera, pero lo que apunta sí se libera (recursivamente).
unsigned int xdr_getpos(XDR *xdrs);
Una macro que invoca la rutina de obtener posición asociada con el flujo XDR, xdrs. La rutina devuelve un entero sin signo, que indica la posición del flujo de bytes XDR. Una característica deseable de los flujos XDR es que la aritmética simple funciona con este número, aunque las instancias de flujo XDR no necesitan garantizar esto.
long *xdr_inline(XDR *xdrs, int len);
Una macro que invoca la rutina en línea asociada con el flujo XDR, xdrs. La rutina devuelve un puntero a una pieza contigua del búfer del flujo; len es la longitud en bytes del búfer deseado. Nota: el puntero se convierte a long *.
Advertencia: xdr_inline() puede devolver NULL (0) si no puede asignar una pieza contigua de un búfer. Por lo tanto, el comportamiento puede variar entre las instancias de flujo; existe por eficiencia.
bool_t xdr_int(XDR *xdrs, int *ip);
Un filtro primitivo que traduce entre enteros C y sus representaciones externas. Esta rutina devuelve uno si tiene éxito, cero en caso contrario.
bool_t xdr_long(XDR *xdrs, long *lp);
Un filtro primitivo que traduce entre enteros long C y sus representaciones externas. Esta rutina devuelve uno si tiene éxito, cero en caso contrario.
void xdrmem_create(XDR *xdrs, char *addr, unsigned int size,
                   enum xdr_op op);
Esta rutina inicializa el objeto de flujo XDR apuntado por xdrs. Los datos del flujo se escriben o leen de un bloque de memoria en la ubicación addr cuya longitud no supera los size bytes. El op determina la dirección del flujo XDR (ya sea XDR_ENCODE, XDR_DECODE o XDR_FREE).
bool_t xdr_opaque(XDR *xdrs, char *cp, unsigned int cnt);
Un filtro primitivo que traduce entre datos opacos de tamaño fijo y su representación externa. El argumento cp es la dirección del objeto opaco y cnt es su tamaño en bytes. Esta rutina devuelve uno si tiene éxito, cero en caso contrario.
bool_t xdr_pointer(XDR *xdrs, char **objpp,
                   unsigned int objsize, xdrproc_t xdrobj);
Similar a xdr_reference() excepto que serializa punteros nulos, mientras que xdr_reference() no lo hace. Por lo tanto, xdr_pointer() puede representar estructuras de datos recursivas, como árboles binarios o listas enlazadas.
void xdrrec_create(XDR *xdrs, unsigned int sendsize,
                   unsigned int recvsize, char *handle,
                   typeof(int (char *, char *, int)) *readit,
                   typeof(int (char *, char *, int)) *writeit);
Esta rutina inicializa el objeto de flujo XDR apuntado por xdrs. Los datos del flujo se escriben en un búfer de tamaño sendsize; un valor de cero indica que el sistema debe usar uno adecuado por defecto. Los datos del flujo se leen de un búfer de tamaño recvsize; este también puede establecerse a un valor adecuado por defecto pasando un valor cero. Cuando el búfer de salida de un flujo está lleno, se llama a writeit. De manera similar, cuando el búfer de entrada de un flujo está vacío, se llama a readit. El comportamiento de estas dos rutinas es similar a las llamadas del sistema read(2) y write(2), excepto que handle se pasa a las rutinas anteriores como el primer argumento. Nota: el campo op del flujo XDR debe ser establecido por el llamador.
Advertencia: para leer desde un flujo XDR creado por esta API, necesitará llamar primero a xdrrec_skiprecord() antes de llamar a cualquier otra API XDR. Esto inserta bytes adicionales en el flujo para proporcionar límites de registro
bool_t xdr_reference(XDR *xdrs, char **pp,
                    unsigned int size, xdrproc_t proc);
Esta rutina se utiliza para serializar estructuras de datos anidadas. El argumento pp es la dirección del puntero al objeto que se está serializando; size es el tamaño del objeto en bytes; proc es el procedimiento XDR apropiado para serializar el objeto.
A diferencia de xdr_pointer(), esta rutina no serializa punteros nulos. Por lo tanto, no puede representar estructuras de datos recursivas que contengan punteros nulos.
bool_t xdr_setpos(XDR *xdrs, unsigned int pos);
Una macro que invoca la rutina de establecer posición asociada con el flujo XDR, xdrs. La rutina establece la posición del flujo de bytes XDR a pos. Esto es útil para retransmitir datos, o para evitar que el flujo de bytes se lea o escriba más allá de un cierto punto.
bool_t xdr_short(XDR *xdrs, short *sp);
Un filtro primitivo que traduce entre enteros short C y sus representaciones externas. Esta rutina devuelve uno si tiene éxito, cero en caso contrario.
bool_t xdr_sizeof(xdrproc_t proc, void *ptr);
Calcula el tamaño en bytes de un objeto serializado dado. El primer argumento es el procedimiento XDR para el objeto, y el segundo argumento es un puntero al objeto.
char *xdr_stream_get_bytes(XDR *xdrs, unsigned int num_bytes);
Esta función está obsoleta y ya no debe usarse. Intenta obtener un puntero a un bloque contiguo de num_bytes de datos del flujo XDR.
bool_t xdr_string(XDR *xdrs, char **sp, unsigned int maxsize);
Un filtro primitivo que traduce entre cadenas de caracteres terminadas en nulo y sus representaciones externas. El argumento sp es la dirección del puntero de la cadena. Las cadenas no pueden tener más de maxsize bytes (incluido el terminador nulo). Esta rutina devuelve uno si tiene éxito, cero en caso contrario.
bool_t xdr_u_char(XDR *xdrs, unsigned char *ucp);
Un filtro primitivo que traduce entre caracteres unsigned char C y sus representaciones externas. Esta rutina devuelve uno si tiene éxito, cero en caso contrario.
bool_t xdr_u_int(XDR *xdrs, unsigned int *uip);
Un filtro primitivo que traduce entre enteros unsigned int C y sus representaciones externas. Esta rutina devuelve uno si tiene éxito, cero en caso contrario.
bool_t xdr_u_long(XDR *xdrs, unsigned long *ulp);
Un filtro primitivo que traduce entre enteros unsigned long C y sus representaciones externas. Esta rutina devuelve uno si tiene éxito, cero en caso contrario.
bool_t xdr_u_quadruple(XDR *xdrs, unsigned long long *uq);
Un filtro primitivo que traduce entre enteros unsigned long long C y sus representaciones externas. Esta rutina devuelve uno si tiene éxito, cero en caso contrario.
bool_t xdr_u_hyper(XDR *xdrs, unsigned long long *uhp);
Un filtro primitivo que traduce entre enteros unsigned long long C y sus representaciones externas. Esta rutina devuelve uno si tiene éxito, cero en caso contrario.
bool_t xdr_void(void);
Este filtro no hace nada y se utiliza para funciones que no toman ningún argumento.
bool_t xdr_wrapstring(XDR *xdrs, char **sp);
Similar a xdr_string(), pero también maneja la asignación y liberación de memoria para la cadena. El puntero sp apunta a un puntero de cadena. Si el puntero de cadena es NULL, se asigna memoria para la cadena. Si el puntero de cadena no es NULL, se utiliza la memoria existente. Esta rutina devuelve uno si tiene éxito, cero en caso contrario.

Servicios de control de bibliotecas (librtpc)

SINOPSIS Y DESCRIPCIÓN

Las rutinas XDR son la base de la serialización y deserialización de datos utilizada por el Remote Procedure Call (RPC) de Sun Microsystems. El RPC es un framework que permite que un programa ejecute código en una máquina remota como si se estuviera ejecutando localmente. XDR se utiliza para transformar estructuras de datos C en una representación estándar independiente de la máquina para su transmisión a través de una red, y luego para transformar estos datos de nuevo en la representación C nativa en la máquina receptora. El sistema RPC define una serie de tipos de datos primitivos, y estas rutinas operan sobre ellos.

bool_t xdr_array(XDR *xdrs, char **pp, unsigned int *sizep,
                 unsigned int maxsize, xdrproc_t xdr_element,
                 xdrproc_t xdr_ ƯCLN);
Una primitiva que traduce entre arreglos C y sus representaciones externas correspondientes. El argumento pp es la dirección del puntero al arreglo, mientras que sizep es la dirección del tamaño del arreglo. El argumento maxsize es el número máximo de elementos que el arreglo puede contener. El argumento xdr_element es un filtro XDR que traduce entre los elementos del arreglo en su forma C y su representación externa. El argumento xdr_ ƯCLN es un filtro XDR que se usa para liberar los elementos del arreglo. Esta rutina devuelve uno si tiene éxito, cero en caso contrario.
bool_t xdr_bool(XDR *xdrs, bool_t *bp);
Una primitiva que traduce entre un booleano C y su representación externa. Esto devuelve uno si tiene éxito, cero en caso contrario.
bool_t xdr_bytes(XDR *xdrs, char **sp, unsigned int *lenp,
                 unsigned int maxsize);
Una primitiva que traduce entre arreglos de bytes y sus representaciones externas. Los arreglos de bytes se representan como una longitud seguida de los bytes. El argumento sp es la dirección del puntero a los bytes, mientras que lenp es la dirección de la longitud de los bytes. El argumento maxsize es el tamaño máximo permitido para el arreglo. Esta rutina devuelve uno si tiene éxito, cero en caso contrario.
bool_t xdr_char(XDR *xdrs, char *cp);
Una primitiva que traduce entre caracteres C y sus representaciones externas. Esta rutina devuelve uno si tiene éxito, cero en caso contrario.
void xdr_destroy(XDR *xdrs);
Libera los recursos asociados con el objeto de flujo XDR xdrs.
bool_t xdr_double(XDR *xdrs, double *dp);
Una primitiva que traduce entre enteros dobles C y sus representaciones externas. Esta rutina devuelve uno si tiene éxito, cero en caso contrario.
bool_t xdr_enum(XDR *xdrs, enum_t *ep);
Una primitiva que traduce entre enumeraciones C y sus representaciones externas. El argumento ep es un puntero a la enumeración C. Esta rutina devuelve uno si tiene éxito, cero en caso contrario.
bool_t xdr_float(XDR *xdrs, float *fp);
Una primitiva que traduce entre flotantes C y sus representaciones externas. Esta rutina devuelve uno si tiene éxito, cero en caso contrario.
void xdr_free(xdrproc_t proc, char *ptr);
Libera la memoria asignada para la estructura de datos XDR filtrada por proc. El argumento ptr es un puntero a la estructura de datos a liberar.
unsigned int xdr_getpos(XDR *xdrs);
Una macro que invoca la rutina de obtención de posición asociada con el flujo XDR xdrs. Devuelve la posición actual del flujo. Tenga en cuenta que no todos los tipos de flujos XDR admiten la obtención de posición.
char *xdr_inline(XDR *xdrs, unsigned int len);
Una primitiva que devuelve un puntero a un búfer en línea de longitud len. Este búfer se puede usar para almacenar datos XDR directamente. Si no hay un búfer en línea disponible, devuelve NULL. Si se utiliza para decodificar datos, los datos se copian en el búfer devuelto. Si se utiliza para codificar datos, los datos se escribirán en el búfer devuelto. El llamador es responsable de asegurarse de que los datos se escriban en el búfer antes de que se llame a la siguiente operación XDR.
bool_t xdr_int(XDR *xdrs, int *ip);
Una primitiva que traduce entre enteros con signo C y sus representaciones externas. Esta rutina devuelve uno si tiene éxito, cero en caso contrario.
bool_t xdr_long(XDR *xdrs, long *lp);
Una primitiva que traduce entre enteros largos con signo C y sus representaciones externas. Esta rutina devuelve uno si tiene éxito, cero en caso contrario.
void xdrmem_create(XDR *xdrs, const char *addr, unsigned int len,
                   enum xdr_op op);
Inicializa el objeto de flujo XDR xdrs para operar en la memoria. El flujo XDR leerá o escribirá desde el búfer de memoria en addr con una longitud de len. El argumento op determina la dirección del flujo XDR (XDR_ENCODE, XDR_DECODE o XDR_FREE).
bool_t xdr_opaque(XDR *xdrs, const char *cp, unsigned int size);
Una primitiva que traduce entre datos opacos de longitud fija y sus representaciones externas. El argumento cp es un puntero a los datos, y size es el número de bytes a traducir. Esta rutina devuelve uno si tiene éxito, cero en caso contrario.
bool_t xdr_pointer(XDR *xdrs, char **pp, unsigned int size,
                   xdrproc_t proc);
Una primitiva que proporciona seguimiento de punteros dentro de estructuras. El argumento pp es la dirección del puntero; size es el tamaño de la estructura a la que apunta *pp; y proc es un procedimiento XDR que filtra la estructura entre su forma C y su representación externa. Esta rutina devuelve uno si tiene éxito, cero en caso contrario.
Esta rutina maneja punteros NULL, a diferencia de xdr_reference().
bool_t xdrrec_create(XDR *xdrs, unsigned int hwm,
                     unsigned int maxsize, FILE *file,
                     bool_t (*readit)(char *, int),
                     bool_t (*writeit)(char *, int));
Esta rutina inicializa el flujo XDR xdrs para usar el protocolo de registro XDR. El protocolo de registro XDR está diseñado para manejar streams de bytes de forma fiable, añadiendo límites de registro para evitar la fragmentación de mensajes en la capa de transporte. Los argumentos hwm y maxsize son la marca de agua alta y el tamaño máximo del búfer de salida. El argumento file es un puntero a un objeto FILE si el flujo de entrada/salida se basa en flujos estándar de E/S. De lo contrario, los argumentos readit y writeit son punteros a funciones personalizadas de lectura y escritura, respectivamente. Estas funciones personalizadas deben devolver 1 si la operación de lectura/escritura tiene éxito, y 0 en caso contrario. La rutina devuelve 1 si tiene éxito, 0 en caso contrario.
Las rutinas de creación XDR, como xdrstdio_create() y xdrmem_create(), son específicas del tipo de flujo XDR que crean. Sin embargo, los flujos XDR creados por xdrrec_create() son recíprocamente compatibles solo con otras rutinas de registro XDR. En particular, los flujos XDR creados con diferentes 
xdr_*
APIs no son compatibles por la misma razón.
bool_t xdrrec_endofrecord(XDR *xdrs, int sendnow);
Esta rutina solo se puede invocar en flujos creados por xdrrec_create(). Los datos en el búfer de salida se marcan como un registro completado, y el búfer de salida se escribe opcionalmente si sendnow es distinto de cero. Esta rutina devuelve uno si tiene éxito, cero en caso contrario.
bool_t xdrrec_eof(XDR *xdrs);
Esta rutina solo se puede invocar en flujos creados por xdrrec_create(). Después de consumir el resto del registro actual en el flujo, esta rutina devuelve uno si el flujo no tiene más entrada, cero en caso contrario.
bool_t xdrrec_skiprecord(XDR *xdrs);
Esta rutina solo se puede invocar en flujos creados por xdrrec_create(). Indica a la implementación XDR que el resto del registro actual en el búfer de entrada del flujo debe ser descartado. Esta rutina devuelve uno si tiene éxito, cero en caso contrario.
bool_t xdr_reference(XDR *xdrs, char **pp, unsigned int size,
                     xdrproc_t proc);
Una primitiva que proporciona seguimiento de punteros dentro de estructuras. El argumento pp es la dirección del puntero; size es el tamaño de la estructura a la que apunta *pp; y proc es un procedimiento XDR que filtra la estructura entre su forma C y su representación externa. Esta rutina devuelve uno si tiene éxito, cero en caso contrario.
Advertencia: esta rutina no comprende los punteros NULL. Use xdr_pointer() en su lugar.
xdr_setpos(XDR *xdrs, unsigned int pos);
Una macro que invoca la rutina de establecimiento de posición asociada con el flujo XDR xdrs. El argumento pos es un valor de posición obtenido de xdr_getpos(). Esta rutina devuelve uno si el flujo XDR pudo ser reposicionado, y cero en caso contrario.
Advertencia: es difícil reposicionar algunos tipos de flujos XDR, por lo que esta rutina puede fallar con un tipo de flujo y tener éxito con otro.
bool_t xdr_short(XDR *xdrs, short *sp);
Una primitiva de filtro que traduce entre enteros short C y sus representaciones externas. Esta rutina devuelve uno si tiene éxito, cero en caso contrario.
void xdrstdio_create(XDR *xdrs, FILE *file, enum xdr_op op);
Esta rutina inicializa el objeto de flujo XDR apuntado por xdrs. Los datos del flujo XDR se escriben o leen del flujo stdio file. El argumento op determina la dirección del flujo XDR (ya sea XDR_ENCODE, XDR_DECODE o XDR_FREE).
Advertencia: la rutina de destrucción asociada con dichos flujos XDR llama a fflush(3) en el flujo file, pero nunca a fclose(3).
bool_t xdr_string(XDR *xdrs, char **sp, unsigned int maxsize);
Una primitiva de filtro que traduce entre cadenas C y sus representaciones externas correspondientes. Las cadenas no pueden tener una longitud mayor que maxsize. Nota: sp es la dirección del puntero de la cadena. Esta rutina devuelve uno si tiene éxito, cero en caso contrario.
bool_t xdr_u_char(XDR *xdrs, unsigned char *ucp);
Una primitiva de filtro que traduce entre caracteres C sin signo y sus representaciones externas. Esta rutina devuelve uno si tiene éxito, cero en caso contrario.
bool_t xdr_u_int(XDR *xdrs, unsigned int *up);
Una primitiva de filtro que traduce entre enteros sin signo C y sus representaciones externas. Esta rutina devuelve uno si tiene éxito, cero en caso contrario.
bool_t xdr_u_long(XDR *xdrs, unsigned long *ulp);
Una primitiva de filtro que traduce entre enteros largos sin signo C y sus representaciones externas. Esta rutina devuelve uno si tiene éxito, cero en caso contrario.
bool_t xdr_u_short(XDR *xdrs, unsigned short *usp);
Una primitiva de filtro que traduce entre enteros cortos sin signo C y sus representaciones externas. Esta rutina devuelve uno si tiene éxito, cero en caso contrario.
bool_t xdr_union(XDR *xdrs, enum_t *dscmp, char *unp,
                 const struct xdr_discrim *choices,
                 xdrproc_t defaultarm);     /* puede ser NULL */
Una primitiva de filtro que traduce entre una union C discriminada y su representación externa correspondiente. Primero traduce el discriminador de la unión ubicado en dscmp. Este discriminador es siempre un enum_t. A continuación, se traduce la unión ubicada en unp. El argumento choices es un puntero a una matriz de estructuras xdr_discrim(). Cada estructura contiene un par ordenado de [valor,proc]. Si el discriminador de la unión es igual al valor asociado, entonces se llama a proc para traducir la unión. El final de la matriz de estructuras xdr_discrim() se denota por una rutina de valor NULL. Si el discriminador no se encuentra en la matriz choices, entonces se llama al procedimiento defaultarm (si no es NULL). Devuelve uno si tiene éxito, cero en caso contrario.
bool_t xdr_vector(XDR *xdrs, char *arrp, unsigned int size,
                  unsigned int elsize, xdrproc_t elproc);
Una primitiva de filtro que traduce entre arreglos de longitud fija y sus representaciones externas correspondientes. El argumento arrp es la dirección del puntero al arreglo, mientras que size es el conteo de elementos del arreglo. El argumento elsize es el tamaño de cada uno de los elementos del arreglo, y elproc es un filtro XDR que traduce entre la forma C de los elementos del arreglo y su representación externa. Esta rutina devuelve uno si tiene éxito, cero en caso contrario.
bool_t xdr_void(void);
Esta rutina siempre devuelve uno. Puede pasarse a rutinas RPC que requieran un argumento de función, donde no se debe hacer nada.
bool_t xdr_wrapstring(XDR *xdrs, char **sp);
Una primitiva que llama a xdr_string(xdrs, sp,MAXUN.UNSIGNED ); donde MAXUN.UNSIGNED es el valor máximo de un entero sin signo. xdr_wrapstring() es útil porque el paquete RPC pasa un máximo de dos rutinas XDR como argumentos, y xdr_string(), una de las primitivas más utilizadas, requiere tres. Devuelve uno si tiene éxito, cero en caso contrario.
