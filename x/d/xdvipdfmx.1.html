DVIPDFMX(1) Manual de Comandos Generales DVIPDFMX(1)

NOMBRE

dvipdfmx, xdvipdfmx, dvipdfm - produce archivos PDF directamente desde archivos DVI

SINOPSIS

dvipdfmx o dvipdfm [opciones] archivo[.dvi]

DESCRIPCIÓN

El programa dvipdfmx genera un archivo PDF a partir de un archivo DVI. Los archivos DVI son la salida producida por TeX. groff también puede generar archivos DVI utilizando grodvi(-Tdvi).

En TeX Live, dvipdfm es otra encarnación de dvipdfmx en lugar de un programa separado. Se intenta mantener la compatibilidad en la medida de lo posible.

xdvipdfmx es otra encarnación. Se utiliza como backend para xetex(1) y no está destinado a ser invocado directamente.

dvipdfmx reconoce varios comandos \special comúnmente utilizados, que son extensiones al formato DVI. Específicamente, comprende especiales de color, especiales de tamaño de papel, especiales de tpic (que le permiten ser utilizado con pic), especiales de hypertex, y algunos especiales de PostScript. Estas extensiones permiten que los documentos contengan color, figuras y enlaces. El programa intenta imitar el comportamiento de dvips siempre que sea posible, de modo que muchos paquetes de macros producidos para su uso con dvips también funcionarán con dvipdfmx. Además, dvipdfmx comprende sus propios comandos \special específicos para permitir el acceso a funciones de PDF como anotaciones y marcadores.

A partir de diciembre de 2018, un especial específico para dvipdfmx es pdf:trailerid, que especifica el /ID en el trailer de PDF. Se utiliza de la siguiente manera (desde el nivel de TeX):
\special{pdf:trailerid [ (0123456789abcdef) (01234567890abcdef) ]}
Es decir, el especial toma una matriz (los corchetes) de dos cadenas PDF de 16 bytes (los paréntesis). Esta es la misma sintaxis que la de LuaTeX \pdfvariable trailerid, mientras que es diferente de la de pdfTeX \pdftrailerid. Debe aparecer en la primera página de salida, de lo contrario se ignora.

Los especiales no reconocidos generarán mensajes de advertencia. Los paquetes que puedan necesitar una opción de driver dvipdfm o dvipdfmx incluyen geometry, hyperref, bookmark, graphicx y xcolor.

Para cuestiones relacionadas con los cuadros delimitadores (y, por lo tanto, con los tamaños de imagen), consulte extractbb(1).

OPCIONES

A diferencia de muchos otros programas, los valores de los argumentos deben separarse de los nombres de las opciones con un espacio, no con un signo =; los nombres de las opciones no pueden abreviarse; y no se pueden usar - ni -- indistintamente.

-c
Ignora (o acepta) los \specials de color. Por defecto, los \special de color se interpretan normalmente (modificable en el archivo de configuración). La opción -c puede utilizarse para producir un documento en blanco y negro a partir de un documento que contiene comandos \special de TeX en color.
--dvipdfm
Habilita el modo de emulación dvipdfm. Este es el valor predeterminado si el nombre del ejecutable es `dvipdfm'.
-d número
Especifica el número de dígitos decimales en la salida PDF; debe estar entre 0 y 5, el valor predeterminado es 2.
-e
Ignorado, para compatibilidad (semi-) con dvipdfm.
-f archivo_mapa
Lee el archivo de mapa de fuentes dado por archivo_mapa. El archivo de mapa predeterminado en TeX Live es pdftex.map, como se define en el archivo de configuración.
--help
Muestra un mensaje de ayuda y sale con éxito.
-i archivo_cfg
Lee archivo_cfg como otro archivo de inclusión, después de leer el archivo predeterminado dvipdfmx.cfg.
--kpathsea-debug número
Hace que Kpathsea imprima información de depuración; `-1' para todo (voluminoso).
-l
Selecciona el modo horizontal (landscape). En otras palabras, intercambia las dimensiones x e y del papel.
-m mag
Magnifica el documento de entrada por mag.
-o nombre_archivo
Establece el nombre del archivo de salida PDF; use `-' para stdout. Por defecto, el nombre del archivo de salida se deriva de la entrada, es decir, archivo.pdf.
-p papel
Selecciona el tamaño del papel por nombre (por ejemplo, letter, legal, ledger, tabloid, a3, a4, o a5 )
--pdfm-str-utf8
Asume que las cadenas PDFMark en los comandos \special están codificadas en UTF-8.
-q
Modo silencioso.
-r tamaño
Establece la resolución de las fuentes de mapa de bits a tamaño puntos por pulgada. Las fuentes de mapa de bits son generadas por la biblioteca Kpathsea, que utiliza Metafont. Las fuentes de mapa de bits se incluyen como fuentes de Tipo 3 en el archivo de salida PDF. El valor predeterminado es 600.
-s especificaciones_pagina
Selecciona las páginas del archivo DVI a procesar; el valor predeterminado es `-', lo que significa todas las páginas. Las especificaciones_pagina consisten en una lista separada por comas de rangos_de_pagina: 
especificaciones_pagina := especificacion_pagina[,especificaciones_pagina]
donde 
especificacion_pagina := pagina_unica|rango_de_pagina
rango_de_pagina := [pagina_primera]-[pagina_ultima]
Una pagina_primera vacía se trata como la primera página del archivo DVI, y una pagina_ultima vacía se trata como la última página del archivo DVI.

Ejemplos:

-s 1,3,5
incluye las páginas 1, 3 y 5;
-s -
incluye todas las páginas;
-s -,-
incluye dos copias de todas las páginas del archivo DVI; y
-s 1-10
incluye las primeras diez páginas del archivo DVI.
-t
Busca imágenes en miniatura de cada página en el directorio llamado por la variable de entorno TMPDIR. Las imágenes en miniatura deben nombrarse en un formato específico: el mismo nombre base que el archivo DVI y el número de página como extensión del nombre del archivo. dvipdfmx no genera estas miniaturas por sí mismo, pero se distribuye con un programa envoltorio llamado dvipdft que lo hace.
--version
Muestra un mensaje de ayuda y sale con éxito.
-v
Aumenta la verbosidad. Los resultados de la opción -v son acumulativos (por ejemplo, -vv aumenta la verbosidad en dos incrementos). La verbosidad máxima es cuatro.
-x offset_x
Establece el margen izquierdo a offset_x. El margen izquierdo predeterminado es 1.0in. La dimensión puede especificarse en cualquier unidad comprendida por TeX (por ejemplo, bp, pt, in, cm).
-y offset_y
Establece el margen superior a offset_y. El margen superior predeterminado es 1.0in. La dimensión puede especificarse en cualquier unidad comprendida por TeX (por ejemplo, bpt, pt, in, cm).
-z número
Establece el nivel de compresión a nivel_compresion. Los niveles de compresión van desde 0 (sin compresión) hasta 9 (compresión máxima) y corresponden a los valores comprendidos por zlib; el valor predeterminado es 9.
-C número
Indicadores de opciones misceláneos; consulte la salida de --help para obtener detalles.
-D plantilla
Plantilla de línea de comandos para la conversión de PostScript a PDF; el valor predeterminado se toma del archivo de configuración, que también proporciona todos los detalles y menciona varias posibilidades.
-E
Intenta siempre incrustar fuentes, ignorando las licencias, etc.
-I número
Vida útil de la caché de imágenes en horas; el valor predeterminado es -2, lo que significa no almacenar en caché imágenes en absoluto. Un valor de -1 significa borrar todas las imágenes antiguas y

IMAGE BOUNDING BOXES

When including images with dvipdfmx, their bounding boxes should be generated by running extractbb. The result will be in an .xbb file; the xbb information is the same as for the PDF format.

ENVIRONMENT

dvipdfmx uses the kpathsea library for locating the files that it opens. Hence, the environment variables documented in the Kpathsea library documentation influence dvipdfmx. It also uses the value of the environment variable TMPDIR as the directory to search for thumbnail images of each page.

FILES

The precise location of the following files is determined by the Kpathsea library configuration. The location may be determined by using kpsewhich, e.g.,

kpsewhich -progname=dvipdfmx -format='other text files' dvipdfmx.cfg
dvipdfmx.cfg
Default configuration file
dvipdfmx-unsafe.cfg
Configuration file that runs Ghostscript without safety checks; use only for trusted source files. It is currently required to use PSTricks with XeTeX: xetex -output-driver="xdvipdfmx -i dvipdfmx-unsafe.cfg -q -E" ...
pdftex.map
The default font map file (this may be changed in the config file).
*.tfm
TeX font metrics
*.vf
TeX virtual font files
*.pfb
PostScript Type 1 font files
texmf.cnf
The Kpathsea library configuration file. The location of this file may be found by typing 
kpsewhich texmf.cnf
