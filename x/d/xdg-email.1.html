NOMBRE

xdg-email - herramienta de línea de comandos para enviar correos electrónicos utilizando el compositor de correo electrónico preferido del usuario

SINOPSIS

xdg-email [--utf8] [--cc dirección] [--bcc dirección] [--subject texto] [--body texto] [--attach archivo] [uri-mailto | dirección(es)]

xdg-email {--help | --manual | --version}

DESCRIPCIÓN

xdg-email abre el compositor de correo electrónico preferido del usuario para enviar un correo a dirección(es) o uri-mailto. RFC2368 define las URIs mailto:. xdg-email limita el soporte a los campos para, cc, asunto y cuerpo en uri-mailto, todos los demás campos se ignoran silenciosamente. dirección(es) deben seguir la sintaxis de RFC822. Se pueden proporcionar varias direcciones como argumentos separados.

Toda la información proporcionada en la línea de comandos se utiliza para prellenar los campos correspondientes en el compositor de correo electrónico del usuario. El usuario tendrá la oportunidad de cambiar cualquiera de esta información antes de enviar realmente el correo electrónico.

xdg-email es para uso exclusivo dentro de una sesión de escritorio. No se recomienda usar xdg-email como root.

OPCIONES

--utf8

Indica que todas las opciones de línea de comandos que siguen están en utf8. Sin esta opción, se espera que las opciones de línea de comandos estén codificadas según la configuración regional. Si la configuración regional ya especifica utf8, esta opción no tiene ningún efecto. Esta opción no afecta a las URIs mailto que se pasan en la línea de comandos.

--cc dirección

Especifica un destinatario al que se enviará una copia del correo electrónico.

--bcc dirección

Especifica un destinatario al que se enviará una copia oculta del correo electrónico.

--subject texto

Especifica un asunto para el correo electrónico.

--body texto

Especifica un cuerpo para el correo electrónico. Dado que el usuario podrá realizar cambios antes de enviar realmente el correo electrónico, esto se puede utilizar para proporcionar al usuario una plantilla para el correo electrónico. texto puede contener saltos de línea.

--attach archivo

Especifica un archivo adjunto para el correo electrónico. archivo debe apuntar a un archivo existente.

Algunas aplicaciones de correo electrónico requieren que el archivo permanezca presente después de que xdg-email regrese.

--help

Muestra la sinopsis del comando.

--manual

Muestra esta página del manual.

--version

Muestra la información de la versión de xdg-utils.

VARIABLES DE ENTORNO

xdg-email respeta las siguientes variables de entorno:

XDG_UTILS_DEBUG_LEVEL

Establecer esta variable de entorno a un valor numérico distinto de cero hace que xdg-email informe de forma más detallada en stderr. Establecer un valor más alto aumenta la verbosidad.

CÓDIGOS DE SALIDA

Un código de salida de 0 indica éxito, mientras que un código de salida distinto de cero indica fallo. Los siguientes códigos de fallo pueden ser devueltos:

1

Error en la sintaxis de la línea de comandos.

2

Uno de los archivos pasados en la línea de comandos no existía.

3

No se pudo encontrar una herramienta requerida.

4

La acción falló.

5

No hay permiso para leer uno de los archivos pasados en la línea de comandos.

VER TAMBIÉN

xdg-open(1), xdg-mime(1), Especificación de asociaciones de aplicaciones MIME[1], RFC 6068 - El esquema URI 'mailto'[2]

EJEMPLOS

xdg-email 'Jeremy White <jwhite@example.com>'
xdg-email --attach /tmp/logo.png \
          --subject 'Concurso de logo' \
          --body 'Adjunto encontrarás el logo para el concurso.' \
          'jwhite@example.com'
xdg-email --subject 'Tu contraseña está a punto de expirar' \
          'jwhite@example.com' 'bastian@example.com' 'whipple@example.com'
