NOMBRE

xdpr - volcar una ventana X directamente a una impresora

SINOPSIS

xdpr [ nombre_archivo ] [ -display host:display ] [ -Pimpresora ] [ -device tipo_dispositivo ] [ opción ... ]

DESCRIPCIÓN

Xdpr utiliza los comandos xwd, xpr, y lpr o lp para volcar una ventana X, procesarla para un tipo de impresora específico e imprimirla en la impresora de su elección. Esta es la forma más sencilla de obtener una impresión de una ventana. Xdpr por defecto imprimirá la representación más grande posible de la ventana en la página de salida.

Las opciones para xdpr son las mismas que las de xpr, xwd, y lpr o lp. Las opciones más comunes se describen a continuación; consulte las páginas del manual de estos comandos para obtener descripciones más detalladas de las muchas opciones disponibles.

OPCIONES

nombre_archivo
Especifica un archivo que contiene un volcado de ventana (creado por xwd) para imprimir en lugar de seleccionar una ventana X.
-Pimpresora
Especifica una impresora a la que enviar la salida. Si no se especifica un nombre de impresora aquí, xdpr (en realidad, lpr o lp) enviará su salida a la impresora especificada por la variable de entorno PRINTER. Asegúrese de que el tipo de la impresora coincida con el tipo especificado con la opción -device.
-display host:display[.screen]
Normalmente, xdpr obtiene el host y el número de pantalla a usar de la variable de entorno ``DISPLAY''. Sin embargo, se pueden especificar explícitamente; consulte X(7).
-device tipo_dispositivo
Especifica el dispositivo en el que se imprimirá el archivo. Actualmente soportados:
ljet
HP LaserJet series y otros dispositivos PCL monocromáticos como ThinkJet, QuietJet, RuggedWriter, HP2560 series y HP 2930 series.
pjet
HP PaintJet (modo color)
pjetxl
Impresora HP PaintJet XL Color Graphics (modo color)
pp
IBM PP3812
ps
Impresora PostScript
El valor predeterminado es PostScript. -device lw (LaserWriter) es equivalente a -device ps y se proporciona solo por compatibilidad con versiones anteriores.
-help
Esta opción muestra la lista de opciones conocidas por xdpr.

Cualquier otro argumento se pasará a los comandos xwd, xpr, y lpr o lp según corresponda para cada uno.

AMBIENTE
