xdr(3) Manual de Funciones de Biblioteca xdr(3)

NOMBRE

xdr — rutinas de biblioteca para la representación externa de datos

BIBLIOTECA

Biblioteca estándar de C (libc, -lc)

SINOPSIS Y DESCRIPCIÓN

Estas rutinas permiten a los programadores de C describir estructuras de datos arbitrarias de una manera independiente de la máquina. Los datos para las llamadas a procedimientos remotos se transmiten utilizando estas rutinas.

Los prototipos a continuación se declaran en <rpc/xdr.h> y hacen uso de los siguientes tipos:

typedef int bool_t;
typedef typeof(bool_t (XDR *, void *, ...))  *xdrproc_t;

Para la declaración del tipo XDR, consulte <rpc/xdr.h>.

bool_t xdr_array(XDR *xdrs, char **arrp, unsigned int *sizep,
                 unsigned int maxsize, unsigned int elsize,
                 xdrproc_t elproc);
Un filtro primitivo que traduce entre arrays de longitud variable y sus representaciones externas correspondientes. El argumento arrp es la dirección del puntero al array, mientras que sizep es la dirección del contador de elementos del array; este contador de elementos no puede exceder maxsize. El argumento elsize es el sizeof de cada uno de los elementos del array, y elproc es un filtro XDR que traduce entre la forma C de los elementos del array y su representación externa. Esta rutina devuelve uno si tiene éxito, cero en caso contrario.
bool_t xdr_bool(XDR *xdrs, bool_t *bp);
Un filtro primitivo que traduce entre booleanos (enteros C) y sus representaciones externas. Al codificar datos, este filtro produce valores de uno o cero. Esta rutina devuelve uno si tiene éxito, cero en caso contrario.
bool_t xdr_bytes(XDR *xdrs, char **sp, unsigned int *sizep,
                 unsigned int maxsize);
Un filtro primitivo que traduce entre cadenas de bytes contadas y sus representaciones externas. El argumento sp es la dirección del puntero a la cadena. La longitud de la cadena se encuentra en la dirección sizep; las cadenas no pueden ser más largas que maxsize. Esta rutina devuelve uno si tiene éxito, cero en caso contrario.
bool_t xdr_char(XDR *xdrs, char *cp);
Un filtro primitivo que traduce entre caracteres C y sus representaciones externas. Esta rutina devuelve uno si tiene éxito, cero en caso contrario. Nota: los caracteres codificados no están empaquetados y ocupan 4 bytes cada uno. Para arrays de caracteres, vale la pena considerar xdr_bytes(), xdr_opaque(), o xdr_string().
void xdr_destroy(XDR *xdrs);
Una macro que invoca la rutina de destrucción asociada con el flujo XDR, xdrs. La destrucción normalmente implica la liberación de estructuras de datos privadas asociadas con el flujo. Usar xdrs después de invocar xdr_destroy() no está definido.
bool_t xdr_double(XDR *xdrs, double *dp);
Un filtro primitivo que traduce entre números de punto flotante de doble precisión C y sus representaciones externas. Esta rutina devuelve uno si tiene éxito, cero en caso contrario.
bool_t xdr_enum(XDR *xdrs, enum_t *ep);
Un filtro primitivo que traduce entre enumeraciones C (en realidad, enteros) y sus representaciones externas. Esta rutina devuelve uno si tiene éxito, cero en caso contrario.
bool_t xdr_float(XDR *xdrs, float *fp);
Un filtro primitivo que traduce entre números de punto flotante C y sus representaciones externas. Esta rutina devuelve uno si tiene éxito, cero en caso contrario.
void xdr_free(xdrproc_t proc, char *objp);
Rutina de liberación genérica. El primer argumento es la rutina XDR para el objeto que se está liberando. El segundo argumento es un puntero al objeto en sí. Nota: el puntero pasado a esta rutina no se libera, pero lo que apunta sí se libera (recursivamente).
unsigned int xdr_getpos(XDR *xdrs);
Una macro que invoca la rutina de obtención de posición asociada con el flujo XDR, xdrs. La rutina devuelve un entero sin signo, que indica la posición del flujo de bytes XDR. Una característica deseable de los flujos XDR es que la aritmética simple funcione con este número, aunque las instancias de flujo XDR no necesitan garantizar esto.
long *xdr_inline(XDR *xdrs, int len);
Una macro que invoca la rutina en línea asociada con el flujo XDR, xdrs. La rutina devuelve un puntero a una pieza contigua del búfer del flujo; len es la longitud en bytes del búfer deseado. Nota: el puntero se convierte a long *.
Advertencia: xdr_inline() puede devolver NULL (0) si no puede asignar una pieza contigua de un búfer. Por lo tanto, el comportamiento puede variar entre las instancias de flujo; existe por motivos de eficiencia.
bool_t xdr_int(XDR *xdrs, int *ip);
Un filtro primitivo que traduce entre enteros C y sus representaciones externas. Esta rutina devuelve uno si tiene éxito, cero en caso contrario.
bool_t xdr_long(XDR *xdrs, long *lp);
Un filtro primitivo que traduce entre enteros long C y sus representaciones externas. Esta rutina devuelve uno si tiene éxito, cero en caso contrario.
void xdrmem_create(XDR *xdrs, char *addr, unsigned int size,
                   enum xdr_op op);
Esta rutina inicializa el objeto de flujo XDR apuntado por xdrs. Los datos del flujo se escriben o leen de un bloque de memoria en la ubicación addr cuya longitud no excede los size bytes. El op determina la dirección del flujo XDR (ya sea XDR_ENCODE, XDR_DECODE, o XDR_FREE).
bool_t xdr_opaque(XDR *xdrs, char *cp, unsigned int cnt);
Un filtro primitivo que traduce entre datos opacos de tamaño fijo y su representación externa. El argumento cp es la dirección del objeto opaco y cnt es su tamaño en bytes. Esta rutina devuelve uno si tiene éxito, cero en caso contrario.
bool_t xdr_pointer(XDR *xdrs, char **objpp,
                   unsigned int objsize, xdrproc_t xdrobj);
Similar a xdr_reference() excepto que serializa punteros nulos, mientras que xdr_reference() no lo hace. Por lo tanto, xdr_pointer() puede representar estructuras de datos recursivas, como árboles binarios o listas enlazadas.
void xdrrec_create(XDR *xdrs, unsigned int sendsize,
                   unsigned int recvsize, char *handle,
                   typeof(int (char *, char *, int)) *readit,
                   typeof(int (char *, char *, int)) *writeit);
Esta rutina inicializa el objeto de flujo XDR apuntado por xdrs. Los datos del flujo se escriben en un búfer de tamaño sendsize; un valor de cero indica que el sistema debe usar uno adecuado por defecto. Los datos del flujo se leen de un búfer de tamaño recvsize; este también se puede establecer a un valor adecuado por defecto pasando un valor cero. Cuando el búfer de salida de un flujo está lleno, se llama a writeit. De manera similar, cuando el búfer de entrada de un flujo está vacío, se llama a readit. El comportamiento de estas dos rutinas es similar a las llamadas al sistema read(2) y write(2), excepto que handle se pasa a las rutinas anteriores como primer argumento. Nota: el campo op del flujo XDR debe ser establecido por el llamador.
Advertencia: para leer de un flujo XDR creado por esta API, necesitará llamar a xdrrec_skiprecord() primero antes de llamar a cualquier otra API XDR. Esto inserta bytes adicionales en el flujo para proporcionar límites de registro.
bool_t xdrrec_skiprecord(XDR *xdrs);
Esta rutina se utiliza para leer un nuevo registro de un flujo XDR recíproco. Si el flujo está en el límite de un registro, no hace nada. Si el flujo está dentro de un registro, entonces descarta el resto del registro actual y se posiciona al principio del siguiente registro. Devuelve uno si tiene éxito, cero en caso contrario.
bool_t xdr_reference(XDR *xdrs, char **pp,
                     unsigned int size, xdrproc_t proc);
Un filtro primitivo que serializa referencias a objetos. El argumento pp es la dirección del puntero al objeto que se va a serializar, size es el tamaño de ese objeto, y proc es el procedimiento XDR para serializar el objeto. Esta rutina es útil para serializar estructuras de datos complejas y anidadas. Devuelve uno si tiene éxito, cero en caso contrario.
bool_t xdr_short(XDR *xdrs, short *sp);
Un filtro primitivo que traduce entre enteros cortos C y sus representaciones externas. Esta rutina devuelve uno si tiene éxito, cero en caso contrario.
char *xdr_sizeof(xdrproc_t proc, char *objp);
Devuelve el tamaño en bytes de la representación externa del objeto apuntado por objp. El argumento proc es el procedimiento XDR para serializar el objeto. Si no se puede determinar el tamaño, devuelve (char *) -1.
bool_t xdr_string(XDR *xdrs, char **sp, unsigned int maxsize);
Un filtro primitivo que traduce entre cadenas de C terminadas en nulo y sus representaciones externas. El argumento sp es la dirección del puntero a la cadena; las cadenas no pueden ser más largas que maxsize. Esta rutina devuelve uno si tiene éxito, cero en caso contrario.
bool_t xdr_u_int32_t(XDR *xdrs, u_int32_t *uip);
Similar a xdr_int() pero para enteros de 32 bits sin signo. Devuelve uno si tiene éxito, cero en caso contrario.
bool_t xdr_u_int64_t(XDR *xdrs, u_int64_t *uip);
Similar a xdr_long() pero para enteros de 64 bits sin signo. Devuelve uno si tiene éxito, cero en caso contrario.
bool_t xdr_u_long(XDR *xdrs, unsigned long *ulp);
Un filtro primitivo que traduce entre enteros unsigned long C y sus representaciones externas. Esta rutina devuelve uno si tiene éxito, cero en caso contrario.
bool_t xdr_u_longlong_t(XDR *xdrs, u_longlong_t *ullp);
Un filtro primitivo que traduce entre enteros unsigned long long C y sus representaciones externas. Esta rutina devuelve uno si tiene éxito, cero en caso contrario.
bool_t xdr_uint(XDR *xdrs, unsigned int *uip);
Un filtro primitivo que traduce entre enteros sin signo C y sus representaciones externas. Esta rutina devuelve uno si tiene éxito, cero en caso contrario.
bool_t xdr_union(XDR *xdrs, enum_t *switchp, char *fmtp,
                 struct xdr_discrim *choices,
                 typeof(bool_t (XDR *, char *, enum_t *)) *defaultix);
Un filtro primitivo que traduce entre uniones C y sus representaciones externas. El argumento switchp es el puntero al discriminante de la unión, fmtp es el puntero a la unión, choices es un puntero a un array de estructuras xdr_discrim que especifican los casos posibles de la unión, y defaultix es un puntero a un procedimiento que se llama si el discriminante no coincide con ninguno de los casos especificados. Esta rutina devuelve uno si tiene éxito, cero en caso contrario.
bool_t xdr_vector(XDR *xdrs, char *arr, unsigned int size,
                  unsigned int maxsize, xdrproc_t proc);
Como xdr_array(), pero para arrays de tamaño fijo. El argumento arr es el puntero al array, size es el número de elementos actualmente en el array, maxsize es el tamaño máximo del array, y proc es el procedimiento XDR para serializar los elementos del array.
bool_t xdr_void(void);
Este filtro no hace nada y siempre tiene éxito. Se utiliza como marcador de posición para procedimientos que no tienen argumentos ni resultados transferidos. Devuelve uno.
bool_t xdr_wrapstring(XDR *xdrs, char **sp);
Similar a xdr_string(), pero utiliza un tamaño máximo implícito determinado por la implementación. Esto es útil para cadenas de longitud arbitraria, pero debe usarse con precaución ya que puede llevar a desbordamientos si la cadena es demasiado grande.
bool_t xdr_longlong_t(XDR *xdrs, long long *llp);
Un filtro primitivo que traduce entre enteros long long C y sus representaciones externas. Esta rutina devuelve uno si tiene éxito, cero en caso contrario.
