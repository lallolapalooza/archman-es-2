xdr(3) Manual de Funciones de Biblioteca xdr(3)

NOMBRE

xdr - rutinas de biblioteca para la representación externa de datos

BIBLIOTECA

Biblioteca C estándar (libc, -lc)

SINopsis Y DESCRIPCIÓN

Estas rutinas permiten a los programadores C describir estructuras de datos arbitrarias de forma independiente de la máquina. Los datos para las llamadas a procedimientos remotos se transmiten utilizando estas rutinas.

Los prototipos a continuación se declaran en <rpc/xdr.h> y utilizan los siguientes tipos:

typedef int bool_t;
typedef typeof(bool_t (XDR *, void *, ...)) *xdrproc_t;

Para la declaración del tipo XDR, consulte <rpc/xdr.h>.

bool_t xdr_array(XDR *xdrs, char **arrp, unsigned int *sizep,
                 unsigned int maxsize, unsigned int elsize,
                 xdrproc_t elproc);
Una primitiva de filtro que traduce entre arreglos de longitud variable y sus representaciones externas correspondientes. El argumento arrp es la dirección del puntero al arreglo, mientras que sizep es la dirección del contador de elementos del arreglo; este contador de elementos no puede exceder maxsize. El argumento elsize es el sizeof cada uno de los elementos del arreglo, y elproc es un filtro XDR que traduce entre la forma C de los elementos del arreglo y su representación externa. Esta rutina devuelve uno si tiene éxito, cero en caso contrario.
bool_t xdr_bool(XDR *xdrs, bool_t *bp);
Una primitiva de filtro que traduce entre booleanos (enteros C) y sus representaciones externas. Al codificar datos, este filtro produce valores de uno o cero. Esta rutina devuelve uno si tiene éxito, cero en caso contrario.
bool_t xdr_bytes(XDR *xdrs, char **sp, unsigned int *sizep,
                 unsigned int maxsize);
Una primitiva de filtro que traduce entre cadenas de bytes contadas y sus representaciones externas. El argumento sp es la dirección del puntero de la cadena. La longitud de la cadena se encuentra en la dirección sizep; las cadenas no pueden tener una longitud mayor que maxsize. Esta rutina devuelve uno si tiene éxito, cero en caso contrario.
bool_t xdr_char(XDR *xdrs, char *cp);
Una primitiva de filtro que traduce entre caracteres C y sus representaciones externas. Esta rutina devuelve uno si tiene éxito, cero en caso contrario. Nota: los caracteres codificados no están empaquetados y ocupan 4 bytes cada uno. Para arreglos de caracteres, vale la pena considerar xdr_bytes(), xdr_opaque() o xdr_string().
void xdr_destroy(XDR *xdrs);
Una macro que invoca la rutina de destrucción asociada al flujo XDR, xdrs. La destrucción generalmente implica liberar estructuras de datos privadas asociadas con el flujo. Usar xdrs después de invocar xdr_destroy() no está definido.
bool_t xdr_double(XDR *xdrs, double *dp);

bool_t xdr_enum(XDR *xdrs, enum_t *ep);
Una primitiva de filtro que traduce entre enumeraciones C (en realidad, enteros) y sus representaciones externas. Esta rutina devuelve uno si tiene éxito, cero en caso contrario.
bool_t xdr_float(XDR *xdrs, float *fp);
Una primitiva de filtro que traduce entre números flotantes C y sus representaciones externas. Esta rutina devuelve uno si tiene éxito, cero en caso contrario.
void xdr_free(xdrproc_t proc, char *objp);
Rutina genérica de liberación. El primer argumento es la rutina XDR para el objeto que se está liberando. El segundo argumento es un puntero al objeto en sí. Nota: el puntero pasado a esta rutina no se libera, pero lo que apunta sí se libera (recursivamente).
unsigned int xdr_getpos(XDR *xdrs);
Una macro que invoca la rutina de obtención de posición asociada al flujo XDR, xdrs. La rutina devuelve un entero sin signo, que indica la posición del flujo de bytes XDR. Una característica deseable de los flujos XDR es que la aritmética simple funciona con este número, aunque las instancias de flujo XDR no necesiten garantizar esto.
long *xdr_inline(XDR *xdrs, int len);
Una macro que invoca la rutina inline asociada al flujo XDR, xdrs. La rutina devuelve un puntero a una pieza contigua del búfer del flujo; len es la longitud en bytes del búfer deseado. Nota: el puntero se convierte a long *.
Advertencia: xdr_inline() puede devolver NULL (0) si no puede asignar una pieza contigua de un búfer. Por lo tanto, el comportamiento puede variar entre las instancias de flujo; existe por eficiencia.
bool_t xdr_int(XDR *xdrs, int *ip);

bool_t xdr_long(XDR *xdrs, long *lp);

void xdrmem_create(XDR *xdrs, char *addr, unsigned int size,
                   enum xdr_op op);
Esta rutina inicializa el objeto de flujo XDR apuntado por xdrs. Los datos del flujo se escriben o leen de un bloque de memoria en la ubicación addr cuya longitud no supera los size bytes. El parámetro op determina la dirección del flujo XDR (ya sea XDR_ENCODE, XDR_DECODE o XDR_FREE).
bool_t xdr_opaque(XDR *xdrs, char *cp, unsigned int cnt);
Una primitiva de filtro que traduce entre datos opacos de tamaño fijo y su representación externa. El argumento cp es la dirección del objeto opaco, y cnt es su tamaño en bytes. Esta rutina devuelve uno si tiene éxito, cero en caso contrario.
bool_t xdr_pointer(XDR *xdrs, char **objpp,
                   unsigned int objsize, xdrproc_t xdrobj);
Similar a xdr_reference() excepto que serializa punteros nulos, mientras que xdr_reference() no lo hace. Por lo tanto, xdr_pointer() puede representar estructuras de datos recursivas, como árboles binarios o listas enlazadas.
void xdrrec_create(XDR *xdrs, unsigned int sendsize,
                   unsigned int recvsize, char *handle,
                   typeof(int (char *, char *, int)) *readit,
                   typeof(int (char *, char *, int)) *writeit);
Esta rutina inicializa el objeto de flujo XDR apuntado por xdrs. Los datos del flujo se escriben en un búfer de tamaño sendsize; un valor de cero indica que el sistema debe usar uno adecuado por defecto. Los datos del flujo se leen de un búfer de tamaño recvsize; este también puede establecerse a un valor adecuado por defecto pasando un valor cero. Cuando el búfer de salida de un flujo está lleno, se llama a writeit. De manera similar, cuando el búfer de entrada de un flujo está vacío, se llama a readit. El comportamiento de estas dos rutinas es similar a las llamadas del sistema read(2) y write(2), excepto que handle se pasa a las rutinas anteriores como primer argumento. Nota: el campo op del flujo XDR debe ser establecido por el llamador.
Advertencia: para leer desde un flujo XDR creado por esta API, necesitará llamar primero a xdrrec_skiprecord() antes de llamar a cualquier otra API XDR. Esto inserta bytes adicionales en el flujo para proporcionar límites de registro
bool_t xdr_reference(XDR *xdrs, char **pp, unsigned int size,
                     xdrproc_t proc);
Una primitiva de filtro que traduce entre un objeto y su representación externa. El argumento pp es la dirección de un puntero al objeto, y size es el tamaño del objeto en bytes. El argumento proc es la rutina XDR que se utiliza para traducir entre el objeto y su representación externa. Esta rutina devuelve uno si tiene éxito, cero en caso contrario.
bool_t xdr_setpos(XDR *xdrs, unsigned int pos);
Una macro que invoca la rutina de establecimiento de posición asociada al flujo XDR, xdrs. La rutina establece la posición del flujo de bytes XDR a pos. El valor de pos fue previamente obtenido por una llamada a xdr_getpos().

bool_t xdr_union(XDR *xdrs, enum_t *discr, char *handle,
                 struct xdr_disc_union *map, typeof(int (XDR *, char *, enum_t *)) *xxx);
Traduce uniones discriminadas. El argumento discr es un puntero al discriminante de la unión. El argumento handle es un puntero a la unión. El argumento map es una matriz de estructuras xdr_disc_union que mapea los valores del discriminante a los procedimientos XDR apropiados. El argumento xxx es un puntero a la rutina de serialización/deserialización que se utilizará si el discriminante no está en el mapa.
bool_t xdr_void(void);
Un filtro nulo que no hace nada. Se utiliza cuando las operaciones XDR no implican datos, como en xdr_calloc().
bool_t xdr_vector(XDR *xdrs, char *arr, unsigned int len,
                  unsigned int maxsize, xdrproc_t elproc);
Similar a xdr_array(), pero el argumento arr es un puntero al búfer del arreglo, en lugar de un puntero a un puntero. Esto significa que xdr_vector() no puede traducir arreglos de tamaño variable.

A common use of these routines is in the implementation of RPC services. The xdr_destroy() macro is used to destroy an XDR stream, freeing any associated resources. The xdr_free() routine is used to free memory allocated by XDR encoding/decoding routines.
