xdr(3) Manual de funciones de biblioteca xdr(3)

NOMBRE

xdr - rutinas de biblioteca para la representación externa de datos

BIBLIOTECA

Biblioteca C estándar (libc, -lc)

SINOPSIS Y DESCRIPCIÓN

Estas rutinas permiten a los programadores C describir estructuras de datos arbitrarias de forma independiente de la máquina. Los datos para las llamadas a procedimientos remotos se transmiten utilizando estas rutinas.

Los prototipos a continuación se declaran en <rpc/xdr.h> y utilizan los siguientes tipos:

typedef int bool_t;
typedef typeof(bool_t (XDR *, void *, ...))  *xdrproc_t;

Para la declaración del tipo XDR, consulte <rpc/xdr.h>.

bool_t xdr_array(XDR *xdrs, char **arrp, unsigned int *sizep,
                 unsigned int maxsize, unsigned int elsize,
                 xdrproc_t elproc);
Un filtro primitivo que traduce entre matrices de longitud variable y sus representaciones externas correspondientes. El argumento arrp es la dirección del puntero a la matriz, mientras que sizep es la dirección del contador de elementos de la matriz; este contador de elementos no puede exceder maxsize. El argumento elsize es el sizeof de cada uno de los elementos de la matriz, y elproc es un filtro XDR que traduce entre la forma C de los elementos de la matriz y su representación externa. Esta rutina devuelve uno si tiene éxito, cero en caso contrario.
bool_t xdr_bool(XDR *xdrs, bool_t *bp);
Un filtro primitivo que traduce entre booleanos (enteros C) y sus representaciones externas. Al codificar datos, este filtro produce valores de uno o cero. Esta rutina devuelve uno si tiene éxito, cero en caso contrario.
bool_t xdr_bytes(XDR *xdrs, char **sp, unsigned int *sizep,
                 unsigned int maxsize);
Un filtro primitivo que traduce entre cadenas de bytes contadas y sus representaciones externas. El argumento sp es la dirección del puntero a la cadena. La longitud de la cadena se encuentra en la dirección sizep; las cadenas no pueden tener una longitud mayor que maxsize. Esta rutina devuelve uno si tiene éxito, cero en caso contrario.
bool_t xdr_char(XDR *xdrs, char *cp);
Un filtro primitivo que traduce entre caracteres C y sus representaciones externas. Esta rutina devuelve uno si tiene éxito, cero en caso contrario. Nota: los caracteres codificados no se empaquetan y ocupan 4 bytes cada uno. Para matrices de caracteres, vale la pena considerar xdr_bytes(), xdr_opaque() o xdr_string().
void xdr_destroy(XDR *xdrs);
Una macro que invoca la rutina de destrucción asociada con el flujo XDR, xdrs. La destrucción generalmente implica la liberación de estructuras de datos privadas asociadas con el flujo. Usar xdrs después de invocar xdr_destroy() no está definido.
bool_t xdr_double(XDR *xdrs, double *dp);
Un filtro primitivo que traduce entre números de precisión double C y sus representaciones externas. Esta rutina devuelve uno si tiene éxito, cero en caso contrario.
bool_t xdr_enum(XDR *xdrs, enum_t *ep);
Un filtro primitivo que traduce entre enums C (en realidad, enteros) y sus representaciones externas. Esta rutina devuelve uno si tiene éxito, cero en caso contrario.
bool_t xdr_float(XDR *xdrs, float *fp);
Un filtro primitivo que traduce entre floats C y sus representaciones externas. Esta rutina devuelve uno si tiene éxito, cero en caso contrario.
void xdr_free(xdrproc_t proc, char *objp);
Rutina de liberación genérica. El primer argumento es la rutina XDR para el objeto que se libera. El segundo argumento es un puntero al objeto en sí. Nota: el puntero pasado a esta rutina no se libera, pero lo que apunta sí se libera (recursivamente).
unsigned int xdr_getpos(XDR *xdrs);
Una macro que invoca la rutina de obtención de posición asociada con el flujo XDR, xdrs. La rutina devuelve un entero sin signo, que indica la posición del flujo de bytes XDR. Una característica deseable de los flujos XDR es que la aritmética simple funciona con este número, aunque las instancias de flujo XDR no garantizan esto.
long *xdr_inline(XDR *xdrs, int len);
Una macro que invoca la rutina en línea asociada con el flujo XDR, xdrs. La rutina devuelve un puntero a una pieza contigua del búfer del flujo; len es la longitud en bytes del búfer deseado. Nota: el puntero se convierte a long *.
Advertencia: xdr_inline() puede devolver NULL (0) si no puede asignar una pieza contigua de un búfer. Por lo tanto, el comportamiento puede variar entre instancias de flujo; existe por motivos de eficiencia.
bool_t xdr_int(XDR *xdrs, int *ip);
Un filtro primitivo que traduce entre enteros C y sus representaciones externas. Esta rutina devuelve uno si tiene éxito, cero en caso contrario.
bool_t xdr_long(XDR *xdrs, long *lp);
Un filtro primitivo que traduce entre enteros long C y sus representaciones externas. Esta rutina devuelve uno si tiene éxito, cero en caso contrario.
void xdrmem_create(XDR *xdrs, char *addr, unsigned int size,
                   enum xdr_op op);
Esta rutina inicializa el objeto de flujo XDR apuntado por xdrs. Los datos del flujo se escriben o leen de un bloque de memoria en la ubicación addr cuya longitud no supera los size bytes. El op determina la dirección del flujo XDR (ya sea XDR_ENCODE, XDR_DECODE o XDR_FREE).
bool_t xdr_opaque(XDR *xdrs, char *cp, unsigned int cnt);
Un filtro primitivo que traduce entre datos opacos de tamaño fijo y su representación externa. El argumento cp es la dirección del objeto opaco, y cnt es su tamaño en bytes. Esta rutina devuelve uno si tiene éxito, cero en caso contrario.
bool_t xdr_pointer(XDR *xdrs, char **objpp,
                   unsigned int objsize, xdrproc_t xdrobj);
Similar a xdr_reference() excepto que serializa punteros nulos, mientras que xdr_reference() no lo hace. Por lo tanto, xdr_pointer() puede representar estructuras de datos recursivas, como árboles binarios o listas enlazadas.
void xdrrec_create(XDR *xdrs, unsigned int sendsize,
                   unsigned int recvsize, char *handle,
                   typeof(int (char *, char *, int)) *readit,
                   typeof(int (char *, char *, int)) *writeit);
Esta rutina inicializa el objeto de flujo XDR apuntado por xdrs. Los datos del flujo se escriben en un búfer de tamaño sendsize; un valor de cero indica que el sistema debe usar uno predeterminado adecuado. Los datos del flujo se leen de un búfer de tamaño recvsize; este también se puede establecer en un valor predeterminado adecuado pasando un valor cero. Cuando el búfer de salida de un flujo está lleno, se llama a writeit. De manera similar, cuando el búfer de entrada de un flujo está vacío, se llama a readit. El comportamiento de estas dos rutinas es similar a las llamadas al sistema read(2) y write(2), excepto que handle se pasa a las rutinas anteriores como el primer argumento. Nota: el campo op del flujo XDR debe ser establecido por el llamador.
Advertencia: para leer de un flujo XDR creado por esta API, deberá llamar a xdrrec_skiprecord() primero antes de llamar a cualquier otra API XDR. Esto inserta bytes adicionales en el flujo para proporcionar límites de registro.

Para más información, véase xdrrec_skiprecord(3).

bool_t xdrrec_endofrecord(XDR *xdrs, bool_t sendr);
Si sendr es verdadero, esta rutina indica que se ha completado un registro. Si sendr es falso, se espera un registro al principio de la siguiente llamada a una rutina de serialización/deserialización XDR. Esta rutina se puede utilizar para el control de flujo en un flujo XDR de registro.
void xdrrec_skiprecord(XDR *xdrs);
Esta rutina omite el resto del registro actual y posiciona el flujo XDR para que lea el siguiente registro en la próxima operación de lectura.
bool_t xdr_reference(XDR *xdrs, char **pp,
                     unsigned int size, xdrproc_t proc);
Este filtro primitivo realiza la serialización y deserialización de objetos C que se encuentran en una dirección indirecta. El argumento pp es la dirección del puntero al objeto. El argumento size es el tamaño del objeto al que apunta pp. El argumento proc es la rutina XDR que se utiliza para serializar o deserializar el objeto.
Advertencia: xdr_reference() no es seguro para estructuras de datos recursivas que puedan contener punteros nulos. Use xdr_pointer() en su lugar si necesita esta funcionalidad.
bool_t xdr_register(XDR *xdrs, u_int *objpp,
                    unsigned int objsize, xdrproc_t xdrobj);
En el contexto de XDR, la serialización y deserialización de estructuras de datos recursivas es posible utilizando un mecanismo de puntero con soporte para punteros nulos. La rutina xdr_pointer() se utiliza para este propósito.
bool_t xdr_setpos(XDR *xdrs, unsigned int pos);
Una macro que invoca la rutina de establecimiento de posición asociada con el flujo XDR, xdrs. La rutina establece la posición del flujo XDR en el valor pos. La posición se obtuvo previamente de xdr_getpos().
bool_t xdr_short(XDR *xdrs, short *sp);
Un filtro primitivo que traduce entre enteros short C y sus representaciones externas. Esta rutina devuelve uno si tiene éxito, cero en caso contrario.
bool_t xdr_string(XDR *xdrs, char **sp, unsigned int maxsize);
Un filtro primitivo que traduce entre cadenas de caracteres de estilo C (terminadas en nulo) y sus representaciones externas. El argumento sp es la dirección del puntero de cadena. La cadena no puede tener una longitud mayor que maxsize. Esta rutina devuelve uno si tiene éxito, cero en caso contrario.
bool_t xdr_u_char(XDR *xdrs, u_char *cp);
Un filtro primitivo que traduce entre caracteres unsigned char C y sus representaciones externas. Esta rutina devuelve uno si tiene éxito, cero en caso contrario. Nota: los caracteres codificados no se empaquetan, y ocupan 4 bytes cada uno.
bool_t xdr_u_int(XDR *xdrs, u_int *up);
Un filtro primitivo que traduce entre enteros sin signo C y sus representaciones externas. Esta rutina devuelve uno si tiene éxito, cero en caso contrario.
bool_t xdr_u_long(XDR *xdrs, u_long *ulp);
Un filtro primitivo que traduce entre enteros long unsigned C y sus representaciones externas. Esta rutina devuelve uno si tiene éxito, cero en caso contrario.
bool_t xdr_uint16_t(XDR *xdrs, uint16_t *u16p);
Un filtro primitivo que traduce entre enteros C uint16_t y sus representaciones externas. Esta rutina devuelve uno si tiene éxito, cero en caso contrario.
bool_t xdr_uint32_t(XDR *xdrs, uint32_t *u32p);
Un filtro primitivo que traduce entre enteros C uint32_t y sus representaciones externas. Esta rutina devuelve uno si tiene éxito, cero en caso contrario.
bool_t xdr_uint64_t(XDR *xdrs, uint64_t *u64p);
Un filtro primitivo que traduce entre enteros C uint64_t y sus representaciones externas. Esta rutina devuelve uno si tiene éxito, cero en caso contrario.
bool_t xdr_union(XDR *xdrs, enum_t *switchp, char *data,
                 struct xdr_discrim *choices, xdrproc_t whence);
Un filtro primitivo que traduce entre uniones discriminadas y sus representaciones externas. El argumento switchp es el puntero al discriminante de la unión. El argumento data es el puntero a los datos de la unión. El argumento choices es una matriz de estructuras xdr_discrim, que especifican el valor del discriminante, el tipo XDR asociado y el valor de desplazamiento de los datos de la unión. El argumento whence es una rutina XDR que se llama para serializar o deserializar los datos de la unión. Esta rutina devuelve uno si tiene éxito, cero en caso contrario.
bool_t xdr_vector(XDR *xdrs, char *cp, size_t size,
                  size_t maxsize, xdrproc_t elproc);
Un filtro primitivo que traduce entre matrices de tamaño fijo y sus representaciones externas. El argumento cp es la dirección del primer elemento de la matriz. El argumento size es el número de elementos en la matriz. El argumento maxsize es el tamaño máximo permitido de la matriz. El argumento elproc es el filtro XDR para los elementos de la matriz. Esta rutina devuelve uno si tiene éxito, cero en caso contrario.
bool_t xdr_void(void);
Esta rutina no hace nada y siempre devuelve uno. Se utiliza como marcador de posición para operaciones que no tienen argumentos o resultados.
bool_t xdr_wrapstring(XDR *xdrs, char **sp);
Similar a xdr_string(), pero maneja la asignación de memoria para la cadena. Se utiliza para codificar y decodificar cadenas de longitud indeterminada. Esta rutina devuelve uno si tiene éxito, cero en caso contrario.
