NOMBRE

xkbseldb - mantener bases de datos xkbsel

SINOPSIS

xkbseldb [-rRmMlLc] [-b] [-x] [-v] [--debug]
xkbseldb {--help,--version}

DESCRIPCIÓN

El paquete xkbsel almacena sus definiciones de mapa de teclado en las jerarquías de directorios del sistema y del usuario y proporciona un acceso a ellas basado en archivos de configuración del sistema y del usuario. Dado que se trata de muchos datos dispersos y que el proceso de selección de mapeo debe ser rápido, las definiciones se codifican en hash y los mapeos mencionados en los archivos de configuración se precompilan en una forma interna de lectura rápida.

xkbseldb se utiliza para mantener estos datos internos. Las opciones disponibles son:

-R, --rebuild-system
reconstruir la base de datos del sistema
-r, --rebuild-user
reconstruir la base de datos del usuario
-M, --missing-system
mostrar una plantilla que cubre los metadatos xkbsel que faltan para los mapeos del sistema y de X11
-m, --missing-user
mostrar una plantilla que cubre los metadatos de usuario que faltan
-L, --list-system
listar el contenido de la base de datos del sistema
-l, --list-user
listar el contenido de las bases de datos desde el punto de vista del usuario
-b, --brief
al listar el contenido, mostrar solo los nombres de los mapas
-x, --explicit
al listar el contenido, omitir los mapas que se toman de la distribución X11 sin modificaciones
-c, --check
mostrar la configuración actual
-v, --verbose
ser detallado
--debug
ser muy detallado
--help
mostrar instrucciones breves de uso
--version
mostrar la versión del programa

Debe reconstruir la base de datos del sistema cada vez que agregue o elimine un mapeo de teclado incluido en los directorios del sistema de X11 o del paquete, cuando cambie metadatos que describen el mapeo (ver xkbsel(5) para los formatos) o cuando cambie el contenido de las definiciones XKB de tal manera que el mapeo resultante sea diferente. Se aconseja encarecidamente reconstruir la base de datos cuando agregue nuevas definiciones de atajos al archivo de configuración del sistema para que el sistema las precompile (de lo contrario, se compilarán en cada usuario que las seleccione).

La situación para las bases de datos de usuario es similar: si el directorio xkbsel del usuario no está vacío, se necesita una reconstrucción después de cada cambio en estos datos. En resumen: en caso de duda, haga las reconstrucciones.

Las opciones --missing-system y --missing-user son para las personas que deseen definir los mapas ellas mismas. La salida debe completarse e instalarse como un archivo de redefinición. No meta mano en esto si solo quiere usar el paquete.

El uso de --check y --list-user --brief a menudo puede ayudar a depurar problemas de configuración.

ARCHIVOS

/usr/X11R6/lib/X11/xkb
Jerarquía XKB de la distribución X11
/usr/share/xkbsel
Directorio de datos del sistema
/etc/xkbsel.conf
Archivo de configuración del sistema
/var/xkbsel
Directorio del sistema para la base de datos hash y los mapas precompilados
~/.xkbsel
Directorio de datos del usuario
~/.xkbsel/xkbsel.conf
Archivo de configuración del usuario

VER TAMBIÉN

xkbsel(1), xkbsel-aw(1), xkbsel(5)

ERRORES

Debería determinar automáticamente cuándo la base de datos del usuario necesita una reconstrucción.
