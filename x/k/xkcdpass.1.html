NOMBRE

xkcdpass - genera contraseñas seguras y memorizables de varias palabras

SINOPSIS

xkcdpass [ opciones ]
xkcdpass --help

DESCRIPCIÓN

Un generador de contraseñas flexible y scriptable que genera contraseñas seguras, inspirado en XKCD 936:

$ xkcdpass
> correct horse battery staple

OPCIONES

--help

Describe cómo usar este comando.

--wordfile ARCHIVO_PALABRAS, -w ARCHIVO_PALABRAS

Especifica que el archivo ARCHIVO_PALABRAS contiene la lista de palabras válidas de las cuales generar contraseñas.

--min LONGITUD_MINIMA

Genera contraseñas que contengan al menos LONGITUD_MINIMA letras. (Por defecto: 5)

--max LONGITUD_MAXIMA

Genera contraseñas que contengan como máximo LONGITUD_MAXIMA letras. (Por defecto: 9)

--numwords NUM_PALABRAS, -n NUM_PALABRAS

Genera contraseñas que contengan exactamente NUM_PALABRAS palabras. (Por defecto: 6)

--interactive, -i

Genera y muestra una contraseña, pregunta al usuario si la acepta y repite hasta que se acepte una.

--valid_chars CARACTERES_VALIDOS, -v CARACTERES_VALIDOS

Limita las contraseñas a incluir solo palabras que coincidan con el patrón regex CARACTERES_VALIDOS (por ejemplo, '[a-z]').

--verbose, -V

Informa sobre varias métricas para las opciones dadas.

--acrostic ACROSTICO, -a ACROSTICO

Genera contraseñas con un acróstico que coincida con ACROSTICO.

--count CONTADOR, -c CONTADOR

Genera CONTADOR contraseñas. (Por defecto: 1)

--delimiter DELIM, -d DELIM

Separa las palabras dentro de una contraseña con DELIM. (Por defecto: ' ')

--separator SEP, -s SEP

Separa las contraseñas generadas con SEP. (Por defecto: ' ')

EJEMPLOS

•
xkcdpass

Genera una contraseña con las opciones por defecto. Ejemplo de salida:

pinball previous deprive militancy bereaved numeric
•
xkcdpass --count=5 --acrostic='chaos' --delimiter='|' --min=5 --max=6 --valid_chars='[a-z]'

Genera 5 contraseñas, todas de palabras en minúsculas y que cumplen el acróstico "chaos", separadas por el carácter "|". Ejemplo de salida:

collar|highly|asset|ovoid|sultan
caper|hangup|addle|oboist|scroll
couple|honcho|abbot|obtain|simple
cutler|hotly|aortae|outset|stool
cradle|helot|axial|ordure|shale

HISTORIAL

El comando xkcdpass invoca el programa Python xkcd_password.py.

La inspiración para el propósito del programa es la tira cómica XKCD 936 "Password Strength".
