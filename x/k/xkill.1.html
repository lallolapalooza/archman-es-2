XKILL(1) Manual de comandos generales XKILL(1)

NOMBRE

xkill - terminar un cliente por su recurso X

SINOPSIS

xkill [-display nombre_pantalla] [-id recurso] [-button número] [-frame] [-all] [-version]

DESCRIPCIÓN

Xkill es una utilidad para forzar al servidor X a cerrar conexiones con clientes. Este programa es muy peligroso, pero es útil para abortar programas que han mostrado ventanas no deseadas en la pantalla de un usuario. Si no se proporciona un identificador de recurso con -id, xkill mostrará un cursor especial como indicación al usuario para seleccionar una ventana que será terminada. Si se presiona un botón del puntero sobre una ventana no raíz, el servidor cerrará su conexión con el cliente que creó la ventana.

OPCIONES

-display nombre_pantalla
Esta opción especifica el nombre del servidor X al que contactar.
-id recurso
Esta opción especifica el identificador X del recurso cuyo creador debe ser abortado. Si no se especifica ningún recurso, xkill mostrará un cursor especial con el que se debe seleccionar una ventana para terminarla.
-button número
Esta opción especifica el número del botón del puntero que se debe usar al seleccionar una ventana para terminarla. Si se especifica la palabra "any" (cualquiera), se puede usar cualquier botón del puntero. Por defecto, se usa el primer botón en el mapa del puntero (que suele ser el botón más a la izquierda).
-all
Esta opción indica que todos los clientes con ventanas de nivel superior en la pantalla deben ser terminados. Xkill le pedirá que seleccione la ventana raíz con cada uno de los botones actualmente definidos para darle varias oportunidades de abortar. Se desaconseja encarecidamente el uso de esta opción.
-frame
Esta opción indica que xkill debe ignorar las convenciones estándar para encontrar ventanas de clientes de nivel superior (que normalmente están anidadas dentro de una ventana del gestor de ventanas), y simplemente creer que desea terminar los hijos directos de la raíz.
-version
Esta opción hace que xkill imprima su versión y salga sin terminar nada.

ADVERTENCIAS

Este comando no ofrece ninguna garantía de que la aplicación cuya conexión al servidor X se cierre abortará de forma limpia, o incluso que abortará. Todo lo que hace este comando es cerrar la conexión al servidor X. Muchas aplicaciones existentes sí abortan cuando se cierra su conexión al servidor X, pero algunas pueden elegir continuar.

XDEFAULTS

Button
Especifica un número de botón de puntero específico o la palabra "any" (cualquiera) a usar al seleccionar ventanas.

VER TAMBIÉN

X(7), xwininfo(1), XKillClient(3), XGetPointerMapping(3), KillClient en la Especificación del Protocolo X
