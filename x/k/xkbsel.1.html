NOMBRE

xkbsel - selecciona la distribución del teclado

SINOPSIS

xkbsel [-v] [--debug] [-s] MAPA
xkbsel [-v] [--debug] {-n,-p}
xkbsel {--help,--version}

DESCRIPCIÓN

xkbsel es una interfaz de línea de comandos para seleccionar los teclados, adecuada para instalar como acción vinculada a alguna combinación de teclas en un gestor de ventanas, inclusión en scripts o uso simple de línea de comandos. xkbsel admite las siguientes opciones:

-s MAPA, --select=MAPA
selecciona el MAPA nombrado
-n, --next
selecciona el siguiente mapa en el orden definido por el archivo de configuración
-p, --previous
selecciona el mapa anterior en el orden definido por el archivo de configuración
-v, --verbose
sea verboso
--debug
sea muy verboso
--help
muestra instrucciones de uso breves
--version
muestra la versión del programa

El MAPA puede especificarse como nombre XKB completo (por ejemplo, xfree86(us) o sun/de(type4_de)), o como un atajo definido en el archivo de configuración. Las opciones -n y -p solo funcionan cuando el mapeo actual se especificó en forma de atajo; de lo contrario, seleccionan el primer y el último mapa respectivamente.

ARCHIVOS

/etc/xkbsel.conf
archivo de configuración del sistema
~/.xkbsel/xkbsel.conf
archivo de configuración del usuario
