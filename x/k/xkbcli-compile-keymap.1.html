NOMBRE

xkbcli-compile-keymap — compila un mapa de teclado X Keyboard

SINOPSIS

xkbcli-compile-keymap [opciones] [RUTA_MAPA_TECLADO]

DESCRIPCIÓN

xkbcli-compile-keymap compila e imprime un mapa de teclado basado en las opciones dadas.

RUTA_MAPA_TECLADO
Ruta a un archivo de mapa de teclado, o “-” para leer la entrada estándar
--help
Imprime la ayuda y sale
--verbose
Habilita la salida de depuración detallada
--test
Prueba la compilación pero no imprime el mapa de teclado
--rmlvo
Imprime el RMLVO completo con los valores predeterminados rellenados para los elementos faltantes en formato YAML
--kccgst
Imprime un mapa de teclado que solo incluye los nombres de los componentes KcCGST en lugar del mapa de teclado completo
--kccgst-yaml
Imprime los nombres de los componentes KcCGST en formato YAML.
--modmaps
Imprime mapas de modificadores de teclas reales y virtuales y codificaciones de modificadores en formato YAML.
--include RUTA
Añade la ruta dada a la lista de rutas de inclusión. Esta opción es dependiente del orden, las rutas de inclusión dadas primero se buscan primero. Si se proporciona una ruta de inclusión, la lista de rutas de inclusión predeterminada no se utiliza. Usa --include-defaults para añadir las rutas de inclusión predeterminadas.
--include-defaults
Añade el conjunto predeterminado de directorios de inclusión. Esta opción es dependiente del orden, las rutas de inclusión dadas primero se buscan primero.
--input-format formato_mapa_teclado
El formato del mapa de teclado (numérico o etiqueta, p. ej., “v1”) para el análisis
--output-format formato_mapa_teclado
El formato del mapa de teclado (numérico o etiqueta, p. ej., “v1”) para la serialización
--format formato_mapa_teclado
El formato del mapa de teclado (numérico o etiqueta, p. ej., “v1”) tanto para el análisis como para la serialización
--no-pretty
Deshabilita la impresión bonita (pretty-printing) para la serialización del mapa de teclado.
--drop-unused
Deshabilita la serialización de bits no utilizados.
--keymap [RUTA], --from-xkb [RUTA]
Carga el mapa de teclado XKB desde un archivo, ignora las opciones RMLVO. Si RUTA está vacío o es “-”, lee desde la entrada estándar.
--rules reglas
El conjunto de reglas de XKB
--model modelo
El modelo de XKB
--layout distribucion
La distribución de XKB
--variant variante
La variante de distribución de XKB
--options opciones
Las opciones de XKB
--enable-environment-names
Permite establecer los valores RMLVO predeterminados a través de las siguientes variables de entorno:
  • XKB_DEFAULT_RULES
  • XKB_DEFAULT_MODEL
  • XKB_DEFAULT_LAYOUT
  • XKB_DEFAULT_VARIANT
  • XKB_DEFAULT_OPTIONS
Nota que esta opción puede afectar a los valores predeterminados de las opciones anteriores.
