NOMBRE

xkbsel - archivos de herramientas de selección de teclado XKB

DESCRIPCIÓN

xkbsel es un framework para definir, seleccionar e indicar mapeos de teclado XKB. Permite adjuntar datos adicionales a los archivos de fuente XKB y seleccionar (por sistema y por usuario) el subconjunto de los mapeos presentados al usuario en una interfaz gráfica o de línea de comandos.

Esta página del manual describe la sintaxis de los archivos de configuración y las extensiones de la sintaxis XKB utilizadas para adjuntar los datos adicionales.

ARCHIVOS DE CONFIGURACIÓN

Los archivos de configuración se llaman xkbsel.conf y contienen entradas de configuración divididas en secciones. Los nombres de las secciones están encerrados entre corchetes y las entradas pueden ser calificadas por un calificador opcional. Una entrada puede tener cero o más valores:

# comentario
// comentario
[seccion]
entrada1 = valor
entrada2[calif] = val1 "val-especial2" val3

Los nombres de las secciones, nombres de entradas, calificadores y valores sin comillas comienzan con una letra, barra o guion bajo; los caracteres restantes pueden incluir números y paréntesis. Cualquier otra cosa en la parte del valor debe ir entre comillas (aún no hay posibilidad de obtener las comillas dobles en el propio valor). Los archivos son generalmente sensibles a mayúsculas y minúsculas y el orden de las secciones es importante.

Si existe el archivo de configuración del usuario, se utiliza en su totalidad; no hay fusión con el archivo de configuración del sistema.

Actualmente hay dos secciones:

atajo

Los atajos definen un mapeo entre nombres cortos utilizados para la nomenclatura conveniente de mapas en herramientas de línea de comandos y gráficas, y nombres completos de mapas de teclado XKB. El nombre completo del mapa de teclado XKB consiste en una ruta relativa a un archivo (a menudo no hay parte de directorio) y un nombre de un mapa en este archivo en particular entre paréntesis.

Un ejemplo de sección de atajos que define teclados americano, alemán y francés (de la distribución X11) y eslovaco (de la distribución xkbsel) es:

[atajo]
us = xfree86(us)
de = xfree86(de)
fr = xfree86(fr)
sk = czsk(sk)

conjunto_de_mapas

Los atajos definidos en la sección anterior se utilizan para construir una lista de selección ordenada, utilizada por los selectores gráficos para presentar un menú de opciones al usuario. Existe la posibilidad de definir listas según la parte del idioma de la definición de la configuración regional (en minúsculas), la parte del territorio (en mayúsculas) y/o una lista predeterminada cuando ninguna lista específica coincide. Un ejemplo:

[conjunto_de_mapas]
map[sk] = sk us
map[de] = de us
map[fr] = fr us
map = us sk de fr

DATOS XKB ADICIONALES

Se asume que sabe cómo crear un mapeo de teclado XKB. Esta sección solo explica cómo añadir los datos de xkbsel a los nuevos mapeos y a los mapeos ya presentes en la distribución X.

El paquete xkbsel refleja la estructura de directorios de XKB (normalmente ubicada en /usr/X11R6/lib/X11/xkb) en el directorio del sistema de xkbsel (normalmente /usr/share/xkbsel) y eventualmente en el directorio del usuario (~/.xkbsel).

El único directorio de la estructura XKB original que importa para xkbsel es el subdirectorio keymap. Este es el punto de partida donde el paquete busca los mapeos y los pasa para su compilación e instalación al xkbcomp(1).

xkbsel añade otros dos directorios a la jerarquía. redef contiene archivos que añaden datos xkbsel adicionales a los mapeos ya definidos, sin necesidad de modificar los mapeos en sí de ninguna manera. pixmap contiene pequeños iconos que pueden ser referenciados por las herramientas gráficas (esto aún no está implementado).

Cuando hay datos en conflicto, la prioridad de la más alta a la más baja es:

1. directorio redef en la jerarquía del usuario
2. archivos de la jerarquía del usuario
3. directorio redef en la jerarquía de xkbsel
4. archivos de la jerarquía de xkbsel
5. distribución original de X11
Los archivos de los directorios del usuario distintos de keymap o redef (por ejemplo, symbols) solo se utilizan cuando el mapeo en sí se menciona en algún archivo de estos dos directorios; de lo contrario, xkbsel no los conoce.

Los datos para xkbsel se añaden a los archivos XKB utilizando comentarios especialmente formateados en el ámbito de la definición del mapa de teclado particular. El formato del comentario es

%xkb_palabra_clave% "valor"
Actualmente hay dos entradas de datos de este tipo:
descripción
define una descripción del mapeo del teclado en las herramientas gráficas
mapa_de_píxeles
define un mapa de píxeles para las herramientas gráficas (aún no implementado)

Un ejemplo de tal definición de mapa de teclado es:

xkb_keymap "sk" {
// %xkb_descripción% "Teclado eslovaco"
// %xkb_mapa_de_píxeles% "slovak.xpm"
xkb_keycodes { include "xfree86" };
xkb_types { include "default" };
xkb_compatibility { include "default" };
xkb_symbols { include "czsk_ibm(sk)" };
xkb_geometry { include "pc" };
};
Las descripciones pueden usar caracteres en una codificación local, pero recuerde que una herramienta gráfica se ejecuta en una configuración regional específica y no necesariamente mostrará todas las descripciones de mapas seleccionadas correctamente.

Es posible añadir estos datos a los mapeos existentes. Como es práctico hacer esto solo en varios archivos en lugar de que los archivos de redefinición coincidan con los archivos de mapa de teclado, existe la posibilidad de definir un nombre de archivo para las siguientes definiciones. Esto solo funciona para archivos en directorios redef y se especifica como

%xkb_archivo% "valor"
fuera de las definiciones de mapa de teclado. Por lo tanto, puede hacer algo como esto:
// %xkb_archivo% "xfree86"
xkb_keymap "us"
{
// %xkb_descripción% "Disposición de EE. UU."
// %xkb_mapa_de_píxeles% "us.xpm"
};

// %xkb_archivo% "sun/xfree86"
xkb_keymap "type4_us"
{
// %xkb_descripción% "Disposición de EE. UU. para Sun"
// %xkb_mapa_de_píxeles% "us.xpm"
};

xkbsel(5)

NOMBRE

xkbsel - Archivos de configuración para la selección del layout del teclado XKB

DESCRIPCIÓN

El programa xkbsel se utiliza para seleccionar el layout del teclado XKB. Permite al usuario elegir entre diferentes layouts y variantes del teclado, así como configurar combinaciones de teclas para cambiar de layout.

Los archivos de configuración para xkbsel se encuentran típicamente en los siguientes directorios:

ARCHIVOS DE CONFIGURACIÓN

Los archivos de configuración de xkbsel pueden contener:

  • Listas de layouts de teclado disponibles.
  • Definiciones de variantes para cada layout.
  • Combinaciones de teclas para cambiar entre layouts.
  • Otras opciones de configuración específicas de XKB.

La sintaxis exacta y la ubicación de estos archivos pueden variar dependiendo de la distribución de Linux y la versión de XKB utilizada.

ARCHIVOS

Los archivos de configuración de XKB, que xkbsel utiliza para determinar los layouts disponibles y su comportamiento, se encuentran comúnmente en:

  • /usr/share/X11/xkb/symbols/: Contiene las definiciones de los layouts y variantes del teclado.
  • /usr/share/X11/xkb/rules/: Contiene las reglas que asocian configuraciones de hardware con layouts y opciones de XKB.

VER TAMBIÉN

setxkbmap(1), xkeyboard-config(7)
