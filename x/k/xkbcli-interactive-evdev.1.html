NOMBRE

xkbcli-interactive-evdev — depurador interactivo para mapas de teclado XKB

SINOPSIS

xkbcli-interactive-evdev [opciones] [RUTA_MAPA_TECLADO]

DESCRIPCIÓN

xkbcli-interactive-evdev es una herramienta de línea de comandos para depurar interactivamente los mapas de teclado XKB escuchando los dispositivos evdev de /dev/input/eventX.

xkbcli-interactive-evdev requiere permisos para abrir los nodos del dispositivo evdev. Esto generalmente requiere ser el usuario "root" o pertenecer al grupo "input".

Presiona la tecla <Escape> para salir.

Esta es una herramienta de depuración, no se garantiza que su comportamiento o salida sean estables.

RUTA_MAPA_TECLADO
Ruta a un archivo de mapa de teclado, o "-" para leer la entrada estándar.
--help
Imprime la ayuda y sale.
--verbose
Habilita la salida de depuración verbosa.
--include RUTA
Añade la ruta dada a la lista de rutas de inclusión. Esta opción depende del orden, las rutas de inclusión dadas primero se buscan primero. Si se proporciona una ruta de inclusión, no se utiliza la lista de rutas de inclusión predeterminada. Usa --include-defaults para añadir las rutas de inclusión predeterminadas.
--include-defaults
Añade el conjunto predeterminado de directorios de inclusión. Esta opción depende del orden, las rutas de inclusión dadas primero se buscan primero.
--format formato_mapa_teclado
Especifica el formato del mapa de teclado (numérico o etiqueta, por ejemplo, "v1").
--rules reglas
El conjunto de reglas XKB.
--model modelo
El modelo XKB.
--layout diseño
El diseño XKB.
--variant variante
La variante del diseño XKB.
--option opciones
Las opciones XKB.
--enable-environment-names
Permite establecer los valores predeterminados de RMLVO a través de las siguientes variables de entorno:
  • XKB_DEFAULT_RULES
  • XKB_DEFAULT_MODEL
  • XKB_DEFAULT_LAYOUT
  • XKB_DEFAULT_VARIANT
  • XKB_DEFAULT_OPTIONS
Tenga en cuenta que esta opción puede afectar a los valores predeterminados de las opciones anteriores.
--keymap archivo
Especifica una ruta de mapa de teclado. Esta opción es mutuamente excluyente con las opciones RMLVO.
--enable-compose
Habilita la funcionalidad Compose.
--consumed-mode {xkb|gtk}
Establece el modo de modificadores consumidos (predeterminado: xkb).
--without-x11-offset
No añade un desplazamiento de 8 al convertir un código de tecla evdev a un código de tecla XKB. Probablemente no querrás esta opción.
--report-state-changes
Informa de los cambios en el estado del teclado.
-1, --uniline
Habilita la salida de eventos en una sola línea.
--multiline
Habilita la salida de eventos en varias líneas.
--short
Imprime una salida de eventos más corta.
