XKBCLI(1) Manual de Comandos Generales XKBCLI(1)

NOMBRE

xkbcli — herramienta para interactuar con mapas de teclado XKB

SINOPSIS

xkbcli comando [argumentos]

xkbcli [--help | --version]

DESCRIPCIÓN

xkbcli es una herramienta de línea de comandos para consultar, compilar y probar mapas de teclado, diseños y otros elementos de XKB.

--help
Imprimir ayuda y salir
--version
Imprimir la versión y salir

COMANDOS

compile-keymap
Compilar un mapa de teclado XKB, véase xkbcli-compile-keymap(1)
compile-compose
Compilar un archivo compose, véase xkbcli-compile-compose(1)
how-to-type
Mostrar cómo escribir un punto de código Unicode dado, véase xkbcli-how-to-type(1)
interactive
Depurador interactivo para mapas de teclado XKB que selecciona automáticamente de los siguientes backends, si están disponibles: Wayland, X11 y evdev. Véase las entradas correspondientes más adelante.
interactive-evdev
Depurador interactivo para mapas de teclado XKB para evdev, véase xkbcli-interactive-evdev(1)
interactive-wayland
Depurador interactivo para mapas de teclado XKB para Wayland, véase xkbcli-interactive-wayland(1)
interactive-x11
Depurador interactivo para mapas de teclado XKB para X11, véase xkbcli-interactive-x11(1)
dump-keymap
Volcar un mapa de teclado XKB desde un compositor Wayland o X11, véase las entradas correspondientes más adelante.
dump-keymap-wayland
Volcar un mapa de teclado XKB desde un compositor Wayland, véase xkbcli-dump-keymap-wayland(1)
dump-keymap-x11
Volcar un mapa de teclado XKB desde un servidor X, véase xkbcli-dump-keymap-x11(1)
list
Listar diseños y más disponibles, véase xkbcli-list(1)

Tenga en cuenta que no todas las herramientas pueden estar disponibles en su sistema.
