XKBPRINT(1) Manual de Comandos Generales XKBPRINT(1)

NOMBRE

xkbprint - imprimir una descripción de teclado XKB

SINOPSIS

xkbprint [opciones] fuente [ archivo_salida ]

DESCRIPCIÓN

El comando xkbprint genera una descripción PostScript imprimible o encapsulada de la descripción del teclado XKB especificada por fuente. La fuente puede ser cualquier archivo de mapa de teclas compilado (.xkm) que incluya una descripción de geometría o una especificación de pantalla X. Si se especifica un archivo_salida, xkbprint escribe en él. Si no se especifica ningún archivo de salida, xkbprint reemplaza la extensión del archivo fuente con .ps o .eps según el formato solicitado. Si la fuente es una pantalla X no local (por ejemplo, :0), xkbprint añade el prefijo apropiado a la especificación de la pantalla, reemplazando los dos puntos por un guion. Para una pantalla local, xkprint utiliza server-n donde n es el número de la pantalla.

OPCIONES

-?, -help
Imprime un mensaje de uso.
-color
Imprime usando los colores especificados en el archivo de geometría; por defecto, xkbprint imprime una imagen en blanco y negro del teclado.
-dflts
Intenta calcular nombres predeterminados para cualquier componente que falte, como teclas.
-diffs
Muestra símbolos solo donde están explícitamente enlazados.
-eps
Genera un archivo PostScript encapsulado.
-fit
Ajusta la imagen del teclado a la página (por defecto).
-full
Imprime el teclado a tamaño completo.
-grid res
Imprime una cuadrícula con una resolución de res mm sobre el teclado.
-if nombre_fuente
Especifica una fuente PostScript tipo 1 interna para volcar al archivo de salida especificado o a nombre_fuente.pfa, si no se especifica ningún archivo de salida. No se imprime ninguna descripción del teclado si se vuelca una fuente interna.
-label tipo
Especifica las etiquetas que se imprimirán en las teclas; los tipos válidos son: none, name, code y symbols.
-lc <locale>
Especifica una configuración regional en la que se resolverán los KeySyms.
-level1
Genera PostScript de nivel 1.
-level2
Genera PostScript de nivel 2.
-lg grupo
Imprime símbolos en grupos de teclado a partir de grupo.
-ll nivel
Imprime símbolos a partir del nivel de desplazamiento nivel.
-mono
Genera una imagen en blanco y negro del teclado (por defecto).
-n num
Imprime num copias.
-nkg num
Imprime los símbolos en num grupos de teclado.
-npk num
Número de imágenes de teclado a imprimir en cada página; para archivos EPS, esto especifica el número total de imágenes de teclado a imprimir.
-o archivo
Escribe la salida en archivo.
-Rdirectorio
Utiliza directorio como directorio raíz; todos los nombres de ruta se interpretan relativamente a directorio.
-pict cuál
Controla el uso de pictogramas en lugar de nombres de teclas donde estén disponibles. cuál puede ser cualquiera de all, none o common (por defecto).
-synch
Fuerza la sincronización de las solicitudes X.
-version
Muestra la versión del programa y sale.
-w nivel
Establece el nivel de advertencia (0 para ninguna advertencia, 10 para todas las advertencias).

VER TAMBIÉN
