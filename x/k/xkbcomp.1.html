NOMBRE

xkbcomp - compila la descripción del teclado XKB

SINOPSIS

xkbcomp [opción] fuente [destino]

DESCRIPCIÓN

El compilador de mapa de teclas xkbcomp convierte una descripción de un mapa de teclas XKB a uno de varios formatos de salida. El uso más común para xkbcomp es crear un archivo de mapa de teclas compilado (extensión .xkm) que puede ser leído directamente por servidores X o utilidades compatibles con XKB. El compilador de mapa de teclas también puede producir archivos de cabecera C o archivos de origen XKB. Los archivos de cabecera C producidos por xkbcomp pueden ser incluidos por servidores X o utilidades que necesiten un mapa de teclas predeterminado integrado. Los archivos de origen XKB producidos por xkbcomp están completamente resueltos y pueden ser usados para verificar que los archivos que típicamente conforman un mapa de teclas XKB se fusionan correctamente o para crear un único archivo que contenga una descripción completa del mapa de teclas.

La fuente puede especificar una pantalla X, o un archivo .xkb o .xkm; a menos que se especifique explícitamente, el formato del destino depende del formato de la fuente. Compilar un archivo .xkb (fuente del mapa de teclas) genera un archivo .xkm (archivo del mapa de teclas compilado) por defecto. Si la fuente es un archivo .xkm o una pantalla X, xkbcomp genera un archivo de fuente del mapa de teclas por defecto.

Si el destino es una pantalla X, el mapa de teclas de la pantalla se actualiza con el mapa de teclas compilado.

El nombre del destino se calcula generalmente a partir del nombre de la fuente, con la extensión reemplazada según corresponda. Al compilar un único mapa a partir de un archivo que contiene varios mapas, xkbcomp construye el nombre del archivo de destino añadiendo una extensión apropiada al nombre del mapa que se va a utilizar.

OPCIONES

-a
Muestra toda la información del teclado, informando la información implícita o derivada como un comentario. Solo afecta a la salida en formato .xkb.
-C
Produce un archivo de cabecera C como salida (extensión .h).
-dflts
Calcula los valores predeterminados para cualquier componente que falte, como los nombres de las teclas.
-em1 msg
Imprime msg antes de imprimir el primer mensaje de error.
-emp msg
Imprime msg al inicio de cada línea de mensaje.
-eml msg
Si hubo algún error, imprime msg antes de salir.
-help, -?
Muestra las opciones disponibles.
-Idir
Especifica directorios de nivel superior que se buscarán para los archivos incluidos por la descripción del mapa de teclas. Después de que todos los directorios especificados por las opciones -I hayan sido buscados, se buscará el directorio actual y finalmente, el directorio predeterminado de xkb, /usr/share/X11/xkb.

Para evitar que se busquen el directorio actual y el predeterminado, use la opción -I sola (es decir, sin un directorio), antes de cualquier opción -I que especifique los directorios que sí desea buscar.

-i deviceid
Si fuente o destino es una pantalla X válida, carga el mapa de teclas desde/hacia el dispositivo con el ID especificado (no el nombre).
-l
Lista los mapas que especifican el patrón map en cualquier archivo listado en la línea de comandos (aún no implementado).
-m nombre
Especifica un mapa que se compilará a partir de un archivo con múltiples entradas.
-merge
Fusiona la información compilada con el mapa del servidor (aún no implementado).
-o nombre
Especifica un nombre para el archivo de salida generado. El valor predeterminado es el nombre del archivo fuente con una extensión apropiada para el formato de salida.
-opt partes
Especifica una lista de partes opcionales. Los errores de compilación en cualquier parte opcional no son fatales. Las partes pueden consistir en cualquier combinación de las letras c, g, k, s y t, que especifican respectivamente el mapa de compatibilidad, la geometría, las teclas, los símbolos y los tipos.
-Rdir
Especifica el directorio raíz para los nombres de ruta relativos.
-synch
Fuerza la sincronización para las solicitudes X.
-version
Imprime el número de versión.
-w lvl
Controla la notificación de advertencias durante la compilación. Un nivel de advertencia de 0 deshabilita todas las advertencias; un nivel de advertencia de 10 las habilita todas.
-xkb
Genera una descripción de origen del teclado como salida (extensión .xkb).
-xkm
Genera un archivo de mapa de teclas compilado como salida (extensión .xkm).
