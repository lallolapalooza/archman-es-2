NOMBRE

xkeyboard-config - archivos de descripción de datos de XKB

DESCRIPCIÓN

xkeyboard-config proporciona los archivos de datos para la Extensión de Teclado X (XKB) y para libxkbcommon. Típicamente, es tarea del entorno de escritorio aplicar la configuración solicitada. Los usuarios que ejecutan un servidor X también pueden usar la herramienta setxkbmap(1) para aplicar la configuración del teclado en tiempo de ejecución o configurar los ajustes de XKB en xorg.conf(5).

RUTAS DE CARGA DE ARCHIVOS DE DATOS XKB

xkeyboard-config proporciona los archivos de datos XKB instalados en /usr/share/xkeyboard-config-2. Los archivos de datos específicos del usuario pueden estar en otro lugar, pero depende de la herramienta si esos archivos se cargan. Por ejemplo, la biblioteca libxkbcommon cargará por defecto los archivos de datos XKB del directorio principal del usuario. Ver la documentación de libxkbcommon para más detalles.

EL DISEÑO PERSONALIZADO

El diseño "custom" es un diseño que se lista como disponible para las herramientas que leen los archivos de datos, pero que no es proporcionado realmente por xkeyboard-config. Un usuario puede guardar una especificación de diseño en el archivo /usr/share/xkeyboard-config-2/symbols/custom y ese diseño estará disponible para la mayoría de las herramientas que interactúan con los archivos de datos de xkeyboard-config. Esto está principalmente dirigido a sistemas que ejecutan X donde las rutas de búsqueda adicionales no se pueden agregar fácilmente.

Debido a que el diseño "custom" solo se lista como disponible pero no es proporcionado por xkeyboard-config, el diseño no se sobrescribirá en las actualizaciones.

NAME

xkeyboard-config - X keyboard extension compatibility files

DESCRIPTION

This manual page describes the configuration files for the X Keyboard Extension (XKB). XKB allows the user to customize the behaviour of the keyboard in many ways. This package contains a comprehensive set of definitions for various keyboard models, layouts, rules, and other related options.

The configuration files are organised in a set of directories and can be loaded using the setxkbmap command.

XKB DATA FILES LOAD PATHS

The X server and the setxkbmap utility will search for XKB configuration files in the following directories:

  • /usr/share/xkeyboard-config-2/
  • /etc/xkb/
  • ~/.xkb/
The directories are searched in the order listed. This allows users to override system-wide defaults with their own configurations.

THE CUSTOM LAYOUT

The directory `symbols/custom` contains definitions for user-defined keymaps. These can be loaded using the `custom` option, for example:

setxkbmap -option custom:my_layout

Where `my_layout` refers to a file named `my_layout` in the `symbols/custom` directory.

MODELS

The `models` directory contains definitions for various keyboard models. These definitions specify the physical layout and key mapping of different keyboard types. Examples include:

Option Description
pc104 Standard 104-key PC keyboard.
pc105 Standard 105-key PC keyboard.
macintosh Apple Macintosh keyboard.
sun_type4 Sun Type 4 keyboard.

LAYOUTS

The `symbols` directory contains definitions for various keyboard layouts, including different languages and variants. You can combine layouts and variants using the `setxkbmap` command. For example:

setxkbmap us,fr -variant altgr-intl,oss4

This command sets the US layout with the `altgr-intl` variant and the French layout with the `oss4` variant.

Option Description
us US English layout.
gb UK English layout.
fr French layout.
de German layout.
es Spanish layout.
ru Russian layout.
ua Ukrainian layout.

OPTIONS

The `symbols/group` directory contains definitions for various options that can modify the keyboard's behavior. These options can be combined with layouts and models using the `-option` flag of `setxkbmap`.
