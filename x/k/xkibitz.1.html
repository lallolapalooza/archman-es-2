XKIBITZ(1) Manual de Comandos Generales XKIBITZ(1)

NOMBRE

xkibitz - permite que varias personas interactúen en un xterm

SINOPSIS

xkibitz [ argumentos-xkibitz ] [ programa argumentos-programa... ]

INTRODUCCIÓN

xkibitz permite que usuarios en xterms separados compartan un shell (o cualquier programa que se ejecute en un xterm). Los usos incluyen:

•
Un usuario novato puede pedir ayuda a un usuario experto. Usando xkibitz, el experto puede ver lo que el usuario está haciendo y ofrecer consejos o mostrar cómo hacerlo correctamente.
•
Al ejecutar xkibitz y luego iniciar un editor de pantalla completa, las personas pueden mantener una conversación, conservando la capacidad de desplazarse hacia atrás, guardar toda la conversación o incluso editarla mientras está en progreso.
•
Las personas pueden colaborar en juegos, edición de documentos u otras tareas cooperativas donde cada persona tiene fortalezas y debilidades que se complementan.
•
Si desea que un gran número de personas realicen una revisión de código en línea, puede sentar a dos personas frente a cada estación de trabajo y luego conectarlas todas mientras todos miran el código juntos en el editor.

USO

Para iniciar xkibitz, un usuario (el maestro) ejecuta xkibitz sin argumentos.

xkibitz inicia un nuevo shell (o otro programa, si se proporciona en la línea de comandos). El usuario puede interactuar normalmente con el shell, o al ingresar una secuencia de escape (descrita cuando xkibitz se inicia) puede agregar usuarios a la interacción.

Para agregar usuarios, ingrese "+ pantalla" donde pantalla es el nombre de la pantalla X. Si no hay ":X.Y" en el nombre de la pantalla, se asume ":0.0". El usuario maestro debe tener permiso para acceder a cada pantalla. A cada pantalla se le asigna una etiqueta, un pequeño número que se puede usar para referirse a la pantalla.

Para mostrar las etiquetas y pantallas actuales, ingrese "=".

Para eliminar una pantalla, ingrese "- etiqueta" donde etiqueta es la etiqueta de la pantalla según el comando "=".

Para regresar al shell compartido, ingrese "return". Luego, las pulsaciones de teclas de todos los usuarios se convierten en la entrada del shell. De manera similar, todos los usuarios reciben la salida del shell.

Para terminar xkibitz, basta con terminar el shell mismo. Por ejemplo, si algún usuario escribe ^D (y el shell acepta esto como EOF), el shell termina seguido por xkibitz.

Normalmente, todos los caracteres se pasan sin interpretar. Sin embargo, en el diálogo de escape, el usuario habla directamente con el intérprete de xkibitz. También se pueden dar comandos de Expect(1) o Tcl(3). Además, se puede usar el control de trabajos mientras se está en el intérprete, para, por ejemplo, suspender o reiniciar xkibitz.

Varios procesos pueden producir varios efectos. Por ejemplo, puede emular una sesión de write(1) multidireccional con el comando:

xkibitz sleep 1000000

ARGUMENTOS

xkibitz entiende algunos argumentos especiales que deben aparecer antes del nombre del programa (si se proporciona). Cada argumento debe estar separado por espacios en blanco. Si los argumentos mismos toman argumentos, estos también deben estar separados por espacios en blanco.

-escape establece el carácter de escape. El carácter de escape predeterminado es ^].

-display agrega una pantalla de manera similar al comando "+". Se pueden dar varios indicadores -display. Por ejemplo, para iniciar xkibitz con tres pantallas adicionales:

xkibitz -display mercury -display fox -display dragon:1.0

ADVERTENCIAS

Debido a limitaciones tanto en X como en UNIX, la propagación de redimensionamiento es débil.

Cuando el usuario maestro redimensiona el xterm, todos los demás xterms se redimensionan lógicamente. Desafortunadamente, xkibitz no puede forzar que el tamaño físico del xterm corresponda con los tamaños lógicos del xterm.

Los otros usuarios son libres de redimensionar su xterm, pero sus tamaños no se propagan. El maestro puede verificar los tamaños lógicos con el comando "=".

Deducir el tamaño de la ventana es una operación no portable. Se sabe que el código funciona para versiones recientes de SunOS, AIX, Unicos y HPUX. Envíe modificaciones si agrega soporte para algo más.

ENTORNO

La variable de entorno SHELL se utiliza para determinar e iniciar un shell, si no se proporciona otro programa en la línea de comandos.

Si la variable de entorno DISPLAY está definida, su valor se usa para el nombre de pantalla del maestro xkibitz (la pantalla con el número de etiqueta 0). De lo contrario, este nombre permanece vacío.

Se pueden pasar argumentos adicionales a nuevos xterms a través de la variable de entorno XKIBITZ_XTERM_ARGS. Por ejemplo, para crear xterms con una barra de desplazamiento y un cursor de puntero verde:

XKIBITZ_XTERM_ARGS="-sb -ms green"
export XKIBITZ_XTERM_ARGS
(esto es para el shell Bourne - use la sintaxis que sea apropiada para su shell favorito). Se puede dar cualquier opción válida para el comando xterm, con la excepción de -display, -geometry y -S, ya que estos son establecidos por xkibitz.
