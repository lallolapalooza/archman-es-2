NOMBRE

xkbbell - utilidad de usuario de la extensión XKB

SINOPSIS

xkbbell [-display <dpy>] [-synch] [-dev <id>] [-force] [-nobeep] [-bf <id>] [-kf <id>] [-v <volumen>] [-w <id>] [-help|-version]

DESCRIPCIÓN

utilidad de usuario

OPCIONES

-display <dpy>
especifica qué pantalla usar
-synch
activa la sincronización
-dev <id>
especifica qué dispositivo usar
-force
forzar campana audible
-nobeep
suprimir campana del servidor, solo evento
-bf <id>
especifica qué retroalimentación de campana usar
-kf <id>
especifica qué retroalimentación de teclado usar
-v <volumen>
especifica qué volumen usar
-w <id>
especifica qué ventana usar
-help
imprime la lista de opciones y sale
-version
imprime la versión del programa y sale

Si no se especifican ni el dispositivo ni la retroalimentación, xkbbell utiliza los valores predeterminados para el dispositivo de teclado principal.
