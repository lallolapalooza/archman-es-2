STRINGS(1) GNU Development Tools STRINGS(1)

NOMBRE

strings - imprime las secuencias de caracteres imprimibles en archivos

SINOPSIS

strings [-afovV] [-len-min]
[-n len-min] [--bytes=len-min]
[-t base] [--radix=base]
[-e codificacion] [--encoding=codificacion]
[-U metodo] [--unicode=metodo]
[-] [--all] [--print-file-name]
[-T nombre-bfd] [--target=nombre-bfd]
[-w] [--include-all-whitespace]
[-s] [--output-separator cadena-sep]
[--help] [--version] archivo...

DESCRIPCIÓN

Para cada archivo dado, GNU strings imprime las secuencias de caracteres imprimibles que tienen al menos 4 caracteres de longitud (o el número dado con las opciones de abajo) y están seguidas por un carácter no imprimible.

Dependiendo de cómo se configuró el programa strings, este mostrará por defecto todas las secuencias imprimibles que pueda encontrar en cada archivo, o solo aquellas secuencias que se encuentren en secciones de datos inicializadas y cargables. Si el tipo de archivo es irreconocible, o si strings está leyendo desde la entrada estándar, siempre mostrará todas las secuencias imprimibles que pueda encontrar.

Para compatibilidad con versiones anteriores, cualquier archivo que aparezca después de una opción de línea de comandos como solo - también será escaneado en su totalidad, independientemente de la presencia de cualquier opción -d.

strings es útil principalmente para determinar el contenido de archivos no textuales.

OPCIONES

-a
--all
-
Escanea el archivo completo, sin importar las secciones que contenga o si esas secciones están cargadas o inicializadas. Normalmente este es el comportamiento por defecto, pero strings puede ser configurado para que -d sea el comportamiento por defecto en su lugar.

La opción - depende de la posición y fuerza a strings a realizar escaneos completos de cualquier archivo que se mencione después de el - en la línea de comandos, incluso si la opción -d ha sido especificada.

-d
--data
Solo imprime cadenas de las secciones de datos inicializadas y cargadas en el archivo. Esto puede reducir la cantidad de basura en la salida, pero también expone el programa strings a cualquier fallo de seguridad que pueda estar presente en la biblioteca BFD utilizada para escanear y cargar secciones. Strings puede ser configurado para que esta opción sea el comportamiento por defecto. En tales casos, la opción -a puede ser usada para evitar el uso de la biblioteca BFD y en su lugar imprimir todas las cadenas encontradas en el archivo.
-f
--print-file-name
Imprime el nombre del archivo antes de cada cadena.
--help
Imprime un resumen del uso del programa en la salida estándar y sale.
-len-min
-n len-min
--bytes=len-min
Imprime secuencias de caracteres visibles que tengan al menos len-min caracteres de longitud. Si no se especifica, se utiliza una longitud mínima por defecto de 4. La distinción entre caracteres visibles y no visibles depende de la configuración de las opciones -e y -U. Las secuencias siempre se terminan en caracteres de control como nueva línea y retorno de carro, pero no en el carácter de tabulación.
-o
Similar a -t o. Algunas otras versiones de strings hacen que -o actúe como -t d en su lugar. Dado que no podemos ser compatibles con ambas formas, simplemente elegimos una.
-t base
--radix=base
Imprime el desplazamiento dentro del archivo antes de cada cadena. El argumento de un solo carácter especifica la base del desplazamiento: o para octal, x para hexadecimal, o d para decimal.
-e codificacion
--encoding=codificacion
Selecciona la codificación de caracteres de las cadenas que se van a encontrar. Los valores posibles para codificacion son: s = caracteres de un solo byte de 7 bits (por defecto), S = caracteres de un solo byte de 8 bits, b = 16 bits bigendian, l = 16 bits littleendian, B = 32 bits bigendian, L = 32 bits littleendian. Útil para encontrar cadenas de caracteres anchos. (l y b aplican a, por ejemplo, codificaciones Unicode UTF-16/UCS-2).
-U [d|i|l|e|x|h]
--unicode=[default|invalid|locale|escape|hex|highlight]
Controla la visualización de caracteres multibyte codificados en UTF-8 en las cadenas. Por defecto (--unicode=default) no se les da ningún tratamiento especial, y en su lugar se basa en la configuración de la opción --encoding. Los otros valores para esta opción habilitan automáticamente --encoding=S.

La opción --unicode=invalid los trata como caracteres no gráficos y por lo tanto no forman parte de una cadena válida. Todas las opciones restantes los tratan como caracteres de cadena válidos.

La opción --unicode=locale los muestra en la configuración regional actual, que puede o no soportar la codificación UTF-8. La opción --unicode=hex los muestra como secuencias de bytes hexadecimales encerradas entre caracteres <>. La opción --unicode=escape los muestra como secuencias de escape (\uxxxx) y la opción --unicode=highlight los muestra como secuencias de escape resaltadas en rojo (si el dispositivo de salida lo soporta). El coloreado está destinado a llamar la atención sobre la presencia de secuencias unicode donde podrían no esperarse.

-T nombre-bfd
--target=nombre-bfd
Especifica un formato de código de objeto distinto del formato predeterminado de su sistema.
-v
-V
--version
Imprime el número de versión del programa en la salida estándar y sale.
-w
--include-all-whitespace
Por defecto, los caracteres de tabulación y espacio se incluyen en las cadenas que se muestran, pero otros caracteres de espacio en blanco, como nuevas líneas y retornos de carro, no. La opción -w cambia esto para que todos los caracteres de espacio en blanco se consideren parte de una cadena.
-s
--output-separator
Por defecto, las cadenas de salida están delimitadas por una nueva línea. Esta opción le permite suministrar cualquier cadena para ser usada como el separador de registros de salida. Útil con --include-all-whitespace donde las cadenas pueden contener nuevas líneas internamente.
@archivo
Lee las opciones de línea de comandos desde archivo. Las opciones leídas se insertan en lugar de la opción original @archivo. Si archivo no existe, o no se puede leer, entonces la opción se tratará literalmente y no se eliminará.

Las opciones en archivo están separadas por espacios en blanco. Un carácter de espacio en blanco puede ser incluido en una opción rodeando la opción completa con comillas simples o dobles. Cualquier carácter (incluyendo una barra invertida) puede ser incluido anteponiendo el carácter a incluir con una barra invertida. El archivo puede contener a su vez opciones adicionales @archivo; cualquier opción de este tipo se procesará recursivamente.

VER TAMBIÉN
