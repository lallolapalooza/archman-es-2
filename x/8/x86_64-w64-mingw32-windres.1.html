WINDRES(1) Herramientas de desarrollo de GNU WINDRES(1)

NOMBRE

windres - manipula recursos de Windows

SINOPSIS

windres [opciones] [archivo-entrada] [archivo-salida]

DESCRIPCIÓN

windres lee recursos de un archivo de entrada y los copia a un archivo de salida. Cualquiera de los archivos puede estar en uno de tres formatos:

"rc"
Un formato de texto leído por el Compilador de Recursos.
"res"
Un formato binario generado por el Compilador de Recursos.
"coff"
Un objeto COFF o ejecutable.

La descripción exacta de estos diferentes formatos está disponible en la documentación de Microsoft.

Cuando windres convierte del formato "rc" al formato "res", actúa como el Compilador de Recursos de Windows. Cuando windres convierte del formato "res" al formato "coff", actúa como el programa "CVTRES" de Windows.

Cuando windres genera un archivo "rc", la salida es similar pero no idéntica al formato esperado para la entrada. Cuando un archivo "rc" de entrada hace referencia a un nombre de archivo externo, un archivo "rc" de salida incluirá en su lugar el contenido del archivo.

Si no se especifica el formato de entrada o salida, windres intentará adivinarlo basándose en el nombre del archivo o, para el archivo de entrada, en el contenido del archivo. Un archivo con extensión .rc se tratará como un archivo "rc", un archivo con extensión .res se tratará como un archivo "res", y un archivo con extensión .o o .exe se tratará como un archivo "coff".

Si no se especifica archivo de salida, windres imprimirá los recursos en formato "rc" en la salida estándar.

El uso normal consiste en que usted escriba un archivo "rc", utilice windres para convertirlo a un archivo objeto COFF, y luego enlace el archivo COFF a su aplicación. Esto hará que los recursos descritos en el archivo "rc" estén disponibles para Windows.

OPCIONES

-i nombre-archivo
--input nombre-archivo
El nombre del archivo de entrada. Si esta opción no se utiliza, windres utilizará el primer argumento que no sea una opción como nombre del archivo de entrada. Si no hay argumentos que no sean opciones, windres leerá de la entrada estándar. windres no puede leer un archivo COFF de la entrada estándar.
-o nombre-archivo
--output nombre-archivo
El nombre del archivo de salida. Si esta opción no se utiliza, windres utilizará el primer argumento que no sea una opción, después de cualquiera utilizado para el nombre del archivo de entrada, como nombre del archivo de salida. Si no hay argumentos que no sean opciones, windres escribirá en la salida estándar. windres no puede escribir un archivo COFF en la salida estándar. Tenga en cuenta que, para compatibilidad con rc, también se acepta la opción -fo, pero no se recomienda su uso.
-J formato
--input-format formato
El formato de entrada a leer. formato puede ser res, rc, o coff. Si no se especifica ningún formato de entrada, windres intentará adivinarlo, como se describe anteriormente.
-O formato
--output-format formato
El formato de salida a generar. formato puede ser res, rc, o coff. Si no se especifica ningún formato de salida, windres intentará adivinarlo, como se describe anteriormente.
-F objetivo
--target objetivo
Especifica el formato BFD a utilizar para un archivo COFF como entrada o salida. Este es un nombre de objetivo BFD; puede usar la opción --help para ver una lista de objetivos compatibles. Normalmente windres utilizará el formato predeterminado, que es el primero listado por la opción --help.
--preprocessor programa
Cuando windres lee un archivo "rc", lo pasa primero por el preprocesador de C. Esta opción puede usarse para especificar el preprocesador a utilizar. El preprocesador predeterminado es "gcc".
--preprocessor-arg opción
Cuando windres lee un archivo "rc", lo pasa primero por el preprocesador de C. Esta opción puede usarse para especificar texto adicional a pasar al preprocesador en su línea de comandos. Esta opción puede usarse varias veces para agregar múltiples opciones a la línea de comandos del preprocesador. Si no se ha especificado la opción --preprocessor, se utilizará un conjunto predeterminado de argumentos del preprocesador, y las opciones --preprocessor-arg se colocarán después de ellas en la línea de comandos. Estos argumentos predeterminados son "-E", "-xc-header" y "-DRC_INVOKED".
-I directorio
--include-dir directorio
Especifica un directorio de inclusión a usar al leer un archivo "rc". windres lo pasará al preprocesador como una opción -I. windres también buscará en este directorio al buscar archivos nombrados en el archivo "rc". Si el argumento pasado a este comando coincide con alguno de los formatos admitidos (como se describe en la opción -J), emitirá una advertencia de deprecación y se comportará exactamente como la opción -J. Los programas nuevos no deberían usar este comportamiento. Si un directorio coincide con un formato, simplemente prefíjelo con ./ para deshabilitar la compatibilidad con versiones anteriores.
-D objetivo
--define sim[=val]
Especifica una opción -D para pasar al preprocesador al leer un archivo "rc".
-U objetivo
--undefine sim
Especifica una opción -U para pasar al preprocesador al leer un archivo "rc".
-r
Ignorado por compatibilidad con rc.
-v
Habilita el modo detallado. Esto le informa cuál es el preprocesador si no especificó uno.
-c val
--codepage val
Especifica la página de códigos predeterminada a utilizar al leer un archivo "rc". val debe ser un código de página de códigos decimal o hexadecimal prefijado con 0x. El rango válido es de cero hasta 0xffff, pero la validez de la página de códigos depende del host y de la configuración.
-l val
--language val
Especifica el idioma predeterminado a utilizar al leer un archivo "rc". val debe ser un código de idioma hexadecimal. Los ocho bits inferiores son el idioma y los ocho bits superiores son el subidioma.
--use-temp-file
Utiliza un archivo temporal en lugar de usar popen para leer la salida del preprocesador. Utilice esta opción si la implementación de popen tiene errores en el host (por ejemplo, ciertas versiones de Windows 95 y Windows 98 en idioma no inglés).

OPCIONES

--help
Muestra un resumen de uso.
--no-use-temp-file
Utiliza popen, no un archivo temporal, para leer la salida del preprocesador. Este es el comportamiento predeterminado.
-h
-v
Imprime la versión de windres.
--version
Imprime el número de versión de windres.
--yydebug
Si windres está compilado con "YYDEBUG" definido como 1, esto activará la depuración del analizador.
@archivo
Lee las opciones de la línea de comandos del archivo. Las opciones leídas se insertan en lugar de la opción original @archivo. Si archivo no existe o no se puede leer, la opción se tratará literalmente y no se eliminará.

Las opciones en archivo están separadas por espacios en blanco. Se puede incluir un carácter de espacio en blanco en una opción rodeando la opción completa con comillas simples o dobles. Se puede incluir cualquier carácter (incluido una barra invertida) prefijando el carácter a incluir con una barra invertida. El archivo puede contener opciones adicionales @archivo; dichas opciones se procesarán recursivamente.
