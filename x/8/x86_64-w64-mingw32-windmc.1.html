WINDMC(1) GNU Development Tools WINDMC(1)

NOMBRE

windmc - genera recursos de mensajes de Windows

SINOPSIS

windmc [opciones] archivo-entrada

DESCRIPCIÓN

windmc lee definiciones de mensajes desde un archivo de entrada (.mc) y las traduce a un conjunto de archivos de salida. Los archivos de salida pueden ser de cuatro tipos:

"h"
Un archivo de cabecera C que contiene las definiciones de mensajes.
"rc"
Un archivo de recursos compilable por la herramienta windres.
"bin"
Uno o más archivos binarios que contienen los datos de recursos para un idioma de mensajes específico.
"dbg"
Un archivo de inclusión C que mapea los id. de mensajes a su nombre simbólico.

La descripción exacta de estos diferentes formatos está disponible en la documentación de Microsoft.

Cuando windmc convierte del formato "mc" al formato "bin", "rc", "h", y opcionalmente "dbg", actúa como el Compilador de Mensajes de Windows.

OPCIONES

-a
--ascii_in
Especifica que el archivo de entrada especificado es ASCII. Este es el comportamiento por defecto.
-A
--ascii_out
Especifica que los mensajes en los archivos "bin" de salida deben estar en formato ASCII.
-b
--binprefix
Especifica que los nombres de archivo "bin" deben tener el prefijo del nombre base del archivo fuente.
-c
--customflag
Establece el bit de cliente en todos los id. de mensajes.
-C codepage
--codepage_in codepage
Establece la página de códigos por defecto que se utilizará para convertir el archivo de entrada a UTF16. La página de códigos por defecto es 1252.
-d
--decimal_values
Genera las constantes en el archivo de cabecera en decimal. Por defecto se utiliza salida hexadecimal.
-e ext
--extension ext
La extensión para el archivo de cabecera. La extensión por defecto es .h.
-F target
--target target
Especifica el formato BFD a utilizar para un archivo bin como salida. Este es un nombre de destino BFD; puede usar la opción --help para ver una lista de destinos soportados. Normalmente windmc usará el formato por defecto, que es el primero listado por la opción --help.
-h path
--headerdir path
El directorio de destino del archivo de cabecera generado. Por defecto es el directorio actual.
-H
--help
Muestra una lista de las opciones de la línea de comandos y luego sale.
-m characters
--maxlength characters
Instruye a windmc para que genere una advertencia si la longitud de cualquier mensaje excede el número especificado.
-n
--nullterminate
Termina el texto del mensaje en los archivos "bin" con un cero. Por defecto, están terminados por CR/LF.
-o
--hresult_use
Aún no implementado. Instruye a "windmc" para generar un archivo de cabecera OLE2, utilizando definiciones HRESULT. Se utilizan códigos de estado si la bandera no está especificada.
-O codepage
--codepage_out codepage
Establece la página de códigos por defecto que se utilizará para generar archivos de texto. La página de códigos por defecto es 1252.
-r path
--rcdir path
El directorio de destino para el script "rc" generado y los archivos "bin" generados que el script del compilador de recursos incluye. Por defecto es el directorio actual.
-u
--unicode_in
Especifica que el archivo de entrada es UTF16.
-U
--unicode_out
Especifica que los mensajes en el archivo "bin" de salida deben estar en formato UTF16. Este es el comportamiento por defecto.
-v
--verbose
Habilita el modo detallado.
-V
--version
Imprime el número de versión de windmc.
-x path
--xdgb path
La ruta del archivo de inclusión C "dbg" que mapea los id. de mensajes al nombre simbólico. No se genera ningún archivo sin especificar esta opción.
@file
Lee las opciones de la línea de comandos desde file. Las opciones leídas se insertan en lugar de la opción @file original. Si file no existe, o no se puede leer, la opción se tratará literalmente y no se eliminará.

Las opciones en file están separadas por espacios en blanco. Un carácter de espacio en blanco puede incluirse en una opción rodeando la opción completa con comillas simples o dobles. Cualquier carácter (incluido una barra invertida) puede incluirse anteponiendo el carácter a incluir con una barra invertida. El file puede contener opciones adicionales @file; cualquier opción de este tipo se procesará recursivamente.
