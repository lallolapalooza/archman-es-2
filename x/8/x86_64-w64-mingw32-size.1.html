SIZE(1) Herramientas de Desarrollo de GNU SIZE(1)

NOMBRE

size - lista tamaños de sección y tamaño total de archivos binarios

SINOPSIS

size [-A|-B|-G|--formato=compatibilidad]
[--ayuda]
[-d|-o|-x|--base=numero]
[--comunes]
[-t|--totales]
[--objetivo=nombre_bfd] [-V|--version]
[-f]
[archivo_obj...]

DESCRIPCIÓN

La utilidad size de GNU lista los tamaños de sección y el tamaño total para cada uno de los archivos binarios archivo_obj en su lista de argumentos. Por defecto, se genera una línea de salida por cada archivo o por cada módulo si el archivo es un archivo.

archivo_obj... son los archivos a examinar. Si no se especifica ninguno, se utilizará el archivo "a.out" en su lugar.

OPCIONES

Las opciones de la línea de comandos tienen los siguientes significados:

-A
-B
-G
--formato=compatibilidad
Usando una de estas opciones, puedes elegir si la salida de size de GNU se parece a la salida de size de System V (usando -A, o --formato=sysv), o a la de size de Berkeley (usando -B, o --formato=berkeley). El valor por defecto es el formato de una línea similar al de Berkeley. Alternativamente, puedes elegir la salida con formato GNU (usando -G, o --formato=gnu), esto es similar al formato de salida de Berkeley, pero los tamaños se cuentan de forma diferente.

Aquí tienes un ejemplo del formato de Berkeley (por defecto) de la salida de size:

$ size --formato=Berkeley ranlib size
   text    data     bss     dec     hex filename
 294880   81920   11592  388392   5ed28 ranlib
 294880   81920   11888  388688   5ee50 size

La salida estilo Berkeley cuenta los datos de solo lectura en la columna "text", no en la columna "data", las columnas "dec" y "hex" muestran ambas la suma de las columnas "text", "data" y "bss" en decimal y hexadecimal respectivamente.

El formato GNU cuenta los datos de solo lectura en la columna "data", no en la columna "text", y solo muestra la suma de las columnas "text", "data" y "bss" una vez, en la columna "total". La opción --base se puede usar para cambiar la base numérica de todas las columnas. Aquí están los mismos datos mostrados con convenciones GNU:

$ size --formato=GNU ranlib size
      text       data        bss      total filename
    279880      96920      11592     388392 ranlib
    279880      96920      11888     388688 size

Estos son los mismos datos, pero mostrados más cerca de las convenciones de System V:

$ size --formato=SysV ranlib size
ranlib  :
section         size         addr
.text         294880         8192
.data          81920       303104
.bss           11592       385024
Total         388392


size  :
section         size         addr
.text         294880         8192
.data          81920       303104
.bss           11888       385024
Total         388688
--ayuda
-h
-H
-?
Muestra un resumen de los argumentos y opciones aceptables.
-d
-o
-x
--base=numero
Usando una de estas opciones, puedes controlar si el tamaño de cada sección se da en decimal (-d, o --base=10); octal (-o, o --base=8); o hexadecimal (-x, o --base=16). En --base=numero, solo los tres valores (8, 10, 16) son compatibles. El tamaño total siempre se da en dos bases; decimal y hexadecimal para la salida de -d o -x, u octal y hexadecimal si estás usando -o.
--comunes
Imprime el tamaño total de los símbolos comunes en cada archivo. Cuando se usa el formato Berkeley o GNU, estos se incluyen en el tamaño bss.
-t
--totales
Muestra los totales de todos los objetos listados (solo en modo de formato Berkeley o GNU).
--objetivo=nombre_bfd
Especifica que el formato del código objeto de archivo_obj es nombre_bfd. Esta opción puede no ser necesaria; size puede reconocer automáticamente muchos formatos.
-v
-V
--version
Muestra el número de versión de size.
-f
Ignorada. Esta opción es usada por otras versiones del programa size, pero no es compatible con la versión de GNU Binutils.
@archivo
Lee las opciones de la línea de comandos desde archivo. Las opciones leídas se insertan en lugar de la opción original @archivo. Si archivo no existe, o no se puede leer, entonces la opción se tratará literalmente, y no se eliminará.

Las opciones en archivo están separadas por espacios en blanco. Un carácter de espacio en blanco puede incluirse en una opción rodeando la opción completa con comillas simples o dobles. Cualquier carácter (incluyendo una barra invertida) puede incluirse prefijando el carácter a incluir con una barra invertida. El archivo puede contener él mismo opciones adicionales de @archivo; cualquier opción de este tipo se procesará recursivamente.
