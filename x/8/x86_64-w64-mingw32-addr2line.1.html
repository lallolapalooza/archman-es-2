ADDR2LINE(1) Herramientas de desarrollo GNU ADDR2LINE(1)

NOMBRE

addr2line - convertir direcciones o símbolo+desplazamiento en nombres de archivo y números de línea

SINOPSIS

addr2line [-a|--addresses]
[-b nombrebfd|--target=nombrebfd]
[-C|--demangle[=estilo]]
[-r|--no-recurse-limit]
[-R|--recurse-limit]
[-e nombrearchivo|--exe=nombrearchivo]
[-f|--functions] [-s|--basename]
[-i|--inlines]
[-p|--pretty-print]
[-j|--section=nombre]
[-H|--help] [-V|--version]
[dir dir ...]

DESCRIPCIÓN

addr2line traduce direcciones o símbolo+desplazamiento a nombres de archivo y números de línea. Dada una dirección o símbolo+desplazamiento en un ejecutable o un desplazamiento en una sección de un objeto relocable, utiliza la información de depuración para determinar qué nombre de archivo y número de línea están asociados con él.

El ejecutable u objeto relocable a utilizar se especifica con la opción -e. El valor predeterminado es el archivo a.out. La sección en el objeto relocable a utilizar se especifica con la opción -j.

addr2line tiene dos modos de operación.

En el primero, se especifican direcciones hexadecimales o símbolo+desplazamiento en la línea de comandos, y addr2line muestra el nombre del archivo y el número de línea para cada dirección.

En el segundo, addr2line lee direcciones hexadecimales o símbolo+desplazamiento de la entrada estándar, e imprime el nombre del archivo y el número de línea para cada dirección en la salida estándar. En este modo, addr2line puede ser utilizado en una tubería para convertir direcciones seleccionadas dinámicamente.

El formato de la salida es NOMBREARCHIVO:NUMEROLINEA. Por defecto, cada dirección de entrada genera una línea de salida.

Dos opciones pueden generar líneas adicionales antes de cada línea de NOMBREARCHIVO:NUMEROLINEA (en ese orden).

Si se utiliza la opción -a, entonces se mostrará una línea con la dirección de entrada.

Si se utiliza la opción -f, entonces se mostrará una línea con el NOMBREFUNCION. Este es el nombre de la función que contiene la dirección.

Una opción puede generar líneas adicionales después de la línea de NOMBREARCHIVO:NUMEROLINEA.

Si se utiliza la opción -i y el código en la dirección dada está presente allí debido a la inlining del compilador, entonces se mostrarán líneas adicionales después. Se mostrarán una o dos líneas adicionales (si se utiliza la opción -f) para cada función inlineada.

Alternativamente, si se utiliza la opción -p, entonces cada dirección de entrada genera una única línea de salida larga que contiene la dirección, el nombre de la función, el nombre del archivo y el número de línea. Si también se ha utilizado la opción -i, entonces las funciones inlineadas se mostrarán de la misma manera, pero en líneas separadas y con el prefijo de texto (inlineado por).

Si el nombre del archivo o el nombre de la función no pueden ser determinados, addr2line imprimirá dos signos de interrogación en su lugar. Si el número de línea no puede ser determinado, addr2line imprimirá 0.

Cuando se utiliza símbolo+desplazamiento, +desplazamiento es opcional, excepto cuando el símbolo es ambiguo con un número hexadecimal. Los símbolos resueltos pueden estar codificados o decodificados, excepto que los símbolos no codificados con + no están permitidos.

OPCIONES

Las formas largas y cortas de las opciones, que se muestran aquí como alternativas, son equivalentes.

-a
--addresses
Muestra la dirección antes de la información del nombre de la función, archivo y número de línea. La dirección se imprime con un prefijo 0x para identificarla fácilmente.
-b nombrebfd
--target=nombrebfd
Especifica que el formato del código objeto para los archivos objeto es nombrebfd.
-C
--demangle[=estilo]
Decodifica (demangle) nombres de símbolos de bajo nivel en nombres de nivel de usuario. Además de eliminar cualquier guion bajo inicial agregado por el sistema, esto hace que los nombres de funciones de C++ sean legibles. Diferentes compiladores tienen diferentes estilos de mangling. El argumento opcional de estilo de demangling puede usarse para elegir un estilo de demangling apropiado para su compilador.
-e nombrearchivo
--exe=nombrearchivo
Especifica el nombre del ejecutable para el cual se deben traducir las direcciones. El archivo predeterminado es a.out.
-f
--functions
Muestra los nombres de las funciones, así como la información del archivo y el número de línea.
-s
--basenames
Muestra solo la parte base de cada nombre de archivo.
-i
--inlines
Si la dirección pertenece a una función que se ha inlineado, también se mostrará la información de origen de todos los ámbitos envolventes hasta la primera función no inlineada. Por ejemplo, si "main" inlinea "callee1" que inlinea "callee2", y la dirección es de "callee2", también se mostrará la información de origen de "callee1" y "main".
-j
--section
Lee los desplazamientos relativos a la sección especificada en lugar de direcciones absolutas.
-p
--pretty-print
Hace que la salida sea más amigable para el humano: cada ubicación se imprime en una línea. Si se especifica la opción -i, las líneas para todos los ámbitos envolventes se prefijan con (inlineado por).
-r
-R
--recurse-limit
--no-recurse-limit
--recursion-limit
--no-recursion-limit
Habilita o deshabilita un límite en la cantidad de recursión realizada al decodificar cadenas. Dado que los formatos de mangling de nombres permiten un nivel infinito de recursión, es posible crear cadenas cuya decodificación agote la cantidad de espacio en la pila disponible en la máquina host, activando una falla de memoria. El límite intenta evitar que esto suceda al restringir la recursión a 2048 niveles de anidamiento.

El valor predeterminado es que este límite esté habilitado, pero deshabilitarlo puede ser necesario para decodificar nombres verdaderamente complicados. Tenga en cuenta, sin embargo, que si el límite de recursión está deshabilitado, es posible el agotamiento de la pila y cualquier informe de error sobre tal evento será rechazado.

La opción -r es un sinónimo de la opción --no-recurse-limit. La opción -R es un sinónimo de la opción --recurse-limit.

Tenga en cuenta que esta opción solo es efectiva si se ha habilitado la opción -C o --demangle.

@archivo
Lee las opciones de la línea de comandos de archivo. Las opciones leídas se insertan en lugar de la opción @archivo original. Si archivo no existe, o no se puede leer, entonces la opción se tratará literalmente y no se eliminará.

Las opciones en archivo están separadas por espacios en blanco. Se puede incluir un carácter de espacio en blanco en una opción rodeando la opción completa con comillas simples o dobles. Se puede incluir cualquier carácter (incluido una barra invertida) prefijando el carácter a incluir con una barra invertida. El archivo puede contener opciones adicionales de @archivo; cualquiera de dichas opciones se procesará recursivamente.

NAME

addr2line, minstrel, c++filt - translate addresses into program names, offsets, and line numbers or virtual addresses to line sections for GNU Binutils.

SYNOPSIS

addr2line [-a] [-e progname] [-f] [-C] [-p] [-R] [-i] [-l] [-s] [-V] [-w] [-h] [address...]

minstrel [-h] [-V] [address...]

c++filt [-h] [-p] [-i] [-C] [-V] [name...]

DESCRIPTION

The addr2line utility converts addresses into file names and line numbers. It can also be used to find out which section an address is in.

The minstrel utility is a synonym for addr2line.

The c++filt utility demangles C++ symbol names, translating them back into names that are more easily read by humans.

OPTIONS

-a
Print the virtual address before each response.
-C
Demangle C++ symbol names. This option should be used when demangling function names.
-e progname
Use progname as the input file (default: a.out).
-f
Print the function name as well as the file and line number.
-h
Print a help message.
-i
Print inline stack information.
-l
Print the section name for each address.
-p
Print the nearest symbol name.
-R
Print the nearest symbol name and offset.
-s
Print only the section names.
-V
Print the version number of addr2line.
-w
Print the name of the file containing the address.

The addr2line utility may be used to translate addresses into source code line numbers. The addresses are specified on the command line, and the program will print the corresponding file names and line numbers. If the addresses are not specified, addr2line will read them from the standard input. The program will then try to infer the names of the functions from the addresses, and print the function names as well.

The c++filt utility may be used to demangle C++ symbol names. The symbol names are specified on the command line, and the program will print the demangled names. If the symbol names are not specified, c++filt will read them from the standard input.

The addr2line utility recursively processes the input file to find the addresses.
