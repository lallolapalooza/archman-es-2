NOMBRE

strip - descarta símbolos y otros datos de archivos objeto

SINOPSIS

strip [-F bfdname |--target=bfdname]
[-I bfdname |--input-target=bfdname]
[-O bfdname |--output-target=bfdname]
[-s|--strip-all]
[-S|-g|-d|--strip-debug]
[--strip-dwo]
[-K nombre-simbolo|--keep-symbol=nombre-simbolo]
[-M|--merge-notes][--no-merge-notes]
[-N nombre-simbolo |--strip-symbol=nombre-simbolo]
[-w|--wildcard]
[-x|--discard-all] [-X |--discard-locals]
[-R nombre-seccion |--remove-section=nombre-seccion]
[--keep-section=patron-seccion]
[--remove-relocations=patron-seccion]
[--strip-section-headers]
[-o archivo] [-p|--preserve-dates]
[-D|--enable-deterministic-archives]
[-U|--disable-deterministic-archives]
[--keep-section-symbols]
[--keep-file-symbols]
[--only-keep-debug]
[--plugin nombre]
[-v |--verbose] [-V|--version]
[--help] [--info]
archivo-objeto...

DESCRIPCIÓN

GNU strip descarta todos los símbolos de los archivos objeto archivo-objeto. La lista de archivos objeto puede incluir archivos. Se debe proporcionar al menos un archivo objeto.

strip modifica los archivos nombrados en su argumento, en lugar de escribir copias modificadas con nombres diferentes.

OPCIONES

-F bfdname
--target=bfdname
Trata el archivo-objeto original como un archivo con el formato de código objeto bfdname, y lo reescribe en el mismo formato.
--help
Muestra un resumen de las opciones de strip y sale.
--info
Muestra una lista que indica todas las arquitecturas y formatos de objeto disponibles.
-I bfdname
--input-target=bfdname
Trata el archivo-objeto original como un archivo con el formato de código objeto bfdname.
-O bfdname
--output-target=bfdname
Reemplaza archivo-objeto con un archivo en el formato de salida bfdname.
-R nombre-seccion
--remove-section=nombre-seccion
Elimina cualquier sección llamada nombre-seccion del archivo de salida, además de las que de otra manera serían eliminadas. Esta opción puede darse más de una vez. Ten en cuenta que usar esta opción de forma inapropiada puede hacer que el archivo de salida sea inutilizable. El carácter comodín * puede darse al final de nombre-seccion. Si es así, se eliminarán todas las secciones que comiencen con nombre-seccion.

Si el primer carácter de patron-seccion es el signo de exclamación (!), entonces las secciones coincidentes no se eliminarán, incluso si un uso anterior de --remove-section en la misma línea de comandos las eliminara. Por ejemplo:

--remove-section=.text.* --remove-section=!.text.foo

eliminará todas las secciones que coincidan con el patrón '.text.*', pero no eliminará la sección '.text.foo'.

--keep-section=patron-seccion
Al eliminar secciones del archivo de salida, conserva las secciones que coinciden con patron-seccion.
--remove-relocations=patron-seccion
Elimina las reubicaciones del archivo de salida para cualquier sección que coincida con patron-seccion. Esta opción puede darse más de una vez. Ten en cuenta que usar esta opción de forma inapropiada puede hacer que el archivo de salida sea inutilizable. Se aceptan caracteres comodín en patron-seccion. Por ejemplo: 
--remove-relocations=.text.*

eliminará las reubicaciones de todas las secciones que coincidan con el patrón '.text.*'.

Si el primer carácter de patron-seccion es el signo de exclamación (!), entonces las reubicaciones de las secciones coincidentes no se eliminarán, incluso si un uso anterior de --remove-relocations en la misma línea de comandos causara que las reubicaciones se eliminaran. Por ejemplo:

--remove-relocations=.text.* --remove-relocations=!.text.foo

eliminará todas las reubicaciones para las secciones que coincidan con el patrón '.text.*', pero no eliminará las reubicaciones para la sección '.text.foo'.

--strip-section-headers
Elimina las cabeceras de sección. Esta opción es específica para archivos ELF. Implica --strip-all y --merge-notes.
-s
--strip-all
Elimina todos los símbolos.
-g
-S
-d
--strip-debug
Elimina solo los símbolos de depuración.
--strip-dwo
Elimina el contenido de todas las secciones DWARF .dwo, dejando intactas las secciones de depuración restantes y todos los símbolos. Consulta la descripción de esta opción en la sección objcopy para más información.
--strip-unneeded
Elimina todos los símbolos que no son necesarios para el procesamiento de reubicaciones, además de los símbolos y secciones de depuración que se eliminan con --strip-debug.
-K nombre-simbolo
--keep-symbol=nombre-simbolo
Al eliminar símbolos, conserva el símbolo nombre-simbolo aunque normalmente sería eliminado. Esta opción puede darse más de una vez.
-M
--merge-notes
--no-merge-notes
Para archivos ELF, intenta (o no intenta) reducir el tamaño de cualquier sección de tipo SHT_NOTE eliminando notas duplicadas. Por defecto, se intenta esta reducción a menos que se elimine información de depuración o DWO.
-N nombre-simbolo
--strip-symbol=nombre-simbolo
Elimina el símbolo nombre-simbolo del archivo fuente. Esta opción puede darse más de una vez y puede combinarse con otras opciones de strip que no sean -K.
-o archivo
Coloca la salida modificada en archivo, en lugar de reemplazar el archivo existente. Cuando se usa este argumento, solo se puede especificar un argumento archivo-objeto.
-p
--preserve-dates
Conserva las fechas de acceso y modificación del archivo.
-D
--enable-deterministic-archives
Opera en modo determinista. Al copiar miembros de archivo y escribir el índice del archivo, usa cero para UID, GID, marcas de tiempo y usa modos de archivo consistentes para todos los archivos.

Si binutils se configuró con --enable-deterministic-archives, entonces este modo está activado por defecto. Se puede desactivar con la opción -U, a continuación.

-U
--disable-deterministic-archives
No opera en modo determinista. Esto deshabilita el comportamiento deterministra del modo -D. Si binutils se configuró con --enable-deterministic-archives, entonces este modo está desactivado por defecto, y se puede habilitar con la opción -D. La opción -D anula a -U.
--keep-section-symbols
No elimine los símbolos que hacen referencia a secciones (por ejemplo, S_SectionSymbols en COFF).
--keep-file-symbols
No elimine los símbolos que hacen referencia a nombres de archivo (por ejemplo, S_FileLine en COFF).
--only-keep-debug
Conserva solo la información de depuración. Elimina todas las secciones que no son de depuración y los símbolos no de depuración. Los símbolos de depuración se conservan.
--plugin nombre
Carga un plugin de BFD llamado nombre. Esto puede usarse para proporcionar soporte para formatos de objeto adicionales.
-V
--version
Muestra la información de versión de strip y sale.
-v
--verbose
Muestra información detallada sobre las operaciones realizadas.
-w
--wildcard
Permite que los caracteres comodín sean utilizados en las opciones --strip-symbol, --keep-symbol, --remove-section y --keep-section. El comodín * coincide con cero o más caracteres, y el comodín ? coincide con exactamente un carácter. Los caracteres comodín deben estar entre comillas simples para evitar que sean interpretados por el shell.
-x
--discard-all
Elimina todos los símbolos no locales.
-X
--discard-locals
Elimina todos los símbolos locales no necesarios.

EJEMPLOS

Para eliminar todos los símbolos de depuración de un archivo objeto llamado a.out:

strip --strip-debug a.out

Para eliminar todos los símbolos de un archivo objeto llamado a.out:

strip --strip-all a.out

Para eliminar el símbolo llamado my_symbol de un archivo objeto llamado a.out:

strip --strip-symbol my_symbol a.out

Para eliminar todos los símbolos de los archivos objeto en un directorio:

strip *.o

VÉASE TAMBIÉN

objdump(1), objcopy(1)

CONFORME A

La utilidad strip se describe en la especificación POSIX.1-2008, utilidades de línea de comandos. El comando de GNU strip es compatible con este estándar.

La mayoría de las opciones de formato de archivo de GNU strip son extensiones de GNU.

NAME

strip - remove symbols from object files

SYNOPSIS

strip [-s] [--strip-all] [-g] [--strip-debug] [-S] [-d] [--strip-unneeded] [-N symbolname] [--strip-symbol=symbolname] [-K symbolname] [--keep-symbol=symbolname] [-u] [--discard-all] [-x] [--discard-locals] [-w] [--wildcard] [--keep-section-symbols] [--keep-file-symbols] [--only-keep-debug] [--plugin=name] [-V] [--version] [-v] [--verbose] [--help] [--info] [--fatal-warnings] [--no-warn-mismatch] [@file] [objfile...]

DESCRIPTION

The strip utility may be used to reduce the size of object files, executables and core dumps by removing unnecessary symbol information. It operates on object files, executables and core dumps.

strip can remove all symbols, only the debugging symbols, or only local symbols.

The default behavior, if no options are specified, is to remove all symbols except for the function and file name symbols that are needed for run-time relocation processing.

Options affecting which symbols are stripped may be repeated. The final set of symbols is the union of all symbols specified for stripping.

Options affecting which symbols are kept may be repeated. The final set of symbols is the intersection of all symbols specified for keeping.

The default behavior is to strip all symbols, except for those required for relocation processing.

If no object files are specified, the standard input is used.

OPTIONS

-s
--strip-all
Strip all symbols from executable files.
-g
--strip-debug
Strip debugging symbols from executable files. Debugging symbols are symbols that start with a . or a L. This option doesn't remove symbols that are needed for relocation processing.
-S
-d
--strip-unneeded
Strip symbols not needed for relocation processing.
-N symbolname
--strip-symbol=symbolname
Do not strip symbol symbolname. This option can be specified multiple times.
-K symbolname
--keep-symbol=symbolname
Do not strip symbol symbolname. This option can be specified multiple times.
-u
Operate in deterministic mode. This is the inverse of the -D option, above: when copying archive members and writing the archive index, use their actual UID, GID, timestamp, and file mode values.

This is the default unless binutils was configured with --enable-deterministic-archives.

-w
--wildcard
Permit regular expressions in symbolnames used in other command line options. The question mark (?), asterisk (*), backslash (\) and square brackets ([]) operators can be used anywhere in the symbol name. If the first character of the symbol name is the exclamation point (!) then the sense of the switch is reversed for that symbol. For example: 
-w -K !foo -K fo*

would cause strip to only keep symbols that start with the letters "fo", but to discard the symbol "foo".

-x
--discard-all
Remove non-global symbols.
-X
--discard-locals
Remove compiler-generated local symbols. (These usually start with L or ..)
--keep-section-symbols
When stripping a file, perhaps with --strip-debug or --strip-unneeded, retain any symbols specifying section names, which would otherwise get stripped.
--keep-file-symbols
When stripping a file, perhaps with --strip-debug or --strip-unneeded, retain any symbols specifying source file names, which would otherwise get stripped.
--only-keep-debug
Strip a file, emptying the contents of any sections that would not be stripped by --strip-debug and leaving the debugging sections intact. In ELF files, this preserves all the note sections in the output as well.

Note - the section headers of the stripped sections are preserved, including their sizes, but the contents of the section are discarded. The section headers are preserved so that other tools can match up the debuginfo file with the real executable, even if that executable has been relocated to a different address space.

The intention is that this option will be used in conjunction with --add-gnu-debuglink to create a two part executable. One a stripped binary which will occupy less space in RAM and in a distribution and the second a debugging information file which is only needed if debugging abilities are required. The suggested procedure to create these files is as follows:

1.<Link the executable as normal. Assuming that it is called>
"foo" then...
1.<Run "objcopy --only-keep-debug foo foo.dbg" to>
create a file containing the debugging info.
1.<Run "objcopy --strip-debug foo" to create a>
stripped executable.
1.<Run "objcopy --add-gnu-debuglink=foo.dbg foo">
to add a link to the debugging info into the stripped executable.

Note---the choice of ".dbg" as an extension for the debug info file is arbitrary. Also the "--only-keep-debug" step is optional. You could instead do this:

1.<Link the executable as normal.>
1.<Copy "foo" to "foo.full">
1.<Run "strip --strip-debug foo">
1.<Run "objcopy --add-gnu-debuglink=foo.full foo">

i.e., the file pointed to by the --add-gnu-debuglink can be the full executable. It does not have to be a file created by the --only-keep-debug switch.

Note---this switch is only intended for use on fully linked files. It does not make sense to use it on object files where the debugging information may be incomplete. Besides the gnu_debuglink feature currently only supports the presence of one filename containing debugging information, not multiple filenames on a one-per-object-file basis.

--plugin name
Load the plugin called name to add support for extra target types. This option is only available if the toolchain has been built with plugin support enabled.

If --plugin is not provided, but plugin support has been enabled then strip iterates over the files in ${libdir}/bfd-plugins in alphabetic order and the first plugin that claims the object in question is used.

Please note that this plugin search directory is not the one used by ld's -plugin option. In order to make strip use the linker plugin it must be copied into the ${libdir}/bfd-plugins directory. For GCC based compilations the linker plugin is called liblto_plugin.so.0.0.0. For Clang based compilations it is called LLVMgold.so. The GCC plugin is always backwards compatible with earlier versions, so it is sufficient to just copy the newest one.

-V
--version
Show the version number for strip.
-v
--verbose
Verbose output: list all object files modified. In the case of archives, strip -v lists all members of the archive.
--help
Show a summary of options.
--info
Show information about the capabilities of strip.
--fatal-warnings
Treat all warnings as errors.
--no-warn-mismatch
Do not warn if a symbol has a different type in different object files.
@file
Read command-line options from file. The options read are inserted in place of the original @file option. If file does not exist, or cannot be read, then the option will be treated literally, and not removed.

Options in file are separated by whitespace. A whitespace character may be included in an option by surrounding the entire option in either single or double quotes. Any character (including a backslash) may be included by prefixing the character to be included with a backslash. The file may itself contain additional @file options; any such options will be processed recursively.
