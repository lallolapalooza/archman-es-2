Paquete: mingw-w64-binutils

NM(1) Herramientas de desarrollo GNU NM(1)

NOMBRE

nm - lista símbolos de archivos objeto

SINOPSIS

nm [-A|-o|--print-file-name]
[-a|--debug-syms]
[-B|--format=bsd]
[-C|--demangle[=estilo]]
[-D|--dynamic]
[-fformato|--format=formato]
[-g|--extern-only]
[-h|--help]
[--ifunc-chars=CARACTERES]
[-j|--format=just-symbols]
[-l|--line-numbers] [--inlines]
[-n|-v|--numeric-sort]
[-P|--portability]
[-p|--no-sort]
[-r|--reverse-sort]
[-S|--print-size]
[-s|--print-armap]
[-t raíz|--radix=raíz]
[-u|--undefined-only]
[-U|--defined-only]
[-V|--version]
[-W|--no-weak]
[-X 32_64]
[--no-demangle]
[--no-recurse-limit|--recurse-limit]]
[--plugin nombre]
[--size-sort]
[--special-syms]
[--synthetic]
[--target=bfdname]
[--unicode=método]
[--with-symbol-versions]
[--without-symbol-versions]
[archivo_objeto...]

DESCRIPCIÓN

GNU nm lista los símbolos de los archivos objeto archivo_objeto.... Si no se especifican archivos objeto como argumentos, nm asume el archivo a.out.

Para cada símbolo, nm muestra:

  • El valor del símbolo, en la base seleccionada por las opciones (ver abajo), o hexadecimal por defecto.
  • El tipo del símbolo. Al menos los siguientes tipos se utilizan; otros también lo son, dependiendo del formato del archivo objeto. Si está en minúsculas, el símbolo es usualmente local; si está en mayúsculas, el símbolo es global (externo). Sin embargo, hay algunos símbolos en minúsculas que se muestran para símbolos globales especiales ("u", "v" y "w").
"A"
El valor del símbolo es absoluto y no será modificado por enlaces posteriores.
"B"
"b"
El símbolo está en la sección de datos BSS. Esta sección típicamente contiene datos inicializados a cero o no inicializados, aunque el comportamiento exacto depende del sistema.
"C"
"c"
El símbolo es común. Los símbolos comunes son datos no inicializados. Al enlazar, múltiples símbolos comunes pueden aparecer con el mismo nombre. Si el símbolo está definido en algún lugar, los símbolos comunes se tratan como referencias indefinidas. El carácter c en minúsculas se utiliza cuando el símbolo está en una sección especial para comunes pequeños.
"D"
"d"
El símbolo está en la sección de datos inicializados.
"G"
"g"
El símbolo está en una sección de datos inicializados para objetos pequeños. Algunos formatos de archivos objeto permiten un acceso más eficiente a objetos de datos pequeños, como una variable entera global en lugar de un array global grande.
"i"
Para archivos con formato PE, esto indica que el símbolo está en una sección específica de la implementación de DLLs.

Para archivos con formato ELF, esto indica que el símbolo es una función indirecta. Esta es una extensión de GNU al conjunto estándar de tipos de símbolos ELF. Indica un símbolo que, si se referencia mediante una relocalización, no se evalúa a su dirección, sino que debe invocarse en tiempo de ejecución. La ejecución en tiempo de ejecución devolverá el valor a utilizar en la relocalización.

Nota: la visualización real de símbolos para símbolos indirectos de GNU está controlada por la opción de línea de comandos --ifunc-chars. Si se ha proporcionado esta opción, el primer carácter de la cadena se utilizará para los símbolos de función indirecta globales. Si la cadena contiene un segundo carácter, este se utilizará para los símbolos de función indirecta locales.

"I"
El símbolo es una referencia indirecta a otro símbolo.
"N"
El símbolo es un símbolo de depuración.
"n"
El símbolo está en una sección de solo lectura que no es de datos, código o depuración.
"p"
El símbolo está en una sección de desenrollado de pila.
"R"
"r"
El símbolo está en una sección de datos de solo lectura.
"S"
"s"
El símbolo está en una sección de datos inicializados o inicializados a cero para objetos pequeños.
"T"
"t"
El símbolo está en la sección de texto (código).
"U"
El símbolo es indefinido.
"u"
El símbolo es un símbolo global único. Esta es una extensión de GNU al conjunto estándar de enlaces de símbolos ELF. Para un símbolo de este tipo, el enlazador dinámico se asegurará de que en todo el proceso solo se utilice un símbolo con este nombre y tipo.
"V"
"v"
El símbolo es un objeto débil. Cuando un símbolo definido débil se enlaza con un símbolo definido normal, se utiliza el símbolo definido normal sin error. Cuando se enlaza un símbolo indefinido débil y el símbolo no está definido, el valor del símbolo débil se convierte en cero sin error. En algunos sistemas, las mayúsculas indican que se ha especificado un valor predeterminado.
"W"
"w"
El símbolo es un símbolo débil que no ha sido etiquetado específicamente como símbolo de objeto débil. Cuando un símbolo definido débil se enlaza con un símbolo definido normal, se utiliza el símbolo definido normal sin error. Cuando se enlaza un símbolo indefinido débil y el símbolo no está definido, el valor del símbolo se determina de manera específica del sistema sin error. En algunos sistemas, las mayúsculas indican que se ha especificado un valor predeterminado.
"-"
El símbolo es un símbolo stabs en un archivo objeto a.out. En este caso, los siguientes valores que se imprimen son el campo other de stabs, el campo desc de stabs y el tipo stab. Los símbolos Stabs se utilizan para almacenar información de depuración.
"?"
El tipo del símbolo es desconocido o específico del formato del archivo objeto.
•
El nombre del símbolo. Si un símbolo tiene información de versión asociada, entonces se muestra la información de versión. Si el símbolo versionado está indefinido o oculto del enlazador, la cadena de versión se muestra como un sufijo del nombre del símbolo, precedido por un carácter @. Por ejemplo foo@VER_1. Si la versión es la versión predeterminada a usar al resolver referencias no versionadas al símbolo, entonces se muestra como un sufijo precedido por dos caracteres @. Por ejemplo foo@@VER_2.

OPCIONES

Las formas largas y cortas de las opciones, que se muestran aquí como alternativas, son equivalentes.

-A
-o
--print-file-name
Anteponer a cada símbolo el nombre del archivo de entrada (o miembro del archivo) en el que se encontró, en lugar de identificar el archivo de entrada una sola vez, antes de todos sus símbolos.
-a
--debug-syms
Mostrar todos los símbolos, incluso los símbolos solo para depuradores; normalmente estos no se listan.
-B
Lo mismo que --format=bsd (para compatibilidad con el nm de MIPS).
-C
--demangle[=estilo]
Decodificar (demangle) nombres de símbolos de bajo nivel a nombres de nivel de usuario. Además de eliminar cualquier guion bajo inicial agregado por el sistema, esto hace que los nombres de funciones de C++ sean legibles. Diferentes compiladores tienen diferentes estilos de mangling. El argumento opcional de estilo de demangling se puede usar para elegir un estilo de demangling apropiado para su compilador.
--no-demangle
No decodificar nombres de símbolos de bajo nivel. Este es el valor predeterminado.
--recurse-limit
--no-recurse-limit
Estas opciones se aplican a la salida de archivos objeto. Si los símbolos son referenciados por relocalizaciones desde otros objetos, estos se listan también, pero si son referenciados por relocalizaciones desde otros símbolos de este mismo archivo, estos no se listan. Si se usa la opción --recurse-limit, entonces se listan recursivamente.
-D
--dynamic
Mostrar solo los símbolos dinámicos.
-f formato
--format=formato
Especificar el formato de salida. El argumento formato puede ser uno de los siguientes:
auto
Intentar determinar el formato más apropiado para la salida (este es el predeterminado).
berkeley
Formato de salida tipo BSD.
bsd
Formato de salida tipo BSD.
default
Formato de salida predeterminado.
gnu
Formato de salida GNU.
posix
Formato de salida compatible con POSIX.
just-symbols
Imprimir solo los nombres de los símbolos. Solo se imprimen los símbolos que tienen un valor.
-g
--extern-only
No listar los símbolos locales.
-h
--help
Mostrar un resumen de los usos y opciones.
--ifunc-chars=CARACTERES
Especifica los caracteres utilizados para mostrar los símbolos de función indirecta. El primer carácter en CARACTERES se usa para símbolos globales y el segundo para símbolos locales. Si no se proporciona, se usa 'i' para ambos.
-j
--format=just-symbols
Imprimir solo los nombres de los símbolos. Solo se imprimen los símbolos que tienen un valor.
-l
--line-numbers
Para cada símbolo, muestre el nombre del archivo fuente y el número de línea de donde se originó. Si el nombre de archivo fuente no está disponible, esto se comporta igual que --radix=d. Este es el valor predeterminado cuando se procesan archivos que contienen información de depuración.
--inlines
Mostrar los símbolos que corresponden a funciones insertadas (inlined functions). Esto solo funciona para los archivos objeto que contienen información de depuración.
-n
-v
--numeric-sort
Ordenar los símbolos numéricamente en lugar de alfabéticamente.
-P
--portability
Usar el formato de salida POSIX. Esto implica usar el formato de salida que es más cercano al de POSIX. La única diferencia es que esto anulará la opción --print-file-name, que de otra manera podría ser activada por la opción -o.
-p
--no-sort
No ordenar la lista de símbolos.
-r
--reverse-sort
Invertir el orden del tipo de ordenación seleccionado.
-S
--print-size
Para cada símbolo, mostrar el tamaño del símbolo. Este tamaño es el tamaño del objeto representado por el símbolo.
-s
--print-armap
Mostrar la tabla de símbolos de un archivo AR.
-t raíz
--radix=raíz
Usar la raíz numérica especificada para mostrar los valores de los símbolos. La raíz puede ser d (decimal), o (octal), x (hexadecimal), o h (hexadecimal). El valor predeterminado es x (hexadecimal).
-u
--undefined-only
Mostrar solo los símbolos indefinidos.
-U
--defined-only
Mostrar solo los símbolos definidos.
-V
--version
Mostrar información sobre la versión de nm y salir.
-W
--no-weak
No mostrar los símbolos débiles.
-X 32_64
Especifica el formato de salida para archivos que contienen múltiples formatos de salida. En este momento, solo se soporta 32_64, que genera una salida para la arquitectura de 32 bits y la de 64 bits.
--plugin nombre
Cargar un plugin de BFD llamado nombre. Esto permite extender las capacidades de nm.
--size-sort
Ordenar los símbolos por tamaño.
--special-syms
Mostrar símbolos especiales, además de los símbolos normales.
--synthetic
Mostrar símbolos sintéticos. Estos son símbolos que no se corresponden directamente con ninguna parte del archivo objeto, sino que son generados por el enlazador o el compilador para fines específicos.
--target=bfdname
Especifica el formato del archivo objeto. El argumento bfdname es el nombre de un formato de BFD. Por ejemplo, --target=elf32-i386.
--unicode=método
Especifica cómo manejar caracteres Unicode en los nombres de símbolos. El argumento método puede ser locale (usar la configuración regional del sistema), standard (usar la codificación estándar de Unicode), o none (no manejar caracteres Unicode).
--with-symbol-versions
Mostrar la información de versión de los símbolos, si está disponible.
--without-symbol-versions
No mostrar la información de versión de los símbolos.

Este sitio no está asociado de ninguna forma con Arch Linux ni afiliado a este proyecto. El contenido es únicamente una traducción de las páginas del manual de Arch publicadas en man.archlinux.org.

--recurse-limit
--no-recurse-limit
--recursion-limit
--no-recursion-limit
Habilita o deshabilita un límite en la cantidad de recursión realizada al desenmascarar cadenas. Dado que los formatos de nombres enmascarados permiten un nivel infinito de recursión, es posible crear cadenas cuya decodificación agotará el espacio de pila disponible en la máquina anfitriona, activando una falla de memoria. El límite intenta evitar que esto suceda restringiendo la recursión a 2048 niveles de anidamiento.

Por defecto, este límite está habilitado, pero deshabilitarlo puede ser necesario para desenmascarar nombres verdaderamente complicados. Tenga en cuenta, sin embargo, que si el límite de recursión está deshabilitado, es posible agotar la pila y cualquier informe de errores sobre tal evento será rechazado.

-D
--dynamic
Muestra los símbolos dinámicos en lugar de los símbolos normales. Esto solo es significativo para objetos dinámicos, como ciertos tipos de bibliotecas compartidas.
-f formato
--format=formato
Utiliza el formato de salida formato, que puede ser "bsd", "sysv", "posix" o "just-symbols". Por defecto es "bsd". Solo el primer carácter de formato es significativo; puede ser mayúscula o minúscula.
-g
--extern-only
Muestra solo símbolos externos.
-h
--help
Muestra un resumen de las opciones de nm y sale.
--ifunc-chars=CHARS
Al mostrar símbolos de funciones indirectas de GNU, nm usará por defecto el carácter "i" tanto para funciones indirectas locales como globales. La opción --ifunc-chars permite al usuario especificar una cadena que contiene uno o dos caracteres. El primer carácter se utilizará para símbolos de funciones indirectas globales y el segundo carácter, si está presente, se utilizará para símbolos de funciones indirectas locales.
j
Lo mismo que --format=just-symbols.
-l
--line-numbers
Para cada símbolo, utiliza información de depuración para intentar encontrar un nombre de archivo y un número de línea. Para un símbolo definido, busca el número de línea de la dirección del símbolo. Para un símbolo indefinido, busca el número de línea de una entrada de reubicación que hace referencia al símbolo. Si se puede encontrar información del número de línea, imprímela después de la otra información del símbolo.
--inlines
Cuando la opción -l está activa, si la dirección pertenece a una función que fue insertada en línea, esta opción hace que la información de origen para todos los ámbitos contenedores hasta la primera función no insertada en línea también se imprima. Por ejemplo, si "main" inserta en línea "callee1", que inserta en línea "callee2", y la dirección es de "callee2", también se imprimirá la información de origen de "callee1" y "main".
-n
-v
--numeric-sort
Ordena los símbolos numéricamente por sus direcciones, en lugar de alfabéticamente por sus nombres.
-p
--no-sort
No se molesta en ordenar los símbolos en ningún orden; imprímelos en el orden en que se encuentran.
-P
--portability
Utiliza el formato de salida estándar POSIX.2 en lugar del formato predeterminado. Equivalente a -f posix.
-r
--reverse-sort
Invierte el orden de la clasificación (ya sea numérica o alfabética); que lo último sea lo primero.
-S
--print-size
Imprime tanto el valor como el tamaño de los símbolos definidos para el estilo de salida "bsd". Esta opción no tiene efecto para formatos de objeto que no registran tamaños de símbolos, a menos que también se use --size-sort, en cuyo caso se muestra un tamaño calculado.
-s
--print-armap
Al listar símbolos de miembros de archivo, incluye el índice: un mapeo (almacenado en el archivo por ar o ranlib) de qué módulos contienen definiciones para qué nombres.
-t base
--radix=base
Utiliza base como la base para imprimir los valores de los símbolos. Debe ser d para decimal, o para octal, o x para hexadecimal.
-u
--undefined-only
Muestra solo símbolos indefinidos (aquellos externos a cada archivo objeto). Por defecto, se muestran tanto los símbolos definidos como los indefinidos.
-U
--defined-only
Muestra solo símbolos definidos para cada archivo objeto. Por defecto, se muestran tanto los símbolos definidos como los indefinidos.
-V
--version
Muestra el número de versión de nm y sale.
-X
Esta opción se ignora por compatibilidad con la versión AIX de nm. Toma un parámetro que debe ser la cadena 32_64. El modo predeterminado de nm en AIX corresponde a -X 32, que no es compatible con el nm de GNU.
--plugin nombre
Carga el plugin llamado nombre para agregar soporte para tipos de destino adicionales. Esta opción solo está disponible si la cadena de herramientas se compiló con soporte de plugins habilitado.

Si no se proporciona --plugin, pero el soporte de plugins ha sido habilitado, entonces nm itera sobre los archivos en ${libdir}/bfd-plugins en orden alfabético y se utiliza el primer plugin que reclama el objeto en cuestión.

Tenga en cuenta que este directorio de búsqueda de plugins no es el que utiliza la opción -plugin de ld. Para que nm utilice el plugin del enlazador, debe copiarse en el directorio ${libdir}/bfd-plugins. Para compilaciones basadas en GCC, el plugin del enlazador se llama liblto_plugin.so.0.0.0. Para compilaciones basadas en Clang, se llama LLVMgold.so. El plugin de GCC siempre es compatible con versiones anteriores, por lo que es suficiente con copiar el más reciente.

--size-sort
Ordena los símbolos por tamaño. Para objetos ELF, los tamaños de los símbolos se leen de ELF; para otros tipos de objetos, los tamaños de los símbolos se calculan como la diferencia entre el valor del símbolo y el valor del símbolo con el siguiente valor más alto. Si se utiliza el formato de salida "bsd", se imprime el tamaño del símbolo en lugar del valor, y se debe usar -S para que se impriman tanto el tamaño como el valor.

Nota: esta opción no funciona si se ha habilitado --undefined-only, ya que los símbolos indefinidos no tienen tamaño.

--special-syms
Muestra símbolos que tienen un significado especial específico del destino. Estos símbolos son generalmente utilizados por el destino para algún procesamiento especial y normalmente no son útiles cuando se incluyen en las listas de símbolos normales. Por ejemplo, para destinos ARM, esta opción omitiría los símbolos de mapeo utilizados para marcar transiciones entre código ARM, código THUMB y datos.
--synthetic
Incluye símbolos sintéticos en la salida. Estos son símbolos especiales creados por el enlazador para varios propósitos. No se muestran por defecto ya que no forman parte del código fuente original del binario.
--unicode=[default|invalid|locale|escape|hex|highlight]
Controla la visualización de caracteres multibyte codificados en UTF-8 en cadenas. El valor predeterminado (--unicode=default) es no darles ningún tratamiento especial. La opción --unicode=locale muestra la secuencia en la configuración regional actual, que puede o no admitirlos. Las opciones --unicode=hex y --unicode=invalid los muestran como secuencias de bytes hexadecimales encerradas entre corchetes angulares o llaves.

La opción --unicode=escape los muestra como secuencias de escape (\uxxxx) y la opción --unicode=highlight los muestra como secuencias de escape resaltadas en rojo (si es compatible con el dispositivo de salida). El coloreado está destinado a llamar la atención sobre la presencia de secuencias unicode donde no se esperan.

-W
--no-weak
No muestres símbolos débiles.
--with-symbol-versions
--without-symbol-versions
Habilita o deshabilita la visualización de información de versiones de símbolos. La cadena de versión se muestra como un sufijo al nombre del símbolo, precedido por un carácter @. Para
example foo@VER_1. Si la versión es la versión por defecto que se utilizará al resolver referencias sin versión a dicho símbolo, entonces se mostrará como un sufijo precedido por dos caracteres @. Por ejemplo, foo@@VER_2. Por defecto, la información de versión del símbolo se muestra.
--target=bfdname
Especifica un formato de código objeto diferente del formato por defecto de su sistema.
@archivo
Lee las opciones de la línea de comandos desde archivo. Las opciones leídas se insertan en lugar de la opción original @archivo. Si archivo no existe, o no se puede leer, entonces la opción se tratará literalmente y no se eliminará.

Las opciones en archivo están separadas por espacios en blanco. Se puede incluir un carácter de espacio en blanco en una opción rodeando la opción completa con comillas simples o dobles. Se puede incluir cualquier carácter (incluyendo una barra invertida) prefijando el carácter que se desea incluir con una barra invertida. El archivo puede contener opciones adicionales @archivo; dichas opciones se procesarán recursivamente.
