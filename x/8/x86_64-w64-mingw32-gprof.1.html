NOMBRE

gprof - muestra datos de perfil de llamadas

SINOPSIS

DESCRIPCIÓN

"gprof" produce un perfil de ejecución de programas C, Pascal o Fortran77. El efecto de las rutinas llamadas se incorpora en el perfil de cada llamador. Los datos del perfil se toman del archivo de perfil de grafo de llamadas (gmon.out por defecto) que se crea con programas compilados con la opción -pg de "cc", "pc" y "f77". La opción -pg también enlaza versiones de las rutinas de biblioteca compiladas para perfilado. "Gprof" lee el archivo objeto dado (el valor por defecto es "a.out") y establece la relación entre su tabla de símbolos y el archivo de perfil de grafo de llamadas de gmon.out. Si se especifican varios archivos de perfil, la salida de "gprof" muestra la suma de la información de perfil de los archivos de perfil dados.

"Gprof" calcula la cantidad de tiempo gastado en cada rutina. Luego, estos tiempos se propagan a lo largo de los bordes del grafo de llamadas. Se descubren ciclos, y las llamadas a un ciclo se asignan para compartir el tiempo del ciclo.

Hay varias formas de salida disponibles del análisis.

El perfil plano muestra cuánto tiempo pasó su programa en cada función y cuántas veces se llamó a esa función. Si simplemente desea saber qué funciones consumen la mayor parte del tiempo, aquí se indica concisamente.

El grafo de llamadas muestra, para cada función, qué funciones la llamaron, qué otras funciones llamó y cuántas veces. También hay una estimación de cuánto tiempo se gastó en las subrutinas de cada función. Esto puede sugerir lugares donde podría intentar eliminar llamadas a funciones que consumen mucho tiempo.

La lista de fuente anotada es una copia del código fuente del programa, etiquetada con el número de veces que se ejecutó cada línea del programa.

OPCIONES

Estas opciones especifican cuál de varios formatos de salida producirá "gprof".

Muchas de estas opciones toman una especificación-símbolo opcional para especificar las funciones a incluir o excluir. Estas opciones se pueden especificar varias veces, con diferentes especificaciones-símbolo, para incluir o excluir conjuntos de símbolos.

La especificación de cualquiera de estas opciones anula el valor predeterminado (-p -q), que imprime un perfil plano y un análisis del grafo de llamadas para todas las funciones.

"-A[especificación-símbolo]"
"--fuente-anotada[=especificación-símbolo]"
La opción -A hace que "gprof" imprima código fuente anotado. Si se especifica especificación-símbolo, imprime la salida solo para los símbolos coincidentes.
"-b"
"--breve"
Si se proporciona la opción -b, "gprof" no imprime los textos explicativos detallados que intentan explicar el significado de todos los campos en las tablas. Esto es útil si tiene la intención de imprimir la salida, o está cansado de ver los textos explicativos.
"-B"
La opción -B hace que "gprof" imprima el análisis del grafo de llamadas.
"-C[especificación-símbolo]"
"--recuentos-ejecucion[=especificación-símbolo]"
La opción -C hace que "gprof" imprima un recuento de funciones y el número de veces que se llamó a cada una. Si se especifica especificación-símbolo, imprime el recuento solo para los símbolos coincidentes.

Si el archivo de datos de perfil contiene registros de recuento de bloques básicos, la especificación de la opción -l, junto con -C, hará que los recuentos de ejecución de bloques básicos se cuenten y se muestren.

"-i"
"--info-archivo"
La opción -i hace que "gprof" muestre información resumen sobre el archivo(s) de datos de perfil y luego salga. Se muestra el número de registros de histograma, grafo de llamadas y bloques básicos.
"-I directorios"
"--ruta-directorios=directorios"
La opción -I especifica una lista de directorios de búsqueda en los que encontrar archivos fuente. La variable de entorno GPROF_PATH también se puede usar para transmitir esta información. Se usa principalmente para la salida de fuente anotada.
"-J[especificación-símbolo]"
"--no-fuente-anotada[=especificación-símbolo]"
La opción -J hace que "gprof" no imprima código fuente anotado. Si se especifica especificación-símbolo, "gprof" imprime fuente anotada, pero excluye los símbolos coincidentes.
"-L"
"--ruta-impresion"
Normalmente, los nombres de archivo fuente se imprimen suprimiendo el componente de ruta. La opción -L hace que "gprof" imprima la ruta completa de los nombres de archivo fuente, que se determina a partir de la información de depuración simbólica en el archivo de imagen y es relativa al directorio en el que se invocó el compilador.
"-p[especificación-símbolo]"
"--perfil-plano[=especificación-símbolo]"
La opción -p hace que "gprof" imprima un perfil plano. Si se especifica especificación-símbolo, imprime el perfil plano solo para los símbolos coincidentes.
"-P[especificación-símbolo]"
"--no-perfil-plano[=especificación-símbolo]"
La opción -P hace que "gprof" suprima la impresión de un perfil plano. Si se especifica especificación-símbolo, "gprof" imprime un perfil plano, pero excluye los símbolos coincidentes.
"-q[especificación-símbolo]"
"--grafo[=especificación-símbolo]"
La opción -q hace que "gprof" imprima el análisis del grafo de llamadas. Si se especifica especificación-símbolo, imprime el grafo de llamadas solo para los símbolos coincidentes y sus hijos.
"-Q[especificación-símbolo]"
"--no-grafo[=especificación-símbolo]"
La opción -Q hace que "gprof" suprima la impresión del grafo de llamadas. Si se especifica especificación-símbolo, "gprof" imprime un grafo de llamadas, pero excluye los símbolos coincidentes.
"-t"
"--longitud-tabla=num"
La opción -t hace que se listen las num líneas fuente más activas en cada archivo fuente cuando se habilita la anotación fuente. El valor predeterminado es 10.
"-y"
"--archivos-separados"
Esta opción solo afecta la salida de fuente anotada. Normalmente, "gprof" imprime archivos fuente anotados en la salida estándar. Si se especifica esta opción, la fuente anotada para un archivo llamado ruta/nombre_archivo se genera en el archivo nombre_archivo-ann. Si el sistema de archivos subyacente truncara nombre_archivo-ann de modo que sobrescribiera el nombre_archivo original, "gprof" generará fuente anotada en el archivo nombre_archivo.ann en su lugar (si el nombre del archivo original tiene una extensión, esa extensión se reemplaza con .ann).

"--no-recuentos-ejecucion[=especificación-símbolo]"

"-r"
"--function-ordering"
La opción --function-ordering hace que "gprof" imprima un orden de funciones sugerido para el programa basado en datos de perfilado. Esta opción sugiere un orden que puede mejorar el comportamiento de paginación, tlb y caché para el programa en sistemas que admiten el ordenamiento arbitrario de funciones en un ejecutable.

Los detalles exactos de cómo forzar al enlazador a colocar las funciones en un orden particular dependen del sistema y están fuera del alcance de este manual.

"-R map_file"
"--file-ordering map_file"
La opción --file-ordering hace que "gprof" imprima un orden sugerido de líneas de enlace .o para el programa basado en datos de perfilado. Esta opción sugiere un orden que puede mejorar el comportamiento de paginación, tlb y caché para el programa en sistemas que no admiten el ordenamiento arbitrario de funciones en un ejecutable.

Se recomienda encarecidamente el uso del argumento -a con esta opción.

El argumento map_file es una ruta a un archivo que proporciona mapeos de nombres de funciones a archivos objeto. El formato del archivo es similar a la salida del programa "nm".

c-parse.o:00000000 T yyparse
c-parse.o:00000004 C yyerrflag
c-lang.o:00000000 T maybe_objc_method_name
c-lang.o:00000000 T print_lang_statistics
c-lang.o:00000000 T recognize_objc_keyword
c-decl.o:00000000 T print_lang_identifier
c-decl.o:00000000 T print_lang_type
...

Para crear un map_file con GNU "nm", escriba un comando como "nm --extern-only --defined-only -v --print-file-name program-name".

"-T"
"--traditional"
La opción -T hace que "gprof" imprima su salida en el estilo "tradicional" de BSD.
"-w width"
"--width=width"
Establece el ancho de las líneas de salida a width. Actualmente solo se utiliza al imprimir el índice de funciones en la parte inferior del grafo de llamadas.
"-x"
"--all-lines"
Esta opción afecta solo a la salida de código fuente anotado. Por defecto, solo se anotan las líneas al principio de un bloque básico. Si se especifica esta opción, cada línea de un bloque básico se anotará repitiendo la anotación de la primera línea. Este comportamiento es similar al -a de "tcov".
"--demangle[=style]"
"--no-demangle"
Estas opciones controlan si los nombres de símbolos de C++ deben ser demanglados al imprimir la salida. El valor predeterminado es demanglar símbolos. La opción "--no-demangle" puede usarse para desactivar el demangling. Diferentes compiladores tienen diferentes estilos de manglado. El argumento opcional de estilo de demangling puede usarse para elegir un estilo de demangling apropiado para su compilador.

Opciones de Análisis

"-a"
"--no-static"
La opción -a hace que "gprof" suprima la impresión de funciones declaradas estáticamente (privadas). (Estas son funciones cuyos nombres no están listados como globales, y que no son visibles fuera del archivo/función/bloque donde fueron definidas.) El tiempo gastado en estas funciones, las llamadas a/desde ellas, etc., se atribuirán a la función que fue cargada directamente antes que ella en el archivo ejecutable. Esta opción afecta tanto al perfilado plano como al grafo de llamadas.
"-c"
"--static-call-graph"
La opción -c hace que el grafo de llamadas del programa se aumente con una heurística que examina el espacio de texto del archivo objeto e identifica llamadas a funciones en el código máquina binario. Dado que los registros normales del grafo de llamadas solo se generan cuando las funciones son ingresadas, esta opción identifica hijos que podrían haber sido llamados, pero nunca lo fueron. Las llamadas a funciones que no fueron compiladas con perfilado habilitado también se identifican, pero solo si existen entradas de tabla de símbolos para ellas. Las llamadas a rutinas de bibliotecas dinámicas típicamente no son encontradas por esta opción. Los padres o hijos identificados a través de esta heurística se indican en el grafo de llamadas con recuentos de llamadas de 0.
"-D"
"--ignore-non-functions"
La opción -D hace que "gprof" ignore los símbolos que no se sabe que son funciones. Esta opción dará datos de perfilado más precisos en sistemas donde es compatible (Solaris y HPUX, por ejemplo).
"-k from/to"
La opción -k le permite eliminar del grafo de llamadas cualquier arco desde símbolos que coincidan con from hasta aquellos que coincidan con to.
"-l"
"--line"
La opción -l habilita el perfilado línea por línea, lo que hace que los aciertos del histograma se carguen a líneas de código fuente individuales, en lugar de a funciones. Esta característica solo funciona con programas compilados por versiones anteriores del compilador "gcc". Las versiones más nuevas de "gcc" están diseñadas para funcionar con la herramienta "gcov" en su lugar.

Si el programa fue compilado con el conteo de bloques básicos habilitado, esta opción también identificará cuántas veces se ejecutó cada línea de código. Si bien el perfilado línea por línea puede ayudar a aislar dónde está pasando tiempo un programa en una función grande, también aumenta significativamente el tiempo de ejecución de "gprof" y magnifica las imprecisiones estadísticas.

"--inline-file-names"
Esta opción hace que "gprof" imprima el archivo fuente después de cada símbolo tanto en el perfilado plano como en el grafo de llamadas. La ruta completa al archivo se imprime si se usa con la opción -L.
"-m num"
"--min-count=num"
Esta opción solo afecta a la salida del recuento de ejecución. Se suprimen los símbolos que se ejecutan menos de num veces.
"-nsymspec"
"--time=symspec"
La opción -n hace que "gprof", en su análisis de grafo de llamadas, solo propague tiempos para los símbolos que coincidan con symspec.
"-Nsymspec"
"--no-time=symspec"
La opción -n hace que "gprof", en su análisis de grafo de llamadas, no propague tiempos para los símbolos que coincidan con symspec.
"-Sfilename"
"--external-symbol-table=filename"
La opción -S hace que "gprof" lea un archivo de tabla de símbolos externa, como /proc/kallsyms, en lugar de leer la tabla de símbolos del archivo objeto dado (el valor predeterminado es "a.out"). Esto es útil para perfilar módulos del kernel.
"-z"
"--display-unused-functions"
Si se proporciona la opción -z, "gprof" mencionará todas las funciones en el perfilado plano, incluso aquellas que nunca fueron llamadas y en las que no se gastó tiempo. Esto es útil en conjunción con la opción -c para descubrir qué rutinas nunca fueron llamadas.

Opciones Misceláneas

"-d[num]"
"--debug[=num]"
La opción -d num especifica opciones de depuración. Si num no se especifica, habilita toda la depuración.
"-h"
"--help"
La opción -h imprime el uso de la línea de comandos.
"-Oname"
"--file-format=name"
Selecciona el formato de los archivos de datos de perfilado. Los formatos reconocidos son auto (el valor predeterminado), bsd, 4.4bsd, magic y prof (aún no soportado).
"-s"
"--sum"
La opción -s hace que "gprof" resuma la información en los archivos de datos de perfilado que leyó, y escriba un archivo de datos de perfilado llamado gmon.sum, que contiene toda la información de los archivos de datos de perfilado que "gprof" leyó. El archivo gmon.sum puede ser uno de los archivos de entrada especificados; el efecto de esto es fusionar los datos de los otros archivos de entrada en gmon.sum.

Eventualmente, puede ejecutar "gprof" nuevamente sin -s para analizar los datos acumulados en el archivo gmon.sum.

"-v"
"--version"
La opción -v hace que "gprof" imprima el número de versión actual y luego salga.

Opciones Obsoletas

Estas opciones han sido reemplazadas por versiones más nuevas que usan symspecs.

"-e function_name"
La opción -e function le dice a "gprof" que no imprima información sobre la función function_name (y sus hijos...) en el grafo de llamadas. La función aún se listará como un hijo de cualquier función que la llame, pero su número de índice se mostrará como [no impreso]. Se puede dar más de una opción -e; solo se puede indicar un function_name con cada opción -e.
"-E function_name"
La opción "-E function" funciona como la opción "-e", pero el tiempo gastado en la función (y los hijos que no fueron llamados desde ningún otro lugar), no se utilizará para calcular los porcentajes de tiempo para el grafo de llamadas. Se puede dar más de una opción -E; solo se puede indicar un function_name con cada opción -E.

OPCIONES

"-f nombre_funcion"
La opción -f con "gprof" se utiliza para limitar el gráfico de llamadas a la función nombre_funcion y sus hijos (y los hijos de sus hijos...). Se pueden dar varias opciones -f; solo se puede indicar un nombre_funcion con cada opción -f.
"-F nombre_funcion"
La opción -F funcion funciona igual que la opción "-f", pero solo el tiempo dedicado a la función y sus hijos (y los hijos de sus hijos...) se utilizará para determinar el tiempo total y los porcentajes de tiempo para el gráfico de llamadas. Se pueden dar varias opciones -F; solo se puede indicar un nombre_funcion con cada opción -F. La opción -F anula la opción -E.

ERRORES

Se muestra la granularidad del muestreo, pero sigue siendo, en el mejor de los casos, estadística. Suponemos que el tiempo de cada ejecución de una función se puede expresar como el tiempo total de la función dividido por el número de veces que se llama a la función. Por lo tanto, el tiempo propagado a lo largo de los arcos del gráfico de llamadas a los padres de la función es directamente proporcional al número de veces que se recorre ese arco.

Los padres que no sean ellos mismos perfilados tendrán el tiempo de sus hijos perfilados propagado a ellos, pero aparecerán como invocados espontáneamente en la lista del gráfico de llamadas, y su tiempo no se propagará más. De manera similar, los receptores de señales, aunque perfilados, aparecerán como espontáneos (aunque por razones más oscuras). Cualquier hijo perfilado de un receptor de señales debería tener su tiempo propagado correctamente, a menos que el receptor de señales se invocara durante la ejecución de la rutina de perfilado, en cuyo caso todo se pierde.

El programa perfilado debe llamar a "exit"(2) o retornar normalmente para que la información de perfilado se guarde en el archivo gmon.out.
