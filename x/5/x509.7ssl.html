NOMBRE

x509 - Manejo de certificados X.509

SINOPSIS

#include <openssl/x509.h>

DESCRIPCIÓN

Un certificado X.509 es una agrupación estructurada de información sobre un individuo, un dispositivo o cualquier cosa que se pueda imaginar. Una CRL (lista de revocación de certificados) X.509 es una herramienta para ayudar a determinar si un certificado sigue siendo válido. La definición exacta de estos se puede encontrar en el documento X.509 de la ITU-T, o en el RFC3280 de PKIX. En OpenSSL, el tipo X509 se utiliza para expresar dicho certificado, y el tipo X509_CRL se utiliza para expresar una CRL.

Una estructura relacionada es una solicitud de certificado, definida en PKCS#10 de RSA Security, Inc, también reflejada en el RFC2896. En OpenSSL, el tipo X509_REQ se utiliza para expresar dicha solicitud de certificado.

Para manejar algunas partes complejas de un certificado, existen los tipos X509_NAME (para expresar un nombre de certificado), X509_ATTRIBUTE (para expresar un atributo de certificado), X509_EXTENSION (para expresar una extensión de certificado) y algunos más.

Finalmente, existe el supertipo X509_INFO, que puede contener una CRL, un certificado y la clave privada correspondiente.

Las funciones X509_XXX, d2i_X509_XXX y i2d_X509_XXX manejan certificados X.509, con algunas excepciones, que se muestran a continuación.

Las funciones X509_CRL_XXX, d2i_X509_CRL_XXX y i2d_X509_CRL_XXX manejan CRLs X.509.

Las funciones X509_REQ_XXX, d2i_X509_REQ_XXX y i2d_X509_REQ_XXX manejan solicitudes de certificado PKCS#10.

Las funciones X509_NAME_XXX manejan nombres de certificados.

Las funciones X509_ATTRIBUTE_XXX manejan atributos de certificados.

Las funciones X509_EXTENSION_XXX manejan extensiones de certificados.
