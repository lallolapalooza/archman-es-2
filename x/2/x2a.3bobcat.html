FBB::X2a(3bobcat) Conversiones de X a ASCII FBB::X2a(3bobcat)

NOMBRE

FBB::X2a - Objetos que realizan conversiones de x a Ascii

SINOPSIS

#include <bobcat/x2a>
Opción de enlazado: -lbobcat

DESCRIPCIÓN

Los objetos FBB::X2a convierten valores de cualquier tipo (insertable) a texto. El texto devuelto se pone automáticamente a disposición como una cadena estándar de C++.

X2a se desarrolló mucho antes de que estuviera disponible la función std::to_string. En muchos casos, esta última función puede utilizarse en lugar de X2a: está disponible para tipos estándar. Sin embargo, si se necesita usar otro tipo, X2a puede ser útil.

ESPACIO DE NOMBRES

FBB
Todos los constructores, miembros, operadores y manipuladores mencionados en esta página del manual están definidos en el espacio de nombres FBB.

HEREDA DE

std::ostringstream

CONSTRUCTORES

o
X2a(T const &value):
En este constructor, T puede ser cualquier tipo que pueda insertarse en un o[string]stream.
o
X2a(double value, size_t behind):
El value double se trunca a behind dígitos detrás del punto decimal. Si un valor no ocupa behind dígitos detrás del punto decimal, se añaden ceros como 0. Por ejemplo, un valor de 7.1 se mostrará como 7.10 si se solicitan dos dígitos detrás del punto decimal. Un valor de 7 se mostrará como 7.00.
o
X2a(double value, size_t width, size_t behind, std::ios::fmtflags flags = std::ios::right):
El valor se muestra en width posiciones de caracteres, extendiendo la cantidad si el valor así lo requiere. El valor convertido se coloca alineado a la derecha en el campo de width caracteres.

El constructor de copia y el operador de asignación de copia están disponibles.

FUNCIÓN MIEMBRO ESTÁTICA

o
bool lastFail():
Este miembro devuelve true si la última conversión falló (es decir, el miembro fail() del objeto devolvió true) y devuelve false en caso contrario. Este miembro permite verificar el éxito de la extracción/conversión utilizando objetos A2x anónimos. El miembro también devuelve true cuando aún no se han realizado conversiones.
Tenga en cuenta que este miembro es un miembro static que no es seguro para hilos: en un programa multihilo, pueden requerirse bloqueos para garantizar que se inspeccione el resultado de conversión correcto.

FUNCIONES MIEMBRO

Todos los miembros de std::ostringstream están disponibles, ya que FBB::X2a hereda de esta clase. En particular, ostringstream::str() se puede usar para obtener el contenido del búfer de texto de un objeto X2a.

OPERADORES SOBRECARGADOS

o
operator std::ostream &operator<<(std::ostream &ostr, X2a const &x2a):
Este operador de conversión inserta la representación textual del valor x2a en el ostream proporcionado.
o
operator std::string const() const:
este operador de conversión devuelve la información almacenada dentro del objeto FBB::X2a.

EJEMPLO

    string is(X2a(5));      // inicializa `is' con "5"
    string ds(X2a(5.25));   // inicializa `ds' con "5.25"
    cout << X2a(7.0 / 3, 4) << endl;
                            // muestra un valor usando 4 dígitos detrás del
                            // punto decimal.
    cout << X2a(7.0 / 3, 8, 4) << endl;
                            // muestra un valor en 8 posiciones, alineado a la
                            // derecha, 4 dígitos detrás del punto decimal.
    cout << X2a(7.0 / 3, 8, 4, std::ios::left) << endl;
                            // muestra un valor en 8 posiciones, alineado a la
                            // izquierda, 4 dígitos detrás del punto decimal.
