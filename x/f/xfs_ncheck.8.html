xfs_ncheck(8) Manual del Administrador del Sistema xfs_ncheck(8)

NOMBRE

xfs_ncheck - generar nombres de ruta a partir de números de inodo para XFS

SINOPSIS

xfs_ncheck [ -i ino ] ... [ -f ] [ -s ] [ -l logdev ] dispositivo
xfs_ncheck -V

DESCRIPCIÓN

xfs_ncheck sin argumentos -i genera una lista de números de inodo y nombres de ruta de todos los archivos en el sistema de archivos dado. Los nombres de los archivos de directorio van seguidos de /.. La salida no está ordenada de ninguna manera particular. El sistema de archivos a examinar se especifica mediante el argumento dispositivo, que debe ser el dispositivo de disco o volumen del sistema de archivos. Los sistemas de archivos almacenados en archivos también pueden ser comprobados, utilizando la bandera -f.

OPCIONES

-f
Especifica que la imagen del sistema de archivos a procesar está almacenada en un archivo regular en dispositivo (ver la opción mkfs.xfs -d archivo). Esto puede ocurrir si se ha realizado una copia de imagen de un sistema de archivos en un archivo ordinario.
-l logdev
Especifica el dispositivo donde reside el registro externo del sistema de archivos. Solo para aquellos sistemas de archivos que utilizan un registro externo. Ver la opción mkfs.xfs -l y consultar xfs(5) para una descripción detallada del registro de XFS.
-s
Limita el informe a archivos especiales y archivos con modo setuserid. Esta opción puede ser utilizada para detectar violaciones de la política de seguridad.
-i ino
Limita el informe solo a aquellos archivos cuyos números de inodo siguen. Puede ser proporcionado múltiples veces para seleccionar múltiples números de inodo.
-V
Imprime el número de versión y sale.

Si el sistema de archivos está gravemente dañado, o muy ocupado y parece estar dañado, puede aparecer un mensaje de la forma que generaría el comando "check" de xfs_db(8).

xfs_ncheck solo es útil con sistemas de archivos XFS.

VER TAMBIÉN

mkfs.xfs(8), xfs(5).
