NOMBRE

xfs_rtcp - comando de copia en tiempo real de XFS

SINOPSIS

xfs_rtcp [ -e tamaño_ext ] [ -p ] fuente ... destino
xfs_rtcp -V

DESCRIPCIÓN

xfs_rtcp copia un archivo a la partición en tiempo real de un sistema de archivos XFS. Si hay más de un fuente y destino, el argumento final (el destino) debe ser un directorio que ya exista.

OPCIONES

-e tamaño_ext
Establece el tamaño de extensión del archivo en tiempo real de destino.
-p
Usar si el tamaño del archivo fuente no es un múltiplo par del tamaño de bloque del sistema de archivos de destino. Cuando se especifica -p xfs_rtcp rellenará el archivo de destino hasta un tamaño que sea un múltiplo par del tamaño de bloque del sistema de archivos. Esto es necesario ya que el archivo en tiempo real se crea utilizando E/S directa y la E/S mínima es el tamaño de bloque del sistema de archivos.
-V
Imprime el número de versión y sale.

VER TAMBIÉN

xfs(5), mkfs.xfs(8), mount(8).

ADVERTENCIAS

Actualmente, las particiones en tiempo real no están soportadas bajo la versión de Linux de XFS, y el uso de una partición en tiempo real CAUSARÁ CORRUPCIÓN en la partición de datos. Como tal, este comando se pone a disposición para DESARROLLADORES ÚNICAMENTE en este momento.
