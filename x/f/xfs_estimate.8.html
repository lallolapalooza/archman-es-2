xfs_estimate(8) Manual del Administrador del Sistema xfs_estimate(8)

NOMBRE

xfs_estimate - estimar el espacio que ocupará un sistema de archivos XFS

SINOPSIS

xfs_estimate [ -h ] [ -b tamaño_bloque ] [ -i tamaño_log ]
		   [ -e tamaño_log ] [ -v ] directorio ...
xfs_estimate -V

DESCRIPCIÓN

Para cada argumento de directorio, xfs_estimate estima el espacio que ocuparía ese directorio si se copiara a un sistema de archivos XFS. xfs_estimate no cruza puntos de montaje. Se utilizan las siguientes definiciones:

KB = *1024
MB = *1024*1024
GB = *1024*1024*1024

Las opciones de xfs_estimate son:

-b tamaño_bloque
Utiliza tamaño_bloque en lugar del tamaño de bloque predeterminado de 4096 bytes. El modificador k se puede usar después del número para indicar la multiplicación por 1024. Por ejemplo,
xfs_estimate -b 64k /
solicita una estimación del espacio requerido por el directorio / en un sistema de archivos XFS usando un tamaño de bloque de 64K (65536) bytes.
-v
Muestra más información, formateada.
-h
Muestra el mensaje de uso.
-i, -e tamaño_log
Utiliza tamaño_log en lugar del tamaño de registro predeterminado de 1000 bloques. -i se refiere a un registro interno, mientras que -e se refiere a un registro externo. Los modificadores k o m se pueden usar después del número para indicar la multiplicación por 1024 o 1048576, respectivamente.
Por ejemplo,
xfs_estimate -i 1m /
solicita una estimación del espacio requerido por el directorio / en un sistema de archivos XFS utilizando un registro interno de 1 megabyte.
-V
Imprime el número de versión y sale.

EJEMPLOS

% xfs_estimate -e 10m /var/tmp
/var/tmp ocupará aproximadamente 4.2 megabytes
        con el registro externo usando 2560 bloques o aproximadamente 10.0 megabytes
% xfs_estimate -v -e 10m /var/tmp
directorio                     tamaño_bloque    bloques    megabytes    tamaño_log
/var/tmp                       4096             792        4.0MB      10485760
% xfs_estimate -v /var/tmp
directorio                     tamaño_bloque    bloques    megabytes    tamaño_log
/var/tmp                       4096             3352       14.0MB     10485760
% xfs_estimate /var/tmp
/var/tmp ocupará aproximadamente 14.0 megabytes
