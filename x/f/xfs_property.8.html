NOMBRE

xfs_property - examinar y editar propiedades de un sistema de archivos XFS

SINOPSIS

xfs_property objetivo get nombre...
xfs_property objetivo list [ -v ]
xfs_property objetivo set nombre=valor...
xfs_property objetivo remove nombre...
xfs_property -V

DESCRIPCIÓN

xfs_property recupera, lista, establece o elimina propiedades de un sistema de archivos XFS. Las propiedades del sistema de archivos son atributos controlados por la raíz que se establecen en el directorio raíz del sistema de archivos para permitir que el administrador del sistema se coordine con los programas del espacio de usuario.

objetivo es uno de: el directorio raíz de un sistema de archivos montado; un dispositivo de bloques que contiene un sistema de archivos XFS; o un archivo regular que contiene un sistema de archivos XFS.

OPCIONES

-V
Imprime el número de versión y sale.

COMANDOS

get
nombre... Imprime los valores de las propiedades dadas del sistema de archivos.
list
Enumera los nombres de todas las propiedades del sistema de archivos. Si se especifica la opción -v, también imprime los valores.
set
nombre=valor... Establece las propiedades dadas del sistema de archivos a los valores especificados e imprime lo que se estableció.
remove
nombre... Deshabilita las propiedades dadas del sistema de archivos.

PROPIEDADES DEL SISTEMA DE ARCHIVOS

autofsck Ver xfs_scrub(8) para más información.
