NOMBRE

xfce4-screensaver-command - controla el salvapantallas de Xfce

SINOPSIS

xfce4-screensaver-command [OPCIÓN...]

DESCRIPCIÓN

xfce4-screensaver-command es una herramienta para controlar una instancia en ejecución de xfce4-screensaver.

OPCIONES

--exit
Hace que el salvapantallas salga con gracia
-q, --query
Consulta el estado del salvapantallas
-t, --time
Consulta el tiempo que el salvapantallas ha estado activo
-l, --lock
Indica al proceso de salvapantallas en ejecución que bloquee la pantalla inmediatamente
-c, --cycle
Si el salvapantallas está activo, cambia a otra demostración gráfica
-a, --activate
Enciende el salvapantallas (oscurece la pantalla)
-d, --deactivate
Si el salvapantallas está activo, lo desactiva (enciende la pantalla)
-p, --poke
Aviva el salvapantallas en ejecución para simular actividad del usuario
-i, --inhibit
Inhibe la activación del salvapantallas. El comando se bloquea mientras la inhibición está activa.
-n, --application-name
La aplicación que llama está inhibiendo el salvapantallas
-r, --reason
La razón para inhibir el salvapantallas
-V, --version
Versión de esta aplicación
