NOMBRE

xflame - dibuja llamas animadas

SINOPSIS

xflame [--display host:display.screen] [--window] [--root] [--window-id número][--install] [--visual visual] [--foreground color] [--hspread int] [--vspread int] [--residual int] [--variance int] [--vartrend int] [--bloom --no-bloom] [--bitmap archivo-xbm] [--baseline int] [--fps]

DESCRIPCIÓN

El programa xflame dibuja llamas animadas en la parte inferior de la pantalla. Las llamas ocasionalmente brotan. Si se especifica un mapa de bits, esa imagen flotará sobre las llamas, quemándose.

OPCIONES

xflame acepta las siguientes opciones:

--window
Dibuja en una ventana recién creada. Este es el valor predeterminado.
--root
Dibuja en la ventana raíz.
--window-id número
Dibuja en la ventana especificada.
--install
Instala un mapa de colores privado para la ventana.
--visual visual
Especifica qué visual usar. Los valores legales son el nombre de una clase visual o el número de id (decimal o hexadecimal) de un visual específico.
--foreground color o --fg color
El color de las llamas; por defecto, rojo. (El color de fondo es siempre negro).
--bitmap archivo
Especifica el archivo de mapa de bits a usar (un archivo XBM monocromático). El nombre "none" significa no usar ningún mapa de bits. Si no se especifica, se usará una imagen integrada.

Las otras opciones son arcanas. Si alguien se tomara la molestia de documentarlas, sería genial.

--fps
Muestra la velocidad de fotogramas actual y la carga de la CPU.

AMBIENTE

DISPLAY
para obtener el host y el número de pantalla predeterminados.
XENVIRONMENT
para obtener el nombre de un archivo de recursos que anula los recursos globales almacenados en la propiedad RESOURCE_MANAGER.
XSCREENSAVER_WINDOW
El ID de la ventana a usar con --root.
