NOMBRE

xfce4-notifyd-config - GUI de configuración para xfce4-notifyd

SINOPSIS

xfce4-notifyd-config [-?] [-V] [-s ID_SOCKET] [--display=DISPLAY]

DESCRIPCIÓN

xfce4-notifyd-config iniciará la GUI de configuración para xfce4-notifyd.

OPCIONES

-?, --help
Mostrar ayuda
-V, --version
Mostrar información de la versión
-s, --socket-id=ID_SOCKET
Socket del gestor de configuración
--display=DISPLAY
Pantalla X a usar
