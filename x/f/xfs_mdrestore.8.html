xfs_mdrestore(8) Manual del Administrador del Sistema xfs_mdrestore(8)

NOMBRE

xfs_mdrestore - restaura una imagen de metadatos de XFS a una imagen del sistema de archivos

SINOPSIS

xfs_mdrestore [ -gi ] [ -l dispositivo_log ] [ -r dispositivo_rt ] fuente destino
xfs_mdrestore -i [ -l dispositivo_log ] [ -r dispositivo_rt ] fuente
xfs_mdrestore -V

DESCRIPCIÓN

xfs_mdrestore es una herramienta de depuración que restaura una imagen de metadatos generada por xfs_metadump(8) a un sistema de archivos. El argumento fuente especifica la ubicación de la imagen de metadatos y el argumento destino especifica el destino para la imagen del sistema de archivos. Si fuente es -, entonces la imagen de metadatos se lee desde stdin. Esto permite que la salida de otro programa, como una aplicación de compresión, se redirija a xfs_mdrestore. El destino puede ser un archivo o un dispositivo.

xfs_mdrestore no debe usarse para restaurar metadatos en un sistema de archivos existente a menos que esté completamente seguro de que el destino puede ser destruido.

OPCIONES

-g
Muestra el progreso de la restauración en stdout.
-i
Muestra información del volcado de metadatos en stdout. Si no se especifica destino, sale después de mostrar la información. Los volcados de metadatos antiguos pueden no incluir información descriptiva.
-l dispositivo_log
Los volcados de metadatos en formato v2 pueden contener metadatos volcados de un registro externo. En tal escenario, el usuario debe proporcionar un dispositivo al cual se copian los contenidos del dispositivo de registro del archivo de metadatos.
-r dispositivo_rt
Restaura los metadatos del dispositivo en tiempo real a este dispositivo. Esto solo es necesario para un volcado de metadatos en formato v2.
-V
Imprime el número de versión y sale.

DIAGNÓSTICOS

xfs_mdrestore devuelve un código de salida de 0 si todos los metadatos se restauran correctamente o 1 si ocurre un error.

VER TAMBIÉN

xfs_metadump(8), xfs_repair(8), xfs(5)
