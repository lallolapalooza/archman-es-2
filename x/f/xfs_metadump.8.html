NOMBRE

xfs_metadump - copia los metadatos del sistema de archivos XFS a un archivo

SINOPSIS

xfs_metadump [ -aefFgow ] [ -m max_extents ] [ -l logdev ] [ -r rtdev ] [ -v version ] fuente destino
xfs_metadump -V

DESCRIPCIÓN

xfs_metadump es una herramienta de depuración que copia los metadatos de un sistema de archivos XFS a un archivo. El argumento fuente debe ser la ruta del dispositivo o archivo que contiene el sistema de archivos XFS y el argumento destino especifica el nombre del archivo de destino. Si destino es -, entonces la salida se envía a stdout. Esto permite que la salida se redirija a otro programa, como una aplicación de compresión.

xfs_metadump solo se puede usar para copiar sistemas de archivos desmontados o sistemas de archivos montados en modo de solo lectura.

xfs_metadump no altera el sistema de archivos de origen de ninguna manera. La imagen de destino es un archivo contiguo (no disperso) que contiene todos los metadatos e índices del sistema de archivos de donde se copiaron los bloques.

Por defecto, xfs_metadump ofusca la mayoría de los nombres de archivos (archivo regular, directorio y enlace simbólico) y nombres de atributos extendidos para permitir que los volquetes se envíen sin revelar información confidencial. Los valores de los atributos extendidos se ponen a cero y no se copia ningún dato. Las únicas excepciones son los nombres de archivos o atributos que tienen 4 o menos caracteres de longitud. Los nombres de archivos que abarcan extensiones (esto solo puede ocurrir con las opciones de mkfs.xfs(8) donde -n tamaño > -b tamaño) tampoco se ofuscan. Los nombres entre 5 y 8 caracteres de longitud, inclusive, se ofuscan parcialmente.

xfs_metadump no puede ofuscar metadatos en el registro del sistema de archivos. La recuperación del registro de una imagen de metadump ofuscada puede exponer metadatos en texto plano y/o causar corrupción del sistema de archivos en la imagen restaurada. Se recomienda que el sistema de archivos de origen se monte y desmonte primero, si es posible, para asegurar que el registro esté limpio. Una invocación posterior de xfs_metadump capturará un registro limpio y ofuscará todos los metadatos correctamente.

Si se debe producir un metadump de un sistema de archivos con un registro sucio, se recomienda desactivar la ofuscación con la opción -o, si los metadatos, como los nombres de archivos, no se consideran sensibles. Si la ofuscación es necesaria en un metadump con un registro sucio, informe al destinatario de la imagen de metadump sobre esta situación.

El contenido de un dispositivo de registro externo solo se puede volcar cuando se utiliza el formato v2. El metadump en formato v2 se puede generar pasando la opción "-v 2". El metadump en formato v2 se genera por defecto si el sistema de archivos tiene un registro externo y la versión de metadump a utilizar no se menciona explícitamente.

xfs_metadump no debe usarse para ningún propósito que no sea la depuración y la notificación de problemas del sistema de archivos. El escenario de uso más común para esta herramienta es cuando xfs_repair(8) falla al reparar un sistema de archivos y se puede enviar una imagen de metadump para su análisis.

El archivo generado por xfs_metadump se puede restaurar a una imagen de sistema de archivos (menos los datos) utilizando la herramienta xfs_mdrestore(8).

OPCIONES

-a
Copia bloques de metadatos completos. Normalmente, xfs_metadump pondrá a cero los bytes obsoletos intercalados con metadatos en uso. Use esta opción para copiar bloques de metadatos completos, para proporcionar más información de depuración para un sistema de archivos corrupto. Tenga en cuenta que los datos adicionales no serán ofuscados.
-e
Detiene el volcado ante un error de lectura. Normalmente, ignora los errores de lectura y copia todos los metadatos que son accesibles.
-f
Especifica que la imagen del sistema de archivos a procesar está almacenada en un archivo regular (ver la opción de archivo mkfs.xfs -d). Esto también puede ocurrir si se ha realizado una copia de imagen de un sistema de archivos en un archivo normal con xfs_copy(8).
-F
Especifica que queremos continuar incluso si la magia de la superbloque no es correcta. Si la fuente realmente no es un sistema de archivos XFS, la imagen resultante será inútil y xfs_metadump puede fallar.
-g
Muestra el progreso del volcado. Esto se envía a stdout si el destino es un archivo o a stderr si el destino es stdout.
-l logdev
Para sistemas de archivos que utilizan un registro externo, esto especifica el dispositivo donde reside el registro externo. Si se selecciona el formato de metadump v2, el contenido del registro externo se copiará al metadump. El formato de metadump v2 se seleccionará automáticamente si se especifica esta opción.
-m
Establece el tamaño máximo de una extensión de metadatos permitida. Las extensiones de metadatos extremadamente grandes probablemente estarán corruptas y se omitirán si exceden este valor. El tamaño por defecto es 2097151 bloques.
-o
Desactiva la ofuscación de nombres de archivos y atributos extendidos.
-r rtdev
Para sistemas de archivos que tienen una sección en tiempo real, esto especifica el dispositivo donde reside la sección en tiempo real. Si se selecciona el formato de metadump v2, los superbloques del grupo en tiempo real se copiarán al metadump. El formato de metadump v2 se seleccionará automáticamente si el sistema de archivos contiene grupos en tiempo real.
-v
El formato del archivo de metadump a producir. Los valores válidos son 1 y 2. El formato de metadump por defecto es 1.
-w
Imprime advertencias de metadatos inconsistentes encontrados en stderr. Los metadatos erróneos todavía se copian.
-V
Imprime el número de versión y sale.

DIAGNÓSTICOS

xfs_metadump devuelve un código de salida de 0 si todos los metadatos legibles se copian con éxito o 1 si ocurre un error de escritura o un error de lectura y se usó la opción -e.

NOTAS

Dado que xfs_metadump solo copia metadatos, no importa si el sistema de archivos de fuente tiene una sección en tiempo real o no. Si el sistema de archivos tiene un registro externo, no se copia. Los registros internos se copian y las transacciones de registro pendientes no se ofuscan si contienen nombres.

xfs_metadump es un script wrapper para el comando metadump de xfs_db(8).

VER TAMBIÉN

xfs_repair(8), xfs_mdrestore(8), xfs_freeze(8), xfs_db(8), xfs_copy(8), xfs(5)

DESCRIPCIÓN

xfs_metadump es una utilidad para volcar los metadatos de un sistema de archivos XFS a un archivo. El propósito principal de xfs_metadump es para la recuperación de datos en caso de que un sistema de archivos se corrompa.

xfs_metadump se puede usar para respaldar una imagen de metadatos de un sistema de archivos XFS desmontado o montado. Sin embargo, se recomienda encarecidamente que el sistema de archivos se desmonte si es posible. Si el sistema de archivos está montado, xfs_metadump intentará tomar una instantánea de la memoria del sistema de archivos y volcar los metadatos del disco de esa instantánea. Si el sistema de archivos está en uso, la imagen de metadatos puede no ser consistente.

La salida de xfs_metadump es una imagen binaria de los metadatos del sistema de archivos XFS. Esta imagen se puede usar posteriormente con xfs_mdrestore para intentar restaurar los metadatos del sistema de archivos.

OPCIONES

-f archivo_salida
Especifica el archivo de salida donde se volcarán los metadatos. Si no se especifica, xfs_metadump intentará volcar los metadatos a /dev/null.
-p patrón_archivo
Especifica un patrón para los nombres de los archivos de salida. Por ejemplo, -p prefijo_%d_sufijo creará archivos de salida como prefijo_0_sufijo, prefijo_1_sufijo, etc. Si se especifica, la opción -f se ignora.
-c separador
Especifica el carácter separador a usar entre los fragmentos del patrón de archivo especificado con -p. El valor predeterminado es _ (guión bajo).
-i archivo_imagen
Especifica un archivo de imagen de sistema de archivos XFS existente. Si se especifica, xfs_metadump volcará los metadatos de este archivo de imagen en lugar de un dispositivo de bloque. Esto es útil para analizar imágenes de disco completas que contienen sistemas de archivos XFS.
-o
Sobrescribe los archivos de salida existentes si ya existen.
-v
Modo verboso. Imprime información detallada sobre el progreso y los metadatos que se están volcando.
-h
Muestra el mensaje de ayuda y sale.
-V
Muestra la información de la versión y sale.

DIAGNÓSTICOS

xfs_metadump devuelve un código de salida de cero si la operación es exitosa. En caso de error, devuelve un valor distinto de cero. Los mensajes de error se imprimen en la salida de error estándar.

NOTAS

Se recomienda encarecidamente que el sistema de archivos XFS se desmonte antes de ejecutar xfs_metadump para garantizar la coherencia de los metadatos volcados. Si el sistema de archivos está montado y en uso, los metadatos volcados pueden no ser consistentes.

La imagen de metadatos creada por xfs_metadump es específica de la versión de XFS y solo puede ser restaurada por xfs_mdrestore de la misma versión de XFS o una compatible.

VER TAMBIÉN

xfs_mdrestore(8), xfs_repair(8), xfsdump(8)

ERRORES

Reportar errores a la lista de correo de XFS: linux-xfs@vger.kernel.org
