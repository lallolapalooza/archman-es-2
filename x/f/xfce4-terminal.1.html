NOMBRE

xfce4-terminal - Un emulador de terminal para X

SINOPSIS

xfce4-terminal [OPCIÓN...]

DESCRIPCIÓN

xfce4-terminal es lo que se conoce como un emulador de terminal X, a menudo referido como terminal o shell. Proporciona un equivalente a la pantalla de texto antigua en su escritorio, pero una que puede compartir fácilmente la pantalla con otras aplicaciones gráficas. Los usuarios de Windows quizás ya estén familiarizados con la utilidad Símbolo del sistema de MS-DOS, que tiene la función análoga de ofrecer una línea de comandos de DOS en Windows, aunque hay que tener en cuenta que la CLI de UNIX ofrece mucha más potencia y facilidad de uso que DOS.

xfce4-terminal emula la aplicación xterm desarrollada por el X Consortium. A su vez, la aplicación xterm emula el terminal DEC VT102 y también soporta las secuencias de escape DEC VT220. Una secuencia de escape es una serie de caracteres que comienzan con el carácter Esc. xfce4-terminal acepta todas las secuencias de escape que los terminales VT102 y VT220 usan para funciones como posicionar el cursor y borrar la pantalla.

OPCIONES

Resumen de Opciones

Aquí hay un resumen de todas las opciones, agrupadas por tipo. Las explicaciones están en las siguientes secciones.

Opciones Generales

Opciones Generales

-h, --help

Lista las diversas opciones de línea de comandos soportadas por xfce4-terminal y sale.

-V, --version

Muestra la información de la versión y sale.

--disable-server

No se registra en el bus de mensajes de sesión D-BUS. Ejecuta este terminal en su propio proceso.

--color-table

Muestra los códigos de color.

--preferences

Abre la ventana de preferencias de xfce4-terminal.

--default-display=display

Pantalla X predeterminada a usar.

--default-working-directory=directorio

Establece directorio como el directorio de trabajo predeterminado para el terminal.

Separadores de Ventana o Pestaña

--tab

Abre una nueva pestaña en la última ventana especificada. Se pueden proporcionar más de una de estas opciones, cada una abriendo una pestaña adicional.

--window

Abre una nueva ventana que contiene una pestaña. Se pueden proporcionar más de una de estas opciones.

Si hay una ventana activa, la última ventana especificada es esa ventana hasta que se encuentra una opción --window, momento en el cual esa nueva ventana es la última ventana especificada.

Si no hay una ventana activa, la última ventana especificada es la ventana creada por xfce4-terminal hasta que se encuentra una opción --window, momento en el cual esa nueva ventana es la última ventana especificada.

Estas opciones se pueden combinar con --drop-down.

Opciones de Pestaña

-x, --execute

Ejecuta el resto de la línea de comandos dentro del terminal.

-e, --command=comando

Ejecuta comando dentro del terminal.

-T, --title=título

Establece título como el título de la ventana para el terminal (ignora el título establecido dinámicamente).

--dynamic-title-mode=modo

Establece modo como el modo de título dinámico para el terminal, uno de: 'replace', 'before', 'after', 'none'.

--initial-title=título

Establece título como el título inicial de la ventana para el terminal (respeta el título establecido dinámicamente).

--working-directory=directorio

Establece directorio como el directorio de trabajo para el terminal.

-H, --hold

Hace que el terminal se mantenga abierto después de que el comando hijo haya terminado.

--active-tab

Hace que la pestaña sea activa: útil cuando una ventana de terminal contiene varias pestañas.

--color-text=color

Establece color como el color del texto para el terminal según la siguiente especificación: https://docs.gtk.org/gdk3/method.RGBA.parse.html

--color-bg=color

Establece color como el color de fondo para el terminal según la siguiente especificación: https://docs.gtk.org/gdk3/method.RGBA.parse.html

Opciones de Ventana

--display=display

Pantalla X a usar para la última ventana especificada.

--drop-down

Iniciará la ventana en modo desplegable (también llamado terminal estilo Quake). Esto solo se aplicará a la primera ventana iniciada con esta opción. Se recomienda vincular esto a un atajo en las preferencias del teclado.

--geometry=geometría

Establece la geometría de la última ventana especificada a geometría. Lea X(7) para más información sobre cómo especificar geometrías de ventana.

--role=rol

Establece el rol de la ventana de la última ventana especificada a rol. Se aplica solo a una ventana y se puede especificar una vez por cada ventana que cree desde la línea de comandos. El rol es un identificador único para la ventana que se utilizará al restaurar una sesión.

--startup-id=cadena

Especifica el id de notificación de inicio para la última ventana especificada. Se utiliza internamente para reenviar el id de notificación de inicio al usar el servicio D-BUS.

-I, --icon=icono

Establece el icono del terminal como un nombre de icono o nombre de archivo.

--fullscreen

Establece la última ventana especificada en modo de pantalla completa; se aplica solo a una ventana; se puede especificar una vez por cada ventana que cree desde la línea de comandos.

--maximize

Establece la última ventana especificada en modo maximizado; se aplica solo a una ventana; se puede especificar una vez por cada ventana que cree desde la línea de comandos.

--minimize

Establece la última ventana especificada en modo minimizado; se aplica solo a una ventana; se puede especificar una vez por cada ventana que cree desde la línea de comandos.

--show-menubar

Activa la barra de menú para la última ventana especificada. Se puede especificar una vez por cada ventana que cree desde la línea de comandos.

--hide-menubar

Desactiva la barra de menú para la última ventana especificada. Se puede especificar una vez por cada ventana que cree desde la línea de comandos.

--show-borders

Muestra los bordes para la última ventana especificada. Se puede especificar una vez por cada ventana que cree desde la línea de comandos.

--hide-borders

Oculta los bordes para la última ventana especificada. Se puede especificar una vez por cada ventana que cree desde la línea de comandos.

--show-toolbar

Muestra la barra de herramientas para la última ventana especificada. Se puede especificar una vez por cada ventana que cree desde la línea de comandos.

--hide-toolbar

Oculta la barra de herramientas para la última ventana especificada. Se puede especificar una vez por cada ventana que cree desde la línea de comandos.

--show-scrollbar

Muestra la barra de desplazamiento para la última ventana especificada. Se puede especificar una vez por cada ventana que cree desde la línea de comandos.

--hide-scrollbar

Oculta la barra de desplazamiento para la última ventana especificada. Se puede especificar una vez por cada ventana que cree desde la línea de comandos.

--font=fuente

Establece la fuente para la última ventana especificada a fuente. Lea la especificación Pango para más información sobre cómo especificar la fuente.

--zoom=zoom

Establece el nivel de zoom para la última ventana especificada. El valor de zoom es un número flotante que representa el porcentaje de la fuente. Por ejemplo, 1.0 es el 100% (sin zoom), 1.2 es el 120% y 0.8 es el 80%.

--class=clase

Establece la clase de ventana para la última ventana especificada a clase. Se puede usar para que el administrador de ventanas agrupe o decore ventanas de manera diferente. Por defecto, la clase es "Xfce4-terminal".

bash(1), zsh(1), X(7)

OPTIONS

--geometry=GEOMETRY

Set the window size and position. The value is a standard X geometry string (e.g. 80x25+10+10).

--full-screen

Start the terminal window in full screen mode.

--maximize

Start the terminal window maximized.

--show-menubar

Turn on the menubar for the last-specified window. Can be specified once for each window you create from the command line.

--hide-menubar

Turn off the menubar for the last-specified window. Can be specified once for each window you create from the command line.

--show-borders

Turn on the window decorations for the last-specified window. Applies to only one window. Can be specified once for each window you create from the command line.

--hide-borders

Turn off the window decorations for the last-specified window. Applies to only one window. Can be specified once for each window you create from the command line.

--show-toolbar

Turn on the toolbar for the last-specified window. Applies to only one window. Can be specified once for each window you create from the command line.

--hide-toolbar

Turn off the toolbar for the last-specified window. Applies to only one window. Can be specified once for each window you create from the command line.

--show-scrollbar

Turn on the scrollbar for the last-specified window. Scrollbar position is taken from the settings; if position is None, the default position is Right side. Applies to only one window. Can be specified once for each window you create from the command line.

--hide-scrollbar

Turn off the scrollbar for the last-specified window. Applies to only one window. Can be specified once for each window you create from the command line.

--font=fuente

Establecer la fuente de la terminal.

--zoom=zoom

Establecer el nivel de zoom: el tamaño de la fuente se multiplicará por este nivel. El rango es de -7 a 7, por defecto es 0. Cada paso multiplica el tamaño por 1.2, es decir, el nivel 7 es 3.5831808 (1.2^7) veces mayor que el tamaño por defecto.

--class=clase

Establecer la clase del gestor de ventanas de todas las ventanas de terminal. Controla la agrupación de ventanas en el panel. Si ya hay una instancia de terminal abierta, requiere que se establezca --disable-server.

EJEMPLOS

xfce4-terminal --geometry 80x40 --command mutt --tab --command mc

Abre una nueva ventana de terminal con una geometría de 80 columnas y 40 filas y dos pestañas en ella, donde la primera pestaña ejecuta mutt y la segunda pestaña ejecuta mc.

MEDIO AMBIENTE

xfce4-terminal utiliza la Especificación de Directorios Base definida en Freedesktop.org[1] para localizar sus archivos de datos y configuración. Esto significa que las ubicaciones de los archivos se especificarán como una ruta relativa a los directorios descritos en la especificación.

${XDG_CONFIG_HOME}

El primer directorio base para buscar archivos de configuración. Por defecto se establece en ~/.config/.

${XDG_CONFIG_DIRS}

Una lista separada por dos puntos de directorios base que contienen datos de configuración. Por defecto, la aplicación buscará en ${sysconfdir}/xdg/. El valor de ${sysconfdir} depende de cómo se compiló el programa y a menudo será /etc/ para los paquetes binarios.

${XDG_DATA_HOME}

La raíz para todos los archivos de datos específicos del usuario. Por defecto se establece en ~/.local/share/.

${XDG_DATA_DIRS}

Un conjunto de directorios base ordenados por preferencia en relación con los cuales se buscarán los archivos de datos además del directorio base ${XDG_DATA_HOME}. Los directorios deben estar separados por dos puntos.

ARCHIVOS

${XDG_CONFIG_HOME}/xfce4/terminal/accels.scm

Esta es la ubicación del archivo de configuración de atajos de teclado para xfce4-terminal. Editar este archivo permite modificar o deshabilitar atajos para las acciones soportadas.
