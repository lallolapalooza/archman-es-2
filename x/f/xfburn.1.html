XFBURN(1) Comandos de usuario XFBURN(1)

NOMBRE

xfburn - Una aplicación de grabación fácil de usar

SINOPSIS

xfburn --quema-imagen [IMAGEN]

xfburn [opciones] --composicion-datos | --composicion-audio [[ARCHIVO]...]

xfburn --borrar

xfburn --transcodificador lista | basico | gst

DESCRIPCIÓN

xfburn es una aplicación de grabación fácil de usar basada en las bibliotecas libburnia. Hasta ahora, permite grabar en CD y DVD, así como borrar discos regrabables. Se pueden crear composiciones de datos y audio desde cero. Se pueden grabar o crear imágenes en formato .iso.

INVOCACIÓN

xfburn se puede llamar con --quema-imagen para mostrar inmediatamente el diálogo de grabación de imagen. Opcionalmente, el *archivo de imagen* puede ser preseleccionado añadiéndolo a la línea de comandos.

Cuando se especifica la opción --composicion-datos o --composicion-audio, la ventana principal de xfburn se abrirá con el tipo de composición seleccionado en lugar de la pestaña de bienvenida. El *nombre del archivo o nombres de archivo* del contenido de la composición pueden seguir a la opción de composición.

Opciones

-?, --ayuda

Imprime ayuda breve y sale.

-V, --versión

Imprime información de la versión y sale.

-i, --quema-imagen [IMAGEN]

Abre el diálogo de grabación de imagen. Opcionalmente, la imagen se proporciona como *IMAGEN*.

-b, --borrar

Abre el diálogo de borrado de disco.

-d, --composicion-datos [ARCHIVO(S)]

Abre xfburn con una nueva composición de datos. Opcionalmente, los *ARCHIVOS(S)* a añadir a la composición le siguen.

-a, --composicion-audio [ARCHIVO(S) DE MÚSICA]

Abre xfburn con una nueva composición de audio. Opcionalmente, los *ARCHIVOS(S) DE MÚSICA* a añadir a la composición le siguen.

-t, --transcodificador [TRANSCODIFICADOR]

Selecciona el transcodificador a utilizar al crear composiciones de audio. Especifique *lista* para ver todas las opciones disponibles. Actualmente implementados son el transcodificador gst y el básico. gst usa gstreamer y permite el uso de cualquier archivo multimedia compatible con gstreamer. basico solo permite el uso de archivos de audio ya en formato CD: archivos WAV de 48 kHz sin comprimir.

-m, --principal

Cuando se selecciona la opción --quema-imagen o --borrar, xfburn saldrá después de que el diálogo haya finalizado, a menos que se proporcione la opción --principal. En ese caso, la ventana principal de xfburn se mostrará después de que el diálogo haya sido cerrado.

--display=PANTALLA

Usa la PANTALLA X especificada para la interfaz de usuario.
