NOMBRE

xfs_growfs - expandir un sistema de archivos XFS

SINOPSIS

xfs_growfs [ -dilnrx ] [ -D tamaño ] [ -e tamaño_ext_rt ] [ -L tamaño ] [ -m porcentaje_max ] [ -t mtab ] [ -R tamaño ] [ punto-de-montaje | dispositivo-bloque ]

xfs_growfs -V

DESCRIPCIÓN

xfs_growfs expande un sistema de archivos XFS existente (ver xfs(5)). El argumento punto-de-montaje es la ruta del directorio donde está montado el sistema de archivos. El argumento dispositivo-bloque es el nombre del dispositivo de un sistema de archivos XFS montado. El sistema de archivos debe estar montado para poder ser expandido (ver mount(8)). El contenido existente del sistema de archivos no se ve alterado y el espacio añadido se vuelve disponible para almacenamiento adicional de archivos.

OPCIONES

-d | -D tamaño
Especifica que la sección de datos del sistema de archivos debe ser redimensionada. Si se proporciona la opción -D tamaño, la sección de datos se cambia a ese tamaño, de lo contrario, la sección de datos se expande al tamaño más grande posible con la opción -d. El tamaño se expresa en bloques del sistema de archivos. Un sistema de archivos con solo 1 AG no puede ser reducido más allá, y un sistema de archivos no puede ser reducido hasta el punto de tener solo 1 AG. [NOTA: Solo se implementa la reducción del último AG sin eliminarlo]
-e
Permite especificar el tamaño del extents en tiempo real. En mkfs.xfs(8) esto se especifica con -r extsize=nnnn.
-i
El nuevo log es un log interno (dentro de la sección de datos). [NOTA: Esta opción no está implementada]
-l | -L tamaño
Especifica que la sección de log del sistema de archivos debe ser expandida, reducida o movida. Si se proporciona la opción -L tamaño, la sección de log se cambia a ese tamaño, si es posible. El tamaño se expresa en bloques del sistema de archivos. El tamaño de un log interno debe ser menor que el tamaño de un grupo de asignación (este valor se imprime al tiempo de mkfs(8)). Si no se proporciona ni -i ni -x con -l, el log continúa siendo interno o externo como estaba antes. [NOTA: Estas opciones no están implementadas]
-m
Especifica un nuevo valor para el porcentaje máximo de espacio en el sistema de archivos que puede ser asignado como inodos. En mkfs.xfs(8) esto se especifica con -i maxpct=nn.
-n
Especifica que no se realizará ningún cambio en el sistema de archivos. Se imprime la geometría del sistema de archivos y se realizan comprobaciones de argumentos, pero no ocurre ninguna expansión. Ver ejemplos de salida a continuación.
-r | -R tamaño
Especifica que la sección en tiempo real del sistema de archivos debe ser expandida. Si se proporciona la opción -R tamaño, la sección en tiempo real se expande a ese tamaño, de lo contrario, la sección en tiempo real se expande al tamaño más grande posible con la opción -r. El tamaño se expresa en bloques del sistema de archivos. El sistema de archivos no necesita haber contenido una sección en tiempo real antes de la operación xfs_growfs.
-t
Especifica un archivo de tabla de montaje alternativo (el valor predeterminado es /proc/mounts si existe, de lo contrario /etc/mtab). Esto se usa cuando se trabaja con sistemas de archivos montados sin escribir en el archivo /etc/mtab; consultar mount(8) para más detalles.
-V
Imprime el número de versión y sale. El argumento punto-de-montaje no es requerido con -V.

xfs_growfs se usa más frecuentemente en conjunto con volúmenes lógicos (ver md(4) y lvm(8) en Linux). Sin embargo, también puede usarse en una partición de disco normal, por ejemplo, si una partición ha sido ampliada conservando el mismo bloque de inicio.

USO PRÁCTICO

Los sistemas de archivos normalmente ocupan todo el espacio en el dispositivo donde residen. Para expandir un sistema de archivos, es necesario proporcionarle espacio adicional para que lo ocupe. Por lo tanto, debe haber al menos una nueva partición de disco libre disponible. La adición de espacio a menudo se realiza a través de un gestor de volúmenes lógicos.

VER TAMBIÉN

mkfs.xfs(8), xfs_info(8), md(4), lvm(8), mount(8).
