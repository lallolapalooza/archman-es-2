NOMBRE

xfs_scrub_all - verificar todos los sistemas de archivos XFS montados

SINOPSIS

xfs_scrub_all [ -hxV ]

DESCRIPCIÓN

xfs_scrub_all intenta leer y comprobar todos los metadatos de todos los sistemas de archivos XFS montados. La verificación en línea se realiza a través de la herramienta xfs_scrub, ya sea ejecutándola directamente o utilizando systemd para iniciarla de forma restringida. Los sistemas de archivos montados se mapean a dispositivos de almacenamiento físicos para que las operaciones de verificación puedan ejecutarse en paralelo, siempre que dos verificadores no accedan al mismo dispositivo simultáneamente.

OPCIONES

--auto-media-scan-interval
Habilita automáticamente el escaneo de datos de archivos (es decir, la bandera -x) si no se ha ejecutado en el intervalo especificado. El intervalo debe ser un número de punto flotante con un sufijo de unidad opcional. Los sufijos de unidad admitidos son y, q, mo, w, d, h, m y s para años, trimestres de 90 días, meses de 30 días, semanas, días, horas, minutos y segundos, respectivamente. Si no se especifican unidades, el valor predeterminado son segundos.
--auto-media-scan-stamp
Ruta a un archivo que registrará la última vez que se ejecutó el escaneo de medios. El valor predeterminado es /var/lib/xfsprogs/xfs_scrub_all_media.stamp.
-h
Mostrar ayuda.
-x
Leer todos los extentos de datos de archivos para buscar errores de disco.
-V
Imprime el número de versión y sale.

CÓDIGO DE SALIDA

El código de salida devuelto por xfs_scrub_all es la suma de las siguientes condiciones:
0 - Sin errores
4 - Errores del sistema de archivos sin corregir
8 - Error operativo
16 - Error de uso o sintaxis

Estos son los mismos códigos de error que devuelve xfs_scrub.

VER TAMBIÉN
