NOMBRE

xfs_protofile - crea un archivo de prototipo para usar con mkfs.xfs

SINOPSIS

xfs_protofile ruta [ rutas... ]
xfs_protofile -V

DESCRIPCIÓN

xfs_protofile recorre un árbol de directorios para generar un archivo de prototipo. El formato del archivo de prototipo se especifica en el manual de mkfs.xfs(8) y se deriva de la 3ª edición de Unix.

OPCIONES

ruta
Crea directivas de archivo de prototipo para copiar esta ruta en el directorio raíz. Si la ruta es un directorio, se emitirán directivas de archivo de prototipo para replicar todo el subárbol como un subárbol del directorio raíz. Si la ruta no es un directorio, se emitirán directivas de archivo de prototipo para crear el archivo como una entrada en el directorio raíz. La primera ruta debe resolverse a un directorio.

ERRORES

Los nombres de archivo no pueden contener espacios. Los atributos extendidos no se copian al sistema de archivos.
