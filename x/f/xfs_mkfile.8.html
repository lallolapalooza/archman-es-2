NOMBRE

xfs_mkfile - crear un archivo XFS

SINOPSIS

xfs_mkfile [ -v ] [ -n ] [ -p ] tamaño[k|b|m|g] nombrearchivo ...
xfs_mkfile -V

DESCRIPCIÓN

xfs_mkfile crea uno o más archivos. El archivo se rellena con ceros por defecto. El tamaño por defecto está en bytes, pero puede ser marcado como kilobytes, bloques, megabytes o gigabytes con los sufijos k, b, m o g, respectivamente.

OPCIONES

-v
Detallado. Informar los nombres y tamaños de los archivos creados.
-n
Sin bytes. Crear un archivo con huecos (holey file) - es decir, no escribir ningún dato, solo buscar al final del archivo y escribir un bloque.
-p
Preasignar. El archivo se preasigna, luego se sobrescribe con ceros, y luego se trunca al tamaño deseado.
-V
Imprime el número de versión y sale.
