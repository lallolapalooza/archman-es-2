xfs_freeze(8) Manual del Administrador del Sistema xfs_freeze(8)

NOMBRE

xfs_freeze - suspender el acceso a un sistema de archivos XFS

SINOPSIS

xfs_freeze [ -f | -u ] punto-de-montaje
xfs_freeze -V

DESCRIPCIÓN

xfs_freeze suspende y reanuda el acceso a un sistema de archivos XFS (ver xfs(5)).

xfs_freeze detiene el nuevo acceso al sistema de archivos y crea una imagen estable en el disco. xfs_freeze está diseñado para usarse con administradores de volúmenes y dispositivos RAID de hardware que admitan la creación de instantáneas.

El argumento punto-de-montaje es la ruta del directorio donde está montado el sistema de archivos. El sistema de archivos debe estar montado para ser congelado (ver mount(8)).

La opción -f solicita que el sistema de archivos XFS especificado sea congelado de nuevas modificaciones. Cuando se selecciona esto, todas las transacciones en curso en el sistema de archivos se permiten completar, se detienen las nuevas llamadas al sistema de escritura, se detienen otras llamadas que modifican el sistema de archivos, y se escriben en el disco todos los datos, metadatos e información de registro sucios. Cualquier proceso que intente escribir en el sistema de archivos congelado se bloqueará esperando a que se descongele el sistema de archivos.

Tenga en cuenta que incluso después de la congelación, el sistema de archivos en disco puede contener información sobre archivos que todavía están en proceso de desvinculación. Estos archivos no se desvincularán hasta que se descongele el sistema de archivos o se complete un montaje limpio de la instantánea.

La opción -u se utiliza para descongelar el sistema de archivos y permitir que las operaciones continúen. Cualquier modificación del sistema de archivos que se bloqueó por la congelación se desbloqueará y se permitirá que se complete.

La opción -V imprime el número de versión y sale.

A menos que se especifique -V, se debe suministrar una de las opciones -f o -u a xfs_freeze.

NOTAS

Una copia de un sistema de archivos XFS congelado generalmente tendrá el mismo identificador único universal (UUID) que el original, y por lo tanto, puede impedirse su montaje. La opción de montaje de XFS nouuid se puede utilizar para evitar este problema.

En la versión 2.6.29 del kernel de Linux, la interfaz que utiliza XFS para congelar y descongelar se elevó al VFS, por lo que esta herramienta ahora se puede utilizar en muchos otros sistemas de archivos de Linux.

VER TAMBIÉN

xfs(5), lvm(8), mount(8).
