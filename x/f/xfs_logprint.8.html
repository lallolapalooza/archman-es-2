NOMBRE

xfs_logprint - imprime el registro de un sistema de archivos XFS

SINOPSIS

xfs_logprint [ opciones ] dispositivo

DESCRIPCIÓN

xfs_logprint imprime el registro de un sistema de archivos XFS (véase xfs(5)). El argumento dispositivo es la ruta del nombre de la partición o volumen lógico que contiene el sistema de archivos. El dispositivo puede ser un archivo regular si se utiliza la opción -f. El contenido del sistema de archivos permanece inalterado. Hay dos modos principales de operación en xfs_logprint.

Un modo es mejor para depurar la operación del sistema de archivos. Se llama vista transaccional y se habilita mediante la opción -t. La vista transaccional imprime solo la porción del registro que pertenece a la recuperación. En otras palabras, imprime transacciones completas entre la cola y la cabeza. Esta vista intenta mostrar cada transacción sin tener en cuenta cómo se dividen en registros de registro.

El segundo modo comienza a imprimir información desde el principio del registro. Algunos bloques de error pueden imprimirse al principio porque el último registro de registro generalmente se superpone con el registro de registro más antiguo. Se imprime un mensaje cuando se alcanza el final físico del registro y cuando se alcanza el final lógico del registro. Se muestra una vista de registro de registro un registro a la vez. Las transacciones que abarcan varios registros de registro pueden no decodificarse completamente.

OPCIONES

-b
Extrae e imprime información del búfer. Solo se usa en la vista transaccional.
-c
Intenta continuar cuando se detecta un error.
-C nombre_archivo
Copia el registro del sistema de archivos al archivo nombre_archivo. El registro en sí no se imprime.
-d
Vuelca el registro de principio a fin, imprimiendo la ubicación de cada registro de registro en el disco.
-D
No decodifique nada; solo imprima los datos.
-e
Sale cuando se encuentra un error en el registro. Normalmente, xfs_logprint intenta continuar y desenrollarse desde registros erróneos. Sin embargo, a veces simplemente falla de forma grave. Usar esta opción evita volcados del núcleo.
-f
Especifica que la imagen del sistema de archivos a procesar se almacena en un archivo regular en dispositivo (consulte la opción -d archivo de mkfs.xfs(8)). Esto puede ocurrir si se ha realizado una copia de imagen de un sistema de archivos en un archivo ordinario con xfs_copy(8).
-l disp_log
Dispositivo de registro externo. Solo para aquellos sistemas de archivos que utilizan un registro externo.
-i
Extrae e imprime información de inodos. Solo se usa en la vista transaccional.
-q
Extrae e imprime información de cuotas. Solo se usa en la vista transaccional.
-n
No intente interpretar los datos del registro; solo interprete la información del encabezado del registro.
-o
También imprima los datos del búfer en hexadecimal. Normalmente, los datos del búfer solo se decodifican, por lo que se puede imprimir mejor información.
-s bloque-inicio
Anula cualquier noción de dónde comenzar a imprimir.
-t
Imprima la vista transaccional.
-v
Imprima datos de "sobrescritura".
-V
Imprime el número de versión y sale.

VER TAMBIÉN

mkfs.xfs(8), mount(8).
