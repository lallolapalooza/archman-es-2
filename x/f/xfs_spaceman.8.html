xfs_spaceman(8) Manual del Administrador del Sistema xfs_spaceman(8)

NOMBRE

xfs_spaceman - mostrar información de espacio libre de un sistema de archivos XFS

SINOPSIS

xfs_spaceman [ -c comando ] archivo
xfs_spaceman -V

DESCRIPCIÓN

xfs_spaceman informa y controla el uso del espacio libre en un sistema de archivos XFS.

OPCIONES

-c comando
Los comandos de xfs_spaceman se pueden ejecutar interactivamente (por defecto) o como argumentos en la línea de comandos. Se pueden proporcionar múltiples argumentos -c. Los comandos se ejecutan en la secuencia indicada y luego el programa sale.

COMANDOS

freesp [ -dgrs ] [-a agno]... [ -b | -e bsize | -h bsize | -m factor ]
Sin argumentos, freesp muestra un histograma de todas las extensiones de espacio libre en el sistema de archivos. El comando toma las siguientes opciones:
-a agno
Recopilar información de espacio libre de este grupo de asignación. Esta opción se puede especificar varias veces para recopilar de múltiples grupos.
-b
Este argumento establece que los tamaños de los contenedores del histograma son potencias sucesivas de dos. Este es el valor predeterminado y es mutuamente excluyente con las opciones -e, -h y -m.
-d
Imprimir información de depuración, como la información bruta de las extensiones de espacio libre.
-g
Imprimir los recuentos de bloques y extensiones de espacio libre para cada AG.
-e bsize
Establecer todos los tamaños de los contenedores del histograma a un valor específico. Esta opción es mutuamente excluyente con las opciones -b, -h y -m.
-h bsize
Crear un contenedor de histograma con un límite inferior de este valor. El límite superior de este contenedor será uno menos que el límite inferior del siguiente contenedor de histograma más alto. Esta opción se puede dar varias veces para controlar los tamaños exactos de los contenedores. Esta opción es mutuamente excluyente con las opciones -b, -e y -m.
-m factor
Crear cada contenedor de histograma con un tamaño que sea tantas veces mayor que el tamaño del contenedor anterior creado. Esta opción es mutuamente excluyente con las opciones -b, -e y -h.
-r
Consultar el dispositivo en tiempo real para obtener información de espacio libre.
-s
Mostrar un resumen de la información de espacio libre encontrada.
info
Muestra información de geometría seleccionada sobre el sistema de archivos. El archivo abierto debe ser un punto de montaje de un sistema de archivos XFS. La salida tendrá el mismo formato que xfs_info imprime al consultar un sistema de archivos.
health [ -a agno] [ -c ] [ -f ] [ -i inum ] [ -n ] [ -q ] [ -r rgno ] [ rutas ]
Informa sobre el estado de salud del grupo dado de metadatos del sistema de archivos.
-a agno
Informar sobre el estado de salud del grupo de asignación dado.
-c
Escanear todos los inodos en el sistema de archivos e informar el estado de salud de cada archivo. Si se da la opción -a, escanear solo los inodos en esa AG.
-f
Informar sobre el estado de salud de los metadatos que afectan a todo el sistema de archivos.
-i inum
Informar sobre el estado de salud de un inodo específico.
-n
Al informar sobre el estado de salud de un archivo, intente informar la ruta completa del archivo, si es posible. Esta opción está deshabilitada por defecto para minimizar el tiempo de ejecución.
-q
Informar solo metadatos no saludables.
-r
Informar sobre el estado de salud del grupo en tiempo real dado.
rutas
Informar sobre el estado de salud de los archivos en la ruta dada.
help [ comando ]
Mostrar una breve descripción de uno o todos los comandos.
prealloc [ -u id ] [ -g id ] [ -p id ] [ -m minlen ] [ -s ]
Elimina la preasignación especulativa. Si no se dan las opciones -u, -g o -p, este comando actúa sobre todos los archivos. El comando toma las siguientes opciones:
-u uid
Borrar todas las preasignaciones especulativas para archivos con este id de usuario. Esta opción se puede dar en combinación con las opciones -g y -p.
-g gid
Borrar todas las preasignaciones especulativas para archivos con este id de grupo. Esta opción se puede dar en combinación con las opciones -u y -p.
-p pid
Borrar todas las preasignaciones especulativas para archivos con este id de proyecto. Esta opción se puede dar en combinación con las opciones -u y -g.
-m minlen
Ignorar todos los archivos más pequeños que este tamaño. Se pueden agregar unidades para este argumento.
-s
Esperar a que la eliminación se complete.
print
Mostrar una lista de todos los archivos abiertos.
quit
Salir de xfs_spaceman.
trim ( -a agno | -f | desplazamiento longitud ) [ -m minlen ]
Instruye al dispositivo de almacenamiento subyacente que libere todo el almacenamiento que pueda estar respaldando el espacio libre en el sistema de archivos. El comando toma las siguientes opciones: (Se requiere una de las opciones -a, -f, o el par desplazamiento/longitud.)
-a agno
Recortar extensiones de espacio libre en el grupo de asignación dado. Esta opción es mutuamente excluyente con la opción -f y las opciones desplazamiento/longitud.
-f
Recortar todo el espacio libre en el sistema de archivos. Esta opción es mutuamente excluyente con la opción -a y las opciones desplazamiento/longitud.
opción, longitud
Recortar todo el espacio libre dentro del rango físico definido por el desplazamiento y la longitud de este sistema de archivos. Se pueden agregar unidades a estos argumentos. Esta opción es mutuamente excluyente con las opciones -a y -f.
-m minlen
No recortar extensiones de espacio libre más cortas que esta longitud. Se pueden agregar unidades a este argumento.
