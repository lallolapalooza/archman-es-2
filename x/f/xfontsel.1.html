XFONTSEL(1) Manual de comandos generales XFONTSEL(1)

NOMBRE

xfontsel - selección de nombres de fuentes X11 mediante puntero y clic

SINTAXIS

xfontsel [-opción_toolkit ...] [-help] [-pattern nombre_fuente] [-print]
         [-sample texto] [-sample16 texto16] [-sampleUCS textoUCS]
         [-scaled] [-version]

DESCRIPCIÓN

La aplicación xfontsel proporciona una forma sencilla de mostrar las fuentes conocidas por su servidor X, examinar muestras de cada una y obtener el nombre completo de Descripción Lógica de Fuente X ("XLFD") para una fuente.

Si no se especifica -pattern, todas las fuentes con nombres XLFD de 14 partes serán seleccionables. Para trabajar solo con un subconjunto de las fuentes, especifique -pattern seguido de un nombre de fuente parcial o totalmente calificado; por ejemplo, ``-pattern *medium*'' seleccionará el subconjunto de fuentes que contienen la cadena ``medium'' en algún lugar de su nombre de fuente. Tenga cuidado al escapar los caracteres comodín en su shell.

Si se especifica -print en la línea de comandos, el especificador de fuente seleccionado se escribirá en la salida estándar cuando se active el botón quit. Independientemente de si se especificó -print o no, el especificador de fuente puede convertirse en la selección PRIMARIA (texto) activando el botón select.

La opción -sample especifica el texto de muestra a utilizar para mostrar la fuente seleccionada si la fuente está indexada linealmente, anulando el valor predeterminado.

La opción -sample16 especifica el texto de muestra a utilizar para mostrar la fuente seleccionada si la fuente está codificada en matriz, anulando el valor predeterminado.

La opción -sampleUCS especifica el texto de muestra codificado en la forma UTF-8 a utilizar para mostrar la fuente seleccionada si la fuente tiene un CHARSET_REGISTRY de ISO10646, anulando el valor predeterminado.

La opción -scaled habilita la capacidad de seleccionar fuentes escalables en tamaños arbitrarios de píxeles o puntos.

La opción -help especifica que xfontsel debe imprimir un mensaje de uso y salir.

La opción -version especifica que xfontsel debe imprimir información de versión y salir.

INTERACCIONES

Hacer clic en cualquier botón del puntero en uno de los nombres de campo XLFD mostrará un menú de las posibilidades actualmente conocidas para ese campo. Si se realizaron elecciones previas de otros campos, solo se podrán seleccionar valores para fuentes que coincidan con los campos seleccionados anteriormente; para hacer que otros valores sean seleccionables, debe deseleccionar algunos otros campos eligiendo la entrada ``*'' en ese campo. Los valores no seleccionables pueden omitirse del menú por completo como opción de configuración; consulte el recurso ShowUnselectable, a continuación. Cada vez que se realiza un cambio en el valor de un campo, xfontsel afirmará la propiedad de la selección PRIMARIA_FONT. Otras aplicaciones (ver, por ejemplo, xterm) pueden recuperar la especificación de fuente seleccionada.

Las fuentes escalables regresan del servidor con cero para los campos de tamaño de píxel, tamaño de punto y ancho promedio. Seleccionar un nombre de fuente con un cero en estas posiciones da como resultado un tamaño dependiente de la implementación. Se puede seleccionar cualquier tamaño de píxel o punto para escalar la fuente a un tamaño particular. Se puede seleccionar cualquier ancho promedio para escalar la fuente anamorphicamente (aunque puede encontrar esto desafiante dado el tamaño del menú de ancho promedio).

Hacer clic en el botón izquierdo del puntero en el widget select hará que el nombre de fuente actualmente seleccionado se convierta en la selección de texto PRIMARIA, así como en la selección PRIMARIA_FONT. Esto le permite pegar la cadena en otras aplicaciones. El botón select permanece resaltado para recordarle este hecho, y se desactiva cuando alguna otra aplicación retira la selección PRIMARIA. El widget select es un conmutador; al presionarlo cuando está resaltado, xfontsel liberará la propiedad de la selección y desactivará el widget. Activar el widget select dos veces es la única forma de hacer que xfontsel libere la selección PRIMARIA_FONT.

RECURSOS

La clase de la aplicación es XFontSel. La mayor parte de la interfaz de usuario está configurada en el archivo app-defaults; si este archivo falta, se imprimirá un mensaje de advertencia en la salida estándar y la ventana resultante será casi incomprensible.

La mayoría de las partes significativas de la jerarquía de widgets se documentan en /usr/share/X11/app-defaults/XFontSel,

Recursos específicos de la aplicación:

cursor (clase Cursor)
Especifica el cursor para la ventana de la aplicación.
pattern (clase Pattern)
Especifica el patrón del nombre de la fuente para seleccionar un subconjunto de fuentes disponibles. Equivalente a la opción -pattern. Los patrones más útiles contendrán al menos un delimitador de campo; por ejemplo, ``*-m-*'' para fuentes monoespaciadas.
pixelSizeList (clase PixelSizeList)
Especifica una lista de tamaños de píxeles para agregar al menú de tamaños de píxeles, de modo que las fuentes escalables se puedan seleccionar en esos tamaños de píxeles. La lista de tamaños de píxeles predeterminada contiene 7, 30, 40, 50 y 60.
pointSizeList (clase PointSizeList)
Especifica una lista de tamaños de puntos (en unidades de décimas de punto) para agregar al menú de tamaños de puntos, de modo que las fuentes escalables se puedan seleccionar en esos tamaños de puntos. La lista de tamaños de puntos predeterminada contiene 250, 300, 350 y 400.
printOnQuit (clase PrintOnQuit)
Si es True, el nombre de fuente actualmente seleccionado se imprimirá en la salida estándar cuando se active el botón de salir. Equivalente a la opción -print.
sampleText (clase Text)
El texto de muestra de 1 byte a utilizar para fuentes indexadas linealmente. Cada índice de glifo es un solo byte, con saltos de línea separando las líneas.
sampleText16 (clase Text16)
El texto de muestra de 2 bytes a utilizar para fuentes codificadas en matriz. Cada índice de glifo son dos bytes, con un salto de línea de 1 byte separando las líneas.
scaledFonts (clase ScaledFonts)
Si es True, se habilita la selección de tamaños arbitrarios de píxeles y puntos para fuentes escalables.

Recursos específicos del widget:

showUnselectable (clase ShowUnselectable)
Especifica, para cada menú de campo, si se deben mostrar o no los valores que actualmente no son seleccionables, basándose en las selecciones previas de campo. Si se muestran, los valores no seleccionables se identifican claramente como tales y no se resaltan cuando el puntero se mueve hacia abajo en el menú. El nombre completo de este recurso es fieldN.menu.options.showUnselectable, clase MenuButton.SimpleMenu.Options.ShowUnselectable; donde N se reemplaza con el número de campo (comenzando desde el campo más a la izquierda numerado 0). El valor predeterminado es True para todos excepto para el campo 11 (ancho promedio de caracteres en la fuente) y False para el campo 11. Si nunca desea ver entradas no seleccionables, '*'menu.options.showUnselectable:False'* es algo razonable para especificar en un archivo de recursos.

ERRORES

Patrones suficientemente ambiguos pueden ser malinterpretados y llevar a una cadena de selección inicial que puede no corresponder a lo que el usuario pretendía y que puede hacer que la salida de texto de muestra inicial falle al coincidir con la cadena ofrecida. Seleccionar cualquier valor de campo nuevo corregirá la salida de muestra, aunque posiblemente resulte en que no haya una fuente coincidente.

Debería poder devolver una FUENTE para la selección PRIMARIA, no solo una CADENA.

Cualquier cambio en un valor de campo hará que xfontsel afirme la propiedad de la selección PRIMARIA_FONT. Quizás esto debería ser parametrizable.

Al ejecutarse en una máquina lenta, es posible que el usuario solicite un menú de campo antes de que los nombres de fuente hayan sido

completamente analizado. Se imprime un mensaje de error que indica un menú faltante en stderr, pero, por lo demás, no ocurre nada malo (ni bueno).

El menú de ancho promedio es demasiado grande para ser útil.
