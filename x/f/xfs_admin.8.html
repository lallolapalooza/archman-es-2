xfs_admin(8) Manual del Administrador del Sistema xfs_admin(8)

NOMBRE

xfs_admin - cambiar parámetros de un sistema de archivos XFS

SINOPSIS

xfs_admin [ -eflpu ] [ -O lista_de_características ] [ -c 0|1 ] [ -L etiqueta ] [ -U uuid ] [ -r dispositivo_rt ] dispositivo [ dispositivo_log ]
xfs_admin -V

DESCRIPCIÓN

xfs_admin utiliza el comando xfs_db(8) para modificar varios parámetros de un sistema de archivos.

Los dispositivos que están montados no pueden ser modificados. Los administradores deben desmontar los sistemas de archivos antes de que xfs_admin o xfs_db(8) puedan convertir parámetros. Un número de parámetros de un sistema de archivos montado pueden ser examinados y modificados usando el comando xfs_growfs(8).

El parámetro opcional dispositivo_log especifica el archivo especial de dispositivo donde reside el registro externo del sistema de archivos. Esto solo es necesario para los sistemas de archivos que utilizan un registro externo. Consulte la opción mkfs.xfs -l y refiérase a xfs(5) para una descripción detallada del registro XFS.

OPCIONES

-e
Habilita el soporte de extensiones no escritas en un sistema de archivos que no tiene esto habilitado (para sistemas de archivos heredados, ya no se puede deshabilitar en tiempo de mkfs).
Esta opción solo se aplica al formato V4 obsoleto.
-f
Especifica que la imagen del sistema de archivos a procesar se almacena en un archivo regular en dispositivo (ver la opción mkfs.xfs -d archivo).
-j
Habilita el formato de registro versión 2 (formato de diario que admite búferes de registro más grandes).
Esta opción solo se aplica al formato V4 obsoleto.
-l
Imprime la etiqueta actual del sistema de archivos.
-p
Habilita el soporte de identificador de proyecto de 32 bits (característica PROJID32BIT).
Esta opción solo se aplica al formato V4 obsoleto.
-u
Imprime el UUID (Identificador Único Universal) actual del sistema de archivos.
-c 0|1
Habilita (1) o deshabilita (0) contadores perezosos en el sistema de archivos.
Los contadores perezosos no se pueden deshabilitar en sistemas de archivos de Superbloque Versión 5 (es decir, aquellos con CRC de metadatos habilitados).
En otras palabras, esta opción solo se aplica al formato V4 obsoleto.
Esta operación puede llevar bastante tiempo en sistemas de archivos grandes, ya que todo el sistema de archivos debe ser escaneado cuando se cambia esta opción.
Con los contadores perezosos habilitados, el superbloque no se modifica ni se registra en cada cambio de los contadores de espacio libre e inodos. En cambio, se mantiene suficiente información en otras partes del sistema de archivos para poder mantener los valores de los contadores sin necesidad de mantenerlos en el superbloque. Esto proporciona mejoras significativas de rendimiento en algunas configuraciones y cargas de trabajo intensivas en metadatos.
-L etiqueta
Establece la etiqueta del sistema de archivos a etiqueta. Las etiquetas de sistemas de archivos XFS pueden tener como máximo 12 caracteres; si etiqueta es más larga que 12 caracteres, xfs_admin la truncará e imprimirá un mensaje de advertencia. La etiqueta del sistema de archivos se puede borrar usando el valor especial "--" para etiqueta.
-O característica1=estado,característica2=estado...
Añade o elimina características en un sistema de archivos V5 existente. Las características deben especificarse como una lista separada por comas. estado debe ser 0 para deshabilitar la característica o 1 para habilitarla. Tenga en cuenta, sin embargo, que la mayoría de las características no se pueden deshabilitar.
NOTA: Los administradores deben asegurarse de que el sistema de archivos esté limpio ejecutando xfs_repair -n para inspeccionar el sistema de archivos antes de realizar la actualización. Si se encuentra corrupción, se deben seguir los procedimientos de recuperación (por ejemplo, reformatear seguido de restauración desde una copia de seguridad; o ejecutar xfs_repair sin la opción -n) para limpiar el sistema de archivos.
Las características soportadas son las siguientes:
inobtcount
Mantiene un recuento del número de bloques en cada árbol B de inodos en la AGI. Esto reduce el tiempo de montaje al acelerar los cálculos de reserva de espacio de metadatos. El sistema de archivos no se puede degradar después de habilitar esta característica. Una vez habilitado, el sistema de archivos no será escribible por kernels más antiguos. Esta característica se añadió en Linux 5.10.
bigtime
Actualiza un sistema de archivos para soportar marcas de tiempo más grandes hasta el año 2486. El sistema de archivos no se puede degradar después de habilitar esta característica. Una vez habilitado, el sistema de archivos no será montable por kernels más antiguos. Esta característica se añadió en Linux 5.10.
nrext64
Actualiza un sistema de archivos para soportar contadores de extensiones grandes por inodo. El número máximo de extensiones de la bifurcación de datos será 2^48 - 1, mientras que el número máximo de extensiones de la bifurcación de atributos será 2^32 - 1. El sistema de archivos no se puede degradar después de habilitar esta característica. Una vez habilitado, el sistema de archivos no será montable por kernels más antiguos. Esta característica se añadió en Linux 5.19.
exchange
Actualiza un sistema de archivos para soportar intercambios atómicos de contenido de archivos a través del ioctl XFS_IOC_EXCHANGE_RANGE, y para soportar reparaciones en línea de directorios, atributos extendidos, enlaces simbólicos y metadatos de espacio libre en tiempo real. El sistema de archivos no se puede degradar después de habilitar esta característica. Una vez habilitado, el sistema de archivos no será montable por kernels más antiguos.
-U uuid
Establece el UUID del sistema de archivos a uuid. Un UUID de ejemplo se ve así: "c1b9d5a2-f162-11cf-9ece-0020afc76f16". El uuid también puede ser nil, que establecerá el UUID del sistema de archivos al UUID nulo. El uuid también puede ser generate, que generará un nuevo UUID para el sistema de archivos. Tenga en cuenta que en los sistemas de archivos habilitados para CRC, esto establecerá una bandera incompatible de modo que los kernels más antiguos no podrán montar el sistema de archivos. Para eliminar esta bandera incompatible, use restore, que restaurará el UUID original y eliminará la bandera de característica incompatible según sea necesario.
-r dispositivo_rt
Especifica el archivo especial de dispositivo donde reside la sección de tiempo real del sistema de archivos. Solo para aquellos sistemas de archivos que utilizan una sección de tiempo real.
-V
Imprime el número de versión y sale.

La entrada del manual mount(8) describe cómo montar un sistema de archivos usando su etiqueta o UUID, en lugar de su nombre de dispositivo especial de bloque.

VER TAMBIÉN

mkfs.xfs(8), mount(8), xfs_db(8), xfs_growfs(8), xfs_repair(8), xfs(5).
