xfs_copy(8) Manual del Administrador del Sistema xfs_copy(8)

NOMBRE

xfs_copy - copia el contenido de un sistema de archivos XFS

SINOPSIS

xfs_copy [ -bd ] [ -L log ] fuente objetivo1 [ objetivo2 ... ]
xfs_copy -V

DESCRIPCIÓN

xfs_copy copia un sistema de archivos XFS a uno o más objetivos en paralelo (ver xfs(5)). El primer argumento (fuente) debe ser la ruta del dispositivo o archivo que contiene el sistema de archivos XFS. Los argumentos restantes especifican uno o más dispositivos o nombres de archivo objetivo. Si las rutas especifican dispositivos, se crea una copia del sistema de archivos XFS de origen en cada dispositivo. El objetivo también puede ser el nombre de un archivo regular, en cuyo caso se crea una imagen del sistema de archivos XFS de origen en ese archivo. Si el archivo no existe, xfs_copy crea el archivo. La longitud del archivo resultante es igual al tamaño del sistema de archivos de origen. Sin embargo, si el archivo se crea en un sistema de archivos XFS, el archivo consume aproximadamente la cantidad de espacio realmente utilizada en el sistema de archivos de origen por el sistema de archivos y el registro XFS. El ahorro de espacio se debe a que xfs_copy omite los bloques libres en lugar de copiarlos, y el sistema de archivos XFS admite archivos dispersos de manera eficiente.

xfs_copy solo debe usarse para copiar sistemas de archivos no montados, sistemas de archivos montados en solo lectura o sistemas de archivos congelados (ver xfs_freeze(8)). De lo contrario, los sistemas de archivos generados serían inconsistentes o corruptos.

xfs_copy no altera el sistema de archivos de origen de ninguna manera. Cada nuevo sistema de archivos (objetivo) es idéntico al sistema de archivos original, excepto que cada nuevo sistema de archivos tiene un nuevo identificador de sistema de archivos único (UUID). Por lo tanto, si tanto el sistema de archivos antiguo como el nuevo se usarán como sistemas de archivos distintos e independientes, se debe usar xfs_copy o xfsdump(8)/xfsrestore(8) para generar los nuevos sistemas de archivos en lugar de dd(1) u otros programas que realizan copias de disco bloque a bloque.

xfs_copy utiliza escrituras síncronas para garantizar que se detecten los errores de escritura.

xfs_copy utiliza pthreads(7) para realizar escrituras paralelas simultáneas. xfs_copy crea un hilo adicional por cada objetivo que se va a escribir. Todos los hilos mueren si xfs_copy termina o se aborta.

OPCIONES

-d
Crea un sistema de archivos duplicado (clon verdadero). Esto solo debe hacerse si el nuevo sistema de archivos se utilizará como reemplazo del sistema de archivos original (como en el caso de reemplazo de disco).
-b
La opción con búfer puede usarse para asegurar que no se intenten E/S directas en ninguno de los archivos objetivo. Esto es útil cuando el sistema de archivos que contiene el archivo objetivo no admite E/S directas.
-L log
Especifica la ubicación del log si la ubicación predeterminada de /var/tmp/xfs_copy.log.XXXXXX no es deseada.
-V
Imprime el número de versión y sale.

DIAGNÓSTICOS

xfs_copy informa de los errores tanto a stderr como de forma más detallada a un archivo de registro generado cuyo nombre tiene el formato /var/tmp/xfs_copy.log.XXXXXX o a un archivo de registro especificado por la opción -L. Si xfs_copy detecta un error de escritura en un objetivo, la copia de ese objetivo se aborta y se emite un mensaje de error a stderr y al archivo de registro, pero las demás copias continúan. Cuando xfs_copy termina, todos los objetivos abortados se informan tanto a stderr como al archivo de registro.

Si todos los objetivos abortan o si hay un error al leer el sistema de archivos de origen, xfs_copy se aborta inmediatamente.

xfs_copy devuelve un código de salida de 0 si todos los objetivos se copian con éxito y un código de salida de 1 si falla algún objetivo.

NOTAS

Al mover sistemas de archivos de un disco a otro, si el sistema de archivos original es significativamente más pequeño que el nuevo sistema de archivos y se va a hacer más grande, recomendamos que se utilice mkfs.xfs(8) y xfsdump(8)/xfsrestore(8) en lugar de usar xfs_copy y xfs_growfs(8). La disposición del sistema de archivos resultante de usar xfs_copy/xfs_growfs es casi siempre peor que el resultado de usar mkfs.xfs/xfsdump/xfsrestore pero en el caso de sistemas de archivos pequeños, las diferencias pueden tener un impacto significativo en el rendimiento. Esto se debe a la forma en que funciona xfs_growfs(8), y no a ninguna deficiencia en el propio xfs_copy.

ADVERTENCIAS

xfs_copy no copia sistemas de archivos XFS que tengan una sección de tiempo real o sistemas de archivos XFS con registros externos. En ambos casos, xfs_copy se aborta con un mensaje de error.

VER TAMBIÉN

mkfs.xfs(8), xfsdump(8), xfsrestore(8), xfs_freeze(8), xfs_growfs(8), xfs(5).
