xfsinvutil(8) Manual del Administrador del Sistema xfsinvutil(8)

NOMBRE

xfsinvutil - utilidad para la comprobación y poda de la base de datos de inventario de xfsdump

SINOPSIS

xfsinvutil [-F|-i] [-m etiqueta_medios] -M punto_montaje mm/dd/aaaa
xfsinvutil [-F|-i] [-m etiqueta_medios] -u UUID mm/dd/aaaa
xfsinvutil [-F] -s ID_SESION
xfsinvutil -i
xfsinvutil -C

DESCRIPCIÓN

xfsdump mantiene un inventario de volcado en línea en /var/lib/xfsdump/inventory. La opción -I de xfsdump muestra el contenido del inventario de forma jerárquica. Los niveles de la jerarquía son: sistema de archivos, sesión de volcado, flujo y archivo de medios.

xfsinvutil es una utilidad para comprobar la coherencia de esta base de datos de inventario, para eliminar entradas de sesiones de volcado que ya no sean relevantes y para navegar por el contenido del inventario.

Las siguientes opciones de línea de comandos están disponibles:

-F
No preguntar al operador. Cuando xfsinvutil encuentra una sesión de volcado coincidente, normalmente preguntará al operador permiso para eliminar la entrada. Con esta opción, la eliminación se realiza sin preguntas.
-i
Modo interactivo. Hace que xfsinvutil se ejecute en un modo que permitirá al operador navegar y modificar el contenido del inventario. Por favor, consulte la sección Modo Interactivo a continuación para más información.
-M punto_montaje mm/dd/aaaa
Poda sesiones de volcado identificadas por el punto de montaje dado que fueron creadas antes de la fecha especificada. Opcionalmente se puede especificar -m para limitar aún más las sesiones de volcado coincidentes por etiqueta de medios. xfsinvutil preguntará al operador antes de podar una sesión de volcado a menos que se den las opciones -F o -i.
-u UUID mm/dd/aaaa
Al igual que -M, excepto que el sistema de archivos coincidente se especifica utilizando su identificador universalmente único (UUID) en lugar de su punto de montaje.
-m etiqueta_medios
Si se especifica, solo las sesiones con al menos un archivo de medios cuya etiqueta coincida con este valor serán elegibles para la poda. Esta restricción se añade a las impuestas por la fecha y las opciones -M o -u. Esta opción permite podar todas las referencias del inventario a medios que puedan haber sido sobrescritos o perdidos. Tenga en cuenta que esta opción no se aplica a las sesiones sin archivos de medios.
-s ID_SESION
Poda la sesión de volcado identificada por el ID de sesión dado. xfsinvutil preguntará al operador antes de podar una sesión de volcado a menos que se dé la opción -F.
-C
Con esta opción, xfsinvutil realiza comprobaciones de coherencia para todas las entradas de la base de datos del inventario. Corrige cualquier problema encontrado. Si no se encuentran entradas coherentes, se elimina el archivo de base de datos del inventario correspondiente.

Modo Interactivo

Cuando se ejecuta con -i, xfsinvutil presentará al operador una representación jerárquica del inventario de xfsdump. En este modo, el operador puede usar las teclas de flecha (o las teclas h j k l) para navegar por el inventario y también utilizar las siguientes teclas y funcionalidades:

+
Expande una rama del árbol.
-
Colapsa una rama del árbol.
*
Expande completamente una rama del árbol.
%
Colapsa completamente una rama del árbol.
h
Mueve la selección a la entrada padre.
l
Mueve la selección a la entrada hija.
j
Mueve la selección a la siguiente entrada.
k
Mueve la selección a la entrada anterior.
d
Marca el registro actual, y todos los sub-registros, para ser eliminados.
u
Borra la marca de eliminación del registro actual y de todos los registros padre.
i
Importa otro inventario de xfsdump.
?
Muestra la ventana de ayuda.
x
Confirma cualquier cambio realizado en el inventario y sale del programa.
q
Sale del programa sin confirmar ningún cambio en el inventario.

Se pueden importar inventarios de otros hosts para crear un inventario común más grande. Se recomienda que el contenido de /var/lib/xfsdump/inventory en el host remoto se copie a un directorio local temporal antes de ejecutar xfsinvutil. Cuando xfsinvutil se ejecuta en modo interactivo y el operador presiona i, se le pedirá la ruta al inventario que se va a importar. xfsinvutil agregará entonces el contenido del inventario importado a la ventana principal, y todas las entradas se marcarán como importadas. El operador puede entonces eliminar cualquiera de estas entradas que no se vayan a importar. Cuando el operador confirma los cambios, xfsinvutil importará todas las entradas que no estuvieran marcadas para eliminar. Las entradas eliminadas no se borran realmente del inventario importado original.

NOTAS

Inventario

Cada sesión de volcado actualiza una base de datos de inventario en /var/lib/xfsdump/inventory. xfsdump utiliza el inventario para determinar la base de los volcados incrementales y reanudados.

Esta base de datos se puede mostrar invocando xfsdump con la opción -I. La visualización utiliza sangría con tabulaciones para presentar el inventario jerárquicamente. El primer nivel es el sistema de archivos. El segundo nivel es la sesión. El tercer nivel es el flujo de medios (actualmente solo se admite un flujo). El cuarto nivel enumera los archivos de medios que componen secuencialmente el flujo.
