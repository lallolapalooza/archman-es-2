XFREERDP(1) xfreerdp XFREERDP(1)

.SH "NOMBRE" xfreerdp - Cliente X11 de FreeRDP

.SH "SINOPSIS"

.PP xfreerdp [archivo] [opciones] [/v:servidor[:puerto]]

.SH "DESCRIPCIÓN"

.PP xfreerdp es un cliente de Protocolo de Escritorio Remoto (RDP) para X11 que forma parte del proyecto FreeRDP. Un servidor RDP está incorporado en muchas ediciones de Windows. Servidores alternativos incluyen xrdp y VRDP (VirtualBox).

.RE .PP /cert:[denegar,ignorar,nombre:nombre,tofu,huella:hash:hash en hexadecimal[,huella:hash:otro hash]]

Opciones de aceptación de certificado. ¡Úselo con cuidado! * denegar ... Abortar automáticamente la conexión si el certificado no coincide, sin interacción del usuario. * ignorar ... Ignorar las comprobaciones del certificado por completo (anula todas las demás opciones) * nombre ... Usar el <nombre> alternativo en lugar del sujeto del certificado para comparar con los certificados almacenados localmente * tofu ... Aceptar el certificado incondicionalmente en la primera conexión y denegar en conexiones subsiguientes si el certificado no coincide * huellas ... Una lista de hashes de certificados que se aceptan incondicionalmente para una conexión

.RE .PP /cert-deny

.PP variable de entorno wlog

xfreerdp usa wLog como su instalación de registro, puedes consultar la página de manual correspondiente (wlog(7)) para obtener más información. Los argumentos pasados a través de /log-level o /log-filters tienen prioridad sobre las variables de entorno.

.SH "EJEMPLOS"

.PP xfreerdp connection.rdp /p:Pwd123! /f

Conectar en modo de pantalla completa usando una configuración almacenada connection.rdp y la contraseña Pwd123!

.RE .PP xfreerdp /u:USUARIO /size:50%h /v:rdp.contoso.com

Conectar al host rdp.contoso.com con el usuario USUARIO y un tamaño del 50 por ciento de la altura. Si se establece el ancho (w) en lugar de la altura (h) como /size:50%w. Se usa el 50 por ciento del ancho.

.RE .PP xfreerdp /u:CONTOSO\\JohnDoe /p:Pwd123! /v:rdp.contoso.com

Conectar al host rdp.contoso.com con el usuario CONTOSO\\JohnDoe y la contraseña Pwd123!

.RE .PP xfreerdp /u:JohnDoe /p:Pwd123! /w:1366 /h:768 /v:192.168.1.100:4489

Conectar al host 192.168.1.100 en el puerto 4489 con el usuario JohnDoe, contraseña Pwd123!. El ancho de pantalla se establece en 1366 y la altura en 768

.RE .PP xfreerdp /u:JohnDoe /p:Pwd123! /vmconnect:C824F53E-95D2-46C6-9A18-23A5BB403532 /v:192.168.1.100

Establecer una conexión al host 192.168.1.100 con el usuario JohnDoe, contraseña Pwd123! y conectar a la consola Hyper-V (usar puerto 2179, deshabilitar negociación) con VMID C824F53E-95D2-46C6-9A18-23A5BB403532
