xfmpc(1) Comandos de usuario xfmpc(1)

NOMBRE

xfmpc - cliente gráfico GTK+ para MPD enfocado en bajo consumo.

DESCRIPCIÓN

Xfmpc es un cliente de MPD (Music Player Daemon), enfocado en bajo consumo para el entorno de escritorio Xfce.

ENTORNO

MPD_HOST - Nombre del host del servidor.
MPD_PORT - Puerto del servidor.

USO

Para conectarse a una máquina remota, establezca las variables de entorno MPD_HOST y MPD_PORT. Consulte mpc(1) para más información.

Atajos de teclado por defecto
Ir atrás - Ctrl+B
Reproducir/Pausar - Ctrl+P
Detener - Ctrl+S
Ir adelante - Ctrl+F
Volumen - Ctrl+V
Salir - Ctrl+Q

Entrada de lista de reproducción y filtro
Activar canción seleccionada - Enter
Borrar entrada y volver a centrar en la canción actual - Escape

Navegador de base de datos
Ir al directorio padre - BackSpace
Añadir una selección múltiple a la lista de reproducción - Enter
