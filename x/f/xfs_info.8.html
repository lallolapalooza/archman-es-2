xfs_info(8) Manual del Administrador del Sistema xfs_info(8)

NOMBRE

xfs_info - muestra información de geometría del sistema de archivos XFS

SINOPSIS

xfs_info [ -t mtab ] [ punto-de-montaje | dispositivo-de-bloques | imagen-de-archivo ]
xfs_info -V

DESCRIPCIÓN

xfs_info muestra información de geometría sobre un sistema de archivos XFS existente. El argumento punto-de-montaje es la ruta de un directorio donde el sistema de archivos está montado. El dispositivo-de-bloques o imagen-de-archivo contienen un sistema de archivos XFS sin procesar. El contenido existente del sistema de archivos no se ve alterado.

OPCIONES

-t
Especifica un archivo de tabla de montaje alternativo (el predeterminado es /proc/mounts si existe, de lo contrario /etc/mtab). Esto se usa al trabajar con sistemas de archivos montados sin escribir en el archivo /etc/mtab; consulte mount(8) para más detalles. Esta opción no tiene efecto con los parámetros de dispositivo-de-bloques o imagen-de-archivo.
-V
Imprime el número de versión y sale. El argumento punto-de-montaje no es necesario con -V.

EJEMPLOS

Comprensión de la salida de xfs_info.

Supongamos que se tiene la siguiente salida de "xfs_info /dev/sda":

meta-data=/dev/pmem0             isize=512    agcount=8, agsize=5974144 blks
         =                       sectsz=512   attr=2, projid32bit=1
         =                       crc=1        finobt=1, sparse=1, rmapbt=1
         =                       reflink=1
data     =                       bsize=4096   blocks=47793152, imaxpct=25
         =                       sunit=32     swidth=128 blks
naming   =version 2              bsize=4096   ascii-ci=0, ftype=1
log      =internal log           bsize=4096   blocks=23336, version=2
         =                       sectsz=512   sunit=0 blks, lazy-count=1
realtime =none                   extsz=4096   blocks=0, rtextents=0

Aquí, la sección de datos de la salida indica "bsize=4096", lo que significa que el tamaño del bloque de datos para este sistema de archivos es de 4096 bytes. Esta sección también muestra "sunit=32 swidth=128 blks", lo que significa que la unidad de stripe es de 32*4096 bytes = 128 kibibytes y el ancho de stripe es de 128*4096 bytes = 512 kibibytes. Una única stripe de este sistema de archivos consta, por lo tanto, de cuatro unidades de stripe (128 bloques / 32 bloques por unidad).

VER TAMBIÉN

mkfs.xfs(8), md(4), lvm(8), mount(8).
