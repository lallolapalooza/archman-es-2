Nombre

xfce4-panel-profiles - Una aplicación sencilla para gestionar diseños del panel de Xfce

SINOPSIS

xfce4-panel-profiles [ COMANDO ] nombre_archivo

DESCRIPCIÓN

xfce4-panel-profiles es una aplicación sencilla para gestionar los diseños del panel de Xfce. Permite aplicar, guardar, eliminar, exportar e importar un diseño de panel como un perfil. Puede, por ejemplo, hacer una copia de seguridad del diseño actual del panel o importar un perfil de panel exportado previamente.

xfce4-panel-profiles es una aplicación gráfica, pero también se puede usar desde la línea de comandos con funciones limitadas.

COMANDOS

cargar nombre_archivo
Carga y aplica un perfil de panel exportado previamente como nombre_archivo.
guardar nombre_archivo
Guarda el diseño actual del panel como nombre_archivo. El nombre del perfil debe terminar en tar.bz2 para mayor claridad.

ARCHIVOS

~/.local/share/xfce4-panel-profiles
Directorio de almacenamiento de perfiles personalizados del panel del usuario.
/usr/share/xfce4-panel-profiles/layouts
Directorio de almacenamiento de perfiles del panel proporcionados por el sistema.

EJEMPLOS

xfce4-panel-profiles guardar copia_seguridad.tar.bz2
Realiza una copia de seguridad del diseño actual del panel.
xfce4-panel-profiles cargar copia_seguridad.tar.bz2
Carga y aplica el diseño del panel exportado previamente.
