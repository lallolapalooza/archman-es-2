NOMBRE

xfce4-dict - página del manual para xfce4-dict 0.8.7git-6f10536 (Xfce 4.18)

DESCRIPCIÓN

Uso:

xfce4-dict [OPCIÓN?] [TEXTO]

Opciones de ayuda:

-h, --help
Mostrar opciones de ayuda
--help-all
Mostrar todas las opciones de ayuda
--help-gtk
Mostrar opciones de GTK+

Opciones de aplicación:

-d, --dict
Buscar el texto dado usando un servidor Dict (RFC 2229)
-w, --web
Buscar el texto dado usando un motor de búsqueda web
-s, --spell
Comprobar el texto dado con un corrector ortográfico
-t, --text-field
Capturar el foco en el campo de texto del panel
-i, --ignore-plugin
Iniciar la aplicación independiente incluso si el plugin del panel está cargado
-c, --clipboard
Captura el contenido de la selección PRIMARIA y lo utiliza como texto de búsqueda
-v, --verbose
Ser detallado
-V, --version
Mostrar información de la versión
--display=PANTALLA
Pantalla X a utilizar
