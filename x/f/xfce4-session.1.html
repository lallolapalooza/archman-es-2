NOMBRE

xfce4-session - Inicia el Entorno de Escritorio Xfce

SINOPSIS

xfce4-session

DESCRIPCIÓN

Esta página del manual documenta brevemente el comando xfce4-session.

El programa xfce4-session inicia el Entorno de Escritorio Xfce y típicamente es ejecutado por su gestor de inicio de sesión (por ejemplo, xdm, gdm, kdm, wdm o desde sus scripts de inicio de X). Cargará su última sesión o una sesión predeterminada que incluya los programas estándar de Xfce si no hay una sesión guardada disponible.

xfce4-session es un gestor de sesiones X11R6 estándar que puede gestionar cualquier programa compatible con SM de X11R6, incluyendo programas de GNOME y KDE.

xfce4-session utiliza el contenido del directorio ~/.cache/sessions/ para iniciar sesiones previamente guardadas.

OPCIONES

xfce4-session toma las siguientes opciones de línea de comandos:

--disable-tcp
Deshabilita la vinculación a puertos TCP en la capa ICE. Esto no es posible en todas las plataformas. Si usa esta opción en una plataforma que no la soporta, xfce4-session imprimirá un mensaje de advertencia e ignorará la configuración.
--help
Imprime una pantalla de ayuda y sale.
--version
Muestra la información de la versión y sale.

ENTORNO

El comportamiento de xfce4-session se ve afectado por las siguientes variables de entorno.

XDG_CONFIG_HOME
Especifica la raíz para todos los archivos de configuración específicos del usuario. Si esta variable de entorno no está definida, por defecto es ~/.config/
XDG_CONFIG_DIRS
Conjunto de directorios base ordenados por preferencia en relación con los cuales se deben buscar los archivos de configuración además del directorio base $XDG_CONFIG_HOME. Los directorios deben estar separados por dos puntos.
XDG_CACHE_HOME
Especifica la raíz para todos los datos de caché específicos del usuario. Si esta variable de entorno no está definida, por defecto es ~/.cache/
XFSM_VERBOSE
Cuando está definida, esta variable de entorno habilita que se guarden mensajes de depuración en ~/.xfce4-session.verbose-log El archivo de registro de la última sesión ejecutada con esta variable de entorno definida se conserva en ~/.xfce4-session.verbose-log.last Estos mensajes de depuración son útiles para la resolución de problemas y el desarrollo.

ARCHIVOS

xfce4-session lee su configuración de Xfconf. xfce4-session almacena sus datos de sesión en $XDG_CACHE_HOME/sessions/.
