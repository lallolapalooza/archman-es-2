XRANDR(1) Manual de comandos generales XRANDR(1)

NOMBRE

xrandr - interfaz de línea de comandos primitiva para la extensión RandR

SINOPSIS

xrandr [--help] [--display display] [-q] [-v] [--verbose] [--dryrun] [--screen snum] [--q1] [--q12] [--current] [--noprimary] [--panning widthxheight[+x+y[/track_widthxtrack_height+track_x+track_y[/border_left/border_top/border_right/border_bottom]]]] [--scale x[xy]] [--scale-from wxh] [--transform a,b,c,d,e,f,g,h,i] [--primary] [--prop] [--fb widthxheight] [--fbmm widthxheight] [--dpi dpi] [--dpi from-output] [--newmode name mode] [--rmmode name] [--addmode output name] [--delmode output name] [--output output] [--auto] [--mode mode] [--preferred] [--pos xxy] [--rate rate] [--reflect reflection] [--rotate orientation] [--left-of output] [--right-of output] [--above output] [--below output] [--same-as output] [--set property value] [--off] [--crtc crtc] [--gamma red[:green:blue]] [--brightness brightness] [-o orientation] [-s size] [-r rate] [-x] [-y] [--listproviders] [--setprovideroutputsource provider source] [--setprovideroffloadsink provider sink] [--listmonitors] [--listactivemonitors] [--setmonitor name geometry outputs] [--delmonitor name]

DESCRIPCIÓN

Xrandr se utiliza para establecer el tamaño, la orientación y/o la reflexión de las salidas para una pantalla. También puede establecer el tamaño de la pantalla.

Si se invoca sin ninguna opción, volcará el estado de las salidas, mostrando los modos existentes para cada una de ellas, con un '+' después de los modos preferidos y un '*' después del modo actual.

Hay algunas opciones globales. Otras opciones modifican la última salida especificada en los parámetros anteriores de la línea de comandos. Se pueden modificar varias salidas al mismo tiempo pasando múltiples opciones --output seguidas inmediatamente por sus opciones modificadoras correspondientes.

--help
Imprime un resumen del uso y sale.
-v, --version
Imprime la versión de RandR reportada por el servidor X y sale.
--verbose
Hace que xrandr sea más verboso. Cuando se usa con -q (o sin otras opciones), xrandr mostrará más información sobre el estado del servidor. Tenga en cuenta que la información de gamma y brillo son solo aproximaciones del perfil de color completo almacenado en el servidor. Cuando se usa junto con opciones que reconfiguran el sistema, se informará del progreso mientras se ejecutan los cambios de configuración.
-q, --query
Cuando esta opción está presente, o cuando no se solicitan cambios de configuración, xrandr mostrará el estado actual del sistema.
--dryrun
Realiza todas las acciones especificadas excepto que no se realiza ningún cambio.
--nograb
Aplica las modificaciones sin capturar la pantalla. Evita bloquear otras aplicaciones durante la actualización, pero también puede hacer que algunas aplicaciones que detectan el redimensionamiento de la pantalla reciban valores antiguos.
-d, --display name
Esta opción selecciona la pantalla X a usar. Tenga en cuenta que esto se refiere a la abstracción de pantalla X, no al monitor (o salida).
--screen snum
Esta opción selecciona qué pantalla manipular. Tenga en cuenta que esto se refiere a la abstracción de pantalla X, no al monitor (o salida).
--q1
Fuerza el uso del protocolo RandR versión 1.1, incluso si una versión superior está disponible.
--q12
Fuerza el uso del protocolo RandR versión 1.2, incluso si la pantalla no lo reporta como soportado o una versión superior está disponible.

Opciones de RandR versión 1.5

Las opciones para RandR 1.5 se utilizan como un superconjunto de las opciones para RandR 1.4.

--listmonitors
Reporta información sobre todos los monitores definidos.
--listactivemonitors
Reporta información sobre los monitores actualmente activos.
--setmonitor name geometry outputs
Define un nuevo monitor con la geometría dada y asociado a las salidas dadas. La lista de salidas es la palabra clave none o una lista de salidas separadas por comas. La geometría es la palabra clave auto, en cuyo caso el monitor seguirá automáticamente la geometría de las salidas asociadas, o una especificación manual en la forma w/mmwxh/mmh+x+y donde w, h, x, y están en píxeles y mmw, mmh son las dimensiones físicas del monitor.
--delmonitor name
Elimina el monitor definido por el usuario dado.

Opciones de RandR versión 1.4

Las opciones para RandR 1.4 se utilizan como un superconjunto de las opciones para RandR 1.3.

--listproviders
Reporta información sobre los proveedores disponibles.
--setprovideroutputsource provider source
Establece source como la fuente de las imágenes de salida de pantalla para provider. Esto solo es posible si source y provider tienen las capacidades de Source Output y Sink Output, respectivamente. Si source es 0x0, entonces provider se desconecta de su fuente de salida actual.
--setprovideroffloadsink provider sink
Establece provider como un dispositivo de descarga de renderizado para sink. Esto solo es posible si provider y sink tienen las capacidades de Source Offload y Sink Offload, respectivamente. Si sink es 0x0, entonces provider se desconecta de su sumidero de descarga de renderizado actual.

Opciones de RandR versión 1.3

Las opciones para RandR 1.3 se utilizan como un superconjunto de las opciones para RandR 1.2.

--current
Devuelve la configuración de pantalla actual, sin consultar cambios de hardware.
--noprimary
No definir una salida primaria.

Opciones por salida

--panning widthxheight[+x+y[/track_widthxtrack_height+track_x+track_y[/border_left/border_top/border_right/border_bottom]]]
Esta opción establece los parámetros de panning. Tan pronto como se activa el panning, la posición del CRTC puede cambiar con cada movimiento del puntero. Los primeros cuatro parámetros especifican el área total de panning, los siguientes cuatro el área de seguimiento del puntero (que por defecto es la misma área). Los últimos cuatro parámetros especifican el borde y son 0 por defecto. Un ancho o alto establecido a cero deshabilita el panning en el eje correspondiente. Normalmente, tendrás que establecer el tamaño de la pantalla con --fb simultáneamente.
--transform a,b,c,d,e,f,g,h,i
Especifica una matriz de transformación para aplicar en la salida. Se selecciona automáticamente un filtro bilineal a menos que también se especifique el parámetro --filter. La forma matemática corresponde a:

a b c
d e f
g h i
La transformación se basa en coordenadas homogéneas. La matriz multiplicada por el vector de coordenadas de un píxel de la salida da como resultado el vector de coordenadas transformado de un píxel en el búfer gráfico. Más precisamente, el vector (x y) del píxel de salida se extiende a 3 valores (x y w), con 1 como la coordenada w y multiplicado por la matriz. Las coordenadas finales del dispositivo del píxel se calculan entonces con la llamada división homogénea por la coordenada w transformada. En otras palabras, las coordenadas del dispositivo (x' y') del píxel transformado son:
x' = (ax + by + c) / w' y
y' = (dx + ey + f) / w' ,
con w' = (gx + hy + i) .
Típicamente, a y e corresponden al escalado en los ejes X e Y, c y f corresponden a la traslación en esos ejes, y g, h, e i son respectivamente 0, 0 y 1. La matriz también puede ser utilizada para expresar transformaciones más complejas como la corrección de distorsión trapezoidal o la rotación. Para una rotación de un ángulo T, se puede usar la siguiente fórmula:
cos T -sen T 0
sen T cos T 0
0 0 1
Como argumento especial, en lugar de pasar una matriz, se puede pasar la cadena none, en cuyo caso se utilizan los valores predeterminados (una matriz identidad sin filtro).
--filter modofiltrado
Elige el método de filtro de escalado que se aplicará cuando la pantalla se escale o se transforme. Puede ser 'bilineal' o 'nearest'.
--scale x[xy]
Cambia las dimensiones de la imagen de salida. Si se omite el valor y, se usará el valor x para ambas dimensiones. Los valores mayores que 1 resultan en una pantalla comprimida (dimensión de pantalla mayor que la dimensión del modo de salida), y los valores menores que 1 resultan en un zoom en la salida. Esta opción es en realidad una versión abreviada de la opción --transform.
--scale-from wxh
Especifica el tamaño en píxeles del área del framebuffer que se mostrará en esta salida. Esta opción es en realidad una versión abreviada de la opción --transform.
--primary
Establece la salida como primaria. Se clasificará primero en las solicitudes de geometría de Xinerama y RANDR.

Opciones de RandR versión 1.2

Estas opciones solo están disponibles para servidores X que soporten la versión 1.2 o posterior de RandR.

--prop, --properties
Esta opción hace que xrandr muestre el contenido de las propiedades para cada salida. --verbose también habilita --prop.
--fb anchuraxaltura
Reconfigura la pantalla al tamaño especificado. Todos los monitores configurados deben caber dentro de este tamaño. Cuando esta opción no se proporciona, xrandr calcula el tamaño de pantalla más pequeño que albergará el conjunto de salidas configuradas; esta opción proporciona una forma de anular ese comportamiento.
--fbmm anchuraxaltura
Establece el valor reportado como tamaño físico de la pantalla X en su conjunto (unión de todos los monitores configurados). En configuraciones con múltiples monitores con diferentes DPI, el valor no tiene significado físico, pero puede ser utilizado por algunos clientes heredados que no soportan RandR versión 1.2 para calcular un escalado de fuente de referencia. Normalmente, xrandr restablece los valores de tamaño físico reportados para mantener los DPI constantes. Esto anula ese cálculo. El valor DPI predeterminado es 96.
--dpi dpi
--dpi desde-salida
Esto también establece el valor reportado como tamaño físico de la pantalla X en su conjunto (unión de todos los monitores configurados). En configuraciones con múltiples monitores con diferentes DPI, el valor no tiene significado físico, pero puede ser utilizado por algunos clientes heredados que no soportan RandR versión 1.2 para calcular un escalado de fuente de referencia. Esta opción utiliza el valor DPI especificado, o el DPI de la salida dada, para calcular un tamaño físico apropiado utilizando el tamaño de píxel que se establecerá. Los valores típicos son el predeterminado (96 DPI), los DPI del único monitor en configuraciones de un solo monitor, o los DPI del monitor principal en configuraciones de múltiples monitores.
--newmode nombre modo
Se pueden añadir nuevos modos de línea al servidor y luego asociarlos con salidas. Esta opción hace lo primero. El modo se especifica usando la sintaxis ModeLine para xorg.conf: clock hdisp hsyncstart hsyncend htotal vdisp vsyncstart vsyncend vtotal flags. flags puede ser cero o más de +HSync, -HSync, +VSync, -VSync, Interlace, DoubleScan, CSync, +CSync, -CSync. Varias herramientas permiten calcular la línea de modo usual a partir de una altura, anchura y tasa de refresco; por ejemplo, puedes usar cvt.
--rmmode nombre
Esto elimina un modo del servidor si no se está utilizando.
--addmode salida nombre
Añade un modo al conjunto de modos válidos para una salida.
--delmode salida nombre
Elimina un modo del conjunto de modos válidos para una salida.

Opciones por salida

--output salida
Selecciona una salida para reconfigurar. Usa el nombre de la salida o su XID.
--auto
Para salidas conectadas pero deshabilitadas, esto las habilitará usando su primer modo preferido (o algo cercano a 96dpi si no tienen modo preferido). Para salidas desconectadas pero habilitadas, las deshabilitará.
--mode modo
Esto selecciona un modo. Usa el nombre o el XID para modo
--preferred
Esto selecciona el mismo modo que --auto, pero no habilita ni deshabilita automáticamente la salida.
--pos xxy
Posiciona la salida dentro de la pantalla usando coordenadas de píxeles. En caso de que se aplique reflexión o rotación, la traslación se aplica después de los efectos.
--rate tasa
Esto marca una preferencia por tasas de refresco cercanas al valor especificado; cuando varios modos tienen el mismo nombre, esto seleccionará aquel con la tasa de refresco más cercana.
--reflect reflexion
La reflexión puede ser una de 'normal', 'x', 'y' o 'xy'. Esto causa que el contenido de la salida se refleje a través de los ejes especificados.
--rotate rotacion
La rotación puede ser una de 'normal', 'left', 'right' o 'inverted'. Esto causa que el contenido de la salida se rote en la dirección especificada. 'right' especifica una rotación en sentido horario de la imagen y 'left' especifica una rotación en sentido antihorario.
--left-of, --right-of, --above, --below, --same-as otra-salida
Usa una de estas opciones para posicionar la salida en relación con la posición de otra salida. Esto permite un mosaico conveniente de salidas dentro de la pantalla. La posición se calcula siempre en relación con la nueva posición de la otra salida, por lo que no es válido decir --output a --left-of b --output b --left-of a.
--set propiedad valor
Establece una propiedad de salida. Las propiedades enteras pueden ser especificadas como una lista válida (ver --prop) separada por comas de valores decimales o hexadecimales (con un prefijo 0x). Las propiedades de átomo pueden establecerse a cualquiera de los átomos válidos (ver --prop). Las propiedades de cadena pueden establecerse a cualquier valor.
--off
Deshabilita la salida.
--crtc crtc
Utiliza el CRTC especificado (ya sea como índice en la lista de CRTCs o XID). En uso normal, esta opción no es necesaria ya que xrandr intenta hacer elecciones sensatas sobre qué CRTC usar con cada salida. Cuando eso falla por alguna razón, esta opción puede anular la selección normal.
--gamma rojo[:verde:azul]
Establece los valores de punto flotante especificados como corrección gamma en el CRTC actualmente conectado a esta salida. Si no se especifican verde y azul, se usará el valor rojo para los tres componentes. Tenga en cuenta que no puede obtener dos valores diferentes para salidas clonadas (es decir, que comparten el mismo CRTC) y que cambiar una salida a otro CRTC no cambia en absoluto las correcciones gamma del CRTC.
--brightness brillo
Multiplica los valores gamma en el CRTC actualmente conectado a la salida por el valor de punto flotante especificado. Útil para salidas demasiado brillantes o demasiado tenues. Sin embargo, esta es una modificación solo de software; si su hardware tiene soporte para cambiar realmente el brillo, probablemente preferirá usar xbacklight.

Opciones de RandR versión 1.1

Estas opciones están disponibles para servidores X que soporten la versión 1.1 o anterior de RandR. Siguen siendo válidas para servidores X más nuevos, pero no interactúan de forma sensata con las opciones de la versión 1.2 en la misma línea de comandos.

-s, --size índice-tamaño o --size anchuraxaltura
Esto establece el tamaño de la pantalla, ya sea coincidiendo por tamaño o usando el índice en la lista de tamaños disponibles.
-r, --rate, --refresh tasa
Esto establece la tasa de refresco más cercana al valor especificado.
-o, --orientation rotacion
Esto especifica la orientación de la pantalla, y puede ser normal, invertida, izquierda o derecha.
-x
Reflejar a través del eje X.
-y
Reflejar a través del eje Y.

EJEMPLOS

Establece la salida VGA en el modo preferido de una pantalla que ha sido girada físicamente en sentido horario:

xrandr --output LVDS --auto --rotate normal --pos 0x0 --output VGA --auto --rotate left --right-of LVDS

Fuerza a usar un modo 1024x768 en una salida llamada VGA:

xrandr --newmode "1024x768" 63.50 1024 1072 1176 1328 768 771 775 798 -hsync +vsync
xrandr --addmode VGA 1024x768
xrandr --output VGA --mode 1024x768

Habilita el desplazamiento (panning) en un escritorio de 1600x768 mientras se muestra un modo de 1024x768 en una salida llamada VGA:

xrandr --fb 1600x768 --output VGA --mode 1024x768 --panning 1600x0

Que una pequeña pantalla LVDS de 1280x800 muestre una versión reducida de un enorme escritorio de 3200x2000, y que una pantalla VGA grande muestre el entorno del ratón a tamaño normal.

xrandr --fb 3200x2000 --output LVDS --scale 2.5x2.5 --output VGA --pos 0x0 --panning 3200x2000+0+0/3200x2000+0+0/64/64/64/64

Muestra la salida VGA con forma trapezoidal para que se corrija la perspectiva cuando el proyector está ligeramente por encima de la pantalla:

xrandr --fb 1024x768 --output VGA --transform 1.24,0.16,-124,0,1.24,0,0,0.000316,1
