NOMBRE

xrdfs - utilidad de metadatos de archivos y directorios de xrootd

SINOPSIS

xrdfs [--no-cwd] host[:puerto] [comando [argumentos]]
comando: help, chmod, ls, locate, mkdir, mv, stat, statvfs, query, rm, rmdir,
           truncate, prepare, cat, tail, spaceinfo

DESCRIPCIÓN

La utilidad xrdfs ejecuta operaciones orientadas a metadatos (p. ej., ls, mv, rm, etc.) en uno o varios servidores xrootd. La ayuda de comandos está disponible invocando xrdfs sin opciones ni parámetros de línea de comandos y luego escribiendo "help" en respuesta al prompt de entrada.

OPCIONES

--no-cwd

No se establece el directorio de trabajo actual (CWD) en modo interactivo.

COMANDOS

chmod ruta <usuario><grupo><otro>

Modifica los permisos de la ruta. Ejemplo de cadena de permisos: rwxr-x--x
ls [-l] [-u] [-R] [-D] [-Z] [-C] [nombre_directorio]
Obtiene el listado del directorio.
-l obtiene estadísticas de cada entrada y muestra un listado largo
-u muestra las rutas como URLs
-R lista subdirectorios recursivamente
-D muestra entradas duplicadas
-Z comprueba si el archivo es un archivo ZIP y si es así, lista su contenido
-C calcula la suma de verificación (checksum) de cada entrada
locate [-n] [-r] [-d] [-m] [-i] [-p] <ruta>
Obtiene las ubicaciones de la ruta.
-r actualiza, no usa ubicaciones cacheadas
-n hace que el servidor devuelva la respuesta inmediatamente aunque pueda estar incompleta
-d realiza una localización profunda y recursiva para encontrar servidores de datos
-m prefiere nombres de host a direcciones IP
-i ignora dependencias de red (IPv6/IPv4)
-p sea pasivo: ignora la información opaca de cgi de los intentos/intentos realizados
mkdir [-p] [-m<usuario><grupo><otro>] <nombre_directorio>
Crea un directorio/árbol de directorios.
-p crea todo el árbol de directorios recursivamente
-m<usuario><grupo><otro> permisos para los directorios recién creados
mv <ruta1> <ruta2>
Mueve ruta1 a ruta2 localmente en el mismo servidor.
stat <ruta> [<rutas>]
Obtiene información sobre el(los) archivo(s) o directorio(s).
-q <flags> Hace que xrdfs devuelva el código de error 55 a la shell si la combinación de flags solicitada no está presente; los flags se pueden combinar usando '|' o '&'
Flags disponibles: XBitSet, IsDir, Other, Offline, POSCPending, IsReadable, IsWriteable, BackUpExists
statvfs <ruta>
Obtiene información sobre un sistema de archivos virtual.
query <código> <parámetros>
Obtiene información del servidor. Códigos de consulta:
config <qué> Configuración del servidor; <qué> es una de las siguientes opciones:
bind_max - el número máximo de flujos paralelos
chksum - la suma de verificación soportada
pio_max - número máximo de solicitudes de E/S paralelas
readv_ior_max - tamaño máximo de un elemento readv
readv_iov_max - número máximo de entradas readv
tpc - soporte para copias de terceros
wan_port - el puerto a usar para copias WAN
wan_window - el tamaño de la ventana del puerto WAN
window - el tamaño de la ventana TCP
cms - el estado del cmsd
role - el rol en un clúster
sitename - el nombre del sitio
version - la versión del servidor
checksumcancel <ruta> Cancelación de la suma de verificación del archivo
checksum <ruta> Suma de verificación del archivo
opaque <arg> Dependiente de la implementación
opaquefile <arg> Dependiente de la implementación
space <espacio> Estadísticas de espacio lógico
stats <qué> Estadísticas del servidor; <qué> es una lista de letras que indican la información a devolver:
a - todas las estadísticas
p - estadísticas de protocolo
b - estadísticas de uso de búfer
s - estadísticas de planificación
d - estadísticas de sondeo de dispositivos
u - estadísticas de uso
i - identificación del servidor
z - estadísticas sincronizadas
l - estadísticas de conexión
xattr <ruta> Atributos extendidos
prepare <reqid> [nombres_archivos] Estado de la solicitud de preparación
rm <nombre_archivo> [<nombres_archivos>]
Elimina un archivo.
rmdir <nombre_directorio>
Elimina un directorio.
truncate <nombre_archivo> <longitud>
Trunca un archivo.
prepare [-c] [-f] [-s] [-w] [-e] [-p prioridad] [-a id_solicitud] nombres_archivos
Prepara uno o más archivos para su acceso.
-c co-localiza los archivos preparados si es posible
-f actualiza la hora de acceso del archivo incluso si la ubicación es conocida
-s almacena los archivos en disco si no están en línea
-w cuando los archivos se accederán para modificación
-p prioridad de la solicitud, de 0 (más baja) a 3 (más alta)
-a aborta la solicitud
-e elimina el archivo de la caché de disco
cat [-o archivo_local] archivos
Imprime el contenido de uno o más archivos en la salida estándar
-o imprime en el archivo local especificado
tail [-c bytes] [-f] archivo
Muestra la última parte de los archivos en la salida estándar.
-c num_bytes muestra los últimos num_bytes
-f muestra los datos añadidos a medida que el archivo crece
spaceinfo ruta
Obtiene estadísticas de espacio para la ruta dada.
xattr <ruta> <código> <parámetros>
Operación sobre atributos extendidos. Códigos:
set <attr> Establece un atributo extendido;
<attr> es una cadena con el formato nombre=valor
get <nombre> Obtiene un atributo extendido.
del <nombre> Elimina un atributo extendido.
list Lista los atributos extendidos.

CÓDIGOS DE RETORNO

50 : error genérico (p. ej., configuración, interno, datos, SO)

51 : error relacionado con el socket

52 : error relacionado con el postmaster

53 : error relacionado con XRootD

54 : error de redirección

55 : la respuesta de la consulta fue negativa (esto no es un error)

NOTAS

Para la lista de variables de entorno disponibles, consulte xrdcopy(1).

DIAGNÓSTICO

Los errores generan un mensaje de error y un estado de salida distinto de cero.

NOMBRE

xrdfs - Utilidad de línea de comandos para interactuar con un sistema de archivos XRootD.

SINOPSIS

xrdfs [OPTIONS] [COMMAND] [ARGS] ...

DESCRIPCIÓN

xrdfs es una herramienta que permite a los usuarios interactuar con un sistema de archivos XRootD. Puede listar archivos, copiar archivos, mover archivos, eliminar archivos, mostrar información de archivos y más.

OPCIONES

Las opciones disponibles incluyen:

  • -h, --help: Muestra un mensaje de ayuda y sale.
  • -V, --version: Muestra información de la versión y sale.
  • -v, --verbose: Habilita la salida detallada.
  • -H, --host <host>: Especifica el host del servidor XRootD.
  • -p, --port <puerto>: Especifica el puerto del servidor XRootD.
  • -u, --user <usuario>: Especifica el nombre de usuario para la autenticación.
  • -P, --password <contraseña>: Especifica la contraseña para la autenticación.
  • -k, --keyfile <archivo_clave>: Especifica el archivo de clave privada para la autenticación con certificado.
  • -c, --certfile <archivo_certificado>: Especifica el archivo de certificado para la autenticación con certificado.

COMANDOS

Los comandos disponibles incluyen:

  • ls [PATH]: Lista el contenido de un directorio o información de un archivo.
  • cp source destination: Copia un archivo o directorio.
  • mv source destination: Mueve o renombra un archivo o directorio.
  • rm PATH: Elimina un archivo o directorio.
  • mkdir PATH: Crea un directorio.
  • stat PATH: Muestra información detallada sobre un archivo o directorio.
  • query [OPTIONS] [PATH]: Realiza consultas sobre el sistema de archivos.
  • xrdcp ...: Copia archivos (similar a cp pero con más opciones).
  • xrdrm ...: Elimina archivos (similar a rm pero con más opciones).
  • xrdmkdir ...: Crea directorios (similar a mkdir pero con más opciones).
  • xrdstat ...: Muestra información sobre archivos (similar a stat pero con más opciones).

CÓDIGOS DE RETORNO

xrdfs devuelve 0 en caso de éxito y un valor distinto de cero en caso de error.

NOTAS

Asegúrese de tener los permisos necesarios para realizar las operaciones solicitadas en el sistema de archivos XRootD.

DIAGNÓSTICOS

Los mensajes de error se mostrarán en la salida de error estándar (stderr).
