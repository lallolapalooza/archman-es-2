NOMBRE

xrdgsiproxy - genera un certificado proxy X.509

SINOPSIS

xrdgsiproxy [-h] [modo] [-debug] [-f [-out] archivo]

DESCRIPCIÓN

La utilidad xrdgsiproxy muestra, crea y destruye certificados proxy de usuario X.509 utilizados por el protocolo de seguridad de la infraestructura de seguridad de la cuadrícula (gsi).

ÓPERANDOS

modo

init crea un certificado proxy y el archivo proxy relacionado
info muestra el contenido del archivo proxy existente
destroy elimina el archivo proxy existente

OPCIONES

-h muestra ayuda

-f [-out] archivo
Ubicación no estándar del archivo proxy
init modo solo:
-certdir dir
Ubicación no estándar del directorio con información sobre CAs conocidas
-cert archivo
Ubicación no estándar del certificado para el cual se desean proxies
-key archivo
Ubicación no estándar de la clave privada que se utilizará para firmar el proxy
-bits n
Fuerza en bits de la clave [predeterminado 2048]
-valid hh:mm
Tiempo de validez del certificado proxy [predeterminado 12:00]
-path-length len
Número máximo de niveles descendientes debajo de este proxy [predeterminado 0]

NOTAS

La documentación completa en HTML se puede encontrar en
https://xrootd.web.cern.ch/doc/dev56/sec_config.htm

La documentación de todos los componentes asociados con xrdgsiproxy se puede encontrar en https://xrootd.org/docs.html

DIAGNÓSTICOS

Los errores generan un mensaje de error y un estado de salida distinto de cero.

LICENCIA

NIVEL DE SOPORTE

https://xrootd.org/contact.html
