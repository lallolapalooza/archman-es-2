NOMBRE

xrdcp - copia archivos

SINOPSIS

xrdcp [opciones] fuente destino
opciones: [--cksum args] [--debug lvl]
[--coerce] [--force] [--help] [--license]
[--nopbar] [--posc] [--proxy ipaddr:puerto]
[--recursive] [--retry tiempo] [--server]
[--silent] [--sources num] [--streams num]
[--tpc [delegate] first|only] [--verbose]
[--version] [--xrate tasa] [--zip archivo]
[--dynamic-src] [--infiles fn]
[--parallel n] [--allow-http] [--xattr]
[--notlsok] [--tlsnodata] [--tlsmetalink]
[--zip-mtln-cksum] [--rm-bad-cksum] [--continue]
[--xrate-threshold] [--retry-policy]
opciones antiguas: [-adler] [-DSparm string] [-DIparm number]
[-md5] [-np] [-ODcgi] [-OScgi] [-x]

DESCRIPCIÓN

La utilidad xrdcp copia uno o más archivos de una ubicación a otra. La fuente y el destino de los datos pueden ser un archivo o directorio local o remoto. Adicionalmente, la fuente de datos también puede residir en múltiples servidores.

OPCIONES

-C | --cksum tipo[:valor|print|source]

obtiene la suma de verificación (checksum) de tipo (es decir, adler32, crc32, md5 o zcrc32) de la fuente, calcula la suma de verificación en el destino y verifica que sean iguales. Si se elige auto como tipo de suma de verificación, xrdcp intentará inferir automáticamente el tipo de suma de verificación correcto basándose en la configuración de origen / destino, el tipo de archivo de origen (metalink, ZIP) y los complementos de suma de verificación disponibles. Si se especifica un valor, se usa como la suma de verificación de origen. Cuando se especifica print, se imprime la suma de verificación en el destino pero *no* se verifica.
-d | --debug lvl
nivel de depuración: 1 (bajo), 2 (medio), 3 (alto)
-F | --coerce
ignora la semántica de bloqueo en el archivo de destino. Esta opción puede provocar corrupción de archivos si no se usa correctamente.
-f | --force
vuelve a crear un archivo si ya está presente.
-h | --help
muestra información de uso.
-H | --license
muestra los términos y condiciones de la licencia.
-N | --nopbar
no muestra la barra de progreso.
-P | --posc
solicita procesamiento POSC (persistir al cerrar con éxito) para crear un nuevo archivo. Los archivos se eliminan automáticamente si no se cierran con éxito.
-D | --proxy dirección_proxy:puerto_proxy
[AÚN NO IMPLEMENTADO]

usa dirección_proxy:puerto_proxy como un proxy SOCKS4. Solo se admiten direcciones numéricas.

-r | --recursive
copia recursivamente todos los archivos a partir del directorio de origen dado.
--retry
reintenta trabajos de copia fallidos.
--server
se ejecuta como si estuviera en un entorno de servidor. Solo se usa para soporte de copia de terceros del lado del servidor.
-s | --silent
no produce información de resumen ni muestra la barra de progreso.
-y | --sources num
usa hasta num fuentes para copiar el archivo.
-S | --streams num
usa num flujos de datos paralelos para realizar la transferencia (el flujo principal no se usa en este caso para realizar la transferencia). El valor máximo es 15. El valor predeterminado es 0 (es decir, usa solo el flujo de control).
--tpc [delegate] first|only
copia el archivo del servidor remoto al servidor remoto utilizando el protocolo de copia de terceros (es decir, los datos fluyen de servidor a servidor). Los servidores de origen y destino deben ser compatibles con copias de terceros. Pueden aplicarse restricciones de seguridad adicionales y estas pueden hacer que la copia falle si no se pueden cumplir. El argumento 'first' intenta tpc y si falla, realiza una copia normal; mientras que 'only' falla la copia a menos que tpc tenga éxito. Cuando se especifica 'delegate', la copia delega las credenciales del emisor del comando al servidor de destino, que utiliza esas credenciales para autenticarse con el servidor de origen. La delegación se ignora si el servidor de destino no está configurado para usar credenciales delegadas. Actualmente, solo se pueden delegar credenciales gsi.
-v | --verbose
muestra información de resumen.
-V | -version
muestra la información de la versión y sale inmediatamente.
-z | --zip archivo
copia el archivo dado desde un archivo ZIP (igual que la información opaca de xrdcl.unzip).
-X | --xrate tasa
limita la velocidad de copia a la tasa especificada. La tasa puede calificarse con la letra k, m o g para indicar kilos, megas o gigas bytes, respectivamente. La opción solo se aplica cuando la fuente o el destino es local.
-X | --xrate-threshold tasa
Si la tasa de transferencia cae por debajo del umbral dado, fuerza al cliente a usar una fuente diferente o falla la transferencia si no hay más fuentes disponibles.
-Z | --dynamic-src
el tamaño del archivo puede cambiar durante la copia
-I | --infiles fn
especifica el archivo que contiene una lista de archivos de entrada
--parallel n
número de trabajos de copia que se ejecutarán simultáneamente
--allow-http
permite HTTP como protocolo de origen o destino. Requiere el plugin cliente XrdClHttp
--xattr
conserva los atributos extendidos
--notlsok
Si el servidor es demasiado antiguo para admitir cifrado TLS, vuelve a la comunicación sin cifrar.
--tlsnodata
En el caso del protocolo roots/xroots, cifra solo el flujo de control y deja los flujos de datos sin cifrar.
--tlsmetalink
Trata todas las URL en metalink como roots/xroots.
--zip-mtln-cksum
Usa la suma de verificación disponible en un archivo metalink incluso si un archivo se está extrayendo de un archivo ZIP.
--rm-bad-cksum
Elimina el archivo de destino si la verificación de la suma de verificación falló (también habilita la semántica POSC).
--continue
Continúa copiando un archivo desde el punto donde se interrumpió la copia anterior.

OPCIONES ANTIGUAS

Las opciones antiguas se proporcionan por compatibilidad con versiones anteriores. Ahora están obsoletas y deben evitarse.
-adler

equivalente a "--cksum adler32:source".
-DIpname valor_numero
establece el parámetro interno pname con el valor numérico valor_numero.
-DSpname valor_cadena
establece el parámetro interno pname con el valor de cadena valor_cadena.
-md5
equivalente a "--cksum md5:source".
-np
equivalente a "--nopbar".
-ODcgi
agrega información cgi cgi a cualquier URL de xrootd de destino. Debes especificar la información opaca directamente en la URL de destino.
-OScgi
agrega información cgi cgi a cualquier URL de xrootd de origen.
-x
equivalente a "--sources 12".

RÚBRICAS

fuente

un guion (es decir, -) que indica entrada estándar, un archivo local, un nombre de directorio local con el sufijo /, o una URL de xrootd en el formato
xroot://[usuario@]host[:puerto]/ruta_absoluta
La ruta_absoluta puede ser un directorio.
destino
un guion (es decir, -) que indica salida estándar, un archivo local, un nombre de directorio local con el sufijo /, o una URL de xrootd en el formato
xroot://[usuario@]host[:puerto]/ruta_absoluta
La ruta_absoluta puede ser un directorio.

ENVIRONMENT VARIABLES

These environment variables are used by the libXrdCl library and any other application using the libXrdCl library, unless specified otherwise. The text in the brackets is a name of the corresponding xrdcp commandline parameter.

XRD_LOGLEVEL

Determina la cantidad de diagnósticos que deben imprimirse. Los valores válidos son: Dump, Debug, Info, Warning, y Error.

XRD_LOGFILE

Si se establece, los diagnósticos se imprimirán en el archivo especificado en lugar de stderr.

XRD_LOGMASK

Determina qué temas de diagnóstico deben imprimirse en todos los niveles. Es una lista de temas separados por "|". El primer elemento puede ser "All" en cuyo caso todos los temas se habilitan y los elementos subsiguientes pueden desactivarlos, o "None" en cuyo caso todos los temas se deshabilitan y las banderas subsiguientes pueden activarlos. Si el nombre del tema va precedido por "^", significa que el tema debe deshabilitarse. Si el nombre del tema no va precedido, significa que el tema debe habilitarse.

La máscara de registro también se puede manejar por separado para cada nivel de diagnóstico estableciendo una o más de las siguientes variables: XRD_LOGMASK_ERROR, XRD_LOGMASK_WARNING, XRD_LOGMASK_INFO, XRD_LOGMASK_DEBUG, y XRD_LOGMASK_DUMP. El valor predeterminado para cada nivel es "All", excepto para el nivel Dump, donde el valor predeterminado es "All|^PollerMsg". Esto significa que, en el nivel Dump, todos los temas excepto "PollerMsg" están habilitados.

Temas disponibles: AppMsg, UtilityMsg, FileMsg, PollerMsg, PostMasterMsg, XRootDTransportMsg, TaskMgrMsg, XRootDMsg, FileSystemMsg, AsyncSockMsg, TlsMsg

XRD_TLSDBGLVL

Determina el nivel de depuración para el componente TLS. Los valores válidos son: OFF, CTX, SOK, SIO, ALL y OUT. El valor predeterminado es OFF.

XRD_PARALLELEVTLOOP

El número de bucles de eventos (es decir, el número de hilos que manejan las solicitudes). El número predeterminado es 10.

XRD_READRECOVERY

Determina si la recuperación de lectura debe habilitarse o deshabilitarse (habilitada por defecto).

XRD_WRITERECOVERY

Determina si la recuperación de escritura debe habilitarse o deshabilitarse (habilitada por defecto).

XRD_OPENRECOVERY

Determina si la recuperación de apertura debe habilitarse o deshabilitarse para aperturas mutables (truncar o crear) (habilitada por defecto).

XRD_CONNECTIONWINDOW (-DIConnectionWindow)

Una ventana de tiempo para el establecimiento de la conexión. Se declara un error de conexión si la conexión no se establece dentro de la ventana de tiempo. Si ocurre un error de conexión antes, otro intento de conexión solo se realizará al comienzo de la próxima ventana.

XRD_CONNECTIONRETRY (-DIConnectionRetry)

Número de intentos de conexión que deben realizarse (número de ventanas de conexión disponibles) antes de declarar un fallo permanente.

XRD_REQUESTTIMEOUT (-DIRequestTimeout)

Valor predeterminado para el tiempo después del cual se declara un error si ha sido imposible obtener una respuesta a una solicitud.

XRD_STREAMTIMEOUT (-DIStreamTimeout)

Valor predeterminado para el tiempo después del cual se declara un error de conexión (y se intenta una recuperación) si hay solicitudes pendientes y no hay actividad de socket o un tiempo de espera registrado.

XRD_SUBSTREAMSPERCHANNEL (-DISubStreamsPerChannel)

Número de flujos por sesión.

XRD_TIMEOUTRESOLUTION (-DITimeoutResolution)

Resolución para los eventos de tiempo de espera. Es decir, los eventos de tiempo de espera solo se procesarán cada XRD_TIMEOUTRESOLUTION segundos.

XRD_STREAMERRORWINDOW (-DIStreamErrorWindow)

Tiempo después del cual se borrarán las banderas de fallo permanente y se podrá intentar una nueva conexión si es necesario.

XRD_RUNFORKHANDLER (-DIRunForkHandler)

Determina si los manejadores de fork deben habilitarse, haciendo que la API sea segura para fork.

XRD_REDIRECTLIMIT (-DIRedirectLimit)

Número máximo de redirecciones permitidas.

XRD_NOTAUTHORIZEDRETRYLIMIT (-dNotAuthorizedRetryLimit)

Número máximo de reintentos permitidos en un meta-gestor para errores de no autorización.

XRD_POLLERPREFERENCE (-DSPollerPreference)

Una lista separada por comas de implementaciones de poller en orden de preferencia. El predeterminado es: integrado.

XRD_CLIENTMONITOR (-DSClientMonitor)

Ruta a la biblioteca del monitor del cliente.

XRD_CLIENTMONITORPARAM (-DSClientMonitorParam)

Parámetros opcionales adicionales que se pasarán al objeto de monitorización en la inicialización.

XRD_WORKERTHREADS (-DIWorkerThreads)

Número de hilos que procesan las devoluciones de llamada del usuario.

XRD_CPPARALLELCHUNKS (-DICPParallelChunks)

Número máximo de solicitudes asíncronas que está procesando el comando xrdcp por subflujo de canal conectado (ajustado en tiempo real).

XRD_CPCHUNKSIZE (-DICPChunkSize)

Tamaño de un único bloque de datos manejado por xrdcp.

XRD_NETWORKSTACK (-DSNetworkStack)

La pila de red que el cliente debe utilizar para conectarse al servidor. Los valores posibles son:

IPAuto: detectar automáticamente qué pila IP usar

IPAll: usar la pila IPv6 (sockets AF_INET6) y direcciones IPv6 e IPv4 (mapeadas a IPv6)

IPv6: usar solo la pila y direcciones IPv6

IPv4: usar solo la pila y direcciones IPv4 (sockets AF_INET)

IPv4Mapped6: usar la pila IPv6 y direcciones IPv4 mapeadas

XRD_DATASERVERTTL (-DIDataServerTTL)

Período de tiempo después del cual se debe cerrar una conexión inactiva a un servidor de datos.

XRD_LOADBALANCERTTL (-DILoadBalancerTTL)

Período de tiempo después del cual se debe cerrar una conexión inactiva a un gestor o equilibrador de carga.

XRD_APPNAME (-DSAppName)

Anula el nombre de la aplicación informado al servidor.

XRD_PLUGINCONFDIR

Una ubicación personalizada que contiene archivos de configuración de complementos del cliente.

XRD_PLUGIN

Un complemento de cliente predeterminado que se utilizará.

XRD_CPINITTIMEOUT (-DICPInitTimeout)

Tiempo máximo permitido para que el proceso de copia se inicialice, es decir, para abrir los archivos de origen y destino.

XRD_CPTPCTIMEOUT (-DICPTPCTimeout)

Tiempo máximo permitido para que finalice una operación de copia de terceros.

XRD_TCPKEEPALIVE (-DITCPKeepAlive)

Habilita/Deshabilita la funcionalidad TCP keep alive.

XRD_TCPKEEPALIVETIME (-DITCPKeepAliveTime)

Tiempo entre el último paquete de datos enviado y la primera sonda keepalive (solo Linux).

XRD_TCPKEEPALIVEINTERVAL (-DITCPKeepAliveInterval)

Intervalo entre sondas keepalive subsiguientes (solo Linux).

XRD_TCPKEEPALIVEPROBES (-DITCPKeepProbes)

Número de sondas no reconocidas antes de considerar que la conexión está muerta (solo Linux).

XRD_METALINKPROCESSING

Habilita/Deshabilita el procesamiento de Metalink (habilitado por defecto).

XRD_LOCALMETALINKFILE

Habilita/Deshabilita el procesamiento de archivos Metalink locales (por convención se debe usar el siguiente esquema de URL: root://localfile//path/filename.meta4) La semántica 'localfile' ahora está obsoleta, ¡use file://localhost/path/filename.meta4 en su lugar!

XRD_GLFNREDIRECTOR

El redireccionador se utilizará como último recurso si se especifica la etiqueta GLFN en un archivo Metalink.

XRD_XCPBLOCKSIZE

Tamaño máximo de un bloque de datos asignado a una sola fuente en caso de una transferencia de copia extrema.

XRD_NODELAY

Deshabilita el algoritmo de Nagle si se establece en 1 (predeterminado), lo habilita si se establece en 0.

XRD_PREFERIPV4

Si está configurado, el cliente intentará primero la dirección IPv4 (desactivado por defecto).

XRD_MAXMETALINKWAIT

El tiempo máximo en segundos que un cliente puede detenerse por el servidor si hay un redireccionador Metalink disponible (predeterminado: 60s).

XRD_PRESERVELOCATETRIED

Si se establece en 1, el cliente XRootD conservará la información opaca cgi tried/triedrc para la solicitud kXR_locate a través de redirecciones/reintentos; si se establece en 0, el cliente XRootD tratará kXR_locate como cualquier otra solicitud pasiva.

XRD_PRESERVEXATTRS

Si se establece en 1 (predeterminado), xrdcp conservará los atributos extendidos del archivo; si se establece en 0, los atributos extendidos del archivo no se conservarán.

XRD_NOTLSOK

Si se establece en 1 y el servidor es demasiado antiguo para admitir el cifrado TLS, xrdcp recurrirá a la transmisión sin cifrar aunque se haya utilizado el protocolo roots/xroots. Por defecto está configurado en 0.

XRD_TLSNODATA

Si se establece en 1, en caso de protocolo roots/xroots, solo el flujo de control se cifrará, los flujos de datos permanecerán sin cifrar. Por defecto está configurado en 0.

XRD_TLSMETALINK

Si se establece en 1, todas las URL en metalink se tratarán como roots/xroots. Por defecto está configurado en 0.

XRD_ZIPMTLNCKSUM

Si se establece en 1, utilice la suma de verificación disponible en un archivo metalink incluso si un archivo se está extrayendo de un archivo ZIP. Por defecto está configurado en 0.

XRD_CPTIMEOUT

Tiempo de espera para un trabajo de copia clásico (no TPC). Por defecto está configurado en 0 (deshabilitado).

XRD_CLCONFDIR

Directorio definido por el usuario con archivos de configuración (*.conf).

XRD_CLCONFFILE

Archivo de configuración definido por el usuario.

XRD_CPRETRY

Número máximo de veces que se reintentarán los trabajos de copia fallidos (predeterminado: 0).

XRD_CPRETRYPOLICY

Política de reintento de trabajos de copia, ya sea forzar o reintentar (predeterminado: force).

XRD_CPUSEPGWRTRD

Habilita la corrección de errores en tiempo real de páginas corruptas (predeterminado: 1).

RETURN CODES

50: error genérico (por ejemplo, configuración, interno, datos, SO, opción de línea de comandos)

51: error relacionado con socket

52: error relacionado con postmaster

53: error relacionado con XRootD

54: error de redirección

55: la respuesta de la consulta fue negativa (esto no es un error)
