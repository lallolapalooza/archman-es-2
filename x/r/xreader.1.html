XREADER(1) Manual de Comandos Generales XREADER(1)

NOMBRE

Xreader - Un visor de documentos

SINTAXIS

xreader [OPCIONES...] [ARCHIVOS...]

DESCRIPCIÓN

Xreader es un visor simple de documentos multipágina. Puede mostrar e imprimir archivos PostScript (PS), Encapsulated PostScript (EPS), DJVU, DVI, XPS y Portable Document Format (PDF).

Cuando es compatible con el documento, también permite buscar texto, copiar texto al portapapeles, navegación por hipertexto y marcadores de índice.
Esta página del manual documenta brevemente el comando xreader.

OPCIONES

nombre(s)...
Especifica el archivo a abrir cuando se inicia xreader. Si esto no se especifica, xreader se iniciará con una ventana en blanco y podrá abrir un archivo desde el menú o usando el atajo CTRL+O. Se pueden cargar múltiples archivos si están separados por espacios. xreader también soporta el manejo de archivos remotos.
-p, --etiqueta-página=PÁGINA
Aquí puede especificar una etiqueta de página; esta página se seleccionará en el documento si existe.
-i, --índice-página=NÚMERO
Aquí puede especificar un número de página; esta página se seleccionará en el documento si existe.
-f, --pantalla-completa
Inicia xreader en modo de pantalla completa. Debe especificar un documento para iniciar en modo de pantalla completa.
-s, --presentación
Inicia xreader en modo de presentación. Debe especificar un documento para iniciar en modo de presentación.
-w, --vista-previa
Inicia xreader en modo de vista previa. Debe especificar un documento para iniciar en modo de vista previa.
--pantalla=PANTALLA
Pantalla X a utilizar.
--versión
Muestra la información de la versión y sale.
-?, -h, --ayuda
Imprime las opciones estándar de la línea de comandos.
--ayuda-completa
Imprime todas las opciones de la línea de comandos.

Este programa también acepta las opciones estándar de GTK.

EJEMPLOS

xreader --vista-previa ~/Escritorio/cosas.ps

Abre cosas.ps del escritorio del usuario actual, en modo de vista previa.

xreader -i 2 -s ./documento.pdf

Abre documento.pdf del directorio de trabajo actual, en la página 2 en modo de presentación.

ERRORES

Si encuentra algún error, pueden informarse en:

http://github.com/linuxmint/xreader/issues

VER TAMBIÉN

La documentación de Xreader se puede encontrar en el menú "Ayuda", o presionando la tecla F1.
