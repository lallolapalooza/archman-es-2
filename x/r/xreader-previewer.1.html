NOMBRE

xreader-previewer - muestra la vista previa de impresión de un documento

SINOPSIS

xreader-previewer [archivo]

DESCRIPCIÓN

xreader-previewer es un programa para mostrar el diálogo de vista previa de impresión para archivos compatibles con xreader.

OPCIONES

xreader-previewer respeta todas las opciones de línea de comandos normales de GTK+.

VER TAMBIÉN

xreader(1), gtk-options(7).

https://www.github.com/linuxmint/xreader/
