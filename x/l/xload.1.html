NOMBRE

xload - visualizador de carga del sistema para X

SINOPSIS

xload [-opción_toolkit ...] [-scale entero] [-update segundos]
      [-hl color] [-highlight color] [-remote host]
      [-jumpscroll píxeles] [-label cadena] [-nolabel] [-lights]
      [-help|-version]

DESCRIPCIÓN

El programa xload muestra un histograma actualizado periódicamente de la carga promedio del sistema.

OPCIONES

Xload acepta todas las opciones estándar de línea de comandos del X Toolkit (ver X(7)). El orden de las opciones no es importante. xload también acepta las siguientes opciones adicionales:

-hl color o -highlight color
Esta opción especifica el color de las líneas de escala.
-jumpscroll píxeles
El número de píxeles para desplazar el gráfico hacia la izquierda cuando el gráfico alcanza el borde derecho de la ventana. El valor predeterminado es 1/2 del ancho de la ventana actual. Se puede lograr un desplazamiento suave estableciéndolo en 1.
-label cadena
La cadena a colocar en la etiqueta encima del promedio de carga.
-nolabel
Si se especifica esta opción de línea de comandos, no se mostrará ninguna etiqueta encima del gráfico de carga.
-lights
Cuando se especifica, esta opción hace que xload muestre la carga promedio actual utilizando los LEDs del teclado; para una carga promedio de n, xload enciende los primeros n LEDs del teclado. Esta opción desactiva la visualización habitual en pantalla.
-scale entero
Esta opción especifica el número mínimo de marcas de verificación en el histograma, donde una división representa un punto de carga promedio. Si la carga supera este número, xload creará más divisiones, pero nunca usará menos que este número. El valor predeterminado es 1.
-update segundos
Esta opción especifica el intervalo en segundos en el que xload actualiza su visualización. El tiempo mínimo permitido entre actualizaciones es de 1 segundo. El valor predeterminado es 10.
-remote host
Esta opción le indica a xload que muestre la carga de host en lugar de localhost. Xload obtiene la información de la base de datos rwhod y, en consecuencia, requiere que rwhod esté ejecutándose tanto en localhost como en host.
-help
Esta opción especifica que xload debe imprimir un mensaje de uso y salir.
-version
Esta opción especifica que xload debe imprimir información de versión y salir.

RECURSOS

Además de los recursos disponibles para cada uno de los widgets utilizados por xload, hay un recurso definido por la propia aplicación.

showLabel (clase Boolean)
Si es Falso, no se mostrará ninguna etiqueta.

WIDGETS

Para especificar recursos, es útil conocer la jerarquía de los widgets que componen xload. En la siguiente notación, la indentación indica la estructura jerárquica. Primero se da el nombre de la clase del widget, seguido del nombre de la instancia del widget.

XLoad  xload
        Paned  paned
                Label  label
                StripChart  load

ENTORNO

DISPLAY
para obtener el host y número de pantalla predeterminados.
XENVIRONMENT
para obtener el nombre de un archivo de recursos que anula los recursos globales almacenados en la propiedad RESOURCE_MANAGER.

ARCHIVOS

/usr/share/X11/app-defaults/XLoad
especifica los recursos requeridos

VER TAMBIÉN

X(7), xrdb(1), mem(4), Widget StripChart de Athena.

ERRORES

En plataformas antiguas, este programa puede requerir la capacidad de abrir y leer el archivo especial del sistema /dev/kmem. Los sitios que no permiten el acceso general a este archivo pueden necesitar hacer que xload pertenezca al mismo grupo que /dev/kmem y activar el flag de permiso de set group id.

Leer la carga promedio es inherentemente no portable. Por lo tanto, la rutina utilizada para leerla (get_load.c) debe ser portada a cada nuevo sistema operativo.
