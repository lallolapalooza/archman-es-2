NOMBRE

xl2tpd - Demonio del Protocolo de Túnel de Capa 2.

DESCRIPCIÓN

xl2tpd es una implementación del Protocolo de Túnel de Capa 2 (RFC 2661). L2TP permite tunelizar PPP sobre UDP. Algunos ISP utilizan L2TP para tunelizar sesiones de usuario desde servidores de acceso telefónico (bancos de módem, DSLAM ADSL) a servidores PPP de backend. Otra aplicación importante son las Redes Privadas Virtuales (VPN) donde se utiliza el protocolo IPsec para asegurar la conexión L2TP (L2TP/IPsec, RFC 3193).

xl2tpd funciona abriendo un pseudo-tty para comunicarse con pppd. Se ejecuta completamente en el espacio de usuario pero admite L2TP en modo núcleo.

xl2tpd admite el seguimiento de referencia de SA IPsec para habilitar IPs internas NAT'eadas superpuestas por diferentes clientes (por ejemplo, todos los clientes que se conectan desde su IP interna Linksys 192.168.1.101), así como varios clientes detrás del mismo enrutador NAT.

Esta implementación se basa en L2TPd 0.61 de http://www.marko.net/l2tp y parches recopilados por Jacco de Leeuw en http://www.jacco2.dds.nl/networking/openswan-l2tp.html.

OPCIONES

-D
Esta opción evita que xl2tpd se desvincule del terminal y se convierta en un demonio.
-l
Esta opción indica a xl2tpd que utilice syslog para el registro, incluso cuando se especificó -D.
-c <archivo_config>
Establecer un archivo de configuración alternativo. El archivo de configuración de respaldo es /etc/l2tp/l2tpd.conf.
-s <archivo_secretos>
Indica a xl2tpd que utilice un archivo de "secretos" alternativo.
-p <archivo_pid>
Establecer un archivo PID alternativo. El predeterminado es /var/run/xl2tpd/xl2tpd.pid.
-C <archivo_control>
Establecer un archivo de control alternativo.

ARCHIVOS

/etc/xl2tpd/xl2tpd.conf
Archivo de configuración de xl2tpd, utilizado por defecto.
/etc/xl2tpd/l2tp-secrets
Archivo de secretos, utilizado por defecto.
/var/run/xl2tpd/l2tp-control
Archivo de control, utilizado por defecto.
