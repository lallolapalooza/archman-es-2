XLSATOMS(1) Manual de comandos generales XLSATOMS(1)

NOMBRE

xlsatoms - lista los átomos internados definidos en el servidor

SINOPSIS

xlsatoms [-opciones ...]

DESCRIPCIÓN

Xlsatoms lista los átomos internados. Por defecto, se listan todos los átomos a partir de 1 (el valor de átomo más bajo definido por el protocolo) hasta que se encuentra un átomo desconocido. Si se proporciona un rango explícito, xlsatoms probará todos los átomos en el rango, sin importar si alguno está indefinido.

OPCIONES

-display dpy
Esta opción especifica el servidor X al que conectarse.
-format cadena
Esta opción especifica una cadena estilo printf usada para listar cada par de átomo <valor,nombre>, impresos en ese orden (el valor es un unsigned long y el nombre es un char *). Xlsatoms proporcionará un salto de línea al final de cada línea. El valor por defecto es %lu\t%s.
-range [bajo]-[alto]
Esta opción especifica el rango de valores de átomos a comprobar. Si no se proporciona bajo, se asume el valor 1. Si no se proporciona alto, xlsatoms se detendrá en el primer átomo indefinido igual o superior a bajo.
-name cadena
Esta opción especifica el nombre de un átomo a listar. Si el átomo no existe, se imprimirá un mensaje en la salida de error estándar.
-version
Imprime la versión del programa y sale.

VER TAMBIÉN

X(7), Xserver(1), xprop(1)

ENTORNO

DISPLAY
para obtener el host y el display por defecto a usar.

AUTOR

Jim Fulton, MIT X Consortium
