subroutine xlaenv (integer ispec, integer nvalue)

XLAENV

Propósito:

!>
!> XLAENV establece ciertas cantidades dependientes de la máquina y del problema
!> que luego serán recuperadas por ILAENV.
!>

Parámetros

ISPEC 
!>          ISPEC es INTEGER
!>          Especifica el parámetro a establecer en el array COMÚN IPARMS.
!>          = 1: el tamaño de bloque óptimo; si este valor es 1, un algoritmo
!>               no bloqueado dará el mejor rendimiento.
!>          = 2: el tamaño de bloque mínimo para el cual se debe usar la rutina
!>               bloqueada; si el tamaño de bloque utilizable es menor que
!>               este valor, se debe usar una rutina no bloqueada.
!>          = 3: el punto de cruce (en una rutina bloqueada, para N menor
!>               que este valor, se debe usar una rutina no bloqueada)
!>          = 4: el número de desplazamientos, utilizado en las rutinas de
!>               valores propios no simétricos
!>          = 5: la dimensión mínima de columna para que se use el bloqueo;
!>               los bloques rectangulares deben tener una dimensión de al
!>               menos k por m, donde k viene dado por ILAENV(2,...) y m por
!>               ILAENV(5,...)
!>          = 6: el punto de cruce para SVD (al reducir una matriz m por n
!>               a una forma bidiagonal, si max(m,n)/min(m,n) excede
!>               este valor, primero se usa una factorización QR para reducir
!>               la matriz a una forma triangular)
!>          = 7: el número de procesadores
!>          = 8: otro punto de cruce, para los métodos QR y QZ multidesplazamiento
!>               para problemas de valores propios no simétricos.
!>          = 9: tamaño máximo de los subproblemas en la parte inferior del
!>               árbol de cálculo en el algoritmo divide y vencerás
!>               (usado por xGELSD y xGESDD)
!>          =10: la aritmética NaN ieee puede confiarse en que no causará errores
!>          =11: la aritmética de infinito puede confiarse en que no causará errores
!>

NVALUE

!>          NVALUE es INTEGER
!>          El valor del parámetro especificado por ISPEC.
!>
