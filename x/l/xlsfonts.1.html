xlsfonts(1) Manual de comandos generales xlsfonts(1)

NOMBRE

xlsfonts - lista las fuentes disponibles para el servidor X

SINOPSIS

xlsfonts [-display host:dpy] [-l] [-ll] [-lll] [-m] [-C] [-1] [-w ancho] [-n columnas] [-u] [-o] [-fn patrón] [-v]

DESCRIPCIÓN

xlsfonts lista las fuentes disponibles en un servidor X que coinciden con el patrón dado. El carácter comodín "*" puede usarse para coincidir con cualquier secuencia de caracteres (incluida ninguna), y "?" para coincidir con cualquier carácter individual. Si no se proporciona ningún patrón, se asume "*".

Los caracteres "*" y "?" deben entrecomillarse para evitar que sean expandidos por el shell.

OPCIONES

-display host:dpy
Esta opción especifica el servidor X al que contactar.
-d host:dpy
Igual que -display host:dpy.
-l
Lista algunos atributos de la fuente en una línea además de su nombre.
-ll
Lista las propiedades de la fuente además de la salida de -l.
-lll
Lista las métricas de caracteres además de la salida de -ll.
-m
Esta opción indica que las listas largas también deben imprimir los límites mínimo y máximo de cada fuente.
-C
Esta opción indica que las listas deben usar varias columnas. Esto es lo mismo que -n 0.
-1
Esta opción indica que las listas deben usar una sola columna. Esto es lo mismo que -n 1.
-w ancho
Esta opción especifica el ancho en caracteres que se debe usar para determinar cuántas columnas imprimir. El valor predeterminado es 79.
-n columnas
Esta opción especifica el número de columnas a usar en la visualización de la salida. Por defecto, intentará ajustar tantas columnas de nombres de fuentes como sea posible en el número de caracteres especificado por el ancho -w.
-u
Esta opción indica que la salida debe dejarse sin ordenar.
-o
Esta opción indica que xlsfonts debe realizar una operación OpenFont (y QueryFont, si es apropiado) en lugar de ListFonts. Esto es útil si ListFonts o ListFontsWithInfo no logran listar una fuente conocida (como ocurre con algunos sistemas de fuentes escaladas).
-fn patrón
Esta opción especifica el patrón de nombre de fuente a coincidir.
-v
Esta opción indica que xlsfonts debe imprimir la versión del programa y salir.

VER TAMBIÉN

X(7), Xserver(1), xset(1), xfd(1), Convenciones de descripción de fuentes lógicas de X

ENTORNO

DISPLAY
DISPLAY debe establecerse para obtener el host y la pantalla predeterminados a usar.

ERRORES

Ejecutar ``xlsfonts -l'' puede bloquear su servidor X durante mucho tiempo. Esto es realmente un error de los servidores no preemptivos de un solo hilo, no de este programa.
