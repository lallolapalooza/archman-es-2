NOMBRE

xlyap - muestra gráficamente un array de exponentes de Lyapunov

SINOPSIS


xlyap [-BLps] [-W ancho] [-H alto] [-o nombre_archivo] [-a n] [-b n] [-w n] [-h n] [-i inicio_x] [-M n] [-R p] [-S n] [-D n] [-F cadena] [-f cadena] [-r n] [-O n] [-C n] [-c n] [-m n] [-x pos_x] [-y pos_y] [--fps] [--visual visual] [--window] [--root] [--window-id número]

DESCRIPCIÓN

xlyap genera y muestra gráficamente un array de exponentes de Lyapunov para una variedad de mapas no lineales periódicamente forzados de interés para la iteración.

OPCIONES

-random
Una buena opción para usar con xscreensaver: elige parámetros aleatorios de una lista incorporada.
-C n
Especifica el índice de color mínimo a usar para exponentes negativos.
-D n
Especifica el "dwell" o número de iteraciones sobre las que promediar para calcular el exponente de Lyapunov. Por defecto es 50.
-H n
Especifica la altura de la ventana. Por defecto es 256.
-L
Indica el uso de log(x) + log(y) en lugar de log(xy).
-M r
Especifica el valor real con el que comparar los valores de los exponentes para indexar en una rueda de colores. El valor por defecto es 1.0.
-O n
Especifica el índice de color mínimo a usar para exponentes positivos.
-R p
Especifica un forzado pseudoaleatorio con probabilidad p de usar el valor del parámetro 'a'.
-S n
Especifica el "settle" o número de iteraciones previas al inicio del cálculo del exponente de Lyapunov. Por defecto es 50.
-a r
Especifica el valor real a usar como valor mínimo del parámetro del eje horizontal. Por defecto es 2.0 para el mapa logístico.
-b n
Especifica el valor real a usar como valor mínimo del parámetro del eje vertical. Por defecto es 2.0 para el mapa logístico.
-c n
Selecciona una de las seis ruedas de colores diferentes a usar. La rueda de colores por defecto es una paleta arcoíris.
-F 10101010
Especifica la función de forzado "Función" a usar. El ejemplo anterior alternaría entre iterar los mapas del círculo y logístico. Un argumento de "-F 2323" alternaría entre los mapas logísticos izquierdo y derecho. Por defecto es usar solo el mapa especificado (ver la descripción de -m).
-f abbabaab
Especifica la función de forzado a usar. Por defecto es alternar entre el parámetro "a" y el parámetro "b".
-h r
Especifica el valor real a usar como rango sobre el cual varían los valores del parámetro vertical. Por defecto es 1.0.
-i r
Especifica el valor real de la condición inicial a usar. Por defecto es 0.65.
-m n
Selecciona entre los mapas no lineales disponibles del intervalo unitario. Un valor de 0 especifica el mapa logístico. Un valor de 1, el mapa del círculo. Un valor de 2, el logístico izquierdo. Un valor de 3, el logístico derecho. Un valor de 4, el logístico doble. Por defecto es 0, el mapa logístico.
-o nombre_archivo
Especifica el nombre del archivo de salida a usar. Si se proporciona la opción -o, este archivo se escribirá automáticamente al completar el dibujo. Si no se especifica, se usará el nombre de archivo por defecto lyap.out y solo se escribirá si se presionan las teclas 'f' o 'F' durante la ejecución. El formato del archivo de salida es PPM para color y PGM para monocromo. Los parámetros utilizados para calcular la imagen se incluyen como comentarios al principio del archivo de salida.
-p
Cambia los índices de color para exponentes negativos y positivos. Generalmente, hace que los exponentes negativos se muestren con más detalle, mientras oscurece y estrecha el rango de colores para los exponentes positivos. Esto se puede activar/desactivar durante la ejecución presionando la tecla 'p'.
-r n
Especifica el valor RGB máximo a usar. Por defecto es 65000.
-s n
Especifica la longitud del giro de la rueda de colores.
-v
Imprime los varios valores a usar y sale.
-w r
Especifica el valor real a usar como rango sobre el cual varían los valores del parámetro horizontal. Por defecto es 1.0.
--visual visual
Especifica qué visual usar. Los valores válidos son el nombre de una clase visual o el número de ID (decimal o hexadecimal) de un visual específico.
--window
Dibuja en una ventana recién creada. Esta es la opción por defecto.
--root
Dibuja en la ventana raíz.
--window-id número
Dibuja en la ventana especificada.

NOTAS

Durante la visualización, presionar cualquier botón del ratón permite seleccionar el área a investigar con el ratón. La esquina superior izquierda del área deseada es la ubicación del cursor cuando se presiona el botón. La esquina inferior derecha se especifica con el cursor cuando se suelta el botón.

El uso de las teclas bBeEfFkKjJmnrRsSwWxXqQ indica:

(<) Duplicar valor de dwell. (>) Reducir valor de dwell. ([) Duplicar valor de settle. (]) Reducir valor de settle. (B o b) Activar/desactivar la visualización de botones (E o e) Recalcular los índices de la rueda de colores usando un método diferente (F o f) Guardar la pantalla actual en un archivo de salida (aún no implementado) (H o h o ?) Mostrar mensaje de ayuda breve (i) Decrementar el intervalo entre bandas para el mapa de colores rayado. (I) Incrementar el intervalo entre bandas para el mapa de colores rayado. (K) Disminuir el valor contra el que se comparan los exponentes en 0.05. (J) Aumentar el valor contra el que se comparan los exponentes en 0.05. (M) Disminuir el valor contra el que se comparan los exponentes en 0.005. (N) Aumentar el valor contra el que se comparan los exponentes en 0.005. (m) Incrementar el índice del mapa, cambiando el mapa a iterar. (P o p) Alternar la visualización de exponentes positivos/negativos. (r) Redibujar la ventana usando los exponentes previamente calculados. (R) Redibujar la ventana usando los valores de dwell y/o settle recién establecidos. (S) Girar la rueda de colores (s) Reducir a la mitad la longitud del giro y girar la rueda de colores (u) Subir a la ventana justo anterior al zoom más reciente. (U) Subir completamente a la ventana original. (V o v) Mostrar los valores de varios parámetros actualmente en uso (W o w) Usar el siguiente mapa de colores (X o x) Limpiar ventana (Q o q) salir

AMBIENTE

DISPLAY
para obtener el host y el número de pantalla por defecto.
XENVIRONMENT
para obtener el nombre de un archivo de recursos que reemplaza los recursos globales almacenados en la propiedad RESOURCE_MANAGER.
XSCREENSAVER_WINDOW
El ID de la ventana a usar con --root.
