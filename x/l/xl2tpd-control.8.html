NOMBRE

xl2tpd-control - Utilidad de control de xl2tpd.

DESCRIPCIÓN

xl2tpd es una implementación del Protocolo de Túnel de Capa 2 (RFC 2661). L2TP permite tunelizar PPP sobre UDP. Algunos ISPs utilizan L2TP para tunelizar sesiones de usuario desde servidores de acceso telefónico (bancos de módems, DSLAMs ADSL) a servidores PPP de backend. Otra aplicación importante son las Redes Privadas Virtuales donde se utiliza el protocolo IPsec para asegurar la conexión L2TP (L2TP/IPsec, RFC 3193).

xl2tpd funciona abriendo un pseudo-tty para comunicarse con pppd. Se ejecuta completamente en el espacio de usuario pero soporta L2TP en modo núcleo.

xl2tpd soporta el seguimiento de referencias de SA de IPsec para permitir IPs internas superpuestas y NAT'ed por diferentes clientes (por ejemplo, todos los clientes que se conectan desde su IP interna de router Linksys 192.168.1.101) así como múltiples clientes detrás del mismo router NAT.

SINOPSIS

xl2tpd-control [-c RUTA] <COMANDO> <NOMBRE_DEL_TUNEL> [OPCIONES]

OPCIONES

-c
Esta opción especifica el archivo de control de xl2tpd.
-d
Esta opción habilita el modo de depuración.

COMANDOS

add-lac
Añade o modifica la configuración existente de LAC (Concentrador de Acceso L2TP). La configuración debe especificarse como opciones de comando en formato de pares <clave>=<valor>. Consulte las opciones disponibles en xl2tpd.conf(5).
connect-lac
Establece una nueva conexión a un LAC. El nombre de usuario y la contraseña para el túnel se pueden pasar como opciones de comando.
disconnect-lac
Desconecta el túnel.
remove-lac
Elimina la configuración existente de LAC. xl2tpd desconecta el túnel antes de eliminarlo.
add-lns
Añade o modifica la configuración existente de LNS (Servidor de Red L2TP).
remove-lns
Elimina la configuración existente de LNS.
status-lns
Comprueba el estado de LNS.
available
Comprueba la disponibilidad.
