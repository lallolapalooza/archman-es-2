XED(1) Manual de Comandos Generales XED(1)

NOMBRE

Xed - El Editor de Texto

SINOPSIS

xed [OPCIONES...] [FICHEROS...]

DESCRIPCIÓN

Xed es el editor de texto oficial del proyecto X-APPS, que tiene como objetivo proporcionar aplicaciones para los entornos de escritorio Cinnamon, MATE y Xfce. Aunque apunta a la simplicidad y facilidad de uso, Xed es un potente editor de texto de propósito general. Puede ser utilizado para crear y editar todo tipo de archivos de texto.

Xed presenta un sistema de plugins flexible que puede ser utilizado para añadir dinámicamente nuevas características avanzadas al propio Xed.

Esta página del manual documenta brevemente el comando xed.

OPCIONES

nombre-de-archivo(s)...
Especifica el archivo a abrir cuando se inicia xed. Si no se especifica, xed iniciará un archivo nuevo y en blanco con la etiqueta "Documento sin guardar". Se pueden cargar varios archivos si están separados por espacios. xed también soporta el manejo de archivos remotos.
--display=DISPLAY
Pantalla X a utilizar.
--encoding
Establece la codificación de caracteres a utilizar para abrir los archivos listados en la línea de comandos.
--new-window
Crea una nueva ventana de nivel superior en una instancia existente de xed.
--new-document
Crea un nuevo documento en una instancia existente de xed, en la última ventana de Xed que tuvo el foco.
+[num]
Para el primer archivo, va a la línea especificada por "num" (no inserte un espacio entre el signo "+" y el número). Si "num" falta, va a la última línea.
--list-encodings
Muestra la lista de valores posibles para la opción de codificación y sale
--version
Muestra información de la versión y sale
-?, -h, --help
Imprime las opciones estándar de la línea de comandos.
-w, --wait
Abre archivos y bloquea el proceso de xed.
--help-all
Imprime todas las opciones de la línea de comandos.

Este programa también acepta las opciones estándar de GTK.

EJEMPLOS

xed --encoding WINDOWS-1252 ftp://ftp.kernel.org/pub/linux/kernel/README

Abre el archivo README del servidor FTP de kernel.org utilizando la codificación de caracteres Windows-1252.

xed +156 http://www.some-website.com/

Abre la página web principal de some-website.com y salta a la línea 156.

xed --new-window ~/.bashrc ~/.bash_history

Abre los archivos .bashrc y .bash_history del usuario actual en una nueva ventana.

ERRORES

Si encuentra algún error, pueden ser reportados en:

http://github.com/linuxmint/xed/issues


VER TAMBIÉN

La documentación de Xed se puede encontrar en el menú "Ayuda", o presionando la tecla F1.
