subrutina xerbla (character*(*) srname, integer info)

XERBLA

Propósito:

!>
!> Esta es una versión especial de XERBLA para ser usada únicamente como parte
!> del programa de prueba para salidas de error de las rutinas LAPACK.
!> Se imprimen mensajes de error si INFO.NE.INFOT o si SRNAME.NE.SRNAMT,
!> donde INFOT y SRNAMT son valores almacenados en COMMON.
!>

Parámetros

SRNAME 
!>          SRNAME es CHARACTER*(*)
!>          El nombre de la subrutina que llama a XERBLA. Este nombre debe
!>          coincidir con la variable COMMON SRNAMT.
!>

INFO

!>          INFO es INTEGER
!>          El código de retorno de error de la subrutina que llama. INFO
!>          debe ser igual a la variable COMMON INFOT.
!>

Autor

Univ. of Tennessee

Univ. of California Berkeley

Univ. of Colorado Denver

NAG Ltd.

Detalles adicionales:

!>
!> Las siguientes variables se pasan a través de los bloques comunes INFOC y
!> SRNAMC:
!>
!>  INFOT   INTEGER      Código de retorno entero esperado
!>  NOUT    INTEGER      Número de unidad para imprimir mensajes de error
!>  OK      LOGICAL      Establecido en .TRUE. si INFO = INFOT y
!>                       SRNAME = SRNAMT, de lo contrario se establece en .FALSE.
!>  LERR    LOGICAL      Establecido en .TRUE., indicando que se llamó a XERBLA
!>  SRNAMT  CHARACTER*(*) Nombre esperado de la subrutina que llama
!>
