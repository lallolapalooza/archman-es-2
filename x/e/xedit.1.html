XEDIT(1) Manual de comandos generales XEDIT(1)

NOMBRE

xedit - editor de texto simple para X

SINTAXIS

xedit [ opción-toolkit ... ] [ nombre-archivo ... ]

DESCRIPCIÓN

Xedit proporciona una ventana que consta de las siguientes cuatro áreas:

Sección de Comandos
Un conjunto de comandos que le permiten salir de xedit, guardar el archivo o cargar un nuevo archivo en la ventana de edición.
Ventana de Mensaje
Muestra los mensajes de xedit. Además, esta ventana también se puede utilizar como un bloc de notas.
Visualización del Nombre de Archivo
Muestra el nombre del archivo que se está editando actualmente y si este archivo es de Lectura-Escritura o de Solo Lectura.
Ventana de Edición
Muestra el texto del archivo que está editando o creando.

OPCIONES

Xedit acepta todas las opciones de línea de comandos estándar del Kit de herramientas X (consulte X(7)). El orden de las opciones de línea de comandos no es importante.

nombre-archivo
Especifica los archivos que se cargarán al inicio. Este es el archivo que se editará. Si no se especifica un archivo, xedit le permite cargar archivos o crear nuevos archivos después de que haya comenzado.

MODO DE EDICIÓN DE LÍNEA

El modo de edición de línea habilita varios comandos de acceso directo para buscar y reemplazar texto en un búfer de xedit. Los comandos del modo de edición de línea tienen el formato: 

[número-línea[,número-línea]]comando[parámetros]

El número de línea puede especificarse como:

.
La línea de texto actual.
$
La última línea del archivo.
número
El número de línea literal.
- o ^
La línea anterior. Equivalente a -1.
-número o ^número
La línea actual menos número.
+
La línea siguiente. Equivalente a +1.
+número
La línea actual más número.
, o %
Desde la primera hasta la última línea. Equivalente a 1,$.
;
Desde la línea actual hasta la última línea. Equivalente a .,$.

El comando puede especificarse como:

s
Sustituir texto en las líneas especificadas.
/re/
Buscar hacia adelante el patrón de expresión regular re.
?re?
Buscar hacia atrás el patrón de expresión regular re.

Los parámetros pueden especificarse como:

/re/
Funciona como parámetro para i o como comando.
/re/texto/
Buscar hacia adelante re y sustituir por texto.

Las opciones pueden seguir o ser parámetros, los valores conocidos son:

i
Búsqueda insensible a mayúsculas/minúsculas.
g
Coincidencia Global al reemplazar texto. A menos que se especifique, solo se reemplazará la n-ésima coincidencia, que por defecto es 1.
c
Confirmar antes de reemplazar texto.
número
Reemplazar solo la ocurrencia referenciada por número.

Los comandos aceptan algunas variaciones, ejemplos: 

/patrón/i
i/patrón/
i/patrón
Buscar hacia adelante patrón. 
,sc/patrón/texto
,sc/patrón/texto/
,s/patrón/texto/c
Buscar en todo el búfer y pedir confirmación para reemplazar patrón por texto. 
,s/patrón/texto/número
Reemplazar la coincidencia número en la línea de texto. Si no se especifica, por defecto es la primera ocurrencia.

Al buscar texto, presione <Enter> para ir a la siguiente coincidencia. Al reemplazar texto interactivamente, presione y o Y para aceptar el cambio, y n o N para ignorarlo e ir a la siguiente coincidencia.
