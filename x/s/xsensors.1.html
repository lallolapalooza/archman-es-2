XSENSORS(1) Comandos de usuario XSENSORS(1)

NOMBRE

xsensors - muestra información de sensores de hardware como una lectura gráfica.

SINOPSIS

xsensors [OPCIÓN]...

DESCRIPCIÓN

Visualiza la salida de la biblioteca libsensors sobre la salud del hardware en una lectura gráfica.

OPCIONES

-f
muestra todas las temperaturas en Fahrenheit.
-c nombre_archivo
especifica el archivo de configuración de libsensors.
-i
especifica el archivo de imagen a usar como tema gráfico.
-t tiempo
especifica el intervalo de actualización en segundos.
-v
muestra el número de versión.

CONFIGURACIÓN

Para encontrar los módulos del kernel necesarios para que xsensors funcione, ejecuta el comando sensors-detect como superusuario y sigue las instrucciones en pantalla; puede ser necesario reiniciar. El comando sensors-detect es proporcionado por el paquete lm-sensors.

ARCHIVOS

/usr/share/xsensors/theme.tiff: el tema gráfico por defecto.

/etc/sensors3.conf: el archivo de configuración por defecto.
