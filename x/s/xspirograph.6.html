NOMBRE

xspirograph - simula la rotación de un disco dentro de un aro circular

SINOPSIS

xspirograph [--display host:display.screen] [--window] [--root] [--window-id número][--install] [--visual visual] [--delay segundos] [--subdelay microsegundos] [--layers entero] [--alwaysfinish] [--noalwaysfinish] [--fps]

DESCRIPCIÓN

xspirograph dibuja patrones como los hechos por un espirograph, es decir, la curva trazada por un punto en un disco circular que gira en el interior de un aro circular hueco.

OPCIONES

xspirograph acepta las siguientes opciones:

--window
Dibuja en una ventana recién creada. Esta es la opción predeterminada.
--root
Dibuja en la ventana raíz.
--window-id número
Dibuja en la ventana especificada.
--install
Instala un mapa de colores privado para la ventana.
--visual visual
Especifica qué visual usar. Los valores legales son el nombre de una clase visual o el número de identificación (decimal o hexadecimal) de un visual específico.
--delay secs
El retraso entre que se termina un dibujo y se comienza el siguiente. Predeterminado: 5 segundos.
--subdelay usec
El tiempo de espera entre cada cien dibujos de línea. Usa esto si quieres ver cómo se forma el patrón. Predeterminado: 0.
--alwaysfinish --noalwaysfinish
Si quieres que cada patrón se dibuje hasta que termine, especifica lo primero. De lo contrario, se detendrán después de un número determinado de iteraciones. Predeterminado: no.
--layers entero
Número de pares de patrones para dibujar entre cada borrado.

AMBIENTE

DISPLAY
para obtener el host y el número de pantalla predeterminados.
XENVIRONMENT
para obtener el nombre de un archivo de recursos que anula los recursos globales almacenados en la propiedad RESOURCE_MANAGER.
XSCREENSAVER_WINDOW
El ID de ventana a usar con --root.
