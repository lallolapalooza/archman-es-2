NOMBRE

xscreensaver-text - imprime texto en stdout, para uso por los salvapantallas.

SINOPSIS

xscreensaver-text [--verbose] [--columns N] [--lines N] [--latin1] [--date] [--text CADENA] [--file RUTA] [--program CMD] [--url URL]

DESCRIPCIÓN

El script xscreensaver-text imprime texto para ser utilizado por varios salvapantallas, según las opciones configuradas en el archivo ~/.xscreensaver. Puede volcar el contenido de un archivo, ejecutar un programa o cargar una URL. El texto se reforma y ajusta según sea apropiado.

OPCIONES

xscreensaver-text acepta las siguientes opciones:

--verbose o --v
Imprime diagnósticos en stderr. Múltiples interruptores -v aumentan la cantidad de salida.
--columns N o --cols N
Dónde ajustar las líneas; el valor predeterminado son 72 columnas.
--lines N
Trunca la salida a como máximo este número de líneas. Predeterminado: ilimitado.
--latin1
Convierte cualquier carácter UTF-8 en la entrada a su equivalente Latin1 más cercano para la salida.

Las opciones de línea de comandos pueden usarse para anular la configuración del archivo ~/.xscreensaver:

--date
Imprime el nombre del host y la hora actual.
--text CADENA
Imprime el texto dado. Puede contener secuencias de escape % según strftime(2).
--file RUTA
Imprime el contenido del archivo dado, reformateándolo según las otras opciones.
--program CMD
Ejecuta el programa dado e imprime su salida, reformateándola según las otras opciones.
--url URL
Descarga e imprime el contenido de la página web. Si contiene HTML, RSS o Atom, se convertirá a texto plano. Esto vuelve a descargar el documento cada vez que se ejecuta.

ENTORNO

HTTP_PROXY, HTTPS_PROXY, http_proxy, o https_proxy
para obtener el host y puerto proxy predeterminados.

ERRORES

Las URL deberían ser cacheadas, usar "If-Modified-Since" y obedecer "Expires".
