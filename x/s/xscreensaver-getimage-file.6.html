NOMBRE

xscreensaver-getimage-file - selecciona un archivo de imagen aleatorio para usarlo en protectores de pantalla

SINOPSIS

xscreensaver-getimage-file [--verbose] [--no-cache] [--flush-caches] directorio-o-URL

DESCRIPCIÓN

El programa xscreensaver-getimage-file es un programa auxiliar para los hacks de xscreensaver que manipulan imágenes. Es invocado por xscreensaver-getimage(6) según sea necesario.

Imprime el nombre de un archivo de imagen seleccionado aleatoriamente. El directorio se busca recursivamente. Se excluyen los archivos que no son imágenes y las imágenes de menos de 500x500.

El directorio también puede ser la URL de un feed RSS/Atom. Las imágenes incluidas se descargarán y almacenarán en caché localmente.

El contenido del directorio se almacena en caché, para mejorar el rendimiento. La caché se regenera si han pasado 3 horas.

OPCIONES

xscreensaver-getimage-file acepta las siguientes opciones:

--verbose
Imprime diagnósticos.
--no-cache
Ignora la caché al buscar imágenes. Esto puede ser lento.
--flush-cache
Descarta todas las cachés inmediatamente. Se regenerarán según sea necesario.
directorio-o-URL
Si es una ruta de archivo, se buscarán imágenes de forma recursiva.

Si es una URL, debe ser un feed RSS o Atom, o una página HTML cuyos metadatos enlacen a su feed. Todas las imágenes del feed se descargarán a una caché local. La URL se consultará periódicamente, descargando cualquier imagen nueva y eliminando las caducadas.

ARCHIVOS

Dependiendo de su sistema operativo, la caché de nombres de archivo será una de las siguientes:

        $HOME/.cache/xscreensaver/xscreensaver-getimage.cache
        $HOME/tmp/.xscreensaver-getimage.cache
        $HOME/.xscreensaver-getimage.cache
        $HOME/Library/Caches/org.jwz.xscreensaver.getimage.cache

Las imágenes de los feeds se descargarán y almacenarán en caché en una de las siguientes ubicaciones:

        $HOME/.cache/xscreensaver/SUBDIR/
        $HOME/tmp/.xscreensaver-feeds/SUBDIR/
        $HOME/.xscreensaver-feeds/SUBDIR/
        $HOME/Library/Caches/org.jwz.xscreensaver.feeds/SUBDIR/
