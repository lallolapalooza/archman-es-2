xscreensaver-settings(1) Manual de Comandos Generales xscreensaver-settings(1)

NOMBRE

xscreensaver-settings - configura y controla el demonio xscreensaver

SINOPSIS

xscreensaver-settings [--display host:display.screen] [--debug]

DESCRIPCIÓN

El programa xscreensaver-settings es una interfaz gráfica para configurar los parámetros utilizados por el demonio xscreensaver(1). Es una herramienta para editar el archivo ~/.xscreensaver y para previsualizar los diversos modos de visualización.

La ventana principal consta de una barra de menú y dos páginas con pestañas. La primera página es para editar la lista de demos, y la segunda es para editar varios otros parámetros del salvapantallas.

COMANDOS DEL MENÚ

Todos estos comandos se encuentran en los menús Archivo o Ayuda:

PANTALLA EN NEGRO AHORA
Activa el demonio de fondo xscreensaver, que ejecutará un demo al azar. Esto es lo mismo que ejecutar xscreensaver-command(1) con la opción --activate.
BLOQUEAR PANTALLA AHORA
Al igual que PANTALLA EN NEGRO AHORA, excepto que la pantalla también se bloqueará (incluso si no está configurada para bloquearse todo el tiempo). Esto es lo mismo que ejecutar xscreensaver-command(1) con la opción --lock.
DETENER DEMONIO
Si el demonio xscreensaver se está ejecutando en esta pantalla, deténgalo. Esto es lo mismo que ejecutar xscreensaver-command(1) con la opción --exit.
REINICIAR DEMONIO
Si el demonio xscreensaver se está ejecutando en esta pantalla, deténgalo. Luego, ejecútelo de nuevo. Esto es lo mismo que hacer "xscreensaver-command --exit" seguido de "xscreensaver".

Tenga en cuenta que no es lo mismo que hacer "xscreensaver-command --restart".

SALIR
Sale del programa xscreensaver-settings (este programa) sin afectar al demonio de fondo xscreensaver, si lo hubiera.
ACERCA DE...
Muestra el número de versión de este programa, xscreensaver-settings.
DOCUMENTACIÓN...
Abre un navegador web en la página web de XScreenSaver, donde puede encontrar copias en línea de los manuales de xscreensaver(1), xscreensaver-settings(1) y xscreensaver-command(1).

PESTAÑA MODOS DE PANTALLA

Esta página contiene una lista de los nombres de los diversos modos de pantalla, un área de previsualización y algunos campos que le permiten configurar el comportamiento del salvapantallas.

Modo

Este menú de opciones controla el comportamiento de activación del salvapantallas. Las opciones son:

DESACTIVAR SALVAPANTALLAS
No poner la pantalla en negro nunca y no permitir que el monitor se apague.
SOLO PANTALLA EN NEGRO
Al poner la pantalla en negro, simplemente se vuelve negra: no ejecuta ninguna gráfica.
SOLO UN SALVAPANTALLAS
Al poner la pantalla en negro, usa siempre un modo de visualización particular (el seleccionado en la lista).
SALVAPANTALLAS ALEATORIO
Al poner la pantalla en negro, selecciona un modo de visualización aleatorio de entre los que están activados y son aplicables. Si hay varios monitores conectados, ejecuta un modo de visualización diferente en cada uno. Este es el valor predeterminado.
ALEATORIO MISMO SALVAPANTALLAS
Esto es igual que SALVAPANTALLAS ALEATORIO, excepto que el mismo modo de visualización seleccionado aleatoriamente se ejecutará en todos los monitores, en lugar de uno diferente en cada uno.

LISTA DE DEMOS

Hacer doble clic en la lista de la izquierda le permitirá probar el demo indicado. La pantalla se volverá negra y el programa se ejecutará en modo de pantalla completa, tal como lo haría si el demonio xscreensaver lo hubiera iniciado. Hacer clic con el ratón nuevamente detendrá el demo y volverá a mostrar la pantalla.

Hacer clic una sola vez en la lista lo ejecutará en la pequeña ventana de previsualización de la derecha. (Pero ¡cuidado!: muchos de los modos de visualización se comportan de manera algo diferente cuando se ejecutan en modo de pantalla completa, por lo que la vista reducida podría no dar una impresión precisa).

Cuando Modo está configurado como SALVAPANTALLAS ALEATORIO, cada nombre en la lista tiene una casilla de verificación al lado: esto controla si este modo de visualización está habilitado. Si no está marcado, entonces ese modo no será elegido. (Aunque aún puede ejecutarlo explícitamente haciendo doble clic en su nombre).

Si la lista tiene el foco, puede escribir cualquier carácter para buscar dentro de ella.

BOTONES DE FLECHA

Debajo de la lista hay un par de flechas hacia arriba y hacia abajo. Hacer clic en la flecha hacia abajo seleccionará el siguiente elemento en la lista, y luego lo ejecutará en modo de pantalla completa, como si hubiera hecho doble clic en él. La flecha hacia arriba hace lo contrario. Esto es solo un atajo para probar todos los modos de visualización en orden.

PANTALLA EN NEGRO DESPUÉS DE

Después de que el usuario ha estado inactivo durante este tiempo, el demonio xscreensaver pondrá la pantalla en negro.

CICLO DESPUÉS DE

Después de que el salvapantallas se ha estado ejecutando durante este tiempo, el demo gráfico que se está ejecutando actualmente se detendrá y se iniciará uno nuevo. Si esto es 0, entonces el demo gráfico nunca cambiará: solo se ejecutará un demo hasta que el salvapantallas se desactive por la actividad del usuario.

Si hay varias pantallas, los salvapantallas se escalonan ligeramente para que, si bien todos cambian cada ciclo minutos, no todos cambian al mismo tiempo.

BLOQUEAR PANTALLA

Cuando esto está marcado, la pantalla se bloqueará cuando se active.

BLOQUEAR PANTALLA DESPUÉS DE

Esto controla la duración del "período de gracia" entre cuando se activa el salvapantallas y cuando la pantalla se bloquea. Por ejemplo, si esto es 5 minutos y PANTALLA EN NEGRO DESPUÉS DE es 10 minutos, entonces después de 10 minutos, la pantalla se pondría en negro. Si hubiera actividad del usuario a los 12 minutos, no se requeriría contraseña para volver a mostrar la pantalla. Pero, si hubiera actividad del usuario a los 15 minutos o más tarde (es decir, BLOQUEAR PANTALLA DESPUÉS DE minutos después de la activación), entonces se requeriría una contraseña. El valor predeterminado es 0, lo que significa que si el bloqueo está habilitado, se requerirá una contraseña tan pronto como la pantalla se ponga en negro.

PREVISUALIZACIÓN

Este botón, debajo de la pequeña ventana de previsualización, ejecuta el demo en modo de pantalla completa para que pueda probarlo. Esto es lo mismo que sucede cuando hace doble clic en un elemento de la lista. Haga clic con el ratón para descartar la previsualización de pantalla completa.

CONFIGURACIÓN

Este botón mostrará un cuadro de diálogo donde puede configurar los ajustes específicos del modo de pantalla seleccionado en la lista.

CUADRO DE DIÁLOGO DE CONFIGURACIÓN

Cuando hace clic en el botón Configuración en la pestaña Modos de pantalla, aparecerá un cuadro de diálogo de configuración que le permite personalizar los ajustes del modo de pantalla seleccionado. Cada modo de pantalla tiene su propio conjunto personalizado de configuraciones co

Pestaña AVANZADA

Esta pestaña te permite cambiar varias configuraciones utilizadas por el propio demonio xscreensaver, así como algunas opciones globales compartidas por todos los modos de visualización.

Manipulación de Imágenes

Algunos de los trucos gráficos manipulan imágenes. Estas configuraciones controlan de dónde provienen esas imágenes fuente. Los salvapantallas cargan imágenes ejecutando los programas xscreensaver-getimage(6) y xscreensaver-getimage-file(6).

Capturar Imágenes del Escritorio
Si esta opción está seleccionada, los salvapantallas tienen permitido manipular la imagen del escritorio, es decir, un modo de visualización podría dibujar una imagen de tu escritorio derritiéndose, o distorsionándose de alguna manera. Los paranoicos de la seguridad podrían querer deshabilitar esta opción, porque si está configurada, significa que las ventanas en tu escritorio serán ocasionalmente visibles mientras tu pantalla esté bloqueada. Otros no podrán *hacer* nada, pero podrán *ver* lo que sea que hayas dejado en tu pantalla.
Capturar Fotogramas de Video
Si tu sistema tiene una cámara u otra entrada de video, seleccionar esta opción puede permitir que los modos de manipulación de imágenes capturen un fotograma de video para operar.
Elegir Imagen Aleatoria
Si esta opción está configurada, los modos de manipulación de imágenes seleccionarán un archivo de imagen aleatorio para operar, de la fuente especificada. Esa fuente puede ser un directorio local, que se buscará recursivamente en busca de imágenes. O puede ser la URL de un feed RSS o Atom (por ejemplo, una galería de Flickr), en cuyo caso se seleccionará una imagen aleatoria de ese feed en su lugar. El contenido del feed se almacenará en caché localmente y se actualizará periódicamente según sea necesario.

Si se seleccionan más de una de las opciones relacionadas con imágenes anteriores, se elegirá una al azar. Si ninguna de ellas está seleccionada, se usará en su lugar una imagen de barras de color de video.

Manipulación de Texto

Algunos de los modos de visualización muestran y manipulan texto. Las siguientes opciones controlan cómo se genera ese texto. Los salvapantallas cargan texto ejecutando el programa xscreensaver-text(6).

Nombre del Host y Hora
Si esta casilla está seleccionada, el texto utilizado por los salvapantallas será el nombre del host local, la versión del SO, la fecha, la hora y la carga del sistema.
Texto
Si esta casilla está seleccionada, se utilizará el texto literal escrito en el campo a su derecha. Si contiene secuencias de escape %, se expandirán según strftime(2).
Archivo de Texto
Si esta casilla está seleccionada, se mostrará el contenido del archivo correspondiente.
Programa
Si esta casilla está seleccionada, se ejecutará el programa dado, repetidamente, y se mostrará su salida.
URL
Si esta casilla está seleccionada, la página web dada se descargará y mostrará repetidamente. Si el documento contiene HTML, RSS o Atom, primero se convertirá a texto plano.

Nota: esto vuelve a descargar el documento cada vez que el salvapantallas se queda sin texto, por lo que probablemente esté accediendo a ese servidor web varias veces por minuto.

Configuraciones de Administración de Energía

Estas configuraciones controlan si y cuándo tu monitor se apaga.

Administración de Energía Habilitada
Si el monitor debe apagarse después de un período de inactividad.

Si esta opción está atenuada, significa que tu servidor X no soporta la extensión XDPMS, y por lo tanto, el control sobre el estado de energía del monitor no está disponible.

Espera Después de
Si se selecciona Administración de Energía Habilitada, el monitor se pondrá negro después de este tiempo de inactividad. (Las demostraciones gráficas también se detendrán).
Suspender Después de
Si se selecciona Administración de Energía Habilitada, el monitor entrará en modo de ahorro de energía después de este tiempo de inactividad. Esta duración debe ser mayor o igual a Espera.
Apagar Después de
Si se selecciona Administración de Energía Habilitada, el monitor se apagará completamente después de este tiempo de inactividad. Esta duración debe ser mayor o igual a Suspender.
Apagado Rápido en Modo Solo Negro
Si el modo de visualización está configurado como Solo Pantalla Negra y esta opción está marcada, el monitor se apagará inmediatamente al oscurecer la pantalla, independientemente de las otras configuraciones de administración de energía. De esta manera, los temporizadores de inactividad de administración de energía pueden ser completamente deshabilitados, pero la pantalla se apagará cuando esté negra.

Oscurecimiento

Estas opciones controlan cómo la pantalla se desvanece a negro o desde negro cuando un salvapantallas comienza o termina.

Desvanecer a Negro al Oscurecer
Si está seleccionado, al activarse el salvapantallas, el contenido actual de la pantalla se desvanecerá a negro en lugar de simplemente apagarse.
Desvanecer desde Negro al Desbloquear
Lo opuesto: si está seleccionado, al desactivarse el salvapantallas, el contenido original de la pantalla se desvanecerá desde negro en lugar de aparecer inmediatamente. Esto solo se hace si Desvanecer a Negro también está seleccionado.
Duración del Desvanecimiento
Cuando se seleccionan el desvanecimiento o el desvanecimiento inverso, esto controla cuánto tiempo tomará el desvanecimiento.

Tema

Este menú de opciones enumera los esquemas de color disponibles para usar en el diálogo de desbloqueo.

Hay más configuraciones disponibles que estas, pero estas son las más comúnmente usadas; consulta el manual de xscreensaver(1) para otros parámetros que se pueden configurar editando el archivo ~/.xscreensaver, o la base de datos de recursos X.

OPCIONES DE LÍNEA DE COMANDOS

xscreensaver-settings acepta las siguientes opciones de línea de comandos.

--display host:display.screen
La pantalla X a usar. El programa xscreensaver-settings abrirá su ventana en esa pantalla, y también controlará el demonio xscreensaver que está gestionando esa misma pantalla.
--debug
Causa que se impriman muchos diagnósticos en stderr.

Los procesos xscreensaver y xscreensaver-settings deben ejecutarse en la misma máquina, o al menos, en dos máquinas que compartan un sistema de archivos. Cuando xscreensaver-settings escribe una nueva versión del archivo ~/.xscreensaver, xscreensaver necesita ver ese mismo archivo, o no funcionará.

ENTORNO

DISPLAY
para obtener el host y número de pantalla predeterminados.
PATH
para encontrar los subprogramas a ejecutar. Sin embargo, ten en cuenta que los subprogramas son lanzados por xscreensaver-settings para su visualización en el panel de previsualización en línea, pero por el demonio xscreensaver cuando se ejecuta a pantalla completa, por lo que la configuración de $PATH en ambos procesos es importante.
HOME
para el directorio en el que leer y escribir el archivo .xscreensaver.
XENVIRONMENT
para obtener el nombre de un archivo de recursos que anula los recursos globales almacenados en la propiedad RESOURCE_MANAGER.
HTTP_PROXY, HTTPS_PROXY, http_proxy, o https_proxy
para obtener el host y puerto del proxy predeterminados.

NAME

xscreensaver-settings - configuration dialog for the xscreensaver daemon.

SYNOPSIS

xscreensaver-settings

DESCRIPTION

The xscreensaver-settings program is a graphical tool that allows you to configure the behaviour of the xscreensaver daemon. You can use it to choose which screen saver modes to enable, how long the screen should be blank before the screen saver starts, and how long the screen saver should be idle before locking the screen. It also allows you to configure the behaviour of individual screen saver modes.

MENU COMMANDS

The xscreensaver-settings program has a menu bar with the following options:

File
Exit
Exits the program.
Edit
Preferences
Opens the Preferences dialog.
Help
About
Displays information about the program.
Manual
Opens the manual page for xscreensaver.

DISPLAY MODES TAB

This tab allows you to select which screen saver modes are available and to set the order in which they appear in the screen saver list. You can also set the timeout and cycle values for the screen saver.

Mode
The name of the screen saver mode.
Author
The author of the screen saver mode.
Enabled
Check this box to enable the screen saver mode.
Priority
A number indicating the priority of the screen saver mode. Higher numbers mean higher priority.
Timeout
The amount of time (in seconds) after which the screen saver will start.
Cycle
The amount of time (in seconds) after which the screen saver will change to a different mode.

SETTINGS DIALOG

This dialog allows you to configure the general settings for the xscreensaver daemon.

Mode
The screen saver mode to use.
Timeout
The amount of time (in minutes) after which the screen saver will start.
Cycle
The amount of time (in minutes) after which the screen saver will change to a different mode.
Lock screen after
The amount of time (in minutes) after which the screen will be locked.
Random screen saver
If checked, a random screen saver will be chosen each time the screen saver starts.
Show clock
If checked, a clock will be displayed on the screen saver.

ADVANCED TAB

This tab allows you to configure advanced settings for the xscreensaver daemon.

Demo mode
If checked, the screen saver will run in demo mode, showing all available screen saver modes.
Root window mode
The mode to use for the root window background.
Blank mode
The mode to use for blanking the screen.

COMMAND-LINE OPTIONS

xscreensaver-settings accepts the following command-line options:

-display <display>
Specifies the X display to use.
-h, --help
Show help message.
-v, --version
Show version information.

ENVIRONMENT

The following environment variables are used by xscreensaver-settings:

DISPLAY
The X display to connect to.

UPGRADES

When upgrading from a previous version of xscreensaver, you may want to delete your ~/.xscreensaver file to ensure that all of the new options are recognized.
