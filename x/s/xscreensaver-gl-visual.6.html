NOMBRE

xscreensaver-gl-visual - averiguar qué visual de X usar para programas GL

SINOPSIS

xscreensaver-gl-visual [--display host:display.screen]

DESCRIPCIÓN

Este programa imprime el ID del visual que debe usarse para el correcto funcionamiento de los programas OpenGL. Este programa solo existe para que el demonio xscreensaver(1) no necesite enlazarse a la biblioteca OpenGL.

ENTORNO

DISPLAY
para obtener el host, display y número de pantalla predeterminados.

VER TAMBIÉN

X(1), xdpyinfo(1), xglinfo(1), glxinfo(1), glxdpyinfo(1), xscreensaver(1), xscreensaver-settings(1), xscreensaver-command(1)
