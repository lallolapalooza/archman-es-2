XSET(1) Manual de comandos generales XSET(1)

NOMBRE

xset - utilidad de preferencias del usuario para X

SINOPSIS

xset [-display display]
[-b] [b {on|off}] [b [volumen [tono [duración]]]]
[-bc] [bc]
[-c] [c {on|off}] [c [volumen]]
[+dpms] [-dpms]
[dpms standby [ suspend [ off]]]
[dpms force {standby|suspend|off|on}]
[fp=lista_rutas] [-fp=lista_rutas] [+fp=lista_rutas] [fp-lista_rutas] [fp+lista_rutas]
[fp default] [fp rehash]
[-led [entero|named indicador]] [led [entero|named indicador]]
[led {on|off}]
[mouse [mult_acel[/div_acel] [umbral]]] [mouse default]
[p píxel color]
[-r [keycode]] [r [keycode]] [r {on|off}] [r rate retraso [tasa]]
[s [longitud [período]]] [s {blank|noblank}]
[s {expose|noexpose}] [s {on|off}] [s default] [s activate] [s reset]
[q]
[-version]

DESCRIPCIÓN

Este programa se utiliza para establecer varias opciones de preferencia del usuario de la pantalla.

OPCIONES

-display display
Esta opción especifica el servidor a utilizar; véase X(7).
b
La opción b controla el volumen, tono y duración del sonido de alarma. Esta opción acepta hasta tres parámetros numéricos, un guion precedente (-), o una bandera 'on/off'. Si no se proporcionan parámetros, o se utiliza la bandera 'on', se usarán los valores predeterminados del sistema. Si se proporcionan el guion o 'off', la alarma se desactivará. Si solo se proporciona un parámetro numérico, el volumen de la alarma se establecerá a ese valor, como un porcentaje de su máximo. De manera similar, el segundo parámetro numérico especifica el tono de la alarma, en hercios, y el tercer parámetro numérico especifica la duración en milisegundos. Tenga en cuenta que no todo el hardware puede variar las características de la alarma. El servidor X establecerá las características de la alarma lo más cerca posible a las especificaciones del usuario.
bc
La opción bc controla el modo de compatibilidad con errores (bug compatibility) en el servidor, si es posible; un guion precedente (-) deshabilita el modo, de lo contrario el modo se habilita. Varios clientes pre-R4 pasan valores ilegales en algunas solicitudes de protocolo, y los servidores pre-R4 no generaron errores correctamente en estos casos. Dichos clientes, cuando se ejecutan contra un servidor R4, terminarán de forma anormal o fallarán de otra manera al operar correctamente. El modo de compatibilidad con errores reintroduce explícitamente ciertos errores en el servidor X, de modo que muchos de dichos clientes aún pueden ejecutarse. Este modo debe usarse con cuidado; el desarrollo de aplicaciones nuevas debe hacerse con este modo deshabilitado. El servidor debe soportar la extensión de protocolo MIT-SUNDRY-NONSTANDARD para que esta opción funcione.
c
La opción c controla el clic de teclas. Esta opción puede tomar un valor opcional, un guion precedente (-), o una bandera 'on/off'. Si no se proporciona parámetro o se usa la bandera 'on', se utilizarán los valores predeterminados del sistema. Si se utiliza el guion o la bandera 'off', el clic de teclas se deshabilitará. Si se proporciona un valor de 0 a 100, se utiliza para indicar el volumen, como un porcentaje del máximo. El servidor X establecerá el volumen al valor más cercano que el hardware pueda soportar.
-dpms
La opción -dpms deshabilita las funciones de Señalización de Gestión de Energía de Pantalla (DPMS).
+dpms
La opción +dpms habilita las funciones de Señalización de Gestión de Energía de Pantalla (DPMS).
dpms flags...
La opción dpms permite establecer los parámetros de Señalización de Gestión de Energía de Pantalla (DPMS). La opción puede tomar hasta tres valores numéricos, o la bandera `force' seguida de un estado DPMS. Las banderas `force' fuerzan al servidor a cambiar inmediatamente al estado DPMS especificado. El estado DPMS puede ser uno de `standby', `suspend', `off', o `on'. Cuando se proporcionan valores numéricos, establecen el período de inactividad (en unidades de segundos) antes de que se activen los tres modos. El primer valor proporcionado es para el modo `standby', el segundo es para el modo `suspend', y el tercero es para el modo `off'. Establecer estos valores habilita implícitamente las características DPMS. Un valor de cero deshabilita un modo particular.
fp= ruta,...
El comando fp= establece la ruta de fuentes a las entradas dadas en el argumento de ruta. Las entradas son interpretadas por el servidor, no por el cliente. Típicamente son nombres de directorios o nombres de servidores de fuentes, pero la interpretación depende del servidor.
fp default
El argumento default hace que la ruta de fuentes se restablezca a la predeterminada del servidor.
fp rehash
El argumento rehash restablece la ruta de fuentes a su valor actual, provocando que el servidor relea las bases de datos de fuentes en la ruta de fuentes actual. Esto generalmente solo se usa al agregar nuevas fuentes a un directorio de fuentes (después de ejecutar mkfontdir para recrear la base de datos de fuentes).
-fp o fp-
Las opciones -fp y fp- eliminan elementos de la ruta de fuentes actual. Deben ir seguidas de una lista de entradas separadas por comas.
+fp o fp+
Estas opciones +fp y fp+ anteponen y añaden elementos a la ruta de fuentes actual, respectivamente. Deben ir seguidas de una lista de entradas separadas por comas.
led
La opción led controla los LEDs del teclado. Controla el encendido o apagado de uno o todos los LEDs. Acepta un entero opcional, un guion precedente (-) o una bandera 'on/off'. Si no se proporciona parámetro o se usa la bandera 'on', todos los LEDs se encenderán. Si se proporciona un guion precedente o la bandera 'off', todos los LEDs se apagarán. Si se proporciona un valor entre 1 y 32, ese LED se encenderá o apagará dependiendo de la existencia de un guion precedente. ``xset led 3'' encendería el led #3. ``xset -led 3'' lo apagaría. Los valores de LED particulares pueden referirse a diferentes LEDs en hardware diferente. Si el servidor X soporta la extensión XKEYBOARD (XKB), los LEDs pueden ser referenciados por el nombre del indicador XKB especificando la palabra clave `named' y el nombre del indicador. Por ejemplo, para encender el LED de Bloq Desplazamiento:
xset led named "Scroll Lock"
mouse
La opción m controla los parámetros del ratón; puede abreviarse como 'm'. Por supuesto, se aplica a la mayoría de los dispositivos señaladores, no solo a los ratones. Los parámetros para el dispositivo señalador son `aceleración' y `umbral'. La aceleración se puede especificar como un entero, o como una fracción simple. El umbral es solo un entero. La configuración se aplica a todos los dispositivos señaladores conectados. xinput(1) debe usarse si necesita configuraciones específicas del dispositivo.

Por defecto, el puntero (la representación en pantalla del dispositivo señalador) irá `aceleración' veces más rápido cuando el dispositivo se mueva más de `umbral' mickeys (es decir, píxeles potenciales) en 10 ms, incluyendo un pequeño rango de transición. De esta manera, el dispositivo señalador se puede usar para alineación precisa cuando se mueve lentamente, y aún así se puede configurar para recorrer la pantalla con un movimiento rápido de muñeca cuando se desee. Uno o ambos parámetros para la opción m pueden omitirse, pero si solo se proporciona uno, se interpretarán como la aceleración. Si no se proporcionan parámetros o se usa la bandera 'default', se establecerán los valores predeterminados del sistema.

Si se proporciona el parámetro `umbral' y es 0, el parámetro `aceleración' se utilizará en el exponente de una fórmula más natural y continua, dando un control preciso para el movimiento lento pero un gran alcance para el movimiento rápido, y una transición progresiva para los movimientos intermedios. El valor de `aceleración' recomendado en este caso es de 3/2 a 3, pero no se limita a ese rango.

En el servidor X.org X Server 1.6 y versiones posteriores, el comportamiento descrito hasta ahora está vinculado al perfil predeterminado. Existen otros perfiles (es decir, funciones que determinan la aceleración del puntero a partir de la velocidad del dispositivo) y configuraciones adicionales, por lo que la descripción anterior puede no aplicarse a casos no predeterminados. En el servidor X.org 1.7, estos están disponibles como propiedades del dispositivo de entrada (consulte xinput).

p
La opción p controla los valores de color de los píxeles.
Los parámetros son el número de entrada del mapa de color en decimal y una especificación de color. Los colores de fondo de la raíz se pueden cambiar en algunos servidores alterando las entradas para BlackPixel y WhitePixel. Aunque a menudo son 0 y 1, no tienen por qué serlo. Además, un servidor puede optar por asignar esos colores de forma privada, en cuyo caso se generará un error. La entrada del mapa no debe ser un color de solo lectura, o se producirá un error.
r
La opción r controla la autorepetición. Invocar con "-r", o "r off", deshabilitará la autorepetición, mientras que "r", o "r on" la habilitará. Después de la opción "-r" o "r" con un código de tecla entero entre 0 y 255, se deshabilitará o habilitará la autorepetición de esa tecla respectivamente, pero solo si tiene sentido para el código de tecla particular. Los códigos de tecla por debajo de 8 no suelen ser válidos para este comando. Ejemplo: "xset -r 10" deshabilitará la autorepetición para la tecla "1" en la fila superior de un teclado IBM PC.

Si el servidor soporta la extensión XFree86-Misc, o la extensión XKB, se acepta un parámetro de 'rate' que debe ir seguido de cero, uno o dos valores numéricos. El primero especifica el retardo antes de que comience la autorepetición y el segundo especifica la velocidad de repetición. En el caso de que el servidor soporte la extensión XKB, el retardo es el número de milisegundos antes de que comience la autorepetición, y la velocidad es el número de repeticiones por segundo. Si no se proporciona la velocidad o el retardo, se establecerán a su valor predeterminado.

s
La opción s te permite establecer los parámetros del salvapantallas. Esta opción acepta hasta dos parámetros numéricos, una bandera 'blank/noblank', una bandera 'expose/noexpose', una bandera 'on/off', una bandera 'activate/reset', o la bandera 'default'. Si no se proporcionan parámetros o se utiliza la bandera 'default', el sistema se configurará con sus características predeterminadas de salvapantallas. Las banderas 'on/off' simplemente activan o desactivan las funciones del salvapantallas. La bandera 'activate' fuerza la activación del salvapantallas incluso si este había sido desactivado. La bandera 'reset' fuerza la desactivación del salvapantallas si está activo. La bandera 'blank' establece la preferencia de apagar el vídeo (si el hardware lo permite) en lugar de mostrar un patrón de fondo, mientras que 'noblank' establece la preferencia de mostrar un patrón en lugar de apagar el vídeo. La bandera 'expose' establece la preferencia de permitir exposiciones de ventanas (el servidor puede descartar libremente el contenido de las ventanas), mientras que 'noexpose' establece la preferencia de deshabilitar el salvapantallas a menos que el servidor pueda regenerar las pantallas sin causar eventos de exposición. Los parámetros de duración y período para la función de salvapantallas determinan cuánto tiempo debe estar inactivo el servidor para que se active el salvapantallas, y el período para cambiar el patrón de fondo y evitar quemaduras. Los argumentos se especifican en segundos. Si solo se proporciona un parámetro numérico, se utilizará para la duración.
q
La opción q te proporciona información sobre la configuración actual.
-version
La opción -version imprime la versión del programa y sale sin hacer nada más.

Estos ajustes se restablecerán a sus valores predeterminados cuando cierres la sesión.

Ten en cuenta que no todas las implementaciones de X garantizan que cumplan con todas estas opciones.
