NOMBRE

xsd - Utilidad de Mono para generar archivos de esquema o de clase

SINOPSIS

xsd <schema.xsd> /classes [opciones]

xsd <schema.xsd> /dataset [opciones]

xsd <assembly>.dll|<assembly>.exe [opciones]

xsd <instancia.xml> [<instancia.xml> ...] [opciones]

DESCRIPCIÓN

xsd es una herramienta destinada a complementar el soporte de serialización XML de Mono. Puede realizar las siguientes tareas:

Generar clases serializables
A partir de un esquema XML dado, genera una clase que puede ser utilizada para leer y escribir documentos XML que cumplen con ese esquema (opción /classes).
Generar DataSets tipados
A partir de un esquema XML dado, genera una clase DataSet tipada que puede ser utilizada para leer y escribir documentos XML que cumplen con ese esquema (opción /dataset).
Generar esquemas XML
A partir de un ensamblado dado y un nombre de tipo opcional, genera un esquema XML que puede ser utilizado para validar los documentos XML que se obtienen al serializar objetos de ese tipo. Si no se proporciona un tipo, xsd genera un esquema para todos los tipos del ensamblado. Al especificar el nombre del ensamblado, no incluya la extensión del archivo (.dll o .exe). xsd buscará el ensamblado utilizando las reglas estándar de carga de ensamblados.
Inferir esquemas XML
A partir de un conjunto de documentos XML, infiere el esquema XML que puede ser utilizado para validar esos documentos.

OPCIONES

Las siguientes opciones están disponibles:

/element:nombre /e:nombre
Especifica el nombre del elemento del esquema XML para el cual se debe generar una clase o un conjunto de datos.
/namespace:nombre /n:nombre
Especifica el espacio de nombres del elemento del esquema XML para el cual se debe generar una clase o un conjunto de datos.
/language:nombre /l:nombre
Especifica el lenguaje de programación a utilizar para el código generado. Los únicos lenguajes compatibles son CS (C#) y VB (Visual Basic.NET).
/generator:tipo,ensamblado /g:tipo,ensamblado
Indica a xsd.exe que utilice un CodeDomProvider personalizado para generar código. El nombre del tipo debe ser el nombre completo. El nombre del ensamblado es un nombre de archivo local que se va a cargar. El Tipo especificado debe tener el constructor predeterminado.
/outputdir:ruta /o:ruta
Especifica el directorio donde generar el código o los esquemas.
/type:nombre /t:nombre
Especifica el nombre completo del tipo (incluyendo el espacio de nombres) para el cual generar el esquema XML.
/help /h
Muestra la ayuda de uso.
