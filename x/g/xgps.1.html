XGPS(1) Documentación de gpsd XGPS(1)

NOMBRE

xgps - cliente X para gpsd

SINOPSIS

xgps [OPCIONES] [servicio[:puerto[:dispositivo]]]

xgps -h

xgps -V

DESCRIPCIÓN

xgps es un cliente de ejemplo simple para gpsd con una interfaz X. Muestra información de posición/tiempo/velocidad GNSS actual y (para receptores GNSS que soportan la función) las ubicaciones de los satélites accesibles.

En la vista del cielo, los satélites están codificados por colores para indicar la calidad de la señal; consulte la pantalla de datos a la izquierda para obtener cifras exactas en dB. Los iconos en forma de diamante indican satélites GLONASS, los cuadrados se usan para SBAS (por ejemplo, WAAS, EGNOS), los círculos indican GPS, y los triángulos apuntando hacia abajo, hacia arriba, hacia la derecha y hacia la izquierda indican respectivamente satélites Galileo, BeiDou, QZSS y de otros sistemas (por ejemplo, IMES, IRNSS, así como sistemas desconocidos). Los iconos rellenos se usaron en la solución actual, los iconos de contorno no. Pasar el puntero del ratón sobre un símbolo mostrará temporalmente una pequeña ventana emergente con los detalles del satélite del panel de Lista de Satélites.

xgps funcionará bien como usuario normal y bien como root. Ejecutar xgps con sudo provocará una pérdida de funcionalidad.

OPCIONES

-?, -h, --help

Hace que el cliente emita un resumen de sus opciones y luego salga.

-device DEVICE

El dispositivo en el host al que conectarse. El valor predeterminado es vacío (cualquiera).

-D LVL, --debug LVL

Establece el nivel de depuración, es principalmente para uso de los desarrolladores de GPSD. Habilita varios mensajes de progreso a la salida de error estándar.

--host HOST

El host (servidor) al que conectarse. El valor predeterminado es localhost.

-l FMT, --llfmt FMT

Establece el formato de los informes de latitud y longitud. El valor 'd' produce grados decimales y es el predeterminado. El valor 'm' produce grados y minutos decimales. El valor 's' produce grados, minutos y segundos decimales.

-p PORT, --port PORT

El puerto al que conectarse. El valor predeterminado es 2947.

-r DEG, --rotate DEG

Acepta un argumento en grados para rotar la vista del cielo en sentido antihorario.

-c FORMAT, --const FORMAT

Formato de visualización de la constelación. Puede mostrar el nombre abreviado, el nombre completo o el nombre completo y la bandera cuando sea posible. NOTA: las banderas requieren una fuente UTF-8 con banderas emoji.

-V, --version

Esta opción hace que cada cliente arroje la versión del paquete y salga.

ARGUMENTOS

Por defecto, los clientes recopilan datos del demonio local gpsd que se ejecuta en localhost, utilizando el puerto predeterminado de GPSD 2947. El argumento opcional a cualquier cliente puede anular este comportamiento: [servidor[:puerto[:dispositivo]]]

Para obtener más explicaciones y ejemplos, consulte la sección ARGUMENTOS en la página del manual gps(1)

ENTORNO

La variable de entorno XGPSOPTS puede establecerse para pasar opciones de línea de comandos usadas comúnmente a xgps. Esto se usa a menudo para establecer la opción -u para unidades específicas de localidad. XGPSOPTS se procesa antes que las opciones de la CLI.

xgps también examina otras variables de entorno para determinar las unidades de visualización: imperial, náutica o métrica. Aquí están las variables y los valores comprobados:

    GPSD_UNITS uno de:
              i          = millas/pies
              imperial   = millas/pies
              n          = nudos/pies
              nautical   = nudos/pies
              m          = km/metros
              metric     = km/metros
    LC_MEASUREMENT
              en_US      = millas/pies
              C          = millas/pies
              POSIX      = millas/pies
              [otro]     = km/metros
    LANG
              en_US      = millas/pies
              C          = millas/pies
              POSIX      = millas/pies
              [otro]     = km/metros

La opción -u o --units anula estas preferencias.

La opción -u se puede utilizar para establecer las unidades del sistema para la visualización; siga la palabra clave con 'i' para 'imperial' para unidades americanas (Pies Internacionales en altitud y estimaciones de errores, millas por hora en velocidades), 'n' para 'náutico' (pies en altitud y estimaciones de errores, nudos en velocidad) o 'm' para 'métrico' (metros en altitud y estimaciones de errores, kilómetros por hora en velocidad).

Nota: El pie de topógrafo de EE. UU. no es compatible.

La variable de entorno GPSD_UNITS se verifica si no se especifica ningún sistema de unidades en la línea de comandos o en XPGSOPTS; puede establecerse en 'i'. 'imperial', 'm', 'metric', o 'n', 'nautical'.

LC_MEASUREMENT y luego LANG se verifican si no se ha especificado ningún sistema de unidades en la línea de comandos, en XPGSOPTS o en GPSD_UNITS. Si el valor es 'C', 'POSIX', o comienza con 'en_US', el sistema de unidades se establece en imperial. El valor predeterminado si no se ha seleccionado ningún sistema es métrico.

OPCIONES DEL MENÚ

Archivo > Conectar

Intenta abrir una nueva conexión al servidor, utilizando el servidor anterior por defecto.

Archivo > Desconectar

Utiliza la función 'desconectar' para cortar la conexión actual del servidor sin salir del programa.

Archivo > Dispositivos

Esto le permite cambiar el dispositivo del que XGPS informa datos, predeterminado a todos los dispositivos.

Archivo > Salir

Salir de xgps.

Ver

Alterna la visibilidad de los paneles en la pantalla; los paneles son (de arriba a abajo) una vista del cielo de satélites y datos de Sistemas Globales de Posicionamiento, el Sistema de Identificación Automática (náutico), sensor de actitud, Unidades de Medición Inercial, estadísticas de ruido y posicionamiento cinemático en tiempo real. Xgps muestra la vista del cielo de satélites y los paneles GPS por defecto, el panel AIS se oculta hasta que se selecciona, y los paneles de actitud, IMU, ruido y RTK no se revelan automáticamente hasta que se reciben los datos apropiados.

Unidades > Imperial, Métrico, Náutico

Selecciona el conjunto de unidades utilizado para velocidad y altitud. Esta configuración tiene como valor predeterminado métrico a menos que xgps detecte una configuración americana, "C" o "POSIX" para las variables de entorno LANG o LC_MEASUREMENT (ver arriba).

Unidades > DD.dd, DD MM.mm, DD MM SS.ss

Establece el formato del ángulo en grados, grados-minutos o grados-minutos-segundos. La última unidad es un número de punto flotante y las anteriores enteros.

Unidades > 30, 45, Desactivado

Cambia los valores predeterminados de los gráficos de dispersión de satélites a 30 grados.

Unidades > Norte Magnético Arriba, Rastro Arriba, Norte Verdadero Arriba

Cambia la orientación en el gráfico de dispersión de satélites a su gusto, predeterminado a norte verdadero.

Ayuda > Acerca de

Muestra información sobre xgps.
