Paquete: gpsd

XGPSSPEED(1) Documentación de GPSD XGPSSPEED(1)

NOMBRE

xgpsspeed - Velocímetro X para gpsd

SINOPSIS

xgpsspeed [OPCIONES] [servicio[:puerto[:dispositivo]]]

xgpsspeed -h

xgpsspeed -V

DESCRIPCIÓN

xgpsspeed es un velocímetro que utiliza la información de posición de gpsd.

El modo de visualización predeterminado es una presentación de velocidad y rumbo modelada a partir de una pantalla de navegación marina; para compatibilidad con versiones anteriores, la opción --nautical fuerza este modo. La opción --landspeed produce un velocímetro simple.

La opción --speedunits se puede utilizar para establecer las unidades de velocidad para la visualización; siga la palabra clave con "knots" para millas náuticas por hora, "kmh" para kilómetros por hora o "mph" para millas por hora. El valor predeterminado son millas por hora.

Solo en modo náutico, --maxspeed establece el máximo en el velocímetro.

xgpsspeed funcionará bien como usuario normal y como root. Ejecutar xgpsspeed con sudo provocará una pérdida de funcionalidad.

OPCIONES

-?, -h, --help

Hace que el cliente emita un resumen de sus opciones y luego salga.

-device DISPOSITIVO

El dispositivo en el host al que conectarse. El valor predeterminado está vacío (cualquiera).

-D LVL, --debug LVL

Establece el nivel de depuración, es principalmente para uso de los desarrolladores de GPSD. Habilita varios mensajes de progreso en la salida estándar de error.

--host HOST

El host (servidor) al que conectarse. El valor predeterminado es localhost.

-p PUERTO, --port PUERTO

El puerto al que conectarse. El valor predeterminado es 2947.

-V, --version

Esta opción hace que cada cliente emita la versión del paquete y salga.

ARGUMENTOS

Por defecto, los clientes recopilan datos del demonio local gpsd que se ejecuta en localhost, utilizando el puerto predeterminado de GPSD 2947. El argumento opcional para cualquier cliente puede anular este comportamiento: [servidor[:puerto[:dispositivo]]]

Para obtener más explicaciones y ejemplos, consulte la sección ARGUMENTOS en la página del manual gps(1)

ENTORNO

La variable de entorno GPSD_UNITS se comprueba si no se especifica ningún sistema de unidades en la línea de comandos. Puede establecerse en 'i', 'imperial', 'm', 'metric' o 'n', 'nautical'.

LC_MEASUREMENT y luego LANG se comprueban si no se ha especificado ningún sistema de unidades en la línea de comandos, o en GPSD_UNITS. Si el valor es 'C', 'POSIX', o comienza con 'en_US', el sistema de unidades se establece en imperial. El valor predeterminado si no se ha seleccionado ningún sistema es métrico.

VALORES DE RETORNO

0

en caso de éxito.

1

en caso de fallo
