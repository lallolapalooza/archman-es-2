NOMBRE

xgamma - Alterar la corrección gamma de un monitor a través del servidor X

SINOPSIS

xgamma [-display pantalla] [-screen pantalla] [-quiet] [-help|-version]
       [-gamma f.f | [[-rgamma f.f] [-ggamma f.f] [-bgamma f.f]]]

DESCRIPCIÓN

xgamma permite a los usuarios de X consultar y alterar la corrección gamma de un monitor a través de la extensión de modo de video de X (XFree86-VidModeExtension).

Tenga en cuenta que la utilidad xgamma está obsoleta y es deficiente; se debe usar xrandr(1) con controladores que soporten la extensión XRandr.

Si no se proporciona ningún valor para la corrección gamma a través de las opciones -gamma o -rgamma/-ggamma/-bgamma, xgamma imprime la corrección gamma actual de la pantalla.

OPCIONES

-display pantalla
Este argumento le permite especificar el servidor al que conectarse; véase X(7).
-screen pantalla
Cuando hay varias pantallas configuradas como una única pantalla lógica, esta opción le permite seleccionar la pantalla que desea cambiar.
-quiet
Silencia la salida normal de xgamma.
-help
Imprime el resumen de la sintaxis del comando `Uso:'.
-version
Imprime la versión del programa y sale.
-gamma f.f
La corrección gamma se puede definir como un solo valor, o por separado para los componentes rojo, verde y azul. Este argumento especifica la corrección gamma como un solo valor.
-rgamma f.f
Este argumento especifica el componente rojo de la corrección gamma.
-ggamma f.f
Este argumento especifica el componente verde de la corrección gamma.
-bgamma f.f
Este argumento especifica el componente azul de la corrección gamma.

MEDIO AMBIENTE

DISPLAY
Para obtener el host y el número de pantalla predeterminados.

ERRORES

Este cliente cambia los valores internos de la corrección gamma del servidor X. Que estos valores sean respetados o no depende de los controladores de video.

Los valores gamma se pasan al servidor X con 3 decimales de precisión.

VER TAMBIÉN

xvidtune(1), xrandr(1)
