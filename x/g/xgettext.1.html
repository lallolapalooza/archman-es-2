XGETTEXT(1) Comandos de usuario XGETTEXT(1)

NOMBRE

xgettext - extraer cadenas gettext del código fuente

SINOPSIS

xgettext [OPCIÓN] [ARCHIVO_ENTRADA]...

DESCRIPCIÓN

Extrae cadenas traducibles de los archivos de entrada dados.

Los argumentos obligatorios para las opciones largas también son obligatorios para las opciones cortas. Similarmente para los argumentos opcionales.

Ubicación del archivo de entrada:

ARCHIVO_ENTRADA ...
archivos de entrada
-f, --files-from=ARCHIVO
obtener lista de archivos de entrada de ARCHIVO
-D, --directory=DIRECTORIO
añadir DIRECTORIO a la lista para la búsqueda de archivos de entrada

Si el archivo de entrada es -, se lee la entrada estándar.

Ubicación del archivo de salida:

-d, --default-domain=NOMBRE
usar NOMBRE.po para la salida (en lugar de messages.po)
-o, --output=ARCHIVO
escribir la salida al archivo especificado
-p, --output-dir=DIR
los archivos de salida se colocarán en el directorio DIR

Si el archivo de salida es -, la salida se escribe en la salida estándar.

Elección del idioma del archivo de entrada:

-L, --language=NOMBRE
reconocer el idioma especificado (C, C++, ObjectiveC, PO, Python, Java, JavaProperties, C#, JavaScript, TypeScript, TSX, Scheme, Guile, Lisp, EmacsLisp, librep, Rust, Go, Ruby, Shell, awk, Lua, Modula-2, D, Smalltalk, Vala, Tcl, Perl, PHP, GCC-source, YCP, NXStringTable, RST, RSJ, Glade, GSettings, Desktop)
-C, --c++
atajo para --language=C++

Por defecto, el idioma se adivina según la extensión del nombre del archivo de entrada.

Interpretación del archivo de entrada:

--from-code=NOMBRE
codificación de los archivos de entrada (excepto para Python, Tcl, Glade)

Por defecto, se asume que los archivos de entrada están en ASCII.

Modo de operación:

-j, --join-existing
unir mensajes con el archivo existente
-x, --exclude-file=ARCHIVO.po
las entradas de ARCHIVO.po no se extraerán
-cTAG, --add-comments=TAG
colocar bloques de comentarios que comienzan con TAG y preceden a las líneas de palabras clave en el archivo de salida
-c, --add-comments
colocar todos los bloques de comentarios que preceden a las líneas de palabras clave en el archivo de salida
--check=NOMBRE
realizar verificación de sintaxis en los mensajes (unicode de elipsis, espacio-elipsis,
unicode de comillas, unicode de viñeta)
--sentence-end=TIPO
tipo que describe el final de una oración (espacio-simple, que es el predeterminado,
o espacio-doble)

Opciones específicas del idioma:

-a, --extract-all
extraer todas las cadenas (solo idiomas C, C++, ObjectiveC, Python, Java, C#, JavaScript, TypeScript, TSX, Scheme, Guile, Lisp, EmacsLisp, librep, Rust, Go, Shell, awk, Lua, Modula-2, D, Vala, Tcl, Perl, PHP, GCC-source, Glade, GSettings)
-kWORD, --keyword=PALABRA
buscar PALABRA como una palabra clave adicional
-k, --keyword
no usar palabras clave predeterminadas (solo idiomas C, C++, ObjectiveC, Python, Java, C#, JavaScript, TypeScript, TSX, Scheme, Guile, Lisp, EmacsLisp, librep, Rust, Go, Shell, awk, Lua, Modula-2, D, Vala, Tcl, Perl, PHP, GCC-source, Glade, GSettings, Desktop)
--flag=PALABRA:ARG:FLAG
bandera adicional para cadenas dentro del argumento número ARG de la palabra clave PALABRA
(solo idiomas C, C++, ObjectiveC, Python,
Java, C#, JavaScript, TypeScript, TSX, Scheme, Guile, Lisp, EmacsLisp, librep, Rust, Go, Shell, awk, Lua, Modula-2, D, Vala, Tcl, Perl, PHP, GCC-source, YCP)
--tag=PALABRA:FORMATO
define el comportamiento de las literales de plantilla etiquetadas con la etiqueta PALABRA
(solo idioma JavaScript)
-T, --trigraphs
entender los trigrafos del C ANSI para la entrada (obsoleto; solo idiomas C, C++, ObjectiveC)
--its=ARCHIVO
aplicar reglas ITS del ARCHIVO (solo idiomas basados en XML)
--qt
reconocer cadenas de formato Qt (solo idioma C++)
--kde
reconocer cadenas de formato KDE 4 (solo idioma C++)
--boost
reconocer cadenas de formato Boost (solo idioma C++)
--debug
resultado más detallado del reconocimiento de cadenas de formato

Detalles de salida:

--color
usar colores y otros atributos de texto siempre
--color=CUÁNDO
usar colores y otros atributos de texto si CUÁNDO. CUÁNDO puede ser 'siempre', 'nunca', 'auto', o 'html'.
--style=ARCHIVOESTILO
especificar archivo de reglas CSS para --color
-e, --no-escape
no usar escapes C en la salida (predeterminado)
-E, --escape
usar escapes C en la salida, sin caracteres extendidos
--force-po
escribir archivo PO incluso si está vacío
-i, --indent
escribir el archivo .po usando estilo indentado
--no-location
no escribir líneas '#: nombre_archivo:línea'
-n, --add-location
generar líneas '#: nombre_archivo:línea' (predeterminado)
--strict
escribir un archivo .po estrictamente conforme a Uniforum
--properties-output
escribir un archivo Java .properties
--stringtable-output
escribir un archivo .strings de NeXTstep/GNUstep
--itstool
escribir comentarios itstool
-w, --width=NÚMERO
establecer el ancho de página de salida
--no-wrap
no dividir las líneas de mensajes largas, que excedan el ancho de página de salida, en varias líneas

OPCIONES

Las siguientes opciones son reconocidas por xgettext:

-s, --sort-output
generar salida ordenada (obsoleto)
-F, --sort-by-file
ordenar la salida por la ubicación del archivo
--omit-header
no escribir la cabecera con la entrada 'msgid ""'
--no-git
no usar el programa git para producir un campo 'POT-Creation-Date' reproducible en la salida.
--copyright-holder=STRING
establecer el titular de los derechos de autor en la salida
--foreign-user
omitir los derechos de autor de la FSF para usuarios extranjeros
--package-name=PACKAGE
establecer el nombre del paquete en la salida
--package-version=VERSION
establecer la versión del paquete en la salida
--msgid-bugs-address=EMAIL@ADDRESS
establecer la dirección de reporte para los errores de msgid
--generated=FILE
Declara que el archivo dado es generado y por lo tanto no debe tener influencia en el campo 'POT-Creation-Date' en la salida.
--reference=FILE
Declara que la salida depende del contenido del archivo dado. Esto tiene influencia en el campo 'POT-Creation-Date' en la salida.
-m[STRING], --msgstr-prefix[=STRING]
usar STRING o "" como prefijo para los valores de msgstr
-M[STRING], --msgstr-suffix[=STRING]
usar STRING o "" como sufijo para los valores de msgstr

Salida informativa:

-h, --help
mostrar esta ayuda y salir
-V, --version
mostrar información de la versión y salir
-v, --verbose
aumentar el nivel de verbosidad
