Paquete: perl-locale-maketext-lexicon

XGETTEXT(1) Documentación de Perl contribuida por el usuario XGETTEXT(1)

NOMBRE

xgettext.pl - Extrae cadenas traducibles del código fuente

VERSIÓN

versión 1.00

SINOPSIS

xgettext.pl [OPCIÓN] [ARCHIVO_ENTRADA]...

DESCRIPCIÓN

Este programa extrae cadenas traducibles de los archivos de entrada dados, o de STDIN si no se proporcionan ninguno.

Consulte Locale::Maketext::Extract para ver una lista de los formatos de archivo de entrada compatibles.

OPCIONES

Los argumentos obligatorios para las opciones largas son obligatorios también para las opciones cortas. Igualmente para los argumentos opcionales.

Ubicación del archivo de entrada:

ARCHIVO_ENTRADA...
Archivos de los que extraer mensajes. Si no se especifica, se asume STDIN.
-f, --files-from=ARCHIVO
Obtiene la lista de archivos de entrada de ARCHIVO.
-D, --directory=DIRECTORIO
Añade DIRECTORIO a la lista para la búsqueda de archivos de entrada.

Formato del archivo de entrada:

-u, --use-gettext-style
Especifica que los programas fuente utilizan el estilo Gettext (por ejemplo, %1) en lugar del estilo Maketext (por ejemplo, "[_1]") en sus llamadas de localización.

Ubicación del archivo de salida:

-d, --default-domain=NOMBRE
Utiliza NOMBRE.po para la salida, en lugar de "messages.po".
-o, --output=ARCHIVO
Nombre del archivo PO a escribir o actualizar incrementalmente; "-" significa escribir en STDOUT.
-p, --output-dir=DIR
Los archivos de salida se colocarán en el directorio DIR.

Detalles de salida:

-g, --gnu-gettext
Habilita la interoperabilidad de GNU gettext imprimiendo "#, perl-maketext-format" antes de cada entrada que tenga variables "%".
-W, --wrap
Si el ajuste está habilitado, entonces, para las entradas con múltiples ubicaciones de archivo, cada ubicación se lista en una línea separada. La opción predeterminada es ponerlas todas en una sola línea.

Otros comentarios no se ven afectados.

Plugins:

Por defecto, todos los plugins de análisis integrados están habilitados para todos los tipos de archivo, con las advertencias desactivadas.

Si se especifica algún plugin en la línea de comandos, las advertencias están activadas por defecto; puedes desactivarlas con "-now"

-P|--plugin nombre_plugin
Utiliza el plugin especificado para los tipos de archivo predeterminados
reconocidos por ese plugin.
-P|--plugin 'nombre_plugin=*'
Utiliza el plugin especificado para todos los tipos de archivo.
-P|--plugin nombre_plugin=ext,ext2
Utiliza el plugin especificado para cualquier archivo que termine en
C<.ext> o C<.ext2>
-P|--plugin Mi::Modulo::Nombre='*'
Utiliza tu módulo plugin personalizado para todos los tipos de archivo

Se pueden especificar múltiples plugins en la línea de comandos.

Plugins disponibles:

"perl" : Locale::Maketext::Extract::Plugin::Perl
Para un analizador de Perl un poco más preciso pero mucho más lento, puedes usar el plugin PPI. Este no tiene un nombre corto, sino que debe especificarse completo, por ejemplo: 
xgettext.pl -P Locale::Maketext::Extract::Plugin::PPI
"tt2" : Locale::Maketext::Extract::Plugin::TT2
"yaml" : Locale::Maketext::Extract::Plugin::YAML
"formfu" : Locale::Maketext::Extract::Plugin::FormFu
"mason" : Locale::Maketext::Extract::Plugin::Mason
"text" : Locale::Maketext::Extract::Plugin::TextTemplate
"generic" : Locale::Maketext::Extract::Plugin::Generic

Advertencias:

Si un plugin de análisis encuentra un error de sintaxis durante el análisis, abortará el análisis y pasará al siguiente plugin de análisis. Si las advertencias están activadas, el error se mostrará en STDERR.

Desactivado por defecto, a menos que se haya especificado algún plugin en la línea de comandos.

-w|--warnings
-now|--nowarnings

Verboso:

Si desea ver qué archivos se han procesado, qué plugins se utilizaron y qué cadenas se extrajeron, habilite "verbose". Si no se encontró ningún plugin aceptable, o no se extrajeron cadenas, el archivo no se lista:

-v|--verbose
Lista los archivos procesados.
-v -v|--verbose --verbose :
Lista los archivos procesados y qué plugins lograron extraer cadenas.
-v -v|--verbose --verbose :
Lista los archivos procesados, qué plugins lograron extraer cadenas, y las cadenas extraídas, la línea donde se encontraron y cualquier variable.
