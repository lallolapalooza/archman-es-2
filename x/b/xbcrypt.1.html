NOMBRE

xbcrypt - Documentación de Percona xbcrypt

Para admitir el cifrado y descifrado de las copias de seguridad, se introdujo una nueva herramienta xbcrypt en Percona XtraBackup.

Percona XtraBackup 8.0.28-20 implementa la variable de entorno XBCRYPT_ENCRYPTION_KEY. La variable solo se utiliza en lugar de la opción --encrypt_key=nombre. Puede usar la variable de entorno o la opción de línea de comandos. Si usa ambas, la opción de línea de comandos tiene prioridad sobre el valor especificado en la variable de entorno.

Esta utilidad se ha modelado después de xbstream_binary para realizar cifrado y descifrado fuera de Percona XtraBackup. xbcrypt tiene las siguientes opciones de línea de comandos:

-d, --decrypt
Descifra los datos de entrada a salida.
-i, --input=nombre
Archivo de entrada opcional. Si no se especifica, la entrada se leerá de la entrada estándar.
-o, --output=nombre
Archivo de salida opcional. Si no se especifica, la salida se escribirá en la salida estándar.
-a, --encrypt-algo=nombre
Algoritmo de cifrado.
-k, --encrypt-key=nombre
Clave de cifrado.
-f, --encrypt-key-file=nombre
Archivo que contiene la clave de cifrado.
-s, --encrypt-chunk-size=#
Tamaño del búfer de trabajo para el cifrado en bytes. El valor predeterminado es 64K.
--encrypt-threads=#
Esta opción especifica el número de hilos trabajadores que se utilizarán para el cifrado/descifrado paralelo.
-v, --verbose
Muestra la salida de estado detallada.
