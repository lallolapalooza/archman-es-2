XBindKeys(1) Manual general de comandos XBindKeys(1)

NOMBRE

xbindkeys - un programa para capturar teclas para X

SINOPSIS

xbindkeys [ opciones ]

DESCRIPCIÓN

XbindKeys es un programa que captura eventos de teclas y botones del ratón en X e inicia comandos de shell asociados.

OPCIONES DE LÍNEA DE COMANDOS

Las opciones disponibles de línea de comandos son las siguientes:

-d, --defaults
Imprime un archivo rc predeterminado.
-f, --file
Usa un archivo rc alternativo.
-h, --help
Ayuda breve sobre las opciones, además de información de versión/autor.
-X, --display
Establece la pantalla X a usar.
-v, --verbose
Más información sobre xbindkeys cuando se ejecuta.
-k, --key
Identifica una tecla presionada (útil para la configuración).
-mk, --multikey
Identifica una combinación de teclas presionadas (útil para la configuración).
-g, --geometry
Tamaño y posición de la ventana con la opción -k|-mk.
-n, --nodaemon
No se inicia como demonio.

Si el soporte de guile no ha sido deshabilitado:

-dg, --defaults-guile
Imprime un archivo de configuración guile predeterminado.
-fg, --file-guile
Usa un archivo de configuración guile alternativo.

XBINDKEYSRC

El archivo de configuración predeterminado de XBindKeys está en $HOME/.xbindkeysrc, usado solo para un usuario.

El archivo de configuración consiste en comandos entre comillas dobles y las teclas asociadas en la línea siguiente.

Los comentarios se inician con una almohadilla (#) y se extienden hasta el final de la línea.

Puedes ver una configuración predeterminada con --defaults


KEYSYMS

El programa espera combinaciones de keysyms a ser utilizadas mediante caracteres más (+) para combinarlas.

El formato de una línea de comandos es:

    "comando a iniciar &"
       tecla asociada
Para especificar una tecla asociada, puedes usar `xbindkeys --key` o
`xbindkeys --multikey` y colocar una de las dos líneas en el archivo de configuración.

Una lista de teclas se encuentra en /usr/include/X11/keysym.h y en /usr/include/X11/keysymdef.h. El prefijo XK_ no es necesario.

Lista de modificadores:

    Release, Control, Shift, Mod1 (Alt), Mod2 (NumLock),
    Mod3 (CapsLock), Mod4, Mod5 (Scroll).
El modificador Release no es un modificador estándar de X, pero puedes usarlo si quieres capturar eventos de liberación en lugar de eventos de pulsación. Los modificadores no distinguen entre mayúsculas y minúsculas.

Por defecto, xbindkeys no presta atención a los modificadores NumLock, CapsLock y ScrollLock. Agrega las siguientes líneas en el archivo de configuración si quieres prestarles atención.


keystate_numlock = enable

    keystate_capslock = enable
    keystate_scrolllock= enable

EJEMPLOS

# control+shift+q inicia xterm

"xterm"
  control+shift + q
# Tecla Menú inicia xbindkeys_show
"xbindkeys_show"
  Menu
# Control + botón del ratón 1 inicia xterm
"xterm"
  Control + b:1
# Control+Shift+a  evento de liberación inicia rxvt
"rxvt"
  release+control+shift + a
# Control + botón del ratón 2 evento de liberación inicia rxvt
"rxvt"
  Control + b:2 + Release

ESTILO DE CONFIGURACIÓN SCHEME

Se puede usar una configuración scheme si el soporte de guile no ha sido deshabilitado. La configuración estándar se carga solo si la configuración scheme no está disponible.

Para más detalles, por favor vea aquí:

http://www.gnu.org/software/guile/guile.html 
Nota: El archivo de configuración guile es preferido para configuraciones no triviales
, por ejemplo doble clic, clic temporizado o combinaciones de teclas.
La ubicación predeterminada es ~/.xbindkeysrc.scm
Usa xbindkeys --defaults-guile para más detalles.
Y xbindkeys --defaults-guile > ~/.xbindkeysrc.scm para usar este método.

NOTA

xbindkeys recarga el archivo de configuración si se modifica. Envía una señal HUP para forzar la recarga:

killall -HUP xbindkeys

Cuando se envía una señal HUP a xbindkeys, los cambios surten efecto solo después de mover el ratón.
