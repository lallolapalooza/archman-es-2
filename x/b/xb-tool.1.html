NOMBRE

xb-tool - utilidad XMLb independiente

SINOPSIS

xb-tool [CMD]

DESCRIPCIÓN

Esta herramienta permite crear, volcar y consultar blobs XML binarios.

Adicionalmente, xb-tool puede usarse para perfilar consultas tokenizadas específicas.

OPCIONES

El comando xb-tool toma varias opciones dependiendo de la acción. Ejecute xb-tool --help para ver la lista completa.

ESTADO DE SALIDA

Los comandos que se ejecutan correctamente devolverán "0", de lo contrario "1".

ERRORES

No se conocen errores.
