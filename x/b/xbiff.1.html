NOMBRE

xbiff - indicador de buzón para X

SINOPSIS

xbiff [ -opción-toolkit ... ] [ -opción ... ]

DESCRIPCIÓN

El programa xbiff muestra una pequeña imagen de un buzón. Cuando no hay correo, la bandera del buzón está bajada. Cuando llega correo, la bandera sube y el buzón suena. Por defecto, al presionar cualquier botón del ratón en la imagen, xbiff fuerza a recordar el tamaño actual del archivo de correo como el tamaño "vacío" y a bajar la bandera.

OPCIONES

Xbiff acepta todas las opciones de línea de comandos estándar del X Toolkit junto con las opciones adicionales listadas a continuación:

-ayuda
Esta opción indica que se debe imprimir un breve resumen de las opciones permitidas en el error estándar.
-actualizar segundos
Esta opción especifica la frecuencia en segundos con la que xbiff debe actualizar su pantalla. Si el buzón está oscurecido y luego se expone, se actualizará inmediatamente. El valor por defecto es 30 segundos.
-archivo nombre_archivo
Esta opción especifica el nombre del archivo que debe ser monitorizado. Por defecto, vigila tu buzón de entrada en la ubicación predeterminada para tu sistema (algunos ejemplos son /var/mail/nombre_usuario, /usr/spool/mail/nombre_usuario, /var/spool/mail/nombre_usuario (donde nombre_usuario es tu nombre de inicio de sesión). Si la variable de entorno MAIL está configurada, se monitorizará el archivo especificado en ella.
-volumen porcentaje
Esta opción especifica cuán alto debe sonar la campana cuando llega correo nuevo. El porcentaje es relativo al volumen actual en xset. Así, 0 es volumen normal, los porcentajes negativos se dirigen hacia el mínimo (-100 es silencio), y los porcentajes positivos se dirigen hacia el volumen máximo (100 es lo más alto).
-forma
Esta opción indica que la ventana del buzón debe tener forma si se proporcionan máscaras para las imágenes vacía o llena.
-versión
Esta opción indica que xbiff debe imprimir su versión y salir.

Los siguientes argumentos de línea de comandos estándar del X Toolkit se usan comúnmente con xbiff:

-pantalla pantalla
Esta opción especifica el servidor X al que contactar.
-geometría geometría
Esta opción especifica el tamaño y la posición preferidos de la ventana del buzón. El buzón tiene 48 píxeles de ancho y 48 píxeles de alto y se centrará en la ventana.
-bg color
Esta opción especifica el color a usar para el fondo de la ventana.
-bd color
Esta opción especifica el color a usar para el borde de la ventana.
-bw número
Esta opción especifica el ancho en píxeles del borde que rodea la ventana.
-fg color
Esta opción especifica el color a usar para el primer plano de la ventana.
-rv
Esta opción indica que el video inverso debe simularse intercambiando los colores de primer plano y fondo.
-xrm cadena_recurso
Esta opción especifica una cadena de recurso a usar. Esto es especialmente útil para establecer recursos que no tienen opciones de línea de comandos separadas.

VALORES PREDETERMINADOS X

El nombre de la clase de la aplicación es XBiff. Este programa utiliza el widget Mailbox. Entiende todos los nombres y clases de recursos principales, así como:

comando_verificar (clase CheckCommand)
Especifica un comando de shell que se ejecutará para verificar si hay correo nuevo en lugar de examinar el tamaño del archivo. La cadena especificada se usa como argumento para una llamada a system(3) y, por lo tanto, puede contener redirección de E/S. Un estado de salida de 0 indica que hay correo nuevo esperando, 1 indica que no ha habido cambios en el tamaño, y 2 indica que el correo ha sido borrado. Por defecto, no se proporciona ningún comando de shell.
archivo (clase File)
Especifica el nombre del archivo a monitorizar. El valor predeterminado es como se describe anteriormente para la opción de línea de comandos -archivo.
solo_una_vez (clase Boolean)
Especifica que la campana solo suena la primera vez que se encuentra correo nuevo y no vuelve a sonar hasta que haya pasado al menos un intervalo sin correo pendiente. La ventana continuará indicando la presencia de correo nuevo hasta que se haya recuperado. El valor predeterminado es falso.
ancho (clase Width)
Especifica el ancho del buzón.
alto (clase Height)
Especifica la altura del buzón.
actualizar (clase Interval)
Especifica la frecuencia en segundos con la que se debe verificar el correo. El valor predeterminado es 30.
volumen (clase Volume)
Especifica cuán alto debe sonar la campana. El valor predeterminado es 33 por ciento. Tenga en cuenta que esto es un porcentaje del volumen actual de xset. Para reducir el volumen, especifique un porcentaje negativo.
primer_plano (clase Foreground)
Especifica el color del primer plano.
video_inverso (clase ReverseVideo)
Especifica que el primer plano y el fondo se invertirán.
voltear (clase Flip)
Especifica si la imagen que se muestra cuando ha llegado correo debe ser invertida o no. El valor predeterminado es "verdadero".
pixmap_lleno (clase Pixmap)
Especifica un mapa de bits que se mostrará cuando haya llegado correo nuevo. El valor predeterminado es flagup.
pixmap_vacio (clase Pixmap)
Especifica un mapa de bits que se mostrará cuando no haya correo nuevo presente. El valor predeterminado es flagdown.
forma_ventana (clase ShapeWindow)
Especifica si la ventana del buzón debe tener forma según los fullPixmapMask y emptyPixmapMask dados. El valor predeterminado es falso.
mascara_pixmap_lleno (clase PixmapMask)
Especifica una máscara para el mapa de bits que se mostrará cuando haya llegado correo nuevo. El valor predeterminado es ninguno.
mascara_pixmap_vacio (clase PixmapMask)
Especifica una máscara para el mapa de bits que se mostrará cuando no haya correo nuevo presente. El valor predeterminado es ninguno.

ACCIONES

El widget Mailbox proporciona las siguientes acciones para su uso en traducciones de eventos:

verificar()
Esta acción hace que el widget verifique si hay correo nuevo y muestre la bandera apropiadamente.
desactivar()
Esta acción hace que el widget baje la bandera hasta que llegue correo nuevo.
activar()
Esta acción hace que el widget suba la bandera hasta que el usuario la restablezca.

La traducción predeterminada es:

        <ButtonPress>:  desactivar()
