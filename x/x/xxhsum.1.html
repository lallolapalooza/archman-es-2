XXHSUM(1) Comandos de usuario XXHSUM(1)

NOMBRE

xxhsum - imprime o verifica sumas de verificación (checksums) xxHash no criptográficas

SINOPSIS

xxhsum [OPCIÓN]... [ARCHIVO]... xxhsum -b [OPCIÓN]...

xxh32sum es equivalente a xxhsum -H0, xxh64sum es equivalente a xxhsum -H1, xxh128sum es equivalente a xxhsum -H2, xxh3sum es equivalente a xxhsum -H3.

DESCRIPCIÓN

Imprime o verifica sumas de verificación (checksums) xxHash (de 32, 64 o 128 bits). Cuando no se especifica ARCHIVO, lee de la entrada estándar, excepto si se trata de la consola. Cuando ARCHIVO es -, lee de la entrada estándar incluso si es la consola.

xxhsum soporta una sintaxis de línea de comandos similar pero no idéntica a md5sum(1). Las diferencias son:

  • xxhsum no tiene el modificador de modo texto (-t)
  • xxhsum no tiene el modificador corto de modo binario (-b)
  • xxhsum siempre trata los archivos como archivos binarios
  • xxhsum tiene un modificador de selección de hash (-H)

Dado que xxHash es un algoritmo de suma de verificación no criptográfica rápido, xxhsum no debe usarse para fines relacionados con la seguridad.

xxhsum -b invoca el modo de benchmark. Vea OPCIONES y EJEMPLOS para más detalles.

OPCIONES

-V, --version
Muestra la versión de xxhsum y sale
-HTIPOHASH
Selección de hash. TIPOHASH significa 0=XXH32, 1=XXH64, 2=XXH128, 3=XXH3. Alternativamente, TIPOHASH 32=XXH32, 64=XXH64, 128=XXH128. El valor por defecto es 1 (XXH64)
--binary
Leer en modo binario.
--tag
Salida en estilo BSD.
--little-endian
Establece el valor hexadecimal de la suma de verificación de salida como convención little-endian. Por defecto, el valor se muestra como big-endian.
-h, --help
Muestra la ayuda y sale

Las siguientes opciones solo son útiles al verificar sumas de verificación (-c):

-c, --check ARCHIVO
Lee las sumas xxHash del ARCHIVO y las verifica
-q, --quiet
No imprime OK para cada archivo verificado con éxito
--strict
Devuelve un código de error si alguna línea del archivo es inválida, no solo si algunas sumas de verificación son incorrectas. Esta política está desactivada por defecto, aunque la interfaz de usuario mostrará un mensaje informativo si se detecta alguna línea inválida en el archivo.
--status
No imprime nada. El código de estado muestra el éxito.
-w, --warn
Emite un mensaje de advertencia sobre cada línea de suma de verificación formateada incorrectamente.

Las siguientes opciones solo son útiles con fines de benchmark:

-b
Modo Benchmark. Ver EJEMPLOS para más detalles.
-b#
Especifica el ID de la variante a probar. Se pueden seleccionar varias variantes, separadas por una coma (,).
-BTAMAÑODBLOQUE
Solo útil para el modo benchmark (-b). Ver EJEMPLOS para más detalles. TAMAÑODBLOQUE especifica el tamaño del bloque de datos de prueba del modo benchmark en bytes. El valor por defecto es 102400
-iITERACIONES
Solo útil para el modo benchmark (-b). Ver EJEMPLOS para más detalles. ITERACIONES especifica el número de iteraciones en el benchmark. Una sola iteración dura aproximadamente 1000 milisegundos. El valor por defecto es 3

ESTADO DE SALIDA

xxhsum sale con 0 en caso de éxito, 1 si al menos un archivo no pudo ser leído o no tiene la misma suma de verificación que la opción -c.

EJEMPLOS

Imprime los valores de las sumas de verificación xxHash (64 bits) de archivos específicos en la salida estándar

$ xxhsum -H1 foo bar baz

Imprime los valores de las sumas de verificación xxHash (32 y 64 bits) de archivos específicos en la salida estándar, y redirígelos a xyz.xxh32 y qux.xxh64

$ xxhsum -H0 foo bar baz > xyz.xxh32
$ xxhsum -H1 foo bar baz > qux.xxh64

Lee las sumas xxHash de archivos específicos y las verifica

$ xxhsum -c xyz.xxh32 qux.xxh64

Evalúa el rendimiento del algoritmo xxHash. Por defecto, xxhsum evalúa las variantes principales de xxHash en una muestra sintética de 100 KB, y muestra los resultados en la salida estándar. La primera columna es el algoritmo, la segunda columna es el tamaño de los datos de origen en bytes, la tercera columna es el número de hashes generados por segundo (rendimiento), y finalmente la última columna traduce la velocidad en megabytes por segundo.

$ xxhsum -b

En el siguiente ejemplo, la muestra a hashear se establece en 16384 bytes, las variantes a evaluar se seleccionan por sus IDs, y cada prueba de benchmark se repite 10 veces, para aumentar la precisión.

$ xxhsum -b1,2,3 -i10 -B16384
