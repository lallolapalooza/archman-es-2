xxkb(1) Manual de Comandos Generales xxkb(1)

NOMBRE

xxkb - cambia e indica la distribución de teclado actual.

SINOPSIS

xxkb

DESCRIPCIÓN

El programa xxkb muestra la distribución de teclado actual (un grupo XKB) y permite cambiarla con un clic del ratón. Tiene algunas características adicionales. xxkb recuerda la distribución para cada ventana de aplicación y cambia el estado del teclado en consecuencia cuando la ventana obtiene el foco. xxkb puede colocar un botón adicional en la barra de título de una ventana y ese botón es un cambiador e indicador para esa ventana separada. Si el mapa de teclado tiene más de dos distribuciones, xxkb puede simplificar el cambio utilizando el modo two_state. En este modo, xxkb permite elegir dos distribuciones, una como distribución base y otra como distribución alternativa, y luego cambiar únicamente el estado del teclado entre ellas. Además, xxkb admite listas de aplicaciones que permiten ajustar su comportamiento para algunas aplicaciones separadas.
xxkb funciona con cualquier gestor de ventanas.

USO

Trabajando como indicador, xxkb muestra la distribución XKB actual utilizando uno de los cuatro pixmaps y cambia el pixmap cuando cambias una distribución con el teclado (utilizando la tecla o la combinación de teclas especificada en el archivo de configuración como cambiador de grupo XKB) o utilizando cualquier otra aplicación capaz de cambiar el grupo XKB. Además, xxkb muestra pixmaps similares en la barra de título de cada ventana de aplicación, que son indicadores para ventanas separadas. Dado que el indicador global y los indicadores por ventana se duplican, puedes ocultar el indicador global o todos los indicadores por ventana utilizando las opciones de configuración.
También puedes usar xxkb como cambiador de distribución utilizando un clic del botón del ratón en la ventana principal de xxkb o en uno de los indicadores por ventana. En este último caso, cambias la distribución para la aplicación elegida.

Botón_del_ratón_1
El primer botón actúa como un cambiador de distribución. Si el modo two_state está activo, el clic del botón cambia la distribución actual entre las dos distribuciones seleccionadas (grupos XKB). De lo contrario, selecciona todas las distribuciones posibles en ciclo.
Botón_del_ratón_3
Cuando el modo two_state está activado, el tercer botón permite elegir una distribución alternativa. Selecciona todas las distribuciones posibles en ciclo y la distribución en la que te detienes se convierte en la distribución alternativa. Sin el modo two_state, la acción de este botón es la misma que la del primer botón.
Botón_del_ratón_2
La acción del segundo botón (central) depende del lugar donde hagas clic. El clic en el indicador principal termina xxkb. Pero el clic en uno de los indicadores por ventana simplemente elimina el indicador de la barra de título y excluye esa aplicación del conjunto de aplicaciones gestionadas. Además, el segundo botón te permite agregar una aplicación a una de las tres listas de aplicaciones que deben ser ignoradas (ver más abajo las Opciones de listas de aplicaciones). Al hacer clic en el indicador por ventana mientras se mantiene presionada la tecla Control, se agrega esa aplicación a la lista wm_class_class. Si se mantiene presionada la tecla Shift, el clic del botón agrega la aplicación a la lista wm_name. Si se presionan ambas teclas, el clic agrega la aplicación a la lista wm_class_name. En todos los casos, las listas actualizadas se guardarán en un archivo de configuración por usuario ~/.xxkbrc.

OPCIONES DE CONFIGURACIÓN

xxkb lee todas las opciones de configuración de los dos archivos app-defaults/XXkb y ~/.xxkbrc.

Opciones comunes

XXkb.ruta.xpm
El directorio donde xxkb busca los archivos pixmap.

Opciones de la ventana principal

XXkb.ventana_principal.habilitar
activa la ventana principal de xxkb (sí por defecto). Si se activa el modo de botón por ventana, algunos usuarios prefieren ocultar la ventana principal de xxkb.
XXkb.ventana_principal.icono_app
ejecuta xxkb como un icono animado. Es útil para gestores de ventanas que permiten 'acoplar' aplicaciones.
XXkb.ventana_principal.en_bandeja
permite acoplar xxkb a una bandeja del sistema. El valor es true o false.
XXkb.ventana_principal.geometría
la geometría ( ANCHOxALTO{+-}XOFF{+-}YOFF ) de la ventana principal. Por favor, lea la sección ESPECIFICACIONES DE GEOMETRÍA de X(7) para más detalles.
XXkb.ventana_principal.color.borde
color a utilizar al dibujar el borde de la ventana.
XXkb.ventana_principal.ancho.borde
ancho del borde en píxeles.
XXkb.ventana_principal.xpm.N
nombres de archivo pixmap para cada grupo N indicado. Si tu mapa de símbolos tiene menos de cuatro grupos, los iconos de grupos no utilizados pueden omitirse. Si el nombre del archivo comienza con '/', significa la ruta completa al archivo. De lo contrario, significa la ruta relativa a partir del valor de XXkb.ruta.xpm.
XXkb.ventana_principal.etiqueta.habilitar
habilita la impresión de etiquetas en lugar de imágenes. Se utilizarán las descripciones de grupo si no se sobrescriben con las opciones XXkb.ventana_principal.etiqueta.texto.N (donde N es 1..4, número de grupo).
XXkb.ventana_principal.etiqueta.texto.N
etiqueta para el grupo N especificado.
XXkb.ventana_principal.etiqueta.fondo
XXkb.ventana_principal.etiqueta.primerplano
colores utilizados para dibujar el fondo y el texto de la etiqueta, respectivamente.
XXkb.ventana_principal.etiqueta.fuente
fuente a utilizar al dibujar etiquetas.

Opciones de modo de operación

Dado que xxkb puede mantener el estado del teclado para cada aplicación y restaurar el estado cuando se cambia el foco, hay un grupo de opciones que controlan cómo xxkb encuentra las ventanas de las aplicaciones.

XXkb.controles.agregar_al_iniciar
Si este modo está activado (por defecto), xxkb al iniciar intenta encontrar todas las aplicaciones ya en ejecución.
XXkb.controles.agregar_al_crear
En este modo, xxkb obtiene una nueva ventana de aplicación en el momento en que la aplicación la crea. Este es el modo base, pero no puedo garantizar que funcione con todos los gestores de ventanas.
XXkb.controles.agregar_al_cambiar
En este modo, xxkb no captura las ventanas en el momento de su creación, sino que las agrega a la lista de ventanas gestionadas si el estado del teclado cambia cuando la ventana tiene el foco. Es un modo adicional (no recomendado) y solo puede ser útil si el modo agregar_al_crear por alguna razón no funciona.
XXkb.controles.sin_foco
Hace que xxkb reinicie el grupo de teclado cuando el foco sale de la ventana. El modo solo tiene sentido con el modo agregar_al_cambiar.
XXkb.controles.borrar_botón

xxkb(1) - Arch Linux Manual Pages

NAME

xxkb - keyboard layout indicator and switcher

SYNOPSIS

xxkb [-options]

DESCRIPTION

xxkb is a small utility for managing keyboard layout switching. It displays the current keyboard layout and allows the user to switch between layouts. It can be configured to display layout indicators on the screen and to automatically switch layouts based on the active window.

USAGE

The xxkb utility can be started from the command line. Its behavior can be customized through configuration options, typically specified in a configuration file (e.g., $HOME/.xxkbrc).

The program displays a main window showing the current keyboard layout. Additional buttons can be added to application windows for per-window layout control.

CONFIGURE OPTIONS

The following options can be used to configure the behavior of xxkb. These are typically placed in a configuration file.

Common options

XXkb.main.restart
If set to 1, xxkb will restart itself if it detects that the X server has been restarted.
XXkb.main.restart.delay
Delay in seconds before restarting xxkb after an X server restart. Default is 5 seconds.
XXkb.main.debug
If set to 1, xxkb will run in debug mode, printing more information to the console.
XXkb.main.quit
If set to 1, xxkb will exit when the layout is switched to the layout specified by XXkb.main.quit.layout.
XXkb.main.quit.layout
The layout to switch to in order to quit xxkb.

Main window options

XXkb.mainwindow.sticky
If set to 1, the main window will be sticky (visible on all virtual desktops).
XXkb.mainwindow.skip_taskbar
If set to 1, the main window will not appear in the taskbar.
XXkb.mainwindow.skip_pager
If set to 1, the main window will not appear in the pager.
XXkb.mainwindow.skip_switcher
If set to 1, the main window will not appear in the window switcher (e.g., Alt+Tab).
XXkb.mainwindow.ontop
If set to 1, the main window will always stay on top of other windows.
XXkb.mainwindow.geometry
Specifies the geometry of the main window (e.g., 80x30+0+0).
XXkb.mainwindow.xpm.N
Specifies the pixmap file for the Nth layout state. This allows custom icons for each layout.
XXkb.mainwindow.label.enable
If set to 1, a label will be displayed on the main window.
XXkb.mainwindow.label.text.N
Specifies the text for the label for the Nth layout state.
XXkb.mainwindow.label.background
Background color for the label.
XXkb.mainwindow.label.foreground
Foreground color for the label.
XXkb.mainwindow.label.font
Font for the label.
XXkb.mainwindow.border.color
Color of the main window border.
XXkb.mainwindow.border.width
Width of the main window border.

Operation mode options

XXkb.controls.button_delete
Este modo (activado por defecto) permite al usuario eliminar el botón por ventana usando el clic del botón central del ratón. Aunque xxkb intenta ignorar las ventanas donde el cambio de distribución del teclado no tiene sentido, tales ventanas aún pueden aparecer. O hay ventanas donde un usuario por alguna razón no desea tener el botón.
XXkb.controls.button_delete_and_forget
Este modo, además del anterior, hace que xxkb olvide la ventana cuyo botón se elimina. Esto significa que xxkb no recordará los cambios de estado del teclado en esta ventana y no restaurará este estado cuando la ventana se centre.
XXkb.controls.two_state
Cambio solo entre dos distribuciones de teclado elegidas. Si el mapa de símbolos XKB tiene más de dos grupos y no todos son necesarios para cada aplicación, xxkb permite omitir las distribuciones innecesarias en el cambio de distribución. Puede seleccionar un grupo como grupo base y otro como grupo alternativo, y luego cambiar solo entre estos dos grupos. El grupo base es común para todas las aplicaciones (generalmente contiene ASCII), pero el grupo alternativo se puede elegir por separado para cada ventana de aplicación. En este modo, el botón derecho del ratón permite seleccionar el grupo alternativo y el botón izquierdo del ratón, así como la tecla configurada como cambiador de distribución, cambian el estado actual solo entre las dos distribuciones seleccionadas.
Este modo utiliza dos opciones de configuración adicionales:
XXkb.group.base
el grupo base (entero 1..4).
XXkb.group.alt
el grupo alternativo predeterminado (entero 1..4).

Opciones del botón de la ventana de la aplicación

Todas estas opciones tienen sentido si XXkb.button.enable está activado.

XXkb.button.enable
Si está activado, xxkb añade un botón adicional a la barra de título de cada ventana administrada, que es el indicador y el cambiador de distribución para esa ventana en particular. Estos botones no son botones habituales del gestor de ventanas, sino ventanas (con un pixmap) propiedad del propio xxkb. Esto significa que, en algunos casos, un usuario necesita ajustar el tamaño y la posición del botón para que parezca un elemento de decoración del gestor de ventanas.
XXkb.button.geometry
la geometría del botón ( ANCHOxALTO{+-}DESPX{+-}DESPY ).
XXkb.button.xpm.N
los nombres de los archivos pixmap (los mismos que para las opciones XXkb.mainwindow.xpm.*).
XXkb.button.label.enable
XXkb.button.label.text.N
XXkb.button.label.background
XXkb.button.label.foreground
XXkb.button.label.font
XXkb.button.border.color
XXkb.button.border.width
ver la descripción de sus homólogos de la ventana principal.

Opciones de campana

XXkb.bell.enable
activa la campana del teclado al cambiar la distribución.
XXkb.bell.percent
un valor de argumento para la llamada XBell.

Opciones de listas de aplicaciones

xxkb permite especificar listas de aplicaciones que requieren alguna acción especial. Las aplicaciones se pueden especificar usando sus propiedades WM_CLASS o WM_NAME.
Una forma común de dicha opción es

XXkb.app_list.propiedad.acción: una lista de aplicaciones


La acción aquí puede ser una de ignore, start_alt o alt_groupn. La acción ignore significa que xxkb debe ignorar las ventanas de esas aplicaciones y no añadirlas al conjunto de ventanas administradas. La acción start_alt significa que xxkb debe establecer el estado del teclado a la distribución alternativa cuando la aplicación se inicia. Y las acciones alt_group1, alt_group2, alt_group3 u alt_group4 permiten especificar la distribución alternativa para algunas aplicaciones si esta distribución debe ser diferente de la distribución alternativa común especificada en la opción XXkb.group.alt.
La propiedad puede ser una de wm_class_class, wm_class_name o wm_name. xxkb puede identificar una aplicación usando sus propiedades de ventana WM_CLASS o WM_NAME. La propiedad WM_CLASS en realidad consta de dos partes: una res_class y una res_name. Por lo tanto, el campo propiedad especifica qué propiedad o parte de la propiedad se debe considerar para la identificación de la aplicación.
Por defecto, todas estas listas están vacías. Una lista no vacía es una secuencia de palabras separadas por espacios/tabulaciones. xxkb acepta un asterisco como parte de una palabra. Las listas largas se pueden continuar en la siguiente línea usando una barra invertida como último carácter de la línea.
Por ejemplo:
XXkb.app_list.wm_name.ignore: Fvwm* *clock \
Xman

XXkb.ignore.reverse
Esta opción cambia el significado de la lista Xxkb.*.ignore. Si la opción está activada, la lista ignore se convierte en la lista de ventanas que deben administrarse, pero todas las demás deben ignorarse.
