XXD(1) Manual de Comandos Generales XXD(1)

NOMBRE

xxd - crear un volcado hexadecimal o hacer lo contrario.

SINOPSIS

xxd -h[elp]
xxd [opciones] [archivo_entrada [archivo_salida]]
xxd -r[everse] [opciones] [archivo_entrada [archivo_salida]]

DESCRIPCIÓN

xxd crea un volcado hexadecimal de un archivo dado o de la entrada estándar. También puede convertir un volcado hexadecimal de vuelta a su forma binaria original. Al igual que uuencode(1) y uudecode(1) permite la transmisión de datos binarios en una representación ASCII "segura para correo", pero tiene la ventaja de decodificar a la salida estándar. Además, puede utilizarse para realizar parches en archivos binarios.

OPCIONES

Si no se proporciona archivo_entrada, se lee la entrada estándar. Si se especifica archivo_entrada como un carácter `-', la entrada se toma de la entrada estándar. Si no se proporciona archivo_salida (o si se utiliza un carácter `-' en su lugar), los resultados se envían a la salida estándar.

Tenga en cuenta que se utiliza un analizador "perezoso" que no comprueba más que la primera letra de la opción, a menos que la opción esté seguida de un parámetro. Los espacios entre una única letra de opción y su parámetro son opcionales. Los parámetros de las opciones se pueden especificar en notación decimal, hexadecimal u octal. Por lo tanto, -c8, -c 8, -c 010 y -cols 8 son todos equivalentes.

-a | -autoskip
Alternar salto automático: Un único '*' reemplaza las líneas NUL. Desactivado por defecto.
-b | -bits
Cambiar a volcado de bits (dígitos binarios), en lugar de volcado hexadecimal. Esta opción escribe octetos como ocho dígitos "1" y "0" en lugar de un volcado hexadecimal normal. Cada línea va precedida de un número de línea en hexadecimal y seguida de una representación ASCII (o EBCDIC). El modificador de línea de comandos -p no funciona con este modo. Puede combinarse con -i.
-c cols | -cols cols
Formatear <cols> octetos por línea. Por defecto 16 (-i: 12, -ps: 30, -b: 6). Máximo 256. Sin máximo para -ps. Con -ps, 0 da como resultado una única línea larga de salida.
-C | -capitalize
Capitalizar los nombres de variables en estilo de archivo de inclusión de C, cuando se utiliza -i.
-d
Mostrar el desplazamiento en decimal en lugar de hexadecimal.
-E | -EBCDIC
Cambiar la codificación de caracteres en la columna derecha de ASCII a EBCDIC. Esto no cambia la representación hexadecimal. La opción no tiene sentido en combinaciones con -r, -p o -i.
-e
Cambiar a volcado hexadecimal little-endian. Esta opción trata los grupos de bytes como palabras en orden de bytes little-endian. La agrupación por defecto de 4 bytes se puede cambiar usando -g. Esta opción solo se aplica al volcado hexadecimal, dejando la representación ASCII (o EBCDIC) sin cambios. Los modificadores de línea de comandos -r, -p, -i no funcionan con este modo.
-g bytes | -groupsize bytes
Separar la salida de cada <bytes> bytes (dos caracteres hexadecimales o ocho dígitos binarios cada uno) con un espacio en blanco. Especifique -g 0 para suprimir la agrupación. <Bytes> es 2 por defecto en modo normal, 4 en modo little-endian y 1 en modo bits. La agrupación no se aplica al estilo PostScript o de inclusión.
-h | -help
Imprimir un resumen de los comandos disponibles y salir. No se realiza ningún volcado hexadecimal.
-i | -include
Salida en estilo de archivo de inclusión C. Se escribe una definición de array estático completa (con el nombre del archivo de entrada), a menos que xxd lea desde la entrada estándar. Puede combinarse con -b.
-l len | -len len
Detenerse después de escribir <len> octetos.
-n name | -name name
Anular el nombre de variable de salida cuando se usa -i. El array se llama name y la longitud se llama name_len.
-o offset
Añadir <offset> a la posición del archivo mostrada.
-p | -ps | -postscript | -plain
Salida en estilo de volcado hexadecimal continuo de PostScript. También conocido como estilo de volcado hexadecimal plano.
-r | -revert
Operación inversa: convertir (o parchear) volcado hexadecimal a binario. Si no se escribe en la salida estándar, xxd escribe en su archivo de salida sin truncarlo. Use la combinación -r -p para leer volcados hexadecimales planos sin información de número de línea y sin un diseño de columna particular. Se permiten espacios adicionales y saltos de línea en cualquier lugar. Use la combinación -r -b para leer un volcado de bits en lugar de un volcado hexadecimal.
-R when
En la salida, el valor hexadecimal y el valor se colorean con el mismo color dependiendo del valor hexadecimal. Principalmente ayuda a diferenciar caracteres imprimibles y no imprimibles. when es never, always, o auto (por defecto: auto). Cuando la variable de entorno $NO_COLOR está establecida, la colorización se desactivará.
-seek offset
Cuando se usa después de -r: revertir con <offset> añadido a las posiciones de archivo encontradas en el volcado hexadecimal.
-s [+][-]seek
Empezar en el desplazamiento de archivo de entrada abs. (o rel.) <seek> bytes. + indica que la búsqueda es relativa a la posición actual del archivo stdin (sin sentido si no se lee de stdin). - indica que la búsqueda debe ser tantos caracteres desde el final de la entrada (o si se combina con +: antes de la posición actual del archivo stdin). Sin la opción -s, xxd comienza en la posición actual del archivo.
-u
Usar letras hexadecimales mayúsculas. Por defecto son minúsculas.
-v | -version
Mostrar cadena de versión.

ADVERTENCIAS

xxd -r tiene algo de magia incorporada al evaluar la información del número de línea. Si el archivo de salida es buscable, los números de línea al principio de cada línea de volcado hexadecimal pueden estar desordenados, faltar líneas o solaparse. En estos casos, xxd usará lseek(2) a la siguiente posición. Si el archivo de salida no es buscable, solo se permiten huecos, que se rellenarán con bytes nulos.

xxd -r nunca genera errores de análisis. La basura se ignora silenciosamente.

Al editar volcados hexadecimales, tenga en cuenta que xxd -r ignora todo en la línea de entrada después de leer suficientes columnas de datos hexadecimales (ver opción -c). Esto también significa que los cambios en las columnas ASCII (o EBCDIC) imprimibles siempre se ignoran. Revertir un volcado hexadecimal plano (o estilo PostScript) con xxd -r -p no depende del número correcto de columnas. Aquí, se interpreta todo lo que parece un par de dígitos hexadecimales.

Tenga en cuenta la diferencia entre
% xxd -i archivo
y
% xxd -i < archivo

xxd -s +seek puede ser diferente de xxd -s seek, ya que se utiliza lseek(2) para "rebobinar" la entrada. Un '+' marca una diferencia si la fuente de entrada es stdin, y si la posición del archivo de stdin no está al principio del archivo en el momento en que se inicia xxd y se le proporciona su entrada. Los siguientes ejemplos pueden ayudar a clarificar (¡o confundir aún más!):

Rebobinar stdin antes de leer; necesario porque `cat' ya ha leído hasta el final de stdin.
% sh -c "cat > copia_plana; xxd -s 0 > copia_hex" < archivo

Volcado hexadecimal a partir de la posición del archivo 0x480 (=1024+128). El signo '+' significa "relativo a la posición actual", por lo tanto, los '128' se suman al 1k donde dd se quedó.
% sh -c "dd of

=plain_snippet bs=1k count=1; xxd -s +128 > hex_snippet" < archivo

Volcado hexadecimal desde la posición 0x100 (=1024-768) en adelante del archivo.
% sh -c "dd of=plain_snippet bs=1k count=1; xxd -s +-768 > hex_snippet" < archivo

Sin embargo, esta es una situación poco común y el uso de `+' raramente es necesario. El autor prefiere supervisar el efecto de xxd con strace(1) o truss(1), siempre que se use -s.

EJEMPLOS

Imprime todo excepto las tres primeras líneas (hex 0x30 bytes) de archivo.
% xxd -s 0x30 archivo

Imprime 3 líneas (hex 0x30 bytes) desde el final de archivo.
% xxd -s -0x30 archivo

Mostrar solo la fecha del archivo xxd.1
% xxd -s 0x33 -l 13 -c 13 xxd.1
00000033: 3231 7374 204d 6179 2031 3939 36 21st May 1996

Copiar archivo_entrada a archivo_salida y anteponer 100 bytes con valor 0x00.
% xxd archivo_entrada | xxd -r -s 100 > archivo_salida

Parchear la fecha en el archivo xxd.1
% echo "0000034: 3574 68" | xxd -r - xxd.1
% xxd -s 0x33 -l 13 -c 13 xxd.1
00000033: 3235 7468 204d 6179 2031 3939 36 25th May 1996

Crear un archivo de 65537 bytes con todos los bytes 0x00, excepto el último que es 'A' (hex 0x41).
% echo "010000: 41" | xxd -r > archivo

Volcado hexadecimal de este archivo con salto automático.
% xxd -a -c 12 archivo
00000000: 0000 0000 0000 0000 0000 0000 ............
*
0000fffc: 0000 0000 41 ....A

Crear un archivo de 1 byte que contenga un solo carácter 'A'. El número después de '-r -s' se suma a los números de línea encontrados en el archivo; en efecto, se suprimen los bytes iniciales.
% echo "010000: 41" | xxd -r -s -0x10000 > archivo

Usar xxd como un filtro dentro de un editor como vim(1) para realizar un volcado hexadecimal de una región marcada entre `a' y `z'.
:'a,'z!xxd

Usar xxd como un filtro dentro de un editor como vim(1) para recuperar un volcado hexadecimal binario marcado entre `a' y `z'.
:'a,'z!xxd -r

Usar xxd como un filtro dentro de un editor como vim(1) para recuperar una línea de un volcado hexadecimal. Mover el cursor sobre la línea y escribir:
!!xxd -r

Leer caracteres individuales de una línea serie
% xxd -c1 < /dev/term/b &
% stty < /dev/term/b -echo -opost -isig -icanon min 1
% echo -n foo > /dev/term/b

VALORES DE RETORNO

Se devuelven los siguientes valores de error:

0
no se encontraron errores.
-1
operación no soportada (xxd -r -i aún imposible).
1
error al analizar las opciones.
2
problemas con el archivo de entrada.
3
problemas con el archivo de salida.
4,5
la posición de búsqueda deseada no es alcanzable.
