NOMBRE

x42-scope - Osciloscopio JACK/LV2

SINOPSIS

x42-scope

DESCRIPCIÓN

x42-scope es un osciloscopio de cuatro canales para usar con el JACK Audio Connection Kit.

Es equivalente a usar el plugin 'http://gareus.org/oss/lv2/sisco#4chan' LV2, excepto que es una versión independiente, sin depender de ningún host LV2.

x42-scope/SiSco implementa una visualización clásica de osciloscopio con el tiempo en el eje X y el nivel de la señal en el eje Y. La escala de tiempo mínima es de 50 microsegundos por cuadrícula, lo que proporciona una resolución máxima de 960 kHz a 48 KHz.

USO

x42-scope no acepta opciones. Se puede cerrar enviando una señal SIGTERM (CTRL+C) en la línea de comandos o cerrando la ventana. Todos los elementos de control se operan usando el ratón:

Clic+Arrastrar
izquierda/abajo: disminuir, derecha/arriba: aumentar valor. Mantenga pulsada la tecla Ctrl para aumentar la sensibilidad.
Shift+Clic
restablecer al valor predeterminado
Rueda del ratón
arriba/abajo en 1 paso (el ajuste más pequeño posible para la configuración dada). El desplazamiento continuo rápido aumenta el tamaño del paso.

La documentación detallada sobre su funcionamiento se puede encontrar en http://x42.github.io/sisco.lv2/
