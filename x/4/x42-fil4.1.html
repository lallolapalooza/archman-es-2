X42-FIL4(1) Comandos de usuario X42-FIL4(1)

NOMBRE

x42-fil4 - Ecualizador Paramétrico JACK de x42

SINOPSIS

x42-fil4 [ OPCIONES ] [ ID de plugin o URI ]

DESCRIPCIÓN

x42-fil4 - EQ Paramétrico JACK

Esta es una aplicación JACK independiente de una colección de plugins LV2. Usa el ID -1, -l o --list para una lista dedicada de los plugins incluidos. Por defecto se utiliza el primer plugin listado (ID 0).

Lista de plugins disponibles: (ID "Nombre" URI)

0
"x42-eq - Ecualizador Paramétrico Estéreo" http://gareus.org/oss/lv2/fil4#stereo
1
"x42-eq - Ecualizador Paramétrico Mono" http://gareus.org/oss/lv2/fil4#mono

Uso: Todos los elementos de control se manejan con el ratón:

Clic+Arrastrar
izquierda/abajo: disminuye el valor, derecha/arriba: aumenta el valor. Mantén presionada la tecla Ctrl para aumentar la sensibilidad.
Mayús+Clic
restablece al valor predeterminado
Rueda del ratón
arriba/abajo en 1 paso (el ajuste más pequeño posible para la configuración dada). El desplazamiento continuo rápido aumenta el tamaño del paso.

La aplicación se puede cerrar enviando una SIGTERM (CTRL+C) en la línea de comandos o cerrando la ventana.

OPCIONES

-h, --help
Muestra esta ayuda y sale
-j, --jack-name <nombre>
Establece el nombre del cliente JACK (el valor predeterminado es el nombre del plugin)
-G, --nogui
se ejecuta sin interfaz gráfica, útil para control remoto OSC.
-l, --list
Imprime la lista de plugins disponibles y sale
-O <puerto>, --osc <puerto>
Escucha mensajes OSC en el puerto UDP dado
-p <índice>:<valor>, --port <índice>:<valor>
Establece el valor inicial para el puerto de control dado
-P, --portlist
Imprime la lista de puertos de control al inicio
--osc-doc
Imprime los comandos OSC disponibles y sale
-V, --version
Imprime la información de la versión y sale

Ver también: http://gareus.org/oss/lv2/fil4 Sitio web: http://x42-plugins.com/
