x42-meter - Colección de Medidores de Audio JACK

SINOPSIS

x42-meter [ OPCIONES ] [ ID o URI del plugin ]

DESCRIPCIÓN

x42-meter - Colección de Medidores JACK

Esta es una aplicación independiente de JACK de una colección de plugins LV2. Usa el ID -1, -l o --list para una lista dedicada de plugins incluidos. Por defecto se utiliza el primer plugin listado (ID 0).

Uso: Todos los elementos de control se operan usando el ratón:

Clic+Arrastrar
izquierda/abajo: disminuir, derecha/arriba: aumentar valor. Mantén presionada la tecla Ctrl para aumentar la sensibilidad.
Mayús+Clic
restablecer al valor predeterminado
Rueda de desplazamiento
arriba/abajo en 1 paso (el ajuste más pequeño posible para la configuración dada). El desplazamiento continuo rápido aumenta el tamaño del paso.

La aplicación se puede cerrar enviando una señal SIGTERM (CTRL+C) en la línea de comandos o cerrando la ventana.

OPCIONES

-h, --help
Mostrar esta ayuda y salir
-j, --jack-name <nombre>
Establecer el nombre del cliente JACK (por defecto es el nombre del plugin)
-G, --nogui
ejecutar sin interfaz gráfica, útil para control remoto OSC.
-l, --list
Imprimir lista de plugins disponibles y salir
-O <puerto>, --osc <puerto>
Escuchar mensajes OSC en el puerto UDP dado
-p <idx>:<val>, --port <idx>:<val>
Establecer el valor inicial para el puerto de control dado
-P, --portlist
Imprimir lista de puertos de control al inicio
--osc-doc
Imprimir comandos OSC disponibles y salir
-V, --version
Imprimir información de la versión y salir
