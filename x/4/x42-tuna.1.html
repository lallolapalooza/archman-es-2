NOMBRE

x42-tuna - Afinador de instrumentos musicales JACK

SINOPSIS

x42-tuna [ OPCIONES ] [ ID_plugin o URI ]

DESCRIPCIÓN

x42-tuna - Afinador de instrumentos JACK

Esta es una aplicación JACK independiente de una colección de plugins LV2. Usa el ID -1, -l o --list para una lista dedicada de plugins incluidos. Por defecto se usa el primer plugin listado (ID 0).

Lista de plugins disponibles: (ID "Nombre" URI)

0
"x42 Instrument Tuner" http://gareus.org/oss/lv2/tuna#one
1
"x42 Instrument Tuner[Spectrum]" http://gareus.org/oss/lv2/tuna#two

Uso: Todos los elementos de control se manejan usando el ratón:

Clic+Arrastrar
izquierda/abajo: disminuir, derecha/arriba: aumentar valor. Mantén presionada la tecla Ctrl para aumentar la sensibilidad.
Mayús+Clic
restablecer al valor predeterminado
Rueda de desplazamiento
arriba/abajo en 1 paso (el ajuste más pequeño posible para la configuración dada). El desplazamiento continuo rápido aumenta el tamaño del paso.

La aplicación se puede cerrar enviando una señal SIGTERM (CTRL+C) en la línea de comandos o cerrando la ventana.

OPCIONES

-h, --help
Muestra esta ayuda y sal.
-j, --jack-name <nombre>
Establece el nombre del cliente JACK (por defecto es el nombre del plugin).
-G, --nogui
Ejecutar sin interfaz gráfica, útil para control remoto OSC.
-l, --list
Imprime la lista de plugins disponibles y sal.
-O <puerto>, --osc <puerto>
Escucha mensajes OSC en el puerto UDP dado.
-p <índice>:<valor>, --port <índice>:<valor>
Establece el valor inicial para el puerto de control dado.
-P, --portlist
Imprime la lista de puertos de control al inicio.
--osc-doc
Imprime los comandos OSC disponibles y sal.
-V, --version
Imprime información de la versión y sal.

Ver también: http://gareus.org/oss/lv2/tuna Sitio web: http://x42-plugins.com/
