X42-SPECTR(1) Comandos de Usuario X42-SPECTR(1)

NOMBRE

x42-spectr - Analizador x42-spectr

SINOPSIS

x42-spectr [ OPCIONES]

DESCRIPCIÓN

x42-spectr - Espectrograma JACK

Esta es una aplicación JACK independiente del plugin LV2: "Spectr".

Uso: Todos los elementos de control se manejan con el ratón:

Clic+Arrastrar
izquierda/abajo: disminuir, derecha/arriba: aumentar valor. Mantenga pulsada la tecla Ctrl para aumentar la sensibilidad.
Mayús+Clic
restablecer al valor predeterminado
Rueda del ratón
arriba/abajo en 1 paso (el ajuste más pequeño posible para la configuración dada). El desplazamiento continuo rápido aumenta el tamaño del paso.

La aplicación se puede cerrar enviando una señal SIGTERM (CTRL+C) en la línea de comandos o cerrando la ventana.

OPCIONES

-h, --help
Mostrar esta ayuda y salir
-j, --jack-name <nombre>
Establecer el nombre del cliente JACK (por defecto es nombre-plugin)
-G, --nogui
ejecutar sin interfaz gráfica, útil para control remoto OSC.
-O <puerto>, --osc <puerto>
Escuchar mensajes OSC en el puerto UDP dado
-p <índice>:<valor>, --port <índice>:<valor>
Establecer el valor inicial para el puerto de control dado
-P, --portlist
Imprimir la lista de puertos de control al inicio
--osc-doc
Imprimir los comandos OSC disponibles y salir
-V, --version
Imprimir información de la versión y salir

Ver también: http://gareus.org/oss/lv2/spectra#Mono Sitio web: http://x42-plugins.com/
