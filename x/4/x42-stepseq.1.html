X42-STEPSEQ(1) Comandos de usuario X42-STEPSEQ(1)

NOMBRE

x42-stepseq - Secuenciador por pasos x42

SINOPSIS

x42-stepseq [ OPCIONES ]

DESCRIPCIÓN

x42-stepseq - Secuenciador por pasos MIDI de x42 8x8

Esta es una aplicación JACK independiente del plugin LV2: "MIDI Step Sequencer8x8".

Uso: Todos los elementos de control se manejan con el ratón:

Clic+Arrastrar
izquierda/abajo: disminuye el valor, derecha/arriba: aumenta el valor. Mantenga pulsada la tecla Ctrl para aumentar la sensibilidad.
Mayús+Clic
restablece al valor predeterminado
Rueda de desplazamiento
arriba/abajo en 1 paso (el ajuste más pequeño posible para la configuración dada). El desplazamiento continuo y rápido aumenta el tamaño del paso.

La aplicación se puede cerrar enviando una señal SIGTERM (CTRL+C) en la línea de comandos o cerrando la ventana.

OPCIONES

-h, --help
Muestra esta ayuda y sale
-j, --jack-name <nombre>
Establece el nombre del cliente JACK (por defecto es el nombre del plugin)
-G, --nogui
ejecutar sin interfaz gráfica, útil para control remoto OSC.
-O <puerto>, --osc <puerto>
Escucha mensajes OSC en el puerto UDP dado
-p <idx>:<val>, --port <idx>:<val>
Establece el valor inicial para el puerto de control dado
-P, --portlist
Imprime la lista de puertos de control al iniciar
--osc-doc
Imprime los comandos OSC disponibles y sale
-V, --version
Imprime la información de la versión y sale

Ver también: http://gareus.org/oss/lv2/stepseq#s8n8 Sitio web: http://x42-plugins.com/
