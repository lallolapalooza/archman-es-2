Documentación Función/Subrutina

subroutine zsytri (character uplo, integer n, complex*16, dimension( lda, * ) a, integer lda, integer, dimension( * ) ipiv, complex*16, dimension( * ) work, integer info)

ZSYTRI

Propósito:

!>
!> ZSYTRI calcula la inversa de una matriz simétrica indefinida compleja
!> A utilizando la factorización A = U*D*U**T o A = L*D*L**T calculada por
!> ZSYTRF.
!>

Parámetros

UPLO 
!>          UPLO es CHARACTER*1
!>          Especifica si los detalles de la factorización se almacenan
!>          como una matriz triangular superior o inferior.
!>          = 'U':  Triangular superior, la forma es A = U*D*U**T;
!>          = 'L':  Triangular inferior, la forma es A = L*D*L**T.
!>

N

!>          N es INTEGER
!>          El orden de la matriz A.  N >= 0.
!>

A

!>          A es un array COMPLEX*16, dimensión (LDA,N)
!>          En la entrada, la matriz diagonal por bloques D y los multiplicadores
!>          utilizados para obtener el factor U o L calculados por ZSYTRF.
!>
!>          En la salida, si INFO = 0, la inversa (simétrica) de la matriz
!>          original.  Si UPLO = 'U', se forma la parte triangular superior de la
!>          inversa y la parte de A debajo de la diagonal no se referencia; si UPLO = 'L'
!>          se forma la parte triangular inferior de la inversa y la parte de A
!>          encima de la diagonal no se referencia.
!>

LDA

!>          LDA es INTEGER
!>          La dimensión principal del array A.  LDA >= max(1,N).
!>

IPIV

!>          IPIV es un array INTEGER, dimensión (N)
!>          Detalles de los intercambios y la estructura de bloques de D
!>          según lo determinado por ZSYTRF.
!>

WORK

!>          WORK es un array COMPLEX*16, dimensión (2*N)
!>

INFO

!>          INFO es INTEGER
!>          = 0: salida exitosa
!>          < 0: si INFO = -i, el i-ésimo argumento tenía un valor ilegal
!>          > 0: si INFO = i, D(i,i) = 0; la matriz es singular y su
!>               inversa no pudo ser calculada.
!>
