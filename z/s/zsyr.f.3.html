subroutine zsyr (character uplo, integer n, complex*16 alpha, complex*16, dimension( * ) x, integer incx, complex*16, dimension( lda, * ) a, integer lda)

ZSYR realiza la actualización de rango 1 simétrico de una matriz simétrica compleja.

Propósito:

!>
!> ZSYR   realiza la operación simétrica de rango 1
!>
!>    A := alpha*x*x**H + A,
!>
!> donde alpha es un escalar complejo, x es un vector de n elementos y A es una
!> matriz simétrica de n por n.
!>

Parámetros

UPLO 
!>          UPLO es CHARACTER*1
!>           A la entrada, UPLO especifica si la parte triangular superior o inferior
!>           del array A se va a referenciar según lo siguiente:
!>
!>              UPLO = 'U' o 'u'   Solo se referenciará la parte triangular superior de A.
!>
!>              UPLO = 'L' o 'l'   Solo se referenciará la parte triangular inferior de A.
!>
!>           Sin cambios a la salida.
!>

N

!>          N es INTEGER
!>           A la entrada, N especifica el orden de la matriz A.
!>           N debe ser al menos cero.
!>           Sin cambios a la salida.
!>

ALPHA

!>          ALPHA es COMPLEX*16
!>           A la entrada, ALPHA especifica el escalar alpha.
!>           Sin cambios a la salida.
!>

X

!>          X es un array COMPLEX*16, con dimensión al menos
!>           ( 1 + ( N - 1 )*abs( INCX ) ).
!>           Antes de la entrada, el array X incrementado debe contener el vector x
!>           de N elementos.
!>           Sin cambios a la salida.
!>

INCX

!>          INCX es INTEGER
!>           A la entrada, INCX especifica el incremento para los elementos de
!>           X. INCX no debe ser cero.
!>           Sin cambios a la salida.
!>

A

!>          A es un array COMPLEX*16, con dimensión ( LDA, N )
!>           Antes de la entrada, con UPLO = 'U' o 'u', la parte triangular superior
!>           principal de n por n del array A debe contener la parte triangular superior
!>           de la matriz simétrica y la parte estrictamente inferior de A no se referencia.
!>           A la salida, la parte triangular superior del array A se sobrescribe con
!>           la parte triangular superior de la matriz actualizada.
!>           Antes de la entrada, con UPLO = 'L' o 'l', la parte triangular inferior
!>           principal de n por n del array A debe contener la parte triangular inferior
!>           de la matriz simétrica y la parte estrictamente superior de A no se referencia.
!>           A la salida, la parte triangular inferior del array A se sobrescribe con
!>           la parte triangular inferior de la matriz actualizada.
!>

LDA

!>          LDA es INTEGER
!>           A la entrada, LDA especifica la primera dimensión de A tal como se declaró
!>           en el programa (sub)llamador. LDA debe ser al menos
!>           max( 1, N ).
!>           Sin cambios a la salida.
!>
