Documentación de función/subrutina

subroutine zsyr2k (character uplo, character trans, integer n, integer k, complex*16 alpha, complex*16, dimension(lda,*) a, integer lda, complex*16, dimension(ldb,*) b, integer ldb, complex*16 beta, complex*16, dimension(ldc,*) c, integer ldc)

ZSYR2K

Propósito:

!>
!> ZSYR2K  realiza una de las operaciones simétricas de rango 2k
!>
!>    C := alpha*A*B**T + alpha*B*A**T + beta*C,
!>
!> o
!>
!>    C := alpha*A**T*B + alpha*B**T*A + beta*C,
!>
!> donde  alpha y beta  son escalares,  C es una matriz simétrica de n x n
!> y  A y B  son  matrices de n x k  en el primer  caso y  matrices de k x n
!> en el segundo caso.
!>

Parámetros

UPLO 
!>          UPLO es CHARACTER*1
!>           A la entrada,  UPLO  especifica si la parte  superior o inferior
!>           triangular del array  C  debe ser referenciada como
!>           se indica a continuación:
!>
!>              UPLO = 'U' o 'u'   Solo la parte triangular superior de  C
!>                                  se referencia.
!>
!>              UPLO = 'L' o 'l'   Solo la parte triangular inferior de  C
!>                                  se referencia.
!>

TRANS

!>          TRANS es CHARACTER*1
!>           A la entrada,  TRANS  especifica la operación a realizar como
!>           se indica a continuación:
!>
!>              TRANS = 'N' o 'n'    C := alpha*A*B**T + alpha*B*A**T +
!>                                         beta*C.
!>
!>              TRANS = 'T' o 't'    C := alpha*A**T*B + alpha*B**T*A +
!>                                         beta*C.
!>

N

!>          N es INTEGER
!>           A la entrada,  N  especifica el orden de la matriz C.  N debe
!>           ser al menos cero.
!>

K

!>          K es INTEGER
!>           A la entrada con  TRANS = 'N' o 'n',  K  especifica el número
!>           de  columnas  de las matrices  A y B,  y a la entrada con
!>           TRANS = 'T' o 't',  K  especifica el número de filas de las
!>           matrices  A y B.  K debe ser al menos cero.
!>

ALPHA

!>          ALPHA es COMPLEX*16
!>           A la entrada, ALPHA especifica el escalar alpha.
!>

A

!>          A es un array COMPLEX*16, dimension ( LDA, ka ), donde ka es
!>           k  cuando  TRANS = 'N' o 'n',  y es  n  en caso contrario.
!>           Antes de la entrada con  TRANS = 'N' o 'n',  la parte  n x k
!>           principal del array  A  debe contener la matriz  A,  en caso
!>           contrario, la parte  k x n  principal del array  A  debe
!>           contener la matriz A.
!>

LDA

!>          LDA es INTEGER
!>           A la entrada, LDA especifica la primera dimensión de A tal como
!>           se declara en el programa (sub)llamador.   Cuando  TRANS = 'N' o 'n'
!>           entonces  LDA debe ser al menos  max( 1, n ), en caso contrario
!>           LDA debe ser al menos  max( 1, k ).
!>

B

!>          B es un array COMPLEX*16, dimension ( LDB, kb ), donde kb es
!>           k  cuando  TRANS = 'N' o 'n',  y es  n  en caso contrario.
!>           Antes de la entrada con  TRANS = 'N' o 'n',  la parte  n x k
!>           principal del array  B  debe contener la matriz  B,  en caso
!>           contrario, la parte  k x n  principal del array  B  debe
!>           contener la matriz B.
!>

LDB

!>          LDB es INTEGER
!>           A la entrada, LDB especifica la primera dimensión de B tal como
!>           se declara en el programa (sub)llamador.   Cuando  TRANS = 'N' o 'n'
!>           entonces  LDB debe ser al menos  max( 1, n ), en caso contrario
!>           LDB debe ser al menos  max( 1, k ).
!>

BETA

!>          BETA es COMPLEX*16
!>           A la entrada, BETA especifica el escalar beta.
!>

C

!>          C es un array COMPLEX*16, dimension ( LDC, N )
!>           Antes de la entrada con  UPLO = 'U' o 'u',  la parte  n x n
!>           triangular superior del array C debe contener la parte
!>           triangular superior  de la matriz simétrica  y la parte
!>           triangular estrictamente inferior de C no se referencia.  A la
!>           salida, la parte triangular superior del array  C  se
!>           sobrescribe con la parte triangular superior de la matriz
!>           actualizada.
!>           Antes de la entrada con  UPLO = 'L' o 'l',  la parte  n x n
!>           triangular inferior del array C debe contener la parte
!>           triangular inferior  de la matriz simétrica  y la parte
!>           triangular estrictamente superior de C no se referencia.  A la
!>           salida, la parte triangular inferior del array  C  se
!>           sobrescribe con la parte triangular inferior de la matriz
!>           actualizada.
!>

LDC

!>          LDC es INTEGER
!>           A la entrada, LDC especifica la primera dimensión de C tal como
!>           se declara en el programa (sub)llamador.   LDC  debe ser
!>           al menos  max( 1, n ).
!>
