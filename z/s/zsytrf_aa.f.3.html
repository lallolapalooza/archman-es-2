Documentación de Función/Subrutina

subrutina zsytrf_aa (carácter uplo, entero n, complejo*16, dimensión( lda, * ) a, entero lda, entero, dimensión( * ) ipiv, complejo*16, dimensión( * ) work, entero lwork, entero info)

ZSYTRF_AA

Propósito:

!>
!> ZSYTRF_AA calcula la factorización de una matriz simétrica compleja A
!> usando el algoritmo de Aasen. La forma de la factorización es
!>
!>    A = U**T*T*U  o  A = L*T*L**T
!>
!> donde U (o L) es un producto de matrices triangulares superiores (inferiores) unitarias y de permutación, y T es una matriz simétrica tridiagonal compleja.
!>
!> Esta es la versión bloqueada del algoritmo, llamando a BLAS de Nivel 3.
!>

Parámetros

UPLO 
!>          UPLO es CHARACTER*1
!>          = 'U':  El triángulo superior de A está almacenado;
!>          = 'L':  El triángulo inferior de A está almacenado.
!>

N

!>          N es INTEGER
!>          El orden de la matriz A. N >= 0.
!>

A

!>          A es un array COMPLEX*16, dimensión (LDA,N)
!>          En la entrada, la matriz simétrica A. Si UPLO = 'U', la parte superior
!>          triangular N-por-N líder de A contiene la parte triangular superior
!>          de la matriz A, y la parte estrictamente triangular inferior de A no se referencia. Si UPLO = 'L', la parte inferior
!>          triangular N-por-N líder de A contiene la parte triangular inferior
!>          de la matriz A, y la parte estrictamente triangular superior de A no se referencia.
!>
!>          En la salida, la matriz tridiagonal se almacena en las diagonales
!>          y las subdiagonales de A justo debajo (o encima) de las diagonales,
!>          y L se almacena debajo (o encima) de las subdiagonales, cuando UPLO
!>          es 'L' (o 'U').
!>

LDA

!>          LDA es INTEGER
!>          La dimensión líder del array A. LDA >= max(1,N).
!>

IPIV

!>          IPIV es un array INTEGER, dimensión (N)
!>          En la salida, contiene los detalles de los intercambios, es decir,
!>          la fila y columna k de A se intercambiaron con la
!>          fila y columna IPIV(k).
!>

WORK

!>          WORK es un array COMPLEX*16, dimensión (MAX(1,LWORK))
!>          En la salida, si INFO = 0, WORK(1) devuelve el LWORK óptimo.
!>

LWORK

!>          LWORK es INTEGER
!>          La longitud de WORK. LWORK >=MAX(1,2*N). Para un rendimiento óptimo
!>          LWORK >= N*(1+NB), donde NB es el tamaño de bloque óptimo.
!>
!>          Si LWORK = -1, entonces se asume una consulta de espacio de trabajo; la rutina
!>          solo calcula el tamaño óptimo del array WORK, devuelve
!>          este valor como la primera entrada del array WORK, y no se emite ningún mensaje de error
!>          relacionado con LWORK por XERBLA.
!>

INFO

!>          INFO es INTEGER
!>          = 0:  Salida exitosa
!>          < 0:  si INFO = -i, el argumento i-ésimo tuvo un valor ilegal.
!>
