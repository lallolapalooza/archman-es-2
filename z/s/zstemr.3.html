ZSTEMR

Propósito:

!>
!> ZSTEMR calcula autovalores seleccionados y, opcionalmente, autovectores
!> de una matriz tridiagonal simétrica real T. Cualquier matriz no reducida de este tipo tiene
!> un conjunto bien definido de autovalores reales distintos por pares, los autovectores
!> reales correspondientes son ortogonales por pares.
!>
!> El espectro puede ser calculado ya sea completamente o parcialmente especificando
!> un intervalo (VL,VU] o un rango de índices IL:IU para los autovalores deseados.
!>
!> Dependiendo del número de autovalores deseados, estos se calculan ya sea
!> por bisección o por el algoritmo dqds. Los autovectores ortogonales numéricamente se
!> calculan mediante el uso de varias factorizaciones L D L^T adecuadas cerca de cúmulos
!> de autovalores cercanos (denominados RRR, Representaciones Relativamente Robustas).
!> Un esbozo informal del algoritmo sigue.
!>
!> Para cada bloque no reducido (submatriz) de T,
!>    (a) Calcular T - sigma I  = L D L^T, de modo que L y D
!>        definen todos los autovalores deseados con alta precisión relativa.
!>        Esto significa que pequeños cambios relativos en las entradas de D y L
!>        causan solo pequeños cambios relativos en los autovalores y
!>        autovectores. La representación estándar (no factorizada) de la
!>        matriz tridiagonal T no tiene esta propiedad en general.
!>    (b) Calcular los autovalores con la precisión adecuada.
!>        Si se desean los autovectores, el algoritmo alcanza la precisión completa
!>        de los autovalores calculados solo justo antes de
!>        que los vectores correspondientes tengan que ser calculados, ver pasos c) y d).
!>    (c) Para cada cúmulo de autovalores cercanos, seleccionar un nuevo
!>        desplazamiento cercano al cúmulo, encontrar una nueva factorización y refinar
!>        los autovalores desplazados a la precisión adecuada.
!>    (d) Para cada autovalor con una separación relativa suficientemente grande, calcular
!>        el autovector correspondiente formando una factorización retorcida que revele el rango.
!>        Volver a (c) para cualquier cúmulo que permanezca.
!>
!> Para más detalles, ver:
!> - Inderjit S. Dhillon y Beresford N. Parlett: 
!>   Linear Algebra and its Applications, 387(1), pp. 1-28, Agosto 2004.
!> - Inderjit Dhillon y Beresford Parlett:  SIAM Journal on Matrix Analysis and Applications, Vol. 25,
!>   2004.  También LAPACK Working Note 154.
!> - Inderjit Dhillon: ,
!>   Computer Science Division Technical Report No. UCB/CSD-97-971,
!>   UC Berkeley, Mayo 1997.
!>
!> Detalles Adicionales
!> 1. ZSTEMR solo funciona en máquinas que siguen el estándar de punto flotante
!> IEEE-754 en su manejo de infinitos y NaNs.
!> Esto permite el uso de bucles internos eficientes que evitan la verificación de
!> divisores cero.
!>
!> 2. Las rutinas de LAPACK pueden usarse para reducir una matriz hermitiana compleja a
!> forma tridiagonal simétrica real.
!>
!> (Cualquier matriz tridiagonal hermitiana compleja tiene valores reales en su diagonal
!> y potencialmente números complejos en sus subdiagonales. Aplicando una
!> transformación de semejanza con una matriz diagonal apropiada
!> diag(1,e^{i \phy_1}, ... , e^{i \phy_{n-1}}), la matriz hermitiana compleja
!> puede ser transformada en una matriz simétrica real y la aritmética compleja
!> puede evitarse por completo.)
!>
!> Mientras que los autovectores de la matriz tridiagonal simétrica real son reales,
!> los autovectores de la matriz hermitiana compleja original tienen entradas complejas
!> en general.
!> Dado que los drivers de LAPACK sobrescriben los datos de la matriz con los autovectores,
!> ZSTEMR acepta espacio de trabajo complejo para facilitar la interoperabilidad
!> con ZUNMTR o ZUPMTR.
!>

Parámetros

JOBZ 
!>          JOBZ es CHARACTER*1
!>          = 'N':  Solo calcula autovalores;
!>          = 'V':  Calcula autovalores y autovectores.
!>

RANGE

!>          RANGE es CHARACTER*1
!>          = 'A': se encontrarán todos los autovalores.
!>          = 'V': se encontrarán todos los autovalores en el intervalo semiabierto (VL,VU]
!>                 .
!>          = 'I': se encontrarán los autovalores del IL-ésimo al IU-ésimo.
!>

N

!>          N es INTEGER
!>          El orden de la matriz.  N >= 0.
!>

D

!>          D es un array DOUBLE PRECISION, dimensión (N)
!>          En la entrada, los N elementos diagonales de la matriz tridiagonal
!>          T. En la salida, D se sobrescribe.
!>

E

!>          E es un array DOUBLE PRECISION, dimensión (N)
!>          En la entrada, los (N-1) elementos subdiagonales de la matriz tridiagonal
!>          T en los elementos 1 a N-1 de E. E(N) no necesita ser establecido en
!>          la entrada, pero se usa internamente como espacio de trabajo.
!>          En la salida, E se sobrescribe.
!>

VL

!>          VL es DOUBLE PRECISION
!>
!>          Si RANGE='V', el límite inferior del intervalo a
!>          buscar para los autovalores. VL < VU.
!>          No referenciado si RANGE = 'A' o 'I'.
!>

VU

!>          VU es DOUBLE PRECISION
!>
!>          Si RANGE='V', el límite superior del intervalo a
!>          buscar para los autovalores. VL < VU.
!>          No referenciado si RANGE = 'A' o 'I'.
!>

IL

!>          IL es INTEGER
!>
!>          Si RANGE='I', el índice del
!>          autovalor más pequeño a devolver.
!>          1 <= IL <= IU <= N, si N > 0.
!>          No referenciado si RANGE = 'A' o 'V'.
!>

IU

!>          IU es INTEGER
!>
!>          Si RANGE='I', el índice del
!>          autovalor más grande a devolver.
!>          1 <= IL <= IU <= N, si N > 0.
!>          No referenciado si RANGE = 'A' o 'V'.
!>

M

!>          M es INTEGER
!>          El número total de autovalores encontrados.  0 <= M <= N.
!>          Si RANGE = 'A', M = N, y si RANGE = 'I', M = IU-IL+1.
!>

W

!>          W es un array DOUBLE PRECISION, dimensión (N)
!>          Los primeros M elementos contienen los autovalores seleccionados en
!>          orden ascendente.
!>

Z

!>          Z es un array COMPLEX*16, dimensión (LDZ, max(1,M) )
!>          Si JOBZ = 'V', y si INFO = 0, entonces las primeras M columnas de Z
!>          contienen los autovectores ortonormales de la matriz T
!>          correspondientes a los autovalores seleccionados, con la i-ésima
!>          columna de Z conteniendo el autovector asociado a W(i).
!>          Si JOBZ = 'N', entonces Z no se referencia.
!>          Nota: el usuario debe asegurarse de que se suministren al menos max(1,M) columnas
!>          en el array Z; si RANGE = 'V', el valor exacto de M
!>          no se conoce de antemano y se puede calcular con una consulta de
!>          espacio de trabajo estableciendo NZC = -1, ver más abajo.
!>

LDZ

!>          LDZ es INTEGER
!>          La dimensión principal del array Z.  LDZ >= 1, y si
!>          JOBZ = 'V', entonces LDZ >= max(1,N).
!>

NZC

!>          NZC es INTEGER
!>          El número
!> If NZC = -1, then a workspace query is assumed; the !> routine calculates the number of columns of the array Z that !> are needed to hold the eigenvectors. !> This value is returned as the first entry of the Z array, and !> no error message related to NZC is issued by XERBLA. !>

ISUPPZ

!>          ISUPPZ is INTEGER array, dimension ( 2*max(1,M) )
!>          The support of the eigenvectors in Z, i.e., the indices
!>          indicating the nonzero elements in Z. The i-th computed eigenvector
!>          is nonzero only in elements ISUPPZ( 2*i-1 ) through
!>          ISUPPZ( 2*i ). This is relevant in the case when the matrix
!>          is split. ISUPPZ is only accessed when JOBZ is 'V' and N > 0.
!>

TRYRAC

!>          TRYRAC is LOGICAL
!>          If TRYRAC = .TRUE., indicates that the code should check whether
!>          the tridiagonal matrix defines its eigenvalues to high relative
!>          accuracy.  If so, the code uses relative-accuracy preserving
!>          algorithms that might be (a bit) slower depending on the matrix.
!>          If the matrix does not define its eigenvalues to high relative
!>          accuracy, the code can uses possibly faster algorithms.
!>          If TRYRAC = .FALSE., the code is not required to guarantee
!>          relatively accurate eigenvalues and can use the fastest possible
!>          techniques.
!>          On exit, a .TRUE. TRYRAC will be set to .FALSE. if the matrix
!>          does not define its eigenvalues to high relative accuracy.
!>

WORK

!>          WORK is DOUBLE PRECISION array, dimension (LWORK)
!>          On exit, if INFO = 0, WORK(1) returns the optimal
!>          (and minimal) LWORK.
!>

LWORK

!>          LWORK is INTEGER
!>          The dimension of the array WORK. LWORK >= max(1,18*N)
!>          if JOBZ = 'V', and LWORK >= max(1,12*N) if JOBZ = 'N'.
!>          If LWORK = -1, then a workspace query is assumed; the routine
!>          only calculates the optimal size of the WORK array, returns
!>          this value as the first entry of the WORK array, and no error
!>          message related to LWORK is issued by XERBLA.
!>

IWORK

!>          IWORK is INTEGER array, dimension (LIWORK)
!>          On exit, if INFO = 0, IWORK(1) returns the optimal LIWORK.
!>

LIWORK

!>          LIWORK is INTEGER
!>          The dimension of the array IWORK.  LIWORK >= max(1,10*N)
!>          if the eigenvectors are desired, and LIWORK >= max(1,8*N)
!>          if only the eigenvalues are to be computed.
!>          If LIWORK = -1, then a workspace query is assumed; the
!>          routine only calculates the optimal size of the IWORK array,
!>          returns this value as the first entry of the IWORK array, and
!>          no error message related to LIWORK is issued by XERBLA.
!>

INFO

!>          INFO is INTEGER
!>          On exit, INFO
!>          = 0:  successful exit
!>          < 0:  if INFO = -i, the i-th argument had an illegal value
!>          > 0:  if INFO = 1X, internal error in DLARRE,
!>                if INFO = 2X, internal error in ZLARRV.
!>                Here, the digit X = ABS( IINFO ) < 10, where IINFO is
!>                the nonzero error code returned by DLARRE or
!>                ZLARRV, respectively.
!>
