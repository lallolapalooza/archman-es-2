ZSTEIN

Documentación de función/subrutina

subrutina zstein (integer n, double precision, dimension( * ) d, double precision, dimension( * ) e, integer m, double precision, dimension( * ) w, integer, dimension( * ) iblock, integer, dimension( * ) isplit, complex*16, dimension( ldz, * ) z, integer ldz, double precision, dimension( * ) work, integer, dimension( * ) iwork, integer, dimension( * ) ifail, integer info)

ZSTEIN

Propósito:

!>
!> ZSTEIN calcula los vectores propios de una matriz tridiagonal simétrica real
!> T correspondientes a los valores propios especificados, utilizando la iteración inversa.
!>
!> El número máximo de iteraciones permitidas para cada vector propio se
!> especifica mediante un parámetro interno MAXITS (actualmente establecido en 5).
!>
!> Aunque los vectores propios son reales, se almacenan en una matriz compleja,
!> que puede pasarse a ZUNMTR o ZUPMTR para la retrotransformación a los vectores
!> propios de una matriz hermitiana compleja que fue reducida a forma tridiagonal.
!>
!>

Parámetros

N 
!>          N es INTEGER
!>          El orden de la matriz.  N >= 0.
!>

D

!>          D es DOUBLE PRECISION array, dimension (N)
!>          Los n elementos diagonales de la matriz tridiagonal T.
!>

E

!>          E es DOUBLE PRECISION array, dimension (N-1)
!>          Los (n-1) elementos subdiagonales de la matriz tridiagonal
!>          T, almacenados en los elementos 1 a N-1.
!>

M

!>          M es INTEGER
!>          El número de vectores propios a encontrar.  0 <= M <= N.
!>

W

!>          W es DOUBLE PRECISION array, dimension (N)
!>          Los primeros M elementos de W contienen los valores propios para
!>          los cuales se calcularán los vectores propios.  Los valores propios
!>          deberían agruparse por bloques divididos y ordenarse de menor a
!>          mayor dentro del bloque.  ( Se espera el array de salida
!>          W de DSTEBZ con ORDER = 'B' aquí. )
!>

IBLOCK

!>          IBLOCK es INTEGER array, dimension (N)
!>          Los índices de submatriz asociados con los valores propios
!>          correspondientes en W; IBLOCK(i)=1 si el valor propio W(i) pertenece a
!>          la primera submatriz desde arriba, =2 si W(i) pertenece a
!>          la segunda submatriz, etc.  ( Se espera el array de salida
!>          IBLOCK de DSTEBZ aquí. )
!>

ISPLIT

!>          ISPLIT es INTEGER array, dimension (N)
!>          Los puntos de división, en los que T se divide en submatrices.
!>          La primera submatriz consta de filas/columnas 1 a
!>          ISPLIT( 1 ), la segunda de filas/columnas ISPLIT( 1 )+1
!>          a ISPLIT( 2 ), etc.
!>          ( Se espera el array de salida ISPLIT de DSTEBZ aquí. )
!>

Z

!>          Z es COMPLEX*16 array, dimension (LDZ, M)
!>          Los vectores propios calculados.  El vector propio asociado
!>          con el valor propio W(i) se almacena en la i-ésima columna de
!>          Z.  Cualquier vector que no converja se establece en su
!>          iteración actual después de MAXITS iteraciones.
!>          Las partes imaginarias de los vectores propios se establecen en cero.
!>

LDZ

!>          LDZ es INTEGER
!>          La dimensión principal del array Z.  LDZ >= max(1,N).
!>

WORK

!>          WORK es DOUBLE PRECISION array, dimension (5*N)
!>

IWORK

!>          IWORK es INTEGER array, dimension (N)
!>

IFAIL

!>          IFAIL es INTEGER array, dimension (M)
!>          En una salida normal, todos los elementos de IFAIL son cero.
!>          Si uno o más vectores propios no convergen después de
!>          MAXITS iteraciones, sus índices se almacenan en
!>          el array IFAIL.
!>

INFO

!>          INFO es INTEGER
!>          = 0: salida exitosa
!>          < 0: si INFO = -i, el i-ésimo argumento tenía un valor ilegal
!>          > 0: si INFO = i, entonces i vectores propios no convergieron
!>               en MAXITS iteraciones.  Sus índices se almacenan en
!>               el array IFAIL.
!>

Parámetros internos:

!>  MAXITS  INTEGER, default = 5
!>          El número máximo de iteraciones realizadas.
!>
!>  EXTRA   INTEGER, default = 2
!>          El número de iteraciones realizadas después de que se satisface
!>          el criterio de crecimiento de la norma, debe ser al menos 1.
!>
