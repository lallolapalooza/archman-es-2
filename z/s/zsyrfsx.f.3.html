ZSYRFSX

Propósito:

!>
!>    ZSYRFSX mejora la solución calculada de un sistema de ecuaciones
!>    lineales cuando la matriz de coeficientes es simétrica indefinida,
!>    y proporciona cotas de error y estimaciones de error residual para la
!>    solución. Además de la cota de error normwise, el código proporciona
!>    la cota de error componente a componente máxima si es posible. Véanse
!>    los comentarios para ERR_BNDS_NORM y ERR_BNDS_COMP para detalles de
!>    las cotas de error.
!>
!>    El sistema original de ecuaciones lineales puede haber sido
!>    equilibrado antes de llamar a esta rutina, como se describe en los
!>    argumentos EQUED y S abajo. En este caso, la solución y las cotas
!>    de error devueltas son para el sistema original no equilibrado.
!> 
!>     Algunos parámetros opcionales están agrupados en el array PARAMS.
!>     Estas configuraciones determinan cómo se realiza el refinamiento,
!>     pero a menudo los valores por defecto son aceptables. Si los valores
!>     por defecto son aceptables, los usuarios pueden pasar NPARAMS = 0
!>     lo que evita que el código fuente acceda al argumento PARAMS.
!>

Parámetros

UPLO 
!>          UPLO es CHARACTER*1
!>       = 'U':  El triángulo superior de A está almacenado;
!>       = 'L':  El triángulo inferior de A está almacenado.
!>

EQUED

!>          EQUED es CHARACTER*1
!>     Especifica la forma de equilibrado que se realizó en A
!>     antes de llamar a esta rutina. Esto es necesario para calcular
!>     correctamente la solución y las cotas de error.
!>       = 'N':  Sin equilibrado
!>       = 'Y':  Equilibrado tanto de filas como de columnas, es decir, A ha sido
!>               reemplazado por diag(S) * A * diag(S).
!>               El lado derecho B se ha modificado en consecuencia.
!>

N

!>          N es INTEGER
!>     El orden de la matriz A.  N >= 0.
!>

NRHS

!>          NRHS es INTEGER
!>     El número de lados derechos, es decir, el número de columnas
!>     de las matrices B y X.  NRHS >= 0.
!>

A

!>          A es array COMPLEX*16, dimensión (LDA,N)
!>     La matriz simétrica A.  Si UPLO = 'U', la parte superior
!>     triangular de N por N de A contiene la parte triangular
!>     superior de la matriz A, y la parte estrictamente triangular
!>     inferior de A no se referencia. Si UPLO = 'L', la parte inferior
!>     triangular de N por N de A contiene la parte triangular
!>     inferior de la matriz A, y la parte estrictamente triangular
!>     superior de A no se referencia.
!>

LDA

!>          LDA es INTEGER
!>     La dimensión principal del array A.  LDA >= max(1,N).
!>

AF

!>          AF es array COMPLEX*16, dimensión (LDAF,N)
!>     La forma factorizada de la matriz A.  AF contiene la matriz
!>     diagonal por bloques D y los multiplicadores utilizados para
!>     obtener U o L de la factorización A = U*D*U**T o A =
!>     L*D*L**T según fue calculada por ZSYTRF.
!>

LDAF

!>          LDAF es INTEGER
!>     La dimensión principal del array AF.  LDAF >= max(1,N).
!>

IPIV

!>          IPIV es array INTEGER, dimensión (N)
!>     Detalles de los intercambios y la estructura de bloques de D
!>     según fue determinada por ZSYTRF.
!>

S

!>          S es array DOUBLE PRECISION, dimensión (N)
!>     Los factores de escala para A.  Si EQUED = 'Y', A se multiplica
!>     a la izquierda y a la derecha por diag(S).  S es un argumento de
!>     entrada si FACT = 'F'; de lo contrario, S es un argumento de salida.
!>     Si FACT = 'F' y EQUED = 'Y', cada elemento de S debe ser positivo.
!>     Si S es de salida, cada elemento de S es una potencia de la base.
!>     Si S es de entrada, cada elemento de S debería ser una potencia de la
!>     base para asegurar una solución y estimaciones de error fiables.
!>     El escalado por potencias de la base no causa errores de redondeo
!>     a menos que el resultado se desborde hacia abajo o hacia arriba.
!>     Los errores de redondeo durante el escalado conducen a refinar con una
!>     matriz que no es equivalente a la matriz de entrada, produciendo
!>     estimaciones de error que pueden no ser fiables.
!>

B

!>          B es array COMPLEX*16, dimensión (LDB,NRHS)
!>     La matriz del lado derecho B.
!>

LDB

!>          LDB es INTEGER
!>     La dimensión principal del array B.  LDB >= max(1,N).
!>

X

!>          X es array COMPLEX*16, dimensión (LDX,NRHS)
!>     En la entrada, la matriz solución X, tal como fue calculada por ZGETRS.
!>     En la salida, la matriz solución mejorada X.
!>

LDX

!>          LDX es INTEGER
!>     La dimensión principal del array X.  LDX >= max(1,N).
!>

RCOND

!>          RCOND es DOUBLE PRECISION
!>     Condición de escala recíproca. Esta es una estimación del
!>     número de condición de Skeel recíproco de la matriz A después
!>     del equilibrado (si se realizó). Si este valor es menor que la
!>     precisión de la máquina (en particular, si es cero), la matriz es
!>     singular para la precisión de trabajo. Tenga en cuenta que el error
!>     puede ser pequeño incluso si este número es muy pequeño y la matriz
!>     parece mal condicionada.
!>

BERR

!>          BERR es array DOUBLE PRECISION, dimensión (NRHS)
!>     Error residual relativo componente a componente. Este es el
!>     error residual relativo componente a componente de cada vector
!>     solución X(j) (es decir, el cambio relativo más pequeño en
!>     cualquier elemento de A o B que haga de X(j) una solución exacta).
!>

N_ERR_BNDS

!>          N_ERR_BNDS es INTEGER
!>     Número de cotas de error a devolver para cada lado derecho
!>     y cada tipo (normwise o componente a componente). Véanse
!>     ERR_BNDS_NORM y ERR_BNDS_COMP abajo.
!>

ERR_BNDS_NORM

!>     varias cotas de error y números de condición correspondientes al

!>            ------------------------------
!>                  max_j abs(X(j,i))
