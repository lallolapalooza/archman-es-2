NOMBRE

zshdb - depurador de zsh

SINOPSIS

zshdb [opciones] [--] nombre-script [opciones-script]

zshdb [opciones] -c cadena-ejecucion

DESCRIPCIÓN

"zshdb" es un script de zsh que organiza la depuración de otro script de zsh. El depurador tiene una interfaz de comandos similar a la de gdb(1).

Si usaste el script zshdb y necesitas pasar opciones al script que se va a depurar, añade "--" antes del nombre del script. Esto le indicará a zshdb que no intente procesar ninguna opción adicional.

OPCIONES

-h | --help
Imprime un mensaje de uso en la salida de error estándar y sale con un código de retorno de 100.
-A | --annotation nivel
Establece la salida de información adicional de la pila y del estado que permite a los front-ends como emacs rastrear lo que está sucediendo sin consultar.

Esto es necesario para las pruebas de regresión. Usar esta opción es equivalente a emitir:

set annotation NIVEL

dentro del depurador.

-B | --basename
En los lugares donde aparece un nombre de archivo en la salida del depurador, muestra solo el nombre base. Esto es necesario para las pruebas de regresión. Usar esta opción es equivalente a emitir: 
set basename on

dentro del depurador.

-n | --nx | --no-init
Normalmente, el depurador leerá los comandos del depurador en "~/.zshdbinit" si ese archivo existe, antes de aceptar la interacción del usuario. ".zshdbinit" es análogo a ".perldb" de Perl o a ".gdbinit" de GNU gdb: un usuario puede querer crear dicho perfil de depurador para agregar varias personalizaciones específicas del usuario.

Usando la opción "-n", este archivo de inicialización no se leerá. Esto es útil en pruebas de regresión o para rastrear un problema con el perfil de ".zshdbinit".

-c | --command cadena-comando
En lugar de especificar el nombre de un archivo de script, se puede dar una cadena de ejecución que se va a depurar. Usa esta opción para hacerlo.
-q | --quiet
No imprime información introductoria de versión y derechos de autor. Esto es útil nuevamente en pruebas de regresión donde no queremos incluir una fecha de derechos de autor cambiante en la coincidencia de pruebas de regresión.
-x | --eval-command archivo-comandos-depurador
Ejecuta los comandos del depurador de archivo-comandos-depurador antes de aceptar la entrada del usuario. Estos comandos se leen, sin embargo, después de cualquier comando de ".zshdbinit". De nuevo, esto es útil para ejecutar scripts de depuración de pruebas de regresión.
-L | --library biblioteca-depurador
El depurador necesita incluir (o "sourcear") una serie de funciones que residen en una biblioteca. Si no se proporciona esta opción, la ubicación predeterminada de la biblioteca es relativa al script zshdb instalado: "../lib/zshdb".
-T | --tempdir directorio-archivos-temporales
El depurador necesita hacer uso de algún almacenamiento temporal en el sistema de archivos para guardar información persistente a través de un retorno de subshell o para evaluar una expresión. El directorio predeterminado es "/tmp", pero puedes usar esta opción para establecer el directorio donde se crearán los archivos temporales del depurador.
-t | --tty nombre-tty
La salida del depurador generalmente va a una terminal en lugar de a stdout o stdin, que el programa depurado puede usar. La determinación de la tty o pseudo-tty normalmente se hace automáticamente. Sin embargo, si desea controlar a dónde va la salida del depurador, use esta opción.
-V | --version
Muestra el número de versión y la ausencia de garantía, y sale con el código de retorno 1.

ERRORES

La forma en que este script organiza la depuración consiste en incluir (o en realidad "sourcear") cierto código de soporte de depuración y luego "sourcear" el script dado o la cadena de comandos.

Un problema al "sourcear" un script depurado es que el nombre del programa almacenado en $0 no será el nombre del script que se está depurando. El script depurado aparecerá en una pila de llamadas no como el elemento superior, sino como el elemento debajo de "zshdb".

La opción de script "zshdb" asume una versión de zsh con soporte de depuración, zsh 4.3.6-dev-2 o posterior.

El depurador ralentiza un poco porque tiene que interceptar cada sentencia y verificar si se va a realizar alguna acción.
