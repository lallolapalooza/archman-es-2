subrutina zsytrf_rk (carácter uplo, entero n, complex*16, dimensión( lda, * ) a, entero lda, complex*16, dimensión( * ) e, entero, dimensión( * ) ipiv, complex*16, dimensión( * ) work, entero lwork, entero info)

ZSYTRF_RK calcula la factorización de una matriz simétrica indefinida compleja utilizando el método de pivoteo diagonal limitado de Bunch-Kaufman (rook) (algoritmo bloqueado BLAS3).

Propósito:

!> ZSYTRF_RK calcula la factorización de una matriz simétrica compleja A
!> utilizando el método de pivoteo diagonal limitado de Bunch-Kaufman (rook):
!>
!>    A = P*U*D*(U**T)*(P**T) o A = P*L*D*(L**T)*(P**T),
!>
!> donde U (o L) es una matriz triangular unitaria superior (o inferior),
!> U**T (o L**T) es la transpuesta de U (o L), P es una matriz de permutación,
!> P**T es la transpuesta de P, y D es simétrica y diagonal por bloques
!> con bloques diagonales de 1x1 y 2x2.
!>
!> Esta es la versión bloqueada del algoritmo, que llama a BLAS de Nivel 3.
!> Para más información, véase la sección Detalles Adicionales.
!>

Parámetros

UPLO 
!>          UPLO es CHARACTER*1
!>          Especifica si la parte triangular superior o inferior de la
!>          matriz simétrica A está almacenada:
!>          = 'U':  Triangular superior
!>          = 'L':  Triangular inferior
!>

N

!>          N es INTEGER
!>          El orden de la matriz A.  N >= 0.
!>

A

!>          A es un array COMPLEX*16, dimensión (LDA,N)
!>          En la entrada, la matriz simétrica A.
!>            Si UPLO = 'U': la parte triangular superior N x N
!>            de A contiene la parte triangular superior de la matriz A,
!>            y la parte triangular estrictamente inferior de A no
!>            se referencia.
!>
!>            Si UPLO = 'L': la parte triangular inferior N x N
!>            de A contiene la parte triangular inferior de la matriz A,
!>            y la parte triangular estrictamente superior de A no
!>            se referencia.
!>
!>          En la salida, contiene:
!>            a) SÓLO los elementos diagonales de la matriz diagonal por
!>               bloques simétrica D en la diagonal de A, es decir, D(k,k) = A(k,k);
!>               (los elementos superdiagonales (o subdiagonales) de D
!>                se almacenan en la salida en el array E), y
!>            b) Si UPLO = 'U': factor U en la parte superdiagonal de A.
!>               Si UPLO = 'L': factor L en la parte subdiagonal de A.
!>

LDA

!>          LDA es INTEGER
!>          La dimensión principal del array A.  LDA >= max(1,N).
!>

E

!>          E es un array COMPLEX*16, dimensión (N)
!>          En la salida, contiene los elementos superdiagonales (o subdiagonales)
!>          de la matriz diagonal por bloques simétrica D
!>          con bloques diagonales de 1x1 o 2x2, donde
!>          Si UPLO = 'U': E(i) = D(i-1,i), i=2:N, E(1) se establece a 0;
!>          Si UPLO = 'L': E(i) = D(i+1,i), i=1:N-1, E(N) se establece a 0.
!>
!>          NOTA: Para un bloque diagonal de 1x1 D(k), donde
!>          1 <= k <= N, el elemento E(k) se establece a 0 en ambos
!>          casos UPLO = 'U' o UPLO = 'L'.
!>

IPIV

!>          IPIV es un array INTEGER, dimensión (N)
!>          IPIV describe la matriz de permutación P en la factorización
!>          de la matriz A de la siguiente manera. El valor absoluto de IPIV(k)
!>          representa el índice de la fila y columna que fueron
!>          intercambiadas con la k-ésima fila y columna. El valor de UPLO
!>          describe el orden en que se aplicaron los intercambios.
!>          Además, el signo de IPIV representa la estructura de bloque
!>          de la matriz diagonal por bloques simétrica D con bloques
!>          de 1x1 o 2x2 que corresponden a 1 o 2 intercambios
!>          en cada paso de factorización. Para más información, véase la
!>          sección Detalles Adicionales.
!>
!>          Si UPLO = 'U',
!>          (en orden de factorización, k disminuye de N a 1):
!>            a) Una sola entrada positiva IPIV(k) > 0 significa:
!>               D(k,k) es un bloque diagonal de 1x1.
!>               Si IPIV(k) != k, las filas y columnas k e IPIV(k) fueron
!>               intercambiadas en la matriz A(1:N,1:N);
!>               Si IPIV(k) = k, no ocurrió ningún intercambio.
!>
!>            b) Un par de entradas negativas consecutivas
!>               IPIV(k) < 0 e IPIV(k-1) < 0 significa:
!>               D(k-1:k,k-1:k) es un bloque diagonal de 2x2.
!>               (NOTA: las entradas negativas en IPIV aparecen SÓLO en pares).
!>               1) Si -IPIV(k) != k, las filas y columnas
!>                  k y -IPIV(k) fueron intercambiadas
!>                  en la matriz A(1:N,1:N).
!>                  Si -IPIV(k) = k, no ocurrió ningún intercambio.
!>               2) Si -IPIV(k-1) != k-1, las filas y columnas
!>                  k-1 y -IPIV(k-1) fueron intercambiadas
!>                  en la matriz A(1:N,1:N).
!>                  Si -IPIV(k-1) = k-1, no ocurrió ningún intercambio.
!>
!>            c) En ambos casos a) y b), siempre ABS( IPIV(k) ) <= k.
!>
!>            d) NOTA: Cualquier entrada IPIV(k) es siempre NO NULA en la salida.
!>
!>          Si UPLO = 'L',
!>          (en orden de factorización, k aumenta de 1 a N):
!>            a) Una sola entrada positiva IPIV(k) > 0 significa:
!>               D(k,k) es un bloque diagonal de 1x1.
!>               Si IPIV(k) != k, las filas y columnas k e IPIV(k) fueron
!>               intercambiadas en la matriz A(1:N,1:N).
!>               Si IPIV(k) = k, no ocurrió ningún intercambio.
!>
!>            b) Un par de entradas negativas consecutivas
!>               IPIV(k) < 0 e IPIV(k+1) < 0 significa:
!>               D(k:k+1,k:k+1) es un bloque diagonal de 2x2.
!>               (NOTA: las entradas negativas en IPIV aparecen SÓLO en pares).
!>               1) Si -IPIV(k) != k, las filas y columnas
!>                  k y -IPIV(k) fueron intercambiadas
!>                  en la matriz A(1:N,1:N).
!>                  Si -IPIV(k) = k, no ocurrió ningún intercambio.
!>               2) Si -IPIV(k+1) != k+1, las filas y columnas
!>                  k-1 y -IPIV(k-1) fueron intercambiadas
!>                  en la matriz A(1:N,1:N).
!>                  Si -IPIV(k+1) = k+1, no ocurrió ningún intercambio.
!>
!>            c) En ambos casos a) y b), siempre ABS( IPIV(k) ) >= k.
!>
!>            d) NOTA: Cualquier entrada IPIV(k) es siempre NO NULA en la salida.
!>

WORK

!>          WORK es un array COMPLEX*16, dimensión ( MAX(1,LWORK) ).
!>          En la salida, si INFO = 0, WORK(1) devuelve el LWORK óptimo.
!>

LWORK

!>          LWORK es INTEGER
!>          La longitud de WORK.  LWORK >=1.  Para un rendimiento óptimo
!>          LWORK >= N*NB, donde NB es el tamaño del bloque devuelto
!>          por ILAENV.
!>
!>          Si LWORK = -1, entonces se asume una consulta de espacio de trabajo;
!>          la rutina solo calcula el tamaño óptimo del array WORK,
!>          devuelve este valor como la primera entrada del array WORK,
!>          y XERBLA no emite ningún mensaje de error relacionado con LWORK.
!>

INFO

!>          INFO es INTEGER
!>          = 0: éxito en la salida
!>
!>          < 0: Si INFO = -k, el k-ésimo argumento tenía un valor ilegal
!>
!>          > 0: Si INFO = k, la matriz A es singular, porque:
!>                 Si UPLO = 'U': la columna k en la parte
!>                 triangular superior de A contiene todos ceros.
!>                 Si UPLO = 'L': la columna k en la parte
!>                 triangular inferior de A contiene todos ceros.
!>
!>               Por lo tanto, D(k,k) es exactamente cero, y los elementos
!>               superdiagonales de la columna k de U (o subdiagonales de
!>               la columna k de L) son todos ceros. La factorización se ha
!>               completado, pero la matriz diagonal por bloques D
!>               es exactamente singular, y

NAME

zsytrf_rk - Factorize a complex symmetric matrix A in the form P*U*D*U**H*Q or P*L*D*L**H*Q using the rook pairing Bunch-Kaufman algorithm, and compute the inverse of the factorization.

SYNOPSIS

CALL ZSYTRF_RK(
   UPLO, N, A, LDA, IPVOT, WORK, LWORK, INFO
)

Parameters:

CHARACTER*1
UPLO
INTEGER
N
COMPLEX*16, DIMENSION( LDA, * )
A
INTEGER, DIMENSION( * )
IPVOT
COMPLEX*16, DIMENSION( * )
WORK
INTEGER
LWORK
INTEGER
INFO

Function/Subroutine Documentation

!>
!>  The routine ZSYTRF_RK is the block version of ZSYTRF. It is intended to
!>  be used for dense complex symmetric matrices.
!>
!>  ZSYTRF_RK factorizes a complex symmetric matrix A in the form
!>
!>     If UPLO = 'U':
!>        A = P*U*D*U**H*Q
!>     else:
!>        A = P*L*D*L**H*Q
!>
!>  where U is upper triangular with unit diagonal entries, L is lower
!>  triangular with unit diagonal entries, D is a block diagonal matrix
!>  with 1-by-1 and 2-by-2 block diagonal entries, P and Q are permutation
!>  matrices. Q is the transpose of the matrix representing the pivoting
!>  for the block LU factorization.
!>
!>  This uses the rook pairing Bunch-Kaufman algorithm for the factorization
!>  of a general complex symmetric matrix.
!>
!>  Arguments:
!>
!>  * UPLO   - CHARACTER*1. Specifies whether the upper or lower triangular
!>             part of the matrix A is stored:
!>             = 'U': Upper triangle of A is stored.
!>             = 'L': Lower triangle of A is stored.
!>
!>  * N      - INTEGER. The order of the matrix A. N >= 0.
!>
!>  * A      - COMPLEX*16 array, dimension (LDA, N). On entry, the symmetric
!>             matrix A. On exit, overwritten by the block factorization
!>             details.
!>
!>  * LDA    - INTEGER. The leading dimension of the array A. LDA >= max(1, N).
!>
!>  * IPVOT  - INTEGER array, dimension (N). Contains the pivoting information.
!>             For k = 1 to N, PVOT(k) specifies the row and column where
!>             pivot is placed, and the sign of the pivot element for the
!>             LU factorization.
!>             If PVOT(k) > 0, then row k of the factorization is a 1-by-1
!>             pivot A(k,k), and PVOT(k) is the row index of the pivot element.
!>             If PVOT(k) < 0, then row k of the factorization is a 2-by-2
!>             pivot composed of rows k and k-1, and PVOT(k) is the row index
!>             of the pivot element.
!>
!>  * WORK   - COMPLEX*16 array, dimension (LWORK). Workspace array.
!>             On exit, WORK(1) contains the minimum required dimension LWORK.
!>
!>  * LWORK  - INTEGER. The dimension of the array WORK. LWORK >= 1.
!>             If LWORK = -1, then ZSYTRF_RK just computes the workspace
!>             required.
!>
!>  * INFO   - INTEGER.
!>             = 0:  Successful exit.
!>             > 0:  If INFO = k, then k is the block index of the first
!>                   block which could not be factored. The factorization
!>                   has been completed, but D is not positive definite.
!>                   A division by zero will occur if it is used to solve
!>                   a system of equations.
!>
!>             NOTE: INFO only stores the first occurrence of
!>             a singularity, any subsequent occurrence of singularity
!>             is not stored in INFO even though the factorization
!>             always completes.
!>
