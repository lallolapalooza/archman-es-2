Documentación de Función/Subrutina

subroutine zsyt01_aa (character uplo, integer n, complex*16, dimension( lda, * ) a, integer lda, complex*16, dimension( ldafac, * ) afac, integer ldafac, integer, dimension( * ) ipiv, complex*16, dimension( ldc, * ) c, integer ldc, double precision, dimension( * ) rwork, double precision resid)

ZSYT01

Propósito:

!>
!> ZSYT01 reconstruye una matriz hermítica indefinida A a partir de su
!> factorización L*D*L' o U*D*U' y calcula la norma del residuo
!>    norm( C - A ) / ( N * norm(A) * EPS ),
!> donde C es la matriz reconstruida y EPS es el epsilon de la máquina.
!>

Parámetros

UPLO 
!>          UPLO es CHARACTER*1
!>          Especifica si la parte triangular superior o inferior de la
!>          matriz hermítica A está almacenada:
!>          = 'U': Triangular superior
!>          = 'L': Triangular inferior
!>

N

!>          N es INTEGER
!>          El número de filas y columnas de la matriz A. N >= 0.
!>

A

!>          A es un array COMPLEX*16, dimensión (LDA,N)
!>          La matriz hermítica original A.
!>

LDA

!>          LDA es INTEGER
!>          La dimensión principal del array A. LDA >= max(1,N)
!>

AFAC

!>          AFAC es un array COMPLEX*16, dimensión (LDAFAC,N)
!>          La forma factorizada de la matriz A. AFAC contiene la matriz
!>          diagonal por bloques D y los multiplicadores utilizados para
!>          obtener L o U de la factorización L*D*L' o U*D*U'
!>          calculada por ZSYTRF.
!>

LDAFAC

!>          LDAFAC es INTEGER
!>          La dimensión principal del array AFAC. LDAFAC >= max(1,N).
!>

IPIV

!>          IPIV es un array INTEGER, dimensión (N)
!>          Los índices de pivote de ZSYTRF.
!>

C

!>          C es un array COMPLEX*16, dimensión (LDC,N)
!>

LDC

!>          LDC es INTEGER
!>          La dimensión principal del array C. LDC >= max(1,N).
!>

RWORK

!>          RWORK es un array COMPLEX*16, dimensión (N)
!>

RESID

!>          RESID es COMPLEX*16
!>          Si UPLO = 'L', norm(L*D*L' - A) / ( N * norm(A) * EPS )
!>          Si UPLO = 'U', norm(U*D*U' - A) / ( N * norm(A) * EPS )
!>
