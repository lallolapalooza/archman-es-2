zsync(1) Transferencia de archivos zsync(1)

NOMBRE

zsync - Cliente de descarga de archivos parcial/diferencial sobre HTTP

SINTAXIS

zsync [ -u url ] [ -i archivo_entrada ] [ -o archivo_salida ] [ { -s | -q } ] [ -k archivo.zsync ] [ -A nombre_host=nombre_usuario:contraseña ] { nombre_archivo | url }

zsync -V

DESCRIPCIÓN

Descarga un archivo a través de HTTP. zsync utiliza un archivo de control para determinar si hay bloques en el archivo que el descargador ya conoce, y solo descarga los bloques nuevos.

Se puede proporcionar un nombre de archivo o una URL en la línea de comandos: este es el camino del archivo de control para la descarga, que normalmente tiene el nombre del archivo real a descargar con .zsync añadido. (Para crear este archivo .zsync, debes tener una copia del archivo de destino, por lo que este archivo debe ser generado por la persona que proporciona la descarga).

zsync descarga en tu directorio actual. Busca cualquier archivo en el directorio con el mismo nombre que el archivo a descargar. Si encuentra uno, asume que esta es una versión anterior o incompleta del nuevo archivo a descargar y escanea este archivo en busca de cualquier bloque que pueda usar para construir el archivo de destino. (También busca un archivo con el mismo nombre y la extensión .part, por lo que encontrará automáticamente descargas de zsync interrumpidas previamente y reutilizará los datos ya descargados. Si sabes que el archivo local a usar como entrada tiene un nombre diferente, debes usar -i)

zsync recupera el resto del archivo de destino a través de HTTP. Una vez que la descarga finaliza, la versión antigua (si el nuevo archivo tiene el mismo nombre) se mueve a un lado (se le añade la extensión .zs-old). La hora de modificación del archivo se establece para que sea la misma que la del archivo de origen remoto (si se especifica en el .zsync).

OPCIONES

-A nombre_host=nombre_usuario:contraseña
Especifica un nombre de usuario y una contraseña que se utilizarán con el nombre de host dado. -A se puede usar varias veces (con diferentes nombres de host), en casos donde, por ejemplo, el
archivo .zsync está en un servidor diferente al de la descarga, o hay varios servidores de descarga (podría haber detalles de autenticación diferentes para diferentes servidores, ¡y zsync nunca asume que tu contraseña debe enviarse a un servidor que no sea el nombrado, de lo contrario los redireccionamientos serían peligrosos!).
-i archivo_entrada
Especifica archivos de entrada (adicionales). Se escanea archivo_entrada para identificar bloques en común con el archivo de destino y zsync utiliza cualquier bloque encontrado. Se puede usar varias veces.
-k archivo.zsync
Indica que zsync debe guardar el archivo zsync que descarga, con el nombre de archivo dado. Si ese archivo ya existe, zsync realizará una solicitud condicional al servidor web, de manera que solo lo descargará nuevamente si la copia del servidor es más reciente. zsync añadirá .part al nombre del archivo para almacenarlo mientras se descarga, y solo sobrescribirá el archivo principal una vez que la descarga esté completa, y si la descarga se interrumpe, se reanudará utilizando los datos del archivo .part.
-o archivo_salida
Anular el nombre del archivo de salida predeterminado.
-q
Suprimir la barra de progreso, la velocidad de descarga y la visualización de la ETA.
-s
Sinónimo obsoleto de -q.
-u url
Esto especifica la URL de referencia. Si tienes un archivo .zsync localmente (si lo descargaste por separado, con wget, por ejemplo) y el archivo .zsync contiene una URL relativa, necesitas especificar de dónde obtuviste el archivo .zsync para que zsync sepa qué servidor y ruta usar para el resto de la descarga (esto es análogo a agregar un <base href="..."> a una página web descargada para que los enlaces funcionen).
-V
Imprime la versión de zsync.

ARCHIVOS

VARIABLES DE ENTORNO

http_proxy
Debería ser el [http://]nombre_host:puerto para tu proxy web, si se requiere para acceder a los servidores web de destino.

EJEMPLOS

zsync -i /var/lib/apt/lists/server.debian.org_debian_dists_etch_main_binary-i386_Packages http://zsync.moria.org.uk/s/etch/Packages.zsync
