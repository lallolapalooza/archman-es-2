Documentación de función/subrutina

subrutina zsyl01 (doble precisión thresh, entero, dimensión( 3 ) nfail, doble precisión, dimensión( 2 ) rmax, entero, dimensión( 2 ) ninfo, entero knt)

ZSYL01

Propósito:

!>
!> ZSYL01 prueba ZTRSYL y ZTRSYL3, rutinas para resolver la ecuación matricial de Sylvester
!>
!>    op(A)*X + ISGN*X*op(B) = scale*C,
!>
!> donde op(A) y op(B) son ambos de forma triangular superior, op() representa una
!> transpuesta conjugada opcional, y ISGN puede ser -1 o +1. Scale es una salida
!> menor o igual a 1, elegida para evitar el desbordamiento en X.
!>
!> El código de prueba verifica que el siguiente residuo no exceda
!> el umbral proporcionado:
!>
!>    norm(op(A)*X + ISGN*X*op(B) - scale*C) /
!>        (EPS*max(norm(A),norm(B))*norm(X))
!>
!> Esta rutina complementa a ZGET35 al probar con matrices más grandes y
!> aleatorias, de las cuales algunas requieren reescalado de X para evitar el desbordamiento.
!>
!>

Parámetros

THRESH 
!>          THRESH es DOBLE PRECISION
!>          Una prueba se contará como si el residuo, calculado como
!>          se describe arriba, excede THRESH.
!>

NFAIL

!>          NFAIL es un array ENTERO, dimensión (3)
!>          NFAIL(1) = No. de veces que el residuo ZTRSYL excede el umbral THRESH
!>          NFAIL(2) = No. de veces que el residuo ZTRSYL3 excede el umbral THRESH
!>          NFAIL(3) = No. de veces que ZTRSYL3 y ZTRSYL difieren
!>

RMAX

!>          RMAX es un array DOBLE PRECISION, dimensión (2)
!>          RMAX(1) = Valor de la relación de prueba más grande de ZTRSYL
!>          RMAX(2) = Valor de la relación de prueba más grande de ZTRSYL3
!>

NINFO

!>          NINFO es un array ENTERO, dimensión (2)
!>          NINFO(1) = No. de veces que ZTRSYL devuelve un INFO esperado
!>          NINFO(2) = No. de veces que ZTRSYL3 devuelve un INFO esperado
!>

KNT

!>          KNT es ENTERO
!>          Número total de ejemplos probados.
!>
