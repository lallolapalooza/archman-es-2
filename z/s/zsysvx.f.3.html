ZSYSVX calcula la solución al sistema de ecuaciones lineales A * X = B para matrices SY

Propósito:

!>
!> ZSYSVX utiliza la factorización por pivoteo diagonal para calcular
!> la solución de un sistema lineal complejo A * X = B, donde A es una
!> matriz simétrica N por N y X y B son matrices N por NRHS.
!>
!> También se proporcionan límites de error en la solución y una estimación
!> de la condición.
!>

Descripción:

!>
!> Se realizan los siguientes pasos:
!>
!> 1. Si FACT = 'N', se utiliza el método de pivoteo diagonal para factorizar A.
!>    La forma de la factorización es
!>       A = U * D * U**T,  si UPLO = 'U', o
!>       A = L * D * L**T,  si UPLO = 'L',
!>    donde U (o L) es un producto de permutaciones y matrices triangulares
!>    un superirores (inferiores), y D es simétrica y diagonal por bloques con
!>    bloques diagonales de 1x1 y 2x2.
!>
!> 2. Si algún D(i,i)=0, de modo que D es exactamente singular, la rutina
!>    retorna con INFO = i. De lo contrario, la forma factorizada de A se utiliza
!>    para estimar el número de condición de la matriz A. Si el
!>    recíproco del número de condición es menor que la precisión de la máquina,
!>    se retorna INFO = N+1 como advertencia, pero la rutina continúa
!>    resolviendo X y calculando límites de error como se describe a continuación.
!>
!> 3. El sistema de ecuaciones se resuelve para X utilizando la forma factorizada
!>    de A.
!>
!> 4. Se aplica refinamiento iterativo para mejorar la solución calculada
!>    matriz y calcular límites de error y estimaciones de error hacia atrás
!>    para ella.
!>

Parámetros

FACT 
!>          FACT es CHARACTER*1
!>          Especifica si la forma factorizada de A ha sido
!>          suministrada en la entrada.
!>          = 'F':  En la entrada, AF e IPIV contienen la forma factorizada
!>                  de A.  A, AF e IPIV no se modificarán.
!>          = 'N':  La matriz A se copiará a AF y se factorizará.
!>

UPLO

!>          UPLO es CHARACTER*1
!>          = 'U':  Se almacena el triángulo superior de A;
!>          = 'L':  Se almacena el triángulo inferior de A.
!>

N

!>          N es INTEGER
!>          El número de ecuaciones lineales, es decir, el orden de la
!>          matriz A.  N >= 0.
!>

NRHS

!>          NRHS es INTEGER
!>          El número de lados derechos, es decir, el número de columnas
!>          de las matrices B y X.  NRHS >= 0.
!>

A

!>          A es un array COMPLEX*16, dimension (LDA,N)
!>          La matriz simétrica A.  Si UPLO = 'U', la parte triangular
!>          superior N por N principal de A contiene la parte triangular
!>          superior de la matriz A, y la parte triangular estrictamente
!>          inferior de A no se referencia.  Si UPLO = 'L', la parte
!>          triangular inferior N por N principal de A contiene la parte
!>          triangular inferior de la matriz A, y la parte triangular
!>          estrictamente superior de A no se referencia.
!>

LDA

!>          LDA es INTEGER
!>          La dimensión principal del array A.  LDA >= max(1,N).
!>

AF

!>          AF es un array COMPLEX*16, dimension (LDAF,N)
!>          Si FACT = 'F', entonces AF es un argumento de entrada y en la
!>          entrada contiene la matriz diagonal por bloques D y los multiplicadores
!>          utilizados para obtener el factor U o L de la factorización
!>          A = U*D*U**T o A = L*D*L**T calculada por ZSYTRF.
!>
!>          Si FACT = 'N', entonces AF es un argumento de salida y en la
!>          salida devuelve la matriz diagonal por bloques D y los multiplicadores
!>          utilizados para obtener el factor U o L de la factorización
!>          A = U*D*U**T o A = L*D*L**T.
!>

LDAF

!>          LDAF es INTEGER
!>          La dimensión principal del array AF.  LDAF >= max(1,N).
!>

IPIV

!>          IPIV es un array INTEGER, dimension (N)
!>          Si FACT = 'F', entonces IPIV es un argumento de entrada y en la
!>          entrada contiene detalles de los intercambios y la estructura de
!>          bloques de D, según lo determinado por ZSYTRF.
!>          Si IPIV(k) > 0, entonces las filas y columnas k e IPIV(k) fueron
!>          intercambiadas y D(k,k) es un bloque diagonal de 1x1.
!>          Si UPLO = 'U' y IPIV(k) = IPIV(k-1) < 0, entonces las filas y
!>          columnas k-1 y -IPIV(k) fueron intercambiadas y D(k-1:k,k-1:k)
!>          es un bloque diagonal de 2x2.  Si UPLO = 'L' y IPIV(k) =
!>          IPIV(k+1) < 0, entonces las filas y columnas k+1 y -IPIV(k) fueron
!>          intercambiadas y D(k:k+1,k:k+1) es un bloque diagonal de 2x2.
!>
!>          Si FACT = 'N', entonces IPIV es un argumento de salida y en la
!>          salida contiene detalles de los intercambios y la estructura de
!>          bloques de D, según lo determinado por ZSYTRF.
!>

B

!>          B es un array COMPLEX*16, dimension (LDB,NRHS)
!>          La matriz del lado derecho B de N por NRHS.
!>

LDB

!>          LDB es INTEGER
!>          La dimensión principal del array B.  LDB >= max(1,N).
!>

X

!>          X es un array COMPLEX*16, dimension (LDX,NRHS)
!>          Si INFO = 0 o INFO = N+1, la matriz solución X de N por NRHS.
!>

LDX

!>          LDX es INTEGER
!>          La dimensión principal del array X.  LDX >= max(1,N).
!>

RCOND

!>          RCOND es DOUBLE PRECISION
!>          La estimación del recíproco del número de condición de la matriz
!>          A.  Si RCOND es menor que la precisión de la máquina (en
!>          particular, si RCOND = 0), la matriz es singular con precisión
!>          de trabajo.  Esta condición se indica con un código de retorno
!>          INFO > 0.
!>

FERR

!>          FERR es un array DOUBLE PRECISION, dimension (NRHS)
!>          El límite de error hacia adelante estimado para cada vector solución
!>          X(j) (la j-ésima columna de la matriz solución X).
!>          Si XTRUE es la solución verdadera correspondiente a X(j), FERR(j)
!>          es un límite superior estimado para la magnitud del elemento más
!>          grande en (X(j) - XTRUE) dividido por la magnitud del elemento más
!>          grande en X(j).  La estimación es tan confiable como
!>          la estimación de RCOND, y casi siempre es una ligera
!>          sobreestimación del error verdadero.
!>

BERR

!>          BERR es un array DOUBLE PRECISION, dimension (NRHS)
!>          El error hacia atrás relativo por componentes de cada vector solución
!>          X(j) (es decir, el cambio relativo más pequeño en
!>          cualquier elemento de A o B que hace que X(j) sea una solución exacta).
!>

WORK

NAME

zsysvx - solve a complex symmetric system of linear equations with automatically determined optimal block size

SYNOPSIS

   SUBROUTINE ZSYSVX( FACT, UPLO, N, A, LDA, AF, LDAF, IPIV, B, LDB, X,
                        LDX, RCOND, FERR, BERR, WORK, LWORK, INFO )
      CHARACTER UPLO
      INTEGER AF
      INTEGER A
      INTEGER LDA
      INTEGER LDAF
      INTEGER LDB
      INTEGER LWORK
      INTEGER LDX
      INTEGER N
      INTEGER IPIV
      INTEGER INFO
      DOUBLE PRECISION RCOND
      DOUBLE PRECISION WORK
      DOUBLE PRECISION FERR
      DOUBLE PRECISION BERR
      COMPLEX*16 X
      COMPLEX*16 B

Function/Subroutine Documentation

This subroutine is part of the LAPACK routines that compute the solution to a system of linear equations AX = B, followed by a refinement of the solution, and the computation of an error bound for the system.

Specifically, ZSYSVX first solves the system AX = B where A is a general complex symmetric matrix. It uses a blocked algorithm, which is the most efficient computationally for large matrices.

It is assumed that the matrix A is symmetric (or Hermitian), and therefore, only the upper or lower triangular part of A needs to be provided. The input matrix A is not changed by ZSYSVX.

The condition number of the matrix is estimated by ZSYSVX. The estimate is used to compute the forward error bound and backward error bound for the solution X.

ZSYSVX can be called in one of two ways:

1. To solve the system AX = B

2. To solve the system AX = B and compute the condition number of A

The routine uses LAPACK's blocked algorithms for solving the system of equations, which involve the following steps:

1. Factorization of A

2. Solution of the triangular system using the factors

3. Refinement of the solution

4. Computation of the error bound

ZSYSVX performs the following steps:

  1. Check the input parameters for validity.

  2. If FACT = 'N' (Not factored), ZSYTRF is called to factorize the matrix A.

  3. If FACT = 'F' (Factored), it is assumed that A contains the factors.

  4. ZSYCON is called to compute the reciprocal of the condition number of A.

  5. ZSYTRS is called to solve the system of equations.

  6. ZSYRFS is called to refine the solution and compute error bounds.

Input Parameters

FACT
CHARACTER*1. ‘E’ or ‘N’.

Specifies whether or not the factored form of the matrix A is supplied on entry.

If FACT = 'E', then AF contains the factored form of A. If FACT = 'N', then the normal form of the matrix A is given and AF is not used.

UPLO
CHARACTER*1. ‘U’ or ‘L’.

Specifies whether A is upper or lower triangular. If UPLO = 'U', then A is upper triangular. If UPLO = 'L', then A is lower triangular.

N
INTEGER.

The order of the matrix A. N >= 0.

A
COMPLEX*16 array, dimension (LDA, N).

On entry, the symmetric or Hermitian matrix A. On exit, the LDU decomposition of A, as returned by ZSYTRF.

LDA
INTEGER.

The leading dimension of the array A. LDA >= max(1, N).

AF
COMPLEX*16 array, dimension (LDAF, N).

On entry, if FACT = 'E', AF contains the factored form of the matrix A. If FACT = 'N', AF is not used. On exit, if FACT = 'N', AF contains the LDU decomposition of A.

LDAF
INTEGER.

The leading dimension of the array AF. LDAF >= max(1, N).

IPIV
INTEGER array, dimension (N).

Details of the interchanges on the factored matrix. You must provide an interface to this array.

B
COMPLEX*16 array, dimension (LDB, N).

On entry, the matrix of right-hand side vectors, B. On exit, if the information is available, B contains the solution vectors X.

LDB
INTEGER.

The leading dimension of the array B. LDB >= max(1, N).

X
COMPLEX*16 array, dimension (LDX, N).

On entry, the matrix of right-hand side vectors, X. On exit, if the information is available, X contains the solution vectors X.

LDX
INTEGER.

The leading dimension of the array X. LDX >= max(1, N).

RCOND
DOUBLE PRECISION.

On exit, this estimate of the reciprocal of the condition number of A. A is not highly computed, but rather estimated.

FERR
DOUBLE PRECISION array, dimension (N).

On exit, an estimate of the forward residual error in the i-th solution vector, which is computed as norm(X(i) - B(i))/norm(B(i)).

BERR
DOUBLE PRECISION array, dimension (N).

On exit, an estimate of the backward error, condition number, and relative pivot growth for the i-th solution vector.

WORK
COMPLEX*16 array, dimension (MAX(1,LWORK))

On exit, if INFO = 0, WORK(1) returns the optimal LWORK.

LWORK
INTEGER.

The length of WORK. LWORK >= max(1,2*N), and for best performance, when FACT = 'N', LWORK >= max(1,2*N,N*NB), where NB is the optimal blocksize for ZSYTRF.

If LWORK = -1, then a workspace query is assumed; the routine only calculates the optimal size of the WORK array, returns this value as the first entry of the WORK array, and no error message related to LWORK is issued by XERBLA.

RWORK
DOUBLE PRECISION array, dimension (N).
INFO
INTEGER.

= 0: successful exit

< 0: if INFO = -i, the i-th argument had an illegal value

> 0: if INFO = i, and i is <= N: D(i,i) is exactly zero. The factorization has been completed but the factor D is exactly singular, so the solution and error bounds could not be computed. RCOND = 0 is returned. = N+1: D is nonsingular, but RCOND is less than machine precision, meaning that the matrix is singular to working precision. Nevertheless, the solution and error bounds are computed because there are a number of situations where the computed solution can be more accurate than the value of RCOND would suggest.
