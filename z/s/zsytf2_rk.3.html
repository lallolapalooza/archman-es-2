SINOPSIS

Funciones/Subrutinas


subrutina zsytf2_rk (uplo, n, a, lda, e, ipiv, info)

ZSYTF2_RK calcula la factorización de una matriz simétrica indefinida compleja utilizando el método de pivoteo diagonal acotado de Bunch-Kaufman (rook) (algoritmo no bloqueado BLAS2).

DOCUMENTACIÓN DE FUNCIÓN/SUBRUTINA

subrutina zsytf2_rk (carácter uplo, entero n, complejo*16, dimensión( lda, * ) a, entero lda, complejo*16, dimensión( * ) e, entero, dimensión( * ) ipiv, entero info)

ZSYTF2_RK calcula la factorización de una matriz simétrica indefinida compleja utilizando el método de pivoteo diagonal acotado de Bunch-Kaufman (rook) (algoritmo no bloqueado BLAS2).

Propósito:

!> ZSYTF2_RK calcula la factorización de una matriz simétrica A compleja
!> utilizando el método de pivoteo diagonal acotado de Bunch-Kaufman (rook):
!>
!>    A = P*U*D*(U**T)*(P**T) o A = P*L*D*(L**T)*(P**T),
!>
!> donde U (o L) es una matriz triangular superior (o inferior) unitaria,
!> U**T (o L**T) es la transpuesta de U (o L), P es una matriz de permutación,
!> P**T es la transpuesta de P, y D es simétrica y diagonal por bloques
!> con bloques diagonales de 1x1 y 2x2.
!>
!> Esta es la versión no bloqueada del algoritmo, que llama a BLAS de Nivel 2.
!> Para más información, consulte la sección Detalles Adicionales.
!>

Parámetros

UPLO 
!>          UPLO es CHARACTER*1
!>          Especifica si la parte triangular superior o inferior de la
!>          matriz simétrica A está almacenada:
!>          = 'U':  Triangular superior
!>          = 'L':  Triangular inferior
!>

N

!>          N es INTEGER
!>          El orden de la matriz A.  N >= 0.
!>

A

!>          A es un array COMPLEX*16, dimensión (LDA,N)
!>          En la entrada, la matriz simétrica A.
!>            Si UPLO = 'U': la parte triangular superior de N por N de
!>            A contiene la parte triangular superior de la matriz A,
!>            y la parte estrictamente triangular inferior de A no se referencia.
!>
!>            Si UPLO = 'L': la parte triangular inferior de N por N de
!>            A contiene la parte triangular inferior de la matriz A,
!>            y la parte estrictamente triangular superior de A no se referencia.
!>
!>          En la salida, contiene:
!>            a) SÓLO los elementos diagonales de la matriz diagonal por bloques
!>               simétrica D en la diagonal de A, es decir, D(k,k) = A(k,k);
!>               (los elementos superdiagonales (o subdiagonales) de D
!>                se almacenan en la salida en el array E), y
!>            b) Si UPLO = 'U': el factor U en la parte superdiagonal de A.
!>               Si UPLO = 'L': el factor L en la parte subdiagonal de A.
!>

LDA

!>          LDA es INTEGER
!>          La dimensión principal del array A.  LDA >= max(1,N).
!>

E

!>          E es un array COMPLEX*16, dimensión (N)
!>          En la salida, contiene los elementos superdiagonales (o subdiagonales)
!>          de la matriz diagonal por bloques simétrica D
!>          con bloques diagonales de 1x1 o 2x2, donde
!>          Si UPLO = 'U': E(i) = D(i-1,i), i=2:N, E(1) se establece a 0;
!>          Si UPLO = 'L': E(i) = D(i+1,i), i=1:N-1, E(N) se establece a 0.
!>
!>          NOTA: Para un bloque diagonal de 1x1 D(k), donde
!>          1 <= k <= N, el elemento E(k) se establece a 0 en ambos
!>          casos UPLO = 'U' o UPLO = 'L'.
!>

IPIV

!>          IPIV es un array INTEGER, dimensión (N)
!>          IPIV describe la matriz de permutación P en la factorización
!>          de la matriz A de la siguiente manera. El valor absoluto de IPIV(k)
!>          representa el índice de la fila y columna que fueron
!>          intercambiadas con la k-ésima fila y columna. El valor de UPLO
!>          describe el orden en que se aplicaron los intercambios.
!>          Además, el signo de IPIV representa la estructura de bloques
!>          de la matriz diagonal por bloques simétrica D con bloques
!>          de 1x1 o 2x2 que corresponden a 1 o 2 intercambios
!>          en cada paso de factorización. Para más información, consulte la
!>          sección Detalles Adicionales.
!>
!>          Si UPLO = 'U',
!>          ( en orden de factorización, k disminuye de N a 1 ):
!>            a) Una única entrada positiva IPIV(k) > 0 significa:
!>               D(k,k) es un bloque diagonal de 1x1.
!>               Si IPIV(k) != k, las filas y columnas k e IPIV(k) fueron
!>               intercambiadas en la matriz A(1:N,1:N);
!>               Si IPIV(k) = k, no ocurrió ningún intercambio.
!>
!>            b) Un par de entradas negativas consecutivas
!>               IPIV(k) < 0 e IPIV(k-1) < 0 significa:
!>               D(k-1:k,k-1:k) es un bloque diagonal de 2x2.
!>               (NOTA: las entradas negativas en IPIV sólo aparecen en pares).
!>               1) Si -IPIV(k) != k, las filas y columnas
!>                  k y -IPIV(k) fueron intercambiadas
!>                  en la matriz A(1:N,1:N).
!>                  Si -IPIV(k) = k, no ocurrió ningún intercambio.
!>               2) Si -IPIV(k-1) != k-1, las filas y columnas
!>                  k-1 y -IPIV(k-1) fueron intercambiadas
!>                  en la matriz A(1:N,1:N).
!>                  Si -IPIV(k-1) = k-1, no ocurrió ningún intercambio.
!>
!>            c) En ambos casos a) y b), siempre ABS( IPIV(k) ) <= k.
!>
!>            d) NOTA: Cualquier entrada IPIV(k) es siempre DISTINTA DE CERO en la salida.
!>
!>          Si UPLO = 'L',
!>          ( en orden de factorización, k aumenta de 1 a N ):
!>            a) Una única entrada positiva IPIV(k) > 0 significa:
!>               D(k,k) es un bloque diagonal de 1x1.
!>               Si IPIV(k) != k, las filas y columnas k e IPIV(k) fueron
!>               intercambiadas en la matriz A(1:N,1:N).
!>               Si IPIV(k) = k, no ocurrió ningún intercambio.
!>
!>            b) Un par de entradas negativas consecutivas
!>               IPIV(k) < 0 e IPIV(k+1) < 0 significa:
!>               D(k:k+1,k:k+1) es un bloque diagonal de 2x2.
!>               (NOTA: las entradas negativas en IPIV sólo aparecen en pares).
!>               1) Si -IPIV(k) != k, las filas y columnas
!>                  k y -IPIV(k) fueron intercambiadas
!>                  en la matriz A(1:N,1:N).
!>                  Si -IPIV(k) = k, no ocurrió ningún intercambio.
!>               2) Si -IPIV(k+1) != k+1, las filas y columnas
!>                  k y -IPIV(k) fueron intercambiadas
!>                  en la matriz A(1:N,1:N).
!>                  Si -IPIV(k+1) = k+1, no ocurrió ningún intercambio.
!>
!>            c) En ambos casos a) y b), siempre ABS( IPIV(k) ) >= k.
!>
!>            d) NOTA: Cualquier entrada IPIV(k) es siempre DISTINTA DE CERO en la salida.
!>

INFO

!>          INFO es INTEGER
!>          = 0: finalización exitosa
!>
!>          < 0: Si INFO = -k, el k-ésimo argumento tenía un valor ilegal
!>
!>          > 0: Si INFO = k, la matriz A es singular, debido a que:
!>                 Si UPLO = 'U': la columna k en la parte
!>                 triangular superior de A contiene todos ceros.
!>                 Si UPLO = 'L': la columna k en la parte
!>                 triangular inferior de A contiene todos ceros.
!>
!>               Por lo tanto, D(k,k) es exactamente cero, y los elementos
!>               superdiagonales de la columna k de U (o los elementos
!>               subdiagonales de la columna k de L) son todos ceros. La factorización se
!>               ha completado, pero la matriz diagonal por bloques D
!>               es exactamente singular, y ocurrirá una división por cero si
!>               se utiliza para resolver un sistema de ecuaciones.
!>
!>               NOTA: INFO sólo almacena la primera ocurrencia
!>               de una singularidad; cualquier ocurrencia posterior de
!>               singularidad no se almacena en INFO, aunque la factorización
!>               siempre se completa.
!>

NAME

zsytf2_rk

Routines to compute the factorization of a general band matrix

SYNOPSIS

 subroutine zsytf2_rk(UPLO, N, NB, A, LDA, IPIV, INFO)

  character UPLO
  integer N
  integer NB
  complex*16, dimension(lda, *) :: A
  integer, dimension(N) :: IPIV
  integer INFO

  character UPLO
  integer N
  integer NB
  complex*16, dimension(lda, *) :: A
  integer, dimension(N) :: IPIV
  integer INFO

Function/Subroutine Documentation

Zsytf2_rk computes the factorization of a general band matrix A in the form

A = P*U*T*U**H or A = P*L*T*L**H

where U is a band upper triangular matrix, L is a band lower triangular matrix, and T is a band tridiagonal matrix. P is a band permutation matrix. T is permuted according to IPIV.

This is the restricted pivoting version of the bordered band updates.

Argument Description

UPLO
CHARACTER*1.
On entry, UPLO specifies whether the upper or lower triangular part of the band matrix A is to be used in the computation and returned in the first NB columns of A:
'U'
U is the upper factor.
'L'
L is the lower factor.

On exit, UPLO is unchanged.
N
INTEGER.
On entry, N specifies the order of the band matrix A. N must be at least 0.
NB
INTEGER.
On entry, NB is the number of subdiagonals/superdiagonals in the band matrix A. NB must be at least 0.
A
COMPLEX*16 dimension(LDA,*)
On entry, the band matrix A in coordinate form: the first NB superdiagonals and the first NB subdiagonals store the given matrix. The remaining superdiagonals and subdiagonals are not referenced.
On exit, if UPLO = 'U', the first NB superdiagonals and the main diagonal of A store the factors U and T.
On exit, if UPLO = 'L', the first NB subdiagonals and the main diagonal of A store the factors L and T.
LDA
INTEGER.
On entry, LDA specifies the leading dimension of the array A. LDA must be at least max(1, NB + 1).
IPIV
INTEGER dimension(N)
On exit, IPIV contains the pivoting information. For each k, the row k of the matrix was interchanged with the row IPIV(k). IPIV(k) < 0 indicates a 1-by-1 pivot, and IPIV(k) > 0 indicates a 2-by-2 pivot.
INFO
INTEGER.
On exit, INFO is an integer flag. If INFO = 0, the execution was successful.
If INFO < 0, the i-th argument had an illegal value.
If INFO > 0, the k-th pivot step failed, and k is returned. T(k,k) is zero.

       Purpose:
       =======
       ZSYTF2_RK computes the factorization of a general band matrix A in the
       form
     
          A = P*U*T*U**H  or  A = P*L*T*L**H
     
       where U is a band upper triangular matrix, L is a band lower
       triangular matrix, and T is a band tridiagonal matrix. P is a band
       permutation matrix. T is permuted according to IPIV.
     
       This is the restricted pivoting version of the bordered band updates.
     
       Arguments:
       ==========
     
       UPLO    (input) CHARACTER*1
               Specifies whether the upper or lower triangular part of the
               band matrix A is to be used in the computation and returned
               in the first NB columns of A.
               = 'U': Upper band;
               = 'L': Lower band.
     
       N       (input) INTEGER
               The order of the band matrix A. N >= 0.
    '
       NB      (input) INTEGER
               The number of subdiagonals/superdiagonals in the band matrix A.
               NB >= 0.
    '
       A       (input/output) COMPLEX*16 array, dimension (LDA,*)
               On entry, the band matrix A in coordinate form. The first NB
               superdiagonals and the first NB subdiagonals store the given
               matrix. The remaining superdiagonals and subdiagonals are not
               referenced.
               On exit, if UPLO = 'U', the first NB superdiagonals and the
               main diagonal of A store the factors U and T.
               On exit, if UPLO = 'L', the first NB subdiagonals and the
               main diagonal of A store the factors L and T.
    '
       LDA     (input) INTEGER
               The leading dimension of the array A. LDA >= max(1, NB + 1).
    '
       IPIV    (output) INTEGER array, dimension (N)
               Pivoting information, by which the matrix A was permuted.
               For k = 1 to N, the row k of the matrix was interchanged with
               the row IPIV(k).
               IPIV(k) > 0 indicates a 1-by-1 pivot.
               IPIV(k) < 0 indicates a 2-by-2 pivot.
    '
       INFO    (output) INTEGER
               = 0: successful exit
               < 0: if INFO = -k, the k-th argument had an illegal value.
               > 0: if INFO = k, the k-th pivot step failed, and k is
                    returned. T(k,k) is zero.
    '
       ========================================================================

                   m = k

                   m = NB+1

    '              20    continue

    '              30    continue

    '              40    continue

                else
                   m = NB+1
                endif

                   else
                      kp1 = 1
                   endif

                      kp2 = k - NB
                   else
                      kp2 = 1
                   endif

    '          50    continue
                   do 60, r = kp2, k - 1
                      call zswap(m, A(r, k), LDA, A(r, k), LDA)
    '              60    continue
                endif

                   A(k, k-1) = ZERO
                   call zdscal(m-1, ONE/A(k, k), A(k, k-1), LDA)

                      A(k-j, k-1) = A(k-j, k-1) - alpha*A(k-j, k)
    '              70    continue
                endif
             endif
    '  10 continue

                else
                   m = NB+1
                endif
                if (m .GT. 1) then
                   call zgeru(m-1, 1, -A(k-1, k), A(k-1, k-m+1), LDA, A(k, k-m+1), LDA, A(k-1, k-m+1), LDA)
                   A(k-1, k) = ZERO
                endif
             else
                if (k .LT. NB+1) then
                   m = k
                else
                   m = NB+1
                endif
                if (m .GT. 1) then
                   call zgeru(1, m-1, -A(k, k-1), A(k-m+1, k-1), LDA, A(k-m+1, k), LDA, A(k-m+1, k-1), LDA)
                   A(k, k-1) = ZERO
                endif
             endif
    '  80 continue
     
          do 90, k = N, 1, -1
             if (lsame(UPLO, 'U')) then
                if (k .LT. NB+1) then
                   m = k
                else
                   m = NB+1
                endif
                if (m .GT. 1) then
                   call zgeru(m-1, 1, -A(k-1, k), A(k-1, k-m+1), LDA, A(k, k-m+1), LDA, A(k-1, k-m+1), LDA)
                   A(k-1, k) = ZERO

                if (m .GT. 1) then

                   A(k, k-1) = ZERO
                endif
             endif
    '  90 continue
     
          return
