DOCUMENTACIÓN DE FUNCIÓN/SUBRUTINA

subroutine zspt02 (character uplo, integer n, integer nrhs, complex*16, dimension( * ) a, complex*16, dimension( ldx, * ) x, integer ldx, complex*16, dimension( ldb, * ) b, integer ldb, double precision, dimension( * ) rwork, double precision resid)

ZSPT02

Propósito:

!>
!> ZSPT02 calcula el residuo en la solución de un sistema complejo
!> simétrico de ecuaciones lineales  A*x = b  cuando se utiliza almacenamiento
!> empaquetado para la matriz de coeficientes. La relación calculada es
!>
!>    RESID = norm( B - A*X ) / ( norm(A) * norm(X) * EPS).
!>
!> donde EPS es la precisión de la máquina.
!>

Parámetros

UPLO 
!>          UPLO es CHARACTER*1
!>          Especifica si la parte triangular superior o inferior de la
!>          matriz simétrica compleja A está almacenada:
!>          = 'U':  Triangular superior
!>          = 'L':  Triangular inferior
!>

N

!>          N es INTEGER
!>          El número de filas y columnas de la matriz A.  N >= 0.
!>

NRHS

!>          NRHS es INTEGER
!>          El número de columnas de B, la matriz de lados derechos.
!>          NRHS >= 0.
!>

A

!>          A es un array COMPLEX*16, dimension (N*(N+1)/2)
!>          La matriz simétrica compleja original A, almacenada como
!>          una matriz triangular empaquetada.
!>

X

!>          X es un array COMPLEX*16, dimension (LDX,NRHS)
!>          Los vectores de solución calculados para el sistema de
!>          ecuaciones lineales.
!>

LDX

!>          LDX es INTEGER
!>          La dimensión principal del array X.   LDX >= max(1,N).
!>

B

!>          B es un array COMPLEX*16, dimension (LDB,NRHS)
!>          En la entrada, los vectores del lado derecho para el sistema
!>          de ecuaciones lineales.
!>          En la salida, B se sobrescribe con la diferencia B - A*X.
!>

LDB

!>          LDB es INTEGER
!>          La dimensión principal del array B.  LDB >= max(1,N).
!>

RWORK

!>          RWORK es un array DOUBLE PRECISION, dimension (N)
!>

RESID

!>          RESID es DOUBLE PRECISION
!>          El máximo sobre el número de lados derechos de
!>          norm(B - A*X) / ( norm(A) * norm(X) * EPS ).
!>
