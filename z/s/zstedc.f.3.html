Documentación de la función/subrutina

subroutine zstedc (character compz, integer n, double precision, dimension( * ) d, double precision, dimension( * ) e, complex*16, dimension( ldz, * ) z, integer ldz, complex*16, dimension( * ) work, integer lwork, double precision, dimension( * ) rwork, integer lrwork, integer, dimension( * ) iwork, integer liwork, integer info)

ZSTEDC

Propósito:

!>
!> ZSTEDC calcula todos los valores propios y, opcionalmente, los vectores propios
!> de una matriz tridiagonal simétrica utilizando el método de división y conquista.
!> Los vectores propios de una matriz Hermítica compleja completa o de banda también
!> pueden encontrarse si se han utilizado ZHETRD o ZHPTRD o ZHBTRD para reducir esta
!> matriz a forma tridiagonal.
!>
!>

Parámetros

COMPZ 
!>          COMPZ es CHARACTER*1
!>          = 'N':  Calcular solo los valores propios.
!>          = 'I':  Calcular también los vectores propios de la matriz tridiagonal.
!>          = 'V':  Calcular también los vectores propios de la matriz Hermítica original.
!>                  En la entrada, Z contiene la matriz unitaria utilizada
!>                  para reducir la matriz original a forma tridiagonal.
!>

N

!>          N es INTEGER
!>          La dimensión de la matriz tridiagonal simétrica.  N >= 0.
!>

D

!>          D es un array DOUBLE PRECISION, de dimensión (N)
!>          En la entrada, los elementos diagonales de la matriz tridiagonal.
!>          En la salida, si INFO = 0, los valores propios en orden ascendente.
!>

E

!>          E es un array DOUBLE PRECISION, de dimensión (N-1)
!>          En la entrada, los elementos subdiagonales de la matriz tridiagonal.
!>          En la salida, E ha sido destruido.
!>

Z

!>          Z es un array COMPLEX*16, de dimensión (LDZ,N)
!>          En la entrada, si COMPZ = 'V', entonces Z contiene la matriz
!>          unitaria utilizada en la reducción a forma tridiagonal.
!>          En la salida, si INFO = 0, entonces si COMPZ = 'V', Z contiene los
!>          vectores propios ortonormales de la matriz Hermítica original,
!>          y si COMPZ = 'I', Z contiene los vectores propios ortonormales
!>          de la matriz tridiagonal simétrica.
!>          Si  COMPZ = 'N', entonces Z no se referencia.
!>

LDZ

!>          LDZ es INTEGER
!>          La dimensión principal del array Z.  LDZ >= 1.
!>          Si se desean vectores propios, entonces LDZ >= max(1,N).
!>

WORK

!>          WORK es un array COMPLEX*16, de dimensión (MAX(1,LWORK))
!>          En la salida, si INFO = 0, WORK(1) devuelve el LWORK óptimo.
!>

LWORK

!>          LWORK es INTEGER
!>          La dimensión del array WORK.
!>          Si COMPZ = 'N' o 'I', o N <= 1, LWORK debe ser al menos 1.
!>          Si COMPZ = 'V' y N > 1, LWORK debe ser al menos N*N.
!>          Tenga en cuenta que para COMPZ = 'V', si N es menor o
!>          igual al tamaño mínimo de división, generalmente 25, entonces LWORK solo
!>          necesita ser 1.
!>
!>          Si LWORK = -1, entonces se asume una consulta de espacio de trabajo; la rutina
!>          solo calcula los tamaños óptimos de los arrays WORK, RWORK y
!>          IWORK, devuelve estos valores como las primeras entradas de
!>          los arrays WORK, RWORK y IWORK, y XERBLA no emite ningún mensaje de error
!>          relacionado con LWORK o LRWORK o LIWORK.
!>

RWORK

!>          RWORK es un array DOUBLE PRECISION, de dimensión (MAX(1,LRWORK))
!>          En la salida, si INFO = 0, RWORK(1) devuelve el LRWORK óptimo.
!>

LRWORK

!>          LRWORK es INTEGER
!>          La dimensión del array RWORK.
!>          Si COMPZ = 'N' o N <= 1, LRWORK debe ser al menos 1.
!>          Si COMPZ = 'V' y N > 1, LRWORK debe ser al menos
!>                         1 + 3*N + 2*N*lg N + 4*N**2 ,
!>                         donde lg( N ) = el menor entero k tal que
!>                         2**k >= N.
!>          Si COMPZ = 'I' y N > 1, LRWORK debe ser al menos
!>                         1 + 4*N + 2*N**2 .
!>          Tenga en cuenta que para COMPZ = 'I' o 'V', si N es menor o
!>          igual al tamaño mínimo de división, generalmente 25, entonces LRWORK solo
!>          necesita ser max(1,2*(N-1)).
!>
!>          Si LRWORK = -1, entonces se asume una consulta de espacio de trabajo; la rutina
!>          solo calcula los tamaños óptimos de los arrays WORK, RWORK y
!>          IWORK, devuelve estos valores como las primeras entradas de
!>          los arrays WORK, RWORK y IWORK, y XERBLA no emite ningún mensaje de error
!>          relacionado con LWORK o LRWORK o LIWORK.
!>

IWORK

!>          IWORK es un array INTEGER, de dimensión (MAX(1,LIWORK))
!>          En la salida, si INFO = 0, IWORK(1) devuelve el LIWORK óptimo.
!>

LIWORK

!>          LIWORK es INTEGER
!>          La dimensión del array IWORK.
!>          Si COMPZ = 'N' o N <= 1, LIWORK debe ser al menos 1.
!>          Si COMPZ = 'V' o N > 1,  LIWORK debe ser al menos
!>                                    6 + 6*N + 5*N*lg N.
!>          Si COMPZ = 'I' o N > 1,  LIWORK debe ser al menos
!>                                    3 + 5*N .
!>          Tenga en cuenta que para COMPZ = 'I' o 'V', si N es menor o
!>          igual al tamaño mínimo de división, generalmente 25, entonces LIWORK solo
!>          necesita ser 1.
!>
!>          Si LIWORK = -1, entonces se asume una consulta de espacio de trabajo; la rutina
!>          solo calcula los tamaños óptimos de los arrays WORK, RWORK y
!>          IWORK, devuelve estos valores como las primeras entradas de
!>          los arrays WORK, RWORK y IWORK, y XERBLA no emite ningún mensaje de error
!>          relacionado con LWORK o LRWORK o LIWORK.
!>

INFO

!>          INFO es INTEGER
!>          = 0:  salida exitosa.
!>          < 0:  si INFO = -i, el i-ésimo argumento tenía un valor ilegal.
!>          > 0:  El algoritmo no pudo calcular un valor propio mientras
!>                trabajaba en la submatriz ubicada en las filas y columnas
!>                INFO/(N+1) hasta mod(INFO,N+1).
!>

NAME

zstedc - ZSTEDC computes the inverse of a reduction of a complex Hermitian (upper or lower) tridiagonal matrix to standard diagonal form.

SYNOPSIS

SUBROUTINE ZSTEDC(
     SENSE, COMPQ, N, D, E, Z, LDZ, WORK, RWORK,
     IWORK, INFO)
CHARACTER * 1 :: SENSE
CHARACTER * 1 :: COMPQ
INTEGER :: N
DOUBLE PRECISION, DIMENSION( * ) :: D
DOUBLE PRECISION, DIMENSION( * ) :: E
COMPLEX(8), DIMENSION( * ) :: Z
INTEGER :: LDZ
COMPLEX(8), DIMENSION( * ) :: WORK
DOUBLE PRECISION, DIMENSION( * ) :: RWORK
INTEGER, DIMENSION( * ) :: IWORK
INTEGER :: INFO

Function/Subroutine Documentation

ZSTEDC computes the inverse of a reduction of a complex Hermitian (upper or lower) tridiagonal matrix to standard diagonal form.

Arguments

SENSE
(Input) CHARACTER*1 Specifies which quantities to compute: = 'N': none = 'E': only the eigenvalues = 'V': only the eigenvectors = 'B': both the eigenvalues and the eigenvectors
COMPQ
(Input) CHARACTER*1 Specifies whether to compute the matrix of eigenvectors. See also SENSE. = 'N': Do not compute the matrix of eigenvectors. = 'P': Compute the matrix of eigenvectors.
N
(Input) INTEGER The order of the matrix T. N >= 0.
D
(Input) DOUBLE PRECISION array, dimension (N) On entry, the diagonal elements of the tridiagonal matrix T. On exit, if SENSE = 'E' or SENSE = 'B', then D contains the eigenvalues of T in ascending order.
E
(Input) DOUBLE PRECISION array, dimension (N-1) On entry, the off-diagonal elements of the tridiagonal matrix T. On exit, E is overwritten by the computation of the eigenvectors.
Z
(Output) COMPLEX*16 array, dimension (LDZ, N) On exit, if COMPQ = 'P' or SENSE = 'V' or SENSE = 'B', then Z contains the eigenvectors of T. The (i, j) column of Z is the eigenvector corresponding to the eigenvalue D(j).
LDZ
(Input) INTEGER The leading dimension of the array Z. LDZ >= max(1, N).
WORK
(Workspace) COMPLEX*16 array, dimension (N) The imaginary parts of the eigenvectors.
RWORK
(Workspace) DOUBLE PRECISION array, dimension (3N) Real workspace array.
IWORK
(Workspace) INTEGER array, dimension (N) Integer workspace array.
INFO
(Output) INTEGER = 0: successful computation < 0: if INFO = -i, the i-th argument had an illegal value. > 0: if INFO = i, the algorithm failed to converge; i off-diagonal elements of an intermediate tridiagonal matrix need to be constructed, and 1 to i elements could not be constructed.
