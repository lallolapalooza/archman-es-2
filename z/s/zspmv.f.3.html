subrutina zspmv (uplo, n, alpha, ap, x, incx, beta, y, incy)

ZSPMV calcula el producto de una matriz por un vector para vectores complejos utilizando una matriz compleja simétrica empaquetada.

Documentación de la función/subrutina

subrutina zspmv (character uplo, integer n, complex*16 alpha, complex*16, dimension( * ) ap, complex*16, dimension( * ) x, integer incx, complex*16 beta, complex*16, dimension( * ) y, integer incy)

ZSPMV calcula el producto de una matriz por un vector para vectores complejos utilizando una matriz compleja simétrica empaquetada.

Propósito:

!>
!> ZSPMV  realiza la operación de matriz-vector
!>
!>    y := alpha*A*x + beta*y,
!>
!> donde alpha y beta son escalares, x e y son vectores de n elementos y
!> A es una matriz simétrica de n por n, suministrada en forma empaquetada.
!>

Parámetros

UPLO 
!>          UPLO es CHARACTER*1
!>           Al entrar, UPLO especifica si la parte triangular superior o
!>           inferior de la matriz A se suministra en el array AP de la
!>           siguiente manera:
!>
!>              UPLO = 'U' o 'u'   La parte triangular superior de A se
!>                                  suministra en AP.
!>
!>              UPLO = 'L' o 'l'   La parte triangular inferior de A se
!>                                  suministra en AP.
!>
!>           Sin cambios a la salida.
!>

N

!>          N es INTEGER
!>           Al entrar, N especifica el orden de la matriz A.
!>           N debe ser al menos cero.
!>           Sin cambios a la salida.
!>

ALPHA

!>          ALPHA es COMPLEX*16
!>           Al entrar, ALPHA especifica el escalar alpha.
!>           Sin cambios a la salida.
!>

AP

!>          AP es un array COMPLEX*16, de dimensión al menos
!>           ( ( N*( N + 1 ) )/2 ).
!>           Antes de la entrada, con UPLO = 'U' o 'u', el array AP debe
!>           contener la parte triangular superior de la matriz simétrica
!>           empaquetada secuencialmente, columna por columna, de modo que AP( 1 )
!>           contenga a( 1, 1 ), AP( 2 ) y AP( 3 ) contengan a( 1, 2 )
!>           y a( 2, 2 ) respectivamente, y así sucesivamente.
!>           Antes de la entrada, con UPLO = 'L' o 'l', el array AP debe
!>           contener la parte triangular inferior de la matriz simétrica
!>           empaquetada secuencialmente, columna por columna, de modo que AP( 1 )
!>           contenga a( 1, 1 ), AP( 2 ) y AP( 3 ) contengan a( 2, 1 )
!>           y a( 3, 1 ) respectivamente, y así sucesivamente.
!>           Sin cambios a la salida.
!>

X

!>          X es un array COMPLEX*16, de dimensión al menos
!>           ( 1 + ( N - 1 )*abs( INCX ) ).
!>           Antes de la entrada, el array incrementado X debe contener el
!>           vector x de N elementos.
!>           Sin cambios a la salida.
!>

INCX

!>          INCX es INTEGER
!>           Al entrar, INCX especifica el incremento para los elementos de
!>           X. INCX no debe ser cero.
!>           Sin cambios a la salida.
!>

BETA

!>          BETA es COMPLEX*16
!>           Al entrar, BETA especifica el escalar beta. Cuando BETA se
!>           suministra como cero, Y no necesita ser establecido a la entrada.
!>           Sin cambios a la salida.
!>

Y

!>          Y es un array COMPLEX*16, de dimensión al menos
!>           ( 1 + ( N - 1 )*abs( INCY ) ).
!>           Antes de la entrada, el array incrementado Y debe contener el
!>           vector y de n elementos. A la salida, Y se sobrescribe con el
!>           vector y actualizado.
!>

INCY

!>          INCY es INTEGER
!>           Al entrar, INCY especifica el incremento para los elementos de
!>           Y. INCY no debe ser cero.
!>           Sin cambios a la salida.
!>
