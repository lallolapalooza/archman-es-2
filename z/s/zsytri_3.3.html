Documentación de Función/Subrutina

subroutine zsytri_3 (character uplo, integer n, complex*16, dimension( lda, * ) a, integer lda, complex*16, dimension( * ) e, integer, dimension( * ) ipiv, complex*16, dimension( * ) work, integer lwork, integer info)

ZSYTRI_3

Propósito:

!> ZSYTRI_3 calcula la inversa de una matriz simétrica indefinida compleja A
!> utilizando la factorización calculada por ZSYTRF_RK o ZSYTRF_BK:
!>
!>     A = P*U*D*(U**T)*(P**T) o A = P*L*D*(L**T)*(P**T),
!>
!> donde U (o L) es una matriz triangular superior (o inferior) unitaria,
!> U**T (o L**T) es la transpuesta de U (o L), P es una matriz de permutación,
!> P**T es la transpuesta de P, y D es simétrica y diagonal por bloques
!> con bloques diagonales de 1x1 y 2x2.
!>
!> ZSYTRI_3 establece la dimensión principal del área de trabajo antes de llamar a
!> ZSYTRI_3X que realmente calcula la inversa. Esta es la versión bloqueada
!> del algoritmo, que llama a BLAS de Nivel 3.
!>

Parámetros

UPLO 
!>          UPLO es CHARACTER*1
!>          Especifica si los detalles de la factorización se almacenan
!>          como una matriz triangular superior o inferior.
!>          = 'U':  Se almacena la parte triangular superior de A;
!>          = 'L':  Se almacena la parte triangular inferior de A.
!>

N

!>          N es INTEGER
!>          El orden de la matriz A.  N >= 0.
!>

A

!>          A es un array COMPLEX*16, dimensión (LDA,N)
!>          En la entrada, la diagonal de la matriz diagonal por bloques D y
!>          los factores U o L calculados por ZSYTRF_RK y ZSYTRF_BK:
!>            a) SÓLO los elementos diagonales de la matriz simétrica diagonal
!>               por bloques D en la diagonal de A, es decir, D(k,k) = A(k,k);
!>               (los elementos de la superdiagonal (o subdiagonal) de D
!>                deben proporcionarse en la entrada en el array E), y
!>            b) Si UPLO = 'U': el factor U en la parte superdiagonal de A.
!>               Si UPLO = 'L': el factor L en la parte subdiagonal de A.
!>
!>          En la salida, si INFO = 0, la inversa simétrica de la matriz original.
!>             Si UPLO = 'U': se forma la parte triangular superior de la inversa
!>             y la parte de A debajo de la diagonal no se referencia;
!>             Si UPLO = 'L': se forma la parte triangular inferior de la inversa
!>             y la parte de A encima de la diagonal no se referencia.
!>

LDA

!>          LDA es INTEGER
!>          La dimensión principal del array A.  LDA >= max(1,N).
!>

E

!>          E es un array COMPLEX*16, dimensión (N)
!>          En la entrada, contiene los elementos de la superdiagonal (o subdiagonal)
!>          de la matriz simétrica diagonal por bloques D
!>          con bloques diagonales de 1x1 o 2x2, donde
!>          Si UPLO = 'U': E(i) = D(i-1,i),i=2:N, E(1) no se referencia;
!>          Si UPLO = 'L': E(i) = D(i+1,i),i=1:N-1, E(N) no se referencia.
!>
!>          NOTA: Para un bloque diagonal de 1x1 D(k), donde
!>          1 <= k <= N, el elemento E(k) no se referencia en ambos
!>          casos UPLO = 'U' o UPLO = 'L'.
!>

IPIV

!>          IPIV es un array INTEGER, dimensión (N)
!>          Detalles de los intercambios y la estructura de bloques de D
!>          determinados por ZSYTRF_RK o ZSYTRF_BK.
!>

WORK

!>          WORK es un array COMPLEX*16, dimensión (N+NB+1)*(NB+3).
!>          En la salida, si INFO = 0, WORK(1) devuelve el LWORK óptimo.
!>

LWORK

!>          LWORK es INTEGER
!>          La longitud de WORK. LWORK >= (N+NB+1)*(NB+3).
!>
!>          Si LDWORK = -1, entonces se asume una consulta de espacio de trabajo;
!>          la rutina solo calcula el tamaño óptimo del tamaño óptimo
!>          del array WORK, devuelve este valor como la primera
!>          entrada del array WORK, y XERBLA no emite ningún mensaje de error
!>          relacionado con LWORK.
!>

INFO

!>          INFO es INTEGER
!>          = 0: finalización exitosa
!>          < 0: si INFO = -i, el i-ésimo argumento tenía un valor ilegal
!>          > 0: si INFO = i, D(i,i) = 0; la matriz es singular y su
!>               inversa no se pudo calcular.
!>
