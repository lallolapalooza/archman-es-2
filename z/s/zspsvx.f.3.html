Documentación de Función/Subrutina

subroutine zspsvx (character fact, character uplo, integer n, integer nrhs, complex*16, dimension( * ) ap, complex*16, dimension( * ) afp, integer, dimension( * ) ipiv, complex*16, dimension( ldb, * ) b, integer ldb, complex*16, dimension( ldx, * ) x, integer ldx, double precision rcond, double precision, dimension( * ) ferr, double precision, dimension( * ) berr, complex*16, dimension( * ) work, double precision, dimension( * ) rwork, integer info)

ZSPSVX calcula la solución al sistema de ecuaciones lineales A * X = B para matrices OTHER

Propósito:

!>
!> ZSPSVX utiliza la factorización de pivoteo diagonal A = U*D*U**T o
!> A = L*D*L**T para calcular la solución a un sistema lineal complejo de
!> ecuaciones A * X = B, donde A es una matriz simétrica de N por N almacenada
!> en formato empaquetado y X y B son matrices de N por NRHS.
!>
!> También se proporcionan límites de error en la solución y una estimación de la condición.
!>

Descripción:

!>
!> Se realizan los siguientes pasos:
!>
!> 1. Si FACT = 'N', se utiliza el método de pivoteo diagonal para factorizar A como
!>       A = U * D * U**T,  si UPLO = 'U', o
!>       A = L * D * L**T,  si UPLO = 'L',
!>    donde U (o L) es un producto de matrices triangulares unitarias superiores (inferiores)
!>    y de permutación, y D es simétrica y de bloques diagonales con
!>    bloques diagonales de 1x1 y 2x2.
!>
!> 2. Si algún D(i,i)=0, de modo que D es exactamente singular, la rutina
!>    regresa con INFO = i. De lo contrario, la forma factorizada de A se utiliza
!>    para estimar el número de condición de la matriz A. Si el
!>    recíproco del número de condición es menor que la precisión de la máquina,
!>    INFO = N+1 se retorna como una advertencia, pero la rutina aún procede
!>    para resolver X y calcular los límites de error como se describe a continuación.
!>
!> 3. El sistema de ecuaciones se resuelve para X utilizando la forma factorizada
!>    de A.
!>
!> 4. Se aplica refinamiento iterativo para mejorar la solución calculada
!>    y calcular los límites de error y las estimaciones de error hacia atrás
!>    para ella.
!>

Parámetros

FACT 
!>          FACT es CHARACTER*1
!>          Especifica si la forma factorizada de A se ha proporcionado o no
!>          en la entrada.
!>          = 'F':  En la entrada, AFP e IPIV contienen la forma factorizada
!>                  de A.  AP, AFP e IPIV no se modificarán.
!>          = 'N':  La matriz A se copiará a AFP y se factorizará.
!>

UPLO

!>          UPLO es CHARACTER*1
!>          = 'U':  Se almacena el triángulo superior de A;
!>          = 'L':  Se almacena el triángulo inferior de A.
!>

N

!>          N es INTEGER
!>          El número de ecuaciones lineales, es decir, el orden de
!>          la matriz A.  N >= 0.
!>

NRHS

!>          NRHS es INTEGER
!>          El número de lados derechos, es decir, el número de columnas
!>          de las matrices B y X.  NRHS >= 0.
!>

AP

!>          AP es una matriz COMPLEX*16, dimensión (N*(N+1)/2)
!>          El triángulo superior o inferior de la matriz simétrica A, empaquetado
!>          por columnas en un array lineal. La j-ésima columna de A se almacena
!>          en el array AP de la siguiente manera:
!>          si UPLO = 'U', AP(i + (j-1)*j/2) = A(i,j) para 1<=i<=j;
!>          si UPLO = 'L', AP(i + (j-1)*(2*n-j)/2) = A(i,j) para j<=i<=n.
!>          Ver más abajo para más detalles.
!>

AFP

!>          AFP es una matriz COMPLEX*16, dimensión (N*(N+1)/2)
!>          Si FACT = 'F', entonces AFP es un argumento de entrada y en la entrada
!>          contiene la matriz diagonal de bloques D y los multiplicadores utilizados
!>          para obtener el factor U o L de la factorización
!>          A = U*D*U**T o A = L*D*L**T tal como fue calculada por ZSPTRF, almacenada como
!>          una matriz triangular empaquetada en el mismo formato de almacenamiento que A.
!>
!>          Si FACT = 'N', entonces AFP es un argumento de salida y en la salida
!>          contiene la matriz diagonal de bloques D y los multiplicadores utilizados
!>          para obtener el factor U o L de la factorización
!>          A = U*D*U**T o A = L*D*L**T tal como fue calculada por ZSPTRF, almacenada como
!>          una matriz triangular empaquetada en el mismo formato de almacenamiento que A.
!>

IPIV

!>          IPIV es un array INTEGER, dimensión (N)
!>          Si FACT = 'F', entonces IPIV es un argumento de entrada y en la entrada
!>          contiene detalles de los intercambios y la estructura de bloques
!>          de D, tal como fue determinada por ZSPTRF.
!>          Si IPIV(k) > 0, entonces las filas y columnas k e IPIV(k) fueron
!>          intercambiadas y D(k,k) es un bloque diagonal de 1x1.
!>          Si UPLO = 'U' e IPIV(k) = IPIV(k-1) < 0, entonces las filas y
!>          columnas k-1 e -IPIV(k) fueron intercambiadas y D(k-1:k,k-1:k)
!>          es un bloque diagonal de 2x2. Si UPLO = 'L' e IPIV(k) =
!>          IPIV(k+1) < 0, entonces las filas y columnas k+1 e -IPIV(k) fueron
!>          intercambiadas y D(k:k+1,k:k+1) es un bloque diagonal de 2x2.
!>
!>          Si FACT = 'N', entonces IPIV es un argumento de salida y en la salida
!>          contiene detalles de los intercambios y la estructura de bloques
!>          de D, tal como fue determinada por ZSPTRF.
!>

B

!>          B es un array COMPLEX*16, dimensión (LDB,NRHS)
!>          La matriz B del lado derecho de N por NRHS.
!>

LDB

!>          LDB es INTEGER
!>          La dimensión principal del array B.  LDB >= max(1,N).
!>

X

!>          X es un array COMPLEX*16, dimensión (LDX,NRHS)
!>          Si INFO = 0 o INFO = N+1, la matriz solución X de N por NRHS.
!>

LDX

!>          LDX es INTEGER
!>          La dimensión principal del array X.  LDX >= max(1,N).
!>

RCOND

!>          RCOND es DOUBLE PRECISION
!>          La estimación del número de condición recíproco de la matriz
!>          A.  Si RCOND es menor que la precisión de la máquina (en
!>          particular, si RCOND = 0), la matriz es singular con precisión de trabajo.
!>          Esta condición se indica con un código de retorno de
!>          INFO > 0.
!>

FERR

!>          FERR es un array DOUBLE PRECISION, dimensión (NRHS)
!>          El límite de error hacia adelante estimado para cada vector solución
!>          X(j) (la j-ésima columna de la matriz solución X).
!>          Si XTRUE es la solución verdadera correspondiente a X(j), FERR(j)
!>          es un límite superior estimado para la magnitud del elemento más grande
!>          en (X(j) - XTRUE) dividido por la magnitud del elemento más grande
!>          en X(j). La estimación es tan confiable como
!>          la estimación para RCOND, y es casi siempre una ligera
!>          sobreestimación del error verdadero.
!>

BERR

!>          BERR es un array DOUBLE PRECISION, dimensión (NRHS)
!>          El error hacia atrás relativo componente a componente de cada vector solución
!>          X(j) (es decir, el cambio relativo más pequeño en
!>          cualquier elemento de A o B que haga que X(j) sea una solución exacta).
!>

WORK

!>          WORK es un array COMPLEX*16, dimensión (2*N)
!>

RWORK

!>          RWORK es un array DOUBLE PRECISION, dimensión (N)
!>

INFO

!>          INFO es INTEGER
!>          = 0: finalización exitosa
!>          < 0: si INFO = -i
