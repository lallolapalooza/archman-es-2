ZSYSV_AA calcula la solución del sistema de ecuaciones lineales A * X = B para matrices SY

Propósito:

!>
!> ZSYSV calcula la solución de un sistema de ecuaciones lineales complejo
!>    A * X = B,
!> donde A es una matriz simétrica de N por N y X y B son matrices de N por NRHS.
!>
!> Se utiliza el algoritmo de Aasen para factorizar A como
!>    A = U**T * T * U,  si UPLO = 'U', o
!>    A = L * T * L**T,  si UPLO = 'L',
!> donde U (o L) es un producto de permutación y matrices triangulares unitarias superiores (inferiores), y T es simétrica tridiagonal. La forma factorizada de A se utiliza entonces para resolver el sistema de ecuaciones A * X = B.
!>

Parámetros

UPLO 
!>          UPLO es CHARACTER*1
!>          = 'U':  El triángulo superior de A se almacena;
!>          = 'L':  El triángulo inferior de A se almacena.
!>

N

!>          N es INTEGER
!>          El número de ecuaciones lineales, es decir, el orden de
!>          la matriz A.  N >= 0.
!>

NRHS

!>          NRHS es INTEGER
!>          El número de lados derechos, es decir, el número de columnas
!>          de la matriz B.  NRHS >= 0.
!>

A

!>          A es una matriz COMPLEX*16, de dimensión (LDA,N)
!>          En la entrada, la matriz simétrica A.  Si UPLO = 'U', la parte
!>          superior triangular de N por N de A contiene la parte
!>          triangular superior de la matriz A, y la parte triangular estrictamente
!>          inferior de A no se referencia. Si UPLO = 'L', la parte
!>          inferior triangular de N por N de A contiene la parte
!>          triangular inferior de la matriz A, y la parte triangular estrictamente
!>          superior de A no se referencia.
!>
!>          En la salida, si INFO = 0, la matriz tridiagonal T y los
!>          multiplicadores utilizados para obtener el factor U o L de
!>          la factorización A = U**T*T*U o A = L*T*L**T como calculados por
!>          ZSYTRF.
!>

LDA

!>          LDA es INTEGER
!>          La dimensión principal de la matriz A.  LDA >= max(1,N).
!>

IPIV

!>          IPIV es una matriz INTEGER, de dimensión (N)
!>          En la salida, contiene los detalles de los intercambios, es decir,
!>          la fila y columna k de A fueron intercambiadas con la
!>          fila y columna IPIV(k).
!>

B

!>          B es una matriz COMPLEX*16, de dimensión (LDB,NRHS)
!>          En la entrada, la matriz B de N por NRHS del lado derecho.
!>          En la salida, si INFO = 0, la matriz solución X de N por NRHS.
!>

LDB

!>          LDB es INTEGER
!>          La dimensión principal de la matriz B.  LDB >= max(1,N).
!>

WORK

!>          WORK es una matriz COMPLEX*16, de dimensión (MAX(1,LWORK))
!>          En la salida, si INFO = 0, WORK(1) devuelve el LWORK óptimo.
!>

LWORK

!>          LWORK es INTEGER
!>          La longitud de WORK.  LWORK >= MAX(1,2*N,3*N-2), y para
!>          el mejor rendimiento, LWORK >= MAX(1,N*NB), donde NB es
!>          el tamaño de bloque óptimo para ZSYTRF_AA.
!>
!>          Si LWORK = -1, entonces se asume una consulta de espacio de trabajo; la rutina
!>          solo calcula el tamaño óptimo de la matriz WORK, devuelve
!>          este valor en la primera entrada de la matriz WORK, y ninguna mensaje de error
!>          relacionado con LWORK es emitido por XERBLA.
!>

INFO

!>          INFO es INTEGER
!>          = 0: salida exitosa
!>          < 0: si INFO = -i, el i-ésimo argumento tuvo un valor ilegal
!>          > 0: si INFO = i, D(i,i) es exactamente cero. La factorización
!>               se ha completado, pero la matriz diagonal por bloques D es
!>               exactamente singular, por lo que la solución no pudo ser calculada.
!>
