DOCUMENTACIÓN DE FUNCIÓN/SUBRUTINA

subroutine zspt03 (character uplo, integer n, complex*16, dimension( * ) a, complex*16, dimension( * ) ainv, complex*16, dimension( ldw, * ) work, integer ldw, double precision, dimension( * ) rwork, double precision rcond, double precision resid)

ZSPT03

Propósito:

!>
!> ZSPT03 calcula el residuo para una matriz simétrica compleja empaquetada
!> multiplicada por su inversa:
!>    norm( I - A*AINV ) / ( N * norm(A) * norm(AINV) * EPS ),
!> donde EPS es la epsilon de la máquina.
!>

Parámetros

UPLO 
!>          UPLO es CHARACTER*1
!>          Especifica si la parte triangular superior o inferior de la
!>          matriz simétrica compleja A está almacenada:
!>          = 'U':  Triangular superior
!>          = 'L':  Triangular inferior
!>

N

!>          N es INTEGER
!>          El número de filas y columnas de la matriz A.  N >= 0.
!>

A

!>          A es array COMPLEX*16, dimension (N*(N+1)/2)
!>          La matriz simétrica compleja original A, almacenada como una
!>          matriz triangular empaquetada.
!>

AINV

!>          AINV es array COMPLEX*16, dimension (N*(N+1)/2)
!>          La inversa (simétrica) de la matriz A, almacenada como una
!>          matriz triangular empaquetada.
!>

WORK

!>          WORK es array COMPLEX*16, dimension (LDW,N)
!>

LDW

!>          LDW es INTEGER
!>          La dimensión principal del array WORK.  LDW >= max(1,N).
!>

RWORK

!>          RWORK es array DOUBLE PRECISION, dimension (N)
!>

RCOND

!>          RCOND es DOUBLE PRECISION
!>          El recíproco del número de condición de A, calculado como
!>          ( 1/norm(A) ) / norm(AINV).
!>

RESID

!>          RESID es DOUBLE PRECISION
!>          norm(I - A*AINV) / ( N * norm(A) * norm(AINV) * EPS )
!>
