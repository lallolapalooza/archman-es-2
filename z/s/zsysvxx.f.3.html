ZSYSVXX calcula la solución al sistema de ecuaciones lineales A * X = B para matrices SY

Propósito:

!>
!>    ZSYSVXX utiliza la factorización por pivoteo diagonal para calcular la
!>    solución a un sistema de ecuaciones lineales complejas*16 A * X = B, donde
!>    A es una matriz simétrica N por N y X y B son matrices N por NRHS.
!>
!>    Si se solicita, se devuelven límites de error tanto normativos como
!>    de componente máxima. ZSYSVXX devolverá una solución con un error
!>    garantizado minúsculo (O(eps) donde eps es la precisión de la máquina de
!>    trabajo) a menos que la matriz esté muy mal condicionada, en cuyo caso
!>    se devuelve una advertencia. También se calculan y devuelven los números
!>    de condición relevantes.
!>
!>    ZSYSVXX acepta factorizaciones y factores de equilibrado proporcionados
!>    por el usuario; consulte las definiciones de las opciones FACT y EQUED.
!>    Resolver con refinamiento y usar una factorización de una llamada
!>    anterior a ZSYSVXX también producirá una solución con errores de O(eps)
!>    o advertencias, pero no podemos hacer esa afirmación para factorizaciones
!>    y factores de equilibrado proporcionados por el usuario en general si
!>    difieren de lo que ZSYSVXX produciría por sí mismo.
!>

Descripción:

!>
!>    Se realizan los siguientes pasos:
!>
!>    1. Si FACT = 'E', se calculan factores de escala de doble precisión para
!>    equilibrar el sistema:
!>
!>      diag(S)*A*diag(S)     *inv(diag(S))*X = diag(S)*B
!>
!>    Si el sistema se equilibrará o no depende de la escala de la matriz A,
!>    pero si se utiliza el equilibrado, A se sobrescribe con diag(S)*A*diag(S)
!>    y B con diag(S)*B.
!>
!>    2. Si FACT = 'N' o 'E', se utiliza la descomposición LU para factorizar
!>    la matriz A (después del equilibrado si FACT = 'E') como
!>
!>       A = U * D * U**T,  si UPLO = 'U', o
!>       A = L * D * L**T,  si UPLO = 'L',
!>
!>    donde U (o L) es un producto de permutaciones y matrices triangulares
!>    unitaria superior (inferior), y D es simétrica y de bloques diagonales
!>    con bloques diagonales de 1x1 y 2x2.
!>
!>    3. Si algún D(i,i)=0, de modo que D sea exactamente singular, entonces
!>    la subrutina sale con INFO = i. De lo contrario, la forma factorizada
!>    de A se utiliza para estimar el número de condición de la matriz A (ver
!>    argumento RCOND). Si la recíproca del número de condición es menor que
!>    la precisión de la máquina, la subrutina continúa resolviendo para X y
!>    calculando límites de error como se describe a continuación.
!>
!>    4. El sistema de ecuaciones se resuelve para X utilizando la forma
!>    factorizada de A.
!>
!>    5. Por defecto (a menos que PARAMS(LA_LINRX_ITREF_I) se establezca en cero),
!>    la subrutina utilizará refinamiento iterativo para intentar obtener
!>    un error pequeño y límites de error. El refinamiento calcula el residuo
!>    al menos al doble de la precisión de trabajo.
!>
!>    6. Si se utilizó el equilibrado, la matriz X se premultiplica por
!>    diag(R) para que resuelva el sistema original antes del
!>    equilibrado.
!> 
!>     Algunos parámetros opcionales se agrupan en el array PARAMS. Estos
!>     ajustes determinan cómo se realiza el refinamiento, pero a menudo
!>     los valores predeterminados son aceptables. Si los valores predeterminados
!>     son aceptables, los usuarios pueden pasar NPARAMS = 0, lo que evita que
!>     el código fuente acceda al argumento PARAMS.
!>

Parámetros

FACT 
!>          FACT es CHARACTER*1
!>     Especifica si la forma factorizada de la matriz A se
!>     proporciona en la entrada, y si no, si la matriz A debe ser
!>     equilibrada antes de ser factorizada.
!>       = 'F':  En la entrada, AF e IPIV contienen la forma factorizada de A.
!>               Si EQUED no es 'N', la matriz A ha sido
!>               equilibrada con factores de escala dados por S.
!>               A, AF, e IPIV no se modifican.
!>       = 'N':  La matriz A se copiará a AF y se factorizará.
!>       = 'E':  La matriz A se equilibrará si es necesario, luego
!>               se copiará a AF y se factorizará.
!>

UPLO

!>          UPLO es CHARACTER*1
!>       = 'U':  El triángulo superior de A se almacena;
!>       = 'L':  El triángulo inferior de A se almacena.
!>

N

!>          N es INTEGER
!>     El número de ecuaciones lineales, es decir, el orden de
!>     la matriz A.  N >= 0.
!>

NRHS

!>          NRHS es INTEGER
!>     El número de lados derechos, es decir, el número de columnas
!>     de las matrices B y X.  NRHS >= 0.
!>

A

!>          A es un array COMPLEX*16, dimensión (LDA,N)
!>     La matriz simétrica A.  Si UPLO = 'U', la parte superior
!>     triangular N por N de A contiene la parte superior triangular
!>     de la matriz A, y la parte estrictamente inferior triangular
!>     de A no se referencia.  Si UPLO = 'L', la parte inferior
!>     triangular N por N de A contiene la parte inferior triangular
!>     de la matriz A, y la parte estrictamente superior triangular
!>     de A no se referencia.
!>
!>     En la salida, si FACT = 'E' y EQUED = 'Y', A se sobrescribe con
!>     diag(S)*A*diag(S).
!>

LDA

!>          LDA es INTEGER
!>     La dimensión principal del array A.  LDA >= max(1,N).
!>

AF

!>          AF es un array COMPLEX*16, dimensión (LDAF,N)
!>     Si FACT = 'F', entonces AF es un argumento de entrada y en la entrada
!>     contiene la matriz diagonal de bloques D y los multiplicadores
!>     utilizados para obtener el factor U o L de la factorización A =
!>     U*D*U**T o A = L*D*L**T calculada por ZSYTRF.
!>
!>     Si FACT = 'N', entonces AF es un argumento de salida y en la salida
!>     devuelve la matriz diagonal de bloques D y los multiplicadores
!>     utilizados para obtener el factor U o L de la factorización A =
!>     U*D*U**T o A = L*D*L**T.
!>

LDAF

!>          LDAF es INTEGER
!>     La dimensión principal del array AF.  LDAF >= max(1,N).
!>

IPIV

!>          IPIV es un array INTEGER, dimensión (N)
!>     Si FACT = 'F', entonces IPIV es un argumento de entrada y en la entrada
!>     contiene detalles de los intercambios y la estructura de bloques

ARGUMENTS




FACT




           CHARACTER*1



Specifies the form of the problem to be solved.


= 'E': Computes the factorization of A and solves the system of


equations A*X = B, A'*X = B, or A''*X = B.


= 'F': Computes the factorization of A and uses it to solve the system


of equations A*X = B, A'*X = B, or A''*X = B.


= 'N': Computes the factorization of A and solves the system of


equations A*X = B, A'*X = B, or A''*X = B.


N is the order of the matrix A and is in the range [0, N], where N is
the number of columns in the array A. If N=0, ZGESVX is not called.




TRANS




           CHARACTER*1



Specifies the form of the system of equations to be solved.


= 'N': Solve A * X = B     (No transpose)


= 'C': Solve A' * X = B    (Conjugate transpose)


= 'T': Solve A' * X = B    (Transpose)




EQUED




           CHARACTER*1



Specifies the form of equilibration that was done.


= 'N': No equilibration (always true if FACT = 'N').


= 'Y': Both row and column equilibration, i.e., A has been


replaced by diag(S) * A * diag(S).


EQUED is an input argument if FACT = 'F'; otherwise, it is an
output argument.




N




           INTEGER



The number of linear equations, i.e., the order of the
matrix A. N >= 0.




NB




           INTEGER



The blocking size for ZSYTRF.




A




           COMPLEX*16 array, dimension (LDA, N)



On entry, the array A to be factorized.


On exit, if EQUED = 'N', the factor U from the factorization
A = P*L*U is stored in the upper triangular part of A, and the factors
L (lower triangular) and P (permutation matrix) are stored in the
lower triangular part of A and the array IPIV, respectively.


If EQUED = 'Y', A is overwritten by diag(S)*A*diag(S).




LDA




           INTEGER



The leading dimension of the array A. LDA >= max(1, N).




AF




           COMPLEX*16 array, dimension (LDAF, N)



On exit, the further details of the factorization of A are
stored in the array AF.




LDAF




           INTEGER



The leading dimension of the array AF. LDAF >= max(1, N).




IPIV




           INTEGER array, dimension (N)



Details of the row and column interchanges if FACT = 'E' or
'N'.


If FACT = 'E' or 'N', then on exit, the pivot choices are recorded
in this array. If IPIV(k) > 0, then rows and columns k and IPIV(k)
were interchanged. If IPIV(k) = 0, then rows and columns k and k were
interchanged.


If IPIV(k) < 0, then rows and columns k and -IPIV(k) were interchanged
and D(k,k) is a 1-by-1 diagonal block. If UPLO = 'U' and
IPIV(k) = IPIV(k-1) < 0, then rows and columns k-1 and
-IPIV(k) were interchanged and D(k-1:k,k-1:k) is a 2-by-2
diagonal block. If UPLO = 'L' and IPIV(k) = IPIV(k+1) < 0,
then rows and columns k+1 and -IPIV(k) were interchanged
and D(k:k+1,k:k+1) is a 2-by-2 diagonal block.


If FACT = 'N', then IPIV is an output argument and on exit
contains details of the interchanges and the block
structure of D, as determined by ZSYTRF.




Q




           COMPLEX*16 array, dimension (LDQ, N)



If TRANS = 'C', the orthogonal matrix Q is needed to
compute the solution.


Q is a COMPLEX*16 array, dimension (LDQ, N).




LDQ




           INTEGER



The leading dimension of the array Q. LDQ >= max(1, N).




B




           COMPLEX*16 array, dimension (LDB, NRHS)



On entry, the N-by-NRHS right hand side matrix B.


On exit,


if EQUED = 'N', B is not modified;


if EQUED = 'Y', B is overwritten by diag(S)*B;




LDB




           INTEGER



The leading dimension of the array B. LDB >= max(1, N).




X




           COMPLEX*16 array, dimension (LDX, NRHS)



If INFO = 0, the N-by-NRHS solution matrix X to the original
system of equations. Note that A and B are modified on exit if
EQUED .ne. 'N', and the solution to the equilibrated system is
inv(diag(S))*X.




LDX




           INTEGER



The leading dimension of the array X. LDX >= max(1, N).




RCOND




           DOUBLE PRECISION



Reciprocal scaled condition number. This is an estimate of the
reciprocal Skeel condition number of the matrix A after
equilibration (if done). If this is less than the machine
precision (in particular, if it is zero), the matrix is singular
to working precision. Note that the error may still be small even
if this number is very small and the matrix appears ill-
conditioned.




RPGRW




           DOUBLE PRECISION



Reciprocal pivot growth. On exit, this contains the reciprocal
pivot growth factor norm(A)/norm(U). The
norm is used. If this is much less than 1, then the stability of
the LU factorization of the (equilibrated) matrix A could be poor.
This also means that the solution X, estimated condition numbers,
and error bounds could be unreliable. If factorization fails with
0<INFO<=N, then this contains the reciprocal pivot growth factor
for the leading INFO columns of A.




BERR




           DOUBLE PRECISION array, dimension (NRHS)



Componentwise relative backward error. This is the
componentwise relative backward error of each solution vector X(j)
(i.e., the smallest relative change in any element of A or B that
makes X(j) an exact solution).




N_ERR_BNDS




           INTEGER



Number of error bounds to return for each right hand side
and each type (normwise or componentwise). See ERR_BNDS_NORM and
ERR_BNDS_COMP below.




ERR_BNDS_NORM




           DOUBLE PRECISION array, dimension (NRHS, N_ERR_BNDS)



For each right-hand side, this array contains information about
various error bounds and condition numbers corresponding to the
normwise relative error, which is defined as follows:


Normwise relative error in the ith solution vector:


max_j (abs(XTRUE(j,i) - X(j,i)))


------------------------------


max_j abs(X(j,i))


The array is indexed by the type of error information as described
below. There currently are up to three pieces of information
returned.


The first index in ERR_BNDS_NORM(i,:) corresponds to the ith
right-hand side.


The second index in ERR_BNDS_NORM(:,err) contains the following
three fields:


err = 1 boolean. Trust the answer if the
reciprocal condition number is less than the threshold
sqrt(n) * dlamch('Epsilon').


err = 2 error bound: The estimated forward error,
almost certainly within a factor of 10 of the true error
so long as the next entry is greater than the threshold
sqrt(n) * dlamch('Epsilon'). This error bound should only
be trusted if the previous boolean is true.


err = 3 Reciprocal condition number: Estimated normwise
reciprocal condition number. Compared with the threshold
sqrt(n) * dlamch('Epsilon') to determine if the error
estimate is . These reciprocal condition
numbers are 1 / (norm(Z^{-1},inf) * norm(Z,inf)) for some
appropriately scaled matrix Z.


Let Z = S*A, where S scales each row by a power of the
radix so all absolute row sums of Z are approximately 1.


See Lapack Working Note 165 for further details and extra
cautions.

           DOUBLE PRECISION array, dimension (NRHS, N_ERR_BNDS)



For each right-hand side, this array contains information about

abs(X(j,i))

the first (:,N_ERR_BNDS) entries are returned.


The first index in ERR_BNDS_COMP(i,:) corresponds to the ith
right-hand side.


The second index in ERR_BNDS_COMP(:,err) contains the following
three fields:


err = 1 boolean. Trust the answer if the
reciprocal condition number is less than the threshold

PARAMS

Default: 1.0D+0

                    Function/Subroutine Documentation
                

                

                    ZSYSVXX (SUBROUTINE)
                

                

                    ZSYSVXX computes the solution to a complex system of linear
                    equations
                

                
    A X = B
                

                
where A is an N-by-N complex symmetric matrix and X and B are
                    N-by-NRHS matrices. Error bounds are computed for the
                    solutions computed by this routine.

                
A small normwise or componentwise relative error is
                    returned if the solution is computed with high accuracy.
                    See More Details.

                
Usage

                
  CALL ZSYSVXX( UPLO, N, NRHS, A, LDA, B, LDB, RCOND, SRANK, BERR,
                N_ERR_BNDS, ERR_BNDS_NORM, ERR_BNDS_COMP, RPOUT, QP, D, Q, LDQ,
                WORK, RWORK, INFO )
                

                
Parameters

                

                    

                        UPLO
                        CHARACTER*1
                    

                    

                        
Specifies whether the matrix A is upper or lower
                            triangular.

                        
 = 'U': Upper triangle of A is stored;

                        
 = 'L': Lower triangle of A is stored.

                    

                    

                        N
                        INTEGER
                    

                    

                        
The number of linear equations, i.e., the dimension
                            of the matrix A. N >= 0.

                    

                    

                        NRHS
                        INTEGER
                    

                    

                        
The number of right hand sides, i.e., the number of
                            columns of the matrix B. NRHS >= 0.

                    

                    

                        A
                        COMPLEX*16 array, dimension (LDA,N)
                    

                    

                        
On entry, the symmetric matrix A. The N-by-N
                            unreduced part of A is the upper or lower
                            triangle of A.

                        
On exit, if INFO = 0 or INFO = N+J, the upper or
                            lower triangle of A is overwritten by details of
                            its factorization.

                    

                    

                        LDA
                        INTEGER
                    

                    

                        
The leading dimension of the array A. LDA
                            >= max(1,N).

                    

                    

                        B
                        COMPLEX*16 array, dimension (LDB,NRHS)
                    

                    

                        
On entry, the N-by-NRHS matrix of right hand sides.

                        
On exit, if INFO = 0, B is overwritten by the
                            solution matrix X.

                    

                    

                        LDB
                        INTEGER
                    

                    

                        
The leading dimension of the array B. LDB
                            >= max(1,N).

                    

                    

                        RCOND
                        DOUBLE PRECISION
                    

                    

                        
On exit, an estimate of the reciprocal of the
                            condition number of A. For symmetric
                            (or triangular) matrices, RCOND is
                            calculated using the formulae

                        
 RCOND = 1 / ( cond_1(A) * norm_1(A) * C_i(A) )

                        
 If RCOND is less than machine epsilon, A is
                            singular or near singular.

                    

                    

                        SRANK
                        INTEGER
                    

                    

                        
On exit, the rank of matrix A. If SRANK < N,
                            then A is rank deficient.

                    

                    

                        BERR
                        DOUBLE PRECISION array, dimension (NRHS)
                    

                    

                        
On exit, BERR(J) contains an estimate of the
                            relative error in the Jth solution in the
                            form norm(X(J) - X_true(J)) / norm(X_true(J)).

                    

                    

                        N_ERR_BNDS
                        INTEGER
                    

                    

                        
On entry, the number of error bounds to be computed.
                            N_ERR_BNDS should be 1 or 2.

                        
 = 1: Compute normwise relative error bounds.

                        
 = 2: Compute normwise and componentwise
                            relative error bounds.
