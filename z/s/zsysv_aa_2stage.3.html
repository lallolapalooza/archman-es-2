Documentación de la Función/Subrutina

subrutina zsysv_aa_2stage (character uplo, integer n, integer nrhs, complex*16, dimension( lda, * ) a, integer lda, complex*16, dimension( * ) tb, integer ltb, integer, dimension( * ) ipiv, integer, dimension( * ) ipiv2, complex*16, dimension( ldb, * ) b, integer ldb, complex*16, dimension( * ) work, integer lwork, integer info)

ZSYSV_AA_2STAGE calcula la solución a un sistema complejo de ecuaciones lineales A * X = B para matrices SY

Propósito:

!>
!> ZSYSV_AA_2STAGE calcula la solución a un sistema complejo de
!> ecuaciones lineales
!>    A * X = B,
!> donde A es una matriz simétrica N-por-N y X y B son matrices N-por-NRHS.
!>
!> Se utiliza el algoritmo de 2 etapas de Aasen para factorizar A como
!>    A = U**T * T * U,  si UPLO = 'U', o
!>    A = L * T * L**T,  si UPLO = 'L',
!> donde U (o L) es un producto de permutación y matrices triangulares unitarias
!> superiores (inferiores), y T es simétrica y de banda. La matriz T se
!> factoriza LU con pivoteo parcial. La forma factorizada de A
!> se utiliza luego para resolver el sistema de ecuaciones A * X = B.
!>
!> Esta es la versión en bloques del algoritmo, que llama a BLAS de Nivel 3.
!>

Parámetros

UPLO 
!>          UPLO es CHARACTER*1
!>          = 'U':  El triángulo superior de A está almacenado;
!>          = 'L':  El triángulo inferior de A está almacenado.
!>

N

!>          N es INTEGER
!>          El orden de la matriz A.  N >= 0.
!>

NRHS

!>          NRHS es INTEGER
!>          El número de lados derechos, es decir, el número de columnas
!>          de la matriz B.  NRHS >= 0.
!>

A

!>          A es array COMPLEX*16, dimensión (LDA,N)
!>          En la entrada, la matriz simétrica A.  Si UPLO = 'U', la parte
!>          superior triangular de N-por-N líder de A contiene la parte
!>          superior triangular de la matriz A, y la parte estrictamente
!>          inferior triangular de A no se referencia. Si UPLO = 'L', la parte
!>          inferior triangular de N-por-N líder de A contiene la parte
!>          inferior triangular de la matriz A, y la parte estrictamente
!>          superior triangular de A no se referencia.
!>
!>          En la salida, L se almacena debajo (o encima) de los bloques
!>          subdiagonales, cuando UPLO  es 'L' (o 'U').
!>

LDA

!>          LDA es INTEGER
!>          La dimensión líder del array A.  LDA >= max(1,N).
!>

TB

!>          TB es array COMPLEX*16, dimensión (LTB)
!>          En la salida, detalles de la factorización LU de la matriz de banda.
!>

LTB

!>          LTB es INTEGER
!>          El tamaño del array TB. LTB >= 4*N, utilizado internamente
!>          para seleccionar NB tal que LTB >= (3*NB+1)*N.
!>
!>          Si LTB = -1, entonces se asume una consulta de espacio de trabajo; la
!>          rutina solo calcula el tamaño óptimo de LTB,
!>          devuelve este valor como la primera entrada de TB, y
!>          XERBLA no emite ningún mensaje de error relacionado con LTB.
!>

IPIV

!>          IPIV es array INTEGER, dimensión (N)
!>          En la salida, contiene los detalles de los intercambios, es decir,
!>          la fila y columna k de A se intercambiaron con la
!>          fila y columna IPIV(k).
!>

IPIV2

!>          IPIV2 es array INTEGER, dimensión (N)
!>          En la salida, contiene los detalles de los intercambios, es decir,
!>          la fila y columna k de T se intercambiaron con la
!>          fila y columna IPIV(k).
!>

B

!>          B es array COMPLEX*16, dimensión (LDB,NRHS)
!>          En la entrada, la matriz del lado derecho B.
!>          En la salida, la matriz solución X.
!>

LDB

!>          LDB es INTEGER
!>          La dimensión líder del array B.  LDB >= max(1,N).
!>

WORK

!>          WORK es espacio de trabajo COMPLEX*16 de tamaño LWORK
!>

LWORK

!>          LWORK es INTEGER
!>          El tamaño de WORK. LWORK >= N, utilizado internamente para seleccionar NB
!>          tal que LWORK >= N*NB.
!>
!>          Si LWORK = -1, entonces se asume una consulta de espacio de trabajo; la
!>          rutina solo calcula el tamaño óptimo del array WORK,
!>          devuelve este valor como la primera entrada del array WORK, y
!>          XERBLA no emite ningún mensaje de error relacionado con LWORK.
!>

INFO

!>          INFO es INTEGER
!>          = 0:  salida exitosa
!>          < 0:  si INFO = -i, el i-ésimo argumento tuvo un valor ilegal.
!>          > 0:  si INFO = i, la factorización LU de banda falló en la i-ésima columna
!>
