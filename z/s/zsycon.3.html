ZSYCON

Propósito:

!>
!> ZSYCON estima el recíproco del número de condición (en la
!> norma 1) de una matriz simétrica compleja A utilizando la factorización
!> A = U*D*U**T o A = L*D*L**T calculada por ZSYTRF.
!>
!> Se obtiene una estimación para norm(inv(A)), y el recíproco del
!> número de condición se calcula como RCOND = 1 / (ANORM * norm(inv(A))).
!>

Parámetros

UPLO 
!>          UPLO es CHARACTER*1
!>          Especifica si los detalles de la factorización se almacenan
!>          como una matriz triangular superior o inferior.
!>          = 'U':  Triangular superior, la forma es A = U*D*U**T;
!>          = 'L':  Triangular inferior, la forma es A = L*D*L**T.
!>

N

!>          N es INTEGER
!>          El orden de la matriz A.  N >= 0.
!>

A

!>          A es un array COMPLEX*16, de dimensión (LDA,N)
!>          La matriz diagonal por bloques D y los multiplicadores utilizados para
!>          obtener el factor U o L calculado por ZSYTRF.
!>

LDA

!>          LDA es INTEGER
!>          La dimensión principal del array A.  LDA >= max(1,N).
!>

IPIV

!>          IPIV es un array INTEGER, de dimensión (N)
!>          Detalles de los intercambios y la estructura de bloques de D
!>          según lo determinado por ZSYTRF.
!>

ANORM

!>          ANORM es DOUBLE PRECISION
!>          La norma 1 de la matriz original A.
!>

RCOND

!>          RCOND es DOUBLE PRECISION
!>          El recíproco del número de condición de la matriz A,
!>          calculado como RCOND = 1/(ANORM * AINVNM), donde AINVNM es una
!>          estimación de la norma 1 de inv(A) calculada en esta rutina.
!>

WORK

!>          WORK es un array COMPLEX*16, de dimensión (2*N)
!>

INFO

!>          INFO es INTEGER
!>          = 0:  Salida exitosa
!>          < 0:  si INFO = -i, el i-ésimo argumento tenía un valor ilegal
!>
