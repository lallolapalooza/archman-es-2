Documentación de función/subrutina

subrutina zspr (carácter uplo, entero n, complejo*16 alpha, complejo*16, dimensión( * ) x, entero incx, complejo*16, dimensión( * ) ap)

ZSPR realiza la actualización simétrica de rango 1 de una matriz empaquetada simétrica compleja.

Propósito:

!>
!> ZSPR    realiza la operación simétrica de rango 1
!>
!>    A := alpha*x*x**H + A,
!>
!> donde alpha es un escalar complejo, x es un vector de n elementos y A es una
!> matriz simétrica de n por n, suministrada en forma empaquetada.
!>

Parámetros

UPLO 
!>          UPLO es CARACTER*1
!>           A la entrada, UPLO especifica si la parte triangular superior o
!>           inferior de la matriz A se suministra en el array empaquetado
!>           AP de la siguiente manera:
!>
!>              UPLO = 'U' o 'u'   La parte triangular superior de A se
!>                                  suministra en AP.
!>
!>              UPLO = 'L' o 'l'   La parte triangular inferior de A se
!>                                  suministra en AP.
!>
!>           Sin cambios a la salida.
!>

N

!>          N es ENTERO
!>           A la entrada, N especifica el orden de la matriz A.
!>           N debe ser mayor o igual que cero.
!>           Sin cambios a la salida.
!>

ALPHA

!>          ALPHA es COMPLEJO*16
!>           A la entrada, ALPHA especifica el escalar alpha.
!>           Sin cambios a la salida.
!>

X

!>          X es un array COMPLEJO*16, de dimensión al menos
!>           ( 1 + ( N - 1 )*abs( INCX ) ).
!>           Antes de la entrada, el array incrementado X debe contener el
!>           vector x de N elementos.
!>           Sin cambios a la salida.
!>

INCX

!>          INCX es ENTERO
!>           A la entrada, INCX especifica el incremento para los elementos
!>           de X. INCX no debe ser cero.
!>           Sin cambios a la salida.
!>

AP

!>          AP es un array COMPLEJO*16, de dimensión al menos
!>           ( ( N*( N + 1 ) )/2 ).
!>           Antes de la entrada, con UPLO = 'U' o 'u', el array AP debe
!>           contener la parte triangular superior de la matriz simétrica
!>           empaquetada secuencialmente, columna por columna, de modo que
!>           AP( 1 ) contenga a( 1, 1 ), AP( 2 ) y AP( 3 ) contengan
!>           a( 1, 2 ) y a( 2, 2 ) respectivamente, y así sucesivamente. A la
!>           salida, el array AP se sobrescribe con la parte triangular
!>           superior de la matriz actualizada.
!>           Antes de la entrada, con UPLO = 'L' o 'l', el array AP debe
!>           contener la parte triangular inferior de la matriz simétrica
!>           empaquetada secuencialmente, columna por columna, de modo que
!>           AP( 1 ) contenga a( 1, 1 ), AP( 2 ) y AP( 3 ) contengan
!>           a( 2, 1 ) y a( 3, 1 ) respectivamente, y así sucesivamente. A la
!>           salida, el array AP se sobrescribe con la parte triangular
!>           inferior de la matriz actualizada.
!>           Tenga en cuenta que las partes imaginarias de los elementos
!>           diagonales no necesitan ser establecidas, se asumen cero, y a
!>           la salida se establecen a cero.
!>
