Documentación de Función/Subrutina

subroutine zsytri2 (character uplo, integer n, complex*16, dimension( lda, * ) a, integer lda, integer, dimension( * ) ipiv, complex*16, dimension( * ) work, integer lwork, integer info)

ZSYTRI2

Propósito:

!>
!> ZSYTRI2 calcula la inversa de una matriz simétrica indefinida COMPLEX*16
!> A utilizando la factorización A = U*D*U**T o A = L*D*L**T calculada por
!> ZSYTRF. ZSYTRI2 establece la DIMENSIÓN PRINCIPAL del espacio de trabajo
!> antes de llamar a ZSYTRI2X que realmente calcula la inversa.
!>

Parámetros

UPLO 
!>          UPLO es CHARACTER*1
!>          Especifica si los detalles de la factorización se almacenan
!>          como una matriz triangular superior o inferior.
!>          = 'U':  Triangular superior, forma es A = U*D*U**T;
!>          = 'L':  Triangular inferior, forma es A = L*D*L**T.
!>

N

!>          N es INTEGER
!>          El orden de la matriz A.  N >= 0.
!>

A

!>          A es un array COMPLEX*16, dimensión (LDA,N)
!>          En la entrada, la matriz diagonal por bloques D y los multiplicadores
!>          utilizados para obtener el factor U o L tal como se calculó por ZSYTRF.
!>
!>          En la salida, si INFO = 0, la inversa (simétrica) de la matriz
!>          original.  Si UPLO = 'U', se forma la parte triangular superior de
!>          la inversa y no se hace referencia a la parte de A debajo de la
!>          diagonal; si UPLO = 'L', se forma la parte triangular inferior de
!>          la inversa y no se hace referencia a la parte de A encima de la
!>          diagonal.
!>

LDA

!>          LDA es INTEGER
!>          La dimensión principal del array A.  LDA >= max(1,N).
!>

IPIV

!>          IPIV es un array INTEGER, dimensión (N)
!>          Detalles de los intercambios y la estructura de bloques de D
!>          tal como fue determinada por ZSYTRF.
!>

WORK

!>          WORK es un array COMPLEX*16, dimensión (N+NB+1)*(NB+3)
!>

LWORK

!>          LWORK es INTEGER
!>          La dimensión del array WORK.
!>          WORK tiene un tamaño >= (N+NB+1)*(NB+3)
!>          Si LDWORK = -1, entonces se asume una consulta de espacio de trabajo; la rutina
!>           calcula:
!>              - el tamaño óptimo del array WORK, devuelve
!>          este valor como la primera entrada del array WORK,
!>              - y no se emite ningún mensaje de error relacionado con LDWORK por XERBLA.
!>

INFO

!>          INFO es INTEGER
!>          = 0: finalización exitosa
!>          < 0: si INFO = -i, el argumento i-ésimo tenía un valor ilegal
!>          > 0: si INFO = i, D(i,i) = 0; la matriz es singular y su
!>               inversa no pudo ser calculada.
!>
