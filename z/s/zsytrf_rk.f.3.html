Documentación de la Función/Subrutina

subroutine zsytrf_rk (character uplo, integer n, complex*16, dimension( lda, * ) a, integer lda, complex*16, dimension( * ) e, integer, dimension( * ) ipiv, complex*16, dimension( * ) work, integer lwork, integer info)

ZSYTRF_RK calcula la factorización de una matriz simétrica indefinida compleja utilizando el método de pivoteo diagonal de Bunch-Kaufman acotado (rook) (algoritmo bloqueado BLAS3).

Propósito:

!> ZSYTRF_RK calcula la factorización de una matriz simétrica A compleja
!> utilizando el método de pivoteo diagonal de Bunch-Kaufman acotado (rook):
!>
!>    A = P*U*D*(U**T)*(P**T) o A = P*L*D*(L**T)*(P**T),
!>
!> donde U (o L) es una matriz triangular superior (o inferior) unitaria,
!> U**T (o L**T) es la transpuesta de U (o L), P es una matriz de permutación,
!> P**T es la transpuesta de P, y D es simétrica y diagonal por bloques
!> con bloques diagonales de 1x1 y 2x2.
!>
!> Esta es la versión bloqueada del algoritmo, que llama a BLAS de Nivel 3.
!> Para más información, véase la sección Detalles Adicionales.
!>

Parámetros

UPLO 
!>          UPLO es CHARACTER*1
!>          Especifica si la parte triangular superior o inferior de la
!>          matriz simétrica A está almacenada:
!>          = 'U':  Triangular superior
!>          = 'L':  Triangular inferior
!>

N

!>          N es INTEGER
!>          El orden de la matriz A.  N >= 0.
!>

A

!>          A es un array COMPLEX*16, de dimensión (LDA,N)
!>          En la entrada, la matriz simétrica A.
!>            Si UPLO = 'U': la parte triangular superior N por N
!>            principal de A contiene la parte triangular superior de la
!>            matriz A, y la parte estrictamente triangular inferior de A
!>            no se referencia.
!>
!>            Si UPLO = 'L': la parte triangular inferior N por N
!>            principal de A contiene la parte triangular inferior de la
!>            matriz A, y la parte estrictamente triangular superior de A
!>            no se referencia.
!>
!>          En la salida, contiene:
!>            a) SÓLO los elementos diagonales de la matriz simétrica
!>               diagonal por bloques D en la diagonal de A, es decir,
!>               D(k,k) = A(k,k); (los elementos superdiagonales (o
!>               subdiagonales) de D se almacenan en la salida en el array E),
!>               y
!>            b) Si UPLO = 'U': factor U en la parte superdiagonal de A.
!>               Si UPLO = 'L': factor L en la parte subdiagonal de A.
!>

LDA

!>          LDA es INTEGER
!>          La dimensión principal del array A.  LDA >= max(1,N).
!>

E

!>          E es un array COMPLEX*16, de dimensión (N)
!>          En la salida, contiene los elementos superdiagonales (o
!>          subdiagonales) de la matriz simétrica diagonal por bloques D
!>          con bloques diagonales de 1x1 o 2x2, donde
!>          Si UPLO = 'U': E(i) = D(i-1,i), i=2:N, E(1) se establece en 0;
!>          Si UPLO = 'L': E(i) = D(i+1,i), i=1:N-1, E(N) se establece en 0.
!>
!>          NOTA: Para un bloque diagonal de 1x1 D(k), donde
!>          1 <= k <= N, el elemento E(k) se establece en 0 tanto en los
!>          casos UPLO = 'U' como UPLO = 'L'.
!>

IPIV

!>          IPIV es un array INTEGER, de dimensión (N)
!>          IPIV describe la matriz de permutación P en la factorización
!>          de la matriz A de la siguiente manera. El valor absoluto de IPIV(k)
!>          representa el índice de la fila y columna que fueron
!>          intercambiados con la k-ésima fila y columna. El valor de UPLO
!>          describe el orden en que se aplicaron los intercambios.
!>          Además, el signo de IPIV representa la estructura de bloques
!>          de la matriz simétrica diagonal por bloques D con bloques
!>          diagonales de 1x1 o 2x2 que corresponden a 1 o 2 intercambios
!>          en cada paso de factorización. Para más información, véase
!>          la sección Detalles Adicionales.
!>
!>          Si UPLO = 'U',
!>          (en orden de factorización, k decrece de N a 1):
!>            a) Una única entrada positiva IPIV(k) > 0 significa:
!>               D(k,k) es un bloque diagonal de 1x1.
!>               Si IPIV(k) != k, las filas y columnas k e IPIV(k) fueron
!>               intercambiadas en la matriz A(1:N,1:N);
!>               Si IPIV(k) = k, no ocurrió ningún intercambio.
!>
!>            b) Un par de entradas negativas consecutivas
!>               IPIV(k) < 0 e IPIV(k-1) < 0 significa:
!>               D(k-1:k,k-1:k) es un bloque diagonal de 2x2.
!>               (NOTA: las entradas negativas en IPIV solo aparecen en pares).
!>               1) Si -IPIV(k) != k, las filas y columnas
!>                  k y -IPIV(k) fueron intercambiadas
!>                  en la matriz A(1:N,1:N).
!>                  Si -IPIV(k) = k, no ocurrió ningún intercambio.
!>               2) Si -IPIV(k-1) != k-1, las filas y columnas
!>                  k-1 y -IPIV(k-1) fueron intercambiadas
!>                  en la matriz A(1:N,1:N).
!>                  Si -IPIV(k-1) = k-1, no ocurrió ningún intercambio.
!>
!>            c) En ambos casos a) y b), siempre ABS( IPIV(k) ) <= k.
!>
!>            d) NOTA: Cualquier entrada IPIV(k) es siempre NO NULA en la salida.
!>
!>          Si UPLO = 'L',
!>          (en orden de factorización, k aumenta de 1 a N):
!>            a) Una única entrada positiva IPIV(k) > 0 significa:
!>               D(k,k) es un bloque diagonal de 1x1.
!>               Si IPIV(k) != k, las filas y columnas k e IPIV(k) fueron
!>               intercambiadas en la matriz A(1:N,1:N).
!>               Si IPIV(k) = k, no ocurrió ningún intercambio.
!>
!>            b) Un par de entradas negativas consecutivas
!>               IPIV(k) < 0 e IPIV(k+1) < 0 significa:
!>               D(k:k+1,k:k+1) es un bloque diagonal de 2x2.
!>               (NOTA: las entradas negativas en IPIV solo aparecen en pares).
!>               1) Si -IPIV(k) != k, las filas y columnas
!>                  k y -IPIV(k) fueron intercambiadas
!>                  en la matriz A(1:N,1:N).
!>                  Si -IPIV(k) = k, no ocurrió ningún intercambio.
!>               2) Si -IPIV(k+1) != k+1, las filas y columnas
!>                  k-1 y -IPIV(k-1) fueron intercambiadas
!>                  en la matriz A(1:N,1:N).
!>                  Si -IPIV(k+1) = k+1, no ocurrió ningún intercambio.
!>
!>            c) En ambos casos a) y b), siempre ABS( IPIV(k) ) >= k.
!>
!>            d) NOTA: Cualquier entrada IPIV(k) es siempre NO NULA en la salida.
!>

WORK

!>          WORK es un array COMPLEX*16, de dimensión ( MAX(1,LWORK) ).
!>          En la salida, si INFO = 0, WORK(1) devuelve el LWORK óptimo.
!>

LWORK

!>          LWORK es INTEGER
!>          La longitud de WORK.  LWORK >=1.  Para un rendimiento óptimo
!>          LWORK >= N*NB, donde NB es el tamaño del bloque devuelto
!>          por ILAENV.
!>
!>          Si LWORK = -1, entonces se asume una consulta de espacio de trabajo;
!>          la rutina solo calcula el tamaño óptimo del array WORK,
!>          devuelve este valor como la primera entrada del array WORK,
!>          y XERBLA no emite ningún mensaje de error relacionado con LWORK.
!>

INFO

!>          INFO es INTEGER
!>          = 0: finalización exitosa
!>
!>          < 0: Si INFO = -k, el k-ésimo argumento tenía un valor ilegal
!>
!>          > 0: Si INFO = k, la matriz A es singular, debido a que:
!>                 Si UPLO = 'U': la columna k en la parte
!>                 triangular superior de A contiene todos ceros.
!>                 Si UPLO = 'L': la columna k en la parte
!>                 triangular inferior de A contiene todos ceros.
!>
!>               Por lo tanto, D(k,k) es exactamente cero, y los elementos
!>               superdiagonales de la columna k de U (o los elementos
!>               subdiagonales de la columna k de L) son todos ceros. La
!>               factorización se ha completado, pero la matriz diagonal
!>               por bloques D es exactamente singular, un factor de
!>               inversión no puede ser calculado.
!>

SYNOPSIS

SUBROUTINE ZSYTRF_RK(UPLO, N, A, LDA, IPVT, WORK, LWORK, INFO)
    CHARACTER(LEN=1) :: UPLO
    INTEGER :: LDA, LWORK, N
    INTEGER, DIMENSION(:), INTENT(OUT) :: IPVT
    INTEGER, INTENT(OUT) :: INFO
    COMPLEX(KIND=8), DIMENSION(:, :) :: A
    COMPLEX(KIND=8), DIMENSION(:) :: WORK

Function/Subroutine Documentation

!>
!>  Purpose
!>  =======
!>
!>  ZSYTRF_RK computes the factorization of a complex symmetric matrix
!>  A = P*U*D*U**H*Q or A = P*L*D*L**H*Q, where P and Q are permutation
!>  matrices, U is a complex upper triangular matrix, L is a complex
!>  lower triangular matrix and D is a real and block diagonal matrix
!>  with 1-by-1 and 2-by-2 diagonal blocks.
!>
!>  The factorization is computed using the rook's algorithm, and it
!>  is intended to be used in conjunction with methods for computing
!>  the determinant or inverse of a symmetric indefinite matrix.
!>
!>  For details of the algorithm, please refer to the following:
!>
!>  Demmel, J.W. and Gu, M. (2008). \emph{Rook's algorithm for matrix
!>  factorization of symmetric or Hermitian matrices}. ACM Trans.
!>  Math. Software, 34(5), Article 25.
!>
!>  The factorization also overwrites the lower or upper triangle of
!>  the original matrix A.
!>
!>  Arguments
!>  =========
!>
!>  UPLO    (CHARACTER(LEN=1)) : Specifies whether the upper or lower
!>                                 triangular part of the matrix A is
!>                                 stored:
!>                                 = 'U': Upper triangle is stored;
!>                                 = 'L': Lower triangle is stored.
!>
!>  N       (INTEGER) : The order of the matrix A. N >= 0.
!>
!>  A       (COMPLEX(KIND=8), DIMENSION(LDA,N)) : The symmetric matrix A.
!>                                                 On exit, A is overwritten
!>                                                 by details of the
!>                                                 factorization.
!>                                                 See below for further details.
!>
!>  LDA     (INTEGER) : The leading dimension of the array A. LDA >=
!>                      max(1,N).
!>
!>  IPVT    (INTEGER, DIMENSION(N)) : Pivot indices. Stores pivot information
!>                                    for the triangular factorization.
!>
!>  WORK    (COMPLEX(KIND=8), DIMENSION(LWORK)) : Workspace array.
!>
!>  LWORK   (INTEGER) : The dimension of the array WORK.
!>                      LWORK = -1 means workspace size is queried.
!>                      For a correct factorization, LWORK must be at least
!>                      max(1,N).
!>
!>  INFO    (INTEGER) : = 0: successful exit
!>                      > 0: if INFO = k, U(k,k) is zero. This corresponds
!>                           to a singularity of the matrix. The
!>                           factorization is still completed, but
!>                           divided by A(k,k). If LWORK is small
!>                           enough to cause division by zero, then
!>                           this error may not be flagged and INFO
!>                           will be zero.
!>
!>  Further Details
!>  ===============
!>
!>  The factorization is in the form
!>
!>  A = P*U*D*U**H*Q  or  A = P*L*D*L**H*Q
!>
!>  where U is a structured upper triangular matrix, L is a structured
!>  lower triangular matrix and D is diagonal or block diagonal with
!>  1-by-1 and 2-by-2 diagonal blocks.
!>
!>  The structure of U and L is determined by the pivot vectors IPVT.
!>
!>  If UPLO = 'U', then A contains on exit:
!>
!>  If k >= 1, A(1:k, k:N) stores the elements of the block U(k),
!>                               and U(k, k+1:N) if k < N.
!>  If k < N, A(k+1:N, k:N) stores the elements of the block D(k).
!>
!>  If UPLO = 'L', then A contains on exit:
!>
!>  If k >= 1, A(k:N, 1:k) stores the elements of the block L(k),
!>                               and L(k+1:N, k) if k < N.
!>  If k < N, A(k:N, k+1:N) stores the elements of the block D(k).
!>
!>  The diagonal blocks D(k) are real and either 1-by-1 or 2-by-2.
!>
!>  The diagonal elements of D are stored in the diagonal of A, and
!>  the 2-by-2 diagonal blocks are stored in the following format:
!>
!>  If UPLO = 'U':
!>     k    k+1
!>  k  [a]  [b]
!>  k+1[c]  [d]
!>
!>  where D(k) = [a] or D(k) = [ a  b ]
!>                             [ c  d ]
!>  The elements a, b, c, d are stored in A(k,k), A(k,k+1), A(k+1,k),
!>  and A(k+1,k+1) respectively.
!>
!>  If UPLO = 'L':
!>     k    k+1
!>  k  [a]  [c]
!>  k+1[b]  [d]
!>
!>  where D(k) = [a] or D(k) = [ a  b ]
!>                             [ b  d ]
!>  The elements a, b, c, d are stored in A(k,k), A(k+1,k), A(k,k+1),
!>  and A(k+1,k+1) respectively.
!>
!>  NOTE: A division by zero will occur if it is used to solve a system
!>        of equations.
!>
!>  NOTE: INFO only stores the first occurrence of
!>        a singularity, any subsequent occurrence of singularity
!>        is not stored in INFO even though the factorization
!>        always completes.
!>
