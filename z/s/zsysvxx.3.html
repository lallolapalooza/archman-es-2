ZSYSVXX calcula la solución al sistema de ecuaciones lineales A * X = B para matrices SY

Propósito:

!>
!>    ZSYSVXX utiliza la factorización de pivoteo diagonal para calcular la
!>    solución a un sistema de ecuaciones lineales de complex*16 A * X = B, donde
!>    A es una matriz simétrica de N por N y X y B son matrices de N por NRHS.
!>
!>    Si se solicita, se devuelven límites de error tanto normados como de
!>    componente máxima. ZSYSVXX devolverá una solución con un error garantizado
!>    pequeño (O(eps) donde eps es la precisión de la máquina de trabajo) a
!>    menos que la matriz esté muy mal condicionada, en cuyo caso se devuelve
!>    una advertencia. También se calculan y devuelven los números de condición
!>    relevantes.
!>
!>    ZSYSVXX acepta factorizaciones y factores de equilibrado proporcionados por
!>    el usuario; consulte las definiciones de las opciones FACT y EQUED.
!>    Resolver con refinamiento y usar una factorización de una llamada anterior
!>    a ZSYSVXX también producirá una solución con errores O(eps) o advertencias,
!>    pero no podemos hacer esa afirmación para factorizaciones y factores de
!>    equilibrado proporcionados por el usuario en general si difieren de lo que
!>    ZSYSVXX produciría por sí mismo.
!>

Descripción:

!>
!>    Se realizan los siguientes pasos:
!>
!>    1. Si FACT = 'E', se calculan factores de escala de doble precisión para
!>    equilibrar el sistema:
!>
!>      diag(S)*A*diag(S)     *inv(diag(S))*X = diag(S)*B
!>
!>    Si el sistema se equilibrará o no depende de la escala de la matriz A,
!>    pero si se utiliza el equilibrado, A se sobrescribe con diag(S)*A*diag(S)
!>    y B con diag(S)*B.
!>
!>    2. Si FACT = 'N' o 'E', se utiliza la descomposición LU para factorizar
!>    la matriz A (después del equilibrado si FACT = 'E') como
!>
!>       A = U * D * U**T,  si UPLO = 'U', o
!>       A = L * D * L**T,  si UPLO = 'L',
!>
!>    donde U (o L) es un producto de permutación y matrices triangulares unitarias
!>    superiores (inferiores), y D es simétrica y de bloques diagonales con
!>    bloques diagonales de 1x1 y 2x2.
!>
!>    3. Si algún D(i,i)=0, por lo que D es exactamente singular, la
!>    rutina sale con INFO = i. De lo contrario, la forma factorizada de A
!>    se utiliza para estimar el número de condición de la matriz A (ver
!>    argumento RCOND). Si la inversa del número de condición es menor que la
!>    precisión de la máquina, la rutina continúa resolviendo para X y
!>    calculando límites de error como se describe a continuación.
!>
!>    4. El sistema de ecuaciones se resuelve para X utilizando la forma
!>    factorizada de A.
!>
!>    5. Por defecto (a menos que PARAMS(LA_LINRX_ITREF_I) esté configurado
!>    a cero), la rutina utilizará refinamiento iterativo para intentar obtener
!>    un error pequeño y límites de error. El refinamiento calcula el residuo
!>    con al menos el doble de la precisión de trabajo.
!>
!>    6. Si se utilizó el equilibrado, la matriz X se premultiplica por
!>    diag(R) para que resuelva el sistema original antes del
!>    equilibrado.
!> 
!>     Algunos parámetros opcionales se agrupan en el array PARAMS. Estas
!>     configuraciones determinan cómo se realiza el refinamiento, pero a menudo
!>     los valores predeterminados son aceptables. Si los valores predeterminados
!>     son aceptables, los usuarios pueden pasar NPARAMS = 0, lo que evita que
!>     el código fuente acceda al argumento PARAMS.
!>

Parámetros

FACT 
!>          FACT es CHARACTER*1
!>     Especifica si la forma factorizada de la matriz A se proporciona o no
!>     en la entrada, y si no, si la matriz A debe equilibrarse antes de
!>     factorizarse.
!>       = 'F':  En la entrada, AF y IPIV contienen la forma factorizada de A.
!>               Si EQUED no es 'N', la matriz A se ha equilibrado
!>               con los factores de escala dados por S.
!>               A, AF e IPIV no se modifican.
!>       = 'N':  La matriz A se copiará en AF y se factorizará.
!>       = 'E':  La matriz A se equilibrará si es necesario, luego
!>               se copiará en AF y se factorizará.
!>

UPLO

!>          UPLO es CHARACTER*1
!>       = 'U':  El triángulo superior de A está almacenado;
!>       = 'L':  El triángulo inferior de A está almacenado.
!>

N

!>          N es INTEGER
!>     El número de ecuaciones lineales, es decir, el orden de la
!>     matriz A.  N >= 0.
!>

NRHS

!>          NRHS es INTEGER
!>     El número de lados derechos, es decir, el número de columnas
!>     de las matrices B y X.  NRHS >= 0.
!>

A

!>          A es un array COMPLEX*16, dimensión (LDA,N)
!>     La matriz simétrica A.  Si UPLO = 'U', la parte triangular superior
!>     principal de N por N de A contiene la parte triangular superior
!>     de la matriz A, y la parte estrictamente triangular inferior
!>     de A no se referencia. Si UPLO = 'L', la parte triangular inferior
!>     principal de N por N de A contiene la parte triangular inferior
!>     de la matriz A, y la parte estrictamente triangular superior
!>     de A no se referencia.
!>
!>     En la salida, si FACT = 'E' y EQUED = 'Y', A se sobrescribe con
!>     diag(S)*A*diag(S).
!>

LDA

!>          LDA es INTEGER
!>     La dimensión principal del array A.  LDA >= max(1,N).
!>

AF

!>          AF es un array COMPLEX*16, dimensión (LDAF,N)
!>     Si FACT = 'F', entonces AF es un argumento de entrada y en la entrada
!>     contiene la matriz diagonal de bloques D y los multiplicadores
!>     utilizados para obtener el factor U o L de la factorización A =
!>     U*D*U**T o A = L*D*L**T como lo calcula ZSYTRF.
!>
!>     Si FACT = 'N', entonces AF es un argumento de salida y en la salida
!>     devuelve la matriz diagonal de bloques D y los multiplicadores
!>     utilizados para obtener el factor U o L de la factorización A =
!>     U*D*U**T o A = L*D*L**T.
!>

LDAF

!>          LDAF es INTEGER
!>     La dimensión principal del array AF.  LDAF >= max(1,N).
!>

IPIV

!>          IPIV es un array INTEGER, dimensión (N)
!>     Si FACT = 'F', entonces IPIV es un argumento de entrada y en la entrada
!>     contiene detalles de los intercambios y la estructura de bloques

NAME


zsysvxx - Solves a complex general system of linear equations A*X = B, AH*X = B, or A*X = B using the L/U factorization with complete pivoting, and provides error bounds.






SYNOPSIS


SUBROUTINE ZSYSVXX(
    UPLO, TRANS, N, NRHS, A, LDA, E, LDE, IPIV, EQPIV, WORK, LWORK, RWORK,
    LRWORK, B, LDB, INFO
)
CHARACTER * 1 A, LDA, LDE, N, NRHS, UPLO
INTEGER IPIV, LDB, LWORK, LRWORK
INTEGER EQPIV(*)
DOUBLE PRECISION COMPLEX B, RWORK
DOUBLE COMPLEX A, E, WORK

SUBROUTINE ZSYSVXX( UPLO, TRANS, N, NRHS, A, LDA, E, LDE, IPIV, EQPIV,

CHARACTER * 1 UPLO, TRANS
INTEGER N, NRHS, LDA, LDE, LDB, LWORK, LRWORK, INFO
INTEGER IPIV( * )
COMPLEX*16 A( LDA, * ), E( LDE, * ), WORK( * ), B( LDB, * )
DOUBLE PRECISION RWORK( * )







Function/Subroutine Documentation




UPLO


CHARACTER*1.

On entry, UPLO specifies whether the matrix A is upper or lower
    triangular.
    
UPLO = ‘U’ => A is upper triangular.
    
UPLO = ‘L’ => A is lower triangular.




TRANS


CHARACTER*1.

On entry, TRANS specifies the form of the system of equations:
    
TRANS = ‘N’ => A*X = B (No transpose).
    
TRANS = ‘C’ => AH*X = B (Conjugate transpose).
    




N


INTEGER.

The order of the matrix A.  N >= 0.
    




NRHS


INTEGER.

The number of right hand sides, i.e., the number of columns of the
    matrices B and X. NRHS >= 0.




A


COMPLEX*16 array, dimension (LDA,N).

On entry, the symmetric or Hermitian matrix A.
    
If UPLO = ‘U’, then A is upper triangular.
    
If UPLO = ‘L’, then A is lower triangular.
    
On exit, if INFO = 0, A is factorized as S*P*L*U, where U is upper
    triangular, and P is a permutation matrix. The L factor is not stored.
    
If UPLO = ‘U’, the elements of the factor U are stored in the upper
    triangle of A, and in the lower triangle of A, the elements of the
    corresponding L factor are stored.
    
If UPLO = ‘L’, then the elements of the factor L are stored in the lower
    triangle of A, and in the upper triangle of A, the elements of the
    corresponding U factor are stored.
    
See below for the description of the array E.




LDA


INTEGER.

The leading dimension of the array A. LDA >= max(1,N).




E


COMPLEX*16 array, dimension (LDE,N).

On entry, the diagonal elements of the unit triangular matrix L or
    U.
    
On exit, on exit, if INFO = 0, the diagonal elements of the factor U are
    stored in the array E.
    
The diagonal elements of the L factor are not stored.




LDE


INTEGER.

The leading dimension of the array E. LDE >= max(1,N).




IPIV


INTEGER array, dimension (MIN(N+1, M)) where M=N if TRANS='N' and M=P for
    some P if TRANS='C' or 'T'.

Details of the interchanges of the rows of A. If UPLO = ‘U’, then the
    value K of IPIV(I) = K means that the first K elements of the row I of
    U are in the row K of U.
    
If UPLO = ‘L’, then the value K of IPIV(I) = K means that the first K
    elements of the column I of L are in the column K of L.
    
The pivots used are in the array EQPIV.




EQPIV


INTEGER array, dimension (N).

Contains the pivot values used in the factorization. EQPIV(I) = K means
    that row/column I was interchanged with row/column K.




WORK


COMPLEX*16 array, dimension (LWORK).

On exit, WORK(1) contains the optimal value of LWORK.
    
On exit, WORK(2) contains the minimum value of LWORK required for this
    routine.




LWORK


INTEGER.

The dimension of the array WORK. LWORK >= max(1,2*N).
    
For optimal performance, LWORK is specified by the user.
    
If LWORK = -1 or LWORK = -2, then the optimal dimension of WORK is
    returned in WORK(1).




RWORK


DOUBLE PRECISION array, dimension (LRWORK).

On exit, RWORK(1) contains the optimal value of LRWORK.
    
On exit, RWORK(2) contains the minimum value of LRWORK required for this
    routine.




LRWORK


INTEGER.

The dimension of the array RWORK. LRWORK >= max(1,N).
    
For optimal performance, LRWORK is specified by the user.
    
If LRWORK = -1 or LRWORK = -2, then the optimal dimension of RWORK is
    returned in RWORK(1).




B


COMPLEX*16 array, dimension (LDB,NRHS).

On entry, the right hand side matrix B.
    
On exit, if INFO = 0, B has been overwritten by the solution
    matrix X.




LDB


INTEGER.

The leading dimension of the array B. LDB >= max(1,N).




INFO


INTEGER.


    
= 0: Successful exit. The solution X has been computed, and error
    bounds have been computed.
    
< 0: If INFO = -i, the i-th argument had an illegal value. A message
    is output to stderr. A solution is not computed.
    
> 0: If INFO = i, and i <= N, then the leading minor of order i of A
    is zero. Triangle is not completely decomposed. The solutions could not
    be computed.
    
> N: If INFO = N + J, then the Jth right hand side is not guaranteed. The
    solutions corresponding to other right hand sides K with K > J may not be
    guaranteed as well, but only the first such right hand side is reported.
    If a small componentwise error is not requested (PARAMS(3) = 0.0) then
    the Jth right hand side is the first with a normwise error bound that is
    not guaranteed (the smallest J such that ERR_BNDS_NORM(J,1) = 0.0). By
    default (PARAMS(3) = 1.0) the Jth right hand side is the first with
    either a normwise or componentwise error bound that is not guaranteed
    (the smallest J such that either ERR_BNDS_NORM(J,1) = 0.0 or
    ERR_BNDS_COMP(J,1) = 0.0). See the definition of
    ERR_BNDS_NORM(:,1) and ERR_BNDS_COMP(:,1). To get information
    about all of the right hand sides check ERR_BNDS_NORM or
    ERR_BNDS_COMP.






RCOND is computed as 0.0.


Error_Bounds




The function computes two error bounds: a normwise error bound and a
    componentwise error bound.
    
Let R = B - A*X be the residual matrix.
    
The normwise error bound is an estimate of the relative error in the
    solution X in the 1-norm:
    
 ||X - X_true||_1 / ||X_true||_1 <= RCOND * norm(A,1) * norm(A_inv,1)
    
The componentwise error bound is an estimate of the largest relative
    error in any component of X:
    
 max_i |X(i) - X_true(i)| / |X_true(i)| <= RCOND * norm(A,1) * norm(A_inv,1)
    
 RCOND is the reciprocal of the condition number of A.
    
 If RCOND is close to zero, the matrix A is ill-conditioned, and the
    solution X may be inaccurate.
    
 If error bounds could not be computed, RCOND = 0 is returned.


If INFO = N + J, then the Jth right-hand side is not guaranteed. The
    solutions corresponding to other right-hand sides K with K > J may not
    be guaranteed as well, but only the first such right-hand side is
    reported. If a small componentwise error is not requested (PARAMS(3) =
    0.0) then the Jth right-hand side is the first with a normwise error
    bound that is not guaranteed (the smallest J such that
    ERR_BNDS_NORM(J,1) = 0.0). By default (PARAMS(3) = 1.0) the Jth
    right-hand side is the first with either a normwise or componentwise
    error bound that is not guaranteed (the smallest J such that either
    ERR_BNDS_NORM(J,1) = 0.0 or ERR_BNDS_COMP(J,1) = 0.0). See the
    definition of ERR_BNDS_NORM(:,1) and ERR_BNDS_COMP(:,1). To get
    information about all of the right-hand sides check ERR_BNDS_NORM or
    ERR_BNDS_COMP.
