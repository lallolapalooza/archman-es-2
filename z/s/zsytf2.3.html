subroutine zsytf2 (character uplo, integer n, complex*16, dimension( lda, * ) a, integer lda, integer, dimension( * ) ipiv, integer info)

ZSYTF2 calcula la factorización de una matriz simétrica compleja indefinida, utilizando el método de pivoteo diagonal de Bunch-Kaufman (algoritmo sin bloques).

Propósito:

!>
!> ZSYTF2 calcula la factorización de una matriz simétrica compleja A
!> utilizando el método de pivoteo diagonal de Bunch-Kaufman:
!>
!>    A = U*D*U**T  o  A = L*D*L**T
!>
!> donde U (o L) es un producto de matrices de permutación y triangulares
!> unitarias superiores (inferiores), U**T es la transpuesta de U, y D es
!> simétrica y diagonal de bloques con bloques diagonales de 1x1 y 2x2.
!>
!> Esta es la versión sin bloques del algoritmo, que llama a BLAS de Nivel 2.
!>

Parámetros

UPLO 
!>          UPLO es CHARACTER*1
!>          Especifica si la parte triangular superior o inferior de la
!>          matriz simétrica A está almacenada:
!>          = 'U':  Triangular superior
!>          = 'L':  Triangular inferior
!>

N

!>          N es INTEGER
!>          El orden de la matriz A.  N >= 0.
!>

A

!>          A es un array COMPLEX*16, dimensión (LDA,N)
!>          En la entrada, la matriz simétrica A. Si UPLO = 'U', la parte
!>          superior triangular de n por n de A contiene la parte triangular
!>          superior de la matriz A, y la parte estrictamente triangular
!>          inferior de A no se referencia. Si UPLO = 'L', la parte
!>          inferior triangular de n por n de A contiene la parte triangular
!>          inferior de la matriz A, y la parte estrictamente triangular
!>          superior de A no se referencia.
!>
!>          En la salida, la matriz diagonal de bloques D y los multiplicadores
!>          utilizados para obtener el factor U o L (ver más abajo para más
!>          detalles).
!>

LDA

!>          LDA es INTEGER
!>          La dimensión principal del array A.  LDA >= max(1,N).
!>

IPIV

!>          IPIV es un array INTEGER, dimensión (N)
!>          Detalles de los intercambios y la estructura de bloques de D.
!>
!>          Si UPLO = 'U':
!>             Si IPIV(k) > 0, entonces las filas y columnas k e IPIV(k) fueron
!>             intercambiadas y D(k,k) es un bloque diagonal de 1x1.
!>
!>             Si IPIV(k) = IPIV(k-1) < 0, entonces las filas y columnas
!>             k-1 e -IPIV(k) fueron intercambiadas y D(k-1:k,k-1:k)
!>             es un bloque diagonal de 2x2.
!>
!>          Si UPLO = 'L':
!>             Si IPIV(k) > 0, entonces las filas y columnas k e IPIV(k) fueron
!>             intercambiadas y D(k,k) es un bloque diagonal de 1x1.
!>
!>             Si IPIV(k) = IPIV(k+1) < 0, entonces las filas y columnas
!>             k+1 e -IPIV(k) fueron intercambiadas y D(k:k+1,k:k+1)
!>             es un bloque diagonal de 2x2.
!>

INFO

!>          INFO es INTEGER
!>          = 0: salida exitosa
!>          < 0: si INFO = -k, el argumento k tuvo un valor ilegal
!>          > 0: si INFO = k, D(k,k) es exactamente cero. La factorización
!>               se ha completado, pero la matriz diagonal de bloques D
!>               es exactamente singular, y ocurrirá una división por cero si
!>               se utiliza para resolver un sistema de ecuaciones.
!>

Detalles adicionales:

!>
!>  Si UPLO = 'U', entonces A = U*D*U**T, donde
!>     U = P(n)*U(n)* ... *P(k)U(k)* ...,
!>  es decir, U es un producto de términos P(k)*U(k), donde k disminuye de n a
!>  1 en pasos de 1 o 2, y D es una matriz diagonal de bloques con bloques
!>  diagonales de 1x1 y 2x2 D(k). P(k) es una matriz de permutación como
!>  se define por IPIV(k), y U(k) es una matriz triangular superior unitaria,
!>  tal que si el bloque diagonal D(k) es de orden s (s = 1 o 2), entonces
!>
!>             (   I    v    0   )   k-s
!>     U(k) =  (   0    I    0   )   s
!>             (   0    0    I   )   n-k
!>                k-s   s   n-k
!>
!>  Si s = 1, D(k) sobrescribe A(k,k), y v sobrescribe A(1:k-1,k).
!>  Si s = 2, el triángulo superior de D(k) sobrescribe A(k-1,k-1), A(k-1,k),
!>  y A(k,k), y v sobrescribe A(1:k-2,k-1:k).
!>
!>  Si UPLO = 'L', entonces A = L*D*L**T, donde
!>     L = P(1)*L(1)* ... *P(k)*L(k)* ...,
!>  es decir, L es un producto de términos P(k)*L(k), donde k aumenta de 1 a
!>  n en pasos de 1 o 2, y D es una matriz diagonal de bloques con bloques
!>  diagonales de 1x1 y 2x2 D(k). P(k) es una matriz de permutación como
!>  se define por IPIV(k), y L(k) es una matriz triangular inferior unitaria,
!>  tal que si el bloque diagonal D(k) es de orden s (s = 1 o 2), entonces
!>
!>             (   I    0     0   )  k-1
!>     L(k) =  (   0    I     0   )  s
!>             (   0    v     I   )  n-k-s+1
!>                k-1   s  n-k-s+1
!>
!>  Si s = 1, D(k) sobrescribe A(k,k), y v sobrescribe A(k+1:n,k).
!>  Si s = 2, el triángulo inferior de D(k) sobrescribe A(k,k), A(k+1,k),
!>  y A(k+1,k+1), y v sobrescribe A(k+2:n,k:k+1).
!>
