ZSNES 2.0.12(1) Manual de Comandos Generales ZSNES 2.0.12(1)

NOMBRE

ZSNES - Emulador de consola Super Nintendo

SINOPSIS

ZSNES [-?] [-1 #] [-2 #] [-dd] [-dh] [-f #] [-g #] [-h | -l] [-j] [-js #] [-k #] [-m] [-mc] [-md] [-ml #] [-n #] [-o] [-p #] [-r #] [-s] [-sa] [-t | -u] [-v #] [-y] [-z] [-zm #] [-zs #] [nombre_rom]

DESCRIPCIÓN

ZSNES es un emulador para la consola de videojuegos Super Nintendo. Está escrito en una combinación de ensamblador x86, C, C++ y PSR. Actualmente está disponible en Windows, DOS, Linux x86, Mac OS X x86 y BSD x86.

Visita http://www.zsnes.com/ para las últimas actualizaciones.

OPCIONES

Nota: Muchas de estas opciones también se pueden configurar en la interfaz gráfica de usuario (GUI).

-?
Mostrar ayuda de la línea de comandos
-1 # / -2 #
Establecer controles para Jugador 1/2 
0 = Ninguno       1 = Teclado/Gamepad
-dd
Deshabilitar emulación de DSP de sonido
-dh
Deshabilitar trucos del juego
-f #
Habilitar omisión de fotogramas (frame skipping), donde # es un valor numérico de 0-9
-g #
Especificar el valor de corrección gamma, donde # es un valor numérico de 0-15
-h
Forzar HiROM. No se puede usar con -l
-j
Deshabilitar ratón (Desactiva automáticamente el clic derecho del ratón)
-js #
Ajustar la sensibilidad del joystick, donde # es un valor numérico de 0-32767
-k #
Establecer el nivel de volumen, donde # es un valor numérico de 1-100
-l
Forzar LoROM. No se puede usar con -h
-m
Deshabilitar la GUI (Debe especificar el nombre del archivo ROM)
-mc
Salir de ZSNES al cerrar una película (usar con -zm)
-md
Volcar video en crudo (usar con -zm)
-ml
Definir la duración del volcado de película en cantidad de fotogramas (usar con -md)
-n #
Habilitar líneas de escaneo (cuando estén disponibles), donde # es uno de: 
0 = ninguna       1 = completa            2 = 25%
3 = 50%
-o
Deshabilitar soporte MMX
-p #
Cambiar la velocidad del reloj de la CPU principal, donde # es un valor numérico de 50-150. 100 es la velocidad normal. Cambiar este valor puede tener efectos adversos.
-r #
Establecer la frecuencia de muestreo de audio, donde # es una de las siguientes opciones: 
0 = 8 KHz      1 = 11.025 KHz     2 = 22.05 KHz
3 = 44.1 KHz   4 = 16 KHz         5 = 32 KHz
6 = 48 KHz
-s
Habilitar emulación SPC700/DSP (Sonido)
-sa
Mostrar archivos con todas las extensiones (*.*) en la GUI. Por defecto, solo se muestran los archivos con una de las extensiones listadas en nombre_rom
-t
Forzar temporización NTSC (60 Hz). No se puede usar con -u
-u
Forzar temporización PAL (50 Hz). No se puede usar con -t
-v #
Seleccionar modo de video, donde # es uno de los siguientes: 
 0 = 256x224 R W      1 = 256x224 R F      2 = 512x448 DR W
 3 = 512x448 DR F     4 = 640x480 DR F     5 = 256x224 OR W
 6 = 512x448 ODR      7 = 640x480 ODS F    8 = 640x480 ODS W
 9 = 640x560 ODR W   10 = 768x672 ODR W   11 = 800x600 ODS F
12 = 800x600 ODS W   13 = 896x784 ODR W   14 = 1024x768 ODS F
15 = 1024x768 ODS W  16 = 1024x896 ODR W  17 = 1280x960 ODS F
18 = 1280x1024 ODS F 19 = 1600x1200 ODS F 20 = VARIABLE ODR W
21 = VARIABLE ODS W  22 = CUSTOM OD F
-y
Habilitar interpolación
-z
Deshabilitar sonido estéreo. El sonido estéreo está habilitado por defecto
-zm #
Cargar automáticamente la película especificada al inicio, donde # es un valor numérico de 0-9
-zs #
Cargar automáticamente el estado de guardado especificado al inicio, donde # es un valor numérico de 0-99
nombre_rom
Nombre de la ROM que se cargará automáticamente. nombre_rom tiene el formato nombre_archivo.ext, donde .ext es una de las siguientes extensiones: SMC, SFC, SWC, FIG, MGD, MGH, UFO, BIN, GD3, GD7, USA, EUR, JAP, AUS, ST, BS, DX2, 048, 058, 078, 1 o A. También puedes cargar ROMs que han sido comprimidas con GZip, Zip o JMA.

ARCHIVOS Y DIRECTORIOS

ZSNES
El programa principal.
~/.zsnes
Este es el directorio donde se almacenan los archivos de configuración de ZSNES. Por defecto, es también el directorio donde se guardan los estados de guardado, capturas de pantalla, volcados SPC y archivos de película ZMV, pero puedes cambiar este comportamiento editando zsnesl.cfg. Este directorio es creado por ZSNES.
~/.zsnes/zsnesl.cfg
Este archivo es donde se almacenan la configuración de ZSNES. Está en un formato legible por humanos y puede ser editado manualmente. Es creado por ZSNES.
~/.zsnes/zmovie.cfg
Este archivo es donde se guardan la configuración específica para volcado AVI. Es creado por ZSNES.
~/.zsnes/zfont.txt
Este archivo te permite personalizar las fuentes en la GUI. Habilita "Usar Fuente Personalizada" en el menú Opciones de la GUI. Es creado por ZSNES.
~/.zsnes/zinput.cfg
Este archivo es donde se almacenan la configuración de entrada para ZSNES.

Si por alguna razón actualizas tu versión de ZSNES y sigue fallando antes de que puedas hacer algo, deberías intentar eliminar los archivos .cfg anteriores y dejar que ZSNES cree unos nuevos.

JUEGOS CON CHIP ESPECIAL

Muchos juegos en Super Nintendo utilizaron CPUs personalizadas además de la CPU principal de SNES. Algunas de estas CPUs no han sido completamente sometidas a ingeniería inversa, y los juegos que las utilizan pueden no funcionar o experimentar errores extraños.

Puedes encontrar más información sobre estas CPUs especiales en:

http://users.tpg.com.au/advlink/dsp/

http://nsrt.edgeemu.com/INFO/chipinfo.htm

PAQUETES DE GRÁFICOS

Algunos juegos basados en el chip SPC7110, como Far East of Eden Zero, pueden usar paquetes de gráficos especiales para solucionar partes no emuladas de su CPU personalizada. Estos paquetes de gráficos deben almacenarse en directorios individuales dentro del directorio de guardado, que se especifica en zsnesl.cfg. Por defecto, este es ~/.zsnes. El nombre del directorio de cada paquete de gráficos debe estar en mayúsculas y todos los archivos dentro de ese directorio deben estar en minúsculas.

El nombre de directorio correcto para un paquete de gráficos dado se puede encontrar en el archivo readme incluido con ese paquete.

NOTA: A partir de la versión 1.40, los juegos que utilizan el chip S-DD1 (Star Ocean y Street Fighter Alpha 2) no requieren paquetes de gráficos.
