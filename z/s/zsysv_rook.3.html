subrutina zsysv_rook (carácter uplo, entero n, entero nrhs, complejo*16, dimensión( lda, * ) a, entero lda, entero, dimensión( * ) ipiv, complejo*16, dimensión( ldb, * ) b, entero ldb, complejo*16, dimensión( * ) work, entero lwork, entero info)

ZSYSV_ROOK calcula la solución al sistema de ecuaciones lineales A * X = B para matrices SY

Propósito:

!>
!> ZSYSV_ROOK calcula la solución a un sistema complejo de ecuaciones lineales
!>    A * X = B,
!> donde A es una matriz simétrica N por N y X y B son matrices N por NRHS.
!>
!> Se utiliza el método de pivoteo diagonal para factorizar A como
!>    A = U * D * U**T,  si UPLO = 'U', o
!>    A = L * D * L**T,  si UPLO = 'L',
!> donde U (o L) es un producto de matrices de permutación y triangulares unitarias superiores (inferiores), y D es simétrica y diagonal de bloques con
!> bloques diagonales de 1x1 y 2x2.
!>
!> Se llama a ZSYTRF_ROOK para calcular la factorización de una matriz simétrica compleja A utilizando el método de pivoteo diagonal acotado de Bunch-Kaufman ().
!>
!> La forma factorizada de A se utiliza luego para resolver el sistema
!> de ecuaciones A * X = B llamando a ZSYTRS_ROOK.
!>

Parámetros

UPLO 
!>          UPLO es CARACTER*1
!>          = 'U':  El triángulo superior de A está almacenado;
!>          = 'L':  El triángulo inferior de A está almacenado.
!>

N

!>          N es ENTERO
!>          El número de ecuaciones lineales, es decir, el orden de
!>          la matriz A.  N >= 0.
!>

NRHS

!>          NRHS es ENTERO
!>          El número de lados derechos, es decir, el número de columnas
!>          de la matriz B.  NRHS >= 0.
!>

A

!>          A es una matriz COMPLEJO*16, dimensión (LDA,N)
!>          En la entrada, la matriz simétrica A.  Si UPLO = 'U', la parte
!>          superior derecha de N por N de A contiene la parte
!>          triangular superior de la matriz A, y la parte estrictamente
!>          triangular inferior de A no se referencia. Si UPLO = 'L', la parte
!>          inferior derecha de N por N de A contiene la parte
!>          triangular inferior de la matriz A, y la parte estrictamente
!>          triangular superior de A no se referencia.
!>
!>          En la salida, si INFO = 0, la matriz diagonal de bloques D y los
!>          multiplicadores utilizados para obtener el factor U o L de la
!>          factorización A = U*D*U**T o A = L*D*L**T según lo calculado por
!>          ZSYTRF_ROOK.
!>

LDA

!>          LDA es ENTERO
!>          La dimensión principal de la matriz A.  LDA >= max(1,N).
!>

IPIV

!>          IPIV es una matriz ENTERO, dimensión (N)
!>          Detalles de los intercambios y la estructura de bloques de D,
!>          según lo determinado por ZSYTRF_ROOK.
!>
!>          Si UPLO = 'U':
!>               Si IPIV(k) > 0, entonces las filas y columnas k e IPIV(k)
!>               fueron intercambiadas y D(k,k) es un bloque diagonal de 1x1.
!>
!>               Si IPIV(k) < 0 e IPIV(k-1) < 0, entonces las filas y
!>               columnas k e -IPIV(k) fueron intercambiadas y las filas y
!>               columnas k-1 e -IPIV(k-1) fueron intercambiadas,
!>               D(k-1:k,k-1:k) es un bloque diagonal de 2x2.
!>
!>          Si UPLO = 'L':
!>               Si IPIV(k) > 0, entonces las filas y columnas k e IPIV(k)
!>               fueron intercambiadas y D(k,k) es un bloque diagonal de 1x1.
!>
!>               Si IPIV(k) < 0 e IPIV(k+1) < 0, entonces las filas y
!>               columnas k e -IPIV(k) fueron intercambiadas y las filas y
!>               columnas k+1 e -IPIV(k+1) fueron intercambiadas,
!>               D(k:k+1,k:k+1) es un bloque diagonal de 2x2.
!>

B

!>          B es una matriz COMPLEJO*16, dimensión (LDB,NRHS)
!>          En la entrada, la matriz B del lado derecho N por NRHS.
!>          En la salida, si INFO = 0, la matriz solución X de N por NRHS.
!>

LDB

!>          LDB es ENTERO
!>          La dimensión principal de la matriz B.  LDB >= max(1,N).
!>

WORK

!>          WORK es una matriz COMPLEJO*16, dimensión (MAX(1,LWORK))
!>          En la salida, si INFO = 0, WORK(1) devuelve el LWORK óptimo.
!>

LWORK

!>          LWORK es ENTERO
!>          La longitud de WORK.  LWORK >= 1, y para un rendimiento óptimo
!>          LWORK >= max(1,N*NB), donde NB es el tamaño de bloque óptimo para
!>          ZSYTRF_ROOK.
!>
!>          TRS se realizará con BLAS de Nivel 2.
!>
!>          Si LWORK = -1, entonces se asume una consulta de espacio de trabajo; la rutina
!>          solo calcula el tamaño óptimo de la matriz WORK, devuelve
!>          este valor como la primera entrada de la matriz WORK, y XERBLA
!>          no emite ningún mensaje de error relacionado con LWORK.
!>

INFO

!>          INFO es ENTERO
!>          = 0: finalización exitosa
!>          < 0: si INFO = -i, el i-ésimo argumento tenía un valor ilegal
!>          > 0: si INFO = i, D(i,i) es exactamente cero. La factorización
!>               se ha completado, pero la matriz diagonal de bloques D es
!>               exactamente singular, por lo que no se pudo calcular la solución.
!>
