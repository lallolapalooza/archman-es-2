Documentación de función/subrutina

subrutina zsycon_3 (character uplo, integer n, complex*16, dimension( lda, * ) a, integer lda, complex*16, dimension( * ) e, integer, dimension( * ) ipiv, double precision anorm, double precision rcond, complex*16, dimension( * ) work, integer info)

ZSYCON_3

Propósito:

!> ZSYCON_3 estima el recíproco del número de condición (en la
!> norma 1) de una matriz compleja simétrica A utilizando la factorización
!> calculada por ZSYTRF_RK o ZSYTRF_BK:
!>
!>    A = P*U*D*(U**T)*(P**T) o A = P*L*D*(L**T)*(P**T),
!>
!> donde U (o L) es una matriz triangular superior (o inferior) unitaria,
!> U**T (o L**T) es la transpuesta de U (o L), P es una matriz de permutación,
!> P**T es la transpuesta de P, y D es simétrica y diagonal por bloques con
!> bloques diagonales de 1x1 y 2x2.
!>
!> Se obtiene una estimación de norm(inv(A)), y el recíproco del
!> número de condición se calcula como RCOND = 1 / (ANORM * norm(inv(A))).
!> Esta rutina utiliza el solucionador BLAS3 ZSYTRS_3.
!>

Parámetros

UPLO 
!>          UPLO es CHARACTER*1
!>          Especifica si los detalles de la factorización se
!>          almacenan como una matriz triangular superior o inferior:
!>          = 'U':  Triangular superior, la forma es A = P*U*D*(U**T)*(P**T);
!>          = 'L':  Triangular inferior, la forma es A = P*L*D*(L**T)*(P**T).
!>

N

!>          N es INTEGER
!>          El orden de la matriz A.  N >= 0.
!>

A

!>          A es un array COMPLEX*16, de dimensión (LDA,N)
!>          La diagonal de la matriz diagonal por bloques D y los factores U o L
!>          calculados por ZSYTRF_RK y ZSYTRF_BK:
!>            a) SÓLO los elementos diagonales de la matriz simétrica diagonal
!>               por bloques D en la diagonal de A, es decir, D(k,k) = A(k,k);
!>               (los elementos superdiagonales (o subdiagonales) de D
!>                deben proporcionarse en la entrada en el array E), y
!>            b) Si UPLO = 'U': el factor U en la parte superdiagonal de A.
!>               Si UPLO = 'L': el factor L en la parte subdiagonal de A.
!>

LDA

!>          LDA es INTEGER
!>          La dimensión principal del array A.  LDA >= max(1,N).
!>

E

!>          E es un array COMPLEX*16, de dimensión (N)
!>          En la entrada, contiene los elementos superdiagonales (o subdiagonales)
!>          de la matriz simétrica diagonal por bloques D
!>          con bloques diagonales de 1x1 o 2x2, donde
!>          Si UPLO = 'U': E(i) = D(i-1,i),i=2:N, E(1) no se referencia;
!>          Si UPLO = 'L': E(i) = D(i+1,i),i=1:N-1, E(N) no se referencia.
!>
!>          NOTA: Para un bloque diagonal de 1x1 D(k), donde
!>          1 <= k <= N, el elemento E(k) no se referencia en ambos
!>          casos UPLO = 'U' o UPLO = 'L'.
!>

IPIV

!>          IPIV es un array INTEGER, de dimensión (N)
!>          Detalles de los intercambios y la estructura de bloques de D
!>          según lo determinado por ZSYTRF_RK o ZSYTRF_BK.
!>

ANORM

!>          ANORM es DOUBLE PRECISION
!>          La norma 1 de la matriz original A.
!>

RCOND

!>          RCOND es DOUBLE PRECISION
!>          El recíproco del número de condición de la matriz A,
!>          calculado como RCOND = 1/(ANORM * AINVNM), donde AINVNM es una
!>          estimación de la norma 1 de inv(A) calculada en esta rutina.
!>

WORK

!>          WORK es un array COMPLEX*16, de dimensión (2*N)
!>

INFO

!>          INFO es INTEGER
!>          = 0:  salida exitosa
!>          < 0:  si INFO = -i, el i-ésimo argumento tuvo un valor ilegal
!>
