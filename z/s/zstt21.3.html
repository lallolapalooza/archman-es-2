subrutina zstt21 (integer n, integer kband, double precision, dimension( * ) ad, double precision, dimension( * ) ae, double precision, dimension( * ) sd, double precision, dimension( * ) se, complex*16, dimension( ldu, * ) u, integer ldu, complex*16, dimension( * ) work, double precision, dimension( * ) rwork, double precision, dimension( 2 ) result)

ZSTT21

Propósito:

!>
!> ZSTT21  verifica una descomposición de la forma
!>
!>    A = U S U**H
!>
!> donde **H significa transpuesta conjugada, A es real simétrica tridiagonal,
!> U es unitaria, y S es real y diagonal (si KBAND=0) o simétrica
!> tridiagonal (si KBAND=1). Se realizan dos pruebas:
!>
!>    RESULT(1) = | A - U S U**H | / ( |A| n ulp )
!>
!>    RESULT(2) = | I - U U**H | / ( n ulp )
!>

Parámetros

N 
!>          N es INTEGER
!>          El tamaño de la matriz. Si es cero, ZSTT21 no hace nada.
!>          Debe ser mayor o igual a cero.
!>

KBAND

!>          KBAND es INTEGER
!>          El ancho de banda de la matriz S. Solo puede ser cero o uno.
!>          Si es cero, S es diagonal, y SE no se referencia. Si
!>          es uno, S es simétrica tri-diagonal.
!>

AD

!>          AD es DOUBLE PRECISION array, dimension (N)
!>          La diagonal de la matriz original (no factorizada) A. Se asume
!>          que A es real simétrica tridiagonal.
!>

AE

!>          AE es DOUBLE PRECISION array, dimension (N-1)
!>          La parte fuera de la diagonal de la matriz original (no factorizada) A.
!>          Se asume que A es simétrica tridiagonal. AE(1) es el elemento (1,2)
!>          y (2,1), AE(2) es el elemento (2,3) y (3,2), etc.
!>

SD

!>          SD es DOUBLE PRECISION array, dimension (N)
!>          La diagonal de la matriz real (simétrica tri-) diagonal S.
!>

SE

!>          SE es DOUBLE PRECISION array, dimension (N-1)
!>          La parte fuera de la diagonal de la matriz (simétrica tri-) diagonal S.
!>          No se referencia si KBSND=0. Si KBAND=1, entonces AE(1) es el
!>          elemento (1,2) y (2,1), SE(2) es el elemento (2,3) y (3,2),
!>          etc.
!>

U

!>          U es COMPLEX*16 array, dimension (LDU, N)
!>          La matriz unitaria en la descomposición.
!>

LDU

!>          LDU es INTEGER
!>          La dimensión principal de U. LDU debe ser al menos N.
!>

WORK

!>          WORK es COMPLEX*16 array, dimension (N**2)
!>

RWORK

!>          RWORK es DOUBLE PRECISION array, dimension (N)
!>

RESULT

!>          RESULT es DOUBLE PRECISION array, dimension (2)
!>          Los valores calculados por las dos pruebas descritas arriba.
!>          Actualmente, los valores están limitados a 1/ulp para evitar desbordamientos.
!>          RESULT(1) siempre se modifica.
!>
