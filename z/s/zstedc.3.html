subrutina zstedc (character compz, integer n, double precision, dimension( * ) d, double precision, dimension( * ) e, complex*16, dimension( ldz, * ) z, integer ldz, complex*16, dimension( * ) work, integer lwork, double precision, dimension( * ) rwork, integer lrwork, integer, dimension( * ) iwork, integer liwork, integer info)

ZSTEDC

Propósito:

!>
!> ZSTEDC calcula todos los valores propios y, opcionalmente, los vectores propios de una
!> matriz tridiagonal simétrica utilizando el método de división y conquista.
!> Los vectores propios de una matriz hermitiana completa o de banda también
!> se pueden encontrar si se ha utilizado ZHETRD o ZHPTRD o ZHBTRD para reducir esta
!> matriz a forma tridiagonal.
!>
!>

Parámetros

COMPZ 
!>          COMPZ es CHARACTER*1
!>          = 'N':  Calcular solo valores propios.
!>          = 'I':  Calcular también los vectores propios de la matriz tridiagonal.
!>          = 'V':  Calcular también los vectores propios de la matriz hermitiana original.
!>                  En la entrada, Z contiene la matriz unitaria utilizada
!>                  para reducir la matriz original a forma tridiagonal.
!>

N

!>          N es INTEGER
!>          La dimensión de la matriz tridiagonal simétrica.  N >= 0.
!>

D

!>          D es un array DOUBLE PRECISION, dimension (N)
!>          En la entrada, los elementos diagonales de la matriz tridiagonal.
!>          En la salida, si INFO = 0, los valores propios en orden ascendente.
!>

E

!>          E es un array DOUBLE PRECISION, dimension (N-1)
!>          En la entrada, los elementos subdiagonales de la matriz tridiagonal.
!>          En la salida, E ha sido destruido.
!>

Z

!>          Z es un array COMPLEX*16, dimension (LDZ,N)
!>          En la entrada, si COMPZ = 'V', entonces Z contiene la matriz
!>          unitaria utilizada en la reducción a forma tridiagonal.
!>          En la salida, si INFO = 0, entonces si COMPZ = 'V', Z contiene los
!>          vectores propios ortonormales de la matriz hermitiana original,
!>          y si COMPZ = 'I', Z contiene los vectores propios ortonormales
!>          de la matriz tridiagonal simétrica.
!>          Si  COMPZ = 'N', entonces Z no se referencia.
!>

LDZ

!>          LDZ es INTEGER
!>          La dimensión principal del array Z.  LDZ >= 1.
!>          Si se desean vectores propios, entonces LDZ >= max(1,N).
!>

WORK

!>          WORK es un array COMPLEX*16, dimension (MAX(1,LWORK))
!>          En la salida, si INFO = 0, WORK(1) devuelve el LWORK óptimo.
!>

LWORK

!>          LWORK es INTEGER
!>          La dimensión del array WORK.
!>          Si COMPZ = 'N' o 'I', o N <= 1, LWORK debe ser al menos 1.
!>          Si COMPZ = 'V' y N > 1, LWORK debe ser al menos N*N.
!>          Tenga en cuenta que para COMPZ = 'V', entonces si N es menor o
!>          igual al tamaño mínimo de división, generalmente 25, entonces LWORK solo
!>          necesita ser 1.
!>
!>          Si LWORK = -1, se asume una consulta de espacio de trabajo; la rutina
!>          solo calcula los tamaños óptimos de los arrays WORK, RWORK e
!>          IWORK, devuelve estos valores como las primeras entradas de
!>          los arrays WORK, RWORK e IWORK, y XERBLA no emite ningún mensaje de error
!>          relacionado con LWORK o LRWORK o LIWORK.
!>

RWORK

!>          RWORK es un array DOUBLE PRECISION, dimension (MAX(1,LRWORK))
!>          En la salida, si INFO = 0, RWORK(1) devuelve el LRWORK óptimo.
!>

LRWORK

!>          LRWORK es INTEGER
!>          La dimensión del array RWORK.
!>          Si COMPZ = 'N' o N <= 1, LRWORK debe ser al menos 1.
!>          Si COMPZ = 'V' y N > 1, LRWORK debe ser al menos
!>                         1 + 3*N + 2*N*lg N + 4*N**2 ,
!>                         donde lg( N ) = entero más pequeño k tal que
!>                         2**k >= N.
!>          Si COMPZ = 'I' y N > 1, LRWORK debe ser al menos
!>                         1 + 4*N + 2*N**2 .
!>          Tenga en cuenta que para COMPZ = 'I' o 'V', entonces si N es menor o
!>          igual al tamaño mínimo de división, generalmente 25, entonces LRWORK
!>          solo necesita ser max(1,2*(N-1)).
!>
!>          Si LRWORK = -1, se asume una consulta de espacio de trabajo; la rutina
!>          solo calcula los tamaños óptimos de los arrays WORK, RWORK e
!>          IWORK, devuelve estos valores como las primeras entradas de
!>          los arrays WORK, RWORK e IWORK, y XERBLA no emite ningún mensaje de error
!>          relacionado con LWORK o LRWORK o LIWORK.
!>

IWORK

!>          IWORK es un array INTEGER, dimension (MAX(1,LIWORK))
!>          En la salida, si INFO = 0, IWORK(1) devuelve el LIWORK óptimo.
!>

LIWORK

!>          LIWORK es INTEGER
!>          La dimensión del array IWORK.
!>          Si COMPZ = 'N' o N <= 1, LIWORK debe ser al menos 1.
!>          Si COMPZ = 'V' o N > 1,  LIWORK debe ser al menos
!>                                    6 + 6*N + 5*N*lg N.
!>          Si COMPZ = 'I' o N > 1,  LIWORK debe ser al menos
!>                                    3 + 5*N .
!>          Tenga en cuenta que para COMPZ = 'I' o 'V', entonces si N es menor o
!>          igual al tamaño mínimo de división, generalmente 25, entonces LIWORK
!>          solo necesita ser 1.
!>
!>          Si LIWORK = -1, se asume una consulta de espacio de trabajo; la rutina
!>          solo calcula los tamaños óptimos de los arrays WORK, RWORK e
!>          IWORK, devuelve estos valores como las primeras entradas de
!>          los arrays WORK, RWORK e IWORK, y XERBLA no emite ningún mensaje de error
!>          relacionado con LWORK o LRWORK o LIWORK.
!>

INFO

!>          INFO es INTEGER
!>          = 0:  salida exitosa.
!>          < 0:  si INFO = -i, el i-ésimo argumento tenía un valor ilegal.
!>          > 0:  El algoritmo no pudo calcular un valor propio mientras
!>                trabajaba en la submatriz ubicada en las filas y columnas
!>                INFO/(N+1) hasta mod(INFO,N+1).
!>

NAME

zstedc - ZSTEDC computes the eigenvalues and, optionally, eigenvectors of a symmetric tridiagonal matrix.

SYNOPSIS

SUBROUTINE ZSTEDC( COMPZ, N, D, E, Z, LDZ, WORK, IWORK, INFO )

  CHARACTER COMPZ
  INTEGER INFO
  INTEGER LDZ, N
  DOUBLE PRECISION D( * ), E( * )
  COMPLEX*16 Z( * ), WORK( * )
  INTEGER IWORK( * )

Function/Subroutine Documentation

ZSTEDC computes the eigenvalues and, optionally, eigenvectors of a symmetric tridiagonal matrix.

This subroutine is part of the LAPACK library, a collection of Fortran subroutines for solving various linear algebra problems.

Arguments:

  • COMPZ: Character flag. Specifies whether to compute eigenvectors.
    • 'N' or 'n': Only eigenvalues are computed.
    • 'V' or 'v': Eigenvalues and eigenvectors are computed.
  • N: Integer. The order of the tridiagonal matrix.
  • D: Double precision array of dimension N. On entry, the diagonal elements of the matrix. On exit, the computed eigenvalues in ascending order.
  • E: Double precision array of dimension N-1. On entry, the off-diagonal elements of the matrix. On exit, E is overwritten.
  • Z: Complex*16 array of dimension (LDZ, N). If COMPZ = 'V' or 'v', Z is the matrix of eigenvectors. If COMPZ = 'N' or 'n', the space is not used.
  • LDZ: Integer. The leading dimension of the array Z.
  • WORK: Complex*16 array of dimension (N*N).
  • IWORK: Integer array of dimension 6*N.
  • INFO: Integer.
    • 0: Successful exit.
    • < 0: If INFO = -i, the i-th argument had an illegal value.
    • > 0: If INFO = i, the algorithm failed to compute all N eigenvalues.

Description:

ZSTEDC uses the divide and conquer method to compute the eigenvalues and eigenvectors of a symmetric tridiagonal matrix. It can be significantly faster than QR iteration for computing all eigenvalues and eigenvectors.
