Documentación de la función/subrutina

subrutina zstein (entero n, doble precisión, dimensión( * ) d, doble precisión, dimensión( * ) e, entero m, doble precisión, dimensión( * ) w, entero, dimensión( * ) iblock, entero, dimensión( * ) isplit, complejo*16, dimensión( ldz, * ) z, entero ldz, doble precisión, dimensión( * ) work, entero, dimensión( * ) iwork, entero, dimensión( * ) ifail, entero info)

ZSTEIN

Propósito:

!>
!> ZSTEIN calcula los vectores propios de una matriz tridiagonal simétrica real
!> T correspondientes a autovalores especificados, usando iteración inversa.
!>
!> El número máximo de iteraciones permitidas para cada vector propio se
!> especifica mediante un parámetro interno MAXITS (actualmente establecido en 5).
!>
!> Aunque los vectores propios son reales, se almacenan en un array complejo,
!> que puede pasarse a ZUNMTR o ZUPMTR para la retrotransformación
!> a los vectores propios de una matriz Hermítica compleja
!> que fue reducida a forma tridiagonal.
!>
!>

Parámetros

N 
!>          N es ENTERO
!>          El orden de la matriz.  N >= 0.
!>

D

!>          D es un array de DOBLE PRECISIÓN, dimensión (N)
!>          Los n elementos diagonales de la matriz tridiagonal T.
!>

E

!>          E es un array de DOBLE PRECISIÓN, dimensión (N-1)
!>          Los n-1 elementos subdiagonales de la matriz
!>          tridiagonal T, almacenados en los elementos 1 a N-1.
!>

M

!>          M es ENTERO
!>          El número de vectores propios a encontrar.  0 <= M <= N.
!>

W

!>          W es un array de DOBLE PRECISIÓN, dimensión (N)
!>          Los primeros M elementos de W contienen los autovalores para
!>          los cuales se deben calcular los vectores propios. Los autovalores
!>          deben agruparse por bloque de división y ordenarse de
!>          menor a mayor dentro del bloque.  ( Se espera aquí el array de
!>          salida W de DSTEBZ con ORDER = 'B'. )
!>

IBLOCK

!>          IBLOCK es un array de ENTEROS, dimensión (N)
!>          Los índices de las submatrices asociados con los autovalores
!>          correspondientes en W; IBLOCK(i)=1 si el autovalor W(i) pertenece a
!>          la primera submatriz desde arriba, =2 si W(i) pertenece a
!>          la segunda submatriz, etc.  ( Se espera aquí el array de
!>          salida IBLOCK de DSTEBZ. )
!>

ISPLIT

!>          ISPLIT es un array de ENTEROS, dimensión (N)
!>          Los puntos de división, en los que T se divide en submatrices.
!>          La primera submatriz consiste en las filas/columnas 1 a
!>          ISPLIT( 1 ), la segunda en las filas/columnas ISPLIT( 1 )+1
!>          hasta ISPLIT( 2 ), etc.
!>          ( Se espera aquí el array de salida ISPLIT de DSTEBZ. )
!>

Z

!>          Z es un array de COMPLEJO*16, dimensión (LDZ, M)
!>          Los vectores propios calculados.  El vector propio asociado
!>          con el autovalor W(i) se almacena en la i-ésima columna de
!>          Z.  Cualquier vector que no converja se establece a su
!>          iteración actual después de MAXITS iteraciones.
!>          Las partes imaginarias de los vectores propios se establecen a cero.
!>

LDZ

!>          LDZ es ENTERO
!>          La dimensión principal del array Z.  LDZ >= max(1,N).
!>

WORK

!>          WORK es un array de DOBLE PRECISIÓN, dimensión (5*N)
!>

IWORK

!>          IWORK es un array de ENTEROS, dimensión (N)
!>

IFAIL

!>          IFAIL es un array de ENTEROS, dimensión (M)
!>          En salida normal, todos los elementos de IFAIL son cero.
!>          Si uno o más vectores propios no convergen después de
!>          MAXITS iteraciones, sus índices se almacenan en
!>          el array IFAIL.
!>

INFO

!>          INFO es ENTERO
!>          = 0: salida exitosa
!>          < 0: si INFO = -i, el i-ésimo argumento tenía un valor ilegal
!>          > 0: si INFO = i, entonces i vectores propios no convergieron
!>               en MAXITS iteraciones. Sus índices se almacenan en
!>               el array IFAIL.
!>

Parámetros internos:

!>  MAXITS  ENTERO, valor predeterminado = 5
!>          El número máximo de iteraciones realizadas.
!>
!>  EXTRA   ENTERO, valor predeterminado = 2
!>          El número de iteraciones realizadas después de que el criterio
!>          de crecimiento de la norma se satisface, debe ser al menos 1.
!>
