DOCUMENTACIÓN DE LA FUNCIÓN/SUBRUTINA

subrutina zsytrf_aa (character uplo, integer n, complex*16, dimension( lda, * ) a, integer lda, integer, dimension( * ) ipiv, complex*16, dimension( * ) work, integer lwork, integer info)

ZSYTRF_AA

Propósito:

!>
!> ZSYTRF_AA calcula la factorización de una matriz simétrica compleja A
!> utilizando el algoritmo de Aasen. La forma de la factorización es
!>
!>    A = U**T*T*U  o  A = L*T*L**T
!>
!> donde U (o L) es un producto de matrices de permutación y triangular superior (inferior)
!> unitarias, y T es una matriz simétrica tridiagonal compleja.
!>
!> Esta es la versión bloqueada del algoritmo, que llama a BLAS de Nivel 3.
!>

Parámetros

UPLO 
!>          UPLO es CHARACTER*1
!>          = 'U':  El triángulo superior de A está almacenado;
!>          = 'L':  El triángulo inferior de A está almacenado.
!>

N

!>          N es INTEGER
!>          El orden de la matriz A.  N >= 0.
!>

A

!>          A es un array COMPLEX*16, de dimensión (LDA,N)
!>          En la entrada, la matriz simétrica A. Si UPLO = 'U', la parte
!>          superior triangular N-por-N principal de A contiene la parte
!>          superior triangular de la matriz A, y la parte triangular estrictamente inferior
!>          de A no se referencia. Si UPLO = 'L', la parte
!>          inferior triangular N-por-N principal de A contiene la parte
!>          inferior triangular de la matriz A, y la parte triangular estrictamente superior
!>          de A no se referencia.
!>
!>          En la salida, la matriz tridiagonal se almacena en las diagonales
!>          y las subdiagonales de A justo debajo (o encima) de las diagonales,
!>          y L se almacena debajo (o encima) de las subdiagonales, cuando UPLO
!>          es 'L' (o 'U').
!>

LDA

!>          LDA es INTEGER
!>          La dimensión principal del array A.  LDA >= max(1,N).
!>

IPIV

!>          IPIV es un array INTEGER, de dimensión (N)
!>          En la salida, contiene los detalles de los intercambios, es decir,
!>          la fila y columna k de A se intercambiaron con la
!>          fila y columna IPIV(k).
!>

WORK

!>          WORK es un array COMPLEX*16, de dimensión (MAX(1,LWORK))
!>          En la salida, si INFO = 0, WORK(1) devuelve el LWORK óptimo.
!>

LWORK

!>          LWORK es INTEGER
!>          La longitud de WORK. LWORK >=MAX(1,2*N). Para un rendimiento óptimo
!>          LWORK >= N*(1+NB), donde NB es el tamaño de bloque óptimo.
!>
!>          Si LWORK = -1, entonces se asume una consulta de espacio de trabajo; la rutina
!>          solo calcula el tamaño óptimo del array WORK, devuelve
!>          este valor como la primera entrada del array WORK, y XERBLA no emite ningún mensaje de error
!>          relacionado con LWORK.
!>

INFO

!>          INFO es INTEGER
!>          = 0:  salida exitosa
!>          < 0:  si INFO = -i, el argumento i-ésimo tenía un valor ilegal.
!>
