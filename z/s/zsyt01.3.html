ZSYT01

Propósito:

!>
!> ZSYT01 reconstruye una matriz indefinida simétrica compleja A a partir de su
!> factorización de bloque L*D*L' o U*D*U' y calcula el residuo
!>    norm( C - A ) / ( N * norm(A) * EPS ),
!> donde C es la matriz reconstruida, EPS es la epsilon de máquina,
!> L' es la transpuesta de L, y U' es la transpuesta de U.
!>

Parámetros

UPLO 
!>          UPLO es CHARACTER*1
!>          Especifica si la parte triangular superior o inferior de la
!>          matriz simétrica compleja A está almacenada:
!>          = 'U':  Triangular superior
!>          = 'L':  Triangular inferior
!>

N

!>          N es INTEGER
!>          El número de filas y columnas de la matriz A.  N >= 0.
!>

A

!>          A es una matriz COMPLEX*16, dimensión (LDA,N)
!>          La matriz simétrica compleja original A.
!>

LDA

!>          LDA es INTEGER
!>          La dimensión principal de la matriz A.  LDA >= max(1,N)
!>

AFAC

!>          AFAC es una matriz COMPLEX*16, dimensión (LDAFAC,N)
!>          La forma factorizada de la matriz A. AFAC contiene la matriz
!>          de bloque diagonal D y los multiplicadores utilizados para
!>          obtener L o U de la factorización de bloque L*D*L' o U*D*U'
!>          calculada por ZSYTRF.
!>

LDAFAC

!>          LDAFAC es INTEGER
!>          La dimensión principal de la matriz AFAC. LDAFAC >= max(1,N).
!>

IPIV

!>          IPIV es una matriz INTEGER, dimensión (N)
!>          Los índices de pivote de ZSYTRF.
!>

C

!>          C es una matriz COMPLEX*16, dimensión (LDC,N)
!>

LDC

!>          LDC es INTEGER
!>          La dimensión principal de la matriz C. LDC >= max(1,N).
!>

RWORK

!>          RWORK es una matriz DOUBLE PRECISION, dimensión (N)
!>

RESID

!>          RESID es DOUBLE PRECISION
!>          Si UPLO = 'L', norm(L*D*L' - A) / ( N * norm(A) * EPS )
!>          Si UPLO = 'U', norm(U*D*U' - A) / ( N * norm(A) * EPS )
!>
