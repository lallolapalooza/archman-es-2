ZSPT01

Propósito:

!>
!> ZSPT01 reconstruye una matriz simétrica indefinida empaquetada A a partir de su
!> factorización de pivoteo diagonal A = U*D*U' o A = L*D*L' y calcula
!> el residuo
!>    norm( C - A ) / ( N * norm(A) * EPS ),
!> donde C es la matriz reconstruida y EPS es la epsilon de la máquina.
!>

Parámetros

UPLO 
!>          UPLO es CHARACTER*1
!>          Especifica si la parte triangular superior o inferior de la
!>          matriz Hermítica A está almacenada:
!>          = 'U':  Triangular superior
!>          = 'L':  Triangular inferior
!>

N

!>          N es INTEGER
!>          El orden de la matriz A.  N >= 0.
!>

A

!>          A es array COMPLEX*16, dimensión (N*(N+1)/2)
!>          La matriz simétrica original A, almacenada como una matriz
!>          triangular empaquetada.
!>

AFAC

!>          AFAC es array COMPLEX*16, dimensión (N*(N+1)/2)
!>          La forma factorizada de la matriz A, almacenada como una matriz
!>          triangular empaquetada. AFAC contiene la matriz diagonal de bloques D
!>          y los multiplicadores utilizados para obtener el factor L o U de la
!>          factorización L*D*L' o U*D*U' según lo calculado por ZSPTRF.
!>

IPIV

!>          IPIV es array INTEGER, dimensión (N)
!>          Los índices de pivote de ZSPTRF.
!>

C

!>          C es array COMPLEX*16, dimensión (LDC,N)
!>

LDC

!>          LDC es INTEGER
!>          La dimensión principal del array C.  LDC >= max(1,N).
!>

RWORK

!>          RWORK es array DOUBLE PRECISION, dimensión (N)
!>

RESID

!>          RESID es DOUBLE PRECISION
!>          Si UPLO = 'L', norm(L*D*L' - A) / ( N * norm(A) * EPS )
!>          Si UPLO = 'U', norm(U*D*U' - A) / ( N * norm(A) * EPS )
!>
