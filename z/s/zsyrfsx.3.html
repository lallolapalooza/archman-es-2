ZSYRFSX

Propósito:

!>
!>    ZSYRFSX mejora la solución calculada para un sistema de ecuaciones
!>    lineales cuando la matriz de coeficientes es simétrica indefinida, y
!>    proporciona límites de error y estimaciones de error hacia atrás para
!>    la solución.  Además del límite de error normwise, el código proporciona
!>    un límite de error componente a componente máximo si es posible.  Ver los
!>    comentarios para ERR_BNDS_NORM y ERR_BNDS_COMP para detalles de los
!>    límites de error.
!>
!>    El sistema original de ecuaciones lineales puede haber sido
!>    equilibrado antes de llamar a esta rutina, como se describe por los
!>    argumentos EQUED y S abajo. En este caso, la solución y los límites de
!>    error devueltos son para el sistema original no equilibrado.
!> 
!>     Algunos parámetros opcionales se agrupan en la matriz PARAMS. Estos
!>     ajustes determinan cómo se realiza el refinamiento, pero a menudo los
!>     valores predeterminados son aceptables.  Si los valores predeterminados
!>     son aceptables, los usuarios
!>     pueden pasar NPARAMS = 0 lo que evita que el código fuente acceda
!>     al argumento PARAMS.
!>

Parámetros

UPLO 
!>          UPLO es CHARACTER*1
!>       = 'U':  El triángulo superior de A se almacena;
!>       = 'L':  El triángulo inferior de A se almacena.
!>

EQUED

!>          EQUED es CHARACTER*1
!>     Especifica la forma de equilibrado que se realizó en A
!>     antes de llamar a esta rutina. Esto es necesario para calcular
!>     la solución y los límites de error correctamente.
!>       = 'N':  No equilibrado
!>       = 'Y':  Equilibrado de filas y columnas, es decir, A ha sido
!>               reemplazado por diag(S) * A * diag(S).
!>               El lado derecho B se ha modificado en consecuencia.
!>

N

!>          N es INTEGER
!>     El orden de la matriz A.  N >= 0.
!>

NRHS

!>          NRHS es INTEGER
!>     El número de lados derechos, es decir, el número de columnas
!>     de las matrices B y X.  NRHS >= 0.
!>

A

!>          A es COMPLEX*16 array, dimension (LDA,N)
!>     La matriz simétrica A.  Si UPLO = 'U', la parte superior
!>     triangular de N por N de A contiene la parte triangular
!>     superior de la matriz A, y la parte triangular estrictamente
!>     inferior de A no se referencia.  Si UPLO = 'L', la parte inferior
!>     triangular de N por N de A contiene la parte triangular
!>     inferior de la matriz A, y la parte triangular estrictamente
!>     superior de A no se referencia.
!>

LDA

!>          LDA es INTEGER
!>     La dimensión principal del array A.  LDA >= max(1,N).
!>

AF

!>          AF es COMPLEX*16 array, dimension (LDAF,N)
!>     La forma factorizada de la matriz A.  AF contiene la matriz
!>     diagonal por bloques D y los multiplicadores utilizados para
!>     obtener U o L de la factorización A = U*D*U**T o A =
!>     L*D*L**T como fue calculada por ZSYTRF.
!>

LDAF

!>          LDAF es INTEGER
!>     La dimensión principal del array AF.  LDAF >= max(1,N).
!>

IPIV

!>          IPIV es INTEGER array, dimension (N)
!>     Detalles de los intercambios y la estructura de bloques de D
!>     como fue determinada por ZSYTRF.
!>

S

!>          S es DOUBLE PRECISION array, dimension (N)
!>     Los factores de escala para A.  Si EQUED = 'Y', A se multiplica
!>     a la izquierda y a la derecha por diag(S).  S es un argumento de
!>     entrada si FACT = 'F'; de lo contrario, S es un argumento de
!>     salida.  Si FACT = 'F' y EQUED = 'Y', cada elemento de S debe ser
!>     positivo.  Si S es de salida, cada elemento de S es una potencia
!>     del radix. Si S es de entrada, cada elemento de S debe ser
!>     una potencia del radix para asegurar una solución fiable
!>     y estimaciones de error. El escalado por potencias del radix no
!>     causa errores de redondeo a menos que el resultado sea un
!>     underflow o overflow.  Los errores de redondeo durante el escalado
!>     conducen a refinar con una matriz que
!>     no es equivalente a la matriz de entrada, produciendo estimaciones
!>     de error que pueden no ser fiables.
!>

B

!>          B es COMPLEX*16 array, dimension (LDB,NRHS)
!>     La matriz del lado derecho B.
!>

LDB

!>          LDB es INTEGER
!>     La dimensión principal del array B.  LDB >= max(1,N).
!>

X

!>          X es COMPLEX*16 array, dimension (LDX,NRHS)
!>     En la entrada, la matriz solución X, como fue calculada por ZGETRS.
!>     En la salida, la matriz solución mejorada X.
!>

LDX

!>          LDX es INTEGER
!>     La dimensión principal del array X.  LDX >= max(1,N).
!>

RCOND

!>          RCOND es DOUBLE PRECISION
!>     Condición recíproca escalada. Esta es una estimación de la
!>     condición de Skeel recíproca de la matriz A después del
!>     equilibrado (si se realizó). Si es menor que la precisión de la
!>     máquina (en particular, si es cero), la matriz es singular
!>     a la precisión de trabajo.  Tenga en cuenta que el error aún puede ser
!>     pequeño incluso si este número es muy pequeño y la matriz parece
!>     mal condicionada.
!>

BERR

!>          BERR es DOUBLE PRECISION array, dimension (NRHS)
!>     Error relativo componente a componente hacia atrás. Este es el
!>     error relativo componente a componente hacia atrás de cada vector
!>     solución X(j)
!>     (es decir, el cambio relativo más pequeño en cualquier elemento de A o B
!>     que haga que X(j) sea una solución exacta).
!>

N_ERR_BNDS

!>          N_ERR_BNDS es INTEGER
!>     Número de límites de error a devolver para cada lado derecho
!>     y cada tipo (normwise o componente a componente). Ver ERR_BNDS_NORM y
!>     ERR_BNDS_COMP abajo.
!>

ERR_BNDS_NORM

!>          ERR_BNDS_NORM es DOUBLE PRECISION array, dimension (NRHS, N_ERR_BNDS)
!>     Para cada lado derecho, esta matriz contiene información sobre
!>     varios límites de error y números de condición correspondientes al
!>     error relativo normwise, que se define de la siguiente manera:
!>
!>     Error relativo normwise en el i-ésimo vector solución:
!>             max_j (abs(XTRUE(j,i) - X(j,i)))
!>            ------------------------------
!>                  max_j abs(X(j,i))
!>
!>     La matriz está i

         UPLO, N, NRHS, A, LDA, AF, LDAF, IPIV, B, LDB, X, LDX,
         ERR_BNDS_NORM, ERR_BNDS_COMP, NPARAMS, PARAMS, WORK, RWORK,
         INFO )

          CHARACTER * 1           :: UPLO
          INTEGER                 :: LDA, LDAF, LDB, LDX
          INTEGER                 :: N, NRHS
          INTEGER                 :: IPIV( * )
          INTEGER                 :: NPARAMS
          INTEGER                 :: INFO

          COMPLEX*16              :: A( LDA, * ), AF( LDAF, * ), B( LDB, * ),

          COMPLEX*16              :: WORK( * )

          DOUBLE PRECISION        :: PARAMS( * ), RWORK( * )

Function/Subroutine Documentation

This routine uses the results of the routine ZSYTRFSX to estimate the error of the solution to a system of linear equations.

The routine ZSYRF SX improves a computed solution X to a set of right-hand sides B for the system of equations A*X = B. The function also computes error bounds and condition numbers for the computed solution.

The solution is computed using the routines ZSYEQU, ZSYEV, ZSYGS2, ZSYGS, ZSYTRF, ZSYTRS, and ZSYRFS.

The error bounds are computed using the routines ZLAG2C, ZLAG2R, ZLACON, ZLACN2, ZLANGE, ZLANTR, ZLAQP1, ZLAQP2, ZLAQP3, ZLAQP4, ZLAQPS, ZLAR1V, ZLARFG, ZLARFP, ZLARFT, ZLARNV, ZLASCL, ZLASet, ZLATBS, ZLATBS, ZLATR, ZLATRS, ZLAUUM, ZLAXPZ, ZSYCON, ZSYFAUX, ZSYRFS, ZSYRFSX, ZSYSV, ZSYTF, ZSYTR, ZSYTRF, ZSYTRI, ZSYTRS.

The routine ZSYRF SX returns the following values:

A

          A is COMPLEX*16 array, dimension (LDA,N)
          The original upper or lower triangular matrix A.

AF

          AF is COMPLEX*16 array, dimension (LDAF,N)
          The factored form of A. Upper or lower triangular factor L is
          in the strictly lower triangular part of AF, and the diagonal
          and upper triangular factor U is in the upper triangle of AF.
          If UPLO = 'U', the factor L is stored in AF(I,J) with I >= J.
          If UPLO = 'L', the factor L is stored in AF(I,J) with I >= J.
          The diagonal entries of U are stored in the diagonal of AF.
          The unit lower triangular factor L is stored in AF(I,J) with I > J.
          The upper triangular factor U is stored in AF(I,J) with I <= J.
          If UPLO = 'L', the factor L is stored in AF(I,J) with I >= J.
          The unit upper triangular factor U is stored in AF(I,J) with I <= J.

IPIV

          IPIV is INTEGER array, dimension (N)
          Details of the factorization of the matrix A. The order of
          diagonal swaps is determined by the entries in IPIV.

B

          B is COMPLEX*16 array, dimension (LDB,NRHS)
          The right-hand side matrix with B(i) = B(:,i).

X

          X is COMPLEX*16 array, dimension (LDX,NRHS)
          On entry, the solution matrix with X(i) = X(:,i).
          On exit, the improved solution matrix.

ERR_BNDS_NORM

!>          ERR_BNDS_NORM is DOUBLE PRECISION array, dimension (NRHS, N_ERR_BNDS)
!>     For each right-hand side, this array contains information about
!>     various error bounds and condition numbers corresponding to the
!>     normwise relative error, which is defined as follows:
!>
!>     Normwise relative error in the ith solution vector:
!>                    norm(XTRUE - X, inf)
!>             --------------------------
!>                           norm(X, inf)
!>
!>     The array is indexed by the right-hand side i (on which the
!>     normwise relative error depends), and the type of error
!>     information as described below. There currently are up to three
!>     pieces of information returned.
!>
!>     The first index in ERR_BNDS_NORM(i,:) corresponds to the ith
!>     right-hand side.
!>
!>     The second index in ERR_BNDS_NORM(:,err) contains the following
!>     three fields:
!>     err = 1  boolean. Trust the answer if the
!>              reciprocal condition number is less than the threshold
!>              sqrt(n) * dlamch('Epsilon').
!>
!>     err = 2  error bound: The estimated forward error,
!>              almost certainly within a factor of 10 of the true error
!>              so long as the next entry is greater than the threshold
!>              sqrt(n) * dlamch('Epsilon'). This error bound should only
!>              be trusted if the previous boolean is true.
!>
!>     err = 3  Reciprocal condition number: Estimated normwise
!>              reciprocal condition number.  Compared with the threshold
!>              sqrt(n) * dlamch('Epsilon') to determine if the error
!>              estimate is . These reciprocal condition
!>              numbers are 1 / (norm(Z^{-1},inf) * norm(Z,inf)) for some
!>              appropriately scaled matrix Z.
!>              Let Z = S*A, where S scales each row by a power of the
!>              radix so all absolute row sums of Z are approximately 1.
!>
!>     See Lapack Working Note 165 for further details and extra
!>     cautions.
!>

ERR_BNDS_COMP

!>          ERR_BNDS_COMP is DOUBLE PRECISION array, dimension (NRHS, N_ERR_BNDS)
!>     For each right-hand side, this array contains information about
!>     various error bounds and condition numbers corresponding to the
!>     componentwise relative error, which is defined as follows:
!>
!>     Componentwise relative error in the ith solution vector:
!>                    abs(XTRUE(j,i) - X(j,i))
!>             max_j ----------------------
!>                         abs(X(j,i))
!>
!>     The array is indexed by the right-hand side i (on which the
!>     componentwise relative error depends), and the type of error
!>     information as described below. There currently are up to three
!>     pieces of information returned for each right-hand side. If
!>     componentwise accuracy is not requested (PARAMS(3) = 0.0), then
!>     ERR_BNDS_COMP is not accessed.  If N_ERR_BNDS < 3, then at most
!>     the first (:,N_ERR_BNDS) entries are returned.
!>
!>     The first index in ERR_BNDS_COMP(i,:) corresponds to the ith
!>     right-hand side.
!>
!>     The second index in ERR_BNDS_COMP(:,err) contains the following
!>     three fields:
!>     err = 1  boolean. Trust the answer if the
!>              reciprocal condition number is less than the threshold
!>              sqrt(n) * dlamch('Epsilon').
!>
!>     err = 2  error bound: The estimated forward error,
!>              almost certainly within a factor of 10 of the true error
!>              so long as the next entry is greater than the threshold
!>              sqrt(n) * dlamch('Epsilon'). This error bound should only
!>              be trusted if the previous boolean is true.
!>
!>     err = 3  Reciprocal condition number: Estimated componentwise
!>              reciprocal condition number.  Compared with the threshold
!>              sqrt(n) * dlamch('Epsilon') to determine if the error
!>              estimate is . These reciprocal condition
!>              numbers are 1 / (norm(Z^{-1},inf) * norm(Z,inf)) for some
!>              appropriately scaled matrix Z.
!>              Let Z = S*(A*diag(x)), where x is the solution for the
!>              current right-hand side and S scales each row of
!>              A*diag(x) by a power of the radix so all absolute row
!>              sums of Z are approximately 1.
!>
!>     See Lapack Working Note 165 for further details and extra
!>     cautions.
!>

NPARAMS

!>          NPARAMS is INTEGER
!>     Specifies the number of parameters set in PARAMS.  If <= 0, the
!>     PARAMS array is never referenced and default values are used.
!>

PARAMS

!>          PARAMS is DOUBLE PRECISION array, dimension NPARAMS
!>     Specifies algorithm parameters.  If an entry is < 0.0, then
!>     that entry will be filled with default value used for that
!>     parameter.  Only positions up to NPARAMS are accessed; defaults
!>     are used for higher-numbered parameters.
!>
!>       PARAMS(LA_LINRX_ITREF_I = 1) : Whether to perform iterative
!>            refinement or not.
!>         Default: 1.0D+0
!>            = 0.0:  No refinement is performed, and no error bounds are
!>                    computed.
!>            = 1.0:  Use the double-precision refinement algorithm,
!>                    possibly with doubled-single computations if the
!>                    compilation environment does not support DOUBLE
!>                    PRECISION.
!>              (other values are reserved for future use)
!>
!>       PARAMS(LA_LINRX_ITHRESH_I = 2) : Maximum number of residual
!>            computations allowed for refinement.
!>         Default: 10
!>         Aggressive: Set to 100 to permit convergence using approximate
!>                     factorizations or factorizations other than LU. If
!>                     the factorization uses a technique other than
!>                     Gaussian elimination, the guarantees in
!>                     err_bnds_norm and err_bnds_comp may no longer be
!>                     trustworthy.
!>
!>       PARAMS(LA_LINRX_CWISE_I = 3) : Flag determining if the code
!>            will attempt to find a solution with small componentwise
!!>            relative error in the double-precision algorithm.  Positive
!>            is true, 0.0 is false.
!>         Default: 1.0 (attempt componentwise convergence)
!>

WORK

!>          WORK is COMPLEX*16 array, dimension (2*N)
!>

RWORK

!>          RWORK is DOUBLE PRECISION array, dimension (2*N)
!>

INFO

!>          INFO is INTEGER
!>       = 0:  Successful exit. The solution to every right-hand side is
!>         guaranteed.
!>       < 0:  If INFO = -i, the i-th argument had an illegal value
!>       > 0 and <= N:  U(INFO,INFO) is exactly zero.  The factorization
!>         has been completed, but the factor U is exactly singular, so
!>         the solution and error bounds could not be computed. RCOND = 0
!>         is returned.
!>       = N+J: The solution corresponding to the Jth right-hand side is
!>         not guaranteed. The solutions corresponding to other right-
!>         hand sides K with K > J may not be guaranteed as well, but
!>         only the first such right-hand side is reported. If a small
!>         componentwise error is not requested (PARAMS(3) = 0.0) then
!>         the Jth right-hand side is the first with a normwise error
!>         bound that is not guaranteed (the smallest J such
!>         that ERR_BNDS_NORM(J,1) = 0.0). By default (PARAMS(3) = 1.0)
!>         the Jth right-hand side is the first with either a normwise or
!>         componentwise error bound that is not guaranteed (the smallest
!>         J such that either ERR_BNDS_NORM(J,1) = 0.0 or
!>         ERR_BNDS_COMP(J,1) = 0.0). See the definition of
!>         ERR_BNDS_NORM(:,1) and ERR_BNDS_COMP(:,1). To get information
!>         about all of the right-hand sides check ERR_BNDS_NORM or
!>         ERR_BNDS_COMP.
!>
