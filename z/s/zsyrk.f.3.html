Documentación de la función/subrutina

subrutina zsyrk (character uplo, character trans, integer n, integer k, complex*16 alpha, complex*16, dimension(lda,*) a, integer lda, complex*16 beta, complex*16, dimension(ldc,*) c, integer ldc)

ZSYRK

Propósito:

!>
!> ZSYRK  realiza una de las operaciones de rango k simétrico
!>
!>    C := alpha*A*A**T + beta*C,
!>
!> o
!>
!>    C := alpha*A**T*A + beta*C,
!>
!> donde  alpha y beta  son escalares,  C es una matriz simétrica de n por n
!> y  A  es una matriz de n por k  en el primer caso y una matriz de k por n
!> en el segundo caso.
!>

Parámetros

UPLO 
!>          UPLO es CHARACTER*1
!>           A la entrada,   UPLO  especifica si la parte triangular superior
!>           o inferior del array  C  debe ser referenciada como
!>           sigue:
!>
!>              UPLO = 'U' o 'u'   Sólo se hace referencia a la parte triangular superior de C.
!>
!>              UPLO = 'L' o 'l'   Sólo se hace referencia a la parte triangular inferior de C.
!>

TRANS

!>          TRANS es CHARACTER*1
!>           A la entrada,  TRANS  especifica la operación a realizar como
!>           sigue:
!>
!>              TRANS = 'N' o 'n'   C := alpha*A*A**T + beta*C.
!>
!>              TRANS = 'T' o 't'   C := alpha*A**T*A + beta*C.
!>

N

!>          N es INTEGER
!>           A la entrada,  N especifica el orden de la matriz C.  N debe ser
!>           al menos cero.
!>

K

!>          K es INTEGER
!>           A la entrada con  TRANS = 'N' o 'n',  K  especifica el número
!>           de  columnas   de  la   matriz   A,   y  a la entrada   con
!>           TRANS = 'T' o 't',  K  especifica el número de filas de la
!>           matriz A.  K debe ser al menos cero.
!>

ALPHA

!>          ALPHA es COMPLEX*16
!>           A la entrada, ALPHA especifica el escalar alpha.
!>

A

!>          A es un array COMPLEX*16, de dimensión ( LDA, ka ), donde ka es
!>           k  cuando  TRANS = 'N' o 'n',  y es  n  en caso contrario.
!>           Antes de la entrada con  TRANS = 'N' o 'n',  la parte principal
!>           de n por k del array  A  debe contener la matriz  A,  en caso
!>           contrario, la parte principal de k por n del array  A  debe
!>           contener la matriz A.
!>

LDA

!>          LDA es INTEGER
!>           A la entrada, LDA especifica la primera dimensión de A tal como
!>           se declara en  el  (sub)programa  llamador.   Cuando  TRANS = 'N' o 'n'
!>           entonces  LDA debe ser al menos  max( 1, n ), en caso contrario
!>           LDA debe ser al menos  max( 1, k ).
!>

BETA

!>          BETA es COMPLEX*16
!>           A la entrada, BETA especifica el escalar beta.
!>

C

!>          C es un array COMPLEX*16, de dimensión ( LDC, N )
!>           Antes de la entrada con  UPLO = 'U' o 'u',  la parte principal
!>           de n por n del array C debe contener la parte triangular superior
!>           de la matriz simétrica y la parte estrictamente triangular inferior
!>           de C no se referencia.  A la salida, la parte triangular superior
!>           del array  C  se sobrescribe con la parte triangular superior
!>           de la matriz actualizada.
!>           Antes de la entrada con  UPLO = 'L' o 'l',  la parte principal
!>           de n por n del array C debe contener la parte triangular inferior
!>           de la matriz simétrica y la parte estrictamente triangular superior
!>           de C no se referencia.  A la salida, la parte triangular inferior
!>           del array  C  se sobrescribe con la parte triangular inferior
!>           de la matriz actualizada.
!>

LDC

!>          LDC es INTEGER
!>           A la entrada, LDC especifica la primera dimensión de C tal como
!>           se declara en  el  (sub)programa  llamador.   LDC  debe ser
!>           al menos  max( 1, n ).
!>
