ZSYRFS

Propósito:

!>
!> ZSYRFS mejora la solución calculada para un sistema de ecuaciones
!> lineales cuando la matriz de coeficientes es simétrica indefinida, y
!> proporciona cotas de error y estimaciones de error hacia atrás para la solución.
!>

Parámetros

UPLO 
!>          UPLO es CARACTER*1
!>          = 'U':  El triángulo superior de A se almacena;
!>          = 'L':  El triángulo inferior de A se almacena.
!>

N

!>          N es ENTERO
!>          El orden de la matriz A.  N >= 0.
!>

NRHS

!>          NRHS es ENTERO
!>          El número de lados derechos, es decir, el número de columnas
!>          de las matrices B y X.  NRHS >= 0.
!>

A

!>          A es una matriz de COMPLEX*16, dimensión (LDA,N)
!>          La matriz simétrica A.  Si UPLO = 'U', la parte triangular
!>          superior N por N principal de A contiene la parte triangular
!>          superior de la matriz A, y la parte triangular estrictamente
!>          inferior de A no se referencia.  Si UPLO = 'L', la parte
!>          triangular inferior N por N principal de A contiene la parte
!>          triangular inferior de la matriz A, y la parte triangular
!>          estrictamente superior de A no se referencia.
!>

LDA

!>          LDA es ENTERO
!>          La dimensión principal de la matriz A.  LDA >= max(1,N).
!>

AF

!>          AF es una matriz de COMPLEX*16, dimensión (LDAF,N)
!>          La forma factorizada de la matriz A.  AF contiene la matriz
!>          diagonal por bloques D y los multiplicadores utilizados para
!>          obtener U o L de la factorización A = U*D*U**T o
!>          A = L*D*L**T tal como se calculó con ZSYTRF.
!>

LDAF

!>          LDAF es ENTERO
!>          La dimensión principal de la matriz AF.  LDAF >= max(1,N).
!>

IPIV

!>          IPIV es una matriz de ENTEROS, dimensión (N)
!>          Detalles de los intercambios y la estructura de bloques de D
!>          tal como se determinó con ZSYTRF.
!>

B

!>          B es una matriz de COMPLEX*16, dimensión (LDB,NRHS)
!>          La matriz del lado derecho B.
!>

LDB

!>          LDB es ENTERO
!>          La dimensión principal de la matriz B.  LDB >= max(1,N).
!>

X

!>          X es una matriz de COMPLEX*16, dimensión (LDX,NRHS)
!>          En la entrada, la matriz solución X, tal como se calculó con ZSYTRS.
!>          En la salida, la matriz solución mejorada X.
!>

LDX

!>          LDX es ENTERO
!>          La dimensión principal de la matriz X.  LDX >= max(1,N).
!>

FERR

!>          FERR es una matriz de DOBLE PRECISIÓN, dimensión (NRHS)
!>          La cota de error hacia adelante estimada para cada vector solución
!>          X(j) (la j-ésima columna de la matriz solución X).
!>          Si XTRUE es la solución verdadera correspondiente a X(j), FERR(j)
!>          es una cota superior estimada para la magnitud del elemento más
!>          grande en (X(j) - XTRUE) dividido por la magnitud del elemento más
!>          grande en X(j). La estimación es tan fiable como la estimación
!>          para RCOND, y casi siempre es una ligera sobreestimación del error real.
!>

BERR

!>          BERR es una matriz de DOBLE PRECISIÓN, dimensión (NRHS)
!>          El error hacia atrás relativo componente a componente de cada vector solución
!>          X(j) (es decir, el cambio relativo más pequeño en
!>          cualquier elemento de A o B que haga que X(j) sea una solución exacta).
!>

WORK

!>          WORK es una matriz de COMPLEX*16, dimensión (2*N)
!>

RWORK

!>          RWORK es una matriz de DOBLE PRECISIÓN, dimensión (N)
!>

INFO

!>          INFO es ENTERO
!>          = 0:  salida exitosa
!>          < 0:  si INFO = -i, el i-ésimo argumento tenía un valor ilegal
!>

Parámetros internos:

!>  ITMAX es el número máximo de pasos de refinamiento iterativo.
!>
