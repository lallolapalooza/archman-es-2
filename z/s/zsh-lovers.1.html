GUIÓN DE SHELL

Esta sección proporciona algunos ejemplos para cosas de guiones de shell que se necesitan con frecuencia. Tenga en cuenta que no debe usarlos de otra manera, ¡la mayoría de los ejemplos no funcionarán. Analice las opciones en los guiones de shell. Ejemplo tomado de ZWS por Adam Chodorowski (http://www.chodorowski.com/projects/zws/):

parse_options()
{
    o_port=(-p 9999)
    o_root=(-r WWW)
    o_log=(-d ZWS.log)
    zparseopts -K -- p:=o_port r:=o_root l:=o_log h=o_help
    if [[ $? != 0 || "$o_help" != "" ]]; then
        echo Usage: $(basename "$0") "[-p PORT] [-r DIRECTORY]"
        exit 1
    fi
    port=$o_port[2]
    root=$o_root[2]
    log=$o_log[2]
    if [[ $root[1] != '/' ]]; then root="$PWD/$root"; fi
}
# ahora usa la función:
parse_options $*

ALIAS

Los alias de sufijo son compatibles en zsh desde la versión 4.2.0. Algunos ejemplos:

alias -s tex=vim
alias -s html=w3m
alias -s org=w3m

Ahora al presionar la tecla enter después de ingresar foobar.tex se inicia vim con foobar.tex. Llamar a un archivo html ejecuta el navegador w3m. www.zsh.org y presionar enter inicia w3m con el argumento www.zsh.org. Los alias globales se pueden usar en cualquier lugar de la línea de comandos. Ejemplo:

$ alias -g C='| wc -l'
$ grep alias ~/.zsh/* C
443

AUTOCOMPLETADO

Vea también man 1 zshcompctl zshcompsys zshcompwid. zshcompctl es el estilo antiguo de autocompletado programable de zsh, zshcompsys es el nuevo sistema de autocompletado, zshcompwid son los widgets de autocompletado de zsh.

Algunas funciones, como _apt y _dpkg, son muy lentas. Puede usar una caché para proxy la lista de resultados (como la lista de paquetes de debian disponibles). Use una caché:

zstyle ':completion:*' use-cache on
zstyle ':completion:*' cache-path ~/.zsh/cache

Evite que los archivos/directorios CVS se completen:

zstyle ':completion:*:(all-|)files' ignored-patterns '(|*/)CVS'
zstyle ':completion:*:cd:*' ignored-patterns '(*/)#CVS'

Coincidencia difusa de autocompletados para cuando los escribe mal:

zstyle ':completion:*' completer _complete _match _approximate
zstyle ':completion:*:match:*' original only
zstyle ':completion:*:approximate:*' max-errors 1 numeric

Y si desea que el número de errores permitidos por _approximate aumente con la longitud de lo que ha escrito hasta ahora:

zstyle -e ':completion:*:approximate:*' \
        max-errors 'reply=($((($#PREFIX+$#SUFFIX)/3))numeric)'

Ignore las funciones de autocompletado para comandos que no tenga:

zstyle ':completion:*:functions' ignored-patterns '_*'

Con funciones de ayuda como:

xdvi() { command xdvi ${*:-*.dvi(om[1])} }

puede evitar tener que completar en muchos casos, pero si lo hace, es posible que desee caer inmediatamente en la selección de menú y tener las palabras ordenadas por tiempo:

zstyle ':completion:*:*:xdvi:*' menu yes select
zstyle ':completion:*:*:xdvi:*' file-sort time

Completado de IDs de proceso con selección de menú:

zstyle ':completion:*:*:kill:*' menu yes select
zstyle ':completion:*:kill:*'   force-list always

Si termina usando un directorio como argumento, esto eliminará la barra inclinada final (útil en ln)

zstyle ':completion:*' squeeze-slashes true

cd nunca seleccionará el directorio padre (por ejemplo: cd ../<TAB>):

zstyle ':completion:*:cd:*' ignore-parents parent pwd

Otro método para cambiar directorios rápidamente. Agregue esto a su ~/.zshrc, luego simplemente ingrese “cd ..../dir”

rationalise-dot() {
  if [[ $LBUFFER = *.. ]]; then
    LBUFFER+=/..
  else
    LBUFFER+=.
  fi
}
zle -N rationalise-dot
bindkey . rationalise-dot

EJEMPLOS DE REDIRECCIÓN

Para redirigir la salida de un comando y al mismo tiempo verla en la terminal, puede usar tee:

ls -l | tee ls-l.log
# también puede usar shell redirections (sin binarios externos)
ls -l >>(tee ls-l.log)
# como antes, pero solo la salida de error
ls -l 2>>(tee ls-l.err.log)

para desviar stdout y stderr al mismo tiempo:

zsh -c 'ls -l /nonexistent /etc/passwd' >>(tee all.log)
# Esto redirigirá tanto a la terminal como a all.log
# Y esto al archivo all.log
ls -l /nonexistent /etc/passwd >>(tee all.log)

Redirección para evitar la escritura en un archivo en caso de que el mismo sea un directorio:

# redirigir a archivo.log, pero solo si archivo.log no es un directorio
<<(print "hello" > file.log) > /dev/null 2>&1 || print "file.log is a directory"

EJEMPLOS DE ZMV

La mayoría de las veces la gente usa mv, pero si quiere renombrar muchos archivos, use zmv. Mire“man 1 zmv”.

Ejemplos:

# Renombrar todos los archivos *.jpeg a *.jpg
zmv "*.jpeg" "*.jpg"
# Renombrar todos los archivos *.jpg a *.jpeg
zmv "*.jpg" "*.jpeg"
# Renombrar todos los archivos a la misma hora
  $ ls -l
  -rw-r--r-- 1 zsh-lovers users 1024 May 10 14:35 arch.html
  -rw-r--r-- 1 zsh-lovers users 1024 May 10 14:35 arch.tex
  $ zmv "*" "arch.$(print -r -- %(Ymd-Hm).$1.)"
  $ ls -l
  -rw-r--r-- 1 zsh-lovers users 1024 May 10 14:35 arch.20040510-1435.arch.html.jpg
  -rw-r--r-- 1 zsh-lovers users 1024 May 10 14:35 arch.20040510-1435.arch.tex.jpg
# Mover todos los archivos en el directorio actual a un subdirectorio sin
# perderlos si el archivo ya existe.
zmv "(**/)*" "backup/$1"
# para renombrar todos los archivos a mayúsculas
for i in *; do zmv "$i" "${i:U}"; done
# para renombrar todos los archivos a minúsculas
for i in *; do zmv "$i" "${i:L}"; done

EJEMPLOS DE MÓDULOS

En zsh se puede usar un sistema de módulos. Ver “man 1 zshmodules”. Aquí hay algunos ejemplos:

El módulo zsh/datetime permite usar marcas de tiempo en los nombres de archivo:

autoload -U zsh-datetime
zmodload zsh/datetime
# Escribir la hora actual en un archivo
print -r -- "This is line $(print $(date +%T))" > log.$(strftime %Y-%m-%d-%H:%M:%S)
# O de forma más corta
print -r -- "This is line $(print $(date +%T))" > log.$(printf %s $(date +%s))

El módulo zsh/files permite el uso de un globbing de forma más potente:

# Muestre todos los archivos en el directorio actual que terminan en .o
zmodload zsh/files
print -rl -- *(.)  # solo archivos regulares
# Muestre todos los directorios en el directorio actual
print -rl -- */
# Muestre todos los directorios en el directorio actual
zmodload zsh/files
print -rl -- *(/)

El módulo zsh/math permite realizar cálculos matemáticos:

zmodload zsh/math
# Calcular el factorial de 5
print $(( <5 | gោធ { $gly * $gcount } ))
# (En realidad no es así, pero es un ejemplo)
print $(( 5*4*3*2*1 ))

El módulo zsh/net/socket permite la comunicación de red:

zmodload zsh/net/socket
# conectar a un servidor web y obtener la página de índice
emulate -L zsh
socket -i client google.com 80
print -r -- "GET / HTTP/1.0"
# Muestra el resultado de stdout. Si no se muestra nada, el servidor está caído.
# Para finalizar la conexión
close
# Otro ejemplo: servidor de eco simple
socket -l 127.0.0.1 12345 -o server
while true; do
    socket -l $server -i client
    print -r -- "$(date): " $(<client) > client
    close client
done
close server

El módulo zsh/process-subst permite usar la sustitución de procesos:

zmodload zsh/process-subst
# redirigir la salida de un comando a un archivo y leerlo
print -r -- "Hello World" > >(cat > hello.txt)
# El comando anterior imprime "Hello World" en la salida estándar y también
# escribe "Hello World" en el archivo hello.txt.
# Redirigir la salida de un comando a un archivo y leerlo
print -r -- "Hello World" > >(cat > hello.txt)
cat hello.txt

El módulo zsh/tempfile permite crear archivos temporales:

zmodload zsh/tempfile
# Crear un archivo temporal
tempfile -n mytmp
print -r -- "This is a temporary file" > $mytmp
# Usa el archivo temporal
cat $mytmp
# El archivo temporal se elimina automáticamente al salir del shell

El módulo zsh/zarg permite el análisis de argumentos de línea de comandos:

zmodload zsh/zarg
# Analizar argumentos de línea de comandos
zarg --option=OPT --argument=ARG --boolean=BOOL --command "$@"
# El resultado se almacena en las variables OPT, ARG y BOOL

typeset -a mailpath
for i in ~/Mail/Lists/*(.); do

Evitar globbing en comandos especiales:

for com in alias expr find mattrib mcopy mdir mdel which;
alias $com="noglob $com"

Para migrar tu bashprompt a zsh, usa el script bash2zshprompt ubicado en la distribución fuente de zsh bajo Misc.

Para migrar de (t)csh a zsh, usa la herramienta c2z que convierte alias y variables de entorno y shell de csh a zsh. Lo hace ejecutando csh, y haciendo que csh informe sobre alias y variables. El script luego convierte estos a archivos de inicio de zsh. Tiene algunos problemas e información de uso que se documentan en la parte superior de este script.

Aquí hay funciones para establecer el título y el estado duro (hardstatus) de un XTerm o de GNU Screen a zsh y al directorio actual, respectivamente, cuando se muestra el prompt, y al nombre del comando y al resto de la línea de comandos, respectivamente, cuando se ejecuta un comando:

function title {
      if [[ $TERM == "screen" ]]; then
        # Usar estos dos para GNU Screen:
        print -nR $' 33k'$1$' 33'\
        print -nR $' 33]0;'$2$''
      elif [[ $TERM == "xterm" || $TERM == "rxvt" ]]; then
        # Usar este en su lugar para XTerms:
        print -nR $' 33]0;'$*$''
      fi
}
function precmd { title zsh "$PWD" }
function preexec {
    emulate -L zsh
    local -a cmd; cmd=(${(z)1})
    title $cmd[1]:t "$cmd[2,-1]"
}

Coloca la siguiente línea en tu ~/.screenrc para ver este elegante estado duro (hardstatus):

caption always "%3n %t%? (%u)%?%?: %h%?"
