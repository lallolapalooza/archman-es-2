ZSPSVX calcula la solución del sistema de ecuaciones lineales A * X = B para matrices OTROS

Propósito:

!>
!> ZSPSVX utiliza la factorización de pivoteo diagonal A = U*D*U**T o
!> A = L*D*L**T para calcular la solución de un sistema complejo de ecuaciones
!> lineales A * X = B, donde A es una matriz simétrica de N por N almacenada
!> en formato empaquetado y X e B son matrices de N por NRHS.
!>
!> También se proporcionan cotas de error en la solución y una estimación
!> de la condición.
!>

Descripción:

!>
!> Se realizan los siguientes pasos:
!>
!> 1. Si FACT = 'N', se utiliza el método de pivoteo diagonal para factorizar A como
!>       A = U * D * U**T,  si UPLO = 'U', o
!>       A = L * D * L**T,  si UPLO = 'L',
!>    donde U (o L) es un producto de matrices triangulares superiores (inferiores)
!>    unitarias y de permutación, y D es simétrica y diagonal por bloques
!>    con bloques diagonales de 1x1 y 2x2.
!>
!> 2. Si algún D(i,i)=0, de modo que D es exactamente singular, la rutina
!>    regresa con INFO = i. De lo contrario, la forma factorizada de A se usa
!>    para estimar el número de condición de la matriz A. Si el
!>    recíproco del número de condición es menor que la precisión de la máquina,
!>    se devuelve INFO = N+1 como advertencia, pero la rutina continúa
!>    resolviendo para X y calculando cotas de error como se describe a
!>    continuación.
!>
!> 3. Se resuelve el sistema de ecuaciones para X utilizando la forma
!>    factorizada de A.
!>
!> 4. Se aplica refinamiento iterativo para mejorar la solución calculada
!>    y calcular cotas de error y estimaciones de error hacia atrás para ella.
!>

Parámetros

FACT 
!>          FACT es CHARACTER*1
!>          Especifica si la forma factorizada de A ha sido
!>          suministrada en la entrada.
!>          = 'F':  En la entrada, AFP y IPIV contienen la forma factorizada
!>                  de A.  AP, AFP e IPIV no se modificarán.
!>          = 'N':  La matriz A se copiará a AFP y se factorizará.
!>

UPLO

!>          UPLO es CHARACTER*1
!>          = 'U':  Se almacena el triángulo superior de A;
!>          = 'L':  Se almacena el triángulo inferior de A.
!>

N

!>          N es INTEGER
!>          El número de ecuaciones lineales, es decir, el orden de la
!>          matriz A.  N >= 0.
!>

NRHS

!>          NRHS es INTEGER
!>          El número de lados derechos, es decir, el número de columnas
!>          de las matrices B y X.  NRHS >= 0.
!>

AP

!>          AP es una matriz COMPLEX*16, dimensión (N*(N+1)/2)
!>          El triángulo superior o inferior de la matriz simétrica A, empaquetado
!>          por columnas en un array lineal.  La j-ésima columna de A se almacena
!>          en el array AP como sigue:
!>          si UPLO = 'U', AP(i + (j-1)*j/2) = A(i,j) para 1<=i<=j;
!>          si UPLO = 'L', AP(i + (j-1)*(2*n-j)/2) = A(i,j) para j<=i<=n.
!>          Ver más abajo para más detalles.
!>

AFP

!>          AFP es una matriz COMPLEX*16, dimensión (N*(N+1)/2)
!>          Si FACT = 'F', entonces AFP es un argumento de entrada y en la entrada
!>          contiene la matriz diagonal por bloques D y los multiplicadores utilizados
!>          para obtener el factor U o L de la factorización
!>          A = U*D*U**T o A = L*D*L**T calculada por ZSPTRF, almacenada como
!>          una matriz triangular empaquetada en el mismo formato de almacenamiento que A.
!>
!>          Si FACT = 'N', entonces AFP es un argumento de salida y en la salida
!>          contiene la matriz diagonal por bloques D y los multiplicadores utilizados
!>          para obtener el factor U o L de la factorización
!>          A = U*D*U**T o A = L*D*L**T calculada por ZSPTRF, almacenada como
!>          una matriz triangular empaquetada en el mismo formato de almacenamiento que A.
!>

IPIV

!>          IPIV es una matriz INTEGER, dimensión (N)
!>          Si FACT = 'F', entonces IPIV es un argumento de entrada y en la entrada
!>          contiene detalles de los intercambios y la estructura de bloques
!>          de D, según lo determinado por ZSPTRF.
!>          Si IPIV(k) > 0, entonces las filas y columnas k e IPIV(k) fueron
!>          intercambiadas y D(k,k) es un bloque diagonal de 1x1.
!>          Si UPLO = 'U' e IPIV(k) = IPIV(k-1) < 0, entonces las filas y
!>          columnas k-1 y -IPIV(k) fueron intercambiadas y D(k-1:k,k-1:k)
!>          es un bloque diagonal de 2x2. Si UPLO = 'L' e IPIV(k) =
!>          IPIV(k+1) < 0, entonces las filas y columnas k+1 y -IPIV(k) fueron
!>          intercambiadas y D(k:k+1,k:k+1) es un bloque diagonal de 2x2.
!>
!>          Si FACT = 'N', entonces IPIV es un argumento de salida y en la salida
!>          contiene detalles de los intercambios y la estructura de bloques
!>          de D, según lo determinado por ZSPTRF.
!>

B

!>          B es una matriz COMPLEX*16, dimensión (LDB,NRHS)
!>          La matriz B del lado derecho de NRHS columnas de tamaño N.
!>

LDB

!>          LDB es INTEGER
!>          La dimensión principal del array B.  LDB >= max(1,N).
!>

X

!>          X es una matriz COMPLEX*16, dimensión (LDX,NRHS)
!>          Si INFO = 0 o INFO = N+1, la matriz solución X de NRHS columnas de tamaño N.
!>

LDX

!>          LDX es INTEGER
!>          La dimensión principal del array X.  LDX >= max(1,N).
!>

RCOND

!>          RCOND es DOUBLE PRECISION
!>          La estimación del recíproco del número de condición de la matriz
!>          A.  Si RCOND es menor que la precisión de la máquina (en
!>          particular, si RCOND = 0), la matriz es singular con precisión de trabajo.
!>          Esta condición se indica con un código de retorno de
!>          INFO > 0.
!>

FERR

!>          FERR es una matriz DOUBLE PRECISION, dimensión (NRHS)
!>          La cota de error hacia adelante estimada para cada vector solución
!>          X(j) (la j-ésima columna de la matriz solución X).
!>          Si XTRUE es la solución verdadera correspondiente a X(j), FERR(j)
!>          es una cota superior estimada para la magnitud del elemento más grande
!>          en (X(j) - XTRUE) dividido por la magnitud del elemento más grande
!>          en X(j). La estimación es tan confiable como
!>          la estimación para RCOND, y es casi siempre una ligera
!>          sobreestimación del error verdadero.
!>

BERR

!>          BERR es una matriz DOUBLE PRECISION, dimensión (NRHS)
!>          El error hacia atrás relativo componente a componente de cada vector solución
!>          X(j) (es decir, el cambio relativo más pequeño en
!>          cualquier elemento de A o B que haga que X(j) sea una solución exacta).
!>

WORK

!>          WORK es una matriz COMPLEX*16, dimensión (2*N)
!>

RWORK

!>          RWORK es una matriz DOUBLE PRECISION, dimensión (N)
!>

INFO

!>          INFO es INTEGER
!>          = 0: salida exitosa
!>          < 0: si INFO = -i,

zspsvx(3) — LAPACK

NAME

zspsvx — General complex double precision general matrix $N \times N$ solved by sparse Cholesky factorization.

SYNOPSIS

CALL ZSPSVX(
     & FACT, UPLO, N, NRHS, ABSTOL, DLAMCH, A, LDA, AFAC, LDAFAC, IPIV, B,
     & LDB, X, LDX, RCOND, FERR, BERR, INFO)

Reads from arguments. Writes to arguments.

Function/Subroutine Documentation

This subroutine computes the solution to a complex double precision system of linear equations

$A X = B$,

where A is an N x N symmetric or Hermitian positive-definite sparse matrix, X and B are N x NRHS matrices, and AP is a structure of dimension N*(N+1)/2 that represents the packed storage of the upper or lower triangles of A.

Before calling ZSPSVX, ZSPTRF is called to compute the factorization of A.

The packed storage scheme is illustrated by the following example when N = 4, UPLO = 'U':

Two-dimensional storage of the symmetric matrix A:

a11 a12 a13 a14
                            a22 a23 a24
                                a33 a34
                                    a44

Packed storage of the upper triangle of A:

AP = [ a11, a12, a22, a13, a23, a33, a14, a24, a34, a44 ]

When UPLO = 'L', the packed storage of the lower triangle of A is represented similarly.

The routine ZSPSVX also uses DLAMCH to determine machine precision.

Arguments

FACT
CHARACTER*1.
On entry, FACT specifies whether or not the factorization of the matrix A has been computed by an earlier call to ZSPTRF.
'N': The solution to be computed and the factorization is to be performed.
'F': The factorisation is already computed; the arrays A and AFAC contain details of the factorisation. Only the solution is to be computed.
FACT must be one of 'N' or 'F'.
UPLO
CHARACTER*1.
On entry, UPLO specifies whether the upper or lower triangular part of the symmetric matrix A is stored in the array AP and how the matrix is stored in the array A.
'U': Upper triangle of A is stored.
'L': Lower triangle of A is stored.
UPLO must be one of 'U' or 'L'.
N
INTEGER.
The order of the matrix A. N >= 0.
NRHS
INTEGER.
The number of right-hand sides, i.e., the number of columns of the matrices B and X. NRHS >= 0.
ABSTOL
REAL.
The absolute tolerance to be used for determining the vector x. A smaller value of ABSTOL can be used to intensify the search for a more accurate solution. If ABSTOL is negative, the default value of DLAMCH('S') is used.
This argument is ignored if FACT = 'F'.
DLAMCH
REAL FUNCTION
DLAMCH is an auxiliary function that returns the machine precision.
A
REAL array, DIMENSION (LDA,N).
Before entry, the N x N matrix A.
If FACT = 'F', then A must contain the details of the factorization of A as returned by ZSPTRF.
On exit, if FACT = 'N', the LDU decomposition of A is stored in the array A. The diagonal elements of U are not explicitly stored.
LDA
INTEGER.
The leading dimension of the array A. LDA >= max(1,N).
AFAC
REAL array, DIMENSION (LDAFAC, N).
If FACT = 'F', AFAC is an input argument and on entry contains the details of the LU factorization of A as computed by ZSPTRF.
If FACT = 'N', AFAC is output argument and on exit contains the factored matrix A.
The packed storage scheme is used for AP, so the actual storage required is less than or equal to N*(N+1)/2.
LDAFAC
INTEGER.
The leading dimension of the array AFAC.
IPIV
INTEGER array, DIMENSION (N).
On exit, IPIV contains the pivot indices of the factorization. The pivot rows are denoted by entries in IPIV. For 1 <= K <= N, the diagonal element that was moved from row K of A (or U) is in row (IPIV(K)) of U (or L).
B
REAL array, DIMENSION (LDB,NRHS).
On entry, the N x NRHS right-hand side matrix B.
On exit, if NRHS = 1, B is overwritten with the solution vector X.
If NRHS > 1, B is overwritten with the solutions for the corresponding right-hand sides.
LDB
INTEGER.
The leading dimension of the array B. LDB >= max(1,N).
X
REAL array, DIMENSION (LDX,NRHS).
On exit, X contains the solution to the system of equations. If NRHS = 1, X may be omitted and B may instead be overwritten by the solution X.
LDX
INTEGER.
The leading dimension of the array X. LDX >= max(1,N).
RCOND
REAL.
On exit, RCOND is an estimate of the reciprocal of the condition number of the matrix A. The pair ( RCOND, FERR ) are the computed and estimated forward error bounds for each solution vector X(j) and the corresponding right hand side vector B(:,j).
FERR
REAL array, DIMENSION (NRHS).
On exit, FERR(j) is an estimate of the forward error bound for the j-th solution vector, that is, the relative error in the j-th solution vector X(*,j), and an upper bound on it.
BERR
REAL array, DIMENSION (NRHS).
On exit, BERR(j) is the componentwise relative backward error of the j-th solution vector X(*,j) with respect to the right-hand side vector B(:,j).
INFO
INTEGER.
On exit, INFO is an integer value indicating the status of the execution.

Info

On exit, INFO indicates the status of the execution.

> 0:  If INFO = i, and i is
                                <= N:  D(i,i) is exactly zero.  The factorization
                                       has been completed but the factor D is exactly
                                       singular, so the solution and error bounds could
                                       not be computed. RCOND = 0 is returned.
                                = N+1: D is nonsingular, but RCOND is less than machine
                                       precision, meaning that the matrix is singular
                                       to working precision.  Nevertheless, the
                                       solution and error bounds are computed because
                                       there are a number of situations where the
                                       computed solution can be more accurate than the
                                       value of RCOND would suggest.
