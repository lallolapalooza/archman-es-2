Documentación de Función/Subrutina

subrutina zstegr (character jobz, character range, integer n, double precision, dimension( * ) d, double precision, dimension( * ) e, double precision vl, double precision vu, integer il, integer iu, double precision abstol, integer m, double precision, dimension( * ) w, complex*16, dimension( ldz, * ) z, integer ldz, integer, dimension( * ) isuppz, double precision, dimension( * ) work, integer lwork, integer, dimension( * ) iwork, integer liwork, integer info)

ZSTEGR

Propósito:

!>
!> ZSTEGR calcula valores propios y, opcionalmente, vectores propios
!> seleccionados de una matriz tridiagonal simétrica real T. Cualquier matriz
!> no reducida de este tipo tiene un conjunto bien definido de valores propios
!> reales distintos por pares, los vectores propios reales correspondientes son
!> ortogonales por pares.
!>
!> El espectro puede calcularse completa o parcialmente especificando
!> ya sea un intervalo (VL,VU] o un rango de índices IL:IU para los valores
!> propios deseados.
!>
!> ZSTEGR es un envoltorio de compatibilidad sobre la rutina mejorada ZSTEMR.
!> Consulte ZSTEMR para más detalles.
!>
!> Un cambio importante es que el parámetro ABSTOL ya no proporciona ningún
!> beneficio y, por lo tanto, ya no se utiliza.
!>
!> Nota: ZSTEGR y ZSTEMR solo funcionan en máquinas que siguen el
!> estándar de punto flotante IEEE-754 en su manejo de infinitos y
!> NaNs. La ejecución normal puede crear estos valores excepcionales y, por lo
!> tanto, puede abortar debido a una excepción de punto flotante en entornos que
!> no se ajustan al estándar IEEE-754.
!>

Parámetros

JOBZ 
!>          JOBZ es CHARACTER*1
!>          = 'N':  Calcula solo los valores propios;
!>          = 'V':  Calcula los valores propios y los vectores propios.
!>

RANGE

!>          RANGE es CHARACTER*1
!>          = 'A': se encontrarán todos los valores propios.
!>          = 'V': se encontrarán todos los valores propios en el intervalo semiabierto (VL,VU]
!>                 (VL,VU].
!>          = 'I': se encontrarán los valores propios desde el índice IL hasta el IU.
!>

N

!>          N es INTEGER
!>          El orden de la matriz.  N >= 0.
!>

D

!>          D es un array DOUBLE PRECISION, dimensión (N)
!>          En la entrada, los N elementos diagonales de la matriz tridiagonal
!>          T. En la salida, D se sobrescribe.
!>

E

!>          E es un array DOUBLE PRECISION, dimensión (N)
!>          En la entrada, los (N-1) elementos subdiagonales de la matriz
!>          tridiagonal T en los elementos 1 a N-1 de E. E(N) no necesita ser
!>          establecido en la entrada, pero se utiliza internamente como espacio de trabajo.
!>          En la salida, E se sobrescribe.
!>

VL

!>          VL es DOUBLE PRECISION
!>
!>          Si RANGE='V', el límite inferior del intervalo a
!>          buscar para los valores propios. VL < VU.
!>          No se hace referencia si RANGE = 'A' o 'I'.
!>

VU

!>          VU es DOUBLE PRECISION
!>
!>          Si RANGE='V', el límite superior del intervalo a
!>          buscar para los valores propios. VL < VU.
!>          No se hace referencia si RANGE = 'A' o 'I'.
!>

IL

!>          IL es INTEGER
!>
!>          Si RANGE='I', el índice del
!>          valor propio más pequeño a devolver.
!>          1 <= IL <= IU <= N, si N > 0.
!>          No se hace referencia si RANGE = 'A' o 'V'.
!>

IU

!>          IU es INTEGER
!>
!>          Si RANGE='I', el índice del
!>          valor propio más grande a devolver.
!>          1 <= IL <= IU <= N, si N > 0.
!>          No se hace referencia si RANGE = 'A' o 'V'.
!>

ABSTOL

!>          ABSTOL es DOUBLE PRECISION
!>          No utilizado. Era la tolerancia de error absoluto para los
!>          valores propios/vectores propios en versiones anteriores.
!>

M

!>          M es INTEGER
!>          El número total de valores propios encontrados.  0 <= M <= N.
!>          Si RANGE = 'A', M = N, y si RANGE = 'I', M = IU-IL+1.
!>

W

!>          W es un array DOUBLE PRECISION, dimensión (N)
!>          Los primeros M elementos contienen los valores propios seleccionados en
!>          orden ascendente.
!>

Z

!>          Z es un array COMPLEX*16, dimensión (LDZ, max(1,M))
!>          Si JOBZ = 'V', y si INFO = 0, entonces las primeras M columnas de Z
!>          contienen los vectores propios ortonormales de la matriz T
!>          correspondientes a los valores propios seleccionados, con la i-ésima
!>          columna de Z conteniendo el vector propio asociado con W(i).
!>          Si JOBZ = 'N', entonces Z no se utiliza.
!>          Nota: el usuario debe asegurarse de que se suministran al menos max(1,M)
!>          columnas en el array Z; si RANGE = 'V', el valor exacto de M
!>          no se conoce de antemano y se debe usar un límite superior.
!>          Suministrar N columnas es siempre seguro.
!>

LDZ

!>          LDZ es INTEGER
!>          La dimensión principal del array Z.  LDZ >= 1, y si
!>          JOBZ = 'V', entonces LDZ >= max(1,N).
!>

ISUPPZ

!>          ISUPPZ es un array INTEGER, dimensión ( 2*max(1,M) )
!>          El soporte de los vectores propios en Z, es decir, los índices
!>          que indican los elementos distintos de cero en Z. El i-ésimo vector propio
!>          calculado es distinto de cero solo en los elementos ISUPPZ( 2*i-1 )
!>          a ISUPPZ( 2*i ). Esto es relevante en el caso de que la matriz
!>          se divida. ISUPPZ solo se accede cuando JOBZ es 'V' y N > 0.
!>

WORK

!>          WORK es un array DOUBLE PRECISION, dimensión (LWORK)
!>          En la salida, si INFO = 0, WORK(1) devuelve el LWORK óptimo
!>          (y mínimo).
!>

LWORK

!>          LWORK es INTEGER
!>          La dimensión del array WORK. LWORK >= max(1,18*N)
!>          si JOBZ = 'V', y LWORK >= max(1,12*N) si JOBZ = 'N'.
!>          Si LWORK = -1, entonces se asume una consulta de espacio de trabajo; la rutina
!>          solo calcula el tamaño óptimo del array WORK, devuelve
!>          este valor como la primera entrada del array WORK, y XERBLA no emite ningún mensaje de error
!>          relacionado con LWORK.
!>

IWORK

!>          IWORK es un array INTEGER, dimensión (LIWORK)
!>          En la salida, si INFO = 0, IWORK(1) devuelve el LIWORK óptimo.
!>

LIWORK

!>          LIWORK es INTEGER
!>          La dimensión del array IWORK.  LIWORK >= max(1,10*N)
!>          si se desean los vectores propios, y LIWORK >= max(1,8*N)
!>          si solo se deben calcular los valores propios.
!>          Si LIWORK = -1, entonces se asume una consulta de espacio de trabajo; la
!>          rutina solo calcula el tamaño óptimo del array IWORK,
!>          devuelve este valor como la primera entrada del array IWORK, y
!>          XERBLA no emite ningún mensaje de error relacionado con LIWORK.
!>

INFO

!>          INFO es INTEGER
!>          En la salida, INFO
!>          = 0:  salida exitosa
!>          < 0:  si INFO = -i, el i-ésimo argumento tenía un valor ilegal
!>          > 0:  si INFO = 1X, error interno en DLARRE,
!>                si INFO = 2X, error interno en ZLARRV.
!>                Aquí, el dígito X = ABS( IINFO ) < 10, donde IINFO es
!>                el código de error distinto de cero devuelto por DLARRE o
!>

NAME

ZSTEGR — routine to compute the eigenvalues and eigenvectors of a general non-symmetric tridiagonal matrix.

SYNOPSIS

 SUBROUTINE ZSTEGR(
  JOBZ, N, D, E, CDIAG, LDACDIAG, VL, VLE, ADRB, VRI, VRR,
  TEMP, WORK, INFO )

CHARACTER * 1 JOBZ

INTEGER N

DOUBLE PRECISION D( * )

DOUBLE PRECISION E( * )

DOUBLE PRECISION CDIAG( LDACDIAG, * )

INTEGER LDACDIAG

DOUBLE PRECISION VL( * )

DOUBLE PRECISION VLE( * )

DOUBLE PRECISION ADRB( * )

DOUBLE PRECISION VRI( * )

DOUBLE PRECISION VRR( * )

DOUBLE PRECISION TEMP( * )

DOUBLE PRECISION WORK( * )

INTEGER INFO

Function/Subroutine Documentation

ZSTEGR computes the eigenvalues and eigenvectors of a general non-symmetric tridiagonal matrix T.

The tridiagonal matrix T is defined as:

 T = diag(D) + diag(E, 1) + diag(E, -1)

where diag(A, k) is a diagonal matrix with vector A on the k-th super- and subdiagonal.

Arguments:

JOBZ
CHARACTER * 1.
Specifies whether to compute the eigenvectors.
If JOBZ = 'N', then only the eigenvalues are computed.
If JOBZ = 'V', then the eigenvalues and eigenvectors are computed.
N
INTEGER.
The order of the matrix T. N >= 0.
D
DOUBLE PRECISION array, dimension (N).
On entry, the vector D contains the diagonal elements of T.
On exit, D contains the eigenvalues of T, sorted in ascending order.
E
DOUBLE PRECISION array, dimension (N-1).
On entry, E contains the subdiagonal elements of T.
On exit, E is overwritten.
CDIAG
DOUBLE PRECISION array, dimension (LDACDIAG, N).
On entry, C(i, j) contains the j-th element of the i-th row of the matrix C.
On exit, C(i, j) contains the j-th element of the i-th row of the matrix C*.
LDACDIAG
INTEGER.
The leading dimension of the array C.
If JOBZ = 'N', LDACDIAG need not be specified.
VL
DOUBLE PRECISION array, dimension (N).
On exit, if JOBZ = 'V', VL contains the left eigenvectors of T, such that VL(i, j) is the i-th component of the j-th left eigenvector.
VLE
DOUBLE PRECISION array, dimension (N).
On exit, if JOBZ = 'V', VLE contains the relative error bounds for the corresponding eigenvectors in VL.
ADRB
DOUBLE PRECISION array, dimension (N).
On exit, ADRB(i) contains the i-th diagonal element of the matrix R.
VRI
DOUBLE PRECISION array, dimension (N).
On exit, if JOBZ = 'V', VRI contains the imaginary parts of the right eigenvectors of T.
VRR
DOUBLE PRECISION array, dimension (N).
On exit, if JOBZ = 'V', VRR contains the real parts of the right eigenvectors of T.
TEMP
DOUBLE PRECISION array, dimension (N).
Workspace array.
WORK
DOUBLE PRECISION array, dimension (N).
Workspace array.
INFO
INTEGER.

= 0: successful exit

= > 0: if INFO is the number of unconverged eigenvalues, then the eigenvectors corresponding to the largest eigenvalues do not converge.
