ZDRVRFP

Propósito:

!>
!> ZDRVRFP prueba las rutinas RFP de LAPACK:
!>     ZPFTRF, ZPFTRS, y ZPFTRI.
!>
!> Esta rutina de prueba sigue las mismas pruebas que ZDRVPO (prueba para el
!> solucionador Simétrico Definido Positivo en formato completo).
!>
!> Las pruebas se realizan en formato completo, la conversión de ida y vuelta
!> desde formato completo a formato RFP se realiza utilizando las rutinas ZTRTTF y
!> ZTFTTR.
!>
!> Primero, se crea una matriz específica A de tamaño N. Hay nueve tipos de
!> matrices diferentes posibles.
!>  1. Diagonal                        6. Aleatoria, CNDNUM = sqrt(0.1/EPS)
!>  2. Aleatoria, CNDNUM = 2              7. Aleatoria, CNDNUM = 0.1/EPS
!> *3. Primera fila y columna cero       8. Escalada cerca de subdesbordamiento
!> *4. Última fila y columna cero        9. Escalada cerca de desbordamiento
!> *5. Fila y columna central cero
!> (* - prueba las salidas de error de ZPFTRF, no se calculan ratios de prueba)
!> Se crea una solución XACT de tamaño N-por-NRHS y el lado derecho asociado B.
!> Luego se llama a ZPFTRF para calcular L (o U), el factor de Cholesky de A.
!> Luego L (o U) se usa para resolver el sistema lineal de ecuaciones AX = B.
!> Esto da X. Luego L (o U) se usa para calcular la inversa de A, AINV.
!> Luego se realizan las siguientes cuatro pruebas:
!> (1) norm( L*L' - A ) / ( N * norm(A) * EPS ) o
!>     norm( U'*U - A ) / ( N * norm(A) * EPS ),
!> (2) norm(B - A*X) / ( norm(A) * norm(X) * EPS ),
!> (3) norm( I - A*AINV ) / ( N * norm(A) * norm(AINV) * EPS ),
!> (4) ( norm(X-XACT) * RCOND ) / ( norm(XACT) * EPS ),
!> donde EPS es la precisión de la máquina, RCOND el número de condición de A, y
!> norm( . ) la norma 1 para (1,2,3) y la norma inf para (4).
!> Ocurren errores cuando el parámetro INFO no es el esperado. Fallan cuando
!> un ratio de prueba es mayor que THRES.
!>

NAME

zdrvrfp - Driver routines for LAPACK

SYNOPSIS

SUBROUTINE ZDRVRFP (
   NMAX, NTYPS, NTESTS, DWORK, IWORK, RESULT,
   GETRF, GETRI, GEQRF, GELS, GESV,

   H, LDH, IPIV, INFO
)

Function/Subroutine Documentation

This routine is a driver routine for LAPACK. It is used to test the correctness of the LAPACK routines for general matrix computations.

The routine takes as input:

  • NMAX: Maximum dimension of the matrices.
  • NTYPS: Number of matrix types to test.
  • NTESTS: Number of tests to perform.
  • DWORK: Double precision work array.
  • IWORK: Integer work array.
  • RESULT: Real array to store the results of the tests.
  • GETRF, GETRI, GEQRF, GELS, GESV: Logical flags to indicate whether to test these routines.
  • LWORK, LIWORK, LRESLT, LDRVRFP, LGETRF, LGETRI, LGEQRF, LGELS, LGESV: Lengths of the work and result arrays.
  • UPLO: String indicating whether to use upper or lower triangular matrices.
  • TRANS: String indicating whether to use the transpose of a matrix.
  • EQUED: String indicating whether the matrix has been equilibrated.
  • A, LDA: Matrix A and its leading dimension.
  • B, LDB: Matrix B and its leading dimension.
  • X, LDX: Matrix X and its leading dimension.
  • Y, LDY: Matrix Y and its leading dimension.
  • C, LDC: Matrix C and its leading dimension.
  • D, LDD: Matrix D and its leading dimension.
  • E, LDE: Matrix E and its leading dimension.
  • F, LDF: Matrix F and its leading dimension.
  • G, LDG: Matrix G and its leading dimension.
  • H, LDH: Matrix H and its leading dimension.
  • IPIV: Integer array for pivot information.
  • INFO: Integer flag indicating the status of the computation.

The routine performs the following tests:

  • GETRF: LU factorization.
  • GETRI: Inverse of a matrix using LU factorization.
  • GEQRF: QR factorization.
  • GELS: Solves a linear system using QR factorization.
  • GESV: Solves a linear system using LU factorization.
