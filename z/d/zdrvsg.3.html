!>      ZDRVSG comprueba los drivers generalizados del problema de eigenvalores
!>      hermitianos complejos.
!>
!>              ZHEGV calcula todos los valores propios y, opcionalmente,
!>              los vectores propios de un problema generalizado de eigenvalores
!>              hermitiano-definido complejo.
!>
!>              ZHEGVD calcula todos los valores propios y, opcionalmente,
!>              los vectores propios de un problema generalizado de eigenvalores
!>              hermitiano-definido complejo utilizando un algoritmo de divide y vencerás.
!>
!>              ZHEGVX calcula valores propios seleccionados y, opcionalmente,
!>              vectores propios de un problema generalizado de eigenvalores
!>              hermitiano-definido complejo.
!>
!>              ZHPGV calcula todos los valores propios y, opcionalmente,
!>              los vectores propios de un problema generalizado de eigenvalores
!>              hermitiano-definido complejo en almacenamiento empaquetado.
!>
!>              ZHPGVD calcula todos los valores propios y, opcionalmente,
!>              los vectores propios de un problema generalizado de eigenvalores
!>              hermitiano-definido complejo en almacenamiento empaquetado
!>              utilizando un algoritmo de divide y vencerás.
!>
!>              ZHPGVX calcula valores propios seleccionados y, opcionalmente,
!>              vectores propios de un problema generalizado de eigenvalores
!>              hermitiano-definido complejo en almacenamiento empaquetado.
!>
!>              ZHBGV calcula todos los valores propios y, opcionalmente,
!>              los vectores propios de un problema generalizado de eigenvalores
!>              hermitiano-definido complejo en banda.
!>
!>              ZHBGVD calcula todos los valores propios y, opcionalmente,
!>              los vectores propios de un problema generalizado de eigenvalores
!>              hermitiano-definido complejo en banda utilizando un algoritmo de
!>              divide y vencerás.
!>
!>              ZHBGVX calcula valores propios seleccionados y, opcionalmente,
!>              vectores propios de un problema generalizado de eigenvalores
!>              hermitiano-definido complejo en banda.
!>
!>      Cuando se llama a ZDRVSG, se especifican un número de tamaños de matriz y
!>      un número de tipos de matriz. Para cada tamaño () y cada tipo de matriz, se
!>      generará una matriz A del tipo dado; también se generará una matriz B aleatoria
!>      bien condicionada y el par (A,B) se utilizará para probar los drivers.
!>
!>      Para cada par (A,B), se realizan las siguientes pruebas:
!>
!>      (1) ZHEGV con ITYPE = 1 y UPLO ='U':
!>
!>              | A Z - B Z D | / ( |A| |Z| n ulp )
!>
!>      (2) como (1) pero llamando a ZHPGV
!>      (3) como (1) pero llamando a ZHBGV
!>      (4) como (1) pero con UPLO = 'L'
!>      (5) como (4) pero llamando a ZHPGV
!>      (6) como (4) pero llamando a ZHBGV
!>
!>      (7) ZHEGV con ITYPE = 2 y UPLO ='U':
!>
!>              | A B Z - Z D | / ( |A| |Z| n ulp )
!>
!>      (8) como (7) pero llamando a ZHPGV
!>      (9) como (7) pero con UPLO = 'L'
!>      (10) como (9) pero llamando a ZHPGV
!>
!>      (11) ZHEGV con ITYPE = 3 y UPLO ='U':
!>
!>              | B A Z - Z D | / ( |A| |Z| n ulp )
!>
!>      (12) como (11) pero llamando a ZHPGV
!>      (13) como (11) pero con UPLO = 'L'
!>      (14) como (13) pero llamando a ZHPGV
!>
!>      ZHEGVD, ZHPGVD y ZHBGVD realizaron las mismas 14 pruebas.
!>
!>      ZHEGVX, ZHPGVX y ZHBGVX realizaron las pruebas anteriores de 14 con
!>      los parámetros RANGE = 'A', 'N' e 'I', respectivamente.
!>
!>      Los se especifican mediante un array NN(1:NSIZES); el valor de
!>      cada elemento NN(j) especifica un tamaño.
!>      Los se especifican mediante un array lógico DOTYPE( 1:NTYPES );
!>      si DOTYPE(j) es .TRUE., entonces se generará el tipo de matriz .
!>      Este tipo se utiliza para la matriz A que tiene un semi-ancho de banda KA.
!>      B se genera como una matriz definida positiva bien condicionada
!>      con un semi-ancho de banda KB (<= KA).

!>      (1) La matriz cero.

!>
!>      (3) Una matriz diagonal con entradas espaciadas uniformemente
!>           1, ..., ULP y signos aleatorios.

!>      (4) Una matriz diagonal con entradas espaciadas geométricamente

!>

!>      (7) Igual que (4), pero multiplicada por SQRT( umbral de subdesbordamiento )
!>
!>      (8) Una matriz de la forma U* D U, donde U es unitaria y
!>           D tiene entradas espaciadas uniformemente 1, ..., ULP con signos aleatorios
!>           en la diagonal.
!>
!>      (9) Una matriz de la forma U* D U, donde U es unitaria y
!>           D tiene entradas espaciadas geométricamente 1, ..., ULP con signos aleatorios
!>           en la diagonal.
!>
!>      (10) Una matriz de la forma U* D U, donde U es unitaria y
!>           D tiene entradas 1, ULP,..., ULP con signos aleatorios
!>           en la diagonal.
!>
!>      (11) Igual que (8), pero multiplicada por SQRT( umbral de desbordamiento )
!>      (12) Igual que (8), pero multiplicada por SQRT( umbral de subdesbordamiento )
!>
!>      (13) Matriz hermitiana con entradas aleatorias elegidas de (-1,1).
!>      (14) Igual que (13), pero multiplicada por SQRT( umbral de desbordamiento )
!>      (15) Igual que (13), pero multiplicada por SQRT( umbral de subdesbordamiento )
!>
!>      (16) Igual que (8), pero con KA = 1 y KB = 1
!>      (17) Igual que (8), pero con KA = 2 y KB = 1
!>      (18) Igual que (8), pero con KA = 2 y KB = 2
!>      (19) Igual que (8), pero con KA = 3 y KB = 1
!>      (20) Igual que (8), pero con KA = 3 y KB = 2
!>      (21) Igual que (8), pero con KA = 3 y KB = 3

NAME

zdrvsg - This subroutine generates random matrices and checks routines that reduce a general matrix A to upper triangular form and a Hermitian positive definite matrix B to upper triangular form.

SYNOPSIS

     NN, NTYPES, DOTYPE, ISEED, THRESH, NOUNIT,
     A, LDA, B, LDB, D, Z, LDZ,
     AB, BB, AP, BP, WORK, NWORK, RWORK, LRWORK,
     IWORK, LIWORK, RESULT, INFO
 )

Function/Subroutine Documentation

NN

INTEGER array, dimension (NSIZES)

The sizes of the matrices to be generated. NN(j) contains the size of the j-th matrix to be generated.

Not modified.

NTYPES

INTEGER

The number of types of matrices to be generated.

Not modified.

DOTYPE

LOGICAL array, dimension (NTYPES)

If DOTYPE(j) is .TRUE., then for each size in NN a matrix of that size and of type j will be generated. If NTYPES is smaller than the maximum number of types defined (PARAMETER MAXTYP), then types NTYPES+1 through MAXTYP will not be generated. If NTYPES is larger than MAXTYP, DOTYPE(MAXTYP+1) through DOTYPE(NTYPES) will be ignored.

Not modified.

ISEED

INTEGER array, dimension (4)

On entry ISEED specifies the seed of the random number generator. The array elements should be between 0 and 4095; if not they will be reduced mod 4096. Also, ISEED(4) must be odd. The random number generator uses a linear congruential sequence limited to small integers, and so should produce machine independent random numbers. The values of ISEED are changed on exit, and can be used in the next call to ZDRVSG to continue the same random number sequence.

Modified.

THRESH

DOUBLE PRECISION

A test will count as if the , computed as described above, exceeds THRESH. Note that the error is scaled to be O(1), so THRESH should be a reasonably small multiple of 1, e.g., 10 or 100. In particular, it should not depend on the precision (single vs. double) or the size of the matrix. It must be at least zero.

Not modified.

NOUNIT

INTEGER

The FORTRAN unit number for printing out error messages (e.g., if a routine returns IINFO not equal to 0.)

Not modified.

INFO

INTEGER

If 0, then everything ran OK. -1: NSIZES < 0 -2: Some NN(j) < 0 -3: NTYPES < 0 -5: THRESH < 0 -9: LDA < 1 or LDA < NMAX, where NMAX is max( NN(j) ). -16: LDZ < 1 or LDZ < NMAX. -21: NWORK too small. -23: LRWORK too small. -25: LIWORK too small.
