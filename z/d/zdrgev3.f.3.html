subroutine zdrgev3 (integer nsizes, integer, dimension( * ) nn, integer ntypes, logical, dimension( * ) dotype, integer, dimension( 4 ) iseed, double precision thresh, integer nounit, complex*16, dimension( lda, * ) a, integer lda, complex*16, dimension( lda, * ) b, complex*16, dimension( lda, * ) s, complex*16, dimension( lda, * ) t, complex*16, dimension( ldq, * ) q, integer ldq, complex*16, dimension( ldq, * ) z, complex*16, dimension( ldqe, * ) qe, integer ldqe, complex*16, dimension( * ) alpha, complex*16, dimension( * ) beta, complex*16, dimension( * ) alpha1, complex*16, dimension( * ) beta1, complex*16, dimension( * ) work, integer lwork, double precision, dimension( * ) rwork, double precision, dimension( * ) result, integer info)

ZDRGEV3

Propósito:

!>
!> ZDRGEV3 comprueba la rutina de controladores del problema de valores propios generalizados no simétricos ZGGEV3.
!>
!> ZGGEV3 calcula para un par de matrices no simétricas n x n (A, B) los
!> valores propios generalizados y, opcionalmente, los vectores propios izquierdos y derechos.
!>
!> Un valor propio generalizado para un par de matrices (A, B) es un escalar w
!> o una relación alpha/beta = w, tal que A - w*B es singular. Se
!> representa habitualmente como el par (alpha, beta), ya que hay una interpretación razonable
!> para beta=0, e incluso para ambos a cero.
!>
!> Un vector propio generalizado derecho correspondiente a un valor propio
!> generalizado w para un par de matrices (A, B) es un vector r tal que
!> (A - wB) * r = 0. Un vector propio generalizado izquierdo es un vector l tal que
!> l**H * (A - wB) = 0, donde l**H es la transpuesta conjugada de l.
!>
!> Cuando se llama a ZDRGEV3, se especifica un número de tamaños de matrices () y un
!> número de tipos de matrices. Para cada tamaño () y cada tipo de matriz, se generará un par de matrices (A, B)
!> y se utilizará para las pruebas. Para cada par de matrices, se realizarán las siguientes pruebas
!> y se compararán con el umbral THRESH.
!>
!> Resultados de ZGGEV3:
!>
!> (1) max sobre todos los pares de valores propios/vectores izquierdos (alpha/beta,l) de
!>
!>      | VL**H * (beta A - alpha B) |/( ulp max(|beta A|, |alpha B|) )
!>
!>      donde VL**H es la transpuesta conjugada de VL.
!>
!> (2)  | |VL(i)| - 1 | / ulp y si el componente más grande es real
!>
!>      VL(i) denota la i-ésima columna de VL.
!>
!> (3)  max sobre todos los pares de valores propios/vectores izquierdos (alpha/beta,r) de
!>
!>      | (beta A - alpha B) * VR | / ( ulp max(|beta A|, |alpha B|) )
!>
!> (4)  | |VR(i)| - 1 | / ulp y si el componente más grande es real
!>
!>      VR(i) denota la i-ésima columna de VR.
!>
!> (5)  W(completo) = W(parcial)
!>      W(completo) denota los valores propios calculados cuando tanto l como r
!>      son también calculados, y W(parcial) denota los valores propios
!>      calculados cuando solo W, solo W y r, o solo W y l son
!>      calculados.
!>
!> (6)  VL(completo) = VL(parcial)
!>      VL(completo) denota los vectores propios izquierdos calculados cuando tanto l
!>      como r son calculados, y VL(parcial) denota el resultado
!>      cuando solo l es calculado.
!>
!> (7)  VR(completo) = VR(parcial)
!>      VR(completo) denota los vectores propios derechos calculados cuando tanto l
!>      como r son también calculados, y VR(parcial) denota el resultado
!>      cuando solo l es calculado.
!>
!>
!> Matrices de Prueba
!> ---- --------------
!>
!> Los tamaños de las matrices de prueba son especificados por un array
!> NN(1:NSIZES); el valor de cada elemento NN(j) especifica un tamaño.
!> Los tipos son especificados por un array lógico DOTYPE( 1:NTYPES ); si
!> DOTYPE(j) es .TRUE., entonces el tipo de matriz j será generado.
!> Actualmente, la lista de tipos posibles es:
!>
!> (1)  ( 0, 0 )         (un par de matrices cero)
!>
!> (2)  ( I, 0 )         (una identidad y una matriz cero)
!>
!> (3)  ( 0, I )         (una identidad y una matriz cero)
!>
!> (4)  ( I, I )         (un par de matrices identidad)
!>
!>         t   t
!> (5)  ( J , J  )       (un par de bloques de Jordan transpuestos)
!>
!>                                     t                ( I   0  )
!> (6)  ( X, Y )         donde  X = ( J   0  )  y Y = (      t )
!>                                  ( 0   I  )          ( 0   J  )
!>                       e I es una identidad k x k y J un bloque de
!>                       Jordan de (k+1)x(k+1); k=(N-1)/2
!>
!> (7)  ( D, I )         donde D es diag( 0, 1,..., N-1 ) (una matriz diagonal
!>                       con esas entradas diagonales.)
!> (8)  ( I, D )
!>
!> (9)  ( big*D, small*I ) donde big es cercano al desbordamiento y small=1/big
!>
!> (10) ( small*D, big*I )
!>
!> (11) ( big*I, small*D )
!>
!> (12) ( small*I, big*D )
!>
!> (13) ( big*D, big*I )
!>
!> (14) ( small*D, small*I )
!>
!> (15) ( D1, D2 )        donde D1 es diag( 0, 0, 1, ..., N-3, 0 ) y
!>                        D2 es diag( 0, N-3, N-4,..., 1, 0, 0 )
!>           t   t
!> (16) Q ( J , J ) Z     donde Q y Z son matrices ortogonales aleatorias.
!>
!> (17) Q ( T1, T2 ) Z    donde T1 y T2 son matrices triangulares superiores
!>                        con entradas O(1) aleatorias sobre la diagonal
!>                        y entradas diagonales diag(T1) =
!>                        ( 0, 0, 1, ..., N-3, 0 ) y diag(T2) =
!>                        ( 0, N-3, N-4,..., 1, 0, 0 )
!>
!> (18) Q ( T1, T2 ) Z    diag(T1) = ( 0, 0, 1, 1, s, ..., s, 0 )
!>                        diag(T2) = ( 0, 1, 0, 1,..., 1, 0 )
!>                        s = precisión de máquina.
!>
!> (19) Q ( T1, T2 ) Z    diag(T1)=( 0,0,1,1, 1-d, ..., 1-(N-5)*d=s, 0 )
!>                        diag(T2) = ( 0, 1, 0, 1, ..., 1, 0 )
!>
!>                                                        N-5
!> (20) Q ( T1, T2 ) Z    diag(T1)=( 0, 0, 1, 1, a, ..., a   =s, 0 )
!>                        diag(T2) = ( 0, 1, 0, 1, ..., 1, 0, 0 )
!>
!> (21) Q ( T1, T2 ) Z    diag(T1)=( 0, 0, 1, r1, r2, ..., r(N-4), 0 )
!>                        diag(T2) = ( 0, 1, 0, 1, ..., 1, 0, 0 )
!>                        donde r1,..., r(N-4) son aleatorias.
!>
!> (22) Q ( big*T1, small*T2 ) Z    diag(T1) = ( 0, 0, 1, ..., N-3, 0 )
!>                                  diag(T2) = ( 0, 1, ..., 1, 0, 0 )
!>
!> (23) Q ( small*T1, big*T2 ) Z    diag(T1) = ( 0, 0, 1, ..., N-3, 0 )
!>                                  diag(T2) = ( 0, 1, ..., 1, 0, 0 )
!>
!> (24) Q ( small*T1, small*T2 ) Z  diag(T1) = ( 0, 0, 1, ..., N-3, 0 )
!>                                  diag(T2) = ( 0, 1, ..., 1, 0, 0 )
!>
!> (25) Q ( big*T1, big*T2 ) Z      diag(T1) = ( 0, 0, 1, ..., N-3, 0 )
!>                                  diag(T2) = ( 0, 1, ..., 1, 0, 0 )
!>
!> (26) Q ( T1, T2 ) Z     donde T1 y T2 son matrices triangulares superiores aleatorias.
!>
!>

NAME

zdrgev3 — A driver routine for testing the double precision complex generalized eigenvalue routines.

SYNOPSIS

        SUBROUTINE ZDRGEV3(NN, NTYPES, DOTYPE, ISEED, THRESH, NOUNIT,
        A, LDA, B, LDB, S, LDT, Q, LDQ, Z, LDZ, QE, LDQE, ALPHA, BETA,
        ALPHA1, BETA1, WORK, LWORK, RWORK, RESULT, IERR)
  • COMPLEX*16 A, B, S, T, Q, Z, QE, ALPHA, BETA, ALPHA1, BETA1, WORK
  • DOUBLE PRECISION THRESH, RWORK, RESULT
  • INTEGER NN, NTYPES, ISEED, NOUNIT, LDA, LDB, LDT, LDQ, LDZ, LDQE, LWORK, IERR
  • LOGICAL DOTYPE

Function/Subroutine Documentation

NN

!>          NN is INTEGER array, dimension (1)
!>          The sizes of the matrices to be generated.
!>          Values of NN are in the range [0, NMAX].
!>          The number of matrices tested is NN(1).
!>

NTYPES

!>          NTYPES is INTEGER
!>          The number of types of matrices to be generated.
!>          NTYPES must be at least 0.  If NTYPES = 1, then only type 1
!>          is generated.  If NTYPES = MAXTYP + 1, then types 1 through
!>          MAXTYP+1 are generated.
!>

DOTYPE

!>          DOTYPE is LOGICAL array, dimension (NTYPES)
!>          If DOTYPE(j) is .TRUE., then for each size in NN a matrix
!>          of that size and of type j will be generated.
!>          If NTYPES is smaller than the maximum number of types
!>          defined (PARAMETER MAXTYP), then types NTYPES+1 through
!>          MAXTYP will not be generated. If NTYPES is larger
!>          than MAXTYP, DOTYPE(MAXTYP+1) through DOTYPE(NTYPES)
!>          will be ignored.
!>

ISEED

!>          ISEED is INTEGER array, dimension (4)
!>          On entry ISEED specifies the seed of the random number
!>          generator. The array elements should be between 0 and 4095;
!>          if not they will be reduced mod 4096. Also, ISEED(4) must
!>          be odd.  The random number generator uses a linear
!>          congruential sequence limited to small integers, and so
!>          should produce machine independent random numbers. The
!>          values of ISEED are changed on exit, and can be used in the
!>          next call to ZDRGEV3 to continue the same random number
!>          sequence.
!>

THRESH

!>          THRESH is DOUBLE PRECISION
!>          A test will count as 'fail' if the relative error in the
!>          eigenvalues and eigenvectors exceeds THRESH.
!>

NOUNIT

!>          NOUNIT is INTEGER
!>          The FORTRAN unit number for printing out error messages
!>          (e.g., if a routine returns IERR not equal to 0.)
!>

A

!>          A is COMPLEX*16 array, dimension(LDA, max(NN))
!>          Used to hold the original A matrix.  Used as input only
!>          if NTYPES=MAXTYP+1, DOTYPE(1:MAXTYP)=.FALSE., and
!>          DOTYPE(MAXTYP+1)=.TRUE.
!>

LDA

!>          LDA is INTEGER
!>          The leading dimension of A, B, S, and T.
!>          It must be at least 1 and at least max( NN ).
!>

B

!>          B is COMPLEX*16 array, dimension(LDA, max(NN))
!>          Used to hold the original B matrix.  Used as input only
!>          if NTYPES=MAXTYP+1, DOTYPE(1:MAXTYP)=.FALSE., and
!>          DOTYPE(MAXTYP+1)=.TRUE.
!>

S

!>          S is COMPLEX*16 array, dimension (LDA, max(NN))
!>          The Schur form matrix computed from A by ZGEEV3.  On exit, S
!>          contains the Schur form matrix corresponding to the matrix
!>          in A.
!>

T

!>          T is COMPLEX*16 array, dimension (LDA, max(NN))
!>          The upper triangular matrix computed from B by ZGEEV3.
!>

Q

!>          Q is COMPLEX*16 array, dimension (LDQ, max(NN))
!>          The (left) eigenvectors matrix computed by ZGEEV3.
!>

LDQ

!>          LDQ is INTEGER
!>          The leading dimension of Q and Z. It must
!>          be at least 1 and at least max( NN ).
!>

Z

!>          Z is COMPLEX*16 array, dimension( LDQ, max(NN) )
!>          The (right) orthogonal matrix computed by ZGEEV3.
!>

QE

!>          QE is COMPLEX*16 array, dimension( LDQ, max(NN) )
!>          QE holds the computed right or left eigenvectors.
!>

LDQE

!>          LDQE is INTEGER
!>          The leading dimension of QE. LDQE >= max(1,max(NN)).
!>

ALPHA

!>          ALPHA is COMPLEX*16 array, dimension (max(NN))
!>

BETA

!>          BETA is COMPLEX*16 array, dimension (max(NN))
!>
!>          The generalized eigenvalues of (A,B) computed by ZGEEV3.
!>          ( ALPHAR(k)+ALPHAI(k)*i ) / BETA(k) is the k-th
!>          generalized eigenvalue of A and B.
!>

ALPHA1

!>          ALPHA1 is COMPLEX*16 array, dimension (max(NN))
!>

BETA1

!>          BETA1 is COMPLEX*16 array, dimension (max(NN))
!>
!>          Like ALPHAR, ALPHAI, BETA, these arrays contain the
!>          eigenvalues of A and B, but those computed when ZGEEV3 only
!>          computes a partial eigendecomposition, i.e. not the
!>          eigenvalues and left and right eigenvectors.
!>

WORK

!>          WORK is COMPLEX*16 array, dimension (LWORK)
!>

LWORK

!>          LWORK is INTEGER
!>          The number of entries in WORK.  LWORK >= N*(N+1)
!>

RWORK

!>          RWORK is DOUBLE PRECISION array, dimension (8*N)
!>          Real workspace.
!>

RESULT

!>          RESULT is DOUBLE PRECISION array, dimension (2)
!>          The values computed by the tests described above.
!>          The values are currently limited to 1/ulp, to avoid overflow.
!>

INFO

!>          INFO is INTEGER
!>          = 0:  successful exit
!>          < 0:  if INFO = -i, the i-th argument had an illegal value.
!>          > 0:  A routine returned an error code.  INFO is the
!>                absolute value of the INFO value returned.
!>
