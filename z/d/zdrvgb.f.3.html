Documentación de Función/Subrutina

subrutina zdrvgb (logical, dimension( * ) dotype, integer nn, integer, dimension( * ) nval, integer nrhs, double precision thresh, logical tsterr, complex*16, dimension( * ) a, integer la, complex*16, dimension( * ) afb, integer lafb, complex*16, dimension( * ) asav, complex*16, dimension( * ) b, complex*16, dimension( * ) bsav, complex*16, dimension( * ) x, complex*16, dimension( * ) xact, double precision, dimension( * ) s, complex*16, dimension( * ) work, double precision, dimension( * ) rwork, integer, dimension( * ) iwork, integer nout)

ZDRVGB

Propósito:

!>
!> ZDRVGB prueba las subrutinas de control ZGBSV y -SVX.
!>

Parámetros

DOTYPE 
!>          DOTYPE es un array LOGICAL, dimension (NTYPES)
!>          Los tipos de matriz a utilizar para las pruebas. Las matrices de tipo j
!>          (para 1 <= j <= NTYPES) se utilizan para las pruebas si DOTYPE(j) =
!>          .TRUE.; si DOTYPE(j) = .FALSE., entonces el tipo j no se utiliza.
!>

NN

!>          NN es INTEGER
!>          El número de valores de N contenidos en el vector NVAL.
!>

NVAL

!>          NVAL es un array INTEGER, dimension (NN)
!>          Los valores de la dimensión de columna de la matriz N.
!>

NRHS

!>          NRHS es INTEGER
!>          El número de vectores del lado derecho a generar para
!>          cada sistema lineal.
!>

THRESH

!>          THRESH es DOUBLE PRECISION
!>          El valor umbral para los ratios de prueba. Un resultado se
!>          incluye en el archivo de salida si RESULT >= THRESH. Para que
!>          cada ratio de prueba se imprima, use THRESH = 0.
!>

TSTERR

!>          TSTERR es LOGICAL
!>          Indicador que señala si se deben probar las salidas de error.
!>

A

!>          A es un array COMPLEX*16, dimension (LA)
!>

LA

!>          LA es INTEGER
!>          La longitud del array A. LA >= (2*NMAX-1)*NMAX
!>          donde NMAX es la entrada más grande en NVAL.
!>

AFB

!>          AFB es un array COMPLEX*16, dimension (LAFB)
!>

LAFB

!>          LAFB es INTEGER
!>          La longitud del array AFB. LAFB >= (3*NMAX-2)*NMAX
!>          donde NMAX es la entrada más grande en NVAL.
!>

ASAV

!>          ASAV es un array COMPLEX*16, dimension (LA)
!>

B

!>          B es un array COMPLEX*16, dimension (NMAX*NRHS)
!>

BSAV

!>          BSAV es un array COMPLEX*16, dimension (NMAX*NRHS)
!>

X

!>          X es un array COMPLEX*16, dimension (NMAX*NRHS)
!>

XACT

!>          XACT es un array COMPLEX*16, dimension (NMAX*NRHS)
!>

S

!>          S es un array DOUBLE PRECISION, dimension (2*NMAX)
!>

WORK

!>          WORK es un array COMPLEX*16, dimension
!>                      (NMAX*max(3,NRHS,NMAX))
!>

RWORK

!>          RWORK es un array DOUBLE PRECISION, dimension
!>                      (NMAX+2*NRHS)
!>

IWORK

!>          IWORK es un array INTEGER, dimension (NMAX)
!>

NOUT

!>          NOUT es INTEGER
!>          El número de unidad para la salida.
!>
