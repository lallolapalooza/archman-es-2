subroutine zdrvsx (integer nsizes, integer, dimension( * ) nn, integer ntypes, logical, dimension( * ) dotype, integer, dimension( 4 ) iseed, double precision thresh, integer niunit, integer nounit, complex*16, dimension( lda, * ) a, integer lda, complex*16, dimension( lda, * ) h, complex*16, dimension( lda, * ) ht, complex*16, dimension( * ) w, complex*16, dimension( * ) wt, complex*16, dimension( * ) wtmp, complex*16, dimension( ldvs, * ) vs, integer ldvs, complex*16, dimension( ldvs, * ) vs1, double precision, dimension( 17 ) result, complex*16, dimension( * ) work, integer lwork, double precision, dimension( * ) rwork, logical, dimension( * ) bwork, integer info)

ZDRVSX

Propósito:

!>
!>    ZDRVSX comprueba el conductor experto del problema de valores propios
!>    no simétricos (forma de Schur) ZGEESX.
!>
!>    ZDRVSX utiliza matrices de prueba generadas aleatoriamente según
!>    los datos suministrados en la secuencia de llamada, así como datos
!>    leídos de un archivo de entrada e incluyendo números de condición
!>    precalculados con los que compara los que calcula.
!>
!>    Cuando se llama a ZDRVSX, se especifica un número de tamaños de matriz ()
!>    y un número de tipos de matriz. Para cada tamaño ()
!>    y cada tipo de matriz, se generará y utilizará una matriz
!>    para probar las rutinas de valores propios no simétricos. Para cada matriz,
!>    se realizarán 15 pruebas:
!>
!>    (1)     0 si T está en forma de Schur, 1/ulp en caso contrario
!>           (sin ordenación de valores propios)
!>
!>    (2)     | A - VS T VS' | / ( n |A| ulp )
!>
!>      Aquí VS es la matriz de los vectores propios de Schur, y T está en forma de Schur
!>      (sin ordenación de valores propios).
!>
!>    (3)     | I - VS VS' | / ( n ulp ) (sin ordenación de valores propios).
!>
!>    (4)     0     si W son valores propios de T
!>            1/ulp en caso contrario
!>            (sin ordenación de valores propios)
!>
!>    (5)     0     si T(con VS) = T(sin VS),
!>            1/ulp en caso contrario
!>            (sin ordenación de valores propios)
!>
!>    (6)     0     si los valores propios (con VS) = los valores propios (sin VS),
!>            1/ulp en caso contrario
!>            (sin ordenación de valores propios)
!>
!>    (7)     0 si T está en forma de Schur, 1/ulp en caso contrario
!>            (con ordenación de valores propios)
!>
!>    (8)     | A - VS T VS' | / ( n |A| ulp )
!>
!>      Aquí VS es la matriz de los vectores propios de Schur, y T está en forma de Schur
!>      (con ordenación de valores propios).
!>
!>    (9)     | I - VS VS' | / ( n ulp ) (con ordenación de valores propios).
!>
!>    (10)    0     si W son valores propios de T
!>            1/ulp en caso contrario
!>            Si el espacio de trabajo es suficiente, también compara W con y
!>            sin números de condición recíprocos
!>            (con ordenación de valores propios)
!>
!>    (11)    0     si T(con VS) = T(sin VS),
!>            1/ulp en caso contrario
!>            Si el espacio de trabajo es suficiente, también compara T con y sin
!>            números de condición recíprocos
!>            (con ordenación de valores propios)
!>
!>    (12)    0     si los valores propios (con VS) = los valores propios (sin VS),
!>            1/ulp en caso contrario
!>            Si el espacio de trabajo es suficiente, también compara VS con y sin
!>            números de condición recíprocos
!>            (con ordenación de valores propios)
!>
!>    (13)    si la ordenación funcionó y SDIM es el número de
!>            valores propios que fueron SELECCIONADOS
!>            Si el espacio de trabajo es suficiente, también compara SDIM con y
!>            sin números de condición recíprocos
!>
!>    (14)    si RCONDE es el mismo sin importar si VS y/o RCONDV fueron calculados
!>
!>    (15)    si RCONDV es el mismo sin importar si VS y/o RCONDE fueron calculados
!>
!>    Los tamaños de matriz se especifican mediante un array NN(1:NSIZES); el valor de
!>    cada elemento NN(j) especifica un tamaño.
!>    Los tipos de matriz se especifican mediante un array lógico DOTYPE( 1:NTYPES );
!>    si DOTYPE(j) es .TRUE., entonces se generará el tipo de matriz j.
!>    Actualmente, la lista de tipos posibles es:
!>
!>    (1)  La matriz cero.
!>    (2)  La matriz identidad.
!>    (3)  Un bloque de Jordan (transpuesto), con 1s en la diagonal.
!>
!>    (4)  Una matriz diagonal con entradas espaciadas uniformemente
!>         1, ..., ULP y ángulos complejos aleatorios.
!>         (ULP = (primer número mayor que 1) - 1 )
!>    (5)  Una matriz diagonal con entradas espaciadas geométricamente
!>         1, ..., ULP y ángulos complejos aleatorios.
!>    (6)  Una matriz diagonal con entradas 1, ULP, ..., ULP
!>         y ángulos complejos aleatorios.
!>
!>    (7)  Igual que (4), pero multiplicado por una constante cercana
!>         al umbral de desbordamiento
!>    (8)  Igual que (4), pero multiplicado por una constante cercana
!>         al umbral de subdesbordamiento
!>
!>    (9)  Una matriz de la forma U' T U, donde U es unitaria y
!>         T tiene entradas espaciadas uniformemente 1, ..., ULP con ángulos
!>         complejos aleatorios en la diagonal y entradas aleatorias O(1) en
!>         el triángulo superior.
!>
!>    (10) Una matriz de la forma U' T U, donde U es unitaria y
!>         T tiene entradas espaciadas geométricamente 1, ..., ULP con ángulos
!>         complejos aleatorios en la diagonal y entradas aleatorias O(1) en
!>         el triángulo superior.
!>
!>    (11) Una matriz de la forma U' T U, donde U es ortogonal y
!>         T tiene entradas 1, ULP,..., ULP con ángulos
!>         complejos aleatorios en la diagonal y entradas aleatorias O(1) en
!>         el triángulo superior.
!>
!>    (12) Una matriz de la forma U' T U, donde U es unitaria y
!>         T tiene valores propios complejos elegidos aleatoriamente de
!>         ULP < |z| < 1 y entradas aleatorias O(1) en el triángulo
!>         superior.
!>
!>    (13) Una matriz de la forma X' T X, donde X tiene condición
!>         SQRT( ULP ) y T tiene entradas espaciadas uniformemente 1, ..., ULP
!>         con ángulos complejos aleatorios en la diagonal y entradas aleatorias O(1)
!>         en el triángulo superior.
!>
!>    (14) Una matriz de la forma X' T X, donde X tiene condición
!>         SQRT( ULP ) y T tiene entradas espaciadas geométricamente
!>         1, ..., ULP con ángulos complejos aleatorios en la diagonal
!>         y entradas aleatorias O(1) en el triángulo superior.
!>
!>    (15) Una matriz de la forma X' T X, donde X tiene condición
!>         SQRT( ULP ) y T tiene entradas 1, ULP,..., ULP con ángulos
!>         complejos aleatorios en la diagonal y entradas aleatorias O(1)
!>         en el triángulo superior.
!>
!>    (16) Una matriz de la forma X' T X, donde X tiene condición
!>         SQRT( ULP ) y T tiene valores propios complejos elegidos aleatoriamente
!>         de ULP < |z| < 1 y entradas aleatorias O(1) en el triángulo
!>         superior.
!>
!>    (17) Igual que (16), pero multiplicado por una constante
!>         cercana al umbral de desbordamiento
!>    (18) Igual que (16), pero multiplicado por una constante
!>         cercana al umbral de subdesbordamiento
!>
!>    (19) Matriz no simétrica con entradas aleatorias elegidas de (-1,1).
!>         Si N es al menos 4, todas las entradas en las dos primeras filas y la última
!>         fila, y la primera columna y las dos últimas columnas son cero.
!>    (20) Igual que (19), pero multiplicado por una constante
!>         cercana al umbral de desbordamiento
!>    (21) Igual que (19), pero multiplicado por una constante
!>         cercana al umbral de subdesbordamiento
!>
!>    Además, se leerá un archivo de entrada de la unidad lógica número
!>

NAME

ZDRVSX

driver routine for ZGEESX

SYNOPSIS

SUBROUTINE ZDRVSX( NSIZES, NN, NTYPES, DOTYPE, ISEED, THRESH,
                   NIUNIT, NOUNIT, A, LDA, H, HT, W, WT, WTMP, VS, LDVS,
                   VS1, RESULT, WORK, LWORK, RWORK, BWORK, INFO )

Parameters

NSIZES 
!>          NSIZES is INTEGER
!>          The number of sizes of matrices to use.  NSIZES must be at
!>          least zero. If it is zero, no randomly generated matrices
!>          are tested, but any test matrices read from NIUNIT will be
!>          tested.
!>

NN

!>          NN is INTEGER array, dimension (NSIZES)
!>          An array containing the sizes to be used for the matrices.
!>          Zero values will be skipped.  The values must be at least
!>          zero.
!>

NTYPES

!>          NTYPES is INTEGER
!>          The number of elements in DOTYPE. NTYPES must be at least
!>          zero. If it is zero, no randomly generated test matrices
!>          are tested, but and test matrices read from NIUNIT will be
!>          tested. If it is MAXTYP+1 and NSIZES is 1, then an
!>          additional type, MAXTYP+1 is defined, which is to use
!>          whatever matrix is in A.  This is only useful if
!>          DOTYPE(1:MAXTYP) is .FALSE. and DOTYPE(MAXTYP+1) is .TRUE. .
!>

DOTYPE

!>          DOTYPE is LOGICAL array, dimension (NTYPES)
!>          If DOTYPE(j) is .TRUE., then for each size in NN a
!>          matrix of that size and of type j will be generated.
!>          If NTYPES is smaller than the maximum number of types
!>          defined (PARAMETER MAXTYP), then types NTYPES+1 through
!>          MAXTYP will not be generated.  If NTYPES is larger
!>          than MAXTYP, DOTYPE(MAXTYP+1) through DOTYPE(NTYPES)
!>          will be ignored.
!>

ISEED

!>          ISEED is INTEGER array, dimension (4)
!>          On entry ISEED specifies the seed of the random number
!>          generator. The array elements should be between 0 and 4095;
!>          if not they will be reduced mod 4096.  Also, ISEED(4) must
!>          be odd.  The random number generator uses a linear
!>          congruential sequence limited to small integers, and so
!>          should produce machine independent random numbers. The
!>          values of ISEED are changed on exit, and can be used in the
!>          next call to ZDRVSX to continue the same random number
!>          sequence.
!>

THRESH

!>          THRESH is DOUBLE PRECISION
!>          A test will count as error if the relative error, computed as
!>          described above, exceeds THRESH.  Note that the error
!>          is scaled to be O(1), so THRESH should be a reasonably
!>          small multiple of 1, e.g., 10 or 100.  In particular,
!>          it should not depend on the precision (single vs. double)
!>          or the size of the matrix.  It must be at least zero.
!>

NIUNIT

!>          NIUNIT is INTEGER
!>          The FORTRAN unit number for reading in the data file of
!>          problems to solve.
!>

NOUNIT

!>          NOUNIT is INTEGER
!>          The FORTRAN unit number for printing out error messages
!>          (e.g., if a routine returns INFO not equal to 0.)
!>

A

!>          A is COMPLEX*16 array, dimension (LDA, max(NN))
!>          Used to hold the matrix whose eigenvalues are to be
!>          computed.  On exit, A contains the last matrix actually used.
!>

LDA

!>          LDA is INTEGER
!>          The leading dimension of A, and H. LDA must be at
!>          least 1 and at least max( NN ).
!>

H

!>          H is COMPLEX*16 array, dimension (LDA, max(NN))
!>          Another copy of the test matrix A, modified by ZGEESX.
!>

HT

!>          HT is COMPLEX*16 array, dimension (LDA, max(NN))
!>          Yet another copy of the test matrix A, modified by ZGEESX.
!>

W

!>          W is COMPLEX*16 array, dimension (max(NN))
!>          The computed eigenvalues of A.
!>

WT

!>          WT is COMPLEX*16 array, dimension (max(NN))
!>          Like W, this array contains the eigenvalues of A,
!>          but those computed when ZGEESX only computes a partial
!>          eigendecomposition, i.e. not Schur vectors
!>

WTMP

!>          WTMP is COMPLEX*16 array, dimension (max(NN))
!>          More temporary storage for eigenvalues.
!>

VS

!>          VS is COMPLEX*16 array, dimension (LDVS, max(NN))
!>          VS holds the computed Schur vectors.
!>

LDVS

!>          LDVS is INTEGER
!>          Leading dimension of VS. Must be at least max(1,max(NN)).
!>

VS1

!>          VS1 is COMPLEX*16 array, dimension (LDVS, max(NN))
!>          VS1 holds another copy of the computed Schur vectors.
!>

RESULT

!>          RESULT is DOUBLE PRECISION array, dimension (17)
!>          The values computed by the 17 tests described above.
!>          The values are currently limited to 1/ulp, to avoid overflow.
!>

WORK

!>          WORK is COMPLEX*16 array, dimension (LWORK)
!>

LWORK

!>          LWORK is INTEGER
!>          The number of entries in WORK.  This must be at least
!>          max(1,2*NN(j)**2) for all j.
!>

RWORK

!>          RWORK is DOUBLE PRECISION array, dimension (max(NN))
!>

BWORK

!>          BWORK is LOGICAL array, dimension (max(NN))
!>

INFO

!>          INFO is INTEGER
!>          If 0, successful exit.
!>            <0, input parameter -INFO is incorrect
!>            >0, ZLATMR, CLATMS, CLATME or ZGET24 returned an error
!>                 code and INFO is its absolute value
!>
!>-----------------------------------------------------------------------
!>
!>     Some Local Variables and Parameters:
!>     ---- ----- --------- --- ----------
!>     ZERO, ONE       Real 0 and 1.
!>     MAXTYP          The number of types defined.
!>     NMAX            Largest value in NN.
!>     NERRS           The number of tests which have exceeded THRESH
!>     COND, CONDS,
!>     IMODE           Values to be passed to the matrix generators.
!>     ANORM           Norm of A; passed to matrix generators.
!>
!>     OVFL, UNFL      Overflow and underflow thresholds.
!>     ULP, ULPINV     Finest relative precision and its inverse.
!>     RTULP, RTULPI   Square roots of the previous 4 values.
!>             The following four arrays decode JTYPE:
!>     KTYPE(j)        The general type (1-10) for type j.
!>     KMODE(j)        The MODE value to be passed to the matrix
!>                     generator for type j.
!>     KMAGN(j)        The order of magnitude ( O(1),
!>                     O(overflow^(1/2) ), O(underflow^(1/2) )
!>     KCONDS(j)       Selects whether CONDS is to be 1 or
!>                     1/sqrt(ulp).  (0 means irrelevant.)
!>

The file contains matrices along with precomputed !> eigenvalues and reciprocal condition numbers for the eigenvalue !> average and right invariant subspace. For these matrices, in !> addition to tests (1) to (15) we will compute the following two !> tests:

(16) |RCONDE - RCDEIN| / cond(RCONDE)

!>
!>      RCONDE is the reciprocal average eigenvalue condition number
!>      computed by ZGEESX and RCDEIN (the precomputed true value)
!>      is supplied as input.  cond(RCONDE) is the condition number
!>      of RCONDE, and takes errors in computing RCONDE into account,
!>      so that the resulting quantity should be O(ULP). cond(RCONDE)
!>      is essentially given by norm(A)/RCONDV.
!>

(17) |RCONDV - RCDVIN| / cond(RCONDV)

!>
!>      RCONDV is the reciprocal right invariant subspace condition
!>      number computed by ZGEESX and RCDVIN (the precomputed true
!>      value) is supplied as input. cond(RCONDV) is the condition
!>      number of RCONDV, and takes errors in computing RCONDV into
!>      account, so that the resulting quantity should be O(ULP).
!>      cond(RCONDV) is essentially given by norm(A)/RCONDE.
!>
