ZDRVSG

Propósito:

!>
!>      ZDRVSG comprueba los controladores del problema de valores propios generalizado hermitiano complejo.
!>
!>              ZHEGV calcula todos los valores propios y, opcionalmente, los vectores propios de un problema generalizado hermitiano definido complejo.
!>
!>              ZHEGVD calcula todos los valores propios y, opcionalmente, los vectores propios de un problema generalizado hermitiano definido complejo utilizando un algoritmo de divide y vencerás.
!>
!>              ZHEGVX calcula valores propios seleccionados y, opcionalmente, vectores propios de un problema generalizado hermitiano definido complejo.
!>
!>              ZHPGV calcula todos los valores propios y, opcionalmente, los vectores propios de un problema generalizado hermitiano definido complejo en almacenamiento empaquetado.
!>
!>              ZHPGVD calcula todos los valores propios y, opcionalmente, los vectores propios de un problema generalizado hermitiano definido complejo en almacenamiento empaquetado utilizando un algoritmo de divide y vencerás.
!>
!>              ZHPGVX calcula valores propios seleccionados y, opcionalmente, vectores propios de un problema generalizado hermitiano definido complejo en almacenamiento empaquetado.
!>
!>              ZHBGV calcula todos los valores propios y, opcionalmente, los vectores propios de un problema generalizado hermitiano definido y bandeado complejo.
!>
!>              ZHBGVD calcula todos los valores propios y, opcionalmente, los vectores propios de un problema generalizado hermitiano definido y bandeado complejo utilizando un algoritmo de divide y vencerás.
!>
!>              ZHBGVX calcula valores propios seleccionados y, opcionalmente, los vectores propios de un problema generalizado hermitiano definido y bandeado complejo.
!>
!>      Cuando se llama a ZDRVSG, se especifican varios tamaños de matriz y varios tipos de matriz. Para cada tamaño y cada tipo de matriz, se generará una matriz A del tipo dado; también se generará una matriz B aleatoria bien condicionada y el par (A,B) se utilizará para probar los controladores.
!>
!>      Para cada par (A,B), se realizan las siguientes pruebas:
!>
!>      (1) ZHEGV con ITYPE = 1 y UPLO ='U':
!>
!>              | A Z - B Z D | / ( |A| |Z| n ulp )
!>
!>      (2) lo mismo que (1) pero llamando a ZHPGV
!>      (3) lo mismo que (1) pero llamando a ZHBGV
!>      (4) lo mismo que (1) pero con UPLO = 'L'
!>      (5) lo mismo que (4) pero llamando a ZHPGV
!>      (6) lo mismo que (4) pero llamando a ZHBGV
!>
!>      (7) ZHEGV con ITYPE = 2 y UPLO ='U':
!>
!>              | A B Z - Z D | / ( |A| |Z| n ulp )
!>
!>      (8) lo mismo que (7) pero llamando a ZHPGV
!>      (9) lo mismo que (7) pero con UPLO = 'L'
!>      (10) lo mismo que (9) pero llamando a ZHPGV
!>
!>      (11) ZHEGV con ITYPE = 3 y UPLO ='U':
!>
!>              | B A Z - Z D | / ( |A| |Z| n ulp )
!>
!>      (12) lo mismo que (11) pero llamando a ZHPGV
!>      (13) lo mismo que (11) pero con UPLO = 'L'
!>      (14) lo mismo que (13) pero llamando a ZHPGV
!>
!>      ZHEGVD, ZHPGVD y ZHBGVD realizaron las mismas 14 pruebas.
!>
!>      ZHEGVX, ZHPGVX y ZHBGVX realizaron las pruebas anteriores de 14 con
!!>      el parámetro RANGE = 'A', 'N' e 'I', respectivamente.
!>
!>      Los tamaños se especifican mediante una matriz NN(1:NSIZES); el valor de
!>      cada elemento NN(j) especifica un tamaño.
!>      Los tipos se especifican mediante una matriz lógica DOTYPE( 1:NTYPES );
!>      si DOTYPE(j) es .VERDADERO., entonces se generará el tipo de matriz j.
!>      Este tipo se utiliza para la matriz A que tiene una banda semiancha KA.
!>      B se genera como una matriz definida positiva bien condicionada
!>      con banda semiancha KB (<= KA).
!>      Actualmente, la lista de tipos posibles para A es:
!>
!>      (1) La matriz cero.
!>      (2) La matriz identidad.
!>
!>      (3) Una matriz diagonal con entradas espaciadas uniformemente
!>           1, ..., ULP y signos aleatorios.
!>           (ULP = (primer número mayor que 1) - 1)
!>      (4) Una matriz diagonal con entradas espaciadas geométricamente
!>           1, ..., ULP y signos aleatorios.
!>      (5) Una matriz diagonal con entradas 1, ULP, ..., ULP
!>           y signos aleatorios.
!>
!>      (6) Igual que (4), pero multiplicado por SQRT( umbral de desbordamiento )
!>      (7) Igual que (4), pero multiplicado por SQRT( umbral de subdesbordamiento )
!>
!>      (8) Una matriz de la forma U* D U, donde U es unitaria y
!>           D tiene entradas espaciadas uniformemente 1, ..., ULP con signos aleatorios
!>           en la diagonal.
!>
!>      (9) Una matriz de la forma U* D U, donde U es unitaria y
!>           D tiene entradas espaciadas geométricamente 1, ..., ULP con signos aleatorios
!>           en la diagonal.
!>
!>      (10) Una matriz de la forma U* D U, donde U es unitaria y
!>           D tiene entradas 1, ULP,..., ULP con signos aleatorios
!>           en la diagonal.
!>
!>      (11) Igual que (8), pero multiplicado por SQRT( umbral de desbordamiento )
!>      (12) Igual que (8), pero multiplicado por SQRT( umbral de subdesbordamiento )
!>
!>      (13) Matriz hermitiana con entradas aleatorias elegidas de (-1,1).
!>      (14) Igual que (13), pero multiplicado por SQRT( umbral de desbordamiento )
!>      (15) Igual que (13), pero multiplicado por SQRT( umbral de subdesbordamiento )
!>
!>      (16) Igual que (8), pero con KA = 1 y KB = 1
!>      (17) Igual que (8), pero con KA = 2 y KB = 1
!>      (18) Igual que (8), pero con KA = 2 y KB = 2
!>      (19) Igual que (8), pero con KA = 3 y KB = 1
!>      (20) Igual que (8), pero con KA = 3 y KB = 2
!>      (21) Igual que (8), pero con KA = 3 y KB = 3
!> 
!>  NSIZES  INTEGER
!>          El número de tamaños de matrices a utilizar. Si es cero,
!>          ZDRVSG no hace nada. Debe ser como mínimo cero.
!>          No modificado.
!>
!>  NN      INTEGER array, dimension (NSIZES)
!>          Una matriz que contiene los tamaños a utilizar para las matrices.
!>          Se omitirán los valores cero. Los valores deben ser como mínimo
!>          cero.
!>          No modificado.
!>
!>  NTYPES  INTEGER
!>          El número de elementos en DOTYPE. Si es cero, ZDRVSG
!>          no hace nada. Debe ser como mínimo cero. Si es MAXTYP+1
!>          y NSIZES es 1, entonces se define un tipo adicional, MAXTYP+1,
!>          que es usar cualquier matriz que esté en A. Esto
!>          sólo es útil si DOTYPE(1:MAXTYP) es .FALSO. y
!>          DOTYPE(MAXTYP+1) es .VERDADERO. .

DOTYPE LOGICAL array, dimension (NTYPES) Si DOTYPE(j) es .TRUE., entonces se probará el tipo j de matriz. No modificado.

ISEED INTEGER array, dimension (4) La semilla para la generación de números aleatorios. Modificado por la rutina.

THRESH DOUBLE PRECISION Umbral para las pruebas relativas. Se utiliza un valor típico de THRESH = 10.0D0. No modificado.

NOUNU INTEGER Si es 0, entonces ZDRVSG imprimirá información sobre los resultados de las pruebas. Si es mayor que 0, no se imprimirá información. No modificado.

A COMPLEX*16 array, dimension (LDA, *) El array de entrada para almacenar la matriz A. No modificado.

LDA INTEGER La longitud de fila de A. Debe ser como mínimo max(1, NN(j)) para todos los j.

B COMPLEX*16 array, dimension (LDB, *) El array de entrada para almacenar la matriz B. No modificado.

LDB INTEGER La longitud de fila de B. Debe ser como mínimo max(1, NN(j)) para todos los j.

D DOUBLE PRECISION array, dimension (*) Array de salida para almacenar los valores propios reales.

Z COMPLEX*16 array, dimension (LDZ, *) Array de salida para almacenar los vectores propios.

LDZ INTEGER La longitud de fila de Z. Debe ser como mínimo max(1, NN(j)) para todos los j.

AB COMPLEX*16 array, dimension (LDA, *) Array de salida para almacenar la matriz A en formato empaquetado (para ZHPGV). No modificado.

BB COMPLEX*16 array, dimension (LDB, *) Array de salida para almacenar la matriz B en formato empaquetado (para ZHPGV). No modificado.

AP COMPLEX*16 array, dimension (*) Array de salida para almacenar la matriz A en formato bandeado (para ZHBGV). No modificado.

BP COMPLEX*16 array, dimension (*) Array de salida para almacenar la matriz B en formato bandeado (para ZHBGV). No modificado.

WORK COMPLEX*16 array, dimension (*) Un array de trabajo para los controladores.

NWORK INTEGER El tamaño del array WORK.

RWORK DOUBLE PRECISION array, dimension (*) Un array de trabajo para los controladores.

LRWORK INTEGER El tamaño del array RWORK.

IWORK INTEGER array, dimension (*) Un array de trabajo para los controladores.

LIWORK INTEGER El tamaño del array IWORK.

RESULT DOUBLE PRECISION array, dimension (*) Los resultados de las pruebas. Las dimensiones dependen de los tipos de prueba. Consulte la sección de descripción para obtener más detalles.

INFO INTEGER array, dimension (*) Los códigos de información devueltos por los controladores. Las dimensiones dependen de los tipos de prueba. Consulte la sección de descripción para obtener más detalles.

NAME

zdrvsg -
Generates random matrices for testing various linear equation solvers. The matrices are of the form A*X = B, A*X = lambda*B*X, or A*X = lambda*X, where A and B are complex matrices. The matrix A is general, B is Hermitian positive definite. The routine is a driver for the LAPACK routines ZDRVSG, ZDRVSX, ZDRVXD, ZDRVFF, ZDRVFD, ZDRVSP, ZDRVVP, ZDRVPO, ZDRVPL.

SUBROUTINE ZDRVSG(
     &           NSIZES, NN, NTYPES, DOTYPE, ISEED, THRESH, NOUNIT,
     &           A, LDA, B, LDB, D, Z, LDZ, AB, BB, AP, BP, WORK, NWORK,
     &           RWORK, LRWORK, IWORK, LIWORK, RESULT, INFO )
  CHARACTER*(*)  DOTYPE
  INTEGER        NN( * ), NTYPES, ISEED( * ), NOUNIT, LDA, LDB, LDZ,
     &           NWORK, LRWORK, LIWORK, INFO
  COMPLEX*16     A( LDA, * ), B( LDB, * ), Z( LDZ, * ), AB( LDA, * ),
     &           BB( LDB, * ), AP( * ), BP( * ), WORK( * )
  DOUBLE PRECISION THRESH, D( * ), RWORK( * ), RESULT( * )

Function/Subroutine Documentation

Parameters

NSIZES INTEGER
The number of sizes in the array NN. Not modified.
NN INTEGER array, dimension (NSIZES)
An array of matrix sizes to be used for testing. Not modified.
NTYPES INTEGER
The number of matrix types to be tested. Not modified.
DOTYPE LOGICAL array, dimension (NTYPES)
If DOTYPE(j) is .TRUE., then for each size in NN a matrix of that size and of type j will be generated. If NTYPES is smaller than the maximum number of types defined (PARAMETER MAXTYP), then types NTYPES+1 through MAXTYP will not be generated. If NTYPES is larger than MAXTYP, DOTYPE(MAXTYP+1) through DOTYPE(NTYPES) will be ignored. Not modified.
ISEED INTEGER array, dimension (4)
On entry ISEED specifies the seed of the random number generator. The array elements should be between 0 and 4095; if not they will be reduced mod 4096. Also, ISEED(4) must be odd. The random number generator uses a linear congruential sequence limited to small integers, and so should produce machine independent random numbers. The values of ISEED are changed on exit, and can be used in the next call to ZDRVSG to continue the same random number sequence. Modified.
THRESH DOUBLE PRECISION
A test will count as an error if the relative error, computed as described above, exceeds THRESH. Note that the error is scaled to be O(1), so THRESH should be a reasonably small multiple of 1, e.g., 10 or 100. In particular, it should not depend on the precision (single vs. double) or the size of the matrix. It must be at least zero. Not modified.
NOUNIT INTEGER
The FORTRAN unit number for printing out error messages (e.g., if a routine returns IINFO not equal to 0.) Not modified.
A COMPLEX*16 array, dimension (LDA , max(NN))
Used to hold the matrix whose eigenvalues are to be computed. On exit, A contains the last matrix actually used. Modified.
LDA INTEGER
The leading dimension of A. It must be at least 1 and at least max( NN ). Not modified.
B COMPLEX*16 array, dimension (LDB , max(NN))
Used to hold the Hermitian positive definite matrix for the generalized problem. On exit, B contains the last matrix actually used. Modified.
LDB INTEGER
The leading dimension of B. It must be at least 1 and at least max( NN ). Not modified.
D DOUBLE PRECISION array, dimension (max(NN))
The eigenvalues of A. On exit, the eigenvalues in D correspond with the matrix in A. Modified.
Z COMPLEX*16 array, dimension (LDZ, max(NN))
The matrix of eigenvectors. Modified.
LDZ INTEGER
The leading dimension of ZZ. It must be at least 1 and at least max( NN ). Not modified.
AB COMPLEX*16 array, dimension (LDA, max(NN))
Workspace. Modified.
BB COMPLEX*16 array, dimension (LDB, max(NN))
Workspace. Modified.
AP COMPLEX*16 array, dimension (max(NN)**2)
Workspace. Modified.
BP COMPLEX*16 array, dimension (max(NN)**2)
Workspace. Modified.
WORK COMPLEX*16 array, dimension (NWORK)
Workspace. Modified.
NWORK INTEGER
The number of entries in WORK. This must be at least 2*N + N**2 where N = max( NN(j), 2 ). Not modified.
RWORK DOUBLE PRECISION array, dimension (LRWORK)
Workspace. Modified.
LRWORK INTEGER
The number of entries in RWORK. This must be at least max( 7*N, 1 + 4*N + 2*N*lg(N) + 3*N**2 ) where N = max( NN(j) ) and lg( N ) = smallest integer k such that 2**k >= N . Not modified.
IWORK INTEGER array, dimension (LIWORK))
Workspace. Modified.
LIWORK INTEGER
The number of entries in IWORK. This must be at least 2 + 5*max( NN(j) ). Not modified.
RESULT DOUBLE PRECISION array, dimension (70)
The values computed by the 70 tests described above. Modified.
INFO INTEGER
If 0, then everything ran OK. -1: NSIZES < 0 -2: Some NN(j) < 0 -3: NTYPES < 0 -5: THRESH < 0 -9: LDA < 1 or LDA < NMAX, where NMAX is max( NN(j) ). -16: LDZ < 1 or LDZ < NMAX. -21: NWORK too small. -23: LRWORK too small. -25: LIWORK too small. If ZLATMR, CLATMS, ZHEGV, ZHPGV, ZHBGV, CHEGVD, CHPGVD, ZHPGVD, ZHEGVX, CHPGVX, ZHBGVX returns an error code, the absolute value of it is returned. Modified.
