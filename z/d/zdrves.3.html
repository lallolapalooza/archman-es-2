ZDRVES

Propósito:

!>
!>    ZDRVES comprueba el problema del autovalor no simétrico (forma de Schur)
!>    driver ZGEES.
!>
!>    Cuando se llama a ZDRVES, se especifica un número de tamaños de matriz () y
!>    un número de tipos de matriz. Para cada tamaño () y cada tipo de matriz,
!>    se generará y utilizará una matriz para probar las rutinas de autovalores
!>    no simétricos. Para cada matriz, se realizarán 13 pruebas:
!>
!>    (1)     0 si T está en forma de Schur, 1/ulp en caso contrario
!>           (sin ordenar autovalores)
!>
!>    (2)     | A - VS T VS' | / ( n |A| ulp )
!>
!>      Aquí VS es la matriz de autovectores de Schur, y T está en forma de Schur
!>      (sin ordenar autovalores).
!>
!>    (3)     | I - VS VS' | / ( n ulp ) (sin ordenar autovalores).
!>
!>    (4)     0     si W son autovalores de T
!>            1/ulp en caso contrario
!>            (sin ordenar autovalores)
!>
!>    (5)     0     si T(con VS) = T(sin VS),
!>            1/ulp en caso contrario
!>            (sin ordenar autovalores)
!>
!>    (6)     0     si autovalores(con VS) = autovalores(sin VS),
!>            1/ulp en caso contrario
!>            (sin ordenar autovalores)
!>
!>    (7)     0 si T está en forma de Schur, 1/ulp en caso contrario
!>            (con ordenación de autovalores)
!>
!>    (8)     | A - VS T VS' | / ( n |A| ulp )
!>
!>      Aquí VS es la matriz de autovectores de Schur, y T está en forma de Schur
!>      (con ordenación de autovalores).
!>
!>    (9)     | I - VS VS' | / ( n ulp ) (con ordenación de autovalores).
!>
!>    (10)    0     si W son autovalores de T
!>            1/ulp en caso contrario
!>            (con ordenación de autovalores)
!>
!>    (11)    0     si T(con VS) = T(sin VS),
!>            1/ulp en caso contrario
!>            (con ordenación de autovalores)
!>
!>    (12)    0     si autovalores(con VS) = autovalores(sin VS),
!>            1/ulp en caso contrario
!>            (con ordenación de autovalores)
!>
!>    (13)    si la ordenación funcionó y SDIM es el número de
!>            autovalores que fueron SELECCIONADOS
!>
!>    Los tamaños se especifican mediante un array NN(1:NSIZES); el valor de
!>    cada elemento NN(j) especifica un tamaño.
!>    Los tipos se especifican mediante un array lógico DOTYPE( 1:NTYPES );
!>    si DOTYPE(j) es .TRUE., entonces se generará el tipo de matriz j.
!>    Actualmente, la lista de tipos posibles es:
!>
!>    (1)  La matriz cero.
!>    (2)  La matriz identidad.
!>    (3)  Un bloque de Jordan (transpuesto), con 1s en la diagonal.
!>
!>    (4)  Una matriz diagonal con entradas espaciadas uniformemente
!>         1, ..., ULP y ángulos complejos aleatorios.
!>         (ULP = (primer número mayor que 1) - 1 )
!>    (5)  Una matriz diagonal con entradas espaciadas geométricamente
!>         1, ..., ULP y ángulos complejos aleatorios.
!>    (6)  Una matriz diagonal con entradas 1, ULP, ..., ULP
!>         y ángulos complejos aleatorios.
!>
!>    (7)  Igual que (4), pero multiplicado por una constante cercana
!>         al umbral de desbordamiento
!>    (8)  Igual que (4), pero multiplicado por una constante cercana
!>         al umbral de subdesbordamiento
!>
!>    (9)  Una matriz de la forma U' T U, donde U es unitaria y
!>         T tiene entradas espaciadas uniformemente 1, ..., ULP con
!>         ángulos complejos aleatorios en la diagonal y entradas O(1)
!>         en el triángulo superior.
!>
!>    (10) Una matriz de la forma U' T U, donde U es unitaria y
!>         T tiene entradas espaciadas geométricamente 1, ..., ULP con
!>         ángulos complejos aleatorios en la diagonal y entradas O(1)
!>         en el triángulo superior.
!>
!>    (11) Una matriz de la forma U' T U, donde U es ortogonal y
!>         T tiene entradas 1, ULP, ..., ULP con
!>         ángulos complejos aleatorios en la diagonal y entradas O(1)
!>         en el triángulo superior.
!>
!>    (12) Una matriz de la forma U' T U, donde U es unitaria y
!>         T tiene autovalores complejos elegidos aleatoriamente de
!>         ULP < |z| < 1 y entradas O(1) en el triángulo superior.
!>
!>    (13) Una matriz de la forma X' T X, donde X tiene condición
!>         SQRT( ULP ) y T tiene entradas espaciadas uniformemente 1, ..., ULP
!>         con ángulos complejos aleatorios en la diagonal y entradas O(1)
!>         en el triángulo superior.
!>
!>    (14) Una matriz de la forma X' T X, donde X tiene condición
!>         SQRT( ULP ) y T tiene entradas espaciadas geométricamente
!>         1, ..., ULP con ángulos complejos aleatorios en la diagonal
!>         y entradas O(1) en el triángulo superior.
!>
!>    (15) Una matriz de la forma X' T X, donde X tiene condición
!>         SQRT( ULP ) y T tiene entradas 1, ULP, ..., ULP con
!>         ángulos complejos aleatorios en la diagonal y entradas O(1)
!>         en el triángulo superior.
!>
!>    (16) Una matriz de la forma X' T X, donde X tiene condición
!>         SQRT( ULP ) y T tiene autovalores complejos elegidos aleatoriamente
!>         de ULP < |z| < 1 y entradas O(1) en el triángulo superior.
!>
!>    (17) Igual que (16), pero multiplicado por una constante
!>         cercana al umbral de desbordamiento
!>    (18) Igual que (16), pero multiplicado por una constante
!>         cercana al umbral de subdesbordamiento
!>
!>    (19) Matriz no simétrica con entradas aleatorias elegidas de (-1,1).
!>         Si N es al menos 4, todas las entradas en las dos primeras filas y la
!>         última fila, y la primera columna y las dos últimas columnas son cero.
!>    (20) Igual que (19), pero multiplicado por una constante
!>         cercana al umbral de desbordamiento
!>    (21) Igual que (19), pero multiplicado por una constante
!>         cercana al umbral de subdesbordamiento
!>

Parámetros

!>          NSIZES es INTEGER
!>          El número de tamaños de matrices a utilizar. Si es cero,
!>          ZDRVES no hace nada. Debe ser al menos cero.
!>

NN

!>          NN es un array INTEGER, dimension (NSIZES)
!>          Un array que contiene los tamaños que se utilizarán para las matrices.
!>          Los valores cero se omitirán. Los valores deben ser al menos
!>          cero.
!>

NTYPES

!>          NTYPES es INTEGER
!>          El número de elementos en DOTYPE. Si es cero, ZDRVES
!>          no hace nada. Debe ser al menos cero. Si es MAXTYP+1
!>          y NSIZES es 1, entonces se define un tipo adicional, MAXTYP+1,
!>          que es utilizar la matriz que esté en A. Esto
!>          sólo es útil si DOTYPE(1:MAXTYP) es .FALSE. y
!>          DOTYPE(MAXTYP+1) es .TRUE. .
!>

Function/Subroutine Documentation

ZDRVES es una rutina de prueba para el problema de valores propios no simétricos. Genera matrices de prueba, llama a ZGEES para calcular sus valores propios y vectores propios, y luego usa el resultado para calcular errores numéricos.

El propósito de ZDRVES es probar la rutina de cálculo de valores propios de LAPACK ZGEES. Lo hace ejecutando una serie de pruebas en matrices generadas aleatoriamente. Las pruebas se basan en las propiedades de los valores propios y vectores propios de una matriz.

Los parámetros de la rutina son los siguientes:

NSIZES

!>          NSIZES es INTEGER
!>          El número de tamaños de matriz a probar.

NN

!>          NN es INTEGER array, dimension (NSIZES)
!>          Los tamaños de las matrices a probar. NN(j) es el número de filas
!>          y columnas de la matriz j. Los valores de NN deben ser no negativos.

NTYPES

!>          NTYPES es INTEGER
!>          El número de tipos de matrices a probar. Los tipos están definidos
!>          por la rutina de generación de matrices ZLATMR.
!>          Si NTYPES es 0, entonces solo se probarán las matrices de tipo 1.
!>          Si NTYPES es mayor que el número máximo de tipos definidos
!>          (PARAMETER MAXTYP), entonces los tipos NTYPES+1 a MAXTYP se ignorarán.
!>          Si NTYPES es menor que MAXTYP, entonces los tipos NTYPES+1 a MAXTYP
!>          no se generarán.

ISHP

!>          ISHP es LOGICAL
!>          Si ISHP es .TRUE., entonces las matrices se generan con diferentes
!>          estructuras de valores propios (por ejemplo, valores propios
!>          reales, complejos, espaciados de manera uniforme, etc.).
!>          Si ISHP es .FALSE., entonces las matrices se generan con una estructura
!>          de valores propios aleatoria.

ISEED

!>          ISEED es array INTEGER, dimension (4)
!>          En la entrada, ISEED especifica la semilla del generador de números
!>          aleatorios. Los elementos del array deben estar entre 0 y 4095;
!>          si no, se reducirán módulo 4096. Además, ISEED(4) debe ser impar.
!>          El generador de números aleatorios utiliza una secuencia congruencial
!>          lineal limitada a enteros pequeños, por lo que debería producir números
!>          aleatorios independientes de la máquina. Los valores de ISEED se
!>          modifican en la salida y se pueden usar en la siguiente llamada a
!>          ZDRVES para continuar la misma secuencia de números aleatorios.

THRESH

!>          THRESH es DOUBLE PRECISION
!>          Una prueba contará como éxito si el error, calculado como se describe
!>          anteriormente, excede THRESH. Tenga en cuenta que el error se escala
!>          para ser O(1), por lo que THRESH debe ser un múltiplo razonablemente
!>          pequeño de 1, por ejemplo, 10 o 100. En particular, no debe depender
!>          de la precisión (simple vs. doble) o del tamaño de la matriz. Debe ser
!>          al menos cero.

NOUNIT

!>          NOUNIT es INTEGER
!>          El número de unidad FORTRAN para imprimir mensajes de error
!>          (por ejemplo, si una rutina devuelve INFO no igual a 0).

A

!>          A es array COMPLEX*16, dimension (LDA, max(NN))
!>          Se utiliza para almacenar la matriz cuyos valores propios se van a
!>          calcular. En la salida, A contiene la última matriz utilizada
!>          realmente.

LDA

!>          LDA es INTEGER
!>          La dimensión líder de A y H. LDA debe ser al menos 1 y al menos
!>          max( NN ).

H

!>          H es array COMPLEX*16, dimension (LDA, max(NN))
!>          Otra copia de la matriz de prueba A, modificada por ZGEES.

HT

!>          HT es array COMPLEX*16, dimension (LDA, max(NN))
!>          Aún otra copia de la matriz de prueba A, modificada por ZGEES.

W

!>          W es array COMPLEX*16, dimension (max(NN))
!>          Los valores propios calculados de A.

WT

!>          WT es array COMPLEX*16, dimension (max(NN))
!>          Al igual que W, este array contiene los valores propios de A,
!>          pero aquellos calculados cuando ZGEES solo calcula una
!>          descomposición eigendecomposición parcial, es decir, sin vectores
!>          Schur.

VS

!>          VS es array COMPLEX*16, dimension (LDVS, max(NN))
!>          VS contiene los vectores propios de Schur calculados.

LDVS

!>          LDVS es INTEGER
!>          Dimensión líder de VS. Debe ser al menos max(1, max(NN)).

RESULT

!>          RESULT es array DOUBLE PRECISION, dimension (13)
!>          Los valores calculados por las 13 pruebas descritas anteriormente.
!>          Actualmente, los valores se limitan a 1/ulp, para evitar desbordamientos.

WORK

!>          WORK es array COMPLEX*16, dimension (NWORK)

NWORK

!>          NWORK es INTEGER
!>          El número de entradas en WORK. Debe ser al menos
!>          5*NN(j)+2*NN(j)**2 para todo j.

RWORK

!>          RWORK es array DOUBLE PRECISION, dimension (max(NN))

IWORK

!>          IWORK es array INTEGER, dimension (max(NN))

BWORK

!>          BWORK es array LOGICAL, dimension (max(NN))

INFO

!>          INFO es INTEGER
!>          Si es 0, entonces todo funcionó correctamente.
!>           -1: NSIZES < 0
!>           -2: Algún NN(j) < 0
!>           -3: NTYPES < 0
!>           -6: THRESH < 0
!>           -9: LDA < 1 o LDA < NMAX, donde NMAX es max( NN(j) ).
!>          -15: LDVS < 1 o LDVS < NMAX, donde NMAX es max( NN(j) ).
!>          -18: NWORK es demasiado pequeño.
!>          Si ZLATMR, CLATMS, CLATME o ZGEES devuelve un código de error,
!>              se devuelve su valor absoluto.
!>
!>-----------------------------------------------------------------------
!>
!>     Algunas Variables y Parámetros Locales:
!>     ---- ----- --------- --- ----------
!>     ZERO, ONE       Reales 0 y 1.
!>     MAXTYP          El número de tipos definidos.
!>     NMAX            El valor más grande en NN.
!>     NERRS           El número de pruebas que han excedido THRESH
!>     COND, CONDS,
!>     IMODE           Valores a pasar a los generadores de matrices.
!>     ANORM           Norma de A; se pasa a los generadores de matrices.
!>
!>     OVFL, UNFL      Umbrales de desbordamiento y subdesbordamiento.
!>     ULP, ULPINV     La precisión relativa más fina y su inversa.
!>     RTULP, RTULPI   Raíces cuadradas de los valores anteriores de 4.
!>             Los siguientes cuatro arrays decodifican JTYPE:
!>     KTYPE(j)        El tipo general (1-10) para el tipo j.
!>     KMODE(j)        El valor MODE a pasar al generador de matrices
!>                     para el tipo j.
!>     KMAGN(j)        El orden de magnitud ( O(1),
!>                     O(overflow^(1/2) ), O(underflow^(1/2) )
!>     KCONDS(j)       Selecciona si CONDS se va a utilizar 1 o
!>                     1/sqrt(ulp). (0 significa irrelevante.)
!>
