ZDRVHE_RK

Propósito:

!>
!> ZDRVHE_RK prueba las rutinas de controlador ZHESV_RK.
!>

Parámetros

DOTYPE 
!>          DOTYPE es un array LOGICAL, de dimensión (NTYPES)
!>          Los tipos de matrices a utilizar para las pruebas. Las matrices de tipo j
!>          (para 1 <= j <= NTYPES) se utilizan para las pruebas si DOTYPE(j) =
!>          .TRUE.; si DOTYPE(j) = .FALSE., entonces el tipo j no se utiliza.
!>

NN

!>          NN es un INTEGER
!>          El número de valores de N contenidos en el vector NVAL.
!>

NVAL

!>          NVAL es un array INTEGER, de dimensión (NN)
!>          Los valores de la dimensión N de la matriz.
!>

NRHS

!>          NRHS es un INTEGER
!>          El número de vectores del lado derecho a generar para
!>          cada sistema lineal.
!>

THRESH

!>          THRESH es un DOUBLE PRECISION
!>          El valor umbral para las relaciones de prueba. Un resultado se
!>          incluye en el archivo de salida si RESULT >= THRESH. Para que
!>          se imprima cada relación de prueba, utilice THRESH = 0.
!>

TSTERR

!>          TSTERR es un LOGICAL
!>          Indicador que señala si se deben probar las salidas de error.
!>

NMAX

!>          NMAX es un INTEGER
!>          El valor máximo permitido para N, utilizado en la dimensionamiento de los
!>          arrays de trabajo.
!>

A

!>          A es un array COMPLEX*16, de dimensión (NMAX*NMAX)
!>

AFAC

!>          AFAC es un array COMPLEX*16, de dimensión (NMAX*NMAX)
!>

E

!>          E es un array COMPLEX*16, de dimensión (NMAX)
!>

AINV

!>          AINV es un array COMPLEX*16, de dimensión (NMAX*NMAX)
!>

B

!>          B es un array COMPLEX*16, de dimensión (NMAX*NRHS)
!>

X

!>          X es un array COMPLEX*16, de dimensión (NMAX*NRHS)
!>

XACT

!>          XACT es un array COMPLEX*16, de dimensión (NMAX*NRHS)
!>

WORK

!>          WORK es un array COMPLEX*16, de dimensión (NMAX*max(2,NRHS))
!>

RWORK

!>          RWORK es un array DOUBLE PRECISION, de dimensión (NMAX+2*NRHS)
!>

IWORK

!>          IWORK es un array INTEGER, de dimensión (NMAX)
!>

NOUT

!>          NOUT es un INTEGER
!>          La unidad de salida.
!>
