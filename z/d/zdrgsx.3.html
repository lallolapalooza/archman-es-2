ZDRGSX

Propósito:

!>
!> ZDRGSX verifica el controlador experto del problema de valores propios generalizados no simétricos (forma de Schur) ZGGESX.
!>
!> ZGGES factoriza A y B como Q*S*Z' y Q*T*Z', donde ' significa transpuesta conjugada, S y T son triangulares superiores (es decir, en forma de Schur generalizada), y Q y Z son unitarias. También calcula los valores propios generalizados (alpha(j),beta(j)), j=1,...,n. Por lo tanto,
!> w(j) = alpha(j)/beta(j) es una raíz de la ecuación característica
!>
!>                 det( A - w(j) B ) = 0
!>
!> Opcionalmente, también reordena los valores propios para que un clúster seleccionado de valores propios aparezca en el bloque diagonal principal de las formas de Schur; calcula un número recíproco de condición para el promedio de los valores propios seleccionados; y calcula un número recíproco de condición para los subespacios deflactantes derecho e izquierdo correspondientes a los valores propios seleccionados.
!>
!> Cuando se llama a ZDRGSX con NSIZE > 0, se utilizan cinco (5) tipos de pares de matrices integradas para probar la subrutina ZGGESX.
!>
!> Cuando se llama a ZDRGSX con NSIZE = 0, lee datos de prueba de matriz para probar ZGGESX.
!> (se necesitan más detalles sobre qué tipo de datos leídos son necesarios).
!>
!> Para cada par de matrices, se realizarán las siguientes pruebas y se compararán con el umbral THRESH, excepto para las pruebas (7) y (9):
!>
!> (1)   | A - Q S Z' | / ( |A| n ulp )
!>
!> (2)   | B - Q T Z' | / ( |B| n ulp )
!>
!> (3)   | I - QQ' | / ( n ulp )
!>
!> (4)   | I - ZZ' | / ( n ulp )
!>
!> (5)   si A está en forma de Schur (es decir, forma triangular)
!>
!> (6)   máximo sobre j de D(j) donde:
!>
!>                     |alpha(j) - S(j,j)|        |beta(j) - T(j,j)|
!>           D(j) = ------------------------ + -----------------------
!>                  max(|alpha(j)|,|S(j,j)|)   max(|beta(j)|,|T(j,j)|)
!>
!> (7)   si la ordenación funcionó y SDIM es el número de valores propios
!>       que fueron seleccionados.
!>
!> (8)   el valor estimado DIF no difiere de los valores verdaderos de
!>       Difu y Difl más que un factor 10*THRESH. Si la estimación DIF
!>       es igual a cero, los valores verdaderos correspondientes de Difu y Difl
!>       deberían ser menores que EPS*norm(A, B). Si el valor verdadero de Difu
!>       y Difl son iguales a cero, la estimación DIF debería ser menor que
!>       EPS*norm(A, B).
!>
!> (9)   Si INFO = N+3 es devuelto por ZGGESX, la reordenación
!>       y verificamos que DIF = PL = PR = 0 y que el valor verdadero de
!>       Difu y Difl es < EPS*norm(A, B). Contamos los eventos cuando
!>       INFO=N+3.
!>
!> Para las matrices de prueba leídas, se ejecutan las mismas pruebas excepto que el
!> valor exacto para DIF (y PL) son datos de entrada. Adicionalmente, hay
!> una prueba más para matrices de prueba leídas:
!>
!> (10)  el valor estimado PL no difiere del valor verdadero de
!>       PLTRU más que un factor THRESH. Si la estimación PL es igual a
!>       cero, el valor verdadero correspondiente de PLTRU debería ser menor que
!>       EPS*norm(A, B). Si el valor verdadero de PLTRU es igual a cero, la
!>       estimación PL debería ser menor que EPS*norm(A, B).
!>
!> Tenga en cuenta que para las pruebas integradas, se generan y prueban un total de 10*NSIZE*(NSIZE-1)
!> pares de matrices. NSIZE debe mantenerse pequeño.
!>
!> SVD (subrutina ZGESVD) se utiliza para calcular el valor verdadero de DIF_u
!> y DIF_l al probar los problemas de prueba integrados.
!>
!> Matrices de Prueba Integradas
!> ======================
!>
!> Todas las matrices de prueba integradas son el bloque de 2 por 2 de matrices triangulares
!>
!>          A = [ A11 A12 ]    y      B = [ B11 B12 ]
!>              [     A22 ]                 [     B22 ]
!>
!> donde para diferentes tipos de A11 y A22 se dan de la siguiente manera.
!> A12 y B12 se eligen de modo que la ecuación de Sylvester generalizada
!>
!>          A11*R - L*A22 = -A12
!>          B11*R - L*B22 = -B12
!>
!> tengan soluciones prescritas R y L.
!>
!> Tipo 1:  A11 = J_m(1,-1) y A_22 = J_k(1-a,1).
!>          B11 = I_m, B22 = I_k
!>          donde J_k(a,b) es el bloque de Jordan kxk con "a" en la
!>          diagonal y "b" en la superdiagonal.
!>
!> Tipo 2:  A11 = (a_ij) = ( 2(.5-sin(i)) ) y
!>          B11 = (b_ij) = ( 2(.5-sin(ij)) ) para i=1,...,m, j=i,...,m
!>          A22 = (a_ij) = ( 2(.5-sin(i+j)) ) y
!>          B22 = (b_ij) = ( 2(.5-sin(ij)) ) para i=m+1,...,k, j=i,...,k
!>
!> Tipo 3:  A11, A22 y B11, B22 se eligen como para el Tipo 2, pero cada
!>          segundo bloque diagonal en A_11 y cada tercer bloque diagonal
!>          en A_22 se convierten en bloques de 2x2.
!>
!> Tipo 4:  A11 = ( 20(.5 - sin(ij)) ) y B22 = ( 2(.5 - sin(i+j)) )
!>             para i=1,...,m,  j=1,...,m y
!>          A22 = ( 20(.5 - sin(i+j)) ) y B22 = ( 2(.5 - sin(ij)) )
!>             para i=m+1,...,k,  j=m+1,...,k
!>
!> Tipo 5:  (A,B) y tienen valores propios potencialmente cercanos o comunes y
!>          una desviación muy grande de la diagonalidad por bloques. A_11
!>          se elige como la submatriz principal mxm de A_1:
!>                  |  1  b                            |
!>                  | -b  1                            |
!>                  |        1+d  b                    |
!>                  |         -b 1+d                   |
!>           A_1 =  |                  d  1            |
!>                  |                 -1  d            |
!>                  |                        -d  1     |
!>                  |                        -1 -d     |
!>                  |                               1  |
!>          y A_22 se elige como la submatriz principal kxk de A_2:
!>                  | -1  b                            |
!>                  | -b -1                            |
!>                  |       1-d  b                     |
!>                  |       -b  1-d                    |
!>           A_2 =  |                 d 1+b            |
!>                  |               -1-b d             |
!>                  |                       -d  1+b    |
!>                  |                      -1+b  -d    |
!>                  |                              1-d |
!>          y la matriz B se elige como matrices de identidad (ver DLATM5).
!>
!>

NAME

zdrgsx - Driver routine for the generalized Schur decomposition of a complex matrix pair (A, B).

SYNOPSIS

  SUBROUTINE ZDRGSX(
            NSIZE, N, KNT,THRESH, NIN, NOUT,
            A, LDA, B,
            AI, BI, Z, Q,
            ALPHA, BETA,
            C, LDC, S,
            WORK, LWORK, RWORK, LIWORK,
            IWORK, LIWORK,
            BWORK, INFO )

  INTEGER            INFO, KNT, LDA, LDC, LIWORK, LWORK, NIN, NOUT, N, NSIZE

  DOUBLE PRECISION   THRESH

  COMPLEX*16         A( LDA, NSIZE ), B( LDA, NSIZE ), C( LDC, LDC ),
                     AI( LDA, NSIZE ), BI( LDA, NSIZE ), Z( LDA, NSIZE ),
                     Q( LDA, NSIZE ), ALPHA( NSIZE ), BETA( NSIZE ),
                     WORK( LWORK )

  DOUBLE PRECISION   RWORK( LIWORK )

  LOGICAL            BWORK( NSIZE )

  INTEGER            IWORK( LIWORK )

Function/Subroutine Documentation

This subroutine is called by ZDRGS to compute the generalized Schur decomposition of a complex matrix pair (A,B) and to estimate the condition number for the eigenvalue problem.

Input parameter information is given in the following table:

NSIZE

!>          NSIZE is INTEGER
!>          The maximum size of the matrices, i.e., NSIZE >= max(N) over
!>          all test problems.
!>

N

!>          N is INTEGER
!>          The size of the matrices, i.e., N >= 0.
!>

KNT

!>          KNT is INTEGER
!>          KNT is the number of problems to be solved.
!>

THRESH

!>          THRESH is DOUBLE PRECISION
!>          A test will count as if the , computed as
!>          described above, exceeds THRESH. Note that the error
!>          is scaled to be O(1), so THRESH should be a reasonably
!>          small multiple of 1, e.g., 10 or 100. In particular,
!>          it should not depend on the precision (single vs. double)
!>          or the size of the matrix. THRESH >= 0.
!>

NIN

!>          NIN is INTEGER
!>          The FORTRAN unit number for reading in the data file of
!>          problems to solve.
!>

NOUT

!>          NOUT is INTEGER
!>          The FORTRAN unit number for printing out error messages
!>          (e.g., if a routine returns INFO not equal to 0.)
!>

A

!>          A is COMPLEX*16 array, dimension (LDA, NSIZE)
!>          Used to store the matrix whose eigenvalues are to be
!>          computed. On exit, A contains the last matrix actually used.
!>

LDA

!>          LDA is INTEGER
!>          The leading dimension of A, B, AI, BI, Z and Q,
!>          LDA >= max( 1, NSIZE ). For the read-in test,
!>          LDA >= max( 1, N ), N is the size of the test matrices.
!>

B

!>          B is COMPLEX*16 array, dimension (LDA, NSIZE)
!>          Used to store the matrix whose eigenvalues are to be
!>          computed. On exit, B contains the last matrix actually used.
!>

AI

!>          AI is COMPLEX*16 array, dimension (LDA, NSIZE)
!>          Copy of A, modified by ZGGESX.
!>

BI

!>          BI is COMPLEX*16 array, dimension (LDA, NSIZE)
!>          Copy of B, modified by ZGGESX.
!>

Z

!>          Z is COMPLEX*16 array, dimension (LDA, NSIZE)
!>          Z holds the left Schur vectors computed by ZGGESX.
!>

Q

!>          Q is COMPLEX*16 array, dimension (LDA, NSIZE)
!>          Q holds the right Schur vectors computed by ZGGESX.
!>

ALPHA

!>          ALPHA is COMPLEX*16 array, dimension (NSIZE)
!>

BETA

!>          BETA is COMPLEX*16 array, dimension (NSIZE)
!>
!>          On exit, ALPHA/BETA are the eigenvalues.
!>

C

!>          C is COMPLEX*16 array, dimension (LDC, LDC)
!>          Store the matrix generated by subroutine ZLAKF2, this is the
!>          matrix formed by Kronecker products used for estimating
!>          DIF.
!>

LDC

!>          LDC is INTEGER
!>          The leading dimension of C. LDC >= max(1, LDA*LDA/2 ).
!>

S

!>          S is DOUBLE PRECISION array, dimension (LDC)
!>          Singular values of C
!>

WORK

!>          WORK is COMPLEX*16 array, dimension (LWORK)
!>

LWORK

!>          LWORK is INTEGER
!>          The dimension of the array WORK. LWORK >= 3*NSIZE*NSIZE/2
!>

RWORK

!>          RWORK is DOUBLE PRECISION array,
!>                                 dimension (5*NSIZE*NSIZE/2 - 4)
!>

IWORK

!>          IWORK is INTEGER array, dimension (LIWORK)
!>

LIWORK

!>          LIWORK is INTEGER
!>          The dimension of the array IWORK. LIWORK >= NSIZE + 2.
!>

BWORK

!>          BWORK is LOGICAL array, dimension (NSIZE)
!>

INFO

!>          INFO is INTEGER
!>          = 0:  successful exit
!>          < 0:  if INFO = -i, the i-th argument had an illegal value.
!>          > 0:  A routine returned an error code.
!>
