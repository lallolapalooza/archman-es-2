Propósito:

!>
!> ZDRVBD comprueba el controlador de descomposición de valores singulares (SVD) ZGESVD,
!> ZGESDD, ZGESVJ, ZGEJSV, ZGESVDX y ZGESVDQ.
!>
!> ZGESVD y ZGESDD factorizan A = U diag(S) VT, donde U y VT son
!> unitarias y diag(S) es diagonal con las entradas del array S en
!> su diagonal. Las entradas de S son los valores singulares, no negativos
!> y almacenados en orden decreciente. U y VT pueden opcionalmente no ser
!> calculados, sobrescritos en A, o calculados parcialmente.
!>
!> A es M por N. Sea MNMIN = min( M, N ). S tiene dimensión MNMIN.
!> U puede ser M por M o M por MNMIN. VT puede ser N por N o MNMIN por N.
!>
!> Cuando se llama a ZDRVBD, se especifican varios tamaños de matriz (M's y N's)
!> y varios tipos de matrices. Para cada tamaño (M,N)
!> y cada tipo de matriz, y para el espacio de trabajo mínimo así como
!> para un espacio de trabajo adecuado para permitir el bloqueo, se generará
!> una matriz M x N y se utilizará para probar las rutinas SVD. Para cada matriz,
!> A se factorizará como A = U diag(S) VT y se calcularán las siguientes 12 pruebas:
!>
!> Prueba para ZGESVD:
!>
!> (1)   | A - U diag(S) VT | / ( |A| max(M,N) ulp )
!>
!> (2)   | I - U'U | / ( M ulp )
!>
!> (3)   | I - VT VT' | / ( N ulp )
!>
!> (4)   S contiene MNMIN valores no negativos en orden decreciente.
!>       (Devuelve 0 si es verdadero, 1/ULP si es falso.)
!>
!> (5)   | U - Upartial | / ( M ulp ) donde Upartial es una U calculada parcialmente.
!>
!> (6)   | VT - VTpartial | / ( N ulp ) donde VTpartial es una VT calculada parcialmente.
!>
!> (7)   | S - Spartial | / ( MNMIN ulp |S| ) donde Spartial es el
!>       vector de valores singulares de la SVD parcial
!>
!> Prueba para ZGESDD:
!>
!> (8)   | A - U diag(S) VT | / ( |A| max(M,N) ulp )
!>
!> (9)   | I - U'U | / ( M ulp )
!>
!> (10)  | I - VT VT' | / ( N ulp )
!>
!> (11)  S contiene MNMIN valores no negativos en orden decreciente.
!>       (Devuelve 0 si es verdadero, 1/ULP si es falso.)
!>
!> (12)  | U - Upartial | / ( M ulp ) donde Upartial es una U calculada parcialmente.
!>
!> (13)  | VT - VTpartial | / ( N ulp ) donde VTpartial es una VT calculada parcialmente.
!>
!> (14)  | S - Spartial | / ( MNMIN ulp |S| ) donde Spartial es el
!>       vector de valores singulares de la SVD parcial
!>
!> Prueba para ZGESVDQ:
!>
!> (36)  | A - U diag(S) VT | / ( |A| max(M,N) ulp )
!>
!> (37)  | I - U'U | / ( M ulp )
!>
!> (38)  | I - VT VT' | / ( N ulp )
!>
!> (39)  S contiene MNMIN valores no negativos en orden decreciente.
!>       (Devuelve 0 si es verdadero, 1/ULP si es falso.)
!>
!> Prueba para ZGESVJ:
!>
!> (15)  | A - U diag(S) VT | / ( |A| max(M,N) ulp )
!>
!> (16)  | I - U'U | / ( M ulp )
!>
!> (17)  | I - VT VT' | / ( N ulp )
!>
!> (18)  S contiene MNMIN valores no negativos en orden decreciente.
!>       (Devuelve 0 si es verdadero, 1/ULP si es falso.)
!>
!> Prueba para ZGEJSV:
!>
!> (19)  | A - U diag(S) VT | / ( |A| max(M,N) ulp )
!>
!> (20)  | I - U'U | / ( M ulp )
!>
!> (21)  | I - VT VT' | / ( N ulp )
!>
!> (22)  S contiene MNMIN valores no negativos en orden decreciente.
!>        (Devuelve 0 si es verdadero, 1/ULP si es falso.)
!>
!> Prueba para ZGESVDX( 'V', 'V', 'A' )/ZGESVDX( 'N', 'N', 'A' )
!>
!> (23)  | A - U diag(S) VT | / ( |A| max(M,N) ulp )
!>
!> (24)  | I - U'U | / ( M ulp )
!>
!> (25)  | I - VT VT' | / ( N ulp )
!>
!> (26)  S contiene MNMIN valores no negativos en orden decreciente.
!>       (Devuelve 0 si es verdadero, 1/ULP si es falso.)
!>
!> (27)  | U - Upartial | / ( M ulp ) donde Upartial es una U calculada parcialmente.
!>
!> (28)  | VT - VTpartial | / ( N ulp ) donde VTpartial es una VT calculada parcialmente.
!>
!> (29)  | S - Spartial | / ( MNMIN ulp |S| ) donde Spartial es el
!>       vector de valores singulares de la SVD parcial
!>
!> Prueba para ZGESVDX( 'V', 'V', 'I' )
!>
!> (30)  | U' A VT''' - diag(S) | / ( |A| max(M,N) ulp )
!>
!> (31)  | I - U'U | / ( M ulp )
!>
!> (32)  | I - VT VT' | / ( N ulp )
!>
!> Prueba para ZGESVDX( 'V', 'V', 'V' )
!>
!> (33)   | U' A VT''' - diag(S) | / ( |A| max(M,N) ulp )
!>
!> (34)   | I - U'U | / ( M ulp )
!>
!> (35)   | I - VT VT' | / ( N ulp )
!>
!> Los tamaños de matriz (M's y N's) se especifican mediante los arrays MM(1:NSIZES) y
!> NN(1:NSIZES); el valor de cada par de elementos (MM(j),NN(j))
!> especifica un tamaño. Los tipos de matriz se especifican mediante un array lógico
!> DOTYPE( 1:NTYPES ); si DOTYPE(j) es .TRUE., entonces se generará una matriz de tipo j.
!> Actualmente, la lista de tipos posibles es:
!>
!> (1)  La matriz cero.
!> (2)  La matriz identidad.
!> (3)  Una matriz de la forma U D V, donde U y V son unitarias y
!>      D tiene entradas espaciadas uniformemente 1, ..., ULP con signos aleatorios
!>      en la diagonal.
!> (4)  Igual que (3), pero multiplicada por el umbral de subdesbordamiento / ULP.
!> (5)  Igual que (3), pero multiplicada por el umbral de desbordamiento * ULP.
!>

Parámetros

NSIZES 
!>          NSIZES es INTEGER
!>          El número de tamaños de matriz a utilizar. Si es cero,
!>          ZDRVBD no hace nada. Debe ser al menos cero.
!>

MM

!>          MM es un array INTEGER, dimension (NSIZES)
!>          Un array que contiene las dimensiones M de la matriz a utilizar. Para
!>          cada j=1,...,NSIZES, si MM(j) es cero, entonces MM(j) y NN(j)
!>          serán ignorados. Los valores de MM(j) deben ser al menos cero.
!>

NN

!>          NN es un array INTEGER, dimension (NSIZES)
!>          Un array que contiene las dimensiones N de la matriz a utilizar. Para
!>          cada j=1,...,NSIZES, si NN(j) es cero, entonces MM(j) y NN(j)
!>          serán ignorados. Los valores de NN(j) deben ser al menos cero.
!>

NTYPES

!>          NTYPES es INTEGER
!>          El número de elementos en DOTYPE. Si es cero, ZDRVBD
!>          no hace nada. Debe ser al menos cero. Si es MAXTYP+1
!>          y NSIZES es 1, entonces se define un tipo adicional, MAXTYP+1,
!>          que es usar las matrices que estén en A y B.
!>          Esto sólo es útil si DOTYPE(1:MAXTYP) es .FALSE. y
!>          DOTYPE(MAXTYP+1) es .TRUE. .
!>

DOTYPE

!>          DOTYPE es un array LOGICAL, dimension (NTYPES)
!>          Si DOTYPE(j) es .TRUE., entonces para cada tamaño (m,n), se generará una matriz
!>          de tipo j. Si NTYPES es ...

zdrvbd —

SYNOPSIS

SUBROUTINE ZDRVBD( NSIZES, NN, NTYPES, DOTYPE, DWORK, ISEED, THRESH, A, LDA, U, LDU, VT, LDVT, ASAV, USAV, VTSAV, S, SSAV, E, WORK, LWORK, RWORK, IWORK, NOUNIT, INFO )

Documentation

This routine is a driver for the general complex double precision routine ZGESVD, which computes the singular value decomposition of a general rectangular matrix.

The driver routine ZDRVBD attempts to solve the problem

A = U * S * VT

for the matrix A = U * DIAG(S) * VT, where U and VT are unitary and S is a diagonal matrix with real nonnegative entries.

ZDRVBD calls the subroutine ZLATMS to generate random matrices of specified dimensions and types, and then calls ZGESVD to compute their singular values and singular vectors.

The driver routine ZDRVBD is called with the following arguments:

NSIZES
          NSIZES is INTEGER
          The number of sizes of matrices to test. NSIZES >= 0.
NN
          NN is INTEGER array, dimension (NSIZES)
          Contains the sizes of the matrices to be tested.
          NN(j) specifies the number of columns of the matrix A(j)
          to be tested. NN(j) must be at least 0.
NTYPES
          NTYPES is INTEGER
          The number of types of matrices to be generated. NTYPES >= 0.
          If NTYPES = 0, then no matrices are generated.
DOTYPE
          DOTYPE is LOGICAL array, dimension (NTYPES)
          DOTYPE(k) = .TRUE. if the k-th matrix type is to be tested,
          and .FALSE. otherwise.
DWORK
          DWORK is DOUBLE PRECISION array, dimension (max(MM,NN))
          Used by ZLATMS.
ISEED
          ISEED is INTEGER array, dimension (4)
          On entry ISEED specifies the seed of the random number
          generator. The array elements should be between 0 and 4095;
          if not they will be reduced mod 4096.  Also, ISEED(4) must
          be odd.  The random number generator uses a linear
          congruential sequence limited to small integers, and so
          should produce machine independent random numbers. The
          values of ISEED are changed on exit, and can be used in the
          next call to ZDRVBD to continue the same random number
          sequence.
THRESH
          THRESH is DOUBLE PRECISION
          A test will count as  if the , computed as
          described above, exceeds THRESH.  Note that the error
          is scaled to be O(1), so THRESH should be a reasonably
          small multiple of 1, e.g., 10 or 100.  In particular,
          it should not depend on the precision (single vs. double)
          or the size of the matrix.  It must be at least zero.
A
          A is COMPLEX*16 array, dimension (LDA,max(NN))
          Used to hold the matrix whose singular values are to be
          computed.  On exit, A contains the last matrix actually
          used.
LDA
          LDA is INTEGER
          The leading dimension of A.  It must be at
          least 1 and at least max( MM ).
U
          U is COMPLEX*16 array, dimension (LDU,max(MM))
          Used to hold the computed matrix of right singular vectors.
          On exit, U contains the last such vectors actually computed.
LDU
          LDU is INTEGER
          The leading dimension of U.  It must be at
          least 1 and at least max( MM ).
VT
          VT is COMPLEX*16 array, dimension (LDVT,max(NN))
          Used to hold the computed matrix of left singular vectors.
          On exit, VT contains the last such vectors actually computed.
LDVT
          LDVT is INTEGER
          The leading dimension of VT.  It must be at
          least 1 and at least max( NN ).
ASAV
          ASAV is COMPLEX*16 array, dimension (LDA,max(NN))
          Used to hold a different copy of the matrix whose singular
          values are to be computed.  On exit, A contains the last
          matrix actually used.
USAV
          USAV is COMPLEX*16 array, dimension (LDU,max(MM))
          Used to hold a different copy of the computed matrix of
          right singular vectors. On exit, USAV contains the last such
          vectors actually computed.
VTSAV
          VTSAV is COMPLEX*16 array, dimension (LDVT,max(NN))
          Used to hold a different copy of the computed matrix of
          left singular vectors. On exit, VTSAV contains the last such
          vectors actually computed.
S
          S is DOUBLE PRECISION array, dimension (max(min(MM,NN)))
          Contains the computed singular values.
SSAV
          SSAV is DOUBLE PRECISION array, dimension (max(min(MM,NN)))
          Contains another copy of the computed singular values.
E
          E is DOUBLE PRECISION array, dimension (max(min(MM,NN)))
          Workspace for ZGESVD.
WORK
          WORK is COMPLEX*16 array, dimension (LWORK)
LWORK
          LWORK is INTEGER
          The number of entries in WORK.  This must be at least
          MAX(3*MIN(M,N)+MAX(M,N)**2,5*MIN(M,N),3*MAX(M,N)) for all
          pairs  (M,N)=(MM(j),NN(j))
RWORK
          RWORK is DOUBLE PRECISION array,
                      dimension ( 5*max(max(MM,NN)) )
IWORK
          IWORK is INTEGER array, dimension at least 8*min(M,N)
NOUNIT
          NOUNIT is INTEGER
          The FORTRAN unit number for printing out error messages
          (e.g., if a routine returns IINFO not equal to 0.)
INFO
          INFO is INTEGER
          If 0, then everything ran OK.
           -1: NSIZES < 0
           -2: Some MM(j) < 0
           -3: Some NN(j) < 0
           -4: NTYPES < 0
           -7: THRESH < 0
          -10: LDA < 1 or LDA < MMAX, where MMAX is max( MM(j) ).
          -12: LDU < 1 or LDU < MMAX.
          -14: LDVT < 1 or LDVT < NMAX, where NMAX is max( NN(j) ).
          -21: LWORK too small.
          If  ZLATMS, or ZGESVD returns an error code, the
              absolute value of it is returned.
