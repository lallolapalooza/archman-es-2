Documentación de la función/subrutina

subroutine zdrot (integer n, complex*16, dimension( * ) zx, integer incx, complex*16, dimension( * ) zy, integer incy, double precision c, double precision s)

ZDROT

Propósito:

!>
!> Aplica una rotación de plano, donde el cos y sin (c y s) son reales
!> y los vectores cx y cy son complejos.
!> jack dongarra, linpack, 3/11/78.
!>

Parámetros

N 
!>          N es un ENTERO
!>           A la entrada, N especifica el orden de los vectores cx y cy.
!>           N debe ser al menos cero.
!>

ZX

!>          ZX es un array COMPLEX*16, de dimensión al menos
!>           ( 1 + ( N - 1 )*abs( INCX ) ).
!>           Antes de la entrada, el array ZX incrementado debe contener el vector
!>           cx de n elementos. A la salida, ZX se sobrescribe con el vector
!>           cx actualizado.
!>

INCX

!>          INCX es un ENTERO
!>           A la entrada, INCX especifica el incremento para los elementos de
!>           ZX. INCX no debe ser cero.
!>

ZY

!>          ZY es un array COMPLEX*16, de dimensión al menos
!>           ( 1 + ( N - 1 )*abs( INCY ) ).
!>           Antes de la entrada, el array ZY incrementado debe contener el vector
!>           cy de n elementos. A la salida, ZY se sobrescribe con el vector
!>           cy actualizado.
!>

INCY

!>          INCY es un ENTERO
!>           A la entrada, INCY especifica el incremento para los elementos de
!>           ZY. INCY no debe ser cero.
!>

C

!>          C es DOUBLE PRECISION
!>           A la entrada, C especifica el coseno, cos.
!>

S

!>          S es DOUBLE PRECISION
!>           A la entrada, S especifica el seno, sin.
!>
