Documentación de función/subrutina

subroutine zdrges3 (nsizes entero, nn entero, dimensión(\*) nn, ntypes entero, dotype lógico, dimensión(\*) dotype, iseed entero, dimensión(4) iseed, thresh precisión doble, nounit entero, a complex*16, dimensión(lda, \*), lda entero, b complex*16, dimensión(lda, \*), s complex*16, dimensión(lda, \*), t complex*16, dimensión(ldq, \*), q complex*16, dimensión(ldq, \*), ldq entero, z complex*16, dimensión(\*), alpha complex*16, dimensión(\*), beta complex*16, dimensión(\*), work complex*16, dimensión(\*), lwork entero, rwork precisión doble, dimensión(\*), result precisión doble, dimensión(13), bwork lógico, dimensión(\*), info entero)

ZDRGES3

Propósito:

!>
!> ZDRGES3 comprueba el controlador del problema de valores propios generalizados no simétricos (forma de Schur) ZGGES3.
!>
!> ZGGES3 factoriza A y B como Q*S*Z' y Q*T*Z', donde ' significa transpuesta conjugada, S y T son triangulares superiores (es decir, en forma de Schur generalizada), y Q y Z son unitarias. También calcula los valores propios generalizados (alpha(j),beta(j)), j=1,...,n. Por lo tanto,
!> w(j) = alpha(j)/beta(j) es una raíz de la ecuación característica
!>
!>                 det( A - w(j) B ) = 0
!>
!> Opcionalmente, también reordena los valores propios para que un clúster seleccionado de valores propios aparezca en el bloque diagonal principal de las formas de Schur.
!>
!> Cuando se llama a ZDRGES3, se especifica un número de tamaños de matrices y un número de tipos de matrices. Para cada tamaño y cada TIPO de matriz, se generará y utilizará un par de matrices (A, B) para las pruebas. Para cada par de matrices, se realizarán las siguientes 13 pruebas y se compararán con el umbral THRESH, excepto las pruebas (5), (11) y (13).
!>
!>
!> (1)   | A - Q S Z' | / ( |A| n ulp ) (sin ordenación de valores propios)
!>
!>
!> (2)   | B - Q T Z' | / ( |B| n ulp ) (sin ordenación de valores propios)
!>
!>
!> (3)   | I - QQ' | / ( n ulp ) (sin ordenación de valores propios)
!>
!>
!> (4)   | I - ZZ' | / ( n ulp ) (sin ordenación de valores propios)
!> (5)   si A está en forma de Schur (es decir, forma triangular) (sin ordenación de
!>       valores propios)
!>
!> (6)   si los valores propios = elementos diagonales de la forma de Schur (S, T),
!>       es decir, prueba el máximo sobre j de D(j) donde:
!>
!>                     |alpha(j) - S(j,j)|        |beta(j) - T(j,j)|
!>           D(j) = ------------------------ + -----------------------
!>                  max(|alpha(j)|,|S(j,j)|)   max(|beta(j)|,|T(j,j)|)
!>
!>       (sin ordenación de valores propios)
!>
!> (7)   | (A,B) - Q (S,T) Z' | / ( |(A,B)| n ulp )
!>       (con ordenación de valores propios).
!>
!> (8)   | I - QQ' | / ( n ulp ) (con ordenación de valores propios).
!>
!> (9)   | I - ZZ' | / ( n ulp ) (con ordenación de valores propios).
!>
!> (10)  si A está en forma de Schur (es decir, forma cuasi-triangular)
!>       (con ordenación de valores propios).
!>
!> (11)  si los valores propios = elementos diagonales de la forma de Schur (S, T),
!>       es decir, prueba el máximo sobre j de D(j) donde:
!>
!>                     |alpha(j) - S(j,j)|        |beta(j) - T(j,j)|
!>           D(j) = ------------------------ + -----------------------
!>                  max(|alpha(j)|,|S(j,j)|)   max(|beta(j)|,|T(j,j)|)
!>
!>       (con ordenación de valores propios).
!>
!> (12)  si la ordenación funcionó y SDIM es el número de valores propios
!>       que fueron SELECCIONADOS.
!>
!> Matrices de Prueba
!> =============
!>
!> Los tamaños de las matrices de prueba se especifican mediante un array
!> NN(1:NSIZES); el valor de cada elemento NN(j) especifica un tamaño.
!> Los tipos se especifican mediante un array lógico DOTYPE( 1:NTYPES ); si
!> DOTYPE(j) es .TRUE., entonces se generará el tipo de matriz j.
!> Actualmente, la lista de tipos posibles es:
!>
!> (1)  ( 0, 0 )         (un par de matrices cero)
!>
!> (2)  ( I, 0 )         (una identidad y una matriz cero)
!>
!> (3)  ( 0, I )         (una identidad y una matriz cero)
!>
!> (4)  ( I, I )         (un par de matrices identidad)
!>
!>         t   t
!> (5)  ( J , J  )       (un par de bloques de Jordan transpuestos)
!>
!>                                     t                ( I   0  )
!> (6)  ( X, Y )         donde  X = ( J   0  )  y Y = (      t )
!>                                  ( 0   I  )          ( 0   J  )
!>                       y I es una identidad k x k y J un bloque de Jordan (k+1)x(k+1)
!>                       k=(N-1)/2
!>
!> (7)  ( D, I )         donde D es diag( 0, 1,..., N-1 ) (una matriz diagonal
!>                       con esas entradas diagonales.)
!> (8)  ( I, D )
!>
!> (9)  ( big*D, small*I ) donde big es cercano al desbordamiento y small=1/big
!>
!> (10) ( small*D, big*I )
!>
!> (11) ( big*I, small*D )
!>
!> (12) ( small*I, big*D )
!>
!> (13) ( big*D, big*I )
!>
!> (14) ( small*D, small*I )
!>
!> (15) ( D1, D2 )        donde D1 es diag( 0, 0, 1, ..., N-3, 0 ) y
!>                        D2 es diag( 0, N-3, N-4,..., 1, 0, 0 )
!>           t   t
!> (16) Q ( J , J ) Z     donde Q y Z son matrices ortogonales aleatorias.
!>
!> (17) Q ( T1, T2 ) Z    donde T1 y T2 son matrices triangulares superiores
!>                        con entradas O(1) aleatorias por encima de la diagonal
!>                        y entradas diagonales diag(T1) =
!>                        ( 0, 0, 1, ..., N-3, 0 ) y diag(T2) =
!>                        ( 0, N-3, N-4,..., 1, 0, 0 )
!>
!> (18) Q ( T1, T2 ) Z    diag(T1) = ( 0, 0, 1, 1, s, ..., s, 0 )
!>                        diag(T2) = ( 0, 1, 0, 1,..., 1, 0 )
!>                        s = precisión de la máquina.
!>
!> (19) Q ( T1, T2 ) Z    diag(T1)=( 0,0,1,1, 1-d, ..., 1-(N-5)*d=s, 0 )
!>                        diag(T2) = ( 0, 1, 0, 1, ..., 1, 0 )
!>
!>                                                        N-5
!> (20) Q ( T1, T2 ) Z    diag(T1)=( 0, 0, 1, 1, a, ..., a   =s, 0 )
!>                        diag(T2) = ( 0, 1, 0, 1, ..., 1, 0, 0 )
!>
!> (21) Q ( T1, T2 ) Z    diag(T1)=( 0, 0, 1, r1, r2, ..., r(N-4), 0 )
!>                        diag(T2) = ( 0, 1, 0, 1, ..., 1, 0, 0 )
!>                        donde r1,..., r(N-4) son aleatorias.
!>
!> (22) Q ( big*T1, small*T2 ) Z    diag(T1) = ( 0, 0, 1, ..., N-3, 0 )
!>                                  diag(T2) = ( 0, 1, ..., 1, 0, 0 )
!>
!> (23) Q ( small*T1, big*T2 ) Z    diag(T1) = ( 0, 0, 1, ..., N-3, 0 )
!>                                  diag(T2) = ( 0, 1, ..., 1, 0, 0 )
!>
!> (24) Q ( small*T1, small*T2 ) Z  diag(T1) = ( 0, 0, 1, ..., N-3, 0 )
!>                                  diag(T2) = ( 0, 1, ..., 1, 0, 0 )
!>
!> (25) Q ( big*T1, big*T2 ) Z      diag(T1) = ( 0, 0, 1, ..., N-3, 0 )
!>                                  diag(T2) = ( 0, 1, ..., 1, 0, 0 )
!>
!> (26) Q ( T1, T2 ) Z     donde T1 y T2 son matrices triangulares superiores aleatorias.
!>
!>

Parámetros

NSIZES 
!>          NSIZES es INTEGER
!>          El número de tamaños de matrices a usar. Si es cero,
!>          DDRGES3 no hace nada.  NSIZES >= 0.
!>

NN

!>          NN es un array de INTEGER, dimensión (NSIZES)
!>          Un array que contiene los tamaños a usar para las matrices.
!>          Los valores cero serán omitidos.  NN >= 0.
!>

NTYPES

NTYPES

NTYPES es un entero. El número de elementos en DOTYPE. Si es cero, DDRGES3 no hace nada. Debe ser al menos cero. Si es MAXTYP+1 y NSIZES es 1, entonces se define un tipo adicional, MAXTYP+1, que es usar la matriz que esté en A en la entrada. Esto solo es útil si DOTYPE(1:MAXTYP) es .FALSE. y DOTYPE(MAXTYP+1) es .TRUE.

DOTYPE

DOTYPE es un array lógico, de dimensión (NTYPES). Si DOTYPE(j) es .TRUE., entonces para cada tamaño en NN se generará una matriz de ese tamaño y de tipo j. Si NTYPES es menor que el número máximo de tipos definidos (PARAMETER MAXTYP), entonces los tipos NTYPES+1 hasta MAXTYP no se generarán. Si NTYPES es mayor que MAXTYP, DOTYPE(MAXTYP+1) hasta DOTYPE(NTYPES) serán ignorados.

ISEED

ISEED es un array de enteros, de dimensión (4). En la entrada, ISEED especifica la semilla del generador de números aleatorios. Los elementos del array deben estar entre 0 y 4095; si no, se reducirán módulo 4096. Además, ISEED(4) debe ser impar. El generador de números aleatorios utiliza una secuencia congruencial lineal limitada a enteros pequeños, y por lo tanto debería producir números aleatorios independientes de la máquina. Los valores de ISEED se modifican a la salida y pueden usarse en la siguiente llamada a DDRGES3 para continuar la misma secuencia de números aleatorios.

THRESH

THRESH es DOUBLE PRECISION. Una prueba se contará como si el error, calculado como se describe anteriormente, excede THRESH. Tenga en cuenta que el error se escala para ser O(1), por lo que THRESH debería ser un múltiplo razonablemente pequeño de 1, por ejemplo, 10 o 100. En particular, no debe depender de la precisión (simple o doble) ni del tamaño de la matriz. THRESH >= 0.

NOUNIT

NOUNIT es INTEGER. El número de unidad FORTRAN para imprimir mensajes de error (por ejemplo, si una rutina devuelve IINFO distinto de 0).

A

A es un array COMPLEX*16, de dimensión(LDA, max(NN)). Se utiliza para contener la matriz A original. Se usa como entrada solo si NTYPES=MAXTYP+1, DOTYPE(1:MAXTYP)=.FALSE. y DOTYPE(MAXTYP+1)=.TRUE.

LDA

LDA es INTEGER. La dimensión principal de A, B, S y T. Debe ser al menos 1 y al menos max(NN).

B

B es un array COMPLEX*16, de dimensión(LDA, max(NN)). Se utiliza para contener la matriz B original. Se usa como entrada solo si NTYPES=MAXTYP+1, DOTYPE(1:MAXTYP)=.FALSE. y DOTYPE(MAXTYP+1)=.TRUE.

S

S es un array COMPLEX*16, de dimensión (LDA, max(NN)). La forma de Schur calculada a partir de A por ZGGES3. A la salida, S contiene la forma de Schur correspondiente a la matriz en A.

T

T es un array COMPLEX*16, de dimensión (LDA, max(NN)). La matriz triangular superior calculada a partir de B por ZGGES3.

Q

Q es un array COMPLEX*16, de dimensión (LDQ, max(NN)). La matriz ortogonal (izquierda) calculada por ZGGES3.

LDQ

LDQ es INTEGER. La dimensión principal de Q y Z. Debe ser al menos 1 y al menos max(NN).

Z

Z es un array COMPLEX*16, de dimensión( LDQ, max(NN) ). La matriz ortogonal (derecha) calculada por ZGGES3.

ALPHA

ALPHA es un array COMPLEX*16, de dimensión (max(NN)).

BETA

BETA es un array COMPLEX*16, de dimensión (max(NN)). Los valores propios generalizados de (A,B) calculados por ZGGES3. ALPHA(k) / BETA(k) es el k-ésimo valor propio generalizado de A y B.

WORK

WORK es un array COMPLEX*16, de dimensión (LWORK).

LWORK

LWORK es INTEGER. La dimensión del array WORK. LWORK >= 3*N*N.

RWORK

RWORK es un array DOUBLE PRECISION, de dimensión ( 8*N ). Espacio de trabajo real.

RESULT

RESULT es un array DOUBLE PRECISION, de dimensión (15). Los valores calculados por las pruebas descritas anteriormente. Los valores están actualmente limitados a 1/ulp, para evitar desbordamiento.

BWORK

BWORK es un array LOGICAL, de dimensión (N).

INFO

INFO es INTEGER. = 0: salida exitosa. < 0: si INFO = -i, el i-ésimo argumento tenía un valor ilegal. > 0: una rutina devolvió un código de error. INFO es el valor absoluto del valor INFO devuelto.
