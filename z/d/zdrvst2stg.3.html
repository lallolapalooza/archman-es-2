Propósito:

!>
!>      ZDRVST2STG  comprueba los drivers del problema de valores propios Hermítico.
!>
!>              ZHEEVD calcula todos los valores propios y, opcionalmente,
!>              los vectores propios de una matriz Hermítica compleja,
!>              utilizando un algoritmo de divide y vencerás.
!>
!>              ZHEEVX calcula valores propios seleccionados y, opcionalmente,
!>              vectores propios de una matriz Hermítica compleja.
!>
!>              ZHEEVR calcula valores propios seleccionados y, opcionalmente,
!>              vectores propios de una matriz Hermítica compleja
!>              utilizando la Representación Relativamente Robusta donde sea posible.
!>
!>              ZHPEVD calcula todos los valores propios y, opcionalmente,
!>              los vectores propios de una matriz Hermítica compleja en
!>              almacenamiento empaquetado, utilizando un algoritmo de divide y vencerás.
!>
!>              ZHPEVX calcula valores propios seleccionados y, opcionalmente,
!>              vectores propios de una matriz Hermítica compleja en
!>              almacenamiento empaquetado.
!>
!>              ZHBEVD calcula todos los valores propios y, opcionalmente,
!>              los vectores propios de una matriz de banda Hermítica compleja,
!>              utilizando un algoritmo de divide y vencerás.
!>
!>              ZHBEVX calcula valores propios seleccionados y, opcionalmente,
!>              vectores propios de una matriz de banda Hermítica compleja.
!>
!>              ZHEEV calcula todos los valores propios y, opcionalmente,
!>              los vectores propios de una matriz Hermítica compleja.
!>
!>              ZHPEV calcula todos los valores propios y, opcionalmente,
!>              los vectores propios de una matriz Hermítica compleja en almacenamiento empaquetado.
!>
!>              ZHBEV calcula todos los valores propios y, opcionalmente,
!>              los vectores propios de una matriz de banda Hermítica compleja.
!>
!>      Cuando se llama a ZDRVST2STG, se especifica un número de tamaños de matriz () y un
!>      número de tipos de matriz. Para cada tamaño ()
!>      y cada tipo de matriz, se generará una matriz y se utilizará
!>      para probar los drivers apropiados. Para cada matriz y cada
!>      rutina de driver llamada, se realizarán las siguientes pruebas:
!>
!>      (1)     | A - Z D Z' | / ( |A| n ulp )
!>
!>      (2)     | I - Z Z' | / ( n ulp )
!>
!>      (3)     | D1 - D2 | / ( |D1| ulp )
!>
!>      donde Z es la matriz de vectores propios devuelta cuando se
!>      da la opción de vector propio y D1 y D2 son los valores propios
!>      devueltos con y sin la opción de vector propio.
!>
!>      Los se especifican mediante un array NN(1:NSIZES); el valor de
!>      cada elemento NN(j) especifica un tamaño.
!>      Los se especifican mediante un array lógico DOTYPE( 1:NTYPES );
!>      si DOTYPE(j) es .TRUE., entonces se generará la matriz de tipo j.
!>      Actualmente, la lista de tipos posibles es:
!>
!>      (1)  La matriz cero.
!>      (2)  La matriz identidad.
!>
!>      (3)  Una matriz diagonal con entradas espaciadas uniformemente
!>           1, ..., ULP  y signos aleatorios.
!>           (ULP = (primer número mayor que 1) - 1 )
!>      (4)  Una matriz diagonal con entradas espaciadas geométricamente
!>           1, ..., ULP  y signos aleatorios.
!>      (5)  Una matriz diagonal con entradas 1, ULP, ..., ULP
!>           y signos aleatorios.
!>
!>      (6)  Igual que (4), pero multiplicado por SQRT( umbral de desbordamiento )
!>      (7)  Igual que (4), pero multiplicado por SQRT( umbral de subdesbordamiento )
!>
!>      (8)  Una matriz de la forma  U* D U, donde U es unitaria y
!>           D tiene entradas espaciadas uniformemente 1, ..., ULP con signos
!>           aleatorios en la diagonal.
!>
!>      (9)  Una matriz de la forma  U* D U, donde U es unitaria y
!>           D tiene entradas espaciadas geométricamente 1, ..., ULP con signos
!>           aleatorios en la diagonal.
!>
!>      (10) Una matriz de la forma  U* D U, donde U es unitaria y
!>           D tiene entradas 1, ULP,..., ULP con signos
!>           aleatorios en la diagonal.
!>
!>      (11) Igual que (8), pero multiplicado por SQRT( umbral de desbordamiento )
!>      (12) Igual que (8), pero multiplicado por SQRT( umbral de subdesbordamiento )
!>
!>      (13) Matriz simétrica con entradas aleatorias elegidas entre (-1,1).
!>      (14) Igual que (13), pero multiplicado por SQRT( umbral de desbordamiento )
!>      (15) Igual que (13), pero multiplicado por SQRT( umbral de subdesbordamiento )
!>      (16) Una matriz de banda con semi-ancho de banda elegido aleatoriamente entre
!>           0 y N-1, con valores propios espaciados uniformemente 1, ..., ULP
!>           con signos aleatorios.
!>      (17) Igual que (16), pero multiplicado por SQRT( umbral de desbordamiento )
!>      (18) Igual que (16), pero multiplicado por SQRT( umbral de subdesbordamiento )

!>          El número de tamaños de matrices a utilizar. Si es cero,
!>          ZDRVST2STG no hace nada. Debe ser como mínimo cero.
!>          No modificado.
!>
!>  NN      INTEGER array, dimension (NSIZES)
!>          Un array que contiene los tamaños a utilizar para las matrices.
