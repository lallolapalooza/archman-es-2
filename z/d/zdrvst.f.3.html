ZDRVST

Propósito:

!>
!>      ZDRVST  comprueba los drivers de problemas de valores propios Hermíticos.
!>
!>              ZHEEVD calcula todos los valores propios y, opcionalmente,
!>              los vectores propios de una matriz Hermítica compleja,
!>              utilizando un algoritmo de divide y vencerás.
!>
!>              ZHEEVX calcula valores propios seleccionados y, opcionalmente,
!>              vectores propios de una matriz Hermítica compleja.
!>
!>              ZHEEVR calcula valores propios seleccionados y, opcionalmente,
!>              vectores propios de una matriz Hermítica compleja
!>              utilizando la Representación Relativamente Robusta donde sea posible.
!>
!>              ZHPEVD calcula todos los valores propios y, opcionalmente,
!>              los vectores propios de una matriz Hermítica compleja en
!>              almacenamiento empaquetado, utilizando un algoritmo de divide y vencerás.
!>
!>              ZHPEVX calcula valores propios seleccionados y, opcionalmente,
!>              vectores propios de una matriz Hermítica compleja en
!>              almacenamiento empaquetado.
!>
!>              ZHBEVD calcula todos los valores propios y, opcionalmente,
!>              los vectores propios de una matriz de banda Hermítica compleja,
!>              utilizando un algoritmo de divide y vencerás.
!>
!>              ZHBEVX calcula valores propios seleccionados y, opcionalmente,
!>              vectores propios de una matriz de banda Hermítica compleja.
!>
!>              ZHEEV calcula todos los valores propios y, opcionalmente,
!>              los vectores propios de una matriz Hermítica compleja.
!>
!>              ZHPEV calcula todos los valores propios y, opcionalmente,
!>              los vectores propios de una matriz Hermítica compleja en
!>              almacenamiento empaquetado.
!>
!>              ZHBEV calcula todos los valores propios y, opcionalmente,
!>              los vectores propios de una matriz de banda Hermítica compleja.
!>
!>      Cuando se llama a ZDRVST, se especifican varios tamaños de matriz () y
!>      varios tipos de matriz. Para cada tamaño ()
!>      y cada tipo de matriz, se generará una matriz y se utilizará
!>      para probar los drivers apropiados. Para cada matriz y cada
!>      driver llamado, se realizarán las siguientes pruebas:
!>
!>      (1)     | A - Z D Z' | / ( |A| n ulp )
!>
!>      (2)     | I - Z Z' | / ( n ulp )
!>
!>      (3)     | D1 - D2 | / ( |D1| ulp )
!>
!>      donde Z es la matriz de vectores propios devuelta cuando se da la
!>      opción de vector propio y D1 y D2 son los valores propios
!>      devueltos con y sin la opción de vector propio.
!>
!>      Los tamaños () se especifican mediante un array NN(1:NSIZES); el valor de
!>      cada elemento NN(j) especifica un tamaño.
!>      Los tipos de matriz se especifican mediante un array lógico DOTYPE( 1:NTYPES );
!>      si DOTYPE(j) es .TRUE., entonces se generará la matriz de tipo j.
!>      Actualmente, la lista de tipos posibles es:
!>
!>      (1)  La matriz cero.
!>      (2)  La matriz identidad.
!>
!>      (3)  Una matriz diagonal con entradas espaciadas uniformemente
!>           1, ..., ULP y signos aleatorios.
!>           (ULP = (primer número mayor que 1) - 1)
!>      (4)  Una matriz diagonal con entradas espaciadas geométricamente
!>           1, ..., ULP y signos aleatorios.
!>      (5)  Una matriz diagonal con entradas 1, ULP, ..., ULP
!>           y signos aleatorios.
!>
!>      (6)  Igual que (4), pero multiplicado por SQRT( umbral de desbordamiento )
!>      (7)  Igual que (4), pero multiplicado por SQRT( umbral de subdesbordamiento )
!>
!>      (8)  Una matriz de la forma U* D U, donde U es unitaria y
!>           D tiene entradas espaciadas uniformemente 1, ..., ULP con signos
!>           aleatorios en la diagonal.
!>
!>      (9)  Una matriz de la forma U* D U, donde U es unitaria y
!>           D tiene entradas espaciadas geométricamente 1, ..., ULP con signos
!>           aleatorios en la diagonal.
!>
!>      (10) Una matriz de la forma U* D U, donde U es unitaria y
!>           D tiene entradas 1, ULP,..., ULP con signos
!>           aleatorios en la diagonal.
!>
!>      (11) Igual que (8), pero multiplicado por SQRT( umbral de desbordamiento )
!>      (12) Igual que (8), pero multiplicado por SQRT( umbral de subdesbordamiento )
!>
!>      (13) Matriz simétrica con entradas aleatorias elegidas de (-1,1).
!>      (14) Igual que (13), pero multiplicado por SQRT( umbral de desbordamiento )
!>      (15) Igual que (13), pero multiplicado por SQRT( umbral de subdesbordamiento )
!>      (16) Una matriz de banda con ancho de banda medio elegido aleatoriamente entre
!>           0 y N-1, con valores propios espaciados uniformemente 1, ..., ULP
!>           con signos aleatorios.
!>      (17) Igual que (16), pero multiplicado por SQRT( umbral de desbordamiento )
!>      (18) Igual que (16), pero multiplicado por SQRT( umbral de subdesbordamiento )
!> 
!>  NSIZES  INTEGER
!>          El número de tamaños de matrices a utilizar. Si es cero,
!>          ZDRVST no hace nada. Debe ser al menos cero.
!>          No modificado.
!>
!>  NN      INTEGER array, dimension (NSIZES)
!>          Un array que contiene los tamaños a utilizar para las matrices.
!>          Los valores cero se omitirán. Los valores deben ser al menos
!>          cero.
!>          No modificado.
!>
!>  NTYPES  INTEGER
!>          El número de elementos en DOTYPE. Si es cero, ZDRVST
!>          no hace nada. Debe ser al menos cero. Si es MAXTYP+1
!>          y NSIZES es 1, entonces se define un tipo adicional, MAXTYP+1,
!>          que es utilizar cualquier matriz que esté en A. Esto
!>          solo es útil si DOTYPE(1:MAXTYP) es .FALSE. y
!>          DOTYPE(MAXTYP+1) es .TRUE. .
!>          No modificado.
!>
!>  DOTYPE  LOGICAL array, dimension (NTYPES)
!>          Si DOTYPE(j) es .TRUE., entonces para cada tamaño en NN se generará
!>          una matriz de ese tamaño y tipo j.
!>          Si NTYPES es menor que el número máximo de tipos
!>          definidos (PARAMETER MAXTYP), entonces los tipos NTYPES+1 hasta
!>          MAXTYP no se generarán. Si NTYPES es mayor
!>          que MAXTYP, DOTYPE(MAXTYP+1) hasta DOTYPE(NTYPES)
!!>          serán ignorados.
!>          No modificado.
!>
!>  ISEED   INTEGER array, dimension (4)
!>          En la entrada, ISEED especifica la semilla del generador
!>          de números aleatorios. Los elementos del array deben estar entre 0 y 4095;
!>          si no lo están, se reducirán módulo

4096. ZDRVST

Prueba de rendimiento de ZHEEV, ZHEGV, ZHPG.

Parámetros

NSIZES
CHARACTER*1

Indica el tamaño de las matrices a probar. 0: Solo se prueba el tamaño NMAX indicado por NN(1). N: Se prueban los tamaños indicados por NN(1) a NN(N).

No modificado.

NN
INTEGER array, dimension (NSIZES)

Los tamaños de las matrices a probar. Por ejemplo, si NSIZES = 'N' y NN = (/10, 20, 30/), se probarán matrices de tamaño 10x10, 20x20 y 30x30.

No modificado.

NTYPES
INTEGER

El número de tipos de matrices a probar. Por ejemplo, si NTYPES = 10, se probarán los 10 tipos de matrices definidos en DLATMR.

No modificado.

THRESH
DOUBLE PRECISION

Una prueba se considera superada si el error calculado, tal como se describe anteriormente, excede THRESH. Tenga en cuenta que el error se escala para que sea O(1), por lo que THRESH debería ser un múltiplo razonablemente pequeño de 1, por ejemplo, 10 o 100. En particular, no debe depender de la precisión (simple o doble) ni del tamaño de la matriz. Debe ser al menos cero.

No modificado.

NOUNIT
INTEGER

El número de unidad FORTRAN para imprimir mensajes de error (por ejemplo, si una rutina devuelve IINFO no igual a 0).

No modificado.

A
COMPLEX*16 array, dimension (LDA , max(NN))

Se utiliza para almacenar la matriz cuyos valores propios se van a calcular. A la salida, A contiene la última matriz utilizada realmente.

Modificado.

LDA
INTEGER

La dimensión principal de A. Debe ser al menos 1 y al menos max( NN ).

No modificado.

D1
DOUBLE PRECISION array, dimension (max(NN))

Los valores propios de A, calculados por ZSTEQR simultáneamente con Z. A la salida, los valores propios en D1 corresponden a la matriz en A.

Modificado.

D2
DOUBLE PRECISION array, dimension (max(NN))

Los valores propios de A, calculados por ZSTEQR si Z no se calcula. A la salida, los valores propios en D2 corresponden a la matriz en A.

Modificado.

D3
DOUBLE PRECISION array, dimension (max(NN))

Los valores propios de A, calculados por DSTERF. A la salida, los valores propios en D3 corresponden a la matriz en A.

Modificado.

WA1
DOUBLE PRECISION array, dimension
WA2
DOUBLE PRECISION array, dimension
WA3
DOUBLE PRECISION array, dimension
U
COMPLEX*16 array, dimension (LDU, max(NN))

La matriz unitaria calculada por ZHETRD + ZUNGC3.

Modificado.

LDU
INTEGER

La dimensión principal de U, Z y V. Debe ser al menos 1 y al menos max( NN ).

No modificado.

V
COMPLEX*16 array, dimension (LDU, max(NN))

Los vectores de Householder calculados por ZHETRD al reducir A a forma tridiagonal.

Modificado.

TAU
COMPLEX*16 array, dimension (max(NN))

Los factores de Householder calculados por ZHETRD al reducir A a forma tridiagonal.

Modificado.

Z
COMPLEX*16 array, dimension (LDU, max(NN))

La matriz unitaria de vectores propios calculada por ZHEEVD, ZHEEVX, ZHPEVD, CHPEVX, ZHBEVD y CHBEVX.

Modificado.

WORK - COMPLEX*16 array of dimension ( LWORK )
Workspace.

Modificado.

LWORK - INTEGER
El número de entradas en WORK. Debe ser al menos 2*max( NN(j), 2 )**2.

No modificado.

RWORK DOUBLE PRECISION array, dimension (3*max(NN))
Workspace.

Modificado.

LRWORK - INTEGER
El número de entradas en RWORK.
IWORK INTEGER array, dimension (6*max(NN))
Workspace.

Modificado.

LIWORK - INTEGER
El número de entradas en IWORK.
RESULT DOUBLE PRECISION array, dimension (??)
Los valores calculados por las pruebas descritas anteriormente. Los valores están actualmente limitados a 1/ulp, para evitar desbordamientos.

Modificado.

INFO INTEGER
Si 0, entonces todo funcionó correctamente.

-1: NSIZES < 0

-2: Algún NN(j) < 0

-3: NTYPES < 0

-5: THRESH < 0

-9: LDA < 1 o LDA < NMAX, donde NMAX es max( NN(j) ).

-16: LDU < 1 o LDU < NMAX.

-21: LWORK demasiado pequeño.

Si DLATMR, SLATMS, ZHETRD, DORGC3, ZSTEQR, DSTERF o DORMC2 devuelven un código de error, el valor absoluto de este se devuelve.

Modificado.
