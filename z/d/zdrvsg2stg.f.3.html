ZDRVSG2STG

Propósito:

!>
!>      ZDRVSG2STG comprueba los controladores del problema general de autovalores hermíticos complejos.
!>
!>              ZHEGV calcula todos los autovalores y, opcionalmente,
!>              los autovectores de un problema general de autovalores hermítico-definido complejo.
!>
!>              ZHEGVD calcula todos los autovalores y, opcionalmente,
!>              los autovectores de un problema general de autovalores hermítico-definido complejo
!>              utilizando un algoritmo de divide y vencerás.
!>
!>              ZHEGVX calcula autovalores seleccionados y, opcionalmente,
!>              los autovectores de un problema general de autovalores hermítico-definido complejo.
!>
!>              ZHPGV calcula todos los autovalores y, opcionalmente,
!>              los autovectores de un problema general de autovalores hermítico-definido complejo
!>              en almacenamiento empaquetado.
!>
!>              ZHPGVD calcula todos los autovalores y, opcionalmente,
!>              los autovectores de un problema general de autovalores hermítico-definido complejo
!>              en almacenamiento empaquetado utilizando un algoritmo de divide y vencerás.
!>
!>              ZHPGVX calcula autovalores seleccionados y, opcionalmente,
!>              los autovectores de un problema general de autovalores hermítico-definido complejo
!>              en almacenamiento empaquetado.
!>
!>              ZHBGV calcula todos los autovalores y, opcionalmente,
!>              los autovectores de un problema general de autovalores hermítico-definido banda complejo.
!>
!>              ZHBGVD calcula todos los autovalores y, opcionalmente,
!>              los autovectores de un problema general de autovalores hermítico-definido banda complejo
!>              utilizando un algoritmo de divide y vencerás.
!>
!>              ZHBGVX calcula autovalores seleccionados y, opcionalmente,
!>              los autovectores de un problema general de autovalores hermítico-definido banda complejo.
!>
!>      Cuando se llama a ZDRVSG2STG, se especifica un número de tamaños de matriz () y un
!>      número de tipos de matriz. Para cada tamaño ()
!>      y cada tipo de matriz, se generará una matriz A del tipo dado; también se generará una matriz B aleatoria bien condicionada
!>      y el par (A,B) se utilizará para probar los controladores.
!>
!>      Para cada par (A,B), se realizan las siguientes pruebas:
!>
!>      (1) ZHEGV con ITYPE = 1 y UPLO ='U':
!>
!>              | A Z - B Z D | / ( |A| |Z| n ulp )
!>              | D - D2 | / ( |D| ulp )   donde D es calculado por
!>                                         ZHEGV y  D2 es calculado por
!>                                         ZHEGV_2STAGE. Esta prueba
!>                                         solo se realiza para DSYGV
!>
!>      (2) igual que (1) pero llamando a ZHPGV
!>      (3) igual que (1) pero llamando a ZHBGV
!>      (4) igual que (1) pero con UPLO = 'L'
!>      (5) igual que (4) pero llamando a ZHPGV
!>      (6) igual que (4) pero llamando a ZHBGV
!>
!>      (7) ZHEGV con ITYPE = 2 y UPLO ='U':
!>
!>              | A B Z - Z D | / ( |A| |Z| n ulp )
!>
!>      (8) igual que (7) pero llamando a ZHPGV
!>      (9) igual que (7) pero con UPLO = 'L'
!>      (10) igual que (9) pero llamando a ZHPGV
!>
!>      (11) ZHEGV con ITYPE = 3 y UPLO ='U':
!>
!>              | B A Z - Z D | / ( |A| |Z| n ulp )
!>
!>      (12) igual que (11) pero llamando a ZHPGV
!>      (13) igual que (11) pero con UPLO = 'L'
!>      (14) igual que (13) pero llamando a ZHPGV
!>
!>      ZHEGVD, ZHPGVD y ZHBGVD realizaron las mismas 14 pruebas.
!>
!>      ZHEGVX, ZHPGVX y ZHBGVX realizaron las pruebas anteriores de 14 con
!>      el parámetro RANGE = 'A', 'N' e 'I', respectivamente.
!>
!>      Los  se especifican mediante un array NN(1:NSIZES); el valor de
!>      cada elemento NN(j) especifica un tamaño.
!>      Los  se especifican mediante un array lógico DOTYPE( 1:NTYPES );
!>      si DOTYPE(j) es .TRUE., entonces el tipo de matriz  se generará.
!>      Este tipo se utiliza para la matriz A que tiene un semi-ancho de banda KA.
!>      B se genera como una matriz definida positiva bien condicionada
!>      con semi-ancho de banda KB (<= KA).
!>      Actualmente, la lista de tipos posibles para A es:
!>
!>      (1)  La matriz cero.
!>      (2)  La matriz identidad.
!>
!>      (3)  Una matriz diagonal con entradas espaciadas uniformemente
!>           1, ..., ULP  y signos aleatorios.
!>           (ULP = (primer número mayor que 1) - 1 )
!>      (4)  Una matriz diagonal con entradas espaciadas geométricamente
!>           1, ..., ULP  y signos aleatorios.
!>      (5)  Una matriz diagonal con entradas  1, ULP, ..., ULP
!>           y signos aleatorios.
!>
!>      (6)  Igual que (4), pero multiplicado por SQRT( umbral de desbordamiento )
!>      (7)  Igual que (4), pero multiplicado por SQRT( umbral de subdesbordamiento )
!>
!>      (8)  Una matriz de la forma  U* D U, donde U es unitaria y
!>           D tiene entradas espaciadas uniformemente 1, ..., ULP con signos aleatorios
!>           en la diagonal.
!>
!>      (9)  Una matriz de la forma  U* D U, donde U es unitaria y
!>           D tiene entradas espaciadas geométricamente 1, ..., ULP con signos aleatorios
!>           en la diagonal.
!>
!>      (10) Una matriz de la forma  U* D U, donde U es unitaria y
!>           D tiene entradas  1, ULP,..., ULP con signos aleatorios
!!>           en la diagonal.
!>
!>      (11) Igual que (8), pero multiplicado por SQRT( umbral de desbordamiento )
!>      (12) Igual que (8), pero multiplicado por SQRT( umbral de subdesbordamiento )
!>
!>      (13) Matriz hermítica con entradas aleatorias elegidas entre (-1,1).
!>      (14) Igual que (13), pero multiplicado por SQRT( umbral de desbordamiento )
!>      (15) Igual que (13), pero multiplicado por SQRT( umbral de subdesbordamiento )
!>
!>      (16) Igual que (8), pero con KA = 1 y KB = 1
!>      (17) Igual que (8), pero con KA = 2 y KB = 1
!>      (18) Igual que (8), pero con KA = 2 y KB = 2
!>      (19) Igual que (8), pero con KA = 3 y KB = 1
!>      (20) Igual que (8), pero con KA = 3 y KB = 2
!>      (21) Igual que (8), pero con KA = 3 y KB = 3
!> 
!>  NSIZES  INTEGER
!>          El número de tamaños de matrices a utilizar. Si es cero,
!>          ZDRVSG2STG no hace nada. Debe ser mayor o igual a cero.
!>          No modificado.
!>
!>  NN      INTEGER array, dimensión (NSIZES)
!>          Un array que contiene los tamaños a utilizar para las matrices.
!>          Los valores cero serán omitidos. Los valores deben ser mayores o iguales a
!>          cero.
!>

zdrvsg2stg.f(3)

NAME

zdrvsg2stg

driver for the general, Hermitian, and triangular eigenvalue problem

SYNOPSIS

SUBROUTINE ZDRVSG2STG(
  NTYPES, DOTYPE, NSIZES, NN, THRESH, NOUNIT, A, LDA, B, LDB, D, Z, LDZ,
  AB, BB, AP, BP, WORK, NWORK, RWORK, LRWORK, IWORK, LIWORK, RESULT, INFO )

      IMPLICIT NONE

*     Subroutine */
      LOGICAL DOTYPE(*)
      INTEGER NTYPES, NSIZES, NN(*)
      DOUBLE PRECISION THRESH, RESULT(*)
      INTEGER NOUNIT
      COMPLEX*16 A(LDA,*), B(LDB,*), Z(LDZ,*), AB(LDA,*), BB(LDB,*),
    $             AP(*)
      COMPLEX*16 BP(*)
      COMPLEX*16 WORK(*)
      INTEGER NWORK
      DOUBLE PRECISION RWORK(*)
      INTEGER LRWORK
      INTEGER IWORK(*)
      INTEGER LIWORK, INFO

*     Local variables and parameters
      INTEGER MAXTYP, NTEST, NTESTT, NMAX, NMATS, NERRS, KTYPE(*),
    $        KMODE(*), KMAGN(*)
      DOUBLE PRECISION ZERO, ONE, COND, ANORM, OVFL, UNFL, ULP, ULPINV,
    $                 RTOVFL, RTUNFL
      INTEGER J, JSIZE, JTYPE, JPASS, INFO

      MAXTYP = 21
      NTEST = 70
      ZERO = 0.0D0
      ONE = 1.0D0

      IF( NSIZES.LT.0 ) THEN
         INFO = -1
         RETURN
      END IF
      DO J = 1, NSIZES
         IF( NN(J).LT.0 ) THEN
            INFO = -2
            RETURN
         END IF
      END DO
      IF( NTYPES.LT.0 ) THEN
         INFO = -3
         RETURN
      END IF
      IF( THRESH.LT.0.0D0 ) THEN
         INFO = -5
         RETURN
      END IF
      IF( NOUNIT.LT.0 ) THEN
         INFO = -8
         RETURN
      END IF
      IF( LDA.LT.1 ) THEN
         INFO = -10
         RETURN
      END IF
      IF( LDB.LT.1 ) THEN
         INFO = -12
         RETURN
      END IF
      IF( LDZ.LT.1 ) THEN
         INFO = -14
         RETURN
      END IF

      NMAX = 0
      DO J = 1, NSIZES
         NMAX = MAX( NMAX, NN(J) )
      END DO

      IF( LDA.LT.NMAX ) THEN
         INFO = -10
         RETURN
      END IF
      IF( LDB.LT.NMAX ) THEN
         INFO = -12
         RETURN
      END IF
      IF( LDZ.LT.NMAX ) THEN
         INFO = -14
         RETURN
      END IF

      CALL ZLATMR( 2, MAXTYP, NSIZES, NN, NMAX, ONE, ONE, THRESH,
    $             ZERO, 'S', 'N', 'N', 'N', 0, 0, 0, 0, 0, 0, ZERO,
    $             ZERO, WORK, 1, IWORK, 1, INFO )
      IF( INFO.NE.0 ) THEN
         INFO = -21
         RETURN
      END IF
      NWORK = INT( WORK(1) )
      IF( NWORK.LT.2*NMAX + NMAX**2 ) THEN
         INFO = -21
         RETURN
      END IF

      CALL ZLATMR( 2, MAXTYP, NSIZES, NN, NMAX, ONE, ONE, THRESH,
    $             ZERO, 'S', 'N', 'N', 'N', 0, 0, 0, 0, 0, 0, ZERO,
    $             ZERO, WORK, 1, IWORK, 1, INFO )
      IF( INFO.NE.0 ) THEN
         INFO = -23
         RETURN
      END IF
      LRWORK = INT( RWORK(1) )
      IF( LRWORK.LT.MAX( 7*NMAX, 1+4*NMAX+2*NMAX*INT(LOG(DBLE(MAX(1,NMAX)))/LOG(2.0D0))
    $     + 3*NMAX**2 ) ) THEN
         INFO = -23
         RETURN
      END IF

      CALL ZLATMR( 2, MAXTYP, NSIZES, NN, NMAX, ONE, ONE, THRESH,
    $             ZERO, 'S', 'N', 'N', 'N', 0, 0, 0, 0, 0, 0, ZERO,
    $             ZERO, WORK, 1, IWORK, 1, INFO )
      IF( INFO.NE.0 ) THEN
         INFO = -25
         RETURN
      END IF
      LIWORK = IWORK(1)
      IF( LIWORK.LT.2+5*NMAX ) THEN
         INFO = -25
         RETURN
      END IF

*     Initialize RESULT
      DO J = 1, 70
         RESULT(J) = ZERO
      END DO

      NERRS = 0
      NMATS = 0

*     -----------------------------------------------------------------------
*     Define the order of the tests
*     -----------------------------------------------------------------------
      CALL ZLATMR( 2, MAXTYP, NSIZES, NN, NMAX, ONE, ONE, THRESH,
    $             ZERO, 'L', 'N', 'N', 'N', 0, 0, 0, 0, 0, 0, ZERO,
    $             ZERO, WORK, 1, IWORK, 1, INFO )
      IF( INFO.NE.0 ) THEN
         INFO = -21
         RETURN
      END IF
      KTYPE(1:MAXTYP) = IWORK(1:MAXTYP)
      KMODE(1:MAXTYP) = IWORK(MAXTYP+1:2*MAXTYP)
      KMAGN(1:MAXTYP) = IWORK(2*MAXTYP+1:3*MAXTYP)

*     -----------------------------------------------------------------------
*     Check the input parameters and matrix generators.
*     -----------------------------------------------------------------------
      CALL ZLATMR( 1, MAXTYP, NSIZES, NN, NMAX, ONE, ONE, THRESH,
    $             ZERO, 'T', 'N', 'N', 'N', 0, 0, 0, 0, 0, 0, ZERO,
    $             ZERO, WORK, 1, IWORK, 1, INFO )
      IF( INFO.NE.0 ) THEN
         INFO = -21
         RETURN
      END IF
      IF( IWORK(1).NE.0 ) THEN
         INFO = -21
         RETURN
      END IF

      CALL ZLATMR( 1, MAXTYP, NSIZES, NN, NMAX, ONE, ONE, THRESH,
    $             ZERO, 'H', 'N', 'N', 'N', 0, 0, 0, 0, 0, 0, ZERO,
    $             ZERO, WORK, 1, IWORK, 1, INFO )
      IF( INFO.NE.0 ) THEN
         INFO = -21
         RETURN
      END IF
      IF( IWORK(1).NE.0 ) THEN
         INFO = -21
         RETURN
      END IF

      CALL ZLATMR( 1, MAXTYP, NSIZES, NN, NMAX, ONE, ONE, THRESH,
    $             ZERO, 'Z', 'N', 'N', 'N', 0, 0, 0, 0, 0, 0, ZERO,
    $             ZERO, WORK, 1, IWORK, 1, INFO )
      IF( INFO.NE.0 ) THEN
         INFO = -21
         RETURN
      END IF
      IF( IWORK(1).NE.0 ) THEN
         INFO = -21
         RETURN
      END IF

*     -----------------------------------------------------------------------
*     Loop over the sizes of the matrices
*     -----------------------------------------------------------------------
      DO JSIZE = 1, NSIZES
         N = NN(JSIZE)
         IF( N.EQ.0 ) THEN
            CYCLE
         END IF

*        --------------------------------------------------------------------
*        Loop over the types of matrices to be generated
*        --------------------------------------------------------------------
         DO JPASS = 1, NTYPES
            IF( DOTYPE(JPASS) ) THEN
               JTYPE = KTYPE(JPASS)
               IMODE = KMODE(JPASS)
               IMAGN = KMAGN(JPASS)

*              ---------------------------------------------------------------
*              Generate the matrix
*              ---------------------------------------------------------------
               NMATS = NMATS + 1
               CALL ZLATMS( N, N, JTYPE, INFO, IMODE, ANORM, RE(A(1,1)),
    $                        LDA, D(1), RE(B(1,1)), LDB, RE(Z(1,1)), LDZ,
    $                        WORK, LRWORK, IWORK, LIWORK )
               IF( INFO.NE.0 ) THEN
                  INFO = -21
                  RETURN
               END IF

               ANORM = DLAMCH( WORK(1) )
               OVFL = DLAMCH( WORK(2) )
               UNFL = DLAMCH( WORK(3) )
               ULP = DLAMCH( WORK(4) )
               ULPINV = DLAMCH( WORK(5) )
               RTOVFL = SQRT( OVFL )
               RTUNFL = SQRT( UNFL )

*              ---------------------------------------------------------------
*              Generate random eigenvalues and eigenvectors
*              ---------------------------------------------------------------
               CALL ZLATMR( 1, 1, 1, N, 1, ZERO, ZERO, ZERO, ZERO, ' '
    $                      , ' ' , ' ' , ' ' , 0, 0, 0, 0, 0, 0, ZERO,
    $                      ZERO, WORK, 1, IWORK, 1, INFO )
               IF( INFO.NE.0 ) THEN
                  INFO = -21
                  RETURN
               END IF
               COND = MAX( 1.0D0, 10**(INT(LOG10(MAX(ONE,ANORM)))) )
               CALL ZLATMR( 1, 1, 1, N, 1, ZERO, ZERO, ZERO, ZERO, 'N'
    $                      , 'N' , 'N' , 'N' , 0, 0, 0, 0, 0, 0, COND,
    $                      ZERO, WORK, 1, IWORK, 1, INFO )
               IF( INFO.NE.0 ) THEN
                  INFO = -21
                  RETURN
               END IF
               D(1:N) = WORK(1:N)
               Z(1:N,1:N) = CMPLX( WORK(N+1:2*N), WORK(2*N+1:3*N) )

*              ---------------------------------------------------------------
*              Copy A and B to AB and BB
*              ---------------------------------------------------------------
               CALL ZCOPY( N*N, A, 1, AB, 1 )
               CALL ZCOPY( N*N, B, 1, BB, 1 )

*              ---------------------------------------------------------------
*              Call ZHEGV to compute the eigenvalues and eigenvectors
*              ---------------------------------------------------------------
               CALL ZHEGV( 1, 'V', 'U', N, AB, LDA, BB, LDB, D, Z, LDZ,
    $                       WORK, NWORK, INFO )

               IF( INFO.NE.0 ) THEN
                  NERRS = NERRS + 1
                  RESULT(NERRS) = DBLE(N)
                  RESULT(NERRS+1) = DBLE(JPASS)
                  RESULT(NERRS+2) = DBLE(INFO)
                  INFO = ABS(INFO)
                  IF( INFO.EQ.2 ) INFO = 1600
                  IF( INFO.EQ.3 ) INFO = 1700
                  IF( INFO.EQ.4 ) INFO = 1800
                  GO TO 900
               END IF

*              ---------------------------------------------------------------
*              Reorder the eigenvalues and eigenvectors
*              ---------------------------------------------------------------
               CALL ZLATPS( 'V', 'U', 'N', 'N', N, Z, LDZ, D, INFO )
               IF( INFO.NE.0 ) THEN
                  NERRS = NERRS + 1
                  RESULT(NERRS) = DBLE(N)
                  RESULT(NERRS+1) = DBLE(JPASS)
                  RESULT(NERRS+2) = DBLE(INFO)
                  GO TO 900
               END IF

*              ---------------------------------------------------------------
*              Compute the residual error norms
*              ---------------------------------------------------------------
               CALL ZDRVXG( 'N', 'A', 'U', N, AB, LDA, BB, LDB, Z, LDZ,
    $                        D, NERRS, RESULT, THRESH, WORK, NWORK,
    $                        INFO )
               IF( INFO.NE.0 ) THEN
                  INFO = -21
                  RETURN
               END IF
               NERRS = INT(RESULT(1))

*              ---------------------------------------------------------------
*              Compute the residual error norms for eigenvectors
*              ---------------------------------------------------------------
               CALL ZDRVXG( 'V', 'A', 'U', N, AB, LDA, BB, LDB, Z, LDZ,
    $                        D, NERRS, RESULT, THRESH, WORK, NWORK,
    $                        INFO )
               IF( INFO.NE.0 ) THEN
                  INFO = -21
                  RETURN
               END IF
               NERRS = INT(RESULT(1))

*              ---------------------------------------------------------------
*              Compute the residual error norms for eigenvalues
*              ---------------------------------------------------------------
               CALL ZDRVXG( 'E', 'A', 'U', N, AB, LDA, BB, LDB, Z, LDZ,
    $                        D, NERRS, RESULT, THRESH, WORK, NWORK,
    $                        INFO )
               IF( INFO.NE.0 ) THEN
                  INFO = -21
                  RETURN
               END IF
               NERRS = INT(RESULT(1))

*              ---------------------------------------------------------------
*              Compute the error in the computed eigenvalues
*              ---------------------------------------------------------------
               CALL ZDRVXG( 'N', 'G', 'U', N, AB, LDA, BB, LDB, Z, LDZ,
    $                        D, NERRS, RESULT, THRESH, WORK, NWORK,
    $                        INFO )
               IF( INFO.NE.0 ) THEN
                  INFO = -21
                  RETURN
               END IF
               NERRS = INT(RESULT(1))

 900          CONTINUE
               IF( INFO.NE.0 .AND. INFO.LT.0 ) THEN
                  INFO = -21
                  RETURN
               END IF
               IF( INFO.NE.0 .AND. INFO.GT.0 ) THEN
                  IF( NERRS.LT.70 ) THEN
                     RESULT(NERRS+1) = DBLE(N)
                     RESULT(NERRS+2) = DBLE(JPASS)
                     RESULT(NERRS+3) = DBLE(INFO)
                     NERRS = NERRS + 3
                  END IF
                  INFO = 0
               END IF
            END IF
         END DO
      END DO

*     -----------------------------------------------------------------------
*     Check if any tests failed
*     -----------------------------------------------------------------------
      IF( NERRS.GT.0 ) THEN
         INFO = NERRS
      ELSE
         INFO = 0
      END IF

      RETURN

      END

!>  NTYPES  INTEGER
!>          The number of elements in DOTYPE.   If it is zero, ZDRVSG2STG
!>          does nothing.  It must be at least zero.  If it is MAXTYP+1
!>          and NSIZES is 1, then an additional type, MAXTYP+1 is
!>          defined, which is to use whatever matrix is in A.  This
!>          is only useful if DOTYPE(1:MAXTYP) is .FALSE. and
!>          DOTYPE(MAXTYP+1) is .TRUE. .
!>          Not modified.
!>
!>  DOTYPE  LOGICAL array, dimension (NTYPES)
!>          If DOTYPE(j) is .TRUE., then for each size in NN a
!>          matrix of that size and of type j will be generated.
!>          If NTYPES is smaller than the maximum number of types
!>          defined (PARAMETER MAXTYP), then types NTYPES+1 through
!>          MAXTYP will not be generated.  If NTYPES is larger
!>          than MAXTYP, DOTYPE(MAXTYP+1) through DOTYPE(NTYPES)
!>          will be ignored.
!>          Not modified.
!>
!>  ISEED   INTEGER array, dimension (4)
!>          On entry ISEED specifies the seed of the random number
!>          generator. The array elements should be between 0 and 4095;
!>          if not they will be reduced mod 4096.  Also, ISEED(4) must
!>          be odd.  The random number generator uses a linear
!>          congruential sequence limited to small integers, and so
!>          should produce machine independent random numbers. The
!>          values of ISEED are changed on exit, and can be used in the
!>          next call to ZDRVSG2STG to continue the same random number
!>          sequence.
!>          Modified.
!>
!>  THRESH  DOUBLE PRECISION
!>          A test will count as  if the , computed as
!>          described above, exceeds THRESH.  Note that the error
!>          is scaled to be O(1), so THRESH should be a reasonably
!>          small multiple of 1, e.g., 10 or 100.  In particular,
!>          it should not depend on the precision (single vs. double)
!>          or the size of the matrix.  It must be at least zero.
!>          Not modified.
!>
!>  NOUNIT  INTEGER
!>          The FORTRAN unit number for printing out error messages
!>          (e.g., if a routine returns IINFO not equal to 0.)
!>          Not modified.
!>
!>  A       COMPLEX*16 array, dimension (LDA , max(NN))
!>          Used to hold the matrix whose eigenvalues are to be
!>          computed.  On exit, A contains the last matrix actually
!>          used.
!>          Modified.
!>
!>  LDA     INTEGER
!>          The leading dimension of A.  It must be at
!>          least 1 and at least max( NN ).
!>          Not modified.
!>
!>  B       COMPLEX*16 array, dimension (LDB , max(NN))
!>          Used to hold the Hermitian positive definite matrix for
!>          the generalized problem.
!>          On exit, B contains the last matrix actually
!>          used.
!>          Modified.
!>
!>  LDB     INTEGER
!>          The leading dimension of B.  It must be at
!>          least 1 and at least max( NN ).
!>          Not modified.
!>
!>  D       DOUBLE PRECISION array, dimension (max(NN))
!>          The eigenvalues of A. On exit, the eigenvalues in D
!>          correspond with the matrix in A.
!>          Modified.
!>
!>  Z       COMPLEX*16 array, dimension (LDZ, max(NN))
!>          The matrix of eigenvectors.
