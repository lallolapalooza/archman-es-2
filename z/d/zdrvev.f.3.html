Propósito:

!>
!>    ZDRVEV  comprueba el controlador del problema de valores propios no simétricos ZGEEV.
!>
!>    Cuando se llama a ZDRVEV, se especifican un número de tamaños de matriz () y un
!>    número de tipos de matriz. Para cada tamaño ()
!>    y cada tipo de matriz, se generará y utilizará una matriz
!>    para probar las rutinas de valores propios no simétricos. Para cada matriz, se realizarán 7
!>    pruebas:
!>
!>    (1)     | A * VR - VR * W | / ( n |A| ulp )
!>
!>      Aquí VR es la matriz de vectores propios derechos unitarios.
!>      W es una matriz diagonal con entradas diagonales W(j).
!>
!>    (2)     | A**H * VL - VL * W**H | / ( n |A| ulp )
!>
!>      Aquí VL es la matriz de vectores propios izquierdos unitarios, A**H es la
!>      transpuesta conjugada de A, y W es como se mencionó anteriormente.
!>
!>    (3)     | |VR(i)| - 1 | / ulp y si el componente más grande es real
!>
!>      VR(i) denota la i-ésima columna de VR.
!>
!>    (4)     | |VL(i)| - 1 | / ulp y si el componente más grande es real
!>
!>      VL(i) denota la i-ésima columna de VL.
!>
!>    (5)     W(completo) = W(parcial)
!>
!>      W(completo) denota los valores propios calculados cuando se calculan tanto VR como VL,
!>      y W(parcial) denota los valores propios calculados cuando solo se calculan W, solo W y VR,
!>      o solo W y VL.
!>
!>    (6)     VR(completo) = VR(parcial)
!>
!>      VR(completo) denota los vectores propios derechos calculados cuando se calculan tanto VR como VL,
!>      y VR(parcial) denota el resultado cuando solo se calcula VR.
!>
!>     (7)     VL(completo) = VL(parcial)
!>
!>      VL(completo) denota los vectores propios izquierdos calculados cuando se calculan tanto VR como VL,
!>      y VL(parcial) denota el resultado cuando solo se calcula VL.
!>
!>    Los tamaños se especifican mediante un array NN(1:NSIZES); el valor de
!>    cada elemento NN(j) especifica un tamaño.
!>    Los tipos se especifican mediante un array lógico DOTYPE( 1:NTYPES );
!>    si DOTYPE(j) es .TRUE., entonces se generará la matriz de tipo j.
!>    Actualmente, la lista de tipos posibles es:
!>
!>    (1)  La matriz cero.
!>    (2)  La matriz identidad.
!>    (3)  Un bloque de Jordan (transpuesto), con 1s en la diagonal.
!>
!>    (4)  Una matriz diagonal con entradas espaciadas uniformemente
!>         1, ..., ULP y ángulos complejos aleatorios.
!>         (ULP = (primer número mayor que 1) - 1)
!>    (5)  Una matriz diagonal con entradas espaciadas geométricamente
!>         1, ..., ULP y ángulos complejos aleatorios.
!>    (6)  Una matriz diagonal con entradas 1, ULP, ..., ULP
!>         y ángulos complejos aleatorios.
!>
!>    (7)  Igual que (4), pero multiplicado por una constante cercana
!>         al umbral de desbordamiento.
!>    (8)  Igual que (4), pero multiplicado por una constante cercana
!>         al umbral de subdesbordamiento.
!>
!>    (9)  Una matriz de la forma U' T U, donde U es unitaria y
!>         T tiene entradas espaciadas uniformemente 1, ..., ULP con ángulos complejos
!>         aleatorios en la diagonal y entradas O(1) aleatorias en el triángulo superior.
!>
!>    (10) Una matriz de la forma U' T U, donde U es unitaria y
!>         T tiene entradas espaciadas geométricamente 1, ..., ULP con ángulos complejos
!>         aleatorios en la diagonal y entradas O(1) aleatorias en el triángulo superior.
!>
!>    (11) Una matriz de la forma U' T U, donde U es unitaria y
!>         T tiene entradas 1, ULP, ..., ULP con ángulos complejos
!>         aleatorios en la diagonal y entradas O(1) aleatorias en el triángulo superior.
!>
!>    (12) Una matriz de la forma U' T U, donde U es unitaria y
!>         T tiene valores propios complejos elegidos aleatoriamente de
!>         ULP < |z| < 1 y entradas O(1) aleatorias en el triángulo superior.
!>
!>    (13) Una matriz de la forma X' T X, donde X tiene condición
!>         SQRT( ULP ) y T tiene entradas espaciadas uniformemente 1, ..., ULP
!>         con ángulos complejos aleatorios en la diagonal y entradas O(1) aleatorias en el triángulo superior.
!>
!>    (14) Una matriz de la forma X' T X, donde X tiene condición
!>         SQRT( ULP ) y T tiene entradas espaciadas geométricamente
!>         1, ..., ULP con ángulos complejos aleatorios en la diagonal
!>         y entradas O(1) aleatorias en el triángulo superior.
!>
!>    (15) Una matriz de la forma X' T X, donde X tiene condición
!>         SQRT( ULP ) y T tiene entradas 1, ULP, ..., ULP con ángulos complejos
!>         aleatorios en la diagonal y entradas O(1) aleatorias en el triángulo superior.
!>
!>    (16) Una matriz de la forma X' T X, donde X tiene condición
!>         SQRT( ULP ) y T tiene valores propios complejos elegidos aleatoriamente
!>         de ULP < |z| < 1 y entradas O(1) aleatorias en el triángulo superior.
!>
!>    (17) Igual que (16), pero multiplicado por una constante cercana
!>         al umbral de desbordamiento.
!>    (18) Igual que (16), pero multiplicado por una constante cercana
!>         al umbral de subdesbordamiento.
!>
!>    (19) Matriz no simétrica con entradas aleatorias elegidas de |z| < 1
!>         Si N es al menos 4, todas las entradas en las dos primeras filas y la última
!>         fila, y la primera columna y las dos últimas columnas son cero.
!>    (20) Igual que (19), pero multiplicado por una constante cercana
!>         al umbral de desbordamiento.
!>    (21) Igual que (19), pero multiplicado por una constante cercana
!>         al umbral de subdesbordamiento.
!>

Parámetros

NSIZES 
!>          NSIZES es INTEGER
!>          El número de tamaños de matrices a utilizar. Si es cero,
!>          ZDRVEV no hace nada. Debe ser al menos cero.
!>

NN

!>          NN es un array INTEGER, dimension (NSIZES)
!>          Un array que contiene los tamaños a utilizar para las matrices.
!>          Los valores cero se omitirán. Los valores deben ser al menos
!>          cero.
!>

NTYPES

!>          NTYPES es INTEGER
!>          El número de elementos en DOTYPE. Si es cero, ZDRVEV
!>          no hace nada. Debe ser al menos cero. Si es MAXTYP+1

NAME

zdrvev - driver routine for ZGEEV, ZGEEVX, ZGESDD, ZGESVD

SYNOPSIS

subroutine zdrvev( nn, ntypes, iseed, thresh, nounit, a, lda, h, w, w1, vl, ldvl, vr, ldvr, lre, ldlre, result, work, nwork, rwork, iwork, info )

Function/Subroutine Documentation

nn
INTEGER array, dimension (NSIZES)
          Array of sizes of the matrices to be generated.
          NN(j) is the dimension of the matrices of type J.
ntypes
INTEGER
          The number of matrix types to be tested.
iseed
INTEGER array, dimension (4)
          On entry ISEED specifies the seed of the random number
          generator. The array elements should be between 0 and 4095;
          if not they will be reduced mod 4096. Also, ISEED(4) must
          be odd. The random number generator uses a linear
          congruential sequence limited to small integers, and so
          should produce machine independent random numbers. The
          values of ISEED are changed on exit, and can be used in the
          next call to ZDRVEV to continue the same random number
          sequence.
thresh
DOUBLE PRECISION
          A test will count as if the value, computed as
          described above, exceeds THRESH. Note that the error
          is scaled to be O(1), so THRESH should be a reasonably
          small multiple of 1, e.g., 10 or 100. In particular,
          it should not depend on the precision (single vs. double)
          or the size of the matrix. It must be at least zero.
nounit
INTEGER
          The FORTRAN unit number for printing out error messages
          (e.g., if a routine returns INFO not equal to 0.)
a
COMPLEX*16 array, dimension (LDA, max(NN))
          Used to hold the matrix whose eigenvalues are to be
          computed. On exit, A contains the last matrix actually used.
lda
INTEGER
          The leading dimension of A, and H. LDA must be at
          least 1 and at least max(NN).
h
COMPLEX*16 array, dimension (LDA, max(NN))
          Another copy of the test matrix A, modified by ZGEEV.
w
COMPLEX*16 array, dimension (max(NN))
          The eigenvalues of A. On exit, W are the eigenvalues of
          the matrix in A.
w1
COMPLEX*16 array, dimension (max(NN))
          Like W, this array contains the eigenvalues of A,
          but those computed when ZGEEV only computes a partial
          eigendecomposition, i.e. not the eigenvalues and left
          and right eigenvectors.
vl
COMPLEX*16 array, dimension (LDVL, max(NN))
          VL holds the computed left eigenvectors.
ldvl
INTEGER
          Leading dimension of VL. Must be at least max(1,max(NN)).
vr
COMPLEX*16 array, dimension (LDVR, max(NN))
          VR holds the computed right eigenvectors.
ldvr
INTEGER
          Leading dimension of VR. Must be at least max(1,max(NN)).
lre
COMPLEX*16 array, dimension (LDLRE, max(NN))
          LRE holds the computed right or left eigenvectors.
ldlre
INTEGER
          Leading dimension of LRE. Must be at least max(1,max(NN)).
result
DOUBLE PRECISION array, dimension (7)
          The values computed by the seven tests described above.
          The values are currently limited to 1/ulp, to avoid
          overflow.
work
COMPLEX*16 array, dimension (NWORK)
nwork
INTEGER
          The number of entries in WORK. This must be at least
          5*NN(j)+2*NN(j)**2 for all j.
rwork
DOUBLE PRECISION array, dimension (2*max(NN))
iwork
INTEGER array, dimension (max(NN))
info
INTEGER
          If 0, then everything ran OK.
           -1: NSIZES < 0
           -2: Some NN(j) < 0
           -3: NTYPES < 0
           -6: THRESH < 0
           -9: LDA < 1 or LDA < NMAX, where NMAX is max( NN(j) ).
          -14: LDVL < 1 or LDVL < NMAX, where NMAX is max( NN(j) ).
          -16: LDVR < 1 or LDVR < NMAX, where NMAX is max( NN(j) ).
          -18: LDLRE < 1 or LDLRE < NMAX, where NMAX is max( NN(j) ).
          -21: NWORK too small.
          If ZLATMR, CLATMS, CLATME or ZGEEV returns an error code,
              the absolute value of it is returned.

-----------------------------------------------------------------------
     Some Local Variables and Parameters:
     ---- ----- --------- --- ----------
     ZERO, ONE       Real 0 and 1.
     MAXTYP          The number of types defined.
     NMAX            Largest value in NN.
     NERRS           The number of tests which have exceeded THRESH
     COND, CONDS,
     IMODE           Values to be passed to the matrix generators.
     ANORM           Norm of A; passed to matrix generators.
     OVFL, UNFL      Overflow and underflow thresholds.
     ULP, ULPINV     Finest relative precision and its inverse.
     RTULP, RTULPI   Square roots of the previous 4 values.
             The following four arrays decode JTYPE:
     KTYPE(j)        The general type (1-10) for type .
     KMODE(j)        The MODE value to be passed to the matrix
                     generator for type .
     KMAGN(j)        The order of magnitude ( O(1),
                     O(overflow^(1/2) ), O(underflow^(1/2) )
     KCONDS(j)       Selectw whether CONDS is to be 1 or
                     1/sqrt(ulp).  (0 means irrelevant.)
