Documentación de la función/subrutina

subrutina zdrvab (lógico, dimensión( * ) dotype, entero nm, entero, dimensión( * ) mval, entero nns, entero, dimensión( * ) nsval, doble precisión thresh, entero nmax, complejo*16, dimensión( * ) a, complejo*16, dimensión( * ) afac, complejo*16, dimensión( * ) b, complejo*16, dimensión( * ) x, complejo*16, dimensión( * ) work, doble precisión, dimensión( * ) rwork, complejo, dimensión( * ) swork, entero, dimensión( * ) iwork, entero nout)

ZDRVAB

Propósito:

!>
!> ZDRVAB prueba ZCGESV
!>

Parámetros

DOTYPE 
!>          DOTYPE es una matriz LOGICA, dimensión (NTIPOS)
!>          Los tipos de matrices a usar para las pruebas. Las matrices de tipo j
!>          (para 1 <= j <= NTYPES) se usan para pruebas si DOTYPE(j) =
!>          .TRUE.; si DOTYPE(j) = .FALSE., entonces el tipo j no se usa.
!>

NM

!>          NM es ENTERO
!>          El número de valores de M contenidos en el vector MVAL.
!>

MVAL

!>          MVAL es una matriz ENTERA, dimensión (NM)
!>          Los valores de la dimensión de filas de la matriz M.
!>

NNS

!>          NNS es ENTERO
!>          El número de valores de NRHS contenidos en el vector NSVAL.
!>

NSVAL

!>          NSVAL es una matriz ENTERA, dimensión (NNS)
!>          Los valores del número de lados derechos NRHS.
!>

THRESH

!>          THRESH es DOBLE PRECISION
!>          El valor umbral para las relaciones de prueba. Un resultado se
!>          incluye en el archivo de salida si RESULTADO >= UMBRAL. Para que
!>          cada relación de prueba se imprima, usar THRESH = 0.
!>

NMAX

!>          NMAX es ENTERO
!>          El valor máximo permitido para M o N, usado en la dimensionamiento
!>          de las matrices de trabajo.
!>

A

!>          A es una matriz COMPLEJA*16, dimensión (NMAX*NMAX)
!>

AFAC

!>          AFAC es una matriz COMPLEJA*16, dimensión (NMAX*NMAX)
!>

B

!>          B es una matriz COMPLEJA*16, dimensión (NMAX*NSMAX)
!>          donde NSMAX es la entrada más grande en NSVAL.
!>

X

!>          X es una matriz COMPLEJA*16, dimensión (NMAX*NSMAX)
!>

WORK

!>          WORK es una matriz COMPLEJA*16, dimensión
!>                      (NMAX*max(3,NSMAX*2))
!>

RWORK

!>          RWORK es una matriz de DOBLE PRECISION, dimensión
!>                      NMAX
!>

SWORK

!>          SWORK es una matriz COMPLEJA, dimensión
!>                      (NMAX*(NSMAX+NMAX))
!>

IWORK

!>          IWORK es una matriz ENTERA, dimensión
!>                      NMAX
!>

NOUT

!>          NOUT es ENTERO
!>          El número de unidad para la salida.
!>
