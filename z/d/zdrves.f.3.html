Propósito:

!>
!>    ZDRVES comprueba el problema del autovalor no simétrico (forma de Schur)
!>    conductor ZGEES.
!>
!>    Cuando se llama a ZDRVES, se especifica un número de tamaño de matriz () y un
!>    número de tipos de matriz. Para cada tamaño () y cada tipo de matriz, se generará y
!>    utilizará una matriz para probar las rutinas de autovalores no simétricos. Para cada
!>    matriz, se realizarán 13 pruebas:
!>
!>    (1)     0 si T está en forma de Schur, 1/ulp en caso contrario
!>           (sin ordenación de autovalores)
!>
!>    (2)     | A - VS T VS' | / ( n |A| ulp )
!>
!>      Aquí VS es la matriz de autovectores de Schur, y T está en forma de Schur
!>      (sin ordenación de autovalores).
!>
!>    (3)     | I - VS VS' | / ( n ulp ) (sin ordenación de autovalores).
!>
!>    (4)     0     si W son autovalores de T
!>            1/ulp en caso contrario
!>            (sin ordenación de autovalores)
!>
!>    (5)     0     si T(con VS) = T(sin VS),
!>            1/ulp en caso contrario
!>            (sin ordenación de autovalores)
!>
!>    (6)     0     si autovalores(con VS) = autovalores(sin VS),
!>            1/ulp en caso contrario
!>            (sin ordenación de autovalores)
!>
!>    (7)     0 si T está en forma de Schur, 1/ulp en caso contrario
!>            (con ordenación de autovalores)
!>
!>    (8)     | A - VS T VS' | / ( n |A| ulp )
!>
!>      Aquí VS es la matriz de autovectores de Schur, y T está en forma de Schur
!>      (con ordenación de autovalores).
!>
!>    (9)     | I - VS VS' | / ( n ulp ) (con ordenación de autovalores).
!>
!>    (10)    0     si W son autovalores de T
!>            1/ulp en caso contrario
!>            (con ordenación de autovalores)
!>
!>    (11)    0     si T(con VS) = T(sin VS),
!>            1/ulp en caso contrario
!>            (con ordenación de autovalores)
!>
!>    (12)    0     si autovalores(con VS) = autovalores(sin VS),
!>            1/ulp en caso contrario
!>            (con ordenación de autovalores)
!>
!>    (13)    si la ordenación funcionó y SDIM es el número de
!>            autovalores que fueron SELECCIONADOS
!>
!>    Los tamaños se especifican mediante un array NN(1:NSIZES); el valor de
!>    cada elemento NN(j) especifica un tamaño.
!>    Los tipos se especifican mediante un array lógico DOTYPE( 1:NTYPES );
!>    si DOTYPE(j) es .TRUE., entonces se generará el tipo de matriz j.
!>    Actualmente, la lista de tipos posibles es:
!>
!>    (1)  La matriz cero.
!>    (2)  La matriz identidad.
!>    (3)  Un bloque Jordan (transpuesto), con 1s en la diagonal.
!>
!>    (4)  Una matriz diagonal con entradas espaciadas uniformemente
!>         1, ..., ULP  y ángulos complejos aleatorios.
!>         (ULP = (primer número mayor que 1) - 1 )
!>    (5)  Una matriz diagonal con entradas espaciadas geométricamente
!>         1, ..., ULP  y ángulos complejos aleatorios.
!>    (6)  Una matriz diagonal con entradas  1, ULP, ..., ULP
!>         y ángulos complejos aleatorios.
!>
!>    (7)  Igual que (4), pero multiplicado por una constante cercana
!>         al umbral de desbordamiento
!>    (8)  Igual que (4), pero multiplicado por una constante cercana
!>         al umbral de infradesbordamiento
!>
!>    (9)  Una matriz de la forma  U' T U, donde U es unitaria y
!>         T tiene entradas espaciadas uniformemente 1, ..., ULP con ángulos
!>         complejos aleatorios en la diagonal y entradas aleatorias O(1) en el
!>         triángulo superior.
!>
!>    (10) Una matriz de la forma  U' T U, donde U es unitaria y
!>         T tiene entradas espaciadas geométricamente 1, ..., ULP con ángulos
!>         complejos aleatorios en la diagonal y entradas aleatorias O(1) en el
!>         triángulo superior.
!>
!>    (11) Una matriz de la forma  U' T U, donde U es ortogonal y
!>         T tiene entradas  1, ULP,..., ULP con ángulos complejos aleatorios
!>         en la diagonal y entradas aleatorias O(1) en el triángulo superior.
!>
!>    (12) Una matriz de la forma  U' T U, donde U es unitaria y
!>         T tiene autovalores complejos elegidos aleatoriamente de
!>         ULP < |z| < 1   y entradas aleatorias O(1) en el triángulo
!>         superior.
!>
!>    (13) Una matriz de la forma  X' T X, donde X tiene condición
!>         SQRT( ULP ) y T tiene entradas espaciadas uniformemente 1, ..., ULP
!>         con ángulos complejos aleatorios en la diagonal y entradas aleatorias O(1)
!>         en el triángulo superior.
!>
!>    (14) Una matriz de la forma  X' T X, donde X tiene condición
!>         SQRT( ULP ) y T tiene entradas espaciadas geométricamente
!>         1, ..., ULP con ángulos complejos aleatorios en la diagonal
!>         y entradas aleatorias O(1) en el triángulo superior.
!>
!>    (15) Una matriz de la forma  X' T X, donde X tiene condición
!>         SQRT( ULP ) y T tiene entradas  1, ULP,..., ULP
!>         con ángulos complejos aleatorios en la diagonal y entradas aleatorias O(1)
!>         en el triángulo superior.
!>
!>    (16) Una matriz de la forma  X' T X, donde X tiene condición
!>         SQRT( ULP ) y T tiene autovalores complejos elegidos aleatoriamente
!>         de ULP < |z| < 1 y entradas aleatorias O(1) en el triángulo
!>         superior.
!>
!>    (17) Igual que (16), pero multiplicado por una constante
!>         cercana al umbral de desbordamiento
!>    (18) Igual que (16), pero multiplicado por una constante
!>         cercana al umbral de infradesbordamiento
!>
!>    (19) Matriz no simétrica con entradas aleatorias elegidas de (-1,1).
!>         Si N es al menos 4, todas las entradas en las dos primeras filas y la última
!>         fila, y la primera columna y las dos últimas columnas son cero.
!>    (20) Igual que (19), pero multiplicado por una constante
!>         cercana al umbral de desbordamiento
!>    (21) Igual que (19), pero multiplicado por una constante
!>         cercana al umbral de infradesbordamiento
!>

NAME

zdrves - driver routine for testing the nonsymmetric eigenvalue problem routines

SYNOPSIS

 subroutine zdrves( NSIZES, NN, NTYPES, THRESH, NOUNIT, ISEED,
                     A, LDA, H, HT, W, WT, VS, LDVS, RESULT,
                     WORK, NWORK, RWORK, IWORK, BWORK, INFO )
  
 ! Arguments
 integer NSIZES, NN( * ), NTYPES, NOUNIT, ISEED( * ), LDA, LDVS,
        NWORK, INFO
 double precision THRESH, RESULT( * ), RWORK( * )
 complex*16 A( LDA, * ), H( LDA, * ), HT( LDA, * ),
        W( * ), WT( * ), VS( LDVS, * ), WORK( * )
 integer IWORK( * )
 logical BWORK( * )

Function/Subroutine Documentation

ZDRVES is a driver routine that tests the nonsymmetric eigenvalue routines (currently ZGEES and ZGEESX) on a suite of randomly generated matrices. It is called by the LAPACK testing programs xerbla.f and xdrpes.f.

The driver routine is called by the main testing program xerbla.f, which generates the test matrices and calls the LAPACK routines. The values computed by xerbla.f are then compared with those computed by xdrpes.f, and the results are printed out.

A description of the tests performed can be found in the comments at the beginning of the source file.

The arguments are as follows:

NSIZES

!>          NSIZES is INTEGER
!>          The number of values of N to be tested.

NN

!>          NN is INTEGER array, dimension (NSIZES)
!>          The dimensions of the matrices to be tested.
!>          NN(j) specifies the dimension of the matrices to be tested
!>          in the j-th iteration.

NTYPES

!>          NTYPES is INTEGER
!>          The number of matrix types to be tested.
!>          The matrix type is specified by the integer DOTYPE(j).
!>          The matrix type is determined by the value of DOTYPE(j).
!>          If DOTYPE(j) = 0, then no matrix of type j will be generated.
!>          If DOTYPE(j) = 1, then a general matrix will be generated.
!>          If DOTYPE(j) = 2, then a matrix with random eigenvalues will be
!>          generated.
!>          If DOTYPE(j) = 3, then a matrix with eigenvalues on the unit circle
!>          will be generated.
!>          If DOTYPE(j) = 4, then a matrix with eigenvalues in the interval
!>          [0,1] will be generated.
!>          If DOTYPE(j) = 5, then a matrix with eigenvalues in the interval
!>          [-1,0] will be generated.
!>          If DOTYPE(j) = 6, then a matrix with eigenvalues in the interval
!>          [-i,i] will be generated.
!>          If DOTYPE(j) = 7, then a matrix with eigenvalues in the interval
!>          [1,i] will be generated.
!>          If DOTYPE(j) = 8, then a matrix with eigenvalues in the interval
!>          [-1, -i] will be generated.
!>          If DOTYPE(j) = 9, then a matrix with eigenvalues in the interval
!>          [-i, 1] will be generated.
!>          If DOTYPE(j) = 10, then a matrix with eigenvalues in the interval
!>          [-1, 1] will be generated.
!>          If DOTYPE(j) > 10, then a general matrix will be generated.
!>          The number of types is limited by MAXTYP. If NTYPES is smaller than
!>          MAXTYP, then types MAXTYP+1 through NTYPES will not be generated.
!>          If NTYPES is larger than MAXTYP, DOTYPE(MAXTYP+1) through
!>          DOTYPE(NTYPES) will be ignored.

DOTYPE

!>          DOTYPE is INTEGER array, dimension (NTYPES)
!>          DOTYPE(j) specifies the type of matrix to be generated.
!>          See the description of NTYPES for the meaning of DOTYPE(j).

ISEED

!>          ISEED is INTEGER array, dimension (4)
!>          On entry ISEED specifies the seed of the random number
!>          generator. The array elements should be between 0 and 4095;
!>          if not they will be reduced mod 4096.  Also, ISEED(4) must
!>          be odd.  The random number generator uses a linear
!>          congruential sequence limited to small integers, and so
!>          should produce machine independent random numbers. The
!>          values of ISEED are changed on exit, and can be used in the
!>          next call to ZDRVES to continue the same random number
!>          sequence.

THRESH

!>          THRESH is DOUBLE PRECISION
!>          A test will count as  if the , computed as
!>          described above, exceeds THRESH.  Note that the error
!>          is scaled to be O(1), so THRESH should be a reasonably
!>          small multiple of 1, e.g., 10 or 100.  In particular,
!>          it should not depend on the precision (single vs. double)
!>          or the size of the matrix.  It must be at least zero.

NOUNIT

!>          NOUNIT is INTEGER
!>          The FORTRAN unit number for printing out error messages
!>          (e.g., if a routine returns INFO not equal to 0.)

A

!>          A is COMPLEX*16 array, dimension (LDA, max(NN))
!>          Used to hold the matrix whose eigenvalues are to be
!>          computed.  On exit, A contains the last matrix actually used.

LDA

!>          LDA is INTEGER
!>          The leading dimension of A, and H. LDA must be at
!>          least 1 and at least max( NN ).

H

!>          H is COMPLEX*16 array, dimension (LDA, max(NN))
!>          Another copy of the test matrix A, modified by ZGEES.

HT

!>          HT is COMPLEX*16 array, dimension (LDA, max(NN))
!>          Yet another copy of the test matrix A, modified by ZGEES.

W

!>          W is COMPLEX*16 array, dimension (max(NN))
!>          The computed eigenvalues of A.

WT

!>          WT is COMPLEX*16 array, dimension (max(NN))
!>          Like W, this array contains the eigenvalues of A,
!>          but those computed when ZGEES only computes a partial
!>          eigendecomposition, i.e. not Schur vectors

VS

!>          VS is COMPLEX*16 array, dimension (LDVS, max(NN))
!>          VS holds the computed Schur vectors.

LDVS

!>          LDVS is INTEGER
!>          Leading dimension of VS. Must be at least max(1,max(NN)).

RESULT

!>          RESULT is DOUBLE PRECISION array, dimension (13)
!>          The values computed by the 13 tests described above.
!>          The values are currently limited to 1/ulp, to avoid overflow.

WORK

!>          WORK is COMPLEX*16 array, dimension (NWORK)

NWORK

!>          NWORK is INTEGER
!>          The number of entries in WORK.  This must be at least
!>          5*NN(j)+2*NN(j)**2 for all j.

RWORK

!>          RWORK is DOUBLE PRECISION array, dimension (max(NN))

IWORK

!>          IWORK is INTEGER array, dimension (max(NN))

BWORK

!>          BWORK is LOGICAL array, dimension (max(NN))

INFO

!>          INFO is INTEGER
!>          If 0, then everything ran OK.
!>           -1: NSIZES < 0
!>           -2: Some NN(j) < 0
!>           -3: NTYPES < 0
!>           -6: THRESH < 0
!>           -9: LDA < 1 or LDA < NMAX, where NMAX is max( NN(j) ).
!>          -15: LDVS < 1 or LDVS < NMAX, where NMAX is max( NN(j) ).
!>          -18: NWORK too small.
!>          If  ZLATMR, CLATMS, CLATME or ZGEES returns an error code,
!>              the absolute value of it is returned.
!>
!>-----------------------------------------------------------------------
!>
!>     Some Local Variables and Parameters:
!>     ---- ----- --------- --- ----------
!>     ZERO, ONE       Real 0 and 1.
!>     MAXTYP          The number of types defined.
!>     NMAX            Largest value in NN.
!>     NERRS           The number of tests which have exceeded THRESH
!>     COND, CONDS,
!>     IMODE           Values to be passed to the matrix generators.
!>     ANORM           Norm of A; passed to matrix generators.
!>
!>     OVFL, UNFL      Overflow and underflow thresholds.
!>     ULP, ULPINV     Finest relative precision and its inverse.
!>     RTULP, RTULPI   Square roots of the previous 4 values.
!>             The following four arrays decode JTYPE:
!>     KTYPE(j)        The general type (1-10) for type .
!>     KMODE(j)        The MODE value to be passed to the matrix
!>                     generator for type .
!>     KMAGN(j)        The order of magnitude ( O(1),
!>                     O(overflow^(1/2) ), O(underflow^(1/2) )
!>     KCONDS(j)       Select whether CONDS is to be 1 or
!>                     1/sqrt(ulp).  (0 means irrelevant.)
