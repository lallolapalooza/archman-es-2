subroutine zdrgev (integer nsizes, integer, dimension( * ) nn, integer ntypes, logical, dimension( * ) dotype, integer, dimension( 4 ) iseed, double precision thresh, integer nounit, complex*16, dimension( lda, * ) a, integer lda, complex*16, dimension( lda, * ) b, complex*16, dimension( lda, * ) s, complex*16, dimension( lda, * ) t, complex*16, dimension( ldq, * ) q, integer ldq, complex*16, dimension( ldq, * ) z, complex*16, dimension( ldqe, * ) qe, integer ldqe, complex*16, dimension( * ) alpha, complex*16, dimension( * ) beta, complex*16, dimension( * ) alpha1, complex*16, dimension( * ) beta1, complex*16, dimension( * ) work, integer lwork, double precision, dimension( * ) rwork, double precision, dimension( * ) result, integer info)

ZDRGEV

Propósito:

!>
!> ZDRGEV comprueba la subrutina de control de problemas de valores propios generalizados no simétricos ZGGEV.
!>
!> ZGGEV calcula para un par de matrices no simétricas n x n (A,B) los
!> valores propios generalizados y, opcionalmente, los vectores propios
!> izquierdo y derecho.
!>
!> Un valor propio generalizado para un par de matrices (A,B) es un escalar w
!> o una razón alpha/beta = w, tal que A - w*B es singular. Se
!> representa usualmente como el par (alpha,beta), ya que hay una
!> interpretación razonable para beta=0, e incluso para ambos siendo cero.
!>
!> Un vector propio generalizado derecho correspondiente a un valor propio
!> generalizado w para un par de matrices (A,B) es un vector r tal que
!> (A - wB) * r = 0. Un vector propio generalizado izquierdo es un vector l
!> tal que l**H * (A - wB) = 0, donde l**H es la transpuesta conjugada de l.
!>
!> Cuando se llama a ZDRGEV, se especifica un número de tamaños de matriz y
!> un número de tipos de matriz. Para cada tamaño y cada tipo de matriz, se generará
!> y utilizará un par de matrices (A, B) para las pruebas. Para cada par de
!> matrices, se realizarán las siguientes pruebas y se compararán con el umbral THRESH.
!>
!> Resultados de ZGGEV:
!>
!> (1) max sobre todos los pares de valores propios/vectores propios izquierdos (alpha/beta,l) de
!>
!>     | VL**H * (beta A - alpha B) |/( ulp max(|beta A|, |alpha B|) )
!>
!>     donde VL**H es la transpuesta conjugada de VL.
!>
!> (2) | |VL(i)| - 1 | / ulp y si el componente más grande es real
!>
!>     VL(i) denota la i-ésima columna de VL.
!>
!> (3) max sobre todos los pares de valores propios/vectores propios izquierdos (alpha/beta,r) de
!>
!>     | (beta A - alpha B) * VR | / ( ulp max(|beta A|, |alpha B|) )
!>
!> (4) | |VR(i)| - 1 | / ulp y si el componente más grande es real
!>
!>     VR(i) denota la i-ésima columna de VR.
!>
!> (5) W(completo) = W(parcial)
!>     W(completo) denota los valores propios calculados cuando también se calculan l y r,
!>     y W(parcial) denota los valores propios calculados cuando solo se calculan W,
!>     solo W y r, o solo W y l.
!>
!> (6) VL(completo) = VL(parcial)
!>     VL(completo) denota los vectores propios izquierdos calculados cuando se calculan l y r,
!>     y VL(parcial) denota el resultado cuando solo se calcula l.
!>
!> (7) VR(completo) = VR(parcial)
!>     VR(completo) denota los vectores propios derechos calculados cuando también se calculan l y r,
!>     y VR(parcial) denota el resultado cuando solo se calcula l.
!>
!>
!> Matrices de Prueba
!> ---- --------
!>
!> Los tamaños de las matrices de prueba se especifican mediante un array
!> NN(1:NSIZES); el valor de cada elemento NN(j) especifica un tamaño.
!> Los tipos de matriz se especifican mediante un array lógico DOTYPE( 1:NTYPES ); si
!> DOTYPE(j) es .TRUE., se generará el tipo de matriz j.
!> Actualmente, la lista de tipos posibles es:
!>
!> (1) ( 0, 0 ) (un par de matrices cero)
!>
!> (2) ( I, 0 ) (una identidad y una matriz cero)
!>
!> (3) ( 0, I ) (una identidad y una matriz cero)
!>
!> (4) ( I, I ) (un par de matrices identidad)
!>
!>     t   t
!> (5) ( J , J  ) (un par de bloques de Jordan transpuestos)
!>
!>                                     t                ( I   0  )
!> (6) ( X, Y ) donde  X = ( J   0  )  y Y = (      t )
!>                                  ( 0   I  )          ( 0   J  )
!>                       y I es una identidad k x k y J un bloque de Jordan (k+1)x(k+1); k=(N-1)/2
!>
!> (7) ( D, I ) donde D es diag( 0, 1,..., N-1 ) (una matriz diagonal
!>                       con esas entradas diagonales.)
!> (8) ( I, D )
!>
!> (9) ( big*D, small*I ) donde big está cerca del desbordamiento y small=1/big
!>
!> (10) ( small*D, big*I )
!>
!> (11) ( big*I, small*D )
!>
!> (12) ( small*I, big*D )
!>
!> (13) ( big*D, big*I )
!>
!> (14) ( small*D, small*I )
!>
!> (15) ( D1, D2 ) donde D1 es diag( 0, 0, 1, ..., N-3, 0 ) y
!>                       D2 es diag( 0, N-3, N-4,..., 1, 0, 0 )
!>    t   t
!> (16) Q ( J , J ) Z donde Q y Z son matrices ortogonales aleatorias.
!>
!> (17) Q ( T1, T2 ) Z donde T1 y T2 son matrices triangulares superiores
!>                       con entradas O(1) aleatorias sobre la diagonal
!>                       y entradas diagonales diag(T1) =
!>                       ( 0, 0, 1, ..., N-3, 0 ) y diag(T2) =
!>                       ( 0, N-3, N-4,..., 1, 0, 0 )
!>
!> (18) Q ( T1, T2 ) Z donde diag(T1) = ( 0, 0, 1, 1, s, ..., s, 0 )
!>                       diag(T2) = ( 0, 1, 0, 1,..., 1, 0 )
!>                       s = precisión de la máquina.
!>
!> (19) Q ( T1, T2 ) Z donde diag(T1)=( 0,0,1,1, 1-d, ..., 1-(N-5)*d=s, 0 )
!>                       diag(T2) = ( 0, 1, 0, 1, ..., 1, 0 )
!>
!>                                                       N-5
!> (20) Q ( T1, T2 ) Z donde diag(T1)=( 0, 0, 1, 1, a, ..., a   =s, 0 )
!>                       diag(T2) = ( 0, 1, 0, 1, ..., 1, 0, 0 )
!>
!> (21) Q ( T1, T2 ) Z donde diag(T1)=( 0, 0, 1, r1, r2, ..., r(N-4), 0 )
!>                       diag(T2) = ( 0, 1, 0, 1, ..., 1, 0, 0 )
!>                       donde r1,..., r(N-4) son aleatorios.
!>
!> (22) Q ( big*T1, small*T2 ) Z donde diag(T1) = ( 0, 0, 1, ..., N-3, 0 )
!>                                  diag(T2) = ( 0, 1, ..., 1, 0, 0 )
!>
!> (23) Q ( small*T1, big*T2 ) Z donde diag(T1) = ( 0, 0, 1, ..., N-3, 0 )
!>                                  diag(T2) = ( 0, 1, ..., 1, 0, 0 )
!>
!> (24) Q ( small*T1, small*T2 ) Z  diag(T1) = ( 0, 0, 1, ..., N-3, 0 )
!>                                  diag(T2) = ( 0, 1, ..., 1, 0, 0 )
!>
!> (25) Q ( big*T1, big*T2 ) Z      diag(T1) = ( 0, 0, 1, ..., N-3, 0 )
!>                                  diag(T2) = ( 0, 1, ..., 1, 0, 0 )
!>
!> (26) Q ( T1, T2 ) Z donde T1 y T2 son matrices triangulares superiores
!>                       aleatorias.
!>
!>

zdrgev(3)

NAME

zdrgev - Computes the generalized eigenvalues and possibly generalized eigenvectors for a pair of arbitrary complex matrices (A,B).

SYNOPSIS

SUBROUTINE ZDRGEV(
     N, NTIPOS, NSIZES, NTYPES, ISEED, THRESH, NOUNIT, A, LDA, B,
     LDA, S, T, Q, LDQ, Z, LDZ, QE, LDQE, ALPHA, BETA, ALPHA1, BETA1,
     WORK, LWORK, RWORK, RESULT, IERR)
CHARACTER*(*) A, B, S, T, Q, Z, QE
INTEGER N, NTIPOS, NSIZES, NTYPES, ISEED, THRESH, NOUNIT, LDA,
     LDQ, LDZ, LDQE, LWORK, IERR
INTEGER NN(*)
COMPLEX*16 S(*), T(*), Q(*), Z(*), QE(*), WORK(*), ALPHA(*),
     BETA(*), ALPHA1(*), BETA1(*)
DOUBLE PRECISION THRESH, RWORK(*), RESULT(*)

Function/Subroutine Documentation

Esta rutina llama a las rutinas de prueba para las pruebas de precisión de los pares de autovalores de matrices de dimensionamiento complejo generalizado. Los pares de autovalores de (A, B) son tales que A*x = lambda*B*x.

La rutina de prueba es:

        ZDRGEV( N, NTIPOS, NSIZES, NTYPES, ISEED, THRESH, NOUNIT, A,
     &           LDA, B, LDA, S, T, Q, LDQ, Z, LDZ, QE, LDQE, ALPHA,
     &           BETA, ALPHA1, BETA1, WORK, LWORK, RWORK, RESULT, IERR )

Donde:

N

N es INTEGER

El tamaño de la matriz.

NTIPOS

NTIPOS es INTEGER

El número de tipos de matrices para generar. Cada tipo se prueba para cada tamaño en NN. Véase DOTYPE para la definición de los tipos.

NSIZES

NSIZES es INTEGER

El número de tamaños de matrices a probar. Véase NN.

NN

NN es INTEGER array, dimension (NSIZES)

Los tamaños de las matrices a probar. Si NSIZES=1, entonces NN(1) es el número de matrices a probar.

Se aplicarán los tamaños especificados por NN.

NTYPES

NTYPES es INTEGER

El número de elementos en DOTYPE. Si es cero, ZDRGEV no hace nada. Debe ser al menos cero. Si es MAXTYP+1 y NSIZES es 1, entonces se define un tipo adicional, MAXTYP+1, que consiste en usar la matriz que esté en A. Esto solo es útil si DOTYPE(1:MAXTYP) es .FALSE. y DOTYPE(MAXTYP+1) es .TRUE.

DOTYPE

DOTYPE es array LOGICAL, dimension (NTYPES)

Si DOTYPE(j) es .TRUE., entonces para cada tamaño en NN se generará una matriz de ese tamaño y de tipo j. Si NTYPES es menor que el número máximo de tipos definidos (PARAMETER MAXTYP), entonces los tipos NTYPES+1 hasta MAXTYP no se generarán. Si NTYPES es mayor que MAXTYP, DOTYPE(MAXTYP+1) hasta DOTYPE(NTYPES) serán ignorados.

ISEED

ISEED es array INTEGER, dimension (4)

A la entrada ISEED especifica la semilla del generador de números aleatorios. Los elementos del array deben estar entre 0 y 4095; si no, serán reducidos módulo 4096. Además, ISEED(4) debe ser impar. El generador de números aleatorios utiliza una secuencia congruencial lineal limitada a enteros pequeños, y por lo tanto debería producir números aleatorios independientes de la máquina. Los valores de ISEED se modifican a la salida, y se pueden usar en la siguiente llamada a ZDRGES para continuar la misma secuencia de números aleatorios.

THRESH

THRESH es DOUBLE PRECISION

Una prueba se contará como exitosa si el error, calculado como se describe anteriormente, excede THRESH. Tenga en cuenta que el error se escala para ser O(1), por lo que THRESH debería ser un múltiplo razonablemente pequeño de 1, por ejemplo, 10 o 100. En particular, no debe depender de la precisión (simple o doble) ni del tamaño de la matriz. Debe ser al menos cero.

NOUNIT

NOUNIT es INTEGER

El número de unidad FORTRAN para imprimir mensajes de error (por ejemplo, si una rutina devuelve IERR distinto de 0).

A

A es array COMPLEX*16, dimension(LDA, max(NN))

Se utiliza para almacenar la matriz A original. Se usa solo como entrada si NTYPES=MAXTYP+1, DOTYPE(1:MAXTYP)=.FALSE., y DOTYPE(MAXTYP+1)=.TRUE.

LDA

LDA es INTEGER

La dimensión principal de A, B, S y T. Debe ser al menos 1 y al menos max( NN ).

B

B es array COMPLEX*16, dimension(LDA, max(NN))

Se utiliza para almacenar la matriz B original. Se usa solo como entrada si NTYPES=MAXTYP+1, DOTYPE(1:MAXTYP)=.FALSE., y DOTYPE(MAXTYP+1)=.TRUE.

S

S es array COMPLEX*16, dimension (LDA, max(NN))

La matriz de forma de Schur calculada a partir de A por ZGGEV. A la salida, S contiene la matriz de forma de Schur correspondiente a la matriz en A.

T

T es array COMPLEX*16, dimension (LDA, max(NN))

La matriz triangular superior calculada a partir de B por ZGGEV.

Q

Q es array COMPLEX*16, dimension (LDQ, max(NN))

La matriz de autovectores (izquierdos) calculada por ZGGEV.

LDQ

LDQ es INTEGER

La dimensión principal de Q y Z. Debe ser al menos 1 y al menos max( NN ).

Z

Z es array COMPLEX*16, dimension( LDQ, max(NN) )

La matriz ortogonal (derecha) calculada por ZGGEV.

QE

QE es array COMPLEX*16, dimension( LDQ, max(NN) )

QE contiene los autovectores derechos o izquierdos calculados.

LDQE

LDQE es INTEGER

La dimensión principal de QE. LDQE >= max(1,max(NN)).

ALPHA

ALPHA es array COMPLEX*16, dimension (max(NN))

BETA

BETA es array COMPLEX*16, dimension (max(NN))

Los autovalores generalizados de (A,B) calculados por ZGGEV. ( ALPHAR(k)+ALPHAI(k)*i ) / BETA(k) es el k-ésimo autovalor generalizado de A y B.

ALPHA1

ALPHA1 es array COMPLEX*16, dimension (max(NN))

BETA1

BETA1 es array COMPLEX*16, dimension (max(NN))

Al igual que ALPHAR, ALPHAI, BETA, estos arrays contienen los autovalores de A y B, pero los calculados cuando ZGGEV solo calcula una descomposición en autovalores parcial, es decir, no los autovalores y los autovectores izquierdos y derechos.

WORK

WORK es array COMPLEX*16, dimension (LWORK)

LWORK

LWORK es INTEGER

El número de entradas en WORK. LWORK >= N*(N+1)

RWORK

RWORK es array DOUBLE PRECISION, dimension (8*N)

Espacio de trabajo real.

RESULT

RESULT es array DOUBLE PRECISION, dimension (2)

Los valores calculados por las pruebas descritas anteriormente. Actualmente, los valores se limitan a 1/ulp, para evitar desbordamientos.

INFO

INFO es INTEGER

= 0: salida exitosa

< 0: si INFO = -i, el i-ésimo argumento tenía un valor ilegal.

> 0: Una rutina devolvió un código de error. INFO es el valor absoluto del valor INFO devuelto.
