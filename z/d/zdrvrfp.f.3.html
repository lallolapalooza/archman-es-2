ZDRVRFP

Propósito:

!>
!> ZDRVRFP prueba las rutinas RFP de LAPACK:
!>     ZPFTRF, ZPFTRS, y ZPFTRI.
!>
!> Esta rutina de prueba sigue las mismas pruebas que ZDRVPO (prueba para el
!> solucionador de formato completo Simétrico Definido Positivo).
!>
!> Las pruebas se realizan en Formato Completo, la conversión de ida y vuelta
!> del formato completo al formato RFP se realiza utilizando las rutinas ZTRTTF y
!> ZTFTTR.
!>
!> Primero, se crea una matriz A específica de tamaño N. Hay nueve tipos de
!> diferentes matrices posibles.
!>  1. Diagonal                        6. Aleatoria, CNDNUM = sqrt(0.1/EPS)
!>  2. Aleatoria, CNDNUM = 2              7. Aleatoria, CNDNUM = 0.1/EPS
!> *3. Primera fila y columna cero       8. Escalada cerca de subdesbordamiento
!> *4. Última fila y columna cero        9. Escalada cerca de desbordamiento
!> *5. Fila y columna central cero
!> (* - prueba las salidas de error de ZPFTRF, no se calculan ratios de prueba)
!> Se crea una solución XACT de tamaño N-por-NRHS y el lado derecho asociado B.
!> Luego se llama a ZPFTRF para calcular L (o U), el factor de Cholesky de A.
!> Luego L (o U) se utiliza para resolver el sistema lineal de ecuaciones AX = B.
!> Esto da X. Luego L (o U) se utiliza para calcular la inversa de A, AINV.
!> Luego se realizan las siguientes cuatro pruebas:
!> (1) norm( L*L' - A ) / ( N * norm(A) * EPS ) o
!>     norm( U'*U - A ) / ( N * norm(A) * EPS ),
!> (2) norm(B - A*X) / ( norm(A) * norm(X) * EPS ),
!> (3) norm( I - A*AINV ) / ( N * norm(A) * norm(AINV) * EPS ),
!> (4) ( norm(X-XACT) * RCOND ) / ( norm(XACT) * EPS ),
!> donde EPS es la precisión de la máquina, RCOND el número de condición de A, y
!> norm( . ) la norma 1 para (1,2,3) y la norma inf para (4).
!> Ocurren errores cuando el parámetro INFO no es el esperado. Fallan cuando
!> un ratio de prueba es mayor que THRES.
!>

NAME

zdrvrfp - Driver routines for the real orthogonal test routines.

SYNOPSIS

This manual page was written by the Fortran developers. It is part of the LAPACK library.

Function/Subroutine Documentation

This is a driver routine for the distributed real orthogonal test routines. It is used to test the real orthogonal routines. The following routines are tested:

ZGEQRF
QR decomposition of a general m x n matrix.
ZUNQRF
Form the orthogonal matrix Q of a QR factorization.
ZUNGQR
Generate an m x n matrix with orthonormal columns.
ZGERQF
LQ decomposition of a general m x n matrix.
ZUNRQF
Form the orthogonal matrix Q of an LQ factorization.
ZUNGLQ
Generate an m x n matrix with orthonormal rows.
The driver routine calls the test routines and checks their output. If any routine fails the test, an error message is printed.
