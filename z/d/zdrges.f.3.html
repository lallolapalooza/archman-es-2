DOCUMENTACIÓN DE FUNCIÓN/SUBRUTINA

subrutina zdrges (integer nsizes, integer, dimension( * ) nn, integer ntypes, logical, dimension( * ) dotype, integer, dimension( 4 ) iseed, double precision thresh, integer nounit, complex*16, dimension( lda, * ) a, integer lda, complex*16, dimension( lda, * ) b, complex*16, dimension( lda, * ) s, complex*16, dimension( lda, * ) t, complex*16, dimension( ldq, * ) q, integer ldq, complex*16, dimension( ldq, * ) z, complex*16, dimension( * ) alpha, complex*16, dimension( * ) beta, complex*16, dimension( * ) work, integer lwork, double precision, dimension( * ) rwork, double precision, dimension( 13 ) result, logical, dimension( * ) bwork, integer info)

ZDRGES

Propósito:

!>
!> ZDRGES comprueba el controlador del problema de valores propios generalizados no simétricos (forma de Schur) ZGGES.
!>
!> ZGGES factoriza A y B como Q*S*Z'  y Q*T*Z' , donde ' significa transpuesta conjugada, S y T son triangulares superiores (es decir, en forma de Schur generalizada), y Q y Z son unitarias. También calcula los valores propios generalizados (alpha(j),beta(j)), j=1,...,n. Así,
!> w(j) = alpha(j)/beta(j) es una raíz de la ecuación característica
!>
!>                 det( A - w(j) B ) = 0
!>
!> Opcionalmente, también reordena los valores propios para que un clúster seleccionado de valores propios aparezca en el bloque diagonal principal de las formas de Schur.
!>
!> Cuando se llama a ZDRGES, se especifica un número de matrices () y un número de matrices. Para cada tamaño () y cada TIPO de matriz, se generará un par de matrices (A, B) y se utilizará para las pruebas. Para cada par de matrices, se realizarán las siguientes 13 pruebas y se compararán con el umbral THRESH, excepto las pruebas (5), (11) y (13).
!>
!>
!> (1)   | A - Q S Z' | / ( |A| n ulp ) (sin ordenación de valores propios)
!>
!>
!> (2)   | B - Q T Z' | / ( |B| n ulp ) (sin ordenación de valores propios)
!>
!>
!> (3)   | I - QQ' | / ( n ulp ) (sin ordenación de valores propios)
!>
!>
!> (4)   | I - ZZ' | / ( n ulp ) (sin ordenación de valores propios)
!>
!> (5)   si A está en forma de Schur (es decir, forma triangular) (sin ordenación de valores propios)
!>
!> (6)   si valores propios = elementos diagonales de la forma de Schur (S, T),
!>       es decir, prueba el máximo sobre j de D(j) donde:
!>
!>                     |alpha(j) - S(j,j)|        |beta(j) - T(j,j)|
!>           D(j) = ------------------------ + -----------------------
!>                  max(|alpha(j)|,|S(j,j)|)   max(|beta(j)|,|T(j,j)|)
!>
!>       (sin ordenación de valores propios)
!>
!> (7)   | (A,B) - Q (S,T) Z' | / ( |(A,B)| n ulp )
!>       (con ordenación de valores propios).
!>
!> (8)   | I - QQ' | / ( n ulp ) (con ordenación de valores propios).
!>
!> (9)   | I - ZZ' | / ( n ulp ) (con ordenación de valores propios).
!>
!> (10)  si A está en forma de Schur (es decir, forma cuasi-triangular)
!>       (con ordenación de valores propios).
!>
!> (11)  si valores propios = elementos diagonales de la forma de Schur (S, T),
!>       es decir, prueba el máximo sobre j de D(j) donde:
!>
!>                     |alpha(j) - S(j,j)|        |beta(j) - T(j,j)|
!>           D(j) = ------------------------ + -----------------------
!>                  max(|alpha(j)|,|S(j,j)|)   max(|beta(j)|,|T(j,j)|)
!>
!>       (con ordenación de valores propios).
!>
!> (12)  si la ordenación funcionó y SDIM es el número de valores propios
!>       que fueron SELECCIONADOS.
!>
!> Matrices de Prueba
!> =================
!>
!> Los tamaños de las matrices de prueba se especifican mediante un array
!> NN(1:NSIZES); el valor de cada elemento NN(j) especifica un tamaño.
!> Los  se especifican mediante un array lógico DOTYPE( 1:NTYPES ); si
!> DOTYPE(j) es .TRUE., entonces se generará el tipo de matriz.
!> Actualmente, la lista de tipos posibles es:
!>
!> (1)  ( 0, 0 )         (un par de matrices cero)
!>
!> (2)  ( I, 0 )         (una identidad y una matriz cero)
!>
!> (3)  ( 0, I )         (una identidad y una matriz cero)
!>
!> (4)  ( I, I )         (un par de matrices identidad)
!>
!>         t   t
!> (5)  ( J , J  )       (un par de bloques de Jordan transpuestos)
!>
!>                                     t                ( I   0  )
!> (6)  ( X, Y )         donde  X = ( J   0  )  e Y = (      t )
!>                                  ( 0   I  )          ( 0   J  )
!>                       e I es una identidad k x k y J un bloque de Jordan (k+1)x(k+1)
!>                       k=(N-1)/2
!>
!> (7)  ( D, I )         donde D es diag( 0, 1,..., N-1 ) (una matriz diagonal
!>                       con esas entradas diagonales.)
!> (8)  ( I, D )
!>
!> (9)  ( big*D, small*I ) donde  es cercano al desbordamiento y small=1/big
!>
!> (10) ( small*D, big*I )
!>
!> (11) ( big*I, small*D )
!>
!> (12) ( small*I, big*D )
!>
!> (13) ( big*D, big*I )
!>
!> (14) ( small*D, small*I )
!>
!> (15) ( D1, D2 )        donde D1 es diag( 0, 0, 1, ..., N-3, 0 ) y
!>                        D2 es diag( 0, N-3, N-4,..., 1, 0, 0 )
!>           t   t
!> (16) Q ( J , J ) Z     donde Q y Z son matrices ortogonales aleatorias.
!>
!> (17) Q ( T1, T2 ) Z    donde T1 y T2 son matrices triangulares superiores
!>                        con entradas O(1) aleatorias sobre la diagonal
!>                        y entradas diagonales diag(T1) =
!>                        ( 0, 0, 1, ..., N-3, 0 ) y diag(T2) =
!>                        ( 0, N-3, N-4,..., 1, 0, 0 )
!>
!> (18) Q ( T1, T2 ) Z    diag(T1) = ( 0, 0, 1, 1, s, ..., s, 0 )
!>                        diag(T2) = ( 0, 1, 0, 1,..., 1, 0 )
!>                        s = precisión de máquina.
!>
!> (19) Q ( T1, T2 ) Z    diag(T1)=( 0, 0, 1, 1, 1-d, ..., 1-(N-5)*d=s, 0 )
!>                        diag(T2) = ( 0, 1, 0, 1, ..., 1, 0 )
!>
!>                                                        N-5
!> (20) Q ( T1, T2 ) Z    diag(T1)=( 0, 0, 1, 1, a, ..., a   =s, 0 )
!>                        diag(T2) = ( 0, 1, 0, 1, ..., 1, 0, 0 )
!>
!> (21) Q ( T1, T2 ) Z    diag(T1)=( 0, 0, 1, r1, r2, ..., r(N-4), 0 )
!>                        diag(T2) = ( 0, 1, 0, 1, ..., 1, 0, 0 )
!>                        donde r1,..., r(N-4) son aleatorias.
!>
!> (22) Q ( big*T1, small*T2 ) Z    diag(T1) = ( 0, 0, 1, ..., N-3, 0 )
!>                                  diag(T2) = ( 0, 1, ..., 1, 0, 0 )
!>
!> (23) Q ( small*T1, big*T2 ) Z    diag(T1) = ( 0, 0, 1, ..., N-3, 0 )
!>                                  diag(T2) = ( 0, 1, ..., 1, 0, 0 )
!>
!> (24) Q ( small*T1, small*T2 ) Z  diag(T1) = ( 0, 0, 1, ..., N-3, 0 )
!>                                  diag(T2) = ( 0, 1, ..., 1, 0, 0 )
!>
!> (25) Q ( big*T1, big*T2 ) Z      diag(T1) = ( 0, 0, 1, ..., N-3, 0 )
!>                                  diag(T2) = ( 0, 1, ..., 1, 0, 0 )
!>
!> (26) Q ( T1, T2 ) Z     donde T1 y T2 son matrices triangulares superiores aleatorias.
!>
!>

Parámetros

NSIZES 
!>          NSIZES es INTEGER
!>          El número de tamaños de matrices a utilizar. Si es cero,
!>          DDRGES no hace nada.  NSIZES >= 0.
!>

NN

!>          NN es un array INTEGER, dimensión (NSIZES)
!>          Un array que contiene los tamaños que se utilizarán para las matrices.
!>          Los valores cero se omitirán.  NN >= 0.
!>

NTYP

DOTYPE

!>          DOTYPE es un array LOGICAL, dimensión (NTYPES)
!>          Un array lógico. Si DOTYPE(j) es .TRUE., entonces se genera el tipo j de matriz.
!>

ISEED

!>          ISEED es un array INTEGER, dimensión (4)
!>          El generador de números aleatorios se inicializa en el primer
!>          llamada a ZDRGES y se actualiza en cada llamada posterior.
!>

THRESH

!>          THRESH es DOUBLE PRECISION
!>          El umbral para las pruebas. Por lo general, se establece en
!>          un valor de alrededor de 10 a 100 veces la precisión de la máquina.
!>

NOUNU

!>          NOUNU es INTEGER
!>          NOUNU es un parámetro de control. Si NOUNU = 0, entonces
!>          a) se calcularán los valores propios generalizados.
!>          b) si se realiza la ordenación, se reordenarán los valores propios.
!>          Si NOUNU /= 0, entonces los valores propios no se calculan
!>          ni se ordenan.
!>

A

!>          A es COMPLEX*16, dimensión (LDA,*)
!>          La matriz A.
!>

LDA

!>          LDA es INTEGER
!>          El primer dimensionamiento de A.
!>

B

!>          B es COMPLEX*16, dimensión (LDA,*)
!>          La matriz B.
!>

S

!>          S es COMPLEX*16, dimensión (LDA,*)
!>          La matriz S (forma de Schur superior de A).
!>

T

!>          T es COMPLEX*16, dimensión (LDA,*)
!>          La matriz T (forma de Schur superior de B).
!>

Q

!>          Q es COMPLEX*16, dimensión (LDQ,*)
!>          La matriz unitaria Q.
!>

LDQ

!>          LDQ es INTEGER
!>          El primer dimensionamiento de Q.
!>

Z

!>          Z es COMPLEX*16, dimensión (LDQ,*)
!>          La matriz unitaria Z.
!>

ALPHA

!>          ALPHA es COMPLEX*16, dimensión (*)
!>          El primer componente de los valores propios generalizados.
!>

BETA

!>          BETA es COMPLEX*16, dimensión (*)
!>          El segundo componente de los valores propios generalizados.
!>

WORK

!>          WORK es COMPLEX*16, dimensión (*)
!>          Un array de trabajo para uso interno del subprograma.
!>

LWORK

!>          LWORK es INTEGER
!>          La longitud del array WORK. LWORK debe ser lo suficientemente grande
!>          como para contener el tamaño máximo de matriz utilizado, más algunos
!>          elementos adicionales (ver la documentación de ZGGES).
!>

RWORK

!>          RWORK es DOUBLE PRECISION, dimensión (*)
!>          Un array de trabajo para uso interno del subprograma.
!>

RESULT

!>          RESULT es DOUBLE PRECISION, dimensión (13)
!>          El resultado de las 13 pruebas.
!>

BWORK

!>          BWORK es LOGICAL, dimensión (*)
!>          Un array de trabajo lógico para uso interno del subprograma.
!>

INFO

!>          INFO es INTEGER
!>          INFO = 0, indica éxito.
!>          INFO < 0, indica un error de entrada. Por ejemplo, si
!>          el i-ésimo argumento no válido tiene el valor de -i.
!>          INFO > 0, indica que el subprograma de cálculo de valores
!>          propios falló en converger, y el valor de INFO indica el número
!>          de la diagonal sobre la cual falló la convergencia.
!>

Function/Subroutine Documentation

NTYPES

!>          NTYPES is INTEGER
!>          The number of elements in DOTYPE.   If it is zero, DDRGES
!>          does nothing.  It must be at least zero.  If it is MAXTYP+1
!>          and NSIZES is 1, then an additional type, MAXTYP+1 is
!>          defined, which is to use whatever matrix is in A on input.
!>          This is only useful if DOTYPE(1:MAXTYP) is .FALSE. and
!>          DOTYPE(MAXTYP+1) is .TRUE. .
!>

DOTYPE

!>          DOTYPE is LOGICAL array, dimension (NTYPES)
!>          If DOTYPE(j) is .TRUE., then for each size in NN a
!>          matrix of that size and of type j will be generated.
!>          If NTYPES is smaller than the maximum number of types
!>          defined (PARAMETER MAXTYP), then types NTYPES+1 through
!>          MAXTYP will not be generated. If NTYPES is larger
!>          than MAXTYP, DOTYPE(MAXTYP+1) through DOTYPE(NTYPES)
!>          will be ignored.
!>

ISEED

!>          ISEED is INTEGER array, dimension (4)
!>          On entry ISEED specifies the seed of the random number
!>          generator. The array elements should be between 0 and 4095;
!>          if not they will be reduced mod 4096. Also, ISEED(4) must
!>          be odd.  The random number generator uses a linear
!>          congruential sequence limited to small integers, and so
!>          should produce machine independent random numbers. The
!>          values of ISEED are changed on exit, and can be used in the
!>          next call to DDRGES to continue the same random number
!>          sequence.
!>

THRESH

!>          THRESH is DOUBLE PRECISION
!>          A test will count as  if the , computed as
!>          described above, exceeds THRESH.  Note that the error is
!>          scaled to be O(1), so THRESH should be a reasonably small
!>          multiple of 1, e.g., 10 or 100.  In particular, it should
!>          not depend on the precision (single vs. double) or the size
!>          of the matrix.  THRESH >= 0.
!>

NOUNIT

!>          NOUNIT is INTEGER
!>          The FORTRAN unit number for printing out error messages
!>          (e.g., if a routine returns IINFO not equal to 0.)
!>

A

!>          A is COMPLEX*16 array, dimension(LDA, max(NN))
!>          Used to hold the original A matrix.  Used as input only
!>          if NTYPES=MAXTYP+1, DOTYPE(1:MAXTYP)=.FALSE., and
!>          DOTYPE(MAXTYP+1)=.TRUE.
!>

LDA

!>          LDA is INTEGER
!>          The leading dimension of A, B, S, and T.
!>          It must be at least 1 and at least max( NN ).
!>

B

!>          B is COMPLEX*16 array, dimension(LDA, max(NN))
!>          Used to hold the original B matrix.  Used as input only
!>          if NTYPES=MAXTYP+1, DOTYPE(1:MAXTYP)=.FALSE., and
!>          DOTYPE(MAXTYP+1)=.TRUE.
!>

S

!>          S is COMPLEX*16 array, dimension (LDA, max(NN))
!>          The Schur form matrix computed from A by ZGGES.  On exit, S
!>          contains the Schur form matrix corresponding to the matrix
!>          in A.
!>

T

!>          T is COMPLEX*16 array, dimension (LDA, max(NN))
!>          The upper triangular matrix computed from B by ZGGES.
!>

Q

!>          Q is COMPLEX*16 array, dimension (LDQ, max(NN))
!>          The (left) orthogonal matrix computed by ZGGES.
!>

LDQ

!>          LDQ is INTEGER
!>          The leading dimension of Q and Z. It must
!>          be at least 1 and at least max( NN ).
!>

Z

!>          Z is COMPLEX*16 array, dimension( LDQ, max(NN) )
!>          The (right) orthogonal matrix computed by ZGGES.
!>

ALPHA

!>          ALPHA is COMPLEX*16 array, dimension (max(NN))
!>

BETA

!>          BETA is COMPLEX*16 array, dimension (max(NN))
!>
!>          The generalized eigenvalues of (A,B) computed by ZGGES.
!>          ALPHA(k) / BETA(k) is the k-th generalized eigenvalue of A
!>          and B.
!>

WORK

!>          WORK is COMPLEX*16 array, dimension (LWORK)
!>

LWORK

!>          LWORK is INTEGER
!>          The dimension of the array WORK.  LWORK >= 3*N*N.
!>

RWORK

!>          RWORK is DOUBLE PRECISION array, dimension ( 8*N )
!>          Real workspace.
!>

RESULT

!>          RESULT is DOUBLE PRECISION array, dimension (15)
!>          The values computed by the tests described above.
!>          The values are currently limited to 1/ulp, to avoid overflow.
!>

BWORK

!>          BWORK is LOGICAL array, dimension (N)
!>

INFO

!>          INFO is INTEGER
!>          = 0:  successful exit
!>          < 0:  if INFO = -i, the i-th argument had an illegal value.
!>          > 0:  A routine returned an error code.  INFO is the
!>                absolute value of the INFO value returned.
!>
