ZDRVBD

Propósito:

!>
!> ZDRVBD comprueba el controlador de descomposición en valores singulares (SVD) ZGESVD,
!> ZGESDD, ZGESVJ, ZGEJSV, ZGESVDX y ZGESVDQ.
!>
!> ZGESVD y ZGESDD factorizan A = U diag(S) VT, donde U y VT son unitarias
!> y diag(S) es diagonal con las entradas del array S en su diagonal.
!> Las entradas de S son los valores singulares, no negativos y almacenados en orden
!> decreciente. U y VT opcionalmente pueden no ser calculados, sobrescritos en A,
!> o calculados parcialmente.
!>
!> A es M por N. Sea MNMIN = min( M, N ). S tiene dimensión MNMIN.
!> U puede ser M por M o M por MNMIN. VT puede ser N por N o MNMIN por N.
!>
!> Cuando se llama a ZDRVBD, se especifican un número de tamaños de
!> matrices (M's y N's) y un número de tipos de matrices. Para cada tamaño (M,N)
!> y cada tipo de matriz, y tanto para el espacio de trabajo mínimo como para
!> el espacio de trabajo adecuado para permitir el bloqueo, se generará una matriz
!> M x N y se usará para probar las rutinas SVD. Para cada matriz, A se
!> factorizará como A = U diag(S) VT y se calcularán las siguientes 12 pruebas:
!>
!> Prueba para ZGESVD:
!>
!> (1)   | A - U diag(S) VT | / ( |A| max(M,N) ulp )
!>
!> (2)   | I - U'U | / ( M ulp )
!>
!> (3)   | I - VT VT' | / ( N ulp )
!>
!> (4)   S contiene MNMIN valores no negativos en orden decreciente.
!>       (Devuelve 0 si es verdadero, 1/ULP si es falso).
!>
!> (5)   | U - Upartial | / ( M ulp ) donde Upartial es una U calculada
!>       parcialmente.
!>
!> (6)   | VT - VTpartial | / ( N ulp ) donde VTpartial es una VT calculada
!>       parcialmente.
!>
!> (7)   | S - Spartial | / ( MNMIN ulp |S| ) donde Spartial es el
!>       vector de valores singulares de la SVD parcial.
!>
!> Prueba para ZGESDD:
!>
!> (8)   | A - U diag(S) VT | / ( |A| max(M,N) ulp )
!>
!> (9)   | I - U'U | / ( M ulp )
!>
!> (10)  | I - VT VT' | / ( N ulp )
!>
!> (11)  S contiene MNMIN valores no negativos en orden decreciente.
!>       (Devuelve 0 si es verdadero, 1/ULP si es falso).
!>
!> (12)  | U - Upartial | / ( M ulp ) donde Upartial es una U calculada
!>       parcialmente.
!>
!> (13)  | VT - VTpartial | / ( N ulp ) donde VTpartial es una VT calculada
!>       parcialmente.
!>
!> (14)  | S - Spartial | / ( MNMIN ulp |S| ) donde Spartial es el
!>       vector de valores singulares de la SVD parcial.
!>
!> Prueba para ZGESVDQ:
!>
!> (36)  | A - U diag(S) VT | / ( |A| max(M,N) ulp )
!>
!> (37)  | I - U'U | / ( M ulp )
!>
!> (38)  | I - VT VT' | / ( N ulp )
!>
!> (39)  S contiene MNMIN valores no negativos en orden decreciente.
!>       (Devuelve 0 si es verdadero, 1/ULP si es falso).
!>
!> Prueba para ZGESVJ:
!>
!> (15)  | A - U diag(S) VT | / ( |A| max(M,N) ulp )
!>
!> (16)  | I - U'U | / ( M ulp )
!>
!> (17)  | I - VT VT' | / ( N ulp )
!>
!> (18)  S contiene MNMIN valores no negativos en orden decreciente.
!>       (Devuelve 0 si es verdadero, 1/ULP si es falso).
!>
!> Prueba para ZGEJSV:
!>
!> (19)  | A - U diag(S) VT | / ( |A| max(M,N) ulp )
!>
!> (20)  | I - U'U | / ( M ulp )
!>
!> (21)  | I - VT VT' | / ( N ulp )
!>
!> (22)  S contiene MNMIN valores no negativos en orden decreciente.
!>        (Devuelve 0 si es verdadero, 1/ULP si es falso).
!>
!> Prueba para ZGESVDX( 'V', 'V', 'A' )/ZGESVDX( 'N', 'N', 'A' )
!>
!> (23)  | A - U diag(S) VT | / ( |A| max(M,N) ulp )
!>
!> (24)  | I - U'U | / ( M ulp )
!>
!> (25)  | I - VT VT' | / ( N ulp )
!>
!> (26)  S contiene MNMIN valores no negativos en orden decreciente.
!>       (Devuelve 0 si es verdadero, 1/ULP si es falso).
!>
!> (27)  | U - Upartial | / ( M ulp ) donde Upartial es una U calculada
!>       parcialmente.
!>
!> (28)  | VT - VTpartial | / ( N ulp ) donde VTpartial es una VT calculada
!>       parcialmente.
!>
!> (29)  | S - Spartial | / ( MNMIN ulp |S| ) donde Spartial es el
!>       vector de valores singulares de la SVD parcial.
!>
!> Prueba para ZGESVDX( 'V', 'V', 'I' )
!>
!> (30)  | U' A VT''' - diag(S) | / ( |A| max(M,N) ulp )
!>
!> (31)  | I - U'U | / ( M ulp )
!>
!> (32)  | I - VT VT' | / ( N ulp )
!!>
!> Prueba para ZGESVDX( 'V', 'V', 'V' )
!>
!> (33)   | U' A VT''' - diag(S) | / ( |A| max(M,N) ulp )
!>
!> (34)   | I - U'U | / ( M ulp )
!>
!> (35)   | I - VT VT' | / ( N ulp )
!>
!> Los tamaños de matriz se especifican mediante los arrays MM(1:NSIZES) y
!> NN(1:NSIZES); el valor de cada par de elementos (MM(j),NN(j))
!> especifica un tamaño. Los tipos de matriz se especifican mediante un array lógico
!> DOTYPE( 1:NTYPES ); si DOTYPE(j) es .TRUE., entonces se generará una matriz
!> de tipo j.
!> Actualmente, la lista de tipos posibles es:
!>
!> (1)  La matriz cero.
!> (2)  La matriz identidad.
!> (3)  Una matriz de la forma  U D V, donde U y V son unitarias y
!>      D tiene entradas espaciadas uniformemente 1, ..., ULP con signos aleatorios
!>      en la diagonal.
!> (4)  Igual que (3), pero multiplicado por el umbral de desbordamiento inferior / ULP.
!> (5)  Igual que (3), pero multiplicado por el umbral de desbordamiento superior * ULP.
!>

Parámetros

NSIZES 
!>          NSIZES es INTEGER
!>          El número de tamaños de matrices a usar. Si es cero,
!>          ZDRVBD no hace nada. Debe ser al menos cero.
!>

MM

!>          MM es un array INTEGER, dimension (NSIZES)
!>          Un array que contiene los valores M de la matriz a utilizar. Para
!>          cada j=1,...,NSIZES, si MM(j) es cero, entonces MM(j) y NN(j)
!>          serán ignorados. Los valores de MM(j) deben ser al menos cero.
!>

NN

!>          NN es un array INTEGER, dimension (NSIZES)
!>          Un array que contiene los valores N de la matriz a utilizar. Para
!>          cada j=1,...,NSIZES, si NN(j) es cero, entonces MM(j) y NN(j)
!>          serán ignorados. Los valores de NN(j) deben ser al menos cero.
!>

NTYPES

!>          NTYPES es INTEGER
!>          El número de elementos en DOTYPE. Si es cero, ZDRVBD
!>          no hace nada. Debe ser al menos cero. Si es MAXTYP+1
!>          y NSIZES es 1, entonces se define un tipo adicional, MAXTYP+1,
!>          que consiste en usar las matrices que estén en A y B.
!>          Esto solo es útil si DOTYPE(1:MAXTYP) es .FALSE. y
!>          DOTYPE(MAXTYP+1) es .TRUE. .
!>

DOTYPE

!>          DOTYPE es un array LOGICAL, dimension (NTYPES)
!>          Si DOTYPE(j) es .TRUE., entonces para cada tamaño (m,n), se generará una matriz
!>          de tipo j. Si NTYPES

ISEED

          ISEED es un array de ENTEROS, de dimensión (4).
          A la entrada, ISEED especifica la semilla del generador de
          números aleatorios. Los elementos del array deben estar entre
          0 y 4095; si no, se reducirán módulo 4096. Además, ISEED(4)
          debe ser impar. El generador de números aleatorios utiliza una
          secuencia congruencial lineal limitada a enteros pequeños, y por
          lo tanto debe producir números aleatorios independientes de la
          máquina. Los valores de ISEED se modifican a la salida y pueden
          utilizarse en la siguiente llamada a ZDRVBD para continuar la
          misma secuencia de números aleatorios.

THRESH

          THRESH es un REAL*8.
          Una prueba se contará como tal si el resultado, calculado como
          se describe anteriormente, excede THRESH. Tenga en cuenta que el
          error está escalado para ser O(1), por lo que THRESH debe ser un
          múltiplo razonablemente pequeño de 1, por ejemplo, 10 o 100. En
          particular, no debe depender de la precisión (simple o doble) o
          del tamaño de la matriz. Debe ser al menos cero.

A

          A es un array de COMPLEJO*16, de dimensión (LDA,max(NN)).
          Se utiliza para contener la matriz cuyos valores singulares se
          van a calcular. A la salida, A contiene la última matriz utilizada
          realmente.

LDA

          LDA es un ENTERO.
          La dimensión principal de A. Debe ser al menos 1 y al menos
          max( MM ).

U

          U es un array de COMPLEJO*16, de dimensión (LDU,max(MM)).
          Se utiliza para contener la matriz calculada de vectores singulares
          derechos. A la salida, U contiene los últimos vectores de este tipo
          realmente calculados.

LDU

          LDU es un ENTERO.
          La dimensión principal de U. Debe ser al menos 1 y al menos
          max( MM ).

VT

          VT es un array de COMPLEJO*16, de dimensión (LDVT,max(NN)).
          Se utiliza para contener la matriz calculada de vectores singulares
          izquierdos. A la salida, VT contiene los últimos vectores de este tipo
          realmente calculados.

LDVT

          LDVT es un ENTERO.
          La dimensión principal de VT. Debe ser al menos 1 y al menos
          max( NN ).

ASAV

          ASAV es un array de COMPLEJO*16, de dimensión (LDA,max(NN)).
          Se utiliza para contener una copia diferente de la matriz cuyos
          valores singulares se van a calcular. A la salida, A contiene la
          última matriz utilizada realmente.

USAV

          USAV es un array de COMPLEJO*16, de dimensión (LDU,max(MM)).
          Se utiliza para contener una copia diferente de la matriz calculada de
          vectores singulares derechos. A la salida, USAV contiene los últimos
          vectores de este tipo realmente calculados.

VTSAV

          VTSAV es un array de COMPLEJO*16, de dimensión (LDVT,max(NN)).
          Se utiliza para contener una copia diferente de la matriz calculada de
          vectores singulares izquierdos. A la salida, VTSAV contiene los
          últimos vectores de este tipo realmente calculados.

S

          S es un array de REAL*8, de dimensión (max(min(MM,NN))).
          Contiene los valores singulares calculados.

SSAV

          SSAV es un array de REAL*8, de dimensión (max(min(MM,NN))).
          Contiene otra copia de los valores singulares calculados.

E

          E es un array de REAL*8, de dimensión (max(min(MM,NN))).
          Espacio de trabajo para ZGESVD.

WORK

          WORK es un array de COMPLEJO*16, de dimensión (LWORK).

LWORK

          LWORK es un ENTERO.
          El número de entradas en WORK. Debe ser al menos
          MAX(3*MIN(M,N)+MAX(M,N)**2,5*MIN(M,N),3*MAX(M,N)) para todos los
          pares (M,N)=(MM(j),NN(j)).

RWORK

          RWORK es un array de REAL*8, de dimensión (5*max(max(MM,NN))).

IWORK

          IWORK es un array de ENTEROS, de dimensión al menos 8*min(M,N).

NOUNIT

          NOUNIT es un ENTERO.
          El número de unidad FORTRAN para imprimir mensajes de error
          (por ejemplo, si una rutina devuelve IINFO distinto de 0).

INFO

          INFO es un ENTERO.
          Si es 0, entonces todo funcionó correctamente.
          -1: NSIZES < 0
          -2: Algún MM(j) < 0
          -3: Algún NN(j) < 0
          -4: NTYPES < 0
          -7: THRESH < 0
          -10: LDA < 1 o LDA < MMAX, donde MMAX es max( MM(j) ).
          -12: LDU < 1 o LDU < MMAX.
          -14: LDVT < 1 o LDVT < NMAX, donde NMAX es max( NN(j) ).
          -21: LWORK demasiado pequeño.
          Si ZLATMS o ZGESVD devuelven un código de error, se devuelve su
          valor absoluto.
