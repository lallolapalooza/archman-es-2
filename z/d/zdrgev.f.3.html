ZDRGEV

Propósito:

!>
!> ZDRGEV comprueba la subrutina principal del controlador del problema de valores
!> propios generalizados no simétricos ZGGEV.
!>
!> ZGGEV calcula para un par de matrices no simétricas n-por-n (A,B) los
!> valores propios generalizados y, opcionalmente, los vectores propios
!> izquierdos y derechos.
!>
!> Un valor propio generalizado para un par de matrices (A,B) es un escalar w
!> o una relación alpha/beta = w, tal que A - w*B es singular. Se representa
!> normalmente como el par (alpha,beta), ya que hay una interpretación razonable
!> para beta=0, e incluso para ambos siendo cero.
!>
!> Un vector propio generalizado derecho correspondiente a un valor propio
!> generalizado w para un par de matrices (A,B) es un vector r tal que
!> (A - wB) * r = 0. Un vector propio generalizado izquierdo es un vector l tal
!> que l**H * (A - wB) = 0, donde l**H es la transpuesta conjugada de l.
!>
!> Cuando se llama a ZDRGEV, se especifica un número de tamaños de matriz () y
!> un número de tipos de matriz. Para cada tamaño () y cada tipo de matriz,
!> se generará y utilizará un par de matrices (A, B) para las pruebas. Para cada
!> par de matrices, se realizarán las siguientes pruebas y se compararán con el
!> umbral THRESH.
!>
!> Resultados de ZGGEV:
!>
!> (1) max sobre todos los pares de valores propios/vectores propios izquierdos
!>     (alpha/beta,l) de
!>
!>      | VL**H * (beta A - alpha B) |/( ulp max(|beta A|, |alpha B|) )
!>
!>     donde VL**H es la transpuesta conjugada de VL.
!>
!> (2) | |VL(i)| - 1 | / ulp y si el componente más grande es real
!>
!>     VL(i) denota la i-ésima columna de VL.
!>
!> (3) max sobre todos los pares de valores propios/vectores propios izquierdos
!>     (alpha/beta,r) de
!>
!>      | (beta A - alpha B) * VR | / ( ulp max(|beta A|, |alpha B|) )
!>
!> (4) | |VR(i)| - 1 | / ulp y si el componente más grande es real
!>
!>     VR(i) denota la i-ésima columna de VR.
!>
!> (5) W(completo) = W(parcial)
!>     W(completo) denota los valores propios calculados cuando también se
!>     calculan l y r, y W(parcial) denota los valores propios
!>     calculados cuando solo se calculan W, solo W y r, o solo W y l.
!>
!> (6) VL(completo) = VL(parcial)
!>     VL(completo) denota los vectores propios izquierdos calculados cuando
!>     también se calculan l y r, y VL(parcial) denota el resultado
!>     cuando solo se calcula l.
!>
!> (7) VR(completo) = VR(parcial)
!>     VR(completo) denota los vectores propios derechos calculados cuando
!>     también se calculan l y r, y VR(parcial) denota el resultado
!>     cuando solo se calcula l.
!>
!>
!> Matrices de Prueba
!> ---- --------
!>
!> Los tamaños de las matrices de prueba se especifican mediante una matriz
!> NN(1:NSIZES); el valor de cada elemento NN(j) especifica un tamaño.
!> Los tipos se especifican mediante una matriz lógica DOTYPE( 1:NTYPES ); si
!> DOTYPE(j) es .TRUE., se generará el tipo de matriz.
!> Actualmente, la lista de tipos posibles es:
!>
!> (1) ( 0, 0 ) (un par de matrices cero)
!>
!> (2) ( I, 0 ) (una identidad y una matriz cero)
!>
!> (3) ( 0, I ) (una identidad y una matriz cero)
!>
!> (4) ( I, I ) (un par de matrices identidad)
!>
!>         t   t
!> (5) ( J , J  ) (un par de bloques de Jordan transpuestos)
!>
!>                                     t                ( I   0  )
!> (6) ( X, Y ) donde  X = ( J   0  )  y Y = (      t )
!>                                  ( 0   I  )          ( 0   J  )
!>                       y I es una identidad kxk y J un bloque de Jordan (k+1)x(k+1)
!>                       k=(N-1)/2
!>
!> (7) ( D, I ) donde D es diag( 0, 1,..., N-1 ) (una matriz diagonal
!>                       con esas entradas diagonales.)
!> (8) ( I, D )
!>
!> (9) ( big*D, small*I ) donde big está cerca del desbordamiento y small=1/big
!>
!> (10) ( small*D, big*I )
!>
!> (11) ( big*I, small*D )
!>
!> (12) ( small*I, big*D )
!>
!> (13) ( big*D, big*I )
!>
!> (14) ( small*D, small*I )
!>
!> (15) ( D1, D2 ) donde D1 es diag( 0, 0, 1, ..., N-3, 0 ) y
!>                        D2 es diag( 0, N-3, N-4,..., 1, 0, 0 )
!>           t   t
!> (16) Q ( J , J ) Z donde Q y Z son matrices ortogonales aleatorias.
!>
!> (17) Q ( T1, T2 ) Z donde T1 y T2 son matrices triangulares superiores
!>                        con entradas aleatorias O(1) por encima de la diagonal
!>                        y entradas diagonales diag(T1) =
!>                        ( 0, 0, 1, ..., N-3, 0 ) y diag(T2) =
!>                        ( 0, N-3, N-4,..., 1, 0, 0 )
!>
!> (18) Q ( T1, T2 ) Z donde diag(T1) = ( 0, 0, 1, 1, s, ..., s, 0 )
!>                        diag(T2) = ( 0, 1, 0, 1,..., 1, 0 )
!>                        s = precisión de la máquina.
!>
!> (19) Q ( T1, T2 ) Z donde diag(T1)=( 0,0,1,1, 1-d, ..., 1-(N-5)*d=s, 0 )
!>                        diag(T2) = ( 0, 1, 0, 1, ..., 1, 0 )
!>
!>                                                        N-5
!> (20) Q ( T1, T2 ) Z donde diag(T1)=( 0, 0, 1, 1, a, ..., a   =s, 0 )
!>                        diag(T2) = ( 0, 1, 0, 1, ..., 1, 0, 0 )
!>
!> (21) Q ( T1, T2 ) Z donde diag(T1)=( 0, 0, 1, r1, r2, ..., r(N-4), 0 )
!>                        diag(T2) = ( 0, 1, 0, 1, ..., 1, 0, 0 )
!>                        donde r1,..., r(N-4) son aleatorios.
!>
!> (22) Q ( big*T1, small*T2 ) Z donde diag(T1) = ( 0, 0, 1, ..., N-3, 0 )
!>                                  diag(T2) = ( 0, 1, ..., 1, 0, 0 )
!>
!> (23) Q ( small*T1, big*T2 ) Z donde diag(T1) = ( 0, 0, 1, ..., N-3, 0 )
!>                                  diag(T2) = ( 0, 1, ..., 1, 0, 0 )
!>
!> (24) Q ( small*T1, small*T2 ) Z  diag(T1) = ( 0, 0, 1, ..., N-3, 0 )
!>                                  diag(T2) = ( 0, 1, ..., 1, 0, 0 )
!>
!> (25) Q ( big*T1, big*T2 ) Z      diag(T1) = ( 0, 0, 1, ..., N-3, 0 )
!>                                  diag(T2) = ( 0, 1, ..., 1, 0, 0 )
!>
!> (26) Q ( T1, T2 ) Z donde T1 y T2 son matrices triangulares superiores
!>                         aleatorias.
!>
!>

zdrgev.f(3) — LAPACK Manual

NAME

zdrgev - driver routines for the generalized eigenvalue problem.

SYNOPSIS

SUBROUTINE ZDRGEV ( NTYPES, NSIZES, NN, DOTYPE, NDOF, NEXPECT,
                          THRESH, NOUNIT, A, LDA, B, LDB, S, LDT, Q, LDQ,
                          Z, LDZ, QE, LDQE, ALPHA, BETA, ALPHA1, BETA1,
                          WORK, LWORK, RWORK, RESULT, IERR )
    CHARACTER * 1 NTYPES, NSIZES
    INTEGER         NN, NDOF, NEXPECT, NOUNIT, LDA, LDB, LDT, LDQ, LDZ,
                    LDQE, LWORK, IERR
    LOGICAL         DOTYPE
    COMPLEX*16      A, B, S, Q, Z, QE, ALPHA, BETA, ALPHA1, BETA1, WORK
    DOUBLE PRECISION THRESH, RWORK, RESULT

Function/Subroutine Documentation

ZDRGEV is a driver routine that uses the following routines to test the double precision routines, ZGEES, ZGESDD, ZGELSD, ZGEQRF, ZGELSd, ZGEQRS, ZGELSd, ZGEQLF, ZGELSd, ZGEQLS, ZGESDD, ZGESv, ZGEsvv, ZGEsvA, ZGESVP, ZGESVj, ZGESVP, ZGECON, ZGELSD, ZGELSY, ZGEBAL, ZGEEV, ZGEGS, ZGEQP, ZGEQR, ZGELS, ZGELSx, ZGELsy, ZGELSZ, ZGELSS, ZGELSX, ZGEQPF, ZGEQR F, ZGEQRT, ZGEQRF, ZGEQRS, ZGESD, ZGESF, ZGESVx, ZGESVX, ZGESS, ZGESV, ZGESSV, ZGESSX, ZGESVj, ZGESVP, ZGESVV, ZGESSVv, ZGESSVx, ZGESSVP, ZGESVv, ZGESVX, ZGESVV, ZGESVx.

Specifically, ZDRGEV generates random matrices of a specified type and size and then calls the routines that solve the generalized eigenvalue problem and checks the error.

Arguments

NTYPES is CHARACTER*1 The number of matrix types to be tested.

NSIZES is CHARACTER*1 The number of matrix sizes to be tested.

NN is INTEGER array, dimension (NSIZES) The sizes of the matrices to be generated. NN(i) will be the dimension of the matrices to be generated by the i-th size. NN(i) must be non-negative.

DOTYPE is LOGICAL array, dimension (NTYPES) If DOTYPE(j) is .TRUE., then for each size in NN a matrix of that size and of type j will be generated. If NTYPES is smaller than the maximum number of types defined (PARAMETER MAXTYP), then types NTYPES+1 through MAXTYP will not be generated. If NTYPES is larger than MAXTYP, DOTYPE(MAXTYP+1) through DOTYPE(NTYPES) will be ignored.

NDOF is INTEGER The number of degrees of freedom in the problem.

NEXPECT is INTEGER The number of eigenvalues expected.

THRESH is DOUBLE PRECISION A test will count as failure if the relative error in the computed eigenvalues exceeds THRESH. This threshold is used for error reporting and does not affect the algorithm.

NOUNIT is INTEGER The FORTRAN unit number for printing out error messages (e.g., if a routine returns IERR not equal to 0.)

A is COMPLEX*16 array, dimension(LDA, max(NN)) Used to hold the matrix A.

LDA is INTEGER The leading dimension of A, B, S, and T. It must be at least max(1, max(NN)).

B is COMPLEX*16 array, dimension(LDB, max(NN)) Used to hold the matrix B.

LDB is INTEGER The leading dimension of B. It must be at least max(1, max(NN)).

S is COMPLEX*16 array, dimension(LDT, max(NN)) Used to hold the Schur form of A.

LDT is INTEGER The leading dimension of S and T. It must be at least max(1, max(NN)).

Q is COMPLEX*16 array, dimension(LDQ, max(NN)) Used to hold the orthogonal matrix Q.

LDQ is INTEGER The leading dimension of Q and Z. It must be at least max(1, max(NN)).

Z is COMPLEX*16 array, dimension(LDZ, max(NN)) Used to hold the orthogonal matrix Z.

LDZ is INTEGER The leading dimension of Z. It must be at least max(1, max(NN)).

QE is COMPLEX*16 array, dimension(LDQE, max(NN)) Used to hold the eigenvectors.

LDQE is INTEGER The leading dimension of QE. LDQE must be at least max(1, max(NN)).

ALPHA is COMPLEX*16 array, dimension (max(NN)) BETA is COMPLEX*16 array, dimension (max(NN)) On exit, ALPHA and BETA contain the generalized eigenvalues of (A,B). The i-th eigenvalue is ALPHA(i)/BETA(i).

ALPHA1 is COMPLEX*16 array, dimension (max(NN)) BETA1 is COMPLEX*16 array, dimension (max(NN)) On exit, ALPHA1 and BETA1 contain the generalized eigenvalues of (A,B) computed by routines that do not compute the full Schur form or eigenvectors.

WORK is COMPLEX*16 array, dimension (LWORK) Workspace array.

LWORK is INTEGER The dimension of WORK. LWORK must be at least max(1, N*(N+1)).

RWORK is DOUBLE PRECISION array, dimension (8*N) Real workspace.

RESULT is DOUBLE PRECISION array, dimension (2) The values computed by the tests described above.

IERR is INTEGER = 0: successful exit < 0: if IERR = -i, the i-th argument had an illegal value. > 0: A routine returned an error code. IERR is the absolute value of the INFO value returned.

NN (NN >= 0)

NTYPES 

NTYPES is INTEGER
        The number of elements in DOTYPE. If it is zero, ZDRGEV
        does nothing. It must be at least zero. If it is MAXTYP+1
        and NSIZES is 1, then an additional type, MAXTYP+1 is
        defined, which is to use whatever matrix is in A. This
        is only useful if DOTYPE(1:MAXTYP) is .FALSE. and
        DOTYPE(MAXTYP+1) is .TRUE. .

DOTYPE 

DOTYPE is LOGICAL array, dimension (NTYPES)
        If DOTYPE(j) is .TRUE., then for each size in NN a
        matrix of that size and of type j will be generated.
        If NTYPES is smaller than the maximum number of types
        defined (PARAMETER MAXTYP), then types NTYPES+1 through
        MAXTYP will not be generated. If NTYPES is larger
        than MAXTYP, DOTYPE(MAXTYP+1) through DOTYPE(NTYPES)
        will be ignored.

ISEED 

ISEED is INTEGER array, dimension (4)
        On entry ISEED specifies the seed of the random number
        generator. The array elements should be between 0 and 4095;
        if not they will be reduced mod 4096. Also, ISEED(4) must
        be odd. The random number generator uses a linear
        congruential sequence limited to small integers, and so
        should produce machine independent random numbers. The
        values of ISEED are changed on exit, and can be used in the
        next call to ZDRGES to continue the same random number
        sequence.

THRESH 

THRESH is DOUBLE PRECISION
        A test will count as if the , computed as
        described above, exceeds THRESH. Note that the error is
        scaled to be O(1), so THRESH should be a reasonably small
        multiple of 1, e.g., 10 or 100. In particular, it should
        not depend on the precision (single vs. double) or the size
        of the matrix. It must be at least zero.

NOUNIT 

NOUNIT is INTEGER
        The FORTRAN unit number for printing out error messages
        (e.g., if a routine returns IERR not equal to 0.)

A 

A is COMPLEX*16 array, dimension(LDA, max(NN))
        Used to hold the original A matrix. Used as input only
        if NTYPES=MAXTYP+1, DOTYPE(1:MAXTYP)=.FALSE., and
        DOTYPE(MAXTYP+1)=.TRUE.

LDA 

LDA is INTEGER
        The leading dimension of A, B, S, and T.
        It must be at least 1 and at least max( NN ).

B 

B is COMPLEX*16 array, dimension(LDA, max(NN))
        Used to hold the original B matrix. Used as input only
        if NTYPES=MAXTYP+1, DOTYPE(1:MAXTYP)=.FALSE., and
        DOTYPE(MAXTYP+1)=.TRUE.

S 

S is COMPLEX*16 array, dimension (LDA, max(NN))
        The Schur form matrix computed from A by ZGGEV. On exit, S
        contains the Schur form matrix corresponding to the matrix
        in A.

T 

T is COMPLEX*16 array, dimension (LDA, max(NN))
        The upper triangular matrix computed from B by ZGGEV.

Q 

Q is COMPLEX*16 array, dimension (LDQ, max(NN))
        The (left) eigenvectors matrix computed by ZGGEV.

LDQ 

LDQ is INTEGER
        The leading dimension of Q and Z. It must
        be at least 1 and at least max( NN ).

Z 

Z is COMPLEX*16 array, dimension( LDQ, max(NN) )
        The (right) orthogonal matrix computed by ZGGEV.

QE 

QE is COMPLEX*16 array, dimension( LDQ, max(NN) )
        QE holds the computed right or left eigenvectors.

LDQE 

LDQE is INTEGER
        The leading dimension of QE. LDQE >= max(1,max(NN)).

ALPHA 

ALPHA is COMPLEX*16 array, dimension (max(NN))

BETA 

BETA is COMPLEX*16 array, dimension (max(NN))

        The generalized eigenvalues of (A,B) computed by ZGGEV.
        ( ALPHAR(k)+ALPHAI(k)*i ) / BETA(k) is the k-th
        generalized eigenvalue of A and B.

ALPHA1 

ALPHA1 is COMPLEX*16 array, dimension (max(NN))

BETA1 

BETA1 is COMPLEX*16 array, dimension (max(NN))

        Like ALPHAR, ALPHAI, BETA, these arrays contain the
        eigenvalues of A and B, but those computed when ZGGEV only
        computes a partial eigendecomposition, i.e. not the
        eigenvalues and left and right eigenvectors.

WORK 

WORK is COMPLEX*16 array, dimension (LWORK)

LWORK 

LWORK is INTEGER
        The number of entries in WORK. LWORK >= N*(N+1)

RWORK 

RWORK is DOUBLE PRECISION array, dimension (8*N)
        Real workspace.

RESULT 

RESULT is DOUBLE PRECISION array, dimension (2)
        The values computed by the tests described above.
        The values are currently limited to 1/ulp, to avoid overflow.

INFO 

INFO is INTEGER
        = 0: successful exit
        < 0: if INFO = -i, the i-th argument had an illegal value.
        > 0: A routine returned an error code. INFO is the
        absolute value of the INFO value returned.
