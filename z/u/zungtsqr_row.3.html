ZUNGTSQR_ROW

DOCUMENTACIÓN DE FUNCIÓN/SUBRUTINA

subrutina zungtsqr_row (integer m, integer n, integer mb, integer nb, complex*16, dimension( lda, * ) a, integer lda, complex*16, dimension( ldt, * ) t, integer ldt, complex*16, dimension( * ) work, integer lwork, integer info)

ZUNGTSQR_ROW

Propósito:

!>
!> ZUNGTSQR_ROW genera una matriz compleja M por N, Q_out, con
!> columnas ortonormales a partir de la salida de ZLATSQR. Estas N columnas ortonormales
!> son las primeras N columnas de un producto de matrices unitarias complejas Q(k)_in
!> de orden M, que son devueltas por ZLATSQR en un formato especial.
!>
!>      Q_out = primeras_N_columnas_de( Q(1)_in * Q(2)_in * ... * Q(k)_in ).
!>
!> Las matrices de entrada Q(k)_in se almacenan en bloques de filas y columnas en A.
!> Consulte la documentación de ZLATSQR para obtener más detalles sobre el formato de
!> Q(k)_in, donde cada Q(k)_in está representada por transformaciones de Householder
!> en bloque. Esta subrutina llama a una subrutina auxiliar ZLARFB_GETT,
!> donde se realiza el cálculo en cada bloque individual. El
!> algoritmo barre primero bloques de columnas de tamaño NB de derecha a izquierda
!> comenzando en el bloque de fila inferior y continuando hasta el bloque de fila superior
!> (de ahí _ROW en el nombre de la subrutina). Este barrido está en orden inverso al
!> orden en que ZLATSQR genera los bloques de salida.
!>

Parámetros

M 
!>          M es ENTERO
!>          El número de filas de la matriz A.  M >= 0.
!>

N

!>          N es ENTERO
!>          El número de columnas de la matriz A. M >= N >= 0.
!>

MB

!>          MB es ENTERO
!>          El tamaño del bloque de fila utilizado por ZLATSQR para devolver
!>          los arrays A y T. MB > N.
!>          (Tenga en cuenta que si MB > M, entonces M se utiliza en lugar de MB
!>          como tamaño del bloque de fila).
!>

NB

!>          NB es ENTERO
!>          El tamaño del bloque de columna utilizado por ZLATSQR para devolver
!>          los arrays A y T. NB >= 1.
!>          (Tenga en cuenta que si NB > N, entonces N se utiliza en lugar de NB
!>          como tamaño del bloque de columna).
!>

A

!>          A es un array COMPLEX*16, dimensión (LDA,N)
!>
!>          En la entrada:
!>
!>             Los elementos en la diagonal y por encima de ella no se utilizan como
!>             entrada. Los elementos debajo de la diagonal representan la matriz
!>             trapezoidal inferior en bloque unitaria V calculada por ZLATSQR
!>             que define las matrices de entrada Q_in(k) (los unos en la
!>             diagonal no se almacenan). Consulte ZLATSQR para obtener más detalles.
!>
!>          En la salida:
!>
!>             El array A contiene una matriz ortonormal M por N, Q_out,
!>             es decir, las columnas de A son vectores unitarios ortogonales.
!>

LDA

!>          LDA es ENTERO
!>          La dimensión principal del array A.  LDA >= max(1,M).
!>

T

!>          T es un array COMPLEX*16,
!>          dimensión (LDT, N * NIRB)
!>          donde NIRB = Número_de_bloques_de_fila_de_entrada
!>                     = MAX( 1, CEIL((M-N)/(MB-N)) )
!>          Sea NICB = Número_de_bloques_de_columna_de_entrada
!>                   = CEIL(N/NB)
!>
!>          Los reflectores de bloque triangulares superiores utilizados para definir las
!>          matrices de entrada Q_in(k), k=(1:NIRB*NICB). Los bloques
!>          reflectores se almacenan en formato compacto en NIRB bloques
!>          de secuencias de reflectores. Cada una de las NIRB secuencias de
!>          reflectores de bloque se almacena en un bloque de columna NB por N más grande de T
!>          y consta de NICB bloques de columna más pequeños NB por NB triangulares superiores.
!>          Consulte ZLATSQR para obtener más detalles sobre el formato de T.
!>

LDT

!>          LDT es ENTERO
!>          La dimensión principal del array T.
!>          LDT >= max(1,min(NB,N)).
!>

WORK

!>          (espacio de trabajo) array COMPLEX*16, dimensión (MAX(1,LWORK))
!>          En la salida, si INFO = 0, WORK(1) devuelve el LWORK óptimo.
!>

LWORK

!>          LWORK es ENTERO
!>          La dimensión del array WORK.
!>          LWORK >= NBLOCAL * MAX(NBLOCAL,(N-NBLOCAL)),
!>          donde NBLOCAL=MIN(NB,N).
!>          Si LWORK = -1, se asume una consulta de espacio de trabajo.
!>          La subrutina solo calcula el tamaño óptimo del array WORK,
!>          devuelve este valor como la primera entrada del array WORK,
!>          y XERBLA no emite ningún mensaje de error relacionado con LWORK.
!>

INFO

!>          INFO es ENTERO
!>          = 0:  salida exitosa
!>          < 0:  si INFO = -i, el i-ésimo argumento tenía un valor ilegal
!>
