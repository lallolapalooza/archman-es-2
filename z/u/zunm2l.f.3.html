Documentación de función/subrutina

subrutina zunm2l (character side, character trans, integer m, integer n, integer k, complex*16, dimension( lda, * ) a, integer lda, complex*16, dimension( * ) tau, complex*16, dimension( ldc, * ) c, integer ldc, complex*16, dimension( * ) work, integer info)

ZUNM2L multiplica una matriz general por la matriz unitaria de una factorización QL determinada por cgeqlf (algoritmo sin bloques).

Propósito:

!>
!> ZUNM2L sobrescribe la matriz compleja general m por n C con
!>
!>       Q * C  si SIDE = 'L' y TRANS = 'N', o
!>
!>       Q**H* C  si SIDE = 'L' y TRANS = 'C', o
!>
!>       C * Q  si SIDE = 'R' y TRANS = 'N', o
!>
!>       C * Q**H si SIDE = 'R' y TRANS = 'C',
!>
!> donde Q es una matriz unitaria compleja definida como el producto de k
!>   reflectores elementales
!>
!>       Q = H(k) . . . H(2) H(1)
!>
!> tal como devuelve ZGEQLF. Q es de orden m si SIDE = 'L' y de orden n
!>   si SIDE = 'R'.
!>

Parámetros

SIDE 
!>          SIDE es CHARACTER*1
!>          = 'L': aplicar Q o Q**H desde la Izquierda
!>          = 'R': aplicar Q o Q**H desde la Derecha
!>

TRANS

!>          TRANS es CHARACTER*1
!>          = 'N': aplicar Q  (Sin transponer)
!>          = 'C': aplicar Q**H (Transpuesta conjugada)
!>

M

!>          M es INTEGER
!>          El número de filas de la matriz C. M >= 0.
!>

N

!>          N es INTEGER
!>          El número de columnas de la matriz C. N >= 0.
!>

K

!>          K es INTEGER
!>          El número de reflectores elementales cuyo producto define
!>          la matriz Q.
!>          Si SIDE = 'L', M >= K >= 0;
!>          si SIDE = 'R', N >= K >= 0.
!>

A

!>          A es un array COMPLEX*16, dimensión (LDA,K)
!>          La columna i debe contener el vector que define el
!>          reflector elemental H(i), para i = 1,2,...,k, tal como
!>          devuelve ZGEQLF en las últimas k columnas de su argumento
!>          de array A.
!>          A es modificado por la rutina pero restaurado a la salida.
!>

LDA

!>          LDA es INTEGER
!>          La dimensión principal del array A.
!>          Si SIDE = 'L', LDA >= max(1,M);
!>          si SIDE = 'R', LDA >= max(1,N).
!>

TAU

!>          TAU es un array COMPLEX*16, dimensión (K)
!>          TAU(i) debe contener el factor escalar del reflector
!>          elemental H(i), tal como devuelve ZGEQLF.
!>

C

!>          C es un array COMPLEX*16, dimensión (LDC,N)
!>          A la entrada, la matriz m por n C.
!>          A la salida, C es sobrescrito por Q*C o Q**H*C o C*Q**H o C*Q.
!>

LDC

!>          LDC es INTEGER
!>          La dimensión principal del array C. LDC >= max(1,M).
!>

WORK

!>          WORK es un array COMPLEX*16, dimensión
!>                                   (N) si SIDE = 'L',
!>                                   (M) si SIDE = 'R'
!>

INFO

!>          INFO es INTEGER
!>          = 0: salida exitosa
!>          < 0: si INFO = -i, el i-ésimo argumento tenía un valor ilegal
!>
