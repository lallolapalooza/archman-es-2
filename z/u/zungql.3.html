Documentación de función/subrutina

subrutina zungql (integer m, integer n, integer k, complex*16, dimension( lda, * ) a, integer lda, complex*16, dimension( * ) tau, complex*16, dimension( * ) work, integer lwork, integer info)

ZUNGQL

Propósito:

!>
!> ZUNGQL genera una matriz compleja M-por-N, Q, con columnas ortonormales,
!> que se define como las últimas N columnas de un producto de K reflectores
!> elementales de orden M
!>
!>       Q  =  H(k) . . . H(2) H(1)
!>
!> tal como devuelve ZGEQLF.
!>

Parámetros

M 
!>          M es ENTERO
!>          El número de filas de la matriz Q. M >= 0.
!>

N

!>          N es ENTERO
!>          El número de columnas de la matriz Q. M >= N >= 0.
!>

K

!>          K es ENTERO
!>          El número de reflectores elementales cuyo producto define la
!>          matriz Q. N >= K >= 0.
!>

A

!>          A es un array COMPLEX*16, de dimensión (LDA,N)
!>          En la entrada, la columna (n-k+i) debe contener el vector que
!>          define el reflector elemental H(i), para i = 1,2,...,k, tal
!>          como devuelve ZGEQLF en las últimas k columnas de su argumento
!>          de array A.
!>          En la salida, la matriz Q de M-por-N.
!>

LDA

!>          LDA es ENTERO
!>          La primera dimensión del array A. LDA >= max(1,M).
!>

TAU

!>          TAU es un array COMPLEX*16, de dimensión (K)
!>          TAU(i) debe contener el factor escalar del reflector elemental
!>          H(i), tal como devuelve ZGEQLF.
!>

WORK

!>          WORK es un array COMPLEX*16, de dimensión (MAX(1,LWORK))
!>          En la salida, si INFO = 0, WORK(1) devuelve el LWORK óptimo.
!>

LWORK

!>          LWORK es ENTERO
!>          La dimensión del array WORK. LWORK >= max(1,N).
!>          Para un rendimiento óptimo LWORK >= N*NB, donde NB es
!>          el tamaño de bloque óptimo.
!>
!>          Si LWORK = -1, se asume una consulta de espacio de trabajo; la rutina
!>          solo calcula el tamaño óptimo del array WORK, devuelve
!>          este valor como la primera entrada del array WORK, y XERBLA no
!>          emite ningún mensaje de error relacionado con LWORK.
!>

INFO

!>          INFO es ENTERO
!>          = 0:  salida exitosa
!>          < 0:  si INFO = -i, el i-ésimo argumento tiene un valor ilegal
!>
