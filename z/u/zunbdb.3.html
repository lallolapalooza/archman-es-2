subroutine zunbdb (character trans, character signs, integer m, integer p, integer q, complex*16, dimension( ldx11, * ) x11, integer ldx11, complex*16, dimension( ldx12, * ) x12, integer ldx12, complex*16, dimension( ldx21, * ) x21, integer ldx21, complex*16, dimension( ldx22, * ) x22, integer ldx22, double precision, dimension( * ) theta, double precision, dimension( * ) phi, complex*16, dimension( * ) taup1, complex*16, dimension( * ) taup2, complex*16, dimension( * ) tauq1, complex*16, dimension( * ) tauq2, complex*16, dimension( * ) work, integer lwork, integer info)

ZUNBDB

Propósito:

!>
!> ZUNBDB bidiagonaliza simultáneamente los bloques de una matriz unitaria M-por-M
!> particionada X:
!>
!>                                 [ B11 | B12 0  0 ]
!>     [ X11 | X12 ]   [ P1 |    ] [  0  |  0 -I  0 ] [ Q1 |    ]**H
!> X = [-----------] = [---------] [----------------] [---------]   .
!>     [ X21 | X22 ]   [    | P2 ] [ B21 | B22 0  0 ] [    | Q2 ]
!>                                 [  0  |  0  0  I ]
!>
!> X11 es P-por-Q. Q no debe ser mayor que P, M-P, o M-Q. (Si este no es
!> el caso, entonces X debe ser transpuesta y/o permutada. Esto se puede
!> hacer en tiempo constante usando las opciones TRANS y SIGNS. Ver ZUNCSD
!> para detalles.)
!>
!> Las matrices unitarias P1, P2, Q1 y Q2 son P-por-P, (M-P)-por-
!> (M-P), Q-por-Q y (M-Q)-por-(M-Q), respectivamente. Están
!> representadas implícitamente por vectores de Householder.
!>
!> B11, B12, B21 y B22 son matrices bidiagonales Q-por-Q representadas
!> implícitamente por los ángulos THETA y PHI.
!>

Parámetros

TRANS 
!>          TRANS es CHARACTER
!>          = 'T':      X, U1, U2, V1T y V2T se almacenan en orden de fila;
!>          de lo contrario: X, U1, U2, V1T y V2T se almacenan en orden de columna.
!>

SIGNS

!>          SIGNS es CHARACTER
!>          = 'O':      El bloque inferior izquierdo se hace no positivo (la
!>                       convención);
!>          de lo contrario: El bloque superior derecho se hace no positivo (la
!>                       convención).
!>

M

!>          M es INTEGER
!>          El número de filas y columnas en X.
!>

P

!>          P es INTEGER
!>          El número de filas en X11 y X12. 0 <= P <= M.
!>

Q

!>          Q es INTEGER
!>          El número de columnas en X11 y X21. 0 <= Q <=
!>          MIN(P,M-P,M-Q).
!>

X11

!>          X11 es COMPLEX*16 array, dimension (LDX11,Q)
!>          En la entrada, el bloque superior izquierdo de la matriz unitaria a
!>          reducir. En la salida, la forma depende de TRANS:
!>          Si TRANS = 'N', entonces
!>             las columnas de tril(X11) especifican los reflectores para P1,
!>             las filas de triu(X11,1) especifican los reflectores para Q1;
!>          de lo contrario TRANS = 'T', y
!>             las filas de triu(X11) especifican los reflectores para P1,
!>             las columnas de tril(X11,-1) especifican los reflectores para Q1.
!>

LDX11

!>          LDX11 es INTEGER
!>          La dimensión principal de X11. Si TRANS = 'N', entonces LDX11 >=
!>          P; de lo contrario LDX11 >= Q.
!>

X12

!>          X12 es COMPLEX*16 array, dimension (LDX12,M-Q)
!>          En la entrada, el bloque superior derecho de la matriz unitaria a
!>          reducir. En la salida, la forma depende de TRANS:
!>          Si TRANS = 'N', entonces
!>             las filas de triu(X12) especifican los primeros P reflectores para
!>             Q2;
!>          de lo contrario TRANS = 'T', y
!>             las columnas de tril(X12) especifican los primeros P reflectores
!>             para Q2.
!>

LDX12

!>          LDX12 es INTEGER
!>          La dimensión principal de X12. Si TRANS = 'N', entonces LDX12 >=
!>          P; de lo contrario LDX11 >= M-Q.
!>

X21

!>          X21 es COMPLEX*16 array, dimension (LDX21,Q)
!>          En la entrada, el bloque inferior izquierdo de la matriz unitaria a
!>          reducir. En la salida, la forma depende de TRANS:
!>          Si TRANS = 'N', entonces
!>             las columnas de tril(X21) especifican los reflectores para P2;
!>          de lo contrario TRANS = 'T', y
!>             las filas de triu(X21) especifican los reflectores para P2.
!>

LDX21

!>          LDX21 es INTEGER
!>          La dimensión principal de X21. Si TRANS = 'N', entonces LDX21 >=
!>          M-P; de lo contrario LDX21 >= Q.
!>

X22

!>          X22 es COMPLEX*16 array, dimension (LDX22,M-Q)
!>          En la entrada, el bloque inferior derecho de la matriz unitaria a
!>          reducir. En la salida, la forma depende de TRANS:
!>          Si TRANS = 'N', entonces
!>             las filas de triu(X22(Q+1:M-P,P+1:M-Q)) especifican los últimos
!>             M-P-Q reflectores para Q2,
!>          de lo contrario TRANS = 'T', y
!>             las columnas de tril(X22(P+1:M-Q,Q+1:M-P)) especifican los últimos
!>             M-P-Q reflectores para P2.
!>

LDX22

!>          LDX22 es INTEGER
!>          La dimensión principal de X22. Si TRANS = 'N', entonces LDX22 >=
!>          M-P; de lo contrario LDX22 >= M-Q.
!>

THETA

!>          THETA es DOUBLE PRECISION array, dimension (Q)
!>          Las entradas de los bloques bidiagonales B11, B12, B21, B22 se pueden
!>          calcular a partir de los ángulos THETA y PHI. Ver Detalles Adicionales.
!>

PHI

!>          PHI es DOUBLE PRECISION array, dimension (Q-1)
!>          Las entradas de los bloques bidiagonales B11, B12, B21, B22 se pueden
!>          calcular a partir de los ángulos THETA y PHI. Ver Detalles Adicionales.
!>

TAUP1

!>          TAUP1 es COMPLEX*16 array, dimension (P)
!>          Los factores escalares de los reflectores elementales que definen
!>          P1.
!>

TAUP2

!>          TAUP2 es COMPLEX*16 array, dimension (M-P)
!>          Los factores escalares de los reflectores elementales que definen
!>          P2.
!>

TAUQ1

!>          TAUQ1 es COMPLEX*16 array, dimension (Q)
!>          Los factores escalares de los reflectores elementales que definen
!>          Q1.
!>

TAUQ2

!>          TAUQ2 es COMPLEX*16 array, dimension (M-Q)
!>          Los factores escalares de los reflectores elementales que definen
!>          Q2.
!>

WORK

!>          WORK es COMPLEX*16 array, dimension (LWORK)
!>

LWORK

!>          LWORK es INTEGER
!>          La dimensión del array WORK. LWORK >= M-Q.
!>
!>          Si LWORK = -1, entonces se asume una consulta de espacio de trabajo; la rutina
!>          solo calcula el tamaño óptimo del array WORK, devuelve
!>          este valor como la primera entrada del array WORK y no se emite ningún
!>          mensaje de error relacionado con LWORK por XERBLA.
!>

INFO

!>          INFO es INTEGER
!>          = 0:  salida exitosa.
!>          < 0:  si INFO = -i, el i-ésimo argumento tenía un valor ilegal.
!>

Detalles Adicionales

Los bloques bidiagonales B11, B12, B21, B22 se pueden construir a partir de los ángulos THETA y PHI. Sea:

      C1(I) = COS(THETA(I)), S1(I) = SIN(THETA(I))
      C2(I) = COS(PHI(I)), S2(I) = SIN(PHI(I))

B11(I,I) = C1(I)*C2(I), B11(I,I+1) = C1(I)*S2(I)

B12(I,I) = S1(I)*C2(I), B12(I,I+1) = S1(I)*S2(I)

B21(I,I) = -S1(I)*C2(I), B21(I,I+1) = -S1(I)*S2(I)

B22(I,I) = S1(I)*C2(I), B22(I,I+1) = S1(I)*S2(I)

Los índices I van de 1 a Q. Si PHI está vacío (Q=1), entonces S2(I) y C2(I) se toman como 1.

Note que el bloque inferior derecho B22 está relacionado con B11.

Detalles Adicionales:

!>
!> Los bloques bidiagonales B11, B12, B21 y B22 se representan
!> implícitamente por los ángulos THETA(1), ..., THETA(Q) y PHI(1), ...,
!> PHI(Q-1). B11 y B21 son bidiagonales superiores, mientras que B21 y B22 son
!> bidiagonales inferiores. Cada entrada en cada banda bidiagonal es un producto
!> de un seno o coseno de un THETA con un seno o coseno de un PHI. Ver
!> [1] o ZUNCSD para más detalles.
!>
!> P1, P2, Q1 y Q2 se representan como productos de reflectores elementales.
!> Ver ZUNCSD para detalles sobre la generación de P1, P2, Q1 y Q2
!> usando ZUNGQR y ZUNGLQ.
!>
