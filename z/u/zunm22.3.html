Documentación de Función/Subrutina

subrutina zunm22 (character side, character trans, integer m, integer n, integer n1, integer n2, complex*16, dimension( ldq, * ) q, integer ldq, complex*16, dimension( ldc, * ) c, integer ldc, complex*16, dimension( * ) work, integer lwork, integer info)

ZUNM22 multiplica una matriz general por una matriz unitaria banda.

Propósito

!>
!>  ZUNM22 sobrescribe la matriz compleja general M-por-N C con
!>
!>                  SIDE = 'L'     SIDE = 'R'
!>  TRANS = 'N':      Q * C          C * Q
!>  TRANS = 'C':      Q**H * C       C * Q**H
!>
!>  donde Q es una matriz unitaria compleja de orden NQ, con NQ = M si
!>  SIDE = 'L' y NQ = N si SIDE = 'R'.
!>  La matriz unitaria Q procesa una estructura de bloques de 2x2
!>
!>         [  Q11  Q12  ]
!>     Q = [            ]
!>         [  Q21  Q22  ],
!>
!>  donde Q12 es una matriz triangular inferior de N1-por-N1 y Q21 es una
!>  matriz triangular superior de N2-por-N2.
!>

Parámetros

SIDE 
!>          SIDE es CHARACTER*1
!>          = 'L': aplicar Q o Q**H desde la Izquierda;
!>          = 'R': aplicar Q o Q**H desde la Derecha.
!>

TRANS

!>          TRANS es CHARACTER*1
!>          = 'N':  aplicar Q (Sin transponer);
!>          = 'C':  aplicar Q**H (Transpuesta conjugada).
!>

M

!>          M es INTEGER
!>          El número de filas de la matriz C. M >= 0.
!>

N

!>          N es INTEGER
!>          El número de columnas de la matriz C. N >= 0.
!>

N1
N2

!>          N1 es INTEGER
!>          N2 es INTEGER
!>          La dimensión de Q12 y Q21, respectivamente. N1, N2 >= 0.
!>          La siguiente condición debe cumplirse:
!>          N1 + N2 = M si SIDE = 'L' y N1 + N2 = N si SIDE = 'R'.
!>

Q

!>          Q es array de COMPLEX*16, dimensión
!>                              (LDQ,M) si SIDE = 'L'
!>                              (LDQ,N) si SIDE = 'R'
!>

LDQ

!>          LDQ es INTEGER
!>          La dimensión principal del array Q.
!>          LDQ >= max(1,M) si SIDE = 'L'; LDQ >= max(1,N) si SIDE = 'R'.
!>

C

!>          C es array de COMPLEX*16, dimensión (LDC,N)
!>          En la entrada, la matriz C de M-por-N.
!>          En la salida, C se sobrescribe con Q*C o Q**H*C o C*Q**H o C*Q.
!>

LDC

!>          LDC es INTEGER
!>          La dimensión principal del array C. LDC >= max(1,M).
!>

WORK

!>          WORK es array de COMPLEX*16, dimensión (MAX(1,LWORK))
!>          En la salida, si INFO = 0, WORK(1) devuelve el LWORK óptimo.
!>

LWORK

!>          LWORK es INTEGER
!>          La dimensión del array WORK.
!>          Si SIDE = 'L', LWORK >= max(1,N);
!>          si SIDE = 'R', LWORK >= max(1,M).
!>          Para un rendimiento óptimo LWORK >= M*N.
!>
!>          Si LWORK = -1, entonces se asume una consulta de espacio de
!>          trabajo; la rutina solo calcula el tamaño óptimo del array
!>          WORK, devuelve este valor como la primera entrada del array
!>          WORK, y XERBLA no emite ningún mensaje de error relacionado con
!>          LWORK.
!>

INFO

!>          INFO es INTEGER
!>          = 0:  salida exitosa
!>          < 0:  si INFO = -i, el i-ésimo argumento tenía un valor ilegal
!>
