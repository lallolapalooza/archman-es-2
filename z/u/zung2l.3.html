Documentación de función/subrutina

subrutina zung2l (integer m, integer n, integer k, complex*16, dimension( lda, * ) a, integer lda, complex*16, dimension( * ) tau, complex*16, dimension( * ) work, integer info)

ZUNG2L genera toda o parte de la matriz unitaria Q de una factorización QL determinada por cgeqlf (algoritmo sin bloques).

Propósito:

!>
!> ZUNG2L genera una matriz compleja m por n, Q, con columnas ortonormales,
!> que se define como las últimas n columnas de un producto de k
!> reflectores elementales de orden m
!>
!>       Q  =  H(k) . . . H(2) H(1)
!>
!> según lo devuelto por ZGEQLF.
!>

Parámetros

M 
!>          M es INTEGER
!>          El número de filas de la matriz Q. M >= 0.
!>

N

!>          N es INTEGER
!>          El número de columnas de la matriz Q. M >= N >= 0.
!>

K

!>          K es INTEGER
!>          El número de reflectores elementales cuyo producto define la
!>          matriz Q. N >= K >= 0.
!>

A

!>          A es array COMPLEX*16, de dimensión (LDA,N)
!>          En la entrada, la columna (n-k+i) debe contener el vector que
!>          define el reflector elemental H(i), para i = 1,2,...,k, tal
!>          como lo devuelve ZGEQLF en las últimas k columnas de su argumento
!>          de array A.
!>          En la salida, la matriz Q de m por n.
!>

LDA

!>          LDA es INTEGER
!>          La primera dimensión del array A. LDA >= max(1,M).
!>

TAU

!>          TAU es array COMPLEX*16, de dimensión (K)
!>          TAU(i) debe contener el factor escalar del reflector
!>          elemental H(i), tal como lo devuelve ZGEQLF.
!>

WORK

!>          WORK es array COMPLEX*16, de dimensión (N)
!>

INFO

!>          INFO es INTEGER
!>          = 0: salida exitosa
!>          < 0: si INFO = -i, el argumento i tiene un valor ilegal
!>
