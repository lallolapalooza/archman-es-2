ZUNCSD

Propósito:

!>
!> ZUNCSD calcula la descomposición CS de una matriz unitaria particionada X de M-por-M:
!>
!>                                 [  I  0  0 |  0  0  0 ]
!>                                 [  0  C  0 |  0 -S  0 ]
!>     [ X11 | X12 ]   [ U1 |    ] [  0  0  0 |  0  0 -I ] [ V1 |    ]**H
!> X = [-----------] = [---------] [---------------------] [---------]   .
!>     [ X21 | X22 ]   [    | U2 ] [  0  0  0 |  I  0  0 ] [    | V2 ]
!>                                 [  0  S  0 |  0  C  0 ]
!>                                 [  0  0  I |  0  0  0 ]
!>
!> X11 es P-por-Q. Las matrices unitarias U1, U2, V1 y V2 son P-por-P,
!> (M-P)-por-(M-P), Q-por-Q y (M-Q)-por-(M-Q), respectivamente. C y S son
!> matrices diagonales no negativas R-por-R que satisfacen C^2 + S^2 = I,
!> donde R = MIN(P,M-P,Q,M-Q).
!>

Parámetros

JOBU1 
!>          JOBU1 es CHARACTER
!>          = 'Y':      se calcula U1;
!>          de lo contrario:  no se calcula U1.
!>

JOBU2

!>          JOBU2 es CHARACTER
!>          = 'Y':      se calcula U2;
!>          de lo contrario:  no se calcula U2.
!>

JOBV1T

!>          JOBV1T es CHARACTER
!>          = 'Y':      se calcula V1T;
!>          de lo contrario:  no se calcula V1T.
!>

JOBV2T

!>          JOBV2T es CHARACTER
!>          = 'Y':      se calcula V2T;
!>          de lo contrario:  no se calcula V2T.
!>

TRANS

!>          TRANS es CHARACTER
!>          = 'T':      X, U1, U2, V1T y V2T se almacenan en orden de fila principal;
!>          de lo contrario:  X, U1, U2, V1T y V2T se almacenan en orden de columna principal.
!>

SIGNS

!>          SIGNS es CHARACTER
!>          = 'O':      el bloque inferior izquierdo se hace no positivo (la
!>                       convención);
!>          de lo contrario:  el bloque superior derecho se hace no positivo (la
!>                       convención).
!>

M

!>          M es INTEGER
!>          El número de filas y columnas en X.
!>

P

!>          P es INTEGER
!>          El número de filas en X11 y X12. 0 <= P <= M.
!>

Q

!>          Q es INTEGER
!>          El número de columnas en X11 y X21. 0 <= Q <= M.
!>

X11

!>          X11 es un array COMPLEX*16, dimensión (LDX11,Q)
!>          En la entrada, parte de la matriz unitaria cuya CSD se desea.
!>

LDX11

!>          LDX11 es INTEGER
!>          La dimensión principal de X11. LDX11 >= MAX(1,P).
!>

X12

!>          X12 es un array COMPLEX*16, dimensión (LDX12,M-Q)
!>          En la entrada, parte de la matriz unitaria cuya CSD se desea.
!>

LDX12

!>          LDX12 es INTEGER
!>          La dimensión principal de X12. LDX12 >= MAX(1,P).
!>

X21

!>          X21 es un array COMPLEX*16, dimensión (LDX21,Q)
!>          En la entrada, parte de la matriz unitaria cuya CSD se desea.
!>

LDX21

!>          LDX21 es INTEGER
!>          La dimensión principal de X11. LDX21 >= MAX(1,M-P).
!>

X22

!>          X22 es un array COMPLEX*16, dimensión (LDX22,M-Q)
!>          En la entrada, parte de la matriz unitaria cuya CSD se desea.
!>

LDX22

!>          LDX22 es INTEGER
!>          La dimensión principal de X11. LDX22 >= MAX(1,M-P).
!>

THETA

!>          THETA es un array DOUBLE PRECISION, dimensión (R), donde R =
!>          MIN(P,M-P,Q,M-Q).
!>          C = DIAG( COS(THETA(1)), ... , COS(THETA(R)) ) y
!>          S = DIAG( SIN(THETA(1)), ... , SIN(THETA(R)) ).
!>

U1

!>          U1 es un array COMPLEX*16, dimensión (LDU1,P)
!>          Si JOBU1 = 'Y', U1 contiene la matriz unitaria P-por-P U1.
!>

LDU1

!>          LDU1 es INTEGER
!>          La dimensión principal de U1. Si JOBU1 = 'Y', LDU1 >=
!>          MAX(1,P).
!>

U2

!>          U2 es un array COMPLEX*16, dimensión (LDU2,M-P)
!>          Si JOBU2 = 'Y', U2 contiene la matriz unitaria (M-P)-por-(M-P)
!>          U2.
!>

LDU2

!>          LDU2 es INTEGER
!>          La dimensión principal de U2. Si JOBU2 = 'Y', LDU2 >=
!>          MAX(1,M-P).
!>

V1T

!>          V1T es un array COMPLEX*16, dimensión (LDV1T,Q)
!>          Si JOBV1T = 'Y', V1T contiene la matriz unitaria Q-por-Q
!>          V1**H.
!>

LDV1T

!>          LDV1T es INTEGER
!>          La dimensión principal de V1T. Si JOBV1T = 'Y', LDV1T >=
!>          MAX(1,Q).
!>

V2T

!>          V2T es un array COMPLEX*16, dimensión (LDV2T,M-Q)
!>          Si JOBV2T = 'Y', V2T contiene la matriz unitaria (M-Q)-por-(M-Q)
!>          V2**H.
!>

LDV2T

!>          LDV2T es INTEGER
!>          La dimensión principal de V2T. Si JOBV2T = 'Y', LDV2T >=
!>          MAX(1,M-Q).
!>

WORK

!>          WORK es un array COMPLEX*16, dimensión (MAX(1,LWORK))
!>          En la salida, si INFO = 0, WORK(1) devuelve el LWORK óptimo.
!>

LWORK

!>          LWORK es INTEGER
!>          La dimensión del array WORK.
!>
!>          Si LWORK = -1, entonces se asume una consulta de espacio de trabajo; la rutina
!>          solo calcula el tamaño óptimo del array WORK, devuelve
!>          este valor como la primera entrada del array WORK, y ninguna
!>          mensaje de error relacionado con LWORK es emitido por XERBLA.
!>

RWORK

!>          RWORK es un array DOUBLE PRECISION

LRWORK

!>          LRWORK es INTEGER
!>          La dimensión del array RWORK.
!>
!>          Si LRWORK = -1, entonces se asume una consulta de espacio de trabajo; la rutina
!>          solo calcula el tamaño óptimo del array RWORK, devuelve
!>          este valor como la primera entrada del array RWORK, y ninguna
!>          mensaje de error relacionado con LRWORK es emitido por XERBLA.
!>

IWORK

!>          IWORK es un array INTEGER
!>          Tamaño del array IWORK: MAX(1, M).
!>

INFO

!>          INFO es INTEGER
!>          = 0: éxito.
!>          < 0: si el k-ésimo argumento (debidamente indexado) tenía un valor ilegal.
!>               Específicamente, si el argumento i es un número de índice,
!>               entonces INFO = -i.
!>
