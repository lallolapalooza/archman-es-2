Documentación de la función/subrutina

subroutine zunhr_col (integer m, integer n, integer nb, complex*16, dimension( lda, * ) a, integer lda, complex*16, dimension( ldt, * ) t, integer ldt, complex*16, dimension( * ) d, integer info)

ZUNHR_COL

Propósito:

!>
!>  ZUNHR_COL toma una matriz compleja M-por-N Q_in con columnas ortonormales
!>  como entrada, almacenada en A, y realiza la Reconstrucción de Householder (HR),
!>  es decir, reconstruye vectores de Householder V(i) que representan implícitamente
!>  otra matriz M-por-N Q_out, con la propiedad de que Q_in = Q_out*S,
!>  donde S es una matriz diagonal N-por-N con entradas diagonales
!>  igual a +1 o -1. Los vectores de Householder (columnas V(i) de V) se
!>  almacenan en A a la salida, y las entradas diagonales de S se almacenan en D.
!>  Los reflectores de bloque también se devuelven en T
!>  (mismo formato de salida que ZGEQRT).
!>

Parámetros

M 
!>          M es INTEGER
!>          El número de filas de la matriz A. M >= 0.
!>

N

!>          N es INTEGER
!>          El número de columnas de la matriz A. M >= N >= 0.
!>

NB

!>          NB es INTEGER
!>          El tamaño del bloque de columnas a utilizar en la reconstrucción
!>          de bloques de vectores de columna de Householder en el array A y
!>          los reflectores de bloque correspondientes en el array T. NB >= 1.
!>          (Tenga en cuenta que si NB > N, entonces N se usa en lugar de NB
!>          como tamaño del bloque de columnas.)
!>

A

!>          A es un array COMPLEX*16, dimensión (LDA,N)
!>
!>          En la entrada:
!>
!>             El array A contiene una matriz ortonormal M-por-N Q_in,
!>             es decir, las columnas de A son vectores unitarios ortogonales.
!>
!>          En la salida:
!>
!>             Los elementos debajo de la diagonal de A representan la matriz
!>             inferior-trapezoidal unitaria V de vectores de columna de Householder
!>             V(i). Las entradas unitarias diagonales de V no se almacenan
!>             (mismo formato que la salida debajo de la diagonal en A de
!>             ZGEQRT). La matriz T y la matriz V almacenadas en la salida
!>             en A definen implícitamente Q_out.
!>
!>             Los elementos por encima de la diagonal contienen el factor U
!>             de la descomposición LU:
!>                Q_in - ( S ) = V * U
!>                       ( 0 )
!>             donde 0 es una matriz cero (M-N)-por-(M-N).
!>

LDA

!>          LDA es INTEGER
!>          La dimensión principal del array A. LDA >= max(1,M).
!>

T

!>          T es un array COMPLEX*16,
!>          dimensión (LDT, N)
!>
!>          Sea NOCB = Número_de_bloques_de_columnas_de_salida
!>                   = CEIL(N/NB)
!>
!>          En la salida, T(1:NB, 1:N) contiene NOCB reflectores de bloque
!>          triangulares superiores utilizados para definir Q_out almacenados en formato
!>          compacto como una secuencia de bloques de columnas de NB-por-NB
!>          triangulares superiores (mismo formato que la salida T en ZGEQRT).
!>          La matriz T y la matriz V almacenadas en la salida en A
!>          definen implícitamente Q_out. NOTA: Los triángulos inferiores
!>          debajo de los bloques triangulares superiores se rellenarán con
!>          ceros. Ver Detalles Adicionales.
!>

LDT

!>          LDT es INTEGER
!>          La dimensión principal del array T.
!>          LDT >= max(1,min(NB,N)).
!>

D

!>          D es un array COMPLEX*16, dimensión min(M,N).
!>          Los elementos solo pueden ser más o menos uno.
!>
!>          D(i) se construye como D(i) = -SIGN(Q_in_i(i,i)), donde
!>          1 <= i <= min(M,N), y Q_in_i es Q_in después de realizar
!>          i-1 pasos de eliminación gaussiana "modificada".
!>          Ver Detalles Adicionales.
!>

INFO

!>          INFO es INTEGER
!>          = 0:  salida exitosa
!>          < 0:  si INFO = -i, el i-ésimo argumento tenía un valor ilegal
!>

Detalles Adicionales:

!>
!> El factor unitario M-por-M calculado Q_out se define implícitamente como
!> un producto de matrices unitarias Q_out(i). Cada Q_out(i) se almacena en
!> el formato de representación WY compacto en los bloques correspondientes de
!> las matrices V (almacenada en A) y T.
!>
!> La matriz inferior-trapezoidal unitaria M-por-N V almacenada en la
!> matriz M-por-N A contiene los vectores de columna V(i) en bloques de
!> columna de tamaño NB, VB(j). Por ejemplo, VB(1) contiene las columnas
!> V(1), V(2), ... V(NB). NOTA: Las entradas unitarias en
!> la diagonal de Y no se almacenan en A.
!>
!> El número de bloques de columna es
!>
!>     NOCB = Número_de_bloques_de_columnas_de_salida = CEIL(N/NB)
!>
!> donde cada bloque es de orden NB excepto el último bloque, que
!> es de orden LAST_NB = N - (NOCB-1)*NB.
!>
!> Por ejemplo, si M=6, N=5 y NB=2, la matriz V es
!>
!>
!>     V = (    VB(1),   VB(2), VB(3) ) =
!>
!>       = (    1                      )
!>         ( v21    1                 )
!>         ( v31  v32    1            )
!>         ( v41  v42  v43   1        )
!>         ( v51  v52  v53  v54    1  )
!>         ( v61  v62  v63  v54   v65 )
!>
!>
!> Para cada uno de los bloques de columna VB(i), se calcula un reflector de bloque
!> triangular superior TB(i). Estos bloques se almacenan como
!> una secuencia de bloques de columna triangulares superiores en la
!> matriz T de NB-por-N. El tamaño de cada bloque TB(i) es NB-por-NB, excepto
!> para el último bloque, cuyo tamaño es LAST_NB-por-LAST_NB.
!>
!> Por ejemplo, si M=6, N=5 y NB=2, la matriz T es
!>
!>     T  = (    TB(1),    TB(2), TB(3) ) =
!>
!>        = ( t11  t12  t13  t14   t15  )
!>          (      t22       t24        )
!>
!>
!> El factor M-por-M Q_out se da como un producto de NOCB
!> matrices M-por-M unitarias Q_out(i).
!>
!>     Q_out = Q_out(1) * Q_out(2) * ... * Q_out(NOCB),
!>
!> donde cada matriz Q_out(i) se da mediante la representación WY
!> utilizando bloques correspondientes de las matrices V y T:
!>
!>     Q_out(i) = I - VB(i) * TB(i) * (VB(i))**T,
!>
!> donde I es la matriz identidad. Aquí está la fórmula con las
!> dimensiones de la matriz:
!>
!>  Q(i){M-por-M} = I{M-por-M} -
!>    VB(i){M-por-INB} * TB(i){INB-por-INB} * (VB(i))**T {INB-por-M},
!>
!> donde INB = NB, excepto para el último bloque NOCB
!> para el cual INB=LAST_NB.
!>
!> =====
!> NOTA:
!> =====
!>
!> Si Q_in es el resultado de hacer una factorización QR
!> B = Q_in * R_in, entonces:
!>
!> B = (Q_out*S) * R_in = Q_out * (S * R_in) = Q_out * R_out.
!>
!> Por lo tanto, si se quiere interpretar Q_out como el resultado
!> de la factorización QR de B, entonces el R_out correspondiente
!> debe ser igual a R_out = S * R_in, es decir, algunas filas de R_in
!> deben multiplicarse por -1.
!>
!> Para los detalles del algoritmo, ver [1].
!>
!> [1] ,
!>     G. Ballard, J. Demmel, L. Grigori, M. Jacquelin, H.D. Nguyen,
!>     E. Solomonik, J. Parallel Distrib. Comput.,
!>     vol. 85, pp. 3-31, 2015.
!>
