Documentación de Función/Subrutina

subrutina zunbdb3 (integer m, integer p, integer q, complex*16, dimension(ldx11,*) x11, integer ldx11, complex*16, dimension(ldx21,*) x21, integer ldx21, double precision, dimension(*) theta, double precision, dimension(*) phi, complex*16, dimension(*) taup1, complex*16, dimension(*) taup2, complex*16, dimension(*) tauq1, complex*16, dimension(*) work, integer lwork, integer info)

ZUNBDB3

Propósito:

!>
!> ZUNBDB3 bidiagonaliza simultáneamente los bloques de una matriz X alta y delgada
!> con columnas ortonormales:
!>
!>                            [ B11 ]
!>      [ X11 ]   [ P1 |    ] [  0  ]
!>      [-----] = [---------] [-----] Q1**T .
!>      [ X21 ]   [    | P2 ] [ B21 ]
!>                            [  0  ]
!>
!> X11 es P-por-Q, y X21 es (M-P)-por-Q. M-P debe ser no mayor que P,
!> Q o M-Q. Las rutinas ZUNBDB1, ZUNBDB2 y ZUNBDB4 manejan casos en
!> los que M-P no es la dimensión mínima.
!>
!> Las matrices unitarias P1, P2 y Q1 son P-por-P, (M-P)-por-(M-P)
!> y (M-Q)-por-(M-Q), respectivamente. Se representan implícitamente por
!> vectores de Householder.
!>
!> B11 y B12 son matrices bidiagonales (M-P)-por-(M-P) representadas
!> implícitamente por los ángulos THETA, PHI.
!>
!>

Parámetros

M 
!>          M es ENTERO
!>           El número de filas de X11 más el número de filas en X21.
!>

P

!>          P es ENTERO
!>           El número de filas en X11. 0 <= P <= M. M-P <= min(P,Q,M-Q).
!>

Q

!>          Q es ENTERO
!>           El número de columnas en X11 y X21. 0 <= Q <= M.
!>

X11

!>          X11 es un array COMPLEX*16, de dimensión (LDX11,Q)
!>           En la entrada, el bloque superior de la matriz X a reducir. En
!>           la salida, las columnas de tril(X11) especifican los
!>           reflectores para P1 y las filas de triu(X11,1) especifican los
!>           reflectores para Q1.
!>

LDX11

!>          LDX11 es ENTERO
!>           La dimensión principal de X11. LDX11 >= P.
!>

X21

!>          X21 es un array COMPLEX*16, de dimensión (LDX21,Q)
!>           En la entrada, el bloque inferior de la matriz X a reducir. En
!>           la salida, las columnas de tril(X21) especifican los
!>           reflectores para P2.
!>

LDX21

!>          LDX21 es ENTERO
!>           La dimensión principal de X21. LDX21 >= M-P.
!>

THETA

!>          THETA es un array DOUBLE PRECISION, de dimensión (Q)
!>           Las entradas de los bloques bidiagonales B11, B21 se definen
!>           por THETA y PHI. Ver Detalles adicionales.
!>

PHI

!>          PHI es un array DOUBLE PRECISION, de dimensión (Q-1)
!>           Las entradas de los bloques bidiagonales B11, B21 se definen
!>           por THETA y PHI. Ver Detalles adicionales.
!>

TAUP1

!>          TAUP1 es un array COMPLEX*16, de dimensión (P)
!>           Los factores escalares de los reflectores elementales que
!>           definen P1.
!>

TAUP2

!>          TAUP2 es un array COMPLEX*16, de dimensión (M-P)
!>           Los factores escalares de los reflectores elementales que
!>           definen P2.
!>

TAUQ1

!>          TAUQ1 es un array COMPLEX*16, de dimensión (Q)
!>           Los factores escalares de los reflectores elementales que
!>           definen Q1.
!>

WORK

!>          WORK es un array COMPLEX*16, de dimensión (LWORK)
!>

LWORK

!>          LWORK es ENTERO
!>           La dimensión del array WORK. LWORK >= M-Q.
!>
!>           Si LWORK = -1, se asume una consulta de espacio de trabajo; la
!>           rutina solo calcula el tamaño óptimo del array WORK, devuelve
!>           este valor como la primera entrada del array WORK, y XERBLA no
!>           emite ningún mensaje de error relacionado con LWORK.
!>

INFO

!>          INFO es ENTERO
!>           = 0: Salida exitosa.
!>           < 0: Si INFO = -i, el i-ésimo argumento tenía un valor
!>           ilegal.
!>

Detalles adicionales:

!>
!>  Los bloques bidiagonales superiores B11, B21 se representan
!>  implícitamente por los ángulos THETA(1), ..., THETA(Q) y PHI(1), ...,
!>  PHI(Q-1). Cada entrada en cada banda bidiagonal es un producto de un
!>  seno o coseno de un THETA con un seno o coseno de un PHI. Ver [1] o
!>  ZUNCSD para detalles.
!>
!>  P1, P2 y Q1 se representan como productos de reflectores elementales.
!>  Ver ZUNCSD2BY1 para detalles sobre cómo generar P1, P2 y Q1 usando
!>  ZUNGQR y ZUNGLQ.
!>

Referencias:
