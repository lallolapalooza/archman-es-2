subroutine zunmr2 (character side, character trans, integer m, integer n, integer k, complex*16, dimension( lda, * ) a, integer lda, complex*16, dimension( * ) tau, complex*16, dimension( ldc, * ) c, integer ldc, complex*16, dimension( * ) work, integer info)

ZUNMR2 multiplica una matriz general por la matriz unitaria de una factorización RQ determinada por cgerqf (algoritmo no bloqueado).

Propósito:

!>
!> ZUNMR2 sobrescribe la matriz general compleja m por n C con
!>
!>       Q * C  si SIDE = 'L' y TRANS = 'N', o
!>
!>       Q**H* C  si SIDE = 'L' y TRANS = 'C', o
!>
!>       C * Q  si SIDE = 'R' y TRANS = 'N', o
!>
!>       C * Q**H si SIDE = 'R' y TRANS = 'C',
!>
!> donde Q es una matriz unitaria compleja definida como el producto de k
!>   reflectores elementales
!>
!>       Q = H(1)**H H(2)**H . . . H(k)**H
!>
!> según lo devuelto por ZGERQF. Q es de orden m si SIDE = 'L' y de orden n
!> si SIDE = 'R'.
!>

Parámetros

SIDE 
!>          SIDE es CHARACTER*1
!>          = 'L': aplicar Q o Q**H desde la Izquierda
!>          = 'R': aplicar Q o Q**H desde la Derecha
!>

TRANS

!>          TRANS es CHARACTER*1
!>          = 'N': aplicar Q  (Sin transpuesta)
!>          = 'C': aplicar Q**H (Transpuesta conjugada)
!>

M

!>          M es INTEGER
!>          El número de filas de la matriz C. M >= 0.
!>

N

!>          N es INTEGER
!>          El número de columnas de la matriz C. N >= 0.
!>

K

!>          K es INTEGER
!>          El número de reflectores elementales cuyo producto define
!>          la matriz Q.
!>          Si SIDE = 'L', M >= K >= 0;
!>          si SIDE = 'R', N >= K >= 0.
!>

A

!>          A es COMPLEX*16 array, dimension
!>                               (LDA,M) si SIDE = 'L',
!>                               (LDA,N) si SIDE = 'R'
!>          La i-ésima fila debe contener el vector que define el
!>          reflector elemental H(i), para i = 1,2,...,k, tal como lo
!>          devuelve ZGERQF en las últimas k filas de su argumento de array A.
!>          A es modificado por la rutina pero restaurado a la salida.
!>

LDA

!>          LDA es INTEGER
!>          La dimensión principal del array A. LDA >= max(1,K).
!>

TAU

!>          TAU es COMPLEX*16 array, dimension (K)
!>          TAU(i) debe contener el factor escalar del reflector
!>          elemental H(i), tal como lo devuelve ZGERQF.
!>

C

!>          C es COMPLEX*16 array, dimension (LDC,N)
!>          A la entrada, la matriz m por n C.
!>          A la salida, C es sobrescrito por Q*C o Q**H*C o C*Q**H o C*Q.
!>

LDC

!>          LDC es INTEGER
!>          La dimensión principal del array C. LDC >= max(1,M).
!>

WORK

!>          WORK es COMPLEX*16 array, dimension
!>                                   (N) si SIDE = 'L',
!>                                   (M) si SIDE = 'R'
!>

INFO

!>          INFO es INTEGER
!>          = 0: salida exitosa
!>          < 0: si INFO = -i, el i-ésimo argumento tuvo un valor ilegal
!>
