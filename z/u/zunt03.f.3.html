Documentación de la Función/Subrutina

subrutina zunt03 (character*( * ) rc, integer mu, integer mv, integer n, integer k, complex*16, dimension( ldu, * ) u, integer ldu, complex*16, dimension( ldv, * ) v, integer ldv, complex*16, dimension( * ) work, integer lwork, double precision, dimension( * ) rwork, double precision result, integer info)

ZUNT03

Propósito:

!>
!> ZUNT03 compara dos matrices unitarias U y V para ver si sus
!> correspondientes filas o columnas abarcan los mismos espacios. Se
!> comprueban las filas si RC = 'R', y las columnas si RC = 'C'.
!>
!> RESULT es el máximo de
!>
!>    | V*V' - I | / ( MV ulp ), si RC = 'R', o
!>
!>    | V'*V - I | / ( MV ulp ), si RC = 'C',
!>
!> y el máximo sobre las filas (o columnas) de 1 a K de
!>
!>    | U(i) - S*V(i) |/ ( N ulp )
!>
!> donde abs(S) = 1 (elegido para minimizar la expresión), U(i) es la
!> i-ésima fila (columna) de U, y V(i) es la i-ésima fila (columna) de V.
!>

Parámetros

RC 
!>          RC es CHARACTER*1
!>          Si RC = 'R' se van a comparar las filas de U y V.
!>          Si RC = 'C' se van a comparar las columnas de U y V.
!>

MU

!>          MU es INTEGER
!>          El número de filas de U si RC = 'R', y el número de
!>          columnas si RC = 'C'. Si MU = 0 ZUNT03 no hace nada.
!>          MU debe ser mayor o igual que cero.
!>

MV

!>          MV es INTEGER
!>          El número de filas de V si RC = 'R', y el número de
!>          columnas si RC = 'C'. Si MV = 0 ZUNT03 no hace nada.
!>          MV debe ser mayor o igual que cero.
!>

N

!>          N es INTEGER
!>          Si RC = 'R', el número de columnas en las matrices U y V,
!>          y si RC = 'C', el número de filas en U y V. Si N = 0
!>          ZUNT03 no hace nada. N debe ser mayor o igual que cero.
!>

K

!>          K es INTEGER
!>          El número de filas o columnas de U y V a comparar.
!>          0 <= K <= max(MU,MV).
!>

U

!>          U es un array COMPLEX*16, dimension (LDU,N)
!>          La primera matriz a comparar. Si RC = 'R', U es MU por N, y
!>          si RC = 'C', U es N por MU.
!>

LDU

!>          LDU es INTEGER
!>          La dimensión principal de U. Si RC = 'R', LDU >= max(1,MU),
!>          y si RC = 'C', LDU >= max(1,N).
!>

V

!>          V es un array COMPLEX*16, dimension (LDV,N)
!>          La segunda matriz a comparar. Si RC = 'R', V es MV por N, y
!>          si RC = 'C', V es N por MV.
!>

LDV

!>          LDV es INTEGER
!>          La dimensión principal de V. Si RC = 'R', LDV >= max(1,MV),
!>          y si RC = 'C', LDV >= max(1,N).
!>

WORK

!>          WORK es un array COMPLEX*16, dimension (LWORK)
!>

LWORK

!>          LWORK es INTEGER
!>          La longitud del array WORK. Para un rendimiento óptimo, LWORK
!>          debería ser al menos N*N si RC = 'C' o M*M si RC = 'R', pero
!>          las pruebas se realizarán incluso si LWORK es 0.
!>

RWORK

!>          RWORK es un array DOUBLE PRECISION, dimension (max(MV,N))
!>

RESULT

!>          RESULT es DOUBLE PRECISION
!>          El valor calculado por la prueba descrita anteriormente. RESULT
!>          está limitado a 1/ulp para evitar desbordamientos.
!>

INFO

!>          INFO es INTEGER
!>          0 indica una salida exitosa
!>          -k indica que el parámetro k tuvo un valor ilegal
!>
