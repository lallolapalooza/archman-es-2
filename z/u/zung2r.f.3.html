subrutina zung2r (integer m, integer n, integer k, complex*16, dimension( lda, * ) a, integer lda, complex*16, dimension( * ) tau, complex*16, dimension( * ) work, integer info)

ZUNG2R

Propósito:

!>
!> ZUNG2R genera una matriz compleja m por n, Q, con columnas ortonormales,
!> que se define como las primeras n columnas de un producto de k
!> reflectores elementales de orden m
!>
!>       Q  =  H(1) H(2) . . . H(k)
!>
!> tal como devuelve ZGEQRF.
!>

Parámetros

M 
!>          M es ENTERO
!>          El número de filas de la matriz Q. M >= 0.
!>

N

!>          N es ENTERO
!>          El número de columnas de la matriz Q. M >= N >= 0.
!>

K

!>          K es ENTERO
!>          El número de reflectores elementales cuyo producto define la
!>          matriz Q. N >= K >= 0.
!>

A

!>          A es un array COMPLEX*16, de dimensión (LDA,N)
!>          En la entrada, la columna i debe contener el vector que
!>          define el reflector elemental H(i), para i = 1,2,...,k, como
!>          devuelto por ZGEQRF en las primeras k columnas de su array
!>          argumento A.
!>          En la salida, la matriz Q de m por n.
!>

LDA

!>          LDA es ENTERO
!>          La primera dimensión del array A. LDA >= max(1,M).
!>

TAU

!>          TAU es un array COMPLEX*16, de dimensión (K)
!>          TAU(i) debe contener el factor escalar del reflector
!>          elemental H(i), tal como lo devuelve ZGEQRF.
!>

WORK

!>          WORK es un array COMPLEX*16, de dimensión (N)
!>

INFO

!>          INFO es ENTERO
!>          = 0: salida exitosa
!>          < 0: si INFO = -i, el argumento i tiene un valor ilegal
!>
