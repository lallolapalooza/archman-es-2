DOCUMENTACIÓN DE LA FUNCIÓN/SUBRUTINA

subroutine zungl2 (integer m, integer n, integer k, complex*16, dimension( lda, * ) a, integer lda, complex*16, dimension( * ) tau, complex*16, dimension( * ) work, integer info)

ZUNGL2 genera toda o parte de la matriz unitaria Q a partir de una factorización LQ determinada por cgelqf (algoritmo sin bloques).

Propósito:

!>
!> ZUNGL2 genera una matriz Q compleja m por n con filas ortonormales,
!> que se define como las primeras m filas de un producto de k reflectores
!> elementales de orden n
!>
!>       Q  =  H(k)**H . . . H(2)**H H(1)**H
!>
!> tal como devuelve ZGELQF.
!>

Parámetros

M 
!>          M es INTEGER
!>          El número de filas de la matriz Q. M >= 0.
!>

N

!>          N es INTEGER
!>          El número de columnas de la matriz Q. N >= M.
!>

K

!>          K es INTEGER
!>          El número de reflectores elementales cuyo producto define la
!>          matriz Q. M >= K >= 0.
!>

A

!>          A es array COMPLEX*16, dimensión (LDA,N)
!>          En la entrada, la fila i debe contener el vector que define
!>          el reflector elemental H(i), para i = 1,2,...,k, tal como
!>          devuelve ZGELQF en las primeras k filas de su argumento de
!>          array A.
!>          En la salida, la matriz Q de m por n.
!>

LDA

!>          LDA es INTEGER
!>          La primera dimensión del array A. LDA >= max(1,M).
!>

TAU

!>          TAU es array COMPLEX*16, dimensión (K)
!>          TAU(i) debe contener el factor escalar del reflector
!>          elemental H(i), tal como devuelve ZGELQF.
!>

WORK

!>          WORK es array COMPLEX*16, dimensión (M)
!>

INFO

!>          INFO es INTEGER
!>          = 0: salida exitosa
!>          < 0: si INFO = -i, el argumento i tiene un valor ilegal
!>
