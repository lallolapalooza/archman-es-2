Documentación de función/subrutina

subrutina zunhr_col01 (integer m, integer n, integer mb1, integer nb1, integer nb2, double precision, dimension(6) resultado)

ZUNHR_COL01

Propósito:

!>
!> ZUNHR_COL01 prueba ZUNGTSQR y ZUNHR_COL usando ZLATSQR, ZGEMQRT.
!> Por lo tanto, ZLATSQR (parte de ZGEQR), ZGEMQRT (parte de ZGEMQR)
!> deben ser probados antes que esta prueba.
!>
!>

Parámetros

M 
!>          M es ENTERO
!>          Número de filas en la matriz de prueba.
!>

N

!>          N es ENTERO
!>          Número de columnas en la matriz de prueba.
!>

MB1

!>          MB1 es ENTERO
!>          Número de filas en el bloque de filas en una matriz de entrada de prueba.
!>

NB1

!>          NB1 es ENTERO
!>          Número de columnas en el bloque de columnas en una matriz de entrada de prueba.
!>

NB2

!>          NB2 es ENTERO
!>          Número de columnas en el bloque de columnas en una matriz de salida de prueba.
!>

RESULTADO

!>          RESULTADO es un arreglo de DOBLE PRECISION, dimensión (6)
!>          Resultados de cada una de las seis pruebas a continuación.
!>
!>            A es una matriz de entrada de prueba de m x n a factorizar.
!>            tal que A = Q_gr * ( R )
!>                               ( 0 ),
!>
!>            Q_qr es una matriz Q unitaria implícita de m x m, el resultado
!>            de la factorización en representación WY en bloques,
!>            almacenada en formato de salida ZGEQRT.
!>
!>            R es una matriz triangular superior de n x n,
!>
!>            0 es una matriz cero de (m-n) x n,
!>
!>            Q es una matriz unitaria explícita de m x m, Q = Q_gr * I
!>
!>            C es una matriz aleatoria de m x n,
!>
!>            D es una matriz aleatoria de n x m.
!>
!>            Las seis pruebas son:
!>
!>            RESULTADO(1) = |R - (Q**H) * A| / ( eps * m * |A| )
!>              es equivalente a la prueba de | A - Q * R | / (eps * m * |A|),
!>
!>            RESULTADO(2) = |I - (Q**H) * Q| / ( eps * m ),
!>
!>            RESULTADO(3) = | Q_qr * C - Q * C | / (eps * m * |C|),
!>
!>            RESULTADO(4) = | (Q_gr**H) * C - (Q**H) * C | / (eps * m * |C|)
!>
!>            RESULTADO(5) = | D * Q_qr - D * Q | / (eps * m * |D|)
!>
!>            RESULTADO(6) = | D * (Q_qr**H) - D * (Q**H) | / (eps * m * |D|),
!>
!>            donde:
!>              Q_qr * C, (Q_gr**H) * C, D * Q_qr, D * (Q_qr**H) se
!>              calculan usando ZGEMQRT,
!>
!>              Q * C, (Q**H) * C, D * Q, D * (Q**H) se
!>              calculan usando ZGEMM.
!>
