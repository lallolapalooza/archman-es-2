Documentación de la función/subrutina

subroutine zunghr (integer n, integer ilo, integer ihi, complex*16, dimension( lda, * ) a, integer lda, complex*16, dimension( * ) tau, complex*16, dimension( * ) work, integer lwork, integer info)

ZUNGHR

Propósito:

!>
!> ZUNGHR genera una matriz unitaria compleja Q que se define como el
!> producto de IHI-ILO reflectores elementales de orden N, como se devuelve en
!> ZGEHRD:
!>
!> Q = H(ilo) H(ilo+1) . . . H(ihi-1).
!>

Parámetros

N 
!>          N es ENTERO
!>          El orden de la matriz Q. N >= 0.
!>

ILO

!>          ILO es ENTERO
!>

IHI

!>          IHI es ENTERO
!>
!>          ILO e IHI deben tener los mismos valores que en la llamada anterior
!>          de ZGEHRD. Q es igual a la matriz identidad excepto en la
!>          submatriz Q(ilo+1:ihi,ilo+1:ihi).
!>          1 <= ILO <= IHI <= N, si N > 0; ILO=1 y IHI=0, si N=0.
!>

A

!>          A es un array COMPLEX*16, dimensión (LDA,N)
!>          En la entrada, los vectores que definen los reflectores elementales,
!>          como se devuelve en ZGEHRD.
!>          En la salida, la matriz unitaria N por N Q.
!>

LDA

!>          LDA es ENTERO
!>          La dimensión principal del array A. LDA >= max(1,N).
!>

TAU

!>          TAU es un array COMPLEX*16, dimensión (N-1)
!>          TAU(i) debe contener el factor escalar del reflector
!>          elemental H(i), como se devuelve en ZGEHRD.
!>

WORK

!>          WORK es un array COMPLEX*16, dimensión (MAX(1,LWORK))
!>          En la salida, si INFO = 0, WORK(1) devuelve el LWORK óptimo.
!>

LWORK

!>          LWORK es ENTERO
!>          La dimensión del array WORK. LWORK >= IHI-ILO.
!>          Para un rendimiento óptimo LWORK >= (IHI-ILO)*NB, donde NB es
!>          el tamaño de bloque óptimo.
!>
!>          Si LWORK = -1, entonces se asume una consulta de espacio de trabajo; la rutina
!>          solo calcula el tamaño óptimo del array WORK, devuelve
!>          este valor como la primera entrada del array WORK, y XERBLA no emite
!>          ningún mensaje de error relacionado con LWORK.
!>

INFO

!>          INFO es ENTERO
!>          = 0:  salida exitosa
!>          < 0:  si INFO = -i, el i-ésimo argumento tenía un valor ilegal
!>
