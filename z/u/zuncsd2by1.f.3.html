ZUNCSD2BY

1

Propósito

: 
!>
!> ZUNCSD2BY1 calcula la descomposición CS de una matriz X de M-por-Q con
!> columnas ortonormales que ha sido particionada en una estructura de
!> bloques de 2-por-1:
!>
!>                                [  I1 0  0 ]
!>                                [  0  C  0 ]
!>          [ X11 ]   [ U1 |    ] [  0  0  0 ]
!>      X = [-----] = [---------] [----------] V1**T .
!>          [ X21 ]   [    | U2 ] [  0  0  0 ]
!>                                [  0  S  0 ]
!>                                [  0  0  I2]
!>
!> X11 es P-por-Q. Las matrices unitarias U1, U2 y V1 son P-por-P,
!> (M-P)-por-(M-P) y Q-por-Q, respectivamente. C y S son matrices
!> diagonales no negativas R-por-R que satisfacen C^2 + S^2 = I, en las
!> que R = MIN(P,M-P,Q,M-Q). I1 es una matriz identidad K1-por-K1 y I2 es
!> una matriz identidad K2-por-K2, donde K1 = MAX(Q+P-M,0), K2 = MAX(Q-P,0).
!
>

!>          WORK y RWORK, respectivamente, y XERBLA no emite ningún mensaje
!>          de error relacionado con LWORK o LRWORK.
!>

RWOR

K 
!>          RWORK es un array DOUBLE PRECISION, dimensión (MAX(1,LRWORK))
!>          En la salida, si INFO = 0, RWORK(1) devuelve el LRWORK óptimo.
!>          Si INFO > 0 en la salida, RWORK(2:R) contiene los valores PHI(1),
!>          ..., PHI(R-1) que, junto con THETA(1), ..., THETA(R),
!>          definen la matriz en forma de bloques bidiagonal intermedia
!>          que permanece después de la no convergencia. INFO especifica el
!>          número de PHI no nulos.
