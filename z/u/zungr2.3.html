Documentación de la Función/Subrutina

subroutine zungr2 (integer m, integer n, integer k, complex*16, dimension( lda, * ) a, integer lda, complex*16, dimension( * ) tau, complex*16, dimension( * ) work, integer info)

ZUNGR2 genera toda o parte de la matriz unitaria Q a partir de una factorización RQ determinada por cgerqf (algoritmo sin bloques).

Propósito:

!>
!> ZUNGR2 genera una matriz compleja Q de m por n con filas ortonormales,
!> que se define como la última m filas de un producto de k reflectores
!> elementales de orden n
!>
!>       Q  =  H(1)**H H(2)**H . . . H(k)**H
!>
!> tal como devuelve ZGERQF.
!>

Parámetros

M 
!>          M es INTEGER
!>          El número de filas de la matriz Q. M >= 0.
!>

N

!>          N es INTEGER
!>          El número de columnas de la matriz Q. N >= M.
!>

K

!>          K es INTEGER
!>          El número de reflectores elementales cuyo producto define la
!>          matriz Q. M >= K >= 0.
!>

A

!>          A es un array COMPLEX*16, de dimensión (LDA,N)
!>          En la entrada, la fila (m-k+i) debe contener el vector que
!>          define el reflector elemental H(i), para i = 1,2,...,k, tal como
!>          devuelve ZGERQF en las últimas k filas de su argumento de array
!>          A.
!>          En la salida, la matriz m-por-n Q.
!>

LDA

!>          LDA es INTEGER
!>          La primera dimensión del array A. LDA >= max(1,M).
!>

TAU

!>          TAU es un array COMPLEX*16, de dimensión (K)
!>          TAU(i) debe contener el factor escalar del reflector elemental
!>          H(i), tal como devuelve ZGERQF.
!>

WORK

!>          WORK es un array COMPLEX*16, de dimensión (M)
!>

INFO

!>          INFO es INTEGER
!>          = 0: salida exitosa
!>          < 0: si INFO = -i, el argumento i tiene un valor ilegal
!>
