ZUNGTR

Propósito:

!>
!> ZUNGTR genera una matriz unitaria compleja Q que se define como el
!> producto de n-1 reflectores elementales de orden N, tal como se devuelve por
!> ZHETRD:
!>
!> si UPLO = 'U', Q = H(n-1) . . . H(2) H(1),
!>
!> si UPLO = 'L', Q = H(1) H(2) . . . H(n-1).
!>

Parámetros

UPLO 
!>          UPLO es CARACTER*1
!>          = 'U': El triángulo superior de A contiene reflectores elementales
!>                 de ZHETRD;
!>          = 'L': El triángulo inferior de A contiene reflectores elementales
!>                 de ZHETRD.
!>

N

!>          N es ENTERO
!>          El orden de la matriz Q. N >= 0.
!>

A

!>          A es arreglo COMPLEJO*16, dimensión (LDA,N)
!>          En la entrada, los vectores que definen los reflectores elementales,
!>          tal como se devuelve por ZHETRD.
!>          En la salida, la matriz unitaria N por N, Q.
!>

LDA

!>          LDA es ENTERO
!>          La dimensión principal del arreglo A. LDA >= N.
!>

TAU

!>          TAU es arreglo COMPLEJO*16, dimensión (N-1)
!>          TAU(i) debe contener el factor escalar del reflector elemental
!>          H(i), tal como se devuelve por ZHETRD.
!>

WORK

!>          WORK es arreglo COMPLEJO*16, dimensión (MAX(1,LWORK))
!>          En la salida, si INFO = 0, WORK(1) devuelve el LWORK óptimo.
!>

LWORK

!>          LWORK es ENTERO
!>          La dimensión del arreglo WORK. LWORK >= N-1.
!>          Para un rendimiento óptimo LWORK >= (N-1)*NB, donde NB es
!>          el tamaño de bloque óptimo.
!>
!>          Si LWORK = -1, entonces se asume una consulta de espacio de trabajo; la rutina
!>          solo calcula el tamaño óptimo del arreglo WORK, devuelve
!>          este valor como la primera entrada del arreglo WORK, y XERBLA no emite ningún mensaje de error
!>          relacionado con LWORK.
!>

INFO

!>          INFO es ENTERO
!>          = 0:  salida exitosa
!>          < 0:  si INFO = -i, el i-ésimo argumento tenía un valor ilegal
!>
