subrutina zunmbr (character vect, character side, character trans, integer m, integer n, integer k, complex*16, dimension( lda, * ) a, integer lda, complex*16, dimension( * ) tau, complex*16, dimension( ldc, * ) c, integer ldc, complex*16, dimension( * ) work, integer lwork, integer info)

ZUNMBR

Propósito:

!>
!> Si VECT = 'Q', ZUNMBR sobrescribe la matriz compleja general M por N, C, con
!>                 LADO = 'I'     LADO = 'D'
!> TRANS = 'N':      Q * C          C * Q
!> TRANS = 'C':      Q**H * C       C * Q**H
!>
!> Si VECT = 'P', ZUNMBR sobrescribe la matriz compleja general M por N, C, con
!>                 LADO = 'I'     LADO = 'D'
!> TRANS = 'N':      P * C          C * P
!> TRANS = 'C':      P**H * C       C * P**H
!>
!> Aquí Q y P**H son las matrices unitarias determinadas por ZGEBRD al
!> reducir una matriz compleja A a forma bidiagonal: A = Q * B * P**H. Q
!> y P**H se definen como productos de reflectores elementales H(i) y
!> G(i) respectivamente.
!>
!> Sea nq = m si LADO = 'I' y nq = n si LADO = 'D'. Así nq es el
!> orden de la matriz unitaria Q o P**H que se aplica.
!>
!> Si VECT = 'Q', se asume que A ha sido una matriz NQ por K:
!> si nq >= k, Q = H(1) H(2) . . . H(k);
!> si nq < k, Q = H(1) H(2) . . . H(nq-1).
!>
!> Si VECT = 'P', se asume que A ha sido una matriz K por NQ:
!> si k < nq, P = G(1) G(2) . . . G(k);
!> si k >= nq, P = G(1) G(2) . . . G(nq-1).
!>

Parámetros

VECT 
!>          VECT es CHARACTER*1
!>          = 'Q': aplicar Q o Q**H;
!>          = 'P': aplicar P o P**H.
!>

SIDE

!>          SIDE es CHARACTER*1
!>          = 'L': aplicar Q, Q**H, P o P**H desde la Izquierda;
!>          = 'R': aplicar Q, Q**H, P o P**H desde la Derecha.
!>

TRANS

!>          TRANS es CHARACTER*1
!>          = 'N': Sin transponer, aplicar Q o P;
!>          = 'C': Transpuesta conjugada, aplicar Q**H o P**H.
!>

M

!>          M es INTEGER
!>          El número de filas de la matriz C. M >= 0.
!>

N

!>          N es INTEGER
!>          El número de columnas de la matriz C. N >= 0.
!>

K

!>          K es INTEGER
!>          Si VECT = 'Q', el número de columnas en la matriz original
!>          reducida por ZGEBRD.
!>          Si VECT = 'P', el número de filas en la matriz original
!>          reducida por ZGEBRD.
!>          K >= 0.
!>

A

!>          A es un array COMPLEX*16, de dimensiones
!>                                (LDA,min(nq,K)) si VECT = 'Q'
!>                                (LDA,nq)        si VECT = 'P'
!>          Los vectores que definen los reflectores elementales H(i) y
!>          G(i), cuyos productos determinan las matrices Q y P, tal como
!>          devuelve ZGEBRD.
!>

LDA

!>          LDA es INTEGER
!>          La dimensión principal del array A.
!>          Si VECT = 'Q', LDA >= max(1,nq);
!>          si VECT = 'P', LDA >= max(1,min(nq,K)).
!>

TAU

!>          TAU es un array COMPLEX*16, de dimensión (min(nq,K))
!>          TAU(i) debe contener el factor escalar del reflector elemental
!>          H(i) o G(i) que determina Q o P, tal como devuelve
!>          ZGEBRD en el argumento de array TAUQ o TAUP.
!>

C

!>          C es un array COMPLEX*16, de dimensión (LDC,N)
!>          En la entrada, la matriz C de M por N.
!>          En la salida, C se sobrescribe con Q*C o Q**H*C o C*Q**H o C*Q
!>          o P*C o P**H*C o C*P o C*P**H.
!>

LDC

!>          LDC es INTEGER
!>          La dimensión principal del array C. LDC >= max(1,M).
!>

WORK

!>          WORK es un array COMPLEX*16, de dimensión (MAX(1,LWORK))
!>          En la salida, si INFO = 0, WORK(1) devuelve el LWORK óptimo.
!>

LWORK

!>          LWORK es INTEGER
!>          La dimensión del array WORK.
!>          Si SIDE = 'L', LWORK >= max(1,N);
!>          si SIDE = 'R', LWORK >= max(1,M);
!>          si N = 0 o M = 0, LWORK >= 1.
!>          Para un rendimiento óptimo LWORK >= max(1,N*NB) si SIDE = 'L',
!>          y LWORK >= max(1,M*NB) si SIDE = 'R', donde NB es el
!>          tamaño de bloque óptimo. (NB = 0 si M = 0 o N = 0.)
!>
!>          Si LWORK = -1, entonces se asume una consulta de espacio de
!>          trabajo; la rutina solo calcula el tamaño óptimo del array WORK,
!>          devuelve este valor como la primera entrada del array WORK, y
!>          XERBLA no emite ningún mensaje de error relacionado con LWORK.
!>

INFO

!>          INFO es INTEGER
!>          = 0:  salida exitosa
!>          < 0:  si INFO = -i, el i-ésimo argumento tenía un valor ilegal
!>
