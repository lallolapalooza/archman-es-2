ZHBEVD calcula los valores propios y, opcionalmente, los vectores propios izquierdos y/o derechos para otras matrices

Propósito:

!>
!> ZHBEVD calcula todos los valores propios y, opcionalmente, los vectores propios
!> de una matriz de banda Hermitiana compleja A. Si se desean los vectores propios,
!> utiliza un algoritmo de división y conquista.
!>
!>

Parámetros

JOBZ 
!>          JOBZ es CHARACTER*1
!>          = 'N':  Solo calcula los valores propios;
!>          = 'V':  Calcula los valores propios y los vectores propios.
!>

UPLO

!>          UPLO es CHARACTER*1
!>          = 'U':  Se almacena el triángulo superior de A;
!>          = 'L':  Se almacena el triángulo inferior de A.
!>

N

!>          N es INTEGER
!>          El orden de la matriz A.  N >= 0.
!>

KD

!>          KD es INTEGER
!>          El número de superdiagonales de la matriz A si UPLO = 'U',
!>          o el número de subdiagonales si UPLO = 'L'.  KD >= 0.
!>

AB

!>          AB es un array COMPLEX*16, de dimensión (LDAB, N)
!>          En la entrada, el triángulo superior o inferior de la matriz de banda
!>          Hermitiana A, almacenado en las primeras KD+1 filas del array. La
!>          j-ésima columna de A se almacena en la j-ésima columna del array AB
!>          de la siguiente manera:
!>          si UPLO = 'U', AB(kd+1+i-j,j) = A(i,j) para max(1,j-kd)<=i<=j;
!>          si UPLO = 'L', AB(1+i-j,j)    = A(i,j) para j<=i<=min(n,j+kd).
!>
!>          En la salida, AB se sobrescribe con los valores generados durante la
!>          reducción a forma tridiagonal. Si UPLO = 'U', la primera
!>          superdiagonal y la diagonal de la matriz tridiagonal T
!>          se devuelven en las filas KD y KD+1 de AB, y si UPLO = 'L',
!>          la diagonal y la primera subdiagonal de T se devuelven en las
!>          primeras dos filas de AB.
!>

LDAB

!>          LDAB es INTEGER
!>          La dimensión principal del array AB.  LDAB >= KD + 1.
!>

W

!>          W es un array DOUBLE PRECISION, de dimensión (N)
!>          Si INFO = 0, los valores propios en orden ascendente.
!>

Z

!>          Z es un array COMPLEX*16, de dimensión (LDZ, N)
!>          Si JOBZ = 'V', entonces si INFO = 0, Z contiene los vectores propios
!>          ortonormales de la matriz A, con la i-ésima columna de Z
!>          conteniendo el vector propio asociado a W(i).
!>          Si JOBZ = 'N', entonces Z no se referencia.
!>

LDZ

!>          LDZ es INTEGER
!>          La dimensión principal del array Z.  LDZ >= 1, y si
!>          JOBZ = 'V', LDZ >= max(1,N).
!>

WORK

!>          WORK es un array COMPLEX*16, de dimensión (MAX(1,LWORK))
!>          En la salida, si INFO = 0, WORK(1) devuelve el LWORK óptimo.
!>

LWORK

!>          LWORK es INTEGER
!>          La dimensión del array WORK.
!>          Si N <= 1,               LWORK debe ser al menos 1.
!>          Si JOBZ = 'N' y N > 1, LWORK debe ser al menos N.
!>          Si JOBZ = 'V' y N > 1, LWORK debe ser al menos 2*N**2.
!>
!>          Si LWORK = -1, entonces se asume una consulta de espacio de trabajo; la rutina
!>          solo calcula los tamaños óptimos de los arrays WORK, RWORK y
!>          IWORK, devuelve estos valores como las primeras entradas de
!>          los arrays WORK, RWORK e IWORK, y XERBLA no emite ningún mensaje de error
!>          relacionado con LWORK o LRWORK o LIWORK.
!>

RWORK

!>          RWORK es un array DOUBLE PRECISION,
!>                                         de dimensión (LRWORK)
!>          En la salida, si INFO = 0, RWORK(1) devuelve el LRWORK óptimo.
!>

LRWORK

!>          LRWORK es INTEGER
!>          La dimensión del array RWORK.
!>          Si N <= 1,               LRWORK debe ser al menos 1.
!>          Si JOBZ = 'N' y N > 1, LRWORK debe ser al menos N.
!>          Si JOBZ = 'V' y N > 1, LRWORK debe ser al menos
!>                        1 + 5*N + 2*N**2.
!>
!>          Si LRWORK = -1, entonces se asume una consulta de espacio de trabajo; la
!>          rutina solo calcula los tamaños óptimos de los arrays WORK, RWORK
!>          e IWORK, devuelve estos valores como las primeras entradas de
!>          los arrays WORK, RWORK e IWORK, y XERBLA no emite ningún mensaje de error
!>          relacionado con LWORK o LRWORK o LIWORK.
!>

IWORK

!>          IWORK es un array INTEGER, de dimensión (MAX(1,LIWORK))
!>          En la salida, si INFO = 0, IWORK(1) devuelve el LIWORK óptimo.
!>

LIWORK

!>          LIWORK es INTEGER
!>          La dimensión del array IWORK.
!>          Si JOBZ = 'N' o N <= 1, LIWORK debe ser al menos 1.
!>          Si JOBZ = 'V' y N > 1, LIWORK debe ser al menos 3 + 5*N .
!>
!>          Si LIWORK = -1, entonces se asume una consulta de espacio de trabajo; la
!>          rutina solo calcula los tamaños óptimos de los arrays WORK, RWORK
!>          e IWORK, devuelve estos valores como las primeras entradas de
!>          los arrays WORK, RWORK e IWORK, y XERBLA no emite ningún mensaje de error
!>          relacionado con LWORK o LRWORK o LIWORK.
!>

INFO

!>          INFO es INTEGER
!>          = 0:  salida exitosa.
!>          < 0:  si INFO = -i, el i-ésimo argumento tenía un valor ilegal.
!>          > 0:  si INFO = i, el algoritmo falló en converger; los i
!>                elementos fuera de la diagonal de una forma tridiagonal
!>                intermedia no convergieron a cero.
!>

    NAME

    zhbevd - Computes the eigenvalues and optionally eigenvectors of a complex Hermitian-banded matrix.

    SYNOPSIS

        SUBROUTINE ZHBEVD( JOBZ, UPLO, N, KD, AB, LDAB, D, Z, LDZ, RWORK, 
 &                   LDWORK, INFO )

    Function/Subroutine Documentation

    This subroutine computes the eigenvalues and optionally eigenvectors of a complex Hermitian-banded matrix.

    Parameters

    • JOBZ CHARACTER*1. Specifies whether to compute eigenvectors.
      = 'N': Compute only the eigenvalues.
      = 'V': Compute the eigenvalues and eigenvectors.
    • UPLO CHARACTER*1. Specifies whether the matrix is upper or lower triangular.
      = 'U': Upper triangle of AB is stored.
      = 'L': Lower triangle of AB is stored.
    • N INTEGER. The order of the matrix A.
    • KD INTEGER. The number of super- or subdiagonals of the matrix AB.
    • AB COMPLEX*16 array, dimension (LDAB,N).
      On entry, the upper or lower band of the matrix A.
    • LDAB INTEGER. The leading dimension of the array AB.
    • D DOUBLE PRECISION array, dimension (N).
      On exit, the eigenvalues, sorted in ascending order.
    • Z COMPLEX*16 array, dimension (LDZ,N).
      On exit, if JOBZ = 'V', Z contains the normalized eigenvectors of A, with the i-th column of Z holding the eigenvector corresponding to the i-th eigenvalue in D.
    • LDZ INTEGER. The leading dimension of the array Z.
    • RWORK DOUBLE PRECISION array, dimension (LRWORK).
    • LRWORK INTEGER. The dimension of the array RWORK.
    • INFO INTEGER.
      = 0: successful exit.
      < 0: if INFO = -i, the i-th argument had an illegal value.
      > 0: if INFO = i, the algorithm failed to converge; i off-diagonal elements of an intermediate tridiagonal matrix did not shrink to zero.
