subrutina zhpgst (integer itype, character uplo, integer n, complex*16, dimension( * ) ap, complex*16, dimension( * ) bp, integer info)

ZHPGST

Propósito:

!>
!> ZHPGST reduce un problema generalizado de autovalores hermitiano-definido
!> complejo a la forma estándar, utilizando almacenamiento empaquetado.
!>
!> Si ITYPE = 1, el problema es A*x = lambda*B*x,
!> y A se sobrescribe con inv(U**H)*A*inv(U) o inv(L)*A*inv(L**H)
!>
!> Si ITYPE = 2 o 3, el problema es A*B*x = lambda*x o
!> B*A*x = lambda*x, y A se sobrescribe con U*A*U**H o L**H*A*L.
!>
!> B debe haber sido previamente factorizado como U**H*U o L*L**H por ZPPTRF.
!>

Parámetros

ITYPE 
!>          ITYPE es INTEGER
!>          = 1: calcular inv(U**H)*A*inv(U) o inv(L)*A*inv(L**H);
!>          = 2 o 3: calcular U*A*U**H o L**H*A*L.
!>

UPLO

!>          UPLO es CHARACTER*1
!>          = 'U':  el triángulo superior de A se almacena y B se factoriza como
!>                  U**H*U;
!>          = 'L':  el triángulo inferior de A se almacena y B se factoriza como
!>                  L*L**H.
!>

N

!>          N es INTEGER
!>          El orden de las matrices A y B.  N >= 0.
!>

AP

!>          AP es un array COMPLEX*16, de dimensión (N*(N+1)/2)
!>          En la entrada, el triángulo superior o inferior de la matriz Hermitiana
!>          A, empaquetado columna por columna en un array lineal. La j-ésima columna de A
!>          se almacena en el array AP de la siguiente manera:
!>          si UPLO = 'U', AP(i + (j-1)*j/2) = A(i,j) para 1<=i<=j;
!>          si UPLO = 'L', AP(i + (j-1)*(2n-j)/2) = A(i,j) para j<=i<=n.
!>
!>          En la salida, si INFO = 0, la matriz transformada, almacenada en
!>          el mismo formato que A.
!>

BP

!>          BP es un array COMPLEX*16, de dimensión (N*(N+1)/2)
!>          El factor triangular de la factorización de Cholesky de B,
!>          almacenado en el mismo formato que A, tal como lo devuelve ZPPTRF.
!>

INFO

!>          INFO es INTEGER
!>          = 0:  salida exitosa
!>          < 0:  si INFO = -i, el i-ésimo argumento tenía un valor ilegal
!>
