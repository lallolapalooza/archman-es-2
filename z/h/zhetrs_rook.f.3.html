Funciones/Subrutinas


subrutina zhetrs_rook (uplo, n, nrhs, a, lda, ipiv, b, ldb, info)
ZHETRS_ROOK calcula la solución a un sistema de ecuaciones lineales A * X = B para matrices HE utilizando la factorización obtenida con uno de los métodos de pivoteo diagonal acotado (máximo 2 intercambios)

Documentación de función/subrutina

subrutina zhetrs_rook (character uplo, integer n, integer nrhs, complex*16, dimension( lda, * ) a, integer lda, integer, dimension( * ) ipiv, complex*16, dimension( ldb, * ) b, integer ldb, integer info)

ZHETRS_ROOK calcula la solución a un sistema de ecuaciones lineales A * X = B para matrices HE utilizando la factorización obtenida con uno de los métodos de pivoteo diagonal acotado (máximo 2 intercambios)

Propósito:

!>
!> ZHETRS_ROOK resuelve un sistema de ecuaciones lineales A*X = B con una matriz
!> compleja Hermitiana A utilizando la factorización A = U*D*U**H o
!> A = L*D*L**H calculada por ZHETRF_ROOK.
!>

Parámetros

UPLO 
!>          UPLO es CHARACTER*1
!>          Especifica si los detalles de la factorización se almacenan
!>          como una matriz triangular superior o inferior.
!>          = 'U':  Triangular superior, la forma es A = U*D*U**H;
!>          = 'L':  Triangular inferior, la forma es A = L*D*L**H.
!>

N

!>          N es INTEGER
!>          El orden de la matriz A.  N >= 0.
!>

NRHS

!>          NRHS es INTEGER
!>          El número de lados derechos, es decir, el número de columnas
!>          de la matriz B.  NRHS >= 0.
!>

A

!>          A es un array COMPLEX*16, dimensión (LDA,N)
!>          La matriz diagonal por bloques D y los multiplicadores utilizados para
!>          obtener el factor U o L calculados por ZHETRF_ROOK.
!>

LDA

!>          LDA es INTEGER
!>          La dimensión principal del array A.  LDA >= max(1,N).
!>

IPIV

!>          IPIV es un array INTEGER, dimensión (N)
!>          Detalles de los intercambios y la estructura de bloques de D
!>          determinados por ZHETRF_ROOK.
!>

B

!>          B es un array COMPLEX*16, dimensión (LDB,NRHS)
!>          En la entrada, la matriz del lado derecho B.
!>          En la salida, la matriz solución X.
!>

LDB

!>          LDB es INTEGER
!>          La dimensión principal del array B.  LDB >= max(1,N).
!>

INFO

!>          INFO es INTEGER
!>          = 0:  salida exitosa
!>          < 0:  si INFO = -i, el i-ésimo argumento tuvo un valor ilegal
!>
