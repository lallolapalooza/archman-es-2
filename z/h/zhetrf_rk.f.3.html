ZHETRF_RK calcula la factorización de una matriz Hermitiana compleja indefinida utilizando el método de pivoteo diagonal Bunch-Kaufman (rook) acotado (algoritmo bloqueado BLAS3).

Documentación de Función/Subrutina

subrutina zhetrf_rk (carácter uplo, entero n, complejo*16, dimensión( lda, * ) a, entero lda, complejo*16, dimensión( * ) e, entero, dimensión( * ) ipiv, complejo*16, dimensión( * ) work, entero lwork, entero info)

ZHETRF_RK calcula la factorización de una matriz Hermitiana compleja indefinida utilizando el método de pivoteo diagonal Bunch-Kaufman (rook) acotado (algoritmo bloqueado BLAS3).

Propósito:

!> ZHETRF_RK calcula la factorización de una matriz Hermitiana compleja A
!> utilizando el método de pivoteo diagonal Bunch-Kaufman (rook) acotado:
!>
!>    A = P*U*D*(U**H)*(P**T) o A = P*L*D*(L**H)*(P**T),
!>
!> donde U (o L) es una matriz triangular superior (o inferior) unitaria,
!> U**H (o L**H) es la conjugada de U (o L), P es una matriz de permutación,
!> P**T es la transpuesta de P, y D es Hermitiana y diagonal por bloques
!> con bloques diagonales de 1x1 y 2x2.
!>
!> Esta es la versión bloqueada del algoritmo, que llama a BLAS de Nivel 3.
!> Para más información, consulte la sección Detalles Adicionales.
!>

Parámetros

UPLO 
!>          UPLO es CHARACTER*1
!>          Especifica si la parte triangular superior o inferior de
!>          la matriz Hermitiana A está almacenada:
!>          = 'U':  Triangular superior
!>          = 'L':  Triangular inferior
!>

N

!>          N es INTEGER
!>          El orden de la matriz A.  N >= 0.
!>

A

!>          A es una matriz de COMPLEX*16, dimensión (LDA,N)
!>          En la entrada, la matriz Hermitiana A.
!>            Si UPLO = 'U': la parte superior N x N de A contiene la parte triangular superior de la matriz A,
!>            y la parte estrictamente triangular inferior de A no se referencia.
!>
!>            Si UPLO = 'L': la parte inferior N x N de A contiene la parte triangular inferior de la matriz A,
!>            y la parte estrictamente triangular superior de A no se referencia.
!>
!>          En la salida, contiene:
!>            a) SOLO los elementos diagonales de la matriz Hermitiana diagonal por bloques
!>               D en la diagonal de A, es decir, D(k,k) = A(k,k);
!>               (los elementos superdiagonales (o subdiagonales) de D
!>                se almacenan en la salida en el array E), y
!>            b) Si UPLO = 'U': el factor U en la parte superdiagonal de A.
!>               Si UPLO = 'L': el factor L en la parte subdiagonal de A.
!>

LDA

!>          LDA es INTEGER
!>          La dimensión principal del array A.  LDA >= max(1,N).
!>

E

!>          E es una matriz de COMPLEX*16, dimensión (N)
!>          En la salida, contiene los elementos superdiagonales (o subdiagonales)
!>          de la matriz Hermitiana diagonal por bloques D
!>          con bloques diagonales de 1x1 o 2x2, donde
!>          Si UPLO = 'U': E(i) = D(i-1,i), i=2:N, E(1) se establece a 0;
!>          Si UPLO = 'L': E(i) = D(i+1,i), i=1:N-1, E(N) se establece a 0.
!>
!>          NOTA: Para un bloque diagonal de 1x1 D(k), donde
!>          1 <= k <= N, el elemento E(k) se establece a 0 en ambos
!>          casos UPLO = 'U' o UPLO = 'L'.
!>

IPIV

!>          IPIV es una matriz de INTEGER, dimensión (N)
!>          IPIV describe la matriz de permutación P en la factorización
!>          de la matriz A de la siguiente manera. El valor absoluto de IPIV(k)
!>          representa el índice de la fila y columna que fueron
!>          intercambiadas con la fila y columna k. El valor de UPLO
!>          describe el orden en que se aplicaron los intercambios.
!>          Además, el signo de IPIV representa la estructura de bloques
!>          de la matriz Hermitiana diagonal por bloques D con bloques
!>          de 1x1 o 2x2 que corresponden a 1 o 2 intercambios
!>          en cada paso de factorización. Para más información, véase la sección
!>          Detalles Adicionales.
!>
!>          Si UPLO = 'U',
!>          ( en orden de factorización, k disminuye de N a 1 ):
!>            a) Una única entrada positiva IPIV(k) > 0 significa:
!>               D(k,k) es un bloque diagonal de 1x1.
!>               Si IPIV(k) != k, las filas y columnas k e IPIV(k) fueron
!>               intercambiadas en la matriz A(1:N,1:N);
!>               Si IPIV(k) = k, no hubo intercambio.
!>
!>            b) Un par de entradas consecutivas negativas
!>               IPIV(k) < 0 e IPIV(k-1) < 0 significa:
!>               D(k-1:k,k-1:k) es un bloque diagonal de 2x2.
!>               (NOTA: las entradas negativas en IPIV aparecen SOLO en pares).
!>               1) Si -IPIV(k) != k, las filas y columnas
!>                  k y -IPIV(k) fueron intercambiadas
!>                  en la matriz A(1:N,1:N).
!>                  Si -IPIV(k) = k, no hubo intercambio.
!>               2) Si -IPIV(k-1) != k-1, las filas y columnas
!>                  k-1 y -IPIV(k-1) fueron intercambiadas
!>                  en la matriz A(1:N,1:N).
!>                  Si -IPIV(k-1) = k-1, no hubo intercambio.
!>
!>            c) En ambos casos a) y b), siempre ABS( IPIV(k) ) <= k.
!>
!>            d) NOTA: Cualquier entrada IPIV(k) es siempre DISTINTA DE CERO en la salida.
!>
!>          Si UPLO = 'L',
!>          ( en orden de factorización, k aumenta de 1 a N ):
!>            a) Una única entrada positiva IPIV(k) > 0 significa:
!>               D(k,k) es un bloque diagonal de 1x1.
!>               Si IPIV(k) != k, las filas y columnas k e IPIV(k) fueron
!>               intercambiadas en la matriz A(1:N,1:N).
!>               Si IPIV(k) = k, no hubo intercambio.
!>
!>            b) Un par de entradas consecutivas negativas
!>               IPIV(k) < 0 e IPIV(k+1) < 0 significa:
!>               D(k:k+1,k:k+1) es un bloque diagonal de 2x2.
!>               (NOTA: las entradas negativas en IPIV aparecen SOLO en pares).
!>               1) Si -IPIV(k) != k, las filas y columnas
!>                  k y -IPIV(k) fueron intercambiadas
!>                  en la matriz A(1:N,1:N).
!>                  Si -IPIV(k) = k, no hubo intercambio.
!>               2) Si -IPIV(k+1) != k+1, las filas y columnas
!>                  k y -IPIV(k+1) fueron intercambiadas
!>                  en la matriz A(1:N,1:N).
!>                  Si -IPIV(k+1) = k+1, no hubo intercambio.
!>
!>            c) En ambos casos a) y b), siempre ABS( IPIV(k) ) >= k.
!>
!>            d) NOTA: Cualquier entrada IPIV(k) es siempre DISTINTA DE CERO en la salida.
!>

WORK

!>          WORK es una matriz de COMPLEX*16, dimensión (MAX(1,LWORK)).
!>          En la salida, si INFO = 0, WORK(1) devuelve el LWORK óptimo.
!>

LWORK

!>          LWORK es INTEGER
!>          La longitud de WORK.  LWORK >= 1.  Para un rendimiento óptimo
!>          LWORK >= N*NB, donde NB es el tamaño del bloque devuelto
!>          por ILAENV.
!>
!>          Si LWORK = -1, entonces se asume una consulta de espacio de trabajo;
!>          la subrutina solo calcula el tamaño óptimo del array WORK,
!>          devuelve este valor como la primera entrada del array WORK,
!>          y XERBLA no emite ningún mensaje de error relacionado con LWORK.
!>

INFO

!>          INFO es INTEGER
!>          = 0: finalización exitosa
!>
!>          < 0: Si INFO = -k, el argumento k tuvo un valor ilegal
!>
!>          > 0: Si INFO = k, la matriz A es singular, debido a:
!>                 Si UPLO = 'U': la columna k en la parte
!>                 triangular superior de A contiene todos ceros.
!>                 Si UPLO = 'L': la columna k en la parte
!>                 triangular inferior de A contiene todos ceros.
!>
!>               Por lo tanto, D(k,k) es exactamente cero, y los elementos superdiagonales
!>               de la columna k de U (o los elementos subdiagonales de
!>               la columna k de L) son todos ceros. La factorización se ha
!>               completado, pero la matriz diagonal por bloques D
!>               es exactamente singular, lo que significa que la matriz A
!>               no es invertible.
!>

NAME

zhetrf_rk - Computes the factorization of a general matrix of the form:

     A = P * K * D * K**H * T

where P is a permutation matrix, K is a unitary matrix, D is Hermitian and block diagonal with 1-by-1 and 2-by-2 diagonal blocks, and T is a unit upper triangular matrix. Zhetf_rk is the minimum-storage in-place sub-routine for ZHEEQU/ZHEEQUB.

SYNOPSIS

 SUBROUTINE ZHETRF_RK(UPLO, N, A, LDA, IPIV, TAU, INFO)

Parameters

UPLO
CHARACTER*1

Specifies whether the matrix A is upper or lower Hermitian:

'U'
A is upper Hermitian.
'L'
A is lower Hermitian.

N
INTEGER

The order of the matrix A. N >= 0.

A
COMPLEX*16 array, dimension (LDA,N)

On entry, the Hermitian matrix A. On exit, the details of the factorization are stored in the upper or lower triangle of A, overwriting the input matrix A.

LDA
INTEGER

The leading dimension of the array A. LDA >= max(1,N).

IPIV
INTEGER array, dimension (N)

Details of the interchanges and the structure of D. If IPIV(i) > 0, then rows and columns i and IPIV(i) were interchanged and D(i) is a 1-by-1 block. If IPIV(i) < 0, then rows and columns i and -IPIV(i) were interchanged and D(i) is a 2-by-2 block.

If UPLO = 'U' and IPIV(i) < 0, then D(i) corresponds to the block D(i:i+1,i:i+1) and the subdiagonal element is stored in A(i+1,i). If UPLO = 'L' and IPIV(i) < 0, then D(i) corresponds to the block D(i:i+1,i:i+1) and the superdiagonal element is stored in A(i,i+1).

TAU
COMPLEX*16 array, dimension (N)

The auxiliary information used in the recursive updates and transformations of the matrix A.

INFO
INTEGER

= 0: Successful exit.

< 0: If INFO = -i, the i-th argument had an illegal value.

> 0: If INFO = i, then D(i,i) is zero. Division by zero will occur if D is used to solve a system of equations.

NOTE: INFO only stores the first occurrence of a singularity, any subsequent occurrence of singularity is not stored in INFO even though the factorization always completes.
