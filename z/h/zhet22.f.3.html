Documentación de Función/Subrutina

subrutina zhet22 (integer itype, character uplo, integer n, integer m, integer kband, complex*16, dimension( lda, * ) a, integer lda, double precision, dimension( * ) d, double precision, dimension( * ) e, complex*16, dimension( ldu, * ) u, integer ldu, complex*16, dimension( ldv, * ) v, integer ldv, complex*16, dimension( * ) tau, complex*16, dimension( * ) work, double precision, dimension( * ) rwork, double precision, dimension( 2 ) result)

ZHET22

Propósito:

!>
!>      ZHET22  generalmente comprueba una descomposición de la forma
!>
!>              A U = U S
!>
!>      donde A es Hermitiana compleja, las columnas de U son ortonormales,
!>      y S es diagonal (si KBAND=0) o simétrica tridiagonal (si
!>      KBAND=1).  Si ITYPE=1, entonces U se representa como una matriz densa,
!>      de lo contrario, U se expresa como un producto de transformaciones
!>      de Householder, cuyos vectores se almacenan en el array  y
!>      cuyas constantes de escalado están en  
 usaremos la letra
!>       para referirnos al producto de transformaciones de Householder
!>      (que debería ser igual a U).
!>
!>      Específicamente, si ITYPE=1, entonces:
!>
!>              RESULT(1) = | U**H A U - S | / ( |A| m ulp ) y
!>              RESULT(2) = | I - U**H U | / ( m ulp )
!> 
!>  ITYPE   INTEGER
!>          Especifica el tipo de pruebas a realizar.
!>          1: U expresada como una matriz ortogonal densa:
!>             RESULT(1) = | A - U S U**H | / ( |A| n ulp )   *y
!>             RESULT(2) = | I - U U**H | / ( n ulp )
!>
!>  UPLO    CHARACTER
!>          Si UPLO='U', se utilizará el triángulo superior de A y no se
!>          referenciará el triángulo (estrictamente) inferior. Si
!>          UPLO='L', se utilizará el triángulo inferior de A y no se
!>          referenciará el triángulo (estrictamente) superior.
!>          No modificado.
!>
!>  N       INTEGER
!>          El tamaño de la matriz. Si es cero, ZHET22 no hace nada.
!>          Debe ser al menos cero.
!>          No modificado.
!>
!>  M       INTEGER
!>          El número de columnas de U. Si es cero, ZHET22 no hace
!>          nada. Debe ser al menos cero.
!>          No modificado.
!>
!>  KBAND   INTEGER
!>          El ancho de banda de la matriz. Solo puede ser cero o uno.
!>          Si es cero, S es diagonal y E no se referencia. Si
!>          es uno, S es simétrica tridiagonal.
!>          No modificado.
!>
!>  A       Arreglo COMPLEX*16, dimensión (LDA , N)
!>          La matriz original (no factorizada). Se asume que es
!>          simétrica, y solo se referenciará la parte superior (UPLO='U')
!>          o solo la inferior (UPLO='L').
!>          No modificado.
!>
!>  LDA     INTEGER
!>          La dimensión principal de A. Debe ser al menos 1
!>          y al menos N.
!>          No modificado.
!>
!>  D       Arreglo DOUBLE PRECISION, dimensión (N)
!>          La diagonal de la matriz (simétrica tri-) diagonal.
!>          No modificado.
!>
!>  E       Arreglo DOUBLE PRECISION, dimensión (N)
!>          La subdiagonal de la matriz (simétrica tri-) diagonal.
!>          Se ignora E(1), E(2) es el elemento (1,2) y (2,1), etc.
!>          No se referencia si KBAND=0.
!>          No modificado.
!>
!>  U       Arreglo COMPLEX*16, dimensión (LDU, N)
!>          Si ITYPE=1, contiene la matriz ortogonal en
!>          la descomposición, expresada como una matriz densa.
!>          No modificado.
!>
!>  LDU     INTEGER
!>          La dimensión principal de U. LDU debe ser al menos N y
!>          al menos 1.
!>          No modificado.
!>
!>  V       Arreglo COMPLEX*16, dimensión (LDV, N)
!>          Si ITYPE=2 o 3, el triángulo inferior de este array contiene
!>          los vectores de Householder que describen la matriz ortogonal
!>          en la descomposición. Si ITYPE=1, entonces no se referencia.
!>          No modificado.
!>
!>  LDV     INTEGER
!>          La dimensión principal de V. LDV debe ser al menos N y
!>          al menos 1.
!>          No modificado.
!>
!>  TAU     Arreglo COMPLEX*16, dimensión (N)
!>          Si ITYPE >= 2, entonces TAU(j) es el factor escalar de
!>          v(j) v(j)**H en la transformación de Householder H(j) de
!>          el producto  U = H(1)...H(n-2)
!>          Si ITYPE < 2, entonces TAU no se referencia.
!>          No modificado.
!>
!>  WORK    Arreglo COMPLEX*16, dimensión (2*N**2)
!>          Espacio de trabajo.
!>          Modificado.
!>
!>  RWORK   Arreglo DOUBLE PRECISION, dimensión (N)
!>          Espacio de trabajo.
!>          Modificado.
!>
!>  RESULT  Arreglo DOUBLE PRECISION, dimensión (2)
!>          Los valores calculados por las dos pruebas descritas anteriormente.
!>          Los valores están actualmente limitados a 1/ulp, para evitar
!>          desbordamiento.
!>          RESULT(1) se modifica siempre. RESULT(2) se modifica solo
!>          si LDU es al menos N.
!>          Modificado.
!>
