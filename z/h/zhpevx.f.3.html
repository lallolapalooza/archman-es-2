ZHPEVX calcula los valores propios y, opcionalmente, los vectores propios izquierdos y/o derechos para OTRAS matrices

Documentación de Función/Subrutina

subrutina zhpevx (carácter jobz, carácter range, carácter uplo, entero n, complex*16, dimensión( * ) ap, double precision vl, double precision vu, entero il, entero iu, double precision abstol, entero m, double precision, dimensión( * ) w, complex*16, dimensión( ldz, * ) z, entero ldz, complex*16, dimensión( * ) work, double precision, dimensión( * ) rwork, entero, dimensión( * ) iwork, entero, dimensión( * ) ifail, entero info)

ZHPEVX calcula valores propios seleccionados y, opcionalmente, vectores propios para matrices Hermitianas complejas A en almacenamiento empaquetado.

Propósito:

!>
!> ZHPEVX calcula valores propios seleccionados y, opcionalmente, vectores
!> propios de una matriz Hermitiana compleja A en almacenamiento empaquetado.
!> Los valores/vectores propios pueden ser seleccionados especificando un rango
!> de valores o un rango de índices para los valores propios deseados.
!>

Parámetros

JOBZ 
!>          JOBZ es CHARACTER*1
!>          = 'N':  Calcular solo valores propios;
!>          = 'V':  Calcular valores propios y vectores propios.
!>

RANGE

!>          RANGE es CHARACTER*1
!>          = 'A': se encontrarán todos los valores propios;
!>          = 'V': se encontrarán todos los valores propios en el intervalo semiabierto (VL,VU]
!>                 ;
!>          = 'I': se encontrarán los valores propios desde el IL-ésimo hasta el IU-ésimo.
!>

UPLO

!>          UPLO es CHARACTER*1
!>          = 'U':  El triángulo superior de A está almacenado;
!>          = 'L':  El triángulo inferior de A está almacenado.
!>

N

!>          N es INTEGER
!>          El orden de la matriz A.  N >= 0.
!>

AP

!>          AP es un array COMPLEX*16, dimensión (N*(N+1)/2)
!>          En la entrada, el triángulo superior o inferior de la matriz Hermitiana
!>          A, empaquetado por columnas en un array lineal. La j-ésima columna de A
!>          se almacena en el array AP como sigue:
!>          si UPLO = 'U', AP(i + (j-1)*j/2) = A(i,j) para 1<=i<=j;
!>          si UPLO = 'L', AP(i + (j-1)*(2*n-j)/2) = A(i,j) para j<=i<=n.
!>
!>          En la salida, AP se sobrescribe con valores generados durante la
!>          reducción a forma tridiagonal. Si UPLO = 'U', la diagonal
!>          y la primera superdiagonal de la matriz tridiagonal T sobrescriben
!>          los elementos correspondientes de A, y si UPLO = 'L', la
!>          diagonal y la primera subdiagonal de T sobrescriben los
!>          elementos correspondientes de A.
!>

VL

!>          VL es DOUBLE PRECISION
!>          Si RANGE='V', el límite inferior del intervalo a
!>          buscar para los valores propios. VL < VU.
!>          No se usa si RANGE = 'A' o 'I'.
!>

VU

!>          VU es DOUBLE PRECISION
!>          Si RANGE='V', el límite superior del intervalo a
!>          buscar para los valores propios. VL < VU.
!>          No se usa si RANGE = 'A' o 'I'.
!>

IL

!>          IL es INTEGER
!>          Si RANGE='I', el índice del
!>          valor propio más pequeño a devolver.
!>          1 <= IL <= IU <= N, si N > 0; IL = 1 y IU = 0 si N = 0.
!>          No se usa si RANGE = 'A' o 'V'.
!>

IU

!>          IU es INTEGER
!>          Si RANGE='I', el índice del
!>          valor propio más grande a devolver.
!>          1 <= IL <= IU <= N, si N > 0; IL = 1 y IU = 0 si N = 0.
!>          No se usa si RANGE = 'A' o 'V'.
!>

ABSTOL

!>          ABSTOL es DOUBLE PRECISION
!>          La tolerancia de error absoluta para los valores propios.
!>          Un valor propio aproximado se acepta como convergente
!>          cuando se determina que yace en un intervalo [a,b]
!>          de ancho menor o igual a
!>
!>                  ABSTOL + EPS *   max( |a|,|b| ) ,
!>
!>          donde EPS es la precisión de la máquina. Si ABSTOL es menor o
!>          igual que cero, entonces EPS*|T| se usará en su lugar,
!>          donde |T| es la norma 1 de la matriz tridiagonal obtenida
!>          al reducir AP a forma tridiagonal.
!>
!>          Los valores propios se calcularán con mayor precisión cuando ABSTOL
!>          se establezca en el doble del umbral de subdesbordamiento 2*DLAMCH('S'),
!>          no cero.
!>          Si esta rutina retorna con INFO>0, indicando que algunos
!>          vectores propios no convergieron, intente establecer ABSTOL en
!>          2*DLAMCH('S').
!>
!>          Ver por Demmel y
!>          Kahan, LAPACK Working Note #3.
!>

M

!>          M es INTEGER
!>          El número total de valores propios encontrados.  0 <= M <= N.
!>          Si RANGE = 'A', M = N, y si RANGE = 'I', M = IU-IL+1.
!>

W

!>          W es un array DOUBLE PRECISION, dimensión (N)
!>          Si INFO = 0, los valores propios seleccionados en orden ascendente.
!>

Z

!>          Z es un array COMPLEX*16, dimensión (LDZ, max(1,M))
!>          Si JOBZ = 'V', entonces si INFO = 0, las primeras M columnas de Z
!>          contienen los vectores propios ortonormales de la matriz A
!>          correspondientes a los valores propios seleccionados, con la i-ésima
!>          columna de Z conteniendo el vector propio asociado con W(i).
!>          Si un vector propio falla en converger, entonces esa columna de Z
!>          contiene la última aproximación al vector propio, y
!>          el índice del vector propio se devuelve en IFAIL.
!>          Si JOBZ = 'N', entonces Z no se usa.
!>          Nota: el usuario debe asegurarse de que se suministran al menos
!>          max(1,M) columnas en el array Z; si RANGE = 'V', el valor exacto de M
!>          no se conoce de antemano y se debe usar un límite superior.
!>

LDZ

!>          LDZ es INTEGER
!>          La dimensión principal del array Z.  LDZ >= 1, y si
!>          JOBZ = 'V', LDZ >= max(1,N).
!>

WORK

!>          WORK es un array COMPLEX*16, dimensión (2*N)
!>

RWORK

!>          RWORK es un array DOUBLE PRECISION, dimensión (7*N)
!>

IWORK

!>          IWORK es un array INTEGER, dimensión (5*N)
!>

IFAIL

!>          IFAIL es un array INTEGER, dimensión (N)
!>          Si JOBZ = 'V', entonces si INFO = 0, los primeros M elementos de
!>          IFAIL son cero.  Si INFO > 0, entonces IFAIL contiene los
!>          índices de los vectores propios que fallaron en converger.
!>          Si JOBZ = 'N', entonces IFAIL no se usa.
!>

INFO

!>          INFO es INTEGER
!>          = 0:  salida exitosa
!>          < 0:  si INFO = -i, entonces el i-ésimo argumento tenía un valor ilegal
!>          > 0:  si INFO = i, entonces i vectores propios fallaron en converger.
!>                Sus índices están almacenados en el array IFAIL.
!>
