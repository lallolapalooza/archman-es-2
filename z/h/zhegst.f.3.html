subrutina zhegst (integer itype, character uplo, integer n, complex*16, dimension( lda, * ) a, integer lda, complex*16, dimension( ldb, * ) b, integer ldb, integer info)

ZHEGST

Propósito:

!>
!> ZHEGST reduce un problema generalizado de autovalores hermitiano-definido complejo a la forma estándar.
!>
!> Si ITYPE = 1, el problema es A*x = lambda*B*x,
!> y A se sobrescribe con inv(U**H)*A*inv(U) o inv(L)*A*inv(L**H)
!>
!> Si ITYPE = 2 o 3, el problema es A*B*x = lambda*x o
!> B*A*x = lambda*x, y A se sobrescribe con U*A*U**H o L**H*A*L.
!>
!> B debe haber sido previamente factorizado como U**H*U o L*L**H por ZPOTRF.
!>

Parámetros

ITYPE 
!>          ITYPE es INTEGER
!>          = 1: calcula inv(U**H)*A*inv(U) o inv(L)*A*inv(L**H);
!>          = 2 o 3: calcula U*A*U**H o L**H*A*L.
!>

UPLO

!>          UPLO es CHARACTER*1
!>          = 'U':  el triángulo superior de A se almacena y B se factoriza como
!>                  U**H*U;
!>          = 'L':  el triángulo inferior de A se almacena y B se factoriza como
!>                  L*L**H.
!>

N

!>          N es INTEGER
!>          El orden de las matrices A y B.  N >= 0.
!>

A

!>          A es un array COMPLEX*16, dimensión (LDA,N)
!>          En la entrada, la matriz Hermitiana A.  Si UPLO = 'U', la parte
!>          triangular superior N por N líder contiene la parte triangular superior
!>          de la matriz A, y la parte estrictamente triangular inferior de A no se referencia.
!>          Si UPLO = 'L', la parte triangular inferior N por N líder contiene la parte triangular inferior
!>          de la matriz A, y la parte estrictamente triangular superior de A no se referencia.
!>
!>          En la salida, si INFO = 0, la matriz transformada, almacenada en el
!>          mismo formato que A.
!>

LDA

!>          LDA es INTEGER
!>          La dimensión líder del array A.  LDA >= max(1,N).
!>

B

!>          B es un array COMPLEX*16, dimensión (LDB,N)
!>          El factor triangular de la factorización de Cholesky de B,
!>          tal como es devuelto por ZPOTRF.
!>          B es modificado por la rutina pero restaurado en la salida.
!>

LDB

!>          LDB es INTEGER
!>          La dimensión líder del array B.  LDB >= max(1,N).
!>

INFO

!>          INFO es INTEGER
!>          = 0:  salida exitosa
!>          < 0:  si INFO = -i, el argumento i tenía un valor ilegal
!>
