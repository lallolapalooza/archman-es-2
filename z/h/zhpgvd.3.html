DOCUMENTACIÓN DE FUNCIÓN/SUBRUTINA

subrutina zhpgvd (integer itype, character jobz, character uplo, integer n, complex*16, dimension( * ) ap, complex*16, dimension( * ) bp, double precision, dimension( * ) w, complex*16, dimension( ldz, * ) z, integer ldz, complex*16, dimension( * ) work, integer lwork, double precision, dimension( * ) rwork, integer lrwork, integer, dimension( * ) iwork, integer liwork, integer info)

ZHPGVD

Propósito:

!>
!> ZHPGVD calcula todos los valores propios y, opcionalmente, los vectores propios
!> de un problema de valores propios generalizado hermitiano-definido complejo,
!> de la forma A*x=(lambda)*B*x,  A*Bx=(lambda)*x,  o B*A*x=(lambda)*x. Aquí A y
!> B se suponen Hermitianas, almacenadas en formato empaquetado, y B es también
!> positiva definida.
!> Si se desean vectores propios, utiliza un algoritmo de división y conquista.
!>
!>

Parámetros

ITYPE 
!>          ITYPE es INTEGER
!>          Especifica el tipo de problema a resolver:
!>          = 1:  A*x = (lambda)*B*x
!>          = 2:  A*B*x = (lambda)*x
!>          = 3:  B*A*x = (lambda)*x
!>

JOBZ

!>          JOBZ es CHARACTER*1
!>          = 'N':  Calcular solo los valores propios;
!>          = 'V':  Calcular valores propios y vectores propios.
!>

UPLO

!>          UPLO es CHARACTER*1
!>          = 'U':  Se almacenan los triángulos superiores de A y B;
!>          = 'L':  Se almacenan los triángulos inferiores de A y B.
!>

N

!>          N es INTEGER
!>          El orden de las matrices A y B.  N >= 0.
!>

AP

!>          AP es un array COMPLEX*16, de dimensión (N*(N+1)/2)
!>          En la entrada, el triángulo superior o inferior de la matriz Hermitiana
!>          A, empaquetado por columnas en un array lineal. La j-ésima columna de A
!>          se almacena en el array AP de la siguiente manera:
!>          si UPLO = 'U', AP(i + (j-1)*j/2) = A(i,j) para 1<=i<=j;
!>          si UPLO = 'L', AP(i + (j-1)*(2*n-j)/2) = A(i,j) para j<=i<=n.
!>
!>          En la salida, el contenido de AP se destruye.
!>

BP

!>          BP es un array COMPLEX*16, de dimensión (N*(N+1)/2)
!>          En la entrada, el triángulo superior o inferior de la matriz Hermitiana
!>          B, empaquetado por columnas en un array lineal. La j-ésima columna de B
!>          se almacena en el array BP de la siguiente manera:
!>          si UPLO = 'U', BP(i + (j-1)*j/2) = B(i,j) para 1<=i<=j;
!>          si UPLO = 'L', BP(i + (j-1)*(2*n-j)/2) = B(i,j) para j<=i<=n.
!>
!>          En la salida, el factor triangular U o L de la factorización de Cholesky
!>          B = U**H*U o B = L*L**H, en el mismo formato de almacenamiento
!>          que B.
!>

W

!>          W es un array DOUBLE PRECISION, de dimensión (N)
!>          Si INFO = 0, los valores propios en orden ascendente.
!>

Z

!>          Z es un array COMPLEX*16, de dimensión (LDZ, N)
!>          Si JOBZ = 'V', entonces si INFO = 0, Z contiene la matriz Z de
!>          vectores propios. Los vectores propios se normalizan de la siguiente manera:
!>          si ITYPE = 1 o 2, Z**H*B*Z = I;
!>          si ITYPE = 3, Z**H*inv(B)*Z = I.
!>          Si JOBZ = 'N', entonces Z no se referencia.
!>

LDZ

!>          LDZ es INTEGER
!>          La dimensión principal del array Z.  LDZ >= 1, y si
!>          JOBZ = 'V', LDZ >= max(1,N).
!>

WORK

!>          WORK es un array COMPLEX*16, de dimensión (MAX(1,LWORK))
!>          En la salida, si INFO = 0, WORK(1) devuelve el LWORK requerido.
!>

LWORK

!>          LWORK es INTEGER
!>          La dimensión del array WORK.
!>          Si N <= 1,               LWORK >= 1.
!>          Si JOBZ = 'N' y N > 1, LWORK >= N.
!>          Si JOBZ = 'V' y N > 1, LWORK >= 2*N.
!>
!>          Si LWORK = -1, entonces se asume una consulta de espacio de trabajo; la rutina
!>          solo calcula los tamaños requeridos de los arrays WORK, RWORK e
!>          IWORK, devuelve estos valores como las primeras entradas de
!>          los arrays WORK, RWORK e IWORK, y XERBLA no emite ningún mensaje de error
!>          relacionado con LWORK, LRWORK o LIWORK.
!>

RWORK

!>          RWORK es un array DOUBLE PRECISION, de dimensión (MAX(1,LRWORK))
!>          En la salida, si INFO = 0, RWORK(1) devuelve el LRWORK requerido.
!>

LRWORK

!>          LRWORK es INTEGER
!>          La dimensión del array RWORK.
!>          Si N <= 1,               LRWORK >= 1.
!>          Si JOBZ = 'N' y N > 1, LRWORK >= N.
!>          Si JOBZ = 'V' y N > 1, LRWORK >= 1 + 5*N + 2*N**2.
!>
!>          Si LRWORK = -1, entonces se asume una consulta de espacio de trabajo; la
!>          rutina solo calcula los tamaños requeridos de los arrays WORK, RWORK
!>          e IWORK, devuelve estos valores como las primeras entradas de
!>          los arrays WORK, RWORK e IWORK, y XERBLA no emite ningún mensaje de error
!>          relacionado con LWORK, LRWORK o LIWORK.
!>

IWORK

!>          IWORK es un array INTEGER, de dimensión (MAX(1,LIWORK))
!>          En la salida, si INFO = 0, IWORK(1) devuelve el LIWORK requerido.
!>

LIWORK

!>          LIWORK es INTEGER
!>          La dimensión del array IWORK.
!>          Si JOBZ  = 'N' o N <= 1, LIWORK >= 1.
!>          Si JOBZ  = 'V' y N > 1, LIWORK >= 3 + 5*N.
!>
!>          Si LIWORK = -1, entonces se asume una consulta de espacio de trabajo; la
!>          rutina solo calcula los tamaños requeridos de los arrays WORK, RWORK
!>          e IWORK, devuelve estos valores como las primeras entradas de
!>          los arrays WORK, RWORK e IWORK, y XERBLA no emite ningún mensaje de error
!>          relacionado con LWORK, LRWORK o LIWORK.
!>

INFO

!>          INFO es INTEGER
!>          = 0:  salida exitosa
!>          < 0:  si INFO = -i, el i-ésimo argumento tenía un valor ilegal
!>          > 0:  ZPPTRF o ZHPEVD devolvieron un código de error:
!>             <= N:  si INFO = i, ZHPEVD no convergió;
!>                    i elementos fuera de la diagonal de una forma tridiagonal intermedia
!>                    no convergieron a cero;
!>             > N:   si INFO = N + i, para 1 <= i <= n, entonces el menor principal
!>                    principal de orden i de B no es positivo.
!>                    La factorización de B no pudo completarse y
!>                    no se calcularon valores propios ni vectores propios.
!>
