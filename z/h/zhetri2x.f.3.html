Documentación de la función/subrutina

subroutine zhetri2x (character uplo, integer n, complex*16, dimension( lda, * ) a, integer lda, integer, dimension( * ) ipiv, complex*16, dimension( n+nb+1,* ) work, integer nb, integer info)

ZHETRI2X

Propósito:

!>
!> ZHETRI2X calcula la inversa de una matriz Hermítica indefinida COMPLEX*16
!> A utilizando la factorización A = U*D*U**H o A = L*D*L**H calculada por
!> ZHETRF.
!>

Parámetros

UPLO 
!>          UPLO es CHARACTER*1
!>          Especifica si los detalles de la factorización se almacenan
!>          como una matriz triangular superior o inferior.
!>          = 'U': Triangular superior, forma es A = U*D*U**H;
!>          = 'L': Triangular inferior, forma es A = L*D*L**H.
!>

N

!>          N es INTEGER
!>          El orden de la matriz A.  N >= 0.
!>

A

!>          A es un array COMPLEX*16, de dimensión (LDA,N)
!>          A la entrada, la matriz diagonal D de NNB y los multiplicadores
!>          utilizados para obtener el factor U o L calculados por ZHETRF.
!>
!>          A la salida, si INFO = 0, la inversa (simétrica) de la matriz
!>          original.  Si UPLO = 'U', se forma la parte triangular superior
!>          de la inversa y la parte de A por debajo de la diagonal no se
!>          referencia; si UPLO = 'L' se forma la parte triangular inferior
!>          de la inversa y la parte de A por encima de la diagonal no se
!>          referencia.
!>

LDA

!>          LDA es INTEGER
!>          La dimensión principal del array A.  LDA >= max(1,N).
!>

IPIV

!>          IPIV es un array INTEGER, de dimensión (N)
!>          Detalles de los intercambios y la estructura NNB de D
!>          tal como se determinó por ZHETRF.
!>

WORK

!>          WORK es un array COMPLEX*16, de dimensión (N+NB+1,NB+3)
!>

NB

!>          NB es INTEGER
!>          Tamaño del bloque
!>

INFO

!>          INFO es INTEGER
!>          = 0: salida exitosa
!>          < 0: si INFO = -i, el i-ésimo argumento tenía un valor ilegal
!>          > 0: si INFO = i, D(i,i) = 0; la matriz es singular y su
!>               inversa no pudo ser calculada.
!>
