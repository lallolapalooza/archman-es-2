Documentación de función/subrutina

subroutine zhsein (character side, character eigsrc, character initv, logical, dimension( * ) select, integer n, complex*16, dimension( ldh, * ) h, integer ldh, complex*16, dimension( * ) w, complex*16, dimension( ldvl, * ) vl, integer ldvl, complex*16, dimension( ldvr, * ) vr, integer ldvr, integer mm, integer m, complex*16, dimension( * ) work, double precision, dimension( * ) rwork, integer, dimension( * ) ifaill, integer, dimension( * ) ifailr, integer info)

ZHSEIN

Propósito:

!>
!> ZHSEIN utiliza iteración inversa para encontrar los autovectores derechos y/o izquierdos especificados
!> de una matriz compleja superior de Hessenberg H.
!>
!> El autovector derecho x y el autovector izquierdo y de la matriz H
!> correspondientes a un autovalor w se definen por:
!>
!>              H * x = w * x,     y**h * H = w * y**h
!>
!> donde y**h denota la transpuesta conjugada del vector y.
!>

Parámetros

SIDE 
!>          SIDE es CHARACTER*1
!>          = 'R': calcular solo autovectores derechos;
!>          = 'L': calcular solo autovectores izquierdos;
!>          = 'B': calcular ambos autovectores derechos e izquierdos.
!>

EIGSRC

!>          EIGSRC es CHARACTER*1
!>          Especifica la fuente de los autovalores suministrados en W:
!>          = 'Q': los autovalores se encontraron usando ZHSEQR; por lo tanto, si
!>                 H tiene elementos subdiagonales cero, y es
!>                 triangular por bloques, entonces el j-ésimo autovalor puede
!>                 asumirse como un autovalor del bloque que contiene
!>                 la fila/columna j. Esta propiedad permite a ZHSEIN
!>                 realizar iteración inversa solo en un bloque diagonal.
!>          = 'N': no se hacen suposiciones sobre la correspondencia
!>                 entre autovalores y bloques diagonales. En este
!>                 caso, ZHSEIN siempre debe realizar iteración inversa
!>                 usando la matriz H completa.
!>

INITV

!>          INITV es CHARACTER*1
!>          = 'N': no se proporcionan vectores iniciales;
!>          = 'U': se proporcionan vectores iniciales definidos por el usuario en los arrays
!>                 VL y/o VR.
!>

SELECT

!>          SELECT es un array LOGICAL, de dimensión (N)
!>          Especifica los autovectores a calcular. Para seleccionar el
!>          autovector correspondiente al autovalor W(j),
!>          SELECT(j) debe establecerse en .TRUE..
!>

N

!>          N es INTEGER
!>          El orden de la matriz H. N >= 0.
!>

H

!>          H es un array COMPLEX*16, de dimensión (LDH,N)
!>          La matriz de Hessenberg superior H.
!>          Si se detecta un NaN en H, la rutina devolverá con INFO=-6.
!>

LDH

!>          LDH es INTEGER
!>          La dimensión principal del array H. LDH >= max(1,N).
!>

W

!>          W es un array COMPLEX*16, de dimensión (N)
!>          En la entrada, los autovalores de H.
!>          En la salida, las partes reales de W pueden haber sido alteradas ya que
!>          los autovalores cercanos se perturban ligeramente al buscar
!>          autovectores independientes.
!>

VL

!>          VL es un array COMPLEX*16, de dimensión (LDVL,MM)
!>          En la entrada, si INITV = 'U' y SIDE = 'L' o 'B', VL debe
!>          contener vectores iniciales para la iteración inversa de los
!>          autovectores izquierdos; el vector inicial para cada autovector
!>          debe estar en la misma columna en la que se almacenará el autovector.
!>          En la salida, si SIDE = 'L' o 'B', los autovectores izquierdos
!>          especificados por SELECT se almacenarán consecutivamente en las
!>          columnas de VL, en el mismo orden que sus autovalores.
!>          Si SIDE = 'R', VL no se referencia.
!>

LDVL

!>          LDVL es INTEGER
!>          La dimensión principal del array VL.
!>          LDVL >= max(1,N) si SIDE = 'L' o 'B'; LDVL >= 1 en caso contrario.
!>

VR

!>          VR es un array COMPLEX*16, de dimensión (LDVR,MM)
!>          En la entrada, si INITV = 'U' y SIDE = 'R' o 'B', VR debe
!>          contener vectores iniciales para la iteración inversa de los
!>          autovectores derechos; el vector inicial para cada autovector
!>          debe estar en la misma columna en la que se almacenará el autovector.
!>          En la salida, si SIDE = 'R' o 'B', los autovectores derechos
!>          especificados por SELECT se almacenarán consecutivamente en las
!>          columnas de VR, en el mismo orden que sus autovalores.
!>          Si SIDE = 'L', VR no se referencia.
!>

LDVR

!>          LDVR es INTEGER
!>          La dimensión principal del array VR.
!>          LDVR >= max(1,N) si SIDE = 'R' o 'B'; LDVR >= 1 en caso contrario.
!>

MM

!>          MM es INTEGER
!>          El número de columnas en los arrays VL y/o VR. MM >= M.
!>

M

!>          M es INTEGER
!>          El número de columnas en los arrays VL y/o VR requeridas para
!>          almacenar los autovectores (= el número de elementos .TRUE. en
!>          SELECT).
!>

WORK

!>          WORK es un array COMPLEX*16, de dimensión (N*N)
!>

RWORK

!>          RWORK es un array DOUBLE PRECISION, de dimensión (N)
!>

IFAILL

!>          IFAILL es un array INTEGER, de dimensión (MM)
!>          Si SIDE = 'L' o 'B', IFAILL(i) = j > 0 si el autovector izquierdo en la i-ésima
!>          columna de VL (correspondiente al autovalor w(j)) no convergió; IFAILL(i) = 0 si el
!>          autovector convergió satisfactoriamente.
!>          Si SIDE = 'R', IFAILL no se referencia.
!>

IFAILR

!>          IFAILR es un array INTEGER, de dimensión (MM)
!>          Si SIDE = 'R' o 'B', IFAILR(i) = j > 0 si el autovector derecho en la i-ésima
!>          columna de VR (correspondiente al autovalor w(j)) no convergió; IFAILR(i) = 0 si el
!>          autovector convergió satisfactoriamente.
!>          Si SIDE = 'L', IFAILR no se referencia.
!>

INFO

!>          INFO es INTEGER
!>          = 0:  salida exitosa
!>          < 0:  si INFO = -i, el i-ésimo argumento tenía un valor ilegal
!>          > 0:  si INFO = i, i es el número de autovectores que no
!>                convergió; consulte IFAILL e IFAILR para más
!>                detalles.
!>

Detalles adicionales:

!>
!> Cada autovector se normaliza de manera que el elemento de mayor
!> magnitud tenga magnitud 1; aquí la magnitud de un número complejo
!> (x,y) se toma como |x|+|y|.
!>
