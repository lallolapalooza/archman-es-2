subroutine zhecon_rook (uplo, n, a, lda, ipiv, anorm, rcond, work, info)
ZHECON_ROOK estima la recíproca del número de condición para matrices HE utilizando la factorización obtenida con uno de los métodos de pivoteo diagonal acotado (máximo 2 intercambios)

Documentación de función/subrutina

subrutina zhecon_rook (character uplo, integer n, complex*16, dimension( lda, * ) a, integer lda, integer, dimension( * ) ipiv, double precision anorm, double precision rcond, complex*16, dimension( * ) work, integer info)

ZHECON_ROOK estima la recíproca del número de condición de una matriz Hermitiana compleja A utilizando la factorización A = U*D*U**H o A = L*D*L**H calculada por CHETRF_ROOK.

Propósito:

!>
!> ZHECON_ROOK estima la recíproca del número de condición de una matriz
!> Hermitiana compleja A utilizando la factorización A = U*D*U**H o
!> A = L*D*L**H calculada por CHETRF_ROOK.
!>
!> Se obtiene una estimación de norm(inv(A)), y la recíproca del
!> número de condición se calcula como RCOND = 1 / (ANORM * norm(inv(A))).
!>

Parámetros

UPLO 
!>          UPLO es CHARACTER*1
!>          Especifica si los detalles de la factorización se almacenan
!>          como una matriz triangular superior o inferior.
!>          = 'U':  Triangular superior, la forma es A = U*D*U**H;
!>          = 'L':  Triangular inferior, la forma es A = L*D*L**H.
!>

N

!>          N es INTEGER
!>          El orden de la matriz A.  N >= 0.
!>

A

!>          A es un array COMPLEX*16, de dimensión (LDA,N)
!>          La matriz diagonal por bloques D y los multiplicadores utilizados para
!>          obtener el factor U o L calculados por CHETRF_ROOK.
!>

LDA

!>          LDA es INTEGER
!>          La dimensión principal del array A.  LDA >= max(1,N).
!>

IPIV

!>          IPIV es un array INTEGER, de dimensión (N)
!>          Detalles de los intercambios y la estructura de bloques de D
!>          determinados por CHETRF_ROOK.
!>

ANORM

!>          ANORM es DOUBLE PRECISION
!>          La 1-norma de la matriz original A.
!>

RCOND

!>          RCOND es DOUBLE PRECISION
!>          La recíproca del número de condición de la matriz A,
!>          calculada como RCOND = 1/(ANORM * AINVNM), donde AINVNM es una
!>          estimación de la 1-norma de inv(A) calculada en esta rutina.
!>

WORK

!>          WORK es un array COMPLEX*16, de dimensión (2*N)
!>

INFO

!>          INFO es INTEGER
!>          = 0:  salida exitosa
!>          < 0:  si INFO = -i, el i-ésimo argumento tenía un valor ilegal
!>
