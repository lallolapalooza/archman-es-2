ZHEEVD_2STAGE calcula los valores propios y, opcionalmente, los vectores propios izquierdos y/o derechos para matrices HE

Propósito:

!>
!> ZHEEVD_2STAGE calcula todos los valores propios y, opcionalmente, los vectores propios de una
!> matriz Hermítica compleja A utilizando la técnica de 2 etapas para
!> la reducción a tridiagonal. Si se desean los vectores propios, utiliza un
!> algoritmo de divide y vencerás.
!>
!>

Parámetros

JOBZ 
!>          JOBZ es CHARACTER*1
!>          = 'N':  Calcular solo los valores propios;
!>          = 'V':  Calcular valores propios y vectores propios.
!>                  No disponible en esta versión.
!>

UPLO

!>          UPLO es CHARACTER*1
!>          = 'U':  El triángulo superior de A está almacenado;
!>          = 'L':  El triángulo inferior de A está almacenado.
!>

N

!>          N es INTEGER
!>          El orden de la matriz A.  N >= 0.
!>

A

!>          A es un array COMPLEX*16, dimensión (LDA, N)
!>          En la entrada, la matriz Hermítica A. Si UPLO = 'U', la
!>          parte superior triangular N por N de A contiene la
!>          parte superior triangular de la matriz A. Si UPLO = 'L',
!>          la parte inferior triangular N por N de A contiene la
!>          parte inferior triangular de la matriz A.
!>          En la salida, si JOBZ = 'V', entonces si INFO = 0, A contiene los
!>          vectores propios ortonormales de la matriz A.
!>          Si JOBZ = 'N', entonces en la salida el triángulo inferior (si UPLO='L')
!>          o el triángulo superior (si UPLO='U') de A, incluyendo la
!>          diagonal, se destruye.
!>

LDA

!>          LDA es INTEGER
!>          La dimensión principal del array A.  LDA >= max(1,N).
!>

W

!>          W es un array DOUBLE PRECISION, dimensión (N)
!>          Si INFO = 0, los valores propios en orden ascendente.
!>

WORK

!>          WORK es un array COMPLEX*16, dimensión (MAX(1,LWORK))
!>          En la salida, si INFO = 0, WORK(1) devuelve el LWORK óptimo.
!>

LWORK

!>          LWORK es INTEGER
!>          La dimensión del array WORK.
!>          Si N <= 1,               LWORK debe ser al menos 1.
!>          Si JOBZ = 'N' y N > 1, LWORK debe ser consultado.
!>                                   LWORK = MAX(1, dimensión) donde
!>                                   dimensión = max(etapa1,etapa2) + (KD+1)*N + N+1
!>                                             = N*KD + N*max(KD+1,FACTOPTNB)
!>                                               + max(2*KD*KD, KD*NTHREADS)
!>                                               + (KD+1)*N + N+1
!>                                   donde KD es el tamaño de bloqueo de la reducción,
!>                                   FACTOPTNB es el bloqueo utilizado por el algoritmo QR o LQ
!>                                   normalmente FACTOPTNB=128 es una buena opción
!>                                   NTHREADS es el número de hilos utilizados cuando
!>                                   se compila con openMP, de lo contrario =1.
!>          Si JOBZ = 'V' y N > 1, LWORK debe ser al menos 2*N + N**2
!>
!>          Si LWORK = -1, entonces se asume una consulta de espacio de trabajo; la rutina
!>          solo calcula los tamaños óptimos de los arrays WORK, RWORK y
!>          IWORK, devuelve estos valores como las primeras entradas de
!>          los arrays WORK, RWORK y IWORK, y XERBLA no emite ningún mensaje de error
!>          relacionado con LWORK o LRWORK o LIWORK.
!>

RWORK

!>          RWORK es un array DOUBLE PRECISION,
!>                                         dimensión (LRWORK)
!>          En la salida, si INFO = 0, RWORK(1) devuelve el LRWORK óptimo.
!>

LRWORK

!>          LRWORK es INTEGER
!>          La dimensión del array RWORK.
!>          Si N <= 1,                LRWORK debe ser al menos 1.
!>          Si JOBZ  = 'N' y N > 1, LRWORK debe ser al menos N.
!>          Si JOBZ  = 'V' y N > 1, LRWORK debe ser al menos
!>                         1 + 5*N + 2*N**2.
!>
!>          Si LRWORK = -1, entonces se asume una consulta de espacio de trabajo; la
!>          rutina solo calcula los tamaños óptimos de los arrays WORK, RWORK
!>          y IWORK, devuelve estos valores como las primeras entradas de
!>          los arrays WORK, RWORK y IWORK, y XERBLA no emite ningún mensaje de error
!>          relacionado con LWORK o LRWORK o LIWORK.
!>

IWORK

!>          IWORK es un array INTEGER, dimensión (MAX(1,LIWORK))
!>          En la salida, si INFO = 0, IWORK(1) devuelve el LIWORK óptimo.
!>

LIWORK

!>          LIWORK es INTEGER
!>          La dimensión del array IWORK.
!>          Si N <= 1,                LIWORK debe ser al menos 1.
!>          Si JOBZ  = 'N' y N > 1, LIWORK debe ser al menos 1.
!>          Si JOBZ  = 'V' y N > 1, LIWORK debe ser al menos 3 + 5*N.
!>
!>          Si LIWORK = -1, entonces se asume una consulta de espacio de trabajo; la
!>          rutina solo calcula los tamaños óptimos de los arrays WORK, RWORK
!>          y IWORK, devuelve estos valores como las primeras entradas de
!>          los arrays WORK, RWORK y IWORK, y XERBLA no emite ningún mensaje de error
!>          relacionado con LWORK o LRWORK o LIWORK.
!>

INFO

!>          INFO es INTEGER
!>          = 0:  finalización exitosa
!>          < 0:  si INFO = -i, el i-ésimo argumento tenía un valor ilegal
!>          > 0:  si INFO = i y JOBZ = 'N', entonces el algoritmo no convergió;
!>                i elementos fuera de la diagonal de una forma tridiagonal intermedia
!>                no convergieron a cero;
!>                si INFO = i y JOBZ = 'V', entonces el algoritmo no pudo calcular
!>                un valor propio mientras trabajaba en la submatriz
!>                yacente en las filas y columnas INFO/(N+1) hasta
!>                mod(INFO,N+1).
!>

This section describes the LAPACK routine ZHEEVD_2STAGE.

    
The main purpose of the ZHEEVD_2STAGE routine is to compute
        the eigenvalues and eigenvectors of a complex Hermitian matrix. It employs a
        two-stage algorithm, which is often more efficient than the standard one-stage
        approach for larger matrices. This routine is part of the LAPACK library,
        a standard collection of Fortran subroutines for solving linear algebra
        problems.

DESCRIPTION

The ZHEEVD_2STAGE subroutine computes the eigenvalues and, optionally, the eigenvectors of a complex Hermitian matrix A. The two-stage reduction algorithm is used to transform the symmetric or Hermitian matrix A into a condensed tridiagonal matrix (for real symmetric) or a condensed Hermitian tridiagonal matrix (for complex Hermitian), which is then factored.

The general structure of the algorithm is:

  1. Stage 1: The matrix A is reduced to a tridiagonal matrix T by unitary transformations. This stage consists of two steps. First, the matrix is reduced to upper Hessenberg form. Then, the Hessenberg matrix is reduced to tridiagonal form. The two-stage approach aims to achieve efficiency by grouping the transformations to reduce the number of matrix-vector operations.

  2. Stage 2: The eigenvalues and eigenvectors of the tridiagonal matrix T are computed using a fast divide-and-conquer algorithm (ZHEEVD).

SPECIFICATIONS

The subroutine is defined as:

SUBROUTINE ZHEEVD_2STAGE(
                                           JOBZ,
                                           UPLO,
                                           N,
                                           A,
                                           LDA,
                                           D,
                                           LWORK,
                                           TAU,
                                           WORK,
                                           INFO
)
JOBZ

CHARACTER*1. Specifies whether to compute the eigenvectors.

  • 'N': Eigenvectors are not computed.

  • 'V': Eigenvectors are computed.

UPLO

CHARACTER*1. Specifies whether A is upper or lower triangular. This option is relevant because A is Hermitian, so if it's upper triangular, the conjugate transpose is lower triangular, and vice versa. LAPACK routines often only require one triangular part to be stored.

  • 'U': A is upper triangular.

  • 'L': A is lower triangular.

N

INTEGER. The order of the matrix A. N >= 0.

A

COMPLEX*16. Array of dimension (LDA, N). On entry, the Hermitian matrix A. Only UPLO part of A is needed.

LDA

INTEGER. The leading dimension of the array A. LDA >= max(1, N).

D

DOUBLE PRECISION. Array of dimension (N). If INFO = 0, D contains the eigenvalues. The eigenvalues are sorted in ascending order.

LWORK

INTEGER. The dimension of the array WORK.

Optimal dimension for LWORK is:

    max( N, N + 2*NB, N + max( 2*NB, 2*N ) )
 
    where NB is the block size for the QR algorithm, typically 32 or 64.
    The routine also uses a workspace query: if LWORK = -1, then
    WORK(1) contains the optimal dimension and WORK is not
    accessed.
TAU

COMPLEX*16. Array of dimension (N-1). This array stores the complex scalars TAU which are needed for the unitary transformations. These scalars are generated by the two-stage reduction algorithm.

WORK

COMPLEX*16. Workspace array of dimension (LWORK).

INFO

INTEGER.

  • 0: Successful exit.

  • > 0: If INFO = i, then the algorithm failed to converge; i off-diagonal elements of an intermediate tridiagonal matrix did not converge to zero.
