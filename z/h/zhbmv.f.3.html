Documentación de función/subrutina

subroutine zhbmv (character uplo, integer n, integer k, complex*16 alpha, complex*16, dimension(lda,*) a, integer lda, complex*16, dimension(*) x, integer incx, complex*16 beta, complex*16, dimension(*) y, integer incy)

ZHBMV

Propósito:

!>
!> ZHBMV  realiza la operación de matriz-vector
!>
!>    y := alpha*A*x + beta*y,
!>
!> donde alpha y beta son escalares, x e y son vectores de n elementos y
!> A es una matriz de banda hermitiana de n por n, con k super-diagonales.
!>

Parámetros

UPLO 
!>          UPLO es CHARACTER*1
!>           A la entrada, UPLO especifica si la parte triangular superior o inferior
!>           de la matriz de banda A se está proporcionando de la siguiente manera:
!>
!>              UPLO = 'U' o 'u'   Se está proporcionando la parte triangular superior de A.
!>
!>              UPLO = 'L' o 'l'   Se está proporcionando la parte triangular inferior de A.
!>

N

!>          N es INTEGER
!>           A la entrada, N especifica el orden de la matriz A.
!>           N debe ser al menos cero.
!>

K

!>          K es INTEGER
!>           A la entrada, K especifica el número de super-diagonales de la
!>           matriz A. K debe satisfacer  0 .le. K.
!>

ALPHA

!>          ALPHA es COMPLEX*16
!>           A la entrada, ALPHA especifica el escalar alpha.
!>

A

!>          A es un array COMPLEX*16, dimensión ( LDA, N )
!>           Antes de la entrada con UPLO = 'U' o 'u', la parte principal ( k + 1 )
!>           por n del array A debe contener la parte de banda triangular superior de la
!>           matriz hermitiana, proporcionada columna por columna, con la diagonal principal
!>           de la matriz en la fila ( k + 1 ) del array, la primera super-diagonal
!>           comenzando en la posición 2 en la fila k, y así sucesivamente. El triángulo
!>           superior izquierdo de k por k del array A no se referencia.
!>           El siguiente segmento del programa transferirá la parte triangular superior
!>           de una matriz de banda hermitiana desde un almacenamiento de matriz completa convencional
!>           a almacenamiento de banda:
!>
!>                 DO 20, J = 1, N
!>                    M = K + 1 - J
!>                    DO 10, I = MAX( 1, J - K ), J
!>                       A( M + I, J ) = matrix( I, J )
!>              10    CONTINUE
!>              20 CONTINUE
!>
!>           Antes de la entrada con UPLO = 'L' o 'l', la parte principal ( k + 1 )
!>           por n del array A debe contener la parte de banda triangular inferior de la
!>           matriz hermitiana, proporcionada columna por columna, con la diagonal principal
!>           de la matriz en la fila 1 del array, la primera sub-diagonal comenzando en la
!>           posición 1 en la fila 2, y así sucesivamente. El triángulo inferior derecho
!>           de k por k del array A no se referencia.
!>           El siguiente segmento del programa transferirá la parte triangular inferior
!>           de una matriz de banda hermitiana desde un almacenamiento de matriz completa convencional
!>           a almacenamiento de banda:
!>
!>                 DO 20, J = 1, N
!>                    M = 1 - J
!>                    DO 10, I = J, MIN( N, J + K )
!>                       A( M + I, J ) = matrix( I, J )
!>              10    CONTINUE
!>              20 CONTINUE
!>
!>           Tenga en cuenta que las partes imaginarias de los elementos diagonales no
!>           necesitan configurarse y se asumen como cero.
!>

LDA

!>          LDA es INTEGER
!>           A la entrada, LDA especifica la primera dimensión de A tal como se declaró
!>           en el programa (sub)llamador. LDA debe ser al menos
!>           ( k + 1 ).
!>

X

!>          X es un array COMPLEX*16, dimensión al menos
!>           ( 1 + ( n - 1 )*abs( INCX ) ).
!>           Antes de la entrada, el array X incrementado debe contener el
!>           vector x.
!>

INCX

!>          INCX es INTEGER
!>           A la entrada, INCX especifica el incremento para los elementos de
!>           X. INCX no debe ser cero.
!>

BETA

!>          BETA es COMPLEX*16
!>           A la entrada, BETA especifica el escalar beta.
!>

Y

!>          Y es un array COMPLEX*16, dimensión al menos
!>           ( 1 + ( n - 1 )*abs( INCY ) ).
!>           Antes de la entrada, el array Y incrementado debe contener el
!>           vector y. A la salida, Y se sobrescribe con el vector y actualizado.
!>

INCY

!>          INCY es INTEGER
!>           A la entrada, INCY especifica el incremento para los elementos de
!>           Y. INCY no debe ser cero.
!>
