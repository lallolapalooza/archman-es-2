ZHESV_AA_2STAGE calcula la solución al sistema de ecuaciones lineales A * X = B para matrices HE

Propósito:

!>
!> ZHESV_AA_2STAGE calcula la solución a un sistema complejo de
!> ecuaciones lineales
!>    A * X = B,
!> donde A es una matriz Hermitiana N-por-N y X y B son matrices N-por-NRHS.
!>
!> Se utiliza el algoritmo de 2 etapas de Aasen para factorizar A como
!>    A = U**H * T * U,  si UPLO = 'U', o
!>    A = L * T * L**H,  si UPLO = 'L',
!> donde U (o L) es un producto de matrices de permutación y triangulares unitarias
!> superiores (inferiores), y T es Hermitiana y de banda. La matriz T
!> se factoriza LU con pivoteo parcial. La forma factorizada de A
!> se utiliza para resolver el sistema de ecuaciones A * X = B.
!>
!> Esta es la versión bloqueada del algoritmo, que llama a BLAS de Nivel 3.
!>

Parámetros

UPLO 
!>          UPLO es CARACTER*1
!>          = 'U':  El triángulo superior de A está almacenado;
!>          = 'L':  El triángulo inferior de A está almacenado.
!>

N

!>          N es ENTERO
!>          El orden de la matriz A.  N >= 0.
!>

NRHS

!>          NRHS es ENTERO
!>          El número de lados derechos, es decir, el número de columnas
!>          de la matriz B.  NRHS >= 0.
!>

A

!>          A es una matriz COMPLEJA*16, dimensión (LDA,N)
!>          En la entrada, la matriz Hermitiana A.  Si UPLO = 'U', la parte
!>          superior N-por-N de A contiene la parte triangular superior
!>          de la matriz A, y la parte estrictamente triangular inferior
!>          de A no se referencia. Si UPLO = 'L', la parte inferior
!>          N-por-N de A contiene la parte triangular inferior
!>          de la matriz A, y la parte estrictamente triangular superior
!>          de A no se referencia.
!>
!>          En la salida, L se almacena debajo (o encima) de los bloques
!>          subdiagonales, cuando UPLO  es 'L' (o 'U').
!>

LDA

!>          LDA es ENTERO
!>          La dimensión principal del array A.  LDA >= max(1,N).
!>

TB

!>          TB es una matriz COMPLEJA*16, dimensión (MAX(1,LTB)).
!>          En la salida, detalles de la factorización LU de la matriz de banda.
!>

LTB

!>          LTB es ENTERO
!>          El tamaño del array TB. LTB >= MAX(1,4*N), utilizado internamente
!>          para seleccionar NB tal que LTB >= (3*NB+1)*N.
!>
!>          Si LTB = -1, se asume una consulta de espacio de trabajo; la
!>          rutina solo calcula el tamaño óptimo de LTB,
!>          devuelve este valor como la primera entrada de TB, y
!>          XERBLA no emite ningún mensaje de error relacionado con LTB.
!>

IPIV

!>          IPIV es un array ENTERO, dimensión (N)
!>          En la salida, contiene los detalles de los intercambios, es decir,
!>          la fila y columna k de A fueron intercambiadas con la
!>          fila y columna IPIV(k).
!>

IPIV2

!>          IPIV2 es un array ENTERO, dimensión (N)
!>          En la salida, contiene los detalles de los intercambios, es decir,
!>          la fila y columna k de T fueron intercambiadas con la
!>          fila y columna IPIV(k).
!>

B

!>          B es una matriz COMPLEJA*16, dimensión (LDB,NRHS)
!>          En la entrada, la matriz del lado derecho B.
!>          En la salida, la matriz solución X.
!>

LDB

!>          LDB es ENTERO
!>          La dimensión principal del array B.  LDB >= max(1,N).
!>

WORK

!>          WORK es un espacio de trabajo COMPLEJO*16 de tamaño (MAX(1,LWORK)).
!>          En la salida, si INFO = 0, WORK(1) devuelve el LWORK óptimo.
!>

LWORK

!>          LWORK es ENTERO
!>          El tamaño de WORK. LWORK >= MAX(1,N), utilizado internamente para
!>          seleccionar NB tal que LWORK >= N*NB.
!>
!>          Si LWORK = -1, se asume una consulta de espacio de trabajo; la
!>          rutina solo calcula el tamaño óptimo del array WORK,
!>          devuelve este valor como la primera entrada del array WORK, y
!>          XERBLA no emite ningún mensaje de error relacionado con LWORK.
!>

INFO

!>          INFO es ENTERO
!>          = 0:  salida exitosa
!>          < 0:  si INFO = -i, el i-ésimo argumento tenía un valor ilegal.
!>          > 0:  si INFO = i, la factorización LU de banda falló en la i-ésima columna
!>
