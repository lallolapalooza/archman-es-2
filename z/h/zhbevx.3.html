subrutina zhbevx (character jobz, character range, character uplo, integer n, integer kd, complex*16, dimension( ldab, * ) ab, integer ldab, complex*16, dimension( ldq, * ) q, integer ldq, double precision vl, double precision vu, integer il, integer iu, double precision abstol, integer m, double precision, dimension( * ) w, complex*16, dimension( ldz, * ) z, integer ldz, complex*16, dimension( * ) work, double precision, dimension( * ) rwork, integer, dimension( * ) iwork, integer, dimension( * ) ifail, integer info)

ZHBEVX calcula los valores y, opcionalmente, los vectores propios izquierdos y/o derechos para matrices DE OTRO TIPO

Propósito:

!>
!> ZHBEVX calcula los valores propios seleccionados y, opcionalmente, los vectores propios
!> de una matriz banda hermitiana compleja A. Los valores y vectores propios
!> pueden ser seleccionados especificando un rango de valores o un rango de
!> índices para los valores propios deseados.
!>

Parámetros

JOBZ 
!>          JOBZ es CHARACTER*1
!>          = 'N':  Calcular solo los valores propios;
!>          = 'V':  Calcular los valores propios y los vectores propios.
!>

RANGE

!>          RANGE es CHARACTER*1
!>          = 'A': se encontrarán todos los valores propios;
!>          = 'V': se encontrarán todos los valores propios en el intervalo semiabierto (VL,VU]
!>                 ;
!>          = 'I': se encontrarán los valores propios desde el IL-ésimo hasta el IU-ésimo.
!>

UPLO

!>          UPLO es CHARACTER*1
!>          = 'U':  el triángulo superior de A está almacenado;
!>          = 'L':  el triángulo inferior de A está almacenado.
!>

N

!>          N es INTEGER
!>          El orden de la matriz A.  N >= 0.
!>

KD

!>          KD es INTEGER
!>          El número de superdiagonales de la matriz A si UPLO = 'U',
!>          o el número de subdiagonales si UPLO = 'L'.  KD >= 0.
!>

AB

!>          AB es una matriz COMPLEX*16, de dimensión (LDAB, N)
!>          En la entrada, el triángulo superior o inferior de la matriz banda hermitiana
!>          A, almacenado en las primeras KD+1 filas de la matriz. La
!>          columna j-ésima de A se almacena en la columna j-ésima de la matriz AB
!>          de la siguiente manera:
!>          si UPLO = 'U', AB(kd+1+i-j,j) = A(i,j) para max(1,j-kd)<=i<=j;
!>          si UPLO = 'L', AB(1+i-j,j)    = A(i,j) para j<=i<=min(n,j+kd).
!>
!>          En la salida, AB se sobrescribe con valores generados durante la
!>          reducción a forma tridiagonal.
!>

LDAB

!>          LDAB es INTEGER
!>          La dimensión principal de la matriz AB.  LDAB >= KD + 1.
!>

Q

!>          Q es una matriz COMPLEX*16, de dimensión (LDQ, N)
!>          Si JOBZ = 'V', la matriz unitaria N por N utilizada en la
!>                          reducción a forma tridiagonal.
!>          Si JOBZ = 'N', la matriz Q no se referencia.
!>

LDQ

!>          LDQ es INTEGER
!>          La dimensión principal de la matriz Q.  Si JOBZ = 'V', entonces
!>          LDQ >= max(1,N).
!>

VL

!>          VL es DOUBLE PRECISION
!>          Si RANGE='V', el límite inferior del intervalo a
!>          buscar para los valores propios. VL < VU.
!>          No se referencia si RANGE = 'A' o 'I'.
!>

VU

!>          VU es DOUBLE PRECISION
!>          Si RANGE='V', el límite superior del intervalo a
!>          buscar para los valores propios. VL < VU.
!>          No se referencia si RANGE = 'A' o 'I'.
!>

IL

!>          IL es INTEGER
!>          Si RANGE='I', el índice del
!>          valor propio más pequeño a devolver.
!>          1 <= IL <= IU <= N, si N > 0; IL = 1 e IU = 0 si N = 0.
!>          No se referencia si RANGE = 'A' o 'V'.
!>

IU

!>          IU es INTEGER
!>          Si RANGE='I', el índice del
!>          valor propio más grande a devolver.
!>          1 <= IL <= IU <= N, si N > 0; IL = 1 e IU = 0 si N = 0.
!>          No se referencia si RANGE = 'A' o 'V'.
!>

ABSTOL

!>          ABSTOL es DOUBLE PRECISION
!>          La tolerancia de error absoluto para los valores propios.
!>          Se acepta un valor propio aproximado como convergente
!>          cuando se determina que yace en un intervalo [a,b]
!>          de anchura menor o igual a
!>
!>                  ABSTOL + EPS *   max( |a|,|b| ) ,
!>
!>          donde EPS es la precisión de la máquina. Si ABSTOL es menor o
!>          igual a cero, entonces EPS*|T| se usará en su lugar,
!>          donde |T| es la norma 1 de la matriz tridiagonal obtenida
!>          al reducir AB a forma tridiagonal.
!>
!>          Los valores propios se calcularán con mayor precisión cuando ABSTOL
!>          se establezca en el doble del umbral de subdesbordamiento 2*DLAMCH('S'), no en cero.
!>          Si esta rutina retorna con INFO>0, indicando que algunos
!>          vectores propios no convergieron, intente establecer ABSTOL en
!>          2*DLAMCH('S').
!>
!>          Ver  por Demmel y
!>          Kahan, Nota de trabajo de LAPACK #3.
!>

M

!>          M es INTEGER
!>          El número total de valores propios encontrados.  0 <= M <= N.
!>          Si RANGE = 'A', M = N, y si RANGE = 'I', M = IU-IL+1.
!>

W

!>          W es una matriz DOUBLE PRECISION, de dimensión (N)
!>          Los primeros M elementos contienen los valores propios seleccionados en
!>          orden ascendente.
!>

Z

!>          Z es una matriz COMPLEX*16, de dimensión (LDZ, max(1,M))
!>          Si JOBZ = 'V', entonces si INFO = 0, las primeras M columnas de Z
!>          contienen los vectores propios ortonormales de la matriz A
!>          correspondientes a los valores propios seleccionados, con la i-ésima
!>          columna de Z conteniendo el vector propio asociado a W(i).
!>          Si un vector propio falla en converger, entonces esa columna de Z
!>          contiene la última aproximación al vector propio, y el
!>          índice del vector propio se devuelve en IFAIL.
!>          Si JOBZ = 'N', entonces Z no se referencia.
!>          Nota: el usuario debe asegurarse de que se proporcionan al menos max(1,M) columnas
!>          en la matriz Z; si RANGE = 'V', el valor exacto de M
!>          no se conoce de antemano y se debe usar un límite superior.
!>

LDZ

!>          LDZ es INTEGER
!>          La dimensión principal de la matriz Z.  LDZ >= 1, y si
!>          JOBZ = 'V', LDZ >= max(1,N).
!>

WORK

!>          WORK es una matriz COMPLEX*16, de dimensión (N)
!>

RWORK

!>          RWORK es una matriz DOUBLE PRECISION, de dimensión (7*N)
!>

IWORK

!>          IWORK es una matriz INTEGER, de dimensión (5*N)
!>

IFAIL

!>          IFAIL es una matriz INTEGER, de dimensión (N)
!>          Si JOBZ = 'V', entonces si INFO = 0, los primeros M elementos de
!>          IFAIL son cero. Si INFO > 0, entonces IFAIL contiene los
!>          índices de los vectores propios que fallaron en converger.
!>          Si JOBZ = 'N', entonces IFAIL no se referencia.
!>

NAME

zhbevx - computes the eigenvalues and eigenvectors of a complex Hermitian band matrix.

SYNOPSIS

SUBROUTINE ZHBEVX(
   JOBZ, COMPZ, RANGE, UPLO, N, KD, AB, LDAB, Q, LDQ, VL, VU, IL, IU,
   M, WL, WWL, ZL, LDZL, D, SD, RWORK, INFO )

 CHARACTER          *
 INTEGER

 CHARACTER          JOBZ
 INTEGER            N, KD, LDAB, LDQ, IL, IU, M, INFO
 REAL               VL, VU
 DOUBLE PRECISION   AB( LDAB, * ), Q( LDQ, * ), WL, WWL, ZL( LDZL, * ), D( * ), SD( * )
 REAL               RWORK( * )
 CHARACTER          COMPZ, RANGE, UPLO

Function/Subroutine Documentation

ZHBEVX computes the eigenvalues and eigenvectors of a complex Hermitian band matrix A of order N.

Band storage scheme is described under SUBROUTINE ZGBBRD.

The routine also handles the case where the matrix A is dense.

Eigenvalues and eigenvectors are computed for the matrix A using the reduction to tridiagonal form and then the QR algorithm. (ZHBEVX uses ZHBTRD and ZHPTRD to reduce the band matrix to tridiagonal form.)

Arguments

JOBZ

Character. Specifies whether to compute the eigenvalues only or both eigenvalues and eigenvectors.

  • 'N': Computes only the eigenvalues of A.
  • 'V': Computes the eigenvalues and eigenvectors of A.
COMPZ

Character. Specifies whether to compute the eigenvectors in an unshifted or shifted form.

  • 'N': Computes the eigenvalues only.
  • 'V': Computes the eigenvalues and eigenvectors.
  • 'I': Computes the eigenvalues and eigenvectors.
RANGE

Character. Specifies whether all, selected, or a range of eigenvalues are to be computed.

  • 'A': All eigenvalues will be computed.
  • 'V': All eigenvalues in the interval (VL, VU] will be computed.
  • 'I': All eigenvalues in the open interval (VL, VU) will be computed.
UPLO

Character. Specifies whether the upper or lower band part of A is to be used.

  • 'U': Uses the upper band part of A.
  • 'L': Uses the lower band part of A.
N

Integer. The order of the matrix A. N >= 0.

KD

Integer. The number of super- or sub-diagonals of the band matrix A. KD >= 0.

AB

Double Precision array, dimension (LDAB,N).

On entry, the upper or lower band part of the Hermitian band matrix A, stored in the first KD+1 rows of the array. The (i, j) element of A is stored in:

  • AB(KD+1+i-j, j) if UPLO = 'U' and i <= j. (See below for the definition of AB when UPLO = 'L')
  • AB(i-j+1, j) if UPLO = 'L' and i >= j. (See below for the definition of AB when UPLO = 'L')

On exit, if JOBZ = 'Q', AB is overwritten by values generated during the computation of the eigenvectors.

LDAB

Integer. The leading dimension of the array AB. LDAB >= KD + 1.

Q

Double Precision array, dimension (LDQ,N).

If COMPZ = 'V', Q is the unitary matrix P such that A = P*D*P**H.

If COMPZ = 'I', Q is the unitary matrix P.

LDQ

Integer. The leading dimension of the array Q. LDQ >= max(1, N).

VL

Real. The lower bound of the interval for the desired eigenvalues.

VU

Real. The upper bound of the interval for the desired eigenvalues.

IL

Integer. The starting index for the desired eigenvalues.

IU

Integer. The ending index for the desired eigenvalues.

M

Integer. The total number of eigenvalues found.

If RANGE = 'A', then M = N.

If RANGE = 'V' or RANGE = 'I', then M is the number of eigenvalues in the specified range.

WL

Double Precision array, dimension (N).

WWL

Double Precision array, dimension (N).

ZL

Double Precision array, dimension (LDZL, max(1,M)).

On exit, the computed eigenvectors, with the j-th column corresponding to the j-th eigenvalue in the array D.

On exit, ZL is overwritten by values generated during the computation of the eigenvectors.

LDZL

Integer. The leading dimension of the array ZL. LDZL >= max(1,N).

D

Double Precision array, dimension (N).

On exit, the computed eigenvalues.

SD

Double Precision array, dimension (N).

On exit, if JOBZ = 'S', the diagonal elements of the reduced tridiagonal matrix T.

RWORK

Real array, dimension (N).

Local array for RWORK.

INFO

Integer.

= 0: successful exit

< 0: if INFO = -i, then the i-th argument had an illegal value.

> 0: if INFO = i, then i eigenvectors failed to converge. Their indices are stored in array IFAIL.
