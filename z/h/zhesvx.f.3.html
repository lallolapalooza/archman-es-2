ZHESVX calcula la solución al sistema de ecuaciones lineales A * X = B para matrices Hermitianes

Propósito:

!>
!> ZHESVX utiliza la factorización por pivoteo diagonal para calcular
!> la solución a un sistema complejo de ecuaciones lineales A * X = B,
!> donde A es una matriz Hermitiana N-por-N y X y B son matrices N-por-NRHS.
!>
!> También se proporcionan cotas de error en la solución y una estimación
!> de la condición.
!>

Descripción:

!>
!> Se realizan los siguientes pasos:
!>
!> 1. Si FACT = 'N', se utiliza el método de pivoteo diagonal para factorizar A.
!>    La forma de la factorización es
!>       A = U * D * U**H,  si UPLO = 'U', o
!>       A = L * D * L**H,  si UPLO = 'L',
!>    donde U (o L) es un producto de matrices de permutación y triangulares
!>    unitarias superiores (inferiores), y D es Hermitiana y diagonal por bloques
!>    con bloques diagonales de 1x1 y 2x2.
!>
!> 2. Si algún D(i,i) = 0, de modo que D es exactamente singular, la rutina
!>    retorna con INFO = i. De lo contrario, la forma factorizada de A se usa
!>    para estimar el número de condición de la matriz A. Si el
!>    recíproco del número de condición es menor que la precisión de la máquina,
!>    se retorna INFO = N+1 como advertencia, pero la rutina aún continúa
!>    para resolver X y calcular las cotas de error como se describe a continuación.
!>
!> 3. El sistema de ecuaciones se resuelve para X utilizando la forma factorizada
!>    de A.
!>
!> 4. Se aplica refinamiento iterativo para mejorar la solución calculada
!>    y calcular cotas de error y estimaciones de error hacia atrás
!>    para ella.
!>

Parámetros

FACT 
!>          FACT es CHARACTER*1
!>          Especifica si la forma factorizada de A ha sido suministrada
!>          en la entrada o no.
!>          = 'F':  En la entrada, AF y IPIV contienen la forma factorizada
!>                  de A.  A, AF e IPIV no se modificarán.
!>          = 'N':  La matriz A se copiará en AF y se factorizará.
!>

UPLO

!>          UPLO es CHARACTER*1
!>          = 'U':  Se almacena el triángulo superior de A;
!>          = 'L':  Se almacena el triángulo inferior de A.
!>

N

!>          N es INTEGER
!>          El número de ecuaciones lineales, es decir, el orden de
!>          la matriz A.  N >= 0.
!>

NRHS

!>          NRHS es INTEGER
!>          El número de lados derechos, es decir, el número de columnas
!>          de las matrices B y X.  NRHS >= 0.
!>

A

!>          A es un array COMPLEX*16, de dimensión (LDA,N)
!>          La matriz Hermitiana A.  Si UPLO = 'U', la parte superior
!>          triangular N-por-N de A contiene la parte superior triangular
!>          de la matriz A, y la parte estrictamente inferior triangular de A
!>          no se referencia. Si UPLO = 'L', la parte inferior
!>          triangular N-por-N de A contiene la parte inferior triangular
!>          de la matriz A, y la parte estrictamente superior triangular de A
!>          no se referencia.
!>

LDA

!>          LDA es INTEGER
!>          La dimensión principal del array A.  LDA >= max(1,N).
!>

AF

!>          AF es un array COMPLEX*16, de dimensión (LDAF,N)
!>          Si FACT = 'F', entonces AF es un parámetro de entrada y en la entrada
!>          contiene la matriz diagonal por bloques D y los multiplicadores usados
!>          para obtener el factor U o L de la factorización
!>          A = U*D*U**H o A = L*D*L**H calculada por ZHETRF.
!>
!>          Si FACT = 'N', entonces AF es un parámetro de salida y en la salida
!>          devuelve la matriz diagonal por bloques D y los multiplicadores usados
!>          para obtener el factor U o L de la factorización
!>          A = U*D*U**H o A = L*D*L**H.
!>

LDAF

!>          LDAF es INTEGER
!>          La dimensión principal del array AF.  LDAF >= max(1,N).
!>

IPIV

!>          IPIV es un array INTEGER, de dimensión (N)
!>          Si FACT = 'F', entonces IPIV es un parámetro de entrada y en la entrada
!>          contiene detalles de los intercambios y la estructura de bloques
!>          de D, tal como lo determinó ZHETRF.
!>          Si IPIV(k) > 0, entonces las filas y columnas k e IPIV(k) fueron
!>          intercambiadas y D(k,k) es un bloque diagonal de 1x1.
!>          Si UPLO = 'U' e IPIV(k) = IPIV(k-1) < 0, entonces las filas y
!>          columnas k-1 e -IPIV(k) fueron intercambiadas y D(k-1:k,k-1:k)
!>          es un bloque diagonal de 2x2. Si UPLO = 'L' e IPIV(k) =
!>          IPIV(k+1) < 0, entonces las filas y columnas k+1 e -IPIV(k) fueron
!>          intercambiadas y D(k:k+1,k:k+1) es un bloque diagonal de 2x2.
!>
!>          Si FACT = 'N', entonces IPIV es un parámetro de salida y en la salida
!>          contiene detalles de los intercambios y la estructura de bloques
!>          de D, tal como lo determinó ZHETRF.
!>

B

!>          B es un array COMPLEX*16, de dimensión (LDB,NRHS)
!>          La matriz del lado derecho B de N-por-NRHS.
!>

LDB

!>          LDB es INTEGER
!>          La dimensión principal del array B.  LDB >= max(1,N).
!>

X

!>          X es un array COMPLEX*16, de dimensión (LDX,NRHS)
!>          Si INFO = 0 o INFO = N+1, la matriz solución X de N-por-NRHS.
!>

LDX

!>          LDX es INTEGER
!>          La dimensión principal del array X.  LDX >= max(1,N).
!>

RCOND

!>          RCOND es DOUBLE PRECISION
!>          La estimación del recíproco del número de condición de la matriz
!>          A. Si RCOND es menor que la precisión de la máquina
!>          (en particular, si RCOND = 0), la matriz es singular con precisión
!>          de trabajo. Esta condición se indica con un código de retorno
!>          de INFO > 0.
!>

FERR

!>          FERR es un array DOUBLE PRECISION, de dimensión (NRHS)
!>          La cota de error hacia adelante estimada para cada vector solución
!>          X(j) (la j-ésima columna de la matriz solución X).
!>          Si XTRUE es la solución verdadera correspondiente a X(j), FERR(j)
!>          es una cota superior estimada para la magnitud del elemento más grande
!>          en (X(j) - XTRUE) dividido por la magnitud del elemento más grande
!>          en X(j). La estimación es tan confiable como la estimación
!>          para RCOND, y es casi siempre una sobreestimación ligera del
!>          error verdadero.
!>

BERR

!>          BERR es un array DOUBLE PRECISION, de dimensión (NRHS)
!>          El error relativo componente a componente hacia atrás de cada vector
!>          solución X(j) (es decir, el cambio relativo más pequeño en
!>          cualquier elemento de A o B que hace de X(j) una solución exacta).
!>

WORK

!>          WORK es un array COMPLEX*16, de dimensión (LWORK)
!>          Espacio de trabajo de uso general.
!>          Si FACT = 'N', WORK(1) contendrá la estimación del número de condición
!>          de A.
!>

LWORK

!>          LWORK es INTEGER
!>          La dimensión del array WORK.  LWORK >= max(1,N).
!>          Para FACT = 'N', se requieren LWORK >= N + N*N para la factorización
!>          y LWORK >= 2*N para el refinamiento.
!>          Si LWORK = -1, entonces se calcula la dimensión óptima de work y
!>          se almacena en work(1), y no se realiza ninguna otra operación.
!>

RWORK

!>          RWORK es un array DOUBLE PRECISION, de dimensión (N)
!>          Espacio de trabajo de precisión doble de uso general.
!>

INFO

!>          INFO es INTEGER
!>          = 0:  Ejecución correcta.
!>          > 0:  Si INFO = k, y 1 <= k <= N, la matriz diagonal por bloques D es
!>                singular y su elemento diagonal k,k es cero. El factoreo
!>                se detuvo.
!>          = N+1: La matriz es singular a la precisión de trabajo. El factoreo
!>                 se completó, pero la matriz es casi singular.
!>

Function/Subroutine Documentation

ZHESVX uses the Left-Right factorization of a complex Hermitian positive definite band matrix A to compute the solution to a set of linear system of equations A*X = B.

Version: 1.0.0

Date: November, 2023

!>          The length of WORK.  LWORK >= MAX(1,2*N), and for best

!>          NB is the optimal blocksize for ZHETRF.

!>

INFO

!>          INFO is INTEGER
!>          = 0: successful exit
!>          < 0: if INFO = -i, the i-th argument had an illegal value
!>          > 0: if INFO = i, and i is
!>                <= N:  D(i,i) is exactly zero.  The factorization
!>                       has been completed but the factor D is exactly
!>                       singular, so the solution and error bounds could
!>                       not be computed. RCOND = 0 is returned.
!>                = N+1: D is nonsingular, but RCOND is less than machine
!>                       precision, meaning that the matrix is singular
!>                       to working precision.  Nevertheless, the
!>                       solution and error bounds are computed because
!>                       there are a number of situations where the
!>                       computed solution can be more accurate than the
!>                       value of RCOND would suggest.
!>
