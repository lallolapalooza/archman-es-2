subrutina zhpt01 (carácter uplo, entero n, complejo*16, dimensión( * ) a, complejo*16, dimensión( * ) afac, entero, dimensión( * ) ipiv, complejo*16, dimensión( ldc, * ) c, entero ldc, doble precisión, dimensión( * ) rwork, doble precisión resid)

ZHPT01

Propósito:

!>
!> ZHPT01 reconstruye una matriz empaquetada hermítica indefinida A a partir de su
!> factorización de bloque L*D*L' o U*D*U' y calcula el residuo
!>    norma( C - A ) / ( N * norma(A) * EPS ),
!> donde C es la matriz reconstruida, EPS es la epsilon de la máquina,
!> L' es la transpuesta conjugada de L, y U' es la transpuesta conjugada
!> de U.
!>

Parámetros

UPLO 
!>          UPLO es CARÁCTER*1
!>          Especifica si la parte triangular superior o inferior de la
!>          matriz hermítica A está almacenada:
!>          = 'U':  Triangular superior
!>          = 'L':  Triangular inferior
!>

N

!>          N es ENTERO
!>          El número de filas y columnas de la matriz A.  N >= 0.
!>

A

!>          A es un array de COMPLEJO*16, dimensión (N*(N+1)/2)
!>          La matriz hermítica original A, almacenada como una matriz
!>          triangular empaquetada.
!>

AFAC

!>          AFAC es un array de COMPLEJO*16, dimensión (N*(N+1)/2)
!>          La forma factorizada de la matriz A, almacenada como una matriz
!>          triangular empaquetada. AFAC contiene la matriz diagonal de bloques D
!>          y los multiplicadores utilizados para obtener el factor L o U a partir de
!>          la factorización L*D*L' o U*D*U' tal como se calcula por ZHPTRF.
!>

IPIV

!>          IPIV es un array de ENTEROS, dimensión (N)
!>          Los índices de pivote de ZHPTRF.
!>

C

!>          C es un array de COMPLEJO*16, dimensión (LDC,N)
!>

LDC

!>          LDC es ENTERO
!>          La dimensión principal del array C.  LDC >= max(1,N).
!>

RWORK

!>          RWORK es un array de DOBLE PRECISIÓN, dimensión (N)
!>

RESID

!>          RESID es DOBLE PRECISIÓN
!>          Si UPLO = 'L', norma(L*D*L' - A) / ( N * norma(A) * EPS )
!>          Si UPLO = 'U', norma(U*D*U' - A) / ( N * norma(A) * EPS )
!>
