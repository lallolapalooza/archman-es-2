Documentación de función/subrutina

subroutine zhpev (character jobz, character uplo, integer n, complex*16, dimension( * ) ap, double precision, dimension( * ) w, complex*16, dimension( ldz, * ) z, integer ldz, complex*16, dimension( * ) work, double precision, dimension( * ) rwork, integer info)

ZHPEV calcula los valores propios y, opcionalmente, los vectores propios izquierdos y/o derechos para matrices HERMITIANAS en almacenamiento empaquetado.

Propósito:

!>
!> ZHPEV calcula todos los valores propios y, opcionalmente, los vectores propios de una
!> matriz hermítica compleja en almacenamiento empaquetado.
!>

Parámetros

JOBZ 
!>          JOBZ es CHARACTER*1
!>          = 'N':  Calcular solo los valores propios;
!>          = 'V':  Calcular los valores propios y los vectores propios.
!>

UPLO

!>          UPLO es CHARACTER*1
!>          = 'U':  Se almacena el triángulo superior de A;
!>          = 'L':  Se almacena el triángulo inferior de A.
!>

N

!>          N es INTEGER
!>          El orden de la matriz A.  N >= 0.
!>

AP

!>          AP es un array COMPLEX*16, de dimensión (N*(N+1)/2)
!>          En la entrada, el triángulo superior o inferior de la matriz hermítica
!>          A, empaquetado columna a columna en un array lineal. La j-ésima columna de A
!>          se almacena en el array AP de la siguiente manera:
!>          si UPLO = 'U', AP(i + (j-1)*j/2) = A(i,j) para 1<=i<=j;
!>          si UPLO = 'L', AP(i + (j-1)*(2*n-j)/2) = A(i,j) para j<=i<=n.
!>
!>          En la salida, AP se sobrescribe con valores generados durante la
!>          reducción a forma tridiagonal. Si UPLO = 'U', la diagonal
!>          y la primera superdiagonal de la matriz tridiagonal T sobrescriben
!>          los elementos correspondientes de A, y si UPLO = 'L', la
!>          diagonal y la primera subdiagonal de T sobrescriben los
!>          elementos correspondientes de A.
!>

W

!>          W es un array DOUBLE PRECISION, de dimensión (N)
!>          Si INFO = 0, los valores propios en orden ascendente.
!>

Z

!>          Z es un array COMPLEX*16, de dimensión (LDZ, N)
!>          Si JOBZ = 'V', entonces si INFO = 0, Z contiene los vectores propios ortonormales
!>          de la matriz A, con la i-ésima columna de Z
!>          conteniendo el vector propio asociado a W(i).
!>          Si JOBZ = 'N', entonces Z no se referencia.
!>

LDZ

!>          LDZ es INTEGER
!>          La dimensión principal del array Z.  LDZ >= 1, y si
!>          JOBZ = 'V', LDZ >= max(1,N).
!>

WORK

!>          WORK es un array COMPLEX*16, de dimensión (max(1, 2*N-1))
!>

RWORK

!>          RWORK es un array DOUBLE PRECISION, de dimensión (max(1, 3*N-2))
!>

INFO

!>          INFO es INTEGER
!>          = 0:  salida exitosa.
!>          < 0:  si INFO = -i, el i-ésimo argumento tenía un valor ilegal.
!>          > 0:  si INFO = i, el algoritmo no convergió; i
!>                elementos fuera de la diagonal de una forma tridiagonal intermedia
!>                no convergieron a cero.
!>
