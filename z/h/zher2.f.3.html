Documentación de función/subrutina

subrutina zher2 (character uplo, integer n, complex*16 alpha, complex*16, dimension(*) x, integer incx, complex*16, dimension(*) y, integer incy, complex*16, dimension(lda,*) a, integer lda)

ZHER2

Propósito:

!>
!> ZHER2  realiza la operación hermitiana de rango 2
!>
!>    A := alpha*x*y**H + conjg( alpha )*y*x**H + A,
!>
!> donde alpha es un escalar, x e y son vectores de n elementos y A es una
!> matriz hermitiana n x n.
!>

Parámetros

UPLO 
!>          UPLO es CHARACTER*1
!>           Al entrar, UPLO especifica si la parte triangular superior o
!>           inferior del array A va a ser referenciada como se indica a
!>           continuación:
!>
!>              UPLO = 'U' o 'u'   Solo se referenciará la parte triangular
!>                                  superior de A.
!>
!>              UPLO = 'L' o 'l'   Solo se referenciará la parte triangular
!>                                  inferior de A.
!>

N

!>          N es INTEGER
!>           Al entrar, N especifica el orden de la matriz A.
!>           N debe ser al menos cero.
!>

ALPHA

!>          ALPHA es COMPLEX*16
!>           Al entrar, ALPHA especifica el escalar alpha.
!>

X

!>          X es un array COMPLEX*16, de dimensión al menos
!>           ( 1 + ( n - 1 )*abs( INCX ) ).
!>           Antes de la entrada, el array X incrementado debe contener el
!>           vector x de n elementos.
!>

INCX

!>          INCX es INTEGER
!>           Al entrar, INCX especifica el incremento para los elementos de
!>           X. INCX no debe ser cero.
!>

Y

!>          Y es un array COMPLEX*16, de dimensión al menos
!>           ( 1 + ( n - 1 )*abs( INCY ) ).
!>           Antes de la entrada, el array Y incrementado debe contener el
!>           vector y de n elementos.
!>

INCY

!>          INCY es INTEGER
!>           Al entrar, INCY especifica el incremento para los elementos de
!>           Y. INCY no debe ser cero.
!>

A

!>          A es un array COMPLEX*16, de dimensión ( LDA, N )
!>           Antes de la entrada con UPLO = 'U' o 'u', la parte superior
!>           del array A, de n por n, debe contener la parte triangular
!>           superior de la matriz hermitiana y la parte triangular estrictamente
!>           inferior de A no se referencia. A la salida, la parte triangular
!>           superior del array A se sobrescribe con la parte triangular
!>           superior de la matriz actualizada.
!>           Antes de la entrada con UPLO = 'L' o 'l', la parte inferior
!>           del array A, de n por n, debe contener la parte triangular
!>           inferior de la matriz hermitiana y la parte triangular estrictamente
!>           superior de A no se referencia. A la salida, la parte triangular
!>           inferior del array A se sobrescribe con la parte triangular
!>           inferior de la matriz actualizada.
!>           Tenga en cuenta que las partes imaginarias de los elementos
!>           diagonales no necesitan estar establecidas, se suponen cero, y a
!>           la salida se establecen a cero.
!>

LDA

!>          LDA es INTEGER
!>           Al entrar, LDA especifica la primera dimensión de A tal como
!>           está declarada en el programa (sub)llamador. LDA debe ser al
!>           menos max( 1, n ).
!>
