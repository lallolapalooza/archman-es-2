DOCUMENTACIÓN DE LA FUNCIÓN/SUBRUTINA

subrutina zhesv (carácter uplo, entero n, entero nrhs, complejo*16, dimensión( lda, * ) a, entero lda, entero, dimensión( * ) ipiv, complejo*16, dimensión( ldb, * ) b, entero ldb, complejo*16, dimensión( * ) work, entero lwork, entero info)

ZHESV calcula la solución a un sistema complejo de ecuaciones lineales A * X = B,

Propósito:

!>
!> ZHESV calcula la solución a un sistema complejo de ecuaciones lineales
!>    A * X = B,
!> donde A es una matriz Hermitiana de N por N y X y B son matrices de N por
!> NRHS.
!>
!> Se utiliza el método de pivoteo diagonal para factorizar A como
!>    A = U * D * U**H,  si UPLO = 'U', o
!>    A = L * D * L**H,  si UPLO = 'L',
!> donde U (o L) es un producto de matrices de permutación y triangulares
!> unitarias superiores (inferiores), y D es Hermitiana y de bloques
!> diagonales con bloques diagonales de 1x1 y 2x2. La forma factorizada de A
!> se utiliza luego para resolver el sistema de ecuaciones A * X = B.
!>

Parámetros

UPLO 
!>          UPLO es CHARACTER*1
!>          = 'U':  El triángulo superior de A está almacenado;
!>          = 'L':  El triángulo inferior de A está almacenado.
!>

N

!>          N es INTEGER
!>          El número de ecuaciones lineales, es decir, el orden de la
!>          matriz A.  N >= 0.
!>

NRHS

!>          NRHS es INTEGER
!>          El número de lados derechos, es decir, el número de columnas
!>          de la matriz B.  NRHS >= 0.
!>

A

!>          A es un array COMPLEX*16, dimensión (LDA,N)
!>          En la entrada, la matriz Hermitiana A.  Si UPLO = 'U', la parte
!>          superior triangular de N por N de A contiene la parte superior
!>          triangular de la matriz A, y la parte estrictamente inferior
!>          triangular de A no se referencia. Si UPLO = 'L', la parte inferior
!>          triangular de N por N de A contiene la parte inferior
!>          triangular de la matriz A, y la parte estrictamente superior
!>          triangular de A no se referencia.
!>
!>          En la salida, si INFO = 0, la matriz de bloques diagonales D y los
!>          multiplicadores utilizados para obtener el factor U o L de la
!>          factorización A = U*D*U**H o A = L*D*L**H tal como se calcula por
!>          ZHETRF.
!>

LDA

!>          LDA es INTEGER
!>          La dimensión principal del array A.  LDA >= max(1,N).
!>

IPIV

!>          IPIV es un array INTEGER, dimensión (N)
!>          Detalles de los intercambios y la estructura de bloques de D, tal
!>          como determinados por ZHETRF.  Si IPIV(k) > 0, entonces las filas y
!>          columnas k e IPIV(k) fueron intercambiadas, y D(k,k) es un bloque
!>          diagonal de 1x1.  Si UPLO = 'U' y IPIV(k) = IPIV(k-1) < 0,
!>          entonces las filas y columnas k-1 y -IPIV(k) fueron intercambiadas
!>          y D(k-1:k,k-1:k) es un bloque diagonal de 2x2. Si UPLO = 'L' y
!>          IPIV(k) = IPIV(k+1) < 0, entonces las filas y columnas k+1 y
!>          -IPIV(k) fueron intercambiadas y D(k:k+1,k:k+1) es un bloque
!>          diagonal de 2x2.
!>

B

!>          B es un array COMPLEX*16, dimensión (LDB,NRHS)
!>          En la entrada, la matriz B de N por NRHS del lado derecho.
!>          En la salida, si INFO = 0, la matriz solución X de N por NRHS.
!>

LDB

!>          LDB es INTEGER
!>          La dimensión principal del array B.  LDB >= max(1,N).
!>

WORK

!>          WORK es un array COMPLEX*16, dimensión (MAX(1,LWORK))
!>          En la salida, si INFO = 0, WORK(1) devuelve el LWORK óptimo.
!>

LWORK

!>          LWORK es INTEGER
!>          La longitud de WORK.  LWORK >= 1, y para un rendimiento óptimo
!>          LWORK >= max(1,N*NB), donde NB es el tamaño de bloque óptimo para
!>          ZHETRF.
!>          para LWORK < N, TRS se hará con BLAS de Nivel 2
!>          para LWORK >= N, TRS se hará con BLAS de Nivel 3
!>
!>          Si LWORK = -1, entonces se asume una consulta de espacio de
!>          trabajo; la rutina solo calcula el tamaño óptimo del array WORK,
!>          devuelve este valor como la primera entrada del array WORK, y no se
!>          emite ningún mensaje de error relacionado con LWORK por XERBLA.
!>

INFO

!>          INFO es INTEGER
!>          = 0: salida exitosa
!>          < 0: si INFO = -i, el argumento i tenía un valor ilegal
!>          > 0: si INFO = i, D(i,i) es exactamente cero. La factorización
!>               se ha completado, pero la matriz de bloques diagonales D es
!>               exactamente singular, por lo que no se pudo calcular la
!>               solución.
!>
