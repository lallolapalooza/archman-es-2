Documentación de función/subrutina

subrutina zhbevd_2stage (character jobz, character uplo, integer n, integer kd, complex*16, dimension( ldab, * ) ab, integer ldab, double precision, dimension( * ) w, complex*16, dimension( ldz, * ) z, integer ldz, complex*16, dimension( * ) work, integer lwork, double precision, dimension( * ) rwork, integer lrwork, integer, dimension( * ) iwork, integer liwork, integer info)

ZHBEVD_2STAGE calcula todos los valores propios y, opcionalmente, los vectores propios de una matriz de banda hermítica compleja A utilizando la técnica de 2 etapas para la reducción a tridiagonal. Si se desean vectores propios, utiliza un algoritmo de divide y vencerás.

Propósito:

!>
!> ZHBEVD_2STAGE calcula todos los valores propios y, opcionalmente, los vectores
!> propios de una matriz de banda hermítica compleja A utilizando la técnica
!> de 2 etapas para la reducción a tridiagonal. Si se desean vectores propios,
!> utiliza un algoritmo de divide y vencerás.
!>
!>

Parámetros

JOBZ 
!>          JOBZ es CHARACTER*1
!>          = 'N':  Calcula solo los valores propios;
!>          = 'V':  Calcula valores propios y vectores propios.
!>                  No disponible en esta versión.
!>

UPLO

!>          UPLO es CHARACTER*1
!>          = 'U':  Se almacena la parte triangular superior de A;
!>          = 'L':  Se almacena la parte triangular inferior de A.
!>

N

!>          N es INTEGER
!>          El orden de la matriz A.  N >= 0.
!>

KD

!>          KD es INTEGER
!>          El número de superdiagonales de la matriz A si UPLO = 'U',
!>          o el número de subdiagonales si UPLO = 'L'.  KD >= 0.
!>

AB

!>          AB es un array de COMPLEX*16, de dimensión (LDAB, N)
!>          En la entrada, la parte triangular superior o inferior de la matriz
!>          de banda hermítica A, almacenada en las primeras KD+1 filas del array.
!>          La j-ésima columna de A se almacena en la j-ésima columna del array AB
!>          de la siguiente manera:
!>          si UPLO = 'U', AB(kd+1+i-j,j) = A(i,j) para max(1,j-kd)<=i<=j;
!>          si UPLO = 'L', AB(1+i-j,j)    = A(i,j) para j<=i<=min(n,j+kd).
!>
!>          En la salida, AB se sobrescribe con valores generados durante la
!>          reducción a forma tridiagonal. Si UPLO = 'U', la primera
!>          superdiagonal y la diagonal de la matriz tridiagonal T
!>          se devuelven en las filas KD y KD+1 de AB, y si UPLO = 'L',
!>          la diagonal y la primera subdiagonal de T se devuelven en las
!>          primeras dos filas de AB.
!>

LDAB

!>          LDAB es INTEGER
!>          La dimensión principal del array AB.  LDAB >= KD + 1.
!>

W

!>          W es un array de DOUBLE PRECISION, de dimensión (N)
!>          Si INFO = 0, los valores propios en orden ascendente.
!>

Z

!>          Z es un array de COMPLEX*16, de dimensión (LDZ, N)
!>          Si JOBZ = 'V', entonces si INFO = 0, Z contiene los vectores
!>          propios ortonormales de la matriz A, con la i-ésima columna de Z
!>          conteniendo el vector propio asociado con W(i).
!>          Si JOBZ = 'N', entonces Z no se referencia.
!>

LDZ

!>          LDZ es INTEGER
!>          La dimensión principal del array Z.  LDZ >= 1, y si
!>          JOBZ = 'V', LDZ >= max(1,N).
!>

WORK

!>          WORK es un array de COMPLEX*16, de dimensión (MAX(1,LWORK))
!>          En la salida, si INFO = 0, WORK(1) devuelve el LWORK óptimo.
!>

LWORK

!>          LWORK es INTEGER
!>          La longitud del array WORK. LWORK >= 1, cuando N <= 1;
!>          de lo contrario
!>          Si JOBZ = 'N' y N > 1, LWORK debe ser consultado.
!>                                   LWORK = MAX(1, dimension) donde
!>                                   dimension = (2KD+1)*N + KD*NTHREADS
!>                                   donde KD es el tamaño de la banda.
!>                                   NTHREADS es el número de hilos usados cuando
!>                                   la compilación openMP está habilitada, de lo
!>                                   contrario =1.
!>          Si JOBZ = 'V' y N > 1, LWORK debe ser consultado. Todavía no está
!>          disponible.
!>
!>          Si LWORK = -1, entonces se asume una consulta de espacio de
!>          trabajo; la rutina solo calcula los tamaños óptimos de los arrays
!>          WORK, RWORK y IWORK, devuelve estos valores como las primeras
!>          entradas de los arrays WORK, RWORK e IWORK, y XERBLA no emite
!>          ningún mensaje de error relacionado con LWORK o LRWORK o LIWORK.
!>

RWORK

!>          RWORK es un array de DOUBLE PRECISION,
!>                                         de dimensión (LRWORK)
!>          En la salida, si INFO = 0, RWORK(1) devuelve el LRWORK óptimo.
!>

LRWORK

!>          LRWORK es INTEGER
!>          La dimensión del array RWORK.
!>          Si N <= 1,               LRWORK debe ser al menos 1.
!>          Si JOBZ = 'N' y N > 1, LRWORK debe ser al menos N.
!>          Si JOBZ = 'V' y N > 1, LRWORK debe ser al menos
!>                        1 + 5*N + 2*N**2.
!>
!>          Si LRWORK = -1, entonces se asume una consulta de espacio de
!>          trabajo; la rutina solo calcula los tamaños óptimos de los arrays
!>          WORK, RWORK y IWORK, devuelve estos valores como las primeras
!>          entradas de los arrays WORK, RWORK e IWORK, y XERBLA no emite
!>          ningún mensaje de error relacionado con LWORK o LRWORK o LIWORK.
!>

IWORK

!>          IWORK es un array de INTEGER, de dimensión (MAX(1,LIWORK))
!>          En la salida, si INFO = 0, IWORK(1) devuelve el LIWORK óptimo.
!>

LIWORK

!>          LIWORK es INTEGER
!>          La dimensión del array IWORK.
!>          Si JOBZ = 'N' o N <= 1, LIWORK debe ser al menos 1.
!>          Si JOBZ = 'V' y N > 1, LIWORK debe ser al menos 3 + 5*N .
!>
!>          Si LIWORK = -1, entonces se asume una consulta de espacio de
!>          trabajo; la rutina solo calcula los tamaños óptimos de los arrays
!>          WORK, RWORK y IWORK, devuelve estos valores como las primeras
!>          entradas de los arrays WORK, RWORK e IWORK, y XERBLA no emite
!>          ningún mensaje de error relacionado con LWORK o LRWORK o LIWORK.
!>

INFO

!>          INFO es INTEGER
!>          = 0:  finalización exitosa.
!>          < 0:  si INFO = -i, el i-ésimo argumento tenía un valor ilegal.
!>          > 0:  si INFO = i, el algoritmo no convergió; i
!>                elementos fuera de la diagonal de una forma tridiagonal
!>                intermedia no convergieron a cero.
!>

NAME

zhbevd_2stage - solves a general band matrix eigenvalue problem.

SYNOPSIS

    SUBROUTINE ZHBEVD_2STAGE( JOBZ, UPLO, N, KD, AB, LDAB, D, Z, LDZ, RWORK,
                              LDWORK, INFO )
        CHARACTER *(*)           :: JOBZ
        CHARACTER *(*)           :: UPLO
        INTEGER                  :: KD
        INTEGER                  :: LDAB
        INTEGER                  :: LDWORK
        INTEGER                  :: LDZ
        INTEGER                  :: N
        DOUBLE PRECISION          :: D( * )
        INTEGER                  :: INFO
        DOUBLE COMPLEX             :: AB( * )
        DOUBLE COMPLEX             :: RWORK( * )
        DOUBLE COMPLEX             :: Z( * )

Function/Subroutine Documentation

The subroutine ZHBEVD_2stage computes the eigenvalues and eigenvectors of a complex general band Hermitian positive definite eigenvalue problem.

It uses a two-stage algorithm that consists of:

  • Reducing the band Hermitian matrix to tridiagonal form.
  • Computing the eigenvalues and eigenvectors of the resulting tridiagonal matrix.

The function is intended for use in applications that require high accuracy and performance, such as electronic structure calculations in computational physics and chemistry.

The algorithm is described in the following papers:

!> J. Dongarra, S. Tomov, and Z. Zhang.
!> Improving the accuracy of the QR eigenvalue algorithm for unsymmetric
!> matrices.
!> SIAM Journal on Matrix Analysis and Applications, 34(3):853-871, 2013.
!> http://dx.doi.org/10.1137/120895383
!>
!> J. K. Anagnostides, N. D. K. Papadelis, and T. S. Papatheodorou.
!> A divide-and-conquer algorithm for the generalized eigenvalue problem
!> of band Hermitian matrices.
!> ACM Transactions on Mathematical Software (TOMS), 36(4):1-22, 2009.
