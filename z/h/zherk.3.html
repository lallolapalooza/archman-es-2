Documentación de Función/Subrutina

subrutina zherk (carácter uplo, carácter trans, entero n, entero k, doble precisión alpha, complejo*16, dimensión(lda,*) a, entero lda, doble precisión beta, complejo*16, dimensión(ldc,*) c, entero ldc)

ZHERK

Propósito:

!>
!> ZHERK  realiza una de las operaciones hermíticas de rango k
!>
!>    C := alpha*A*A**H + beta*C,
!>
!> o
!>
!>    C := alpha*A**H*A + beta*C,
!>
!> donde  alpha y beta  son  escalares  reales,  C es una  matriz  hermítica  de n x n
!> y  A  es una  matriz de n x k  en el primer caso y una matriz de k x n
!> en el segundo caso.
!>

Parámetros

UPLO 
!>          UPLO es CARACTER*1
!>           Al entrar,  UPLO  especifica  si la parte  triangular  superior o inferior
!>           del array  C  debe ser referenciada como:
!>
!>              UPLO = 'U' o 'u'   Solo la parte triangular superior de C
!>                                  será referenciada.
!>
!>              UPLO = 'L' o 'l'   Solo la parte triangular inferior de C
!>                                  será referenciada.
!>

TRANS

!>          TRANS es CARACTER*1
!>           Al entrar,  TRANS  especifica la operación a realizar como:
!>
!>              TRANS = 'N' o 'n'   C := alpha*A*A**H + beta*C.
!>
!>              TRANS = 'C' o 'c'   C := alpha*A**H*A + beta*C.
!>

N

!>          N es ENTERO
!>           Al entrar,  N  especifica el orden de la matriz C.  N debe ser
!>           al menos cero.
!>

K

!>          K es ENTERO
!>           Al entrar con  TRANS = 'N' o 'n',  K  especifica el número
!>           de  columnas   de la   matriz   A,   y al   entrar   con
!>           TRANS = 'C' o 'c',  K  especifica el número de filas de la
!>           matriz A.  K debe ser al menos cero.
!>

ALPHA

!>          ALPHA es DOBLE PRECISIÓN .
!>           Al entrar, ALPHA especifica el escalar alpha.
!>

A

!>          A es un array de COMPLEJO*16, dimensión ( LDA, ka ), donde ka es
!>           k  cuando  TRANS = 'N' o 'n',  y es  n  en caso contrario.
!>           Antes de entrar con  TRANS = 'N' o 'n',  la parte principal de n x k
!>           del array  A  debe contener la matriz  A,  en caso contrario
!>           la parte principal de k x n  del array  A  debe contener la
!>           matriz A.
!>

LDA

!>          LDA es ENTERO
!>           Al entrar, LDA especifica la primera dimensión de A tal como se declaró
!>           en  el  programa  (sub)  llamador.   Cuando  TRANS = 'N' o 'n'
!>           entonces  LDA debe ser al menos  max( 1, n ), en caso contrario  LDA debe
!>           ser al menos  max( 1, k ).
!>

BETA

!>          BETA es DOBLE PRECISIÓN.
!>           Al entrar, BETA especifica el escalar beta.
!>

C

!>          C es un array de COMPLEJO*16, dimensión ( LDC, N )
!>           Antes de entrar con  UPLO = 'U' o 'u',  la parte triangular superior de n x n
!>           del array C debe contener la parte triangular superior  de la
!>           matriz  hermítica  y la parte triangular estrictamente inferior de C no se referencia.  Al salir, la
!>           parte triangular superior del array  C se sobrescribe con la
!>           parte triangular superior de la matriz actualizada.
!>           Antes de entrar con  UPLO = 'L' o 'l',  la parte triangular inferior de n x n
!>           del array C debe contener la parte triangular inferior  de la
!>           matriz  hermítica  y la parte triangular estrictamente superior de C no se referencia.  Al salir, la
!>           parte triangular inferior del array  C se sobrescribe con la
!>           parte triangular inferior de la matriz actualizada.
!>           Nota que las partes imaginarias de los elementos diagonales no
!>           necesitan ser establecidas,  se asumen cero,  y al salir se
!>           establecen a cero.
!>

LDC

!>          LDC es ENTERO
!>           Al entrar, LDC especifica la primera dimensión de C tal como se declaró
!>           en  el  programa  (sub)  llamador.   LDC  debe  ser  al  menos
!>           max( 1, n ).
!>
