subroutine zhbevx_2stage (character jobz, character range, character uplo, integer n, integer kd, complex*16, dimension( ldab, * ) ab, integer ldab, complex*16, dimension( ldq, * ) q, integer ldq, double precision vl, double precision vu, integer il, integer iu, double precision abstol, integer m, double precision, dimension( * ) w, complex*16, dimension( ldz, * ) z, integer ldz, complex*16, dimension( * ) work, integer lwork, double precision, dimension( * ) rwork, integer, dimension( * ) iwork, integer, dimension( * ) ifail, integer info)

ZHBEVX_2STAGE calcula los valores propios y, opcionalmente, los vectores propios izquierdos y/o derechos para matrices HERMITIANAS DE BANDA complejas usando la técnica de 2 etapas para la reducción a tridiagonal. Los valores propios y vectores propios pueden ser seleccionados especificando un rango de valores o un rango de índices para los valores propios deseados.

Propósito:

!>
!> ZHBEVX_2STAGE calcula valores propios seleccionados y, opcionalmente, vectores propios
!> de una matriz Hermitiana de banda compleja A utilizando la técnica de 2 etapas para
!> la reducción a tridiagonal. Los valores propios y vectores propios
!> pueden ser seleccionados especificando ya sea un rango de valores o un rango de
!> índices para los valores propios deseados.
!>

Parámetros

JOBZ 
!>          JOBZ es CHARACTER*1
!>          = 'N':  Calcular solo los valores propios;
!>          = 'V':  Calcular valores propios y vectores propios.
!>                  No disponible en esta versión.
!>

RANGE

!>          RANGE es CHARACTER*1
!>          = 'A': se encontrarán todos los valores propios;
!>          = 'V': se encontrarán todos los valores propios en el intervalo semiabierto (VL,VU]
!>                 ;
!>          = 'I': se encontrarán los valores propios del IL-ésimo al IU-ésimo.
!>

UPLO

!>          UPLO es CHARACTER*1
!>          = 'U':  El triángulo superior de A está almacenado;
!>          = 'L':  El triángulo inferior de A está almacenado.
!>

N

!>          N es INTEGER
!>          El orden de la matriz A.  N >= 0.
!>

KD

!>          KD es INTEGER
!>          El número de superdiagonales de la matriz A si UPLO = 'U',
!>          o el número de subdiagonales si UPLO = 'L'.  KD >= 0.
!>

AB

!>          AB es un array COMPLEX*16, dimensión (LDAB, N)
!>          En la entrada, el triángulo superior o inferior de la matriz de banda Hermitiana
!>          A, almacenado en las primeras KD+1 filas del array. La
!>          columna j de A está almacenada en la columna j del array AB
!>          de la siguiente manera:
!>          si UPLO = 'U', AB(kd+1+i-j,j) = A(i,j) para max(1,j-kd)<=i<=j;
!>          si UPLO = 'L', AB(1+i-j,j)    = A(i,j) para j<=i<=min(n,j+kd).
!>
!>          En la salida, AB se sobrescribe con valores generados durante la
!>          reducción a forma tridiagonal.
!>

LDAB

!>          LDAB es INTEGER
!>          La dimensión principal del array AB.  LDAB >= KD + 1.
!>

Q

!>          Q es un array COMPLEX*16, dimensión (LDQ, N)
!>          Si JOBZ = 'V', la matriz unitaria N por N utilizada en la
!>                          reducción a forma tridiagonal.
!>          Si JOBZ = 'N', el array Q no se referencia.
!>

LDQ

!>          LDQ es INTEGER
!>          La dimensión principal del array Q.  Si JOBZ = 'V', entonces
!>          LDQ >= max(1,N).
!>

VL

!>          VL es DOUBLE PRECISION
!>          Si RANGE='V', el límite inferior del intervalo a
!>          investigar para los valores propios. VL < VU.
!>          No se referencia si RANGE = 'A' o 'I'.
!>

VU

!>          VU es DOUBLE PRECISION
!>          Si RANGE='V', el límite superior del intervalo a
!>          investigar para los valores propios. VL < VU.
!>          No se referencia si RANGE = 'A' o 'I'.
!>

IL

!>          IL es INTEGER
!>          Si RANGE='I', el índice del
!>          valor propio más pequeño a devolver.
!>          1 <= IL <= IU <= N, si N > 0; IL = 1 e IU = 0 si N = 0.
!>          No se referencia si RANGE = 'A' o 'V'.
!>

IU

!>          IU es INTEGER
!>          Si RANGE='I', el índice del
!>          valor propio más grande a devolver.
!>          1 <= IL <= IU <= N, si N > 0; IL = 1 e IU = 0 si N = 0.
!>          No se referencia si RANGE = 'A' o 'V'.
!>

ABSTOL

!>          ABSTOL es DOUBLE PRECISION
!>          La tolerancia de error absoluto para los valores propios.
!>          Un valor propio aproximado se acepta como convergido
!>          cuando se determina que yace en un intervalo [a,b]
!>          de ancho menor o igual a
!>
!>          ABSTOL + EPS *   max( |a|,|b| ) ,
!>
!>          donde EPS es la precisión de la máquina. Si ABSTOL es menor que
!>          o igual a cero, entonces EPS*|T| será usado en su lugar,
!>          donde |T| es la norma 1 de la matriz tridiagonal obtenida
!>          al reducir AB a forma tridiagonal.
!>
!>          Los valores propios se calcularán con mayor precisión cuando ABSTOL
!>          se establezca en el doble del umbral de subdesbordamiento 2*DLAMCH('S'), no cero.
!>          Si esta rutina retorna con INFO > 0, indicando que algunos
!>          vectores propios no convergieron, intente establecer ABSTOL a
!>          2*DLAMCH('S').
!>
!>          Ver  por Demmel y
!>          Kahan, LAPACK Working Note #3.
!>

M

!>          M es INTEGER
!>          El número total de valores propios encontrados.  0 <= M <= N.
!>          Si RANGE = 'A', M = N, y si RANGE = 'I', M = IU-IL+1.
!>

W

!>          W es un array DOUBLE PRECISION, dimensión (N)
!>          Los primeros M elementos contienen los valores propios seleccionados en
!>          orden ascendente.
!>

Z

!>          Z es un array COMPLEX*16, dimensión (LDZ, max(1,M))
!>          Si JOBZ = 'V', entonces si INFO = 0, las primeras M columnas de Z
!>          contienen los vectores propios ortonormales de la matriz A
!>          correspondientes a los valores propios seleccionados, con la i-ésima
!>          columna de Z conteniendo el vector propio asociado con W(i).
!>          Si un vector propio falla en converger, entonces esa columna de Z
!>          contiene la última aproximación al vector propio, y el
!>          índice del vector propio se devuelve en IFAIL.
!>          Si JOBZ = 'N', entonces Z no se referencia.
!>          Nota: el usuario debe asegurarse de que se suministran al menos max(1,M) columnas
!>          en el array Z; si RANGE = 'V', el valor exacto de M
!>          no se conoce de antemano y se debe usar un límite superior.
!>

LDZ

!>          LDZ es INTEGER
!>          La dimensión principal del array Z.  LDZ >= 1, y si
!>          JOBZ = 'V', LDZ >= max(1,N).
!>

WORK

!>          WORK es un array COMPLEX*16, dimensión (LWORK)
!>

LWORK

!>          LWORK es INTEGER
!>          La longitud del array WORK. LWORK >= 1, cuando N <= 1;
!>          de lo contrario
!>          Si JOBZ = 'N' y N > 1, LWORK debe ser consultado.
!>                                   LWORK = MAX(1, dimension) donde
!>                                   dimen

NAME

zhbevx_2stage - zlbevx_2stage computes the eigenvalues and eigenvectors of a complex Hermitian band matrix.

SYNOPSIS

call zhbevx_2stage(JOBZ, RANGE, UPLO, N, KD, AB, LDAB, Q, LDQ, VL, VU, IL, IU, M, W, Z, LDZ, DWORK, RWORK, IWORK, INFO)

Function/Subroutine Documentation

Parameters

JOBZ
CHARACTER*1. Required.
Specifies whether to compute only the eigenvalues or both eigenvalues and eigenvectors for the Hermitian eigenvalue problem.
JOBZ = 'N': Compute only the eigenvalues of A.
JOBZ = 'V': Compute the eigenvalues and eigenvectors of A.
RANGE
CHARACTER*1. Required.
Specifies the range of eigenvalues to be computed.
RANGE = 'A': All eigenvalues will be computed.
RANGE = 'V': All eigenvalues in the interval (VL, VU] will be computed.
RANGE = 'I': The IL-th through the IU-th eigenvalues will be computed.
UPLO
CHARACTER*1. Required.
UPLO = 'U': Upper triangle of A, AB, and Q will be used.
UPLO = 'L': Lower triangle of A, AB, and Q will be used.
N
INTEGER. Required.
The order of the matrix A. N >= 0.
KD
INTEGER. Required.
The number of super- or sub-diagonals of the band matrix A. KD >= 0.
AB
COMPLEX*16 array, dimension (LDAB, N). Required.
On entry, the complex Hermitian band matrix A in band storage format. The (i,j)-th element of A is stored in the (KD+1 + i-j, j)-th element of AB if UPLO = 'U' and i <= j, or in the (i-j+1, j)-th element of AB if UPLO = 'L' and i >= j.
On exit, if JOBZ = 'V' and INFO = 0, the transformed matrix A.
LDAB
INTEGER. Required.
On entry, the leading dimension of the array AB. LDAB >= KD+1.
Q
COMPLEX*16 array, dimension (LDQ, N).
On exit, if JOBZ = 'V', then the n-by-n matrix of eigenvectors Q.
If JOBZ = 'N', then the array Q is not referenced.
LDQ
INTEGER. Required.
On entry, the leading dimension of the array Q. If JOBZ = 'V', then LDQ >= max(1, N).
VL
DOUBLE PRECISION. Required.
On entry if RANGE = 'V', the lower bound of the eigenvalue interval.
VU
DOUBLE PRECISION. Required.
On entry if RANGE = 'V', the upper bound of the eigenvalue interval.
IL
INTEGER. Required.
On entry if RANGE = 'I', the index of the smallest eigenvalue to be computed.
IU
INTEGER. Required.
On entry if RANGE = 'I', the index of the largest eigenvalue to be computed.
M
INTEGER. Output.
On exit, the number of eigenvalues found in the specified range.
W
DOUBLE PRECISION array, dimension (N).
On exit, the eigenvalues, sorted in an ascending order. If RANGE = 'I' or 'V', the stub contains the computed eigenvalues.
Z
COMPLEX*16 array, dimension (LDZ, N).
On exit, if JOBZ = 'V', the eigenvectors of the matrix A. The column Z(:, i) is the eigenvector corresponding to the eigenvalue W(i).
If JOBZ = 'N', then the array Z is not referenced.
LDZ
INTEGER. Required.
On entry, the leading dimension of the array Z. If JOBZ = 'V', then LDZ >= max(1, N).
DWORK
COMPLEX*16 array, dimension (LDWORK).
LRWORK:DOUBLE PRECISION array, dimension (max(7*N, 2*KD)).
LIWORK:INTEGER array, dimension (max(5*N, 2*KD)).
Work array. The size of DWORK, RWORK, and IWORK depends on the value of N and KD.
LDWORK: INTEGER. Required.
On entry, dimension of DWORK. LDWORK >= 1. If LWORK = -1, then LDWORK is the minimum size required for the workspace. The workspace must be at least 
sion = (2*KD+1)*N + KD*NTHREADS
!>                                   where KD is the size of the band.
!>                                   NTHREADS is the number of threads used when
!>                                   openMP compilation is enabled, otherwise =1.
!>          If JOBZ = 'V' and N > 1, LWORK must be queried. Not yet available.
!>
!>          If LWORK = -1, then a workspace query is assumed; the routine
!>          only calculates the optimal sizes of the WORK, RWORK and
!>          IWORK arrays, returns these values as the first entries of
!>          the WORK, RWORK and IWORK arrays, and no error message
!>          related to LWORK or LRWORK or LIWORK is issued by XERBLA.
!>
RWORK
DOUBLE PRECISION array, dimension (7*N).
IWORK
INTEGER array, dimension (5*N).
IFAIL
INTEGER array, dimension (N).
If JOBZ = 'V', then if INFO = 0, the first M elements of IFAIL are zero. If INFO > 0, then IFAIL contains the indices of the eigenvectors that failed to converge. If JOBZ = 'N', then IFAIL is not referenced.
INFO
INTEGER.
  • 0: successful exit
  • < 0: if INFO = -i, the i-th argument had an illegal value
  • > 0: if INFO = i, then i eigenvectors failed to converge. Their indices are stored in array IFAIL.
