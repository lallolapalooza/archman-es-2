Documentación de Función/Subrutina

subroutine zher2k (character uplo, character trans, integer n, integer k, complex*16 alpha, complex*16, dimension(lda,*) a, integer lda, complex*16, dimension(ldb,*) b, integer ldb, double precision beta, complex*16, dimension(ldc,*) c, integer ldc)

ZHER2K

Propósito:

!>
!> ZHER2K  realiza una de las operaciones hermíticas de rango 2k
!>
!>    C := alpha*A*B**H + conjg( alpha )*B*A**H + beta*C,
!>
!> o
!>
!>    C := alpha*A**H*B + conjg( alpha )*B**H*A + beta*C,
!>
!> donde  alpha y beta  son escalares con  beta  real,  C es una matriz
!> hermítica de n por n y  A y B son matrices de n por k en el primer caso
!> y de k por n en el segundo caso.
!>

Parámetros

UPLO 
!>          UPLO es CHARACTER*1
!>           En la entrada,  UPLO  especifica si la parte triangular
!>           superior o inferior del array  C  se debe referenciar como
!>           sigue:
!>
!>              UPLO = 'U' o 'u'   Solo se debe referenciar la parte triangular
!>                                  superior de C.
!>
!>              UPLO = 'L' o 'l'   Solo se debe referenciar la parte triangular
!>                                  inferior de C.
!>

TRANS

!>          TRANS es CHARACTER*1
!>           En la entrada,  TRANS  especifica la operación a realizar
!>           como sigue:
!>
!>              TRANS = 'N' o 'n'    C := alpha*A*B**H          +
!>                                         conjg( alpha )*B*A**H +
!>                                         beta*C.
!>
!>              TRANS = 'C' o 'c'    C := alpha*A**H*B          +
!>                                         conjg( alpha )*B**H*A +
!>                                         beta*C.
!>

N

!>          N es INTEGER
!>           En la entrada,  N especifica el orden de la matriz C.  N
!>           debe ser al menos cero.
!>

K

!>          K es INTEGER
!>           En la entrada con  TRANS = 'N' o 'n',  K  especifica el
!>           número de  columnas  de las matrices  A y B,  y en la
!>           entrada con  TRANS = 'C' o 'c',  K  especifica el número de
!>           filas de las matrices  A y B.  K debe ser al menos cero.
!>

ALPHA

!>          ALPHA es COMPLEX*16 .
!>           En la entrada, ALPHA especifica el escalar alpha.
!>

A

!>          A es un array COMPLEX*16 , de dimensión ( LDA, ka ), donde ka es
!>           k  cuando  TRANS = 'N' o 'n',  y es  n  en caso contrario.
!>           Antes de la entrada con  TRANS = 'N' o 'n',  la parte
!>           principal de n por k del array  A  debe contener la matriz
!>           A, en caso contrario, la parte principal de k por n del array
!>           A  debe contener la matriz A.
!>

LDA

!>          LDA es INTEGER
!>           En la entrada, LDA especifica la primera dimensión de A tal
!>           como se declaró en el programa (sub)llamador.  Cuando
!>           TRANS = 'N' o 'n',  entonces  LDA debe ser al menos  max( 1,
!>           n ), en caso contrario, LDA debe ser al menos  max( 1, k ).
!>

B

!>          B es un array COMPLEX*16 , de dimensión ( LDB, kb ), donde kb es
!>           k  cuando  TRANS = 'N' o 'n',  y es  n  en caso contrario.
!>           Antes de la entrada con  TRANS = 'N' o 'n',  la parte
!>           principal de n por k del array  B  debe contener la matriz
!>           B, en caso contrario, la parte principal de k por n del array
!>           B  debe contener la matriz B.
!>

LDB

!>          LDB es INTEGER
!>           En la entrada, LDB especifica la primera dimensión de B tal
!>           como se declaró en el programa (sub)llamador.  Cuando
!>           TRANS = 'N' o 'n',  entonces  LDB debe ser al menos  max( 1,
!>           n ), en caso contrario, LDB debe ser al menos  max( 1, k ).
!>           Sin cambios en la salida.
!>

BETA

!>          BETA es DOUBLE PRECISION .
!>           En la entrada, BETA especifica el escalar beta.
!>

C

!>          C es un array COMPLEX*16 , de dimensión ( LDC, N )
!>           Antes de la entrada con  UPLO = 'U' o 'u',  la parte superior
!>           de n por n del array C debe contener la parte triangular
!>           superior de la matriz hermítica y la parte triangular inferior
!>           estricta de C no se referencia.  En la salida, la parte
!>           triangular superior del array  C se sobrescribe con la parte
!>           triangular superior de la matriz actualizada.
!>           Antes de la entrada con  UPLO = 'L' o 'l',  la parte inferior
!>           de n por n del array C debe contener la parte triangular
!>           inferior de la matriz hermítica y la parte triangular superior
!>           estricta de C no se referencia.  En la salida, la parte
!>           triangular inferior del array  C se sobrescribe con la parte
!>           triangular inferior de la matriz actualizada.
!>           Tenga en cuenta que las partes imaginarias de los elementos
!>           diagonales no es necesario que se establezcan, se asumen como
!>           cero, y en la salida se establecen a cero.
!>

LDC

!>          LDC es INTEGER
!>           En la entrada, LDC especifica la primera dimensión de C tal
!>           como se declaró en el programa (sub)llamador.  LDC debe ser
!>           al menos  max( 1, n ).
!>
