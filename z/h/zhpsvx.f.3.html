ZHPSVX calcula la solución al sistema de ecuaciones lineales A * X = B para matrices HERMITIANAS

Propósito:

!>
!> ZHPSVX utiliza la factorización de pivoteo diagonal A = U*D*U**H o
!> A = L*D*L**H para calcular la solución a un sistema complejo de ecuaciones
!> lineales A * X = B, donde A es una matriz Hermitiana N-por-N almacenada
!> en formato empaquetado y X y B son matrices N-por-NRHS.
!>
!> También se proporcionan cotas de error en la solución y una estimación
!> de la condición.
!>

Descripción:

!>
!> Se realizan los siguientes pasos:
!>
!> 1. Si FACT = 'N', se utiliza el método de pivoteo diagonal para factorizar A como
!>       A = U * D * U**H,  si UPLO = 'U', o
!>       A = L * D * L**H,  si UPLO = 'L',
!>    donde U (o L) es un producto de matrices triangulares unitarias superiores (inferiores)
!>    y de permutación, y D es Hermitiana y diagonal por bloques con bloques
!>    diagonales de 1x1 y 2x2.
!>
!> 2. Si algún D(i,i)=0, de modo que D sea exactamente singular, la rutina
!>    regresa con INFO = i. De lo contrario, se utiliza la forma factorizada de A
!>    para estimar el número de condición de la matriz A. Si la
!>    inversa del número de condición es menor que la precisión de la máquina,
!>    se devuelve INFO = N+1 como advertencia, pero la rutina continúa
!>    resolviendo para X y calculando cotas de error como se describe a continuación.
!>
!> 3. Se resuelve el sistema de ecuaciones para X utilizando la forma factorizada
!>    de A.
!>
!> 4. Se aplica refinamiento iterativo para mejorar la matriz de solución calculada
!>    y calcular cotas de error y errores residuales para ella.
!>

Parámetros

FACT 
!>          FACT es CHARACTER*1
!>          Especifica si la forma factorizada de A se ha suministrado o no
!>          en la entrada.
!>          = 'F':  En la entrada, AFP y IPIV contienen la forma factorizada de
!>                  A.  AFP y IPIV no se modificarán.
!>          = 'N':  La matriz A se copiará en AFP y se factorizará.
!>

UPLO

!>          UPLO es CHARACTER*1
!>          = 'U':  Se almacena el triángulo superior de A;
!>          = 'L':  Se almacena el triángulo inferior de A.
!>

N

!>          N es INTEGER
!>          El número de ecuaciones lineales, es decir, el orden de
!>          la matriz A.  N >= 0.
!>

NRHS

!>          NRHS es INTEGER
!>          El número de lados derechos, es decir, el número de columnas
!>          de las matrices B y X.  NRHS >= 0.
!>

AP

!>          AP es un array COMPLEX*16, de dimensión (N*(N+1)/2)
!>          El triángulo superior o inferior de la matriz Hermitiana A, empaquetado
!>          por columnas en un array lineal.  La j-ésima columna de A se almacena
!>          en el array AP de la siguiente manera:
!>          si UPLO = 'U', AP(i + (j-1)*j/2) = A(i,j) para 1<=i<=j;
!>          si UPLO = 'L', AP(i + (j-1)*(2*n-j)/2) = A(i,j) para j<=i<=n.
!>          Ver más abajo para más detalles.
!>

AFP

!>          AFP es un array COMPLEX*16, de dimensión (N*(N+1)/2)
!>          Si FACT = 'F', entonces AFP es un argumento de entrada y en la entrada
!>          contiene la matriz diagonal por bloques D y los multiplicadores utilizados
!>          para obtener el factor U o L de la factorización
!>          A = U*D*U**H o A = L*D*L**H, calculados por ZHPTRF, almacenados como
!>          una matriz triangular empaquetada en el mismo formato de almacenamiento que A.
!>
!>          Si FACT = 'N', entonces AFP es un argumento de salida y en la salida
!>          contiene la matriz diagonal por bloques D y los multiplicadores utilizados
!>          para obtener el factor U o L de la factorización
!>          A = U*D*U**H o A = L*D*L**H, calculados por ZHPTRF, almacenados como
!>          una matriz triangular empaquetada en el mismo formato de almacenamiento que A.
!>

IPIV

!>          IPIV es un array INTEGER, de dimensión (N)
!>          Si FACT = 'F', entonces IPIV es un argumento de entrada y en la entrada
!>          contiene detalles de los intercambios y la estructura de bloques
!>          de D, según lo determinado por ZHPTRF.
!>          Si IPIV(k) > 0, entonces las filas y columnas k e IPIV(k) fueron
!>          intercambiadas y D(k,k) es un bloque diagonal de 1x1.
!>          Si UPLO = 'U' e IPIV(k) = IPIV(k-1) < 0, entonces las filas y
!>          columnas k-1 y -IPIV(k) fueron intercambiadas y D(k-1:k,k-1:k)
!>          es un bloque diagonal de 2x2. Si UPLO = 'L' e IPIV(k) =
!>          IPIV(k+1) < 0, entonces las filas y columnas k+1 y -IPIV(k) fueron
!>          intercambiadas y D(k:k+1,k:k+1) es un bloque diagonal de 2x2.
!>
!>          Si FACT = 'N', entonces IPIV es un argumento de salida y en la salida
!>          contiene detalles de los intercambios y la estructura de bloques
!>          de D, según lo determinado por ZHPTRF.
!>

B

!>          B es un array COMPLEX*16, de dimensión (LDB,NRHS)
!>          La matriz del lado derecho B de N x NRHS.
!>

LDB

!>          LDB es INTEGER
!>          La dimensión principal del array B.  LDB >= max(1,N).
!>

X

!>          X es un array COMPLEX*16, de dimensión (LDX,NRHS)
!>          Si INFO = 0 o INFO = N+1, la matriz solución X de N x NRHS.
!>

LDX

!>          LDX es INTEGER
!>          La dimensión principal del array X.  LDX >= max(1,N).
!>

RCOND

!>          RCOND es DOUBLE PRECISION
!>          La estimación de la inversa del número de condición de la matriz
!>          A.  Si RCOND es menor que la precisión de la máquina (en
!>          particular, si RCOND = 0), la matriz es singular con precisión de trabajo.
!>          Esta condición se indica con un código de retorno INFO > 0.
!>

FERR

!>          FERR es un array DOUBLE PRECISION, de dimensión (NRHS)
!>          La cota de error hacia adelante estimada para cada vector solución
!>          X(j) (la j-ésima columna de la matriz solución X).
!>          Si XTRUE es la solución verdadera correspondiente a X(j), FERR(j)
!>          es una cota superior estimada para la magnitud del elemento más grande
!>          en (X(j) - XTRUE) dividido por la magnitud del elemento más grande
!>          en X(j). La estimación es tan confiable como
!>          la estimación de RCOND, y es casi siempre una ligera
!>          sobreestimación del error verdadero.
!>

BERR

!>          BERR es un array DOUBLE PRECISION, de dimensión (NRHS)
!>          El error residual relativo componente a componente de cada vector solución
!>          X(j) (es decir, el cambio relativo más pequeño en
!>          cualquier elemento de A o B que haga que X(j) sea una solución exacta).
!>

WORK

!>          WORK es un array COMPLEX*16, de dimensión (2*N)
!>

RWORK

!>          RWORK es un array DOUBLE PRECISION, de dimensión (N)
!>

INFO

!>          INFO es INTEGER
!>          = 0: ejecución exitosa
!>          < 0: si INFO = -i, entonces el i-ésimo argumento, siendo 1,
!>               había tenido un valor ilegal.
!>          > 0: si INFO = i y i <= N, entonces el pivote diagonal D(i,i)
!>               es cero. La factorización podría no estar completa.
!>               El resultado de la solución y las cotas de error no son
!>               confiables.
!>               Si INFO = N+1, la inversa del número de condición
!>               estimada es menor que la precisión de la máquina. La matriz
!>               es singular o casi singular con precisión de trabajo, y la
!>               solución puede no ser precisa.
!>

NAME

zhpsvx — zhpsvx

SYNOPSIS

 subroutine zhpsvx(fact, trans, n, nrhs, apx, lda, ipiv, b, ldb, x, ldx, rcond,
          ferr, rpiv, info)

     character complex*16 :: apx(*), b(*), x(*)
     integer :: n, nrhs, lda, ldb, ldx
     integer :: ipiv(*)
     real*8 :: rcond, ferr(*)
     character*1 :: fact, trans
     integer :: info
     real*8 :: rpiv(*)

Function/Subroutine Documentation

Purpose: 

 ========
 
 zhpsvx uses the left looking RH factorization to compute the solution to a
 complex conjugate transpose system of linear equations
 
    A * x = b
 
 or
 
    A**T * x = b
 
 or
 
    A**H * x = b
 
 where A is a complex Hermitian n x n matrix, which is supplied in
'packed' format. Whenever possible, the routine uses the fastest
 available algorithm, by choosing a blocked algorithm if the dimensions
 permit, the equivalent nonsymmetric reduction to upper triangular form and
 then solves the triangular system.
 
 Arguments
 =========
 
 fact    (input) character*1
         Specifies whether or not the factorization of A is supplied on
         entry. 
 
         'N': the driver routine will factorize A.
 
         'F': the factorization of A has already been computed and
              passed to the driver routine.
 
         'E': the factorization of A has already been computed in
              conditionally optimal 'exact' form.
 
 trans   (input) character*1
         'N': the system to be solved is A * x = b.
 
         'C': the system to be solved is A**H * x = b.
 
         'T': the system to be solved is A**T * x = b.
 
 n       (input) integer
         The order of the matrix A.  n >= 0.
 
 nrhs    (input) integer
         The number of right hand sides, i.e., the number of columns in the
         arrays B and X.  nrhs >= 0.
 
 apx     (input/output) character complex*16 array, dimension (N*(N+1)/2)
         On entry, the n x n coefficient matrix A in packed format. 
         'N':             the array apx contains the packed coefficient matrix A.
'        'F':             the array apx contains the packed factorization A = P*U*U**H*Q
'                           of the matrix A.
'        'E':             the array apx contains the packed factorization A = P*U*U**H*Q
'                           of the matrix A in exactly factored form.
'        On exit:
'        if fact = 'N', the array apx contains the packed factorization
'        A = P*U*U**H*Q.
'
'lwork   (input) integer
'        The dimension of the array apx.
'
'ipiv    (input/output) integer array, dimension (N)
'        Details of the interchanges in the factorization.  ipiv[i] is the
'        pivot row positive if block row i was interchanged with a block row
'        below it, and negative if block row i was interchanged with a block
'        row above it.
'
'b       (input) character complex*16 array, dimension (LDB,N)
'        If trans = 'N', the n x nrhs right hand side matrix, B.
'        If trans = 'C' or 'T', the n x nrhs right hand side matrix, B.
'
'ldb     (input) integer
'        The leading dimension of array b. LDB >= max(1,N).
'
'x       (output) character complex*16 array, dimension (LDX,NRHS)
'        If trans = 'N', the n x nrhs solution matrix, X.
'        If trans = 'C' or 'T', the n x nrhs solution matrix, X.
'
'ldx     (input) integer
'        The leading dimension of array x. LDX >= max(1,N).
'
'rcond   (output) real*8
'        The estimate of the reciprocal condition number of the matrix A.
'        The matrix is singular if rcond is less than the machine epsilon.
'
'ferr    (output) real*8 array, dimension (NRHS)
'        The estimates and error bounds for the errors in the solutions
'        in the columns of X.  ferr[j] contains an estimate of the norm
'        of the error and                     max(i) |x_i - x_i| / |x_i|,
'        for the j-th solution vector,       where x_i is the i-th input
'        to the routine.
'
'rpiv    (output) real*8 array, dimension (N)
'        Details of the scaling factors used during the factorization.
'
'info    (output) integer
'        = 0:  successful exit
'        < 0:  if the i-th argument had an illegal value
'              > 0:  if i <= N: D(i,i) is exactly zero.  The factorization
'                    has been completed but the factor D is exactly
'                    singular, so the solution and error bounds could
'                    not be computed. RCOND = 0 is returned.
'              = N+1: D is nonsingular, but RCOND is less than machine
'                    precision, meaning that the matrix is singular
'                    to working precision.  Nevertheless, the
'                    solution and error bounds are computed because
'                    there are a number of situations where the
'                    computed solution can be more accurate than the
'                    value of RCOND would suggest.
'

Further Details:

  The packed storage scheme is illustrated by the following example
  when N = 4, UPLO = 'U':

  Two-dimensional storage of the Hermitian matrix A:

     a11 a12 a13 a14
         a22 a23 a24
             a33 a34     (aij = conjg(aji))
                 a44

  Packed storage of the upper triangle of A:

  AP = [ a11, a12, a22, a13, a23, a33, a14, a24, a34, a44 ]
