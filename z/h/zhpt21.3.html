subrutina zhpt21 (integer itype, character uplo, integer n, integer kband, complex*16, dimension( * ) ap, double precision, dimension( * ) d, double precision, dimension( * ) e, complex*16, dimension( ldu, * ) u, integer ldu, complex*16, dimension( * ) vp, complex*16, dimension( * ) tau, complex*16, dimension( * ) work, double precision, dimension( * ) rwork, double precision, dimension( 2 ) result)

ZHPT21

Propósito:

!>
!> ZHPT21  generalmente comprueba una descomposición de la forma
!>
!>         A = U S U**H
!>
!> donde **H significa transpuesta conjugada, A es hermitiana, U es
!> unitaria y S es diagonal (si KBAND=0) o (real) simétrica
!> tridiagonal (si KBAND=1). Si ITYPE=1, entonces U se representa como
!> una matriz densa, de lo contrario U se expresa como un producto de
!> transformaciones de Householder, cuyos vectores se almacenan en el
!> array  y cuyas constantes de escala están en  
 usaremos la letra  para referirnos al producto de transformaciones de
!> Householder (que debería ser igual a U).
!>
!> Específicamente, si ITYPE=1, entonces:
!>
!>         RESULT(1) = | A - U S U**H | / ( |A| n ulp ) y
!>         RESULT(2) = | I - U U**H | / ( n ulp )
!>
!> Si ITYPE=2, entonces:
!>
!>         RESULT(1) = | A - V S V**H | / ( |A| n ulp )
!>
!> Si ITYPE=3, entonces:
!>
!>         RESULT(1) = | I - U V**H | / ( n ulp )
!>
!> El almacenamiento empaquetado significa que, por ejemplo, si UPLO='U', entonces las columnas
!> del triángulo superior de A se almacenan una tras otra, de modo que
!> A(1,j+1) sigue inmediatamente a A(j,j) en el array AP. Del mismo modo, si
!> UPLO='L', entonces las columnas del triángulo inferior de A se almacenan una tras otra
!> en AP, de modo que A(j+1,j+1) sigue inmediatamente a A(n,j)
!> en el array AP. Esto significa que A(i,j) se almacena en:
!>
!>    AP( i + j*(j-1)/2 )                 si UPLO='U'
!>
!>    AP( i + (2*n-j)*(j-1)/2 )           si UPLO='L'
!>
!> El array VP tiene la misma relación con la matriz V que A con
!> AP.
!>
!> Para ITYPE > 1, la transformación U se expresa como un producto
!> de transformaciones de Householder:
!>
!>    Si UPLO='U', entonces  V = H(n-1)...H(1),  donde
!>
!>        H(j) = I  -  tau(j) v(j) v(j)**H
!>
!>    y los primeros j-1 elementos de v(j) se almacenan en V(1:j-1,j+1),
!>    (es decir, VP( j*(j+1)/2 + 1 : j*(j+1)/2 + j-1 ) ),
!>    el elemento j es 1, y los últimos n-j elementos son 0.
!>
!>    Si UPLO='L', entonces  V = H(1)...H(n-1),  donde
!>
!>        H(j) = I  -  tau(j) v(j) v(j)**H
!>
!>    y los primeros j elementos de v(j) son 0, el (j+1)-ésimo es 1, y los
!>    elementos del (j+2)-ésimo al n-ésimo se almacenan en V(j+2:n,j) (es decir,
!>    en VP( (2*n-j)*(j-1)/2 + j+2 : (2*n-j)*(j-1)/2 + n ) .)
!>

Parámetros

ITYPE 
!>          ITYPE es INTEGER
!>          Especifica el tipo de pruebas a realizar.
!>          1: U expresada como una matriz unitaria densa:
!>             RESULT(1) = | A - U S U**H | / ( |A| n ulp )   y
!>             RESULT(2) = | I - U U**H | / ( n ulp )
!>
!>          2: U expresada como un producto V de transformaciones de Housholder:
!>             RESULT(1) = | A - V S V**H | / ( |A| n ulp )
!>
!>          3: U expresada tanto como una matriz unitaria densa y
!>             como un producto de transformaciones de Housholder:
!>             RESULT(1) = | I - U V**H | / ( n ulp )
!>

UPLO

!>          UPLO es CHARACTER
!>          Si UPLO='U', se utilizará el triángulo superior de A y V y
!>          el triángulo (estrictamente) inferior no se referenciará.
!>          Si UPLO='L', se utilizará el triángulo inferior de A y V y
!>          el triángulo (estrictamente) superior no se referenciará.
!>

N

!>          N es INTEGER
!>          El tamaño de la matriz. Si es cero, ZHPT21 no hace nada.
!>          Debe ser al menos cero.
!>

KBAND

!>          KBAND es INTEGER
!>          El ancho de banda de la matriz. Solo puede ser cero o uno.
!>          Si es cero, S es diagonal y E no se referencia. Si
!>          es uno, S es simétrica tridiagonal.
!>

AP

!>          AP es array COMPLEX*16, dimension (N*(N+1)/2)
!>          La matriz original (no factorizada). Se asume que es
!>          hermitiana y contiene las columnas solo del triángulo superior
!>          (UPLO='U') o solo del triángulo inferior (UPLO='L'),
!>          empaquetadas una tras otra.
!>

D

!>          D es array DOUBLE PRECISION, dimension (N)
!>          La diagonal de la matriz (simétrica tri-) diagonal.
!>

E

!>          E es array DOUBLE PRECISION, dimension (N)
!>          La subdiagonal de la matriz (simétrica tri-) diagonal.
!>          E(1) es el elemento (1,2) y (2,1), E(2) es el elemento (2,3) y
!>          (3,2), etc.
!>          No se referencia si KBAND=0.
!>

U

!>          U es array COMPLEX*16, dimension (LDU, N)
!>          Si ITYPE=1 o 3, contiene la matriz unitaria en
!>          la descomposición, expresada como una matriz densa. Si ITYPE=2,
!>          entonces no se referencia.
!>

LDU

!>          LDU es INTEGER
!>          La dimensión principal de U. LDU debe ser al menos N y
!>          al menos 1.
!>

VP

!>          VP es array DOUBLE PRECISION, dimension (N*(N+1)/2)
!>          Si ITYPE=2 o 3, las columnas de este array contienen los
!>          vectores de Householder utilizados para describir la matriz unitaria
!>          en la descomposición, como se describe en el propósito.
!>          *NOTA* Si ITYPE=2 o 3, V se modifica y se restaura. La
!>          subdiagonal (si UPLO='L') o la superdiagonal (si UPLO='U')
!>          se establece en uno, y más tarde se restablece a su valor original, durante
!>          el curso del cálculo.
!>          Si ITYPE=1, entonces no se referencia ni se modifica.
!>

TAU

!>          TAU es array COMPLEX*16, dimension (N)
!>          Si ITYPE >= 2, entonces TAU(j) es el factor escalar de
!>          v(j) v(j)**H en la transformación de Householder H(j) del
!>          producto  U = H(1)...H(n-2)
!>          Si ITYPE < 2, entonces TAU no se referencia.
!>

WORK

!>          WORK es array COMPLEX*16, dimension (N**2)
!>          Espacio de trabajo.
!>

RWORK

!>          RWORK es array DOUBLE PRECISION, dimension (N)
!>          Espacio de trabajo.
!>

RESULT

!>          RESULT es array DOUBLE PRECISION, dimension (2)
!>          Los valores calculados por las dos pruebas descritas anteriormente. Los
!>          valores están actualmente limitados a 1/ulp, para evitar desbordamientos.
!>          RESULT(1) siempre se modifica. RESULT(2) se modifica solo
!>          si ITYPE=1.
!>
