subroutine zhfrk (character transr, character uplo, character trans, integer n, integer k, double precision alpha, complex*16, dimension( lda, * ) a, integer lda, double precision beta, complex*16, dimension( * ) c)

ZHFRK realiza una operación hermitiana de rango-k para matrices en formato RFP.

Propósito:

!>
!> Rutina similar a BLAS de Nivel 3 para C en formato RFP.
!>
!> ZHFRK realiza una de las operaciones hermitianas de rango-k
!>
!>    C := alpha*A*A**H + beta*C,
!>
!> o
!>
!>    C := alpha*A**H*A + beta*C,
!>
!> donde alpha y beta son escalares reales, C es una matriz hermitiana de n x n
!> y A es una matriz de n x k en el primer caso y una matriz de k x n
!> en el segundo caso.
!>

Parámetros

TRANSR 
!>          TRANSR es CHARACTER*1
!>          = 'N':  Se almacena la Forma Normal de RFP A;
!>          = 'C':  Se almacena la Forma Conjugada Transpuesta de RFP A.
!>

UPLO

!>          UPLO es CHARACTER*1
!>           En la entrada, UPLO especifica si la parte triangular superior o
!>           inferior del array C debe ser referenciada de la siguiente manera:
!>
!>              UPLO = 'U' o 'u'   Solo se referencia la parte triangular superior de C.
!>
!>              UPLO = 'L' o 'l'   Solo se referencia la parte triangular inferior de C.
!>
!>           Sin cambios en la salida.
!>

TRANS

!>          TRANS es CHARACTER*1
!>           En la entrada, TRANS especifica la operación a realizar de la
!>           siguiente manera:
!>
!>              TRANS = 'N' o 'n'   C := alpha*A*A**H + beta*C.
!>
!>              TRANS = 'C' o 'c'   C := alpha*A**H*A + beta*C.
!>
!>           Sin cambios en la salida.
!>

N

!>          N es INTEGER
!>           En la entrada, N especifica el orden de la matriz C. N debe ser
!>           al menos cero.
!>           Sin cambios en la salida.
!>

K

!>          K es INTEGER
!>           En la entrada, con TRANS = 'N' o 'n', K especifica el número
!>           de columnas de la matriz A, y en la entrada, con
!>           TRANS = 'C' o 'c', K especifica el número de filas de la
!>           matriz A. K debe ser al menos cero.
!>           Sin cambios en la salida.
!>

ALPHA

!>          ALPHA es DOUBLE PRECISION
!>           En la entrada, ALPHA especifica el escalar alpha.
!>           Sin cambios en la salida.
!>

A

!>          A es un array COMPLEX*16, dimension (LDA, ka)
!>           donde ka
!>           es K cuando TRANS = 'N' o 'n', y es N en caso contrario. Antes
!>           de la entrada con TRANS = 'N' o 'n', la parte N x K principal
!>           del array A debe contener la matriz A, en caso contrario, la parte
!>           principal K x N del array A debe contener la matriz A.
!>           Sin cambios en la salida.
!>

LDA

!>          LDA es INTEGER
!>           En la entrada, LDA especifica la primera dimensión de A tal como está
!>           declarada en el programa (sub)llamador. Cuando TRANS = 'N' o 'n',
!>           entonces LDA debe ser al menos max( 1, n ), en caso contrario LDA debe
!>           ser al menos max( 1, k ).
!>           Sin cambios en la salida.
!>

BETA

!>          BETA es DOUBLE PRECISION
!>           En la entrada, BETA especifica el escalar beta.
!>           Sin cambios en la salida.
!>

C

!>          C es un array COMPLEX*16, dimension (N*(N+1)/2)
!>           En la entrada, la matriz A en formato RFP. El formato RFP se
!>           describe mediante TRANSR, UPLO y N. Tenga en cuenta que las partes
!>           imaginarias de los elementos diagonales no necesitan ser establecidas,
!>           se asumen cero, y en la salida se establecen a cero.
!>
