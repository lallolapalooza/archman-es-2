subrutina zheevx (character jobz, character range, character uplo, integer n, complex*16, dimension( lda, * ) a, integer lda, double precision vl, double precision vu, integer il, integer iu, double precision abstol, integer m, double precision, dimension( * ) w, complex*16, dimension( ldz, * ) z, integer ldz, complex*16, dimension( * ) work, integer lwork, double precision, dimension( * ) rwork, integer, dimension( * ) iwork, integer, dimension( * ) ifail, integer info)

ZHEEVX calcula los valores propios y, opcionalmente, los vectores propios izquierdos y/o derechos para matrices HE

Propósito:

!>
!> ZHEEVX calcula los valores propios seleccionados y, opcionalmente, los vectores propios
!> de una matriz hermítica compleja A. Los valores propios y vectores propios pueden
!> ser seleccionados especificando un rango de valores o un rango de
!> índices para los valores propios deseados.
!>

Parámetros

JOBZ 
!>          JOBZ es CHARACTER*1
!>          = 'N':  Calcula solo los valores propios;
!>          = 'V':  Calcula los valores propios y los vectores propios.
!>

RANGE

!>          RANGE es CHARACTER*1
!>          = 'A': se encontrarán todos los valores propios.
!>          = 'V': se encontrarán todos los valores propios en el intervalo semiabierto (VL,VU]
!>                 que se está buscando.
!>          = 'I': se encontrarán los valores propios del IL-ésimo al IU-ésimo.
!>

UPLO

!>          UPLO es CHARACTER*1
!>          = 'U':  el triángulo superior de A está almacenado;
!>          = 'L':  el triángulo inferior de A está almacenado.
!>

N

!>          N es INTEGER
!>          El orden de la matriz A.  N >= 0.
!>

A

!>          A es un array COMPLEX*16, dimension (LDA, N)
!>          En la entrada, la matriz hermítica A. Si UPLO = 'U', la
!>          parte triangular superior de N por N de A contiene la
!>          parte triangular superior de la matriz A. Si UPLO = 'L',
!>          la parte triangular inferior de N por N de A contiene
!>          la parte triangular inferior de la matriz A.
!>          En la salida, el triángulo inferior (si UPLO='L') o el triángulo
!>          superior (si UPLO='U') de A, incluyendo la diagonal, se
!>          destruye.
!>

LDA

!>          LDA es INTEGER
!>          La dimensión principal del array A.  LDA >= max(1,N).
!>

VL

!>          VL es DOUBLE PRECISION
!>          Si RANGE='V', el límite inferior del intervalo a
!>          buscar para los valores propios. VL < VU.
!>          No referenciado si RANGE = 'A' o 'I'.
!>

VU

!>          VU es DOUBLE PRECISION
!>          Si RANGE='V', el límite superior del intervalo a
!>          buscar para los valores propios. VL < VU.
!>          No referenciado si RANGE = 'A' o 'I'.
!>

IL

!>          IL es INTEGER
!>          Si RANGE='I', el índice del
!>          valor propio más pequeño a devolver.
!>          1 <= IL <= IU <= N, si N > 0; IL = 1 e IU = 0 si N = 0.
!>          No referenciado si RANGE = 'A' o 'V'.
!>

IU

!>          IU es INTEGER
!>          Si RANGE='I', el índice del
!>          valor propio más grande a devolver.
!>          1 <= IL <= IU <= N, si N > 0; IL = 1 e IU = 0 si N = 0.
!>          No referenciado si RANGE = 'A' o 'V'.
!>

ABSTOL

!>          ABSTOL es DOUBLE PRECISION
!>          La tolerancia de error absoluto para los valores propios.
!>          Se acepta un valor propio aproximado como convergido
!>          cuando se determina que yace en un intervalo [a,b]
!>          de ancho menor o igual a
!>
!>                  ABSTOL + EPS *   max( |a|,|b| ) ,
!>
!>          donde EPS es la precisión de la máquina. Si ABSTOL es menor que
!>          o igual a cero, entonces EPS*|T| se usará en su lugar,
!>          donde |T| es la norma 1 de la matriz tridiagonal obtenida
!>          al reducir A a forma tridiagonal.
!>
!>          Los valores propios se calcularán con mayor precisión cuando ABSTOL
!>          se establezca en el doble del umbral de subdesbordamiento 2*DLAMCH('S'), no cero.
!>          Si esta rutina retorna con INFO>0, indicando que algunos
!>          vectores propios no convergieron, intente establecer ABSTOL en
!>          2*DLAMCH('S').
!>
!>          Ver  por Demmel y
!>          Kahan, Nota de trabajo de LAPACK #3.
!>

M

!>          M es INTEGER
!>          El número total de valores propios encontrados.  0 <= M <= N.
!>          Si RANGE = 'A', M = N, y si RANGE = 'I', M = IU-IL+1.
!>

W

!>          W es un array DOUBLE PRECISION, dimension (N)
!>          En salida normal, los primeros M elementos contienen los valores propios
!>          seleccionados en orden ascendente.
!>

Z

!>          Z es un array COMPLEX*16, dimension (LDZ, max(1,M))
!>          Si JOBZ = 'V', entonces si INFO = 0, las primeras M columnas de Z
!>          contienen los vectores propios ortonormales de la matriz A
!>          correspondientes a los valores propios seleccionados, con la i-ésima
!>          columna de Z conteniendo el vector propio asociado a W(i).
!>          Si un vector propio falla en converger, entonces esa columna de Z
!>          contiene la última aproximación al vector propio, y el
!>          índice del vector propio se retorna en IFAIL.
!>          Si JOBZ = 'N', entonces Z no es referenciado.
!>          Nota: el usuario debe asegurarse de que se proporcionan al menos max(1,M) columnas
!>          en el array Z; si RANGE = 'V', el valor exacto de M
!>          no se conoce de antemano y se debe usar un límite superior.
!>

LDZ

!>          LDZ es INTEGER
!>          La dimensión principal del array Z.  LDZ >= 1, y si
!>          JOBZ = 'V', LDZ >= max(1,N).
!>

WORK

!>          WORK es un array COMPLEX*16, dimension (MAX(1,LWORK))
!>          En salida, si INFO = 0, WORK(1) retorna el LWORK óptimo.
!>

LWORK

!>          LWORK es INTEGER
!>          La longitud del array WORK.  LWORK >= 1, cuando N <= 1;
!>          de lo contrario 2*N.
!>          Para una eficiencia óptima, LWORK >= (NB+1)*N,
!>          donde NB es el máximo del tamaño del bloque para ZHETRD y para
!>          ZUNMTR tal como es retornado por ILAENV.
!>
!>          Si LWORK = -1, entonces se asume una consulta de espacio de trabajo; la rutina
!>          solo calcula el tamaño óptimo del array WORK, retorna
!>          este valor como la primera entrada del array WORK, y ningún mensaje de error
!>          relacionado con LWORK es emitido por XERBLA.
!>

RWORK

!>          RWORK es un array DOUBLE PRECISION, dimension (7*N)
!>

IWORK

!>          IWORK es un array INTEGER, dimension (5*N)
!>

IFAIL

!>          IFAIL es un array INTEGER, dimension (N)
!>          Si JOBZ = 'V', entonces si INFO = 0, los primeros M elementos de
!>          IFAIL son cero. Si INFO > 0, entonces IFAIL contiene los
!>          índices de los vectores propios que fallaron en converger.
!>          Si JOBZ = 'N', entonces IFAIL no es referenciado.
!>

INFO

!>          INFO es INTEGER
!>          = 0:  salida exitosa
!>          < 0:  si INFO = -i, el i-ésimo argumento tenía un

NAME

zheevx - This subroutine computes the eigenvalues and right eigenvectors of a complex Hermitian (or real symmetric) matrix.

Function/Subroutine Documentation

This subroutine computes the eigenvalues and right eigenvectors of a complex Hermitian (or real symmetric) matrix.

  --     DOUBLE PRECISION   ABSTOL, VL, VU                 --
  --     INTEGER            IL, INFO, IU, LDA, LDWORK, M, N--
  --     ..                                                --
  --     .. Array Arguments ..                             --
  --     INTEGER            IWORK                          --
  --     DOUBLE PRECISION   RWORK                          --
  --     COMPLEX*16         A(LDA,*), W(N), WORK(LDWORK,*),--
  --                        Z(LDZ,*)                       --
  --     ..                                                --
  --                                                          --
  ==================================================================
  --                                                              --
  --  Purpose                                                     --
  --  =====                                                       --
  --                                                              --
  --  ZHEEVX computes the eigenvalues and right eigenvectors of   --
  --  a complex Hermitian (or real symmetric) matrix A.           --
  --                                                              --
  --  The task of finding eigenvectors is made possible by the    --
  --  inclusion of the optional parameter ABSTOL.                 --
  --                                                              --
  --  ZHEEVX uses the divide-and-conquer method.                  --
  --                                                              --
  --  Arguments                                                   --
  --  =========                                                   --
  --                                                              --
  --  LINE    (input) CHARACTER*1                                 --
  --          Specifies the storage format of the eigenvectors.   --
  --          = 'N': Z is stored column-wise                      --
  --          = 'T': Z is stored transpose                        --
  --                                                              --
  --  JOBZ    (input) CHARACTER*1                                 --
  --          Specifies whether to compute the eigenvectors of    --
  --          A.                                                  --
  --          = 'N': Eigenvalues only; eigenvectors are not       --
  --                 computed.                                    --
  --          = 'V': Eigenvalues and eigenvectors are computed.   --
  --                                                              --
  --  RANGE   (input) CHARACTER*1                                 --
  --          Specifies the range of eigenvalues to be computed.  --
  --          = 'A': All eigenvalues will be computed.           --
  --          = 'V': All eigenvalues between VL and VU will be   --
  --                 computed.                                    --
  --          = 'I': The IL-th to IU-th eigenvalues will be       --
  --                 computed.                                    --
  --                                                              --
  --  UPLO    (input) CHARACTER*1                                 --
  --          Specifies whether the upper or lower triangular     --
  --          part of A is to be used.                          --
  --          = 'U': Upper triangle of A is to be used.         --
  --          = 'L': Lower triangle of A is to be used.         --
  --                                                              --
  --  N       (input) INTEGER                                     --
  --          The order of the matrix A.  N >= 0.                 --
  --                                                              --
  --  A       (input/output) COMPLEX*16 array, dimension (LDA,N)  --
  --          On entry, the upper or lower triangular part of the --
  --          Hermitian matrix A.                                 --
  --          On exit, if JOBZ = 'V', A is overwritten by the     --
  --          unit triangular factor U or L from the decomposition --
  --          A = U*T*U**H or A = L*T*L**H.                         --
  --                                                              --
  --  LDA     (input) INTEGER                                     --
  --          The leading dimension of A.  LDA >= max(1,N).       --
  --                                                              --
  --  VL      (input) DOUBLE PRECISION                            --
  --          If RANGE='V', the lower bound of the range for the  --
  --          eigenvalues.                                        --
  --                                                              --
  --  VU      (input) DOUBLE PRECISION                            --
  --          If RANGE='V', the upper bound of the range for the  --
  --          eigenvalues.                                        --
  --                                                              --
  --  IL      (input) INTEGER                                     --
  --          If RANGE='I', the index of the smallest eigenvalue  --
  --          to be computed.                                     --
  --                                                              --
  --  IU      (input) INTEGER                                     --
  --          If RANGE='I', the index of the largest eigenvalue   --
  --          to be computed.                                     --
  --                                                              --
  --  ABSTOL  (input) DOUBLE PRECISION                            --
  --           the absolute tolerance for the eigenvalues.         --
  --          If ABSTOL is not positive, the default value is used.--
  --          Use ABSTOL to ensure that the eigenvalues are       --
  --          distinct.                                           --
  --                                                              --
  --  M       (output) INTEGER                                    --
  --          The number of eigenvalues found in the specified    --
  --          range.                                              --
  --                                                              --
  --  W       (output) DOUBLE PRECISION array, dimension (N)      --
  --          The approximate eigenvalues, sorted in ascending    --
  --          order.                                              --
  --                                                              --
  --  Z       (output) COMPLEX*16 array, dimension (LDZ,*)        --
  --          If JOBZ = 'V', then the eigenvectors of A, sorted   --
  --          according to the corresponding eigenvalues in W.    --
  --          The vector Z*w(i) is the eigenvector for the        --
  --          eigenvalue w(i), with the sign normalized so that   --
  --          the element of largest absolute value is real and   --
  --          positive.                                           --
  --          If JOBZ = 'N', then Z is not referenced.            --
  --                                                              --
  --  LDZ     (input) INTEGER                                     --
  --          The leading dimension of the array Z.  LDA >=       --
  --          max(1,N).                                           --
  --                                                              --
  --  WORK    (workspace) COMPLEX*16 array, dimension (LDWORK,*)  --
  --                                                              --
  --  RWORK   (workspace) DOUBLE PRECISION array, dimension     --
  --          (N)                                                 --
  --                                                              --
  --  LDWORK  (input) INTEGER                                     --
  --          The leading dimension of the array WORK.            --
  --                                                              --
  --  IWORK   (workspace) INTEGER array, dimension (N)            --
  --                                                              --
  --  INFO    (output) INTEGER                                    --
  --          = 0:  successful exit.                              --
  --          < 0:  if INFO = -i, the i-th argument had an illegal --
  --                value.                                        --
  --          > 0:  if INFO = i, then i eigenvectors failed to    --
  --                converge. Their indices are stored in array   --
  --                IFAIL.                                        --
