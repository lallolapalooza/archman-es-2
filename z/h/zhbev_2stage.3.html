Documentación de la Función/Subrutina

subrutina zhbev_2stage (character jobz, character uplo, integer n, integer kd, complex*16, dimension( ldab, * ) ab, integer ldab, double precision, dimension( * ) w, complex*16, dimension( ldz, * ) z, integer ldz, complex*16, dimension( * ) work, integer lwork, double precision, dimension( * ) rwork, integer info)

ZHBEV_2STAGE calcula todos los valores y, opcionalmente, los vectores propios de una matriz de banda Hermitiana compleja A usando la técnica de 2 etapas para la reducción a tridiagonal.

Propósito:

!>
!> ZHBEV_2STAGE calcula todos los valores y, opcionalmente, los vectores propios
!> de una matriz de banda Hermitiana compleja A usando la técnica de 2 etapas para
!> la reducción a tridiagonal.
!>

Parámetros

JOBZ 
!>          JOBZ es CHARACTER*1
!>          = 'N':  Calcular solo valores propios;
!>          = 'V':  Calcular valores y vectores propios.
!>                  No disponible en esta versión.
!>

UPLO

!>          UPLO es CHARACTER*1
!>          = 'U':  Se almacena el triángulo superior de A;
!>          = 'L':  Se almacena el triángulo inferior de A.
!>

N

!>          N es INTEGER
!>          El orden de la matriz A.  N >= 0.
!>

KD

!>          KD es INTEGER
!>          El número de superdiagonales de la matriz A si UPLO = 'U',
!>          o el número de subdiagonales si UPLO = 'L'.  KD >= 0.
!>

AB

!>          AB es un array de COMPLEX*16, de dimensión (LDAB, N)
!>          En la entrada, el triángulo superior o inferior de la matriz de banda
!>          Hermitiana A, almacenado en las primeras KD+1 filas del array. La
!>          columna j de A se almacena en la columna j del array AB
!>          de la siguiente manera:
!>          si UPLO = 'U', AB(kd+1+i-j,j) = A(i,j) para max(1,j-kd) <= i <= j;
!>          si UPLO = 'L', AB(1+i-j,j)    = A(i,j) para j <= i <= min(n,j+kd).
!>
!>          En la salida, AB se sobrescribe con valores generados durante la
!>          reducción a forma tridiagonal. Si UPLO = 'U', la primera
!>          superdiagonal y la diagonal de la matriz tridiagonal T
!>          se devuelven en las filas KD y KD+1 de AB, y si UPLO = 'L',
!>          la diagonal y la primera subdiagonal de T se devuelven en las
!>          dos primeras filas de AB.
!>

LDAB

!>          LDAB es INTEGER
!>          La dimensión principal del array AB.  LDAB >= KD + 1.
!>

W

!>          W es un array de DOUBLE PRECISION, de dimensión (N)
!>          Si INFO = 0, los valores propios en orden ascendente.
!>

Z

!>          Z es un array de COMPLEX*16, de dimensión (LDZ, N)
!>          Si JOBZ = 'V', entonces si INFO = 0, Z contiene los vectores propios
!>          ortonormales de la matriz A, con la columna i de Z
!>          conteniendo el vector propio asociado a W(i).
!>          Si JOBZ = 'N', entonces Z no se referencia.
!>

LDZ

!>          LDZ es INTEGER
!>          La dimensión principal del array Z.  LDZ >= 1, y si
!>          JOBZ = 'V', LDZ >= max(1,N).
!>

WORK

!>          WORK es un array de COMPLEX*16, de dimensión LWORK
!>          En la salida, si INFO = 0, WORK(1) devuelve el LWORK óptimo.
!>

LWORK

!>          LWORK es INTEGER
!>          La longitud del array WORK. LWORK >= 1, cuando N <= 1;
!>          en caso contrario
!>          Si JOBZ = 'N' y N > 1, se debe consultar LWORK.
!>                                   LWORK = MAX(1, dimensión) donde
!>                                   dimensión = (2KD+1)*N + KD*NTHREADS
!>                                   donde KD es el tamaño de la banda.
!>                                   NTHREADS es el número de hilos utilizados cuando
!>                                   la compilación openMP está habilitada, de lo contrario =1.
!>          Si JOBZ = 'V' y N > 1, se debe consultar LWORK. Aún no disponible.
!>
!>          Si LWORK = -1, entonces se asume una consulta de espacio de trabajo; la rutina
!>          solo calcula los tamaños óptimos de los arrays WORK, RWORK e
!>          IWORK, devuelve estos valores como las primeras entradas de
!>          los arrays WORK, RWORK e IWORK, y XERBLA no emite ningún mensaje de error
!>          relacionado con LWORK o LRWORK o LIWORK.
!>

RWORK

!>          RWORK es un array de DOUBLE PRECISION, de dimensión (max(1,3*N-2))
!>

INFO

!>          INFO es INTEGER
!>          = 0:  salida exitosa.
!>          < 0:  si INFO = -i, el i-ésimo argumento tuvo un valor ilegal.
!>          > 0:  si INFO = i, el algoritmo no convergió; i
!>                elementos fuera de la diagonal de una forma tridiagonal intermedia
!>                no convergieron a cero.
!>

NAME

zhbev_2stage - Computes the eigenvalues and eigenvectors of a complex general band Hermitian matrix.

SYNOPSIS

SUBROUTINE ZHBEV_2STAGE( JOBZ, UPLO, N, KD, AB, LDAB, WORK, LWORK, RWORK, INFO )

Function/Subroutine Documentation

ZHBEV_2STAGE is a subroutine in LAPACK (Linear Algebra PACKage) that computes the eigenvalues and eigenvectors of a complex general band Hermitian matrix. It uses a two-stage method to improve performance.

Parameters

  • JOBZ (CHARACTER*1): Specifies whether to compute eigenvalues only ('N') or eigenvalues and eigenvectors ('V').
  • UPLO (CHARACTER*1): Specifies whether the upper ('U') or lower ('L') triangle of the band matrix is stored.
  • N (INTEGER): The order of the matrix `AB`.
  • KD (INTEGER): The number of super-diagonals (or sub-diagonals) of the band matrix `AB`.
  • AB (COMPLEX*16 array, dimension (LDAB,*) ): The array containing the band matrix. The shape of the matrix is (N, N).
  • LDAB (INTEGER): Leading dimension of the array `AB`.
  • WORK (COMPLEX*16 array, dimension (LWORK) ): Workspace array.
  • LWORK (INTEGER): The dimension of the array `WORK`.
  • RWORK (DOUBLE PRECISION array, dimension (max(1, 2*N-1)) ): Real workspace array.
  • INFO (INTEGER): Output: 0 if successful, <0 if an error occurred.

Description

The routine computes the eigenvalues and, if requested, the eigenvectors of a complex Hermitian band matrix.

The two-stage approach first reduces the band matrix to a tridiagonal matrix using unitary transformations, and then computes the eigenvalues and eigenvectors of the tridiagonal matrix.

Return Value

The subroutine returns an integer value INFO. If INFO is 0, the computation was successful. If INFO is negative, it indicates an error in the input parameters.
