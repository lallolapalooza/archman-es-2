ZHESVXX calcula la solución al sistema de ecuaciones lineales A * X = B para matrices HE

DOCUMENTACIÓN DE FUNCIÓN/SUBRUTINA

subrutina zhesvxx (character fact, character uplo, integer n, integer nrhs, complex*16, dimension( lda, * ) a, integer lda, complex*16, dimension( ldaf, * ) af, integer ldaf, integer, dimension( * ) ipiv, character equed, double precision, dimension( * ) s, complex*16, dimension( ldb, * ) b, integer ldb, complex*16, dimension( ldx, * ) x, integer ldx, double precision rcond, double precision rpvgrw, double precision, dimension( * ) berr, integer n_err_bnds, double precision, dimension( nrhs, * ) err_bnds_norm, double precision, dimension( nrhs, * ) err_bnds_comp, integer nparams, double precision, dimension( * ) params, complex*16, dimension( * ) work, double precision, dimension( * ) rwork, integer info)

ZHESVXX calcula la solución al sistema de ecuaciones lineales A * X = B para matrices Hermitianas

Propósito:

!>
!>    ZHESVXX utiliza la factorización de pivoteo diagonal para calcular
!>    la solución de un sistema de ecuaciones lineales complex*16 A * X = B,
!>    donde A es una matriz Hermitiana N-por-N y X y B son matrices
!>    N-por-NRHS.
!>
!>    Si se solicita, se devuelven límites de error normados y
!>    componentes máximos. ZHESVXX devolverá una solución con un error
!>    garantizado diminuto (O(eps) donde eps es la precisión de la máquina
!>    de trabajo) a menos que la matriz sea muy mal condicionada, en cuyo
!>    caso se devuelve una advertencia. También se calculan y devuelven
!>    los números de condición relevantes.
!>
!>    ZHESVXX acepta factorizaciones y factores de 
¡
equivalencia proporcionados por el usuario; véanse las definiciones de
!>    las opciones FACT y EQUED. Resolver con refinamiento y usar una
!>    factorización de una llamada anterior a ZHESVXX también producirá
!>    una solución con errores O(eps) o advertencias, pero no podemos
!>    hacer esa afirmación para factorizaciones y factores de
¡
equivalencia
!>    proporcionados por el usuario en general si difieren de lo que el
!>    propio ZHESVXX produciría.
!>

Descripción:

!>
!>    Se realizan los siguientes pasos:
!>
!>    1. Si FACT = 'E', se calculan factores de escala de doble precisión para
!>    equivalenciar el sistema:
!>
!>      diag(S)*A*diag(S)     *inv(diag(S))*X = diag(S)*B
!>
!>    Si el sistema se va a equivalenciar o no depende del escalado de la
!>    matriz A, pero si se utiliza la equivalencia, A se sobrescribe con
!>    diag(S)*A*diag(S) y B con diag(S)*B.
!>
!>    2. Si FACT = 'N' o 'E', se utiliza la descomposición LU para factorizar
!>    la matriz A (después de la equivalencia si FACT = 'E') como
!>
!>       A = U * D * U**T,  si UPLO = 'U', o
!>       A = L * D * L**T,  si UPLO = 'L',
!>
!>    donde U (o L) es un producto de matrices de permutación y triangulares
!>    superiores (inferiores) unitarias, y D es Hermitiana y diagonal por
!>    bloques con bloques diagonales de 1x1 y 2x2.
!>
!>    3. Si algún D(i,i)=0, de modo que D es exactamente singular, la rutina
!>    devuelve INFO = i. De lo contrario, la forma factorizada de A se usa
!>    para estimar el número de condición de la matriz A (ver argumento
!>    RCOND). Si la inversa del número de condición es menor que la
!>    precisión de la máquina, la rutina aún continúa resolviendo para X
!>    y calculando límites de error como se describe a continuación.
!>
!>    4. El sistema de ecuaciones se resuelve para X usando la forma
!>    factorizada de A.
!>
!>    5. Por defecto (a menos que PARAMS(LA_LINRX_ITREF_I) se establezca en
!>    cero), la rutina usará refinamiento iterativo para intentar obtener
!>    un error pequeño y límites de error. El refinamiento calcula el
!>    residuo con al menos el doble de la precisión de trabajo.
!>
!>    6. Si se utilizó la equivalencia, la matriz X se premultiplica por
!>    diag(R) para que resuelva el sistema original antes de la
!>    equivalencia.
!>

!>     Algunos parámetros opcionales se agrupan en el array PARAMS. Estos
!>     ajustes determinan cómo se realiza el refinamiento, pero a menudo
!>     los valores predeterminados son aceptables. Si los valores
!>     predeterminados son aceptables, los usuarios pueden pasar NPARAMS = 0,
!>     lo que evita que el código fuente acceda al argumento PARAMS.
!>

Parámetros

FACT 
!>          FACT es CHARACTER*1
!>     Especifica si la forma factorizada de la matriz A se proporciona
!>     en la entrada, y si no, si la matriz A debe ser
!>     equivalenciada antes de ser factorizada.
!>       = 'F':  En la entrada, AF y IPIV contienen la forma factorizada
!>               de A. Si EQUED no es 'N', la matriz A ha sido
!>               equivalenciada con factores de escala dados por S.
!>               A, AF e IPIV no se modifican.
!>       = 'N':  La matriz A se copiará en AF y se factorizará.
!>       = 'E':  La matriz A se equivalenciará si es necesario, luego
!>               se copiará en AF y se factorizará.
!>

UPLO

!>          UPLO es CHARACTER*1
!>       = 'U':  Se almacena el triángulo superior de A;
!>       = 'L':  Se almacena el triángulo inferior de A.
!>

N

!>          N es INTEGER
!>     El número de ecuaciones lineales, es decir, el orden de la
!>     matriz A.  N >= 0.
!>

NRHS

!>          NRHS es INTEGER
!>     El número de lados derechos, es decir, el número de columnas
!>     de las matrices B y X.  NRHS >= 0.
!>

A

!>          A es un array COMPLEX*16, dimensión (LDA,N)
!>     La matriz Hermitiana A. Si UPLO = 'U', la parte superior
!>     triangular N-por-N de A contiene la parte triangular superior
!>     de la matriz A, y la parte triangular estrictamente inferior
!>     de A no se referencia. Si UPLO = 'L', la parte inferior
!>     triangular N-por-N de A contiene la parte triangular inferior
!>     de la matriz A, y la parte triangular estrictamente superior
!>     de A no se referencia.
!>
!>     En la salida, si FACT = 'E' y EQUED = 'Y', A se sobrescribe con
!>     diag(S)*A*diag(S).
!>

LDA

!>          LDA es INTEGER
!>     La dimensión principal del array A.  LDA >= max(1,N).
!>

AF

!>          AF es un array COMPLEX*16, dimensión (LDAF,N)
!>     Si FACT = 'F', entonces AF es un argumento de entrada y en la
!>     entrada contiene la matriz diagonal por bloques D y los
!>     multiplicadores utilizados para obtener el factor U o L de la
!>     factorización A = U*D*U**H o A = L*D*L**H tal como la calcula
!>     ZHETRF.
!>
!>     Si FACT = 'N', entonces AF es un argumento de salida y en la
!>     salida devuelve la matriz diagonal por bloques D y los
!>     multiplicadores utilizados para obtener el factor U o L de la
!>     factorización A = U*D*U**H o A = L*D*L**H.
!>

LDAF

!>          LDAF es INTEGER
!>     La dimensión principal del array AF.  LDAF >= max(1,N).
!>

IPIV

!>          IPIV es un array INTEGER, dimensión (N)
!>     Si FACT = 'F', entonces IPIV es un argumento de entrada y en la
!>     entrada contiene detalles de los intercambios y la estructura de
¡
bloques
!>     de D, tal como fueron devueltos por ZHETRF.
!>
!>     Si FACT = 'N', entonces IPIV es un argumento de salida y en la
!>     salida contiene detalles de los intercambios y la estructura de
¡
bloques
!>     de D, tal como fueron calculados por ZHETRF.
!>

EQUED

!>          EQUED es CHARACTER*1
!>     Especifica los datos de la diagonal de A que se han utilizado en
!>     la equivalencia.
!>       = 'N': Ninguna fila/columna ha sido escalada.
!>       = 'R': Las filas han sido escaladas de forma diferente de las columnas.
!>       = 'C': Las columnas han sido escaladas de forma diferente de las filas.
!>       = 'B': Tanto las filas como las columnas han sido escaladas.
!>     Si FACT = 'F', entonces EQUED es un argumento de entrada.
!>     Si FACT = 'N' o 'E', entonces EQUED es un argumento de salida.
!>

S

!>          S es un array DOUBLE PRECISION, dimensión (N)
!>     Los factores de escala de la diagonal para la equivalencia.
!>     Si EQUED = 'R' o 'B', A es escalado por S(i) en la fila i.
!>     Si EQUED = 'C' o 'B', A es escalado por S(i) en la columna i.
!>     Si FACT = 'F', S es un argumento de entrada.
!>     Si FACT = 'N' o 'E', S es un argumento de salida.
!>

B

!>          B es un array COMPLEX*16, dimensión (LDB,NRHS)
!>     El array N-por-NRHS que contiene los lados derechos de las
!>     ecuaciones lineales.
!>     En la salida, si FACT = 'E' y EQUED = 'Y', B se sobrescribe con
!>     diag(S)*B.
!>

LDB

!>          LDB es INTEGER
!>     La dimensión principal del array B.  LDB >= max(1,N).
!>

X

!>          X es un array COMPLEX*16, dimensión (LDX,NRHS)
!>     La matriz N-por-NRHS del sistema. En la salida, X contiene la
!>     solución del sistema. Si EQUED = 'Y', X se premultiplica por
!>     diag(S).
!>

LDX

!>          LDX es INTEGER
!>     La dimensión principal del array X.  LDX >= max(1,N).
!>

RCOND

!>          RCOND es DOUBLE PRECISION
!>     El estimado de la inversa del número de condición de la matriz.
!>     Las condiciones de la matriz se computan al final de la
!>     factorización. Un valor grande de RCOND indica que la
!>     matriz está bien condicionada, mientras que un valor pequeño
!>     indica que la matriz está mal condicionada.
!>

RPVGRW

!>          RPVGRW es DOUBLE PRECISION
!>     El ratio de crecimiento esperado para la estimación del error,
!>     es decir, el ratio de la norma más grande de A inv(A) por B
!>     a la norma de la solución X. Si RPVGRW es mucho mayor que 1
!>     al final de la computación, puede indicar que el residuo
!>     calculado está mal estimado.
!>

BERR

!>          BERR es un array DOUBLE PRECISION, dimensión (NRHS)
!>     El error estimado en la matriz B para cada lado derecho.
!>     BERR(j) es una estimación del error en B para la j-ésima
!>     solución.
!>

N_ERR_BNDS

!>          N_ERR_BNDS es INTEGER
!>     Número de límites de error calculados en los arrays
!>     ERR_BNDS_NORM y ERR_BNDS_COMP.
!>

ERR_BNDS_NORM

!>          ERR_BNDS_NORM es un array DOUBLE PRECISION, dimensión
!>     (NRHS, *). Los valores son los límites de error normados.
!>

ERR_BNDS_COMP

!>          ERR_BNDS_COMP es un array DOUBLE PRECISION, dimensión
!>     (NRHS, *). Los valores son los límites de error de componente
!>     máximo.
!>

NPARAMS

!>          NPARAMS es INTEGER
!>     El número de parámetros de entrada opcionales. Si NPARAMS = 0,
!>     se utilizan los valores predeterminados de los parámetros
!>     opcionales.
!>

PARAMS

!>          PARAMS es un array DOUBLE PRECISION, dimensión (NPARAMS)
!>     Los parámetros opcionales. Ver la sección de la descripción para
!>     más detalles.
!>

WORK

!>          WORK es un array COMPLEX*16, dimensión (MAX(1,LWORK))
!>     Si FACT = 'F', WORK es un argumento de entrada y no se utiliza.
!>     Si FACT = 'N' o 'E', WORK es un argumento de salida y contiene
!>     los vectores de trabajo.
!>
!>     LWORK: El tamaño del array WORK. Si LWORK = -1, se calcula el
!>     tamaño óptimo de WORK.
!>

RWORK

!>          RWORK es un array DOUBLE PRECISION, dimensión (MAX(1,LRWORK))
!>     Si FACT = 'F', RWORK es un argumento de entrada y no se utiliza.
!>     Si FACT = 'N' o 'E', RWORK es un argumento de salida y contiene
!>     los vectores de trabajo de doble precisión.
!>
!>     LRWORK: El tamaño del array RWORK. Si LRWORK = -1, se calcula el
!>     tamaño óptimo de RWORK.
!>

INFO

!>          INFO es INTEGER
!>     = 0: Éxito en la ejecución.
!>     < 0: Si INFO = -i, el i-ésimo argumento indica un error.
!>          Por ejemplo, si INFO = -13, entonces el argumento S
!>          es inválido.
!>     > 0: Si INFO = i, i > 0, indica que la matriz D es singular
!>          y la solución no se puede calcular. El valor i es la
!>          orden de la entrada D(i,i) que es cero.
!>

EQUED

!>          EQUED es CHARACTER*1
!>     Especifica la forma de   equilibrado que se realizó.
!>       = 'N':  Sin equilibrado (siempre verdadero si FACT = 'N').
!>       = 'Y':  Equilibrado de filas y columnas, es decir, A ha sido
!>               reemplazado por diag(S) * A * diag(S).
!>     EQUED es un argumento de entrada si FACT = 'F'; de lo contrario, es un
!>     argumento de salida.
!>

S


!>          S es un array de DOBLE PRECISIÓN, de dimensión (N)
!>     Los factores de escala para A. Si EQUED = 'Y', A se multiplica por la izquierda
!>     y por la derecha por diag(S). S es un argumento de entrada si FACT =
!>     'F'; de lo contrario, S es un argumento de salida. Si FACT = 'F' y EQUED
!>     = 'Y', cada elemento de S debe ser positivo. Si S es de salida, cada
!>     elemento de S es una potencia de la base. Si S es de entrada, cada elemento
!>     de S debe ser una potencia de la base para asegurar una solución y estimaciones de error fiables.
!>     El escalado por potencias de la base no causa errores de redondeo, a menos que el resultado desborde inferior o superiormente.
!>     Los errores de redondeo durante el escalado conducen a un refinamiento con una matriz que
!>     no es equivalente a la matriz de entrada, produciendo estimaciones de error
!>     que pueden no ser fiables.
!>

B


!>          B es un array de COMPLEJO*16, de dimensión (LDB,NRHS)
!>     En la entrada, la matriz B del lado derecho de N por NRHS.
!>     En la salida,
!>     si EQUED = 'N', B no se modifica;
!>     si EQUED = 'Y', B se sobrescribe con diag(S)*B;
!>

LDB


!>          LDB es INTEGER
!>     La dimensión principal del array B. LDB >= max(1,N).
!>

X


!>          X es un array de COMPLEJO*16, de dimensión (LDX,NRHS)
!>     Si INFO = 0, la matriz solución X de N por NRHS al sistema original
!>     de ecuaciones. Tenga en cuenta que A y B se modifican en la salida si
!>     EQUED .ne. 'N', y la solución al sistema equilibrado es
!>     inv(diag(S))*X.
!>

LDX


!>          LDX es INTEGER
!>     La dimensión principal del array X. LDX >= max(1,N).
!>

RCOND


!>          RCOND es DOBLE PRECISIÓN
!>     Número de condición escalado recíproco. Esta es una estimación del
!>     número de condición de Skeel recíproco de la matriz A después del
!>     equilibrado (si se realizó). Si este es menor que la precisión de la máquina
!>     (en particular, si es cero), la matriz es singular
!>     a precisión de trabajo. Tenga en cuenta que el error aún puede ser pequeño incluso
!>     si este número es muy pequeño y la matriz parece mal condicionada.
!>

RPVGRW


!>          RPVGRW es DOBLE PRECISIÓN
!>     Crecimiento recíproco de pivote. En la salida, esto contiene el factor
!>     de crecimiento de pivote recíproco norm(A)/norm(U). Se utiliza la norma .
!>     Si esto es mucho menor que 1, entonces la estabilidad de
!>     la factorización LU de la matriz A (equilibrada) podría ser pobre.
!>     Esto también significa que la solución X, los números de condición estimados
!>     y las cotas de error podrían no ser fiables. Si la factorización falla con
!>     0     para las columnas principales INFO de A.
!>

BERR


!>          BERR es un array de DOBLE PRECISIÓN, de dimensión (NRHS)
!>     Error relativo de retroceso componente a componente. Este es el
!>     error relativo de retroceso componente a componente de cada vector solución X(j)
!>     (es decir, el cambio relativo más pequeño en cualquier elemento de A o B que
!>     haga que X(j) sea una solución exacta).
!>

N_ERR_BNDS


!>          N_ERR_BNDS es INTEGER
!>     Número de cotas de error a devolver por cada lado derecho
!>     y cada tipo (norma global o componente a componente). Consulte ERR_BNDS_NORM y
!>     ERR_BNDS_COMP a continuación.
!>

ERR_BNDS_NORM


!>          ERR_BNDS_NORM es un array de DOBLE PRECISIÓN, de dimensión (NRHS, N_ERR_BNDS)
!>     Para cada lado derecho, esta matriz contiene información sobre
!>     varias cotas de error y números de condición correspondientes al
!>     error relativo global, que se define de la siguiente manera:
!>
!>     Error relativo global en el i-ésimo vector solución:
!>             max_j (abs(XTRUE(j,i) - X(j,i)))
!>            ------------------------------
!>                  max_j abs(X(j,i))
!>
!>     La matriz se indexa por el tipo de información de error, como se describe
!>     a continuación. Actualmente hay hasta tres piezas de información
!>     devueltas.
!>
!>     El primer índice en ERR_BNDS_NORM(i,:) corresponde al i-ésimo
!>     lado derecho.
!>
!>     El segundo índice en ERR_BNDS_NORM(:,err) contiene los siguientes
!>     tres campos:
!>     err = 1  booleano. Confíe en la respuesta si el
!>              número de condición recíproco es menor que el umbral
!>              sqrt(n) * dlamch('Epsilon').
!>
!>     err = 2  cota de error: El error directo estimado,
!>              casi seguramente dentro de un factor de 10 del error real
!>              siempre que la siguiente entrada sea mayor que el umbral
!>              sqrt(n) * dlamch('Epsilon'). Esta cota de error solo debe
!>              confiarse si el booleano anterior es verdadero.
!>
!>     err = 3  Número de condición recíproco: Estimación global
!>              número de condición recíproco. Comparado con el umbral
!>              sqrt(n) * dlamch('Epsilon') para determinar si la estimación del error
!>              es . Estos números de condición recíprocos
!>              son 1 / (norm(Z^{-1},inf) * norm(Z,inf)) para alguna
!>              matriz Z apropiadamente escalada.
!>              Sea Z = S*A, donde S escala cada fila por una potencia de la
!>              base de modo que todas las sumas de filas absolutas de Z sean aproximadamente 1.
!>
!>     Consulte el Nota de trabajo de Lapack 165 para obtener más detalles y precauciones adicionales.
!>

ERR_BNDS_COMP


!>          ERR_BNDS_COMP es un array de DOBLE PRECISIÓN, de dimensión (NRHS, N_ERR_BNDS)
!>     Para cada lado derecho, esta matriz contiene información sobre
!>     varias cotas de error y números de condición correspondientes al
!>     error relativo componente a componente, que se define de la siguiente manera:
!>
!>     Error relativo componente a componente en el i-ésimo vector solución:
!>                    abs(XTRUE(j,i) - X(j,i))
!>             max_j ----------------------
!>                         abs(X(j,i))
!>
!>     La matriz se indexa por el lado derecho i (del cual depende el error relativo componente a componente), y el tipo de información de error, como se describe a continuación. Actualmente hay hasta tres piezas de información devueltas por cada lado derecho. Si
!>     la precisión componente a componente no se solicita (PARAMS(3) = 0.0), entonces
!>     ERR_BNDS_COMP no se accede. Si N_ERR_BNDS < 3, entonces se devuelven como máximo
!>     las primeras entradas (:,N_ERR_BNDS).
!>
!>     El primer índice en ERR_BNDS_COMP(i,:) corresponde al i-ésimo
!>     lado derecho.
!>
!>     El segundo índice en ERR_BNDS_COMP(:,err) contiene los siguientes
!>     tres campos:
!>     err = 1  booleano. Confíe en la respuesta si el
!>              número de condición recíproco es menor que el umbral
!>              sqrt(n) * dlamch('Epsilon').
!>
!>     err = 2  cota de error: El error directo estimado,
!>              casi seguramente dentro de un factor de 10 del error real
!>              siempre que la siguiente entrada sea mayor que el umbral
!>              sqrt(n) * dlamch('Epsilon'). Esta cota de error solo debe
!>              confiarse si el booleano anterior es verdadero.
!>
!>     err = 3  Número de condición recíproco: Estimación componente a componente
!>              número de condición recíproco. Comparado con el umbral
!>              sqrt(n) * dlamch('Epsilon') para determinar si la estimación del error
!>              es . Estos números de condición recíprocos
!>              son 1 / (norm(Z^{-1},inf) * norm(Z,inf)) para alguna
!>              matriz Z apropiadamente escalada.
!>              Sea Z = S*(A*diag(x)), donde x es la solución para
!>              el lado derecho actual y S escala cada fila de
!>              A*diag(x) por una potencia de la base para que todas las sumas de filas
!>              absolutas de Z sean aproximadamente 1.
!>
!>     Consulte el Nota de trabajo de Lapack 165 para obtener más detalles y precauciones adicionales.
!>

NPARAMS


!>          NPARAMS es INTEGER

NAME


zhesvxx


zhesvxx - the routines solve a complex conjugate system of linear equations Ax=B, A x=B for multiple right-hand side vectors x and compute error bounds on the solution of these systems.






SYNOPSIS


#include <lapack.h>
...


CALL ZHE SVXX (JOBZ, UPLO, N, NRHS, A, LDA, B, LDB, X, LDX, RCOND, SRANK, BERR, RES, WORK, LWORK, INFO)


TYPE (Zgesvxx) ZHE SVXX ;






Function/Subroutine Documentation


ZHE SVXX implements the following algorithm:


      Call ZHEsvx( JOBZ, UPLO, N, NRHS, A, LDA, ipiv, B, LDB, X, LDX,
     $             RCOND, SRANK, BERR, RES, WORK, LWORK, INFO )
      Call ZLATBS( TRANS, DIAG, NORM, RHS, UPLO, NONZERO, B, LDB,
     $             X, LDX, XMAX, NB, EQNRM, WORK2, INFO2 )


This subroutine computes the solution to a complex conjugate
    system of linear equations Ax = B, where A is an n-by-n complex Hermitian
    matrix and x is an n-by-jobz matrix. Error bounds are computed for the
    solution of these systems.


A direct solver is used for the computation of the solution
    x, and it is not guaranteed to be available, and if it is not, the
    routine returns directly.


See also: zgesvxx(3)




Parameters




JOBZ




CHARACTER. = 'N': Solve Ax = B for a single system.


= 'X': Compute error bounds for the solution of Ax = B.


UPLO




CHARACTER. = 'U': Upper triangle of A is stored and will be used in
    computation.


= 'L': Lower triangle of A is stored and will be used in
    computation.


N




INTEGER. The order of the matrix A. N >= 0.


NRHS




INTEGER. The number of right hand sides, i.e., the number of columns
    of the matrices B and X. NRHS >= 0.


A




COMPLEX*16 array, dimension (LDA,N). On entry, the
    Hermitian matrix A.


LDA




INTEGER. The leading dimension of the array A. LDA >= max(1,N).


B




COMPLEX*16 array, dimension (LDB,NRHS). On entry, the right
    hand side matrix B.


LDB




INTEGER. The leading dimension of the array B. LDB >= max(1,N).


X




COMPLEX*16 array, dimension (LDX,NRHS). On exit, if INFO = 0,
    the solution matrix X to the system Ax = B.


LDX




INTEGER. The leading dimension of the array X. LDX >= max(1,N).


RCOND




DOUBLE PRECISION. On exit, an estimate of the reciprocal condition
    number of A. A value near zero indicates that A is near to being singular.


SRANK




INTEGER. The rank of the matrix A, possibly different from N.


BERR




DOUBLE PRECISION array, dimension (NRHS). On exit, the componentwise
    backward error of the solution computed by this routine. BERR(J) is
    max(abs(REG(J)))/max(abs(A)*X(:,J),abs(B(:,J))).


RES




DOUBLE PRECISION array, dimension (NRHS). On exit, the normwise
    backward error of the solution computed by this routine. RES(J) is
    norm(B(:,J) - A*X(:,J)) / (norm(A)*norm(X(:,J)))


WORK




COMPLEX*16 array, dimension (LWORK).


LWORK




INTEGER. The dimension of the array WORK. LWORK >= max(1, 2*N).


If LWORK = -1, then LWORK is an input parameter and the code
    returns without actually performing the operation. 


INFO




INTEGER


= 0: Successful exit. The solution is computed and the error
    bounds are computed.


< 0: If INFO = -i, the i-th argument had an illegal value.


> 0: If INFO = i, and 1 <= i <= N, then UPLO(i) was the only
    subdiagonal not being zero. If INFO = N + i, then the leading minor of
    order i of A was not positive definite, and the solution corresponding
    to the i-th right-hand side is not guaranteed. The error bounds might not
    be computed.


If RCOND is less than machine epsilon, RCOND = 0.0d0 is returned.
    Error bounds could not be computed. RCOND = 0


is returned.


= N+J: The solution corresponding to the Jth right-hand side is
    not guaranteed. The solutions corresponding to other right-
    hand sides K with K > J may not be guaranteed as well, but
    only the first such right-hand side is reported. If a small
    componentwise error is not requested (PARAMS(3) = 0.0) then
    the Jth right-hand side is the first with a normwise error
    bound that is not guaranteed (the smallest J such
    that ERR_BNDS_NORM(J,1) = 0.0). By default (PARAMS(3) = 1.0)
    the Jth right-hand side is the first with either a normwise or
    componentwise error bound that is not guaranteed (the smallest
    J such that either ERR_BNDS_NORM(J,1) = 0.0 or
    ERR_BNDS_COMP(J,1) = 0.0). See the definition of
    ERR_BNDS_NORM(:,1) and ERR_BNDS_COMP(:,1). To get information
    about all of the right-hand sides check ERR_BNDS_NORM or
    ERR_BNDS_COMP.
