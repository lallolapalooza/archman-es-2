Documentación de función/subrutina

subrutina zhetrf_aa_2stage (character uplo, integer n, complex*16, dimension( lda, * ) a, integer lda, complex*16, dimension( * ) tb, integer ltb, integer, dimension( * ) ipiv, integer, dimension( * ) ipiv2, complex*16, dimension( * ) work, integer lwork, integer info)

ZHETRF_AA_2STAGE

Propósito:

!>
!> ZHETRF_AA_2STAGE calcula la factorización de una matriz hermítica doble A
!> usando el algoritmo de Aasen. La forma de la factorización es
!>
!>    A = U**H*T*U  o  A = L*T*L**H
!>
!> donde U (o L) es un producto de matrices triangulares superiores (inferiores)
!> unitarias y de permutación, y T es una matriz de banda hermítica con el
!> ancho de banda NB (NB se selecciona internamente y se almacena en TB( 1 ), y T es 
!> factorizada LU con pivoteo parcial).
!>
!> Esta es la versión bloqueada del algoritmo, que llama a BLAS de Nivel 3.
!>

Parámetros

UPLO 
!>          UPLO es CHARACTER*1
!>          = 'U':  Se almacena el triángulo superior de A;
!>          = 'L':  Se almacena el triángulo inferior de A.
!>

N

!>          N es INTEGER
!>          El orden de la matriz A.  N >= 0.
!>

A

!>          A es una matriz COMPLEX*16, de dimensión (LDA,N)
!>          En la entrada, la matriz hermítica A. Si UPLO = 'U', la parte
!>          superior triangular N por N de A contiene la parte superior
!>          triangular de la matriz A, y la parte estrictamente inferior
!>          triangular de A no se referencia. Si UPLO = 'L', la parte
!>          inferior triangular N por N de A contiene la parte inferior
!>          triangular de la matriz A, y la parte estrictamente superior
!>          triangular de A no se referencia.
!>
!>          En la salida, L se almacena debajo (o encima) de los bloques subdiagonales,
!>          cuando UPLO es 'L' (o 'U').
!>

LDA

!>          LDA es INTEGER
!>          La dimensión principal del array A.  LDA >= max(1,N).
!>

TB

!>          TB es una matriz COMPLEX*16, de dimensión (MAX(1,LTB))
!>          En la salida, detalles de la factorización LU de la matriz de banda.
!>

LTB

!>          LTB es INTEGER
!>          El tamaño del array TB. LTB >= MAX(1,4*N), utilizado internamente
!>          para seleccionar NB tal que LTB >= (3*NB+1)*N.
!>
!>          Si LTB = -1, entonces se asume una consulta de espacio de trabajo; la
!>          rutina solo calcula el tamaño óptimo de LTB,
!>          lo devuelve como la primera entrada de TB, y
!>          XERBLA no emite ningún mensaje de error relacionado con LTB.
!>

IPIV

!>          IPIV es un array INTEGER, de dimensión (N)
!>          En la salida, contiene los detalles de los intercambios, es decir,
!>          la fila y columna k de A fueron intercambiadas con la
!>          fila y columna IPIV(k).
!>

IPIV2

!>          IPIV2 es un array INTEGER, de dimensión (N)
!>          En la salida, contiene los detalles de los intercambios, es decir,
!>          la fila y columna k de T fueron intercambiadas con la
!>          fila y columna IPIV(k).
!>

WORK

!>          WORK es un espacio de trabajo COMPLEX*16 de tamaño (MAX(1,LWORK))
!>

LWORK

!>          LWORK es INTEGER
!>          El tamaño de WORK. LWORK >= MAX(1,N), utilizado internamente para
!>          seleccionar NB tal que LWORK >= N*NB.
!>
!>          Si LWORK = -1, entonces se asume una consulta de espacio de trabajo; la
!>          rutina solo calcula el tamaño óptimo del array WORK,
!>          lo devuelve como la primera entrada del array WORK, y
!>          XERBLA no emite ningún mensaje de error relacionado con LWORK.
!>

INFO

!>          INFO es INTEGER
!>          = 0:  salida exitosa
!>          < 0:  si INFO = -i, el i-ésimo argumento tuvo un valor ilegal.
!>          > 0:  si INFO = i, la factorización LU de banda falló en la i-ésima columna
!>
