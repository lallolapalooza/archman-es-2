Documentación de la función/subrutina

subrutina zhptri (character uplo, integer n, complex*16, dimension( * ) ap, integer, dimension( * ) ipiv, complex*16, dimension( * ) work, integer info)

ZHPTRI

Propósito:

!>
!> ZHPTRI calcula la inversa de una matriz Hermítica indefinida compleja
!> A en almacenamiento empaquetado utilizando la factorización A = U*D*U**H o
!> A = L*D*L**H calculada por ZHPTRF.
!>

Parámetros

UPLO 
!>          UPLO es CHARACTER*1
!>          Especifica si los detalles de la factorización se almacenan
!>          como una matriz triangular superior o inferior.
!>          = 'U':  Triangular superior, forma es A = U*D*U**H;
!>          = 'L':  Triangular inferior, forma es A = L*D*L**H.
!>

N

!>          N es INTEGER
!>          Orden de la matriz A.  N >= 0.
!>

AP

!>          AP es un array COMPLEX*16, dimension (N*(N+1)/2)
!>          En la entrada, la matriz diagonal de bloques D y los multiplicadores
!>          utilizados para obtener el factor U o L calculados por ZHPTRF,
!>          almacenados como una matriz triangular empaquetada.
!>
!>          En la salida, si INFO = 0, la inversa (Hermítica) de la matriz
!>          original, almacenada como una matriz triangular empaquetada. La
!>          columna j de inv(A) se almacena en el array AP de la siguiente
!>          manera:
!>          si UPLO = 'U', AP(i + (j-1)*j/2) = inv(A)(i,j) para 1<=i<=j;
!>          si UPLO = 'L',
!>             AP(i + (j-1)*(2n-j)/2) = inv(A)(i,j) para j<=i<=n.
!>

IPIV

!>          IPIV es un array INTEGER, dimension (N)
!>          Detalles de los intercambios y la estructura de bloques de D
!>          determinada por ZHPTRF.
!>

WORK

!>          WORK es un array COMPLEX*16, dimension (N)
!>

INFO

!>          INFO es INTEGER
!>          = 0: salida exitosa
!>          < 0: si INFO = -i, el i-ésimo argumento tenía un valor ilegal
!>          > 0: si INFO = i, D(i,i) = 0; la matriz es singular y su
!>               inversa no pudo ser calculada.
!>
