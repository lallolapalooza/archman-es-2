Funciones/Subrutinas


subrutina zhetf2_rk (uplo, n, a, lda, e, ipiv, info)

ZHETF2_RK calcula la factorización de una matriz Hermitiana indefinida compleja utilizando el método de pivoteo diagonal acotado de Bunch-Kaufman (rook) (algoritmo no bloqueado BLAS2).

DOCUMENTACIÓN DE FUNCIÓN/SUBRUTINA

subrutina zhetf2_rk (character uplo, integer n, complex*16, dimension( lda, * ) a, integer lda, complex*16, dimension( * ) e, integer, dimension( * ) ipiv, integer info)

ZHETF2_RK calcula la factorización de una matriz Hermitiana indefinida compleja utilizando el método de pivoteo diagonal acotado de Bunch-Kaufman (rook) (algoritmo no bloqueado BLAS2).

Propósito:

!> ZHETF2_RK calcula la factorización de una matriz Hermitiana A compleja
!> utilizando el método de pivoteo diagonal acotado de Bunch-Kaufman (rook):
!>
!>    A = P*U*D*(U**H)*(P**T) o A = P*L*D*(L**H)*(P**T),
!>
!> donde U (o L) es una matriz triangular unitaria superior (o inferior),
!> U**H (o L**H) es la conjugada de U (o L), P es una matriz de permutación,
!> P**T es la transpuesta de P, y D es Hermitiana y diagonal por bloques
!> con bloques diagonales de 1x1 y 2x2.
!>
!> Esta es la versión no bloqueada del algoritmo, que llama a BLAS de Nivel 2.
!> Para más información ver la sección Detalles Adicionales.
!>

Parámetros

UPLO 
!>          UPLO es CHARACTER*1
!>          Especifica si la parte triangular superior o inferior de la
!>          matriz Hermitiana A está almacenada:
!>          = 'U':  Triangular superior
!>          = 'L':  Triangular inferior
!>

N

!>          N es INTEGER
!>          El orden de la matriz A.  N >= 0.
!>

A

!>          A es un array COMPLEX*16, de dimensiones (LDA,N)
!>          En la entrada, la matriz Hermitiana A.
!>            Si UPLO = 'U': la parte superior triangular N-por-N
!>            de A contiene la parte triangular superior de la matriz A,
!>            y la parte estrictamente triangular inferior de A no
!>            se referencia.
!>
!>            Si UPLO = 'L': la parte inferior triangular N-por-N
!>            de A contiene la parte triangular inferior de la matriz A,
!>            y la parte estrictamente triangular superior de A no
!>            se referencia.
!>
!>          En la salida, contiene:
!>            a) SOLAMENTE los elementos diagonales de la matriz Hermitiana
!>               diagonal por bloques D en la diagonal de A, es decir,
!>               D(k,k) = A(k,k);
!>               (los elementos superdiagonales (o subdiagonales) de D
!>                se almacenan en la salida en el array E), y
!>            b) Si UPLO = 'U': factor U en la parte superdiagonal de A.
!>               Si UPLO = 'L': factor L en la parte subdiagonal de A.
!>

LDA

!>          LDA es INTEGER
!>          La dimensión principal del array A.  LDA >= max(1,N).
!>

E

!>          E es un array COMPLEX*16, de dimensiones (N)
!>          En la salida, contiene los elementos superdiagonales (o subdiagonales)
!>          de la matriz Hermitiana diagonal por bloques D
!>          con bloques diagonales de 1x1 o 2x2, donde
!>          Si UPLO = 'U': E(i) = D(i-1,i), i=2:N, E(1) se establece a 0;
!>          Si UPLO = 'L': E(i) = D(i+1,i), i=1:N-1, E(N) se establece a 0.
!>
!>          NOTA: Para un bloque diagonal de 1x1 D(k), donde
!>          1 <= k <= N, el elemento E(k) se establece a 0 en ambos
!>          casos UPLO = 'U' o UPLO = 'L'.
!>

IPIV

!>          IPIV es un array INTEGER, de dimensiones (N)
!>          IPIV describe la matriz de permutación P en la factorización
!>          de la matriz A de la siguiente manera. El valor absoluto de IPIV(k)
!>          representa el índice de la fila y columna que fueron
!>          intercambiadas con la k-ésima fila y columna. El valor de UPLO
!>          describe el orden en que se aplicaron los intercambios.
!>          Además, el signo de IPIV representa la estructura de bloques de
!>          la matriz Hermitiana diagonal por bloques D con bloques de 1x1 o 2x2
!>          que corresponden a 1 o 2 intercambios
!>          en cada paso de factorización. Para más información ver la sección
!>          Detalles Adicionales.
!>
!>          Si UPLO = 'U',
!>          ( en orden de factorización, k disminuye de N a 1 ):
!>            a) Una única entrada positiva IPIV(k) > 0 significa:
!>               D(k,k) es un bloque diagonal de 1x1.
!>               Si IPIV(k) != k, las filas y columnas k e IPIV(k) fueron
!>               intercambiadas en la matriz A(1:N,1:N);
!>               Si IPIV(k) = k, no ocurrió ningún intercambio.
!>
!>            b) Un par de entradas consecutivas negativas
!>               IPIV(k) < 0 e IPIV(k-1) < 0 significa:
!>               D(k-1:k,k-1:k) es un bloque diagonal de 2x2.
!>               (NOTA: las entradas negativas en IPIV aparecen SÓLO en pares).
!>               1) Si -IPIV(k) != k, las filas y columnas
!>                  k y -IPIV(k) fueron intercambiadas
!>                  en la matriz A(1:N,1:N).
!>                  Si -IPIV(k) = k, no ocurrió ningún intercambio.
!>               2) Si -IPIV(k-1) != k-1, las filas y columnas
!>                  k-1 y -IPIV(k-1) fueron intercambiadas
!>                  en la matriz A(1:N,1:N).
!>                  Si -IPIV(k-1) = k-1, no ocurrió ningún intercambio.
!>
!>            c) En ambos casos a) y b), siempre ABS( IPIV(k) ) <= k.
!>
!>            d) NOTA: Cualquier entrada IPIV(k) es siempre DISTINTA DE CERO en la salida.
!>
!>          Si UPLO = 'L',
!>          ( en orden de factorización, k aumenta de 1 a N ):
!>            a) Una única entrada positiva IPIV(k) > 0 significa:
!>               D(k,k) es un bloque diagonal de 1x1.
!>               Si IPIV(k) != k, las filas y columnas k e IPIV(k) fueron
!>               intercambiadas en la matriz A(1:N,1:N).
!>               Si IPIV(k) = k, no ocurrió ningún intercambio.
!>
!>            b) Un par de entradas consecutivas negativas
!>               IPIV(k) < 0 e IPIV(k+1) < 0 significa:
!>               D(k:k+1,k:k+1) es un bloque diagonal de 2x2.
!>               (NOTA: las entradas negativas en IPIV aparecen SÓLO en pares).
!>               1) Si -IPIV(k) != k, las filas y columnas
!>                  k y -IPIV(k) fueron intercambiadas
!>                  en la matriz A(1:N,1:N).
!>                  Si -IPIV(k) = k, no ocurrió ningún intercambio.
!>               2) Si -IPIV(k+1) != k+1, las filas y columnas
!>                  k-1 y -IPIV(k-1) fueron intercambiadas
!>                  en la matriz A(1:N,1:N).
!>                  Si -IPIV(k+1) = k+1, no ocurrió ningún intercambio.
!>
!>            c) En ambos casos a) y b), siempre ABS( IPIV(k) ) >= k.
!>
!>            d) NOTA: Cualquier entrada IPIV(k) es siempre DISTINTA DE CERO en la salida.
!>

INFO

!>          INFO es INTEGER
!>          = 0: salida exitosa
!>
!>          < 0: Si INFO = -k, el k-ésimo argumento tenía un valor ilegal
!>
!>          > 0: Si INFO = k, la matriz A es singular, debido a que:
!>                 Si UPLO = 'U': la columna k en la parte
!>                 triangular superior de A contiene todos ceros.
!>                 Si UPLO = 'L': la columna k en la parte
!>                 triangular inferior de A contiene todos ceros.
!>
!>               Por lo tanto D(k,k) es exactamente cero, y los elementos superdiagonales
!>               de la columna k de U (o los elementos subdiagonales de
!>               la columna k de L) son todos ceros. La factorización ha
!>               sido completada, pero la matriz diagonal por bloques D
!>               es exactamente singular, y ocurrirá una división por cero si
!>               se utiliza para resolver un sistema de ecuaciones.
!>
!>               NOTA: INFO solo almacena la primera ocurrencia de
!>               una singularidad, cualquier ocurrencia posterior de singularidad
!>               no se almacena en INFO aunque la factorización
!>               siempre se completa.
!>

  CHARACTER * 1 :: UPLO

  COMPLEX*16 :: WORK( * )

Function/Subroutine Documentation

  !>  LAPACK auxiliary routine (version 3.1).
!>
!>  Purpose
!>  =======
!>
!>  ZHETF2_RK computes the factorization of a complex Hermitian
!>  matrix A in the form
!>
!>     A =  U * T * U**H
!>
!>  where U is a unitary matrix, T is a tridiagonal matrix, and
!>  UPLO = 'U'.
!>
!>  In the following recalls, U is not required.
!>
!>     A =  U * T * U**H
!>
!>  In the following recalls, U is not required.
!>
!>     A =  U * T * U**H
!>
!>  where U is a unitary matrix and T is a tridiagonal matrix.
!>
!>  ZHETF2_RK is the unblocked version of the routine ZHETRF.
!>  If WITHZ = .TRUE.
!>     Then the unitary matrix U is computed and stored in
!>     RETURN WORK( 2*N+1 ), and the diagonal matrix D is computed
!>     and stored in WORK( N+1 ).
!>
!>  If WITHZ = .FALSE.
!>     Then the unitary matrix U is not computed.
!>
!>  If WITHK = .TRUE.
!>     Then the diagonal matrix D is computed and stored in WORK( N+1 ).
!>
!>  Arguments
!>  =========
!>
!>  UPLO    (input) CHARACTER*1
!>          Specifies whether the upper or lower triangular part of the
!>          Hermitian matrix A is stored:
!>          = 'U':      Upper triangular part is stored.
!>          = 'L':      Lower triangular part is stored.
!>
!>  N       (input) INTEGER
!>          The order of the matrix A.  N >= 0.
!>
!>  K       (output) INTEGER
!>          The number of the subdiagonal entries.
!>
!>  A       (input/output) COMPLEX*16 array, dimension (LDA,N)
!>          On entry, the Hermitian matrix A.
!>          On exit, if UPLO = 'U', the upper triangle of A is
!>          alternatingly overwritten with diagonal elements and
!>          multipliers of the subdiagonal elements below the k-th
!>          subdiagonal needed to form the diagonal elements of the
!>          tridiagonal matrix T. The nangonal elements of A contain
!>          the diagonal elements of T, and the elements above the
!>          diagonal contain the corresponding elements of the tridiagonal
!>          matrix T. The elements below the k-th subdiagonal are
!>          overwritten by elements of the unitary matrix U.
!>          If UPLO = 'L', the lower triangle of A is similarly overwritten
!>          by the factors of the tridiagonal matrix T.
!>
!>  LDA     (input) INTEGER
!>          The leading dimension of the array A.  LDA >= max(1,N).
!>
!>  D       (output) COMPLEX*16 array, dimension (N)
!>          On exit, the diagonal elements of the tridiagonal matrix T.
!>
!>  E       (output) COMPLEX*16 array, dimension (N-1)
!>          On exit, the subdiagonal elements of the tridiagonal matrix T.
!>          E(i) elements are stored for i = 1..N-1.
!>
!>  TAU     (output) COMPLEX*16 array, dimension (N-1)
!>          On exit, TAU(i) contains the scalar factor of the elementary
!>          re ector stored in the i-th column and (i+1)-th row of A,
!>          from the above triangular factor.
!>
!>  WORK    (workspace) COMPLEX*16 array, dimension (N)
!>          On exit, WORK(i) contains the i-th diagonal element of the
!>          diagonal matrix D.
!>
!>  INFO    (output) INTEGER
!>          = 0: successful exit
!>          < 0: if INFO = -i, the i-th argument had an illegal value.
!>

!>     Based on the algorithms used in DSYTRF and DSFTRF.
