subroutine zheevx_2stage (character jobz, character range, character uplo, integer n, complex*16, dimension( lda, * ) a, integer lda, double precision vl, double precision vu, integer il, integer iu, double precision abstol, integer m, double precision, dimension( * ) w, complex*16, dimension( ldz, * ) z, integer ldz, complex*16, dimension( * ) work, integer lwork, double precision, dimension( * ) rwork, integer, dimension( * ) iwork, integer, dimension( * ) ifail, integer info)

ZHEEVX_2STAGE calcula los valores propios y, opcionalmente, los vectores propios izquierdos y/o derechos para matrices HE

Propósito:

!>
!> ZHEEVX_2STAGE calcula valores propios seleccionados y, opcionalmente, vectores
!> propios de una matriz Hermítica compleja A utilizando la técnica de
!> 2 etapas para la reducción a tridiagonal. Los valores propios y vectores
!> propios pueden ser seleccionados especificando un rango de valores o un
!> rango de índices para los valores propios deseados.
!>

Parámetros

JOBZ 
!>          JOBZ es CHARACTER*1
!>          = 'N':  Calcula solo los valores propios;
!>          = 'V':  Calcula los valores propios y vectores propios.
!>                  No disponible en esta versión.
!>

RANGE

!>          RANGE es CHARACTER*1
!>          = 'A': se encontrarán todos los valores propios.
!>          = 'V': se encontrarán todos los valores propios en el intervalo semiabierto (VL,VU].
!>          = 'I': se encontrarán los valores propios del IL-ésimo al IU-ésimo.
!>

UPLO

!>          UPLO es CHARACTER*1
!>          = 'U':  Se almacena el triángulo superior de A;
!>          = 'L':  Se almacena el triángulo inferior de A.
!>

N

!>          N es INTEGER
!>          El orden de la matriz A. N >= 0.
!>

A

!>          A es un array COMPLEX*16, dimensión (LDA, N)
!>          En la entrada, la matriz Hermítica A. Si UPLO = 'U', la
!>          parte triangular superior N por N de A contiene la
!>          parte triangular superior de la matriz A. Si UPLO = 'L',
!>          la parte triangular inferior N por N de A contiene la
!>          parte triangular inferior de la matriz A.
!>          En la salida, el triángulo inferior (si UPLO='L') o el triángulo
!>          superior (si UPLO='U') de A, incluyendo la diagonal, se destruye.
!>

LDA

!>          LDA es INTEGER
!>          La dimensión principal del array A. LDA >= max(1,N).
!>

VL

!>          VL es DOUBLE PRECISION
!>          Si RANGE='V', el límite inferior del intervalo a
!>          buscar para los valores propios. VL < VU.
!>          No referenciado si RANGE = 'A' o 'I'.
!>

VU

!>          VU es DOUBLE PRECISION
!>          Si RANGE='V', el límite superior del intervalo a
!>          buscar para los valores propios. VL < VU.
!>          No referenciado si RANGE = 'A' o 'I'.
!>

IL

!>          IL es INTEGER
!>          Si RANGE='I', el índice del
!>          valor propio más pequeño a devolver.
!>          1 <= IL <= IU <= N, si N > 0; IL = 1 y IU = 0 si N = 0.
!>          No referenciado si RANGE = 'A' o 'V'.
!>

IU

!>          IU es INTEGER
!>          Si RANGE='I', el índice del
!>          valor propio más grande a devolver.
!>          1 <= IL <= IU <= N, si N > 0; IL = 1 y IU = 0 si N = 0.
!>          No referenciado si RANGE = 'A' o 'V'.
!>

ABSTOL

!>          ABSTOL es DOUBLE PRECISION
!>          La tolerancia de error absoluto para los valores propios.
!>          Se acepta un valor propio aproximado como convergente
!>          cuando se determina que yace en un intervalo [a,b]
!>          de anchura menor o igual que
!>
!>                  ABSTOL + EPS *   max( |a|,|b| ) ,
!>
!>          donde EPS es la precisión de la máquina. Si ABSTOL es menor
!>          o igual que cero, entonces se usará EPS*|T| en su lugar,
!>          donde |T| es la norma 1 de la matriz tridiagonal obtenida
!>          al reducir A a forma tridiagonal.
!>
!>          Los valores propios se calcularán con mayor precisión cuando ABSTOL
!>          se establezca en el doble del umbral de subdesbordamiento 2*DLAMCH('S'), no cero.
!>          Si esta rutina retorna con INFO>0, indicando que algunos
!>          vectores propios no convergieron, intente establecer ABSTOL en
!>          2*DLAMCH('S').
!>
!>          Ver  por Demmel y
!>          Kahan, LAPACK Working Note #3.
!>

M

!>          M es INTEGER
!>          El número total de valores propios encontrados. 0 <= M <= N.
!>          Si RANGE = 'A', M = N, y si RANGE = 'I', M = IU-IL+1.
!>

W

!>          W es un array DOUBLE PRECISION, dimensión (N)
!>          En una salida normal, los primeros M elementos contienen los valores propios
!>          seleccionados en orden ascendente.
!>

Z

!>          Z es un array COMPLEX*16, dimensión (LDZ, max(1,M))
!>          Si JOBZ = 'V', entonces si INFO = 0, las primeras M columnas de Z
!>          contienen los vectores propios ortonormales de la matriz A
!>          correspondientes a los valores propios seleccionados, con la i-ésima
!>          columna de Z conteniendo el vector propio asociado a W(i).
!>          Si un vector propio falla en converger, entonces esa columna de Z
!>          contiene la última aproximación del vector propio, y el
!>          índice del vector propio se devuelve en IFAIL.
!>          Si JOBZ = 'N', entonces Z no se referencia.
!>          Nota: el usuario debe asegurarse de que se suministran al menos
!>          max(1,M) columnas en el array Z; si RANGE = 'V', el valor exacto de M
!>          no se conoce de antemano y se debe usar un límite superior.
!>

LDZ

!>          LDZ es INTEGER
!>          La dimensión principal del array Z. LDZ >= 1, y si
!>          JOBZ = 'V', LDZ >= max(1,N).
!>

WORK

!>          WORK es un array COMPLEX*16, dimensión (MAX(1,LWORK))
!>          En la salida, si INFO = 0, WORK(1) retorna el LWORK óptimo.
!>

LWORK

!>          LWORK es INTEGER
!>          La longitud del array WORK. LWORK >= 1, cuando N <= 1;
!>          de lo contrario
!>          Si JOBZ = 'N' y N > 1, se debe consultar LWORK.
!>                                   LWORK = MAX(1, 8*N, dimension) donde
!>                                   dimension = max(stage1,stage2) + (KD+1)*N + N
!>                                             = N*KD + N*max(KD+1,FACTOPTNB)
!>                                               + max(2*KD*KD, KD*NTHREADS)
!>                                               + (KD+1)*N + N
!>                                   donde KD es el tamaño del bloque de la reducción,
!>                                   FACTOPTNB es el bloqueo utilizado por el algoritmo QR o LQ
!>                                   generalmente FACTOPTNB=128 es una buena opción
!>                                   NTHREADS es el número de hilos utilizados cuando
!>                                   la compilación openMP está habilitada, de lo contrario =1.
!>          Si JOBZ = 'V' y N > 1, se debe consultar LWORK. Aún no disponible.
!>
!>          Si LWORK = -1, se asume una consulta de espacio de trabajo; la rutina
!>

NAME

zheevx_2stage - The subroutine computes the eigenvalues and eigenvectors of a complex Hermitian matrix.

SYNOPSIS

Call zheevx_2stage(JOBZ, RANGE, UPLO, N, A, LDA, VL, VU, IL, IU,
                   ABSTOL, M, W, Z, LDZ, ZWORK, RWORK, IWORK, INFO)

     CHARACTER          JOBZ, RANGE, UPLO
     INTEGER            N, LDA, IL, IU, M, LDZ
     DOUBLE PRECISION   VL, VU, ABSTOL
     COMPLEX*16         A( LDA, * ), W( * ), Z( LDZ, * ), ZWORK( * )
     DOUBLE PRECISION   RWORK( * )
     INTEGER            IWORK( * )

Function/Subroutine Documentation

JOBZ CHARACTER*1
= 'N': Compute only the eigenvalues of A.
= 'V': Compute the eigenvalues and eigenvectors of A.
Constraint: JOBZ = 'N' or 'V'.
RANGE CHARACTER*1
= 'A': all eigenvalues will be found.
= 'V': all eigenvalues in the range [VL,VU] will be found.
= 'I': all eigenvalues in the range [IL,IU]-th place will be found.
Constraint: RANGE = 'A', 'V' or 'I'.
UPLO CHARACTER*1
= 'U': Upper triangle of A is stored and referenced.
= 'L': Lower triangle of A is stored and referenced.
Constraint: UPLO = 'U' or 'L'.
N INTEGER
The order of the matrix A. N >= 0.
A COMPLEX*16 array, dimension (LDA, N)
On entry, the complex symmetric matrix A.
On exit:
if JOBZ = 'V', A is overwritten by details of its factorization.
if JOBZ = 'N', the upper or lower triangle of A may be modified by some internal routines.
LDA INTEGER
The leading dimension of A. LDA >= max(1,N).
VL DOUBLE PRECISION
If RANGE = 'V', the lower bound of the eigenvalue range.
VU DOUBLE PRECISION
If RANGE = 'V', the upper bound of the eigenvalue range.
IL INTEGER
If RANGE = 'I', the index of the smallest eigenvalue in the range.
IU INTEGER
If RANGE = 'I', the index of the largest eigenvalue in the range.
ABSTOL DOUBLE PRECISION
The tolerance for the eigenvalues. An eigenvalue is accepted if it is in the range [VL,VU], and relative error is less than ABSTOL. For the 'I' case, the set of eigenvalues with indices [IL, IU] will be chosen. For the 'A' and 'V' cases, tolerance ABSTOL is used to delimit the range of confidence for the selected eigenvalues. Use ABSTOL = MAX(ABS(VL),ABS(VU)) * EPS or zero if you want to select all computable eigenvalues. To achieve the most typically desired tolerance (underflow related), use an zero value for ABSTOL.
M INTEGER
The total number of eigenvalues found.
If RANGE = 'E' and ABSTOL >= zero, M is the number of eigenvalues found.
If RANGE = 'E' and ABSTOL < zero, M is the number of eigenvalues calculated.
If RANGE = 'I', M is the number of eigenvalues with indices between IL and IU.
W DOUBLE PRECISION array, dimension (N)
On exit, the estimated eigenvalues, sorted in an increasing order.
Z COMPLEX*16 array, dimension (LDZ, N)
On exit, the normalized (unit L2 norm) eigenvectors, such that the column Z(i) is the eigenvector corresponding to the eigenvalue W(i).
Only returned if JOBZ = 'V'.
LDZ INTEGER
The leading dimension of the array Z.
LDZ >= max(1,N).
ZWORK COMPLEX*16 array, dimension (MAX(1,LWORK))
On exit, if JOBZ = 'N', ZWORK is used as workspace.
On exit, if JOBZ = 'V', ZWORK is used as workspace.
Note: LWORK is the optimal length of ZWORK. LWORK is determined by the routine, and the minimum length required is MAX(1,2*N). The optimal value is returned in ZWORK(1).
RWORK DOUBLE PRECISION array, dimension (7*N)
IWORK INTEGER array, dimension (5*N)
INFO INTEGER
= 0: successful exit
< 0: if INFO = -i, the i-th argument had an illegal value
> 0: if INFO = i, then i eigenvectors failed to converge. Their indices are stored in array IFAIL.
