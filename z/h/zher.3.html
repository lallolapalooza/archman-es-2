Documentación de Función/Subrutina

subrutina zher (carácter uplo, entero n, doble precisión alpha, complejo*16, dimensión(*) x, entero incx, complejo*16, dimensión(lda,*) a, entero lda)

ZHER

Propósito:

!>
!> ZHER   realiza la operación hermitiana de rango 1
!>
!>    A := alpha*x*x**H + A,
!>
!> donde alpha es un escalar real, x es un vector de n elementos y A es una
!> matriz hermitiana de n por n.
!>

Parámetros

UPLO 
!>          UPLO es CHARACTER*1
!>           A la entrada, UPLO especifica si la parte triangular superior o
!>           inferior del array A debe ser referenciada como
!>           sigue:
!>
!>              UPLO = 'U' o 'u'   Solo la parte triangular superior de A
!>                                  debe ser referenciada.
!>
!>              UPLO = 'L' o 'l'   Solo la parte triangular inferior de A
!>                                  debe ser referenciada.
!>

N

!>          N es INTEGER
!>           A la entrada, N especifica el orden de la matriz A.
!>           N debe ser al menos cero.
!>

ALPHA

!>          ALPHA es DOUBLE PRECISION.
!>           A la entrada, ALPHA especifica el escalar alpha.
!>

X

!>          X es un array COMPLEX*16, de dimensión al menos
!>           ( 1 + ( n - 1 )*abs( INCX ) ).
!>           Antes de la entrada, el array X incrementado debe contener el
!>           vector x de n elementos.
!>

INCX

!>          INCX es INTEGER
!>           A la entrada, INCX especifica el incremento para los elementos
!>           de X. INCX no debe ser cero.
!>

A

!>          A es un array COMPLEX*16, de dimensión ( LDA, N )
!>           Antes de la entrada con UPLO = 'U' o 'u', la parte triangular
!>           superior de n por n del array A debe contener la parte
!>           triangular superior de la matriz hermitiana y la parte
!>           triangular inferior estricta de A no es referenciada. A la
!>           salida, la parte triangular superior del array A se sobrescribe
!>           con la parte triangular superior de la matriz actualizada.
!>           Antes de la entrada con UPLO = 'L' o 'l', la parte triangular
!>           inferior de n por n del array A debe contener la parte
!>           triangular inferior de la matriz hermitiana y la parte
!>           triangular superior estricta de A no es referenciada. A la
!>           salida, la parte triangular inferior del array A se sobrescribe
!>           con la parte triangular inferior de la matriz actualizada.
!>           Tenga en cuenta que las partes imaginarias de los elementos
!>           diagonales no necesitan ser establecidas, se asumen cero, y a
!>           la salida se establecen a cero.
!>

LDA

!>          LDA es INTEGER
!>           A la entrada, LDA especifica la primera dimensión de A tal como
!>           está declarada en el programa (sub)llamador. LDA debe ser al
!>           menos max( 1, n ).
!>
