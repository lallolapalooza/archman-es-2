subrutina zhetri2 (character uplo, integer n, complex*16, dimension( lda, * ) a, integer lda, integer, dimension( * ) ipiv, complex*16, dimension( * ) work, integer lwork, integer info)

ZHETRI2

Propósito:

!>
!> ZHETRI2 calcula la inversa de una matriz hermítica indefinida COMPLEX*16
!> A utilizando la factorización A = U*D*U**T o A = L*D*L**T calculada por
!> ZHETRF. ZHETRI2 establece la DIMENSIÓN PRINCIPAL del espacio de trabajo
!> antes de llamar a ZHETRI2X, que realmente calcula la inversa.
!>

Parámetros

UPLO 
!>          UPLO es CHARACTER*1
!>          Especifica si los detalles de la factorización se almacenan
!>          como una matriz triangular superior o inferior.
!>          = 'U': Triangular superior, la forma es A = U*D*U**T;
!>          = 'L': Triangular inferior, la forma es A = L*D*L**T.
!>

N

!>          N es INTEGER
!>          El orden de la matriz A.  N >= 0.
!>

A

!>          A es un array COMPLEX*16, dimensión (LDA,N)
!>          En la entrada, la matriz diagonal de bloques D y los multiplicadores
!>          utilizados para obtener el factor U o L calculados por ZHETRF.
!>
!>          En la salida, si INFO = 0, la inversa (simétrica) de la matriz
!>          original. Si UPLO = 'U', la parte triangular superior de la
!>          inversa se forma y la parte de A por debajo de la diagonal no
!>          se referencia; si UPLO = 'L' la parte triangular inferior de la
!>          inversa se forma y la parte de A por encima de la diagonal no
!>          se referencia.
!>

LDA

!>          LDA es INTEGER
!>          La dimensión principal del array A.  LDA >= max(1,N).
!>

IPIV

!>          IPIV es un array INTEGER, dimensión (N)
!>          Detalles de los intercambios y la estructura de bloques de D
!>          tal como determinó ZHETRF.
!>

WORK

!>          WORK es un array COMPLEX*16, dimensión (MAX(1,LWORK)).
!>

LWORK

!>          LWORK es INTEGER
!>          La dimensión del array WORK.
!>          Si N = 0, LWORK >= 1, de lo contrario LWORK >= (N+NB+1)*(NB+3).
!>          Si LWORK = -1, se asume una consulta de espacio de trabajo; la rutina
!>          calcula:
!>              - el tamaño óptimo del array WORK, devuelve
!>          este valor como la primera entrada del array WORK,
!>              - y XERBLA no emite ningún mensaje de error relacionado con LWORK.
!>

INFO

!>          INFO es INTEGER
!>          = 0: finalización exitosa
!>          < 0: si INFO = -i, el argumento i-ésimo tenía un valor ilegal
!>          > 0: si INFO = i, D(i,i) = 0; la matriz es singular y su
!>               inversa no pudo ser calculada.
!>
