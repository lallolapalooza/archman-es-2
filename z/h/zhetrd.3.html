ZHETRD

Documentación de Función/Subrutina

subrutina zhetrd (character uplo, integer n, complex*16, dimension( lda, * ) a, integer lda, double precision, dimension( * ) d, double precision, dimension( * ) e, complex*16, dimension( * ) tau, complex*16, dimension( * ) work, integer lwork, integer info)

ZHETRD

Propósito:

!>
!> ZHETRD reduce una matriz Hermitiana compleja A a la forma tridiagonal
!> Hermitiana simétrica real T mediante una transformación unitaria de
!> similitud:
!> Q**H * A * Q = T.
!>

Parámetros

UPLO 
!>          UPLO es CHARACTER*1
!>          = 'U':  El triángulo superior de A se almacena;
!>          = 'L':  El triángulo inferior de A se almacena.
!>

N

!>          N es INTEGER
!>          El orden de la matriz A.  N >= 0.
!>

A

!>          A es array COMPLEX*16, dimensión (LDA,N)
!>          En la entrada, la matriz Hermitiana A. Si UPLO = 'U', la parte
!>          superior triangular N-por-N líder de A contiene la parte
!>          superior triangular de la matriz A, y la parte estrictamente
!>          inferior triangular de A no se referencia. Si UPLO = 'L', la
!>          parte inferior triangular N-por-N líder de A contiene la parte
!>          inferior triangular de la matriz A, y la parte estrictamente
!>          superior triangular de A no se referencia.
!>          En la salida, si UPLO = 'U', la diagonal y la primera
!>          superdiagonal de A se sobrescriben con los elementos
!>          correspondientes de la matriz tridiagonal T, y los elementos
!>          por encima de la primera superdiagonal, junto con el array
!>          TAU, representan la matriz unitaria Q como un producto de
!>          reflejos elementales; si UPLO = 'L', la diagonal y la primera
!>          subdiagonal de A se sobrescriben con los elementos
!>          correspondientes de la matriz tridiagonal T, y los elementos
!>          por debajo de la primera subdiagonal, junto con el array TAU,
!>          representan la matriz unitaria Q como un producto de reflejos
!>          elementales. Ver Detalles Adicionales.
!>

LDA

!>          LDA es INTEGER
!>          La dimensión líder del array A.  LDA >= max(1,N).
!>

D

!>          D es array DOUBLE PRECISION, dimensión (N)
!>          Los elementos diagonales de la matriz tridiagonal T:
!>          D(i) = A(i,i).
!>

E

!>          E es array DOUBLE PRECISION, dimensión (N-1)
!>          Los elementos fuera de la diagonal de la matriz tridiagonal T:
!>          E(i) = A(i,i+1) si UPLO = 'U', E(i) = A(i+1,i) si UPLO = 'L'.
!>

TAU

!>          TAU es array COMPLEX*16, dimensión (N-1)
!>          Los factores escalares de los reflejos elementales (ver
!>          Detalles Adicionales).
!>

WORK

!>          WORK es array COMPLEX*16, dimensión (MAX(1,LWORK))
!>          En la salida, si INFO = 0, WORK(1) devuelve el LWORK óptimo.
!>

LWORK

!>          LWORK es INTEGER
!>          La dimensión del array WORK.  LWORK >= 1.
!>          Para un rendimiento óptimo LWORK >= N*NB, donde NB es el
!>          tamaño de bloque óptimo.
!>
!>          Si LWORK = -1, entonces se asume una consulta de espacio de
!>          trabajo; la rutina solo calcula el tamaño óptimo del array
!>          WORK, devuelve este valor como la primera entrada del array
!>          WORK, y XERBLA no emite ningún mensaje de error relacionado
!>          con LWORK.
!>

INFO

!>          INFO es INTEGER
!>          = 0:  salida exitosa
!>          < 0:  si INFO = -i, el i-ésimo argumento tenía un valor ilegal
!>

Detalles Adicionales:

!>
!>  Si UPLO = 'U', la matriz Q se representa como un producto de reflejos
!>  elementales
!>
!>     Q = H(n-1) . . . H(2) H(1).
!>
!>  Cada H(i) tiene la forma
!>
!>     H(i) = I - tau * v * v**H
!>
!>  donde tau es un escalar complejo, y v es un vector complejo con
!>  v(i+1:n) = 0 y v(i) = 1; v(1:i-1) se almacena en la salida en
!>  A(1:i-1,i+1), y tau en TAU(i).
!>
!>  Si UPLO = 'L', la matriz Q se representa como un producto de reflejos
!>  elementales
!>
!>     Q = H(1) H(2) . . . H(n-1).
!>
!>  Cada H(i) tiene la forma
!>
!>     H(i) = I - tau * v * v**H
!>
!>  donde tau es un escalar complejo, y v es un vector complejo con
!>  v(1:i) = 0 y v(i+1) = 1; v(i+2:n) se almacena en la salida en A(i+2:n,i),
!>  y tau en TAU(i).
!>
!>  El contenido de A en la salida se ilustra con los siguientes ejemplos
!>  con n = 5:
!>
!>  si UPLO = 'U':                       si UPLO = 'L':
!>
!>    (  d   e   v2  v3  v4 )              (  d                  )
!>    (      d   e   v3  v4 )              (  e   d              )
!>    (          d   e   v4 )              (  v1  e   d          )
!>    (              d   e  )              (  v1  v2  e   d      )
!>    (                  d  )              (  v1  v2  v3  e   d  )
!>
!>  donde d y e denotan elementos diagonales y fuera de la diagonal de T,
!>  y vi denota un elemento del vector que define H(i).
!>
