ZHET21

Propósito:

!>
!> ZHET21 generalmente comprueba una descomposición de la forma
!>
!>    A = U S U**H
!>
!> donde **H significa transpuesta conjugada, A es hermitiana, U es unitaria, y
!> S es diagonal (si KBAND=0) o (real) simétrica tridiagonal (si
!> KBAND=1).
!>
!> Si ITYPE=1, entonces U se representa como una matriz densa; de lo contrario, U se
!> expresa como un producto de transformaciones de Householder, cuyos vectores
!> se almacenan en el array  y cuyas constantes de escala están en .
!> Usaremos la letra  para referirnos al producto de transformaciones de
!> Householder (que debe ser igual a U).
!>
!> Específicamente, si ITYPE=1, entonces:
!>
!>    RESULT(1) = | A - U S U**H | / ( |A| n ulp ) y
!>    RESULT(2) = | I - U U**H | / ( n ulp )
!>
!> Si ITYPE=2, entonces:
!>
!>    RESULT(1) = | A - V S V**H | / ( |A| n ulp )
!>
!> Si ITYPE=3, entonces:
!>
!>    RESULT(1) = | I - U V**H | / ( n ulp )
!>
!> Para ITYPE > 1, la transformación U se expresa como un producto
!> V = H(1)...H(n-2),  donde H(j) = I  -  tau(j) v(j) v(j)**H y cada
!> vector v(j) tiene sus primeros j elementos 0 y los elementos restantes n-j
!> almacenados en V(j+1:n,j).
!>

Parámetros

ITYPE 
!>          ITYPE es INTEGER
!>          Especifica el tipo de pruebas a realizar.
!>          1: U se expresa como una matriz unitaria densa:
!>             RESULT(1) = | A - U S U**H | / ( |A| n ulp ) y
!>             RESULT(2) = | I - U U**H | / ( n ulp )
!>
!>          2: U se expresa como un producto V de transformaciones de Householder:
!>             RESULT(1) = | A - V S V**H | / ( |A| n ulp )
!>
!>          3: U se expresa tanto como una matriz unitaria densa como
!>             un producto de transformaciones de Householder:
!>             RESULT(1) = | I - U V**H | / ( n ulp )
!>

UPLO

!>          UPLO es CHARACTER
!>          Si UPLO='U', se utilizará el triángulo superior de A y V, y
!>          el triángulo (estrictamente) inferior no se referenciará.
!>          Si UPLO='L', se utilizará el triángulo inferior de A y V, y
!>          el triángulo (estrictamente) superior no se referenciará.
!>

N

!>          N es INTEGER
!>          El tamaño de la matriz. Si es cero, ZHET21 no hace nada.
!>          Debe ser mayor o igual a cero.
!>

KBAND

!>          KBAND es INTEGER
!>          El ancho de banda de la matriz. Solo puede ser cero o uno.
!>          Si es cero, entonces S es diagonal, y E no se referencia. Si
!>          es uno, entonces S es tridiagonal simétrica.
!>

A

!>          A es un array COMPLEX*16, dimensión (LDA, N)
!>          La matriz original (no factorizada). Se asume que es
!>          hermitiana, y solo se referenciará la parte superior (UPLO='U')
!>          o solo la inferior (UPLO='L').
!>

LDA

!>          LDA es INTEGER
!>          La dimensión principal de A. Debe ser al menos 1
!>          y al menos N.
!>

D

!>          D es un array DOUBLE PRECISION, dimensión (N)
!>          La diagonal de la matriz (tridiagonal simétrica).
!>

E

!>          E es un array DOUBLE PRECISION, dimensión (N-1)
!>          La parte fuera de la diagonal de la matriz (tridiagonal simétrica).
!>          E(1) es el elemento (1,2) y (2,1), E(2) es el elemento (2,3) y
!>          (3,2), etc.
!>          No se referencia si KBAND=0.
!>

U

!>          U es un array COMPLEX*16, dimensión (LDU, N)
!>          Si ITYPE=1 o 3, contiene la matriz unitaria en
!>          la descomposición, expresada como una matriz densa. Si ITYPE=2,
!>          entonces no se referencia.
!>

LDU

!>          LDU es INTEGER
!>          La dimensión principal de U. LDU debe ser al menos N y
!>          al menos 1.
!>

V

!>          V es un array COMPLEX*16, dimensión (LDV, N)
!>          Si ITYPE=2 o 3, las columnas de esta matriz contienen los
!>          vectores de Householder que describen la matriz unitaria en
!>          la descomposición. Si UPLO='L', entonces los vectores están en
!>          el triángulo inferior, si UPLO='U', entonces en el triángulo
!>          superior.
!>          *NOTA* Si ITYPE=2 o 3, V se modifica y se restaura. La
!>          subdiagonal (si UPLO='L') o la supradiagonal (si UPLO='U')
!>          se establece en uno, y posteriormente se restaura a su valor original,
!>          durante el curso del cálculo.
!>          Si ITYPE=1, entonces no se referencia ni se modifica.
!>

LDV

!>          LDV es INTEGER
!>          La dimensión principal de V. LDV debe ser al menos N y
!>          al menos 1.
!>

TAU

!>          TAU es un array COMPLEX*16, dimensión (N)
!>          Si ITYPE >= 2, entonces TAU(j) es el factor escalar de
!>          v(j) v(j)**H en la transformación de Householder H(j) del
!>          producto  U = H(1)...H(n-2)
!>          Si ITYPE < 2, entonces TAU no se referencia.
!>

WORK

!>          WORK es un array COMPLEX*16, dimensión (2*N**2)
!>

RWORK

!>          RWORK es un array DOUBLE PRECISION, dimensión (N)
!>

RESULT

!>          RESULT es un array DOUBLE PRECISION, dimensión (2)
!>          Los valores calculados por las dos pruebas descritas anteriormente.
!>          Los valores se limitan actualmente a 1/ulp, para evitar desbordamientos.
!>          RESULT(1) se modifica siempre. RESULT(2) se modifica solo
!>          si ITYPE=1.
!>

NOMBRE

zhet21 - Construye una matriz Hermitiana a partir de la mitad inferior y la diagonal.

SINOPSIS

 SUBROUTINE ZHET21(
     N, A, LDA, TRI, INFO)

     INTEGER            N
     COMPLEX*16         A( LDA, * )
     INTEGER            LDA
     CHARACTER*1        TRI
     INTEGER            INFO

Documentación/Subrutina/Función

ZHET21 es una subrutina de la biblioteca LAPACK que se utiliza para construir una matriz Hermitiana a partir de su parte triangular inferior y su diagonal. Esta subrutina es útil cuando se trabaja con matrices Hermitianas en operaciones de álgebra lineal, especialmente en el contexto de la resolución de sistemas de ecuaciones lineales o el cálculo de valores y vectores propios.

**Parámetros:**

* **N** (ENTERO): Es el orden de la matriz (N x N).

* **A** (COMPLEX*16): Es la matriz que contendrá la información. En la entrada, contiene la parte triangular inferior y la diagonal de la matriz Hermitiana. En la salida, contendrá la matriz Hermitiana completa.

* **LDA** (ENTERO): Es la longitud de la fila de A (el primer índice de la dimensión de A).

* **TRI** (CARÁCTER*1): Especifica qué parte de la matriz se está proporcionando.

* Si TRI = 'L', la parte triangular inferior de A se utiliza para construir la matriz Hermitiana.

* Si TRI = 'U', la parte triangular superior de A se utiliza para construir la matriz Hermitiana.

* **INFO** (ENTERO): Es un indicador de salida.

* INFO = 0: Ejecución exitosa.

* INFO < 0: Si el valor de -INFO es el número de parámetro inválido.

**Detalles:**

La subrutina asume que la matriz A contiene la información necesaria en la parte especificada por TRI. Para construir la matriz Hermitiana completa, la subrutina copia los elementos de la parte triangular especificada a la parte conjugada transpuesta para asegurar que A sea Hermitiana.

Por ejemplo, si TRI = 'L', los elementos A(i, j) para i > j se copian a A(j, i) tomando el conjugado complejo. Si TRI = 'U', los elementos A(i, j) para i < j se copian a A(j, i) tomando el conjugado complejo.

La diagonal de la matriz A permanece inalterada.
