subrutina zhet01 (character uplo, integer n, complex*16, dimension( lda, * ) a, integer lda, complex*16, dimension( ldafac, * ) afac, integer ldafac, integer, dimension( * ) ipiv, complex*16, dimension( ldc, * ) c, integer ldc, double precision, dimension( * ) rwork, double precision resid)

ZHET01

Propósito:

!>
!> ZHET01 reconstruye una matriz Hermitiana indefinida A a partir de su
!> factorización de bloque L*D*L' o U*D*U' y calcula la norma residual
!>    norm( C - A ) / ( N * norm(A) * EPS ),
!> donde C es la matriz reconstruida, EPS es la epsilon de la máquina,
!> L' es la transpuesta conjugada de L y U' es la transpuesta conjugada
!> de U.
!>

Parámetros

UPLO 
!>          UPLO es CHARACTER*1
!>          Especifica si la parte triangular superior o inferior de la
!>          matriz Hermitiana A está almacenada:
!>          = 'U':  Triangular superior
!>          = 'L':  Triangular inferior
!>

N

!>          N es INTEGER
!>          El número de filas y columnas de la matriz A.  N >= 0.
!>

A

!>          A es array COMPLEX*16, dimension (LDA,N)
!>          La matriz Hermitiana original A.
!>

LDA

!>          LDA es INTEGER
!>          La dimensión principal del array A.  LDA >= max(1,N)
!>

AFAC

!>          AFAC es array COMPLEX*16, dimension (LDAFAC,N)
!>          La forma factorizada de la matriz A. AFAC contiene la matriz
!>          diagonal de bloques D y los multiplicadores utilizados para
!>          obtener L o U a partir de la factorización de bloque L*D*L'
!>          o U*D*U' calculada por ZHETRF.
!>

LDAFAC

!>          LDAFAC es INTEGER
!>          La dimensión principal del array AFAC. LDAFAC >= max(1,N).
!>

IPIV

!>          IPIV es array INTEGER, dimension (N)
!>          Los índices de pivote de ZHETRF.
!>

C

!>          C es array COMPLEX*16, dimension (LDC,N)
!>

LDC

!>          LDC es INTEGER
!>          La dimensión principal del array C. LDC >= max(1,N).
!>

RWORK

!>          RWORK es array DOUBLE PRECISION, dimension (N)
!>

RESID

!>          RESID es DOUBLE PRECISION
!>          Si UPLO = 'L', norm(L*D*L' - A) / ( N * norm(A) * EPS )
!>          Si UPLO = 'U', norm(U*D*U' - A) / ( N * norm(A) * EPS )
!>
