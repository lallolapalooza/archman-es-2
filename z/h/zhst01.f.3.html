subrutina zhst01 (entero n, entero ilo, entero ihi, complejo*16, dimensión( lda, * ) a, entero lda, complejo*16, dimensión( ldh, * ) h, entero ldh, complejo*16, dimensión( ldq, * ) q, entero ldq, complejo*16, dimensión( lwork ) work, entero lwork, doble precisión, dimensión( * ) rwork, doble precisión, dimensión( 2 ) result)

ZHST01

Propósito:

!>
!> ZHST01 prueba la reducción de una matriz general A a la forma Hessenberg superior:
!> A = Q*H*Q'. Se calculan dos ratios de prueba;
!>
!> RESULT(1) = norm( A - Q*H*Q' ) / ( norm(A) * N * EPS )
!> RESULT(2) = norm( I - Q'*Q ) / ( N * EPS )
!>
!> Se asume que la matriz Q se proporciona explícitamente tal como estaría
!> después de ZGEHRD + ZUNGHR.
!>
!> En esta versión, ILO e IHI no se utilizan, pero podrían usarse
!> para ahorrar algo de trabajo si se desea.
!>

Parámetros

N 
!>          N es ENTERO
!>          El orden de la matriz A. N >= 0.
!>

ILO

!>          ILO es ENTERO
!>

IHI

!>          IHI es ENTERO
!>
!>          Se asume que A es triangular superior en filas y columnas
!>          1:ILO-1 y IHI+1:N, por lo que Q difiere de la identidad solo en
!>          las filas y columnas ILO+1:IHI.
!>

A

!>          A es una matriz COMPLEJO*16, dimensión (LDA,N)
!>          La matriz original A de n por n.
!>

LDA

!>          LDA es ENTERO
!>          La dimensión principal de la matriz A. LDA >= max(1,N).
!>

H

!>          H es una matriz COMPLEJO*16, dimensión (LDH,N)
!>          La matriz Hessenberg superior H de la reducción A = Q*H*Q'
!>          calculada por ZGEHRD. Se asume que H es cero debajo de la
!>          primera subdiagonal.
!>

LDH

!>          LDH es ENTERO
!>          La dimensión principal de la matriz H. LDH >= max(1,N).
!>

Q

!>          Q es una matriz COMPLEJO*16, dimensión (LDQ,N)
!>          La matriz ortogonal Q de la reducción A = Q*H*Q' calculada
!>          por ZGEHRD + ZUNGHR.
!>

LDQ

!>          LDQ es ENTERO
!>          La dimensión principal de la matriz Q. LDQ >= max(1,N).
!>

WORK

!>          WORK es una matriz COMPLEJO*16, dimensión (LWORK)
!>

LWORK

!>          LWORK es ENTERO
!>          La longitud de la matriz WORK. LWORK >= 2*N*N.
!>

RWORK

!>          RWORK es una matriz DOBLE PRECISION, dimensión (N)
!>

RESULT

!>          RESULT es una matriz DOBLE PRECISION, dimensión (2)
!>          RESULT(1) = norm( A - Q*H*Q' ) / ( norm(A) * N * EPS )
!>          RESULT(2) = norm( I - Q'*Q ) / ( N * EPS )
!>
