Documentación de la función/subrutina

subrutina zherfs (character uplo, integer n, integer nrhs, complex*16, dimension( lda, * ) a, integer lda, complex*16, dimension( ldaf, * ) af, integer ldaf, integer, dimension( * ) ipiv, complex*16, dimension( ldb, * ) b, integer ldb, complex*16, dimension( ldx, * ) x, integer ldx, double precision, dimension( * ) ferr, double precision, dimension( * ) berr, complex*16, dimension( * ) work, double precision, dimension( * ) rwork, integer info)

ZHERFS

Propósito:

!>
!> ZHERFS mejora la solución calculada de un sistema de ecuaciones
!> lineales cuando la matriz de coeficientes es hermitiana indefinida, y
!> proporciona cotas de error y estimaciones de error hacia atrás para la solución.
!>

Parámetros

UPLO 
!>          UPLO es CHARACTER*1
!>          = 'U':  El triángulo superior de A está almacenado;
!>          = 'L':  El triángulo inferior de A está almacenado.
!>

N

!>          N es INTEGER
!>          El orden de la matriz A.  N >= 0.
!>

NRHS

!>          NRHS es INTEGER
!>          El número de lados derechos, es decir, el número de columnas
!>          de las matrices B y X.  NRHS >= 0.
!>

A

!>          A es un array COMPLEX*16, de dimensión (LDA,N)
!>          La matriz hermitiana A.  Si UPLO = 'U', la parte triangular
!>          superior N-por-N principal de A contiene la parte triangular
!>          superior de la matriz A, y la parte triangular estrictamente
!>          inferior de A no se referencia. Si UPLO = 'L', la parte
!>          triangular inferior N-por-N principal de A contiene la parte
!>          triangular inferior de la matriz A, y la parte triangular
!>          estrictamente superior de A no se referencia.
!>

LDA

!>          LDA es INTEGER
!>          La dimensión principal del array A.  LDA >= max(1,N).
!>

AF

!>          AF es un array COMPLEX*16, de dimensión (LDAF,N)
!>          La forma factorizada de la matriz A.  AF contiene la matriz
!>          diagonal por bloques D y los multiplicadores utilizados para
!>          obtener U o L de la factorización A = U*D*U**H o
!>          A = L*D*L**H calculada por ZHETRF.
!>

LDAF

!>          LDAF es INTEGER
!>          La dimensión principal del array AF.  LDAF >= max(1,N).
!>

IPIV

!>          IPIV es un array INTEGER, de dimensión (N)
!>          Detalles de los intercambios y la estructura de bloques de D
!>          tal como se determinó por ZHETRF.
!>

B

!>          B es un array COMPLEX*16, de dimensión (LDB,NRHS)
!>          La matriz del lado derecho B.
!>

LDB

!>          LDB es INTEGER
!>          La dimensión principal del array B.  LDB >= max(1,N).
!>

X

!>          X es un array COMPLEX*16, de dimensión (LDX,NRHS)
!>          En la entrada, la matriz solución X, tal como la calculó ZHETRS.
!>          En la salida, la matriz solución mejorada X.
!>

LDX

!>          LDX es INTEGER
!>          La dimensión principal del array X.  LDX >= max(1,N).
!>

FERR

!>          FERR es un array DOUBLE PRECISION, de dimensión (NRHS)
!>          La cota de error hacia adelante estimada para cada vector solución
!>          X(j) (la j-ésima columna de la matriz solución X).
!>          Si XTRUE es la solución verdadera correspondiente a X(j), FERR(j)
!>          es una cota superior estimada para la magnitud del elemento más grande
!>          en (X(j) - XTRUE) dividido por la magnitud del elemento más grande
!>          en X(j). La estimación es tan confiable como la estimación para
!>          RCOND, y es casi siempre una ligera sobreestimación del error real.
!>

BERR

!>          BERR es un array DOUBLE PRECISION, de dimensión (NRHS)
!>          El error hacia atrás relativo componente a componente de cada vector solución
!>          X(j) (es decir, el cambio relativo más pequeño en
!>          cualquier elemento de A o B que hace que X(j) sea una solución exacta).
!>

WORK

!>          WORK es un array COMPLEX*16, de dimensión (2*N)
!>

RWORK

!>          RWORK es un array DOUBLE PRECISION, de dimensión (N)
!>

INFO

!>          INFO es INTEGER
!>          = 0:  salida exitosa
!>          < 0:  si INFO = -i, el i-ésimo argumento tenía un valor ilegal
!>

Parámetros internos:

!>  ITMAX es el número máximo de pasos de refinamiento iterativo.
!>
