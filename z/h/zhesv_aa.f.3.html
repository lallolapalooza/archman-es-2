Funciones/Subrutinas


subrutina zhesv_aa (uplo, n, nrhs, a, lda, ipiv, b, ldb, work, lwork, info)
ZHESV_AA calcula la solución al sistema de ecuaciones lineales A * X = B para matrices HE

Documentación de la Función/Subrutina

subrutina zhesv_aa (character uplo, integer n, integer nrhs, complex*16, dimension( lda, * ) a, integer lda, integer, dimension( * ) ipiv, complex*16, dimension( ldb, * ) b, integer ldb, complex*16, dimension( * ) work, integer lwork, integer info)

ZHESV_AA calcula la solución a un sistema complejo de ecuaciones lineales A * X = B,

Propósito:

!>
!> ZHESV_AA calcula la solución a un sistema complejo de ecuaciones lineales
!>    A * X = B,
!> donde A es una matriz Hermitiana N-por-N y X y B son matrices N-por-NRHS.
!>
!> Se utiliza el algoritmo de Aasen para factorizar A como
!>    A = U**H * T * U,  si UPLO = 'U', o
!>    A = L * T * L**H,  si UPLO = 'L',
!> donde U (o L) es un producto de matrices de permutación y triangulares unitarias
!> superiores (inferiores), y T es Hermitiana y tridiagonal. La forma factorizada
!> de A se utiliza luego para resolver el sistema de ecuaciones A * X = B.
!>

Parámetros

UPLO 
!>          UPLO es CHARACTER*1
!>          = 'U':  El triángulo superior de A está almacenado;
!>          = 'L':  El triángulo inferior de A está almacenado.
!>

N

!>          N es INTEGER
!>          El número de ecuaciones lineales, es decir, el orden de
!>          la matriz A.  N >= 0.
!>

NRHS

!>          NRHS es INTEGER
!>          El número de lados derechos, es decir, el número de columnas
!>          de la matriz B.  NRHS >= 0.
!>

A

!>          A es array COMPLEX*16, dimension (LDA,N)
!>          En la entrada, la matriz Hermitiana A.  Si UPLO = 'U', la parte
!>          superior triangular N-por-N de A contiene la parte superior
!>          triangular de la matriz A, y la parte estrictamente inferior
!>          triangular de A no se referencia.  Si UPLO = 'L', la parte
!>          inferior triangular N-por-N de A contiene la parte inferior
!>          triangular de la matriz A, y la parte estrictamente superior
!>          triangular de A no se referencia.
!>
!>          En la salida, si INFO = 0, la matriz tridiagonal T y los
!>          multiplicadores utilizados para obtener el factor U o L de la
!>          factorización A = U**H*T*U o A = L*T*L**H, tal como lo calcula
!>          ZHETRF_AA.
!>

LDA

!>          LDA es INTEGER
!>          La dimensión principal del array A.  LDA >= max(1,N).
!>

IPIV

!>          IPIV es array INTEGER, dimension (N)
!>          En la salida, contiene los detalles de los intercambios, es decir,
!>          la fila y columna k de A fueron intercambiadas con la
!>          fila y columna IPIV(k).
!>

B

!>          B es array COMPLEX*16, dimension (LDB,NRHS)
!>          En la entrada, la matriz B del lado derecho N-por-NRHS.
!>          En la salida, si INFO = 0, la matriz solución X N-por-NRHS.
!>

LDB

!>          LDB es INTEGER
!>          La dimensión principal del array B.  LDB >= max(1,N).
!>

WORK

!>          WORK es array COMPLEX*16, dimension (MAX(1,LWORK))
!>          En la salida, si INFO = 0, WORK(1) devuelve el LWORK óptimo.
!>

LWORK

!>          LWORK es INTEGER
!>          La longitud de WORK.  LWORK >= MAX(1,2*N,3*N-2), y para el mejor 
!>          rendimiento LWORK >= max(1,N*NB), donde NB es el tamaño de bloque óptimo
!>          para ZHETRF_AA.
!>
!>          Si LWORK = -1, entonces se asume una consulta de espacio de trabajo; la rutina
!>          solo calcula el tamaño óptimo del array WORK, devuelve
!>          este valor como la primera entrada del array WORK, y XERBLA no emite
!>          ningún mensaje de error relacionado con LWORK.
!>

INFO

!>          INFO es INTEGER
!>          = 0: finalización exitosa
!>          < 0: si INFO = -i, el i-ésimo argumento tenía un valor ilegal
!>          > 0: si INFO = i, D(i,i) es exactamente cero. La factorización
!>               se ha completado, pero la matriz diagonal por bloques D es
!>               exactamente singular, por lo que la solución no pudo ser calculada.
!>
