Documentación de la función/subrutina

subroutine zhseqr (character job, character compz, integer n, integer ilo, integer ihi, complex*16, dimension( ldh, * ) h, integer ldh, complex*16, dimension( * ) w, complex*16, dimension( ldz, * ) z, integer ldz, complex*16, dimension( * ) work, integer lwork, integer info)

ZHSEQR

Propósito:

!>
!>    ZHSEQR calcula los valores propios de una matriz de Hessenberg H
!>    y, opcionalmente, las matrices T y Z de la descomposición de Schur
!>    H = Z T Z**H, donde T es una matriz triangular superior (la
!>    forma de Schur), y Z es la matriz unitaria de vectores de Schur.
!>
!>    Opcionalmente, Z puede ser postmultiplicada en una matriz unitaria
!>    de entrada Q para que esta subrutina pueda dar la factorización de Schur
!>    de una matriz A que ha sido reducida a la forma de Hessenberg
!>    H por la matriz unitaria Q:  A = Q*H*Q**H = (QZ)*T*(QZ)**H.
!>

Parámetros

JOB 
!>          JOB es CHARACTER*1
!>           = 'E':  calcular solo los valores propios;
!>           = 'S':  calcular los valores propios y la forma de Schur T.
!>

COMPZ

!>          COMPZ es CHARACTER*1
!>           = 'N':  no se calculan vectores de Schur;
!>           = 'I':  Z se inicializa a la matriz identidad y se devuelve la matriz Z
!>                   de vectores de Schur de H;
!>           = 'V':  Z debe contener una matriz unitaria Q en la entrada, y
!>                   el producto Q*Z se devuelve.
!>

N

!>          N es INTEGER
!>           El orden de la matriz H.  N >= 0.
!>

ILO

!>          ILO es INTEGER
!>

IHI

!>          IHI es INTEGER
!>
!>           Se asume que H ya es triangular superior en las filas
!>           y columnas 1:ILO-1 e IHI+1:N. ILO e IHI normalmente
!>           son establecidos por una llamada previa a ZGEBAL, y luego pasados a ZGEHRD
!>           cuando la matriz de salida de ZGEBAL se reduce a la forma de Hessenberg.
!>           De lo contrario, ILO e IHI deben establecerse a 1 y N
!>           respectivamente.  Si N > 0, entonces 1 <= ILO <= IHI <= N.
!>           Si N = 0, entonces ILO = 1 e IHI = 0.
!>

H

!>          H es un array COMPLEX*16, dimensión (LDH,N)
!>           En la entrada, la matriz de Hessenberg superior H.
!>           En la salida, si INFO = 0 y JOB = 'S', H contiene la matriz
!>           triangular superior T de la descomposición de Schur
!>           (la forma de Schur). Si INFO = 0 y JOB = 'E', el contenido de
!>           H no se especifica en la salida.  (El valor de salida de H cuando
!>           INFO > 0 se da bajo la descripción de INFO a continuación.)
!>
!>           A diferencia de las versiones anteriores de ZHSEQR, esta subrutina puede
!>           establecer explícitamente H(i,j) = 0 para i > j y j = 1, 2, ... ILO-1
!>           o j = IHI+1, IHI+2, ... N.
!>

LDH

!>          LDH es INTEGER
!>           La dimensión principal del array H. LDH >= max(1,N).
!>

W

!>          W es un array COMPLEX*16, dimensión (N)
!>           Los valores propios calculados. Si JOB = 'S', los valores propios se
!>           almacenan en el mismo orden que en la diagonal de la forma de
!>           Schur devuelta en H, con W(i) = H(i,i).
!>

Z

!>          Z es un array COMPLEX*16, dimensión (LDZ,N)
!>           Si COMPZ = 'N', Z no se referencia.
!>           Si COMPZ = 'I', en la entrada Z no necesita estar establecida y en la salida,
!>           si INFO = 0, Z contiene la matriz unitaria Z de los vectores de Schur
!>           de H.  Si COMPZ = 'V', en la entrada Z debe contener una
!>           matriz N por N, Q, que se asume igual a la matriz identidad excepto
!>           por la submatriz Z(ILO:IHI,ILO:IHI). En la salida,
!>           si INFO = 0, Z contiene Q*Z.
!>           Normalmente Q es la matriz unitaria generada por ZUNGHR
!>           después de la llamada a ZGEHRD que formó la matriz de Hessenberg
!>           H. (El valor de salida de Z cuando INFO > 0 se da bajo
!>           la descripción de INFO a continuación.)
!>

LDZ

!>          LDZ es INTEGER
!>           La dimensión principal del array Z.  si COMPZ = 'I' o
!>           COMPZ = 'V', entonces LDZ >= MAX(1,N).  De lo contrario, LDZ >= 1.
!>

WORK

!>          WORK es un array COMPLEX*16, dimensión (LWORK)
!>           En la salida, si INFO = 0, WORK(1) devuelve una estimación de
!>           el valor óptimo para LWORK.
!>

LWORK

!>          LWORK es INTEGER
!>           La dimensión del array WORK.  LWORK >= max(1,N)
!>           es suficiente y proporciona un rendimiento muy bueno y a veces
!>           óptimo.  Sin embargo, LWORK tan grande como 11*N
!>           puede ser necesario para un rendimiento óptimo.
!>           Se recomienda una consulta del espacio de trabajo para determinar el tamaño óptimo del espacio de trabajo.
!>
!>           Si LWORK = -1, entonces ZHSEQR realiza una consulta del espacio de trabajo.
!>           En este caso, ZHSEQR comprueba los parámetros de entrada y
!>           estima el tamaño óptimo del espacio de trabajo para los
!>           valores dados de N, ILO e IHI.  La estimación se devuelve
!>           en WORK(1).  XERBLA no emite ningún mensaje de error relacionado con LWORK.
!>           Ni H ni Z se acceden.
!>

INFO

!>          INFO es INTEGER
!>             = 0:  salida exitosa
!>             < 0:  si INFO = -i, el i-ésimo argumento tuvo un valor ilegal
!>                    valor
!>             > 0:  si INFO = i, ZHSEQR no pudo calcular todos los
!>                valores propios.  Los elementos 1:ilo-1 y i+1:n de W
!>                contienen aquellos valores propios que se han
!>                calculado con éxito.  (Los fallos son raros.)
!>
!>                Si INFO > 0 y JOB = 'E', entonces en la salida,
!>                los valores propios no convergidos restantes son los valores
!>                propios de la matriz de Hessenberg superior de las filas
!>                y columnas ILO a INFO del valor final de H.
!>
!>                Si INFO > 0 y JOB   = 'S', entonces en la salida
!>
!>           (*)  (valor inicial de H)*U  = U*(valor final de H)
!>
!>                donde U es una matriz unitaria.  El valor final
!>                de H es de Hessenberg superior y triangular en
!>                las filas y columnas INFO+1 a IHI.
!>
!>                Si INFO > 0 y COMPZ = 'V', entonces en la salida
!>
!>                  (valor final de Z)  =  (valor inicial de Z)*U
!>
!>                donde U es la matriz unitaria en (*) (independientemente
!>                del valor de JOB.)
!>
!>                Si INFO > 0 y COMPZ = 'I', entonces en la salida
!>                      (valor final de Z)  = U
!>                donde U es la matriz unitaria en (*) (independientemente
!>                del valor de JOB.)
!>
!>                Si INFO > 0 y COMPZ = 'N', entonces Z no se
!>                accede.
!>

zhseqr(3) - LAPACK

NAME

zhseqr - computes the eigenvalues and Schur factorization of a general complex sequencematrix

SYNOPSIS

 subroutine zhseqr(job, compz, n, ILO, IHI, A, LDA, WR, WI, Z, LDZ,
                   WORK, LWORK, INFO)
 integer n, ILO, IHI, LDA, LDZ, LWORK, INFO
 complex*16 A(LDA, *), Z(LDZ, *), WORK(LWORK)
 complex*16 WR(*), WI(*)
 character job, compz

Function/Subroutine Documentation

This subroutine implements the QR algorithm for finding the eigenvalues and Schur factorization of a general matrix. It is described in detail in Chapter 3 of the LAPACK Users' Guide.

Input Parameters

JOB
Specifies whether to compute all eigenvalues or only the eigenvalues of the Hessenberg part of the matrix.
'E': Compute all eigenvalues.
'S': Compute eigenvalues of the Hessenberg part only.
COMPZ
Specifies whether to compute the Schur vectors.
'N': Do not compute the Schur vectors.
'V': Compute the Schur vectors.
'I': Compute the Schur vectors (initial matrix).
N
The order of the matrix A. N must be at least 0.
ILO
The row and column index of the starting element of the diagonal block.
IHI
The row and column index of the ending element of the diagonal block.
A
The N-by-N matrix for which the eigenvalues and Schur factorization are to be computed.
LDA
The leading dimension of the array A. LDA must be at least max(1, N).
WR
WR and WI contain the real and imaginary parts, respectively, of the eigenvalues of A. The eigenvalues are always stored in the order they are found. If job is 'E', then the eigenvalues are sorted in descending order of magnitude.
WI
See WR.
Z
If COMPZ is 'V' or 'I', Z is an N-by-N array which contains the unitary matrix U such that A * U = U * T, where T is the Schur form. If COMPZ is 'N', Z is not used.
LDZ
The leading dimension of the array Z. LDZ must be at least max(1, N).
WORK
On exit, WORK(1) contains the minimum and required amount of real workspace.
LWORK
The dimension of the array WORK. LWORK must be at least max(1, N). For optimal performance, LWORK should be at least N*NB, where NB is the block size.
INFO
INFO is INTEGER
= 0: successful exit
< 0: if INFO = -i, then the i-th argument had an illegal value.
> 0: if INFO = i, then the QR algorithm failed to compute all the eigenvalues, and i off-diagonal elements of A did not converge to zero.

Options from IPARMQ

The following options can be set using IPARMQ:

            ISPEC=1: Whether to use the aggressive early deflation
                     technique. (Default: Use.)
            ISPEC=2: Whether to use the shift-in-place technique.
                     (Default: Use.)
            ISPEC=3: Whether to use the divide-and-conquer technique
                     for finding eigenvalues. (Default: Use.)
            ISPEC=4: Whether to use the implicit double shift technique.
                     (Default: Use.)
            ISPEC=5: Whether to use the explicit double shift technique.
                     (Default: Use.)
            ISPEC=6: Whether to use the single shift technique.
                     (Default: Use.)
            ISPEC=7: Whether to use the two-shift technique.
                     (Default: Use.)
            ISPEC=8: Whether to use the implicit single shift technique.
                     (Default: Use.)
            ISPEC=9: Whether to use the implicit two-shift technique.
                     (Default: Use.)
            ISPEC=10: Whether to use the explicit single shift technique.
                      (Default: Use.)
            ISPEC=11: Whether to use the explicit two-shift technique.
                      (Default: Use.)
            ISPEC=12: Selects the routine used to compute the Schur
                      factorization. The default is ZLAHQR.
            ISPEC=13: Block size for the deflation window. (See ISPEC=15
                      below.) The default for (IHI-ILO+1) <= 500 is NS.
                      The default for (IHI-ILO+1) >  500 is 3*NS/2.
            ISPEC=14: Nibble crossover point. (See IPARMQ for
                      details.) Default: 14% of deflation window
                      size.
            ISPEC=15: Number of simultaneous shifts in a multishift
                      QR iteration.
                      If IHI-ILO+1 is ...
                      greater than      ...but less    ... the
                      or equal to ...      than        default is
                           1               30          NS =   2(+)
                          30               60          NS =   4(+)
                          60              150          NS =  10(+)
                         150              590          NS =  **
                         590             3000          NS = 64
                        3000             6000          NS = 128
                        6000             infinity      NS = 256
                      (+)  By default some or all matrices of this order
                           are passed to the implicit double shift routine
                           ZLAHQR and this parameter is ignored.  See
                           ISPEC=12 above and comments in IPARMQ for
                           details.
                     (**)  The asterisks (**) indicate an ad-hoc
                           function of N increasing from 10 to 64.
            ISPEC=16: Select structured matrix multiply.
                      If the number of simultaneous shifts (specified
                      by ISPEC=15) is less than 14, then the default
                      for ISPEC=16 is 0.  Otherwise the default for
                      ISPEC=16 is 2.
