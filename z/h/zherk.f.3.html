Documentación de la función/subrutina

subrutina zherk (character uplo, character trans, integer n, integer k, double precision alpha, complex*16, dimension(lda,*) a, integer lda, double precision beta, complex*16, dimension(ldc,*) c, integer ldc)

ZHERK

Propósito:

!>
!> ZHERK  realiza una de las operaciones hermíticas de rango k
!>
!>    C := alpha*A*A**H + beta*C,
!>
!> o
!>
!>    C := alpha*A**H*A + beta*C,
!>
!> donde  alpha y beta  son  escalares reales,  C es una matriz  hermítica
!> de n por n y  A  es una matriz de n por k en el primer caso y una matriz
!> de k por n en el segundo caso.
!>

Parámetros

UPLO 
!>          UPLO es CHARACTER*1
!>           Al entrar, UPLO especifica si la parte triangular superior o inferior
!>           de la matriz C debe ser referenciada según se indica a continuación:
!>
!>              UPLO = 'U' o 'u'   Solo se referencia la parte triangular superior de C.
!>
!>              UPLO = 'L' o 'l'   Solo se referencia la parte triangular inferior de C.
!>

TRANS

!>          TRANS es CHARACTER*1
!>           Al entrar, TRANS especifica la operación a realizar de la siguiente manera:
!>
!>              TRANS = 'N' o 'n'   C := alpha*A*A**H + beta*C.
!>
!>              TRANS = 'C' o 'c'   C := alpha*A**H*A + beta*C.
!>

N

!>          N es INTEGER
!>           Al entrar, N especifica el orden de la matriz C. N debe ser
!>           al menos cero.
!>

K

!>          K es INTEGER
!>           Al entrar con TRANS = 'N' o 'n', K especifica el número
!>           de columnas de la matriz A, y al entrar con
!>           TRANS = 'C' o 'c', K especifica el número de filas de la
!>           matriz A. K debe ser al menos cero.
!>

ALPHA

!>          ALPHA es DOUBLE PRECISION.
!>           Al entrar, ALPHA especifica el escalar alpha.
!>

A

!>          A es un array COMPLEX*16, de dimensión ( LDA, ka ), donde ka es
!>           k  cuando  TRANS = 'N' o 'n',  y es  n  en caso contrario.
!>           Antes de entrar con TRANS = 'N' o 'n', la parte principal n por k
!>           del array A debe contener la matriz A, en caso contrario, la parte principal
!>           k por n del array A debe contener la matriz A.
!>

LDA

!>          LDA es INTEGER
!>           Al entrar, LDA especifica la primera dimensión de A tal como se declaró
!>           en el programa (sub)llamador. Cuando TRANS = 'N' o 'n',
!>           LDA debe ser al menos max( 1, n ), en caso contrario LDA debe
!>           ser al menos max( 1, k ).
!>

BETA

!>          BETA es DOUBLE PRECISION.
!>           Al entrar, BETA especifica el escalar beta.
!>

C

!>          C es un array COMPLEX*16, de dimensión ( LDC, N ).
!>           Antes de entrar con UPLO = 'U' o 'u', la parte principal n por n
!>           del array C debe contener la parte triangular superior de la
!>           matriz hermítica y la parte estrictamente triangular inferior de C no se referencia. A la salida, la
!>           parte triangular superior del array C se sobrescribe con la
!>           parte triangular superior de la matriz actualizada.
!>           Antes de entrar con UPLO = 'L' o 'l', la parte principal n por n
!>           del array C debe contener la parte triangular inferior de la
!>           matriz hermítica y la parte estrictamente triangular superior de C no se referencia. A la salida, la
!>           parte triangular inferior del array C se sobrescribe con la
!>           parte triangular inferior de la matriz actualizada.
!>           Tenga en cuenta que las partes imaginarias de los elementos diagonales no
!>           necesariamente se establecen, se asumen como cero, y a la salida se
!>           establecen a cero.
!>

LDC

!>          LDC es INTEGER
!>           Al entrar, LDC especifica la primera dimensión de C tal como se declaró
!>           en el programa (sub)llamador. LDC debe ser al menos
!>           max( 1, n ).
!>
