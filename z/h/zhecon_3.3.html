DOCUMENTACIÓN DE FUNCIÓN/SUBRUTINA

subroutine zhecon_3 (character uplo, integer n, complex*16, dimension( lda, * ) a, integer lda, complex*16, dimension( * ) e, integer, dimension( * ) ipiv, double precision anorm, double precision rcond, complex*16, dimension( * ) work, integer info)

ZHECON_3

Propósito:

!> ZHECON_3 estima el recíproco del número de condición (en la norma 1)
!> de una matriz Hermitiana compleja A utilizando la factorización
!> calculada por ZHETRF_RK o ZHETRF_BK:
!>
!>    A = P*U*D*(U**H)*(P**T) o A = P*L*D*(L**H)*(P**T),
!>
!> donde U (o L) es una matriz triangular unitaria superior (o inferior),
!> U**H (o L**H) es la conjugada de U (o L), P es una matriz de permutación,
!> P**T es la transpuesta de P, y D es Hermitiana y diagonal por bloques
!> con bloques diagonales de 1x1 y 2x2.
!>
!> Se obtiene una estimación para norm(inv(A)), y el recíproco del
!> número de condición se calcula como RCOND = 1 / (ANORM * norm(inv(A))).
!> Esta rutina utiliza el resolvedor BLAS3 ZHETRS_3.
!>

Parámetros

UPLO 
!>          UPLO es CHARACTER*1
!>          Especifica si los detalles de la factorización se almacenan
!>          como una matriz triangular superior o inferior:
!>          = 'U':  Triangular superior, la forma es A = P*U*D*(U**H)*(P**T);
!>          = 'L':  Triangular inferior, la forma es A = P*L*D*(L**H)*(P**T).
!>

N

!>          N es INTEGER
!>          El orden de la matriz A.  N >= 0.
!>

A

!>          A es un array COMPLEX*16, dimensión (LDA,N)
!>          Diagonal de la matriz diagonal por bloques D y factores U o L
!>          calculados por ZHETRF_RK y ZHETRF_BK:
!>            a) SÓLO los elementos diagonales de la matriz diagonal por bloques
!>               Hermitiana D en la diagonal de A, es decir, D(k,k) = A(k,k);
!>               (los elementos supradiagonales (o subdiagonales) de D
!>                deben proporcionarse en la entrada en el array E), y
!>            b) Si UPLO = 'U': factor U en la parte supradiagonal de A.
!>               Si UPLO = 'L': factor L en la parte subdiagonal de A.
!>

LDA

!>          LDA es INTEGER
!>          La dimensión principal del array A.  LDA >= max(1,N).
!>

E

!>          E es un array COMPLEX*16, dimensión (N)
!>          En la entrada, contiene los elementos supradiagonales (o subdiagonales)
!>          de la matriz diagonal por bloques Hermitiana D
!>          con bloques diagonales de 1x1 o 2x2, donde
!>          Si UPLO = 'U': E(i) = D(i-1,i),i=2:N, E(1) no referenciado;
!>          Si UPLO = 'L': E(i) = D(i+1,i),i=1:N-1, E(N) no referenciado.
!>
!>          NOTA: Para un bloque diagonal de 1x1 D(k), donde
!>          1 <= k <= N, el elemento E(k) no se referencia en ambos
!>          casos UPLO = 'U' o UPLO = 'L'.
!>

IPIV

!>          IPIV es un array INTEGER, dimensión (N)
!>          Detalles de los intercambios y la estructura de bloques de D
!>          según lo determinado por ZHETRF_RK o ZHETRF_BK.
!>

ANORM

!>          ANORM es DOUBLE PRECISION
!>          La norma 1 de la matriz original A.
!>

RCOND

!>          RCOND es DOUBLE PRECISION
!>          El recíproco del número de condición de la matriz A,
!>          calculado como RCOND = 1/(ANORM * AINVNM), donde AINVNM es una
!>          estimación de la norma 1 de inv(A) calculada en esta rutina.
!>

WORK

!>          WORK es un array COMPLEX*16, dimensión (2*N)
!>

INFO

!>          INFO es INTEGER
!>          = 0:  salida exitosa
!>          < 0:  si INFO = -i, el i-ésimo argumento tenía un valor ilegal
!>
