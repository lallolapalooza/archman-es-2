subrutina zhbgvx (character jobz, character range, character uplo, integer n, integer ka, integer kb, complex*16, dimension( ldab, * ) ab, integer ldab, complex*16, dimension( ldbb, * ) bb, integer ldbb, complex*16, dimension( ldq, * ) q, integer ldq, double precision vl, double precision vu, integer il, integer iu, double precision abstol, integer m, double precision, dimension( * ) w, complex*16, dimension( ldz, * ) z, integer ldz, complex*16, dimension( * ) work, double precision, dimension( * ) rwork, integer, dimension( * ) iwork, integer, dimension( * ) ifail, integer info)

ZHBGVX

Propósito:

!>
!> ZHBGVX calcula todos los valores propios, y opcionalmente, los vectores propios
!> de un problema de valores propios hermítico-definido general complejo con banda,
!> de la forma A*x=(lambda)*B*x. Aquí A y B se suponen hermíticos
!> y con banda, y B es también positivo definido. Los valores propios y
!> los vectores propios pueden ser seleccionados especificando todos los valores propios,
!> un rango de valores o un rango de índices para los valores propios deseados.
!>

Parámetros

JOBZ 
!>          JOBZ es CHARACTER*1
!>          = 'N':  Calcular solo los valores propios;
!>          = 'V':  Calcular valores propios y vectores propios.
!>

RANGE

!>          RANGE es CHARACTER*1
!>          = 'A': se encontrarán todos los valores propios;
!>          = 'V': se encontrarán todos los valores propios en el intervalo semiabierto (VL,VU]
!>                 que se buscan;
!>          = 'I': se encontrarán los valores propios desde el IL-ésimo hasta el IU-ésimo.
!>

UPLO

!>          UPLO es CHARACTER*1
!>          = 'U':  Se almacenan las bandas superiores de A y B;
!>          = 'L':  Se almacenan las bandas inferiores de A y B.
!>

N

!>          N es INTEGER
!>          El orden de las matrices A y B.  N >= 0.
!>

KA

!>          KA es INTEGER
!>          El número de superdiagonales de la matriz A si UPLO = 'U',
!>          o el número de subdiagonales si UPLO = 'L'. KA >= 0.
!>

KB

!>          KB es INTEGER
!>          El número de superdiagonales de la matriz B si UPLO = 'U',
!>          o el número de subdiagonales si UPLO = 'L'. KB >= 0.
!>

AB

!>          AB es un array COMPLEX*16, dimensión (LDAB, N)
!>          En la entrada, la banda superior o inferior de la matriz Hermítica
!>          con banda A, almacenada en las primeras ka+1 filas de la matriz. La
!>          columna j de A se almacena en la columna j de la matriz AB
!>          de la siguiente manera:
!>          si UPLO = 'U', AB(ka+1+i-j,j) = A(i,j) para max(1,j-ka)<=i<=j;
!>          si UPLO = 'L', AB(1+i-j,j)    = A(i,j) para j<=i<=min(n,j+ka).
!>
!>          En la salida, el contenido de AB se destruye.
!>

LDAB

!>          LDAB es INTEGER
!>          La dimensión principal de la matriz AB.  LDAB >= KA+1.
!>

BB

!>          BB es un array COMPLEX*16, dimensión (LDBB, N)
!>          En la entrada, la banda superior o inferior de la matriz Hermítica
!>          con banda B, almacenada en las primeras kb+1 filas de la matriz. La
!>          columna j de B se almacena en la columna j de la matriz BB
!>          de la siguiente manera:
!>          si UPLO = 'U', BB(kb+1+i-j,j) = B(i,j) para max(1,j-kb)<=i<=j;
!>          si UPLO = 'L', BB(1+i-j,j)    = B(i,j) para j<=i<=min(n,j+kb).
!>
!>          En la salida, el factor S de la factorización de Cholesky dividida
!>          B = S**H*S, tal como devuelve ZPBSTF.
!>

LDBB

!>          LDBB es INTEGER
!>          La dimensión principal de la matriz BB.  LDBB >= KB+1.
!>

Q

!>          Q es un array COMPLEX*16, dimensión (LDQ, N)
!>          Si JOBZ = 'V', la matriz n x n utilizada en la reducción de
!>          A*x = (lambda)*B*x a la forma estándar, es decir, C*x = (lambda)*x,
!>          y consecuentemente C a forma tridiagonal.
!>          Si JOBZ = 'N', la matriz Q no se utiliza.
!>

LDQ

!>          LDQ es INTEGER
!>          La dimensión principal de la matriz Q. Si JOBZ = 'N',
!>          LDQ >= 1. Si JOBZ = 'V', LDQ >= max(1,N).
!>

VL

!>          VL es DOUBLE PRECISION
!>
!>          Si RANGE='V', el límite inferior del intervalo a
!>          buscar para los valores propios. VL < VU.
!>          No se utiliza si RANGE = 'A' o 'I'.
!>

VU

!>          VU es DOUBLE PRECISION
!>
!>          Si RANGE='V', el límite superior del intervalo a
!>          buscar para los valores propios. VL < VU.
!>          No se utiliza si RANGE = 'A' o 'I'.
!>

IL

!>          IL es INTEGER
!>
!>          Si RANGE='I', el índice del
!>          valor propio más pequeño a devolver.
!>          1 <= IL <= IU <= N, si N > 0; IL = 1 y IU = 0 si N = 0.
!>          No se utiliza si RANGE = 'A' o 'V'.
!>

IU

!>          IU es INTEGER
!>
!>          Si RANGE='I', el índice del
!>          valor propio más grande a devolver.
!>          1 <= IL <= IU <= N, si N > 0; IL = 1 y IU = 0 si N = 0.
!>          No se utiliza si RANGE = 'A' o 'V'.
!>

ABSTOL

!>          ABSTOL es DOUBLE PRECISION
!>          La tolerancia de error absoluta para los valores propios.
!>          Un valor propio aproximado se acepta como convergido
!>          cuando se determina que se encuentra en un intervalo [a,b]
!>          de anchura menor o igual a
!>
!>                  ABSTOL + EPS *   max( |a|,|b| ) ,
!>
!>          donde EPS es la precisión de la máquina. Si ABSTOL es menor o
!>          igual a cero, entonces se utilizará EPS*|T| en su lugar,
!>          donde |T| es la norma 1 de la matriz tridiagonal obtenida
!>          al reducir AP a forma tridiagonal.
!>
!>          Los valores propios se calcularán con mayor precisión cuando ABSTOL
!>          se establezca en el doble del umbral de subdesbordamiento 2*DLAMCH('S'), no cero.
!>          Si esta rutina retorna con INFO>0, indicando que algunos
!>          vectores propios no convergieron, intente establecer ABSTOL en
!>          2*DLAMCH('S').
!>

M

!>          M es INTEGER
!>          El número total de valores propios encontrados.  0 <= M <= N.
!>          Si RANGE = 'A', M = N, y si RANGE = 'I', M = IU-IL+1.
!>

W

!>          W es un array DOUBLE PRECISION, dimensión (N)
!>          Si INFO = 0, los valores propios en orden ascendente.
!>

Z

!>          Z es un array COMPLEX*16, dimensión (LDZ, N)
!>          Si JOBZ = 'V', entonces si INFO = 0, Z contiene la matriz Z de
!>          vectores propios, con la columna i de Z conteniendo el
!>          vector propio asociado a W(i). Los vectores propios
!>          se normalizan de modo que Z**H*B*Z = I.
!>          Si JOBZ = 'N', entonces Z no se utiliza.
!>

LDZ

!>          LDZ es INTEGER
!>          La dimensión principal de la matriz Z.  LDZ >= 1, y si
!>          JOBZ = 'V', LDZ >= N.
!>

Function/Subroutine Documentation

JOBZ 

CHARACTER*1 JOBZ

          Specifies whether to compute the eigenvectors:
          = 'N': Compute only the eigenvalues of the symmetric or
          Hermitian generalized eigenvalue problem A*x = lambda*B*x.
          = 'V': Compute the eigenvalues and eigenvectors of the
          symmetric or Hermitian generalized eigenvalue problem.
          = 'V': Compute the eigenvalues and eigenvectors of the
          symmetric or Hermitian generalized eigenvalue problem.

RANGE 

CHARACTER*1 RANGE
          Specifies whether to compute all eigenvalues, or a range of
          eigenvalues:
          = 'A': all eigenvalues will be found.
          = 'V': all eigenvalues will be found in the interval (VL, VU).
          = 'I': the IL-th to the IU-th eigenvalues will be found.

UPLO 

CHARACTER*1 UPLO
          Specifies whether A and B are upper or lower triangular:
          = 'U': Upper triangle of A and B are stored.
          = 'L': Lower triangle of A and B are stored.

N 

INTEGER N
          The order of the matrices A and B. N >= 0.

VL 

DOUBLE PRECISION VL
          If RANGE='V', the lower bound of the eigenvalue interval.

VU 

DOUBLE PRECISION VU
          If RANGE='V', the upper bound of the eigenvalue interval.

IL 

INTEGER IL
          If RANGE='I', the index of the smallest eigenvalue to be
          returned.

IU 

INTEGER IU
          If RANGE='I', the index of the largest eigenvalue to be
          returned.

ABSTOL 

DOUBLE PRECISION ABSTOL
          The tolerance for the convergence test.  The routine will exit
          the iterative loop if the confidence interval for the eigenvalue
          is less than or equal to ABSTOL.

M 

INTEGER M
          The total number of eigenvalues found. If RANGE='A', M = N. If
          RANGE='V' or RANGE='I', M < N.

W 

DOUBLE PRECISION W( N )
          The array containing the eigenvalues in ascending order.
          If RANGE='A', W(1:N) contains all eigenvalues.

Z 

COMPLEX*16 Z( LDZ, * )
          If JOBZ = 'V', then Z contains the eigenvectors of the
          generalized eigenvalue problem A*x = lambda*B*x corresponding to
          the eigenvalues in W. The eigenvectors are normalized so that the
          imaginary part is zero and the real part is squared sum to 1.

LDZ 

INTEGER LDZ
          The leading dimension of the array Z.

V 

COMPLEX*16 V( LDV, * )
          If JOBZ = 'V', then V contains the eigenvectors of the
          generalized eigenvalue problem A*x = lambda*B*x corresponding to
          the eigenvalues in W.

LDV 

INTEGER LDV
          The leading dimension of the array V.

WORK 

COMPLEX*16 WORK( * )
          Double precision work space. The dimension of WORK is at least
          max(2*N, LWORK)

RWORK 

DOUBLE PRECISION RWORK( * )
          Double precision work space. The dimension of RWORK is at least
          7*N.

IWORK 

INTEGER IWORK( * )
          Integer work space. The dimension of IWORK is at least 5*N.

IFAIL 

INTEGER IFAIL( N )
          If JOBZ = 'V', then if INFO = 0, the first M elements of
          IFAIL are zero.  If INFO > 0, then IFAIL contains the
          indices of the eigenvectors that failed to converge.
          If JOBZ = 'N', then IFAIL is not referenced.

INFO 

INTEGER INFO
          = 0:  successful exit
          < 0:  if INFO = -i, the i-th argument had an illegal value
          > 0:  if INFO = i, and i is:
             <= N:  then i eigenvectors failed to converge.  Their
                    indices are stored in array IFAIL.
             > N:   if INFO = N + i, for 1 <= i <= N, then ZPBSTF
                    returned INFO = i: B is not positive definite.
                    The factorization of B could not be completed and
                    no eigenvalues or eigenvectors were computed.
