DOCUMENTACIÓN DE LA FUNCIÓN/SUBRUTINA

subroutine zhetrd_he2hb (character uplo, integer n, integer kd, complex*16, dimension( lda, * ) a, integer lda, complex*16, dimension( ldab, * ) ab, integer ldab, complex*16, dimension( * ) tau, complex*16, dimension( * ) work, integer lwork, integer info)

ZHETRD_HE2HB

Propósito:

!>
!> ZHETRD_HE2HB reduce una matriz Hermitiana compleja A a una forma de banda Hermitiana
!> diagonal AB mediante una transformación unitaria de semejanza:
!> Q**H * A * Q = AB.
!>

Parámetros

UPLO 
!>          UPLO es CHARACTER*1
!>          = 'U':  El triángulo superior de A está almacenado;
!>          = 'L':  El triángulo inferior de A está almacenado.
!>

N

!>          N es INTEGER
!>          El orden de la matriz A.  N >= 0.
!>

KD

!>          KD es INTEGER
!>          El número de superdiagonales de la matriz reducida si UPLO = 'U',
!>          o el número de subdiagonales si UPLO = 'L'.  KD >= 0.
!>          La matriz reducida se almacena en el array AB.
!>

A

!>          A es un array COMPLEX*16, dimensión (LDA,N)
!>          En la entrada, la matriz Hermitiana A.  Si UPLO = 'U', la parte
!>          superior triangular N-por-N líder contiene la parte superior
!>          triangular de la matriz A, y la parte triangular estrictamente inferior
!>          de A no se referencia. Si UPLO = 'L', la parte inferior
!>          triangular N-por-N líder contiene la parte inferior
!>          triangular de la matriz A, y la parte triangular estrictamente superior
!>          de A no se referencia.
!>          En la salida, si UPLO = 'U', la diagonal y la superdiagonal principal
!>          de A se sobrescriben con los elementos correspondientes de la
!>          matriz tridiagonal T, y los elementos por encima de la superdiagonal
!>          principal, junto con el array TAU, representan la matriz unitaria
!>          Q como un producto de reflectores elementales; si UPLO
!>          = 'L', la diagonal y la subdiagonal principal de A se
!>          sobrescriben con los elementos correspondientes de la
!>          matriz tridiagonal T, y los elementos por debajo de la subdiagonal
!>          principal, junto con el array TAU, representan la matriz unitaria
!>          Q como un producto de reflectores elementales. Ver Detalles Adicionales.
!>

LDA

!>          LDA es INTEGER
!>          La dimensión líder del array A.  LDA >= max(1,N).
!>

AB

!>          AB es un array COMPLEX*16, dimensión (LDAB,N)
!>          En la salida, el triángulo superior o inferior de la matriz de banda
!>          Hermitiana A, almacenado en las primeras KD+1 filas del array.
!>          La j-ésima columna de A se almacena en la j-ésima columna del array AB
!>          de la siguiente manera:
!>          si UPLO = 'U', AB(kd+1+i-j,j) = A(i,j) para max(1,j-kd)<=i<=j;
!>          si UPLO = 'L', AB(1+i-j,j)    = A(i,j) para j<=i<=min(n,j+kd).
!>

LDAB

!>          LDAB es INTEGER
!>          La dimensión líder del array AB.  LDAB >= KD+1.
!>

TAU

!>          TAU es un array COMPLEX*16, dimensión (N-KD)
!>          Los factores escalares de los reflectores elementales (ver Detalles
!>          Adicionales).
!>

WORK

!>          WORK es un array COMPLEX*16, dimensión (MAX(1,LWORK))
!>          En la salida, si INFO = 0, o si LWORK = -1,
!>          WORK(1) devuelve el tamaño de LWORK.
!>

LWORK

!>          LWORK es INTEGER
!>          La dimensión del array WORK que debe calcularse
!>          mediante una consulta de espacio de trabajo.
!>          Si N <= KD+1, LWORK >= 1, de lo contrario LWORK = MAX(1, LWORK_QUERY).
!>
!>          Si LWORK = -1, se asume una consulta de espacio de trabajo; la rutina
!>          solo calcula el tamaño óptimo del array WORK, devuelve
!>          este valor como la primera entrada del array WORK, y no se emite
!>          ningún mensaje de error relacionado con LWORK por XERBLA.
!>          LWORK_QUERY = N*KD + N*max(KD,FACTOPTNB) + 2*KD*KD
!>          donde FACTOPTNB es el bloqueo utilizado por el algoritmo QR o LQ,
!>          generalmente FACTOPTNB=128 es una buena opción; de lo contrario,
!>          poner LWORK=-1 proporcionará el tamaño de WORK.
!>

INFO

!>          INFO es INTEGER
!>          = 0:  salida exitosa
!>          < 0:  si INFO = -i, el i-ésimo argumento tuvo un valor ilegal
!>

!>  Si UPLO = 'U', la matriz Q se representa como un producto de reflectores
!>  elementales
!>
!>     Q = H(k)**H . . . H(2)**H H(1)**H, donde k = n-kd.
!>
!>  Cada H(i) tiene la forma
!>
!>     H(i) = I - tau * v * v**H
!>
!>  donde tau es un escalar complejo, y v es un vector complejo con
!>  v(1:i+kd-1) = 0 y v(i+kd) = 1; conjg(v(i+kd+1:n)) se almacena en la salida en
!>  A(i,i+kd+1:n), y tau en TAU(i).
!>
!>  Si UPLO = 'L', la matriz Q se representa como un producto de reflectores
!>  elementales
!>
!>     Q = H(1) H(2) . . . H(k), donde k = n-kd.
!>
!>  Cada H(i) tiene la forma
!>
!>     H(i) = I - tau * v * v**H
!>
!>  donde tau es un escalar complejo, y v es un vector complejo con
!>  v(kd+1:i) = 0 y v(i+kd+1) = 1; v(i+kd+2:n) se almacena en la salida en
!>  A(i+kd+2:n,i), y tau en TAU(i).
!>
!>  El contenido de A en la salida se ilustra con los siguientes ejemplos
!>  con n = 5:
!>
!>  si UPLO = 'U':                       si UPLO = 'L':
!>
!>    (  ab  ab/v1  v1      v1     v1    )              (  ab                            )
!>    (      ab     ab/v2   v2     v2    )              (  ab/v1  ab                     )
!>    (             ab      ab/v3  v3    )              (  v1     ab/v2  ab              )
!>    (                     ab     ab/v4 )              (  v1     v2     ab/v3  ab       )
!>    (                            ab    )              (  v1     v2     v3     ab/v4 ab )
!>
!>  donde d y e denotan elementos diagonales y fuera de la diagonal de T, y vi
!>  denota un elemento del vector que define H(i).

NAME

                    
zhetrd_he2hb - computes the spectral ordering of a complex Hermitian matrix.

                


                

                    
SYNOPSIS

                    
This subroutine is called by ZHEEVX to compute the spectral ordering of a complex Hermitian matrix.

                


                

                    
Function/Subroutine Documentation

                    
Routine: ZHETRD_HE2HB

                    
Purpose:

                    
ZHETRD_HE2HB computes the spectral ordering of a complex Hermitian matrix.

                    
Description:

                    
This subroutine is part of the LAPACK library, specifically designed for complex Hermitian matrices. It rearranges the eigenvalues and eigenvectors in ascending order, which is a common requirement for various numerical algorithms.

                    
Arguments:

                    
    
                        
  • UPLO (CHARACTER*1) - Specifies whether the matrix is upper or lower triangular.
    • 
                        
  • A (COMPLEX*16), dimension (LDA, N) - The input matrix.
    • 
                        
  • LDA (INTEGER) - Leading dimension of the array A.
    • 
                        
  • TAU (COMPLEX*16), dimension (N-1) - The auxiliary array storing the scalar factors of the elementary reflectors.
    • 
                        
  • WORK (COMPLEX*16), dimension (N) - Workspace array.
    • 
                        
  • INFO (INTEGER) - Output flag: 0 for success, < 0 for error.
    • 
                    

                    
Details:

                    
The subroutine uses a sequence of elementary transformations to reduce the matrix to tridiagonal form, then sorts the eigenvalues and applies the corresponding transformations to the eigenvectors.

                    
See Also:

                    
ZHEEVX, ZHEGV, ZHETRD.
