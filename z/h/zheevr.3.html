ZHEEVR calcula los valores propios y, opcionalmente, los vectores propios izquierdos y/o derechos para matrices HE

Propósito:

!>
!> ZHEEVR calcula valores propios seleccionados y, opcionalmente, vectores propios
!> de una matriz Hermitiana compleja A. Los valores y vectores propios se pueden
!> seleccionar especificando un rango de valores o un rango de índices
!> para los valores propios deseados. Las invocaciones con diferentes opciones para
!> estos parámetros pueden resultar en el cálculo de valores y/o vectores propios ligeramente diferentes
!> para la misma matriz. La razón de
!> este comportamiento es que existe una variedad de algoritmos (cada uno
!> funcionando mejor para un conjunto particular de opciones) y ZHEEVR
!> intenta seleccionar el mejor basándose en los diversos parámetros. En todos
!> los casos, los valores calculados son precisos dentro de los límites de la aritmética de precisión finita.
!>
!> ZHEEVR primero reduce la matriz A a la forma tridiagonal T con una llamada
!> a ZHETRD. Luego, siempre que sea posible, ZHEEVR llama a ZSTEMR para calcular
!> el espectro de valores propios utilizando Representaciones Relativamente Robustas.
!> ZSTEMR calcula los valores propios mediante el algoritmo dqds, mientras que los vectores propios ortogonales
!> se calculan a partir de varias representaciones L D L^T
!> (también conocidas como Representaciones Relativamente Robustas). La
!> ortogonalización de Gram-Schmidt se evita en la medida de lo posible. Más específicamente,
!> los diversos pasos del algoritmo son los siguientes.
!>
!> Para cada bloque no reducido (submatriz) de T,
!>    (a) Calcula T - sigma I = L D L^T, de modo que L y D
!>        definen todos los valores propios deseados con alta precisión relativa.
!>        Esto significa que pequeños cambios relativos en las entradas de D y L
!>        causan solo pequeños cambios relativos en los valores y
!>        vectores propios. La representación estándar (no factorizada) de la
!>        matriz tridiagonal T no tiene esta propiedad en general.
!>    (b) Calcula los valores propios con la precisión adecuada.
!>        Si se desean los vectores propios, el algoritmo alcanza la precisión total
!>        de los valores propios calculados solo justo antes
!>        de que los vectores correspondientes deban calcularse, ver pasos c) y d).
!>    (c) Para cada grupo de valores propios cercanos, selecciona un nuevo
!>        desplazamiento cercano al grupo, encuentra una nueva factorización y refina
!>        los valores propios desplazados a la precisión adecuada.
!>    (d) Para cada valor propio con una separación relativa suficientemente grande, calcula
!>        el vector propio correspondiente formando una factorización retorcida que revela el rango. Vuelve a (c) para cualquier grupo que quede.
!>
!> La precisión deseada de la salida se puede especificar mediante el parámetro de entrada
!> ABSTOL.
!>
!> Para más detalles, véase la documentación de ZSTEMR y:
!> - Inderjit S. Dhillon y Beresford N. Parlett: 
!>   Linear Algebra and its Applications, 387(1), pp. 1-28, agosto de 2004.
!> - Inderjit Dhillon y Beresford Parlett:  SIAM Journal on Matrix Analysis and Applications, Vol. 25,
!>   2004.  También Nota de trabajo de LAPACK 154.
!> - Inderjit Dhillon: ,
!>   Informe Técnico de la División de Ciencias de la Computación No. UCB/CSD-97-971,
!>   UC Berkeley, mayo de 1997.
!>
!>
!> Nota 1: ZHEEVR llama a ZSTEMR cuando se solicita el espectro completo
!> en máquinas que cumplen el estándar de punto flotante ieee-754.
!> ZHEEVR llama a DSTEBZ y ZSTEIN en máquinas no ieee y
!> cuando se realizan solicitudes de espectro parcial.
!>
!> La ejecución normal de ZSTEMR puede crear NaNs e infinitos y
!> por lo tanto, puede abortar debido a una excepción de punto flotante en entornos
!> que no manejan NaNs e infinitos de la manera predeterminada estándar ieee.
!>

Parámetros

JOBZ 
!>          JOBZ es CHARACTER*1
!>          = 'N':  Calcula solo los valores propios;
!>          = 'V':  Calcula los valores propios y los vectores propios.
!>
!>          Este parámetro influye en la elección del algoritmo y
!>          puede alterar los valores calculados.
!>

RANGE

!>          RANGE es CHARACTER*1
!>          = 'A': se encontrarán todos los valores propios.
!>          = 'V': se encontrarán todos los valores propios en el intervalo semiabierto (VL,VU]
!>                 que se buscarán.
!>          = 'I': se encontrarán los valores propios del IL-ésimo al IU-ésimo.
!>          Para RANGE = 'V' o 'I' y IU - IL < N - 1, se llaman DSTEBZ y
!>          ZSTEIN.
!>
!>          Este parámetro influye en la elección del algoritmo y
!>          puede alterar los valores calculados.
!>

UPLO

!>          UPLO es CHARACTER*1
!>          = 'U':  El triángulo superior de A está almacenado;
!>          = 'L':  El triángulo inferior de A está almacenado.
!>

N

!>          N es INTEGER
!>          El orden de la matriz A.  N >= 0.
!>

A

!>          A es una matriz COMPLEX*16, dimensión (LDA, N)
!>          En la entrada, la matriz Hermitiana A.  Si UPLO = 'U', la
!>          parte triangular superior N por N líder contiene la
!>          parte triangular superior de la matriz A.  Si UPLO = 'L',
!>          la parte triangular inferior N por N líder contiene
!>          la parte triangular inferior de la matriz A.
!>          En la salida, el triángulo inferior (si UPLO='L') o el triángulo
!>          superior (si UPLO='U') de A, incluyendo la diagonal, se
!>          destruye.
!>

LDA

!>          LDA es INTEGER
!>          La dimensión líder del array A.  LDA >= max(1,N).
!>

VL

!>          VL es DOUBLE PRECISION
!>          Si RANGE='V', el límite inferior del intervalo a
!>          buscar para los valores propios. VL < VU.
!>          No se hace referencia si RANGE = 'A' o 'I'.
!>

VU

!>          VU es DOUBLE PRECISION
!>          Si RANGE='V', el límite superior del intervalo a
!>          buscar para los valores propios. VL < VU.
!>          No se hace referencia si RANGE = 'A' o 'I'.
!>

IL

!>          IL es INTEGER
!>          Si RANGE='I', el índice del
!>          valor propio más pequeño a devolver.
!>          1 <= IL <= IU <= N, si N > 0; IL = 1 y IU = 0 si N = 0.
!>          No se hace referencia si RANGE = 'A' o 'V'.
!>

IU

!>          IU es INTEGER
!>          Si RANGE='I', el índice del
!>          valor propio más grande a devolver.
!>          1 <= IL <= IU <= N, si N > 0; IL = 1 y IU = 0 si N = 0.
!>          No se hace referencia si RANGE = 'A' o 'V'.
!>

ABSTOL

!>          ABSTOL es DOUBLE PRECISION
!>          La tolerancia de error absoluto para los valores propios.
!>          Un valor propio aproximado se acepta como convergente
!>          cuando se determina que se encuentra en un intervalo [a,b]
!>          de ancho menor o igual que
!>
!>                  ABSTOL + EPS *   max( |a|,|b| ) ,
!>
!>          donde EPS es

M

M es ENTERO
El número total de valores propios encontrados. 0 <= M <= N.
Si RANGE = 'A', M = N, y si RANGE = 'I', M = IU-IL+1.

W

W es un array de DOBLE PRECISIÓN, dimensión (N)
Los primeros M elementos contienen los valores propios seleccionados en orden ascendente.

Z

Z es un array COMPLEX*16, dimensión (LDZ, max(1,M))
Si JOBZ = 'V', entonces si INFO = 0, las primeras M columnas de Z contienen los vectores propios ortonormales de la matriz A correspondientes a los valores propios seleccionados, con la i-ésima columna de Z conteniendo el vector propio asociado a W(i).
Si JOBZ = 'N', entonces Z no se referencia.
Nota: el usuario debe asegurarse de que se suministran al menos max(1,M) columnas en el array Z; si RANGE = 'V', el valor exacto de M no se conoce de antemano y se debe usar un límite superior.
Suministrar N columnas es siempre seguro.

LDZ

LDZ es ENTERO
La dimensión principal del array Z. LDZ >= 1, y si
JOBZ = 'V', LDZ >= max(1,N).

ISUPPZ

ISUPPZ es un array ENTERO, dimensión ( 2*max(1,M) )
El soporte de los vectores propios en Z, es decir, los índices
que indican los elementos distintos de cero en Z. El i-ésimo vector propio
es distinto de cero solo en los elementos ISUPPZ( 2*i-1 ) hasta
ISUPPZ( 2*i ). Esto es una salida de ZSTEMR (matriz tridiagonal).
El soporte de los vectores propios de A es típicamente
1:N debido a las transformaciones unitarias aplicadas por ZUNMTR.
Implementado solo para RANGE = 'A' o 'I' y IU - IL = N - 1

WORK

WORK es un array COMPLEX*16, dimensión (MAX(1,LWORK))
A la salida, si INFO = 0, WORK(1) devuelve el LWORK óptimo.

LWORK

LWORK es ENTERO
La longitud del array WORK.
Si N <= 1, LWORK >= 1, de lo contrario LWORK >= 2*N.
Para una eficiencia óptima, LWORK >= (NB+1)*N,
donde NB es el máximo del tamaño de bloque para ZHETRD y para
ZUNMTR devuelto por ILAENV.

Si LWORK = -1, entonces se asume una consulta de espacio de trabajo; la rutina
solo calcula los tamaños óptimos de los arrays WORK, RWORK y
IWORK, devuelve estos valores como las primeras entradas de
los arrays WORK, RWORK e IWORK, y XERBLA no emite ningún mensaje de error
relacionado con LWORK o LRWORK o LIWORK.

RWORK

RWORK es un array de DOBLE PRECISIÓN, dimensión (MAX(1,LRWORK))
A la salida, si INFO = 0, RWORK(1) devuelve el LRWORK óptimo
(y mínimo).

LRWORK

LRWORK es ENTERO
La longitud del array RWORK.
Si N <= 1, LRWORK >= 1, de lo contrario LRWORK >= 24*N.

Si LRWORK = -1, entonces se asume una consulta de espacio de trabajo; la
rutina solo calcula los tamaños óptimos de los arrays WORK, RWORK
e IWORK, devuelve estos valores como las primeras entradas de
los arrays WORK, RWORK e IWORK, y XERBLA no emite ningún mensaje de error
relacionado con LWORK o LRWORK o LIWORK.

IWORK

IWORK es un array ENTERO, dimensión (MAX(1,LIWORK))
A la salida, si INFO = 0, IWORK(1) devuelve el LIWORK óptimo
(y mínimo).

LIWORK

LIWORK es ENTERO
La dimensión del array IWORK.
Si N <= 1, LIWORK >= 1, de lo contrario LIWORK >= 10*N.

Si LIWORK = -1, entonces se asume una consulta de espacio de trabajo; la
rutina solo calcula los tamaños óptimos de los arrays WORK, RWORK
e IWORK, devuelve estos valores como las primeras entradas de
los arrays WORK, RWORK e IWORK, y XERBLA no emite ningún mensaje de error
relacionado con LWORK o LRWORK o LIWORK.

INFO

INFO es ENTERO
= 0: salida exitosa
< 0: si INFO = -i, el i-ésimo argumento tenía un valor ilegal
> 0: Error interno
