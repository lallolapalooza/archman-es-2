Documentación de la función/subrutina

subroutine zhetrf (character uplo, integer n, complex*16, dimension( lda, * ) a, integer lda, integer, dimension( * ) ipiv, complex*16, dimension( * ) work, integer lwork, integer info)

ZHETRF

Propósito:

!>
!> ZHETRF calcula la factorización de una matriz Hermitiana compleja A
!> utilizando el método de pivoteo diagonal de Bunch-Kaufman. La forma de la
!> factorización es
!>
!>    A = U*D*U**H  o  A = L*D*L**H
!>
!> donde U (o L) es un producto de matrices de permutación y triangulares unitarias superiores (inferiores), y D es Hermitiana y diagonal por bloques con
!> bloques diagonales de 1x1 y 2x2.
!>
!> Esta es la versión bloqueada del algoritmo, que llama a BLAS de Nivel 3.
!>

Parámetros

UPLO 
!>          UPLO es CHARACTER*1
!>          = 'U':  El triángulo superior de A está almacenado;
!>          = 'L':  El triángulo inferior de A está almacenado.
!>

N

!>          N es INTEGER
!>          El orden de la matriz A.  N >= 0.
!>

A

!>          A es un array COMPLEX*16, de dimensión (LDA,N)
!>          En la entrada, la matriz Hermitiana A.  Si UPLO = 'U', la parte
!>          triangular superior N×N principal de A contiene la parte
!>          triangular superior de la matriz A, y la parte estrictamente triangular inferior
!>          de A no se referencia. Si UPLO = 'L', la parte
!>          triangular inferior N×N principal de A contiene la parte
!>          triangular inferior de la matriz A, y la parte estrictamente triangular superior
!>          de A no se referencia.
!>
!>          En la salida, la matriz diagonal por bloques D y los multiplicadores utilizados
!>          para obtener el factor U o L (ver más abajo para más detalles).
!>

LDA

!>          LDA es INTEGER
!>          La dimensión principal del array A.  LDA >= max(1,N).
!>

IPIV

!>          IPIV es un array INTEGER, de dimensión (N)
!>          Detalles de los intercambios y la estructura de bloques de D.
!>          Si IPIV(k) > 0, entonces las filas y columnas k e IPIV(k) fueron
!>          intercambiadas y D(k,k) es un bloque diagonal de 1x1.
!>          Si UPLO = 'U' e IPIV(k) = IPIV(k-1) < 0, entonces las filas y
!>          columnas k-1 e -IPIV(k) fueron intercambiadas y D(k-1:k,k-1:k)
!>          es un bloque diagonal de 2x2. Si UPLO = 'L' e IPIV(k) =
!>          IPIV(k+1) < 0, entonces las filas y
!>          columnas k+1 e -IPIV(k) fueron intercambiadas y D(k:k+1,k:k+1)
!>          es un bloque diagonal de 2x2.
!>

WORK

!>          WORK es un array COMPLEX*16, de dimensión (MAX(1,LWORK))
!>          En la salida, si INFO = 0, WORK(1) devuelve el LWORK óptimo.
!>

LWORK

!>          LWORK es INTEGER
!>          La longitud de WORK. LWORK >= 1. Para un rendimiento óptimo
!>          LWORK >= N*NB, donde NB es el tamaño del bloque devuelto por ILAENV.
!>

INFO

!>          INFO es INTEGER
!>          = 0:  salida exitosa
!>          < 0:  si INFO = -i, el i-ésimo argumento tuvo un valor ilegal
!>          > 0:  si INFO = i, D(i,i) es exactamente cero.  La factorización
!>                se ha completado, pero la matriz diagonal por bloques D es
!>                exactamente singular, y ocurrirá una división por cero si
!>                se utiliza para resolver un sistema de ecuaciones.
!>

Más detalles:

!>
!>  Si UPLO = 'U', entonces A = U*D*U**H, donde
!>     U = P(n)*U(n)* ... *P(k)U(k)* ...,
!>  es decir, U es un producto de términos P(k)*U(k), donde k disminuye de n a
!>  1 en pasos de 1 o 2, y D es una matriz diagonal por bloques con bloques
!>  diagonales de 1x1 y 2x2 D(k).  P(k) es una matriz de permutación como
!>  se define por IPIV(k), y U(k) es una matriz triangular unitaria superior, tal
!>  que si el bloque diagonal D(k) es de orden s (s = 1 o 2), entonces
!>
!>             (   I    v    0   )   k-s
!>     U(k) =  (   0    I    0   )   s
!>             (   0    0    I   )   n-k
!>                k-s   s   n-k
!>
!>  Si s = 1, D(k) sobrescribe A(k,k), y v sobrescribe A(1:k-1,k).
!>  Si s = 2, el triángulo superior de D(k) sobrescribe A(k-1,k-1), A(k-1,k),
!>  y A(k,k), y v sobrescribe A(1:k-2,k-1:k).
!>
!>  Si UPLO = 'L', entonces A = L*D*L**H, donde
!>     L = P(1)*L(1)* ... *P(k)*L(k)* ...,
!>  es decir, L es un producto de términos P(k)*L(k), donde k aumenta de 1 a
!>  n en pasos de 1 o 2, y D es una matriz diagonal por bloques con bloques
!>  diagonales de 1x1 y 2x2 D(k).  P(k) es una matriz de permutación como
!>  se define por IPIV(k), y L(k) es una matriz triangular unitaria inferior, tal
!>  que si el bloque diagonal D(k) es de orden s (s = 1 o 2), entonces
!>
!>             (   I    0     0   )  k-1
!>     L(k) =  (   0    I     0   )  s
!>             (   0    v     I   )  n-k-s+1
!>                k-1   s  n-k-s+1
!>
!>  Si s = 1, D(k) sobrescribe A(k,k), y v sobrescribe A(k+1:n,k).
!>  Si s = 2, el triángulo inferior de D(k) sobrescribe A(k,k), A(k+1,k),
!>  y A(k+1,k+1), y v sobrescribe A(k+2:n,k:k+1).
!>
