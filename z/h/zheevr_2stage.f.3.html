subroutine zheevr_2stage (character jobz, character range, character uplo, integer n, complex*16, dimension( lda, * ) a, integer lda, double precision vl, double precision vu, integer il, integer iu, double precision abstol, integer m, double precision, dimension( * ) w, complex*16, dimension( ldz, * ) z, integer ldz, integer, dimension( * ) isuppz, complex*16, dimension( * ) work, integer lwork, double precision, dimension( * ) rwork, integer lrwork, integer, dimension( * ) iwork, integer liwork, integer info)

ZHEEVR_2STAGE calcula los valores propios y, opcionalmente, los vectores propios izquierdos y/o derechos para matrices HERMITIANAS

Propósito:

!>
!> ZHEEVR_2STAGE calcula valores propios seleccionados y, opcionalmente, vectores
!> propios de una matriz hermítica A utilizando la técnica de 2 etapas para
!> la reducción a tridiagonal. Los valores y vectores propios pueden
!> ser seleccionados especificando un rango de valores o un rango de
!> índices para los valores propios deseados.
!>
!> ZHEEVR_2STAGE primero reduce la matriz A a la forma tridiagonal T con una llamada
!> a ZHETRD. Luego, siempre que sea posible, ZHEEVR_2STAGE llama a ZSTEMR para calcular
!> el espectro de valores propios utilizando Representaciones Relativamente Robustas.
!> ZSTEMR calcula los valores propios mediante el algoritmo dqds, mientras que los vectores
!> propios ortogonales se calculan a partir de varias representaciones L D L^T
!> (también conocidas como Representaciones Relativamente Robustas). La ortogonalización
!> de Gram-Schmidt se evita tanto como sea posible. Más específicamente,
!> los diversos pasos del algoritmo son los siguientes:
!>
!> Para cada bloque no reducido (submatriz) de T,
!>    (a) Calcular T - sigma I = L D L^T, de modo que L y D
!>        definan todos los valores propios deseados con alta precisión relativa.
!>        Esto significa que pequeños cambios relativos en las entradas de D y L
!>        causan solo pequeños cambios relativos en los valores y
!>        vectores propios. La representación estándar (no factorizada) de la
!>        matriz tridiagonal T no tiene esta propiedad en general.
!>    (b) Calcular los valores propios con la precisión adecuada.
!>        Si se desean los vectores propios, el algoritmo alcanza la precisión completa
!>        de los valores propios calculados solo justo antes de
!>        que se deban calcular los vectores correspondientes, consulte los pasos c) y d).
!>    (c) Para cada clúster de valores propios cercanos, seleccionar un nuevo
!>        desplazamiento cercano al clúster, encontrar una nueva factorización y refinar
!>        los valores propios desplazados a la precisión adecuada.
!>    (d) Para cada valor propio con una separación relativa suficientemente grande, calcular
!>        el vector propio correspondiente formando una factorización retorcida que revele el rango.
!>        Volver a (c) para cualquier clúster que permanezca.
!>
!> La precisión deseada de la salida se puede especificar mediante el parámetro de entrada
!> ABSTOL.
!>
!> Para más detalles, consulte la documentación de ZSTEMR y:
!> - Inderjit S. Dhillon y Beresford N. Parlett: 
!>   Linear Algebra and its Applications, 387(1), pp. 1-28, agosto de 2004.
!> - Inderjit Dhillon y Beresford Parlett:  SIAM Journal on Matrix Analysis and Applications, Vol. 25,
!>   2004. También LAPACK Working Note 154.
!> - Inderjit Dhillon: ,
!>   Computer Science Division Technical Report No. UCB/CSD-97-971,
!>   UC Berkeley, mayo de 1997.
!>
!>
!> Nota 1: ZHEEVR_2STAGE llama a ZSTEMR cuando se solicita el espectro completo
!> en máquinas que cumplen con el estándar de punto flotante ieee-754.
!> ZHEEVR_2STAGE llama a DSTEBZ y ZSTEIN en máquinas no ieee y
!> cuando se realizan solicitudes de espectro parcial.
!>
!> La ejecución normal de ZSTEMR puede crear NaNs e infinitos y
!> por lo tanto, puede abortar debido a una excepción de punto flotante en entornos
!> que no manejan NaNs e infinitos de la manera predeterminada estándar de ieee.
!>

!>          los valores propios se calculen con alta r

Workspace query

Para obtener el tamaño mínimo requerido de LWORK, LRWORK y LIWORK, establezca cada uno de ellos en -1.0D0 y ejecute ZHEEVR_2STAGE. La longitud requerida se devolverá en el array WORK, en la primera posición del mismo. Por ejemplo:

CALL ZHEEVR_2STAGE(JOBZ,RANGE,UPLO,N,A,LDA,VL,VU,IL,IU,ABSTOL,M,W,Z,LDZ,ISUPPZ,
                    WORK,-1.0D0,RWORK,-1.0D0,IWORK,-1.0D0,INFO)

La longitud requerida será devuelta en WORK(1).

Further Details

Autor: Ling, Wei, Oak Ridge National Laboratory

Basado en la versión de Richard Byers y Hong-Nian Huang.

En la práctica, la mayoría de los usuarios llamarán a los subprogramas de nivel superior como ZHESV, ZHEEV, ZHETRD o ZHEEVR, que llaman a ZHEEVR_2STAGE por ellos. Solo deben llamar a ZHEEVR_2STAGE directamente si saben lo que están haciendo.

La precisión de los valores propios y vectores propios devueltos depende de la precisión de los cálculos de punto flotante y de la forma en que se utiliza la matriz A de entrada. En particular, si la matriz A no está bien condicionada, los valores propios y vectores propios calculados pueden ser inexactos.

El algoritmo utilizado en ZHEEVR_2STAGE es una implementación de la técnica de dos etapas para reducir una matriz hermítica a tridiagonal. Esta técnica es particularmente útil para matrices grandes, ya que permite una reducción más eficiente a la forma tridiagonal que los métodos estándar. Una vez que la matriz está en forma tridiagonal, se utilizan algoritmos especializados para calcular los valores y vectores propios.

La llamada a ZSTEMR es una parte crucial del proceso, ya que implementa el algoritmo dqds (Divide, Conquer, and Quadtree Subdivision) para encontrar los valores propios de manera eficiente y relativamente robusta. Este algoritmo está diseñado para manejar eficientemente los casos en los que los valores propios están muy juntos.

Se recomienda encarecidamente consultar la documentación de ZSTEMR para obtener información más detallada sobre los aspectos numéricos del cálculo de valores y vectores propios.

Además, los autores señalan que el uso de NaNs e infinitos puede ocurrir durante la ejecución de ZSTEMR, lo que podría provocar excepciones de punto flotante si el entorno no los maneja de acuerdo con el estándar IEEE. Por lo tanto, es importante asegurarse de que el entorno de ejecución sea compatible con el manejo de estos valores.

Para las solicitudes de espectro parcial (cuando RANGE = 'V' o 'I'), se utilizan las subrutinas DSTEBZ y ZSTEIN. Estas subrutinas están diseñadas para seleccionar y calcular eficientemente los valores y vectores propios dentro de un rango especificado.

Finalmente, la disposición para consultar el tamaño del espacio de trabajo (workspace query) es una característica estándar de las rutinas de LAPACK. Permite a los usuarios determinar dinámicamente la cantidad de memoria necesaria para la ejecución, evitando así la sobreasignación o la subasignación de memoria.

Function/Subroutine Documentation

ZHEEVR computes the eigenvalues and eigenvectors of a complex Hermitian matrix A. Since the matrix A is Hermitian, its eigenvalues are real and its eigenvectors are orthonormal. The eigenvalues are returned in W and are not necessarily ordered. The eigenvectors are returned in the columns of the matrix Z.

If the eigenvectors are requested, then the subroutine returns the orthonormal eigenvectors Z of A.

The subroutine uses a two-stage approach for computing the eigenvalues and eigenvectors:

  1. The Hermitian matrix A is reduced to bidiagonal matrix B.

  2. The eigenvalues and eigenvectors of the bidiagonal matrix B are computed using the QR algorithm.

The subroutine also computes the eigenvalues and eigenvectors of the matrix A.

The subroutine ZHEEVR is designed to be highly efficient and accurate, especially for large matrices. It uses a variety of techniques to optimize performance, including:

  1. Two-stage reduction for improved performance.

  2. Parallel computation of eigenvalues and eigenvectors for multicore architectures.

  3. Out-of-core computation for matrices that do not fit into memory.

Input Parameters

JOBZ

JOBZ is CHARACTER*1
         = 'N':  Compute only the eigenvalues of A.
         = 'V':  Compute the eigenvalues and eigenvectors of A.

RANGE

RANGE is CHARACTER*1
         = 'A': all eigenvalues will be found.
         = 'V': all eigenvalues in the interval (VL, VU] will be found.
         = 'I': all eigenvalues in the index range [IL, IU] will be found.

UPLO

UPLO is CHARACTER*1
         = 'U':  Upper triangle of A is stored and referenced.
         = 'L':  Lower triangle of A is stored and referenced.

N

N is INTEGER
         The order of the matrix A. N >= 0.

A

A is COMPLEX*16 array, dimension (LDA, N)
         On entry, the Hermitian matrix A.

LDA

LDA is INTEGER
         The leading dimension of the array A. LDA >= max(1, N).

VL

VL is DOUBLE PRECISION
         The lower bound of the interval for the desired eigenvalues.
         Relevant only if RANGE='V'. The range is restricted to (VL, VU].

VU

VU is DOUBLE PRECISION
         The upper bound of the interval for the desired eigenvalues.
         Relevant only if RANGE='V'. The range is restricted to (VL, VU].

IL

IL is INTEGER
         The starting index for the desired eigenvalues.
         Relevant only if RANGE='I'. The range is restricted to [IL, IU].

IU

IU is INTEGER
         The ending index for the desired eigenvalues.
         Relevant only if RANGE='I'. The range is restricted to [IL, IU].

ABSTOL

ABSTOL is DOUBLE PRECISION
         The absolute tolerance to use when checking for convergence.
         If ABSTOL is negative, the routine will use the machine-dependent
         default value, which is n*eps*norm(A).

Output Parameters

M

M is INTEGER
         The total number of eigenvalues found. 0 <= M <= N.
         If RANGE = 'A', M = N, and if RANGE = 'I', M = IU-IL+1.

W

W is DOUBLE PRECISION array, dimension (N)
         The first M elements contain the selected eigenvalues in
         ascending order.

Z

Z is COMPLEX*16 array, dimension (LDZ, max(1,M))
         If JOBZ = 'V', then if INFO = 0, the first M columns of Z
         contain the orthonormal eigenvectors of the matrix A
         corresponding to the selected eigenvalues, with the i-th
         column of Z holding the eigenvector associated with W(i).
         If JOBZ = 'N', then Z is not referenced.
         Note: the user must ensure that at least max(1,M) columns are
         supplied in the array Z; if RANGE = 'V', the exact value of M
         is not known in advance and an upper bound must be used.

LDZ

LDZ is INTEGER
         The leading dimension of the array Z. LDZ >= 1, and if
         JOBZ = 'V', LDZ >= max(1,N).

ISUPPZ

ISUPPZ is INTEGER array, dimension ( 2*max(1,M) )
         The support of the eigenvectors in Z, i.e., the indices
         indicating the nonzero elements in Z. The i-th eigenvector
         is nonzero only in elements ISUPPZ( 2*i-1 ) through
         ISUPPZ( 2*i ). This is an output of ZSTEMR (tridiagonal
         matrix). The support of the eigenvectors of A is typically
         1:N because of the unitary transformations applied by ZUNMTR.
         Implemented only for RANGE = 'A' or 'I' and IU - IL = N - 1

WORK

WORK is COMPLEX*16 array, dimension (MAX(1,LWORK))
         On exit, if INFO = 0, WORK(1) returns the optimal LWORK.

LWORK

LWORK is INTEGER
         The dimension of the array WORK.
         If N <= 1,               LWORK must be at least 1.
         If JOBZ = 'N' and N > 1, LWORK must be queried.
                                    LWORK = MAX(1, 26*N, dimension) where
                                    dimension = max(stage1,stage2) + (KD+1)*N + N
                                              = N*KD + N*max(KD+1,FACTOPTNB)
                                                + max(2*KD*KD, KD*NTHREADS)
                                                + (KD+1)*N + N
                                    where KD is the blocking size of the reduction,
                                    FACTOPTNB is the blocking used by the QR or LQ
                                    algorithm, usually FACTOPTNB=128 is a good choice
                                    NTHREADS is the number of threads used when
                                    openMP compilation is enabled, otherwise =1.
         If JOBZ = 'V' and N > 1, LWORK must be queried. Not yet available


         If LWORK = -1, then a workspace query is assumed; the routine
         only calculates the optimal sizes of the WORK, RWORK and
         IWORK arrays, returns these values as the first entries of
         the WORK, RWORK and IWORK arrays, and no error message
         related to LWORK or LRWORK or LIWORK is issued by XERBLA.

RWORK

RWORK is DOUBLE PRECISION array, dimension (MAX(1,LRWORK))
         On exit, if INFO = 0, RWORK(1) returns the optimal
         (and minimal) LRWORK.

LRWORK

LRWORK is INTEGER
         The length of the array RWORK.
         If N <= 1, LRWORK >= 1, else LRWORK >= 24*N.


         If LRWORK = -1, then a workspace query is assumed; the
         routine only calculates the optimal sizes of the WORK, RWORK
         and IWORK arrays, returns these values as the first entries
         of the WORK, RWORK and IWORK arrays, and no error message
         related to LWORK or LRWORK or LIWORK is issued by XERBLA.

IWORK

IWORK is INTEGER array, dimension (MAX(1,LIWORK))
         On exit, if INFO = 0, IWORK(1) returns the optimal
         (and minimal) LIWORK.

LIWORK

LIWORK is INTEGER
         The dimension of the array IWORK.
         If N <= 1, LIWORK >= 1, else LIWORK >= 10*N.


         If LIWORK = -1, then a workspace query is assumed; the
         routine only calculates the optimal sizes of the WORK, RWORK
         and IWORK arrays, returns these values as the first entries
         of the WORK, RWORK and IWORK arrays, and no error message
         related to LWORK or LRWORK or LIWORK is issued by XERBLA.

INFO

INFO is INTEGER
         = 0:  successful exit
         < 0:  if INFO = -i, the i-th argument had an illegal value
         > 0:  Internal error
