Documentación de Función/Subrutina

subroutine zhegvd (integer itype, character jobz, character uplo, integer n, complex*16, dimension( lda, * ) a, integer lda, complex*16, dimension( ldb, * ) b, integer ldb, double precision, dimension( * ) w, complex*16, dimension( * ) work, integer lwork, double precision, dimension( * ) rwork, integer lrwork, integer, dimension( * ) iwork, integer liwork, integer info)

ZHEGVD

Propósito:

!>
!> ZHEGVD calcula todos los valores propios, y opcionalmente, los vectores propios
!> de un problema de eigenvalor generalizado hermítico definido complejo, de la forma
!> A*x=(lambda)*B*x,  A*Bx=(lambda)*x,  o B*A*x=(lambda)*x. Aquí A y
!> B se suponen hermíticos y B es también positivo definido.
!> Si se desean vectores propios, utiliza un algoritmo de divide y vencerás.
!>
!>

Parámetros

ITYPE 
!>          ITYPE es INTEGER
!>          Especifica el tipo de problema a resolver:
!>          = 1:  A*x = (lambda)*B*x
!>          = 2:  A*B*x = (lambda)*x
!>          = 3:  B*A*x = (lambda)*x
!>

JOBZ

!>          JOBZ es CHARACTER*1
!>          = 'N':  Solo calcular valores propios;
!>          = 'V':  Calcular valores propios y vectores propios.
!>

UPLO

!>          UPLO es CHARACTER*1
!>          = 'U':  Se almacenan los triángulos superiores de A y B;
!>          = 'L':  Se almacenan los triángulos inferiores de A y B.
!>

N

!>          N es INTEGER
!>          El orden de las matrices A y B.  N >= 0.
!>

A

!>          A es un array COMPLEX*16, dimensión (LDA, N)
!>          En la entrada, la matriz hermítica A. Si UPLO = 'U', la
!>          parte triangular superior N por N principal de A contiene la
!>          parte triangular superior de la matriz A. Si UPLO = 'L',
!>          la parte triangular inferior N por N principal de A contiene
!>          la parte triangular inferior de la matriz A.
!>
!>          En la salida, si JOBZ = 'V', entonces si INFO = 0, A contiene la
!>          matriz Z de vectores propios. Los vectores propios se normalizan
!>          como sigue:
!>          si ITYPE = 1 o 2, Z**H*B*Z = I;
!>          si ITYPE = 3, Z**H*inv(B)*Z = I.
!>          Si JOBZ = 'N', entonces en la salida el triángulo superior (si UPLO='U')
!>          o el triángulo inferior (si UPLO='L') de A, incluyendo la
!>          diagonal, se destruye.
!>

LDA

!>          LDA es INTEGER
!>          La dimensión principal del array A.  LDA >= max(1,N).
!>

B

!>          B es un array COMPLEX*16, dimensión (LDB, N)
!>          En la entrada, la matriz hermítica B. Si UPLO = 'U', la
!>          parte triangular superior N por N principal de B contiene la
!>          parte triangular superior de la matriz B. Si UPLO = 'L',
!>          la parte triangular inferior N por N principal de B contiene
!>          la parte triangular inferior de la matriz B.
!>
!>          En la salida, si INFO <= N, la parte de B que contiene la matriz se
!>          sobrescribe con el factor triangular U o L de la factorización de Cholesky
!>          B = U**H*U o B = L*L**H.
!>

LDB

!>          LDB es INTEGER
!>          La dimensión principal del array B.  LDB >= max(1,N).
!>

W

!>          W es un array DOUBLE PRECISION, dimensión (N)
!>          Si INFO = 0, los valores propios en orden ascendente.
!>

WORK

!>          WORK es un array COMPLEX*16, dimensión (MAX(1,LWORK))
!>          En la salida, si INFO = 0, WORK(1) devuelve el LWORK óptimo.
!>

LWORK

!>          LWORK es INTEGER
!>          La longitud del array WORK.
!>          Si N <= 1,                LWORK >= 1.
!>          Si JOBZ  = 'N' y N > 1, LWORK >= N + 1.
!>          Si JOBZ  = 'V' y N > 1, LWORK >= 2*N + N**2.
!>
!>          Si LWORK = -1, entonces se asume una consulta de espacio de trabajo; la rutina
!>          solo calcula los tamaños óptimos de los arrays WORK, RWORK y
!>          IWORK, devuelve estos valores como las primeras entradas de
!>          los arrays WORK, RWORK e IWORK, y XERBLA no emite ningún mensaje de error
!>          relacionado con LWORK o LRWORK o LIWORK.
!>

RWORK

!>          RWORK es un array DOUBLE PRECISION, dimensión (MAX(1,LRWORK))
!>          En la salida, si INFO = 0, RWORK(1) devuelve el LRWORK óptimo.
!>

LRWORK

!>          LRWORK es INTEGER
!>          La dimensión del array RWORK.
!>          Si N <= 1,                LRWORK >= 1.
!>          Si JOBZ  = 'N' y N > 1, LRWORK >= N.
!>          Si JOBZ  = 'V' y N > 1, LRWORK >= 1 + 5*N + 2*N**2.
!>
!>          Si LRWORK = -1, entonces se asume una consulta de espacio de trabajo; la
!>          rutina solo calcula los tamaños óptimos de los arrays WORK, RWORK
!>          e IWORK, devuelve estos valores como las primeras entradas de
!>          los arrays WORK, RWORK e IWORK, y XERBLA no emite ningún mensaje de error
!>          relacionado con LWORK o LRWORK o LIWORK.
!>

IWORK

!>          IWORK es un array INTEGER, dimensión (MAX(1,LIWORK))
!>          En la salida, si INFO = 0, IWORK(1) devuelve el LIWORK óptimo.
!>

LIWORK

!>          LIWORK es INTEGER
!>          La dimensión del array IWORK.
!>          Si N <= 1,                LIWORK >= 1.
!>          Si JOBZ  = 'N' y N > 1, LIWORK >= 1.
!>          Si JOBZ  = 'V' y N > 1, LIWORK >= 3 + 5*N.
!>
!>          Si LIWORK = -1, entonces se asume una consulta de espacio de trabajo; la
!>          rutina solo calcula los tamaños óptimos de los arrays WORK, RWORK
!>          e IWORK, devuelve estos valores como las primeras entradas de
!>          los arrays WORK, RWORK e IWORK, y XERBLA no emite ningún mensaje de error
!>          relacionado con LWORK o LRWORK o LIWORK.
!>

INFO

!>          INFO es INTEGER
!>          = 0:  salida exitosa
!>          < 0:  si INFO = -i, el i-ésimo argumento tuvo un valor ilegal
!>          > 0:  ZPOTRF o ZHEEVD devolvieron un código de error:
!>             <= N:  si INFO = i y JOBZ = 'N', entonces el algoritmo
!>                    falló en converger; i elementos fuera de la diagonal de una
!>                    forma tridiagonal intermedia no convergieron a cero;
!>                    si INFO = i y JOBZ = 'V', entonces el algoritmo
!>                    falló en calcular un valor propio mientras trabajaba en
!>                    la submatriz ubicada en las filas y columnas INFO/(N+1)
!>                    a mod(INFO,N+1);
!>             > N:   si INFO = N + i, para 1 <= i <= N, entonces el menor
!>                    principal de orden i de B no es positivo.
!>                    La factorización de B no pudo completarse y
!>                    no se calcularon valores propios ni vectores propios.
!>
