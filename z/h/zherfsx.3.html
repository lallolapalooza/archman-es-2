DOCUMENTACIÓN DE FUNCIÓN/SUBRUTINA

subroutine zherfsx (character uplo, character equed, integer n, integer nrhs, complex*16, dimension( lda, * ) a, integer lda, complex*16, dimension( ldaf, * ) af, integer ldaf, integer, dimension( * ) ipiv, double precision, dimension( * ) s, complex*16, dimension( ldb, * ) b, integer ldb, complex*16, dimension( ldx, * ) x, integer ldx, double precision rcond, double precision, dimension( * ) berr, integer n_err_bnds, double precision, dimension( nrhs, * ) err_bnds_norm, double precision, dimension( nrhs, * ) err_bnds_comp, integer nparams, double precision, dimension( * ) params, complex*16, dimension( * ) work, double precision, dimension( * ) rwork, integer info)

ZHERFSX

Propósito:

!>
!>    ZHERFSX mejora la solución calculada para un sistema de ecuaciones
!>    lineales cuando la matriz de coeficientes es Hermítica indefinida, y
!>    proporciona cotas de error y estimaciones de error hacia atrás para la
!>    solución. Además de la cota de error normwise, el código proporciona
!>    una cota de error componente a componente máxima si es posible. Ver los
!>    comentarios de ERR_BNDS_NORM y ERR_BNDS_COMP para detalles sobre las
!>    cotas de error.
!>
!>    El sistema original de ecuaciones lineales puede haber sido
!>    equilibrado antes de llamar a esta rutina, como se describe en los
!>    argumentos EQUED y S a continuación. En este caso, la solución y las
!>    cotas de error devueltas son para el sistema original no
!>    equilibrado.
!> 
!>    Algunos parámetros opcionales se agrupan en el array PARAMS. Estas
!>    configuraciones determinan cómo se realiza el refinamiento, pero a
!>    menudo los valores predeterminados son aceptables. Si los valores
!>    predeterminados son aceptables, los usuarios pueden pasar NPARAMS = 0
!>    lo que evita que el código fuente acceda al argumento PARAMS.
!>

Parámetros

UPLO 
!>          UPLO es CHARACTER*1
!>       = 'U':  El triángulo superior de A se almacena;
!>       = 'L':  El triángulo inferior de A se almacena.
!>

EQUED

!>          EQUED es CHARACTER*1
!>     Especifica la forma de equilibrado que se realizó en A
!>     antes de llamar a esta rutina. Esto es necesario para calcular
!>     la solución y las cotas de error correctamente.
!>       = 'N':  Sin equilibrado
!>       = 'Y':  Equilibrado de fila y columna, es decir, A ha sido
!>               reemplazado por diag(S) * A * diag(S).
!>               El lado derecho B se ha modificado en consecuencia.
!>

N

!>          N es INTEGER
!>     El orden de la matriz A.  N >= 0.
!>

NRHS

!>          NRHS es INTEGER
!>     El número de lados derechos, es decir, el número de columnas
!>     de las matrices B y X.  NRHS >= 0.
!>

A

!>          A es un array COMPLEX*16, dimensión (LDA,N)
!>     La matriz Hermítica A.  Si UPLO = 'U', la parte superior
!>     del triángulo N por N de A contiene la parte triangular
!>     superior de la matriz A, y la parte triangular estrictamente
!>     inferior de A no se referencia. Si UPLO = 'L', la parte inferior
!>     del triángulo N por N de A contiene la parte triangular
!>     inferior de la matriz A, y la parte triangular estrictamente
!>     superior de A no se referencia.
!>

LDA

!>          LDA es INTEGER
!>     La dimensión principal del array A.  LDA >= max(1,N).
!>

AF

!>          AF es un array COMPLEX*16, dimensión (LDAF,N)
!>     La forma factorizada de la matriz A. AF contiene la matriz
!>     diagonal de bloques D y los multiplicadores utilizados para
!>     obtener U o L de la factorización A = U*D*U**H o A =
!>     L*D*L**H calculada por ZHETRF.
!>

LDAF

!>          LDAF es INTEGER
!>     La dimensión principal del array AF.  LDAF >= max(1,N).
!>

IPIV

!>          IPIV es un array INTEGER, dimensión (N)
!>     Detalles de los intercambios y la estructura de bloques de D
!>     según lo determinado por ZHETRF.
!>

S

!>          S es un array DOUBLE PRECISION, dimensión (N)
!>     Los factores de escala para A. Si EQUED = 'Y', A se multiplica a
!>     la izquierda y a la derecha por diag(S). S es un argumento de
!>     entrada si FACT = 'F'; de lo contrario, S es un argumento de
!>     salida. Si FACT = 'F' y EQUED = 'Y', cada elemento de S debe ser
!>     positivo. Si S es una salida, cada elemento de S es una potencia
!>     del radix. Si S es una entrada, cada elemento de S debe ser una
!>     potencia del radix para asegurar una solución fiable y estimaciones
!>     de error. El escalado por potencias del radix no causa errores de
!>     redondeo a menos que el resultado sea un subdesbordamiento o
!>     desbordamiento. Los errores de redondeo durante el escalado
!>     conducen a un refinamiento con una matriz que no es equivalente
!>     a la matriz de entrada, produciendo estimaciones de error que
!>     pueden no ser fiables.
!>

B

!>          B es un array COMPLEX*16, dimensión (LDB,NRHS)
!>     La matriz del lado derecho B.
!>

LDB

!>          LDB es INTEGER
!>     La dimensión principal del array B.  LDB >= max(1,N).
!>

X

!>          X es un array COMPLEX*16, dimensión (LDX,NRHS)
!>     A la entrada, la matriz solución X, tal como fue calculada por
!>     ZHETRS. A la salida, la matriz solución mejorada X.
!>

LDX

!>          LDX es INTEGER
!>     La dimensión principal del array X.  LDX >= max(1,N).
!>

RCOND

!>          RCOND es DOUBLE PRECISION
!>     Condición recíproca escalada. Esta es una estimación del
!>     número de condición de Skeel recíproco de la matriz A después
!>     del equilibrado (si se realizó). Si es menor que la precisión
!>     de la máquina (en particular, si es cero), la matriz es singular
!>     para la precisión de trabajo. Tenga en cuenta que el error puede
!>     ser pequeño incluso si este número es muy pequeño y la matriz
!>     parece mal condicionada.
!>

BERR

!>          BERR es un array DOUBLE PRECISION, dimensión (NRHS)
!>     Error relativo componente a componente hacia atrás. Este es el
!>     error relativo componente a componente de cada vector solución
!>     X(j) (es decir, el menor cambio relativo en cualquier elemento de A
!>     o B que haga que X(j) sea una solución exacta).
!>

N_ERR_BNDS

!>          N_ERR_BNDS es INTEGER
!>     Número de cotas de error a devolver para cada lado derecho
!>     y cada tipo (normwise o componente a componente). Ver ERR_BNDS_NORM
!>     y ERR_BNDS_COMP a continuación.
!>

ERR_BNDS_NORM

!>          ERR_BNDS_NORM es un array DOUBLE PRECISION, dimensión (NRHS, N_ERR_BNDS)
!>     Para cada lado derecho, esta matriz contiene información sobre
!>     varias cotas de error y números de condición correspondientes al
!>     error relativo normwise, que se define de la siguiente manera:
!>
!>     Error relativo normwise en el i-ésimo vector solución:
!>             max_j (abs(XTRUE(j,i) - X(j,i)))
!>            ------------------------------
!>                  max_j abs(X(j,i))
!>
!>     La matriz está i
