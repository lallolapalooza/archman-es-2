Documentación de la Función/Subrutina

subrutina zhpgvx (integer itype, character jobz, character range, character uplo, integer n, complex*16, dimension( * ) ap, complex*16, dimension( * ) bp, double precision vl, double precision vu, integer il, integer iu, double precision abstol, integer m, double precision, dimension( * ) w, complex*16, dimension( ldz, * ) z, integer ldz, complex*16, dimension( * ) work, double precision, dimension( * ) rwork, integer, dimension( * ) iwork, integer, dimension( * ) ifail, integer info)

ZHPGVX

Propósito:

!>
!> ZHPGVX calcula valores propios seleccionados y, opcionalmente, vectores propios
!> de un problema de valores propios Hermítico-definido generalizado complejo,
!> de la forma A*x=(lambda)*B*x,  A*Bx=(lambda)*x,  o B*A*x=(lambda)*x. Aquí,
!> se asume que A y B son Hermíticos, almacenados en formato empaquetado, y
!> B también es positivo definido. Los valores propios y vectores propios pueden
!> ser seleccionados especificando un rango de valores o un rango de índices
!> para los valores propios deseados.
!>

Parámetros

ITYPE 
!>          ITYPE es INTEGER
!>          Especifica el tipo de problema a resolver:
!>          = 1:  A*x = (lambda)*B*x
!>          = 2:  A*B*x = (lambda)*x
!>          = 3:  B*A*x = (lambda)*x
!>

JOBZ

!>          JOBZ es CHARACTER*1
!>          = 'N':  Calcular solo los valores propios;
!>          = 'V':  Calcular valores propios y vectores propios.
!>

RANGE

!>          RANGE es CHARACTER*1
!>          = 'A': se encontrarán todos los valores propios;
!>          = 'V': se encontrarán todos los valores propios en el intervalo semiabierto (VL,VU]
!>                 ;
!>          = 'I': se encontrarán los valores propios del índice IL al IU.
!>

UPLO

!>          UPLO es CHARACTER*1
!>          = 'U':  Se almacenan los triángulos superiores de A y B;
!>          = 'L':  Se almacenan los triángulos inferiores de A y B.
!>

N

!>          N es INTEGER
!>          El orden de las matrices A y B. N >= 0.
!>

AP

!>          AP es array COMPLEX*16, dimension (N*(N+1)/2)
!>          En la entrada, el triángulo superior o inferior de la matriz Hermítica
!>          A, empaquetado por columnas en un array lineal. La j-ésima columna de A
!>          se almacena en el array AP de la siguiente manera:
!>          si UPLO = 'U', AP(i + (j-1)*j/2) = A(i,j) para 1<=i<=j;
!>          si UPLO = 'L', AP(i + (j-1)*(2*n-j)/2) = A(i,j) para j<=i<=n.
!>
!>          En la salida, el contenido de AP se destruye.
!>

BP

!>          BP es array COMPLEX*16, dimension (N*(N+1)/2)
!>          En la entrada, el triángulo superior o inferior de la matriz Hermítica
!>          B, empaquetado por columnas en un array lineal. La j-ésima columna de B
!>          se almacena en el array BP de la siguiente manera:
!>          si UPLO = 'U', BP(i + (j-1)*j/2) = B(i,j) para 1<=i<=j;
!>          si UPLO = 'L', BP(i + (j-1)*(2*n-j)/2) = B(i,j) para j<=i<=n.
!>
!>          En la salida, el factor triangular U o L de la factorización de Cholesky
!!>          B = U**H*U o B = L*L**H, en el mismo formato de almacenamiento
!>          que B.
!>

VL

!>          VL es DOUBLE PRECISION
!>
!>          Si RANGE='V', el límite inferior del intervalo a
!>          buscar para los valores propios. VL < VU.
!>          No se hace referencia si RANGE = 'A' o 'I'.
!>

VU

!>          VU es DOUBLE PRECISION
!>
!>          Si RANGE='V', el límite superior del intervalo a
!>          buscar para los valores propios. VL < VU.
!>          No se hace referencia si RANGE = 'A' o 'I'.
!>

IL

!>          IL es INTEGER
!>
!>          Si RANGE='I', el índice del
!>          valor propio más pequeño a devolver.
!>          1 <= IL <= IU <= N, si N > 0; IL = 1 e IU = 0 si N = 0.
!>          No se hace referencia si RANGE = 'A' o 'V'.
!>

IU

!>          IU es INTEGER
!>
!>          Si RANGE='I', el índice del
!>          valor propio más grande a devolver.
!>          1 <= IL <= IU <= N, si N > 0; IL = 1 e IU = 0 si N = 0.
!>          No se hace referencia si RANGE = 'A' o 'V'.
!>

ABSTOL

!>          ABSTOL es DOUBLE PRECISION
!>          La tolerancia de error absoluto para los valores propios.
!>          Se acepta un valor propio aproximado como convergente
!>          cuando se determina que yace en un intervalo [a,b]
!>          de ancho menor o igual a
!>
!>                  ABSTOL + EPS *   max( |a|,|b| ) ,
!>
!>          donde EPS es la precisión de la máquina. Si ABSTOL es menor o
!>          igual a cero, entonces se usará EPS*|T| en su lugar,
!>          donde |T| es la norma 1 de la matriz tridiagonal obtenida
!>          al reducir AP a forma tridiagonal.
!>
!>          Los valores propios se calcularán con mayor precisión cuando ABSTOL
!>          se establezca en el doble del umbral de subdesbordamiento 2*DLAMCH('S'), no
!>          cero. Si esta rutina retorna con INFO>0, indicando que algunos
!>          vectores propios no convergieron, intente establecer ABSTOL en
!>          2*DLAMCH('S').
!>

M

!>          M es INTEGER
!>          El número total de valores propios encontrados. 0 <= M <= N.
!>          Si RANGE = 'A', M = N, y si RANGE = 'I', M = IU-IL+1.
!>

W

!>          W es array DOUBLE PRECISION, dimension (N)
!>          En una salida normal, los primeros M elementos contienen los valores propios
!>          seleccionados en orden ascendente.
!>

Z

!>          Z es array COMPLEX*16, dimension (LDZ, N)
!>          Si JOBZ = 'N', entonces Z no se hace referencia.
!>          Si JOBZ = 'V', entonces si INFO = 0, las primeras M columnas de Z
!>          contienen los vectores propios ortonormales de la matriz A
!>          correspondientes a los valores propios seleccionados, con la i-ésima
!>          columna de Z conteniendo el vector propio asociado con W(i).
!>          Los vectores propios están normalizados de la siguiente manera:
!>          si ITYPE = 1 o 2, Z**H*B*Z = I;
!>          si ITYPE = 3, Z**H*inv(B)*Z = I.
!>
!>          Si un vector propio no converge, entonces esa columna de Z
!>          contiene la última aproximación al vector propio, y el
!>          índice del vector propio se devuelve en IFAIL.
!>          Nota: el usuario debe asegurarse de que se proporcionan al menos
!>          max(1,M) columnas en el array Z; si RANGE = 'V', el valor exacto de M
!>          no se conoce de antemano y se debe usar un límite superior.
!>

LDZ

!>          LDZ es INTEGER
!>          La dimensión principal del array Z. LDZ >= 1, y si
!>          JOBZ = 'V', LDZ >= max(1,N).
!>

WORK

!>          WORK es array COMPLEX*16, dimension (2*N)
!>

RWORK

!>          RWORK es array DOUBLE PRECISION, dimension (7*N)
!>

IWORK

!>          IWORK es array INTEGER, dimension (5*N)
!>

IFAIL

!>          IFAIL es array INTEGER, dimension (N)
!>          Si JOBZ = 'V', entonces si INFO = 0, los primeros M elementos de
!>          IFAIL son cero. Si INFO > 0, entonces IFAIL contiene los
!>          índices de los vectores propios que no convergieron.
!>          Si JOBZ = 'N', entonces IFAIL no se hace referencia.
!>

INFO

Function/Subroutine Documentation

 This subroutine is part of the LAPACK routines.
 Its purpose is to compute the eigenvalues and eigenvectors of a complex
 Hermitian-definite generalized eigenvalue problem of the form:

 A*x = lambda*B*x,

 where A and B are complex Hermitian matrices, and B is positive-definite.
 The problem is solved by computing the Cholesky factorization of B,
 B = S*S**H, transforming the original problem into an equivalent
 standard eigenvalue problem:

 (S**(-1))*A*(S**H)**(-1) * y = lambda*y,

 where y = (S**H)*x. This standard eigenvalue problem is then solved
 using the ZHPTRD and ZHPTRF routines.

 The arguments of the subroutine are:

 ITYPE: Character*1. Specifies the problem type:
        = '1': A*x = lambda*B*x
        = '2': A*x = lambda*B**H*x
        = '3': A**H*x = lambda*B*x

 JOBZ:  Character*1. Specifies whether to compute the eigenvalues only
        or both eigenvalues and eigenvectors:
        = 'N': Compute eigenvalues only.
        = 'V': Compute eigenvalues and eigenvectors.

 RANGE: Character*1. Specifies the range of eigenvalues to be computed:
        = 'A': All eigenvalues will be computed.
        = 'V': All eigenvalues in the interval (VL, VU] will be
               computed, in the sense the distance between the
               theoretical and computed values of the i-th
               eigenvalue is within a tolerance specified by the
               user.
        = 'I': All eigenvalues in the interval [ILO, IHI] will be
               computed.

 UPLO:  Character*1. Specifies whether the upper or lower triangular part
        of the matrices A and B is stored:
        = 'U': Upper triangular.
        = 'L': Lower triangular.

 N:     Integer. The order of the matrices A and B.

 AP:    Complex*16 array of dimension (LDA, *). The upper or lower
        triangular part of the matrix A, packed by columns.

 B:     Complex*16 array of dimension (LDB, *). The upper or lower
        triangular part of the matrix B, packed by columns.

 PB:    Complex*16 array of dimension (LDB, *). The upper or lower
        triangular part of the matrix B, packed by columns, after
        being transformed by ZHPTRD.

 Q:     Complex*16 array of dimension (LDQ, *). If JOBZ = 'V', Q contains
        the computed eigenvectors.

 PQ:    Integer. The number of rows of Q.

 VI:    Complex*16 array of dimension (LDVP, *).
        If RANGE = 'V', VI contains the interval (VL, VU] on exit.
        If RANGE = 'I', VI contains the interval [ILO, IHI] on exit.

 CLPNT: Integer. The number of eigenvalues (or eigenvectors) to be computed.

 WORK:  Complex*16 array of dimension (LWORK).
        On exit, WORK(1) contains the minimum required dimension LWORK.

 RWORK: Real*8 array of dimension (LRWORK).
        Workspace array.

 IWORK: Integer array of dimension (LIWORK).
        Workspace array.

 IFAIL: Integer array of dimension (N).
        On exit, IFAIL contains the indices of the eigenvectors that
        failed to converge.

 INFO:  Integer.
        = 0: successful exit
        < 0: if INFO = -i, the i-th argument had an illegal value
        > 0: ZPPTRF or ZHPEVX returned an error code:
            <= N: if INFO = i, ZHPEVX failed to converge;
                   i eigenvectors failed to converge. Their indices
                   are stored in array IFAIL.
            > N:  if INFO = N + i, for 1 <= i <= n, then the leading
                   principal minor of order i of B is not positive.
                   The factorization of B could not be completed and
                   no eigenvalues or eigenvectors were computed.
