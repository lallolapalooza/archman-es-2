subroutine zhbevx_2stage (character jobz, character range, character uplo, integer n, integer kd, complex*16, dimension( ldab, * ) ab, integer ldab, complex*16, dimension( ldq, * ) q, integer ldq, double precision vl, double precision vu, integer il, integer iu, double precision abstol, integer m, double precision, dimension( * ) w, complex*16, dimension( ldz, * ) z, integer ldz, complex*16, dimension( * ) work, integer lwork, double precision, dimension( * ) rwork, integer, dimension( * ) iwork, integer, dimension( * ) ifail, integer info)

ZHBEVX_2STAGE calcula los valores propios y, opcionalmente, los vectores propios de una matriz de banda Hermitiana compleja A utilizando la técnica de 2 etapas para la reducción a tridiagonal

Propósito:

!>
!> ZHBEVX_2STAGE calcula valores propios seleccionados y, opcionalmente, vectores
!> propios de una matriz de banda Hermitiana compleja A utilizando la técnica de
!> 2 etapas para la reducción a tridiagonal. Los valores propios y vectores
!> propios pueden ser seleccionados especificando un rango de valores o un rango
!> de índices para los valores propios deseados.
!>

Parámetros

JOBZ 
!>          JOBZ es CHARACTER*1
!>          = 'N':  Calcular solo los valores propios;
!>          = 'V':  Calcular valores propios y vectores propios.
!>                  No disponible en esta versión.
!>

RANGE

!>          RANGE es CHARACTER*1
!>          = 'A': se encontrarán todos los valores propios;
!>          = 'V': se encontrarán todos los valores propios en el intervalo semi-abierto (VL,VU];
!>          = 'I': se encontrarán los valores propios del IL-ésimo al IU-ésimo.
!>

UPLO

!>          UPLO es CHARACTER*1
!>          = 'U':  Se almacena el triángulo superior de A;
!>          = 'L':  Se almacena el triángulo inferior de A.
!>

N

!>          N es INTEGER
!>          El orden de la matriz A.  N >= 0.
!>

KD

!>          KD es INTEGER
!>          El número de superdiagonales de la matriz A si UPLO = 'U',
!>          o el número de subdiagonales si UPLO = 'L'.  KD >= 0.
!>

AB

!>          AB es un array COMPLEX*16, de dimensión (LDAB, N)
!>          En la entrada, el triángulo superior o inferior de la matriz de banda Hermitiana
!>          A, almacenado en las primeras KD+1 filas del array. La
!>          columna j-ésima de A se almacena en la columna j-ésima del array AB
!>          como sigue:
!>          si UPLO = 'U', AB(kd+1+i-j,j) = A(i,j) para max(1,j-kd) <= i <= j;
!>          si UPLO = 'L', AB(1+i-j,j)    = A(i,j) para j <= i <= min(n,j+kd).
!>
!>          En la salida, AB se sobrescribe con valores generados durante la
!>          reducción a forma tridiagonal.
!>

LDAB

!>          LDAB es INTEGER
!>          La dimensión principal del array AB.  LDAB >= KD + 1.
!>

Q

!>          Q es un array COMPLEX*16, de dimensión (LDQ, N)
!>          Si JOBZ = 'V', la matriz unitaria N por N utilizada en la
!>                          reducción a forma tridiagonal.
!>          Si JOBZ = 'N', el array Q no se referencia.
!>

LDQ

!>          LDQ es INTEGER
!>          La dimensión principal del array Q.  Si JOBZ = 'V', entonces
!>          LDQ >= max(1,N).
!>

VL

!>          VL es DOUBLE PRECISION
!>          Si RANGE='V', el límite inferior del intervalo a
!>          buscar para los valores propios. VL < VU.
!>          No se referencia si RANGE = 'A' o 'I'.
!>

VU

!>          VU es DOUBLE PRECISION
!>          Si RANGE='V', el límite superior del intervalo a
!>          buscar para los valores propios. VL < VU.
!>          No se referencia si RANGE = 'A' o 'I'.
!>

IL

!>          IL es INTEGER
!>          Si RANGE='I', el índice del
!>          valor propio más pequeño a devolver.
!>          1 <= IL <= IU <= N, si N > 0; IL = 1 e IU = 0 si N = 0.
!>          No se referencia si RANGE = 'A' o 'V'.
!>

IU

!>          IU es INTEGER
!>          Si RANGE='I', el índice del
!>          valor propio más grande a devolver.
!>          1 <= IL <= IU <= N, si N > 0; IL = 1 e IU = 0 si N = 0.
!>          No se referencia si RANGE = 'A' o 'V'.
!>

ABSTOL

!>          ABSTOL es DOUBLE PRECISION
!>          La tolerancia de error absoluta para los valores propios.
!>          Un valor propio aproximado se acepta como convergente
!>          cuando se determina que se encuentra en un intervalo [a,b]
!>          de ancho menor o igual que
!>
!>                  ABSTOL + EPS *   max( |a|,|b| ) ,
!>
!>          donde EPS es la precisión de la máquina. Si ABSTOL es menor o
!>          igual a cero, entonces se usará EPS*|T| en su lugar,
!>          donde |T| es la norma 1 de la matriz tridiagonal obtenida
!>          al reducir AB a forma tridiagonal.
!>
!>          Los valores propios se calcularán con la mayor precisión cuando ABSTOL
!>          se establezca en el doble del umbral de subdesbordamiento 2*DLAMCH('S'), no cero.
!>          Si esta rutina retorna con INFO>0, indicando que algunos
!>          vectores propios no convergieron, intente establecer ABSTOL en
!>          2*DLAMCH('S').
!>
!>          Ver  por Demmel y
!>          Kahan, LAPACK Working Note #3.
!>

M

!>          M es INTEGER
!>          El número total de valores propios encontrados.  0 <= M <= N.
!>          Si RANGE = 'A', M = N, y si RANGE = 'I', M = IU-IL+1.
!>

W

!>          W es un array DOUBLE PRECISION, de dimensión (N)
!>          Los primeros M elementos contienen los valores propios seleccionados en
!>          orden ascendente.
!>

Z

!>          Z es un array COMPLEX*16, de dimensión (LDZ, max(1,M))
!>          Si JOBZ = 'V', entonces si INFO = 0, las primeras M columnas de Z
!>          contienen los vectores propios ortonormales de la matriz A
!>          correspondientes a los valores propios seleccionados, con la i-ésima
!>          columna de Z conteniendo el vector propio asociado a W(i).
!>          Si un vector propio falla en converger, entonces esa columna de Z
!>          contiene la última aproximación del vector propio, y el
!>          índice del vector propio se devuelve en IFAIL.
!>          Si JOBZ = 'N', entonces Z no se referencia.
!>          Nota: el usuario debe asegurarse de que se suministran al menos max(1,M) columnas
!>          en el array Z; si RANGE = 'V', el valor exacto de M
!>          no se conoce de antemano y se debe usar un límite superior.
!>

LDZ

!>          LDZ es INTEGER
!>          La dimensión principal del array Z.  LDZ >= 1, y si
!>          JOBZ = 'V', LDZ >= max(1,N).
!>

WORK

!>          WORK es un array COMPLEX*16, de dimensión (LWORK)
!>

LWORK

!>          LWORK es INTEGER
!>          La longitud del array WORK. LWORK >= 1, cuando N <= 1;
!>          de lo contrario
!>          Si JOBZ = 'N' y N > 1, LWORK debe ser consultado.
!>                                   LWORK = MAX(1, dimension) donde
!>                                   dim
zhbevx_2stage.f(3) — LAPACK

NAME

zhbevx_2stage — The \fROUTINE is transposed and then converted to a 2 stage algorithm.

SYNOPSIS

call zhbevx_2stage(JOBZ, RANGE, UPLO, N, AB, LDAB, Q, LDQ, VL, VU, IL, IU, M,
                 TAU, X, LDX, WORK, LWORK, RWORK, LRWORK, IWORK, LIWORK,
                 IFAIL, INFO)

Parameters

JOBZ

CHARACTER*1.

Specifies whether to compute all eigenvectors, or only the eigenvectors corresponding to the diagonal elements of the Level 2 block (a sub-diagonal block).

If JOBZ = 'N', then only the eigenvalues are computed.

If JOBZ = 'V', then the eigenvalues and the corresponding eigenvectors are computed.

Constraint: JOBZ = 'V' or 'N'.

RANGE

CHARACTER*1.

Specifies the range of values for the eigenvalues to be returned.

If RANGE = 'A', then all eigenvalues will be returned.

If RANGE = 'V', then all eigenvalues in the interval (VL, VU] will be returned.

If RANGE = 'I', then the IL-th through IU-th eigenvalues will be returned.

Constraint: RANGE = 'A', 'V' or 'I'.

UPLO

CHARACTER*1.

Specifies whether the upper or lower triangular part of the band matrix AB is stored.

If UPLO = 'U', then the upper triangular part is stored.

If UPLO = 'L', then the lower triangular part is stored.

N

INTEGER.

The order of the matrix AB. N >= 0.

AB

COMPLEX*16 array, dimension (LDAB,K)

On entry, the n-by-n upper or lower banded complex symmetric (Hermitian) matrix AB.

The j-th column of AB is stored in the j-th column of the array AB. If UPLO = 'U', AB is stored on the sub-diagonal and main diagonal of the array. If UPLO = 'L', AB is stored on the main diagonal and the super-diagonal of the array.

If UPLO = 'U', the k-th super-diagonal is in AB(1:N-K,K+1), the main diagonal is in AB(1:N,1), and the k-th sub-diagonal is in AB(K+1:N,1). Similarly, If UPLO = 'L', the k-th sub-diagonal is in AB(K+1:N,1), the main diagonal is in AB(1:N,1), and the k-th super-diagonal is in AB(1:N-K,2).

On exit, AB is overwritten by values generated during the computation of the eigenvectors.

LDAB

INTEGER.

The leading dimension of the array AB. LDAB >= max(1,N).

Q

COMPLEX*16 array, dimension (LDQ, N)

If JOBZ = 'V', then if INFO = 0, Q contains the orthogonal (unitary) eigenvectors of the matrix AB. The j-th column of Q contains the eigenvector to the corresponding eigenvalue, that is, the j-th column of Q contains the eigenvector corresponding to the j-th element of W.

If JOBZ = 'N', then Q is not referenced.

LDQ

INTEGER.

The leading dimension of the array Q. If JOBZ = 'V', then LDQ >= max(1,N).

VL

DOUBLE PRECISION.

If RANGE = 'V', the lower bound of the eigenvalue range.

If RANGE = 'A' or 'I', VL is not used.

VU

DOUBLE PRECISION.

If RANGE = 'V', the upper bound of the eigenvalue range.

If RANGE = 'A' or 'I', VU is not used.

IL

INTEGER.

If RANGE = 'I', the index of the smallest eigenvalue to be returned.

If RANGE = 'A' or 'V', IL is not used.

IU

INTEGER.

If RANGE = 'I', the index of the largest eigenvalue to be returned.

If RANGE = 'A' or 'V', IU is not used.

M

INTEGER.

The total number of eigenvalues found.

If RANGE = 'A', M = N.

If RANGE = 'V', M = the number of eigenvalues in (VL, VU].

If RANGE = 'I', M = IU - IL + 1.

TAU

COMPLEX*16 array, dimension (N)

The imaginary parts of the eigenvalues.

X

COMPLEX*16 array, dimension (LDX,N)

This array is a temporary array, used to store eigenvectors.

LDX

INTEGER.

The leading dimension of the array X.

WORK

COMPLEX*16 array, dimension (LWORK)

On exit, WORK(1) contains the optimal LWORK.

LWORK

INTEGER.

The dimension of the array WORK.

LWORK determines the amount of workspace available for intermediate calculations.

If LWORK = -1, then only the optimal dimensions of the arrays WORK, RWORK and IWORK are computed and returned in the first entry of the arrays WORK, RWORK and IWORK, respectively. No further processing is done.

The optimal dimension is:

LWORK = MAX( N+N, NB*(N+1)+N, N*(MAX(NB, FINEGRAIN))+N )

where NB is the block size used in the recurrence relation and FINEGRAIN is the granularity size used in the tasking implementation.

NTHREADS is the number of threads used when openMP compilation is enabled, otherwise =1.

If JOBZ = 'V' and N > 1, LWORK must be queried. Not yet available.

If LWORK = -1, then a workspace query is assumed; the routine only calculates the optimal sizes of the WORK, RWORK and IWORK arrays, returns these values as the first entries of the WORK, RWORK and IWORK arrays, and no error message related to LWORK or LRWORK or LIWORK is issued by XERBLA.

RWORK

DOUBLE PRECISION array, dimension (7*N)

IWORK

INTEGER array, dimension (5*N)

IFAIL

INTEGER array, dimension (N)

If JOBZ = 'V', then if INFO = 0, the first M elements of IFAIL are zero. If INFO > 0, then IFAIL contains the indices of the eigenvectors that failed to converge. If JOBZ = 'N', then IFAIL is not referenced.

INFO

INTEGER

= 0: successful exit

< 0: if INFO = -i, the i-th argument had an illegal value

> 0: if INFO = i, then i eigenvectors failed to converge. Their indices are stored in array IFAIL.
