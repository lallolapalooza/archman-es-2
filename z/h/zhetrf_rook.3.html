subroutine zhetrf_rook (uplo, n, a, lda, ipiv, work, lwork, info)

ZHETRF_ROOK calcula la factorización de una matriz Hermítica indefinida compleja utilizando el método de pivoteo diagonal acotado de Bunch-Kaufman ( "rook" ) (algoritmo en bloques, llamando a BLAS de Nivel 3).

DOCUMENTACIÓN FUNCIÓN/SUBRUTINA

subroutine zhetrf_rook (character uplo, integer n, complex*16, dimension( lda, * ) a, integer lda, integer, dimension( * ) ipiv, complex*16, dimension( * ) work, integer lwork, integer info)

ZHETRF_ROOK calcula la factorización de una matriz Hermítica indefinida compleja utilizando el método de pivoteo diagonal acotado de Bunch-Kaufman ( "rook" ).

Propósito:

!>
!> ZHETRF_ROOK calcula la factorización de una matriz Hermítica compleja A
!> utilizando el método de pivoteo diagonal acotado de Bunch-Kaufman().
!> La forma de la factorización es
!>
!>    A = U*D*U**T  o  A = L*D*L**T
!>
!> donde U (o L) es un producto de matrices de permutación y triangulares
!> unitarias superiores (inferiores), y D es Hermítica y diagonal por
!> bloques con bloques diagonales de 1x1 y 2x2.
!>
!> Esta es la versión en bloques del algoritmo, que llama a BLAS de Nivel 3.
!>

Parámetros

UPLO 
!>          UPLO es CHARACTER*1
!>          = 'U':  El triángulo superior de A está almacenado;
!>          = 'L':  El triángulo inferior de A está almacenado.
!>

N

!>          N es INTEGER
!>          El orden de la matriz A.  N >= 0.
!>

A

!>          A es un array COMPLEX*16, de dimensión (LDA,N)
!>          En la entrada, la matriz Hermítica A.  Si UPLO = 'U', la parte
!>          superior N x N de A contiene la parte triangular superior de la
!>          matriz A, y la parte estrictamente inferior de A no se referencia.
!>          Si UPLO = 'L', la parte inferior N x N de A contiene la parte
!>          triangular inferior de la matriz A, y la parte estrictamente
!>          superior de A no se referencia.
!>
!>          En la salida, la matriz diagonal por bloques D y los multiplicadores
!>          utilizados para obtener el factor U o L (ver detalles más abajo).
!>

LDA

!>          LDA es INTEGER
!>          La dimensión principal del array A.  LDA >= max(1,N).
!>

IPIV

!>          IPIV es un array INTEGER, de dimensión (N)
!>          Detalles de los intercambios y la estructura de bloques de D.
!>
!>          Si UPLO = 'U':
!>             Sólo los últimos KB elementos de IPIV se establecen.
!>
!>             Si IPIV(k) > 0, entonces las filas y columnas k e IPIV(k) fueron
!>             intercambiadas y D(k,k) es un bloque diagonal de 1x1.
!>
!>             Si IPIV(k) < 0 y IPIV(k-1) < 0, entonces las filas y
!>             columnas k e -IPIV(k) fueron intercambiadas y las filas y
!>             columnas k-1 e -IPIV(k-1) fueron intercambiadas,
!>             D(k-1:k,k-1:k) es un bloque diagonal de 2x2.
!>
!>          Si UPLO = 'L':
!>             Sólo los primeros KB elementos de IPIV se establecen.
!>
!>             Si IPIV(k) > 0, entonces las filas y columnas k e IPIV(k)
!>             fueron intercambiadas y D(k,k) es un bloque diagonal de 1x1.
!>
!>             Si IPIV(k) < 0 y IPIV(k+1) < 0, entonces las filas y
!>             columnas k e -IPIV(k) fueron intercambiadas y las filas y
!>             columnas k+1 e -IPIV(k+1) fueron intercambiadas,
!>             D(k:k+1,k:k+1) es un bloque diagonal de 2x2.
!>

WORK

!>          WORK es un array COMPLEX*16, de dimensión (MAX(1,LWORK)).
!>          En la salida, si INFO = 0, WORK(1) devuelve el LWORK óptimo.
!>

LWORK

!>          LWORK es INTEGER
!>          La longitud de WORK.  LWORK >= 1.  Para un rendimiento óptimo
!>          LWORK >= N*NB, donde NB es el tamaño de bloque devuelto por ILAENV.
!>
!>          Si LWORK = -1, entonces se asume una consulta de espacio de trabajo; la rutina
!>          solo calcula el tamaño óptimo del array WORK, devuelve
!>          ese valor como la primera entrada del array WORK, y XERBLA no emite ningún mensaje de error
!>          relacionado con LWORK.
!>

INFO

!>          INFO es INTEGER
!>          = 0:  salida exitosa
!>          < 0:  si INFO = -i, el i-ésimo argumento tenía un valor ilegal
!>          > 0:  si INFO = i, D(i,i) es exactamente cero.  La factorización
!>                se ha completado, pero la matriz diagonal por bloques D es
!>                exactamente singular, y ocurrirá una división por cero si
!>                se utiliza para resolver un sistema de ecuaciones.
!>

Detalles Adicionales:

!>
!>  Si UPLO = 'U', entonces A = U*D*U**T, donde
!>     U = P(n)*U(n)* ... *P(k)U(k)* ...,
!>  es decir, U es un producto de términos P(k)*U(k), donde k disminuye de n a
!>  1 en pasos de 1 o 2, y D es una matriz diagonal por bloques con bloques
!>  diagonales de 1x1 y 2x2 D(k).  P(k) es una matriz de permutación como
!>  se define en IPIV(k), y U(k) es una matriz triangular superior unitaria, tal
!>  que si el bloque diagonal D(k) es de orden s (s = 1 o 2), entonces
!>
!>             (   I    v    0   )   k-s
!>     U(k) =  (   0    I    0   )   s
!>             (   0    0    I   )   n-k
!>                k-s   s   n-k
!>
!>  Si s = 1, D(k) sobrescribe A(k,k), y v sobrescribe A(1:k-1,k).
!>  Si s = 2, el triángulo superior de D(k) sobrescribe A(k-1,k-1), A(k-1,k),
!>  y A(k,k), y v sobrescribe A(1:k-2,k-1:k).
!>
!>  Si UPLO = 'L', entonces A = L*D*L**T, donde
!>     L = P(1)*L(1)* ... *P(k)*L(k)* ...,
!>  es decir, L es un producto de términos P(k)*L(k), donde k aumenta de 1 a
!>  n en pasos de 1 o 2, y D es una matriz diagonal por bloques con bloques
!>  diagonales de 1x1 y 2x2 D(k).  P(k) es una matriz de permutación como
!>  se define en IPIV(k), y L(k) es una matriz triangular inferior unitaria, tal
!>  que si el bloque diagonal D(k) es de orden s (s = 1 o 2), entonces
!>
!>             (   I    0     0   )  k-1
!>     L(k) =  (   0    I     0   )  s
!>             (   0    v     I   )  n-k-s+1
!>                k-1   s  n-k-s+1
!>
!>  Si s = 1, D(k) sobrescribe A(k,k), y v sobrescribe A(k+1:n,k).
!>  Si s = 2, el triángulo inferior de D(k) sobrescribe A(k,k), A(k+1,k),
!>  y A(k+1,k+1), y v sobrescribe A(k+2:n,k:k+1).
!>

zhetrf_rook(3)

NAME

zhetrf_rook - Computes the factorization of a general complex Hermitian matrix A in the form A = P * U * T * UH * PT, where U is a unitary matrix, P is a permutation matrix, and T is a tridiagonal matrix.

SYNOPSIS

SUBROUTINE zhetrf_rook( UPLO, N, A, LDA, IPIV, WORK, LWORK, INFO )

CHARACTER(LEN=1) :: UPLO

INTEGER, INTENT(IN) :: N, LDA, LWORK, INFO

COMPLEX(KIND=8), DIMENSION(LDA, N) :: A

INTEGER, DIMENSION(N) :: IPIV

COMPLEX(KIND=8), DIMENSION(LWORK) :: WORK

Function/Subroutine Documentation

zhetrf_rook is a subroutine in LAPACK (Linear Algebra PACKage) that performs the Bunch-Kaufman decomposition (also known as rook pivoting) of a complex Hermitian matrix. The decomposition is of the form:

A = P * U * T * UH * PT

where:

  • A is the input complex Hermitian matrix.
  • P is a permutation matrix.
  • U is an upper triangular matrix that is unitary on its first k columns and has ones on its diagonal.
  • T is a real tridiagonal matrix.
  • UH denotes the conjugate transpose of U.

The rook pivoting strategy is used to ensure numerical stability during the factorization.

Arguments

  • UPLO: CHARACTER*1. Specifies whether the matrix A is upper or lower Hermitian triangular.
    • 'U' : A is upper Hermitian triangular.
    • 'L' : A is lower Hermitian triangular.
  • N: INTEGER. The order of the matrix A. N ≥ 0.
  • A: COMPLEX*16, DIMENSION(LDA, N). On entry, the complex Hermitian matrix A. On exit, the factors U and T are stored in the upper or lower triangle of A, respectively. The diagonal elements of U are not stored.
  • LDA: INTEGER. The leading dimension of the array A. LDA ≥ max(1, N).
  • IPIV: INTEGER, DIMENSION(N). This array stores information about the permutations P. For each column i, IPIV(i) records the row that was swapped with row i, or with row k if row i was part of a 2x2 block swap.
  • WORK: COMPLEX*16, DIMENSION(LWORK). A workspace array used by the subroutine for intermediate calculations.
  • LWORK: INTEGER. The dimension of the workspace array WORK. LWORK ≥ N. If LWORK = -1, then the optimal size of WORK is returned in WORK(1).
  • INFO: INTEGER.
    • INFO = 0 : The factorization was successful.
    • INFO < 0 : If INFO = -i, the i-th argument had an illegal value.
    • INFO > 0 : If INFO = i, the factorization failed, and the matrix is singular. The diagonal element of the tridiagonal matrix T is zero at position i.

Notes

  • The routine overwrites the input matrix A with the factorization.
  • The IPIV array is crucial for reconstructing the matrix or for using the factorization in subsequent computations (e.g., solving linear systems).
  • The rook pivoting strategy is a variation of the standard Bunch-Kaufman pivoting that aims to improve stability by considering 1x1 or 2x2 blocks on the diagonal.
