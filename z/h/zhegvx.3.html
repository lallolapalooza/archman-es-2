subrutina zhegvx (integer itype, character jobz, character range, character uplo, integer n, complex*16, dimension( lda, * ) a, integer lda, complex*16, dimension( ldb, * ) b, integer ldb, double precision vl, double precision vu, integer il, integer iu, double precision abstol, integer m, double precision, dimension( * ) w, complex*16, dimension( ldz, * ) z, integer ldz, complex*16, dimension( * ) work, integer lwork, double precision, dimension( * ) rwork, integer, dimension( * ) iwork, integer, dimension( * ) ifail, integer info)

ZHEGVX

Propósito:

!>
!> ZHEGVX calcula valores propios seleccionados, y opcionalmente, vectores propios
!> de un problema de Ecuación Hermitiana definida generalizada compleja, de la forma
!> A*x=(lambda)*B*x,  A*Bx=(lambda)*x,  o B*A*x=(lambda)*x. Aquí A y
!> B se suponen Hermitianas y B es también definida positiva.
!> Los valores propios y vectores propios pueden seleccionarse especificando un
!> rango de valores o un rango de índices para los valores propios deseados.
!>

Parámetros

ITYPE 
!>          ITYPE es INTEGER
!>          Especifica el tipo de problema a resolver:
!>          = 1:  A*x = (lambda)*B*x
!>          = 2:  A*B*x = (lambda)*x
!>          = 3:  B*A*x = (lambda)*x
!>

JOBZ

!>          JOBZ es CHARACTER*1
!>          = 'N':  Calcular solo los valores propios;
!>          = 'V':  Calcular valores propios y vectores propios.
!>

RANGE

!>          RANGE es CHARACTER*1
!>          = 'A': se encontrarán todos los valores propios.
!>          = 'V': se encontrarán todos los valores propios en el intervalo semiabierto (VL,VU]
!>                 .
!>          = 'I': se encontrarán los valores propios desde el IL-ésimo hasta el IU-ésimo.
!>

UPLO

!>          UPLO es CHARACTER*1
!>          = 'U':  Se almacenan las formas triangulares superior de A y B;
!>          = 'L':  Se almacenan las formas triangulares inferior de A y B.
!>

N

!>          N es INTEGER
!>          El orden de las matrices A y B.  N >= 0.
!>

A

!>          A es una matriz COMPLEX*16, de dimensión (LDA, N)
!>          En la entrada, la matriz Hermitiana A. Si UPLO = 'U', la
!>          parte triangular superior N por N de A contiene la
!>          parte triangular superior de la matriz A. Si UPLO = 'L',
!>          la parte triangular inferior N por N de A contiene
!>          la parte triangular inferior de la matriz A.
!>
!>          En la salida, el triángulo inferior (si UPLO='L') o el triángulo
!>          superior (si UPLO='U') de A, incluyendo la diagonal, es
!>          destruido.
!>

LDA

!>          LDA es INTEGER
!>          La dimensión principal de la matriz A.  LDA >= max(1,N).
!>

B

!>          B es una matriz COMPLEX*16, de dimensión (LDB, N)
!>          En la entrada, la matriz Hermitiana B. Si UPLO = 'U', la
!>          parte triangular superior N por N de B contiene la
!>          parte triangular superior de la matriz B. Si UPLO = 'L',
!>          la parte triangular inferior N por N de B contiene
!>          la parte triangular inferior de la matriz B.
!>
!>          En la salida, si INFO <= N, la parte de B que contiene la matriz se
!>          sobrescribe con el factor triangular U o L de la factorización de Cholesky
!>          B = U**H*U o B = L*L**H.
!>

LDB

!>          LDB es INTEGER
!>          La dimensión principal de la matriz B.  LDB >= max(1,N).
!>

VL

!>          VL es DOUBLE PRECISION
!>
!>          Si RANGE='V', el límite inferior del intervalo a
!>          buscar para los valores propios. VL < VU.
!>          No se utiliza si RANGE = 'A' o 'I'.
!>

VU

!>          VU es DOUBLE PRECISION
!>
!>          Si RANGE='V', el límite superior del intervalo a
!>          buscar para los valores propios. VL < VU.
!>          No se utiliza si RANGE = 'A' o 'I'.
!>

IL

!>          IL es INTEGER
!>
!>          Si RANGE='I', el índice del
!>          valor propio más pequeño a devolver.
!>          1 <= IL <= IU <= N, si N > 0; IL = 1 e IU = 0 si N = 0.
!>          No se utiliza si RANGE = 'A' o 'V'.
!>

IU

!>          IU es INTEGER
!>
!>          Si RANGE='I', el índice del
!>          valor propio más grande a devolver.
!>          1 <= IL <= IU <= N, si N > 0; IL = 1 e IU = 0 si N = 0.
!>          No se utiliza si RANGE = 'A' o 'V'.
!>

ABSTOL

!>          ABSTOL es DOUBLE PRECISION
!>          La tolerancia de error absoluto para los valores propios.
!>          Se acepta un valor propio aproximado como convergente
!>          cuando se determina que yace en un intervalo [a,b]
!>          de ancho menor o igual a
!>
!>                  ABSTOL + EPS *   max( |a|,|b| ) ,
!>
!>          donde EPS es la precisión de la máquina. Si ABSTOL es menor o
!>          igual a cero, entonces EPS*|T| será utilizado en su lugar,
!>          donde |T| es la norma 1 de la matriz tridiagonal obtenida
!>          al reducir C a forma tridiagonal, donde C es la matriz simétrica
!>          del problema simétrico estándar al que se transforma
!>          el problema generalizado.
!>
!>          Los valores propios se calcularán de forma más precisa cuando ABSTOL
!>          se establezca en el doble del umbral de subdesbordamiento 2*DLAMCH('S'), no cero.
!>          Si esta rutina retorna con INFO>0, indicando que algunos
!>          vectores propios no convergieron, intente establecer ABSTOL en
!>          2*DLAMCH('S').
!>

M

!>          M es INTEGER
!>          El número total de valores propios encontrados.  0 <= M <= N.
!>          Si RANGE = 'A', M = N, y si RANGE = 'I', M = IU-IL+1.
!>

W

!>          W es una matriz DOUBLE PRECISION, de dimensión (N)
!>          Los primeros M elementos contienen los valores propios
!>          seleccionados en orden ascendente.
!>

Z

!>          Z es una matriz COMPLEX*16, de dimensión (LDZ, max(1,M))
!>          Si JOBZ = 'N', entonces Z no se utiliza.
!>          Si JOBZ = 'V', entonces si INFO = 0, las primeras M columnas de Z
!>          contienen los vectores propios ortonormales de la matriz A
!>          correspondientes a los valores propios seleccionados, con la i-ésima
!>          columna de Z conteniendo el vector propio asociado con W(i).
!>          Los vectores propios se normalizan de la siguiente manera:
!>          si ITYPE = 1 o 2, Z**T*B*Z = I;
!>          si ITYPE = 3, Z**T*inv(B)*Z = I.
!>
!>          Si un vector propio falla en converger, entonces esa columna de Z
!>          contiene la última aproximación al vector propio, y el
!>          índice del vector propio se devuelve en IFAIL.
!>          Nota: el usuario debe asegurarse de que se proporcionan al menos max(1,M) columnas
!>          en la matriz Z; si RANGE = 'V', el valor exacto de M
!>          no se conoce de antemano y se debe usar un límite superior.
!>

LDZ

!>          LDZ es INTEGER
!>          La dimensión principal de la matriz Z.  LDZ >= 1, y si
!>          JOBZ = 'V', LDZ >= max(1,N).
!>

WORK

!>          WORK es una matriz COMPLEX*16, de dimensión

zhegvx.3 - LAPACK

NAME

zhegvx - ZHEGVX computes the eigenvalues and eigenvectors of a complex Hermitian-positive definite generalized eigenvalue problem.

SYNOPSIS

  SUBROUTINE ZHEGVX( JOBZ, RANGE, UPLO, N, A, LDA, B, LDB, VL, VU, IL, IU,
                 ABSTOL, M, W, Z, LDZ, WORK, LWORK, RWORK, IWORK, IFAIL,
                 INFO )
    CHARACTER JOBZ, RANGE, UPLO
    INTEGER IL, IU, LDA, LDB, LDZ, INFO, N, M, LWORK
    INTEGER IWORK( * ), IFAIL( * )
    DOUBLE PRECISION VL, VU, ABSTOL
    DOUBLE COMPLEX A( LDA, * ), B( LDB, * ), Z( LDZ, * )
    DOUBLE PRECISION W( * ), RWORK( * )
    DOUBLE COMPLEX WORK( * )

Function/Subroutine Documentation

ZHEGVX is part of the LAPACK routines that compute the eigenvalues and eigenvectors of the generalized eigenvalue problem A*z = lambda*B*z, where A and B are complex Hermitian matrices, and B is positive definite.

Arguments

JOBZ
CHARACTER*1
Must be either 'V' or 'N'.
If JOBZ = 'V', then the eigenvectors are computed.
If JOBZ = 'N', then only the eigenvalues are computed.
RANGE
CHARACTER*1
Must be either 'A', 'V', or 'I'.
If RANGE = 'A', then all eigenvalues will be computed.
If RANGE = 'V', then the computed eigenvalues lambda will be in the range VL < lambda < VU.
If RANGE = 'I', then the eigenvalues with indices IL to IU will be computed.
UPLO
CHARACTER*1
Must be either 'U' or 'L'.
If UPLO = 'U', then the upper triangle of A and B will be used.
If UPLO = 'L', then the lower triangle of A and B will be used.
N
INTEGER
The order of the matrices A and B. N >= 0.
A
COMPLEX*16 array, dimension (LDA, N)
On entry, the complex Hermitian matrix A.
On exit, if JOBZ = 'V', then A is overwritten by details of its factorization.
LDA
INTEGER
The leading dimension of the array A. LDA >= max(1,N).
B
COMPLEX*16 array, dimension (LDB, N)
On entry, the complex Hermitian positive definite matrix B.
On exit, if JOBZ = 'V', then B is overwritten by details of its factorization.
LDB
INTEGER
The leading dimension of the array B. LDB >= max(1,N).
VL
DOUBLE PRECISION
If RANGE = 'V', the lower bound of the range for eigenvalues.
If RANGE = 'A' or 'I', VL is not used.
VU
DOUBLE PRECISION
If RANGE = 'V', the upper bound of the range for eigenvalues.
If RANGE = 'A' or 'I', VU is not used.
IL
INTEGER
If RANGE = 'I', the index of the smallest eigenvalue to be computed.
If RANGE = 'A' or 'V', IL is not used.
IU
INTEGER
If RANGE = 'I', the index of the largest eigenvalue to be computed.
If RANGE = 'A' or 'V', IU is not used.
ABSTOL
DOUBLE PRECISION
Absolute tolerance for computing eigenvalues. Use ABSTOL = 0.0 to use the default value.
M
INTEGER
The total number of eigenvalues found.
If RANGE = 'A', M = N.
If RANGE = 'I', M = IU - IL + 1.
If RANGE = 'V', M is the number of eigenvalues in the range.
W
DOUBLE PRECISION array, dimension (N)
On exit, the computed eigenvalues, in the order W(I) <= W(I+1).
Z
COMPLEX*16 array, dimension (LDZ, max(1,N))
On exit, if JOBZ = 'V', the normalized (unit length) eigenvectors, such that the value of the j-th column of Z satisfies
A*z = lambda*B*z, where lambda = W(j).
If the j-th eigenvalue is computed within a loop (RANGE = 'I' or 'V'), then the column Z(j) is the corresponding eigenvector. If JOBZ = 'N', then Z is not accessed.
LDZ
INTEGER
The leading dimension of the array Z. LDZ >= max(1,N).
WORK
COMPLEX*16 array, dimension (LWORK)
On exit, if INFO = 0 and JOBZ = 'V', then WORK(1) returns the optimal LWORK.
LWORK
INTEGER
The length of the array WORK. LWORK >= max(1,2*N).
For optimal efficiency, LWORK >= (NB+1)*N, where NB is the blocksize for ZHETRD returned by ILAENV.
If LWORK = -1, then a workspace query is assumed; the routine only calculates the optimal size of the WORK array, returns this value as the first entry of the WORK array, and no error message related to LWORK is issued by XERBLA.
RWORK
DOUBLE PRECISION array, dimension (7*N)
IWORK
INTEGER array, dimension (5*N)
IFAIL
INTEGER array, dimension (N)
If JOBZ = 'V', then if INFO = 0, the first M elements of IFAIL are zero. If INFO > 0, then IFAIL contains the indices of the eigenvectors that failed to converge.
If JOBZ = 'N', then IFAIL is not referenced.
INFO
INTEGER
  • 0: successful exit
  • < 0: if INFO = -i, the i-th argument had an illegal value
  • > 0: ZPOTRF or ZHEEVX returned an error code:
  • <= N: if INFO = i, ZHEEVX failed to converge; i eigenvectors failed to converge. Their indices are stored in array IFAIL.
  • > N: if INFO = N + i, for 1 <= i <= N, then the leading principal minor of order i of B is not positive. The factorization of B could not be completed and no eigenvalues or eigenvectors were computed.
