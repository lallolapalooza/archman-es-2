subrutina zhfrk (transr, uplo, trans, n, k, alpha, a, lda, beta, c)

ZHFRK realiza una operación Hermitiana de rango-k para matrices en formato RFP.

DOCUMENTACIÓN DE FUNCIÓN/SUBRUTINA

subrutina zhfrk (character transr, character uplo, character trans, integer n, integer k, double precision alpha, complex*16, dimension( lda, * ) a, integer lda, double precision beta, complex*16, dimension( * ) c)

ZHFRK realiza una operación Hermitiana de rango-k para matrices en formato RFP.

Propósito:

!>
!> Procedimiento similar a BLAS de Nivel 3 para C en Formato RFP.
!>
!> ZHFRK realiza una de las operaciones Hermitiana de rango-k
!>
!>    C := alpha*A*A**H,
!>
!> o
!>
!>    C := alpha*A**H*A + beta*C,
!>
!> donde alpha y beta son escalares reales, C es una matriz Hermitiana n--por--n
!> y A es una matriz n--por--k en el primer caso y una matriz k--por--n
!> en el segundo caso.
!>

Parámetros

TRANSR 
!>          TRANSR es CHARACTER*1
!>          = 'N':  Se almacena la Forma Normal de RFP A;
!>          = 'C':  Se almacena la Forma Transpuesta Conjugada de RFP A.
!>

UPLO

!>          UPLO es CHARACTER*1
!>           En la entrada, UPLO especifica si la parte triangular superior o inferior
!>           del array C se hará referencia según lo siguiente:
!>
!>              UPLO = 'U' o 'u'   Sólo se hará referencia a la parte triangular superior de C.
!>
!>              UPLO = 'L' o 'l'   Sólo se hará referencia a la parte triangular inferior de C.
!>
!>           Sin cambios a la salida.
!>

TRANS

!>          TRANS es CHARACTER*1
!>           En la entrada, TRANS especifica la operación a realizar de la siguiente manera:
!>
!>              TRANS = 'N' o 'n'   C := alpha*A*A**H + beta*C.
!>
!>              TRANS = 'C' o 'c'   C := alpha*A**H*A + beta*C.
!>
!>           Sin cambios a la salida.
!>

N

!>          N es INTEGER
!>           En la entrada, N especifica el orden de la matriz C. N debe ser
!>           al menos cero.
!>           Sin cambios a la salida.
!>

K

!>          K es INTEGER
!>           En la entrada con TRANS = 'N' o 'n', K especifica el número
!>           de columnas de la matriz A, y en la entrada con
!>           TRANS = 'C' o 'c', K especifica el número de filas de la
!>           matriz A. K debe ser al menos cero.
!>           Sin cambios a la salida.
!>

ALPHA

!>          ALPHA es DOUBLE PRECISION
!>           En la entrada, ALPHA especifica el escalar alpha.
!>           Sin cambios a la salida.
!>

A

!>          A es un array COMPLEX*16, dimension (LDA, ka)
!>           donde ka
!>           es K cuando TRANS = 'N' o 'n', y es N en caso contrario. Antes
!>           de la entrada con TRANS = 'N' o 'n', la parte líder N--por--K
!>           del array A debe contener la matriz A, de lo contrario, la parte líder
!>           K--por--N del array A debe contener la matriz A.
!>           Sin cambios a la salida.
!>

LDA

!>          LDA es INTEGER
!>           En la entrada, LDA especifica la primera dimensión de A tal como se declara
!>           en el programa (sub)llamador. Cuando TRANS = 'N' o 'n',
!>           entonces LDA debe ser al menos max( 1, n ), en caso contrario LDA debe
!>           ser al menos max( 1, k ).
!>           Sin cambios a la salida.
!>

BETA

!>          BETA es DOUBLE PRECISION
!>           En la entrada, BETA especifica el escalar beta.
!>           Sin cambios a la salida.
!>

C

!>          C es un array COMPLEX*16, dimension (N*(N+1)/2)
!>           En la entrada, la matriz A en formato RFP. El formato RFP se
!>           describe mediante TRANSR, UPLO y N. Tenga en cuenta que las partes imaginarias
!>           de los elementos diagonales no necesitan ser establecidas, se
!>           asumen que son cero, y a la salida se establecen a cero.
!>
