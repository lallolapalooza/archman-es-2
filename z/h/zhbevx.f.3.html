ZHBEVX calcula los valores propios y, opcionalmente, los vectores propios izquierdos y/o derechos para OTRAS matrices

Propósito:

!>
!> ZHBEVX calcula valores propios seleccionados y, opcionalmente, vectores propios
!> de una matriz de banda hermitiana compleja A. Los valores y vectores propios
!> pueden ser seleccionados especificando un rango de valores o un rango de
!> índices para los valores propios deseados.
!>

Parámetros

JOBZ 
!>          JOBZ es CHARACTER*1
!>          = 'N':  Calcula solo los valores propios;
!>          = 'V':  Calcula los valores propios y los vectores propios.
!>

RANGE

!>          RANGE es CHARACTER*1
!>          = 'A': se encontrarán todos los valores propios;
!>          = 'V': se encontrarán todos los valores propios en el intervalo semiabierto (VL,VU];
!>          = 'I': se encontrarán los valores propios del IL-ésimo al IU-ésimo.
!>

UPLO

!>          UPLO es CHARACTER*1
!>          = 'U':  El triángulo superior de A está almacenado;
!>          = 'L':  El triángulo inferior de A está almacenado.
!>

N

!>          N es INTEGER
!>          El orden de la matriz A. N >= 0.
!>

KD

!>          KD es INTEGER
!>          El número de superdiagonales de la matriz A si UPLO = 'U',
!>          o el número de subdiagonales si UPLO = 'L'. KD >= 0.
!>

AB

!>          AB es array COMPLEX*16, dimensión (LDAB, N)
!>          En la entrada, el triángulo superior o inferior de la matriz de banda hermitiana
!>          A, almacenado en las primeras KD+1 filas del array. La
!>          columna j de A se almacena en la columna j del array AB
!>          de la siguiente manera:
!>          si UPLO = 'U', AB(kd+1+i-j,j) = A(i,j) para max(1,j-kd)<=i<=j;
!>          si UPLO = 'L', AB(1+i-j,j)    = A(i,j) para j<=i<=min(n,j+kd).
!>
!>          En la salida, AB se sobrescribe con valores generados durante la
!>          reducción a forma tridiagonal.
!>

LDAB

!>          LDAB es INTEGER
!>          La dimensión principal del array AB. LDAB >= KD + 1.
!>

Q

!>          Q es array COMPLEX*16, dimensión (LDQ, N)
!>          Si JOBZ = 'V', la matriz unitaria N por N utilizada en la
!>                          reducción a forma tridiagonal.
!>          Si JOBZ = 'N', el array Q no se referencia.
!>

LDQ

!>          LDQ es INTEGER
!>          La dimensión principal del array Q. Si JOBZ = 'V', entonces
!>          LDQ >= max(1,N).
!>

VL

!>          VL es DOUBLE PRECISION
!>          Si RANGE='V', el límite inferior del intervalo a
!>          buscar para los valores propios. VL < VU.
!>          No se referencia si RANGE = 'A' o 'I'.
!>

VU

!>          VU es DOUBLE PRECISION
!>          Si RANGE='V', el límite superior del intervalo a
!>          buscar para los valores propios. VL < VU.
!>          No se referencia si RANGE = 'A' o 'I'.
!>

IL

!>          IL es INTEGER
!>          Si RANGE='I', el índice del
!>          valor propio más pequeño a devolver.
!>          1 <= IL <= IU <= N, si N > 0; IL = 1 y IU = 0 si N = 0.
!>          No se referencia si RANGE = 'A' o 'V'.
!>

IU

!>          IU es INTEGER
!>          Si RANGE='I', el índice del
!>          valor propio más grande a devolver.
!>          1 <= IL <= IU <= N, si N > 0; IL = 1 y IU = 0 si N = 0.
!>          No se referencia si RANGE = 'A' o 'V'.
!>

ABSTOL

!>          ABSTOL es DOUBLE PRECISION
!>          La tolerancia de error absoluto para los valores propios.
!>          Un valor propio aproximado se acepta como convergido
!>          cuando se determina que se encuentra en un intervalo [a,b]
!>          de anchura menor o igual a
!>
!>                  ABSTOL + EPS *   max( |a|,|b| ) ,
!>
!>          donde EPS es la precisión de la máquina. Si ABSTOL es menor o
!>          igual a cero, entonces EPS*|T| se usará en su lugar,
!>          donde |T| es la norma 1 de la matriz tridiagonal obtenida
!>          al reducir AB a forma tridiagonal.
!>
!>          Los valores propios se calcularán con mayor precisión cuando ABSTOL
!>          se establezca en el doble del umbral de desbordamiento inferior 2*DLAMCH('S'), no cero.
!>          Si esta rutina retorna con INFO>0, indicando que algunos
!>          vectores propios no convergieron, intente establecer ABSTOL en
!>          2*DLAMCH('S').
!>
!>          Ver  por Demmel y
!>          Kahan, LAPACK Working Note #3.
!>

M

!>          M es INTEGER
!>          El número total de valores propios encontrados. 0 <= M <= N.
!>          Si RANGE = 'A', M = N, y si RANGE = 'I', M = IU-IL+1.
!>

W

!>          W es array DOUBLE PRECISION, dimensión (N)
!>          Los primeros M elementos contienen los valores propios seleccionados en
!>          orden ascendente.
!>

Z

!>          Z es array COMPLEX*16, dimensión (LDZ, max(1,M))
!>          Si JOBZ = 'V', entonces si INFO = 0, las primeras M columnas de Z
!>          contienen los vectores propios ortonormales de la matriz A
!>          correspondientes a los valores propios seleccionados, con la i-ésima
!>          columna de Z conteniendo el vector propio asociado con W(i).
!>          Si un vector propio no converge, entonces esa columna de Z
!>          contiene la última aproximación al vector propio, y el
!>          índice del vector propio se devuelve en IFAIL.
!>          Si JOBZ = 'N', entonces Z no se referencia.
!>          Nota: el usuario debe asegurarse de que se suministran al menos max(1,M) columnas
!>          en el array Z; si RANGE = 'V', el valor exacto de M
!>          no se conoce de antemano y se debe usar un límite superior.
!>

LDZ

!>          LDZ es INTEGER
!>          La dimensión principal del array Z. LDZ >= 1, y si
!>          JOBZ = 'V', LDZ >= max(1,N).
!>

WORK

!>          WORK es array COMPLEX*16, dimensión (N)
!>

RWORK

!>          RWORK es array DOUBLE PRECISION, dimensión (7*N)
!>

IWORK

!>          IWORK es array INTEGER, dimensión (5*N)
!>

IFAIL

!>          IFAIL es array INTEGER, dimensión (N)
!>          Si JOBZ = 'V', entonces si INFO = 0, los primeros M elementos de
!>          IFAIL son cero. Si INFO > 0, entonces IFAIL contiene los
!>          índices de los vectores propios que fallaron en converger.
!>          Si JOBZ = 'N', entonces IFAIL no se referencia.
!>

INFO

!>          INFO es INTEGER
!>          = 0: éxito.
!>          > 0:  si INFO = i, entonces i eigenvectors no convergieron. Los índices
!>              de estos vectores propios se encuentran en IFAIL.
!>

NAME

zhbevx -
zhbevx is a subroutine that computes the eigenvectors and eigenvalues of a complex Hermitian banded matrix.

SYNOPSIS

    SUBROUTINE ZHBEVX(
        JOBZ, RANGE, UPLO, N, KD, AB, LDAB, Q, LDQ, VL, VU, IL, IU,
        ABSRT, TOL, M, NZ, V, LDV, WORK, RWORK, IWORK, IFAIL, INFO
    )

Parameters:

JOBZ
CHARACTER*1

Specifies whether to compute the eigenvectors:

  • 'N': Compute only the eigenvalues.
  • 'V': Compute the eigenvalues and eigenvectors.
    RANGE
    CHARACTER*1

    Specifies the range of eigenvalues to be computed:

    • 'A': All eigenvalues will be computed.
  • 'V': All eigenvalues between VL and VU will be computed.
  • 'I': The IL-th to IU-th eigenvalues will be computed.
    UPLO
    CHARACTER*1

    Specifies whether the matrix is upper or lower banded:

    • 'U': Upper banded.
  • 'L': Lower banded.
    N
    INTEGER

    Order of the matrix A. 0 <= N.

    KD
    INTEGER

    The number of super- or sub-diagonals of the matrix A. 0 <= KD.

    AB
    COMPLEX*16 array, dimension (LDAB, N)

    On entry, the upper or lower banded part of the Hermitian band matrix A, stored in rows 1 to KD+1. More precisely, if UPLO = 'U', AB(i, j) is stored for 1 <= i <= kd+1 and i <= j <= n. If UPLO = 'L', AB(i, j) is stored for 1 <= j <= kd+1 and j <= i <= n. See “Notes” for more detail.

    LDAB
    INTEGER

    Leading dimension of the array AB. LDAB >= KD + 1.

    Q
    COMPLEX*16 array, dimension (LDQ, N)

    On exit, the unitary matrix Q having the eigenvectors as columns. If JOBZ = 'N', Q is not used.

    LDQ
    INTEGER

    Leading dimension of the array Q. If JOBZ = 'V', LDQ >= max(1, N). Required only if JOBZ = 'V'.

    VL
    DOUBLE PRECISION

    If RANGE = 'V', the lower bound of the eigenvalue range.

    VU
    DOUBLE PRECISION

    If RANGE = 'V', the upper bound of the eigenvalue range.

    IL
    INTEGER

    If RANGE = 'I', the index of the smallest eigenvalue to be computed.

    IU
    INTEGER

    If RANGE = 'I', the index of the largest eigenvalue to be computed.

    ABSRT
    DOUBLE PRECISION

    Absolute tolerance for the eigenvalues. If TOL is negative, the tolerance is set to the machine precision.

    TOL
    DOUBLE PRECISION

    Relative tolerance for the eigenvalues. If TOL is negative, the tolerance is set to the machine precision.

    M
    INTEGER

    On exit, the total number of eigenvalues found.

    NZ
    INTEGER

    On exit, the number of eigenvectors computed. If JOBZ = 'N', NZ is zero.

    V
    COMPLEX*16 array, dimension (LDV, max(M, 1))

    On exit, the computed eigenvectors, with the i-th column corresponding to the i-th eigenvalue in the array ABSRT (if these are computed). The vector is normalized so the squared Euclidean norm is 1. Only returned if JOBZ = 'V'.

    LDV
    INTEGER

    Leading dimension of the array V. If JOBZ = 'V', LDV >= max(1, N). Required only if JOBZ = 'V'.

    WORK
    COMPLEX*16 array, dimension (max(1, 2*N)).
    RWORK
    DOUBLE PRECISION array, dimension (max(1, 8*N)).
    IWORK
    INTEGER array, dimension (max(1, 5*N)).
    IFAIL
    INTEGER array, dimension (N)

    On exit, IFAIL(i) is the index of the i-th eigenvector that failed to converge. Only relevant if INFO > 0.

    INFO
    INTEGER

    Output Information:

    • 0: successful exit.
  • < 0: if INFO = -i, then the i-th argument had an illegal value.
  • > 0: if INFO = i, then i eigenvectors failed to converge. Their indices are stored in array IFAIL.
