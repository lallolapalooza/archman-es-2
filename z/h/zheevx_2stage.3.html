DOCUMENTACIÓN DE FUNCIÓN/SUBRUTINA

subroutine zheevx_2stage (character jobz, character range, character uplo, integer n, complex*16, dimension( lda, * ) a, integer lda, double precision vl, double precision vu, integer il, integer iu, double precision abstol, integer m, double precision, dimension( * ) w, complex*16, dimension( ldz, * ) z, integer ldz, complex*16, dimension( * ) work, integer lwork, double precision, dimension( * ) rwork, integer, dimension( * ) iwork, integer, dimension( * ) ifail, integer info)

ZHEEVX_2STAGE calcula los valores propios y, opcionalmente, los vectores propios de una matriz Hermítica compleja A utilizando la técnica de 2 etapas para la reducción a tridiagonal. Los valores y vectores propios se pueden seleccionar especificando un rango de valores o un rango de índices para los valores propios deseados.

Propósito:

!>
!> ZHEEVX_2STAGE calcula valores propios seleccionados y, opcionalmente, vectores
!> propios de una matriz Hermítica compleja A utilizando la técnica de 2 etapas
!> para la reducción a tridiagonal. Los valores propios y vectores propios pueden
!> ser seleccionados especificando un rango de valores o un rango de
!> índices para los valores propios deseados.
!>

Parámetros

JOBZ 
!>          JOBZ es CHARACTER*1
!>          = 'N':  Calcula solo los valores propios;
!>          = 'V':  Calcula los valores propios y vectores propios.
!>                  No disponible en esta versión.
!>

RANGE

!>          RANGE es CHARACTER*1
!>          = 'A': se encontrarán todos los valores propios.
!>          = 'V': se encontrarán todos los valores propios en el intervalo semiabierto (VL,VU]
!>                 se encontrarán.
!>          = 'I': se encontrarán los valores propios desde el IL-ésimo hasta el IU-ésimo.
!>

UPLO

!>          UPLO es CHARACTER*1
!>          = 'U':  El triángulo superior de A está almacenado;
!>          = 'L':  El triángulo inferior de A está almacenado.
!>

N

!>          N es INTEGER
!>          El orden de la matriz A.  N >= 0.
!>

A

!>          A es un array COMPLEX*16, dimensión (LDA, N)
!>          En la entrada, la matriz Hermítica A. Si UPLO = 'U', la
!>          parte triangular superior N por N principal de A contiene la
!>          parte triangular superior de la matriz A. Si UPLO = 'L',
!>          la parte triangular inferior N por N principal de A contiene la
!>          parte triangular inferior de la matriz A.
!>          En la salida, el triángulo inferior (si UPLO='L') o el triángulo
!>          superior (si UPLO='U') de A, incluyendo la diagonal, se destruye.
!>

LDA

!>          LDA es INTEGER
!>          La dimensión principal del array A.  LDA >= max(1,N).
!>

VL

!>          VL es DOUBLE PRECISION
!>          Si RANGE='V', el límite inferior del intervalo a
!>          buscar para los valores propios. VL < VU.
!>          No referenciado si RANGE = 'A' o 'I'.
!>

VU

!>          VU es DOUBLE PRECISION
!>          Si RANGE='V', el límite superior del intervalo a
!>          buscar para los valores propios. VL < VU.
!>          No referenciado si RANGE = 'A' o 'I'.
!>

IL

!>          IL es INTEGER
!>          Si RANGE='I', el índice del
!>          valor propio más pequeño a devolver.
!>          1 <= IL <= IU <= N, si N > 0; IL = 1 e IU = 0 si N = 0.
!>          No referenciado si RANGE = 'A' o 'V'.
!>

IU

!>          IU es INTEGER
!>          Si RANGE='I', el índice del
!>          valor propio más grande a devolver.
!>          1 <= IL <= IU <= N, si N > 0; IL = 1 e IU = 0 si N = 0.
!>          No referenciado si RANGE = 'A' o 'V'.
!>

ABSTOL

!>          ABSTOL es DOUBLE PRECISION
!>          La tolerancia de error absoluta para los valores propios.
!>          Un valor propio aproximado se acepta como convergente
!>          cuando se determina que yace en un intervalo [a,b]
!>          de ancho menor o igual que
!>
!>                  ABSTOL + EPS *   max( |a|,|b| ) ,
!>
!>          donde EPS es la precisión de la máquina. Si ABSTOL es menor que
!>          o igual a cero, entonces EPS*|T| se usará en su lugar,
!>          donde |T| es la norma 1 de la matriz tridiagonal obtenida
!>          al reducir A a forma tridiagonal.
!>
!>          Los valores propios se calcularán con mayor precisión cuando ABSTOL sea
!>          establecido en el doble del umbral de subdesbordamiento 2*DLAMCH('S'), no cero.
!>          Si esta rutina retorna con INFO>0, indicando que algunos
!>          vectores propios no convergieron, intente establecer ABSTOL a
!>          2*DLAMCH('S').
!>
!>          Ver  por Demmel y
!>          Kahan, Nota de Trabajo LAPACK #3.
!>

M

!>          M es INTEGER
!>          El número total de valores propios encontrados.  0 <= M <= N.
!>          Si RANGE = 'A', M = N, y si RANGE = 'I', M = IU-IL+1.
!>

W

!>          W es un array DOUBLE PRECISION, dimensión (N)
!>          En salida normal, los primeros M elementos contienen los valores propios
!>          seleccionados en orden ascendente.
!>

Z

!>          Z es un array COMPLEX*16, dimensión (LDZ, max(1,M))
!>          Si JOBZ = 'V', entonces si INFO = 0, las primeras M columnas de Z
!>          contienen los vectores propios ortonormales de la matriz A
!>          correspondientes a los valores propios seleccionados, con la i-ésima
!>          columna de Z conteniendo el vector propio asociado con W(i).
!>          Si un vector propio falla en converger, entonces esa columna de Z
!>          contiene la última aproximación al vector propio, y el
!>          índice del vector propio se devuelve en IFAIL.
!>          Si JOBZ = 'N', entonces Z no se referencia.
!>          Nota: el usuario debe asegurarse de que se suministran al menos max(1,M) columnas
!>          en el array Z; si RANGE = 'V', el valor exacto de M
!>          no se conoce de antemano y se debe usar un límite superior.
!>

LDZ

!>          LDZ es INTEGER
!>          La dimensión principal del array Z.  LDZ >= 1, y si
!>          JOBZ = 'V', LDZ >= max(1,N).
!>

WORK

!>          WORK es un array COMPLEX*16, dimensión (MAX(1,LWORK))
!>          En salida, si INFO = 0, WORK(1) devuelve el LWORK óptimo.
!>

LWORK

!>          LWORK es INTEGER
!>          La longitud del array WORK. LWORK >= 1, cuando N <= 1;
!>          de lo contrario
!>          Si JOBZ = 'N' y N > 1, LWORK debe ser consultado.
!>                                   LWORK = MAX(1, 8*N, dimension) donde
!>                                   dimension = max(stage1,stage2) + (KD+1)*N + N
!>                                             = N*KD + N*max(KD+1,FACTOPTNB)
!>                                               + max(2*KD*KD, KD*NTHREADS)
!>                                               + (KD+1)*N + N
!>                                   donde KD es el tamaño del bloque de la reducción,
!>                                   FACTOPTNB es el tamaño del bloque utilizado por el
!>                                   algoritmo QR o LQ, usualmente FACTOPTNB=128 es una buena elección
!>                                   NTHREADS es el número de hilos utilizados cuando
!>                                   la compilación openMP está habilitada, de lo contrario =1.
!>          Si JOBZ = 'V' y N > 1, LWORK debe ser consultado. Aún no disponible
!>
!>          Si LWORK = -1, entonces se asume una consulta de espacio de trabajo; la rutina
!&g
t; solo calcula el tamaño óptimo del array WORK, devuelve !> este valor como la primera entrada del array WORK y no se emite ningún mensaje de error !> relacionado con LWORK por XERBLA. !>

RWORK

!>          RWORK es un array de DOUBLE PRECISION, con dimensión (7*N)
!>

IWORK

!>          IWORK es un array de INTEGER, con dimensión (5*N)
!>

IFAIL

!>          IFAIL es un array de INTEGER, con dimensión (N)
!>          Si JOBZ = 'V', entonces si INFO = 0, los primeros M elementos de
!>          IFAIL son cero. Si INFO > 0, entonces IFAIL contiene los
!>          índices de los autovectores que no convergieron.
!>          Si JOBZ = 'N', entonces IFAIL no se referencia.
!>

INFO

!>          INFO es un INTEGER
!>          = 0:  salida exitosa
!>          < 0:  si INFO = -i, el i-ésimo argumento tenía un valor ilegal
!>          > 0:  si INFO = i, entonces i autovectores no convergieron.
!>                Sus índices están almacenados en el array IFAIL.
!>
