Documentación de la función/subrutina

subrutina zhpgv (integer itype, character jobz, character uplo, integer n, complex*16, dimension( * ) ap, complex*16, dimension( * ) bp, double precision, dimension( * ) w, complex*16, dimension( ldz, * ) z, integer ldz, complex*16, dimension( * ) work, double precision, dimension( * ) rwork, integer info)

ZHPGV

Propósito:

!>
!> ZHPGV calcula todos los valores propios y, opcionalmente, los vectores propios
!> de un problema de eigenvalor Hermítico-definido general complejo, de la forma
!> A*x=(lambda)*B*x,  A*Bx=(lambda)*x,  o B*A*x=(lambda)*x.
!> Aquí se asume que A y B son Hermíticos, almacenados en formato empaquetado,
!> y B también es positivo definido.
!>

Parámetros

ITYPE 
!>          ITYPE es INTEGER
!>          Especifica el tipo de problema a resolver:
!>          = 1:  A*x = (lambda)*B*x
!>          = 2:  A*B*x = (lambda)*x
!>          = 3:  B*A*x = (lambda)*x
!>

JOBZ

!>          JOBZ es CHARACTER*1
!>          = 'N':  Calcular solo los valores propios;
!>          = 'V':  Calcular valores propios y vectores propios.
!>

UPLO

!>          UPLO es CHARACTER*1
!>          = 'U':  Se almacenan los triángulos superiores de A y B;
!>          = 'L':  Se almacenan los triángulos inferiores de A y B.
!>

N

!>          N es INTEGER
!>          El orden de las matrices A y B.  N >= 0.
!>

AP

!>          AP es un array COMPLEX*16, dimensión (N*(N+1)/2)
!>          En la entrada, el triángulo superior o inferior de la matriz Hermítica
!>          A, empaquetado por columnas en un array lineal. La j-ésima columna de A
!>          se almacena en el array AP de la siguiente manera:
!>          si UPLO = 'U', AP(i + (j-1)*j/2) = A(i,j) para 1<=i<=j;
!>          si UPLO = 'L', AP(i + (j-1)*(2*n-j)/2) = A(i,j) para j<=i<=n.
!>
!>          En la salida, el contenido de AP se destruye.
!>

BP

!>          BP es un array COMPLEX*16, dimensión (N*(N+1)/2)
!>          En la entrada, el triángulo superior o inferior de la matriz Hermítica
!>          B, empaquetado por columnas en un array lineal. La j-ésima columna de B
!>          se almacena en el array BP de la siguiente manera:
!>          si UPLO = 'U', BP(i + (j-1)*j/2) = B(i,j) para 1<=i<=j;
!>          si UPLO = 'L', BP(i + (j-1)*(2*n-j)/2) = B(i,j) para j<=i<=n.
!>
!>          En la salida, se almacena el factor triangular U o L de la
!>          factorización de Cholesky B = U**H*U o B = L*L**H, en el mismo formato
!>          de almacenamiento que B.
!>

W

!>          W es un array DOUBLE PRECISION, dimensión (N)
!>          Si INFO = 0, los valores propios en orden ascendente.
!>

Z

!>          Z es un array COMPLEX*16, dimensión (LDZ, N)
!>          Si JOBZ = 'V', entonces si INFO = 0, Z contiene la matriz Z de
!>          vectores propios. Los vectores propios se normalizan de la siguiente manera:
!>          si ITYPE = 1 o 2, Z**H*B*Z = I;
!>          si ITYPE = 3, Z**H*inv(B)*Z = I.
!>          Si JOBZ = 'N', entonces Z no se referencia.
!>

LDZ

!>          LDZ es INTEGER
!>          La dimensión principal del array Z.  LDZ >= 1, y si
!>          JOBZ = 'V', LDZ >= max(1,N).
!>

WORK

!>          WORK es un array COMPLEX*16, dimensión (max(1, 2*N-1))
!>

RWORK

!>          RWORK es un array DOUBLE PRECISION, dimensión (max(1, 3*N-2))
!>

INFO

!>          INFO es INTEGER
!>          = 0:  salida exitosa
!>          < 0:  si INFO = -i, el i-ésimo argumento tuvo un valor ilegal
!>          > 0:  ZPPTRF o ZHPEV devolvieron un código de error:
!>             <= N:  si INFO = i, ZHPEV no convergió;
!>                    i elementos fuera de la diagonal de una forma tridiagonal intermedia
!>                    no convergieron a cero;
!>             > N:   si INFO = N + i, para 1 <= i <= n, entonces el menor
!>                    principal de orden i de B no es positivo.
!>                    La factorización de B no pudo completarse y
!>                    no se calcularon valores propios ni vectores propios.
!>
