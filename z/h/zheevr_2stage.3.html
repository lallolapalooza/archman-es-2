ZHEEVR_2STAGE calcula los valores propios y, opcionalmente, los vectores propios de matrices Hermitianas HE

Propósito:

!>
!> ZHEEVR_2STAGE calcula valores propios seleccionados y, opcionalmente, vectores propios
!> de una matriz Hermitiana compleja A utilizando la técnica de 2 etapas para
!> la reducción a tridiagonal. Los valores propios y vectores propios pueden
!> ser seleccionados especificando un rango de valores o un rango de
!> índices para los valores propios deseados.
!>
!> ZHEEVR_2STAGE primero reduce la matriz A a forma tridiagonal T con una llamada
!> a ZHETRD. Luego, siempre que sea posible, ZHEEVR_2STAGE llama a ZSTEMR para calcular
!> el espectro de valores propios utilizando Representaciones Relativamente Robustas. ZSTEMR
!> calcula los valores propios mediante el algoritmo dqds, mientras que los vectores propios ortogonales
!> se calculan a partir de varias representaciones L D L^T
!> (también conocidas como Representaciones Relativamente Robustas). La ortogonalización de Gram-Schmidt
!> se evita tanto como sea posible. Más específicamente,
!> los diversos pasos del algoritmo son los siguientes.
!>
!> Para cada bloque no reducido (submatriz) de T,
!>    (a) Calcular T - sigma I  = L D L^T, de modo que L y D
!>        definan todos los valores propios deseados con alta precisión relativa.
!>        Esto significa que pequeños cambios relativos en las entradas de D y L
!>        causan solo pequeños cambios relativos en los valores propios y
!>        vectores propios. La representación estándar (no factorizada) de la
!>        matriz tridiagonal T no tiene esta propiedad en general.
!>    (b) Calcular los valores propios con precisión adecuada.
!>        Si se desean los vectores propios, el algoritmo alcanza la precisión completa
!>        de los valores propios calculados solo justo antes de
!>        que los vectores correspondientes tengan que ser calculados, ver pasos c) y d).
!>    (c) Para cada cluster de valores propios cercanos, seleccionar un nuevo
!>        desplazamiento cercano al cluster, encontrar una nueva factorización y refinar
!>        los valores propios desplazados a precisión adecuada.
!>    (d) Para cada valor propio con una separación relativa suficientemente grande, calcular
!>        el vector propio correspondiente formando una factorización retorcida que revele el rango. Volver a c) para cualquier cluster que quede.
!>
!> La precisión deseada de la salida se puede especificar mediante el parámetro de entrada
!> ABSTOL.
!>
!> Para más detalles, ver la documentación de ZSTEMR y:
!> - Inderjit S. Dhillon y Beresford N. Parlett: 
!>   Linear Algebra and its Applications, 387(1), pp. 1-28, agosto de 2004.
!> - Inderjit Dhillon y Beresford Parlett:  SIAM Journal on Matrix Analysis and Applications, Vol. 25,
!>   2004. También LAPACK Working Note 154.
!> - Inderjit Dhillon: ,
!>   Computer Science Division Technical Report No. UCB/CSD-97-971,
!>   UC Berkeley, mayo de 1997.
!>
!>
!> Nota 1: ZHEEVR_2STAGE llama a ZSTEMR cuando se solicita el espectro completo
!> en máquinas que cumplen el estándar de punto flotante ieee-754.
!> ZHEEVR_2STAGE llama a DSTEBZ y ZSTEIN en máquinas no ieee y
!> cuando se solicitan espectros parciales.
!>
!> La ejecución normal de ZSTEMR puede crear NaNs e infinitos y
!> por lo tanto, puede abortar debido a una excepción de punto flotante en entornos
!> que no manejan NaNs e infinitos en la forma predeterminada estándar de ieee.
!>

Parámetros

JOBZ 
!>          JOBZ es CHARACTER*1
!>          = 'N':  Calcular solo los valores propios;
!>          = 'V':  Calcular valores propios y vectores propios.
!>                  No disponible en esta versión.
!>

RANGE

!>          RANGE es CHARACTER*1
!>          = 'A': se encontrarán todos los valores propios.
!>          = 'V': se encontrarán todos los valores propios en el intervalo semiabierto (VL,VU]
!>                 .
!>          = 'I': se encontrarán los valores propios del IL-ésimo al IU-ésimo.
!>          Para RANGE = 'V' o 'I' e IU - IL < N - 1, se llaman DSTEBZ y
!>          ZSTEIN
!>

UPLO

!>          UPLO es CHARACTER*1
!>          = 'U':  Se almacena el triángulo superior de A;
!>          = 'L':  Se almacena el triángulo inferior de A.
!>

N

!>          N es INTEGER
!>          El orden de la matriz A.  N >= 0.
!>

A

!>          A es una matriz COMPLEX*16, dimensión (LDA, N)
!>          En la entrada, la matriz Hermitiana A.  Si UPLO = 'U', la
!>          parte triangular superior de N por N de A contiene la
!>          parte triangular superior de la matriz A.  Si UPLO = 'L',
!>          la parte triangular inferior de N por N de A contiene
!>          la parte triangular inferior de la matriz A.
!>          En la salida, el triángulo inferior (si UPLO='L') o el triángulo
!>          superior (si UPLO='U') de A, incluyendo la diagonal, se
!>          destruye.
!>

LDA

!>          LDA es INTEGER
!>          La dimensión principal del array A.  LDA >= max(1,N).
!>

VL

!>          VL es DOUBLE PRECISION
!>          Si RANGE='V', el límite inferior del intervalo a
!>          buscar para los valores propios. VL < VU.
!>          No referenciado si RANGE = 'A' o 'I'.
!>

VU

!>          VU es DOUBLE PRECISION
!>          Si RANGE='V', el límite superior del intervalo a
!>          buscar para los valores propios. VL < VU.
!>          No referenciado si RANGE = 'A' o 'I'.
!>

IL

!>          IL es INTEGER
!>          Si RANGE='I', el índice del
!>          valor propio más pequeño a devolver.
!>          1 <= IL <= IU <= N, si N > 0; IL = 1 e IU = 0 si N = 0.
!>          No referenciado si RANGE = 'A' o 'V'.
!>

IU

!>          IU es INTEGER
!>          Si RANGE='I', el índice del
!>          valor propio más grande a devolver.
!>          1 <= IL <= IU <= N, si N > 0; IL = 1 e IU = 0 si N = 0.
!>          No referenciado si RANGE = 'A' o 'V'.
!>

ABSTOL

!>          ABSTOL es DOUBLE PRECISION
!>          La tolerancia de error absoluto para los valores propios.
!>          Un valor propio aproximado se acepta como convergente
!>          cuando se determina que yace en un intervalo [a,b]
!>          de ancho menor o igual a
!>
!>                  ABSTOL + EPS *   max( |a|,|b| ) ,
!>
!>          donde EPS es la precisión de la máquina. Si ABSTOL es menor o
!>          igual a cero, entonces se usará EPS*|T| en su lugar,
!>          donde |T| es la norma 1 de la matriz tridiagonal obtenida
!>          al reducir A a forma tridiagonal.
!>
!>          Ver  por Demmel y
!>          Kahan, LAPACK Working Note #3.
!>
!>          Si la alta precisión relativa es importante, establezca ABSTOL a
!>          DLAMCH( 'Safe minimum' ). Hacer esto garantizará que
!>          los valores propios se calculen con alta precisión rel.

Function/Subroutine Documentation

zheevr_2stage

SUBROUTINE ZHEEVR_2STAGE( JOBZ, RANGE, UPLO, N, A, LDA, VL, VU, IL, IU, ABSTOL, M, W, Z, LDZ, ISUPPZ, WORK, LWORK, RWORK, LRWORK, IWORK, LIWORK, INFO )

Purpose:

    ZHEEVR_2STAGE computes the eigenvalues and eigenvectors of a
    complex hermaphroditian matrix A using the 2-stage parallel reduction.

    ZHEEVR_2STAGE is usually called by ZHEEVR, which uses it to compute
    the eigenvalues and eigenvectors. ZHEEVR_2STAGE uses a 2-stage
    reduction of the matrix to tridiagonal form.

Parameters

JOBZ
CHARACTER*1 
          = 'N':  Compute only the eigenvalues of A.
          = 'V':  Compute the eigenvalues and eigenvectors of A.
          Constraint: JOBZ = 'N' or 'V'.
RANGE
CHARACTER*1 
          = 'A': All eigenvalues will be found.
          = 'V': All eigenvalues in the interval (VL, VU] will be found.
          = 'I': All eigenvalues in the range [IL, IU] will be found.
          Constraint: RANGE = 'A', 'V', or 'I'.
UPLO
CHARACTER*1 
          = 'U':  Upper triangle of A is used.
          = 'L':  Lower triangle of A is used.
N
INTEGER 
          The order of the matrix A.  0 <= N.
A
COMPLEX*16 array, dimension (LDA,N) 
          On entry, the complex hermaphroditian matrix A.
          If UPLO = 'U', only the upper trapezoid of A is needed.
          If UPLO = 'L', only the lower trapezoid of A is needed.
          On exit, if JOBZ = 'V', A is overwritten by details of its
          QR or LQ factorization which is not needed by the caller.
LDA
INTEGER 
          The leading dimension of the array A. LDA >= max(1,N).
VL
DOUBLE PRECISION 
          If RANGE = 'V', the lower bound of the interval for the desired
          eigenvalues.
VU
DOUBLE PRECISION 
          If RANGE = 'V', the upper bound of the interval for the desired
          eigenvalues.
IL
INTEGER 
          If RANGE = 'I', the index of the smallest eigenvalue to be
          returned.
IU
INTEGER 
          If RANGE = 'I', the index of the largest eigenvalue to be
          returned.
ABSTOL
DOUBLE PRECISION 
          The absolute tolerance for the eigenvalues. An eigenvalue is
          considered to be found when it is within ABSTOL of the
          target value or interval. For example, if the target interval is
          [VL, VU], then an eigenvalue W is accepted if W <= VU + ABSTOL
          and W >= VL - ABSTOL.
          If ABSTOL is supplied, use it as the tolerance.
          If ABSTOL is not supplied (e.g. the user sets it to 0), then
          the routine computes a machine-dependent tolerance
          for the purpose of selecting the eigenvalues.
          Future releases will make some attempt to achieve high relative
          accuracy when possible. The current code does not make any
          guarantees about high relative accuracy, but future releases
          will. See J. Barlow and J. Demmel, , LAPACK Working Note #7, for a
          discussion of which matrices define their eigenvalues to high relative
          accuracy.
M
INTEGER 
          The total number of eigenvalues found.  0 <= M <= N.
          If RANGE = 'A', M = N, and if RANGE = 'I', M = IU-IL+1.
W
DOUBLE PRECISION array, dimension (N) 
          The first M elements contain the selected eigenvalues in
          ascending order.
Z
COMPLEX*16 array, dimension (LDZ, max(1,M)) 
          If JOBZ = 'V', then if INFO = 0, the first M columns of Z
          contain the orthonormal eigenvectors of the matrix A
          corresponding to the selected eigenvalues, with the i-th
          column of Z holding the eigenvector associated with W(i).
          If JOBZ = 'N', then Z is not referenced.
          Note: the user must ensure that at least max(1,M) columns are
          supplied in the array Z; if RANGE = 'V', the exact value of M
          is not known in advance and an upper bound must be used.
LDZ
INTEGER 
          The leading dimension of the array Z. LDZ >= 1, and if
          JOBZ = 'V', LDZ >= max(1,N).
ISUPPZ
INTEGER array, dimension ( 2*max(1,M) ) 
          The support of the eigenvectors in Z, i.e., the indices
          indicating the nonzero elements in Z. The i-th eigenvector
          is nonzero only in elements ISUPPZ( 2*i-1 ) through
          ISUPPZ( 2*i ). This is an output of ZSTEMR (tridiagonal
          matrix). The support of the eigenvectors of A is typically
          1:N because of the unitary transformations applied by ZUNMTR.
          Implemented only for RANGE = 'A' or 'I' and IU - IL = N - 1
WORK
COMPLEX*16 array, dimension (MAX(1,LWORK)) 
          On exit, if INFO = 0, WORK(1) returns the optimal LWORK.
LWORK
INTEGER 
          The dimension of the array WORK.
          If N <= 1,               LWORK must be at least 1.
          If JOBZ = 'N' and N > 1, LWORK must be queried.
                                   LWORK = MAX(1, 26*N, dimension) where
                                   dimension = max(stage1,stage2) + (KD+1)*N + N
                                             = N*KD + N*max(KD+1,FACTOPTNB)
                                               + max(2*KD*KD, KD*NTHREADS)
                                               + (KD+1)*N + N
                                   where KD is the blocking size of the reduction,
                                   FACTOPTNB is the blocking used by the QR or LQ
                                   algorithm, usually FACTOPTNB=128 is a good choice
                                   NTHREADS is the number of threads used when
                                   openMP compilation is enabled, otherwise =1.
          If JOBZ = 'V' and N > 1, LWORK must be queried. Not yet available

          If LWORK = -1, then a workspace query is assumed; the routine
          only calculates the optimal sizes of the WORK, RWORK and
          IWORK arrays, returns these values as the first entries of
          the WORK, RWORK and IWORK arrays, and no error message
          related to LWORK or LRWORK or LIWORK is issued by XERBLA.
RWORK
DOUBLE PRECISION array, dimension (MAX(1,LRWORK)) 
          On exit, if INFO = 0, RWORK(1) returns the optimal
          (and minimal) LRWORK.
LRWORK
INTEGER 
          The length of the array RWORK.
          If N <= 1, LRWORK >= 1, else LRWORK >= 24*N.

          If LRWORK = -1, then a workspace query is assumed; the
          routine only calculates the optimal sizes of the WORK, RWORK
          and IWORK arrays, returns these values as the first entries
          of the WORK, RWORK and IWORK arrays, and no error message
          related to LWORK or LRWORK or LIWORK is issued by XERBLA.
IWORK
INTEGER array, dimension (MAX(1,LIWORK)) 
          On exit, if INFO = 0, IWORK(1) returns the optimal
          (and minimal) LIWORK.
LIWORK
INTEGER 
          The dimension of the array IWORK.
          If N <= 1, LIWORK >= 1, else LIWORK >= 10*N.

          If LIWORK = -1, then a workspace query is assumed; the
          routine only calculates the optimal sizes of the WORK, RWORK
          and IWORK arrays, returns these values as the first entries
          of the WORK, RWORK and IWORK arrays, and no error message
          related to LWORK or LRWORK or LIWORK is issued by XERBLA.
INFO
INTEGER 
          = 0:  successful exit
          < 0:  if INFO = -i, the i-th argument had an illegal value
          > 0:  Internal error
