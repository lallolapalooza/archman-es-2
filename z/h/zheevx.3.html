ZHEEVX calcula los valores propios y, opcionalmente, los vectores propios izquierdos y/o derechos para matrices HE

Propósito:

!>
!> ZHEEVX calcula los valores propios seleccionados y, opcionalmente, los vectores propios
!> de una matriz Hermitiana compleja A. Los valores propios y vectores propios pueden
!> ser seleccionados especificando un rango de valores o un rango de
!> índices para los valores propios deseados.
!>

Parámetros

JOBZ 
!>          JOBZ es CHARACTER*1
!>          = 'N':  Calcular solo los valores propios;
!>          = 'V':  Calcular valores propios y vectores propios.
!>

RANGE

!>          RANGE es CHARACTER*1
!>          = 'A': se encontrarán todos los valores propios.
!>          = 'V': se encontrarán todos los valores propios en el intervalo semiabierto (VL,VU]
!>                 .
!>          = 'I': se encontrarán los valores propios del IL-ésimo al IU-ésimo.
!>

UPLO

!>          UPLO es CHARACTER*1
!>          = 'U':  El triángulo superior de A está almacenado;
!>          = 'L':  El triángulo inferior de A está almacenado.
!>

N

!>          N es INTEGER
!>          El orden de la matriz A.  N >= 0.
!>

A

!>          A es un array COMPLEX*16, de dimensión (LDA, N)
!>          En la entrada, la matriz Hermitiana A. Si UPLO = 'U', la
!>          parte triangular superior de N por N de A contiene la
!>          parte triangular superior de la matriz A. Si UPLO = 'L',
!>          la parte triangular inferior de N por N de A contiene
!>          la parte triangular inferior de la matriz A.
!>          En la salida, el triángulo inferior (si UPLO='L') o el triángulo
!>          superior (si UPLO='U') de A, incluyendo la diagonal, es
!>          destruido.
!>

LDA

!>          LDA es INTEGER
!>          La dimensión principal del array A. LDA >= max(1,N).
!>

VL

!>          VL es DOUBLE PRECISION
!>          Si RANGE='V', el límite inferior del intervalo a
!>          buscar para los valores propios. VL < VU.
!>          No referenciado si RANGE = 'A' o 'I'.
!>

VU

!>          VU es DOUBLE PRECISION
!>          Si RANGE='V', el límite superior del intervalo a
!>          buscar para los valores propios. VL < VU.
!>          No referenciado si RANGE = 'A' o 'I'.
!>

IL

!>          IL es INTEGER
!>          Si RANGE='I', el índice del
!>          valor propio más pequeño a devolver.
!>          1 <= IL <= IU <= N, si N > 0; IL = 1 e IU = 0 si N = 0.
!>          No referenciado si RANGE = 'A' o 'V'.
!>

IU

!>          IU es INTEGER
!>          Si RANGE='I', el índice del
!>          valor propio más grande a devolver.
!>          1 <= IL <= IU <= N, si N > 0; IL = 1 e IU = 0 si N = 0.
!>          No referenciado si RANGE = 'A' o 'V'.
!>

ABSTOL

!>          ABSTOL es DOUBLE PRECISION
!>          La tolerancia de error absoluta para los valores propios.
!>          Un valor propio aproximado se acepta como convergente
!>          cuando se determina que yace en un intervalo [a,b]
!>          de anchura menor o igual a
!>
!>                  ABSTOL + EPS *   max( |a|,|b| ) ,
!>
!>          donde EPS es la precisión de la máquina. Si ABSTOL es menor que
!>          o igual a cero, entonces EPS*|T| se usará en su lugar,
!>          donde |T| es la norma 1 de la matriz tridiagonal obtenida
!>          al reducir A a forma tridiagonal.
!>
!>          Los valores propios se calcularán con mayor precisión cuando ABSTOL
!>          se establezca en el doble del umbral de subdesbordamiento 2*DLAMCH('S'), no cero.
!>          Si esta rutina retorna con INFO>0, indicando que algunos
!>          vectores propios no convergieron, intente establecer ABSTOL en
!>          2*DLAMCH('S').
!>
!>          Ver  por Demmel y
!>          Kahan, Nota de Trabajo LAPACK #3.
!>

M

!>          M es INTEGER
!>          El número total de valores propios encontrados.  0 <= M <= N.
!>          Si RANGE = 'A', M = N, y si RANGE = 'I', M = IU-IL+1.
!>

W

!>          W es un array DOUBLE PRECISION, de dimensión (N)
!>          En una salida normal, los primeros M elementos contienen los valores propios
!>          seleccionados en orden ascendente.
!>

Z

!>          Z es un array COMPLEX*16, de dimensión (LDZ, max(1,M))
!>          Si JOBZ = 'V', entonces si INFO = 0, las primeras M columnas de Z
!>          contienen los vectores propios ortonormales de la matriz A
!>          correspondientes a los valores propios seleccionados, con la i-ésima
!>          columna de Z conteniendo el vector propio asociado con W(i).
!>          Si un vector propio falla en converger, entonces esa columna de Z
!>          contiene la última aproximación del vector propio, y el
!>          índice del vector propio se devuelve en IFAIL.
!>          Si JOBZ = 'N', entonces Z no se referencia.
!>          Nota: el usuario debe asegurarse de que se suministran al menos max(1,M) columnas
!>          en el array Z; si RANGE = 'V', el valor exacto de M
!>          no se conoce de antemano y se debe usar un límite superior.
!>

LDZ

!>          LDZ es INTEGER
!>          La dimensión principal del array Z. LDZ >= 1, y si
!>          JOBZ = 'V', LDZ >= max(1,N).
!>

WORK

!>          WORK es un array COMPLEX*16, de dimensión (MAX(1,LWORK))
!>          En la salida, si INFO = 0, WORK(1) devuelve el LWORK óptimo.
!>

LWORK

!>          LWORK es INTEGER
!>          La longitud del array WORK. LWORK >= 1, cuando N <= 1;
!>          de lo contrario 2*N.
!>          Para una eficiencia óptima, LWORK >= (NB+1)*N,
!>          donde NB es el máximo del tamaño de bloque para ZHETRD y para
!>          ZUNMTR según lo devuelto por ILAENV.
!>
!>          Si LWORK = -1, entonces se asume una consulta de espacio de trabajo; la rutina
!>          solo calcula el tamaño óptimo del array WORK, devuelve
!>          este valor como la primera entrada del array WORK, y ningún mensaje de error
!>          relacionado con LWORK es emitido por XERBLA.
!>

RWORK

!>          RWORK es un array DOUBLE PRECISION, de dimensión (7*N)
!>

IWORK

!>          IWORK es un array INTEGER, de dimensión (5*N)
!>

IFAIL

!>          IFAIL es un array INTEGER, de dimensión (N)
!>          Si JOBZ = 'V', entonces si INFO = 0, los primeros M elementos de
!>          IFAIL son cero. Si INFO > 0, entonces IFAIL contiene los
!>          índices de los vectores propios que fallaron en converger.
!>          Si JOBZ = 'N', entonces IFAIL no se referencia.
!>

INFO

NAME

zheevx - Computes the eigenvalues and eigenvectors of a complex Hermitian matrix.

SYNOPSIS

        SUBROUTINE ZHEEVX( JOBZ, RANGE, UPLO, N, A, LDA, VL, VU, IL,
 &                  IU, KEY, PIVOT, IFAIL, GEVL, LDGAVL, V, LDV, W,
 &                  WORK, RWORK, INFO )

IN OUT A COMPLEX*16 array, DIMENSION ( LDA, N )

IN VL DOUBLE PRECISION

IN VU DOUBLE PRECISION

IN IL INTEGER

IN IU INTEGER

IN KEY INTEGER

IN PIVOT INTEGER

OUT IFAIL INTEGER array, DIMENSION ( N )

OUT GEVL INTEGER

OUT LDGAVL INTEGER

OUT V COMPLEX*16 array, DIMENSION ( LDV, * )

OUT W DOUBLE PRECISION array, DIMENSION ( N )

INOUT WORK COMPLEX*16 array, DIMENSION ( 2*N )

OUT RWORK DOUBLE PRECISION array, DIMENSION ( max( N, 2*N-1 ) )

OUT INFO INTEGER

Function/Subroutine Documentation

SUBROUTINE ZHEEVX( JOBZ, RANGE, UPLO, N, A, LDA, VL, VU, IL, IU, KEY, PIVOT, IFAIL, GEVL, LDGAVL, V, LDV, W, WORK, RWORK, INFO )

ZHEEVX computes the eigenvalues and eigenvectors of a complex Hermitian matrix.

Arguments:

JOBZ

          CHARACTER*1. Specifies whether to compute the eigenvalues only (N)
          or both eigenvalues and eigenvectors (V).

RANGE

          CHARACTER*1. Specifies the range of eigenvalues to be computed:
          'A' (all): all eigenvalues will be found.
          'V' (values): all eigenvalues in the interval (VL, VU] will be found.
          'I' (indices): all eigenvalues whose indices are in [IL, IU] will
          be found.

UPLO

          CHARACTER*1. Specifies whether the upper ('U') or lower ('L')
          triangular part of A is used.

N

          INTEGER. The order of the matrix A. N >= 0.

A

          COMPLEX*16 array, DIMENSION ( LDA, N ).
          On entry, the upper or lower triangular matrix A.
          On exit, A is overwritten by values read by ZHEEVX.

LDA

          INTEGER. The leading dimension of the array A. LDA >= max(1, N).

VL

          DOUBLE PRECISION. The lower bound of the interval for the desired
          eigenvalues. Used only if RANGE = 'V'.

VU

          DOUBLE PRECISION. The upper bound of the interval for the desired
          eigenvalues. Used only if RANGE = 'V'.

IL

          INTEGER. The lower index for the desired eigenvalues. Used only if
          RANGE = 'I'.

IU

          INTEGER. The upper index for the desired eigenvalues. Used only if
          RANGE = 'I'.

KEY

          INTEGER. The KEY determines which subarray to be selected if
          RANGE = 'I' or 'V'.

PIVOT

          INTEGER. The PIVOT determines whether to select the eigenvectors
          corresponding to the eigenvalues of index IL to IU or the ones
          corresponding to the eigenvalues which lie in the interval (VL, VU].

IFAIL

          INTEGER array, DIMENSION ( N ).
          On exit, IFAIL(i) is the index of the eigenvector that failed to
          converge. Only relevant if INFO = 2.

GEVL

          INTEGER. The number of eigenvalues found in the interval (VL, VU]
          or the number of eigenvalues with indices in [IL, IU].

LDGAVL

          INTEGER. The value of LDGAVL is always set to 1.

V

          COMPLEX*16 array, DIMENSION ( LDV, * ).
          If JOBZ = 'V', V contains the eigenvectors of A. The eigenvectors
          are stored one per column. The i-th column of V corresponds to the
          i-th eigenvalue in W.

LDV

          INTEGER. The leading dimension of the array V. LDV >= max(1, N).

W

          DOUBLE PRECISION array, DIMENSION ( N ).
          On exit, the eigenvalues, sorted in an unspecified order. If
          RANGE = 'V', the sub-array W(1:GEVL) contains the eigenvalues
          in the interval (VL, VU]. If RANGE = 'I', the sub-array W(1:GEVL)
          contains the eigenvalues with indices in [IL, IU].

WORK

          COMPLEX*16 array, DIMENSION ( 2*N ).
          On exit, WORK(1) contains the minimum dimension of the array WORK
          required to use the subroutine ZHEEVX without workspace error.
          WORK is used as workspace.

RWORK

          DOUBLE PRECISION array, DIMENSION ( max( N, 2*N-1 ) ).
          Used as workspace.

INFO

          INTEGER.
          = 0: successful exit.
          > 0: If INFO = 3, ZHEEVX failed to converge; if the current block
          of eigenvectors could not be computed.
            If INFO = 3, it is a severe error.
          > 0: If INFO = 2, ZHEEVX failed to converge; if the current block
          of eigenvectors could not be computed.
          If INFO = 2, then the eigenvectors of the first INFO eigenvectors
          were computed successfully, but Information about the convergency of
          the other eigenvectors is in the array IFAIL.

An example is provided below:

          Example program:
          > ZHEEVX example program results
          >
          >
          > Job Type: Compute Eigenvalues and Eigenvectors
          > Range Type: All Eigenvalues
          > Matrix (Upper Triangular Part):
          > (  1.0+0.0i,  2.0+1.0i,  3.0+2.0i )
          > (  0.0+0.0i,  4.0+0.0i,  5.0+3.0i )
          > (  0.0+0.0i,  0.0+0.0i,  6.0+0.0i )
          >
          > Eigenvalues:
          >   1.0000000000000000     
          >   2.0000000000000000     
          >   3.0000000000000000     
          >
          > Eigenvectors:
          >   ( 1.0+0.0i,  0.0+0.0i,  0.0+0.0i )
          >   ( 0.0+0.0i,  1.0+0.0i,  0.0+0.0i )
          >   ( 0.0+0.0i,  0.0+0.0i,  1.0+0.0i )
          >
          > INFO = 0
          >
          > For another example on how to use ZHEEVX, see the example program
          > provided in the LAPACK source code repository.
          >
          >
          > If INFO = 0, then all eigenvectors are computed successfully.
          > If INFO = 1, then only eigenvalues are computed.
          > If INFO = 2, then the first K eigenvectors computed are correct. The
          >            remaining N-K eigenvectors did not converge. Their indices
          >            are stored in array IFAIL.
          > If INFO = 3, then the algorithm failed to converge.
          > If INFO < 0, then the i-th argument had an illegal value.
          >             -1:   The absolute value of the i-th argument was illegal.
          >             -2:   If JOBZ = 'V', then the leading dimension of the array A
          >                   is too small.
          >             -3:   If JOBZ = 'V', then the leading dimension of the array V
          >                   is too small.
          >             -4:   If JOBZ = 'V', then the array WORK is too small.
          >             -5:   If JOBZ = 'V', then the array RWORK is too small.
          >             -6:   If RANGE = 'V', then VL >= VU.
          >             -7:   If RANGE = 'I', then IL > IU.
          >             -8:   If RANGE = 'A', then N > 0.
          >             -9:   If JOBZ = 'V', then the algorithm failed to converge;
          >                   if the current block of eigenvectors could not be
          >                   computed. Their indices are stored in array IFAIL.
