subroutine ztprfb (carácter side, carácter trans, carácter direct, carácter storev, entero m, entero n, entero k, entero l, complejo*16, dimensión( ldv, * ) v, entero ldv, complejo*16, dimensión( ldt, * ) t, entero ldt, complejo*16, dimensión( lda, * ) a, entero lda, complejo*16, dimensión( ldb, * ) b, entero ldb, complejo*16, dimensión( ldwork, * ) work, entero ldwork)

ZTPRFB aplica un reflector de bloque complejo "triangular-pentagonal" a una matriz compleja, la cual se compone de dos bloques.

Propósito:

!>
!> ZTPRFB aplica un reflector de bloque complejo H o su
!> transpuesta conjugada H**H a una matriz compleja C, que se compone de dos
!> bloques A y B, ya sea desde la izquierda o la derecha.
!>
!>

Parámetros

SIDE 
!>          SIDE es CHARACTER*1
!>          = 'L': aplicar H o H**H desde la Izquierda
!>          = 'R': aplicar H o H**H desde la Derecha
!>

TRANS

!>          TRANS es CHARACTER*1
!>          = 'N': aplicar H (Sin transpuesta)
!>          = 'C': aplicar H**H (Transpuesta conjugada)
!>

DIRECT

!>          DIRECT es CHARACTER*1
!>          Indica cómo se forma H a partir de un producto de
!>          reflectores elementales
!>          = 'F': H = H(1) H(2) . . . H(k) (Hacia adelante)
!>          = 'B': H = H(k) . . . H(2) H(1) (Hacia atrás)
!>

STOREV

!>          STOREV es CHARACTER*1
!>          Indica cómo se almacenan los vectores que definen los
!>          reflectores elementales:
!>          = 'C': Columnas
!>          = 'R': Filas
!>

M

!>          M es INTEGER
!>          El número de filas de la matriz B.
!>          M >= 0.
!>

N

!>          N es INTEGER
!>          El número de columnas de la matriz B.
!>          N >= 0.
!>

K

!>          K es INTEGER
!>          El orden de la matriz T, es decir, el número de
!>          reflectores elementales cuyo producto define el reflector de bloque.
!>          K >= 0.
!>

L

!>          L es INTEGER
!>          El orden de la parte trapezoidal de V.
!>          K >= L >= 0. Ver Detalles Adicionales.
!>

V

!>          V es un array COMPLEX*16, dimensión
!>                                (LDV,K) si STOREV = 'C'
!>                                (LDV,M) si STOREV = 'R' y SIDE = 'L'
!>                                (LDV,N) si STOREV = 'R' y SIDE = 'R'
!>          La matriz pentagonal V, que contiene los reflectores elementales
!>          H(1), H(2), ..., H(K). Ver Detalles Adicionales.
!>

LDV

!>          LDV es INTEGER
!>          La dimensión principal del array V.
!>          Si STOREV = 'C' y SIDE = 'L', LDV >= max(1,M);
!>          Si STOREV = 'C' y SIDE = 'R', LDV >= max(1,N);
!>          Si STOREV = 'R', LDV >= K.
!>

T

!>          T es un array COMPLEX*16, dimensión (LDT,K)
!>          La matriz triangular K-por-K T en la representación del
!>          reflector de bloque.
!>

LDT

!>          LDT es INTEGER
!>          La dimensión principal del array T.
!>          LDT >= K.
!>

A

!>          A es un array COMPLEX*16, dimensión
!>          (LDA,N) si SIDE = 'L' o (LDA,K) si SIDE = 'R'
!>          En la entrada, la matriz A de K-por-N o M-por-K.
!>          En la salida, A se sobrescribe con el bloque correspondiente de
!>          H*C o H**H*C o C*H o C*H**H. Ver Detalles Adicionales.
!>

LDA

!>          LDA es INTEGER
!>          La dimensión principal del array A.
!>          Si SIDE = 'L', LDA >= max(1,K);
!>          Si SIDE = 'R', LDA >= max(1,M).
!>

B

!>          B es un array COMPLEX*16, dimensión (LDB,N)
!>          En la entrada, la matriz B de M-por-N.
!>          En la salida, B se sobrescribe con el bloque correspondiente de
!>          H*C o H**H*C o C*H o C*H**H. Ver Detalles Adicionales.
!>

LDB

!>          LDB es INTEGER
!>          La dimensión principal del array B.
!>          LDB >= max(1,M).
!>

WORK

!>          WORK es un array COMPLEX*16, dimensión
!>          (LDWORK,N) si SIDE = 'L',
!>          (LDWORK,K) si SIDE = 'R'.
!>

LDWORK

!>          LDWORK es INTEGER
!>          La dimensión principal del array WORK.
!>          Si SIDE = 'L', LDWORK >= K;
!>          Si SIDE = 'R', LDWORK >= M.
!>

Detalles Adicionales:

!>
!>  La matriz C es una matriz compuesta formada a partir de los bloques A y B.
!>  El bloque B es de tamaño M-por-N; si SIDE = 'R', A es de tamaño M-por-K,
!>  y si SIDE = 'L', A es de tamaño K-por-N.
!>
!>  Si SIDE = 'R' y DIRECT = 'F', C = [A B].
!>
!>  Si SIDE = 'L' y DIRECT = 'F', C = [A]
!>                                      [B].
!>
!>  Si SIDE = 'R' y DIRECT = 'B', C = [B A].
!>
!>  Si SIDE = 'L' y DIRECT = 'B', C = [B]
!>                                      [A].
!>
!>  La matriz pentagonal V se compone de un bloque rectangular V1 y un
!>  bloque trapezoidal V2. El tamaño del bloque trapezoidal está determinado
!>  por el parámetro L, donde 0<=L<=K. Si L=K, el bloque V2 de V es triangular;
!>  si L=0, no hay bloque trapezoidal, por lo tanto V = V1 es rectangular.
!>
!>  Si DIRECT = 'F' y STOREV = 'C':  V = [V1]
!>                                         [V2]
!>     - V2 es un trapecio superior (primeras L filas de un triángulo superior K-por-K)
!>
!>  Si DIRECT = 'F' y STOREV = 'R':  V = [V1 V2]
!>
!>     - V2 es un trapecio inferior (primeras L columnas de un triángulo inferior K-por-K)
!>
!>  Si DIRECT = 'B' y STOREV = 'C':  V = [V2]
!>                                         [V1]
!>     - V2 es un trapecio inferior (últimas L filas de un triángulo inferior K-por-K)
!>
!>  Si DIRECT = 'B' y STOREV = 'R':  V = [V2 V1]
!>
!>     - V2 es un trapecio superior (últimas L columnas de un triángulo superior K-por-K)
!>
!>  Si STOREV = 'C' y SIDE = 'L', V es M-por-K con V2 L-por-K.
!>
!>  Si STOREV = 'C' y SIDE = 'R', V es N-por-K con V2 L-por-K.
!>
!>  Si STOREV = 'R' y SIDE = 'L', V es K-por-M con V2 K-por-L.
!>
!>  Si STOREV = 'R' y SIDE = 'R', V es K-por-N con V2 K-por-L.
!>
