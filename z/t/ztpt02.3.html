subrutina ztpt02 (carácter uplo, carácter trans, carácter diag, entero n, entero nrhs, complejo*16, dimensión( * ) ap, complejo*16, dimensión( ldx, * ) x, entero ldx, complejo*16, dimensión( ldb, * ) b, entero ldb, complejo*16, dimensión( * ) work, doble precisión, dimensión( * ) rwork, doble precisión resid)

ZTPT02

Propósito:

!>
!> ZTPT02 calcula el residuo para la solución calculada de un
!> sistema triangular de ecuaciones lineales op(A)*X = B, cuando la
!> matriz triangular A se almacena en formato empaquetado. La relación de prueba es
!> el máximo de
!>    norma(b - op(A)*x) / ( ||op(A)||_1 * norma(x) * EPS ),
!> donde op(A) = A, A**T, o A**H, b es la columna de B, x es el
!> vector solución, y EPS es la epsilon de la máquina.
!>

Parámetros

UPLO 
!>          UPLO es CARACTER*1
!>          Especifica si la matriz A es triangular superior o inferior.
!>          = 'U': Triangular superior
!>          = 'L': Triangular inferior
!>

TRANS

!>          TRANS es CARACTER*1
!>          Especifica la operación aplicada a A.
!>          = 'N': A    * X = B  (Sin transponer)
!>          = 'T': A**T * X = B  (Transpuesta)
!>          = 'C': A**H * X = B  (Transpuesta conjugada)
!>

DIAG

!>          DIAG es CARACTER*1
!>          Especifica si la matriz A es triangular unitaria o no.
!>          = 'N': Triangular no unitaria
!>          = 'U': Triangular unitaria
!>

N

!>          N es ENTERO
!>          El orden de la matriz A.  N >= 0.
!>

NRHS

!>          NRHS es ENTERO
!>          El número de lados derechos, es decir, el número de columnas
!>          de las matrices X y B.  NRHS >= 0.
!>

AP

!>          AP es un array COMPLEJO*16, dimensión (N*(N+1)/2)
!>          La matriz triangular superior o inferior A, empaquetada por columnas en
!>          un array lineal. La j-ésima columna de A se almacena en el array
!>          AP de la siguiente manera:
!>          si UPLO = 'U', AP((j-1)*j/2 + i) = A(i,j) para 1<=i<=j;
!>          si UPLO = 'L',
!>             AP((j-1)*(n-j) + j*(j+1)/2 + i-j) = A(i,j) para j<=i<=n.
!>

X

!>          X es un array COMPLEJO*16, dimensión (LDX,NRHS)
!>          Los vectores solución calculados para el sistema de ecuaciones
!>          lineales.
!>

LDX

!>          LDX es ENTERO
!>          La dimensión principal del array X.  LDX >= max(1,N).
!>

B

!>          B es un array COMPLEJO*16, dimensión (LDB,NRHS)
!>          Los vectores del lado derecho para el sistema de ecuaciones
!>          lineales.
!>

LDB

!>          LDB es ENTERO
!>          La dimensión principal del array B.  LDB >= max(1,N).
!>

WORK

!>          WORK es un array COMPLEJO*16, dimensión (N)
!>

RWORK

!>          RWORK es un array DOBLE PRECISIÓN, dimensión (N)
!>

RESID

!>          RESID es DOBLE PRECISIÓN
!>          El máximo sobre el número de lados derechos de
!>          norma(op(A)*X - B) / ( norma(op(A)) * norma(X) * EPS ).
!>
