Documentación de Función/Subrutina

subroutine ztrsv (character uplo, character trans, character diag, integer n, complex*16, dimension(lda,*) a, integer lda, complex*16, dimension(*) x, integer incx)

ZTRSV

Propósito:

!>
!> ZTRSV  resuelve uno de los sistemas de ecuaciones
!>
!>    A*x = b,   o   A**T*x = b,   o   A**H*x = b,
!>
!> donde b y x son vectores de n elementos y A es una matriz triangular
!> unitaria o no unitaria, superior o inferior, de n por n.
!>
!> Esta rutina no incluye pruebas de singularidad o cuasi-singularidad.
!> Dichas pruebas deben realizarse antes de llamar a esta rutina.
!>

Parámetros

UPLO 
!>          UPLO es CHARACTER*1
!>           En la entrada, UPLO especifica si la matriz es una matriz
!>           triangular superior o inferior, como sigue:
!>
!>              UPLO = 'U' o 'u'   A es una matriz triangular superior.
!>
!>              UPLO = 'L' o 'l'   A es una matriz triangular inferior.
!>

TRANS

!>          TRANS es CHARACTER*1
!>           En la entrada, TRANS especifica las ecuaciones a resolver
!>           como sigue:
!>
!>              TRANS = 'N' o 'n'   A*x = b.
!>
!>              TRANS = 'T' o 't'   A**T*x = b.
!>
!>              TRANS = 'C' o 'c'   A**H*x = b.
!>

DIAG

!>          DIAG es CHARACTER*1
!>           En la entrada, DIAG especifica si A es unitaria o no:
!>
!>              DIAG = 'U' o 'u'   Se asume que A es unitaria.
!>
!>              DIAG = 'N' o 'n'   No se asume que A es unitaria.
!>

N

!>          N es INTEGER
!>           En la entrada, N especifica el orden de la matriz A.
!>           N debe ser al menos cero.
!>

A

!>          A es un array COMPLEX*16, de dimensión ( LDA, N )
!>           Antes de la entrada con UPLO = 'U' o 'u', la parte superior
!>           triangular principal de n por n del array A debe contener la
!>           matriz triangular superior, y la parte estrictamente inferior
!>           triangular de A no se referencia.
!>           Antes de la entrada con UPLO = 'L' o 'l', la parte inferior
!>           triangular principal de n por n del array A debe contener la
!>           matriz triangular inferior, y la parte estrictamente superior
!>           triangular de A no se referencia.
!>           Tenga en cuenta que cuando DIAG = 'U' o 'u', los elementos
!>           diagonales de A tampoco se referencian, pero se asumen que son
!>           la unidad.
!>

LDA

!>          LDA es INTEGER
!>           En la entrada, LDA especifica la primera dimensión de A tal
!>           como se declaró en el programa (sub)llamador. LDA debe ser
!>           al menos max( 1, n ).
!>

X

!>          X es un array COMPLEX*16, de dimensión al menos
!>           ( 1 + ( n - 1 )*abs( INCX ) ).
!>           Antes de la entrada, el array X incrementado debe contener el
!>           vector b del lado derecho de n elementos. En la salida, X
!>           se sobrescribe con el vector solución x.
!>

INCX

!>          INCX es INTEGER
!>           En la entrada, INCX especifica el incremento para los
!>           elementos de X. INCX no debe ser cero.
!>
