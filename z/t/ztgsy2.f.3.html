subrutina ztgsy2 (character trans, integer ijob, integer m, integer n, complex*16, dimension( lda, * ) a, integer lda, complex*16, dimension( ldb, * ) b, integer ldb, complex*16, dimension( ldc, * ) c, integer ldc, complex*16, dimension( ldd, * ) d, integer ldd, complex*16, dimension( lde, * ) e, integer lde, complex*16, dimension( ldf, * ) f, integer ldf, double precision scale, double precision rdsum, double precision rdscal, integer info)

ZTGSY2 resuelve la ecuación de Sylvester generalizada (algoritmo sin bloques).

Propósito:

!>
!> ZTGSY2 resuelve la ecuación de Sylvester generalizada
!>
!>             A * R - L * B = scale * C               (1)
!>             D * R - L * E = scale * F
!>
!> utilizando BLAS de Nivel 1 y 2, donde R y L son matrices desconocidas
!> de tamaño M por N, (A, D), (B, E) y (C, F) son pares de matrices
!> dadas de tamaño M por M, N por N y M por N, respectivamente. A, B, D y E
!> son triangulares superiores (es decir, (A,D) y (B,E) en forma de Schur
!> generalizada).
!>
!> La solución (R, L) sobrescribe (C, F). 0 <= SCALE <= 1 es un factor de
!> escala de salida elegido para evitar desbordamientos.
!>
!> En notación matricial, resolver la ecuación (1) corresponde a resolver
!> Zx = scale * b, donde Z se define como
!>
!>        Z = [ kron(In, A)  -kron(B**H, Im) ]             (2)
!>            [ kron(In, D)  -kron(E**H, Im) ],
!>
!> Ik es la matriz identidad de tamaño k y X**H es la transpuesta conjugada de X.
!> kron(X, Y) es el producto de Kronecker entre las matrices X e Y.
!>
!> Si TRANS = 'C', se resuelve y en el sistema transpuesto conjugado
!> Z**H*y = scale*b, lo que equivale a resolver para R y L en
!>
!>             A**H * R  + D**H * L   = scale * C           (3)
!>             R  * B**H + L  * E**H  = scale * -F
!>
!> Este caso se utiliza para calcular una estimación de Dif[(A, D), (B, E)] =
!> = sigma_min(Z) utilizando comunicación inversa con ZLACON.
!>
!> ZTGSY2 también (IJOB >= 1) contribuye al cálculo en ZTGSYL
!> de un límite superior de la separación entre dos pares de matrices.
!> Entonces, las sub-pertenencias de entrada (A, D), (B, E) son sub-pertenencias
!> de dos pares de matrices en ZTGSYL.
!>

Parámetros

TRANS 
!>          TRANS es CHARACTER*1
!>          = 'N': resuelve la ecuación de Sylvester generalizada (1).
!>          = 'T': resuelve el sistema 'transpuesto' (3).
!>

IJOB

!>          IJOB es INTEGER
!>          Especifica qué tipo de funcionalidad se va a realizar.
!>          =0: resuelve solo (1).
!>          =1: Se calcula una contribución de este subsistema a una
!>              estimación basada en la norma de Frobenius de la
!>              separación entre dos pares de matrices. (Se utiliza la
!>              estrategia de mirada anticipada).
!>          =2: Se calcula una contribución de este subsistema a una
!>              estimación basada en la norma de Frobenius de la
!>              separación entre dos pares de matrices. (Se utiliza
!>              DGECON en subsistemas).
!>          No se referencia si TRANS = 'T'.
!>

M

!>          M es INTEGER
!>          En la entrada, M especifica el orden de A y D, y la dimensión
!>          de fila de C, F, R y L.
!>

N

!>          N es INTEGER
!>          En la entrada, N especifica el orden de B y E, y la dimensión
!>          de columna de C, F, R y L.
!>

A

!>          A es un array COMPLEX*16, dimensión (LDA, M)
!>          En la entrada, A contiene una matriz triangular superior.
!>

LDA

!>          LDA es INTEGER
!>          La dimensión principal de la matriz A. LDA >= max(1, M).
!>

B

!>          B es un array COMPLEX*16, dimensión (LDB, N)
!>          En la entrada, B contiene una matriz triangular superior.
!>

LDB

!>          LDB es INTEGER
!>          La dimensión principal de la matriz B. LDB >= max(1, N).
!>

C

!>          C es un array COMPLEX*16, dimensión (LDC, N)
!>          En la entrada, C contiene el lado derecho de la primera matriz
!>          de la ecuación en (1).
!>          En la salida, si IJOB = 0, C ha sido sobrescrito por la solución
!>          R.
!>

LDC

!>          LDC es INTEGER
!>          La dimensión principal de la matriz C. LDC >= max(1, M).
!>

D

!>          D es un array COMPLEX*16, dimensión (LDD, M)
!>          En la entrada, D contiene una matriz triangular superior.
!>

LDD

!>          LDD es INTEGER
!>          La dimensión principal de la matriz D. LDD >= max(1, M).
!>

E

!>          E es un array COMPLEX*16, dimensión (LDE, N)
!>          En la entrada, E contiene una matriz triangular superior.
!>

LDE

!>          LDE es INTEGER
!>          La dimensión principal de la matriz E. LDE >= max(1, N).
!>

F

!>          F es un array COMPLEX*16, dimensión (LDF, N)
!>          En la entrada, F contiene el lado derecho de la segunda matriz
!>          de la ecuación en (1).
!>          En la salida, si IJOB = 0, F ha sido sobrescrito por la solución
!>          L.
!>

LDF

!>          LDF es INTEGER
!>          La dimensión principal de la matriz F. LDF >= max(1, M).
!>

SCALE

!>          SCALE es DOUBLE PRECISION
!>          En la salida, 0 <= SCALE <= 1. Si 0 < SCALE < 1, las soluciones
!>          R y L (C y F en la entrada) contendrán las soluciones de un
!>          sistema ligeramente perturbado pero las matrices de entrada
!>          A, B, D y E no han sido cambiadas. Si SCALE = 0, R y L
!>          contendrán las soluciones del sistema homogéneo con C = F = 0.
!>          Normalmente, SCALE = 1.
!>

RDSUM

!>          RDSUM es DOUBLE PRECISION
!>          En la entrada, la suma de cuadrados de las contribuciones
!>          calculadas a la estimación de Dif- que está siendo calculada
!>          por ZTGSYL, donde el factor de escala RDSCAL (ver abajo) se ha
!>          extraído.
!>          En la salida, la suma de cuadrados correspondiente actualizada
!>          con las contribuciones del subsistema actual.
!>          Si TRANS = 'T', RDSUM no se modifica.
!>          NOTA: RDSUM solo tiene sentido cuando ZTGSY2 es llamado por
!>          ZTGSYL.
!>

RDSCAL

!>          RDSCAL es DOUBLE PRECISION
!>          En la entrada, factor de escala utilizado para prevenir
!>          desbordamientos en RDSUM.
!>          En la salida, RDSCAL se actualiza con respecto a las
!>          contribuciones actuales en RDSUM.
!>          Si TRANS = 'T', RDSCAL no se modifica.
!>          NOTA: RDSCAL solo tiene sentido cuando ZTGSY2 es llamado por
!>          ZTGSYL.
!>

INFO

!>          INFO es INTEGER
!>          En la salida, si INFO se establece en
!>            =0: Salida exitosa
!>            <0: Si INFO = -i, el argumento de entrada número i es
!>                ilegal.
!>            >0: Los pares de matrices (A, D) y (B, E) tienen
!>                autovalores comunes o muy cercanos.
!>

@brief The entry point for the LAPACK API of ztgsy2. @details ztgsy2 computes the solution to the generalized Sylvester equation

   A*X*B + C*X*D = E

or the alternative

   A*X*D + C*X*B = E

The matrices A, B, C, D, E, F and G are complex.

@param matrix_layout Storage layout of the matrices in the calling program. Possible values: @c LAPACK_ROW_MAJOR or @c LAPACK_COL_MAJOR. @param ijob Flag indicating the form of the equation to be solved. @param trans Flag indicating whether to transform the matrices. @param n1 First dimension of matrices A, C, D, F. @param n2 Second dimension of matrices B, D, E, G. @param A Input matrix. @param lda Stride of matrix A. @param B Input matrix. @param ldb Stride of matrix B. @param C Input matrix. @param ldc Stride of matrix C. @param D Input matrix. @param ldd Stride of matrix D. @param E Input matrix. @param lde Stride of matrix E. @param F Input matrix. @param ldf Stride of matrix F. @param G Input matrix. @param ldg Stride of matrix G. @param info Return code. @retval 0 Success. @retval < 0 If info = -i, the i-th argument had an illegal value. @retval > 0 If info = i, the i-th diagonal element of the triangular factor of G is zero, so G is singular (and the solution has not been computed).
