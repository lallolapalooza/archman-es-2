Documentación de la función/subrutina

subrutina ztpmqrt (character side, character trans, integer m, integer n, integer k, integer l, integer nb, complex*16, dimension( ldv, * ) v, integer ldv, complex*16, dimension( ldt, * ) t, integer ldt, complex*16, dimension( lda, * ) a, integer lda, complex*16, dimension( ldb, * ) b, integer ldb, complex*16, dimension( * ) work, integer info)

ZTPMQRT

Propósito:

!>
!> ZTPMQRT aplica una matriz ortogonal compleja Q obtenida de un
!>  reflector de bloque complejo H a una
!>matriz compleja general C, que consta de dos bloques A y B.
!>

Parámetros

SIDE 
!>          SIDE es CHARACTER*1
!>          = 'L': aplica Q o Q**H desde la izquierda;
!>          = 'R': aplica Q o Q**H desde la derecha.
!>

TRANS

!>          TRANS es CHARACTER*1
!>          = 'N':  sin transponer, aplica Q;
!>          = 'C':  transpuesta conjugada, aplica Q**H.
!>

M

!>          M es INTEGER
!>          El número de filas de la matriz B. M >= 0.
!>

N

!>          N es INTEGER
!>          El número de columnas de la matriz B. N >= 0.
!>

K

!>          K es INTEGER
!>          El número de reflectores elementales cuyo producto define
!>          la matriz Q.
!>

L

!>          L es INTEGER
!>          El orden de la parte trapezoidal de V.
!>          K >= L >= 0.  Ver Detalles adicionales.
!>

NB

!>          NB es INTEGER
!>          El tamaño de bloque utilizado para el almacenamiento de T.  K >= NB >= 1.
!>          Este debe ser el mismo valor de NB utilizado para generar T
!>          en CTPQRT.
!>

V

!>          V es un arreglo COMPLEX*16, dimensión (LDV,K)
!>          La i-ésima columna debe contener el vector que define el
!>          reflector elemental H(i), para i = 1,2,...,k, tal como lo devuelve
!>          CTPQRT en B.  Ver Detalles adicionales.
!>

LDV

!>          LDV es INTEGER
!>          La dimensión principal del arreglo V.
!>          Si SIDE = 'L', LDV >= max(1,M);
!>          si SIDE = 'R', LDV >= max(1,N).
!>

T

!>          T es un arreglo COMPLEX*16, dimensión (LDT,K)
!>          Los factores triangulares superiores de los reflectores de bloque
!>          tal como los devuelve CTPQRT, almacenados como una matriz NB-por-K.
!>

LDT

!>          LDT es INTEGER
!>          La dimensión principal del arreglo T.  LDT >= NB.
!>

A

!>          A es un arreglo COMPLEX*16, dimensión
!>          (LDA,N) si SIDE = 'L' o
!>          (LDA,K) si SIDE = 'R'
!>          En la entrada, la matriz A de K-por-N o M-por-K.
!>          En la salida, A es sobrescrito por el bloque correspondiente de
!>          Q*C o Q**H*C o C*Q o C*Q**H.  Ver Detalles adicionales.
!>

LDA

!>          LDA es INTEGER
!>          La dimensión principal del arreglo A.
!>          Si SIDE = 'L', LDC >= max(1,K);
!>          Si SIDE = 'R', LDC >= max(1,M).
!>

B

!>          B es un arreglo COMPLEX*16, dimensión (LDB,N)
!>          En la entrada, la matriz B de M-por-N.
!>          En la salida, B es sobrescrito por el bloque correspondiente de
!>          Q*C o Q**H*C o C*Q o C*Q**H.  Ver Detalles adicionales.
!>

LDB

!>          LDB es INTEGER
!>          La dimensión principal del arreglo B.
!>          LDB >= max(1,M).
!>

WORK

!>          WORK es un arreglo COMPLEX*16. La dimensión de WORK es
!>           N*NB si SIDE = 'L', o  M*NB si SIDE = 'R'.
!>

INFO

!>          INFO es INTEGER
!>          = 0:  salida exitosa
!>          < 0:  si INFO = -i, el i-ésimo argumento tenía un valor ilegal
!>

Detalles adicionales:

!>
!>  Las columnas de la matriz pentagonal V contienen los reflectores elementales
!>  H(1), H(2), ..., H(K); V está compuesta de un bloque rectangular V1 y un
!>  bloque trapezoidal V2:
!>
!>        V = [V1]
!>            [V2].
!>
!>  El tamaño del bloque trapezoidal V2 está determinado por el parámetro L,
!>  donde 0 <= L <= K; V2 es trapezoidal superior, consistente en las primeras L
!>  filas de una matriz triangular superior de K-por-K.  Si L=K, V2 es triangular superior;
!>  si L=0, no hay bloque trapezoidal, por lo tanto V = V1 es rectangular.
!>
!>  Si SIDE = 'L':  C = [A]  donde A es K-por-N,  B es M-por-N y V es M-por-K.
!>                      [B]
!>
!>  Si SIDE = 'R':  C = [A B]  donde A es M-por-K, B es M-por-N y V es N-por-K.
!>
!>  La matriz ortogonal compleja Q se forma a partir de V y T.
!>
!>  Si TRANS='N' y SIDE='L', C es reemplazada en la salida con Q * C.
!>
!>  Si TRANS='C' y SIDE='L', C es reemplazada en la salida con Q**H * C.
!>
!>  Si TRANS='N' y SIDE='R', C es reemplazada en la salida con C * Q.
!>
!>  Si TRANS='C' y SIDE='R', C es reemplazada en la salida con C * Q**H.
!>
