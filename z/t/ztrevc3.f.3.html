DOCUMENTACIÓN DE LA FUNCIÓN/SUBRUTINA

subrutina ztrevc3 (carácter side, carácter howmny, lógico, dimensión( * ) select, entero n, complejo*16, dimensión( ldt, * ) t, entero ldt, complejo*16, dimensión( ldvl, * ) vl, entero ldvl, complejo*16, dimensión( ldvr, * ) vr, entero ldvr, entero mm, entero m, complejo*16, dimensión( * ) work, entero lwork, doble precisión, dimensión( * ) rwork, entero lrwork, entero info)

ZTREVC3

Propósito:

!>
!> ZTREVC3 calcula algunos o todos los vectores propios a la derecha y/o a la izquierda
!> de una matriz triangular superior compleja T.
!> Las matrices de este tipo son producidas por la factorización de Schur de
!> una matriz general compleja:  A = Q*T*Q**H, como la calculada por ZHSEQR.
!>
!> Los vectores propios a la derecha x y a la izquierda y de T correspondientes
!> a un valor propio w se definen por:
!>
!>              T*x = w*x,     (y**H)*T = w*(y**H)
!>
!> donde y**H denota la transpuesta conjugada del vector y.
!> Los valores propios no son una entrada para esta rutina, sino que se leen directamente
!> de la diagonal de T.
!>
!> Esta rutina devuelve las matrices X y/o Y de vectores propios a la derecha y a la izquierda
!> de T, o los productos Q*X y/o Q*Y, donde Q es una
!> matriz de entrada. Si Q es el factor unitario que reduce una matriz A
!> a la forma de Schur T, entonces Q*X y Q*Y son las matrices de vectores propios
!> a la derecha y a la izquierda de A.
!>
!> Esto utiliza una versión de Nivel 3 BLAS de la retrotransformación.
!>

Parámetros

SIDE 
!>          SIDE es CHARACTER*1
!>          = 'R':  solo se calculan los vectores propios a la derecha;
!>          = 'L':  solo se calculan los vectores propios a la izquierda;
!>          = 'B':  se calculan ambos, vectores propios a la derecha y a la izquierda.
!>

HOWMNY

!>          HOWMNY es CHARACTER*1
!>          = 'A':  se calculan todos los vectores propios a la derecha y/o a la izquierda;
!>          = 'B':  se calculan todos los vectores propios a la derecha y/o a la izquierda,
!>                  retrotransformados usando las matrices suministradas en
!>                  VR y/o VL;
!>          = 'S':  se calculan los vectores propios a la derecha y/o a la izquierda seleccionados,
!>                  como se indica en el array lógico SELECT.
!>

SELECT

!>          SELECT es un array LÓGICO, de dimensión (N)
!>          Si HOWMNY = 'S', SELECT especifica los vectores propios a calcular.
!>          El vector propio correspondiente al j-ésimo valor propio se
!>          calcula si SELECT(j) = .TRUE..
!>          No se hace referencia si HOWMNY = 'A' o 'B'.
!>

N

!>          N es ENTERO
!>          El orden de la matriz T. N >= 0.
!>

T

!>          T es un array COMPLEJO*16, de dimensión (LDT,N)
!>          La matriz triangular superior T. T se modifica, pero se restaura
!>          al salir.
!>

LDT

!>          LDT es ENTERO
!>          La dimensión principal del array T. LDT >= max(1,N).
!>

VL

!>          VL es un array COMPLEJO*16, de dimensión (LDVL,MM)
!>          Al entrar, si SIDE = 'L' o 'B' y HOWMNY = 'B', VL debe
!>          contener una matriz Q de N por N (normalmente la matriz unitaria Q de
!>          vectores de Schur devueltos por ZHSEQR).
!>          Al salir, si SIDE = 'L' o 'B', VL contiene:
!>          si HOWMNY = 'A', la matriz Y de vectores propios a la izquierda de T;
!>          si HOWMNY = 'B', la matriz Q*Y;
!>          si HOWMNY = 'S', los vectores propios a la izquierda de T especificados por
!>                           SELECT, almacenados consecutivamente en las columnas
!>                           de VL, en el mismo orden que sus
!>                           valores propios.
!>          No se hace referencia si SIDE = 'R'.
!>

LDVL

!>          LDVL es ENTERO
!>          La dimensión principal del array VL.
!>          LDVL >= 1, y si SIDE = 'L' o 'B', LDVL >= N.
!>

VR

!>          VR es un array COMPLEJO*16, de dimensión (LDVR,MM)
!>          Al entrar, si SIDE = 'R' o 'B' y HOWMNY = 'B', VR debe
!>          contener una matriz Q de N por N (normalmente la matriz unitaria Q de
!>          vectores de Schur devueltos por ZHSEQR).
!>          Al salir, si SIDE = 'R' o 'B', VR contiene:
!>          si HOWMNY = 'A', la matriz X de vectores propios a la derecha de T;
!>          si HOWMNY = 'B', la matriz Q*X;
!>          si HOWMNY = 'S', los vectores propios a la derecha de T especificados por
!>                           SELECT, almacenados consecutivamente en las columnas
!>                           de VR, en el mismo orden que sus
!>                           valores propios.
!>          No se hace referencia si SIDE = 'L'.
!>

LDVR

!>          LDVR es ENTERO
!>          La dimensión principal del array VR.
!>          LDVR >= 1, y si SIDE = 'R' o 'B', LDVR >= N.
!>

MM

!>          MM es ENTERO
!>          El número de columnas en los arrays VL y/o VR. MM >= M.
!>

M

!>          M es ENTERO
!>          El número de columnas en los arrays VL y/o VR realmente
!>          utilizadas para almacenar los vectores propios.
!>          Si HOWMNY = 'A' o 'B', M se establece en N.
!>          Cada vector propio seleccionado ocupa una columna.
!>

WORK

!>          WORK es un array COMPLEJO*16, de dimensión (MAX(1,LWORK))
!>

LWORK

!>          LWORK es ENTERO
!>          La dimensión del array WORK. LWORK >= max(1,2*N).
!>          Para un rendimiento óptimo, LWORK >= N + 2*N*NB, donde NB es
!>          el tamaño de bloque óptimo.
!>
!>          Si LWORK = -1, entonces se asume una consulta de espacio de trabajo; la rutina
!>          solo calcula el tamaño óptimo del array WORK, devuelve
!>          este valor como la primera entrada del array WORK, y XERBLA no emite ningún mensaje
!>          de error relacionado con LWORK.
!>

RWORK

!>          RWORK es un array DOBLE PRECISIÓN, de dimensión (LRWORK)
!>

LRWORK

!>          LRWORK es ENTERO
!>          La dimensión del array RWORK. LRWORK >= max(1,N).
!>
!>          Si LRWORK = -1, entonces se asume una consulta de espacio de trabajo; la rutina
!>          solo calcula el tamaño óptimo del array RWORK, devuelve
!>          este valor como la primera entrada del array RWORK, y XERBLA no emite ningún mensaje
!>          de error relacionado con LRWORK.
!>

INFO

!>          INFO es ENTERO
!>          = 0:  salida exitosa
!>          < 0:  si INFO = -i, el i-ésimo argumento tenía un valor ilegal
!>
