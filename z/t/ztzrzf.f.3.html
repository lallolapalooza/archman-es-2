DOCUMENTACIÓN DE FUNCIÓN/SUBRUTINA

subrutina ztzrzf (integer m, integer n, complex*16, dimension( lda, * ) a, integer lda, complex*16, dimension( * ) tau, complex*16, dimension( * ) work, integer lwork, integer info)

ZTZRZF

Propósito:

!>
!> ZTZRZF reduce la matriz compleja superior trapezoidal A de M por N ( M<=N )
!> a forma triangular superior mediante transformaciones unitarias.
!>
!> La matriz superior trapezoidal A se factoriza como
!>
!>    A = ( R  0 ) * Z,
!>
!> donde Z es una matriz unitaria de N por N y R es una matriz triangular
!> superior de M por M.
!>

Parámetros

M 
!>          M es INTEGER
!>          El número de filas de la matriz A.  M >= 0.
!>

N

!>          N es INTEGER
!>          El número de columnas de la matriz A.  N >= M.
!>

A

!>          A es array COMPLEX*16, dimensión (LDA,N)
!>          En la entrada, la parte superior trapezoidal líder M por N de la
!>          matriz A debe contener la matriz a factorizar.
!>          En la salida, la parte triangular superior líder M por M de A
!>          contiene la matriz triangular superior R, y los elementos M+1 a
!>          N de las primeras M filas de A, con el array TAU, representan la
!>          matriz unitaria Z como un producto de M reflectores elementales.
!>

LDA

!>          LDA es INTEGER
!>          La dimensión líder del array A.  LDA >= max(1,M).
!>

TAU

!>          TAU es array COMPLEX*16, dimensión (M)
!>          Los factores escalares de los reflectores elementales.
!>

WORK

!>          WORK es array COMPLEX*16, dimensión (MAX(1,LWORK))
!>          En la salida, si INFO = 0, WORK(1) devuelve el LWORK óptimo.
!>

LWORK

!>          LWORK es INTEGER
!>          La dimensión del array WORK.  LWORK >= max(1,M).
!>          Para un rendimiento óptimo LWORK >= M*NB, donde NB es
!>          el tamaño de bloque óptimo.
!>
!>          Si LWORK = -1, entonces se asume una consulta de espacio de trabajo; la rutina
!>          solo calcula el tamaño óptimo del array WORK, devuelve
!>          este valor como la primera entrada del array WORK, y XERBLA no emite
!>          ningún mensaje de error relacionado con LWORK.
!>

INFO

!>          INFO es INTEGER
!>          = 0:  salida exitosa
!>          < 0:  si INFO = -i, el i-ésimo argumento tenía un valor ilegal
!>

Detalles adicionales:

!>
!>  La matriz N por N Z puede ser calculada por
!>
!>     Z =  Z(1)*Z(2)* ... *Z(M)
!>
!>  donde cada Z(k) de N por N está dada por
!>
!>     Z(k) = I - tau(k)*v(k)*v(k)**H
!>
!>  con v(k) es el vector de fila k de la matriz M por N
!>
!>     V = ( I   A(:,M+1:N) )
!>
!>  I es la matriz identidad M por M, A(:,M+1:N)
!>  es la salida almacenada en A en la salida de ZTZRZF,
!>  y tau(k) es el elemento k del array TAU.
!>
!>
