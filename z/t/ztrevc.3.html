Documentación de Función/Subrutina

subrutina ztrevc (character side, character howmny, logical, dimension( * ) select, integer n, complex*16, dimension( ldt, * ) t, integer ldt, complex*16, dimension( ldvl, * ) vl, integer ldvl, complex*16, dimension( ldvr, * ) vr, integer ldvr, integer mm, integer m, complex*16, dimension( * ) work, double precision, dimension( * ) rwork, integer info)

ZTREVC

Propósito:

!>
!> ZTREVC calcula algunos o todos los vectores propios derechos y/o izquierdos de
!> una matriz triangular superior compleja T.
!> Las matrices de este tipo se producen por la factorización de Schur de
!> una matriz general compleja:  A = Q*T*Q**H, tal como se calcula por ZHSEQR.
!>
!> Los vectores propios derechos x e izquierdos y de T correspondientes
!> a un valor propio w se definen por:
!>
!>              T*x = w*x,     (y**H)*T = w*(y**H)
!>
!> donde y**H denota la transpuesta conjugada del vector y.
!> Los valores propios no se introducen en esta rutina, sino que se leen directamente
!> de la diagonal de T.
!>
!> Esta rutina devuelve las matrices X y/o Y de vectores propios derechos e izquierdos
!> de T, o los productos Q*X y/o Q*Y, donde Q es una
!> matriz de entrada. Si Q es el factor unitario que reduce una matriz A a
!> la forma de Schur T, entonces Q*X y Q*Y son las matrices de vectores propios
!> derechos e izquierdos de A.
!>

Parámetros

SIDE 
!>          SIDE es CHARACTER*1
!>          = 'R':  solo se calculan los vectores propios derechos;
!>          = 'L':  solo se calculan los vectores propios izquierdos;
!>          = 'B':  se calculan ambos vectores propios derechos e izquierdos.
!>

HOWMNY

!>          HOWMNY es CHARACTER*1
!>          = 'A':  se calculan todos los vectores propios derechos y/o izquierdos;
!>          = 'B':  se calculan todos los vectores propios derechos y/o izquierdos,
!>                  transformados hacia atrás usando las matrices suministradas en
!>                  VR y/o VL;
!>          = 'S':  se calculan vectores propios derechos y/o izquierdos seleccionados,
!>                  como se indica en el array lógico SELECT.
!>

SELECT

!>          SELECT es un array LOGICAL de dimensión (N)
!>          Si HOWMNY = 'S', SELECT especifica los vectores propios a calcular.
!>          El vector propio correspondiente al j-ésimo valor propio
!>          se calcula si SELECT(j) = .TRUE..
!>          No se referencia si HOWMNY = 'A' o 'B'.
!>

N

!>          N es INTEGER
!>          El orden de la matriz T. N >= 0.
!>

T

!>          T es un array COMPLEX*16 de dimensión (LDT,N)
!>          La matriz triangular superior T.  T se modifica, pero se restaura
!>          al salir.
!>

LDT

!>          LDT es INTEGER
!>          La dimensión principal del array T. LDT >= max(1,N).
!>

VL

!>          VL es un array COMPLEX*16 de dimensión (LDVL,MM)
!>          A la entrada, si SIDE = 'L' o 'B' y HOWMNY = 'B', VL debe
!>          contener una matriz Q de N por N (normalmente la matriz unitaria Q de
!>          vectores de Schur devuelta por ZHSEQR).
!>          A la salida, si SIDE = 'L' o 'B', VL contiene:
!>          si HOWMNY = 'A', la matriz Y de vectores propios izquierdos de T;
!>          si HOWMNY = 'B', la matriz Q*Y;
!>          si HOWMNY = 'S', los vectores propios izquierdos de T especificados por
!>                           SELECT, almacenados consecutivamente en las columnas
!>                           de VL, en el mismo orden que sus
!>                           valores propios.
!>          No se referencia si SIDE = 'R'.
!>

LDVL

!>          LDVL es INTEGER
!>          La dimensión principal del array VL.  LDVL >= 1, y si
!>          SIDE = 'L' o 'B', LDVL >= N.
!>

VR

!>          VR es un array COMPLEX*16 de dimensión (LDVR,MM)
!>          A la entrada, si SIDE = 'R' o 'B' y HOWMNY = 'B', VR debe
!>          contener una matriz Q de N por N (normalmente la matriz unitaria Q de
!>          vectores de Schur devuelta por ZHSEQR).
!>          A la salida, si SIDE = 'R' o 'B', VR contiene:
!>          si HOWMNY = 'A', la matriz X de vectores propios derechos de T;
!>          si HOWMNY = 'B', la matriz Q*X;
!>          si HOWMNY = 'S', los vectores propios derechos de T especificados por
!>                           SELECT, almacenados consecutivamente en las columnas
!>                           de VR, en el mismo orden que sus
!>                           valores propios.
!>          No se referencia si SIDE = 'L'.
!>

LDVR

!>          LDVR es INTEGER
!>          La dimensión principal del array VR.  LDVR >= 1, y si
!>          SIDE = 'R' o 'B'; LDVR >= N.
!>

MM

!>          MM es INTEGER
!>          El número de columnas en los arrays VL y/o VR. MM >= M.
!>

M

!>          M es INTEGER
!>          El número de columnas en los arrays VL y/o VR realmente
!>          utilizadas para almacenar los vectores propios.  Si HOWMNY = 'A' o 'B', M
!>          se establece en N. Cada vector propio seleccionado ocupa una
!>          columna.
!>

WORK

!>          WORK es un array COMPLEX*16 de dimensión (2*N)
!>

RWORK

!>          RWORK es un array DOUBLE PRECISION de dimensión (N)
!>

INFO

!>          INFO es INTEGER
!>          = 0:  salida exitosa
!>          < 0:  si INFO = -i, el i-ésimo argumento tenía un valor ilegal
!>
