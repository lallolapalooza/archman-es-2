Documentación de la función/subrutina

subrutina ztpmv (character uplo, character trans, character diag, integer n, complex*16, dimension(*) ap, complex*16, dimension(*) x, integer incx)

ZTPMV

Propósito:

!>
!> ZTPMV  realiza una de las operaciones de matriz-vector
!>
!>    x := A*x,   o   x := A**T*x,   o   x := A**H*x,
!>
!> donde x es un vector de n elementos y A es una matriz triangular superior
!> o inferior de n por n, unitaria o no unitaria, suministrada en forma empaquetada.
!>

Parámetros

UPLO 
!>          UPLO es CHARACTER*1
!>           A la entrada, UPLO especifica si la matriz es triangular superior o inferior
!>           de la siguiente manera:
!>
!>              UPLO = 'U' o 'u'   A es una matriz triangular superior.
!>
!>              UPLO = 'L' o 'l'   A es una matriz triangular inferior.
!>

TRANS

!>          TRANS es CHARACTER*1
!>           A la entrada, TRANS especifica la operación a realizar de la siguiente
!>           manera:
!>
!>              TRANS = 'N' o 'n'   x := A*x.
!>
!>              TRANS = 'T' o 't'   x := A**T*x.
!>
!>              TRANS = 'C' o 'c'   x := A**H*x.
!>

DIAG

!>          DIAG es CHARACTER*1
!>           A la entrada, DIAG especifica si A es unitaria o no
!>           triangular de la siguiente manera:
!>
!>              DIAG = 'U' o 'u'   Se asume que A es triangular unitaria.
!>
!>              DIAG = 'N' o 'n'   No se asume que A es triangular
!>                                  unitaria.
!>

N

!>          N es INTEGER
!>           A la entrada, N especifica el orden de la matriz A.
!>           N debe ser al menos cero.
!>

AP

!>          AP es un array COMPLEX*16, de dimensión al menos
!>           ( ( n*( n + 1 ) )/2 ).
!>           Antes de la entrada con UPLO = 'U' o 'u', el array AP debe
!>           contener la matriz triangular superior empaquetada secuencialmente,
!>           columna por columna, de modo que AP( 1 ) contenga a( 1, 1 ),
!>           AP( 2 ) y AP( 3 ) contengan a( 1, 2 ) y a( 2, 2 )
!>           respectivamente, y así sucesivamente.
!>           Antes de la entrada con UPLO = 'L' o 'l', el array AP debe
!>           contener la matriz triangular inferior empaquetada secuencialmente,
!>           columna por columna, de modo que AP( 1 ) contenga a( 1, 1 ),
!>           AP( 2 ) y AP( 3 ) contengan a( 2, 1 ) y a( 3, 1 )
!>           respectivamente, y así sucesivamente.
!>           Tenga en cuenta que cuando DIAG = 'U' o 'u', los elementos diagonales
!>           de A no se referencian, pero se asumen como unidad.
!>

X

!>          X es un array COMPLEX*16, de dimensión al menos
!>           ( 1 + ( n - 1 )*abs( INCX ) ).
!>           Antes de la entrada, el array X incrementado debe contener el vector
!>           x de n elementos. A la salida, X se sobrescribe con el
!>           vector transformado x.
!>

INCX

!>          INCX es INTEGER
!>           A la entrada, INCX especifica el incremento para los elementos de
!>           X. INCX no debe ser cero.
!>
