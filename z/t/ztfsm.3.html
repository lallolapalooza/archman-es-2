ZTFSM resuelve una ecuación matricial (un operando es una matriz triangular en formato RFP).

Documentación de función/subrutina

subroutine ztfsm (character transr, character side, character uplo, character trans, character diag, integer m, integer n, complex*16 alpha, complex*16, dimension( 0: * ) a, complex*16, dimension( 0: ldb-1, 0: * ) b, integer ldb)

ZTFSM resuelve una ecuación matricial (un operando es una matriz triangular en formato RFP).

Propósito:

!>
!> Rutina de nivel 3 tipo BLAS para A en formato RFP.
!>
!> ZTFSM  resuelve la ecuación matricial
!>
!>    op( A )*X = alpha*B  o  X*op( A ) = alpha*B
!>
!> donde alpha es un escalar, X y B son matrices de m por n, A es una matriz
!> triangular unitaria o no unitaria, superior o inferior y op( A ) es una de
!>
!>    op( A ) = A   o   op( A ) = A**H.
!>
!> A está en formato Rectangular Full Packed (RFP).
!>
!> La matriz X se sobrescribe en B.
!>

Parámetros

TRANSR 
!>          TRANSR es CHARACTER*1
!>          = 'N':  Se almacena la Forma Normal de RFP A;
!>          = 'C':  Se almacena la Forma Transpuesta Conjugada de RFP A.
!>

SIDE

!>          SIDE es CHARACTER*1
!>           En la entrada, SIDE especifica si op( A ) aparece a la izquierda
!>           o a la derecha de X de la siguiente manera:
!>
!>              SIDE = 'L' o 'l'   op( A )*X = alpha*B.
!>
!>              SIDE = 'R' o 'r'   X*op( A ) = alpha*B.
!>
!>           Sin cambios en la salida.
!>

UPLO

!>          UPLO es CHARACTER*1
!>           En la entrada, UPLO especifica si la matriz RFP A provino de
!>           una matriz triangular superior o inferior de la siguiente manera:
!>           UPLO = 'U' o 'u' RFP A provino de una matriz triangular superior
!>           UPLO = 'L' o 'l' RFP A provino de una matriz triangular inferior
!>
!>           Sin cambios en la salida.
!>

TRANS

!>          TRANS es CHARACTER*1
!>           En la entrada, TRANS especifica la forma de op( A ) a utilizar
!>           en la multiplicación de matrices de la siguiente manera:
!>
!>              TRANS  = 'N' o 'n'   op( A ) = A.
!>
!>              TRANS  = 'C' o 'c'   op( A ) = conjg( A' ).
!>
!>           Sin cambios en la salida.
!>

DIAG

!>          DIAG es CHARACTER*1
!>           En la entrada, DIAG especifica si RFP A es unitaria o no
!>           triangular de la siguiente manera:
!>
!>              DIAG = 'U' o 'u'   Se asume que A es triangular unitaria.
!>
!>              DIAG = 'N' o 'n'   No se asume que A es unitaria
!>                                  triangular.
!>
!>           Sin cambios en la salida.
!>

M

!>          M es INTEGER
!>           En la entrada, M especifica el número de filas de B. M debe ser
!>           al menos cero.
!>           Sin cambios en la salida.
!>

N

!>          N es INTEGER
!>           En la entrada, N especifica el número de columnas de B. N debe ser
!>           al menos cero.
!>           Sin cambios en la salida.
!>

ALPHA

!>          ALPHA es COMPLEX*16
!>           En la entrada, ALPHA especifica el escalar alpha. Cuando alpha es
!>           cero, A no se referencia y B no necesita ser establecida antes
!>           de la entrada.
!>           Sin cambios en la salida.
!>

A

!>          A es un array COMPLEX*16, dimensión (N*(N+1)/2)
!>           NT = N*(N+1)/2 si SIDE='R' y NT = M*(M+1)/2 en caso contrario.
!>           En la entrada, la matriz A en formato RFP.
!>           El formato RFP se describe mediante TRANSR, UPLO y N de la siguiente
!>           manera:
!>           Si TRANSR='N' entonces RFP A es (0:N,0:K-1) cuando N es par;
!>           K=N/2. RFP A es (0:N-1,0:K) cuando N es impar; K=N/2. Si
!>           TRANSR = 'C' entonces RFP es la Transpuesta Conjugada de RFP A como
!>           se define cuando TRANSR = 'N'. Los contenidos de RFP A se definen
!>           por UPLO de la siguiente manera: Si UPLO = 'U' RFP A contiene los
!>           NT elementos de A empacada superior, ya sea en formato normal o
!>           transpuesta conjugada. Si UPLO = 'L' RFP A contiene los NT elementos
!>           de A empacada inferior, ya sea en formato normal o transpuesta
!>           conjugada. La LDA de RFP A es (N+1)/2 cuando TRANSR = 'C'. Cuando
!>           TRANSR es 'N', la LDA es N+1 cuando N es par y es N cuando es impar.
!>           Ver la Nota a continuación para más detalles. Sin cambios en la salida.
!>

B

!>          B es un array COMPLEX*16, dimensión (LDB,N)
!>           Antes de la entrada, la parte principal de m por n del array B debe
!>           contener la matriz del lado derecho B, y en la salida se sobrescribe
!>           con la matriz solución X.
!>

LDB

!>          LDB es INTEGER
!>           En la entrada, LDB especifica la primera dimensión de B tal como se
!>           declara en el programa (sub)llamador. LDB debe ser al menos max( 1, m ).
!>           Sin cambios en la salida.
!>

NAME

ztfsm - to set up the triangular matrix to be factorized.

SYNOPSIS

Call ztfsm( uplo, transr, n, k, alpha, a, lda, b, ldb )

Function/Subroutine Documentation

ztfsm sets up the triangular matrix to be factorized.

This subroutine is called by the user routines like ZTFSM to set up the triangular matrix to be factorized.

If TRANSR = 'N', then the matrix A is stored in 

   RFP A ( 0:N-1, 0:K-1 )

in the array A. The matrix A consists of the first K columns of the last N rows of the full N x N matrix.

If TRANSR = 'C', then the matrix A is stored in 

   RFP A ( 0:K-1, 0:N-1 )

in the array A. The matrix A consists of the first K rows of the last N columns of the full N x N matrix.

If UPLO = 'L', then the matrix A is stored in the lower triangle of the matrix.

If UPLO = 'U', then the matrix A is stored in the upper triangle of the matrix.

The elements of the matrix are stored in the RFP format. The RFP format stores the elements of a triangular matrix in a rectangular array. The elements are stored column-by-column if UPLO = 'L' and row-by-row if UPLO = 'U'.

The elements are also stored in a conjugate-transpose fashion if TRANSR = 'C'.

Below are some examples of how the RFP format works.

Case 1: UPLO = 'L', TRANSR = 'N'

The RFP A(0:N-1, 1:K) consists of the conjugate-transpose of the last N rows of the full N x N matrix.

Let N=5, K=3.

            RFP A ( 0:4, 1:3 )
            -----------------
            02 12 22
            03 13 23
            04 14 24
            00 33 43
            01 11 44

The elements are stored in the following order:

            (0,1) (1,1) (2,1) (3,1) (4,1)
            (0,2) (1,2) (2,2) (3,2) (4,2)
            (0,3) (1,3) (2,3) (3,3) (4,3)

The indices in the matrix A are given by:

            A(0,0) A(1,0) ... A(N-1,0)
            A(0,1) A(1,1) ... A(N-1,1)
            ...
            A(0,K-1) A(1,K-1) ... A(N-1,K-1)

The elements in the RFP format are ordered as follows.

Let's consider the matrix A(0:N-1, 1:K) where N=5, K=3.

If UPLO = 'L' and TRANSR = 'N':

The full matrix is:

        11 00 00 00 00
        21 22 00 00 00
        31 32 33 00 00
        41 42 43 44 00
        51 52 53 54 55

The RFP A(0:4, 1:3) consists of the last N rows of the matrix. The last N rows of the full matrix are:

        11 00 00 00 00
        21 22 00 00 00
        31 32 33 00 00
        41 42 43 44 00
        51 52 53 54 55

The RFP format stores the lower triangle column by column.

The elements of A(0:N-1, 1:K) are:

        A(0,0) A(1,0) ... A(N-1,0)
        A(0,1) A(1,1) ... A(N-1,1)
        ...
        A(0,K-1) A(1,K-1) ... A(N-1,K-1)

With N=5, K=3, UPLO = 'L', TRANSR = 'N':

The RFP A(0:4, 1:3) consists of the last N rows of the full matrix, and the elements are stored in the lower triangle.

        RFP A ( 0:4, 1:3 )
        -----------------
        A(0,0) A(1,0) A(2,0)  (col 1)
        A(0,1) A(1,1) A(2,1)  (col 2)
        A(0,2) A(1,2) A(2,2)  (col 3)
