ZTGSEN

Propósito:

!>
!> ZTGSEN reorganiza la descomposición de Schur generalizada de un par
!> de matrices complejas (A, B) (en términos de una transformación de
!> equivalencia unitaria Q**H * (A, B) * Z), de modo que un clúster
!> seleccionado de valores propios aparezca en los bloques diagonales
!> principales del par (A,B). Las columnas principales de Q y Z forman
!> bases unitarias de los correspondientes subespacios propios (deflexionantes)
!> izquierdos y derechos. (A, B) deben estar en forma canónica de Schur
!> generalizada, es decir, A y B son ambas triangulares superiores.
!>
!> ZTGSEN también calcula los valores propios generalizados
!>
!>          w(j)= ALPHA(j) / BETA(j)
!>
!> del par de matrices reorganizado (A, B).
!>
!> Opcionalmente, la rutina calcula estimaciones de los recíprocos de los
!> números de condición para los valores propios y subespacios propios.
!> Estos son Difu[(A11,B11), (A22,B22)] y Difl[(A11,B11), (A22,B22)],
!> es decir, las separaciones entre los pares de matrices (A11, B11) y
!> (A22,B22) que corresponden al clúster seleccionado y a los valores propios
!> fuera del clúster, respectivamente, y las normas de los subespacios
!> propios izquierdos y derechos con respecto al clúster seleccionado
!> en el bloque (1,1).
!>
!>

Parámetros

IJOB 
!>          IJOB es INTEGER
!>          Especifica si se requieren números de condición para el
!>          clúster de valores propios (PL y PR) o los subespacios
!>          deflexionantes (Difu y Difl):
!>           =0: Solo reorganizar con respecto a SELECT. Sin extras.
!>           =1: Recíproco de las normas de los subespacios propios
!>               izquierdos y derechos con respecto al clúster
!>               seleccionado (PL y PR).
!>           =2: Límites superiores sobre Difu y Difl. Estimación basada
!>               en la norma F (DIF(1:2)).
!>           =3: Estimación de Difu y Difl. Estimación basada en la
!>               norma 1 (DIF(1:2)).
!>               Aproximadamente 5 veces más caro que IJOB = 2.
!>           =4: Calcular PL, PR y DIF (es decir, 0, 1 y 2 anteriores):
!>               Versión económica para obtenerlo todo.
!>           =5: Calcular PL, PR y DIF (es decir, 0, 1 y 3 anteriores)
!>

WANTQ

!>          WANTQ es LOGICAL
!>          .TRUE. : actualizar la matriz de transformación izquierda Q;
!>          .FALSE.: no actualizar Q.
!>

WANTZ

!>          WANTZ es LOGICAL
!>          .TRUE. : actualizar la matriz de transformación derecha Z;
!>          .FALSE.: no actualizar Z.
!>

SELECT

!>          SELECT es un array LOGICAL, de dimensión (N)
!>          SELECT especifica los valores propios en el clúster seleccionado.
!>          Para seleccionar un valor propio w(j), SELECT(j) debe estar
!>          establecido a .TRUE..
!>

N

!>          N es INTEGER
!>          El orden de las matrices A y B. N >= 0.
!>

A

!>          A es un array COMPLEX*16, de dimensión(LDA,N)
!>          En la entrada, la matriz triangular superior A, en forma
!>          canónica de Schur generalizada.
!>          En la salida, A se sobrescribe con la matriz reorganizada A.
!>

LDA

!>          LDA es INTEGER
!>          La dimensión principal del array A. LDA >= max(1,N).
!>

B

!>          B es un array COMPLEX*16, de dimensión(LDB,N)
!>          En la entrada, la matriz triangular superior B, en forma
!>          canónica de Schur generalizada.
!>          En la salida, B se sobrescribe con la matriz reorganizada B.
!>

LDB

!>          LDB es INTEGER
!>          La dimensión principal del array B. LDB >= max(1,N).
!>

ALPHA

!>          ALPHA es un array COMPLEX*16, de dimensión (N)
!>

BETA

!>          BETA es un array COMPLEX*16, de dimensión (N)
!>
!>          Los elementos diagonales de A y B, respectivamente,
!>          cuando el par (A,B) se ha reducido a la forma de Schur
!>          generalizada. ALPHA(i)/BETA(i) para i=1,...,N son los valores
!>          propios generalizados.
!>

Q

!>          Q es un array COMPLEX*16, de dimensión (LDQ,N)
!>          En la entrada, si WANTQ = .TRUE., Q es una matriz N por N.
!>          En la salida, Q se ha multiplicado por la matriz de
!>          transformación unitaria izquierda que reorganiza (A, B);
!>          Las M columnas principales de Q forman bases ortonormales
!>          para el par seleccionado de subespacios propios izquierdos
!>          (deflexionantes).
!>          Si WANTQ = .FALSE., Q no se utiliza.
!>

LDQ

!>          LDQ es INTEGER
!>          La dimensión principal del array Q. LDQ >= 1.
!>          Si WANTQ = .TRUE., LDQ >= N.
!>

Z

!>          Z es un array COMPLEX*16, de dimensión (LDZ,N)
!>          En la entrada, si WANTZ = .TRUE., Z es una matriz N por N.
!>          En la salida, Z se ha multiplicado por la matriz de
!>          transformación unitaria izquierda que reorganiza (A, B);
!>          Las M columnas principales de Z forman bases ortonormales
!>          para el par seleccionado de subespacios propios izquierdos
!>          (deflexionantes).
!>          Si WANTZ = .FALSE., Z no se utiliza.
!>

LDZ

!>          LDZ es INTEGER
!>          La dimensión principal del array Z. LDZ >= 1.
!>          Si WANTZ = .TRUE., LDZ >= N.
!>

M

!>          M es INTEGER
!>          La dimensión del par seleccionado de subespacios propios
!>          izquierdos y derechos (deflexionantes), 0 <= M <= N.
!>

PL

!>          PL es DOUBLE PRECISION
!>

PR

!>          PR es DOUBLE PRECISION
!>
!>          Si IJOB = 1, 4 o 5, PL y PR son límites inferiores para el
!>          recíproco de la norma de los subespacios propios izquierdo y
!>          derecho con respecto al clúster seleccionado.
!>          0 < PL, PR <= 1.
!>          Si M = 0 o M = N, PL = PR = 1.
!>          Si IJOB = 0, 2 o 3, PL y PR no se utilizan.
!>

DIF

!>          DIF es un array DOUBLE PRECISION, de dimensión (2).
!>          Si IJOB >= 2, DIF(1:2) almacenan las estimaciones de Difu y Difl.
!>          Si IJOB = 2 o 4, DIF(1:2) son límites superiores basados en la
!>          norma F de Difu y Difl. Si IJOB = 3 o 5, DIF(1:2) son
!>          estimaciones basadas en la norma 1 de Difu y Difl, calculadas
!>          mediante comunicación inversa con ZLACN2.
!>          Si M = 0 o N, DIF(1:2) = norma F de [A, B].
!>          Si IJOB = 0 o 1, DIF no se utiliza.
!>

WORK

!>          WORK es un array COMPLEX*16, de dimensión (MAX(1,LWORK))
!>          En la salida, si INFO = 0, WORK(1) devuelve el LWORK óptimo.
!>

LWORK

!>          LWORK es INTEGER
!>          La dimensión del array WORK.

NAME

ztgsen - ZTGSEN computes the Schur factorization of a generalized eigenvalue problem P*A = lambda*Q*B, where A and B are upper triangular matrices. It rearranges the Schur decomposition so that the selected eigenvalues are at the top left corner of the matrix pair.

Function/Subroutine Documentation

ZTGSEN computes the Schur factorization of a generalized eigenvalue problem P*A = lambda*Q*B, where A and B are upper triangular matrices. It rearranges the Schur decomposition so that the selected eigenvalues are at the top left corner of the matrix pair.

Arguments:

IOBJ

CHARACTER*1.
 On entry, IOBJ specifies the form of the problem to be solved:
 = 'G': Compute the generalized Schur factorization for the problem
        A*x = lambda*B*x
 = 'A': Compute the generalized Schur factorization for the problem
        A*B*x = lambda*x
 = 'B': Compute the generalized Schur factorization for the problem
        A*x = lambda*A*B*x
 = 'C': Compute the generalized Schur factorization for the problem
        A*B*x = lambda*x

HOWMNY

CHARACTER*1.
 On entry, HOWMNY specifies the selection mode:
 = 'S': Select the eigenvalues specified by the array SELECT.
 = 'A': Select all eigenvalues.
 = 'L': Select the leading selected eigenvalues.
 = 'R': Select the trailing selected eigenvalues.

SELECT

LOGICAL array, dimension (N).
 On entry, if HOWMNY = 'S', only the entries of SELECT indicating the
 eigenvalues of interest are accessed. On exit, the SELECT array is
 updated with the selected eigenvalues.

N

INTEGER.
 The order of the matrix pair (A, B).

A

COMPLEX*16 matrix, dimension (LDA, N).
 On entry, the upper triangular matrix A.

LDA

INTEGER.
 The leading dimension of the array A. LDA >= max(1, N).

B

COMPLEX*16 matrix, dimension (LDB, N).
 On entry, the upper triangular matrix B.

LDB

INTEGER.
 The leading dimension of the array B. LDB >= max(1, N).

ALPHA

COMPLEX*16 array, dimension (N).
 On exit, ALPHA contains the selected eigenvalues of the generalized
 problem.

BETA

COMPLEX*16 array, dimension (N).
 On exit, BETA contains the selected eigenvalues of the generalized
 problem.

Q

COMPLEX*16 matrix, dimension (LDQ, N).
 On exit, Q is a unitary matrix which contains the left eigenvectors
 of the selected eigenvalues.

LDQ

INTEGER.
 The leading dimension of the array Q. LDQ >= max(1, N).

Z

COMPLEX*16 matrix, dimension (LDZ, N).
 On exit, Z is a unitary matrix which contains the right eigenvectors
 of the selected eigenvalues.

LDZ

INTEGER.
 The leading dimension of the array Z. LDZ >= max(1, N).

WORK

COMPLEX*16 array, dimension (LWORK).
 On exit, WORK(1) contains the optimal LWORK.

LWORK

INTEGER.
 The dimension of the array WORK.
 If LWORK = -1, then a workspace query is assumed; the routine only
 calculates the optimal size of the WORK array, returns this value as
 the first entry of the WORK array, and no error message related to
 LWORK is issued by XERBLA.

IWORK

INTEGER array, dimension (LIWORK).
 On exit, if INFO = 0, IWORK(1) returns the optimal LIWORK.

LIWORK

INTEGER.
 The dimension of the array IWORK. LIWORK >= 1.

PDIF

DOUBLE PRECISION array, dimension (2).
 On exit, PDIF(1) and PDIF(2) contain the reciprocal condition numbers
 of the left and right eigenvectors, respectively.

PL

DOUBLE PRECISION.
 On exit, PL contains the reciprocal condition number of the selected
 left eigenspace.


PR


DOUBLE PRECISION.
 On exit, PR contains the reciprocal condition number of the selected
 right eigenspace.


DIF


DOUBLE PRECISION array, dimension (N).
 On exit, DIF(1:M) contains the reciprocal condition numbers of the
 selected eigenvalues. M is the number of selected eigenvalues.


INFO


INTEGER.
 = 0: Successful exit.
 < 0: If INFO = -i, the i-th argument had an illegal value.
 = 1: Reordering of (A, B) failed because the transformed
      matrix pair (A, B) would be too far from generalized
      Schur form; the problem is very ill-conditioned.
      (A, B) may have been partially reordered.
      If requested, 0 is returned in DIF(*), PL and PR.

Further Details:




  ZTGSEN first collects the selected eigenvalues by computing unitary
  U and W that move them to the top left corner of (A, B). In other
  words, the selected eigenvalues are the eigenvalues of (A11, B11) in

              U**H*(A, B)*W = (A11 A12) (B11 B12) n1
                              ( 0  A22),( 0  B22) n2
                                n1  n2    n1  n2

  where N = n1+n2 and U**H means the conjugate transpose of U. The first
  n1 columns of U and W span the specified pair of left and right
  eigenspaces (deflating subspaces) of (A, B).

  If (A, B) has been obtained from the generalized real Schur
  decomposition of a matrix pair (C, D) = Q*(A, B)*Z**H, then the
  reordered generalized Schur form of (C, D) is given by

           (C, D) = (Q*U)*(U**H *(A, B)*W)*(Z*W)**H,

  and the first n1 columns of Q*U and Z*W span the corresponding
  deflating subspaces of (C, D) (Q and Z store Q*U and Z*W, resp.).

  Note that if the selected eigenvalue is sufficiently ill-conditioned,
  then its value may differ significantly from its value before
  reordering.

  The reciprocal condition numbers of the left and right eigenspaces
  spanned by the first n1 columns of U and W (or Q*U and Z*W) may
  be returned in DIF(1:2), corresponding to Difu and Difl, resp.

  The Difu and Difl are defined as:

       Difu[(A11, B11), (A22, B22)] = sigma-min( Zu )
  and
       Difl[(A11, B11), (A22, B22)] = Difu[(A22, B22), (A11, B11)],

  where sigma-min(Zu) is the smallest singular value of the
  (2*n1*n2)-by-(2*n1*n2) matrix

       Zu = [ kron(In2, A11)  -kron(A22**H, In1) ]
            [ kron(In2, B11)  -kron(B22**H, In1) ].

  Here, Inx is the identity matrix of size nx and A22**H is the
  conjugate transpose of A22. kron(X, Y) is the Kronecker product between
  the matrices X and Y.

  When DIF(2) is small, small changes in (A, B) can cause large changes
  in the deflating subspace. An approximate (asymptotic) bound on the
  maximum angular error in the computed deflating subspaces is

       EPS * norm((A, B)) / DIF(2),

  where EPS is the machine precision.

  The reciprocal norm of the projectors on the left and right
  eigenspaces associated with (A11, B11) may be returned in PL and PR.
  They are computed as follows. First we compute L and R so that
  P*(A, B)*Q is block diagonal, where

       P = ( I -L ) n1           Q = ( I R ) n1
           ( 0  I ) n2    and        ( 0 I ) n2
             n1 n2                    n1 n2

  and (L, R) is the solution to the generalized Sylvester equation

       A11*R - L*A22 = -A12
       B11*R - L*B22 = -B12

  Then PL = (F-norm(L)**2+1)**(-1/2) and PR = (F-norm(R)**2+1)**(-1/2).
  An approximate (asymptotic) bound on the average absolute error of
  the selected eigenvalues is

       EPS * norm((A, B)) / PL.

  There are also global error bounds which valid for perturbations up
  to a certain restriction:  A lower bound (x) on the smallest
  F-norm(E,F) for which an eigenvalue of (A11, B11) may move and
  coalesce with an eigenvalue of (A22, B22) under perturbation (E,F),
  (i.e. (A + E, B + F), is

   x = min(Difu,Difl)/((1/(PL*PL)+1/(PR*PR))**(1/2)+2*max(1/PL,1/PR)).

  An approximate bound on x can be computed from DIF(1:2), PL and PR.

  If y = ( F-norm(E,F) / x) <= 1, the angles between the perturbed
  (L', R') and unperturbed (L, R) left and right deflating subspaces
  associated with the selected cluster in the (1,1)-blocks can be
  bounded as

   max-angle(L, L') <= arctan( y * PL / (1 - y * (1 - PL * PL)**(1/2))
   max-angle(R, R') <= arctan( y * PR / (1 - y * (1 - PR * PR)**(1/2))

  See LAPACK User's Guide section 4.11 or the following references
  for more information.

  Note that if the default method for computing the Frobenius-norm-
  based estimate DIF is not wanted (see ZLATDF), then the parameter
  IDIFJB (see below) should be changed from 3 to 4 (routine ZLATDF
  (IJOB = 2 will be used)). See ZTGSYL for more details.
