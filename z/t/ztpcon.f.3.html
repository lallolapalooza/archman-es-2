Documentación de Función/Subrutina

subroutine ztpcon (character norm, character uplo, character diag, integer n, complex*16, dimension( * ) ap, double precision rcond, complex*16, dimension( * ) work, double precision, dimension( * ) rwork, integer info)

ZTPCON

Propósito:

!>
!> ZTPCON estima la recíproca del número de condición de una matriz triangular empaquetada A,
!> en norma 1 o en norma infinito.
!>
!> Se calcula la norma de A y se obtiene una estimación de
!> norm(inv(A)), luego se calcula la recíproca del número de condición como
!>    RCOND = 1 / ( norm(A) * norm(inv(A)) ).
!>

Parámetros

NORM 
!>          NORM es CHARACTER*1
!>          Especifica si se requiere el número de condición en norma 1 o norma infinito:
!>          = '1' o 'O':  Norma 1;
!>          = 'I':         Norma Infinito.
!>

UPLO

!>          UPLO es CHARACTER*1
!>          = 'U':  A es triangular superior;
!>          = 'L':  A es triangular inferior.
!>

DIAG

!>          DIAG es CHARACTER*1
!>          = 'N':  A es triangular no unitaria;
!>          = 'U':  A es triangular unitaria.
!>

N

!>          N es INTEGER
!>          El orden de la matriz A.  N >= 0.
!>

AP

!>          AP es COMPLEX*16 array, dimension (N*(N+1)/2)
!>          La matriz triangular superior o inferior A, empaquetada por columnas en
!>          un array lineal. La j-ésima columna de A se almacena en el array
!>          AP de la siguiente manera:
!>          si UPLO = 'U', AP(i + (j-1)*j/2) = A(i,j) para 1<=i<=j;
!>          si UPLO = 'L', AP(i + (j-1)*(2n-j)/2) = A(i,j) para j<=i<=n.
!>          Si DIAG = 'U', los elementos diagonales de A no se referencian
!>          y se asumen como 1.
!>

RCOND

!>          RCOND es DOUBLE PRECISION
!>          La recíproca del número de condición de la matriz A,
!>          calculada como RCOND = 1/(norm(A) * norm(inv(A))).
!>

WORK

!>          WORK es COMPLEX*16 array, dimension (2*N)
!>

RWORK

!>          RWORK es DOUBLE PRECISION array, dimension (N)
!>

INFO

!>          INFO es INTEGER
!>          = 0:  salida exitosa
!>          < 0:  si INFO = -i, el i-ésimo argumento tenía un valor ilegal
!>
