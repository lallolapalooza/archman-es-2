ZTGEVC

Propósito:

!>
!> ZTGEVC calcula algunos o todos los vectores propios derechos y/o izquierdos
!> de un par de matrices complejas (S,P), donde S y P son triangulares superiores.
!> Los pares de matrices de este tipo se producen por la factorización generalizada de Schur
!> de un par de matrices complejas (A,B):
!>
!>    A = Q*S*Z**H,  B = Q*P*Z**H
!>
!> como se calcula por ZGGHRD + ZHGEQZ.
!>
!> El vector propio derecho x y el vector propio izquierdo y de (S,P)
!> correspondientes a un valor propio w se definen por:
!>
!>    S*x = w*P*x,  (y**H)*S = w*(y**H)*P,
!>
!> donde y**H denota la transpuesta conjugada de y.
!> Los valores propios no son de entrada a esta rutina, sino que se calculan
!> directamente a partir de los elementos diagonales de S y P.
!>
!> Esta rutina devuelve las matrices X y/o Y de vectores propios derechos e izquierdos
!> de (S,P), o los productos Z*X y/o Q*Y,
!> donde Z y Q son matrices de entrada.
!> Si Q y Z son los factores unitarios de la factorización generalizada de Schur
!> de un par de matrices (A,B), entonces Z*X y Q*Y
!> son las matrices de vectores propios derechos e izquierdos de (A,B).
!>

Parámetros

SIDE 
!>          SIDE es CHARACTER*1
!>          = 'R': calcular solo vectores propios derechos;
!>          = 'L': calcular solo vectores propios izquierdos;
!>          = 'B': calcular ambos vectores propios derechos e izquierdos.
!>

HOWMNY

!>          HOWMNY es CHARACTER*1
!>          = 'A': calcular todos los vectores propios derechos y/o izquierdos;
!>          = 'B': calcular todos los vectores propios derechos y/o izquierdos,
!>                 retrotransformados por las matrices en VR y/o VL;
!>          = 'S': calcular vectores propios derechos y/o izquierdos seleccionados,
!>                 especificados por la matriz lógica SELECT.
!>

SELECT

!>          SELECT es una matriz LOGICAL, dimensión (N)
!>          Si HOWMNY='S', SELECT especifica los vectores propios a calcular.
!>          El vector propio correspondiente al j-ésimo valor propio se calcula si SELECT(j) = .TRUE..
!>          No se referencia si HOWMNY = 'A' o 'B'.
!>

N

!>          N es INTEGER
!>          El orden de las matrices S y P.  N >= 0.
!>

S

!>          S es una matriz COMPLEX*16, dimensión (LDS,N)
!>          La matriz triangular superior S de una factorización generalizada de Schur,
!>          como se calcula por ZHGEQZ.
!>

LDS

!>          LDS es INTEGER
!>          La dimensión principal del array S.  LDS >= max(1,N).
!>

P

!>          P es una matriz COMPLEX*16, dimensión (LDP,N)
!>          La matriz triangular superior P de una factorización generalizada de Schur,
!>          como se calcula por ZHGEQZ.  P debe tener elementos diagonales reales.
!>

LDP

!>          LDP es INTEGER
!>          La dimensión principal del array P.  LDP >= max(1,N).
!>

VL

!>          VL es una matriz COMPLEX*16, dimensión (LDVL,MM)
!>          En la entrada, si SIDE = 'L' o 'B' y HOWMNY = 'B', VL debe
!>          contener una matriz Q de N por N (generalmente la matriz unitaria Q
!>          de vectores de Schur izquierdos devuelta por ZHGEQZ).
!>          En la salida, si SIDE = 'L' o 'B', VL contiene:
!>          si HOWMNY = 'A', la matriz Y de vectores propios izquierdos de (S,P);
!>          si HOWMNY = 'B', la matriz Q*Y;
!>          si HOWMNY = 'S', los vectores propios izquierdos de (S,P) especificados por
!>                      SELECT, almacenados consecutivamente en las columnas de
!>                      VL, en el mismo orden que sus valores propios.
!>          No se referencia si SIDE = 'R'.
!>

LDVL

!>          LDVL es INTEGER
!>          La dimensión principal del array VL.  LDVL >= 1, y si
!>          SIDE = 'L' o 'l' o 'B' o 'b', LDVL >= N.
!>

VR

!>          VR es una matriz COMPLEX*16, dimensión (LDVR,MM)
!>          En la entrada, si SIDE = 'R' o 'B' y HOWMNY = 'B', VR debe
!>          contener una matriz Z de N por N (generalmente la matriz unitaria Z
!>          de vectores de Schur derechos devuelta por ZHGEQZ).
!>          En la salida, si SIDE = 'R' o 'B', VR contiene:
!>          si HOWMNY = 'A', la matriz X de vectores propios derechos de (S,P);
!>          si HOWMNY = 'B', la matriz Z*X;
!>          si HOWMNY = 'S', los vectores propios derechos de (S,P) especificados por
!>                      SELECT, almacenados consecutivamente en las columnas de
!>                      VR, en el mismo orden que sus valores propios.
!>          No se referencia si SIDE = 'L'.
!>

LDVR

!>          LDVR es INTEGER
!>          La dimensión principal del array VR.  LDVR >= 1, y si
!>          SIDE = 'R' o 'B', LDVR >= N.
!>

MM

!>          MM es INTEGER
!>          El número de columnas en los arrays VL y/o VR. MM >= M.
!>

M

!>          M es INTEGER
!>          El número de columnas en los arrays VL y/o VR realmente
!>          utilizado para almacenar los vectores propios.  Si HOWMNY = 'A' o 'B', M
!>          se establece en N. Cada vector propio seleccionado ocupa una columna.
!>

WORK

!>          WORK es una matriz COMPLEX*16, dimensión (2*N)
!>

RWORK

!>          RWORK es una matriz DOUBLE PRECISION, dimensión (2*N)
!>

INFO

!>          INFO es INTEGER
!>          = 0:  salida exitosa.
!>          < 0:  si INFO = -i, el i-ésimo argumento tenía un valor ilegal.
!>
