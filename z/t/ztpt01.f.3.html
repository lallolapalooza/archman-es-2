Documentación de Función/Subrutina

subrutina ztpt01 (character uplo, character diag, integer n, complex*16, dimension( * ) ap, complex*16, dimension( * ) ainvp, double precision rcond, double precision, dimension( * ) rwork, double precision resid)

ZTPT01

Propósito:

!>
!> ZTPT01 calcula el residuo para una matriz triangular A multiplicada por su
!> inversa cuando A está almacenada en formato empaquetado:
!>    RESID = norm(A*AINV - I) / ( N * norm(A) * norm(AINV) * EPS ),
!> donde EPS es la epsilon de la máquina.
!>

Parámetros

UPLO 
!>          UPLO es CHARACTER*1
!>          Especifica si la matriz A es triangular superior o inferior.
!>          = 'U':  Triangular superior
!>          = 'L':  Triangular inferior
!>

DIAG

!>          DIAG es CHARACTER*1
!>          Especifica si la matriz A es unitriangular o no.
!>          = 'N':  No unitriangular
!>          = 'U':  Unitriangular
!>

N

!>          N es INTEGER
!>          El orden de la matriz A.  N >= 0.
!>

AP

!>          AP es un array de tipo COMPLEX*16, de dimensión (N*(N+1)/2)
!>          La matriz triangular superior o inferior original A, empaquetada
!>          por columnas en un array lineal. La j-ésima columna de A se almacena
!>          en el array AP como sigue:
!>          si UPLO = 'U', AP((j-1)*j/2 + i) = A(i,j) para 1<=i<=j;
!>          si UPLO = 'L',
!>             AP((j-1)*(n-j) + j*(j+1)/2 + i-j) = A(i,j) para j<=i<=n.
!>

AINVP

!>          AINVP es un array de tipo COMPLEX*16, de dimensión (N*(N+1)/2)
!>          A la entrada, la inversa (triangular) de la matriz A, empaquetada
!>          por columnas en un array lineal como en AP.
!>          A la salida, el contenido de AINVP se destruye.
!>

RCOND

!>          RCOND es DOUBLE PRECISION
!>          El número de condición recíproco de A, calculado como
!>          1/(norm(A) * norm(AINV)).
!>

RWORK

!>          RWORK es un array de tipo DOUBLE PRECISION, de dimensión (N)
!>

RESID

!>          RESID es DOUBLE PRECISION
!>          norm(A*AINV - I) / ( N * norm(A) * norm(AINV) * EPS )
!>
