Propósito:

!>
!> ZTGSNA estima los números de condición recíprocos para valores
!> propios y/o vectores propios especificados de un par de matrices (A, B).
!>
!> (A, B) deben estar en forma canónica de Schur generalizada, es decir,
!> A y B son ambas matrices triangulares superiores.
!>

Parámetros

JOB 
!>          JOB es CHARACTER*1
!>          Especifica si se requieren números de condición para
!>          valores propios (S) o vectores propios (DIF):
!>          = 'E': solo para valores propios (S);
!>          = 'V': solo para vectores propios (DIF);
!>          = 'B': para ambos, valores y vectores propios (S y DIF).
!>

HOWMNY

!>          HOWMNY es CHARACTER*1
!>          = 'A': calcular números de condición para todos los pares propios;
!>          = 'S': calcular números de condición para pares propios
!>                 seleccionados especificados por el array SELECT.
!>

SELECT

!>          SELECT es un array LOGICAL, de dimensión (N)
!>          Si HOWMNY = 'S', SELECT especifica los pares propios para los
!>          cuales se requieren números de condición. Para seleccionar
!>          números de condición para el j-ésimo valor propio y/o vector
!>          propio correspondiente, SELECT(j) debe ser establecido a .TRUE..
!>          Si HOWMNY = 'A', SELECT no se referencia.
!>

N

!>          N es INTEGER
!>          El orden del par de matrices cuadradas (A, B). N >= 0.
!>

A

!>          A es un array COMPLEX*16, de dimensión (LDA,N)
!>          La matriz triangular superior A en el par (A,B).
!>

LDA

!>          LDA es INTEGER
!>          La dimensión principal del array A. LDA >= max(1,N).
!>

B

!>          B es un array COMPLEX*16, de dimensión (LDB,N)
!>          La matriz triangular superior B en el par (A, B).
!>

LDB

!>          LDB es INTEGER
!>          La dimensión principal del array B. LDB >= max(1,N).
!>

VL

!>          VL es un array COMPLEX*16, de dimensión (LDVL,M)
!>          Si JOB = 'E' o 'B', VL debe contener los vectores propios
!>          izquierdos de (A, B), correspondientes a los pares propios
!>          especificados por HOWMNY y SELECT. Los vectores propios deben
!>          almacenarse en columnas consecutivas de VL, como devuelve ZTGEVC.
!>          Si JOB = 'V', VL no se referencia.
!>

LDVL

!>          LDVL es INTEGER
!>          La dimensión principal del array VL. LDVL >= 1; y
!>          Si JOB = 'E' o 'B', LDVL >= N.
!>

VR

!>          VR es un array COMPLEX*16, de dimensión (LDVR,M)
!>          Si JOB = 'E' o 'B', VR debe contener los vectores propios
!>          derechos de (A, B), correspondientes a los pares propios
!>          especificados por HOWMNY y SELECT. Los vectores propios deben
!>          almacenarse en columnas consecutivas de VR, como devuelve ZTGEVC.

!>

LDVR

!>          LDVR es INTEGER

!>

S

!>          S es un array DOUBLE PRECISION, de dimensión (MM)
!>          Si JOB = 'E' o 'B', los números de condición recíprocos de los
!>          valores propios seleccionados, almacenados en elementos
!>          consecutivos del array.
!>          Si JOB = 'V', S no se referencia.
!>

DIF

!>          DIF es un array DOUBLE PRECISION, de dimensión (MM)
!>          Si JOB = 'V' o 'B', los números de condición recíprocos
!>          estimados de los vectores propios seleccionados, almacenados

!>          Si los valores propios no pueden ser reordenados para calcular
!>          DIF(j), DIF(j) se establece a 0; esto solo puede ocurrir cuando
!>          el valor real sería muy pequeño de todos modos.

MM

M

!>          almacenar los números de condición especificados; para cada

!>          M se establece a N.
!>

WORK

!>          WORK es un array COMPLEX*16, de dimensión (MAX(1,LWORK))

LWORK

!>          LWORK es INTEGER
!>          La dimensión del array WORK. LWORK >= max(1,N).

IWORK

!>          IWORK es un array INTEGER, de dimensión (N+2)

INFO

!>          INFO es INTEGER

NAME

ztgsna - ztgsna computes the Schur vectors and estimated error bounds for the eigenvectors of a generalized eigenvalue problem. It is used in the subroutine ZTGSY.

SYNOPSIS

 SUBROUTINE ZTGSNA( JOB, HOWMNY, SELECT, N, A, LDA, B, LDB, VL, LDVL, VR, LDVR, S, DIFL, DIFR, WORK, LWORK, IWORK, INFO )
    
    
    
      CHARACTER          HOWMNY, JOB, SELECT
    
      INTEGER            INFO, LDA, LDB, LDVL, LDVR, LWORK, N
    
      INTEGER            IWORK( * )
    
      DOUBLE PRECISION   A( LDA, * ), B( LDB, * ), DIFL( * ), DIFR( * ), S( * ),
    
      COMPLEX*16         VL( LDVL, * ), VR( LDVR, * ), WORK( * )

Function/Subroutine Documentation

ZTGSNA computes the Schur vectors and estimated error bounds for the eigenvectors of a generalized eigenvalue problem.

It is intended to be used after the generalized Schur decomposition of a regular matrix pair (A, B) has been computed by ZTGSEN.

The generalized eigenvalue problem is A*V = lambda*B*V, and it is assumed that the matrices A and B are in the generalized real Schur form:

 A = Q * [ S11  S12 ] * Z**H
            [  0   S22 ]
    
    B = Q * [ T11  T12 ] * Z**H
            [  0   T22 ]

where S11 and T11 (or S22 and T22) are upper quasi-triangular matrices.

The function computes the Schur vectors VL and VR, and the corresponding error bounds S, DIFL, and DIFR for the selected eigenvectors.

Arguments:

JOB

JOB is CHARACTER*1

Specifies the desired roles of VL and VR:

= 'V': Compute the Schur vectors VL and VR.

= 'L': Compute the Schur vectors VL.

= 'R': Compute the Schur vectors VR.

HOWMNY

HOWMNY is CHARACTER*1

Specifies whether the error bounds are computed for all eigenvalues/eigenvectors ('A') or for selected eigenvalues/eigenvectors ('S').

= 'A': Compute error bounds for all selected eigenvalues/eigenvectors.

= 'S': Compute error bounds for selected eigenvalues/eigenvectors. In this case, the array SELECT must be provided.

SELECT

SELECT is LOGICAL array, dimension (N)

If HOWMNY = 'S', SELECT specifies which eigenvalues/eigenvectors to process. To select the i-th eigenvalue/eigenvector, SELECT(I) must be .TRUE.. If HOWMNY = 'A', SELECT is not referenced.

N

N is INTEGER

The order of the matrices A and B. N >= 0.

A

A is COMPLEX*16 array, dimension (LDA, N)

The upper quasi-triangular matrix A in the generalized Schur decomposition.

LDA

LDA is INTEGER

The leading dimension of the array A. LDA >= max(1, N).

B

B is COMPLEX*16 array, dimension (LDB, N)

The upper quasi-triangular matrix B in the generalized Schur decomposition.

LDB

LDB is INTEGER

The leading dimension of the array B. LDB >= max(1, N).

VL

VL is COMPLEX*16 array, dimension (LDVL, N)

If JOB = 'L' or JOB = 'V', VL is an output array which contains the left Schur vectors of the generalized Schur form. VL(i,j) is the i-th element of the j-th left Schur vector.

LDVL

LDVL is INTEGER

The leading dimension of the array VL. LDVL >= N.

VR

VR is COMPLEX*16 array, dimension (LDVR, N)

If JOB = 'R' or JOB = 'V', VR is an output array which contains the right Schur vectors of the generalized Schur form. VR(i,j) is the i-th element of the j-th right Schur vector.

LDVR

LDVR is INTEGER

The leading dimension of the array VR. LDVR >= N.

S

S is DOUBLE PRECISION array, dimension (N)

S contains the Schur values of the pencil (A,B). S(i) is the i-th Schur value.

DIFL

DIFL is DOUBLE PRECISION array, dimension (N)

DIFL(i) is the reciprocal of the estimated error bound for computing the corresponding left eigenvector of the i-th generalized eigenvalue. If DIFL(i) is small, the left eigenvector is computed to high accuracy.

DIFR

DIFR is DOUBLE PRECISION array, dimension (N)

DIFR(i) is the reciprocal of the estimated error bound for computing the corresponding right eigenvector of the i-th generalized eigenvalue. If DIFR(i) is small, the right eigenvector is computed to high accuracy.

WORK

WORK is COMPLEX*16 array, dimension (LWORK)

LWORK

LWORK is INTEGER

The dimension of the array WORK. LWORK = -1 indicates that the routine should be called to query the optimal block size.

IWORK

IWORK is INTEGER array, dimension (N)

INFO

INFO is INTEGER

INFO = 0: successful exit.

INFO < 0: If INFO = -i, then the i-th argument had an illegal value.

INFO > 0: If INFO = i, then the i-th eigenvalue/eigenvector could not be processed.

Matrix Description:

The matrices A and B are assumed to be in the generalized real Schur form:

 A = Q * S * Z**H
    B = Q * T * Z**H

where Q and Z are orthogonal matrices. S and T are upper quasi-triangular matrices.

Algorithm:

The algorithm used is described in Reference [1].

The error bounds are computed using the technique described in Reference [2].

The Schur vectors VL and VR are computed by extending the Schur vectors from the computed generalized Schur decomposition. This is done by using the algorithm described in Reference [3].

For example, if the generalized Schur decomposition is:

 A = Q * [ S11  S12 ] * Z**H
            [  0   S22 ]
    
    B = Q * [ T11  T12 ] * Z**H
            [  0   T22 ]

and we want to compute the Schur vectors corresponding to the eigenvalues of S22 and T22, then the computation involves solving a Sylvester equation.

The left Schur vectors VL are given by:

 VL = Q * [ V11  V12 ]
            [  0    V22 ]

where V11 and V22 are the left Schur vectors of the subproblems.

The right Schur vectors VR are given by:

 VR = Z * [ U11  U12 ]
            [  0   U22 ]

where U11 and U22 are the right Schur vectors of the subproblems.

The error bounds are computed using the smallest singular value of a related matrix. Specifically, the error bound for the i-th eigenvector is approximated by EPS * norm(A, B) / DIF(i), where DIF(i) is related to the separation between the i-th eigenvalue and the other eigenvalues.

The expression ( In-1 -kron(1, B22) ) relates to the computation of the smallest singular value of a matrix related to the Sylvester equation.

In-1 is the identity matrix of size n-1.

X**H is the conjugate transpose of X.

kron(X, Y) is the Kronecker product between the matrices X and Y.

An approximate error bound for a computed eigenvector VL(i) or VR(i) is given by

 EPS * norm(A, B) / DIF(i).

See references [2-3] for more details and further references.
