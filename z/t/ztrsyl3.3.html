Documentación de la función/subrutina

subrutina ztrsyl3 (character trana, character tranb, integer isgn, integer m, integer n, complex*16, dimension( lda, * ) a, integer lda, complex*16, dimension( ldb, * ) b, integer ldb, complex*16, dimension( ldc, * ) c, integer ldc, double precision scale, double precision, dimension( ldswork, * ) swork, integer ldswork, integer info)

ZTRSYL3

Propósito:

!>
!>  ZTRSYL3 resuelve la ecuación matricial compleja de Sylvester:
!>
!>     op(A)*X + X*op(B) = scale*C o
!>     op(A)*X - X*op(B) = scale*C,
!>
!>  donde op(A) = A o A**H, y A y B son ambas matrices triangulares superiores. A es
!>  de tamaño M por M y B es de tamaño N por N; el lado derecho C y la solución X son
!>  de tamaño M por N; y scale es un factor de escala de salida, establecido en <= 1 para evitar
!>  desbordamientos en X.
!>
!>  Esta es la versión en bloque del algoritmo.
!>

Parámetros

TRANA 
!>          TRANA es CHARACTER*1
!>          Especifica la opción op(A):
!>          = 'N': op(A) = A    (Sin transposición)
!>          = 'C': op(A) = A**H (Transpuesta conjugada)
!>

TRANB

!>          TRANB es CHARACTER*1
!>          Especifica la opción op(B):
!>          = 'N': op(B) = B    (Sin transposición)
!>          = 'C': op(B) = B**H (Transpuesta conjugada)
!>

ISGN

!>          ISGN es INTEGER
!>          Especifica el signo en la ecuación:
!>          = +1: resuelve op(A)*X + X*op(B) = scale*C
!>          = -1: resuelve op(A)*X - X*op(B) = scale*C
!>

M

!>          M es INTEGER
!>          El orden de la matriz A, y el número de filas en las
!>          matrices X y C. M >= 0.
!>

N

!>          N es INTEGER
!>          El orden de la matriz B, y el número de columnas en las
!>          matrices X y C. N >= 0.
!>

A

!>          A es un array COMPLEX*16, dimensión (LDA,M)
!>          La matriz triangular superior A.
!>

LDA

!>          LDA es INTEGER
!>          La dimensión principal del array A. LDA >= max(1,M).
!>

B

!>          B es un array COMPLEX*16, dimensión (LDB,N)
!>          La matriz triangular superior B.
!>

LDB

!>          LDB es INTEGER
!>          La dimensión principal del array B. LDB >= max(1,N).
!>

C

!>          C es un array COMPLEX*16, dimensión (LDC,N)
!>          A la entrada, la matriz C del lado derecho de tamaño M por N.
!>          A la salida, C se sobrescribe con la matriz solución X.
!>

LDC

!>          LDC es INTEGER
!>          La dimensión principal del array C. LDC >= max(1,M)
!>

SCALE

!>          SCALE es DOUBLE PRECISION
!>          El factor de escala, scale, establecido en <= 1 para evitar desbordamientos en X.
!>

SWORK

!>          SWORK es un array DOUBLE PRECISION, dimensión (MAX(2, ROWS),
!>          MAX(1,COLS)).
!>          A la salida, si INFO = 0, SWORK(1) devuelve el valor óptimo ROWS
!>          y SWORK(2) devuelve el valor óptimo COLS.
!>

LDSWORK

!>          LDSWORK es INTEGER
!>          LDSWORK >= MAX(2,ROWS), donde ROWS = ((M + NB - 1) / NB + 1)
!>          y NB es el tamaño de bloque óptimo.
!>
!>          Si LDSWORK = -1, entonces se asume una consulta de espacio de trabajo; la rutina
!>          solo calcula las dimensiones óptimas de la matriz SWORK,
!>          devuelve estos valores como la primera y segunda entrada de la
!>          matriz SWORK, y XERBLA no emite ningún mensaje de error relacionado con LWORK.
!>

INFO

!>          INFO es INTEGER
!>          = 0: salida exitosa
!>          < 0: si INFO = -i, el i-ésimo argumento tenía un valor ilegal
!>          = 1: A y B tienen valores propios comunes o muy cercanos; se utilizaron
!>               valores perturbados para resolver la ecuación (pero las matrices
!>               A y B no cambian).
!>
