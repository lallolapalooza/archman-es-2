Documentación de la Función/Subrutina

subroutine ztbtrs (character uplo, character trans, character diag, integer n, integer kd, integer nrhs, complex*16, dimension( ldab, * ) ab, integer ldab, complex*16, dimension( ldb, * ) b, integer ldb, integer info)

ZTBTRS

Propósito:

!>
!> ZTBTRS resuelve un sistema triangular de la forma
!>
!>    A * X = B,  A**T * X = B,  o  A**H * X = B,
!>
!> donde A es una matriz de banda triangular de orden N, y B es una matriz N por NRHS.
!>
!> Esta subrutina verifica que A es no singular, pero los llamadores deben tener en cuenta que solo se detecta la singularidad exacta.
!> Es concebible que uno o más elementos diagonales de A sean números extremadamente pequeños sin que esta subrutina señale un error.
!>
!> Si la posible pérdida de precisión numérica debido a matrices casi singulares es una preocupación, el
!> llamador debe verificar que A es no singular dentro de alguna tolerancia antes de llamar a esta subrutina.
!>

Parámetros

UPLO 
!>          UPLO es CHARACTER*1
!>          = 'U':  A es triangular superior;
!>          = 'L':  A es triangular inferior.
!>

TRANS

!>          TRANS es CHARACTER*1
!>          Especifica la forma del sistema de ecuaciones:
!>          = 'N':  A * X = B     (Sin transposición)
!>          = 'T':  A**T * X = B  (Transpuesta)
!>          = 'C':  A**H * X = B  (Transpuesta conjugada)
!>

DIAG

!>          DIAG es CHARACTER*1
!>          = 'N':  A es triangular no unitaria;
!>          = 'U':  A es triangular unitaria.
!>

N

!>          N es INTEGER
!>          El orden de la matriz A.  N >= 0.
!>

KD

!>          KD es INTEGER
!>          El número de superdiagonales o subdiagonales de la
!>          matriz de banda triangular A.  KD >= 0.
!>

NRHS

!>          NRHS es INTEGER
!>          El número de lados derechos, es decir, el número de columnas
!>          de la matriz B.  NRHS >= 0.
!>

AB

!>          AB es un array COMPLEX*16, dimensión (LDAB,N)
!>          La matriz de banda triangular superior o inferior A, almacenada en las
!>          primeras kd+1 filas de AB. La j-ésima columna de A se almacena
!>          en la j-ésima columna de la matriz AB de la siguiente manera:
!>          si UPLO = 'U', AB(kd+1+i-j,j) = A(i,j) para max(1,j-kd)<=i<=j;
!>          si UPLO = 'L', AB(1+i-j,j)    = A(i,j) para j<=i<=min(n,j+kd).
!>          Si DIAG = 'U', los elementos diagonales de A no se referencian
!>          y se asumen que son 1.
!>

LDAB

!>          LDAB es INTEGER
!>          La dimensión principal de la matriz AB.  LDAB >= KD+1.
!>

B

!>          B es un array COMPLEX*16, dimensión (LDB,NRHS)
!>          En la entrada, la matriz del lado derecho B.
!>          En la salida, si INFO = 0, la matriz solución X.
!>

LDB

!>          LDB es INTEGER
!>          La dimensión principal de la matriz B.  LDB >= max(1,N).
!>

INFO

!>          INFO es INTEGER
!>          = 0:  salida exitosa
!>          < 0:  si INFO = -i, el i-ésimo argumento tenía un valor ilegal
!>          > 0:  si INFO = i, el i-ésimo elemento diagonal de A es exactamente cero,
!>                lo que indica que la matriz es singular y las
!>                soluciones X no se han calculado.
!>
