Propósito

: 
!>
!> ZTRSNA estima los números de condición recíprocos para valores
!> propios especificados y/o vectores propios derechos de una matriz
!> triangular superior compleja T (o de cualquier matriz Q*T*Q**H con Q
!> unitaria).
!
>

Parámetro

s
JOB 
!>          JOB es CHARACTER*1
!>          Especifica si se requieren números de condición para
!>          valores propios (S) o vectores propios (SEP):
!>          = 'E': solo para valores propios (S);
!>          = 'V': solo para vectores propios (SEP);
!>          = 'B': tanto para valores propios como para vectores
!>          propios (S y SEP).

HOWMN

Y

!>          = 'A': calcular números de condición para todos los

!> !> El recíproco del número de condición de un valor propio lambda se !> define como !> !> S(lambda) = |v**H*u| / (norm(u)*norm(v)) !> !> donde u y v son los vectores propios derechos e izquierdos de T !> correspondientes a lambda; v**H denota la transpuesta conjugada de !> v, y norm(u) denota la norma euclidiana. Estos números de !> condición recíprocos siempre se encuentran entre cero (muy mal !> condicionado) y uno (muy bien condicionado). Si n = 1, S(lambda) !> se define como 1. !> !> Una cota de error aproximada para un valor propio calculado W(i) !> viene dada por !> !> EPS * norm(T) / S(i) !> !> donde EPS es la precisión de la máquina. !> !> El recíproco del número de condición del vector propio derecho u !> correspondiente a lambda se define de la siguiente manera. !> Supongamos !> !> T = ( lambda c ) !> ( 0 T22 ) !> !> Entonces el número de condición recíproco es !> !> SEP( lambda, T22 ) = sigma-min( T22 - lambda*I ) !> !> donde sigma-min denota el valor singular más pequeño. ztrsna.f(3)

NOMBRE

ztrsna - calcula los residuos de las soluciones estimadas de un sistema lineal denso o una subrutina de cálculo de los números de condición de la(s) solución(es) estimadas de un sistema lineal denso.

SINOPSIS

SUBROUTINE ZTRSNA(
     &             UPLO, TRANS, DIAG,
     &             N, A, LDA, X, LDX,
     &             SRFAC, SCNU, SCNL,
     &             INFO )

Documentación de Funciones/Subrutinas

Esta sección proporciona documentación detallada para la subrutina ztrsna, incluyendo sus parámetros y el propósito de cada uno.

UPLO
Especifica si la matriz A es triangular superior o inferior.
TRANS
Especifica el tipo de sistema a resolver (no transpuesto, transpuesto, conjugado transpuesto).
DIAG
Especifica si la matriz A es unitaria.
N
La orden de la matriz A.
A
La matriz triangular A.
LDA
El rango de la matriz A.
X
La solución estimada del sistema lineal.
LDX
El rango de la matriz X.
SRFAC
Matrices de residuos de las soluciones estimadas.
SCNU
Números de condición de la(s) solución(es) estimada(s) a partir del numerador.
SCNL
Números de condición de la(s) solución(es) estimada(s) a partir del denominador.
INFO
Indicador de error.
