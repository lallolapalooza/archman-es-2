Documentación de Función/Subrutina

subrutina ztgsy2 (carácter trans, entero ijob, entero m, entero n, complejo*16, dimensión( lda, * ) a, entero lda, complejo*16, dimensión( ldb, * ) b, entero ldb, complejo*16, dimensión( ldc, * ) c, entero ldc, complejo*16, dimensión( ldd, * ) d, entero ldd, complejo*16, dimensión( lde, * ) e, entero lde, complejo*16, dimensión( ldf, * ) f, entero ldf, doble precisión scale, doble precisión rdsum, doble precisión rdscal, entero info)

ZTGSY2 resuelve la ecuación generalizada de Sylvester (algoritmo sin bloques).

Propósito:

!>
!> ZTGSY2 resuelve la ecuación generalizada de Sylvester
!>
!>             A * R - L * B = scale * C               (1)
!>             D * R - L * E = scale * F
!>
!> usando BLAS de Nivel 1 y 2, donde R y L son matrices desconocidas de M-por-N,
!> (A, D), (B, E) y (C, F) son pares de matrices dadas de tamaño M-por-M,
!> N-por-N y M-por-N, respectivamente. A, B, D y E son triangulares superiores
!> (es decir, (A,D) y (B,E) en forma de Schur generalizada).
!>
!> La solución (R, L) sobrescribe (C, F). 0 <= SCALE <= 1 es un factor de
!> escala de salida elegido para evitar el desbordamiento.
!>
!> En notación matricial, resolver la ecuación (1) corresponde a resolver
!> Zx = scale * b, donde Z se define como
!>
!>        Z = [ kron(In, A)  -kron(B**H, Im) ]             (2)
!>            [ kron(In, D)  -kron(E**H, Im) ],
!>
!> Ik es la matriz identidad de tamaño k y X**H es la transpuesta conjugada de X.
!> kron(X, Y) es el producto de Kronecker entre las matrices X e Y.
!>
!> Si TRANS = 'C', se resuelve y en el sistema transpuesto conjugado Z**H*y = scale*b,
!> lo que es equivalente a resolver para R y L en
!>
!>             A**H * R  + D**H * L   = scale * C           (3)
!>             R  * B**H + L  * E**H  = scale * -F
!>
!> Este caso se utiliza para calcular una estimación de Dif[(A, D), (B, E)] =
!> = sigma_min(Z) usando comunicación inversa con ZLACON.
!>
!> ZTGSY2 también (IJOB >= 1) contribuye al cálculo en ZTGSYL
!> de un límite superior de la separación entre dos pares de matrices. Entonces
!> (A, D), (B, E) son sub-polinomios de dos pares de matrices en
!> ZTGSYL.
!>

Parámetros

TRANS 
!>          TRANS es CHARACTER*1
!>          = 'N': resuelve la ecuación generalizada de Sylvester (1).
!>          = 'T': resuelve el sistema 'transpuesto' (3).
!>

IJOB

!>          IJOB es INTEGER
!>          Especifica qué tipo de funcionalidad se va a realizar.
!>          =0: resuelve (1) solamente.
!>          =1: Se calcula una contribución de este subsistema a una estimación
!>              basada en la norma de Frobenius de la separación entre dos
!>              pares de matrices. (Se usa estrategia de "look ahead").
!>          =2: Se calcula una contribución de este subsistema a una estimación
!>              basada en la norma de Frobenius de la separación entre dos
!>              pares de matrices. (Se usa DGECON en sub-sistemas.)
!>          No se hace referencia si TRANS = 'T'.
!>

M

!>          M es INTEGER
!>          En la entrada, M especifica el orden de A y D, y la dimensión
!>          de fila de C, F, R y L.
!>

N

!>          N es INTEGER
!>          En la entrada, N especifica el orden de B y E, y la dimensión
!>          de columna de C, F, R y L.
!>

A

!>          A es un array COMPLEX*16, dimensión (LDA, M)
!>          En la entrada, A contiene una matriz triangular superior.
!>

LDA

!>          LDA es INTEGER
!>          La dimensión principal de la matriz A. LDA >= max(1, M).
!>

B

!>          B es un array COMPLEX*16, dimensión (LDB, N)
!>          En la entrada, B contiene una matriz triangular superior.
!>

LDB

!>          LDB es INTEGER
!>          La dimensión principal de la matriz B. LDB >= max(1, N).
!>

C

!>          C es un array COMPLEX*16, dimensión (LDC, N)
!>          En la entrada, C contiene el lado derecho de la primera matriz
!>          ecuación en (1).
!>          En la salida, si IJOB = 0, C ha sido sobrescrito con la solución
!>          R.
!>

LDC

!>          LDC es INTEGER
!>          La dimensión principal de la matriz C. LDC >= max(1, M).
!>

D

!>          D es un array COMPLEX*16, dimensión (LDD, M)
!>          En la entrada, D contiene una matriz triangular superior.
!>

LDD

!>          LDD es INTEGER
!>          La dimensión principal de la matriz D. LDD >= max(1, M).
!>

E

!>          E es un array COMPLEX*16, dimensión (LDE, N)
!>          En la entrada, E contiene una matriz triangular superior.
!>

LDE

!>          LDE es INTEGER
!>          La dimensión principal de la matriz E. LDE >= max(1, N).
!>

F

!>          F es un array COMPLEX*16, dimensión (LDF, N)
!>          En la entrada, F contiene el lado derecho de la segunda matriz
!>          ecuación en (1).
!>          En la salida, si IJOB = 0, F ha sido sobrescrito con la solución
!>          L.
!>

LDF

!>          LDF es INTEGER
!>          La dimensión principal de la matriz F. LDF >= max(1, M).
!>

SCALE

!>          SCALE es DOUBLE PRECISION
!>          En la salida, 0 <= SCALE <= 1. Si 0 < SCALE < 1, las soluciones
!>          R y L (C y F en la entrada) contendrán las soluciones a un
!>          sistema ligeramente perturbado pero las matrices de entrada A, B, D y
!>          E no han sido modificadas. Si SCALE = 0, R y L contendrán las
!>          soluciones al sistema homogéneo con C = F = 0.
!>          Normalmente, SCALE = 1.
!>

RDSUM

!>          RDSUM es DOUBLE PRECISION
!>          En la entrada, la suma de cuadrados de las contribuciones calculadas a
!>          la estimación de Dif calculada por ZTGSYL, donde el
!>          factor de escala RDSCAL (ver abajo) ha sido extraído.
!>          En la salida, la suma de cuadrados correspondiente actualizada con las
!>          contribuciones del subsistema actual.
!>          Si TRANS = 'T', RDSUM no se modifica.
!>          NOTA: RDSUM solo tiene sentido cuando ZTGSY2 es llamado por
!>          ZTGSYL.
!>

RDSCAL

!>          RDSCAL es DOUBLE PRECISION
!>          En la entrada, factor de escala utilizado para prevenir desbordamiento
!>          en RDSUM.
!>          En la salida, RDSCAL se actualiza con respecto a las contribuciones
!>          actuales en RDSUM.
!>          Si TRANS = 'T', RDSCAL no se modifica.
!>          NOTA: RDSCAL solo tiene sentido cuando ZTGSY2 es llamado por
!>          ZTGSYL.
!>

INFO

!>          INFO es INTEGER
!>          En la salida, si INFO se establece en
!>            =0: Salida exitosa
!>            <0: Si INFO = -i, el argumento de entrada número i es ilegal.
!>            >0: Los pares de matrices (A, D) y (B, E) tienen valores propios comunes o muy
!>                cercanos.
!>

NAME

ztgsy2 - an encoder/decoder for the generalized Schur decomposition of a pair of complex matrices.

SYNOPSIS

The subroutine ztgsy2 is part of the LAPACK library.

```fortran SUBROUTINE ZTGSY2( ILASCL, IROWSL, IROWSR, IQ ) ```

Function/Subroutine Documentation

The subroutine ztgsy2 is used in the generalized Schur decomposition of a pair of complex matrices A and B.

It computes the generalized Schur decomposition of a pair of upper quasi-triangular matrices A and B:

A = Q * S * Z**H

B = Q * T * Z**H

where S and T are upper quasi-triangular matrices, and Q and Z**H are unitary matrices. The decomposition is computed in-place, so that A and B contain S and T respectively.

The subroutine takes the following arguments:

ILASCL

A logical flag. If .TRUE., the scaling of A and B is preserved.

IROWSL

An integer array of size N, where N is the dimension of the matrices. This array contains the row-wise scaling factors for the left transformation matrix Q.

IROWSR

An integer array of size N, where N is the dimension of the matrices. This array contains the row-wise scaling factors for the right transformation matrix Z**H.

IQ

A logical flag. If .TRUE., the transformation matrices Q and Z**H are returned. Otherwise, they are not computed.

The routine is called as follows:

```fortran CALL ZTGSY2( ILASCL, IROWSL, IROWSR, IQ ) ```

This is a low-level routine intended for internal use by LAPACK. For most users, the higher-level routines like ZGGES or ZGEES are more appropriate.
