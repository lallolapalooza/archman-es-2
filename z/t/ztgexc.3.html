ZTGEXC

Documentación de Función/Subrutina

subroutine ztgexc (logical wantq, logical wantz, integer n, complex*16, dimension( lda, * ) a, integer lda, complex*16, dimension( ldb, * ) b, integer ldb, complex*16, dimension( ldq, * ) q, integer ldq, complex*16, dimension( ldz, * ) z, integer ldz, integer ifst, integer ilst, integer info)

ZTGEXC

Propósito:

!>
!> ZTGEXC reordena la descomposición de Schur generalizada de un par de
!> matrices complejas (A, B), utilizando una transformación de
!> equivalencia unitaria (A, B) := Q * (A, B) * Z**H, de modo que el bloque
!> diagonal de (A, B) con índice de fila IFST se mueva a la fila ILST.
!>
!> (A, B) debe estar en forma canónica de Schur generalizada, es decir,
!> A y B son ambas triangulares superiores.
!>
!> Opcionalmente, se actualizan las matrices Q y Z de vectores de Schur
!> generalizados.
!>
!>        Q(in) * A(in) * Z(in)**H = Q(out) * A(out) * Z(out)**H
!>        Q(in) * B(in) * Z(in)**H = Q(out) * B(out) * Z(out)**H
!>

Parámetros

WANTQ 
!>          WANTQ es LOGICAL
!>          .TRUE. : actualiza la matriz de transformación izquierda Q;
!>          .FALSE.: no actualiza Q.
!>

WANTZ

!>          WANTZ es LOGICAL
!>          .TRUE. : actualiza la matriz de transformación derecha Z;
!>          .FALSE.: no actualiza Z.
!>

N

!>          N es INTEGER
!>          El orden de las matrices A y B. N >= 0.
!>

A

!>          A es un array COMPLEX*16, dimensión (LDA,N)
!>          En la entrada, la matriz triangular superior A en el par (A, B).
!>          En la salida, la matriz A actualizada.
!>

LDA

!>          LDA es INTEGER
!>          La dimensión principal del array A. LDA >= max(1,N).
!>

B

!>          B es un array COMPLEX*16, dimensión (LDB,N)
!>          En la entrada, la matriz triangular superior B en el par (A, B).
!>          En la salida, la matriz B actualizada.
!>

LDB

!>          LDB es INTEGER
!>          La dimensión principal del array B. LDB >= max(1,N).
!>

Q

!>          Q es un array COMPLEX*16, dimensión (LDQ,N)
!>          En la entrada, si WANTQ = .TRUE., la matriz unitaria Q.
!>          En la salida, la matriz Q actualizada.
!>          Si WANTQ = .FALSE., Q no se referencia.
!>

LDQ

!>          LDQ es INTEGER
!>          La dimensión principal del array Q. LDQ >= 1;
!>          Si WANTQ = .TRUE., LDQ >= N.
!>

Z

!>          Z es un array COMPLEX*16, dimensión (LDZ,N)
!>          En la entrada, si WANTZ = .TRUE., la matriz unitaria Z.
!>          En la salida, la matriz Z actualizada.
!>          Si WANTZ = .FALSE., Z no se referencia.
!>

LDZ

!>          LDZ es INTEGER
!>          La dimensión principal del array Z. LDZ >= 1;
!>          Si WANTZ = .TRUE., LDZ >= N.
!>

IFST

!>          IFST es INTEGER
!>

ILST

!>          ILST es INTEGER
!>          Especifica la reordenación de los bloques diagonales de (A, B).
!>          El bloque con índice de fila IFST se mueve a la fila ILST, mediante
!>          una secuencia de intercambios entre bloques adyacentes.
!>

INFO

!>          INFO es INTEGER
!>           =0:  Salida exitosa.
!>           <0:  si INFO = -i, el i-ésimo argumento tenía un valor ilegal.
!>           =1:  La matriz par transformada (A, B) estaría demasiado lejos
!>                de la forma de Schur generalizada; el problema está mal
!>                condicionado. (A, B) puede haber sido reordenada parcialmente,
!>                y ILST apunta a la primera fila de la posición actual
!>                del bloque que se está moviendo.
!>
