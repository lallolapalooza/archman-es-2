subroutine ztrsen (character job, character compq, logical, dimension( * ) select, integer n, complex*16, dimension( ldt, * ) t, integer ldt, complex*16, dimension( ldq, * ) q, integer ldq, complex*16, dimension( * ) w, integer m, double precision s, double precision sep, complex*16, dimension( * ) work, integer lwork, integer info)

ZTRSEN

Propósito:

!>
!> ZTRSEN reordena la factorización de Schur de una matriz compleja
!> A = Q*T*Q**H, de modo que un clúster seleccionado de autovalores aparezca
!> en las posiciones principales de la diagonal de la matriz triangular superior
!> T, y las columnas principales de Q formen una base ortonormal del
!> subespacio invariante derecho correspondiente.
!>
!> Opcionalmente, la rutina calcula los números de condición recíprocos del
!> clúster de autovalores y/o el subespacio invariante.
!>

Parámetros

JOB 
!>          JOB es CHARACTER*1
!>          Especifica si se requieren números de condición para el
!>          clúster de autovalores (S) o el subespacio invariante (SEP):
!>          = 'N': ninguno;
!>          = 'E': solo para autovalores (S);
!>          = 'V': solo para subespacio invariante (SEP);
!>          = 'B': para autovalores y subespacio invariante (S y
!>                 SEP).
!>

COMPQ

!>          COMPQ es CHARACTER*1
!>          = 'V': actualiza la matriz Q de vectores de Schur;
!>          = 'N': no actualiza Q.
!>

SELECT

!>          SELECT es un array LOGICAL, de dimensión (N)
!>          SELECT especifica los autovalores en el clúster seleccionado. Para
!>          seleccionar el j-ésimo autovalor, SELECT(j) debe ser .TRUE..
!>

N

!>          N es INTEGER
!>          El orden de la matriz T. N >= 0.
!>

T

!>          T es un array COMPLEX*16, de dimensión (LDT,N)
!>          En la entrada, la matriz triangular superior T.
!>          En la salida, T se sobrescribe con la matriz T reordenada, con los
!>          autovalores seleccionados como elementos diagonales principales.
!>

LDT

!>          LDT es INTEGER
!>          La dimensión principal del array T. LDT >= max(1,N).
!>

Q

!>          Q es un array COMPLEX*16, de dimensión (LDQ,N)
!>          En la entrada, si COMPQ = 'V', la matriz Q de vectores de Schur.
!>          En la salida, si COMPQ = 'V', Q ha sido postmultiplicada por la
!>          matriz de transformación unitaria que reordena T; las M columnas
!>          principales de Q forman una base ortonormal para el subespacio
!>          invariante especificado.
!>          Si COMPQ = 'N', Q no se referencia.
!>

LDQ

!>          LDQ es INTEGER
!>          La dimensión principal del array Q.
!>          LDQ >= 1; y si COMPQ = 'V', LDQ >= N.
!>

W

!>          W es un array COMPLEX*16, de dimensión (N)
!>          Los autovalores reordenados de T, en el mismo orden en que aparecen
!>          en la diagonal de T.
!>

M

!>          M es INTEGER
!>          La dimensión del subespacio invariante especificado.
!>          0 <= M <= N.
!>

S

!>          S es DOUBLE PRECISION
!>          Si JOB = 'E' o 'B', S es un límite inferior del número de condición
!>          recíproco para el clúster seleccionado de autovalores.
!>          S no puede subestimar el número de condición recíproco real
!>          en más de un factor de sqrt(N). Si M = 0 o N, S = 1.
!>          Si JOB = 'N' o 'V', S no se referencia.
!>

SEP

!>          SEP es DOUBLE PRECISION
!>          Si JOB = 'V' o 'B', SEP es el número de condición recíproco estimado
!>          del subespacio invariante especificado. Si
!>          M = 0 o N, SEP = norm(T).
!>          Si JOB = 'N' o 'E', SEP no se referencia.
!>

WORK

!>          WORK es un array COMPLEX*16, de dimensión (MAX(1,LWORK))
!>          En la salida, si INFO = 0, WORK(1) devuelve el LWORK óptimo.
!>

LWORK

!>          LWORK es INTEGER
!>          La dimensión del array WORK.
!>          Si JOB = 'N', LWORK >= 1;
!>          si JOB = 'E', LWORK = max(1,M*(N-M));
!>          si JOB = 'V' o 'B', LWORK >= max(1,2*M*(N-M)).
!>
!>          Si LWORK = -1, entonces se asume una consulta de espacio de trabajo; la rutina
!>          solo calcula el tamaño óptimo del array WORK, devuelve
!>          este valor como la primera entrada del array WORK, y no se emite ningún mensaje
!>          de error relacionado con LWORK por XERBLA.
!>

INFO

!>          INFO es INTEGER
!>          = 0:  salida exitosa
!>          < 0:  si INFO = -i, el i-ésimo argumento tenía un valor ilegal
!>

Detalles Adicionales:

!>
!>  ZTRSEN primero recopila los autovalores seleccionados calculando una transformación unitaria
!>  Z para moverlos a la esquina superior izquierda de T. En otras palabras, los
!>  autovalores seleccionados son los autovalores de T11 en:
!>
!>          Z**H * T * Z = ( T11 T12 ) n1
!>                         (  0  T22 ) n2
!>                            n1  n2
!>
!>  donde N = n1+n2. Las primeras n1 columnas de Z abarcan el subespacio
!>  invariante especificado de T.
!>
!>  Si T se ha obtenido de la factorización de Schur de una matriz
!>  A = Q*T*Q**H, entonces la factorización de Schur reordenada de A es dada por
!>  A = (Q*Z)*(Z**H*T*Z)*(Q*Z)**H, y las primeras n1 columnas de Q*Z abarcan el
!>  subespacio invariante correspondiente de A.
!>
!>  El número de condición recíproco del promedio de los autovalores de
!>  T11 puede ser devuelto en S. S se encuentra entre 0 (muy mal condicionado)
!>  y 1 (muy bien condicionado). Se calcula de la siguiente manera. Primero calculamos
!>  R tal que
!>
!>                         P = ( I  R ) n1
!>                             ( 0  0 ) n2
!>                               n1 n2
!>
!>  es el proyector sobre el subespacio invariante asociado con T11.
!>  R es la solución de la ecuación de Sylvester:
!>
!>                        T11*R - R*T22 = T12.
!>
!>  Sea F-norm(M) la norma de Frobenius de M y 2-norm(M) la norma 2 de M. Entonces S se calcula como el límite inferior
!>
!>                      (1 + F-norm(R)**2)**(-1/2)
!>
!>  del recíproco de 2-norm(P), el número de condición recíproco real.
!>  S no puede subestimar 1 / 2-norm(P) en más de un factor de
!>  sqrt(N).
!>
!>  Un límite de error aproximado para el promedio calculado de los
!>  autovalores de T11 es
!>
!>                         EPS * norm(T) / S
!>
!>  donde EPS es la precisión de la máquina.
!>
!>  El número de condición recíproco del subespacio invariante derecho
!>  cubierto por las primeras n1 columnas de Z (o de Q*Z) se devuelve en SEP.
!>  SEP se define como la separación de T11 y T22:
!>
!>                     sep( T11, T22 ) = sigma-min( C )
!>
!>  donde sigma-min(C) es el valor singular mínimo de la matriz
!>  n1*n2 por n1*n2
!>
!>     C  = kprod( I(n2), T11 ) - kprod( transpose(T22), I(n1) )
!>
!>  I(m) es una matriz identidad de m por m, y kprod denota el producto de Kronecker.
!>  Estimamos sigma-min(C) con el recíproco de una estimación
!>  de la norma 1 de inverse(C). La norma 1 recíproca real de inverse(C)
!>  no puede diferir de sigma-min(C) en más de un factor de sqrt(n1*n2).
!>
!>  Cuando SEP es pequeño, pequeños cambios en T pueden causar grandes cambios en
!>  el subespacio invariante. Un límite aproximado para el error angular máximo i

NAME

ZTRSEN - ZTRSEN computes the Schur factorization of a general matrix.

SYNOPSIS

  SUBROUTINE ZTRSEN(
     JOB, COMPQ, SELECT, N, A, LDA, DESCR, M, W, LWORK, WORK, IWORK,
     INFO )

  CHARACTER JOB, COMPQ

  LOGICAL SELECT(*)

  INTEGER N, LDA, M, LWORK, INFO

  COMPLEX*16 A( LDA, * ), W( * )

  INTEGER DESCR( * ), IWORK( * )

  COMPLEX*16 WORK( * )

Function/Subroutine Documentation

ZTRSEN computes the Schur factorization of a general triangular matrix. It is used to determine the accuracy of the computed Schur factorization of a general matrix.

The Schur factorization of a general matrix A is given by

  A = Q * T * Q**H

where Q is a unitary matrix and T is an upper triangular matrix.

In the case of the Schur factorization of a general matrix A, this subroutine can be used to determine the accuracy of the computed Schur factorization.

The function is used to determine the accuracy of the computed Schur factorization of a general matrix.

Arguments:

JOB
CHARACTER*1. Specifies whether to reorder the triangular matrix T.
  • 'N': T is not reordered.
  • 'S': T is reordered such that the first M diagonal elements are selected.
COMPQ
CHARACTER*1. Specifies whether to compute the matrix Q.
  • 'N': Q is not computed.
  • 'V': Q is computed and returned.
SELECT
LOGICAL array of dimension N. If JOB is 'S', SELECT(I) specifies whether the eigenvalue A(I,I) is selected.
  • True: A(I,I) is selected.
  • False: A(I,I) is not selected.
N
INTEGER. The order of the triangular matrix A. N >= 0.
A
COMPLEX*16 array of dimension (LDA, N). On entry, A contains the upper triangular matrix T. On exit, if COMPQ is 'V', A contains the Schur factorization of the original matrix. Otherwise, the contents of A are overwritten.
LDA
INTEGER. The leading dimension of the array A. LDA >= max(1, N).
DESCR
INTEGER array of dimension 4.
  • DESCR(1) = number of blocks
  • DESCR(2) = number of scalars
  • DESCR(3) = number of complex pairs
  • DESCR(4) = block size
The array DESCR is used to describe the block structure of the triangular matrix T. This is used for optimizing the computation of the Schur factorization.
M
INTEGER. On exit, M is the number of selected eigenvalues, i.e., the number of columns of the computed Schur factorization.
  • If JOB = 'N', M = 0.
  • If JOB = 'S', M = sum(SELECT(i) for i=1 to N).
W
COMPLEX*16 array of dimension N. On exit, W contains the selected eigenvalues, in the same order as they appear on the diagonal of A.
LWORK
INTEGER. The dimension of the array WORK. LWORK >= max(1, N). For optimal performance, LWORK >= N*NB, where NB is the block size for the block Schur algorithm.
WORK
COMPLEX*16 array of dimension (LWORK).
  • If LWORK = -1, then the optimal dimension for WORK is returned in WORK(1).
  • WORK is used as scratch space for the computation of the Schur factorization.
IWORK
INTEGER array of dimension N.
  • IWORK is used as scratch space for the computation of the Schur factorization.
INFO
INTEGER.
  • 0: successful exit
  • < 0: if INFO = -i, the i-th argument had an illegal value
  • > 0: if INFO = i, the i-th eigenvalue could not be reordered. This is an unlikely error condition.

The right invariant subspace is computed as

!>
!>                      EPS * norm(T) / SEP
!>
