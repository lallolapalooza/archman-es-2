Documentación de la función/subrutina

subrutina ztrtrs (character uplo, character trans, character diag, integer n, integer nrhs, complex*16, dimension( lda, * ) a, integer lda, complex*16, dimension( ldb, * ) b, integer ldb, integer info)

ZTRTRS

Propósito:

!>
!> ZTRTRS resuelve un sistema triangular de la forma
!>
!>    A * X = B,  A**T * X = B,  o  A**H * X = B,
!>
!> donde A es una matriz triangular de orden N, y B es una matriz N por NRHS.
!>
!> Esta subrutina verifica que A no es singular, pero los llamadores deben tener en cuenta que solo se detecta la singularidad exacta. Es concebible que uno o más elementos diagonales de A sean números subnormalmente pequeños sin que esta subrutina señale un error.
!>
!> Si la posible pérdida de precisión numérica debido a matrices casi singulares es una preocupación, el llamador debe verificar que A no es singular dentro de alguna tolerancia antes de llamar a esta subrutina.
!>

Parámetros

UPLO 
!>          UPLO es CHARACTER*1
!>          = 'U':  A es triangular superior;
!>          = 'L':  A es triangular inferior.
!>

TRANS

!>          TRANS es CHARACTER*1
!>          Especifica la forma del sistema de ecuaciones:
!>          = 'N':  A * X = B     (Sin transpuesta)
!>          = 'T':  A**T * X = B  (Transpuesta)
!>          = 'C':  A**H * X = B  (Transpuesta conjugada)
!>

DIAG

!>          DIAG es CHARACTER*1
!>          = 'N':  A es triangular no unitaria;
!>          = 'U':  A es triangular unitaria.
!>

N

!>          N es INTEGER
!>          El orden de la matriz A.  N >= 0.
!>

NRHS

!>          NRHS es INTEGER
!>          El número de lados derechos, es decir, el número de columnas
!>          de la matriz B.  NRHS >= 0.
!>

A

!>          A es un array COMPLEX*16, de dimensiones (LDA,N)
!>          La matriz triangular A.  Si UPLO = 'U', la parte superior triangular
!>          N por N líder del array A contiene la matriz triangular superior, y la parte estrictamente triangular inferior de A no se referencia. Si UPLO = 'L', la parte inferior triangular N por N líder del array A contiene la matriz triangular inferior, y la parte estrictamente triangular superior de A no se referencia. Si DIAG = 'U', los elementos diagonales de A tampoco se referencian y se asumen como 1.
!>

LDA

!>          LDA es INTEGER
!>          La dimensión líder del array A.  LDA >= max(1,N).
!>

B

!>          B es un array COMPLEX*16, de dimensiones (LDB,NRHS)
!>          En la entrada, la matriz del lado derecho B.
!>          En la salida, si INFO = 0, la matriz solución X.
!>

LDB

!>          LDB es INTEGER
!>          La dimensión líder del array B.  LDB >= max(1,N).
!>

INFO

!>          INFO es INTEGER
!>          = 0:  salida exitosa
!>          < 0: si INFO = -i, el i-ésimo argumento tenía un valor ilegal
!>          > 0:  si INFO = i, el i-ésimo elemento diagonal de A es exactamente cero,
!>               indicando que la matriz es singular y las soluciones
!>               X no se han calculado.
!>
