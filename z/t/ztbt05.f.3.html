Documentación de Función/Subrutina

subroutine ztbt05 (character uplo, character trans, character diag, integer n, integer kd, integer nrhs, complex*16, dimension( ldab, * ) ab, integer ldab, complex*16, dimension( ldb, * ) b, integer ldb, complex*16, dimension( ldx, * ) x, integer ldx, complex*16, dimension( ldxact, * ) xact, integer ldxact, double precision, dimension( * ) ferr, double precision, dimension( * ) berr, double precision, dimension( * ) reslts)

ZTBT05

Propósito:

!>
!> ZTBT05 prueba los límites de error del refinamiento iterativo para la
!> solución calculada de un sistema de ecuaciones A*X = B, donde A es una
!> matriz triangular de banda.
!>
!> RESLTS(1) = prueba del límite de error
!>           = norm(X - XACT) / ( norm(X) * FERR )
!>
!> Se devuelve un valor grande si esta relación no es menor que uno.
!>
!> RESLTS(2) = residuo de la rutina de refinamiento iterativo
!>           = el máximo de BERR / ( NZ*EPS + (*) ), donde
!>             (*) = NZ*UNFL / (min_i (abs(A)*abs(X) +abs(b))_i )
!>             y NZ = máx. número de no ceros en cualquier fila de A, más 1
!>

Parámetros

UPLO 
!>          UPLO es CHARACTER*1
!>          Especifica si la matriz A es triangular superior o inferior.
!>          = 'U':  Triangular superior
!>          = 'L':  Triangular inferior
!>

TRANS

!>          TRANS es CHARACTER*1
!>          Especifica la forma del sistema de ecuaciones.
!>          = 'N':  A * X = B  (Sin transponer)
!>          = 'T':  A'* X = B  (Transpuesta)
!>          = 'C':  A'* X = B  (Transpuesta conjugada = Transpuesta)
!>

DIAG

!>          DIAG es CHARACTER*1
!>          Especifica si la matriz A es triangular unitaria o no.
!>          = 'N':  No unitaria triangular
!>          = 'U':  Unitaria triangular
!>

N

!>          N es INTEGER
!>          El número de filas de las matrices X, B y XACT, y el
!>          orden de la matriz A.  N >= 0.
!>

KD

!>          KD es INTEGER
!>          El número de superdiagonales de la matriz A si UPLO = 'U',
!>          o el número de subdiagonales si UPLO = 'L'.  KD >= 0.
!>

NRHS

!>          NRHS es INTEGER
!>          El número de columnas de las matrices X, B y XACT.
!>          NRHS >= 0.
!>

AB

!>          AB es array COMPLEX*16, dimension (LDAB,N)
!>          La matriz de banda triangular superior o inferior A, almacenada en las
!>          primeras kd+1 filas del array. La j-ésima columna de A se almacena
!>          en la j-ésima columna del array AB de la siguiente manera:
!>          si UPLO = 'U', AB(kd+1+i-j,j) = A(i,j) para max(1,j-kd)<=i<=j;
!>          si UPLO = 'L', AB(1+i-j,j)    = A(i,j) para j<=i<=min(n,j+kd).
!>          Si DIAG = 'U', los elementos diagonales de A no se referencian
!>          y se asume que son 1.
!>

LDAB

!>          LDAB es INTEGER
!>          La dimensión principal del array AB.  LDAB >= KD+1.
!>

B

!>          B es array COMPLEX*16, dimension (LDB,NRHS)
!>          Los vectores del lado derecho para el sistema de ecuaciones
!>          lineales.
!>

LDB

!>          LDB es INTEGER
!>          La dimensión principal del array B.  LDB >= max(1,N).
!>

X

!>          X es array COMPLEX*16, dimension (LDX,NRHS)
!>          Los vectores de solución calculados. Cada vector se almacena como
!>          una columna de la matriz X.
!>

LDX

!>          LDX es INTEGER
!>          La dimensión principal del array X.  LDX >= max(1,N).
!>

XACT

!>          XACT es array COMPLEX*16, dimension (LDX,NRHS)
!>          Los vectores de solución exactos. Cada vector se almacena como
!>          una columna de la matriz XACT.
!>

LDXACT

!>          LDXACT es INTEGER
!>          La dimensión principal del array XACT.  LDXACT >= max(1,N).
!>

FERR

!>          FERR es array DOUBLE PRECISION, dimension (NRHS)
!>          Los límites de error de avance estimados para cada vector de solución
!>          X.  Si XTRUE es la solución verdadera, FERR limita la magnitud
!>          de la entrada más grande en (X - XTRUE) dividida por la magnitud
!>          de la entrada más grande en X.
!>

BERR

!>          BERR es array DOUBLE PRECISION, dimension (NRHS)
!>          El error residual componente a componente de cada vector de solución
!>          (es decir, el cambio relativo más pequeño en cualquier entrada de A
!>          o B que hace que X sea una solución exacta).
!>

RESLTS

!>          RESLTS es array DOUBLE PRECISION, dimension (2)
!>          El máximo sobre los vectores de solución NRHS de las relaciones:
!>          RESLTS(1) = norm(X - XACT) / ( norm(X) * FERR )
!>          RESLTS(2) = BERR / ( NZ*EPS + (*) )
!>
