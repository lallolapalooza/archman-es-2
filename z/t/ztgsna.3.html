subrutina ztgsna (character job, character howmny, logical, dimension( * ) select, integer n, complex*16, dimension( lda, * ) a, integer lda, complex*16, dimension( ldb, * ) b, integer ldb, complex*16, dimension( ldvl, * ) vl, integer ldvl, complex*16, dimension( ldvr, * ) vr, integer ldvr, double precision, dimension( * ) s, double precision, dimension( * ) dif, integer mm, integer m, complex*16, dimension( * ) work, integer lwork, integer, dimension( * ) iwork, integer info)

ZTGSNA

Propósito:

!>
!> ZTGSNA estima los números de condición recíprocos para valores propios
!> y/o vectores propios especificados de un par de matrices (A, B).
!>
!> (A, B) deben estar en forma canónica generalizada de Schur, es decir,
!> A y B son ambas triangulares superiores.
!>

Parámetros

JOB 
!>          JOB es CHARACTER*1
!>          Especifica si se requieren números de condición para
!>          valores propios (S) o vectores propios (DIF):
!>          = 'E': solo para valores propios (S);
!>          = 'V': solo para vectores propios (DIF);
!>          = 'B': para ambos, valores propios y vectores propios (S y DIF).
!>

HOWMNY

!>          HOWMNY es CHARACTER*1
!>          = 'A': calcular números de condición para todos los pares propios;
!>          = 'S': calcular números de condición para pares propios seleccionados
!>                 especificados por el array SELECT.
!>

SELECT

!>          SELECT es un array LOGICAL, de dimensión (N)
!>          Si HOWMNY = 'S', SELECT especifica los pares propios para los que
!>          se requieren números de condición. Para seleccionar números de
!>          condición para el j-ésimo valor propio y/o vector propio
!>          correspondiente, SELECT(j) debe establecerse en .TRUE..
!>          Si HOWMNY = 'A', SELECT no se referencia.
!>

N

!>          N es INTEGER
!>          El orden del par de matrices cuadradas (A, B). N >= 0.
!>

A

!>          A es un array COMPLEX*16, de dimensión (LDA,N)
!>          La matriz triangular superior A en el par (A,B).
!>

LDA

!>          LDA es INTEGER
!>          La dimensión principal del array A. LDA >= max(1,N).
!>

B

!>          B es un array COMPLEX*16, de dimensión (LDB,N)
!>          La matriz triangular superior B en el par (A, B).
!>

LDB

!>          LDB es INTEGER
!>          La dimensión principal del array B. LDB >= max(1,N).
!>

VL

!>          VL es un array COMPLEX*16, de dimensión (LDVL,M)
!>          Si JOB = 'E' o 'B', VL debe contener los vectores propios izquierdos de
!>          (A, B), correspondientes a los pares propios especificados por HOWMNY
!>          y SELECT. Los vectores propios deben almacenarse en columnas
!>          consecutivas de VL, tal como devuelve ZTGEVC.
!>          Si JOB = 'V', VL no se referencia.
!>

LDVL

!>          LDVL es INTEGER
!>          La dimensión principal del array VL. LDVL >= 1; y
!>          Si JOB = 'E' o 'B', LDVL >= N.
!>

VR

!>          VR es un array COMPLEX*16, de dimensión (LDVR,M)
!>          Si JOB = 'E' o 'B', VR debe contener los vectores propios derechos de
!>          (A, B), correspondientes a los pares propios especificados por HOWMNY
!>          y SELECT. Los vectores propios deben almacenarse en columnas
!>          consecutivas de VR, tal como devuelve ZTGEVC.
!>          Si JOB = 'V', VR no se referencia.
!>

LDVR

!>          LDVR es INTEGER
!>          La dimensión principal del array VR. LDVR >= 1;
!>          Si JOB = 'E' o 'B', LDVR >= N.
!>

S

!>          S es un array DOUBLE PRECISION, de dimensión (MM)
!>          Si JOB = 'E' o 'B', los números de condición recíprocos de los
!>          valores propios seleccionados, almacenados en elementos
!>          consecutivos del array.
!>          Si JOB = 'V', S no se referencia.
!>

DIF

!>          DIF es un array DOUBLE PRECISION, de dimensión (MM)
!>          Si JOB = 'V' o 'B', los números de condición recíprocos estimados de los
!>          vectores propios seleccionados, almacenados en elementos
!>          consecutivos del array.
!>          Si los valores propios no se pueden reordenar para calcular DIF(j),
!>          DIF(j) se establece en 0; esto solo puede ocurrir cuando el valor
!>          real sería muy pequeño de todos modos.
!>          Para cada valor propio/vector propio especificado por SELECT, DIF
!>          almacena una estimación basada en la norma de Frobenius de Difl.
!>          Si JOB = 'E', DIF no se referencia.
!>

MM

!>          MM es INTEGER
!>          El número de elementos en los arrays S y DIF. MM >= M.
!>

M

!>          M es INTEGER
!>          El número de elementos de los arrays S y DIF utilizados para almacenar
!>          los números de condición especificados; se utiliza un elemento por cada
!>          valor propio seleccionado. Si HOWMNY = 'A', M se establece en N.
!>

WORK

!>          WORK es un array COMPLEX*16, de dimensión (MAX(1,LWORK))
!>          Al salir, si INFO = 0, WORK(1) devuelve el LWORK óptimo.
!>

LWORK

!>          LWORK es INTEGER
!>          La dimensión del array WORK. LWORK >= max(1,N).
!>          Si JOB = 'V' o 'B', LWORK >= max(1,2*N*N).
!>

IWORK

!>          IWORK es un array INTEGER, de dimensión (N+2)
!>          Si JOB = 'E', IWORK no se referencia.
!>

INFO

!>          INFO es INTEGER
!>          = 0: Salida exitosa
!>          < 0: Si INFO = -i, el i-ésimo argumento tenía un valor ilegal
!>

Detalles adicionales:

!>
!> El recíproco del número de condición del i-ésimo valor propio generalizado
!> w = (a, b) se define como
!>
!>          S(I) = (|v**HAu|**2 + |v**HBu|**2)**(1/2) / (norm(u)*norm(v))
!>
!> donde u y v son los vectores propios derecho e izquierdo de (A, B)
!> correspondientes a w; |z| denota el valor absoluto del número complejo,
!> y norm(u) denota la norma 2 del vector u. El par (a, b) corresponde a un
!> valor propio w = a/b (= v**HAu/v**HBu) del par de matrices (A, B).
!> Si tanto a como b son cero, entonces (A,B) es singular y se devuelve S(I) = -1.
!>
!> Una cota de error aproximada en la distancia de la cuerda entre el i-ésimo
!> valor propio generalizado calculado w y el valor propio exacto
!> lambda correspondiente es
!>
!>          chord(w, lambda) <=   EPS * norm(A, B) / S(I),
!>
!> donde EPS es la precisión de la máquina.
!>
!> El recíproco del número de condición del vector propio derecho u
!> y el vector propio izquierdo v correspondientes al valor propio generalizado w
!> se define de la siguiente manera. Supongamos
!>
!>                   (A, B) = ( a   *  ) ( b  *  )  1
!>                            ( 0  A22 ),( 0 B22 )  n-1
!>                              1  n-1     1 n-1
!>
!> Entonces, el número de condición recíproco DIF(I) es
!>
!>          Difl[(a, b), (A22, B22)]  = sigma-min( Zl )
!>
!> donde sigma-min(Zl) denota el valor singular más pequeño de
!>
!>         Zl = [ kron(a, In-1) -kron(1, A22) ]
!>              [ kron(b, I
ztgsna(3) - LAPACK

NAME

ztgsna - ZTGSNA computes the norm of the reciprocal of the separation vector between the computed generalized eigenvalues and generalized eigenvectors and estimates the condition numbers of the corresponding generalized eigenvectors under the unitary equivalence Z = Q * T * Z.

SYNOPSIS

 SUBROUTINE ZTGSNA( JOB, HOWMNY, SELECT, N, A, LDA, B, LDB, Q, LDQ, Z, LDZ,
                DIFL, DIFR, SCORE, LDWORK, WORK, INFO )

Arguments:

CHARACTER JOB

Must be set to 'E' or 'V'.

If JOB = 'E', the function computes the norm of the reciprocal of the separation vector.

If JOB = 'V', the function computes the norm of the reciprocal of the separation vector and the condition number of the corresponding eigenvector.

CHARACTER HOWMNY

Must be set to 'A' or 'S'.

If HOWMNY = 'A', the separation vector in the denominator of each reciprocal norm is computed for the corresponding generalized eigenvector.

If HOWMNY = 'S', the separation vector is computed for each selected generalized eigenvector.

LOGICAL SELECT( N )

Specifies the eigenvectors for which the condition numbers are to be computed. For each i, if SELECT(I) is true, then the I-th generalized eigenvector is selected.

INTEGER N

The order of the matrices A and B.

COMPLEX*16 A( LDA, * )

The upper triangular matrix A.

INTEGER LDA

The leading dimension of the array A.

COMPLEX*16 B( LDB, * )

The upper triangular matrix B.

INTEGER LDB

The leading dimension of the array B.

COMPLEX*16 Q( LDQ, * )

The unitary matrix Q, with dimensions (N, N).

INTEGER LDQ

The leading dimension of the array Q.

COMPLEX*16 Z( LDZ, * )

The unitary matrix Z, with dimensions (N, N).

INTEGER LDZ

The leading dimension of the array Z.

DOUBLE PRECISION DIFL( N )

The diagonal elements of the matrix DIF, in the block lower triangular form.

DOUBLE PRECISION DIFR( N )

The diagonal elements of the matrix DIF, in the block upper triangular form.

DOUBLE PRECISION SCORE( N )

The reciprocal norm of the errors.

INTEGER LDWORK

The length of the array WORK.

COMPLEX*16 WORK( LDWORK )

The work array.

INTEGER INFO

Error exit flag.

Function/Subroutine Documentation

!> @brief
!>
!> ZTGSNA computes the norm of the reciprocal of the separation vector
!> between the computed generalized eigenvalues and generalized
!> eigenvectors and estimates the condition numbers of the corresponding
!> generalized eigenvectors under the unitary equivalence
!> Z = Q * T * Z.
!>
!> @param job
!> If JOB = 'E', the function computes the norm of the reciprocal of the
!> separation vector.
!> If JOB = 'V', the function computes the norm of the reciprocal of the
!> separation vector and the condition number of the corresponding
!> eigenvector.
!>
!> @param howmny
!> If HOWMNY = 'A', the separation vector in the denominator of each
!> reciprocal norm is computed for the corresponding generalized
!> eigenvector.
!> If HOWMNY = 'S', the separation vector is computed for each selected
!> generalized eigenvector.
!>
!> @param select
!> Specifies the eigenvectors for which the condition numbers are to be
!> computed. For each i, if SELECT(I) is true, then the I-th generalized
!> eigenvector is selected.
!>
!> @param n
!> The order of the matrices A and B.
!>
!> @param a
!> The upper triangular matrix A.
!>
!> @param lda
!> The leading dimension of the array A.
!>
!> @param b
!> The upper triangular matrix B.
!>
!> @param ldb
!> The leading dimension of the array B.
!>
!> @param q
!> The unitary matrix Q, with dimensions (N, N).
!>
!> @param ldq
!> The leading dimension of the array Q.
!>
!> @param z
!> The unitary matrix Z, with dimensions (N, N).
!>
!> @param ldz
!> The leading dimension of the array Z.
!>
!> @param difl
!> The diagonal elements of the matrix DIF, in the block lower
!> triangular form.
!>
!> @param difr
!> The diagonal elements of the matrix DIF, in the block upper
!> triangular form.
!>
!> @param score
!> The reciprocal norm of the errors.
!>
!> @param ldwork
!> The length of the array WORK.
!>
!> @param work
!> The work array.
!>
!> @param info
!> Error exit flag.
!>
!> @author
!> Bo Kagstrom and Peter Poromaa, Department of Computing Science, Umea University,
!> S-901 87 Umea, Sweden.
!>
!> @date
!> October 1997.
!>
!> @version
!> 3.0
!>
!> @par Details:
!> The generalized eigenvalues and eigenvectors of a matrix pair (A, B) are
!> computed by first reducing A and B to generalized Schur form
!>
!>       A = Q * T * Z
!>       B = Q * S * Z
!>
!> where T and S are upper triangular matrices, and Q and Z are unitary
!> matrices. The generalized eigenvalues are then the ratios
!> lambda(i) = T(i,i) / S(i,i).
!>
!> The function ZTGSNA is used to estimate the condition numbers of the
!> generalized eigenvectors. The generalized eigenvectors are computed by
!> solving the generalized Sylvester equation
!>
!>       A*X - lambda*B*X = 0
!>
!> for each eigenvalue lambda. The condition number of the i-th
!> generalized eigenvector is given by
!>
!>       C(i) = norm(A, B) / DIF(i)
!>
!> where DIF(i) is the separation vector, and norm(A, B) is a norm of the
!> matrix pair (A, B). The function estimates this condition number.
!>
!> The separation vector DIF(i) is computed using the Schur form of A and B.
!> Specifically, it is computed from the diagonal blocks of the matrices
!>
!>       T_11 - lambda*S_11   and   T_22 - lambda*S_22
!>
!> where T = [ T_11 T_12 ] and S = [ S_11 S_12 ].
!>             [ 0  T_22 ]         [ 0  S_22 ]
!>
!> The condition number is then estimated as
!>
!>       cond(i) = max(norm(T_11-lambda*S_11), norm(T_22-lambda*S_22)) /
!>                 min(norm(T_11-lambda*S_11), norm(T_22-lambda*S_22))
!>
!> where norm(X) denotes the 1-norm of matrix X.
!>
!> The function computes the reciprocal norm of the error in the computed
!> generalized eigenvector, which is given by
!>
!>       SCORE(i) = EPS / DIF(i)
!>
!> where EPS is the machine epsilon.
!>
!> The quantity DIFL(i) and DIFR(i) are the diagonal entries of the matrix
!> DIF in the block lower and upper triangular forms, respectively.
!>
!> The norm of the reciprocal of the separation vector is computed as
!>
!>       norm(inv(A,B)) = norm( [ inv(A11 - lambda*B11)  *  (A12 - lambda*B12) * inv(A22 - lambda*B22) ] )
!>                        [ 0                       inv(A22 - lambda*B22)                          ]
!>
!> where A = [ A11 A12 ] and B = [ B11 B12 ].
!>           [  0  A22 ]         [  0  B22 ]
!>
!> This is approximated by ZLATDF.
!>
!> An approximate error bound for a computed eigenvector VL(i) or VR(i) is
!> given by
!>
!>                      EPS * norm(A, B) / DIF(i).
!>
!> See ref. [2-3] for more details and further references.
!>
