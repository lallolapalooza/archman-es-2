Documentación de la función/subrutina

subrutina ztgsen (integer ijob, logical wantq, logical wantz, logical, dimension( * ) select, integer n, complex*16, dimension( lda, * ) a, integer lda, complex*16, dimension( ldb, * ) b, integer ldb, complex*16, dimension( * ) alpha, complex*16, dimension( * ) beta, complex*16, dimension( ldq, * ) q, integer ldq, complex*16, dimension( ldz, * ) z, integer ldz, integer m, double precision pl, double precision pr, double precision, dimension( * ) dif, complex*16, dimension( * ) work, integer lwork, integer, dimension( * ) iwork, integer liwork, integer info)

ZTGSEN

Propósito:

!>
!> ZTGSEN reordena la descomposición de Schur generalizada de un par de
!> matrices complejas (A, B) (en términos de una transformación unitaria de
!> equivalencia Q**H * (A, B) * Z), de modo que un clúster seleccionado de
!> valores propios aparezca en los bloques diagonales principales del par
!> (A,B). Las columnas principales de Q y Z forman bases unitarias de los
!> correspondientes subespacios propios (deflacionados) izquierdo y derecho.
!> (A, B) deben estar en forma canónica de Schur generalizada, es decir, A y
!> B son ambas triangulares superiores.
!>
!> ZTGSEN también calcula los valores propios generalizados
!>
!>          w(j)= ALPHA(j) / BETA(j)
!>
!> del par de matrices reordenadas (A, B).
!>
!> Opcionalmente, la rutina calcula estimaciones de los recíprocos de los
!> números de condición para valores propios y subespacios propios. Estas son
!> Difu[(A11,B11), (A22,B22)] y Difl[(A11,B11), (A22,B22)], es decir, la
!> separación entre los pares de matrices (A11, B11) y (A22,B22) que corresponden
!> al clúster seleccionado y a los valores propios fuera del clúster, respectivamente,
!> y las normas de sobre los subespacios propios izquierdo y derecho con respecto
!> al clúster seleccionado en el bloque (1,1).
!>
!>

Parámetros

IJOB 
!>          IJOB es INTEGER
!>          Especifica si se requieren números de condición para el clúster
!>          de valores propios (PL y PR) o para los subespacios de deflación
!>          (Difu y Difl):
!>           =0: Solo reordenar respecto a SELECT. Sin extras.
!>           =1: Recíproco de las normas de sobre los subespacios propios
!>               izquierdo y derecho respecto al clúster seleccionado (PL y PR).
!>           =2: Límites superiores para Difu y Difl. Estimación basada en la
!>               norma F (DIF(1:2)).
!>           =3: Estimación de Difu y Difl. Estimación basada en la norma 1
!>               (DIF(1:2)).
!>               Aproximadamente 5 veces más caro que IJOB = 2.
!>           =4: Calcular PL, PR y DIF (es decir, 0, 1 y 2 anteriores): Versión
!>               económica para obtenerlo todo.
!>           =5: Calcular PL, PR y DIF (es decir, 0, 1 y 3 anteriores)
!>

WANTQ

!>          WANTQ es LOGICAL
!>          .TRUE. : actualizar la matriz de transformación izquierda Q;
!>          .FALSE.: no actualizar Q.
!>

WANTZ

!>          WANTZ es LOGICAL
!>          .TRUE. : actualizar la matriz de transformación derecha Z;
!>          .FALSE.: no actualizar Z.
!>

SELECT

!>          SELECT es un array LOGICAL, de dimensión (N)
!>          SELECT especifica los valores propios en el clúster seleccionado.
!>          Para seleccionar un valor propio w(j), SELECT(j) debe estar
!>          establecido a .TRUE..
!>

N

!>          N es INTEGER
!>          El orden de las matrices A y B. N >= 0.
!>

A

!>          A es COMPLEX*16, de dimensión (LDA,N)
!>          En la entrada, la matriz triangular superior A, en forma canónica
!>          de Schur generalizada.
!>          En la salida, A se sobrescribe con la matriz reordenada A.
!>

LDA

!>          LDA es INTEGER
!>          La dimensión principal del array A. LDA >= max(1,N).
!>

B

!>          B es COMPLEX*16, de dimensión (LDB,N)
!>          En la entrada, la matriz triangular superior B, en forma canónica
!>          de Schur generalizada.
!>          En la salida, B se sobrescribe con la matriz reordenada B.
!>

LDB

!>          LDB es INTEGER
!>          La dimensión principal del array B. LDB >= max(1,N).
!>

ALPHA

!>          ALPHA es un array COMPLEX*16, de dimensión (N)
!>

BETA

!>          BETA es un array COMPLEX*16, de dimensión (N)
!>
!>          Los elementos diagonales de A y B, respectivamente, cuando el par
!>          (A,B) ha sido reducido a forma de Schur generalizada.
!>          ALPHA(i)/BETA(i) i=1,...,N son los valores propios generalizados.
!>

Q

!>          Q es COMPLEX*16, de dimensión (LDQ,N)
!>          En la entrada, si WANTQ = .TRUE., Q es una matriz N-por-N.
!>          En la salida, Q ha sido postmultiplicada por la matriz de
!>          transformación unitaria izquierda que reordena (A, B); Las M
!>          columnas principales de Q forman bases ortonormales para el par
!>          seleccionado de subespacios propios izquierdos (deflacionados).
!>          Si WANTQ = .FALSE., Q no se referencia.
!>

LDQ

!>          LDQ es INTEGER
!>          La dimensión principal del array Q. LDQ >= 1.
!>          Si WANTQ = .TRUE., LDQ >= N.
!>

Z

!>          Z es COMPLEX*16, de dimensión (LDZ,N)
!>          En la entrada, si WANTZ = .TRUE., Z es una matriz N-por-N.
!>          En la salida, Z ha sido postmultiplicada por la matriz de
!>          transformación unitaria izquierda que reordena (A, B); Las M
!>          columnas principales de Z forman bases ortonormales para el par
!>          seleccionado de subespacios propios izquierdos (deflacionados).
!>          Si WANTZ = .FALSE., Z no se referencia.
!>

LDZ

!>          LDZ es INTEGER
!>          La dimensión principal del array Z. LDZ >= 1.
!>          Si WANTZ = .TRUE., LDZ >= N.
!>

M

!>          M es INTEGER
!>          La dimensión del par seleccionado de subespacios propios izquierdos
!>          y derechos (deflacionados), 0 <= M <= N.
!>

PL

!>          PL es DOUBLE PRECISION
!>

PR

!>          PR es DOUBLE PRECISION
!>
!>          Si IJOB = 1, 4 o 5, PL, PR son límites inferiores del recíproco
!>          de la norma de sobre los subespacios propios izquierdo y derecho
!>          con respecto al clúster seleccionado.
!>          0 < PL, PR <= 1.
!>          Si M = 0 o M = N, PL = PR = 1.
!>          Si IJOB = 0, 2 o 3, PL, PR no se referencian.
!>

DIF

!>          DIF es un array DOUBLE PRECISION, de dimensión (2).
!>          Si IJOB >= 2, DIF(1:2) almacenan las estimaciones de Difu y Difl.
!>          Si IJOB = 2 o 4, DIF(1:2) son límites superiores basados en la
!>          norma F para Difu y Difl. Si IJOB = 3 o 5, DIF(1:2) son estimaciones
!>          basadas en la norma 1 de Difu y Difl, calculadas usando
!>          comunicación inversa con ZLACN2.
!>          Si M = 0 o N, DIF(1:2) = Norma-F([A, B]).
!>          Si IJOB = 0 o 1, DIF no se referencia.
!>

WORK

!>          WORK es un array COMPLEX*16, de dimensión (MAX(1,LWORK))
!>          En la salida, si INFO = 0, WORK(1) devuelve el LWORK óptimo.
!>

LWORK

!>          LWORK es INTEGER
!>          La dimensión del array WORK

Detalles Adicionales:

!>
!> ZTGSEN primero recopila los valores propios seleccionados calculando matrices unitarias
!> U y W que los mueven a la esquina superior izquierda de (A, B). En otras
!> palabras, los valores propios seleccionados son los valores propios de (A11, B11) en
!>
!> U**H*(A, B)*W = (A11 A12) (B11 B12) n1
!>                 ( 0  A22),( 0  B22) n2
!>                  n1  n2    n1  n2
!>
!> donde N = n1+n2 y U**H significa la transpuesta conjugada de U. Las primeras
!> n1 columnas de U y W abarcan los pares especificados de subespacios propios
!> (subespacios de deflación) izquierdos y derechos de (A, B).
!>
!> Si (A, B) se ha obtenido de la descomposición de Schur real generalizada
!> de un par de matrices (C, D) = Q*(A, B)*Z**H, entonces la
!> forma de Schur generalizada reorganizada de (C, D) está dada por
!>
!> (C, D) = (Q*U)*(U**H *(A, B)*W)*(Z*W)**H,
!>
!> y las primeras n1 columnas de Q*U y Z*W abarcan los correspondientes
!> subespacios de deflación de (C, D) (Q y Z almacenan Q*U y Z*W, respectivamente).
!>
!> Tenga en cuenta que si el valor propio seleccionado está suficientemente mal condicionado,
!> entonces su valor puede diferir significativamente de su valor antes
!> de la reorganización.
!>
!> Los recíprocos de los números de condición de los subespacios propios izquierdo y derecho
!> abarcados por las primeras n1 columnas de U y W (o Q*U y Z*W) pueden
!> devolverse en DIF(1:2), correspondientes a Difu y Difl, respectivamente.
!>
!> Difu y Difl se definen como:
!>
!> Difu[(A11, B11), (A22, B22)] = sigma-min( Zu )
!> y
!> Difl[(A11, B11), (A22, B22)] = Difu[(A22, B22), (A11, B11)],
!>
!> donde sigma-min(Zu) es el valor singular mínimo de la matriz
!>
!> Zu = [ kron(In2, A11)  -kron(A22**H, In1) ]
!>      [ kron(In2, B11)  -kron(B22**H, In1) ].
!>
!> Aquí, Inx es la matriz identidad de tamaño nx y A22**H es la
!> transpuesta conjugada de A22. kron(X, Y) es el producto de Kronecker entre
!> las matrices X e Y.
!>
!> Cuando DIF(2) es pequeño, pequeños cambios en (A, B) pueden causar grandes cambios
!> en el subespacio de deflación. Un límite aproximado (asintótico) del
!> error angular máximo en los subespacios de deflación calculados es
!>
!> EPS * norm((A, B)) / DIF(2),
!>
!> donde EPS es la precisión de la máquina.
!>
!> Los recíprocos de las normas de los proyectores sobre los subespacios propios izquierdo y derecho
!> asociados con (A11, B11) pueden devolverse en PL y PR.
!> Se calculan de la siguiente manera. Primero calculamos L y R de modo que
!> P*(A, B)*Q sea diagonal por bloques, donde
!>
!> P = ( I -L ) n1           Q = ( I R ) n1
!>     ( 0  I ) n2    y        ( 0 I ) n2
!>       n1 n2                    n1 n2
!>
!> y (L, R) es la solución de la ecuación de Sylvester generalizada
!>
!> A11*R - L*A22 = -A12
!> B11*R - L*B22 = -B12
!>
!> Entonces PL = (F-norm(L)**2+1)**(-1/2) y PR = (F-norm(R)**2+1)**(-1/2).
!> Un límite aproximado (asintótico) del error absoluto promedio de
!> los valores propios seleccionados es
!>
!> EPS * norm((A, B)) / PL.
!>
!> Existen también límites de error globales que son válidos para perturbaciones
!> hasta cierta restricción: Un límite inferior (x) sobre el menor
!> F-norm(E,F) para el cual un valor propio de (A11, B11) puede moverse y
!> fusionarse con un valor propio de (A22, B22) bajo una perturbación (E,F),
!> (es decir, (A + E, B + F), es
!>
!> x = min(Difu,Difl)/((1/(PL*PL)+1/(PR*PR))**(1/2)+2*max(1/PL,1/PR)).
!>
!> Se puede calcular un límite aproximado de x a partir de DIF(1:2), PL y PR.
!>
!> Si y = ( F-norm(E,F) / x) <= 1, los ángulos entre los subespacios propios
!> perturbados (L', R') y no perturbados (L, R) izquierdos y derechos
!> asociados con el clúster seleccionado en los bloques (1,1) pueden acotarse como
!>
!> max-angle(L, L') <= arctan( y * PL / (1 - y * (1 - PL * PL)**(1/2))
!> max-angle(R, R') <= arctan( y * PR / (1 - y * (1 - PR * PR)**(1/2))
!>
!> Consulte la Guía del Usuario de LAPACK, sección 4.11 o las siguientes referencias
!> para obtener más información.
!>
!> Tenga en cuenta que si no se desea el método predeterminado para calcular la estimación DIF basada en la norma de Frobenius
!> (consulte ZLATDF), entonces el parámetro
!> IDIFJB (consulte más abajo) debe cambiarse de 3 a 4 (se utilizará la rutina ZLATDF
!> (IJOB = 2)). Consulte ZTGSYL para obtener más detalles.
!>
