Documentación de la función/subrutina

subrutina ztrsna (character job, character howmny, logical, dimension( * ) select, integer n, complex*16, dimension( ldt, * ) t, integer ldt, complex*16, dimension( ldvl, * ) vl, integer ldvl, complex*16, dimension( ldvr, * ) vr, integer ldvr, double precision, dimension( * ) s, double precision, dimension( * ) sep, integer mm, integer m, complex*16, dimension( ldwork, * ) work, integer ldwork, double precision, dimension( * ) rwork, integer info)

ZTRSNA

Propósito:

!>
!> ZTRSNA estima los recíprocos de los números de condición para
!> valores propios y/o vectores propios derechos especificados de una
!> matriz triangular superior compleja T (o de cualquier matriz
!> Q*T*Q**H con Q unitaria).
!>

Parámetros

JOB 
!>          JOB es CHARACTER*1
!>          Especifica si se requieren números de condición para
!>          valores propios (S) o vectores propios (SEP):
!>          = 'E': solo para valores propios (S);
!>          = 'V': solo para vectores propios (SEP);
!>          = 'B': para ambos valores propios y vectores propios (S y SEP).
!>

HOWMNY

!>          HOWMNY es CHARACTER*1
!>          = 'A': calcular los números de condición para todos los
!>                 pares propios;
!>          = 'S': calcular los números de condición para los pares
!>                 propios seleccionados especificados por el array SELECT.
!>

SELECT

!>          SELECT es un array LOGICAL, de dimensión (N)
!>          Si HOWMNY = 'S', SELECT especifica los pares propios para los
!>          que se requieren los números de condición. Para seleccionar
!>          los números de condición para el j-ésimo par propio,
!>          SELECT(j) debe establecerse en .TRUE..
!>          Si HOWMNY = 'A', SELECT no se referencia.
!>

N

!>          N es INTEGER
!>          El orden de la matriz T. N >= 0.
!>

T

!>          T es un array COMPLEX*16, de dimensión (LDT,N)
!>          La matriz triangular superior T.
!>

LDT

!>          LDT es INTEGER
!>          La dimensión principal del array T. LDT >= max(1,N).
!>

VL

!>          VL es un array COMPLEX*16, de dimensión (LDVL,M)
!>          Si JOB = 'E' o 'B', VL debe contener los vectores propios
!>          izquierdos de T (o de cualquier Q*T*Q**H con Q unitaria),
!>          correspondientes a los pares propios especificados por HOWMNY
!>          y SELECT. Los vectores propios deben almacenarse en columnas
!>          consecutivas de VL, tal como devuelto por ZHSEIN o ZTREVC.
!>          Si JOB = 'V', VL no se referencia.
!>

LDVL

!>          LDVL es INTEGER
!>          La dimensión principal del array VL.
!>          LDVL >= 1; y si JOB = 'E' o 'B', LDVL >= N.
!>

VR

!>          VR es un array COMPLEX*16, de dimensión (LDVR,M)
!>          Si JOB = 'E' o 'B', VR debe contener los vectores propios
!>          derechos de T (o de cualquier Q*T*Q**H con Q unitaria),
!>          correspondientes a los pares propios especificados por HOWMNY
!>          y SELECT. Los vectores propios deben almacenarse en columnas
!>          consecutivas de VR, tal como devuelto por ZHSEIN o ZTREVC.
!>          Si JOB = 'V', VR no se referencia.
!>

LDVR

!>          LDVR es INTEGER
!>          La dimensión principal del array VR.
!>          LDVR >= 1; y si JOB = 'E' o 'B', LDVR >= N.
!>

S

!>          S es un array DOUBLE PRECISION, de dimensión (MM)
!>          Si JOB = 'E' o 'B', los recíprocos de los números de condición
!>          de los valores propios seleccionados, almacenados en elementos
!>          consecutivos del array. Así, S(j), SEP(j), y las columnas j de
!>          VL y VR corresponden todos al mismo par propio (pero no, en
!>          general, al j-ésimo par propio, a menos que todos los pares
!>          propios sean seleccionados).
!>          Si JOB = 'V', S no se referencia.
!>

SEP

!>          SEP es un array DOUBLE PRECISION, de dimensión (MM)
!>          Si JOB = 'V' o 'B', los recíprocos de los números de condición
!>          estimados de los vectores propios seleccionados, almacenados en
!>          elementos consecutivos del array.
!>          Si JOB = 'E', SEP no se referencia.
!>

MM

!>          MM es INTEGER
!>          El número de elementos en los arrays S (si JOB = 'E' o 'B')
!!>          y/o SEP (si JOB = 'V' o 'B'). MM >= M.
!>

M

!>          M es INTEGER
!>          El número de elementos de los arrays S y/o SEP realmente
!>          utilizados para almacenar los números de condición estimados.
!>          Si HOWMNY = 'A', M se establece en N.
!>

WORK

!>          WORK es un array COMPLEX*16, de dimensión (LDWORK,N+6)
!>          Si JOB = 'E', WORK no se referencia.
!>

LDWORK

!>          LDWORK es INTEGER
!>          La dimensión principal del array WORK.
!>          LDWORK >= 1; y si JOB = 'V' o 'B', LDWORK >= N.
!>

RWORK

!>          RWORK es un array DOUBLE PRECISION, de dimensión (N)
!>          Si JOB = 'E', RWORK no se referencia.
!>

INFO

!>          INFO es INTEGER
!>          = 0: salida exitosa
!>          < 0: si INFO = -i, el i-ésimo argumento tenía un valor ilegal
!>

Detalles Adicionales:

!>
!>  El recíproco del número de condición de un valor propio lambda se
!>  define como
!>
!>          S(lambda) = |v**H*u| / (norm(u)*norm(v))
!>
!>  donde u y v son los vectores propios derecho e izquierdo de T
!>  correspondientes a lambda; v**H denota la transpuesta conjugada de v,
!>  y norm(u) denota la norma Euclidiana. Estos recíprocos de números de
!>  condición siempre están entre cero (muy mal condicionado) y uno (muy
!>  bien condicionado). Si n = 1, S(lambda) se define como 1.
!>
!>  Una cota de error aproximada para un valor propio calculado W(i)
!>  viene dada por
!>
!>                      EPS * norm(T) / S(i)
!>
!>  donde EPS es la precisión de la máquina.
!>
!>  El recíproco del número de condición del vector propio derecho u
!>  correspondiente a lambda se define como sigue. Supongamos
!>
!>              T = ( lambda  c  )
!>                  (   0    T22 )
!>
!>  Entonces el recíproco del número de condición es
!>
!>          SEP( lambda, T22 ) = sigma-min( T22 - lambda*I )
!>
!>  donde sigma-min denota el valor singular mínimo. Aproximamos
!>  el valor singular mínimo por el recíproco de una estimación de la
!>  norma 1 de la inversa de T22 - lambda*I. Si n = 1, SEP(1) se
!>  define como abs(T(1,1)).
!>
!>  Una cota de error aproximada para un vector propio derecho calculado
!>  VR(i) viene dada por
!>
!>                      EPS * norm(T) / SEP(i)
!>
