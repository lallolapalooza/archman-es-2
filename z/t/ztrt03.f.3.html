subrutina ztrt03 (character uplo, character trans, character diag, integer n, integer nrhs, complex*16, dimension( lda, * ) a, integer lda, double precision scale, double precision, dimension( * ) cnorm, double precision tscal, complex*16, dimension( ldx, * ) x, integer ldx, complex*16, dimension( ldb, * ) b, integer ldb, complex*16, dimension( * ) work, double precision resid)

ZTRT03

Propósito:

!>
!> ZTRT03 calcula el residuo para la solución de un sistema triangular escalado
!> de ecuaciones A*x = s*b,  A**T *x = s*b,  o  A**H *x = s*b.
!> Aquí A es una matriz triangular, A**T denota la transpuesta de A, A**H
!> denota la transpuesta conjugada de A, s es un escalar y x e b son
!> matrices N por NRHS. La relación de prueba es el máximo sobre el número de
!> lados derechos de
!>    norm(s*b - op(A)*x) / ( norm(op(A)) * norm(x) * EPS ),
!> donde op(A) denota A, A**T, o A**H, y EPS es el épsilon de la máquina.
!>

Parámetros

UPLO 
!>          UPLO es CHARACTER*1
!>          Especifica si la matriz A es triangular superior o inferior.
!>          = 'U':  Triangular superior
!>          = 'L':  Triangular inferior
!>

TRANS

!>          TRANS es CHARACTER*1
!>          Especifica la operación aplicada a A.
!>          = 'N':  A *x = s*b     (Sin transponer)
!>          = 'T':  A**T *x = s*b  (Transpuesta)
!>          = 'C':  A**H *x = s*b  (Transpuesta conjugada)
!>

DIAG

!>          DIAG es CHARACTER*1
!>          Especifica si la matriz A es unitaria triangular o no.
!>          = 'N':  Triangular no unitaria
!>          = 'U':  Triangular unitaria
!>

N

!>          N es INTEGER
!>          El orden de la matriz A.  N >= 0.
!>

NRHS

!>          NRHS es INTEGER
!>          El número de lados derechos, es decir, el número de columnas
!>          de las matrices X y B.  NRHS >= 0.
!>

A

!>          A es un array COMPLEX*16, de dimensión (LDA,N)
!>          La matriz triangular A.  Si UPLO = 'U', la parte superior triangular
!>          superior de dimensión N por N de la matriz A contiene la matriz
!>          triangular superior, y la parte estrictamente triangular inferior
!>          de A no se referencia. Si UPLO = 'L', la parte inferior triangular
!>          inferior de dimensión N por N de la matriz A contiene la matriz
!>          triangular inferior, y la parte estrictamente triangular superior
!>          de A no se referencia. Si DIAG = 'U', los elementos diagonales de A
!>          tampoco se referencian y se asumen como 1.
!>

LDA

!>          LDA es INTEGER
!>          La dimensión principal del array A.  LDA >= max(1,N).
!>

SCALE

!>          SCALE es DOUBLE PRECISION
!>          El factor de escala s utilizado al resolver el sistema triangular.
!>

CNORM

!>          CNORM es un array DOUBLE PRECISION, de dimensión (N)
!>          Las normas 1 de las columnas de A, sin contar la diagonal.
!>

TSCAL

!>          TSCAL es DOUBLE PRECISION
!>          El factor de escala utilizado al calcular las normas 1 en CNORM.
!>          CNORM realmente contiene las normas de columna de TSCAL*A.
!>

X

!>          X es un array COMPLEX*16, de dimensión (LDX,NRHS)
!>          Los vectores de solución calculados para el sistema de ecuaciones
!>          lineales.
!>

LDX

!>          LDX es INTEGER
!>          La dimensión principal del array X.  LDX >= max(1,N).
!>

B

!>          B es un array COMPLEX*16, de dimensión (LDB,NRHS)
!>          Los vectores del lado derecho para el sistema de ecuaciones
!>          lineales.
!>

LDB

!>          LDB es INTEGER
!>          La dimensión principal del array B.  LDB >= max(1,N).
!>

WORK

!>          WORK es un array COMPLEX*16, de dimensión (N)
!>

RESID

!>          RESID es DOUBLE PRECISION
!>          El máximo sobre el número de lados derechos de
!>          norm(op(A)*x - s*b) / ( norm(op(A)) * norm(x) * EPS ).
!>
