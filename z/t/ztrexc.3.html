Documentación de la Función/Subrutina

subrutina ztrexc (character compq, integer n, complex*16, dimension( ldt, * ) t, integer ldt, complex*16, dimension( ldq, * ) q, integer ldq, integer ifst, integer ilst, integer info)

ZTREXC

Propósito:

!>
!> ZTREXC reordena la factorización de Schur de una matriz compleja
!> A = Q*T*Q**H, de modo que el elemento diagonal de T con índice de fila IFST
!> se mueva a la fila ILST.
!>
!> La forma de Schur T se reordena mediante una transformación unitaria de similitud
!> Z**H*T*Z, y opcionalmente la matriz Q de vectores de Schur se actualiza
!> postmultiplicándola con Z.
!>

Parámetros

COMPQ 
!>          COMPQ es CHARACTER*1
!>          = 'V':  actualiza la matriz Q de vectores de Schur;
!>          = 'N':  no actualiza Q.
!>

N

!>          N es INTEGER
!>          El orden de la matriz T. N >= 0.
!>          Si N == 0, los argumentos ILST e IFST pueden tener cualquier valor.
!>

T

!>          T es un array COMPLEX*16, dimensión (LDT,N)
!>          En la entrada, la matriz triangular superior T.
!>          En la salida, la matriz triangular superior reordenada.
!>

LDT

!>          LDT es INTEGER
!>          La dimensión principal del array T. LDT >= max(1,N).
!>

Q

!>          Q es un array COMPLEX*16, dimensión (LDQ,N)
!>          En la entrada, si COMPQ = 'V', la matriz Q de vectores de Schur.
!>          En la salida, si COMPQ = 'V', Q ha sido postmultiplicada por la
!>          matriz de transformación unitaria Z que reordena T.
!>          Si COMPQ = 'N', Q no se referencia.
!>

LDQ

!>          LDQ es INTEGER
!>          La dimensión principal del array Q. LDQ >= 1, y si
!>          COMPQ = 'V', LDQ >= max(1,N).
!>

IFST

!>          IFST es INTEGER
!>

ILST

!>          ILST es INTEGER
!>
!>          Especifica la reordenación de los elementos diagonales de T:
!>          El elemento con índice de fila IFST se mueve a la fila ILST mediante una
!>          secuencia de transposiciones entre elementos adyacentes.
!>          1 <= IFST <= N; 1 <= ILST <= N.
!>

INFO

!>          INFO es INTEGER
!>          = 0:  salida exitosa
!>          < 0:  si INFO = -i, el argumento i-ésimo tenía un valor ilegal
!>
