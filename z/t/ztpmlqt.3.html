ZTPMLQT

Documentación de la función/subrutina

subrutina ztpmlqt (character side, character trans, integer m, integer n, integer k, integer l, integer mb, complex*16, dimension( ldv, * ) v, integer ldv, complex*16, dimension( ldt, * ) t, integer ldt, complex*16, dimension( lda, * ) a, integer lda, complex*16, dimension( ldb, * ) b, integer ldb, complex*16, dimension( * ) work, integer info)

ZTPMLQT

Propósito:

!>
!> ZTPMLQT aplica una matriz unitaria compleja Q obtenida de un
!>  reflector de bloque complejo H a una matriz general
!> compleja C, que consta de dos bloques A y B.
!>

Parámetros

SIDE 
!>          SIDE es CHARACTER*1
!>          = 'L': aplicar Q o Q**H desde la Izquierda;
!>          = 'R': aplicar Q o Q**H desde la Derecha.
!>

TRANS

!>          TRANS es CHARACTER*1
!>          = 'N':  Sin transposición, aplicar Q;
!>          = 'C':  Transposición conjugada, aplicar Q**H.
!>

M

!>          M es INTEGER
!>          El número de filas de la matriz B. M >= 0.
!>

N

!>          N es INTEGER
!>          El número de columnas de la matriz B. N >= 0.
!>

K

!>          K es INTEGER
!>          El número de reflectores elementales cuyo producto define
!>          la matriz Q.
!>

L

!>          L es INTEGER
!>          El orden de la parte trapezoidal de V.
!>          K >= L >= 0.  Ver Detalles Adicionales.
!>

MB

!>          MB es INTEGER
!>          El tamaño del bloque utilizado para el almacenamiento de T.  K >= MB >= 1.
!>          Debe ser el mismo valor de MB utilizado para generar T
!>          en ZTPLQT.
!>

V

!>          V es un array COMPLEX*16, dimensión (LDV,K)
!>          La i-ésima fila debe contener el vector que define el
!>          reflector elemental H(i), para i = 1,2,...,k, tal como fue devuelto por
!>          ZTPLQT en B.  Ver Detalles Adicionales.
!>

LDV

!>          LDV es INTEGER
!>          La dimensión principal del array V. LDV >= K.
!>

T

!>          T es un array COMPLEX*16, dimensión (LDT,K)
!>          Los factores triangulares superiores de los reflectores de bloque
!>          tal como fueron devueltos por ZTPLQT, almacenados como una matriz MB-por-K.
!>

LDT

!>          LDT es INTEGER
!>          La dimensión principal del array T.  LDT >= MB.
!>

A

!>          A es un array COMPLEX*16, dimensión
!>          (LDA,N) si SIDE = 'L' o
!>          (LDA,K) si SIDE = 'R'
!>          En la entrada, la matriz A de K-por-N o M-por-K.
!>          En la salida, A es sobrescrita por el bloque correspondiente de
!>          Q*C o Q**H*C o C*Q o C*Q**H.  Ver Detalles Adicionales.
!>

LDA

!>          LDA es INTEGER
!>          La dimensión principal del array A.
!>          Si SIDE = 'L', LDA >= max(1,K);
!>          Si SIDE = 'R', LDA >= max(1,M).
!>

B

!>          B es un array COMPLEX*16, dimensión (LDB,N)
!>          En la entrada, la matriz B de M-por-N.
!>          En la salida, B es sobrescrita por el bloque correspondiente de
!>          Q*C o Q**H*C o C*Q o C*Q**H.  Ver Detalles Adicionales.
!>

LDB

!>          LDB es INTEGER
!>          La dimensión principal del array B.
!>          LDB >= max(1,M).
!>

WORK

!>          WORK es un array COMPLEX*16. La dimensión de WORK es
!>           N*MB si SIDE = 'L', o  M*MB si SIDE = 'R'.
!>

INFO

!>          INFO es INTEGER
!>          = 0:  salida exitosa
!>          < 0:  si INFO = -i, el i-ésimo argumento tenía un valor ilegal
!>

Detalles Adicionales:

!>
!>  Las columnas de la matriz pentagonal V contienen los reflectores elementales
!>  H(1), H(2), ..., H(K); V está compuesto por un bloque rectangular V1 y un
!>  bloque trapezoidal V2:
!>
!>        V = [V1] [V2].
!>
!>
!>  El tamaño del bloque trapezoidal V2 está determinado por el parámetro L,
!>  donde 0 <= L <= K; V2 es trapezoidal inferior, que consta de las primeras L
!>  filas de una matriz triangular superior K-por-K.  Si L=K, V2 es triangular inferior;
!>  si L=0, no hay bloque trapezoidal, por lo tanto V = V1 es rectangular.
!>
!>  Si SIDE = 'L':  C = [A]  donde A es K-por-N,  B es M-por-N y V es K-por-M.
!>                      [B]
!>
!>  Si SIDE = 'R':  C = [A B]  donde A es M-por-K, B es M-por-N y V es K-por-N.
!>
!>  La matriz unitaria compleja Q se forma a partir de V y T.
!>
!>  Si TRANS='N' y SIDE='L', C se reemplaza en la salida con Q * C.
!>
!>  Si TRANS='C' y SIDE='L', C se reemplaza en la salida con Q**H * C.
!>
!>  Si TRANS='N' y SIDE='R', C se reemplaza en la salida con C * Q.
!>
!>  Si TRANS='C' y SIDE='R', C se reemplaza en la salida con C * Q**H.
!>
