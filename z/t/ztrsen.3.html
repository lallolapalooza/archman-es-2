Documentación de la función/subrutina

subrutina ztrsen (carácter job, carácter compq, lógico, dimensión( * ) select, entero n, complejo*16, dimensión( ldt, * ) t, entero ldt, complejo*16, dimensión( ldq, * ) q, entero ldq, complejo*16, dimensión( * ) w, entero m, doble precisión s, doble precisión sep, complejo*16, dimensión( * ) work, entero lwork, entero info)

ZTRSEN

Propósito:

!>
!> ZTRSEN reordena la factorización de Schur de una matriz compleja
!> A = Q*T*Q**H, de modo que un clúster seleccionado de valores propios aparezca en
!> las posiciones principales de la diagonal de la matriz triangular superior
!> T, y las columnas principales de Q formen una base ortonormal del
!> subespacio invariante derecho correspondiente.
!>
!> Opcionalmente, la rutina calcula los números de condición recíprocos del
!> clúster de valores propios (S) y/o del subespacio invariante.
!>

Parámetros

JOB 
!>          JOB es CHARACTER*1
!>          Especifica si se requieren números de condición para el
!>          clúster de valores propios (S) o el subespacio invariante (SEP):
!>          = 'N': ninguno;
!>          = 'E': solo para valores propios (S);
!>          = 'V': solo para subespacio invariante (SEP);
!>          = 'B': para valores propios y subespacio invariante (S y
!>                 SEP).
!>

COMPQ

!>          COMPQ es CHARACTER*1
!>          = 'V': actualiza la matriz Q de vectores de Schur;
!>          = 'N': no actualiza Q.
!>

SELECT

!>          SELECT es un array LOGICAL, dimensión (N)
!>          SELECT especifica los valores propios en el clúster seleccionado. Para
!>          seleccionar el j-ésimo valor propio, SELECT(j) debe establecerse en .TRUE..
!>

N

!>          N es INTEGER
!>          El orden de la matriz T. N >= 0.
!>

T

!>          T es un array COMPLEX*16, dimensión (LDT,N)
!>          En la entrada, la matriz triangular superior T.
!>          En la salida, T se sobrescribe con la matriz T reordenada, con los
!>          valores propios seleccionados como los elementos diagonales principales.
!>

LDT

!>          LDT es INTEGER
!>          La dimensión principal del array T. LDT >= max(1,N).
!>

Q

!>          Q es un array COMPLEX*16, dimensión (LDQ,N)
!>          En la entrada, si COMPQ = 'V', la matriz Q de vectores de Schur.
!>          En la salida, si COMPQ = 'V', Q ha sido postmultiplicada por la
!>          matriz de transformación unitaria que reordena T; las M columnas
!>          principales de Q forman una base ortonormal para el subespacio
!>          invariante especificado.
!>          Si COMPQ = 'N', Q no se referencia.
!>

LDQ

!>          LDQ es INTEGER
!>          La dimensión principal del array Q.
!>          LDQ >= 1; y si COMPQ = 'V', LDQ >= N.
!>

W

!>          W es un array COMPLEX*16, dimensión (N)
!>          Los valores propios reordenados de T, en el mismo orden en que
!>          aparecen en la diagonal de T.
!>

M

!>          M es INTEGER
!>          La dimensión del subespacio invariante especificado.
!>          0 <= M <= N.
!>

S

!>          S es DOUBLE PRECISION
!>          Si JOB = 'E' o 'B', S es un límite inferior del número de
!>          condición recíproco para el clúster seleccionado de valores
!>          propios.
!>          S no puede subestimar el número de condición recíproco real
!>          en más de un factor de sqrt(N). Si M = 0 o N, S = 1.
!>          Si JOB = 'N' o 'V', S no se referencia.
!>

SEP

!>          SEP es DOUBLE PRECISION
!>          Si JOB = 'V' o 'B', SEP es el número de condición recíproco estimado
!>          del subespacio invariante especificado. Si
!>          M = 0 o N, SEP = norm(T).
!>          Si JOB = 'N' o 'E', SEP no se referencia.
!>

WORK

!>          WORK es un array COMPLEX*16, dimensión (MAX(1,LWORK))
!>          En la salida, si INFO = 0, WORK(1) devuelve el LWORK óptimo.
!>

LWORK

!>          LWORK es INTEGER
!>          La dimensión del array WORK.
!>          Si JOB = 'N', LWORK >= 1;
!>          si JOB = 'E', LWORK = max(1,M*(N-M));
!>          si JOB = 'V' o 'B', LWORK >= max(1,2*M*(N-M)).
!>
!>          Si LWORK = -1, entonces se asume una consulta de espacio de trabajo; la rutina
!>          solo calcula el tamaño óptimo del array WORK, devuelve
!>          este valor como la primera entrada del array WORK, y XERBLA no emite ningún
!>          mensaje de error relacionado con LWORK.
!>

INFO

!>          INFO es INTEGER
!>          = 0:  salida exitosa
!>          < 0:  si INFO = -i, el i-ésimo argumento tenía un valor ilegal
!>

Detalles adicionales:

!>
!>  ZTRSEN primero recopila los valores propios seleccionados calculando una transformación unitaria Z para moverlos a la esquina superior izquierda de T. En otras palabras, los valores propios seleccionados son los valores propios de T11 en:
!>
!>          Z**H * T * Z = ( T11 T12 ) n1
!>                         (  0  T22 ) n2
!>                            n1  n2
!>
!>  donde N = n1+n2. Las primeras n1 columnas de Z abarcan el subespacio invariante especificado de T.
!>
!>  Si T se obtuvo de la factorización de Schur de una matriz
!>  A = Q*T*Q**H, entonces la factorización de Schur reordenada de A se da por
!>  A = (Q*Z)*(Z**H*T*Z)*(Q*Z)**H, y las primeras n1 columnas de Q*Z abarcan el
!>  subespacio invariante correspondiente de A.
!>
!>  El número de condición recíproco del promedio de los valores propios de
!>  T11 puede devolverse en S. S se encuentra entre 0 (muy mal condicionado)
!>  y 1 (muy bien condicionado). Se calcula de la siguiente manera. Primero calculamos R tal que
!>
!>                         P = ( I  R ) n1
!>                             ( 0  0 ) n2
!>                               n1 n2
!>
!>  es el proyector sobre el subespacio invariante asociado a T11.
!>  R es la solución de la ecuación de Sylvester:
!>
!>                        T11*R - R*T22 = T12.
!>
!>  Que F-norm(M) denote la norma de Frobenius de M y 2-norm(M) denote
!>  la norma 2 de M. Entonces S se calcula como el límite inferior
!>
!>                      (1 + F-norm(R)**2)**(-1/2)
!>
!>  de la recíproca de 2-norm(P), el número de condición recíproco real.
!>  S no puede subestimar 1 / 2-norm(P) en más de un factor de
!>  sqrt(N).
!>
!>  Un límite de error aproximado para el promedio calculado de los
!>  valores propios de T11 es
!>
!>                         EPS * norm(T) / S
!>
!>  donde EPS es la precisión de la máquina.
!>
!>  El número de condición recíproco del subespacio invariante derecho
!>  abarca por las primeras n1 columnas de Z (o de Q*Z) se devuelve en SEP.
!>  SEP se define como la separación de T11 y T22:
!>
!>                     sep( T11, T22 ) = sigma-min( C )
!>
!>  donde sigma-min(C) es el valor singular más pequeño de la
!>  matriz n1*n2 por n1*n2
!>
!>     C  = kprod( I(n2), T11 ) - kprod( transpose(T22), I(n1) )
!>
!>  I(m) es una matriz identidad m por m, y kprod denota el producto de Kronecker. Estimamos sigma-min(C) por la recíproca de una estimación
!>  de la norma 1 de inverse(C). La norma 1 recíproca real de inverse(C)
!>  no puede diferir de sigma-min(C) en más de un factor de sqrt(n1*n2).
!>
!>  Cuando SEP es pequeño, pequeños cambios en T pueden causar grandes cambios en
!>  el subespacio invariante. Un límite aproximado en el error angular máximo en
el subespacio invariante derecho calculado es !> !> EPS * norm(T) / SEP !>
