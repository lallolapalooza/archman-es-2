Documentación de la función/subrutina

subroutine ztrt05 (character uplo, character trans, character diag, integer n, integer nrhs, complex*16, dimension( lda, * ) a, integer lda, complex*16, dimension( ldb, * ) b, integer ldb, complex*16, dimension( ldx, * ) x, integer ldx, complex*16, dimension( ldxact, * ) xact, integer ldxact, double precision, dimension( * ) ferr, double precision, dimension( * ) berr, double precision, dimension( * ) reslts)

ZTRT05

Propósito:

!>
!> ZTRT05 prueba los límites de error del refinamiento iterativo para la
!> solución calculada de un sistema de ecuaciones A*X = B, donde A es una
!> matriz triangular n por n.
!>
!> RESLTS(1) = prueba del límite de error
!>           = norm(X - XACT) / ( norm(X) * FERR )
!>
!> Se devuelve un valor grande si esta relación no es menor que uno.
!>
!> RESLTS(2) = residuo de la rutina de refinamiento iterativo
!>           = el máximo de BERR / ( (n+1)*EPS + (*) ), donde
!>             (*) = (n+1)*UNFL / (min_i (abs(A)*abs(X) +abs(b))_i )
!>

Parámetros

UPLO 
!>          UPLO es CHARACTER*1
!>          Especifica si la matriz A es triangular superior o inferior.
!>          = 'U':  Triangular superior
!>          = 'L':  Triangular inferior
!>

TRANS

!>          TRANS es CHARACTER*1
!>          Especifica la forma del sistema de ecuaciones.
!>          = 'N':  A * X = B  (Sin transpuesta)
!>          = 'T':  A'* X = B  (Transpuesta)
!>          = 'C':  A'* X = B  (Transpuesta conjugada = Transpuesta)
!>

DIAG

!>          DIAG es CHARACTER*1
!>          Especifica si la matriz A es triangular unitaria o no.
!>          = 'N':  Triangular no unitaria
!>          = 'U':  Triangular unitaria
!>

N

!>          N es INTEGER
!>          El número de filas de las matrices X, B y XACT, y el
!>          orden de la matriz A.  N >= 0.
!>

NRHS

!>          NRHS es INTEGER
!>          El número de columnas de las matrices X, B y XACT.
!>          NRHS >= 0.
!>

A

!>          A es una matriz COMPLEX*16, dimensión (LDA,N)
!>          La matriz triangular A.  Si UPLO = 'U', la parte superior
!>          triangular principal de n por n de la matriz A contiene la
!>          matriz triangular superior, y la parte triangular estrictamente
!>          inferior de A no se referencia.  Si UPLO = 'L', la parte inferior
!>          triangular principal de n por n de la matriz A contiene la
!>          matriz triangular inferior, y la parte triangular estrictamente
!>          superior de A no se referencia.  Si DIAG = 'U', los elementos
!>          diagonales de A tampoco se referencian y se asumen como 1.
!>

LDA

!>          LDA es INTEGER
!>          La dimensión principal de la matriz A.  LDA >= max(1,N).
!>

B

!>          B es una matriz COMPLEX*16, dimensión (LDB,NRHS)
!>          Los vectores del lado derecho para el sistema de ecuaciones
!>          lineales.
!>

LDB

!>          LDB es INTEGER
!>          La dimensión principal de la matriz B.  LDB >= max(1,N).
!>

X

!>          X es una matriz COMPLEX*16, dimensión (LDX,NRHS)
!>          Los vectores de solución calculados.  Cada vector se almacena
!>          como una columna de la matriz X.
!>

LDX

!>          LDX es INTEGER
!>          La dimensión principal de la matriz X.  LDX >= max(1,N).
!>

XACT

!>          XACT es una matriz COMPLEX*16, dimensión (LDXACT,NRHS)
!>          Los vectores de solución exactos.  Cada vector se almacena
!>          como una columna de la matriz XACT.
!>

LDXACT

!>          LDXACT es INTEGER
!>          La dimensión principal de la matriz XACT.  LDXACT >= max(1,N).
!>

FERR

!>          FERR es una matriz DOUBLE PRECISION, dimensión (NRHS)
!>          Los límites de error hacia adelante estimados para cada vector
!>          de solución X.  Si XTRUE es la solución verdadera, FERR acota
!>          la magnitud de la entrada más grande en (X - XTRUE) dividida
!>          por la magnitud de la entrada más grande en X.
!>

BERR

!>          BERR es una matriz DOUBLE PRECISION, dimensión (NRHS)
!>          El error residual relativo componente a componente de cada vector
!>          de solución (es decir, el cambio relativo más pequeño en cualquier
!>          entrada de A o B que hace que X sea una solución exacta).
!>

RESLTS

!>          RESLTS es una matriz DOUBLE PRECISION, dimensión (2)
!>          El máximo sobre los vectores de solución NRHS de las relaciones:
!>          RESLTS(1) = norm(X - XACT) / ( norm(X) * FERR )
!>          RESLTS(2) = BERR / ( (n+1)*EPS + (*) )
!>
