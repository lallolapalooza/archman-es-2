Documentación de Función/Subrutina

subrutina ztzrqf (integer m, integer n, complex*16, dimension( lda, * ) a, integer lda, complex*16, dimension( * ) tau, integer info)

ZTZRQF

Propósito:

!>
!> Esta rutina está obsoleta y ha sido reemplazada por la rutina ZTZRZF.
!>
!> ZTZRQF reduce la matriz A superior trapezoidal M por N ( M<=N ) compleja
!> a forma triangular superior mediante transformaciones unitarias.
!>
!> La matriz superior trapezoidal A se factoriza como
!>
!>    A = ( R  0 ) * Z,
!>
!> donde Z es una matriz unitaria N por N y R es una matriz triangular
!> superior M por M.
!>

Parámetros

M 
!>          M es INTEGER
!>          El número de filas de la matriz A.  M >= 0.
!>

N

!>          N es INTEGER
!>          El número de columnas de la matriz A.  N >= M.
!>

A

!>          A es un array COMPLEX*16, dimensión (LDA,N)
!>          En la entrada, la parte superior trapezoidal M por N líder
!>          de la matriz A debe contener la matriz a factorizar.
!>          En la salida, la parte triangular superior M por M líder
!>          de A contiene la matriz triangular superior R, y los
!>          elementos M+1 a N de las primeras M filas de A, con la
!>          matriz TAU, representan la matriz unitaria Z como un
!>          producto de M reflectores elementales.
!>

LDA

!>          LDA es INTEGER
!>          La dimensión líder del array A.  LDA >= max(1,M).
!>

TAU

!>          TAU es un array COMPLEX*16, dimensión (M)
!>          Los factores escalares de los reflectores elementales.
!>

INFO

!>          INFO es INTEGER
!>          = 0: salida exitosa
!>          < 0: si INFO = -i, el i-ésimo argumento tenía un valor ilegal
!>

Detalles adicionales:

!>
!>  La factorización se obtiene por el método de Householder. La k-ésima
!>  matriz de transformación, Z( k ), cuya transpuesta conjugada se utiliza
!>  para introducir ceros en la (m - k + 1)-ésima fila de A, se da en la forma
!>
!>     Z( k ) = ( I     0   ),
!>              ( 0  T( k ) )
!>
!>  donde
!>
!>     T( k ) = I - tau*u( k )*u( k )**H,   u( k ) = (   1    ),
!>                                                   (   0    )
!>                                                   ( z( k ) )
!>
!>  tau y z( k ) se eligen para aniquilar los elementos de la k-ésima fila
!>  de X.
!>
!>  El escalar tau se devuelve en el k-ésimo elemento de TAU y el vector
!>  u( k ) en la k-ésima fila de A, de modo que los elementos de z( k )
!>  están en a( k, m + 1 ), ..., a( k, n ). Los elementos de R se devuelven
!>  en la parte triangular superior de A.
!>
!>  Z se da por
!>
!>     Z =  Z( 1 ) * Z( 2 ) * ... * Z( m ).
!>
