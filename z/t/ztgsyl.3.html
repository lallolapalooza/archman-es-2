Documentación de Función/Subrutina

subrutina ztgsyl (character trans, integer ijob, integer m, integer n, complex*16, dimension( lda, * ) a, integer lda, complex*16, dimension( ldb, * ) b, integer ldb, complex*16, dimension( ldc, * ) c, integer ldc, complex*16, dimension( ldd, * ) d, integer ldd, complex*16, dimension( lde, * ) e, integer lde, complex*16, dimension( ldf, * ) f, integer ldf, double precision scale, double precision dif, complex*16, dimension( * ) work, integer lwork, integer, dimension( * ) iwork, integer info)

ZTGSYL

Propósito:

!>
!> ZTGSYL resuelve la ecuación de Sylvester generalizada:
!>
!>             A * R - L * B = escala * C            (1)
!>             D * R - L * E = escala * F
!>
!> donde R y L son matrices desconocidas de m por n, (A, D), (B, E) y
!> (C, F) son pares de matrices dadas de tamaño m por m, n por n y m por n,
!> respectivamente, con entradas complejas. A, B, D y E son
!> triangulares superiores (es decir, (A,D) y (B,E) en forma de Schur
!> generalizada).
!>
!> La solución (R, L) sobrescribe (C, F). 0 <= ESCALA <= 1
!> es un factor de escala de salida elegido para evitar el desbordamiento.
!>
!> En notación matricial (1) es equivalente a resolver Zx = escala*b, donde Z
!> se define como
!>
!>        Z = [ kron(In, A)  -kron(B**H, Im) ]        (2)
!>            [ kron(In, D)  -kron(E**H, Im) ],
!>
!> Aquí Ix es la matriz identidad de tamaño x y X**H es la transpuesta
!> conjugada de X. Kron(X, Y) es el producto de Kronecker entre las
!> matrices X y Y.
!>
!> Si TRANS = 'C', se resuelve y en el sistema conjugado transpuesto Z**H *y = escala*b
!> lo que es equivalente a resolver para R y L en
!>
!>             A**H * R + D**H * L = escala * C           (3)
!>             R * B**H + L * E**H = escala * -F
!>
!> Este caso (TRANS = 'C') se usa para calcular una estimación basada en
!> norma uno de Dif[(A,D), (B,E)], la separación entre los pares de matrices (A,D)
!> y (B,E), usando ZLACON.
!>
!> Si IJOB >= 1, ZTGSYL calcula una estimación basada en norma de Frobenius de
!> Dif[(A,D),(B,E)]. Es decir, el recíproco de una cota inferior sobre el
!> recíproco del valor singular más pequeño de Z.
!>
!> Este es un algoritmo BLAS de nivel 3.
!>

Parámetros

TRANS 
!>          TRANS es CHARACTER*1
!>          = 'N': resolver la ecuación de Sylvester generalizada (1).
!>          = 'C': resolver el sistema (3).
!>

IJOB

!>          IJOB es INTEGER
!>          Especifica qué tipo de funcionalidad se debe realizar.
!>          =0: resolver (1) solamente.
!>          =1: La funcionalidad de 0 y 3.
!>          =2: La funcionalidad de 0 y 4.
!>          =3: Solo se calcula una estimación de Dif[(A,D), (B,E)].
!>              (se usa la estrategia de mirar hacia adelante).
!>          =4: Solo se calcula una estimación de Dif[(A,D), (B,E)].
!>              (se usa ZGECON en subsistemas).
!>          No se referencia si TRANS = 'C'.
!>

M

!>          M es INTEGER
!>          El orden de las matrices A y D, y la dimensión de filas de
!>          las matrices C, F, R y L.
!>

N

!>          N es INTEGER
!>          El orden de las matrices B y E, y la dimensión de columnas
!>          de las matrices C, F, R y L.
!>

A

!>          A es un arreglo COMPLEX*16, dimensión (LDA, M)
!>          La matriz triangular superior A.
!>

LDA

!>          LDA es INTEGER
!>          La dimensión principal del arreglo A. LDA >= max(1, M).
!>

B

!>          B es un arreglo COMPLEX*16, dimensión (LDB, N)
!>          La matriz triangular superior B.
!>

LDB

!>          LDB es INTEGER
!>          La dimensión principal del arreglo B. LDB >= max(1, N).
!>

C

!>          C es un arreglo COMPLEX*16, dimensión (LDC, N)
!>          A la entrada, C contiene el lado derecho de la primera ecuación
!>          matricial en (1) o (3).
!>          A la salida, si IJOB = 0, 1 o 2, C ha sido sobrescrito por
!>          la solución R. Si IJOB = 3 o 4 y TRANS = 'N', C contiene R,
!>          la solución alcanzada durante el cálculo de la
!>          estimación de Dif.
!>

LDC

!>          LDC es INTEGER
!>          La dimensión principal del arreglo C. LDC >= max(1, M).
!>

D

!>          D es un arreglo COMPLEX*16, dimensión (LDD, M)
!>          La matriz triangular superior D.
!>

LDD

!>          LDD es INTEGER
!>          La dimensión principal del arreglo D. LDD >= max(1, M).
!>

E

!>          E es un arreglo COMPLEX*16, dimensión (LDE, N)
!>          La matriz triangular superior E.
!>

LDE

!>          LDE es INTEGER
!>          La dimensión principal del arreglo E. LDE >= max(1, N).
!>

F

!>          F es un arreglo COMPLEX*16, dimensión (LDF, N)
!>          A la entrada, F contiene el lado derecho de la segunda ecuación
!>          matricial en (1) o (3).
!>          A la salida, si IJOB = 0, 1 o 2, F ha sido sobrescrito por
!>          la solución L. Si IJOB = 3 o 4 y TRANS = 'N', F contiene L,
!>          la solución alcanzada durante el cálculo de la
!>          estimación de Dif.
!>

LDF

!>          LDF es INTEGER
!>          La dimensión principal del arreglo F. LDF >= max(1, M).
!>

DIF

!>          DIF es DOUBLE PRECISION
!>          A la salida DIF es el recíproco de una cota inferior del
!>          recíproco de la función Dif, es decir, DIF es una cota superior de
!>          Dif[(A,D), (B,E)] = sigma-min(Z), donde Z es como en (2).
!>          SI IJOB = 0 o TRANS = 'C', DIF no se referencia.
!>

SCALE

!>          SCALE es DOUBLE PRECISION
!>          A la salida SCALE es el factor de escala en (1) o (3).
!>          Si 0 < SCALE < 1, C y F contienen las soluciones R y L, respectivamente,
!>          a un sistema ligeramente perturbado pero las matrices de entrada A, B,
!>          D y E no han sido cambiadas. Si SCALE = 0, R y L contendrán
!>          las soluciones al sistema homogéneo con C = F = 0.
!>

WORK

!>          WORK es un arreglo COMPLEX*16, dimensión (MAX(1,LWORK))
!>          A la salida, si INFO = 0, WORK(1) devuelve el LWORK óptimo.
!>

LWORK

!>          LWORK es INTEGER
!>          La dimensión del arreglo WORK. LWORK >= 1.
!>          Si IJOB = 1 o 2 y TRANS = 'N', LWORK >= max(1,2*M*N).
!>
!>          Si LWORK = -1, se asume una consulta de espacio de trabajo; la rutina
!>          solo calcula el tamaño óptimo del arreglo WORK, devuelve
!>          este valor como la primera entrada del arreglo WORK, y no se emite
!>          ningún mensaje de error relacionado con LWORK por parte de XERBLA.
!>

IWORK

!>          IWORK es un arreglo INTEGER, dimensión (M+N+2)
!>

INFO

!>          INFO es INTEGER
!>            =0: salida exitosa
!>            <0: Si INFO = -i, el i-ésimo argumento tenía un valor ilegal.
!>            >0: (A, D) y (B, E) tienen eigenvalores comunes o muy cercanos.
!>

NAME

ztgsyl - Resuelve una ecuación de Sylvester generalizada de la forma

A*R - L*B = C

o

A*R - R*B = C

y estima la separación entre los pares de matrices regulares (A, D) y (B, E).

SYNOPSIS

    SUBROUTINE ZTGSYL( TRANS, TRGHRD, TRANSB, DIAG,
 &                   AFAC, BFAC, C )

Parameters:

  • TRANS character*1.

    Indica si se debe resolver la ecuación de Sylvester generalizada.

    • 'N': Resuelve A*R - L*B = C.
    • 'T': Resuelve A**T*R - L*B**T = C.
    • 'C': Resuelve A**H*R - L*B**H = C.
  • TRGHRD character*1.

    Indica si se debe triangularizar la matriz B o E en A*R - L*B = C.

    • 'N': No se realiza ninguna triangularización.
    • 'V': Se triangulariza B (o E) y se calcula una matriz V tal que B*V = V*S (o E*V = V*S).
  • TRANSB character*1.

    Indica si se debe triangularizar la matriz B o E en A*R - L*B = C.

    • 'N': No se realiza ninguna triangularización.
    • 'V': Se triangulariza B (o E) y se calcula una matriz V tal que B*V = V*S (o E*V = V*S).
  • DIAG character*1.

    Indica si las matrices L e R deben ser de Hessenberg o triangulares inferiores.

    • 'N': L e R son de Hessenberg.
    • 'L': L e R son triangulares inferiores.
  • AFAC complex*16 array, dimension (LDAR, M, N).

    Los factores triangulares de la matriz A o A*Q.

  • BFAC complex*16 array, dimension (LDBR, M, N).

    Los factores triangulares de la matriz B o B*Q.

  • C complex*16 array, dimension (LDC, M, N).

    En la entrada, contiene la matriz C. En la salida, contiene la matriz R o L.

Function/Subroutine Documentation

La rutina ZTGSYL resuelve una ecuación de Sylvester generalizada de la forma

op(A)*R - L*op(B) = C

o

op(A)*R - R*op(B) = C,

donde op(X) es X, X**T o X**H. Aquí, A y B son matrices generales de Hessenberg.

Se utilizan los siguientes argumentos:

TRANS
Especifica la transposición a aplicar a A y B.
TRGHRD
Especifica si se debe triangularizar B. Si es así, se calcula una matriz V tal que B*V = V*S.
TRANSB
Especifica si se debe triangularizar B. Si es así, se calcula una matriz V tal que B*V = V*S.
DIAG
Especifica si las matrices L e R deben ser de Hessenberg o triangulares inferiores.
AFAC
Contiene los factores triangulares de A.
BFAC
Contiene los factores triangulares de B.
C
En la entrada, contiene la matriz C. En la salida, contiene la matriz solución R o L.

La subrutina también puede estimar la separación entre los pares de matrices regulares (A, D) y (B, E) si se le proporcionan las matrices apropiadas en lugar de C.
