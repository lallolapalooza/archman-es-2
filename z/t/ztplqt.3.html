Documentación de la función/subrutina

subroutine ztplqt (integer m, integer n, integer l, integer mb, complex*16, dimension( lda, * ) a, integer lda, complex*16, dimension( ldb, * ) b, integer ldb, complex*16, dimension( ldt, * ) t, integer ldt, complex*16, dimension( * ) work, integer info)

ZTPLQT

Propósito:

!>
!> ZTPLQT calcula una factorización LQ bloqueada de una matriz compleja
!> C, que se compone de una matriz triangular A y una matriz pentagonal B,
!> utilizando la representación compacta WY para Q.
!>

Parámetros

M 
!>          M es INTEGER
!>          El número de filas de la matriz B, y el orden de la
!>          matriz triangular A.
!>          M >= 0.
!>

N

!>          N es INTEGER
!>          El número de columnas de la matriz B.
!>          N >= 0.
!>

L

!>          L es INTEGER
!>          El número de filas de la parte trapezoidal inferior de B.
!>          MIN(M,N) >= L >= 0. Véase Detalles Adicionales.
!>

MB

!>          MB es INTEGER
!>          El tamaño del bloque a utilizar en la QR bloqueada. M >= MB >= 1.
!>

A

!>          A es un array COMPLEX*16, dimensión (LDA,M)
!>          En la entrada, la matriz triangular inferior M por M A.
!>          En la salida, los elementos en y debajo de la diagonal del array
!>          contienen la matriz triangular inferior L.
!>

LDA

!>          LDA es INTEGER
!>          La dimensión principal del array A. LDA >= max(1,M).
!>

B

!>          B es un array COMPLEX*16, dimensión (LDB,N)
!>          En la entrada, la matriz pentagonal M por N B. Las primeras N-L columnas
!>          son rectangulares, y las últimas L columnas son trapezoidales inferiores.
!>          En la salida, B contiene la matriz pentagonal V. Véase Detalles Adicionales.
!>

LDB

!>          LDB es INTEGER
!>          La dimensión principal del array B. LDB >= max(1,M).
!>

T

!>          T es un array COMPLEX*16, dimensión (LDT,N)
!>          Los reflectores de bloque triangulares inferiores almacenados en forma
!>          compacta como una secuencia de bloques triangulares superiores. Véase
!>          Detalles Adicionales.
!>

LDT

!>          LDT es INTEGER
!>          La dimensión principal del array T. LDT >= MB.
!>

WORK

!>          WORK es un array COMPLEX*16, dimensión (MB*M)
!>

INFO

!>          INFO es INTEGER
!>          = 0:  salida exitosa
!>          < 0:  si INFO = -i, el i-ésimo argumento tenía un valor ilegal
!>

Detalles Adicionales:

!>
!>  La matriz de entrada C es una matriz M por (M+N)
!>
!>               C = [ A ] [ B ]
!>
!>
!>  donde A es una matriz M por M triangular inferior, y B es una matriz
!>  pentagonal M por N que consiste en una matriz rectangular M por (N-L) B1
!>  a la izquierda de una matriz trapezoidal inferior L por M B2:
!>          [ B ] = [ B1 ] [ B2 ]
!>                   [ B1 ]  <- M por (N-L) rectangular
!>                   [ B2 ]  <-     M por L trapezoidal inferior.
!>
!>  La matriz trapezoidal inferior B2 consiste en las primeras L columnas de una
!>  matriz triangular inferior M por M, donde 0 <= L <= MIN(M,N). Si L=0,
!>  B es rectangular M por N; si M=L=N, B es triangular inferior.
!>
!>  La matriz W almacena los reflectores elementales H(i) en la fila i
!>  por encima de la diagonal (de A) en la matriz de entrada C M por (M+N)
!>            [ C ] = [ A ] [ B ]
!>                   [ A ]  <- triangular inferior M por M
!>                   [ B ]  <- M por N pentagonal
!>
!>  de modo que W pueda representarse como
!>            [ W ] = [ I ] [ V ]
!>                   [ I ]  <- identidad, M por M
!>                   [ V ]  <- M por N, misma forma que B.
!>
!>  Así, toda la información necesaria para W está contenida en la salida en B,
!>  que llamamos V anteriormente. Nótese que V tiene la misma forma que B; es decir,
!>            [ V ] = [ V1 ] [ V2 ]
!>                   [ V1 ] <- M por (N-L) rectangular
!>                   [ V2 ] <-     M por L trapezoidal inferior.
!>
!>  Las filas de V representan los vectores que definen los H(i).
!>
!>  El número de bloques es B = techo(M/MB), donde cada
!>  bloque es de orden MB excepto el último bloque, que es de orden
!>  IB = M - (M-1)*MB. Para cada uno de los B bloques, se calcula un factor
!>  reflector de bloque triangular superior: T1, T2, ..., TB. Los T de MB por MB
!>  (y IB por IB para el último bloque) se almacenan en la matriz T de MB por N como
!>
!>               T = [T1 T2 ... TB].
!>
