subrutina ztpqrt (m entero, n entero, l entero, nb entero, complejo*16, dimensión( lda, * ) a, lda entero, complejo*16, dimensión( ldb, * ) b, ldb entero, complejo*16, dimensión( ldt, * ) t, ldt entero, complejo*16, dimensión( * ) work, info entero)

ZTPQRT

Propósito:

!>
!> ZTPQRT calcula una factorización QR bloqueada de una matriz compleja
!>  C, que se compone de un bloque triangular A y un bloque pentagonal B,
!>  utilizando la representación WY compacta para Q.
!>

Parámetros

M 
!>          M es ENTERO
!>          El número de filas de la matriz B.
!>          M >= 0.
!>

N

!>          N es ENTERO
!>          El número de columnas de la matriz B y el orden de la
!>          matriz triangular A.
!>          N >= 0.
!>

L

!>          L es ENTERO
!>          El número de filas de la parte superior trapezoidal de B.
!>          MIN(M,N) >= L >= 0. Ver Detalles Adicionales.
!>

NB

!>          NB es ENTERO
!>          El tamaño del bloque a utilizar en la QR bloqueada.  N >= NB >= 1.
!>

A

!>          A es una matriz de COMPLEJO*16, dimensión (LDA,N)
!>          En la entrada, la matriz N-por-N triangular superior A.
!>          En la salida, los elementos en y por encima de la diagonal de la
!>          matriz contienen la matriz triangular superior R.
!>

LDA

!>          LDA es ENTERO
!>          La dimensión principal de la matriz A.  LDA >= max(1,N).
!>

B

!>          B es una matriz de COMPLEJO*16, dimensión (LDB,N)
!>          En la entrada, la matriz pentagonal M-por-N B. Las primeras M-L filas
!>          son rectangulares, y las últimas L filas son superiores trapezoidales.
!>          En la salida, B contiene la matriz pentagonal V. Ver Detalles Adicionales.
!>

LDB

!>          LDB es ENTERO
!>          La dimensión principal de la matriz B.  LDB >= max(1,M).
!>

T

!>          T es una matriz de COMPLEJO*16, dimensión (LDT,N)
!>          Los reflectores de bloque triangulares superiores se almacenan en
!>          forma compacta como una secuencia de bloques triangulares superiores.
!>          Ver Detalles Adicionales.
!>

LDT

!>          LDT es ENTERO
!>          La dimensión principal de la matriz T.  LDT >= NB.
!>

WORK

!>          WORK es una matriz de COMPLEJO*16, dimensión (NB*N)
!>

INFO

!>          INFO es ENTERO
!>          = 0:  salida exitosa
!>          < 0:  si INFO = -i, el i-ésimo argumento tuvo un valor ilegal
!>

Detalles Adicionales:

!>
!>  La matriz de entrada C es una matriz (N+M)-por-N
!>
!>               C = [ A ]
!>                   [ B ]
!>
!>  donde A es una matriz N-por-N triangular superior, y B es una matriz
!>  pentagonal M-por-N que consiste en una matriz rectangular (M-L)-por-N B1
!>  encima de una matriz trapezoidal superior L-por-N B2:
!>
!>               B = [ B1 ]  <- rectangular (M-L)-por-N
!>                   [ B2 ]  <-     trapezoidal superior L-por-N.
!>
!>  La matriz trapezoidal superior B2 consiste en las primeras L filas de una
!>  matriz triangular superior N-por-N, donde 0 <= L <= MIN(M,N). Si L=0,
!>  B es rectangular M-por-N; si M=L=N, B es triangular superior.
!>
!>  La matriz W almacena los reflectores elementales H(i) en la i-ésima columna
!>  debajo de la diagonal (de A) en la matriz de entrada C (N+M)-por-N
!>
!>               C = [ A ]  <- triangular superior N-por-N
!>                   [ B ]  <- pentagonal M-por-N
!>
!>  de manera que W pueda representarse como
!>
!>               W = [ I ]  <- identidad, N-por-N
!>                   [ V ]  <- M-por-N, misma forma que B.
!>
!>  Por lo tanto, toda la información necesaria para W se contiene a la salida
!>  en B, a la que llamamos V arriba. Tenga en cuenta que V tiene la misma
!>  forma que B; es decir,
!>
!>               V = [ V1 ] <- rectangular (M-L)-por-N
!>                   [ V2 ] <-     trapezoidal superior L-por-N.
!>
!>  Las columnas de V representan los vectores que definen los H(i).
!>
!>  El número de bloques es B = techo(N/NB), donde cada
!>  bloque es de orden NB excepto el último bloque, que es de orden
!>  IB = N - (B-1)*NB. Para cada uno de los B bloques, se calcula un
!>  reflector de bloque triangular superior: T1, T2, ..., TB. Los T de
!>  NB-por-NB (y IB-por-IB para el último bloque) se almacenan en la matriz
!>  T de NB-por-N como
!>
!>               T = [T1 T2 ... TB].
!>
