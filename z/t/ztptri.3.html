subrutina ztpri (character uplo, character diag, integer n, complex*16, dimension( * ) ap, integer info)

ZTPTRI

Propósito:

!>
!> ZTPTRI calcula la inversa de una matriz triangular superior o inferior compleja
!> almacenada en formato empaquetado.
!>

Parámetros

UPLO 
!>          UPLO es CHARACTER*1
!>          = 'U':  A es triangular superior;
!>          = 'L':  A es triangular inferior.
!>

DIAG

!>          DIAG es CHARACTER*1
!>          = 'N':  A es triangular no unitaria;
!>          = 'U':  A es triangular unitaria.
!>

N

!>          N es INTEGER
!>          El orden de la matriz A.  N >= 0.
!>

AP

!>          AP es un array COMPLEX*16, de dimensión (N*(N+1)/2)
!>          En la entrada, la matriz triangular superior o inferior A, almacenada
!>          columna a columna en un array lineal. La j-ésima columna de A se almacena
!>          en el array AP de la siguiente manera:
!>          si UPLO = 'U', AP(i + (j-1)*j/2) = A(i,j) para 1<=i<=j;
!>          si UPLO = 'L', AP(i + (j-1)*((2*n-j)/2) = A(i,j) para j<=i<=n.
!>          Ver más abajo para más detalles.
!>          En la salida, la inversa (triangular) de la matriz original, en
!>          el mismo formato de almacenamiento empaquetado.
!>

INFO

!>          INFO es INTEGER
!>          = 0:  salida exitosa
!>          < 0:  si INFO = -i, el i-ésimo argumento tuvo un valor ilegal
!>          > 0:  si INFO = i, A(i,i) es exactamente cero. La matriz triangular
!>                es singular y su inversa no puede ser calculada.
!>

Más detalles:

!>
!>  Una matriz triangular A puede ser transferida a almacenamiento empaquetado usando uno
!>  de los siguientes segmentos de programa:
!>
!>  UPLO = 'U':                      UPLO = 'L':
!>
!>        JC = 1                           JC = 1
!>        DO 2 J = 1, N                    DO 2 J = 1, N
!>           DO 1 I = 1, J                    DO 1 I = J, N
!>              AP(JC+I-1) = A(I,J)              AP(JC+I-J) = A(I,J)
!>      1    CONTINUE                    1    CONTINUE
!>           JC = JC + J                      JC = JC + N - J + 1
!>      2 CONTINUE                       2 CONTINUE
!>
