ZTGSJA

Propósito:

!>
!> ZTGSJA calcula la descomposición de valores singulares generalizada (GSVD)
!> de dos matrices complejas triangulares superiores (o trapezoidales) A y B.
!>
!> A la entrada, se asume que las matrices A y B tienen las siguientes
!> formas, que pueden haberse obtenido de la subrutina de preprocesamiento ZGGSVP
!> a partir de una matriz general M por N, A, y una matriz P por N, B:
!>
!>              N-K-L  K    L
!>    A =    K ( 0    A12  A13 ) si M-K-L >= 0;
!>           L ( 0     0   A23 )
!>       M-K-L ( 0     0    0  )
!>
!>            N-K-L  K    L
!>    A =  K ( 0    A12  A13 ) si M-K-L < 0;
!>       M-K ( 0     0   A23 )
!>
!>            N-K-L  K    L
!>    B =  L ( 0     0   B13 )
!>       P-L ( 0     0    0  )
!>
!> donde la matriz K por K, A12, y la matriz L por L, B13, son no singulares
!> triangulares superiores; A23 es triangular superior L por L si M-K-L >= 0,
!> de lo contrario, A23 es trapezoidal superior (M-K) por L.
!>
!> A la salida,
!>
!>        U**H *A*Q = D1*( 0 R ),    V**H *B*Q = D2*( 0 R ),
!>
!> donde U, V y Q son matrices unitarias.
!> R es una matriz triangular superior no singular, y D1
!> y D2 son matrices "diagonales", que son de las siguientes
!> estructuras:
!>
!> Si M-K-L >= 0,
!>
!>                     K  L
!>        D1 =     K ( I  0 )
!>                 L ( 0  C )
!>             M-K-L ( 0  0 )
!>
!>                    K  L
!>        D2 = L   ( 0  S )
!>             P-L ( 0  0 )
!>
!>                N-K-L  K    L
!>   ( 0 R ) = K (  0   R11  R12 ) K
!>             L (  0    0   R22 ) L
!>
!> donde
!>
!>   C = diag(ALPHA(K+1), ... , ALPHA(K+L) ),
!>   S = diag(BETA(K+1),  ... , BETA(K+L) ),
!>   C**2 + S**2 = I.
!>
!>   R se almacena en A(1:K+L,N-K-L+1:N) a la salida.
!>
!> Si M-K-L < 0,
!>
!>                K M-K K+L-M
!>     D1 =   K ( I  0    0   )
!>          M-K ( 0  C    0   )
!>
!>                  K M-K K+L-M
!>     D2 =   M-K ( 0  S    0   )
!>          K+L-M ( 0  0    I   )
!>            P-L ( 0  0    0   )
!>
!>                N-K-L  K   M-K  K+L-M
!> ( 0 R ) =    K ( 0    R11  R12  R13  )
!>           M-K ( 0     0   R22  R23  )
!>         K+L-M ( 0     0    0   R33  )
!>
!> donde
!> C = diag(ALPHA(K+1), ... , ALPHA(M) ),
!> S = diag(BETA(K+1),  ... , BETA(M) ),
!> C**2 + S**2 = I.
!>
!> R = ( R11 R12 R13 ) se almacena en A(1:M, N-K-L+1:N) y R33 se almacena
!>     (  0  R22 R23 )
!> en B(M-K+1:L,N+M-K-L+1:N) a la salida.
!>
!> El cálculo de las matrices de transformación unitarias U, V o Q
!> es opcional. Estas matrices pueden formarse explícitamente, o pueden
!> ser postmultiplicadas en las matrices de entrada U1, V1 o Q1.
!>

Parámetros

JOBU 
!>          JOBU es CHARACTER*1
!>          = 'U': U debe contener una matriz unitaria U1 a la entrada, y
!>                 el producto U1*U se devuelve;
!>          = 'I': U se inicializa a la matriz identidad, y la
!>                 matriz unitaria U se devuelve;
!>          = 'N': U no se calcula.
!>

JOBV

!>          JOBV es CHARACTER*1
!>          = 'V': V debe contener una matriz unitaria V1 a la entrada, y
!>                 el producto V1*V se devuelve;
!>          = 'I': V se inicializa a la matriz identidad, y la
!>                 matriz unitaria V se devuelve;
!>          = 'N': V no se calcula.
!>

JOBQ

!>          JOBQ es CHARACTER*1
!>          = 'Q': Q debe contener una matriz unitaria Q1 a la entrada, y
!>                 el producto Q1*Q se devuelve;
!>          = 'I': Q se inicializa a la matriz identidad, y la
!>                 matriz unitaria Q se devuelve;
!>          = 'N': Q no se calcula.
!>

M

!>          M es INTEGER
!>          El número de filas de la matriz A. M >= 0.
!>

P

!>          P es INTEGER
!>          El número de filas de la matriz B. P >= 0.
!>

N

!>          N es INTEGER
!>          El número de columnas de las matrices A y B. N >= 0.
!>

K

!>          K es INTEGER
!>

L

!>          L es INTEGER
!>
!>          K y L especifican los subbloques en las matrices de entrada A y B:
!>          A23 = A(K+1:MIN(K+L,M),N-L+1:N) y B13 = B(1:L,,N-L+1:N)
!>          de A y B, cuya GSVD se va a calcular con ZTGSJA.
!>          Ver Más Detalles.
!>

A

!>          A es COMPLEX*16 array, dimensión (LDA,N)
!>          A la entrada, la matriz M por N, A.
!>          A la salida, A(N-K+1:N,1:MIN(K+L,M) ) contiene la matriz
!>          triangular R o parte de R. Ver Propósito para detalles.
!>

LDA

!>          LDA es INTEGER
!>          La dimensión principal del array A. LDA >= max(1,M).
!>

B

!>          B es COMPLEX*16 array, dimensión (LDB,N)
!>          A la entrada, la matriz P por N, B.
!>          A la salida, si es necesario, B(M-K+1:L,N+M-K-L+1:N) contiene
!>          una parte de R. Ver Propósito para detalles.
!>

LDB

!>          LDB es INTEGER
!>          La dimensión principal del array B. LDB >= max(1,P).
!>

TOLA

!>          TOLA es DOUBLE PRECISION
!>

TOLB

!>          TOLB es DOUBLE PRECISION
!>
!>          TOLA y TOLB son los criterios de convergencia para el procedimiento
!>          de iteración de Jacobi-Kogbetliantz. Generalmente, son los
!>          mismos que se usaron en el paso de preprocesamiento, por ejemplo
!>              TOLA = MAX(M,N)*norm(A)*MAZHEPS,
!>              TOLB = MAX(P,N)*norm(B)*MAZHEPS.
!>

ALPHA

!>          ALPHA es array de DOUBLE PRECISION, dimensión (N)
!>

BETA

!>          BETA es array de DOUBLE PRECISION, dimensión (N)
!>
!>          A la salida, ALPHA y BETA contienen los pares de valores singulares
!>          generalizados de A y B;
!>            ALPHA(1:K) = 1,
!>            BETA(1:K)  = 0,
!>          y si M-K-L >= 0,
!>            ALPHA(K+1:K+L) = diag(C),
!>            BETA(K+1:K+L)  = diag(S),
!>          o si M-K-L < 0,
!>            ALPHA(K+1:M)= C, ALPHA(M+1:K+L)= 0
!>            BETA(K+1:M) = S, BETA(M+1:K+L) = 1.
!>          Además, si K+L < N,
!>            ALPHA(K+L+1:N) = 0 y
!>            BETA(K+L+1:N)  = 0.
!>

U

!>          la matriz unitaria devuelta por ZGGSVP).

Detalles Adicionales:

!>
!>  ZTGSJA utiliza esencialmente una variante del algoritmo de Kogbetliantz para reducir
!>  la matriz triangular (o trapezoidal) A23 de min(L,M-K)-por-L y la matriz B13 de L-por-L
!>  a la forma:
!>
!>           U1**H *A13*Q1 = C1*R1; V1**H *B13*Q1 = S1*R1,
!>
!>  donde U1, V1 y Q1 son matrices unitarias.
!>  C1 y S1 son matrices diagonales que satisfacen
!>
!>                C1**2 + S1**2 = I,
!>
!>  y R1 es una matriz triangular superior no singular de L-por-L.
!>
