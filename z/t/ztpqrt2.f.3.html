subroutine ztpqrt2 (integer m, integer n, integer l, complex*16, dimension( lda, * ) a, integer lda, complex*16, dimension( ldb, * ) b, integer ldb, complex*16, dimension( ldt, * ) t, integer ldt, integer info)

ZTPQRT2 calcula una factorización QR de una matriz real o compleja "triangular-pentagonal", que está compuesta de un bloque triangular y un bloque pentagonal, utilizando la representación compacta WY para Q.

Propósito:

!>
!> ZTPQRT2 calcula una factorización QR de una matriz compleja 
!> C, que está compuesta de un bloque triangular A y un bloque pentagonal B,
!> utilizando la representación compacta WY para Q.
!>

Parámetros

M 
!>          M es INTEGER
!>          El número total de filas de la matriz B.
!>          M >= 0.
!>

N

!>          N es INTEGER
!>          El número de columnas de la matriz B, y el orden de
!>          la matriz triangular A.
!>          N >= 0.
!>

L

!>          L es INTEGER
!>          El número de filas de la parte superior trapezoidal de B.
!>          MIN(M,N) >= L >= 0. Ver Detalles Adicionales.
!>

A

!>          A es un array COMPLEX*16, de dimensión (LDA,N)
!>          En la entrada, la matriz N por N triangular superior A.
!>          En la salida, los elementos en y por encima de la diagonal de la matriz
!>          contienen la matriz triangular superior R.
!>

LDA

!>          LDA es INTEGER
!>          La dimensión principal de la matriz A.  LDA >= max(1,N).
!>

B

!>          B es un array COMPLEX*16, de dimensión (LDB,N)
!>          En la entrada, la matriz pentagonal M por N B. Las primeras M-L filas
!>          son rectangulares, y las últimas L filas son trapezoidales superiores.
!>          En la salida, B contiene la matriz pentagonal V. Ver Detalles Adicionales.
!>

LDB

!>          LDB es INTEGER
!>          La dimensión principal de la matriz B.  LDB >= max(1,M).
!>

T

!>          T es un array COMPLEX*16, de dimensión (LDT,N)
!>          El factor triangular superior N por N T del reflector de bloque.
!>          Ver Detalles Adicionales.
!>

LDT

!>          LDT es INTEGER
!>          La dimensión principal de la matriz T.  LDT >= max(1,N)
!>

INFO

!>          INFO es INTEGER
!>          = 0: ejecución exitosa
!>          < 0: si INFO = -i, el i-ésimo argumento tuvo un valor ilegal
!>

Detalles Adicionales:

!>
!>  La matriz de entrada C es una matriz (N+M)-por-N
!>
!>               C = [ A ]
!>                   [ B ]
!>
!>  donde A es una matriz N por N triangular superior, y B es una matriz
!>  pentagonal M por N que consiste en una matriz rectangular B1 de (M-L)-por-N
!>  encima de una matriz trapezoidal superior B2 de L por N:
!>
!>               B = [ B1 ]  <- (M-L)-por-N rectangular
!>                   [ B2 ]  <-     L-por-N trapezoidal superior.
!>
!>  La matriz trapezoidal superior B2 consiste en las primeras L filas de una
!>  matriz triangular superior N por N, donde 0 <= L <= MIN(M,N). Si L=0,
!>  B es rectangular M por N; si M=L=N, B es triangular superior.
!>
!>  La matriz W almacena los reflectores elementales H(i) en la i-ésima columna
!>  debajo de la diagonal (de A) en la matriz de entrada C de (N+M)-por-N
!>
!>               C = [ A ]  <- N por N triangular superior
!>                   [ B ]  <- M por N pentagonal
!>
!>  de tal manera que W pueda representarse como
!>
!>               W = [ I ]  <- identidad, N por N
!>                   [ V ]  <- M por N, misma forma que B.
!>
!>  Por lo tanto, toda la información necesaria para W está contenida en la salida en B,
!>  a la que llamamos V arriba. Nótese que V tiene la misma forma que B; es decir,
!>
!>               V = [ V1 ] <- (M-L)-por-N rectangular
!>                   [ V2 ] <-     L-por-N trapezoidal superior.
!>
!>  Las columnas de V representan los vectores que definen los H(i).
!>  El reflector de bloque H de (M+N)-por-(M+N) está dado entonces por
!>
!>               H = I - W * T * W**H
!>
!>  donde W**H es la transpuesta conjugada de W y T es el factor triangular superior
!>  del reflector de bloque.
!>
