Documentación de Función/Subrutina

subrutina ztrevc3 (character side, character howmny, logical, dimension( * ) select, integer n, complex*16, dimension( ldt, * ) t, integer ldt, complex*16, dimension( ldvl, * ) vl, integer ldvl, complex*16, dimension( ldvr, * ) vr, integer ldvr, integer mm, integer m, complex*16, dimension( * ) work, integer lwork, double precision, dimension( * ) rwork, integer lrwork, integer info)

ZTREVC3

Propósito:

!>
!> ZTREVC3 calcula algunos o todos los autovectores derechos y/o izquierdos de
!> una matriz triangular superior compleja T.
!> Este tipo de matrices se produce mediante la factorización de Schur de
!> una matriz compleja general:  A = Q*T*Q**H, como lo calcula ZHSEQR.
!>
!> El autovector derecho x y el autovector izquierdo y de T correspondientes
!> a un autovalor w se definen como:
!>
!>              T*x = w*x,     (y**H)*T = w*(y**H)
!>
!> donde y**H denota la transpuesta conjugada del vector y.
!> Los autovalores no se introducen en esta rutina, sino que se leen directamente
!> de la diagonal de T.
!>
!> Esta rutina devuelve las matrices X y/o Y de autovectores derechos e izquierdos
!> de T, o los productos Q*X y/o Q*Y, donde Q es una matriz de entrada. Si Q es
!> el factor unitario que reduce una matriz A a la forma de Schur T, entonces
!> Q*X y Q*Y son las matrices de autovectores derechos e izquierdos de A.
!>
!> Esto utiliza una versión de BLAS de Nivel 3 de la transformación inversa.
!>

Parámetros

SIDE 
!>          SIDE es CHARACTER*1
!>          = 'R':  calcular solo autovectores derechos;
!>          = 'L':  calcular solo autovectores izquierdos;
!>          = 'B':  calcular tanto autovectores derechos como izquierdos.
!>

HOWMNY

!>          HOWMNY es CHARACTER*1
!>          = 'A':  calcular todos los autovectores derechos y/o izquierdos;
!>          = 'B':  calcular todos los autovectores derechos y/o izquierdos,
!>                  transformados inversamente usando las matrices proporcionadas en
!>                  VR y/o VL;
!>          = 'S':  calcular autovectores derechos y/o izquierdos seleccionados,
!>                  como lo indica el array lógico SELECT.
!>

SELECT

!>          SELECT es un array LOGICAL, dimensión (N)
!>          Si HOWMNY = 'S', SELECT especifica los autovectores a ser
!>          calculados.
!>          El autovector correspondiente al j-ésimo autovalor se
!>          calcula si SELECT(j) = .TRUE..
!>          No se referencia si HOWMNY = 'A' o 'B'.
!>

N

!>          N es INTEGER
!>          El orden de la matriz T. N >= 0.
!>

T

!>          T es un array COMPLEX*16, dimensión (LDT,N)
!>          La matriz triangular superior T. T se modifica, pero se restaura
!>          al salir.
!>

LDT

!>          LDT es INTEGER
!>          La dimensión principal del array T. LDT >= max(1,N).
!>

VL

!>          VL es un array COMPLEX*16, dimensión (LDVL,MM)
!>          A la entrada, si SIDE = 'L' o 'B' y HOWMNY = 'B', VL debe
!>          contener una matriz Q de N por N (usualmente la matriz unitaria Q de
!>          vectores de Schur devuelta por ZHSEQR).
!>          A la salida, si SIDE = 'L' o 'B', VL contiene:
!>          si HOWMNY = 'A', la matriz Y de autovectores izquierdos de T;
!>          si HOWMNY = 'B', la matriz Q*Y;
!>          si HOWMNY = 'S', los autovectores izquierdos de T especificados por
!>                           SELECT, almacenados consecutivamente en las columnas
!>                           de VL, en el mismo orden que sus
!>                           autovalores.
!>          No se referencia si SIDE = 'R'.
!>

LDVL

!>          LDVL es INTEGER
!>          La dimensión principal del array VL.
!>          LDVL >= 1, y si SIDE = 'L' o 'B', LDVL >= N.
!>

VR

!>          VR es un array COMPLEX*16, dimensión (LDVR,MM)
!>          A la entrada, si SIDE = 'R' o 'B' y HOWMNY = 'B', VR debe
!>          contener una matriz Q de N por N (usualmente la matriz unitaria Q de
!>          vectores de Schur devuelta por ZHSEQR).
!>          A la salida, si SIDE = 'R' o 'B', VR contiene:
!>          si HOWMNY = 'A', la matriz X de autovectores derechos de T;
!>          si HOWMNY = 'B', la matriz Q*X;
!>          si HOWMNY = 'S', los autovectores derechos de T especificados por
!>                           SELECT, almacenados consecutivamente en las columnas
!>                           de VR, en el mismo orden que sus
!>                           autovalores.
!>          No se referencia si SIDE = 'L'.
!>

LDVR

!>          LDVR es INTEGER
!>          La dimensión principal del array VR.
!>          LDVR >= 1, y si SIDE = 'R' o 'B', LDVR >= N.
!>

MM

!>          MM es INTEGER
!>          El número de columnas en los arrays VL y/o VR. MM >= M.
!>

M

!>          M es INTEGER
!>          El número de columnas en los arrays VL y/o VR realmente
!>          utilizadas para almacenar los autovectores.
!>          Si HOWMNY = 'A' o 'B', M se establece en N.
!>          Cada autovector seleccionado ocupa una columna.
!>

WORK

!>          WORK es un array COMPLEX*16, dimensión (MAX(1,LWORK))
!>

LWORK

!>          LWORK es INTEGER
!>          La dimensión del array WORK. LWORK >= max(1,2*N).
!>          Para un rendimiento óptimo, LWORK >= N + 2*N*NB, donde NB es
!>          el tamaño de bloque óptimo.
!>
!>          Si LWORK = -1, se asume una consulta de espacio de trabajo; la rutina
!>          solo calcula el tamaño óptimo del array WORK, devuelve
!>          este valor como la primera entrada del array WORK, y no se emite
!>          ningún mensaje de error relacionado con LWORK por XERBLA.
!>

RWORK

!>          RWORK es un array DOUBLE PRECISION, dimensión (LRWORK)
!>

LRWORK

!>          LRWORK es INTEGER
!>          La dimensión del array RWORK. LRWORK >= max(1,N).
!>
!>          Si LRWORK = -1, se asume una consulta de espacio de trabajo; la rutina
!>          solo calcula el tamaño óptimo del array RWORK, devuelve
!>          este valor como la primera entrada del array RWORK, y no se emite
!>          ningún mensaje de error relacionado con LRWORK por XERBLA.
!>

INFO

!>          INFO es INTEGER
!>          = 0:  salida exitosa
!>          < 0:  si INFO = -i, el i-ésimo argumento tenía un valor ilegal
!>
