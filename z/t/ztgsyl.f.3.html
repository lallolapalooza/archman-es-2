Documentación de la función/subrutina

subroutine ztgsyl (character trans, integer ijob, integer m, integer n, complex*16, dimension( lda, * ) a, integer lda, complex*16, dimension( ldb, * ) b, integer ldb, complex*16, dimension( ldc, * ) c, integer ldc, complex*16, dimension( ldd, * ) d, integer ldd, complex*16, dimension( lde, * ) e, integer lde, complex*16, dimension( ldf, * ) f, integer ldf, double precision scale, double precision dif, complex*16, dimension( * ) work, integer lwork, integer, dimension( * ) iwork, integer info)

ZTGSYL

Propósito:

!>
!> ZTGSYL resuelve la ecuación de Sylvester generalizada:
!>
!>             A * R - L * B = scale * C            (1)
!>             D * R - L * E = scale * F
!>
!> donde R y L son matrices desconocidas de m x n, (A, D), (B, E) y
!> (C, F) son pares de matrices dadas de tamaño m x m, n x n y m x n,
!> respectivamente, con entradas complejas. A, B, D y E son triangulares
!> superiores (es decir, (A,D) y (B,E) en forma de Schur generalizada).
!>
!> La solución (R, L) sobrescribe (C, F). 0 <= SCALE <= 1
!> es un factor de escala de salida elegido para evitar el desbordamiento.
!>
!> En notación matricial, (1) es equivalente a resolver Zx = scale*b, donde Z
!> se define como
!>
!>        Z = [ kron(In, A)  -kron(B**H, Im) ]        (2)
!>            [ kron(In, D)  -kron(E**H, Im) ],
!>
!> Aquí Ix es la matriz identidad de tamaño x y X**H es la transpuesta conjugada
!> de X. Kron(X, Y) es el producto de Kronecker entre las
!> matrices X e Y.
!>
!> Si TRANS = 'C', se resuelve para y en el sistema transpuesto conjugado Z**H *y = scale*b,
!> lo cual es equivalente a resolver para R y L en
!>
!>             A**H * R + D**H * L = scale * C           (3)
!>             R * B**H + L * E**H = scale * -F
!>
!> Este caso (TRANS = 'C') se utiliza para calcular una estimación basada en la
!> norma uno de Dif[(A,D), (B,E)], la separación entre los pares de matrices (A,D)
!> y (B,E), utilizando ZLACON.
!>
!> Si IJOB >= 1, ZTGSYL calcula una estimación basada en la norma de Frobenius de
!> Dif[(A,D),(B,E)]. Es decir, el recíproco de un límite inferior del
!> recíproco del valor singular más pequeño de Z.
!>
!> Este es un algoritmo de BLAS de nivel 3.
!>

Parámetros

TRANS 
!>          TRANS es CHARACTER*1
!>          = 'N': resuelve la ecuación de Sylvester generalizada (1).
!>          = 'C': resuelve el sistema (3).
!>

IJOB

!>          IJOB es INTEGER
!>          Especifica qué tipo de funcionalidad se realizará.
!>          =0: resuelve solo (1).
!>          =1: La funcionalidad de 0 y 3.
!>          =2: La funcionalidad de 0 y 4.
!>          =3: Solo se calcula una estimación de Dif[(A,D), (B,E)].
!>              (se utiliza la estrategia de "look ahead").
!>          =4: Solo se calcula una estimación de Dif[(A,D), (B,E)].
!>              (se utiliza ZGECON en subsistemas).
!>          No referenciado si TRANS = 'C'.
!>

M

!>          M es INTEGER
!>          El orden de las matrices A y D, y la dimensión de fila de
!>          las matrices C, F, R y L.
!>

N

!>          N es INTEGER
!>          El orden de las matrices B y E, y la dimensión de columna de
!>          las matrices C, F, R y L.
!>

A

!>          A es un array COMPLEX*16, dimensión (LDA, M)
!>          La matriz triangular superior A.
!>

LDA

!>          LDA es INTEGER
!>          La dimensión principal del array A. LDA >= max(1, M).
!>

B

!>          B es un array COMPLEX*16, dimensión (LDB, N)
!>          La matriz triangular superior B.
!>

LDB

!>          LDB es INTEGER
!>          La dimensión principal del array B. LDB >= max(1, N).
!>

C

!>          C es un array COMPLEX*16, dimensión (LDC, N)
!>          En la entrada, C contiene el lado derecho de la primera matriz
!>          de la ecuación en (1) o (3).
!>          En la salida, si IJOB = 0, 1 o 2, C ha sido sobrescrito por
!>          la solución R. Si IJOB = 3 o 4 y TRANS = 'N', C contiene R,
!>          la solución lograda durante el cálculo de la
!>          estimación Dif.
!>

LDC

!>          LDC es INTEGER
!>          La dimensión principal del array C. LDC >= max(1, M).
!>

D

!>          D es un array COMPLEX*16, dimensión (LDD, M)
!>          La matriz triangular superior D.
!>

LDD

!>          LDD es INTEGER
!>          La dimensión principal del array D. LDD >= max(1, M).
!>

E

!>          E es un array COMPLEX*16, dimensión (LDE, N)
!>          La matriz triangular superior E.
!>

LDE

!>          LDE es INTEGER
!>          La dimensión principal del array E. LDE >= max(1, N).
!>

F

!>          F es un array COMPLEX*16, dimensión (LDF, N)
!>          En la entrada, F contiene el lado derecho de la segunda matriz
!>          de la ecuación en (1) o (3).
!>          En la salida, si IJOB = 0, 1 o 2, F ha sido sobrescrito por
!>          la solución L. Si IJOB = 3 o 4 y TRANS = 'N', F contiene L,
!>          la solución lograda durante el cálculo de la
!>          estimación Dif.
!>

LDF

!>          LDF es INTEGER
!>          La dimensión principal del array F. LDF >= max(1, M).
!>

DIF

!>          DIF es DOUBLE PRECISION
!>          En la salida, DIF es el recíproco de un límite inferior del
!>          recíproco de la función Dif, es decir, DIF es un límite superior de
!>          Dif[(A,D), (B,E)] = sigma-min(Z), donde Z es como en (2).
!>          Si IJOB = 0 o TRANS = 'C', DIF no se referencia.
!>

SCALE

!>          SCALE es DOUBLE PRECISION
!>          En la salida, SCALE es el factor de escala en (1) o (3).
!>          Si 0 < SCALE < 1, C y F contienen las soluciones R y L, respectivamente,
!>          de un sistema ligeramente perturbado pero las matrices de entrada A, B,
!>          D y E no han sido modificadas. Si SCALE = 0, R y L contendrán
!>          las soluciones del sistema homogéneo con C = F = 0.
!>

WORK

!>          WORK es un array COMPLEX*16, dimensión (MAX(1,LWORK))
!>          En la salida, si INFO = 0, WORK(1) devuelve el LWORK óptimo.
!>

LWORK

!>          LWORK es INTEGER
!>          La dimensión del array WORK. LWORK > = 1.
!>          Si IJOB = 1 o 2 y TRANS = 'N', LWORK >= max(1,2*M*N).
!>
!>          Si LWORK = -1, entonces se asume una consulta de espacio de trabajo; la rutina
!>          solo calcula el tamaño óptimo del array WORK, devuelve
!>          este valor como la primera entrada del array WORK, y XERBLA no emite ningún mensaje
!>          de error relacionado con LWORK.
!>

IWORK

!>          IWORK es un array INTEGER, dimensión (M+N+2)
!>

INFO

!>          INFO es INTEGER
!>            =0: salida exitosa
!>            <0: Si INFO = -i, el i-ésimo argumento tenía un valor ilegal.
!>            >0: (A, D) y (B, E) tienen valores propios comunes o muy cercanos.
!>

NAME

ztgsyl - solvesthe generalized Sylvester equation $A X B$ + $Y C D$ = $Q$.

SYNOPSIS

  SUBROUTINE ZTGSYL( TRANS, TRANSA, TRANSB, SIGNS, M, N,
 &                   A, LDA, B, LDB, C, LDC, D, LDD, E, LDE, Q, LDQ,
 &                   X, LDX, Y, LDY, SCALE, IINFO )

  CHARACTER * 1   TRANS, TRANSA, TRANSB, SIGNS
  INTEGER         M, N, LDA, LDB, LDC, LDD, LDE, LDQ, LDX, LDY, IINFO
  COMPLEX*16      A( LDA, * ), B( LDB, * ), C( LDC, * ), D( LDD, * ),
 &                E( LDE, * ), Q( LDQ, * ), X( LDX, * ), Y( LDY, * )
  DOUBLE PRECISION SCALE

Function/Subroutine Documentation

ZTGSYL solves the generalized Sylvester equation:

       

       op(A) * X * op(B) + op(E) * Y * op(D) = Q
       


where X and Y are unknown matrices, and op(A) is either A or
    A**H, op(E) is either E or E**H, op(B) is either B or B**H, and op(D)
    is either D or D**H. A, B, E, D, Q, X and Y are complex
    double-precision matrices. A, E are m-by-m and B, D are n-by-n.


The matrices A, E, B, D must be in generalized Schur form, i.e.,
    A and E are upper triangular, and B and D are upper triangular (or
    quasi-upper triangular if complex).


A typical application is to find the solution X, Y of a
    Sylvester-like equation $R Z S - S L R = Q$ where R, S are
    in generalized Schur form R = Z'*A*Z, S = Z'*B*Z, L, R are block
    upper triangular matrices, i.e.,


       

       op(R) = [ R11 R12 ]    op(S) = [ S11 S12 ]
               [  0  R22 ]            [  0  S22 ]
       


and Z is a permutation matrix.


The problem is solved using a Schur decomposition method, which is
    described in detail in [3].


Arguments:




TRANS




Specifies whether to solve the equation with A, E, B, D or
        their conjugates transpose.


TRANS = 'N' Solve op(A) X op(B) + op(E) Y op(D) = Q


TRANS = 'T' Solve op(A)**T X op(B)**T + op(E)**T Y
        op(D)**T = Q


TRANS = 'C' Solve op(A)**H X op(B)**H + op(E)**H Y
        op(D)**H = Q


TRANSA




Specifies whether to use A or A**H.


TRANSA = 'N' Use A.


TRANSA = 'T' Use A**T.


TRANSA = 'C' Use A**H.


TRANSB




Specifies whether to use B or B**H.


TRANSB = 'N' Use B.


TRANSB = 'T' Use B**T.


TRANSB = 'C' Use B**H.


SIGNS




Specifies the signs of the terms op(E)*Y*op(D).


SIGNS = '+' solve op(A) X op(B) + op(E) Y op(D) = Q


SIGNS = '-' solve op(A) X op(B) - op(E) Y op(D) = Q


M




Number of rows of A, E, Q, X.
