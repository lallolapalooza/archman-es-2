NAME

la_constants - constants used in LAPACK

SYNOPSIS

    use la_constants

Detailed Description

This module defines a number of constants used by LAPACK routines. These include standard mathematical constants (like pi, e, etc.), machine- dependent constants (like machine epsilon, smallest/largest representable numbers, etc.), and some commonly used integers (0, 1, 2, 3, 4, 8, 10).

The constants are defined for both single-precision (real(sp)) and double-precision (real(dp)) floating-point types. The naming convention is as follows:

  • s prefix for single-precision constants.
  • d prefix for double-precision constants.
  • z prefix for complex double-precision constants.
  • zero, one, two, etc., for integer constants.
  • pi for the mathematical constant pi.
  • e for the mathematical constant e.
  • eps for machine epsilon.
  • sulp/ dulp for machine epsilon.
  • smlnum/ smlnov for the smallest representable number (subnormal).
  • bigmak/ bigmac for the largest representable number.
  • safmin/ safnm for the smallest number such that 1.0/x is not overflow.
  • rmax/ rmin for the largest/smallest representable number.

The constants are defined as parameters within the module, so they can be used directly by referencing the module name.

For example:

    use la_constants

    real(dp) :: x
    x = dten * dtwo  ! x will be 20.0
