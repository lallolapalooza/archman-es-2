zzat(1) Manual de comandos generales zzat(1)

NOMBRE

zzat - concatena archivos usando diferentes secuencias de instrucciones

SINOPSIS

zzat [-AbdeEntTv] [-r bucles] [-x secuencia] [ARCHIVO]...
zzat -l | --list
zzat -h | --help
zzat -V | --version

DESCRIPCIÓN

La utilidad zzat lee archivos secuencialmente, escribiéndolos a la salida estándar. El usuario puede decidir qué secuencia de llamadas a bibliotecas se utiliza para buscar y leer datos.

zzat se utiliza principalmente como una herramienta de depuración para zzuf, ya que puede emular las diferentes formas en que los programas leen archivos.

OPCIONES

-A, --show-all
Equivalente a -vET.
-b, --number-nonblank
Enumera las líneas de salida no vacías.
-d, --debug
Muestra información de depuración.
-e
Equivalente a -vET.
-E, --show-ends
Muestra $ al final de cada línea.
-n, --number
Enumera todas las líneas de salida.
-r, --repeat=bucles
Concatena todos los archivos bucles veces.
-t
Equivalente a -vT.
-T, --show-tabs
Muestra los caracteres TAB como ^I.
-v, --show-nonprinting
Utiliza la notación ^ y M-, excepto para LFD y TAB.
-x, --execute=secuencia
Lee un archivo o un flujo utilizando la secuencia de instrucciones especificada en secuencia.

Las instrucciones se ejecutan secuencialmente hasta el final del programa. El fin de archivo no es una condición de salida, excepto donde se utiliza la palabra clave feof:

fread(1,10); feof(1); fread(1,10)

Se permiten bucles usando la palabra clave repeat. De nuevo, se puede usar feof para salir prematuramente de un bucle:

repeat(10000, fgetc() feof(1))

Las instrucciones pueden estar separadas por espacios, comas o punto y coma. Una lista de todas las instrucciones y palabras clave de control disponibles se puede obtener usando este comando:

zzat -l

Si no se especifica ninguna secuencia, se utiliza la siguiente secuencia predeterminada:

repeat(-1, fread(1,32768), feof(1))

-l, --list
Muestra la lista de palabras clave y funciones compatibles y sale.
-h, --help
Muestra un breve mensaje de ayuda y sale.
-V, --version
Muestra la información de la versión y sale.

EJEMPLOS

Leer los primeros 1000 bytes de f, y luego salir:

zzat -x 'fread(1,1000)' f

Leer los primeros cuatro bytes de f, usando cuatro instrucciones diferentes:

zzat -x 'getc(),fgetc(),getc_unlocked(),_IO_getc()' f

Leer f por completo, llamando a getc() repetidamente hasta alcanzar el final del archivo:

zzat -x 'repeat(-1, getc(), feof(1))' f

Leer f por completo, en bloques de 32768 bytes hasta alcanzar el final del archivo:

zzat -x 'repeat(-1, fread(1,32768), feof(1))' f
