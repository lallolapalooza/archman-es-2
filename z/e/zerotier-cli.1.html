NOMBRE

zerotier-cli - controla el servicio de red virtual local de ZeroTier

SINOPSIS

zerotier-cli [-opciones] <comando> [argumentos]

DESCRIPCIÓN

zerotier-cli proporciona una interfaz de línea de comandos sencilla para la API JSON local del servicio de punto final de red virtual ZeroTier zerotier-one(8).

Por defecto, zerotier-cli debe ejecutarse como root o con sudo. Si desea permitir que un usuario no privilegiado utilice zerotier-cli para controlar el servicio ZeroTier del sistema, puede crear una copia local del token de autorización del servicio ZeroTier en el directorio de inicio del usuario:

sudo cp /var/lib/zerotier-one/authtoken.secret /home/usuario/.zeroTierOneAuthToken
chown usuario /home/usuario/.zeroTierOneAuthToken
chmod 0600 /home/usuario/.zeroTierOneAuthToken

(La ubicación del directorio principal del servicio ZeroTier puede variar según la plataforma. Consulte zerotier-one(8).)

Tenga en cuenta que esto otorga al usuario el poder de conectar o desconectar el sistema a o desde cualquier red virtual, lo cual es un permiso significativo.

zerotier-cli tiene varios argumentos de línea de comandos que son visibles en la salida de help. Los dos más utilizados son -j para obtener salida JSON sin procesar y -D<ruta> para especificar un directorio de trabajo alternativo del servicio ZeroTier. La salida JSON sin procesar es más fácil de analizar en scripts y también contiene detalles verborreicos que no están presentes en la salida tabular. La opción -D<ruta> especifica dónde se encuentran los archivos zerotier-one.port y authtoken.secret del servicio si el servicio no se está ejecutando en la ubicación predeterminada para su sistema.

COMANDOS

  • help: Muestra la ayuda de zerotier-cli.
  • info: Muestra información sobre este dispositivo, incluyendo su dirección ZeroTier de 10 dígitos y su estado de conexión aparente. Use -j para una salida más detallada.
  • listpeers: Este comando lista los pares VL1 (capa virtual 1, la red peer-to-peer) que este servicio conoce y con los que se ha comunicado recientemente (en los últimos 30 minutos más o menos). Estos no son necesariamente todos los dispositivos en su(s) red(es) virtual(es), y también pueden incluir algunos dispositivos que no están en ninguna red virtual a la que se haya unido. Estos suelen ser servidores raíz o controladores de red.
  • listnetworks: Esto lista las redes a las que pertenece su sistema y alguna información sobre ellas, como las direcciones IP administradas por ZeroTier que se le han asignado. (Las direcciones IP asignadas manualmente a las interfaces ZeroTier no se mostrarán aquí. Utilice los comandos estándar de interfaz de red para verlas).
  • join: Para unirse a una red, simplemente use join y su ID de red hexadecimal de 16 dígitos. Eso es todo. Luego use listnetworks para ver el estado. Recibirá una respuesta del controlador de red con un certificado y otra información, como asignaciones de IP, o recibirá "acceso denegado". En este caso, necesitará que el administrador de esta red autorice su dispositivo por su ID de dispositivo de 10 dígitos (visible con info) en el controlador de red.
  • leave: Salir de una red es tan fácil como unirse a ella. Esto desconecta de la red y elimina su interfaz del sistema. Tenga en cuenta que los pares en la red pueden permanecer en listpeers hasta por 30 minutos hasta que expiren debido a la falta de tráfico. Pero si ya no comparten una red con usted, no pueden comunicarse con usted de manera significativa.

EJEMPLOS

Únete a la red pública principal de ZeroTier, "Earth":

$ sudo zerotier-cli join 8056c2e21c000001
$ sudo zerotier-cli listnetworks
( espera hasta que obtengas una IP de Earth )
$ ping earth.zerotier.net
( ahora deberías poder hacer ping a nuestra IP de prueba de Earth )

Sal de "Earth":

$ sudo zerotier-cli leave 8056c2e21c000001

Lista de pares VL1:

$ sudo zerotier-cli listpeers
