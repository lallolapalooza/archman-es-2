null(4) Manual de Controladores de Dispositivos null(4)

NOMBRE

null, zero - sumidero de datos

DESCRIPCIÓN

Los datos escritos en los archivos especiales /dev/null y /dev/zero se descartan.

Las lecturas desde /dev/null siempre devuelven fin de archivo (es decir, read(2) devuelve 0), mientras que las lecturas desde /dev/zero siempre devuelven bytes que contienen cero (caracteres '\0').

Estos dispositivos se crean típicamente con:


mknod -m 666 /dev/null c 1 3
mknod -m 666 /dev/zero c 1 5
chown root:root /dev/null /dev/zero

ARCHIVOS

/dev/null
/dev/zero

NOTAS

Si estos dispositivos no son escribibles y legibles para todos los usuarios, muchos programas se comportarán de forma extraña.

Desde Linux 2.6.31, las lecturas desde /dev/zero se pueden interrumpir con señales. (Este cambio se realizó para ayudar con las malas latencias en lecturas grandes desde /dev/zero).

VER TAMBIÉN

chown(1), mknod(1), full(4)
