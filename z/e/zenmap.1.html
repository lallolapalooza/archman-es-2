ZENMAP(1) Guía de referencia de Zenmap ZENMAP(1)

NOMBRE

zenmap - Interfaz gráfica de Nmap y visor de resultados

SINOPSIS

zenmap [opciones] [archivo de resultados]

DESCRIPCIÓN

Zenmap es una interfaz gráfica multiplataforma de Nmap y visor de resultados. Zenmap tiene como objetivo hacer que Nmap sea fácil de usar para principiantes, al tiempo que proporciona a los usuarios experimentados de Nmap funciones avanzadas. Los escaneos usados con frecuencia se pueden guardar como perfiles para que sean fáciles de ejecutar repetidamente. Un creador de comandos permite la creación interactiva de líneas de comandos de Nmap. Los resultados de los escaneos se pueden guardar y ver más tarde. Los resultados de escaneos guardados se pueden comparar entre sí para ver en qué se diferencian. Los resultados de escaneos recientes se almacenan en una base de datos consultable.

Esta página de manual solo describe las pocas opciones de línea de comandos de Zenmap y algunas notas críticas. Una Guía del usuario de Zenmap mucho más detallada está disponible en https://nmap.org/book/zenmap.html. Otra documentación e información está disponible en la página web de Zenmap en https://nmap.org/zenmap/.

RESUMEN DE OPCIONES

-f, --file archivo de resultados

Abre el archivo de resultados dado para su visualización. El archivo de resultados puede ser un archivo de salida XML de Nmap (.xml, como el producido por nmap -oX) o un archivo de resultados de escaneo de Umit (.usr). Esta opción se puede dar más de una vez.

-h, --help

Muestra un mensaje de ayuda y sale.

-n, --nmap línea de comandos de Nmap

Ejecuta el comando Nmap dado dentro de la interfaz de Zenmap. Después de -n o --nmap, cada argumento restante de la línea de comandos se lee como la línea de comandos a ejecutar. Esto significa que -n o --nmap deben proporcionarse al final, después de cualquier otra opción. Tenga en cuenta que la línea de comandos debe incluir el nombre del ejecutable nmap: zenmap -n nmap -sS objetivo.

-p, --profile perfil

Inicia con el perfil dado seleccionado. El nombre del perfil es solo una cadena: "Escaneo regular". Si se combina con -t, inicia un escaneo con el perfil dado contra el objetivo especificado.

-t, --target objetivo

Inicia con el objetivo dado. Si se combina con -p, inicia un escaneo con el perfil dado contra el objetivo especificado.

-v, --verbose

Aumenta la verbosidad (de Zenmap, no de Nmap). Esta opción se puede dar varias veces para obtener aún más verbosidad.

Cualquier otro argumento se toma como los nombres de los archivos de resultados a abrir.

VARIABLES DE ENTORNO

ZENMAP_DEVELOPMENT

Establezca ZENMAP_DEVELOPMENT para deshabilitar la información automática de fallos.

ERRORES

Al igual que sus autores, Nmap y Zenmap no son perfectos. Pero usted puede ayudar a mejorarlos enviando informes de errores o incluso escribiendo parches. Si Nmap o Zenmap no se comportan como espera, primero actualice a la última versión disponible en https://nmap.org. Si el problema persiste, investigue para determinar si ya ha sido descubierto y abordado. Intente buscar el mensaje de error o navegar por los archivos de nmap-dev en https://seclists.org/. Lea también esta página de manual completa. Si nada de esto da resultado, envíe un informe de error a <dev@nmap.org>. Incluya todo lo que haya aprendido sobre el problema, así como qué versión de Zenmap está ejecutando y en qué versión del sistema operativo se está ejecutando. Los informes de problemas y las preguntas sobre el uso de Zenmap enviadas a dev@nmap.org tienen muchas más probabilidades de ser respondidas que las enviadas directamente a Fyodor.

Los parches de código para corregir errores son aún mejores que los informes de errores. Las instrucciones básicas para crear archivos de parche con sus cambios están disponibles en https://svn.nmap.org/nmap/HACKING. Los parches se pueden enviar a nmap-dev (recomendado) o directamente a Fyodor.

HISTORIA

Zenmap se derivó originalmente de Umit, una GUI de Nmap creada durante el Nmap Summer of Code patrocinado por Google en 2005 y 2006. El autor principal de Umit fue Adriano Monteiro Marques. Cuando Umit se modificó y se integró en Nmap en 2007, se le cambió el nombre a Zenmap.
