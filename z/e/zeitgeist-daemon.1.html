ZEITGEIST-DAEMON(1) Manual de Comandos Generales ZEITGEIST-DAEMON(1)

NOMBRE

zeitgeist-daemon - Interfaz D-Bus que proporciona un registro de actividades

SINOPSIS

zeitgeist-daemon [OPCIÓN]

DESCRIPCIÓN

zeitgeist-daemon es un demonio que proporciona un registro de actividades. Es decir, consiste en una base de datos central para eventos como el uso de archivos, historial del navegador, entradas del calendario, etc.

Toda esta información se pone a disposición de aplicaciones externas que se comunican con zeitgeist-daemon a través de D-Bus. Las aplicaciones interesadas pueden solicitar información, insertar nuevos eventos o eliminar eventos existentes.

Zeitgeist también es capaz de establecer relaciones entre actividades. Su propósito es permitir un escritorio consciente de la actividad con interfaces de usuario adaptables.

Por defecto, zeitgeist-daemon también iniciará la aplicación de registro incluida zeitgeist-datahub.

OPCIONES

El programa sigue la sintaxis habitual de línea de comandos de GNU, con opciones que comienzan con dos guiones (`--'). A continuación se incluye un resumen de las opciones.

--no-datahub
No iniciar zeitgeist-datahub junto con este demonio.
-r, --replace
Reemplazar cualquier instancia existente de Zeitgeist si ya hay una en ejecución. Si no se utiliza esta opción, zeitgeist-daemon se negará a iniciarse si se encuentra otra instancia en ejecución.
--nivel-de-registro=NIVEL_DE_REGISTRO
Especifica cuánta información se debe imprimir en la salida estándar. Los valores posibles son: DEBUG, INFO, WARNING, ERROR, CRITICAL.
--archivo-de-registro=ARCHIVO_DE_REGISTRO
Especifica un archivo al que se añadirán los registros de salida.
-q, --quit
Detener una instancia de Zeitgeist en ejecución y salir. Esto permite a Zeitgeist finalizar cualquier operación que pueda estar realizando actualmente.
-v, --version
Muestra qué versión de Zeitgeist se está ejecutando.
-h, --help
Muestra un breve mensaje de ayuda que enumera todas las opciones soportadas.

VARIABLES DE ENTORNO

ZEITGEIST_DATA_PATH
Anula el directorio donde se colocan los archivos de datos del usuario. El valor por defecto es el del directorio de datos de XDG (generalmente ~/.local/share/zeitgeist).
ZEITGEIST_DATABASE_PATH
Esta variable permite especificar una anulación para el nombre de archivo de la base de datos principal. El valor por defecto es $ZEITGEIST_DATA_PATH/activity.sqlite.
ZEITGEIST_DATABASE_BACKUP_PATH
Esta variable permite especificar una anulación para el nombre de archivo de una posible copia de seguridad de la base de datos. El valor por defecto es $ZEITGEIST_DATA_PATH/activity.sqlite.bck.
ZEITGEIST_DISABLED_EXTENSIONS
Esta variable permite especificar una lista separada por comas de nombres de extensiones que no deberían cargarse. Los nombres se extraen de los nombres de tipo de las extensiones, por lo que para deshabilitar la extensión con nombre de tipo ZeitgeistDataSourceRegistry, el valor de la variable debería ser DataSourceRegistry.

SEÑALES

SIGHUP: zeitgeist-daemon se cerrará de forma limpia.

Se recomienda que las actualizaciones del sistema de Zeitgeist envíen esta señal a todas las instancias en ejecución de zeitgeist-daemon. La activación de DBus se asegurará de que el software actualizado se reinicie automáticamente cuando sea necesario.

CÓDIGOS DE SALIDA

0
Zeitgeist terminó normalmente.
1
Ocurrió un error no especificado.
10
Ya existe una instancia de Zeitgeist en ejecución.
21
No se pudo acceder al archivo de la base de datos.
22
El archivo de la base de datos está bloqueado.

VER TAMBIÉN

zeitgeist-datahub, gnome-activity-journal
