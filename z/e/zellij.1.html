NOMBRE

zellij - ejecuta zellij

DESCRIPCIÓN

Zellij es un espacio de trabajo dirigido a desarrolladores, gente orientada a operaciones y cualquiera que ame la terminal. En su núcleo, es un multiplexor de terminal (similar a tmux y screen), pero esta es meramente su capa de infraestructura.

Zellij incluye un sistema de diseño y un sistema de plugins que permite crear plugins en cualquier lenguaje que compile a WebAssembly.

Para listar las sesiones en ejecución, ejecuta: `zellij list-sessions` Para adjuntarte a una sesión en ejecución, ejecuta: `zellij attach [nombre-de-sesión]`

OPCIONES

Ejecuta `zellij --help` para ver las opciones y subcomandos disponibles.

CONFIGURACIÓN

Zellij busca el archivo de configuración en el siguiente orden:

1.
el archivo proporcionado con --config
2.
bajo la ruta proporcionada en la variable de entorno ZELLIJ_CONFIG_FILE
3.
la ubicación predeterminada (ver sección ARCHIVOS)
4.
la ubicación del sistema

Ejecuta `zellij setup --check` para ver posibles problemas con la configuración.

DISEÑOS

Los diseños son archivos yaml que Zellij puede cargar al inicio cuando se proporciona la opción --layout. Por defecto, Zellij cargará un diseño llamado `default.yaml`, pero esto se puede cambiar usando la opción de configuración `default_layout: [NOMBRE-DEL-DISEÑO]`.

Por ejemplo, un archivo como este:

---
direction: Vertical
parts:
    - direction: Horizontal
      split_size:
        Percent: 50
      parts:
        - direction: Vertical
          split_size:
            Percent: 50
        - direction: Vertical
          split_size:
            Percent: 50
    - direction: Horizontal
      split_size:
        Percent: 50

le indicará a Zellij que cree este diseño:

+-----+-----+|     |     |+-----+     ||     |     |+-----+-----+

CREACIÓN DE DISEÑOS

Un archivo de diseño es una estructura de árbol anidada. Cada nodo describe un panel (hoja) o un espacio en el que se crearán sus partes (hijos).

Cada nodo tiene los siguientes campos:

  • direction: <Horizontal / Vertical> - los hijos del nodo se crearán mediante una división en la dirección dada.
  • split_size: - esto indica un porcentaje del espacio del padre del nodo o un tamaño fijo de columnas/filas del espacio de su padre.
  • Percent: <1-100>
  • Fixed: <número-de-líneas/número-de-columnas>
•
plugin: /ruta/a/plugin.wasm - ruta opcional a un plugin de Zellij compilado. Si se indica, carga un plugin en el espacio creado. Para más información, ver la sección PLUGINS.

COMBINACIONES DE TECLAS

Zellij viene con un conjunto predeterminado de combinaciones de teclas que pretende adaptarse al mayor número posible de usuarios, pero ese comportamiento puede ser anulado o modificado en los archivos de configuración del usuario. La información sobre las combinaciones está disponible en la sección keybinds de la configuración. Por ejemplo, para introducir una combinación de teclas que creará una nueva pestaña y navegará a la pestaña 1 después de presionar 'c', se puede escribir:

keybinds:
    normal:
        - action: [ NewTab, GoToTab: 1,]
          key: [ Char: 'c',]

donde "normal" representa un nombre de modo (ver sección MODOS), la parte "action" especifica las acciones a ejecutar por Zellij (ver sección ACCIONES) y "key" se usa para listar teclas o combinaciones de teclas enlazadas a acciones dadas (ver sección TECLAS).

Las combinaciones de teclas predeterminadas se pueden desvincular, ya sea para un modo específico o para todos los modos. Admite una lista de `keybinds` o un booleano que indica que todas las combinaciones de teclas deben desvincularse:

keybinds:
    unbind: true

Desvinculará todas las combinaciones predeterminadas.

keybinds:
    unbind: [ Ctrl: 'p']

Desvinculará todas las combinaciones predeterminadas de `^P` para cada modo.

keybinds:
    normal:
        - unbind: true

Desvinculará todas las combinaciones de teclas predeterminadas para el modo `normal`.

keybinds:
    normal:
        - unbind: [ Alt: 'n', Ctrl: 'g']

Desvinculará todas las combinaciones de teclas predeterminadas para `n` y `^g` para el modo `normal`.

ACCIONES

  • Quit - sale de Zellij
  • SwitchToMode: <InputMode> - cambia al modo de entrada especificado. Ver sección MODOS para valores posibles.
  • Resize: <Direction> - redimensiona el panel enfocado en la dirección especificada (una de: Left, Right, Up, Down).
  • FocusNextPane - cambia el foco al siguiente panel a la derecha o abajo si está en el borde de la pantalla.
  • FocusPreviousPane - cambia el foco al siguiente panel a la izquierda o arriba si está en el borde de la pantalla.
  • SwitchFocus - deja para soporte legado. Cambia el foco a un panel con el siguiente ID.
  • MoveFocus: <Direction> - mueve el foco en la dirección especificada (Left, Right, Up, Down).
  • Clear - limpia la pantalla actual.
  • DumpScreen: <File> - vuelca la pantalla en el archivo especificado.
  • DumpLayout: <File> - vuelca la pantalla en el archivo especificado o predeterminado.
  • EditScrollback - reemplaza el panel actual con el búfer de scrollback.
  • ScrollUp - se desplaza hacia arriba 1 línea en el panel enfocado.
  • ScrollDown - se desplaza hacia abajo 1 línea en el panel enfocado.
  • PageScrollUp - se desplaza hacia arriba 1 página en el panel enfocado.
  • PageScrollDown - se desplaza hacia abajo 1 página en el panel enfocado.
  • ToggleFocusFullscreen - alterna entre enfocar el panel a pantalla completa y el diseño normal.
  • NewPane: <Direction> - abre un nuevo panel en la dirección especificada (Left, Right, Up, Down) en relación al foco.
  • CloseFocus - cierra el panel enfocado.
  • NewTab - crea una nueva pestaña.
  • GoToNextTab - va a la siguiente pestaña.
  • GoToPreviousTab - va a la pestaña anterior.
  • CloseTab - cierra la pestaña actual.
  • GoToTab: <Index> - va a la pestaña con el número de índice especificado.
  • Detach - desvincula la sesión y sale.
  • ToggleActiveSyncTab - alterna entre enviar comandos de texto a todos los paneles en la pestaña actual y el modo normal.
  • UndoRenameTab - deshace el cambio de nombre de la pestaña y revierte al nombre anterior.
  • UndoRenamePane - deshace el cambio de nombre del panel y revierte al nombre anterior.

TECLAS

  • Char: <carácter> - un solo carácter sin modificador.
  • Alt: <carácter> - un solo carácter con la tecla `Alt` como modificador.
  • Ctrl: <carácter> - un solo carácter con la tecla `Ctrl` como modificador.
  • F: <1-12> - una de las teclas `F` (generalmente en la parte superior del teclado).
  • Backspace
  • Left / Right / Up / Down - teclas de flecha en el teclado.
  • Home
  • End
  • PageUp / PageDown
  • BackTab - una tecla Tab hacia atrás.
  • Delete
  • Insert
  • Esc

zellij(1) - Arch Linux Man Pages

NAME

zellij

a terminal multiplexer with a budapest-style layout

DESCRIPTION

Zellij is a terminal multiplexer that aims to be intuitive and easy to use. It allows users to create, manage, and switch between multiple terminal sessions within a single window.

Zellij's layout is inspired by the "Budapest-style" layout, which features a fixed status bar at the bottom and a tab bar at the top, with panes arranged in a grid below the tabs.

OPTIONS

This section outlines the various command-line options available for Zellij.

-h, --help
Display a help message and exit.
-v, --version
Display the version information and exit.
-l, --layout FILE
Load a layout from the specified FILE.
-c, --config FILE
Load configuration from the specified FILE.
-t, --theme NAME
Use the color theme with the specified NAME.
-s, --scroll
Enter scroll mode to navigate the pane history.
-q, --quit
Quit the current Zellij session.

CONFIGURATION

Zellij's configuration is managed through a TOML file, typically located at ~/.config/zellij/config.toml. This file allows customization of various aspects of Zellij's behavior and appearance.

Key configuration options include:

# Configuration file example
# Theme to use
theme "default"

# Keybindings
bind "Ctrl-a" {
    unbind "a"
    bind "a" { SwitchToMode "Normal"; }
    bind "Alt-a" { SwitchToMode "Normal"; }
}

# Plugins
plugins {
    status-bar
    tab-bar
    strider
}

The configuration file allows defining custom keybindings, specifying plugins to load, and setting the default theme.

LAYOUTS

Layouts define the arrangement of panes and tabs within a Zellij session. They are typically stored in TOML files within the ~/.config/zellij/layouts/ directory.

A layout file can define multiple named layouts, each specifying the structure of the panes and their initial commands.

# Example layout file
layout {
    default_layout = "default"
    
    layout "default" {
        pane_direction = "vertical"
        
        pane split_direction = "horizontal" {
            pane split_direction = "vertical" {
                pane command="ls -l"
                pane command="htop"
            }
            pane command="vim"
        }
    }
}

KEYBINDINGS

Zellij provides a powerful and flexible keybinding system. Keybindings can be defined in the configuration file to control various aspects of Zellij, including switching modes, manipulating panes and tabs, and executing commands.

Zellij has several modes, each with its own set of keybindings:

  • Normal: The default mode for navigating and interacting with sessions.
  • Locked: A mode that prevents accidental input.
  • Pane: Allows manipulation of panes (splitting, resizing, closing).
  • Tab: Allows manipulation of tabs (creating, switching, closing).
  • Scroll: Allows scrolling within a pane.
  • Resize: Allows resizing of the focused pane.
  • RenameTab: A hidden mode to rename the current tab.
  • RenamePane: A hidden mode to rename the current pane.
  • Session: Allows detaching from the current session.

Keybindings can be defined using the following structure:

bind "KEY" { ACTION }

Where KEY is the key combination (e.g., Ctrl-a, Alt-j) and ACTION is the command to execute.

Predefined actions include:

  • SwitchToMode: Switches to a specified mode (e.g., SwitchToMode "Pane").
  • Pane: Includes instructions that manipulate the panes (adding new panes, moving, closing).
  • Tab: Includes instructions that manipulate the tabs (adding new tabs, moving, closing).
  • Resize: Allows resizing of the focused pane.
  • Scroll: Allows scrolling within the focused pane.
  • RenameTab: is a "hidden" mode that can be passed to SwitchToMode action. It will trigger renaming of a tab.
  • RenamePane: is a "hidden" mode that can be passed to SwitchToMode action. It will trigger renaming of a pane.
  • Session: Allows detaching from a session.

Theme

A color theme can be defined either in truecolor, 256 or hex color format. Truecolor:

fg: [0, 0, 0]

256:

fg: 0

Hex color:

fg: "#000000"
bg: "#000"

The color theme can be specified in the following way:

themes:
  default:
    fg: [0,0,0]
    bg: [0,0,0]
    black: [0,0,0]
    red: [0,0,0]
    green: [0,0,0]
    yellow: [0,0,0]
    blue: [0,0,0]
    magenta: [0,0,0]
    cyan: [0,0,0]
    white: [0,0,0]
    orange: [0,0,0]

If the theme is called default, then zellij will pick it on startup. To specify a different theme, run zellij with:

zellij options --theme [NAME]

or put the name in the configuration file with theme: [NAME].

PLUGINS

Zellij has a plugin system based on WebAssembly. Any language that can run on WASI can be used to develop a plugin. To load a plugin include it in a layout file. Zellij comes with default plugins included: status-bar, strider, tab-bar.

  • Subdirectory called layouts inside of the configuration directory.
  • Linux: _$XDG_HOME/zellij/layouts /home/alice/.config/zellij/layouts
  • macOS: /Users/Alice/Library/Application/layouts Support/com.Zellij-Contributors.zellij/layouts

•
Linux: _$XDG_DATA_HOME/zellij/plugins /home/alice/.local/share/plugins
