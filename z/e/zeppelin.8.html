NOMBRE

zeppelin - Demonio cliente de emulación LAN ATM (LED) Zeppelin

SINOPSIS

zeppelin [-b ] [-c dirección_LECS  | -s dirección_LES ] [-e esi] [-n nombre_VLAN] [-m máscara_mensajes] [-l dirección_escucha | selector] [-i número_interfaz] [-I número_interfaz_física] [-t 1516|1580|4544|9234|18190] [-1 ] [-2 ] [-p ] [-F archivo_registro] [-f nombre_específico_Fore]

DESCRIPCIÓN

Un Cliente de Emulación LAN es una entidad en una estación final ATM que realiza la retransmisión de datos, resolución de direcciones y otras funciones de control. Utiliza la interfaz LUNI al comunicarse con otros componentes en LANs emuladas. Proporciona a las capas de protocolo superiores una interfaz similar a MAC, como las LAN IEEE 802.3/Ethernet o IEEE 802.5/Token Ring.

El código del cliente de Emulación LAN está dividido en dos partes: la aplicación de espacio de usuario llamada Demonio de Emulación LAN (LED) zeppelin(8), y el componente del kernel. Zeppelin es responsable de las operaciones de control necesarias en la condición de cliente de Emulación LAN. Forma las VCCs necesarias y recibe todos los marcos de control LE, actuando en consecuencia. También controla el funcionamiento del componente del kernel LEC.

LEC de Linux solo soporta el tipo Ethernet de LAN emulada.

SIGHUP provoca el reinicio del LEC. Se liberan todos los recursos y se inicia zeppelin.

OPCIONES

-b
Ejecutar en segundo plano (es decir, en un proceso hijo bifurcado) después de inicializar la interfaz del kernel.
-c dirección_LECS
Dirección ATM de lecs(8) (Servidor de Configuración de Emulación LAN), si no se establece, se utiliza la dirección del servidor Bien Conocido.
-s dirección_LES
Dirección ATM de les(8) (Servidor de Emulación LAN), se puede usar para omitir la fase de configuración al unirse a una LAN emulada, es decir, no se usa la dirección lecs.
-e esi
Dirección MAC a utilizar al comunicarse en la LAN Emulada. Por ejemplo, 00:20:22:23:04:05.
-n nombre_VLAN
Nombre de la LAN virtual a la que se solicita unirse. Esto se utiliza en LE_CONFIGURE_REQUEST a LECS o LE_JOIN_RESPONSE a LES, si se omite la fase de configuración.
-m máscara_mensajes
A veces uno quiere saber más sobre lo que está sucediendo en el demonio LE, por ejemplo, cuando nada funciona. Este es un valor hexadecimal largo que establece la máscara global de mensajes. 0 = Sin mensajes, ffff = Todos los mensajes.
-l dirección_escucha | selector
Dirección ATM local que zeppelin utiliza como punto de enlace local en la señalización. Úselo si está ejecutando más de un cliente o un conjunto de servidores LE. La dirección ATM local se puede especificar dando la dirección ATM completa o el byte selector deseado.
-i número_interfaz
LEC de Linux soporta hasta 40+8 interfaces de red. El número_interfaz indica a zeppelin a cuál de ellas debe adjuntarse. Las interfaces de red de tipo Ethernet están numeradas desde "lec0" hasta "lec39" y las interfaces Token Ring desde "lec40" hasta "lec47". Estos parámetros son configurables durante la compilación del kernel, consulte <linux/atmlec.h>.
-I número_interfaz_física
La interfaz física a la que este cliente LANE debe enlazarse. Si su host tiene múltiples tarjetas de red ATM, puede usar esta opción para elegir qué tarjeta utilizará este zeppelin.
-t MTU
La MTU de la ELAN a la que unirse. También debe usar ifconfig(8) para establecer la MTU de la interfaz LANE.
-1
Ejecutar como cliente LANEv1. Este es el valor predeterminado.
-2
Ejecutar como cliente LANEv2. Esto es requerido por MPOA.
-p
Habilitar proxy. Cuando se inicia con esta opción, es posible enlazar paquetes entre ATM y Ethernet. Es decir, puede usar interfaces LANE con puente normal. Consulte el mini-Howto de Puente para más información.
-F archivo_registro
En lugar de escribir mensajes de depuración en stderr, escriba los mensajes en el archivo archivo_registro. Use syslog como nombre de archivo para usar la instalación de syslog(3).
-f nombre_específico_Fore
Los servidores LANE en los switches Fore ATM pueden mostrar un nombre especial si un cliente puede proporcionarlo. Este nombre se muestra con el comando ´conf lane les show advanced´.

CONSIDERACIONES DE TOKEN RING

Se reserva un número de interfaces lec para ELANs Token Ring cuando el kernel se compila con soporte Token Ring (CONFIG_TR). Consulte la discusión sobre la opción de línea de comandos número_interfaz más arriba. El cliente Linux Token Ring LANE no soporta el puente entre Token Ring legado y las partes ATM de la ELAN, por lo que no se recomienda el uso de la opción -p. El soporte de Token Ring ha recibido menos pruebas que su contraparte Ethernet.

ARCHIVOS

/var/run/lec[número_interfaz].pid El archivo que contiene el ID del proceso de zeppelin.
