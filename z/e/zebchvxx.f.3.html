subroutine zebchvxx (double precision thresh, character*3 path)

ZEBCHVXX Propósito:

!>
!>  ZEBCHVXX ejecutará Z**SVXX en una serie de matrices de Hilbert y luego
!>  comparará los límites de error devueltos por Z**SVXX para ver si la respuesta
!>  devuelta realmente cae dentro de esos límites.
!>
!>  Se calcularán ocho cocientes de prueba. Las pruebas pasarán si son .LT.
!>  THRESH. Hay dos casos que se determinan por 1 / (SQRT( N ) * EPS).
!>  Si ese valor es .LE. al número de condición recíproco componente a componente,
!>  usa el caso garantizado, de lo contrario usa el caso no garantizado.
!>
!>  Cocientes de prueba:
!>     Sea Xc X_computada y Xt X_verdadera.
!>     La norma utilizada es la norma infinito.
!>
!>     Sea A el caso garantizado y B el caso no garantizado.
!>
!>       1. Límite de error directo garantizado norma a norma.
!>       A: norm ( abs( Xc - Xt ) / norm ( Xt ) .LE. ERRBND( *, nwise_i, bnd_i ) y
!>          ERRBND( *, nwise_i, bnd_i ) .LE. MAX(SQRT(N),10) * EPS.
!>          Si estas condiciones se cumplen, el cociente de prueba se establece en
!>          ERRBND( *, nwise_i, bnd_i ) / MAX(SQRT(N), 10). De lo contrario, es 1/EPS.
!>       B: Para este caso, CGESVXX debería simplemente devolver 1. Si es menor que
!>          uno, trátalo igual que en 1A. De lo contrario, falla. (¿Establecer el
!>          cociente de prueba en ERRBND( *, nwise_i, bnd_i ) * THRESH?)
!>
!>       2. Límite de error directo garantizado componente a componente.
!>       A: norm ( abs( Xc(j) - Xt(j) ) ) / norm (Xt(j)) .LE. ERRBND( *, cwise_i, bnd_i )
!>          para todo j Y ERRBND( *, cwise_i, bnd_i ) .LE. MAX(SQRT(N), 10) * EPS.
!>          Si estas condiciones se cumplen, el cociente de prueba se establece en
!>          ERRBND( *, cwise_i, bnd_i ) / MAX(SQRT(N), 10). De lo contrario, es 1/EPS.
!>       B: Igual que el cociente de prueba norma a norma.
!>
!>       3. Error hacia atrás.
!>       A: El cociente de prueba se establece en BERR/EPS.
!>       B: Mismo cociente de prueba.
!>
!>       4. Número de condición recíproco.
!>       A: Se calcula un número de condición con Xt y se compara con el
!>          devuelto por CGESVXX. Sea RCONDc el RCOND devuelto por CGESVXX
!>          y RCONDt el RCOND del valor verdadero. El cociente de prueba se
!>          establece en MAX(RCONDc/RCONDt, RCONDt/RCONDc).
!>       B: El cociente de prueba se establece en 1 / (EPS * RCONDc).
!>
!>       5. Número de condición recíproco norma a norma.
!>       A: El cociente de prueba se establece en
!>          MAX(ERRBND( *, nwise_i, cond_i ) / NCOND, NCOND / ERRBND( *, nwise_i, cond_i )).
!>       B: El cociente de prueba se establece en 1 / (EPS * ERRBND( *, nwise_i, cond_i )).
!>
!>       6. Número de condición recíproco componente a componente.
!>       A: El cociente de prueba se establece en
!>          MAX(ERRBND( *, cwise_i, cond_i ) / CCOND, CCOND / ERRBND( *, cwise_i, cond_i )).
!>       B: El cociente de prueba se establece en 1 / (EPS * ERRBND( *, cwise_i, cond_i )).
!>
!>     .. Parámetros ..
!>     NMAX lo determina el número más grande en la inversa de la matriz de Hilbert.
!>     La precisión se agota cuando la entrada más grande es mayor
!>     que 2 elevado al número de bits en la fracción del tipo de dato
!>     utilizado más uno, que es 24 para precisión simple.
!>     NMAX debería ser 6 para precisión simple y 11 para precisión doble.
!>
