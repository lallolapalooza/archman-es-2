ZERK(1) Documentación de GPSD ZERK(1)

NOMBRE

zerk - Ajuste GREIS (GNSS Receiver External Interface Specification) para todo uso

OPCIONES

zerk [OPCIONES] [servidor[:puerto[:dispositivo]]]

zerk -h

zerk -V

DESCRIPCIÓN

zerk es un ajuste GREIS (GNSS Receiver External Interface Specification) para todo uso. Si no tiene un GPS Javad que hable el protocolo GREIS, puede dejar de leer ahora.

Esta herramienta opera con su GPS Javad a un nivel muy bajo. Para entender zerk, primero debe estar familiarizado con su GPS Javad y la documentación del protocolo GREIS. Guía GREIS https://www.javad.com/downloads/javadgnss/manuals/GREIS/GREIS_Reference_Guide.pdf.

zerk puede decodificar mensajes GREIS comunes, consultar el estado del GPS, habilitar y deshabilitar funciones del GPS, y enviar comandos generados por el usuario al GPS. Puede leer mensajes GREIS de un archivo. Puede leer y escribir directamente a través de un dispositivo serie, o a través de una instancia de gpsd en ejecución.

zerk no requiere privilegios de root, excepto quizás para acceder al puerto serie en modo directo. Funcionará bien como root. Ejecutar bajo sudo causará pérdida de funcionalidad.

OPCIONES

El programa acepta las siguientes opciones:

-?, -h

Hace que zerk imprima un mensaje de uso y salga.

-c COMANDO

Envía una cadena de texto al GPS. Acepta un parámetro, COMANDO, la cadena de comando a enviar al GPS. La cadena se envía tal cual, excepto que se añade un salto de línea.

-d OPCIÓN

Deshabilita una opción en el GPS. Acepta un parámetro, OPCIÓN, la opción a deshabilitar. zerk saldrá después de que el GPS acuse recibo del comando, a menos que se proporcione -W.

4HZ

Deshabilita mensajes GREIS básicos a 4Hz. Los mensajes son: [RT], [UO], [GT], [PV], [SG], [DP], [SI], [EL], [AZ], [EC], [SS], y [ET]

COMPASS

Deshabilita el uso de la constelación COMPASS (BeiDou).

CONS

Deshabilita el uso de todas las constelaciones.

DEFMSG

Deshabilita el conjunto de mensajes predeterminado (/dev/msg) a 1Hz.

GALILEO

Deshabilita el uso de la constelación GALILEO.

GLONASS

Deshabilita el uso de la constelación GLONASS.

GPS

Deshabilita el uso de la constelación GPS.

IPR

Deshabilita todos los mensajes de Pseudorango Entero. Estos son [rx], [rc], [r1], [r2], [r3], [r5], [rl].

IRNSS

Deshabilita el uso de la constelación IRNSS.

NMEA

Deshabilita mensajes NMEA 4.1e básicos a 4Hz. Los mensajes son GBS, GGA, GSA, GST, GSV, RMC, VTG, y ZDA.

QZSS

Deshabilita el uso de la constelación QZSS.

SBAS

Deshabilita el uso de la constelación SBAS.

SNR

Deshabilita todos los mensajes SNR, excepto [EC]. Los mensajes deshabilitados son: [E1], [E2], [E3], [E5], [El].

-e OPCIÓN

Habilita una opción en el GPS. Acepta un parámetro, OPCIÓN, la opción a habilitar. zerk saldrá después de que el GPS acuse recibo del comando, a menos que se proporcione -W. -e acepta las mismas OPCIONES que -d, excepto que la acción es habilitar la opción.

-f ARCHIVO

Conéctate a un archivo o dispositivo. Acepta un parámetro, ARCHIVO, el archivo o dispositivo a abrir. Los archivos se abren en modo de solo lectura. Los dispositivos de caracteres se abren en modo de lectura/escritura, a menos que se proporcione el parámetro -r. Requiere el módulo pyserial.

-O OAF

Carga un Archivo de Autorización de Opciones (OAF) en el GPS. Acepta un parámetro, OAF, archivo de comandos a leer. El OAF es solo un caso especial de un archivo de comandos '.jpo' (GREIS). -O enviará cualquier archivo .jpo válido al GPS.

-p PRESELECCIÓN

Envía un comando preestablecido al GPS. Acepta un parámetro, PRESELECCIÓN, el nombre del comando a enviar. zerk saldrá después de que el GPS acuse recibo del comando, a menos que se proporcione -W.

COLDBOOT

Reinicio en frío del GPS.

CONS

Consulta las constelaciones habilitadas.

DM

Deshabilita todos los mensajes GREIS periódicos.

ID

Consulta el ID del receptor.

IPR

Consulta todos los mensajes de Pseudorango Entero. Estos son [rx], [rc], [r1], [r2], [r3], [r5], [rl].

OAF

Consulta todas las opciones OAF.

RESET

Reinicia (rearranca) el GPS.

SERIAL

Consulta el número de serie del receptor.

SNR

Consulta todos los mensajes de Relación Señal/Ruido (SNR). [EC], [E1], [E2], [E3], [E5], [El].

VENDOR

Consulta el vendedor del GPS.

VER

Consulta la versión del GPS.

-r

Solo lectura. No envía nada al GPS.

-R RAW

Guarda todos los datos brutos del GPS en el archivo RAW.

-S VELOCIDAD

Configura la velocidad serie del GPS a VELOCIDAD bps.

-s VELOCIDAD

Establece la velocidad del puerto serie local a VELOCIDAD bps. Predeterminado 115,200 bps.

-V

Imprime la versión de zerk y sale.

-v VERBOSIDAD

Establece el nivel de verbosidad a VERBOSIDAD. La verbosidad puede ser de 0 (muy silencioso) a 4 (muy ruidoso). Predeterminado 2.

-W

Forza esperar el tiempo de espera completo. Sin salida anticipada para completar el comando -d, -e o -p.

-w ESPERA

Espera ESPERA segundos antes de salir. Saldrá anticipadamente al completar el comando -d, -e o -p, a menos que se proporcione -W. Predeterminado 2.0 segundos.

ARGUMENTOS

Por defecto, los clientes recopilan datos del demonio gpsd local en ejecución en localhost, utilizando el puerto predeterminado de GPSD 2947. El argumento opcional a cualquier cliente puede anular este comportamiento: [servidor[:puerto[:dispositivo]]]

Para más explicaciones y ejemplos, consulte la sección ARGUMENTOS en la página del manual gps(1)

AMBIENTE

Las opciones pueden colocarse en la variable de entorno ZERKOPTS. ZERKOPTS se procesa antes que las opciones de la línea de comandos.

EJEMPLOS

Imprimir el puerto serie Javad actual del GPS conectado al gpsd local en ejecución:

 zerk -c "print,/cur/term"

Decodificar archivo de registro crudo:

zerk -r -f greis-binary.log -v 2

Cambiar la velocidad del puerto GPS del dispositivo en /dev/ttyAMA0 a 230,400 bps:

zerk -S 230400 -f /dev/ttyAMA0

Observar el ciclo completo de reinicio del GPS:

zerk -p RESET -v 2 -w 20 -W

Consultar Estado de SVs:

zerk -W -w 2 -v 2 -c "out,,jps/{CS,ES,GS,Is,WS,QS}"

Volcar datos de gpsd desde un servidor remoto:

zerk -v 2 -w 5 servidor

VALORES DE RETORNO

0

en caso de éxito.

1

en caso de fallo.

VER TAMBIÉN
