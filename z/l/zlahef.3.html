Documentación de Función/Subrutina

subrutina zlahef (character uplo, integer n, integer nb, integer kb, complex*16, dimension( lda, * ) a, integer lda, integer, dimension( * ) ipiv, complex*16, dimension( ldw, * ) w, integer ldw, integer info)

ZLAHEF calcula una factorización parcial de una matriz indefinida hermitiana compleja utilizando el método de pivoteo diagonal de Bunch-Kaufman (algoritmo en bloques, llamando a BLAS de Nivel 3).

Propósito:

!>
!> ZLAHEF calcula una factorización parcial de una matriz hermitiana
!> A compleja utilizando el método de pivoteo diagonal de Bunch-Kaufman.
!> La factorización parcial tiene la forma:
!>
!> A  =  ( I  U12 ) ( A11  0  ) (  I      0     )  si UPLO = 'U', o:
!>       ( 0  U22 ) (  0   D  ) ( U12**H U22**H )
!>
!> A  =  ( L11  0 ) (  D   0  ) ( L11**H L21**H )  si UPLO = 'L'
!>       ( L21  I ) (  0  A22 ) (  0      I     )
!>
!> donde el orden de D es como máximo NB. El orden real se devuelve en
!> el argumento KB, y es NB o NB-1, o N si N <= NB.
!> Nótese que U**H denota la transpuesta conjugada de U.
!>
!> ZLAHEF es una subrutina auxiliar llamada por ZHETRF. Utiliza código en
!> bloques (llamando a BLAS de Nivel 3) para actualizar la submatriz A11
!> (si UPLO = 'U') o A22 (si UPLO = 'L').
!>

Parámetros

UPLO 
!>          UPLO es CHARACTER*1
!>          Especifica si la parte triangular superior o inferior de la
!>          matriz hermitiana A está almacenada:
!>          = 'U':  Triangular superior
!>          = 'L':  Triangular inferior
!>

N

!>          N es INTEGER
!>          El orden de la matriz A.  N >= 0.
!>

NB

!>          NB es INTEGER
!>          El número máximo de columnas de la matriz A que deben
!>          factorizarse.  NB debe ser al menos 2 para permitir bloques
!>          de pivote de 2 por 2.
!>

KB

!>          KB es INTEGER
!>          El número de columnas de A que fueron realmente factorizadas.
!>          KB es NB-1 o NB, o N si N <= NB.
!>

A

!>          A es un array COMPLEX*16, dimensión (LDA,N)
!>          En la entrada, la matriz hermitiana A.  Si UPLO = 'U', la parte
!>          triangular superior principal de n por n de A contiene la parte
!>          triangular superior de la matriz A, y la parte triangular
!>          estrictamente inferior de A no se referencia. Si UPLO = 'L', la
!>          parte triangular inferior principal de n por n de A contiene la
!>          parte triangular inferior de la matriz A, y la parte triangular
!>          estrictamente superior de A no se referencia.
!>          En la salida, A contiene detalles de la factorización parcial.
!>

LDA

!>          LDA es INTEGER
!>          La dimensión principal del array A.  LDA >= max(1,N).
!>

IPIV

!>          IPIV es un array INTEGER, dimensión (N)
!>          Detalles de los intercambios y la estructura de bloques de D.
!>
!>          Si UPLO = 'U':
!>             Solo los últimos KB elementos de IPIV se establecen.
!>
!>             Si IPIV(k) > 0, entonces las filas y columnas k y IPIV(k) fueron
!>             intercambiadas y D(k,k) es un bloque diagonal de 1 por 1.
!>
!>             Si IPIV(k) = IPIV(k-1) < 0, entonces las filas y columnas
!>             k-1 y -IPIV(k) fueron intercambiadas y D(k-1:k,k-1:k)
!>             es un bloque diagonal de 2 por 2.
!>
!>          Si UPLO = 'L':
!>             Solo los primeros KB elementos de IPIV se establecen.
!>
!>             Si IPIV(k) > 0, entonces las filas y columnas k y IPIV(k) fueron
!>             intercambiadas y D(k,k) es un bloque diagonal de 1 por 1.
!>
!>             Si IPIV(k) = IPIV(k+1) < 0, entonces las filas y columnas
!>             k+1 y -IPIV(k) fueron intercambiadas y D(k:k+1,k:k+1)
!>             es un bloque diagonal de 2 por 2.
!>

W

!>          W es un array COMPLEX*16, dimensión (LDW,NB)
!>

LDW

!>          LDW es INTEGER
!>          La dimensión principal del array W.  LDW >= max(1,N).
!>

INFO

!>          INFO es INTEGER
!>          = 0: salida exitosa
!>          > 0: si INFO = k, D(k,k) es exactamente cero. La factorización
!>               se ha completado, pero la matriz diagonal de bloques D es
!>               exactamente singular.
!>
