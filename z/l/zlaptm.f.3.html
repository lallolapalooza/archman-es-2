subrutina zlaptm (character uplo, integer n, integer nrhs, double precision alpha, double precision, dimension( * ) d, complex*16, dimension( * ) e, complex*16, dimension( ldx, * ) x, integer ldx, double precision beta, complex*16, dimension( ldb, * ) b, integer ldb)

ZLAPTM

Propósito:

!>
!> ZLAPTM multiplica una matriz N por NRHS X por una matriz tridiagonal hermitiana
!> A y almacena el resultado en una matriz B. La operación tiene la
!> forma
!>
!>    B := alpha * A * X + beta * B
!>
!> donde alpha puede ser 1. o -1. y beta puede ser 0., 1. o -1.
!>

Parámetros

UPLO 
!>          UPLO es CHARACTER
!>          Especifica si la superdiagonal o la subdiagonal de la
!>          matriz tridiagonal A está almacenada.
!>          = 'U':  Superior, E es la superdiagonal de A.
!>          = 'L':  Inferior, E es la subdiagonal de A.
!>

N

!>          N es INTEGER
!>          El orden de la matriz A. N >= 0.
!>

NRHS

!>          NRHS es INTEGER
!>          El número de lados derechos, es decir, el número de columnas
!>          de las matrices X e B.
!>

ALPHA

!>          ALPHA es DOUBLE PRECISION
!>          El escalar alpha. ALPHA debe ser 1. o -1.; de lo contrario,
!>          se asume que es 0.
!>

D

!>          D es array de DOUBLE PRECISION, dimension (N)
!>          Los n elementos diagonales de la matriz tridiagonal A.
!>

E

!>          E es array de COMPLEX*16, dimension (N-1)
!>          Los n-1 elementos subdiagonales o superdiagonales de A.
!>

X

!>          X es array de COMPLEX*16, dimension (LDX,NRHS)
!>          La matriz N por NRHS X.
!>

LDX

!>          LDX es INTEGER
!>          La dimensión principal del array X. LDX >= max(N,1).
!>

BETA

!>          BETA es DOUBLE PRECISION
!>          El escalar beta. BETA debe ser 0., 1. o -1.; de lo contrario,
!>          se asume que es 1.
!>

B

!>          B es array de COMPLEX*16, dimension (LDB,NRHS)
!>          En la entrada, la matriz N por NRHS B.
!>          En la salida, B se sobrescribe con la expresión matricial
!>          B := alpha * A * X + beta * B.
!>

LDB

!>          LDB es INTEGER
!>          La dimensión principal del array B. LDB >= max(N,1).
!>
