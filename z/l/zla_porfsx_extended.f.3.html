subrutina zla_porfsx_extended (integer prec_type, character uplo, integer n, integer nrhs, complex*16, dimension( lda, * ) a, integer lda, complex*16, dimension( ldaf, * ) af, integer ldaf, logical colequ, double precision, dimension( * ) c, complex*16, dimension( ldb, * ) b, integer ldb, complex*16, dimension( ldy, * ) y, integer ldy, double precision, dimension( * ) berr_out, integer n_norms, double precision, dimension( nrhs, * ) err_bnds_norm, double precision, dimension( nrhs, * ) err_bnds_comp, complex*16, dimension( * ) res, double precision, dimension( * ) ayb, complex*16, dimension( * ) dy, complex*16, dimension( * ) y_tail, double precision rcond, integer ithresh, double precision rthresh, double precision dz_ub, logical ignore_cwise, integer info)

ZLA_PORFSX_EXTENDED mejora la solución computada de un sistema de ecuaciones lineales para matrices simétricas o Hermitianas definidas positivas realizando un refinamiento iterativo de precisión extra y proporciona estimaciones de límites de error y error hacia atrás para la solución.

Propósito:

!>
!> ZLA_PORFSX_EXTENDED mejora la solución computada de un sistema de
!> ecuaciones lineales realizando un refinamiento iterativo de precisión extra
!> y proporciona estimaciones de límites de error y error hacia atrás para la solución.
!> Esta subrutina es llamada por ZPORFSX para realizar el refinamiento iterativo.
!> Además del límite de error normwise, el código proporciona un límite de error
!> máximo por componentes si es posible. Ver comentarios para ERR_BNDS_NORM
!> y ERR_BNDS_COMP para detalles de los límites de error. Note que esta
!> subrutina solo es responsable de establecer los segundos campos de
!> ERR_BNDS_NORM y ERR_BNDS_COMP.
!>

Parámetros

PREC_TYPE 
!>          PREC_TYPE es INTEGER
!>     Especifica la precisión intermedia a ser usada en el refinamiento.
!>     El valor es definido por ILAPREC(P) donde P es un CHARACTER y P
!>          = 'S':  Simple
!>          = 'D':  Doble
!>          = 'I':  Indígena
!>          = 'X' o 'E':  Extra
!>

UPLO

!>          UPLO es CHARACTER*1
!>       = 'U':  El triángulo superior de A está almacenado;
!>       = 'L':  El triángulo inferior de A está almacenado.
!>

N

!>          N es INTEGER
!>     El número de ecuaciones lineales, es decir, el orden de la
!>     matriz A.  N >= 0.
!>

NRHS

!>          NRHS es INTEGER
!>     El número de lados derechos, es decir, el número de columnas de la
!>     matriz B.
!>

A

!>          A es arreglo COMPLEX*16, dimensión (LDA,N)
!>     En la entrada, la matriz A de N por N.
!>

LDA

!>          LDA es INTEGER
!>     La dimensión principal del arreglo A.  LDA >= max(1,N).
!>

AF

!>          AF es arreglo COMPLEX*16, dimensión (LDAF,N)
!>     El factor triangular U o L de la factorización de Cholesky
!>     A = U**T*U o A = L*L**T, tal como es calculada por ZPOTRF.
!>

LDAF

!>          LDAF es INTEGER
!>     La dimensión principal del arreglo AF.  LDAF >= max(1,N).
!>

COLEQU

!>          COLEQU es LOGICAL
!>     Si es .VERDADERO. entonces se realizó un escalado de columna a A antes de llamar
!>     a esta rutina. Esto es necesario para calcular la solución y los límites de error
!>     correctamente.
!>

C

!>          C es arreglo DOUBLE PRECISION, dimensión (N)
!>     Los factores de escala de columna para A. Si COLEQU = .FALSO., C
!>     no se accede. Si se ingresa C, cada elemento de C debe ser una potencia
!>     de la base para asegurar una solución y estimaciones de error fiables.
!>     El escalado por potencias de la base no causa errores de redondeo a menos
!>     que el resultado sea subdesbordamiento o desbordamiento. Los errores de redondeo durante el escalado
!>     conducen a refinar con una matriz que no es equivalente a la
!>     matriz de entrada, produciendo estimaciones de error que pueden no ser
!>     fiables.
!>

B

!>          B es arreglo COMPLEX*16, dimensión (LDB,NRHS)
!>     La matriz del lado derecho B.
!>

LDB

!>          LDB es INTEGER
!>     La dimensión principal del arreglo B.  LDB >= max(1,N).
!>

Y

!>          Y es arreglo COMPLEX*16, dimensión (LDY,NRHS)
!>     En la entrada, la matriz solución X, tal como es calculada por ZPOTRS.
!>     En la salida, la matriz solución mejorada Y.
!>

LDY

!>          LDY es INTEGER
!>     La dimensión principal del arreglo Y.  LDY >= max(1,N).
!>

BERR_OUT

!>          BERR_OUT es arreglo DOUBLE PRECISION, dimensión (NRHS)
!>     En la salida, BERR_OUT(j) contiene el error relativo hacia atrás por componentes
!>     para el lado derecho j de la fórmula
!>         max(i) ( abs(RES(i)) / ( abs(op(A_s))*abs(Y) + abs(B_s) )(i) )
!>     donde abs(Z) es el valor absoluto por componentes de la matriz
!>     o vector Z. Esto es calculado por ZLA_LIN_BERR.
!>

N_NORMS

!>          N_NORMS es INTEGER
!>     Determina qué límites de error se devolverán (ver ERR_BNDS_NORM
!>     y ERR_BNDS_COMP).
!>     Si N_NORMS >= 1 se devuelven límites de error normwise.
!>     Si N_NORMS >= 2 se devuelven límites de error por componentes.
!>

ERR_BNDS_NORM

!>          ERR_BNDS_NORM es arreglo DOUBLE PRECISION, dimensión (NRHS, N_ERR_BNDS)
!>     Para cada lado derecho, esta matriz contiene información sobre
!>     varios límites de error y números de condición correspondientes al
!>     error relativo normwise, que se define como sigue:
!>
!>     Error relativo normwise en el i-ésimo vector solución:
!>             max_j (abs(XTRUE(j,i) - X(j,i)))
!>            ------------------------------
!>                  max_j abs(X(j,i))
!>
!>     La matriz está indexada por el tipo de información de error como se describe
!>     a continuación. Actualmente hay hasta tres piezas de información
!>     devueltas.
!>
!>     El primer índice en ERR_BNDS_NORM(i,:) corresponde al i-ésimo
!>     lado derecho.
!>
!>     El segundo índice en ERR_BNDS_NORM(:,err) contiene los siguientes
!>     tres campos:
!>     err = 1  booleano. Confiar en la respuesta si el
!>              número de condición recíproco es menor que el umbral
!>              sqrt(n) * slamch('Epsilon').
!>
!>     err = 2  límite de error: El error directo estimado,
!>              casi con certeza dentro de un factor de 10 del error verdadero
!>              siempre que la siguiente entrada sea mayor que el umbral
!>

NAME

zla_porfsx_extended - provides extensions to la_porfsx for single right-hand side problems

SYNOPSIS

 SUBROUTINE ZLA_PORFSX_EXTENDED(
     UPLO, TRANSPOSE, EQUILIZES,
     N, NRHS, A, LDA, AF, LDAF, IPIV,
     B, LDB, X, LDX, XTRUE, LDXTRUE,
     ERR_BNDS_NORM, ERR_BNDS_COMP, RES, AYB,
     DY, Y_TAIL, RCOND, ITHRESH, RTHRESH,
     DZ_UB, IGNORE_CWISE, INFO)

     CHARACTER(LEN=1)               :: UPLO, TRANSPOSE, EQUILIZES
     INTEGER                        :: N, NRHS, LDA, LDAF, LDB, LDX,
                                     LDXTRUE
     INTEGER                        :: IPIV( * )
     INTEGER                        :: INFO
     DOUBLE PRECISION               :: ERR_BNDS_NORM( * ),
                                     ERR_BNDS_COMP( * ), AYB( * ),
                                     RCOND, RTHRESH, DZ_UB
     INTEGER                        :: ITHRESH
     LOGICAL                        :: IGNORE_CWISE
     COMPLEX*16                     :: AF( * ), B( * ), X( * ),
                                     XTRUE( * ), RES( * ), DY( * ),
                                     Y_TAIL( * )
     COMPLEX*16                     :: A( * )

Function/Subroutine Documentation

This subroutine is part of the LAPACK routines that compute the error bounds for the solution of a complex symmetric (Hermitian) system of linear equations.

Purpose This subroutine computes error bounds and estimates of reciprocal condition numbers for the solutions of a complex Hermitian positive definite system of linear equations $A \cdot x = b$.

For details on this routine, see the following:

 * ZLA_PORFSX_EXTENDED (LAPACK Working Note 165)
 * ZLA_PORFSX (LAPACK Working Note 165)

This routine is a modification of ZPORFSX that returns error bounds and condition number estimates for problems with multiple right-hand sides.

See Also

ZPORFS(3) for a similar routine without error bounds computation.

Arguments

UPLO
CHARACTER(LEN=1).

On entry, UPLO specifies whether the matrix A is upper or lower triangular.

UPLO = 'U' or 'u' only: Upper triangular matrix.

UPLO = 'L' or 'l' only: Lower triangular matrix.

TRANSPOSE
CHARACTER(LEN=1).

Specifies the form of the system of equations:

TRANSPOSE = 'N' or 'n': $A \cdot X = B$ (No transpose)

TRANSPOSE = 'C' or 'c': $A^H \cdot X = B$ (Conjugate transpose)

EQUILIZES
CHARACTER(LEN=1).

Specifies whether the matrix A has been equilibrated.

EQUILIZES = 'E' or 'e': The matrix A has been equilibrated before.

EQUILIZES = 'N' or 'n': The matrix A has not been equilibrated.

N
INTEGER.

The order of the matrix A. N >= 0.

NRHS
INTEGER.

The number of right hand sides, i.e., the number of columns of the matrices B, X, XTRUE.

NRHS >= 0.

A
COMPLEX*16 array, dimension (LDA, N).

The original upper or lower triangular matrix A. If EQUILIZES is 'E' or 'e', then A must be the equilibrated matrix.

LDA
INTEGER.

The leading dimension of the array A. LDA >= max(1, N).

AF
COMPLEX*16 array, dimension (LDAF, N).

The factors of the factorization of A. This must be the output of ZPOTRF.

LDAF
INTEGER.

The leading dimension of the array AF. LDAF >= max(1, N).

IPIV
INTEGER array, dimension (N).

The pivot indices from the factorization of A; id A = P*U'U*P^T, then IPIV is the pivot vector of U. This argument is not accessed when UPLO = 'L'.

B
COMPLEX*16 array, dimension (LDB, NRHS).

The right-hand side matrix B.

LDB
INTEGER.

The leading dimension of the array B. LDB >= max(1, N).

X
COMPLEX*16 array, dimension (LDX, NRHS).

On exit, the solution matrix X to the system of equations.

LDX
INTEGER.

The leading dimension of the array X. LDX >= max(1, N).

XTRUE
COMPLEX*16 array, dimension (LDXTRUE, NRHS).

The true solution matrix XTRUE.

LDXTRUE
INTEGER.

The leading dimension of the array XTRUE. LDXTRUE >= max(1, N).

ERR_BNDS_NORM
DOUBLE PRECISION array, dimension (NRHS, N_ERR_BNDS).

For each right hand side, this array contains information about various error bounds and condition numbers corresponding to the normwise relative error, which is defined as follows:

         norm(XTRUE - X) / norm(X)

The array is indexed by the right hand side i (on which the normwise relative error depends), and the type of error information as described below. There currently are up to three pieces of information returned for each right hand side. If componentwise accuracy is not requested (PARAMS(3) = 0.0), then ERR_BNDS_NORM is not accessed. If N_ERR_BNDS < 3, then at most the first (:, N_ERR_BNDS) entries are returned.

The first index in ERR_BNDS_NORM(i,:) corresponds to the i-th right hand side.

The second index in ERR_BNDS_NORM(:, err) contains the following three fields:

err = 1
boolean. Trust the answer if the reciprocal condition number is less than the threshold sqrt(n) * slamch('Epsilon').
err = 2
error bound: The estimated forward error, almost certainly within a factor of 10 of the true error so long as the next entry is greater than the threshold sqrt(n) * slamch('Epsilon'). This error bound should only be trusted if the previous boolean is true.
err = 3
Reciprocal condition number: Estimated normwise reciprocal condition number. Compared with the threshold sqrt(n) * slamch('Epsilon') to determine if the error estimate is . These reciprocal condition numbers are 1 / (norm(Z^{-1},inf) * norm(Z,inf)) for some appropriately scaled matrix Z. Let Z = S*A, where S scales each row by a power of the radix so all absolute row sums of Z are approximately 1.

This subroutine is only responsible for setting the second field above.

See Lapack Working Note 165 for further details and extra cautions.

ERR_BNDS_COMP
DOUBLE PRECISION array, dimension (NRHS, N_ERR_BNDS).

For each right-hand side, this array contains information about various error bounds and condition numbers corresponding to the componentwise relative error, which is defined as follows:

     Componentwise relative error in the ith solution vector:
                    abs(XTRUE(j,i) - X(j,i))
             max_j ----------------------
                         abs(X(j,i))

The array is indexed by the right-hand side i (on which the componentwise relative error depends), and the type of error information as described below. There currently are up to three pieces of information returned for each right-hand side. If componentwise accuracy is not requested (PARAMS(3) = 0.0), then ERR_BNDS_COMP is not accessed. If N_ERR_BNDS < 3, then at most the first (:,N_ERR_BNDS) entries are returned.

The first index in ERR_BNDS_COMP(i,:) corresponds to the i-th right-hand side.

The second index in ERR_BNDS_COMP(:,err) contains the following three fields:

err = 1
boolean. Trust the answer if the reciprocal condition number is less than the threshold sqrt(n) * slamch('Epsilon').
err = 2
error bound: The estimated forward error, almost certainly within a factor of 10 of the true error so long as the next entry is greater than the threshold sqrt(n) * slamch('Epsilon'). This error bound should only be trusted if the previous boolean is true.
err = 3
Reciprocal condition number: Estimated componentwise reciprocal condition number. Compared with the threshold sqrt(n) * slamch('Epsilon') to determine if the error estimate is . These reciprocal condition numbers are 1 / (norm(Z^{-1},inf) * norm(Z,inf)) for some appropriately scaled matrix Z. Let Z = S*(A*diag(x)), where x is the solution for the current right-hand side and S scales each row of A*diag(x) by a power of the radix so all absolute row sums of Z are approximately 1.

This subroutine is only responsible for setting the second field above.

See Lapack Working Note 165 for further details and extra cautions.

RES
COMPLEX*16 array, dimension (N).

Workspace to hold the intermediate residual.

AYB
DOUBLE PRECISION array, dimension (N).

Workspace.

DY
COMPLEX*16 PRECISION array, dimension (N).

Workspace to hold the intermediate solution.

Y_TAIL
COMPLEX*16 array, dimension (N).

Workspace to hold the trailing bits of the intermediate solution.

RCOND
DOUBLE PRECISION.

Reciprocal scaled condition number. This is an estimate of the reciprocal Skeel condition number of the matrix A after equilibration (if done). If this is less than the machine precision (in particular, if it is zero), the matrix is singular to working precision. Note that the error may still be small even if this number is very small and the matrix appears ill-conditioned.

ITHRESH
INTEGER.

The maximum number of residual computations allowed for refinement. The default is 10. For 'aggressive' set to 100 to permit convergence using approximate factorizations or factorizations other than LU. If the factorization uses a technique other than Gaussian elimination, the guarantees in ERR_BNDS_NORM and ERR_BNDS_COMP may no longer be trustworthy.

RTHRESH
DOUBLE PRECISION.

Determines when to stop refinement if the error estimate stops decreasing. Refinement will stop when the next solution no longer satisfies norm(dx_{i+1}) < RTHRESH * norm(dx_i) where norm(Z) is the infinity norm of Z. RTHRESH satisfies 0 < RTHRESH <= 1. The default value is 0.5. For 'aggressive' set to 0.9 to permit convergence on extremely ill-conditioned matrices. See LAWN 165 for more details.

DZ_UB
DOUBLE PRECISION.

Determines when to start considering componentwise convergence. Componentwise convergence is only considered after each component of the solution Y is stable, which we define as the relative change in each component being less than DZ_UB. The default value is 0.25, requiring the first bit to be stable. See LAWN 165 for more details.

IGNORE_CWISE
LOGICAL.

If .TRUE. then ignore componentwise convergence. Default value is .FALSE..

INFO
INTEGER.

= 0: Successful exit.

< 0: if INFO = -i, the i-th argument to ZPOTRS had an illegal value
