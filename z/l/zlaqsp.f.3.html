Documentación de función/subrutina

subrutina zlaqsp (carácter uplo, entero n, complejo*16, dimensión( * ) ap, doble precisión, dimensión( * ) s, doble precisión scond, doble precisión amax, carácter equed)

ZLAQSP escala una matriz simétrica/hermitiana en almacenamiento empaquetado, utilizando factores de escalado calculados por sppequ.

Propósito

!>
!> ZLAQSP equilibra una matriz simétrica A utilizando los factores de
!> escalado en el vector S.
!>

Parámetros

UPLO 
!>          UPLO es CHARACTER*1
!>          Especifica si la parte triangular superior o inferior de la
!>          matriz simétrica A está almacenada.
!>          = 'U':  Triangular superior
!>          = 'L':  Triangular inferior
!>

N

!>          N es INTEGER
!>          El orden de la matriz A.  N >= 0.
!>

AP

!>          AP es un array COMPLEX*16, de dimensión (N*(N+1)/2)
!>          En la entrada, la parte triangular superior o inferior de la
!>          matriz simétrica A, empaquetada por columnas en un array
!>          lineal. La j-ésima columna de A se almacena en el array AP
!>          como sigue:
!>          si UPLO = 'U', AP(i + (j-1)*j/2) = A(i,j) para 1<=i<=j;
!>          si UPLO = 'L', AP(i + (j-1)*(2n-j)/2) = A(i,j) para j<=i<=n.
!>
!>          En la salida, la matriz equilibrada: diag(S) * A * diag(S),
!>          en el mismo formato de almacenamiento que A.
!>

S

!>          S es un array DOUBLE PRECISION, de dimensión (N)
!>          Los factores de escala para A.
!>

SCOND

!>          SCOND es DOUBLE PRECISION
!>          Relación del S(i) más pequeño con el S(i) más grande.
!>

AMAX

!>          AMAX es DOUBLE PRECISION
!>          Valor absoluto del elemento de matriz más grande.
!>

EQUED

!>          EQUED es CHARACTER*1
!>          Especifica si se realizó o no el equilibrado.
!>          = 'N':  No se realizó equilibrado.
!>          = 'Y':  Se realizó equilibrado, es decir, A ha sido reemplazada
!>                  por diag(S) * A * diag(S).
!>

Parámetros internos:

!>  THRESH es un valor umbral utilizado para decidir si se debe realizar
!>  el escalado basándose en la relación de los factores de escalado.
!>  Si SCOND < THRESH, se realiza el escalado.
!>
!>  LARGE y SMALL son valores umbral utilizados para decidir si se debe
!>  realizar el escalado basándose en el tamaño absoluto del elemento
!>  de matriz más grande.
!>  Si AMAX > LARGE o AMAX < SMALL, se realiza el escalado.
!>
