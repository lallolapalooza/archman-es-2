Documentación de Función/Subrutina

subroutine zlarfb_gett (character ident, integer m, integer n, integer k, complex*16, dimension( ldt, * ) t, integer ldt, complex*16, dimension( lda, * ) a, integer lda, complex*16, dimension( ldb, * ) b, integer ldb, complex*16, dimension( ldwork, * ) work, integer ldwork)

ZLARFB_GETT

Propósito:

!>
!> ZLARFB_GETT aplica un reflector de bloque Householder complejo H desde la
!> izquierda a una matriz compleja de (K+M)-por-N
!> compuesta por dos matrices de bloque: una matriz A de K-por-N trapezoidal superior
!> almacenada en el array A, y una matriz B rectangular de M-por-(N-K), almacenada
!> en el array B. El reflector de bloque H se almacena en una representación
!> compacta WY, donde los reflectores elementales se encuentran en los
!> arrays A, B y T. Ver la sección Detalles adicionales.
!>

Parámetros

IDENT 
!>          IDENT es CHARACTER*1
!>          Si IDENT = no es 'I', o no es 'i', entonces V1 es unitaria
!>             triangular inferior y se almacena en el bloque superior izquierdo K-por-K de
!>             la matriz de entrada A,
!>          Si IDENT = 'I' o 'i', entonces V1 es una matriz identidad y
!>             no se almacena.
!>          Ver la sección Detalles adicionales.
!>

M

!>          M es INTEGER
!>          El número de filas de la matriz B.
!>          M >= 0.
!>

N

!>          N es INTEGER
!>          El número de columnas de las matrices A y B.
!>          N >= 0.
!>

K

!>          K es INTEGER
!>          El número o filas de la matriz A.
!>          K es también el orden de la matriz T, es decir, el número de
!>          reflectores elementales cuyo producto define el bloque
!>          reflector. 0 <= K <= N.
!>

T

!>          T es un array COMPLEX*16, dimension (LDT,K)
!>          La matriz T triangular superior K-por-K en la representación
!>          del reflector de bloque.
!>

LDT

!>          LDT es INTEGER
!>          La dimensión principal del array T. LDT >= K.
!>

A

!>          A es un array COMPLEX*16, dimension (LDA,N)
!>
!>          En la entrada:
!>           a) En la parte trapezoidal superior K-por-N A: matriz de entrada A.
!>           b) En las columnas debajo de la diagonal: columnas de V1
!>              (unos no se almacenan en la diagonal).
!>
!>          En la salida:
!>            A se sobrescribe con el producto rectangular K-por-N H*A.
!>
!>          Ver la sección Detalles adicionales.
!>

LDA

!>          LDB es INTEGER
!>          La dimensión principal del array A. LDA >= max(1,K).
!>

B

!>          B es un array COMPLEX*16, dimension (LDB,N)
!>
!>          En la entrada:
!>            a) En el bloque derecho M-por-(N-K): matriz de entrada B.
!>            b) En el bloque izquierdo M-por-N: columnas de V2.
!>
!>          En la salida:
!>            B se sobrescribe con el producto rectangular M-por-N H*B.
!>
!>          Ver la sección Detalles adicionales.
!>

LDB

!>          LDB es INTEGER
!>          La dimensión principal del array B. LDB >= max(1,M).
!>

WORK

!>          WORK es un array COMPLEX*16,
!>          dimension (LDWORK,max(K,N-K))
!>

LDWORK

!>          LDWORK es INTEGER
!>          La dimensión principal del array WORK. LDWORK>=max(1,K).
!>
!>

Detalles adicionales:

!>
!>    (1) Descripción de la Operación Algebraica.
!>
!>    La matriz A es una matriz K-por-N compuesta por dos matrices de bloque de columnas,
!>    A1, que es K-por-K, y A2, que es K-por-(N-K):
!>    A = ( A1, A2 ).
!>    La matriz B es una matriz M-por-N compuesta por dos matrices de bloque de columnas,
!>    B1, que es M-por-K, y B2, que es M-por-(N-K):
!>    B = ( B1, B2 ).
!>
!>    Realiza la operación:
!>
!>       ( A_salida ) := H * ( A_entrada ) = ( I - V * T * V**H ) * ( A_entrada ) =
!>       ( B_salida )        ( B_entrada )                          ( B_entrada )
!>                  = ( I - ( V1 ) * T * ( V1**H, V2**H ) ) * ( A_entrada )
!>                          ( V2 )                            ( B_entrada )
!>     En la entrada:
!>
!>    a) ( A_entrada ) consiste en dos bloques de columnas:
!!>       ( B_entrada )
!>
!>       ( A_entrada ) = (( A1_entrada ) ( A2_entrada )) = (( A1_entrada ) ( A2_entrada ))
!>       ( B_entrada )   (( B1_entrada ) ( B2_entrada ))   ((     0 ) ( B2_entrada )),
!>
!>       donde los bloques de columnas son:
!>
!>       (  A1_entrada )  es una matriz triangular superior K-por-K almacenada en la
!>                       parte triangular superior del array A(1:K,1:K).
!>       (  B1_entrada )  es una matriz CERO rectangular M-por-K y no se almacena.
!>
!>       ( A2_entrada )  es una matriz rectangular K-por-(N-K) almacenada
!>                       en el array A(1:K,K+1:N).
!>       ( B2_entrada )  es una matriz rectangular M-por-(N-K) almacenada
!>                       en el array B(1:M,K+1:N).
!>
!>    b) V = ( V1 )
!>           ( V2 )
!>
!>       donde:
!>       1) si IDENT == 'I', V1 es una matriz identidad K-por-K, no se almacena;
!>       2) si IDENT != 'I', V1 es una matriz triangular inferior unitaria K-por-K,
!>          almacenada en la parte triangular inferior del array
!>          A(1:K,1:K) (los unos no se almacenan),
!>       y V2 es una matriz rectangular M-por-K almacenada en el array
!>          B(1:M,1:K),
!>          (porque en la entrada B1_entrada es una matriz cero rectangular que no se almacena y el espacio
!>           se utiliza para almacenar V2).
!>
!>    c) T es una matriz triangular superior K-por-K almacenada
!>       en el array T(1:K,1:K).
!>
!>    En la salida:
!>
!>    a) ( A_salida ) consiste en dos bloques de columnas:
!>       ( B_salida )
!>
!>       ( A_salida ) = (( A1_salida ) ( A2_salida ))
!>       ( B_salida )   (( B1_salida ) ( B2_salida )),
!>
!>       donde los bloques de columnas son:
!>
!>       ( A1_salida )  es una matriz cuadrada K-por-K, o una matriz
!>                      triangular superior K-por-K, si V1 es una
!>                      matriz identidad. AiSalida se almacena en
!>                      el array A(1:K,1:K).
!>       ( B1_salida )  es una matriz rectangular M-por-K almacenada
!>                      en el array B(1:M,K:N).
!>
!>       ( A2_salida )  es una matriz rectangular K-por-(N-K) almacenada
!>                      en el array A(1:K,K+1:N).
!>       ( B2_salida )  es una matriz rectangular M-por-(N-K) almacenada
!>                      en el array B(1:M,K+1:N).
!>
!>
!>    La operación anterior se puede representar como la misma operación
!>    en cada bloque de columna:
!>
!>       ( A1_salida ) := H * ( A1_entrada ) = ( I - V * T * V**H ) * ( A1_entrada )
!>       ( B1_salida )        (     0 )                          (     0 )
!>
!>       ( A2_salida ) := H * ( A2_entrada ) = ( I - V * T * V**H ) * ( A2_entrada )
!>       ( B2_salida )        ( B2_entrada )                          ( B2_entrada )
!>
!>    Si IDENT != 'I':
!>
!>       El cálculo para el bloque de columna 1:
!>
!>       A1_salida: = A1_entrada - V1*T*(V1**H)*A1_entrada
!>
!>       B1_salida: = - V2*T*(V1**H)*A1_entrada
!>
!>       El cálculo para el bloque de columna 2, que existe si N > K:
!>
!>       A2_salida: = A2_entrada - V1*T*( (V1**H)*A2_entrada + (V2**H)*B2_entrada )
!>
!>       B2_salida: = B2_entrada - V2*T*( (V1**H)*A2_entrada + (V2**H)*B2_entrada )
!>
!>    Si IDENT == 'I':
!>
!>       La operación para el bloque de columna 1:
!>
!>       A1_salida: = A1_entrada - V1*T*A1_entrada
!>
!>       B1_salida: = - V2*T*A1_entrada
!>
!>       El cálculo para el bloque de columna 2, que existe si N > K:

NAME


zlarfb_gett - para obtener la matriz de transformación de
  bloque de columna triangular inferior de forma unitaria.






SYNOPSIS

                         V, LDV, T, LDT, C, LDC, Q, LDQ, WORK, LWORK, INFO)
    character(len=1) :: SIDE, TRANS, DIRECT, FORWARD, STOREZ
    integer :: M, N, K, LDV, LDT, LDC, LDQ, LWORK, INFO
    complex(8) :: V(LDV, *), T(LDT, *), C(LDC, *), Q(LDQ, *), WORK(LWORK)

    character(len=1) :: SIDE, TRANS, DIRECT, FORWARD, STOREZ
    integer :: M, N, K, LDV, LDT, LDC, LDQ, LWORK, INFO
    complex(8) :: V(LDV, *), T(LDT, *), C(LDC, *), Q(LDQ, *), WORK(LWORK)
    complex(8) :: W1(K, K), W2(K, N - K)







Function/Subroutine Documentation








       Subroutine zlarfb_gett(SIDE, TRANS, DIRECT, FORWARD, STOREZ, M, N, K,
                              V, LDV, T, LDT, C, LDC, Q, LDQ, WORK, LWORK,
                              INFO)









!> \brief
!> END
!>
!> \param[in] SIDE
!>           \parblock
!>           = &#39;L&#39;: apply left side
!>           = &#39;R&#39;: apply right side
!>           \endparblock
!>
!> \param[in] TRANS
!>           \parblock
!>           = &#39;N&#39;: not a transpose, and not a conjugate transpose, and not
!>                     a transpose conjugate
!>           = &#39;C&#39;: conjugate transpose
!>           \endparblock
!>
!> \param[in] DIRECT
!>           \parblock
!>           = &#39;F&#39;: forward sweep using triangular factor T
!>           = &#39;B&#39;: backward sweep using triangular factor T
!>           \endparblock
!>
!> \param[in] FORWARD
!>           \parblock
!>           = &#39;F&#39;: forward sweep
!>           = &#39;B&#39;: backward sweep
!>           \endparblock
!>
!> \param[in] STOREZ
!>           \parblock
!>           = &#39;A&#39;: the vector V is stored column-wise below the diagonal
!>                     of the rectangular matrix S and
!>                     the transformation is applied to the matrix S.
!>           = &#39;L&#39;: the vector V is stored column-wise left of the
!>                     k-th column of the rectangular matrix S and
!>                     the transformation is applied to the matrix S.
!>           = &#39;R&#39;: the vector V is stored column-wise right of the
!>                     k-th column of the rectangular matrix S and
!>                     the transformation is applied to the matrix S.
!>           \endparblock
!>
!> \param[in] M
!>           The number of rows of the matrix C.
!>
!> \param[in] N
!>           The number of columns of the matrix C.
!>
!> \param[in] K
!>           The number of columns of the matrix V and the number of rows and
!>           columns of the matrix T.
!>
!> \param[in] V
!>           The K-by-M matrix V if SIDE = &#39;L&#39;, or the K-by-N matrix V if
!>           SIDE = &#39;R&#39;.
!>
!> \param[in] LDV
!>           The leading dimension of the array V.
!>
!> \param[in] T
!>           The K-by-K upper triangular factor of the triangular factor
!>           of the triangular multiplier.
!>
!> \param[in] LDT
!>           The leading dimension of the array T.
!>
!> \param[in,out] C
!>           On entry, the M-by-N matrix C to which theautenfactor is applied.
!>           On exit, C is updated with the result of applying theautenfactor.
!>
!> \param[in] LDC
!>           The leading dimension of the array C.
!>
!> \param[out] Q
!>           The M-by-K matrix Q if SIDE = &#39;L&#39;, or the N-by-K matrix Q if
!>           SIDE = &#39;R&#39;.
!>
!> \param[in] LDQ
!>           The leading dimension of the array Q.
!>
!> \param[out] WORK
!>           Workspace array of dimension (LWORK).
!>
!> \param[in] LWORK
!>           The dimension of the array WORK.
!>
!> \param[out] INFO
!>           \parblock
!>           = 0:  successful exit
!>           &lt; 0:  if INFO = -i, the i-th argument had an illegal value.
!>           \endparblock
!>
!> ********************************************************************************
!> ** ZLARFB_GETT computes the triangular factor of a block reflector.            **
!> **                                                                            **
!> ** This subroutine is the "get" version of ZLARFB, which computes the        **
!> ** triangular factor of the block reflector H = I - V T V**H                  **
!> **                                                                            **
!> ** Arguments                                                                  **
!> ********************************************************************************
!>
!> Let C be an M-by-N matrix. We are computing the triangular factor of
!> the block reflector H, where
!>
!>       If SIDE = 'L', H is an M-by-M matrix, and we are computing the
!>       triangular factor of H applied to C as follows:
!>          Forward sweep:                  Backward sweep:
!>          C := H * C                      C := H**H * C
!>          A2 := A2 - V * (T * (V**H * A2))   A1 := A1 - V * (T * (V**H * A1))
!>          B2 := B2 - V * (T * (V**H * B2))   B1 := B1 - V * (T * (V**H * B1))
!>       where C = [A1 A2] and V = [V1 V2] is an M-by-K matrix, and T is a
!>       K-by-K upper triangular matrix. A1 and V1 are M-by-K, A2 and V2 are
!>       M-by-(N-K).
!>
!>       If SIDE = 'R', H is an N-by-N matrix, and we are computing the
!>       triangular factor of H applied to C as follows:
!>          Forward sweep:                  Backward sweep:
!>          C := C * H                      C := C * H**H
!>          A1 := A1 - (A1 * V * T) * V**H   A2 := A2 - (A2 * V * T) * V**H
!>          B1 := B1 - (B1 * V * T) * V**H   B2 := B2 - (B2 * V * T) * V**H
!>       where C = [A1 B1] and V = [A2 B2] is an N-by-K matrix, and T is a
!>       K-by-K upper triangular matrix. A1 and V1 are N-by-K, A2 and V2 are
!>       N-by-(N-K).
!>
!>
!> ** The relation between H and T is:                                          **
!> ** H = I - V T V**H                                                          **
!> **                                                                            **
!> ** The subroutine computes the required triangular factor (A1 or A2) of H.  **
!> ** Let the computed triangular factor be denoted by W.                        **
!> **                                                                            **
!> ** If SIDE = 'L':                                                            **
!> **   If FORWARD = 'F', the subroutine computes the triangular factor of      **
!> **   the block reflector applied from the left                               **
!> **   [ A1 ]   [ I - V1 T V1**H   0   ] [ A1 ]                                **
!> **   [ A2 ] = [        0          I   ] [ A2 ]                                **
!> **   In this case, the subroutine computes the triangular factor of A1.      **
!> **   Let A1 = [A11 A12]. The subroutine computes W1, where                   **
!> **   A1 := A1 - V1 * (T * (V1**H * A1))                                      **
!> **   So, W1 is computed such that A1 becomes A1 - V1 * (T * (V1**H * A1)).   **
!> **   Here A1 is M-by-K, V1 is M-by-K, T is K-by-K, W1 is K-by-K.              **
!> **                                                                            **
!> **   If FORWARD = 'B', the subroutine computes the triangular factor of      **
!> **   the block reflector applied from the left                               **
!> **   [ A1 ]   [ I   0   ] [ A1 ]                                             **
!> **   [ A2 ] = [ 0  I - V2 T V2**H ] [ A2 ]                                   **
!> **   In this case, the subroutine computes the triangular factor of A2.      **
!> **   Let A2 = [A21 A22]. The subroutine computes W2, where                   **
!> **   A2 := A2 - V2 * (T * (V2**H * A2))                                      **
!> **   So, W2 is computed such that A2 becomes A2 - V2 * (T * (V2**H * A2)).   **
!> **   Here A2 is M-by-(N-K), V2 is M-by-K, T is K-by-K, W2 is K-by-K.          **
!> **                                                                            **
!> ** If SIDE = 'R':                                                            **
!> **   If FORWARD = 'F', the subroutine computes the triangular factor of      **
!> **   the block reflector applied from the right                              **
!> **   [ A1 A2 ] = [ A1 A2 ] [ I - V1 T V1**H  0  ]                           **
!> **                             [       0         I ]                           **
!> **   In this case, the subroutine computes the triangular factor of A1.      **
!> **   Let A1 = [A11 A12]. The subroutine computes W1, where                   **
!> **   A1 := A1 - (A1 * V1 * T) * V1**H                                        **
!> **   So, W1 is computed such that A1 becomes A1 - (A1 * V1 * T) * V1**H.     **
!> **   Here A1 is K-by-K, V1 is N-by-K, T is K-by-K, W1 is K-by-K.              **
!> **                                                                            **
!> **   If FORWARD = 'B', the subroutine computes the triangular factor of      **
!> **   the block reflector applied from the right                              **
!> **   [ A1 A2 ] = [ A1 A2 ] [ I  0 ]                                          **
!> **                         [ 0 I - V2 T V2**H ]                               **
!> **   In this case, the subroutine computes the triangular factor of A2.      **
!> **   Let A2 = [A21 A22]. The subroutine computes W2, where                   **
!> **   A2 := A2 - (A2 * V2 * T) * V2**H                                        **
!> **   So, W2 is computed such that A2 becomes A2 - (A2 * V2 * T) * V2**H.     **
!> **   Here A2 is (N-K)-by-K, V2 is N-by-K, T is K-by-K, W2 is K-by-K.          **
!> **                                                                            **
!> **                                                                            **
!> ** Notes:                                                                     **
!> **   - The matrices A1, A2, B1, B2, V1, V2 are defined as follows:          **
!> **                                                                            **
!> **     If SIDE = 'L':                                                        **
!> **       C is an M-by-N matrix.                                               **
!> **       If FORWARD = 'F', then C is split into A1 (M-by-K) and A2 (M-by-N-K).**
!> **       V is an M-by-K matrix.                                               **
!> **       If FORWARD = 'F', then V is split into V1 (M-by-K) and V2 (M-by-N-K).**
!> **       The subroutine computes W1 (K-by-K).                                **
!> **       If FORWARD = 'B', then C is split into A1 (M-by-K) and A2 (M-by-N-K).**
!> **       V is an M-by-K matrix.                                               **
!> **       If FORWARD = 'B', then V is split into V1 (M-by-K) and V2 (M-by-N-K).**
!> **       The subroutine computes W2 (K-by-K).                                **
!> **                                                                            **
!> **     If SIDE = 'R':                                                        **
!> **       C is an M-by-N matrix.                                               **
!> **       If FORWARD = 'F', then C is split into A1 (K-by-N) and A2 (M-K-by-N).**
!> **       V is an N-by-K matrix.                                               **
!> **       If FORWARD = 'F', then V is split into V1 (K-by-K) and V2 (N-K-by-K).**
!> **       The subroutine computes W1 (K-by-K).                                **
!> **       If FORWARD = 'B', then C is split into A1 (K-by-N) and A2 (M-K-by-N).**
!> **       V is an N-by-K matrix.                                               **
!> **       If FORWARD = 'B', then V is split into V1 (K-by-K) and V2 (N-K-by-K).**
!> **       The subroutine computes W2 (K-by-K).                                **
!> **                                                                            **
!> ** The relation between H and T is:                                          **
!> ** H = I - V T V**H                                                          **
!> **                                                                            **
!> ** The description below follows the standard formulation of the triangular   **
!> ** factor of the block reflector.                                             **
!> ** Let H = I - V T V**H.                                                      **
!> **                                                                            **
!> ** Case 1: SIDE = 'L'                                                         **
!> **   If FORWARD = 'F', then the subroutine computes the triangular factor of  **
!> **   the block reflector applied to the first K columns of C. Let C = [A1 A2].**
!> **   Then the operation is:                                                   **
!> **      A1 := A1 - V1 * (T * (V1**H * A1))                                    **
!> **   where V1 is the first K columns of V.                                    **
!> **   Let W1 be the K-by-K matrix such that A1 = W1.                           **
!> **                                                                            **
!> **   If FORWARD = 'B', then the subroutine computes the triangular factor of  **
!> **   the block reflector applied to the last N-K columns of C. Let C = [A1 A2].**
!> **   Then the operation is:                                                   **
!> **      A2 := A2 - V2 * (T * (V2**H * A2))                                    **
!> **   where V2 is the last K columns of V.                                     **
!> **   Let W2 be the K-by-K matrix such that A2 = W2.                           **
!> **                                                                            **
!> ** Case 2: SIDE = 'R'                                                         **
!> **   If FORWARD = 'F', then the subroutine computes the triangular factor of  **
!> **   the block reflector applied to the first K rows of C. Let C = [A1; A2].  **
!> **   Then the operation is:                                                   **
!> **      A1 := A1 - (A1 * V1 * T) * V1**H                                      **
!> **   where V1 is the first K rows of V.                                       **
!> **   Let W1 be the K-by-K matrix such that A1 = W1.                           **
!> **                                                                            **
!> **   If FORWARD = 'B', then the subroutine computes the triangular factor of  **
!> **   the block reflector applied to the last N-K rows of C. Let C = [A1; A2]. **
!> **   Then the operation is:                                                   **
!> **      A2 := A2 - (A2 * V2 * T) * V2**H                                      **
!> **   where V2 is the last K rows of V.                                        **
!> **   Let W2 be the K-by-K matrix such that A2 = W2.                           **
!> **                                                                            **
!> ** The relationship between the input and output is as follows:             **
!> **                                                                            **
!> ** The routine computes the triangular factor of the block reflector.        **
!> ** Let H = I - V T V**H.                                                      **
!> **                                                                            **
!> ** Case A: V1 is unit lower-triangular.                                       **
!> **   In this case, we compute the triangular factor of H as follows:          **
!> **   If SIDE = 'L' and FORWARD = 'F':                                        **
!> **     Let C = [A1 A2]. We compute the triangular factor of the reflector     **
!> **     applied to A1. The operation is:                                       **
!> **     A1 := A1 - V1 * (T * (V1**H * A1))                                    **
!> **     The resulting matrix A1 is stored in the workspace matrix W1.        **
!> **                                                                            **
!> **   If SIDE = 'L' and FORWARD = 'B':                                        **
!> **     Let C = [A1 A2]. We compute the triangular factor of the reflector     **
!> **     applied to A2. The operation is:                                       **
