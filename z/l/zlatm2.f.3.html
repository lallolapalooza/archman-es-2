función complex*16 zlatm2 (integer m, integer n, integer i, integer j, integer kl, integer ku, integer idist, integer, dimension( 4 ) iseed, complex*16, dimension( * ) d, integer igrade, complex*16, dimension( * ) dl, complex*16, dimension( * ) dr, integer ipvtng, integer, dimension( * ) iwork, double precision sparse)

ZLATM2

Propósito:

!>
!>    ZLATM2 devuelve la entrada (I,J) de una matriz aleatoria de dimensión
!>    (M, N) descrita por los otros parámetros. Es llamada por la
!>    rutina ZLATMR para construir matrices de prueba aleatorias. No se realiza
!>    ninguna comprobación de errores en los parámetros, ya que esta rutina es llamada
!>    en un bucle ajustado por ZLATMR, que ya ha comprobado los parámetros.
!>
!>    El uso de ZLATM2 difiere de CLATM3 en el orden en que se llama al generador
!>    de números aleatorios para rellenar las entradas de la matriz aleatoria.
!>    Con ZLATM2, el generador se llama para rellenar la matriz
!>    pivotada columna por columna. Con ZLATM3, el generador se llama para rellenar la
!>    matriz columna por columna, después de lo cual se pivota. Por lo tanto, ZLATM3 puede
!>    utilizarse para construir matrices aleatorias que difieren solo en su
!>    orden de filas y/o columnas. ZLATM2 se utiliza para construir
!>    matrices de banda mientras se evita llamar al generador de números aleatorios
!>    para entradas fuera de la banda (y por lo tanto generando números aleatorios
!>
!>    La matriz cuya entrada (I,J) se devuelve se construye como
!>    sigue (esta rutina solo calcula una entrada):
!>
!>      Si I está fuera de (1..M) o J está fuera de (1..N), devuelve cero
!>         (esto es conveniente para generar matrices en formato de banda).
!>
!>      Genera una matriz A con entradas aleatorias de distribución IDIST.
!>
!>      Establece la diagonal a D.
!>
!>      Califica la matriz, si se desea, desde la izquierda (por DL) y/o
!>         desde la derecha (por DR o DL) según lo especificado por IGRADE.
!>
!>      Permuta, si se desea, las filas y/o columnas según lo especificado por
!>         IPVTNG y IWORK.
!>
!>      Bandifica la matriz para que tenga ancho de banda inferior KL y superior
!>         ancho de banda KU.
!>
!>      Establece entradas aleatorias a cero según lo especificado por SPARSE.
!>

Parámetros

M 
!>          M es INTEGER
!>           Número de filas de la matriz. No modificada.
!>

N

!>          N es INTEGER
!>           Número de columnas de la matriz. No modificada.
!>

I

!>          I es INTEGER
!>           Fila de la entrada a devolver. No modificada.
!>

J

!>          J es INTEGER
!>           Columna de la entrada a devolver. No modificada.
!>

KL

!>          KL es INTEGER
!>           Ancho de banda inferior. No modificado.
!>

KU

!>          KU es INTEGER
!>           Ancho de banda superior. No modificado.
!>

IDIST

!>          IDIST es INTEGER
!>           En la entrada, IDIST especifica el tipo de distribución a utilizar
!>           para generar una matriz aleatoria.
!>           1 => partes real e imaginaria cada UNA UNIFORME( 0, 1 )
!>           2 => partes real e imaginaria cada UNA UNIFORME( -1, 1 )
!>           3 => partes real e imaginaria cada UNA NORMAL( 0, 1 )
!>           4 => número complejo uniforme en DISCO( 0 , 1 )
!>           No modificado.
!>

ISEED

!>          ISEED es array de INTEGER de dimensión ( 4 )
!>           Semilla para el generador de números aleatorios.
!>           Modificado en la salida.
!>

D

!>          D es array de COMPLEX*16 de dimensión ( MIN( I , J ) )
!>           Entradas diagonales de la matriz. No modificada.
!>

IGRADE

!>          IGRADE es INTEGER
!>           Especifica la calificación de la matriz como sigue:
!>           0  => sin calificación
!>           1  => matriz premultiplicada por diag( DL )
!>           2  => matriz postmultiplicada por diag( DR )
!>           3  => matriz premultiplicada por diag( DL ) y
!>                         postmultiplicada por diag( DR )
!>           4  => matriz premultiplicada por diag( DL ) y
!>                         postmultiplicada por inv( diag( DL ) )
!>           5  => matriz premultiplicada por diag( DL ) y
!>                         postmultiplicada por diag( CONJG(DL) )
!>           6  => matriz premultiplicada por diag( DL ) y
!>                         postmultiplicada por diag( DL )
!>           No modificado.
!>

DL

!>          DL es array de COMPLEX*16 ( I o J, según corresponda )
!>           Factores de escala izquierdos para calificar la matriz. No modificada.
!>

DR

!>          DR es array de COMPLEX*16 ( I o J, según corresponda )
!>           Factores de escala derechos para calificar la matriz. No modificada.
!>

IPVTNG

!>          IPVTNG es INTEGER
!>           En la entrada especifica las permutaciones de pivote como sigue:
!>           0 => ninguna.
!>           1 => pivoteo de filas.
!>           2 => pivoteo de columnas.
!>           3 => pivoteo completo, es decir, en ambos lados.
!>           No modificado.
!>

IWORK

!>          IWORK es array de INTEGER ( I o J, según corresponda )
!>           Este array especifica la permutación utilizada. La
!>           fila (o columna) en la posición K estaba originalmente en
!>           la posición IWORK( K ).
!>           Esto difiere de IWORK para ZLATM3. No modificado.
!>

SPARSE

!>          SPARSE es DOUBLE PRECISION entre 0. y 1.
!>           En la entrada especifica la dispersión de la matriz
!>           si se va a generar una matriz dispersa.
!>           SPARSE debe estar entre 0 y 1.
!>           Se genera un número aleatorio x UNIFORME( 0, 1 ) y
!>           se compara con SPARSE; si x es mayor, la entrada de la matriz
!>           no se modifica y si x es menor, la entrada se establece
!>           a cero. Por lo tanto, en promedio, una fracción SPARSE de las
!>           entradas se establecerá a cero.
!>           No modificado.
!>

NAME

zlatm2 - Devuelve la matriz A(M,N) con las siguientes propiedades:

  • El valor absoluto máximo de los elementos es 1.
  • La norma 1 es 1.
  • Los valores escalados de los elementos A(I,J) son razonablemente pequeños.

Se utiliza para probar las rutinas de la biblioteca de álgebra lineal.

SYNOPSIS

SUBROUTINE ZLATM2( ISEED, M, N, A, LDA, W, RES )
CHARACTER*1 ISEED(*)
INTEGER M, N, LDA
COMPLEX*16 A(LDA,*), W(*)
REAL*8 RES

PURPOSE

ZLATM2 genera una matriz M por N de números complejos con los siguientes atributos:

  • El valor absoluto máximo de sus elementos es 1.
  • La norma 1 es 1.
  • Los valores escalados de los elementos A(I,J) son razonablemente pequeños.

Se utiliza para probar las rutinas de la biblioteca de álgebra lineal.

ARGUMENT PARAMETERS

  • ISEED (CHARACTER*1) - La semilla utilizada para la generación de números aleatorios.
  • M (INTEGER) - El número de filas de la matriz A.
  • N (INTEGER) - El número de columnas de la matriz A.
  • A (COMPLEX*16) - La matriz de salida (M,N).
  • LDA (INTEGER) - El tamaño de la primera dimensión de A.
  • W (COMPLEX*16) - Un vector de trabajo.
  • RES (REAL*8) - La norma 1 de la matriz A.

EXAMPLE

Aquí hay un ejemplo de cómo usar ZLATM2:

PROGRAM EXAMPLE
IMPLICIT NONE
INTEGER, PARAMETER :: M = 5, N = 4, LDA = 5
COMPLEX*16 :: A(LDA, N)
REAL*8 :: RES
CHARACTER*1 :: ISEED(4) = (/ '1', '2', '3', '4' /)

CALL ZLATM2(ISEED, M, N, A, LDA, A, RES)

PRINT *, "Matrix A:"
CALL PRINT_MATRIX(A, M, N, LDA)
PRINT *, "Norm 1: ", RES

END PROGRAM EXAMPLE

SUBROUTINE PRINT_MATRIX(MATRIX, M, N, LDA)
IMPLICIT NONE
INTEGER M, N, LDA
COMPLEX*16 MATRIX(LDA, *)
INTEGER I, J

DO I = 1, M
    DO J = 1, N
        PRINT '(A, F10.5, A, F10.5, A)', "(", REAL(MATRIX(I, J)), ",", AIMAG(MATRIX(I, J)), ")"
    END DO
END DO
END SUBROUTINE PRINT_MATRIX
