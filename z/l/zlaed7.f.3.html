subroutine zlaed7 (integer n, integer cutpnt, integer qsiz, integer tlvls, integer curlvl, integer curpbm, double precision, dimension( * ) d, complex*16, dimension( ldq, * ) q, integer ldq, double precision rho, integer, dimension( * ) indxq, double precision, dimension( * ) qstore, integer, dimension( * ) qptr, integer, dimension( * ) prmptr, integer, dimension( * ) perm, integer, dimension( * ) givptr, integer, dimension( 2, * ) givcol, double precision, dimension( 2, * ) givnum, complex*16, dimension( * ) work, double precision, dimension( * ) rwork, integer, dimension( * ) iwork, integer info)

ZLAED7 utilizada por ZSTEDC. Calcula el sistema propio actualizado de una matriz diagonal después de la modificación por una matriz simétrica de rango uno. Se utiliza cuando la matriz original es densa.

Propósito:

!>
!> ZLAED7 calcula el sistema propio actualizado de una
!> matriz diagonal después de la modificación por una matriz simétrica de
!> rango uno. Esta
!> rutina se utiliza solo para el problema de eigenvalores que requiere todos
!> los eigenvalores y opcionalmente los eigenvectores de una matriz
!> Hermítica densa o de banda que ha sido reducida a forma tridiagonal.
!>
!>   T = Q(entrada) ( D(entrada) + RHO * Z*Z**H ) Q**H(entrada) = Q(salida) * D(salida) * Q**H(salida)
!>
!>   donde Z = Q**Hu, u es un vector de longitud N con unos en los
!>   elementos CUTPNT y CUTPNT + 1 y ceros en otros lugares.
!>
!>    Los eigenvectores de la matriz original están almacenados en Q, y los
!>    eigenvalores están en D. El algoritmo consta de tres etapas:
!>
!>       La primera etapa consiste en desinflar el tamaño del problema
!>       cuando hay eigenvalores múltiples o si hay un cero en
!>       el vector Z. Por cada ocurrencia de este tipo, la dimensión del
!>       problema de la ecuación secular se reduce en uno. Esta etapa
!>       se realiza mediante la rutina DLAED2.
!>
!>       La segunda etapa consiste en calcular los eigenvalores
!>       actualizados. Esto se hace encontrando las raíces de la ecuación
!>       secular a través de la rutina DLAED4 (llamada por SLAED3).
!>       Esta rutina también calcula los eigenvectores del problema
!>       actual.
!>
!>       La etapa final consiste en calcular directamente los eigenvectores
!>       actualizados utilizando los eigenvalores actualizados. Los
!>       eigenvectores del problema actual se multiplican con los
!>       eigenvectores del problema general.
!>

Parámetros

N 
!>          N es INTEGER
!>         La dimensión de la matriz tridiagonal simétrica.  N >= 0.
!>

CUTPNT

!>          CUTPNT es INTEGER
!>         Contiene la ubicación del último eigenvalor en la submatriz
!>         principal.  min(1,N) <= CUTPNT <= N.
!>

QSIZ

!>          QSIZ es INTEGER
!>         La dimensión de la matriz unitaria utilizada para reducir
!>         la matriz completa a forma tridiagonal.  QSIZ >= N.
!>

TLVLS

!>          TLVLS es INTEGER
!>         El número total de niveles de fusión en el árbol de
!>         divide y vencerás general.
!>

CURLVL

!>          CURLVL es INTEGER
!>         El nivel actual en la rutina de fusión general,
!>         0 <= curlvl <= tlvls.
!>

CURPBM

!>          CURPBM es INTEGER
!>         El problema actual en el nivel actual de la rutina de fusión
!>         general (contando de arriba a la izquierda a abajo a la derecha).
!>

D

!>          D es array DOUBLE PRECISION, dimension (N)
!>         En la entrada, los eigenvalores de la matriz perturbada de
!>         rango 1.
!>         En la salida, los eigenvalores de la matriz reparada.
!>

Q

!>          Q es array COMPLEX*16, dimension (LDQ,N)
!>         En la entrada, los eigenvectores de la matriz perturbada de
!>         rango 1.
!>         En la salida, los eigenvectores de la matriz tridiagonal
!>         reparada.
!>

LDQ

!>          LDQ es INTEGER
!>         La dimensión principal del array Q.  LDQ >= max(1,N).
!>

RHO

!>          RHO es DOUBLE PRECISION
!>         Contiene el subelemento diagonal utilizado para crear la
!>         modificación de rango 1.
!>

INDXQ

!>          INDXQ es array INTEGER, dimension (N)
!>         Contiene la permutación que reintegrará el subproblema recién
!>         resuelto en el orden correcto,
!>         es decir, D( INDXQ( I = 1, N ) ) estará en orden ascendente.
!>

IWORK

!>          IWORK es array INTEGER, dimension (4*N)
!>

RWORK

!>          RWORK es array DOUBLE PRECISION,
!>                                 dimension (3*N+2*QSIZ*N)
!>

WORK

!>          WORK es array COMPLEX*16, dimension (QSIZ*N)
!>

QSTORE

!>          QSTORE es array DOUBLE PRECISION, dimension (N**2+1)
!>         Almacena los eigenvectores de las submatrices encontradas
!>         durante el divide y vencerás, empaquetados juntos. QPTR apunta
!>         al principio de las submatrices.
!>

QPTR

!>          QPTR es array INTEGER, dimension (N+2)
!>         Lista de índices que apuntan al principio de las submatrices
!>         almacenadas en QSTORE. Las submatrices se numeran comenzando
!>         desde la parte inferior izquierda del árbol de divide y vencerás,
!>         de izquierda a derecha y de abajo hacia arriba.
!>

PRMPTR

!>          PRMPTR es array INTEGER, dimension (N lg N)
!>         Contiene una lista de punteros que indican dónde en PERM se
!>         almacena la permutación de un nivel. PRMPTR(i+1) - PRMPTR(i)
!>         indica el tamaño de la permutación y también el tamaño del
!>         problema completo, no desinflado.
!>

PERM

!>          PERM es array INTEGER, dimension (N lg N)
!>         Contiene las permutaciones (de la desinflación y ordenamiento)
!>         que se aplicarán a cada bloque de eigenvalores.
!>

GIVPTR

!>          GIVPTR es array INTEGER, dimension (N lg N)
!>         Contiene una lista de punteros que indican dónde en GIVCOL se
!>         almacenan las rotaciones de Givens de un nivel. GIVPTR(i+1) -
!>         GIVPTR(i) indica el número de rotaciones de Givens.
!>

GIVCOL

!>          GIVCOL es array INTEGER, dimension (2, N lg N)
!>         Cada par de números indica un par de columnas para realizar
!>         una rotación de Givens.
!>

GIVNUM

!>          GIVNUM es array DOUBLE PRECISION, dimension (2, N lg N)
!>         Cada número indica el valor S que se utilizará en la rotación
!>         de Givens correspondiente.
!>

INFO

!>          INFO es INTEGER
!>          = 0:  salida exitosa.
!>          < 0:  si INFO = -i, el i-ésimo argumento tenía un valor ilegal.
!>          > 0:  si INFO = 1, un eigenvalor no convergió
!>
