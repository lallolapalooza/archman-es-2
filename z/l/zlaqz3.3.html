ZLAQZ3

Propósito:

!>
!> ZLAQZ3 Ejecuta una única barrida QZ multienlace
!>

Parámetros

ILSCHUR 
!>          ILSCHUR es LOGICO
!>              Determina si se actualiza o no la forma de Schur completa
!>

ILQ

!>          ILQ es LOGICO
!>              Determina si se actualiza o no la matriz Q
!>

ILZ

!>          ILZ es LOGICO
!>              Determina si se actualiza o no la matriz Z
!>

N

!>          N es ENTERO
!>          El orden de las matrices A, B, Q y Z.  N >= 0.
!>

ILO

!>          ILO es ENTERO
!>

IHI

!>          IHI es ENTERO
!>

NSHIFTS

!>          NSHIFTS es ENTERO
!>          El número deseado de desplazamientos a utilizar
!>

NBLOCK_DESIRED

!>          NBLOCK_DESIRED es ENTERO
!>          El tamaño deseado de las ventanas computacionales
!>

ALPHA

!>          ALPHA es un array COMPLEX*16. SR contiene
!>          las partes alfa de los desplazamientos a utilizar.
!>

BETA

!>          BETA es un array COMPLEX*16. SS contiene
!>          la escala de los desplazamientos a utilizar.
!>

A

!>          A es un array COMPLEX*16, dimensión (LDA, N)
!>

LDA

!>          LDA es ENTERO
!>          La dimensión principal del array A.  LDA >= max( 1, N ).
!>

B

!>          B es un array COMPLEX*16, dimensión (LDB, N)
!>

LDB

!>          LDB es ENTERO
!>          La dimensión principal del array B.  LDB >= max( 1, N ).
!>

Q

!>          Q es un array COMPLEX*16, dimensión (LDQ, N)
!>

LDQ

!>          LDQ es ENTERO
!>

Z

!>          Z es un array COMPLEX*16, dimensión (LDZ, N)
!>

LDZ

!>          LDZ es ENTERO
!>

QC

!>          QC es un array COMPLEX*16, dimensión (LDQC, NBLOCK_DESIRED)
!>

LDQC

!>          LDQC es ENTERO
!>

ZC

!>          ZC es un array COMPLEX*16, dimensión (LDZC, NBLOCK_DESIRED)
!>

LDZC

!>          LDZ es ENTERO
!>

WORK

!>          WORK es un array COMPLEX*16, dimensión (MAX(1,LWORK))
!>          A la salida, si INFO >= 0, WORK(1) devuelve el LWORK óptimo.
!>

LWORK

!>          LWORK es ENTERO
!>          La dimensión del array WORK.  LWORK >= max(1,N).
!>
!>          Si LWORK = -1, se asume una consulta de espacio de trabajo; la rutina
!>          solo calcula el tamaño óptimo del array WORK, devuelve
!>          este valor como la primera entrada del array WORK, y XERBLA no emite ningún
!>          mensaje de error relacionado con LWORK.
!>

INFO

!>          INFO es ENTERO
!>          = 0: salida exitosa
!>          < 0: si INFO = -i, el i-ésimo argumento tenía un valor ilegal
!>
