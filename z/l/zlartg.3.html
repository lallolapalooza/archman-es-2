Documentación de función/subrutina

subrutina zlartg (complex(wp) f, complex(wp) g, real(wp) c, complex(wp) s, complex(wp) r)

ZLARTG genera una rotación de plano con coseno real y seno complejo.

Propósito:

!>
!> ZLARTG genera una rotación de plano tal que
!>
!>    [  C         S  ] . [ F ]  =  [ R ]
!>    [ -conjg(S)  C  ]   [ G ]     [ 0 ]
!>
!> donde C es real y C**2 + |S|**2 = 1.
!>
!> Las fórmulas matemáticas utilizadas para C y S son
!>
!>    sgn(x) = {  x / |x|,   x != 0
!>             {  1,         x  = 0
!>
!>    R = sgn(F) * sqrt(|F|**2 + |G|**2)
!>
!>    C = |F| / sqrt(|F|**2 + |G|**2)
!>
!>    S = sgn(F) * conjg(G) / sqrt(|F|**2 + |G|**2)
!>
!> Condiciones especiales:
!>    Si G=0, entonces C=1 y S=0.
!>    Si F=0, entonces C=0 y S se elige de tal manera que R sea real.
!>
!> Cuando F y G son reales, las fórmulas se simplifican a C = F/R y
!> S = G/R, y los valores devueltos de C, S y R deberían ser
!> idénticos a los devueltos por DLARTG.
!>
!> El algoritmo utilizado para calcular estas cantidades incorpora escalado
!> para evitar desbordamiento o subdesbordamiento al calcular la raíz cuadrada de la
!> suma de cuadrados.
!>
!> Esta es la misma rutina ZROTG de BLAS1, excepto que
!> F y G no se modifican al regresar.
!>
!> Abajo, wp=>dp significa precisión doble del módulo LA_CONSTANTS.
!>

Parámetros

F 
!>          F es COMPLEX(wp)
!>          El primer componente del vector a rotar.
!>

G

!>          G es COMPLEX(wp)
!>          El segundo componente del vector a rotar.
!>

C

!>          C es REAL(wp)
!>          El coseno de la rotación.
!>

S

!>          S es COMPLEX(wp)
!>          El seno de la rotación.
!>

R

!>          R es COMPLEX(wp)
!>          El componente distinto de cero del vector rotado.
!>
