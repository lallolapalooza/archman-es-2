función de doble precisión zlanhf (norma, transr, uplo, n, a, trabajo)


ZLANHF devuelve el valor de la norma 1, o la norma de Frobenius, o la norma infinito, o el elemento de mayor valor absoluto de una matriz Hermítica en formato RFP.

DOCUMENTACIÓN DE FUNCIÓN/SUBRUTINA

función de doble precisión zlanhf (carácter norma, carácter transr, carácter uplo, entero n, complejo*16, dimensión( 0: * ) a, doble precisión, dimensión( 0: * ) trabajo)

ZLANHF devuelve el valor de la norma 1, o la norma de Frobenius, o la norma infinito, o el elemento de mayor valor absoluto de una matriz Hermítica en formato RFP.

Propósito:

!>
!> ZLANHF  devuelve el valor de la norma uno,  o la norma de Frobenius, o
!> la  norma  infinito,  o el  elemento de  mayor valor absoluto  de una
!> matriz Hermítica compleja A en formato RFP.
!>

Devuelve

ZLANHF 
!>
!>    ZLANHF = ( max(abs(A(i,j))), NORMA = 'M' o 'm'
!>             (
!>             ( norma1(A),         NORMA = '1', 'O' o 'o'
!>             (
!>             ( normaI(A),         NORMA = 'I' o 'i'
!>             (
!>             ( normaF(A),         NORMA = 'F', 'f', 'E' o 'e'
!>
!> donde  norma1  denota la  norma uno de una matriz (suma máxima de columnas),
!> normaI  denota la  norma  infinito  de una matriz  (suma máxima de filas) y
!> normaF  denota la  norma  de Frobenius de una matriz (raíz cuadrada de la suma de
!> cuadrados).  Nótese que  max(abs(A(i,j)))  no es una  norma matricial.
!>

Parámetros

NORMA 
!>          NORMA es CARACTER
!>            Especifica el valor que se devolverá en ZLANHF tal como se describe
!>            arriba.
!>

TRANSR

!>          TRANSR es CARACTER
!>            Especifica si el formato RFP de A es normal o
!>            conjugado-transpuesto.
!>            = 'N':  El formato RFP es Normal
!>            = 'C':  El formato RFP es Conjugado-transpuesto
!>

UPLO

!>          UPLO es CARACTER
!>            En la entrada, UPLO especifica si la matriz A de RFP provino
!>            de una matriz triangular superior o inferior, como se indica a
!>            continuación:
!>
!>            UPLO = 'U' o 'u' RFP A provino de una matriz triangular
!>            superior
!>
!>            UPLO = 'L' o 'l' RFP A provino de una matriz triangular
!>            inferior
!>

N

!>          N es ENTERO
!>            El orden de la matriz A.  N >= 0.  Cuando N = 0, ZLANHF se
!>            establece a cero.
!>

A

!>          A es un array de COMPLEX*16, dimensión ( N*(N+1)/2 );
!>            En la entrada, la matriz A en formato RFP.
!>            El formato RFP se describe mediante TRANSR, UPLO y N como sigue:
!>            Si TRANSR='N' entonces RFP A es (0:N,0:K-1) cuando N es par;
!>            K=N/2. RFP A es (0:N-1,0:K) cuando N es impar; K=N/2. Si
!>            TRANSR = 'C' entonces RFP es la traspuesta conjugada de RFP A
!>            tal como se define cuando TRANSR = 'N'. El contenido de RFP A se
!>            define mediante UPLO como sigue: Si UPLO = 'U' la RFP A
!>            contiene los elementos de A superior empaquetada ( N*(N+1)/2 )
!>            ya sea en formato normal o conjugado-transpuesto. Si
!>            UPLO = 'L' la RFP A contiene los elementos de A inferior empaquetada
!>            ( N*(N+1) /2 ) ya sea en formato normal o conjugado-transpuesto.
!>            El LDA de RFP A es (N+1)/2 cuando TRANSR = 'C'. Cuando
!>            TRANSR es 'N', el LDA es N+1 cuando N es par y es N cuando
!>            es impar. Consulte la Nota a continuación para más detalles.
!>            No cambia en la salida.
!>

TRABAJO

!>          TRABAJO es un array de DOBLE PRECISIÓN, dimensión (LWORK),
!>            donde LWORK >= N cuando NORMA = 'I' o '1' o 'O'; de lo contrario,
!>            TRABAJO no se referencia.
!>

!>
!>  Primero consideramos el formato empaquetado estándar cuando N es par.
!>  Damos un ejemplo donde N = 6.
!>
!>      AP es Superior             AP es Inferior
!>
!>   00 01 02 03 04 05       00
!>      11 12 13 14 15       10 11
!>         22 23 24 25       20 21 22
!>            33 34 35       30 31 32 33
!>               44 45       40 41 42 43 44
!>                  55       50 51 52 53 54 55
!>

!>  Sea TRANSR = 'N'. RFP contiene AP como sigue:
!>  Para UPLO = 'U', el trapecio superior A(0:5,0:2) consiste en las últimas
!>  tres columnas de AP superior. El triángulo inferior A(4:6,0:2) consiste en
!>  la traspuesta conjugada de las primeras tres columnas de AP superior.
!>  Para UPLO = 'L', el trapecio inferior A(1:6,0:2) consiste en las primeras
!>  tres columnas de AP inferior. El triángulo superior A(0:2,0:2) consiste en
!>  la traspuesta conjugada de las últimas tres columnas de AP inferior.
!>  Para denotar conjugado, colocamos -- encima del elemento. Esto cubre el
!>  caso N par y TRANSR = 'N'.
!>
!>         RFP A                   RFP A
!>
!>                                -- -- --
!>        03 04 05                33 43 53
!>                                   -- --
!>        13 14 15                00 44 54
!>                                      --
!>        23 24 25                10 11 55
!>
!>        33 34 35                20 21 22
!>        --
!>        00 44 45                30 31 32
!>        -- --
!>        01 11 55                40 41 42
!>        -- -- --
!>        02 12 22                50 51 52
!>
!>  Ahora sea TRANSR = 'C'. RFP A en ambos casos UPLO es solo la traspuesta
!>  conjugada de RFP A anterior. Por lo tanto, obtenemos:
!>
!>
!>           RFP A                   RFP A
!>
!>     -- -- -- --                -- -- -- -- -- --
!>     03 13 23 33 00 01 02    33 00 10 20 30 40 50
!>     -- -- -- -- --                -- -- -- -- --
!>     04 14 24 34 44 11 12    43 44 11 21 31 41 51
!>     -- -- -- -- -- --                -- -- -- --
!>     05 15 25 35 45 55 22    53 54 55 22 32 42 52
!>
!>
!>  A continuación, consideramos el formato empaquetado estándar cuando N es impar.
!>  Damos un ejemplo donde N = 5.
!>
!>     AP es Superior              AP es Inferior
!>
!>   00 01 02 03 04              00
!>      11 12 13 14              10 11
!>         22 23 24              20 21 22
!>            33 34              30 31 32 33
!>               44              40 41 42 43 44
!>
!>
!>  Sea TRANSR = 'N'. RFP contiene AP como sigue:
!>  Para UPLO = 'U', el trapecio superior A(0:4,0:2) consiste en las últimas
!>  tres columnas de AP superior. El triángulo inferior A(3:4,0:1) consiste en
!>  la traspuesta conjugada de las dos primeras columnas de AP superior.
!>  Para UPLO = 'L', el trapecio inferior A(0:4,0:2) consiste en las primeras
!>  tres columnas de AP inferior. El triángulo superior A(0:1,1:2) consiste en
!>  la traspuesta conjugada de las dos últimas columnas de AP inferior.
!>  Para denotar conjugado, colocamos -- encima del elemento. Esto cubre el
!>  caso N impar y TRANSR = 'N'.
!>
!>         RFP A                   RFP A
!>
!>                                   -- --
!>        02 03 04                00 33 43
!>                                      --
!>        12 13 14                10 11 44
!>
!>        22 23 24                20 21 22
!>        --
!>        00 33 34                30 31 32
!>        -- --
!>        01 11 44                40 41 42
!>
!>  Ahora sea TRANSR = 'C'. RFP A en ambos casos UPLO es solo la traspuesta

NAME

zlanhf — zlanhf computes the value of the one norm, the Frobenius norm, or the infinity norm for an upper triangular matrix.

SYNOPSIS

DOUBLE PRECISION FUNCTION ZLANHF(NORM, UPLO, N, A, LDA, WORK)

INTEGER N

INTEGER LDA

DOUBLE PRECISION WORK(N)

CHARACTER UPLO

CHARACTER NORM

Description

This subroutine is intended to be called by the user only. The call is useful if the user wants to compute its norm without having to return an error flag.

Arguments

NORM
CHARACTER*1.

Specifies the value to be returned:

= 'O' or 'o'   Compute the one norm: max(Re(sum(A))),
              beta*max(abs(A(i,i))), 1/min(Re(sum(A)))
= 'I' or 'i'   Compute the infinity norm: max(sum(abs(A)))
= 'F' or 'f'   Compute the Frobenius norm: sqrt(sum(abs(A)**2))
UPLO
CHARACTER*1.

Specifies whether the matrix A is upper or lower triangular:

= 'U' or 'u'   A is upper triangular
= 'L' or 'l'   A is lower triangular
N
INTEGER.

The order of the matrix A. N >= 0.

A
DOUBLE COMPLEX array, dimension (LDA, N).

The upper or lower triangular matrix A.

LDA
INTEGER.

The leading dimension of the array A. LDA >= max(1, N).

WORK
DOUBLE PRECISION array, dimension (N).

Workspace. If NORM = 'I' or '1', WORK is not used.

Return Value

zlanhf double precision. The value of the one norm, the Frobenius norm, or the infinity norm, or 0 if N = 0.

Author

Univ. of Tennessee. Univ. of California Berkeley. Univ. of Colorado Denver. Courant Institute.

Date: September 2023

    SUBROUTINE ZLANHF( NORM, UPLO, N, A, LDA, WORK )

    IMPLICIT NONE

    INTEGER :: N

    INTEGER :: LDA

    DOUBLE PRECISION :: WORK(N)

    CHARACTER :: NORM, UPLO

    DOUBLE COMPLEX :: A(LDA,N)

    ! Local variables

    INTEGER :: I, J

    DOUBLE PRECISION :: SUM, TEMP

    DOUBLE COMPLEX :: DIAG, SUMC

    DOUBLE PRECISION :: ANRM

    ! Statement functions

    ANRM(Z) = MAX(DBLE(Z), DBLE(Z))

    ! Quick return if possible

    IF (N .EQ. 0) THEN

      ZLANHF = 0.0D0

      RETURN

    END IF

    IF (NORM .EQ. 'O' .OR. NORM .EQ. 'o') THEN

      IF (UPLO .EQ. 'U' .OR. UPLO .EQ. 'u') THEN

        ANRM = 0.0D0

        DO J = 1, N

          SUMC = (0.0D0, 0.0D0)

          DO I = 1, J

            SUMC = SUMC + A(I,J)

          END DO

          WORK(J) = ABS(SUMC)

        END DO

        ANRM = MAX(ANRM, MAX(WORK(1:N)))

      ELSE IF (UPLO .EQ. 'L' .OR. UPLO .EQ. 'l') THEN

        ANRM = 0.0D0

        DO J = 1, N

          SUMC = (0.0D0, 0.0D0)

          DO I = J, N

            SUMC = SUMC + A(I,J)

          END DO

          WORK(J) = ABS(SUMC)

        END DO

        ANRM = MAX(ANRM, MAX(WORK(1:N)))

      END IF

    ELSE IF (NORM .EQ. 'I' .OR. NORM .EQ. 'i') THEN

      IF (UPLO .EQ. 'U' .OR. UPLO .EQ. 'u') THEN

        ANRM = 0.0D0

        DO J = 1, N

          SUM = 0.0D0

          DO I = 1, J

            SUM = SUM + ABS(A(I,J))

          END DO

          ANRM = MAX(ANRM, SUM)

        END DO

      ELSE IF (UPLO .EQ. 'L' .OR. UPLO .EQ. 'l') THEN

        ANRM = 0.0D0

        DO J = 1, N

          SUM = 0.0D0

          DO I = J, N

            SUM = SUM + ABS(A(I,J))

          END DO

          ANRM = MAX(ANRM, SUM)

        END DO

      END IF

    ELSE IF (NORM .EQ. 'F' .OR. NORM .EQ. 'f') THEN

      ANRM = 0.0D0

      IF (UPLO .EQ. 'U' .OR. UPLO .EQ. 'u') THEN

        DO J = 1, N

          DO I = 1, J

            TEMP = DBLE(A(I,J))**2 + DVIDBLE(A(I,J))**2

            ANRM = ANRM + TEMP

          END DO

        END DO

      ELSE IF (UPLO .EQ. 'L' .OR. UPLO .EQ. 'l') THEN

        DO J = 1, N

          DO I = J, N

            TEMP = DBLE(A(I,J))**2 + DVIDBLE(A(I,J))**2

            ANRM = ANRM + TEMP

          END DO

        END DO

      END IF

      ANRM = SQRT(ANRM)

    END IF

    ZLANHF = ANRM

    END FUNCTION ZLANHF
