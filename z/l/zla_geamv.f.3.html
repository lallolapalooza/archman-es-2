subrutina zla_geamv (trans, m, n, alpha, a, lda, x, incx, beta, y, incy)
ZLA_GEAMV calcula el producto de una matriz por un vector utilizando una matriz general para calcular límites de error.

Documentación de la Función/Subrutina

subrutina zla_geamv (integer trans, integer m, integer n, double precision alpha, complex*16, dimension( lda, * ) a, integer lda, complex*16, dimension( * ) x, integer incx, double precision beta, double precision, dimension( * ) y, integer incy)

ZLA_GEAMV calcula el producto de una matriz por un vector utilizando una matriz general para calcular límites de error.

Propósito:

!>
!> ZLA_GEAMV realiza una de las operaciones de matriz-vector
!>
!>         y := alpha*abs(A)*abs(x) + beta*abs(y),
!>    o    y := alpha*abs(A)**T*abs(x) + beta*abs(y),
!>
!> donde alpha y beta son escalares, x e y son vectores y A es una
!> matriz de m por n.
!>
!> Esta función se utiliza principalmente para calcular límites de error.
!> Para proteger contra el subdesbordamiento durante la evaluación, los
!> componentes del vector resultante se perturban alejándose de cero en
!> (N+1) veces el umbral de subdesbordamiento. Para evitar errores
!> innecesariamente grandes para la estructura de bloques incrustada en
!> matrices generales, los componentes cero no se perturban. Una entrada
!> cero se considera si todas las multiplicaciones involucradas en el
!> cálculo de esa entrada tienen al menos un multiplicando cero.
!>

Parámetros

TRANS 
!>          TRANS es INTEGER
!>           En la entrada, TRANS especifica la operación a realizar como
!>           sigue:
!>
!>             BLAS_NO_TRANS      y := alpha*abs(A)*abs(x) + beta*abs(y)
!>             BLAS_TRANS         y := alpha*abs(A**T)*abs(x) + beta*abs(y)
!>             BLAS_CONJ_TRANS    y := alpha*abs(A**T)*abs(x) + beta*abs(y)
!>
!>           Sin cambios en la salida.
!>

M

!>          M es INTEGER
!>           En la entrada, M especifica el número de filas de la matriz A.
!>           M debe ser al menos cero.
!>           Sin cambios en la salida.
!>

N

!>          N es INTEGER
!>           En la entrada, N especifica el número de columnas de la matriz A.
!>           N debe ser al menos cero.
!>           Sin cambios en la salida.
!>

ALPHA

!>          ALPHA es DOUBLE PRECISION
!>           En la entrada, ALPHA especifica el escalar alpha.
!>           Sin cambios en la salida.
!>

A

!>          A es un array COMPLEX*16, de dimensión ( LDA, n )
!>           Antes de la entrada, la parte principal de m por n del array A
!>           debe contener la matriz de coeficientes.
!>           Sin cambios en la salida.
!>

LDA

!>          LDA es INTEGER
!>           En la entrada, LDA especifica la primera dimensión de A tal
!>           como se declara en el programa (sub)llamador. LDA debe ser
!>           al menos max( 1, m ).
!>           Sin cambios en la salida.
!>

X

!>          X es un array COMPLEX*16, de dimensión al menos
!>           ( 1 + ( n - 1 )*abs( INCX ) ) cuando TRANS = 'N' o 'n'
!>           y al menos
!>           ( 1 + ( m - 1 )*abs( INCX ) ) en caso contrario.
!>           Antes de la entrada, el array X incrementado debe contener el
!>           vector x.
!>           Sin cambios en la salida.
!>

INCX

!>          INCX es INTEGER
!>           En la entrada, INCX especifica el incremento para los elementos
!>           de X. INCX no debe ser cero.
!>           Sin cambios en la salida.
!>

BETA

!>          BETA es DOUBLE PRECISION
!>           En la entrada, BETA especifica el escalar beta. Cuando BETA se
!>           suministra como cero, entonces Y no necesita establecerse en
!>           la entrada.
!>           Sin cambios en la salida.
!>

Y

!>          Y es un array DOUBLE PRECISION, de dimensión
!>           ( 1 + ( m - 1 )*abs( INCY ) ) cuando TRANS = 'N' o 'n'
!>           y al menos
!>           ( 1 + ( n - 1 )*abs( INCY ) ) en caso contrario.
!>           Antes de la entrada con BETA no cero, el array Y incrementado
!>           debe contener el vector y. En la salida, Y se sobrescribe con
!>           el vector y actualizado.
!>           Si m o n es cero, entonces Y no se referencia y la función
!>           realiza un retorno rápido.
!>

INCY

!>          INCY es INTEGER
!>           En la entrada, INCY especifica el incremento para los elementos
!>           de Y. INCY no debe ser cero.
!>           Sin cambios en la salida.
!>
!>  Rutina Blas de nivel 2.
!>
