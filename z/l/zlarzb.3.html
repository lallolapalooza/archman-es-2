subrutina zlarzb (side, trans, direct, storev, m, n, k, l, v, ldv, t, ldt, c, ldc, work, ldwork)

ZLARZB aplica un reflector de bloque o su transpuesta conjugada a una matriz general.

Documentación de Función/Subrutina

subrutina zlarzb (character side, character trans, character direct, character storev, integer m, integer n, integer k, integer l, complex*16, dimension( ldv, * ) v, integer ldv, complex*16, dimension( ldt, * ) t, integer ldt, complex*16, dimension( ldc, * ) c, integer ldc, complex*16, dimension( ldwork, * ) work, integer ldwork)

ZLARZB aplica un reflector de bloque complejo H o su transpuesta conjugada H**H a una matriz C compleja distribuida M por N, desde la izquierda o la derecha.

Propósito:

!>
!> ZLARZB aplica un reflector de bloque complejo H o su transpuesta H**H
!> a una matriz C compleja distribuida M por N desde la izquierda o la derecha.
!>
!> Actualmente, solo se admiten STOREV = 'R' y DIRECT = 'B'.
!>

Parámetros

SIDE 
!>          SIDE es CHARACTER*1
!>          = 'L': aplicar H o H**H desde la Izquierda
!>          = 'R': aplicar H o H**H desde la Derecha
!>

TRANS

!>          TRANS es CHARACTER*1
!>          = 'N': aplicar H (Sin transponer)
!>          = 'C': aplicar H**H (Transpuesta conjugada)
!>

DIRECT

!>          DIRECT es CHARACTER*1
!>          Indica cómo se forma H a partir de un producto de
!>          reflectores elementales
!>          = 'F': H = H(1) H(2) . . . H(k) (Hacia adelante, todavía no soportado)
!>          = 'B': H = H(k) . . . H(2) H(1) (Hacia atrás)
!>

STOREV

!>          STOREV es CHARACTER*1
!>          Indica cómo se almacenan los vectores que definen los
!>          reflectores elementales:
!>          = 'C': Por columnas (todavía no soportado)
!>          = 'R': Por filas
!>

M

!>          M es INTEGER
!>          El número de filas de la matriz C.
!>

N

!>          N es INTEGER
!>          El número de columnas de la matriz C.
!>

K

!>          K es INTEGER
!>          El orden de la matriz T (= el número de reflectores
!>          elementales cuyo producto define el reflector de bloque).
!>

L

!>          L es INTEGER
!>          El número de columnas de la matriz V que contienen la parte
!>          significativa de los reflectores de Householder.
!>          Si SIDE = 'L', M >= L >= 0, si SIDE = 'R', N >= L >= 0.
!>

V

!>          V es un array COMPLEX*16, dimension (LDV,NV).
!>          Si STOREV = 'C', NV = K; si STOREV = 'R', NV = L.
!>

LDV

!>          LDV es INTEGER
!>          La dimensión principal del array V.
!>          Si STOREV = 'C', LDV >= L; si STOREV = 'R', LDV >= K.
!>

T

!>          T es un array COMPLEX*16, dimension (LDT,K)
!>          La matriz triangular K por K, T, en la representación del
!>          reflector de bloque.
!>

LDT

!>          LDT es INTEGER
!>          La dimensión principal del array T. LDT >= K.
!>

C

!>          C es un array COMPLEX*16, dimension (LDC,N)
!>          En la entrada, la matriz C de M por N.
!>          En la salida, C se sobrescribe con H*C o H**H*C o C*H o C*H**H.
!>

LDC

!>          LDC es INTEGER
!>          La dimensión principal del array C. LDC >= max(1,M).
!>

WORK

!>          WORK es un array COMPLEX*16, dimension (LDWORK,K)
!>

LDWORK

!>          LDWORK es INTEGER
!>          La dimensión principal del array WORK.
!>          Si SIDE = 'L', LDWORK >= max(1,N);
!>          si SIDE = 'R', LDWORK >= max(1,M).
!>
