Documentación de función/subrutina

función de doble precisión zla_herpvgrw (character*1 uplo, integer n, integer info, complex*16, dimension( lda, * ) a, integer lda, complex*16, dimension( ldaf, * ) af, integer ldaf, integer, dimension( * ) ipiv, double precision, dimension( * ) work)

ZLA_HERPVGRW

Propósito:

!>
!>
!> ZLA_HERPVGRW calcula el factor de crecimiento del pivote recíproco
!> norm(A)/norm(U). Se utiliza la norma . Si esto es
!> mucho menor que 1, la estabilidad de la factorización LU de la
!> matriz (equilibrada) A podría ser pobre. Esto también significa que la
!> solución X, los números de condición estimados y los límites de error podrían ser
!> poco fiables.
!>

Parámetros

UPLO 
!>          UPLO es CHARACTER*1
!>       = 'U':  El triángulo superior de A está almacenado;
!>       = 'L':  El triángulo inferior de A está almacenado.
!>

N

!>          N es INTEGER
!>     El número de ecuaciones lineales, es decir, el orden de la
!>     matriz A.  N >= 0.
!>

INFO

!>          INFO es INTEGER
!>     El valor de INFO devuelto por ZHETRF, .i.e., el pivote en
!>     la columna INFO es exactamente 0.
!>

A

!>          A es un array COMPLEX*16, dimensión (LDA,N)
!>     En la entrada, la matriz A de N por N.
!>

LDA

!>          LDA es INTEGER
!>     La dimensión principal del array A.  LDA >= max(1,N).
!>

AF

!>          AF es un array COMPLEX*16, dimensión (LDAF,N)
!>     La matriz de bloques diagonales D y los multiplicadores utilizados para
!>     obtener el factor U o L tal como lo calcula ZHETRF.
!>

LDAF

!>          LDAF es INTEGER
!>     La dimensión principal del array AF.  LDAF >= max(1,N).
!>

IPIV

!>          IPIV es un array INTEGER, dimensión (N)
!>     Detalles de los intercambios y la estructura de bloques de D
!>     tal como lo determina ZHETRF.
!>

WORK

!>          WORK es un array DOUBLE PRECISION, dimensión (2*N)
!>
