subrutina zlaqr2 (logical wantt, logical wantz, integer n, integer ktop, integer kbot, integer nw, complex*16, dimension( ldh, * ) h, integer ldh, integer iloz, integer ihiz, complex*16, dimension( ldz, * ) z, integer ldz, integer ns, integer nd, complex*16, dimension( * ) sh, complex*16, dimension( ldv, * ) v, integer ldv, integer nh, complex*16, dimension( ldt, * ) t, integer ldt, integer nv, complex*16, dimension( ldwv, * ) wv, integer ldwv, complex*16, dimension( * ) work, integer lwork)

ZLAQR2 realiza la transformación de similitud unitaria de una matriz de Hessenberg para detectar y descargar completamente los valores propios convergidos de una submatriz principal de cola (descarga temprana agresiva).

Propósito:

!>
!>    ZLAQR2 es idéntica a ZLAQR3 excepto que evita
!>    la recursión llamando a ZLAHQR en lugar de ZLAQR4.
!>
!>    Descarga temprana agresiva:
!>
!>    ZLAQR2 acepta como entrada una matriz de Hessenberg superior
!>    H y realiza una transformación de similitud unitaria
!>    diseñada para detectar y descargar los valores propios completamente
!>    convergidos de una submatriz principal de cola. En la salida, H ha sido
!>    sobrescrita por una nueva matriz de Hessenberg que es una perturbación de
!>    una transformación de similitud unitaria de H. Se espera
!>    que la versión final de H tenga muchas entradas subdiagonales cero.
!>
!>

Parámetros

WANTT 
!>          WANTT es LOGICAL
!>          Si .TRUE., entonces la matriz de Hessenberg H se actualiza completamente
!>          para que el factor triangular de Schur pueda ser
!>          calculado (en cooperación con la subrutina que llama).
!>          Si .FALSE., entonces solo se actualiza suficiente de H para preservar
!>          los valores propios.
!>

WANTZ

!>          WANTZ es LOGICAL
!>          Si .TRUE., entonces la matriz unitaria Z se actualiza
!>          para que el factor de Schur unitario pueda ser calculado
!>          (en cooperación con la subrutina que llama).
!>          Si .FALSE., entonces Z no se referencia.
!>

N

!>          N es INTEGER
!>          El orden de la matriz H y (si WANTZ es .TRUE.) el
!>          orden de la matriz unitaria Z.
!>

KTOP

!>          KTOP es INTEGER
!>          Se asume que KTOP = 1 o H(KTOP,KTOP-1)=0.
!>          KBOT y KTOP juntos determinan un bloque aislado
!>          a lo largo de la diagonal de la matriz de Hessenberg.
!>

KBOT

!>          KBOT es INTEGER
!>          Se asume sin verificación que KBOT = N o H(KBOT+1,KBOT)=0.
!>          KBOT y KTOP juntos determinan un bloque aislado a lo largo de la
!>          diagonal de la matriz de Hessenberg.
!>

NW

!>          NW es INTEGER
!>          Tamaño de la ventana de descarga. 1 <= NW <= (KBOT-KTOP+1).
!>

H

!>          H es array COMPLEX*16, dimension (LDH,N)
!>          En la entrada, la sección N por N inicial de H almacena la
!>          matriz de Hessenberg que se somete a descarga temprana agresiva.
!>          En la salida, H ha sido transformada por una similitud unitaria
!>          transformación, perturbada y devuelta
!>          a la forma de Hessenberg que (se espera) tiene algunas
!>          entradas subdiagonales cero.
!>

LDH

!>          LDH es INTEGER
!>          Dimensión principal de H tal como se declara en la subrutina
!>          llamadora. N <= LDH
!>

ILOZ

!>          ILOZ es INTEGER
!>

IHIZ

!>          IHIZ es INTEGER
!>          Especifica las filas de Z a las que se deben aplicar las
!>          transformaciones si WANTZ es .TRUE.. 1 <= ILOZ <= IHIZ <= N.
!>

Z

!>          Z es array COMPLEX*16, dimension (LDZ,N)
!>          Si WANTZ es .TRUE., entonces en la salida, la similitud unitaria
!>          transformación mencionada anteriormente ha sido
!>          acumulada en Z(ILOZ:IHIZ,ILOZ:IHIZ) desde la derecha.
!>          Si WANTZ es .FALSE., entonces Z no se referencia.
!>

LDZ

!>          LDZ es INTEGER
!>          La dimensión principal de Z tal como se declara en la
!>          subrutina llamadora. 1 <= LDZ.
!>

NS

!>          NS es INTEGER
!>          El número de valores propios no convergidos (es decir, aproximados)
!>          devueltos en SR y SI que pueden ser usados como desplazamientos por
!>          la subrutina que llama.
!>

ND

!>          ND es INTEGER
!>          El número de valores propios convergidos descubiertos por esta
!>          subrutina.
!>

SH

!>          SH es array COMPLEX*16, dimension (KBOT)
!>          En la salida, los valores propios aproximados que pueden
!>          ser usados para desplazamientos se almacenan en SH(KBOT-ND-NS+1)
!>          hasta SR(KBOT-ND). Los valores propios convergidos se
!>          almacenan en SH(KBOT-ND+1) hasta SH(KBOT).
!>

V

!>          V es array COMPLEX*16, dimension (LDV,NW)
!>          Un array de trabajo NW por NW.
!>

LDV

!>          LDV es INTEGER
!>          La dimensión principal de V tal como se declara en la
!>          subrutina llamadora. NW <= LDV
!>

NH

!>          NH es INTEGER
!>          El número de columnas de T. NH >= NW.
!>

T

!>          T es array COMPLEX*16, dimension (LDT,NW)
!>

LDT

!>          LDT es INTEGER
!>          La dimensión principal de T tal como se declara en la
!>          subrutina llamadora. NW <= LDT
!>

NV

!>          NV es INTEGER
!>          El número de filas del array de trabajo WV disponibles para
!>          espacio de trabajo. NV >= NW.
!>

WV

!>          WV es array COMPLEX*16, dimension (LDWV,NW)
!>

LDWV

!>          LDWV es INTEGER
!>          La dimensión principal de W tal como se declara en la
!>          subrutina llamadora. NW <= LDV
!>

WORK

!>          WORK es array COMPLEX*16, dimension (LWORK)
!>          En la salida, WORK(1) se establece en una estimación del valor
!>          óptimo de LWORK para los valores dados de N, NW, KTOP y KBOT.
!>

LWORK

!>          LWORK es INTEGER
!>          La dimensión del array de trabajo WORK. LWORK = 2*NW
!>          es suficiente, pero una mayor eficiencia puede resultar de valores
!>          mayores de LWORK.
!>
!>          Si LWORK = -1, entonces se asume una consulta de espacio de trabajo; ZLAQR2
!>          solo estima el tamaño óptimo del espacio de trabajo para los valores
!>          dados de N, NW, KTOP y KBOT. La estimación se devuelve
!>          en WORK(1). Ningún mensaje de error relacionado con LWORK es emitido
!>          por XERBLA. Ni H ni Z son accedidos.
!>
