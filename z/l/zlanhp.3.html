double precision function zlanhp (norm, uplo, n, ap, work)
ZLANHP devuelve el valor de la norma 1, o la norma de Frobenius, o la norma infinito, o el elemento de mayor valor absoluto de una matriz Hermítica compleja suministrada en forma empaquetada.

Documentación de función/subrutina

double precision function zlanhp (character norm, character uplo, integer n, complex*16, dimension( * ) ap, double precision, dimension( * ) work)

ZLANHP devuelve el valor de la norma 1, o la norma de Frobenius, o la norma infinito, o el elemento de mayor valor absoluto de una matriz Hermítica compleja suministrada en forma empaquetada.

Propósito:

!>
!> ZLANHP  devuelve el valor de la norma uno,  o la norma de Frobenius, o
!> la  norma de infinito,  o el  elemento de  mayor valor absoluto de una
!> matriz Hermítica compleja A,  suministrada en forma empaquetada.
!>

Devuelve

ZLANHP 
!>
!>    ZLANHP = ( max(abs(A(i,j))), NORM = 'M' or 'm'
!>             (
!>             ( norm1(A),         NORM = '1', 'O' or 'o'
!>             (
!>             ( normI(A),         NORM = 'I' or 'i'
!>             (
!>             ( normF(A),         NORM = 'F', 'f', 'E' or 'e'
!>
!> donde  norm1  denota la  norma uno de una matriz (suma máxima de columnas),
!> normI  denota la  norma de infinito  de una matriz  (suma máxima de filas) y
!> normF  denota la  norma de Frobenius  de una matriz (raíz cuadrada de la suma de
!> cuadrados).  Tenga en cuenta que  max(abs(A(i,j)))  no es una norma matricial consistente.
!>

Parámetros

NORM 
!>          NORM is CHARACTER*1
!>          Especifica el valor a devolver en ZLANHP según se describe
!>          arriba.
!>

UPLO

!>          UPLO is CHARACTER*1
!>          Especifica si se suministra la parte triangular superior o inferior de
!>          la matriz Hermítica A.
!>          = 'U':  Se suministra la parte triangular superior de A
!>          = 'L':  Se suministra la parte triangular inferior de A
!>

N

!>          N is INTEGER
!>          El orden de la matriz A.  N >= 0.  Cuando N = 0, ZLANHP se
!>          establece a cero.
!>

AP

!>          AP is COMPLEX*16 array, dimension (N*(N+1)/2)
!>          La parte triangular superior o inferior de la matriz Hermítica A, empaquetada
!>          por columnas en un array lineal.  La columna j de A se almacena
!>          en el array AP como sigue:
!>          si UPLO = 'U', AP(i + (j-1)*j/2) = A(i,j) para 1<=i<=j;
!>          si UPLO = 'L', AP(i + (j-1)*(2n-j)/2) = A(i,j) para j<=i<=n.
!>          Tenga en cuenta que  las partes imaginarias de los elementos diagonales no
!>          necesitan ser establecidas y se asume que son cero.
!>

WORK

!>          WORK is DOUBLE PRECISION array, dimension (MAX(1,LWORK)),
!>          donde LWORK >= N cuando NORM = 'I' o '1' o 'O'; en caso contrario,
!>          WORK no se referencia.
!>
