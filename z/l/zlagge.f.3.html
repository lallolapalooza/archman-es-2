DOCUMENTACIÓN DE FUNCIÓN/SUBRUTINA

subroutine zlagge (integer m, integer n, integer kl, integer ku, double precision, dimension( * ) d, complex*16, dimension( lda, * ) a, integer lda, integer, dimension( 4 ) iseed, complex*16, dimension( * ) work, integer info)

ZLAGGE

Propósito:

!>
!> ZLAGGE genera una matriz compleja general m por n A, pre- y post-multiplicando
!> una matriz diagonal real D con matrices unitarias aleatorias: A = U*D*V.
!> Los anchos de banda inferior y superior pueden entonces reducirse a kl y ku
!> mediante transformaciones unitarias adicionales.
!>

Parámetros

M 
!>          M es ENTERO
!>          El número de filas de la matriz A.  M >= 0.
!>

N

!>          N es ENTERO
!>          El número de columnas de la matriz A.  N >= 0.
!>

KL

!>          KL es ENTERO
!>          El número de subdiagonales no nulas dentro de la banda de A.
!>          0 <= KL <= M-1.
!>

KU

!>          KU es ENTERO
!>          El número de superdiagonales no nulas dentro de la banda de A.
!>          0 <= KU <= N-1.
!>

D

!>          D es un array de DOBLE PRECISIÓN, dimensión (min(M,N))
!>          Los elementos diagonales de la matriz diagonal D.
!>

A

!>          A es un array de COMPLEJO*16, dimensión (LDA,N)
!>          La matriz A generada de m por n.
!>

LDA

!>          LDA es ENTERO
!>          La dimensión principal del array A.  LDA >= M.
!>

ISEED

!>          ISEED es un array de ENTERO, dimensión (4)
!>          A la entrada, la semilla del generador de números aleatorios; los
!>          elementos del array deben estar entre 0 y 4095, y ISEED(4) debe
!>          ser impar.
!>          A la salida, la semilla se actualiza.
!>

WORK

!>          WORK es un array de COMPLEJO*16, dimensión (M+N)
!>

INFO

!>          INFO es ENTERO
!>          = 0: salida exitosa
!>          < 0: si INFO = -i, el i-ésimo argumento tenía un valor ilegal
!>
