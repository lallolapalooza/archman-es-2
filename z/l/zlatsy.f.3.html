subrutina zlatsy (carácter uplo, entero n, complejo*16, dimensión( ldx, * ) x, entero ldx, entero, dimensión( * ) iseed)

ZLATSY

Propósito:

!>
!> ZLATSY genera una matriz de prueba especial para la factorización
!> de matrices complejas simétricas (indefinidas). Los bloques pivote
!> de la matriz generada estarán en el siguiente orden:
!>    Bloque pivote de 2x2, no diagonalizable
!>    Bloque pivote de 1x1
!>    Bloque pivote de 2x2, diagonalizable
!>    (el ciclo se repite)
!> Se requiere un intercambio de filas para cada bloque de 2x2 no
!> diagonalizable.
!>

Parámetros

UPLO 
!>          UPLO es CARACTER
!>          Especifica si la matriz generada debe ser triangular superior
!>          o inferior.
!>          = 'U':  Triangular superior
!>          = 'L':  Triangular inferior
!>

N

!>          N es ENTERO
!>          La dimensión de la matriz a generar.
!>

X

!>          X es un array de COMPLEJO*16, dimensión (LDX,N)
!>          La matriz generada, que consiste en bloques diagonales de 3x3
!>          y 2x2 que resultan en la secuencia de pivote anterior.
!>          La matriz fuera de estos bloques diagonales es cero.
!>

LDX

!>          LDX es ENTERO
!>          La dimensión principal del array X.
!>

ISEED

!>          ISEED es un array de ENTEROS, dimensión (4)
!>          En la entrada, la semilla para el generador de números aleatorios.
!>          El último de los cuatro enteros debe ser impar.
!>          (modificado en la salida)
!>
