subrutina zlatme (integer n, character dist, integer, dimension( 4 ) iseed, complex*16, dimension( * ) d, integer mode, double precision cond, complex*16 dmax, character rsign, character upper, character sim, double precision, dimension( * ) ds, integer modes, double precision conds, integer kl, integer ku, double precision anorm, complex*16, dimension( lda, * ) a, integer lda, complex*16, dimension( * ) work, integer info)

ZLATME

Propósito:

!>
!>    ZLATME genera matrices cuadradas aleatorias no simétricas con
!>    autovalores especificados para probar programas LAPACK.
!>
!>    ZLATME opera aplicando la siguiente secuencia de
!>    operaciones:
!>
!>    1. Establece la diagonal a D, donde D puede ser de entrada o
!>         calculada según MODE, COND, DMAX y RSIGN
!>         como se describe a continuación.
!>
!>    2. Si UPPER='T', el triángulo superior de A se establece a valores aleatorios
!>         fuera de la distribución DIST.
!>
!>    3. Si SIM='T', A se multiplica por la izquierda por una matriz aleatoria
!>         X, cuyos valores singulares se especifican por DS, MODES y
!>         CONDS, y por la derecha por X inversa.
!>
!>    4. Si KL < N-1, la banda inferior se reduce a KL usando
!>         transformaciones de Householder. Si KU < N-1, la banda superior
!>         se reduce a KU.
!>
!>    5. Si ANORM no es negativo, la matriz se escala para tener
!>         la norma de elemento máximo ANORM.
!>
!>    (Nota: dado que la matriz no se puede reducir más allá de la forma de Hessenberg,
!>     no hay opciones de empaquetado disponibles.)
!>

Parámetros

N 
!>          N es un ENTERO
!>           El número de columnas (o filas) de A. No modificado.
!>

DIST

!>          DIST es CHARACTER*1
!>           A la entrada, DIST especifica el tipo de distribución que se utilizará
!>           para generar los autovalores/valores singulares aleatorios, y en el
!>           triángulo superior (ver UPPER).
!>           'U' => UNIFORME( 0, 1 )  ( 'U' para uniforme )
!>           'S' => UNIFORME( -1, 1 ) ( 'S' para simétrico )
!>           'N' => NORMAL( 0, 1 )   ( 'N' para normal )
!>           'D' => uniforme en el disco complejo |z| < 1.
!>           No modificado.
!>

ISEED

!>          ISEED es un array de ENTEROS, dimensión ( 4 )
!>           A la entrada, ISEED especifica la semilla del generador de números
!>           aleatorios. Deben estar entre 0 y 4095 inclusive,
!>           y ISEED(4) debe ser impar. El generador de números aleatorios
!>           utiliza una secuencia congruencial lineal limitada a enteros pequeños,
!>           y por lo tanto debería producir números aleatorios independientes de la máquina.
!>           Los valores de ISEED se modifican a la salida y se pueden utilizar
!>           en la siguiente llamada a ZLATME para continuar la misma secuencia de números aleatorios.
!>           Modificado a la salida.
!>

D

!>          D es un array COMPLEX*16, dimensión ( N )
!>           Este array se utiliza para especificar los autovalores de A. Si
!>           MODE=0, entonces se asume que D contiene los autovalores;
!>           de lo contrario, se calcularán según MODE, COND,
!>           DMAX y RSIGN y se colocarán en D.
!>           Modificado si MODE es distinto de cero.
!>

MODE

!>          MODE es un ENTERO
!>           A la entrada, esto describe cómo se especificarán los autovalores:
!>           MODE = 0 significa usar D como entrada
!>           MODE = 1 establece D(1)=1 y D(2:N)=1.0/COND
!>           MODE = 2 establece D(1:N-1)=1 y D(N)=1.0/COND
!>           MODE = 3 establece D(I)=COND**(-(I-1)/(N-1))
!>           MODE = 4 establece D(i)=1 - (i-1)/(N-1)*(1 - 1/COND)
!>           MODE = 5 establece D a números aleatorios en el rango
!>                    ( 1/COND , 1 ) tales que sus logaritmos
!>                    estén distribuidos uniformemente.
!>           MODE = 6 establece D a números aleatorios de la misma distribución
!>                    que el resto de la matriz.
!>           MODE < 0 tiene el mismo significado que ABS(MODE), excepto que
!>              el orden de los elementos de D se invierte.
!>           Por lo tanto, si MODE está entre 1 y 4, D tiene entradas que varían
!>              de 1 a 1/COND, si está entre -1 y -4, D tiene entradas
!>              que varían de 1/COND a 1,
!>           No modificado.
!>

COND

!>          COND es DOUBLE PRECISION
!>           A la entrada, se utiliza como se describe en MODE arriba.
!>           Si se utiliza, debe ser >= 1. No modificado.
!>

DMAX

!>          DMAX es COMPLEX*16
!>           Si MODE no es -6, 0 ni 6, el contenido de D, como se
!>           calcula según MODE y COND, se escalará por
!>           DMAX / max(abs(D(i))). Tenga en cuenta que DMAX no necesita
!>           ser positivo o real: si DMAX es negativo o complejo (o cero),
!>           D se escalará por un número negativo o complejo (o cero).
!>           Si RSIGN='F', el autovalor más grande (en valor absoluto) será
!>           igual a DMAX.
!>           No modificado.
!>

RSIGN

!>          RSIGN es CHARACTER*1
!>           Si MODE no es 0, 6 ni -6, y RSIGN='T', entonces los
!>           elementos de D, calculados según MODE y COND, se
!>           multiplicarán por un número complejo aleatorio del círculo unitario
!>           |z| = 1. Si RSIGN='F', no lo serán. RSIGN solo puede tener
!>           los valores 'T' o 'F'.
!>           No modificado.
!>

UPPER

!>          UPPER es CHARACTER*1
!>           Si UPPER='T', entonces los elementos de A por encima de la diagonal
!>           se establecerán a números aleatorios fuera de DIST. Si UPPER='F',
!>           no lo harán. UPPER solo puede tener los valores 'T' o 'F'.
!>           No modificado.
!>

SIM

!>          SIM es CHARACTER*1
!>           Si SIM='T', entonces A será operado por , es decir, se multiplica por la izquierda por una matriz X y
!>           por la derecha por X inversa. X = U S V, donde U y V son
!>           matrices unitarias aleatorias y S es una matriz (diagonal) de
!>           valores singulares especificados por DS, MODES y
!>           CONDS. Si
!>           SIM='F', entonces A no será transformado.
!>           No modificado.
!>

DS

!>          DS es un array DOUBLE PRECISION, dimensión ( N )
!>           Este array se utiliza para especificar los valores singulares de X,
!>           de la misma manera que D especifica los autovalores de A.
!>           Si MODE=0, DS contiene los valores singulares, que
!>           no pueden ser cero.
!>           Modificado si MODE es distinto de cero.
!>

MODES

!>          MODES es un ENTERO
!>

CONDS

!>          CONDS es DOUBLE PRECISION
!>           Similar a MODE y COND, pero para especificar la diagonal
!>           de S. MODES=-6 y +6 no están permitidos (ya que resultarían
!>           en autovalores aleatoriamente mal condicionados).
!>

KL

!>          KL es un ENTERO
!>           Esto especifica el ancho de banda inferior de la matriz. KL=1
!>           especifica la forma de Hessenberg superior. Si KL es al menos N-1,
!>           entonces A tendrá un ancho de banda inferior completo.
!>           No modificado.
!>

KU

!>          KU es un ENTERO
!>           Esto especifica el ancho de banda superior de la matriz. KU=1
!>           especifica la forma de Hessenberg inferior. Si KU es al menos N-1,
!>           entonces A tendrá un ancho de banda superior completo; si KU y KL
!>           son ambos N-1

NAME

zlatme — LAPACK routine for generating test matrices

SYNOPSIS

  SUBROUTINE ZLATME (
     M, N, DIST, DIAG, MODE, NSE, D, SIGMA, KIND, SUB, RESID,
     ANORM, A, LDA, WORK, INFO
  )

Parameters:

  INTEGER          M, N
  CHARACTER*1      DIST, DIAG, KIND, SUB
  INTEGER          MODE, NSE
  REAL*8           D( * ), SIGMA, RESID, ANORM
  REAL*8           CONDS( * )
  INTEGER          LDA
  COMPLEX*16       A( LDA, * ), WORK( * )
  INTEGER          INFO

Function/Subroutine Documentation

ZLATME

!> 
!> Purpose
!> =======
!> 
!> ZLATME generates test matrices, for use in LAPACK routines.
!> 
!> Arguments
!> =========
!> 
!> M (input) INTEGER
!>          The number of rows of the matrix A.
!> 
!> N (input) INTEGER
!>          The number of columns of the matrix A.
!> 
!> DIST (input) CHARACTER*1
!>          Specifies the distribution of the singular values.
!>          'U' => uniformly distributed in (0,1]
!>          'S' => distributed as squares of cosines of angles from
!>                 GS231 algorithm.
!>          'E' => exponentially distributed.
!>          'H' => distributed as squares of cosines of angles from
!>                 GS231 algorithm (for orthogonal matrix).
!> 
!> DIAG (input) CHARACTER*1
!>          Specifies the type of matrix.
!>          'N' => general triangular matrix.
!>          'U' => upper triangular matrix.
!>          'L' => lower triangular matrix.
!> 
!> MODE (input) INTEGER
!>          Specifies the rank and condition number of the matrix.
!>          -1 => random orthogonal matrix.
!>           0 => random                                      
!>           1 => diagonal matrix.
!>           2 => upper triangular matrix.
!>           3 => lower triangular matrix.
!>           4 => upper Hessenberg matrix.
!>           5 => lower Hessenberg matrix.
!>           6 => symmetric or skew-symmetric matrix.
!>           7 => general matrix.
!>           8 => tridiagonal matrix.
!>           9 => upper bidiagonal matrix.
!>          10 => lower bidiagonal matrix.
!> 
!> NSE (input) INTEGER
!>          The number of non-zero singular values.
!> 
!> D (input) REAL*8 array, dimension (N)
!>          The singular values of A. If NSE < N, then D(NSE+1:N)
!>          are set to zero.
!> 
!> SIGMA (input) REAL*8
!>          The desired condition number.
!> 
!> KIND (input) CHARACTER*1
!>          Specifies the type of singular values.
!>          'R' => random singular values.
!>          'Q' => uniformly distributed singular values.
!>          'V' => values from 1 to N.
!>          'L' => values from 1 to N, with N/2 values set to 1.
!> 
!> SUB (input) CHARACTER*1
!>          Specifies the structure of the matrix.
!>          'R' => random matrix.
!>          'H' => random Householder matrix.
!>          'U' => random upper triangular matrix.
!>          'L' => random lower triangular matrix.
!>          'B' => random bidiagonal matrix.
!>          'T' => random tridiagonal matrix.
!>          'Q' => random upper quasi-triangular matrix.
!>          'K' => random upper Hessenberg matrix.
!>          'S' => random symmetric matrix.
!>          'A' => random skew-symmetric matrix.
!>          'X' => random sparse matrix.
!> 
!> RESID (input) REAL*8
!>          Desired residual norm.
!> 
!> ANORM (input) REAL*8
!>          If ANORM is not negative, then A will be scaled by a non-
!>          negative real number to make the maximum-element-norm of A
!>          to be ANORM.
!>          Not modified.
!> 
!> A (output) COMPLEX*16 array, dimension ( LDA, N )
!>          On exit A is the desired test matrix.
!>          Modified.
!> 
!> LDA (input) INTEGER
!>          LDA specifies the first dimension of A as declared in the
!>          calling program. LDA must be at least M.
!>          Not modified.
!> 
!> WORK (workspace) COMPLEX*16 array, dimension ( 3*N )
!>          Workspace.
!>          Modified.
!> 
!> INFO (output) INTEGER
!>          Error code. On exit, INFO will be set to one of the
!>          following values:
!>             0 => normal return
!>            -1 => N negative
!>            -2 => DIST illegal string
!>            -5 => MODE not in range -6 to 6
!>            -6 => COND less than 1.0, and MODE neither -6, 0 nor 6
!>            -9 => RSIGN is not 'T' or 'F'
!>           -10 => UPPER is not 'T' or 'F'
!>           -11 => SIM   is not 'T' or 'F'
!>           -12 => MODES=0 and DS has a zero singular value.
!>           -13 => MODES is not in the range -5 to 5.
!>           -14 => MODES is nonzero and CONDS is less than 1.
!>           -15 => KL is less than 1.
!>           -16 => KU is less than 1, or KL and KU are both less than
!>                  N-1.
!>           -19 => LDA is less than M.
!>             1 => Error return from ZLATM1 (computing D)
!>             2 => Cannot scale to DMAX (max. eigenvalue is 0)
!>             3 => Error return from DLATM1 (computing DS)
!>             4 => Error return from ZLARGE
!>             5 => Zero singular value from DLATM1.
!>
