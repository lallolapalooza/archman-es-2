subrutina zlavsy_rook (character uplo, character trans, character diag, integer n, integer nrhs, complex*16, dimension( lda, * ) a, integer lda, integer, dimension( * ) ipiv, complex*16, dimension( ldb, * ) b, integer ldb, integer info)

ZLAVSY_ROOK

Propósito:

!>
!> ZLAVSY_ROOK realiza una de las operaciones de matriz-vector
!>    x := A*x  o  x := A'*x,
!> donde x es un vector de N elementos y A es uno de los factores
!> de la factorización en bloque U*D*U' o L*D*L' calculada por ZSYTRF_ROOK.
!>
!> Si TRANS = 'N', multiplica por U  o U * D  (o L  o L * D)
!> Si TRANS = 'T', multiplica por U' o D * U' (o L' o D * L')
!>

Parámetros

UPLO 
!>          UPLO es CHARACTER*1
!>          Especifica si el factor almacenado en A es superior o inferior
!>          triangular.
!>          = 'U':  Triangular superior
!>          = 'L':  Triangular inferior
!>

TRANS

!>          TRANS es CHARACTER*1
!>          Especifica la operación a realizar:
!>          = 'N':  x := A*x
!>          = 'T':  x := A'*x
!>

DIAG

!>          DIAG es CHARACTER*1
!>          Especifica si los bloques diagonales son matrices unitarias o no.
!>          Si se asume que los bloques diagonales son unitarios,
!>          entonces A = U o A = L, de lo contrario A = U*D o A = L*D.
!>          = 'U':  Se asume que los bloques diagonales son matrices unitarias.
!>          = 'N':  Se asume que los bloques diagonales son matrices no unitarias.
!>

N

!>          N es INTEGER
!>          El número de filas y columnas de la matriz A.  N >= 0.
!>

NRHS

!>          NRHS es INTEGER
!>          El número de lados derechos, es decir, el número de vectores
!>          x a multiplicar por A.  NRHS >= 0.
!>

A

!>          A es COMPLEX*16 array, dimension (LDA,N)
!>          La matriz diagonal por bloques D y los multiplicadores utilizados para
!>          obtener el factor U o L, tal como es calculada por ZSYTRF_ROOK.
!>          Almacenada como una matriz triangular 2-D.
!>

LDA

!>          LDA es INTEGER
!>          La dimensión principal del array A.  LDA >= max(1,N).
!>

IPIV

!>          IPIV es INTEGER array, dimension (N)
!>          Detalles de los intercambios y la estructura de bloques de D,
!>          tal como es determinada por ZSYTRF_ROOK.
!>
!>          Si UPLO = 'U':
!>               Si IPIV(k) > 0, entonces las filas y columnas k e IPIV(k)
!>               fueron intercambiadas y D(k,k) es un bloque diagonal de 1x1.
!>               (Si IPIV( k ) = k, no se realizó ningún intercambio).
!>
!>               Si IPIV(k) < 0 e IPIV(k-1) < 0, entonces las filas y
!>               columnas k e -IPIV(k) fueron intercambiadas y las filas y
!>               columnas k-1 y -IPIV(k-1) fueron intercambiadas,
!>               D(k-1:k,k-1:k) es un bloque diagonal de 2x2.
!>
!>          Si UPLO = 'L':
!>               Si IPIV(k) > 0, entonces las filas y columnas k e IPIV(k)
!!               fueron intercambiadas y D(k,k) es un bloque diagonal de 1x1.
!>               (Si IPIV( k ) = k, no se realizó ningún intercambio).
!>
!>               Si IPIV(k) < 0 e IPIV(k+1) < 0, entonces las filas y
!>               columnas k e -IPIV(k) fueron intercambiadas y las filas y
!>               columnas k+1 y -IPIV(k+1) fueron intercambiadas,
!>               D(k:k+1,k:k+1) es un bloque diagonal de 2x2.
!>

B

!>          B es COMPLEX*16 array, dimension (LDB,NRHS)
!>          A la entrada, B contiene NRHS vectores de longitud N.
!>          A la salida, B es sobrescrito con el producto A * B.
!>

LDB

!>          LDB es INTEGER
!>          La dimensión principal del array B.  LDB >= max(1,N).
!>

INFO

!>          INFO es INTEGER
!>          = 0: ejecución exitosa
!>          < 0: si INFO = -k, el k-ésimo argumento tenía un valor ilegal
!>
