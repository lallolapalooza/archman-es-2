TESTING/MATGEN/zlatmr.f

SINOPSIS

Funciones/Subrutinas


subroutine zlatmr (m, n, dist, iseed, sym, d, mode, cond, dmax, rsign, grade, dl, model, condl, dr, moder, condr, pivtng, ipivot, kl, ku, sparse, anorm, pack, a, lda, iwork, info)
ZLATMR

DOCUMENTACIÓN DE LA FUNCIÓN/SUBRUTINA

subroutine zlatmr (integer m, integer n, character dist, integer, dimension( 4 ) iseed, character sym, complex*16, dimension( * ) d, integer mode, double precision cond, complex*16 dmax, character rsign, character grade, complex*16, dimension( * ) dl, integer model, double precision condl, complex*16, dimension( * ) dr, integer moder, double precision condr, character pivtng, integer, dimension( * ) ipivot, integer kl, integer ku, double precision sparse, double precision anorm, character pack, complex*16, dimension( lda, * ) a, integer lda, integer, dimension( * ) iwork, integer info)

ZLATMR

Propósito:

!>
!>    ZLATMR genera matrices aleatorias de varios tipos para probar
!>    los programas LAPACK.
!>
!>    ZLATMR opera aplicando la siguiente secuencia de
!>    operaciones:
!>
!>      Genera una matriz A con entradas aleatorias de distribución DIST
!>         que es simétrica si SYM='S', Hermítica si SYM='H', y
!>         no simétrica si SYM='N'.
!>
!>      Establece la diagonal a D, donde D puede ser de entrada o
!>         calculada según MODE, COND, DMAX y RSIGN
!>         como se describe a continuación.
!>
!>      Califica la matriz, si se desea, desde la izquierda y/o derecha
!>         como se especifica en GRADE. Las entradas DL, MODEL, CONDL, DR,
!>         MODER y CONDR también determinan la calificación como se describe
!>         a continuación.
!>
!>      Permuta, si se desea, las filas y/o columnas como se especifica en
!>         PIVTNG e IPIVOT.
!>
!>      Establece entradas aleatorias a cero, si se desea, para obtener una matriz
!>         dispersa aleatoria como se especifica en SPARSE.
!>
!>      Convierte A en una matriz de banda, si se desea, poniendo a cero la matriz
!>         fuera de una banda de ancho inferior KL y ancho superior KU.
!>
!>      Escala A, si se desea, para tener la entrada máxima ANORM.
!>
!>      Empaqueta la matriz si se desea. Las opciones especificadas por PACK son:
!>         sin empaquetar
!>         poner a cero la mitad superior (si es simétrica o Hermítica)
!>         poner a cero la mitad inferior (si es simétrica o Hermítica)
!>         almacenar la mitad superior columna por columna (si es simétrica o Hermítica
!>             o triangular superior cuadrada)
!>         almacenar la mitad inferior columna por columna (si es simétrica o Hermítica
!>             o triangular inferior cuadrada)
!>             igual que la mitad superior fila por fila si es simétrica
!>             igual que la mitad superior conjugada fila por fila si es Hermítica
!>         almacenar el triángulo inferior en formato de banda
!>             (si es simétrica o Hermítica)
!>         almacenar el triángulo superior en formato de banda
!>             (si es simétrica o Hermítica)
!>         almacenar toda la matriz en formato de banda
!>
!>    Nota: Si dos llamadas a ZLATMR difieren solo en el parámetro PACK,
!!>          generarán matrices matemáticamente equivalentes.
!>
!>          Si dos llamadas a ZLATMR tienen ancho de banda completo (KL = M-1
!>          y KU = N-1), y difieren solo en los parámetros PIVTNG y PACK,
!>          entonces las matrices generadas diferirán solo
!>          en el orden de las filas y/o columnas, y de lo contrario
!>          contendrán los mismos datos. Esta consistencia no puede ser y
!>          no se mantiene con un ancho de banda menor al completo.
!>

Parámetros

M 
!>          M es INTEGER
!>           Número de filas de A. No modificado.
!>

N

!>          N es INTEGER
!>           Número de columnas de A. No modificado.
!>

DIST

!>          DIST es CHARACTER*1
!>           A la entrada, DIST especifica el tipo de distribución que se utilizará
!>           para generar una matriz aleatoria.
!>           'U' => partes real e imaginaria son INDEPENDIENTES
!>                  UNIFORMES( 0, 1 )  ( 'U' para uniforme )
!>           'S' => partes real e imaginaria son INDEPENDIENTES
!>                  UNIFORMES( -1, 1 ) ( 'S' para simétrica )
!>           'N' => partes real e imaginaria son INDEPENDIENTES
!>                  NORMAL( 0, 1 )   ( 'N' para normal )
!>           'D' => uniforme en el interior del disco unitario ( 'D' para disco )
!>           No modificado.
!>

ISEED

!>          ISEED es un array de INTEGER, de dimensión (4)
!>           A la entrada, ISEED especifica la semilla del generador de números
!>           aleatorios. Deberían estar entre 0 y 4095 inclusive,
!>           y ISEED(4) debería ser impar. El generador de números aleatorios
!>           utiliza una secuencia lineal congruencial limitada a enteros
!>           pequeños, y por lo tanto debería producir números aleatorios
!>           independientes de la máquina. Los valores de ISEED se cambian al
!>           salir, y se pueden usar en la siguiente llamada a ZLATMR
!>           para continuar la misma secuencia de números aleatorios.
!>           Cambiado al salir.
!>

SYM

!>          SYM es CHARACTER*1
!>           Si SYM='S', la matriz generada es simétrica.
!>           Si SYM='H', la matriz generada es Hermítica.
!>           Si SYM='N', la matriz generada es no simétrica.
!>           No modificado.
!>

D

!>          D es un array de COMPLEX*16, de dimensión (min(M,N))
!>           A la entrada, este array especifica las entradas diagonales
!>           de la diagonal de A. D puede ser especificado
!>           en la entrada, o establecido según MODE y COND como se describe
!>           a continuación. Si la matriz es Hermítica, se tomará la parte real de D.
!>           Puede ser cambiado a la salida si MODE es distinto de cero.
!>

MODE

!>          MODE es INTEGER
!>           A la entrada, describe cómo se utiliza D:
!>           MODE = 0 significa usar D como entrada
!>           MODE = 1 establece D(1)=1 y D(2:N)=1.0/COND
!>           MODE = 2 establece D(1:N-1)=1 y D(N)=1.0/COND
!>           MODE = 3 establece D(I)=COND**(-(I-1)/(N-1))
!>           MODE = 4 establece D(i)=1 - (i-1)/(N-1)*(1 - 1/COND)
!>           MODE = 5 establece D a números aleatorios en el rango
!>                    ( 1/COND , 1 ) tales que sus logaritmos
!>                    están distribuidos uniformemente.
!>           MODE = 6 establece D a números aleatorios de la misma distribución
!>                    que el resto de la matriz.
!>           MODE < 0 tiene el mismo significado que ABS(MODE), excepto que
!>              el orden de los elementos de D se invierte.
!>           Por lo tanto, si MODE es positivo, D tiene entradas que van desde
!>              1 hasta 1/COND, si es negativo, desde 1/COND hasta 1,
!>           No modificado.
!>

COND

!>          COND es DOUBLE PRECISION
!>           A la entrada, se utiliza como se describe en MODE arriba.
!>           Si se utiliza, debe ser >= 1. No modificado.
!>

DMAX

!>          DMAX es COMPLEX*16
!>           Si MODE no es -6, 0 ni 6, la diagonal se escala por
!>           DMAX / max(abs(D(i))), de modo que la entrada máxima absoluta
!>           de la diagonal sea abs(DMAX). Si DMAX es complejo (o cero),
!>           la diagonal se escalará por un número complejo (o cero).
!>

RSIGN

!>          RSIGN es CHARACTER*1
!>           Si MODE no es -6, 0 ni 6, especifica el signo de la diagonal
!>           de la siguiente manera:
!>           'T' => las entradas diagonales se multiplican por un número complejo
!>                  aleatorio uniformemente distribuido con valor absoluto 1
!>           'F' => la diagonal no se modifica
!>           No modificado.
!>

GRADE

!>          GRADE es CHARACTER*1
!>           Si GRADE = 'L', la matriz se califica desde la izquierda.
!>           Si GRADE = 'R', la matriz se califica desde la derecha.
!>           Si GRADE = 'B', la matriz se califica desde ambos lados.
!>           Si GRADE = 'N', la matriz no se califica.
!>           No modificado.
!>

DL

!>          DL es COMPLEX*16 array, dimension (M)
!>           Si GRADE = 'L' o 'B', DL especifica el vector de calificación
!>           desde la izquierda. Si MODEL es distinto de cero, DL se genera
!>           según las reglas de MODEL, CONDL y CONDL. DL se utiliza
!>           para la calificación de izquierda.
!>

MODEL

!>          MODEL es INTEGER
!>           Si GRADE = 'L' o 'B', MODEL describe cómo se genera DL.
!>           MODEL = 0 => usar DL como entrada.
!>           MODEL = 1 => DL(I) = 1 para todos I.
!>           MODEL = 2 => DL(I) = 1 - (I-1)/(M-1)*(1-1/CONDL)
!>           MODEL = 3 => DL(I) = CONDL**(-(I-1)/(M-1))
!>           MODEL = 4 => DL(I) = aleatorio en (1/CONDL, 1).
!>           MODEL = 5 => DL(I) = aleatorio en (1, CONDL).
!>           MODEL < 0 => igual que ABS(MODEL), pero con el orden de DL invertido.
!>           No modificado.
!>

CONDL

!>          CONDL es DOUBLE PRECISION
!>           Si GRADE = 'L' o 'B', CONDL se utiliza según se describe en MODEL.
!>           Debe ser >= 1. No modificado.
!>

DR

!>          DR es COMPLEX*16 array, dimension (N)
!>           Si GRADE = 'R' o 'B', DR especifica el vector de calificación
!>           desde la derecha. Si MODER es distinto de cero, DR se genera
!>           según las reglas de MODER, CONDR y CONDR. DR se utiliza
!>           para la calificación de derecha.
!>

MODER

!>          MODER es INTEGER
!>           Si GRADE = 'R' o 'B', MODER describe cómo se genera DR.
!>           MODER = 0 => usar DR como entrada.
!>           MODER = 1 => DR(J) = 1 para todos J.
!>           MODER = 2 => DR(J) = 1 - (J-1)/(N-1)*(1-1/CONDR)
!>           MODER = 3 => DR(J) = CONDR**(-(J-1)/(N-1))
!>           MODER = 4 => DR(J) = aleatorio en (1/CONDR, 1).
!>           MODER = 5 => DR(J) = aleatorio en (1, CONDR).
!>           MODER < 0 => igual que ABS(MODER), pero con el orden de DR invertido.
!>           No modificado.
!>

CONDR

!>          CONDR es DOUBLE PRECISION
!>           Si GRADE = 'R' o 'B', CONDR se utiliza según se describe en MODER.
!>           Debe ser >= 1. No modificado.
!>

PIVTNG

!>          PIVTNG es CHARACTER*1
!>           Si PIVTNG = 'R', se realiza una permutación aleatoria de filas.
!>           Si PIVTNG = 'C', se realiza una permutación aleatoria de columnas.
!>           Si PIVTNG = 'B', se realizan ambas permutaciones.
!>           Si PIVTNG = 'N', no se realiza ninguna permutación.
!>           No modificado.
!>

IPIVOT

!>          IPIVOT es INTEGER array, dimension (max(M,N))
!>           Si PIVTNG = 'R', 'C' o 'B', IPIVOT contiene la permutación.
!>           Si PIVTNG = 'R', IPIVOT(I) contiene la fila de destino de la fila I.
!>           Si PIVTNG = 'C', IPIVOT(J) contiene la columna de destino de la col J.
!>           IPIVOT se genera aleatoriamente si PIVTNG = 'R', 'C' o 'B'.
!>           IPIVOT puede ser sobreescrito por ZLATMR.
!>

KL

!>          KL es INTEGER
!>           Si KL < 0, la matriz es dispersa (ver PARÁMETRO SPARSE).
!>           Si KL >= 0, entonces la matriz se limita a un ancho de banda
!>           inferior KL.
!>           No modificado.
!>

KU

!>          KU es INTEGER
!>           Si KU < 0, la matriz es dispersa (ver PARÁMETRO SPARSE).
!>           Si KU >= 0, entonces la matriz se limita a un ancho de banda
!>           superior KU.
!>           No modificado.
!>

SPARSE

!>          SPARSE es DOUBLE PRECISION
!>           Si KL < 0 o KU < 0, entonces la matriz se hace dispersa.
!>           SPARSE especifica la fracción de entradas que no son cero.
!>           Debe estar en el rango [0, 1].
!>           No modificado.
!>

ANORM

!>          ANORM es DOUBLE PRECISION
!>           Si ANORM > 0, la matriz A se escala para que tenga norma
!>           máxima de entrada ANORM.
!>           Si ANORM < 0, la matriz A se escala para que tenga norma
!>           1 de entrada ANORM.
!>           No modificado.
!>

PACK

!>          PACK es CHARACTER*1
!>           Si PACK = 'N', la matriz A se almacena en formato de matriz
!>           completa de doble precisión.
!>           Si PACK = 'Z', la mitad superior se pone a cero si SYM = 'S' o 'H'.
!>           Si PACK = 'U', la mitad inferior se pone a cero si SYM = 'S' o 'H'.
!>           Si PACK = 'C', la matriz A se empaqueta en formato de banda
!>           columna por columna si SYM = 'S' o 'H'.
!>           Si PACK = 'R', la matriz A se empaqueta en formato de banda
!>           fila por fila si SYM = 'S' o 'H'.
!>           Si PACK = 'L', se almacena el triángulo inferior de A en formato
!>           de banda (si SYM = 'S' o 'H').
!>           Si PACK = 'U', se almacena el triángulo superior de A en formato
!>           de banda (si SYM = 'S' o 'H').
!>           No modificado.
!>

A

!>          A es COMPLEX*16 array, dimension (LDA, N)
!>           En la salida, A contiene la matriz aleatoria deseada.
!>

LDA

!>          LDA es INTEGER
!>           Tamaño de la primera dimensión de A. Debe ser al menos max(1,M).
!>           No modificado.
!>

IWORK

!>          IWORK es INTEGER array, dimension (max(M,N))
!>           Espacio de trabajo para IPIVOT.
!>

INFO

!>          INFO es INTEGER
!>           = 0:  correcta ejecución.
!>           < 0: si INFO = -i, el i-ésimo argumento hacia fuera
!>                de rango.
!>
anged !> No modificado. !>

GRADE

!>          GRADE es CHARACTER*1
!>           Especifica la graduación de la matriz como sigue:
!>           'N'  => sin graduación
!>           'L'  => matriz premultiplicada por diag( DL )
!>                   (sólo si la matriz es no simétrica)
!>           'R'  => matriz postmultiplicada por diag( DR )
!>                   (sólo si la matriz es no simétrica)
!>           'B'  => matriz premultiplicada por diag( DL ) y
!>                         postmultiplicada por diag( DR )
!>                   (sólo si la matriz es no simétrica)
!>           'H'  => matriz premultiplicada por diag( DL ) y
!>                         postmultiplicada por diag( CONJG(DL) )
!>                   (sólo si la matriz es Hermítica o no simétrica)
!>           'S'  => matriz premultiplicada por diag( DL ) y
!>                         postmultiplicada por diag( DL )
!>                   (sólo si la matriz es simétrica o no simétrica)
!>           'E'  => matriz premultiplicada por diag( DL ) y
!>                         postmultiplicada por inv( diag( DL ) )
!>                         ( 'S' para similitud )
!>                   (sólo si la matriz es no simétrica)
!>                   Nota: si GRADE='S', entonces M debe ser igual a N.
!>           No modificado.
!>

DL

!>          DL es un array COMPLEX*16, de dimensión (M)
!>           Si MODEL=0, entonces en la entrada este array especifica las entradas diagonales
!>           de una matriz diagonal utilizada como se describe en GRADE
!>           anteriormente. Si MODEL no es cero, entonces DL se establecerá
!>           según MODEL y CONDL, de forma análoga a como D se establece según
!>           MODE y COND (excepto que no hay parámetro DMAX para DL).
!>           Si GRADE='E', entonces DL no puede tener entradas cero.
!>           No referenciado si GRADE = 'N' o 'R'. Modificado a la salida.
!>

MODEL

!>          MODEL es INTEGER
!>           Esto especifica cómo se va a calcular el array diagonal DL,
!>           del mismo modo que MODE especifica cómo se va a calcular D.
!>           No modificado.
!>

CONDL

!>          CONDL es DOUBLE PRECISION
!>           Cuando MODEL no es cero, esto especifica el número de condición
!>           del DL calculado. No modificado.
!>

DR

!>          DR es un array COMPLEX*16, de dimensión (N)
!>           Si MODER=0, entonces en la entrada este array especifica las entradas diagonales
!>           de una matriz diagonal utilizada como se describe en GRADE
!>           anteriormente. Si MODER no es cero, entonces DR se establecerá
!>           según MODER y CONDR, de forma análoga a como D se establece según
!>           MODE y COND (excepto que no hay parámetro DMAX para DR).
!>           No referenciado si GRADE = 'N', 'L', 'H' o 'S'.
!>           Modificado a la salida.
!>

MODER

!>          MODER es INTEGER
!>           Esto especifica cómo se va a calcular el array diagonal DR,
!>           del mismo modo que MODE especifica cómo se va a calcular D.
!>           No modificado.
!>

CONDR

!>          CONDR es DOUBLE PRECISION
!>           Cuando MODER no es cero, esto especifica el número de condición
!>           del DR calculado. No modificado.
!>

PIVTNG

!>          PIVTNG es CHARACTER*1
!>           En la entrada especifica las permutaciones de pivoteo como sigue:
!>           'N' o ' ' => ninguna.
!>           'L' => pivoteo izquierdo o por filas (la matriz debe ser no simétrica).
!>           'R' => pivoteo derecho o por columnas (la matriz debe ser
!>                  no simétrica).
!>           'B' o 'F' => ambos o pivoteo completo, es decir, en ambos lados.
!>                         En este caso, M debe ser igual a N
!>
!>           Si dos llamadas a ZLATMR tienen ambos ancho de banda completo (KL = M-1
!>           y KU = N-1), y difieren sólo en los parámetros PIVTNG y PACK,
!>           entonces las matrices generadas diferirán sólo en el orden de las filas
!>           y/o columnas, y de lo contrario contendrán los mismos datos. Esta consistencia no puede
!>           mantenerse con un ancho de banda menor que el completo.
!>

IPIVOT

!>          IPIVOT es un array INTEGER, de dimensión (N o M)
!>           Este array especifica la permutación utilizada. Después de que la
!>           matriz básica se genera, las filas, columnas, o ambas
!>           se permutan. Si, por ejemplo, se selecciona pivoteo por filas, ZLATMR
!>           comienza con la *última* fila e intercambia la fila M-ésima y la
!>           fila IPIVOT(M)-ésima, luego pasa a la penúltima fila,
!>           intercambiando la fila (M-1)-ésima y la fila IPIVOT(M-1)-ésima,
!>           y así sucesivamente. En términos de , la permutación es
!>           (1 IPIVOT(1)) (2 IPIVOT(2)) ... (M IPIVOT(M))
!>           donde el ciclo más a la derecha se aplica primero. Este es el
!>           *inverso* del efecto del pivoteo en LINPACK. La idea
!>           es que factorizar (con pivoteo) una matriz identidad
!>           que ha sido pivoteada inversamente de esta manera debería
!>           resultar en un vector de pivote igual a IPIVOT.
!>           No referenciado si PIVTNG = 'N'. No modificado.
!>

KL

!>          KL es INTEGER
!>           En la entrada especifica el ancho de banda inferior de la matriz. Por
!>           ejemplo, KL=0 implica triangular superior, KL=1 implica
!>           Hessenberg superior, y KL al menos M-1 implica que la matriz no
!>           es de banda. Debe ser igual a KU si la matriz es simétrica o Hermítica.
!>           No modificado.
!>

KU

!>          KU es INTEGER
!>           En la entrada especifica el ancho de banda superior de la matriz. Por
!>           ejemplo, KU=0 implica triangular inferior, KU=1 implica
!>           Hessenberg inferior, y KU al menos N-1 implica que la matriz no
!>           es de banda. Debe ser igual a KL si la matriz es simétrica o Hermítica.
!>           No modificado.
!>

SPARSE

!>          SPARSE es DOUBLE PRECISION
!>           En la entrada especifica la dispersión de la matriz si se va a generar una matriz dispersa. SPARSE debe estar entre
!>           0 y 1. Para generar una matriz dispersa, para cada entrada de la matriz
!>           se genera un número aleatorio uniforme ( 0, 1 ), x, y se compara
!>           con SPARSE; si x es mayor, la entrada de la matriz no se modifica y si x es menor, la entrada se establece
!>           a cero. Por lo tanto, en promedio, una fracción SPARSE de las
!>           entradas se establecerá a cero.
!>           No modificado.
!>

ANORM

!>          ANORM es DOUBLE PRECISION
!>           En la entrada especifica la entrada máxima de la matriz de salida
!>           (la matriz de salida se multiplicará por una constante para que
!>           su entrada absoluta más grande sea igual a ANORM)
!>           si ANORM es no negativo. Si ANORM es negativo, no se realiza escalado.
!>           No modificado.
!>

PACK

!>          PACK es CHARACTER*1
!>           En la entrada especifica el empaquetado de la matriz como sigue:
!>           'N' => sin empaquetar
!>           'U' => poner a cero todas las entradas subdiagonales
!>                  (si es simétrica o Hermítica)
!>           'L' => poner a cero todas las entradas superdiagonales
!>                  (si es simétrica o Hermítica)
!>           'C' => almacenar el triángulo superior por columnas
!>                  (sólo si la matriz es simétrica o Hermítica o
!>                   triangular superior cuadrada)
!>           'R' => almacenar el triángulo inferior por columnas
!>                  (sólo si la matriz es simétrica o Hermítica o
!>                   triangular inferior cuadrada)
!>                  (igual que la mitad superior por filas si es simétrica)
!>                  (igual que la mitad superior conjugada por filas si es Hermítica)
!>           'B' => almacenar el triángulo inferior en esquema de almacenamiento de banda
!>                  (sólo si la matriz es simétrica o Hermítica)
!>           'Q' => almacenar el triángulo superior en esquema de almacenamiento de banda
!>                  (sólo si la matriz es simétrica o Hermítica)
!>           'Z' => almacenar toda la matriz en esquema de almacenamiento de banda
!>                      (el pivoteo puede proporcionarse mediante el uso de esta
!>                      opción para almacenar A en las filas finales del
!>                      almacenamiento asignado)
!>
!>           Utilizando estas opciones, se pueden obtener los diversos esquemas de
!>           almacenamiento empaquetado y de banda de LAPACK:
!>           GB               - usar 'Z'
!>           PB, HB o TB     - usar 'B' o 'Q'
!>           PP, HP o TP     - usar 'C' o 'R'
!>
!>           Si dos llamadas a ZLATMR difieren sólo en el parámetro PACK,
!>           generarán matrices matemáticamente equivalentes.
!>           No modificado.
!>

A

!>          A es un array COMPLEX*16, de dimensión (LDA,N)
!>           A la salida, A es la matriz de prueba deseada. Sólo las
!>           entradas de A que son significativas a la salida
!>           serán referenciadas (incluso si A está en formato de almacenamiento empaquetado o de banda).
!>           Las 'esquinas desocupadas' de A en
