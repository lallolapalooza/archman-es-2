función de doble precisión zlanht (norma, n, d, e)

ZLANHT devuelve el valor de la norma 1, o la norma de Frobenius, o la norma infinito, o el elemento de mayor valor absoluto de una matriz tridiagonal Hermitiana compleja.

Documentación de Función/Subrutina

función de doble precisión zlanht (carácter norma, entero n, doble precisión, dimensión( * ) d, complejo*16, dimensión( * ) e)

ZLANHT devuelve el valor de la norma 1, o la norma de Frobenius, o la norma infinito, o el elemento de mayor valor absoluto de una matriz tridiagonal Hermitiana compleja.

Propósito:

!>
!> ZLANHT  devuelve el valor de la norma uno,  o la norma de Frobenius, o
!> la norma infinito,  o el  elemento de  mayor valor absoluto  de una
!> matriz tridiagonal Hermitiana compleja A.
!>

Devuelve

ZLANHT 
!>
!>    ZLANHT = ( max(abs(A(i,j))), NORMA = 'M' o 'm'
!>             (
!>             ( norm1(A),         NORMA = '1', 'O' o 'o'
!>             (
!>             ( normI(A),         NORMA = 'I' o 'i'
!>             (
!>             ( normF(A),         NORMA = 'F', 'f', 'E' o 'e'
!>
!> donde  norm1  denota la  norma uno de una matriz (suma máxima de
!> columnas),  normI  denota la  norma infinito  de una matriz  (suma
!> máxima de filas) y  normF  denota la  norma de Frobenius de una
!> matriz (raíz cuadrada de la suma de cuadrados).  Tenga en cuenta que
!> max(abs(A(i,j)))  no es una norma matricial consistente.
!>

Parámetros

NORMA 
!>          NORMA es CHARACTER*1
!>          Especifica el valor que se devolverá en ZLANHT como se describe
!>          arriba.
!>

N

!>          N es INTEGER
!>          El orden de la matriz A.  N >= 0.  Cuando N = 0, ZLANHT se
!>          establece en cero.
!>

D

!>          D es un array DOUBLE PRECISION, de dimensión (N)
!>          Los elementos diagonales de A.
!>

E

!>          E es un array COMPLEX*16, de dimensión (N-1)
!>          Los elementos subdiagonales o superdiagonales (n-1) de A.
!>
