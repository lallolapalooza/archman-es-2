Documentación de la función/subrutina

subrutina zlavhp (character uplo, character trans, character diag, integer n, integer nrhs, complex*16, dimension( * ) a, integer, dimension( * ) ipiv, complex*16, dimension( ldb, * ) b, integer ldb, integer info)

ZLAVHP

Propósito:

!>
!>    ZLAVHP  realiza una de las operaciones de vector-matriz
!>       x := A*x  o  x := A^H*x,
!>    donde x es un vector de N elementos y  A es uno de los factores
!>    de la factorización simétrica calculada por ZHPTRF.
!>    ZHPTRF produce una factorización de la forma
!>         U * D * U^H     o     L * D * L^H,
!>    donde U (o L) es un producto de matrices de permutación y triangulares
!>    unitarias superiores (inferiores), U^H (o L^H) es la transpuesta conjugada de
!>    U (o L), y D es hermitiana y diagonal por bloques con bloques diagonales de 1x1 y
!>    2x2. Los multiplicadores para las transformaciones
!>    y las partes triangulares superiores o inferiores de los bloques diagonales
!>    se almacenan columna a columna en formato empaquetado en el array lineal A.
!>
!>    Si TRANS = 'N' o 'n', ZLAVHP multiplica por U o U * D
!>    (o L o L * D).
!>    Si TRANS = 'C' o 'c', ZLAVHP multiplica por U^H o D * U^H
!>    (o L^H o D * L^H ).
!> 
!>  UPLO   - CHARACTER*1
!>           En la entrada, UPLO especifica si la matriz triangular
!>           almacenada en A es superior o inferior triangular.
!>              UPLO = 'U' o 'u'   La matriz es triangular superior.
!>              UPLO = 'L' o 'l'   La matriz es triangular inferior.
!>           Sin cambios en la salida.
!>
!>  TRANS  - CHARACTER*1
!>           En la entrada, TRANS especifica la operación a realizar como
!>           sigue:
!>              TRANS = 'N' o 'n'   x := A*x.
!>              TRANS = 'C' o 'c'   x := A^H*x.
!>           Sin cambios en la salida.
!>
!>  DIAG   - CHARACTER*1
!>           En la entrada, DIAG especifica si los bloques diagonales
!>           se asumen como matrices unitarias, como sigue:
!>              DIAG = 'U' o 'u'   Los bloques diagonales son matrices unitarias.
!>              DIAG = 'N' o 'n'   Los bloques diagonales no son unitarios.
!>           Sin cambios en la salida.
!>
!>  N      - INTEGER
!>           En la entrada, N especifica el orden de la matriz A.
!>           N debe ser mayor o igual a cero.
!>           Sin cambios en la salida.
!>
!>  NRHS   - INTEGER
!>           En la entrada, NRHS especifica el número de lados derechos,
!>           es decir, el número de vectores x a multiplicar por A.
!>           NRHS debe ser mayor o igual a cero.
!>           Sin cambios en la salida.
!>
!>  A      - Array COMPLEX*16, dimension( N*(N+1)/2 )
!>           En la entrada, A contiene una matriz diagonal por bloques y los
!>           multiplicadores de las transformaciones utilizadas para obtenerla,
!>           almacenados como una matriz triangular empaquetada.
!>           Sin cambios en la salida.
!>
!>  IPIV   - Array INTEGER, dimension( N )
!>           En la entrada, IPIV contiene el vector de índices de pivote tal como
!>           fue determinado por ZSPTRF o ZHPTRF.
!>           Si IPIV( K ) = K, no se realizó ningún intercambio.
!>           Si IPIV( K ) <> K pero IPIV( K ) > 0, entonces la fila K fue
!>           intercambiada con la fila IPIV( K ) y se utilizó un bloque pivote de 1x1.
!>           Si IPIV( K ) < 0 y UPLO = 'U', entonces la fila K-1 fue intercambiada
!>           con la fila | IPIV( K ) | y se utilizó un bloque pivote de 2x2.
!>           Si IPIV( K ) < 0 y UPLO = 'L', entonces la fila K+1 fue intercambiada
!>           con la fila | IPIV( K ) | y se utilizó un bloque pivote de 2x2.
!>
!>  B      - Array COMPLEX*16, dimension( LDB, NRHS )
!>           En la entrada, B contiene NRHS vectores de longitud N.
!>           En la salida, B se sobrescribe con el producto A * B.
!>
!>  LDB    - INTEGER
!>           En la entrada, LDB contiene la dimensión principal de B tal como
!>           fue declarada en el programa llamador. LDB debe ser al menos
!>           max( 1, N ).
!>           Sin cambios en la salida.
!>
!>  INFO   - INTEGER
!>           INFO es la bandera de error.
!>           En la salida, un valor de 0 indica una salida exitosa.
!>           Un valor negativo, por ejemplo -K, indica que el K-ésimo argumento
!>           tiene un valor ilegal.
!>
