subroutine zlaic1 (integer job, integer j, complex*16, dimension( j ) x, double precision sest, complex*16, dimension( j ) w, complex*16 gamma, double precision sestpr, complex*16 s, complex*16 c)

ZLAIC1 aplica un paso de estimación incremental de la condición en su versión más simple:

Propósito:

!>
!> ZLAIC1 aplica un paso de estimación incremental de la condición en
!> su versión más simple:
!>
!> Sea x, twonorm(x) = 1, un vector singular aproximado de una matriz
!> triangular inferior j por j, L, tal que
!>          twonorm(L*x) = sest
!> Entonces ZLAIC1 calcula sestpr, s, c tales que
!> el vector
!>                 [ s*x ]
!>          xhat = [  c  ]
!> es un vector singular aproximado de
!>                 [ L       0  ]
!>          Lhat = [ w**H gamma ]
!> en el sentido de que
!>          twonorm(Lhat*xhat) = sestpr.
!>
!> Dependiendo de JOB, se calcula una estimación del valor singular
!> más grande o más pequeño.
!>
!> Nótese que [s c]**H y sestpr**2 es un par propio del sistema
!>
!>     diag(sest*sest, 0) + [alpha  gamma] * [ conjg(alpha) ]
!>                                           [ conjg(gamma) ]
!>
!> donde  alpha =  x**H * w.
!>

Parámetros

JOB 
!>          JOB es INTEGER
!>          = 1: se calcula una estimación del valor singular más grande.
!>          = 2: se calcula una estimación del valor singular más pequeño.
!>

J

!>          J es INTEGER
!>          Longitud de X y W
!>

X

!>          X es un array COMPLEX*16, de dimensión (J)
!>          El vector j x.
!>

SEST

!>          SEST es DOUBLE PRECISION
!>          Valor singular estimado de la matriz L de j por j
!>

W

!>          W es un array COMPLEX*16, de dimensión (J)
!>          El vector j w.
!>

GAMMA

!>          GAMMA es COMPLEX*16
!>          El elemento diagonal gamma.
!>

SESTPR

!>          SESTPR es DOUBLE PRECISION
!>          Valor singular estimado de la matriz Lhat de (j+1) por (j+1).
!>

S

!>          S es COMPLEX*16
!>          Seno necesario para formar xhat.
!>

C

!>          C es COMPLEX*16
!>          Coseno necesario para formar xhat.
!>
