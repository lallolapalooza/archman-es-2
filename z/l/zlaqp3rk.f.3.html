subrutina zlaqp3rk (integer m, integer n, integer nrhs, integer ioffset, integer nb, double precision abstol, double precision reltol, integer kp1, double precision maxc2nrm, complex*16, dimension( lda, * ) a, integer lda, logical done, integer kb, double precision maxc2nrmk, double precision relmaxc2nrmk, integer, dimension( * ) jpiv, complex*16, dimension( * ) tau, double precision, dimension( * ) vn1, double precision, dimension( * ) vn2, complex*16, dimension( * ) auxv, complex*16, dimension( ldf, * ) f, integer ldf, integer, dimension( * ) iwork, integer info)

ZLAQP3RK calcula un paso de la factorización QR truncada con pivoteo de columnas de una matriz compleja m-por-n A usando BLAS de Nivel 3 y sobrescribe una matriz compleja m-por-nrhs B con Q**H * B.

Propósito:

!>
!> ZLAQP3RK calcula un paso de la factorización QR truncada con pivoteo
!> de columnas de un bloque complejo M-por-N de la matriz A, A(IOFFSET+1:M,1:N),
!> utilizando BLAS de Nivel 3 como
!>
!>   A * P(KB) = Q(KB) * R(KB).
!>
!> La rutina intenta factorizar NB columnas de A comenzando desde la fila
!> IOFFSET+1 y actualiza la matriz residual con BLAS 3 xGEMM. El número de
!> columnas efectivamente factorizadas es devuelto y es menor que NB.
!>
!> El bloque A(1:IOFFSET,1:N) se pivotea en consecuencia, pero no se
!> factoriza.
!>
!> La rutina también sobrescribe las partes derechas B de la matriz almacenada
!> en A(IOFFSET+1:M,1:N+1:N+NRHS) con Q(KB)**H * B.
!>
!> Casos en los que el número de columnas factorizadas KB < NB:
!>
!> (1) En algunos casos, debido a cancelaciones catastróficas, no puede
!> factorizar todas las NB columnas y necesita actualizar la matriz residual.
!> Por lo tanto, el número real de columnas factorizadas en el bloque devuelto
!> en KB es menor que NB. La bandera lógica DONE se devuelve como FALSE.
!> La factorización de la matriz original completa A_orig debe continuar
!> con el siguiente bloque.
!>
!> (2) Siempre que se satisface el criterio de parada ABSTOL o RELTOL,
!> se detiene la factorización de la matriz original completa A_orig,
!> la bandera lógica DONE se devuelve como TRUE. El número de columnas
!> factorizadas, que es menor que NB, se devuelve en KB.
!>
!> (3) En caso de que ambos criterios de parada ABSTOL o RELTOL no se utilicen,
!> y cuando la matriz residual es una matriz cero en algún paso de
!> factorización KB, se detiene la factorización de la matriz original
!> completa A_orig, la bandera lógica DONE se devuelve como TRUE. El número de
!> columnas factorizadas, que es menor que NB, se devuelve en KB.
!>
!> (4) Siempre que se detecta NaN en la matriz A o en el array TAU,
!> se detiene la factorización de la matriz original completa A_orig,
!> la bandera lógica DONE se devuelve como TRUE. El número de columnas
!> factorizadas, que es menor que NB, se devuelve en KB. El parámetro INFO
!> se establece en el índice de columna de la primera ocurrencia de NaN.
!>
!>

Parámetros

M 
!>          M es INTEGER
!>          El número de filas de la matriz A. M >= 0.
!>

N

!>          N es INTEGER
!>          El número de columnas de la matriz A. N >= 0.
!>

NRHS

!>          NRHS es INTEGER
!>          El número de lados derechos, es decir, el número de
!>          columnas de la matriz B. NRHS >= 0.
!>

IOFFSET

!>          IOFFSET es INTEGER
!>          El número de filas de la matriz A que deben pivotearse
!>          pero no factorizarse. IOFFSET >= 0.
!>
!>          IOFFSET también representa el número de columnas de la matriz
!>          original completa A_orig que se han factorizado
!>          en los pasos anteriores.
!>

NB

!>          NB es INTEGER
!>          Tamaño del bloque de factorización, es decir, el número de columnas
!>          a factorizar en la matriz A. 0 <= NB.
!>
!>          Si NB = 0, entonces la rutina sale inmediatamente.
!>             Esto significa que la factorización no se realiza,
!>             las matrices A y B y los arrays TAU, IPIV
!>             no se modifican.
!>

ABSTOL

!>          ABSTOL es DOUBLE PRECISION, no puede ser NaN.
!>
!>          La tolerancia absoluta (umbral de parada) para
!>          la norma 2 de la columna máxima de la matriz residual.
!>          El algoritmo converge (detiene la factorización) cuando
!>          la norma 2 de la columna máxima de la matriz residual
!>          es menor o igual a ABSTOL.
!>
!>          a) Si ABSTOL < 0.0, entonces este criterio de parada no
!>                se utiliza, la rutina factoriza columnas dependiendo
!>                de NB y RELTOL.
!>                Esto incluye el caso ABSTOL = -Inf.
!>
!>          b) Si 0.0 <= ABSTOL, entonces se utiliza el valor de entrada
!>                de ABSTOL.
!>

RELTOL

!>          RELTOL es DOUBLE PRECISION, no puede ser NaN.
!>
!>          La tolerancia (umbral de parada) para la relación de la
!>          norma 2 de la columna máxima de la matriz residual con la
!>          norma 2 de la columna máxima de la matriz original A_orig.
!>          El algoritmo converge (detiene la factorización) cuando
!>          esta relación es menor o igual a RELTOL.
!>
!>          a) Si RELTOL < 0.0, entonces este criterio de parada no
!>                se utiliza, la rutina factoriza columnas dependiendo
!>                de NB y ABSTOL.
!>                Esto incluye el caso RELTOL = -Inf.
!>
!>          d) Si 0.0 <= RELTOL, entonces se utiliza el valor de entrada de RELTOL.
!>

KP1

!>          KP1 es INTEGER
!>          El índice de la columna con la norma 2 máxima en
!>          la matriz original completa A_orig determinado en
!>          la rutina principal ZGEQP3RK. 1 <= KP1 <= N_orig.
!>

MAXC2NRM

!>          MAXC2NRM es DOUBLE PRECISION
!>          La norma 2 de la columna máxima de la matriz original
!>          completa A_orig calculada en la rutina principal ZGEQP3RK.
!>          MAXC2NRM >= 0.
!>

A

!>          A es array COMPLEX*16, dimension (LDA,N+NRHS)
!>          En la entrada:
!>              la matriz A de M-por-N y la matriz B de M-por-NRHS, como en
!>
!>                                  N     NRHS
!>              array_A   =   M  [ mat_A, mat_B ]
!>
!>          En la salida:
!>          1. Los elementos del bloque A(IOFFSET+1:M,1:KB) por debajo
!>             de la diagonal junto con el array TAU representan
!>             la matriz unitaria Q(KB) como un producto de
!>             reflejos elementales.
!>          2. El bloque triangular superior de la matriz A almacenado
!>             en A(IOFFSET+1:M,1:KB) es el factor triangular obtenido.
!>          3. El bloque de la matriz A almacenado en A(1:IOFFSET,1:N)
!>             ha sido pivotado en consecuencia, pero no factorizado.
!>          4. El resto del array A, bloque A(IOFFSET+1:M,KB+1:N+NRHS).
!>             La parte izquierda A(IOFFSET+1:M,KB+1:N) de este bloque
!>             contiene el residuo de la matriz A y,
!>             si NRHS > 0, la parte derecha del bloque
!>             A(IOFFSET+1:M,N+1:N+NRHS) contiene la b

Author

!>          LDA is INTEGER
!>          The leading dimension of the array A. LDA >= max(1,M).
!>

DONE

!>          DONE is LOGICAL
!>          TRUE: a) if the factorization completed before processing
!>                   all min(M-IOFFSET,NB,N) columns due to ABSTOL
!>                   or RELTOL criterion,
!>                b) if the factorization completed before processing
!>                   all min(M-IOFFSET,NB,N) columns due to the
!>                   residual matrix being a ZERO matrix.
!>                c) when NaN was detected in the matrix A
!>                   or in the array TAU.
!>          FALSE: otherwise.
!>

KB

!>          KB is INTEGER
!>          Factorization rank of the matrix A, i.e. the rank of
!>          the factor R, which is the same as the number of non-zero
!>          rows of the factor R.  0 <= KB <= min(M-IOFFSET,NB,N).
!>
!>          KB also represents the number of non-zero Householder
!>          vectors.
!>

MAXC2NRMK

!>          MAXC2NRMK is DOUBLE PRECISION
!>          The maximum column 2-norm of the residual matrix,
!>          when the factorization stopped at rank KB. MAXC2NRMK >= 0.
!>

RELMAXC2NRMK

!>          RELMAXC2NRMK is DOUBLE PRECISION
!>          The ratio MAXC2NRMK / MAXC2NRM of the maximum column
!>          2-norm of the residual matrix (when the factorization
!>          stopped at rank KB) to the maximum column 2-norm of the
!>          original matrix A_orig. RELMAXC2NRMK >= 0.
!>

JPIV

!>          JPIV is INTEGER array, dimension (N)
!>          Column pivot indices, for 1 <= j <= N, column j
!>          of the matrix A was interchanged with column JPIV(j).
!>

TAU

!>          TAU is COMPLEX*16 array, dimension (min(M-IOFFSET,N))
!>          The scalar factors of the elementary reflectors.
!>

VN1

!>          VN1 is DOUBLE PRECISION array, dimension (N)
!>          The vector with the partial column norms.
!>

VN2

!>          VN2 is DOUBLE PRECISION array, dimension (N)
!>          The vector with the exact column norms.
!>

AUXV

!>          AUXV is COMPLEX*16 array, dimension (NB)
!>          Auxiliary vector.
!>

F

!>          F is COMPLEX*16 array, dimension (LDF,NB)
!>          Matrix F**H = L*(Y**H)*A.
!>

LDF

!>          LDF is INTEGER
!>          The leading dimension of the array F. LDF >= max(1,N+NRHS).
!>

IWORK

!>          IWORK is INTEGER array, dimension (N-1).
!>          Is a work array. ( IWORK is used to store indices
!>          of  columns for norm downdating in the residual
!>          matrix ).
!>

INFO

!>          INFO is INTEGER
!>          1) INFO = 0: successful exit.
!>          2) If INFO = j_1, where 1 <= j_1 <= N, then NaN was
!>             detected and the routine stops the computation.
!>             The j_1-th column of the matrix A or the j_1-th
!>             element of array TAU contains the first occurrence
!>             of NaN in the factorization step KB+1 ( when KB columns
!>             have been factorized ).
!>
!>             On exit:
!>             KB                  is set to the number of
!>                                    factorized columns without
!>                                    exception.
!>             MAXC2NRMK           is set to NaN.
!>             RELMAXC2NRMK        is set to NaN.
!>             TAU(KB+1:min(M,N))     is not set and contains undefined
!>                                    elements. If j_1=KB+1, TAU(KB+1)
!>                                    may contain NaN.
!>          3) If INFO = j_2, where N+1 <= j_2 <= 2*N, then no NaN
!>             was detected, but +Inf (or -Inf) was detected and
!>             the routine continues the computation until completion.
!>             The (j_2-N)-th column of the matrix A contains the first
!>             occurrence of +Inf (or -Inf) in the actorization
!>             step KB+1 ( when KB columns have been factorized ).
!>
