Funciones/Subrutinas


subroutine zlarfb_gett (ident, m, n, k, t, ldt, a, lda, b, ldb, work, ldwork)
ZLARFB_GETT

Documentación de la función/subrutina

subrutina zlarfb_gett (character ident, integer m, integer n, integer k, complex*16, dimension( ldt, * ) t, integer ldt, complex*16, dimension( lda, * ) a, integer lda, complex*16, dimension( ldb, * ) b, integer ldb, complex*16, dimension( ldwork, * ) work, integer ldwork)

ZLARFB_GETT

Propósito:

!>
!> ZLARFB_GETT aplica un bloque reflector de Householder complejo H desde la
!> izquierda a una matriz K+M por N compleja
!> compuesta por dos matrices de bloque: una matriz A K por N trapezoidal superior
!> almacenada en el array A, y una matriz rectangular B M por (N-K), almacenada
!> en el array B. El reflector de bloque H se almacena en una representación
!> compacta WY, donde los reflectores elementales están en los
!> arrays A, B y T. Ver la sección Detalles adicionales.
!>

Parámetros

IDENT 
!>          IDENT es CHARACTER*1
!>          Si IDENT = no 'I', o no 'i', entonces V1 es unitaria
!>             triangular inferior y almacenada en el bloque K por K de
!>             la matriz de entrada A,
!>          Si IDENT = 'I' o 'i', entonces V1 es una matriz identidad y
!>             no se almacena.
!>          Ver la sección Detalles adicionales.
!>

M

!>          M es INTEGER
!>          El número de filas de la matriz B.
!>          M >= 0.
!>

N

!>          N es INTEGER
!>          El número de columnas de las matrices A y B.
!>          N >= 0.
!>

K

!>          K es INTEGER
!>          El número de filas de la matriz A.
!>          K es también el orden de la matriz T, es decir, el número de
!>          reflectores elementales cuyo producto define el bloque
!>          reflector. 0 <= K <= N.
!>

T

!>          T es COMPLEX*16 array, dimension (LDT,K)
!>          La matriz triangular superior T K por K en la representación
!>          del reflector de bloque.
!>

LDT

!>          LDT es INTEGER
!>          La dimensión principal del array T. LDT >= K.
!>

A

!>          A es COMPLEX*16 array, dimension (LDA,N)
!>
!>          En la entrada:
!>           a) En la parte trapezoidal superior K por N, A: matriz de entrada A.
!>           b) En las columnas debajo de la diagonal: columnas de V1
!>              (los unos no se almacenan en la diagonal).
!>
!>          En la salida:
!>            A se sobrescribe con el producto rectangular K por N H*A.
!>
!>          Ver la sección Detalles adicionales.
!>

LDA

!>          LDB es INTEGER
!>          La dimensión principal del array A. LDA >= max(1,K).
!>

B

!>          B es COMPLEX*16 array, dimension (LDB,N)
!>
!>          En la entrada:
!>            a) En el bloque derecho M por (N-K): matriz de entrada B.
!>            b) En el bloque izquierdo M por N: columnas de V2.
!>
!>          En la salida:
!>            B se sobrescribe con el producto rectangular M por N H*B.
!>
!>          Ver la sección Detalles adicionales.
!>

LDB

!>          LDB es INTEGER
!>          La dimensión principal del array B. LDB >= max(1,M).
!>

WORK

!>          WORK es COMPLEX*16 array,
!>          dimension (LDWORK,max(K,N-K))
!>

LDWORK

!>          LDWORK es INTEGER
!>          La dimensión principal del array WORK. LDWORK>=max(1,K).
!>
!>

Detalles adicionales:

!>
!>    (1) Descripción de la Operación Algebraica.
!>
!>    La matriz A es una matriz K por N compuesta por dos matrices de bloque
!>    de columnas, A1, que es K por K, y A2, que es K por (N-K):
!>    A = ( A1, A2 ).
!>    La matriz B es una matriz M por N compuesta por dos matrices de bloque
!>    de columnas, B1, que es M por K, y B2, que es M por (N-K):
!>    B = ( B1, B2 ).
!>
!>    Realiza la operación:
!>
!>       ( A_salida ) := H * ( A_entrada ) = ( I - V * T * V**H ) * ( A_entrada ) =
!>       ( B_salida )        ( B_entrada )                          ( B_entrada )
!>                  = ( I - ( V1 ) * T * ( V1**H, V2**H ) ) * ( A_entrada )
!>                          ( V2 )                            ( B_entrada )
!>     En la entrada:
!>
!>    a) ( A_entrada ) consiste en dos bloques de columnas:
!>       ( B_entrada )
!>
!>       ( A_entrada ) = (( A1_entrada ) ( A2_entrada )) = (( A1_entrada ) ( A2_entrada ))
!>       ( B_entrada )   (( B1_entrada ) ( B2_entrada ))   ((     0 ) ( B2_entrada )),
!>
!>       donde los bloques de columnas son:
!>
!>       (  A1_entrada )  es una matriz triangular superior K por K almacenada en
!>                   la parte triangular superior del array A(1:K,1:K).
!>       (  B1_entrada )  es una matriz CERO rectangular M por K y no se almacena.
!>
!>       ( A2_entrada )  es una matriz rectangular K por (N-K) almacenada
!>                  en el array A(1:K,K+1:N).
!>       ( B2_entrada )  es una matriz rectangular M por (N-K) almacenada
!>                  en el array B(1:M,K+1:N).
!>
!>    b) V = ( V1 )
!>           ( V2 )
!>
!>       donde:
!>       1) si IDENT == 'I', V1 es una matriz identidad K por K, no almacenada;
!>       2) si IDENT != 'I', V1 es una matriz triangular inferior unitaria K por K,
!>          almacenada en la parte triangular inferior del array
!>          A(1:K,1:K) (los unos no se almacenan),
!>       y V2 es una matriz rectangular M por K almacenada en el array
!>                 B(1:M,1:K),
!>                 (porque en la entrada B1_entrada es una matriz cero rectangular
!>                  que no se almacena y el espacio se usa para almacenar V2).
!>
!>    c) T es una matriz triangular superior K por K almacenada
!>       en el array T(1:K,1:K).
!>
!>    En la salida:
!>
!>    a) ( A_salida ) consiste en dos bloques de columnas:
!>       ( B_salida )
!>
!>       ( A_salida ) = (( A1_salida ) ( A2_salida ))
!>       ( B_salida )   (( B1_salida ) ( B2_salida )),
!>
!>       donde los bloques de columnas son:
!>
!>       ( A1_salida )  es una matriz cuadrada K por K, o una matriz
!>                   triangular superior K por K, si V1 es una
!>                   matriz identidad. AiSalida se almacena en
!>                   el array A(1:K,1:K).
!>       ( B1_salida )  es una matriz rectangular M por K almacenada
!>                   en el array B(1:M,K:N).
!>
!>       ( A2_salida )  es una matriz rectangular K por (N-K) almacenada
!>                   en el array A(1:K,K+1:N).
!>       ( B2_salida )  es una matriz rectangular M por (N-K) almacenada
!>                   en el array B(1:M,K+1:N).
!>
!>
!>    La operación anterior se puede representar como la misma operación
!>    en cada bloque de columnas:
!>
!>       ( A1_salida ) := H * ( A1_entrada ) = ( I - V * T * V**H ) * ( A1_entrada )
!>       ( B1_salida )        (     0 )                          (     0 )
!>
!>       ( A2_salida ) := H * ( A2_entrada ) = ( I - V * T * V**H ) * ( A2_entrada )
!>       ( B2_salida )        ( B2_entrada )                          ( B2_entrada )
!>
!>    Si IDENT != 'I':
!>
!>       El cálculo para el bloque de columnas 1:
!>
!>       A1_salida: = A1_entrada - V1*T*(V1**H)*A1_entrada
!>
!>       B1_salida: = - V2*T*(V1**H)*A1_entrada
!>
!>       El cálculo para el bloque de columnas 2, que existe si N > K:
!>
!>       A2_salida: = A2_entrada - V1*T*( (V1**H)*A2_entrada + (V2**H)*B2_entrada )
!>
!>       B2_salida: = B2_entrada - V2*T*( (V1**H)*A2_entrada + (V2**H)*B2_entrada )
!>
!>    Si IDENT == 'I':
!>
!>       La operación para el bloque de columnas 1:
!>
!>       A1_salida: = A1_entrada - V1*T*A1_entrada
!>
!>       B1_salida: = - V2*T*A1_entrada
!>
!>       El cálculo para el bloque de columnas 2, que existe si N > K:
!>
!>       A2_salida: = A2_entrada - V1*T*( (V1**H)*A2_entrada + (V2**H)*B2_entrada )
!>
!>       B2_salida: = B2_entrada - V2*T*( (V1**H)*A2_entrada + (V2**H)*B2_entrada )
!>
!>    (2) Nota sobre la eficiencia:
!>
!>    Para maximizar la eficiencia, se debe elegir el array WORK de modo que
!!>    LDWORK sea igual a K. El número de columnas de WORK debe ser max(K,N-K).
!>
!>    (3) Advertencia:
!>
!>    La matriz A es un K por N matriz. El array A tiene N columnas.
!>    Las primeras K columnas de A se utilizan para almacenar la parte
!>    superior de la matriz de entrada A, y para almacenar la matriz V1 si
!>    IDENT = 'N'. Las columnas de A de K+1 a N se utilizan para almacenar
!>    la parte superior de la matriz de entrada A.
!>
!>    La matriz B es una matriz M por N. El array B tiene N columnas.
!>    Las primeras K columnas de B se utilizan para almacenar la matriz V2.
!>    Las columnas de B de K+1 a N se utilizan para almacenar la matriz
!>    de entrada B.
!>
!>    El usuario debe asegurarse de que la matriz V1 (si se almacena en A)
!>    y la matriz V2 (almacenada en B) se pasan correctamente a esta
!>    subrutina. La subrutina ZLARFB_GETT espera que la matriz V1 este
!>    almacenada en la parte triangular inferior de A(1:K,1:K) (con unos
!>    en la diagonal, que no se almacenan), y que la matriz V2 este
!>    almacenada en B(1:M,1:K).
!>
!>    La subrutina ZLARFB_GETT aplica el operador H a A y B.
!>    Si IDENT = 'I', la matriz V1 es la matriz identidad y no se almacena.
!>    En este caso, el usuario solo necesita asegurarse de que A(1:K,1:K)
!>    contiene la parte triangular superior de la matriz de entrada A.
!>
!>    Si IDENT = 'N', la matriz V1 es una matriz triangular inferior unitaria
!>    y se almacena en la parte triangular inferior de A(1:K,1:K) (con unos
!>    en la diagonal, que no se almacenan).
!>
!>    Si la operación se realiza en dos pasos, la primera llamada a
!>    ZLARFB_GETT para aplicar H a A(1:K,1:K) y B(1:M,1:K) escribirá
!>    el resultado en A(1:K,1:K) y B(1:M,1:K). La segunda llamada a
!>    ZLARFB_GETT para aplicar H a A(1:K,K+1:N) y B(1:M,K+1:N) escribirá
!>    el resultado en A(1:K,K+1:N) y B(1:M,K+1:N).
!>
!>    Es responsabilidad del usuario organizar los datos de entrada para
!>    que se ajusten a los requisitos de almacenamiento de esta subrutina.
!>
!>    (4) Consideraciones sobre el formato WY:
!>
!>    El formato WY es una forma de representar un producto de
!>    reflectores de Householder en forma compacta. En este caso,
!>    la matriz H se representa como H = I - V*T*V**H, donde V es una
!>    matriz cuyas columnas son los vectores de Householder, y T es
!>    una matriz triangular superior. Esta subrutina aplica H a una
!>    matriz dada.
!>
!>    Referencia:
!>    [1] D. D. Szyld y G. W. Stewart, "Approximating the inverse
!>        of a matrix by block factorizations", SIAM J. Sci. Comput.,
!>        Vol. 18, No. 6, pp. 1658-1673, 1997.
!>
!>    [2] J. Demmel, "Applied Numerical Linear Algebra", SIAM, 1997.
!>
!>    (5) Posibles errores:
!>
!>    - Si K < 0, K > N, M < 0, LDA < max(1,K), LDB < max(1,M), LDT < K,
!>      o LDWORK < max(1,K), la subrutina podría comportarse de
!>      manera indefinida.
!>    - Si IDENT no es 'I', 'i', 'N', o 'n', el comportamiento es indefinido.
!>
!>

NAME

zlarfb_gett - Provides the documentation for the subroutine ZLARFB.

SYNOPSIS

    SUBROUTINE ZLARFB( SIDE, TRANS, DIRECT, REORTH, K, L, FACT,     &
!>                       V, LDV, T, LDT, C, LDC, WORK, LDWORK )
!>
!>       CHARACTER * 1   SIDE
!>       CHARACTER * 1   TRANS
!>       CHARACTER * 1   DIRECT
!>       CHARACTER * 1   REORTH
!>       INTEGER         K
!>       INTEGER         L
!>       CHARACTER * 1   FACT
!>       COMPLEX*16      V( LDV, * )
!>       INTEGER         LDV
!>       COMPLEX*16      T( LDT, * )
!>       INTEGER         LDT
!>       COMPLEX*16      C( LDC, * )
!>       INTEGER         LDC
!>       COMPLEX*16      WORK( LDWORK, * )
!>       INTEGER         LDWORK
!>
!>       -- CALL ZLARFB( SIDE, TRANS, DIRECT, REORTH, K, L, FACT,     &
!>      --              V, LDV, T, LDT, C, LDC, WORK, LDWORK )
!>

Function/Subroutine Documentation

!>    Purpose
!>    =======
!>
!>    ZLARFB applies a real block triangular matrix factor R, or its transpose R**H, to a
!>    complex general rectangular matrix C.
!>
!>    R is a k x k matrix.
!>    The matrix V is a n x k matrix.
!>    The matrix T is a k x k matrix.
!>    The matrix C is a m x n matrix.
!>
!>    The matrix R is given by
!>
!>       R = [ I ]
!>           [ V ]
!>
!>    or
!>
!>       R = [ V ]
!>           [ I ]
!>
!>    The matrix R is updated from
!>
!>       R := TRIU( V ) * T
!>
!>    or
!>
!>       R := tril( V ) * T
!>
!>    In the cases when SIDE = 'L' or SIDE = 'R', the matrix V is not needed.
!>
!>    The matrix T is a triangular block factor.
!>    The orthogonal matrix Q is computed from the QR decomposition of V
!>    or LQ decomposition of V.
!>
!>    If DIRECT = 'F', V is a block reflector from the left.
!>    If DIRECT = 'B', V is a block reflector from the right.
!>
!>    If TRANS = 'N', R is not transposed.
!>    If TRANS = 'C', R is transposed.
!>
!>    If REORTH = 'R', V is refreshed.
!>    If REORTH = 'N', V is not refreshed.
!>
!>    If FACT = 'F', V is assumed to be factored.
!>    If FACT = 'N', V is not factored.
!>
!>    The algorithm
!>    ===========
!>
!>    The subroutine ZLARFB applies the block reflector R to the matrix C.
!>    The update is in the form
!>
!>        C := R * C  if SIDE = 'L'
!>
!>        C := C * R  if SIDE = 'R'
!>
!>    where R is the k x k block reflector given by
!>
!>        R = [ I ]
!>            [ V ]
!>
!>    or
!>
!>        R = [ V ]
!>            [ I ]
!>
!>    Here V is a n x k matrix.
!>
!>    The matrix R is defined implicitly by V and T.
!>    Let V be a m x k matrix.
!>
!>    If SIDE = 'L' and DIRECT = 'F' and TRANS = 'N', then
!>        C[1:k,:] = C[1:k,:] - V * (T * (V**H * C[1:m,:]))
!>        C[k+1:m,:] = C[k+1:m,:] - V * (T * (V**H * C[1:m,:]))
!>    If SIDE = 'L' and DIRECT = 'B' and TRANS = 'N', then
!>        C[1:m,:] = C[1:m,:] - V * (T * (V**H * C[k+1:m,:]))
!>    If SIDE = 'R' and DIRECT = 'F' and TRANS = 'N', then
!>        C[:,1:k] = C[:,1:k] - (C[:,1:k] * V) * T * V**H
!>        C[:,k+1:n] = C[:,k+1:n] - (C[:,k+1:n] * V) * T * V**H
!>
!>    The calculation is done using the formula
!>
!>    A2_out: = A2_in - T*( A2_in + (V2**H)*B2_in )
!>
!>    B2_out: = B2_in - V2*T*( A2_in + (V2**H)*B2_in )
!>
!>    (2) Description of the Algorithmic Computation.
!>
!>    In the first step, we compute column block 2, i.e. A2 and B2.
!>    Here, we need to use the K-by-(N-K) rectangular workspace
!>    matrix W2 that is of the same size as the matrix A2.
!>    W2 is stored in the array WORK(1:K,1:(N-K)).
!>
!>    In the second step, we compute column block 1, i.e. A1 and B1.
!>    Here, we need to use the K-by-K square workspace matrix W1
!>    that is of the same size as the as the matrix A1.
!>    W1 is stored in the array WORK(1:K,1:K).
!>
!>    NOTE: Hence, in this routine, we need the workspace array WORK
!>    only of size WORK(1:K,1:max(K,N-K)) so it can hold both W2 from
!>    the first step and W1 from the second step.
!>
!>    Case (A), when V1 is unit lower-triangular, i.e. IDENT != 'I',
!>    more computations than in the Case (B).
!>
!>    if( IDENT != 'I' ) then
!>     if ( N > K ) then
!>       (First Step - column block 2)
!>       col2_(1) W2: = A2
!>       col2_(2) W2: = (V1**H) * W2 = (unit_lower_tr_of_(A1)**H) * W2
!>       col2_(3) W2: = W2 + (V2**H) * B2 = W2 + (B1**H) * B2
!>       col2_(4) W2: = T * W2
!>       col2_(5) B2: = B2 - V2 * W2 = B2 - B1 * W2
!>       col2_(6) W2: = V1 * W2 = unit_lower_tr_of_(A1) * W2
!>       col2_(7) A2: = A2 - W2
!>     else
!>       (Second Step - column block 1)
!>       col1_(1) W1: = A1
!>       col1_(2) W1: = (V1**H) * W1 = (unit_lower_tr_of_(A1)**H) * W1
!>       col1_(3) W1: = T * W1
!>       col1_(4) B1: = - V2 * W1 = - B1 * W1
!>       col1_(5) square W1: = V1 * W1 = unit_lower_tr_of_(A1) * W1
!>       col1_(6) square A1: = A1 - W1
!>     end if
!>    end if
!>
!>    Case (B), when V1 is an identity matrix, i.e. IDENT == 'I',
!>    less computations than in the Case (A)
!>
!>    if( IDENT == 'I' ) then
!>     if ( N > K ) then
!>       (First Step - column block 2)
!>       col2_(1) W2: = A2
!>       col2_(3) W2: = W2 + (V2**H) * B2 = W2 + (B1**H) * B2
!>       col2_(4) W2: = T * W2
!>       col2_(5) B2: = B2 - V2 * W2 = B2 - B1 * W2
!>       col2_(7) A2: = A2 - W2
!>     else
!>       (Second Step - column block 1)
!>       col1_(1) W1: = A1
!>       col1_(3) W1: = T * W1
!>       col1_(4) B1: = - V2 * W1 = - B1 * W1
!>       col1_(6) upper-triangular_of_(A1): = A1 - W1
!>     end if
!>    end if
!>
!>    Combine these cases (A) and (B) together, this is the resulting
!>    algorithm:
!>
!>    if ( N > K ) then
!>
!>      (First Step - column block 2)
!>
!>      col2_(1)  W2: = A2
!>      if( IDENT != 'I' ) then
!>        col2_(2)  W2: = (V1**H) * W2
!>                      = (unit_lower_tr_of_(A1)**H) * W2
!>      end if
!>      col2_(3)  W2: = W2 + (V2**H) * B2 = W2 + (B1**H) * B2]
!>      col2_(4)  W2: = T * W2
!>      col2_(5)  B2: = B2 - V2 * W2 = B2 - B1 * W2
!>      if( IDENT != 'I' ) then
!>        col2_(6)    W2: = V1 * W2 = unit_lower_tr_of_(A1) * W2
!>      end if
!>      col2_(7) A2: = A2 - W2
!>
!>    else
!>
!>    (Second Step - column block 1)
!>
!>      col1_(1) W1: = A1
!>      if( IDENT != 'I' ) then
!>        col1_(2) W1: = (V1**H) * W1
!>                    = (unit_lower_tr_of_(A1)**H) * W1
!>      end if
!>      col1_(3) W1: = T * W1
!>      col1_(4) B1: = - V2 * W1 = - B1 * W1
!>      if( IDENT != 'I' ) then
!>        col1_(5) square W1: = V1 * W1 = unit_lower_tr_of_(A1) * W1
!>        col1_(6_a) below_diag_of_(A1): =  - below_diag_of_(W1)
!>      end if
!>      col1_(6_b) up_tr_of_(A1): = up_tr_of_(A1) - up_tr_of_(W1)
!>
!>    end if
!>
