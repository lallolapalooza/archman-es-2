Funciones/Subrutinas


función double precision zlansp (norm, uplo, n, ap, work)
ZLANSP devuelve el valor de la norma 1, o la norma de Frobenius, o la norma infinito, o el elemento de mayor valor absoluto de una matriz simétrica suministrada en formato empaquetado.

Documentación de la Función/Subrutina

función double precision zlansp (carácter norm, carácter uplo, entero n, complejo*16, dimensión( * ) ap, doble precisión, dimensión( * ) work)

ZLANSP devuelve el valor de la norma 1, o la norma de Frobenius, o la norma infinito, o el elemento de mayor valor absoluto de una matriz simétrica compleja A, suministrada en formato empaquetado.

Propósito:

!>
!> ZLANSP  devuelve el valor de la norma uno,  o la norma de Frobenius, o
!> la  norma de infinito,  o el  elemento de  mayor valor absoluto  de una
!> matriz simétrica compleja A,  suministrada en formato empaquetado.
!>

Devuelve

ZLANSP 
!>
!>    ZLANSP = ( max(abs(A(i,j))), NORM = 'M' o 'm'
!>             (
!>             ( norm1(A),         NORM = '1', 'O' o 'o'
!>             (
!>             ( normI(A),         NORM = 'I' o 'i'
!>             (
!>             ( normF(A),         NORM = 'F', 'f', 'E' o 'e'
!>
!> donde  norm1  denota la  norma uno de una matriz (suma máxima de columna),
!> normI  denota la  norma de infinito  de una matriz  (suma máxima de fila) y
!> normF  denota la  norma de Frobenius  de una matriz (raíz cuadrada de la suma de
!> cuadrados).  Tenga en cuenta que  max(abs(A(i,j)))  no es una norma matricial
!> consistente.
!>

Parámetros

NORM 
!>          NORM es CHARACTER*1
!>          Especifica el valor a devolver en ZLANSP tal como se describe
!>          arriba.
!>

UPLO

!>          UPLO es CHARACTER*1
!>          Especifica si se suministra la parte triangular superior o
!>          inferior de la matriz simétrica A.
!>          = 'U':  Se suministra la parte triangular superior de A
!>          = 'L':  Se suministra la parte triangular inferior de A
!>

N

!>          N es INTEGER
!>          El orden de la matriz A.  N >= 0.  Cuando N = 0, ZLANSP se
!>          establece a cero.
!>

AP

!>          AP es un array COMPLEX*16, de dimensión (N*(N+1)/2)
!>          La parte triangular superior o inferior de la matriz simétrica A,
!>          empaquetada por columnas en un array lineal. La j-ésima columna
!>          de A se almacena en el array AP como sigue:
!>          si UPLO = 'U', AP(i + (j-1)*j/2) = A(i,j) para 1<=i<=j;
!>          si UPLO = 'L', AP(i + (j-1)*(2n-j)/2) = A(i,j) para j<=i<=n.
!>

WORK

!>          WORK es un array DOUBLE PRECISION, de dimensión (MAX(1,LWORK)),
!>          donde LWORK >= N cuando NORM = 'I' o '1' o 'O'; de lo contrario,
!>          WORK no se referencia.
!>
