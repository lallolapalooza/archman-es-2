subrutina zlattr (integer imat, character uplo, character trans, character diag, integer, dimension( 4 ) iseed, integer n, complex*16, dimension( lda, * ) a, integer lda, complex*16, dimension( * ) b, complex*16, dimension( * ) work, double precision, dimension( * ) rwork, integer info)

ZLATTR

Propósito:

!>
!> ZLATTR genera una matriz de prueba triangular en almacenamiento bidimensional.
!> IMAT y UPLO especifican de forma única las propiedades de la matriz de prueba,
!> que se devuelve en la matriz A.
!>

Parámetros

IMAT 
!>          IMAT es ENTERO
!>          Una clave entera que describe qué matriz generar para esta
!>          ruta.
!>

UPLO

!>          UPLO es CHARACTER*1
!>          Especifica si la matriz A será superior o inferior
!>          triangular.
!>          = 'U':  Triangular superior
!>          = 'L':  Triangular inferior
!>

TRANS

!>          TRANS es CHARACTER*1
!>          Especifica si se usará la matriz o su transpuesta.
!>          = 'N':  Sin transponer
!>          = 'T':  Transpuesta
!>          = 'C':  Transpuesta conjugada
!>

DIAG

!>          DIAG es CHARACTER*1
!>          Especifica si la matriz A es unitriangular o no.
!>          = 'N':  Triangular no unitaria
!>          = 'U':  Triangular unitaria
!>

ISEED

!>          ISEED es una matriz ENTERA, de dimensión (4)
!>          El vector semilla para el generador de números aleatorios (usado en
!>          ZLATMS).  Modificado al salir.
!>

N

!>          N es ENTERO
!>          El orden de la matriz a generar.
!>

A

!>          A es una matriz COMPLEX*16, de dimensión (LDA,N)
!>          La matriz triangular A. Si UPLO = 'U', la parte triangular
!>          superior N x N líder de la matriz A contiene la matriz
!>          triangular superior, y la parte estrictamente triangular inferior
!>          de A no se referencia. Si UPLO = 'L', la parte triangular
!>          inferior N x N líder de la matriz A contiene la matriz
!>          triangular inferior y la parte estrictamente triangular superior
!>          de A no se referencia.
!>

LDA

!>          LDA es ENTERO
!>          La dimensión líder de la matriz A.  LDA >= max(1,N).
!>

B

!>          B es una matriz COMPLEX*16, de dimensión (N)
!>          El vector del lado derecho, si IMAT > 10.
!>

WORK

!>          WORK es una matriz COMPLEX*16, de dimensión (2*N)
!>

RWORK

!>          RWORK es una matriz DOUBLE PRECISION, de dimensión (N)
!>

INFO

!>          INFO es ENTERO
!>          = 0:  salida exitosa
!>          < 0:  si INFO = -i, el i-ésimo argumento tenía un valor ilegal
!>
