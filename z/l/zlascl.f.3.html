Funciones/Subrutinas


subrutina zlascl (tipo, kl, ku, cfrom, cto, m, n, a, lda, info)
ZLASCL multiplica una matriz rectangular general por un escalar real definido como cto/cfrom.

Documentación de Función/Subrutina

subrutina zlascl (carácter tipo, entero kl, entero ku, doble precisión cfrom, doble precisión cto, entero m, entero n, complejo*16, dimensión( lda, * ) a, entero lda, entero info)

ZLASCL multiplica la matriz compleja M por N, A, por el escalar real CTO/CFROM. Esto se hace sin desbordamiento superior/inferior siempre que el resultado final CTO*A(I,J)/CFROM no desborde superior o inferiormente. TYPE especifica que A puede ser completa, triangular superior, triangular inferior, upperHessenberg, o de banda.

Propósito:

!>
!> ZLASCL multiplica la matriz compleja M por N, A, por el escalar real
!> CTO/CFROM.  Esto se hace sin desbordamiento superior/inferior siempre que el
!> resultado final CTO*A(I,J)/CFROM no desborde superior o inferiormente. TYPE especifica que
!> A puede ser completa, triangular superior, triangular inferior,
!> upperHessenberg, o de banda.
!>

Parámetros

TIPO 
!>          TIPO es CHARACTER*1
!>          TYPE indica el tipo de almacenamiento de la matriz de entrada.
!>          = 'G':  A es una matriz completa.
!>          = 'L':  A es una matriz triangular inferior.
!>          = 'U':  A es una matriz triangular superior.
!>          = 'H':  A es una matriz upperHessenberg.
!>          = 'B':  A es una matriz de banda simétrica con ancho de banda inferior KL
!>                  y ancho de banda superior KU y con solo la mitad inferior almacenada.
!>          = 'Q':  A es una matriz de banda simétrica con ancho de banda inferior KL
!>                  y ancho de banda superior KU y con solo la mitad superior almacenada.
!>          = 'Z':  A es una matriz de banda con ancho de banda inferior KL y superior
!>                  KU. Ver ZGBTRF para detalles de almacenamiento.
!>

KL

!>          KL es ENTERO
!>          El ancho de banda inferior de A.  Referenciado solo si TIPO = 'B',
!>          'Q' o 'Z'.
!>

KU

!>          KU es ENTERO
!>          El ancho de banda superior de A.  Referenciado solo si TIPO = 'B',
!>          'Q' o 'Z'.
!>

CFROM

!>          CFROM es DOBLE PRECISIÓN
!>

CTO

!>          CTO es DOBLE PRECISIÓN
!>
!>          La matriz A se multiplica por CTO/CFROM. A(I,J) se calcula
!>          sin desbordamiento/subdesbordamiento si el resultado final CTO*A(I,J)/CFROM
!>          se puede representar sin desbordamiento/subdesbordamiento.  CFROM debe
!>          ser distinto de cero.
!>

M

!>          M es ENTERO
!>          El número de filas de la matriz A.  M >= 0.
!>

N

!>          N es ENTERO
!>          El número de columnas de la matriz A.  N >= 0.
!>

A

!>          A es un array COMPLEX*16, dimensión (LDA,N)
!>          La matriz a multiplicar por CTO/CFROM. Ver TIPO para el
!>          tipo de almacenamiento.
!>

LDA

!>          LDA es ENTERO
!>          La dimensión principal del array A.
!>          Si TIPO = 'G', 'L', 'U', 'H', LDA >= max(1,M);
!>             TIPO = 'B', LDA >= KL+1;
!>             TIPO = 'Q', LDA >= KU+1;
!>             TIPO = 'Z', LDA >= 2*KL+KU+1.
!>

INFO

!>          INFO es ENTERO
!>          0  - salida exitosa
!>          <0 - si INFO = -i, el i-ésimo argumento tenía un valor ilegal.
!>
