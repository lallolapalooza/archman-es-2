subroutine zlaed8 (integer k, integer n, integer qsiz, complex*16, dimension( ldq, * ) q, integer ldq, double precision, dimension( * ) d, double precision rho, integer cutpnt, double precision, dimension( * ) z, double precision, dimension( * ) dlambda, complex*16, dimension( ldq2, * ) q2, integer ldq2, double precision, dimension( * ) w, integer, dimension( * ) indxp, integer, dimension( * ) indx, integer, dimension( * ) indxq, integer, dimension( * ) perm, integer givptr, integer, dimension( 2, * ) givcol, double precision, dimension( 2, * ) givnum, integer info)

ZLAED8 utilizado por ZSTEDC. Combina valores propios y descompone la ecuación secular. Utilizado cuando la matriz original es densa.

Propósito:

!>
!> ZLAED8 combina los dos conjuntos de valores propios en un único
!> conjunto ordenado. Luego intenta descomponer el problema.
!> Hay dos formas en que puede ocurrir la descomposición: cuando dos o más
!> valores propios están juntos o si hay un elemento diminuto en el
!> vector Z. Por cada ocurrencia de este tipo, el orden del problema de
!> la ecuación secular relacionada se reduce en uno.
!>

Parámetros

K 
!>          K es INTEGER
!>         Contiene el número de valores propios no descompuestos.
!>         Este es el orden del problema de la ecuación secular relacionada.
!>

N

!>          N es INTEGER
!>         La dimensión de la matriz tridiagonal simétrica.  N >= 0.
!>

QSIZ

!>          QSIZ es INTEGER
!>         La dimensión de la matriz unitaria utilizada para reducir
!>         la matriz densa o de banda a forma tridiagonal.
!>         QSIZ >= N si ICOMPQ = 1.
!>

Q

!>          Q es un array COMPLEX*16, dimension (LDQ,N)
!>         En la entrada, Q contiene los vectores propios del sistema
!>         parcialmente resuelto que ha sido previamente actualizado en
!>         multiplicaciones matriciales con otros sistemas propios
!>         parcialmente resueltos.
!>         En la salida, Q contiene los últimos N-K vectores propios
!>         actualizados (aquellos que fueron descompuestos) en sus últimas
!>         N-K columnas.
!>

LDQ

!>          LDQ es INTEGER
!>         La dimensión principal del array Q.  LDQ >= max( 1, N ).
!>

D

!>          D es un array DOUBLE PRECISION, dimension (N)
!>         En la entrada, D contiene los valores propios de las dos submatrices
!>         a combinar. En la salida, D contiene los últimos N-K valores
!>         propios actualizados (aquellos que fueron descompuestos) ordenados
!>         en orden ascendente.
!>

RHO

!>          RHO es DOUBLE PRECISION
!>         Contiene el elemento fuera de la diagonal asociado con el corte de
!>         rango 1 que originalmente dividió las dos submatrices que ahora
!>         se están combinando. RHO se modifica durante el cálculo al valor
!>         requerido por DLAED3.
!>

CUTPNT

!>          CUTPNT es INTEGER
!>         Contiene la ubicación del último valor propio en la submatriz
!>         principal.  MIN(1,N) <= CUTPNT <= N.
!>

Z

!>          Z es un array DOUBLE PRECISION, dimension (N)
!>         En la entrada, este vector contiene el vector de actualización (la
!>         última fila de la primera matriz de sub-vectores propios y la
!>         primera fila de la segunda matriz de sub-vectores propios). Los
!>         contenidos de Z se destruyen durante el proceso de actualización.
!>

DLAMBDA

!>          DLAMBDA es un array DOUBLE PRECISION, dimension (N)
!>         Contiene una copia de los primeros K valores propios que se
!>         utilizarán en DLAED3 para formar la ecuación secular.
!>

Q2

!>          Q2 es un array COMPLEX*16, dimension (LDQ2,N)
!>         Si ICOMPQ = 0, Q2 no se referencia. De lo contrario,
!>         Contiene una copia de los primeros K vectores propios que se
!>         utilizarán en DLAED7 en una multiplicación matricial (DGEMM)
!>         para actualizar los nuevos vectores propios.
!>

LDQ2

!>          LDQ2 es INTEGER
!>         La dimensión principal del array Q2.  LDQ2 >= max( 1, N ).
!>

W

!>          W es un array DOUBLE PRECISION, dimension (N)
!>         Aquí se almacenarán los primeros k valores del vector z
!>         alterado por descomposición final y se pasará a DLAED3.
!>

INDXP

!>          INDXP es un array INTEGER, dimension (N)
!>         Contendrá la permutación utilizada para colocar los valores
!>         descompuestos de D al final del array. En la salida, INDXP(1:K)
!>         apunta a los valores D no descompuestos y INDXP(K+1:N)
!>         apunta a los valores propios descompuestos.
!>

INDX

!>          INDX es un array INTEGER, dimension (N)
!>         Contendrá la permutación utilizada para ordenar los contenidos
!>         de D en orden ascendente.
!>

INDXQ

!>          INDXQ es un array INTEGER, dimension (N)
!>         Contiene la permutación que ordena por separado los dos
!>         subproblemas en D en orden ascendente.  Tenga en cuenta que los
!>         elementos de la segunda mitad de esta permutación deben tener
!>         CUTPNT añadido a sus valores para ser precisos.
!>

PERM

!>          PERM es un array INTEGER, dimension (N)
!>         Contiene las permutaciones (de descomposición y ordenación)
!>         que se aplicarán a cada bloque propio.
!>

GIVPTR

!>          GIVPTR es INTEGER
!>         Contiene el número de rotaciones de Givens que tuvieron lugar en
!>         este subproblema.
!>

GIVCOL

!>          GIVCOL es un array INTEGER, dimension (2, N)
!>         Cada par de números indica un par de columnas que participarán
!>         en una rotación de Givens.
!>

GIVNUM

!>          GIVNUM es un array DOUBLE PRECISION, dimension (2, N)
!>         Cada número indica el valor S que se utilizará en la
!>         rotación de Givens correspondiente.
!>

INFO

!>          INFO es INTEGER
!>          = 0:  salida exitosa.
!>          < 0:  si INFO = -i, el i-ésimo argumento tuvo un valor ilegal.
!>
