subrutina zlalsd (carácter uplo, entero smlsiz, entero n, entero nrhs, doble precisión, dimensión( * ) d, doble precisión, dimensión( * ) e, complejo*16, dimensión( ldb, * ) b, entero ldb, doble precisión rcond, entero rank, complejo*16, dimensión( * ) work, doble precisión, dimensión( * ) rwork, entero, dimensión( * ) iwork, entero info)

ZLALSD usa la descomposición en valores singulares de A para resolver el problema de mínimos cuadrados.

Propósito:

!>
!> ZLALSD usa la descomposición en valores singulares de A para resolver el problema de mínimos cuadrados
!> de encontrar X que minimice la norma euclidiana de cada columna de A*X-B, donde A es N por N superior
!> bidiagonal, y X y B son N por NRHS. La solución X sobrescribe B.
!>
!> Los valores singulares de A menores que RCOND multiplicado por el valor singular más grande
!> se tratan como cero al resolver el problema de mínimos cuadrados; en este caso se devuelve una solución
!> de norma mínima. Los valores singulares reales se devuelven en D en orden ascendente.
!>
!>

Parámetros

UPLO 
!>          UPLO es CARACTER*1
!>         = 'U': D y E definen una matriz bidiagonal superior.
!>         = 'L': D y E definen una matriz bidiagonal inferior.
!>

SMLSIZ

!>          SMLSIZ es ENTERO
!>         El tamaño máximo de los subproblemas en la parte inferior del
!>         árbol de cálculo.
!>

N

!>          N es ENTERO
!>         La dimensión de la matriz bidiagonal. N >= 0.
!>

NRHS

!>          NRHS es ENTERO
!>         El número de columnas de B. NRHS debe ser al menos 1.
!>

D

!>          D es un array de DOBLE PRECISIÓN, dimensión (N)
!>         En la entrada D contiene la diagonal principal de la matriz
!>         bidiagonal. En la salida, si INFO = 0, D contiene sus valores singulares.
!>

E

!>          E es un array de DOBLE PRECISIÓN, dimensión (N-1)
!>         Contiene las entradas superdiagonales de la matriz bidiagonal.
!>         En la salida, E ha sido destruido.
!>

B

!>          B es un array de COMPLEJO*16, dimensión (LDB,NRHS)
!>         En la entrada, B contiene los lados derechos del problema de mínimos cuadrados.
!>         En la salida, B contiene la solución X.
!>

LDB

!>          LDB es ENTERO
!>         La dimensión principal de B en la subrutina de llamada.
!>         LDB debe ser al menos max(1,N).
!>

RCOND

!>          RCOND es DOBLE PRECISIÓN
!>         Los valores singulares de A menores o iguales a RCOND multiplicado por
!>         el valor singular más grande se tratan como cero al resolver el problema de mínimos cuadrados.
!>         Si RCOND es negativo, se utiliza la precisión de máquina en su lugar.
!>         Por ejemplo, si diag(S)*X=B fuera el problema de mínimos cuadrados,
!>         donde diag(S) es una matriz diagonal de valores singulares, la
!>         solución sería X(i) = B(i) / S(i) si S(i) es mayor que
!>         RCOND*max(S), y X(i) = 0 si S(i) es menor o igual a
!>         RCOND*max(S).
!>

RANK

!>          RANK es ENTERO
!>         El número de valores singulares de A mayores que RCOND multiplicado por
!>         el valor singular más grande.
!>

WORK

!>          WORK es un array de COMPLEJO*16, dimensión (N * NRHS)
!>

RWORK

!>          RWORK es un array de DOBLE PRECISIÓN, dimensión al menos
!>         (9*N + 2*N*SMLSIZ + 8*N*NLVL + 3*SMLSIZ*NRHS +
!>         MAX( (SMLSIZ+1)**2, N*(1+NRHS) + 2*NRHS ),
!>         donde
!>         NLVL = MAX( 0, INT( LOG_2( MIN( M,N )/(SMLSIZ+1) ) ) + 1 )
!>

IWORK

!>          IWORK es un array de ENTEROS, dimensión al menos
!>         (3*N*NLVL + 11*N).
!>

INFO

!>          INFO es ENTERO
!>         = 0: salida exitosa.
!>         < 0: si INFO = -i, el i-ésimo argumento tenía un valor ilegal.
!>         > 0: El algoritmo no pudo calcular un valor singular mientras
!>               trabajaba en la submatriz situada en las filas y columnas
!>               INFO/(N+1) hasta MOD(INFO,N+1).
!>
