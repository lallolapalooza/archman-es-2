doble precisión function zla_gercond_c (character trans, integer n, complex*16, dimension( lda, * ) a, integer lda, complex*16, dimension( ldaf, * ) af, integer ldaf, integer, dimension( * ) ipiv, double precision, dimension( * ) c, logical capply, integer info, complex*16, dimension( * ) work, double precision, dimension( * ) rwork)

ZLA_GERCOND_C calcula el número de condición de la norma infinito de op(A)*inv(diag(c)) para matrices generales.

Propósito:

!>
!>    ZLA_GERCOND_C calcula el número de condición de la norma infinito de
!>    op(A) * inv(diag(C)) donde C es un vector de DOBLE PRECISIÓN.
!>

Parámetros

TRANS 
!>          TRANS es CHARACTER*1
!>     Especifica la forma del sistema de ecuaciones:
!>       = 'N':  A * X = B     (Sin transpuesta)
!>       = 'T':  A**T * X = B  (Transpuesta)
!>       = 'C':  A**H * X = B  (Transpuesta Conjugada = Transpuesta)
!>

N

!>          N es INTEGER
!>     El número de ecuaciones lineales, es decir, el orden de la
!>     matriz A.  N >= 0.
!>

A

!>          A es array COMPLEX*16, dimensión (LDA,N)
!>     En la entrada, la matriz A de N-por-N
!>

LDA

!>          LDA es INTEGER
!>     La dimensión principal del array A.  LDA >= max(1,N).
!>

AF

!>          AF es array COMPLEX*16, dimensión (LDAF,N)
!>     Los factores L y U de la factorización
!>     A = P*L*U como se calculó por ZGETRF.
!>

LDAF

!>          LDAF es INTEGER
!>     La dimensión principal del array AF.  LDAF >= max(1,N).
!>

IPIV

!>          IPIV es array INTEGER, dimensión (N)
!>     Los índices de pivote de la factorización A = P*L*U
!>     como se calculó por ZGETRF; la fila i de la matriz se intercambió
!>     con la fila IPIV(i).
!>

C

!>          C es array DOUBLE PRECISION, dimensión (N)
!>     El vector C en la fórmula op(A) * inv(diag(C)).
!>

CAPPLY

!>          CAPPLY es LOGICAL
!>     Si es .TRUE. entonces accede al vector C en la fórmula anterior.
!>

INFO

!>          INFO es INTEGER
!>       = 0:  Salida exitosa.
!>     i > 0:  El i-ésimo argumento es inválido.
!>

WORK

!>          WORK es array COMPLEX*16, dimensión (2*N).
!>     Espacio de trabajo.
!>

RWORK

!>          RWORK es array DOUBLE PRECISION, dimensión (N).
!>     Espacio de trabajo.
!>
