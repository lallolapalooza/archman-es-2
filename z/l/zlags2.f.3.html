Documentación de función/subrutina

subroutine zlags2 (logical upper, double precision a1, complex*16 a2, double precision a3, double precision b1, complex*16 b2, double precision b3, double precision csu, complex*16 snu, double precision csv, complex*16 snv, double precision csq, complex*16 snq)

ZLAGS2

Propósito:

!>
!> ZLAGS2 calcula matrices unitarias 2x2 U, V y Q, tales
!> que si ( UPPER ) entonces
!>
!>           U**H *A*Q = U**H *( A1 A2 )*Q = ( x  0  )
!>                             ( 0  A3 )     ( x  x  )
!> e
!>           V**H*B*Q = V**H *( B1 B2 )*Q = ( x  0  )
!>                            ( 0  B3 )     ( x  x  )
!>
!> o si ( .NOT.UPPER ) entonces
!>
!>           U**H *A*Q = U**H *( A1 0  )*Q = ( x  x  )
!>                             ( A2 A3 )     ( 0  x  )
!> e
!>           V**H *B*Q = V**H *( B1 0  )*Q = ( x  x  )
!>                             ( B2 B3 )     ( 0  x  )
!> donde
!>
!>   U = (   CSU    SNU ), V = (  CSV    SNV ),
!>       ( -SNU**H  CSU )      ( -SNV**H CSV )
!>
!>   Q = (   CSQ    SNQ )
!>       ( -SNQ**H  CSQ )
!>
!> Las filas de A y B transformadas son paralelas. Además, si la
!> matriz de entrada 2x2 A no es cero, entonces la entrada (1,1)
!> transformada de A no es cero. Si las matrices de entrada A y B
!> no son cero, entonces el elemento (2,2) transformado de B no es
!> cero, excepto cuando las primeras filas de A y B de entrada son
!> paralelas y las segundas filas son cero.
!>

Parámetros

UPPER 
!>          UPPER es LOGICAL
!>          = .TRUE.: las matrices de entrada A y B son triangulares superiores.
!>          = .FALSE.: las matrices de entrada A y B son triangulares inferiores.
!>

A1

!>          A1 es DOUBLE PRECISION
!>

A2

!>          A2 es COMPLEX*16
!>

A3

!>          A3 es DOUBLE PRECISION
!>          En la entrada, A1, A2 y A3 son elementos de la matriz
!>          triangular superior (inferior) 2x2 de entrada A.
!>

B1

!>          B1 es DOUBLE PRECISION
!>

B2

!>          B2 es COMPLEX*16
!>

B3

!>          B3 es DOUBLE PRECISION
!>          En la entrada, B1, B2 y B3 son elementos de la matriz
!>          triangular superior (inferior) 2x2 de entrada B.
!>

CSU

!>          CSU es DOUBLE PRECISION
!>

SNU

!>          SNU es COMPLEX*16
!>          La matriz unitaria deseada U.
!>

CSV

!>          CSV es DOUBLE PRECISION
!>

SNV

!>          SNV es COMPLEX*16
!>          La matriz unitaria deseada V.
!>

CSQ

!>          CSQ es DOUBLE PRECISION
!>

SNQ

!>          SNQ es COMPLEX*16
!>          La matriz unitaria deseada Q.
!>
