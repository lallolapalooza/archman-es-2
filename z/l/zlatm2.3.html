Documentación de Función/Subrutina

función complex*16 zlatm2 (integer m, integer n, integer i, integer j, integer kl, integer ku, integer idist, integer, dimension( 4 ) iseed, complex*16, dimension( * ) d, integer igrade, complex*16, dimension( * ) dl, complex*16, dimension( * ) dr, integer ipvtng, integer, dimension( * ) iwork, double precision sparse)

ZLATM2

Propósito:

!>
!>    ZLATM2 devuelve la entrada (I,J) de una matriz aleatoria de dimensión
!>    (M, N) descrita por los otros parámetros. Es llamada por la rutina
!>    ZLATMR para construir matrices de prueba aleatorias. No se realiza
!>    verificación de errores en los parámetros, ya que esta rutina es llamada
!>    en un bucle cerrado por ZLATMR, que ya ha verificado los parámetros.
!>
!>    El uso de ZLATM2 difiere de CLATM3 en el orden en que se llama al
!>    generador de números aleatorios para rellenar las entradas de la matriz
!>    aleatoria.
!>    Con ZLATM2, el generador se llama para rellenar la matriz pivotada
!>    por columnas. Con ZLATM3, el generador se llama para rellenar la
!>    matriz por columnas, después de lo cual se pivota. Por lo tanto,
!>    ZLATM3 puede usarse para construir matrices aleatorias que difieren
!>    solo en el orden de sus filas y/o columnas. ZLATM2 se usa para
!>    construir matrices de banda, evitando llamar al generador de números
!>    aleatorios para entradas fuera de la banda (y por lo tanto generando
!>    números aleatorios
!>
!>    La matriz cuya entrada (I,J) se devuelve se construye de la siguiente
!>    manera (esta rutina solo calcula una entrada):
!>
!>      Si I está fuera de (1..M) o J está fuera de (1..N), devolver cero
!>         (esto es conveniente para generar matrices en formato de banda).
!>
!>      Generar una matriz A con entradas aleatorias de distribución IDIST.
!>
!>      Establecer la diagonal a D.
!>
!>      Graduar la matriz, si se desea, desde la izquierda (por DL) y/o
!>         desde la derecha (por DR o DL) según lo especificado por IGRADE.
!>
!>      Permutar, si se desea, las filas y/o columnas según lo especificado por
!>         IPVTNG y IWORK.
!>
!>      Bandear la matriz para tener un ancho de banda inferior KL y un ancho
!>         de banda superior KU.
!>
!>      Establecer entradas aleatorias a cero según lo especificado por SPARSE.
!>

Parámetros

M 
!>          M es INTEGER
!>           Número de filas de la matriz. No modificado.
!>

N

!>          N es INTEGER
!>           Número de columnas de la matriz. No modificado.
!>

I

!>          I es INTEGER
!>           Fila de la entrada a devolver. No modificado.
!>

J

!>          J es INTEGER
!>           Columna de la entrada a devolver. No modificado.
!>

KL

!>          KL es INTEGER
!>           Ancho de banda inferior. No modificado.
!>

KU

!>          KU es INTEGER
!>           Ancho de banda superior. No modificado.
!>

IDIST

!>          IDIST es INTEGER
!>           A la entrada, IDIST especifica el tipo de distribución a usar para
!>           generar una matriz aleatoria.
!>           1 => partes real e imaginaria UNIFORMES ( 0, 1 ) cada una
!>           2 => partes real e imaginaria UNIFORMES ( -1, 1 ) cada una
!>           3 => partes real e imaginaria NORMALES ( 0, 1 ) cada una
!>           4 => número complejo uniforme en DISCO( 0 , 1 )
!>           No modificado.
!>

ISEED

!>          ISEED es un array INTEGER de dimensión ( 4 )
!>           Semilla para el generador de números aleatorios.
!>           Cambiado a la salida.
!>

D

!>          D es un array COMPLEX*16 de dimensión ( MIN( I , J ) )
!>           Entradas diagonales de la matriz. No modificado.
!>

IGRADE

!>          IGRADE es INTEGER
!>           Especifica la graduación de la matriz de la siguiente manera:
!>           0  => sin graduación
!>           1  => matriz premultiplicada por diag( DL )
!>           2  => matriz postmultiplicada por diag( DR )
!>           3  => matriz premultiplicada por diag( DL ) y
!>                         postmultiplicada por diag( DR )
!>           4  => matriz premultiplicada por diag( DL ) y
!>                         postmultiplicada por inv( diag( DL ) )
!>           5  => matriz premultiplicada por diag( DL ) y
!>                         postmultiplicada por diag( CONJG(DL) )
!>           6  => matriz premultiplicada por diag( DL ) y
!>                         postmultiplicada por diag( DL )
!>           No modificado.
!>

DL

!>          DL es un array COMPLEX*16 ( I o J, según corresponda )
!>           Factores de escala izquierda para graduar la matriz. No modificado.
!>

DR

!>          DR es un array COMPLEX*16 ( I o J, según corresponda )
!>           Factores de escala derecha para graduar la matriz. No modificado.
!>

IPVTNG

!>          IPVTNG es INTEGER
!>           A la entrada especifica las permutaciones de pivoteo de la siguiente
!>           manera:
!>           0 => ninguna.
!>           1 => pivoteo de filas.
!>           2 => pivoteo de columnas.
!>           3 => pivoteo completo, es decir, en ambos lados.
!>           No modificado.
!>

IWORK

!>          IWORK es un array INTEGER ( I o J, según corresponda )
!>           Este array especifica la permutación utilizada. La
!>           fila (o columna) en la posición K estaba originalmente en
!>           la posición IWORK( K ).
!>           Esto difiere de IWORK para ZLATM3. No modificado.
!>

SPARSE

!>          SPARSE es DOUBLE PRECISION entre 0. y 1.
!>           A la entrada especifica la dispersión de la matriz
!>           si se va a generar una matriz dispersa.
!>           SPARSE debe estar entre 0 y 1.
!>           Se genera un número aleatorio uniforme ( 0, 1 ), x,
!>           y se compara con SPARSE; si x es mayor, la entrada de la
!>           matriz no cambia y si x es menor, la entrada se
!>           establece a cero. Por lo tanto, en promedio, una fracción
!>           SPARSE de las entradas se establecerá a cero.
!>           No modificado.
!>

NAME

zlatm2 - zlartg2

SYNOPSIS

SUBROUTINE ZLATM2(
   LCASE, CI, CI2, D, D2, LL, G, L, M, N,
   SR, SI, M_R, M_I, D_R, D_I, Z_R, Z_I)

CHARACTER*1 LCASE
COMPLEX*16 CI, CI2, D, D2, LL, G, L, M, N
DOUBLE PRECISION SR, SI
COMPLEX*16 M_R, M_I, D_R, D_I, Z_R, Z_I

PURPOSE

This routine is the inverse of zlartg2. It is used to compute the complex eigenvalues of a 2-by-2 matrix in the form

[ A B ] [ C D ]

This routine is part of the LAPACK routines. It is not intended for general use.

ARGUMENTS

LCASE
CHARACTER*1. Specifies the form of the eigenvalues.
  • If LCASE = 'R', the eigenvalues are real.
  • If LCASE = 'C', the eigenvalues are complex.
CI
COMPLEX*16. The imaginary part of the first eigenvalue.
CI2
COMPLEX*16. The imaginary part of the second eigenvalue.
D
COMPLEX*16. The diagonal element D of the matrix.
D2
COMPLEX*16. Not used.
LL
COMPLEX*16. Not used.
G
COMPLEX*16. The quantity G = C*CONJG(B).
L
COMPLEX*16. The quantity L = A*CONJG(A) + C*CONJG(C).
M
COMPLEX*16. The quantity M = D*CONJG(D) + B*CONJG(B).
N
COMPLEX*16. The quantity N = A*CONJG(D) + C*CONJG(B).
SR
DOUBLE PRECISION. The real part of the first eigenvalue.
SI
DOUBLE PRECISION. The imaginary part of the first eigenvalue.
M_R
COMPLEX*16. Real part of M.
M_I
COMPLEX*16. Imaginary part of M.
D_R
COMPLEX*16. Real part of D.
D_I
COMPLEX*16. Imaginary part of D.
Z_R
COMPLEX*16. Real part of Z.
Z_I
COMPLEX*16. Imaginary part of Z.

FURTHER DETAILS

This routine is the inverse of zlartg2. It is used to compute the complex eigenvalues of a 2-by-2 matrix in the form

[ A B ] [ C D ]

The eigenvalues lambda are the solutions to the characteristic equation:

(A - lambda)*(D - lambda) - B*C = 0

lambda^2 - (A + D)*lambda + (A*D - B*C) = 0

The routine uses the relationship between the eigenvalues and the quantities L, M, N, G, D, and CI to reconstruct the original matrix elements A, B, C, and D.

This routine is part of the LAPACK routines. It is not intended for general use.
