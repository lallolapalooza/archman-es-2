DOCUMENTACIÓN DE FUNCIÓN/SUBRUTINA

doble precisión función zla_syrpvgrw (character*1 uplo, integer n, integer info, complex*16, dimension( lda, * ) a, integer lda, complex*16, dimension( ldaf, * ) af, integer ldaf, integer, dimension( * ) ipiv, double precision, dimension( * ) work)

ZLA_SYRPVGRW calcula el factor de crecimiento de pivote recíproco norm(A)/norm(U) para una matriz indefinida simétrica.

Propósito:

!>
!>
!> ZLA_SYRPVGRW calcula el factor de crecimiento de pivote recíproco
!> norm(A)/norm(U). Se usa la norma . Si esto es
!> mucho menor que 1, la estabilidad de la factorización LU de la
!> matriz (equilibrada) A podría ser pobre. Esto también significa que
!> la solución X, los números de condición estimados y los límites de error podrían
!> no ser fiables.
!>

Parámetros

UPLO 
!>          UPLO es CHARACTER*1
!>       = 'U':  El triángulo superior de A está almacenado;
!>       = 'L':  El triángulo inferior de A está almacenado.
!>

N

!>          N es INTEGER
!>     El número de ecuaciones lineales, es decir, el orden de la
!>     matriz A.  N >= 0.
!>

INFO

!>          INFO es INTEGER
!>     El valor de INFO devuelto por ZSYTRF, es decir, el pivote en
!>     la columna INFO es exactamente 0.
!>

A

!>          A es array COMPLEX*16, dimension (LDA,N)
!>     En la entrada, la matriz N-por-N A.
!>

LDA

!>          LDA es INTEGER
!>     La dimensión principal del array A.  LDA >= max(1,N).
!>

AF

!>          AF es array COMPLEX*16, dimension (LDAF,N)
!>     La matriz diagonal por bloques D y los multiplicadores utilizados para
!>     obtener el factor U o L según lo calculado por ZSYTRF.
!>

LDAF

!>          LDAF es INTEGER
!>     La dimensión principal del array AF.  LDAF >= max(1,N).
!>

IPIV

!>          IPIV es array INTEGER, dimension (N)
!>     Detalles de los intercambios y la estructura de bloques de D
!>     según lo determinado por ZSYTRF.
!>

WORK

!>          WORK es array DOUBLE PRECISION, dimension (2*N)
!>
