Propósito:

!>
!>    ZLATM3 devuelve la entrada (ISUB,JSUB) de una matriz aleatoria de
!>    dimensión (M, N) descrita por los otros parámetros. (ISUB,JSUB)
!>    es la posición final de la entrada (I,J) después de ser pivoteada
!>    según IPVTNG e IWORK. ZLATM3 es llamada por la rutina ZLATMR
!>    para construir matrices de prueba aleatorias. No se realiza comprobación
!>    de errores en los parámetros, ya que esta rutina es llamada en
!>    un bucle ajustado por ZLATMR, que ya ha comprobado los parámetros.
!>
!>    El uso de ZLATM3 difiere de CLATM2 en el orden en que se llama al
!>    generador de números aleatorios para rellenar las entradas de la matriz
!>    aleatoria. Con ZLATM2, el generador se llama para rellenar la matriz
!>    pivoteada columna a columna. Con ZLATM3, el generador se llama para
!>    rellenar la matriz columna a columna, después de lo cual se pivotea.
!>    Por lo tanto, ZLATM3 puede usarse para construir matrices aleatorias
!>    que difieren solo en el orden de sus filas y/o columnas. ZLATM2 se usa
!>    para construir matrices de banda, evitando llamar al generador de números
!>    aleatorios para entradas fuera de la banda (y por lo tanto generando
!>    números aleatorios en órdenes diferentes para diferentes órdenes de pivote).
!>
!>    La matriz cuya entrada (ISUB,JSUB) se devuelve se construye de la
!>    siguiente manera (esta rutina solo calcula una entrada):
!>
!>      Si ISUB está fuera de (1..M) o JSUB está fuera de (1..N), devuelve cero
!>         (esto es conveniente para generar matrices en formato de banda).
!>
!>      Genera una matriz A con entradas aleatorias de distribución IDIST.
!>
!>      Establece la diagonal a D.
!>
!>      Califica la matriz, si se desea, desde la izquierda (por DL) y/o
!>         desde la derecha (por DR o DL) según lo especificado por IGRADE.
!>
!>      Permuta, si se desea, las filas y/o columnas según lo especificado por
!>         IPVTNG e IWORK.
!>
!>      Banda la matriz para tener un ancho de banda inferior KL y superior
!>         KU.
!>
!>      Establece entradas aleatorias a cero según lo especificado por SPARSE.
!>

Parámetros

M 
!>          M es INTEGER
!>           Número de filas de la matriz. No modificado.
!>

N

!>          N es INTEGER
!>           Número de columnas de la matriz. No modificado.
!>

I

!>          I es INTEGER
!>           Fila de la entrada sin pivotar a devolver. No modificado.
!>

J

!>          J es INTEGER
!>           Columna de la entrada sin pivotar a devolver. No modificado.
!>

ISUB

!>          ISUB es INTEGER
!>           Fila de la entrada pivoteada a devolver. Cambiado en la salida.
!>

JSUB

!>          JSUB es INTEGER
!>           Columna de la entrada pivoteada a devolver. Cambiado en la salida.
!>

KL

!>          KL es INTEGER
!>           Ancho de banda inferior. No modificado.
!>

KU

!>          KU es INTEGER
!>           Ancho de banda superior. No modificado.
!>

IDIST

!>          IDIST es INTEGER
!>           A la entrada, IDIST especifica el tipo de distribución a utilizar
!>           para generar una matriz aleatoria.
!>           1 => partes real e imaginaria cada una UNIFORME( 0, 1 )
!>           2 => partes real e imaginaria cada una UNIFORME( -1, 1 )
!>           3 => partes real e imaginaria cada una NORMAL( 0, 1 )
!>           4 => número complejo uniforme en DISCO( 0 , 1 )
!>           No modificado.
!>

ISEED

!>          ISEED es array INTEGER de dimensión ( 4 )
!>           Semilla para el generador de números aleatorios.
!>           Cambiado en la salida.
!>

D

!>          D es array COMPLEX*16 de dimensión ( MIN( I , J ) )
!>           Entradas diagonales de la matriz. No modificado.
!>

IGRADE

!>          IGRADE es INTEGER
!>           Especifica la calificación de la matriz de la siguiente manera:
!>           0 => sin calificación
!>           1 => matriz premultiplicada por diag( DL )
!>           2 => matriz postmultiplicada por diag( DR )
!>           3 => matriz premultiplicada por diag( DL ) y
!>                         postmultiplicada por diag( DR )
!>           4 => matriz premultiplicada por diag( DL ) y
!>                         postmultiplicada por inv( diag( DL ) )
!>           5 => matriz premultiplicada por diag( DL ) y
!>                         postmultiplicada por diag( CONJG(DL) )
!>           6 => matriz premultiplicada por diag( DL ) y
!>                         postmultiplicada por diag( DL )
!>           No modificado.
!>

DL

!>          DL es array COMPLEX*16 ( I o J, según corresponda )
!>           Factores de escala izquierda para calificar la matriz. No modificado.
!>

DR

!>          DR es array COMPLEX*16 ( I o J, según corresponda )
!>           Factores de escala derecha para calificar la matriz. No modificado.
!>

IPVTNG

!>          IPVTNG es INTEGER
!>           A la entrada especifica las permutaciones de pivote de la siguiente manera:
!>           0 => ninguna.
!>           1 => pivoteo de filas.
!>           2 => pivoteo de columnas.
!>           3 => pivoteo completo, es decir, en ambos lados.
!>           No modificado.
!>

IWORK

!>          IWORK es array INTEGER ( I o J, según corresponda )
!>           Este array especifica la permutación utilizada. La
!>           fila (o columna) originalmente en la posición K está en
!>           la posición IWORK( K ) después del pivoteo.
!>           Esto difiere de IWORK para ZLATM2. No modificado.
!>

SPARSE

!>          SPARSE es DOUBLE PRECISION entre 0. y 1.
!>           A la entrada especifica la escasez de la matriz
!>           si se va a generar una matriz dispersa.
!>           SPARSE debe estar entre 0 y 1.
!>           Se genera un número aleatorio uniforme ( 0, 1 ), x, y
!>           se compara con SPARSE; si x es mayor, la entrada de la
!>           matriz no se modifica y si x es menor, la entrada se
!>           establece a cero. Por lo tanto, en promedio, una fracción
!>           SPARSE de las entradas se establecerá a cero.
!>           No modificado.
!>
