subrutina zlaqr5 (logical wantt, logical wantz, integer kacc22, integer n, integer ktop, integer kbot, integer nshfts, complex*16, dimension( * ) s, complex*16, dimension( ldh, * ) h, integer ldh, integer iloz, integer ihiz, complex*16, dimension( ldz, * ) z, integer ldz, complex*16, dimension( ldv, * ) v, integer ldv, complex*16, dimension( ldu, * ) u, integer ldu, integer nv, complex*16, dimension( ldwv, * ) wv, integer ldwv, integer nh, complex*16, dimension( ldwh, * ) wh, integer ldwh)

ZLAQR5 realiza un barrido QR multi-shift de una sola burbuja pequeña.

Propósito:

!>
!>    ZLAQR5, llamado por ZLAQR0, realiza un
!>    barrido QR multi-shift de una sola burbuja pequeña.
!>

Parámetros

WANTT 
!>          WANTT es LOGICAL
!>             WANTT = .true. si se está calculando el factor de Schur
!>             triangular.  WANTT se establece en .false. en caso contrario.
!>

WANTZ

!>          WANTZ es LOGICAL
!>             WANTZ = .true. si se está calculando el factor de Schur
!>             unitario.  WANTZ se establece en .false. en caso contrario.
!>

KACC22

!>          KACC22 es INTEGER con valor 0, 1 o 2.
!>             Especifica el modo de cálculo de las actualizaciones ortogonales
!>             lejanas de la diagonal.
!>        = 0: ZLAQR5 no acumula reflexiones y no utiliza multiplicaciones
!>             matriz-matriz para actualizar las entradas de matriz lejanas
!>             de la diagonal.
!>        = 1: ZLAQR5 acumula reflexiones y utiliza multiplicaciones
!>             matriz-matriz para actualizar las entradas de matriz lejanas
!>             de la diagonal.
!>        = 2: Igual que KACC22 = 1. Esta opción solía habilitar la
!>             explotación de la estructura de 2x2 durante las multiplicaciones
!>             de matrices, pero esto ya no es compatible.
!>

N

!>          N es INTEGER
!>             N es el orden de la matriz de Hessenberg H sobre la cual opera
!>             esta subrutina.
!>

KTOP

!>          KTOP es INTEGER
!>

KBOT

!>          KBOT es INTEGER
!>             Estas son las primeras y últimas filas y columnas de un
!>             bloque diagonal aislado sobre el cual se aplicará el barrido QR.
!>             Se asume sin comprobación que
!>                       o KTOP = 1  o   H(KTOP,KTOP-1) = 0
!>             y
!>                       o KBOT = N  o   H(KBOT+1,KBOT) = 0.
!>

NSHFTS

!>          NSHFTS es INTEGER
!>             NSHFTS indica el número de desplazamientos simultáneos. NSHFTS
!>             debe ser positivo y par.
!>

S

!>          S es un array COMPLEX*16, dimensión (NSHFTS)
!>             S contiene los desplazamientos de origen que definen el barrido
!>             QR multi-shift. A la salida, S puede ser reordenado.
!>

H

!>          H es un array COMPLEX*16, dimensión (LDH,N)
!>             A la entrada, H contiene una matriz de Hessenberg. A la salida,
!>             se aplica un barrido QR multi-shift con desplazamientos SR(J)+i*SI(J)
!>             al bloque diagonal aislado en las filas y columnas KTOP a KBOT.
!>

LDH

!>          LDH es INTEGER
!>             LDH es la dimensión líder de H, tal como se declara en el
!>             procedimiento de llamada. LDH >= MAX(1,N).
!>

ILOZ

!>          ILOZ es INTEGER
!>

IHIZ

!>          IHIZ es INTEGER
!>             Especifican las filas de Z a las que se deben aplicar las
!>             transformaciones si WANTZ es .TRUE.. 1 <= ILOZ <= IHIZ <= N
!>

Z

!>          Z es un array COMPLEX*16, dimensión (LDZ,IHIZ)
!>             Si WANTZ = .TRUE., entonces la transformación de semejanza unitaria
!>             del barrido QR se acumula en Z(ILOZ:IHIZ,ILOZ:IHIZ) desde la
!>             derecha.
!>             Si WANTZ = .FALSE., entonces Z no se utiliza.
!>

LDZ

!>          LDZ es INTEGER
!>             LDZ es la dimensión líder de Z, tal como se declara en el
!>             procedimiento de llamada. LDZ >= N.
!>

V

!>          V es un array COMPLEX*16, dimensión (LDV,NSHFTS/2)
!>

LDV

!>          LDV es INTEGER
!>             LDV es la dimensión líder de V tal como se declara en el
!>             procedimiento de llamada. LDV >= 3.
!>

U

!>          U es un array COMPLEX*16, dimensión (LDU,2*NSHFTS)
!>

LDU

!>          LDU es INTEGER
!>             LDU es la dimensión líder de U tal como se declara en el
!>             procedimiento de llamada. LDU >= 2*NSHFTS.
!>

NV

!>          NV es INTEGER
!>             NV es el número de filas en WV disponibles para espacio de
!>             trabajo. NV >= 1.
!>

WV

!>          WV es un array COMPLEX*16, dimensión (LDWV,2*NSHFTS)
!>

LDWV

!>          LDWV es INTEGER
!>             LDWV es la dimensión líder de WV tal como se declara en el
!>             procedimiento de llamada. LDWV >= NV.
!>

NH

!>          NH es INTEGER
!>             NH es el número de columnas en el array WH disponibles para
!>             espacio de trabajo. NH >= 1.
!>

WH

!>          WH es un array COMPLEX*16, dimensión (LDWH,NH)
!>

LDWH

!>          LDWH es INTEGER
!>             Dimensión líder de WH tal como se declara en el
!>             procedimiento de llamada. LDWH >= 2*NSHFTS.
!>
