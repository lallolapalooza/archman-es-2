subrutina zlattb (enter imat, caracter uplo, caracter trans, caracter diag, enter, dimension( 4 ) iseed, enter n, enter kd, complejo*16, dimension( ldab, * ) ab, enter ldab, complejo*16, dimension( * ) b, complejo*16, dimension( * ) work, doble precisión, dimension( * ) rwork, enter info)

ZLATTB

Propósito:

!>
!> ZLATTB genera una matriz de prueba triangular en almacenamiento 2-dimensional.
!> IMAT y UPLO especifican de forma única las propiedades de la matriz de prueba,
!> que se devuelve en el array A.
!>

Parámetros

IMAT 
!>          IMAT es ENTERO
!>          Una clave entera que describe qué matriz generar para esta
!>          ruta.
!>

UPLO

!>          UPLO es CARACTER*1
!>          Especifica si la matriz A será triangular superior o inferior.
!>          = 'U':  Triangular superior
!>          = 'L':  Triangular inferior
!>

TRANS

!>          TRANS es CARACTER*1
!>          Especifica si se utilizará la matriz o su transpuesta.
!>          = 'N':  Sin transponer
!>          = 'T':  Transponer
!>          = 'C':  Transpuesta conjugada (= transpuesta)
!>

DIAG

!>          DIAG es CARACTER*1
!>          Especifica si la matriz A es unitaria triangular o no.
!>          = 'N':  Triangular no unitaria
!>          = 'U':  Triangular unitaria
!>

ISEED

!>          ISEED es un array de ENTEROS, dimensión (4)
!>          El vector semilla para el generador de números aleatorios (usado en
!>          ZLATMS). Modificado a la salida.
!>

N

!>          N es ENTERO
!>          El orden de la matriz a generar.
!>

KD

!>          KD es ENTERO
!>          El número de superdiagonales o subdiagonales de la matriz
!>          triangular de banda A. KD >= 0.
!>

AB

!>          AB es un array de COMPLEJO*16, dimensión (LDAB,N)
!>          La matriz triangular de banda superior o inferior A, almacenada en
!>          las primeras KD+1 filas de AB. Sea j una columna de A, 1<=j<=n.
!>          Si UPLO = 'U', AB(kd+1+i-j,j) = A(i,j) para max(1,j-kd)<=i<=j.
!>          Si UPLO = 'L', AB(1+i-j,j)    = A(i,j) para j<=i<=min(n,j+kd).
!>

LDAB

!>          LDAB es ENTERO
!>          La dimensión principal del array AB. LDAB >= KD+1.
!>

B

!>          B es un array de COMPLEJO*16, dimensión (N)
!>

WORK

!>          WORK es un array de COMPLEJO*16, dimensión (2*N)
!>

RWORK

!>          RWORK es un array de DOBLE PRECISIÓN, dimensión (N)
!>

INFO

!>          INFO es ENTERO
!>          = 0:  salida exitosa
!>          < 0:  si INFO = -i, el i-ésimo argumento tenía un valor ilegal
!>
