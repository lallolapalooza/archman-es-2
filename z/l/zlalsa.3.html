subrutina zlalsa (entero icompq, entero smlsiz, entero n, entero nrhs, complejo*16, dimensión( ldb, * ) b, entero ldb, complejo*16, dimensión( ldbx, * ) bx, entero ldbx, doble precisión, dimensión( ldu, * ) u, entero ldu, doble precisión, dimensión( ldu, * ) vt, entero, dimensión( * ) k, doble precisión, dimensión( ldu, * ) difl, doble precisión, dimensión( ldu, * ) difr, doble precisión, dimensión( ldu, * ) z, doble precisión, dimensión( ldu, * ) poles, entero, dimensión( * ) givptr, entero, dimensión( ldgcol, * ) givcol, entero ldgcol, entero, dimensión( ldgcol, * ) perm, doble precisión, dimensión( ldu, * ) givnum, doble precisión, dimensión( * ) c, doble precisión, dimensión( * ) s, doble precisión, dimensión( * ) rwork, entero, dimensión( * ) iwork, entero info)

ZLALSA calcula la SVD de la matriz de coeficientes en forma compacta. Utilizada por sgelsd.

Propósito:

!>
!> ZLALSA es un paso intermedio en la resolución del problema de mínimos cuadrados
!> calculando la SVD de la matriz de coeficientes en forma compacta (Los
!> vectores singulares se calculan como productos de matrices ortogonales
!> simples.).
!>
!> Si ICOMPQ = 0, ZLALSA aplica la inversa de la matriz de vectores singulares
!> izquierdos de una matriz bidiagonal superior al lado derecho; y si
!> ICOMPQ = 1, ZLALSA aplica la matriz de vectores singulares derechos al
!> lado derecho. Las matrices de vectores singulares fueron generadas en
!> forma compacta por ZLALSA.
!>

Parámetros

ICOMPQ 
!>          ICOMPQ es ENTERO
!>         Especifica si se involucra la matriz de vectores singulares
!>         izquierdos o derechos.
!>         = 0: Matriz de vectores singulares izquierdos
!>         = 1: Matriz de vectores singulares derechos
!>

SMLSIZ

!>          SMLSIZ es ENTERO
!>         El tamaño máximo de los subproblemas en la parte inferior del
!>         árbol de cómputo.
!>

N

!>          N es ENTERO
!>         Las dimensiones de fila y columna de la matriz bidiagonal superior.
!>

NRHS

!>          NRHS es ENTERO
!>         El número de columnas de B y BX. NRHS debe ser al menos 1.
!>

B

!>          B es un arreglo COMPLEX*16, dimensión ( LDB, NRHS )
!>         En la entrada, B contiene los lados derechos del problema de
!>         mínimos cuadrados en las filas 1 hasta M.
!>         En la salida, B contiene la solución X en las filas 1 hasta N.
!>

LDB

!>          LDB es ENTERO
!>         La dimensión principal de B en el subprograma de llamada.
!>         LDB debe ser al menos max(1,MAX( M, N ) ).
!>

BX

!>          BX es un arreglo COMPLEX*16, dimensión ( LDBX, NRHS )
!>         En la salida, el resultado de aplicar la matriz de vectores singulares
!>         izquierdos o derechos a B.
!>

LDBX

!>          LDBX es ENTERO
!>         La dimensión principal de BX.
!>

U

!>          U es un arreglo DOUBLE PRECISION, dimensión ( LDU, SMLSIZ ).
!>         En la entrada, U contiene las matrices de vectores singulares
!>         izquierdos de todos los subproblemas en el nivel inferior.
!>

LDU

!>          LDU es ENTERO, LDU = > N.
!>         La dimensión principal de los arreglos U, VT, DIFL, DIFR,
!>         POLES, GIVNUM y Z.
!>

VT

!>          VT es un arreglo DOUBLE PRECISION, dimensión ( LDU, SMLSIZ+1 ).
!>         En la entrada, VT**H contiene las matrices de vectores singulares
!>         derechos de todos los subproblemas en el nivel inferior.
!>

K

!>          K es un arreglo ENTERO, dimensión ( N ).
!>

DIFL

!>          DIFL es un arreglo DOUBLE PRECISION, dimensión ( LDU, NLVL ).
!>         donde NLVL = INT(log_2 (N/(SMLSIZ+1))) + 1.
!>

DIFR

!>          DIFR es un arreglo DOUBLE PRECISION, dimensión ( LDU, 2 * NLVL ).
!>         En la entrada, DIFL(*, I) y DIFR(*, 2 * I -1) registran
!>         las distancias entre los valores singulares en el nivel I y
!>         los valores singulares en el nivel (I -1), y DIFR(*, 2 * I)
!>         registra los factores de normalización de las matrices de vectores singulares
!>         derechos de los subproblemas en el nivel I.
!>

Z

!>          Z es un arreglo DOUBLE PRECISION, dimensión ( LDU, NLVL ).
!>         En la entrada, Z(1, I) contiene los componentes del vector
!>         fila de actualización ajustado por deflación para los subproblemas en el nivel I.
!>

POLES

!>          POLES es un arreglo DOUBLE PRECISION, dimensión ( LDU, 2 * NLVL ).
!>         En la entrada, POLES(*, 2 * I -1: 2 * I) contiene los valores
!>         singulares nuevos y antiguos involucrados en las ecuaciones
!>         seculares en el nivel I.
!>

GIVPTR

!>          GIVPTR es un arreglo ENTERO, dimensión ( N ).
!>         En la entrada, GIVPTR( I ) registra el número de rotaciones de
!>         Givens realizadas en el problema I en el árbol de cómputo.
!>

GIVCOL

!>          GIVCOL es un arreglo ENTERO, dimensión ( LDGCOL, 2 * NLVL ).
!>         En la entrada, para cada I, GIVCOL(*, 2 * I - 1: 2 * I) registra las
!>         ubicaciones de las rotaciones de Givens realizadas en el nivel I en
!>         el árbol de cómputo.
!>

LDGCOL

!>          LDGCOL es ENTERO, LDGCOL = > N.
!>         La dimensión principal de los arreglos GIVCOL y PERM.
!>

PERM

!>          PERM es un arreglo ENTERO, dimensión ( LDGCOL, NLVL ).
!>         En la entrada, PERM(*, I) registra las permutaciones realizadas en el nivel I
!>         del árbol de cómputo.
!>

GIVNUM

!>          GIVNUM es un arreglo DOUBLE PRECISION, dimensión ( LDU, 2 * NLVL ).
!>         En la entrada, GIVNUM(*, 2 *I -1 : 2 * I) registra los valores C y S
!>         de las rotaciones de Givens realizadas en el nivel I en
!>         el árbol de cómputo.
!>

C

!>          C es un arreglo DOUBLE PRECISION, dimensión ( N ).
!>         En la entrada, si el subproblema I no es cuadrado,
!>         C( I ) contiene el valor C de una rotación de Givens relacionada
!>         con el espacio nulo derecho del subproblema I.
!>

S

!>          S es un arreglo DOUBLE PRECISION, dimensión ( N ).
!>         En la entrada, si el subproblema I no es cuadrado,
!>         S( I ) contiene el valor S de una rotación de Givens relacionada
!>         con el espacio nulo derecho del subproblema I.
!>

RWORK

!>          RWORK es un arreglo DOUBLE PRECISION, dimensión al menos
!>         MAX( (SMLSZ+1)*NRHS*3, N*(1+NRHS) + 2*NRHS ).
!>

IWORK

!>          IWORK es un arreglo ENTERO, dimensión al menos
!>         MAX( N, (SMLSZ+1)*NRHS ).
!>

INFO

!>          INFO es ENTERO
!>         = 0: Éxito.
!>         < 0: Si INFO = -i, entonces el i-ésimo argumento no válido.
!>         > 0: El algoritmo de convergencia falló. Típicamente, indica que un
!>             subproblema no se ha resuelto.
!>

NAME

zlalsa - computes the largest singular value of a bidiagonal matrix

SYNOPSIS

    SUBROUTINE ZLALSA(Z, MATZ, N, A, LDA, B, LDB, RWORK, TOL, U, LDU, V,
    LDV, WORK, INFO)
    CHARACTER * 1 Z
    LOGICAL MATZ
    INTEGER N
    COMPLEX *16 A(LDA,*)
    INTEGER LDA
    COMPLEX *16 B(LDB,*)
    INTEGER LDB
    DOUBLE PRECISION RWORK(*)
    DOUBLE PRECISION TOL
    COMPLEX *16 U(LDU,*)
    INTEGER LDU
    COMPLEX *16 V(LDV,*)
    INTEGER LDV
    COMPLEX *16 WORK(*)
    INTEGER INFO

Function/Subroutine Documentation

This subroutine is called when the k-th singular value of A is requested and k=N.

Arguments:

Z is CHARACTER*1

Specifies whether to compute the singular values of A (if Z='N') or the singular values of the matrix Z*A (if Z='Z').

MATZ is LOGICAL

Specifies whether to compute the left singular vectors (if MATZ=.TRUE.) or not (if Z='N').

N is INTEGER

The order of the matrix A. N >= 0.

A is COMPLEX*16 array, dimension (LDA, *)

If Z='N', A contains the bidiagonal matrix.

LDA is INTEGER

The leading dimension of the array A. LDA >= (1, N).

B is COMPLEX*16 array, dimension (LDB, *)

If Z='Z', B contains the bidiagonal matrix.

LDB is INTEGER

The leading dimension of the array B. LDB >= (1, N).

RWORK is DOUBLE PRECISION array, dimension (N)

Workspace array.

TOL is DOUBLE PRECISION

Tolerance for convergence.

U is COMPLEX*16 array, dimension (LDU, *)

If MATZ=.TRUE., U is array of dimension (LDU, N) and on exit contains the left singular vectors.

LDU is INTEGER

The leading dimension of the array U. LDU >= (1, N).

V is COMPLEX*16 array, dimension (LDV, *)

If MATZ=.TRUE., V is array of dimension (LDV, N) and on exit contains the right singular vectors.

LDV is INTEGER

The leading dimension of the array V. LDV >= (1, N).

WORK is COMPLEX*16 array, dimension (N)

Workspace array.

INFO is INTEGER

= 0: successful exit.

< 0: if INFO = -i, the i-th argument had an illegal value.
