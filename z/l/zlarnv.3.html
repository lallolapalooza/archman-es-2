Documentación de la Función/Subrutina

subrutina zlarnv (integer idist, integer, dimension( 4 ) iseed, integer n, complex*16, dimension( * ) x)

ZLARNV devuelve un vector de números complejos aleatorios de una distribución uniforme o normal.

Propósito:

!>
!> ZLARNV devuelve un vector de n números complejos aleatorios de una distribución uniforme o
!> normal.
!>

Parámetros

IDIST 
!>          IDIST es INTEGER
!>          Especifica la distribución de los números aleatorios:
!>          = 1:  partes real e imaginaria uniformemente (0,1)
!>          = 2:  partes real e imaginaria uniformemente (-1,1)
!>          = 3:  partes real e imaginaria normalmente (0,1)
!>          = 4:  distribuidos uniformemente en el disco abs(z) < 1
!>          = 5:  distribuidos uniformemente en el círculo abs(z) = 1
!>

ISEED

!>          ISEED es un array INTEGER, dimensión (4)
!>          A la entrada, la semilla del generador de números aleatorios; los elementos
!>          del array deben estar entre 0 y 4095, y ISEED(4) debe ser
!>          impar.
!>          A la salida, la semilla se actualiza.
!>

N

!>          N es INTEGER
!>          El número de números aleatorios a generar.
!>

X

!>          X es un array COMPLEX*16, dimensión (N)
!>          Los números aleatorios generados.
!>

Detalles adicionales:

!>
!>  Esta rutina llama a la rutina auxiliar DLARUV para generar números
!>  reales aleatorios de una distribución uniforme (0,1), en lotes de hasta
!>  128 usando código vectorizable. Se utiliza el método de Box-Muller para
!>  transformar números de una distribución uniforme a una normal.
!>
