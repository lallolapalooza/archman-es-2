subrutina zlabrd (m, n, nb, a, lda, d, e, tauq, taup, x, ldx, y, ldy)
ZLABRD reduce las primeras nb filas y columnas de una matriz general a forma bidiagonal.

Documentación de Función/Subrutina

subrutina zlabrd (integer m, integer n, integer nb, complex*16, dimension( lda, * ) a, integer lda, double precision, dimension( * ) d, double precision, dimension( * ) e, complex*16, dimension( * ) tauq, complex*16, dimension( * ) taup, complex*16, dimension( ldx, * ) x, integer ldx, complex*16, dimension( ldy, * ) y, integer ldy)

ZLABRD reduce las primeras nb filas y columnas de una matriz general a forma bidiagonal.

Propósito:

!>
!> ZLABRD reduce las primeras NB filas y columnas de una matriz general compleja
!> m por n A a forma bidiagonal real superior o inferior mediante una transformación unitaria
!> Q**H * A * P, y devuelve las matrices X e Y que
!> son necesarias para aplicar la transformación a la parte no reducida de A.
!>
!> Si m >= n, A se reduce a forma bidiagonal superior; si m < n, a forma bidiagonal
!> inferior.
!>
!> Esta es una subrutina auxiliar llamada por ZGEBRD
!>

Parámetros

M 
!>          M es ENTERO
!>          El número de filas en la matriz A.
!>

N

!>          N es ENTERO
!>          El número de columnas en la matriz A.
!>

NB

!>          NB es ENTERO
!>          El número de filas y columnas principales de A a reducir.
!>

A

!>          A es un array COMPLEX*16, de dimensión (LDA,N)
!>          En la entrada, la matriz general m por n a reducir.
!>          En la salida, las primeras NB filas y columnas de la matriz se
!>          sobrescriben; el resto del array permanece sin cambios.
!>          Si m >= n, los elementos en y por debajo de la diagonal en las primeras NB
!>            columnas, con el array TAUQ, representan la matriz
!>            unitaria Q como un producto de reflectores elementales; y
!>            los elementos por encima de la diagonal en las primeras NB filas, con el
!>            array TAUP, representan la matriz unitaria P como un producto
!>            de reflectores elementales.
!>          Si m < n, los elementos por debajo de la diagonal en las primeras NB
!>            columnas, con el array TAUQ, representan la matriz
!>            unitaria Q como un producto de reflectores elementales, y
!>            los elementos en y por encima de la diagonal en las primeras NB filas, con el
!>            array TAUP, representan la matriz unitaria P como un producto
!>            de reflectores elementales.
!>          Ver Detalles Adicionales.
!>

LDA

!>          LDA es ENTERO
!>          La dimensión principal del array A. LDA >= max(1,M).
!>

D

!>          D es un array DOUBLE PRECISION, de dimensión (NB)
!>          Los elementos diagonales de las primeras NB filas y columnas de
!>          la matriz reducida. D(i) = A(i,i).
!>

E

!>          E es un array DOUBLE PRECISION, de dimensión (NB)
!>          Los elementos fuera de la diagonal de las primeras NB filas y columnas de
!>          la matriz reducida.
!>

TAUQ

!>          TAUQ es un array COMPLEX*16, de dimensión (NB)
!>          Los factores escalares de los reflectores elementales que
!>          representan la matriz unitaria Q. Ver Detalles Adicionales.
!>

TAUP

!>          TAUP es un array COMPLEX*16, de dimensión (NB)
!>          Los factores escalares de los reflectores elementales que
!>          representan la matriz unitaria P. Ver Detalles Adicionales.
!>

X

!>          X es un array COMPLEX*16, de dimensión (LDX,NB)
!>          La matriz X de m por nb necesaria para actualizar la parte no reducida
!>          de A.
!>

LDX

!>          LDX es ENTERO
!>          La dimensión principal del array X. LDX >= max(1,M).
!>

Y

!>          Y es un array COMPLEX*16, de dimensión (LDY,NB)
!>          La matriz Y de n por nb necesaria para actualizar la parte no reducida
!>          de A.
!>

LDY

!>          LDY es ENTERO
!>          La dimensión principal del array Y. LDY >= max(1,N).
!>

Detalles Adicionales:

!>
!>  Las matrices Q y P se representan como productos de reflectores
!>  elementales:
!>
!>     Q = H(1) H(2) . . . H(nb)  y  P = G(1) G(2) . . . G(nb)
!>
!>  Cada H(i) y G(i) tiene la forma:
!>
!>     H(i) = I - tauq * v * v**H  y G(i) = I - taup * u * u**H
!>
!>  donde tauq y taup son escalares complejos, y v y u son vectores complejos.
!>
!>  Si m >= n, v(1:i-1) = 0, v(i) = 1, y v(i:m) se almacena en la salida en
!>  A(i:m,i); u(1:i) = 0, u(i+1) = 1, y u(i+1:n) se almacena en la salida en
!>  A(i,i+1:n); tauq se almacena en TAUQ(i) y taup en TAUP(i).
!>
!>  Si m < n, v(1:i) = 0, v(i+1) = 1, y v(i+1:m) se almacena en la salida en
!>  A(i+2:m,i); u(1:i-1) = 0, u(i) = 1, y u(i:n) se almacena en la salida en
!>  A(i,i+1:n); tauq se almacena en TAUQ(i) y taup en TAUP(i).
!>
!>  Los elementos de los vectores v y u juntos forman la matriz m-por-nb
!>  V y la matriz nb-por-n U**H que son necesarias, con X e Y, para aplicar
!>  la transformación a la parte no reducida de la matriz, usando una actualización
!>  de bloque de la forma: A := A - V*Y**H - X*U**H.
!>
!>  Los contenidos de A en la salida se ilustran con los siguientes ejemplos
!>  con nb = 2:
!>
!>  m = 6 y n = 5 (m > n):          m = 5 y n = 6 (m < n):
!>
!>    (  1   1   u1  u1  u1 )           (  1   u1  u1  u1  u1  u1 )
!>    (  v1  1   1   u2  u2 )           (  1   1   u2  u2  u2  u2 )
!>    (  v1  v2  a   a   a  )           (  v1  1   a   a   a   a  )
!>    (  v1  v2  a   a   a  )           (  v1  v2  a   a   a   a  )
!>    (  v1  v2  a   a   a  )           (  v1  v2  a   a   a   a  )
!>    (  v1  v2  a   a   a  )
!>
!>  donde a denota un elemento de la matriz original que no ha cambiado,
!>  vi denota un elemento del vector que define H(i), y ui un elemento
!>  del vector que define G(i).
!>

NOMBRE

zlabrd - Devuelve los elementos de la matriz de datos de una matriz de banda.

SINOPSIS

SUBROUTINE ZLABRD(
       NB,       A,        LDA,      D,        E,        TAUQ,     TAUP,
       X,        LDX,      Y,        LDY,      WORK,     LWORK)

SUBROUTINE ZLABRD( INTEGER NB, COMPLEX*16, DIMENSION( * ) :: A,
       INTEGER LDA, REAL*8, DIMENSION( * ) :: D,
       REAL*8, DIMENSION( * ) :: E, REAL*8, DIMENSION( * ) :: TAUQ,
       REAL*8, DIMENSION( * ) :: TAUP, COMPLEX*16,
       DIMENSION( * ) :: X, INTEGER LDX, COMPLEX*16,
       DIMENSION( * ) :: Y, INTEGER LDY, COMPLEX*16,
       DIMENSION( * ) :: WORK, INTEGER LWORK )

DESCRIPCIÓN

ZLABRD reduce una matriz de banda general A de dimensiones M-by-N a la forma bidiagonal superior, tal que

P * A * Q**H = [ B | 0 ] [ 0 | 0 ]

donde B es una matriz bidiagonal superior de dimensiones MB-by-NB, P es una matriz unitaria de dimensiones M-by-M, y Q es una matriz unitaria de dimensiones N-by-N. P y Q se representan implícitamente mediante matrices de Householder. En particular,

P = P_M * ... * P_{M-NB+1}

Q = Q_1 * ... * Q_{NB}

donde P_I y Q_I son transformaciones de Householder.

La matriz de banda A se almacena en la matriz A. La diagonal principal se almacena en el primer elemento de cada fila de A, la primera superdiagonal se almacena en el segundo elemento de cada fila, y así sucesivamente.

A continuación, se muestra un ejemplo de almacenamiento de una matriz de banda de 6x5 con NB=3:

A = [ u11 u12 u13 0 0 ] [ u21 u22 u23 u24 0 ] [ u31 u32 u33 u34 u35 ] [ 0 u42 u43 u44 u45 ] [ 0 0 u53 u54 u55 ] [ 0 0 0 u64 u65 ]

donde u_ij son los elementos de la matriz de banda A. Los elementos de la matriz de banda A se almacenan en la matriz A de la siguiente manera:

A = [ u11 u12 u13 0 0 ] [ u21 u22 u23 u24 0 ] [ u31 u32 u33 u34 u35 ] [ * u42 u43 u44 u45 ] [ * * u53 u54 u55 ] [ * * * u64 u65 ]

Aquí, los elementos con asteriscos se pueden sobreescribir.

Esta rutina es un paso intermedio en la reducción de una matriz de banda general a una forma bidiagonal. Se espera que se llame a la rutina ZLACON para obtener las normas de las columnas o las normas de las filas.

ARGUMENTOS

NB

INTEGER. El número de subdiagonales y superdiagonales en la banda de A.

NB >= 0.

A

COMPLEX*16, DIMENSION( LDA, * ). La matriz de banda A.

LDA

INTEGER. El número de filas de la matriz A.

D

REAL*8, DIMENSION( * ). El vector D de longitud min(M,N). D contendrá los elementos de la diagonal principal de la matriz bidiagonal.

E

REAL*8, DIMENSION( * ). El vector E de longitud min(M,N)-1. E contendrá los elementos de la superdiagonal de la matriz bidiagonal.

TAUQ

REAL*8, DIMENSION( * ). El vector TAUQ de longitud NB. TAUQ(I) contendrá los escalares de Householder que anulan los elementos de las columnas de A.

TAUP

REAL*8, DIMENSION( * ). El vector TAUP de longitud NB. TAUP(I) contendrá los escalares de Householder que anulan los elementos de las filas de A.

X

COMPLEX*16, DIMENSION( LDX, * ). Matriz de transformaciones de Householder que anulan los elementos de las columnas de A.

LDX

INTEGER. La longitud de las filas de X.

Y

COMPLEX*16, DIMENSION( LDY, * ). Matriz de transformaciones de Householder que anulan los elementos de las filas de A.

LDY

INTEGER. La longitud de las filas de Y.

WORK

COMPLEX*16, DIMENSION( * ). Workspace de trabajo.

LWORK

INTEGER. La longitud del workspace de trabajo.

INDICES

Los elementos de la matriz de banda A se almacenan de la siguiente manera: A(I,J) se almacena en A(I-J+NB+1, J) para I >= J - NB y I <= J + NB.
