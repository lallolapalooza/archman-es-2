Documentación de Función/Subrutina

subroutine zlarfb (character side, character trans, character direct, character storev, integer m, integer n, integer k, complex*16, dimension( ldv, * ) v, integer ldv, complex*16, dimension( ldt, * ) t, integer ldt, complex*16, dimension( ldc, * ) c, integer ldc, complex*16, dimension( ldwork, * ) work, integer ldwork)

ZLARFB aplica un reflector de bloque complejo H o su transpuesta conjugada H**H a una matriz general M por N de números complejos C, desde la izquierda o la derecha.

Propósito:

!>
!> ZLARFB aplica un reflector de bloque complejo H o su transpuesta H**H a una
!> matriz general M por N de números complejos C, desde la izquierda o la
!> derecha.
!>

Parámetros

SIDE 
!>          SIDE es CHARACTER*1
!>          = 'L': aplica H o H**H desde la Izquierda
!>          = 'R': aplica H o H**H desde la Derecha
!>

TRANS

!>          TRANS es CHARACTER*1
!>          = 'N': aplica H (Sin transpuesta)
!>          = 'C': aplica H**H (Transpuesta conjugada)
!>

DIRECT

!>          DIRECT es CHARACTER*1
!>          Indica cómo se forma H a partir de un producto de
!>          reflectores elementales
!>          = 'F': H = H(1) H(2) . . . H(k) (Adelante)
!>          = 'B': H = H(k) . . . H(2) H(1) (Atrás)
!>

STOREV

!>          STOREV es CHARACTER*1
!>          Indica cómo se almacenan los vectores que definen los
!>          reflectores elementales:
!>          = 'C': Por columnas
!>          = 'R': Por filas
!>

M

!>          M es INTEGER
!>          El número de filas de la matriz C.
!>

N

!>          N es INTEGER
!>          El número de columnas de la matriz C.
!>

K

!>          K es INTEGER
!>          El orden de la matriz T (= el número de reflectores
!>          elementales cuyo producto define el reflector de bloque).
!>          Si SIDE = 'L', M >= K >= 0;
!>          si SIDE = 'R', N >= K >= 0.
!>

V

!>          V es un array COMPLEX*16, de dimensión
!>                                (LDV,K) si STOREV = 'C'
!>                                (LDV,M) si STOREV = 'R' y SIDE = 'L'
!>                                (LDV,N) si STOREV = 'R' y SIDE = 'R'
!>          Ver Detalles Adicionales.
!>

LDV

!>          LDV es INTEGER
!>          La dimensión principal del array V.
!>          Si STOREV = 'C' y SIDE = 'L', LDV >= max(1,M);
!>          Si STOREV = 'C' y SIDE = 'R', LDV >= max(1,N);
!>          Si STOREV = 'R', LDV >= K.
!>

T

!>          T es un array COMPLEX*16, de dimensión (LDT,K)
!>          La matriz triangular K por K, T, en la representación del
!>          reflector de bloque.
!>

LDT

!>          LDT es INTEGER
!>          La dimensión principal del array T. LDT >= K.
!>

C

!>          C es un array COMPLEX*16, de dimensión (LDC,N)
!>          En la entrada, la matriz C de M por N.
!>          En la salida, C se sobrescribe con H*C o H**H*C o C*H o C*H**H.
!>

LDC

!>          LDC es INTEGER
!>          La dimensión principal del array C. LDC >= max(1,M).
!>

WORK

!>          WORK es un array COMPLEX*16, de dimensión (LDWORK,K)
!>

LDWORK

!>          LDWORK es INTEGER
!>          La dimensión principal del array WORK.
!>          Si SIDE = 'L', LDWORK >= max(1,N);
!>          Si SIDE = 'R', LDWORK >= max(1,M).
!>
