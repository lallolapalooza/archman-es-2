DOCUMENTACIÓN DE FUNCIÓN/SUBRUTINA

función double precision zla_gbrcond_x (character trans, integer n, integer kl, integer ku, complex*16, dimension( ldab, * ) ab, integer ldab, complex*16, dimension( ldafb, * ) afb, integer ldafb, integer, dimension( * ) ipiv, complex*16, dimension( * ) x, integer info, complex*16, dimension( * ) work, double precision, dimension( * ) rwork)

ZLA_GBRCOND_X calcula el número de condición de la norma infinita de op(A)*diag(x) para matrices generales de banda.

Propósito:

!>
!>    ZLA_GBRCOND_X Calcula el número de condición de la norma infinita de
!>    op(A) * diag(X) donde X es un vector COMPLEX*16.
!>

Parámetros

TRANS 
!>          TRANS es CHARACTER*1
!>     Especifica la forma del sistema de ecuaciones:
!>       = 'N':  A * X = B     (Sin transposición)
!>       = 'T':  A**T * X = B  (Transpuesta)
!>       = 'C':  A**H * X = B  (Transpuesta Conjugada = Transpuesta)
!>

N

!>          N es INTEGER
!>     El número de ecuaciones lineales, es decir, el orden de la
!>     matriz A.  N >= 0.
!>

KL

!>          KL es INTEGER
!>     El número de subdiagonales dentro de la banda de A.  KL >= 0.
!>

KU

!>          KU es INTEGER
!>     El número de superdiagonales dentro de la banda de A.  KU >= 0.
!>

AB

!>          AB es array COMPLEX*16, dimensión (LDAB,N)
!>     En la entrada, la matriz A en almacenamiento de banda, en las filas 1 a KL+KU+1.
!>     La j-ésima columna de A se almacena en la j-ésima columna de la
!>     matriz AB de la siguiente manera:
!>     AB(KU+1+i-j,j) = A(i,j) para max(1,j-KU) <= i <= min(N,j+kl)
!>

LDAB

!>          LDAB es INTEGER
!>     La dimensión principal del array AB.  LDAB >= KL+KU+1.
!>

AFB

!>          AFB es array COMPLEX*16, dimensión (LDAFB,N)
!>     Detalles de la factorización LU de la matriz de banda A, como
!>     calculada por ZGBTRF.  U se almacena como una matriz de banda triangular superior
!>     con KL+KU superdiagonales en las filas 1 a KL+KU+1,
!>     y los multiplicadores utilizados durante la factorización se almacenan
!>     en las filas KL+KU+2 a 2*KL+KU+1.
!>

LDAFB

!>          LDAFB es INTEGER
!>     La dimensión principal del array AFB.  LDAFB >= 2*KL+KU+1.
!>

IPIV

!>          IPIV es array INTEGER, dimensión (N)
!>     Los índices de pivote de la factorización A = P*L*U
!>     tal como se calcula por ZGBTRF; la fila i de la matriz fue intercambiada
!>     con la fila IPIV(i).
!>

X

!>          X es array COMPLEX*16, dimensión (N)
!>     El vector X en la fórmula op(A) * diag(X).
!>

INFO

!>          INFO es INTEGER
!>       = 0:  Salida exitosa.
!>     i > 0:  El i-ésimo argumento es inválido.
!>

WORK

!>          WORK es array COMPLEX*16, dimensión (2*N).
!>     Espacio de trabajo.
!>

RWORK

!>          RWORK es array DOUBLE PRECISION, dimensión (N).
!>     Espacio de trabajo.
!>
