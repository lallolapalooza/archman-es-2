Documentación de la función/subrutina

subrutina zlqt01 (integer m, integer n, complex*16, dimension( lda, * ) a, complex*16, dimension( lda, * ) af, complex*16, dimension( lda, * ) q, complex*16, dimension( lda, * ) l, integer lda, complex*16, dimension( * ) tau, complex*16, dimension( lwork ) work, integer lwork, double precision, dimension( * ) rwork, double precision, dimension( * ) result)

ZLQT01

Propósito:

!>
!> ZLQT01 prueba ZGELQF, que calcula la factorización LQ de una matriz m-por-n
!> A, y prueba parcialmente ZUNGLQ que forma la matriz ortogonal n-por-n
!> Q.
!>
!> ZLQT01 compara L con A*Q', y comprueba que Q es ortogonal.
!>

Parámetros

M 
!>          M es ENTERO
!>          El número de filas de la matriz A.  M >= 0.
!>

N

!>          N es ENTERO
!>          El número de columnas de la matriz A.  N >= 0.
!>

A

!>          A es un array COMPLEX*16, dimensión (LDA,N)
!>          La matriz A de m-por-n.
!>

AF

!>          AF es un array COMPLEX*16, dimensión (LDA,N)
!>          Detalles de la factorización LQ de A, tal como es devuelto por ZGELQF.
!>          Consultar ZGELQF para más detalles.
!>

Q

!>          Q es un array COMPLEX*16, dimensión (LDA,N)
!>          La matriz ortogonal n-por-n Q.
!>

L

!>          L es un array COMPLEX*16, dimensión (LDA,max(M,N))
!>

LDA

!>          LDA es ENTERO
!>          La dimensión principal de los arrays A, AF, Q y L.
!>          LDA >= max(M,N).
!>

TAU

!>          TAU es un array COMPLEX*16, dimensión (min(M,N))
!>          Los factores escalares de los reflectores elementales, tal como son
!>          devueltos por ZGELQF.
!>

WORK

!>          WORK es un array COMPLEX*16, dimensión (LWORK)
!>

LWORK

!>          LWORK es ENTERO
!>          La dimensión del array WORK.
!>

RWORK

!>          RWORK es un array DOUBLE PRECISION, dimensión (max(M,N))
!>

RESULT

!>          RESULT es un array DOUBLE PRECISION, dimensión (2)
!>          Los ratios de prueba:
!>          RESULT(1) = norm( L - A*Q' ) / ( N * norm(A) * EPS )
!>          RESULT(2) = norm( I - Q*Q' ) / ( N * EPS )
!>
