ZLATTP

Propósito:

!>
!> ZLATTP genera una matriz de prueba triangular en almacenamiento empaquetado.
!> IMAT y UPLO especifican de forma única las propiedades de la matriz de prueba,
!> que se devuelve en el array AP.
!>

Parámetros

IMAT 
!>          IMAT es ENTERO
!>          Una clave entera que describe qué matriz generar para esta
!>          ruta.
!>

UPLO

!>          UPLO es CARACTER*1
!>          Especifica si la matriz A será triangular superior o inferior.
!>          = 'U':  Triangular superior
!>          = 'L':  Triangular inferior
!>

TRANS

!>          TRANS es CARACTER*1
!>          Especifica si se usará la matriz o su transpuesta.
!>          = 'N':  Sin transpuesta
!>          = 'T':  Transpuesta
!>          = 'C':  Transpuesta conjugada
!>

DIAG

!>          DIAG es CARACTER*1
!>          Especifica si la matriz A es unitriangular o no.
!>          = 'N':  Triangular no unitaria
!>          = 'U':  Triangular unitaria
!>

ISEED

!>          ISEED es un array ENTERO, dimensión (4)
!>          El vector semilla para el generador de números aleatorios (usado en
!>          ZLATMS). Modificado al salir.
!>

N

!>          N es ENTERO
!>          El orden de la matriz a generar.
!>

AP

!>          AP es un array COMPLEJO*16, dimensión (N*(N+1)/2)
!>          La matriz triangular superior o inferior A, empaquetada por columnas
!>          en un array lineal. La j-ésima columna de A se almacena en el
!>          array AP de la siguiente manera:
!>          si UPLO = 'U', AP((j-1)*j/2 + i) = A(i,j) para 1<=i<=j;
!>          si UPLO = 'L',
!>             AP((j-1)*(n-j) + j*(j+1)/2 + i-j) = A(i,j) para j<=i<=n.
!>

B

!>          B es un array COMPLEJO*16, dimensión (N)
!>          El vector del lado derecho, si IMAT > 10.
!>

WORK

!>          WORK es un array COMPLEJO*16, dimensión (2*N)
!>

RWORK

!>          RWORK es un array DOBLE PRECISIÓN, dimensión (N)
!>

INFO

!>          INFO es ENTERO
!>          = 0:  salida exitosa
!>          < 0:  si INFO = -i, el i-ésimo argumento tenía un valor ilegal
!>
