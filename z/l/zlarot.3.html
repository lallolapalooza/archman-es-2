Documentación de Función/Subrutina

subroutine zlarot (logical lrows, logical lleft, logical lright, integer nl, complex*16 c, complex*16 s, complex*16, dimension( * ) a, integer lda, complex*16 xleft, complex*16 xright)

ZLAROT

Propósito:

!>
!>    ZLAROT aplica una rotación (de Givens) a dos filas o columnas adyacentes,
!>    donde un elemento de la primera y/o última columna/fila se usa para
!>    matrices almacenadas en un formato distinto a GE, de modo que los elementos
!>    de la matriz puedan usarse o modificarse para los que no se proporciona
!>    ningún elemento de array.
!>
!>    Un ejemplo es una matriz simétrica en formato SB (ancho de banda=4), para
!>    la cual UPLO='L': Dos filas adyacentes tendrán el formato:
!>
!>    fila j:     C> C> C> C> C> .  .  .  .
!>    fila j+1:      C> C> C> C> C> .  .  .  .
!>
!>    '*' indica elementos para los que se proporciona almacenamiento,
!>    '.' indica elementos para los que no se proporciona almacenamiento, pero
!>    no son necesariamente cero; sus valores están determinados por
!>    la simetría.  ' ' indica elementos que son necesariamente cero,
!>     y para los que no se proporciona almacenamiento.
!>
!>    Aquellas columnas que tienen dos '*' pueden ser manejadas por DROT.
!>    Aquellas columnas que no tienen '*' pueden ser ignoradas, ya que
!>    mientras las rotaciones de Givens se apliquen cuidadosamente para preservar
!>    la simetría, sus valores están determinados.
!>    Aquellas columnas que tienen una '*' deben ser manejadas por separado,
!>    utilizando variables separadas  y :
!>
!>    fila j:     C> C> C> C> C> p  .  .  .
!>    fila j+1:   q  C> C> C> C> C> .  .  .  .
!>
!>    El elemento p tendría que ser fijado correctamente, luego esa columna
!>    se rota, fijando p a su nuevo valor. La siguiente llamada a
!>    ZLAROT rotará las columnas j y j+1, usando p, y restaurará
!>    la simetría. El elemento q comenzaría siendo cero, y se haría
!>    no cero por la rotación. Más tarde, las rotaciones presumiblemente
!>    se elegirían para poner q a cero.
!>
!>    Secuencias de llamada típicas: rotando las filas i y (i+1).
!>    ------- ------- ---------
!>
!>      Matriz densa general:
!>
!>              CALL ZLAROT(.TRUE.,.FALSE.,.FALSE., N, C,S,
!>                      A(i,1),LDA, DUMMY, DUMMY)
!>
!>      Matriz de banda general en formato GB:
!>
!>              j = MAX(1, i-KL )
!>              NL = MIN( N, i+KU+1 ) + 1-j
!>              CALL ZLAROT( .TRUE., i-KL.GE.1, i+KU.LT.N, NL, C,S,
!>                      A(KU+i+1-j,j),LDA-1, XLEFT, XRIGHT )
!>
!>              [ nótese que i+1-j es solo MIN(i,KL+1) ]
!>
!>      Matriz simétrica de banda en formato SY, ancho de banda K,
!>      solo triángulo inferior:
!>
!>              j = MAX(1, i-K )
!>              NL = MIN( K+1, i ) + 1
!>              CALL ZLAROT( .TRUE., i-K.GE.1, .TRUE., NL, C,S,
!>                      A(i,j), LDA, XLEFT, XRIGHT )
!>
!>      Igual, pero solo triángulo superior:
!>
!>              NL = MIN( K+1, N-i ) + 1
!>              CALL ZLAROT( .TRUE., .TRUE., i+K.LT.N, NL, C,S,
!>                      A(i,i), LDA, XLEFT, XRIGHT )
!>
!>      Matriz simétrica de banda en formato SB, ancho de banda K,
!>      solo triángulo inferior:
!>
!>              [ igual que para SY, excepto:]
!>                  . . . .
!>                      A(i+1-j,j), LDA-1, XLEFT, XRIGHT )
!>
!>              [ nótese que i+1-j es solo MIN(i,K+1) ]
!>
!>      Igual, pero solo triángulo superior:
!>                  . . . . . .
!>                      A(K+1,i), LDA-1, XLEFT, XRIGHT )
!>
!>      Rotando columnas es solo la transpuesta de rotar filas, excepto
!>      para GB y SB: (rotando columnas i e i+1)
!>
!>      GB:
!>              j = MAX(1, i-KU )
!>              NL = MIN( N, i+KL+1 ) + 1-j
!>              CALL ZLAROT( .TRUE., i-KU.GE.1, i+KL.LT.N, NL, C,S,
!>                      A(KU+j+1-i,i),LDA-1, XTOP, XBOTTM )
!>
!>              [nótese que KU+j+1-i es solo MAX(1,KU+2-i)]
!>
!>      SB: (triángulo superior)
!>
!>                   . . . . . .
!>                      A(K+j+1-i,i),LDA-1, XTOP, XBOTTM )
!>
!>      SB: (triángulo inferior)
!>
!>                   . . . . . .
!>                      A(1,i),LDA-1, XTOP, XBOTTM )
!> 
!>  LROWS  - LOGICAL
!>           Si es .TRUE., entonces ZLAROT rotará dos filas. Si es .FALSE.,
!>           entonces rotará dos columnas.
!>           No modificado.
!>
!>  LLEFT  - LOGICAL
!>           Si es .TRUE., entonces XLEFT se usará en lugar del
!>           elemento correspondiente de A para el primer elemento en la
!>           segunda fila (si LROWS=.FALSE.) o columna (si LROWS=.TRUE.)
!>           Si es .FALSE., entonces se usará el elemento correspondiente de A.
!>           No modificado.
!>
!>  LRIGHT - LOGICAL
!>           Si es .TRUE., entonces XRIGHT se usará en lugar del
!>           elemento correspondiente de A para el último elemento en la
!>           primera fila (si LROWS=.FALSE.) o columna (si LROWS=.TRUE.) Si
!>           es .FALSE., entonces se usará el elemento correspondiente de A.
!>           No modificado.
!>
!>  NL     - INTEGER
!>           La longitud de las filas (si LROWS=.TRUE.) o columnas (si
!>           LROWS=.FALSE.) a rotar. Si se usan XLEFT y/o XRIGHT, las
!>           columnas/filas que ocupan deben incluirse en NL, p. ej., si
!>           LLEFT = LRIGHT = .TRUE., entonces NL debe ser al menos 2.
!>           El número de filas/columnas a rotar
!>           excluyendo aquellas que involucran XLEFT y/o XRIGHT no
!>           puede ser negativo, es decir, NL menos cuántos de LLEFT y
!>           LRIGHT son .TRUE. debe ser cero o mayor; si no, se llamará a XERBLA.
!>           No modificado.
!>
!>  C, S   - COMPLEX*16
!>           Especifican la rotación de Givens a aplicar. Si LROWS es
!>           verdadero, entonces la matriz ( c  s )
!>                                 ( _  _ )
!>                                 (-s  c ) se aplica desde la izquierda;
!>           si es falso, entonces la transpuesta (no conjugada) de la misma
!>           se aplica desde la derecha. Nótese que en contraste con la
!>           salida de ZROTG o con la mayoría de las versiones de ZROT, tanto C como S
!>           son complejos. Para una rotación de Givens, |C|**2 + |S|**2 debería
!>           ser 1, pero esto no se verifica.
!>           No modificado.
!>
!>  A      - Array COMPLEX*16.
!>           El array que contiene las filas/columnas a rotar. El
!>           primer elemento de A debe ser el elemento superior izquierdo a
!>           rotar.
!>           Leído y modificado.
!>
!>  LDA    - INTEGER
!>           La dimensión principal de A. Si A contiene
!>           una matriz almacenada en formato GE, HE o SY, entonces esta es solo
!>           la dimensión principal de A tal como se dimensionó en la rutina de llamada.
!>           Si A contiene una matriz almacenada en formato de banda (GB, HB o
!>           SB), entonces debe ser *uno menos* que la dimensión principal
!>           utilizada en la rutina de llamada. Por lo tanto, si A estuviera
!>           dimensionada A(LDA,*) en ZLAROT, entonces A(1,j) sería el
!>           j-ésimo elemento en la primera de las dos filas a rotar,
!>           y A(2,j) sería el j-ésimo en la segunda, independientemente de
!>           cómo se almacene el array en la rutina de llamada. [A
!>           no puede, sin embargo, ser dimensionado así, ya que para
!>           el formato de banda, el número de fila puede exceder LDA, lo cual no
!>           es FORTRAN legal.]
!>           Si LROWS=.TRUE., entonces LDA debe ser al menos 1, de lo contrario
!>           debe ser al menos NL menos el número de valores .TRUE.
!>           en XLEFT y XRIGHT.
!>           No modificado.
!>
!>  XLEFT  - COMPLEX*16
!>           Si LLEFT es .TRUE., entonces XLEFT se usará y modificará
!>           en lugar de A(2,1) (si LROWS=.TRUE.) o A(1,2)
!>           (si LROWS=.FALSE.).
!>           Leído y modificado.
!>
!>  XRIGHT - COMPLEX*16
!>           Si LRIGHT es .TRUE., entonces XRIGHT se usará y modificará
!>           en lugar de A(1,NL) (si LROWS=.TRUE.) o A(NL,1)
!>           (si LROWS=.FALSE.).
!>           Leído y modificado.
!>

NAME

ZLAROT

applies a plane rotation to a pair of complex vectors

Function/Subroutine Documentation

ZLAROT

This subroutine applies a plane rotation to a pair of vectors.

Specifically, it computes and applies the plane rotation

[ x ] = [   c   s ] [ x ]
[ y ]   [ -s'  c  ] [ y ]
where ' denotes conjugate transpose. The rotation is defined by

c = cos(theta)
s = sin(theta)

and is applied to the vectors

x = ( x(1), x(2), ..., x(n) )^T
y = ( y(1), y(2), ..., y(n) )^T

A plane rotation is applied to the first order

x(i) = c*x(i) + s*y(i)
y(i) = -s*x(i) + c*y(i)

for i = 1, 2, ..., n.

Arguments:

N

The number of elements to be applied to the vectors.

X

The first vector.

INCX

The increment for the elements of X.

Y

The second vector.

INCY

The increment for the elements of Y.

C

The value of cos(theta).

S

The value of sin(theta).

Author:


This routine is an adaptation of the Higham routines.

Further Details:


Each vector is stored in an array, and the first element of X is at


location X(1), the second element of X is at X(1+INCX), and so on, using


INCX as the stride between elements in the array.

Similarly, the first element of Y is at Y(1), the second element


of Y is at Y(1+INCY), and so on.

Example:


To apply the rotation to a pair of vectors x = ( 1.0, 2.0, 3.0 ) and


y = ( 4.0, 5.0, 6.0 ) with c = 1/sqrt(2) and s = 1/sqrt(2):


CALL ZLAROT( 3, X, 1, Y, 1, 1/SQRT(2), 1/SQRT(2) )

The vectors X and Y will be updated as follows:


X = ( (1+4)/sqrt(2), (2+5)/sqrt(2), (3+6)/sqrt(2) )


Y = ( (-1+4)/sqrt(2), (-2+5)/sqrt(2), (-3+6)/sqrt(2) )

This is equivalent to


X = ( 3.5355, 4.9497, 6.3640 )


Y = ( 2.1213, 2.1213, 2.1213 )
