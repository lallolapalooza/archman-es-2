doble precisión función zla_syrcond_x (carácter uplo, entero n, complejo*16, dimensión( lda, * ) a, entero lda, complejo*16, dimensión( ldaf, * ) af, entero ldaf, entero, dimensión( * ) ipiv, complejo*16, dimensión( * ) x, entero info, complejo*16, dimensión( * ) work, doble precisión, dimensión( * ) rwork)

ZLA_SYRCOND_X calcula el número de condición de la norma infinita de op(A)*diag(x) para matrices simétricas indefinidas.

Propósito:

!>
!>    ZLA_SYRCOND_X Calcula el número de condición de la norma infinita de
!>    op(A) * diag(X) donde X es un vector COMPLEX*16.
!>

Parámetros

UPLO 
!>          UPLO es CHARACTER*1
!>       = 'U':  El triángulo superior de A está almacenado;
!>       = 'L':  El triángulo inferior de A está almacenado.
!>

N

!>          N es INTEGER
!>     El número de ecuaciones lineales, es decir, el orden de la
!>     matriz A.  N >= 0.
!>

A

!>          A es array COMPLEX*16, dimensión (LDA,N)
!>     En la entrada, la matriz N por N A.
!>

LDA

!>          LDA es INTEGER
!>     La dimensión principal del array A.  LDA >= max(1,N).
!>

AF

!>          AF es array COMPLEX*16, dimensión (LDAF,N)
!>     La matriz diagonal por bloques D y los multiplicadores usados para
!>     obtener el factor U o L como lo calcula ZSYTRF.
!>

LDAF

!>          LDAF es INTEGER
!>     La dimensión principal del array AF.  LDAF >= max(1,N).
!>

IPIV

!>          IPIV es array INTEGER, dimensión (N)
!>     Detalles de los intercambios y la estructura de bloques de D
!>     según lo determinado por ZSYTRF.
!>

X

!>          X es array COMPLEX*16, dimensión (N)
!>     El vector X en la fórmula op(A) * diag(X).
!>

INFO

!>          INFO es INTEGER
!>       = 0:  Salida exitosa.
!>     i > 0:  El i-ésimo argumento es inválido.
!>

WORK

!>          WORK es array COMPLEX*16, dimensión (2*N).
!>     Espacio de trabajo.
!>

RWORK

!>          RWORK es array DOBLE PRECISION, dimensión (N).
!>     Espacio de trabajo.
!>
