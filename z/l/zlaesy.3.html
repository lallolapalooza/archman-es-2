Documentación de la Función/Subrutina

subrutina zlaesy (complex*16 a, complex*16 b, complex*16 c, complex*16 rt1, complex*16 rt2, complex*16 evscal, complex*16 cs1, complex*16 sn1)

ZLAESY calcula los valores y vectores propios de una matriz compleja simétrica de 2x2.

Propósito:

!>
!> ZLAESY calcula la descomposicion en valores propios de una matriz simétrica de 2x2
!>    ( ( A, B );( B, C ) )
!> siempre que la norma de la matriz de vectores propios sea mayor que
!> algún valor umbral.
!>
!> RT1 es el valor propio de mayor valor absoluto, y RT2 el de
!> menor valor absoluto. Si se calculan los vectores propios, entonces
!!> a la salida ( CS1, SN1 ) es el vector propio unitario para RT1, por lo tanto,
!>
!> [  CS1     SN1   ] . [ A  B ] . [ CS1    -SN1   ] = [ RT1  0  ]
!> [ -SN1     CS1   ]   [ B  C ]   [ SN1     CS1   ]   [  0  RT2 ]
!>

Parámetros

A 
!>          A es COMPLEX*16
!>          El elemento ( 1, 1 ) de la matriz de entrada.
!>

B

!>          B es COMPLEX*16
!>          El elemento ( 1, 2 ) de la matriz de entrada. El elemento ( 2, 1 )
!>          también viene dado por B, ya que la matriz de 2x2 es simétrica.
!>

C

!>          C es COMPLEX*16
!>          El elemento ( 2, 2 ) de la matriz de entrada.
!>

RT1

!>          RT1 es COMPLEX*16
!>          El valor propio de mayor módulo.
!>

RT2

!>          RT2 es COMPLEX*16
!>          El valor propio de menor módulo.
!>

EVSCAL

!>          EVSCAL es COMPLEX*16
!>          El valor complejo por el cual se escaló la matriz de vectores
!>          propios para hacerla ortonormal. Si EVSCAL es cero, los vectores
!>          propios no se calcularon. Esto significa una de dos cosas: la matriz
!>          de 2x2 no pudo ser diagonalizada, o la norma de la matriz de vectores
!>          propios antes de escalarla fue mayor que el valor umbral THRESH
!>          (establecido abajo).
!>

CS1

!>          CS1 es COMPLEX*16
!>

SN1

!>          SN1 es COMPLEX*16
!>          Si EVSCAL .NE. 0, ( CS1, SN1 ) es el vector propio derecho unitario
!>          para RT1.
!>
