double precision function zlanhe (norm, uplo, n, a, lda, work)
ZLANHE devuelve el valor de la norma 1, o la norma de Frobenius, o la norma infinito, o el elemento de mayor valor absoluto de una matriz Hermítica compleja.

Documentación de Función/Subrutina

double precision function zlanhe (character norm, character uplo, integer n, complex*16, dimension( lda, * ) a, integer lda, double precision, dimension( * ) work)

ZLANHE devuelve el valor de la norma 1, o la norma de Frobenius, o la norma infinito, o el elemento de mayor valor absoluto de una matriz Hermítica compleja.

Propósito:

!>
!> ZLANHE  devuelve el valor de la norma uno,  o la norma de Frobenius, o
!> la  norma infinito,  o el  elemento de  mayor valor absoluto de una
!> matriz hermítica A.
!>

Devuelve

ZLANHE 
!>
!>    ZLANHE = ( max(abs(A(i,j))), NORM = 'M' o 'm'
!>             (
!>             ( norm1(A),         NORM = '1', 'O' o 'o'
!>             (
!>             ( normI(A),         NORM = 'I' o 'i'
!>             (
!>             ( normF(A),         NORM = 'F', 'f', 'E' o 'e'
!>
!> donde  norm1  denota la  norma uno de una matriz (suma máxima de columna),
!> normI  denota la  norma infinito  de una matriz  (suma máxima de fila) y
!> normF  denota la  norma de Frobenius  de una matriz (raíz cuadrada de la suma
!> de cuadrados).  Tenga en cuenta que  max(abs(A(i,j)))  no es una norma de matriz consistente.
!>

Parámetros

NORM 
!>          NORM es CHARACTER*1
!>          Especifica el valor que se devolverá en ZLANHE como se describe
!>          arriba.
!>

UPLO

!>          UPLO es CHARACTER*1
!>          Especifica si se hará referencia a la parte triangular superior o
!>          inferior de la matriz hermítica A.
!>          = 'U':  Se hace referencia a la parte triangular superior de A
!>          = 'L':  Se hace referencia a la parte triangular inferior de A
!>

N

!>          N es INTEGER
!>          El orden de la matriz A.  N >= 0.  Cuando N = 0, ZLANHE se
!>          establece a cero.
!>

A

!>          A es un array COMPLEX*16, dimension (LDA,N)
!>          La matriz hermítica A.  Si UPLO = 'U', la parte superior de N por N
!>          de A contiene la parte triangular superior de la matriz A, y la
!>          parte triangular estrictamente inferior de A no se referencia.
!>          Si UPLO = 'L', la parte inferior de N por N de A contiene la
!>          parte triangular inferior de la matriz A, y la parte triangular
!>          estrictamente superior de A no se referencia. Tenga en cuenta que
!>          las partes imaginarias de los elementos diagonales no necesitan
!>          establecerse y se asumen como cero.
!>

LDA

!>          LDA es INTEGER
!>          La dimensión principal del array A.  LDA >= max(N,1).
!>

WORK

!>          WORK es un array DOUBLE PRECISION, dimension (MAX(1,LWORK)),
!>          donde LWORK >= N cuando NORM = 'I' o '1' o 'O'; de lo contrario,
!>          WORK no se referencia.
!>
