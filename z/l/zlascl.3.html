Documentación de la Función/Subrutina

subroutine zlascl (character type, integer kl, integer ku, double precision cfrom, double precision cto, integer m, integer n, complex*16, dimension( lda, * ) a, integer lda, integer info)

ZLASCL multiplica la matriz compleja M por N A por el escalar real CTO/CFROM. Esto se hace sin desbordamiento/subdesbordamiento siempre que el resultado final CTO*A(I,J)/CFROM no se desborde/subdesborde. TYPE especifica que A puede ser completa, triangular superior, triangular inferior, superior Hessenberg, o bandeada.

Propósito:

!>
!> ZLASCL multiplica la matriz compleja M por N A por el escalar real
!> CTO/CFROM. Se hace sin sobre/subdesbordamiento siempre que el resultado
!> final CTO*A(I,J)/CFROM no se sobre/subdesborde. TYPE indica que
!> A puede ser completa, triangular superior, triangular inferior, superior
!> Hessenberg, o bandeada.
!>

Parámetros

TYPE 
!>          TYPE es CHARACTER*1
!>          TYPE indica el tipo de almacenamiento de la matriz de entrada.
!>          = 'G':  A es una matriz completa.
!>          = 'L':  A es una matriz triangular inferior.
!>          = 'U':  A es una matriz triangular superior.
!>          = 'H':  A es una matriz superior Hessenberg.
!>          = 'B':  A es una matriz bandeada simétrica con ancho de banda inferior KL
!>                  y ancho de banda superior KU y con solo la mitad inferior almacenada.
!>          = 'Q':  A es una matriz bandeada simétrica con ancho de banda inferior KL
!>                  y ancho de banda superior KU y con solo la mitad superior almacenada.
!>          = 'Z':  A es una matriz bandeada con ancho de banda inferior KL y superior
!>                  KU. Ver ZGBTRF para detalles de almacenamiento.
!>

KL

!>          KL es INTEGER
!>          El ancho de banda inferior de A. Se referencia solo si TYPE = 'B',
!>          'Q' o 'Z'.
!>

KU

!>          KU es INTEGER
!>          El ancho de banda superior de A. Se referencia solo si TYPE = 'B',
!>          'Q' o 'Z'.
!>

CFROM

!>          CFROM es DOUBLE PRECISION
!>

CTO

!>          CTO es DOUBLE PRECISION
!>
!>          La matriz A se multiplica por CTO/CFROM. A(I,J) se calcula
!>          sin sobre/subdesbordamiento si el resultado final CTO*A(I,J)/CFROM
!>          puede ser representado sin sobre/subdesbordamiento. CFROM debe ser
!>          distinto de cero.
!>

M

!>          M es INTEGER
!>          El número de filas de la matriz A. M >= 0.
!>

N

!>          N es INTEGER
!>          El número de columnas de la matriz A. N >= 0.
!>

A

!>          A es un array COMPLEX*16, de dimensión (LDA,N)
!>          La matriz a multiplicar por CTO/CFROM. Ver TYPE para el
!>          tipo de almacenamiento.
!>

LDA

!>          LDA es INTEGER
!>          La dimensión principal del array A.
!>          Si TYPE = 'G', 'L', 'U', 'H', LDA >= max(1,M);
!>             TYPE = 'B', LDA >= KL+1;
!>             TYPE = 'Q', LDA >= KU+1;
!>             TYPE = 'Z', LDA >= 2*KL+KU+1.
!>

INFO

!>          INFO es INTEGER
!>          0 - salida exitosa
!>          <0 - si INFO = -i, el i-ésimo argumento tenía un valor ilegal.
!>
