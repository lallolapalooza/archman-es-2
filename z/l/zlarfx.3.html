NOMBRE

SRC/zlarfx.f

SINOPSIS

Funciones/Subrutinas


subrutina zlarfx (side, m, n, v, tau, c, ldc, work)
ZLARFX aplica un reflector elemental a una matriz rectangular general, con bucles desenrollados cuando el reflector tiene orden ≤ 10.

Documentación de Función/Subrutina

subrutina zlarfx (carácter side, entero m, entero n, complejo*16, dimensión( * ) v, complejo*16 tau, complejo*16, dimensión( ldc, * ) c, entero ldc, complejo*16, dimensión( * ) work)

ZLARFX aplica un reflector elemental complejo H a una matriz compleja m por n C, desde la izquierda o desde la derecha. H se representa en la forma


H = I - tau * v * v**H

donde tau es un escalar complejo y v es un vector complejo.

Si tau = 0, entonces H se toma como la matriz unidad.

Esta versión utiliza código en línea si H tiene orden < 11.

Parámetros

SIDE 
          SIDE es CHARACTER*1
          = 'L': forma  H * C
          = 'R': forma  C * H

M

          M es INTEGER
          El número de filas de la matriz C.

N

          N es INTEGER
          El número de columnas de la matriz C.

V

          V es un array COMPLEX*16, dimensión (M) si SIDE = 'L'
                                        o (N) si SIDE = 'R'
          El vector v en la representación de H.

TAU

          TAU es COMPLEX*16
          El valor tau en la representación de H.

C

          C es un array COMPLEX*16, dimensión (LDC,N)
          En la entrada, la matriz m por n C.
          En la salida, C se sobrescribe con la matriz H * C si SIDE = 'L',
          o C * H si SIDE = 'R'.

LDC

          LDC es INTEGER
          La dimensión principal del array C. LDC >= max(1,M).

WORK

          WORK es un array COMPLEX*16, dimensión (N) si SIDE = 'L'
                                            o (M) si SIDE = 'R'
          WORK no se hace referencia si H tiene orden < 11.
