Documentación de la función/subrutina

subrutina zlarscl2 (integer m, integer n, double precision, dimension( * ) d, complex*16, dimension( ldx, * ) x, integer ldx)

ZLARSCL2 realiza un escalado diagonal recíproco en una matriz.

Propósito:

!>
!> ZLARSCL2 realiza un escalado diagonal recíproco en una matriz:
!>   x <-- inv(D) * x
!> donde la matriz diagonal DOUBLE PRECISION D se almacena como un vector.
!>
!> Eventualmente será reemplazado por BLAS_zge_diag_scale en el nuevo
!> estándar BLAS.
!>

Parámetros

M 
!>          M es INTEGER
!>     El número de filas de D y X. M >= 0.
!>

N

!>          N es INTEGER
!>     El número de columnas de X. N >= 0.
!>

D

!>          D es un array DOUBLE PRECISION, longitud M
!>     Matriz diagonal D, almacenada como un vector de longitud M.
!>

X

!>          X es un array COMPLEX*16, dimensión (LDX,N)
!>     En la entrada, la matriz X a escalar por D.
!>     En la salida, la matriz escalada.
!>

LDX

!>          LDX es INTEGER
!>     La dimensión principal de la matriz X. LDX >= M.
!>
