Documentación de Función/Subrutina

subroutine zlatrs (character uplo, character trans, character diag, character normin, integer n, complex*16, dimension( lda, * ) a, integer lda, complex*16, dimension( * ) x, double precision scale, double precision, dimension( * ) cnorm, integer info)

ZLATRS resuelve un sistema de ecuaciones triangular con el factor de escala establecido para prevenir el desbordamiento.

Propósito:

!>
!> ZLATRS resuelve uno de los sistemas triangulares
!>
!>    A * x = s*b,  A**T * x = s*b,  o  A**H * x = s*b,
!>
!> con escalado para prevenir el desbordamiento. Aquí A es una matriz superior o inferior
!> triangular, A**T denota la transpuesta de A, A**H denota la
!> transpuesta conjugada de A, x y b son vectores de n elementos, y s es un
!> factor de escala, usualmente menor o igual a 1, elegido de tal manera que los
!> componentes de x sean menores que el umbral de desbordamiento. Si el
!> problema sin escalar no causa desbordamiento, se llama a la rutina BLAS de nivel 2
!> ZTRSV. Si la matriz A es singular (A(j,j) = 0 para algún j),
!> entonces s se establece en 0 y se devuelve una solución no trivial a A*x = 0.
!>

Parámetros

UPLO 
!>          UPLO es CHARACTER*1
!>          Especifica si la matriz A es superior o inferior triangular.
!>          = 'U':  Triangular superior
!>          = 'L':  Triangular inferior
!>

TRANS

!>          TRANS es CHARACTER*1
!>          Especifica la operación aplicada a A.
!>          = 'N':  Resolver A * x = s*b     (Sin transpuesta)
!>          = 'T':  Resolver A**T * x = s*b  (Transpuesta)
!>          = 'C':  Resolver A**H * x = s*b  (Transpuesta conjugada)
!>

DIAG

!>          DIAG es CHARACTER*1
!>          Especifica si la matriz A es unitaria o no.
!>          = 'N':  No unitaria triangular
!>          = 'U':  Unitaria triangular
!>

NORMIN

!>          NORMIN es CHARACTER*1
!>          Especifica si CNORM ha sido establecido o no.
!>          = 'Y':  CNORM contiene las normas de columna en la entrada
!>          = 'N':  CNORM no está establecido en la entrada. En la salida, las normas se
!>                  calcularán y se almacenarán en CNORM.
!>

N

!>          N es INTEGER
!>          El orden de la matriz A.  N >= 0.
!>

A

!>          A es un array COMPLEX*16, dimension (LDA,N)
!>          La matriz triangular A.  Si UPLO = 'U', la parte superior triangular
!>          de n por n de la matriz A contiene la matriz triangular superior, y la parte estrictamente
!>          triangular inferior de A no se referencia. Si UPLO = 'L', la parte inferior triangular
!>          de n por n de la matriz A contiene la matriz triangular inferior, y la parte estrictamente
!>          triangular superior de A no se referencia. Si DIAG = 'U', los elementos diagonales de A
!>          tampoco se referencian y se asumen que son 1.
!>

LDA

!>          LDA es INTEGER
!>          La dimensión principal del array A.  LDA >= max (1,N).
!>

X

!>          X es un array COMPLEX*16, dimension (N)
!>          En la entrada, el lado derecho b del sistema triangular.
!>          En la salida, X se sobrescribe con el vector solución x.
!>

SCALE

!>          SCALE es DOUBLE PRECISION
!>          El factor de escala s para el sistema triangular
!>             A * x = s*b,  A**T * x = s*b,  o  A**H * x = s*b.
!>          Si SCALE = 0, la matriz A es singular o mal escalada, y
!>          el vector x es una solución exacta o aproximada a A*x = 0.
!>

CNORM

!>          CNORM es un array DOUBLE PRECISION, dimension (N)
!>
!>          Si NORMIN = 'Y', CNORM es un argumento de entrada y CNORM(j)
!>          contiene la norma de la parte no diagonal de la j-ésima columna
!>          de A. Si TRANS = 'N', CNORM(j) debe ser mayor o igual a
!>          la norma infinito, y si TRANS = 'T' o 'C', CNORM(j)
!>          debe ser mayor o igual a la norma 1.
!>
!>          Si NORMIN = 'N', CNORM es un argumento de salida y CNORM(j)
!>          devuelve la norma 1 de la parte no diagonal de la j-ésima columna
!>          de A.
!>

INFO

!>          INFO es INTEGER
!>          = 0:  salida exitosa
!>          < 0:  si INFO = -k, el k-ésimo argumento tuvo un valor ilegal
!>

Detalles adicionales:

!>
!> Se calcula un límite aproximado para x; si este es menor que el desbordamiento, se llama a ZTRSV,
!> de lo contrario, se utiliza un código específico que verifica posibles
!> desbordamientos o divisiones por cero en cada operación.
!>
!> Se utiliza un esquema columna por columna para resolver A*x = b. El algoritmo básico
!> si A es triangular inferior es
!>
!>       x[1:n] := b[1:n]
!>       for j = 1, ..., n
!>            x(j) := x(j) / A(j,j)
!>            x[j+1:n] := x[j+1:n] - x(j) * A[j+1:n,j]
!>       end
!>
!> Definimos límites para los componentes de x después de j iteraciones del bucle:
!>     M(j) = límite de x[1:j]
!>     G(j) = límite de x[j+1:n]
!> Inicialmente, sea M(0) = 0 y G(0) = max{x(i), i=1,...,n}.
!>
!> Entonces, para la iteración j+1 tenemos
!>     M(j+1) <= G(j) / | A(j+1,j+1) |
!>     G(j+1) <= G(j) + M(j+1) * | A[j+2:n,j+1] |
!>            <= G(j) ( 1 + CNORM(j+1) / | A(j+1,j+1) | )
!>
!> donde CNORM(j+1) es mayor o igual a la norma infinito de
!> la columna j+1 de A, sin contar la diagonal. Por lo tanto
!>
!>     G(j) <= G(0) product ( 1 + CNORM(i) / | A(i,i) | )
!>                  1<=i<=j
!> y
!>
!>     |x(j)| <= ( G(0) / |A(j,j)| ) product ( 1 + CNORM(i) / |A(i,i)| )
!>                                   1<=i< j
!>
!> Dado que |x(j)| <= M(j), usamos la rutina BLAS de nivel 2 ZTRSV si el
!> recíproco del M(j) máximo, j=1,..,n, es mayor que
!> max(subdesbordamiento, 1/desbordamiento).
!>
!> El límite de x(j) también se usa para determinar cuándo un paso en el
!> método columna por columna puede realizarse sin temor a desbordamiento. Si
!> el límite calculado es mayor que una constante grande, x se escala para
!> prevenir el desbordamiento, pero si el límite desborda, x se establece en 0, x(j) en
!> 1, y scale en 0, y se encuentra una solución no trivial a A*x = 0.
!>
!> De manera similar, se utiliza un esquema fila por fila para resolver A**T *x = b o
!> A**H *x = b. El algoritmo básico para A triangular superior es
!>
!>       for j = 1, ..., n
!>            x(j) := ( b(j) - A[1:j-1,j]' * x[1:j-1] ) / A(j,j)
!>       end
!>
!> Simultáneamente calculamos dos límites
!>       G(j) = límite de ( b(i) - A[1:i-1,i]' * x[1:i-1] ), 1<=i<=j
!>       M(j) = límite de x(i), 1<=i<=j
!>
!> Los valores iniciales son G(0) = 0, M(0) = max{b(i), i=1,..,n}, y añadimos la restricción
!> G(j) >= G(j-1) y M(j) >= M(j-1) para j >= 1.
!> Entonces el límite de x(j) es
!>
!>       M(j) <= M(j-1) * ( 1 + CNORM(j) ) / | A(j,j) |
!>            <= M(0) * product ( ( 1 + CNORM(i) ) / |A(i,i)| )
!>                      1<=i<=j
!> y podemos llamar de forma segura a ZTRSV si 1/M(n) y 1/G(n) son ambos mayores
!> que max(subdesbordamiento, 1/desbordamiento).
!>
