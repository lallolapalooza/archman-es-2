subroutine zlasyf_rk (character uplo, integer n, integer nb, integer kb, complex*16, dimension( lda, * ) a, integer lda, complex*16, dimension( * ) e, integer, dimension( * ) ipiv, complex*16, dimension( ldw, * ) w, integer ldw, integer info)

ZLASYF_RK calcula una factorización parcial de una matriz simétrica compleja indefinida usando el método de pivoteo diagonal de Bunch-Kaufman acotado (rook).

Propósito:

!> ZLASYF_RK calcula una factorización parcial de una matriz simétrica
!> compleja A usando el método de pivoteo diagonal acotado de Bunch-Kaufman
!> (rook). La factorización parcial tiene la forma:
!>
!> A  =  ( I  U12 ) ( A11  0  ) (  I       0    )  si UPLO = 'U', o:
!>       ( 0  U22 ) (  0   D  ) ( U12**T U22**T )
!>
!> A  =  ( L11  0 ) (  D   0  ) ( L11**T L21**T )  si UPLO = 'L',
!>       ( L21  I ) (  0  A22 ) (  0       I    )
!>
!> donde el orden de D es como máximo NB. El orden real se devuelve en
!> el argumento KB, y es NB o NB-1, o N si N <= NB.
!>
!> ZLASYF_RK es una rutina auxiliar llamada por ZSYTRF_RK. Utiliza
!> código bloqueado (llamando a BLAS de Nivel 3) para actualizar la submatriz
!> A11 (si UPLO = 'U') o A22 (si UPLO = 'L').
!>

Parámetros

UPLO 
!>          UPLO es CHARACTER*1
!>          Especifica si la parte triangular superior o inferior de la
!>          matriz simétrica A está almacenada:
!>          = 'U':  Triangular superior
!>          = 'L':  Triangular inferior
!>

N

!>          N es INTEGER
!>          El orden de la matriz A.  N >= 0.
!>

NB

!>          NB es INTEGER
!>          El número máximo de columnas de la matriz A que deben ser
!>          factorizadas. NB debe ser al menos 2 para permitir bloques
!>          de pivote de 2x2.
!>

KB

!>          KB es INTEGER
!>          El número de columnas de A que fueron realmente factorizadas.
!>          KB es NB-1 o NB, o N si N <= NB.
!>

A

!>          A es un array COMPLEX*16, de dimensión (LDA,N)
!>          En la entrada, la matriz simétrica A.
!>            Si UPLO = 'U': la parte triangular superior N x N líder
!>            de A contiene la parte triangular superior de la matriz A,
!>            y la parte estrictamente triangular inferior de A no
!>            se referencia.
!>
!>            Si UPLO = 'L': la parte triangular inferior N x N líder
!>            de A contiene la parte triangular inferior de la matriz A,
!>            y la parte estrictamente triangular superior de A no
!>            se referencia.
!>
!>          En la salida, contiene:
!>            a) SÓLO los elementos diagonales de la matriz simétrica
!>               diagonalmente por bloques D en la diagonal de A, es decir,
!>               D(k,k) = A(k,k); (los elementos superdiagonales (o
!>               subdiagonales) de D se almacenan en la salida en el
!>               array E), y
!>            b) Si UPLO = 'U': factor U en la parte superdiagonal de A.
!>               Si UPLO = 'L': factor L en la parte subdiagonal de A.
!>

LDA

!>          LDA es INTEGER
!>          La dimensión principal del array A. LDA >= max(1,N).
!>

E

!>          E es un array COMPLEX*16, de dimensión (N)
!>          En la salida, contiene los elementos superdiagonales (o
!>          subdiagonales) de la matriz simétrica diagonalmente por bloques
!>          D con bloques diagonales de 1x1 o 2x2, donde
!>          Si UPLO = 'U': E(i) = D(i-1,i), i=2:N, E(1) se establece en 0;
!>          Si UPLO = 'L': E(i) = D(i+1,i), i=1:N-1, E(N) se establece en 0.
!>
!>          NOTA: Para un bloque diagonal de 1x1 D(k), donde
!>          1 <= k <= N, el elemento E(k) se establece en 0 en ambos
!>          casos UPLO = 'U' o UPLO = 'L'.
!>

IPIV

!>          IPIV es un array INTEGER, de dimensión (N)
!>          IPIV describe la matriz de permutación P en la factorización
!>          de la matriz A de la siguiente manera. El valor absoluto de IPIV(k)
!>          representa el índice de la fila y columna que fueron
!>          intercambiadas con la k-ésima fila y columna. El valor de UPLO
!>          describe el orden en el que se aplicaron los intercambios.
!>          Además, el signo de IPIV representa la estructura de bloques
!>          de la matriz simétrica diagonalmente por bloques D con bloques
!>          diagonales de 1x1 o 2x2 que corresponden a 1 o 2 intercambios
!>          en cada paso de factorización.
!>
!>          Si UPLO = 'U',
!>          (en orden de factorización, k disminuye de N a 1):
!>            a) Una única entrada positiva IPIV(k) > 0 significa:
!>               D(k,k) es un bloque diagonal de 1x1.
!>               Si IPIV(k) != k, las filas y columnas k e IPIV(k) fueron
!>               intercambiadas en la submatriz A(1:N,N-KB+1:N);
!>               Si IPIV(k) = k, no ocurrió ningún intercambio.
!>
!>
!>            b) Un par de entradas negativas consecutivas
!>               IPIV(k) < 0 y IPIV(k-1) < 0 significa:
!>               D(k-1:k,k-1:k) es un bloque diagonal de 2x2.
!>               (NOTA: las entradas negativas en IPIV aparecen SÓLO en pares).
!>               1) Si -IPIV(k) != k, las filas y columnas
!>                  k y -IPIV(k) fueron intercambiadas
!>                  en la matriz A(1:N,N-KB+1:N).
!>                  Si -IPIV(k) = k, no ocurrió ningún intercambio.
!>               2) Si -IPIV(k-1) != k-1, las filas y columnas
!>                  k-1 y -IPIV(k-1) fueron intercambiadas
!>                  en la submatriz A(1:N,N-KB+1:N).
!>                  Si -IPIV(k-1) = k-1, no ocurrió ningún intercambio.
!>
!>            c) En ambos casos a) y b) siempre se cumple ABS( IPIV(k) ) <= k.
!>
!>            d) NOTA: Cualquier entrada IPIV(k) es siempre DISTINTA DE CERO en la salida.
!>
!>          Si UPLO = 'L',
!>          (en orden de factorización, k aumenta de 1 a N):
!>            a) Una única entrada positiva IPIV(k) > 0 significa:
!>               D(k,k) es un bloque diagonal de 1x1.
!>               Si IPIV(k) != k, las filas y columnas k e IPIV(k) fueron
!>               intercambiadas en la submatriz A(1:N,1:KB).
!>               Si IPIV(k) = k, no ocurrió ningún intercambio.
!>
!>            b) Un par de entradas negativas consecutivas
!>               IPIV(k) < 0 y IPIV(k+1) < 0 significa:
!>               D(k:k+1,k:k+1) es un bloque diagonal de 2x2.
!>               (NOTA: las entradas negativas en IPIV aparecen SÓLO en pares).
!>               1) Si -IPIV(k) != k, las filas y columnas
!>                  k y -IPIV(k) fueron intercambiadas
!>                  en la submatriz A(1:N,1:KB).
!>                  Si -IPIV(k) = k, no ocurrió ningún intercambio.
!>               2) Si -IPIV(k+1) != k+1, las filas y columnas
!>                  k-1 y -IPIV(k-1) fueron intercambiadas
!>                  en la submatriz A(1:N,1:KB).
!>                  Si -IPIV(k+1) = k+1, no ocurrió ningún intercambio.
!>
!>            c) En ambos casos a) y b) siempre se cumple ABS( IPIV(k) ) >= k.
!>

NAME

zlasyf_rk - zlasyf_rk computes the factorization of a general matrix A (or a Hermitian-Peierls matrix A) using partial pivoting with rook equilibration.

SYNOPSIS

  SUBROUTINE ZLASYF_RK(
      UPLO, N, NB, A, LDA, IPIV, WORK, LWORK, INFO
  )

  CHARACTER          UPLO
  INTEGER            N, NB, LDA, LWORK, INFO
  COMPLEX*16         A( LDA, * ), WORK( * )
  INTEGER            IPIV( * )

Function/Subroutine Documentation

Purpose:

This routine is deprecated. Use ZSYGVX, ZHEGVX or ZLAGSX instead.

ZLASYF_RK computes the factorization of a real matrix A (or a Hermitian matrix A) using partial pivoting with rook equilibration.

The factorization is in the form:

    A = P*U*T*U**H*Q if UPLO = 'U', or
    A = P*L*T*L**H*Q if UPLO = 'L',

where P and Q are permutation matrices. T is a tridiagonal matrix. U is a unit upper triangular matrix if UPLO = 'U', and L is a unit lower triangular matrix if UPLO = 'L'.

This is the "rook" factorization, meaning that partial pivoting is used for the diagonal elements and rook pivoting is used for the off-diagonal elements.

Arguments:

UPLO CHARACTER*1

Specifies whether the matrix A is upper or lower triangular. ‘U’ => A is upper triangular

‘L’ => A is lower triangular.

N INTEGER

The order of the matrix A. N >= 0.

NB INTEGER

The block size for recursive factorization. NB >= 1.

A COMPLEX*16 array, dimension (LDA,N)

On entry, the array A must contain the block of the matrix A to be factored.

On exit, the factors P, L and U are stored on the diagonal and upper or lower triangular part of the array A.

LDA INTEGER

The leading dimension of the array A. LDA >= max(1,N).

IPIV INTEGER array, dimension (N)

Details of the interchanges, i.e., the block pivots.

Column k of the matrix was interchanged with column IPIV(k).

IPIV(k) > 0: Rook partial pivoting was used, and column k was interchanged with column IPIV(k).

IPIV(k) < 0: The diagonal element of the k-th block was interchanged with column abs(IPIV(k)).

WORK COMPLEX*16 array, dimension (LWORK)

On exit, WORK contains the LWORK elements of the block vector W.

LWORK INTEGER

The size of the array WORK. LWORK >= N. For optimal performance, LWORK >= N*NB.

INFO INTEGER

= 0: successful exit

> 0: if INFO = k, then k > 0 and the element k-th diagonal element of the block diagonal matrix D is zero. If INFO = k, the factorization has been completed, but D is singular (so the last k-1 columns of U or L are linearly dependent on the previous columns). The factorization is not useful for solving a linear system, but is still valid for rank determination. See Further Details.

< 0: if INFO = -k, then the k-th argument had an illegal value. Kendeck, November 2006
