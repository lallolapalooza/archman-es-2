subrutina zla_gbamv (trans, m, n, kl, ku, alpha, ab, ldab, x, incx, beta, y, incy)

ZLA_GBAMV realiza una operación de matriz-vector para calcular límites de error.

Documentación de Función/Subrutina

subrutina zla_gbamv (integer trans, integer m, integer n, integer kl, integer ku, double precision alpha, complex*16, dimension( ldab, * ) ab, integer ldab, complex*16, dimension( * ) x, integer incx, double precision beta, double precision, dimension( * ) y, integer incy)

ZLA_GBAMV realiza una operación de matriz-vector para calcular límites de error.

Propósito:

!>
!> ZLA_GBAMV  realiza una de las operaciones de matriz-vector
!>
!>         y := alpha*abs(A)*abs(x) + beta*abs(y),
!>    o    y := alpha*abs(A)**T*abs(x) + beta*abs(y),
!>
!> donde alpha y beta son escalares, x e y son vectores y A es una
!> matriz de m por n.
!>
!> Esta función se utiliza principalmente para calcular límites de error.
!> Para proteger contra la subflotación durante la evaluación, los
!> componentes del vector resultante se perturban lejos de cero en
!> (N+1) veces el umbral de subflotación. Para evitar errores
!> innecesariamente grandes para la estructura de bloque incrustada en
!> matrices generales, los componentes cero no se perturban. Se considera
!> una entrada cero si todas las multiplicaciones involucradas
!> en el cálculo de esa entrada tienen al menos un multiplicando cero.
!>

Parámetros

TRANS 
!>          TRANS es INTEGER
!>           En la entrada, TRANS especifica la operación a realizar
!>           como sigue:
!>
!>             BLAS_NO_TRANS      y := alpha*abs(A)*abs(x) + beta*abs(y)
!>             BLAS_TRANS         y := alpha*abs(A**T)*abs(x) + beta*abs(y)
!>             BLAS_CONJ_TRANS    y := alpha*abs(A**T)*abs(x) + beta*abs(y)
!>
!>           Sin cambios a la salida.
!>

M

!>          M es INTEGER
!>           En la entrada, M especifica el número de filas de la matriz A.
!>           M debe ser al menos cero.
!>           Sin cambios a la salida.
!>

N

!>          N es INTEGER
!>           En la entrada, N especifica el número de columnas de la matriz A.
!>           N debe ser al menos cero.
!>           Sin cambios a la salida.
!>

KL

!>          KL es INTEGER
!>           El número de subdiagonales dentro de la banda de A. KL >= 0.
!>

KU

!>          KU es INTEGER
!>           El número de superdiagonales dentro de la banda de A. KU >= 0.
!>

ALPHA

!>          ALPHA es DOUBLE PRECISION
!>           En la entrada, ALPHA especifica el escalar alpha.
!>           Sin cambios a la salida.
!>

AB

!>          AB es un array COMPLEX*16, dimensión ( LDAB, n )
!>           Antes de la entrada, la parte principal de m por n del array AB
!>           debe contener la matriz de coeficientes.
!>           Sin cambios a la salida.
!>

LDAB

!>          LDAB es INTEGER
!>           En la entrada, LDAB especifica la primera dimensión de AB tal
!>           como se declara en el programa (sub)llamante. LDAB debe ser
!>           al menos max( 1, m ).
!>           Sin cambios a la salida.
!>

X

!>          X es un array COMPLEX*16, dimensión
!>           ( 1 + ( n - 1 )*abs( INCX ) ) cuando TRANS = 'N' o 'n'
!>           y al menos
!>           ( 1 + ( m - 1 )*abs( INCX ) ) en caso contrario.
!>           Antes de la entrada, el array X incrementado debe contener el
!>           vector x.
!>           Sin cambios a la salida.
!>

INCX

!>          INCX es INTEGER
!>           En la entrada, INCX especifica el incremento para los elementos
!>           de X. INCX no debe ser cero.
!>           Sin cambios a la salida.
!>

BETA

!>          BETA es DOUBLE PRECISION
!>           En la entrada, BETA especifica el escalar beta. Cuando BETA se
!>           proporciona como cero, Y no necesita ser establecido en la entrada.
!>           Sin cambios a la salida.
!>

Y

!>          Y es un array DOUBLE PRECISION, dimensión
!>           ( 1 + ( m - 1 )*abs( INCY ) ) cuando TRANS = 'N' o 'n'
!>           y al menos
!>           ( 1 + ( n - 1 )*abs( INCY ) ) en caso contrario.
!>           Antes de la entrada con BETA distinto de cero, el array Y
!>           incrementado debe contener el vector y. A la salida, Y se
!>           sobrescribe con el vector y actualizado.
!>           Si m o n es cero, entonces Y no se hace referencia y la función
!>           realiza un retorno rápido.
!>

INCY

!>          INCY es INTEGER
!>           En la entrada, INCY especifica el incremento para los elementos
!>           de Y. INCY no debe ser cero.
!>           Sin cambios a la salida.
!>
!>  Rutina BLAS de Nivel 2.
!>
