ZLAQZ2

Propósito:

!>
!> ZLAQZ2 realiza AED
!>

Parámetros

ILSCHUR 
!>          ILSCHUR es LOGICAL
!>              Determina si se actualizará o no la forma de Schur completa
!>

ILQ

!>          ILQ es LOGICAL
!>              Determina si se actualizará o no la matriz Q
!>

ILZ

!>          ILZ es LOGICAL
!>              Determina si se actualizará o no la matriz Z
!>

N

!>          N es INTEGER
!>          El orden de las matrices A, B, Q y Z. N >= 0.
!>

ILO

!>          ILO es INTEGER
!>

IHI

!>          IHI es INTEGER
!>          ILO e IHI marcan las filas y columnas de (A,B) que
!>          se normalizarán
!>

NW

!>          NW es INTEGER
!>          El tamaño deseado de la ventana de deflación.
!>

A

!>          A es una matriz COMPLEX*16, dimensión (LDA, N)
!>

LDA

!>          LDA es INTEGER
!>          La dimensión principal de la matriz A. LDA >= max( 1, N ).
!>

B

!>          B es una matriz COMPLEX*16, dimensión (LDB, N)
!>

LDB

!>          LDB es INTEGER
!>          La dimensión principal de la matriz B. LDB >= max( 1, N ).
!>

Q

!>          Q es una matriz COMPLEX*16, dimensión (LDQ, N)
!>

LDQ

!>          LDQ es INTEGER
!>

Z

!>          Z es una matriz COMPLEX*16, dimensión (LDZ, N)
!>

LDZ

!>          LDZ es INTEGER
!>

NS

!>          NS es INTEGER
!>          El número de valores propios no convergidos disponibles para
!>          usar como desplazamientos.
!>

ND

!>          ND es INTEGER
!>          El número de valores propios convergidos encontrados.
!>

ALPHA

!>          ALPHA es una matriz COMPLEX*16, dimensión (N)
!>          Cada escalar alpha define un valor propio
!>          de GNEP.
!>

BETA

!>          BETA es una matriz COMPLEX*16, dimensión (N)
!>          Los escalares beta que definen los valores propios de GNEP.
!>          Juntos, las cantidades alpha = ALPHA(j) y
!>          beta = BETA(j) representan el j-ésimo valor propio del par de matrices
!>          (A,B), en una de las formas lambda = alpha/beta o
!>          mu = beta/alpha. Dado que lambda o mu pueden desbordarse,
!>          no deben calcularse, en general.
!>

QC

!>          QC es una matriz COMPLEX*16, dimensión (LDQC, NW)
!>

LDQC

!>          LDQC es INTEGER
!>

ZC

!>          ZC es una matriz COMPLEX*16, dimensión (LDZC, NW)
!>

LDZC

!>          LDZ es INTEGER
!>

WORK

!>          WORK es una matriz COMPLEX*16, dimensión (MAX(1,LWORK))
!>          Al salir, si INFO >= 0, WORK(1) devuelve el LWORK óptimo.
!>

LWORK

!>          LWORK es INTEGER
!>          La dimensión de la matriz WORK. LWORK >= max(1,N).
!>
!>          Si LWORK = -1, entonces se asume una consulta de espacio de trabajo; la rutina
!>          solo calcula el tamaño óptimo de la matriz WORK, devuelve
!>          este valor como la primera entrada de la matriz WORK, y XERBLA no emite ningún mensaje de error
!>          relacionado con LWORK.
!>

RWORK

!>          RWORK es una matriz DOUBLE PRECISION, dimensión (N)
!>

REC

!>          REC indica el nivel actual de recursión. Debe establecerse
!>          en 0 en la primera llamada.
!>

INFO

!>          INFO es INTEGER
!>          = 0: salida exitosa
!>          < 0: si INFO = -i, el i-ésimo argumento tenía un valor ilegal
!>
