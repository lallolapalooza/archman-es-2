subrutina zlatrz (m, n, l, a, lda, tau, work)

ZLATRZ factoriza una matriz trapezoidal superior mediante transformaciones unitarias.

DOCUMENTACIÓN DE FUNCIÓN/SUBRUTINA

subrutina zlatrz (integer m, integer n, integer l, complex*16, dimension( lda, * ) a, integer lda, complex*16, dimension( * ) tau, complex*16, dimension( * ) work)

ZLATRZ factoriza una matriz trapezoidal superior M por (M+L) mediante transformaciones unitarias.

Propósito:

!>
!> ZLATRZ factoriza la matriz trapezoidal superior compleja M por (M+L)
!> [ A1 A2 ] = [ A(1:M,1:M) A(1:M,N-L+1:N) ] como ( R  0 ) * Z mediante
!> transformaciones unitarias, donde Z es una matriz unitaria (M+L) por (M+L)
!> y R y A1 son matrices triangulares superiores M por M.
!>

Parámetros

M 
!>          M es ENTERO
!>          El número de filas de la matriz A. M >= 0.
!>

N

!>          N es ENTERO
!>          El número de columnas de la matriz A. N >= 0.
!>

L

!>          L es ENTERO
!>          El número de columnas de la matriz A que contienen la
!>          parte significativa de los vectores de Householder. N-M >= L >= 0.
!>

A

!>          A es un array COMPLEX*16, dimensión (LDA,N)
!>          En la entrada, la parte trapezoidal superior principal M por N de
!>          la matriz A debe contener la matriz a factorizar.
!>          En la salida, la parte triangular superior principal M por M de A
!>          contiene la matriz triangular superior R, y los elementos N-L+1 a
!>          N de las primeras M filas de A, junto con la matriz TAU, representan
!>          la matriz unitaria Z como un producto de M transformaciones elementales.
!>

LDA

!>          LDA es ENTERO
!>          La dimensión principal del array A. LDA >= max(1,M).
!>

TAU

!>          TAU es un array COMPLEX*16, dimensión (M)
!>          Los factores escalares de las transformaciones elementales.
!>

WORK

!>          WORK es un array COMPLEX*16, dimensión (M)
!>

Detalles adicionales:

!>
!>  La factorización se obtiene por el método de Householder. La k-ésima
!>  matriz de transformación, Z( k ), que se utiliza para introducir ceros en
!>  la ( m - k + 1 )-ésima fila de A, se da en la forma
!>
!>     Z( k ) = ( I     0   ),
!>              ( 0  T( k ) )
!>
!>  donde
!>
!>     T( k ) = I - tau*u( k )*u( k )**H,   u( k ) = (   1    ),
!>                                                 (   0    )
!>                                                 ( z( k ) )
!>
!>  tau es un escalar y z( k ) es un vector de longitud l. tau y z( k )
!>  se eligen para aniquilar los elementos de la k-ésima fila de A2.
!>
!>  El escalar tau se devuelve en el k-ésimo elemento de TAU y el vector
!>  u( k ) en la k-ésima fila de A2, de modo que los elementos de z( k )
!>  están en a( k, l + 1 ), ..., a( k, n ). Los elementos de R se devuelven en
!>  la parte triangular superior de A1.
!>
!>  Z se da por
!>
!>     Z =  Z( 1 ) * Z( 2 ) * ... * Z( m ).
!>
