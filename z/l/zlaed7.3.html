subrutina zlaed7 (integer n, integer cutpnt, integer qsiz, integer tlvls, integer curlvl, integer curpbm, double precision, dimension( * ) d, complex*16, dimension( ldq, * ) q, integer ldq, double precision rho, integer, dimension( * ) indxq, double precision, dimension( * ) qstore, integer, dimension( * ) qptr, integer, dimension( * ) prmptr, integer, dimension( * ) perm, integer, dimension( * ) givptr, integer, dimension( 2, * ) givcol, double precision, dimension( 2, * ) givnum, complex*16, dimension( * ) work, double precision, dimension( * ) rwork, integer, dimension( * ) iwork, integer info)

ZLAED7 utilizada por ZSTEDC. Calcula el sistema de autovalores actualizado de una matriz diagonal después de la modificación por una matriz simétrica de rango uno. Se utiliza solo para el problema de autovalores que requiere todos los autovalores y opcionalmente los autovectores de una matriz hermitiana densa o de banda que se ha reducido a forma tridiagonal.

Propósito:

!>
!> ZLAED7 calcula el sistema de autovalores actualizado de una matriz
!> diagonal después de la modificación por una matriz simétrica de rango uno.
!> Esta subrutina se utiliza solo para el problema de autovalores que requiere todos
!> los autovalores y opcionalmente los autovectores de una matriz hermitiana densa o de banda
!> que se ha reducido a forma tridiagonal.
!>
!>   T = Q(in) ( D(in) + RHO * Z*Z**H ) Q**H(in) = Q(out) * D(out) * Q**H(out)
!>
!>   donde Z = Q**Hu, u es un vector de longitud N con unos en los
!>   elementos CUTPNT y CUTPNT + 1 y ceros en otros lugares.
!>
!>    Los autovectores de la matriz original se almacenan en Q, y los
!>    autovalores están en D. El algoritmo consta de tres etapas:
!>
!>       La primera etapa consiste en desinflar el tamaño del problema
!>       cuando hay múltiples autovalores o si hay un cero en
!>       el vector Z. Por cada ocurrencia de este tipo, la dimensión del
!>       problema de la ecuación secular se reduce en uno. Esta etapa
!>       es realizada por la subrutina DLAED2.
!>
!>       La segunda etapa consiste en calcular los autovalores
!>       actualizados. Esto se hace encontrando las raíces de la ecuación
!>       secular a través de la subrutina DLAED4 (llamada por SLAED3).
!>       Esta subrutina también calcula los autovectores del problema
!>       actual.
!>
!>       La etapa final consiste en calcular los autovectores actualizados
!>       directamente utilizando los autovalores actualizados. Los autovectores
!>       para el problema actual se multiplican con los autovectores del
!>       problema general.
!>

Parámetros

N 
!>          N es INTEGER
!>         La dimensión de la matriz tridiagonal simétrica.  N >= 0.
!>

CUTPNT

!>          CUTPNT es INTEGER
!>         Contiene la ubicación del último autovalor en la submatriz
!>         principal.  min(1,N) <= CUTPNT <= N.
!>

QSIZ

!>          QSIZ es INTEGER
!>         La dimensión de la matriz unitaria utilizada para reducir
!>         la matriz completa a forma tridiagonal.  QSIZ >= N.
!>

TLVLS

!>          TLVLS es INTEGER
!>         El número total de niveles de fusión en el árbol de
!>         dividir y conquistar general.
!>

CURLVL

!>          CURLVL es INTEGER
!>         El nivel actual en la subrutina de fusión general,
!>         0 <= curlvl <= tlvls.
!>

CURPBM

!>          CURPBM es INTEGER
!>         El problema actual en el nivel actual de la subrutina
!>         de fusión general (contando desde la esquina superior
!>         izquierda hacia la inferior derecha).
!>

D

!>          D es un array DOUBLE PRECISION, dimension (N)
!>         En la entrada, los autovalores de la matriz perturbada de rango 1.
!>         En la salida, los autovalores de la matriz reparada.
!>

Q

!>          Q es un array COMPLEX*16, dimension (LDQ,N)
!>         En la entrada, los autovectores de la matriz perturbada de rango 1.
!>         En la salida, los autovectores de la matriz tridiagonal reparada.
!>

LDQ

!>          LDQ es INTEGER
!>         La dimensión principal del array Q.  LDQ >= max(1,N).
!>

RHO

!>          RHO es DOUBLE PRECISION
!>         Contiene el elemento subdiagonal utilizado para crear la
!>         modificación de rango 1.
!>

INDXQ

!>          INDXQ es un array INTEGER, dimension (N)
!>         Contiene la permutación que reintegrará el subproblema
!>         recién resuelto en orden ordenado,
!>         es decir, D( INDXQ( I = 1, N ) ) estará en orden ascendente.
!>

IWORK

!>          IWORK es un array INTEGER, dimension (4*N)
!>

RWORK

!>          RWORK es un array DOUBLE PRECISION,
!>                                 dimension (3*N+2*QSIZ*N)
!>

WORK

!>          WORK es un array COMPLEX*16, dimension (QSIZ*N)
!>

QSTORE

!>          QSTORE es un array DOUBLE PRECISION, dimension (N**2+1)
!>         Almacena los autovectores de las submatrices encontradas
!>         durante el dividir y conquistar, empaquetadas juntas. QPTR
!>         apunta al inicio de las submatrices.
!>

QPTR

!>          QPTR es un array INTEGER, dimension (N+2)
!>         Lista de índices que apuntan al inicio de las submatrices
!>         almacenadas en QSTORE. Las submatrices se numeran a partir de
!>         la esquina inferior izquierda del árbol de dividir y
!>         conquistar, de izquierda a derecha y de abajo hacia arriba.
!>

PRMPTR

!>          PRMPTR es un array INTEGER, dimension (N lg N)
!>         Contiene una lista de punteros que indican dónde en PERM
!>         se almacena la permutación de un nivel. PRMPTR(i+1) - PRMPTR(i)
!>         indica el tamaño de la permutación y también el tamaño del
!>         problema completo y no desinflado.
!>

PERM

!>          PERM es un array INTEGER, dimension (N lg N)
!>         Contiene las permutaciones (de la deflación y el ordenamiento)
!>         que se aplicarán a cada bloque de autovalores.
!>

GIVPTR

!>          GIVPTR es un array INTEGER, dimension (N lg N)
!>         Contiene una lista de punteros que indican dónde en GIVCOL se
!>         almacenan las rotaciones de Givens de un nivel. GIVPTR(i+1) -
!>         GIVPTR(i) indica el número de rotaciones de Givens.
!>

GIVCOL

!>          GIVCOL es un array INTEGER, dimension (2, N lg N)
!>         Cada par de números indica un par de columnas para realizar
!>         una rotación de Givens.
!>

GIVNUM

!>          GIVNUM es un array DOUBLE PRECISION, dimension (2, N lg N)
!>         Cada número indica el valor S que se utilizará en la
!>         rotación de Givens correspondiente.
!>

INFO

!>          INFO es INTEGER
!>          = 0:  salida exitosa.
!>          < 0:  si INFO = -i, el i-ésimo argumento tuvo un valor ilegal.
!>          > 0:  si INFO = 1, un autovalor no convergió.
!>
