Documentación de Función/Subrutina

subroutine zlatmt (integer m, integer n, character dist, integer, dimension( 4 ) iseed, character sym, double precision, dimension( * ) d, integer mode, double precision cond, double precision dmax, integer rank, integer kl, integer ku, character pack, complex*16, dimension( lda, * ) a, integer lda, complex*16, dimension( * ) work, integer info)

ZLATMT

Propósito:

!>
!>    ZLATMT genera matrices aleatorias con valores singulares especificados
!>    (o hermíticas con valores propios especificados)
!>    para probar programas LAPACK.
!>
!>    ZLATMT opera aplicando la siguiente secuencia de
!>    operaciones:
!>
!>      Establecer la diagonal en D, donde D puede ser de entrada o
!>         calculada según MODE, COND, DMAX y SYM
!>         como se describe a continuación.
!>
!>      Generar una matriz con la estructura de banda apropiada, mediante uno
!>         de dos métodos:
!>
!>      Método A:
!>          Generar una matriz M x N densa multiplicando D por la izquierda
!>              y por la derecha por matrices unitarias aleatorias, luego:
!>
!>          Reducir el ancho de banda según KL y KU, usando
!>              transformaciones de Householder.
!>
!>      Método B:
!>          Convertir la matriz de ancho de banda 0 (es decir, diagonal) a una
!>              matriz de ancho de banda 1 usando rotaciones de Givens, 
!>              elementos fuera de banda hacia atrás, muy similar a QR; luego convertir
!>              el ancho de banda 1 a una matriz de ancho de banda 2, etc. Nota
!>              que para anchos de banda razonablemente pequeños (en relación con M y
!>              N) esto requiere menos almacenamiento, ya que no se genera una matriz densa.
!>              Además, para matrices hermíticas o simétricas,
!>              solo se genera un triángulo.
!>
!>      Método A se elige si el ancho de banda es una gran fracción del
!>          orden de la matriz, y LDA es al menos M (para que una matriz densa
!>          pueda ser almacenada.) Método B se elige si el ancho de banda
!>          es pequeño (< 1/2 N para hermítica o simétrica, < .3 N+M para
!>          no simétrica), o LDA es menor que M y no menor que el
!>          ancho de banda.
!>
!>      Empaquetar la matriz si se desea. Las opciones especificadas por PACK son:
!>         sin empaquetar
!>         poner a cero la mitad superior (si es hermítica)
!>         poner a cero la mitad inferior (si es hermítica)
!>         almacenar la mitad superior en columna (si es hermítica o
!>               triangular superior)
!>         almacenar la mitad inferior en columna (si es hermítica o
!>               triangular inferior)
!>         almacenar el triángulo inferior en formato de banda (si es hermítica o
!>               triangular inferior)
!>         almacenar el triángulo superior en formato de banda (si es hermítica o
!>               triangular superior)
!>         almacenar la matriz completa en formato de banda
!>      Si se elige el Método B, y se especifica el formato de banda, entonces la
!>         matriz se generará en formato de banda, por lo que no será necesario
!>         reempaquetar.
!>

Parámetros

M 
!>          M es INTEGER
!>           El número de filas de A. No modificado.
!>

N

!>          N es INTEGER
!>           El número de columnas de A. N debe ser igual a M si la matriz
!>           es simétrica o hermítica (es decir, si SYM no es 'N')
!>           No modificado.
!>

DIST

!>          DIST es CHARACTER*1
!>           En la entrada, DIST especifica el tipo de distribución a utilizar
!>           para generar los valores propios/singulares aleatorios.
!>           'U' => UNIFORME( 0, 1 )  ( 'U' de uniforme )
!>           'S' => UNIFORME( -1, 1 ) ( 'S' de simétrico )
!>           'N' => NORMAL( 0, 1 )   ( 'N' de normal )
!>           No modificado.
!>

ISEED

!>          ISEED es un array INTEGER, de dimensión ( 4 )
!>           En la entrada, ISEED especifica la semilla del generador de números
!>           aleatorios. Debe estar entre 0 y 4095 inclusive,
!>           y ISEED(4) debe ser impar. El generador de números aleatorios
!>           utiliza una secuencia congruencial lineal limitada a enteros pequeños,
!>           y por lo tanto debería producir números aleatorios independientes de la máquina.
!>           Los valores de ISEED se modifican al salir, y pueden usarse en la siguiente llamada a ZLATMT
!>           para continuar la misma secuencia de números aleatorios.
!>           Modificado al salir.
!>

SYM

!>          SYM es CHARACTER*1
!>           Si SYM='H', la matriz generada es hermítica, con
!>             valores propios especificados por D, COND, MODE y DMAX; pueden
!>             ser positivos, negativos o cero.
!>           Si SYM='P', la matriz generada es hermítica, con
!>             valores propios (= valores singulares) especificados por D, COND,
!>             MODE y DMAX; no serán negativos.
!>           Si SYM='N', la matriz generada es no simétrica, con
!>             valores singulares especificados por D, COND, MODE y DMAX;
!>             no serán negativos.
!>           Si SYM='S', la matriz generada es simétrica (compleja),
!>             con valores singulares especificados por D, COND, MODE y
!>             DMAX; no serán negativos.
!>           No modificado.
!>

D

!>          D es un array DOUBLE PRECISION, de dimensión ( MIN( M, N ) )
!>           Este array se utiliza para especificar los valores singulares o
!>           valores propios de A (ver SYM, arriba). Si MODE=0, entonces D
!>           se asume que contiene los valores propios/singulares, de lo contrario
!>           se calcularán según MODE, COND y DMAX,
!>           y se colocarán en D.
!>           Modificado si MODE es distinto de cero.
!>

MODE

!>          MODE es INTEGER
!>           En la entrada esto describe cómo se especifican los valores propios/singulares:
!>           MODE = 0 significa usar D como entrada
!>           MODE = 1 establece D(1)=1 y D(2:RANK)=1.0/COND
!>           MODE = 2 establece D(1:RANK-1)=1 y D(RANK)=1.0/COND
!>           MODE = 3 establece D(I)=COND**(-(I-1)/(RANK-1))
!>           MODE = 4 establece D(i)=1 - (i-1)/(N-1)*(1 - 1/COND)
!>           MODE = 5 establece D a números aleatorios en el rango
!>                    ( 1/COND , 1 ) de tal manera que sus logaritmos
!>                    estén distribuidos uniformemente.
!>           MODE = 6 establece D a números aleatorios de la misma distribución
!>                    que el resto de la matriz.
!>           MODE < 0 tiene el mismo significado que ABS(MODE), excepto que
!>              el orden de los elementos de D se invierte.
!>           Por lo tanto, si MODE es positivo, D tiene entradas que varían de
!>              1 a 1/COND, si es negativo, de 1/COND a 1,
!>           Si SYM='H', y MODE no es 0, 6 ni -6, entonces
!>              los elementos de D también se multiplicarán por un signo aleatorio
!>              (es decir, +1 o -1.)
!>           No modificado.
!>

COND

!>          COND es DOUBLE PRECISION
!>           En la entrada, se utiliza como se describe en MODE arriba.
!>           Si se usa, debe ser >= 1. No modificado.
!>

DMAX

!>          DMAX es DOUBLE PRECISION
!>           Si MODE no es -6, 0 ni 6, los contenidos de D, como se
!>           calculan según MODE y COND, se escalarán por
!>           DMAX / max(abs(D(i))); por lo tanto, el valor propio o singular
!>           máximo absoluto (que es la norma) será abs(DMAX).
!>           Tenga en cuenta que DMAX no tiene por qué ser positivo: si DMAX es negativo
!>           (o cero), D se escalará por un número negativo (o cero).
!>           No modificado.
!>

RANK

!>          RANK es INTEGER
!>           El rango de la matriz a generar para los modos 1, 2, 3 solamente.
!>           D( RANK+1:N ) = 0.
!>           No modificado.
!>

zlatmt(3) - LAPACK

NAME

zlatmt

generate a complex triangular-band matrix with specified properties

SYNOPSIS

SUBROUTINE ZLATMT(
   M, N, DIST,             SYM,      MODE,      COND,
   DMAX, PACK,             A,        LDA,       WORK,
   INFO
)
INTEGER M, N, INFO
CHARACTER*1 DIST, SYM, PACK
CHARACTER*1 MODE
REAL*8 COND, DMAX
COMPLEX*16 A( LDA, * ), WORK( * )

Function/Subroutine Documentation

This routine generates a complex general triangular-band matrix (or array) with specified properties.

Author

Univ. of Tennessee

Univ. of California Berkeley

Univ. of Colorado Denver

NAG Ltd.

Arguments

M
M is INTEGER
           The number of rows of the matrix A.
N
N is INTEGER
           The number of columns of the matrix A.
DIST
DIST is CHARACTER*1
           The distribution of the matrix A, as follows:
           'U' => upper triangular
           'L' => lower triangular
           'B' => upper and lower triangular (i.e., full matrix)
           'Z' => upper triangular band matrix
           'A' => lower triangular band matrix
           'Q' => upper and lower triangular band matrix
           Not modified.
SYM
SYM is CHARACTER*1
           Specifies the symmetry of the matrix:
           'N' => no symmetry (e.g., no packing)
           'U' => upper triangular packed
           'L' => lower triangular packed
           'S' => symmetric
           'H' => hermitian
           'P' => general packed matrix (lower triangle stored columnwise)
           'Q' => general packed matrix (upper triangle stored columnwise)
           Not modified.
MODE
MODE is INTEGER
           The generation mode, and the matrix properties, as follows:
           MODE = -1: generate a matrix with condition number CND = abs(COND).
                     The elements are chosen uniformly from (-1, 1).
                     The matrix is scaled so that the largest singular
                     value is DMAX.
           MODE = 0: generate a matrix with condition number CND = abs(COND).
                     The elements are chosen uniformly from (-1, 1).
           MODE = 1: generate a matrix with condition number CND = 1.0
                     The elements are chosen uniformly from (-1, 1).
           MODE = 2: generate a matrix with condition number CND = 1.0 / abs(COND).
                     The elements are chosen uniformly from (-1, 1).
           MODE = 3: generate a matrix with condition number CND = 1.0.
                     The elements are chosen uniformly from (-1, 1).
           MODE = 4: generate a matrix with condition number CND = abs(COND).
                     The elements are chosen uniformly from (-1, 1) and the
                     diagonal elements are chosen uniformly from (0, 1).
           MODE = 5: generate a matrix with condition number CND = abs(COND).
                     The elements are chosen uniformly from (-1, 1) and the
                     diagonal elements are chosen uniformly from (0, 1).
           MODE = 6: generate a matrix with condition number CND = 1.0 / abs(COND).
                     The elements are chosen uniformly from (-1, 1) and the
                     diagonal elements are chosen uniformly from (0, 1).
           MODE = 7: generate a matrix with condition number CND = 1.0.
                     The elements are chosen uniformly from (-1, 1) and the
                     diagonal elements are chosen uniformly from (0, 1).
           For MODE < 0, the singular values are chosen to be
           abs(COND)**(i/(N-1)) for i = 0, ..., N-1.
           For MODE > 0, the singular values are chosen to be
           abs(COND)**(i/(N-1)) for i = 0, ..., N-1.
           Not modified.
COND
COND is REAL*8
           The condition number of the matrix. This is only used if
           MODE is not 1, 3, or 7.
           Not modified.
DMAX
DMAX is REAL*8
           The maximum value of the singular values of the matrix. This is
           only used if MODE is -1.
           Not modified.
KL
KL is INTEGER
           This specifies the lower bandwidth of the matrix. For
           example, KL=0 implies upper triangular, KL=1 implies upper
           Hessenberg, and KL being at least M-1 means that the matrix
           has full lower bandwidth. KL must equal KU if the matrix
           is symmetric or hermitian.
           Not modified.
KU
KU is INTEGER
           This specifies the upper bandwidth of the matrix. For
           example, KU=0 implies lower triangular, KU=1 implies lower
           Hessenberg, and KU being at least N-1 means that the matrix
           has full upper bandwidth. KL must equal KU if the matrix
           is symmetric or hermitian.
           Not modified.
PACK
PACK is CHARACTER*1
           This specifies packing of matrix as follows:
           'N' => no packing
           'U' => zero out all subdiagonal entries (if symmetric
                  or hermitian)
           'L' => zero out all superdiagonal entries (if symmetric
                  or hermitian)
           'C' => store the upper triangle columnwise (only if the
                  matrix is symmetric, hermitian, or upper triangular)
           'R' => store the lower triangle columnwise (only if the
                  matrix is symmetric, hermitian, or lower triangular)
           'B' => store the lower triangle in band storage scheme
                  (only if the matrix is symmetric, hermitian, or
                  lower triangular)
           'Q' => store the upper triangle in band storage scheme
                  (only if the matrix is symmetric, hermitian, or
                  upper triangular)
           'Z' => store the entire matrix in band storage scheme
                      (pivoting can be provided for by using this
                      option to store A in the trailing rows of
                      the allocated storage)

           Using these options, the various LAPACK packed and banded
           storage schemes can be obtained:
           GB                    - use 'Z'
           PB, SB, HB, or TB     - use 'B' or 'Q'
           PP, SP, HB, or TP     - use 'C' or 'R'

           If two calls to ZLATMT differ only in the PACK parameter,
           they will generate mathematically equivalent matrices.
           Not modified.
A
A is COMPLEX*16 array, dimension ( LDA, N )
           On exit A is the desired test matrix. A is first generated
           in full (unpacked) form, and then packed, if so specified
           by PACK. Thus, the first M elements of the first N
           columns will always be modified. If PACK specifies a
           packed or banded storage scheme, all LDA elements of the
           first N columns will be modified; the elements of the
           array which do not correspond to elements of the generated
           matrix are set to zero.
           Modified.
LDA
LDA is INTEGER
           LDA specifies the first dimension of A as declared in the
           calling program. If PACK='N', 'U', 'L', 'C', or 'R', then
           LDA must be at least M. If PACK='B' or 'Q', then LDA must
           be at least MIN( KL, M-1) (which is equal to MIN(KU,N-1)).
           If PACK='Z', LDA must be large enough to hold the packed
           array: MIN( KU, N-1) + MIN( KL, M-1) + 1.
           Not modified.
WORK
WORK is COMPLEX*16 array, dimension ( 3*MAX( N, M ) )
           Workspace.
           Modified.
INFO
INFO is INTEGER
           Error code. On exit, INFO will be set to one of the
           following values:
             0 => normal return
            -1 => M negative or unequal to N and SYM='S', 'H', or 'P'
            -2 => N negative
            -3 => DIST illegal string
            -5 => SYM illegal string
            -7 => MODE not in range -6 to 6
            -8 => COND less than 1.0, and MODE neither -6, 0 nor 6
           -10 => KL negative
           -11 => KU negative, or SYM is not 'N' and KU is not equal to
                  KL
           -12 => PACK illegal string, or PACK='U' or 'L', and SYM='N';
                  or PACK='C' or 'Q' and SYM='N' and KL is not zero;
                  or PACK='R' or 'B' and SYM='N' and KU is not zero;
                  or PACK='U', 'L', 'C', 'R', 'B', or 'Q', and M is not
                  N.
           -14 => LDA is less than M, or PACK='Z' and LDA is less than
                  MIN(KU,N-1) + MIN(KL,M-1) + 1.
             1  => Error return from DLATM7
             2  => Cannot scale to DMAX (max. sing. value is 0)
             3  => Error return from ZLAGGE, ZLAGHE or ZLAGSY
