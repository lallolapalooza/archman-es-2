ZLATSP

Propósito:

!>
!> ZLATSP genera una matriz de prueba especial para la factorización compleja
!> simétrica (indefinida) para matrices empaquetadas. Los bloques pivote de
!> la matriz generada estarán en el siguiente orden:
!>    Bloque pivote de 2x2, no diagonalizable
!>    Bloque pivote de 1x1
!>    Bloque pivote de 2x2, diagonalizable
!>    (el ciclo se repite)
!> Se requiere un intercambio de filas para cada bloque de 2x2 no diagonalizable.
!>

Parámetros

UPLO 
!>          UPLO es CHARACTER
!>          Especifica si la matriz generada debe ser triangular superior o
!>          inferior.
!>          = 'U': Triangular superior
!>          = 'L': Triangular inferior
!>

N

!>          N es INTEGER
!>          La dimensión de la matriz a generar.
!>

X

!>          X es un array COMPLEX*16, dimensión (N*(N+1)/2)
!>          La matriz generada en formato de almacenamiento empaquetado. La matriz
!>          consiste en bloques diagonales de 3x3 y 2x2 que resultan en la
!>          secuencia de pivote dada anteriormente. La matriz fuera de estos
!>          bloques diagonales es cero.
!>

ISEED

!>          ISEED es un array INTEGER, dimensión (4)
!>          En la entrada, la semilla para el generador de números aleatorios. El último
!>          de los cuatro enteros debe ser impar. (modificado en la salida)
!>
