función de precisión doble zla_gbrcond_x (carácter trans, entero n, entero kl, entero ku, complejo*16, dimensión( ldab, * ) ab, entero ldab, complejo*16, dimensión( ldafb, * ) afb, entero ldafb, entero, dimensión( * ) ipiv, complejo*16, dimensión( * ) x, entero info, complejo*16, dimensión( * ) work, precisión doble, dimensión( * ) rwork)

ZLA_GBRCOND_X calcula el número de condición de la norma infinito de op(A)*diag(x) para matrices generales de banda.

Propósito:

!>
!>    ZLA_GBRCOND_X Calcula el número de condición de la norma infinito de
!>    op(A) * diag(X) donde X es un vector COMPLEX*16.
!>

Parámetros

TRANS 
!>          TRANS es CHARACTER*1
!>     Especifica la forma del sistema de ecuaciones:
!>       = 'N':  A * X = B     (Sin transpuesta)
!>       = 'T':  A**T * X = B  (Transpuesta)
!>       = 'C':  A**H * X = B  (Transpuesta conjugada = Transpuesta)
!>

N

!>          N es ENTERO
!>     El número de ecuaciones lineales, es decir, el orden de
!>     la matriz A.  N >= 0.
!>

KL

!>          KL es ENTERO
!>     El número de subdiagonales dentro de la banda de A.  KL >= 0.
!>

KU

!>          KU es ENTERO
!>     El número de superdiagonales dentro de la banda de A.  KU >= 0.
!>

AB

!>          AB es array COMPLEX*16, dimensión (LDAB,N)
!>     En la entrada, la matriz A en almacenamiento de banda, en las filas 1 a KL+KU+1.
!>     La columna j de A se almacena en la columna j del
!>     array AB como sigue:
!>     AB(KU+1+i-j,j) = A(i,j) para max(1,j-KU)<=i<=min(N,j+kl)
!>

LDAB

!>          LDAB es ENTERO
!>     La dimensión principal del array AB.  LDAB >= KL+KU+1.
!>

AFB

!>          AFB es array COMPLEX*16, dimensión (LDAFB,N)
!>     Detalles de la factorización LU de la matriz de banda A, tal como
!>     calculada por ZGBTRF.  U se almacena como una matriz triangular superior
!>     de banda con KL+KU superdiagonales en las filas 1 a KL+KU+1,
!>     y los multiplicadores usados durante la factorización se almacenan
!>     en las filas KL+KU+2 a 2*KL+KU+1.
!>

LDAFB

!>          LDAFB es ENTERO
!>     La dimensión principal del array AFB.  LDAFB >= 2*KL+KU+1.
!>

IPIV

!>          IPIV es array ENTERO, dimensión (N)
!>     Los índices de pivote de la factorización A = P*L*U
!>     calculada por ZGBTRF; la fila i de la matriz fue intercambiada
!>     con la fila IPIV(i).
!>

X

!>          X es array COMPLEX*16, dimensión (N)
!>     El vector X en la fórmula op(A) * diag(X).
!>

INFO

!>          INFO es ENTERO
!>       = 0:  Salida exitosa.
!>     i > 0:  El i-ésimo argumento es inválido.
!>

WORK

!>          WORK es array COMPLEX*16, dimensión (2*N).
!>     Espacio de trabajo.
!>

RWORK

!>          RWORK es array de PRECISIÓN DOBLE, dimensión (N).
!>     Espacio de trabajo.
!>
