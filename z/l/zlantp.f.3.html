ZLANTP devuelve el valor de la norma 1, o la norma de Frobenius, o la norma infinito, o el elemento de mayor valor absoluto de una matriz triangular suministrada en forma empaquetada.

Documentación de función/subrutina

doble precisión función zlantp (carácter norm, carácter uplo, carácter diag, entero n, complejo*16, dimensión( * ) ap, doble precisión, dimensión( * ) work)

ZLANTP devuelve el valor de la norma 1, o la norma de Frobenius, o la norma infinito, o el elemento de mayor valor absoluto de una matriz triangular suministrada en forma empaquetada.

Propósito:

!>
!> ZLANTP  devuelve el valor de la norma uno,  o la norma de Frobenius, o
!> la  norma infinito,  o el  elemento de  mayor valor absoluto  de una
!> matriz triangular A, suministrada en forma empaquetada.
!>

Devuelve

ZLANTP 
!>
!>    ZLANTP = ( max(abs(A(i,j))), NORM = 'M' o 'm'
!>             (
!>             ( norm1(A),         NORM = '1', 'O' o 'o'
!>             (
!>             ( normI(A),         NORM = 'I' o 'i'
!>             (
!>             ( normF(A),         NORM = 'F', 'f', 'E' o 'e'
!>
!> donde  norm1  denota la  norma uno de una matriz (suma máxima de columna),
!> normI  denota la  norma infinito  de una matriz  (suma máxima de fila) y
!> normF  denota la  norma de Frobenius  de una matriz (raíz cuadrada de la suma de
!> cuadrados).  Tenga en cuenta que  max(abs(A(i,j)))  no es una norma matricial consistente.
!>

Parámetros

NORM 
!>          NORM es CHARACTER*1
!>          Especifica el valor que se devolverá en ZLANTP como se describe
!>          arriba.
!>

UPLO

!>          UPLO es CHARACTER*1
!>          Especifica si la matriz A es triangular superior o inferior.
!>          = 'U':  Triangular superior
!>          = 'L':  Triangular inferior
!>

DIAG

!>          DIAG es CHARACTER*1
!>          Especifica si la matriz A es unitaria o no.
!>          = 'N':  No unitaria
!>          = 'U':  Unitaria
!>

N

!>          N es INTEGER
!>          El orden de la matriz A.  N >= 0.  Cuando N = 0, ZLANTP se
!>          establece a cero.
!>

AP

!>          AP es arreglo COMPLEX*16, dimensión (N*(N+1)/2)
!>          La matriz triangular superior o inferior A, empaquetada por
!>          columnas en un arreglo lineal.  La j-ésima columna de A se
!>          almacena en el arreglo AP de la siguiente manera:
!>          si UPLO = 'U', AP(i + (j-1)*j/2) = A(i,j) para 1<=i<=j;
!>          si UPLO = 'L', AP(i + (j-1)*(2n-j)/2) = A(i,j) para j<=i<=n.
!>          Tenga en cuenta que cuando DIAG = 'U', los elementos del arreglo AP
!>          correspondientes a los elementos diagonales de la matriz A
!>          no se referencian, pero se asumen como uno.
!>

WORK

!>          WORK es arreglo DOUBLE PRECISION, dimensión (MAX(1,LWORK)),
!>          donde LWORK >= N cuando NORM = 'I'; de lo contrario, WORK no
!>          se referencia.
!>
