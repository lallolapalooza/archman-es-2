subroutine zla_geamv (trans, m, n, alpha, a, lda, x, incx, beta, y, incy)

ZLA_GEAMV calcula un producto matriz-vector utilizando una matriz general para calcular límites de error.

Documentación de función/subrutina

subrutina zla_geamv (integer trans, integer m, integer n, double precision alpha, complex*16, dimension( lda, * ) a, integer lda, complex*16, dimension( * ) x, integer incx, double precision beta, double precision, dimension( * ) y, integer incy)

ZLA_GEAMV calcula un producto matriz-vector utilizando una matriz general para calcular límites de error.

Propósito:

!>
!> ZLA_GEAMV  realiza una de las operaciones de matriz-vector
!>
!>         y := alpha*abs(A)*abs(x) + beta*abs(y),
!>    o    y := alpha*abs(A)**T*abs(x) + beta*abs(y),
!>
!> donde alpha y beta son escalares, x e y son vectores y A es una
!> matriz de m por n.
!>
!> Esta función se utiliza principalmente para calcular límites de error.
!> Para protegerse contra el subdesbordamiento durante la evaluación, los
!> componentes del vector resultante se perturban a partir de cero en (N+1)
!> veces el umbral de subdesbordamiento. Para evitar errores innecesariamente
!> grandes para la estructura de bloque incrustada en matrices generales,
!> los componentes cero no se perturban. Se considera un elemento cero
!> si todas las multiplicaciones involucradas
!> en el cálculo de ese elemento tienen al menos un multiplicando cero.
!>

Parámetros

TRANS 
!>          TRANS es INTEGER
!>           Al entrar, TRANS especifica la operación a realizar como
!>           sigue:
!>
!>             BLAS_NO_TRANS      y := alpha*abs(A)*abs(x) + beta*abs(y)
!>             BLAS_TRANS         y := alpha*abs(A**T)*abs(x) + beta*abs(y)
!>             BLAS_CONJ_TRANS    y := alpha*abs(A**T)*abs(x) + beta*abs(y)
!>
!>           Sin cambios a la salida.
!>

M

!>          M es INTEGER
!>           Al entrar, M especifica el número de filas de la matriz A.
!>           M debe ser al menos cero.
!>           Sin cambios a la salida.
!>

N

!>          N es INTEGER
!>           Al entrar, N especifica el número de columnas de la matriz A.
!>           N debe ser al menos cero.
!>           Sin cambios a la salida.
!>

ALPHA

!>          ALPHA es DOUBLE PRECISION
!>           Al entrar, ALPHA especifica el escalar alpha.
!>           Sin cambios a la salida.
!>

A

!>          A es un array COMPLEX*16, dimensión ( LDA, n )
!>           Antes de la entrada, la parte principal de m por n del array A debe
!>           contener la matriz de coeficientes.
!>           Sin cambios a la salida.
!>

LDA

!>          LDA es INTEGER
!>           Al entrar, LDA especifica la primera dimensión de A tal como se declara
!>           en el programa (sub)llamador. LDA debe ser al menos
!>           max( 1, m ).
!>           Sin cambios a la salida.
!>

X

!>          X es un array COMPLEX*16, dimensión al menos
!>           ( 1 + ( n - 1 )*abs( INCX ) ) cuando TRANS = 'N' o 'n'
!>           y al menos
!>           ( 1 + ( m - 1 )*abs( INCX ) ) en caso contrario.
!>           Antes de la entrada, el array X incrementado debe contener el
!>           vector x.
!>           Sin cambios a la salida.
!>

INCX

!>          INCX es INTEGER
!>           Al entrar, INCX especifica el incremento para los elementos de
!>           X. INCX no debe ser cero.
!>           Sin cambios a la salida.
!>

BETA

!>          BETA es DOUBLE PRECISION
!>           Al entrar, BETA especifica el escalar beta. Cuando BETA se
!>           proporciona como cero, entonces Y no necesita ser establecido a la entrada.
!>           Sin cambios a la salida.
!>

Y

!>          Y es un array DOUBLE PRECISION, dimensión
!>           ( 1 + ( m - 1 )*abs( INCY ) ) cuando TRANS = 'N' o 'n'
!>           y al menos
!>           ( 1 + ( n - 1 )*abs( INCY ) ) en caso contrario.
!>           Antes de la entrada con BETA distinto de cero, el array Y
!>           incrementado debe contener el vector y. A la salida, Y se sobrescribe con el
!>           vector y actualizado.
!>           Si m o n es cero, entonces Y no se hace referencia y la función
!>           realiza un retorno rápido.
!>

INCY

!>          INCY es INTEGER
!>           Al entrar, INCY especifica el incremento para los elementos de
!>           Y. INCY no debe ser cero.
!>           Sin cambios a la salida.
!>
!>  Rutina Blas de Nivel 2.
!>
