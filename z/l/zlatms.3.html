ZLATMS

Propósito:

!>
!>    ZLATMS genera matrices aleatorias con valores singulares especificados
!>    (o hermíticas con valores propios especificados)
!>    para probar programas LAPACK.
!>
!>    ZLATMS opera aplicando la siguiente secuencia de
!>    operaciones:
!>
!>      Establecer la diagonal en D, donde D puede ser de entrada o
!>         calculada de acuerdo con MODE, COND, DMAX y SYM
!>         como se describe a continuación.
!>
!>      Generar una matriz con la estructura de banda apropiada, mediante uno
!>         de dos métodos:
!>
!>      Método A:
!>          Generar una matriz densa M x N multiplicando D a la izquierda
!>              y a la derecha por matrices unitarias aleatorias, y luego:
!>
!>          Reducir el ancho de banda de acuerdo con KL y KU, usando
!>              transformaciones de Householder.
!>
!>      Método B:
!>          Convertir la matriz de ancho de banda 0 (es decir, diagonal) a una
!>              matriz de ancho de banda 1 usando rotaciones de Givens, 
!>              elementos fuera de banda hacia atrás, de forma similar a QR; luego convertir
!>              el ancho de banda 1 a una matriz de ancho de banda 2, etc.  Observe
!>              que para anchos de banda razonablemente pequeños (en relación con M y
!>              N) esto requiere menos almacenamiento, ya que no se genera una matriz densa.
!>              Además, para matrices hermíticas o simétricas,
!>              solo se genera un triángulo.
!>
!>      El método A se elige si el ancho de banda es una gran fracción del
!>          orden de la matriz, y LDA es al menos M (para que se pueda almacenar
!>          una matriz densa). El método B se elige si el ancho de banda
!>          es pequeño (< 1/2 N para hermítica o simétrica, < .3 N+M para
!>          no simétrica), o LDA es menor que M y no menor que el
!>          ancho de banda.
!>
!>      Empaquetar la matriz si se desea. Las opciones especificadas por PACK son:
!>         sin empaquetar
!>         poner a cero la mitad superior (si es hermítica)
!>         poner a cero la mitad inferior (si es hermítica)
!>         almacenar la mitad superior por columnas (si es hermítica o triangular superior)
!>         almacenar la mitad inferior por columnas (si es hermítica o triangular inferior)
!>         almacenar el triángulo inferior en formato de banda (si es hermítica o
!>               triangular inferior)
!>         almacenar el triángulo superior en formato de banda (si es hermítica o
!>               triangular superior)
!>         almacenar toda la matriz en formato de banda
!>      Si se elige el Método B, y se especifica el formato de banda, entonces la
!>         matriz se generará en formato de banda, por lo que no será necesario
!>         reempaquetar.
!>

Parámetros

M 
!>          M es ENTERO
!>           El número de filas de A. No se modifica.
!>

N

!>          N es ENTERO
!>           El número de columnas de A. N debe ser igual a M si la matriz
!>           es simétrica o hermítica (es decir, si SYM es 'N')
!>           No se modifica.
!>

DIST

!>          DIST es CARACTER*1
!>           A la entrada, DIST especifica el tipo de distribución a utilizar
!>           para generar los valores propios/singulares aleatorios.
!>           'U' => UNIFORME( 0, 1 )  ( 'U' para uniforme )
!>           'S' => UNIFORME( -1, 1 ) ( 'S' para simétrica )
!>           'N' => NORMAL( 0, 1 )   ( 'N' para normal )
!>           No se modifica.
!>

ISEED

!>          ISEED es un array de ENTEROS, de dimensión ( 4 )
!>           A la entrada, ISEED especifica la semilla del generador
!>           de números aleatorios. Deben estar entre 0 y 4095 inclusive,
!>           y ISEED(4) debe ser impar. El generador de números aleatorios
!>           utiliza una secuencia congruencial lineal limitada a enteros pequeños,
!>           y por lo tanto debería producir números aleatorios independientes de la máquina.
!>           Los valores de ISEED se modifican a la salida, y pueden usarse en
!>           la siguiente llamada a ZLATMS para continuar la misma secuencia
!>           de números aleatorios.
!>           Modificado a la salida.
!>

SYM

!>          SYM es CARACTER*1
!>           Si SYM='H', la matriz generada es hermítica, con
!>             valores propios especificados por D, COND, MODE y DMAX;
!>             pueden ser positivos, negativos o cero.
!>           Si SYM='P', la matriz generada es hermítica, con
!>             valores propios (= valores singulares) especificados por D, COND,
!>             MODE y DMAX; no serán negativos.
!>           Si SYM='N', la matriz generada es no simétrica, con
!>             valores singulares especificados por D, COND, MODE y DMAX;
!>             no serán negativos.
!>           Si SYM='S', la matriz generada es simétrica (compleja),
!>             con valores singulares especificados por D, COND, MODE y
!>             DMAX; no serán negativos.
!>           No se modifica.
!>

D

!>          D es un array de DOBLE PRECISIÓN, de dimensión ( MIN( M, N ) )
!>           Este array se utiliza para especificar los valores singulares o
!>           los valores propios de A (ver SYM, arriba). Si MODE=0, entonces D
!>           contiene los valores propios/singulares, de lo contrario
!>           se calcularán de acuerdo con MODE, COND y DMAX,
!>           y se colocarán en D.
!>           Modificado si MODE es distinto de cero.
!>

MODE

!>          MODE es ENTERO
!>           A la entrada, esto describe cómo se especificarán los valores propios/singulares:
!>           MODE = 0 significa usar D como entrada
!>           MODE = 1 establece D(1)=1 y D(2:N)=1.0/COND
!>           MODE = 2 establece D(1:N-1)=1 y D(N)=1.0/COND
!>           MODE = 3 establece D(I)=COND**(-(I-1)/(N-1))
!>           MODE = 4 establece D(i)=1 - (i-1)/(N-1)*(1 - 1/COND)
!>           MODE = 5 establece D a números aleatorios en el rango
!>                    ( 1/COND , 1 ) tales que sus logaritmos
!>                    estén distribuidos uniformemente.
!>           MODE = 6 establece D a números aleatorios de la misma distribución
!>                    que el resto de la matriz.
!>           MODE < 0 tiene el mismo significado que ABS(MODE), excepto que
!>              el orden de los elementos de D se invierte.
!>           Por lo tanto, si MODE es positivo, D tiene entradas que van desde
!>              1 hasta 1/COND, si es negativo, desde 1/COND hasta 1,
!>           Si SYM='H', y MODE no es ni 0, 6 ni -6, entonces
!>              los elementos de D también se multiplicarán por un signo aleatorio (es decir, +1 o -1).
!>           No se modifica.
!>

COND

!>          COND es DOBLE PRECISIÓN
!>           A la entrada, se utiliza como se describe en MODE arriba.
!>           Si se usa, debe ser >= 1. No se modifica.
!>

DMAX

!>          DMAX es DOBLE PRECISIÓN
!>           Si MODE no es ni -6, 0 ni 6, el contenido de D, tal como se
!>           calcula de acuerdo con MODE y COND, se escalará por
!>           DMAX / max(abs(D(i))); por lo tanto, el valor propio o
!>           singular máximo absoluto (que es la norma) será abs(DMAX).
!>           Tenga en cuenta que DMAX no tiene por qué ser positivo: si DMAX es negativo
!>           (o cero), D se escalará por un número negativo (o cero).
!>           No se modifica.
!>

KL

!>          KL es ENTERO
!>           Esto especifica el ancho de banda inferior de la matriz. Por
!>           ejemplo, KL=0 implica triangular superior, KL=1 implica
!>           Hessenberg superior, y KL siendo al menos M-1 significa que la matriz

NAME


zlatms


generates test matrices






SYNOPSIS


 CALL ZLATMS( M, N, DIST, DIAG, SIDE, SPARSE, TYPE, SUBTYP, PACK,
              DL, DR, SE, PIV, SUB, DLAMCH, WORK, LWORK, INFO )







Function/Subroutine Documentation


This subroutine generates test matrices.


Arguments




M


 M is INTEGER
  The number of rows of the matrix A.




N


 N is INTEGER
  The number of columns of the matrix A.




DIST


 DIST is CHARACTER*1
  Specifies the distribution of the elements of A.


  'U' => uniform distribution
  'N' => normal distribution
  'D' => diagonal matrix with random
         diagonal entries
  'R' => random orthogonal matrix
  'S' => random sparse matrix
  'H' => random Hessenberg matrix
  'P' => random triangular matrix
  'T' => random triangular matrix
  'B' => random bidiagonal matrix
  'L' => random lower triangular matrix
  'U' => random upper triangular matrix
  'Q' => random upper quasi-triangular matrix
  'K' => random lower quasi-triangular matrix
  'E' => identity matrix
  'I' => identity matrix
  'O' => zero matrix



  Not modified.



DIAG


 DIAG is CHARACTER*1
  Specifies the properties of the diagonal entries.


  'N' => no special diagonal entries
  'A' => random diagonal entries
  'S' => scalar diagonal entries
  'U' => diagonal entries are unit (1)
  'Z' => diagonal entries are zero (0)
  'R' => diagonal entries are random orthogonal



  Not modified.



SIDE


 SIDE is CHARACTER*1
  Specifies whether to form A or A**H.
  'L' => form A
  'R' => form A**H
  Not modified.



SPARSE


 SPARSE is CHARACTER*1
  Specifies whether to return a sparse or dense matrix.
  'S' => sparse matrix
  'D' => dense matrix
  Not modified.



TYPE


 TYPE is CHARACTER*1
  Specifies the type of matrix to be generated.


  'G' => general rectangular matrix
  'U' => upper triangular matrix
  'L' => lower triangular matrix
  'S' => symmetric matrix
  'H' => Hermitian matrix
  'B' => bidiagonal matrix
  'T' => tridiagonal matrix
  'C' => triangular matrix with subdiagonal entries zero
  'Q' => upper quasi-triangular matrix
  'K' => lower quasi-triangular matrix
  'E' => upper triangular matrix with subdiagonal entries zero
  'I' => lower triangular matrix with superdiagonal entries zero



  Not modified.



SUBTYP


 SUBTYP is CHARACTER*1
  Specifies the type of subdiagonal or superdiagonal entries.


  'N' => no special subdiagonal or superdiagonal entries
  'R' => random subdiagonal or superdiagonal entries
  'S' => scalar subdiagonal or superdiagonal entries
  'Z' => zero subdiagonal or superdiagonal entries
  'U' => unit subdiagonal or superdiagonal entries



  Not modified.



PACK


 PACK is CHARACTER*1
  This specifies packing of matrix as follows:
  'N' => no packing
  'U' => zero out all subdiagonal entries (if symmetric
         or hermitian)
  'L' => zero out all superdiagonal entries (if symmetric
         or hermitian)
  'C' => store the upper triangle columnwise (only if the
         matrix is symmetric, hermitian, or upper triangular)
  'R' => store the lower triangle columnwise (only if the
         matrix is symmetric, hermitian, or lower triangular)
  'B' => store the lower triangle in band storage scheme
         (only if the matrix is symmetric, hermitian, or
         lower triangular)
  'Q' => store the upper triangle in band storage scheme
         (only if the matrix is symmetric, hermitian, or
         upper triangular)
  'Z' => store the entire matrix in band storage scheme
         (pivoting can be provided for by using this
         option to store A in the trailing rows of
         the allocated storage)

  Using these options, the various LAPACK packed and banded
  storage schemes can be obtained:
  GB                    - use 'Z'
  PB, SB, HB, or TB     - use 'B' or 'Q'
  PP, SP, HB, or TP     - use 'C' or 'R'

  If two calls to ZLATMS differ only in the PACK parameter,
  they will generate mathematically equivalent matrices.
  Not modified.



DL


 DL is REAL*8 array, dimension ( N )
  The diagonal elements of the matrix A.




DR


 DR is REAL*8 array, dimension ( N )
  The diagonal elements of the matrix A.




SE


 SE is REAL*8 array, dimension ( N )
  The subdiagonal elements of the matrix A.




PIV


 PIV is REAL*8 array, dimension ( N )
  The subdiagonal elements of the matrix A.




SUB
 SUB is REAL*8 array, dimension ( max(1, N-1) )
  The subdiagonal elements of the matrix A.
DLAMCH
 DLAMCH is REAL*8 function
  The data type of DLAMCH is DOUBLE PRECISION.
  DLAMCH is used to query machine parameters.
  Not modified.
WORK
 WORK is COMPLEX*16 array, dimension ( LWORK )
  Workspace array.
  Modified.
LWORK
 LWORK is INTEGER
  The dimension of the array WORK. LWORK must be large enough to
  allow the matrix to be generated.
  Not modified.
INFO
 INFO is INTEGER
  Error code. On exit, INFO will be set to one of the following values:
    0 => normal return
  < 0 => error in the input parameters
