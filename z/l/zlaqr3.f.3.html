subrutina zlaqr3 (logical wantt, logical wantz, integer n, integer ktop, integer kbot, integer nw, complex*16, dimension( ldh, * ) h, integer ldh, integer iloz, integer ihiz, complex*16, dimension( ldz, * ) z, integer ldz, integer ns, integer nd, complex*16, dimension( * ) sh, complex*16, dimension( ldv, * ) v, integer ldv, integer nh, complex*16, dimension( ldt, * ) t, integer ldt, integer nv, complex*16, dimension( ldwv, * ) wv, integer ldwv, complex*16, dimension( * ) work, integer lwork)

ZLAQR3 realiza la transformación de semejanza unitaria de una matriz de Hessenberg para detectar y reducir los valores propios completamente convergidos de una submatriz principal final (deflación temprana agresiva).

Propósito:

!>
!>    Deflación temprana agresiva:
!>
!>    ZLAQR3 acepta como entrada una matriz de Hessenberg superior
!>    H y realiza una transformación de semejanza unitaria
!>    diseñada para detectar y reducir los valores propios completamente
!>    convergidos de una submatriz principal final.  En la salida H ha sido
!>    sobrescrita por una nueva matriz de Hessenberg que es una perturbación de
!>    una transformación de semejanza unitaria de H.  Se espera que
!>    la versión final de H tenga muchas entradas subdiagonales cero.
!>
!>

Parámetros

WANTT 
!>          WANTT es LOGICAL
!>          Si .TRUE., entonces la matriz de Hessenberg H se actualiza
!>          completamente de modo que el factor triangular de Schur pueda
!>          ser calculado (en cooperación con la subrutina llamante).
!>          Si .FALSE., entonces solo se actualiza lo suficiente de H para
!>          preservar los valores propios.
!>

WANTZ

!>          WANTZ es LOGICAL
!>          Si .TRUE., entonces la matriz unitaria Z se actualiza
!>          para que el factor de Schur unitario pueda ser calculado
!>          (en cooperación con la subrutina llamante).
!>          Si .FALSE., entonces Z no se referencia.
!>

N

!>          N es INTEGER
!>          El orden de la matriz H y (si WANTZ es .TRUE.) el
!>          orden de la matriz unitaria Z.
!>

KTOP

!>          KTOP es INTEGER
!>          Se asume que KTOP = 1 o H(KTOP,KTOP-1)=0.
!>          KBOT y KTOP juntos determinan un bloque aislado
!>          a lo largo de la diagonal de la matriz de Hessenberg.
!>

KBOT

!>          KBOT es INTEGER
!>          Se asume sin verificación que KBOT = N o H(KBOT+1,KBOT)=0.
!>          KBOT y KTOP juntos determinan un bloque aislado a lo largo de la
!>          diagonal de la matriz de Hessenberg.
!>

NW

!>          NW es INTEGER
!>          Tamaño de la ventana de deflación.  1 <= NW <= (KBOT-KTOP+1).
!>

H

!>          H es un array COMPLEX*16, dimension (LDH,N)
!>          En la entrada, la sección N por N inicial de H almacena la
!>          matriz de Hessenberg que se somete a deflación temprana agresiva.
!>          En la salida, H ha sido transformada por una semejanza
!>          unitaria, perturbada, y devuelta
!>          a la forma de Hessenberg que (se espera) tiene algunas
!>          entradas subdiagonales cero.
!>

LDH

!>          LDH es INTEGER
!>          Dimensión principal de H tal como se declara en la subrutina
!>          llamante.  N <= LDH
!>

ILOZ

!>          ILOZ es INTEGER
!>

IHIZ

!>          IHIZ es INTEGER
!>          Especifican las filas de Z a las que se deben aplicar
!>          transformaciones si WANTZ es .TRUE.. 1 <= ILOZ <= IHIZ <= N.
!>

Z

!>          Z es un array COMPLEX*16, dimension (LDZ,N)
!>          SI WANTZ es .TRUE., entonces en la salida, la semejanza
!>          unitaria mencionada anteriormente se ha
!>          acumulado en Z(ILOZ:IHIZ,ILOZ:IHIZ) desde la derecha.
!>          Si WANTZ es .FALSE., entonces Z no se referencia.
!>

LDZ

!>          LDZ es INTEGER
!>          La dimensión principal de Z tal como se declara en la
!>          subrutina llamante.  1 <= LDZ.
!>

NS

!>          NS es INTEGER
!>          El número de valores propios no convergidos (es decir, aproximados)
!>          devueltos en SR y SI que pueden ser utilizados como desplazamientos por
!>          la subrutina llamante.
!>

ND

!>          ND es INTEGER
!>          El número de valores propios convergidos descubiertos por esta
!>          subrutina.
!>

SH

!>          SH es un array COMPLEX*16, dimension (KBOT)
!>          En la salida, los valores propios aproximados que pueden
!>          ser utilizados para desplazamientos se almacenan en SH(KBOT-ND-NS+1)
!>          a través de SR(KBOT-ND).  Los valores propios convergidos se
!>          almacenan en SH(KBOT-ND+1) a través de SH(KBOT).
!>

V

!>          V es un array COMPLEX*16, dimension (LDV,NW)
!>          Un array de trabajo NW por NW.
!>

LDV

!>          LDV es INTEGER
!>          La dimensión principal de V tal como se declara en la
!>          subrutina llamante.  NW <= LDV
!>

NH

!>          NH es INTEGER
!>          El número de columnas de T.  NH >= NW.
!>

T

!>          T es un array COMPLEX*16, dimension (LDT,NW)
!>

LDT

!>          LDT es INTEGER
!>          La dimensión principal de T tal como se declara en la
!>          subrutina llamante.  NW <= LDT
!>

NV

!>          NV es INTEGER
!>          El número de filas del array de trabajo WV disponibles para
!>          espacio de trabajo.  NV >= NW.
!>

WV

!>          WV es un array COMPLEX*16, dimension (LDWV,NW)
!>

LDWV

!>          LDWV es INTEGER
!>          La dimensión principal de W tal como se declara en la
!>          subrutina llamante.  NW <= LDV
!>

WORK

!>          WORK es un array COMPLEX*16, dimension (LWORK)
!>          En la salida, WORK(1) se establece en una estimación del valor
!>          óptimo de LWORK para los valores dados de N, NW, KTOP y KBOT.
!>

LWORK

!>          LWORK es INTEGER
!>          La dimensión del array de trabajo WORK.  LWORK = 2*NW
!>          es suficiente, pero una mayor eficiencia puede resultar de
!>          valores mayores de LWORK.
!>
!>          Si LWORK = -1, entonces se asume una consulta de espacio de
!>          trabajo; ZLAQR3 solo estima el tamaño óptimo del espacio de
!>          trabajo para los valores dados de N, NW, KTOP y KBOT.
!>          La estimación se devuelve en WORK(1).  XERBLA no emite
!>          ningún mensaje de error relacionado con LWORK.
!>          Ni H ni Z se acceden.
!>

Function/Subroutine Documentation

This subroutine is part of the LAPACK routines that compute the eigenvalues and eigenvectors of a general matrix.

Purpose

zlaqr3 is part of the QR algorithm for computing the Schur decomposition of a general complex matrix.

This subroutine implements one step of the QR iteration for a general matrix.

It is used to compute the eigenvalues of a general matrix by reducing it to an upper triangular matrix.

The matrix is represented in the form Z * T * Z**H, where T is upper triangular and Z is unitary.

The subroutine is called recursively.

Parameters
W

Complex*16 array, dimension (*). On entry, W contains the eigenvalues of the matrix.

On exit, W contains the updated eigenvalues.

V

Complex*16 array, dimension (*). On entry, V contains the eigenvectors of the matrix.

On exit, V contains the updated eigenvectors.

TOL

Double Precision value.

Convergence criterion for eigenvalues.

N

Integer.

The order of the matrix.

ILO

Integer.

The starting index of the submatrix for which the eigenvalues are computed.

IHI

Integer.

The ending index of the submatrix for which the eigenvalues are computed.

NB

Integer.

The blocking factor for the QR iteration.

DWORK

Complex*16 array, dimension (*). Workspace array.

VWORK

Complex*16 array, dimension (*). Workspace array.

INFO

Integer.

Error flag.

0: successful exit

<0: if INFO = -i, then the i-th argument had an illegal value

This subroutine is called by zqrt03. The main purpose of zlaqr3 is to perform one step of the QR iteration on a sub-block of the matrix for which Schur decomposition is being computed.
