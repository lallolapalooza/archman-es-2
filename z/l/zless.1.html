NOMBRE

zless - filtro de perusal de archivos para visualización en pantalla de texto comprimido

SINOPSIS

zless [ nombre ... ]

DESCRIPCIÓN

El comando zless es un filtro que permite examinar archivos de texto sin comprimir o comprimidos pantalla por pantalla en una terminal de copia blanda. Es el equivalente a establecer la variable de entorno LESSOPEN a '|gzip -cdfq -- %s', y la variable de entorno LESSMETACHARS a '<espacio><tab><nueva línea>;*?"()<>[|&^`#\$%=~', y luego ejecutar less. Sin embargo, parece que a suficiente gente le parece importante tener el comando zless disponible como para justificar su provisión.

VER TAMBIÉN

zmore(1), less(1)

ERRORES

El comando zless no funciona con datos comprimidos que se le envían a través de la entrada estándar; requiere que los archivos de entrada se especifiquen como argumentos. Para leer datos comprimidos de una tubería, puede usar ...|gunzip|less en lugar de ...|zless.
