subroutine zla_gbrfsx_extended (integer prec_type, integer trans_type, integer n, integer kl, integer ku, integer nrhs, complex*16, dimension( ldab, * ) ab, integer ldab, complex*16, dimension( ldafb, * ) afb, integer ldafb, integer, dimension( * ) ipiv, logical colequ, double precision, dimension( * ) c, complex*16, dimension( ldb, * ) b, integer ldb, complex*16, dimension( ldy, * ) y, integer ldy, double precision, dimension( * ) berr_out, integer n_norms, double precision, dimension( nrhs, * ) err_bnds_norm, double precision, dimension( nrhs, * ) err_bnds_comp, complex*16, dimension( * ) res, double precision, dimension(*) ayb, complex*16, dimension( * ) dy, complex*16, dimension( * ) y_tail, double precision rcond, integer ithresh, double precision rthresh, double precision dz_ub, logical ignore_cwise, integer info)

ZLA_GBRFSX_EXTENDED mejora la solución calculada de un sistema de ecuaciones lineales para matrices generales de banda mediante un refinamiento iterativo de precisión extra, y proporciona límites de error y estimaciones de error hacia atrás para la solución.

Propósito:

!>
!> ZLA_GBRFSX_EXTENDED mejora la solución calculada de un sistema de
!> ecuaciones lineales mediante un refinamiento iterativo de precisión extra
!> y proporciona límites de error y estimaciones de error hacia atrás para la solución.
!> Esta subrutina es llamada por ZGBRFSX para realizar el refinamiento iterativo.
!> Además del límite de error normwise, el código proporciona el límite de error
!> máximo por componentes si es posible. Ver los comentarios para ERR_BNDS_NORM
!> y ERR_BNDS_COMP para detalles de los límites de error. Tenga en cuenta que esta
!> subrutina solo es responsable de establecer los segundos campos de
!> ERR_BNDS_NORM y ERR_BNDS_COMP.
!>

Parámetros

PREC_TYPE 
!>          PREC_TYPE es INTEGER
!>     Especifica la precisión intermedia a utilizar en el refinamiento.
!>     El valor se define por ILAPREC(P) donde P es un CHARACTER y P
!>          = 'S':  Simple
!>          = 'D':  Doble
!>          = 'I':  Indígena
!>          = 'X' o 'E':  Extra
!>

TRANS_TYPE

!>          TRANS_TYPE es INTEGER
!>     Especifica la operación de transposición sobre A.
!>     El valor se define por ILATRANS(T) donde T es un CHARACTER y T
!>          = 'N':  Sin transposición
!>          = 'T':  Transpuesta
!>          = 'C':  Transpuesta conjugada
!>

N

!>          N es INTEGER
!>     El número de ecuaciones lineales, es decir, el orden de la
!>     matriz A.  N >= 0.
!>

KL

!>          KL es INTEGER
!>     El número de subdiagonales dentro de la banda de A.  KL >= 0.
!>

KU

!>          KU es INTEGER
!>     El número de superdiagonales dentro de la banda de A.  KU >= 0
!>

NRHS

!>          NRHS es INTEGER
!>     El número de lados derechos, es decir, el número de columnas de la
!>     matriz B.
!>

AB

!>          AB es COMPLEX*16 array, dimension (LDAB,N)
!>     En la entrada, la matriz A de N por N.
!>

LDAB

!>          LDAB es INTEGER
!>     La dimensión principal del array A.  LDAB >= max(1,N).
!>

AFB

!>          AFB es COMPLEX*16 array, dimension (LDAF,N)
!>     Los factores L y U de la factorización
!>     A = P*L*U tal como lo calcula ZGBTRF.
!>

LDAFB

!>          LDAFB es INTEGER
!>     La dimensión principal del array AF.  LDAF >= max(1,N).
!>

IPIV

!>          IPIV es INTEGER array, dimension (N)
!>     Los índices de pivote de la factorización A = P*L*U
!>     tal como lo calcula ZGBTRF; la fila i de la matriz fue intercambiada
!>     con la fila IPIV(i).
!>

COLEQU

!>          COLEQU es LOGICAL
!>     Si es .TRUE. entonces se realizó la equilibrio de columna en A antes de llamar
!>     a esta rutina. Esto es necesario para calcular correctamente la solución y los límites de error.
!>

C

!>          C es DOUBLE PRECISION array, dimension (N)
!>     Los factores de escala de columna para A. Si COLEQU = .FALSE., C
!>     no se accede. Si se introduce C, cada elemento de C debe ser una potencia
!>     de la base para garantizar una solución y estimaciones de error fiables.
!>     La escala por potencias de la base no causa errores de redondeo a menos
!>     que el resultado sea subdesbordado o desbordado. Los errores de redondeo durante la escala
!>     conducen a un refinamiento con una matriz que no es equivalente a la
!>     matriz de entrada, produciendo estimaciones de error que pueden no ser
!>     fiables.
!>

B

!>          B es COMPLEX*16 array, dimension (LDB,NRHS)
!>     La matriz del lado derecho B.
!>

LDB

!>          LDB es INTEGER
!>     La dimensión principal del array B.  LDB >= max(1,N).
!>

Y

!>          Y es COMPLEX*16 array, dimension (LDY,NRHS)
!>     En la entrada, la matriz solución X, tal como la calcula ZGBTRS.
!>     En la salida, la matriz solución mejorada Y.
!>

LDY

!>          LDY es INTEGER
!>     La dimensión principal del array Y.  LDY >= max(1,N).
!>

BERR_OUT

!>          BERR_OUT es DOUBLE PRECISION array, dimension (NRHS)
!>     En la salida, BERR_OUT(j) contiene el error hacia atrás relativo por componentes
!>     para el lado derecho j de la fórmula
!>         max(i) ( abs(RES(i)) / ( abs(op(A_s))*abs(Y) + abs(B_s) )(i) )
!>     donde abs(Z) es el valor absoluto por componentes de la matriz
!>     o vector Z. Esto se calcula por ZLA_LIN_BERR.
!>

N_NORMS

!>          N_NORMS es INTEGER
!>     Determina qué límites de error devolver (ver ERR_BNDS_NORM
!>     y ERR_BNDS_COMP).
!>     Si N_NORMS >= 1 devuelve límites de error normwise.
!>     Si N_NORMS >= 2 devuelve límites de error por componentes.
!>

ERR_BNDS_NORM

!>          ERR_BNDS_NORM es DOUBLE PRECISION array, dimension (NRHS, N_ERR_BNDS)
!>     Para cada lado derecho, esta matriz contiene información sobre
!>     varios límites de error y números de condición correspondientes al
!>     error relativo normwise, que se define como sigue:
!>
!>     Error relativo normwise en el i-ésimo vector solución:
!>             max_j (abs(XTRUE(j,i) - X(j,i)))
!>            ------------------------------


NAME


zla_gbrfsx_extended - Launches the extended driver routines for GEBRFSX.







SYNOPSIS


   SUBROUTINE ZLA_GBRFSX_EXTENDED (
           UPLO, TRANS, EQUED, N, KBL, KBU,
           NRHS, AF, LDAF, IPIV, B, LDB, X, LDX,
           RCOND, SRCOND, PROFAC, PARAMS, WORK, IWORK,
           ERR_BNDS_NORM, ERR_BNDS_COMP, RES, AYB, DY, Y_TAIL,
           RTHRESH, DZ_UB, IGNORE_CWISE, INFO
   )



This routine is an interface to the extended driver routines for GEBRFSX.


It is called by the extended driver routines ZGEBRFSX, ZGBRFSX, ZPOBRFSX, ZSYRFSX, and ZTBRFSX.


The extended driver routines call this routine in order to compute the
    solution to a system of linear equations AX = B, where A is a general band
    matrix, and to estimate the error in the computed solution and the
    reciprocal condition number.


The extended driver routines are:
    ZGEBRFSX (general band matrix)
    ZGBRFSX (general band matrix)
    ZPOBRFSX (upper or lower triangular band matrix)
    ZSYRFSX (symmetric band matrix)
    ZTBRFSX (triangular band matrix)


See Lapack Working Note 165 for further details and extra cautions.







Function/Subroutine Documentation




 UPLO




 CHARACTER*1



Specifies whether the matrix A is upper or lower triangular banded.
    = 'U': Upper triangular banded.


= 'L': Lower triangular banded.




 TRANS




 CHARACTER*1



Specifies the form of the system of equations:


    = 'N': A * X = B      (No transpose)
    = 'T': A**T * X = B   (Transpose)
    = 'C': A**H * X = B   (Conjugate transpose)


where A**H is the conjugate transpose of A.




 EQUED




 CHARACTER*1



Specifies the form of equilibration computed, if any.


    = 'N': No equilibration computed.
    = 'S': Scales row and column sums of absolute values of A.
    = 'R': Row scaling computed.
    = 'C': Column scaling computed.




 N




 INTEGER



The order of the matrix A. N >= 0.




 KBL




 INTEGER



The number of subdiagonals of the matrix A. KBL >= 0.




 KBU




 INTEGER



The number of superdiagonals of the matrix A. KBU >= 0.




 NRHS




 INTEGER



The number of right hand sides, i.e., the number of columns of the matrices
    B, X, AF, and potentially of the arrays ERR_BNDS_NORM and ERR_BNDS_COMP.
    NRHS >= 0.




 AF




 COMPLEX*16 array, dimension (LDAF, N)



Details of the LU factorization of the band matrix A, and of the
    equilibrated band matrix A*diag(S) or A*diag(S,T) or diag(S)*A or
    diag(T)*A. See comments below for details of each argument.




 LDAF




 INTEGER



The leading dimension of the array AF. LDAF >= KBL + KBU + 1.




 IPIV




 INTEGER array, dimension (min(N, KBL+KBU+1))



Details of the LU factorization of A. IPIV[i] is the pivot row of the
    matrix that is in row i of the previous factorization computed by ZGBTRF.




 B




 COMPLEX*16 array, dimension (LDB, NRHS)



The right hand side matrix B.




 LDB




 INTEGER



The leading dimension of the array B. LDB >= max(N, 1).




 X




 COMPLEX*16 array, dimension (LDX, NRHS)



The computed solution matrix X.




 LDX




 INTEGER



The leading dimension of the array X. LDX >= max(N, 1).




 RCOND




 DOUBLE PRECISION



Reciprocal scaled condition number. This is an estimate of the reciprocal
    Skeel condition number of the matrix A after equilibration (if
    done). If this is less than the machine precision (in particular, if it is
    zero), the matrix is singular to working precision. Note that the error
    may still be small even if this number is very small and the matrix
    appears ill-conditioned.




 SRCOND




 DOUBLE PRECISION



Reciprocal scaled condition number computed using the Skeel condition estimator.




 PROFAC




 DOUBLE PRECISION array, dimension (N)



The scaling factors used for row equilibration.




 PARAMS




 DOUBLE PRECISION array, dimension (8)



Algorithm parameters. See comments below for details.


    PARAMS(1) = threshold for residual computations.
    PARAMS(2) = threshold for iterative refinement.
    PARAMS(3) = threshold for componentwise error estimation.
    PARAMS(4) = threshold for reciprocal condition number.
    PARAMS(5) = threshold for determining if the matrix is to be
                considered singular.
    PARAMS(6) = threshold for normwise error estimation.
    PARAMS(7) = threshold for determining whether to use iterative
                refinement.
    PARAMS(8) = threshold for determining whether to use componentwise
                error estimation.





 WORK




 COMPLEX*16 array, dimension (N)



Workspace to hold the intermediate residual.




 IWORK




 INTEGER array, dimension (N)



Workspace.




 ERR_BNDS_NORM




 DOUBLE PRECISION array, dimension (NRHS, N_ERR_BNDS)



ERR_BNDS_NORM is DOUBLE PRECISION array, dimension (NRHS, N_ERR_BNDS)


For each right-hand side, this array contains information about
    various error bounds and condition numbers corresponding to the
    normwise relative error, which is defined as follows:


    Normwise relative error in the ith solution vector:
                       abs(XTRUE(j,i) - X(j,i))
                max_j ----------------------
                            abs(X(j,i))



The array is indexed by the type of error information as described
    below. There currently are up to three pieces of information
    returned.
    The first index in ERR_BNDS_NORM(i,:) corresponds to the ith
    right-hand side.
    The second index in ERR_BNDS_NORM(:,err) contains the following
    three fields:
    err = 1  boolean. Trust the answer if the
             reciprocal condition number is less than the threshold
             sqrt(n) * slamch('Epsilon').
    err = 2  error bound: The estimated forward error,
             almost certainly within a factor of 10 of the true error
             so long as the next entry is greater than the threshold
             sqrt(n) * slamch('Epsilon'). This error bound should only
             be trusted if the previous boolean is true.
    err = 3  Reciprocal condition number: Estimated normwise
             reciprocal condition number. Compared with the threshold
             sqrt(n) * slamch('Epsilon') to determine if the error
             estimate is . These reciprocal condition
             numbers are 1 / (norm(Z^{-1},inf) * norm(Z,inf)) for some
             appropriately scaled matrix Z.
             Let Z = S*A, where S scales each row by a power of the
             radix so all absolute row sums of Z are approximately 1.


This subroutine is only responsible for setting the second field
    above.
    See Lapack Working Note 165 for further details and extra
    cautions.




 ERR_BNDS_COMP




 DOUBLE PRECISION array, dimension (NRHS, N_ERR_BNDS)



ERR_BNDS_COMP is DOUBLE PRECISION array, dimension (NRHS, N_ERR_BNDS)


For each right-hand side, this array contains information about
    various error bounds and condition numbers corresponding to the
    componentwise relative error, which is defined as follows:


    Componentwise relative error in the ith solution vector:
                   abs(XTRUE(j,i) - X(j,i))
            max_j ----------------------
                        abs(X(j,i))



The array is indexed by the right-hand side i (on which the
    componentwise relative error depends), and the type of error
    information as described below. There currently are up to three
    pieces of information returned for each right-hand side. If
    componentwise accuracy is not requested (PARAMS(3) = 0.0), then
    ERR_BNDS_COMP is not accessed. If N_ERR_BNDS < 3, then at most
    the first (:,N_ERR_BNDS) entries are returned.


The first index in ERR_BNDS_COMP(i,:) corresponds to the ith
    right-hand side.


The second index in ERR_BNDS_COMP(:,err) contains the following
    three fields:
    err = 1  boolean. Trust the answer if the
             reciprocal condition number is less than the threshold
             sqrt(n) * slamch('Epsilon').
    err = 2  error bound: The estimated forward error,
             almost certainly within a factor of 10 of the true error
             so long as the next entry is greater than the threshold
             sqrt(n) * slamch('Epsilon'). This error bound should only
             be trusted if the previous boolean is true.
    err = 3  Reciprocal condition number: Estimated componentwise
             reciprocal condition number. Compared with the threshold
             sqrt(n) * slamch('Epsilon') to determine if the error
             estimate is . These reciprocal condition
             numbers are 1 / (norm(Z^{-1},inf) * norm(Z,inf)) for some
             appropriately scaled matrix Z.
             Let Z = S*(A*diag(x)), where x is the solution for the
             current right-hand side and S scales each row of
             A*diag(x) by a power of the radix so all absolute row
             sums of Z are approximately 1.


This subroutine is only responsible for setting the second field
    above.
    See Lapack Working Note 165 for further details and extra
    cautions.




 RES




 COMPLEX*16 array, dimension (N)



Workspace to hold the intermediate residual.




 AYB




 DOUBLE PRECISION array, dimension (N)



Workspace.




 DY




 COMPLEX*16 array, dimension (N)



Workspace to hold the intermediate solution.




 Y_TAIL




 COMPLEX*16 array, dimension (N)



Workspace to hold the trailing bits of the intermediate solution.




 RCOND




 DOUBLE PRECISION



Reciprocal scaled condition number. This is an estimate of the
    reciprocal Skeel condition number of the matrix A after
    equilibration (if done). If this is less than the machine
    precision (in particular, if it is zero), the matrix is singular
    to working precision. Note that the error may still be small even
    if this number is very small and the matrix appears ill-
    conditioned.




 ITHRESH




 INTEGER



The maximum number of residual computations allowed for
    refinement. The default is 10. For 'aggressive' set to 100 to
    permit convergence using approximate factorizations or
    factorizations other than LU. If the factorization uses a
    technique other than Gaussian elimination, the guarantees in
    ERR_BNDS_NORM and ERR_BNDS_COMP may no longer be trustworthy.




 RTHRESH




 DOUBLE PRECISION



Determines when to stop refinement if the error estimate stops
    decreasing. Refinement will stop when the next solution no longer
    satisfies norm(dx_{i+1}) < RTHRESH * norm(dx_i) where norm(Z) is
    the infinity norm of Z. RTHRESH satisfies 0 < RTHRESH <= 1. The
    default value is 0.5. For 'aggressive' set to 0.9 to permit
    convergence on extremely ill-conditioned matrices. See LAWN 165
    for more details.




 DZ_UB




 DOUBLE PRECISION



Determines when to start considering componentwise convergence.
    Componentwise convergence is only considered after each component
    of the solution Y is stable, which we define as the relative
    change in each component being less than DZ_UB. The default value
    is 0.25, requiring the first bit to be stable. See LAWN 165 for
    more details.




 IGNORE_CWISE




 LOGICAL



If .TRUE. then ignore componentwise convergence. Default value
    is .FALSE..




 INFO




 INTEGER



= 0: Successful exit.
    < 0: if INFO = -i, the ith argument to ZGBTRS had an illegal
    value
