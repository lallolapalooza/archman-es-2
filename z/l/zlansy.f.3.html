Documentación de Función/Subrutina

doble precisión función zlansy (carácter norma, carácter uplo, entero n, complejo*16, dimensión( lda, * ) a, entero lda, doble precisión, dimensión( * ) trabajo)

ZLANSY devuelve el valor de la norma 1, o la norma de Frobenius, o la norma infinito, o el elemento de mayor valor absoluto de una matriz simétrica compleja.

Propósito:

!>
!> ZLANSY devuelve el valor de la norma uno, o la norma de Frobenius, o
!> la norma infinito, o el elemento de mayor valor absoluto de
!> una matriz simétrica A.
!>

Devuelve

ZLANSY 
!>
!>    ZLANSY = ( max(abs(A(i,j))), NORMA = 'M' or 'm'
!>             (
!>             ( norm1(A),         NORMA = '1', 'O' or 'o'
!>             (
!>             ( normI(A),         NORMA = 'I' or 'i'
!>             (
!>             ( normF(A),         NORMA = 'F', 'f', 'E' or 'e'
!>
!> donde norm1 denota la norma uno de una matriz (suma máxima de columnas),
!> normI denota la norma infinito de una matriz (suma máxima de filas) y
!> normF denota la norma de Frobenius de una matriz (raíz cuadrada de la suma de
!> cuadrados). Tenga en cuenta que max(abs(A(i,j))) no es una norma matricial
!> consistente.
!>

Parámetros

NORMA 
!>          NORMA es CHARACTER*1
!>          Especifica el valor que se devolverá en ZLANSY como se describe
!>          arriba.
!>

UPLO

!>          UPLO es CHARACTER*1
!>          Especifica si la parte triangular superior o inferior de la
!>          matriz simétrica A se va a referenciar.
!>          = 'U': se referencia la parte triangular superior de A
!>          = 'L': se referencia la parte triangular inferior de A
!>

N

!>          N es ENTERO
!>          El orden de la matriz A. N >= 0. Cuando N = 0, ZLANSY se
!>          establece a cero.
!>

A

!>          A es una matriz COMPLEX*16, dimensión (LDA,N)
!>          La matriz simétrica A. Si UPLO = 'U', la parte triangular
!>          superior principal de n por n de A contiene la parte triangular
!>          superior de la matriz A, y la parte triangular estrictamente
!>          inferior de A no se referencia. Si UPLO = 'L', la parte
!>          triangular inferior principal de n por n de A contiene la parte
!>          triangular inferior de la matriz A, y la parte triangular
!>          estrictamente superior de A no se referencia.
!>

LDA

!>          LDA es ENTERO
!>          La dimensión principal de la matriz A. LDA >= max(N,1).
!>

TRABAJO

!>          TRABAJO es una matriz DOUBLE PRECISION, dimensión (MAX(1,LWORK)),
!>          donde LWORK >= N cuando NORMA = 'I' o '1' o 'O'; de lo contrario,
!>          TRABAJO no se referencia.
!>
