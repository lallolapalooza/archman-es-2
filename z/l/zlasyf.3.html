subrutina zlasyf (uplo, n, nb, kb, a, lda, ipiv, w, ldw, info)
ZLASYF calcula una factorización parcial de una matriz simétrica compleja utilizando el método de pivoteo diagonal de Bunch-Kaufman.

Documentación de la función/subrutina

subrutina zlasyf (character uplo, integer n, integer nb, integer kb, complex*16, dimension( lda, * ) a, integer lda, integer, dimension( * ) ipiv, complex*16, dimension( ldw, * ) w, integer ldw, integer info)

ZLASYF calcula una factorización parcial de una matriz simétrica compleja utilizando el método de pivoteo diagonal de Bunch-Kaufman.

Propósito:

!>
!> ZLASYF calcula una factorización parcial de una matriz simétrica compleja
!> A utilizando el método de pivoteo diagonal de Bunch-Kaufman. La factorización
!> parcial tiene la forma:
!>
!> A  =  ( I  U12 ) ( A11  0  ) (  I       0    )  si UPLO = 'U', o:
!>       ( 0  U22 ) (  0   D  ) ( U12**T U22**T )
!>
!> A  =  ( L11  0 ) ( D    0  ) ( L11**T L21**T )  si UPLO = 'L'
!>       ( L21  I ) ( 0   A22 ) (  0       I    )
!>
!> donde el orden de D es como máximo NB. El orden real se devuelve en
!> el argumento KB, y es NB o NB-1, o N si N <= NB.
!> Tenga en cuenta que U**T denota la transpuesta de U.
!>
!> ZLASYF es una subrutina auxiliar llamada por ZSYTRF. Utiliza código bloqueado
!> (llamando a BLAS de Nivel 3) para actualizar la submatriz A11 (si UPLO = 'U') o
!> A22 (si UPLO = 'L').
!>

Parámetros

UPLO 
!>          UPLO es CHARACTER*1
!>          Especifica si la parte triangular superior o inferior de la
!>          matriz simétrica A está almacenada:
!>          = 'U':  Triangular superior
!>          = 'L':  Triangular inferior
!>

N

!>          N es INTEGER
!>          El orden de la matriz A.  N >= 0.
!>

NB

!>          NB es INTEGER
!>          El número máximo de columnas de la matriz A que deben ser
!>          factorizadas.  NB debe ser al menos 2 para permitir bloques
!>          pivotales de 2x2.
!>

KB

!>          KB es INTEGER
!>          El número de columnas de A que fueron realmente factorizadas.
!>          KB es NB-1 o NB, o N si N <= NB.
!>

A

!>          A es una matriz COMPLEX*16, dimensión (LDA,N)
!>          En la entrada, la matriz simétrica A.  Si UPLO = 'U', la parte
!>          superior triangular líder n x n de A contiene la parte
!>          triangular superior de la matriz A, y la parte triangular
!>          estrictamente inferior de A no se referencia.  Si UPLO = 'L',
!>          la parte inferior triangular líder n x n de A contiene la parte
!>          triangular inferior de la matriz A, y la parte triangular
!>          estrictamente superior de A no se referencia.
!>          En la salida, A contiene detalles de la factorización parcial.
!>

LDA

!>          LDA es INTEGER
!>          La dimensión líder de la matriz A.  LDA >= max(1,N).
!>

IPIV

!>          IPIV es una matriz INTEGER, dimensión (N)
!>          Detalles de los intercambios y la estructura de bloque de D.
!>
!>          Si UPLO = 'U':
!>             Solo los últimos KB elementos de IPIV se establecen.
!>
!>             Si IPIV(k) > 0, entonces las filas y columnas k e IPIV(k) fueron
!>             intercambiadas y D(k,k) es un bloque diagonal de 1x1.
!>
!>             Si IPIV(k) = IPIV(k-1) < 0, entonces las filas y columnas
!>             k-1 e IPIV(k) fueron intercambiadas y D(k-1:k,k-1:k)
!>             es un bloque diagonal de 2x2.
!>
!>          Si UPLO = 'L':
!>             Solo los primeros KB elementos de IPIV se establecen.
!>
!>             Si IPIV(k) > 0, entonces las filas y columnas k e IPIV(k) fueron
!>             intercambiadas y D(k,k) es un bloque diagonal de 1x1.
!>
!>             Si IPIV(k) = IPIV(k+1) < 0, entonces las filas y columnas
!>             k+1 e IPIV(k) fueron intercambiadas y D(k:k+1,k:k+1)
!>             es un bloque diagonal de 2x2.
!>

W

!>          W es una matriz COMPLEX*16, dimensión (LDW,NB)
!>

LDW

!>          LDW es INTEGER
!>          La dimensión líder de la matriz W.  LDW >= max(1,N).
!>

INFO

!>          INFO es INTEGER
!>          = 0: ejecución exitosa
!>          > 0: si INFO = k, D(k,k) es exactamente cero. La factorización
!>               se ha completado, pero la matriz diagonal D es
!>               exactamente singular.
!>
