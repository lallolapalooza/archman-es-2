Documentación de Función/Subrutina

subrutina zlargv (integer n, complex*16, dimension( * ) x, integer incx, complex*16, dimension( * ) y, integer incy, double precision, dimension( * ) c, integer incc)

ZLARGV genera un vector de rotaciones de plano con cosenos reales y senos complejos.

Propósito:

!>
!> ZLARGV genera un vector de rotaciones de plano complejas con cosenos
!> reales, determinado por los elementos de los vectores complejos x e y.
!> Para i = 1,2,...,n
!>
!>    (        c(i)   s(i) ) ( x(i) ) = ( r(i) )
!>    ( -conjg(s(i))  c(i) ) ( y(i) ) = (   0  )
!>
!>    donde c(i)**2 + ABS(s(i))**2 = 1
!>
!>    Se utilizan las siguientes convenciones (estas son las mismas que en ZLARTG,
!>    pero difieren de la rutina ZROTG de BLAS1):
!>       Si y(i)=0, entonces c(i)=1 y s(i)=0.
!>       Si x(i)=0, entonces c(i)=0 y s(i) se elige de modo que r(i) sea real.
!>

Parámetros

N 
!>          N es ENTERO
!>          El número de rotaciones de plano a generar.
!>

X

!>          X es un array COMPLEX*16, de dimensión (1+(N-1)*INCX)
!>          En la entrada, el vector x.
!>          En la salida, x(i) se sobrescribe con r(i), para i = 1,...,n.
!>

INCX

!>          INCX es ENTERO
!>          El incremento entre elementos de X. INCX > 0.
!>

Y

!>          Y es un array COMPLEX*16, de dimensión (1+(N-1)*INCY)
!>          En la entrada, el vector y.
!>          En la salida, los senos de las rotaciones de plano.
!>

INCY

!>          INCY es ENTERO
!>          El incremento entre elementos de Y. INCY > 0.
!>

C

!>          C es un array DOUBLE PRECISION, de dimensión (1+(N-1)*INCC)
!>          Los cosenos de las rotaciones de plano.
!>

INCC

!>          INCC es ENTERO
!>          El incremento entre elementos de C. INCC > 0.
!>
