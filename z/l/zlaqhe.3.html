subroutine zlaqhe (character uplo, integer n, complex*16, dimension( lda, * ) a, integer lda, double precision, dimension( * ) s, double precision scond, double precision amax, character equed)

ZLAQHE escala una matriz Hermítica.

Propósito:

!>
!> ZLAQHE equilibra una matriz Hermítica A utilizando los factores de escala
!> en el vector S.
!>

Parámetros

UPLO 
!>          UPLO es CHARACTER*1
!>          Especifica si la parte triangular superior o inferior de la
!>          matriz Hermítica A está almacenada.
!>          = 'U':  Triangular superior
!>          = 'L':  Triangular inferior
!>

N

!>          N es INTEGER
!>          El orden de la matriz A.  N >= 0.
!>

A

!>          A es un array COMPLEX*16, de dimensión (LDA,N)
!>          En la entrada, la matriz Hermítica A.  Si UPLO = 'U', la parte
!>          triangular superior de n por n líder de A contiene la parte
!>          triangular superior de la matriz A, y la parte triangular
!>          estrictamente inferior de A no se referencia. Si UPLO = 'L', la
!>          parte triangular inferior de n por n líder de A contiene la parte
!>          triangular inferior de la matriz A, y la parte triangular
!>          estrictamente superior de A no se referencia.
!>
!>          En la salida, si EQUED = 'Y', la matriz equilibrada:
!>          diag(S) * A * diag(S).
!>

LDA

!>          LDA es INTEGER
!>          La dimensión líder del array A.  LDA >= max(N,1).
!>

S

!>          S es un array DOUBLE PRECISION, de dimensión (N)
!>          Los factores de escala para A.
!>

SCOND

!>          SCOND es DOUBLE PRECISION
!>          Razón del S(i) más pequeño al S(i) más grande.
!>

AMAX

!>          AMAX es DOUBLE PRECISION
!>          Valor absoluto de la entrada matricial más grande.
!>

EQUED

!>          EQUED es CHARACTER*1
!>          Especifica si se realizó o no el equilibrado.
!>          = 'N':  No se realizó equilibrado.
!>          = 'Y':  Se realizó equilibrado, es decir, A ha sido reemplazada por
!>                  diag(S) * A * diag(S).
!>

Parámetros Internos:

!>  THRESH es un valor umbral utilizado para decidir si se debe realizar el escalado
!>  basándose en la razón de los factores de escala. Si SCOND < THRESH,
!>  se realiza el escalado.
!>
!>  LARGE y SMALL son valores umbrales utilizados para decidir si se debe
!>  realizar el escalado basándose en el tamaño absoluto del elemento
!>  matricial más grande.
!>  Si AMAX > LARGE o AMAX < SMALL, se realiza el escalado.
!>
