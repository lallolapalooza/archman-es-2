ZLANTB devuelve el valor de la norma 1, o la norma de Frobenius, o la norma infinito, o el elemento de mayor valor absoluto de una matriz triangular banda.

Documentación de función/subrutina

doble precisión función zlantb (carácter norma, carácter uplo, carácter diag, entero n, entero k, complejo*16, dimensión( ldab, * ) ab, entero ldab, doble precisión, dimensión( * ) work)

ZLANTB devuelve el valor de la norma 1, o la norma de Frobenius, o la norma infinito, o el elemento de mayor valor absoluto de una matriz triangular banda.

Propósito:

!>
!> ZLANTB  devuelve el valor de la norma uno,  o la norma de Frobenius, o
!> la norma infinito,  o el elemento de  mayor valor absoluto de una
!> matriz banda triangular A, con ( k + 1 ) diagonales.
!>

Devuelve

ZLANTB 
!>
!>    ZLANTB = ( max(abs(A(i,j))), NORMA = 'M' o 'm'
!>             (
!>             ( norm1(A),         NORMA = '1', 'O' o 'o'
!>             (
!>             ( normI(A),         NORMA = 'I' o 'i'
!>             (
!>             ( normF(A),         NORMA = 'F', 'f', 'E' o 'e'
!>
!> donde  norm1  denota la  norma uno de una matriz (suma máxima de columna),
!> normI  denota la  norma infinito  de una matriz  (suma máxima de fila) y
!> normF  denota la  norma de Frobenius  de una matriz (raíz cuadrada de la suma de
!> cuadrados).  Tenga en cuenta que  max(abs(A(i,j)))  no es una norma matricial consistente.
!>

Parámetros

NORMA 
!>          NORMA es CHARACTER*1
!>          Especifica el valor a devolver en ZLANTB como se describe
!>          arriba.
!>

UPLO

!>          UPLO es CHARACTER*1
!>          Especifica si la matriz A es triangular superior o inferior.
!>          = 'U':  Triangular superior
!>          = 'L':  Triangular inferior
!>

DIAG

!>          DIAG es CHARACTER*1
!>          Especifica si la matriz A es unitaria triangular o no.
!>          = 'N':  No unitaria triangular
!>          = 'U':  Unitaria triangular
!>

N

!>          N es ENTERO
!>          El orden de la matriz A.  N >= 0.  Cuando N = 0, ZLANTB se
!>          establece a cero.
!>

K

!>          K es ENTERO
!>          El número de superdiagonales de la matriz A si UPLO = 'U',
!>          o el número de subdiagonales de la matriz A si UPLO = 'L'.
!>          K >= 0.
!>

AB

!>          AB es matriz COMPLEX*16, dimensión (LDAB,N)
!>          La matriz banda triangular superior o inferior A, almacenada en
!>          las primeras k+1 filas de AB.  La columna j de A se almacena
!>          en la columna j de la matriz AB de la siguiente manera:
!>          si UPLO = 'U', AB(k+1+i-j,j) = A(i,j) para max(1,j-k)<=i<=j;
!>          si UPLO = 'L', AB(1+i-j,j)   = A(i,j) para j<=i<=min(n,j+k).
!>          Tenga en cuenta que cuando DIAG = 'U', los elementos de la matriz AB
!>          correspondientes a los elementos diagonales de la matriz A no
!>          se referencian, pero se asumen como uno.
!>

LDAB

!>          LDAB es ENTERO
!>          La dimensión principal de la matriz AB.  LDAB >= K+1.
!>

WORK

!>          WORK es matriz DOUBLE PRECISION, dimensión (MAX(1,LWORK)),
!>          donde LWORK >= N cuando NORMA = 'I'; de lo contrario, WORK no
!>          se referencia.
!>
