ZLA_GBRFSX_EXTENDED mejora la solución calculada para un sistema de ecuaciones lineales para matrices generales de banda realizando un refinamiento iterativo de precisión extra y proporciona cotas de error y estimaciones de error hacia atrás para la solución.

Propósito:

!>
!> ZLA_GBRFSX_EXTENDED mejora la solución calculada para un sistema de
!> ecuaciones lineales realizando un refinamiento iterativo de precisión extra
!> y proporciona cotas de error y estimaciones de error hacia atrás para la solución.
!> Esta subrutina es llamada por ZGBRFSX para realizar el refinamiento iterativo.
!> Además de la cota de error normwise, el código proporciona la cota de error
!> componente a componente máxima si es posible. Ver los comentarios para
!> ERR_BNDS_NORM y ERR_BNDS_COMP para detalles de las cotas de error. Tenga en cuenta que esta
!> subrutina solo es responsable de establecer los segundos campos de
!> ERR_BNDS_NORM y ERR_BNDS_COMP.
!>

Parámetros

PREC_TYPE 
!>          PREC_TYPE es INTEGER
!>     Especifica la precisión intermedia a utilizar en el refinamiento.
!>     El valor se define por ILAPREC(P) donde P es un CHARACTER y P
!>          = 'S':  Simple
!>          = 'D':  Doble
!>          = 'I':  Indígena
!>          = 'X' o 'E':  Extra
!>

TRANS_TYPE

!>          TRANS_TYPE es INTEGER
!>     Especifica la operación de transposición en A.
!>     El valor se define por ILATRANS(T) donde T es un CHARACTER y T
!>          = 'N':  Sin transposición
!>          = 'T':  Transpuesta
!>          = 'C':  Transpuesta conjugada
!>

N

!>          N es INTEGER
!>     El número de ecuaciones lineales, es decir, el orden de la
!>     matriz A.  N >= 0.
!>

KL

!>          KL es INTEGER
!>     El número de subdiagonales dentro de la banda de A.  KL >= 0.
!>

KU

!>          KU es INTEGER
!>     El número de superdiagonales dentro de la banda de A.  KU >= 0
!>

NRHS

!>          NRHS es INTEGER
!>     El número de lados derechos, es decir, el número de columnas de la
!>     matriz B.
!>

AB

!>          AB es COMPLEX*16 array, dimension (LDAB,N)
!>     A la entrada, la matriz A de N por N.
!>

LDAB

!>          LDAB es INTEGER
!>     La dimensión principal del array A.  LDAB >= max(1,N).
!>

AFB

!>          AFB es COMPLEX*16 array, dimension (LDAF,N)
!>     Los factores L y U de la factorización
!>     A = P*L*U tal como se calcula por ZGBTRF.
!>

LDAFB

!>          LDAFB es INTEGER
!>     La dimensión principal del array AF.  LDAF >= max(1,N).
!>

IPIV

!>          IPIV es INTEGER array, dimension (N)
!>     Los índices de pivote de la factorización A = P*L*U
!>     tal como se calcula por ZGBTRF; la fila i de la matriz fue intercambiada
!>     con la fila IPIV(i).
!>

COLEQU

!>          COLEQU es LOGICAL
!>     Si es .TRUE. entonces se realizó un escalado de columnas en A antes de llamar
!>     a esta rutina. Esto es necesario para calcular la solución y las cotas de error
!>     correctamente.
!>

C

!>          C es DOUBLE PRECISION array, dimension (N)
!>     Los factores de escala de columna para A. Si COLEQU = .FALSE., C
!>     no se accede. Si se introduce C, cada elemento de C debe ser una potencia
!>     de la base para asegurar una solución y estimaciones de error fiables.
!>     El escalado por potencias de la base no causa errores de redondeo a menos
!>     que el resultado tenga un subdesbordamiento o desbordamiento. Los errores de redondeo durante el escalado
!>     conducen a un refinamiento con una matriz que no es equivalente a la
!>     matriz de entrada, produciendo estimaciones de error que pueden no ser
!>     fiables.
!>

B

!>          B es COMPLEX*16 array, dimension (LDB,NRHS)
!>     La matriz del lado derecho B.
!>

LDB

!>          LDB es INTEGER
!>     La dimensión principal del array B.  LDB >= max(1,N).
!>

Y

!>          Y es COMPLEX*16 array, dimension (LDY,NRHS)
!>     A la entrada, la matriz solución X, tal como se calcula por ZGBTRS.
!>     A la salida, la matriz solución mejorada Y.
!>

LDY

!>          LDY es INTEGER
!>     La dimensión principal del array Y.  LDY >= max(1,N).
!>

BERR_OUT

!>          BERR_OUT es DOUBLE PRECISION array, dimension (NRHS)
!>     A la salida, BERR_OUT(j) contiene el error relativo hacia atrás componente a
!>     componente para el lado derecho j de la fórmula
!>         max(i) ( abs(RES(i)) / ( abs(op(A_s))*abs(Y) + abs(B_s) )(i) )
!>     donde abs(Z) es el valor absoluto componente a componente de la matriz
!>     o vector Z. Esto se calcula por ZLA_LIN_BERR.
!>

N_NORMS

!>          N_NORMS es INTEGER
!>     Determina qué cotas de error se devolverán (ver ERR_BNDS_NORM
!>     y ERR_BNDS_COMP).
!>     Si N_NORMS >= 1 devuelve cotas de error normwise.
!>     Si N_NORMS >= 2 devuelve cotas de error componente a componente.
!>

ERR_BNDS_NORM

!>          ERR_BNDS_NORM es DOUBLE PRECISION array, dimension (NRHS, N_ERR_BNDS)
!>     Para cada lado derecho, esta matriz contiene información sobre
!>     varias cotas de error y números de condición correspondientes al
!>     error relativo normwise, que se define de la siguiente manera:
!>
!>     Error relativo normwise en el i-ésimo vector solución:
!>             max_j (abs(XTRUE(j,i) - X(j,i)))
!>            ----------------------------
