función de precisión doble zla_porpvgrw (uplo, ncols, a, lda, af, ldaf, work)
ZLA_PORPVGRW calcula el factor de crecimiento del pivote recíproco norm(A)/norm(U) para una matriz simétrica o hermitiana definida positiva.

DOCUMENTACIÓN DE FUNCIÓN/SUBRUTINA

función de doble precisión zla_porpvgrw (character*1 uplo, integer ncols, complex*16, dimension( lda, * ) a, integer lda, complex*16, dimension( ldaf, * ) af, integer ldaf, doble precisión, dimension( * ) work)

ZLA_PORPVGRW calcula el factor de crecimiento del pivote recíproco norm(A)/norm(U) para una matriz simétrica o hermitiana definida positiva.

Propósito:

!>
!>
!> ZLA_PORPVGRW calcula el factor de crecimiento del pivote recíproco
!> norm(A)/norm(U). Se utiliza la norma. Si este valor es
!> mucho menor que 1, la estabilidad de la factorización LU de la
!> matriz (equilibrada) A podría ser pobre. Esto también significa que
!> la solución X, los números de condición estimados y los límites de error podrían
!> no ser fiables.
!>

Parámetros

UPLO 
!>          UPLO es CHARACTER*1
!>       = 'U':  El triángulo superior de A está almacenado;
!>       = 'L':  El triángulo inferior de A está almacenado.
!>

NCOLS

!>          NCOLS es INTEGER
!>     El número de columnas de la matriz A. NCOLS >= 0.
!>

A

!>          A es un array COMPLEX*16, de dimensión (LDA,N)
!>     En la entrada, la matriz N por N A.
!>

LDA

!>          LDA es INTEGER
!>     La dimensión principal del array A.  LDA >= max(1,N).
!>

AF

!>          AF es un array COMPLEX*16, de dimensión (LDAF,N)
!>     El factor triangular U o L de la factorización de Cholesky
!>     A = U**T*U o A = L*L**T, tal como fue calculada por ZPOTRF.
!>

LDAF

!>          LDAF es INTEGER
!>     La dimensión principal del array AF.  LDAF >= max(1,N).
!>

WORK

!>          WORK es un array DOUBLE PRECISION, de dimensión (2*N)
!>
