subrutina zlarf1f (side, m, n, v, incv, tau, c, ldc, work)
ZLARF1F aplica un reflector elemental a una matriz rectangular general

Documentación de Función/Subrutina

subrutina zlarf1f (carácter side, entero m, entero n, complejo*16, dimensión( * ) v, entero incv, complejo*16 tau, complejo*16, dimensión( ldc, * ) c, entero ldc, complejo*16, dimensión( * ) work)

ZLARF1F aplica un reflector elemental complejo H a una matriz real m por n C, desde la izquierda o la derecha. H se representa en la forma

Propósito:

!>
!> ZLARF1F aplica un reflector elemental complejo H a una matriz real m por n
!> C, desde la izquierda o la derecha. H se representa en la forma
!>
!>       H = I - tau * v * v**H
!>
!> donde tau es un escalar complejo y v es un vector complejo.
!>
!> Si tau = 0, entonces H se considera la matriz identidad.
!>
!> Para aplicar H**H, proporcione conjg(tau) en lugar de
!> tau.
!>

Parámetros

SIDE 
!>          SIDE es CHARACTER*1
!>          = 'L': forma  H * C
!>
!> \param[in] M
!> \verbatim
!>          M es INTEGER
!>          El número de filas de la matriz C.
!>

N

!>          N es INTEGER
!>          El número de columnas de la matriz C.
!>

V

!>          V es un array COMPLEX*16, dimensión
!>                     (1 + (M-1)*abs(INCV)) si SIDE = 'L'
!>                  o (1 + (N-1)*abs(INCV)) si SIDE = 'R'
!>          El vector v en la representación de H. V no se usa si
!>          TAU = 0. V(1) no se referencia ni se modifica.
!>

INCV

!>          INCV es INTEGER
!>          El incremento entre elementos de v. INCV <> 0.
!>

TAU

!>          TAU es COMPLEX*16
!>          El valor tau en la representación de H.
!>

C

!>          C es un array COMPLEX*16, dimensión (LDC,N)
!>          En la entrada, la matriz m por n C.
!>          En la salida, C se sobrescribe con la matriz H * C si SIDE = 'L',
!>          o C * H si SIDE = 'R'.
!>

LDC

!>          LDC es INTEGER
!>          La dimensión principal del array C. LDC >= max(1,M).
!>

WORK

!>          WORK es un array COMPLEX*16, dimensión
!>                         (N) si SIDE = 'L'
!>                      o (M) si SIDE = 'R'
!>
