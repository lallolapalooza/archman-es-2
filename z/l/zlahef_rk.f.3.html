subroutine zlahef_rk (character uplo, integer n, integer nb, integer kb, complex*16, dimension( lda, * ) a, integer lda, complex*16, dimension( * ) e, integer, dimension( * ) ipiv, complex*16, dimension( ldw, * ) w, integer ldw, integer info)

ZLAHEF_RK calcula una factorización parcial de una matriz Hermitiana indefinida compleja utilizando el método de pivoteo diagonal acotado de Bunch-Kaufman (rook).

Propósito:

!> ZLAHEF_RK calcula una factorización parcial de una matriz Hermitiana compleja A
!> utilizando el método de pivoteo diagonal acotado de Bunch-Kaufman (rook).
!> La factorización parcial tiene la forma:
!>
!> A  =  ( I  U12 ) ( A11  0  ) (  I       0    )  si UPLO = 'U', o:
!>       ( 0  U22 ) (  0   D  ) ( U12**H U22**H )
!>
!> A  =  ( L11  0 ) (  D   0  ) ( L11**H L21**H )  si UPLO = 'L',
!>       ( L21  I ) (  0  A22 ) (  0       I    )
!>
!> donde el orden de D es como máximo NB. El orden real se devuelve en
!> el argumento KB, y es NB o NB-1, o N si N <= NB.
!>
!> ZLAHEF_RK es una rutina auxiliar llamada por ZHETRF_RK. Utiliza
!> código bloqueado (llamando a BLAS de Nivel 3) para actualizar la submatriz
!> A11 (si UPLO = 'U') o A22 (si UPLO = 'L').
!>

Parámetros

UPLO 
!>          UPLO es CHARACTER*1
!>          Especifica si la parte triangular superior o inferior de la
!>          matriz Hermitiana A está almacenada:
!>          = 'U':  Triangular superior
!>          = 'L':  Triangular inferior
!>

N

!>          N es INTEGER
!>          El orden de la matriz A.  N >= 0.
!>

NB

!>          NB es INTEGER
!>          El número máximo de columnas de la matriz A que deben ser
!>          factorizadas.  NB debe ser al menos 2 para permitir bloques de pivote
!>          de 2x2.
!>

KB

!>          KB es INTEGER
!>          El número de columnas de A que fueron realmente factorizadas.
!>          KB es NB-1 o NB, o N si N <= NB.
!>

A

!>          A es un array COMPLEX*16, de dimensión (LDA,N)
!>          En la entrada, la matriz Hermitiana A.
!>            Si UPLO = 'U': la parte superior N por N de A contiene la parte
!>            triangular superior de la matriz A, y la parte estrictamente
!>            inferior de A no se referencia.
!>
!>            Si UPLO = 'L': la parte inferior N por N de A contiene la parte
!>            triangular inferior de la matriz A, y la parte estrictamente
!>            superior de A no se referencia.
!>
!>          En la salida, contiene:
!>            a) SÓLO los elementos de la diagonal de la matriz diagonal
!>               Hermitiana D en la diagonal de A, es decir, D(k,k) = A(k,k);
!>               (los elementos superdiagonales (o subdiagonales) de D
!>                se almacenan en la salida en el array E), y
!>            b) Si UPLO = 'U': factor U en la parte superdiagonal de A.
!>               Si UPLO = 'L': factor L en la parte subdiagonal de A.
!>

LDA

!>          LDA es INTEGER
!>          La dimensión principal del array A.  LDA >= max(1,N).
!>

E

!>          E es un array COMPLEX*16, de dimensión (N)
!>          En la salida, contiene los elementos superdiagonales (o subdiagonales)
!>          de la matriz diagonal Hermitiana D
!>          con bloques diagonales de 1x1 o 2x2, donde
!>          Si UPLO = 'U': E(i) = D(i-1,i), i=2:N, E(1) se establece a 0;
!>          Si UPLO = 'L': E(i) = D(i+1,i), i=1:N-1, E(N) se establece a 0.
!>
!>          NOTA: Para un bloque diagonal de 1x1 D(k), donde
!>          1 <= k <= N, el elemento E(k) se establece a 0 en ambos
!>          casos UPLO = 'U' o UPLO = 'L'.
!>

IPIV

!>          IPIV es un array INTEGER, de dimensión (N)
!>          IPIV describe la matriz de permutación P en la factorización
!>          de la matriz A de la siguiente manera. El valor absoluto de IPIV(k)
!>          representa el índice de la fila y columna que fueron
!>          intercambiadas con la k-ésima fila y columna. El valor de UPLO
!>          describe el orden en que se aplicaron los intercambios.
!>          Además, el signo de IPIV representa la estructura de bloques de
!>          la matriz diagonal Hermitiana D con bloques diagonales de 1x1 o 2x2
!>          que corresponden a 1 o 2 intercambios
!>          en cada paso de factorización.
!>
!>          Si UPLO = 'U',
!>          (en orden de factorización, k disminuye de N a 1):
!>            a) Una única entrada positiva IPIV(k) > 0 significa:
!>               D(k,k) es un bloque diagonal de 1x1.
!>               Si IPIV(k) != k, las filas y columnas k e IPIV(k) fueron
!>               intercambiadas en la submatriz A(1:N,N-KB+1:N);
!>               Si IPIV(k) = k, no ocurrió ningún intercambio.
!>
!>
!>            b) Un par de entradas consecutivas negativas
!>               IPIV(k) < 0 e IPIV(k-1) < 0 significa:
!>               D(k-1:k,k-1:k) es un bloque diagonal de 2x2.
!>               (NOTA: las entradas negativas en IPIV solo aparecen en pares).
!>               1) Si -IPIV(k) != k, las filas y columnas
!>                  k y -IPIV(k) fueron intercambiadas
!>                  en la matriz A(1:N,N-KB+1:N).
!>                  Si -IPIV(k) = k, no ocurrió ningún intercambio.
!>               2) Si -IPIV(k-1) != k-1, las filas y columnas
!>                  k-1 y -IPIV(k-1) fueron intercambiadas
!>                  en la submatriz A(1:N,N-KB+1:N).
!>                  Si -IPIV(k-1) = k-1, no ocurrió ningún intercambio.
!>
!>            c) En ambos casos a) y b), siempre se cumple ABS( IPIV(k) ) <= k.
!>
!>            d) NOTA: Cualquier entrada IPIV(k) es siempre distinta de cero en la salida.
!>
!>          Si UPLO = 'L',
!>          (en orden de factorización, k aumenta de 1 a N):
!>            a) Una única entrada positiva IPIV(k) > 0 significa:
!>               D(k,k) es un bloque diagonal de 1x1.
!>               Si IPIV(k) != k, las filas y columnas k e IPIV(k) fueron
!>               intercambiadas en la submatriz A(1:N,1:KB).
!>               Si IPIV(k) = k, no ocurrió ningún intercambio.
!>
!>            b) Un par de entradas consecutivas negativas
!>               IPIV(k) < 0 e IPIV(k+1) < 0 significa:
!>               D(k:k+1,k:k+1) es un bloque diagonal de 2x2.
!>               (NOTA: las entradas negativas en IPIV solo aparecen en pares).
!>               1) Si -IPIV(k) != k, las filas y columnas
!>                  k y -IPIV(k) fueron intercambiadas
!>                  en la submatriz A(1:N,1:KB).
!>                  Si -IPIV(k) = k, no ocurrió ningún intercambio.
!>               2) Si -IPIV(k+1) != k+1, las filas y columnas
!>                  k-1 y -IPIV(k-1) fueron intercambiadas
!>                  en la submatriz A(1:N,1:KB).
!>                  Si -IPIV(k+1) = k+1, no ocurrió ningún intercambio.
!>
!>            c) En ambos casos a) y b), siempre se cumple ABS( IPIV(k) ) >= k.
!>
!>            d) NOTA: Cualquier entrada IPIV(k) es siempre distinta de cero en la salida.
!>

W

!>          W es un array COMPLEX*16, de dimensión (LDW,NB)
!>

LDW

!>          LDW es INTEGER
!>          La dimensión principal del array W.  LDW >= max(1,N).
!>

INFO

!>          INFO es INTEGER
!>          = 0: salida exitosa
!>
!>          < 0: Si INFO = -k, el k-ésimo argumento tenía un valor ilegal.
!>
!>          > 0: Si INFO = k, la matriz A es singular, porque:
!>                 Si UPLO = 'U': la columna k en la parte
!>                 triangular superior de A contiene todos ceros.
!>                 Si UPLO = 'L': la columna k en la parte
!>                 triangular inferior de A contiene todos ceros.
!>
!>               Por lo tanto, D(k,k) es exactamente cero, y los elementos
!>               superdiagonales de la columna k de U (o los elementos
!>               subdiagonales de
  • SRC/zlahef_rk.f(3)

Function/Subroutine Documentation

This subroutine is part of the LAPACK routines that compute the L-infinite norm of a matrix. It uses the following factorization:

           A = P * U * Q**H

where U is block upper triangular with NB x NB blocks and Q is orthogonal.

This subroutine computes the factorization in place, and also the Rk information.

Arguments:

N

The order of the matrix A.

N is INTEGER, Input.

NB

The block size for the factorization.

NB is INTEGER, Input.

A

On entry, the m x n matrix A.

On exit, the factors P, U and Q are stored in A.

A is COMPLEX*16 array, dimension (LDA, N).

LDA

The leading dimension of the array A.

LDA is INTEGER, Input.

D

On exit, the scaling factors D.

D is DOUBLE PRECISION array, dimension (min(N, M)).

SD

On exit, the singular values (Rk information).

SD is COMPLEX*16 array, dimension (min(N, M)).

INFO

Information on potential singularity. If INFO = 0, the factorization has been completed, but the block diagonal matrix D is exactly singular, and division by zero will occur if it is used to solve a system of equations.

NOTE: INFO only stores the first occurrence of a singularity, any subsequent occurrence of singularity is not stored in INFO even though the factorization always completes.

INFO is INTEGER, Output.
