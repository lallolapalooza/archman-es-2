subrutina zlattr (entero imat, caracter uplo, caracter trans, caracter diag, entero, dimensión( 4 ) iseed, entero n, complejo*16, dimensión( lda, * ) a, entero lda, complejo*16, dimensión( * ) b, complejo*16, dimensión( * ) work, doble precisión, dimensión( * ) rwork, entero info)

ZLATTR

Propósito:

!>
!> ZLATTR genera una matriz de prueba triangular en almacenamiento 2-dimensional.
!> IMAT y UPLO especifican de forma única las propiedades de la matriz de prueba,
!> que se devuelve en la matriz A.
!>

Parámetros

IMAT 
!>          IMAT es ENTERO
!>          Una clave entera que describe qué matriz generar para esta
!>          ruta.
!>

UPLO

!>          UPLO es CARACTER*1
!>          Especifica si la matriz A será triangular superior o inferior.
!>          = 'U':  Triangular superior
!>          = 'L':  Triangular inferior
!>

TRANS

!>          TRANS es CARACTER*1
!>          Especifica si se utilizará la matriz o su transpuesta.
!>          = 'N':  Sin transponer
!>          = 'T':  Transpuesta
!>          = 'C':  Transpuesta conjugada
!>

DIAG

!>          DIAG es CARACTER*1
!>          Especifica si la matriz A es triangular unitaria o no.
!>          = 'N':  Triangular no unitaria
!>          = 'U':  Triangular unitaria
!>

ISEED

!>          ISEED es matriz ENTERA, dimensión (4)
!>          El vector semilla para el generador de números aleatorios (usado en
!>          ZLATMS). Modificado a la salida.
!>

N

!>          N es ENTERO
!>          El orden de la matriz a generar.
!>

A

!>          A es matriz COMPLEJA*16, dimensión (LDA,N)
!>          La matriz triangular A. Si UPLO = 'U', la parte superior triangular
!>          N x N principal de la matriz A contiene la matriz triangular superior,
!>          y la parte triangular inferior estricta de A no se referencia.
!>          Si UPLO = 'L', la parte inferior triangular N x N principal de la
!>          matriz A contiene la matriz triangular inferior y la parte triangular
!>          superior estricta de A no se referencia.
!>

LDA

!>          LDA es ENTERO
!>          La dimensión principal de la matriz A. LDA >= max(1,N).
!>

B

!>          B es matriz COMPLEJA*16, dimensión (N)
!>          El vector del lado derecho, si IMAT > 10.
!>

WORK

!>          WORK es matriz COMPLEJA*16, dimensión (2*N)
!>

RWORK

!>          RWORK es matriz DOBLE PRECISION, dimensión (N)
!>

INFO

!>          INFO es ENTERO
!>          = 0:  salida exitosa
!>          < 0:  si INFO = -i, el i-ésimo argumento tuvo un valor ilegal
!>
