subroutine zla_syrfsx_extended (integer prec_type, character uplo, integer n, integer nrhs, complex*16, dimension( lda, * ) a, integer lda, complex*16, dimension( ldaf, * ) af, integer ldaf, integer, dimension( * ) ipiv, logical colequ, double precision, dimension( * ) c, complex*16, dimension( ldb, * ) b, integer ldb, complex*16, dimension( ldy, * ) y, integer ldy, double precision, dimension( * ) berr_out, integer n_norms, double precision, dimension( nrhs, * ) err_bnds_norm, double precision, dimension( nrhs, * ) err_bnds_comp, complex*16, dimension( * ) res, double precision, dimension( * ) ayb, complex*16, dimension( * ) dy, complex*16, dimension( * ) y_tail, double precision rcond, integer ithresh, double precision rthresh, double precision dz_ub, logical ignore_cwise, integer info)

ZLA_SYRFSX_EXTENDED mejora la solución computada de un sistema de ecuaciones lineales para matrices indefinidas simétricas realizando un refinamiento iterativo de precisión extra y proporciona cotas de error y estimaciones de error hacia atrás para la solución.

Propósito:

!>
!> ZLA_SYRFSX_EXTENDED mejora la solución computada de un sistema de
!> ecuaciones lineales realizando un refinamiento iterativo de precisión extra
!> y proporciona cotas de error y estimaciones de error hacia atrás para la solución.
!> Esta subrutina es llamada por ZSYRFSX para realizar el refinamiento iterativo.
!> Además de la cota de error normwise, el código proporciona una cota de error
!> componente a componente máxima si es posible. Ver los comentarios para ERR_BNDS_NORM
!> y ERR_BNDS_COMP para detalles de las cotas de error. Tenga en cuenta que esta
!> subrutina solo es responsable de establecer los segundos campos de
!> ERR_BNDS_NORM y ERR_BNDS_COMP.
!>

Parámetros

PREC_TYPE 
!>          PREC_TYPE es INTEGER
!>     Especifica la precisión intermedia a utilizar en el refinamiento.
!>     El valor se define por ILAPREC(P) donde P es un CHARACTER y P
!>          = 'S':  Simple
!>          = 'D':  Doble
!>          = 'I':  Indígena
!>          = 'X' o 'E':  Extra
!>

UPLO

!>          UPLO es CHARACTER*1
!>       = 'U':  El triángulo superior de A está almacenado;
!>       = 'L':  El triángulo inferior de A está almacenado.
!>

N

!>          N es INTEGER
!>     El número de ecuaciones lineales, es decir, el orden de la
!>     matriz A.  N >= 0.
!>

NRHS

!>          NRHS es INTEGER
!>     El número de lados derechos, es decir, el número de columnas de la
!>     matriz B.
!>

A

!>          A es array COMPLEX*16, dimensión (LDA,N)
!>     En la entrada, la matriz A de N por N.
!>

LDA

!>          LDA es INTEGER
!>     La dimensión principal del array A.  LDA >= max(1,N).
!>

AF

!>          AF es array COMPLEX*16, dimensión (LDAF,N)
!>     La matriz diagonal por bloques D y los multiplicadores utilizados para
!>     obtener el factor U o L tal como lo calcula ZSYTRF.
!>

LDAF

!>          LDAF es INTEGER
!>     La dimensión principal del array AF.  LDAF >= max(1,N).
!>

IPIV

!>          IPIV es array INTEGER, dimensión (N)
!>     Detalles de los intercambios y la estructura de bloques de D
!>     tal como los determina ZSYTRF.
!>

COLEQU

!>          COLEQU es LOGICAL
!>     Si es .TRUE. entonces se realizó la   equilibración de columnas a A antes de llamar
!>     a esta rutina. Esto es necesario para calcular la solución y las cotas de error
!>     correctamente.
!>

C

!>          C es array DOUBLE PRECISION, dimensión (N)
!>     Los factores de escala de columna para A. Si COLEQU = .FALSE., C
!>     no se accede. Si se introduce C, cada elemento de C debe ser una potencia
!>     de la base para asegurar una solución y estimaciones de error fiables.
!>     La escala por potencias de la base no causa errores de redondeo a menos
!>     que el resultado cause un subdesbordamiento o desbordamiento. Los errores de redondeo durante la escala
!>     conducen a refinar con una matriz que no es equivalente a la
!>     matriz de entrada, produciendo estimaciones de error que pueden no ser
!>     fiables.
!>

B

!>          B es array COMPLEX*16, dimensión (LDB,NRHS)
!>     La matriz del lado derecho B.
!>

LDB

!>          LDB es INTEGER
!>     La dimensión principal del array B.  LDB >= max(1,N).
!>

Y

!>          Y es array COMPLEX*16, dimensión (LDY,NRHS)
!>     En la entrada, la matriz solución X, tal como la calcula ZSYTRS.
!>     En la salida, la matriz solución mejorada Y.
!>

LDY

!>          LDY es INTEGER
!>     La dimensión principal del array Y.  LDY >= max(1,N).
!>

BERR_OUT

!>          BERR_OUT es array DOUBLE PRECISION, dimensión (NRHS)
!>     En la salida, BERR_OUT(j) contiene el error relativo de atrás componente a componente
!>     para el lado derecho j de la fórmula
!>         max(i) ( abs(RES(i)) / ( abs(op(A_s))*abs(Y) + abs(B_s) )(i) )
!>     donde abs(Z) es el valor absoluto componente a componente de la matriz
!>     o vector Z. Esto es calculado por ZLA_LIN_BERR.
!>

N_NORMS

!>          N_NORMS es INTEGER
!>     Determina qué cotas de error se devuelven (ver ERR_BNDS_NORM
!>     y ERR_BNDS_COMP).
!>     Si N_NORMS >= 1 devuelve cotas de error normwise.
!>     Si N_NORMS >= 2 devuelve cotas de error componente a componente.
!>

ERR_BNDS_NORM

!>          ERR_BNDS_NORM es array DOUBLE PRECISION, dimensión (NRHS, N_ERR_BNDS)
!>     Para cada lado derecho, este array contiene información sobre
!>     varias cotas de error y números de condición correspondientes al
!>     error relativo normwise, que se define como sigue:
!>
!>     Error relativo normwise en el i-ésimo vector solución:
!>             max_j (abs(XTRUE(j,i) - X(j,i)))
!>            ------------------------------
!>                  max_j abs(X(j,i))
!>
!>     El array está indexado por el tipo de información de error como se describe
!>     a continuación. Actualmente hay hasta tres piezas de información
!>     devueltas.
!>
!>     El primer índice en ERR_BNDS_NORM(i,:) corresponde al i-ésimo
!>     lado derecho.
!>
!>     El segundo índice en ERR_BNDS_NORM(:,err) contiene los siguientes
!>     tres campos:
!>     err = 1  booleano. Confía en la respuesta si el
!>              número de condición recíproco es menor que el umbral
!>              sqrt(n) * slam

zla_syrfsx_extended - LAPACK

NAME

zla_syrfsx_extended - La rutina de interfaz para el solucionador de sistemas lineales simétricos/hermitianos de precisión simple.

SYNOPSIS

SUBROUTINE ZLA_SYRFSX_EXTENDED( UPLO, EQUED, N, NRHS, A, LDA, AF, LDAF, IPIV, B, LDB, X, LDX,
                                FERR, BERR, ERR_BNDS_NORM, ERR_BNDS_COMP, RES, AYB, DY, Y_TAIL,
                                RCOND, ITHRESH, RTHRESH, DZ_UB, IGNORE_CWISE, INFO )

Parámetros:

`UPLO`
CHARACTER*1. Debe ser 'U' o 'L'. Especifica si la matriz A es superior o inferior triangular.
`EQUED`
CHARACTER*1. Debe ser 'N', 'S', 'D' o 'B'. Especifica las opciones de equilibrio aplicadas a la matriz A.
`N`
INTEGER. El orden de la matriz A. N >= 0.
`NRHS`
INTEGER. El número de sistemas a resolver, es decir, el número de columnas de las matrices B y X. NRHS >= 0.
`A`
COMPLEX*16 array, dimension (LDA,N). El factor de la matriz A.
`LDA`
INTEGER. El segundo de los array A. LDA >= max(1, N).
`AF`
COMPLEX*16 array, dimension (LDAF,N). El factor de la matriz A. AF contiene la factorización LU de A.
`LDAF`
INTEGER. El segundo de los array AF. LDAF >= max(1, N).
`IPIV`
INTEGER array, dimension (min(N,N)). Las operaciones de pivote utilizadas en la factorización de A. Las filas i y IPIV(i) fueron intercambiadas.
`B`
COMPLEX*16 array, dimension (LDB,NRHS). El lado derecho de los sistemas lineales con N ecuaciones y NRHS variables.
`LDB`
INTEGER. El segundo de los array B. LDB >= max(1,N).
`X`
COMPLEX*16 array, dimension (LDX,NRHS). El resultado que se obtiene de resolver los sistemas.
`LDX`
INTEGER. El segundo de los array X. LDX >= max(1,N).
`FERR`
DOUBLE PRECISION array, dimension (NRHS). Estima la frontera superior de la cantidad de error relativo para cada uno de los NRHS sistemas resueltos.
`BERR`
DOUBLE PRECISION array, dimension (NRHS). El error relativo de la componente más grande de la solución.
`ERR_BNDS_NORM`
DOUBLE PRECISION array, dimension (NRHS, 3). Devuelve las estimaciones del error relativo y los números de condición normwise.
`ERR_BNDS_COMP`
DOUBLE PRECISION array, dimension (NRHS, 3). Devuelve las estimaciones del error relativo y los números de condición componentwise.
`RES`
COMPLEX*16 array, dimension (N). Espacio de trabajo para mantener el residuo intermedio.
`AYB`
DOUBLE PRECISION array, dimension (N). Espacio de trabajo.
`DY`
COMPLEX*16 array, dimension (N). Espacio de trabajo para mantener la solución intermedia.
`Y_TAIL`
COMPLEX*16 array, dimension (N). Espacio de trabajo para mantener los bits finales de la solución intermedia.
`RCOND`
DOUBLE PRECISION. Número de condición escalado recíproco.
`ITHRESH`
INTEGER. El número máximo de cómputos de residuo permitidos para el refinamiento.
`RTHRESH`
DOUBLE PRECISION. Determina cuándo detener el refinamiento si la estimación del error deja de disminuir.
`DZ_UB`
DOUBLE PRECISION. Determina cuándo empezar a considerar la convergencia componentwise.
`IGNORE_CWISE`
LOGICAL. Si es .TRUE. entonces ignorar la convergencia componentwise.
`INFO`
INTEGER. = 0: Salida exitosa. < 0: si INFO = -i, el i-ésimo argumento al ZLA_SYRFSX_EXTENDED tuvo un valor ilegal.

Function/Subroutine Documentation

FERR

!>          FERR is DOUBLE PRECISION array, dimension (NRHS)
!>     The estimated forward error for the i-th solution vector X(i),
!>     is computed as:
!>
!>     forward error = norm(X(i) - XTRUE(i)) / norm(X(i))
!>
!>     This error is bounded by ferr(i) =       ( norm(x(i),1) *       anorm ) / C(A,X)
!>                                      max( cond_n, cond_c )
!>
!>     where C(A,X) is the condition number.
!>
!>     The condition number is the Skeel condition number for the matrix A
!>     after equilibration (if done). This is computed as:
!>
!>     Skeel condition number =
!>          max_i |inv(A)|_i * |A|_i
!>
!>     If cond <= 1, then the matrix is considered to be singular to
!>     working precision.

BERR

!>          BERR is DOUBLE PRECISION array, dimension (NRHS)
!>     The componentwise relative error of the i-th solution vector X(i),
!>     is computed as:
!>
!>     Componentwise relative error in the i-th solution vector:
!>                    abs(XTRUE(j,i) - X(j,i))
!>             max_j ----------------------
!>                         abs(X(j,i))
!>
!>     The quantity berr(i) is the smallest value such that
!>
!>     max_j |XTRUE(j,i) - X(j,i)| / |X(j,i)| <= berr(i) *
!>                                          ( norm(Ainv,inf) * anorm )
!>                                         ------------------------
!>                                               cond(A,X)
!>
!>     where cond(A,X) is the Skeel condition number of the matrix A.

ERR_BNDS_NORM

!>          ERR_BNDS_NORM is DOUBLE PRECISION array, dimension (NRHS, N_ERR_BNDS)
!>     For each right hand side, this array contains information about
!>     various error bounds and condition numbers corresponding to the
!>     normwise relative error, which is defined as follows:
!>
!>     Normwise relative error in the ith solution vector:
!>                    norm(XTRUE(i) - X(i))
!>             --------------------------
!>                      norm(X(i))
!>
!>     The array is indexed by the right hand side i (on which the
!>     normwise relative error depends), and the type of error
!>     information as described below. There currently are up to three
!>     pieces of information returned for each right hand side. If
!>     normwise accuracy is not requested (PARAMS(1) = 0.0), then
!>     ERR_BNDS_NORM is not accessed. If N_ERR_BNDS < 3, then at most
!>     the first (:,N_ERR_BNDS) entries are returned.
!>
!>     The first index in ERR_BNDS_NORM(i,:) corresponds to the ith
!>     right hand side.
!>
!>     The second index in ERR_BNDS_NORM(:,err) contains the following
!>     three fields:
!>     err = 1  boolean. Trust the answer if the
!>              reciprocal condition number is less than the threshold
!>              sqrt(n) * slamch('Epsilon').
!>
!>     err = 2  error bound: The estimated forward error,
!>              almost certainly within a factor of 10 of the true error
!>              so long as the next entry is greater than the threshold
!>              sqrt(n) * slamch('Epsilon'). This error bound should only
!>              be trusted if the previous boolean is true.
!>
!>     err = 3  Reciprocal condition number: Estimated normwise
!>              reciprocal condition number.  Compared with the threshold
!>              sqrt(n) * slamch('Epsilon') to determine if the error
!>              estimate is . These reciprocal condition
!>              numbers are 1 / (norm(Z^{-1},inf) * norm(Z,inf)) for some
!>              appropriately scaled matrix Z.
!>              Let Z = S*A, where S scales each row by a power of the
!>              radix so all absolute row sums of Z are approximately 1.
!>
!>     This subroutine is only responsible for setting the second field
!>     above.
!>     See Lapack Working Note 165 for further details and extra
!>     cautions.

ERR_BNDS_COMP

!>          ERR_BNDS_COMP is DOUBLE PRECISION array, dimension (NRHS, N_ERR_BNDS)
!>     For each right-hand side, this array contains information about
!>     various error bounds and condition numbers corresponding to the
!>     componentwise relative error, which is defined as follows:
!>
!>     Componentwise relative error in the ith solution vector:
!>                    abs(XTRUE(j,i) - X(j,i))
!>             max_j ----------------------
!>                         abs(X(j,i))
!>
!>     The array is indexed by the right-hand side i (on which the
!>     componentwise relative error depends), and the type of error
!>     information as described below. There currently are up to three
!>     pieces of information returned for each right-hand side. If
!>     componentwise accuracy is not requested (PARAMS(3) = 0.0), then
!>     ERR_BNDS_COMP is not accessed.  If N_ERR_BNDS < 3, then at most
!>     the first (:,N_ERR_BNDS) entries are returned.
!>
!>     The first index in ERR_BNDS_COMP(i,:) corresponds to the ith
!>     right-hand side.
!>
!>     The second index in ERR_BNDS_COMP(:,err) contains the following
!>     three fields:
!>     err = 1  boolean. Trust the answer if the
!>              reciprocal condition number is less than the threshold
!>              sqrt(n) * slamch('Epsilon').
!>
!>     err = 2  error bound: The estimated forward error,
!>              almost certainly within a factor of 10 of the true error
!>              so long as the next entry is greater than the threshold
!>              sqrt(n) * slamch('Epsilon'). This error bound should only
!>              be trusted if the previous boolean is true.
!>
!>     err = 3  Reciprocal condition number: Estimated componentwise
!>              reciprocal condition number.  Compared with the threshold
!>              sqrt(n) * slamch('Epsilon') to determine if the error
!>              estimate is . These reciprocal condition
!>              numbers are 1 / (norm(Z^{-1},inf) * norm(Z,inf)) for some
!>              appropriately scaled matrix Z.
!>              Let Z = S*(A*diag(x)), where x is the solution for the
!>              current right-hand side and S scales each row of
!>              A*diag(x) by a power of the radix so all absolute row
!>              sums of Z are approximately 1.
!>
!>     This subroutine is only responsible for setting the second field
!>     above.
!>     See Lapack Working Note 165 for further details and extra
!>     cautions.

RES

!>          RES is COMPLEX*16 array, dimension (N)
!>     Workspace to hold the intermediate residual.

AYB

!>          AYB is DOUBLE PRECISION array, dimension (N)
!>     Workspace.

DY

!>          DY is COMPLEX*16 array, dimension (N)
!>     Workspace to hold the intermediate solution.

Y_TAIL

!>          Y_TAIL is COMPLEX*16 array, dimension (N)
!>     Workspace to hold the trailing bits of the intermediate solution.

RCOND

!>          RCOND is DOUBLE PRECISION
!>     Reciprocal scaled condition number.  This is an estimate of the
!>     reciprocal Skeel condition number of the matrix A after
!>     equilibration (if done).  If this is less than the machine
!>     precision (in particular, if it is zero), the matrix is singular
!>     to working precision.  Note that the error may still be small even
!>     if this number is very small and the matrix appears ill-
!>     conditioned.

ITHRESH

!>          ITHRESH is INTEGER
!>     The maximum number of residual computations allowed for
!>     refinement. The default is 10. For 'aggressive' set to 100 to
!>     permit convergence using approximate factorizations or
!>     factorizations other than LU. If the factorization uses a
!>     technique other than Gaussian elimination, the guarantees in
!>     ERR_BNDS_NORM and ERR_BNDS_COMP may no longer be trustworthy.

RTHRESH

!>          RTHRESH is DOUBLE PRECISION
!>     Determines when to stop refinement if the error estimate stops
!>     decreasing. Refinement will stop when the next solution no longer
!>     satisfies norm(dx_{i+1}) < RTHRESH * norm(dx_i) where norm(Z) is
!>     the infinity norm of Z. RTHRESH satisfies 0 < RTHRESH <= 1. The
!>     default value is 0.5. For 'aggressive' set to 0.9 to permit
!>     convergence on extremely ill-conditioned matrices. See LAWN 165
!>     for more details.

DZ_UB

!>          DZ_UB is DOUBLE PRECISION
!>     Determines when to start considering componentwise convergence.
!>     Componentwise convergence is only considered after each component
!>     of the solution Y is stable, which we define as the relative
!>     change in each component being less than DZ_UB. The default value
!>     is 0.25, requiring the first bit to be stable. See LAWN 165 for
!>     more details.

IGNORE_CWISE

!>          IGNORE_CWISE is LOGICAL
!>     If .TRUE. then ignore componentwise convergence. Default value
!>     is .FALSE..

INFO

!>          INFO is INTEGER
!>       = 0:  Successful exit.
!>       < 0:  if INFO = -i, the ith argument to ZLA_HERFSX_EXTENDED had an illegal
!>             value
