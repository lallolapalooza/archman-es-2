función de precisión doble zlanhs (norma, n, a, lda, work)

ZLANHS devuelve el valor de la 1-norma, norma de Frobenius, norma infinito o el mayor valor absoluto de cualquier elemento de una matriz superior de Hessenberg.

Documentación de función/subrutina

función de precisión doble zlanhs (carácter norma, entero n, complejo*16, dimensión( lda, * ) a, entero lda, precisión doble, dimensión( * ) work)

ZLANHS devuelve el valor de la 1-norma, norma de Frobenius, norma infinito o el mayor valor absoluto de cualquier elemento de una matriz superior de Hessenberg.

Propósito:

!>
!> ZLANHS  devuelve el valor de la norma uno,  o la norma de Frobenius, o
!> la norma del infinito, o el elemento de mayor valor absoluto de una
!> matriz de Hessenberg A.
!>

Devuelve

ZLANHS 
!>
!>    ZLANHS = ( max(abs(A(i,j))), NORMA = 'M' o 'm'
!>             (
!>             ( norm1(A),         NORMA = '1', 'O' o 'o'
!>             (
!>             ( normI(A),         NORMA = 'I' o 'i'
!>             (
!>             ( normF(A),         NORMA = 'F', 'f', 'E' o 'e'
!>
!> donde  norm1  denota la  norma uno de una matriz (suma máxima de columna),
!> normI  denota la  norma del infinito  de una matriz  (suma máxima de fila) y
!> normF  denota la  norma de Frobenius de una matriz (raíz cuadrada de la suma de
!> cuadrados).  Tenga en cuenta que  max(abs(A(i,j)))  no es una norma matricial consistente.
!>

Parámetros

NORMA 
!>          NORMA es CHARACTER*1
!>          Especifica el valor que se devolverá en ZLANHS como se describe
!>          arriba.
!>

N

!>          N es INTEGER
!>          El orden de la matriz A.  N >= 0.  Cuando N = 0, ZLANHS se
!>          establece a cero.
!>

A

!>          A es una matriz COMPLEX*16, dimensión (LDA,N)
!>          La matriz de Hessenberg superior n por n A; la parte de A debajo de
!>          la primera subdiagonal no se referencia.
!>

LDA

!>          LDA es INTEGER
!>          La dimensión principal de la matriz A.  LDA >= max(N,1).
!>

WORK

!>          WORK es una matriz DOUBLE PRECISION, dimensión (MAX(1,LWORK)),
!>          donde LWORK >= N cuando NORMA = 'I'; de lo contrario, WORK no se
!>          referencia.
!>
