Funciones/Subrutinas


función double precision zlange (norm, m, n, a, lda, work)
ZLANGE devuelve el valor de la 1-norma, norma de Frobenius, infinito-norma o el valor absoluto más grande de cualquier elemento de una matriz rectangular general.

DOCUMENTACIÓN DE FUNCIÓN/SUBRUTINA

función double precision zlange (carácter norm, entero m, entero n, complejo*16, dimensión( lda, * ) a, entero lda, double precision, dimensión( * ) work)

ZLANGE devuelve el valor de la 1-norma, norma de Frobenius, infinito-norma, o el elemento de mayor valor absoluto de una matriz compleja.

Propósito:

!>
!> ZLANGE  devuelve el valor de la norma uno,  o la norma de Frobenius, o
!> la norma infinito,  o el elemento de mayor valor absoluto de una matriz
!> compleja A.
!>

Devuelve

ZLANGE 
!>
!>    ZLANGE = ( max(abs(A(i,j))), NORM = 'M' o 'm'
!>             (
!>             ( norm1(A),         NORM = '1', 'O' o 'o'
!>             (
!>             ( normI(A),         NORM = 'I' o 'i'
!>             (
!>             ( normF(A),         NORM = 'F', 'f', 'E' o 'e'
!>
!> donde  norm1  denota la  norma uno de una matriz (suma máxima de columna),
!> normI  denota la  norma infinito  de una matriz  (suma máxima de fila) y
!> normF  denota la  norma de Frobenius  de una matriz (raíz cuadrada de la suma de
!> cuadrados).  Tenga en cuenta que  max(abs(A(i,j)))  no es una norma matricial consistente.
!>

Parámetros

NORM 
!>          NORM es CHARACTER*1
!>          Especifica el valor que se devolverá en ZLANGE como se describe
!>          arriba.
!>

M

!>          M es ENTERO
!>          El número de filas de la matriz A.  M >= 0.  Cuando M = 0,
!>          ZLANGE se establece en cero.
!>

N

!>          N es ENTERO
!>          El número de columnas de la matriz A.  N >= 0.  Cuando N = 0,
!>          ZLANGE se establece en cero.
!>

A

!>          A es un array COMPLEX*16, dimensión (LDA,N)
!>          La matriz A de m por n.
!>

LDA

!>          LDA es ENTERO
!>          La dimensión principal del array A.  LDA >= max(M,1).
!>

WORK

!>          WORK es un array DOUBLE PRECISION, dimensión (MAX(1,LWORK)),
!>          donde LWORK >= M cuando NORM = 'I'; de lo contrario, WORK no se
!>          referencia.
!>
