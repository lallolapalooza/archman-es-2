subroutine zlacn2 (integer n, complex*16, dimension( * ) v, complex*16, dimension( * ) x, double precision est, integer kase, integer, dimension( 3 ) isave)

ZLACN2 estima la norma 1 de una matriz compleja cuadrada, utilizando comunicación inversa para evaluar productos matriz-vector.

Propósito:

!>
!> ZLACN2 estima la norma 1 de una matriz compleja cuadrada A.
!> Se utiliza comunicación inversa para evaluar productos matriz-vector.
!>

Parámetros

N 
!>          N es ENTERO
!>         El orden de la matriz.  N >= 1.
!>

V

!>          V es un array de COMPLEX*16, de dimensión (N)
!>         En el retorno final, V = A*W,  donde  EST = norm(V)/norm(W)
!>         (W no se devuelve).
!>

X

!>          X es un array de COMPLEX*16, de dimensión (N)
!>         En un retorno intermedio, X debe ser sobrescrito por
!>               A * X,   si KASE=1,
!>               A**H * X,  si KASE=2,
!>         donde A**H es la transpuesta conjugada de A, y ZLACN2 debe ser
!>         llamada de nuevo con todos los demás parámetros sin cambios.
!>

EST

!>          EST es DOUBLE PRECISION
!>         En la entrada con KASE = 1 o 2 e ISAVE(1) = 3, EST debe ser
!>         sin cambios desde la llamada anterior a ZLACN2.
!>         En la salida, EST es una estimación (un límite inferior) para norm(A).
!>

KASE

!>          KASE es ENTERO
!>         En la llamada inicial a ZLACN2, KASE debe ser 0.
!>         En un retorno intermedio, KASE será 1 o 2, indicando
!>         si X debe ser sobrescrito por A * X  o A**H * X.
!>         En el retorno final de ZLACN2, KASE volverá a ser 0.
!>

ISAVE

!>          ISAVE es un array ENTERO, de dimensión (3)
!>         ISAVE se utiliza para guardar variables entre llamadas a ZLACN2
!>
