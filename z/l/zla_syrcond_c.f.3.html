función de precisión doble zla_syrcond_c (carácter uplo, entero n, complejo*16, dimensión( lda, * ) a, entero lda, complejo*16, dimensión( ldaf, * ) af, entero ldaf, entero, dimensión( * ) ipiv, precisión doble, dimensión( * ) c, lógico capply, entero info, complejo*16, dimensión( * ) work, precisión doble, dimensión( * ) rwork)

ZLA_SYRCOND_C calcula el número de condición de la norma infinito de op(A)*inv(diag(c)) para matrices indefinidas simétricas.

Propósito:

!>
!>    ZLA_SYRCOND_C Calcula el número de condición de la norma infinito
!>    de op(A) * inv(diag(C)) donde C es un vector de PRECISIÓN DOBLE.
!>

Parámetros

UPLO 
!>          UPLO es CARACTER*1
!>       = 'U':  El triángulo superior de A está almacenado;
!>       = 'L':  El triángulo inferior de A está almacenado.
!>

N

!>          N es ENTERO
!>     El número de ecuaciones lineales, es decir, el orden de la
!>     matriz A.  N >= 0.
!>

A

!>          A es una matriz COMPLEX*16, dimensión (LDA,N)
!>     En la entrada, la matriz A de N por N
!>

LDA

!>          LDA es ENTERO
!>     La dimensión principal de la matriz A.  LDA >= max(1,N).
!>

AF

!>          AF es una matriz COMPLEX*16, dimensión (LDAF,N)
!>     La matriz diagonal por bloques D y los multiplicadores utilizados para
!>     obtener el factor U o L tal como lo calcula ZSYTRF.
!>

LDAF

!>          LDAF es ENTERO
!>     La dimensión principal de la matriz AF.  LDAF >= max(1,N).
!>

IPIV

!>          IPIV es una matriz ENTERA, dimensión (N)
!>     Detalles de los intercambios y la estructura de bloques de D
!>     tal como son determinados por ZSYTRF.
!>

C

!>          C es una matriz de PRECISIÓN DOBLE, dimensión (N)
!>     El vector C en la fórmula op(A) * inv(diag(C)).
!>

CAPPLY

!>          CAPPLY es LÓGICO
!>     Si es .CIERTO. entonces accede al vector C en la fórmula anterior.
!>

INFO

!>          INFO es ENTERO
!>       = 0:  Salida exitosa.
!>     i > 0:  El i-ésimo argumento es inválido.
!>

WORK

!>          WORK es una matriz COMPLEX*16, dimensión (2*N).
!>     Espacio de trabajo.
!>

RWORK

!>          RWORK es una matriz de PRECISIÓN DOBLE, dimensión (N).
!>     Espacio de trabajo.
!>
