ZLA_SYRFSX_EXTENDED mejora la solución calculada para un sistema de ecuaciones lineales para matrices indefinidas simétricas realizando un refinamiento iterativo de precisión extra y proporciona límites de error y estimaciones de error hacia atrás para la solución.

Propósito:

!>
!> ZLA_SYRFSX_EXTENDED mejora la solución calculada para un sistema de
!> ecuaciones lineales realizando un refinamiento iterativo de precisión extra
!> y proporciona límites de error y estimaciones de error hacia atrás para la solución.
!> Esta subrutina es llamada por ZSYRFSX para realizar el refinamiento iterativo.
!> Además del límite de error normwise, el código proporciona el límite de error
!> máximo componente a componente si es posible. Ver los comentarios de
!> ERR_BNDS_NORM y ERR_BNDS_COMP para detalles de los límites de error.
!> Nótese que esta subrutina solo es responsable de establecer los segundos campos de
!> ERR_BNDS_NORM y ERR_BNDS_COMP.
!>

Parámetros

PREC_TYPE 
!>          PREC_TYPE es INTEGER
!>     Especifica la precisión intermedia a usar en el refinamiento.
!>     El valor se define por ILAPREC(P) donde P es un CHARACTER y P
!>          = 'S':  Simple
!>          = 'D':  Doble
!>          = 'I':  Indígena
!>          = 'X' o 'E':  Extra
!>

UPLO

!>          UPLO es CHARACTER*1
!>       = 'U':  El triángulo superior de A está almacenado;
!>       = 'L':  El triángulo inferior de A está almacenado.
!>

N

!>          N es INTEGER
!>     El número de ecuaciones lineales, es decir, el orden de la
!>     matriz A.  N >= 0.
!>

NRHS

!>          NRHS es INTEGER
!>     El número de lados derechos, es decir, el número de columnas de la
!>     matriz B.
!>

A

!>          A es un array COMPLEX*16, dimension (LDA,N)
!>     En la entrada, la matriz N por N A.
!>

LDA

!>          LDA es INTEGER
!>     La dimensión principal del array A.  LDA >= max(1,N).
!>

AF

!>          AF es un array COMPLEX*16, dimension (LDAF,N)
!>     La matriz diagonal por bloques D y los multiplicadores usados para
!>     obtener el factor U o L tal como lo calcula ZSYTRF.
!>

LDAF

!>          LDAF es INTEGER
!>     La dimensión principal del array AF.  LDAF >= max(1,N).
!>

IPIV

!>          IPIV es un array INTEGER, dimension (N)
!>     Detalles de los intercambios y la estructura de bloques de D
!>     tal como lo determina ZSYTRF.
!>

COLEQU

!>          COLEQU es LOGICAL
!>     Si .TRUE. entonces se realizó la  equilibración de columnas a A antes de llamar
!>     a esta subrutina. Esto es necesario para calcular la solución y los límites de error
!>     correctamente.
!>

C

!>          C es un array DOUBLE PRECISION, dimension (N)
!>     Los factores de escala de columna para A. Si COLEQU = .FALSE., C
!>     no se accede. Si se introduce C, cada elemento de C debe ser una potencia
!>     del radix para asegurar una solución y estimaciones de error fiables.
!>     La escala por potencias del radix no causa errores de redondeo a menos
!>     que el resultado cause subdesbordamiento o desbordamiento. Los errores de redondeo durante el escalado
!>     conducen a refinar con una matriz que no es equivalente a la
!>     matriz de entrada, produciendo estimaciones de error que pueden no ser
!>     fiables.
!>

B

!>          B es un array COMPLEX*16, dimension (LDB,NRHS)
!>     La matriz del lado derecho B.
!>

LDB

!>          LDB es INTEGER
!>     La dimensión principal del array B.  LDB >= max(1,N).
!>

Y

!>          Y es un array COMPLEX*16, dimension (LDY,NRHS)
!>     En la entrada, la matriz solución X, tal como la calcula ZSYTRS.
!>     En la salida, la matriz solución mejorada Y.
!>

LDY

!>          LDY es INTEGER
!>     La dimensión principal del array Y.  LDY >= max(1,N).
!>

BERR_OUT

!>          BERR_OUT es un array DOUBLE PRECISION, dimension (NRHS)
!>     En la salida, BERR_OUT(j) contiene el error relativo de retroceso componente a componente
!>     para el lado derecho j de la fórmula
!>         max(i) ( abs(RES(i)) / ( abs(op(A_s))*abs(Y) + abs(B_s) )(i) )
!>     donde abs(Z) es el valor absoluto componente a componente de la matriz
!>     o vector Z. Esto es calculado por ZLA_LIN_BERR.
!>

N_NORMS

!>          N_NORMS es INTEGER
!>     Determina qué límites de error devolver (ver ERR_BNDS_NORM
!>     y ERR_BNDS_COMP).
!>     Si N_NORMS >= 1 devuelve límites de error normwise.
!>     Si N_NORMS >= 2 devuelve límites de error componente a componente.
!>

ERR_BNDS_NORM

!>          ERR_BNDS_NORM es un array DOUBLE PRECISION, dimension (NRHS, N_ERR_BNDS)
!>     Para cada lado derecho, este array contiene información sobre
!>     varios límites de error y números de condición correspondientes al
!>     error relativo normwise, que se define de la siguiente manera:
!>
!>     Error relativo normwise en el i-ésimo vector solución:
!>             max_j (abs(XTRUE(j,i) - X(j,i)))
!>            ------------------------------
!>                  max_j abs(X(j,i))
!>
!>     El array está indexado por el tipo de información de error tal como se describe
!>     a continuación. Actualmente hay hasta tres piezas de información
!>     devueltas.
!>
!>     El primer índice en ERR_BNDS_NORM(i,:) corresponde al i-ésimo
!>     lado derecho.
!>
!>     El segundo índice en ERR_BNDS_NORM(:,err) contiene los siguientes
!>     tres campos:
!>     err = 1  booleano. Confía en la respuesta si el
!>              número de condición recíproco es menor que el umbral
!>              sqrt(n) * sl

NAME

ZLA_SYRFSX_EXTENDED

high accuracy reciprocal condition numbers for the solution to a symmetric system of linear equations

SYNOPSIS

 SUBROUTINE ZLA_SYRFSX_EXTENDED(
     UPLO, N, NRHS, A, LDA, AF, LDAF, IPIV, B, LDB, X, LDX,
     ERR_BNDS_NORM, ERR_BNDS_COMP, RES, AYB, DY, Y_TAIL, RCOND,
     ITHRESH, RTHRESH, DZ_UB, IGNORE_CWISE, INFO )
  CHARACTER * 1 UPLO
  INTEGER N, NRHS, LDA, LDAF, LDB, LDX, ITHRESH, INFO
  INTEGER, DIMENSION( N ) :: IPIV
  COMPLEX*16 A( LDA, * ), AF( LDAF, * ), B( LDB, * ), X( LDX, * ),
 & RES( N ), AYB( N ), DY( N ), Y_TAIL( N )
  DOUBLE PRECISION ERR_BNDS_NORM( NRHS, 3 ),
 & ERR_BNDS_COMP( NRHS, 3 ), RCOND, RTHRESH, DZ_UB
  LOGICAL IGNORE_CWISE

Function/Subroutine Documentation

ZLA_SYRFSX_EXTENDED computes high accuracy reciprocal condition numbers for the solution to a symmetric system of linear equations AX=B.

This subroutine is an extension of ZSPSVX and ZSPSVX. The routine also computes error bounds and estimates iterative refinement on the solution X to improve the accuracy of the computed solution.

Arguments:

UPLO
CHARACTER*1.

Specifies whether the symmetric matrix A is upper or lower triangular.

'U': Upper triangular

'L': Lower triangular.

N
INTEGER.

The order of the matrix A. N >= 0.

NRHS
INTEGER.

The number of right hand sides, i.e., the number of columns of the matrix B. NRHS >= 0.

A
COMPLEX*16 array, dimension (LDA,N).

The symmetric matrix A. Only the UPLO portion of A is needed.

LDA
INTEGER.

The leading dimension of the array A. LDA >= (1.

AF
COMPLEX*16 array, dimension (LDAF,N).

The factors of A from the factorization.

LDAF
INTEGER.

The leading dimension of the array AF. LDAF >= (1.

IPIV
INTEGER array, dimension (N).

The pivot indices from the factorization. IPIV[i] details the pivot for the ith column.

B
COMPLEX*16 array, dimension (LDB,NRHS).

The right hand side matrix of size N x NRHS.

LDB
INTEGER.

The leading dimension of the array B. LDB >= (1.

X
COMPLEX*16 array, dimension (LDX,NRHS).

On entry, the solution matrix X of size N x NRHS to the system of equations AX=B. On exit, the improved solution matrix X.

LDX
INTEGER.

The leading dimension of the array X. LDX >= (1.

ERR_BNDS_NORM
DOUBLE PRECISION array, dimension (NRHS,3).

For each right hand side, this array contains information about various error bounds and condition numbers corresponding to the normwise error, which is defined as follows:

Normwise relative error in the ith solution vector: norm(XTRUE - X) / norm(X)

The array is indexed by the right hand side i (on which the normwise error depends), and the type of error information as described below. There currently are up to three pieces of information returned for each right hand side. If N_ERR_BNDS < 3, then at most the first (:,N_ERR_BNDS) entries are returned.

The first index in ERR_BNDS_NORM(i,:) corresponds to the ith right-hand side.

The second index in ERR_BNDS_NORM(:,err) contains the following three fields:

err = 1 boolean. Trust the answer if the reciprocal condition number is less than the threshold sqrt(n) * slamch('Epsilon').

err = 2 error bound: The estimated forward error, almost certainly within a factor of 10 of the true error so long as the next entry is greater than the threshold sqrt(n) * slamch('Epsilon'). This error bound should only be trusted if the previous boolean is true.

err = 3 Reciprocal condition number: Estimated normwise reciprocal condition number. Compared with the threshold sqrt(n) * slamch('Epsilon') to determine if the error estimate is . These reciprocal condition numbers are 1 / (norm(Z^{-1},inf) * norm(Z,inf)) for some appropriately scaled matrix Z. Let Z = S*A, where S scales each row by a power of the radix so all absolute row sums of Z are approximately 1.

This subroutine is only responsible for setting the second field above.

See Lapack Working Note 165 for further details and extra cautions.

ERR_BNDS_COMP
DOUBLE PRECISION array, dimension (NRHS, 3).

For each right-hand side, this array contains information about various error bounds and condition numbers corresponding to the componentwise relative error, which is defined as follows:

Componentwise relative error in the ith solution vector: max_j abs(XTRUE(j,i) - X(j,i)) / abs(X(j,i))

The array is indexed by the right-hand side i (on which the componentwise relative error depends), and the type of error information as described below. There currently are up to three pieces of information returned for each right-hand side. If componentwise accuracy is not requested (PARAMS(3) = 0.0), then ERR_BNDS_COMP is not accessed. If N_ERR_BNDS < 3, then at most the first (:,N_ERR_BNDS) entries are returned.

The first index in ERR_BNDS_COMP(i,:) corresponds to the ith right-hand side.

The second index in ERR_BNDS_COMP(:,err) contains the following three fields:

err = 1 boolean. Trust the answer if the reciprocal condition number is less than the threshold sqrt(n) * slamch('Epsilon').

err = 2 error bound: The estimated forward error, almost certainly within a factor of 10 of the true error so long as the next entry is greater than the threshold sqrt(n) * slamch('Epsilon'). This error bound should only be trusted if the previous boolean is true.

err = 3 Reciprocal condition number: Estimated componentwise reciprocal condition number. Compared with the threshold sqrt(n) * slamch('Epsilon') to determine if the error estimate is . These reciprocal condition numbers are 1 / (norm(Z^{-1},inf) * norm(Z,inf)) for some appropriately scaled matrix Z. Let Z = S*(A*diag(x)), where x is the solution for the current right-hand side and S scales each row of A*diag(x) by a power of the radix so all absolute row sums of Z are approximately 1.

This subroutine is only responsible for setting the second field above.

See Lapack Working Note 165 for further details and extra cautions.

RES
COMPLEX*16 array, dimension (N).

Workspace to hold the intermediate residual.

AYB
DOUBLE PRECISION array, dimension (N).

Workspace.

DY
COMPLEX*16 array, dimension (N).

Workspace to hold the intermediate solution.

Y_TAIL
COMPLEX*16 array, dimension (N).

Workspace to hold the trailing bits of the intermediate solution.

RCOND
DOUBLE PRECISION.

Reciprocal scaled condition number. This is an estimate of the reciprocal Skeel condition number of the matrix A after equilibration (if done). If this is less than the machine precision (in particular, if it is zero), the matrix is singular to working precision. Note that the error may still be small even if this number is very small and the matrix appears ill- conditioned.

ITHRESH
INTEGER.

The maximum number of residual computations allowed for refinement. The default is 10. For 'aggressive' set to 100 to permit convergence using approximate factorizations or factorizations other than LU. If the factorization uses a technique other than Gaussian elimination, the guarantees in ERR_BNDS_NORM and ERR_BNDS_COMP may no longer be trustworthy.

RTHRESH
DOUBLE PRECISION.

Determines when to stop refinement if the error estimate stops decreasing. Refinement will stop when the next solution no longer satisfies norm(dx_{i+1}) < RTHRESH * norm(dx_i) where norm(Z) is the infinity norm of Z. RTHRESH satisfies 0 < RTHRESH <= 1. The default value is 0.5. For 'aggressive' set to 0.9 to permit convergence on extremely ill-conditioned matrices. See LAWN 165 for more details.

DZ_UB
DOUBLE PRECISION.

Determines when to start considering componentwise convergence. Componentwise convergence is only considered after each component of the solution Y is stable, which we define as the relative change in each component being less than DZ_UB. The default value is 0.25, requiring the first bit to be stable. See LAWN 165 for more details.

IGNORE_CWISE
LOGICAL.

If .TRUE. then ignore componentwise convergence. Default value is .FALSE..

INFO
INTEGER.

= 0: Successful exit.

< 0: if INFO = -i, the ith argument to ZLA_HERFSX_EXTENDED had an illegal value
