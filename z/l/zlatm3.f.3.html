complex*16 function zlatm3 (integer m, integer n, integer i, integer j, integer isub, integer jsub, integer kl, integer ku, integer idist, integer, dimension( 4 ) iseed, complex*16, dimension( * ) d, integer igrade, complex*16, dimension( * ) dl, complex*16, dimension( * ) dr, integer ipvtng, integer, dimension( * ) iwork, double precision sparse)

ZLATM3

Propósito:

!>
!>    ZLATM3 devuelve la entrada (ISUB,JSUB) de una matriz aleatoria de
!>    dimensión (M, N) descrita por los otros parámetros. (ISUB,JSUB)
!>    es la posición final de la entrada (I,J) después de la pivota-
!>    ción según IPVTNG e IWORK. ZLATM3 es llamada por la rutina
!>    ZLATMR para construir matrices de prueba aleatorias. No se realiza
!>    ninguna comprobación de errores en los parámetros, ya que esta
!>    rutina es llamada en un bucle ajustado por ZLATMR, que ya ha
!>    comprobado los parámetros.
!>
!>    El uso de ZLATM3 difiere de CLATM2 en el orden en que se llama
!>    al generador de números aleatorios para rellenar las entradas de
!>    la matriz aleatoria. Con ZLATM2, el generador se llama para rellenar
!>    la matriz pivoteada por columnas. Con ZLATM3, el generador se llama
!>    para rellenar la matriz por columnas, después de lo cual se pivota.
!>    Por lo tanto, ZLATM3 se puede usar para construir matrices aleatorias
!>    que difieren solo en el orden de sus filas y/o columnas. ZLATM2 se
!>    usa para construir matrices de banda, evitando llamar al generador
!>    de números aleatorios para entradas fuera de la banda (y por lo tanto
!>    generando números aleatorios en órdenes diferentes para diferentes
!>    órdenes de pivote).
!>
!>    La matriz cuya entrada (ISUB,JSUB) se devuelve se construye como
!>    sigue (esta rutina solo calcula una entrada):
!>
!>      Si ISUB está fuera de (1..M) o JSUB está fuera de (1..N), devuelve cero
!>         (esto es conveniente para generar matrices en formato de banda).
!>
!>      Genera una matriz A con entradas aleatorias de distribución IDIST.
!>
!>      Establece la diagonal a D.
!>
!>      Califica la matriz, si se desea, desde la izquierda (por DL) y/o
!>         desde la derecha (por DR o DL) según lo especificado por IGRADE.
!>
!>      Permuta, si se desea, las filas y/o columnas según lo especificado por
!>         IPVTNG y IWORK.
!>
!>      Banda la matriz para tener un ancho de banda inferior KL y un ancho
!>         de banda superior KU.
!>
!>      Establece entradas aleatorias a cero según lo especificado por SPARSE.
!>

Parámetros

M 
!>          M es INTEGER
!>           Número de filas de la matriz. No modificado.
!>

N

!>          N es INTEGER
!>           Número de columnas de la matriz. No modificado.
!>

I

!>          I es INTEGER
!>           Fila de la entrada sin pivotar a devolver. No modificado.
!>

J

!>          J es INTEGER
!>           Columna de la entrada sin pivotar a devolver. No modificado.
!>

ISUB

!>          ISUB es INTEGER
!>           Fila de la entrada pivoteada a devolver. Cambiado al salir.
!>

JSUB

!>          JSUB es INTEGER
!>           Columna de la entrada pivoteada a devolver. Cambiado al salir.
!>

KL

!>          KL es INTEGER
!>           Ancho de banda inferior. No modificado.
!>

KU

!>          KU es INTEGER
!>           Ancho de banda superior. No modificado.
!>

IDIST

!>          IDIST es INTEGER
!>           En la entrada, IDIST especifica el tipo de distribución a utilizar
!>           para generar una matriz aleatoria.
!>           1 => partes real e imaginaria cada una UNIFORM( 0, 1 )
!>           2 => partes real e imaginaria cada una UNIFORM( -1, 1 )
!>           3 => partes real e imaginaria cada una NORMAL( 0, 1 )
!>           4 => número complejo uniforme en DISK( 0 , 1 )
!>           No modificado.
!>

ISEED

!>          ISEED es array INTEGER de dimensión ( 4 )
!>           Semilla para el generador de números aleatorios.
!>           Cambiado al salir.
!>

D

!>          D es array COMPLEX*16 de dimensión ( MIN( I , J ) )
!>           Entradas diagonales de la matriz. No modificado.
!>

IGRADE

!>          IGRADE es INTEGER
!>           Especifica la calificación de la matriz como sigue:
!>           0  => sin calificación
!>           1  => matriz premultiplicada por diag( DL )
!>           2  => matriz postmultiplicada por diag( DR )
!>           3  => matriz premultiplicada por diag( DL ) y
!>                         postmultiplicada por diag( DR )
!>           4  => matriz premultiplicada por diag( DL ) y
!>                         postmultiplicada por inv( diag( DL ) )
!>           5  => matriz premultiplicada por diag( DL ) y
!>                         postmultiplicada por diag( CONJG(DL) )
!>           6  => matriz premultiplicada por diag( DL ) y
!>                         postmultiplicada por diag( DL )
!>           No modificado.
!>

DL

!>          DL es array COMPLEX*16 ( I o J, según corresponda )
!>           Factores de escala izquierda para calificar la matriz. No
!>           modificado.
!>

DR

!>          DR es array COMPLEX*16 ( I o J, según corresponda )
!>           Factores de escala derecha para calificar la matriz. No
!>           modificado.
!>

IPVTNG

!>          IPVTNG es INTEGER
!>           En la entrada, especifica las permutaciones de pivote como sigue:
!>           0 => ninguna.
!>           1 => pivota-ción de fila.
!>           2 => pivota-ción de columna.
!>           3 => pivota-ción completa, es decir, en ambos lados.
!>           No modificado.
!>

IWORK

!>          IWORK es array INTEGER ( I o J, según corresponda )
!>           Este array especifica la permutación utilizada. La
!>           fila (o columna) originalmente en la posición K está en
!>           la posición IWORK( K ) después de la pivota-ción.
!>           Esto difiere de IWORK para ZLATM2. No modificado.
!>

SPARSE

!>          SPARSE es DOUBLE PRECISION entre 0. y 1.
!>           En la entrada, especifica la escasez de la matriz
!>           si se va a generar una matriz dispersa.
!>           SPARSE debe estar entre 0 y 1.
!>           Se genera un número aleatorio uniforme ( 0, 1 ) x y se
!>           compara con SPARSE; si x es mayor, la entrada de la matriz
!>           no cambia y si x es menor, la entrada se establece a
!>           cero. Por lo tanto, en promedio, una fracción SPARSE de las
!>           entradas se establecerá a cero.
!>           No modificado.
!>

zlatm3(3)

NOMBRE

zlatm3 - Esta subrutina genera una matriz aleatoria de condición M.

SINOPSIS

SUBROUTINE ZLATM3(
   N, M, NB, NRMB, LDA, A, LWORK, WORK, INFO
)
      INTEGER            N, M, NB, NRMB, LDA, LWORK, INFO
      COMPLEX*16         A( LDA, * ), WORK( * )

Documentación de funciones/subrutinas

Esta subrutina genera una matriz aleatoria de condición M.

Parámetros

N
(input) INTEGER     El orden de la matriz a generar.
M
(input) INTEGER     El número de filas de la matriz a generar.
NB
(input) INTEGER     El número de columnas de la matriz a generar.
NRMB
(input) INTEGER     El número de bloques de columnas a generar.
LDA
(input) INTEGER     El primer dimensión de A.
A
(output) COMPLEX*16 array, dimension (LDA, M) si NRMB = 1, y (LDA, NB*NRMB) si NRMB > 1.     La matriz generada.
LWORK
(input) INTEGER     Longitud del array WORK.
WORK
(workspace) COMPLEX*16 array, dimension (LWORK).     Area de trabajo.
INFO
(output) INTEGER     = 0: procedimiento correcto.     < 0: si el i-ésimo argumento no es correcto.     > 0: el algoritmo de factorización no convergió.
