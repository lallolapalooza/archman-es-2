ZLIB-FLATE(1) Comandos de usuario ZLIB-FLATE(1)

NOMBRE

zlib-flate - programa de compresión zlib cruda

SINOPSIS

zlib-flate -compress | -uncompress

DESCRIPCIÓN

El programa zlib-flate forma parte del paquete qpdf.

El programa zlib-flate lee de la entrada estándar y escribe en la salida estándar, comprimiendo o descomprimiendo su entrada mediante compresión zlib cruda. Puede ser utilizado para descomprimir o comprimir flujos de PDF crudos u otros datos que estén comprimidos con compresión zlib cruda. Este programa se proporciona principalmente como una herramienta de depuración, aunque podría usarse para otros propósitos, como ser llamado desde un script que crea archivos PDF simples.

No se debe usar este programa como una herramienta de compresión de propósito general. Usa algo como gzip(1) en su lugar.

Para más detalles sobre qpdf, consulta el manual de qpdf, que se puede encontrar en https://qpdf.readthedocs.io.

VER TAMBIÉN

qpdf(1), gzip(1)
