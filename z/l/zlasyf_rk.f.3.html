ZLASYF_RK calcula una factorización parcial de una matriz simétrica indefinida compleja utilizando el método de pivoteo diagonal acotado de Bunch-Kaufman (rook).

Documentación de Función/Subrutina

subrutina zlasyf_rk (carácter uplo, entero n, entero nb, entero kb, complejo*16, dimensión( lda, * ) a, entero lda, complejo*16, dimensión( * ) e, entero, dimensión( * ) ipiv, complejo*16, dimensión( ldw, * ) w, entero ldw, entero info)

ZLASYF_RK calcula una factorización parcial de una matriz simétrica indefinida compleja utilizando el método de pivoteo diagonal acotado de Bunch-Kaufman (rook).

Propósito:

!> ZLASYF_RK calcula una factorización parcial de una matriz simétrica
!> compleja A utilizando el método de pivoteo diagonal acotado de
!> Bunch-Kaufman (rook). La factorización parcial tiene la forma:
!>
!> A  =  ( I  U12 ) ( A11  0  ) (  I       0    )  si UPLO = 'U', o:
!>       ( 0  U22 ) (  0   D  ) ( U12**T U22**T )
!>
!> A  =  ( L11  0 ) (  D   0  ) ( L11**T L21**T )  si UPLO = 'L',
!>       ( L21  I ) (  0  A22 ) (  0       I    )
!>
!> donde el orden de D es como máximo NB. El orden real se devuelve en
!> el argumento KB, y es NB o NB-1, o N si N <= NB.
!>
!> ZLASYF_RK es una subrutina auxiliar llamada por ZSYTRF_RK. Utiliza
!> código en bloque (llamando a BLAS de Nivel 3) para actualizar la
!> submatriz A11 (si UPLO = 'U') o A22 (si UPLO = 'L').
!>

Parámetros

UPLO 
!>          UPLO es CHARACTER*1
!>          Especifica si la parte triangular superior o inferior de la
!>          matriz simétrica A está almacenada:
!>          = 'U': Triangular superior
!>          = 'L': Triangular inferior
!>

N

!>          N es INTEGER
!>          El orden de la matriz A. N >= 0.
!>

NB

!>          NB es INTEGER
!>          El número máximo de columnas de la matriz A que deben ser
!>          factorizadas. NB debe ser al menos 2 para permitir bloques
!>          de pivote de 2x2.
!>

KB

!>          KB es INTEGER
!>          El número de columnas de A que fueron realmente factorizadas.
!>          KB es NB-1 o NB, o N si N <= NB.
!>

A

!>          A es arreglo COMPLEX*16, dimensión (LDA,N)
!>          En la entrada, la matriz simétrica A.
!>            Si UPLO = 'U': la parte superior triangular N x N líder
!>            de A contiene la parte triangular superior de la matriz A,
!>            y la parte estrictamente triangular inferior de A no se
!>            referencia.
!>
!>            Si UPLO = 'L': la parte inferior triangular N x N líder
!>            de A contiene la parte triangular inferior de la matriz A,
!>            y la parte estrictamente triangular superior de A no se
!>            referencia.
!>
!>          En la salida, contiene:
!>            a) SÓLO los elementos diagonales de la matriz bloque diagonal
!>               simétrica D en la diagonal de A, es decir, D(k,k) = A(k,k);
!>               (los elementos superdiagonales (o subdiagonales) de D
!>                se almacenan en la salida en el arreglo E), y
!>            b) Si UPLO = 'U': factor U en la parte superdiagonal de A.
!>               Si UPLO = 'L': factor L en la parte subdiagonal de A.
!>

LDA

!>          LDA es INTEGER
!>          La dimensión líder del arreglo A. LDA >= max(1,N).
!>

E

!>          E es arreglo COMPLEX*16, dimensión (N)
!>          En la salida, contiene los elementos superdiagonales (o subdiagonales)
!>          de la matriz bloque diagonal simétrica D
!>          con bloques diagonales de 1x1 o 2x2, donde
!>          Si UPLO = 'U': E(i) = D(i-1,i), i=2:N, E(1) se establece en 0;
!>          Si UPLO = 'L': E(i) = D(i+1,i), i=1:N-1, E(N) se establece en 0.
!>
!>          NOTA: Para un bloque diagonal de 1x1 D(k), donde
!>          1 <= k <= N, el elemento E(k) se establece en 0 en ambos
!>          casos UPLO = 'U' o UPLO = 'L'.
!>

IPIV

!>          IPIV es arreglo INTEGER, dimensión (N)
!>          IPIV describe la matriz de permutación P en la factorización
!>          de la matriz A de la siguiente manera. El valor absoluto de IPIV(k)
!>          representa el índice de fila y columna que fueron
!>          intercambiados con la k-ésima fila y columna. El valor de UPLO
!>          describe el orden en que se aplicaron los intercambios.
!>          Además, el signo de IPIV representa la estructura de bloque
!>          de la matriz bloque diagonal simétrica D con bloques diagonales
!>          de 1x1 o 2x2 que corresponden a 1 o 2 intercambios
!>          en cada paso de factorización.
!>
!>          Si UPLO = 'U',
!>          ( en orden de factorización, k disminuye de N a 1 ):
!>            a) Una entrada positiva única IPIV(k) > 0 significa:
!>               D(k,k) es un bloque diagonal de 1x1.
!>               Si IPIV(k) != k, las filas y columnas k e IPIV(k) fueron
!>               intercambiadas en la submatriz A(1:N,N-KB+1:N);
!>               Si IPIV(k) = k, no ocurrió ningún intercambio.
!>
!>
!>            b) Un par de entradas consecutivas negativas
!>               IPIV(k) < 0 e IPIV(k-1) < 0 significa:
!>               D(k-1:k,k-1:k) es un bloque diagonal de 2x2.
!>               (NOTA: las entradas negativas en IPIV aparecen SÓLO en pares).
!>               1) Si -IPIV(k) != k, las filas y columnas
!>                  k y -IPIV(k) fueron intercambiadas
!>                  en la matriz A(1:N,N-KB+1:N).
!>                  Si -IPIV(k) = k, no ocurrió ningún intercambio.
!>               2) Si -IPIV(k-1) != k-1, las filas y columnas
!>                  k-1 y -IPIV(k-1) fueron intercambiadas
!>                  en la submatriz A(1:N,N-KB+1:N).
!>                  Si -IPIV(k-1) = k-1, no ocurrió ningún intercambio.
!>
!>            c) En ambos casos a) y b) siempre es ABS( IPIV(k) ) <= k.
!>
!>            d) NOTA: Cualquier entrada IPIV(k) es siempre DISTINTA DE CERO en la salida.
!>
!>          Si UPLO = 'L',
!>          ( en orden de factorización, k aumenta de 1 a N ):
!>            a) Una entrada positiva única IPIV(k) > 0 significa:
!>               D(k,k) es un bloque diagonal de 1x1.
!>               Si IPIV(k) != k, las filas y columnas k e IPIV(k) fueron
!>               intercambiadas en la submatriz A(1:N,1:KB).
!>               Si IPIV(k) = k, no ocurrió ningún intercambio.
!>
!>            b) Un par de entradas consecutivas negativas
!>               IPIV(k) < 0 e IPIV(k+1) < 0 significa:
!>               D(k:k+1,k:k+1) es un bloque diagonal de 2x2.
!>               (NOTA: las entradas negativas en IPIV aparecen SÓLO en pares).
!>               1) Si -IPIV(k) != k, las filas y columnas
!>                  k y -IPIV(k) fueron intercambiadas
!>                  en la submatriz A(1:N,1:KB).
!>                  Si -IPIV(k) = k, no ocurrió ningún intercambio.
!>               2) Si -IPIV(k+1) != k+1, las filas y columnas
!>                  k-1 y -IPIV(k-1) fueron intercambiadas
!>                  en la submatriz A(1:N,1:KB).
!>                  Si -IPIV(k+1) = k+1, no ocurrió ningún intercambio.
!>
!>            c) En ambos casos a) y b) siempre es ABS( IPIV(k) ) >= k.
!>
!>            d) NOTA: Cualquier entrada IPIV(k) es siempre DISTINTA DE CERO en la salida.
!>

W

!>          W es arreglo COMPLEX*16, dimensión (LDW,NB)
!>

LDW

!>          LDW es INTEGER
!>          La dimensión líder del arreglo W. LDW >= max(1,N).
!>

INFO

!>          INFO es INTEGER
!>          = 0: salida exitosa
!>
!>          < 0: Si INFO = -k, el k-ésimo argumento tenía un valor ilegal
!>
!>          > 0: Si INFO = k, la matriz A es singular, porque:
!>                 Si UPLO = 'U': la columna k en la parte
!>                 triangular superior de A contiene todos ceros.

!>

NAME

zlasyf_rk — Blocked version of the recursive panel-factorization for partial Cholesky factorization of a symmetric indefinite matrix, of the form

ZLASYF_RK is used to approximate the factorization of a symmetric indefinite matrix. It is used in routines that compute the factorization of a symmetric indefinite matrix. For information about the matrix type, see the zasyf(3) man page.

SYNOPSIS

    SUBROUTINE ZLASYF_RK(UPLO, N, NB, KASE, KB, A, LDA, IPVT, WORK, LWORK, INFO)
                    
                        CHARACTER * 1           UPLO
                        INTEGER                 N
                        INTEGER                 NB
                        INTEGER                 KASE
                        INTEGER                 KB
                        COMPLEX*16              A( LDA, * )
                        INTEGER                 LDA
                        INTEGER                 IPVT( * )
                        COMPLEX*16              WORK( * )
                        INTEGER                 LWORK
                        INTEGER                 INFO

Function/Subroutine Documentation

Purpose:

ZLASYF_RK is a blocked version of the recursive panel-factorization for partial Cholesky factorization of a symmetric indefinite matrix, of the form

                                     [ U ] [ U_k ]
                                A =  [ K ] [ K_k ]

where U is upper triangular and K is lower triangular. The factorization is performed by the following algorithm:

                                Algorithm ZLASYF_RK(A, J)
                                1. If panel size <= NB, call ZLASYF.
                                2. Compute
                                   A[J, J+NB] = A[J, J+NB] * inv(U[J,J])
                                   A[J+NB, J] = A[J+NB, J] * inv(L[J,J])
                                3. Update
                                   A[J+NB, J+NB] = A[J+NB, J+NB] - A[J, J+NB]^T * A[J, J+NB]
                                   (if UPLO = 'U')
                                   A[J+NB, J+NB] = A[J+NB, J+NB] - A[J+NB, J] * A[J+NB, J]^T
                                   (if UPLO = 'L')
                                4. Recursively call ZLASYF_RK(A[J+NB, J+NB], J+NB)

When KASE = 0, the factorization is computed.

When KASE = 1, the factorization is updated.

When KASE = 2, the factorization is applied.

When KASE = 3, the factorization is inverted.

Arguments:

UPLO
CHARACTER*1.
'U': Upper triangular factor is stored.
'L': Lower triangular factor is stored.
N
INTEGER.
The order of the matrix A.
N >= 0.
NB
INTEGER.
The block size to be used in the recursive panel factorization.
NB >= 1.
KASE
INTEGER.
Specifies the cases of the algorithm:
= 0: Compute the factorization
= 1: Update the factorization
= 2: Apply the factorization
= 3: Invert the factorization
KB
INTEGER.
'L' or 'U'. On entry, specifies the sign of the diagonal
blocks.
'L': A is a lower triangular matrix.
'U': A is an upper triangular matrix.
'U' and 'L' are equivalent to the specification UPLO = 'U' and
UPLO = 'L' respectively.
A
COMPLEX*16 array, dimension (LDA, N).
On entry, the symmetric/Hermitian matrix A.
On exit, A is overwritten by details of the factorization.
LDA
INTEGER.
The leading dimension of the array A. LDA >= max(1,N).
IPVT
INTEGER array, dimension (N).
On exit, contains information about the row and column
permutations that stabilise the factorization. For
further information, see beta.
WORK
COMPLEX*16 array, dimension (LWORK).
On exit, WORK(1) contains the minimum value of LWORK.
LWORK
INTEGER.
The dimension of the array WORK. LWORK >= max(1,N).
For optimum performance LWORK >= N*NB.
INFO
INTEGER.
= 0: successful exit
> 0: if INFO = i, then the pivot element at the i-th
row/column is zero. The factorization has been
completed, but the block diagonal matrix D is
exactly singular and division by zero will occur if
it is used to solve a system of equations.
NOTE: INFO only stores the first occurrence of
a singularity, any subsequent occurrence of singularity
is not stored in INFO even though the factorization
always completes.
