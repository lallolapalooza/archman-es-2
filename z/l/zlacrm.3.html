Documentación de función/subrutina

subrutina zlacrm (integer m, integer n, complex*16, dimension( lda, * ) a, integer lda, double precision, dimension( ldb, * ) b, integer ldb, complex*16, dimension( ldc, * ) c, integer ldc, double precision, dimension( * ) rwork)

ZLACRM multiplica una matriz compleja por una matriz real cuadrada.

Propósito:

!>
!> ZLACRM realiza una multiplicación de matrices muy simple:
!>          C := A * B,
!> donde A es M por N y compleja; B es N por N y real;
!> C es M por N y compleja.
!>

Parámetros

M 
!>          M es ENTERO
!>          El número de filas de la matriz A y de la matriz C.
!>          M >= 0.
!>

N

!>          N es ENTERO
!>          El número de columnas y filas de la matriz B y
!>          el número de columnas de la matriz C.
!>          N >= 0.
!>

A

!>          A es un array COMPLEX*16, de dimensión (LDA, N)
!>          En la entrada, A contiene la matriz A de M por N.
!>

LDA

!>          LDA es ENTERO
!>          La dimensión principal del array A. LDA >=max(1,M).
!>

B

!>          B es un array DOUBLE PRECISION, de dimensión (LDB, N)
!>          En la entrada, B contiene la matriz B de N por N.
!>

LDB

!>          LDB es ENTERO
!>          La dimensión principal del array B. LDB >=max(1,N).
!>

C

!>          C es un array COMPLEX*16, de dimensión (LDC, N)
!>          En la salida, C contiene la matriz C de M por N.
!>

LDC

!>          LDC es ENTERO
!>          La dimensión principal del array C. LDC >=max(1,N).
!>

RWORK

!>          RWORK es un array DOUBLE PRECISION, de dimensión (2*M*N)
!>
