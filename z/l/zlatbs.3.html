ZLATBS resuelve un sistema de ecuaciones triangular bandeado.

DOCUMENTACIÓN DE FUNCIÓN/SUBRUTINA

subroutine zlatbs (character uplo, character trans, character diag, character normin, integer n, integer kd, complex*16, dimension( ldab, * ) ab, integer ldab, complex*16, dimension( * ) x, double precision scale, double precision, dimension( * ) cnorm, integer info)

ZLATBS resuelve un sistema de ecuaciones triangular bandeado.

Propósito:

!>
!> ZLATBS resuelve uno de los sistemas triangulares
!>
!>    A * x = s*b,  A**T * x = s*b,  o  A**H * x = s*b,
!>
!> con escalado para prevenir desbordamientos, donde A es una matriz banda
!> triangular superior o inferior. Aquí A**T denota la transpuesta de A, x y b
!> son vectores de n elementos, y s es un factor de escalado, usualmente menor o
!> igual a 1, elegido de forma que los componentes de x sean menores que
!> el umbral de desbordamiento. Si el problema no escalado no causa
!> desbordamiento, se llama a la rutina ZTBSV de BLAS de nivel 2. Si la matriz A
!> es singular (A(j,j) = 0 para algún j), entonces s se establece en 0 y se
!> devuelve una solución no trivial a A*x = 0.
!>

Parámetros

UPLO 
!>          UPLO es CHARACTER*1
!>          Especifica si la matriz A es triangular superior o inferior.
!>          = 'U':  Triangular superior
!>          = 'L':  Triangular inferior
!>

TRANS

!>          TRANS es CHARACTER*1
!>          Especifica la operación aplicada a A.
!>          = 'N':  Resuelve A * x = s*b     (Sin transponer)
!>          = 'T':  Resuelve A**T * x = s*b  (Transpuesta)
!>          = 'C':  Resuelve A**H * x = s*b  (Transpuesta conjugada)
!>

DIAG

!>          DIAG es CHARACTER*1
!>          Especifica si la matriz A es unitaria triangular o no.
!>          = 'N':  Triangular no unitaria
!>          = 'U':  Triangular unitaria
!>

NORMIN

!>          NORMIN es CHARACTER*1
!>          Especifica si CNORM se ha establecido o no.
!>          = 'Y':  CNORM contiene las normas de las columnas en la entrada
!>          = 'N':  CNORM no se establece en la entrada. En la salida, las normas se
!>                  calcularán y almacenarán en CNORM.
!>

N

!>          N es INTEGER
!>          El orden de la matriz A.  N >= 0.
!>

KD

!>          KD es INTEGER
!>          El número de subdiagonales o superdiagonales en la
!>          matriz triangular A.  KD >= 0.
!>

AB

!>          AB es un array COMPLEX*16, de dimensión (LDAB,N)
!>          La matriz banda triangular superior o inferior A, almacenada en las
!>          primeras KD+1 filas del array. La j-ésima columna de A se almacena
!>          en la j-ésima columna del array AB de la siguiente manera:
!>          si UPLO = 'U', AB(kd+1+i-j,j) = A(i,j) para max(1,j-kd)<=i<=j;
!>          si UPLO = 'L', AB(1+i-j,j)    = A(i,j) para j<=i<=min(n,j+kd).
!>

LDAB

!>          LDAB es INTEGER
!>          La dimensión principal del array AB.  LDAB >= KD+1.
!>

X

!>          X es un array COMPLEX*16, de dimensión (N)
!>          En la entrada, el lado derecho b del sistema triangular.
!>          En la salida, X se sobrescribe con el vector solución x.
!>

SCALE

!>          SCALE es DOUBLE PRECISION
!>          El factor de escalado s para el sistema triangular
!>             A * x = s*b,  A**T * x = s*b,  o  A**H * x = s*b.
!>          Si SCALE = 0, la matriz A es singular o está mal escalada, y
!>          el vector x es una solución exacta o aproximada a A*x = 0.
!>

CNORM

!>          CNORM es un array DOUBLE PRECISION, de dimensión (N)
!>
!>          Si NORMIN = 'Y', CNORM es un argumento de entrada y CNORM(j)
!>          contiene la norma de la parte fuera de la diagonal de la j-ésima columna
!>          de A.  Si TRANS = 'N', CNORM(j) debe ser mayor o igual a
!>          la norma infinito, y si TRANS = 'T' o 'C', CNORM(j)
!>          debe ser mayor o igual a la norma 1.
!>
!>          Si NORMIN = 'N', CNORM es un argumento de salida y CNORM(j)
!>          devuelve la norma 1 de la parte fuera de la diagonal de la j-ésima columna
!>          de A.
!>

INFO

!>          INFO es INTEGER
!>          = 0:  salida exitosa
!>          < 0:  si INFO = -k, el k-ésimo argumento tuvo un valor ilegal
!>

Detalles adicionales:

!>
!>  Se calcula una cota aproximada de x; si esta es menor que el desbordamiento,
!>  se llama a ZTBSV, de lo contrario, se utiliza código específico que comprueba
!>  posibles desbordamientos o divisiones por cero en cada operación.
!>
!>  Se utiliza un esquema columna por columna para resolver A*x = b. El algoritmo básico
!>  si A es triangular inferior es
!>
!>       x[1:n] := b[1:n]
!>       para j = 1, ..., n
!>            x(j) := x(j) / A(j,j)
!>            x[j+1:n] := x[j+1:n] - x(j) * A[j+1:n,j]
!>       fin
!>
!>  Definimos cotas de los componentes de x después de j iteraciones del bucle:
!>     M(j) = cota de x[1:j]
!>     G(j) = cota de x[j+1:n]
!>  Inicialmente, sea M(0) = 0 y G(0) = max{x(i), i=1,...,n}.
!>
!>  Entonces, para la iteración j+1 tenemos
!>     M(j+1) <= G(j) / | A(j+1,j+1) |
!>     G(j+1) <= G(j) + M(j+1) * | A[j+2:n,j+1] |
!>            <= G(j) ( 1 + CNORM(j+1) / | A(j+1,j+1) | )
!>
!>  donde CNORM(j+1) es mayor o igual que la norma infinito
!>  de la columna j+1 de A, sin contar la diagonal. Por lo tanto
!>
!>     G(j) <= G(0) producto ( 1 + CNORM(i) / | A(i,i) | )
!>                  1<=i<=j
!>  y
!>
!>     |x(j)| <= ( G(0) / |A(j,j)| ) producto ( 1 + CNORM(i) / |A(i,i)| )
!>                                   1<=i< j
!>
!>  Como |x(j)| <= M(j), usamos la rutina ZTBSV de BLAS de nivel 2 si el
!>  recíproco de la mayor M(j), j=1,..,n, es mayor que
!>  max(desbordamiento bajo, 1/desbordamiento).
!>
!>  La cota de x(j) también se usa para determinar cuándo un paso en
!>  el método columna por columna puede realizarse sin temor a desbordamiento. Si
!>  la cota calculada es mayor que una constante grande, x se escala para
!>  prevenir el desbordamiento, pero si la cota se desborda, x se establece en 0,
!>  x(j) en 1 y scale en 0, y se encuentra una solución no trivial a A*x = 0.
!>
!>  De forma similar, se utiliza un esquema fila por fila para resolver A**T *x = b  o
!>  A**H *x = b. El algoritmo básico para A triangular superior es
!>
!>       para j = 1, ..., n
!>            x(j) := ( b(j) - A[1:j-1,j]' * x[1:j-1] ) / A(j,j)
!>       fin
!>
!>  Simultáneamente calculamos dos cotas:
!>       G(j) = cota de ( b(i) - A[1:i-1,i]' * x[1:i-1] ), 1<=i<=j
!>       M(j) = cota de x(i), 1<=i<=j
!>
!>  Los valores iniciales son G(0) = 0, M(0) = max{b(i), i=1,..,n}, y añadimos
!>  la restricción G(j) >= G(j-1) y M(j) >= M(j-1) para j >= 1.
!>  Entonces la cota de x(j) es
!>
!>       M(j) <= M(j-1) * ( 1 + CNORM(j) ) / | A(j,j) |
!>
!>            <= M(0) * producto ( ( 1 + CNORM(i) ) / |A(i,i)| )
!>                      1<=i<=j
!>
!>  y podemos llamar de forma segura a ZTBSV si 1/M(n) y 1/G(n) son ambos mayores
!>  que max(desbordamiento bajo, 1/desbordamiento).
!>

NAME

zlatbs - Resuelve un sistema de ecuaciones lineales con una matriz triangular y un subespacio de vectores de RHS.

SINOPSIS

SUBROUTINE ZLATBS(
     UPLO, TRANS, DIAG, NOROWS, N, NRHS, AB, LDAB, B, LDB, INFO
)
OBJECT ( KIND = 8 ) :: ZLATBS
  
CHARACTER(LEN=1) :: UPLO, TRANS, DIAG
LOGICAL :: NOROWS
INTEGER :: N, NRHS, LDAB, LDB, INFO
COMPLEX(KIND=8), DIMENSION( * ) :: AB
COMPLEX(KIND=8), DIMENSION( * ) :: B

Documentación de Funciones/Subrutinas

ZLATBS resuelve uno de los siguientes sistemas de ecuaciones lineales para X:

A*X = B

o

A**T*X = B,

o

A**H*X = B,

donde A es una matriz triangular real de orden N con la triangulación especificada por UPLO y DIAG. Los vectores de la derecha RHS se dan en la matriz B y los resultados se devuelven en la misma matriz, con los vectores de las columnas de RHS reemplazados por las soluciones correspondientes de las columnas de X. Se supone que la matriz A está en almacenamiento de bloque por filas o por columnas.
