función de precisión doble zlantr (norma, uplo, diag, m, n, a, lda, work)
ZLANTR devuelve el valor de la norma 1, o la norma de Frobenius, o la norma infinito, o el elemento de mayor valor absoluto de una matriz trapezoidal o triangular.

Documentación de Función/Subrutina

doble precisión función zlantr (carácter norma, carácter uplo, carácter diag, entero m, entero n, complejo*16, dimensión( lda, * ) a, entero lda, doble precision, dimensión( * ) work)

ZLANTR devuelve el valor de la norma 1, o la norma de Frobenius, o la norma infinito, o el elemento de mayor valor absoluto de una matriz trapezoidal o triangular.

Propósito:

!>
!> ZLANTR  devuelve el valor de la norma uno,  o la norma de Frobenius, o
!> la norma infinito,  o el  elemento de  mayor valor absoluto  de una
!> matriz trapezoidal o triangular A.
!>

Devuelve

ZLANTR 
!>
!>    ZLANTR = ( max(abs(A(i,j))), NORMA = 'M' o 'm'
!>             (
!>             ( norm1(A),         NORMA = '1', 'O' o 'o'
!>             (
!>             ( normI(A),         NORMA = 'I' o 'i'
!>             (
!>             ( normF(A),         NORMA = 'F', 'f', 'E' o 'e'
!>
!> donde  norm1  denota la  norma uno de una matriz (suma máxima de columna),
!> normI  denota la  norma infinito  de una matriz  (suma máxima de fila) y
!> normF  denota la  norma de Frobenius de una matriz (raíz cuadrada de la suma de
!> cuadrados).  Tenga en cuenta que  max(abs(A(i,j)))  no es una norma de matriz consistente.
!>

Parámetros

NORMA 
!>          NORMA es CHARACTER*1
!>          Especifica el valor a devolver en ZLANTR como se describe
!>          arriba.
!>

UPLO

!>          UPLO es CHARACTER*1
!>          Especifica si la matriz A es trapezoidal superior o inferior.
!>          = 'U':  Trapezoidal superior
!>          = 'L':  Trapezoidal inferior
!>          Tenga en cuenta que A es triangular en lugar de trapezoidal si M = N.
!>

DIAG

!>          DIAG es CHARACTER*1
!>          Especifica si la matriz A tiene o no una diagonal unitaria.
!>          = 'N':  Diagonal no unitaria
!>          = 'U':  Diagonal unitaria
!>

M

!>          M es INTEGER
!>          El número de filas de la matriz A.  M >= 0, y si
!>          UPLO = 'U', M <= N.  Cuando M = 0, ZLANTR se establece en cero.
!>

N

!>          N es INTEGER
!>          El número de columnas de la matriz A.  N >= 0, y si
!>          UPLO = 'L', N <= M.  Cuando N = 0, ZLANTR se establece en cero.
!>

A

!>          A es un array COMPLEX*16, dimensión (LDA,N)
!>          La matriz trapezoidal A (A es triangular si M = N).
!>          Si UPLO = 'U', la parte trapezoidal superior de m por n principal de
!>          el array A contiene la matriz trapezoidal superior, y la
!>          parte triangular estrictamente inferior de A no se referencia.
!>          Si UPLO = 'L', la parte trapezoidal inferior de m por n principal de
!>          el array A contiene la matriz trapezoidal inferior, y la
!>          parte triangular estrictamente superior de A no se referencia.  Tenga
!>          en cuenta que cuando DIAG = 'U', los elementos diagonales de A no
!>          se referencian y se asumen que son uno.
!>

LDA

!>          LDA es INTEGER
!>          La dimensión principal del array A.  LDA >= max(M,1).
!>

WORK

!>          WORK es un array DOUBLE PRECISION, dimensión (MAX(1,LWORK)),
!>          donde LWORK >= M cuando NORMA = 'I'; de lo contrario, WORK no
!>          se referencia.
!>
