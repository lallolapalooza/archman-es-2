SRC/zlaqp2rk.f

SINOPSIS

Funciones/Subrutinas


subrutina zlaqp2rk (m, n, nrhs, ioffset, kmax, abstol, reltol, kp1, maxc2nrm, a, lda, k, maxc2nrmk, relmaxc2nrmk, jpiv, tau, vn1, vn2, work, info)
ZLAQP2RK calcula la factorización QR truncada con pivoteo de columnas de un bloque de matriz compleja utilizando BLAS de nivel 2 y sobrescribe una matriz compleja m por nrhs B con Q**H * B.

Documentación de función/subrutina

subrutina zlaqp2rk (entero m, entero n, entero nrhs, entero ioffset, entero kmax, doble precisión abstol, doble precisión reltol, entero kp1, doble precisión maxc2nrm, complejo*16, dimensión( lda, * ) a, entero lda, entero k, doble precisión maxc2nrmk, doble precisión relmaxc2nrmk, entero, dimensión( * ) jpiv, complejo*16, dimensión( * ) tau, doble precisión, dimensión( * ) vn1, doble precisión, dimensión( * ) vn2, complejo*16, dimensión( * ) work, entero info)

ZLAQP2RK calcula la factorización QR truncada (rango K) con pivoteo de columnas de la matriz compleja A(IOFFSET+1:M,1:N) como A * P(K) = Q(K) * R(K).

Propósito:

!>
!> ZLAQP2RK calcula una factorización QR truncada (de rango K) o de rango completo
!> con pivoteo de columnas de la matriz compleja
!> bloque A(IOFFSET+1:M,1:N) como
!>
!>   A * P(K) = Q(K) * R(K).
!>
!> La rutina utiliza BLAS de nivel 2. El bloque A(1:IOFFSET,1:N)
!> se pivota en consecuencia, pero no se factoriza.
!>
!> La rutina también sobrescribe el bloque de matriz de los lados derechos B
!> almacenado en A(IOFFSET+1:M,N+1:N+NRHS) con Q(K)**H * B.
!>

Parámetros

M 
!>          M es ENTERO
!>          El número de filas de la matriz A. M >= 0.
!>

N

!>          N es ENTERO
!>          El número de columnas de la matriz A. N >= 0.
!>

NRHS

!>          NRHS es ENTERO
!>          El número de lados derechos, es decir, el número de
!>          columnas de la matriz B. NRHS >= 0.
!>

IOFFSET

!>          IOFFSET es ENTERO
!>          El número de filas de la matriz A que deben ser pivotadas
!>          pero no factorizadas. IOFFSET >= 0.
!>
!>          IOFFSET también representa el número de columnas de la matriz
!>          A_orig completa que han sido factorizadas
!>          en los pasos anteriores.
!>

KMAX

!>          KMAX es ENTERO
!>
!>          El primer criterio de parada de la factorización. KMAX >= 0.
!>
!>          El número máximo de columnas de la matriz A a factorizar,
!>          es decir, el rango máximo de factorización.
!>
!>          a) Si KMAX >= min(M-IOFFSET,N), entonces este criterio
!>                de parada no se utiliza, se factorizan columnas
!>                dependiendo de ABSTOL y RELTOL.
!>
!>          b) Si KMAX = 0, entonces este criterio de parada se
!>             satisface en la entrada y la rutina sale inmediatamente.
!>             Esto significa que la factorización no se realiza,
!>             las matrices A y B y los arrays TAU, IPIV
!>             no se modifican.
!>

ABSTOL

!>          ABSTOL es DOBLE PRECISIÓN, no puede ser NaN.
!>
!>          El segundo criterio de parada de la factorización.
!>
!>          La tolerancia absoluta (umbral de parada) para
!>          la norma 2 máxima de columna de la matriz residual.
!>          El algoritmo converge (detiene la factorización) cuando
!>          la norma 2 máxima de columna del residuo
!>          es menor o igual a ABSTOL.
!>
!>          a) Si ABSTOL < 0.0, entonces este criterio de parada no se
!>                utiliza, la rutina factoriza columnas dependiendo
!>                de KMAX y RELTOL.
!>                Esto incluye el caso ABSTOL = -Inf.
!>
!>          b) Si 0.0 <= ABSTOL, entonces se utiliza el valor de entrada
!>                de ABSTOL.
!>

RELTOL

!>          RELTOL es DOBLE PRECISIÓN, no puede ser NaN.
!>
!>          El tercer criterio de parada de la factorización.
!>
!>          La tolerancia (umbral de parada) para la relación entre la
!>          norma 2 máxima de columna de la matriz residual y la norma 2
!>          máxima de columna de la matriz original A_orig. El algoritmo
!>          converge (detiene la factorización) cuando esta relación es
!>          menor o igual a RELTOL.
!>
!>          a) Si RELTOL < 0.0, entonces este criterio de parada no se
!>                utiliza, la rutina factoriza columnas dependiendo
!>                de KMAX y ABSTOL.
!>                Esto incluye el caso RELTOL = -Inf.
!>
!>          d) Si 0.0 <= RELTOL, entonces se utiliza el valor de entrada
!>                de RELTOL.
!>

KP1

!>          KP1 es ENTERO
!>          El índice de la columna con la norma 2 máxima en
!>          la matriz original completa A_orig determinada en
!>          la rutina principal ZGEQP3RK. 1 <= KP1 <= N_orig_mat.
!>

MAXC2NRM

!>          MAXC2NRM es DOBLE PRECISIÓN
!>          La norma 2 máxima de columna de la matriz original completa
!>          A_orig calculada en la rutina principal ZGEQP3RK.
!>          MAXC2NRM >= 0.
!>

A

!>          A es array COMPLEX*16, dimensión (LDA,N+NRHS)
!>          En la entrada:
!>              la matriz A de M por N y la matriz B de M por NRHS, como en
!>
!>                                  N     NRHS
!>              array_A   =   M  [ mat_A, mat_B ]
!>
!>          En la salida:
!>          1. Los elementos del bloque A(IOFFSET+1:M,1:K) por debajo
!>             de la diagonal junto con el array TAU representan
!>             la matriz unitaria Q(K) como un producto de
!>             reflejos elementales.
!>          2. El bloque triangular superior de la matriz A almacenado
!>             en A(IOFFSET+1:M,1:K) es el factor triangular obtenido.
!>          3. El bloque de la matriz A almacenado en A(1:IOFFSET,1:N)
!>             ha sido pivotado en consecuencia, pero no factorizado.
!>          4. El resto del array A, bloque A(IOFFSET+1:M,K+1:N+NRHS).
!>             La parte izquierda A(IOFFSET+1:M,K+1:N) de este bloque
!>             contiene el residuo de la matriz A y,
!>             si NRHS > 0, la parte derecha del bloque
!>             A(IOFFSET+1:M,N+1:N+NRHS) contiene el bloque de
!>             la matriz del lado derecho B. Ambos bloques han sido
!>             actualizados por multiplicación por la izquierda por Q(K)**H.
!>

LDA

!>          LDA es ENTERO
!>          La dimensión principal del array A. LDA >= max(1,M).
!>

K

!>          K es ENTERO
!>          Rango de factorización de la matriz A, es decir, el rango
!>          del factor R, que es lo mismo que el número de filas no cero
!>          del factor R. 0 <= K <= min(M-IOFFSET,KMAX,N).
!>
!>          K también representa el número de vectores de Householder no cero.
!>

MAXC2NRMK

!>          MAXC2NRMK es DOBLE PRECISIÓN
!>          La norma 2 máxima de columna de la matriz residual,
!>          cuando la factorización se detuvo en el rango K. MAXC2NRMK >= 0.
!>

RELMAXC2NRMK

!>          RELMAXC2NRMK es DOBLE PRECISIÓN
!>          La relación MAXC2NRMK / MAXC2NRM de la norma 2 máxima de columna
!>          de la matriz residual (cuando la factorización
!>          se detuvo en el rango K) con la norma 2 máxima de columna
!>          de la matriz original completa A. RELMAXC2NRMK >= 0.
!>

JPIV

!>          JPIV es array ENTERO, dimensión (N)
!>          Índices de pivote de columna, para 1 <= j <= N, columna j
!>

NAME

zlaqp2rk - The subroutine laqp2rk_ is an auxiliary routine that computes the QR factorization of a real matrix A
that is updated with a rank-revealing QR factorization of an N x N matrix.

SYNOPSIS

SUBROUTINE ZLAQP2RK(
  M, N, K, IOFFSET,       NPIVOT, COLTYP, TAU, VN1, VN2, WORK, INFO
)
INTEGER M, N, K, IOFFSET, IPIVOT(*), COLTYP(*)
COMPLEX*16 TAU(*), WORK(*)
DOUBLE PRECISION VN1(*), VN2(*)
INTEGER INFO

Arguments.

M
CHARACTER*1. Specifies whether the matrix A is upper or lower triangular and whether to form the triangular factor Q or R.

M = 'U' : A is upper triangular.
M = 'L' : A is lower triangular.

N
INTEGER. The number of columns of the matrix A. N >= 0.
K
INTEGER. The number of columns of the matrix A. K >= 0.
IOFFSET
INTEGER.

IOFFSET = 0: the first row of A is to be treated as the first row.

IOFFSET > 0: the first row of A is assumed to be empty, and the algorithm is applied to the submatrix A(IOFFSET+1:M, :).

IPIVOT
INTEGER array, dimension at least max(1,N).

IPIVOT(j) is the pivot index for the j-th column.

COLTYP
INTEGER array, dimension at least max(1,N).

COLTYP(j) = 0: free column

COLTYP(j) = 1: basic column

COLTYP(j) = 2: rank-revealing column

TAU
COMPLEX*16 array, dimension (min(M-IOFFSET,N)).

The scalar factors of the elementary reflectors.

VN1
DOUBLE PRECISION array, dimension (N).

The vector with the partial column norms.

VN2
DOUBLE PRECISION array, dimension (N).

The vector with the exact column norms.

WORK
COMPLEX*16 array, dimension (N-1).

Used in ZLARF1F subroutine to apply an elementary reflector from the left.

INFO
INTEGER.

1) INFO = 0: successful exit.

2) If INFO = j_1, where 1 <= j_1 <= N, then NaN was detected and the routine stops the computation. The j_1-th column of the matrix A or the j_1-th element of array TAU contains the first occurrence of NaN in the factorization step K+1 ( when K columns have been factorized ).

On exit:

K is set to the number of factorized columns without exception.

MAXC2NRMK is set to NaN.

RELMAXC2NRMK is set to NaN.

TAU(K+1:min(M,N)) is not set and contains undefined elements. If j_1=K+1, TAU(K+1) may contain NaN.

3) If INFO = j_2, where N+1 <= j_2 <= 2*N, then no NaN was detected, but +Inf (or -Inf) was detected and the routine continues the computation until completion. The (j_2-N)-th column of the matrix A contains the first occurrence of +Inf (or -Inf) in the factorization step K+1 ( when K columns have been factorized ).
