Documentación de función/subrutina

subrutina zlacn2 (integer n, complex*16, dimension( * ) v, complex*16, dimension( * ) x, double precision est, integer kase, integer, dimension( 3 ) isave)

ZLACN2 estima la norma 1 de una matriz cuadrada, utilizando comunicación inversa para evaluar productos matriz-vector.

Propósito:

!>
!> ZLACN2 estima la norma 1 de una matriz compleja cuadrada A.
!> Se utiliza comunicación inversa para evaluar productos matriz-vector.
!>

Parámetros

N 
!>          N es INTEGER
!>         El orden de la matriz.  N >= 1.
!>

V

!>          V es un array COMPLEX*16, de dimensión (N)
!>         En la llamada final, V = A*W, donde EST = norm(V)/norm(W)
!>         (W no se devuelve).
!>

X

!>          X es un array COMPLEX*16, de dimensión (N)
!>         En una llamada intermedia, X debe ser sobrescrito por
!>               A * X,   si KASE=1,
!>               A**H * X,  si KASE=2,
!>         donde A**H es la transpuesta conjugada de A, y ZLACN2 debe ser
!>         llamada de nuevo con todos los demás parámetros sin cambios.
!>

EST

!>          EST es DOUBLE PRECISION
!>         En la entrada con KASE = 1 o 2 y ISAVE(1) = 3, EST debe estar
!>         sin cambios con respecto a la llamada anterior a ZLACN2.
!>         En la salida, EST es una estimación (un límite inferior) para norm(A).
!>

KASE

!>          KASE es INTEGER
!>         En la llamada inicial a ZLACN2, KASE debe ser 0.
!>         En una llamada intermedia, KASE será 1 o 2, indicando
!>         si X debe ser sobrescrito por A * X  o A**H * X.
!>         En la llamada final desde ZLACN2, KASE volverá a ser 0.
!>

ISAVE

!>          ISAVE es un array INTEGER, de dimensión (3)
!>         ISAVE se utiliza para guardar variables entre llamadas a ZLACN2
!>
